#### 分享大纲（基于文章配图幻灯片重构）

##### MD5 与常见加密

- **MD5 算法特性**：单向散列函数，不可逆，仅能通过碰撞库、彩虹表、暴力破解等方式还原。
- **实战要点**：需识别算法实现细节（如加盐、多次哈希、截断等），针对性选择爆破策略。
- **相关工具/资源**：在线解密网站、Hashcat、John the Ripper、Factordb 等。

##### 逆向工程基础与进阶

- **核心难点解析**：
  - **加壳**：UPX 等压缩壳、保护壳（VMProtect、Themida 等）对静态分析的阻碍，脱壳技术（ESP 定律、单步跟踪、内存镜像导出）。
  - **反调试**：`IsDebuggerPresent`、`CheckRemoteDebuggerPresent`、时间检测、硬件断点检测、自修改代码等常见手法及绕过思路。
  - **花指令**：插入无效指令干扰反汇编流程（如 `JMP`、`CALL` 配合垃圾字节），IDA Pro 识别失败，需动态调试或脚本修复。
- **实战题目演示**：（文章标注「本内容仅现场可见」）现场演示一道典型逆向题目，涵盖上述技术点的综合运用。

##### PWN 入门与题目介绍

- **核心概念**：PWN 即攻破二进制程序获取 Shell/控制权，涉及栈溢出、堆利用、格式化字符串、ROP 链构造等。
- **题目介绍**：（文章标注「本内容仅现场可见」）现场讲解常见 PWN 题目类型、调试环境搭建（pwndbg/peda）、基本利用流程。

#### 史料价值

- 记录了 0w1Club **早期「萌新培养」体系下的系列化线下分享会** 典型案例（第十一期），主讲人为大三学生（于丁），自称「CTF赛狗」「热衷二进制安全」，体现社团**「传帮带、实战派上台」**的工程文化。

#### 分享大纲（基于文章配图幻灯片重构）

##### 前置知识：ARP 协议

- **ARP 协议作用**：解决 IP 地址到 MAC 地址的映射。
- **ARP 请求/应答流程**：广播请求目标 IP 对应的 MAC，目标单播应答。
- **ARP 缓存表**：本地维护 IP-MAC 映射缓存，提高通信效率。
- **免费 ARP (Gratuitous ARP)**：主动广播自身 IP-MAC 绑定，用于地址冲突检测、IP 漂移、更新邻居缓存。

##### ARP 攻击（ARP 欺骗/投毒）

- **攻击原理**：利用 ARP 协议无身份认证、缓存可被覆盖的缺陷，伪造 ARP 应答包，将攻击者 MAC 地址与网关/目标 IP 绑定，写入受害者及网关缓存。
- **中间人攻击 (MITM) 流程**：
  1. **探测**：扫描局域网存活主机（如 `netdiscover`、`arp-scan`）。
  2. **投毒**：持续发送伪造 ARP 包，欺骗目标“网关 MAC 是攻击者”，欺骗网关“目标 MAC 是攻击者”。
  3. **转发**：开启 IP 转发 (`sysctl -w net.ipv4.ip_forward=1`)，流量经攻击者机器中转，实现窃听、篡改、会话劫持。
- **常用工具演示**：`arpspoof` (dsniff 套件)、`ettercap` (图形/命令行)、`bettercap` (现代化框架)、`Wireshark` (流量抓取分析)。
- **后续利用思路**：DNS 劫持、HTTP 注入、会话劫持、SSL Strip 降级攻击（结合证书伪造）、内网渗透横向移动跳板。
- **防御与检测**：静态绑定 ARP、动态 ARP 检测 (DAI)、端口安全、监控 ARP 流量异常、使用 HTTPS/HSTS 防止明文劫持。

##### 伪造 CA 证书

核心内容围绕 SSL/TLS 证书体系的信任链机制，演示如何伪造 CA 证书实施中间人攻击：

- **证书信任链原理**：根 CA → 中间 CA → 叶子证书的验证流程
- **自签名证书制作**：使用 OpenSSL 生成根 CA 密钥对、签发中间 CA、签发目标域名证书
- **信任植入攻击**：将伪造根证书导入受害者系统/浏览器信任存储，绕过证书验证告警
- **中间人攻击实战**：配合 ARP 欺骗/ DNS 劫持，拦截 HTTPS 流量并解密
- **检测与防御**：证书透明度、HPKP（已废弃）、Expect-CT、浏览器证书固定机制

> **技术延伸**：该主题与 [[0w1club-week2-wifi-hijacking-arp-spoofing]] 中的 ARP 欺骗中间人攻击形成完整攻击链——ARP 欺骗实现流量劫持，伪造证书实现 HTTPS 解密。

核心内容涵盖以人为突破口的攻击手法体系：

- **核心原理**：利用人性弱点（信任、恐惧、贪婪、好奇、懒惰）绕过技术防线
- **攻击阶段**：信息收集 → 建立信任 → 诱导操作 → 获取权限/信息 → 清理痕迹
- **常见手法**：
  - **钓鱼邮件/钓鱼网站**：伪造登录页、伪造证书配合 HTTPS 增加可信度

  - **物理渗透**：尾随入内、伪造工牌、USB 投放
  - **水坑攻击**：植入常访网站恶意代码
- **实战案例**：结合证书伪造，演示如何制作「带绿锁」的钓鱼页面降低受害者警惕
- **防范意识**：多因子认证、证书指纹校验、安全意识培训、零信任架构

#### 研究方向全景

| 方向 | 核心描述 | 关键技术点 |
|------|----------|------------|
| **WEB 安全** | 网络安全常用突破口，攻击方式多样、技术复杂、难以防御；网页作为对外媒介常为攻击起点，访问量大适合撒网 | SQL注入、XSS、CSRF、SSRF、文件上传、反序列化、框架漏洞等 |
| **逆向工程** | 通过已有结果（汇编、二进制）推导实现方法；如分析验证逻辑跳过注册码（破解） | 静态分析、动态调试、脱壳破解、算法还原、IDA/Ghidra 使用 |
| **密码学** | 研究编制/破译密码技术科学，广泛应用于安全协议、数字签名、身份认证，保障机密性、完整性、抗抵赖 | 对称/非对称加密、哈希、数字签名、侧信道攻击、协议分析 |
| **PWN** | 黑客俚语，指攻破设备/系统获取 Shell 实现控制；万物皆可 PWN 时代已来 | 栈溢出、堆利用、ROP、格式化字符串、内核漏洞、沙箱逃逸 |
| **无线安全** | 涵盖无线电相关安全：RFID、蓝牙、WiFi、汽车遥控、手机通讯、GPS 导航等 | 协议分析、信号重放、中继攻击、SDR、蓝牙/WiFi 协议栈漏洞 |
| **其他方向** | 包含但不限于以上，步伐不止步于当前 | 移动安全、IoT 安全、AI 安全、区块链安全等新兴领域 |
