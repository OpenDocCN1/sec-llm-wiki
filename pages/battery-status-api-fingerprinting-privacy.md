## 概述

HTML5 **Battery Status API（电池状态API）** 作为标准 Web 接口内置于 Firefox、Chrome、Opera 等主流浏览器，原本设计用于让网站根据设备剩余电量提供省电版页面。然而，斯坦福大学研究人员发现，该 API 返回的**电量百分比、充电时间、放电时间**三个字段组合可形成约 **1400 万种唯一组合**，足以构建高熵的**设备数字指纹**，实现跨会话、跨站点的用户追踪，准确率高达 **90%**。

> **核心风险**：该追踪机制**不依赖 Cookie、LocalStorage 或 IP 地址**，常规隐私防护手段（清理 Cookie、使用 VPN、安装 AdBlock 等）**全部失效**。几乎所有移动设备均受影响，电池老化设备因特征更稳定、风险更高。

## 技术原理

### API 字段与指纹熵

| 字段 | 说明 | 更新频率 | 指纹贡献 |
|------|------|----------|----------|
| `level` | 当前电量百分比（0.0–1.0） | 每 30 秒 | 高 |
| `chargingTime` | 距充满剩余秒数（充电中） | 每 30 秒 | 中 |
| `dischargingTime` | 距耗尽剩余秒数（放电中） | 每 30 秒 | 高 |

三字段组合形成 **~1400 万种可能状态**，在短时间窗口内对单一设备近乎唯一，可作为**高稳定性指纹因子**。

### 追踪模型

1. **首次访问**：站点读取 Battery API，记录三元组 `(level, chargingTime, dischargingTime)` 作为指纹基线。
2. **后续访问 / 跨站嵌入**：同一浏览器上下文中再次读取 API，若三元组演化轨迹与基线吻合，即判定为同一设备/用户。
3. **企业内网场景**：设备共享相似硬件型号、相同出口 IP，电池指纹成为**唯一区分因子**。

## 实证威胁

- **野外检测**：安全研究人员已在互联网上发现 **两个大规模部署的追踪脚本**，主动调用 Battery API 采集用户数据，证实该技术已被商业化滥用。
- **商业动机**：Uber 经济研究主管 Keith Chen 透露，公司已关注电量监控技术——**电量低时用户支付意愿显著上升**，可用于动态定价。

## 防御现状：常规手段全面失效

| 防护手段 | 对 Battery 指纹有效性 | 原因 |
|----------|----------------------|------|
| 清除 Cookie / LocalStorage | ❌ 无效 | 指纹源自硬件状态，非存储介质 |
| 使用 VPN / 代理 | ❌ 无效 | 指纹与网络层无关 |
| 安装 AdBlock / 隐私插件 | ❌ 无效 | 多数插件未拦截 Battery API 调用 |
| 无痕/隐私模式 | ❌ 无效 | API 在无痕模式下仍可用 |

## 可行缓解方案

### 用户端（权宜之计）

1. **保持设备接入电源**  
   充电状态下 `dischargingTime` 为 `Infinity`，`chargingTime` 随充电曲线变化，**打破指纹的规律性与唯一性**。
2. **使用浏览器扩展阻断/噪声化 API**  
   - `Chameleon`、`CanvasBlocker` 等扩展可伪造或随机化 Battery API 返回值。
   - 需注意：过度随机化可能导致网站省电策略失效。

### 厂商/标准端（根治路径）

1. **降低 API 精度**  
   - 将 `level` 量化为粗粒度区间（如 0%、25%、50%、75%、100%），大幅降低指纹熵。
   - Firefox 曾在 v52+ 尝试四舍五入至最近 10%，后因兼容性回滚。
2. **引入权限模型**  
   - 将 Battery API 列入**强权限**，需用户显式授权后方可调用（类比 Geolocation API）。
3. **仅在安全上下文暴露**  
   - 限制仅 HTTPS 页面可调用，减少中间人注入追踪脚本的面。

## 时间线与演进

| 时间 | 事件 |
|------|------|

| 2015 | Firefox、Chrome、Opera 陆续默认启用 |

## 总结与建议

1. **威胁等级：高** —— 无需用户交互、跨会话稳定、常规防护失效。
2. **短期对策**：保持充电、部署 API 阻断扩展、关注浏览器厂商补丁。
3. **长期呼吁**：推动 W3C/浏览器厂商将 Battery API 纳入**权限治理体系**，默认拒绝、最小化精度、审计调用方。

> **一句话**：电池电量不再只是续航指标，它已成为**无需授权、难以清除、高精度识别**的隐形追踪器。
