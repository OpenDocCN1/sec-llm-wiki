## 概述

本页面复盘 301在路上 微信公众号于 2017 年元宵节（2 月 11 日）发布的实战案例《妈，我没法回家过元宵节，机票被人”恶意”取消了》。文章记录了两起因用户在朋友圈晒登机牌/行程单图片，导致**电子客票号（ETKT）、姓名、手机号**三要素泄露，攻击者仅凭这三要素即可登入**中国国际航空、中国南方航空、中国东方航空、中国海南航空**四大航司自助值机系统，实施恶意选座、改签、退票等操作的完整攻击链。本页面将零散案例沉淀为结构化知识页，包含攻击面分析、四大航司鉴权逻辑对比、敏感字段清单及防范操作指南。

## 攻击链完整复现

### 核心前提：三要素即可接管值机流程

| 要素 | 来源 | 泄露渠道 |
|------|------|----------|
| **电子客票号 (ETKT)** | 登机牌/行程单正文、二维码/条形码解码 | 朋友圈/微博/小红书等社交平台晒图 |
| **姓名** | 登机牌/行程单正文 | 同上 |
| **手机号** | 行程单预留字段、或通过社工库/公开资料关联 | 同上/跨平台关联 |

> **关键结论**：四大航司自助值机接口均**不强制要求身份证号/护照号**，仅需「票号/身份证号/护照号 + 姓名」或「票号 + 姓名 + 手机号」组合即可通过鉴权，进入值机、选座、改签、退票全功能流程。

### 案例一：安全从业者「部分遮挡」仍泄露 ETKT

- **场景**：某白帽子同学发朋友圈求勾搭，附行程单图片，**姓名已打码，但 ETKT 清晰可见**。
- **攻击路径**：
  1. 识别航班号 `JD5561`（首都航空，北京→呼和浩特）。
  2. 结合已知姓名、手机号（熟人社工）+ 图片中的 ETKT。
  3. 登录 **信天游平台**（首都航空值机入口）核验行程单详情。
  4. 进入自助值机系统，可执行补打登机牌、取消行程等操作。
- **教训**：**仅遮挡姓名不够，ETKT 与手机号同属核心凭证**，必须同步打码。

### 案例二：完全裸奔的全图晒单

- **场景**：同学晒全图行程单（上海→武汉 `MU2506` 东航），**姓名、ETKT、航班号全可见**。
- **攻击路径**：
  1. 直接提取 ETKT、姓名、航班号。
  2. 打开 **东方航空官网自助服务**，仅需「身份证/护照/票号 + 姓名」即可查询。
  3. 成功进入值机界面，可执行全流程操作。
- **教训**：**全图晒单等同于把「机票钥匙」交给陌生人**。

## 四大航司自助值机鉴权逻辑对比（2017 年实测）

| 航司 | 入口示例 | 鉴权要素组合 | 是否强制身份证号 | 备注 |
|------|----------|--------------|------------------|------|
| **中国国际航空 (CA)** | 官网/APP「自助值机」 | 身份证/护照/票号 + **手机号 + 姓名** | 否 | 三要素任选其一配合手机号+姓名 |
| **中国南方航空 (CZ)** | 官网/APP「自助值机」 | 身份证/护照/票号 + **姓名** | 否 | 双要素即可 |
| **中国东方航空 (MU)** | 官网/APP「自助服务」 | 身份证/护照/票号 + **姓名** | 否 | 双要素即可 |
| **中国海南航空 (HU)** | 官网/APP「自助值机」 | 身份证/护照/票号/订票编码 + **姓名 + 出发城市** | 否 | 三要素，增加出发城市作为弱校验 |

> **共性弱点**：均**未实施二次认证（短信验证码/人脸核验/动态口令）**，亦无「值机密码」或「动态令牌」机制，导致静态三要素即可完全接管值机权限。

## 登机牌/行程单敏感字段清单（必打码字段）

| 字段 | 位置示例 | 风险等级 | 说明 |
|------|----------|----------|------|
| **电子客票号 (ETKT)** | 正文「ETKT」字段、二维码/条形码 Payload | **Critical** | 核心凭证，等同「机票密钥」 |
| **姓名** | 正文「NAME/PASSENGER」字段 | **Critical** | 配合 ETKT 完成身份绑定 |
| **手机号** | 行程单「联系电话」、预留信息 | **High** | 国航值机必填，亦可用于社工库关联 |
| **身份证号/护照号** | 行程单「证件号码」、登机牌磁条/二维码 | **Critical** | 部分航司可替代 ETKT 作为查询键 |
| **航班号/日期/出发-到达城市** | 正文显眼位置 | **Medium** | 辅助缩小攻击面，锁定具体航段 |
| **订票编码 (PNR/Booking Reference)** | 行程单「订单号/预订码」 | **High** | 海航值机可用，亦可登录航司官网管理行程 |
| **二维码/条形码** | 登机牌右侧/底部 | **Critical** | 扫码即可解析上述所有字段，**必须物理遮挡或像素级打码** |

> **实操建议**：使用**不透明色块/马赛克**覆盖上述字段；**不要仅用手指/表情贴纸遮挡**（可被图像复原）；**不要发送原图**（EXIF 可能含 GPS/设备信息）。

## 防范清单（个人版 + 企业版）

### 个人用户操作指南

1. **不晒图最安全**：行程单/登机牌默认不发朋友圈/微博/小红书。
2. **必须晒时**：
   - 使用**截图+像素级打码**（推荐微信自带编辑器/美图秀秀「马赛克」），覆盖 ETKT、姓名、手机号、证件号、二维码、PNR。
   - **遮挡二维码/条形码整块区域**，防止扫码解析。
   - 发布后**及时删除**，缩短暴露窗口。
3. **值机后销毁实体登机牌**：登机牌磁条/二维码同含完整信息，登机后剪碎/撕毁再丢弃。
4. **开启航司 APP 登录保护**：绑定手机动态验证码/人脸识别/指纹，若航司支持「值机锁」功能务必开启。
5. **发现异常立即联系航司**：通过官方客服电话/柜台冻结行程，保留截图证据报警。

### 企业/组织安全规范建议

| 控制点 | 实施建议 |
|--------|----------|
| **员工安全意识培训** | 纳入入职/年度培训，演示「晒登机牌→被退票」实战视频，发放《出差信息安全口袋书》 |
| **差旅管理制度** | 规定「含敏感字段的登机牌/行程单严禁发布至公开社交平台」，违规纳入绩效考核 |
| **供应链/合作伙伴协议** | 要求差旅服务商（OTA/旅行社）在电子行程单中**默认脱敏/加密 ETKT、证件号**，提供「一键生成脱敏版」功能 |
| **航司侧加固建议（推送给 SRC/监管）** | 引入「值机二次认证（短信/邮件/APP 推送验证码）」、「动态值机令牌」、「异地/异设备值机风控拦截」、「操作审计日志实时推送旅客」 |

## 关联攻击面与延伸阅读

- **SIM Swap / 补卡攻击**：攻击者若进一步劫持手机号（[[sim-swap-attack-case-study-alipay-bank-theft]]），可绕过「手机号」要素，直接重置航司账号密码，实现持久化控制。
- **社工库撞库/凭证填充**：泄露的「姓名+手机号+身份证号」可用于 [[credential-stuffing-password-hygiene]]、[[api-business-logic-phone-enumeration]] 等下游攻击。
- **社会工程学钓鱼**：攻击者冒充航司客服，引用 ETKT/航班号建立信任，诱导受害者点击钓鱼链接/安装远控（[[social-engineering-attack-techniques]]）。
- **行程单/登机牌二维码溯源**：二维码遵循 IATA BCBP 标准，解析工具（如 `zxing`、在线解码站）可批量提取字段，**打码必须覆盖整个码块**。

## 结语

「晒登机牌 = 发机票钥匙」在 2017 年即被实战验证，**核心根因在于航司自助值机系统长期依赖静态弱鉴权（三要素），缺乏动态二次认证与风控**。虽然头部航司已逐步加固，但**存量风险、长尾航司、国际航段、代理渠道**仍存同类漏洞。个人层面「不晒、全码、即毁」是成本最低的防御；企业层面应将「差旅数据脱敏」纳入供应链安全要求，推动航司侧从合规与 SRC 双向完成鉴权升级。
