## CTF 简介

CTF（Capture The Flag，夺旗赛）是网络安全领域主流的竞赛形式。参赛者通过解决出题方设计的挑战题目，从目标系统、文件、流量、代码等载体中提取特定格式的字符串——**Flag**（通常形如 `KEY{...}` 或 `flag{...}`），提交得分。

- **赛制分类**：Jeopardy（解题模式，按类别分题、按分值计分）、Attack-Defense（攻防模式，维护己方服务攻击对方）、King of the Hill（争夺目标主机控制权）。
- **常考方向**：Web、Pwn、Reverse、Crypto、Misc、Forensics 等。
- **价值**：保研加分、均分加成、奖金丰厚，更核心的是通过实战快速提升网络安全综合技术栈。

## 主流练习平台梯度推进

| 平台 | 定位 | 题目特点 | 适用阶段 | 题解获取难度 |
|------|------|----------|----------|--------------|
| **[bugku](https://ctf.bugku.com/)** | 基础入门平台 | 经典基础题、覆盖面广、社区题解极丰富 | 入门期（建议全做） | 易（百度/必应即可搜到） |
| **[adworld.xctf.org.cn](https://adworld.xctf.org.cn/)** | 进阶提升平台 | 题目质量高、贴近实战、知识点更深 | 基础掌握后 | 中（部分题解需深挖） |
| **[buuoj.cn](https://buuoj.cn/challenges)** | 实战接轨平台 | 全新题目、贴近近年比赛原题、无现成题解 | 冲刺/实战期 | 难（需自力更生或组队研讨） |

> **建议路线**：bugku 全刷建立知识骨架 → adworld 专项攻坚补齐短板 → buuoj 模拟实战检验综合能力。

## Writeup 驱动学习法（核心自学闭环）

> **核心原则**：**“不会就查、查不会再查、查完记笔记、定期回顾”**。做对题不是目的，**理解解题链路、内化知识点**才是目的。

### 标准化步骤

1. **独立尝试**  
   打开新题，调动已有知识库在 15–30 分钟内尝试解出；能解出则记录关键技巧，进入下一题。

2. **检索 Writeup**  
   关键词策略：`平台名 + 题目名 + writeup`（如 `bugku web2 writeup`）  
   推荐搜索引擎：必应（cn.bing.com）> Google > 百度。

3. **对照复现**  
   逐步跟随 Writeup 操作，**每一步都要亲手敲命令/点界面**，遇到陌生名词（如“开发者工具”、“Base64”、“SQL 注入”）立即停下来。

4. **名词展开搜索（知识树生长）**  
   - 将不懂的名词记入笔记  
   - 搜索该名词的定义、原理、常用工具、变种利用  
   - 搜索过程中再遇新名词，递归上述过程，直到落地到可操作的命令/代码片段。

5. **笔记沉淀（见下节）**  
   将本题涉及的**知识点、工具命令、绕过技巧、易错点**结构化写入个人知识库。

6. **延迟复现**  
   24 小时、1 周、1 个月后**不看笔记**重做一遍，验证内化程度。

## 笔记沉淀与知识图谱构建策略

### 单题笔记模板（建议 Markdown + 双向链接）

```markdown
# [平台] 题目名 - 方向 - 难度

## 核心考点
- 知识点 A（链接到通用知识页面）
- 知识点 B

## 解题链路
1. 信息收集：...
2. 漏洞发现：...
3. 利用构造：...
4. Flag 获取：...

## 关键命令/代码片段
```bash
# 关键命令
```

## 坑点/绕过技巧
- ...

## 延伸学习
- [[相关通用知识页面]]
- 参考 Writeup 链接
```

### 通用知识页面（原子化、可复用）

- 按**技术点**建立页面（如 `SQL注入-报错注入`、`XSS-反射型绕过WAF`、`Vim加密文件破解`），而非按题目。
- 页面内部用 `[[wikilink]]` 互联，形成知识图谱。
- 定期回顾合并同类项，提炼**通用方法论/检查清单/工具速查表**。

### 工具链管理

- 在通用页面维护“常用工具/命令/参数”表格，避免重复造轮子。
- 例：`[[ctf-misc入门与工具箱]]` 已整理 binwalk、foremost、steghide、Volatility 等核心工具速查。

## 实战演示：bugku Web2 解题复现

> 以最基础的“查看源码/开发者工具”考点为例，演示完整闭环。

1. **注册登录** → 进入题目列表 → 点击 `web2` 获取目标 URL。
2. **独立尝试**：打开页面，无明显交互入口。
3. **检索 Writeup**：搜索 `bugku web2 writeup` → 发现提示“F12 开发者工具查看源码/元素/控制台”。
4. **名词展开**：搜索“浏览器开发者工具 使用教程” → 学会 Elements/Console/Sources/Network 面板基础操作。
5. **复现**：F12 打开 Elements 面板 → 在 HTML 注释/隐藏输入框/JS 变量中发现 `flag` 字符串 → 提交得分。
6. **笔记沉淀**：
   - 新建/更新 `Web-信息收集-前端源码审计` 页面，记录“F12 Elements/Console/Network 三板斧”、“注释泄露”、“前端校验绕过”等通用技巧。
   - 在单题笔记中引用该通用页面。

## 结语

**CTF 全靠自学，自学全靠“Writeup 驱动 + 笔记沉淀 + 间隔复现”**。  
从 bugku 的第一道 Web 题开始，把每一个陌生名词变成知识库里的一个页面，把每一次绕过技巧变成通用检查清单的一个条目。  
**日日精进，终成 Dalao。**
