### Hades - Java 白盒审计工具

**项目地址**：https://github.com/zsdlove/Hades

新开源的 Java 白盒审计工具，旨在辅助安全研究人员对 Java 应用程序进行静态代码分析与漏洞挖掘。

### Voyager - 安全工具集合平台（Web 端）

**项目地址**：https://github.com/ody5sey/Voyager.git

基于 Web 界面的安全工具聚合平台，集成多类安全工具，便于渗透测试与安全运营人员统一调度与管理。
