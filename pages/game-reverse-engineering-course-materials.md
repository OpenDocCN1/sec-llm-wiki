## 概述

本页面整理自 0w1Club 微信公众号 2022 年新年福利分享的「游戏逆向课程网盘资料」，由 **易道云** 老师授课制作。课程采用**项目驱动**教学模式，从逆向基础入手，逐步深入到游戏实战项目（登陆器开发、上帝视角修复、多开检测对抗）、加壳保护技术（壳代码生成、隐藏跳转、数据加密）、反调试原理与绕过，形成一套较完整的 **游戏逆向工程技术栈**。

> 📌 资料获取方式：公众号后台回复「新年快乐」获取阿里云盘不限速下载链接。

### 模块 3：游戏登陆器逆向与开发实战

**项目目标**：从零逆向某款游戏登陆器，重写配置解析、UI 交互、启动游戏、进程通信全流程。

| 编号 | 视频标题 | 技术重点 |
|------|----------|----------|
| 3.1 | 项目需求与需求拆解 | 需求建模、模块划分、接口设计 |
| 3.2 | 设定画面质量功能的逆向分析 | 配置文件二进制结构、画质参数映射 |
| 3.3 | 登陆器配置文件的二进制分析 | 自定义二进制格式、偏移定位、校验算法 |
| 3.4 | 游戏登陆器的 UI 搭建 | Qt/MFC 界面框架、信号槽/消息映射 |
| 3.5 | 读取配置文件到 UI 界面 | 结构体映射、数据绑定、异常处理 |
| 3.6 | UI 界面数据写入配置文件 | 逆向写入逻辑、校验重算、完整性保护 |
| 3.7 | 登陆器启动游戏功能的逆向分析 | CreateProcess、参数注入、环境变量构造 |
| 3.8 | 登陆器启动游戏功能的实现 | 进程创建、DLL 注入、入口点 Hook |
| 3.9 | 实现客户端关闭登陆器的消息接口 | IPC 通信（管道/共享内存/WM_COPYDATA）、优雅退出 |

> 🔗 涉及 PE 结构解析、导入表修复、手动映射等底层技术，可参考 [[pe-import-table-internals]]、[[pe-export-table-internals]]、[[pe-manual-mapping-loader-implementation]]。

### 模块 4：上帝视角功能逆向分析与修复

**项目目标**：定位并修复游戏客户端「上帝视角」功能被屏蔽/破坏的问题。

| 编号 | 视频标题 | 技术重点 |
|------|----------|----------|
| 4.1 | 项目需求与需求拆解 | 功能定位、调用链追踪、补丁策略 |
| 4.2 | 上帝视角的逆向分析与修复尝试 | 视角矩阵计算、渲染管线 Hook、NOP/跳转修补 |

### 模块 5：多开检测对抗与代码保护引擎

**项目目标**：实现游戏多开检测（启动时/运行时），并设计代码保护引擎防止插件被剥离。

| 5.3 | 客户端插件模块项目的搭建 | DLL 插件架构、导出表规范、版本管理 |
| 5.4 | 游戏启动时多开检测功能的实现 | 互斥体、全局原子、窗口类枚举、WMI 查询 |
| 5.5 | 游戏结束过程的逆向分析 | 退出回调、资源清理、反调试埋点 |
| 5.6 | 游戏多开检测功能的完善 | 运行时轮询、驱动级枚举、进程快照对比 |
| 5.7 | 防止插件被剥离的代码保护引擎设计 | 代码虚拟化、控制流平坦化、指令抽离、关键代码加密 |
| 5.8 | 壳技术应用-代码保护引擎的实现 | 虚拟机解释器、字节码设计、上下文切换 |
| 5.9 | 代码保护引擎还原游戏代码 | 运行时解密、JIT 还原、调试器对抗 |
| 5.10 | 逆向分析代码保护引擎的奔溃原因 | 异常处理、上下文保存恢复、指令长度解析 |
| 5.11 | 重新接管游戏退出过程 | 向量异常处理 (VEH)、SEH 链劫持、退出钩子 |
| 5.12 | 实现游戏运行中的多开检测 | 定时器轮询、驱动回调、共享内存标记 |

> 🔗 代码保护引擎涉及 **控制流平坦化**、**指令虚拟化**，可对照 [[binary-ninja-ollvm-deobfuscation]] 学习去平坦化分析；反调试技巧见 [[0w1club-week11-crypto-re-pwn-training]]。

### 模块 7：隐藏跳转壳代码与数据加密

**项目目标**：在壳层引入控制流混淆（隐藏跳转），并对壳数据实施强加密，提升静态分析难度。

| 7.1 | 项目需求与需求拆解 | 混淆策略、性能权衡、兼容性测试 |
| 7.2 | 回顾我们之前的逆向分析寻找壳漏洞 | 静态特征、动态调试断点、内存搜索 |
| 7.3 | 保护壳增加隐藏跳转代码的功能 | 不透明谓词、间接跳转、栈平衡维护 |
| 7.4 | 选择配置时自动显示对应反汇编 | 交互式反汇编、指令高亮、控制流图 |
| 7.5 | 实现生成隐藏跳转的壳代码 | 代码模板、随机化插桩、控制流图变换 |
| 7.6 | 游戏扩展插件实现对隐藏壳代码的支持 | 运行时还原、指令模拟执行、上下文重建 |

## 学习建议与实践路线

1. **基础夯实（第 1-2 模块）**  
   - 补齐汇编、PE 结构、编译原理、法律红线  
   - 搭建分析环境：IDA Pro + x64dbg + CE + Python 脚本库

2. **项目实战（第 3-5 模块）**  
   - 选取一款简单 Unity/UE4/Cocos2d-x 游戏，完整复现「登陆器逆向 → 功能 Hook → 多开对抗 → 保护引擎」全链路  
   - 重点攻克：**入口点注入**、**IAT Hook**、**VEH/SEH 异常处理**、**代码虚拟化雏形**

3. **壳技术深造（第 6-7 模块）**  
   - 手写一个 **最小可用加壳器**（支持代码段加密、OEP 隐藏、IAT 重建）  
   - 引入 **控制流平坦化**、**不透明谓词**、**指令替换** 三大混淆手段  
   - 使用 Binary Ninja / IDA + Python 编写去混淆脚本，形成「攻-防」闭环

4. **反调试对抗（第 8 模块）**  
   - 收集主流反调试手法清单（BeingDebugged、NtGlobalFlag、Heap Flags、Timing Check、Hardware BP、内核回调）  
   - 在调试器插件层（x64dbg Python / TitanEngine / ScyllaHide）逐个实现绕过  
   - 尝试编写 **内核级隐藏驱动**（仅限本地测试环境），理解驱动对抗本质

5. **持续扩展**  
   - 移动端游戏逆向：[[android-shelling-unshelling-techniques]]  
   - 浏览器/引擎漏洞挖掘：[[v8-issue-944062-gc-arbitrary-write]]、[[v8-turbofan-changeint32toint64-1day-analysis]]  
   - 内核漏洞利用：[[heap-overflow-principles-unlink-exploitation]]、[[mtctf-2021-pwn-writeup]]  
   - 红队基础设施：[[c2-redirectors-malleable-c2-profiles]]、[[cobalt-strike-external-c2-smb-beacon]]
