## 概述

**Listing View**（陈列窗口）是 Ghidra CodeBrowser 中占据界面中央、面积最大的核心窗口。它以线性方式陈列程序的指令与数据，并作为用户与反汇编结果交互的主要入口。掌握 Listing View 的导航、选择、标记、控制流可视化及悬浮提示等能力，是高效开展静态二进制分析的基础。

> 关联页面：[[ghidra-decompiler-window-guide]]（反编译器窗口指南）、[[ghidra-program-tree-symbol-tree-guide]]（程序树与符号树指南）

## 窗口布局与基础显示

Listing View 默认显示整个程序的地址空间，主要列包括：

- **地址**：当前指令或数据的虚拟地址
- **字节**：原始机器码字节序列
- **算子 / 助记符**：反汇编后的指令文本

通过 **Browser Field Formatter** 可自定义显示列的组合与顺序。当视图内容超出屏幕时，可使用滚动条或鼠标滚轮上下移动。

### 区域聚焦

在 **Program Trees** 窗口（如 Symbol Tree 或 Module Tree）中双击某个段（例如 `.rodata`、`.text`），Listing View 会立即将显示范围限定在该段内，便于聚焦分析特定区域。

## 光标与多重选择

### 光标定位

Listing View 始终维护一个**光标位置**，指向某一具体地址。光标可通过方向键或鼠标点击移动。光标所在位置直接影响其他联动组件，例如：

- 光标置于某函数内 → 打开 **Window → Function Graph** 即可查看该函数的控制流图
- 光标置于数据定义处 → 对应的数据类型、引用关系等信息会在其他窗口同步更新

### 选择操作

| 操作 | 说明 |
|------|------|
| 鼠标左键拖拽 | 连续选择地址范围 |
| `Shift` + 方向键 | 扩展/收缩当前选择范围 |
| `Ctrl` + 鼠标左键点击/拖拽 | **添加**离散区块到当前选择集 |
| `Ctrl` + 对已选区块点击/拖拽 | **移除**该区块出选择集 |

### 高亮显示

- **整体高亮**：选中范围后右键 → **Program Highlight → Entire Selection** 或 `Ctrl+H`，将所选指令/数据在全程序范围内高亮。
- **同文本高亮**：鼠标**中键点击**某条指令（如 `MOV`），全视图内所有**完全匹配**（区分大小写、字符完全一致）的同文本指令均会高亮，便于快速定位同类操作。

## 导航与跳转

Listing View 提供强大的**导航**能力：

- **双击地址/标签**：直接跳转至目标地址。若目标不在当前视野，视图会自动滚动并扩展以包含该地址。
- **双击控制流箭头**：见下节“控制流箭头”，可在跳转源与目标间双向穿梭。

---

## 书签与标记体系

Ghidra 提供两类标记机制，均可通过右键菜单 **Bookmark** 或快捷键 `Ctrl+D` 在光标处或选中范围添加。

### 边缘标记

位于 Listing View **左侧边栏**，仅在当前可见代码范围内显示。用于标记单个地址（点标记）或地址区间（区域标记），直观指示当前屏幕内的关注点。

### 导航标记

位于 Listing View **右侧边栏**，**始终显示整个程序范围内的所有标记**，纵向分为两栏：

- **左栏（点标记）**：单地址书签、断点、注释等
- **右栏（区域标记）**：函数体、数据结构、用户自定义区间等

**交互**：左键单击导航标记 → 视图即刻定位至对应位置；右键点击导航标记区域 → 可自定义显示过滤规则（如仅显示书签、仅显示断点等）。

> 技巧：善用导航标记作为“全程序书签索引”，配合边缘标记的“局部上下文提示”，实现宏观跳转与微观分析的无缝切换。

## 控制流箭头

Listing View 内部以**图形化箭头**直观呈现函数内部控制流：

- **实线箭头**：无条件跳转（`JMP`、 `CALL`、`RET` 等）
- **虚线箭头**：有条件跳转（`JZ`、`JNZ`、`JNE` 等）

### 箭头导航

- 双击箭头任意处 → 跳转至跳转**目标地址**
- 若光标已在目标地址，双击同一箭头 → 反向跳转至**源地址**

此机制使分析者能在分支结构间快速往返，无需在 Program Tree 中反复展开/折叠。

## 悬浮提示

将鼠标悬停于特定元素上方，Listing View 会弹出**上下文悬浮窗**，无需改变当前视图焦点即可获取关键信息。支持的触发对象包括：

| 悬停对象 | 提示内容示例 |
|----------|--------------|
| **地址** | 相对偏移、所属段、所属函数 |
| **内存引用** | 被引用地址的指令/数据上下文、引用类型（读/写/执行） |
| **缩略文本** | 被截断的长字符串、完整的注释内容 |
| **数据类型** | 结构体定义、枚举值映射、数组维度 |
| **函数名** | 函数签名、参数个数、调用约定、栈帧大小 |
| **数量** | 数组元素个数、位掩码位数等 |

> 最佳实践：分析复杂数据结构时，配合悬浮提示快速确认类型布局；追踪交叉引用时，悬停引用地址即可预览上下文，决定是否需要跳转。

## 进阶使用建议

1. **组合键导航**：`G` 键（Go To Address）+ 地址表达式（支持 `currentPC+0x20` 等相对偏移）实现精确跳转。
2. **选择集持久化**：重要分析区间添加书签后，通过导航标记右键 → **Export Bookmarks** 导出为 XML/CSV，便于团队协作或后续复盘。
3. **控制流可视化联动**：Listing View 中双击箭头跳转 → Function Graph 窗口自动高亮对应节点，双窗口协同分析复杂分支逻辑。
4. **悬浮提示配置**：`Edit → Tool Options → Listing Fields → Tooltip` 可调整触发延迟、显示字段集合，适配不同分析节奏。
