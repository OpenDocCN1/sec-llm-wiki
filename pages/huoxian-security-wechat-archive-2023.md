## 公司概况

**火线安全**（北京安全共识科技有限公司）定位为**社区驱动的应用安全创新企业**，核心差异化能力体现在三大维度：

| 维度 | 关键指标 | 说明 |
|------|----------|------|
| **安全服务创新** | 12,000+ 实名白帽专家、100,000+ 原创漏洞 | 全球唯一全实名白帽社区，漏洞产出规模行业领先 |
| **开源理念倡导** | 27 个国家/地区、2,000,000+ 装机量 | **洞态 IAST** 为全球首个开源 IAST 产品，装机量与覆盖面均居前列 |
| **行业最佳实践** | 200+ 大型企业、10w+ 节点部署 | 服务自然资源部、中国银行、腾讯、字节跳动、美团、京东、快手等头部客户 |

投资方包括 **奇绩创坛、经纬中国、五源资本** 等知名机构。

## 薪资福利与文化

- **薪资结构**：全年 13~16 薪，年均 2 次调薪机会，**股票期权** 激励
- **保障体系**：入职即缴 **六险一金**，补充医疗保险、年度免费体检
- **管理模式**：OKR 扁平化管理，**拒绝 KPI**
- **工作制**：不打卡弹性工作时间
- **办公环境**：零食不限量，暖心转正礼物，不定期团队/节日活动
- **成长路径**：汇聚大量技术大佬，提供高效学习环境与全方位学习姿势支持

## 招聘岗位详情

### 一、售前与咨询类

#### 售前工程师（北京/上海/深圳）
**核心职责**
1. 协助销售进行技术交流，精准把握客户需求，结合产品优势引导
2. 撰写售前技术文档（答疑、需求说明书、招投标文档等）
3. 跟进产品使用场景挖掘，为产研提供业务支撑
4. 重点项目项目管理，协调内部技术资源

**任职要求**
- 本科及以上，3 年以上网安行业售前经验（业绩突出可放宽）
- 逻辑清晰，善倾听，精准把握需求
- 熟悉安全产品，有成功项目经验
- **加分项**：CISP/CISSP/CCIE 认证；渗透测试、漏洞挖掘、白盒代码审计背景 → 参见 [[security-engineer-recruitment-requirements]] 中对实战对抗、APT攻防、代码审计等能力维度的细化描述

#### 安全咨询专家
**核心职责**：在售前工程师基础上增加市场拓展计划制定、内部文档体系建设、重点项目统筹、经验沉淀与赋能培训  
**任职要求**：本科及以上，5-8 年网安售前经验，具备方案宣讲、文档呈现、行业洞察、团队管理能力，同等加分项

### 二、销售类

#### 大客户经理（深圳） / 战略客户经理（上海/深圳）
**核心职责**：顾问式销售开发目标行业客户，完成季度/年度指标，推动产品使用场景深化，争取 Upsell 与转介绍  
**任职要求**：
- 本科及以上，理工科背景
- 5-8 年从业，3 年以上 ToB SaaS 销售，业绩前 30%，有拓新经验
- 自律、逻辑强，能深入浅出表述技术话题
- 具备 CXO 对话能力、跨部门决策处理能力
- **加分项**：安全行业相关工作经历（销售/售前/咨询/渗透/培训均可）

### 三、设计类

#### 品牌设计师
**核心职责**：品牌市场分析定位、IP体系搭建、VI制定管理、全链路设计（营销/平面/展会/视频）、品牌活动文案策划  
**任职要求**：
- 本科及以上，平面/多媒体/视觉传达相关专业
- 熟练 CorelDraw/PS/AI，视频剪辑/3D渲染优先
- ToB 或互联网品牌设计经验优先
- 具备综合分析、创意、文案能力，团队精神与推动力

### 四、研发与安全工程类

#### 开发安全工程师
**核心职责**
1. 代码审计，制定安全编码规范
2. 跟踪分析复现安全事件，输出加固建议
3. 研判客户安全工具检测结果，指导代码修复

**任职要求**
- 3 年以上安全行业经验，具备安全编码规范制定经验
- 熟悉 Java 等语言代码缺陷与标准修复方案
- 熟练掌握源代码审计工具与流程，有实战经验
- 熟悉 OWASP TOP 10（SQLi、XSS、CSRF、LFI 等） → 可关联 [[oasys-system-code-audit]] 中 MyBatis `${}` SQL注入、Fastjson、文件上传、越权、任意文件读取、存储型 XSS 等实战审计案例

#### Java开发工程师（核心岗——洞态IAST探针研发）
**核心职责**
1. **Java探针研发**（Agent 端核心开发）
2. 配合安全检测策略，保证漏洞检出率
3. 保证探针兼容性与稳定性

**任职要求**
- 本科以上，计算机相关专业
- **有 APM、RASP、IAST 至少一项开发经验**（直接对标洞态IAST技术栈）
- Java 基础扎实：JVM、多线程、Spring 全家桶、Struts、Hibernate/MyBatis 深入理解
- 微服务开发经验，熟悉常见微服务架构
- 设计模式、基础算法熟悉
- 了解 WebSphere、WebLogic 等中间件

**优先考虑（高阶技术栈揭示）**
1. **分布式系统开发**，熟悉 RPC 框架（Dubbo、gRPC）且**读过源码**
2. **熟练使用 Java 字节码操作**（ASM/ByteBuddy/Javassist 等）——探针插桩核心技能
3. **阅读过相关框架源码**（Spring、中间件、JDK 等）

> **技术栈关键词提取**：Java Agent / 字节码插桩 / JVM TI / APM / RASP / IAST / 微服务治理 / 分布式追踪 / 中间件适配 → 参见 [[java-preparedstatement-sql-injection-defense]] 中对 Java 预编译机制、mysql-connector-java 源码、服务端预编译验证的深度解析，可作为 Java 安全开发基础参考

#### Java测试工程师
**核心职责**：洞态IAST产品测试（Agent端自动化：稳定性/兼容性/性能），全流程测试，Code Review/白盒测试，测试计划/用例设计，灰度发布质量把关  
**任职要求**：
- 3 年以上自动化测试经验，本科及以上
- 具备 Java 测试用例编写与应用开发能力，自动化平台开发经验
- 具备 Code Review/白盒测试能力
- 掌握 SQL、Linux 基础命令

#### Python开发工程师（实习）
**核心职责**：开源产品商业版架构设计与开发，关键系统/模块设计开发，API可用性保障  
**任职要求**：
- 大二大三/研一研二/应届生，计算机相关专业
- 扎实编程功底，良好代码习惯，了解 Pylint/Flake8
- 熟悉 Python/Django，掌握 RESTful 设计与无状态概念
- 熟练 MySQL/Redis/Elasticsearch，基本查询调优
- 探索新技术欲望强，责任心强，抗压
- 了解云原生生态，掌握 Docker，了解 K8s 优先

**优先考虑**
1. **Web漏洞挖掘经验** → 可结合 [[xd-security-src-vulnerability-hunting-notes-day86-88]] 中教育SRC挖掘流程、FOFA语法、.NET单点登录漏洞、MSSQL写Shell等实战技巧
2. **GitHub 账号且向开源项目提交过 Patch**（呼应公司开源理念）

## 核心产品技术栈洞察：洞态IAST

从招聘JD可反推 **洞态IAST（OpenRASP/IAST 混合模式）** 的关键技术架构：

| 技术层面 | 关键能力点 | 对应招聘要求 |
|----------|------------|--------------|
| **探针层** | Java Agent 字节码插桩、JVMTI 原生接口、类加载器隔离、热附着 | Java字节码操作、APM/RASP/IAST开发经验、JVM深入理解 |
| **检测引擎** | 污点传播分析、语义规则引擎、零规则检测、漏洞验证回放 | 安全检测策略配合、漏洞检出率保障、代码审计规范制定 |
| **兼容性** | 主流中间件适配、框架版本兼容、微服务架构支持、多租户隔离 | WebSphere/WebLogic等中间件、微服务/Dubbo/gRPC、分布式系统 |
| **工程化** | 自动化测试体系、灰度发布、性能基线、稳定性压测 | Java测试工程师自动化平台、Code Review、灰度指标把关 |
| **开源生态** | 插件化扩展、社区贡献流程、商业版差异化架构 | Python实习生开源商业版架构、GitHub Patch经验优先 |
