## 概述

本页面整理自某安全团队微信公众号发布的内推招聘信息，汇总了 **渗透测试工程师**、**安全服务工程师**、**蓝队指挥/实战工程师**、**安全运维工程师**、**驻场安全运维工程师** 五类核心安全部门岗位的招聘要求。覆盖北京、深圳、上海、重庆、常州五地，薪资区间 8k–20k/月，经验门槛 1–3 年不等。旨在为安全从业者提供岗位技能画像参考，助力简历匹配与面试准备。

## 核心技能画像拆解

### 渗透测试工程师（北京）

**硬性门槛**
- 本科及以上，毕业 ≥1 年
- 熟悉 **WebShell、SQL 注入、XSS** 等常见漏洞原理及修复方案

**技术栈要求**
- **测试方法论**：黑盒 / 白盒 / 灰盒测试方法熟练掌握
- **主流工具链**：
  - 代理/抓包：[[burpsuite-basics-tutorial|Burp Suite]]
  - 扫描器：AppScan、AWVS、Nessus
  - 注入利用：sqlmap
  - 网络探测：nmap
- **主机安全**：主机漏扫、安全加固、主机入侵检测（HIDS）
- **内网渗透**：横向移动、权限提升、域环境渗透、凭证获取
- **脚本开发能力**：能独立编写自动化脚本/工具（Python/Go/Shell 等）

### 安全服务工程师（深圳）

**硬性门槛**
- 本科及以上，毕业 ≥3 年，3 年工作经验

**核心能力**
- **全栈漏洞知识体系**：熟悉各大漏洞类型（Web、中间件、框架、组件、逻辑漏洞等）
- **移动端/小程序测试**：App 逆向、Hook、动态调试、小程序反编译与接口测试
- **内网渗透实战能力强**：从边界突破到核心资产拿下的完整攻击链经验

**典型交付场景**
- 渗透测试项目交付
- 代码审计/白盒测试
- 红蓝对抗/实战演练（HW/HVV）攻击队支撑
- 应急响应溯源分析

### 蓝队指挥/实战工程师（上海）

**核心定位**
- 面向 **国家电网（国网）实战化攻防演练** 场景
- 需具备**蓝队指挥官**角色经验：技战法制定、防御部署、应急处置、复盘报告输出

**关键能力项**
| 能力维度 | 具体要求 |
|----------|----------|
| 实战经验 | 多次国网/重保/护网实战参与，熟悉攻防演练规则与评分体系 |
| 技战法构建 | 能针对高危漏洞、APT 攻击链产出检测规则、封堵策略、溯源方案 |
| 文档输出 | 规范的防御方案、应急预案、复盘报告、技战法文档编写能力 |
| 资质加分 | CISP、CISSP、ISO27001 LA、软考高项等证书优先 |

### 安全运维工程师（重庆）

**硬性门槛**
- 本科及以上，≥3 年安全相关工作经验
- 云安全运维经验优先

**知识体系**
- **合规框架**：等级保护（等保 2.0）基本流程、测评配合、整改落地
- **攻防技术基本概念**：网络攻击防御、安全评估、安全加固、安全检查、杀毒、渗透测试
- **工程落地能力**：安全设备规划部署、策略调优、日志分析、告警处置

**设备厂商偏好**
- **新华三（H3C）安全设备**建设、维护经验优先（防火墙、WAF、态势感知、准入、审计等）

**软素质要求**
- 良好的沟通协调、团队合作、高执行力、高职业素养、主动性强、独立开展工作

### 驻场安全运维工程师（常州）

**基础信息**
- 薪资：8–12k/月
- 工作制：早八晚六，周末双休
- 定位：某大型国企驻场，周期 2 年

**能力要求**
1. **≥1 年安全行业经验**
2. **主流安全产品运维**：WAF、防火墙、主机防病毒、审计产品、堡垒机、态势感知等
3. **安服交付经验**：Web 漏洞熟悉、渗透测试、漏洞扫描、应急响应、基线核查、安全加固
4. **文档与沟通**：安全报告、整改方案、周/月报输出；甲方汇报、跨部门协调
5. **职业素养**：踏实不浮躁、执行力强
6. **驻场经验优先**

**日常工作内容**
- 网络安全产品日常运维（策略更新、版本升级、故障排查）
- 周期性安全服务：渗透测试、漏洞扫描、基线核查、安全加固
- 配合甲方输出合规材料（等保、整改报告、应急预案等）

## 备注与趋势观察

1. **经验分层明显**：北京/常州接受 1 年经验；深圳/重庆/上海要求 3 年+ 且强调实战交付履历。
2. **内网渗透成标配**：除蓝队指挥岗外，其余四个岗位均将“内网渗透”列为核心硬指标。
3. **工具链标准化**：Burp Suite、sqlmap、Nessus、AWVS、AppScan、nmap 形成事实标准工具集，简历中体现“精通而非会用”更具竞争力。
4. **文档与合规双重压力**：驻场、运维、蓝队岗位均强调文档输出能力与等保/合规流程熟悉度，反映甲方侧“留痕合规”诉求上升。
5. **云安全、移动端成加分项**：重庆岗明确“云安全运维优先”，深圳岗要求“App/小程序测试”，体现攻击面外扩趋势。
