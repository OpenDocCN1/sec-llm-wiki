## 概述

**水影**（ShuiYing_0x727）是由 **0x727团队** 开发的一款基于 C 语言编写的域环境信息收集工具，旨在协助红队或甲方人员评估域环境的安全性。该工具通过枚举域内存活主机、本地管理员组成员、NetSession 会话、委派配置等关键信息，并结合弱口令爆破与通用口令尝试，辅助实现横向移动的“滚雪球”式权限扩展。

> **项目地址**：https://github.com/0x727/ShuiYing_0x727  
> **声明**：文中所涉及的技术、思路和工具仅供以安全为目的的学习交流使用，任何人不得将其用于非法用途以及盈利等目的，否则后果自行承担。

## 核心功能

| 功能模块 | 说明 | 输出文件 |
|----------|------|----------|
| **存活主机探测** | 列出域内所有域机器并进行存活探测，解析 IP | `alive.txt` |
| **本地管理员组枚举** | 获取每台存活域机器的本地管理员组成员（域管理员、域用户、域组、本地 Administrator 等） | `local.txt` |
| **弱口令/通用口令检测** | 针对本地 Administrator 及本地其他用户，尝试通用弱口令（如 `123456`、`P@ssw0rd`）及用户名即密码 | `success.txt`（含完整 IPC 连接命令） |
| **NetSession 枚举** | 查询每台存活域机器的 `net session` 会话信息 | `NetSessions.txt` |
| **委派配置查询** | 枚举域内三类委派配置：非约束委派、约束委派、基于资源的约束委派 | `Deleg.txt` |

## 设计思路与实现原理

### 信息收集的必要性

作者通过场景分析指出域环境常存在的隐患：

- **历史弱口令遗留**：服务器/个人机加入域前可能存在弱口令，加入域后域密码虽强，但本地弱口令账户仍存留。
- **本地管理员组配置不当**：若 `Domain Users` 被加入某台域机器的本地管理员组，攻击者可通过该机器获取大量域用户凭证。
- **委派配置风险**：非约束/约束/基于资源的约束委派配置不当可导致权限提升至域控。

### 工作流程

1. 使用普通域用户凭证与域控建立 IPC 连接，枚举所有域机器。
2. 对每台域机器进行存活探测（ICMP/TCP）。
3. 与存活主机建立 IPC 连接，枚举本地管理员组成员。
4. 针对枚举出的本地账户尝试五种方式获取权限：
   - 当前域用户已在本地管理员组中 → 直接拿下。
   - 本地管理员组包含 `Domain Users` → 直接拿下。
   - 尝试本地 `Administrator` 的通用弱口令。
   - 尝试本地其他用户的“用户名即密码”及弱口令。
   - 利用委派配置（约束委派、基于资源的约束委派）获取机器权限（**不在自动化流程中**，需人工后续利用）。
5. 从拿下的主机导出内存凭证（Hash/明文），积累更多域用户权限，结合 `local.txt` 与委派信息持续横向扩展，直至获取域管权限。

### 横向扩展模型

```
初始凭证 → 拿下弱口令主机 → 导出凭证 → 查找本地管理员组含该用户的主机/委派利用 → 滚雪球扩展 → 域控
```

## 使用方法

```bash
Usage: ShuiYing_0x727.exe <DC-IP> <DC> <domainname\\username> <password> <nbpassword> <t_num>
       ShuiYing_0x727.exe \\域控IP 域名 域名\\域用户 域用户密码 本地administrator通用密码 多线程数目
```

### 三种运行场景

| 场景 | 参数示例 | 说明 |
|------|----------|------|
| **当前 Webshell 为普通域用户，非管理员** | `ShuiYing_0x727.exe \\192.168.159.149 Motoo.nc Motoo\\liwei NULL 123456 1` | `password` 传 `NULL`，以当前进程令牌运行，**不查询委派** |
| **当前 Webshell 为本地普通用户，已提权至 SYSTEM（域机器）** | `ShuiYing_0x727.exe \\192.168.159.149 Motoo.nc Motoo\\LiWei-PC$ NULL 123456 1` | `username` 为机器名`$`，`password` 传 `NULL`，以机器账户运行，**不查询委派** |
| **指定域用户账号密码** | `ShuiYing_0x727.exe \\192.168.159.149 Motoo.nc Motoo\\liwei lw123!@#45 123456 1` | 完整凭证，**会查询域内委派** |

- `nbpassword`：本地 Administrator 通用密码，不知则填 `123456`。
- `t_num`：线程数。

## 常见错误码

| 错误码 | 含义 | 处理建议 |
|--------|------|----------|
| **1219** | 同一用户对同一服务器/共享存在多重连接 | `net use * /del /y` 断开现有连接后重试 |
| **1326** | 用户名或密码错误 | 核对凭证、域名拼写、账户是否锁定 |
