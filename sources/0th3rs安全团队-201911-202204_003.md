### 0x01 1linephp

#### 整体思路

来自2018年hitcon CTF的Orange出的题，加了.php的限制，题目很简单，还是一行PHP代码

```
<?php
($\_\=@$\_GET\['yxxx'\].'.php') && @substr(file($\_)\[0\],0,6) \=== '@<?php' ? include($\_) : highlight\_file(\_\_FILE\_\_) && include('phpinfo.html');
```

这里对比了phpinfo，和官方的php apache的docker中差别就在于多了zip，因此应该是zip读取的利用

通过zip://读上传的临时文件来包含其中的php后缀文件

  

#### 临时上传文件

临时上传的文件测试发现以php+6位\[0-9a-zA-Z\]构成，需要爆破。虽然能够通过zip://http://的形式使得临时文件存在60秒，但是爆破的空间仍然太大（并且10分钟重启），实测没有成功

/index.php?yxxx=compress.zlib://http://XXXX:7890/holdme%3f

  

#### 临时session文件

PHP的临时session中会有前缀导致zip解析失败，需要解决，这也是正解

```
upload\_progress\_XXXX
```

通过构造头偏移的zip来绕过

https://users.cs.jmu.edu/buchhofp/forensics/formats/pkzip.html
