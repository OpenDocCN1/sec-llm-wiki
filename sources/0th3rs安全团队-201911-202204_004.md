# 如何利用IDA Flair编译符号表

## 背景

*   Github上有几个sig的库
    

*   https://github.com/push0ebp/sig-database
    
*   https://github.com/Maktm/FLIRTDB
    

*   如果找不到，就可以根据lib库+Flair自行生成sig文件，用于恢复符号表
    

## 恢复符号表

*   首先下载Flair，一般都是需要正版授权的，但可以自行找一下相关下载文件（链接见参考）
    
*   下载后，可以在`Flair_Path/bin/`下找到需要的程序
    
*   以GLFW为例，可以在官网下载Release版文件
    

![](../Images/f62f27745c683f3e3fa01f6925bc01b3.png)

*   通过上面查看文件信息可以知道，exe是通过VC++2015编译的，所以可以在`GLFW_Path/lib-vc2015`下找到相应lib，即`glfw3_mt.lib`
    
*   接下来就是生成sig文件
    
    ```
     Flair\_Path/bin/mac/pcf GLFW\_Path/lib-vc2015/glfw3\_mt.lib GLFW\_Path/lib-vc2015/glfw3\_mt.pat
    Flair\_Path/bin/mac/sigmake GLFW\_Path/lib-vc2015/glfw3\_mt.pat GLFW\_Path/lib-vc2015/glfw3\_mt.sig
    ```
    
*   如果此时报错
    
    ```
     ./glfw/glfw3\_mt.sig: modules/leaves: 245/333, COLLISIONS: 4
    See the documentation to learn how to resolve collisions.
    ```
    

*   说明是出现了碰撞情况，打开.exc文件
    
*   打开文件，在想要应用的函数签名前面加个"+"，想要注释的加个"-"，然后删除前4行，保存
    

![](../Images/5a2f79f192116bf4e2abe6f73ddcb96c.png)

*   再次使用sigmake生成sig文件
    
*   将sig文件放到`IDA_Path/sig/pc`路径下
    
*   在IDA中，Shift+F5，调出导入库的界面，右键添加新的签名，导入我们新生成的sig文件
    

![](../Images/9e7d456a7dc731fb71f16f4a7bc6f0a3.png)

*   不知道为什么，在windows系统下，使用sigmake命令会提示找不到.err文件，最后在macOS上成功的

# Windows下IDA插件安装Findcrypt-Yara

## 背景

*   Findcrypt-Yara是一款IDA下寻找加密方式的插件
    

## 安装步骤

*   `pip2 install yara-python==3.11`，因为最新版的yara不支持python2了，而且需要找一个Windows版本的。
    

*   如果直接使用`pip install yara-python`安装，就会报错
    
*   ![](../Images/8da8dc080162a480cc0e2e3339ce11fe.png)
    

  

*   `git clone https://github.com/polymorf/findcrypt-yara.git`
    
*   将clone目录下的`findcrypt3.py`和`findcrypt3.rules`复制到`$IDA_PATH$\plugins`中
    
*   重启IDA后，可以在Edit->Plugins->Findcrypt下找到
    

![](../Images/6461009af79097d2ee2923f9d20942ba.png)

## 参考  

*   https://blog.csdn.net/fjh1997/article/details/107167704
    
*   https://github.com/polymorf/findcrypt-yara
    
*   https://www.cnblogs.com/zhaijiahui/p/7978897.html
    

# Windows下IDA插件安装Keypatch

## 安装步骤

*   安装keystone python模块
    

*   32位ida安装：https://github.com/keystone-engine/keystone/releases/download/0.9.1/keystone-0.9.1-python-win32.msi
    
*   64位ida安装：https://github.com/keystone-engine/keystone/releases/download/0.9.1/keystone-0.9.1-python-win64.msi
    

*   `pip install six`安装six模块，**我之前没有安装过six模块，导致前后所有步骤都进行了，但还是无法识别（启动）KeyPatch**
    
*   `git clone https://github.com/keystone-engine/keypatch.git` 
    
*   将clone目录下的`keypatch.py`复制到`$IDA_PATH$\plugins`中
    
*   重启IDA后，可以在Edit->Keypatch下找到
    

![](../Images/8c9448ffac295fec574d4369cda4c424.png)

*   快捷键呼出：Ctrl+Alt+K
    

![](../Images/3af306df00e0e98b7773643215d61e5d.png)

# 如何在IDA Pro中启用第三方Python库

## 背景

*   对于IDA Pro来说，如果需要使用第三方库是很不方便的，比如pefile，直接在命令行中导入，就会报错
    

## 设置

*   需要将pip的site-package目录添加到python环境变量中
    
*   如何查看该目录所在路径？在命令行中输入如下命令
    
    ```
     python -m site
    ```
    

![](../Images/537d329c222f8d582beccd244cadd5da.png)

*   其中，`C:\\Users\\xxx\\AppData\\Roaming\\Python\\Python27\\site-packages`就是我们要找的
    

*   然后将该目录路径添加到sys.path中
    
    ```
    import sys
    print sys.path.append("\`C:\\\\Users\\\\xxx\\\\AppData\\\\Roaming\\\\Python\\\\Python27\\\\site-packages\`")
    ```
    
*   最后在IDA中导入我们需要的python包，比如pefile就可以了
