## 我们能为你提供什么？

### 起步

*    入门培训

*    Reverse  
    编译是将人类阅读的源代码编译为机器阅读的机器码的过程，逆向工程指的是通过人工辅助运用某些手段对编译过程进行逆转。逆向需要非常多的计算机底层知识，如汇编语言，操作系统，编译原理等等，如果逆向者不熟悉 C++内存对象模型，他可能会在围绕着虚函数表与虚基类表的各种间接跳转中不知所措，如果不熟悉操作系统与编译原理，他可能会陷入编译优化产生的 memcpy，malloc 之类的函数无从下手。学习逆向，有助于从底层开始建构计算机知识体系，以后无论钻研什么方向，计算机底层的知识都是大有裨益的
*    PWN  
    冯诺伊曼计算机体系存在固有缺陷：数据与代码之间没有绝对的间隔，这导致黑客可以通过输入劫持程序控制流，进而产生一系列恶意行为，如数据泄露、恶意代码执行。PWN 研究的就是如何构造出这些输入以达到恶意目的。PWN 的发展与对抗过程其实很大程度上反映了软件工程的进步，比如学术界软工与安全领域最近比较热的 Rust 语言，它创造性地引入了 Borrowing 与 Ownership，以试图解决 UAF（Use-After-Free，指解引用释放过的指针）类型漏洞
*    Web  
    与 PWN 类似，Web 安全的本质其实仍然是软件质量的问题。运行在服务器上提供 HTTP 服务的程序如 Nginx, Apache2 等也可能存在漏洞，黑客利用网站操作系统的漏洞和 WEB 服务程序的漏洞得到 WEB 服务器的控制权限，轻则篡改网页内容，重则窃取重要内部数据，更为严重的则是在网页中植入恶意代码，使得网站访问者受到侵害

### 进阶

*    安全研究

*    产业界  
    社团成员多次在国内网安产业界具有较高影响力的会议上做报告，比如 2021 年的看雪安全开发者峰会，2022 年的KCon 黑客大会  
    社团成员已经探索过的研究方向有代码混淆、代码相似度检测、恶意软件分类、模糊测试，在这些方向已经有非常深的积累
*    学术界  
    社团与网络安全学院联系密切，合适的社团成员可推荐至课题组参与学术科研

*    企业实习

*    校企合作  
    社团与乙方安全大厂有较多联系，社团成员可以进入安全实验室学习最前沿的攻防实战技术技术
