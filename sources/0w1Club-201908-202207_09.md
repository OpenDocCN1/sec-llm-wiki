## 1\. 简介  

burpsuite 是一个针对网站安全测试的强大工具，一个集成化渗透测试工具，简单高效，日站必备。尤其在对 HTTP 数据包进行修改的时候非常好用，同时也支持简单的密码爆破，而高级版有一个好用的功能叫做主(yi)动(jian)扫(ri)描(zhan)，直接扫除常见高危漏洞：

## 3\. 代理设置

burpsuite 主要工作是截取、修改自己电脑的 HTTP 流量，那么这就相当于一个代理的工作（burp 代理浏览器发送流量），这就需要配置一下 burpsuite 的代理功能，由于网上教程比较多，不同电脑配置代理出现的问题又不太一样，所以就先放几个教程链接出来供参考，不在公众号里细说了：

*   安全客：https://www.anquanke.com/post/id/85925 
    
*   腾讯云：https://cloud.tencent.com/developer/news/288748 
    
*   简书：https://www.jianshu.com/p/9a0f964ce4f8 
    

代理一定要配好，不然抓不上包

  

## 4\. 功能简介

先观察一下咱们大 burp 的主界面

![](../Images/4213e8f25a9f6ca3827de884bc78392b.png)

放大点  

![](../Images/a47f21a26f044249dedbbc14e0f6485c.png)

第一行从 Target 到 Alerts 就是 burp 的主要功能模块，下面简单介绍一下几个比较常用的功能模组：  

### i. Proxy 抓包开关

这个部分是手动安全测试的灵魂，因为有关代理的设置、HTTP 包的抓获都是从这里操作的，首先打开抓包按钮：

![](../Images/03cb43e2c625988df5de88ab5cb4125e.png)

同时打开之前设置过代理的浏览器，输入 www.baidu.com 抓一个浏览器申请百度的页面：  

![](../Images/13fdd2fc00f6161ee873abdd56dbb9a2.png)

此时是加载不出来的，因为电脑向百度服务器发送的数据包被 burp 拦截下来的，现在去 burp 看看我们的电脑准备发送的 HTTP 数据长什么样子：  

![](../Images/2fcf806b5cb6877fea36904f25940c57.png)

可以清楚地看见整个 HTTP 包的内容~  

看到这里你可能有疑问了：自己拦截自己是在干啥？我干我自己？不不不，这个包是可以改的，比如可以手动改一下 cookie 等参数，然后点击一下 Forward，就将修改过的包发出去了。自己浏览器发出的数据包一定是一个合法的数据包，我们可以通过 burp 进行篡改，定制出一些 “非法” 数据包，从而对目标服务器进行试探、攻击，从而发现可能存在的安全隐患。

### ii. Repeater HTTP 包微调

Proxy 中对一个包只能改一次，Forward 就没了，如果要对同一个页面频繁发送篡改数据包，就要用到 Repeater 这个包，首先还是回到之前的 Proxy 模块，右键选择 Send to Repeater：

![](../Images/4f889107c3924cc375c0ccbcdd4a9fea.png)

然后进入 Repeater 模块：  

![](../Images/36a5005425c6fb6af223e11626184181.png)

修改完包后直接点 Go，可多次修改，多次发包。  

### iii. Scanner 一键扫描

这是非常方便的一个功能了，传说中的一键日站，如果嫌慢慢手动改包发包测漏洞太慢，可以进行自动扫描，弊端是只能扫到常见漏洞，比较刁钻的就 emmmm。

首先，咱们先去教务处的网站，在 Proxy 中 抓个包：

![](../Images/8328aa0a687546f924c3408e535ccd2f.png)

![](../Images/cd18f490140834835879227a58f645fd.png)

然后右键点击 Do an active scan：  

![](../Images/f2e60b2a6a98f11ac70d1eae7e7af1fe.png)

进入Scanner -> Scan queue 可以看到已经开始扫描了：  

![](../Images/c3f821b28858fdef070a06c71fa89c2b.png)

然后可以在 Results 模块下看到扫描结果（下面是没扫完，如果扫完可以惊喜的发现高危的说。。。所以咱们的学校的网络服务器啊 emmm）：

![](../Images/127b5e9d375fa013a96a66b0b96d2c02.png)

全部扫描完后还可以自动生成渗透测试报告，对应漏洞有对应的修复建议，可以说是非常好用的摸鱼功能。

### iv. Intruder 密码爆破

最后一个着重讲解的模块就是 Intruder，用来爆破密码的，常用于登录框，比如这个：

![](../Images/a9dc796a27b7016167fdc55c6cd39060.png)

老规矩，对登录框、密码框随便输入，然后点登陆，抓住这个包，右键送入 Intruder：在抓的包里已经可以看到我登陆框里输的是什么了：用户名 cxk，密码加密过看不出来，我们进入 Intruder:

![](../Images/c03e84b1d291a724c064eb064fd39946.png)

在 position 项中修改需要爆破的表象，比如要爆破密码就只对 pwd= 后的值加那个奇怪符号的标记，然后进入 Payload 添加密码表进行强行爆破，爆破就是指强行遍历密码表找到对应密码，这个里面虽然骚操作挺多，但是现在好多网站都有密码错误多少次后禁 IP 的操作，不太好用了，不过在一些不太安全的网站还是可以日一日的。
