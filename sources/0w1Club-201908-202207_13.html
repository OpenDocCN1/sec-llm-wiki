一、灵魂 apache + mysql

web 服务器：apache

这里的 web 服务器指的是提供 web 服务的一段程序，运行在服务器上，它通过 PHP 语言行一切后端看不见的响应操作，相当于一个网站的脑子。

很多公司都在做 web 服务器，现在市场份额最大的要数 apache 啦，下面我们给自己的机子上面也整一个 apache：

sudo apt-get install apache2 # 安装服务器
sudo apt-get install php # 安装 php

apache2 -v # 出现版本号，证明已经安装
php -v # 出现版本号，证明已安装
cd /etc/init.d/
sudo ./apache2 start # 开启 apache 服务器

安装好之后，我们可以用 ubuntu 虚拟机上的浏览器访问 http://127.0.0.1，可以看到 apache 的声明:

此时，在机器上 /var/ 目录下可以发现新增了一个 www 目录，其实，/var/www/html 就是 apache 的根目录，网站所有内容都要放在这个目录下：

数据库：mysql

所谓数据库，就是当数据量非常大之后，一般的数据结构无法满足快速查找、搜索等操作，一群大佬就暗搓搓搞出来这么一个东西，常见数据库中集成了非常多的优秀数据结构与算法，满足用户在使用大量数据时的操作，这样，用户在编程的时候只用专注于程序功能，而不用头疼数据存储查找了。

对于一个网站来说，非常多的信息需要存储：文件路径啦、用户信息啦、安全信息啦等等，所以需要这么一个数据库存储自己的数据，和 apache 类似，mysql 是数据库的一种，非常普遍，我们给我们的机子上也整一个：

sudo apt-get install mysql-server
sudo apt-get install php-mysql # 这个步骤使 php 能够对 mysql 操作
sudo service mysql start # 开启 mysql 服务

然后需要手动为网站创建一个新的数据库存放网站数据

mysql -u root # 先进入 mysql 交互界面

在交互界面，输入以下指令：

--创建一个名为 wordpress 的用户，用户密码 qwe123
CREATE USER 'wordpress'@'localhost' IDENTIFIED BY 'qwe123';

--创建一个名为 wordpress 的数据库
CREATE DATABASE wordpress;

--为 wordpress 用户赋予 wordpress 数据库权限
GRANT ALL ON wordpress.* TO 'wordpress'@'localhost';


二、皮囊 CMS：wordpress

其实通过上面的操作，一个网站的后端的雏形已经出来了，放入自己写的 HTML、CSS、JavaScript、PHP 文件就已经可以实现简单的网页了，不过，如果想要制作出合格的网站，emmm，工作量过大，自己设计 HTML、CSS 还有内在逻辑是在是一件要命的事（这也是为啥 2000 年左右的网页现在看起来超级有年代感的原因）

所以一群人都希望有一个好用框架帮他们免去自己写 HTML、自己写 UI、逻辑的琐事（比如一个作家显然不想学写这个），在这种需求的推动下，web 的 CMS 出现了，它们帮人省去了那些细节，使用者只用专注于创作就好。

今天的内容是搭建一个个人博客，wordpress 就是 CMS 中一个非常好的选择：

话不多说，给机子整上：

cd /var/www/html # 进入 apache 的默认根目录
wget https://cn.wordpress.org/latest-zh_CN.tar.gz # 下载 wordpress
tar -xzf latest-zh_CN.tar.gz # 解压缩
rm latest-zh_CN.tar.gz # 删除压缩包
