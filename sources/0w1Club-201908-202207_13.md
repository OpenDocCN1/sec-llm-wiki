## 一、灵魂 apache + mysql  

### web 服务器：apache

![](../Images/bcad623d047b150502cdcfb635a1cdf7.png)

这里的 web 服务器指的是提供 web 服务的一段程序，运行在服务器上，它**通过 PHP 语言行一切后端看不见的响应操作**，相当于一个网站的**脑子**。  

很多公司都在做 web 服务器，现在市场份额最大的要数 apache 啦，下面我们给自己的机子上面也整一个 apache：

```
sudo apt-get install apache2 \# 安装服务器
sudo apt-get install php \# 安装 php
```

![](../Images/a2d99a5b616953d9d95ad80272a5830c.png)

```
apache2 -v # 出现版本号，证明已经安装
php -v # 出现版本号，证明已安装
cd /etc/init.d/
sudo ./apache2 start # 开启 apache 服务器

```

安装好之后，我们可以用 ubuntu 虚拟机上的浏览器访问 http://127.0.0.1，可以看到 apache 的声明:

![](../Images/4f655bcd56e62aabda57d48f12854d49.png)

此时，在机器上 `/var/` 目录下可以发现新增了一个 `www` 目录，其实，`/var/www/html` 就是 apache 的根目录，网站所有内容都要放在这个目录下：  

![](../Images/93e4e1118fb512242eea906734053431.png)

* * *

### 数据库：mysql

![](../Images/a27b177776006bfa34708d180b1cd43a.png)

所谓数据库，就是当数据量非常大之后，一般的数据结构无法满足快速查找、搜索等操作，一群大佬就暗搓搓搞出来这么一个东西，常见数据库中集成了非常多的优秀数据结构与算法，满足用户在使用大量数据时的操作，这样，用户在编程的时候只用专注于程序功能，而不用头疼数据存储查找了。  

对于一个网站来说，非常多的信息需要存储：文件路径啦、用户信息啦、安全信息啦等等，所以需要这么一个数据库存储自己的数据，和 apache 类似，mysql 是数据库的一种，非常普遍，我们给我们的机子上也整一个：

```
sudo apt-get install mysql-server
sudo apt-get install php-mysql \# 这个步骤使 php 能够对 mysql 操作
sudo service mysql start \# 开启 mysql 服务
```

然后需要手动为网站创建一个新的数据库存放网站数据

```
mysql \-u root \# 先进入 mysql 交互界面
```

在交互界面，输入以下指令：

```
\--创建一个名为 wordpress 的用户，用户密码 qwe123
CREATE USER 'wordpress'@'localhost' IDENTIFIED BY 'qwe123';

\--创建一个名为 wordpress 的数据库
CREATE DATABASE wordpress;

\--为 wordpress 用户赋予 wordpress 数据库权限
GRANT ALL ON wordpress.\* TO 'wordpress'@'localhost';
```

  

## 二、皮囊 CMS：wordpress

其实通过上面的操作，一个网站的后端的雏形已经出来了，放入自己写的 HTML、CSS、JavaScript、PHP 文件就已经可以实现简单的网页了，不过，如果想要制作出合格的网站，emmm，工作量过大，自己设计 HTML、CSS 还有内在逻辑是在是一件要命的事（这也是为啥 2000 年左右的网页现在看起来超级有年代感的原因）

所以一群人都希望有一个好用框架帮他们免去自己写 HTML、自己写 UI、逻辑的琐事（比如一个作家显然不想学写这个），在这种需求的推动下，web 的 CMS 出现了，它们帮人省去了那些细节，使用者只用专注于创作就好。

今天的内容是搭建一个个人博客，wordpress 就是 CMS 中一个非常好的选择：

![](../Images/6487f94a2b336bfb8d9fadecfe858da8.png)

话不多说，给机子整上：  

```
cd /var/www/html \# 进入 apache 的默认根目录
wget https://cn.wordpress.org/latest-zh\_CN.tar.gz \# 下载 wordpress
tar \-xzf latest-zh\_CN.tar.gz \# 解压缩
rm latest-zh\_CN.tar.gz \# 删除压缩包
```

![](../Images/da14473c1c48c73b2b8be62e3bcac9c5.png)

这个时候会发现 `/var/www/html/` 目录下多出来的 `wordpress` 目录，这个就是我们 CMS 的根目录啦，由于之前已经配置好了服务器后端，直接进入浏览器输入`http://127.0.0.1/wordpress` 就能够看到我们 wordpress 的安装界面啦：  

![](../Images/137a1be26432ebe99936784b03f1a087.png)

根据之前创建数据库中的信息填注册表：  

![](../Images/cf92a9dcb62fcb93113b0131a0a9336d.png)

出现这个界面：  

![](../Images/ee5c85796d71b274c696143f43d0a9d4.png)

注意这个不是报错，而是接下来的提示，提示说要手动配置 `wp-config.php` 文件，那么我们进根目录手撸一份：  

```
cd /var/www/html/wordpress \# 进目录
nano wp-config.php \# 创建文件，把上图的文件内容粘贴进去
\# 文件编辑好后保存退出编辑界面
```

点击现在安装，得到以下界面：

![](../Images/ccb8d81f7d09a093d020d2061569f2ad.png)

这个就随缘了，自己填，就和注册个 QQ 号那么简单：  

![](../Images/220388885e70249701e0fcf5dcb1e026.png)

登陆进后是后台面板，这里可以修改自己的网站，可自己研究，可以先换个主题试试  

![](../Images/493116e72df8ad406f63e046fe974abb.png)

OK，简易网站建立完成：  

![](../Images/2bcb22f5706d6ac5b24ff8cb72fe791c.png)
