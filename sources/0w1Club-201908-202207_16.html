2. 破解 M ⊕ K = C

  • 大体思路：由于密钥K与明文M的长度不一致，通常使用异或加密时是利用迭代循环K的方式获得与明文相同长度的exp-K。这种方式往往存在二次加密攻击（two-time-pad attack)，通过对K中每个字符进行爆破分析可以得到可能取值集合，最后根据词频分析可以猜出密钥K。

以de1ctf 2019的xor题目为例：

from itertools import *
from data import flag,plain

key=flag.strip("de1ctf{").strip("}")
assert(len(key<38))
salt="WeAreDe1taTeam"
ki=cycle(key)
si=cycle(salt)
cipher = ''.join([hex(ord(p) ^ ord(next(ki)) ^ ord(next(si)))[2:]
    .zfill(2) for p in plain])
print cipher

3. 流密码(Stream Cipher)

  • OTP(one time pad)，是一种具有绝对安全性的加密方式（密钥），但是由于在实际应用上成本高昂且无意义（密钥长度和明文长度一样长），衍生出利用短密钥生成伪随机数以提升加密安全性的方法，这种伪随机数也叫做流密码。

  • 基于流密码，有各种加密算法，比如RC4、WPA-PSK等。
