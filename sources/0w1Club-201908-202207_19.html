自动化制作需要工具social-engineer-toolkit。安装方法。

直接cd进去，执行 ./setoolkit

然后输入自己的host

之后打开浏览器访问127.0.0.1即可，这里是云服务器，只能curl演示

三、实际操作

首先安装docker

sudo apt-get install docker.io

然后安装docker-compose 自动化部署docker的工具，(可以批量部署多个docker，但这几次用不到，想要学习的可以自行学习)

sudo apt-get install docker-compose

如果出现错误，可以自行百度安装docker 和docker-compose，尽量不要用wget下载压缩包然后解压那种方法，容易出错，尽量使用apt-get或者snap或者pip yum等自动化安装管理的工具。

之后下载项目代码

git clone https://github.com/gwyxjtu/fish-docker.git

下载好之后cd进去，执行

docker-compose up

然后访问本地127.0.0.1:8090即可。

特别重要：记得养成好习惯，每次关机前清理一下docker，就在当前目录下执行

docker-compose down即可
