好好学习天天向上

（采纳自：袁靖松）


题目描述：b0f7b1e3f4e6fbc7b0b0e4dfe7b0efe4dfd3f4f5e4f9fd

参考今年DDCTF杂项掀桌题。

将这串字符串两两分组，进行16进制到ASCII码转换，按凯撒密码解密方式进行位移暴力求解：


python
str = "b0f7b1e3f4e6fbc7b0b0e4dfe7b0efe4dfd3f4f5e4f9fd"
flag = ""
for i in range(len(str)/2):
    tmp = int(str[2*i :2*i+2], 16)
    tmp = tmp & 0b01111111
    flag += chr(tmp)
print flag


得到flag：0w1ctf{G00d_g0od_Study}
