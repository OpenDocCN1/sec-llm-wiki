**04**

  

好好学习天天向上

（采纳自：袁靖松）

  

题目描述：b0f7b1e3f4e6fbc7b0b0e4dfe7b0efe4dfd3f4f5e4f9fd  
  
参考今年DDCTF杂项掀桌题。  
  
将这串字符串两两分组，进行16进制到ASCII码转换，按凯撒密码解密方式进行位移暴力求解：

  

python  
str = "b0f7b1e3f4e6fbc7b0b0e4dfe7b0efe4dfd3f4f5e4f9fd"  
flag = ""  
for i in range(len(str)/2):  
    tmp = int(str\[2\*i :2\*i+2\], 16)  
    tmp = tmp & 0b01111111  
    flag += chr(tmp)  
print flag  

  

得到flag：0w1ctf{G00d\_g0od\_Study}

  

  

**05**

  

看不见的鬼

（采纳自：张恒煜）

  

题目描述：这个文件有鬼啊！！！  
  
附件是一个txt文件，用浏览器打开文件：

![](../Images/55416555e4e24eb97fab215eee2ff3d6.png)

 观察到a之间有许多&#8203Unicode编码，这些是零宽字符。统计&#8203个数，得每一段连续个数分别为：  
  
15，23，12，3，12，21，2，6，21，2  
  
观察数学均在26以内，故考虑用数字对于字母表中字母得到：owlclubfub  
  
故flag：flag{owlclubfub}

  

  

**06**

  

逢雪宿芙蓉山

  

题目描述：同志，天冷了，进来坐坐，顺便帮我修一修路由器  
  
附件是一个压缩文件，解压得流量包和一个加密得压缩文件。

![](../Images/808722c83a787e47714a267d03e02992.png)

Wireshark打开柴门闻犬吠，可以发现这是一段PPPoE认证过程，利用PAP协议漏洞获取PPPoE认证密码：

![](../Images/0544476ba4a6e07d0bd9b25ee4f973fa.png)

密码为：/=3ngxu3y36uir3n，是"fengxueyeguiren"得leet文。推测是解压密码，用其解压压缩包得到一堆文件：

![](../Images/de8884680abe26b29f39b8284a80be4c.png)

在挨个看完，学习完该诗的赏析和刘长卿的生平后，发现“touche me.zip”应该才是和解题有关的。试图解压缩发现压缩文件损坏。用winhex查看该压缩文件：

![](../Images/9993d19c7c1edd33b4292eacd9b846a9.png)

 由于压缩文件仅为txt纯文本，可容易直接得到flag：ekhhMHlpbmcxQWlzSGkxdQ==。  
  
Base64解码得flag：flag{zHa0ying1AisHi1u}。  
  
另一种做法：修复zip文件。zip格式文件头结构如下：

![](../Images/fea16f7aee743b9ad0e8eca15c9868a1.png)

可以发现该压缩包文件头标记被篡改，修改为04034b50即可正常解压得到flag。
