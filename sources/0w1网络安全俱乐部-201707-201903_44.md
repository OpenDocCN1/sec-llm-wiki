base-75（作者：尹赫泽）

  

考虑3种可能性：zip加密，zip伪加密，zip明文攻击  
对于外层zip首先考虑爆破，使用Ziperello设置可输出字符破解，得到密码9527，解压得到res.zip  
对于内层zip首先考虑爆破，使用Ziperello无法破解，接下来考虑消除未加密，根据zip格式伪加密的套路，将加密标志位修改为未加密，解压得到res.txt，其内容为：  
flag{a98hd908h129ejhdi9anduba9a9scjkop09080jh912e4ausdcvbjni0dh}  
即为答案

  

reverseMe-200（作者：尹赫泽）

  

编写程序反转文件  
c++  
#include <iostream>  
#include <stack>  
#include <fstream>  
using namespace std;  
int main() {  
    ifstream fin("reverseMe", ios::binary);  
    ofstream fout("a.jpg", ios::binary);  
    stack<char> s;  
    char c;  
    while (fin >> noskipws >> c) {  
        s.push(c);  
    }  
    while (!s.empty()) {  
        fout << s.top();  
        s.pop();  
    }  
    fin.close();  
    fout.close();  
    return 0;  
}  
十六进制查看，根据文件首尾的FFD8和FFD9可知该文件为jpg图片  
以jpg图片方式打开，看到翻转过的flag  
翻转后得到正的flag，为：flag{4f7548f93c7bef1dc6a0542cf04e796e}

管理员的密码-200（作者：培训理事Wind-Wing）  

  

这是一道SQL注入的题目，你们没有猜错。不过看着这200分的分值你们也应该知道不好拿吧。。。这道题目考察你到底懂不懂SQLmap的原理。SQL注入分为4种，这里用的是UNION注入，利用sql支持的一次可以执行两条查询语句的union关键词来借助程序员留给用户进行合法查询的接口查询不合法的内容。

题目中的url是ctf.0w1.club:10247/task4?id=c4ca1

访问后发现出现了如下的页面：

![](../Images/275e93333affa610a4c0b7602b6d8b73.png)

注意到用户的ID也是1，联想参数id=c4ca1，可以猜到前面4位是验证位，1才是参数。

将1用32位md5码加密后可以发现前四位就是c4ca。由于有4位的验证位，纯SQLmap就被防御住了，所有就算是risk/level 3 也是没有用的。如果你自己可以写一个SQLmap就可以注入了，或者可以选择手动注入。

再试一下id=c81e2，可以合法查询。

![](../Images/fce56a62664190b33b67db8d8e482b69.png)

接下来进行手动注入。所有Mysql数据库中都有一个叫做information\_schema的数据库，里面有数据库所有的结构信息。用注入语句查询后可以知道这是一个wordpress的网页，再进一步注入查询后可以知道wordpress的版本为4.4.1（具体查询语句不进行赘述，参考下面的注入语句）。由于所有的同一版本的wordpress的数据库结构相似，可以通过google得到详细的wordpress数据库结构。然后用下面的语句进行联合注入。

构造以下语句对于目标内容进行查询。

id=1' union selectuser\_login,user\_pass,user\_pass,user\_pass from wordpress.wp\_users;#

1后面的单引号用于闭合1前面在php程序内的单引号

结尾的#用于注释掉php程序中的原本接在1之后的内容

用from选定目标数据库wordpress中的表wp\_users

中间将user\_pass重复三次是因为union有一个毛病，必须前后两天语句的查询字段数一致。通过之前网页返回的信息可以知道前面查询语句有4个字段（id，name，age，sex）

因此重复3遍来满足这个条件。

特别注意一点，在注入之前将语句转化为url编码才可以完整得传输到后台。此处将空格用%20代替，#用%23代替。

id=1’%20union%20select%20user\_login,user\_pass,user\_pass,user\_pass%20from%20wordpress.wp\_users;%23

接下来准备校验位，特别注意一点的是校验是在后台执行的，这时候所有的url编码就解码了。因此计算md5码时应当用未编码之前的参数，结果如下图：

![](../Images/a55f11ac7ff58590a3480a1cff186e7c.png)

最后用以下的完整语句进行SQL注入就可以得到答案。

id=94e51’%20union%20select%20user\_login,user\_pass,user\_pass,user\_pass%20from%20wordpress.wp\_users;%23

![](../Images/95d63093c331cef35a4b4b2e0680dc5c.png)
