#### 简介

    一句话木马，简单的理解就是，几个代码组成的一段简单的代码，然而这段简单的的代码，就可以连接到别人后台的功能。一句话木马原理简单，构造也简单，防御起来也容易，从而会容易检测出来，我们需要通过变形才能完美绕过。

#### 解析

你要理解这句木马，首先要知道PHP代码和eval函数

##### eval() 函数

*   eval() 函数把字符串按照 PHP 代码来计算。
*   该字符串必须是合法的 PHP 代码，且必须以分号结尾。
*   如果没有在代码字符串中调用 return 语句，则返回 NULL。如果代码中存在解析错误，则 eval() 函数返回 false。

post 是表单提交的数据，传入的参数必须为PHP代码，既需要以分号结尾。命令执cmd=system(whoami); 蚁剑连接密码：cmd；

将 写入webshell.php文件中，然后上传至网站目录下，以POST方式连接

eval会把name=c的输入框里的value字符串当作php代码执行，提交文件时就会运行phpinfo()，就是网页向php文件发送请求，php读取请求里的phpinfo并用eval执行

#### 示例

    有些系统只是在客户端使用js对上传文件的后缀进行检查，服务端没有进行检查。由于客户端的js用户可以禁用，修改等等，导致可以绕过客户端的检测，上传不合法文件。

上传webshell ，使用burp，将content-type改为image/jpeg即可绕过。

#### 如何预防

    对用户上传的文件做二次判断一次在前端，一次在后端，且限制用户上传文件类型，目的是禁止用户上传危险的文件
