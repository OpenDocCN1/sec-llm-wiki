## ARP欺骗

ARP欺骗（ARP spoofing），又称ARP毒化（ARP poisoning）、ARP病毒、中间人攻击

ARP欺骗可以造成的效果：

```


可让攻击者获取局域网上的数据包甚至可篡改数据包可让网络上特定电脑之间无法正常通信
```

#### 步骤

```


假设主机C是攻击者，主机A、B是被攻击者 C只要收到过A、B发送的ARP请求，就会拥有A、B的IP、MAC地址，就可以进行欺骗活动
```

### 根本原理

```

ARP欺骗攻击的根源在于ARP协议在设计时认为局域网内部的所有用户都是可信的，当攻击者渗透进入内网后，通过向局域网内节点缓存中注入伪造的IP/MAC映射关系，从而进行欺骗，成为局域网内的中间人节点，即可以监听并进一步篡改数据包。
```

现在流程应该变成了：

1）140向250发起请求  【源IP：140 目IP：250 源MAC：140的MAC 目标MAC：**129的MAC**】

2）由于mac是129的 250即使收到该包也会**丢弃** 请求包来到129处

3）129进行转发 【源IP：140 目IP：250 源MAC：**129的MAC** 目标MAC：250的MAC】

4）250收到请求 且MAC是自己的 会接收该请求包并返回响应包 【源IP：250 目IP：140 源MAC：250的MAC 目标MAC：**129的MAC**】

5）129收到响应包 转给140 【源IP：250 目IP：140 源MAC：250的MAC 目MAC：129的MAC】

双方均无感 而129攻击机已经在途中做了 **中间人** 截获了两者的往来包
