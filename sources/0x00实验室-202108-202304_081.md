## robots  

![](../Images/7af3c22f317f8bf88b67d907c44bd16e.png)

我们先来了解下什么是robots,百度百科解释如下：  

```
robots是网站跟爬虫间的协议，用简单直接的txt格式文本方式告诉对应的爬虫被允许的权限，也就是说robots.txt是搜索引擎中访问网站的时候要查看的第一个文件。当一个搜索蜘蛛访问一个站点时，它会首先检查该站点根目录下是否存在robots.txt，如果存在，搜索机器人就会按照该文件中的内容来确定访问的范围；
如果该文件不存在，所有的搜索蜘蛛将能够访问网站上所有没有被口令保护的页面。
```

总的来说就是一个说明文件，会告诉搜索引擎一些信息，不过有时候会暴露一些信息。

下面开始爆破操作，需要**把流量打到Burp Suite上**，**需要准备个密码字典**,将抓到的包发到Intruder上，

![](../Images/9758c4258e5c3a8be315cc1f7465af17.png)

转到后有四个选项，Target，Positions，Payloads，Options，第一个Target是要爆破的ip+端口，第二个Positions要说一下，它有四种模式如下图：  

*   Sniper ：一个一个爆破，如果payload有50个，一个参数就需要50次，如有第二个参数同样爆破50次，此时其他参数不受影响，两个参数就是100次
*   Batteringram：一个参数的话和Sniper一样，如果是多个参数，可以同时爆破（爆破值一样），如果payload有50个，只需要爆破50次
*   Pitchfork：可以多个参数分别采用不同的payload，一个参数对应一个字典，假如有两个参数，

*   字典一：1，2，3，4
*   字典二：5，6，7，8
*   爆破参数为：（1，5），（2，6），（3，7），（4，8）
*   **如果字典数目不同，采用最小字典个数进行爆破**

*   Cluster bomb：每个参数的字典都交叉取值爆破，假设两个参数

*   字典一：1，2，3，4
*   字典二：5，6，7，8
*   爆破参数为：（1，5），（1，6），（1，7），（1，8），（2，5），（2，6）......

我们就一个参数，选第一个模式就好，然后点击右上角Start attack开始爆破，发现`123456`的返回数据包大小和其他不一样，查看返回包看到flag

## xff\_referer

![](../Images/986ec310b963679892e5f3f77e8a2e90.png)

**X-Forwarded-For**（**XFF**）是用来识别通过HTTP代理或负载均衡方式连接到Web服务器的客户端最原始的IP地址的HTTP请求头字段。Squid 缓存代理服务器的开发人员最早引入了这一HTTP头字段，并由IETF在HTTP头字段标准化草案中正式提出。  

HTTP Referer是header的一部分，当浏览器向web服务器发送请求的时候，一般会带上Referer，告诉服务器该网页是从哪个页面链接过来的，服务器因此可以获得一些信息用于处理。

![](../Images/464b710e542c251c4429f5abe6d2d9ba.png)

*   抓包修改来源ip,添加`X-Forwarded-For: 123.123.123.123`
*   后看回显发现还要限制来源，添加来源`referer: https://www.google.com`
*   看到flag，`cyberpeace{04fb2d1752c3a42b36bfc04b465e0b7c}`
