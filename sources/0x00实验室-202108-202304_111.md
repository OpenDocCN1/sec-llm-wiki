# 0x00.关于IP定位  
  

## 

IDC的 IP、CDN的IP、运营商IP

IP定位：

```


https://www.opengps.cn/Data/IP/IPSearch.aspx#IP信息查询


```

然后通过上述的查询结果，进一步分析：

还可以通过IP反查域名：

```


http://whois.chinaz.com/#国外查询

```

注意：如果查到的域名过多，考虑可能是CDN ，视具体场景进行处理。

## 0x01.钓鱼邮件反查

1.通过威胁情报碰撞邮件附件MD5信息和恶意URL程序，并对邮件中的附件上传到沙箱进行处理。

2.反查邮件，看看能不能溯源到发件人的信息。

## 0x02.VPS渗透

1.如果通过web应用界面的信息收集：是否是攻击者的个人博客、论坛等。

2.对web站点应用进行漏洞挖掘，收集有用的信息，从而获取VPS权限

注：小心web站点是蜜网。

## 0x03.ID追踪

常见的ID类型：手机号、邮箱、微博ID、论坛昵称、"娱乐圈代号"

支付宝账户获取真实姓名等

1.收集攻击者的ID

通过蜜罐、防火墙等安全设备获取到的攻击者的指纹信息，

在上一步中IP反查到的攻击者的ID信息

业务功能日志中抓取到的攻击者的ID

2.溯源手段

社工库匹配、威胁情报库、不同的平台根据指纹进行搜索。
