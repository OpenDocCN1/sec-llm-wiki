## 0\. 前言

公众号的第一篇文章（也就是上一篇）中的样式是使用@lyricat的wechat-format^(\[1\])生成的，它的样式是我喜欢的极简主义，字体、title居中、分段都很优雅，而且可以自动解析链接生成文末引用。

但它的代码高亮不太行，它使用了微信公众号编辑器原生组件的代码高亮，支持的语言太少，比如下面针对Rust的两者对比，原生的明显无法识别特定语法元素

```
use std::io;

```

```
use std::io;
fn main() {    #[cfg(target_arch = "x86")]    let a = "AAA";    for _ in 0..10 {        println!(a);    }}
```

所以上一篇文章中的代码段我使用了@颜家大少的Md2All^(\[2\])，它支持几十种代码高亮主题，但文章的样式却花里胡哨的辣眼睛。

所以我就取两者所长：代码段都用后者生成，而文章样式用前者。

但这样导致了两种样式的重叠和变形，由于微信编辑器会隐式插入剪贴板的HTML标签，在编辑器里无法修改隐式插入的标签，所以很难补救。

故有了此文，扯一些相关技术问题，并且对wechat-format的语法高亮进行魔改，改良写作体验

## 1\. 操作系统剪贴板的数据格式

一般来说，操作系统的剪贴板都不仅仅可以存储纯文本。以Windows系统举例，剪贴板可以复制文件、文件夹、图片等二进制。Windows的剪贴板可以降级转换不同的数据格式，比如Unicode -> ANSI，RTF (Rich Text Format) -> Text等等。Windows剪贴板除了标准格式^(\[3\])，还允许应用自定义格式^(\[4\])。

回到公众号编辑器，它监听onpaste事件，获取剪贴板里的HTML数据，然后插入。如果剪贴板里没有HTML数据，则降级获取text数据，这也就是为什么某些工具复制过来的文本有格式信息，而直接Ctrl + C过来的HTML却被当做纯文本插入。  

上述功能的demo：

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
document.addEventListener('paste', (e) => {    let data = e.clipboardData;    for (let i = 0; i < data.items.length; i++) {        let item = data.items[i];        console.log(item);        if (item.kind == 'string') {            item.getAsString((s) => console.log(s))        }    }})
```

现代浏览器不允许直接访问剪贴板，只能通过事件回调。可以看到由wechar-format拷贝的数据有`text/plain`和`text/html`

## 2\. 编辑器中引入highlight.js

前端编辑器中引入代码高亮功能，highlight.js是个好选择。它的原理是解析语法，并插入相应的标签（例如built-in、keyword等），最后由全局的highlight.css引入不同标签的样式。

*   
*   
*   
*   

```
hljs.highlight('int a = 1;', {    language: lang || 'c',     ignoreIllegals: true}).value;
```

引入highlight.js后，本地的编辑器有代码高亮了，但复制到微信公众号编辑器里没有样式，原因上面已经提到了，highlight.js是由全局CSS提供的样式，微信里并没有引入该CSS。

## 3\. 内联highlight.js样式

公众号里不支持引入CSS，那么只能直接将样式内联，例如把`<span class="hljs-keyword>"`转为`<span style="color:#d73a49;">`

highlight.js提供了几十种代码主题^(\[5\])，基本都是同一个格式，简单写个脚本做转换：  

*   
*   
*   
*   
*   
*   
*   
*   
*   

```
import sys
s = open(sys.argv[1], 'r').read().replace(' ', '').replace('\n', '').replace('}', '}\n')
s = s.replace(',', '').split('\n')[:-1]
for i in s:    ss = i.split('{')[0].split('.')[1:]    print(f""".replace(/class\=\"({'|'.join(ss)})\"/g, 'style="{i.split('{')[1][:-1]}"')""")
```

我选用了GitHub主题，简单魔改了如注释斜体、meta灰色加粗、字符串绿色等。

生成的代码插入到`src/assets/scripts/renderers/wx-render.js`中，像这样

*   
*   
*   
*   
*

*   
*   
*   
*   
*

*

*   
*   
*   

```
let hljsCode = hljs.highlight(line, { language: infostring || 'c', ignoreIllegals: true }).valuehljsCode = hljsCode    .replace(/class\="(hljs)"/g, 'style="display:block;overflow-x:auto;padding:0.5em;color:#24292e;background:#ffffff;"')    .replace(/class\="(hljs-builtin-name|hljs-doctag|hljs-keyword|hljs-meta-keyword|hljs-template-tag|hljs-template-variable|hljs-type)"/g, 'style="color:#d73a49;"')    .replace(/class\="(hljs-title)"/g, 'style="color:#6f42c1;"')    .replace(/class\="(hljs-attr|hljs-attribute|hljs-literal|hljs-number|hljs-variable|hljs-selector-attr|hljs-selector-class|hljs-selector-id)"/g, 'style="color:#005cc5;"')    .replace(/class\="(hljs-meta)"/g, 'style="color:#999;font-weight:bold;"')    .replace(/class\="(hljs-regexp|hljs-string|hljs-meta-string)"/g, 'style="color:#219161;"')    .replace(/class\="(hljs-built_in|hljs-symbol|hljs-class|hljs-title)"/g, 'style="color:#e36209;"')    .replace(/class\="(hljs-comment|hljs-code|hljs-formula)"/g, 'style="color:#6a737d;font-style:italic;"')    .replace(/class\="(hljs-name|hljs-quote|hljs-selector-tag|hljs-selector-pseudo)"/g, 'style="color:#22863a;"')    .replace(/class\="(hljs-subst)"/g, 'style="color:#24292e;"')    .replace(/class\="(hljs-section)"/g, 'style="color:#005cc5;font-weight:bold;"')    .replace(/class\="(hljs-bullet)"/g, 'style="color:#735c0f;"')    .replace(/class\="(hljs-emphasis)"/g, 'style="color:#24292e;font-style:italic;"')    .replace(/class\="(hljs-strong)"/g, 'style="color:#24292e;font-weight:bold;"')    .replace(/class\="(hljs-addition)"/g, 'style="color:#22863a;background-color:#f0fff4;"')    .replace(/class\="(hljs-deletion)"/g, 'style="color:#b31d28;background-color:#ffeef0;"')
```
