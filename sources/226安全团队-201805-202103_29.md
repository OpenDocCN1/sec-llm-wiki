# \[学员作品\]FFmpeg任意文件读取复现（CVE-2016-1897）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MDE5ODExNQ==&mid=2652901509&idx=1&sn=9e8b12094505f55c05ab3dff8420761b&chksm=f0689e09c71f171f5b64a0fc17980dd465b0c52331a3d1c93c2baf01459d5336562403ded778&scene=126&sessionid=1681399977#rd](http://mp.weixin.qq.com/s?__biz=MzI4MDE5ODExNQ==&mid=2652901509&idx=1&sn=9e8b12094505f55c05ab3dff8420761b&chksm=f0689e09c71f171f5b64a0fc17980dd465b0c52331a3d1c93c2baf01459d5336562403ded778&scene=126&sessionid=1681399977#rd)

影响版本

· FFmpeg 2.8.x < 2.8.5

· FFmpeg 2.7.x < 2.7.5

· FFmpeg 2.6.x < 2.6.7

· FFmpeg 2.5.x < 2.5.10

注意事项

此漏洞只能在 linux 上复现 不支持 windows系统 因为payload中需要利用类似linux中的/dev/zero的空文件 进行对数据进行读取和不断的写入。Win下不存在这种文件或者功能

复现开始

打开linux系统 我这里用的 kali

1.命令行下输入 wget  “https://ffmpeg.org/releases/ffmpeg-2.8.1.tar.bz2 ” 下载ffmpeg

2.再用  tar -xjvf ffmpeg-2.8.1.tar.bz2  解压下载的文件

3.进入解压后的目录 cd ffmpeg-2.8.1/

然后输入一下命令开始编译和安装

4../configure --enable-shared --prefix=/monchickey/ffmpeg

5.make  (时间较长慢慢等待)

6.make  install

如果在执行 ./configure 时出错 请先安装 yasm  下载地址是：http://yasm.tortall.net/Download.html

7.设置动态库路径 vim /etc/ld.so.conf.d/ffmpeg.conf  

![](../Images/383b83a72a15f77ea010308f40f58c7b.png)

将图上两行添加上去

8. 此时如果输入 ./ffmpeg -version  显示如下 证明成功

![](../Images/c2f97d5920b569c38b48b47389411c5b.png)

9.下载playload 生成工具 生成一个 1.avi文件 地址 

https://github.com/neex/ffmpeg-avi-m3u-xbin/blob/master/gen\_xbin\_avi.py

10.将1.avi 用ffmpeg工具转换成 1.mp4  命令 ：./ffmpeg -i 1.avi 1.mp4 

![](../Images/1ecda58630dafe6b345392ec2dc8bb6a.png)

如上所示 代表成功 

此时我们来看一下 root 目录下 转换后的 1.mp4   如下图

![](../Images/d46a4aaef730f3b0a227c51d2e21f611.png)

打开视频 即可 看见读取文件的内容  此时读取的是 /etc/passwd

![](../Images/a18751aaf764275fbee3d91025ffa4e4.png)
