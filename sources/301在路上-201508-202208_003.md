# 首批特聘专家——杨蔚

工联众测平台旨在形成“专家会诊，资源聚焦”的新型安全技术服务模式，以众测形式面向工业互联网企业提供渗透测试、漏洞挖掘等安全服务。目前聘请15位业内权威专家，为平台提供战略性、前瞻性业务指导，与我们共同推动工业互联网企业安全能力建设，全面提升工业互联网安全防护水平。

![](../Images/a6efd4c8bf088e330144c8312aa42740.png)

特聘专家杨蔚，北京众安天下科技有限公司创始人&CEO，众测开拓者与拓荒者，拥有超过13年安全行业经验，近9年众测运营经验，长期致力于安全运营、攻防对抗、业务安全、安全创新领域研究。
