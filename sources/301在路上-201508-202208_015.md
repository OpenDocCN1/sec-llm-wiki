# 安全创业感受与一波福利

半年多没更新内容了，最近经历了不少事情，加上近期互联网暴露出来的各种负能量太多影响心情，各种信息泄露，社会问题，经济问题，包括税改、资本对创业公司影响，第一次感觉创业真不容易，当然很多事情发生了，我们总得面对，解决实际问题。  

  

太久没更新内容，我内心还是有些负罪感的 ，回归到正题，谈谈最近大半年的感受吧。

  

回想大半年前，年初的状态截止到现在，再一次从0到1的过程，搬家四次。每个阶段需要解决的问题很多，我们都坦然面对，积极面对，当然也离不开朋友们的坚持和支持，allsec一路上能活下来，这里特别感谢老齐、钰丹、龙飞、大伟以及原来allsec老团队的同学的坚守和支持，不然自己也很难坚持下去；也感谢新一轮的投资人和客户对我们的支持和理解，在这半年里我们也得到了一些收获和沉淀，让我们有基础和信心去面对未来。

  

年前和年初，我花了很多时间去了解互联网行业与安全行业的动态，也做了大量的分析工作，回归到现在，自己定的目标和承诺逐步完成，也验证了之前考虑的很多问题。这2年经历的人和事情多了，看人和看事情会看得更清晰，能收获到很多别人看不到的问题和价值，总的来讲，创业路上真是不易。然而创业最大的感受主要体现在以下几方面：

  

**第一、团队建设**

年前因为身体的缘故，生病了1个多月，一直到3月底4月份才开始组建新的团队，由于一直没对外发声也错过了第一波和第二波的招聘高峰期，从年初招人到现在半年时间里，发现整个行业的人才梯队和自我期望有了明显的区别。各大厂疯狂抢人，对于小团队而言优势不明显的情况下， 我们只能在人员选择上退让，尽可能去培养一些优秀的同学，不过回顾看之前考虑的方方面面，觉得还是没选择错，小伙伴们也非常努力，取得了一个个成功。关于人才方面，后面有机会单独分享谈谈看法。

  

**第二、项目来源与认可**

在项目方面，非常庆幸得到了原来不少朋友的帮助和支持，我们用心做好每个月项目，大部分都得到的新的反馈，口碑的形式认识了新的朋友/客户，积累了多个行业领域的案例。创业最重要的除了团队建设就是项目来源，如何支撑下来，去做好每个项目，离我们团队期望的理想状态还有一定努力的空间，活着，活好是衡量一个优秀安全团队的标准，寒冬之际，共勉。

  

**第三、业务模式**

在这大半年里，我们在面对很多商业的诱惑，选择了放弃和坚持自我，没有忘记创业的初心。关于业务模式，我们很清晰自我的定位，我们以开放的心态去迎接未来的挑战，合作大于竞争，在业务模式规则的制定，就决定了我们未来的方向，让更多“友商”成为我们的合作伙伴，互惠互利，共同成长这才是我们的目标。

  

**第四、坚持与毅力**

创业最大的是毅力，很多朋友劝过我，为什么要选择创业这条不归路，找个安稳点的公司待着，不需要承担那么大的压力，真正了解我的人，应该能力为什么当初选择，这也是我坚持下来的动力。

  

这个公众号会继续运营，会把我自己的想法和观点会持续输出，在个人能力的范围内，我会继续去帮助需要帮助的人。毕竟个人的沉淀有限，自己想做的事情太多，而需要去做的还很多，甚至是远远不够。
