# iPhone因安全问题需要更新，细节你知道吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwMTQ2NzY4NA==&mid=2652521030&idx=2&sn=0e60cfa8632540372ec38c08035cd0a1&chksm=8d03900dba74191ba22da74b6db9be2580ff458e580a01d8744e3a1966331d2cbd1c4448107f&scene=126&sessionid=1681656732#rd](http://mp.weixin.qq.com/s?__biz=MzIwMTQ2NzY4NA==&mid=2652521030&idx=2&sn=0e60cfa8632540372ec38c08035cd0a1&chksm=8d03900dba74191ba22da74b6db9be2580ff458e580a01d8744e3a1966331d2cbd1c4448107f&scene=126&sessionid=1681656732#rd)

       苹果公司经常会发布更新补丁，或者是一些公测版系统，有些用户比较喜欢体验新版本功能，常常会选择更新。而有些用户，则更喜欢保持现状，所以会选择忽略这些更新。

![](../Images/e2a15e7c05dbfc511ac74c7f33320319.png)  

       不过，苹果今天发布的更新与以往有所不同，其强调这一更新非常重要，如果你是iOS 9的用户，那么你必须选择升级。

       这是怎么一回事呢？

       在iOS 9.3.3发布之前，苹果曾发布过多个公测版，但是公测版的更迭过程中，并没有发现和修复安全问题。

![](../Images/fd5472e459c2aca03371890c74858b27.png)  

       但今天，苹果公司突然发布iOS 9.3.4版本，并且强烈推荐所有iOS 9用户更新。除了iOS 9用户之外，该安全更新还影响到iPhone 4S系列，iPad系列，还有第五代和第六代iPod touch。

       苹果这一异常举措，让我们很自然地将此次升级与盘古团队之前发布的越狱工具相关联。

       更新公告中称，此次更新针对一重要安全问题，CVE编号为 CVE-2016-4654，主要是内存损害问题。

![](../Images/13c00f16254739d8d585bb7e920b30e4.png)  

       中国的**盘古安全团队**发现了该漏洞，从安全角度来讲，该漏洞确实存在巨大的安全隐患，苹果称，此漏洞可以让任何应用程序借助内核权限来执行任意代码。

       而苹果通过改进内存处理解决了此问题，并发布了相应更新。

       虽然在公告中苹果并没有明确提到越狱，但是显而易见的是，进行更新之后，新版本系统将无法进行越狱，因为盘古团队提供的越狱工具是借助该漏洞进行越狱过程的。

![](../Images/6e5084d4dddece38bbced47bde6e9a27.png)  

       选择进行系统更新，会增强苹果的安全性，避免手机被黑和资料被盗取等威胁。选择不进行更新，那么你可以继续享受越狱给你带来方便，享受一些免费软件。

       所以说，你会做出怎么样的选择呢？
