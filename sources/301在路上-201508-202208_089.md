# 谁来保障智能汽车的网络安全？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwMTQ2NzY4NA==&mid=2652520841&idx=1&sn=4b63bac7bedbf3154cc6dda2260282bc&chksm=8d0393c2ba741ad47d9d1fa8932cf8fbc1c2875737477033eaa3ab7d79ec9bbfb4e1784c7169&scene=126&sessionid=1681656737#rd](http://mp.weixin.qq.com/s?__biz=MzIwMTQ2NzY4NA==&mid=2652520841&idx=1&sn=4b63bac7bedbf3154cc6dda2260282bc&chksm=8d0393c2ba741ad47d9d1fa8932cf8fbc1c2875737477033eaa3ab7d79ec9bbfb4e1784c7169&scene=126&sessionid=1681656737#rd)

        现如今，越来越多的汽车开始采用计算机来辅助，甚至自动化驾驶(自行驶汽车)，而未来的趋势就是智能完全取代人工驾驶。

        而汽车，也变成了带轮子的电脑，但汽车的互联性和技术性不断提高的同时，其安全问题也必须得到人们的重视了。

![](../Images/5ca7caa4546d95bf3aabc66a2ff2c88e.png)

        数据安全专家Craig Smith最近出版了一本名为《汽车黑客手册：防入侵指南》,其中指出了无人驾驶汽车的诸多安全漏洞，旨在为车主了提供一个保护自己的教程。因为他发现，在汽车技术研发机构的自动驾驶技术会议中，来的几乎都是机械工程师，只有他从事于数据安全方向，汽车行业目前仍不重视网络安全问题。

        在一次实验中，Smith通过接入汽车的车载联网系统，植入了自己的恶意代码。接着，他就能控制这辆汽车了，远程控制汽车上的其它物理部件，包括雨刷，印象，变速器，刹车，油门等。

![](../Images/57b87cc92274c94b59eeb3173a01e8c7.png)

        一些厂商提到：我们设计了一个入侵监测系统，嵌入在汽车之中去监测外界的干扰，一旦监测到网络攻击，汽车可以立即关闭掉整个网络。

        这一解决方案在某种程度上可以起到一些作用，但是这只能针对一些比较普通的汽车，对于高度依赖网络的无人驾驶汽车来说，这一方法完全不适用。

        并且，随着一些安全工具的出现，针对于智能类汽车的攻击将会更频繁。

![](../Images/cd91b3bf9f3ecaea8adde1eec4341421.png)

        近日一名法国研究者将发布一款检测汽车安全漏洞的工具，利用这款免费的工具就可以检测出汽车安全问题。

        这名法国安全研究人员将会在Black Hat会议上，详细介绍这款CANSPY安全审计工具，并把它免费分享给大家。

![](../Images/082d34180977e16f72536358d8f48121.png)

        一场全球汽车安全峰会中提出， 汽车行业的网络安全保障，少不了黑客这一角色。一方面我们应该加强相关的法律法规建设，防止汽车骇客对这一行业带来巨大冲击，但是更重要的是，我们应该通过培养，吸引，鼓励白帽子们来参与到汽车行业的安全建设中来，一同推进汽车安全的发展。

![](../Images/6dc98df2bffe0d8798ed0e724ca9523a.png)

        汽车厂家的技术人员并不擅长于挖掘汽车安全漏洞，所以许多汽车厂商，都纷纷发布了赏金计划，邀请全球精英白帽子帮助他们挖掘漏洞，并给予他们不菲的奖金。

        菲亚特-克莱斯勒（FCA）汽车公司就宣布，将为反馈漏洞的白帽子支付150到1500美元不等的报酬。
