# Windows10，你背着我们都做了写什么！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwMTQ2NzY4NA==&mid=2652520767&idx=3&sn=b87f1cd8f700823015f09c92a0c55af2&chksm=8d039374ba741a62e35bd4589cf41a1e72a313278d9c709daa983025ad2ddd8a8f66ec0e209c&scene=126&sessionid=1681656737#rd](http://mp.weixin.qq.com/s?__biz=MzIwMTQ2NzY4NA==&mid=2652520767&idx=3&sn=b87f1cd8f700823015f09c92a0c55af2&chksm=8d039374ba741a62e35bd4589cf41a1e72a313278d9c709daa983025ad2ddd8a8f66ec0e209c&scene=126&sessionid=1681656737#rd)

       自从Windows 10推出以来，经常会听到用户们对于微软未经用户允许收集用户信息的控诉。

       最近，法国国家数据保护委员会要求微软公司立即停止这种数据收集行为，并在本周三时，发表了官方声明，决定对微软进行长达3个月的监控，如果再次违反规定，将对微软公司进行制裁。

![](../Images/359809394e46e65da07bac4184fcd698.png)  

      这一事件的导火索呢？

      原来，在2016年4月至6月份期间，法国当局进行了一系列的调查，调查结果显示，尽管去年10月份时，欧洲法院已经判决安全港协议无效，但微软仍将法国用户数据源源不断地向美国秘密传输。  

      微软对收集用户数据行为做出了回应，表示充分理解，并且会主动配合法国国家数据保护委员会来解决这一问题。

![](../Images/9bb0ccbb2a9ca40f4a2f6d33cc2329b6.png)  

      有趣的是，微软并没有否认委员会对其进行的指控，也没有对 Windows 10过度收集用户隐私信息进行辩解，也就是说，这一行为确实是存在的。

      这已经不是第一次国家层面的机构对微软进行指责了。

      2015年8月，英国隐私维权机构Big Brother Watch对微软推出的Windows10表达了强烈的不满，认为Windows10存在严重的窥探用户隐私行为，而微软对此表示，收集信息是为了更好的为用户提供个性化体验。

      当然了，我们可以通过在W10系统中的一些设置，来减少一些微软对我们用户信息进行收集的行为：

  

>       计算机--设置--隐私设置

  

      Windows 10推出以来，不只是其收集隐私行为，它的其它行为也备受人们指责，例如 其令人厌烦的升级功能。
