# 最可怕的事情是竞争对手比你还勤奋

**前言**

  

昨天晚上很晚才睡，突然想起了往事、故友，觉得有太多的事情想写，但是，处于一些原因没办法直接分享，最近一直困扰我个人的更多的是，在安全领域这条路上，如何不密实自我，更好的磨炼自己的性格。但是，想起来了之前遇到的一些情况，无论是学业上，还是生活，感情上、事业上，遇到了太多有竞争的情况，然而，大多数人，包括我自己在内，并没有特别在意一些细节。最终，时间轨迹能证明一切的时候，很多人会醒悟。就比如我：“还会因为自己在这方面不足，而失眠”。

  

在年初的的时候，让我印象最深的是：当我知道某些友商在很多方面领域，所花费的时间和精力远远超出自己的想象的时候，我感到恐惧了。并且，这样的情况，我得到了论证—我见过有友商的同学在时间和勤奋程度上比他们同类竞争的企业/团队要高的多。然而有人会问，怎么个勤奋法？

  

1、晚睡早起，把绝大多数时间（吃了吃饭睡觉）投入在工作和学习当中，最大化的提升工作/学习效率。这点“幸福来敲门”片中，深有体会。本次文章的配图也是来源在这里。

  

2、熟知对手的背景情况，无论是内部的情报信息，还是产品模式信息甚至比友商内部的同学还了解。“**情报工作做到极致。**”

  

3、双休时间投入在资源积累和学习当中。我之前接触过不少业务、技术的同学。有极少数人是把自己的个人时间投入在自我学习成长和了解更多新知识储备上。相反，绝大多数人把更多的个人时间真正花费在打游戏、无效社交、泡吧等事情上。当然，不否认这样的生活方式，这也是正常的人该过的生活。

  

4、友商的高管对外发布的任何PR、演讲都会花时间去研究，学习，会花费更多的时间和精力去演讲友商的立场、风向标。

  

我们从生下来就就一直活在这个竞争的世界里，从小学、初中、高中、大学等等，一直到社会生存过程中，都一直在与他人竞争。做的每件事情都希望自己比别人走的更远，希望自己和家人过得比更人好。然而，最近接触到一些人更多的是在为自己找借口，而不是从自己身上找问题。

  

其实，人活着世界上，最大的竞争对手是自己。自己都战胜不了自己，怎么去战胜对手？

  

能看明白我想说什么的同学，把我提到的内容放到生活、学习，安全领域上，你会发现身边确实有这样的情况。

  

你觉得呢？
