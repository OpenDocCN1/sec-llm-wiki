# 如何(xuan)做(ze)一个靠谱的老大？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwMTQ2NzY4NA==&mid=2652520528&idx=1&sn=32f8811017548729ef2a914f13f0f17e&chksm=8d03921bba741b0d370af54afddc7ca131ae41c8453ffac6ab4513ad5c73abe4c674f05b701d&scene=126&sessionid=1681656752#rd](http://mp.weixin.qq.com/s?__biz=MzIwMTQ2NzY4NA==&mid=2652520528&idx=1&sn=32f8811017548729ef2a914f13f0f17e&chksm=8d03921bba741b0d370af54afddc7ca131ae41c8453ffac6ab4513ad5c73abe4c674f05b701d&scene=126&sessionid=1681656752#rd)

前言

前几天，跟哥们一直在讨论招人的话题，特别是在这个毕业季，大家都在物色安全人才。当然，主要是在前些天被某人在招人环节上，深深的刺激了一番，加上最近跟特别好的哥们聊人才管理相关的话题，没想到作为技术出身的哥们，在经历了几次创业团队后总结出来的人才管理的方法论上，着实让我一惊，使得引发更多的思考。

  

> “**如何选择一家靠谱的企业/团队”**和**“如何留住核心人才上”**这个话题，想到**失眠**。

  

介于这样的背景，我跟几个关系还不错的小伙伴一起聊了下这个话题，觉得还挺值得思考的，一方面主要是如何选择一个靠谱的老大；另一方面作为管理者，该如何去在团队上下更多的功夫去做一些事情。于是，在公众号关（fen）注（si）者群深入讨论这个话题，于是，有了几个比较有意思的评论。

  

> “我经历过一次换领导，我觉得领导自身专业水平过硬，严谨，专业，很重要。从管理者的角度上如果能给成员在专业上予以帮助，然后能为员工的安居乐业，成长空间想实际的，而不是只画大饼。leader的个人魅力，工作一丝不苟，团队扁平化管理，在团建活动中更加自然，不是领导而是朋友，自然可以“嘻嘻哈哈”，才可以深入交流。”

  

互联网公司扁平化，深入人心。

  

> “作为一个应届毕业生，你直属上司的处事风格和办公风格会在很大程度上影响你，所以选择一味靠谱的上司很重要。我觉得要选择一位靠谱的上司。首先，因为你刚接触真正的大社会，有一个会站在你的角度考虑问题，替你想一些比较深远的问题，带你分析一些复杂的东西何尝不是一种幸运？其次，你领导最好干过你所做的活，这样指导起来会更方便，说直白点，就是这个领导够专业，外行领导内行的话沟通障碍问题会引起更多问题，虽然领导最重要看中的是工作的结果和你最后办成的事情，可是温情的领导更容易留住人心不对吗？”  

  

得人心，得天下。

  

> “Leader的作用是带领大家超一个方向奋斗，并有着协调各方资源。技术过硬是基本，能上能下，无论是在做一线工程师，还是做了老板，都依然保持开始的风格，不因外界的变化而改变。理解、担当、不忘初心。人格魅力所在。”

  

不忘初心，在路上。

  

> “足够信任自己下属，下属为了不辜负这份信任会十分卖力！还有就是，给资质平庸的人多点机会！”  

  

做领导的要疑人不用，用人不疑！

  

> “我认为首先做领导的要有大局观，不能三拍（拍脑门，拍胸脯，拍大腿），管理不能过细，信任下属各司其职，个人感觉最重要的一点是有担当，不怕问题，能解决问题，不能太冷血，虽然也讲效益，但不能用你的时候你啥都好，不用你的时候啥都不是，一出问题就往外推卸责任，跟这种领导工作自然会显得没意思，没价值！不是安全行业的，针对自己工作的一点体会。”  

  

> **心理上：**
> 
> *   不装，平起平坐
>     
> *   接纳，无条件正反馈
>     
> *   馈赠，就是传授帮助带领
>     
> *   延伸，共建pkm（pkm是知识管理）
>     
> 
> **言语上（全是工具）：**
> 
> *   倾听，接收+积极反映+主动复述
>     
> *   分析，确认目标、现状及障碍，理清事实
>     
> *   提问，从一般到特殊，是否普适？
>     
> *   回应，这么做，会怎么样？不这么做，会怎么样？
>     
> *   这么做，不会怎么样？
>     
> 
>   
> 
> **行为上：**
> 
> *   领导要在不同时间，分四个角色。
>     
> *   命令，顾问，教练，授权。
>     
> *   对于意愿低能力低的，命令。
>     
> *   对于意愿高能力低的，顾问。
>     
> *   对于意愿低能力高的，教练。
>     
> *   对于意愿高能力高的，授权。
>     

  

**301总结：**

作为从一线成长起来的同学，个人自认为“略懂员工、略懂团队、略懂客户、略懂行业”各个角色要什么。但是个人从管理者的角度上，更应该给团队成员更多的学习机会、展示能力的机会，当然包括成长空间，作为leader帮助团队成本在自己擅长领域做合理定位。时间条件允许下，考虑未来职位方向定位。如果，从老大选择的角度上看，如果leader在行业内的评（pr）价，口碑应该决定自己在团队待的时长。这点我很佩服only\_guest团队近几年只有1个离职的同学，不过301也在尝试组建这样的团队，希望做个好的leader。

  

我个人特别喜欢跟有志向，有想法的朋友沟通，无论你是其他行业领域，还是向往安全领域的朋友，我都很乐意交往。当然，如果能一起共事是最好不过了，其实这真不是招聘广告。
