# 不看后悔：为什么企业招不到安全人才？你知道吗？

301也作为过来人也想谈谈自己的看法，包括今天通过朋友圈收集到了很多朋友的评论和留言，也看到了很多共性的问题。当然，作为读者的你，肯定很好奇，究竟有哪些问题？

  

> “目前学校的教育体制存在一些问题，学校所谓的信息安全专业几年的知识，跟企业实际需求是脱节的，无法满足企业对人才的要求。”
> 
>   
> 
> “大多数传统企业给的待遇很低，安全学习环境较差，工作内容过于单一，甚至充当的是真正保安的角色，没有一个好的安全leader带领，很难快速成长，更谈不上流人了。”  
> 
>   
> 
> “互联网的快速发展，各行业领域对安全人才需求过于旺盛，当然很多企业也不知道自己究竟需要什么样的人才，招聘广告前面一律，直接copy，供需相差太大。”
> 
>   
> 
> “技术不错的人才不愁安全工作，更看重的是薪资和成长空间。薪资过高后在企业内部会引起矛盾，HR不能理解安全岗位与其他技术岗位的差距；技术一般的企业看不上。绝大数甲方企业更看熟悉业务安全的复合型人才，而这方面的安全人才缺口极大，绝大多数安全新人不具备行业能力，更谈不上安全防护经验了”
> 
>   
> 
> “在一些金融机构，企业对人才的教育背景要求过高，而最终招聘过来的人才并不是企业所需，互联网岗位的薪资过高，传统金融岗位薪资相差太大，企业对安全人才的要求过高，全能型选手看不上XX职位，安全岗位缺口太小，业务盘子太大。”
> 
>   
> 
> “某保险机构反馈，当然还是薪资待遇的问题，领导对职位定义不清晰，安全工作支持不够，认可度不够，自然就没有多余的预算和岗位”
> 
>   
> 
> “商业太重，团队在技术氛围不够，很难吸引到合适的安全人才，人才得不到成长。安全研究岗位当做售前使用。你懂的”  
> 
>   
> 
> “安全是一个靠实战经验的工种，这两年物联网、智能设备、大数据的兴起，安全需求旺盛，企业要求过高，具备一定经验的人才太少，一时无法满足企业缺口；在企业的角度是但问题，并且一味想通过1-2个人员改变整个公司内部的安全环境，过于理想化，甚至不了解自己要什么样的人才。”
> 
>   
> 
> “钱给的不够多，优秀人才急缺，并且需要一个背锅侠。”
> 
>   
> 
> “自我估值与企业估值间差距太大；大多数技术人员的通病，愤世嫉俗，特立独行；企业对安全的态度，对安全从业者的职业道德信任度；当然提到钱，归根结底还是特定人的价值判断和整体在企业内部的价值。”
> 
>   
> 
> “企业对外号称重视安全，对内安全没有任何话语权，这是钱解决不了的问题。”
> 
>   
> 
> “很多企业很矛盾，要求没有做过黑产的人，又要招聘研究黑产攻防的人员，又不愿意给钱，还一堆XX需求。”
> 
>   
> 
> “安全理念，安全工程师不能用业务开发工程师的标准衡量，安全工程师需要以抵抗风险的能力衡量。意志坚定，头脑清晰，行动果断。”
> 
>   
> 
> “安全人才虚高，近几年的安全炒作，让安全创业成本越来越低，安全薪资炒作极为严重。需要经历一段时间的市场洗牌后，洗刷掉一部分，整体安全人才的市场会好很多。”
> 
>   
> 
> “安全人才纯粹当做救火队员，着火时才想着有安全专员来背锅，自然跳槽率很高，留不住人。”
> 
>   
> 
> “一些真正懂得管理的人在创业，一些真正掌握技术的人在做黑产。”
> 
>   
> 
> “企业的安全期望与优秀人才的自我价值期望不匹配，往往就是高不成低不就。”
> 
>   
> 
> “没有妹子，没有票子，没有长期的发展规划，没有提升空间，没有各种福利，没有牛逼的leader，没有正规的安全团队，没有把安全当回事，而只是为了招人，拼凑一个安全团队。”
> 
>   
> 
> “第一，找不到人。
> 
> a.企业安全招聘机制不完善，所需门槛高，有学历要求，但安全从业人员大多自学成才，学历可能不能满足。
> 
> b.安全是一个隐形的投资，尚未发生安全事件之前，公司不能充分意识到安全人才的重要性，可是安全事件也是不定时的，在大多数公司看来，安全人员去了事件不发生，这种"不作为”不值得花大量的资本。
> 
> c.安全人员学的东西相比开发和研发以及测试等等同样归属计算机这一大类的行业而言，更多更难，所以本身会觉得自己应该收获得比别的岗位的高，但是企业或者公司只看中产出来评优或者是升职加薪，公司当然招不到人。
> 
> 第二，公司留不住人。
> 
> a.安全行业的人是沉下心来做技术的，他自己需要得到一些肯定或者说是体现自己价值的地方，可是公司重大安全问题出现少，所以价值得不到体现，也同样不得领导的重视。
> 
> b.安全人员在不断升级学习的过程中，可能自己的能力早已超出了能在该公司实现的，可是实际为公司付出的能获得的收益也相对同样能力的别人的少，得到的工资与自己的能力不成正比，发展也没帮助，想寻求更好的氛围来学习。”
> 
>   
> 
> “某些领导傻逼，所以招不到人。”
> 
>   
> 
> 看了这么多，找到答案了吗？。
