# 原来你也怕自己变成这样的人？

有追求，平庸且无所作为，成为螺丝钉大军中的一员。

  

面对社会的快速发展和生活在各种细节上对个人不断的挑战，尽可能努力让自己不被社会淘汰、不被他人左右思想的人。

  

对于现在、未来、人生，我希望自己和现在的你最后不要变成下面这样。

  

1、10来岁的时候，每天翘课、打游戏、打架，在最应该憧憬自己理想的时候，忘掉了自己该成为什么样的人，忘掉当初想变成一名有理想的黑客。

  

2、20岁的时候，每天打dota、泡妞，追星，拼爹，而自己缺什么都不懂，在大学忘了理想和该如何准备面向社会，丢掉了互联网安全的期待。

  

3、20多岁的时候，每天挤公交、地铁，为了工作和生活的小事跟同事、父母争吵不休，找一份早九晚五的信息安全岗位，然后看领导的脸色做事情。

  

4、30岁的时候，每天为了奶粉和财米油盐的事情劳累奔波，自己变成一个各方面都很平庸的人。已经跟不上互联网安全的发展，却忘了自己该如何去奋斗。

  

5、40岁的时候，把一生的希望和未完成的理想寄托在孩子身上，期望自己尽快退休，幻想着孩子能够好好努力，老来自己能够轻松一些，安安静静养老。

  

6、50岁的时候，开始为孩子的工作、将来的房子、结婚劳累，此时发现自己原来不在年轻，与互联网和社会脱节，向往年轻人对互联网安全梦的追求。

  

7、60岁的时候，终于到退休的日子，把一切寄托都到下一代，希望未来能实现自己的当初的安全梦想。

  

8、80岁的时候，记忆力开始减退，手脚不在利索，已经开始逐步忘了当年利用漏洞去泡过的妹子和挂过的黑页。自己却无心无力的开始忧伤。

  

当生命真正结束的时候，回顾当年，在应有的年纪上去做更有价值的事情，应该有一个长远的理想和希望自己未来成为一个什么样的人。

  

而不是让自己看到别人忙碌的背影，没有自己人生的那一丝精彩和值得历史留念的一刻，没有骄傲、没有理想、没有值得下一代吹牛的筹码，那才是最可悲的。

  

301觉得人生如此，你觉得呢？
