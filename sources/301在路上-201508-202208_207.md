# 贷齐乐网贷系统最新版爆安全漏洞，可造成用户敏感信息泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwMTQ2NzY4NA==&mid=402853150&idx=1&sn=41ab37bcade63bc8e675c175f80dae67&chksm=0b1adf553c6d564302f10ad30c3ff0dc4ae4a54ffadeec0bea076cf59ee4cb39d784dd4dd2a6&scene=126&sessionid=1681656802#rd](http://mp.weixin.qq.com/s?__biz=MzIwMTQ2NzY4NA==&mid=402853150&idx=1&sn=41ab37bcade63bc8e675c175f80dae67&chksm=0b1adf553c6d564302f10ad30c3ff0dc4ae4a54ffadeec0bea076cf59ee4cb39d784dd4dd2a6&scene=126&sessionid=1681656802#rd)

乌云导读

通过构造特殊的变量覆盖方式可绕过贷齐乐系统内置的Web应用防火墙程序（WAF）安全机制，从而可对数据库进行攻击，可造成用户敏感信息（用户名、密码、投资信息等）泄露，对平台资金安全造成威胁。

1月22日下午（16：06），有白帽“phith0n”向乌云平台报告了贷齐乐系统最新版SQL注入高危漏洞（漏洞编号：WooYun-2016-171945），类型为SQL注射漏洞。

白帽子发现，通过构造特殊的变量覆盖方式可绕过贷齐乐系统内置的Web应用防火墙程序（WAF）安全机制，从而可对数据库进行攻击，可造成**用户敏感信息（用户名、密码、投资信息等）泄露**，对平台**资金安全**造成威胁。  

贷齐乐是国内知名的P2P网贷系统，由宁波贷齐乐网络科技有限公司开发。该系统在国内P2P市场应用及其广泛，根据官方统计：月交易量1000万以上的平台有400多家，正在施工建设的有50多家，具体可参考其官网合作案例。  

乌云已经及时将该漏洞报告提供给贷齐乐官方，官方已对漏洞进行确认。建议使用贷齐乐系统的网贷平台近期可关注官方补丁更新，及时跟进修复。同时建议相关平台对用户进行安全提示，及时修改密码，确保资金安全。  

另外需要提及，Web应用防火墙（W  
AF）为贷齐乐最主要的安全机制，被绕过将直接暴露程序安全隐患。考虑到贷齐乐系统自身许多地方不甚完善，危害可被再次放大，远超此次漏洞影响。建议厂商能重视自身产品漏洞，提升安全品质。WAF类机制不能担起系统所有的安全防护工作，要深入安全之本质。
