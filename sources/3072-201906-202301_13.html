0x00 概述

最近碰到了利用TLS进行反调试的程序，在这里分享一下相关的技术原理。

TLS（Thread Local Storage）又叫做线程局部存储，它用来将数据和一个指定的线程关联起来。它能应用于反调试技术的原因在于TLS的回调函数是先于OEP执行的。

TLS相关的结构如下，其中重点是AddressOfCallBacks这个回调函数的表，这些回调函数就用来实现反调试。

0x01 例子

下面是网上找到的一个有TLS的crackme，其中的反调试部分如下。

void __stdcall TlsCallback_0(int a1, int a2, int a3)
{
  void (__stdcall *v3)(int, int, int); // edi
  unsigned int v4; // et0
  void *v5; // eax
  void *v6; // eax
  unsigned int v7; // [esp+0h] [ebp-10h]

  if ( a2 == 1 )
  {
    v3 = sub_4020F7;
    v4 = __readeflags();
    v7 = v4;
    if ( v4 & 0x100 )
      v3 = 0;
    __writeeflags(v7);
    if ( *(_DWORD *)&NtCurrentPeb()->InheritedAddressSpace & 0x10000 )
      v3 = 0;
    v5 = (void *)GetCurrentThread();
    NtSetInformationThread(v5, ThreadHideFromDebugger, 0, 0);
    v6 = (void *)GetCurrentProcess();
    NtQueryInformationProcess(v6, ProcessDebugPort, &ReturnLength, 4u, 0);
    if ( ReturnLength )
      v3 = 0;
    dword_404036 = (int)v3;
  }
}


sub_4020F7函数

void __stdcall sub_4020F7(int a1, int a2, int a3)
{
  void *v3; // eax

  if ( a2 == 1 )
  {
    v3 = (void *)GetCurrentProcess();
    NtQueryInformationProcess(v3, ProcessDebugPort, &ReturnLength, 4u, &ReturnLength);
    ReturnLength ^= 0x31333337u;
    dword_40403A = 0;
    ReturnLength ^= *(unsigned __int8 *)start;
  }
}

这里的TLS回调函数通过调用NtSetInformationThread来拒绝内核的调试信息，通过调用NtQueryInformationProcess来获得是否在被调试的状态，同时通过状态的不同设置全局变量ReturnLength来暗中影响后续的加解密的过程。

0x02 绕过方法

1.通过x64dbg的选项设置TLS回调函数断点调试TLS的回调函数，并对代码进行patch。

2.使用调试器自带的反反调试插件来绕过反调试。
