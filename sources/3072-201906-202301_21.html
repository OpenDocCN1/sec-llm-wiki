Micro-CMS v1 (4*2)

1.XSS

发现编辑页面有用户交互，我们在标题和内容处添加XSS payload即可，注意这里标题和文章内容是两个flag 

2.IDOR

观察到我们创建的页面起始id是11，而原本的文章id是从2开始的，所以对2-11间的文章进行访问。page下会返回403，我们通过edit api来访问便可以成功拿到flag


3.sqli

同样是edit api处存在sqli，我们添加单引号便可以爆出flag


Micro-CMS v2 (3*3)

1.sqli

在登录出通过报错拿到登录的SQL语句，构造如下payload即可登录，登录后我们在private页面拿到第一个flag 


  1. username: admin' union select 1#
  2. passwd:1



登录的同时我们拿到提示，意味着需要挖掘出账号和密码，这里直接sqlmap一梭子，用账号密码登录后便拿到第二个flag


2.测试api

测试CMS的各个api并注意与CMS1.0的不同之处，发现修改并保存文章会返回404，尝试修改HTTP头中的信息，POST改GET，删referer，删cookie等。当删除cookie时会爆出flag


Petshop Pro (3*3)

1.褥羊毛


观察到checkout会通过POST请求发给后台相关的价格，我们抓包修改POST请求中的价格，返回第一个flag


2.目录爆破&账号密码爆破

测试了该页面所有的功能没有什么收获后，通过dirb爆破出登录目录。对登录功能尝试弱口令，sqli都不能获得进一步的信息。注意到没有对请求限制频率，且会返回用户名错误的字段，所以尝试对用户名和密码进行爆破 


字典是用的github上的这个项目。另外我目录爆破，ssh密码爆破等等都是用的这个项目的字典


  1. github.com/danielmiessler/SecLists
  2. 用户名：https://raw.githubusercontent.com/danielmiessler/SecLists/master/Usernames/Names/names.txt 
  3. 密码: https://raw.githubusercontent.com/danielmiessler/SecLists/master/Passwords/darkweb2017-top10000.txt


如果是kali 下使用的话通过apt-get便可以下载下来 

apt-get-y install seclists


最后成功拿到账号和密码,登录后拿到第二个flag

 username=freda&password=wombat
