P4wnP1

目前已经比较成熟的基于树莓派的BadUsB的开源项目就是P4wnP1，基于这个开源项目我们可以很简单的实现带后门的，或者截取hash的USB

不过在这之前我们可以先认识一下，USB设备分为两种，一种是host，一种是device，关于它们的区别stackexchange上的一个问题和答案写的很清楚

Q : What exactly are the differences between a USB host and device? Is it just that who powers the bus?(USB host 和 USB device的区别到底是个啥啊？难道就是谁给总线供电吗？) A : The host initiates all communication on the bus, the device only responds when asked by the host.(区别就是USB host要在总线上初始化他们之间所有的交流，USB device只是响应一下USB host的请求)

搭建BadUSB device的环境

硬件设备：

  • Raspberry Pi Zero W

  • SD卡

  • Pi Zero W USB-A Addon Board

  • 读卡器

软件：

  • SD Card Formatter

  • Win32DiskImager

步骤：

  1. 格式化SD卡

  2. 将raspbian用烧到SD卡中，注意这里最好不要用最新的系统，我使用的是raspbian-jessie-lite

  3. 将一个名为ssh，无后缀名的文件添加boot下

  4. 添加一个名为wpasupplicant.conf的文件用来配置wifi，文件内容如下，其中相关的信息都可以在连接的wifi属性中找到。keymgmt是看你的wifi加密方式，这里使用的WPA2,所以填WPA-PSK,最后的priority是配置多个wifi时用的优先级

  1. network={
  2.     ssid="*******"
  3.     psk="password"
  4.     key_mgmt=WPA-PSK
  5.     priority=1
  6. }

  1. 此时将SD卡插入安装了扩展板的zero w，然后将zero w插入电脑。如果黄灯闪烁一会后停止，表明系统并没有启动成功，建议重新烧一次系统。黄灯亮表示系统启动成功，过一段时间后在路由器管理界面就可以找到对应的IP了，利用putty或Xshell连接zero w，用户名pi密码raspberry。如果过了很长时间都没有设备上线，而且前面操作没错，建议重新烧一次系统

  2. 换源，这里是清华的镜像，请根据自己的版本更改sources.list文件和raspi.list文件的的内容

  1. # 编辑 `/etc/apt/sources.list` 文件，删除原文件所有内容，用以下内容取代：
  2. deb http://mirrors.tuna.tsinghua.edu.cn/raspbian/raspbian/ jessie main non-free contrib
  3. deb-src http://mirrors.tuna.tsinghua.edu.cn/raspbian/raspbian/ jessie main non-free contrib

  5. # 编辑 `/etc/apt/sources.list.d/raspi.list` 文件，删除原文件所有内容，用以下内容取代：
  6. deb http://mirrors.tuna.tsinghua.edu.cn/raspberrypi/ jessie main

  1. bash执行以下命令。注意，直接clone P4wnP1项目的.git无法将子模块下载完整，这会在后续引发各种bug

  1. sudo apt-get update

  3. sudo apt-get install git john

  5. git clone --recursive https://github.com/mame82/P4wnP1

  7. cd P4wnP1/

  9. ./install.sh

  1. install.sh的执行会花费较长时间，执行完毕后reboot，待听到电脑插入U盘的声音后表明reboot成功，过几分钟后就会出现一个名叫P4wnP1的wifi，wifi密码为MaMe82-P4wnP1

  2. 连接上wifi后，用putty或xshell连接P4wnP1 server，IP地址为172.24.0.1，用户名和密码不变

  3. 选择payload，就是更改setup.cfg中的内容，不用的payload注释掉，要使用的payload的注释符号去掉，保存

  4. 保存后拔出，插到靶机上，手机或电脑通过连接P4wnP1 server来控制靶机(自己的机器)

另一个思路

一顿猛如虎的操作后，我突然意识到即使知道如何使用P4wnP1拿shell，但依然不太清楚整个过程的运行机理，整个开源项目的抽象程度太高，我们在配置的过程中几乎没有接触到关于USB的一些更底层的特性。而且这里的反弹shell的payload操作也就是模拟键盘的操作，这里提供另一种实现思路，直接实现键盘模拟

设置树莓派为HID设备(键盘)

将一个刚刚烧好系统的树莓派配置成一个HID设备，需要创建USB Gadget。也就需要配置一些文件

初始化的操作

  1. modprobe libcomposite
  2. cd /sys/kernel/config/usb_gadget/
  3. mkdir -p g1
  4. cd g1

添加设备描述符

  1. echo 0x1d6b > idVendor # Linux Foundation
  2. echo 0x0104 > idProduct # Multifunction Composite Gadget
  3. echo 0x0100 > bcdDevice # v1.0.0
  4. echo 0x0200 > bcdUSB # USB2
  5. mkdir -p strings/0x409
  6. echo "fedcba9876543210" > strings/0x409/serialnumber
  7. echo "Valentin Brosseau" > strings/0x409/manufacturer
  8. echo "Keyboard-dev" > strings/0x409/product

键盘相关的操作

  1. mkdir -p functions/hid.usb0
  2. echo 1 > functions/hid.usb0/protocol
  3. echo 1 > functions/hid.usb0/subclass
  4. echo 8 > functions/hid.usb0/report_length
  5. echo -ne \\x05\\x01\\x09\\x06\\xa1\\x01\\x05\\x07\\x19\\xe0\\x29\\xe7\\x15\\x00\\x25\\x01\\x75\\x01\\x95\\x08\\x81\\x02\\x95\\x01\\x75\\x08\\x81\\x03\\x95\\x05\\x75\\x01\\x05\\x08\\x19\\x01\\x29\\x05\\x91\\x02\\x95\\x01\\x75\\x03\\x91\\x03\\x95\\x06\\x75\\x08\\x15\\x00\\x25\\x65\\x05\\x07\\x19\\x00\\x29\\x65\\x81\\x00\\xc0 > functions/hid.usb0/report_desc
  6. mkdir -p configs/c.1
  7. ln -s functions/hid.usb0 configs/c.1/

关联配置文件启用设备

  1. mkdir -p configs/c.1/strings/0x409
  2. echo "Config 1: Keyboard" > configs/c.1/strings/0x409/configuration
  3. echo 250 > configs/c.1/MaxPower
  4. ls /sys/class/udc > UDC

这样，一个模拟的键盘便实现了，我们可以通过keycode来写入payload从而getshell。因为是树莓派的第一篇文章，所以这里相关的keycode和payload的具体细节就不展开讨论了，以后有时间将会进一步拓展
