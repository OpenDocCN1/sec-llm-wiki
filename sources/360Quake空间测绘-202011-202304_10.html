环境搭建

  • 详细搭建教程可参考官网http://wiki.r1soft.com/display/ServerBackup/Install+Server+Backup+Manager+on+Debian+and+Ubuntu.html
  • 先下载安装包
  • http://repo.r1soft.com/6.16.3/75/trials/R1soft-ServerBackup-Manager-SE-linux64.zip
  • 再下载存在漏洞的module版本
  • http://repo.r1soft.com/6.16.3/75/r1soft-getmodule-1.0.0-101_amd64.deb
  • 把压缩包文件和deb文件放ubuntu服务器上，使用unzip解压zip文件
  • unzip R1soft-ServerBackup-Manager-SE-linux64.zip
  • 若无unzip，可使用apt安装
  • 把deb放到同一个目录，然后sudo dpkg -i *.deb
  • 设置用户名密码以及服务端口并重启
sudo serverbackup-setup --user admin --pass r1soft
sudo serverbackup-setup --http-port 8080 --https-port 8443
sudo systemctl restart sbm-server.service

  • 安装完成以后访问http://172.16.142.186:8080/login.zul
  • 若需要调试java可编辑/usr/sbin/r1soft/conf/server.conf加一行
additional.23=-agentlib:jdwp=transport=dt_socket,server=y,suspend=n,address=5005

利用

  • 本文主要讲解如何实战利用此漏洞
  • 第一步，获取dt值，以及JSESSIONID=C468A45F7D96ECA16E48DE470E3AE9DE
  • 然后就可以加上这个dt值以及session验证是否存在漏洞，可读取配置文件/WEB-INF/applicationContext-security.xml或/WEB-INF/web.xml
  • 到这一步已经绕过了权限验证，下一步就是RCE了
  • RCE的点是通过上传MySql Database Driver进行命令执行的
  • 所以我们需要上传一个jar包，具体分析可看toc_mysql-driver-rce
  • 下文主要讲解如何通过pocsuite3完成自动化反弹shell
  • 首先需要构造一个java代码，进行rce，这里进行反弹shell
