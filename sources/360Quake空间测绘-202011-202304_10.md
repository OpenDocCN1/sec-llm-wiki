## 环境搭建

*   详细搭建教程可参考官网http://wiki.r1soft.com/display/ServerBackup/Install+Server+Backup+Manager+on+Debian+and+Ubuntu.html
*   先下载安装包
*   http://repo.r1soft.com/6.16.3/75/trials/R1soft-ServerBackup-Manager-SE-linux64.zip
*   再下载存在漏洞的module版本
*   http://repo.r1soft.com/6.16.3/75/r1soft-getmodule-1.0.0-101\_amd64.deb
*   把压缩包文件和deb文件放ubuntu服务器上，使用unzip解压zip文件
*   unzip R1soft-ServerBackup-Manager-SE-linux64.zip
*   *若无unzip，可使用apt安装*
*   把deb放到同一个目录，然后`sudo dpkg -i *.deb`

![](../Images/595efbd865fb9cca02622fa1ab1b941d.png)

*   设置用户名密码以及服务端口并重启

```



sudo serverbackup-setup --user admin --pass r1soft
```

![](../Images/6bef514bee77edc5cab12c57e011cca7.png)

*   安装完成以后访问`http://172.16.142.186:8080/login.zul`

![](../Images/02b7001a52d3657fad3ee1bc43821a18.png)

*   若需要调试java可编辑/usr/sbin/r1soft/conf/server.conf加一行

```
additional.23=-agentlib:jdwp=transport=dt_socket,server=y,
```

## 利用

*   本文主要讲解如何实战利用此漏洞
*   第一步，获取dt值，以及JSESSIONID=C468A45F7D96ECA16E48DE470E3AE9DE

![](../Images/827b16e447bfbc245734b6e3e50d6101.png)

*   然后就可以加上这个dt值以及session验证是否存在漏洞，可读取配置文件`/WEB-INF/applicationContext-security.xml`或`/WEB-INF/web.xml`

![](../Images/96614fed447a4bb95bcdd5871cae5a67.png)

*   到这一步已经绕过了权限验证，下一步就是RCE了
