## 0x01 域名接管漏洞

域名接管漏洞通常发生在example.com或subdomain.example.com指向已被删除或被删除的服务（例如 GitHub Pages、Heroku 等）时。这允许攻击者在正在使用的服务上设置一个页面，并将他们的页面指向该域名。例如，如果 subdomain.example.com 指向一个GitHub Pages并且用户删除了该GitHub Pages，攻击者现在可以创建一个GitHub Pages，添加一个包含 subdomain.example.com 的CNAME文件，并声明 subdomain.example.com便可接管该域名发布任意内容。

## 0x02 GitHub Pages

GitHub Pages 是一种静态站点托管服务，它直接从 GitHub 上的存储库获取 HTML、CSS 和 JavaScript 文件，可选择通过构建过程运行文件，然后发布网站。您可以在GitHub Pages 示例集合中查看 GitHub Pages 站点示例。

## 0x03 域名接管实战

### 域名接管三步走

1.  获取 Github Pages ip地址
    
2.  获取指向 Github Pages ip地址且Github Pages被删除了的域名
    
3.  建立自己的Github Pages并接管域名到Github Pages
