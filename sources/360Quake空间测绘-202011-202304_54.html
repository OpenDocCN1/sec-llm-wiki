# 快速搜索多个IP或域名

收集某公司的信息时，遇到有多个主域名的情况不需要一个个手动输入进行搜索，可使用

Quake的IP/域名批量搜索功能：

在搜索框右侧点击第一个icon ”IP/域名批量搜索“，直接上传文件或手动输入批量IP/域名进行查询；还可将搜索的内容加入到收藏列表，方便下次快捷搜索哦～


# 字符串型的数据支持分词功能

如：【端口响应】【证书】。

Quake提供在线分词debug，附带超链接，

可自动拼接搜索语法，快来试试呀~
