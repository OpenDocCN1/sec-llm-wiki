题目1

设计思路：

本题难点和有趣的地方主要在于wingdings字体，只有了解过webdings、wingdings之类字体的人才能联想解题思路。设计题目时，首先假设答案是10631，考虑到如果直接将六位数字用wingdins字体显示过于简单，太容易被猜到，因此将六位数字使用MD5算法计算摘要得到9770eb65dfb1c8dacd19eb61a2c03418。六位数字的MD5很容易通过一些在线解密网站破解，保证了谜题可以被正常解开。但是MD5摘要有很强的规律性，比如长度是32位，字符范围是0-9a-f，所以需要将这串摘要进行base64编码得到OTc3MGViNjVkZmIxYzhkYWNkMTllYjYxYTJjMDM0MTg=。最后将编码后的值用wingdings字体输出就是本次的谜题。

解题方法

1.     首先看到题目是一连串奇怪的字符，猜测是符号字体wingdings，将题目字体转换为times new roman得到字符串：OTc3MGViNjVkZmIxYzhkYWNkMTllYjYxYTJjMDM0MTg=（现场可以使用手机搜索wingdings对照表进行手动转换，例如https://wenku.baidu.com/view/81b41244336c1eb91a375dcb.html）

2.     字符串以等号结尾，很容易猜到是经过base64编码过的，利用在线解码网站（例如：http://www1.tc711.com/tool/BASE64.htm）解码得到：9770eb65dfb1c8dacd19eb61a2c03418

3.     解码后的字符串为32位，由[0-9a-f]组成，猜测为哈希值，放到解密网站（例如：http://cmd5.com/）进行解密，得到最终结果：103601



题目2

泰勒，你手上有36种星牌，每4张星牌可以组合出一种魔法。

但由于魔法斥力，一旦某个魔法存在，其它几种魔法就不能同时存在。

比如，若存在魔法1234，那么魔法2134、1324、1243、3214、1432、4321就不能存在。

为了解救你的弟弟，你需要释放尽可能多的魔法组合。告诉我，你最多可以组合出多少魔法？

解题方法

36 + C(2,36)*4 + C(3,36)*15 + C(4,36)*8 =

36 + 2520 + 107100 + 471240 = 580896

泰勒哥哥，我把1314变异，让每个数字都不在原来的位置，也只有3141和4131两种变体，难道我们的未来只有死亡与离别这两种结果吗？我不信命，我拿到了星际领主留下的生命密码：861314520。这是拯救家族最后的机会，算出861314520所有的变体总数，去寻找和平与安宁的希望吧！

题目4

泰勒，你的弟弟在我手上，看到他站在哪了吗？没错，黑洞就在他前面两步远了。多么天真可爱的小孩子啊！他有50%的可能前进1步或后退2步， 你说，他跳进黑洞的概率有多少？时间不等人，找到宇宙WiFi再等消息吧，哈哈！（已知√2=1.41421356，√3=1.73205081，√5=2.23606798，结果取小数点后8位）

解题方法

P(1) = 1/2 + 1/2*P(3)

P(3) = P(1)^3

P(1) = 1/2 + 1/2*P(1)^3

P(1) = (√5-1)/2

P(2) = P(1)^2 = (3-√5)/2 = (3-2.23606798)/2 = 0.38196601
