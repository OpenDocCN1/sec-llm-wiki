# CVE-2014-0226 apache httpd信息泄漏漏洞分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkzOTIyMzYyMg==&mid=2247487985&idx=1&sn=a134d6cc547976eba55912ac3b6a1b59&chksm=c2f56ed8f582e7ceb3ce5f23067fe2f0dffb39b619122e2c7c09f2b700b65a08ef9200176742&scene=126&sessionid=1681377469#rd](http://mp.weixin.qq.com/s?__biz=MzkzOTIyMzYyMg==&mid=2247487985&idx=1&sn=a134d6cc547976eba55912ac3b6a1b59&chksm=c2f56ed8f582e7ceb3ce5f23067fe2f0dffb39b619122e2c7c09f2b700b65a08ef9200176742&scene=126&sessionid=1681377469#rd)

**危害等级：低危**

 

**代码分析:**

存在条件竞争的地方在worker\_score结构体的request元素，结构如下：

  

![](../Images/cacf77e33fa3a61444a72a5a02edd45a.png)

1.1. 开启mod\_status,将在update\_child\_status\_internal()中使用copy\_request()操作request

  

1.2.ap\_escape\_logitem()也可以同时操作request指向的内存。

  

2\. 假设ws\_record->request的第一个字节是""，ap\_escape\_logitem()计算出ws\_record->request的长度是1，此时另一线程将ws\_record->request修改为"GET/"；

  

3.ap\_escape\_logitem()函数中调用了ap\_pmemdup(pool,str, 1)从"GET /"复制1个字节

  

4\. ap\_escape\_logitem返回了"G......"

 

上面流程产生的值进入ap\_escape\_html2()中继续处理。

  

![](../Images/8ada50a5f1517e680aa51049f29fdb00.png)

  

**如果发生条件竞争，流程如下:**

1.第1个for循环该行计算s的长度

  

2.因为s字符串包括了垃圾字符，可能包含'>'字符。

  

3.第1个for循环结束之后，j大于0

  

4.x = apr\_palloc(p,i + j + 1); x字符串被申请

  

5.1.第2个for循环复制s字符串到x字符串，但是apr\_palloc申请的内存第一字节为条件竞争的得到的,对于i > 0，x字符串会读取随机内存。因此会导致信息泄露漏洞。

  

5.2.或者第2个循环无限进行，只到遇到非0的值，或者遇到未分配的内存和只读内存。

 

 

**动态调试:**

**注意：**

 确定apache httpd的编译选项中使用MPM event 或者MPM worker，具体方法如下:

  

 编辑 /etc/sysconfig/httpd 文件，可以将HTTPD=/usr/sbin/httpd.worker 这行取消注释，然后重启httpd服务，即可使用到woker模式的httpd了；不过可能使用worker模式的httpd会与PHP的一些东西存在兼容性而导致httpd服务不能启动，如下所示，是需要yum安装 php-zts 软件包。

  

**环境搭建:**

 1.下载httpd-2.4.9.tar.gz

  

 2.在子目录srclib中下载apr-util-1.5.4.tar.gz和apr-1.5.4.tar.gz，解压缩，并在目录名中去除版本符号

  

 3../configure --enable-mods-shared=reallyall--with-included-apr --with-mpm=worker

  

 4.配置httpd.conf

  

 SetHandler server-status

 ExtendedStatus On

 <Location /server-status>

 SetHandler server-status

 

 Order Deny,Allow

 Allow from all

 </Location>

 5.service httpd start

  

 6../poc.py | grep "" |grep -v AAAA| grep -v "{}"| grep -v notables
