# 快报丨被泄漏的出生信息

一家允许美国人获取出生/死亡证明的在线公司被爆信息泄露事件。目前在Amazon Web Services(AWS) 储存库中发现了超过75.2万美国人的出生证明副本。外媒已经与当地数据保护机构联系，以警告安全漏洞，但它没有立即发表评论。  

  

该储存库没有进行密码保护，任何人都可以通过非常容易猜测的URL网址来访问这些数据。虽然美国各个州的申请流程各不相同，但都会执行一项相同的任务：允许美国人向该州的记录保存机构（通常是州卫生部门）提出申请，以获取其历史记录的副本。我们审查的申请书包含申请人的姓名，出生日期，当前家庭住址，电子邮件地址，电话号码和历史个人信息，包括过去的地址，家庭成员的姓名和申请理由（例如申请护照）或研究家族史。

近日，美国司法部门对两名罗马尼亚黑客BogdanNicolescu和Radu Miclaus进行了审判。这两名黑客利用多种手段感染了40万台计算机，并获取了数百万美元的收益，分别被判处20年和18年监禁。据了解，两人于2007年创建了一个名为Bayrob Group的黑客组织，并开发出了相关恶意软件。

  

此类恶意软件主要通过钓鱼邮件传播，可用于收集受害者个人数据、信用卡信息、用户名和密码，并禁用了受害者的恶意软件保护工具。之后，该恶意软件还会利用受害者的邮箱继续进行传播。此外，二人还在合法网站注入虚假页面、冒充合法广告代理商，以窃取受害者登录凭证、植入勒索软件。

## DNS是网络安全运营的重要信号。企业利用DNS查看和控制网络中发生的事情。使用DNS数据，可以检测DNS隧道或受感染主机与命令和控制服务器（C＆C）之间的通信等行为。但是，专家发现，DoH可以掩盖DNS安全工具。使用DoH，DNS流量无法与其他HTTPS流量区分开。  

 

以前可用的基于DNS的监视和策略控制可访问的数据现在仅通过加密的端口443传递。恶意软件作者已经在利用这种新的盲目性。此外，运行拆分DNS实施的企业可能会发现为DoH设置的应用程序将无法解析内部名称。在某些情况下，这可能会破坏对依赖那些名称的服务的访问。同时，使用拆分DNS的企业还将内部域名发送到集中式公共DoH服务器，从而泄漏内部域名。

据外媒The Verge报道，Facebook高管对美国司法部长威廉·巴尔（William Barr）表示，在周二参议院就加密问题进行听证会之前，该公司不会向执法部门提供对其加密消息产品的调查访问。

  

在一封信中，WhatsApp和Messenger负责人分别表示，不良行为者可能出于恶意目的利用任何“后门”访问Facebook为执法而创建的产品。因此，Facebook拒绝了使其产品更易于使用的请求。今年早些时候，Facebook首席执行官马克·扎克伯格（Mark Zuckerberg）宣布，该公司将大力发展端到端的加密消息服务。它的三个消息传递产品（Instagram，WhatsApp和Messenger）的底层基础结构将被捆绑在一起并变得更加私密。

  

司法部就这一隐私声明与Facebook发生了争执，暗示该公司的计划将使罪犯受益。Facebook和其他大型科技公司在针对涉及数据隐私和内容审查的更广泛的监管威胁时，一再对外国政府做出类似拒绝的声明。

近日，Unit 42的安全研究人员观察到了一个新的分发活动，该活动通过网络钓鱼电子邮件进行发送，其主题通常为工资单或年度奖金。据悉，攻击者使用的是Trickbot的最新版本中一个名为TrickBooster的垃圾邮件发送组件，该组件从受Trickbot感染的计算机发送垃圾邮件。它还能够利用服务器消息块（SMB）漏洞传播到同一网络上的其他系统。

 

此活动可使用合法服务，例如SendGrid和GSuite来掩盖恶意活动。研究人员建议组织防止在端点上下载或执行未知可执行文件。

近日，有关人员调查发现，勒索软件威胁和恶意软件越来越活跃，并且越来越危险。从2019年1月到9月，发生了超过72亿次病毒攻击。此外，还发现了1.519亿勒索软件犯罪。调查结果显示，物联网恶意软件已达2500万，增长了33％ 、加密攻击上升到58％ 、Web应用程序威胁正在增加，去年同期增长了37％恶意软件威胁达到72亿 、勒索软件威胁达到1.519亿 、14％的恶意软件威胁来自非标准网关。
