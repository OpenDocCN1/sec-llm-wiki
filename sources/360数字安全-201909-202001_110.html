受美国制裁影响，伊朗于本月15日宣布实施汽油配给并上调汽油价格，该措施宣布后在伊朗100多个城镇引发抗议游行。面对全国性抗议游行，伊朗选择断掉全国互联网络。自抗议爆发以来，伊朗政府已实施五天断网。

网络才恢复的伊朗，就有一个活跃的伊朗黑客组织宣布将攻击重心转向了电力公司、制造业和炼油厂广泛使用的工业控制系统。该黑客组织被称为 APT33 aka Holmium、Refined Kitten 或 Elfin。

微软研究人员报告过去两个月 APT33 的密码破解攻击集中瞄准了工控设备的制造商、供应商和维修服务商。黑客的动机尚不清楚，研究人员猜测是为发动具有物理破坏效应的攻击获取立足点。

 


赛门铁克研究人员近期发现神秘黑客组织SowBug正肆意分发一款新型恶意软件“Felismus”，意在窃取阿根廷、巴西、厄瓜多尔、秘鲁与马来西亚等多国政府机构的外交机密。


调查显示，黑客组织SowBug至少从2015年开始活动，其主要瞄准南美、东南亚地区的多个国家机构进行一系列针对性攻击活动。此外，研究人员发现该组织资源充足，能够同时渗透多家系统并在目标机构的工作时间外运作。相关证据表明，该攻击者主要使用一款黑客工具 Starloader 通过 Windows 或 Adobe Reader 更新时在受害者的网络中部署恶意软件。
 




Kyhigh Networks的研究人员警告，允许公共写入权限（Write Access）的马逊S3存储桶会导致恶意第三方发起中间人攻击（MiTM Attack）。

配置错误的S3存储桶导致过多起数据泄露事件，美国国防承包商博思艾伦汉密  尔顿控股公司（Booz Allen Hamilton）6万个文件遭遇泄露，其中包括员工  访问美国政府系统的安全证书和密码。Verizon合作伙伴泄露超过1400万 Verizon客户的个人记录，包括姓名、地址、账户详细信息，还有一些受害者的 账号PIN。




ApacheSolr 是一个用Java编写的高度可靠，可扩展且容错的开源搜索引擎。可提供分布式索引，复制和负载平衡查询，自动故障转移和恢复，集中式配置等。

安全公告称，此问题最初被命名为“solr.in.sh含有未注释行”，并告诉用户检查其  solr.in.sh 文件。后来由于远程执行代码的风险，他们升级了此漏洞并取得了CVE编号。

该漏洞影响 ApacheSolr 在 Linux 系统上的8.1.1和8.2.0版本（不影响Windows），这些版本的 sol.in.sh 文件中的ENABLE_REMOTE_JMX_OPTS 配置不安全。虽然专家们目前还没有探测到在野利用攻击，不过他们认为这只是时间问题。



外媒近日曝光了Facebook的一款内部应用程序，该应用程序允许Facebook员工对其同事进行面部识别。应用程序目前已经停用并且从未公开发布过，但Facebook拥有这样的应用程序可能已经足以再次发出危险信号。

隐私权倡导者担心Facebook拥有这样的应用程序会给用户隐私带来重大风险。Facebook一直对实时或通过照片的人脸识别技术感兴趣。实际上，它一直在使用面部识别功能来标记用户上传到Facebook的照片。

Facebook承认该应用程序的存在，但明确了两点。首先是它是一款内部应用程序，自2016年以来已停止使用，并且从未向公众发布过。其次，它仅用于Facebook员工在其同事上使用。





一个网络犯罪组织正在将运行易受攻击的 Webmin 应用程序（Linux 系统的基于 Web 的远程管理应用程序）的 Linux 服务器组建成一个新的僵尸网络，安全研究人员目前正在使用 Roboto 的名称对其进行跟踪。僵尸网络的出现可追溯到今年夏天，这与披露了一个在超过 215,000 台服务器上安装的 Web 应用程序中的一个重大安全漏洞的披露有关。


在近日发布的一份报告中，中国网络安全供应商奇虎 360 的 Netlab 团队表示，这些早期攻击者之一是他们目前以 Roboto 的名义跟踪的新僵尸网络。在过去的三个月中，该僵尸网络一直以 Webmin服务器为目标。由于该安全漏洞易于利用，并且存在大量易受攻击的系统，在漏洞披露后数天攻击者就开始对安装了Webmin的服务器进行攻击。



北京时间11月22日，Google发布最新安全公告，公开致谢360 Alpha Lab首个发现并提交关于攻破Pixel手机的“梯云纵”漏洞链报告，以及向360Alpha Lab负责人龚广颁发总金额为201,337美元的漏洞奖励。
 
此次挖掘出“梯云纵”漏洞的幕后功臣，正是360安全大脑中安全专家云下的360 Alpha Lab。始终奋战在挖洞第一线的360 Alpha Lab发现 “梯云纵”组合漏洞，并再一次刷新Google史上最高漏洞奖金纪录。

大安全时代，“漏洞”关乎着企业自身的安全、品牌以及用户的利益，一旦漏洞被不法分子发现利用，后果严重。360安全团队，凭借着其过硬的实力，守护网络安全，帮助各大企业厂商完善系统安全，为广大用户提供一个安全的网络环境。



俄罗斯男子StanislavVitaliyevich Lisov因使用名为Neverquest的特洛伊木马从银行账户窃取钱款而在美国纽约南区被判处4年徒刑，并被勒令没收5万美元且要支付近一百万美元的赔偿。

据检方称， Lisov创建并管理了一个NeverQuest僵尸网络，并盗取了数百万张证件。该恶意软件旨在监视受感染的计算机，以尝试登录在线银行帐户。当受害者登录时，恶意软件会窃取其用户名和密码。Lisov于2017年1月在西班牙被捕，一年后他被引渡到美国。近日，他对有关使用恶意软件获取银行凭证和从银行帐户中窃取资金的指控认罪。 涉及Neverquest 木马的攻击在Lisov被捕后已全部停止。



Cybersecurity Ventures 最近的一份报告预测，到2021年全世界将有大约350万个网络安全职位空缺。在2017年至2018年期间，对网络安全专业人员的需求增长了7％。自2016年以来，该行业的失业率一直保持在0％。

这是一个利润丰厚，稳定且非常有价值的行业，随着网络犯罪分子不断使用更先进的策略渗透企业，其重要性将也变得越来越重要。如今，黑客们使用的攻击手段正在为AI武器化，以增加攻击的频率和有效性，这导致对网络安全专家的需求量增加。其中首席软件安全工程师、云支持工程师、信息安全总监、网络安全工程师、渗透测试员、应用安全工程师和首席信息安全官等职位，年薪都已超过100,000美元。




俄亥俄州男子 JamesRobinson 因针对俄亥俄州阿克伦市和阿克伦警察局网站的一系列DDoS攻击而被判处六年徒刑。被捕后，其对所有指控均表示认罪。其中大多数指控都易于证明，因为罗宾逊已公开在Twitter上记录了发生的所有攻击事件。

此外，罗宾逊还被发现在Twitter上通过用户名“AkronPhoenix420”与匿名黑客团体保持联系。其目标有国防部、国立卫生研究院、财政部和北约等的网站。这些攻击大多未造成大规模中断，Robinson最频繁袭击的主要目标是他家乡俄亥俄州阿克伦市的警察局网站“akronohio.gov”。

在被捕后的审讯中，罗宾逊告诉调查人员，他恨这座城市的警察。他经常在其上传到Twitter的视频中指责Akron的警察腐败、窃取嫌疑犯的毒品并对性工作者进行勒索和侵犯。两家提供DDoS缓解服务的网络安全公司表示，直到他被捕，他们才知道他的活动。认罪后，Robinson被判入狱六年，还被勒令向阿克伦市官员赔偿668,684美元。



近日，安全研究团队MalwareHunterTeam表示，发现了一个新的特洛伊木马程序SectopRAT。该木马可用于控制受感染计算机上的浏览器会话、更改浏览器配置，以及禁用安全措施。 

该恶意程序主要由C#编译，包含一个RemoteClient.Config类，其中有四个可供配置的值：IP、retip、filename和mutexName。尽管该程序中存在一些明显的缺陷，但程序中所涉及的技术都表明攻击者具有专业技术水平，专家怀疑，该木马可能只是一个测试产品。
