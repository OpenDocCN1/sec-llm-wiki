# 360网络安全大学助力武职落地全国首家信创学院

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTg0MDQ4Nw==&mid=2247493382&idx=1&sn=013e0335bfce7243bbc78fe3615a2504&chksm=9f8c770ea8fbfe18e918f23e2d5dd3f787598588bb9b17ec006b0603dd794557e3a246d11666&scene=126&sessionid=1681364911#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247493382&idx=1&sn=013e0335bfce7243bbc78fe3615a2504&chksm=9f8c770ea8fbfe18e918f23e2d5dd3f787598588bb9b17ec006b0603dd794557e3a246d11666&scene=126&sessionid=1681364911#rd)

2020年8月28日下午，全国首家信创学院在武汉职业技术学院成立揭牌。

  

![](../Images/a94c41817101ae66dc897967429258d6.png)

揭牌暨签约仪式现场

  

湖北省经济和信息化厅软件和信息服务业处处长董爱军、湖北省教育厅职业教育与成人教育处副处长余弢、武汉市经济和信息化局总工程师明文龙等多位领导受邀出席活动。

  

**360网络安全大学、湖北长城计算机系统有限公司、武汉达梦数据库有限公司、武汉蓝星科技股份有限公司、麒麟软件有限公司等多家信创企业代表参与共建信创学院签约揭牌仪式。360网络安全大学总经理姜思红、产教合作创新发展中心总监吕沐阳出席本次签约揭牌仪式。**

  

![](../Images/5e1232c2362080006b671e88ebc339f4.png)

领导和嘉宾现场启动手印

为武汉职业技术学院信创学院揭牌

  

![](../Images/38f30b33dc5dadacd8b45a7ac20e098b.png)

北京鸿腾智能科技有限公司

与武汉职业技术学院签约共建信创学院

  

当前，我国信息技术应用创新体系建设处于落地关键期，发展信息技术应用创新产业，是实现我国IT产业发展的内在需求，也是保障网络安全的必要手段。武汉职业技术学院信创学院的成立，是对信创产业发展在人才储备上的有力支撑。

  

**360网络安全大学作为共建信创学院的企业代表，结合企业自身在信创领域多年积累的安全输出能力与技术沉淀，整合公司内部产业经验，在教育领域形成体系化人才培养解决方案，充分发挥企业在产业端与资源整合上的优势，投入优质资源，深度参与全国首家信创学院的建设，携手武汉职业技术学院共同为国家信创产业发展，信创人才培养做贡献。**

  

![](../Images/d621fcb506c7fc7850110bbbf299c8a1.png)

  

武汉职业技术学院作为我国高职教育知名院校，360网络安全大学与武汉职业技术学院积极探索产教融合，校企合作新模式。

  

现阶段双方在网络安全人才培养合作上已初见成效。通过在“1+X网络安全评估职业技能等级证书”、360网络安全职业技能认证等项目的合作，引入企业人才培养标准与教育资源，建立一个有效激发校企双方的创新动力、创新活力、创新潜力，实现协同创新的新模式和新机制，以信息技术应用创新产业发展的新趋势、新需求为导向，共同培养信创产业急需的高素质创新型人才。

  

**同时，通过“共建360网络安全大学联合实验室”、“共建360网络安全大学实训基地”等项目的合作落地，双方共同开展社会培训、安全科普教育等工作，更好的服务和融入国家、湖北“一芯两带三区”区域和产业发展战略布局。**

  

武汉职业技术学院信创学院的成立，也将是校企双方在深度产教融合上的再次升华，对《国家职业教育改革实施方案》的积极践行与探索。

  

在未来的合作中360网络安全大学也将继续加大投入，与武汉职业技术学院在更多内容、更多领域落地合作，双方一同为国家培养高质量职业技能人才而努力。
