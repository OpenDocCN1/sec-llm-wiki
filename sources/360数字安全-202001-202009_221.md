# 快报⁹⁵丨超50万个Zoom帐号在暗网低价出售

疫情让视频聊天应用Zoom迅速成为了新宠，但也成为了黑客攻击的新目标。援引外媒报道有超过50万个Zoom账户在暗网和黑客论坛上出售，单价不到一便士，有些甚至还可以免费赠送。

  

这些帐号都是通过凭证填充（credential stuffing）方式攻击获取的，黑客试图利用旧有数据泄露的账户登录到Zoom。成功登录的账号被汇编成名单，卖给其他黑客。

  

而部分Zoom帐号在黑客论坛上免费提供，以便黑客可以利用这些账户进行zoom-bombing恶作剧和恶意活动。而另一些则是以单价不到一分钱的价格出售。根据网络安全情报公司Cyble与BleepingComputer分享的信息，黑客们提供这些免费账户是为了在黑客社区中获得更多的声誉。

近日，据外媒报道：Eftpos希望进入澳大利亚的数字身份体系中，并宣布其解决方案将很快进入测试阶段。在与17家澳大利亚企业完成了数字身份解决方案的概念验证后，这家支付公司表示，它正在与业界合作，打造对经济和社会具有重大优势的产品。

  

尽管澳大利亚政府有自己的数字身份认证解决方案，但Eftpos表示，其解决方案可以提供更顺畅、更快、更安全的入职体验，包括政府服务。Eftpos表示，在适当的政府支持下，其解决方案可以在很短的时间内激活，并为金融科技界带来重大利益。

近日，据外媒报道：Sodinokibi Ransomware背后的团伙已开始接受Monero加密货币而不是比特币，这使执法机构更难以进行调查。利用Tor的匿名网络进行Monero付款，使得追踪资金和试图去匿名化运动背后的威胁行动者变得不可能。由于CryptoNote应用层协议和协议中实现的混淆，Monero加密货币方案中的任何事务都是匿名的。

  

Sodinokibi团队宣布，他们将不再支持比特币支付。为了阻止比特币的使用，他们将比特币的赎金提高了10%。Sodinokibi的经营者也为那些愿意帮助受害者支付赎金的公司提供折扣。在很多情况下，勒索软件的受害者会付钱给公司，让它们帮助他们恢复数据，还会联系勒索软件团伙，支付费用。

热门短视频应用 TikTok 近日被发现存在一个较大的安全隐患，由于部分资源内容未启用安全的 HTTPS 加密连接，导致其容易被黑客攻击而篡改。开发者 Talal Haj Baktry 和 Tommy Mysk 以近期流行的新冠病毒资讯类视频为例，对 TikTok 默认通过 HTTP 连接的资源进行了拦截追踪和篡改攻击。

  

三月份的时候，专注于研究热门 App 中漏洞的两人，发现了一个能够用于窥探 iOS 用户剪贴板中内容的 bug 。现在，Baktry 和 Mysk 又揭示了月用户 8 亿的热门短视频应用 TikTok 中的一个安全隐患 —— 即便是最新的版本，其仍在通过未加密的 HTTP 连接，来获取 CDN 上的资源。这意味着 Android / iOS 客户端的 TikTok 用户的观看历史记录易受拦截，甚至为更隐蔽的中间人攻击（MITM）敞开了大门。

  

研究人员警告称，攻击者甚至可以通过入侵本地网络，将客户端上的视频替换成任何虚假的信息。

近日，据外媒报道：一名网络犯罪分子正在出售美国境内141万名医生的个人和联系方式。对于大流行期间忙于挽救生命的医生和医护人员而言，这可能会成为灾难。数据库于2020年4月11日从在线服务qa.findadoctor.com被盗，利用该服务人们可以搜索医疗保健专业人员，即时预约并在线咨询医生。

  

出售的记录包括详细信息，例如全名，性别，医院名称，位置，邮寄地址，诊所地址，国家/地区，电话号码，许可证号等等。网络罪犯可以利用可用的电话号码进行网络钓鱼攻击，如发送带有网络钓鱼链接的文本消息来窃取财务数据。

近日，据外媒报道：Quidd是一个用于交易贴纸，卡片，玩具和其他收藏品的在线市场，该市似乎在2019年遭受数据泄露，现在大约有400万用户的详细信息正在地下黑客论坛上免费共享。

  

Quidd信息已经在高层团体之间秘密交易了几个月，并且至少从2019年10月和2019年12月开始分别在黑客论坛和Pastebin上发布有关Quidd信息的广告。Quidd尚未披露任何最近的安全事件，目前尚不清楚该公司是否知道该违规行为。所幸泄露的密码不是明文格式的，而是用bcrypt哈希算法加密的。经确认，泄露的信息为真实。

近日，据外媒报道：谷歌和苹果公司最近宣布了一个联合项目，旨在开发用于移动设备的冠状病毒“接触者追踪”工具。在包括韩国，新加坡，以色列和其他国家在内的多个国家，接触者追踪技术在遏制大流行中起着至关重要的作用。

  

两家公司计划设计一个内置的系统级平台，该平台使用蓝牙低功耗（BLE）信标来实现联系人跟踪技术。该项目与其他实时定位系统的不同之处在于，它没有利用跟踪用户位置或其他可用于识别特定移动用户的数据。根据设计人员的说法，它使用BLE信标确定被感染的个人是否在他人附近。

近日，据外媒报道：游戏控制器和其他配件的制造商SCUF Gaming发生数据泄露。该数据库共有110万条记录，完全向公众开放，其中包括敏感的详细信息，例如客户姓名，联系信息，付款信息和员工记录等。

  

得知消息后，公司立马采取了行动，但是数据库已经被恶意下载，并留下消息要求赎金。数据库中包含的所有客户数据都可能被滥用来发起社会工程攻击此外，员工数据可用于鱼叉网络钓鱼活动，从而最终获得对员工帐户的访问权限。此次事件完全是由于公司安全措施不足。
