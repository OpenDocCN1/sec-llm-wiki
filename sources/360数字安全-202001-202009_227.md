# 快报⁹³丨活久见？5G基站被焚毁竟因会传播病毒

前不久英国有部分人烧了三座5G基站，理由是5G基站会传播新冠病毒，这种反智的想法及行动受到了英国政府的抨击。对5G的攻击不只是这一个，荷兰最近也有4座5G基站被毁，理由是5G影响健康。

  

据外媒报道，上周荷兰发现了一起5G基站被焚烧的案件，近期已经出现了4起类似的案例，一些纵火犯甚至在电信塔上留下了反5G的口号。与英国人认为5G传播病毒类似，这些人反对的是5G影响人类健康，还会侵犯个人隐私。值得注意的是，荷兰目前还在试验5G，并没有正式商用5G。

  

在全球，网络通讯带来的辐射及其他健康问题都是个热点，很多人都在担心这个问题，不过总部位于德国的ICNIRP（防止非电离辐射国际委员会）此前已经宣布，5G不影响健康，这跟1998年制定的指南中的结论是一样的。

  

这种类似封建迷信的作法出现不免让人思考问题的原因，如今全球抗疫正在关键时期只有采取科学、理智的方法全人类才能共同迈向胜利。而伺机传谣破坏的不法分子最终只会得到法律的制裁。

近日，据外媒报道：经VPNpro研究人员发现并通知存在该漏洞后，Google已从Google Play商店中删除了一个Android VPN程序。该应用程序SuperVPN已被下载超过1亿次。为VPN产品提供审查和建议的公司VPNpro在2月就警告该产品中存在一个漏洞，该漏洞可能导致中间人（MITM）攻击，从而使入侵者能够将自己插入用户和VPN服务之间，该程序正在发送加密数据，但对解密密钥进行了硬编码，解密数据会显示有关SuperVPN服务器、证书和身份验证凭据的信息，这使攻击者可以迫使SuperVPN连接到假服务器，从而使他们能够查看用户的所有数据，包括密码，私人文本和语音消息。

  

VPNpro的研究人员Jan Youngren于2019年10月发现了此漏洞，该VPN开发人员SuperSoftTech未响应其通知。因此他通知了由HackerOne为Google运营的Google Play安全奖励计划（GPSRP），该团队也无法获得SuperSoftTech的回应，因此于2020年4月7日从Google Play商店中删除了该程序。

近日，据外媒报道：Box本周三（4月8日）宣布，它将在云内容管理平台的安全产品Box Shield在原有的通过基于分类的安全策略帮助用户防止数据泄漏，并且可以根据异常活动识别潜在的内部威胁或受感染的帐户的基础上，添加自动恶意软件检测监控功能。

  

在Box中发现恶意软件后，Box Shield将自动向最终用户发出警报，限制恶意文件的下载和共享，并通知IT和安全团队。新功能在本月底前可上线。

iOS 13时代的越狱变成了Checkra1n和Unc0ver“两虎相争”的局面，本周，Checkra1n（0.10.1 Beta）率先实现对iOS 13.4/13.4.1正式版的越狱支持。截止发稿，Unc0ver依然停留在iOS 13.3。两套工具各有优劣，Checkra1n仅提供了macOS和Linux客户端，无法在Windows或者iOS上操作，而且仅支持Cydia商店，但优点是相对稳定。Unc0ver则能直接在iOS上操作越狱过程，支持的设备也更多，缺点就是稳定性稍差。

  

当然，两者都是不完美越狱，一旦设备重启需要重新走一遍越狱流程。回到iOS 13.4上，堪称iOS 13的一次较为重大升级，新功能包括重构邮件APP工具栏、新的ANIMOJI表情、iCloud支持文件夹分享，实测现实，iPhone SE/7/8在内的老设备，开机速度、网页渲染性能也都有提升。

近日，据外媒报道：Tails 4.5 稳定版已发布，主要变化是新增了“安全启动”（Secure Boot）功能，修复安全问题和升级部分软件包。Tails ("The Amnesic Incognito Live System"的缩写) 是一个十分注重“隐私性”和“隐匿性”的 Linux 发行版，它衍生自 Debian，设计之初就是帮助用户匿名使用互联网，并最大限度保护个人隐私。

  

为达到此目标，Tails 使用了 Tor 网络，使得网络流量很难被追踪。Tails 还预装了一些应用，包括网页浏览器、IRC 客户端、邮件客户端、即时消息通信工具，它们都以安全为理念进行了预配置，并对网络流量进行了匿名性处理。因此通过 Tails 我们可以不留下任何痕迹“隐身”地使用互联网。

在本周发布的一份报告中，英国安全公司Sophos透露，有超过350万iOS用户安装了 “吸费软件”，这是一种相对较新的网络诈骗。这些应用大多以图像编辑器、二维码和条码扫描器、图像和视频过滤应用以及与星座和算命相关的东西的形式出现。

  

Sophos的恶意软件分析师Jagadeesh Chandraiah指出，"应用发布商也有能力通过发布新的盗版应用和订阅政策，或者通过改变应用在App Store中的资料，将之前免费的应用转化为盗版应用，尽管苹果开发者政策禁止这种行为。"避免上当受骗的最好方法是仔细检查描述页面和评论，同时养成每次卸载应用时都要检查账户是否有订阅的习惯。下面是Sophos发现的全部盗版软件应用列表：

Linux 内核现在已经增加了对 exFAT 的支持，同时它也没有放弃维护原有 FAT 文件系统驱动，甚至现在从邮件列表上看，FAT 性能方面可能会有大幅提升。开发 Tux3 文件系统而闻名的 OGAWA Hirofumi 在邮件列表中提到了目前 Linux FAT 文件系统的预读取处理有瑕疵：“FAT 条目的当前预读非常简单，但是有一些缺陷，因此在某些环境下效果不佳。这个补丁或多或少可以提高预读能力。”

  

OGAWA Hirofumi 测试结果表明，使用此补丁，在慢速 USB 连接的 2TB 硬盘上，此前需要 383 秒才能完成的传输测试现在只需 51 秒即可完成。

美国联邦上诉法院周四恢复了全国范围内的诉讼，其中有官司指控Facebook公司侵犯了用户的隐私权，具体表现在即使在用户退出社交媒体网站后，也会追踪他们的网络活动。位于旧金山的美国第九巡回上诉法院表示，Facebook用户可以根据联邦和加州的隐私和窃听法提出多项索赔。

  

Facebook用户曾指责该公司在浏览器上悄悄地存储cookie，追踪他们何时访问含有 "喜欢 "按钮的外部网站，然后根据他们的浏览记录向广告商出售个人档案。并引用了Facebook的数据使用政策，称原告们 "有理有据地声称，Facebook设定了不收集已登录的用户数据的期望，但无论如何也都会收集这些数据"。
