# 快报⁸⁸丨“世界最安全的在线备份”提供商遭数据泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTg0MDQ4Nw==&mid=2247489018&idx=3&sn=129bec6746efab360b8773494cd731ed&chksm=9f8f85f2a8f80ce474825689d8dc4a0d9483a6b55c642fe3039b2f1cdcd15cf50d895e672fad&scene=126&sessionid=1681364962#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247489018&idx=3&sn=129bec6746efab360b8773494cd731ed&chksm=9f8f85f2a8f80ce474825689d8dc4a0d9483a6b55c642fe3039b2f1cdcd15cf50d895e672fad&scene=126&sessionid=1681364962#rd)

据外媒报道，一家号称“世界最安全的在线备份”云备份服务提供商SOS Online Backup（以下简称SOS）的客户数据遭泄露。总部设在加利福利亚的SOS在全球各大洲都建有数据中心，名符其实的行业巨头。据研究团队vpnMentor的发现，由于ES数据库配置错误，SOS大约暴露了1.35亿的客户信息记录在网上，其中有70GB是相关客户账户元数据信息，包括架构、参数、描述和管理元数据，覆盖SOS云服务的方方面面。  
此次事件并非是首次“安全的云备份”公司数据泄露，前不久加拿大的云备份提供商Data Deposit Box也有此遭遇，用户上传的27万份个人文档被泄露。Gartner近期的一份调查显示，到2025年，99%的云安全问题将会是客户本身的问题，配置错误将会持续成为所有组织数据泄露的首要原因。  
![](../Images/f908302ca01b02a883dab8272fc577fb.png)  
![](../Images/cbaf3e257c8d66e56e2cc0d5606d7b23.png)![](../Images/b7ddd8704438d3ac7cb894863fbd56ce.png)  
3 月 25 日，IPv6 倡导者 Jun Murai 宣布，他将出售超过 1400 万个 IPv4 地址，所有收益将以信托基金的方式，用于提升亚太地区的互联网服务，进一步填补甚至消除全球性的数字鸿沟。  
由于此类 32 位网络地址的严重短缺，其市场价值非常巨大。目前，每个 IPv4 地址的价格在 20 美元至 30 美元之间。而 Murai 的地址块中有大约 1470 万个地址，目前的价值在 2.94 亿美元至 4.41亿 美元之间。据估计，此次出售预计可以获得 3 亿美元左右的资金。  
一次性出售如此大量的未使用地址前所未闻。除了谷歌、Facebook 等巨头之外，有线通信领域的巨头、跨国移动运营商等也非常需要这些地址。届时，巨头们之间可能会有一场激烈的竞争。  
最近，由于冠状病毒大流行的影响，互联网访问受限、访问速度缓慢地区的人们受到了更大的影响。如果 IPv4 地址空间中的最后一个大块收益可以帮助取代 IPv6，缩小数字鸿沟，并增强互联网的整体安全性，那么毫无疑问，它将被视为一种成功。  
![](../Images/56406460be0f44147c1d95db1ddd321a.png)  
![](../Images/c0805f1d67fa6b50cadccd9d489de924.png)![](../Images/7474aa448eddebd1d172e52bff7e589f.png)  
Mozilla 紧急发布了 Firefox 74.0.1 和 Firefox ESR 68.6.1 版本，针对其内存空间管理方式中存在的两个错误进行了修复。两项漏洞分别为 CVE-2020-6819 和 CVE-2020-6820，均被评级为”严重“。这类 ”user-after-free“ 漏洞使黑客可以将代码放入 Firefox 的内存中，并在浏览器的上下文中执行代码。  
  
显然目前官方优先专注于发布补丁，之后才会进一步展开调查。建议所有 Firefox 用户尽快更新修复。这已经是 Mozilla 今年第二次在 Firefox 中进行 0day 漏洞修复。一月份，随着 Firefox v72.0.1 的发布，它修复过另一个错误，该漏洞曾使中国和日本的用户受到攻击。  
![](../Images/75344ad823953a96a15a65fe414d226d.png)  
![](../Images/58c7da01d982ad9dfc32230dc5882274.png)![](../Images/42121b3e8d9efac9cd4a8c5da42d2c24.png)  
4月2日，Twitter 官方博客称，Mozilla Firefox 储存缓存的方式可能导致用户的非公开信息储存在浏览器的缓存里，这意味着如果你用 Mozilla Firefox 在公用或共享计算机上访问 Twitter，采取行动如下载存档或发送接收私信，那么你登出之后这些信息可能会仍然储存在浏览器的缓存里。  
  
Firefox 的启发式缓存会缓存内容七天。Twitter 没有给私信的缓存加入 no-store 指令。这个问题之所以没有在其它浏览器上重现是因为当 Content-Disposition 出现的情况下这些浏览器会禁用启发式缓存。而在 Firefox 上，Content-Disposition 存在的情况下没有禁用启发式缓存。问题看起来是 Twitter 没有在   Firefox 上测试其网站的缓存行为。这其实是一种非常普遍的现象。    
![](../Images/c881028a3dfcd95425688949fdb0d798.png)  
![](../Images/4ef9a7e6de69024e098a23ded3b3365f.png)![](../Images/5da3b0ebbb7d3b916f65340b7a60a415.png)  
因新冠疫情，Zoom 被数以百万计的人用于举行远程会议。但其安全性也日益引起关注。加拿大多伦多大学公民实验室的研究人员对软件进行了逆向工程，发现该公司在加密方案上有虚假宣传。Zoom 称其会议使用 AES-256 加密，但实际上只在 ECB 模式下使用了简单的 AES-128 密钥，密钥由 Zoom 的服务器产生，  
在某些情况下密钥由来自中国的服务器产生。它还声称使用端对端加密，但事实上距离真正的端对端加密还比较遥远，该公司对端对端加密的定义与通常的定义有差距。  
![](../Images/5a66094fb0f9bd78afdb05bcdd4ccb8c.png)  
![](../Images/6d2a746cc523248768e9888d59c9229e.png)![](../Images/e617daf44b4b6515f560e54766e71d55.png)  
Chrome 工程总监 Justin Schuh 在 Chromium Blog 发文宣布暂时回滚 SameSite Cookie 功能，以确保新冠病毒疫情期间网站的稳定性。  
  
在这种策略支持下，用户可禁用第三方 cookie。但同时，禁用第三方 cookie 可能会导致某些站点崩溃。为此，谷歌表示，”我们希望确保提供基本服务的网站的稳定性，这些服务包括银行、在线食品杂货、政府服务和医疗保健，它们能够在这段时间内改善我们的日常生活。  
![](../Images/cca7e994206bd761884d616228e36dd6.png)  
![](../Images/cb2480cc3bf734f2ebfec5f3025bdce8.png)![](../Images/8d657346e068e9fe2bf0272f71ce3339.png)  
据《福布斯》报道，苹果向黑客支付了75000美元，以识别其软件中的多个零日漏洞，其中一些漏洞可用于劫持MacBook或iPhone上的相机。零日漏洞是指软件开发人员和公众所不知道的软件安全漏洞，而悄悄利用它的攻击者可能已经知道了这些漏洞。  
  
据报道，安全研究员瑞安·皮克伦（Ryan Pickren）在决定用“模糊的角落案例敲打浏览器”直到它开始显示怪异行为后，才发现了Safari中的漏洞。该漏洞猎人共发现了7个漏洞。这些漏洞涉及Safari解析统一资源标识符、管理web源和初始化安全上下文的方式，其中三个漏洞可以用来诱骗用户访问恶意网站，使攻击者能够访问摄像头。  
![](../Images/599e0427ea796ea7a549adaa12813076.png)  
![](../Images/f36d27d114c0f5f65433df20bf90b954.png)![](../Images/aad327eec04e8de7d54f5b5eafce12f5.png)  
近日，据外媒报道：至少有19个网站成为新数据收集器的受害者，该数据收集器似乎由威胁组织Magecart Group 7开发。这种新型的数据分离器已经被发现了几种不同的版本。研究人员于1月24日首次发现了这种数据收集器，并将其称为“ MakeFrame”。从那以后，MakeFrame被发现承载了收集代码，将数据收集器加载到其他受攻击的网站，并窃取数据。  
  
RiskIQ已经确定了三种不同版本的收集器，它们具有不同的混淆级别，从清晰的JS代码到加密的混淆。其中一些似乎是运行调试过程的开发人员版本，其中一个甚至包含版本号。MakeFrame的多个版本证明了攻击者不断寻找新的方法，从更多的受害者中窃取。
