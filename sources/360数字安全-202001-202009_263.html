黑客集团通常喜欢使用各种漏洞来向目标企业发动攻击，但基于软件层面的安全漏洞并不是总能够有效进行利用。某电商客户回馈送你个优盘你要不要？百思买是国外比较流行的电商购物网站与国内某东和某宝类似。黑客集团的套路是这样的：以百思买的名义向目标企业寄送实体包裹，包裹内含有优盘和所谓的忠诚客户礼品卡。


多数企业员工收到这样的包裹都以为真的是百思买发的客户回馈，因此这些员工美滋滋的收获优盘自己拿起来用。当然这种社会工程学手段也真的很难被人轻易识别，即便是有安全基础的用户遇到这种好事可能都无法及时分辨。


黑客集团寄送的这些优盘实际上是经过定制开发的，当这种数据线形状的键盘连接电脑后便可激活输入法，而黑客在固件里内置自动键盘输入悄悄执行某些恶意命令。总有人会以为天上掉馅饼美滋滋的使用。企业管理员最好的办法是及时对企业员工展开安全培训，避免将来历不明的外接设备连接任何电脑。




基于Chromium的Edge新版在设置中提供了一个选项，允许用户在关闭浏览器的时候清除浏览数据，用户可以对浏览历史、下载历史、Cookies、其他网站数据和自动表单填写数据进行选择。


如果你已经配置在关闭浏览器之后自动删除Cookies（也就是在关闭之后登出大部分网站），那么在重新打开浏览器的时候就需要重新登录凭证。为了避免这种情况，在Edge Canary 83版本在Cookies和网站数据栏目下方新增了新选项，在edge://settings/clearBrowsingDataOnClose页面能够保留用户指定的网站cookies。


最新上线的Do not clear选项通知用户“您已允许以下网站在您的设备上保存和读取Cookie。当您退出浏览器时，不会清除这些网站的Cookie”。现在当你关闭浏览器之后，就会清除白名单之外的Cookies。




知名浏览器 Firefox 开发商 Mozilla，刚刚发起了一项旨在“修正互联网”的分布式 Web 3.0 新活动。感兴趣的程序员、创作者和其它普通人，都可以通过加入“春季 MVP 实验室”（Fix-The-Internet Spring MVP Lab）来帮助改进技术，共同构建和测试新产品。


Mozilla 在声明中写道：通过为充满活力的实验创作者社区引入挑战赛的形式，其希望这项活动有助于找到修复互联网的几个重要议题的可持续解决方案和新点子。


Mozilla 指出，本次活动的几个重要议题，包括与错误信息、虚假新闻和滥用数据收集作斗争，人工智能、社交网络概念等。




近日，据外媒报道：根据报告，专家发现，新的虚假“ Zoom”域和恶意“ Zoom”可执行文件的注册数量大大增加。研究人员发现，自冠状病毒爆发以来，已经注册了1,700多个新的“ Zoom”域，其中25％的域名是在上周注册的。专家们还发现恶意文件的名字都改成了“zoom-us-zoom_ # # # # # # # # # #.exe”和“Microsoft-teams_V #μ# D_ # # # # # # # # # #.exe”(#表示不同的数字)。


该文件充当InstallCore PUA的滴管，可能会传递其他恶意有效负载。在此期间，由于冠状病毒的流行，骗子们还瞄准了其他被广泛使用的应用，比如谷歌教室。攻击者注册了像googloclassroom[.]com和googieclassroom [.]com传送恶意软件。




上周六，某黑客论坛公布了包含 493 万 4863 乔治亚州居民的详细个人信息的数据库。在大小为 1.04 GB 的 Microsoft Access 数据库文件中，可查看到包括全名、家庭住址、出生日期、身份证编号、手机号码之类的隐私内容。


周末的时候，数据泄露监视和预防服务公司 Under The Breach 曝光了本次泄漏事件，并向外媒 ZDNet 分享了一些细节。由快照可知，数据库包含了超过 490 万条记录，其中包含了数百万已故公民。根据 2019 年的人口普查，该州目前预估人口在 370 万左右。


目前尚不清楚黑客论坛中有多少访客已获取该数据库，数据泄露的源头也仍然是个谜。在周日的报道中，ZDNet 认为可能源自该州的中央选举委员会（CEC）。然而在周一的一份声明中，该委员会已予以否认，因其通常并不会收集如此详尽的个人信息。黑客论坛，其拒绝在致 ZDNet 的一份声明中透露他们是从何处获得数据的，但已排除了 CEC 的嫌疑。目前当地有关部门正在对此事展开深入的调查。




一家美国法院下令对两家电信运营商下达禁令，这两家运营商曾促成数亿次欺诈性的骚扰电话。这种诈骗主要针对老年人和弱势群体，骗取受害者的个人信息、金钱和财产。许多电话都是海外骗子冒充政府机构发出的。


两项禁令涉及两项独立的民事诉讼，是美国司法部首次获得这类禁令。这两项命令都是由美国纽约东区地方法院发布，两项民事诉讼仍在审理中。法院指出，尽管Palumbos已经被警告了100多次有关通过他们的网络传输欺诈性电话的具体事例，但他们从未切断与任何与欺诈性电话流量有关的实体的业务关系。




近日，据外媒报道：新南威尔士州警察部队已与身份解决方案公司Idemia重新签署了一项生物识别技术的合同。新合同为期六年，Idemia将支持和维护部队的扫描，该扫描将处理和记录罪犯的生物特征数据。


该协议涉及新南威尔士州的142个派出所。Idemia表示，其扫描技术为执法人员提供了应用程序，可以捕获罪犯的生物特征信息和人口统计信息。Idemia在180个国家/地区拥有客户。除新南威尔士州外，生物扫描还用于昆士兰州，维多利亚州和北领地。




近日，据外媒报道：英国信息专员办公室（ICO）已向政府提供建议，可以在对抗冠状病毒的过程中使用匿名手机数据。副专员互联网上表示：“通用位置数据趋势分析正在帮助解决冠状病毒危机。


在对这些数据进行适当匿名和汇总的情况下，由于未发现任何个人，因此不属于数据保护法之列。在这种情况下，只要采取了适当的保护措施，就不会违反隐私法。隐私国际组织在ICO公告之前发布的帖子中建议，对此类数据的任何使用都必须受到特别保护，并指出在某些情况下可以对数据进行匿名处理。
