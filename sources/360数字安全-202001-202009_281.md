# 快报⁸⁰丨特斯拉中央触摸屏暴露于DoS攻击

近日，据外媒报道：仅仅通过让目标用户访问特制网站，黑客就可能导致特斯拉Model 3的中央触摸屏无法使用。研究人员发现，Tesla Model 3的Web界面受到拒绝服务（DoS）漏洞的影响。该漏洞跟踪为CVE-2020-10558，属于“进程分离不当”，它可能导致中央显示器无响应。

  

攻击者可以从主屏幕上禁用车速表，Web浏览器，气候控制，转向信号，导航，自动驾驶仪通知和信号灯通知以及其他功能。要利用此漏洞，用户必须转到特制的网页。该网页将使基于谷歌的界面崩溃，并使整个Tesla Model 3界面崩溃。研究人员指出，尽管利用此漏洞导致中央显示器崩溃，但汽车仍可行驶。而且汽车熄火再打开后，显示器就会开始工作。据悉，特斯拉已经发布了对该漏洞进行修补的软件更新。

近日，据外媒报道：纽约州官员希望域名注册商加紧努力，以应对与冠状病毒相关的欺诈网站数量不断增加的问题。这些网站包括出售假药，假疫苗的网站，或伪装成冠状病毒相关应用程序的兜售恶意软件的网站。在过去的一个月中，每天都有成千上万的此类域名注册，并且数量在不断增加。

  

纽约州总检察长希望域名注册商部署以下一种或多种解决方案：1. 对所有新注册的冠状病毒相关域名使用自动审查和人工审查。2. 建立主管当局和公众举报与冠状病毒相关的欺诈网站的特殊渠道。3. 注销所有报告的域名。4. 部署系统以停止冠状病毒相关域的注册。5. 部署系统以阻止冠状病毒相关域的快速注册6. 更新服务条款以添加“针对非法使用冠状病毒域的积极执法”条款。

近日，据外媒报道：员工打开包含加密代码的电子邮件后，新墨西哥学区，大学和政府机构共同花费了数百万美元来重新获得对计算机系统的控制。最近一次袭击导致所有24所学校的计算机服务器，互联网，电话和电子邮件服务都被锁定。

  

技术人员在整个系统中清理并重新加载约8,000个单独的设备。原因可能是一台计算机在没有首先经过技术部门检查的情况下重新连接到网络，而且该计算机在去年7月的勒索软件攻击中已被感染。不过黑客对新墨西哥州勒索软件攻击仅是锁定类型，没有受害者报告数据或机密信息受到损害。

微软今天承认已经有黑客利用尚未公开的漏洞对所有尚处于支持状态的Windows设备发起了网络攻击，而且目前还没有针对该漏洞的安全补丁。在本周一发布的公告中，微软承认该漏洞属于“严重”（critical）级别，存在于Windows处理和渲染字体中。目前黑客已经利用该漏洞来诱骗用户打开恶意文档。一旦受害者打开文档（或者在Windows Preview中进行查看），攻击者就能在设备上安装诸如勒索软件在内的各种恶意程序。

  

微软表示目前正在研究新补丁，会尽快发布提供修复。虽然Windows 7系统也存在该漏洞，不过伴随着主流支持周期的结束，只有付费获得扩展支持的企业用户才能获得更新。此外该公告中还提供了临时解决方案，以便于受影响的Windows用户能缓解该漏洞的影响。

路透社报道称，随着新冠病毒引发的 COVID-19 疾病的全球大流行，世界卫生组织也在本月遭受了多倍的网络攻击。WHO 首席信息安全官 Flavio Aggio 表示：“黑客的身份尚不清楚，但他们本次并未得逞”。即便如此，安全专家还是将源头指向了某个被称作 DarHotel 的高级网络间谍黑客。  

  

Flavio 警告称：疫情爆发以来，冠状病毒已在全球范围内导致了超1.5 万人的死亡，同时针对抗击疫情的世界卫生组织及其合作机构的攻击企图也出现了激增。

据工业和信息化部3月24日消息，3月21日，针对媒体报道的新浪微博因用户查询接口被恶意调用导致App数据泄露问题，工业和信息化部网络安全管理局对新浪微博相关负责人进行了问询约谈，要求其按照《网络安全法》《电信和互联网用户个人信息保护规定》等法律法规要求，对照工信部等四部门制定的《App违法违规收集使用个人信息行为认定方法》，进一步采取有效措施，消除数据安全隐患：  

  

一是要尽快完善隐私政策，规范用户个人信息收集使用行为；二是要加强用户信息分类分级保护，强化用户查询接口风险控制等安全保护策略；三是要加强企业内部数据安全管理，定期及新业务上线前要开展数据安全合规性自评估，及时防范数据安全风险；四是要在发生重大数据安全事件时，及时告知用户并向主管部门报告。

  

新浪微博表示，公司高度重视数据安全和个人信息保护，针对此次事件已采取了升级接口安全策略等措施，后续将按照工信部要求，落实企业数据安全主体责任，切实做好用户个人信息保护工作。

近日，据外媒报道：研究人员分析了五种流行的商业密码管理器（LastPass、Dashlane、Keeper、1Password和RoboForm）并发现了四种漏洞，其中一种可能会导致凭证暴露。密码管理器是用于存储凭证和其他敏感信息的加密金库，它允许对个人使用的每个应用程序和在线服务使用强大的、唯一的凭证。这些被发现的漏洞中最重要的是，恶意应用程序可以冒充一个合法程序，诱使密码管理器暴露各自服务的存储凭证。  

  

这个问题影响了1Password和LastPass的Android应用程序，这两个应用程序都容易受到钓鱼攻击，因为它们使用了弱匹配标准来识别哪些存储的凭证适合自动填充。另一个漏洞是(1Password除外)，它们没有为复制到剪贴板的凭据提供足够的保护。另外，为了提高易用性，一些密码管理器允许用户使用4位密码来保护他们的保险库，但是RoboForm和Dashlane的Android应用程序并没有一个针对错误密码尝试次数的计数器。

据外媒报道，网络犯罪从不会休眠，而现在全世界都在关注着这种新冠病毒疫情，于是前者想着利用后者来为自己牟利。这一次则是一个叫做Corona Antivirus的假冒Windows杀毒软件。Malwarebytes和MalwareHunter在两个不同的网站都发现了这个假冒应用。  

  

![](../Images/48fa6b2867350d419294a297606d89fb.png)

  

该应用网站写道：“我们来自哈佛大学的科学家一直在研究一种特殊的AI开发技术，通过使用Windows应用来对抗这种（新冠）病毒。当应用运行时，你的电脑会主动保护你免受冠状病毒(Cov)的攻击。”

  

网站提供了一个被感染的安装器，据Malwarebytes披露，它不会在一台被攻击的机器上丢下BlackNET RAT，而设备则会自动添加到BlackNET僵尸网络中。

恶意软件感染自身具有一系列功能，包括作为僵尸网络的一部分发起DDOS攻击、截屏、窃取Firefox cookie等敏感信息、保存密码和比特币钱包以及运行一个键盘记录器来监控系统上的活动等。

  

Malwarebytes表示：“在此期间，在家和上网都要注意安全。我们在过去几周看到的诈骗数量表明，罪犯会利用任何情况。我们建议您随时更新您的计算机，并在下载新程序时格外小心。当心即时通知和其他消息，即使它们看起来像是来自朋友。”
