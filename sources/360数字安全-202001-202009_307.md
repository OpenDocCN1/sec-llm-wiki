# 快报⁷⁴丨数百万eBay和亚马逊消费者数据泄漏

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTg0MDQ4Nw==&mid=2247488547&idx=2&sn=437d2271a053141f4686548aafc7e500&chksm=9f8f842ba8f80d3d8ea601cc49cd599309ed4566451b31bb26bc18ba92b2243d10ab7b44b1b1&scene=126&sessionid=1681364972#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247488547&idx=2&sn=437d2271a053141f4686548aafc7e500&chksm=9f8f842ba8f80d3d8ea601cc49cd599309ed4566451b31bb26bc18ba92b2243d10ab7b44b1b1&scene=126&sessionid=1681364972#rd)

据外媒报道，有研究人员发现一个大型的数据库，其中包含存储在亚马逊网络(aws)数百万个欧洲客户记录，任何人使用搜索引擎都能查找到这些记录。泄露的数据库共涉及 800 万条记录，主要是通过亚马逊，eBay，Shopify，PayPal和Stripe在内的支付系统API收集到的。记录中的数据包括姓名、送货地址、电子邮件地址、电话号码、购买的物品、付款等信息。此外，还包括成千上万的Amazon Marketplace Web服务(MWS)查询、MWS身份验证令牌和AWS访问密钥ID。

  

由于一个客户可能会生成多个记录，所以无法估计有多少客户受到影响。据称大约有一半泄露记录的客户来自英国，其余的大部分都来自欧洲其他地方。根据Comparitech的数据，这可能与进行跨境增值税分析的第三方公司有关。亚马逊查询可用于查询MWS API，这可能使攻击者可以从销售数据库中请求记录。因此，它建议所涉及的公司应立即更改其密码和密钥。亚马逊已于 2 月 8 日向涉嫌关闭数据库的第三方公司开始调查该违规行为。

自由软件基金会（FSF）通过 2020 LibrePlanet 线上会议 宣布了 2019 年度的自由软件奖得主。社会公益项目奖授予了 Let's Encrypt 项目，此前获得该奖的项目包括了 OpenStreetMap 和 Public Lab。

  

Let's Encrypt 项目旨在让每一个网站都能启用加密。该项目执行总监 Josh Aas 表示，没有隐私就没有自由，随着 Web 日益成为人们生活的中心，确保百分之一百加密和尊重隐私对一个自由健康的社会至关重要。自由软件进步奖授予了 Jim Meyering，她是一位知名的自由软件程序员、维护者和作者。今年的奖项新增加了一个杰出新自由软件贡献者奖，授予了参与多个 GNOME 应用可用性测试的巴西学生 Clarissa Lima Borges。

据信，韩国学者发现了23个开源web应用程序、论坛、存储构建器和内容管理系统(cms)使用的文件上传机制中存在30个漏洞。在真实的web应用程序中，这些类型的漏洞允许黑客利用文件上传表单并将恶意文件植入服务器。这些文件可以用来执行网站上的代码，削弱现有的安全设置，或者充当后门，让黑客完全控制服务器。

  

所有的漏洞都是利用FUSE发现的，FUSE是一种新型自动渗透测试工具，用于发现PHP应用程序中的UFU(不受限制的文件上传)和UEFU(不受限制的可执行文件上传)漏洞。测试于2019年2月进行，报告中可能包含了在过去一年中收到更新的网络应用程序。但研究人员表示，并非所有项目都修补了他们发现的漏洞，一些项目可能仍然包含一个或多个文件上传漏洞。

近日，捷克共和国Brno市的Brno大学医院在COVID-19爆发期间遭到网络攻击。医院官员尚未透露安全漏洞的性质。不过这一事件已被认为是严重的，足以推迟紧急外科手术。目前医院已重新安排急性病人到附近的圣安妮大学医院就诊。

  

在安全事件发生期间，该医院被迫关闭了整个IT网络，其他两个分支机构，儿童医院和妇产医院也受到了影响。安全研究员Sucuri表示，攻击是在当地时间早上5点左右出现。医院的公告系统不停重复，由于网络安全，所有人员应立即关闭计算机。

  

事件发生后，捷克国家网络安全中心（NCSC），捷克警察（NCOZ）和医院的IT人员组成了的调查团队，对医院网络进行了修复抢救，希望尽快恢复IT网络的运行。Brno大学医院是捷克共和国最大的COVID-19测试实验室之一。在发布之时，尚不清楚医院的冠状病毒测试能力是否受到网络攻击的影响。

据外媒报道：美国一所大学推出一套全新工具箱，可以帮助抓捕网络罪犯。这款由普渡大学(Purdue University)网络安全专家开发的文件选择性分析和重建工具包(FileTSAR)是一款集跟踪、重建文件、在线活动于一体的工具。可以让执法人员获取罪犯数据。

  

主要功能是捕获数据流，并提供一种机制来选择性地重建文档、图像、电子邮件和VoIP对话。到目前为止，来自世界各地的100多个执法机构已经要求获得该技术。

微软已经确认，在 Windows 10 操作系统的最新版本中，存在着一个 SMBv3 网络文件共享协议漏洞。该协议允许计算机上的应用程序读取文件，以及向服务器请求服务。然而新曝光的严重漏洞或被攻击者利用，在 SMB 服务器或客户机上执行远程代码。

  

该公司在昨日的安全公告中解释称：该漏洞影响 1903 / 1909 版本的 Windows 10 和 Windows Server 操作系统。庆幸的是，目前尚无漏洞被利用的报告。据悉，未经身份验证的攻击者，可将特制数据包发送到目标 SMBv3 服务器。得逞之前，攻击者需配置恶意的 SMBv3 服务器，并诱使用户连接到该服务器。需要注意的是，在宣布漏洞的同一天，微软并未在“星期二补丁”中修复这一缺陷。有鉴于此，该公司建议 IT 管理人员禁用 SMBv3 压缩功能，以防止攻击者借此发起攻击。

近日，据外媒报道：报告称，与俄罗斯有关的威胁组织Turla被观察到在2019年秋季的大约两个月内发动的攻击中使用了两种新的恶意软件。该组织拥有大量的恶意工具组合，并且正在不断扩展以确保攻击效率。在2019年9月之前，受害者被诱骗安装了Skipper恶意软件，该软件最早记录于2017年。

  

在9月到11月之间，恶意域名会发布一个新的net下载器，名为NetFlash，它获取了PyFlash的第二阶段后门。该恶意软件似乎是Turla有史以来使用的第一个基于Python的后门，它使用HTTP与命令和控制（C＆C）服务器进行通信。该恶意软件可以接收JSON格式的后门命令，以下载其他文件，执行Windows命令，更改执行延迟。

随着新冠病毒引发的 COVID-19 疫情在全球的爆发，各种鱼龙混杂的“疫情追踪器”也开始盯上粗心的移动设备用户。一旦被名为 CovidLock 的勒索软件给劫持，用户将不得不支付 100 美元的赎金，以解锁他们的 Android 智能机。

  

据悉，这款勒索软件会锁定受害者的屏幕并更改设备密码。如果此前未设定密码，CovidLock 还会自动设置一个密码，以迫使用户就范。分析称，受害者必须支付相当于 100 美元的 BTC 赎金才能解锁他们的智能手机，否则将窃取照片、联系人之类的敏感信息，甚至在网络上泄露一部分细节。
