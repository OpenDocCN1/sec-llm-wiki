# 快报⁷¹丨微软大破全球最大僵尸网络

近日，据外媒报道，微软联合35个国家的合作伙伴，共同破获了全球最大的网络犯罪僵尸网络Necurs。据悉，Necurs是迄今为止已知的全球最大垃圾邮件和恶意软件僵尸网络之一，已感染全球超过900万台计算机。  

  

微软最早在2012年就发现了该网络的存在，并将所有感染相同恶意软件模块的计算机命名为Necurs，该模块会自动运行在用户的计算机上，并使用其资源每天发送大量垃圾邮件。微软表示，在最近58天的调查中，其工程师跟踪记录了Necurs网络中1台计算机，发现仅仅这1台电脑就在2个月的时间内发送了380万封电子邮件。

近日，据外媒报道：英特尔制造的许多处理器都易受到一种新型攻击侵害，即负载值注入（Load Value Injection，LVI），但英特尔称，这种攻击在现实环境中不太实用。该漏洞跟踪编号为CVE-2020-0551，研究人员还英特尔报告了LVI攻击的一种变体，为行填充缓冲区中的负载值注入（LVI-LFB）。

  

研究人员还证明，LVI攻击可以针对英特尔的软件保护扩展(SGX)，该扩展允许开发人员利用硬件加密隔离内存中的应用程序代码和数据。研究人员指出：在共享硬件的多工作负载环境中，攻击者可以利用该漏洞控制特权较低的进程来劫持具有更高特权的进程。英特尔表示，至少有一种版本的攻击针对其至强，酷睿和某些Atom处理器。该公司指出，在现实世界中进行攻击并不容易，但它已发布更新和缓解建议，以应对LVI带来的风险。

近日，据外媒报道：网络安全研究人员发现了一个新的网络钓鱼活动，该活动使用虚假的HIV测试结果诱使受害者单击恶意链接。已发现针对全球保险，医疗保健和制药公司的活动。

  

收件人打开嵌入到邮件中的恶意内容，从而触发了Koadic RAT的安装。安装后，该恶意软件可以完全控制用户的系统，在受感染的设备上运行程序，并访问受害者的数据，包括敏感的个人和财务信息。研究人员建议公众在单击之前进行思考，并考虑到医疗保健专业人员极不可能通过电子邮件发送敏感信息，例如艾滋病毒检测结果。

近日，据外媒报道：墨尔本理工大学披露了一起高度复杂的数据泄露事件。这起事件发生在2018年9月至12月之间。2018年9月至12月间保存在墨尔本理工大学的IT系统中的学生、工作人员和供应商的信息，都受到此次泄露影响。一位发言人称，大约有9万人受到了这次攻击的影响。

  

有5.5万份包含个人、健康和财务数据的文件被窃取。对大多数受影响的人来说，他们的墨尔本理工大学用户名、密码和电子邮件地址都被窃取了。不过包含学生成绩记录的系统没有受到影响。学校表示已针对此次黑客入侵对其网络安全程序进行了独立审查，目前正在实施一系列改进措施，包括软件和硬件升级，以更好地保护IT系统。

近日，据外媒报道：洛杉矶水电局被指控故意向监管机构隐瞒其网络安全方面存在的普遍漏洞。这些指控是由Ardent Cyber Solutions LLC公司提出的，该公司于2019年4月受聘于美国水电部(DWP)，从事网络安全工作。

  

据称，DWP董事会和高管于2019年8月12日得知了安全问题。但是，他们并没有解决这些问题，而是做出了虚假陈述，试图掩盖这些事实。DWP发言人表示水电局已经采取了适当的措施来确保网络安全符合所有适用的法律和安全标准。去年8月，美国联邦调查局(FBI)对DWP总部进行了突击搜查，没有人因为这次突袭行动而被逮捕或起诉。

近日，据外媒报道：澳大利亚参议院委员通过了反洗钱/反恐融资修正案，该修正案简化并简化了反洗钱/反恐融资机制中的相应银行义务，禁止金融机构建立涉及空壳银行的代理银行关系，将豁免范围扩大到“小费”禁令，将报告要求合并为单一的“货币工具”报告计划，并提高对不遵守跨境流动报告义务的民事处罚。内政部认为，如果该法案实施，将有可能节省13亿澳元的监管成本。

近日，据外媒报道：研究人员发现一项新的黑客活动正在散布Paradise勒索恶意软件。Paradise勒索软件的新变种（自2017年以来一直以一种或多种形式活跃）通过网络钓鱼电子邮件传播，但它与其他勒索软件活动不同，它使用了一种不常见但有效的文件类型来渗透网络。它利用IQY（Internet查询文件）），Microsoft Excel读取这些文本文件以从Internet下载数据。IQY属于合法的文件类型，许多商品安全产品和自动化系统不会或不能解析这些文件类型。最初的钓鱼信息设计鼓励用户打开IQY附件。

  

如果受害者这样做了，IQY文件就会连接到攻击者运行的命令和控制服务器，而攻击者又会抛出PowerShell命令，该命令用于在机器上执行勒索程序。目前尚不清楚“天堂”背后操作人员，但研究人员指出，如果机器检测到的语言ID为俄语、哈萨克语、白俄罗斯语、乌克兰语或塔塔语，那么勒索软件就不会安装在机器上。

近日，据外媒报道：HPE正在通过新的5G核心网络软件堆栈进入5G市场，该堆栈旨在吸引电信公司远离大型网络设备提供商，例如华为，诺基亚和爱立信。新的核心堆栈将是云原生基础架构，这意味着它将建立在5G阶段2核心上，其理论速度可以达到100Gbps。

  

几家大型运营商，例如沃达丰和Sprint，已经部署了他们的非独立5G网络。非独立5G的网络运行在4G核心之上，理论上可以达到150Mbps下载和50Mbps上传的速度。相比之下，HPE的核心将使用5G单元进行信令和信息传输。这不仅可以确保更高的速度和更低的延迟，还可以为网络增加功能。HPE计划在今年下半年开始销售新的5G Core Stack，并表示正在与50多家运营商就潜在部署进行对话。
