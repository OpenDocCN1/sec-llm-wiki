# 快报⁶¹丨Wi-Fi 漏洞 Kr00k 曝光：全球数十亿台设备受影响

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTg0MDQ4Nw==&mid=2247488080&idx=4&sn=d453571c4c3366fde6a69ffc46f6cb28&chksm=9f8f8258a8f80b4ea18e21841fdb4212d8525edfaf0a5570de363b1d294f3d156432e4baa699&scene=126&sessionid=1681364982#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247488080&idx=4&sn=d453571c4c3366fde6a69ffc46f6cb28&chksm=9f8f8258a8f80b4ea18e21841fdb4212d8525edfaf0a5570de363b1d294f3d156432e4baa699&scene=126&sessionid=1681364982#rd)

由赛普拉斯半导体（Cypress Semiconductor）和博通（Broadcom）制造的Wi-Fi芯片存在严重安全漏洞，让全球数十亿台设备非常容易受到黑客的攻击，能让攻击者解密他周围空中传输的敏感数据。

  

安全公司ESET在RSA会议上详细介绍了这个漏洞，黑客可以利用称为Kr00k的漏洞来中断和解密WiFi网络流量。该漏洞存在于赛普拉斯和博通的Wi-Fi芯片中，而这是拥有全球市场份额较高的两大品牌，从笔记本电脑到智能手机、从AP到物联网设备中都有广泛使用。

  

其中亚马逊的Echo和Kindle、苹果的iPhone和iPad、谷歌的Pixel、三星的Galaxy系列、树莓派、小米、华硕、华为等品牌产品中都有使用。保守估计全球有十亿台设备受到该漏洞影响。

近日，据外媒报道：墨西哥经济部在声明中表示，该部在周日检测到一些服务器受到网络攻击，目前没有发现敏感信息泄露问题，并且已经并加强了安全措施。这是继去年11月墨西哥国家石油公司(Pemex)被黑客索要500万美元比特币后，墨西哥政府遭受的第二次备受关注的网络攻击。

  

信息产业部周一表示，供应商已被要求暂时隔离网络和服务器，并补充说，一些表格的处理将暂时停止，以保护其合法性。目前尚不清楚此次网络攻击是否与墨西哥国家石油公司(Pemex)的情况一样，要求赎金。

近日，据外媒报道：专家们在OpenSMTPD中发现了一个新的重要的远程代码执行漏洞，该漏洞可能允许黑客入侵运行BSD或Linux的电子邮件服务器。OpenSMTPD是实现服务器端SMTP协议的开源的平台。

  

它允许普通机器与使用SMTP协议的其他系统交换电子邮件。OpenSMTPD出现在许多Linux发行版中，包括FreeBSD、NetBSD、Debian、Fedora和Alpine Linux上。这个新漏洞跟踪为CVE-2020-8794，存在于2015年12月引入的OpenSMTPD客户端代码的一个组件中。专家指出攻击者在这个问题揭露的几个小时后就开始利用漏洞，本地或远程攻击者可以通过发送专门编写的SMTP消息来利用此漏洞。建议BSD或Linux服务器的管理员下载OpenSMTPD 6.6.4p1并尽快打上补丁。

据外媒ZDNet报道，近日黑客在PayPal的Google Pay集成中发现了一个漏洞，现在正使用它通过PayPal帐户进行未经授权的交易。自上周五以来，用户报告称在其PayPal历史中突然出现了源自其Google Pay帐户的神秘交易。

  

受害者报告说，黑客滥用Google Pay帐户来使用链接的PayPal帐户购买产品。根据截图和各种证词，大多数非法交易发生在美国商店，尤其是在纽约各地的Target商店。而大多数受害者似乎是德国使用者。

近日，据外媒报道：Fbot恶意软件再次出现，并以更快的速度传播。Fbot是Mirai的变种之一，Mirai是一种Linux恶意软件，最初于2016年8月发现。多年来，Fbot一直是Mirai变种的一部分，利用程序员制造的其他Mirai变种的泄漏源代码，并改进它们，使它们比其他的物联网僵尸网络更好，显然这就造成了更多的感染。

  

研究人员表示，虽然新传播在监控下已经停止了一个月，但攻击者只是让僵尸网络进入睡眠状态，并重建他们的僵尸网络技术以期更好地逃避检测和更广泛的传播。2020年2月25日的感染数字显示，台湾、香港和越南的感染率高于其他受感染国家。

外媒 ZDNet 报道称，Mozilla 刚刚向 Linux 和 Mac 用户交付了 RLBox 沙箱系统更新，升级到两个平台对应的 Firefox 74 / 75 版本即可享用。作为一种广泛使用的技术，沙箱可防止恶意代码从特定的应用程序中逃逸，并在系统级别执行。而 Firefox 新引入的 RLBox，则能够将第三方库与应用程序的代码分离开来，以带来更加安全的运行环境。

  

RLBox 是一个创新项目，旨在将沙箱的安全性提升到一个新的水平。它并未将应用程序与操作系统的底层隔离，而是将应用程序的内部组件（即第三方库）与应用程序的核心引擎分开执行。RLBox 将于下月向 Firefox 浏览器用户提供，此技术可防止在第三方库中发现的错误和漏洞影响使用该库的另一个项目。

近日，据外媒报道：专家们发现了一个泄露的活动数据库，其中超过1.23亿条记录属于迪卡侬西班牙公司。不安全的归档文件的大小超过9GB，并发布在ElasticSearch服务器上。数据包括，员工未加密的密码，API日志，API用户名和未加密的密码，员工的个人识别信息，工作电子邮件地址，雇佣合同信息，客户的电子邮件和登录信息，私有IP地址。

近日，据外媒报道：欧盟委员会决定让其工作人员采用加密消息服务signal进行通信，以提高其通讯的安全性。该指令于2月初出现在内部消息墙上，通知员工使用signal传递公共即时消息。但signal只能用于发送非机密的敏感信息，机密文件必须通过更安全的渠道传输。Signal成为内部人员与组织外部人员之间通信的特权通信通道。
