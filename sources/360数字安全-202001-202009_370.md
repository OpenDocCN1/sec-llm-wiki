# RSAC 2020展馆探访 ²丨360专家团领路 这些精彩不容错过

聚焦RSAC 2020。美国时间2月25日，360专家团深入探访RSAC 2020展馆，继续为大家带来网络安全的一线资讯。

![](../Images/a63f9c400f168b7e99b11a471acab4a4.png)

今年RSA大会参展厂商依旧火爆，大约近700家全球安全厂商参与，涵盖了网络安全厂商、运营商、咨询机构、高等院校等。其中不乏Cisco、IBM、McAfee、微软、VMware等国际公司，然而中国企业因受新冠肺炎疫情影响只有7家参加。**虽然RSAC各种花里胡哨的宣传不断刷新我们对于创新的认识，但专业人士更在意那些传统“老炮儿”每一年带来哪些新科技，就让我们跟随360专家团的脚步一起看看展馆究竟有哪些精彩。**

![](../Images/a63f9c400f168b7e99b11a471acab4a4.png)

  

****国际厂商组团亮相********百花齐放****  
  
  
大会展览区分布在Moscone Center的南馆和北馆，北馆集合较大型网络安全企业如Cisco、VMware等，南馆主要展出相对规模小一点的创新公司。来自加拿大、以色列、韩国、日本等地安全科技企业纷纷组团亮相，包括Ligntship Security、J-SaS、Interfox、UBsecure、Biolog等公司。  
**360专家团注意到Check Point在展位中展示了Mastero 安全平台。**作為全球范围內長期領先的信息安全解決方案提供商，Check Point深知传统的网络架构无法适应层出不穷的安全威胁，Check Point站在网络架构设计的角度解决安全问题，增强企业抵御未知威胁的能力，同时还全面展示零信任信息安全架構解決方案。  
Imperva展台在 1227号，作为提供数据、应用、API安全解决方案的网络安全供应商，其Web应用防火墙(WAF)产品在多类报告中处于领导者品牌，同时展台还有Imperva “网络威胁指数”的展示。Netscope是一家做CASB的公司，360专家团表示他们业务扩展，现在专注于CASB+数据防泄漏。  
另外，展馆中不乏专注于威胁情报的企业，如Cyberint、ReversingLabs、Randori等，其中ReversingLabs 的Titanium平台利用可解释性机器学习的威胁情报平台，具有全新的机器学习算法模型、数据分类、即插即用的SIEM插件、SOAR，且支持MITRE ATT&CK框架，帮助用户更好地进行事件响应与决策；更有专攻数据安全的企业，如Unisys、Farsight Security Inc等，其中SIE作为Farsight Security Inc王牌产品，实时获取自身DNS情报解决方案中的数据以及第三方的实时数据，SIE Batch可帮助安全专家更轻松地“消化”实时安全数据的新方法。

******国内厂商360展位最吸睛************安全大脑占据“C位”******  
  
由于疫情影响，国内只有包含360、山石网科、绿盟等七家企业参展，展示在安全产品研发及技术革新方面的多年积淀，持续在国际网络安全市场发出属于中国网络安全企业的声音。  
**作为中国网络安全领军企业，360坐标南展馆1541号，携360安全大脑，汽车安全大脑、家庭安全大脑、360BugCloud等产品亮相，全面展示360在全网安全大数据、威胁情报、知识库、安全专家等方面的深厚积累和赋能多行业多场景的技术实力。**  
360展位吸引了现场不少观众和全球同行的瞩目，更有不少国际安全专家就360业务和技术细节沟通，并进一步就在大数据、智慧生活等方向合作进行深度交流，一时间成为全场“最亮的星”。  
📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_1226967752339030016](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_1226967752339030016)  
其中，作为“重量级”产品亮相的360安全大脑，是360公司应对当前最大网络安全威胁（APT）的核心技术。基于大范围、长时间、多维度的安全大数据，综合运用大数据分析、机器学习以及人机结合等关键技术，发现高级网络攻击的蛛丝马迹并 " 看见 " 攻击行为的全貌，最终帮助国家和客户应对各种网络安全威胁。  
目前已经成功用于实践，挖掘谷歌，微软，苹果，奔驰等主流厂商CVE漏洞近2000个，并发现 40 多起境外对中国发起的 APT 攻击，成为现场最吸睛的一款产品。  
📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_1226972606541266944](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_1226972606541266944)  
从参展企业的标语看，黑客与威胁、风险管理、云安全、应用安全、隐私等是此次大会的热点技术方向，在实际探馆中，各大厂商百花齐放，即使在同一领域内想法也可能各不相同，一些安全厂商的标语中也体现出各自的核心优势、品牌理念及市场定位。  
大厂商敢于在细分领域里尝试创新，创新企业更是信心满满专注耕耘某一领域。可见RASC不仅仅是各个安全厂商的自我展示，更是了解信息安全趋势、理念和技术的最佳窗口。
