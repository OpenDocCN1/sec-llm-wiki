# 快报⁵¹丨CIA利用Crypto AG从事间谍活动

全世界许多国家都依赖于瑞士公司 Crypto AG制造的加密设备保护通信安全。但它们不知道的是，数十年来，Crypto AG已被CIA和西德的情报机构秘密控制，控制了该公司的情报机构纂改了加密设备使他们能更容易的破解加密信息。  
《华盛顿邮报》和德国ZDF披露 ，这一行动先后有两个代号，分别为 Thesaurus 和 Rubicon。CIA在其报告形容这是情报界的世界政变，外国政府甚至花更多的钱购买设备以获得优先权让它们最秘密的通信能被美国和德国阅读。  
目前仍然有逾十个国家在使用Crypto AG的加密系统，但2月10日晚，瑞士政府吊销了Crypto AG的出口许可证。

## ![](../Images/cbaf3e257c8d66e56e2cc0d5606d7b23.png)

![](../Images/3c088f7553ac4cc0eb6cad852f0ac180.png)  
  
防病毒软件开发商Malwarebytes今天公布了2020年恶意软件预估报告，表明Mac平台的恶意软件正变得越来越普遍。在每个端点检测到的威胁数量上，Mac首次超过Windows PC。Malwarebytes检测到Mac平台共有11个威胁，而Windows用户只有5.8个。而在2018年，Mac平台每个端点仅检测到4.8个。  
这可能是因为，随着2019年市场份额的增加，Mac成为网络犯罪分子更具吸引力的目标。此外，macOS的内置安全系统并未像对待恶意软件一样对广告软件和PUP进行严厉打击，这为这些边界程序的渗透打开了大门。  
![](../Images/56dde7e740a6f8727e54f3d2ef8112c5.png)  

## ![](../Images/c0805f1d67fa6b50cadccd9d489de924.png)

![](../Images/a36c4c65106c20d28142805afe6dee6e.png)  
  
Google Play Protect是一种预装在官方Android设备上的恶意软件保护系统，已在2019年阻止了超过19亿次来自非官方（非Google）来源的恶意应用安装，例如第三方应用商店。  
谷歌表示Play Protect的每日扫描速度已经翻了一番。谷歌在今天更安全的互联网日发布的Android安全计划的评论中说，Play Protect现在每天扫描超过1000亿个Android应用。  
每日扫描的增加不仅意味着Android用户群的不断增长，而且还意味着设备存储的改进，从而使设备可以存储比以前更多的应用程序。

## ![](../Images/58c7da01d982ad9dfc32230dc5882274.png)

![](../Images/ab4e43f8f3ad5ef18c14afdd9aa3f92c.png)  
  
Emotet 是最具危险性的恶意程序之一，它能窃取银行账号，安装不同类型的其它恶意程序。最近其运营者被发现开始采用新的方法进行传播：通过相邻的 Wi-Fi 网络。它利用名为 wlanAPI 的 API 收集附近无线网络的 SSID、信号强度、加密方法如 WPA，然后使用一个常用用户名密码组合列表尝试登陆。  
如果成功登陆，被感染的设备会枚举所有连接到该网络的非隐藏设备，然后使用第二个密码列表去猜测连接设备的凭证。

## ![](../Images/4ef9a7e6de69024e098a23ded3b3365f.png)

![](../Images/25cd5eb813d78b07f9e4e113c9c46611.png)  
此前微软官方上线了 Python 教程文档，后来甚至推出了免费视频教程，引起一阵热议，现在美国国家安全局（NSA）的 Python 培训文档也在网上公开了。这一文档的公开要归功于软件工程师 Chris Swenson。  
NSA 的培训文档简要介绍了 Python 语法，着重介绍了一些实用的模块，以及该语言适用的领域，比如自动化任务、创建 Web 应用或进行高级数学研究等，并且有一些实操项目，大致上与其它 Python 教程大同小异。  
![](../Images/8ca51792ba662c0a313b44fca5bf88f9.png)![](../Images/6d2a746cc523248768e9888d59c9229e.png)![](../Images/45e7778f573bf8822061cbc37ab596af.png)  
区块链数据分析公司 CipherTrace 的最新分析显示，2019 年加密货币犯罪造成的损失超过 45 亿美元，较 2018 年的 17.4 亿美元增长了近 160%。过去一年中，由黑客攻击造成的损失下降了 66%，而诈骗和内盗给加密货币用户和投资者带来的损失增加了五倍以上。  
  
![](../Images/65183c5a8b978da956f027e54c9dd736.png)  
![](../Images/cb2480cc3bf734f2ebfec5f3025bdce8.png)![](../Images/487d05094b99e98a6e8188e1414ac3fb.png)  
安全公司 Cybereason 的研究人员报告 ，源码托管平台 Bitbucket 被滥用托管了恶意盗版软件，这些软件被下载了 50 多万次。攻击者使用了多个账号去传播恶意盗版或破解软件，其恶意功能包括窃取电子邮件凭证和其它敏感用户信息，安装勒索软件，窃取数字货币，悄悄利用计算机资源挖掘数字货币等等。攻击者上传了 Adobe Photoshop 等商业软件的破解版本，安装文件捆绑了恶意程序，这些恶意程序包括：Predator、Azorult、Evasive Monero Miner、STOP Ransomware 等等。Bitbucket 在接到通知后已经删除了这些恶意程序。  
![](../Images/ec09e5f55e2e046d276a4459829192d5.png)  
![](../Images/f36d27d114c0f5f65433df20bf90b954.png)![](../Images/d0db395e8ce21fc91fdf4714249e4028.png)  
微软周二释出的二月例行安全更新修复了  99  个 漏洞 ，其中之一是上个月披露的 IE 0day 漏洞。另外 98 个中 11 个漏洞属于高危漏洞。大部分高危漏洞是远程代码执行和内存损坏，位于 IE 脚本引擎、Remote Desktop Protocol 远程桌面协议服务、LNK 文件、Media Foundation 组件中。Adobe 也在同一天释出了多个安全更新修复 Adobe Flash Player 等产品中的漏洞 。
