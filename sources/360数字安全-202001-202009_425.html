1、 背景介绍


据360安全大脑监测发现，2020年1月，半岛APT组织Darkhotel（APT-C-06）利用“双星”0Day漏洞针对我国重点省份商贸相关的政府、企业及相关机构发起攻击。


在微软Windows 7系统停服关键节点，Darkhotel（APT-C-06）APT组织同时利用IE浏览器和火狐浏览器两个0day漏洞发起复合攻击。由于360安全大脑全球首次捕获此次在野攻击，将其命名为“双星”0day漏洞攻击，漏洞编号分别是CVE-2020-0674（IE）和CVE-2019-17026（火狐）。


在捕获Darkhotel APT组织发起攻击的第一时间，360安全大脑对该组织攻击流程及技术细节进行深度溯源分析，并将报告提交官方，以及给出了全面有效的安全建议及防护方案。360安全大脑建议火狐浏览器用户升级至最新版本，并尽快更新Windows 10系统安全补丁，Windows 7用户则可选择360安全大脑Windows 7盾甲企业版抵御攻击。


1.1 漏洞介绍


“双星”0day漏洞是全球首例利用双浏览器0day漏洞发起的复合攻击，即IE脚本引擎远程代码执行漏洞（CVE-2020-0674）和火狐类型混淆漏洞（CVE-2019-17026）。


其中，IE浏览器漏洞存在于IE 中的脚本引擎jscript.dll中，该脚本引擎在处理内存对象的过程中，触发漏洞后会造成内存损坏，从而可以造成远程代码执行漏洞。


/图：IE浏览器漏洞相关信息/


而火狐浏览器则存在IonMonkey JIT编译器的类型混淆漏洞，导致可以执行任意代码或触发崩溃。


/图：Mozilla官方确认了漏洞信息/


在捕捉到“双星”漏洞后，360安全大脑立即分别向微软和Mozilla提交了详细的漏洞信息报告，微软和Mozilla官方均已确认了0day漏洞。目前，Mozilla已修复了火狐浏览器漏洞，但IE浏览器漏洞仍然处于“双星”漏洞攻击威胁之中。


/图：微软官方确认IE浏览器漏洞信息并致谢360安全团队/



1.2 风险分析


综合此次攻击发起者Darkhotel(APT-C-06)组织的背景，以及360安全大脑对本次攻击的分析来看，该组织在Windows 7系统停服前后趁机发起“双星”漏洞攻击显然蓄谋已久，整体攻击情况呈现以下态势：


1） 专门针对我国特殊目标群体：根据360安全大脑的溯源分析，Darkhotel(APT-C-06)是一个活跃近十余年的东亚背景APT组织，长期向中、俄、日等多国政府、组织机构和企业发起APT攻击，此次攻击更是直接针对我国重点省份商贸相关的政府机构及企业，威胁面直指我国政企用户的网络安全；


2） 正值Win7停服安全空窗期：Win7停服的敏感时期，国内近六成仍然使用Windows 7系统的用户群体，特别容易受到Darkhotel(APT-C-06)攻击。尤其是受组织依赖性、系统不稳定性等问题影响，目前，我国大部分政府、军队、企业及个人用户正处于系统延用、系统迁移、升级过渡期，停服意味着这些用户的系统失去了官方保护和技术支持，Darkhotel(APT-C-06)此举无疑占尽天时地利人和。


3） 0Day漏洞复合型攻击危害性大：Darkhotel(APT-C-06) 复合利用“双星”0Day漏洞，并通过网页挂马和WPAD本地提权的多种攻击方式进行的复杂组合攻击，可在用户不知情的情况下浏览恶意网页并执行攻击程序，进而控制用户电脑，并发起植入勒索病毒、监听监控、窃取信息等，进行任意攻击操作。


2、 技术分析


在发现此次利用Office文档触发“双星”漏洞（IE浏览器漏洞）攻击后，360安全研究人员第一时间分析并还原了此次攻击的流程及技术细节，以下内容为相关技术分析。


2.1攻击流程分析


本次攻击综合利用了office漏洞文档、网页挂马和WPAD本地提权等多种攻击方式，对目标电脑进行复杂的组合攻击，完整的攻击流程如下：


 

 

以IE x86为例，整个攻击流程大致可分为四个部分：

1.    IE加载JS-1漏洞利用成功，获得代码执行权限，第一次执行JS-1中的shellcode。

2.    Shellcode利用winhttp API

（winHttpOpen和WinHttpGetProxyForUrl） 触发WPAD服务的运行。


3.    WPAD服务运行后从远程加载JS-1，再次运行脚本中的shellcode，shellcode通过判断进程名是否为svchost来判断是否在服务中被运行。

4.    Shellcode从远程下载后续文件，并获取当前系统版本来决定是否需要使用DCOM提权，win7下的WPAD服务具有system权限， 不需要使用提权，win10下的WPAD服务为local Service，则利用bits服务来提权，最后运行下载的后续文件。


2.2 攻击细节分析


一般来说，“双星”漏洞网页会自动判断当前浏览器为IE还是Firefox，操作系统为32位还是64位，然后加载相应的exploit攻击代码。攻击者可以直接利用双星漏洞进行网页挂马攻击，有意思的是我们发现了一例Office漏洞文档触发的双星漏洞，是默认打开IE浏览器进行攻击。攻击步骤如下图所示：

当用户运行该文档触发漏洞后，启动公式编辑器，利用公式编辑器进程打开用户IE浏览器，访问恶意网页触发“双星”漏洞。

当shellcode得到第二次执行时，发现当前进程名为“svchost.exe”，即已经成功从浏览器进程跨越到WPAD服务进程时，开始执行另外一个流程，下载远程的木马文件释放到temp目录下并执行该程序。



最终，木马程序接受固定URL地址的C&C命令，在受害者计算机中执行任意操作。



3、 安全防护


由于政企用户受到组织依赖性、系统不稳定性等多重问题制约，难以快速完成操作系统升级迭代，针对这类风险较大的用户，360安全大脑整理了以下防护方案及建议。


3.1 防护思路


1）预防阶段：


提升政企用户网络安全意识，加强政企相关部门对使用终端的统一管理，制定多样、详细的安全保护策略，定期加固系统关键位置以防止恶意网络攻击的破坏；及时检测、定期排查和修复系统漏洞，做好相关预防工作，更要注意防止内部计算机之间的横向传播扩散。


2）防御阶段：


面对未知且多样化的各类网络攻击，政企各单位需重视拦截和防护勒索病毒、恶意木马植入、敏感信息窃取等网络技术的发展及采用，借助先进防御技术多维度自我保护；并建立周密、完善的防御机制，重点关注主机的系统文件、注册表、启动项等核心位置防护；重视应对高级威胁防护实力与相关策略，APT攻击始终是政企用户网络安全的首要威胁。


3）响应阶段：


在进行充分的前期检测工作和防御工作后，政企用户应在响应阶段重点提升病毒查杀、修复拦截实力，并建立完善的应急响应机制，完成政企内部网络安全防护闭环。


3.2 防护方案


排查梳理：对在网设备的详细信息进行详细梳理，全面扫描、监测设备漏洞及网络风险；严格管控入网设备，防止非法入侵攻击内网；增强弱口令防护，规避弱口令带来的安全风险；及时修复系统漏洞及相关程序。


安全防御：加强政企防火墙保护，实时分析监测网络异常便于及时发现网络攻击情况。


应急措施：在特殊时期，更要提升安全防范意识，启动周密的应急响应措施并安排实时人工监测，便于快速处理响应。


3.3 防护建议


针对此次攻击，360安全团队建议广大用户提高警惕，面对难以防范的恶意文档攻击，首先应及时更新软件补丁，可借助安全产品进行自我防护。


1）目前火狐浏览器已经发布了Firefox 72.0.1 and Firefox ESR 68.4.1，我们建议所有的火狐浏览器用户更新到最新版本；


2）针对Windows10系统的用户，我们建议Windows 10系统用户尽快更新2020年2月份的微软安全补丁；


3）Windows 7系统用户则可以使用360 Win7盾甲产品避免“双星”0day漏洞攻击。
