# 俄罗斯将颁布人脸识别技术法案

据外媒报道，莫斯科法院将针对人脸识别技术推出新的法律，以应对用户对自身隐私方面的担忧，同时这也将影响人脸识别技术在俄罗斯的使用。

  

据悉，根据俄罗斯的购买数据库显示，在过去的一年中，莫斯科加快了人脸识别技术发展的步伐，在该项目的硬件上支出或分配了至少33亿卢布。针对此次法案颁布，相关专家表示，隐私和安全之间始终存在冲突，但是在制定了正确的法规之后所取得的结果肯定是巨大的，人们会很快感受到更加安全的面部识别技术所带来的好处。

英国警方警告称有网络犯罪分子正在清洁公司安插所谓的“休眠者”病毒软件，以便他们能够实际访问相关IT基础设施公司并对其进行黑客攻击。

  

根据报道，此次警告是由一名高级警官发布的，同时警方敦促各相关公司加强自身的网络安全程序管理。同时，他们表示目前相关清洁公司的部分系统漏洞可以让攻击者绕过物理防御措施，一旦黑客进入目标组织，他们就可以侵入内部系统并进行横向移动，因此相关公司应该高度重视。

据外媒报道，YouTube表示，它将在2020年美国大选之前对其平台进行更改，以遏制平台上对有关候选人或选举过程的虚假信息的传播。为达到此目的，Youtube通知用户表示，最佳的视频上传方法是在可用内容上提供尽可能多的信息，以帮助公司作出判断。

  

目前，该公司正在寻求将高质量的视频引入到搜索和“观看下一个视频”的面板中，并表示应该将衡量的标准偏向于视频内容真实信息。此外，YouTube表示，这些措施将有助于“高质量”的选举广告投放，帮助候选人和政治创作者的内容覆盖更广泛的受众范围，并且确保他们帐户的安全性。

安全研究人员在以色列政府DNS服务器上发现了一个开放的Open SSH访问。使用Qualys开发的在线SSL检查器，分析了服务器上的SSL配置，最终在端口22上收到来自其中一个被检查IP的答复。 SSH使用端口22，该服务允许管理员连接到Linux服务器，开放访问允许任何人尝试登录。

  

经过进一步分析，发现该服务器使用了一个OpenSSH旧版本，该版本以包含多个漏洞而闻名。该服务器运行的是OpenSSH 7.4p1，该版本于2016年12月发布，因此已经存在三年多了。从那时起，OpenSSH发行了多个版本和针对各种安全问题的一系列安全修复程序，现在服务器中并没有安装这些更新版本和修复程序。

法国跨国公司Bouygues Construction发表声明称，遭受了Maze勒索软件攻击，迫使公司关闭了其在全球范围内的系统。据了解，Maze不仅以加密和保存计算机以勒索赎金而闻名，还以窃取受害者的数据并将其发布到网络上以强制付款而闻名。目前，该公司表示正在尽最大努力调查和修复已将对客户和合作伙伴的影响降到最低。

  

![](../Images/69dacc9b9aab19f4bcb8eb3cb9b29472.png)

据外媒报道，一个名为EKAN的勒索软件（也称为Snake）于2019年12月首次出现，并且正在针对工业控制系统（ICS）发动勒索软件攻击。 

  

据悉，自EKANS（又名Snake）首次出现以来，来自各个安全机构的研究人员一直在对其进行分析，发现EKANS除其他事项外，能够停止与工业控制系统（ICS）操作相关的许多流程应用程序。 尽管目前所有迹象都显示出对控制系统网络的攻击机制相对比较原始，但静态“杀伤力清单”中列出的过程中的特殊性表明，此前针对工业领域的勒索软件没有这种故意性。

  

![](../Images/28970c2187281a7389a0f7fb4b12f254.png)

  

![](../Images/cb2480cc3bf734f2ebfec5f3025bdce8.png)

根据Microsoft发布的报告，该公司平均每天检测到77,000个活动的Web Shell，它们分布在46,000台受感染的服务器上。

  

Web Shell是用Web开发编程语言（例如ASP，PHP，JSP）编写的代码，攻击者将其植入Web服务器上以进行远程访问和执行代码。平均每天检测到77,000个web shell，这一数字不得不让人意识到黑客的活动有多么频繁。

据外媒报道，以色列风险投资公司Jerusalem Venture Partners与纽约市市长办公室和纽约经济发展公司共同在曼哈顿苏豪区大街122号启动了JVP国际网络中心。该中心的创立旨在帮助已经建立业务的公司发展到新的水平。

  

JVP创始人兼董事长Erel Margalit向媒体表示，这个新的网络安全中心的目的是提供生态系统，并为增长到1亿美元或2亿美元的公司，以及最终可能发展到下一个10亿美元的网络安全业务提供必要的帮助。专家预计，预计纽约JVP国际网络中心将使更广泛的网络安全生态圈和城市本身受益。
