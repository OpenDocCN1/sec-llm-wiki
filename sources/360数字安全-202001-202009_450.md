# 360驰援湖北 捐款1500万加1000万美金执行款

**1-24日 大年三十**

360成立**抗击新型肺炎专项小组**，驰援武汉抗击疫情。

  

**1-26日**

360公益基金会募得善款**1500万元**，WG公司委托360全面执行总价值**1000万美元**的医疗物资。360商业化合作伙伴捐赠**109万元**。

**1-27日**

第一批价值**700万的物资**发货，医用口罩、温度计、防疫手套、消毒液等驰援武汉。

**1-28日**

360配合WG专项捐赠的执行工作已经展开，通过国际渠道完成**58万美金**的设备采购，**扫描CT仪、移动X光机、专业防护服**等陆续发出。

**1-29日**

WG专项捐赠的佳能32层多功能CT**送抵湖北黄冈中医医院**。

  

**1-30日**

360公益基金会已采购可供超**3.6万人次**使用的检测试剂盒，当日华中科技大学同济医院和湖北荆州市中心医院分别收到可供**2000人次**和**7200人次**使用的检测试剂盒。

**1-31日**

3台意大利生产的康达移动式X射线机当日送达**孝感东南医院、武汉红十字会医院和荆州市第一人民医院**。

**2-01日**

  

**108台新冠肺炎检测仪**从北京疾驰武汉。

  
  
  
![](../Images/757a12885a3ddb7502ea86604c070dcb.png)  
![](../Images/9f539ac66c8584d07b20fe90b1a351a2.png)  
/ 360公益基金会驰援疫区运输现场 /  
自1月24日360公益基金会专项小组成立以来，已采购多种医疗物资在第一时间驰援了湖北省包括武汉在内的多个城市**，新型冠状病毒核酸检测试剂盒、新冠病毒检测仪、医用口罩**等医疗物资也陆续抵达**黄冈、孝感、随州、荆门、咸宁的医院或慈善机构**。  
截至目前，**360公益基金会自筹的1500万资金中已有1200余万购买了疫区急需的物资**，将随生产进度陆续发货，另有商业化合作伙伴捐赠的109万元以及国际合作伙伴WG公司的1000万美金捐助款也在同步采购执行中。  
  
**360公益基金会将一直站在“抗毒”一线，助益疫情防控。**
