# 上榜！360金融信创成果获行业点赞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTg0MDQ4Nw==&mid=2247559522&idx=1&sn=d6b97ea9710d1a5d5733467dc04578b4&chksm=9f8d796aa8faf07c4f600c19b160199016ffbe48a98f7b9218fc4261032ff2a4eb43669ceadd&scene=126&sessionid=1681364297#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247559522&idx=1&sn=d6b97ea9710d1a5d5733467dc04578b4&chksm=9f8d796aa8faf07c4f600c19b160199016ffbe48a98f7b9218fc4261032ff2a4eb43669ceadd&scene=126&sessionid=1681364297#rd)

近日，中国人民银行直属机构中国金融电子化公司牵头组建的金融信创生态实验室正式发布金融信创优秀解决方案，**360数字安全集团依托“B/S应用兼容性检测和修复工具解决方案”成功上榜。**这套解决方案也是360打造的“以企业安全浏览器为核心的跨平台解决方案”重要环节，目前已应用于我国关键部委、政府、金融、能源、运营商、教育、医疗等重要领域。

![](../Images/c6f7939fbb7e47316a22f7aa341677ba.png)2018年，360率先发布企业安全浏览器，至今已服务近千客户、适配数万业务系统。并在多年实践过程中，总结出一套**以浏览器为载体，面向政企客户，以提高整体效率，降低协作成本，保护web数据安全，支持国密改造、助力信创替代为主要目标的跨平台安全办公解决方案。**

具体来讲，360企业安全浏览器主要有四大重要功能：

**其一，**建设标准、统一、规范的安全浏览器入口，以新技术与业务深度融合构建新型协同办公平台，提升终端用户体验和高效运维管理水平；

**其二，**通过自动化检测修复工具、远程浏览器隔离等解决方案实现异构计算平台适配、多应用兼容，上榜的“B/S应用兼容性检测和修复工具解决方案”即为此环节的一个板块；

**其三，**商用密码算法支持、敏感数据加密、业务系统多维安全防护，为传统终端数据安全方案增添新能力；

**其四，**以浏览器为探针，对业务系统的相关数据进行采集与分析，为业务系统的运行态势、安全态势提供数据可视化指标，助力客户安全运营与决策管理，保障业务安全稳固运行。时下信创产业迎来众多利好信息，整个产业走向快速发展的新阶段，作为数字安全行业的龙头企业，360始终立足数字安全领域优势，多层面参与信创发展浪潮：打造信创解决方案、推动信创产业合作、助力信创人才培养、参与信创标准制定和信创生态建设等。基于此，**近日360入围了中国科学院《互联网周刊》、eNet研究院、德本咨询联合发布的“2022中国信创500强”榜单。**

**![](../Images/9dd45a6848cb913331fcdd93d904d6d3.png)**  //  

得益于数字经济迅猛发展，信创市场释放出前所未有的活力，对于数字安全行业来讲，既是一次空前的发展机遇，也是一次新的安全挑战。**而作为数字安全行业的龙头企业，360在信创产业的探索脚步从未停止。**
