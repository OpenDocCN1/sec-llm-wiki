# 筑牢数字安全屏障！联通CA入根360信创SM2国密根证书库

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTg0MDQ4Nw==&mid=2247559156&idx=1&sn=46e81c8e03191e2a89b94d398dff93ee&chksm=9f8d77fca8fafeeabf6f319bb7ad13c7f082ad65c9916f5448167f89793dfbb63ae72734b472&scene=126&sessionid=1681364307#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247559156&idx=1&sn=46e81c8e03191e2a89b94d398dff93ee&chksm=9f8d77fca8fafeeabf6f319bb7ad13c7f082ad65c9916f5448167f89793dfbb63ae72734b472&scene=126&sessionid=1681364307#rd)

近日，**联通CA正式加入360信创SM2国密根证书库，**其入根后将内置在360安全浏览器（包括普通版、企业版、信创版三大版本）中，并同步内置于统信、麒麟、中科方德操作系统中，进一步完善数字安全体系建设，与360一道助力国密数字证书体系发展与落地。

![](../Images/ea5a0d24dddbb3df2eedd405e4eaa05c.png)2023年2月27日中共中央、国务院印发的《数字中国建设整体布局规划》明确指出，**“筑牢可信可控的数字安全屏障”**，而数字证书作为实施安全认证的重要技术手段，对构建数字证书安全生态、筑牢整体数字安全屏障具有重要战略意义。

为有效破局我国数字证书认证所面临的“卡脖子”困境，360早在2018年，就依托浏览器，极具战略前瞻性地推行“360根证书计划”，**目前已覆盖全球98%HTTPS流量，成为中国唯一、全球第五大自有根证书库。**

其后，360更是联合统信软件、麒麟软件、中科方德、多家国内CA、网关厂商、Ukey厂商共同发布了“信创国密根证书计划”，进一步夯实数字证书的安全根基。**截至目前，已有超过20家CA厂商完成了360信创SM2国密根证书库的入根工作，共同致力于推动国密数字证书体系进一步发展。**

此次入根的联通CA由联通数字科技有限公司安全事业部运营。联通CA是由国家电子认证服务主管部门批准的权威、公证、第三方电子认证服务机构，具有电子认证服务许可证、商用密码使用许可证、电子政务电子认证服务许可证等多项资质，并牵头参与多项国家、密码行业及重要团体标准制定。

随着数字中国顶层规划的出炉，我国数字经济将步入发展的快车道，数字安全作为健康发展的保障，也具有重要战略价值。而数字证书作为实施安全认证的重要技术手段，是建立我国信息技术产业体系安全保障的核心基础。  //  

未来，**360数字安全集团将持续推进“信创国密根证书计划”**，联合生态上下游厂商，发展壮大国密数字证书体系，夯实数字证书安全之根基, 持续为数字中国建设做出重要贡献。
