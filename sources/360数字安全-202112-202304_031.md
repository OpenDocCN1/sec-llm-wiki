# 从两会的“反诈声音” 看电信网络诈骗犯罪治理的进阶之路

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTg0MDQ4Nw==&mid=2247558753&idx=1&sn=916d4fd2055a1adc76589750f3d286f3&chksm=9f8d7669a8faff7f0ab394655ee43202306293be3254a420d68b1547b7438ce04cf632a3126d&scene=126&sessionid=1681364307#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247558753&idx=1&sn=916d4fd2055a1adc76589750f3d286f3&chksm=9f8d7669a8faff7f0ab394655ee43202306293be3254a420d68b1547b7438ce04cf632a3126d&scene=126&sessionid=1681364307#rd)

3月13日，十四届全国人大一次会议正式闭幕。期间，“惩治电信网络诈骗犯罪”成为两会关键词之一。最高人民法院工作报告和最高人民检察院工作报告提请十四届全国人大一次会议审议，两份报告均谈到司法机关对网络安全的守护，并明确表示，网络空间不是法外之地，要惩治电信网络诈骗犯罪。

  

![](../Images/2349c3bc6296a021c89ae7e02ad2ce36.png)

  

据两会报告介绍，过去五年，最高人民法院审结电信网络诈骗及关联犯罪案件22.6万件，通过审理刷单返利、虚假理财、交友陷阱等网络诈骗案件，揭露花样翻新的诈骗套路助力全民反诈。同时，最高人民检察院协同公安机关从严惩治电信网络诈骗犯罪，深挖幕后金主、严惩团伙骨干、全力追赃挽损，起诉19.3万人。

  

而作为构建电信网络诈骗违法犯罪工作治理体系和治理能力的核心力量，全国人大代表、政协委员多年来持续关注打击整治电信网络诈骗犯罪并推动相关立法工作，两会上的“反诈声音”愈发响亮：

  

**两会上的“反诈声音”**

  

**2010年3月**

全国两会上，全国人大代表、时任广东省广州市公安局人事处副处长陈伟才提出实行手机实名制、预防和打击手机短信诈骗的议案。此后，他连续7年提出关于打击治理电信诈骗的建议

  

****2014年3月****

全国人大代表、九三学社中央委员阎建国提出关于完善网络犯罪立法的议案

  

****2015年6月****

国务院批准建立打击治理电信网络新型违法犯罪工作部际联席会议制度

  

****2016年11月7日****

全国人大常委会通过的《中华人民共和国网络安全法》中特别增加了惩治网络诈骗的有关规定

**2016年12月**

最高法、最高检和公安部共同制定出台《关于办理电信网络诈骗等刑事案件适用法律若干问题的意见》，加大对电信诈骗犯罪惩处力度

  

****2017年3月****

依法惩治电信网络诈骗首次写入国务院政府工作报告

  

****2018年3月****

全国政协委员、时任中国信息安全测评中心党委书记吴世忠建议，要建立严打电信网络诈骗犯罪的“系统工程”，并加强个人信息保护方面的立法

  

****2019年3月****

全国人大代表、时任自治区财政厅厅长关礼提交了《关于支持电信诈骗重点地区开展打击治理电信网络违法犯罪工作的建议》，建议加强行业监管、夯实制度基础、加大打击惩处电信网络违法犯罪的力度

  

**2020年3月**

全国人大代表粟琼提出了《关于进一步加大电信网络诈骗监管力度的建议》。粟琼建议，强化社会相关部门对电信网络诈骗的防范打击责任，进一步加大科技强警的投入，加强实施如“云剑”行动等专项措施，严厉打击电信诈骗犯罪

  

****2021年4月底****

全国人大常委会法工委牵头，会同公安部、工业和信息化部、中国人民银行等部门抓紧推进反电信网络诈骗立法工作

  

****2021年10月19日****

反电信网络诈骗法草案提请十三届全国人大常委会初次审议

  

****2022年8月16日****

全国人大常委会法工委邀请有关基层部门、企业、全国人大代表和专家学者，就反电信网络诈骗法草案的可行性、出台时机、实施的社会效果和可能出现的问题等进行评估

  

**2022年9月2日**

《中华人民共和国反电信网络诈骗法》（以下简称《反电信网络诈骗法》）由中华人民共和国第十三届全国人民代表大会常务委员会第三十六次会议审议通过，自2022年12月1日起施行

  

****2023年3月7日****

最高人民法院工作报告和最高人民检察院工作报告提请十四届全国人大一次会议审议。两份报告明确表示，网络空间不是法外之地，要惩治电信网络诈骗犯罪

  

****2023年3月10日****

全国人大代表程伟：建议构建反电诈法配套政策制度体系 尽快出台涉诈电话号卡快速处置管理办法

  

**构建反诈安全网，360这样做**

随着《中华人民共和国反电信网络诈骗法》（以下简称《反电信网络诈骗法》）的正式施行，为依法、准确、及时预防治理电信网络诈骗违法犯罪工作提供法律指引和法治保障。有关监管部门逐步建立并完善预警劝阻专门系统和反诈大数据平台、APP，全方位织密织牢技术反诈防护网络，不断提升预警信息监测发现能力，及时发现更多潜在受害者，分级分类劝阻，防止群众被骗。

  

  

作为长期从事打击网络犯罪、黑灰产、反欺诈等领域研究及实践的企业，360数字安全集团涉网犯罪研究中心经过多年的打磨，基于海量安全大数据赋能，立足“宣、防、打、控、管、培”六大基础业务，打造了一套集预警感知、调度协同、溯源打击、重点布控、决策分析五维一体的新型犯罪作战中心体系。

  

![](../Images/5e03e1b2b3c8b7724c06d258221bf47c.png)

  

在这套体系之下，360数字安全集团能够对各类型新型网络犯罪进行全方位地打击，帮助监管部门有效提升反电信网络诈骗工作的效率。

  

仅2022年，360数字安全集团就累计配合支撑全国范围内超过600家公安机关，支撑国安&公安部及地方厅市局会战近10次，协助打击网络犯罪相关案件超900余起，案件侦破率近80%，抓获犯罪嫌疑人数百人，成功挽回我国公民数以千亿计的财产损失。

  //  

未来，360数字安全集团将依托黑灰产打击联合实验室、虚拟币、经济犯罪联合实验室、反诈联合实验室、新型网络犯罪研究联合实验室的技术及专家资源，持续与各级公安部门协同作战，不断加大打击力度和强度，参与反诈行动，全力斩断新型网络诈骗的犯罪链条，守护群众的“钱袋子”平安。
