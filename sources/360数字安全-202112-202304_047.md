# 载誉而归！360“闪亮”2023年中国网络和数据安全产业高峰论坛

 ![](../Images/36f311de9a4873030409268852994193.png) 

今日，2023年中国网络和数据安全产业高峰论坛在成都成功召开。本次论坛由工业和信息化部联合四川省人民政府共同举办，以“新征程、新思路、高质量发展”为主题，汇聚网络安全领域院士专家、企业代表，以及投融资机构、高校、用户单位等相关负责人开展交流研讨，致力于为网络和数据安全产业高质量发展输出指引性观点。

  

![](../Images/971630a8f4c08a6bb2d0fcee9021520f.png)

  
**凭借着多年深耕网络与数据安全行业的研发经验及创新能力积淀，360数字安全集团在本次论坛上一举斩获两大重磅奖项！**

**获评****“工业和信息化部**

**‘铸网2022’实网演练优秀技术支撑单位”称号**

  
面对数字化转型浪潮下不断加剧的高级网络威胁，定期进行实网攻防演习已经成为政企机构不断完善安全防御水平的必要之举。  
为提升工业和信息化领域网络安全保障能力，增强网络安全风险协同防御水平，工业和信息化部网络安全管理局在2022年组织开展“铸网2022”网络安全演练工作，此次论坛重磅表彰了表现突出单位。其中，360获评工业和信息化部“铸网2022”实网演练优秀技术支撑单位荣誉称号。  

![](../Images/ca240bebed33a4e2a431ec1f11fe465f.png)

  

作为我国数字安全产业核心力量之一，360已连续七年深度参与“国家级实网攻防演习”活动，并将此过程中积累的丰富演习组织经验和完善的安全防护措施固化到产品与相关服务中，最终形成流程完备、能力全面、验证客观、安全可控且与时俱进的实网攻防靶场平台。

  

目前，360攻防演练服务已支撑全国30多个省份，支持国家级、省部级和各企事业单位等演练行动百余次，展现了360独有的网络高阶对抗能力。

  

同时，360还曾为两会、十九大、九三阅兵、“一带一路”峰会、G20、金砖会议、APEC、七十周年庆典等国家重大活动提供网络安全保障工作，用安全的能力和行动捍卫国家安全。

  

**荣膺“2022年度漏洞报送最具贡献单位”称号**

  

长期以来，漏洞的治理与防护一直是数字安全建设的重要课题。此次论坛则对2022年在工业和信息化部网络安全威胁和漏洞信息共享平台漏洞报送相关工作中提供了有力支撑的各家单位进行表彰，旨在进一步聚力推动安全漏洞治理体系的建设。其中，360荣膺“2022年度漏洞报送最具贡献单位”称号。

  

![](../Images/39834dd4ffa40712a9e469affeff26ef.png)

  

近年来，360持续协助CAPPVD漏洞库做好网络产品安全漏洞管理、消控国内移动互联网APP产品安全隐患等相关工作。

  

作为最早与CAPPVD漏洞库合作的技术单位之一，360数字安全集团旗下的360漏洞云积极发挥在信息漏洞与风险研判、报送等方面的能力，聚焦于漏洞技术研究，积极开展漏洞挖掘工作，及时发现安全漏洞，消除风险隐患，推动我国漏洞安全体系建设；并多次参与CAPPVD举行的各项主题活动沙龙并分享漏洞管理行业发展的新趋势、新技术、新思路和新成果，全力支撑国家移动互联网APP产品安全漏洞管理工作。

  
  //  

此次360获评两项殊荣，不仅是国家权威机构对360技术与服务能力的高度认可，更是对360持续加强技术和产品研发的重大激励。未来，360将继续深耕数字安全技术，携手全行业共同筑牢安全防线，为数字中国建设贡献更多安全力量。
