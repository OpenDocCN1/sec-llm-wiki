# 助推国产操作系统的生态建设，360成麒麟软件安全生态联盟首批成员

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTg0MDQ4Nw==&mid=2247558255&idx=4&sn=d5e5103d73d77919b885ac0369053e2c&chksm=9f8d7467a8fafd71fee5195608bbc31ab1b5957be9fba1f9ed257202321243327eb59e42e62d&scene=126&sessionid=1681364309#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247558255&idx=4&sn=d5e5103d73d77919b885ac0369053e2c&chksm=9f8d7467a8fafd71fee5195608bbc31ab1b5957be9fba1f9ed257202321243327eb59e42e62d&scene=126&sessionid=1681364309#rd)

2月23日，麒麟软件安全生态联盟首次工作会议成功举行。作为安全生态联盟首批成员之一，360数字安全集团应邀参会并发表重要观点。

![](../Images/e6acb233b3c5f3f277d1945eb7ff1011.png)今年1月，麒麟软件联合安全厂商、固件厂商等多家企业成立安全生态联盟（以下简称“联盟”），**360数字安全集团作为首批成员正式加入，目前已有近40家成员单位参与。**联盟旨在联合打造原创性、引领性的基于麒麟操作系统的自主内生安全产业体系和创新生态。本次会议确定了联盟2023年工作计划，并就“建立创新安全体系生态、安全漏洞协同处理、打造安全解决方案”等议题进行讨论。联盟会员授牌仪式同期举行。**360数字安全集团是数字安全的领导者**，过去17年，360投入250亿，聚集超2000名安全专家，积累了2000PB安全大数据，基于以“看见”为核心的安全理念，帮助城市、政府、企业数字安全体系的规划和建设数字安全体系。360数字安全旗下**核心产品“360终端安全防护系统”**可以广泛应用于党政机关、能源、交通、金融、医疗、军工等国家命脉产业关键信息基础设施，有效保障国产操作系统及业务的安全稳定运行，助力现有业务平稳安全的向自主国产化平台过渡，解决国产操作系统上的防病毒感染、准入管理、合规检查、外设管理、违规外联、移动存储安全、数据安全防护等诸多安全防护问题。![](../Images/09d4f9549c8690c341f333819429095a.png)**360终端产线研发总监崔士波**在发言中表示，作为行业龙头企业，360在安全生态建设、产品研发等领域有着丰富的实践积累，希望能够与麒麟软件公司在国产操作系统上加强合作深度，实现情报共享，打通适配屏障，并一同为安全生态联盟贡献绵薄之力。会上，**麒麟软件高级副总裁李祥凯**向大家阐述了国产操作系统生态建设的重要性，麒麟软件安全生态联盟成立的目的及使命，即打造安全生态的“大市场、大生态、大联合”理念。麒麟软件已逐步形成了体系化的操作系统生态建设模式和方法论，未来面向市场需求和国家需要，麒麟软件将联合安全生态伙伴，齐心协力持续打造自主创新、好用、易用的产业创新生态，建设安全可靠的供应链和价值链，服务于重点行业和国家网络安全的需要。![](../Images/d2602b1c37b66a1e08609824feae3cdf.png)国产操作系统的生态建设需要监管部门、操作系统厂商、开源社区、ISV、IHV、用户等多方积极参与共建，涵盖兼容适配、性能测试、联合优化、解决方案和联合落地实施多个环节。作为麒麟软件生态建设的重要一环，安全生态联盟的建立将整合麒麟软件和安全厂商的资源能力，持续为各行业打造安全可靠一体化解决方案。  //  

360数字安全也将持续发挥数字安全领域优势，与各方一道，共同建设**以安全、好用、易用为特点的高质量生态体系**，服务千行百业数字化转型，助力国家数字经济高质量发展。
