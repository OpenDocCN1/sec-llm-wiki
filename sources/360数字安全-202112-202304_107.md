# 头部实力获认可！360数字安全集团入围2022年中国十大网信龙头企业

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTg0MDQ4Nw==&mid=2247553061&idx=2&sn=f50b486f848ea2ae101686465ab4d5a8&chksm=9f8c802da8fb093b73bf719a920697405ab3ac5f50746ee63957d7db09c068d9908173ddfff7&scene=126&sessionid=1681364315#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247553061&idx=2&sn=f50b486f848ea2ae101686465ab4d5a8&chksm=9f8c802da8fb093b73bf719a920697405ab3ac5f50746ee63957d7db09c068d9908173ddfff7&scene=126&sessionid=1681364315#rd)

近日，北京交通大学信息管理理论与技术国际研究中心（ICIR）公布2022年中国十大网信龙头企业名单。360数字安全集团以专业评分最高分成功入围，并被评为中国数字安全的技术引领者和坚定捍卫者。

据了解，该名单是由北京交通大学信息管理理论与技术国际研究中心（ICIR）经过对《ICIR网信产业数据库》详细梳理，提炼出100个网信企业，邀请80位业界专家进行打分推荐，最终遴选出10个得分最高的企业。根据专家意见，此次评选出的十大网信龙头企业普遍具有科技创新能力强，拥有独特的产品体系，企业规模较大等特点。  
![](../Images/9d27001592e4cdcf3bf8c03ec023ae67.png)在此次评选的官方评论文章中，北京交通大学信息管理理论与技术国际研究中心（ICIR）对360数字安全集团的技术领先性和企业使命感给予了高度认可，称360数字安全集团为中国数字安全的技术引领着和坚定捍卫者。![](../Images/b2af515c06fbdd8823cc869fc8131dcb.png)**北京交通大学信息管理理论与技术国际研究中心（ICIR）评论文章截图**进入数字时代以来，外部威胁不断升级，数字化技术的内在脆弱性导致安全风险风险遍布所有数字化场景。内外部双重挑战之下，各行各业亟需建立健全数字安全保障体系，从而筑牢数字经济发展的安全底座。作为深耕安全多年的安全企业，360于2022年初宣布全面转型数字安全，为国家、城市、大型企业、中小微企业提供数字安全服务。在过去17年，360投入200亿，聚集超2000名安全专家，积累了2000PB安全大数据，基于以“看见”为核心的安全理念，凝练行业独有的高级安全威胁对抗实践，提出“1+4”数字安全框架模型，帮助城市、政府、企业数字安全体系的规划和建设数字安全体系，构建“摸清家底、感知风险、看见威胁、处置攻击、提升能力”5大安全能力，形成应对数字安全复杂威胁的完整能力。面向政府管理部门，以SaaS化方式输出全网安全数据，提供数据赋能。目前，360数字安全大脑已捕获50个境外APT组织，检测到5200多次对我国20000多家重要机构单位的高级网络攻击事件。2022年，360数字安全集团联合有关单位针对“西北工业大学遭受境外网络攻击”开展了技术溯源工作，全面还原了数年间美国情报部门利用网络武器发起的一系列攻击行为，打破了一直以来美国对我国的“单向透明”优势。面向大型企业，集中建设以数字安全大脑为核心的安全运营体系，云地一体、双脑协同，形成统一的风险感知、威胁发现、协同响应能力。目前已覆盖多数头部客户累计服务超10000家政企客户。面向城市，把“卖药”模式升级为“数字安全医院”模式，建设城市级的看见、处置、指挥和防御能力，积极打造城市数字安全基地。目前已落地超20多个大中型城市，涵盖四大直辖市和部分省会城市，树立了标志性的城市级安全服务典范。面向中小微企业，提供SaaS化的一站式安全云服务，实现从本地到远程、从终端到网络的硬件、软件、数据、行为、人的全方位安全管理。目前已被众多政府、企业、教育院校等各类单位采用，并在国内多个省份的重点供应链企业得到落地部署。  //  

数字时代，360数字安全集团将持续发挥“看见”威胁的能力优势，肩负起龙头企业的责任，为筑牢我国数字安全屏障，护航数字经济发展发挥重要作用，做当之无愧的中国数字安全的技术引领者和坚定捍卫者。
