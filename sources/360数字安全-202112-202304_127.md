# 喜报，360荣获“2022中国软件技术创新产品奖”！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTg0MDQ4Nw==&mid=2247551996&idx=4&sn=ae0d07bc0046ef06200c53cebcb2ff92&chksm=9f8c9bf4a8fb12e22e14bea83c87dc438b34fd58c53cdc36deadad9fd95f29da2e26ff67c0ba&scene=126&sessionid=1681364315#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247551996&idx=4&sn=ae0d07bc0046ef06200c53cebcb2ff92&chksm=9f8c9bf4a8fb12e22e14bea83c87dc438b34fd58c53cdc36deadad9fd95f29da2e26ff67c0ba&scene=126&sessionid=1681364315#rd)

近日，以“软件改变世界，技术赋能未来”为主题的中国软件技术大会在北京顺利召开，并对在技术创新方面表现较为突出的标杆企业和个人，以及标杆软件产品、解决方案和技术服务进行了表彰。360鹰眼内容安全智能监测一体机凭借在人工智能、大数据、搜索引擎领域的技术优势荣获“2022中国软件技术创新产品奖”。

  

![](../Images/649cb8f78f37d7ba9c9e18e136ac4e54.png)  
当前，数字安全已成为推动数字经济高质量发展的重要引擎，贯穿着数字经济发展的始终。而随着新一代信息技术的不断深入与应用，短视频、直播、弹幕等各种形态的新媒体形式迅猛发展，海量互联网信息随之应运而生，其传播的高速化及传播形式的多样化使得内容信息安全监管面临巨大挑战。如何构建一套合法合规的内容安全智能审核体系化产品，守护数字时代内容信息的安全屏障迫在眉睫。  

  

面对拨云诡谲的数字安全新威胁，作为将AI技术落地于内容监测监管场景的产品，360鹰眼内容安全智能监测一体机，通过将海量内容数据转换为标签、文本及特征信息，提供涉黄、涉政、涉暴、涉恐等内容监测和预警服务，全面满足内容生产、服务、监管平台对视频、音频、图像、文本等内容的审核要求，实现了高危内容预警、中危内容发现、低危内容统计的分级分类管控。

  

  
其中，360鹰眼内容安全智能监测一体机通过全流水线深度学习算法，AI识别模型自动累积训练，**建立了基于人脸识别、暴恐、淫秽色情、声纹识别四大主题场景**下数百种AI算法模型，并支持通过标注工具和AI自训练平台升级AI模型，达到持续学习、智能进化。![](../Images/41cc803c12bd360dfa5aaaa6725d0e35.png)![](../Images/a59a88f2fed86fecd342c57700aee0c4.png)

  

此外，与传统的内容审核平台相比，360鹰眼内容安全智能监测一体机内嵌360自研的行业领先的AI算法模型和工程应用架构，采用GPU内核，最大化AI处理能力和效率；同时拥有丰富的实战模型，系统能够实现包括涉政、涉黄、涉恐等内容监测监管，并支持以API形式接入图片和视频数据进行AI识别分析；此外，360自研多模态搜索引擎，支持多模态搜索，多维度标签筛选过滤，自带应用界面；通过对审核结果建立一人一档、分类分级标签，进行有效管控。

  

![](../Images/414b7c3c3e5e3fa681dec8164696f970.png)  

目前，360鹰眼内容安全智能监测一体机主要聚焦于视频直播、点播场景，社交媒体场景，融媒体场景以及内容监管场景等应用场景，已与国家广电总局、新疆生产建设兵团电视台等合作伙伴达成了深度合作，并参与了众多重点监测工程建设项目以及相关的课题研究等。

  

其中，在国家广电总局内容安全工程建设项目中，按照实际业务需求，团队运用智能搜索、大数据、人工智能、知识图谱等关键技术，重点搭建“5大环节+4大支撑系统+3项行业标准”的内容安全智能监测一体化平台，覆盖5个大类70个小类的业务场景，参与并完成了“国庆阅兵”、“春晚”、“20大”等重要事件直播保障工作，深度赋能广电智慧监管。

  

  //  

未来，作为数字安全的领导者，360将持续以“看见”为核心的安全理念为指引，基于复杂的监管场景构建一套简单易用的全栈式内容安全解决方案，赋能内容安全，助力产业健康升级。
