# 创新势能领跑行业！360入选嘶吼最新报告XDR技术典型厂商

近日，嘶吼安全产业研究院发布《日日新，又日新 中国网络安全细分赛道发展与技术创新趋势洞察》报告，聚焦五大网络安全重点赛道和五种新兴网络安全技术，展望行业未来发展趋势。**360凭借新一代XDR数字安全防御架构入选XDR扩展威胁检测与响应技术典型厂商，创新势能领跑行业。**

  
![](../Images/1bdd53a7d6c09de3eab0ff1251f7c2c6.png)  

当前，网络安全既面临着风险挑战，也孕育着未来发展的新赛道、新机遇。苟日新，日日新，又日新，中国迎来网络安全产业变革的关键期，在此背景下，嘶吼安全产业研究院发布《日日新，又日新 中国网络安全细分赛道发展与技术创新趋势洞察报告》旨在携手广大厂商共同见证中国网络安全与数字化转型的进程，为全面加强中国网络安全保障体系和能力贡献智慧与力量。

  

  

报告指出，XDR技术为客户提供较为全面的网络安全状态检测，针对完整的攻击事件予以警告，提升运维的工作效率，降低企业应对网络安全风险所付出的成本，并给出具有针对性的解决方案，对于企业防护而言能够提升威胁检测效率和质量，有效识别高级威胁，未来将会进入快速发展期。

  

  

XDR是安全对抗技术之集大成者，是终端安全、大数据处理和分析、AI人工智能、智能安全评估BAS、APT基因库和攻防知识百科、安全运营和对抗专家服务发展到高峰的自然成果，是安全领域的复杂性系统工程。

  

360作为国内XDR代表厂商，在上述领域拥有压倒性优势，在长期一线实战中构建了新一代XDR数字安全防御架构，帮助广大用户持续提升“看见”威胁的能力和对抗效率。

  

![](../Images/2d0cf9f4527e7fdd1f52ac06970b5989.png)

  

报告指出，从攻击者视角出发，以结果为导向，以运营为中心，全天候全方位感知网络安全态势，能够有效助力各行各业全面提升网络安全威胁发现、监测预警、应急响应、攻击溯源能力。  
 基于新一代XDR数字安全防御架构，360向广大用户提供以“看见”为核心的一站式安全运营平台，帮助城市、政府、企业客户打造集态势感知、指挥控制、通报预警、信息共享、应急响应为一体的安全运营体系，构建“摸清家底、感知风险、看见威胁、处置攻击、提升能力”5大面向数字安全复杂威胁的完整应对能力。  
  //  

本次入选嘶吼安全产业研究院XDR创新技术典型厂商，是行业对360 XDR领先的技术优势、突出的创新能力、成熟的综合实力的认可与肯定。未来，360将继续发挥领先优势，持续深化XDR数字安全防御架构，为行业提供参考借鉴，为广大用户数字化转型保驾护航。
