# 荣登两项行业榜单！360入选《2022中国网络安全产业势能榜》

12月21日，嘶吼安全产业研究院发布《2022中国网络安全产业势能榜》评选结果，360数字安全集团凭借行业领先的技术优势、创新能力和市场影响力，实力入选政务与能源两大行业榜单，被评为“综合型”厂商代表。

  
![](../Images/c2f110ebf3a6aefdb6d61211f2eb6d7f.png)  
![](../Images/618bba5fd8e8f6a83e9c6ddd5671a384.png)  

  

为推动网络安全产业更加健康有序深化发展，同时鼓励在本年度行业安全领域有擎天架海能力的安全厂商，嘶吼安全产业研究院启动《嘶吼2022中国网络安全产业势能榜》调研。

  
选取政务、金融、能源、制造、运营商五大热门行业以及“综合型”、“专精型”、“创新型”三大类型，历时近2个月的调研、数据提炼、横向对比，打分复核等阶段，最终从参与报名的近300家厂商中评选出84名行业安全厂商入选榜单。**成功入选政务与能源两大行业榜单，是行业对360数字安全集团综合实力、行业地位和市场影响力的充分肯定与认可。**

  

  

一直以来，360数字安全集团坚持以“看见”为核心的安全理念，以“1+4框架模型”为指导，凝练行业独有的高级安全威胁对抗实践，帮助广大客户规划和建设数字安全体系，构建“摸清家底、感知风险、看见威胁、处置攻击、提升能力”5大安全能力，形成应对数字安全复杂威胁的完整能力。

  

**在政务行业**，360打造以“看见”为核心的政务外网安全运营服务体系，为广大政企客户建立起“态势感知、指挥控制、通报预警、信息共享、应急响应”的纵深防御体系。**在能源行业**，360基于360全网数字安全大脑赋能，为广大能源行业客户打造坚实的数字安全底座，守护行业安全。

  //  

本次入选《2022中国网络安全产业势能榜》，是对360数字安全集团安全能力的实力认可与肯定，更加充分验证了360多年来深耕数字安全对于行业发展风向的引领意义。

未来，360将继续把握行业发展趋势，持续深耕数字安全领域，探索数字安全时代的中国方案，为城市、政府、大型企业和中小微企业数字化转型保驾护航！
