# 这5组数据告诉你，世界杯不为人知的一面

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTg0MDQ4Nw==&mid=2247550190&idx=1&sn=258cd8977c1758101da6868c5b40a899&chksm=9f8c94e6a8fb1df0e9312016d9207604169d2d2afc34d1108911e3bbc6efc4a2efdd8ec33969&scene=126&sessionid=1681364398#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247550190&idx=1&sn=258cd8977c1758101da6868c5b40a899&chksm=9f8c94e6a8fb1df0e9312016d9207604169d2d2afc34d1108911e3bbc6efc4a2efdd8ec33969&scene=126&sessionid=1681364398#rd)

当下卡塔尔世界杯决赛即将到来，赛事热度也进一步升温。作为四年一度的重大体育赛事，本届世界杯32支参赛球队中，谁将捧起“大力神杯”，关心这一话题的，除了忠实的球迷，还有贪婪的赌球玩家。不同于正规渠道发售的体育彩票，赔率更高、参与方式更为多样的地下博彩平台，在各种渠道平台上悄然传播。

近年来，互联网领域黑灰产业助推传统赌博和跨境赌博违法犯罪活动向互联网迁移，新型开设赌场犯罪呈高发态势。据2020年9月第九届中国支付清算论坛上公布数据显示，每年自境内流出的涉赌资金逾1万亿元之巨。除此之外，以赌球为代表的地下博彩也对社会稳定产生严重的危害。  
360长期以来致力于反赌事业，多次协助公安机关侦破涉赌案件，拥有丰富的反赌经验和数据，360经过长时间的案件数据积累，分享了几组数据带大家了解地下博彩不为人知的一面，从而做到“知己知彼”，有效远离赌博，保障社会稳定。

  

![](../Images/57e34d0c80c7f1085adb02c5ed3368fa.png)

近一年赌博类APP新增超**500万**个，近一个月赌博类网站新增超2000万个，博彩人员想方设法躲避监管，通过众多APP诱导普通用户深陷，从而谋取利益。

  

  

![](../Images/8293dadc8c33a40657ef35fa74398dff.png)

国内参赌人员超**1000万人**，参赌人员分布TOP5地方为广东、江苏、宁夏、四川、浙江，参赌人员在**南北方的分布比例约为2：1**，国内赌徒已有一定基数，因而众多博彩人员有利可图。

  

  

![](../Images/650e7eb5ae6b7052155996b32044e276.png)

涉赌资金充值流水前五的省份（近三个月统计）：广东、重庆、湖北、江苏、浙江，涉赌金额较多的省份均在南方。

  

  

博彩运营人员位置前三的地域：**菲律宾、中国台湾、柬埔寨**，运营网站集中于中国大陆以外，以图躲避监管。

  

  

参赌输钱（充值大于提现）人员占比96%，其中超过1万的占比超过10%，可谓“**十赌九输**”。

  

  
360一直以来关注反赌领域，依托数字安全领域的攻防技术优势，借助360新型网络犯罪打击领域的优势，从多个视角助力反赌业务发展。![](../Images/aed2ae0a59b5e0d1701cceb1dbb92934.png)

✦

**首先，360发挥对大数据分析处理的优势，协助监管部门进行有效的监测、预警、封堵。**360新型犯罪作战中心体系基于自身强大而全面的数据捕获能力、大数据分析检索能力、云端深度学习建模和高效计算能力，通过预设博彩网站、跑分网站等产业链环节识别规则，建立模型样本库等，对博彩产业链进行相关监测，帮助监管部门完成高效封堵，降低恶意站点访问量，守护群众安全访问网络。另外对于骚扰电话以及垃圾短信，360全网数字安全大脑也已于云端建立了相关识别拦截规则，并优化本地算法模型，持续抵制互联网不法信息传播，维护用户移动信息安全。

  

✦

✦

✦

**其次，360发挥专家人才库和知识库优势，和有关部门共同建立分析研究的人才实验室。**360通过线上线下不同形式，为公安等有关监管部门提供专业的黑灰产业链条分析、网络安全技术、案件研判思路等培训课程，开展“反诈学院”建立人才培训体系和人才选拔，切实提升人员业务能力并应用于实战，助力反赌业务发展。

  

✦

✦

✦

**最后，360发挥安全领域的攻防技术优势，为相关执法部门提供协助分析、打击服务。**360政企安全集团为更好地助力公安打击博彩，发挥安全领域攻防技术优势，自2022年起组织一线的攻防技术人员，组建反赌业务支撑团队，截至目前已经协助多地公安机关侦办博彩案件13起，参赌人员超300万，案件月充值流水超10亿，历史涉案金额超百亿，累计冻结资金超6000万余元，抓捕涉案犯罪链条人员百余人，帮助国家追回大量损失。

  

✦

✦

目前，我国参与世界杯竞猜的唯一合法途径就是由中国体彩中心发行的足球彩票，其发行运作有着严格的审批监控程序，收益也被用于公益事业。除此之外的“博彩”、“买球”、“赌球”都属于违法行为，存在巨大风险。远离赌球、远离诈骗，让足球回归本真，才是打开世界杯的正确方式。
