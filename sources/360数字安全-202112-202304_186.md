# 再添信创落地标杆！360织语成功签约某中央金融企业

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTg0MDQ4Nw==&mid=2247549294&idx=1&sn=2c0e4f8ed48c1ba99195f44e2bb277c1&chksm=9f8c9166a8fb1870713968f1d180a9461554560c86be2814f3b5019b99d9a88c37e1a0f66f69&scene=126&sessionid=1681364399#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247549294&idx=1&sn=2c0e4f8ed48c1ba99195f44e2bb277c1&chksm=9f8c9166a8fb1870713968f1d180a9461554560c86be2814f3b5019b99d9a88c37e1a0f66f69&scene=126&sessionid=1681364399#rd)

![](../Images/eadaf834a891753c74340644f1217593.png)

  

近期，某中央金融企业正式签约360织语，合作共建全集团使用的信创协同办公平台。作为推进信创建设的重要一环，**360织语将不仅为该中央金融企业解决内外网沟通不统一的难题，更通过统一应用集成、文件集中存储等解决方案，为其打造覆盖全集团的数字化协同办公平台**。

  

该项目一期目前已顺利上线，也为360织语在金融信创领域的开拓和推广中打造了高质量的落地标杆。

  

✦

****金融信创再次高质量“落地”****

✦

  

2022年，信创产业经过了党政行业的试验实践阶段，开启了“2+8+N”的新格局，在金融、电信、电力、交通等8大重点行业加速落地。

  

随着信创建设提上日程，该中央金融企业原先使用的办公协同软件既无法满足内外网统一使用需求，也跟不上全集团数字化建设的步伐。出于人员众多、机构复杂、保密门槛高、应用入口分散等痛点，该金融集团在经过层层考察之后选择了360织语，以期打造一个适应信创混合部署环境、覆盖全集团内外网的统一数字化协同办公平台。  

  

360织语针对该中央金融的需求全面规划与设计，提供的整体项目解决方案大幅提高了全集团的办公效率及信息安全防护能力，项目一期上线后即获得了集团用户的整体好评。

  

✦

**解决内外网“互通”难题**

✦

  

据了解，**360织语为该中央金融企业提供了覆盖全集团内外网的数字化协同办公平台，不仅可以进行统一配置和统一管理，更通过统一的管控和安全防护，支持随时随地的工作沟通与无缝协作**。

  

基于强大的IM能力，360织语通过专业的消息推送引擎和消息处理引擎，为该办公平台搭建统一的消息主线，提供全端解决方案。考虑到该金融企业的业务多、应用多，但访问入口分散，所以360织语通过统一应用中心的打造，将包括云盘、OA等在内的应用进行集成和身份认证，实现一个入口就能访问所有应用，极大地提升了用户的使用体验和办公效率。

  

出于安全保密的需求，360织语不仅通过S3对接实现了文件的集中存储，更支持文件和图片“不落地”，该金融企业的员工在进行总部内外网、总部与分公司以及分公司与分公司之间的办公沟通和文件传输时，可根据网络和传输终端对文件传输和下载进行控制，最大限度地保证信息不泄露。

  

![](../Images/a927a08b48be52e369cd90b543bc149b.png)

**织语平台可根据网络和传输终端对文件传输和下载进行控制**

  

✦

**信创适配更“深”一层**

✦

  

值得一提的是，按照该中央金融企业信创建设的进程，所属机构将分批次进行国产化替代，其办公平台的部署环境非常复杂，要求很高，不仅需要进行信创与非信创混合环境的适配，平台还必须兼容支持不同厂家的信创操作系统和服务器。

  

![](../Images/b0d1199445594dd0d6c7e3d9a15cc879.png)

**360织语全面支持信创与非信创混合环境协同应用**

  

针对此“特殊需求”，早已在全端布局的360织语也再次发挥出“自主可控、全面兼容”的巨大优势——**织语提供了完善的信创协同办公平台解决方案，不仅可全面适配国产主流的基础软硬件，更拥有多种服务端+多种客户端的混合适配能力，用户可以在信创和非信创环境之间平滑切换，无论在哪种环境下都可以连到单位内的服务器，和不同环境上的其他用户进行协作**。

  

平台按等级保护和分级保护要求进行权限管控，仅以超大组织通讯录为例，织语针对该中央金融企业复杂的多层次组织结构管理需要，进行了多层次部门和分支隐藏的设置，确保组织的敏感信息不被扩散。

  

此外，基于360强大的安全技术和理念，360织语支持全系统私有化部署，聊天消息、信息传输与存储加密、严格的权限控制，更采用了多重加密和防护技术，支持三员管理，具备高密低流管控技术，避免信息泄露，有效保证信息的安全。

  
![](../Images/414b7c3c3e5e3fa681dec8164696f970.png)  

  

**在和该中央金融企业的合作中，360织语成功利用在信创领域的产品势能，加速了信创解决方案在大型政企中的落地。而实际上，360织语2018年就参与试水了某地政府机关的信创IM项目，并凭借此案例成功入选工信部首届“鼎信杯”信息技术应用创新典型应用软件奖。**

  //  

**此前，360织语已陆续在全国股份制商业银行、城商行、农商行等各类银行多次中标,充分满足了各类金融客户对即时通讯及协同门户统一沟通、高效协同、信创迁移、国密改造等需求，此外，360织语也已积累了多个政府、能源、交通等行业的信创标杆案例，并因为安全性、先进性、强扩展、适配广、体验好等多重优势深受认可和好评。**
