# 信创安全建设再加码！四川CA入根360信创SM2国密根证书库

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTg0MDQ4Nw==&mid=2247548764&idx=2&sn=67b398c441e0c27c814a6f8997854e36&chksm=9f8caf54a8fb2642aa16063ec721f8ee223bee464bbea323e00473db5c005f3264b4f9704f3c&scene=126&sessionid=1681364400#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247548764&idx=2&sn=67b398c441e0c27c814a6f8997854e36&chksm=9f8caf54a8fb2642aa16063ec721f8ee223bee464bbea323e00473db5c005f3264b4f9704f3c&scene=126&sessionid=1681364400#rd)

近日，四川省数字证书认证管理中心有限公司（简称四川CA）正式加入360信创SM2国密根证书库，其在入根后将内置在360安全浏览器中，并同步内置于统信、麒麟、中科方德操作系统中，与360共同助力推动我国信创战略的深度落地。

  
![](../Images/18b145a037f7a8e2e42d641d7eaa2a48.png)  
  

  

数字证书作为实施安全认证的重要技术手段，对信创安全的发展具备着不可替代的推动意义。为有效破局我国数字证书认证所面临的“卡脖子”困境，360早在2018年，就依托浏览器，极具战略前瞻性地推行“360根证书计划”，目前已覆盖全球98%HTTPS流量，成为中国唯一、全球第五大自有根证书库。

  

2020年8月，360联合统信软件、多家国内CA、网关厂商、Ukey厂商共同发布了“信创国密根证书计划”，进一步夯实数字证书的安全根基；截至目前，已有20家CA厂商完成了360信创SM2国密根证书库的入根工作，共同致力于推动国密数字证书体系进一步发展。

  

  
此次完成入根的四川CA是具有工信部颁发的《电子认证服务许可证》和国家密码管理局颁发的《电子认证服务使用密码许可证》的权威、公证、第三方电子认证服务机构，持续面向政府、企业、个人提供各类数字证书的签发、更新、吊销等管理服务，为网上业务活动提供可信身份、可信行为、可信时间、可信结果的网络信任环境，解决用户身份真实、数据完整、行为不可抵赖等安全问题。  
 //  

数字时代，数字证书作为实施安全认证的重要技术手段，是建立我国信息技术产业体系安全保障的核心基础。四川CA的加入，继续扩大了360信创SM2国密根证书库的规模、影响力。

  

未来，360数字安全集团将联合更多信创生态上下游厂商，发展壮大国密数字证书体系，为加快商用密码推广和生态建设提速，助力国密数字证书生态的健康发展。
