# 技术创新引领者！360数字安全集团入选北京市市级企业技术中心创建名单

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTg0MDQ4Nw==&mid=2247547642&idx=1&sn=b4706412b61d3fd823d73c6f252701d9&chksm=9f8caaf2a8fb23e4115dbc4de9b92dbd3b89baec11916ca405b6bf4018721a833456c6e56eca&scene=126&sessionid=1681364413#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247547642&idx=1&sn=b4706412b61d3fd823d73c6f252701d9&chksm=9f8caaf2a8fb23e4115dbc4de9b92dbd3b89baec11916ca405b6bf4018721a833456c6e56eca&scene=126&sessionid=1681364413#rd)

近日，北京市经济和信息化局发布了《关于公示2022年度第一批北京市市级企业技术中心创建名单的通知》，360数字安全集团凭借领先的技术创新能力和显著的发展与竞争优势实力入选。

  
![](../Images/74bdee968aca0c94c4b6668cd26f965e.png)

  

  

为助力北京国际科技创新中心建设，贯彻落实北京市“十四五”时期高精尖产业发展规划，引导和支持企业加强创新能力，培育和引导企业技术中心建设，北京市经济和信息化局组织开展了2022年度第一批北京市市级企业技术中心的创建工作，经过严格的核查、评审，96家企业进入“2022年度第一批北京市市级企业技术中心”公示名单。

  

  
![](../Images/6d0fd7f60e2bc36cdf825c015e6fb6d3.png)  
本次被认定为北京市企业技术中心，是北京市经济和信息化局等相关单位和广大用户对360数字安全集团在科技创新、技术应用等综合实力的全面肯定，标志着360数字安全集团跻身技术创新引领者阵营。  
360深耕安全领域近20年，不断加码研发，累计投入超200亿，聚集超2000名安全专家，积累了2000PB安全大数据，拥有过万项专利，围绕360全网数字安全大脑建立了一套以“看见+处置”为核心的安全运营服务体系，形成了“感知风险、看见威胁、抵御攻击”的安全能力。  
此外，360长期聚焦攻克“看不见”国家级网络攻击的卡脖子难题，已捕获50个境外APT组织，监测到5200多起针对中国的国家级网络攻击行为，为数字经济安全发展提供了有力的支撑，成为保护国家网络安全和基础设施安全不可或缺的力量。  //  

凭借足够硬核的科研实力和项目执行力，360屡次获得相关部门认可，前不久，360成功入选北京市委网信办网络安全技术支撑单位。

  

未来，360数字安全集团将充分发挥自身技术优势和能力优势，不断攀登数字安全的科技前沿，为北京建设国际科创中心和全球数字经济标杆城市贡献力量。
