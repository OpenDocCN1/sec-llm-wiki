# 360入选北京市委网信办网络安全技术支撑单位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTg0MDQ4Nw==&mid=2247546849&idx=2&sn=296a5a6ccfc5792d66eecd264fe4c8c7&chksm=9f8ca7e9a8fb2eff8f738518200a5df21dccc795e9edb38324d600cda5cae4c3c37a12604b4a&scene=126&sessionid=1681364415#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247546849&idx=2&sn=296a5a6ccfc5792d66eecd264fe4c8c7&chksm=9f8ca7e9a8fb2eff8f738518200a5df21dccc795e9edb38324d600cda5cae4c3c37a12604b4a&scene=126&sessionid=1681364415#rd)

![](../Images/25c09d7848790f6fad23985b5e663859.png) ![](../Images/36f311de9a4873030409268852994193.png) 

近日，在2022北京市国家网络安全宣传周活动中，北京市委网信办联合国家互联网应急中心北京分中心发布了网络安全技术支撑单位名单。**360数字安全集团凭借过硬的技术实力和在国家级重要活动保障工作中的优异表现，成功入选网络安全威胁预警与监测处置领域技术支撑单位。**

  
![](../Images/5569506ffa71f3e6b2515bfa803d24ca.png)  
据了解，为充分发挥北京市网络安全技术资源优势，进一步提升网络安全综合服务保障水平，2022年8月至9月，北京市委网信办联合国家互联网应急中心北京分中心，聚焦网络安全威胁预警与监测处置、数据安全与移动互联网安全、工控系统及物联网安全三大领域，面向社会公开遴选技术支撑单位。最终，360数字安全集团从55家申报企业中脱颖而出。不仅体现了国家网络安全重要支撑部门对其综合能力、网络安全技术实力、服务保障能力、合作情况及支撑规划的高度认可，更标志着360数字安全集团已成为首都网络安全应急指挥工作体系的重要组成部分。过去17年，360投入200亿，聚集超2000名安全专家，积累了2000PB安全大数据，围绕360全网数字安全大脑建立了一套以“看见”为核心的安全运营服务体系，形成了“感知风险、看见威胁、抵御攻击”的安全能力。至今，360已捕获50个境外APT组织，监测到5200多起针对中国的国家级网络攻击行为。此外，360长期积极配合国家网络安全重要支撑部门提供高级持续性威胁（APT）深度分析、安全漏洞信息报送与处置、网络安全信息报送、网络安全应急处置及网络安全专项工作等多个维度的应急服务支撑，并为两会、十九大、九三阅兵、“一带一路”峰会、G20、金砖会议、APEC、七十周年庆典等国家级重大活动提供安全保障服务。  //  

未来，360数字安全集团将充分发挥自身技术优势，积极参与全市网络安全风险防范、信息报送、监测预警、应急处置及网络安全宣传教育等工作，在应急响应服务、APT监测分析、反网络诈骗等方面紧密合作，为推动首都数字时代高质量安全发展贡献力量。
