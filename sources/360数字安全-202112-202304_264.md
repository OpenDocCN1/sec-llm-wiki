# 全国首个信创安全服务平台启动 360与天津市政府合力打造信创产业高地

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTg0MDQ4Nw==&mid=2247546087&idx=1&sn=a8bc70d73276f48d648f61add9f770d4&chksm=9f8ca4efa8fb2df982c466b5132518977c944b8886617ac0177e762092c21398d634006d7674&scene=126&sessionid=1681364415#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247546087&idx=1&sn=a8bc70d73276f48d648f61add9f770d4&chksm=9f8ca4efa8fb2df982c466b5132518977c944b8886617ac0177e762092c21398d634006d7674&scene=126&sessionid=1681364415#rd)

![](../Images/25c09d7848790f6fad23985b5e663859.png) ![](../Images/36f311de9a4873030409268852994193.png) 

8月31日下午，天津滨海高新区党委书记、管委会主任夏青林、天津滨海高新区管委会副主任崔同湘、360集团创始人周鸿祎、360集团首席运营官叶健、360数字安全集团天津公司总经理刘霏、360数字安全集团技术副总裁张锦章、360数字安全集团安全运营总经理卫东等领导受邀出席天津信创安全中心启动仪式，共同见证近年来天津市信创产业蓬勃发展的强劲势头及信创产业生态建设的标杆成果。

  

![](../Images/440b5415638e7530d53db55ebfed8827.png)

  

据了解，信创安全中心是以360数字安全能力赋能天津信创产业发展为切入点，围绕“可信、安全、可控、可对抗、可存活”的信创安全目标，打造起的中国信创谷政府公共服务平台，旨在提升天津信创企业的安全能力，帮助天津信创产业实现体系化的安全防御，起到强链、补链的作用。  
![](../Images/c6a026fb57c0c0cf7f7b3f9e173a46a1.png)  
启动仪式上，360集团天津公司总经理刘霏介绍到，作为引领天津市信创产业升级、高质量发展的重要驱动力，天津信创安全中心以360网络安全、数据安全和产品安全等数字安全能力为抓手，向信创企业提供以安全防御为核心、以安全策略管控为重点、以自动化运维管理为支撑的安全运营服务。此外，作为信创安全中心的运营服务提供者，360还利用“实时、全样、精准”的安全大数据，建立了全程在线、全域覆盖、实时反馈的安全运营服务体系，有效完善了政府、信创安全中心和信创企业三方之间的协同配合机制，扎实打造了天津市感知风险、看见威胁、抵御攻击的安全能力体系。  
天津信创安全中心的落地及运营离不开天津市政府对信创产业发展的战略引领及资源扶持。天津滨海高新区管委会副主任崔同湘强调，滨海新区作为全市信创产业的集聚地和主战场，以中国信创谷建设为抓手，全力打造有竞争力的信创产业集群。目前，滨海新区已经集聚了以360为首的信创网信安全产业上下游企业共1000余家。崔同湘表示，360数字安全集团已经通过信创安全运营中心、安全检测中心和靶场中心攻防体系，检验了高新区内信创企业安全水平的同时提供了安全服务保障。期待360不断发挥创新引领作用，为天津信创产业集群建设保驾护航。  
截至目前，信创安全中心已检测勒索、木马、蠕虫、挖矿、恶意攻击等各类攻击告警7500万余次，处置安全事件79000余条，修复高中低危漏洞2067个，累计运营服务次数超过4000次并输出服务报告877份。  //  

未来，360数字安全集团将持续依托以“看见”为核心的全网数字安全大脑，帮助天津市建立一套能力完备、可运营、可输出的信创安全体系。同时，360还将携手信创生态伙伴共同推动产业发展，为相关重点行业网络安全保驾护航，全方位守护信创安全、国家安全。
