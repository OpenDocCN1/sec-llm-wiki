# 聚焦数字赋能，360受邀参展世界职业教育产教融合博览会

近日，首届世界职业技术教育发展大会在天津举办，120多个国家和地区的代表注册参会，大会同期举办世界职业教育产教融合线上博览会，**360集团副总裁、首席安全官杜跃进**在开展仪式发表讲话。作为联合参展的数字安全行业代表之一，360数字安全集团自主研发的360安全教育云平台，以及创新服务的产业学院、实训案例、人才能力评测等产教融合成果在博览会首次亮相。

  

**职教发展正当时，360积极参与探索**

  
![](../Images/a171549c73f240aad8ea41333297560a.png)  
全球新科技革命背景下，职业教育已成为世界经济发展格局的关键变量，许多国家和重要国际组织积极探索符合本国、本行业领域人才需求的职业教育体系，形成了众多特色发展经验和模式。  
杜跃进表示，我国企业数量达5000万左右，大量的人才缺口不能单单依靠其它领域输送，应该从职业教育体系定向培养，尤其数字安全领域需要一批特殊人才，更需要通过职业教育来挖掘。杜跃进认为，以我国目前职业教育在校生的体量，一定是满足现阶段特殊人才需求的，同时在数字时代背景下，职业教育的培养方式将拥有广阔的创新空间和发展机遇。  
在助推职业教育高质量发展上的责任担当方面，杜跃进提到，360一直以来十分重视职业教育领域并付诸实践，也得到中国职业教育学会的大量支持，在数字安全方案、技术安全、人才培养、信任机制、威胁应对等领域，积极与各界合作，沉淀出360自己的方法论。同时，360在很多地方建立了现代产业学院，建立了安全专业人才培养认证和安全领域师资认证体系，开发了在线教育平台，做出诸多探索。未来，我们期待和更多职业教育学校、老师合作，共同培养数字时代的职业教育人才。  

**数款产品频落地，360提供有效助力**

  
多年来360始终关注职业教育领域的落地实践，360数字安全集团在现有产教融合基础上，进一步打造了360数字安全产业学院、360安全教育云平台和360安全人才综合能力评价系统，促进职业教育的高质量发展，为我国数字经济发展提供高技能、智慧型人才提供有力支撑。  
![](../Images/cad3dbfea49d5fbec78fa2265cd5a4cd.png)  
共建人才培养基地，既是改革传统教学育人的手段，也是产教融合、育训结合的有效平台支撑。作为360数字安全集团唯一官方对外教育机构，360安全人才能力发展中心一直致力于数字安全人才能力研究与教育，结合产业需求打造更多数字安全人才培养场景。先后多次通过“以练促学”的模式，用最接近实战场景的练习方式帮助学生快速掌握知识点，攻克相关技术难点。360始终以培养一流数字安全人才和发展数字安全产业作为首要任务，积极构建政府主导、校企合作、社会参与的国家数字安全人才培养建设新格局。  
![](../Images/e2157b3762410dcd691f90397aa80f6b.png)  

**360数字安全产业学院**

  
近年来，职业教育全面深化产教融合，校企合作呈现出多样化格局。与其他产教融合措施相比，现代产业学院是更复杂的组织形态，不确定因素更多，难度也更大。360数字安全产业学院围绕国家数字化战略转型，通过政产学研用多方协同，以四融和四链的方式，建设一个集信息人才技术与物质资源共享的产业学院，立足产业学院本地，服务当地产业，培养区域发展亟需的高素质技术服务人才。  

**360安全教育云平台**

  
经过两年的打磨与沉淀，360安全教育云平台通过提供涵盖线上直播教学、录播学习、实验练习、考试测评、备课组课、意识普及、答疑互动、专家课程、安全认证以及人才对接的一站式在线人才安全教育解决方案，为院校、企业、社会大众提供高效便捷的人才培养路径。目前，360安全教育云平台已在全国30余所院校、20余家企事业单位落地使用，为15万用户提供数字安全教育培训服务。  
![](../Images/682b97a36ccd963fefb4e6f1f32744f7.png)  

**360安全人才综合能力评价系统**

  
传统数字安全人才评测工具只在知识、技能方向进行评测，缺失底层科学评测模型，也不符合“不拘一格降人才”的数字安全人才选拔理念。360安全人才综合能力评价系统是基于对海量数字安全人才需求画像调研、采集、分析、归纳形成的胜任力标准，不特意强调某一领域的竞技能力，更强调面向职业发展的综合能力。  
同时，在360数字安全产业学院建设和360安全人才综合能力评价中，皆以《网络安全人才能力发展白皮书》为标准，对学生进行知识能力、专业素养、技能水平等维度评测，根据需求对其素质状况、发展潜力、个性特点等心理特征作出科学评价，为院校数字安全专业人才培养提供依据。  
![](../Images/d4ea8d28ab3ab057dbd60ffac1280549.png)  
据了解，世界职业教育产教融合博览会长期吸引着职教人的目光，博览会以线上为主，线上线下结合的方式进行为期18个月的展览。360数字安全集团通过本次参展契机，向社会充分展示了在安全人才培养层面取得的成果，进一步开阔了科技成果转化、产学合作等方面的视野，推进产业与教育的深度融合，不断提升高素质技术技能型人才培养质量，为区域经济发展乃至国家建设培养更多高质量数字安全人才。
