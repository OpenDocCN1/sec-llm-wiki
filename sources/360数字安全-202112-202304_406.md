# 昌都市委网信办与360签署战略合作协议，着力提升网络攻防实力

近日，西藏昌都市委网信办与360政企安全集团签署战略合作协议。双方将在数字化发展、人才交流、战略投资、数字安全等方面开展合作，着力提升昌都市网络攻防实力。

  
![](../Images/25e53b47ab950ea95b99978110e49213.png)

  

近年来，围绕数字中国战略的总体部署，昌都市委网信办全力推进数字昌都工作，倾力打好安全、持续、融合等特色招商牌，着力吸引一批互联网企业进行数字化建设，抢抓数字经济浪潮，推动数字经济发展。 

据悉，昌都市委网信办与360政企安全集团此次签署战略合作协议，将依托360政企安全集团在技术、人才、平台、产品、数据资源等方面的优势，通过资源整合、流程融合、技术改进等方式，围绕昌都市委网信办具体业务，整体推进数字安全和信息化各项工作建设，全面为昌都市互联网发展和治理不断开创新局面，让网络空间日益清朗。

 具体而言，**360政企安全集团将助力昌都市提升数字安全保卫能力、实网攻防能力和威胁情报能力，提供安全专家服务，同时与昌都市委网信办开展数字安全人才交流与培养，**为昌都市数字安全与信息化建设提供技术支撑、智力支持。 未来，双方还将从昌都市整体战略层面，加强数字安全产业合作模式研究，将更多的新技术应用于昌都市数字安全建设。
