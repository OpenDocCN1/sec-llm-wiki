0x02 漏洞描述


    Ajax.NET Professional (AjaxPro) 是最早可用于 Microsoft ASP.NET 的 AJAX 框架之一。该框架将创建代理 JavaScript 类，用于在客户端调用 Web 服务器上的方法，并具有适用于所有常见 Web 浏览器（包括移动设备）的完整数据类型支持。

    2021年12月15日，360漏洞云团队在互联网上监测到一则关于 AjaxPro.Net某版本存在反序列化漏洞的信息。漏洞编号：CVE-2021-23758，漏洞威胁等级：高危，漏洞评分：8.1。

    由于任意 .NET 类可能被反序列化，因此所有版本的 ajaxpro.2 包都容易受到反序列化不可信数据的影响，这些类可能被滥用以获取远程代码执行。由于限制检查不严格，导致任意 .NET 类可能被反序列化，因此AjaxPro.NET v21.12.8.1之前的版本容易受到反序列化不可信数据的影响，这些类可能被滥用以获取远程代码执行。

    Java 反序列化问题已为人所知多年。然而，在 2015 年，人们对这个问题的兴趣大大增强，当时在一个Apache Commons Collection中发现了可以被滥用来实现远程代码执行的类。这些类用于影响 IBM WebSphere、Oracle WebLogic 和许多其他产品的零日漏洞。

    攻击者只需要识别一个在其路径上具有易受攻击类的软件，并对不受信任的数据执行反序列化。然后他们需要做的就是将有效负载发送到解串器中，让命令得到执行。
