0x02 漏洞描述


   活动目录（Active Directory）是面向Windows Standard Server、Windows Enterprise Server以及 Windows Datacenter Server的目录服务。

Active Directory使用了一种结构化的数据存储方式，并以此作为基础对目录信息进行合乎逻辑的分层组织。


Active Directory主要提供以下功能：

①服务器及客户端计算机管理：管理服务器及客户端计算机账户

②用户服务：管理用户域账户、用户信息、企业通讯录（与电子邮件系统集成）、用户组管理、用户身份认证、用户授权等

③资源管理：管理打印机、文件共享服务等网络资源。

④桌面配置：系统管理员可以集中的配置各种桌面配置策略。

⑤应用系统支撑：支持财务、人事、电子邮件、企业信息门户、办公自动化、补丁管理、防病毒系统等各种应用系统。


    域内管理权限涉及大部分企业的身份核心，一直以来都是企业内网安全的重点关注内容。

 

    2021年11月10日，360漏洞云就已监测到Microsoft发布安全更新，修复了多个Microsoft中的漏洞，其中就包括两个域服务权限提升漏洞（CVE-2021-42287、CVE-2021-42278）。

    2021年12月12日，360漏洞云检测到一则上述漏洞的漏洞细节和利用过程在互联网上公开的信息。这两个漏洞可将域内的任意用户提升至域管权限，对企业身份认证及相关数据资产造成了严重威胁。

 CVE-2021-42278

漏洞等级：高危（7.5）

漏洞类型：权限提升

漏洞描述：Microsoft Windows Active Directory 域服务存在特权提升漏洞，该漏洞是由于Active Directory 域中机器账户的名字应该以`$`结尾，但是Active Directory域没有对此做出验证，从而可以绕过安全缓解机制。攻击者可以配合CVE-2021-42287漏洞实现权限提升。

 CVE-2021-42287

漏洞等级：高危（7.5）

漏洞类型：权限提升

漏洞描述：Microsoft Windows Active Directory 域服务存在特权提升漏洞，该漏洞是由于应用程序没有对Active Directory域服务进行安全限制。当攻击者通过创建与机器账户用户名相同的机器账户（不以$结尾），配合CVE-2021-42278漏洞可实现域内用户权限提升。

0x06 修复建议


1. Microsoft已在11月安全更新中发布了官方补丁KB5008602、KB5008380，Windows服务器管理员通过Windows自动更新即可修复。

 

2. 手动安装补丁

对于不能自动更新的系统版本（如Windows Server 2008、Windows Server 2008 R2），可参考以下链接下载适用于该系统的补丁并安装：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-42278

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-42287


与此同时，360漏洞云提醒您请做好资产自查以及预防工作，以免遭受黑客攻击。
