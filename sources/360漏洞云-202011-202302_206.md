**0x01 漏洞描述**

  
VMware vCenter Server是VMware虚拟化管理平台，广泛的应用于企业私有云内网中。通过使用vCenter，管理员可以轻松的管理上百台虚拟化环境 。![](../Images/d1a8aee66bacf58a4af6c1fe6221bbcf.png)

  

2021年11月24日，360漏洞云团队监测到VMware发布安全公告，修复了两个存在于vCenter Server中的漏洞。其中，1个高危漏洞，1个中危漏洞。漏洞详情如下：

**CVE-2021-21980**

漏洞等级：高危（7.5）

漏洞类型：任意文件读取

漏洞影响：对 vCenter Server 上的端口 443 具有网络访问权限的恶意行为者可能会利用此问题来访问敏感信息。

**CVE-2021-22049**

漏洞等级：中危（6.5）

漏洞类型：SSRF

漏洞影响：可以通过网络访问 vCenter Server 上的端口 443 的恶意行为者可能会通过访问 vCenter Server 外部的 URL 请求或访问内部服务来利用此问题。

**0x02 危害等级**

  
高危  

**0x03 影响版本**

  
VMware vCenter Server-VMware =6.7||=7.0||=6.5VMware Cloud Foundation-VMware =4.x||=3.x
