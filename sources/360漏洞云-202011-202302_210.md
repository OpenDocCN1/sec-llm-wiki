**0x01 漏洞描述**

  
美国CommVault公司是世界领先的数据管理软件及相关服务的供应商。Commvault CommCell可以备份和恢复虚拟机、结构化和非结构化数据，具有速度和规模。 ![](../Images/1820d0ce421ac4a9b847b649291c7e9b.png)2021年11月23日，360漏洞云团队在网上监测到一则关于Commvault  CommCell中存在多个漏洞的信息。其中有1个严重漏洞，4个高危漏洞。漏洞详情如下：

**CVE-2021-34993**

漏洞评分：9.8

漏洞类型：身份验证绕过

漏洞描述：CVSearchService服务中存在特定缺陷。该问题是由于在身份验证之前缺乏适当的验证造成的。攻击者可以利用此漏洞绕过系统上的身份验证。 

**CVE-2021-**34994****

漏洞评分：8.8

漏洞类型：任意代码执行

漏洞描述：DataProvider 类中存在特定缺陷。该问题是由于在将用户提供的字符串作为 JavaScript 代码执行之前缺乏对其进行适当验证造成的。攻击者可以利用此漏洞逃逸 JavaScript 沙箱并在 NETWORK SERVICE 上下文中执行 Java 代码。

**CVE-2021-**34995****

漏洞评分：8.8

漏洞类型：任意代码执行

漏洞描述：该特定缺陷存在于 DownloadCenterUploadHandler 类中。该问题是由于缺乏对用户提供的数据的适当验证造成的，这可能允许上传任意文件。攻击者可以利用此漏洞在 NETWORK SERVICE 的上下文中执行代码。

** CVE-2021-**34996****

漏洞评分：8.8

漏洞类型：任意代码执行

漏洞描述：Demo\_ExecuteProcessOnGroup 工作流中存在特定缺陷。通过创建工作流，攻击者可以指定要执行的任意命令。攻击者可以利用此漏洞在 SYSTEM 上下文中执行代码。

**CVE-2021-**34997****

漏洞评分：8.8

漏洞类型：任意代码执行

漏洞描述：AppStudioUploadHandler 类中存在特定缺陷。该问题是由于缺乏对用户提供的数据的适当验证造成的，这可能允许上传任意文件。攻击者可以利用此漏洞在 NETWORK SERVICE 的上下文中执行代码。
