**0x01 漏洞描述**

  

ShenYu（原名 Soul）是一款高性能，响应式的网关，同时也是应用于所有微服务场景的，可扩展、高性能、响应式的 API 网关解决方案。

  

![](../Images/30ff9983b621c2ea6ef17ff13cf138a0.png)

2021年11月18日，360漏洞云团队在网上监测到一则Apache ShenYu JWT登陆认证绕过漏洞的信息。漏洞编号：CVE-2021-37580，漏洞威胁等级：高危，漏洞评分：8.1。  

  
攻击者可通过该漏洞绕过JSON Web Token (JWT)安全认证，直接进入系统后台。

  

**0x02 危害等级**

  
高危：8.1  
  

**0x03 漏洞复现**

  
2021年11月18日，360漏洞云安全专家已复现上述漏洞，演示如下：  
![](../Images/0e4322fac15e63a7757daa6418633f3d.png)*CVE-2021-37580*  
  
完整POC代码已在360漏洞云情报平台（https://loudongyun.360.cn/）发布，360漏洞云情报平台用户可通过平台下载进行安全自检。  

**0x04 影响版本**

  
Apache ShenYu\=2.3.0\=2.4.0  

**0x05 修复建议**

  
厂商已发布升级修复漏洞，用户请尽快更新至安全版本。官网地址：https://shenyu.apache.org/zh/download
