**0x01 漏洞描述**

  

npm（全称 Node Package Manager，即“node包管理器”）是Node.js默认的、用JavaScript编写的软件包管理系统。

![](../Images/38934f5247c9898220bf59d4b627b8d1.png)

2021年11月17日，360漏洞云团队监测到 GitHub发布安全公告，修复了两个存在于npm中的漏洞，攻击者可利用该漏洞发起针对性的依赖混淆攻击和域名抢注，或者未经授权更新任何npm 包的新版本。CVE编号：暂无，漏洞等级：8.5。

** CVE编号暂无**

漏洞类型：信息泄露

漏洞影响：信息泄露

漏洞描述：GitHub公开可用的 npm 服务的日常维护引起了npmjs 的副本服务器上的数据泄漏。泄漏暴露了私有 npm 包的名称列表，但私有包的内容没有暴露。黑客可以利用这些私有包的名称以自动化的方式进行有针对性的依赖混淆和域名抢注攻击。

** CVE编号暂无**

影响类型：逻辑处理错误

漏洞影响：越权

漏洞描述：该漏洞存在于 npm 软件包的发布过程中，源于处理对npm软件包发布请求的多个微服务之间不正确的授权检查和数据验证，导致授权和发布的软件包存在差异。该漏洞允许攻击者在未经适当授权的情况下使用帐户发布任何 npm 包的新版本。GitHub表示该漏洞目前尚未被恶意利用，并且已经通过确保发布服务和授权服务的一致性来缓解这个问题，以确保授权和发布使用的是同一个软件包。

与此同时，请做好资产自查以及预防工作，以免遭受黑客攻击。
