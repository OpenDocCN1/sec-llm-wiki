**0x01 漏洞描述**

  

VMware vCenter Server是VMware虚拟化管理平台，广泛的应用于企业私有云内网中。通过使用vCenter，管理员可以轻松的管理上百台虚拟化环境 。  

![](../Images/a9daaa58d4e50e27d52009ba39b907f9.png)  
360漏洞云监测到VMware vCenter Server中存在一个权限提升漏洞（CVE-2021-22048），该漏洞存在于vCenter Server 在 IWA（集成 Windows 身份验证）身份验证机制中。对 vCenter Server 具有非管理访问权限者可能会利用此问题将特权提升到更高特权组。 

**0x02 危害等级**

  

中危：7.1  

  

**0x03 影响版本**

  
vCenterServer 6.7vCenterServer 7.0CloudFoundation (vCenter Server) 3.xCloudFoundation (vCenter Server) 4.x  

**0x04 修复建议**

  
目前VMware暂未发布此漏洞的补丁，但VMware提供了该漏洞的修复方案：将SSO 身份源配置从集成 Windows 身份验证 (IWA) 切换到以下选项之一：

*   Active Directory over LDAPs 身份验证
    
*   AD FS 的身份提供者联合（仅限 vSphere 7.0）
    

注意：Active Directory over LDAP 身份验证不受此漏洞的影响，但该方式不理解域信任，所以改用这种方法的用户必须为每个受信任的域配置一个独特的身份源。AD FS的身份提供者联合没有这个限制。更多信息请参考：https://kb.vmware.com/s/article/86292
