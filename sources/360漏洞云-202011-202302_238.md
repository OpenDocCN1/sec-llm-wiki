**0x01 漏洞描述**

  
Microsoft Exchange Server是微软公司开发的一款邮件服务器和日历服务器。它只在Windows Server操作系统上运行。![](../Images/74dbd8e0ef12bb195a46670c87b5f0d3.png)360漏洞云监测到Microsoft于2021年11月10日(北京时间)发布了11月安全更新，此次安全更新发布了55个漏洞的补丁(6个严重漏洞, 49个高危漏洞)主要覆盖了以下组件：Microsoft Windows 和 Windows 组件、Azure、Azure RTOS、Azure Sphere、Microsoft Dynamics、Microsoft Edge (Chromium-based)、Exchange Server、Microsoft Office、Office 组件、Windows Hyper-V、Windows Defender、Visual Studio。其中, 需重点关注的漏洞如下:  
  

*   ****CVE-2021-42298****
    

*   影响产品：Windows Defender
    
*   漏洞类型：远程代码执行
    
*   漏洞描述:  该漏洞是由于Microsoft Defender中的输入验证不正确。远程攻击者可以在目标系统上执行任意代码。成功利用该漏洞可能会导致脆弱系统的完全破坏。  
    
      
    

*   ******CVE-2021-42279******
    

*   影响产品：IE Chakra
    
*   漏洞类型：远程代码执行
    
*   漏洞描述:  该漏洞是由于Chakra脚本引擎的边界错误。远程攻击者可以触发内存损坏并在目标系统上执行任意代码。成功利用该漏洞可能会导致脆弱系统的完全破坏。
    
      
    

*   ******CVE-2021-42316******
    

*   影响产品：Microsoft Dynamics 365
    
*   漏洞类型：远程代码执行
    
*   漏洞描述: 该漏洞是由于Microsoft Dynamics 365中的输入验证不正确。经过身份验证的远程攻击者可以发送一个专门设计的请求，并在目标系统上执行任意代码。成功利用该漏洞可能会导致脆弱系统的完全破坏。
    
      
    

*   ******CVE-2021-26443******
    

*   影响产品：Microsoft Virtual Machine Bus (VMBus) 
    
*   漏洞类型：远程代码执行
    
*   漏洞描述:  该漏洞是由于Microsoft Virtual Machine Bus(VMBus) 中的输入验证不正确。本地网络上经过远程身份验证的攻击者可以在 VMBus 通道上发送特制的通信并在目标系统上执行任意代码。
    
      
    

*   ******CVE-2021-3711******
    

*   影响产品：OpenSSL SM2
    
*   漏洞类型：缓冲区溢出
    
*   漏洞描述:  该漏洞是由于SM2解密实现中的EVP\_PKEY\_decrypt()函数的边界错误。远程攻击者可以发送专门制作的SM2内容进行解密，以触发缓冲区溢出62个字节，并在目标系统上执行任意代码。
    
      
    

*   ******CVE-2021-38666******
    

*   影响产品：Windows远程桌面客户端
    
*   漏洞类型：远程代码执行
    
*   漏洞描述:  该漏洞存在于mstscax.dll, 攻击者可以利用客户端和服务器之间现有的本地RDPDR静态虚拟通道设置，通过 RDP 智能卡虚拟通道扩展功能 (MS-RDPESC) 触发该漏洞。
