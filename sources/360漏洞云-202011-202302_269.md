**0x01 漏洞描述**

  

VMware Workspace ONE 是一款数字化工作空间平台，可通过集成访问控制、应用管理和多平台端点管理来在任意设备上交付和管理任意应用。

![](../Images/8f737545238e610764f6168583e322c9.png)  

360漏洞云监测到VMware Workspace ONE统一端点管理 (UEM) 控制台存在拒绝服务漏洞（CVE-2021-22029）。该漏洞源于/API/system/admins/session REST API处的请求速率限制不当，远程攻击者可通过发送大量的请求来执行拒绝服务攻击。

  

**0x02 危害等级**

  

中危：5.3

  

**0x03 影响版本**

  

VMware Workspace ONE UEM console 2105 < 21.5.0.2

VMware Workspace ONE UEM console 2102 < 21.2.0.14

VMware Workspace ONE UEM console 2011 < 20.11.0.30

VMware Workspace ONE UEM console 2008 < 20.0.8.32

VMware Workspace ONE UEM console 2005 < 20.5.0.51

VMware Workspace ONE UEM console 2001 < 20.1.0.33

  

**0x04 修复版本**

  

VMware Workspace ONE UEM console 2105 21.5.0.2

VMware Workspace ONE UEM console 2102 21.2.0.14

VMware Workspace ONE UEM console 2011 20.11.0.30

VMware Workspace ONE UEM console 2008 20.0.8.32

VMware Workspace ONE UEM console 2005 20.5.0.51

VMware Workspace ONE UEM console 2001 20.1.0.33

  

**0x05 修复建议**

  

厂商已发布升级修复漏洞，用户请尽快更新至安全版本。
