**0x01 漏洞描述**

  

BlackBerry QNX Software Development Platform（SDP）是加拿大黑莓（Blackberry）公司的一套QNX软件开发平台，该平台主要用于开发基于QNX平台的软件。

![](../Images/7d888cd0e2929a351692784c4adaeffa.png)

360漏洞云监测到BlackBerry QNX SDP存在整型溢出漏洞（CVE-2021-22156）。该漏洞源于其C运行时库的calloc()函数中存在整数溢出问题，攻击者可利用该漏洞导致拒绝服务或执行任意代码。

  

**0x02 危害等级**

  

严重：9.0

  

**0x03 影响版本**

  

QNX SDP <= 6.5.0SP1

**0x04 修复版本**

  

QNX SDP >= 6.6.0

  

**0x05 修复建议**

  

厂商已发布补丁（Patch ID 4844）修复漏洞，受影响的用户请尽快安装补丁，或升级至 QNX SDP 6.6.0 及以上的版本。
