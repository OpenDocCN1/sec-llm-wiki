**0x01 漏洞描述**

  

Lexmark Universal Print Driver是美国利盟（Lexmark）公司的一个打印机驱动。

![](../Images/faf4e55620813462d30957e8659fd4a6.png)

360漏洞云监测到Lexmark Universal Print Driver存在特权提升漏洞（CVE-2021-35449）。一个标准的低权限用户可以在添加打印机的过程中使用驱动程序来执行DLL文件，从而导致权限提升到SYSTEM。

  

**0x02 危害等级**

  

高危：7.8

  

**0x03 漏洞复现**

  

360漏洞云已成功复现该漏洞，演示如下：

![](../Images/c8f6b69cbe4bc3f0134a5563f07841d5.png)

![](../Images/b5d180159baa6eee8db5816560e0942f.png)

![](../Images/4657f496663348f1ac68b94c581acaf1.png)

完整POC代码已在360漏洞云情报平台发布，360漏洞云情报平台用户可通过平台下载进行安全自检。  

  

**0x04 影响版本**

  

Universal Print Driver <= 2.15.1.0 

G2 driver <= 2.7.1.0

G3 driver <= 3.2.0.0

G4 driver <= 4.2.1.0

  

**0x05 修复版本**

  

Universal Print Driver v2.15.2.0

  

**0x06 修复建议**

  

厂商已发布升级修复漏洞，用户请尽快更新至安全版本。
