**0x01 漏洞描述**

  

Cisco Adaptive Security Appliances (ASA) 是美国思科（Cisco）公司的一套防火墙和网络安全平台，提供对数据和网络资源的高度安全访问等功能。

Cisco Firepower Threat Defense (FTD) 是美国思科（Cisco）的一套提供下一代防火墙服务的统一软件。

![](../Images/d289ead7f211ab8cdcd9e6a8dac07eb0.png)

360漏洞云监测到 Cisco ASA/FTD 存在拒绝服务漏洞（CVE-2021-1422）。该漏洞源于产品的加密模块在处理特定类型的解密错误时存在逻辑错误，经认证的远程攻击者或未认证的处于中间人位置的攻击者可通过已建立的IPsec连接发送恶意包， 从而引发目标系统拒绝服务。

  

**0x02 危害等级**

  

高危：7.7

  

**0x03 影响版本**

  

Cisco Adaptive Security Appliance (ASA) 9.16.1

Cisco Firepower Threat Defense (FTD) 7.0.0

  

**0x04 修复版本**

  

Cisco Adaptive Security Appliance (ASA)  9.16.1.28

Cisco Firepower Threat Defense (FTD) 7.0.0.1

  

**0x05 修复建议**

  

厂商已发布升级修复漏洞，用户请尽快更新至安全版本。
