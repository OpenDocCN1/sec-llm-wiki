**0x01 漏洞描述**

  

SolarWinds Serv-U FTP Server是美国SolarWinds公司的一套FTP和MFT文件传输软件。  

![](../Images/fa15102c2c95648d0d56c35d3871e765.png)

360漏洞云监测到Serv-U Managed File Transfer Server 和 Serv-U Secured FTP 存在远程代码执行漏洞（CVE-2021-35211）。该漏洞源于边界错误，远程攻击者可通过发送特殊构造的请求到Serv-U服务器，触发内存损坏，实现在目标系统上执行任意代码，包括安装和运行程序，查看、更改或删除数据等。

该漏洞存在在野利用。

  

**0x02 危害等级**

  

高危

  

**0x03 影响版本**

  

SolarWinds Serv-U <=15.2.3 HF1

  

**0x04 修复版本**

  

SolarWinds Serv-U 15.2.3 HF2

  

**0x05 修复建议**

  

厂商已发布升级修复漏洞，用户请尽快更新至安全版本。
