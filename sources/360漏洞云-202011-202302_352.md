**0x01 漏洞描述**

  

北京时间2021年7月14日，360漏洞云监测到微软官方发布了2021年7月的安全更新。

![](../Images/483618be42716c911b39c475088266ac.png)

本次安全更新共修复了116个漏洞，其中包含12个严重性为关键（Critial）的漏洞，103个严重性为重要（Important）的漏洞，以及1个中危（Moderate）漏洞。

其中3个漏洞已发现在野利用：

*   **CVE-2021-34448 脚本引擎内存损坏漏洞**  
    CVSS:3.0 6.8 / 6.3  
    组件: Microsoft Scripting Engine  
    漏洞类型: 内存损坏  
    简述: 该漏洞源于处理微软脚本引擎中HTML内容时的边界错误。远程攻击者可创建一个特殊构造的网页，诱导用户打开，从而触发内存损坏，实现在目标系统上执行任意代码。
*   **CVE-2021-31979 Windows 内核特权提升漏洞**  
    CVSS:3.0 7.8 / 7.2  
    组件: Windows Kernel  
    漏洞类型：特权提升  
    漏洞简述：该漏洞源于Windows Kernel中的边界错误。本地用户可通过运行特殊构造的程序触发内存损坏，从而在系统上以提升的权限执行任意代码。
*   **CVE-2021-33771 Windows 内核特权提升漏洞**  
    CVSS:3.0 7.8 / 7.2  
    组件: Windows Kernel  
    漏洞类型：特权提升  
    漏洞简述：该漏洞源于Windows Kernel中的边界错误。本地用户可通过运行特殊构造的程序触发内存损坏，从而在系统上以提升的权限执行任意代码。
