**0x01 漏洞描述**

  

Apache Tomcat是美国阿帕奇（Apache）基金会的一款轻量级Web应用服务器。该程序实现了对Servlet和JavaServer Page（JSP）的支持。

![](../Images/c3f474d070a0d0e95fa3cc7d31b6da38.png)

360漏洞云监测到Apache Tomcat存在请求走私漏洞（CVE-2021-33037）。该漏洞源于未能正确地解析HTTP传输编码请求头，在与反向代理一起使用时，可能引起请求走私。  
  

**0x02 危害等级**

  

高危

  

**0x03 影响版本**

  

Apache Tomcat 10.0.0-M1 - 10.0.6

Apache Tomcat 9.0.0.M1 - 9.0.46

Apache Tomcat 8.5.0 - 8.5.66

  

**0x04 修复版本**

  

Apache Tomcat 10.0.7   
Apache Tomcat 9.0.48   
Apache Tomcat 8.5.68 

  

**0x05 修复建议**

  

厂商已发布升级修复漏洞，用户请尽快更新至安全版本。
