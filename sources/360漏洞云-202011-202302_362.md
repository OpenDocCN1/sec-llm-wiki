**0x01 漏洞描述**

  

Microsoft SharePoint是美国微软（Microsoft）公司的一套企业业务协作平台。该平台用于对业务信息进行整合，并能够共享工作、与他人协同工作、组织项目和工作组、搜索人员和信息。

![](../Images/042cc5ed0ded525e28d475a488f3cec8.png)

  

微软在2021年5月的安全更新中修复了一处SharePoint的远程代码执行漏洞（CVE-2021-28474），该漏洞源于输入验证不当，经认证的远程攻击者可通过发送特殊构造的请求触发漏洞，在目标系统上执行任意代码。

2021年7月9日，360漏洞云监测到安全研究人员公开了该漏洞的POC，并于第一时间成功复现了该漏洞。

  

**0x02 危害等级**

  

严重：8.8

  

**0x03 漏洞复现**

  
360漏洞云已成功复现该漏洞，演示如下：

![](../Images/f865827e4e9df216908fd2d34bdea5b5.png)

完整POC代码已在360漏洞云情报平台发布，360漏洞云情报平台用户可通过平台下载进行安全检测。  

**0x04 影响版本**

  

Microsoft SharePoint Foundation 2013 Service Pack 1

Microsoft SharePoint Server 2019

Microsoft SharePoint Enterprise Server 2016

  

**0x05 修复建议**

  

微软已于2021年5月11日发布补丁修复该漏洞，用户请立即下载安装相应的补丁程序：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-28474
