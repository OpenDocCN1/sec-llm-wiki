**0x01 漏洞描述**

  

Microsoft Windows Defender是美国微软公司的一款防病毒软件，具有病毒和威胁防护、账户保护，防火墙与网络保护，应用和浏览器控制等功能。

![](../Images/b88d23e6bc94f397562aa246fa40e411.png)

微软在2021年6月的安全更新中修复了一处Windows Defender远程代码执行漏洞（CVE-2021-31985），该漏洞源于输入验证不当，远程攻击者可利用该漏洞实现任意代码执行。

2021年7月8日，360漏洞云监测到Google Project Zero发布了该漏洞的细节。Window Defender在解析asprotect文件格式时采用了虚拟执行的方式，但由于解析过程中Defender以SYSTEM权限运行，并且对加载的DLL未进行严格验证，导致攻击者可利用该漏洞实现远程代码执行。攻击者只需通过邮件发送特殊构造的文件到用户计算机上，无需用户打开，即可接管用户计算机。

  

**0x02 危害等级**

  

严重：8.8

360漏洞云已成功复现了该漏洞，演示如下：
