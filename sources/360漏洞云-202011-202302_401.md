**0x01 漏洞描述**

  

Cisco Anyconnect Secure Mobility Client是美国思科（Cisco）公司的一款用于安全连接的VPN客户端软件。

![](../Images/d31bdf6aa2ee0ef9fc938a6431f2a1c2.png)

2021年6月18日，360漏洞云监测到Cisco AnyConnect Secure Mobility Client for Windows存在DLL劫持漏洞（CVE-2021-1567），该漏洞源于对加载的DLL文件的签名验证过程中的一个竞争条件。如果AnyConnect客户端安装有VPN Posture (HostScan) 模块，经过授权的本地攻击者可利用该漏洞放置一个特殊构造的DLL文件到系统中，并以系统权限执行任意代码。

  

**0x02 危害等级**

  

高危：7.0

  

**0x03 影响版本**

  

Cisco AnyConnect Secure Mobility Client for Windows <4.10.01075

  

**0x04 修复版本**

  

Cisco AnyConnect Secure Mobility Client for Windows 4.10.01075

  

**0x05 修复建议**

  

厂商已发布软件更新修复该漏洞，受影响的用户请尽快更新至安全版本（4.10.01075）。
