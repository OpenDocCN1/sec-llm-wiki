**0x01 漏洞描述**

  

今天，微软发布了2021年6月的安全更新。此次的安全更新共修复了50个漏洞，其中包括6个在野利用的零日漏洞。

  

![](../Images/483618be42716c911b39c475088266ac.png)

**Microsoft Enhanced Cryptographic Provider 特权提升漏洞**  

*   CVE: CVE-2021-31199，CVE-2021-31201
    
*   CVSS: 3.0 5.2 / 4.8
    
*   组件: Microsoft Enhanced Cryptographic Provider 
    
*   漏洞类型: 特权提升
    
*   简述: 该漏洞是Windows加密程序中的一处本地权限提升漏洞，微软已经发现有攻击者将其与Adobe Reader CVE-2021-28550组合进行远程攻击。
    
*   在野利用：是
    

  

# **Windows MSHTML Platform远程代码执行漏洞**

*   # CVE: CVE-2021-33742
    
*   CVSS: 3.0 7.5 / 7.0
    
*   组件: Windows MSHTML Platform
    
*   漏洞类型: 远程代码执行
    
*   简述: 该漏洞是Windows IE浏览器使用的渲染引擎 Trident中的一处远程代码执行漏洞，攻击者通过诱导用户访问特殊构建的WEB页面，即可控制用户的计算机设备。
    
*   在野利用：是
    

  

# **Microsoft DWM 核心库权限提升漏洞**

*   # CVE: CVE-2021-33739
    
*   CVSS: 3.0 8.4 / 7.8
    
*   组件: Microsoft DWM 核心库
    
*   漏洞类型: 特权提升
    
*   简述: 该漏洞是Windows Desktop Window Manager(DWM)组件中的一处权限提升漏洞，攻击者通过诱导用户打开特殊构造的EXE可执行文件，即可获得管理员权限，控制用户的计算机设备。
    
*   在野利用：是
    

  

# **Windows NTFS 特权提升漏洞**

*   # CVE: CVE-2021-31956
    
*   CVSS: 3.0 7.8 / 7.2
    
*   组件: Windows NTFS
    
*   漏洞类型: 特权提升
    
*   简述: 该漏洞是Windows NTFS文件系统组件中的一处权限提升漏洞，攻击者通过诱导用户打开特殊构造的EXE可执行文件，即可获得管理员权限，控制用户的计算机设备。
    
*   在野利用：是
    

  

# **Windows 内核信息泄露漏洞**

*   # CVE: CVE-2021-31955
    
*   CVSS: 3.0 5.5 / 5.1
    
*   组件: Windows 内核
    
*   漏洞类型: 信息泄露
    
*   简述: 该漏洞是Windows内核组件中的一处信息泄露漏洞，可泄露Windows内核中的敏感信息，微软已经发现有攻击者将其与CVE-2021-31956组合进行攻击。
    
*   在野利用：是
