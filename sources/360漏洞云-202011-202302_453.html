0x01 漏洞简介


Exchange Server 是微软公司的一套电子邮件服务组件，是个消息与协作系统。 

2021年3月3日，360漏洞云监测到微软发布了Exchange 多个高危漏洞的通告，CVE编号包括CVE-2021-26855,CVE-2021-26857,CVE-2021-26858,CVE-2021-27065等。



0x02 漏洞详情


CVE-2021-27078 Microsoft Exchange Server 远程命令执行漏洞

漏洞描述：攻击者通过该漏洞可以在Exchange服务器上执行任意操作系统命令。

危害等级：9.1 | 严重


CVE-2021-27065 Microsoft Exchange Server 任意文件写入漏洞

漏洞描述：该漏洞是Exchange进行身份验证后的漏洞，如果攻击者通过了Exchange服务器身份验证，他们可以利用该漏洞将文件写入服务器上的任何路径。并且该漏洞还可以和CVE-2021-26855服务端请求伪造漏洞进行组合利用。

危害等级：7.8 | 高危


CVE-2021-26858 Microsoft Exchange Server 任意文件写入漏洞

漏洞描述：该漏洞是Exchange进行身份验证后的漏洞，如果攻击者通过了Exchange服务器身份验证，他们可以利用该漏洞将文件写入服务器上的任何路径。并且该漏洞还可以和CVE-2021-26855服务端请求伪造漏洞进行组合利用。

危害等级：7.8 | 高危


CVE-2021-26857 Microsoft Exchange Server 反序列化漏洞

漏洞描述：拥有管理员权限的攻击者可以在Exchange服务器上以SYSTEM身份运行代码。

危害等级：7.8 | 高危


CVE-2021-26855 Microsoft Exchange Server 服务端请求伪造漏洞

漏洞描述：攻击者能够发送任意HTTP请求并通过Exchange Server进行身份验证。

危害等级：9.1 | 严重


CVE-2021-26854 Microsoft Exchange Server 远程命令执行漏洞

漏洞描述：攻击者通过该漏洞可以在Exchange服务器上执行任意操作系统命令。

危害等级：6.6 | 中危


CVE-2021-26412 Microsoft Exchange Server 远程命令执行漏洞

漏洞描述：攻击者通过该漏洞可以在Exchange服务器上执行任意操作系统命令。

危害等级：9.1 | 严重

Microsoft Exchange Server 2016

0x04 修复建议


应及时进行Microsoft Windows版本更新并且保持Windows自动更新开启。


对于其他原因无法开启Windows自动更新的，请访问地址：

https://msrc.microsoft.com/update-guide/vulnerability/{CVE编号}

获取漏洞补丁KB编号。


此次多个漏洞共涉及两个漏洞补丁KB编号，KB5000871，KB5000978。


然后访问地址：

https://www.catalog.update.microsoft.com/Home.aspx

搜索下载对应的补丁安装使用。


360漏洞云强烈建议将Windows Update开启自动更新。
