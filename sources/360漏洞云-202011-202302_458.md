**0x01 漏洞简介**

  

VMware（威睿） 是全球桌面到数据中心虚拟化解决方案的领导厂商。  

2021年2月24日，**360漏洞云**监测到**VMware官方**发布了多个高危漏洞的通告，CVE编号分别是**CVE-2021-21972**，**CVE-2021-21973**，**CVE-2021-21974**。

**360漏洞云已分析**CVE-2021-21972**漏洞并完成POC输出。**

![](../Images/457bbc14dc0fe2aa2d477890a1f0895a.png)

  

  

**0x02 漏洞详情**

  

CVE-2021-21972：**vSphere Client 远程执行代码漏洞**

危害等级：9.8 | **严重**

CVE-2021-21973：**vSphere Client SSRF漏洞**

危害等级：5.3 | **中危**

CVE-2021-21974：**ESXi OpenSLP 堆溢出漏洞**

危害等级：8.8 | **高危**

  

  

**0x03 漏洞影响版本**

  

CVE-2021-21972：**vSphere Client 远程执行代码漏洞**

受影响版本：VMware vCenter Server 7.0，6.7，6.5，VMware Cloud Foundation（Cloud Foundation）4.X，3.X

CVE-2021-21973：**vSphere Client SSRF漏洞**

受影响版本：VMware vCenter Server 7.0，6.7，6.5，VMware Cloud Foundation（vCenter Server）4.X，3.X

CVE-2021-21974：**ESXi OpenSLP 堆溢出漏洞**

受影响版本：VMware ESXi 7.0，6.7，6.5，VMware Cloud Foundation（ESXi）4.X，3.X

  

  

  

**0x04 修复建议**

  

CVE-2021-21972：**vSphere Client 远程执行代码漏洞**

已修复版本：VMware vCenter Server 7.0 U1c，6.7 U3l，6.5 U3n，VMware Cloud Foundation 4.2，3.10.1.2

CVE-2021-21973：**vSphere Client SSRF漏洞**

已修复版本：VMware vCenter Server 7.0 U1c，6.7 U3l，6.5 U3n，VMware Cloud Foundation 4.2，3.10.1.2

CVE-2021-21974：**ESXi OpenSLP 堆溢出漏洞**

已修复版本：VMware ESXi ESXi70U1c-17325551，ESXi670-202102401-SG，ESXi650-202102101-SG，VMware Cloud Foundation 4.2

**360漏洞云强烈建议：**  

将相关产品升级到已修复版本。
