# 漏洞情报 | Sudo 堆缓冲区溢出漏洞（CVE-2021-3156）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5MTc5Mzk2OA==&mid=2247496597&idx=1&sn=c38483922fc8741f0feeb2e2a9a7c419&chksm=cfc554caf8b2dddc709bc8162dc2c0424ca9ebd1ac280294f24e9de2116af554a4effdaa27a3&scene=126&sessionid=1681271886#rd](http://mp.weixin.qq.com/s?__biz=Mzg5MTc5Mzk2OA==&mid=2247496597&idx=1&sn=c38483922fc8741f0feeb2e2a9a7c419&chksm=cfc554caf8b2dddc709bc8162dc2c0424ca9ebd1ac280294f24e9de2116af554a4effdaa27a3&scene=126&sessionid=1681271886#rd)

![](../Images/8d0e5bb1673d1c9fd4bbbe7e7d3a3a86.png)

  

  

**0x01 组件介绍**

  

Sudo 是一种程序，用于类Unix操作系统如BSD，Mac OS X，以及GNU/Linux以允许用户透过安全的方式使用特殊的权限运行程序 （通常为系统的超级用户）。

  

  

**0x02 漏洞描述**

  

近日，**360漏洞云**监测到Sudo官方发布了关于Sudo的一则安全更新，Sudo 存在基于堆的**缓冲区溢出漏洞**，该漏洞可以导致普通用户在默认配置的sudo主机上**获取root权限**。

  

  

**0x03 受影响版本**

  

1.9.0 <= Sudo <= 1.9.5p1 所有稳定版（默认配置） 

1.8.2 <= Sudo <= 1.8.31p2 所有老版本

  

  

**0x04 修复建议**

  

  

360漏洞云强烈建议用户升级到1.18及以上版本，并且时刻关注官方信息。

下载地址：

https://github.com/apache/nutch/releases
