0x01 漏洞描述


SonicWall SSL-VPN是SonicWall旗下的VPN软件。近日，360漏洞云监测到国外某安全研究员披露了SonicWall SSL-VPN历史版本的远程命令执行漏洞，由于使用了老旧的Linux内核与HTTP CGI程序，导致该程序在处理http请求时，无法正确解析http header，从而攻击者可以通过注入命令轻松获得nobody用户的控制权限。



0x02 漏洞影响版本


Sonic SMA < 8.0.0.4

0x04 临时防护方案


针对 http header 进行检测

可能存在的特征字符串如下() { :; };

使用 nginx 反向代理对 header 进行强制过滤

location /cgi-bin/jarrewrite.sh { proxy_pass http://your-ssl-vpn:your-ssl-vpn-port$request_uri; proxy_set_header host $http_host; proxy_set_header user-agent "sonicwall ssl-vpn rec fix";}



0x05 正式防护方案


360漏洞云强烈建议：

将Sonic SMA升级到安全版本8.0.0.4及以上版本。该漏洞属于历史漏洞的POC公开利用，官方已于2015年修复了该漏洞，请相关用户检测自有资产，是否在受影响范围版本内。

该产品属于商业产品，建议相关用户联系官方协助升级。
