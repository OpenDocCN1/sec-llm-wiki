0x01 漏洞描述


WebLogic是美国Oracle公司出品的一个application server，确切的说是一个基于JAVAEE架构的中间件，WebLogic是用于开发、集成、部署和管理大型分布式Web应用、网络应用和数据库应用的Java应用服务器。 

近日，360漏洞云监测到Oracle官方发布了关于WebLogic Server的远程代码执行漏洞的通告(CVE-2021-2109)，攻击者可通过LDAP协议方式实现JNDI注入，进而远程命令执行。



0x02 漏洞影响范围


WebLogic Server 10.3.6.0.0 

WebLogic Server 12.1.3.0.0 

WebLogic Server 12.2.1.3.0 

WebLogic Server 12.2.1.4.0 

WebLogic Server 14.1.1.0.0



0x03 漏洞评分


漏洞评分：CVSS:3.1/AV:N/AC:L/PR:H/UI:N/S:U/C:H/I:H/A:H

危害级别：高危



0x04 修复建议


1、由于是通过JNDI注入进行远程命令执行，所以受到JDK版本的影响，建议升级WebLogic Server运行环境的JDK版本 

2、官方已经发布漏洞修复更新，建议及时更新官方补丁；

3、该漏洞需要WebLogic管理权限才能触发，建议定期修改WebLogic密码；

4、不方便更新的用户，建议临时关闭/console/console.portal对外访问
