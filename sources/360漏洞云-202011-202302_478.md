**0x01组件介绍**

  

![](../Images/439802b0ba299f530da58545febda1b5.png)

**JumpServer **是全球首款完全开源的堡垒机, 使用 GNU GPL v2.0 开源协议, 是符合 4A 的专业运维审计系统。 使用 Python / Django 进行开发, 遵循 Web 2.0 规范, 配备了业界领先的 Web Terminal 解决方案, 交互界面美观、用户体验好。 采纳分布式架构, 支持多机房跨区域部署, 中心节点提供 API, 各机房部署登录节点, 可横向扩展、无并发访问限制。

  

  

**0x02漏洞简述**

  

近日，**360漏洞云**监测到开源堡垒机JumpServer厂商发布重要通知，发现一处远程命令执行漏洞。攻击者可获取目标服务器日志敏感信息，或者执行任意命令。

  

  

**0x03漏洞影响范围**

  

JumpServer < v2.6.2

JumpServer < v2.5.4 

JumpServer < v2.4.5

JumpServer = v1.5.9

  

  

**0x04漏洞详情**

  

由于**JumpServer**程序中连接websocket的接口未做授权限制，导致攻击者可**构造恶意请求获取服务器敏感信息，通过敏感信息中的相关参数，可构造请求获取相应token**，进而可通过相关API操作来执行任意命令。

  

  

**0x05通用修复建议**

  

当前安全版本为：

**JumpServer堡垒机＞=v2.6.2版本**

**JumpServer堡垒机＞=v2.5.4版本**

**JumpServer堡垒机＞=v2.4.5版本**

建议相关用户升级到安全版本  

**下载地址：**

https://github.com/jumpserver/jumpserver/releases
