0x01漏洞简述


近日，360漏洞云监测到Apache Flink官方发布了安全更新，修复了两个高危漏洞。漏洞编号分别为：CVE-2020-17518和CVE-2020-17519，漏洞等级：高危。



0x02漏洞影响范围


Apache Flink 1.5.1 ~ 1.11.2



0x03安全版本


Apache Flink 1.12.0 

Apache Flink 1.11.3



0x04漏洞详情


Apache Flink是由Apache软件基金会开发的开源流处理框架，其核心是用Java和Scala编写的分布式流式的数据流执行引擎，其针对数据流的分布式计算提供了数据分布、数据通信以及容错机制等功能。在Apache Flink 1.5.1版本中引入了REST API。


CVE-2020-17518    任意文件写入漏洞

Flink 1.5.1 引入了REST处理程序，该处理程序允许攻击者通过恶意修改HTTP头写入文件到本地系统任意位置，从而实现任意文件写入。


CVE-2020-17519    任意文件读取漏洞

Apache Flink 1.11.0中引入了一项更新，该更新在1.11.1及更高的版本和1.11.2中发布。该项更新允许攻击者通过JobManager进程的REST API读取JobManager本地文件系统上的任何文件(JobManager进程权限所允许的范围)



0x05通用修复建议


当前安全版本为Apache Flink 1.12.0 1.11.3，建议相关用户升级Apache Flink到安全版本。

https://flink.apache.org/downloads.html
