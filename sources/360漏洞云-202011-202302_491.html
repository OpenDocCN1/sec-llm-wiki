0x01漏洞简述


2020年12月9日，360漏洞云监测到微软官方发布了多个安全风险通告，事件等级为严重级别。其中有6个高危漏洞由360公司Vulcan团队发现并提交，分别为：CVE-2020-17089、CVE-2020-17117-A、CVE-2020-17120、CVE-2020-17132、CVE-2020-17141、CVE-2020-17143。


此次安全更新一共发布了58个漏洞补丁，漏洞影响范围大，360漏洞云提醒广大用户，及时更新Windows Update补丁，做好资产自查预防工作，以免受到黑客入侵攻击。



0x02漏洞影响产品


此次漏洞影响范围主要包括Windows Exchange、office办公套件、IE/Edge浏览器、Hyper-V、Visual Studio、Microsoft SharePoint 、Windows操作系统等产品和组件。



0x03漏洞详情


CVE-2020-17089 Microsoft SharePoint 特权提升漏洞

漏洞成因:

CVE-2020-17089此漏洞是由于攻击者可以将DataFormParameter参数绑定到ParametersBinding类型而造成的。这些类型可以通过Location属性从请求或服务器中提取到。


漏洞影响:经过身份验证的攻击者可以通过单击精心构建的链接欺骗用户泄漏RTFA和FedAuthcookie来获得eop。


漏洞影响范围：

Microsoft SharePoint 2010 SP2/2013 SP1/2016/2019


官方漏洞链接：

https://msrc.microsoft.com/update-guide/en-us/vulnerability/CVE-2020-17089


CVE-2020-17117 Microsoft Exchange 远程代码执行漏洞


漏洞成因：

CVE-2020-17117漏洞是由于Exchange管理控制台传输规则导入解析而引起的远程代码执行漏洞。


漏洞影响范围：

Microsoft Microsoft Exchange Server 2013 CU23/2016 CU17/2016 CU18/2019 CU6/2019 CU7


利用效果：



官方漏洞链接：

https://msrc.microsoft.com/update-guide/en-us/vulnerability/CVE-2020-17117


CVE-2020-17120 Microsoft SharePoint 信息泄露漏洞


漏洞影响：

漏洞成功利用后，会泄露数据库中一些受限的表数据。


漏洞影响范围：

CVE-2020-17141 Microsoft Exchange 远程代码执行漏洞


漏洞成因：

MicrosoftExchange Server EWS RouteComplaint ParseComplaintData 外部实体注入漏洞。该漏洞是由于对cmdlet参数的验证不正确而导致的，某域用户可以通过精心构造的语句对Exchange发起请求，从而导致信息泄露或拒绝服务。该漏洞也可能导致在云实例或云元数据中导致远程代码执行，也可能在本地部署中导致远程代码执行。


漏洞影响范围：

Microsoft Exchange Server 2016 、2019


官方漏洞链接：

https://msrc.microsoft.com/update-guide/en-us/vulnerability/CVE-2020-17141


POC效果：



CVE-2020-17143 Microsoft Exchange 信息泄露漏洞


漏洞成因：

MicrosoftExchange OneDriveProUtilities GetWacUrl 外部注入漏洞。Exchange在处理GetWacIframeUrlForOneDrive服务命令时存在特定缺陷，该问题是由于没有对用户提交的XML进行有效的校验造成的，攻击者可以利用该漏洞获取Exchange的版本等安装信息。攻击此漏洞需要一定的身份验证。


漏洞影响范围: 

Microsoft Exchange Server 2013、2016 、2019


官方漏洞链接：

https://msrc.microsoft.com/update-guide/en-us/vulnerability/CVE-2020-17143



0x04修复建议


应及时进行Microsoft Windows版本更新并且保持Windows自动更新开启。


对于其他原因无法开启Windows自动更新的，请访问地址：

https://msrc.microsoft.com/update-guide/vulnerability/{CVE编号}获取漏洞补丁KB编号。


然后访问地址：

https://www.catalog.update.microsoft.com/Home.aspx


搜索下载对应的补丁安装使用。


强烈建议将Windows update开启自动更新。
