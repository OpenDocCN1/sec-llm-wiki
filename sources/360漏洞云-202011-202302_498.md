**0x01漏洞简述**

  

VMware是全球云基础架构和移动商务解决方案厂商，提供基于VMware的解决方案，企业通过数据中心改造和公有云整合业务，借助企业安全转型维系客户信任，实现任意云端和设备上运行、管理、连接及保护任意应用。

  

360Vulcan团队的Xiao Wei 和 Tianwen Tang 向VMware报告了两个严重漏洞（CVE-2020-4004、CVE-2020-4005），360漏洞云监测到2020年11月19日VMware官方发布了漏洞的部分产品解决方案(部分产品的补丁还在等待中，360漏洞云将持续关注漏洞补丁动态)。

  

  

**0x02漏洞所属厂商**

  

VMware

  

  

**0x03漏洞影响产品**

  

**VMware ESXi**

**VMware Workstation Pro / Player (Workstation)**

**VMware Fusion Pro / Fusion (Fusion)**

**VMware CloudFoundation (ESXi)**

  

  

**0x04漏洞描述**

  

**CVE-2020-4004（CVSS:9.3）**

VMware ESXi，Workstation和Fusion在XHCI USB控制器中包含一个UAF（Use-After-Free）漏洞，虚拟机中具有本地管理员权限的用户利用该漏洞后，可以造成虚拟机逃逸。

  

**影响范围：**

VMware ESXi :

7.0: < ESXi70U1b-17168206

6.7: < ESXi670-202011101-SG,

6.5: < ESXi650-202011301-SG

VMware Workstation:

15.x: < 15.5.7

VMware Fusion:

11.x: < 11.5.7

  

**CVE-2020-4005（CVSS:8.8）**

CVE-2020-4005漏洞是一个特权提升漏洞，该漏洞与上述CVE-2020-4004漏洞一起使用时可以在ESXi上获得完整的root权限。

  

**影响范围**

VMware ESXi ：

7.0: < ESXi70U1b-17168206

6.7: < ESXi670-202011101-SG

6.5: < ESXi650-202011301-SG

  

  

**0x05临时防护方案**

  

CVE-2020-4005 临时解决方案：移除XHCI（USB 3.x）控制器
