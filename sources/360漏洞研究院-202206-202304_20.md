**在微软2023年2月的补丁星期二中，安全更新修复了3个被活跃利用的0day漏洞和总共78个漏洞，其中含9个“严重”漏洞。**

****在这78个漏洞中，含有12个提权漏洞，2个安全功能绕过漏洞，38个远程代码执行漏洞，8个信息泄露漏洞，10个拒绝服务漏洞，8个欺骗漏洞。******此计数不包括本月早些时候修复的3个Microsoft Edge漏洞。**

  
  

**0day漏洞三重奏**

**CVE-2023-21823**

这是由Mandiant的Dhanesh Kizhakkinan、Genwei Jiang和Dhanesh Kizhakkinan发现的Windows Graphics Component**远程代码执行****漏洞。**

微软表示，这个远程代码执行漏洞允许攻击者以**系统权限**执行任意代码。

此安全更新将通过Microsoft Store而不是Windows Update推送给用户。因此，对于那些在Microsoft Store中禁用自动更新的用户，微软不会自动向他们推送更新。

**CVE-2023-21715**

这是微软的Hidetake Jo发现的Microsoft Publisher**安全特性绕过漏洞**。

这个0day漏洞存在于Microsoft Publisher中，允许特制文档绕过，阻止不受信任或恶意文件的Office宏指令。

利用此漏洞可以允许恶意Publisher文档中的宏运行，且无需事先警告用户。

微软解释说，“攻击本身是由对目标系统进行身份验证的用户在本地执行的。”

“经过身份验证的攻击者可以通过社会工程攻击来引导用户从网站下载并打开特制文件来利用此漏洞，这可能会导致对受害者计算机的本地攻击。”

**CVE-2023-23376**

这是微软威胁情报中心 (MSTIC) 和微软安全响应中心 (MSRC) 发现的 Windows Common Log File System Driver**特权提升漏洞**。

微软表示“攻击者可利用此漏洞获取**系统权限**。”
