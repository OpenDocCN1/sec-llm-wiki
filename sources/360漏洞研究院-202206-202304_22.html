最近一款人工智能聊天机器人ChatGPT的出现吸引了大众的眼球，它也正在带来全新的网络攻击方向和风险。黑客很容易绕过ChatGPT对创建非法内容的限制。


研究人员表示，绕过 ChatGPT 限制的方法是使用OpenAI的GPT-3模型（称为text-davinci-003)。黑客们正在利用它来出售允许人们创建恶意软件和钓鱼电子邮件的服务。




什么是ChatGPT？

ChatGPT是一款AI聊天机器人，它使用AI技术以模拟人类输出的方式回答问题和执行任务。用户可以用它来创建文档、编写基本的计算机代码和做其他事情。ChatGPT会主动阻止生成潜在非法内容的请求。如果用户要求ChatGPT编写代码，用于从被入侵的设备中窃取数据或制作钓鱼电子邮件，则将被ChatGPT拒绝，并回复此类内容是“非法、不道德和有害的”。

打开潘多拉魔盒

据安全公司 Check Point Research 的研究人员报道，黑客们已经找到了一种绕过这些限制的简单方法，并利用它在地下犯罪论坛中出售非法服务。该技术通过使用 OpenAI 的 GPT-3 模型之一的应用程序编程接口（称为 text-davinci-003）而不是 ChatGPT 来工作。ChatGPT 是专门为聊天机器人应用程序设计的 GPT-3 模型的变体。OpenAI 为开发人员提供了 text-davinci-003 API 和其他模型 API，以便他们可以将 AI 机器人集成到他们的应用程序中。但事实证明，API 版本并没有对恶意内容实施限制。 
研究人员写道：“当前版本的 OpenAI API 被外部应用程序使用（例如，将OpenAI的GPT-3模型整合到Telegram频道中），并且几乎没有采取任何反滥用措施。因此，它允许恶意内容的创建，例如网络钓鱼电子邮件和恶意代码，而不受ChatGPT 在其用户界面上设置的限制或障碍。”
例如，一个论坛中的用户现在正在出售一种结合了 API 和 Telegram 消息传递应用程序的服务。前 20 个查询是免费的。之后，用户每 100 次查询需支付 5.5 美元。
使用ChatGPT生成恶意内容的Telegram机器人的广告
Check Point 的研究人员测试了text-davinci-003API的工作情况。结果是：一封钓鱼电子邮件和一个脚本，该脚本会从被感染的计算机上窃取PDF文档，并通过FTP将它们发送给攻击者。
Telegram机器人生成的网络钓鱼
 Telegram机器人生成的恶意软件
与此同时，论坛的其他参与者正在发布使用text-davinci-003免费生成恶意内容的代码。一位用户写道：“这里有一个小bash脚本，可以帮助您绕过ChatGPT的限制，以便将其用于任何您想要的用途，包括恶意软件开发。

用于绕过ChatGPT限制的bash脚本

上个月，Check Point研究人员记录了ChatGPT如何被用于编写恶意软件和网络钓鱼消息。
Check Point研究员谢尔盖·希凯维奇（Sergey Shykevich）在一封电子邮件中写道：“在12月至1月期间，使用 ChatGPT web 用户界面生成恶意软件和钓鱼邮件仍然很容易（大多数情况下只需基本的迭代就足够了），根据网络罪犯的聊天记录，我们假设我们展示的大多数示例都是使用web UI创建的。最近，ChatGPT的反滥用机制似乎有了显著改进，所以现在网络犯罪分子转向了限制更少的API。”
媒体询问了 ChatGPT 的开发公司是否知道这项研究结果，或者是否计划修改API接口。开发 ChatGPT 的 OpenAI 是一家总部位于旧金山的公司，目前，该公司的代表并没有对此问题进行回复。
恶意软件和钓鱼邮件的产生，只是 ChatGPT 打开潘多拉魔盒的一种方式，它可以用有害的内容轰炸世界。当然，同样产生有害的、不道德的或非法内容的能力，也可以被防御者用来开发检测和阻止这些内容的方法，但我们还尚不清楚良性使用是否能够跟上恶意使用的步伐。
