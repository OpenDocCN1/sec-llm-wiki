Part.1 会议介绍


HITBSecConf将在春天回到阿姆斯特丹！HITBSecConf是目前欧洲知名度最高、影响力最大的信息安全会议。2003年首次举办，今年已经是第21届。峰会每年都会吸引全球顶尖的信息安全人才聚集阿姆斯特丹，共同探讨最为前沿的信息安全攻防技术。

HITBSecConf通常包括两天的培训和为期两天的会议演讲，全球顶尖的安全研究专家，科研学术人员和企业代表将会受邀来发表议题演讲和分享研究成果。本次会议按照计划将会是一个面对面的会议。会议将讨论新的和以前从未见过的攻击和防御方法的演讲，这比以前多次讨论过的主题会更有趣。 


Part.2 会议主题


1. 0days和新的攻击技术
2. 新的漏洞利用缓解技术
3. 网络协议、分析和攻击
4. 硬件设备的侧信道分析
5. 恶意代码/病毒/恶意软件分析
6. 基于硬件的攻击和逆向工程
7. Windows / Linux / OS X / *NIX 安全漏洞
8. 人工智能/机器学习的漏洞
9. NFC、WLAN、GPS、卫星、RFID、蓝牙和其他无线技术
10. 任何有趣的攻防技术
