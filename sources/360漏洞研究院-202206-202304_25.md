**会议地点：阿姆斯特丹，荷兰**

**会议时间：2023.4.20-2023.4.21**

  

  

***Part.1 会议介绍***

  

HITBSecConf将在春天回到阿姆斯特丹！HITBSecConf是目前欧洲知名度最高、影响力最大的信息安全会议。2003年首次举办，今年已经是第21届。峰会每年都会吸引全球顶尖的信息安全人才聚集阿姆斯特丹，共同探讨最为前沿的信息安全攻防技术。  
HITBSecConf通常包括两天的培训和为期两天的会议演讲，全球顶尖的安全研究专家，科研学术人员和企业代表将会受邀来发表议题演讲和分享研究成果。本次会议按照计划将会是一个面对面的会议。会议将讨论新的和以前从未见过的攻击和防御方法的演讲，这比以前多次讨论过的主题会更有趣。   

  

***Part.2 会议主题***

  

1\. 0days和新的攻击技术2\. 新的漏洞利用缓解技术3\. 网络协议、分析和攻击4\. 硬件设备的侧信道分析5\. 恶意代码/病毒/恶意软件分析6\. 基于硬件的攻击和逆向工程7\. Windows / Linux / OS X / \*NIX 安全漏洞8\. 人工智能/机器学习的漏洞9\. NFC、WLAN、GPS、卫星、RFID、蓝牙和其他无线技术10\. 任何有趣的攻防技术  

  

  

***Part.3 CFP 截止日期***

  

2023.1.31 ，(GMT+01:00) 阿姆斯特丹
