Viper简介

————————————————

一个采用图形化界面，用户使用浏览器即可登录协同操作的内网神器。集成文件管理、内网路由、端口转发、命令终端、msf等功能。包含持久化、权限提升、防御绕过、信息收集、横向移动等N+模块。

PS：还有免杀亲测好用（￣▽￣）d



Viper安装

————————————————

准备linux的虚拟机或VPS，建议直接在root用户下安装，sudo可能会出现未知错误。


更新

yum update


安装docker

curl -sSL https://get.daocloud.io/docker | shservice docker start


安装docker-compose

curl -L https://get.daocloud.io/docker/compose/releases/download/1.25.5/docker-compose-`uname -s`-`uname -m` > /usr/bin/docker-composechmod +x /usr/bin/docker-compose


如果 VPS 内存小于 2G,需要增加 2G 虚拟内存

PS：若需要与其他工具联动或真实环境打内网，建议内存4G及以上（VPS2G崩好几次。。哭了，很误事的啊喂！）

dd if=/dev/zero of=/root/swapfile2 bs=1M count=2048chmod 0600 /root/swapfile2mkswap /root/swapfile2swapon /root/swapfile2


设置安装目录

export VIPER_DIR=/root/VIPER


执行如下命名生成安装目录,并进入安装目录

mkdir -p $VIPER_DIR && cd $VIPER_DIR


执行如下命令生成docker-compose.yml

tee docker-compose.yml <<-'EOF'version: "3"services:  viper:    image: registry.cn-shenzhen.aliyuncs.com/toys/viper:latest    container_name: viper-c    network_mode: "host"    restart: always    volumes:      - ${PWD}/loot:/root/.msf4/loot      - ${PWD}/db:/root/viper/Docker/db      - ${PWD}/module:/root/viper/Docker/module      - ${PWD}/log:/root/viper/Docker/log      - ${PWD}/nginxconfig:/root/viper/Docker/nginxconfig    command: ["VIPER_PASSWORD"]EOF


设置登录密码

Viper不允许使用默认密码,diypassword替换为自定义密码密码且大于8位

export VIPER_PASSWORD=diypassword


写入密码到docker-compose.yml

sed -i "s/VIPER_PASSWORD/$VIPER_PASSWORD/g" docker-compose.yml


启动Viper

cd $VIPER_DIRdocker-compose up -d（第一次启动用这个命令）


等待系统启动,访问 https://ip:60000登录. 用户名:root 密码:自定义密码

如果你使用VPS部署Viper,请确认VPS的防火墙开放了60000端口及后续监听需要的端口



Viper配置

————————————————

安装Viper并启动

登录Viper所在的服务器执行如下命令

cd /root/VIPER/nginxconfig    # /root/VIPER为viper安装目录chmod 755 gencert.sh./gencert.sh                  # 按照提示运行,牢记密码

需要设置端口、是否双向认证（证书）、证书密码

将 /root/VIPER/nginxconfig/client.pfx 拷贝到本地,双击导入证书到PC即可

重启浏览器(必须关闭chrome浏览器的所有进程,然后重新打开)

访问https://ip:newport 登录



Viper与CS联动

————————————————

环境

——————————

192.168.253.129  受害机  win10

192.168.253.128  cs、viper服务端  kali


CS派生到Viper

——————————

首先准备好一台机器上线cs

在cs与viper中创建监听器，类型与端口需一致

cs中选中已上线机器，右键派生会话选择刚刚新建的监听器

成功上线


Viper派生到CS

——————————

在viper中生成载荷并在受害机中执行上线

点击左边蓝色小箭头找到“迁移权限到CobaltStrick”，参数按照cs监听器中配置填写

成功上线
