由于CS现在被各种AV盯上，自己又不想把大量的时间精力放在免杀上。所以最近突然想搞一个低配版C2，与其说是低配C2，不如说是一个高级一点的Shell反弹工具。现在的渗透习惯非必要情况已经很少使用CS，更多的需求是一个隧道，所以搞一个只支持命令执行和上传下载简单的C2来维持一下内网的权限就可以了。

  

## 0x01 总体设计思路

总体的设计思想是：

控制端：python3

被控端：C#/C++/GO等

通讯协议：https

通讯加密：AES

免杀方式：白加黑/powershell注册表

  

由于功能很简单所以我们可以使用多种语言重写，达到可以同时控制Linux和Windows的目标。出于前期方便测试我这里Client使用C#，由于C#的反射加载很方便，这样后期可以传递我们想要的其他功能。

## 0x02 代码实现

  

参考了大量代码，Server最终选用`SimpleC2_Server`使用的`aiohttp`库来做Web服务，因为本身设计的就是乞丐版C2，所以代码一定要简单，太难了太复杂就不符合我们的乞丐思想，总体的请求路由就是如下这样。

```


from aiohttp import web
```

Demo版本整体代码不过130，众所周知Windows的VPS太贵了，所以130行的PY跑在乞丐版Linux上真的太舒服了。
