![](../Images/b5c040371a8f294cd453d5b024a1b871.png)

我们把详细信息×了看看这个过程调用了那些文件，一般前面参数可能是有我们想要的，没有的话就找找这几个js文件那里有这个关键词，当然可能也有特殊情况。  

![](../Images/84ebdfeb787cc5bdd6c53a2bf1735241.png)

进来我们点左下角的{}格式化代码 然后CTRL+F进行搜索关键词，找到包含sign的关键词，可能有很多个这里就需要一点判断了 ，你可以全部下断点来看断到什么地方，但是有点基础我们基本能看出来是那个地方调用的。

我们判断这里就是调用过程，下好断点 然后操作我们开始的那个功能  

![](../Images/8c4fcd979874786953476d2a1e9f988c.png)

然后F8运行  

![](../Images/2d166779185fc05ad3b0021df26ce0f2.png)

发现我们找到的算法是对的  

```
1.  `e.sign = obejSort_n(e, dgApi.parseTokenData().access_key);`
    
```

简单的看看这个代码，就是调用 `obejSort_n()` 函数传入2个值，其中的e就是我们post 的数据

![](../Images/4960045f8f4c234f463b40c6d120c1c8.png)

`dgApi.parseTokenData().access_key` 就是调用的这个对象的方法，我们看看代码  

```
1.  `var dgApi = {`
    
2.  `    count: 0,`
    
3.  `    totalCount: 5,`
    
4.  `    url: "",`
    
5.  `    loginStatus: !0,`
    
6.  `    newData: Date.parse(new Date) / 1E3,`
    
7.  `    checkLogin: function() {`
    
8.  `        Date.parse(new Date);`
    
9.  `        return "" == getCookie("m_showID") || "" == getCookie("m_access") ? !1 : !0`
    
10.  `    },`
     
11.  `    ajax: function(c) {`
     
12.  `        this.ajaxValue(c)`
     
13.  `    },`
     
14.  `    parseTokenData: function() {`
     
15.  `        try {`
     
16.  `            return JSON.parse(Decrypt(decodeURIComponent(getCookie("m_access"))))`
     
17.  `        } catch (c) {`
     
18.  `            dgApi.catchTokenError()`
     
19.  `        }`
     
20.  `    },`
     
21.  `   ...................................................................`
     
22.  `    },`
     
```

截取部分代码可以看到关键点 `returnJSON.parse(Decrypt(decodeURIComponent(getCookie("m_access"))))` 很明显是获取cookie的m_access的值我们可以在控制台看看

![](../Images/bcf042d6c2f653a7d6984519aa1e493d.png)

最终他获取了我们的access\_key的值来进行加密 。  

我们来梳理一下流程

```
1.  `1. getCookie("m_access") 获取cookies的m_aceess 的值`
    
2.  `2. decodeURIComponent(getCookie("m_access"))  url解密一下`
    
3.  `3. Decrypt(decodeURIComponent(getCookie("m_access"))) 调用 Decrypt函数进行解密`
    
4.  `4. JSON.parse(Decrypt(decodeURIComponent(getCookie("m_access")))) 转为 JSON格式`
    
5.  `5. dgApi.parseTokenData().access_key 获取 access_key的值`
    
6.  `6. obejSort_n(e, dgApi.parseTokenData().access_key); //调用obejSort_n函数对2个值进行加密`
    
```

咳咳 这个网站貌似代码貌似改了，都不用怎么修改代码了 直接完全扣下来就可以了

```
1.  `<script type="text/javascript">`
    
2.  `js文件代码`
    
3.  
    
4.  `document.write(obejSort_n({deduct_switch: "false", timestamp: 1558158967, nonce: "CvlnXj6ZN", show_uid: "200914569"},"3068671e9d86ab8d"))`
    
5.  `</script>`
    
```
