网上都能查到，敲了一遍命令看了看都是什么内容，并做了下笔记方便ctrl c /v。


1.查询操作系统和版本信息

systeminfo | findstr /B /C:"OS Name" /C:"OS Version" 

systeminfo | findstr /B /C:"OS 名称" /C:"OS 版本"

2.查询安装的软件及版本、路径等

1）wmic product get name,version

2）powershell命令

powershell "Get-WmiObject -class win32_product | Select-Object -property name,version"

3.查询本机服务信息

wmic service list brief

4.查询进程列表

1）tasklist

tasklist -v 查看系统进程

2）wmic process list brief

5.查看启动程序信息

wmic startup get command,caption

6.查看计划任务

schtasks /query /fo list /v

7.查看主机开机时间

net statistics workstation

8.查询用户列表

1）本机用户列表

net user

2）本地管理员(通常包含域用户)

net localgroup administrators

3）查询当前在线用户

query user || qwinsta

9.显示所有与本地计算机的会话消息

net session

10.查询端口列表

netstat -ano

11.查看补丁信息

systeminfo

或

wmic qfe get caption,description,hotfixid,installedon

（比较详细，有补丁地址）

12.查看本机共享列表（也可以看到域共享列表）

net share

或

wmic share get name,path,status

13.查询路由表及所有可用的ARP缓存表

route print和arp -a

14.查看防火墙相关

查看防火墙配置：

netsh firewall show config

关闭防火墙：

winserver 2003之前：netsh firewall set opmode disable

winserver 2003之后：netsh advfirewall set allprofiles state off

一般不操作防火墙开关，只需要查看配置即可

修改防火墙配置：

win03及之前版本，允许指定程序全部放行 

netsh firewall add allowedprogram c:\nc.exe "allow nc" enable

win03之后版本，允许指定程序进入 

netsh advfirewall firewall add rule name="pass nc" dir=in action=allow program="C:\nc.exe" 

允许指定程序退出 

netsh advfirewall firewall add rule name="Allow nc" dir=out action=allow program="C:\nc.exe" 

允许3389端口放行 

netsh advfirewall firewall add rule name="Remote Desktop" protocol=TCP dir=in localport=3389 action=allow

（修改防火墙配置的我没有试）

15.查询本机ip段，所在的域等

ipconfig /all

16.查看代理配置情况

reg query "HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Internet Settings"

17.查询远程连接服务

reg query "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\Winstations\RDP-Tcp" /V PortNumber
