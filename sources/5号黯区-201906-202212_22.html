这是一个辅助测试的xss平台，用来做测试写报告蛮好用的
BlueLotus_XSSReceiver
资源地址：
https://github.com/asw3asw/BlueLotus_XSSReceiver


 平台搭建 


1、环境部署

yum install httpd –y

service httpd start

yum install php –y

yum install git –y


2、拉取XSS平台源码

rm -rf /var/www/*

mkdir /var/www/xss

git clone https://github.com/asw3asw/BlueLotus_XSSReceiver.git /var/www/xss/

chmod –R 777 /var/www/xss/


3、配置Apache

mkdir /etc/httpd/conf/vhost

touch /etc/httpd/conf/vhost/httpd-vhosts.conf

编辑httpd-vhosts.conf并写入以下内容保存退出

vim /etc/httpd/conf/vhost/httpd-vhosts.conf

<VirtualHost *:80>       DocumentRoot "/var/www/xss"       DirectoryIndex admin.php</VirtualHost>

修改httpd.conf文件配置

cp/etc/httpd/conf/httpd.conf /etc/httpd/conf/httpd.conf.bak

vi/etc/httpd/conf/httpd.conf



Options ExecCGI FollowSymLinks




在末尾插入
Include /etc/httpd/conf/vhost/httpd-vhosts.conf



#重新载入Apache配置文件

servicehttpd reload


4.安装xss平台

直接访问服务器IP地址，点安装即可
然后修改登录密码和数据加密密码，提交
