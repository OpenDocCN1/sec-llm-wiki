** 前  言 **

  

这是一个辅助测试的xss平台，用来做测试写报告蛮好用的BlueLotus\_XSSReceiver资源地址：https://github.com/asw3asw/BlueLotus\_XSSReceiver  
  
** 平台搭建 **

  

1、环境部署

yum install httpd –y

service httpd start

yum install php –y

yum install git –y

  

2、拉取XSS平台源码

rm -rf /var/www/\*

mkdir /var/www/xss

git clone https://github.com/asw3asw/BlueLotus\_XSSReceiver.git /var/www/xss/

chmod –R 777 /var/www/xss/

  

3、配置Apache

mkdir /etc/httpd/conf/vhost

touch /etc/httpd/conf/vhost/httpd-vhosts.conf

编辑httpd-vhosts.conf并写入以下内容保存退出

vim /etc/httpd/conf/vhost/httpd-vhosts.conf

*   
*   
*   
*   

```
<VirtualHost *:80>       DocumentRoot "/var/www/xss"       DirectoryIndex admin.php</VirtualHost>
```

  
修改httpd.conf文件配置

cp/etc/httpd/conf/httpd.conf /etc/httpd/conf/httpd.conf.bak

vi/etc/httpd/conf/httpd.conf

  

![](../Images/ab64c2e78f019a8f47f424545c440697.png)

  

Options ExecCGI FollowSymLinks

  

![](../Images/13fee8d7c043384d87ab3048af2616da.png)

  

![](../Images/53a1d31d2e5cad086d9e375284d4fa49.png)

  

在末尾插入Include /etc/httpd/conf/vhost/httpd-vhosts.conf  

  

![](../Images/8d4dece3b076c17bccbc179e9bd1b7d3.png)

  

#重新载入Apache配置文件

servicehttpd reload

  

4.安装xss平台

直接访问服务器IP地址，点安装即可然后修改**登录密码**和**数据加密密码**，提交** 平台使用 **  
靶机：pikachu（随便一个xss漏洞靶机）找到xss漏洞的页面，先随便点点，找可控点。在输入框输入1，message就是我们要找的位置。随手试一下<script>alert(/xss/)</script>，发现可以弹窗。接下来就试试xss平台。
