0X01 环境部署
1.安装
curl -s https://get.docker.com/ | sh
或
apt-get update && apt-get install docker.io
2.下载漏洞环境
git clone https://github.com/phith0n/vulhub.git
3.启动
service docker start
4.查看docker信息
docker version
5.安装docker-compose
pip3 install docker-compose
6.启动环境
cd到weblogic的ssrf漏洞目录下
docker-compose build 编译环境
docker-compose up -d 启动环境
7.踩坑
如果遇到Service 'redis' failed to build Exited (139) 错误 #188
将ssrf目录下的Dockerfile文件修改为：


FROM centos:latest

MAINTAINER phithon <root@leavesongs.com>

RUN set -ex \
    && yum -y update \
    && yum -y install make gcc-c++ tcl wget



然后重新编译启动环境
想要在宿主机中进行操作，可以在宿主机与靶机相互通信的前提下添加到docker的路由实现

0X03 常见限制
1.限制为http://www.xxx.com 域名
@绕过
http://www.xxx.com@www.test.com
2.限制请求IP不为内网地址
当不允许ip为内网地址时
短网址绕过
特殊域名绕过
进制转换绕过
3.限制请求只为http协议
302跳转绕过
短地址绕过


0X04 常用绕过方式
1.@
在对@解析域名中，不同的处理函数存在处理差异，如：http://www.aaa.com@www.bbb.com@www.ccc.com在PHP的parse_url中会识别www.ccc.com，而libcurl则识别为www.bbb.com
2.[::]
http://[::]:80/  >>>  http://127.0.0.1
3.短网址
4.利用特殊域名
原理是DNS解析，xip.io可以指向任意域名：
127.0.0.1.xip.io >>> 127.0.0.1
6.利用DNS解析
7.利用进制转换
8.句号
127。0。0。1  >>>  127.0.0.1
9.302跳转
使用http://www.ab173.com/zhanzhang/redirect.php生成302跳转地址
