**0X01 环境部署****1.安装**  
curl -s https://get.docker.com/ | sh或  
apt-get update && apt-get install docker.io**2.下载漏洞环境**git clone https://github.com/phith0n/vulhub.git**3.启动**service docker start**4.查看docker信息**docker version**5.安装docker-compose**  
pip3 install docker-compose**6.启动环境**cd到weblogic的ssrf漏洞目录下  
docker-compose build 编译环境docker-compose up -d 启动环境**7.踩坑**如果遇到Service 'redis' failed to build Exited (139) 错误 #188将ssrf目录下的Dockerfile文件修改为：

`  FROM centos:latest`

****0X03 **常见限制**1.限制为http://www.xxx.com 域名@绕过http://www.xxx.com@www.test.com2.限制请求IP不为内网地址当不允许ip为内网地址时短网址绕过特殊域名绕过进制转换绕过3.限制请求只为http协议302跳转绕过短地址绕过
