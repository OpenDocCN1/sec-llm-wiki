0X01 什么是ssrf
    SSRF为服务器端请求伪造，基于服务端的请求伪造。
    大多是因为服务端提供了从其他服务器应用获取数据的功能且没有对地址和协议等做过滤和限制，导致攻击者利用漏洞伪造服务器端发起请求，从而突破客户端获取不到数据的限制。


    攻击者访问目标机器 ——> 拒绝
    存在ssrf漏洞的服务器访问目标机器 ——> 允许
    攻击者 ——> 存在ssrf漏洞的服务器 ——> 目标机器

0X02 相关函数和协议
1.相关函数
（1）file_get_contents() 将整个文件读入一个字符串
<?php  $url = $_GET['url'];  echo file_get_contents($url);?>

（2）fsockopen() 打开一个网络连接或一个Unix套
接字连接
function GetFile($host,$port,$link) {     $fp = fsockopen($host, intval($port), $errno, $errstr, 30);       if (!$fp) {         echo "$errstr (error number $errno) \n";     } else {         $out = "GET $link HTTP/1.1\r\n";         $out .= "Host: $host\r\n";         $out .= "Connection: Close\r\n\r\n";         $out .= "\r\n";         fwrite($fp, $out);         $contents='';         while (!feof($fp)) {             $contents.= fgets($fp, 1024);         }         fclose($fp);         return $contents;     } }
该函数使用socket（端口）跟服务器建立tcp连接，传
输数据，可以探测端口开放情况。

（3）curl_exec() 执行指定的cURL会话
function curl($url){      $ch = curl_init();    curl_setopt($ch, CURLOPT_URL, $url);    curl_setopt($ch, CURLOPT_HEADER, 0);    curl_exec($ch);    curl_close($ch);}
$url = $_GET['url'];curl($url);

2.协议
（1）file：在有回显的情况下，利用 file 协议可以读取任意内容
（2）dict：泄露安装软件版本信息，查看端口，操作内网redis服务等
（3）gopher：gopher支持发出GET、POST请求：可以先截获get请求包和post请求包，再构造成符合gopher协议的请求。gopher协议是ssrf利用中一个最强大的协议(俗称万能协议)。
（4）http和https：探测内网存活主机

0X03 如何判断ssrf
判断ssrf漏洞基本方法：
例如：  
    1.http://www.xxx.com/**/service?image=http://www.baidu.com/img/xxx.png
通过查看图片地址是不是http://www.baidu.com/img/xxx.png判断，如果是，说明不存在SSRF漏洞。
    2.使用burpsuite等抓包工具来判断是否不是SSRF，SSRF是由服务端发起的请求，因此在加载资源的时候，本地浏览器不应该存在这个请求，应是由服务端发起的。

容易存在ssrf漏洞的场景：
  1. 转码服务
  2. 在线翻译
  3. 通过URL地址加载或下载图片
  4. 图片、文章的收藏功能
  5. 网站采集、网页抓取的地方
  6. 远程加载头像的地方
  7. 可以输入网址的地方和可以输入ip的地方
  8. URL关键字带有：share、wap、url、link、src、source、target、u、3g、display、sourceURl、imageURL、domain ...
