前言

新手小白一定听到过这样的名词——“脚本小子”，说的是那些只会舞弄别人写好的简单工具，而不深究其中原理的菜鸟“黑客”，很多人都告诫过你，千万不要成为“脚本小子”。

    但是，现在的渗透工作不同于几年前，工具偏向专和精。

    大神一定会自己写工具吗？是！

    大神就一定要全都用自己写工具吗？我看未必。

    AWVS，APPScan，Burp suite，这些正版售价不菲的拥有众多大神的大公司大团队做出来的产品，比不上个人做出来的工具，这话你相信么？（就算是那些个人开发的渗透框架，也多多少少借鉴或直接用了一些神器）。

    所以，我想，如果你想要成为大神，不妨先学会站在大神的肩膀上，用上大神开发的工具。

    可是，当小白下载好一些神器，学着教程去运行的时候，很尴尬的问题出现了

    啊，不好意思，我输错命令了！

    嗯，这次没错啊！为什么还是报错呢！啊，我裂开了！

    这是因为，你还没学会部署环境，用Python写的工具就要部署好Python环境，用JAVA写的工具就要部署好JAVA环境，纵观目前的神器，你不部署好环境，就得被迫放弃使用大部分神器（以前的傻瓜式工具包？醒醒，现在已经是0202年了！）。所以，不如在你正式步入学习之旅之前，跟着我一起来看看我们要准备哪些环境吧！

Kali

  如果你比较懒，可以直接使用虚拟机安装Kali，Kali是一个集成了各种渗透环境和工具的linux操作系统，你可以理解为一个虚拟机，自带了工具包。但是，看看下面这张图，你觉得真的有必要吗？

  当然啦，不必要不代表你可以不会。

    HR：“用Kali么？”

    小鹿：“不用，但我会Linux和常见的渗透工具使用。”

    HR os：“不会Kali？看来不太行了。”

    不过呢，小鹿这样就太蠢了，应该这么说“我会，但是不太用，个人觉得太冗余”。

Docker


 虽然Kali不必要，但你一定得试试Docker，晦涩的百科我就不复制了，我的理解是，Docker允许你将要使用的工具或靶场，以及它们运行需要的环境打包上传，当别人需要使用的时候，只需要Pull下来就可以啦，听起来是不是很方便？不过，Docker最好在服务器或虚拟机Linux系统中运行，更方便，也可以避免一些可能发生的冲突。后面会专门出一期推文来讲Docker的一些使用。

Python3


  Python写的神器实在是太多了，SQLMAP啊，XSSTrike啊，现在很多人选择学Python来辅助自己开发渗透工具，所以大家肯定要部署好Python环境的，Python2即将被时代洪流抛弃，大家直接上Python3就好了。


Python 官网：

https://www.python.org/

Python文档下载地址：

https://www.python.org/doc/



JAVA


做web安全，不用Burp suite，恐怕只有搞笑是认真的。要用Burp，JAVA环境必不可少。

    这里简单说一下JDK和JRE的区别：

    JDK是面向开发人员使用的SDK。

    JRE是是面向Java程序的使用者。

    怎么安装？打开JAVA官网，不会装，你再来问我。

JAVA 官网：

https://www.java.com/zh_CN/



PHPStudy


打开PHPStudy官网，你可以看到一串很霸气的字符“让天下没有难配的服务器环境，解放运维”，这就是它的用处，web漏洞挖掘和代码审计最好入门的就是PHP，所以初期练手用PHP靶场再好不过啦，但是，靶场要运行，要提供环境，PHPStudy为你提供了mysql数据库+apache集成环境，搭配简洁明了的GUI界面，对小白来说是非常友好的。



PHPStudy 官网：

https://www.xp.cn/download.html



Git


    Git是一个开源的分布式版本控制系统，可以有效、高速地处理从很小到非常大的项目版本管理。

    不过初学者不用care这些，你只要学会使用git clone命令从github下载项目就可以啦。


Git官网：

https://git-scm.com/downloads
