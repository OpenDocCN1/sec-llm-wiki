0x00 前言

简单介绍下常见的查杀工具使用方法；

0x01 Rootkit查杀工具

chkrootkit

项目地址：http://www.chkrootkit.org/download/

安装


tar zxvf chkrootkit.tar.gzcd chkrootkitmake sense


查杀


./chkrootkit


rkhunter

项目地址：http://rkhunter.sourceforge.net/

安装


tar -zxvf rkhunter-1.4.6.tar.gzcd rkhunter-1.4.6./installer.sh --install


查杀


rkhunter -update                                  # 更新rkhunter -versioncheck                            # 版本检测rkhunter -c                                       # 查杀


0x02 病毒查杀工具

Clamav

项目地址：http://www.clamav.net/download.html

安装&使用


yum install -y clamavfreshclam                                                               # 更新病毒库
clamscan -r /etc --max-dir-recursion=5 -l /root/etcclamav.log           # 扫描clamscan -r --bell -i /bin                                              # 扫描bin目录并且显示有问题的文件的扫描结果
clamscan -r --remove /usr/bin/bsd-port                                  # 扫描&杀毒clamscan -r --remove /usr/bin/clamscan -r --remove /usr/local/zabbix/sbin
cat /root/usrclamav.log |grep FOUND                                     # #查看日志发
