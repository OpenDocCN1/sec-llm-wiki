**0x02 病毒查杀工具**

**Clamav  
**

项目地址：http://www.clamav.net/download.html

**安装&使用**

  

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
yum install -y clamavfreshclam                                                               # 更新病毒库
clamscan -r /etc --max-dir-recursion=5 -l /root/etcclamav.log           # 扫描clamscan -r --bell -i /bin                                              # 扫描bin目录并且显示有问题的文件的扫描结果
clamscan -r --remove /usr/bin/bsd-port                                  # 扫描&杀毒clamscan -r --remove /usr/bin/clamscan -r --remove /usr/local/zabbix/sbin
cat /root/usrclamav.log |grep FOUND                                     # #查看日志发
```
