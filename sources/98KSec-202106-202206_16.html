0x00 前言

近日爆出数千台云主机由于YAPI远程代码执行在野0day攻击而失陷，给相关企业造成了不小的损失；今天就来学习下该漏洞的原理和防御方法。

0x01 漏洞原理

YAPI接口管理平台是国内某旅行网站的大前端技术中心开源项目，使用mock数据/脚本作为中间交互层，为前端后台开发与测试人员提供更优雅的接口管理服务，该系统被国内较多知名互联网企业所采用。


YAPI接口管理平台默认可进行用户注册，攻击者可以通过注册新用户，然后进入管理平台添加接口并设置mock脚本；由于mock脚本自定义服务未对JS脚本加以命令过滤，攻击者可以在脚本中植入命令，然后访问接口发起请求时触发命令执行。

0x02 影响版本

目前所有在网版本均受影响

0x03 环境搭建

YAPI项目地址：https://github.com/YMFE/yapi

内网部署环境要求：

  • nodejs（7.6+)

  • mongodb（2.6+）

  • git

安装nodejs

官网：https://nodejs.org/en/download/

下载并解压（这里选择v12.x版本，最新版为v16.x）：

wget https://nodejs.org/dist/latest-v12.x/node-v12.22.3-linux-x64.tar.xzxz -d node-v12.22.3-linux-x64.tar.xztar -xf node-v12.22.3-linux-x64.tarmv node-v12.22.3-linux-x64 /opt/node-v12      #放在opt目录下

添加环境变量（这里为了方便直接编辑/etc/profile文件）：
vi /etc/profileexport PATH=/opt/node-v12/bin:$PATHsource /etc/profile

查看是否安装成功：
node -vnpmnpx
安装mongodb
网站：https://www.mongodb.com/try/download/community
选择版本下载并解压：
wget https://fastdl.mongodb.org/linux/mongodb-linux-x86_64-rhel70-4.2.14.tgztar -zxvf mongodb-linux-x86_64-rhel70-4.2.14.tgzmv mongodb-linux-x86_64-rhel70-4.2.14 mongodb        #重命名，方便操作

创建所需文件/文件夹：
cd mongodb/bin/touch mongodb.conf    #新建配置文件mkdir db              #创建数据库目录mkdir log             #创建日志目录cd logtouch mongodb.log

编辑mongodb.conf文件，写入以下内容：
port=27017 #端口dbpath= /opt/mongodb/db #数据库存文件存放目录logpath= /opt/mongodb/log/mongodb.log #日志文件存放路径logappend=true #使用追加的方式写日志fork=true #以守护进程的方式运行，创建服务器进程maxConns=100 #最大同时连接数noauth=true #不启用验证journal=true #每次写入会记录一条操作日志(通过journal可以重新构造出写入的数据)storageEngine=wiredTiger  #存储引擎，有mmapv1、wiretiger、mongorocksbind_ip = 0.0.0.0  #设置成全部ip可以访问

添加环境变量（这里为了方便直接编辑/etc/profile文件）:
vi /etc/profileexport PATH=/opt/mongodb/bin:$PATHsource /etc/profile

启动：
mongod --config /opt/mongodb/mongodb.conf

为了方便使用mongodb，可编写脚本mongodb.sh：
#!/bin/sh##chkconfig: 2345 80 90#description: mongodbstart() { /opt/mongodb/bin/mongod -f /opt/mongodb/mongodb.conf} stop() {   /opt/mongodb/bin/mongod -f /opt/mongodb/mongodb.conf --shutdown} case "$1" in  start) start ;;  stop) stop ;;  restart) stop start ;;  *) echo $"Usage: $0 {start|stop|restart}" exit 1esac

0x05 防御方法
  1. 修改YAPI默认端口；
  2. 禁用YAPI用户注册功能；
  3. 删除已注册的恶意用户，避免攻击者再次添加mock脚本；
  4. 删除恶意mock文件；
  5. 部署防火墙，实时拦截威胁；

关于禁用YAPI用户注册功能，可在my-yapi/config.json中添加 closeRegister:true 配置项：
