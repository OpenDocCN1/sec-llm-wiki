### 服务器取证\_14

**题目：统计涉案网站哪一天登录的会员人数最多。（答案参考格式：1999-09-09）**

使用仿真系统挂载到本地后查看Larvel的默认配置路径,里面有数据库的账号和密码

cat /www/wwwroot/v9.licai.com/.env

![](../Images/5643c59cc13ba83865c65ef0581280e7.png)

mysql连接后在memberlogs表下可以看到访问的人数和日期时间,修改memberlogs表单updated\_at的长度为10方便我们排序

命令：

```
alter table memberlogs modify column updated_at varchar(10);
```

![](../Images/8b0f6271f10c65b467797bfed634516b.png)

根据命令排序后找到访问人数最多的时间为2021-07-14

命令:

```
select updated_at,count(*) from memberlogs where status=1 group by updated_at order by count(*);
```
