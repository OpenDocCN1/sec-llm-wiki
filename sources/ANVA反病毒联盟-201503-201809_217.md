# 速来加入 CCTGA 中国互联网网络安全威胁治理联盟（筹）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxNjMzOTY1OA==&mid=406796723&idx=1&sn=04f6d5557da956c623bfd50d856f4d14&chksm=063dde16314a570015610883099002a527e5a486db28d57c50e2bb0f8acf859717c32c2dd485&scene=126&sessionid=1681364660#rd](http://mp.weixin.qq.com/s?__biz=MzAxNjMzOTY1OA==&mid=406796723&idx=1&sn=04f6d5557da956c623bfd50d856f4d14&chksm=063dde16314a570015610883099002a527e5a486db28d57c50e2bb0f8acf859717c32c2dd485&scene=126&sessionid=1681364660#rd)

 2015年7月31日，国家互联网应急中心 CNCERT 会同中国互联网协会网络与信息安全工作委会联合国内54家企事业单位通过行业自律方式，启动了互联网网络安全威胁治理专项行动。经过4个多月的努力，行动取得好的成效。

  

 截至2015年12月31日，DDoS攻击事件日均次数由行动前的1491起下降到358起，下降了76.7%，境内被篡改政府网站月均数量下降44%。

  

 为持续开展互联网网络安全威胁治理工作，充分发挥行业自律作用，构建威胁治理联盟体系，加强威胁情报共享和威胁协同处理，有效净化网络安全环境，树立我国负责任网络大国形象，我中心会同中国互联网协会网络与信息安全工作委会发起成立中国互联网网络安全威胁治理联盟（筹），英文名称为 China Cyber Threat Governance Alliance（ CCTGA ）。特邀请各单位共同参与，成为联盟成立的首批单位。

  

 请有意愿的单位按照附件1要求，填写附件1申请表，并盖章，将扫描件发送至 zhaohui@cert.org.cn，将纸质件快递至我中心（地址：北京市朝阳区裕民路甲3号（100029））。同时，报送1名技术专家（姓名、单位、职务、手机、邮箱），加入联盟（筹）专家委员会，为联盟运行相关工作提供技术支持和专家意见。  

  

 首批单位申请截止日期：2016年1月21日17：00前

  

 （联系人：赵慧 82990178 zhaohui@cert.org.cn）

  

 以上情况，特此通知。
