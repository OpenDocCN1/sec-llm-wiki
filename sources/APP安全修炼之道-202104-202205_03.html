ipa砸壳

frida-ios-dump

frida-ios-dump基于frida提供的强大功能，通过注入js实现 内存dump，然后利用python自动复制到macOS生成最终的ipa文件。--《iOS应用逆向与安全之道》

Frida

Frida是一个跨平台的轻量级Hook框架，支持所有主流操作系统，它可以帮助与逆向研究人员对指定的进程进行分析。它主要提供了精简的Python接口和丰富的JS接口，除了使用自身的控制台交互以外，还可以利用Python将JS脚本注入目标进程。使用Frida可以获取进程详细信息、拦截和调用指定函数、注入代码、修改参数、从iOS应用程序中dump类和类方法等信息。--《iOS应用逆向与安全之道》

越狱手机上安装frida

打开越狱商店添加软件源https://build.frida.re/，搜索frida进行安装。

pc上安装对应版本的frida

proxychains pip install frida==15.1.14
proxychains pip install frida-tools==10.4.1

❝

「备注：PC和手机上安装的firda版本要一致」

❞

下载砸壳工具frida-ios-dump

proxychains git clone https://github.com/AloneMonkey/frida-ios-dump.git

安装工具所需的库

proxychains pip install -r requirements.txt --upgrade

开启端口转发

iproxy 2222 22

开始砸壳并打开目标APP

./dump.py zapp-ios
