# 加强版隐藏Magisk

在完成之前的相关配置后，虽然能达到一定的反检测效果，但是遇到安全性更高的APP就无法绕过相关检测正常运行APP，比如在完成前面的相关设置后，使用以下检查工具依然能检查到手机的root相关特征，如下：

## MagiskDetector检查工具

https://github.com/vvb2060/MagiskDetector/releases

![](../Images/a7edab0ebe40bcebc5c1423af6965b78.png)

## Momo 检查工具：号称已知最强的检测应用程序  

https://www.coolapk.com/apk/io.github.vvb2060.mahoshojo

![](../Images/fd2418341d8485be303322292d3a1f7f.png)

可以看到，使用以上检测工具后，依然提示 能检测su以及magisk相关的特征，接下来使用magisk 模块：# **「Riru-MomoHider」**  来绕过 对magisk以及root相关检测。  

## \# Riru-MomoHider 配置

*   下载**「Riru-MomoHider」** ：

https://github.com/canyie/Riru-MomoHider/releases/download/0.0.7/Riru-MomoHider.zip

*   将下载的zip文件拷贝到设备存储目录

![](../Images/254aac13820914322aae26b937d4b309.png)

*   打开Magisk管理界面，进入插件模块，选择从本地安装插件，如下：

![](../Images/d1209d51c4fd59ef6970f6361439a2fe.png)

选中上传的Riru-MomoHider.zip  直接进行安装即可。  

*   安装重启后，对Riru-MomoHider 进行配置，如下：

执行adb shell，进入手机命令终端

```


cd /data/adb/modules/riru_momohider/config
```

创建完成后，重启手机，再次打开Momo 和MagiskDetector即可发现相关特征的隐藏已经有了一些效果，如下：

![](../Images/9978ad3b16ce78f45d068ac4b2f2c2a3.png)

![](../Images/a8ba8e544669104e544d617fcc4cd7d0.png)

以上就是关于Magisk root以及lsposed相关特征的隐藏，其他还存在的一些特征接下来会继续尝试进行隐藏，如果大家有遇到无法正常运行的APP，建议先尝试使用相关特征检查工具自查，然后隐藏特征后，再尝试运行目标APP
