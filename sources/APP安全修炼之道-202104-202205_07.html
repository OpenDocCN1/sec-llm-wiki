Xposed插件开发之Hook构造函数

Xposed是一款可以在不修改APK的情况下影响程序运行（修改系统）的框架，基于它可以制作出许多功能强大的模块，且在功能不冲突的情况下同时运作。在这个框架下，我们可以编写并加载自己米编写的插件APP，实现对目标APK的注入、拦截等。

环境准备

AndroidStudio

Google Pixel2

Magisk+LSPosed

Xposed插件编写

新建工程

打开运行Android Studio，点击“File”—“New”—“New project”—“Empty Activity”，一直到最后，点击Finish，即可完成新工程的创建：

拷贝XposedBridgeApi.jar到libs目录

XposedBridgeApi下载：

https://github.com/asktaosec/AndroidApplicationSecurity/tree/master/Tools/XposedBridgeApi

编辑AndroidManifest.xml

<meta-data
  android:name="xposedmodule"    
  android:value="true //是否配置为xposed插件" />
<meta-data
  android:name="xposeddescription  //模块的名称"
  android:value="xposed01test //模块的描述" />
<meta-data
  android:name="xposedminversion //最低版本号"
  android:value="54"/>

修改build.gradle文件

双击app目录下的build。gradle文件，进行如下编辑：

 compileOnly fileTree(dir: 'libs',includes: ['*.jar'])

编写Hook代码

新建Hook类

新建hook类，对hook类实现接口IXposedHookLoadPackage，并实现方法handleLoadPackage(XC_LoadPackage.LoadPackageParam loadPackageParam)，该方法会在每个软件被启动的时候回调，所以一般需要通过目标报名过滤。

package com.example.xposed01;

import android.util.Log;

import de.robv.android.xposed.IXposedHookLoadPackage;
import de.robv.android.xposed.XposedBridge;
import de.robv.android.xposed.callbacks.XC_LoadPackage;

public class Xposed01 implements IXposedHookLoadPackage {
    public void handleLoadPackage(XC_LoadPackage.LoadPackageParam loadPackageParam) throws Throwable{
        Log.i("Xposed01",loadPackageParam.packageName);
        XposedBridge.log("app:"+loadPackageParam.packageName);
        if(loadPackageParam.packageName.equals("com.xiaojianbang.app")){
            XposedBridge.log("XLZH"+loadPackageParam.packageName);

        }
    }
}

创建xposed_init文件

新建assets目录，在其中新建文本xposed_init，里面内容为实现了IXposedHookLoadPackage接口的hook类的完整类名（可以有多个，每一个hook实现类一行）

Hook构造函数

对构造函数的Hook，有以下2个方法可调用

public static de.robv.android.xposed.XC_MethodHook.Unhook findAndHookConstructor(java.lang.Class<?> clazz, java.lang.Object... parameterTypesAndCallback)
public static de.robv.android.xposed.XC_MethodHook.Unhook findAndHookConstructor(java.lang.String className, java.lang.ClassLoader classLoader, java.lang.Object... parameterTypesAndCallback)

Hook构造函数方法1

hook无参构造函数

package com.example.xposed01;

import android.util.Log;

import de.robv.android.xposed.IXposedHookLoadPackage;
import de.robv.android.xposed.XC_MethodHook;
import de.robv.android.xposed.XposedBridge;
import de.robv.android.xposed.XposedHelpers;
import de.robv.android.xposed.callbacks.XC_LoadPackage;



        import android.util.Log;

        import de.robv.android.xposed.IXposedHookLoadPackage;
        import de.robv.android.xposed.XposedBridge;
        import de.robv.android.xposed.callbacks.XC_LoadPackage;

public class myhook implements IXposedHookLoadPackage {
    public void handleLoadPackage(XC_LoadPackage.LoadPackageParam loadPackageParam) throws Throwable{
        Log.i("Xposed01",loadPackageParam.packageName);
        XposedBridge.log("app:"+loadPackageParam.packageName);
        if(loadPackageParam.packageName.equals("com.kanxue.xposedhook01")){
            XposedBridge.log("XLZH"+loadPackageParam.packageName);
            
            ClassLoader classLoader = loadPackageParam.classLoader;
            Class StudentClass = classLoader.loadClass("com.kanxue.xposedhook01.Student");
            
            XposedHelpers.findAndHookConstructor(StudentClass, new XC_MethodHook(){
                @Override
                protected void beforeHookedMethod(MethodHookParam param) throws Throwable {
                    super.beforeHookedMethod(param);
                    XposedBridge.log("aaaaaaaaaaaaaaa:"+"com.kanxue.xposedhook01.Student() is called!!beforeHookedMethod");
                }

                @Override
                protected void afterHookedMethod(MethodHookParam param) throws Throwable {
                    super.afterHookedMethod(param);
                    XposedBridge.log("bbbbbbbbbbbbbbbb:"+"com.kanxue.xposedhook01.Student() is called!!beforeHookedMethod");
                }
            });

        }
    }
}

hook有参构造函数

package com.example.xposed01;

import android.util.Log;

import de.robv.android.xposed.IXposedHookLoadPackage;
import de.robv.android.xposed.XC_MethodHook;
import de.robv.android.xposed.XposedBridge;
import de.robv.android.xposed.XposedHelpers;
import de.robv.android.xposed.callbacks.XC_LoadPackage;



        import android.util.Log;

        import de.robv.android.xposed.IXposedHookLoadPackage;
        import de.robv.android.xposed.XposedBridge;
        import de.robv.android.xposed.callbacks.XC_LoadPackage;

public class myhook implements IXposedHookLoadPackage {
    public void handleLoadPackage(XC_LoadPackage.LoadPackageParam loadPackageParam) throws Throwable{
        Log.i("Xposed01",loadPackageParam.packageName);
        XposedBridge.log("app:"+loadPackageParam.packageName);
        if(loadPackageParam.packageName.equals("com.kanxue.xposedhook01")){
            XposedBridge.log("XLZH"+loadPackageParam.packageName);
            ClassLoader classLoader = loadPackageParam.classLoader;
            Class StudentClass = classLoader.loadClass("com.kanxue.xposedhook01.Student");
            XposedHelpers.findAndHookConstructor(StudentClass,String.class,String.class,int.class,String.class,String.class,new XC_MethodHook(){
                @Override
                protected void beforeHookedMethod(MethodHookParam param) throws Throwable {
                    super.beforeHookedMethod(param);
                    java.lang.Object[] args = param.args;
                    XposedBridge.log("aaaaaaaaaaaaaaa:"+(String)args[0]);
                    XposedBridge.log("bbbbbbbbbbbbbbb:"+(String) args[1]);
                    XposedBridge.log("ccccccccccccccc:"+(int) args[2]);
                    XposedBridge.log("ddddddddddddddd:"+(String) args[3]);
                    XposedBridge.log("eeeeeeeeeeeeeee:"+(String) args[4]);
                    XposedBridge.log("bbbbbbbbbbbbbbbb:"+"com.kanxue.xposedhook01.Student() is called!!beforeHookedMethod");
                }

                @Override
                protected void afterHookedMethod(MethodHookParam param) throws Throwable {
                    super.afterHookedMethod(param);
                    XposedBridge.log("bbbbbbbbbbbbbbbb:"+"com.kanxue.xposedhook01.Student() is called!!beforeHookedMethod");
                }
            });

        }
    }
}
