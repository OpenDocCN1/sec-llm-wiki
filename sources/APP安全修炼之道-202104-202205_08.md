# 不走代理型

> 案例下载：https://github.com/AndroidAppSec/vuls/releases/tag/v4.4
> 
> 原理：[https://mp.weixin.qq.com/s?\_biz=MzAwMjg1NTI2Nw==&mid=2650520090&idx=1&sn=d296354b9a9884f20a146080e6ba292b&chksm=82cb0216b5bc8b00295f6165385a62bf98e18f0e5e5658d6c443ff93baa52cdbfa2ee7448855&scene=21#wechatredirect](https://mp.weixin.qq.com/s?__biz=MzAwMjg1NTI2Nw==&mid=2650520090&idx=1&sn=d296354b9a9884f20a146080e6ba292b&chksm=82cb0216b5bc8b00295f6165385a62bf98e18f0e5e5658d6c443ff93baa52cdbfa2ee7448855&scene=21#wechat_redirect)

当APP客户端设置了网络通信流量不走代理时，将手机设置代理后，APP所有的网络请求正常进行，但是BurpSuite等抓包工具却无法抓取到数据包，具体效果如下：

![](../Images/98701513834c171a59fc5bdc484f1289.png)

这种情况下会发现虽然设置代理后，APP依然能正常进行网络请求，但是抓包工具却无法抓取到任何数据包，这时可以猜测该APP是不是设置了网络流量不走代理，并使用以下几种方式进行尝试。

## 1\. iptables流量转发（root权限）

设置BurpSuite为透明代理

![](../Images/1c72e46c9b2cce1d57f20bb1e599b6fc.png)

获取目标应用的uid

```
1.  `ps | grep <包名>`
    
```

![](../Images/1a28084729894e903dae1a2babe4dd64.png)

执行命令如下：

```
1.  `iptables -t nat -A OUTPUT -p tcp -m owner --uid-owner u0_a116 -j DNAT --to-destination 192.168.137.1:8888`
    
```

![](../Images/8a3c7a6aa464d10d44d510f3387dd3ef.png)

抓包验证

![](../Images/09c06e9a950d4c9259728da70811b471.png)

> **测试结束后，可使用 iptables -t nat -F 命令来清除规则。**

## 2\. Postern

> vpn属于网络层，设置了vpn后，手机上会多一个接口，相当于加了一个虚拟网卡，所有的流量都会从这走。应用层和传输层的请求都可以拿到，即可绕过不走代理的限制。

开启vpn前：

![](../Images/191205c9dfba99d18958fc77f113e9b5.png)

开启vpn后：

![](../Images/be00ad296a6e713afa1e0fe0df082e45.png)

配置好Postern，即可抓取不走代理型APP的数据包，验证如下：

![](../Images/f4cf0a841fd98e97813d31dfe95a8595.png)

![](../Images/c0fd8c169cd497bb4a0769a5c9e16fe7.png)

## 3\. HttpCanary

httpCanary是手机上的一个app抓包软件，采用vpn+中间人攻击的方法来抓包。

app下载地址：

httpcanarybasicv3.2.5.apk

## 4\. HTTP Analyzer

通过HTTP Analyzer可抓取请求的网络请求数据包，如将APP在夜夜神模拟器中运行，开启HTTP Analyzer后，操作模拟器中的APP，即可抓取到相应的请求数据包。（**如果在真机中测试APP使用此方式抓取数据包，可下载一个wifi热点工具，手机连接开启的热点，然后使用此工具抓取wifi热点工具进程的网络数据包即可抓到对应APP的请求数据包** ）

![](../Images/4547caff1d45fb194fad63982beca152.png)

## 5\. Hook方式绕过

HttpURLConnection框架为例，通过hook方式，修改代理设置调用的方法。

反编译目标APP代码，搜索Proxy.NO\_PROXY关键字。

![](../Images/3cb0d27c64e9cd5d12f5fb9c55ddf157.png)

编写hook脚本，替换openConnection传入的参数为空，即可绕过APP的不走代理设置，如下：

![](../Images/56a3b79c20267d3b23671707c7ee8e1c.png)

![](../Images/7a0611cf98497a855812c06d1ae2b520.png)
