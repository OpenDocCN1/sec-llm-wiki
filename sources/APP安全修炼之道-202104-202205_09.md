# 01 /system分区扩容

> 给n5第一次刷安卓11需要扩容/system分区，（如果不扩容会一直报E1001错误）

下载专版的twrp Repartition (HH.R versions)然后按下列操作执行即可

https://forum.xda-developers.com/t/recovery-unofficial-twrp-hh-for-nexus-5-hammerhead-discontinued.4047653/

![](../Images/715372f84b328d2d6b108f0894e9a647.png)

### 刷入专版Twrp并运行Twrp

执行命令使n5手机进入bootloader模式

```

adb reboot bootloader
```

![](../Images/2ae9985599382db689c8f4a7ef99f50d.png)

执行命令输入专版twrp

```

fastboot.exe  flash recovery twrp-3.5.2_9-HH.R.14.img
```

![](../Images/69f2edf01e38b4781cf5c74a3db42aba.png)

按上下键，调整模式为recovery  mod后，按开机键，即可启动运行刷入的twrp（进入twrp后拔掉usb线）

![](../Images/b4722192b6e2b0b4a3247435ffb542b4.png)

![](../Images/405de406feffd4d2e6247fa09cabab62.png)

### 打开terminal (TWRP -> Advanced -> Terminal)

**Terminal中输入hh\_repart -m** 

![](../Images/04962595f1c44fba3e7b3b4855f211dc.png)

等待命令执行完毕重启即可完成分区扩容

# 02 刷入镜像

### Wipe

![](../Images/829db2f881eeeb5541b78da2e7b64b22.png)

![](../Images/722bf5bb47d25e75bce1787f7db5f938.png)

### 下载镜像

http://49.235.84.125:8080/GoogleNexus5r0envImages

![](../Images/a5d6c9dcd899d3274dd00b646a3d13ea.png)

解压后：

![](../Images/a2fccb3cfdd679e7dc41140527bb351b.png)

两个镜像的刷入方式相同，后面的步骤

### 拷贝镜像到手机

压缩包解压出来后是个TWRP文件夹

![](../Images/d378490a7569aefc788868947e2fa9bc.png)

在twrp模式下插上USB线

![](../Images/f7f636e2549cf94d8d93be7a7d3a50ff.png)

可以看到，在手机的/sdcard目录下也有个TWRP。所以将下载的镜像解压得到的TWRP文件夹下的所有东西拷贝至手机的TWRP目录下：

```

adb push 2021-07-13--09-41-08_RQ3A210605005 /sdcard/TWRP
```

![](../Images/d94da270c1ba6f814c3d001ed8c39647.png)

传输完成后拔掉usb线，然后reboot至recovery模式

### 开始刷机

点击Restore，即可看到拷贝到手机上的镜像

![](../Images/40ef342555e489f2ee3e3b034c480c47.png)

![](../Images/f9860c324f6e5d3059ea951d7bc74fbe.png)

点击上传的内容，自动选中所有的文件后，再滑动Swip to Restore即可完成刷机

![](../Images/4cc9109dee3c0e0a6c01d7bf169f503b.png)

![](../Images/7bff594208e7c841edf1813e27dc1e53.png)
