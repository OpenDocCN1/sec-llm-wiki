主动调用static修饰的函数

第一种情况就是如何通过Frida主动调用某个类中使用static关键字修饰的函数。

随便找个APP进行主动调用的练习，以下为APP反编译代码中截取的代码片段，为APP登录请求中生成校验参数的地方。

获取APP反编译代码中的要主动调用的方法所在的类：com.softgarden.baselibrary.utils.MD5Util，接下开始使用Frida对static修饰的ToMD5()方法进行主动调用。

Frida hook代码

function main(){
    Java.perform(function x(){
        var MD5Util = Java.use("com.softgarden.baselibrary.utils.MD5Util");
        var rel = MD5Util.ToMD5("d367f4699214cec412f7c2a1d513fe05","{\"password\":\"12345678\",\"phone\":\"18888888888\"}");
        console.log("主动调用返回结果:"+rel);
    })
}
setImmediate(main);
