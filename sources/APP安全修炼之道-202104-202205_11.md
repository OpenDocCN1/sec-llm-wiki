# OkHttpLogger-Frida

## 项目地址

siyujie/OkHttpLogger-Frida：https://github.com/siyujie/OkHttpLogger-Frida

## 食用方法

将okhttpfind.dex 拷贝到 /data/local/tmp/ 目录下

```
adb okhttpfind.dex /data/
```

给目标App授予存储权限

![](../Images/0e337eebfe7a3b4df3d8f48fd79bb811.png)

  

手机上执行命令启动frida服务端

```

./frida-server
```

PC端执行以下命令

```

frida -U -l okhttp_poker.js -f com.x.x --no-pause
```

拦截Okhttp实现非常规抓包效果如下：

![](../Images/1e023958cc15831ccffd32c19756f1e8.png)

  

```
root@AskTao:~/Frida/frida-agent-example/agent
```

> ❝
> 
> 备注：使用的时候出现过一些奇奇怪怪的问题，最后确认是由于在使用frida的同时使用的xposed导致，换个没有xposed的手机就好了。
