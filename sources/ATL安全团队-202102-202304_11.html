2. 基础知识

2.1 定义

序列化是将变量或对象转换成字符串的过程。

反序列化是将字符串转换成变量或对象的过程。

2.2 常见的魔术方法

  • _construct()

    构造函数/方法

    构造函数也称构造器，是类中的一种特殊函数，当使用new关键字实例化一个对象时，构造函数将会自动调用。

  • _destruct()

    析构方法

    析构函数会在某个对象的所有引用都被删除或者当对象被显示销毁时执行。

  • _call()

    方法重载

    在对象中调用一个不可以访问方法时，_call会被调用。

  • _callStatic

    方法重载

    在静态上下文中调用一个不可以访问方法时，会被调用。

  • _get()

    属性重载

    读取不可访问(protected或private)或不存在的属性值时，会被调用。

    （只有从类外部访问这个属性时，重载才会发生）

  • _set()

    属性重载

    在给不可访问(protected或private)或不存在的属性赋值时，会被调用。

    （只有从类外部访问这个属性时，重载才会发生）

  • _toString()

    用于一个类被当成字符串时应怎样回应。

  • _sleep()

    常用于提交未提交的数据，或类似的清理操作。同时，如果有一些很大的对象，但不需要全部保存，这功能就很好用。（注意：serialize()函数会检查类中是否存在一个魔术方法_sleep().如果存在，该方法会先被调用，然后才执行序列化操作。）

    返回值为数组类型。

  • _wakeup()

    经常用在反序列化操作中，例如重新建立数据库连接，或执行其它初始化操作。

    unserialize()会检查是否存在一个_wakeup()方法。如果存在，则会先调用——wakeup()方法，预先准备对象需要的资源。

  • _isset()

    当对不可访问(protected或private)或不存在的属性isset()或empty()会被调用。

  • _unset()

    当对不可访问(protected或private)或不存在的属性调用unset()时，_unset()会被调用。unset()这个函数的作用是删除指定的变量且传回true，参数为要删除的变量。

  • _invoke()

    当尝试以调用函数的方式调用一个对象时，_invoke()方法会被自动调用。

  • serialize()

    函数用于序列化对象或数组，并返回一个字符串。

  • unserialize()

    将已序列化的字符串还原回PHP值。

2.3 序列化后结构

String：s:字符串长度:"字符串值"；Integer：i:数值；Boolean:b:value;(value为1或0)Null:N;Array:a:数组大小:{键的描述;值的描述;值得描述；值的描述;...}(描述值同String或Int型的序列化格式)Object:O:类名长度:"类名":属性数量:{属性类型:属性名长度:属性名;属性类型:属性长度:属性值;...}

例子：

O:3:"pop":l:{s:"ClassObj";0:5:"shell":l:{s:4:"data";s:10:"phpinfo();";}}

注意：

      private、protected属性在序列化的时候，多出来的字节都被\x00填充，需要进行在代码中使用urlencode对序列化后字符串进行编码，否则无法复制解析。

序列化的值不关注方法，主要关注类名和属性。

3. PHP反序列化利用方法

3.1 Session反序列化

3.1.1 简介

  • PHP_SESSION反序列化：

PHP在存储和读取session时，都会有一个序列化和反序列化的过程，同时序列化中也会调用一些魔术方法。

  • 特征

phpinfo中默认的session_serialize_handler和本地的值不一样

ini_set('session.serialize_handler','php');之类的phpinfo中session.upload_progress.enabled打开

3.1.2 利用

第一步:配置php.ini

session.save_path=""  -- 设置session的存储路径

session.save_handler=""  --设置用户自定义村出函数，如果想使用PHP内置会话存储机制之外的可以使用本函数(数据库等方式)

session.auto_start  boolen  --指定会话模块是否在请求开始时启动一个会话，默认为0不启动

session.serialize_handler  string  --定义用来序列化/反序列化的处理器名字，默认使用php。

    例子：

session.save_ path="D:\phpstudy_pro\WWW\tmp"session.save_handler=filessession.auto_start=0session.serialize_handler=php


第二步:分析源码

demo_session2.php

<?phperroreporting(O);ini_set('session.serialize_handler','php_serialize');session start();$_SESSION['username']=$_GET['username'];?>

demo_session3.php

<?phpini_set(session.serialize_handler.'php);session_start();class A{public $test;function_wakeup(){eval($this->test); }}?>


第三步：根据源代码构造反序列化payload

3.2 phar反序列化

3.2.1 简介

phar://—PHP归档（PHP>5.3).phar是类似于JAR的一种打包文件。

注：phar文件默认状态是只读，读取操作不需要额外配置。
官方文档: https://www.php.net/manval/zh/wrappers.phar.php

3.2.2 利用前提条件

  • 1.调用受影响函数且可以调用魔法方法

  • 2.参数可控，且：、/、phar等特殊字符没有被过滤。

  • 3.phar文件必须可以上传到服务器端

3.2.3 文件结构

  • stub

    供phar扩展用于识别的标志，<?php xxx;_HALT_COMPILER();?>

  • manifest

    压缩文件的属性等信息，其中的Meta-data会以序列化的形式存储且该值可以自定义

  • contents

    被压缩文件的内容

  • signature

    签名放到文件尾部

3.2.4 利用

第一步：构造恶意的phar文件

a.配置php.ini文件中的phar.readonly选项为off，如果没有该参数可以自己添加上去

3.3 CVE-2016-7124_wakeup()函数

  • 原理

    反序列化时，如果表示对象属性个数的值大于真实的属性个数时，就会_wakeup()函数的执行。

    影响版本：php5<5.6.25  php7<7.0.10

 举例：

<?phpclass xctf{    public $flag = '111';
    function __wakeup(){        exit('bad request');    }}//解题$a = new xctf();$b = serialize($a);echo $b;
http://ip/?code=O:4:%22xctf%22:2:{s:4:%22flag%22;s:3:%22111%22;}

考点：

1.反序列化2.魔术函数__wakeup()的绕过3.绕过__wakeup()的姿势:__wakeup 触发于 unserilize() 调用之前, 当反序列化时的字符串所对应的对象的数目被修改, __wake 的函数就不会被调用. 并且不会重建为对象

4 POP利用链(反序列化链)

4.1 简介

POP面向属性编程（Property-Oriented Programing）,简单来说就是出发反序列化的调用链（A=>B=>C）。

注：重点确定可控制输入点（首）和最终调用的函数（尾），先定尾再定头。

4.3 Tips

  • 反序列化中为避免信息丢失，使用大写S支持字串的编码

    s:4:"user";->S:4:"use\72";
    PHP 为了更加方便进行反序列化Payload的传输与显示（避免丢失某些控制字符串等信息），我们可以在序列化内容中用大写S表示字符串，此时这个字符串就支持将后买你的字符串用16进制表示。

  • 一些有用的POP链中出现的方法

    命令执行：exec()、passthru()、popen()、system()

    文件操作：file_put_contents()、file_get_contents()、unlink()

    代码执行：eval()、assert()、call_user_func()
