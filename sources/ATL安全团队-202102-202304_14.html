0x01 Croc简介

1.什么是Croc

操作系统之间文件传输的方法有很多种，常用的软件xftp非常的方便和实用，但部署比较花时间，或者自己搭建FTP服务进行文件传输，或者透过SSH方式来传送档案，需要学习SCP指令，采用Go语言写的文件传输工具Croc能够更快捷的在操作系统之间既快速又安全的传输文件。

2.下载链接

https://github.com/schollz/croc/releases
Croc适用于多种架构：32bit、64bit、ARM64，多种操作系统：FreeBSD、Linux、macOS、NetBSD、OpenBSD、Windows。适配性和兼容性非常好。

3.特点及优势

  • 用Relay（中继）方式允许任意两台计算机传输数据
  • 提供端到端加密（使用 PAKE）
  • 实现轻松的跨平台传输（Windows、Linux、Mac）
  • 一次可以传送多个文件或整个目录
  • 允许恢复被中断的传输
  • 不需要本地服务器或端口转发
  • 优先使用IPv6，而IPv4当作备用
  • 可以使用代理，比如tor、Socks5 proxy

0x02安装与部署


 1.在Linux上可直接get clone，下载软件压缩包

get clone https://github.com/schollz/croc/releases/

选择合适的版本，下载后为可执行文件，设置权限chmod +x croc，执行：./croc+命令

也可以从命令行安装一个版本

curl https://getcroc.schollz.com | bash
2.在 macOS 上，您可以使用Homebrew安装最新版本
brew install croc
3.在 macOS 上，您还可以使用MacPorts安装最新版本
sudo port selfupdatesudo port install croc
4.在 Windows 上为可执行程序exe无需安装
双击exe程序，输入加密code，接受或者传送文件即可。
5.在 Unix 上，您可以使用Nix安装最新版本：
nix-env -i croc

6.在 Alpine Linux 上，您必须先安装依赖项：

apk add bash coreutilswget -qO- https://getcroc.schollz.com | bash

7.在 Arch Linux 上，您可以使用以下命令安装最新版本pacman：

pacman -S croc

8.在 Gentoo 上你可以安装portage：

emerge net-misc/croc
9.在 Termux 上，您可以安装pkg：
pkg install croc
10.在 FreeBSD 上，您可以安装pkg：
pkg install croc


0x03 使用方法

1.使用默认配置

由于此工具是通过 relay server 方式来进行传送，所以指令会预设连到官方所搭建的服务器，默认从官方服务器进行中继。
// DEFAULT_RELAY is the default relay used (can be set using--relay)var (    DEFAULT_RELAY      = "croc.schollz.com"    DEFAULT_RELAY6     = "croc6.schollz.com"    DEFAULT_PORT       = "9009"    DEFAULT_PASSPHRASE ="pass123")
传送端执行传送文件命令。

软件会自动生成传输密钥code，
在另一台计算机上接收文件（或文件夹）执行接受命令
croc code 输入传输密钥，接受文件。

2.自行设置密钥

发送端设置密码code命令（必须超过 6 个字符）
croc send –code 密钥 发送的文件


3.自行创建中继服务并设置密码

搭建自己的Relay Server，并指定单一端口。默认情况下，使用TCP端口9009-9013，要确保端口开启。可以自定义端口（例如croc relay--ports 1111,1112），但必须至少有2 个用于中继的端口。第一个端口用于通信，后续端口用于多路复用数据传输。（Relay Server搭建环境为kali2021）
注意，发送时只需要包含第一个端口（通信端口）即可。用于数据传输的后续端口将从中继传输回用户。

--relay如果想自定义主机，可以通过输入更改正在使用的中继来使用中继发送文件。
发送端kali2019，使用搭建的中继服务发送传输密钥为kk1667…的文件

接收端win10输入传输密钥接受文件。


0x04 其他功能

1.允许在没有提示的情况下覆盖

默认情况下，croc 会提示是否覆盖文件。可以使用该--overwrite标志（仅限收件人）自动覆盖文件。例如，接收文件以自动覆盖：
croc --yes --overwrite <code>

2.使用管道 - stdin 和stdout

可以通过管道连接到croc：

cat [filename] | croc send
在这种情况下，croc将自动使用标准输入数据并发送和分配一个文件名，如“croc-stdin-123456789”。要接收到stdout，可以随时使用--yes will 自动批准转移并将其通过管道发送到stdout。
croc --yes [code-phrase] > out
打印到控制台的所有其他文本stderr都将转到stdout。

3.发短讯

有时想发送 URL 或短文本。除了管道之外，还可以使用以下命令轻松发送文本croc：
croc send --text "hello world"
这将自动告诉接收者stdout在收到文本时使用，以便显示。

4.使用代理

可以通过添加代理地址来使用代理作为与中继的连接--socks5。例如，可以通过 tor 中继发送：
croc --socks5 "127.0.0.1:9050" send SOMEFILE

5.更改加密曲线

可以使用--curve标志从几个不同的椭圆曲线中进行选择以用于加密。只有收件人可以选择曲线。例如，使用 P-521 曲线接收文件：
croc --curve p521 <codephrase>
可用曲线有 P-256、P-348、P-521 和 SIEC。SIEC 是使用的默认曲线，它是一种鲜为人知的曲线，属于一类“超隔离”曲线，其安全性不会降低到其周围曲线的安全性。

6.自主机中继（docker）

如果更简单，还可以使用 Docker 运行中继：
docker run -d -p 9009-9013:9009-9013 -eCROC_PASS='YOURPASSWORD' schollz/croc
请务必包含中继的密码，否则任何请求都将被拒绝。
croc --pass YOURPASSWORD --relay"myreal.example.com:9009" send [filename]
注意：当包含时，--pass YOURPASSWORD可以改为传递带有密码的文件，例如--passFILEWITHPASSWORD。
