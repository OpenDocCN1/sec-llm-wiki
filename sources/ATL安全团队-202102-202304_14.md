# **1.什么是Croc**

## 

操作系统之间文件传输的方法有很多种，常用的软件xftp非常的方便和实用，但部署比较花时间，或者自己搭建FTP服务进行文件传输，或者透过SSH方式来传送档案，需要学习SCP指令，采用Go语言写的文件传输工具Croc能够更快捷的在操作系统之间既快速又安全的传输文件。

## **2.下载链接**

https://github.com/schollz/croc/releasesCroc适用于多种架构：32bit、64bit、ARM64，多种操作系统：FreeBSD、Linux、macOS、NetBSD、OpenBSD、Windows。适配性和兼容性非常好。  

## **3.特点及****优势**

*   用Relay（中继）方式允许任意两台计算机传输数据
*   提供端到端加密（使用 PAKE）
*   实现轻松的跨平台传输（Windows、Linux、Mac）
*   一次可以传送多个文件或整个目录
*   允许恢复被中断的传输
*   不需要本地服务器或端口转发
*   优先使用IPv6，而IPv4当作备用
*   可以使用代理，比如tor、Socks5 proxy

# **0x03 使用方法**

* * *

**1.使用默认配置**

由于此工具是通过 relay server 方式来进行传送，所以指令会预设连到官方所搭建的服务器，默认从官方服务器进行中继。

*   
*   
*   
*   
*   
*   
*   

```
// DEFAULT_RELAY is the default relay used (can be set using--relay)var (    DEFAULT_RELAY      = "croc.schollz.com"    DEFAULT_RELAY6     = "croc6.schollz.com"    DEFAULT_PORT       = "9009"    DEFAULT_PASSPHRASE ="pass123")
```

传送端执行传送文件命令。

![](../Images/a52e4e7c90da5f5be0b2a864e3646934.png)

软件会自动生成传输密钥code，  
在另一台计算机上接收文件（或文件夹）执行接受命令  
croc code 输入传输密钥，接受文件。

![](../Images/bceb9703c39775eee8fa3280f38765a8.png)

## **2.自行设置密钥**

发送端设置密码code命令（必须超过 6 个字符）croc send –code 密钥 发送的文件

![](../Images/1b28ae23f2ee64e66f3fcc65fbb97924.png)  

## **3.自行创建中继服务并设置密码**

搭建自己的Relay Server，并指定单一端口。默认情况下，使用TCP端口9009-9013，要确保端口开启。可以自定义端口（例如croc relay--ports 1111,1112），但必须至少有2 个用于中继的端口。第一个端口用于通信，后续端口用于多路复用数据传输。（Relay Server搭建环境为kali2021）注意，发送时只需要包含第一个端口（通信端口）即可。用于数据传输的后续端口将从中继传输回用户。

![](../Images/e8d4088eb3000e3bd51938baf6e473d7.png)

\--relay如果想自定义主机，可以通过输入更改正在使用的中继来使用中继发送文件。发送端kali2019，使用搭建的中继服务发送传输密钥为kk1667…的文件
