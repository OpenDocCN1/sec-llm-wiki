# 前言

As you know, ad域控的攻击是属于相当复杂的一个攻击流程，我们需要了解目标网络的拓扑结构、操作系统和安全配置等信息，以便能够在不被检测的情况下突破目标网络的防御并获取管理员权限。因此，攻击AD域控需要有一定的技术门槛和复杂程度，同样OSCP考试当中现在也是有AD域控的题目，近期我查看了我司（Orange Cyberdefense）在GitHub上面的一个分享的AD域控攻击思维导图, 写的比较全面，缺点是只有英文版的。于是我将其中的描述都替换成了中文版，发布出来，供各位师傅参考。
