# 前言

云安全逐渐在网络安全中逐渐变得重要了起来，远程办公/混合办公/线上会议等主题也受Covid-19的影响在我们生活中变的寻常起来，那么如何保障云产品便变得十分重要起来

## 本文章中将提到两个微软云平台的实践

*   Microsoft Intune（仅测试数据）
*   Microsoft 365 Defender（脱敏数据）

* * *

# Microsoft Intune

![](../Images/a82186e48da5892be7613656d0bcfab8.png)

这个平台可以管理用户的访问，并且简化设备的应用和设备管理，设备包括了移动设备/台式电脑以及虚拟终端。Intune的主要功能包括：

1.  可以管理用户和设备，包括组织有的设备以及个人有的设备。支持Android、Android 开源项目 (AOSP) 、iOS/iPadOS、macOS 和 Windows 客户端设备。
2.  可以通过内置的程序更方便的管理应用（应用部署/更新以及删除）。
3.  可以自动部署应用/安全性/设备配置/合规性/条件访问等策略。
4.  可以通过Portal进行重置PIN/密码，安装应用，加入到组等。
5.  可以跟Defender联动。
6.  拥有一个管理中心，来获取设备的相关信息。

通过设备的连接之后可以在管理员界面查看想要的信息， 以下是主界面：

![](../Images/02b32ca0d3fa4f23f8639eb6602b6af9.png)当连接了设备之后可以看到所有的设备的基本情况：

![](../Images/a9e493961e9cd8a37d8789955c706980.png)选择全部设备，你可以查看到所有的设备的信息，其中就包括了设备名，被什么进行管理，所有权，合规性等等信息。

![](../Images/7d28b1baad960e984ec0d3531df92a23.png)选择其中一个设备，可以查看更多有关于这个设备的信息，并且你可以对这个设备进行相应的操作。

![](../Images/eb43b6e5c27f22cc94e0a791528227ec.png)你同样可以在左侧列表的监控中选择“Discovery Apps”，紧接着你就能看到这个设备上安装了什么应用。

![](../Images/1b750de1227252f77bba67ebbf8042d6.png)再深入我发现，这玩意连接了手机之后就可以自动安装所添加的应用，所以每当一个设备连接到Intune之后，主屏幕上就会自动下载这个应用。就例如说我下载了Office365的几个常用的应用。

![](../Images/578abc1bc4ec009ab0f8a3861dad29ea.png)然后咱们也可以为每个不一样的应用添加不一样的规则，这个规则可以针对不同的系统框架（好像macOS还不支持）。

![](../Images/bf529827f30df6fd713b59704dd516ce.png)

![](../Images/f140361fccdf0401e6a4e8af44d788b5.png)

同样也可以选择抹去数据。

![](../Images/cd202ed8befb16feaeec471a5729b010.png)

## 终端安全

在终端安全当中咱们也可以看到所有的设备安全，你可以管理杀软/磁盘加密（计算机独有）/防火墙/端点检测以及响应等等。

![](../Images/cd00a860e16cb3b2b4d7976d793b7045.png)  
在管理当中，每个模块当中我们都能创建自定义规则。

![](../Images/42fc41980639a3d0ece69c6307280604.png)  
![](../Images/cc0d95a1d6373699e755088a8c84ae9a.png)

![](../Images/0df1ab61ca3ca1e20eccd15494701e3c.png)

Intune可以生成三种不同的报告，组织报告，趋势报告以及高级报告。

![](../Images/39e0bd6475d56d2ff933461043523b8d.png)在设备合规性当中，会列出那些设备不合规，并且自动生成报告，相对应的也有两种类型的报告。

![](../Images/b144b9b42765b31df28ee97be5a12829.png)

![](../Images/b309d8652bbb2ec0bb6a1b42e74b77be.png)

# Microsoft 365 Defender

在Defender的默认主界面，我们可以自定义想要的模块信息，当然你如果想打造你的大屏，那也不是不行。

![](../Images/18d0fcce23a2c5a773cb5f9dfdf15049.png)  
在事件&告警中，点击事件可以看到自动生成的趋势图

![](../Images/02938e04ad4c31d0f5514ff86a0465f8.png)点击告警，可以查看最近的告警，同样也可以选择时间跨度。筛选可以选择告警状态，级别，分类。

![](../Images/23da8f957b66a5550204f76b308e88ec.png)

## Hunting（暂译为狩猎）

在狩猎-进阶狩猎当中，你可以使用强大的语句来查找告警的相关信息，并且可以自定义语句去生成你想要的语句

![](../Images/63ee039081980e3b4ac883743823c559.png)为了提高效率，需要的话可以保存查询的语句在Defender当中

![](../Images/ff46714180e8d2c11ee377751dd9a1ad.png)点击其中一个事件，你可以获得此事件的更多信息，接着你就可以对此设备做一些操作。

![](../Images/31c2b40bf4d22b66965008a7902596f7.png)

![](../Images/008ef6ea7b7428cd20ff4acf1eea03d0.png)在自定检测规则当中，咱们可以在进阶狩猎当中为告警创建规则，当这个规则被某些关键字触发之后将会自动生成一个告警用于应急响应。

![](../Images/b93beb5e86813bd6cc75cbce601454eb.png)

![](../Images/8fec2c273ef538ad645dbc79b7286e22.png)

![](../Images/586f14f65cac2b279b9ff58546228bc7.png)
