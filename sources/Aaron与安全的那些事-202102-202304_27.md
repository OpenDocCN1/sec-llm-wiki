## 突破边界

### SSH密码爆破

到后面, web页面基本上只给了我们一个passwd的信息, 这样我们只能通过ssh爆破来实现突破边界

![](../Images/6e4951e098918078041d06379c2fda9c.png)

拿到了ssh密码

### 获取密码后提权

通过ssh密码我们能够直接登录靶机

查看一下是否有suid的文件以及是否有sudo权限

![](../Images/0b0820db86a8b4e9ce4ad91a7accbefa.png)

发现/usr/bin/base32拥有suid权限  
查看如何利用base32去提权  

![](../Images/eb6ae8e071729d885b47a4e500a8e69b.png)

那我们就可以通过base32去读取/etc/shadow的的文件了!

![](../Images/006339b40247fbba8215113da1495930.png)

获取到root的密码哈希, 尝试能否使用john爆破![](../Images/8370f9bd623994620aea4e1c071217ce.png)同样的我们也可以尝试去获取root的sshkey

![](../Images/22dcbdb4534527e72a9fec652afad5dc.png)

拿到root的sshkey, 拿到时我们需要修改sshkey的权限, 否则无法登录

![](../Images/d9a761567e97a700cf57626830d44897.png)

### 提权成功

通过修改id\_rsa的权限, 成功登录root

![](../Images/0d7b95471f9902d807d97e37e02ac785.png)

![](../Images/3a8f122e302880235c19e776c88dfec7.png)

## Note

在本文当中使用到的查找suid权限的文件的命令为

```
find / -perm -u=s -type
 f 2>/dev/null
```

## 总结

这次靶机当中我们主要以爆破来突破边界, 通过suid的方式提权, 端口很多导致我们的进度缓慢, 所以要整理思路, 可以在一开始拿到passwd文件的时候就进行爆破, 以减少自己的工作量, 节省时间
