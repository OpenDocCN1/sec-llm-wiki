## 突破边界

使用ssh登录

```


└─$ ssh tre@192.168.146.77                      for
 tre on tre:local/sbin\:/usr/local

/bin\:/usr/sbin\:/usr/bin\:/sbin\:/bin
```

使用sudo -l之后可以看到我们可以不需要密码调用/sbin/shutdown  
使用pspy查看一下系统进程  

![](../Images/5b47250075ccd98f62debecd82eb2292.png)

在这里可以看到系统不断在运行check-system, 查看一下这个文件的内容

```


tre@tre:/tmp$ ls -al /usr/bin/check-system '+%Y-%m-%d %H:%M:%S'
`echo "Service started at ${DATE}"

 | systemd-cat -p infowhile
 :do
echo "Checking..."

;done


```

修改文件内容, 把反弹shell语句插入进去  

![](../Images/652f9d0da5722dbaa0197724abb05ad5.png)
