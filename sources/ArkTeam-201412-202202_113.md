# 云桌面（Cloud Desktop）

目前，对云桌面尚无明确的定义。但云桌面被普遍认为是基于分布式云计算存储技术，集成互联网精华应用，依托高度加密算法，可为用户提供私有云服务解决方案的一项服务。目前各大厂商推出版本众多的云桌面服务，采用技术也不全然相同，目前常见的云桌面主要有以下几种模式：  

1、虚拟桌面架构(Virtual Desktop Instructure，VDI)模式，即虚拟机在云端，计算能力也在云端。这类云桌面源起于主机虚拟化技术，即虚拟机技术。用户在云端拥有一台有虚拟机，其中有独立的操作系统，用户独享该虚拟机的CPU、内存等资源。  

2、托管虚拟应用(Hosted Virtual Application)，也称远程共享应用，已经应用广泛的远程桌面采用的也是这种技术。此时计算能力仍在云端，但用户的桌面以用户所需使用应用集合的形式体现，多用户在云端共享一台虚拟机，每个用户没有独立的操作系统及计算资源，但有自己的应用进程。  

3、本地虚拟应用(Local Virtual Application)，也是很多厂家宣扬的流技术。此时计算能力在用户本机，但应用程序在云端，使用应用程序时将从云端"流向"客户端。这种技术可以作为终端软件管理的方式，例如从集中主机向各客户端推送更新的软件或新功能软件，也可以在当应用软件与客户端操作系统或其他软件冲突时使用。  

近些年云桌面产品层出不穷，也收到广大用户的喜爱，使用云桌面产品主要有以下几点优势：  

1、安全。由于数据存储在服务器，使用过程中的数据安全能得到有效的保证，服务器的安全级别比主机要高出几个数量级。同时也能设置每台虚拟机的网络和usb等权限，杜绝了U盘感染病毒和木马的风险。  

2、管理方便。因为云桌面采用集中管理，布署一个环境，只需建一个模板，然后模板覆盖所有的虚拟机即可。包括批量开关机，批量升级系统，批量安装软件都可以实现。  

3、运维成本低。云终端故障率低，即使出现故障，云端重启虚拟机或者重新覆盖一个模板即可，无需像传统PC一样更换硬件。硬件升级，也只需添加服务器，然后修改虚拟机的CPU、内存、硬盘参数即可。  

目前云桌面技术较为成熟，对于日常办公完全可以胜任，Office办公软件、上网、通讯工具等使用并无障碍。但在图像处理、视频剪辑等方面稍显不足，但相信在市场的推动下，新的云桌面适用解决方案也会很快实现。
