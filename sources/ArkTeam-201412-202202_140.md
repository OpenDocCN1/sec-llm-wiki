# 检测企业网络中有凭证的鱼叉式钓鱼攻击

原文标题：Detecting Credential Spearphishing Attacks in Enterprise Settings  

原文会议：26^(th) USENIX Security Symposium,2017。  

在近些年中，成功的鱼叉式钓鱼攻击造成许多重大信息泄露事件。当人们加强了技术方面的检测和预防能力之后，人为因素就成了更重要的入侵环节。帮助人们避免社会工程学攻击变得愈发重要。该文章的研究有助于减少未来发生的鱼叉式钓鱼攻击。该文章还获得Facebook价值10万美元的互联网防御奖。高检测率、低误报率是该检测系统的主要突破，图1为检测系统流程图。

图1 实时检测系统流程图  

他们在研究中首先针对鱼叉式钓鱼攻击的基础特征进行分析，总结出成功的鱼叉式钓鱼攻击在不同阶段的特征。然后引入只需未标注分类的数据即可训练的DAS（Directed Anomaly Scoring，定向异常得分）系统。将鱼叉式钓鱼攻击的特征与 DAS 的大量数据分析处理相结合，就能得到鱼叉式钓鱼攻击的实时检测工具。  

第一阶段，他们让 DAS 系统分析了某个拥有几千名员工的大公司3.7 亿多封邮件以及相关的 HTTP 日志，用作对 DAS 的训练。接受训练后，DAS 系统中配置了一系列评估指标，用于评估最新接收到的邮件。第一阶段的评估指标包括：发件人域名信誉得分、发件人信誉得分。其中，域名信誉指标的评估需要分析邮件中的链接，确认其是否含有风险。此外，DAS还会分析 SMTP、NIDS 和 LDAP 日志；检测来自新 IP 的登录情况、每位员工的总登录情况、不活跃的时段等。  

第二阶段，一旦发件人和 URL 的信息被搜集完毕，DAS 系统就会评估并确认是否发出警报。DAS 会根据邮件的可疑程度把所有事件分级，并在分级之后将最高层级的事件筛选出来，向安全团队发出警告。  

第三阶段，收到一封新邮件时DAS 对这些指标进行评估后，就能实时检测出欺诈性网址、欺诈性发件人姓名，甚至检测出被攻击的账户对同事带来的侧面攻击。  

该系统在19封攻击邮件中检测出6封已知的成功钓鱼邮件，9封未成功的已知的钓鱼邮件，2封未知的成功钓鱼邮件，误报率降到0.004%，比之前的研究成果低了近200倍。
