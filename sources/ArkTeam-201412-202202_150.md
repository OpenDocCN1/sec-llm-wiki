# 美军网络司令部升级&美国情报体系大起底

2017年8月18日，特朗普正式宣布将网络司令部级别提升为联合作战司令部(Unified Combatant Command，简称UCC)。升级后，网络司令部将成为美军第十个联合作战司令部，与原上级单位战略司令部"平起平坐"，均为美军最高级别的联合作战司令部。  

联合作战司令部是直属美国国防部的跨军种司令部，每个司令部由一名上将指挥。在美国网络司令部升级之前，美军已有九个联合作战司令部，其中有六个按区域划分，另外三个按功能划分。网络司令部由奥巴马政府于2009年成立，隶属于美国战略司令部，由美国国家安全局（National Security Agency，简称NSA）直接领导，且和国家安全局由同一名上将指挥。

由于网络司令部和国家安全局一直都是由统同一个领导管理，业务上也有交叉，而国家安全局是美国情报体系中非常重要的一个部门，因此，很多人认为网络司令部也属于美国情报体系之中。实际上网络司令部并不在美国情报体系内，属于作战部门，尤其是在它独立之后，与国家安全局在行政上几乎没有联系了。  

美国情报体系包括17个情报机构，架构复杂。国家情报总监领导其余16个情报机构，其中包括：  

独立机构中央情报局（CIA）；  

隶属于国防部的美国空军情报监视侦查局（AFISRA）、军事情报部队（MI）、国防情报局（DIA）、美国海军陆战队情报部队（MCIA）、国家地理空间情报局（NGA）、国家侦查局（NRO）、国家安全局（NSA）、美国海军情报室（ONI）；  

隶属于能源部的情报防谍室（OICI）；  

隶属于国土安全部的情报分析室（I&A）和美国海岸警卫队调查处（CGI）；  

隶属于司法部的联邦调查局国家安全科（FBI/NSB）和美国缉毒局国家安全情报室（DEA/ONSI）；  

隶属于国务院的情报研究局（INR）；  

隶属于财政部的美国财政部恐怖主义及金融情报次长（TFI）。

升级后的网络司令部将更专注于防范和遏制来自外国军方、恐怖组织的网络攻击。美防长马蒂斯近期将向特朗普推荐一名四星上将担任该司令部的新任指挥官。网络司令部计划在2018年9月30日前完成网络部队建设任务，届时它将拥有全面作战能力，将有133个行动组，人员超过6200人。  

特朗普表示，新的联合作战司令部将精简指挥时间，加强美国网络空间作战能力，并为改进国防增加机会。  

网络司令部的升级表明了美国对网络战的重视，体现了美国在未来可能出现的网络战争中想要获得先机的决心，显示了美国对网络战理论、力量、武器、手段和能力建设的强力推进。
