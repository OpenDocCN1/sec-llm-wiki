# 你愿意为世界和平妥协自己的隐私吗？

犯罪分子正在利用“用户隐私”这一免死牌，来逃避执法部门的打击。  

iMessage、WhatsApp、Telegram等通信工具，使用了高强度的加密技术来保护用户的通信隐私安全，但也为恐怖分子逃避监控带来的便利。近些年的一些极端分子的恐怖袭击中，攻击者就是通过 Telegram 进行的联系的。因为无法拦截和破解通讯信息，各国政府和执法机构感到非常沮丧，并强烈要求在加密通讯中添加后门来监控恐怖分子通讯。虽然Telegram从2015年起逐步关闭了78个ISIS相关频道，2017年也在持续清除恐怖活动相关的公开广播内容及频道，但仍然表示会坚守用户隐私，不干涉私人之间的通讯内容。  

Tor网络诞生的目的之一是以匿名通信的方式，让用户在完全“隐身”的环境下上网，以保护用户隐私，但这也为网络犯罪的滋生提供了温床，如儿童色情，敲诈，恐怖事件等。为了打击依托Tor的网络犯罪，2002起FBI就开始在Tor中使用网络调查技术（Network Investigative Technique，NIT）侦查隐匿的犯罪分子。NIT能够获取的信息包括计算机名称和地址、完整的文件、网络历史记录、网络摄像头活动等用户隐私信息。该技术引发了极大的争议，政府机构不断争取扩大NIT的使用范围，而各大公民自由组织也极力抵制，捍卫自身的隐私权利。  

保护用户隐私与打击网络犯罪之间，似乎有着不可调和的矛盾，永远是一个争论不休的话题。大家怎么看待这一问题，是否愿意为了世界和平而妥协自己的隐私？
