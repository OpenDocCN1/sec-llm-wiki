# 漏洞产生原因

总结一下1.2.24的漏洞产生原因，type字段的特性会加载任意类(反序列化入口点)，反射调用特定的setter和getter(反序列化链入口)，进而从这些链子比如TemplatesImpl走到加载字节码(反序列化的触发payload)

        //2.长度判断
