safe\_script\_new:

题目给了三个文件的源码，自定义了 sesssion 的处理。session 会接收用户输入的 sessid cookie 作为文件名，最终用 FileRead 类创建文件并用fopen打开。文件的内容则是由用户 post 输入的 ket 和 value 决定。于是直接 php://filter 创建文件，用 key 和 value 写文件内容就可以getshell了。

  

![](../Images/7ae65c3c4555b56b472dc2a01fbc1caa.png)

  

flag 在根目录但是需要 root 读取。通过根目录的 start.sh 找到/scan/run.py 可知，root 会一直寻找 ps -ef 中命令带有 java 字样的进程，readlink 获取进程对应可执行文件的路径，并且最终以 root 身份执行这个文件（--version 选项就可以忽略了）。

  

于是写一个简单的马编译上传运行，重命名 java，终止第一次 www-data 的 shell 后，等着root 连接即可:
