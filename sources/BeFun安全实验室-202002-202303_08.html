本文是路由器的NetUSB模块漏洞挖掘系列第一章，描述了如何自行编译一个包含用户自定义的Linux内核模块的mips镜像，并用qemu启动以作为漏洞挖掘调试的环境。

翻译自https://blog.security.sea.com/posts/netusb-emulation/，在原文基础上有部分修改和补充。

原作者Bien Pham (@bienpnn)在 Pwn2Own Austin 2021 上利用了NetUSB模块的漏洞对TP-Link Archer C7和Netgear R6700v3路由器完成了攻击。本文是原作者所在团队 Sea Security 对NetUSB模块漏洞利用的第一篇文章，总结了如何在路由器上加载并调试一个内核模块，以及如何在模拟mips架构运行一些用户态的程序。

目标

TP-Link Archer C7 router, MIPS32r2 Big Endian, firmware version 211022.

为什么选择NetUSB作为目标

台湾 USB 解决方案提供商 KCodes，专门从事 USB over IP 软件开发。NetUSB 是 KCodes 开发的一种内核模块连接解决方案，允许网络中的远程设备与直接插入到路由器的 USB 设备进行交互。只要路由器厂商在设备上添加 USB 端口，用户便可以通过这一端口共享联网的打印机和 USB 驱动器。

NetUSB 服务会在公网上开放一个20005的端口，一般我们针对路由器的攻击都是在内网（LAN）上的，谁不想要一个打全网（WAN）的洞呢？而且历史上这个组件也出过几个可以 RCE 的洞（CVE-2021-45608，CVE-2021-45388），所以 NetUSB 是一个很好的目标。

把路由器的文件系统的路径命名为$ROUTER_ROOTFS：

$ ROUTER_ROOTFS=`pwd`

环境配置

GPL 包

由于 OpenWrt 和 Linux 内核遵守 GPL 协议，所以 TPLink 官方提供了修改后的源码，Archer C7 V5 的 GPL 包可在这里下载，然后在 32 位机器上用 GCC 4.x 编译。

把 GPL 的目录命名为$GPL_PACKAGE，分析 GPL 包后可以知道内核版本是linux-3.3.8（有一个配置文件位于$GPL_PACKAGE/build/linux-3.3.config），内核补丁位于$GPL_PACKAGE/openwrt/target/linux：

$ wget https://static.tp-link.com/resources/gpl/ArcherC7V5.tar.bz2
$ tar -xf ArcherC7V5.tar.bz2
$ cd Archer_C7_V5/
$ GPL_PACKAGE=`pwd`
$ cd ..

通过串口获取 shell

原作者一开始尝试了通过焊接主板上的串口来拿 shell，但是没成功，方法在这里，所以最后决定做一个可以加载 NetUSB 模块的 MIPS VM Buildroot 镜像，只需要把之前在 GPL 下载的补丁打上就 OK。

内核编译

环境

原作者使用的是 Ubuntu 16.04.7 LTS i386，我用的是 Ubuntu 20.04.4 LTS amd64，实测可以成功编译并启动。

Buildroot 下载

$ wget https://buildroot.org/downloads/buildroot-2016.02.tar.bz2
$ tar -xf buildroot-2016.02.tar.bz2

内核下载

配置了 buildroot 的目录为BUILD_ROOT

$ cd buildroot-2016.02/
$ BUILD_ROOT=`pwd`
$ wget https://mirrors.edge.kernel.org/pub/linux/kernel/v3.x/linux-3.3.8.tar.bz2
$ tar -xf linux-3.3.8.tar.bz2

打补丁

$ rsync -av $GPL_PACKAGE/openwrt/target/linux/generic/files/ $BUILD_ROOT/linux-3.3.8/
$ mkdir $BUILD_ROOT/linux-patches
$ rsync -av $GPL_PACKAGE/openwrt/target/linux/generic/patches-3.3/ $BUILD_ROOT/linux-patches/
$ rsync -av $GPL_PACKAGE/openwrt/target/linux/malta/patches-3.3/ $BUILD_ROOT/linux-patches/

打包

$ cd $BUILD_ROOT
$ rm linux-3.3.8.tar.bz2
$ tar -cjSf linux-3.3.8.tar.bz2 linux-3.3.8

然后把文末的配置文件复制到$BUILD_ROOT/linux-3.3.8.config，这个配置文件由 GPL 包中的配置文件修改而来，例如将目标机器更改为Malta、启用PCI和virtIO等。

把 NetUSB 模块复制到镜像中

$ mkdir -p $BUILD_ROOT/overlay/etc/init.d/
$ mkdir -p $BUILD_ROOT/overlay/lib/modules/
$ cp -r $ROUTER_ROOTFS/lib/modules/kcodes $BUILD_ROOT/overlay/lib/modules/

原作者通过对 NetUSB 模块的逆向发现需要配置br0桥接设备和usbcore模块功能，所以需要配置一下网络，创建以下两个文件并给权限。此时我们还可以放一些其他的文件进去，比如gdbserver，直接复制到$BUILD_ROOT/overlay/下即可。

gedit $BUILD_ROOT/overlay/etc/init.d/S98bridge
gedit $BUILD_ROOT/overlay/etc/init.d/S99netusb
chmod +x $BUILD_ROOT/overlay/etc/init.d/*

S98bridge：

#!/bin/sh

case "$1" in
  start)
  echo "Setting up bridge..."
 brctl addbr br0
 brctl addif br0 eth0
 ip link set eth0 up
 ip link set br0 up
 udhcpc -i br0
 ;;
  stop)
 printf "Deleting bridge..."
 ip link set br0 down
 ip link set eth0 down
 brctl delif br0 eth0
 brctl delbr br0
 ;;
  restart|reload)
 "$0" stop
 "$0" start
 ;;
  *)
 echo "Usage: $0 {start|stop|restart}"
 exit 1
esac

exit $?

S99netusb：

#!/bin/sh

case "$1" in
  start)
  echo "Starting NetUSB..."
 modprobe usbcore
 insmod /lib/modules/kcodes/GPL_NetUSB.ko
 insmod /lib/modules/kcodes/NetUSB.ko
 ;;
  stop)
 printf "Stopping NetUSB..."
 rmmod /lib/modules/kcodes/NetUSB.ko
 rmmod /lib/modules/kcodes/GPL_NetUSB.ko
 modprobe -r usbcore
 ;;
  restart|reload)
 "$0" stop
 "$0" start
 ;;
  *)
 echo "Usage: $0 {start|stop|restart}"
 exit 1
esac

exit $?

然后写个run.sh启动 VM：

#!/bin/bash
qemu-system-mips \
  -M malta \
  -m 128M \
  -nographic \
  -append "console=ttyS0,115200" \
  -netdev user,id=lan,hostfwd=tcp::20005-:20005,hostfwd=tcp::33344-:33344 \
  -device virtio-net-pci,netdev=lan \
  -kernel $BUILD_ROOT/output/images/vmlinuz \
  -s
