# \[漏洞通告\]Apache Log4j任意代码执行漏洞安全风险提示

**No.1**

**漏洞描述**

  

近日，Apache Log4j2 发布安全更新修复了一处远程代码执行漏洞。经过分析和确认，该漏洞影响范围极其广泛，危害极其严重。我们建议尽快采取安全措施阻止漏洞攻击。

Apache Log4j2 是一款开源的 Java 日志记录工具，大量的业务框架都使用了该组件（Apache Druid、Apache Flink等等）。由于Apache Log4j2某些功能存在递归解析功能，攻击者可直接构造恶意请求，触发远程代码执行漏洞。但在实现的过程中，并未对输入进行严格的判断，从而造成漏洞的发生。

**No.2**

**漏洞编号**

  

  

暂无

  

**No.3**

**风险等级**

  

  

  高风险

  

**No.4**

**影响范围**

  

  

Apache Log4j 2.x <= 2.14.1

  

**No.5**

**修复方案**

  

1.  升级Apache Log4j2所有相关应用到最新的 log4j-2.15.0-rc2 版本(需要评估业务稳定性)
    
2.  升级已知受影响的应用及组件。
    
3.  做好出网限制。
