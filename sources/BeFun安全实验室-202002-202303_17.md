# Apache Solr 存在任意文件读取漏洞

**No.1**

**漏洞描述**

  

Apache Solr是一个开源搜索服务引擎，Solr 使用 Java 语言开发，主要基于 HTTP 和 Apache Lucene 实现。近日，Apache Solr全版本发现存在任意文件读取漏洞，在Solr默认安装后无需任何其它配置即可读取系统任意文件。鉴于漏洞危害较大，建议客户尽快应用缓解措施。
