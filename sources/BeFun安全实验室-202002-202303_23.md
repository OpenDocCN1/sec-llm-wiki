# \[漏洞通告\]Apache Struts远程代码执行漏洞S2-061（CVE-2020-17530）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NDEzMDgzNw==&mid=2247483942&idx=1&sn=94a22af8645a6fa938d24956aba85487&chksm=eb19f0dcdc6e79ca05f0cfa3cbb33bfd5497a32d69500e8584d0621766e2b17d6533491b81b1&scene=126&sessionid=1681668873#rd](http://mp.weixin.qq.com/s?__biz=MzI3NDEzMDgzNw==&mid=2247483942&idx=1&sn=94a22af8645a6fa938d24956aba85487&chksm=eb19f0dcdc6e79ca05f0cfa3cbb33bfd5497a32d69500e8584d0621766e2b17d6533491b81b1&scene=126&sessionid=1681668873#rd)

**No.1**

**漏洞描述**

  

Apache structs2 框架是一个用于开发Java EE网络应用程序的开放源代码网页应用程序架构。Apache structs2 在2020年12月8日披露Struts 远程代码执行漏洞S2-061 （CVE-2020-17530），如果开发人员通过使用%{...} 语法对OGNL进行强制评估，则某些标记的属性可能会执行双重评估。对不受信任的用户输入使用强制OGNL评估可能存在OGNL表达式注入漏洞。

**No.2**

**漏洞编号**

  

  

CVE-2020-17530

  

**No.3**

**风险等级**

  

  

  高风险

  

**No.4**

**影响范围**

  

  

Struts 2.0.0-Struts 2.5.25

  

**No.5**

**修复方案**

  

升级到安全版本Struts 2.5.26或更高版本
