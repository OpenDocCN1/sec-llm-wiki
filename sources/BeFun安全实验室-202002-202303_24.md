# \[漏洞通告\]Apache Solr configset upload文件上传漏洞（CVE-2020-13957）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NDEzMDgzNw==&mid=2247483936&idx=1&sn=53ba5bce9818c921a528e850ebaa9614&chksm=eb19f0dadc6e79cc310523b6422e6875f67e9ebafb02eaaf553150d437e0f27b36d66cf4cb8c&scene=126&sessionid=1681668873#rd](http://mp.weixin.qq.com/s?__biz=MzI3NDEzMDgzNw==&mid=2247483936&idx=1&sn=53ba5bce9818c921a528e850ebaa9614&chksm=eb19f0dadc6e79cc310523b6422e6875f67e9ebafb02eaaf553150d437e0f27b36d66cf4cb8c&scene=126&sessionid=1681668873#rd)

**No.1**

**漏洞描述**

  

Apache Solr是用Java编写、运行在Servlet容器（如Apache Tomcat或Jetty）的一个独立的全文搜索服务器。是Apache Lucene项目的开源企业搜索平台。近日Apache Solr发布安全更新，修复了CVE-2020-13957 Apache Solr configset upload文件上传漏洞。攻击者可以构造特定请求，上传相关恶意文件，直接获取到服务器权限。

**No.2**

**漏洞编号**

  

  

CVE-2020-13957

  

**No.3**

**风险等级**

  

  

  高风险

  

**No.4**

**影响范围**

  

  

Apache Solr 6.6.0-6.6.5  
ApacheSolr 7.0.0-7.7.3  
ApacheSolr 8.0.0-8.6.2

  

**No.5**

**修复方案**

  

升级至安全版本
