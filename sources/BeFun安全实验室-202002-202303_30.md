# 【漏洞通告】Nexus Repository Manager 存在远程命令执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NDEzMDgzNw==&mid=2247483898&idx=1&sn=10c8fdf5db5941d888f79afbc351489a&chksm=eb19f300dc6e7a16d41684e7c7b77f060e5b17436292b01d8c5d8ccd8e8c6a72e76f8bffffa3&scene=126&sessionid=1681668873#rd](http://mp.weixin.qq.com/s?__biz=MzI3NDEzMDgzNw==&mid=2247483898&idx=1&sn=10c8fdf5db5941d888f79afbc351489a&chksm=eb19f300dc6e7a16d41684e7c7b77f060e5b17436292b01d8c5d8ccd8e8c6a72e76f8bffffa3&scene=126&sessionid=1681668873#rd)

**No.1**

**漏洞描述**

  

Sonatype Nexus Repository 是一个开源的仓库管理系统，在安装、配置、使用简单的基础上提供了更加丰富的功能。近日，Sonatype Security Team官方发布了一则关于Nexus Repository Manager 3.x产品的远程代码执行漏洞通告。攻击者可在登录后利用该漏洞执行任意命令。漏洞利用需要登录，危害相对较小。

**No.2**

**漏洞编号**

  

  

CVE-2020-15871

  

**No.3**

**风险等级**

  

  

  高风险

  

**No.4**

**影响范围**

  

Nexus RepositoryManager 3 OSS < 3.25.1

Nexus Repository Manager 3 Pro < 3.25.1

  

**No.5**

**修复方案**

  

升级到Nexus Repository Manager 3.x 至最新版本 3.25.1
