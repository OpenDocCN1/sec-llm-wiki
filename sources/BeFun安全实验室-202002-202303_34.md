**No.1**

**漏洞描述**

  

2020年7月14日，Microsoft 发布了一个有关CVE-2020-1350 | 中所述问题的安全更新。Windows DNS 服务器远程代码执行漏洞。此通报介绍了一个关键的远程代码执行（RCE）漏洞，该漏洞影响配置为运行 DNS 服务器角色的 Windows 服务器。

**No.5**

**修复方案**

  

1）更新系统补丁：确保服务器打上了所需的补丁，打开 Windows Update 更新功能或下载修复补丁，点击“检查更新”；2）临时缓解方案：如果无法快速应用更新，则可以运行如下命令缓解该漏洞：

 HKEY\_LOCAL\_MACHINE\\SYSTEM\\CurrentControlSet\\Services\\DNS\\Parameters 

DWORD = TcpReceivePacketSize

Value = 0xFF00

注意 必须重新启动 DNS 服务才能使注册表更改生效。

    默认值（也是 max）值 = 0xFFFF

    推荐值 = 0xFF00 （小于 max 的255字节）

实现解决方法后，当上游服务器的 DNS 响应大于65280字节时，Windows DNS 服务器将无法解析其客户端的 DNS 名称。
