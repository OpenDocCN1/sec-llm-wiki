# \[漏洞通告\]WebLogic远程代码执行漏洞(CVE-2020-14645)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NDEzMDgzNw==&mid=2247483843&idx=1&sn=d5c811e6e57647c72783617314ad902a&chksm=eb19f339dc6e7a2f42c6c700d9c4e3504b3532205b0730ed427e6331bcb3e086a78dfc8a0165&scene=126&sessionid=1681668878#rd](http://mp.weixin.qq.com/s?__biz=MzI3NDEzMDgzNw==&mid=2247483843&idx=1&sn=d5c811e6e57647c72783617314ad902a&chksm=eb19f339dc6e7a2f42c6c700d9c4e3504b3532205b0730ed427e6331bcb3e086a78dfc8a0165&scene=126&sessionid=1681668878#rd)

**No.1**

**漏洞描述**

  

今日，Oracle官方发布WebLogic安全更新，修复了一处远程代码执行漏洞，该漏洞风险极高，CVSS评分为9.8。通过T3协议进行利用，攻击者可以实现远程代码执行，进而控制服务器。漏洞利用难度较低，危害较大，建议立即修复。

**No.2**

**漏洞编号**

  

  

CVE-2020-14645

  

**No.3**

**风险等级**

  

  

  高风险

  

**No.4**

**影响范围**

  

  

Oracle WebLogic Server 12.2.1.4

  

**No.5**

**修复方案**

  

1.  官网已发布安全更新，安装安全补丁即可。
    
2.  限制T3访问来源阻止攻击。
