# \[漏洞通告\]F5 BIG-IP 存在远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NDEzMDgzNw==&mid=2247483838&idx=1&sn=9fe2718c2f6624f13d441635e4ee84f5&chksm=eb19f344dc6e7a522608d7d7616b7d58b2d8227c8045314212eb42bae25257da9bc297fc9e44&scene=126&sessionid=1681668878#rd](http://mp.weixin.qq.com/s?__biz=MzI3NDEzMDgzNw==&mid=2247483838&idx=1&sn=9fe2718c2f6624f13d441635e4ee84f5&chksm=eb19f344dc6e7a522608d7d7616b7d58b2d8227c8045314212eb42bae25257da9bc297fc9e44&scene=126&sessionid=1681668878#rd)

**No.1**

**漏洞描述**

  

F5 BIG-IP 是美国 F5 公司的一款集成了网络流量管理、应用程序安全管理、负载均衡等功能的应用交付平台。

2020年7月1日，F5 官方发布安全通告，修复了一处BIG-IP远程代码执行漏洞。

  

该漏洞为前台远程代码执行，攻击者可以在未授权的情况下，精心构造恶意请求，实现远程代码执行。可以直接获取到服务器权限。

**No.2**

**漏洞编号**

  

  

CVE-2020-5902

  

**No.3**

**风险等级**

  

  

  高风险

  

**No.4**

**影响范围**

  

  

F5 BIG-IP < 15.1.0.4F5 

F5 BIG-IP < 14.1.2.6F5 

F5 BIG-IP < 13.1.3.4F5 

F5 BIG-IP < 12.1.5.2F5 

F5 BIG-IP < 11.6.5.2

  

**No.5**

**修复方案**

  

官网已发布安全更新，升级至最新版本即可。
