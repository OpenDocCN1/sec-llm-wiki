## 04 请求下载（0x1a）

请求下载一般是指step7或者博图软件发送块数据到PLC。请求报文如下：

![](../Images/a621f85da1ff0b5c56d5a0c0ef180499.png)

这个报文就是要告诉PLC要下载块。这些块在上传、下载请求中使用特别的文件系统寻址，这个文件名的结构如下：

File identifier:文件标识符。一般有\_( Complete Module)和$( Module header forup-loading)两种文件标识符。

Block type: 块类型，如上图；

Block number: 块编号；

Destination filesystem: 目标文件系统，有三种文件系统：

   P（Passive (copied, but not chained) module)：被动文件系统

A (Activeembedded module)：主动文件系统

B (Active aswell as passive module)：既主既被文件系统

这里文件标识是\_( Complete Module)，块类型是0A(DB)，块的编号为00001，目标块的文件系统是P (Passive (copied, but not chained) module)，所以文件名为\_0A00001P。

## 07 密码破解

        西门子设备的上传下载一般受密码保护，如果获取到了包含密码的报文，应该怎么破解呢？

       获取到的设置密码的报文：

![](../Images/51dd023df9da4e95eaa0f8f06396e374.png)

这里主要关心设置的密码的数据，s7-300设置密码采用了加密传输，加密过程如下：

1.  对前两个数与0x55进行异或操作：0x32^0x55=a,0x22^0x55=w
    
2.  对剩下的数组操作，操作为与自己距离为-2的数进行异或，再与0x55异或
