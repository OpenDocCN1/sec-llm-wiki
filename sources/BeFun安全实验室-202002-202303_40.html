[漏洞通告]Windows SMBv3 RCE漏洞利用工具已被公开

原文：http://mp.weixin.qq.com/s?__biz=MzI3NDEzMDgzNw==&mid=2247483793&idx=1&sn=8ff8a3bbaa8ec35d9bb4c71aa127c225&chksm=eb19f36bdc6e7a7d078508c3ee9c109475a043662a91eaf55da8974e946eabd0f9e2e519ce0a&scene=126&sessionid=1681668878#rd

No.1

漏洞描述


昨日，国外安全研究员公开了一份CVE-2020-0796利用代码，攻击者可能基于此POC编写传播该漏洞的武器化工具。


该漏洞源于SMBv3没有正确处理压缩的数据包，在解压数据包的时候使用客户端传过来的长度进行解压时，并没有检查长度是否合法，最终导致整数溢出。攻击者利用该漏洞可在目标SMB Server或者Client中执行任意代码。


漏洞只影响Windows 10系统和Server 1903、1909系统版本，不影响主流Windows服务器版本。

No.2

漏洞编号



CVE-2020-0796


No.3

风险等级



  中风险


No.4

影响范围



Windows 10 Version 1903 for 32-bit Systems

Windows 10 Version 1903 for x64-based Systems

Windows 10 Version 1903 for ARM64-based Systems

Windows Server, Version 1903 (Server Core installation)

Windows 10 Version 1909 for 32-bit Systems

Windows 10 Version 1909 for x64-based Systems

Windows 10 Version 1909 for ARM64-based Systems

Windows Server, Version 1909 (Server Core installation)


No.5

修复方案


1）关闭SMB服务端口，禁止139和445端口对外部开放。


2）安装微软安全补丁：https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2020-0796


3）使用注册表禁用SMBv3 的compression功能来达到漏洞缓解。
