No.1

漏洞描述


近日，获取到漏洞情报，Fastjson <=1.2.68版本存在远程代码执行漏洞，攻击者成功利用该漏洞可以直接获取到服务器权限。


Fastjson是一款开源的常用JSON组件，它可以解析 JSON 格式的字符串，支持将 Java Bean 序列化为 JSON 字符串，也可以从 JSON 字符串反序列化到 JavaBean。

No.2

漏洞编号



暂无


No.3

风险等级



  高风险


No.4

影响范围



Fastjson <= 1.2.68


No.5

修复方案


截止目前，官网暂未发布新版本修复该漏洞，可采取如下措施进行处理：

1）关注官方更新信息，及时升级至最新版本，即1.2.69。


2）升级版本至Fastjson 1.2.68，开启 SafeMode 来防护攻击。（需评估对业务的影响）


3）从长远来看，建议使用Gson 等其他组件进行替换。
