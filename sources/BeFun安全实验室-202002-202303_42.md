# \[漏洞通告\]Fastjson <=1.2.68全版本远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NDEzMDgzNw==&mid=2247483788&idx=1&sn=43d5bef9bea25b2b7b1a385a65703010&chksm=eb19f376dc6e7a60ae608e3b1c9fae7c31097dd598f97297eeb9fb4b38a42e1bd46db724e64f&scene=126&sessionid=1681668878#rd](http://mp.weixin.qq.com/s?__biz=MzI3NDEzMDgzNw==&mid=2247483788&idx=1&sn=43d5bef9bea25b2b7b1a385a65703010&chksm=eb19f376dc6e7a60ae608e3b1c9fae7c31097dd598f97297eeb9fb4b38a42e1bd46db724e64f&scene=126&sessionid=1681668878#rd)

**No.1**

**漏洞描述**

  

近日，获取到漏洞情报，Fastjson <=1.2.68版本存在远程代码执行漏洞，攻击者成功利用该漏洞可以直接获取到服务器权限。

  

Fastjson是一款开源的常用JSON组件，它可以解析 JSON 格式的字符串，支持将 Java Bean 序列化为 JSON 字符串，也可以从 JSON 字符串反序列化到 JavaBean。

**No.2**

**漏洞编号**

  

  

暂无

  

**No.3**

**风险等级**

  

  

  高风险

  

**No.4**

**影响范围**

  

  

Fastjson <= 1.2.68

  

**No.5**

**修复方案**

  

截止目前，官网暂未发布新版本修复该漏洞，可采取如下措施进行处理：

1）关注官方更新信息，及时升级至最新版本，即1.2.69。

  

2）升级版本至Fastjson 1.2.68，开启 SafeMode 来防护攻击。（需评估对业务的影响）  

  

3）从长远来看，建议使用Gson 等其他组件进行替换。
