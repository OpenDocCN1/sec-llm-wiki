# \[漏洞通告\]CVE-2020-9484 Apache Tomcat 远程代码执行

**No.1**

**漏洞描述**

  

近日，Apache Tomcat官方发布了安全通告，披露了一个通过持久化Session可能导致远程代码执行的漏洞CVE-2020-9484。使用不安全的配置将导致攻击者可以发送恶意数据包造成远程代码执行。攻击者通过精心构造的数据包，能够对使用了自带session同步功能的Tomcat服务器进行攻击。

  

Tomcat是Apache 软件基金会（Apache Software Foundation）的Jakarta 项目中的一个核心项目，是一个开源的JSP Web应用软件的基于Java的Web应用软件容器。

**No.2**

**漏洞编号**

  

  

CVE-2020-9484

  

**No.3**

**风险等级**

  

  

  高风险

  

**No.4**

**影响范围**

  

  

Apache Tomcat 10.x < 10.0.0-M5

Apache Tomcat 9.x < 9.0.35

Apache Tomcat 8.x < 8.5.55

Apache Tomcat 7.x < 7.0.104

  

**No.5**

**修复方案**

  

1.目前官方已经发布更新，升级Apache Tomcat至不受影响版本。

2.禁用FileStore功能。
