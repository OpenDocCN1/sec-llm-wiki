**XSS之htmlspecialchars**  

在php中，htmlspecialchars()函数是使用来把一些预定义的字符转换为HTML实体，返回转换后的新字符串，原字符串不变。

htmlspecialchars ( string \`$string\` \[, int \`$flags\` = ENT\_COMPAT | ENT\_HTML401 \[, string \`$encoding\` = ini\_get("default\_charset") \[, bool \`$double\_encode\` = \*\*\`TRUE\`\*\* \]\]\] ) : string

如果指定的编码 encoding 里， string 包含了无效的代码单元序列， 没有设置 ENT\_IGNORE 或者 ENT\_SUBSTITUTE 标记的情况下，会返回空字符串。
