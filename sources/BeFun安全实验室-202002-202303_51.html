前言

        在前文《Msf系列--(2)metasploit自定义模块开发基础知识》我们介绍了msf开发所需ruby语言的一部分知识，并观摩了metasploit里的一些成品模块的编写方法。本文介绍一个简单的后渗透测试模块(获得系统权限后使用)的开发，然后再继续逐步扩展它的功能。

一、自定义后渗透测试模块--启用远程桌面

  1. 代码实现和说明

    Windows大多数配置都存储在注册表内，修改Windows注册表能够实现更改Windows配置，开启远程桌面服务也能通过注册表修改。下面我们看下如何通过代码实现这个简单的模块。

  • 第一步：指明要用到的库，定义模块头，定义模块基本信息。第一步的代码如下。

  1 require 'rex'
  2 require 'msf/core/post/windows/registry'
  3 
  4 class MetasploitModule < Msf::Post
  5   include Msf::Post::Windows::Registry
  6   def initialize
  7     super(
  8     'Name'        => 'En RDP',
  9     'Description'         => 'This Module Modify Registor To Enable RDP',
 10     'License'        => MSF_LICENSE,
 11     'Author'        => 'OWL'
 12      )
 13   end
 14 

代码说明：第1和第2行代码导入rex库和编辑修改windows注册表的registry库，第4行代码声明这是一个Metasoloit的post模块，第5行包含Registry库文件以使用这个文件内定义的函数，第6到13行初始化一些info信息。

  • 第二步：修改windows注册表键值对，启用远程桌面，设置远程桌面端口为3389，代码有点长，我们放在说明后面。

    代码说明：下面的代码主要修改三个注册表项的键值，所以三个修改注册表部分一个原理，选我们说明其中一个部分进行关键行说明，即第16行和第19行至30行。

    第16行把注册表项的路径赋值给一个名为key_rdp_serv的变量，其中路径中的反斜线("\")需要使用另一个反斜线进行反转义，否则程序运行时会当作转译符。

    第19行使用了existsmeterpreter_registry_key_exist?()函数检测注册表项是否存在，bool型的结果ture或者false赋值给exists_rdp_serv，这个函数是Registry库内定义的函数。函数功能和返回结果等可以参考官方的Metasploit编程API。

    第20行使用了if判断注册表项是否存在，如果不存在则使用第21行至第25行的代码创建注册表项并给注册表键“fDenyTSConnections”的值为0，如果存在，则使用第27行至第30行代码直接修改注册表键“fDenyTSConnections”的值为0。

    第22行目的是调用Registry的registry_createkey()函数创建key_rdp_serv。

    第24行目的是给key_rdp_serv注册表项的fDenyTSConnections键的值设置为0(16进制表示)

最后再说明一下函数print_error()、print_good()、print_status()，他们都是调用print_line()函数分别添加上不同颜色的符号前缀“-”、“+”、“*”。

在print_line系列方法的官方API 中给出了这些函数的源码，我们看下它print_line()和print_good()的源码：

# File 'lib/rex/ui/text/output.rb', line 65

def print_line(msg = '')
 print(msg + "\n")
end
# File 'lib/rex/ui/text/output.rb', line 57

def print_good(msg = '')
  print_line("%bld%grn[+]%clr #{msg}")
end
