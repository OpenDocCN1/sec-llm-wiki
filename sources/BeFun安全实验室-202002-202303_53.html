前言

Metasploit简称msf，是一款优秀的开源安全检测工具，能够帮助安全工程师识别安全问题、验证漏洞和对信息系统进行安全评估。msf由Ruby语言开发，其中针对每种漏洞都对应一个或多个ruby脚本。msf为安全工程师提供了大量的安全测试方面的功能，同时支持工程师自行开发扩展模块，在安全工程师群体广泛使用。

msf在使用上较为简单，msf系列文章内容侧重msf自定义模块的开发，边写边学习，请老师傅多多指点。

一、Metasploit简介

1. Metasploit版本

版本简介适用对象
Metasploit Pro专业版，提供大量功能有web扫描，渗透模块，自动化渗透工具适合专业的高级的大型渗透测试项目专业的安全企业及安全团队
Metasploit Express企业版，包含智能化渗透密码的自动化暴力破解等功能适合中小型企业的安全团队
Meatasploit Community精简版,具备企业版的小部分功能适合小企业和学生
Metasploit FrameworkFramework版，在命令行下运行版本，所有任务都在命令行下完成适合开发人员和安全研究人员

渗透测试工程师和安全研究人员使用最广泛的是Metasploit Framework，它适合自行扩展框架和开发渗透测试模块，如漏洞利用脚本，攻击载荷等。

2.  MetaSploit Framework 用户接口介绍

  • 图形用户界面(GUI)：图形化模式下，使用鼠标点击即可完成任务，图形界面提供了友好的操作模式和简单便捷的漏洞管理模式，如典型的Armitage就是一个充满黑客风的GUI。

  • 控制台界面(console)：提供了统一的工作方式管理Metasploit的所有功能，也是最流行的方式和最稳定的控制方法之一。

  • 命令行界面：是功能最全的界面支持对所有渗透模块的操作，甚至支持与系统shell编程调用。

3. MetaSploit模块

Metasploit框架下包含多种模块，并且支持使用者自行开发模块脚本等，下面介绍几种常用的主要模块。

  • 渗透模块(exploit)：该模块下包含大量的漏洞利用脚本，可针对特定漏洞选择利用脚本，发起对漏洞的利用。

  • 攻击载荷模块(payload)：该模块包含大量获得操作系统访问权限或者系统shell的代码，通常由exploit模块挂载特定的攻击载荷，实现利用漏洞—>获取shell的目的。

  • 编码模块(encoder)：该模块包含大量的编码混淆脚本，通常利用该模块下的特定脚本对payload进行编码，以绕过杀毒软件或防火墙。

  • 辅助模块(auxlary):该模块包含大量扫描探测脚本，通常利用该模块下面的各种脚本进行扫描、探测、识别等。

4. Metasploit基本命令

命令用途示例
use [auxiliary/exploit/payload/encouder]选择使用某一具体模块msf>use exploit/unix/ftp/ftpd_backdoor
show [auxiliary/exploits/payloads/encouders/options]列出特定类别有哪些具体模块，或者显示具体模块的设置信息msf>show exploits
msf> show options
set [options/payload]给某模块的参数赋值set LPORT 3306
setg [options/payload]给全局参数赋值setg RHOST 192.168.1.2

二、Metasploit结构分析

      在上文我们介绍到msf有很多功能模块，如exploit、encoder、payload、auxilary，这些模块下有大量脚本，并且msf支持自行开发这些模块下的脚本或加载其他自定义模块使用。接下来我们就用上面介绍的Ruby基础知识常识自己开发一个metasploit模块。

  • 框架结构

    在开发自定义模块之前，我们先简单了解msf框架结构和msf组成部分。metasploit框架结构如下图所示：

    该框架可以大概区分为4个组成部分，分别是基础库文件、功能程序及交互接口、模块及扩展脚本、插件及外部安全工具。通过下面的表格简要介绍各部分组成和功能

    组成部分组成部分作用说明组成部分简介
    基础库文件基础库文件是msf核心组成部分，它负责支持、调度、解释各类功能。有Ruby扩展(Rex)、MSF核心、MSF基础3部分。Ruby扩展：处理所有核心功能，如网络套接字，网络连接，格式化，模块解释等。
    MSF核心：框架自身程序代码、负责模块管理、插件管理、会话管理、事件调度、数据存储等msf框架的核心功能。
    MSF基础：为模块和插件提供编程接口，负责配置功能、日志功能等。
    模块及扩展脚本msf模块及扩展脚本是完成实际业务功能的主要代码，按照业务功能进行了多个分类，是实际渗透测试中使用的各功能的具体实现。实现扫描、漏洞利用、编码、攻击载荷生产等各类业务。
    功能程序及交互接口该组成部分主要分为两类，一类是与msf框架进行交互的用户接口如msfconsole、msfgui、msfapi等；一类是通过系统命令行单独调用msf某项功能的程序，如使用msfvenom生成木马，或使用msfencode进行编码等。为用户提供全部业务功能或部分业务功能的访问接口。
    插件和外部工具外部插件和工具主要提供与外部工具的调用功能，如调用nmap工具进行扫描或直接使用nmap工具扫描报告，或调用nessus扫描工具等支持msf调用其他工具的功能。
