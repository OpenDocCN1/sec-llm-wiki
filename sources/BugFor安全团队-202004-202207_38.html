‍前言


由于手动挡的缘故，这个文件监控看起来就low了很多，我的技术也暴露了。制作这个手动挡的原因，一、技术太菜；二、作为伸手党过来人，打比赛前找的很多文件监控脚本都用不了，主要是文件的权限问题。改脚本的话我还没学习过那些模块，所以就先写了个”二手奥拓”用用。


正文

先来一手py：
import hashlibimport os, sysdef md5log(file,log):  m = hashlib.md5()  try:    f = open(file,'rb')    for line in f:      m.update(line)      f.close    #print(file+": "+m.hexdigest())    w = open(log,'a+')    w.write(file+": "+m.hexdigest()+"n")    w.close
  except PermissionError:#权限不够的文件，一般你没有别人也没有。    w = open(log,'a+')    w.write(file+": Errorn")    w.close
def listls(folder,logname):  ls = os.listdir(folder)  for path in ls:    list = os.path.join(folder, path)    if os.path.isdir(list):      listls(list,logname)    else:      md5log(list,logname)
if __name__ == "__main__":  try:    listls(sys.argv[1],sys.argv[2])  except IndexError:    print("Input Index: python3 md5log.py folder logname")

代码很简单，就2个简单的函数，md5log将文件的MD5计算出来然后写入指定log文件，listls就是遍历目录然后再调用md5log。
用法：python3 “xxx.py”  “xx目录” “logname


增添删改，都对md5有影响，再结合linux的diff命令，就能直观明了看到是哪个文件发生了变化，具体改动还需审计
