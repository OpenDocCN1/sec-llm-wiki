baby_Magic.php的页面中有Baby和 love两个参数，先 include 了 file 所指向的文件，再经过一系列的检测之后 反序列化 payload。

然后 Gay.php有两个类 Mygirl 和 Gayme。对于 Mygirl 类，它的魔术方法 __Weakup 会清空其自身的成员变量，将其都置为 null。而其析构函数则会调用自身成员变量 mygirl 的Flagcome()方法。而 Gayme 类就有这个 Flagcome() 方法了，其中会this->gayyou 和 this->gayme做比较，本身不相等并且MD5编码后相等就去读文件。看起来我们可以用这里来读 flag.php 文件了。

第三个参数goodfriend赋值给gayyou之后需要满足的条件：

1) $this->gayyou!=$this->gayme

2) md5($this->gayme) == md5($this->gayyou

这里要用到php-MD5()函数漏洞：PHP在处理哈希字符串时，它把每一个以“0E”开头的哈希值都解释为0，所以如果两个不同的密码经过哈希以后，其哈希值都是以“0E”开头的，那么PHP将会认为他们相同，都是0。
