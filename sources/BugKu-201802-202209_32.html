Notepad++是在Windows环境之下的一个免费的代码编辑器，其方便轻巧的特性吸引了许多粉丝。

昨日 Notepad++官网发布了一篇文章，作者公开发表反华言论。（下图被微信和谐了看不到了）


作者Don Ho（侯今吾）是中国台湾人，经常发表一些反华言论


在这里呼吁大家卸载Notepad++（下个版本加个后门也不一定呢？），其实还有很多好用的编辑器这里推荐一下。


01
Sublime Text

Sublime Text 是一款用于代码、标记和散文的精致文本编辑器。Sublime Text在Windows和macOS下都非常好用小编一直在用。

官网：http://www.sublimetext.cn/


02
Atom

Atom 是 Github 专门为程序员推出的一个跨平台文本编辑器。具有简洁和直观的图形用户界面，并有很多有趣的特点：支持CSS，HTML，JavaScript等网页编程语言。它支持宏，自动完成分屏功能，集成了文件管理器。

官网：https://atom.io/


03
editplus

EditPlus是用于Windows的文本编辑器，具有内置的FTP，FTPS和sftp功能。尽管它可以很好地替代记事本，但它还为网页作者和程序员提供了许多强大的功能。（和notepad++有点相似）

官网：https://www.editplus.com/


04
EverEdit

EverEdit，国产的文本编辑器身躯小巧，性能卓越，自定义功能完善，丰富的主题和脚本，完美的编码、大字符集字符显示。

官网：http://cn.everedit.net/


以上几个编辑器都和Notepad++类似比较轻便，大家可以了解下。
