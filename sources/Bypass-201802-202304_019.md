Actuator是Spring Boot提供的应用系统监控的开源框架。在攻防场景里经常会遇到Actuator配置不当的情况，攻击者可以直接下载heapdump堆转储文件，然后通过一些工具来分析heapdump文件，从而可进一步获取敏感信息。

* * *

**01、jvisualvm分析**

jvisualvm是jdk自带可视化java监控工具，在cmd命令行直接输入jvisualvm就可以运行这款工具。

（1）通过jvisualvm加载heapdump文件

![](../Images/61e92b7b21d23ed0c28846d0eb40574b.png)

（2）切换到OQL控制台标签，Springboot heapdump端点存在版本差异，构建OQL语句进行关键字查询，从而获取明文密码。

```


*   
*   

```
Spring boot 1.x版本：select s.value.toString() from java.util.Hashtable$Entry s where /password/.test(s.key.toString())Spring boot 2.x版本：select s.value.toString() from java.util.LinkedHashMap$Entry s where /password/.test(s.key.toString())
```

![](../Images/82c05161272af5ea1cc39a8820071eb1.png)
```

**02、jhat命令分析**

jhat 是jdk自带的用于分析JVM heapdump文件的工具。

（1）使用jhat命令分析heapdump文件，启动一个端口为7000的http服务。备注：jhat 后面可配置jvm参数，避免heapdump文件占用过大内存。

![](../Images/f02a016450204cd5d778723ba712ef61.png)

（2）访问http服务，搜索关键字进入依次查看对象，获取到redis数据对象。

![](../Images/9b621181cdd057e38d2c8c0b705c29f7.png)

（3）点击password，从而获取到redis对象的明文密码。

![](../Images/c70dd6eae84684fc23406cfbe5109263.png)
