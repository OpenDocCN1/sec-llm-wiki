**场景3：Linux服务器批量执行命令**

在Linux自动化运维里，有很多类似的工具，可以实现批量命令执行，如Ansible、SaltStack、Fabric、Puppet、Chef等。

这里介绍两种简单的方式，通过编写shell/python脚本快速实现批量命令执行。

#!/bin/bashcat iplist|while read line #iplist文件中存放了IP地址和密码，每行格式为“IP地址 密码”do    a=($line)                        /usr/bin/expect <<EOF           spawn ssh root@${a[0]}         expect {    "*yes/no" { send "yes\r"; exp_continue}    "*password:" { send "${a[1]}\r" }     }    expect "#"    send "whoami\r"    send "ip add\r"                    send "exit\r"               expect eof    EOFdone
