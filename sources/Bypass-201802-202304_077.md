**3、SUDO提权**

普通用户在使用sudo执行命令的过程中，会以root方式执行命令。在很多场景里，管理员为了运维管理方便，sudoer配置文件错误导致提权。

（1）设置sudo免密码

```


*   
*   

```
$vi /etc/sudoers在最后一行添加：bypass ALL=(ALL:ALL) NOPASSWD:ALL
```


```

**4、计划任务**

（1）查看计划任务，找到有修改权限的计划任务脚本。

```

```

（1）查看NFS服务器上的共享目录
