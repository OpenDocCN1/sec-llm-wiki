**在学习域渗透技巧的时候，首先你需要搭建一个域环境，用来做一些域渗透的攻击模拟测试。**很早之前就答应小密圈的朋友把域环境分享出来，这事我也一直记着，只是测试环境里面有很多个人测试数据和工具，比较乱，不太敢直接打包放出来，于是，我就拖延到了现在。

这事答应挺久的了，本来打算弄个复杂点的环境，想想估计下载的人也不多，就不花时间去折腾了。我重新搭建了几个单域环境，从Window Server 2003 到 Windows Server 2019 全系列，全部都是纯净而又非常简单的单域环境，可以用来进一步组合和重建复杂的域环境，作为基础镜像，分享出来帮大家节省点时间。

**单域，是最简单的域环境，在实战中，也有着很重要的意义。**我曾遇到过，某家单位把内外网上万台的PC/服务器都在同一个域控下，拿到域控，就已宣布全部沦陷；我也曾遇到过，某家单位存在多个域控，域控之间互不关联，每个域控只管理某些特定网段的服务器。

有段时间一直听到内网渗透等于域渗透的论调，在这里引用朋友陶侃说的一句话：刚学得一手大内网的域渗透技巧，你告诉我，你们没有使用域控？？？对于一些内网服务器资产不是很多的单位，域控更多的只是起到一个域账号统一管理的作用，可以直接通过堡垒机的密码托管/批量改密功能来管理服务器账号。随着技术架构的升级，比如微服务架构、容器自动化部署、云服务等，**有一天，企业使用域控的场景越来越少，到那时真的就是，域渗透，从入门到放弃了。**
