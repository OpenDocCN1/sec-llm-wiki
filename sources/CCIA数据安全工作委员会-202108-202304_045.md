# 专题工作 | 基于数据运营安全的个人信息保护——《个保法》实施“大家谈”

个人信息因其自身携带隐私特性，与我们每个人的生活、工作、社会关系休戚相关，如今个人信息被广泛收集和使用，多环节存在着数据被滥用和泄露等安全风险。随着《个人信息保护法》的颁布实施，个人信息保护合规成为法律强制性要求，若防护不当将影响公众权益、企业利益以及社会秩序，个人信息处理者也将面临最高五千万元或者上一年度营业额百分之五罚款。

> > **个人信息保护的发展与现状**
> > 
> >   
> >   
> >   

在纸质办公时代，个人信息的保护一般通过签署保密协议等承诺方式进行保护，个人信息的保护诉求相对比较弱化。进入互联网、大数据、5G万物互联的时代，一方面，个人信息被急速地收集、汇聚；另一方面，企业为了从个人信息数据中挖掘商业价值，扩大个人信息的使用、共享，个人信息流动频率上升。越来越多的行业、企业、个人意识到个人信息中蕴含的价值，这也引导更多的注意力集中在个人信息的收集上。

与此同时，不法分子从中嗅到了商机，使用各种非法手段窃取个人信息进行倒卖。其中，不乏企业内部人员借助工作便利直接进行信息倒卖博取经济利益，内部威胁在个人信息侵害中占比很大。个人信息保护不当导致个人财产受损乃至造成生命危险，个人信息保护形势极其严峻。

纵观过去几年公开披露的因个人信息遭受侵害而引起的案件，究其原因大概包括以下几点：1）倒卖个人信息的经济利益空间巨大，黑产业链受利益驱使选择铤而走险；2）针对个人信息保护的法律法规不健全，难以从法律层面落实保护措施以及违法后的处罚；3）部分法律法规虽然涉及个人信息保护，但证据收集很难，执行难度很大；4）个人信息保护的安全意识薄弱。

我国立法部门、执法部门以及社会产业等各界持续致力于推动个人信息保护的发展与落实，《个人信息保护法》的出台实施，弥补了过去尚没有一部专门的法律或法规可以为个人信息提供直接法律保护的空白。与此同时，为了有效落实法律要求，针对金融、电信、互联网等各行业自身行业特征，国家及行业相关部门制定了相应的个人信息保护指南，如《金融数据安全数据安全分级指南》，《个人金融信息保护技术规范》，《电信和互联网用户个人信息保护规定》等。

根据《个人信息保护法》的定义，个人信息是以电子或者其他方式记录的与已识别或者可识别的自然人有关的各种信息，不包括匿名化处理后的信息。个人信息维度多样，法律对其的保护要求涵盖到所有数据处理环节，包括个人信息的收集、存储、使用、加工、传输、提供、公开、删除等。

> > **个人信息保护面临的时代需求与挑战**
> > 
> >   
> >   
> >   

个人信息的数据规模持续快速增长，这些数据蕴含着巨大的价值，而数据价值要释放出来，就需要打破个人信息的孤岛式数据服务提供方式，加速开放和共享，这就必须首先解决个人信息的安全问题。

长期以来，保护个人信息保护的主要手段以网络安全边界防护和数据库安全为主，以防火墙、IDS/IPS为代表的传统安全策略主要用于抵御外部攻击，带有一定的数据安全检测和管控的能力，但并不关注内部数据流动的过程，也就缺乏对应的响应机制。数据库加密、脱敏、运维、审计等手段主要着重解决结构化数据的安全问题，面对非结构化数据及其流动过程难以进行有效保护。

新一代的技术如DLP位于终端或网络出口，重在对外发的个人信息进行安全监控或保护，但缺乏保障个人信息在内部不同终端间，不同服务器、业务系统之间的流动安全；UEBA能够发现并保护内部数据异常使用和安全威胁，但对数据从生产到运维，从前端到后端的整个生命周期中的流动安全缺乏保障。

可以看到，现有手段在面对新时代个人信息保护方面存在明显短板。数据作为信息的表现形式和载体，在针对个人信息的一系列处理活动中，同一数据将会表现为多种格式和形态，如文本、表格、图片、音频等；同时，数据的存储和使用位置也会随之变动，流转扩散到不同的数据库、终端设备、系统接口、供应链等等环节中。**正是数据运营过程中数据位置和形态的多样性特征，驱使对个人信息的保护必须要覆盖数据的全生命周期。所谓的“全生命周期”并不止于笼统的数据“由生到死”的全过程，还需要精确到单个数据在其整个生命周期内的流动，无论其跨域流转或改变形态，都需要具备一致性的跟踪与防护。**

> > **基于数据运营安全的个人信息保护**
> > 
> >   
> >   
> >   

针对眼下个人信息保护的新形势，需要建立聚焦于数据本体、贯穿于数据全生命周期的安全新方案。**数据运营安全通过在数据运营中内嵌数据安全属性，对敏感数据的扩散及滥用风险进行快速响应，将数据安全防护策略传递至参与数据运营的所有人员，且不影响据业务流程的正常运行。**在数据流动、数据处理等数据运营过程中动态实时、全流程、细粒度地保护个人信息，才是个人信息保护的重点。

实现数据运营安全，需要建立诊疗一体的数据安全平台。首先，创建个人信息资产的全景视图，对各种类型、各种来源的个人信息进行深度识别，从个人信息本体特征、行业特性、合规性等角度，结合机器学习等技术对个人信息进行梳理，包括用户的姓名、电话、身份证等基础属性，以及与业务紧密关联的个人信息，比如在电信运营中的通话数据、位置数据等，金融行业中的账户信息、财产信息、借贷信息等。个人信息以结构化、半结构化、非结构化等多形态方式，或在数据库中存储，或转为办公文档方式流转，或在内部业务流转过程中进一步进行格式转换、数据的解析等等，需要通过跟踪打标的方式全程记录，以此完整掌握所有的个人信息资产情况。

紧接着，追溯个人信息在组织中的流动使用情况。主要包括三个层次：一是基于业务的广泛的流动，部分个人信息集中式在特定业务系统中处理分析，也有另一部分会随着不同部门、不同业务需求在网络中向不同的系统流动。通过对广域分布的个人信息流动进行追溯管理，感知个人信息的风险态势。二是生命周期数据链的个人信息流动，个人信息流动从产生、收集、存储、使用、共享到销毁，在数据链的每个节点上，抓取个人信息的轨迹，以数据与业务的运营周期为牵引，追溯个人信息，保护全数据链的流动安全。三是新技术下个人信息多流转路径追溯，为了挖掘数据价值，企业在进一步寻求打破内部业务壁垒的方式，同时随着大数据时代、5G时代的数据开放共享，网络环境趋于开放，数据流也愈来愈多，企业需要追溯各流转路径，突破传统的数据边界，保障数据的可控性。对个人信息的数据流转路径的追溯管理主要是建立个人信息与主体的映射关系，其在流动中的原文流转、变形流转的血缘关系，以及版本、状态、位置以及轨迹形成的个人信息数据流全生命周期的流动画像。

下一步，基于数据使用风险的自适应防护。分布于各业务、各域的个人信息，以及在数据运营过程中流动的个人信息，如果保护力度不当，会造成新的难题。比如，保护力度弱，达不到安全要求，则个人信息安全无法保障。保护力度过强，可能影响业务的持续性，导致本来正常流转的业务被中断。由此，通过数据运营全周期的特征追踪与数据分析，对个人信息进行数据分布采集、流动追溯，感知个人信息的风险态势，基于机器学习，对各类事件和风险进行分析和分诊，结合用户使用场景、安全基线以及风险活动，从响应时间到响应力度，形成适合数据运营业务安全的按需保护响应机制。

《个人信息保护法》实施以来，全面提升了企业和公众对于个人信息保护的重视，也有力促进着满足合规以及真正提升个人信息安全的创新技术的发展和运用。未来的个人信息保护，需要注重公共利益与个人信息保护的平衡，个人隐私的让渡应当基于保障社会公共利益的必要，在合理的限度内限制个人权利的行使，但不意味着个人信息可以被无限度无规则地使用。即使是基于社会公共利益的需要，个人信息的公开也必须在必要合理范围内，如果超出必要边界，随意泄露个人信息，甚至是恶意传播，给信息主体造成损害或其他不利后果，信息控制者和传播者也应当承担相应的法律责任。进一步讲，筑牢个人信息保护的安全边界，除了企业保护责任的建立和落实，还离不开监管要求与用户意识等层面的共同推进。监管机构应加大监管和处罚力度，并为用户提供便利的维权渠道；用户则应提升自身个人信息保护意识，提升数字素养。
