实时情报

ShenYu（原名 Soul）是一款高性能，响应式的网关，同时也是应用于所有微服务场景的，可扩展、高性能、响应式的 API 网关解决方案，提供了诸如限流、熔断、转发 、重写、重定向、和路由监控等插件。

ShenYu网关认证有两种方式，用户名密码及jwt认证。在jwt生成过程中只使用了用户名而没有使用密码，那么就可以在获得了用户名的前提下获得jwt，实现登录。

漏洞的成因是因为jwt加密密钥泄露导致的，ShenYu网关采用了HS256加密方式，是一种对称加密的方式。其jwt的生成方式只使用了用户名与key，如果知道管理员的用户名为admin，则可以生成管理员的jwt，使用该jwt访问ShenYu则可绕过权限认证。

漏洞复现

1.Apache ShenYu网关的登录界面如下，默认账户密码为admin/123456；

2.对/dashboardUser进行抓包，使用生成的admin的jwt带入head中，发送数据包;

3.使用admin的jwt认证成功之后，返回的数据包中会包含管理员的账号和口令。

4.使用得到的用户名及密码，成功登入系统。
