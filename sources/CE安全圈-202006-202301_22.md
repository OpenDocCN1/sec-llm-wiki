**实时情报**

GitLab 是基于网络的Git 仓库管理工具，具有 issue 跟踪功能。它是使用 Git 作为代码管理工具，并在此基础上搭建起来的 web 服务。GitLab 可以运行在几乎所有计算机平台上，由于其跨平台和安全性被广泛使用，成为最流行的仓库管理系统项目之一。

该漏洞是由于 GitLab 没有正确的处理传入的图像文件，攻击者可通过构造一张恶意的图片文件并上传到gitlab，从而导致远程命令执行，可导致代码被攻击者拖库，造成敏感性信息泄露。目前，这个漏洞细节、POC均已在互联网上公开，建议尽快自查修复。

**漏洞复现**  

1.可通过网上公开的脚本对GitLab 是否存在漏洞进行扫描检测。

![](../Images/1672354d1898e95c537983d76f29c2b9.png)

2.当检测到存在漏洞后，攻击者可通过工具对漏洞发起命令执行，例如whoami。

![](../Images/3205dcfe09444b5aa13014a178ced319.png)

3.成功的在目标机子上返回whoami 信息。

![](../Images/64cca7ba258e1f56541d6f68682faf5a.png)
