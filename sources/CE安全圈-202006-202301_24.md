**实时情报**

Apache HTTP Server 存在目录遍历漏洞，攻击者可利用此漏洞将 URL 映射到由 Alias-like 指令配置的目录之外的文件。同时若Apache HTTPd开启了cgi支持，攻击者可构造恶意请求执行命令，控制服务器。此漏洞由Apache HTTP Server 2.4.49引入，但由于 2.4.50 版本中对 CVE-2021-41773 的修复不够充分，因而此漏洞影响 2.4.49 和 2.4.50 版本。使用默认配置“require all denied”可保护这些目录之外的文件，不受此漏洞影响。目前，这两个漏洞细节、POC及EXP均已在互联网上公开。鉴于此漏洞影响较大，建议尽快自查修复。
