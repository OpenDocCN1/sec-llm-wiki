# 网安中心开展《生命重于泰山》安全专题学习

生命

**重于泰山**

  

  

  

  

8月4日，网络与信息安全中心组织项目组全体成员进行《生命重于泰山》安全专题片学习。

  

  

![](../Images/29364b97cb33464bce6f42230b5a105e.png)

  

专题片中，习近平总书记关于安全生产的重要论述思想深邃、内涵丰富，系统阐述了如何认识安全生产、如何做好安全生产工作等重要理论和现实问题。习近平总书记的论述，是安全生产经验教训的科学总结，是我们开展安全生产工作的根本依据和行动指南。

安全生产是企业永恒主题，“安全为了生产，生产必须安全”，安全生产事关企业的稳定和职工的生命安全。结合国家能源集团产业结构实际情况，对于高风险的传统行业来说，其意义更加重要，工作任重而道远，各项安全工作常抓不懈、消除隐患为主才能保持安全生产良好局面长期稳定。

通过本次学习，网络与信息安全中心项目组将进一步强化项目安全生产管理工作。

一是要牢固树立“安全第一、预防为主、综合治理”方针，坚持奉行“管行业必须管安全、管生产必须管安全、管业务必须管安全”理念。

二是在项目实施中安全生产预防一定要常态化，要坚持预防为主的工作方针，做好安全隐患排查工作，积极有效的消除生产现场存在的各类隐患，把事故消灭在萌芽状态。

三是要加强安全培训，在项目实施中从安全生产方针、安全法律法规、安全管理制度、安全操作规程、安全规范技能和意识等方面入手开展形式多样的宣传教育工作，保证项目相关人员具备必要的安全生产知识，熟悉有关安全生产规章制度和安全操作规程，掌握本岗位的安全操作技能。

通过本次学习，项目组全体成员将坚持落实安全生产主体责任，确保安全生产贯彻到每个项目、每个层面、每个岗位、每个环节。
