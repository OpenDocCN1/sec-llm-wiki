# 王虹桥到国家能源集团调研网络安全工作

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5ODA0NDUxNA==&mid=2247485197&idx=1&sn=404efee95ad0d72d43d8022875290ffe&chksm=ecaa9a00dbdd13163357e524b613ad013da0c72e2be8932a168aff765a58fd50c9a2986cc4f3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI5ODA0NDUxNA==&mid=2247485197&idx=1&sn=404efee95ad0d72d43d8022875290ffe&chksm=ecaa9a00dbdd13163357e524b613ad013da0c72e2be8932a168aff765a58fd50c9a2986cc4f3&scene=27#wechat_redirect)

4月20日，中国煤炭工业协会副会长王虹桥一行3人到国家能源集团，就煤炭行业网络安全及实网攻防演练工作开展情况进行调研，人事培训部副主任胡连辉和统计信息部主任科员王荣博参与调研。国家能源集团煤炭与运输产业部副主任尤文顺、国能信息公司总经理徐会军、副总经理郑磊陪同调研。

王虹桥一行首先参观了国家能源集团总部2021网络安全实战攻防演练现场，对集团网络安全纵深防御体系、态势感知、溯源反制等工作进行了调研，并对140余名现场防守人员进行了亲切慰问。国能信息技术有限公司详细汇报了国家能源集团网络安全总体情况、煤炭业务板块网络及工控安全建设、智能矿山工控安全建设团体标准编制进展情况。  

王虹桥副会长对国家能源集团网络安全工作取得的成绩和效果给予了高度评价，他指出，网络安全直接威胁生产安全，包括生产过程安全，很多煤炭企业都曾经遭受过多次网络攻击，导致一些系统瘫痪，直接影响了生产调度指挥和生产运营，大部分煤炭企业都没有自己的网络安全队伍，出了问题短时间内根本无法恢复系统正常运行。国家能源集团拥有一支政治可靠、技术过硬网络安全专业队伍，网络安全工作确实走在了全国煤炭行业的前列。但随着物联网、5G、人工智能等新技术大规模应用，智能矿山的大规模建设，数据高度关联和集中，网络安全问题会越来越突出，还需要进一步加强防御。要对网络安全新课题加大攻关力度，把这些好的做法和技术手段在全煤炭行业内分享。
