# 关于VMware存在高危漏洞的预警通知

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5ODA0NDUxNA==&mid=2247485014&idx=1&sn=591d059ab942bbb0f0f01d37a985c1c5&chksm=ecaa9b5bdbdd124df4a75eaea0437dabe151c7439bea1a7169b8c9b93d760a648e0e5f8ea406&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI5ODA0NDUxNA==&mid=2247485014&idx=1&sn=591d059ab942bbb0f0f01d37a985c1c5&chksm=ecaa9b5bdbdd124df4a75eaea0437dabe151c7439bea1a7169b8c9b93d760a648e0e5f8ea406&scene=27#wechat_redirect)

近日，国能信息公司网安中心监测发现：VMware 官方修复了多个高危漏洞（CVE-2021-21972、CVE-2021-21973、CVE-2021-21974）。具体情况如下：  

**一、漏洞基本情况**

1、CVE-2021-21972 VMware vCenter Server 远程代码执行漏洞。

2、vSphere Client（HTML5）在 vCenter Server 插件中存在一个远程执行代码漏洞。远程且未经过授权的攻击者通过向 443 端口发送恶意请求，即可在服务端执行恶意代码，获取 vCenter Server 系统权限。

3、CVE-2021-21974 ESXi OpenSLP 堆溢出漏洞。

4、与 ESXi 处于同一网段中且可以访问 427 端口的攻击者可触发 OpenSLP 服务中的堆溢出漏洞，并可能导致远程代码执行。

5、CVE-2021-21973 VMware vCenter Server SSRF 漏洞。

6、由于 vCenter Server 插件对 URL 校验不足，导致 vSphere Client（HTML5）存在 SSRF（服务器端请求伪造）漏洞。远程且未经过授权的攻击者可通过 443 端口来进行 SSRF 漏洞的利用。

**二、漏洞影响范围**

1、VMware ESXi 6.5 系列 < ESXi650-202102101-SG

2、VMware vCenter Server 7.0 系列 < 7.0.U1c

3、VMware vCenter Server 6.7 系列 < 6.7.U3l

4、VMware vCenter Server 6.5 系列 < 6.5 U3n

5、VMware ESXi 7.0 系列 < ESXi70U1c-17325551

6、VMware ESXi 6.7 系列 < ESXi670-202102401-SG

**三、整改建议**

尽快开展漏洞排查，如存在相关情况，系统责任人需尽快制定整改方案，在确保数据安全的情况下，及时升级VMware版本至以下安全版本：

1、VMware vCenter Server 7.0.U1c

2、VMware vCenter Server 6.7.U3l

3、VMware vCenter Server 6.5 U3n

4、VMware ESXi ESXi70U1c-17325551

5、VMware ESXi ESXi670-202102401-SG

6、VMware ESXi ESXi650-202102101-SG

  

如若无法进行安全更新，则可参考官方给出的缓解方案采取相应的防御措施：

1、VMware vCenter Server CVE-2021-21972、CVE-2021-21973 漏洞的缓解方案：https://kb.vmware.com/s/article/82374

2、VMware ESXi CVE-2021-21974 漏洞的缓解方案：https://kb.vmware.com/s/article/76372
