关于 Oracle WebLogic Server未授权远程代码执行漏洞的预警通报

2020年10月29日，网络与信息安全中心监测到Oracle WebLogic Server 远程代码执行漏洞（CVE-2020-14882）POC被公开。通过上述漏洞，远程攻击者可以在未经身份验证的情况下接管 WebLogic Server Console 并执行任意代码。

请各单位立即排查并采取漏洞修复措施，警惕上述漏洞被恶意攻击者利用。

一、漏洞情况分析

在Oracle官方发布的2020年10月关键补丁更新公告CPU（Critical Patch Update）中，包含一个存在于Weblogic Console中的高危远程代码执行漏洞CVE-2020-14882。该漏洞能够在无需身份验证的情况下被触发，影响面较大。

未经身份验证的远程攻击者可能通过构造特殊的 HTTPGET请求，利用该漏洞在受影响的 WebLogic Server 上执行任意代码。

二、漏洞影响范围

Oracle Weblogic Server 10.3.6.0.0

Oracle Weblogic Server 12.1.3.0.0

Oracle Weblogic Server 12.2.1.3.0

Oracle Weblogic Server 12.2.1.4.0

Oracle Weblogic Server 14.1.1.0.0

三、安全建议

Oracle官方已发布针对该漏洞的补丁：

Oracle Critical Patch Update Advisory - October2020

https://www.oracle.com/security-alerts/cpuoct2020traditional.html 

Oracle 官方补丁需要用户持有许可账号登陆 https://support.oracle.com 后，下载最新补丁并及时更新。
