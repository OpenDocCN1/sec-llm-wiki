基于macOS m1 pro Ventura 13.1

系统设置

开启任何来源

作为一名网络安全从业者，肯定是要安装一些非官方软件的

这个时候就需要去「安全与隐私」-「通用」里面来勾选开启任何来源，但是默认是没有这个选项的

需要下面命令来手动开启

sudo spctl --master-disable

然后就出现啦

清除用户账户的密码策略

在安一些破解软件时经常提示我们要输入密码 很是麻烦，这里需要弱口令一下啦

mac怎样开启弱口令呢 输入下面这行命令后再设置密码就可以了

pwpolicy -clearaccountpolicies

触控优化

触控板默认是用力点按 需要按下去才行 这样手会非常容易酸痛

可以在 系统设置-触控板 勾选单指轻点

鼠标的滚轮默认也是反向的 勾选滚动方向 自然即可

输入法

mac的默认输入法 键盘简直反人类 当然习惯了也还好，不过我还是建议使用搜狗输入法，键盘就不会那么反人类了哈哈

可从官网下载

https://shurufa.sogou.com

sip

sip(系统安全性保护)，有些破解软件需要关闭才能安装运行，但是大部分还是不需要关就可以正常破解的，关闭后可能会导致无法运行一些ios软件

对于这个问题有的师傅说要关有的说不能关 当然笔者这里一直是开启的 看自己选择 这里只是提供下教程

Oh My Zsh

mac自带的终端有点小丑

mac是自带zsh 当然你也可以去确认一下

#查看当前使用的终端
cat /etc/shells

把默认的终端 切换至 zsh

#切换终端为zsh
chsh -s /bin/zsh

安装Oh My Zsh

sh -c "$(curl -fsSL https://raw.githubusercontent.com/robbyrussell/oh-my-zsh/master/tools/install.sh)"

安装高亮插件以及代码提示插件

git clone git://github.com/zsh-users/zsh-syntax-highlighting $ZSH_CUSTOM/plugins/zsh-syntax-highlighting

git clone git://github.com/zsh-users/zsh-autosuggestions $ZSH_CUSTOM/plugins/zsh-autosuggestions

Oh My Zsh 支持各种主题 可以随心切换 项目地址：

https://github.com/ohmyzsh/ohmyzsh/wiki/External-themes
