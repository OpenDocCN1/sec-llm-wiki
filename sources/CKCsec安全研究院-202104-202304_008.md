## 系统设置

### 开启任何来源

作为一名网络安全从业者，肯定是要安装一些非官方软件的

这个时候就需要去「安全与隐私」-「通用」里面来勾选开启任何来源，但是默认是没有这个选项的

![](../Images/00825dc2a6d9e99a3e996ed8d26af408.png)

需要下面命令来手动开启

```

sudo spctl --master-disable
```

然后就出现啦

![](../Images/2ab7d65abef6e3cebf2f5b44d48fc321.png)

### 清除用户账户的密码策略

在安一些破解软件时经常提示我们要输入密码 很是麻烦，这里需要弱口令一下啦

mac怎样开启弱口令呢 输入下面这行命令后再设置密码就可以了

```

pwpolicy -clearaccountpolicies
```

### 触控优化

触控板默认是用力点按 需要按下去才行 这样手会非常容易酸痛

可以在 系统设置-触控板 勾选单指轻点

![](../Images/78a439f543b457ef02df1c6643cbe9dd.png)

鼠标的滚轮默认也是反向的 勾选滚动方向 自然即可

### 输入法

mac的默认输入法 键盘简直反人类 当然习惯了也还好，不过我还是建议使用搜狗输入法，键盘就不会那么反人类了哈哈

可从官网下载

https://shurufa.sogou.com

### sip

sip(系统安全性保护)，有些破解软件需要关闭才能安装运行，但是大部分还是不需要关就可以正常破解的，关闭后可能会导致无法运行一些ios软件

对于这个问题有的师傅说要关有的说不能关 当然笔者这里一直是开启的 看自己选择 这里只是提供下教程

关闭/开启方式

http://mumu.163.com/help/mac/20200928/30132\_907352.html
