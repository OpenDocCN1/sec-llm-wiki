适用场景 ：特殊环境下`ICMP`流量允许出网，穿透防火墙

工具：icmptunnel

**「安装服务端」**

```
git clone
 https://github.com/jamesbarlow/icmptunnel.gitcd

 icmptunnel/#禁用自带的ICMP，两端都要

#挂后台
bg
											#给隧道接口分配一个 IP 地址


```

**「客户端连接」**

```


./icmptunnel <server-IP>bg
											#给隧道接口分配一个 IP 地址
```

## Linux SSH隧道

SSH一般是允许通过防火墙的，而且传输过程是加密的

**「本地转发（正向）」**

在中转VPS上执行以下命令

```


ssh -CfNg -L <VPS监听端口>:<目标内网IP>:<目标端口> <（root@目标外网Web服务器，会要求输入密码）>#VPS上查看8090端口是否已经连接
"8090"

#连接目标内网服务器的远程桌面


```

SSH进程的本地端口映射，将本地端口转发到远端指定机器的指定端口；

在本地监听一个端口，所有访问这个端口的流量都会通过SSH隧道传输到远端的对应端口。

**「远程转发（反向）」**

在`Web服务器`上执行如下命令

```


ssh -CfNg -R <VPS的端口>:<目标内网IP>:<目标端口> <（root@VPS-IP，会要求输入密码）>
```

访问`VPS`的8090端口，即可连接内网数据库服务器的3389

```

VPS-IP:8090
```

所有访问`VPS`的8090端口的流量都会通过SSH隧道传输到数据库服务器的3389端口

## Linux iptables 端口转发

1、编辑配置文件

```

vi /etc/sysctl.conf#开启IP转发

```

2、关闭服务

```

service iptables stop
```

3、配置规则

```
#需要访问的内网地址：10.1.1.11（Windows）
#内网边界web服务器：192.168.100.100（Linux）


```

4、保存并重启服务

```

service iptables save && service iptables start
```

这时访问Web服务器的3389就能登录到内网机器的桌面了。
