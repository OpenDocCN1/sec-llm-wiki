## 前言  

此项目由saucer-man师傅开发 并开源于github 在此表示由衷的钦佩 并分享该项目

项目地址：https://github.com/saucer-man/saucerframe

## 特点

*   List item
*   支持多线程并发/协程
*   指定目标支持多种方式
*   指定单个目标
*   从文本种获取目标
*   某一网段获取目标 e.g. 192.168.1.0/24
*   某一ip段获取目标 192.168.1.0-192.168.2.33
*   支持多种api批量获取目标: Shodan、Zoomeye、Fofa、Censys
*   支持全局代理(socks5|socks4|http)

## 安装方法：

git拉取项目 如果git拉取较慢的 也可直接文末获取

```

git clone https://github.com/saucer-man/saucerframe.git
```

进入项目文件

```

cd saucerframe
```

安装模块

```

pip install -r requirement.txt
```

## 使用方法

```


python3 saucerframe.py -h
```
