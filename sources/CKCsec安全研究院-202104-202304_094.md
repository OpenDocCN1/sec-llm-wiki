# Fiora：漏洞PoC框架的图形版，快捷搜索PoC、一键运行Nuclei

Fiora是LoL中的无双剑姬的名字，她善于发现对手防守弱点，实现精准打击。该项目为PoC框架nuclei提供图形界面，实现快速搜索、一键运行等功能，提升nuclei的使用体验。

## Fiora获取

公众号后台回复**「0105」** 获取

## 安装运行

### 作为burp插件运行

1、公众号后台回复**「0105」**获取下载链接

2、如下方法安装插件

![](../Images/2fcbcdbd296179749b993cfbc1545ab6.png)

如果你想使用最新的功能，可以使用如下方法自行打包。

```
git clone
 https://github.com/bit4woo/knifecd

 knife
```

### 作为独立程序运行

该程序即可作为burp插件运行，也可以作为独立程序运行。命令行下通过java启动程序的命令：

```

java -jar Fiora-202100220-jar-with-dependencies.jar
```

如果你配置好了环境变量也可以直接双击运行

![](../Images/45f867d0ece0e0e5a6190d241c7c59d5.png)

## 注意说明

1、你需要自行安装nuclei到本地环境，并且将命令加入环境变量。安装方法可以参考官方文档。

2、windows用户 可直接下载对于压缩包解压 双击运行exe文件即可自动安装部署

下载链接：https://github.com/projectdiscovery/nuclei/releases

3、nuclei的模板文件存放的默认路径是当前用户路径下，即 YourUserHome/nuclei-templates。

## 使用方法

以grafana的PoC为例。

### 搜索PoC

程序会自动扫描nuclei-templates目录下的所有PoC文件，并加载进程序中，可以通过关键词搜索来找到想要的PoC。

![](../Images/768c470d9af63bcfd4ef10f5e085a4b1.png)

### 生成PoC命令

选中想要的PoC，右键选择“generate Command Of This PoC”即可。命令会写入剪切板，直接粘贴运行即可。优点是可以对命令行进行再次编辑，但是需要自行粘贴后运行。

![](../Images/fb09ea1b56f27096662839656a1a4788.png)

```
#生产的单个PoC 

#生产workflow PoC


```

### 直接执行PoC

和生成PoC命令类似，但是它会直接执行生成的命令，不需要粘贴。优点是更便捷，但是无法编辑命令行。
