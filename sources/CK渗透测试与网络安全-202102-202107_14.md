1、安装gcc编译器

    gcc -v 命令：查看gcc版本

 没有就安装  命令:yum -y install gcc

2、pcre、pcre-devel安装

安装命令：

  

yum install -y pcre pcre-devel

yum install -y zlib zlib-devel

yum install -y openssl openssl-devel

  

下载nginx源码安装包并解压

wget http://nginx.org/download/nginx-1.9.9.tar.gz

  

tar -zxvf nginx-1.9.9.tar.gz

  

进入解压目录中执行编译安装

cd nginx-1.9.9

./configure

make

make install

安装成功后，找到Nginx安装目录，执行sbin目录下的nginx文件启动nginx

/usr/local/nginx/sbin/nginx

Nginx启动成功后，默认端口80

![](../Images/ec8ea06b9332a0f4e26f7fe8dc05308a.png)

  

接下来进入Nginx安装目录修改配置文件，代码如下

  

vi /usr/local/nginx/conf/nginx.conf

对nginx.conf文件进行编辑，编辑内容如下

  

server {

listen 80; #配置监听端口号

  

server\_name localhost; #配置访问域名，域名可以有多个，用空格隔开

  

location / {

  

proxy\_pass http://baidu.com;

proxy\_redirect default;

  

#root html;

#index index.html index.htm;

  

}

根据自己需要配置完成后，重启Nginx，

重启命令如下/usr/local/nginx/sbin/nginx -s reload
