在CentOS 7上安装PHP 7

要安装PHP 7，必须使用以下命令在CentOS 7系统上安装和启用EPEL和Remi存储库。


安装gcc 


#yum -y install gcc gcc-c++


#gcc -v查看信息


安装和启用EPEL和Remi存储库

#yum install https://dl.fedoraproject.org/pub/epel/epel-release-latest-7.noarch.rpm


#yum install http://rpms.remirepo.net/enterprise/remi-release-7.rpm




安装yum-utils，这是一组用于管理yum存储库和包的有用程序

#yum -y install yum-utils



yum-utils提供的程序之一是yum-config-manager，您可以使用它来启用Remi存储库作为安装不同PHP版本的默认存储库

#yum-config-manager --enable remi-php71 [ 安装PHP 7.1 ]


#yum-config-manager --enable remi-php72 [ 安装PHP 7.2 ]


#yum-config-manager --enable remi-php73 [ 安装PHP 7.3 ]


安装模块

#yum -y install php php-mcrypt php-devel php-cli php-gd php-pear php-curl php-fpm php-mysql php-ldap php-zip php-fileinfo



输入php-v查看php版本


PHP 7.1.28 (cli) (built: Apr  2 2019 17:49:56) ( NTS )


Copyright (c) 1997-2018 The PHP Group


Zend Engine v3.1.0, Copyright (c) 1998-2018 Zend Technologies


启动php-fpm


#systemctl start php-fpm



开启启动

#systemctl enable php-fpm.service


pecl安装扩展

# yum -y install php-pear

# pecl

pecl安装redis

# pecl install redis

# echo "extension=redis.so;" >> /etc/php.d/20-redis.ini

报错的话

# pecl install igbinary

# echo "extension=igbinary.so;" >> /etc/php.d/20-redis.ini
