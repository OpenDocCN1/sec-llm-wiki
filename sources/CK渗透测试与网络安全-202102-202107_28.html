先来聊一聊黑客与渗透测试工程师吧

渗透:渗入敌方，透过封锁。
渗透测试工程师:又称白帽子，甲方授权乙方对甲方网络资产进行渗透测试。模拟黑客攻击，检查乙方资产并发现防御薄弱提供解决方案。

白帽子与黑客的区别:
白帽子:取得甲方授权，以检查甲方网络资产发现防御薄弱环节并提供修复。在渗透过程需要保证数据完整性和系统稳定性。
黑客:以达到不可告人的目的，如 挖矿 肉鸡 窃取情报等 
授权书:主要授权以及渗透测试中需要保证对数据和系统的安全与稳定，有的可能会详细到哪些方式不能用(社会工程学 ddos Cc )哪些工具不能用(比如说自动化工具sqlmap 那么需要手工挖掘)。一般拿到webshell是可以横向渗透的。
也许可能有人说既然授权了，模拟就是实战。我们的目的是插入敌方，不破坏数据。在主动信息收集，我们需要与目标进行交互，不要甲方公司运维是吃干饭的，人家也会检查端口 日志 可能搭建了蜜罐，可能你一个扫描器梭过去，人家那边警报。人家直接封你IP，我们应该隐藏身份，等待致命一击。
比如说kali与目标主机建立大量的连接，那么目标主机或者web日志是不是有连接信息，假如有1欠条连接记录，其中某一个IP连接次数最多，我相信运维肯定第一对象肯定是它。那如果使用代理IP混淆一下呢比方说有连接记录1000条，我连接次数是10，运维肯定不会想到连接10次的这个IP是黑客攻击源。我们使用伪造或者说代理混淆了了真是IP地址。

这里说说一下网络加速proxychains4和tor代理实现匿名
 tor可能最早接触的是洋葱路由或者暗网，其实它是一个很好的匿名访问网络的工具。它会每隔多久自动更新IP ，IP都是由志愿者提供的。相信进过暗网的朋友都知道，首先我们通过ssr突破长城防火墙的封锁，然后随机选择三个节点访问目标站点。
假如说我访问茶马古道 我本机 IP192.168.0.123  经过ssr 220.168.8.211  然后通过洋葱中继 随机三次跳转(德国-美国-加拿大)再到茶马古道，实际上出口IP是加拿大的，这样就实现了多层代理了。



kali配置tor网络

1.安装tor                      su do apt-get install tor

 安装 proxychins4  sudo apt-get install          proxychains4

  

2.编辑配置文件             vim / etc/ proxy chains.conf


注释strict_chains 去掉#号，启用dynamic_chains  添加#号，以防止代理服务器停止工作或者遇到重载荷导致的proxychain失效。



3.编辑/etc/proxychains.conf文件中的[ProxyList] 模糊自己的ip



4.启动服务 service tor start

5.检查查是否正常运行 service tor startus

6.测试

proxychains firefox www. ip138.com

如果显示IP非本IP则 代理成功。
