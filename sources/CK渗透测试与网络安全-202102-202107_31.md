# burp suite抓包(2))

这里我用谷歌游览器(游览器设置大同小异，推荐大家使用谷歌，毕竟不管是插件还是翻译都很好用)  
PC端1.打开burp suite

![](../Images/180843d33f43619feb2ec2216733a7b4.png)

拦截默认是打开的，我们先把它关闭  

![](../Images/3471face63f78f1fad79e3a9ca6dba04.png)

然后点击标签 option s设置代理

![](../Images/1e7e9cbbe0b30389697d07840ee659a7.png)

把代理设置成127.0.0.1端口号改为8080(记得把前面的勾选上)

  

![](../Images/1e7e9cbbe0b30389697d07840ee659a7.png)

  

在游览器中输入 http://burp/回车，然后下载证书  
  

![](../Images/3175cf0e68533491422870d0aa5af892.png)

下载证书

  

![](../Images/d4a50270b631b28bd04abb2847f10962.png)

接下来在谷歌游览器中导入证书

  

![](../Images/484b6d1559311c934cb07291f6146b7e.png)

![](../Images/02baf68dafbbf7af52f4a7494565f3a9.png)

![](../Images/0a866517d696639de3c8e62c73f4b52b.png)

![](../Images/ba40fe581258afede33270fdda4c6805.png)

信任证书

  

  

![](../Images/89a0e3ecfbbd99a2c36c2cac58d9ef3c.png)

![](../Images/96b86403ec5c414e275d2b789a392c01.png)

![](../Images/84f9db39540d065ba8be9b0f8ce0c889.png)

然后重启游览器

如果开启了代理，然后数据包是拦截的。如果需要切换代理麻烦，我们可以下载插件switchy 

  

![](../Images/b66144c4c63e92803cbe785908df012a.png)

记住游览器和burp代理必须一致。

  
  

![](../Images/414f523a29223d7c667e01e2e83a21af.png)

![](../Images/6ea8b239b63f90e2c6a1b5494ad5827e.png)

移动端(安卓或者模拟器) 本人不用苹果手机所以使用安卓

首先点击标签 option s设置代理

  

![](../Images/2a23bb7e82e7eb7099fe158339bf91e2.png)

然后打开手机设置 wlan 高级设置—代理设置

(注意:模拟器或者手机必须和burp端在同一网段，不知道的可以用ipconfig或者ifconfig查看IP)

  

![](../Images/40a5d443cd350e247fc1df47298bb669.png)

![](../Images/b2ba4aaa5b6831593850e6685ec9adf5.png)

  

然后在游览器中输入 http://burp/回车，然后下载证书

  

  

![](../Images/3175cf0e68533491422870d0aa5af892.png)

  

保存位置要记得，最好把名字改了，不然等下导入证书是你找不到证书下载到哪里去了

![](../Images/753b5030dc8ed61853e799f9fb7b92e4.png)

安装证书

  

  

  

![](../Images/6547b09d2bf175d2d5bc8e5a4e8294a9.png)

接下来就可以抓包了

把拦截开起来

  

![](../Images/64d18de478b7af0c9cde8e131419bc87.png)

  

![](../Images/180843d33f43619feb2ec2216733a7b4.png)

打开游览器输入127.0.0.1/dvwa-master登录 然后就可以拦截到数据了

![](../Images/d079a62436d07d0b29c06d0082c542ac.png)
