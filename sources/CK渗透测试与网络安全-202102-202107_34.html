什么是系统环境变量：系统环境变量有点类似于全局变量，比如说没有配置环境变量我们只有在程序所在目录打开它，如果配置了环境变量我们可以在运行框直接输入程序名打开它。如果只求方便那么直接设置系统环境变量就行，一劳永逸，也可以选择设置用户变量也是可以的，只不过只能在配置用户下使用。
因为在很多工具java或者Python编写，特别是以后我们用到的一些开源工具(比如扫描器xray我们就需要用到Python环境我们在运行是没有环境会运行不了)
Python下载地址    https://www. Python.org/
jdk 下载地址        https://www.oracle.com/
实验环境是windows7系统
环境安装目录不能有中文
一&Python环境安装
1.下载
2.双击安装(一定要记住安装路径)
3.安装完成，修改环境变量
方法1.右键计算机-属性-高级设置-系统变量-编辑在加上;Python安装路径就可以了


记住路径前需要用分号(；)隔开，不然导致安装失败，或者cmd里很多命令不能用
方法2.命令修改path
win+ r   > cmd >输入以下命令
path=% path%; C:\ Python
记住C:\ Python 是你的安装路径。
测试:
在cmd下输入Python提示命令成功说明OK了

二& jdk安装
1.下载jdk
2.双击安装(一定要记住安装路径)
3.安装完成，修改环境变量
右键计算机-属性-高级设置-系统变量-双击path
1.新建变量JAVA_HOME  变量值(JDK安装的所在位置):
2.path修改-编辑-变量值输入; jdk安装路径
3.新建变量CLASSPATH 变量值填写jdk安装路径
测试：
在cmd下输去java -version能显示java版本信息说明成功了。
