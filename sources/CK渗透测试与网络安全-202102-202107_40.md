## root获取

Kali主要用于安全方面，很多命令需要使用root权限执行，获取root权限益处多多。

1.  启动Kali，在启动页按**E键**。
    
    ![](../Images/4093a8ab0de401ff5709d8426d2c487d.png)
    
2.  进入**Kali GNU GRUB**页面。
    
    ![](../Images/5373032f0ed45a83e56cebed0df688e9.png)
    
3.  修改倒数第三行（**linux**），将**`ro`**改为**`rw`**，在行末插入**`init=/bin/bash`**。
    
    ![](../Images/ed0315777dda739f6c052b976214e89c.png)
    
4.  修改完成后按下**Ctrl+X**，等待进入命令行页面。
    
    ![](../Images/929b23ff0bdd250993a448138b93fe8f.png)
    
5.  输入**`passwd`**回车执行，设置root用户密码。
    
    ![](../Images/26d66054a8593dc370bccace0865231e.png)
    
6.  重启Kali，可使用root用户登录。（后续操作均用root账户）
    
    ![](../Images/0d265331cfbeab7bf1bb2d53bf07118f.png)
    

## 修改更新源

国内使用默认源速度会比较慢，换成其他源更加方便。换源需要用到root权限，否则会提示文件为只读不可修改，没有root权限使用sudo。

1.  执行**`vim /etc/apt/sources.list`**，修改**sources.list**文件。
    
    ![](../Images/24c12c930ec1954cc0efac3a0892dbc9.png)
    
2.  修改为其他源，注释或删除默认源，将国内源粘贴进去，保存。
    
    ```
    
    
    #部分源列表，更多可以自行搜索。//mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib
    //mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib
    
    //mirrors.aliyun.com/kali kali-rolling main non-free contrib
    //mirrors.aliyun.com/kali kali-rolling main non-free contrib
    
    //mirrors.tuna.tsinghua.edu.cn/kali kali-rolling main contrib non-free
    //mirrors.tuna.tsinghua.edu.cn/kali kali-rolling main contrib non-free
    
    //mirrors.zju.edu.cn/kali kali-rolling main contrib non-free
    //mirrors.zju.edu.cn/kali kali-rolling main contrib non-free
    
    //http.kali.org/kali kali-rolling main non-free contrib
    //http.kali.org/kali kali-rolling main non-free contrib
    
    
    
    ```
    
    ![](../Images/64ec9f93c86b1a7a74ddaad56aba9a30.png)
    
3.  执行**`apt-get update`**，更新源。
    
    ![](../Images/35d5979819fd9d7d352420b4be4b9eb8.png)
    
4.  执行**`apt-get upgrade`**，更新软件，需要几分钟时间。
    
    ![](../Images/7657107e765cdde425a6db6d556af0fb.png)
    
5.  执行**`apt-get clean`**，清理安装包。
    

## 汉化

Kali默认英文，对英文不够熟悉，汉化后便于使用。

1.  执行**`dpkg-reconfigure locales`**，配置语言。
    
    ![](../Images/7d99429f36e5329d6d37a686ac4aa6fa.png)
    
2.  选择**zh\_CN.UTF-8**，设为默认语言。
    
    ![](../Images/882664ef63a47ec98d51b367733e248d.png)
    
    ![](../Images/3ba7168178a6717de1ac7c2576bc5211.png)
    
    ![](../Images/8802870b570d9aba325b5716ccaadde9.png)
    
3.  执行**`apt-get install ttf-wqy-microhei ttf-wqy-zenhei xfonts-wqy`**，
    
    ![](../Images/925fd373b075593fd53bc45e49207ae9.png)  
    
4.  安装中文字体。
    

![](../Images/925fd373b075593fd53bc45e49207ae9.png)

重启
