渗透测试:模拟黑客攻击，为企业资产进行安全防御检测。  
渗透测试需要甲方提供渗透测试授权书，以及详细的环境条件(如不能使用社会工程学或某些工具和压力测试等)  
渗透测试大致分为黑盒测试和白盒测试1）黑盒测试:渗透者完全处于对系统一无所知的状态2）白盒测试:可以向甲方获取各种资料，比如说代码审计目标分类1  主机渗透 Windows linux  MacOS 等2 数据库渗透  mssql mysql  oracle 等3应用系统 app 客户端 网站 等4 网络设备 防火墙 路由 入侵系统检测等   
学习框架Windows: dos命令 power shell命令 注册表端口 提权 iis 等  
  
linux:  文件操作 vim编辑器 应用安装更新 IP配置 提权 Apache Nginx 容器等lnmp环境 phpstudy环境 以及安装dvwa靶场编程语言: c++ JavaScript java Python php html CSS等 最少精通一门语言 kali linux:主要学习工具使用 包括扫描 注入 爆破 漏洞利用框架 等web漏洞弱口令 sql注入 文件上传 文件包含 目录遍历 命令执行 反序列化 敏感信息收集 跨站请求 服务端请求 外部注入 跨站脚本攻击  漏洞利用框架 + Google hacking shodan 钟馗之眼
