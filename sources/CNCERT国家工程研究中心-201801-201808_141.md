# 报告 | 智慧城市网络威胁挑战

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247484689&idx=3&sn=8b2f4e5f376d62a4f0156b510cf2454b&chksm=fa90b3d0cde73ac6fd85a73435f2e82739a282d436fd051582bf62970318718309c3ae208fff&scene=126&sessionid=1681365725#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247484689&idx=3&sn=8b2f4e5f376d62a4f0156b510cf2454b&chksm=fa90b3d0cde73ac6fd85a73435f2e82739a282d436fd051582bf62970318718309c3ae208fff&scene=126&sessionid=1681365725#rd)

国际信息系统审计协会（简称 ISACA）调查全球数千个对象后发现，受访者认为关键基础设施系统最易遭受网络攻击的行业为能源、通信、金融服务；恶意/勒索软件和 DoS 是智能基础设施最可能遭受的攻击威胁。

![](../Images/d7d865af88d204f5c859321cff9c2dac.png)

  

### 

**报告主要内容**

这份调查报告显示：

> *   71%的受访者认为能源行业是最易遭受网络攻击的关键基础设施系统，其次是通信行业（70%）和金融服务行业（64%）。
>     
> *   能源、通信和运输行业可能会是智慧城市中获益最大的前三大行业。
>     
> *   67%的受访者认为，国家型黑客最可能对智能基础设施构成威胁，其次是激进黑客（63%）。
>     
> *   受访者担心恶意/勒索软件和 DoS 是智能基础设施最可能遭受的攻击威胁。
>     
> *   15%的受访者认为，城市具备能力应对针对智能基础设施的网络攻击，55%的受访者认为政府机构更适合应对此类威胁。
>     

### **训练专业安全人员很有必要**  

软件交付自动化公司 XebiaLabs 首席产品官罗伯特**·**斯特劳德表示，在确定智慧城市之前，首先必须将智慧的观点转移到采用并管理推出新技术和系统的方式上。

城市中心对恶意攻击者而言是潜在诱人的目标，对于将信息和技术基础设施现代化的城市而言，有必要对训练有素的安全专业人员进行必要的投资，同时将信息和技术基础设施现代化。Clyde Consulting 咨询公司总经理罗伯**·**克莱德对此表示支持，他认为可根据需要与私营部门合作弥补差距，以应对伴随城市化和威胁形势的未来挑战。

大部分受访者认为，实现网络安全人工智能（AI）等新工具和技术至关重要， 但不到一半的受访者认为这些新工具和技术可能会在未来五年内实现。

**智慧城市需要做好“居民沟通”工作**  

报告显示，有必要与发展中智慧城市的居民进行更有效的沟通。四分之三的受访者认为，智慧城市的市政府并没有向居民宣传居住在智慧城市的好处，比如，利用智能技术将停车、身份证系统和其它城市服务现代化可提高效率，减少拥堵。

Clyde Consulting 咨询公司总经理罗伯**·**克莱德表示，对于将信息和技术基础设施现代化的城市而言，有必要对训练有素的技术专业人员进行必要的投资，并根据需要与私营部门合作弥补差距，以应对伴随城市化和威胁形势的未来挑战。
