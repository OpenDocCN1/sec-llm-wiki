# 加拿大核实验室宣布设立国家网络安全创新中心

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247484549&idx=1&sn=e2d794beb8f2389b17da813b037a9081&chksm=fa90b244cde73b5246ebf8262d717de4d12bb553f30d912b9f92f6a4310fa8a0005eb85a2787&scene=126&sessionid=1681365737#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247484549&idx=1&sn=e2d794beb8f2389b17da813b037a9081&chksm=fa90b244cde73b5246ebf8262d717de4d12bb553f30d912b9f92f6a4310fa8a0005eb85a2787&scene=126&sessionid=1681365737#rd)

加拿大核实验室（Canadian Nuclear Laboratories，CNL）2018年5月16日宣布，将在加拿大新不伦瑞克省（New Brunswick）弗雷德里克顿（Fredericton）设立国家网络安全创新中心，并称该中心将显著扩大 CNL 的网络安全研究能力，为加拿大的国家网络安全再添助力。

![](../Images/ebd3bef1c850c1e1e4b64850fb43f03a.png)

### 

**加拿大核实验室CNL**

> *   CNL 核科技公司是核科技研究领域的佼佼者，为多个行业提供独特的科技能力和解决方案。该公司参与行业驱动的研究和开发，涉足核、交通、清洁技术、能源、国防、安全和生命科学领域，提供解决方案，帮助保持以上领域的国际竞争力。
>     
> *   2018年5月7日，CNL 还与中国核工业集团有限公司（CNNC）达成核能科技方面的合作协议，推动更加可持续的低碳经济方面实现切实进展。
>     

**国家网络安全创新中心将引进人才**

CNL 宣布将在未来五年投入300多万美元用于购置新设备，升级基础设施；CNL 还将为该中心增加24名员工，目前正在物色多学科（计算机科学、系统工程和应用物理和数学等）人才。

弗雷德里克顿的地方政府机构 Opportunities NB（ONB） 表示，创造这24个就业岗位预计会在四年内为该省的 GDP 贡献1020万美元（约合人民币6492万元）。

### **研究中心关注关键基础设施中的漏洞**

新的研究中心主要负责开展研发工作，以解决关键基础设施过程控制系统目前及未来面临的挑战。该中心将为 CNL 提供能力全面模拟操作设施，测试整个操作安全系统如何响应大规模网络攻击和简单的软件升级。借助这种能力，CNL 将能帮助其客户在其安全系统出现问题之前发现漏洞，从而避免设施运行中断的情况。

![](../Images/9060e6034e95a743421e506e4cff4a97.png)

**保护工控系统完整性和安全性**

CNL 总裁兼首席执行官马克**·**列辛斯基在新闻发布会上表示，加拿大新不伦瑞克省将逐渐演变成为网络安全研究与创新中心。包括核在内的所有行业已将工业控制系统安全列为重大优先事项，工业控制系统安全市场的全球规模已高达几十亿美元。为了确保工业控制系统的完整性和安全性，组织机构必须借助最先进的设施，在受控的环境中测试这些系统。在世界领先的工业控制系统和安全专家的全力支持下，CNL 开设该中心就是为客户提供这种能力。

同时，ONB 将对 CNL 设立国家网络安全创新中心予以支持并将与其合作。

加拿大新不伦瑞克省省长布莱恩**·**加伦特表示，网络安全被视为多年经济增长计划的重要机会。他认为 CNL 这样的公司之所以选择该地，是与新不伦瑞克省具有世界先进的基础设施、教育设施以及优秀的人才有关。
