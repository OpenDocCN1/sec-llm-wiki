# Abbott心脏植入设备暴隐患！会是下一个“大规模杀伤性武器”？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247484467&idx=1&sn=d8c29f3c8d83351af3cd5f6bdb3d3a89&chksm=fa90b2f2cde73be40a1db3818c915333c4a88a7a0b912ae74b977cf733d5905e1b6ef6cbebad&scene=126&sessionid=1681365737#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247484467&idx=1&sn=d8c29f3c8d83351af3cd5f6bdb3d3a89&chksm=fa90b2f2cde73be40a1db3818c915333c4a88a7a0b912ae74b977cf733d5905e1b6ef6cbebad&scene=126&sessionid=1681365737#rd)

Abbott公司（之前叫St. Jude医疗公司）最近发布了对固定式心脏复律除颤器（ICD）和心脏再同步治疗除颤器（CRT-D）设备上固件的升级，旨在防止除医生以外的任何人更改设备设置。当前，大约有35万除颤器需要安全更新，以修复可能威胁生命的漏洞。在2016年时，研究人员就表明当时St. Jude的心脏植入生态系统充斥着安全漏洞，这些漏洞可能严重影响植入者的生命安全。

  

Abbott发言人说：“食品药品监督管理局（FDA）的建议并非基于新发现的漏洞，而是一些公开的已知漏洞——却仍然出现在新产品上。每当我们对新产品进行更新时，都需要经过开发、测试、验证和安全审查。我们正按部就班的更新这些设备，从2017开始更新起搏器固件，之后将更新除颤器。经过努力，2017年尚未有任何未经授权访问任何患者植入设备的报告”。

  

事实上，这些心脏植入设备安全问题的根源在于一种通用的、硬编码的解锁代码，黑客能够利用该代码后门访问被影响的设备。另外，Merlin @ home发射器被发现容易受到中间人攻击。当两者一起使用时，黑客可以利用Merlin @ home发送器的向被植入设备发送命令，从而操纵被植入设备，并导致心脏问题甚至死亡。该调查结果出自MedSec和Muddy Waters，却招来了医疗供应商对安全研究人员的诽谤诉讼。但FDA以及DHS ICS-CERT随后发布了报告，并明确支持安全研究者所担忧的合理性。St. Jude随后才开始推出更新，并自愿召回受影响设备。FDA的这份报告也指出，至少从2014年起St. Jude就已经意识到了这个问题。

  

事实上，Abbott并不是唯一一家在设计产品时未充分考虑安全因素的厂商。自去年以来，来自4家不同制造商的7种不同起搏器programmers（一种用于编程起搏器的设备）共暴出了8000多个漏洞。White Scope是一家专门研究射频功能的programmers的机构，它把所有这些漏洞都报告给了DHS ICS-CERT。White Scope所检查的所有programmers都使用了具有很多公开漏洞的老旧软件，例如 Windows XP。

  

Cynerio首席执行官Leon Lerman 说:“联网设备已成为医院网络安全链中最薄弱的一环。这些联网设备并没有认真考虑安全性。这些设备常常运行着已经淘汰的操作系统，使用着不安全的通信协议，且传统IT安全解决方案无法有效保护这些设备。医院必须采取措施保护自己的生态系统、保护病人的数据——针对医疗设备的网络攻击真的生死攸关”。

  

虽然Abbott表示目前还没有任何关于病人的设备遭到黑客入侵或未经授权访问的报告，但以往的研究结果已经证明了起搏器被黑客入侵的可能性。2012年，IOActive的物联网研究人员Barnaby Jack展示了如何远程控制起搏器，并通过笔记本电脑控制起搏器发出830伏的电击，这足以杀死一个人。Jack当时就指出，这些漏洞为“大规模谋杀”打开了大门。

  

Lerman说：“随着医院内使用的物联网设备的不断增多和多样化，潜在的网络安全风险很高；MRI机器、胰岛素泵等都可能存在安全漏洞，后者可能导致攻击者施用致命剂量”。

  

Abbott声称“对于Abbott的设备，获得更新需要在医院或者规定场所进行，该过程是非侵入性的。在升级过程中，一根具有写功能的小棒被放置在ICD或CRT-D上，并将信息传输到植入设备中。在升级结束时，要对植入设备上的配置进行验证，以确保更新已成功完成。整个升级过程大约需要三分钟”。Abbott还建议患者与他们的医生讨论，以确定自身的设备是否适合更新。这个建议恰恰被安全研究人员认为是没有考虑到网络安全的象征。

  

Rubicon Labs首席产品官员Rod Schultz说：“很高兴看到医疗设备制造商推出安全更新，但将医生变成精通医疗设备的全能专家乎并不可行。设备安全、固件更新和安全认证绝对不应成为大多数劳累过度的医生的核心能力。随着我们连接越来越多的设备，这个问题只会越来越难以解决，而解决这个问题的云服务则迫切需要”。
