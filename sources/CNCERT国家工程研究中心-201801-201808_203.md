# 北约2018“锁盾”演习关键词：电网、4G网络、无人机、净水厂

4月29日讯 由北约网络合作防御卓越中心（CCDCOE）组织的2018“锁盾”（Locked Shields）演习于2018年4月23日~27日举行，这是全球最大规模的网络防御演习，30个国家1000多名网络专家参与了这场演习，演习涉及约4000个虚拟化系统和超过2500次网络攻击。除了保护基础设施，防御者还必须解决取证、法律和媒体挑战。

![](../Images/277d3e0014545a8c65c3e590d3a736cc.png "北约2018“锁盾”演习模拟关键基础设施攻击 将复杂程度提上新水平-E安全")

### 

**2018“锁盾”演习内容**

在这场演习中，虚构国 Berylia 的一个大型互联网提供商和军事空军基地遭遇了协调性网络攻击，电网、4G公共安全网络、无人机操作和其它关键设施组件遭到严重破坏。

一支“红队”（攻击者）试图黑进22支“蓝队”（由IT专家组成）防御的系统，这些坚守防御的 IT 专家扮演的快速响应小组，协助该虚构国处理大规模网络事件。“蓝队“主要由国家的军事和文职网络安全专家组成。该演习的组织者聚集在爱沙尼亚首都塔林参加演习，而 “蓝队”则可在自己的国家在线参与。

组织这场演习的技术演习项目经理阿勒**·**雷托恩表示，2018“锁盾“演习在复杂程度上达到新的水平。CCDCOE 表示，为了解决北约成员国目前最担心的威胁，这场演习将重点放在保护关键服务和关键基础设施上。各国政府日益担心网络战可能会对关键基础设施造成潜在的损害。考虑到国家在现实世界面临的网络威胁，参与者有机会防御针对以下几方面的大规模攻击：

> *   电网SCADA系统和变电站；
>     
> *   执法机构和应急通信的4G公共安全网络；
>     
> *   PLC 控制的净水厂；
>     
> *   军事监控无人机和控制无人机操作的地面站。  
>     

北约派出的小组在这场演习中夺冠，法国队和捷克队分别摘得亚军和季军。

北约网络合作防御卓越中心的主任默尔·迈格尔表示，“锁盾“演习为参与者提供机会在最复杂、最激烈的环境中练习解决网络事件。以构建网络弹性，抵御针对关键基础设施的网络攻击。
