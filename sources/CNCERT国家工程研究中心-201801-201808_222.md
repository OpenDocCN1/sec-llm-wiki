# 关于Schneider HMI相关软件存在缓冲区溢出漏洞的情况通报

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247484357&idx=1&sn=b6bfa49e9dab8a1656416cf642d3e316&chksm=fa90b504cde73c12cc2ea1a58bb7098220f4bb2c4fc434f6a0e8ebb5ef174216cb328d207738&scene=126&sessionid=1681365749#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247484357&idx=1&sn=b6bfa49e9dab8a1656416cf642d3e316&chksm=fa90b504cde73c12cc2ea1a58bb7098220f4bb2c4fc434f6a0e8ebb5ef174216cb328d207738&scene=126&sessionid=1681365749#rd)

美国当地时间2018年04月17日，ICS-CERT通报了法国施耐德电气（Schneider Electric）公司生产的InduSoft Web Studio中存在缓冲区溢出漏洞的情况。CNCERT下属的工业互联网安全应急响应中心（http://www.ics-cert.org.cn）针对漏洞情况进行了分析，并对国内相关联网资产进行了在线监测，具体情况通报如下：

  

**一、漏洞情况分析**

InduSoft Web Studio和InTouch Machine Edition是法国施耐德电气公司的一个嵌入式HMI软件包，为HMI客户端提供读取，写入标签和监视警报和事件的功能。

安全研究人员发现，在InduSoft Web Studio（<=V8.1）以及InTouch Machine Edition（<=V8.1）中存在可利用的缓冲区溢出漏洞。分析表明，远程恶意实体可能会发送精心设计的数据包，在读取和写入标签、警报或与事件相关的操作期间，利用该漏洞在服务器中执行代码。该代码将在高权限下执行，将导致InduSoft Web Studio和InTouch Machine Edition服务器机器的完全损害。

  

**二、漏洞影响范围**

该漏洞的综合评级为“高危”。

根据生产厂商以及漏洞研究者的测试结果，该漏洞影响的产品：InduSoft Web Studio（<=V8.1）以及InTouch Machine Edition（<=V8.1）

截止当前，我中心通过监测手段发现国内若干暴露在互联网上的相关网络资产，详细信息见附录一。

  

**三、漏洞处置建议**

目前厂商暂未发布软件更新，建议使用此设备的用户随时关注厂商主页或参考网址以获取解决办法。

详情请关注厂商网站的相关信息：http://software.schneider-electric.com/pdf/security-bulletin/lfsec00000125/

此外，建议相关用户应采取的其他安全防护措施如下：

（1）最大限度地减少所有控制系统设备和/或系统的网络暴露，并确保无法从Internet访问。

（2）定位防火墙防护的控制系统网络和远程设备，并将其与业务网络隔离。

（3）当需要远程访问时，请使用安全方法如虚拟专用网络（VPN），要认识到VPN可能存在的漏洞，需将VPN更新到最新版本。
