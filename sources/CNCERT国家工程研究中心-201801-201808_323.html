关于3S-Smart Software Solutions GmbH的CoDeSys软件漏洞的情况通报

原文：http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247483830&idx=1&sn=bc92cd9e0e9858938c78369da7d46ae4&chksm=fa90b777cde73e61790667d8a8683d47227f795f5a36431e72c6b1baa26bcadd03bef35172ee&scene=126&sessionid=1681365769#rd

美国当地时间2018年02月01日， ICS-CERT发布了3S-Smart Software Solutions GmbH公司 CoDeSys软件的一个高危漏洞，声明该软件的 Web 服务存在远程代码执行风险。成功利用该漏洞，攻击者可以使运行有CoDeSys软件的Windows系统缓存区溢出，从而在该系统上任意执行代码，进而影响系统的安全运行。CNCERT下属的工业互联网安全应急保障中心（http://www.ics-cert.org.cn）针对漏洞情况进行了分析，并对国内相关联网资产进行了在线监测，具体情况通报如下：

一、漏洞情况分析

3S-Smart Software Solutions GmbH公司的CoDeSys的（Controlled Development System的缩写）为可编程逻辑控制器PLC（Programmable Logic Controller的缩写）提供完整开发环境。在PLC程序员编程时，CoDeSys为强大的IEC语言提供了一种简单的方法，它的编辑器和调试器的功能建立在高级编程语言的基础上（如Visual C++）。

CoDeSys软件的运行环境为微软Windows操作系统，该软件开放的WEB服务存在漏洞，成功利用此漏洞可能造成安装CoDeSys软件的Windows系统缓冲区溢出，从而允许攻击者在安装有该软件的系统中执行任意代码。

二、漏洞影响范围

该漏洞的综合评级为“高危”。

根据生产厂商以及漏洞研究者的测试结果，该漏洞影响的产品是CoDeSys V2.3。

截止当前，我中心通过监测手段发现国内若干暴露在互联网上的安装有该软件的设备，详细信息见附录一和附录二。

三、漏洞处置建议

目前厂商已经发布了升级补丁以修复此安全漏洞，建议相关用户尽快下载更新补丁，预防风险发生。

详情请关注厂商网站的相关信息：

https://www.codesys.com/support-training/codesys-support.html

此外，建议相关用户应采取的其他安全防护措施如下：

（1）最大限度地减少所有控制系统设备和/或系统的网络暴露，并确保无法从Internet访问。

（2）定位防火墙防护的控制系统网络和远程设备，并将其与业务网络隔离。

（3）当需要远程访问时，请使用安全方法如虚拟专用网络（VPN），要认识到VPN可能存在的漏洞，需将VPN更新到最新版本。
