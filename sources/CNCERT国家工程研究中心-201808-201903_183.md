# 美国电信运营商CenturyLink停电致各地911服务受影响

由于几个CenturyLink数据中心报告了大规模停电，美国一些州的紧急911服务27日和28日已经停止。

根据CenturyLink 状态页面显示，故障于美国东部时间12月27日中午12点左右开始，并且在美国东部时间28日早上7点左右开始处理，但并非所有服务都已恢复。

在Twitter上，服务商将这次宕机描述为“影响客户服务的网络因素”。该公司称，神秘的“网络元素”问题影响了欧洲和北美的15个数据中心的服务。

互联网服务提供商一直处于长时间停电状态。然而，这个技术问题与其他不同，因为CenturyLink是许多美国911紧急呼叫中心的互联网和电话连接的主要提供商之一。

全美各地在过去几小时内报告了其911个呼叫中心的停机时间，影响了华盛顿州，俄勒冈州，明尼苏达州，马萨诸塞州，爱达荷州，新墨西哥州，密苏里州，亚利桑那州，科罗拉多州等，宕机影响甚至跨越边境，加拿大的911个服务也被波及。

28日，当地警方和县治安部门一直在社交媒体上回应受到困扰的用户，向当地调度员提供直接电话号码。除了911服务外，停电还影响了公司的住宅互联网，电话和电视提供商服务。由于同样的原因，一些自动取款机也出现故障。在社交媒体上抱怨的客户声称他们的连接问题是在CenturyLink宣布问题发生发生的前一天（也就是26日）就开始了。

不过，尽管这家美国ISP正致力于恢复服务，但事情可能不会像该公司希望的那样顺利。今天早些时候，CenturyLink的一名发言人在Twitter上说，该公司发现“在我们正在进行的服务恢复工作中还存在一些技术问题”。

到目前为止，仍没有时间恢复对所有百年连接受影响客户的全面服务。

但是，尽管美国ISP正在致力于恢复服务，但事情可能并不像公司希望的那样顺利。CenturyLink发言人28日在Twitter上表示，“在我们正在进行的服务恢复工作中还存在一些技术问题，目前为止没有时间为所有受CenturyLink影响的客户恢复全面服务”。
