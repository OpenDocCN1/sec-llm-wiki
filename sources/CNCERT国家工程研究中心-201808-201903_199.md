# 受到网络攻击的电动汽车充电器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247486880&idx=3&sn=0ae7ff849030a78009ca2b9aff5c419a&chksm=fa90bb61cde732779b0cb83afac1c3707a307ee0e0fcfc292c2e3837605828de69e0b5e1cac9&scene=126&sessionid=1681365658#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247486880&idx=3&sn=0ae7ff849030a78009ca2b9aff5c419a&chksm=fa90bb61cde732779b0cb83afac1c3707a307ee0e0fcfc292c2e3837605828de69e0b5e1cac9&scene=126&sessionid=1681365658#rd)

电动汽车开始出现在世界各地的道路上。虽然家用电动汽车充电器可以非常方便，但同时它们还会给用户的家庭带来危险。

卡巴斯基实验室(Kaspersky Lab)的研究人员称，一家未被点名的大型供应商制造的电动汽车充电器可能存在危险的漏洞。

专家们得出结论，黑客可以远程干扰充电过程，从而导致电动汽车没有足够的燃料。另一种是操纵充电过程，使这个充电过程能够持续产生最大的电流。

任何连接到物联网的设备都面临同样的危险。由于所有这些设备都连接到同一个网络（物联网），通过访问其中任何一个设备的漏洞都有可能让网络罪犯访问其他设备。这会危害用户的隐私和安全。

新发现的漏洞已经被修补，但是，最好假设不是所有的漏洞在被利用之前都会被保护。此外，许多物联网设备的安全依赖于用户的保护能力以及他们的选择。然而，这是另一个问题出现的地方，因为用户并不总是熟悉他们在这方面的责任。

为了有助于保护用户的家庭和设备，卡巴斯基实验室提供了可能提高安全措施的建议之一，就是定期升级智能设备（的软件和固件）。

另一条建议是不要使用默认密码。因为这可能会导致僵尸网络（Botnet）的创建，侵犯隐私，或对链接物联网的设备造成损害。最后，卡巴斯基建议用户隔离他们的家庭网络。但这个过程可能需要与路由器制造商或网络专家合作。然而，这样做可以保护设备免受其他设备(如计算机)已经熟悉的互联网的危险。
