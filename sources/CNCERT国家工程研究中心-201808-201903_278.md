# CNCERT在2018年全国网络安全等级测评机构网络安全攻防大赛中荣获佳绩

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247486474&idx=1&sn=200530e7bef1dce4fb1505cbaac38f14&chksm=fa90bacbcde733dd9b684f4d28cd26ed170bd50fdf7e3c2a57d6b0bb2e0ccd5ed46f8d4f9907&scene=126&sessionid=1681365679#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247486474&idx=1&sn=200530e7bef1dce4fb1505cbaac38f14&chksm=fa90bacbcde733dd9b684f4d28cd26ed170bd50fdf7e3c2a57d6b0bb2e0ccd5ed46f8d4f9907&scene=126&sessionid=1681365679#rd)

2018年10月21日， 2018年网络安全等级保护测评能力验证与攻防比赛在北京科技大学体育馆圆满落下帷幕。经过一整天赛事的激烈角逐，国家计算机网络与信息安全管理中心代表队脱颖而出，赢得了综合排名第四的佳绩。

本次大赛由公安部网络安全保卫局、中国合格评定国家认可委员会（CNAS）指导开展，由中国电子科技集团公司第十五研究所主办。公安部网络安全保卫局总工程师郭启全、CNAS副秘书长宋桂兰、中国电子科技集团公司第十五研究所副所长谭景信等领导一行莅临现场参观指导。来自全国各地的166家等级保护测评机构、870多名测评人员参与此次大赛。共有38家单位能力验证活动评价结果有待加强。

本次活动在《中华人民共和国网络安全法》实施的背景下，落实《网络安全等级保护测评机构管理办法》要求，旨在规范全国测评机构的工作，提升各测评机构的网络安全测评与攻防能力，考查已获CNAS认可的测评机构及准备申请认可机构的测评能力，加强测评机构之间的交流，为测评机构管理、认可和能力持续提供有力的支持。
