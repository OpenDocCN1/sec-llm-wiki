# 中国移动发布工业互联网系列产品

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247486347&idx=3&sn=1e8dc1b67fd9968a1a2412622cdb392e&chksm=fa90bd4acde7345cc15f8eacd76bac88badf30b173584d3e1e43e3e9843c18373c9a96b0656f&scene=126&sessionid=1681365679#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247486347&idx=3&sn=1e8dc1b67fd9968a1a2412622cdb392e&chksm=fa90bd4acde7345cc15f8eacd76bac88badf30b173584d3e1e43e3e9843c18373c9a96b0656f&scene=126&sessionid=1681365679#rd)

![](../Images/a25346dec44cd18bd669b01c78de8c15.png "中国移动发布工业互联网系列产品")

中国移动首次对外发布针对工业互联网垂直行业的 “1+4”为核心的工业互联网平台产品，同时在会上宣布构建开放、合作、共赢的工业互联网行业新生态。

中国移动立足连接、服务、开放三大优势，聚焦设备联网、数据分析、行业机理标准化三大问题，构建深入行业的工业互联网开放平台。平台采用“1+4”的产品布局，即1个行业平台，提供统一、通用、聚合、开放的行业共性服务；4大垂直行业，即制造云、电器云、能源云、动力云，通过深入细分领域提升行业价值；同时聚合自有产品和行业能力构建区域工业云助力百万工业企业上云，推动区域经济发展。中国移动将依托工业互联网平台，赋能行业，智造未来。

![](../Images/70bf503b9d0aab3f1cea59f6858eec37.png "中国移动发布工业互联网系列产品")

中国移动同时还发布了工业互联网生态。中国移动将发挥自身网络优势、客户优势、渠道优势、资本合作优势，构建全面战略合作伙伴加行业合作伙伴的立体化合作体系，发挥产业链各方优势，汇聚行业优质能力。发布会完成首批18家合作伙伴现场签约，实现优质工业互联网能力的一点接入、全网服务。

未来，中国移动将继续深耕工业互联网领域，立足垂直领域行业化需求，用5G、物联网和大数据等技术为工业企业打造智慧运营新模式，携手合作伙伴共建工业互联网行业生态。
