# 智能变电站二次设备漏洞挖掘初探

**1、 引言**

随着智能电网概念的出现而兴起，以往的常规变电站已经无法满足智能电网的要求，智能变电站应运而生，并成为智能电网的重要环节。

然而随着智能化程度的提高，智能变电站系统面临的信息安全形势也越加严峻。尽管智能变电站网络相对封闭，但当威胁源以APT（高级持续威胁）的形式出现时，由于其具有强大的渗透能力和隐蔽性，工业网络内部的HMI、数字化/保护测控装置以及通信协议（如IEC 61850等）的脆弱性也将暴露出来，成为主要受攻击面。因此，如何提高智能变电站的安全运行水平，发现系统脆弱性，并做好安全防护就成为电网安全的一个重要研究方向。

本文是对智能变电站实验室仿真环境中的二次设备进行漏洞挖掘的初步总结，主要给读者呈现两个方面的内容：

结合智能变电站的实际情况，了解其技术和设备具有的主要技术特点；

对智能变电站二次设备进行漏洞挖掘，发现其脆弱性，为今后智能变电站安全防护技术研究提供技术支撑。

**2、 智能变电站简介**

2.1 智能变电站系统结构

目前典型智能变电站一体化监控系统由站控层、间隔层、过程层设备以及网络设备组成，各层主要包括的设备如下：

站控层：包括监控主机、数据通信网关机、数据服务器、综合应用服务器、操作员站、工程师站、PMU数据集中器和计划管理终端等；

间隔层：包括线路保护装置、测控装置、故障录波装置、网络记录分析仪及稳控装置等；

过程层设备包括合并单元、智能终端、智能组件等。

![](../Images/9d736ca7deb7ca84726243efffd8cee0.png)

  

2.2 智能变电站工作过程

智能变电站主要包括智能高压设备和变电站统一信息平台两部分。智能高压设备主要包括智能变压器、智能高压开关设备、电子式互感器等。智能变压器与控制系统依靠通信光纤相连，可及时掌握变压器状态参数和运行数据。当运行方式发生改变时，设备根据系统的电压、功率情况，决定是否调节分接头；当设备出现问题时，会发出预警并提供状态参数等，在一定程度上降低运行管理成本，减少隐患，提高变压器运行可靠性。智能高压开关设备是具有较高性能的开关设备和控制设备，配有电子设备、传感器和执行器，具有监测和诊断功能。电子式互感器是指纯光纤互感器、磁光玻璃互感器等，可有效克服传统电磁式互感器的缺点。变电站统一信息平台功能有两个，一是系统横向信息共享，主要表现为管理系统中各种上层应用对信息获得的统一化；二是系统纵向信息的标准化，主要表现为各层对其上层应用支撑的透明化。智能变电站信息流如图所示：

![](../Images/d0a9d9428c39fdc02fa38d826adc6f8a.png)

  

图中①、⑥在间隔层和变电站层之间通过MMS交换数据（如：保护定值，遥测，遥信，动作报告，文件传输）；③在间隔内通过GOOSE或私有协议交换数据；（如：闭锁控制）；④在过程层和间隔层之间通过SV交换PT、CT的实时采样数据；⑤在过程层和间隔层之间通过GOOSE交换控制数据（如：跳闸信号，开关位置）；⑦、⑩在站控层和地调、省调通过远动协议（IEC104）交换数据（如：四遥信号）；⑧在间隔之间通过GOOSE直接交换快速功能数据（如：联锁信息）；⑨在站控层之间通过私有协议交换数据（如：同步数据）。

**3、 研究过程**

3.1 安全现状分析

智能变电站二次设备研发过程主要考虑的是功能实现、高效处理等问题，自身安全性问题往往被忽略。它们使用SV、Goose、IEC104及MMS等相关工业控制协议，本次研究的是用于指令控制的MMS协议，其主要特点如下：

通信基于TCP/IP；

明文传输，无加密；

缺乏身份认证、访问控制等安全措施。

在无任何安全防护措施的工业控制环境中，攻击者可利用自己编写的攻击程序与二次设备进行通信，轻则致使二次设备宕机，重则导致变电站配电线路跳闸、引发电网异常等。

3.2 仿真环境介绍

实验室仿真环境参照电网使用的主流智能变电站二次设备的实际组网情况进行搭建，考虑到成本问题，仅部署核心组件，一次设备通过软件仿真实现。

3.3 漏洞挖掘工具

智能变电站二次设备的硬件类似一个“黑盒子”，对此设备的安全研究有别于传统软件安全研究，我们并不完全知道它们内部系统的运行原理，因此需要使用专业的、针对工控系统的漏洞挖掘工具进行相关研究。

威努特工控漏洞挖掘平台（Winicssec IVM）是用于挖掘各类工控设备未知漏洞的一款产品。该产品对当前主流的工业控制协议进行分析，根据它们的特点，用模糊测试的原理来生成对应的协议测试报文（包括正确的和错误的报文），通过对协议字段进行变换，例如边界测试等等方法，进行安全性和健壮性测试，深度挖掘工控设备存在的各类未知漏洞。

模糊测试(Fuzzing)是一种基于缺陷注入的自动软件测试技术，其思想是通过编写fuzzer工具向目标程序提供某种形式的输入并观察其响应来发现问题。威努特工控漏洞挖掘平台（Winicssec IVM）通过智能Fuzzing技术，针对不同工控设备通信协议（TCP/IP协议和Modbus/TCP、DNP3、IEC104、IEC61850、MMS、GOOSE等工控协议）的特点精心构造相应的随机发送测试报文，观察工控设备的各种响应异常情况来分析工控设备存在的可被利用的漏洞。

模糊测试数据的生成分为两种，如下：

基于变异的模糊测试生成器，通过对已有的数据样本进行变异来创建测试用例。

基于生成的模糊测试生成器，通过为被测设备使用的协议格式和交互逻辑进行建模，从而用此模型来生成输入并据此创建测试用例。

3.5 问题汇总分析

通过上述对智能变电站设备的漏洞挖掘测试，威努特安全研究团队在智能变电站设备上发现了以下安全隐患。

应用层协议问题（含工控协议）

保护装置的MMS协议栈存在溢出漏洞，可导致设备宕机；

测控装置的MMS协议栈存在溢出漏洞，可导致设备离线；;

测控装置存在WDBrpc接口，可导出设备运行内存信息；

远动装置的rpcbind协议存在脆弱性，可导致设备离线。

设备网络协议栈安全问题（共计27处，不一一列举）

**4、问题影响分析 **

漏洞挖掘过程中发现的问题可导致设备离线或宕机，如果有攻击程序进行长时间或定期实施攻击，那么对变电站的稳定运行将产生严重影响，通俗讲其效果如同变电站没有这些设备，处于最原始的运行状态。

即使智能变电站的网络与互联网是隔离的，但仍然有被攻击的可能性，而且实现方式更加隐蔽。在智能变电站运行现场，攻击者就可以利用其系统脆弱点进行生产破坏，如攻击者可以利用软件升级或设备调试的机会，在智能变电站的工程师站注入恶意程序进行攻击，可以导致变电站输电线路断闸，也可使设备宕机或拒绝服务。下图是已经注入攻击程序Paylaod的正常程序，当正常程序运行时攻击程序也会运行并进入潜伏期，并可以在指定的时间进行间歇性攻击，从而导致变电站二次设备工作异常,甚至可对变电站输电线路实现断闸操作。

**5、问题解决**

通过对智能变电站系统的初步漏洞挖掘，可以发现其工控设备在系统层面、应用层面都存在着不同程度的安全漏洞，这些安全漏洞一旦被敌对势力或破坏分子利用将对电网的安全生产构成巨大的威胁。在这种情况下，我们建议通过网络层防护+应用层防护的思路来解决这些现有问题。

● 在应用层面，上位机上部署基于白名单思想的工控主机卫士，在彻底防止非法程序运行的同时，也能有效管控移动存储设备。

● 在网络层面，部署工业防火墙实现对工业协议的深度解析和指令级控制，防止攻击者利用伪造控制指令发起的攻击和误操作等问题。

对安全而言，问题发现的越早，解决问题的代价就越低。如果能建立一种业界共识、切实可行的机制，对入网设备进行准入测试，如通过漏洞挖掘提前发现未知漏洞等，将会是一种更有效、更经济的工控安全解决方案。
