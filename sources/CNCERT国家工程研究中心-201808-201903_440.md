# 9月1日起公共安全视频监控产品GA认证工作正式开始

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247485739&idx=3&sn=8bfbcd7da07fb2da73e6ffd5295787d2&chksm=fa90bfeacde736fc19afaba70b07c6c23e4fb126a74c8942cb6bb813834b20751b588b13c261&scene=126&sessionid=1681365699#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247485739&idx=3&sn=8bfbcd7da07fb2da73e6ffd5295787d2&chksm=fa90bfeacde736fc19afaba70b07c6c23e4fb126a74c8942cb6bb813834b20751b588b13c261&scene=126&sessionid=1681365699#rd)

日前，公安部科技信息化局给中国安全技术防范认证中心发文《关于同意开展“社会公共安全产品自愿性认证公共安全视频监控产品”认证工作的批复》（公科信标准\[2018\]74号），批准了由中国安全技术防范认证中心牵头，安防认证、检测机构、标委会、行协及有关企业等方面参加制订的公共安全视频监控产品认证实施规则，至此，我国视频监控产品正式纳入中国公共安全产品认证(GA认证)范围，公共安全视频监控产品GA认证全面开启。

近年来，全国公安机关大力推进公共安全视频监控联网建设，深化公安视频图像信息综合应用，有效地服务于社会治安防控，提升了公安工作战斗力。为加强公共安全视频监控联网建设的标准化、规范化、专业化水平，保证产品质量，在公安部科技信息化局组织下，开展了公共安全视频监控产品认证的调研论证工作，并按照国家对于产品认证的法律法规和规范要求，起草相应认证实施规则。历时两年多，多次召开讨论会，广泛征求各方意见，数易其稿。为了认真贯彻落实国家发改委、中治办、公安部、科技部、信产部、财政部、人社部、住建部、交通部八部委发布的《关于加强公共安全视频监控建设联网应用工作的若干意见》，保证视频监控联网应用和视频信息安全，今年初开始，围绕视频监控产品联网功能和信息传输安全性能的落实，经过充分论证，在制订的公共安全视频监控产品认证实施规则中，规定了通过GA认证的视频监控产品应符合国家标准GB/T28181-20116《安全防范视频监控联网系统信息传输、交换、控制技术要求》和GB35114-2017《公共安全视频监控联网信息安全技术要求》的相关要求。

目前，开展公共安全视频监控GA产品认证的各项准备工作已就绪。遵照公安部要严格规范、有序推进公共安全产品认证工作的要求，承担公共安全视频监控产品认证检测的公安部安全与警用电子产品质量监督检测中心已完成GB35114-2017等新颁布国家标准的检测能力建设，通过了国家认可委实验室能力认可。中国安全技术防范认证中心向国家认监委报备了认证实施规则，自2018年9月1日正式受理公共安全视频监控产品GA认证申请，将在今年10月于北京举办的安防国际博览会上，举行首批“公共安全视频监控产品GA认证颁证仪式”。

公共安全视频监控GA产品认证工作进展，敬请关注中国安全技术防范认证中心网站。认证中心、检测中心开会确定视频监控GA认证实施方案。
