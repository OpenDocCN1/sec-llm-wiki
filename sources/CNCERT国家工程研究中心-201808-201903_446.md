# 特斯拉出现大面积网络故障，车主无法登录网站和应用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247485719&idx=3&sn=198fa6739c01774f13f7107ea796ad09&chksm=fa90bfd6cde736c0e0a7cf0ab5f82034f6ba20189f2f8d87d13ac42ecf5240e5c28f3df617ee&scene=126&sessionid=1681365699#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247485719&idx=3&sn=198fa6739c01774f13f7107ea796ad09&chksm=fa90bfd6cde736c0e0a7cf0ab5f82034f6ba20189f2f8d87d13ac42ecf5240e5c28f3df617ee&scene=126&sessionid=1681365699#rd)

**摘要：特斯拉的车队网络连接目前处于大面积瘫痪中，一名特斯拉发言人称，他们正在“努力解决这个问题”。**

![](../Images/82ee32285e4a0e762c77a1eb2c6b4161.png)

北京时间8月30日早间消息，特斯拉的车队网络连接正逐渐成为车主们较为重视的一个功能，然而这个备受器重的功能目前处于大面积瘫痪中。

一名特斯拉发言人称，他们正在“努力解决这个问题”。

在此之前，特斯拉的网络也多次瘫痪过较长一段时间。

2016年的时候，特斯拉系统瘫痪了整整一天后，车主才得以重新接入互联网，使用远程数据、流媒体音乐、实时导航，乃至Autopilot等功能。

当时，特斯拉表示问题出在AT&T的网络上，后者为特斯拉在北美的互联网宽带供应商。

今天，有车主报告他们车上的网络自美国东部时间下午3:30左右开始无法正常使用。这一次，问题似乎出在特斯拉的应用和车队网络上，因为车内的其他网络功能没有异常。

该网络连接和访问特斯拉应用的功能对Model 3的车主尤其重要，因为他们经常使用应用来解锁和启动自己的车辆。

在上一次的网络连接故障时，特斯拉称Model 3车主如果已在手机上登录他们的特斯拉账户的话，他们仍可以使用手机解锁车辆。

特斯拉官网同时也无法访问。
