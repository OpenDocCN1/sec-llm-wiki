过去几年，物联网（IoT）发展在第一波热潮过后逐渐趋于冷静，而就今年的巨头动作频频，竞争越来越激烈来看，第二波热潮已然到来。

物联网设备接入量作为物联网平台得以继续发展的基石，不断被各公司提及，百万级、千万级、亿级，整个市场的容量和各公司的发展从这一数据也可见一斑。雷锋网编辑就部分公司公布的平台设备接入量数据统计如下：

截止目前，华为HiLink设备的注册量达到1000万~1500万台，激活率为70%（700万~1050 万台）；小米IoT开发者平台设备接入量达8500万台；百度DuerOS设备接入量超过1亿台；海尔U+平台用户超过1.3亿台；阿里云Link计划未来5年内接入设备量达到100亿台。

![](../Images/ab89ba0d2ea066b35a6610eefdc54843.png)

### **IoT迎来第二春，平台设备接入量屡破新高**

## 物联网发展在第一波热潮后，经过几年的过渡期，如今整个市场又迎来第二波热潮，而这第二波热潮究其原因是物联网操作系统、边缘设备、智能硬件等整个生态中其他技术及产业日趋成熟带来的局势，具体表现为：  

1）物联网操作系统。各巨头公司相继推出面向IoT及其设备的操作系统，谷歌Cloud IoT Core、百度DuerOS、阿里云AliOS Things、华为LiteOS操作系统等，操作系统的匹配为物联网的设备连接带来铺平了道路；

2）边缘计算。边缘计算仍是现在物联网布局中重要组成部分，在过去几年里，边缘计算布局也渐渐成形，例如微软Azure IoT Edge、百度BIE、阿里云Link Edge等；

3）智能硬件。作为物联网最终服务对象，智能硬件的市场体量在很大程度上决定着物联网的发展速度，过去几年智能硬件的热潮带来了整个市场的扩容，据前瞻产业研究院2018年物联网产业分析报告中公布的统计数据显示，2016年全球物联网设备量为64亿台，2017年全球物联网设备量达到84亿台，预计2020年将达到204亿台。

物联网生态的不断拓展、智能设备量的不断激增，为物联网平台厂商带来了更多机会，包括谷歌、微软、亚马逊、百度、腾讯、阿里、京东等国内外科技巨头，以及如机智云、庆科云等新兴势力都拥有自己的IoT平台。

如此众多的物联网平台各自有何特征及应用方向？雷锋网编辑将从云端平台和终端平台两方面为大家盘点国内外物联网平台的布局及现状。

### **百度“天工”**

百度“天工”是百度在2016年7月推出的基于百度云构建的物联网平台，同时融合了自家大数据平台（天算）和人工智能技术（天智），自成一体（ABC战略）。百度开放云高级行业发展经理金锋曾表示：区别于面向个人智能设备的终端物联网平台，百度“天工”的目标是打造侧重于面向制造、能源、物流等行业的产业物联网平台。

百度“天工”是一个端到云的全栈物联网平台，提供包括物接入、物解析、物管理、规则引擎、时序数据库、机器学习、MapReduce等物联网产品和服务，设备接入能力在千万级，数据读写能力在百万数据点每秒。另外，百度作为国内第一大搜索引擎，拥有毫不逊色的智能大数据平台——“天算”，百度“天工”可以无缝对接“天算”大数据平台，同时，“天工”还可以通过自身提供的API接口实现与企业应用或其他第三方平台的对接。

![](../Images/5165ef340141019b5dc5bc6f3f6183ce.png)

以风电机组运维为例，通过应用百度云“天工平台+人工智能”解决方案，对影响风电设备使用寿命的主要数据进行长期采集，从历史监控数据中找出故障发生前的数据，通过百度机器学习（BML）进行模型训练，得到设备发生故障前的特征和趋势，并通过该模型进行设备故障预测，可提前12小时预测风电机组设备故障，故障预测召回率可达99%。

今年5月，百度“天工”发布智能边缘产品BIE（Baidu IntelliEdge），进一步推进端云融合，提供端云一体解决方案。

BIE在云端进行智能边缘核心设备的建立、身份制定、策略规则制定、函数编写、AI建模，生成配置文件下发至本地运行包，在本地运行包里完成数据采集、消息分发、函数计算和AI推断等功能，通过一键发布和无感部署提高智能迭代速度。另外，BIE还支持PaddlePaddle和TensorFlow等主流AI平台训练的算法模型，与百度云推出的函数计算服务完全兼容。 

![](../Images/7923ad7d92990d3daa365a47e9e6b3ce.png)

据百度官网信息显示，百度“天工”如今已经能够提供包括智慧城市、智慧物流、工业设备、车联网、智慧家居各领域解决方案。其中在智慧城市方面已有霍尼韦尔、迹客科技、智向科技、百度系统部、从容维护客户应用案例；在智慧物流方面已有中鼎智慧物流云、阳泉智慧陆港客户应用案例；在工业设备方面已有宝武集团、普奥运、登云、物联天下等客户应用案例。  

另外，百度在2017年7月发布的DuerOS对话式人工智能系统作为其在物联网方面的拓展系统，截至2018年7月底，搭载DuerOS的智能设备激活数量已突破1亿台。

### **阿里云Link**

2017年10月，阿里云在杭州.云栖大会上发布阿里云Link物联网平台，提供物联网云端一体化使能平台、物联网市场、ICA全球标准联盟等三大基础设施，宣布走“平台+市场+标准”三位一体战略，并提出五年连接百亿设备的目标。 

早在2017年6月，阿里联合200多家物联网产业链企业成立物联网标准联盟。如今阿里云Link已经完成生活平台、城市平台和商业共享平台的的搭建，解决方案覆盖智能生活、智能城市、智能园区、智能农业、智能制造、智慧共享六大行业。

在基础产品层面，阿里云分别通过AIiOS Thing、阿里云Link WAN、阿里云Link Edge布局了嵌入式操作系统、广域低功耗物联通讯网络、边缘计算三个方面；在应用服务层面，阿里云Link可以提供测试与认证、魔笔、语音服务。

![](../Images/f6477442f51f80a1757601799ac4a2d5.png)

阿里云Link分为基础版和高级版（黄色部分为高级版本特有模块），其架构主要由IoT Hub、设备管理、规则引擎和安全认证组成。

**IoT Hub，**支持PUB/SUB与RRPC两种通信方式，帮助设备连接到阿里云IoT服务。阿里云Link的IoT Hub整个通信链路以RSA、AES加密，最多可支撑十亿级别设备同时连接，支持设备使用CoAP、MQTT、HTTPS多种协议接入；

**设备管理**，提供生命周期、设备组、设备影子、固件升级、物模型、数据解析、在线调试、远程维护、实时监控等多种设备管理服务；

**支持规则引擎**，当设备基于Topic进行通信时，可以编写SQL对Topic中的数据进行处理，然后配置转发规则将数据转发到其他Topic或阿里云服务上。例如可以转发到RDS、Table Store、HiTSDB中进行存储，转发到DataHub中进而使用Streamcompute进行流计算，转发到消息队列MQ实现高可靠消费数据，或将Topic中的数据处理转发到另一个Topic中实现M2M通信。

在安全认证方面，阿里云Link通过为每台设备颁布唯一的证书，提供多种设备安全认证来实现安全认证。授权粒度精确到设备级别。

![](../Images/80ebbbd3c9684e224e2fd98e4d90f7bb.png)

阿里云Link如今已有诸多落地物联网解决方案，包括智能停车解决方案、PFID药品追溯解决方案、特种集装箱物联网解决方案等。以RFID药品解决方案为例，针对医药产品全生命周期追溯系统阿里基于物联网技术，主要构建了药品制造过程物联网系统、药品流通过程物联网系统以及药品销售管理过程物联网系统，通过建立覆盖医药产品生产、流通、销售过程的全生命周期的追溯流程，实现生产、流通、销售全程跟踪与控制。

### **京东Alpha-IoT  
**

2017年6月，京东发布了Alpha-IoT开放平台。

据雷锋了解，在此前后，京东针对物联网APP、标准协议、产业联盟等方面进行了多方布局。2014年，京东发布用于智能连接的京东微联APP，用于接入各大智能设备，同年年底与国家相关部门、行业伙伴共建标准，发布物联标准协议Joylink；2016年4月，成立智能音箱联盟；2017年11月，京东联合康佳、乐视、海信、三星、夏普、小米等数百家厂商成立智能大屏产业联盟。

京东Alpha-IoT开放平台是2017年6月发布的面向硬件厂家的一站式智能硬件开发平台。该平台基于京东自家的 Joylink 协议，为各类生产企业提供跨品牌、跨品类智能设备的互联互通整体解决方案。整个平台包括一站式的开发平台、技术服务平台及内容服务平台。据今年年初京东对外公布的数据显示，京东IoT平台国内外合作厂商已有300多家，接入设备1000余类，每年销售额超过300亿元。

![](../Images/fe465f1bb29b094368e9b0662b5039ba.png)

京东Alpha-IoT平台可以通过WiFi、蓝牙、移动通讯网络（2G、3G、4G等）方式接入，接入端分为产品中心和应用中心。其中产品中心端接入遵循标准的产品接入流程，可以提供虚拟设备管理以及多维度（用户维度、设备维度等）数据信息；应用中心端基于平台提供的SDK或API自行定制开发，满足用户个性化需求。  

京东Alpha-IoT平台与自家的Skill开发平台（提供开发工具）、AI赋能平台（提供用于集成语音助手功能的标准API/SDK）共同组成Alpha智能服务平台，主要应用场景涉及智能家居、智能车载、智能手机及可穿戴。

### **华为OceanConnect IoT平台**

2016年9月，华为在HUAWEI CONNECT 2016大会上发布了其以IoT联接管理平台为核心的OceanConnect IoT平台。

OceanConnect IoT平台能够实现物联网终端设备到云端的互联，提供设备和平台之间的数据采集和命令下发的双向通道，对设备进行高效、可视化的管理，对数据进行整合分析，并通过调用平台面向行业的开放能力，快速构建创新的物联网业务。

华为针对物联网在2016年提出“121”战略，即1个开源物联网操作系统Huawei LiteOS、2种连接方式（包括家庭网关、工业网关的有线连接和2G/3G/4G/NB-IoT无线连接）及1个物联网平台——OceanConnect IoT联接管理平台。OceanConnect平台基于Cloud Native架构，提供包括设备接入、设备管理、数据分析、API网关、IoT Agent、规则引擎、业务管理门户七项行业功能套件，以及与第三方平台的开放互通能力，从而覆盖智慧家庭、车联网、公共事业及平安园区在内的行业解决方案。

![](../Images/d32e7f5a2606ec1824d337a38b96caff.png)

以智慧家庭为例，华为利用物联网技术，将家庭智能控制、信息交流及消费服务等家居生活有效地结合起来，使用户可以与家里的智能设备进行连接和沟通。通过OceanConnect IoT联接管理平台，实现不同品牌厂家设备快速集成、跨网关设备规则联动、统一家庭网关和App入口，涵盖家庭自动化、家庭安全、人身健康、能源管理和家庭娱乐等多个业务场景。

![](../Images/2ab70f6a1a1f5bfb28196a64db5a94c4.png)

### **机智云智能硬件自助开发平台**

2013年，机智云推出机智云物联网云服务平台1.0，随后经过四次迭代，如今已经更新到机智云5.0。

机智云物联网智能硬件自助开发平台同智能设备运用管理平台和大数据分析应用平台组成机智云在物联网端的整体布局。主要涉及家电、能源、商业、物联改造等行业解决方案。虽与BAT等巨头的生态体系有一定差距，但整个生态仍有自己的完整性。

雷锋网了解到，最新发布的机智云5.0平台包括机智云5.0物联网开发及云服务平台和IoT开源套件GoKit4.0。支持设备端开发（GAgent、MCU开发）和应用端开发（APP端、微信端开发、设备厂家业务云开发），提供IoT SaaS服务、企业SaaS服务及企业智能设备管理系统（CDMS系统）。

### **庆科云FogCloud**

2014年，庆科云发布物联网操作系统MiCO，随后开发出自家物联网云端平台FogCloud，2017年8月推出FogCloud 3.0，支持更多PaaS层、适用性更广、部署更灵活，提供AI服务和第三方资源接口。

不同于BAT等巨头企业，庆科云以操作系统入局，FogCloud是庆科云面向消费电子生产商、工业设备生产商和集成商的企业级物联网云服务平台，提供设备接入、数据存储和数据分析等平台服务。

FogCloud为设备及APP提供云端服务，包括产品/APP管理 、消息通道、数据存储、设备状态数据远程同步到手机设备，以及第三方微信平台开发、代码托管、在线调试等功能，针对智能家电、工业领域、智慧农业、智慧城市及智慧医疗领域提供解决方案。

![](../Images/ba54db8e9328d4f391577bf65029cf5c.png)

2017年8月庆科云CEO王永宏在2017庆科信息IoT解决方案上发布会上解释了其“三点三线”的战略方针。三点指FogCloud云服务、智能硬件设备以及应用开发者社区，三线指将云服务、设备、人连接起来的交互、配网等协议。

**谷歌云端物联网平台（Google Cloud IoT）  
**

谷歌在2017年5月发布Google Cloud IoT Core服务内测版，9月发布公测版，今年2月面向大众发布测试版，不断加强物联网的云端布局。

Google Cloud IoT提供完全托管服务，用于连接和管理物联网设备，设备连接量可达百万级别。Google Cloud IoT从连接的设备中提取数据，构建与Google Cloud Platform的其他大数据服务集成的丰富应用程序。Cloud IoT Core 将收集的设备数据发布到 Cloud Pub/Sub 以进行下游分析。用户可以使用 Google BigQuery 进行即时分析，通过 Cloud Machine Learning Engine 进行高级分析，或使用 Google Data Studio 中的报表和信息中心以可视化的方式呈现物联网数据结果。

![](../Images/0dadfed4d190145238b3518501341417.png)

Cloud IoT Core 由设备管理器和协议桥两部分组成。

通过设备管理器，用户可以用粗略的方式安全配置和管理各个设备；管理时可使用控制台或采用编程方式。设备管理器可确定设备的身份，并提供身份验证机制，用来在连接设备时对设备进行身份验证。它还会保留每台设备的逻辑配置，并可用于从云端远程控制设备。

协议桥为协议提供了连接端点，可对所有设备连接执行自动负载平衡。协议桥原生支持使用业界标准协议（比如 MQTT 和 HTTP）进行安全连接。协议桥可将所有设备遥测数据发布到 Cloud Pub/Sub，然后交由下行分析系统使用。

Google Cloud IoT平台支持大量嵌入式操作系统，可与 Android Things 无缝搭配使用，对来自领先制造商（例如 Intel 和 Microchip）的设备支持开箱即用，主要针对制造业、公用事业、智能运输、油气提供行业解决而方案。

Google Cloud IoT特点在于其端到端安全、便捷的数据洞察、角色权限数据管理及自动部署设备能力。另外，在今年7月的Google Cloud Next 2018上，谷歌发布了 Cloud Services Platform，用于帮助用户提升在谷歌云上的速度、稳定性，以及安全性和管理能力，公布了其最新的Cloud TPU。

### **亚马逊AWS IoT**

2015年10月，亚马逊在其re:Invent开发者大会上发布了AWS IoT物联网应用平台。

AWS IoT是使互联设备实现与云应用程序及其他设备交互的托管云平台，可以通过多台设备收集遥测数据，并存储和分析数据。AWS IoT支持数十亿台设备和数万亿条消息，并且可以对这些消息进行处理并将其安全可靠地路由至 AWS 终端节点和其他设备。即使这些设备未处于连接状态，应用程序也可以随时跟踪所有设备并与其通信。

![](../Images/6c895d6bc7275282a0f986f68ddeac88.png)

设备通过在 MQTT 主题下以 JSON 格式发布消息来报告自身的状态，通过使用 X.509 证书保护设备与 AWS IoT 之间的通信，用户可在注册表中为连接到 AWS IoT 的所有设备都创建一个条目，制定相关规则，确定要基于消息内数据执行的一项或多项操作，每台设备都有一个可存储和检索状态信息的影子，影子通过提供包含状态信息（报告状态和预期状态）、元数据和版本号的 JSON 文档来响应请求。应用程序可以通过请求更改状态来控制设备。  

AWS IoT组件包括设备网关、消息代理、规则引擎、安全与身份服务、注册表、组注册表、Device Shadow、Device Shadow 服务、设备预配置服务、自定义身份验证服务、任务服务。提供AWS CLI、AWS IoT API 、AWS SDK 、AWS IoT 设备开发工具包接口，以创建设备并与AWS IoT进行交互。提供包括Amazon Simple Storage Service（可扩展存储）、Amazon DynamoDB（托管型 NoSQL 数据库）、Amazon Kinesis（大规模的流数据处理）、AWS Lambda（在 Amazon EC2 的虚拟服务器上运行代码以响应事件）、Amazon Simple Notification Service（发送或接收通知）、Amazon Simple Queue Service （将数据存储在队列中以供应用程序检索）六类服务，主要应用互联网家居及工业IoT两大领域。

### **微软Azure IoT**

Azure IoT是提供在云中进行托管服务服务的 SaaS平台，充当中央消息中心，用于 IoT 应用程序与其管理的设备之间的双向通信。借助此解决方案可轻松连接、监视以及管理大规模的 IoT 资产。提供包括设备阴影、规则引擎、身份注册 、信息监测功能。另外，为了处理传感器生成的大量信息，Azure IoT套件随附Azure Stream Analytics，可实时处理大量信息。

![](../Images/e205e1127c03b06ac97357c7798d3b24.png)

通过与Azure IoT Hub、Azure 时序见解、Azure 机器学习、Azure Maps的组合服务平台服务，提供亿万 IoT 设备建立双向通信并大规模管理这些设备。然后将用户数据与其他平台服务相集成，以增强用户的解决方案。另外，Azure IoT可以通过Azure IoT Edge、Windows 10 IoT、Azure Sphere、Azure Stack构建智能化安全边缘。

![](../Images/e274df5a643f983027e8235dcbaeaac4.png)

目前，设备厂商可通过微信硬件平台提供的开发模式接入设备，微信官网也有给出诸如智能空调、智能电视、微信运动等接入参考方案。

### **苹果HomeKit**

2014年苹果发布智能家居平台HomeKit，2015年5月宣布首批支持其HomeKit平台的智能家居设备在6月上市。

![](../Images/31bfbd5b2151f8f67edc9e2eb01fe3eb.png)

HomeKit允许用户使用应用程序与家中的相关配件进行通信和控制。户还可以创建控制附件（例如恒温器或灯）的动作，将它们组合在一起，并使用Siri触发它们。HomeKit对象存储在驻留在用户iOS设备上的数据库中，该设备通过iCloud与其他iOS设备同步。HomeKit支持远程访问附件，多个用户设备和多个用户。HomeKit还为您处理安全和隐私。

HomeKit将家庭视为家庭自动化配件的集合，包括HMHome、HMRoom、HMAccessory、HMService、HMZone基本数据包，并使用独立于设备的协议将iOS、tvOS和watchOS设备与家庭自动化配件集成在一起。其应用程序主要可以实现以下三类功能：

1）发现与HomeKit兼容的自动化附件，并将它们添加到持久的跨设备家庭配置数据库中；

2）显示，编辑和处理主配置数据库中的数据；

3）与配置的配件和服务进行通信，让他们执行操作，例如打开起居室的灯。

另外，用户可以使用配件，服务和命令的逻辑分组来配置家庭，然后使用Siri通过简单的语音控制来调用复杂的操作。

### 物联网平台厂商的“分”与“合”

通览国内外诸多物联网平台，大都不只是提供一个云平台，而均加入了AI平台、互联互通平台（狭义上的物联网平台）、边缘计算三部分，或者更有财气的巨头公司会再为平台提供配套OS嵌入式系统。通过整体配备，自成一体，形成生态闭环。

这样的闭环生态也带来了物联网平台厂商竞争的必然性，例如，在2017年7月5日，百度DuerOS与阿里天猫精灵同天发布，火药味很是浓烈。

这样的闭环生态也有点类似苹果的闭环体系，但是现在的格局却并非如智能手机的“iOS+Android”的两大阵营（其他份额很小，可以不计），而是形成了N多阵营，这就带来了多个物联网平台的碎片化格局。但是随着物联网设备量的急剧增长，更多人对用户体验提出更高要求，也对平台的互联性提出了需求，也就有了现在一些平台开始考虑互通性和兼容性。例如海尔与百度的合作，将为平台的互联性带来更多可能。融合会是一个趋势，几经合纵连横后，最终会有几个生态体系留下来，现在还难下断言。不过，这一趋势将会加速亿级平台的涌现。

物联网正在不断影响着人类生活各方面，注定将会成为继互联网之后又一个改变人类游戏规则的技术概念。
