# 报告 | 《2019上半年科技金融安全报告》、《2019健康医疗行业网络安全观测报告》发布（附全文下载）

7月31日，在第五届互联网安全领袖峰会（Cyber Security Summit，简称CSS 2019）金融安全专场上，腾讯安全联合第一财经发布了《2019上半年科技金融安全报告》，详细披露了2019上半年科技金融的风险大数据和主要特点，旨在助力开拓科技金融安全思路，推进金融行业健康发展。

![](../Images/1473f710120788e12c944b2c3e1f93e3.png)

会上，腾讯副总裁马斌详细解读了腾讯“金融安全智慧超脑”的能力全景和实践成果，致力协同行业伙伴打造贯穿金融监管、风控和基础安全各层级的金融安全联动防御生态。依托金融行业的真实业务场景、行业需求和风控实战，“金融安全智慧超脑”已形成了金融监管、金融风控和金融基础安全等三大核心安全解决方案，能够帮助监管部门和银行、保险、证券等金融机构实现监管科技、风控模型和基础安全建设的升级迭代。

马斌介绍，目前，在与合作伙伴展开的落地实践中，“金融安全智慧超脑”已成功在金融监管领域，协助全国超过15个省市的金融监管部门实现金融风险“打早打小”，累计监测非法集资金融风险平台1.1万家。在金融风控领域，“金融安全智慧超脑”风控解决方案已累计服务超过1亿的用户，累计守护资金安全超过10000亿，防止了800亿的业务损失。已累计防护10亿风险请求，助力银行银行降本增效。而在金融基础安全方面，腾讯安全金融基础安全团队正在为腾讯云上所有客户提供DDoS防护，成功防御国内最高流量1.23T的攻击；并能为合作伙伴提供Web、主机以及数据运营等方面的防护，实现了用AI精准定位数据安全隐患，过滤97%的数据异常操作告警，平均每月节省300人/小时的安全运营工作量。

![](../Images/9fac33b337ae3bfa26faa89de2d7430f.png)

第一财经研究院副院长林纯洁详细解读了《2019上半年科技金融安全报告》。《报告》详细披露了包括“中高风险P2P网贷平台降至45%”、“非法集资涉案金额同比增长97.2%”、“金融风控压力升至千万量级”、“百G超大流量DDoS攻击增势明显”等安全大数据及其背后的推动力。同时，指出传统监管可以通过与监管科技的深度结合，增强监管“穿透力”和风险防御能力；金融风险管理应借助大数据、人工智能等技术完善风险控制体系；而在金融消费者层面，则应打造便捷工具，激发用户防范金融风险热情。

在同期举行的大中型政企通用安全专场，腾讯安全联合中国信通院发布《2019健康医疗行业网络安全观测报告》，基于腾讯安脉网络安全风险监测及量化评估系统提供的技术支持，对全国涵盖疾控中心、卫生监督局、公私立医院等15339家医疗行业单位机构进行观测并输出医疗行业风险量化报告，以期为医疗行业管理部门、医疗机构和信息安全厂商提供安全决策依据。

![](../Images/9c4759fdd76ca7bc005375d1d14c061a.png)

同时双方宣布达成战略合作，将共建“产业互联网安全实验室”，深入各行业网络安全标准研究，为智慧产业发展保驾护航。

![](../Images/6418223ae1bf1990292a1f6ae7a19170.png)

腾讯安全副总裁方斌表示，产业数字化转型催生安全形势变化，对安全管理提出更高要求。针对困扰企业和政府机构的网络安全管理问题，腾讯安全提出了打造以腾讯御见安全中心（SOC）为基础，接入腾讯内部及生态合作伙伴安全能力的一体化智慧安全管理体系，适应不同的行业实际需要，实现全天候、24小时的情报感知、攻击防御，并助力提升安全规划、管理效率。

区别于传统SOC，腾讯御见安全中心以“智能驱动安全运营”为技术核心，具备一体化、自动化和可视化三大特点。据腾讯安全技术专家梁玉博士介绍，首先，腾讯御见安全中心扮演着安全运营与风险管理的“航母”，将安全运营过程中的安全防护设施、流程机制等纳入同一框架内，构建统一的安全控制平面，这奠定智能驱动安全管理的基础。在此基础上，腾讯御见安全中心构建了自动化安全体系。例如，可结合云原生特性，实现自动化的持续风险监测、及时的风险闭环；可通过“AI辅助”进行自动化的安全事件分析，提升安全运营效率。最后， 通过可视化技术，来帮助安全人员更有效的理解和处理安全数据。例如，可通过可视化技术和灵活的交互方式来提升AI分析结果的说服力和可解释性。在具体的安全防护场景方面，腾讯安全还围绕政企客户最关注的人机关系和终端安全问题，从合规性出发，提供了覆盖终端防护及管理、办公网络、移动业务等多种场景的终端一体化安全解决方案，结合腾讯御点终端安全管理系统、零信任无边界办公系统（iOA）、统一端点管理系统（UEM）等，助力政企客户提升安全运营管理效率。
