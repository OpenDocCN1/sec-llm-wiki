2019年中国工业信息安全大会将于6月21日-22日在北京举办

本次大会以“智慧连接工业，安全守护未来”为主题，贯彻落实《国务院关于深化“互联网+先进制造业”发展工业互联网的指导意见》等文件要求，聚焦工业信息安全技术和标准研制、产业发展、工业互联网安全、工业控制系统安全和工业大数据安全等前瞻热点话题，邀请政府领导，国内外高校、科研机构、相关组织及企业代表出席活动，共商工业信息安全未来发展。

物联网安全——未来网络安全的主战场

近年来，“云物移大智”这些所谓的颠覆性技术，正日益成为网络信息技术应用趋之若鹜的新抓手，也自然成为网络安全矛头所向的主战场。

![](../Images/0229e69b0a542122569d610793346273.png)

这其中，随着5G时代的临近，引爆物联网广泛应用的趋势和热潮尤为人们所热议和关注。有人把物联网引发的这一变革，称之为继计算机互联网之后，世界信息产业发展的第3次浪潮或第4次科技革命。

物联网的应用无处不在，它所带来的风险也将无处不在。在未来的30年，随着物联网的发展以及日常生活中越来越多的连接，物联网安全将会成为网络行业的热门话题。

  

安全威胁分析 Security Threat Analysis

网络摄像头的安全威胁技术分

![](../Images/cec137a29b02805ba4af5c19514d5ada.png)

近年来，随着网络摄像头（Webcam）在安防监控、智能交通、智慧城市、智能生活等领域的应用越来越广泛，其安全变得尤为重要。由于需要通过网络进行管理，所以网络摄像头设备通常直接暴露在互联网上，并且缺乏完善的安全防护措施，导致网络摄像头设备极易受到攻击，致使个人隐私安全与互联网安全都面临着严峻的挑战。

  

安全事件 Security incidents

伊朗黑客组织新添黑客武器，政府网络易受影响

![](../Images/6097f248acb12b4f4608fb3c4d075936.png)

据外媒报道，伊朗黑客组织Muddywater APT在他们的黑客武器库中添加了新攻击手段。该组织影响范围广泛，其中包括政府、军方、电信和学术界。研究人员发现，新攻击手段针对政府网络，恶意文档包含嵌入式宏，一旦受害者打开文件，就会下载有效负载，最终利用远程代码执行漏洞CVE-2017-0199，允许攻击者使用Windows OLE（对象连接与嵌入）中的存在的漏洞。
