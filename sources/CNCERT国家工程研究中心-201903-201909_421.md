引言  

**什么是Booter？**

在互联网上发布的网站或站点，在上面可以购买或订阅一类付费的服务，即分布式拒绝服务（DDos）攻击服务。

**谁能使用Booter？**

通常情况下，只需要一个对目标有恶意的意愿和一个电子支付账号（比如PayPal）就足够了。通俗点说就是，我想用DDos攻击谁就可以攻击谁，而花费的代价却低廉到你无法想像：最低甚至可以不到一美元。

**谁在使用Booter？**

根据泄露的数据研究表明，目前大部分在Booter上订阅的DDos攻击行为，不管是发起方还是受害者，都不是些高价值的目标而是大量的普通人参与其中。比如有很多玩游戏的青少年在Booter上购买DDos服务，迫使游戏中的某一方下线；有很多小型的赌博或游戏类的网站运营方，通过购买DDos攻击服务攻击竞争者的网站，等等。

然而，通过公开或者泄露出来的数据所获取的情报，永远只是冰山一角。DDos攻击作为目前最活跃的网络黑产之一，其影响力任何时候都不能小觑，而Booter则是提供了发挥其影响力的一个平台，这也是网络空间面临的主要威胁之一。DDoS攻击不但破坏了网络的发展和进步，也削弱了那些新兴在线网站的创新能力，这些创业者们并不善于应对DDoS攻击威胁，因此更容易受到DDoS的敲诈、勒索。

另外，Booter一旦被恶意者有组织有系统的利用，用来攻击各类网络基础设施，比如新涌现的各类工业互联网物联网云平台，比如政府的选举投票网站，造成其服务被破坏或者中断，则会对部分区域或者行业的经济和政治造成安全威胁，进而可能会威胁到整个国家安全，最后有可能演变成一场网络战争。考虑到极其低廉的订阅成本，所以说Booter有可能是最廉价的网络武器。

Booter及背后的DDos攻击组织，是一种新型的包罗万象的跨国界犯罪组织，危害了全球网络空间及数十亿的互联网用户。为了应对其带来的威胁，不仅需要研究者们持续跟踪Booter及整个DDos攻击技术的演进和黑产生态的发展，提出相应的应对策略；也需要各国政府部门联合合作，形成一种有效的全球化应对政策。

**概述**

分布式拒绝服务攻击（以下简称DDos攻击），相信大家都不陌生，几乎随着互联网的一诞生就出现了，各大安全公司和政府部门也都在持续跟踪全球DDos攻击的情况。根据CNCERT发布的报告\[1\]，不管是发起攻击方，还是被攻击方，我国都是DDos攻击的重灾区之一。虽然在有关部门持续的打击下，最近两年其发展的势头得到了缓解，但仍然是网络空间面临的主要威胁之一。

在二十年前DDos刚开始出现的时候，这是一项只有资深黑客才能掌握的技术和资源，跟普通人几乎没有交集。而从2005年左右甚至更早开始，DDos攻击作为一种可以购买的商品或服务（DDos-for-hire）就已经出现了，这样普通老百姓也参与到了DDos攻击的生态中。随着互联网技术的进步，以及各种漏洞利用技术及攻击方法的发展，DDos攻击已经演变成为主要的网络黑产之一，其商业形态也变得越来越成熟。现在任何人都可以很容易的在互联网上购买到DDos攻击服务，而购买的一个主要入口就是各类Booter站点。

恶意者只需花低至几美金，就可以在Booter页面上买到一项DDos攻击服务，能够对一个目标对象发起网络攻击，而攻击的发起时间、持续时间和流量大小都可以定制。由于该服务是如此廉价，成为了网络地下经济最活跃的部分，通过网络DDos攻击来敲诈、骚扰和恐吓企业和个人变得异常容易。由于商业模式一直在地下运转的，人们对它们的底层技术和系统架构等知之甚少。

目前虽然有很多关于DDos攻击的监测和分析报告\[1\]，\[2\]，\[3\]，\[4\]，但是其主要关注点都在攻击事件和攻击资源的发现和分析上面，大部分都是基于流量分析、恶意样本分析等技术等来监测攻击事件。很少有把DDos-for-hire作为一个生态系统去整体研究，本文则通过对DDos-for-hire生态进行整体分析和对相关前沿的研究进行综述，试图为DDos攻击相关方向的研究和应对措施给出一点新的提示。

接下来的内容安排如下：首先分析了DDos-for-hire生态的整体结构，一般分为前端的Booter订阅页面和后端的攻击基础设施；接下来并分别对这两种都进行了详尽分析；后端攻击基础设施又分为直接反射攻击和大规模僵尸网络发起的攻击；在僵尸网络部分重点关注了物联网设备组成的僵尸网络；最后是总结。

**DDos-for-hire技术架构**

一个典型的DDos-for-hire服务技术架构由两部分构成：

1、面向用户直接提供订阅服务的Booter页面，一般也称之为Booter或者Stresser。他们都有一个合法的宣称：即对目标IP进行压力测试，但是该测试行为是善意的还是恶意的，并没有一个明显的界限。在搜索引擎上简单搜索一下这两个关键字，即可以检索到很多提供DDos服务的页面，另外还有大量的Booter服务通过各种地下论坛来交易；

2、面向目标具体实施攻击的后端基础设施。攻击设施是全球网络黑产的重要组成部分，经过很多年网络黑产经济的发展，已经变得非常庞大和复杂，几乎没有人能够一窥全貌。但是我们可以从技术原理上简单的把它划分为两大类：

第一类则是直接租用高带宽虚拟专用服务器(VPS)，利用网络空间的各类反射服务器直接发起攻击的基础设施；

第二类是由大规模僵尸网络（Botnet）组成的基础设施，一般需要很强的黑客技术来长期维护大量的僵尸节点。随着黑产商业的发展，也出现了Botnet-as-service，可以直接购买Botnet。

而具有讽刺意味的是，DDos攻击服务提供者在对别人发起攻击的同时，也通过购买云服务商或者其他机构（如CloudFlare）提供的DDos保护服务，来保护其他们的系统，包括前端Booter页面和后端攻击基础设施，免受竞争对手发起的DDos攻击。

从上面的示意图可以看到，DDos服务一般都是按月购买，价格甚至低至几美元，而他们能提供的攻击能力普遍达到了百GB级别。试想一下，如果一个恶意的攻击者订阅多个Booter服务，同时对同一个目标发起攻击，那么攻击流量很容易就能达到TB级别。一般的网站或者在线服务都承受不了这么如此大流量的DDos攻击，会直接瘫痪。

购买和使用DDos攻击服务并不需要专业背景知识，只需要一个恶意的想法和一点付费能力（有PayPal账户或者比特币钱包）就能购买到，而花费的代价却很低，甚至还不如一顿饭钱。但是其造成的破坏却会非常严重，甚至会危及整个网络产业，尤其是基于用户信任和持续可用的软件即服务和电子商务等。这类服务作为一种新型的网络犯罪方式，是最活跃的网络黑产之一。

那么，在整个网络空间到底有多少Booter服务？又是谁在购买和使用这些服务？我们能不能对整个Booter业务生态一窥究竟，对它有个基本的了解和认识? \[15\]的作者提出了一种构建Booter黑名单的方法，通过抓取搜索引擎关键字（论文中仅使用了三个关键词：Booter，Stresser，DDoser）的返回结果，从返回结果中抽取多维特征并使用各种分类器算法，最终识别出了600多个Booter服务站点，目前该列表还在github上维护。在\[7\]中，作者分析了三个著名的Booter服务商数据，包括Asylum、Lizard和VDO。从泄露出来的数据分析结果表明，这些Booter服务已经吸引了6000多名付费用户，并发起了60多万次攻击。作者还发现，Booter的大多数客户更愿意通过PayPal支付，通过PayPal支付干预能有效的打击到Booter服务。

事实上， Booter或其他类型DDoS租用工具等都是新技术新形式下的网络武器，针对其泛滥和普及，只有实行有效的应对措施和采取雷厉风行的打击行动才能够控制。根据\[21\]的报道，美国联邦调查局在关闭了15个最大的Booter服务站点后，全球的DDos规模降低了11%，平均攻击的降低了85%。由此可见，执法行动才是最为直接有效的解决方案。而发现和控制Booter、CC服务器和其他资源等，也一直是政府部门打击网络犯罪的重要组成部分。

在\[21\]的报道中同时也提到，这次美国联邦调查局的关闭行动只触及了DDos-for-hire问题的表面，随着DDos业务需求的增加和攻击基础设施或Botnet规模的变大，这些被关闭的Booter服务随时会卷土重来。这也说明：打击DDos网络犯罪是一项任重而道远的任务。因为这是个全球性问题，如果不能实施一种有效的全球化政策，在互联网空间完全自由的背景下，那么Booter服务今天在这里打下去，明天就会从那里冒出来。所以从技术上保持对Booter服务的持续关注和研究，显得尤为重要。

Booter订阅服务及交易信息，本质上是一类网络犯罪情报，如何搜集和分析这些网络犯罪情报，可以参考剑桥大学网络犯罪研究中心的研究 \[18\]\[19\]\[20\]，针对大量的地下论坛如著名的HackForums等，进行长期的数据爬取和跟踪分析，并运用社会网络分析方法分析他们的社会兴趣，运用自然语言处理方法对发布的信息进行分类，并根据论坛活动对参与者进行聚类，最后试图还原出Booter服务提供方和参与方构成的整个生态系统，从而为打击网络犯罪提供技术支撑。

**后端攻击基础设施**

**4.1 反射攻击**

反射攻击基础设施基本上由两部分组成：一是存在网络空间的大量被利用的反射服务器；二是发起直接反射攻击的服务器，一般租用虚拟主机。有关反射DDos攻击的原理及利用方式详见附录1。

笔者认为反射攻击的发展壮大主要得益于两个方面：一方面是网络带宽发展越来越快，相应的资费也越来越便宜，可以很方便进行全球网络空间扫描和探测，容易获取到反射服务器资源（当然，也有可能是直接在地下论坛购买相关信息）；二是云计算产业的兴起，租用一个虚拟主机搭建反射攻击服务器，不仅部署方便而且成本低廉。

让我们先来看看反射攻击的成本有多低：以亚马逊EC2云服务为例，一台最低配置的虚拟主机价格约为每小时0.0065美元。因此，如果租用50台虚拟主机用于对某在线网站发起低功耗DDoS攻击，每小时花费的成本将不到0.325美元，再考虑其他额外的费用，例如注册SIM卡并添加信用卡等等，使用虚拟主机进行一个小时的DDoS攻击花费大概在几美元左右。

根据统计\[17\]，对一个大型在线网站发起持续5分钟DDos攻击的成本平均为5美元。价格低廉、审核宽松的虚拟主机，不仅成为直接发起反射攻击的基础设施之一，也是架设Botnet控制端的主要阵地。

目前各国CERT机构及大型的安全公司一直在密切跟踪反射DDos攻击情况，如\[1\]中报告了目前我国境内的被利用的反射服务器位置分布及主要协议（Memcached、NTP、SSDP）。这些报告主要是跟踪反射服务器的情况，对于躲在后面发起攻击的服务器是哪些以及这些服务器背后的实际控制方是谁，则知之甚少。反射攻击采用的是源地址欺骗技术，目前也没有成熟的技术手段对其进行追踪。学术界最近这些年有大量针对反射攻击的相关研究，试图弄清楚背后的情况。接下来介绍最近几年关于反射攻击的研究情况。

**反射攻击相关研究情况**

针对反射攻击的研究，我们通过对相关论文的调研，我们总结可能主要是需要解决如下三方面的问题：

1、一是反射技术本身。跟踪和研究互联网上开放的协议哪些可能被利用来作为反射攻击，以及具体的反射攻击利用方式和放大因子等。2014年在\[5\]中首次对反射攻击所利用的协议和反射因子等做了系统性研究，总结出有14种网络协议可以用来进行反射攻击，包括DNS、NTP等等，但是2018年广为流行的Memcached反射攻击方式在该论文中并没有被提到。可见，随着互联网各种新的在线服务的发展，新的反射攻击方式相信还会继续出现；

2、二是反射行为跟踪。如何监测和发现正在发生的反射攻击行为，以及如何定位是由哪些服务器在发起反射攻击。研究人员设计了一种反射攻击蜜罐Ampot\[6\]，可以用来跟踪反射攻击。AmpPot通过监听可能被滥用的UDP端口来模拟具有反射放大攻击的服务，包括QOTD(17)、CharGen(19)、DNS(53)、NTP(123)、NetBIOS(137)、SNMP(161)、SSDP(1900)，MSSQL(1434)和SIP(5060/5061)等，同时根据端口侦听传入的UDP数据包进行监测。通过分析IP包头中TTL值的变化来分析攻击包的来源，发现大部分攻击都是单一来源，即反射攻击不是主要由Botnet发起。在\[8\]中继续对AmpPot蜜罐数据进行了深入分析。反射蜜罐被攻击利用之前首先要被探测包扫描发现，作者设计了几种新颖的方法能够区分出探测包和攻击包，然后将攻击包映射到探测包，从而知道攻击是实际从哪里发生的。根据\[8\]的数据和分析，反射DDos攻击的发起方服务器地址主要位于美国、荷兰、立陶宛、巴拿马、德国等；

![](../Images/37dc947303f6479c44d662af42b62c48.png)

图 反射扫描和攻击的主要发起方国家（来自参考文献8）

3、三是追踪反射攻击服务提供方。如何将已经或者正在发生的反射攻击行为与具体组织或Booter服务提供商关联起来。追踪可能是最难的部分，\[9\]提出了一种非常新颖的方法来解决此问题，该论文的研究团队花费不到400美元，订购了23项Booter服务对自己发起攻击，然后通过反射蜜罐抓到这些攻击数据，以此作为标记数据，设计了一个有监督的KNN分类算法，去识别攻击是由哪个Booter发起的。他们的数据和研究成果共享给了欧洲刑警组织和美国联邦调查局，协助警方打击网络犯罪时的调查取证。\[9\]研究方法或许能对我们以后开展相关工作给一点提示。

在DDos攻击黑产经济巨大的商业利益驱动下，反射攻击作为一种较新的成本低廉的DDos攻击方式，黑客必将会将继续挖掘反射攻击的潜能，将其利用到极致：一方面是对各种已有和新出现的互联网在线服务进行研究，哪些可能会变成反射攻击资源，比如\[25\]在DNS协议中发现了一种新的可以利用来作反射攻击的方式；另外一方面是更多的物联网设备，甚至是躲在家庭网关后面的家居类IoT设备\[24\]，都可能被用作反射攻击资源。所以针对反射攻击的对抗研究也是无止境的。

#### **4.2 大规模僵尸网络（Botnet）**

僵尸网络Botnet，即由大量感染恶意代码的计算机或设备构成的大型网络，是全球互联网和通信生态系统面临的最突出的一类威胁，也是DDos攻击基础设施最重要的组成部分。僵尸网络几乎伴随互联网的一诞生就有了，而随着网络黑产的商业化程度越来越发达，僵尸网络也跟DDos一样变成了一种服务，即Botnet-as-a-service\[12\]。

僵尸网络的根源在于设备软硬件的漏洞和人们的疏忽大意，为黑客进入和控制设备提供了入口。从理论上讲，最好的办法是修补所有漏洞和提高用户的安全意识。但实际上说起来容易做起来难，因此僵尸网络和DDoS-for-hire服务不太可能在短期内消失。

我们看到有一个新的趋势，万物互联大背景下，大量物联网设备IoT连接上网后，由于IoT设备的能力普遍较弱，安全措施较低，成为了广大黑产人员的香馍馍。根据卡巴斯基的报告\[4\]，在2017年11月至2018年11月期间，仅使用CoAP协议的物联网Botnet设备数量就增加了将近100倍。根据CERT恶意样本监测情况，目前活跃着多个由物联网IoT设备组成的僵尸网络，如Mirai、Gafgyt、Hajime 、BillGates等。接下来我们将重点关注由物联网设备组成的Botnet，下面介绍几种最主要的物联网僵尸网络家族：

Mirai：以日语“未来”发音而命名，于2016年5月第一次被发现。2016 年 10月初，在公开了其源代码以后，该恶意代码的变种越来越多。2016 年 9 月对某安全博客实施了大规模 DDoS 攻击，接下来的10 月又对著名运营商Dyn 进行了DDos攻击，导致美国半数的网络瘫痪数小时，随后 Mirai 便闻名天下。Mirai 恶意代码具有 UDP Flood, Syn Flood, ACK Flood, GRE IP Flood 等多种 DDos 攻击功能。\[11\]对mirai进行了多维度全方位的分析，数据来源包括网络远程探测、全网扫描、物联网蜜罐、C2 嗅探、DNS跟踪和攻击受害者提供的日志，以及mirai样本分析等。

Gafgyt：于 2014 年 8 月第一次被发现，特别是 2014 年末在 Lizard Squard ( Xbox Live ) 与 PlayStation Network 的 DDoS 攻击发生后变得更加知名。2015 年 1 月 Gafgyt 的源代码被公开，目前 Gafgyt 也是变种数量最多的恶意代码。我们收集到的数万个物联网恶意样本中，其中超过一半都是Gafgyt家族的；

Hajime：跟Mirai几乎是同时诞生，早期版本采用了很多与Mirai相同的感染方式，但与Mirai相比它有三个明显区别：首先，Hajime没有使用集中的CC服务器，而是使用点对点分布式哈希表(DHT)向其节点传播软件更新；其次，Hajime支持比Mirai更广泛的设备感染方法，包括最新Vault7泄漏的更新；第三，Hajime使用自定义协议来传播文件，其中包括交换公钥，从而允许我们通过长期密钥而不是短暂的IP地址来测量僵尸网络。\[23\]对Hajme进行了详细分析，使用了主动与Bot握手获取密钥，定期枚举DHT使用情况、DNS数据分析、恶意软件逆向分析等方法。

通过对主流物联网僵尸网络的分析，可以看到目前大部分运作方式一般是经过如下三个阶段：

第一阶段：侵入阶段，通过多种方式侵入IoT设备获取命令执行shell权限，主要有两种方式：一是通过ssh、telnet等暴力破解方式，这也是目前物联网Botnet野蛮发展的主要原因；二是通过特定设备的特定漏洞利用工具，某些最新漏洞的利用工具可以在黑产市场上买到；

第二阶段：传播阶段，将恶意代码植入IoT设备潜伏下来，一般采用wget、sftp等方式从集中的远程服务器上下载，或者采用P2P方式传播，运行恶意代码并消除痕迹；

第三阶段：执行阶段，设备上运行的恶意程序通过接收控制服务器发出的攻击指令，对目标发起攻击。

虽然各大安全公司或实验室都会定期发布IoT Botnet相关的技术报告\[26\]\[27\]，但是在学术研究领域，关于物联网僵尸网络，目前在主流刊物上发表的相关论文还相对较少。传统的DDos研究重点在DDos的攻击检测机制，在目前攻击流量动辄数百G或者上T的背景下，基于实时流量去做检测意义很小。我们认为更重要的是研究如何能够及早的抑制Botnet发展，即在入侵阶段和传播阶段就发现和控制，包括控制服务器地址，传播服务器地址等，配合网络执法部门关停它，或者共享给ISP服务商加入IP黑名单。

  

5  

**总结**

DDos-for-hire作为最活跃的网络黑产经济之一，在巨大商业利益的驱动下，相信会将一直活跃下去，最后对脆弱的互联网生态构成冲击。刘慈欣在科幻小说《三体》中提出了一种黑暗森林概念，描绘了这样一副场景：地球或者其他有生命的行星在广阔的宇宙中就像身处在黑暗森林中，只要在宇宙中暴露自己的星球坐标，就会遭到更高级别文明的侵略和打击。而现在的互联网在线服务有点类似，一旦目标暴露且被恶意者盯上，就会成为DDos攻击的目标。

虽然目前商业公司推出了防DDos攻击的解决方案，比如把web站点交给CDN托管防护，把真实的IP隐藏起来等。但是网络空间开放的天然基因决定了DDos攻击的风险会一直存在，而且会越来越严重，因为攻击手法越来越先进，攻击资源越来越丰富。尤其是万物互联的大背景下，海量接入互联网的设备都有可能成为DDos的攻击资源，不管是成为Botnet节点还是反射资源节点。

DDos攻击的基础设施是全球流动性的，不管是前端还是后端，都是哪里部署方便和便宜就去哪里，其威胁是对整个互联网空间的威胁。所以，针对DDos攻击的治理问题，不是哪一个国家或者政府能够独自解决的，需要全球齐心协力共同面对。

### **附录1：常见反射DDos攻击方式分析**

反射型的DDoS 攻击是一种新的DDos攻击形式。攻击者并不直接攻击目标服务 IP，而是利用互联网的某些服务开放的服务器，通过伪造被攻击者的 IP 地址、向有开放服务的服务器发送构造的请求报文，该服务器会将数倍于请求报文的回复数据发送到被攻击 IP，从而对后者间接形成 DDoS 攻击。作者在\[5\]中详细分析了能被反射攻击利用的协议，总结出共有14种协议可以被利用，具体如下图所示：

![](../Images/50aa36c887109fe63a9ae53c182b30dc.png)

图 x 常见反射协议及放大因子-参考文献\[5\]

目前主流的反射攻击服务主要有DNS、NTP、SSDP、Memcached等。Memcached是2018年开始流行的，由于其反射因子最高可以5万倍，被大量利用。下面简要介绍下这几种利用方式：

—DNS 服务是整个互联网的基础服务。理论上来说 ISP 的 DNS 服务器只响应来自它自己客户 IP 的 DNS Query 响应，但事实上互联网上大量 DNS 服务的默认配置缺失，导致了会响应所有 IP 的 DNS Query 请求。同时，DNS 大部分使用 UDP 协议，UDP 协议没有握手过程让其去验证请求的源 IP。攻击者发送大量伪造了受害者IP 的请求给 DNS 服务器，DNS 服务器成为放大器将 DNS 响应回复给受害者；

—NTP 是网络时间协议的简称，用来使计算机时间同步的网络协议。NTP 包含一个 monlist 功能，也被称为 MON\_GETLIST，主要用于监控 NTP 服务器，NTP 服务器响应 monlist 后就会返回与 NTP 服务器进行过时间同步的最后 600 个客户端的 IP，响应包按照每 6 个 IP 进行分割，最多有 100 个响应包。作为 NTP 管理员，需要加固 NTP 服务，将NTP 服务器升级到最新版本，并关闭 NTP 服务的 monlist 功能；

—SSDP，互联网上家用路由器、网络摄像头、打印机、智能家电等智能设备普遍采用 UPnP（即插即用）协议作为网络通讯协议， 而 UPnP 设备的发现是通过源端口为 1900 的 SSDP（简单服务发现协议）进行相互感知。利用 SSDP 协议进行反射攻击的原理与利用 DNS 服务、NTP 服务类似，都是伪造成被攻击者的 IP 地址向互联网上大量的智能设备发起 SSDP 请求，接收到请求的智能设备根据源 IP 地址将响应数据包返回给受害者。随着物联网和智能设备的快速发展和普及，利用智能设备展开 DDoS 攻击会越来越普遍。根据\[27\]的报告，在2018年第四季度，所有DDos攻击向量中， SSDP反射攻击占比最高，达到48.26%；

—Memcached，是一个全球范围内广泛使用的高性能的开源分布式内存对象缓存系统，基于内存的key-value存储小块数据，并使用该数据完成数据库调用、API调用等。攻击者正是利用 key-value 这项功能构造了大流量的Memcached反射攻击。攻击者首先在公开的Memcached服务器上植入大量数据；接下来，攻击者使用目标受害者的IP地址欺骗HTTP GET请求；脆弱的Memcached服务器接收请求后向目标发送一个大型响应。目标服务器或其周围的基础设施无法处理从Memcached服务器发送的大量数据，从而导致对合法请求的过载和拒绝服务。
