# 伊朗曾对英国关键基础设施发动网络攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247487948&idx=5&sn=e4d41cb6cd2fa457614b5ea4fc9088b3&chksm=fa90a70dcde72e1b91aad63940944b515e7503a332ab803ce52c64320d2b259862d98f9dedab&scene=126&sessionid=1681365608#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247487948&idx=5&sn=e4d41cb6cd2fa457614b5ea4fc9088b3&chksm=fa90a70dcde72e1b91aad63940944b515e7503a332ab803ce52c64320d2b259862d98f9dedab&scene=126&sessionid=1681365608#rd)

  

**小编来报：**一个与伊朗革命卫队（IRGC）有关的黑客组织曾对英国国家基础设施发动了两次网络攻击，但英国安全部门尚未证实这一报道。

  

据外媒报道，有调查报告显示，**一个与伊朗革命卫队（IRGC）有关的黑客组织曾对英国国家基础设施发动了两次网络攻击。**

  

**一次发生在12月23日，当时国家邮政局和其他一些政府网络遭到了攻击。**英国国家网络安全中心（National Cyber Security Centre）当时表示，2018年末发生了一起影响英国部分组织的网络攻击事件，提供了缓解建议。**黑客窃取了包含数千名员工的个人信息，其中包括邮局局长Paula Vennells等一些政府高官的个人信息。**

  

![](../Images/aa8f599d069a175a940651cc022698fd.png)

  

**另一次发生在2017年，英国议会网络遭受了网络攻击。**美国加利福尼亚州的一个网络安全团队发现，发动两次网络攻击的黑客来自同一组织。在2017年的网络攻击中，10204条个人数据遭泄露，数据主要来自议会的通讯录。

  

英国网络安全公司Glasswall副总裁认为，**黑客的目的可能是发动更深层的攻击。**黑客可以利用这些数据影响选举，也可以假冒政府内部人员。

  

英国安全部门尚未证实这一报道，不过《天空新闻》称，四个独立的安全部门相信调查结果是正确的。
