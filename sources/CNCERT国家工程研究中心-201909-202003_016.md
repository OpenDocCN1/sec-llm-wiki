习近平总书记强调要把生物安全纳入国家安全体系，全面提高生物安全治理能力。2020年以来，由新型冠状病毒肺炎引发的重大传染病疫情持续牵动着全国人民的心，而重大传染病的爆发流行是人类社会所面临的最重要和最现实的生物安全问题\[1\] 。本文对近20年来全球重大传染病疫情事件进行了回顾，针对典型事件的防控工作进行分析，并对我国的疫情防控工作进行总结和展望。

**一、近20年全球重大传染病疫情**

重大传染病疫情是生物安全研究中最受关注的问题，但关于重大传染病疫情并没有严格的定义，一般认为，在一定区域内，一定时间段内，发生一定数量的传染病，造成或者可能造成社会公众健康严重损害的传染病疫情即为重大传染病疫情\[2\]。本文基于上述定义，回顾了近20年全球发生的重大传染病疫情事件见表1。

2001年的炭疽疫情事件并不是单纯的传染病疫情，而是源于美国“炭疽邮件”的生物恐怖袭击。剩下的11次事件中，海地霍乱疫情和野生型脊髓灰质炎疫情是由复发传染病引起的，其余9次均由新发传染病引起\[15\]。相较于人类具有一定预防和治疗经验的复发传染病，新发传染病因其不确定性、突发性、人群无免疫力、传染性强以及传播速度快等特点而具有更大风险\[16\]，因此本文重点对新发传染病疫情进行讨论。

**二、防控工作分析**

根据疫情国的客观条件，这9次新发传染病疫情可以大致分为两类：第一类是疫情国本身医疗卫生力量有限的，如2014-2016年的西非埃博拉出血热疫情，2016年的巴西寨卡病毒疫情以及2018年至今的刚果（金）埃博拉出血热疫情；第二类是疫情国医疗卫生力量较发达的，如2003年的中国SRAS疫情，2009-2010年的美国H1N1猪流感疫情，2011年的德国肠出血性大肠杆菌感染疫情，2013年的中国H7N9禽流感疫情，2015年的韩国MERS疫情，2019年至今的中国新冠肺炎疫情。对于第一类疫情，疫情国本身的防控能力有限，疫情的控制很大程度上依赖于国际援助。而对于第二类疫情，疫情国的防控措施则较为关键。下面对第二类情况中疫情国的防控工作进行总结和分析。

**1. 中国SARS疫情**

2003年2月，突如其来的SARS疫情袭击了中国，疫情波及内地24个省（自治区、直辖市），累计报告确诊病例5327例，死亡349人。SRAS疫情还波及4大洲32个国家和地区，全球报告确诊病例8439例，死亡812人\[4\]。在该次疫情的防控过程中主要暴露出了以下问题\[4\]：

**( 1 ) 缺乏应急响应机制。**在SARS疫情初期，卫生部门缺乏应对疫情的经验和应急响应制度的指导，没有意识到这是一场突发公共卫生事件，也没有采取严格的控制措施对患者和疑似病例进行隔离，导致错过了疫情控制的黄金时期。

**( 2 ) 疫情信息的收集和发布渠道过于集中。**SARS疫情期间未实行传染病属地管理体制，疫情信息由卫生部进行统一管理，这导致了疫情信息的收集和发布效率较低，同时地方卫生部门上报的疫情信息存在不全面、不及时、不准确的问题，卫生部按地方上报数字汇总对外通报，与社会民众感受到的情况存在差距，增加了民众的疑虑。

**( 3 ) 未及时形成强有力的领导机制。**到2003年春，SARS疫情已在多个省份流行，但有些地方还没有建立统一的领导机构，没有形成社会民众广泛参与的防控大军，仅靠医疗卫生人员难以组织起强大的防控体系。

**( 4 ) 病毒基因研究能力较弱。**当时中国在生物领域的科研力量相对较弱，在3月31日对SARS病毒进行分离后认为其可能是一种新变异的衣原体。而实际上在3月25日，美国疾控中心和香港大学就已宣布SARS病原体属于一种“冠状病毒”，但没有引起北京研究者的重视，使得早期的治疗方案有所偏差。

**( 5 ) 缺乏有效的国际交流与合作。**在SARS疫情爆发之初，由于疫情信息收集存在滞后，中国与世卫组织和国际媒体的沟通交流不畅，与各国政府也未建立起有效的合作机制，使得中国在国际舆论中处于不利地位。

**SARS疫情对中国乃至世界都产生了巨大影响。**疫情过后，党中央、国务院做出了一系列重大决策，加强公共卫生体系建设和应急体系建设，2004年修订了《中华人民共和国传染病防治法》，2006年发布了《国家突发公共卫生事件应急预案》和《国家突发公共事件医疗卫生救援应急预案》，使中国应对突发传染病的能力明显增强。世卫组织也感到了修订《国际卫生条例》的紧迫性，并于2005年正式发布，其中引入了“国际关注的突发公共卫生事件”的机制。

**2. 美国H1N1猪流感疫情**

2009年3月美国爆发H1N1猪流感疫情，截至2009年11月底，世卫组织记录了62万个确诊病例和接近8000个死亡案例，随后考虑到成员国确认并调查所有病例所耗费的资源过于巨大，因此放弃了确认案例的计数。

美国的第一起病例发现于2009年3月25日，同年4月15日，美国疾控中心提取了H1N1病毒的基因组，4月18日报告给了世卫组织，4月23日美国疾控中心举行了新闻发布会，正式对外公布疫情\[17\]。4月25日，世界卫生组织宣布H1N1疫情成为“国际关注的突发公共卫生事件”，此次是世卫组织自2005年修改《国际卫生条例》后第一次向全球发布“国际关注的突发公共卫生事件”警告。4月26日，美国政府宣布全国范围内的公共卫生紧急情况，美国疾控中心开始释放25% 的战略储备物资，用于保护和治疗流感，向各州提供1100万剂抗病毒药物和个人防护设备，超过3900万套呼吸保护设备、长袍、手套和面罩，但其防控措施也仅限于此\[17\]。流感疫情迅速以无法阻挡的速度蔓延，第一例样本发现后一个月左右，感染人数就突破1万人\[18\]。此外，在疫情蔓延期间，美国政府甚至没有采取任何措施来阻止企业的囤积、投机和涨价行为\[19\]。

从早期预警的角度看，美国的反应是迅速且成功的\[20\]，美国针对重大传染病疫情的应急响应机制以及疫情信息的收集和发布机制是完善的。但美国在疫情攻坚阶段的防控能力、宣传能力和稳定市场能力明显不足，甚至弱于2003年SRAS疫情中的中国，最终导致了H1N1病毒在全美的大流行。2011年，美国疾控中心运用模型估计美国从2009年4月12日到2010年4月10日共发生了6080万例感染，27.4万例住院治疗，12469例死亡。目前，H1N1流感病毒已经成为美国每年季节性流感的一部分内容，每年带走大概3万美国人的生命\[18\]。

**3. 德国肠出血性大肠杆菌感染疫情**

2011年5-7月，德国爆发肠出血性大肠杆菌感染疫情，波及欧盟13个国家及美国、加拿大等地，报告确诊病例4400例，死亡50人。德国防控工作中存在的主要问题如下\[1\]：

**( 1 ) 缺少全国性的生物安全数据平台。**疫情初期，由于德国缺少致病菌基因图谱和标准检测方法数据库，未将真正的致病原大肠杆菌纳入常规化验范围，错过了早日发现致病原的宝贵时机。

**( 2 ) 信息发布机构太多但缺乏权威性。**本次疫情中，德国联邦机构、地方官员、科研专家等纷纷对媒体发布各种信息和见解。但这些信息缺乏疫情中央监控机制，经常出现反转的情况。比如汉堡官员宣布其在西班牙黄瓜上发现肠出血性大肠杆菌，但最终实验室检验证实，西班牙黄瓜虽然带菌，但并不是造成本次疫情的特殊菌株。各种不加管控的信息满天飞，增进了民众的不安，降低了政府的公信力。

**( 3 ) 病例汇总不及时。**与SRAS疫情期间的中国类似，德国当时也采取分级上报机制，各地确诊或疑似病例数通过地方卫生局、各州卫生主管当局后汇总至罗伯特·科赫研究所。这种分级上报的机制导致病例数汇总严重滞后。

**( 4 ) 病菌基因研究缺乏统一快速协调。**此次疫情中的病菌基因是由中国的华大基因集团率先检测出的。作为德国本土研究机构的明斯特大学医院卫生研究所公布基因测序结果比中方还晚了半天，这说明德国在病菌基因研究上缺乏统一快速协调，缺乏有效的合作机制。

**( 5 ) 缺乏对医疗资源的统筹管理。**德国并没有全国性的机构来统筹和协调医疗资源，使得重病区的床位、血浆供应等临床资源的供应紧张得不到缓解，也导致一些地方医院总结的有效治疗经验没有迅速扩散。

此次疫情的致病原具有较强的耐药性，加之德国初期的应急管理较为混乱，使得疫情颇为严重。

**4. 中国H7N9禽流感疫情**

2013年3月31日，在中国上海出现了全球首次人感染H7N9禽流感病例。同年4月3日，上海市即召开H7N9禽流感疫情防控工作新闻发布会，宣布即日起启动流感流行应急预案III级响应，按照要求，确定上海市公共卫生临床中心为市级定点医疗机构；将发热门诊不明原因肺炎（即疑似病例）主动搜索频率改为“每日报告”；关闭上海活禽市场，加强市场检查，保障市场供应稳定；加强对餐饮服务单位采购、经营禽类产品的监管力度\[21\]。截至2014年12月31日，中国共报告确诊病例349例，死亡136人\[8\]。

相比于SRAS疫情，中国在此次疫情中的表现有显著提高。在发现新型人感染H7N9禽流感病毒后，迅速对外披露疫情，分享了有关基因序列和病毒等关键信息，并启动应急响应预案，在病例统计方面进行属地负责制管理，采取“每日报告”机制，对内对外发布信息都高度透明。此外，中国加强了与世卫组织的合作，在19日至23日，中国--世卫组织人感染H7N9禽流感联合考察组对人感染H7N9禽流感形势展开评估。世卫组织卫生安全和环境事务时任助理总干事福田敬二表示，中国的H7N9禽流感疫情应对堪称典范\[22\]。

此次疫情能够得到有效控制，一方面与中国自SRAS疫情后大力建设公共卫生体系和应急体系有关，另一方面也与H7N9禽流感病毒本身传染性较低有关。但中国在应对传染性较强的重大传染病疫情时的防控工作仍有很多需要改进的地方，这将在第6节“中国新冠肺炎（COVID-19）疫情”中进行分析。

**5. 韩国MERS疫情**

2015年5月20日韩国暴发 MERS 疫情\[23\]，截至同年7月28日韩国总理宣布疫情结束时，共确诊186例，死亡36人\[24\]。MERS病毒本身的传染性较低，发生二次感染的可能性较小\[25\]，但在此次疫情中，有153名感染者是被5名“超级感染者”传染患病的，其中1位“超级感染者”甚至导致了85人感染\[26\]。而且原本应该消灭病毒的医院却成为这次病毒传播的温床，感染初期的确诊患者全部发生在6家医疗机构内。以上这些现象暴露出韩国的防控措施存在一定问题\[27, 28\]：

**首先是早期预警不力。**在发现首例确诊患者后，韩国保健当局一再表示这种疾病“传染性不强”，此后又多次强调发生第二代人传人“可能性不大”。正是由于重视不够，政府的初期防控措施过于薄弱。例如，首名确诊患者的一名密切接触者，竟能脱离韩方监管前往中国，引发了国际社会对韩国疫情扩散的忧虑。**其次是应对措施滞后。**在同年5月下旬首位患者确诊后，韩国政府首先仅以保健福祉部旗下中央对策本部的名义开展防治工作，直到6月1日，总统朴槿惠才就MERS疫情首次表态，3日才下令尽快成立MERS防治应对领导小组。而本应当行使重大安全预警职能的国民安全处，直到疫情发生后的17天，才向国民发送预防MERS预警短信。**最后是政府公开信息渠道不畅。**韩国政府曾一再表示，为了不引发社会公众的恐慌，坚持不公开相关医院和患者信息的原则。但这反而引发社会及公众的更大恐慌，亦使得流行病学调查和隔离预防体系频频出现漏洞。直至新任韩国国务总理黄教安成立抗击MERS疫情专门工作组后，才于6月5日起对外公示具体的感染数据、感染源及感染医院等信息。韩国国会也于6月25日快速通过了《传染病预防及管理法》修正案（《MERS特别法案》），赋予了防疫部门更多信息收集、发布和协调指挥权\[29\]，初步弥补了疫情信息管理方面的不足。

此次疫情属于新发传染病疫情，但其实它的致病原MERS病毒早于2012年就被发现了，各国的医疗机构已经对该病毒的病毒学特征、临床特征以及流行病学特征有了大量研究。但正是这些信息导致韩国在应对疫情的初期过于大意，使得本能够被快速控制的病毒传播发展为了重大传染病疫情。此外，**韩国在疫情信息的发布机制上的漏洞也是疫情防控不利的重要因素。**

**6. 中国新冠肺炎（COVID-19）疫情**

2019年12月新冠肺炎疫情在武汉爆发，至今仍在中华大地上肆虐。截至发稿日，中国累计确诊新冠肺炎79968例，死亡2873人。

疫情的爆发有一定客观因素：此次的致病原是一种全新的冠状病毒，科学界对它的病毒学特征、临床表现以及流行病学特征一无所知，而后来的研究也证实，该病毒的传染性明显强过SARS和MERS\[25\]。此外，爆发期间正值春运，这些都有利于新冠病毒的扩散。不过防控难度虽大，但自2003年SRAS爆发到今天已经17年了，在这17年间中国的公共卫生体系和应急体系有了长足的发展和进步，而这次的新冠肺炎疫情却仍令中国各界都措手不及且损失巨大，因此需要对防控工作进行深刻的反思。

为深入分析，笔者梳理了自2019年12月26日张继先医生上报4名不明原因肺炎病例起至2月23日中国政府及各界进行的防控工作\[30-33\]，并对各类工作按照其性质进行了大致分类（疫情上报、官方通报、对外合作、科研进展、防控措施、关键措施和负面事件），如图1所示。根据图1所呈现的情况，笔者将时间轴分为三段：2019年12月26日-2020年1月4日（第一阶段）；2020年1月5日-2020年1月19日（第二阶段）；2020年1月20日至今（第三阶段）。

在第一阶段，从上报速度看，自2019年12月26日医院发现不明肺炎病例，到上报至国家卫健委和国家疾控中心只用了3天（29日）；从公布速度看，国家卫健委接到报告后2天（31日）即对社会进行了通报并通知了世卫组织；从防控措施看，发现病例后3天（29日）即开始实行隔离治疗，向社会公布后1天（2020年1月1日）即封闭了华南海鲜市场，随后在3日和5日又对社会发布了疫情通报，并于5日启动二级应急响应。这三个速度都远快于SRAS时期，甚至也明显快于H1N1期间的美国，因此可以说第一阶段中国对疫情的反应是迅速且有效的。

“封城”（1月23日）、多地启动重大公共卫生事件一级响应（1月23日、24日）、筹建火神山医院和雷神山医院（1月23日、25日）、延长春节假期（1月26日）、全国范围内的社区出入限制（1月29日）、建立“方舱医院”（2月4日）等。上述防控措施的力度之大在全球传染病疫情史上都是空前的\[34\]，虽然形势依然严峻\[35\]，但在强有力的防控工作下，疫情正在得到逐步遏制。

而与上述两个阶段形成鲜明对比的是第二阶段的防控工作。从图1中可以看出，第一阶段和第三阶段的防控工作在横向上都很饱满，但第二阶段的防控工作却乏善可陈，除了1月15日在武汉机场、火车站、汽车站、客运站设置红外测温仪之外，几乎没有实质性的防控措施。此外，图1中采用红色框来标记有一定负面作用的事件。总共三处：一是1月1日，武汉市公安局对所谓的8名“散布谣言”的医生进行依法查处，而之后的事实证明，8名医生发布的内容并非完全捏造，如果社会公众当时听信了这个“谣言”，并采取了佩戴口罩、严格消毒、避免再去野生动物市场等措施，这对更好地防控新冠肺炎，可能是一件幸事\[36\]。二是1月15日武汉卫健委发布的疫情知识问答中表示存在“有限人传人”的可能，但“持续人传人”的风险较低。虽然从科学的角度出发，问答中的说法符合当时的认知，但偏学术的词汇，以及对二次感染的低估并不利于提高公众的防控意识。三是1月18日在武汉市江岸区百步亭举行“万人宴”，这次“万人宴”在舆论发酵后更是为全民所诟病，而事实也证明，“万人宴”对武汉的防疫工作起到了负面的作用，在“万人宴”举办10余天后，该社区辖内安居苑共55栋楼，其中33栋出现发热病人，百合苑共36栋楼里，其中17栋出现发热病人，其他小区也有疑似、确诊病例\[37\]。

此次疫情防控工作确实存在一些不足，但也要肯定第一阶段和第三阶段中的迅速响应和果断施策。还需要指出的是，在此次疫情防控工作有三个鲜明的特色：

**一是党中央强有力的集中领导和统筹部署。**在习近平总书记的坚强领导下，此次防疫工作中，中国特色社会主义制度的优越性得到了充分体现，武汉“封城”及其背后的物资供应、火神山医院和雷神山医院的急速建成、全国医疗队伍迅速但有条不紊的驰援、各地基层党员响应号召对疫情的严防死守等等，所有这些放在世界任何一个国家都不可能比中国做的更好。

**二是中西医结合治疗。**中医医疗方案和中药在这次疫情中起到了积极作用。中央应对新冠肺炎疫情工作领导小组\[38\]，国家卫健委\[39\]、中纪委\[40\]等中央部委，钟南山、张伯礼、黄璐琦、仝小林等院士\[41\]，都在强调并强化中西医结合，促进中医药深度介入诊疗全过程，及时推广有效方药和中成药。中医药和西医药可以优势互补、相互促进，共同维护和增进民众健康，这是中国特色医药卫生和健康事业的重要特征和优势\[42\]。

**三是大数据技术支撑防疫工作。**现今大数据技术的应用是17年前SRAS疫情期间所不能比拟的。在此次疫情中，通过手机基站、导航卫星和数字地图大数据较为准确的定位了用户位置，用于回溯人口流向和预测疫情走势；通过卫健委、交通、工信部门的联合大数据查找确诊病例的密切接触者，提高了隔离效率；通过电信大数据为个人用户提供行程查询服务，用于个人自证无疫区行程；通过医疗大数据进行智能诊断和分析，提高了患者确诊、疫苗研发、新药研发和老药筛选的效率；通过资源管理大数据，汇总物资的入库、调度、审批、库存、日常消耗需求，提高了应急物资的配置调度效率；通过电力大数据，分析区域用电情况，从宏观层面掌握了复工趋势；通过大数据可视化，清晰的展示出疫情相关态势，为国家决策部署和信息高效发布提供了助力。习总书记指出，要运用大数据等手段加强疫情的溯源和监测，这是对大数据技术在防疫工作中发挥作用的肯定\[43\]。

**三、总结和展望**

传染病与人类之间的战争自人类诞生之日就已经开始，在可预见的未来也会一直持续下去。对抗传染病疫情的防控工作需要随着社会、科技的发展以及致病原的变化而不断适应和完善。本文基于上述分析，对中国的传染病疫情防控工作进行总结和展望：

**( 1 ) 完善重大疫情防控体制机制，健全国家公共卫生应急管理体系。**习近平总书记强调，确保人民群众生命安全和身体健康，是我们党治国理政的一项重大任务。既要立足当前，科学精准打赢疫情防控阻击战，更要放眼长远，总结经验、吸取教训，针对这次疫情暴露出来的短板和不足，完善重大疫情防控体制机制，健全国家公共卫生应急管理体系。

**( 2 ) 细化相关法律法规及规章制度，将生物安全纳入国家安全体系。**通过推动《生物安全法》立法，细化《传染病防治法》、《国家突发公共卫生事件应急预案》等法律法规及规章制度，规范疫情上报和信息发布的时间、流程及内容，更具体的指导疫情防控各个环节的工作。

**( 3 ) 加大医疗技术研究投入，规范医疗评价体系。**医疗技术是对抗疫情的利刃，一方面要加大研究投入，为疫苗、药物的研发和医疗队伍的建设提供资金保障，另一方面要建立科学的医疗评价体系，优化评价指标，营造高效良好的创新环境。

**( 4 ) 加强互联网信息治理能力，科学处理“虚假信息”。**一方面要严厉打击恶意谣言，另一方面也要对“虚假信息”发布者、传播者主观上并无恶意，行为客观上并未造成严重危害的保持宽容态度\[36\]。

**( 5 ) 利用大数据技术提升传染病疫情预警能力，防患于未然。**大数据技术在疫情爆发后为防控工作提供了强大的支撑，但它的另一项重要能力--预警能力却没有在此次疫情中显现。与之形成对比的是，谷歌公司利用美国2003年-2008年的数据建立模型，提前几周预测了2009年美国H1N1猪流感的爆发\[43\]。因此，我国也需要加强大数据技术在疫情预警方面的能力。

**( 6 ) 加快推进个人信息保护的立法和规范。**大数据技术在助力防疫工作的同时，也带来了个人信息泄露的隐患，推进个人信息保护立法，规范个人信息的采集、保存、传输和处理，是进行“依法防疫”的重要依据。

**( 7 ) 进一步加强野生动物保护。**此次疫情的爆发源自华南海鲜市场的野生动物，1月26日国家也发布了疫情期间禁止贩卖野生动物的通告，但疫情结束后也要从生物安全的角度出发，采取措施严格管控野生动物的贩卖和滥食，减少来自动物的病原威胁。

**( 8 ) 加强地方政府应急响应演练，提高社会治理能力。**地方政府应时刻保持警惕，把人民群众生命安全和身体健康放在第一位，通过应急响应演练提高应对突发公共卫生事件的能力和社会治理能力，避免发生“万人宴”变“鸿门宴”的类似事件。

当前疫情形势依然严峻复杂，防控正处在最吃劲的关键阶段，但在以习近平总书记为核心的党中央的坚强领导下，疫情防控形势积极向好的态势正在拓展。中华民族历史上经历过很多磨难，但从来没有被压垮过，而是愈挫愈勇，不断在磨难中成长、从磨难中奋起。相信我们一定能取得“战疫”的最终胜利！
