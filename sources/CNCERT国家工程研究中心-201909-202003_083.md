# 兰德报告：美国防部可参考这两种方法阻止电网攻击

增强弹性和可靠性，以拒止的方式阻止攻击；以开展报复性措施作为威胁，以施加成本的方式阻止攻击。

当前，美国国防部对能源，尤其是电力的依赖越来越大，确保部队和设施能够获得可靠的电力供应对于保证任务成功至关重要。然而，美国军事设施消耗的大部分电力来自商业电网，该系统很大程度上不受国防部控制，且越来越容易受到自然灾害和蓄意攻击，包括网络攻击。

![](../Images/ead4e2ecffee92ea4aaa77b68056fced.png)

为此，2020年1月6日，美国智库兰德公司发表题为《阻止电网攻击：供美国国防部参考的两种方法》的报告，探索了可供美国国防部参考的、阻止电网攻击的两种方法：

①增强弹性和可靠性，以拒止的方式阻止攻击；

②以开展报复性措施作为威胁，以施加成本的方式阻止攻击。该报告是为支持国防部在该领域的决策而研发相关框架的第一步。

**报告着重于分析两种用于阻止蓄意攻击电网的策略：拒止和提高成本。报告评估了提高国防部对电力中断的防御能力的选项，以及阻止对电网网络攻击的惩罚性措施。**

**报告主要发现包括：**

( 1 ) 就通过拒止进行威慑而言，报告重点关注外部干预措施，即国防部可以如何与不属于国防部的实体或基础设施进行互动。案例研究表明，外部干预措施是对内部干预措施的补充，而无法替代现有的内部干预措施，而弹性和可靠性干预可以增强国防部的能力，不仅可以阻止军事对手的攻击，还可以在潜在隐患环境中维持作战能力，例如自然灾害和基础设施老化。

( 2 ) 就通过施加成本的威胁来进行威慑而言，报告审查了有关战争法的国际协定的适用性。对于针对民用电网的网络攻击，攻击的严重程度和归因强度揭示了几种回应与报复的选择，如：民族国家对电网发起的网络入侵可能会受到法律的惩治，达到武装袭击水平的攻击可能需要军事回应。

( 3 ) 威慑的挑战主要源于网络空间的模糊性。这种模糊性可从两个方面理解：网络攻击归因的模糊性和网络攻击严重程度的模糊性。严重程度的模糊性导致的问题似乎并不明显，但对“网络空间中武器的使用”这一问题界定不够清楚，很可能会导致冲突升级。
