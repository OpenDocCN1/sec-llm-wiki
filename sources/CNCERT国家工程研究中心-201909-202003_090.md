# 国际工业互联网技术前瞻：智能电网创新安全平台---OSGP

**按：****全球范围内，传统电网的建设已经到达顶峰，智能电网将带来高效和环保。****但在实施智能电网的过程中，一个突出的痛点是如何把众多而繁杂的生产设备，管理平台，传感设备，数据分析平台等等集成在一个网络中，并且保证其安全性。**

![](../Images/135b9ae12b13ea229dd75e1ec9bbde54.png)

委内瑞拉大停电、乌克兰电网事件这些耳熟能详的国际网络安全事件对我国的电力行业网络安全建设影响深远。中国的电力企业在网络安全上的投入远远超过其他关键信息基础行业企业。同样，国外电力行业对网络安全的重视不亚于国内。LE Enegy公司提出一个全新的网络安全架构，针对物联网行业，特别是电力行业，并将与荷兰电力公司开展一个创新的项目。网安知讯介绍此创新理念，希望对我国的物联网安全，特别是智能电网安全有所借鉴。

**智能电网(Smart Power Grids)**

也被称为“电网2.0”，它是建立在集成的、高速双向通信网络的基础上，通过先进的传感和测量技术、先进的设备技术、先进的控制方法以及先进的决策支持系统技术的应用，实现电网的可靠、安全、经济、高效、环境友好和使用安全的目标。

**智能电网解决方案有三个体系：**

1\. 传感器连接体系，打通资产和设备实现数字化运营

2\. 数据的整合体系和收集体系

3\. 数据分析体系，优化运行和管理。

![](../Images/4fd2525072965aa0c299c660e4c63beb.png)

**全球范围内，传统电网的建设已经到达顶峰，智能电网将带来高效和环保。但在实施智能电网的过程中，一个突出的痛点是如何把众多而繁杂的生产设备，管理平台，传感设备，数据分析平台等等集成在一个网络中，并且保证其安全性。**

LF Enegy 公司在这方面给我们一个非常前瞻的启示，其倡导的开放式智能电网平台---OSGP, 是一个开放，通用，可扩展且独立的“物联网”平台，该平台使公共空间中的各种连接的智能对象易于控制和监控。平台允许使用任何（网络）应用程序以及任何IP通信基础设施。

OSGP倡导者的目的是促进智能和可持续解决方案的发展。智能设备和智能应用程序在智能电网和智能社会的发展中起着核心作用。开放式智能电网平台软件使您可以连接到数千个设备，对其进行控制并监视其性能。而这些连接是以一种开放和安全的方式完成的，可以应用于专属的应用程序和设备

目前OSGP联盟成员目前已经包括，法国电力，荷兰电力，IBM，Cloudbees, Elering, OSIsoft, Recurve,R9B Windriver, Unicorn等公司。

![](../Images/cef94e1489e810a9a90fc704eb2f29de.png)

OSGP是一个可扩展且与技术无关的工业物联网（IIoT）平台。它使网格运营商能够安全地收集数据以及监视，控制和管理网格上的智能设备。

*   用户或操作员使用一个Web应用程序监视和/或控制设备。
    
*   应用程序通过Web服务连接到OSGP。分为不同功能领域，例如公共照明，智能电表和电能质量。第三方开发人员可以使用Web服务来开发或集成新的应用程序。
    
*   PSGP平台可以安全地处理所有这些应用程序请求，并使用各种功能和服务来做到这一点。为了将“用户/操作员”命令“翻译”并传达到各种智能设备，该平台使用开放协议。  
    
*   该平台支持各种基于IP的数据电信技术和协议来与设备进行通信。  
    

电网运营商将IIoT设备添加到其电网中，每个设备都需要非常不同的工具和过程来确保互操作性。OSGP的目的是通过创建抽象数据访问的单一通用方法来降低访问这些设备的总体复杂性和相关的维护成本。简而言之，这是将系统集成到电网的一种方式。 ![](../Images/176b1fd1c3b8a55a4adfc3f0a38bf18c.png)

OSGP 的安全设计非常独特，包括：

*   TLS通讯
    
*   IPSec虚拟专用网
    
*   所有服务器和层之间的防火墙
    
*   来自公认的证书颁发机构（CA）的证书
    
*   审核整个平台上所有操作的跟踪
    
*   基于角色的访问控制（RBAC） 
    

**OSGP 的4层架构**

### OSGP是应用程序和硬件之间的转换层。开放式智能电网平台具有四个不同的层。

### 每层都有自己的功能，可以根据特定需要进行调整。为了优化层之间的安全性，设计了安全层。

![](../Images/279c9bf95e9e6519172041059aa42216.png)

![](../Images/dd3e2b07882f5b6ac8d1257c68f5f8a4.png)

### **1.应用集成层**

在这一层中，Web服务向外界公开。应用程序可以连接到应用程序集成层，并使用Open Smart Grid Platform所需的功能。应用程序集成层分为功能域。当需要其他功能域时，将添加它。

这种分离为每个功能域提供了授权。每个Web服务组件都将队列消息发送到相应的域组件。

为每个功能域实现一个单独的Web服务。所有soap操作都有一个request对象参数，并返回对该对象的响应。对于同步的Web服务，结果将立即包含在响应中。

对于异步Web服务，响应包含相关ID。请求者将使用此相关ID从平台接收实际结果。

### **2.域**

通过域驱动设计（ddd），创建了用于特定功能域的模型。

在域逻辑块中，可以找到功能域的业务逻辑。在这里，功能命名命令的翻译将被翻译成通用的中间格式。

域可以重用核心内的所有功能和协议。该平台是无状态的（该平台使用队列来处理消息），并且可以轻松扩展至大容量，或在需要时进行缩减

### **3\. 核心**

Open Smart Grid Platform核心组件从域组件接收队列消息。来自域组件的这些消息将转发到协议适配器。Open Smart Grid Platform核心组件还为协议适配器提供了逻辑，以将智能设备的响应发送回域项目。

对于每个功能域，使用单独的域组件来实现业务逻辑。诸如授权之类的通用功能应抽象到共享组件。域组件从Web服务组件接收队列消息，并将队列消息发送到The Open Smart Grid Platform核心组件。

在开放式智能电网平台的核心中，可以找到以下通用功能：

*   设备管理
    
*   固件管理
    
*   时间同步
    
*   工作流程引擎
    
*   设备安装服务
    
*   排程器
    
*   设备状态监控
    
*   将设备命令路由到适当的设备协议
    

**4\. 协议**

在此层中找到了不同的协议适配器。此处，用于特定设备的命令的通用中间格式将转换为设备可理解的协议消息。此消息将发送到设备。对于通信失败，存在重试机制。设备实现的消息侦听器在此处实现。

已经支持和将支持的协议包括：

*   OSLP
    
*   DLMS 
    
*   IEC61850
    
*   OpenADR
    
*   IEC 60870-5-104
    
*   OPC UA / IEC 62541
    
*   Modbus TCP
