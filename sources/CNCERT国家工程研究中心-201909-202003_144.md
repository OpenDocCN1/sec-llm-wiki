# 关键基础设施保护对我们有多重要？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247491178&idx=2&sn=da73c6aa4fc9f55961087e1eaddad13d&chksm=fa90a8abcde721bdc81e283ce927cea9cb5aa0b554a0d647e503dc503dc2d4dd163f6f14cb68&scene=126&sessionid=1681365474#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247491178&idx=2&sn=da73c6aa4fc9f55961087e1eaddad13d&chksm=fa90a8abcde721bdc81e283ce927cea9cb5aa0b554a0d647e503dc503dc2d4dd163f6f14cb68&scene=126&sessionid=1681365474#rd)

![](../Images/5e20e51fb9ff010d688093ff89fab043.png)随着2019年12月31日最后一刻的钟声敲响，意味着我们步入了21世纪第三个十年，对于普通人来说，只是年纪又大了一岁，但往整个世界看去，似乎我们迎来的是一个波诡云谲的年代。1月3日，随着“没谱”总统一声令下，远在中东伊拉克的伊朗将军苏莱曼尼被迫离开人世。霎时，中东风云突变，伊朗和美国剑拔弩张，导弹发射，战机升空，似乎随时准备干一场大的。只是，雷声大雨点小，到最后两边都软化了立场，终究不敢承受发生大规模战争的巨大损失。  
想象一下，随着互联网技术的发展，假如美伊战争开打，除了常规热战以外，我们可能会看到人类迄今为止最大规模的网络战，伊朗的各类军事设施、工业设施等关键基础设施都不可能幸免于难，而网络化程度更高的美国，也不会安然无恙。关键基础设施对一个国家是那么重要，以至于国家不得不想尽办法制定各种法律、条例来进行保护，而随着各种网络新技术的发展和融合到各行各业，我们不得不正视其带来的网络威胁。

**1**

**关键基础设施的威胁背景**关键基础设施是指对一个国家至关重要的物理的或虚拟的系统和资产，其中包含能源、电力、供水、交通、信息网络、公共卫生服务系统、国家应急处理系统等，这些系统和资产的功能丧失或遭受破坏，会给国家安全、经济稳定以及公众健康与安全带来严重的影响。近年来，随着“两化”(信息化与工业化)的相互渗透与融合，智能化的控制产品被广泛应用于关键基础设施领域，控制系统设备正逐渐从专有标准向通用的标准、通信协议以及软硬件转化，并通过各种形式和企业管理网、因特网等“公共网络”相连，将原本相对封闭的系统相互联系在一起，在实现智能控制的同时也增加了其脆弱性，并引入了诸如木马、病毒、网络攻击等网络安全问题；相关控制系统存在的漏洞被发现并公布，攻击技术的不断加强。这些都使得关键基础设施系统面临着严重的信息安全威胁。2007年，“Aurora”演习中针对电力控制系统其中一台发电机的控制系统发动信息攻击导致其自毁；2010年，“震网”(Stuxnet)蠕虫病毒侵入伊朗布什尔核电站，将核电站近五分之一的离心机物理破坏，核电站的建设计划毁于一旦；2011年，代号为“夜龙”(NightDragon)的网络攻击以石油、能源、天然气公司为攻击目标，窃取有竞争力的自营业务和项目融资等敏感信息。

**2**

**关键基础设施特征及信息安全特点****1、关键基础设施特征**关键基础设施包括能源、供水、交通、电信、紧急服务等关系国计民生的系统和资产，其分布范围广泛，设计的初衷是为社会向提供特定的服务。如图1所示，将基础设施抽象成为一个包含有节点和边的网络图，多个基础设施之间不仅在物理结构上，而且在信息层上相互依赖。![](../Images/3d114f41dd285d4fedeeced38563f116.png)图1  相互依赖的关键基础设施群随着信息技术的高速发展，关键基础设施越来越依赖于IT信息系统以加快各层信息之间的交互并降低运营成本，同时也使关键基础设施领域面临着严重的安全威胁(如木马、蠕虫、网络攻击等)，影响其社会服务的交付。由于关键基础设施之间的相互依赖，特定服务的中断会传播到与其关联的节点产生级联效应，甚至一个“正常”服务的扰动都会对相互依赖的系统造成重大的影响。**2、关键基础设施信息安全特点**根据美国第21号总统令的定义，关键基础设施信息安全是指通过物理手段或信息防御措施来降低入侵、攻击、自然或人为灾难的影响对关键基础设施的风险。信息安全的目标是保证信息的保密性、完整性和可用性。传统的IT系统关注的最大的风险是信息泄露，故其将保密性放在首位，优先保证，完整性次之，可用性最后。关键基础设施系统属于信息物理融合系统，首先考虑的是所有部件的可用性，其直接关系到社会服务的提供，完整性次之，保密性最后。关键基础设施控制系统是为实现特定的功能而选取的，导致其资源有限，且为了不影响特定控制功能的实现以及对现场的实时控制与响应，信息加密处理简单且相关防病毒软件未能安装或及时更新补丁。关键基础设施系统攻击目标多样且来源复杂，攻击不仅针对系统本身，而且能窃取与系统相关的机密信息，而一旦遭受攻击可能直接导致现实世界中的危害，造成关键基础设施的异常运行或瘫痪，并影响相互关联的系统发生级联效应，给社会带来灾难性影响。从弹性和风险的角度来看，关键基础设施内部组件以各种方式相互连接、相互依赖，使得很难充分了解失效的潜在影响。即使我们了解关键基础设施在某个时间点上的相互依赖关系，关键基础设施的有机增长和演化可能导致不可预见的和微妙的依赖关系，会引入新的单点失效和造成其他系统性风险。

**3**

****关基设施信息安全防护框架及验证平台******1、关键基础设施信息安全框架**应联邦政府要求，NIST于2014年2月12日发布了第一版《提升关键基础设施信息安全框架》。框架采用基于风险的方法将信息安全风险纳入组织风险管理流程来进行信息安全风险管理。框架聚焦于业务需求，依靠一系列存在的标准、指南、实践来帮助关键基础设施供应商实现恢复力。框架共分为三个部分：一是框架核心；二是框架实施层；三是框架剖面。框架核心包括一系列信息安全活动、期望达到的效果以及适用于各类关键基础设施部门的应用参考。核心由识别、防护、检测、响应、恢复5个可以并行和连续的功能组成，明确定义了各步骤所需技术的类别、子类别和参考资料，从信息安全管理的全生命周期为组织提供了安全标准、指南和实践的方式，帮助其了解和调整安全项目，为个人组织剖面的建立提供了具体指导。框架实施层提供了一个组织如何看待信息安全风险以及管理对应风险的流程的环境，并按照信息安全风险管理实践表现出的特征分为从部分实施到自适应依次递增的四个等级，而其中每个实施层由以下三个要素决定：(1)风险管理方法；(2)整个组织安全程序集成的级别；(3)与第三方的合作以应对共享的安全风险。框架剖面提供一种机制用来创建反映安全风险管理全局状态的“剖面”，这其中包括安全活动与业务需求、风险容忍和资源的一致性。框架表达一个组织通过识别已经实施或计划实施子类如何管理在每个框架核心功能和分类的安全风险，可以被认为是框架核心中的安全标准、指南以及实践在针对某个场景的一个具体应用。组织可以通过创建一个反映已有的网络安全实践的“当前”剖面，一个反映在未来实践中期望状态的“目标”剖面，对比二者，根据现场的反馈不断更新调整安全活动以满足业务需求、风险容忍和资源的需求，改善网络安全态势。**2、关键基础设施信息安全测试平台**针对信息安全攻击的破坏性及不可控性，直接在真实的环境下进行信息安全分析实验可能会对系统造成难以想象的破坏，进而给国家造成严重的影响。因此针对关键基础设施信息安全相关研究、开发、测试等需在测试平台上开展，以验证其有效性。美国能源部NSTB(National SCADA Test Bed)计划中爱达荷国家实验室建设的关键基础设施测试靶场(CITR)就是一个专门用于控制系统网际安全评估、标准改进、推广和培训的大规模测试床；美国Sandia国家实验室搭建的VCSE(Virtual Control Systems Environment)测试平台，用于模拟电网系统信息安全攻击场景，分析信息攻击对电网系统造成的影响，验证相关策略对电网控制系统的稳定性提升的效果；美国Iowa州立大学搭建的PowerCyber Security测试床，用于进行智能电网系统脆弱性分析、信息物理影响评估以及信息安全攻防演练；Queiroz等人提出一种全软件仿真的SCADA测试平台，以供水SCADA系统为对象，针对分布式拒绝服务攻击场景进行了研究。为方便关键基础设施信息安全相关研究工作的开展，拟搭建关键基础设施信息安全防护测试与验证平台。本平台以天然气管道输送系统为背景，采用半实物仿真方案(其中控制网络采用实物仿真与软件虚拟仿真相结合的方式实现，而底层物理对象则在PC机中仿真实现)，模拟天然气输送系统整体的运行机制和各层次的功能。本平台拟从识别、防护、检测、响应以及恢复这几个方面入手进行开展如下工作：分析关键基础设施不同层次中信息流的流动与交互规则；对关键基础设施进行脆弱性分析；针对其存在的脆弱性评估不同类型的信息攻击造成的影响；分析关键基础设施、系统内部的关联性；验证相关防护措施能否阻止信息攻击导致的级联崩溃以及提高关键基础设施的安全性能。

**4**

**总结**现代社会越来依赖于关键基础设施有效运作以提供必需的社会服务，如能源、供水、应急服务等，这些服务交付的中断或扰动会给国家经济安全和国民健康安全带来严重的威胁。随着信息化技术在关键基础设施领域的大规模应用，实现智能控制、信息交互便利、产生了巨大的经济效益，但也让关键基础设施系统暴露在攻击者面前，使其面临着前所未有的信息安全威胁。近年来，我国加大了对网络信息安全的重视程度，2014年成立了以习总书记为组长的网络安全与信息化领导小组，但总体上来说在保护关键基础设施信息安全方面的工作开展的相对较晚，而且大部分关键基础设施系统在建立初期并未着重考虑信息安全问题，致使其存在严重的安全隐患。为此应该向欧美等在关键基础设施信息安全保护领域处于领先水平的国家学习，加大对关键基础设施保护的投入与研究，在国家层面上制定相关顶层设计以及出台战略性政策文件，从以下几个方面入手：首先要尽早确定关键基础设施的含义；其次，要建立与完善关键基础设施安全信息共享与部门协作机制；最后加强对关键基础设施的风险评估和分析。最终指导我国关键基础设施安全保护工作高效有序进行，确保其能持续不断地为社会提供稳定的服务。
