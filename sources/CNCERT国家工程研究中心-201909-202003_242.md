# 新泽西州最大的医院系统遭到勒索软件攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247490881&idx=3&sn=ac6d6c9a3b8edd8208ff3e93eeb48738&chksm=fa90ab80cde722961bbf3f0b77b7099c6aaa0ae932f7a3720c1cd12bb1867c3f02fbaae2b000&scene=126&sessionid=1681365492#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247490881&idx=3&sn=ac6d6c9a3b8edd8208ff3e93eeb48738&chksm=fa90ab80cde722961bbf3f0b77b7099c6aaa0ae932f7a3720c1cd12bb1867c3f02fbaae2b000&scene=126&sessionid=1681365492#rd)

近日，新泽西州最大的医院Hackensack Meridian Health宣布，**勒索软件攻击中断了其网络，IT人员决定通过支付勒索金来解密文件。**Hackensack Meridian经营着17家急性病护理和专科医院，以及精神病机构载体诊所、疗养院和门诊中心。其医院包括位于哈肯萨克的哈肯萨克大学医学中心、位于海王星的泽西海岸大学医学中心和位于爱迪生的肯尼迪医学中心。

![](../Images/fe914ff9f74635b2710d06df1019ba58.png)

此次袭击迫使该医院重新安排了非紧急手术的时间，医生和护士在没有电子记录的情况下提供护理。该公司表示，没有迹象表明任何患者信息会受到未经授权的访问或泄露。其网络的主要临床系统已经恢复运行，信息技术专家正在努力使其所有应用程序恢复在线。

![](../Images/e35dc2268647cb93da6323801b35b2bc.png)

事发后，该医院已迅速通知了联邦调查局和其他当局，并与网络安全和法医专家进行了交谈。目前，还不了解具体的勒索软件详细信息，以及关攻击者破坏医院网络的方式。该医院也没有透露所支付的勒索金的具体金额，但表示拥有此类紧急情况的保险。
