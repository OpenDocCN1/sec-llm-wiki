# 数据安全与企业内控

大数据时代，数据是最重要的。从个人角度来看，衣食住行都会产生数据，包含着最基本的个人信息以及历史消费记录等等。如果被盗，就会造成财产损失甚至更严重的后果；从企业来看，数据是市场竞争的关键部分，而保护用户的数据安全是最基本的责任，事关企业发展与信誉等等。因此，无论从哪个角度来看，做好数据安全防护都是必须要做的事。过去，当企业单位在提到做安全建设时，几乎毫无例外的认为安全是成本，不愿意做。尤其是在发展初期，活下来才是最重要的。至于活的好不好，没有精力也没有资源管。所以在产品、业务发展成熟时，安全问题已经无法填补。![](../Images/4eefc472456e1d95e3c09e33cfcc1ab5.png)![](../Images/88436ec9a167b937bdcdd8ad988ec469.png)![](../Images/aaab54e4a459a79c93621140d4e36a5a.png)![](../Images/916c53c9e19dc5a44a6bb7ffba6c135b.png)![](../Images/8cda155fd0167a61dea3d3f65c0c8de5.png)![](../Images/27af482b2d83cd123ed5017368912135.png)![](../Images/da44c0a87f9a6f01eb369e4882ab7f73.png)![](../Images/d130574116d75151ca9f2e6033d4dc1a.png)![](../Images/30b7f7e97f3fbf3e00e86e85e25c9a67.png)![](../Images/d6a6aebf7209b4a599db6d386abfd882.png)![](../Images/ef89609fc6e3e78cc72fd87878be2846.png)![](../Images/2a54cf4d1f683f53e55a5999d1183fb6.png)![](../Images/a4225c07359cd7e8afd08d8e6bf54f85.png)![](../Images/d47a8cc51266a2dea5e6f0c5a8406089.png)![](../Images/0974bbdcbe74a94b4dc983d22468419d.png)![](../Images/b899d22c80b3b35a86a21c54110ad676.png)![](../Images/8b16e1e86b8aa5d24b7cdd9799d3753a.png)![](../Images/56549deb3d4058850f9266eba83704cc.png)![](../Images/27dfcf942105aaef722d005276d95f7b.png)![](../Images/6faddf1c2c0394248f82bac4998cb8de.png)![](../Images/b2622c401971ed5b7a67a9e569e5f7f9.png)![](../Images/e3e4f4331a61d31d23c288ca3200ccc9.png)![](../Images/80f93126851e80e95ebc850bbe425239.png)![](../Images/fa4f051f10f26ec2f99ff543f98f58fc.png)![](../Images/4e1903e40194db21d1dd3820ec5c7c24.png)![](../Images/0666d8612135aca1d113bd8999fccf82.png)![](../Images/7c15179c4c212ce80855e17a8e47e9bc.png)![](../Images/ddd68bb6c4dfe7f17020d56a6c0cb95e.png)![](../Images/c754e923ac4f0ba01f175a3d96843f3c.png)![](../Images/7f27846361f9bcac423d66d59b6e2bdb.png)![](../Images/3cfe30ad3ec034402ef6651cb33a686d.png)![](../Images/d3c0e49d2e23d88daf9319d23ce29338.png)![](../Images/0420269a72921912cc97cd38b5892bcb.png)![](../Images/9bd889786db6f69e1348734a7e726e02.png)![](../Im
