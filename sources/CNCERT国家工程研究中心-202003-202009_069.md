# 浙江省首届工业控制网络安全技能大赛启动 邀您来报名！

为深入贯彻习近平总书记关于网络强国的重要思想，加大工控网络安全专业人才选拔与培养力度，不断提升工控网络安全防护能力和水平，助力全省制造业高质量发展，我省将举办2020年浙江省工业控制网络安全技能大赛。大赛由国家计算机网络应急技术处理协调中心指导，浙江省委网信办主办，宁波市委网信办、宁波市经信局、宁波市公安局、宁波市通信管理局、国家计算机网络应急技术处理协调中心浙江分中心承办，镇海区委网信办、宁波市工业互联网研究院有限公司、浙江国利网安科技有限公司、中国石化镇海炼化公司、中国电信宁波分公司、宁波绿盟网络安全技术有限公司、宁波计算机信息网络安全协会、宁波互联网发展联合会等单位协办。  

赛事安排

**一、参赛对象**大赛面向全国公开接受报名。中国境内（港澳台除外）对工控网络安全有研究特长的各类企业、研究机构、科研院所以及高校师生、科研人员、个人开发者等均可组队参赛。参赛以队伍为单位，可自由组队，每队3-4人，设队长1名。**二、比赛形式**大赛为线下赛事，采取仿真环境闯关形式，依托宁波市工业互联网研究院工控安全试验场资源平台，提供模拟工业控制自动化综合场景，每个场景包含办公层、数据层、控制层等。比赛时，网络层级按固定时间逐级开放，参赛队伍逐级进攻，获得FLAG后提交即可得分，并获得下一层的进入权，闯关难度逐级增大，分数逐级提高。总分值1000分。**三、报名方式**参赛队伍可登录宁波市经信局官网（http://jxj.ningbo.gov.cn/）、宁波工业互联网研究院有限公司官网（http://www.niii.com/signup）进行报名，报名截止时间为2020年8月30日。报名应提交完整报名材料，并对所填信息的准确性负责。组委会审查报名材料，对符合参赛条件的队伍确认参赛资格。**四、奖项设置**一等奖1个，奖金10万元/队；二等奖2个，奖金5万元/队；三等奖3个，奖金2万元/队。**五、比赛时间**2020年9月13日（星期日）**六、比赛地点**中国石化镇海炼化公司体育馆（宁波市镇海区沿河路）
