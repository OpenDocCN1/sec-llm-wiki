# Sodinokibi勒索软件团伙从Brown-Forman窃取多达1TB数据

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247499689&idx=4&sn=11dc523e6a7e21c6a27e79f28b1950f6&chksm=fa934968cde4c07eac7da8bad2035e177fc7cc364749f125258041732f73f3744dd84b7c36a0&scene=126&sessionid=1681365383#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247499689&idx=4&sn=11dc523e6a7e21c6a27e79f28b1950f6&chksm=fa934968cde4c07eac7da8bad2035e177fc7cc364749f125258041732f73f3744dd84b7c36a0&scene=126&sessionid=1681365383#rd)

近日据外媒报道，Sodinokibi（REvil）勒索软件运营商上周宣布，**他们已经破坏了Brown-Forman的网络系统，该公司是美国烈酒和葡萄酒行业最大公司之一。**

![](../Images/25703d95ce984cfd4acc4fcfd29d9a75.png)

据悉，Brown-Forman公司是美国最大的烈酒和葡萄酒公司之一，该公司总部位于肯塔基州路易斯维尔，在全球范围内制造多个知名品牌，包括杰克·丹尼尔（Jack Daniel's），Old Forester，伍德福德（Woodford），和Chambord等等品牌。

事件发生后，**威胁行动者声称已窃取1TB的机密数据，并计划将最敏感的信息用于拍卖，并会泄漏其余信息。**据统计，该团伙窃取的数据包括机密员工的信息，公司协议，合同，财务报表和内部消息。

![](../Images/4f41cc95394113f149b9fc5d3dca5545.png)  

Sodinokibi勒索软件运营商表示，**在攻击发生之前，他们已经花费了一个多月的时间来检查该公司的基础架构。**Sodinokibi勒索软件操作员在其泄漏站点上发布了多个屏幕快照，其中显示了据称属于该公司的目录和文件，以及一些员工之间的内部对话。Sodinokibi运营商旨在通过该报告迫使Brown-Forman支付赎金。

随后，Brown-Forman公司在一份声明中披露了该事件，承认遭受了勒索软件的攻击，同时他们披露了有关该事件的一些细节，包括事件何时发生以及黑客是如何访问数据的。该公司向当局报告了此事件，并聘请了世界一流的第三方数据安全专家来调查此事件并尽快解决此问题。

![](../Images/e2333c169c0638743db37170e81b02ac.png)

Brown-Forman发言人表示：“我们在发现攻击后迅速采取行动，阻止了我们的系统被加密。但是部分重要信息，包括员工数据依旧受到了影响。**我们正在与执法机构以及世界一流的第三方数据安全专家紧密合作，以尽快缓解和解决这种情况。**”
