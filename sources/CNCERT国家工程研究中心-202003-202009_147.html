专题丨 基于新型基础设施加快5G网络与数据中心建设

摘要：为澄清对新型基础设施的模糊认识、明确5G网络和数据中心为新型基础设施的科学界定、争取相应的政策支持，从基础设施的本质特征出发，论述了基础设施和新型基础设施的概念，分析了5G网络和数据中心建设面临的主要挑战，最后提出了加快5G网络和数据中心建设应争取的政府支持举措之建议。

1  引言
2020年3月4日，中共中央政治局常委会明确提出“加快5G网络、数据中心等新型基础设施建设进度”，再次为信息通信行业5G网络和数据中心建设注入了强大动力。一石激起千层浪，信息通信行业反响热烈。信息通信行业的许多专家学者、技术人员纷纷发表相关看法，信心满满，亮点纷呈。但一些观点是基于信息通信技术的角度来认识和看待新型基础设施的，对什么是基础设施理解不深、了解不够、认识不够准确，因此有必要深刻认识、充分理解什么是基础设施、什么是新型基础设施、如何就5G网络和数据中心属于新型基础设施的本质特征获得政府部门的实际支持。本文就此展开论述，从基础设施的本质特征角度来认识5G网络、数据中心的新型基础设施定位，争取得到相应的政府政策支持，有效促进、推动5G网络和数据中心建设，更好地服务于我国经济社会的发展。
2  基础设施与新型基础设施

2.1基础设施

基础设施，传统上又称为城市基础设施。城市基础设施，广义泛指由国家或各种公益部门建设、经营，为社会生活和生产提供基本服务的一般性非盈利的行业和设施。国家标准GB/T50280-98《城市规划基本术语标准》将城市基础设施定义为：城市生存和发展所必须具备的工程性基础设施和社会性基础设施的总称。城市基础设施按狭义的定义，是为城市人民提供生产和生活所必需的最基本的基础设施，包括以城市工程性基础设施为主体的六大系统，即交通系统、水系统、能源系统、通信系统、环境系统、防灾系统[1]。基础设施所具有的本质特征具体如下。
( 1 ) 固定占有一定的空间资源，即固定使用一定的土地资源。例如，交通系统中的公路、铁路、大桥、隧道、机场、码头等；水系统中的自来水厂、污水处理厂等，各类基础设施无一例外。
( 2 ) 具有工程性物理实体。其工程建设属性往往具有土木工程属性或市政工程属性。
( 3 ) 为全社会生产生活服务的设施，故又称公用基础设施。
( 4 ) 城市生存和发展所必须具备的设施，缺一不可。一个现代城市，如果缺少了道路交通系统、水系统（给水排水等）、能源系统（电力、汽油、燃气等）、通信系统（邮政、电信、广电）、环境系统（环境卫生设施如垃圾处理、公共厕所等）、防灾系统（消防、防洪等）中任何一类，必然陷入瘫痪、难以运转。
( 5 ) 需要投资建设，难以盈利，具有公用事业属性。基础设施建设往往投资巨大，盈利不一定大，甚至不能盈利，或回报周期很长，需要政府以提供公共物品的形式提供或投资建设。
以上5个特点是传统的基础设施具有的本质特征，从理论到实践得到社会各界特别是政府部门的认同。

2.2新型基础设施

新型基础设施除了具有传统基础设施的5个特点外，还有一个显著特点：与高新技术紧密相连，如依靠先进的信息技术建设、具有高度信息技术含量的信息基础设施。当今，新一代移动通信网络5G网络、数据中心就是新型基础设施的典型代表。
数据中心往往也称为云计算中心，是集中放置电子信息设备并为电子信息设备提供运行环境的建筑场所，可以是一栋或一群建筑物，也可以是一栋建筑物的一部分。如今信息社会已进入云计算时代，云计算设备基本上都放置在云计算中心即数据中心。数据中心内放置了大量的服务器、交换机、存储设备，并配套设置了庞大的动力设备、空调设备等。数据中心从其特点来看具备基础设施的全部要素。
( 1 ) 均要占有较大的空间资源和土地资源。
( 2 ) 均为工程性物理实体。
( 3 ) 为全社会生产生活信息化服务。
( 4 ) 信息社会城市生存和发展所必须具备的设施，在2020年抗击新冠肺炎疫情中发挥了巨大作用。
( 5 ) 需要投入巨资建设，也具有普遍服务的公用事业属性。
( 6 ) 数据中心集成了先进的云计算、大数据、微电子等高新电子信息技术和先进的建筑技术、动力技术、空调技术等，与电子类和建筑类高新技术紧密相连，因而也是典型的新型基础设施。
3  5G网络和数据中心建设面临的挑战
5G网络和数据中心建设面临的机遇巨大，挑战也很大。

3.15G网络建设面临的挑战

随着经济社会的发展特别是进入信息社会后，人类社会对移动通信特别是移动互联网产生了巨大需求。4G改变生活，5G改变社会。我国政府于2019年6月6日给中国电信、中国移动、中国联通、中国广电颁发了4张5G牌照，中国正式拉开了5G网络建设的大幕，2019年正式进入5G元年。5G建设面临的挑战主要如下。
3.1.1 建设资金不足
按相同覆盖预测，5G网络的建站数量将是4G网络的3倍左右，投资也将是4G的几倍。通信运营商连续三年响应政府号召、实施提速降费惠民政策，同时一直承担普遍服务的社会义务，2019年开始全面实施携号转网。这些举措都是响应政府号召、实际履行公益事业的社会义务、让利服务于全社会经济社会发展和人民生产生活，因而也造成业务收入增长乏力，2018年和2019年全国电信业务收入增速连续两年大幅下降（2017年6.6%，2018 年2.9%，2019年0.8%）。通信运营商利润增长困难并出现下滑趋势，部分省区通信运营商甚至出现负增长。因此，除中国移动外主要通信运营商难以拿出足够的建设资金投资5G建设，即使中国移动资金状况较好，但如按市场规律进行投资，也难以进行大规模亏损性建设。
3.1.2 运维成本较高
就能耗成本来说，根据有关方面测算，5G基站耗电约是4G基站的2.7倍，按相同覆盖预测，5G无线网络的能耗成本是4G的8~9倍。加上其他运维开支，在相同覆盖水平下，5G网络运维成本高于4G网络8~9倍可能是常态。
3.1.3 基站选址困难，建设投入大
5G网络频段高，无线传播损耗大，要达到有效覆盖，建站密度远远高于4G网络。在当今城市建设5G网络，新站选址十分困难。落地宏站建设如果没有划拨地的用地政策，采用出让地的拿地方式，需要支出大量的土地出让金，这将大大增加5G的建设成本。
3.1.4 盈利困难
5G建设如果要达到4G的覆盖水平，必将是投资巨大、数倍于4G网络，如果没有有效的收入回报，就难以形成投入产出的良性循环，会形成入不敷出、不能盈利，出现发展困难。

3.2数据中心建设面临的挑战

3.2.1 建设资金不足
数据中心建设成本很大，其投资包括土地成本、建筑建造、动力设备、空调设备、电子设备、通信设备、辅助用房等投资，往往要达到几亿、十几亿，甚至更高。通信运营商近两年业务收入增长乏力，利润增长困难并出现下滑趋势，部分省区通信运营商甚至出现负增长。因此，通信运营商就全国全社会的数据中心需求而言，缺乏足够的建设资金，只能建设一部分数据中心为信息通信业务和自身信息化需求服务，同时为社会提供一部分云计算、大数据等信息化服务。
3.2.2 运维成本较高
数据中心属于高能耗信息基础设施。一个拥有1000台高密度机架的小型数据中心，总功耗是21000 kW，需要2 个110 kV变电所同时供电才能满足，全年满负荷能耗将达到18 亿千瓦时[2]。那么，具有3000个以上机架的大型数据中心，其巨大的能耗可想而知。因此，巨大的能耗成本是数据中心最主要的运营成本之一。
3.2.3 土地成本较高
一个数据中心占地至少需要几十亩，大型数据中心需要几百亩、甚至上千亩。如果不能享受划拨地的用地政策，采用出让地的拿地方式，需要支出很大的购地成本，这将大大增加数据中心的建设成本、制约数据中心的发展。
4  5G网络和数据中心建设应获得的支持举措之建议
5G网络和数据中心是新型基础设施，同时属于信息基础设施。要将加快发展的支持态度转化为政府主管部门的现实行动，建议采取如下举措。

4.1明确加快新型基础设施建设的范围

在信息通信行业，应基于基础设施的本质特征，明确认识5G网络和数据中心是党中央明确号召加快建设的新型基础设施。其他没有形成网络的、不符合基础设施本质特征的某种技术或某种设备不应随意归类为信息基础设施或新型基础设施。宽带固网、工业互联网、物联网基本具备信息基础设施的特征，也基本具备新型基础设施的特征。但宽带固网按传统认识属于通信系统中的固定通信网发展而来，因而归类于传统六大类基础设施中的通信设施。工业互联网其基础承载网主要依托于移动互联网和宽带固网，大规模的工业互联网平台必然同数据中心相关连、其主要设备将放置在数据中心，加快5G网络和数据中心建设，就是为工业互联网发展创造基础设施条件。物联网依托于互联网，即依托于移动互联网和宽带固网，加快5G网络和数据中心建设就是为物联网发展创造基础设施条件。因而党中央提出加快5G网络和数据中心等新型基础设施建设，没有连带加上宽带固网、工业互联网、物联网等，是高瞻远瞩抓住主要矛盾、解决主要问题的关键之举。同时，不应把某种智能技术或某种高新技术随意地认定为新型基础设施。如果技术范畴与基础设施的概念分不清、将各种新技术都说成是新型基础设施，很难取得政府部门的认同，反而扰乱认识、影响发展。

4.2得到城市规划保障

应基于基础设施的定位，向国土空间规划主管部门争取应有的城市规划管理地位，即5G网络和数据中心建设用地应及时地、严格地纳入控制性详细规划，纳入基础设施黄线管理，从而获得有效的国土空间规划保障和城市规划管理保障。

4.3获得划拨地的用地政策

应基于新型基础设施的定位，就5G网络和数据中心建设用地向政府国土、规划、自然资源等主管部门争取应有的土地政策，即5G网络和数据中心所用土地应采用划拨方式，而不是出让方式，从而为5G网络和数据中心建设发展创造有利条件，有效降低建设成本。

4.4采取代征建设用地的办法

对于5G建设用地、特别是基站与传输建设用地，采用城市道路用地和绿化用地代征的办法，在居住区项目、各种园区建设、工业仓储项目、公共管理与公共服务项目等办理建设用地规划许可时，规定由建设单位代征5G建设用地，纳入规划条件，从而为5G网络建设创造有利条件，有效降低建设成本。

4.5适时征收新型基础设施建设附加费

为解决建设资金不足问题，应基于新型基础设施投资巨大、盈利困难的公益性特点，学习民用机场等基础设施做法，建议向政府部门提出申请，时机合适时在通信资费中征收新型基础设施建设附加费，专项用于5G网络和数据中心建设。
5  结束语
应科学准确地认识5G网络和数据中心是党中央明确要求加快建设的新型基础设施。借此强劲东风，务实行动，真抓实干，积极争取各级政府在国土空间规划、土地政策、用地管理、财政政策、税收政策等方面的大力支持，加快5G网络和数据中心等新型基础设施建设，从而更有效地服务于经济社会发展，助力伟大中国梦的实现。
