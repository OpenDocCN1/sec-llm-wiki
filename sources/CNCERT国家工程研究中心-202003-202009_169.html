本文通过分析电力企业中面临互联网的网络安全威胁，结合目前网络安全入侵检测技术，建立了基于人工智能深度学习算法与分布式云计算平台的电力信息网络入侵检测模型，同时对入侵检测系统捕获的海量信息网络数据流，借助深度学习的深层特征提取能力，提出一种基于Spark云计算平台的自动编码器特征选择算法，通过对该算法的并行化，使入侵检测系统在特征选择速度上有显著提高，保证了本系统快速、准确运行，从而使电力企业信息网络安全、稳定。

1  电力企业信息网络基本概要与网络安全的重要性

电力信息网络可分为两大区网：生产控制大区网和管理信息大区网。生产控制大区网主要包括生产实时控制系统与生产非实时控制系统。管理信息大区网包括生产管理系统与日常办公管理系统。这两大区网之间通常采用物理隔离的方式，隔离设备为正向型和反向型的专用安全隔离装置。传统的电力企业网络拓扑图示如图1所示：

图1  网络拓扑图

由图可见数据流是从生产控制大区往生产管理区必须采用正向安全隔离装置单向传输信息，由生产管理区往生产控制区的单向数据传输必须经反向安全隔离装置。严格禁止E-mail、Web、Telnet等网络服务和数据库访问功能穿越专用安全隔离装置，仅允许纯数据的单向安全传输。反向安全隔离装置采取签名认证和数据过滤措施，仅允许纯文本数据通过。电力企业建设了专用的实时控制网络，再将实时网络与非实时网络之间从网络物理层隔开，保护了实时控制网络。

管理信息大区网则通过防火墙与外部Internet网进行连接。为了实现对内部网络信息、物理结构和运行状况对外部网络的不可见，保护网络安全，一般可设置防火墙相关参数，来实现过滤不符合防火墙规则和策略的数据包、应用级网关和代理服务等的安全功能。但由于防火墙在过滤数据包时只针对的是数据包的源地址、目的地址和端口号，对数据包中的数据内容并不扫描，而且防火墙是基于策略的，是通过制定相应的过滤规则来实施过滤的，所以防火墙是用固定的模式来防范未知攻击，并不能完全保护电力信息网，是电力企业面临复杂多变的网络威胁中。
2  电力管理信息区网入侵检测模型
随着网络入侵检测系统（简称IPS与IDS）在电力公司的逐渐普及与应用，该系统作为防火墙后连接的第二道防御屏障，检测网络入侵行为，并及时感知报警，降低了电力信息网络所面临的入侵安全威胁。入侵检测系统是一种通过采集数据包和网络审计数据，分析受保护系统的状态信息，从而发现是否入侵的一种技术。通过对主干网络和核心计算机系统进行实时监控，察觉和识别系统中的入侵行为，入侵及时报警，及时阻止，保护系统和网络安全。

2.1

新概念的入侵检测系统

网络入侵检测系统（IPS、IDS）根据入侵检测的行为可分为两种检测模式：异常检测和误用检测。异常检测先要建立一个系统访问正常行为的模型，凡是访问者不符合这个模型的行为将被断定为入侵；误用检测则相反，先要将所有可能发生的不利的不可接受的行为归纳建立一个模型，凡是访问者符合这个模型的行为将被断定为入侵。

这两种模式的安全策略是完全不同的，而且它们各有长处和短处：异常检测的漏报率很低，但是不符合正常行为模式的行为并不见得就是恶意攻击，因此这种策略误报率较高；误用检测由于直接匹配比对异常的不可接受的行为模式，因此误报率较低。但恶意行为千变万化，可能没有被收集在行为模式库中，因此漏报率就很高。

因此本文借助Hadoop和spark云平台处理大数据的能力，在分析电力信息网络结构基础上，提出了一种基于人工智能神经网络与分布式云计算技术的信息网络入侵检测模型，通过分析网络流量和所采用的网络协议，对捕获的网络数据包进行预处理，形成网络连接记录，对网络连接记录进行深度特征提取，并设计和实现了深度学习算法在Spark云平台上的并行化运行，将改进后的BP网络作为分类器，进行入侵检测实验。

2.3

入侵检测云平台分为建立训练和实际检测两个步骤

在建立训练阶段，通过Hadoop云平台对收集到的数据进行预处理，将预处理后的数据作为输入数据，训练多层编码器对数据进行特征提取，井同时进行BP网络的初始权值优化。在实际检测阶段，行为记录特征通过BP神经网络分类器，根据BP分类器的分类结果产生报警消息。下图4是在云平台下基于深度学习算法的电力信息网入侵检测模型。

图4  电力信息网入侵检测模型
模型由四部分组成：云平台下的数据预处理模块、基于异常行为特征匹配检测模块、基于DBN优化的BP网络检测模块和报警响应模块。
( 1 ) 云平台下的数据预处理
数据收集模块收集从核心节点传送过来的待测数据后交给Hadoop集群进行数据预处理，将处理好的数据存放在Hbase数据库中形成预处理数据库。
( 2 ) 基于异常行为特征匹配检测
该模块涉及异常行为特征库的建立和行为匹配规则。对已知的网络攻击行为进行特征抽取，如行为的特征名称、对应漏洞、发布时间、影响系统、特征属性等组成，对概要特征进行MD5运算存入特征库。匹配时可根据对攻击包的特征信息，包括攻击使用的协议、包长度、包中具有代表性的字节的签名值来判断是否异常行为。
( 3 ) 基于DBN优化的BP网络检测
该模块分为训练阶段和检测阶段。在训练阶段，为了加快BP网络的检测的速度和精度，抽取一部分数据组成训练数据库在云节点上同时进行自动编码器的特征选择训练和BP网络的优化训练。在检测阶段，利用训练好的编码器対预处理后的数据进行特征选择后作为BP神经网络的输入，然后BP网络进行预测输出结果。
( 4 ) 报警响应
结合异常行为特征匹配结果和BP网络预测输出结果来判定在该时刻系统是否遭受入侵攻击。如下图5所示为报警响应情况。

图5  报警响应情况

当BP网络检测异常而行为特征匹配显示匹配失败时，该行为有可能是变种攻击行为，抽取该行为概要特征，用MD5算法对概要特征进行签名，更新特征库。

3  基于spark的深度学习算法在电力信息网中的并行化设计

3.1

基于自动编码器的特征选择算法

本文通过引入自编码网络方法，利用编码网络给出了高维数据与低维嵌套之间的双向映射，克服了逆映射问题。可以通过自动编码网络将高维原始数据向低维嵌套转换，也可以将高维数据作为具有多个中间层的双向深层神经网络的输入，转换成低维嵌套，而低维嵌套向高维数据转换主要使用类似的解码（decoder）网络。本文将用深度学习的稀疏自编码器组成多层编码器网络对全集特征进行逐层特征选择，用BP网络分类准确率来评价选出的特征。

3.1.1 自动编码器原理
稀疏自编码器 （Sparse Auto-Encodcr，SAE）作为一种无监督的学习算法，它运用反向调整算法，使输出值输入值相等，网络中的每个隐含层都是输入信息的一个抽象。自编码器隐含层网络示例如图6所示。

3.2

基于Spark的自动编码器网络并行化设计

3.2.1 并行化模型设计
算法并行设计可分为数据并行和结构并行。数据并行是指在算法的训练阶段每个处理节点采用批处理方式训练一部分样本数据，各个节点将训练完成的权值汇总到中央处理节点，中央处理节点对权值参数进行更新，每个节点再从中央节点获取更新权值参数，进行多次迭代和计算。结构并行是通过分析算法本身的结构依赖特征，分解出并行的结构模块进行同时计算。结构并行需要算法具有并行的结构特征，由于自动编码器层节点之间具有的依赖关系，因此本文中采用数据并行的方式训练自编码器。如下图7所示是并行的多层编码器模型图。

3.4

测试数据集描述

本文采用的数据集是电力企业的网络流量审计日志数据库，为了增加各类入侵行为数据，在经过Hadoop分析处理后的数据集中加入哥伦比亚大字IDS实验室整理形成的一部分安全审计数据集共同构成入侵检测数据集（KD），该数据集共200万条网络流量作为训练数据，测试数据集共100万条数据集。其中包含了四类入侵类型；DDos攻击、端口扫描攻击、远程主机未授权访问和本地用户越权访问，共39种入侵攻击类型，训练数据集中含有22种入侵类型。每条记录共有53维属性，最后一个属性为所属类别。数据分别从四个方面组合而成。第一、考虑网络连接所具有的基本特征，如源IP地址、目的IP地址、源端口、目的端口等属性字段。第二、考虑网络连接的内容特征：数据包的数据部分含有用户远程访问和操作系统敏感文件的指令和登录系统的密码等信息。第三、考虑流量的时间特征；由于网络攻击在时间上的关联性，所以统计在当前连接前2s内与该连接的某些联系，如在前2s内与当前连接有相同主机和服务类型的百分比等。第四、考虑针对特定主机的流量统计特征：实际的网络攻击行为会比2s的时间跨度要长，为了找出这一部分攻击，统计当前连接之前的100个连接与该连接之间的关系，如统计在前100个连接中与当前连接有相同主机和服务类型的百分比等。

搭建4个节点的Spark云计算平台以供本文提出的两个基于云计算的深度学习算法电力网入侵检测算法实验和性能测试，通过对数据集的标准化和归一化处理，作为神经网络单元的输入。对本文提出的基于Spark的MR_SAE特征提取算法、DBN优化的BP网络DBN_BP分类算法分别进行性能测试以及与一些传统的特征提取算法、BP优化算法进行针对性的对比实验，实验结果表明提取后分类的准确率、性能均好于传统算法，且具有良好的并行性，基于Spark的深度学习算法能够满足在海量高维的电力网人侵检测数据上进行准实时检测时对计算机资源的大量需求。

4  结语
通过分析电力信息网络面临的入侵威胁，本文结合现有的电力信息网络入侵检测技术对网络安全进行了深入研究和探索工作：
特征选择是影响电力信息网络入侵检测好坏的其中一个重要因素，本文通过分析现有特征选择算法的不足，结合机器学习的最新研究成果，将深度学习算法引入入侵检测特性选择中来，提出一种基于spark的多层编码器特征选择算法，通过对算法的并行化，使得电力信息入侵检测系统在特征选择的速度上有显著提高，减少了漏报率。并研究了BP网络作为入侵检测分类器时的不足，提出了基于DBN的BP网络优化算法。随着电网系统的更大程度的互联网化，海量的数据和电网信息安全的高要求都促使运用新技术来更好的提供安全保障，在大数据环境下，将深度学习技术和云计算引入网络入侵检测是势在必行。
