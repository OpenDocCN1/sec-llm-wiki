姜宁：站在“新基建”的风口，展望工业互联网的发展与安全

一、中国特色的社会主义发展之路
中国特色社会主义理论是马克思主义中国化的集中体现，在马克思主义哲学中认为历史规律和自然规律一样，矛盾的对立和统一推动着事物的发展，认为人类社会的基本矛盾是：一是生产力和生产关系的矛盾，二是经济基础和上层建筑的矛盾。二者存在着辩证关系，经济基础决定上层建筑，上层建筑反映经济基础，并具有相对的独立性，对经济基础有反作用。简单的说，经济基础就是一个国家的经济，上层建筑包括经济以外所有的内容，而国家政权是上层建筑的核心。社会主义上层建筑在为自己的经济基础所决定的前提下，对自己的经济基础具有不同于以往社会的巨大反作用。以人民民主专政为核心的社会主义政治上层建筑和以马克思主义为指导的社会主义意识形态相互作用，形成强大的社会"合力"，促进了经济基础的迅速发展。
中国有句话叫要想富，先修路。这句朴实的话语不仅在中国尽人皆知，而且也成了世界人民总结中国经验最常见的引用语之一。的确，包括修路在内的基础设施建设为中国的发展铺平了道路。政府在基础建设方面的投资可以带动几倍于政府投资的社会投资，进而拉动GDP。从而通过率先启动大规模的基础设施建设，为经济高速增长奠定坚实的基础。例如中国的高速公路和高铁已经领跑世界，到2019年年底，中国铁路营业里程将达到13.9万公里以上，其中高铁3.5万公里，居世界第一，成为拉动经济发展的“高铁动力”。40年间，我们取得举世瞩目的经济成就，获得宝贵的经验成果，中国经济已成为影响全球经济发展的重要力量。
二、与时俱进的“新基建”
不忘初心，砥砺前行。40年的改革开放极大地提高了生产力发展水平和加强了社会主义经济建设能力，改善了人民生产生活水平，但最终也导致了我国传统基建领域的存量基数过高，使得现在基建投入拉动经济的边际效用越来越小，体现了经济运行主要矛盾仍然是供给侧结构性的事实。党的十九大提出以推进供给侧结构性改革为主线，结合实施“中国制造2025”和“互联网+”，加快建设和发展工业互联网，促进新一代信息技术与制造业深度融合。以推进中国制造向中国创造转变、中国速度向中国质量转变、制造大国向制造强国转变为目标，强化科技创新，大力培育新动能，推动传统产业优化升级。标志着中国特色社会主义进入了新时代。
2018年底，中央经济工作会议重新定义了基础设施建设，把5G、人工智能、工业互联网、物联网定义为“新型基础设施建设”。 2020年初，“新基建”（主要包括5G基站建设、特高压、城际高速铁路和城市轨道交通、新能源汽车充电桩、大数据中心、人工智能、工业互联网七大领域，涉及诸多产业链）被写进了《2020年国务院政府工作报告》。4月，国家发改委明确新基建范围，提出“以新发展理念为引领、以技术创新为驱动、以信息网络为基础，面向高质量发展的需要，打造产业的升级、融合、创新的基础设施体系”的目标。至此，拉开了以注入新动能、发展新领域、助力我国经济高质量发展的新一轮经济建设的序幕。


“新基建”看似旧瓶装新酒，实则不然。与传统基础设施建设相比，新型基础设施建设更加侧重于突出产业转型升级的新方向，无论是人工智能还是物联网，都体现出加快推进产业高端化发展的大趋势。结合2018年底中央经济工作会议提出的“巩固、增强、提升、畅通”八字方针，可以看到，开展新基建是在巩固阶段性成果的基础上，加大基础设施等领域补短板的力度，全面提升产业链水平，发展创新型产业，利用科技更新换代带来产业革命，使基建的边际效果再次增强。
三、未来已来，做好准备迎接工业互联网时代
自国家提出“互联网+”战略以来，工业互联网就成为了国内“工业化和信息化”深度融合的重要手段之一，也成为了我国打造“工业强国”、“网络强国”的重要道路选择。同时，工业互联网作为新一代信息技术与制造业深度融合的产物，通过对人、机、物的全面互联，构建起全要素、全产业链、全价值链全面连接的新型生产制造和服务体系，成为数字化转型及新旧动能转换的关键力量。
在中国发展工业互联网，具有全球最旺盛的市场需求和最完备的互联网生态。一方面，改革开放四十年，我国的制造业得到了迅猛的发展，形成了完整的工业体系，按照工业体系完整度来算，中国已拥有39个工业大类，191个中类，525个小类，成为全世界唯一拥有联合国产业分类中全部工业门类的国家。另一方面，中国互联网发展理念、商业模式、应用实践都较成熟，基本形成覆盖了全员、全社会的互联网生态，具备推进工业互联网平台、抢抓工业发展“换道超车”机遇的独特优势。一定要利用技术创新和规模效应形成的竞争优势，加快解决关键核心技术“卡脖子”问题。着重提高供给体系质量，加快经济结构优化升级，提升科技创新能力，不断提高全要素生产率。

近年来，我国工业互联网发展态势良好，有力提升了产业融合创新水平，有力加快了制造业数字化转型步伐，有力推动了实体经济高质量发展。为落实中央关于推动工业互联网加快发展的决策部署，统筹发展与安全，推动工业互联网在更广范围、更深程度、更高水平上融合创新，工业和信息化部制定并印发《关于推动工业互联网加快发展的通知》，明确提出加快新型基础设施建设、加快拓展融合创新应用、加快健全安全保障体系、加快壮大创新发展动能、加快完善产业生态布局、加大政策支持力度等6个方面20项具体举措。投入的重点主要还是集中在网络侧和平台侧。网络侧包括外网和企业内网的建设。外网方面，主要是依托基础电信企业建设覆盖全国所有地市的高质量外网，用以支撑工业互联网平台和应用，同时加大工业企业上云的网络建设力度，打造企业工业互联网外网优秀案例；内网方面，除了加快基于 TSN（时间敏感性网络）、工业 PON 等关键网络技术应用之外，重点实施“5G+工业互联网”512 工程，利用5G改造工业互联网内网，为实现无线自动控制打好基础。平台侧方面，将增强5G、人工智能、区块链、AR/VR等新技术支撑能力，强化全流程数字化功能集成，提升工业互联网平台核心能力。同时加快工业互联网大数据中心建设，打造“国家中心+分中心”的建设布局。
在抗击疫情的过程中，工业互联网充分发挥互联互通和资源链接的能力，促进供需对接，有力支撑了全社会资源的整合和物资高效调用。伴随着《2020年国务院政府工作报告》工业互联网站上了新基建的风口，随着新一轮基础建设的开展必将加挡提速，进入经济发展的工业互联网时代。
四、聚力发展，不忘安全
新一代信息技术与制造业深度融合而成的工业互联网，随着我国工业互联网发展进入实践深耕阶段，由此带来的安全挑战也不断升级。业内人士认为，安全已然成为工业互联网健康发展的关键所在，企业安全防护水平亟待提升，风险隐患突出，一旦发生安全事件影响严重。
从2010 年“震网”病毒针对封闭环境下的工业控制系统的定制化攻击；到2014 年春，Havex 病毒在能源行业大规模爆发；再到乌克兰及委内瑞拉的大停电事件，都呈现出针对工业控制系统的网络攻击事件正在向有国家背景的、有组织的、长期潜伏的、定制化设计的、大规模的、针对基础设施的方向发展的趋势。并伴随着黑产的发展，利用“勒索病毒”和“挖矿”等牟利的恶意攻击事件数量大幅增长，网络空间的对抗已演变成大国间对抗的首选战场。
面对当今世界复杂的安全形式，在十部门联合印发的《加强工业互联网安全工作的指导意见》中要求，必须统筹发展与安全，企业要落实网络安全“三同步”原则：在建设网络和平台的同时，切实履行网络安全主体责任，同步建立安全管理制度，建设安全防护手段，提升安全防护能力，保障工业互联网健康有序发展。
工业互联网广泛涉及到能源、智能制造、交通、电子与通信等众多重要行业或领域，其安全关乎国计民生、公共利益和国家安全。为应对新时期工控安全形势，工业企业应以《中华人民共和国网络安全法》为准绳，按照工信部《工业控制系统信息安全防护指南》以及公安部《信息安全技术网络安全等级保护基本要求》各项要求，坚持“安全是发展的前提，发展是安全的保障”的思想，开展和完善工控安全防护工作，在改善自身安全防护能力的同时，为全面提升我国工业信息安全防护水平提供支撑。


工控网络安全建设新思路

工控网络安全建设要适应工业互联网发展的新形式，要服务于“互联网+”行动计划的新需求，为工业生产提供保障，紧密围绕等保2.0，切实保障工业生态体系安全发展。
( 1 ) 立足当下，服务新需求
随着“两化”深度融合，企业已经构建起信息与制造融合的多层次数字化制造技术体系，内部生产域之间、供应商协同域之间、生产域与管理域之间都将形成互联。实现信息共享，打通智能制造的断路，这对信息安全建设的能力和安全建设规划都形成了巨大的挑战。
( 2 ) 着眼合规，适应新形式
工业控制系统的网络环境非常复杂，又具有不同的行业特性。面对工业控制系统如何定级，怎样确定系统之间的边界，如何解决工控网络中实时性与安全性的矛盾等新问题，需要围绕等级保护2.0和《工业控制系统信息安全防护指南》，建立适应行业特征的新安全体系。
( 3 ) 管理与技术并举，建立新体系
防护领域有“三分技术、七分管理”的传统。要将技术与管理有效结合，构建科学完备的安全防护管理流程，根据工业互联网安全目标对其面临的安全风险进行安全评估，并选择适当的安全策略作为指导，才能实现防护措施的有效部署。

工控安全防护设计新理念

( 1 ) 零信任
零信任数据：在云时代，数据是安全架构的核心。敏感数据不再始终处于安全边界内，而是在本地与云端之间来回传输。在零信任模型中，不能信任出入网络的任何内容。
零信任网络：零信任模式的实施需要强大的网络控制能力，能够划分和隔离数据及资源。严格执行细粒度的访问控制。
零信任人员：员工是企业最宝贵的资产，也是最薄弱的环节。需要精确掌控哪些用户有哪些访问权限、可访问哪些数据以及何时访问。他们还需要先进的技术来保护他们远离网络钓鱼攻击和凭据失窃等侵害。
零信任设备：在互联的世界中，每台端点设备都需要保护到位。有效的零信任安全战略意味着您必须审核每台设备；确保其值得信赖；授予访问权限；然后随时隔离、保护和控制每台接触网络的设备。
( 2 ) 白环境
对于工业控制网络来说，基于异常的检测方法对其非常适用，因为工业控制网络的拓扑结构相对静态，通信模式具有规律性并可预测，非常适合利用白名单机制建立工控安全“白环境”。通过主机白名单结合网络白名单共同完善建立生产网络应用及数据流向的完整画像，帮助企业建立工控安全防护的基线，及时发现网络中的异常流量和异常行为。而工业防火墙、工业监测与审计系统、工业主机防护系统成为建立工控安全“白环境”必不可少的基础套件。
( 3 ) 全感知
威胁无处不在，而且攻击者使用越来越狡猾的手段，例如隐藏在加密通信中以逃避检测。可见性技术可以抵御它们的攻击，并有助于检测和及时响应风险。
综合利用SOC、态势感知、EDR、全流量检测等技术，收集工业网络安全大数据及威胁情报信息，分析工业网络安全模型，为用户提供企业级工业网络智能安全预警与一体化管控平台，帮助用户建设工业网络安全集控中心与态势感知中心，从全局视角提升对安全威胁的发现识别、理解分析、响应处置能力，最终为决策与行动提供支撑。

五、写在最后
经济创新发展需双向发力，向上创新创变，向下夯实基础，基础设施建设是关键。以云计算、数据中心、大数据、人工智能、5G为代表的“新基建”，其着力点便是为国民经济打造数字经济体系的底座，支撑整个国民经济，由传统模式逐步走向信息化、数字化，最终走向智能化。我们要以奋进的姿态探索自身边界，透析经济建设的变迁，紧跟政策指引，不断创新创造。在为新基建保驾护航同时，亦将迎来网络安全产业发展新机遇!
