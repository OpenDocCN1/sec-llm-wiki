# “新基建”下5G模组风口已至：移远通信做好桥梁助力5G行业应用提速

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247496312&idx=5&sn=6c1d6337f50d5ea924d1b54cf9bbaf86&chksm=fa9344b9cde4cdafc1a9eaf8387dde1c6114625424a9f1a047ac9b079b4aa47a835fc82d1e3b&scene=126&sessionid=1681365405#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247496312&idx=5&sn=6c1d6337f50d5ea924d1b54cf9bbaf86&chksm=fa9344b9cde4cdafc1a9eaf8387dde1c6114625424a9f1a047ac9b079b4aa47a835fc82d1e3b&scene=126&sessionid=1681365405#rd)

距离商用发牌仅仅一年时间，5G比我们想象中来得更快。截至今年5月底，我国已建成5G基站逾24万个、中国移动和中国电信两家服务了超过8500万5G套餐用户。

每一次信息技术的变革都会为世界带来巨大的推动力，“5G改变社会”也不再只是个口号。相比前几代移动通信技术聚焦于人与人的连接，它正以“更多连接、更大带宽、更低时延”的鲜明特性，全面由消费侧向行业侧渗透，创造出全新的价值。在当前这个特殊时期，如何进一步加快5G在行业中的应用，也已成为全社会众所关注的焦点。

作为产业链中关键一环、最贴近行业的无线通信模组厂商们无疑拥有相当的发言权。C114日前连线采访了上海移远通信技术股份有限公司（下称“移远通信”）董事长兼CEO钱鹏鹤。凭借在模组行业多年的技术积累，以及涵盖NB-IoT、LTE、5G、车载前装的丰富产品线，移远通信目前已是全球第一大蜂窝物联网模组供应商，而钱鹏鹤本人更是国内最早一批投身无线通信模组开发的工程师之一。

![](../Images/8b50cd45d1903016a253975c297b85ba.png)

移远通信董事长兼CEO钱鹏鹤

“5G的行业发展前景巨大，它将会激发创新，带来目不暇接的甚至我们今天意想不到的新应用，令各行各业都从中获益。而我们移远通信也将一如既往地作为桥梁，推动通信技术与其他行业的融合，帮助新技术尽快普及，释放其中蕴含的价值。”他以此打开了话匣。

**“5G改变社会”照进现实**

  
根据中国信通院发布的《5G经济社会影响白皮书》，到2030年，在直接贡献方面，5G将带动的总产出、经济增加值、就业机会分别为6.3万亿元2.9万亿元和800万个；在间接贡献方面，5G将带动的总产出、经济增加值、就业机会分别为10.6万亿元、3.6万亿元和1150万个。  
在为消费者提供前所未有的体验升级的同时，5G在提出之初便将服务行业作为主要目标。正如国家工信部部长苗圩去年9月在国新办发布会上指出的那样，5G应用将呈“二八律”分布，“绝大多数的应用将会是面向车联网、工业互联网等物与物之间的通信”。我国三大运营商在推动5G的行业应用方面也向来不遗余力，早在网络试验阶段就已携手各方建立起行业应用的创新孵化平台、发起包含诸多垂直行业领袖企业的产业联盟，乃至拨款成立专门的发展基金。而5G SA的商用提速，很大程度上也来自开拓行业市场的需要——基于SA的网络切片、边缘计算等功能，5G可支持包括低时延高可靠性（uRLLC）、海量连接（mMTC）在内的全业务场景，从而满足垂直行业所需。钱鹏鹤指出，随着网络迅速铺开，如今的5G已经广泛渗透到制造、交通、能源、医疗、教育、物流等行业领域，打造出一批商用标杆项目；在此次抗击新冠肺炎疫情的过程中，5G的重大作用也得到了凸显，其与云计算、物联网、人工智能、超高清等技术的深度融合，有力支撑了各地的疫情防治、复工复产工作。![](../Images/0a9171275a4831957e5e8e815d17f2d3.png)搭载了移远C-V2X模组的上汽集团重型卡车在上海洋山深水港成功实现集装箱的智能转运他尤其看好5G在智能网联汽车中的应用。一方面，联网是汽车最重要的发展方向之一，自4G时代车联网便已开始快速发展、LTE-V2X等技术得到了车企的广泛认同，拥有一定基础，5G因为带宽和时延方面的优势或将更受欢迎。另一方面，消费者普遍愿意为车辆智能化付费，对运营商而言，智能网联汽车相比一些低端物联网应用属于高价值用户，将是一个重要的行业突破点。“近年来，中国汽车年销量平均超过2000万辆，随着蜂窝物联技术成为标配，将开启一个极为庞大的市场。移远通信在车联网领域布局较早，已经有大量客户将我们的LTE-V2X模组用于车辆和路边单元。在5G方面我们已经推出5G+V2X的车载通信模组，去年早些时候与长城汽车启动5G汽车方面的战略合作，并且支持了上海洋山港的智能重卡项目。后续智能网联汽车在5G+V2X的促进下有望进入规模发展期，苗部长此前预测，2020年中国智能网联汽车的市场规模可达到1000亿元以上。”钱鹏鹤展望道。

**“新基建”下5G模组风口已来**

  
在中央密集部署与国人全民热议下，“新基建”热潮迅速席卷大江南北，将撬动数十万亿级的市场。  
“新基建”不仅是对冲疫情影响、确保经济健康发展的“维稳器”，更是促进数字经济与实体经济融合、推动传统行业升级转型的“加速器”。加快新型基础设施建设已成我国立足当前、着眼未来的重大战略部署，并首次被写入两会政府工作报告之中。而无论央视前期提出的七大方向还是发改委官方明确的所涉范围，5G均名列其中，且领衔之势明显。今年以来，国家已经发布了一系列5G发展引导性政策。比如发改委、工信部发布了包括医疗、教育、电力、港口、制造、超高清、车路协同等垂直领域的七项5G创新应用提升工程。同时，工信部还明确提出了有关5G加快网络部署、丰富应用场景、加大研发力度、构建安全体系、加强组织实施等五方面18项措施。网络与行业终端的协同将直接关系到5G在垂直行业中的进展，乃至5G整体发展。根据全球移动设备供应商协会（GSA）报告，5G终端款型数量“呈现出持续而显著的增长”，截至4月中旬，已发布的终端有283款，其中108款为手机，应用于物联的更多。而5G模组是各类行业终端实现通信功能的核心部件，其重要性毋庸置疑。在“新基建”加持下，5G模组风口已至。“‘新基建’的加快推进将会牵引更大的产业投入，对5G、对相关产业来说都将是一个重大机遇。”钱鹏鹤表示，5G模组上下游均已进入了成熟期，芯片侧高通、华为海思、紫光展锐、联发科都进展较快，行业终端侧量产厂商逐月增多。在利好的大环境下，5G模组的价格也会随着行业终端上量而下降，反过来促进5G发展，形成一个良性的商业循环。值得一提的是，在新能源汽车充电桩领域，移远通信也与多家行业龙头企业保持着合作关系，已有多款搭载其模组的充电桩成功落地应用，占到全国联网充电桩总规模的一半以上。在人工智能领域，这家公司今年亦推出了新一代智能模组SA800U，适用于服务型、交互式、工业类机器人，游戏类、异构计算AI应用，以及AR/VR、视频会议系统等。

**做好通信行业与其他行业的桥梁**

  
在从事5G模组的厂商中，移远通信可谓表现突出。早在2018年该公司便已启动了相关布局与开发工作，2019年初率先推出4款5G模组，皆符合3GPP R15规范、支持5G独立组网（SA）和非独立组网（NSA）两种模式。  
![](../Images/2d2457766eb30ef46095ad9ee35dfc84.png)目前，其支持sub6的RG500Q-EA已经在2020年一季度实现规模商用，支持30多个行业的1000多家终端厂商使用，比较典型的应用包括CPE、高清视频直播、电力、笔记本电脑、工业网关、视频监控等。此外，移远通信还不断推出新的模组产品以满足客户多样化的需求，加速更多5G行业规模应用顺利落地，比如今年2月在伦敦基于海思平台发布了超高性价比的5G多模通信模组RG801H。前段时间，“5G上珠峰”一事刷爆了朋友圈。在高寒、高海拔、高施工难度下，中国移动在珠穆朗玛峰6500米前进营完成全球海拔最高的5G基站建设和开通，实现了珠峰峰顶的5G覆盖，支撑了2020珠峰高程测量和媒体直播相关工作。此举堪称信息通信领域的一座里程碑，也充分体现了我国在科技领域的“大国实力”。而移远通信亦在其中作出了贡献，在其5G模组的支持下，TVU One 5G直播背包为中国珠峰高程测量登山队的全程直播提供了重要助力。对于加快5G在行业中的应用，钱鹏鹤从无线通信模组供应商角度强调要做好通信行业与其他行业的桥梁：“不少行业中的客户对通信技术并不了解，甚至没有用过模组，那么我们模组厂商就要引导他们，包括提供从产品设计到上市的全流程、全方位的服务。”“只要客户有需求，我们都会尽力去支持，有一种使命感和责任感在其中。”他还举例说，移远通信的实验室里配备了非常先进的5G测试设备，除了自用，还安排了专人支持客户进行终端性能测试，帮助客户5G产品迅速落地；再比如，移远是一家全球化的公司，与海外的运营商等上下游合作伙伴保持着密切合作，客户可以借助这些海外资源做大做强。Berg Insight今年5月发布的最新调研结果显示，2019年全球蜂窝物联网模组出货量增长22％，达到2.65亿片的新纪录水平。五大供应商合计占据了71%的市场份额，而移远通信超越加拿大Sierra Wireless排名全球第一。之所以能够在十年里做到今天的成绩，除了对蜂窝物联网模组的热爱，也在于对技术的专注。钱鹏鹤与他的团队骨干从2002年起就最早一批进入了模组领域，沉淀了丰厚的技术实力和垂直行业应用经验。同时，移远通信在国内的上海、安徽合肥，以及塞尔维亚贝尔格莱德（欧洲）、加拿大温哥华（北美）均设有研发中心，广东佛山的研发中心也在建之中，从而汇集全球的研发力量，并贴近客户以快速响应。此外，移远通信的产品线在业界也是最齐全的，目前为止量产的模组已有近600款。“我们移远通信擅长做产品、也钟情于这个行业。我们未来也将持续扩大布局、围绕模组发展自己的技术和服务能力，帮助客户尽快上市产品，不断把整个模组行业的规模做大，促进千行百业的联网化、数字化、智能化升级。”在采访的最后，钱鹏鹤如是展望道。
