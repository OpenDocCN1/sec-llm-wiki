# 解决基层就医问题才是互联网医疗征途的星辰大海

导读互联网的特点在于在时间前置和空间并发，智能化由此可以大显身手。

近期，左手医生团队通过高密度深入走访，与众多行业专家进行交流，深刻感受到，互联网医疗的核心价值将体现在三个方面：第一，帮助实体医院更好地优化线下诊疗流程；第二，承载诊后的健康促进业务；第三，解决基层群众看病难、看病贵问题。  

要实现互联网医疗的核心价值，智能化应用不可或缺。因为智能化应用是一种新生产力，其本质是帮助线下医疗资源在线上更高效地服务患者。![](../Images/819f3f0525a9b6399dc9cec77950a08e.png)**智能化应用可以帮助实体医院更好地优化线下诊疗流程**  
《国务院深化医药卫生体制改革领导小组关于进一步推广深化医药卫生体制改革经验的若干意见》明确指出：充分利用互联网技术，改善群众就医体验。在《医院智慧服务分级评估标准体系（试行）》中，更是将此以“智慧服务建设”的方式写进标准。  
虽然目前流行的智能导诊、在线挂缴查、信息推送宣教、在线咨询等服务是实现医院智慧服务的重要功能，但其本质还是把相关服务从线下照搬到线上，并不能从根本上改善医院的服务能力。互联网的特点在于在时间前置和空间并发，智能化由此可以大显身手。  
**1.智能化应用可以帮助医院优化就诊流程**患者线上挂号后即可收到AI医生的预诊，快速提交主诉信息；患者信息传到医院端后，交给科室值班医生，由值班医生和AI医生协同为患者提供就医指导，甚至为患者开具基础检验检查单；患者就医前，手机上已生成完整的就医指导与就医步骤，到医院后可先去自助机刷卡缴费，做完基础检验检查后再去见医生。  
据统计分析，上述优化流程不仅可以改进患者的就诊体验，减少了院内就诊等待时间和排队，还可明显提高医生接诊效率。借助互联网的时空效应和智能化技术，医生可以在一定程度提前获知患者病情。这一流程的优化，可以帮助医院更有效率地开展诊疗业务。  
**2.智能化应用可以帮助区域更好地优化医疗资源分配**虽然现在有的区域已建立了统一的预约挂号平台，但由于现有号源还是需要靠“抢”，并没有实现平台价值的最大化。其实，只要平台拿出10%的医疗资源，按需分配给真正有需要的患者，在这些患者没有挂到目标号时，可以申请绿色通道，按要求把病情及历史报告提交给AI医生；AI医生经过分析判断，结合绿色通道要求，为急切需求的患者分配号源。  
**3.智能化应用可以助力双向转诊**当前以“向上转诊”为主要需求的分级诊疗无法有效开展，原因在于基层医生很难精确地把患者转到合适的上级机构。但在未来，智能化应用可以帮助我们实现这个目标。患者在基层就医时，基层医生可以求助AI医生，AI医生即可精准给出就医建议，从而帮助患者精准就医，实现医疗资源的合理分配。  
**智能化应用助力患者诊后健康促进业务**针对诊后人群的院外指导，患者的需求十分明显，但这也一直是市场的空白。如果患者离开医院后，即刻衔接健康管理计划，可以获得医生指导和处方，将显著增强患者获得感。同时，在支付层面，借助药险互动，也给互联网医疗商业化带来一些机遇。  
在用户粘性方面，国家政策在持续引导医院为离院患者提供健康促进服务。在院外服务过程中，可以通过院外干预，提升患者康复效果，支持医院临床研究工作。在这个过程中，智能化应用是最成功的解决办法之一。如图1所示。

图1在互联网医疗发展初期，医院要从服务入手，为门诊患者提供延续性的诊后康复指导、用药指导、患者教育、随访管理、复诊复查等服务。通过诊后的健康管理闭环设计，融入在线问诊、在线续方等功能，完成线上使用闭环，在无形中引导并培养患者的线上使用习惯。如此一来，通过诊后服务的延续性，互联网医疗可以获取私域流量（线下门诊量）的线上转移，积累第一批种子用户。  
由于需投入大量人力成本和培训管理成本，诊后管理服务无法通过人工达到理想状况。引入智能化应用，让AI医生一对多、24小时不间断地为患者提供个性化康复指导、用药指导等一系列诊后服务，有效增强患者粘性，达到活跃互联网诊疗业务的目的。在诊后随访、健康管理过程中，智能化应用同样可以提高医疗机构为患者服务的效率，提升患者粘性。在诊后管理环节，左手医生通过疾病管理产品，与头部三甲医院的重点科室合作，已陆续在胃癌切除术后管理、痛风管理、哮喘管理、关节置换管理等场景获得积极的反馈。  
不过，现阶段医保只支付医疗服务费用，不支付健康管理费用。所以在诊后患者管理环节，一定要让患者获得显著性获益，进而提升患者及医保支付意愿，获得持续发展动力。  
**智能化应用解决基层群众看病难、看病贵问题**  
谈到这个话题，很多人立刻想到，把智能化应用投入基层，给基层医生配上人工智能设备，提升他们的能力，进而缓解医疗资源紧缺，解决看病难、看病贵的问题。但是，这条路可能并不是最优路径，有可能仅在某些地区或某些场景适用。  
从数字上看，我国三级医院医生通过高强度的劳动，解决了大部分群众就诊需求。但是，中国缺少的并不是普通医疗资源，而是优质医疗资源。  
一些有疑难重症的患者，往往需要从县医院、到市医院、到省医院、再到一线城市。互联网医疗，可以真正让优质医疗资源更加快速对接到刚需人群。优质的医疗资源是稀缺的，只有通过智能化应用来充分释放专家资源的潜力，加大优质医疗资源的供给。  
作为一家医疗AI创业团队，左手医生在探索过程中发现，医疗创新的价值不仅仅在于模式创新，更重要的在于技术创新。通过技术创新，释放优质医疗资源的潜力，增大医疗资源供给，进而缓解看病难、看病贵问题。  
互联网医疗，恰好是技术创新的孵化场所。互联网医疗的使命并不是简单地方便患者就医，解决基层群众看病难、看病贵的问题，才是它未来征途的星辰大海。
