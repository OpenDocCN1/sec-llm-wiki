# Nature：量子增强的密码远程控制为人工智能和物联网安全提供解决方案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247492268&idx=4&sn=16755877d39cf6b2ac8ebd8637b04a7a&chksm=fa93546dcde4dd7b6cfc6e5f06875f53c83b30ebc8a31d0589b1e3a94c55eb9ad7b038cab373&scene=126&sessionid=1681365426#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247492268&idx=4&sn=16755877d39cf6b2ac8ebd8637b04a7a&chksm=fa93546dcde4dd7b6cfc6e5f06875f53c83b30ebc8a31d0589b1e3a94c55eb9ad7b038cab373&scene=126&sessionid=1681365426#rd)

【导读】上海交通大学的研究者提出了一种量子增强的密码远程控制方案，在无人机控制系统上进行了实验验证。文章以简单实用的方式将真正的随机性和量子增强加入到安全控制算法的领域中，**为人工智能和物联网安全提供了一种改进的解决方案。**随着人工智能和物联网技术的飞速发展，黑客攻击事件日益增多，对安全性提出了更高的要求。为了实现密码远程控制，人们正在广泛研究基于密钥的通用算法。

随机性在密码学和数值模拟中有着重要的应用。**然而，真正的随机序列很难用数学方法生成**，但必须依赖于不可预测的物理过程。

量子密码学利用量子力学的随机性，除了可以在安全通信领域发挥作用，还可以为实现无条件安全的控制网络大展身手。

在许多情况下，随机性的实时共享在实践中并不真正必要。例如，无人机或卫星在发射前已经完成了密钥识别，任务期间与其他各方进行了很好的隔离。基于这样的情况，研究者将量子密钥预充到控制器和被控系统中，并以一种简单实用的方式实现量子增强的密码远程控制。

密码系统由三个子系统组成：密钥管理单元、控制器单元和控制单元，如图1。

利用单光子量子特性产生的随机性，通过安全密钥存储芯片对物联网设备进行一次性密钥加密解密。利用自制的密钥管理单元实现了柔性小型安全密钥存储（SKS）芯片与量子随机数（QRN）发生器的连接，SKS芯片在分离前被植入控制器和控制对象中，命令是用一次性密钥算法以一定的密钥段加密的，只有被控制方用相应的密钥才能正确解密。

在控制器端，使用QRN键，在发送命令之前对命令执行逐位异或；相反，使用相同的键，可以在被控制端解码和执行命令，如图1( b ) 所示。

无人机控制系统的数据传输图如图2( a ) 所示。加密密钥由Quantis生成，Quantis是一个可靠的QRN发生器，采用量子过程作为随机源，以4 Mb/s的比特率产生随机序列。具体来说，入射在半透明反射镜上的光子将以一半的概率反射，导致“0”；或以一半的概率透射，导致“1”。

实验结果来自1638400个样本，显著性水平α=0.01。在直方图中，超过红色虚线的每个测试的值都是成功通过的。

一次性密钥算法的成功执行依赖于密钥的同步。然而，命令有可能丢失或出错，导致控制器和被控制者之间的密钥不匹配。任何小的密钥不匹配都可能导致控制系统故障。

为了解决这个问题，研究者为每个命令分配唯一的地址信息，这样每个带有量子密钥的命令都是独立、标记良好的。一旦发生错误，将直接丢弃相应的命令及其加密和解密密钥，以保持同步。这样的地址信息不必加密，因为它们不包含有关命令的信息。

量子密钥的随机性是决定系统安全性的重要参数。基于量子力学不确定性原理的量子随机数具有不可预测和不可产生的性质，它提供了世界上最纯粹、最绝对的随机性。研究者使用NIST套件进行统计测试，最终结果如图2( b ) 所示。NIST测试的结果证明了量子密钥具有极好的统计随机性。

由于命令的安全性依赖于一次性密钥，因此在这种加密控制方案中，通信容量主要受到预充电QRN的数量限制。为了延长密钥更新周期，一方面，安全密钥存储设备的容量应该足够大，而存储密钥地址信息的命令可能需要更多的字节。另一方面，可以根据不同的结构对加密命令进行优化，忽略某个命令中的一些琐碎信息来保存密钥，提高解密速度。

综上，研究者提出并实验证明了一种结合量子随机性和一次性密钥算法的量子增强密码远程控制方案。量子增强密码方案有望推广到双向系统，被控制者可以安全地控制，也可以将加密的飞行记录数据发送回控制器，如位置、方向和速度。

此外，点对点解还可以扩展到点对多点或分布式网络。更重要的是，该方案可以与固定量子密钥分配信道相结合，实现远程量子密钥计费，为大规模人工智能和物联网的控制安全提供了灵活的解决方案。
