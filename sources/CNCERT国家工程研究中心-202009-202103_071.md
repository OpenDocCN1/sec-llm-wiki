# SCADA系统正经历重大变化：实现更多价值提升 促进IT和OT融合

![](../Images/3e7adf59f2360c8f285dffbab36553a1.png)澳大利亚 ESM 公司帮助 YourCoffee 公司将客户与工厂联系起来。图片来源 ：ESM“ 现代技术和创新思维使很多令人印象深刻的项目成为可能，这些项目使用了先进的HMI和SCADA软件以实现更多的价值提升，并有助于OT和 IT融合。”毫无疑问，人机界面（HMI）和监控与数据采集（SCADA）系统对于工业企业至关重要。SCADA 允许工业企业能够本地或远程控制工业过程 ；监视、收集和处理实时数据 ；通过 HMI 软件可直接与传感器、阀门、 泵、电动机等进行交互，并将事件记录到日志文件中。 多年来，SCADA 系统经历了重大变化，使工业企业可以做更多的事情。随着智能机器、大数据和工业互联网的引入，运营技术 （OT）和信息技术（IT）部门发现他们需要解决相同的问题 ：访问工业数据，集成更多系统并应对业务挑战。现代 SCADA 系统旨在利用最佳控制和 IT 技术来解决这些问题。

**SCADA 软件的优势**

制造企业正在拥抱现代工业应用平台和技术，在各个行业中创建创新的工业系统。SCADA 系统处于中间位置，可以提供以下功能 ：合并数据并与不同的系统集成 ；消除纸质表格 ；运行高级逻辑引擎和计算 ；为更多人提供数据 ；利用移动设备，连接工厂和人。SCADA 系统擅长与可编程逻辑控制器（PLC）和现场设备进行通信。传统的 SCADA 系统通常会限制与它们通信的 PLC 品牌。能够将来自多个不同 PLC 的数据提取到同一个平台上，对于运行人员来说是非常重要的。借助 OPC UA 等现代标准，用户可以将 SCADA 系统连接到这些设备。 除了 PLC，与其它一些数据源集成对于 SCADA 也很重要，例如计算机维护管理系统 （CMMS）、企业资源计划（ERP）、制造执行 系统（MES）等。连接这些系统并在操作员屏幕上添加情境信息，会带来很大收益。

**连接客户和供应商**

澳大利亚 ESM 的团队帮助 YourCoffee 公司，将其 Shopify 电子商务平台连接到工厂车间。将配置 RESTful Web 服务 API 的 SCADA 系统，和基于可编程自动化控制器 （PAC）的工厂自动化平台结合使用， ESM 为 YourCoffee 提供了工业 4.0 工具，用于连接、 评估、结构化和控制信息及物理过程，帮助用户高效实现其生产目标。 YourCoffee 的客户订购定制的混合产品，并选择袋子的尺寸、类型和标签类型。使用 Web 服务调用，SCADA 可以利用电子商务平台上返回的 JSON 数据。然后将订单分为基于产品的对象，用户可以从中整理出来自不同订单的几种产品，并进行优化，制定出可以减少转换时间的生产调度。 生产系统自动计算生产混合咖啡所需的时间、地点和数量，然后创建烘焙和包装时间表。电子商务平台和 SCADA 的结合，消除了客户与供应商之间的鸿沟，从而提高了供应链的质量和效率。 通过组合功能并使用现代技术，工业企业可以实现无纸化办公。使用支持结构化查询语言（SQL）数据库的 SCADA，可以实现文书工 作的数字化。微软 Excel 工作表或 Access 程序 也可以转换为中央共享应用程序。

**在一个软件平台上实现标准化**

开发空中作业平台的 JLG 工业公司，希望在其制造工厂的一个软件平台上实现标准化。该平台将统一现有的应用和设备，消除纸质表格，提供历史数据存储并提供 MES 功能。系统集成商 MDI 公司，利用 JLG 公司的 ERP 系统、条形码技术和配方管理，开发了 一个新系统。客户利用蓝牙从秤上获取重量样本，并在完成后打印条形码标签。然后在下游工作站扫描标签，配方管理系统使用数据自动设置机器计算并加载配方。所有数据都保存在 MSSQL 服务器中，并在每个制造站生成报告。该方案消除了纸质的统计过程控制图表和关键区域的生产计划、人工计算和手动数据输入。

**更多SCADA数据和远程访问**

由 于 SCADA 系统可以访问重要的 OT 数据，因此企业希望在 PLC 附近运行更高级的计算。例如，经营天然气处理装置的Streamline Innovations 公司，需要将危险的硫化氢（H2S）转化为化肥级硫。最开始， 它希望采用在 PLC 上编写的自动化平台。但是，这无法进行复杂的计算以提供基于模型的控制，因此无法实现半自主操作，也无法对设备进行远程控制。 Streamline 公司转向了可以运行多个 Python 脚本的 SCADA 平台，以实现复杂的 计算。例如，对泵振动进行快速傅立叶变换分析，根据从美国国家气象局下载的天气预报来确定最佳工作温度，这在 PLC 中似乎是不可能实现的。出现问题时，警报自动通知将通过 Twilio 发送给操作人员和工程师。 访问数据是至关重要的，并且智能手机和平板电脑的使用正在不断增加。实际上，移动设备已取代台式机成为上网和查找信息的首选方式。这种模式转换在工业领域中也正在发生。![](../Images/6f8ee0e48f0ae2a154ababc950621684.png)移动应用程序使用户可以从任何地方控制 SCADA

**支持虚拟现实和可视化**

美国南加州的圣贝纳迪诺县正在为其垃圾掩埋场寻找下一代可视化和控制系统。现有设备很旧，需要升级，并且没有易于使用的 HMI 或 数 据 可 视 化。任 务 很 明 确 ：需要 一种灵活的体系结构，该体系结构允许利用 HTML5 本身所具有的可视化功能，以使用任何基于浏览器的现代设备。 通过使用中心辐射型模型、现场边缘网关和云 平台，Corso Systems 和 SCS  Engineers 公司为该县提供了完整的企业解决方案。SCS 使用航空数据来组合各种废物设施的地形图、2D 图像、3D 渲染、GIS、 热成像、近红外（NIR）和甲烷泄漏检测。 在飞越该县的垃圾场，上传图像并绘制了设施图之后，SCS 和 Corso 公司能够嵌入 2D 图像和 3D 渲染图。这使用户可以从任何地方使用任何现代设备访问数据。此外，该团队还能拍摄这些渲染图像并将其应用到微软 HoloLens VR（虚拟现实）头戴设备中，从而使圣贝纳迪诺县的决策者能够在他们的办公室身临其境的感受到现场。该试点的成功，使项目扩展到了其它 27 个县。

**连接服务器、工厂和管理数据**

SCADA 系统具有独特的功能，不仅可以将数据连接在一起，还可以将人员连接在一起。使用具有无限许可模式的现代 SCADA 系统，OT 和 IT 部门可以访问所需的数据。随着新挑战的出现，企业希望通过建立新项目来解决这些问题。 生产建筑材料的 Lafarge Holcim 公司在全球雇佣了 7 万多名员工。在一次重组过程中，该公司希望管理其在全球 6 个地点的 近 300 名员工的工作。由于该公司计划设立一个中央 SCADA 服务器，来管理所有就地 SCADA 服务器，因此它决定创建一个连接工厂数据与人员和管理数据的应用。 主要应用具有 3 个基本流程 ：1）任务，由工厂经理提出请求（协助，技术研究）；2）活动，谁负责哪个主题 ；和 3）时间表，显示已完成的工作，并实时预测将来会发生的情况。现在已有将近 600 人在使用该应用，它是一个突破常规思维的应用的好例子。 先进的 HMI/SCADA 软件利用现代技术和开放标准，可完成比旧版软件更多的工作。为了从 SCADA 软件中获得最大收益，需要识别挑战，构建解决方案以应对这些挑战并实现业务价值。拥抱新技术将使运营从应用中获得更多价值，并允许在整个企业中进行更多访问。
