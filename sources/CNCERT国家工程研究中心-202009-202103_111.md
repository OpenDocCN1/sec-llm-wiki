# 2021年ICS/OT网络安全展望

作者 | 天地和兴工业网络安全研究院

【编者按】近期，全球各大安全厂商、知名咨询机构、有关专业媒体和众多智库纷纷抛出了其对2021年网络空间安全发展的态势预测，无一例外，大家的关切都包含勒索软件、工业物联网安全、供应链攻击、IT/OT融合趋势、远程办公常态化、APT组织攻击、针对ICS的恶意软件等领域。天地和兴作为长期专注于工业网络安全的厂商，自然将关注点也聚焦到了ICS/IoT/OT安全，我们对卡巴斯基、Radiflow、Dragos、Claroty、Booz Allen、Gartner等机构关于2021年网络空间威胁发展趋势的报告进行了学习和梳理，将有关ICS/IoT的预测进行分析汇总。结果显示：2021年ICS/IoT/OT安全将呈现一些鲜明特点，勒索软件攻击者将对工业企业产生浓厚的兴趣；工业企业将成为APT组织的攻击目标；5G将拓展工业物联网的攻击面将有新型非传统的针对OT/ICS现场设备的攻击；远程办公常态化带来新的安全风险；供应链攻击风险增加等。

**一、针对工业组织的勒索攻击仍然是头号威胁**

Group-IB在《2020/2021年度高科技犯罪网络威胁趋势报告》中指出，2020年，勒索软件攻击出现了前所未有的激增。事实证明，无论是私营企业还是政府机构，都无法幸免于勒索病毒的肆虐。由于攻击者的动机仅仅是经济利益，任何公司，无论大小和行业，都可能成为勒索软件攻击的受害者。与此同时，如果没有必要的技术工具集和数据恢复能力，勒索软件攻击不仅会导致生产停工，还会导致运营陷入停顿。根据Group-IB的保守估计，勒索软件操作造成的经济损失总计超过10亿美元，但实际损失可能要高得多。受害者往往对事件保持沉默，并悄悄地支付赎金，而攻击者并不总是公布来自受攻击网络的数据。

Cybereason预计，2021年嵌入黑客行动中的多阶段勒索软件将会增加。医院，银行和关键基础设施提供商将面临更高的风险，但是许多行业都面临着这一威胁。只有在黑客将勒索软件放置在网络中的每台计算机上，然后完成攻击的其他阶段，包括数据窃取、用户密码窃取和在网络上传播之后，他们才会在所有受感染的端点上引爆勒索软件。

Dragos在《制造业网络威胁展望》中指出，在过去两年中，影响ICS环境和操作的非公开和公共勒索软件事件数量显著增加。

Radiflow认为，与前几年试图控制工业机械控制器的恶意软件攻击不同，勒索软件攻击完全是为了金钱。随着IT密集型组织（如金融部门）在保护其网络方面做得更好，黑客转向了受保护程度较低的OT行业，如制造业和医疗保健行业。在许多情况下，这些攻击使用了几十年来的鱼叉和隐写术（将图像隐藏在图像或文件中）。2020年的勒索软件既有熟悉的名字，也有新鲜的名字，包括LockerGoga、MegaCortex、Ryuk、Maze、Snake/Ekans等。2021年，勒索软件将变得更加针对于OT，不仅针对可能影响生产的IT网络，而且还将直接针对工业设备。

卡巴斯基ICS CERT则预测，2021年勒索软件攻击将表现如下特点：

● 勒索软件在技术上越来越先进和复杂。网络攻击者将继续使用黑客和APT技术，努力探索和探测目标组织的网络，以找到最有价值/最易受攻击的系统，劫持管理员帐户，并使用标准管理工具同时发动闪电攻击。

● 网络攻击者对工业企业产生了浓厚兴趣，因为工业企业倾向于支付赎金。这意味着袭击将持续进行。

● 将会发生涉及文件盗窃的混合攻击，并威胁如果拒绝付款的话就会公开或在暗网上出售文件。

● 针对OT/ICS进行Snake勒索软件攻击将持续进行。

● 很有可能发生伪装成勒索软件攻击但其实是追求完全不同的目标的攻击，如恶意软件ExPetr那样。

****二、国家支持的APT组织将对OT网络发起更强攻击****

针对关键基础设施进行的攻击事件正在不断增加。值得注意的案例包括SolarWinds攻击；俄罗斯行为者对阿塞拜疆的可再生能源部门进行了多次袭击；伊朗黑客对以色列主要供水系统的多次袭击；以及（可能是）报复性袭击使伊朗海港瘫痪。由于政治敏感性，这些公开的攻击只是冰山一角。

卡巴斯基ICS CERT预测，到2021年：

● APT组织的数量将继续增长，将会看到越来越多的新攻击者，包括攻击各个工业领域的攻击者；

● 这些组织的活动将与当地冲突相关联，包括处于激烈阶段的冲突，与无人机和媒体驱动的误报一起，对工业企业和其他设施的网络攻击被用作战争工具；

● 除了数据窃取和其他零星的操作外，某些组织很可能在2021年开始更严肃的业务，例如Stuxnet、Black Energy、Industroyer、Triton等。

****三、针对工业控制系统的恶意软件将持续增加****

根据Dragos的《制造业网络威胁展望》，目前有两个攻击组织XENOTIME和ELECTRUM被证明有能力利用专门针对ICS进程的恶意软件（TRISIS和CRASHOVERRIDE),并破坏ICS进程。尽管Dragos尚未观察到有恶意软件家族会扰乱制造运营，但这些攻击者可能会在开发此类恶意软件的过程中将目标锁定在制造公司，即使它们不是最终目标。

2016年恶意软件CRASHOVERRIDE在乌克兰的一个输变电站中专门针对西门子SIPROTEC保护继电器和ABB设备进行破坏。Dragos观察到，一些大型制造公司可能会在现场有自己的电力运营部门，其中包含相同的设备。从理论上讲，如果使用相同的设备，攻击者可以将制造业作为针对关键基础设施（如电力公司）的破坏性攻击的“试验场”。Dragos估计，由于总体上较复杂的网络安全基础设施和较少的政府监督，制造业可能成为攻击者更具吸引力的目标。

卡巴斯基预测，到2021年：

● 网络威胁分子在过去几年里一直在随机感染连接到工业网络或定期访问工业网络的计算机，而现在的趋势是减少随机攻击。这些计算机的访问权将被（也许已经被）转售给更复杂的组织，这些组织已经制定了具体的计划来攻击工业设施并进行货币化。

● 多年来，各类威胁组织专门针对工业企业进行攻击，目的是为了窃取钱财，通过BEC计划或先进的黑客攻击来获取受害者的财务和会计系统的访问权。通过多年的犯罪活动，他们逐渐了解了工业企业的业务流程，并掌握了大量网络资产和运营技术的技术信息。预计将会看到新的非传统的针对OT/ICS现场设备的攻击，以及巧妙的货币化方案。网络犯罪分子有足够的时间和机会来发展他们。

● Windows 7和Windows Server 2008在ICS中全球流行，然而Windows 7和Windows Server 2008都已终止支持，特别是在工业网络中仍然很常见Windows XP源代码泄露，对工业企业的安全构成了重大威胁。类似WannaCry之类的场景可能在不久的将来再次出现，而工业企业可能受到的打击最大。

****四、5G应用将放大工业物联网的攻击面****

BoozAllen的《2021年值得关注的8种网络威胁趋势》预测，5G将拓展工业物联网的攻击面。5G网络与ICS/OT的结合将导致复杂的攻击面，并暴露出工业物联网网络运行方式中的潜在缺陷。通过以互联网为中心的设备集中OT通信，可以很好地满足用户的攻击需求，并且通过对物理操作的直接访问会带来更多的破坏性攻击。

5G改变OT环境。许多不同的行业都期望5G网络的到来和更广泛的可用性，以实现5G对各种环境的功能支持，包括IIoT系统的无线集成。将这些网络过渡到5G，将给这些环境带来完全不同的攻击面，而这些环境通常比企业端点受到的保护要少，因为网络抽象提供了一定程度的保护。

5G将在ICS环境中集中通信。5G条件下，集线器可用于丰富来自底层组件的通信，其中包括完全抽象的物理层和控制器层来自现有有线环境中的面向互联网的网络层。通过面向互联网的设备集中化OT通信所提供的丰富性和访问性可能会吸引攻击者，并通过直接访问物理操作来提供更具破坏性和破坏性的攻击。

5G作为ICS环境无线可行性解决方案可能会暴露出传统协议带来的安全问题。许多ICS/OT设备都使用Modbus协议。5G是第一个消除此延迟障碍的新兴无线技术，可实现如Modbus通信这样对延迟敏感的操作。

对于使用诸如Modbus之类的过时且不安全的协议的实施，攻击者可以简单地将命令发送到设备，而无需接收者验证请求的性质。考虑到ICS/IIoT环境的真实性质以及这些连接的系统所起的作用，与传统的网络攻击相比，此类攻击的后果将更为昂贵。此外，这些新兴技术呈现出不断发展的威胁态势，目前尚无法确定。随着技术的普及，漏洞将不可避免地被发现。

物联网安全公司Sequitur Labs专家预测，物联网设备在2021年的市场规模将大幅增长。物联网设备在工业领域的应用具有巨大的潜力，将改善人们的工作、交流和生活方式。Sequitur Labs预计在2021年，工业物联网的远程设备管理和控制将取得实质性进展。新冠疫情迫使人们远程工作，还加速了远程配置、控制和管理工业设备远程的需求。因此，绝大多数工业终端将支持基于互联网协议（IP）的网络，如以太网和Wi-fi，而不是专用网络，如Modbus或Profibus。这些设备可以连接到互联网，因此还需要具有安全启动、安全更新、启用系统恢复、保护敏感应用程序和数据存储的能力。

****五、IT/OT融合态势凸显IT安全与OT安全融合的挑战****

Dragos认为，制造商的网络安全成熟度取决于行业、监管要求、地理位置和各种其他因素。然而，在工业环境中存在“扁平网络”并不罕见。这是因为企业和运营部门之间共享网络连接。这使得攻击者更容易跨越IT和OT边界，并从IT接入点进入后攻击制造业务。如果企业和运营部门之间确实存在隔离，利用跳转主机和访问限制，那么制造工厂通常利用所有制造工厂的相同广域网（WAN）连接。如果攻击者能够进入一个设施的运营，则可能会危及整个公司的运营。

然而随着业务的联系日益紧密，工业环境中仍然缺乏对过程、资产和连接的可见性，很难抵御运营商看不到的威胁。根据Dragos的数据，81%的Dragos服务团队合作的组织对ICS/OT网络的可见性极为有限或根本没有。从事件响应活动中发现，多数组织没有用于事件分析的安全性和过程数据聚合，而需要手动检索日志和分布式分析。至关重要的是，在未来，所有制造部门和运营部门（包括工程、装配和物流）的资产所有者和运营商应改善网络和主机可见性，以识别和抵御日益增长的威胁。

对此，Claroty认为，OT安全性是推动业务的重要因素。企业对OT进行核心业务活动的依赖程度越高，安全作为确保运营成功和连续性的业务推动因素的重要性就越大。试图用传统的IT安全最佳实践和技术来增强OT安全性是非常无效的，同时往往会引入不必要的复杂性，因为OT网络很少有适合其因数字化转型而日益面临的网络威胁的安全控制措施。

对负责OT环境安全的人员来说，最大的挑战之一是缺乏遥测技术，因此缺乏对OT网络的可见性。OT资产通信和共享的信息远远多于IT资产之间通常共享的信息，包括运行的软件版本、固件和序列号等。在大多数情况下，OT网络流量可以提供全面威胁监控所需的所有安全信息。因此，决策者应基于其快速实施并集成到IT系统和工作流中的能力来评估以OT为中心的资产可视性和持续的威胁监视解决方案，以立即提高防范能力和降低风险。

因此，改善IT与OT之间的协作面临重大挑战。前所未有的新冠疫情大流行暴露了许多安全漏洞，并促使IT和OT人员共同努力解决此问题。长期以来，不同且往往相互竞争的优先级一直是IT团队和OT团队之间的障碍。具体来说，IT团队通常优先考虑机密性、完整性、可用性原则，而OT团队通常在物理过程和相应OT系统中优先考虑可用性、可靠性、安全性原则。

另一个IT/OT的区别是组织和攻击者看待IT和OT网络的方式不同。组织更倾向于将IT和OT视为独立的网络，但对于攻击者来说，网络就是网络，因此攻击是相互交织的。

****六、远程办公常态化使人成为新的网络边界****

Gartner预测，在接下来的12到18个月，远程工作和向云迁移将继续推动基础设施领域的趋势。到2023年底，90%以上的基础设施和运营组织将让大部分员工实行远程工作。新冠疫情可能加速了这一趋势，但这也归因于基础设施的性质因组织向云和边缘转变而发生了变化。

Gartner研究副总裁JeffreyHewitt表示：“多年来，随时随地的运营和核心现代化之类的趋势一直进入到基础设施领域组织的最前沿，但新冠疫情迅速加快了这些趋势，以至于它们在不久的将来具有变革性影响。”

安全研究公司Radiflow的CEO Ilan Barda表示，居家办公可能是2020年每个工业CISO的噩梦，它要求为工业设施的远程操作设置各种安全工具和程序。由于没有先例可循，工业（SCADA/ICS）运营商不得不争先恐后地做出艰难的决定，从谁可以在家工作，到谁购买商务专用笔记本电脑，因为私人计算机本身就存在着无数安全风险。

对此，Radiflow的安全专家发布了针对自动化网络的远程访问最佳实践建议，大多数建议都是与居家办公无关的组织应采取的常识性步骤：IT/OT微隔离、VPN的MFA身份验证、定期检查访问策略、最重要的是，了解OT网络和网络面临的风险。

**七、**供应链攻击的防范面临前所未有之重大挑战****

作为威胁受害者的第一步，多种威胁已转移到危害供应商、托管服务提供商（MSP）和外部网络服务。攻击者可以滥用现有的信任关系和互联性，以获得对敏感资源的访问权，在某些情况下还包括ICS系统，几乎都不可能被发现。

此类活动的案例包括：DYMALLOY和ALLANITE组织针对几个原始设备制造商和供应商进行了攻击，针对电力部门实施了后续网络钓鱼攻击；针对几家原始设备制造商和供应商的XENOTIME；APT10进行了一场广泛的黑客攻击，劫持了MSP及其客户之间的连接，其中包括制造企业。

承包商、供应商和其他第三方人员通常可以直接访问操作环境进行更新、检查或新设备安装等活动。攻击者有可能将这些个人使用的设备作为进入其最终目标的接入点。企业资源规划（ERP）供应商还提供了潜在的感染媒介，如果没有适当的隔离和安全控制，这些媒介可以弥合IT和OT之间的鸿沟。ERP服务需要访问操作资产以监视和存储与生产、供应链、库存和安全相关的信息。

制造业实体是全球供应链的一部分，支持多个其他行业，这使得它们成为对手攻击电力公用事业或制药等行业的跳板。利用第三方连接可使攻击者进行间谍活动、侦察和数据窃取操作，以预先做好准备以展开破坏性OT攻击。由于制造业公司在各个行业垂直领域的相互关联关系，资产所有者和运营商应意识到所有ICS实体面临的威胁，并将ICS特定威胁情报纳入安全运营和风险管理。

2020年底,SolarWinds事件使供应链攻击震惊全球。据称SolarWinds攻击可能是由国家支持的黑客实施的，但可以肯定的是，非关联行为者很可能会模仿这种攻击的方法和TTP，从而使供应链风险增加，任何供应链软件（如SolarWinds的Orion）都应被视为受到危害。供应链攻击通常表现为网络行为的经常变化，例如检测到与外部IP地址通信的设备。因此，需要对工业网络进行连续监控，以检测网络模式的任何变化。同时风险评估也需要不断更新，以跟进最新发布的攻击公告。所有这些都应该成为结构化备份和弹性计划的一部分。
