# 在物联网网络边界处普遍存在一种现象即终端入网监测及终端设备的安全防护相对薄弱，致使以网络边界处终端设备作为跳板入侵至核心网络，已成为物联网攻击的常规手段。网络边界处终端安全如何保障？准入控制必不可少。为确保接入网络终端为可信终端，终端接入时需要对其合法性进行检测，终端接入后可识别仿冒资产，才能有效解决因不安全终端接入网络而引起的安全威胁，增强物联网网络防御能力。

准入控制---网络边界安全防护的重要手段。

**网络是否有以下安全隐患存在？**

1.  物联网设备厂商、种类繁多，资产不清晰电力、交通、银行、智能城市等各行业物联网终端，包括PC、打印机、摄像头、自助终端机，消防设备等多种类、多品牌、数量庞大的物联网设备网络拓扑复杂，资产家底不清楚，安全防护盲点增多，难以进行全面安全防护。2\. 物联网设备的微隔离边界防护弱一旦被攻击难以发现及阻断，易造成持续性大范围攻击，导致生产指令下发变缓/无法下发/伪造下发，影响生产业务；或被利用组建成僵尸网络，造成更大影响。3\. 缺乏物联网设备间的安全防护机制工业专用通讯协议如Modbus，,水文监测协议等缺乏安全防护机制，单靠传统防火墙无法保证资产、网络行为、数据及指令安全性、可靠性。4. 无法实时监控前端设备管理员无法实时获取前端设备状态，安全事件发生时，无法第一时间发现。5. 边界工作的安全防护网络系统维护时有新设备接入，造成其相互之间的随意访问，病毒、蠕虫等恶意类代码的扩散传播和入侵攻击，缺少有效的访问防护手段。

**如何实现准入控制，保障网络边界安全？**

准入控制是指对网络边界处接入的终端资产进行合规性检查，其主要目的是保障新入网终端合法，避免已入网终端被伪造/仿冒，以及实时掌握终端运行状态。准入控制一般解决方案有：( 1 ) 基于标准的准入协议开发的准入控制通过802.1x、Portal等准入协议进行认证以实现对其接入设备的准入控制，该方案对准入协议有要求，是相对传统的解决方案。其特点是产品形态通常为硬件准入网关，入网终端需要支持准入协议或安装准入客户端，通过协议认证的方式实现准入控制。其解决方案相对大而全且传统，面向对象大多为PC机或专用设备，不适用于搭建终端设备类型复杂的认证环境，如终端设备不支持传统准入协议，就无法使用。( 2 ) 基于网关设备的准入控制技术准入网关一般直接部署在终端设备上游，通过硬件路由或Agent探测针对其网络进行管控的方式以实现对其下游设备的准入控制。产品形态通常为硬件路由或Agent探测针，实现功能的基础类似Nmap探测工具实现的终端服务扫描画像，再结合IP/MAC/端口绑定进行终端准入。该方案主要基于资产的硬件属性进行准入识别，无法识别仿冒终端。然而感知层终端大都部署在无人监管的区域，使部分内网环境暴露在未知环境中且网络环境复杂，极易进行MAC冒充后的终端接入攻击。

**物联网终端准入安全防护方案**

景眸准入控制解决方案主要思路是：在不改变网络拓扑、对网络内其他设备及模块进行端口扫描、诱探行为的条件下，通过对镜像流量的采集、分析，实现资产属性包括IP、MAC、厂商等识别，同时通过分析网络流量分析测绘资产网络指纹，通过资产网络指纹实现接入网络边界终端设备的发现识别、准入监测及仿冒监测，同时，也可在终端上游部署安全网关，对非法设备进行联动阻断，防止非法外联及仿冒接入。

**实施案例**

案例背景：某市道路交通场景中，需要对城市内居民辖区街道的摄像头、球机、NVR设备等20个资产进行安全防护。（如下图所示）![](../Images/56e937774b8b5bd47aba8c8b53835100.png)**实施步骤：**第一步：某单位内网系统服务器上部署管理平台；第二步：了解网络拓扑环境，在网络汇聚层部署流量感知引擎，在终端资产上游部署感知层安全网关；第三步：录入资产白名单，学习接入合法资产网络指纹，管理员下发安全策略；**实施效果：**( 1 ) 实施部门新接入5台资产，安全管理员策略未做任何调整，景眸物联网安全系统发现新资产并提示管理员有非法接入需进行审批；( 2 ) 路由设备伪造为已接入摄像头的IP/Mac，景眸物联网安全系统发出仿冒资产接入报警。( 3 ) 内网资产的横向微隔离。当边界设备摄像头A被入侵，试图访问摄像头B时，内网之间的横向微隔离使得该访问被拦截，有效的防止内网资产的相互入侵，大面积传播。
