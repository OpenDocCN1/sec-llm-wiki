# 数字贸易之 ( 四 ) | 欧盟两项数字法案被指针对美国巨头，欧美会否爆发数字贸易战？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247506945&idx=4&sn=03faf812b851d8b5e82e518c78e84c9b&chksm=fa936ac0cde4e3d68044beb291cc732e3f161c830c371454eefe34b816b60b9832bc252a0656&scene=126&sessionid=1681365318#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247506945&idx=4&sn=03faf812b851d8b5e82e518c78e84c9b&chksm=fa936ac0cde4e3d68044beb291cc732e3f161c830c371454eefe34b816b60b9832bc252a0656&scene=126&sessionid=1681365318#rd)

有关对数字服务（主要是互联网服务）的监管和征收数字税的争端，是否会成为欧美贸易战乃至新一轮全球贸易摩擦的引爆点？欧盟15日公布规范有关数字服务的两项重要法案《数字服务法》和《数字市场法》。法案中对一些互联网公司等数字服务巨头进行更严格的规范和征收数字税的规定被认为是直接针对谷歌、亚马逊、苹果、脸书等美国公司。近来，法国等多国还宣布要对美国巨头征收数字税，就连美国的“小弟”加拿大也狮子大开口。尽管担忧美国可能会对这些监管措施实施报复，但欧盟仍坚决出台两项法案。德国《世界报》15日引述欧盟主管内部市场的委员蒂埃里的话称：“这关系到欧盟的价值观，也关系到欧盟数字经济的未来。”

**欧盟将严惩违规美国巨头**

“今天，我们提出一套针对所有数字服务的新规则:《数字服务法案》和《数字市场法案》。”欧盟委员会主管反垄断事务的委员韦斯塔格15日在欧盟总部宣布，我们希望确保用户能够在网上获得广泛的安全产品和服务选择，确保企业公平、自由地竞争。

“欧盟宣布限制谷歌、亚马逊、苹果、脸书等科技巨头的里程碑式法律。”路透社称，这两项法案为美国的科技巨头在欧盟开展业务制定严格的规则。据报道，法案涉及的主要是超过4500万使用者的大型网络平台公司，这相当于英国脱欧后欧盟人口的10％。欧盟将对这些平台进行定期检查。对于违规或不接受检查的网络公司、平台，欧盟将课以罚款，最多的可达其营业额的10％。此外，美国巨头还利用自己的垄断优势“杀死”各种潜在的竞争对手，并且涉及严重的侵犯隐私问题。因此这些法案将从源头做起限制垄断，由欧盟提出约束清单，明确规定哪些是禁止的、哪些是要求做到的。

德国之声称，包括谷歌、脸书、苹果、亚马逊和微软在内的10家公司将被指定为互联网“看门人”，这意味着它们将受到更具体、更严格监管规定的约束；这些公司必须将任何计划中的合并、收购事先通报欧盟，而且其取得的数据必须与监管机构共享。报道称，这些互联网巨头如“严重且屡次违反规则”，甚至将被完全禁止进入欧盟市场。

法新社称，在这两项具有里程碑意义的法案出台之际，硅谷巨头们正面临着全球范围内越来越多的审查。欧盟主管工业的委员布雷顿称:“我们的想法不是要废除大型平台，而是对它们用规则实施约束，防止它们对民主构成风险。”报道称，这两项法案还需得到欧盟27个成员国以及欧洲议会的批准才能生效实施，在此期间，互联网巨头们的游说狂潮可能对最终的法律条文产生影响。

**“一个巨大的转折点”**

“一个巨大的转折点”，德国《世界报》15日称，在欧洲数字产业方面，欧盟及欧洲各国政府、消费者，尤其是欧洲公司很难与美国的网络巨头及它们创造的数字平台相抗衡。欧盟不愿再接受这一点，将利用法律来改变这一切。两项法案矛头对准的就是美国几个屈指可数的科技巨头。脸书等美国科技公司对此警告称，更多的监管或迫使他们搬离欧洲，使欧盟民众失去大量就业岗位，甚至失去访问网站的权限，但欧盟并不妥协。欧盟主管内部市场的委员蒂埃里表示：“这关系到欧盟的价值观，也关系到欧盟数字经济的未来。”

美国AXIOS新闻网称，除了加大对美国互联网巨头的监管外，以法国为首的多国政府纷纷准备对美国公司开征数字税。10日，法国还对谷歌和亚马逊分别开出1亿欧元、3500万欧元的罚单。报道称，欧洲对美国科技巨头开始加大力度进行抵制，以反对“美国优先”的贸易保护主义。在拜登即将就任美国总统之际，欧洲对大型美国科技公司的数字服务进行征税的企图可能会引发激烈的贸易战。

法国《回声报》称，这些美国的巨头如今已经变得太大、太强、太唯利是图了。法国财政部部长勒梅尔指责，苹果、谷歌和脸书等通过将欧洲总部设在爱尔兰和卢森堡等“避税天堂”国家来逃避税收，它们在法国、德国等欧盟各国开展业务赚得盆满钵满，却享受着爱尔兰和卢森堡的低税收待遇，这显然有失公平。欧盟委员韦斯塔格也表示，由于爱尔兰对苹果公司的“照顾”，该公司的税率仅为0.005%，逃避了大量税金。

对于征收数字税，法国是首倡者和推动的主力。2019年，法国政府拟向大型跨国互联网企业征收3%的数字服务税，但遭到美国的反击。特朗普政府宣布对来自法国的化妆品和手提包等商品加收25%的关税。之后，美法两国于2020年1月暂时达成妥协，双方停止加税并就数字税问题在经合组织内进行多边谈判。不过，今年6月，美国突然退出了谈判，经合组织只好宣称谈判推迟到2021年。

英国《金融时报》称，今年以来，受新冠肺炎疫情影响，各国政府开支激增，为弥补赤字需要寻找新的税基。报道称，法国已迫不及待对美国科技巨头征税，因为它们成了疫情的最大赢家。勒梅尔称：“数字税从未像现在这样合理和必要。疫情之下，科技巨头赚得比谁都多，它们需要承担更多的义务。”

**欧美会爆发数字贸易战吗**

“欧盟能驯服美国科技巨头吗？”德国《商报》15日称，欧盟企图迫使脸书、谷歌等美国互联网巨头承担更多的责任。多年来，来自硅谷的巨头能够几乎不受阻碍地扩大对欧洲公民的影响力：他们在很大程度上确定人们在互联网上找到哪些信息。然而，欧盟的措施势必会引发美国的不满，甚至可能采取报复措施，而德国的汽车可能是一个重点报复对象。美国贸易代表办公室今年6月曾宣布，对欧盟、英国、意大利等10个贸易伙伴拟征收的数字税发起“301调查”。

尽管担忧美国会实施报复，但赞成对互联网巨头进行监管并像其他企业一样征税的国家越来越多。美国“政治”新闻网14日称，意大利和英国已制订了数字税计划，加拿大财政部称计划从2022年1月1日起征收数字税。报道愤怒地讽刺称，特鲁多政府在不可预测的特朗普政府面前总是小心翼翼。2017年，特鲁多前往华盛顿与特朗普首次会晤前，甚至专门排练如何与其握手，既能表现风度又不会得罪特朗普。报道称，特鲁多在数字税问题上的大胆立场可能是（反抗美国数字垄断的）一个早期迹象。加拿大准备在拜登当选美国总统之际抓住更多机会，这可能是美国当选总统拜登赢得大选后的国际新格局的考验。

对于欧盟对美国互联网巨头加强监管和征税，美国政府用贸易战进行威胁，美国互联网巨头则展开了强大的游说。《纽约时报》14日称，美国科技巨头的说客们正以布鲁塞尔“从未见过的大手笔支出”来对欧盟展开游说。不久前，一份泄露的文件详细列举了谷歌破坏两项数字立法的计划，震惊了欧盟。比如位于布鲁塞尔的智库欧洲国际政治经济中心曾发布报告，宣称新的数字法规将导致欧洲损失200万个就业岗位和850亿欧元的GDP。而该组织就是谷歌赞助的至少36个协会和智库之一。对此，欧洲公司观察组织的专家席尔瓦称，这些游说是“企图创造一个让最富有的人受益的体系”。
