# 关于发布第八届CNCERT工业控制领域网络安全应急服务支撑单位考核和增选结果的通知

2020年8月至9月期间，CNCERT组织开展了CNCERT第八届工业控制领域网络安全应急服务支撑单位（以下简称“支撑单位”）考核和增选工作。

一、考核情况

本次考核对象为第八届工业控制领域支撑单位全体，考核内容是2019年7月1日至2020年6月30日期间支撑工作情况。大部分支撑单位都能够按照要求在日常或特定任务期间，较好地支撑中心各项业务工作。其中，有5家考评等级为优，5家为良，8家为中。

二、增选情况

本次增改选工作由CNCERT国家中心审议确定，旨在根据实际工作需求，进一步完善工业控制领域网络安全应急体系。

经提名推荐、筛选和审议，CNCERT决定增选“恒安嘉新(北京)科技股份公司”为第八届工业控制领域支撑单位，有效期从2020年7月1日起，至2021年6月30日止。

CNCERT将与上述企业联系处理发放证书、签署合作协议等事宜，并在网站“应急体系——应急服务支撑单位”栏目更新相关信息，敬请留意。
