# 快讯｜CNCERT受邀在“城轨企业信息安全与应急管理专题培训”上作专题报告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247504969&idx=1&sn=fae9ed15715c9f2ccb57b46372b32786&chksm=fa936288cde4eb9e61272500a61e8d989496df87a87e12397dd50b53491a2fa794bb56cd5f8b&scene=126&sessionid=1681365329#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247504969&idx=1&sn=fae9ed15715c9f2ccb57b46372b32786&chksm=fa936288cde4eb9e61272500a61e8d989496df87a87e12397dd50b53491a2fa794bb56cd5f8b&scene=126&sessionid=1681365329#rd)

2020年11月19日，由中国城市轨道交通协会信息化专业委员会主办的“城轨企业信息安全与应急管理专题培训”在广州召开。此次培训为使城轨企业更好的认识到当前企业信息安全与应急管理痛点、难点以及信息化发展的未来趋势，培养一批信息安全、应急管理专业人才，为城轨企业信息安全管理提供有效帮助，达到促进城轨企业信息化共同发展的战略目的。

国家互联网应急中心孙中豪博士受邀在会上做“工控安全应急响应体系”专题报告；王庆博士受邀在会上做“面向关键信息基础设施的网络安全态势与对策建议、关键信息基础设施安全防护”的专题报告。两位博士的报告在会上取得热烈反响。参加培训的学员包括北京地铁、广州地铁、上海地铁、重庆地铁、厦门地铁、武汉地铁、南昌地铁、南宁地铁、成都地铁、天津地铁、合肥地铁、长春地铁等国内主要地铁业主信息部门相关人员，还包括铁科院、比亚迪通信信号有限公司等供应商。
