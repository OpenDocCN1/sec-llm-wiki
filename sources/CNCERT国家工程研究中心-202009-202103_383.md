# 智慧机场和航空系统的物联网安全

物联网将以不同方式连接我们日常生活中的许多事物，民航业也不例外。确实，物联网技术可以帮助例如提高现有空中交通系统的容量和效率，同时改善乘客的体验。因此，以前分开的IT系统通过新建立的网络连接起来，包括传感器或执行器在内的新IoT设备成为新的复杂基础架构的一部分。

**智慧机场**

智慧机场开始在世界范围内出现。它们不再仅仅是一个概念，而是一个不断上升的现实。许多进步和改进源于：

1.  创新技术数量和范围的增加
    
2.  乘客越来越多地使用平板电脑和智能手机等智能设备
    
3.  普通旅客的体验提升
    
4.  使用飞机作为首选转乘方式的人数激增
    

后者导致机场实施新技术并从本质上成为智慧机场。这些新机场被称为Airports 4.0，这些数字清楚地描绘了它们在不久的将来不断增加的实施和统治地位。

43％的机场正在实施物联网计划以监控现场位置。大约59％的机场正在实施网络安全措施以防御常见的网络威胁。后一个数字指出了智慧机场新时代中至关重要的安全性。

**智能机场的安全**

当实施新技术时，并且当重要领域越来越依赖互联网时，就会出现新的威胁。智慧机场不可避免地会面临网络威胁，因为这些威胁不可避免地在其计算机系统中存在固有的缺陷和错误。

在实施了新的智能技术的大多数行业和领域中，情况都是一样的。智慧机场已经发生了事故。2016年8月，由于达美航空在亚特兰大总部附近的重大停电，美国达美航空不得不暂停航班并导致了数千名乘客无法正常出行。系统崩溃，并且它们无法正常运行足够长的时间以导致航班取消。

大型飞机制造商空中客车每年遭受多达12次网络攻击。有些人设法突破了他们的安全系统并造成了严重的干扰。结果表明，即使是世界上最大的公司也没有安全的。

这些情况以及必须涵盖大量流程和人员的系统固有的缺陷，使得智慧机场必须具备网络安全性。

智慧机场中连接到Internet的所有系统固有的缺陷仅仅是因为它们已连接。这使它们成为黑客的可行目标，他们很可能利用任何漏洞来破坏系统。

**航空系统物联网安全认证框架**

对于机场而言，至关重要的是要优先考虑网络安全并确保对中央系统进行充分的保护。然后，他们可以移至其余系统。

需要分配资源以及足够的、有才能的专业人员。除此之外，还需要制定并遵守适当的政策-确保在机场所有需要采取此类措施的地区实施适当的网络安全措施的政策。

由于网络威胁的数量和有效性只会不断增加，因此保护智慧机场的安全需要相应地遵循这些发展。

牢记这些目标和概念，必须建立专门针对物联网的安全认证框架，以满足每个运营环境对基本、实质性或高安全性保证水平的需求。该解决方案有助于降低安全评估和测试服务的成本，消除网络安全专家的匮乏、提高业务和风险所有者的安全意识，并最终在保持安全标准的同时在利益相关者之间建立一定程度的信任。

必须理解，在机场中必须实施先进的网络安全措施，并且需要一个值得信赖的合作伙伴来帮助维持可确保机场和乘客安全的标准。
