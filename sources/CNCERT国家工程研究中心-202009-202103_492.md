# 

**前言**

在做样本分析的时候，通常都是针对恶意软件进行分析。这种属于样本分析，是安全分析中的一部分，但也是比较关键的一部分。样本分析是安全分析人员与恶意软件开发/投放人员沟通最直接的桥梁。但是很明显，攻击并不是直接就是从恶意软件开始的。我们拿到的恶意软件，可能是鱼叉类钓鱼邮件攻击精准投放，也有可能是水坑类攻击下发。作为分析人员，除了分析看到的这个恶意样本，也应该关注整个攻击事件和攻击背景的分析。

# 

**样本背景**

笔者在app.any.run上看到了如下的样本：![](../Images/13f6e00205afd28704e45698df0f9d5a.png)样本链接为：  
https://app.any.run/tasks/6b9baf15-be08-4446-a07c-b1308130dd01/样本md5：183960d220750086595d8591041bd3e7样本原始名称：ExternalRetrievedPlată restantă.msg根据多家翻译引擎显示，这个邮件的名称应该是罗马尼亚语。![](../Images/c4cf2384a9f93ee4b3d39df9ac039936.png)标题跟付款、金额相关。目前只知道应该是针对罗马尼亚地区的攻击，具体的受害人信息未知，应该是批量投放用于钓鱼的。  

并且目前该样本VT上没有相关信息，只被投递到了app.any.run。

![](../Images/7dbea11b481f37b78a9de981799f6767.png)

**邮件诱饵**

邮件内容如下：![](../Images/4c40ef5e01a66672d6f32387afd01cc9.png)翻译之后邮件内容如下：  
External：\[已检索\]剩余付款早上好。我希望你身体健康，生意兴隆。附件中的证据是你方确认的逾期付款，因此我们将通知银行立即付款。热烈的问候玛丽安娜·普拉斯卡。财务总监这就是一个非常普通的钓鱼邮件，目标没有针对性，应该是批量下发的。最下面的pdf是一个下载链接，下载地址如下。hxxp\[:\]//www.mediafire.com/file/m3mcxobpymp9dy5/Plata+restanta\[.\]7z/file![](../Images/1f1d31601ab87bad39c162f41691a2bb.png)需要注意的是，这里的mediafire并不是恶意地址，而是一个免费的托管机构，有点类似于我们所使用的百度云盘。  
![](../Images/5695b2950cdacb3ec081736671462434.png)这里很明显，攻击者是将后续的payload放到了第三方平台中，然后通过URL链接去下载回来执行。  
这样做的好处是，可以节约一定的攻击成本，且不容易被溯源。如果没有猜错的话，后面的木马应该也是用的邮件的方式来传数据，也是攻击者免费申请的邮箱。这个地址还可以正常访问，下载了一个7z文件回来。![](../Images/fea3b8530fdd50cdb349cce612fcc912.png)解压缩后的文件是一个exe：  
![](../Images/455db6ff3c8cae40a562adfb1a7e7b06.png)文件命名为Plata restanta.exe。  
将罗马尼亚语翻译为中文是：重新付款.exe![](../Images/dc093ec6924dc7c0713639ca72764828.png)从钓鱼邮件来看，钓鱼的手法并不高级，就是靠大众心理，散发这种可能会有人感兴趣的邮件。

**第一阶段payload**

原始样本是带了一定混淆的，但这里的混淆很好解，就直接de4dot去混淆即可。![](../Images/64ef59cb8b8b765e9d9cb0a7f9da7da1.png)去混淆之后，样本名还是乱序韩文，但类名和方法名已经显示正常了：  
![](../Images/f322171ac6845caba9ad5ccc4791cd37.png)这里需要注意，样本执行的时候，首先执行的不是70行的Main函数的内容。  
而是95行的public static byte\[\] Bytes = Class0.smethod\_0();原因很简单，静态变量的初始化会在正式的代码执行之前完成。所以当程序运行的时候，会首先将各个静态变量赋值，这里95行处，程序就会通过Class0类的Smethod\_0方法给Bytes变量赋值。Smethod\_0方法是直接返回了一个大的数组。![](../Images/28d62886f672f875fd930e1d749b2bb1.png)分别在95行这里和Main函数里面new GClass0().method\_0();进来的地方设置断点：  
![](../Images/7bad0519d94189c166fa1f211483de07.png)![](../Images/2a2b57725b08ed0e00e95d0b23db676e.png)然后程序跑起来，选择不要中断，程序会首先命中95行的断点：![](../Images/9a481cb1f036bee892e9011f8d92bcf7.png)![](../Images/a298e93e6d53670899644b38288c781c.png)F10直接跑过这一行，拿到结果：![](../Images/80da3a28502e31e193ecaf7adac70dd7.png)然后继续F5，让程序中断在smethod\_0中：  
![](../Images/8c07a8783df651f06ebfb3ea11caeb34.png)这里可以看到，程序进来之后，直接就是通过一个循环对刚才拿到的Bytes变量进行操作。

![](../Images/51465f514b1c6c93371c70625189d216.png)

操作完成之后，可以看到这类Bytes已经被解密成了一个PE文件，这里将这个PE文件给复制出来。  
![](../Images/5e2e1c19d7f8d0eaff402925f2101ca2.png)该文件看起来像是一个C#的DLL。  
这里基本可以知道，最外层的这个程序是一个loader。用于解密PE并加载执行。加载的方式就在smethod\_0后面，使用反射委托加载：![](../Images/9aaffa21154fc311f03545e4c873d7fb.png)

1\. 通过Abs(-3) 给switch case的初始值设置为3，执行case 3分支2\. 将num赋值为2，跳转到IL\_02重新执行switch ，执行case 0分支。3\. 跳转到IL\_4A执行b.a()4\. 如果b.a()执行失败，则跳转到最后执行f.a()5\. 如果b.a()执行成，这num赋值为2，退出程序。![](../Images/229f16d922801ed02d354c0c9e65c97a.png)所以这里就是两个关键函数，一个是b.a()，一个是f.a()。

**最终阶段payload**

最后的这个payload进来就可以发现是AgentTesla的商业窃密马。程序进来之后，首先是调用了一个q函数，这个函数没有什么实际用，就是干扰分析的，根据参数计算出一个sleep时间。![](../Images/1e2b757c55ab61885640da12d83952c7.png)程序获取了一些基本信息，然后设置了几个Timer。  
![](../Images/2bb5747b94e252450ba8f91c34b24bb3.png)![](../Images/415bdf379bb9f2c6dd3d108735b48f75.png)![](../Images/90ff74f68f80482ff1edf9af67c6eca7.png)![](../Images/0d86017eb0b21c762bc28aa4d5f2e631.png)![](../Images/25004c59aab8f35a07df5927e0afbd21.png)分别对这几个timer执行的函数设置断点，然后跑起来。  
最后发现程序会在 Passwords这个函数里面，尝试获取浏览器存储的密码。![](../Images/ce23e075467a548a4fbc370e64db05d9.png)![](../Images/a3a8bbafa4dbf1a58f488facf3dbd930.png)程序会尝试获取一些主流浏览器中存储的账号密码：![](../Images/909809f45cfc732ffbbfb59f79020feb.png)直到获取成功，程序才会执行下一步的操作。比如收集本地主机的信息上传到指定的邮件服务器。
