# NAS是什么以及它的工作原理

网络附属存储（NAS）是一种文件级存储，它连接到网络，可以向开放式系统服务器提供整合的文件系统和存储服务。  

研究公司Gartner在其对NAS的定义中说：“理想情况下，NAS是独立于平台和操作系统的，对于任何应用程序来说，它都是另一台服务器，可以在不关闭网络的情况下联机，并且不需要更改其他企业服务器。”

# 

**NAS历史：网络附加存储的演进**

NAS从1980年代使用的文件服务器演变而来，为网络客户端提供对文件的访问。NAS设备通常由捆绑的硬件、软件和内置操作系统组成，它们通常使用行业标准的网络协议，如用于远程文件服务和数据共享的SMB和NFS，以及用于数据传输的TCP/IP。在企业环境中，NAS可以让IT团队简化数据存储和检索，同时整合他们的服务器和存储基础设施。

Enterprise Strategy Group的高级分析师Scott Sinclair说：“有了NAS，你就有了一个文件系统。当您设置NAS时，它看起来就像一个巨大的共享驱动器。您可以设置许多不同的共享驱动器。”“它可以利用SMB协议（主要用于Windows）或NFS协议（主要用于Linux）——这往往是NAS的两个基于大文件的协议。”

# 

**有哪些NAS规格类型？**

供应商提供NAS包括较为低端的紧凑型NAS设备、用于机架设置的传统NAS服务器以及扩展到多拍字节的高端系统。提供企业NAS产品的供应商包括 Dell EMC、NetApp、Hewlett-Packard Enterprise、IBM和Hitachi Vantara等。

# 

**NAS与SAN：有何不同？**

NAS和存储区域网络（SAN）都是基于网络的存储解决方案。NAS通常通过标准以太网连接与网络相连，而SAN通常使用光纤通道连接；NAS以文件的形式访问数据，而SAN在块级别存储数据；对于客户端操作系统，NAS显示为文件服务器，而SAN通常显示为磁盘并作为其自己独立的存储设备网络存在。

NAS通常与非结构化数据（如视频和医学图像）相关联，而SAN与结构化工作负载（如数据库）相关联。Sinclair说大多数组织都在一定程度上同时部署了NAS和SAN，而且通常是根据工作负载或应用程序来决定的。

# 

**什么是统一存储？**

统一存储（也称为多协议存储）一般是指不再将SAN和NAS作为两个独立的存储平台，对于分布式存储而言，统一存储一般是指对象存储（Object Storage）、文件存储（File Storage）和块存储（Block Storage）的统一。借助统一存储，单个系统可以支持NFS和SMB等文件协议以及光纤通道和iSCSI块存储。尽管许多供应商提供多协议选项，但普遍认为NetApp在统一存储的开发方面通常功不可没。

Sinclair说，如今，大多数中型企业存储阵列往往是多协议的。“与其买一个用于SAN存储的盒子和一个用于NAS存储的盒子，不如买一个支持所有四种协议的盒子——可以是光纤通道、iSCSI、SMB、NFS等等任何你想要的。相同的物理存储可以分配给NAS或SAN。”

# 

**横向扩展与纵向扩展NAS**

多协议存储趋势的一个例外是在企业环境中，在这些环境中，非结构化数据的需求远远低于结构化数据的需求——媒体和娱乐、医疗保健、石油和天然气等行业往往会生成更多非结构化数据。在这些情况下，企业关心的是高可扩展性，并且他们往往更多地依赖NAS而不是SAN。

特别是，横向扩展NAS对主要具有非结构化数据需求的组织具有吸引力。

Sinclair将传统的放大模型比作一列带有单个发动机的货运列车，可以根据需要牵引尽可能多的汽车。“引擎推动着火车前进，当你需要更多的存储空间时，你需要购买更多的车厢。但这种方法存在一个根本性挑战：它需要大量预购才能购买发动机，发动机的尺寸和定价必须相应地满足未来的容量需求。

相比之下，横向扩展NAS允许企业根据需要增加容量和性能。“横向扩展NAS更像是购买卡车车队。每台发动机都经过专门设计，仅能拉动与其相关的存储空间，卡车协同工作。如果我以后想增加更多性能，我可以添加另一个节点，同时扩展性能和容量。这样我就不会被巨额的前期采购所困扰。”

另一个对NAS环境至关重要的横向扩展功能是向包含上一代设备的基础架构中添加新的NAS机箱的能力。“如果一个架构能够很好地横向扩展，那么它就允许您在同一个解决方案中混合多代产品，”Sinclair说。

相反，纵向扩展架构需要将数据从旧设备转移到新设备。在具有多拍字节存储空间的环境中，此类数据迁移将非常耗时且成本高昂。

“因此，这些更大的数据环境往往包含更多非结构化数据，并且常常与NAS更相关，它们通常基于一种可以承受多代的横向扩展体系结构。”

# 

**企业NAS有什么新功能？**

NAS供应商不断添加功能以提高可扩展性、可管理性和效率。在性能方面，闪存正在对企业NAS产生影响。厂商提供混合NAS阵列，将旋转磁盘与闪存驱动器以及全闪存NAS硬件结合在一起。

在企业存储领域，截至目前闪存在SAN环境中的负载越来越大，因为与大规模非结构化NAS部署相比，SAN中的结构化数据工作负载往往更小且更容易迁移。闪存正在影响SAN和NAS环境，“但它首先主要是在SAN端，然后是在NAS端。”“话虽如此，随着机器学习和人工智能等某些工作负载的增加，他们希望以非常高的性能访问大量数据，我们看到了他们对大规模全闪存文件系统的兴趣。”

这个市场仍处于早期阶段——IDC的2020年IT基础设施调查发现，44%的受访者在全闪存阵列上运行不到40%的应用程序和工作负载——但IDC预计这一数字会增长。

一个可能更重要的趋势是软件定义的NAS系统的兴起，这些系统将数据存储在云中——无论是公共的、私有的还是混合的，这取决于用户的需求。

Kompromise总裁兼首席运营官Krishna Subramanian表示：“医疗保健和生命科学客户、制药和基因组学公司、大学、媒体和娱乐以及技术制造等数据密集型组织都在率先向云NAS迁移。基于云的NAS使用基于文件的存储，而不是著名的云对象存储，这导致成本要高得多，但在许多情况下，总体成本仍然超过本地NAS部署。

Subramanian说：“如果您需要云NAS对频繁访问的文件的性能，那么管理数据生命周期是很重要的。”“冷文件应完全从云NAS转移到成本较低但具有弹性的云对象存储（如AWS S3或Glacier或Azure Blob），并在文件级别进行透明分层，以最大限度地节省存储、数据恢复和备份成本。”

# 

**什么是消费级NAS？**

消费级NAS面向需要集中存储系统的家庭用户，该系统允许多个用户从PC和移动设备访问文件，而无需直接插入驱动器。消费级NAS可用作文件服务器、打印服务器、备份系统和媒体服务器。

在不久的将来，这个较低端的市场将会出现增长：最近的一项市场研究发现，2021年到2027年，消费者和中小企业的NAS市场将以每年7.6%的速度增长。提供消费级NAS产品的供应商包括Asustor、Buffalo、QNAP、Synology和Western Digital。
