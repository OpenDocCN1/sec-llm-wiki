# 有几个因素使得在全源评估中使用公开的信息比在机密信息中使用更困难。

鲍勃·阿什利和尼尔·威利

2021年7月16日

![](../Images/4558e94dac4421c427b6be2fc9e0d360.png)

在2021年5月27日众议院拨款委员会作证时，美军参谋长联席会议主席马克·米利将军有先见之明地指出，**一个国家必须掌握无处不在的情报监视侦察，才能赢得下一场重大战争。**事实上，在一个美国不能再依靠经济或军事超强来保证其安全的时代，我们需要更深入地了解对手的目标、意图、能力和行动，以维护我们的国家利益。参联会主席所说的挑战引出了重要的问题。我们如何确保我们的文职和军事领导人在竞争日益激烈的环境中享有决策优势？借用孙子的思想，我们怎么能在第一枪发射之前赢呢？  

高级领导一贯主张，在ISR结构中，**决策优势的关键是及时获取和分析最佳信息。**从历史上看，为满足情报要求而进行的分析主要基于政府收藏和政府技术获得的数据。与公开数据来源不同，情报官员可以借助任务敏感的情报来源和方法，以特定的人、地点和事件为目标，这些人员、地点和事件驱动着我们的决策者和指挥官的情报需求。

但是世界已经改变了。在当今的数字时代，人们和组织使用技术开展活动，将有关其背景、行动和偏好的数据投射到公共平台上。同时，私营公司围绕选择为大多数情报工作提供活力的两种追求——识别和预测个人行为——建立了商业模式。这些现象的综合结果是一个数据生态系统，将大量信息与复杂的处理工具相结合，以产生惊人的多样化见解，包括与最难的情报问题相关的见解。

这些公共数据的无处不在和可访问性破坏了政府专有情报来源方法的假定优势——国家安全界一直迟迟不能承认和接受这一现实。从公共/商业信息（PAI/CAI）的庞大信息库中衍生的开源情报（OSINT）不会取代传统情报——但至少它可以丰富和增强这些数据，对于许多情报需求来说，它可能是一种更好、更安全和更便宜的先发制人的选择。OSINT 还可以为不在活动 IC 覆盖区域范围之外的区域和主题方面提供情报来源。

不幸的是，我们实现这些好处的姿态很差，因为技术和工业已经远远超过了优化OSINT在国家安全界使用OSINT所需的法律、政策和治理。目前的国家安全框架没有预料到基于互联网的PAI的爆炸式增长、公私部门合作需求的增加，或者政府无法合法收集和出售的私营公司收集和出售的某些数据的广泛可用性。我们需要加快政策响应，为IC制定所需的法律、政策、资源和贸易手段，以自信地将OSINT的全部力量用于应对我们面临的严重威胁，同时确保获得和利用PAI/CAI保护美国人的隐私，并遵守情报行业的道德和惯例。

**这个最终状态最可怕的障碍之一是文化。**在情报界（IC）中，OSINT 的生产不被视为一种独特的情报学科，而是作为全源分析或媒体制作服务的研究事件。当开放数据源主要包括媒体和学术产出时，这种做法是合理的。然而，现在，鉴于互联网衍生的PAI/CAI的数量和多样性，OSINT比图书馆研究更类似于SIGINT。在IC中，SIGINT学科是一个强大的重心——管理各种独特的数据类型，每个类型都有自己独特的收集、发现、处理、开发、交易、共享和监督流程——由专门的机构管理和倡导。

另一方面，OSINT仍然是一个分布式活动，其功能更像是各种产业的集合。虽然 OSINT 拥有大量卓越人才，但情报界 OSINT 生产在很大程度上是基于主动性的，集成程度极小，在共同指导、标准和贸易方面几乎没有什么优势。明显缺乏共同标准、社区协调和企业治理，使得 PAI/CAI 在全源评估中使用比 IC 较成熟的学科产生的机密信息更难使用。例如，SIGINT、GEOINT 和 HUMINT 报告被分析师们非常容易理解，他们建立了交换技术，并得到一群专家的支持，他们帮助解释和评估报告。**在开源世界中，缺乏共同的交换技巧和对学科专家的回溯支持，**使得评估PAI/CAI的准确性和有效性具有挑战性，全源分析师可能不愿意使用该报告，这可以理解——这大大降低了重要资源的价值。情报界必须使OSINT成为与传统职能学科同等的真正情报学科，并充满领导力和权威，使OSINT企业能够自我管理，并建立一个品牌，灌输对开源信息的信心和信任。只有这样，OSINT才能有从山寨产业向必须成为的核心学科的倡导、承诺和结构。

**第二个重大障碍是资源。**OSINT活动的资金水平与其价值几乎不相称，尽管美国国会情报监督委员会一再要求更多地使用OSINT。可预见，缺乏专门的OSINT倡导者和拥护者会导致开源信息投资严重不足，而此时我们的国家安全态势要求曼哈顿项目的心态来获取开源数据的巨大情报价值。相反，每个情报界元素中新生的 OSINT 计划在其组织的预算雷电范围内竞争，导致可预见的匮乏的结果。

**最后，我们需要更新过时的数据处理规则和政策，旨在监管旧技术并降低不同风险。**互联网衍生信息、创新机器分析以及私人商业数据提供商的激增，为情报界提供了一个独特的机会，可以实现十年前无法想象的地理和专题报道范围。然而，缺乏全企业的法律和政策指导妨碍了PAI/CAI的广泛使用，并增加了当社区各机构对现有指导的解释不一致时，不适当活动的风险。例如，什么是固有的政府收集职能的问题直接影响到情报界和商业数据提供者之间伙伴关系的形成。私营部门正目睹商业公司的激增，这些公司不仅提供独特的数据，而且还将这些数据与分析工具捆绑在一起，从而提供新的和引人注目的见解。最大限度地提高 OSINT 的效用，需要开源社区与行业合作，这与 GEOINT 社区目前与商业图像提供商的合作伙伴方式大体相同。我们需要预期政策，使IC能够安全、有效和合乎道德地与私营部门合作，发展关键的开源收集和分析能力。

**实施OSINT对情报界的成功和我们国家的安全至关重要。**为同等对手和加剧的全球不确定性的时代创造外国情报OSINT能力将是具有挑战性的。调整结构、政策和资源需要国会、国家情报总监办公室和国防部的共同努力。情报界必须大胆行动，将OSINT转变为真正的情报纪律。政策和监督必须跟上努力，培育公私伙伴关系，使政府能够利用商业和非政府组织部门迅速取得的技术进步。资源规划必须支持这些努力，并调整预算支出，以实现OSINT对情报任务的巨大和不断增长的价值。

**我们国家面对的对手是非常真实、非常有能力和非常危险的。**我们再也不能自满了。现在是采取大胆行动实现主席对无处不在的ISR的设想的时候了，积极利用PAI/CAI将是关键。决策优势的竞争在第一枪发射之前就开始了，它跨越了所有国家权力工具：外交、信息、军事和经济。公共领域的技术和数据现在可以弥补关键知识差距。政府必须将这些能力与承诺、政策和资源相匹配和接受。如果不这样做，就可能带来灾难性的后果。我们的对手将利用这些机会.
