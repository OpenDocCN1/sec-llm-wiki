# Azure Confidential Ledger：微软推出基于区块链的安全账本

**微软推出基于区块链的安全账本Azure Confidential Ledger服务。**  

5月10日，微软宣布将于2021年9月10日停止Azure 区块链服务。已经部署的服务将继续支持到9月10日，但5月10日之后将不再支持新的部署或成员创建。当时大众普遍认为微软不再看好区块链服务，但近日，微软官方宣布将于5月25日举行的2021开发者大会上发布Azure Confidential Ledger（机密账本）的预览版。

微软称，Azure机密账本与Azure区块链服务一样，都是基于区块链分布式账本技术的。Azure机密账本在区块链的基础上加了额外的一层安全和扩展。Azure机密账本使用Azure 机密计算平台，也就是说所有的Azure 机密账本实例都运行在专用和经过完全认证的硬件支持的enclave中。

![](../Images/f24c361432fa536894044cf6329c005a.png)

Azure机密账本运行在许可区块链模型之上，提供了独特的数据完整性优势，包括不可篡改性、账本只加性，以确保账本上所有的数据都是完整的。在设计中，微软也被排除在账本之外，机密账本运行在简单的可信计算基之上，可以防止账本服务器开发者、数据中心技术人员和云管理员对账本的访问。  

机密账本技术的使用场景是哪些关键元数据记录不能被修改的场景，包括用于法规遵从性和存档目的的永久性数据记录。比如：

· 与商业交易相关的记录，如转账记录；

· 管理或控制记录，比如授予访问权限；

· 操作IT和安全事件，比如azure 安全中心告警。

在问及微软Azure是否会替代Azure区块链即服务时，微软发言人称Azure机密账本技术并不是也不会取代Azure区块链服务，而是另一种为用户提供最大化隐私的分布式账本技术。Azure机密账本使用的是机密计算技术，而ConsenSys Quorum区块链是基于Quorum区块链的开源技术，同时兼容Azure区块链服务，只是为用户提供无缝迁移体验。
