美国陆军计划投入巨资实施网络现代化

据美国陆军代理采购主管道格·布什称，约有 27 亿美元用于网络升级，超过任何其他陆军的优先领域。

一名伞兵正在组装一台收音机

华盛顿消息：尽管美国陆军现代化投入在新预算计划中大幅削减，但在该军种的 2022 年预算请求中，升级战场网络的资金增加了 25%，增加了 5.37 亿美元，总计 27 亿美元。美国陆军代理采购事务助理部长道格·布什今天上午在对工业界的讲话中说，这比用于美国陆军任何其他现代化优先事项所需的资金都多。

美国陆军有六个广泛的优先领域，而网络名义上排第四位。它排在远程导弹和大炮、地面战车和高速飞机之后。但是，远距离安全共享战术数据的能力对于所有类型的部队都至关重要，尤其是远程炮兵，它们必须与不是由自己的传感器而是由无人机、卫星和前方观察员发现的远处目标交战。

网络升级支出巨大的另一个原因是，虽然新导弹、车辆和飞机主要处于原型阶段，但美国陆军已经在批量购买新的网络技术。它目前正在对轻型步兵部队进行名为Capability Set 21的升级，并计划在 2023、2025 和 2027 年对其他部队进行进一步升级。

“我们已经部署的 Capability Set 21 美国将陆军提升到一个全新的水平，”布什在今天上午的网络技术交流会议上说。特别是，美国陆军负责指挥、控制和通信-战术 (PEO-C3T) 的计划执行官罗伯特柯林斯将军也对此进行了强调，面对像俄罗斯或中国这样的高端威胁，我们非常关注通信和生存：这意味着敌人更难发现、干扰和定位信号源，以便他们可以轰炸发射单元。

美国陆军官员在给媒体的电子邮件中提供了 27 亿美元申请的部分细目：

  • 大部分资金流向采购网络设备的 PEO-C3T，战术网络计划总体上从近 18 亿美元增加到近 23 亿美元。

  • 手持无线电增加了 2.18 亿美元，其中大部分用于升级步兵的 Capability Set 21。

  • 增加了 8900 万美元用于战术网络传输(TNT)，使部队指挥网络的骨干现代化。

  • 额外的 5200 万美元用于一项名为低成本战术无线电更换的新项目，该计划为美国陆军大量库存的模拟 SINCGARS 无线电购买负担得起的替代品。

  • 3200 万美元用于另一个新起点Tactical Communication Components，该公司购买从 Link-16 无线电到 Capability Set 21 的软件支持和技术数据的所有产品。

但是，美国陆军负责通信的副参谋长 (G-6) 中将约翰·莫里森 (John Morrison) 补充说，对战术网络（旅、营和以下）进行现代化是不够的。您还需要在战略和战术层面进行现代化——师、军和更高级别。他说，在与作战单位一起部署的战术网络与安装在永久性设施上以服务于更高总部的企业网络之间仍然存在“人为鸿沟”。莫里森说，在未来覆盖陆地、空中、海洋、太空和网络空间的远距离全域作战中，信息必须从最高指挥部快速无缝地传递到最低指挥层次。

莫里森说，美国陆军最近批准了对结合战术和企业层面的“统一网络”的第一个正式要求（这个要求被称为统一网络操作信息系统初始能力文件）。他说，“你将看到”美国陆军“最早在明年”获取网络设备的方式发生重大转变。
