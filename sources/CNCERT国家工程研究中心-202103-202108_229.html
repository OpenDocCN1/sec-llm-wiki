5月27日，美国国土安全部下属的运输安全管理局(TSA)宣布了一项安全指令，该指令将使国土安全部能够更好地识别、防范和应对管道行业关键公司的威胁。正式的指令文本，终于在28日发布。

此前，国土安全部部长亚历杭德罗.马约卡斯(Alejandro N. Mayorkas)说:“网络安全形势在不断演变，我们必须适应以应对新的和正在出现的威胁。”“最近对Colonial石油管道的勒索软件攻击表明，管道系统的网络安全对我们的国土安全至关重要。国土安全部将继续与我们的私营部门合作伙伴密切合作，支持它们的运作，提高我国关键基础设施的抗灾能力。”
该安全指令将要求关键管道所有者和运营商向美国国土安全部网络安全与基础设施安全局(CISA)报告确认的和潜在的网络安全事件，并指定一名网络安全协调员，每周7天、每天24小时待命。它还要求重要的管道所有者和运营商审查他们当前的做法，找出任何差距和相关的补救措施，以解决网络相关风险，并在30天内向TSA和CISA报告结果。
TSA还在考虑采取后续强制性措施，进一步支持管道行业加强其网络安全，并加强公私伙伴关系，这对美国的网络安全至关重要。
一、指令出台背景

自2001年以来，TSA一直与管道所有者和运营商以及整个联邦政府的合作伙伴密切合作，以加强美国危险液体和天然气管道系统的物理安全准备。作为美国保护关键基础设施免受网络安全威胁的领导机构，CISA提供网络安全资源以减轻潜在风险，包括通过一个专门的中心向组织、社区和个人传播有关如何更好地防范勒索软件攻击的信息。

有关油气管道的网络安全问题，可追溯到2001年。911事件后在政府的干预下，美国运输安全管理局(TSA)获得了确保地面运输和管道安全的法定权力。TSA在2010年制定并于2018年更新了无效自愿的管道网络安全指南（Pipeline Security Guidelines），该指南于2021年4月份，即Colonial公司遭勒索之前，进行了修订。
当地时间5月28日中午，美国国土安全部(DHS)下属的运输安全管理局(TSA)发布了一项关于加强管道网络安全的安全指令（Security Directive Pipeline-2021-01）。在拜登政府透露该法规出台的消息两天之后，TSA公布了这份文件。而20多天前，Colonial输油管道公司遭到勒索软件攻击，导致美国东南部油气供给出现严重短缺。
二、指令的主要内容
最新的油气管道网络安全指令有哪些新的要求或者措施呢？主要有六个方面的要求。

( 一 ) 设立网络安全协调员

业主/运营商必须指定并使用至少一名主要网络安全协调员。

1.业主/运营商必须在本安全指令生效、新运营开始或本节要求的任何信息变更后七天内，以书面形式向TSA提供网络安全协调员和备用网络安全协调员的姓名、头衔、电话号码和电子邮件地址。
2.网络安全协调员应当：
  1. 成为有资格获得安全许可的美国公民；
  2. 作为网络相关情报信息和网络安全相关活动以及与TSA和CISA通信的主要联系人；
  3. 每周7天，每天24小时可访问TSA和CISA；
  4. 在内部协调网络和相关的安全实践和程序；以及与适当的执法部门和应急反应机构合作。

( 二 ) 必须报告网络安全事件

业主/运营商必须报告涉及业主/运营商负责运行和维护的系统的CISA网络安全事件，包括：
1.未经授权访问信息（IT）或运营（OT）系统；
2.在信息（IT）或运营（OT）系统上发现恶意软件；
3.导致拒绝向任何信息（IT）或运营（OT）系统提供服务的活动；
4.对业主/运营商的网络基础设施的物理攻击，如故意损坏通信线路；
5.任何其他导致网络安全系统运行中断的事件
6.业主/运营商信息（IT）或运营（OT）系统或业主/运营商管道系统或设施的其他方面，或以其他方式可能造成操作中断，对液体和气体的安全和高效运输产生不利影响，包括但不限于影响大量客户、关键基础设施或政府核心政府职能，或影响国家安全、经济安全或公共健康和安全。

( 三 ) 要在12小时内及时详细报告

业主/运营商必须尽快报告B节所要求的信息，但不迟于在网络安全事件确定后12小时。必须使用CISA的报告系统表格：https://us-cert.cisa.gov/fdmis/report或致电（888）282-0870向CISA中心提交报告，如果报告时没有所需的信息，业主/运营商必须在指定的时间范围内提交初始报告，并在其他信息可用时进行补充。所有报告的信息都将以适合信息敏感性和关键性的方式得到保护。

( 四 ) 明确事件报告的细节要求

在前述要求的CISA报告中，业主/运营商必须包括以下信息：
1.报告个人的姓名和联系信息，包括电话号码或电子邮件地址。该报告还必须明确规定正在报告的信息，以满足安全分流管道-2021-01中的报告要求。­
2.受影响的危险液体和天然气管道和/或设施，包括标识信息和位置。
3.对威胁、事件或活动的描述，包括：
  1. 关于已通知谁以及已采取了什么行动的信息；
  2. 业主/运营商观察到或收集的任何相关信息，如恶意IP地址、恶意域名、恶意软件或滥用合法软件或帐户；以及任何已知的威胁信息，包括有关威胁或可能的攻击来源的信息。
4.对该事件的描述对信息或运营技术系统和操作的影响或潜在影响。这些信息还必须包括对实际的、即将发生的或潜在的服务操作、操作延迟和/或数据盗窃的评估，以及可以理解网络安全事件的影响或潜在影响的任何其他信息。
5.计划或正在考虑的所有响应的说明，包括手动备份。
6.任何其他相关信息。
( 五 ) 要进行漏洞评估
1.业主/运营商必须立即审查TSA的第7节5s2018年管道安全指南（带变更1（2021年4月））/和
  1. 评估解决业主/运营商信息和运营技术系统网络风险的当前做法和活动是否与指南一致；
  2. 确定任何差距；
  3. 确定将为弥补这些差距而采取的补救措施，以及实施这些补救措施的时间表。
2.必须使用TSA提供的表格来完成对差距的评估和识别。
[https://www.tsa.gov/sites/deftult/files/pipeline_security_guidelines.pdf] [评估表单在完成前不是敏感的安全信息。然而，一旦在表单上回答了任何问题，它就会成为敏感的受49CFR第1520部分保护的安全信息。]
业主/运营商必须在本安全指令生效之日起30天内向TSA和CISA提供一份包含本节要求的所有信息的报告。

( 六 ) 加强指令宣贯和落实

业主/运营商必须：
1.立即通过电子邮件向SurfOps-SD@tsa.dhs.gov提供收到本安全指令的书面确认。
2.立即向公司高级管理人员、安全管理代表以及负责执行本安全指令中规定的任何人员宣传本安全指令中的信息和措施。业主/运营商还应与遵守本安全指令规定的任何人分享本安全指令，其中包括但不限于，联邦、州和地方政府人员、租户和承包商。
3.简要介绍负责执行本安全指令的所有人员。
业主/运营商可通过电子邮件在SurfQps-SD@tsa.dhs.gov向TSA提交数据、视图或书面参数，对本安全指令发表评论，TSA可根据收到的意见修改安全指令。提交意见并不会延迟安全指令的生效日期。

( 七 ) 对相关术语进行了明确定义

A.网络安全事件是指在没有合法授权的情况下，实际、立即或可能危害、破坏或影响计算机、信息、通信系统或网络、计算机控制的物理或虚拟基础设施、信息系统或系统上的信息的完整性、机密性或可用性的事件。此定义包括以下事件：
1.正在调查可能的网络安全事件，但成功确定事件的根本原因或性质（如恶意、可疑、良性）；
2.可能会影响计算机、信息或通信系统或网络、由计算机或信息系统控制的物理或虚拟信息结构或系统内的信息的完整性、机密性或可用性。
B.信息技术系统是指自动采集、存储、分析、评估、操作、管理、移动、控制、显示、交换、设备或互连的系统或子系统，
C.运行中断是指对正常活动或运行的偏离或中断，导致数据、系统可用性、系统可靠性或系统控制的丢失，或表明未经授权访问或在关键信息技术系统上存在的恶意软件。
D.运营技术系统是一个通用术语，包括几种类型的控制系统，包括工业控制系统、监督控制和数据采集系统、分布式控制系统和其他控制系统配置，如可编程逻辑控制器、消防控制系统和物理访问控制系统，通常在工业部门和关键信息结构中发现。这类系统由可编程的电气、机械、液压、气动设备或与物理环境交互的系统或管理与物理环境交互的设备。
E.业主/运营商是指拥有或维持对管道设施的运营控制，或从事危险液体或天然气的运输，并被TSA认定为最关键的州际和州内天然气和危险液体输送管道基础设施和运营的人员。
F.未经授权的信息技术或运营技术系统访问是指访问未知来源；第三方或前雇员访问；未经授权访问系统fbr；并可能包括违反非恶意所有者/运营商政策，例如由其他授权访问的雇员使用共享凭证。
三、各方反应
政府官员表示，尽管指令中没有任何规定，但未能达到安全要求的管道公司将受到罚款，起价为每天7000美元。此外，该指令很可能只是更过分的监管要求的开始。在宣布该指令的新闻稿中，TSA表示，“它还在考虑采取后续强制性措施，进一步支持管道行业加强其网络安全，并加强对美国国土网络安全至关重要的公私合作关系。”
许多专家表示，该指令早该出台，但这只是朝着更严格的管道安全要求迈出的第一步。CISA前局长克里斯•克雷布斯(Chris Krebs)称，这是安全标准和性能标准制定之前的“渐进步骤”。
一些石油和天然气公司对该指令持怀疑态度，私下里说，政府推出该指令主要是为了传达一个信息，即在Colonial输油管道遭到勒索后，政府将迅速采取行动。其他油气行业代表表示，政府在起草该指令时没有充分咨询相关公司。
美国石油学会运营安全和应急响应经理苏珊娜·勒米厄(Suzanne Lemieux)提出了更为积极的官方立场。她在一份声明中表示:“API支持TSA加强网络报告的努力，并正与政府密切合作，制定事故报告政策和程序，以最好地保护我们的关键基础设施，包括管道。”“任何法规都应加强相互信息共享和责任保护，并建立在我们现有的强有力的公私合作基础上，以简化和提高我们保护国家关键基础设施的努力。”
安全公司Scythe的创始人、工业控制系统(ICS)安全非营利组织ICS Village的联合创始人布莱森·伯特(Bryson Bort)同意克雷布斯的看法，认为该指令是向新方向迈出的一步。他也认同一些石油和天然气公司的观点，认为该指令可能有些轻率。他告诉CSO:“这是为了表明他们正在做些什么，这就是为什么它除了提供一些大棒(而不是胡萝卜)之外没有什么作用。”“你不能把问题写下来，他们需要时间来建立资源来提供帮助。”
该指令的一个更清晰、更短期的好处是收集了管道公司急需的入侵统计数据。“该报告将使美国政府有数据洞察问题的程度，这是他们今天实际上没有的，”伯特说。
曾任司法部和海军部律师的罗伯特·卡塔纳奇(Robert Cattanach)现在是多西惠特尼律师事务所(Dorsey and Whitney)的合伙人，他也强调了这项指令的增量性质。“这只是第一步，”他告诉CSO。“我预计，我们还需要一段时间才能真正看到有意义的监管措施。”
Cattanach认为，该指令的一个明确结论是，管道行业“显然将不得不提高他们的检测能力。”他还认为，在管道公司有义务报告哪些项目的问题上，必须取得平衡。该指令规定，除了已知的网络安全事件外，管道公司还必须报告“可能的”网络安全事件。“你不能拖泥带水。
