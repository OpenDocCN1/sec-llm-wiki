# 美国太空组织加强合作以提升网络安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDYxOTA1NA==&mid=2247515501&idx=4&sn=3b60c5bc9dfeef71eda32821429b1e73&chksm=fa930baccde482ba8ced4e0f6912b36d0ce25283f8582f2aeabc89f6417806ebbbd13b81c481&scene=126&sessionid=1681365239#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDYxOTA1NA==&mid=2247515501&idx=4&sn=3b60c5bc9dfeef71eda32821429b1e73&chksm=fa930baccde482ba8ced4e0f6912b36d0ce25283f8582f2aeabc89f6417806ebbbd13b81c481&scene=126&sessionid=1681365239#rd)

**华盛顿消息：美国两个著名的航空航天工业集团正在网络信息共享、感知、教育和宣传方面进行合作，以改善太空运行的网络安全性。**  

美国宇航研究所（AIAA）和太空信息共享与分析中心（SISAC）之间达成协议加强网络安全，其他行业最近发生的网络事件突显了信息共享的不足。明显缺乏信息共享最近已经被国会提出了无数次，行政机构最近也为解决国防承包商和联邦机构网络安全发布了行政命令。

**该协议值得关注，因为航天工业正在积极推进网络信息共享，而不是等待法律或法规强迫政府采取行动。**在网络安全行业，主要的联邦机构（例如CISA）和国会之间，就改进网络信息共享的必要性和好处达成了广泛共识，但此类举措可能会阻碍精确地做到这一点。这种协议带来的伙伴关系可以作为其他行业在网络安全信息共享、感知、教育和沟通方面的典范。

**“我们在推动艺术和航天科学方面的想法是，网络安全信息共享发生在更根本的层面，”**史蒂夫李，AIAA负责网络安全和新产品开发的高级经理在一个采访中表示。他说：“我们经常互相交谈，”他指出在交流网络安全时诸如共享之类的事情的重要性。

这项合作扩大了两个组织的工作量。空间ISAC将提供直接适用于航空航天业的特定于网络的信息和资源。AIAA将为特定领域的专家知识以及行业，教育和出版领域做出贡献。

SISAC始于2019年，是1990年代以来成立的25家国家SISAC之一，旨在通过共享有关漏洞，缓解措施和应对方案的信息来帮助美国联邦机构与行业合作，以阻止并从网络攻击中恢复过来。正如人们可能记得的那样，SISAC是上届政府国家安全委员会的关键优先事项。

**AIAA是世界上最大的航空航天技术学会。**除了这种合作关系外，AIAA还开展了其他以空间为重点的网络安全计划，例如在本周的RSA会议（网络行业最大的活动）和DEFCON的航空航天村（这是运行时间最长的行业会议之一）上的“夺旗活动”。网络专业人士。AIAA也与航空ISAC达成了类似的协议。

**AIAA和空间ISAC的成员包括航空航天国防承包商以及新兴的私人太空领域的公司。**SISAC处于网络战中。对我们来说，将我们在科学研究方面的传统与从业者联系在一起才有意义。”

SISAC执行董事艾琳·米勒（Erin Miller）在新闻稿中表示，两个小组的共同努力“是一个很好的补充。我们现在正在正式建立伙伴关系，并期望通过劳动力发展，教育，太空部门网络安全意识等方面的努力将看到影响。”

媒体向SISAC寻求进一步的评论，但在发布前没有回音。

许多人可能只考虑与地面计算机、服务器和网络有关的网络安全，但是航天工业面临着独特的威胁介质，例如卫星黑客攻击。Lee还指出，还有一些共同的威、脆弱性和风险，航天工业可以从其他行业的网络事件中学习。

Lee声称，“我们正在监视所有这些网络事件。” “我们认为这是因为它发生在\[该行业\]那里，所以它不可能在\[航天行业\]这里发生。当我们考虑网络时，我们不仅在考虑太空资产。我们显然生活在一种联系的方式中。”

Lee对航天工业网络安全的主要关注中的两个与其他行业所面临的类似。

“我认为太空网络安全最大的担忧和问题是企业IT和（运营技术-OT）之间的接口，以控制发射和系统，” Lee说。如人们所知，NSA最近建议所有行业审查其OT安全性。在输油管道和佛罗里达州奥德马尔水厂网络事故突出等行业OT安全问题。

“另一件事是供应链，”李说。“我们系统中包含哪些芯片、小工具和代码？人们越来越担心。” 随着行业的发展，空间供应链的风险也越来越复杂。Lee说：“这就像我们是自己成功的受害者。” “当事情变小时，将坏人拒之门外更容易。”

Lee指出，航天工业中的人们通常专注于设计和开发，**而网络安全通常只是事后才想到的，与许多行业相差无几。**他想看到这种变化。他说：“从概念化的角度出发，就像我们对待安全性一样，我们也应该考虑网络安全性。” “如果没有制造机翼和引擎的人与设计公共汽车的人之间进行有力的对话，我们永远不会设计和制造任何成熟的东西。”

**这两个组织过去曾进行过合作。**2020年，SISAC和AIAA在AIAA的ASCEND会议上合作进行了以网络为中心的桌面演习，该演习汇集了来自全球的3,000名航空航天专业人士。该计划的基础是过去的努力，并将其扩展到未来。

“这是一场漫长的比赛，”李说。“这将需要一段时间才能站稳脚跟。”

GA-ASI参与了美国太平洋舰队的无人综合作战问题

圣迭戈- 2021年4月28日-通用原子航空系统公司（GA-ASI）参加了美国太平洋舰队的（PACFLT）无人作战综合问题'21（UXS IBP 21），4月21日至26日，2021 UXS IBP 21将有人和无人作战能力整合到最具挑战性的作战方案中，以产生战斗优势。**该演习旨在直接告知战士，作战中心和开发商，以进一步将无人驾驶能力纳入日常的舰队行动和战斗计划中。**

在UxS IBP 21期间，GA-ASI MQ-9A第5座无人飞机系统（UAS）充当了MQ-9B SeaGuardian的替代品，并首次展示了：与美国海军水面舰艇和飞机的成功Link连接性; 合作的反潜战（ASW）行动，包括首次成功从无人机系统降落的高空声纳浮标；与美国海军P-8波塞冬号和MH-60R海鹰自动识别系统（AIS）的关联；通过UAS在全球海事指挥和控制系统（GCCS-M）上交换Link 16数据；以及从UAS到美国海军驱逐舰的远程超视距目标。

“我们在这次演习中与美国海军的合作伙伴关系和合作非常有益，并为美国海军和我们的外国伙伴应对革命性的变化奠定了基础，以应对完成分布式海事业务日益增加的挑战和复杂性，” ，GA-ASI国防部战略发展副总裁。“我们成功地首次展示了几种突破性的能力，我们期待着利用这一势头继续开发和测试更先进的能力，这些能力将为国内外的战斗员提供巨大的价值。”

GA-ASI通过开发可以安全地进行飞行的远征MQ-9B SeaGuardian，扩大了MQ-9在美国政府和外国客户中的传统作用，以支持包括ASW在内的海上情报，监视和侦察（ISR）任务。在恶劣天气和非隔离空域中运行。
