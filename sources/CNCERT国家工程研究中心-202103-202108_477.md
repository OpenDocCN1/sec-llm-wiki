当地时间2020年9月9日，德国杜塞道夫大学医院（Duesseldorf University Hospital）在遭到勒索病毒攻击，被迫关闭急诊室，使得该院必须将一名急诊病患转至20英里（32公里）外的医院，造成该名病患死亡，而这很可能是全球首起因勒索软体攻击而致死的案件。01**事件经过**  
  
  

**1、2020.9.8**

即患者死亡发生前约24小时，病毒在德国杜塞道夫大学医院爆发，利用了美国思杰公司（Citrix）旗下产品Citrix ADC及Citrix Gateway存在的一个严重RCE漏洞CVE-2019-19781成功入侵并加密了大约30台医院服务器，留下勒索信息，指示杜塞尔多夫医院所属的海因里希·海涅大学与攻击者联系。

**2、2020.9.9**

当地的一些报道表明，黑客无意攻击医院，实际上是在试图针对其所属大学。杜塞尔多夫警方最终与攻击者进行了沟通，并告诉他们袭击事件袭击的是一家医院，据报道，攻击者撤回了勒索要求，提供了解密密钥来解锁服务器后失去联系。在上述沟通期间，一名有生命危险的妇女被救护车送往杜塞道夫大学医院救治，然而因为IT系统受到勒索软体攻击医疗人员无法取得患者数据，医院迫不得已下只能延后所有手术，并将急诊患者转诊至其他医院，妇女被转诊送往32 公里外的一家医院，治疗也被延后了一个小时，这导致妇女最终回天乏术。

02**利用漏洞分析**  
  
  

此次勒索病毒利用的攻击漏洞为CVE-2019-19781，攻击范围涉及美国思杰公司（Citrix）旗下多款产品：

Citrix ADC and Citrix Gateway version 13.0 all supported builds

Citrix ADC and NetScaler Gateway version 12.1 all supported builds

Citrix ADC and NetScaler Gateway version 12.0 all supported builds

Citrix ADC and NetScaler Gateway version 11.1 all supported builds

Citrix NetScaler ADC and NetScaler Gateway version 10.5 all supported builds

该漏洞披露于2019年底，远程未授权攻击者可利用该漏洞对目标系统执行任意命令，即所谓远程命令执行漏洞（Remote Command/Code Execute，RCE）。

漏洞exploit如下：

https://github.com/mpgn/CVE-2019-1978

https://github.com/trustedsec/cve-2019-19781

https://www.anquanke.com/post/id/197074

针对这一漏洞，Citrix于2020年1月底发布了相关补丁，负责发布网络安全警告的德国机构BSI从1月开始在推特上发布了与该通报的链接。但是似乎德国杜塞道夫大学医院并未及时处理相关漏洞。

03**勒索病毒知识简介**  
  
  

勒索病毒，是一种新型电脑病毒，主要以邮件、程序木马、网页挂马等形式进行传播。该病毒性质恶劣、危害极大，一旦感染将给用户带来无法估量的损失。这种病毒利用各种加密算法对文件进行加密，被感染者一般无法解密，必须拿到解密的私钥才有可能破解。

**勒索病毒常见攻击方式如下：**

通过用户浏览网页下载勒索病毒，攻击者将病毒伪装为盗版软件、外挂软件、色情播放器等，诱导受害者下载运行病毒，运行后加密受害者机器。

通过系统漏洞攻击，系统漏洞是指操作系统在逻辑设计上的缺陷或错误，不法者通过网络植入木马、病毒等方式来攻击或控制整个电脑，窃取电脑中的重要资料和信息，甚至破坏系统。同个人用户一样，组织用户也会受到系统漏洞攻击，由于组织局域网中机器众多，更新补丁费时费力，有时还需要中断业务，因此组织用户不太及时更新补丁，给系统造成严重的威胁，攻击者可以通过漏洞植入病毒，并迅速传播。席卷全球的Wannacry勒索病毒就是利用了永恒之蓝漏洞在网络中迅速传播。

通过应用漏洞攻击，勒索病毒利用的漏洞工具除了广为人知的永恒之蓝系列等系统漏洞外，新型的勒索病毒一般还携带许多Web应用漏洞利用工具，比如 JBoss 反序列化漏洞(CVE-2013-4810)、Tomcat 任意文件上传漏洞（CVE-2017-12615）、Tomcat web 管理后台弱口令爆破、Apache Struts2 远程代码执行漏洞 S2-045 等。此次杜塞道夫大学医院勒索病毒事件中，勒索病毒采用的Citrix ADC and NetScaler Gateway RCE（CVE-2019-19781）就是典型的应用漏洞攻击行为。

通过远程访问弱口令攻击，由于企业机器很多需要远程维护，所以很多机器都开启了远程访问功能。如果密码过于简单，就会给攻击者可乘之机。很多用户存在侥幸心理，总觉得网络上的机器这么多，自己被攻击的概率很低，然而事实上，在全世界范围内，成千上万的攻击者不停的使用工具扫描网络中存在弱口令的机器。有的机器由于存在弱口令，被不同的攻击者攻击，植入了多种病毒。这个病毒还没删除，又中了新病毒，导致机器卡顿，文件被加密。

通过钓鱼邮件攻击，用户受到钓鱼邮件攻击，用户现在使用邮件频率较高，各种业务需要不得不打开很多邮件，而一旦打开的附件中含有勒索病毒，就会导致计算机遭受遭受攻击。

**勒索病毒具备以下特点：**

**( 1 ) 加密用户文件，导致用户文件丢失，业务瘫痪**

勒索病毒的传播极快，可以在短短几个小时内让大部分地区的电脑感染病毒。如2017年“WannaCry”勒索病毒在中国的扩散，最早是从互联网开始，而后扩散至学校、医院、公安等公共服务行业，对行业内网系统危害极大，甚至一度导致各类基础设施服务系统瘫痪。

**( 2 ) 索取解密赎金**

一旦勒索软件发动攻击，并攻击成功，损失几乎是无法阻挡的。如果不支付赎金，那么恢复数据就需要很高的成本。安全和 IT 员工需要全天候进行工作，将系统恢复至运行状态，这个过程中需要支出设备、运营成本等。如果数据恢复成本大于赎金成本，那么受害组织很有可能会付钱。否则攻击者会“撕票”，然而这里面也可能会有支付完赎金被骗的情况发生。

04**勒索病毒技术原理**  
  
  

从技术行为上看，一个勒索病毒至少包含3个不同模块，分别应用于勒索过程中的不同阶段。

**( 1 ) 攻击模块：前勒索阶段**

勒索病毒攻击模块，主要通过携带各类漏洞exploit、密码字典等形式，对

攻击目标进行漏洞检测以及服务口令爆破，若目标机器存在相应漏洞或弱口令，则将被攻击模块成功攻破，从而获得对该主机的用户权限甚至管理员权限。获得权限后，本地将被执行加密模块，同时当前主机将被攻击模块继续利用作为跳板对同网段其他主机进行攻击扩散。

攻击模块的主要目标是感染尽可能多的主机，获得尽可能多的主机控制权，为后续加密主机的基数提供保证。在攻击模块执行的过程中，加密尚未开始，因故我们称之为“前勒索阶段”。该阶段实际会有较为明显的安全告警，例如流量分析、威胁监等监测设备、系统EDR等均可能产生大量告警日志，例如 “SMB 远程溢出攻击”、“弱口令爆破”等，此类迹象很可能是勒索病毒病毒在尝试攻击扩散。

## **( 2 ) 加密模块：中勒索阶段**

当攻击模块成功获取本地权限后，加密模块将开始运行，通过公钥加密或对称密钥加密等形式进行本地文件加密操作。

此处以公钥加密手段为例，则加密模块流程如下图所示。

![](../Images/a1894a49dffe6d07c5dd1199deb97943.png)

病毒攻击自身持有公私密钥对Q，并将其中公钥Q包含在病毒加密模块中，自身持有私钥Q，当加密模块执行时，将在用户本地随机生成另一对公私密钥对Z，使用其中公钥Z进行本地数据加密，并利用公钥Q对私钥Z进行加密后上传给攻击者。

至此，根据非对称密钥原理，用户本地数据有公钥Z加密，只有私钥Z可对其解密，而私钥Z被攻击者的公钥Q加密，可解密公钥Q的只有病毒攻击者持有的私钥Q，因此受害用户将不得不于攻击者联系，获得其提供的解密后的私钥Z以解密本地文件。

在该阶段勒索病毒将对文件造成真实损害，因故称之为中勒索阶段，勒索病毒执行加密模块后会加密特定类型的文件，不同的勒索病毒会加密几十到几百种类型的文件，基本都会包括常见的文档、图片、数据库文件。当文件夹下文件变成如下图所示的统一异常且不可用后缀，则很可能已经被加密了。

![](../Images/d17cd880747659ef3db62bf5c0df09ce.png)

## **( 3 ) 勒索模块：后勒索阶段**

一旦勒索病毒加密完成，其往往将进行部分模块自毁，以防止自身加密逻辑或内存残留信息被利用于解密，通常会自毁加密模块甚至攻击模块，并释放勒索模块向受害者用户提供勒索信息，要求受害者用户通过特定渠道支付赎金。

勒索病毒加密文件的最终目的是索要赎金，所以会在系统明显位置如桌面上留下文件提示，或将勒索图片更改为桌面。勒索信绝大多数为英文，引导被勒索的用户交赎金。

在该阶段，主要勒索过程均已完成，只剩余提示勒索信息，因故称之为后勒索阶段。

05**勒索病毒响应措施**  
  
  

如前所述，主机在感染勒索病毒后，除了自身会被加密，勒索病毒往往还会利用这台主机去攻击同一局域网内的其他主机，所以当发现一台主机已被感染，应尽快采取响应措施，以尽可能减少损失。

## **( 1 ) 隔离中毒主机**

### 物理隔离

断网，拔掉网线或禁用网卡，笔记本也要禁用无线网络，防止病毒进一步扩散。

### 逻辑隔离

设置访问控制、关闭端口、修改密码。

访问控制可以由防火墙等设备来设置，禁止已感染主机与其他主机相互访问；视情况关闭 135、139、445、3389 等端口，避免漏洞被或 RDP（远程桌面服务）被利用；尽快修改被感染主机与同一局域网内的其他主 机的密码，尤其是管理员（Windows 下的 Administrator，Linux 下的 root）密码， 密码长度不少于 8 个字符，至少包含以下四类字符中的三类：大小写字母、数字、 特殊符号，不能是人名、计算机名、用户名等。

## **( 2 ) 排查其他主机**

隔离已感染主机后，应尽快排查业务系统与备份系统是否受到影响，确定病毒影响范围，准备事后恢复。如果存在备份系统且备份系统是安全的，就可以将损失降到最低，也可以最快的恢复业务。

## **( 3 ) 主机加固**

主机感染病毒一般都是由未修复的系统漏洞、未修复的应用漏洞或者弱口令导致，所以在已知局域网内已有主机感染并将之隔离后，应检测其他主机是否有类似的问题存在。

系统漏洞可以使用免费的安全软件检测并打补丁。

应用漏洞可以使用免费的漏扫产品（AWVS、APPScan 等）检测并升级或采用 其他方式修复。

弱口令应立即修改，密码长度不少于 8 个字符，至少包含以下四类字符中的三类：大小写字母、数字、特殊符号，不能是人名、计算机名、用户名等。

06**勒索病毒预防建议**  
  
  

勒索病毒的防治主要预防为主，加强整体网络安全管理，以及有效的技术治理手段。

## **( 1 ) 增强安全意识**

除了漏洞利用与暴力破解外，最多的感染勒索病毒的原因就是利用网页挂马、垃圾电子邮件与捆绑恶意程序，所以日常使用网络时要有以下安全意识：

不访问色情、博彩等等不良信息网站，这些网站通常会引导访客下载病毒文件或发动钓鱼、挂马攻击。

不轻易下载陌生人发来的邮件附件，不点击陌生邮件中的链接。

不随意使用陌生U盘、移动硬盘等外设，使用时切勿关闭防护软件比如 Windows 自带的 Windows defender，避免拷入恶意文件。

不轻易运行 bat、vbs、vbe、js、jse、wsh、wsf 等后缀的脚本文件和 exe 可执行程序，不轻易解压不明压缩文件。

定期查杀病毒，清理可疑文件，备份数据。

## **( 2 ) 增加口令强度**

勒索病毒最常用的攻击方式是利用永恒之蓝漏洞和爆破 RDP（远程桌面协议）等服务弱口令，为应对后者应立即修改系统和各应用（MySQL、SQLServer 等）的弱口令、空口令、多台服务器共用的重复口令。强密码长度不少于 8 个字符，至少包含以下四类字符中的三类：大小写字母、数字、特殊符号，不能是人名、计算机名、用户名、邮箱名等。

在企业中可以通过密码策略让电脑使用者必须设置一个复杂密码，Windows 操作系统可以通过配置密码策略来实现。

## **( 3 ) 修复系统漏洞**

在微软发布高危漏洞公告后应尽快修复系统存在的漏洞，避免被恶意利用。微软安全响应中心：https://docs.microsoft.com/zh-cn/security-updates/。

## **( 4 ) 修复应用漏洞**

勒索病毒利用的漏洞工具除了广为人知的永恒之蓝系列，新型的勒索病毒一般还携带许多 Web 应用漏洞利用工具，比如 JBoss反序列化漏洞(CVE-2013-4810)、Tomcat任意文件上传漏洞（CVE-2017-12615）、Tomcat web管理后台弱口令爆破、Apache Struts2远程代码执行漏洞 S2-045等。此次杜塞道夫大学医院勒索病毒事件中，勒索病毒采用的Citrix ADC and NetScaler Gateway RCE（CVE-2019-19781）就是典型的应用漏洞攻击行为。所以应定期检测并修复漏洞，并及时更新版本。

## **( 5 ) 端口管理**

除了必要的业务需求应关闭 135、139、445、3389 等端口，及时需要对部分机器开放，也应做出配置仅限部分机器可访问。通过防火墙配置、安全软件隔离或准入管理。

## **( 6 ) 安装诺亚防勒索**

美创诺亚防勒索系统采用主动防护的模式，利用底层驱动技术，监控所有进程的写操作，对文件的“写”操作判断，对于非法写操作进行阻断。通过控制文件的“写”权限，从而对勒索病毒的写操作进行控制，就算被植入勒索病毒，勒索病毒也无法对文件进行加密，就能保证该办公电脑或者服务器彻底免除勒索病毒的困扰。通过白名单机制监控所有进程，精准识别文件的操作行为，确保只有被允许的合法操作才能被执行，避免勒索病毒对文件加密和修改。即使业务系统未及时安装补丁，可防止漏洞被利用进行勒索加密。
