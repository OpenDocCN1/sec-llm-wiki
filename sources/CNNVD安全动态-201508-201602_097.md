# 三星SRN系列网络硬盘录像机中存在多个安全漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODY1OTM5OQ==&mid=402353051&idx=1&sn=ea51aa28f794989c1f5c361d372cc5fa&chksm=09dd2ab33eaaa3a5c233e4f3b78fbc86c31b4de4616af0e4e4c1c127ac7ee17972f4b9361187&scene=126&sessionid=1681378390#rd](http://mp.weixin.qq.com/s?__biz=MzAxODY1OTM5OQ==&mid=402353051&idx=1&sn=ea51aa28f794989c1f5c361d372cc5fa&chksm=09dd2ab33eaaa3a5c233e4f3b78fbc86c31b4de4616af0e4e4c1c127ac7ee17972f4b9361187&scene=126&sessionid=1681378390#rd)

经过研究能够证实，在三星SRN系列网络硬盘录像机中存在多个安全漏洞，严重影响设备的数据安全。攻击者利用这些漏洞，无需进行身份验证，便可直接远程控制设备。三星要感谢CMU CERT(卡内基梅隆大学互联网安全事件报告中心)的协助，对该漏洞的研究提供了很大的帮助。

  

具体说来，安全人员发现了三种不同的安全问题，以下将对每个问题展开说明。

**1.Arbitary file read****（CNNVD-201601-231）—所有文件可任意读取**

攻击者可自行编写一个未授权的PHP页面，来读取任一本地文件。这一步对于网络攻击者来说，仅仅只是小菜一碟。因为只要他们想读取哪个文件，都可以在所获取的URL参数中得到那个文件名。

比如，想要读取本地文件/etc/shadow，就必须执行下面的请求：

![](../Images/05e000c98e022f5c07d269eb35b92e3d.png)  

攻击者可以利用该漏洞读取一个存储Web界面凭证的本地文件。在测试设备中，把上述的文件，按/root/php\_modules/lighttpd/sbin/userpw,路径保存，该文件包含以明文形式保存的用户名和密码。这样就给攻击者提供了机会，他们想要盗取该数据，可以说是不费吹灰之力。

  

**2.Weak firmware encryption(CNNVD-201601-229)****—固件加密保护程度不足**

设备供应商告诉每一个购买SRN系列产品的顾客说，他们可以在SRN的官网上对相关软件进行更新。但是，固件图像用一种专有模式进行了加密，顾客无法做到这一点。

例如：在文件mproject\_add\_header.dtb中，最开始的几个字节包含一个隐藏标识名（EncryptFileFormat）,是否带有这个标识名，就是文件加密与否的标志。

![](../Images/27146d615c9ebc03b047473dbff6752f.png)  

然而，当看到文件末尾时，会发现一个反复出现的字节模式：

![](../Images/30f29306ce327f85639aaf5f9b136cb5.png)  

由于考虑到文件是经过加密的，同时假设设备供应商使用了一个标准的加密方案，一些加密算法就会产生这样的循环模式。这其中最显著的假设就是异或加密（XOR encryption）。

通常当文件位数不够时，会用零在文件末尾进行补足。安全人员推测该文件在进行异或加密时，所用的16字节加密密钥应该是 e854 1db6 ad50 4e6f b70e 7869 1acb c98d。我们就试着用该密钥对固件和文件进行解密，结果都成功了。

![](../Images/e367baad098cf4b4866c4c27fc1fe3d9.png)  

同一个异或加密码可用于解密该固件的其他组件。包含有ext2文件系统的任一一个元素，都有着与设备主分区相同的属性。

  

**3.User enumeration(CNNVD-201601-230)****—用户枚举漏洞**

远程攻击者可通过采用不同的用户名和密码进行试探登录，查看返回的错误消息的方式，来枚举出正确的Web用户名。

例如：当输入了一个无效的用户名时，系统就会弹出一个“ID错误”的页面。请求如下所示：

![](../Images/801413eece2a8eacbd7ac124dd15306d.png)  

然而，当输入用户名和密码后，若系统提示“密码错误”，则说明该用户名是正确的。

![](../Images/2113b350abd2f97dd2076de0c2b00771.png)  

根据研究：型号为Samsung SRN-1670D的网络硬盘录像机受漏洞的影响最为严重，其他类似的设备和软件也可能受到了影响。
