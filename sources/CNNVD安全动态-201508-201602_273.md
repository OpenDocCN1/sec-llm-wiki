# Mabouia：第一款Mac OS X勒索赎金软件

ransomware，是一种通过某种方式感染电脑，限制用户访问系统，操作者会借此要挟用户赎金的恶意软件。普通用户几乎不可能单独破解ransomware，这样一来，剩下的唯一办法就是花钱用该恶意软件制作者的密码来解锁。现在市面上已经有不少ransomware，而这几天，针对Mac OS X的ransomware也出现在市面上。

Rafael Salema Marques，一名巴西籍的网络安全研究员，昨日公布了Mabouia ransomware的POC，这是史上第一款针对Mac OS X的ransomware。研究人员表示，6600万的Mac OS X用户应该警醒了，没有恶意软件针对苹果电脑的神话将被打破。

Mabouia是由C++编写，感染后使用XTEA加密算法将用户文件进行32层加密。此外，考虑到ransomware只会修改个人文件，Mabouia的执行并不需要超级用户权限。
