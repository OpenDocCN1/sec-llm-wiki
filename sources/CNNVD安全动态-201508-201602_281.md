# Windows XP延期支持合约到期，英国政府的计算机陷入危险境地

微软早在一年半以前就已经停止了对WindowsXP系统的后续支持，但这并不意味着大家都已经抛弃了这款系统，其中还在用这套系统的就包括了英国的不少组织，其中还有一些慈善团体，在英国政府与微软的XP延期支持合约到期之后，这些组织的计算机将处在不受保护的状态。

比如乐施会（Oxfam），其现有团体组织已遍及全球94个国家，英国的这家慈善机构就还在使用Windows XP系统，其内部人员表示他们需要自己花钱升级到Windows 7系统，因为英国政府已经结束和微软之间的合约。

2014年时，英国政府跟微软签订了为期一年多的Windows XP延长支持合约，确保政府部门、国务院、学校、慈善机构等的计算机能持续获得安全升级。这份合约是在今年4月份到期的，所以那些还在用Windows XP的设备已经不会再收到任何更新了。目前乐施会还有数千台设备仍在运行Windows XP系统，他们宣称政府没有给他们任何选择，唯有自己做系统升级，他们也的确已经打算这么做了。

乐施会CIOPeter Ransom表示：“我们是在政府合约下才得以延续使用Windows XP至今的，政府今年没有再投入，我们也就置身于网络风险之中了。微软给了我们一些弹性的支付选择，但我们仍然是需要自己花钱的。”

比较意外的是，乐施会没有选择Windows 10或Windows 8.1，而选了Windows 7，Peter Ransom认为这是更好的选择，而且未来也有可能升级到Windows 10。
