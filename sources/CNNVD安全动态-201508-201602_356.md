# 警告！请立刻关闭Windows 10的键盘记录

Windows 10是美国微软公司所研发的新一代跨平台及设备应用的操作系统。用户在使用最新版的Windows 10操作系统时,微软公司可以跟踪用户所输入的每一个字符,以及用户与语音助手Cortana所说的每一句话。

去年秋天,曾报道过,微软公司公开地将“键盘记录器”加入了Windows 10操作系统的技术预览版本中。而且微软公司还表示,他们可能会收集用户的语音信息以及通过外部交互设备所输入的字符。很多技术人员还以为微软公司只会在Windows 10的技术预览版中添加键盘记录器,而且目的也只是为了进行系统测试。但事实证明,这种想法是错误的。

Windows 10操作系统的公开发行版是由微软公司免费提供给广大用户的,而公司还是想办法在该系统中加入了键盘记录器。除了一大堆的隐私问题以外,当使用键盘,语音,屏幕,鼠标以及写字板的时候,在该系统中还会有一个软件组件来跟踪操作行为。但是,具体的情况可能会比想象的更加复杂。

Windows 10的键盘记录器不仅仅只是一个简单的“键盘记录器”。实际上,这个系统组件其实并不是一个键盘记录器,从某种程度上来说,这是一款恶意软件。而且情况可能比我们想象的更为严重,微软公司曾公开表示:“当你通过语音,手写板,或键盘来与你的Windows设备进行交互,微软公司会收集你的语音信息,手写记录,以及键盘的输入数据,除此之外,我们还会收集你的日历信息以及通讯录信息等等。”

由于Windows 10操作系统中存在一系列的隐私问题,微软公司也因此名声扫地。在大约一周之前,微软公司还将Windows 10操作系统中的数据采集功能和用户行为跟踪功能添加进了Window 7和Windows 8操作系统中,这样的行为也使得很多用户开始担心他们的隐私信息了。
