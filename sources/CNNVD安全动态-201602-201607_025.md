# 戴尔网络安全产品被曝存在后门账户

据国外媒体报道，安全研究人员发现多个Dell SonicWall产品存在6大安全问题，其中一个就是存在隐藏账号，易于猜测登录凭证。

研究人员表示，这些安全漏洞出现在Dell SonicWALL全球管理系统（Global Management System, 缩写GMS）中。GMS是集中式管理系统，负责报告与监控SonicWALL设备的解决方案，比如公司的VPN与防火墙。

根据今日发布的公告显示，研究人员揭示了使用易猜测密码的隐藏默认账号。公告内容如下：

![](../Images/3dc7fbc7309392503a0eb3ed78f47aba.png)

隐藏账号能通过CLI客户端添加非管理用户，而CLT客户端可以在GMS网络应用程序的控制台（CONSOLE）界面进行下载。之后，非管理用户便可以登录WEB界面并修改管理员密码，在注销时提升管理员权限并使用新密码以管理员身份再次登录。这能让攻击者完全控制GMS界面以及所有SONICWALL设备。

另外，研究人员还发现两个未经验证的root命令注入，会通过Dell设备上的root权限进行远程代码执行（remote code execution，缩写RCE）。

另外，还有两个未经验证的XML外部实体注入（XML External Entity Injection）漏洞。同时，还存在一个漏洞，允许通过GMC服务改变未经验证的网络配置。

Dell承认漏洞的存在，今日为所有受影响的用户发布补丁。Dell并不是唯一被曝其设备存在后门的网络设备厂商，先前Fortinet与Juniper也存在同样的问题。
