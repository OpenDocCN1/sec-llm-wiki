# 服务器界的Windows XP--Windows Server 2003

传统软件停止支持并不意味着软件同现实生活中的联系就此中断。据最新报道，尽管Windows Server 2003系统已经于2015年7月14日停止支持，但全球范围内超过一半（53%）的企业在服务器上至少运行一个实例。

![](../Images/ba5be9aea3980eb021bd029d30a9d160.png)  

因为过期的系统在网络上运行意味着安全隐患，也有不少企业已经开始开展迁移工作，然而这个进程是非常缓慢的。根据调查自2015年9月份至今长达10个月的时间内，Windows Server 2003在使用率上的占比（60%）仅仅下降了7%。为何迁移工作推进如何缓慢，IT管理员认为没有立即升级的必要、缺乏升级时间、预算紧张等都是关键因素。

Windows Server 2008目前依然是市场上最受欢迎的系统版本，占据45%的市场，随后是Windows Server 2003，占比为24%。微软总共占据了88%的市场。
