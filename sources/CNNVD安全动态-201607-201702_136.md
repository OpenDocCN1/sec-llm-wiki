# 中国信息安全测评中心博士后招聘启事

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODY1OTM5OQ==&mid=2651434748&idx=1&sn=0892bd15b1a7a6ba63fb6b08806899e9&chksm=802fefd4b75866c2ca16c4a949a1035118109f8573938ff36a1bdb8612c1e09c60b2e6b59c3e&scene=126&sessionid=1681378143#rd](http://mp.weixin.qq.com/s?__biz=MzAxODY1OTM5OQ==&mid=2651434748&idx=1&sn=0892bd15b1a7a6ba63fb6b08806899e9&chksm=802fefd4b75866c2ca16c4a949a1035118109f8573938ff36a1bdb8612c1e09c60b2e6b59c3e&scene=126&sessionid=1681378143#rd)

中国信息安全测评中心（以下简称“测评中心”）是我国专门从事信息技术安全测试和风险评估的权威职能机构。测评中心的主要职能包括：负责信息技术产品和系统的安全漏洞分析与信息通报；负责党政机关信息网络、重要信息系统的安全风险评估；开展信息技术产品、系统和工程建设的安全性测试与评估；开展信息安全服务和专业人员的能力评估与资质审核；从事信息安全测试评估的理论研究、技术研发、标准研制等。

测评中心下设国家信息安全漏洞库运行管理中心（简称“漏洞库运管中心”），负责国家信息安全漏洞库（CNNVD）的建设、发展规划、运行管理等工作。CNNVD是测评中心为切实履行漏洞分析和风险评估职能，负责建设运维的国家级信息安全漏洞数据管理平台，旨在为我国信息安全保障提供服务。经过几年的建设与运营，CNNVD在信息安全漏洞搜集、重大漏洞信息通报、高危漏洞安全消控等方面发挥了重大作用，为我国重要行业和关键基础设施安全保障工作提供了重要的技术支撑和数据支持。随着CNNVD漏洞库漏洞数量不断扩大、影响力逐步提升，目前成为收录漏洞数目最多、漏洞属性最全、内容质量最高的国家级信息安全漏洞库。

 

根据漏洞库运管中心工作需要，现面向全国公开招聘博士后科研人员2名，竭诚欢迎优秀博士前来应聘。

 

**1、工作内容：**

从事漏洞库体系建设相关研究，主要内容包括漏洞消控技术/机制、漏洞标准体系、信息安全法律法规、漏洞库发展/建设规划等。

 

**2、招聘条件：**

（1）在国内著名高校或科研机构获得博士学位，品学兼优、身体健康；

（2）信息安全、网络安全、计算机、管理等相关专业，具有漏洞库建设、管理经验者优先考虑；

（3）年龄一般在35周岁及以下，特别优秀者可适当放宽；

（4）具有较强科研能力和良好的团队协作精神，参与过信息安全相关课题研究工作；

（5）具有良好的中英文写作和交流能力，在国内外学术期刊上发表过高水平论文。

 

**3、福利待遇：**

（1）工资福利与在职人员同等，另有项目绩效奖励；

（2）提供博士后公寓、工作餐和出国学术交流机会；

（3）可根据研究方向与内容，给予项目支持；

（4）按国家有关规定，可解决夫妻、子女北京户口等。 

 

**4、报名要求：**

请应聘者将应聘材料发送至联系人邮箱（见联系方式），应聘材料包括个人简历（教育经历、工作经历、主要论文、曾从事项目和奖励简况、近期免冠照片、电话与手机联系方式等内容），以及能证明符合条件的相关材料的扫描件（PDF格式，含学历学位证书，论著、课题、专利等科研成果，获奖证明等）。
