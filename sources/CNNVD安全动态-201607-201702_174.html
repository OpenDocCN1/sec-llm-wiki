滥用 Telegram API 的勒索软件被破解

原文：http://mp.weixin.qq.com/s?__biz=MzAxODY1OTM5OQ==&mid=2651434541&idx=3&sn=4ec38ae2b8cd65ab2f799247fdbe65cd&chksm=802fef05b75866137786127a16f1a7e62bd83c8ab65fef4dfaeece23417f10d43b85a0b6186b&scene=126&sessionid=1681378163#rd



名叫 TeleCrypt 的勒索软件滥用 Telegram API，将流行的即时通讯软件作为CC指令控制中心。该勒索软件针对的是俄罗斯用户，用Delphi编写，大小3MB，感染之后会向受害者勒索5000卢布。

幸运的是， TeleCrypt 使用的加密并不强，研究人员发现它的加密方法十分简单，因此开发出了破解程序，帮助受害者解密加密的文件。破解程序需要 .NET 4.0。
