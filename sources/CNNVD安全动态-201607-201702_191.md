# Windows 7/8.1的首个预览累积补丁放出

今年10月下旬，针对Windows 7/8.1系统微软宣布启动全新的更新策略，在每个月第2个周二将会放出纯安全补丁（当月安全更新）和安全累积补丁（当月安全更新及过去每月安全/非安全更新），而在每个月第3个周二则会预览累积补丁（在安全累积更新的基础上再加上下月的非安全更新预览）。今天微软如约放出了Windows 7/8.1的预览累积更新，介绍了即将在12月上线的非安全更新。

尤其需要指出的是微软将不再发布独立的更新补丁，而是采用包含此前所有月份发布更新的累积包形式出现。从本质上来说预览累积补丁仅仅适用于那些想要测试微软最新补丁的用户，同时也是方便IT管理员为下个月的补丁星期二活动做准备。这些更新会在每个月的第3个星期二上线，可以通过微软的Update Catalog上进行下载，如果你想要尝试和体验可以分别下载KB3197869 和 KB3197875。

KB3197869称之为面向Windows 7 SP1和Windows Server 2008 R2 SP1的2016年11月累积更新预览，主要修复了操作系统的BUG和后台性能。而KB3197875则是面向Windows 8.1的2016年11月累积更新预览，引入了诸多的改善。
