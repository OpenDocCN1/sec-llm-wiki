# 卡内基梅隆研究人员黑掉LG智能手表把它变成一个手势设备

来自卡内基梅隆大学未来接口组的一组研究人员已经想出了一种将现成的智能手表超越通知系统或健身跟踪器的方法。通过超频LG智能手表上的加速度计，研究人员能够捕获和处理生物声学信号，将智能手表同时变成手势设备，数据发射器和高度具体的活动跟踪器。

简而言之，智能手表成为超敏感的数据接收器和发射器。在YouTube上发布的视频中，您可以看到被黑客入侵的智能手表，即使是最小的电动牙刷振动和音频信号也能拾取。

使用超频的智能手表，相应的应用程序也可以更好地了解用户正在做的日常活动，卡内基梅隆大学未来接口组主任克里斯·哈里森表示，假设用户佩戴智能手表驾驶一辆汽车，或者按下搅拌器上的按钮，或使用电钻。由于数据的详细程度，智能手表会解释用户操作，应用可以向用户显示相关信息。
