# 小心Wi-Fi会透露位置信息

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODY1OTM5OQ==&mid=2651434212&idx=5&sn=0b906a8a010bab60aaa7b1db04702c23&chksm=802fedccb75864da8a7ff253edf8b6d48bb1416c8d3eac93fd4a18a72bff124e654629e0130a&scene=126&sessionid=1681378178#rd](http://mp.weixin.qq.com/s?__biz=MzAxODY1OTM5OQ==&mid=2651434212&idx=5&sn=0b906a8a010bab60aaa7b1db04702c23&chksm=802fedccb75864da8a7ff253edf8b6d48bb1416c8d3eac93fd4a18a72bff124e654629e0130a&scene=126&sessionid=1681378178#rd)

最近，丹麦技术大学的研究人员表示，他们已经研究出了一个新的系统可以用来监视用户。这一系统能根据 Wi-Fi 信号的强弱，探测出用户位置以及身边还有谁。  

系统开发人员，Sapiezynski表示：“通过 Wi-Fi 信号探测位置并不是什么新创意。但是据我们所知，还没有人能在长时间大范围内将这一技术实现。并且，这一系统还能清楚地记录人的位置移动，进而推算出周围有哪些人。”

这项系统是怎样实现的呢？

首先这个系统能通过800位志愿者所连接的Wi-Fi 网络确定他们的位置，紧接着进一步研究他们的位置移动。这一系统不仅仅只能确定志愿者的位置，还能通过 Wi-Fi 信号强弱来确定实际距离是多少。例如，系统追踪到两个人连接到同一Wi-Fi信号，这也就说明这两人现在在同一位置。

此外，研究人员表示这一系统只会影响安卓用户，因为大部分谷歌应用中的程序都能读取 Wi-Fi 的连接信息。

尽管最新版的安卓系统已经解决了这一问题，在升级之后，所有的程序想要读取Wi-Fi连接信息都要先经过用户许可。但是目前大多数在使用中的手机还不能进行这一升级。
