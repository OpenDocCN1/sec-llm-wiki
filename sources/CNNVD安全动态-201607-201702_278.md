# 特朗普集团被爆邮件服务器使用过期的系统和软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODY1OTM5OQ==&mid=2651434197&idx=4&sn=953a870ebdfbe72d952baedabd6292ff&chksm=802fedfdb75864ebf47dc1289d9f00dd80d01d1f87144c3af889ad14bbcd2f4d61eaf08a0bfc&scene=126&sessionid=1681378189#rd](http://mp.weixin.qq.com/s?__biz=MzAxODY1OTM5OQ==&mid=2651434197&idx=4&sn=953a870ebdfbe72d952baedabd6292ff&chksm=802fedfdb75864ebf47dc1289d9f00dd80d01d1f87144c3af889ad14bbcd2f4d61eaf08a0bfc&scene=126&sessionid=1681378189#rd)

独立安全专家KevinBeaumont近日表示川普（Donald Trump）旗下特朗普集团（Trump Organization）所属的邮件服务器使用严重过期的系统软件，依然还运行在Windows Server 2003和IIS 6.0软件上，两者都属于过时淘汰的技术。

Windows Server2003的寿命终止日期（EOL）为2015年7月，这意味特朗普集团的系统管理员至少有1年多的时间没有更新服务器。整个邮件系统的安全解决方案非常的糟糕，而且近期针对美国政府机构的黑客攻击事件不断，民主国家委员会（DNC）和民主党国会运动委员会（DCCC）等都存在数据被窃。

Windows Server2003和IIS 6.0并非Beaumont发现的唯一问题，该安全专家还发现运行在该服务器上的大部分软件都没有打上补丁或者更新至最新版本，也没有迹象表明服务器使用了MDM软件或启用双因素认证等安全手段。
