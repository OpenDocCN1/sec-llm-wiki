# EAST报告：2016上半年，ATM物理攻击和欺诈攻击数量上升

据欧洲ATM安全小组（European ATM Security Team，EAST）发布的报告显示，罪犯喜欢使用炸药入侵ATM。

该机构称，2016年上半年，犯罪团伙使用炸药入侵ATM的事件有492起，而2015年同期为273起。这种趋势还表明，有许多欧洲犯罪团伙不具备技术能力部署并运行伪造技术或恶意软件实施操作。

**ATM****“爆炸性攻击”致间接损害**

EAST执行董事Lachlan Gunn表示，“爆炸性攻击的数量攀升，欧洲行业内备受关注，因为这类攻击给设备、建筑甚至生命带来大量间接损害。”

该报告还表明其它物理攻击的数量也在增加，比如撞击（使用撞击设备或开车直接毁坏ATM、建筑或墙体。）

每起撞击事件的平均损失为17,327欧元，每起抢劫攻击的平均损失为20,017欧元，爆炸性攻击为16,631欧元。但Gunn表示，这个数值仅包括被窃金额，而对周边造成的损失还不在其中，而就这方面而言，爆炸攻击的损失相当大。

EAST表示，2016年上半年，ATM的物理攻击数量高达1604起，2015年同期仅为1232起。

2016年上半年，物理攻击所致的损失为2700万欧元，相比2015年上半年的2630万欧元，增加3%。

**大量损失来自ATM伪造技术和ATM恶意软件攻击**

然而，欺诈攻击，例如ATM伪造技术、ATM恶意软件和交易冲正等仍是银行业的头号威胁。EAST称，总体而言，ATM欺诈攻击从2015年上半年的8421起增加到2016年上半年的10820起，增长率高达28%。

该机构记录的最高增长要数交易冲正攻击，从1270起增加到4840起，增长281%。

ATM伪造技术和ATM恶意软件仍是ATM欺诈攻击的常用手段。而最引人关注的头条便是所谓的“吐钞攻击”，攻击者使用ATM恶意软件“吐钞”。

EAST报告显示，“吐钞攻击”并不太常见，2016年上半年仅发生28起，而2015年同期仅为5起。这类事件的实际经济损失仅为40万欧元。

2016年上半年，ATM欺诈攻击（包括恶意软件和伪造技术）的总损失为1.74亿欧元，相比2015年上半年的1.56亿美元，增长12%。
