# 微软开始向Windows 7和8.1提供累积补丁

微软在今年8月宣布 Windows 7/8.1/2008/2012将开始采用Windows 10的累积补丁更新模式，即系统在长时间未更新后无需个别的下载一个个补丁，而是可选择下载一个包含所有已发布补丁的累积更新包。

本周二释出的例行更新中，微软正式开始向Windows 7和8.1用户提供累积更新包。微软将提供三种累积更新包：包含当月安全更新和非安全更新的补丁包，只包含安全更新的补丁包，以及预览下个月非安全更新的补丁包。前两个累积更新包在每个月的第二个星期二释出，第三个则在第三个星期二释出。累积更新将通过Windows Update、Windows Server Update Services (WSUS)和 Windows Update Catalog分发，而独立安全更新只通过WSUS和 Catalog提供。

从2017年2月开始，微软将向累积更新包中加入旧的补丁，这意味着累积更新包的容量将日益庞大。
