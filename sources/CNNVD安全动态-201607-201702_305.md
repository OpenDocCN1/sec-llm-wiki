# 泄露至少5亿信息，雅虎已暂禁电子邮件自动转发

本月初雅虎已暂时禁用电子邮件自动转发功能。过去已设置自动转发功能的邮箱用户并不会受到影响。不过最近爆出雅虎用户账户遭黑客窃取和数据监控丑闻后，一些用户正摒弃雅虎邮箱转而选择竞争对手的邮箱。

上个月有消息透露，自2014年以来，至少5亿个雅虎用户的账户遭窃。此后，雅虎就一直在接受投资者的的审查。

有报道称，雅虎去年秘密研发了一个定制软件程序，用以在所有用户的电子邮件中搜索是否存在美国情报机构提供的特定信息。这一消息引发了人们对人权受侵的担忧。

由于这些负面新闻，一些用户已经弃用或打算弃用雅虎邮箱。

雅虎网站称，“电子邮件自动转发”功能正在开发中，并已暂时停用。
