# Windows 7/8.1累积更新将不再包含IE浏览器补丁

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODY1OTM5OQ==&mid=2651433984&idx=3&sn=3b01e3441f440be62e28e2d3decb43db&chksm=802fed28b758643e5d89132d121158a233734dcac6fcfb3c6798bfcb989b81d2c85ad15ce81e&scene=126&sessionid=1681378199#rd](http://mp.weixin.qq.com/s?__biz=MzAxODY1OTM5OQ==&mid=2651433984&idx=3&sn=3b01e3441f440be62e28e2d3decb43db&chksm=802fed28b758643e5d89132d121158a233734dcac6fcfb3c6798bfcb989b81d2c85ad15ce81e&scene=126&sessionid=1681378199#rd)

微软将于下月开始发布Windows 7/8.1发布的累积更新中将不再包含针对IE浏览器的更新，而是将会作为独立累积更新方式进行发布。微软高级市场营销经理Nathan Mercer在原公告的声明部分中目前正为Windows 7/8.1系统中的IE浏览器提供独立的累积补丁更新，但是目前没有准确的发布时间。

Windows 7/8.1的月度补丁包有点类似于Windows 10系统中的累积更新，是确保系统处于最新状态的最简单方式。Mercer解释道：“目前我们通过月度补丁包和安全方面的补丁更新这两种方式进行升级，但今后将不会再这样做了，具体上线日期还未确认。IE版本的升级并不会随系统月度补丁更新升级，我们计划根据你在月度补丁更新中安装的IE补丁数量来进行升级，这有点类似于.NET更新方式。”

此外Mervcer还确认Windows Vista系统在新调整策略中将不会获得任意累积更新，独立更新将会持续到10月11日补丁更新。

微软工程师解释道：“尽管Windows Vista和Windows Server 2008已经进入扩展支持模式，我们也考虑为Vista/2008提供改变但是从技术角度来说在这些平台上做任何改变都是极具挑战的事情，因此我们目前并没有计划扩展Rollup服务模型至Windows Vista或者Windows Server 2008。”
