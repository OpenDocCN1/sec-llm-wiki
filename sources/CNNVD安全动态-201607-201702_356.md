# 谷歌Gmail服务突现故障：英美两国用户受到严重影响

周三的时候，谷歌旗下Gmail电子邮件服务遭遇了大规模故障，美国和英国首当其中。由于大量用户已经将Gmail和Gchat当做了日常工作生活中的重要工具，无数人在故障发生的瞬间变得手足无措。这家搜索巨头证实，其电子邮件网络从太平洋时间上午8:16起服务中断。Google在应用状态黑板上写到：“我们正在调查汇报上来的Gmail问题，稍后会提供更多信息”。

根据报告可知，本次中断仅影响到Google for Work Gmail用户。

Google给出了一个临时解决方案，受影响的用户可暂时在管理员控制界面（Admin Console UI）禁用Gmail服务并保存更改，等到服务恢复正常了再改回来。

太平洋时间周三上午9点，一些Gmail for Work用户的服务已经恢复正常。

虽然谷歌应用状态仪表板（App Status Dashboard）上仍显示为掉线状态，但该公司声称已找到故障原因，并且正在进行潜在的修复工作。
