微软将于10月起禁用旧版Flash Player：Win8.1/10平台不受影响

从2016年10月11日起，微软将自动阻止旧版Flash Player插件在Windows 7和Windows Server 2008 R2版本的IE浏览器上使用。这一决定并不会影响Windows 8.1或Windows 10用户，因其系统更新可以自动升级到最新版本的Flash Player。微软在公告中称：“我们已将阻止过时ActiveX控件的功能扩展至包含Adobe Flash Player在内”。

“系统会在打开一个网页并试图加载旧版Flash ActiveX控件时给出更新提示，但Adobe Flash Player v21.0.0.198和Adobe Flash Player v18.0.0.241扩展支持版本除外。”

这项措施仅针对Windows 7 / Windows Server 2008 R2上的IE浏览器，Windows 10上独占的Microsoft Edge浏览器不受影响。

Flash Player已经内建到了Edge浏览器之中，并且会随着Windows Update（每个月的“补丁星期二”周期）自动更新。

微软表示，IE会在每次打开调用旧版Flash ActiveX（以及其它过时控件）的标签页时给出警示，但本地管理员之外群组的用户不会看到任何阻碍。

随着互联网上各大网站和服务向着HTML5迁移，有着“漏洞王”之称的Flash Player也遭到了越来越多企业的嫌弃。
