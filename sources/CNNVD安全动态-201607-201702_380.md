# 统计数据显示Linux还未能对Windows造成威胁

业界都认为Linux是Windows的最佳替代品，有很多用户已经“跳槽”到Linux。但上个月的统计数据显示，Windows仍是占主导地位的桌面操作系统。更重要的是，Linux还未能对Windows造成任何实质性威胁。Net Applications统计数据显示，得益于8月份良好的市场表现，Windows在桌面操作系统市场上的份额再度超过90%。

Net Applications声称Windows市占率目前是90.52%，高于一个月前的89.79%，Windows市占率最糟糕的月份是今年四月份，当时下降到88.77%。 在另一方面，Linux市占率仍然远远落后，8月份市占率仅为2.11%，而更重要的是，Linux市占率正在下降，其7月份市占率是2.33%。

苹果的Mac OS X目前市占率是7.37%，被认为是Windows更大的威胁。但就像在Linux市占率下降一样，Mac OS X市占率也在下降的，7月份它的市占率是7.87%，4月份它的市占率不低于9.57%。
