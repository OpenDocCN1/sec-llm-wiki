# 2021年全球网络犯罪成本将增加至6万亿美元

预计到2021年，网络犯罪的成本可能达6万亿美元。全球的网络犯罪成本将继续呈增长态势，倒也不足为奇，因为此类非法手段泛滥。 Cybersecurity Ventures的分析表明，网络犯罪成本2012年可能会高达6万亿美元。（预计，2015年全球网络犯罪的年成本为3万亿美元）。

Ponemon Institute的创始人Larry Ponemon表示，安全专家质疑未来5年，网络犯罪成本将明显增加，可能以万亿美元的趋势增长。Larry Ponemon评论到，“一万亿美元真有可能”。

网络犯罪活动的增长趋势将增加全球在网络安全产品和服务方面的支出。预计未来五年（2017-2021）全球支出将累计增加超过1万亿美元。

犯罪活动将目标从计算机和移动设备不断扩展至物联网、交通和电网。

![](../Images/c0e82d49f42c0d5de5f43b9408843994.png)  

该报告强调当今缺乏有效的金融网络犯罪的执法机构。尽管执法机构在打击全球网络组织方面取得一定成功，但仍需不断努力应对不断增加的威胁。
