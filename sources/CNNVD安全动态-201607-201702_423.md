# Windows 10一周年更新版插入Kindle会导致蓝屏死机

Windows 10一周年内更新曝出了更多的QA测试方面的问题。  

Windows 用户在官方论坛抱怨更新后插入KindlePaperwhite会立即导致电脑蓝屏死机，更新前使用没有任何问题。Kindle是最流行的电子书阅读器之一。无论是笔记本电脑还是台式机，安装了最新更新后，插入Kindle Paperwhite后会立即导致蓝屏死机。这一问题与电脑品牌无关，受影响的电脑包括惠普、戴尔和联想。亚马逊Kindle论坛同样有大量的问题报告，问题被认为与驱动有关。一种权宜之计是在电脑睡眠状态时候插入Kindle。
