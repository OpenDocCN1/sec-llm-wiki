Linux Kernel 4.7.2版本发布：改善对AMDGPU和ARM64的支持

原文：http://mp.weixin.qq.com/s?__biz=MzAxODY1OTM5OQ==&mid=2651433704&idx=2&sn=3c0c4ec90d971cc83a94858985e1ffb5&chksm=802febc0b75862d68d179054131420a41a6914b35f1217af93cc1b6a1944c41f8f42603adcb4&scene=126&sessionid=1681378225#rd

Linux Kernel开发者和多个内核分支的重要维护人Greg Kroah-Hartman于今天宣布了LinuxKernel 4.7系列的第二个维护版本。这款知名的开源项目正在高速发展中，离Linux Kernel 4.7.1版本只有4天时间，本次更新共计更改192个文件，在2086处进行插入，删除1108处。

Greg Kroah-Hartman说道：“我宣布Linux Kernel 4.7.2内核。所有Linux 4.7系列用户务必尽快完成升级。升级版4.7.y git tree可以在git://git.kernel.org/pub/scm/linux/kernel/git/stable/linux-stable.gitlinux-4.7.y找到，或者访问kernel.org网站进行访问:http://git.kernel.org/?p=linux/kernel/git/stable/linux-stable.git;a=summary.”

 

本次维护版本带来了诸多调整，包括改善对ARM64 (AArch64), ARM, ARC, MIPS, s390, x86和PowerPC (PPC)等架构的支持，诸多驱动更新，尤其是AMDGPU, ACPI, BCMA, Bluetooth, GPIO, CLK, CPUFreq, EDAC, Intel i915,Nouveau, Radeon, Rockchip, I2C, InfiniBand, IOMMU, MD, MFD, iwlwifi, PHY,PINCTRL, SCSI, SPI, TTY, USB和Virtio。此外Linux Kernel 4.7.2还改善了Btrfs, CIFS,JBD2, NFS, OverlayFS和XFS文件系统的支持。
