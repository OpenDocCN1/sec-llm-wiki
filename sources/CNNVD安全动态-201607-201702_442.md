# 研究人员建议用户禁用WPAD协议

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODY1OTM5OQ==&mid=2651433643&idx=1&sn=2c3e2d2ac2c9b6d8039b714486ea6307&chksm=802feb83b75862953c8a5460fefcbb3639ba1b45b78a693f336de29bfc0cbb46903f6a7cf64d&scene=126&sessionid=1681378235#rd](http://mp.weixin.qq.com/s?__biz=MzAxODY1OTM5OQ==&mid=2651433643&idx=1&sn=2c3e2d2ac2c9b6d8039b714486ea6307&chksm=802feb83b75862953c8a5460fefcbb3639ba1b45b78a693f336de29bfc0cbb46903f6a7cf64d&scene=126&sessionid=1681378235#rd)

研究人员发现了一种攻击方法能绕过HTTPS保护，潜在可用于窃取用户的账号等信息。

这种攻击方法滥用了名叫Web Proxy Autodisovery（WPAD）的特性，攻击者可以迫使浏览器获取一个Proxy Autoconfig (PAC)文件，指定特定网址触发使用代理。这种攻击方法可被中间人用于劫持用户的在线账号和其它敏感信息，即使连接使用了加密或通过VPN传输。

安全研究人员建议用户禁用WPAD协议，Windows下的方法是在注册表里搜索和修改如下项的值：\[HKEY\_CURRENT\_USER\\Software\\Microsoft\\Windows\\CurrentVersion\\Internet Settings\\Wpad\] "WpadOverride"=dword:00000001 。
