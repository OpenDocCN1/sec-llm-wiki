# 生命周期9个月，Ubuntu 15.10停止支持

2016年7月28日，在经历了9个月之后Ubuntu 15.10（Wily Werewolf）的生命周期正式画上了句号，也意味着目前处于支持状态的Ubuntu发行版本只有12.04 LTS、14.04 LTS和16.04 LTS三个版本。如果还在运行Ubuntu 15.10或者14.04 LTS，推荐用户尽快升级至最新的LTS版本。

Ubuntu 15.10于2015年10月22日正式上线，被Canonical和Ubuntu创始人Mark Shuttleworth称之为Wily Werewolf，这也是首个基于虚构角色的取名。Ubuntu 15.10并非是长期支持版本，这意味着在安全修复和软件更新上的生命支持周期比较短。

Canonical的Adam Conrand此前说道：“作为非LTS版本，Ubuntu 15.10拥有9个月支持周期，根据规范该版本将会在7月28日周四的时候结束生命。届时，Ubuntu安全更新并不会为Ubuntu 15.10提供信息和更新包。”
