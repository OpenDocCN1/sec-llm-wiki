今日CNNVD共发布安全漏洞27个，更新安全漏洞8个。主要影响厂商为美国Linux（2个）、印度PHP Scripts Mall（2个）、美国Apache（1个）。主要影响产品为Linux kernel内核（2个）、PHP Scripts Mall Entrepreneur Job Portal Script基于PHP的招聘、求职网站脚本（2个）、Apache OpenMeetings视频会议和协作系统（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Linux kernel 安全漏洞**  

**【漏洞编号】****CNNVD-201802-682（CVE-2017-18203）**

**【漏洞详情】**Linux kernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。

Linux kernel 4.14.3之前版本中的drivers/md/dm.c文件的‘dm\_get\_from\_kobject’函数存在安全漏洞。本地攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.kernel.org/pub/linux/kernel/v4.x/ChangeLog-4.14.3

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-682

  

**【漏洞名称】****PHP Scripts Mall Entrepreneur Job Portal Script 跨站脚本漏洞**  

**【漏洞编号】****CNNVD-201802-978（CVE-2018-7469）**

**【漏洞详情】**PHP Scripts Mall Entrepreneur Job Portal Script是印度PHP Scripts Mall公司的一套基于PHP的招聘、求职网站脚本。

PHP Scripts Mall Entrepreneur Job Portal Script 2.0.9版本中存在跨站脚本漏洞。远程攻击者可通过向admin/categories\_industry.php文件发送p\_name字段利用该漏洞注入任意的Web脚本或HTML。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.phpscriptsmall.com/product/entrepreneur-job-portal-script/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-978

  

**【漏洞名称】****Apache OpenMeetings 安全漏洞**  

**【漏洞编号】****CNNVD-201802-976（CVE-2018-1286）**

**【漏洞详情】**Apache OpenMeetings是美国阿帕奇（Apache）软件基金会所研发的一套多语言可定制的视频会议和协作系统，它支持音频、视频并允许用户查看每个与会者的桌面等。

Apache OpenMeetings 3.0.0版本至4.0.1版本中存在安全漏洞。攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lists.apache.org/thread.html/dc2151baa5301bae773603cede0d62c21ee28588dd06e5e9253c13a8@%3Cuser.openmeetings.apache.org%3E

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-976

  

**【漏洞名称】****多款Comforte产品SWAP 安全漏洞**  

**【漏洞编号】****CNNVD-201802-970（CVE-2018-6653）**

**【漏洞详情】**Comforte SecurCS等都是德国Comforte公司的产品。Comforte SecurCS是一款基于TCP/IP的SSL加密工具。SecurFTP是一款在NonStop系统与其它平台之间提供文件传输功能的工具。SWAP是其中的一个简单对象访问协议。

多款Comforte产品中使用的SWAP 1049版本至1069版本和20.0.0版本至21.5.3版本中存在安全漏洞，该漏洞源于程序没有确保客户端使用较强的TLS加密套件。远程攻击者可通过嗅探网络利用该漏洞破坏加密保护机制。以下产品受到影响：Comforte SecurCS；SecurFTP；SecurLib/SSL-AT；SecurTN。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://comforte.com/cve-2018-6653/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-970

  

**【漏洞名称】****Bonitasoft Bonita BPM Portal 安全漏洞**  

**【漏洞编号】CNNVD-201802-975（CVE-2015-3898）**

**【漏洞详情】**Bonitasoft Bonita BPM是美国Bonitasoft公司的一套开源的业务流程管理平台（BPM），它支持自由地创建和管理可定制的业务应用程序。Bonita BPM Portal是其中的一个门户产品。

Bonitasoft Bonita BPM Portal 6.5.3之前版本中存在开放重定向漏洞。远程攻击者可利用该漏洞将用户重定向到任意的网站并实施钓鱼攻击。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.bonitasoft.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-975
