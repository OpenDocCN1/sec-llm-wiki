今日CNNVD共发布安全漏洞50个，更新安全漏洞8个。主要影响厂商为美国Google（7个）、美国Apache（1个）、中国天睿（1个）。主要影响产品为Android操作系统（7个）、Apache TomcatWeb应用服务器（1个）、Dayrui FineCms内容管理系统（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Android Qualcomm WLAN 权限许可和访问控制漏洞**  

**【漏洞编号】****CNNVD-201802-565（CVE-2017-15862）**

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Qualcomm WLAN是其中的一个美国高通（Qualcomm）公司开发的无线局域网组件。

Android中的Qualcomm WLAN的‘wma\_unified\_link\_radio\_stats\_event\_handler()’函数存在提权漏洞，该漏洞源于程序没有正确的校验来自固件的无线电通道的数量。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2018-02-01

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-565

  

**【漏洞名称】****Apache Tomcat 安全漏洞**  

**【漏洞编号】****CNNVD-201802-564（CVE-2018-1305）**

**【漏洞详情】**Apache Tomcat是美国阿帕奇（Apache）软件基金会下属的Jakarta项目的一款轻量级Web应用服务器，它主要用于开发和调试JSP程序，适用于中小型系统。

Apache Tomcat中存在安全漏洞。攻击者可利用该漏洞获取被限制的资源。以下版本受到影响：Apache Tomcat 9.0.0.M1版本至9.0.4版本，8.5.0版本至8.5.27版本，8.0.0.RC1版本至8.0.49版本，7.0.0版本至7.0.84版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lists.apache.org/thread.html/d3354bb0a4eda4acc0a66f3eb24a213fdb75d12c7d16060b23e65781@%3Cannounce.tomcat.apache.org%3E

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-564

  

**【漏洞名称】****Dayrui FineCms 跨站脚本漏洞**  

**【漏洞编号】****CNNVD-201802-619（CVE-2018-7476）**

**【漏洞详情】**Dayrui FineCms是中国天睿（Dayrui）程序设计团队发布的一套使用MVC架构和PDO数据库接口开发的内容管理系统（CMS）。

Dayrui FineCms 5.3.0版本中的controllers/admin/Linkage.php文件存在跨站脚本漏洞。远程攻击者可通过向admin.php文件发送带有‘id’或‘lid’参数的c=linkage,m=import请求利用该漏洞注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.finecms.net

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-619

  

**【漏洞名称】****IBM Financial Transaction Manager for ACH Services for Multi-Platform 安全漏洞**  

**【漏洞编号】****CNNVD-201802-443（CVE-2017-1758）**

**【漏洞详情】**IBM Financial Transaction Manager for ACH Services for Multi-Platform是美国IBM公司的一款跨平台的金融事务管理器产品，它主要用于监控、跟踪和报告金融支付和交易。

基于多个平台的IBM Financial Transaction Manager for ACH Services中存在安全漏洞。远程攻击者可利用该漏洞泄露敏感信息或消耗内存资源。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22013375

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-443

  

**【漏洞名称】****Red Hat libvirt 安全漏洞**  

**【漏洞编号】CNNVD-201802-607（CVE-2018-6764）**

**【漏洞详情】**Red Hat libvirt是美国红帽（Red Hat）公司的一个用于实现Linux虚拟化功能的Linux API，它支持各种Hypervisor，包括Xen和KVM，以及QEMU和用于其他操作系统的一些虚拟产品。

Red Hat libvirt中的util/virlog.c文件存在安全漏洞，该漏洞源于程序没有正确的确定主机名。本地攻击者可借助特制的NSS模块利用该漏洞绕过容器保护机制并执行任意命令。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://libvirt.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-607
