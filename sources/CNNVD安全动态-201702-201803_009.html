今日CNNVD共发布安全漏洞50个，更新安全漏洞40个。主要影响厂商为美国Microsoft（40个）、美国IBM（4个）、中国华为（2个）。主要影响产品为Microsoft Windows操作系统（23个）、IBM Financial Transaction Manager（FTM）for ACH Services服务管理器（2个）、Huawei LON-L29D智能手机（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Microsoft Internet Explorer scripting引擎安全漏洞

【漏洞编号】CNNVD-201802-480（CVE-2018-0866）

【漏洞详情】Microsoft Windows是美国微软（Microsoft）公司发布的一系列操作系统。Internet Explorer（IE）是一款Windows操作系统附带的Web浏览器。scripting engine是其中的一个JavaScript引擎。

Microsoft IE 9、10和11版本的scripting引擎存在远程代码执行漏洞。远程攻击者可利用该漏洞在当前用户的上下文中执行任意代码，造成内存损坏。以下系统版本受到影响：Microsoft Windows 7 SP1，Windows Server 2008和R2 SP1，Windows 8.1，Windows RT 8.1，Windows Server 2012和R2，Windows 10，Windows 10版本1511，Windows 10版本1607，Windows 10版本1703，Windows 10版本1709，Windows Server 2016。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2018-0866

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-480


【漏洞名称】IBM Financial Transaction Manager for ACH Services 输入验证漏洞

【漏洞编号】CNNVD-201802-542（CVE-2018-1392）

【漏洞详情】IBM Financial Transaction Manager（FTM）for ACH Services是美国IBM公司的一款金融事务管理器产品，它主要用于监控、跟踪和报告金融支付和交易。

IBM FTM for ACH Services 3.0.4版本和3.1.0版本中存在输入验证漏洞。攻击者可利用该漏洞执行特制的命令，获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.ibm.com/support/docview.wss?uid=swg22013249

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-542


【漏洞名称】Huawei LON-L29D 安全漏洞

【漏洞编号】CNNVD-201802-461（CVE-2017-15345）

【漏洞详情】Huawei LON-L29D是中国华为（Huawei）公司的一款智能手机产品。

Huawei LON-L29D LON-L29DC721B186版本中存在拒绝服务漏洞。攻击者可通过发送伪造的3GPP报文利用该漏洞造成设备重启。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20171108-01-smartphone-cn

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-461


【漏洞名称】Cisco Jabber Client Framework 跨站脚本漏洞

【漏洞编号】CNNVD-201802-433（CVE-2018-0201）

【漏洞详情】Cisco Jabber Client Framework（JCF）是美国思科（Cisco）公司的一套统一通信客户端框架。该框架提供了在线状态显示、即时消息、语音等功能。

Cisco JCF中存在跨站脚本漏洞。远程攻击者可利用该漏洞使聊天客户端发送出站请求。 

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bst.cloudapps.cisco.com/bugsearch/bug/CSCve54001

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-433


【漏洞名称】Microsoft Office 2016 Click-to-Run 安全漏洞

【漏洞编号】CNNVD-201802-498（CVE-2018-0841）

【漏洞详情】Microsoft Office 2016 Click-to-Run是美国微软（Microsoft）公司开发的一款办公软件套件产品。

Microsoft Office 2016 Click-to-Run中存在远程代码执行漏洞，该漏洞源于程序没有正确的处理内存中的对象。远程攻击者可借助特制的文件利用该漏洞在当前用户的上下文中执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2018-0841

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-498
