今日CNNVD共发布安全漏洞27个，更新安全漏洞21个。主要影响厂商为美国Cisco（13个）、美国IBM（8个）、中国华为（6个）。主要影响产品为Cisco Prime Collaboration Provisioning Tool通信服务工具（2个）、IBM Forms Experience Builder应用程序（1个）、Huawei LON-AL00B智能手机（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Cisco Prime Collaboration Provisioning Tool User Provisioning tab 跨站脚本漏洞 **  

**【漏洞编号】****CNNVD-201802-430（CVE-2018-0205）**

**【漏洞详情】**Cisco Prime Collaboration Provisioning Tool是美国思科（Cisco）公司的一套基于Web的下一代通信服务工具。该工具对IP电话、语音邮件和统一通信环境提供IP通信服务功能。User Provisioning tab是其中的一个用户配置选项卡。

Cisco Prime Collaboration Provisioning Tool中的User Provisioning tab存在跨站脚本漏洞，该漏洞源于程序没有正确的验证输入。远程攻击者可通过向Prime Collaboration Provisioning数据库放入恶意的字符串利用该漏洞访问Cisco Prime Collaboration Provisioning。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bst.cloudapps.cisco.com/bugsearch/bug/CSCvd86609

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-430

  

**【漏洞名称】****IBM Forms Experience Builder 安全漏洞**  

**【漏洞编号】****CNNVD-201802-446（CVE-2016-0369）**

**【漏洞详情】**IBM Forms Experience Builder是美国IBM公司的一套用于创建网站Web表单的应用程序。

IBM Forms Experience Builder 8.5版本、8.5.1版本和8.6版本中存在XML外部实体注入漏洞。远程攻击者可借助特制的XML数据利用该漏洞获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg21988727

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-446

  

**【漏洞名称】****Huawei LON-AL00B Bluetooth模块缓冲区错误漏洞**  

**【漏洞编号】****CNNVD-201802-457（CVE-2017-17285）**

**【漏洞详情】**Huawei LON-AL00B是中国华为（Huawei）公司的一款智能手机产品。Bluetooth module是其中的一个蓝牙模块。

Huawei LON-AL00B LON-AL00BC00B229及之前版本中的Bluetooth模块存在缓冲区溢出漏洞，该漏洞源于程序没有充分的验证输入。攻击者可通过在蓝牙配对成功后伪造或者篡改蓝牙AVDTP/AVCTP报文利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20180129-01-bluetooth-cn

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-457

  

**【漏洞名称】****Cisco Data Center Analytics Framework应用程序跨站请求伪造漏洞**  

**【漏洞编号】****CNNVD-201802-437（CVE-2018-0146）**

**【漏洞详情】**Cisco Data Center Analytics Framework（DCAF）application是美国思科（Cisco）公司的一套数据中心分析框架。

Cisco DCAF应用程序中存在跨站请求伪造漏洞，该漏洞源于不正确的跨站请求伪造保护。远程攻击者可通过诱使用户点击恶意链接利用该漏洞提交任意请求，执行未授权的操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bst.cloudapps.cisco.com/bugsearch/bug/CSCvg45114

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-437

  

**【漏洞名称】****IBM Client Application Access和IBM Notes for Windows IBM Notes Diagnostics 权限许可和访问控制漏洞**  

**【漏洞编号】CNNVD-201802-449（CVE-2018-1411）**

**【漏洞详情】**IBM Client Application Access和IBM Notes for Windows都是美国IBM公司的产品。IBM Notes for Windows是一套基于Windows平台的协同办公软件。IBM Client Application Access是一套基于Windows平台的用来访问本地应用程序的工具。IBM Notes Diagnostics是其中的一个数据收集诊断应用程序。

基于Windows平台的IBM Client Application Access和IBM Notes中的IBM Notes Diagnostics存在提权漏洞。攻击者可通过借助使用共享内存的进程间通信发送特制的命令行利用该漏洞在系统上执行命令。以下版本受到影响：IBM Client Application Access 1.0.1版本，1.0.1.1版本，1.0.1.1 Interim Fix 1版本，1.0.1.2 Interim Fix 1版本；IBM Notes 9.0.1版本至9.0.1 FP10版本，9.0版本至9.0 IF4版本，8.5.3版本至8.5.3 FP6 IF15版本，8.5.2版本至8.5.2 FP4 IF3版本，8.5.1版本至8.5.1 FP5 IF3版本，8.5版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22010767

http://www-01.ibm.com/support/docview.wss?uid=swg22010766

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-449
