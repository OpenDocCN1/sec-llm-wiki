今日CNNVD共发布安全漏洞35个，更新安全漏洞15个。主要影响厂商为美国Google（11个）、美国IBM（5个）、中国福昕（1个），主要影响产品为Google Chrome for Mac、Windows和LinuxWeb浏览器（10个）、IBM WebSphere MQ消息传递中间件产品（1个）、Foxit Reader PDF文档阅读器（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Google Chrome for Mac、Windows和Linux Blink 安全漏洞

【漏洞编号】CNNVD-201802-190（CVE-2017-5133）

【漏洞详情】Google Chrome for Mac、Windows和Linux是美国谷歌（Google）公司开发的一款基于Mac、Windows和Linux平台的Web浏览器。Blink是其中的一个美国谷歌（Google）公司和挪威欧朋（Opera Software）公司共同开发的一套浏览器排版引擎（渲染引擎）。

基于Windows、Mac和Linux平台的Google Chrome 62.0.3202.62之前版本中的Blink存在安全漏洞。远程攻击者可借助特制的PDF文件利用该漏洞损坏内存、可能泄露信息，执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://chromereleases.googleblog.com/2017/10/stable-channel-update-for-desktop.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-190


【漏洞名称】IBM WebSphere MQ GSKit 安全漏洞

【漏洞编号】CNNVD-201802-205（CVE-2018-1388）

【漏洞详情】IBM WebSphere MQ是美国IBM公司的一款消息传递中间件产品。该产品主要为面向服务的体系结构（SOA）提供可靠的、经过验证的消息传递主干网。GSKit（Global Security Toolkit）是用于其中的一套安全管理工具。

IBM WebSphere MQ 7.0.1.0版本至7.0.1.14版本中的GSKit 7版本存在安全漏洞。攻击者可借助有效和无效PKCS#1填充之间的差异利用该漏洞获取边信道信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22013022

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-205


【漏洞名称】Foxit Reader和PhantomPDF 缓冲区错误漏洞

【漏洞编号】CNNVD-201802-221（CVE-2016-6169）

【漏洞详情】Foxit Reader是中国福昕（Foxit）软件公司的一款PDF文档阅读器。Foxit PhantomPDF是一个商业版。

Foxit Reader和PhantomPDF 7.3.4.311及之前版本中存在基于堆的缓冲区溢出漏洞。远程攻击者可借助特制PDF文件中的Bezier数据利用该漏洞造成拒绝服务（内存损坏和应用程序崩溃）或可能执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.foxitsoftware.com/support/security-bulletins.php

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-221


【漏洞名称】CCN-lite 安全漏洞

【漏洞编号】CNNVD-201802-210（CVE-2017-12473）

【漏洞详情】CCN-lite是CCN-lite项目的一个轻量级CCNx（内容中心网络协议）的实现。

CCN-lite中的ccnl_ccntlv_bytes2pkt存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（应用程序崩溃）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://github.com/cn-uofbasel/ccn-lite

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-210


【漏洞名称】NetApp AltaVault OST插件信息泄露漏洞

【漏洞编号】CNNVD-201711-593（CVE-2017-15517）

【漏洞详情】NetApp AltaVault是美国NetApp公司的一套云存储解决方案。该方案具可扩展、数据加密以及支持数据备份和恢复等特点。OST Plug-in是其中的一个用于提供备份与存储优化功能的API。

NetApp AltaVault OST插件1.2.2之前版本中存在安全漏洞。本地攻击者可利用该漏洞获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://security.netapp.com/advisory/ntap-20171116-0001/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-593
