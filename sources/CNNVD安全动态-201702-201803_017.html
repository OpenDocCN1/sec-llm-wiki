CNNVD最新漏洞（2018-02-07）

今日CNNVD共发布安全漏洞74个，更新安全漏洞6个。主要影响厂商为澳大利亚Atlassian（12个）、美国Extreme Networks（11个）、美国Intel（1个），主要影响产品为Atlassian Bamboo持续集成构建工具（4个）、Extreme Networks ExtremeWireless WiNG无线接入解决方案（11个）、Intel Graphics Driver集成显卡驱动程序（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Atlassian Bamboo 跨站脚本漏洞

【漏洞编号】CNNVD-201802-060（CVE-2017-18082）

【漏洞详情】Atlassian Bamboo是澳大利亚Atlassian公司的一套持续集成构建工具。该工具可帮助开发团队使用持续交付功能构建、测试、发布和部署项目。

Atlassian Bamboo 6.2.3之前版本中的plan configure branches resource存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的HTML或JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://jira.atlassian.com/browse/BAM-19666

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-060


【漏洞名称】Extreme Networks ExtremeWireless WiNG 安全漏洞

【漏洞编号】CNNVD-201802-115（CVE-2018-5797）

【漏洞详情】Extreme Networks ExtremeWireless WiNG是美国极进网络（Extreme Networks）公司的一款无线接入解决方案。Secure MINT static message key是其中的一个静态MIMT消息密钥。

Extreme Networks ExtremeWireless WiNG 5.8.6.9之前的5.x版本和5.9.1.3之前的5.9.x版本中的Secure MINT static message key存在安全漏洞。攻击者可通过实施中间人攻击利用该漏洞解密数据包。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://gtacknowledge.extremenetworks.com/articles/Vulnerability_Notice/VN-2018-003

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-115


【漏洞名称】Intel Graphics Driver 安全漏洞

【漏洞编号】CNNVD-201802-050（CVE-2017-5727）

【漏洞详情】Intel Graphics Driver是美国英特尔（Intel）公司开发的一款集成显卡驱动程序。

Intel Graphics Driver 15.40.x.x版本、15.45.x.x版本和15.46.x.x版本中的子系统的指针逆向引用存在安全漏洞。攻击者可借助本地访问权限利用该漏洞更改内核内存，并提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://security-center.intel.com/advisory.aspx?intelid=INTEL-SA-00089&languageid=en-fr

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-050


【漏洞名称】Micro Focus Fortify Audit Workbench和Micro Focus Fortify Software Security Center 安全漏洞

【漏洞编号】CNNVD-201802-055（CVE-2018-6486）

【漏洞详情】Micro Focus Fortify Audit Workbench（AWB）和Micro Focus Fortify Software Security Center（SSC）都是英国Micro Focus公司的产品。Micro Focus Fortify Audit Workbench（AWB）是一套软件安全审计平台。Micro Focus Fortify Software Security Center（SSC）是一套软件安全管理平台。

Micro Focus Fortify AWB和Micro Focus Fortify SSC中存在XML外部实体注入漏洞。攻击者可利用该漏洞获取敏感信息的访问权限或造成拒绝服务。以下产品和版本受到影响：Micro Focus Fortify Audit Workbench 16.10版本，16.20版本，17.10版本；Micro Focus Fortify Software Security Center 16.10版本，16.20版本，17.10版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://softwaresupport.softwaregrp.com/document/-/facetsearch/document/KM03083653

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-055


【漏洞名称】Artifex MuPDF 安全漏洞

【漏洞编号】CNNVD-201802-075（CVE-2018-6544）

【漏洞详情】Artifex MuPDF是美国Artifex Software公司的一款免费的、轻量级的PDF阅读器。

Artifex MuPDF 1.12.0版本中的pdf/pdf-xref.c文件的pdf_load_obj_stm存在安全漏洞。远程攻击者可借助特制的PDF文档利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://mupdf.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-075
