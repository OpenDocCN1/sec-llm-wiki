今日CNNVD共发布安全漏洞43个。主要影响厂商为美国Apple（11个）、美国Mozilla（10个）、中国华为（1个），主要影响产品为Apple macOS High Sierra操作系统（4个）、Mozilla Firefox浏览器产品（10个）、Huawei Campus S9300交换机设备（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Apple macOS High Sierra IOHIDFamily 安全漏洞

【漏洞编号】CNNVD-201801-1094（CVE-2018-4098）

【漏洞详情】Apple macOS High Sierra是美国苹果（Apple）公司的一套专为Mac计算机所开发的专用操作系统。IOHIDFamily API是其中的一个内核扩展（人机接口设备的抽象接口）API组件。

Apple macOS High Sierra 10.13.3之前的版本中的IOHIDFamily组件存在安全漏洞。攻击者可利用该漏洞以内核权限执行任意代码（内存损坏）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/zh-cn/HT208465

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-1094


【漏洞名称】Mozilla Firefox和Firefox ESR 安全漏洞

【漏洞编号】CNNVD-201801-1105（CVE-2018-5091）

【漏洞详情】Mozilla Firefox和Firefox ESR都是美国Mozilla基金会开发的浏览器产品。Firefox是一款开源Web浏览器；Firefox ESR是Firefox的一个延长支持版本。

Mozilla Firefox 58之前版本和Firefox ESR 52.6之前版本中存在释放后重用漏洞。远程攻击者可利用该漏洞造成拒绝服务（崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.mozilla.org/en-US/security/advisories/mfsa2018-02/

https://www.mozilla.org/en-US/security/advisories/mfsa2018-03/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-1105


【漏洞名称】多款Huawei产品eSap software platform 缓冲区错误漏洞

【漏洞编号】CNNVD-201801-1088（CVE-2014-4705）

【漏洞详情】Huawei Campus S9300等都是中国华为（Huawei）公司的产品。Campus S9300等都是交换机设备。WLAN AC6005等都是接入控制器设备。eSap software platform是运行在其中的一套ESAP软件平台。

多款Huawei产品中的eSap software platform存在基于堆的缓冲区溢出漏洞。远程攻击者可借助数据包中特制的length字段利用该漏洞造成拒绝服务（设备重启）。以下产品和版本受到影响：Huawei Campus S9300/ S7700/ S9700系列交换机V200R001C00SPC300版本，V200R002C00SPC100版本，V200R003C00SPC500版本；Campus S5300/ S5700/ S6300/ S6700系列交换机V200R001C00SPC300版本，V200R002C00SPC100版本，V200R003C00SPC300版本；AR150/ AR160/ AR200/ AR1200/ AR2200/ AR3200/ AR530/ NetEngine16EX/ SRG1300/ SRG2300/ SRG3300系列路由器V200R003C01SPC900版本，V200R003C01SPC300版本，V200R003C01SPC100版本，V200R003C00SPC200版本，V200R003C00SPC100版本，V200R005C00SPC100版本，V200R005C00SPC200版本；WLAN AC6005/6605 V200R003C00SPC100版本，V200R003C00SPC200版本，V200R003C00SPC300版本，V200R003C00SPC500版本，V200R005C00SPC100版本；WLAN ACU2 V200R005C00SPC100版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.huawei.com/en/psirt/security-advisories/hw-345171

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-1088


【漏洞名称】WordPress Splashing Images插件安全漏洞

【漏洞编号】CNNVD-201801-1076（CVE-2018-6195）

【漏洞详情】WordPress是WordPress软件基金会的一套使用PHP语言开发的博客平台，该平台支持在PHP和MySQL的服务器上架设个人博客网站。Splashing Images（wp-splashing-images）是使用在其中的一个图片选择插件。

WordPress Splashing Images插件2.1.1之前版本中的admin/partials/wp-splashing-admin-main.php文件存在安全漏洞。攻击者可通过向wp-admin/upload.php文件发送带有特制序列化的‘session’ HTTP GET参数利用该漏洞实施PHP对象注入攻击。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/wp-splashing-images/#developers

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-1076


【漏洞名称】BMC Track-It! 安全漏洞

【漏洞编号】CNNVD-201801-1079（CVE-2016-6599）

【漏洞详情】BMC Track-It!是美国BMC Software公司的一套专为中小企业提供的全面集成的IT帮助台和资产管理解决方案。该方案提供工单跟踪、变更管理、流程自动化、资产清单和资产管理等功能。

BMC Track-It! 11.4 Hotfix 3之前的11.4版本中存在安全漏洞。攻击者可利用该漏洞检索配置文件（包含：数据库名称、用户名、密码、域管理员名和密码）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://communities.bmc.com/community/bmcdn/bmc_track-it/blog/2016/01/04/track-it-security-advisory-24-dec-2015

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-1079
