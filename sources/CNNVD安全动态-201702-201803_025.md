今日CNNVD共发布安全漏洞41个，更新安全漏洞22个。主要影响厂商为美国IBM（11个）、美国Mozilla（2个）、中国联想（2个），主要影响产品为IBM Rational DOORS需求软件（11个）、Mozilla Firefox开源Web浏览器（2个）、Lenovo System x服务器（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****IBM Rational DOORS IBM Doors Web Access 跨站脚本漏洞**  

**【漏洞编号】****CNNVD-201801-1013（CVE-2017-1567）**

**【漏洞详情】**IBM Rational DOORS是美国IBM公司的一套用于捕获、跟踪、分析和管理需求的软件。该软件提供了一个用于全球团队协作的单一平台，以便更有效地管理需求，共享统一的用户、服务器和项目管理。IBM Doors Web Access是其中的一个Web端访问程序。

IBM Rational DOORS中的IBM Doors Web Access 9.5版本和9.6版本存在跨站脚本漏洞。远程攻击者可利用该漏洞向Web UI注入任意的JavaScript脚本。以下版本受到影响：IBM Rational DOORS 9.5.0.0版本至9.5.0.7版本，9.5.1.0版本至9.5.1.8版本，9.5.2.0版本至9.5.2.7版本，9.6.0.0版本至9.6.0.6版本，9.6.1.0版本至9.6.1.9版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22012789

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-1013

  

**【漏洞名称】****Mozilla Firefox 安全漏洞**  

**【漏洞编号】****CNNVD-201801-945（CVE-2018-5109）**

**【漏洞详情】**Mozilla Firefox是美国Mozilla基金会开发的一款开源Web浏览器。

Mozilla Firefox 58之前的版本中存在安全漏洞。远程攻击者可利用该漏洞捕获音频流。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.mozilla.org/en-US/security/advisories/mfsa2018-02/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-945

  

**【漏洞名称】****Lenovo System x系列和IBM System x系列安全漏洞**  

**【漏洞编号】****CNNVD-201801-1035（CVE-2017-3768）**

**【漏洞详情】**Lenovo System x是中国联想（Lenovo）公司的一款服务器。IBM System x是美国IBM公司的一款服务器。

Lenovo System x系列4.4之前版本和IBM System x系列6.4之前版本中存在安全漏洞。攻击者可借助大量失败的身份验证请求利用该漏洞造成拒绝服务（重启）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.lenovo.com/us/zh/product\_security/len-14450

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-1035

  

**【漏洞名称】****WordPress acurax-social-media-widget插件跨站请求伪造漏洞**  

**【漏洞编号】****CNNVD-201801-1007（CVE-2018-6357）**

**【漏洞详情】**WordPress是WordPress软件基金会的一套使用PHP语言开发的博客平台，该平台支持在PHP和MySQL的服务器上架设个人博客网站。acurax-social-media-widget plugin是使用在其中的一个社交媒体链接添加插件。

WordPress acurax-social-media-widget插件3.2.6之前版本中的function.php文件的‘acx\_asmw\_saveorder\_callback’函数存在跨站请求伪造漏洞。远程攻击者可通过向wp-admin/admin-ajax.php文件发送‘recordsArray’参数利用该漏洞更新插件的social\_widget\_icon\_array\_order选项，实施跨站脚本攻击。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/acurax-social-media-widget/#developers

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-1007

  

**【漏洞名称】****VMware vRealize Automation和vSphere Integrated Containers 安全漏洞**  

**【漏洞编号】CNNVD-201801-1045（CVE-2017-4947）**

**【漏洞详情】**VMware vRealize Automation(vRA)和vSphere Integrated Containers(VIC)都是美国威睿（VMware）公司的产品。vRealize Automation(vRA)是一套云计算自动化软件。该软件支持自动交付个性化基础架构，跨多供应商、混合云基础架构进行部署，简化应用发布自动化和持续交付等。vSphere Integrated Containers(VIC)是一套企业级容器基础架构，支持在通用平台上运行传统应用和容器化应用。

VMware vRA 7.3、7.2和VIC 1.x版本中存在反序列化漏洞。远程攻击者可利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.vmware.com/security/advisories/VMSA-2018-0006.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-1045
