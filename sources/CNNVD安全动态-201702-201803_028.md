今日CNNVD共发布安全漏洞30个，更新安全漏洞34个。主要影响厂商为美国CloudBees（8个）、美国HP（6个）、美国Apache（2个），主要影响产品为CloudBees Jenkins持续集成工具（8个）、HP JetAdvantage Security Manager安全解决方案（2个）、Apache NiFi数据处理和分发系统（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****CloudBees Jenkins Translation Assistance Plugin 跨站请求伪造漏洞**  

**【漏洞编号】****CNNVD-201801-883（CVE-2018-1000014）**

**【漏洞详情】**CloudBees Jenkins是美国CloudBees公司的一套基于Java开发的持续集成工具，它主要用于监控持续的软件版本发布/测试项目和一些定时执行的任务。Translation Assistance Plugin是使用在其中的一个协助翻译插件。

CloudBees Jenkins Translation Assistance Plugin 1.15及之前的版本中存在跨站请求伪造漏洞，该漏洞源于程序没有要求以POST请求提交表格。远程攻击者可利用该漏洞覆盖显示给用户的本地化字符串。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://jenkins.io/security/advisory/2018-01-22/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-883

  

**【漏洞名称】****HP JetAdvantage Security Manager 安全漏洞**  

**【漏洞编号】****CNNVD-201801-874（CVE-2017-2746）**

**【漏洞详情】**HP JetAdvantage Security Manager是美国惠普（HP）公司的一套用于管理HP打印设备的安全解决方案。

HP JetAdvantage Security Manager 3.0.1之前的版本中存在安全漏洞。攻击者可利用该漏洞实施跨站脚本攻击，造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.hp.com/us-en/document/c05639510

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-874

  

**【漏洞名称】****Apache NiFi 安全漏洞**  

**【漏洞编号】****CNNVD-201801-866（CVE-2017-15697）**

**【漏洞详情】**Apache NiFi是美国阿帕奇（Apache）软件基金会的一套基于数据流的数据处理和分发系统。该系统支持数据路由指示图的配置和转换以及系统中介逻辑等。

Apache NiFi 1.0.0版本至1.4.0版本中存在安全漏洞。远程攻击者可借助带有外部资源或嵌入代码的恶意X-ProxyContextPath或X-Forwarded-Context包头利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://nifi.apache.org/security.html#CVE-2017-15697

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-866

  

**【漏洞名称】****Symantec Reporter 安全漏洞**  

**【漏洞编号】****CNNVD-201801-868（CVE-2017-15531）**

**【漏洞详情】**Symantec Reporter是美国赛门铁克（Symantec）公司的一套用于日志的收集、存储以及查看功能的软件。

Symantec Reporter 9.5.4.1之前的9.5版本和10.2之前的10.x版本中存在安全漏洞，该漏洞源于程序没有限制身份验证请求次数。远程攻击者可借助暴力搜索利用该漏洞猜测用户密码，获取访问权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.symantec.com/security-center/network-protection-security-advisories/SA158

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-868

  

**【漏洞名称】****多款产品安全漏洞**  

**【漏洞编号】CNNVD-201801-890（CVE-2015-1142857）**

**【漏洞详情】**Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。Linux kernel ixgbe driver和i40e/i40evf driver是其中的网卡驱动程序；DPDK是其中的一个数据平面开发套件。

多款产品中存在安全漏洞。攻击者可利用该漏洞控制其它虚拟机的吞吐量和延迟。以下产品和版本受到影响：Linux kernel ixgbe驱动程序commit f079fa005aae08ee0e1bc32699874ff4f02e11c1之前的版本；Linux Kernel i40e/i40evf驱动程序e7358f54a3954df16d4f87e3cad35063f1c17de5之前的版本；DPDK commit 3f12b9f23b6499ff66ec8b0de941fb469297e5d0之前的版本及多个产商适配器固件。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.kernel.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-890
