今日CNNVD共发布安全漏洞35个，更新安全漏洞1个。主要影响厂商为美国Oracle（29个）、美国F5（1个）、韩国Hancom（1个），主要影响产品为Oracle Financial Services Applications金融服务软件（21个）、F5 BIG-IP LTM本地流量管理器（1个）、Hancom NEO办公软件套件（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Oracle Financial Services Applications Oracle Financial Services Funds Transfer Pricing组件安全漏洞

【漏洞编号】CNNVD-201801-639（CVE-2018-2729）

【漏洞详情】Oracle Financial Services Applications是美国甲骨文（Oracle）公司的一套集核心银行、网上银行和财产管理于一身的金融服务软件。Oracle Financial Services Funds Transfer Pricing是其中的一个金融服务资金转移定价组件。

Oracle Financial Services Applications中的Oracle Financial Services Funds Transfer Pricing组件6.1.x版本和8.0.x版本的User Interface子组件存在安全漏洞。攻击者可利用该漏洞未授权访问、创建、删除或更改数据，影响数据的保密性和完整性。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.oracle.com/technetwork/security-advisory/cpujan2018-3236628.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-639


【漏洞名称】多款F5产品安全漏洞

【漏洞编号】CNNVD-201710-1363

【漏洞详情】F5 BIG-IP LTM等都是美国F5公司的产品。F5 BIG-IP LTM是一款本地流量管理器；BIG-IP AAM是一款应用程序加速管理器。

多款F5产品中存在安全漏洞。攻击者可利用该漏洞造成拒绝服务。以下产品和版本受到影响：BIG-IP LTM 13.0.0版本，12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本，11.5.1版本至11.5.4版本；BIG-IP AAM 13.0.0版本，12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本，11.5.1版本至11.5.4版本；BIG-IP AFM 13.0.0版本，12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本，11.5.1版本至11.5.4版本；BIG-IP Analytics 13.0.0版本，12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本，11.5.1版本至11.5.4版本；BIG-IP APM 13.0.0版本，12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本，11.5.1版本至11.5.4版本；BIG-IP ASM 13.0.0版本，12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本，11.5.1版本至11.5.4版本；BIG-IP DNS 13.0.0版本，12.0.0版本至12.1.2版本；BIG-IP GTM 11.6.0版本至11.6.1版本，11.5.1版本至11.5.4版本；BIG-IP Link Controller 13.0.0版本，12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本，11.5.1版本至11.5.4版本；BIG-IP PEM 13.0.0版本，12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本，11.5.1版本至11.5.4版本；BIG-IP WebSafe 13.0.0版本，12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

【漏洞编号】CNNVD-201801-595（CVE-2018-5195）

【漏洞详情】Hancom NEO是韩国Hancom公司开发的是韩国Hancom公司开发的一款办公软件套件产品。

【漏洞名称】Oracle Hyperion Oracle Hyperion Planning组件安全漏洞

【漏洞编号】CNNVD-201801-635（CVE-2018-2733）

【漏洞详情】Oracle Hyperion是美国甲骨文（Oracle）公司的一套财务建模应用软件，它提供财务结算、报表制作等功能。Oracle Hyperion Planning是其中的一个计划任务组件。

Oracle Hyperion中的Oracle Hyperion Planning组件11.1.2.4.007版本的Security子组件存在安全漏洞。攻击者可利用该漏洞控制组件，影响数据的完整性、保密性和可用性。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.oracle.com/technetwork/security-advisory/cpujan2018-3236628.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-635


【漏洞名称】rsync rsyncd 安全漏洞

【漏洞编号】CNNVD-201801-592（CVE-2018-5764）

【漏洞详情】rsync是澳大利亚软件开发者安德鲁-垂鸠（Andrew Tridgell）和保罗-麦可拉斯（Paul Mackerras）共同研发的一套用于类Unix系统中的数据镜像备份应用程序，它能够同步更新两处计算机的文件与目录，并利用差分编码减少数据传输。rsyncd是其中的一个守护进程。

rsync 3.1.3之前的版本中的rsyncd的options.c文件的‘parse_arguments’函数存在安全漏洞，该漏洞源于程序没有阻止多次使用--protect-args。远程攻击者可利用该漏洞绕过参数过滤保护机制。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://download.samba.org/pub/rsync/src-previews/rsync-3.1.3pre1-NEWS

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-592
