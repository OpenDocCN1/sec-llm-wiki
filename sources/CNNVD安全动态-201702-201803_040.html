今日CNNVD共发布安全漏洞39个，更新安全漏洞51个。主要影响厂商为美国Microsoft（14个）、美国Google（5个）、美国IBM（5个），主要影响产品为Microsoft Office办公软件（6个）、Android开源操作系统（5个）、IBM Security Key Lifecycle Manager生命周期管理软件（3个）。

今日需关注的典型漏洞如下:

【漏洞名称】Microsoft Office 2016 for Mac 安全漏洞

【漏洞编号】CNNVD-201801-386（CVE-2018-0819）

【漏洞详情】Microsoft Office 2016 for Mac是美国微软（Microsoft）公司开发的一款基于Mac平台的办公软件套件产品。

基于Mac平台的Microsoft Office 2016中存在安全漏洞，该漏洞源于程序没有正确的处理邮件地址的加密和显示。本地攻击者可通过发送特制的邮件附件利用该漏洞造成反病毒和反垃圾邮件扫描无法正常工作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2018-0819

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-386


【漏洞名称】Android Qualcommr Driver 权限许可和访问控制漏洞

【漏洞编号】CNNVD-201801-360（CVE-2017-15848）

【漏洞详情】Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Qualcommr Driver是使用在其中的一个美国高通（Qualcomm）公司开发的高通驱动程序。

Android中的Qualcommr Driver存在提权漏洞。远程攻击者可利用该漏洞获取权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/pixel/2018-01-01

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-360


【漏洞名称】IBM Security Access Manager 安全漏洞

【漏洞编号】CNNVD-201801-378（CVE-2017-1534）

【漏洞详情】IBM Security Access Manager是美国IBM公司的一款应用于信息安全管理的产品。该产品通过面向Web、移动和云计算的集成设备来实现访问管理控制。

IBM Security Access Manager中存在开放重定向漏洞。远程攻击者可通过诱使用户访问恶意的网站利用该漏洞伪造URL，将用户重定向到恶意的网站，实施钓鱼攻击，获取敏感信息。以下版本受到影响：IBM Security Access Manager for Web 8.0版本至8.0.1.6版本，IBM Security Access Manager for Mobile 8.0版本至8.0.1.6版本，IBM Security Access Manager 9.0版本至9.0.3.0版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22008936

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-378


【漏洞名称】Juniper Junos Space Network Management Platform 安全漏洞

【漏洞编号】CNNVD-201801-357（CVE-2018-0013）

【漏洞详情】Juniper Junos Space Network Management Platform是美国瞻博网络（Juniper Networks）公司的一套网络管理平台。该平台支持在设备和服务的整个生命周期内对其进行自动配置、监控和故障排除。

Juniper Junos Space Network Management Platform中存在本地包含漏洞。攻击者可利用该漏洞检索系统中的文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://kb.juniper.net/InfoCenter/index?page=content&id=JSA10838&actp=METADATA

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-357


【漏洞名称】Apache Geode cluster 安全漏洞

【漏洞编号】CNNVD-201801-384（CVE-2017-12622）

【漏洞详情】Apache Geode cluster是美国阿帕奇（Apache）软件基金会的一套应用于分布式云架构中提供对数据密集型应用程序实时和一致访问数据的管理平台。

Apache Geode cluster 1.3.0之前的版本中存在安全漏洞。攻击者可利用该漏洞获取状态信息并控制集群成员。 

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lists.apache.org/thread.html/560578479dabbdc93d0ee8746b7c857549202ef82f43aa22496aa589@%3Cuser.geode.apache.org%3E

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-384
