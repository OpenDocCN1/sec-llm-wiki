今日CNNVD共发布安全漏洞46个，更新安全漏洞11个。主要影响厂商为印度PHP Scripts Mall（8个）、美国Linux（2个）、美国Oracle（1个），主要影响产品为PHP Scripts Mall Muslim Matrimonial Script网站脚本（8个）、Linux kernel内核（2个）、Oracle Java SE软件开发工具包（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****PHP Scripts Mall Muslim Matrimonial Script 跨站脚本漏洞**  

**【漏洞编号】****CNNVD-201801-028（CVE-2017-17988）**

**【漏洞详情】**PHP Scripts Mall Muslim Matrimonial Script是印度PHP Scripts Mall公司的一套基于PHP的面向穆斯林的婚恋网站脚本。

PHP Scripts Mall Muslim Matrimonial Script中存在跨站脚本漏洞。远程攻击者可通过向admin/event\_add.php文件发送‘event\_title’参数利用该漏洞注入任意的Web脚本或HTML。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.phpscriptsmall.com/product/matrimonial-script/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-028

  

**【漏洞名称】****Linux kernel 安全漏洞**  

**【漏洞编号】****CNNVD-201801-053（CVE-2016-3695）**

**【漏洞详情】**Linux kernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。

Linux kernel中的drivers/acpi/apei/einj.c文件的‘einj\_error\_inject’函数存在安全漏洞。本地攻击者可利用该漏洞模拟硬件错误，进而造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/mjg59/linux/commit/d7a6be58edc01b1c66ecd8fcc91236bfbce0a420

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-053

  

**【漏洞名称】****Oracle OpenJDK和Java SE jarsigner 安全漏洞**  

**【漏洞编号】****CNNVD-201801-042（CVE-2013-4578）**

**【漏洞详情】**Oracle OpenJDK和Java SE都是美国甲骨文（Oracle）公司的产品。OpenJDK是一个Java平台的开源参考实现。Oracle Java SE是一个Java软件开发工具包。jarsigner是其中的一个命令行工具。

Oracle OpenJDK和Java SE 7u51之前的版本中的jarsigner存在安全漏洞。远程攻击者可利用该漏洞绕过代码签名保护机制并向已签名的JAR文件中注入未签名的字节码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://hg.openjdk.java.net/jdk7u/jdk7u/jdk/rev/d5f36e1c927e

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-042

  

**【漏洞名称】****WordPress Z-URL Preview插件跨站脚本漏洞**  

**【漏洞编号】****CNNVD-201801-004（CVE-2017-18012）**

**【漏洞详情】**WordPress是WordPress软件基金会的一套使用PHP语言开发的博客平台，该平台支持在PHP和MySQL的服务器上架设个人博客网站。Z-URL Preview plugin是使用在其中的一个外部链接获取插件。

WordPress Z-URL Preview插件1.6.1版本中存在跨站脚本漏洞，该漏洞源于程序没有充分的过滤用户提交的数据。远程攻击者可通过向class.zlinkpreview.php文件发送‘url’参数利用该漏洞向浏览器中注入任意脚本代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/z-url-preview/#developers

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-004

  

**【漏洞名称】****Trustwave Secure Web Gateway 安全漏洞**  

**【漏洞编号】CNNVD-201801-014（CVE-2017-18001）**

**【漏洞详情】**Trustwave Secure Web Gateway（SWG）是美国Trustwave公司的一款Web安全网关产品。

Trustwave SWG 11.8.0.27及之前的版本中存在安全漏洞。远程攻击者可通过向/sendKey URI发送‘publicKey’参数利用该漏洞将任意的公钥添加到SSH Authorized Keys数据中，从而获取远程的root访问权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.trustwave.com/Resources/Trustwave-Software-Updates/Important-Security-Update-for-Trustwave-Secure-Web-Gateway/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201801-014
