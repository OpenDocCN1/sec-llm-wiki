今日CNNVD共发布安全漏洞71个，更新安全漏洞73个。主要影响厂商为美国IBM（17个）、奥地利IKARUS Security Software（9个）、美国VMware（4个），主要影响产品为IBM Security Guardium Database Activity Monitor数据库活动监控器（9个）、IKARUS anti.virus杀毒软件产品（9个）、VMware ESXi虚拟化平台（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****IBM Security Guardium Database Activity Monitor 跨站脚本漏洞**  

**【漏洞编号】****CNNVD-201712-761（CVE-2017-1600）**

**【漏洞详情】**IBM Security Guardium Database Activity Monitor是美国IBM公司的一款数据库活动监控器产品。该产品提供合规性自动化控制和防止内外部威胁等功能。

IBM Security Guardium Database Activity Monitor中存在跨站脚本漏洞。远程攻击者可利用该漏洞在Web UI中注入任意的JavaScript代码。以下版本受到影响：IBM Security Guardium Database Activity Monitor 10.0版本，10.0.1版本，10.1版本，10.1.2版本，10.1.3版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22009622

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201712-761

  

**【漏洞名称】****IKARUS anti.virus ntguard.sys驱动程序安全漏洞**  

**【漏洞编号】****CNNVD-201712-766（CVE-2017-14969）**

**【漏洞详情】**IKARUS anti.virus是奥地利IKARUS Security Software公司一套杀毒软件产品。ntguard.sys driver是其中的一个自我保护系统驱动程序。

IKARUS anti.virus 2.16.18之前的版本中的ntguard.sys驱动程序存在安全漏洞，该漏洞源于程序没有验证来自IOCtl 0x83000084的输入值。攻击者可利用该漏洞执行任意写入操作。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.ikarussecurity.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201712-766

  

**【漏洞名称】****Vmware ESXi、Workstation和Fusion 缓冲区错误漏洞**  

**【漏洞编号】****CNNVD-201712-748（CVE-2017-4933）**

**【漏洞详情】**VMware ESXi、Workstation和Fusion都是美国威睿（VMware）公司的产品。VMware ESXi是一套可直接安装在物理服务器上的服务器虚拟化平台；VMware Workstation是一套虚拟机软件；Fusion是一套专用于在苹果机（Mac）上运行Windows应用程序的的虚拟机软件。

Vmware ESXi、Workstation和Fusion中存在堆溢出漏洞。远程攻击者可通过发送特制的VNC数据包利用该漏洞在虚拟设备上执行任意代码。以下产品和版本受到影响：VMware ESXi ESXi650-201710401-BG之前的6.5版本；Workstation 12.5.8之前的12.x版本；Fusion 8.5.9之前的8.x版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.vmware.com/security/advisories/VMSA-2017-0021.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201712-748

  

**【漏洞名称】****Linux kernel KEYS子系统安全漏洞**  

**【漏洞编号】****CNNVD-201712-752（CVE-2017-17807）**

**【漏洞详情】**Linux kernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。KEYS subsystem是其中的一套密钥子系统。

Linux kernel 4.14.6之前的版本中的KEYS子系统存在安全漏洞，该漏洞源于程序没有进程访问控制检测。本地攻击者可利用该漏洞将密钥添加到只有搜索权限的密钥环中。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=4dca6ea1d9432052afb06baf2e3ae78188a4410b

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201712-752

  

**【漏洞名称】****Huawei TAG-AL00 信息泄露漏洞**  

**【漏洞编号】CNNVD-201712-675（CVE-2017-15340）**

**【漏洞详情】**Huawei TAG-AL00是中国华为（Huawei）公司的一款智能手机产品。

Huawei TAG-AL00 TAG-AL00C92B168版本中存在信息泄露漏洞，该漏洞源于安卓辅助功能模拟点击操作以非加密方式备份数据。攻击者可通过诱使用户安装特制的应用程序利用该漏洞获取信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20171213-05-smartphone-cn

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201712-675
