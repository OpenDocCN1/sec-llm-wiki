今日CNNVD共发布安全漏洞33个，更新安全漏洞22个。主要影响厂商为美国IBM（6个）、美国ImageMagick Studio（2个）、美国Joyent（2个），主要影响产品为IBM Sterling File Gateway文件传输软件（3个）、ImageMagick图象处理软件（2个）、Joyent Node.js网络应用平台（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】IBM Sterling File Gateway 跨站脚本漏洞

【漏洞编号】CNNVD-201712-330（CVE-2017-1632）

【漏洞详情】IBM Sterling File Gateway是美国IBM公司的一套文件传输软件。该软件可整合不同的文件传输活动中心，并帮助基于文件的数据通过因特网实现安全交换。

IBM Sterling File Gateway 2.2版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞向Web UI注入任意的JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22010549

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201712-330


【漏洞名称】ImageMagick 缓冲区错误漏洞

【漏洞编号】CNNVD-201712-351（CVE-2017-17504）

【漏洞详情】ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.7-12之前的版本中的coders/png.c文件的‘Magick_png_read_raw_profile’函数存在堆缓冲区溢出漏洞。攻击者可借助特制的文件利用该漏洞执行代码或造成拒绝服务（基于堆的缓冲区越边界读取）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.imagemagick.org

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201712-351


【漏洞名称】Joyent Node.js 信息泄露漏洞

【漏洞编号】CNNVD-201712-331（CVE-2017-15897）

【漏洞详情】Joyent Node.js是美国Joyent公司的一套建立在Google V8 JavaScript引擎之上的网络应用平台。该平台主要用于构建高度可伸缩的应用程序，以及编写能够处理数万条且同时连接到一个物理机的连接代码。

Joyent Node.js 8.X版本和9.X版本中存在信息泄露漏洞，该漏洞源于程序没有初始化缓冲区。攻击者可利用该漏洞获取信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://nodejs.org/en/blog/vulnerability/december-2017-security-releases/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201712-331


【漏洞名称】NetApp VASA Provider for Clustered Data ONTAP 安全漏洞

【漏洞编号】CNNVD-201712-342（CVE-2016-6904）

【漏洞详情】NetApp VASA Provider for Clustered Data ONTAP是美国NetApp公司的一款用于Clustered Data ONTAP（存储系统）的VASA的虚拟程序。该程序能够提供存储阵列之间的通信功能。

NetApp VASA Provider for Clustered Data ONTAP 7.0P1之前的版本中存在安全漏洞。攻击者可利用该漏洞获取身份验证证书。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://security.netapp.com/advisory/ntap-20171208-0002/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201712-342


【漏洞名称】GraphicsMagick 缓冲区错误漏洞

【漏洞编号】CNNVD-201712-352（CVE-2017-17503）

【漏洞详情】GraphicsMagick是一套简单的图像处理工具。该工具对图像提供尺寸调整、旋转、加亮等功能。

GraphicsMagick 1.3.26版本中的coders/gray.c文件的‘ReadGRAYImage’函数和magick/import.c文件的‘ImportGrayQuantumType’函数存在堆缓冲区溢出漏洞。攻击者可借助特制的文件利用该漏洞执行代码或造成拒绝服务（基于堆的缓冲区越边界读取）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.graphicsmagick.org/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201712-352
