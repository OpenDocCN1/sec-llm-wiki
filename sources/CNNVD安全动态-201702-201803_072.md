今日CNNVD共发布安全漏洞30个，更新安全漏洞33个。主要影响厂商为美国Google（20个）、美国Linux（1个）、中国友盟（1个），主要影响产品为Android on Google Pixel和Nexus开源操作系统（14个）、Linux kernel内核（1个）、Umeng Push SDK软件开发工具包（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Android Qualcomm闭源组件安全漏洞**  

**【漏洞编号】****CNNVD-201712-081（CVE-2017-15813）**

**【漏洞详情】**Android on Google Pixel和Nexus是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套运行于Google Pixel和Nexus（智能手机）中并以Linux为基础的开源操作系统。Qualcomm Closed-source是其中的一个美国高通（Qualcomm）公司开发的闭源组件。

Google Pixel和Nexus设备上的Android中的Qualcomm闭源组件存在安全漏洞。攻击者可利用该漏洞可能执行代码（释放后重用）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/pixel/2017-12-01

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201712-081

  

**【漏洞名称】****Linux kernel 安全漏洞**  

**【漏洞编号】****CNNVD-201712-072（CVE-2017-15868）**

**【漏洞详情】**Linux kernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。

Linux kernel 3.19之前的版本中的net/bluetooth/bnep/core.c文件的‘bnep\_add\_connection’函数存在安全漏洞，该漏洞源于程序没有确保l2cap套字节可用。本地攻击者可借助特制的应用程序利用该漏洞获取权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=71bb99a02b32b4cc4265118e85f6035ca72923f0

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201712-072

  

**【漏洞名称】****Umeng Push SDK导出Service组件安全漏洞**  

**【漏洞编号】****CNNVD-201712-070**

**【漏洞详情】**Umeng Push SDK是中国友盟（Umeng）公司的一套用于开发消息推送程序的软件开发工具包。导出Service组件是其中的一个导出组件。

Umeng Push SDK 3.1.3之前的3.1.X版本中的导出Service组件存在安全漏洞。攻击者可利用该漏洞恶意调用使用了友盟SDK的应用程序的任意组件，发送任意虚假消息的通知或实施远程代码执行等攻击。使用Umeng Push SDK的以下产品受到影响：搜狗手机助手（企鹅电竞）；西瓜视频；集金期货通；集金学堂；可米酷漫画；搜狐新闻（资讯版）；内涵段子；蓝盾安全卫士等。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.umeng.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201712-070

  

**【漏洞名称】****GNU C Library 数字错误漏洞**  

**【漏洞编号】****CNNVD-201712-080（CVE-2017-17426）**

**【漏洞详情】**GNU C Library（又名glibc，libc6）是一种按照LGPL许可协议发布的开源免费的C语言编译程序。

GNU C Library 2.26版本中的‘malloc’函数存在整数溢出漏洞，该漏洞源于程序返回的内存块较小。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://sourceware.org/bugzilla/show\_bug.cgi?id=22375

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201712-080

  

**【漏洞名称】****多款产品postgresql-common包安全漏洞**  

**【漏洞编号】CNNVD-201712-095（CVE-2016-1255）**

**【漏洞详情】**Debian是Debian Project合作组织创建的以Linux或FreeBSD为内核的自由操作系统。wheezy、jessie和unstable都是Debian的分支版本。Ubuntu是英国科能（Canonical）公司和Ubuntu基金会共同开发的一套以桌面应用为主的GNU/Linux操作系统。postgresql-common package是一个使用在Linux中的PostgresSQL数据库集群管理器。

多款产品中的postgresql-common包的pg\_ctlcluster脚本存在安全漏洞。本地攻击者可通过对/var/log/postgresql中的日志文件实施符号链接攻击利用该漏洞获取root权限。以下产品和版本受到影响：Debian wheezy 134wheezy5之前的版本；Debian jessie 165+deb8u2之前的版本；Debian unstable 178之前的版本；Ubuntu  129ubuntu1.2之前的2.04 LTS版本；Ubuntu 154ubuntu1.1之前的14.04版本；Ubuntu 173ubuntu0.1之前的16.04版本；Ubuntu 179ubuntu0.1之前的17.04版本；Ubuntu 184ubuntu1.1之前的17.10版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://usn.ubuntu.com/usn/USN-3476-2/

https://lists.debian.org/debian-lts-announce/2017/01/msg00002.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201712-095
