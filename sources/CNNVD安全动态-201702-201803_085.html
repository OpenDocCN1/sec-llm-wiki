CNNVD最新漏洞（2017-11-23）

今日CNNVD共发布安全漏洞80个，更新安全漏洞5个。主要影响厂商为美国Intel（7个）、美国VMware（6个）、美国Scilico（4个），主要影响产品为Intel Xeon Processor E3-1200中央处理器（7个）、VMWare Workstation和Fusion虚拟计算机软件（6个）、Scilico I，Librarian文件管理系统（4个）。

今日需关注的典型漏洞如下:

【漏洞名称】多款Intel产品Manageability Engine Firmware 缓冲区错误漏洞

【漏洞编号】CNNVD-201711-881（CVE-2017-5711）

【漏洞详情】Intel Xeon Processor E3-1200等都是美国英特尔（Intel）公司的CPU（中央处理器）。Manageability Engine Firmware是一款使用在CPU（中央处理器）中的管理引擎。Active Management Technology（AMT）是其中的一个主动管理组件。

多款Intel产品中的Manageability Engine Firmware的AMT存在缓冲区溢出漏洞。拥有本地系统访问权限的攻击者可利用该漏洞执行任意代码。以下产品和版本受到影响：Intel Manageability Engine Firmware 8.x版本，9.x版本，10.x版本，11.0版本，11.5版本，11.6版本，11.7版本，11.10版本，11.20版本；6th、7th和8th Generation Intel Core Processor Family；Intel Xeon Processor E3-1200 v5和v6 Product Family；Intel Xeon Processor Scalable Family；Intel Xeon Processor W Family；Intel Atom C3000 Processor Family；Apollo Lake Intel Atom Processor E3900 series；Apollo Lake Intel Pentium；Celeron N和J series Processors。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://security-center.intel.com/advisory.aspx?intelid=INTEL-SA-00086&languageid=en-fr

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-881


【漏洞名称】VMWare Workstation和Fusion 安全漏洞

【漏洞编号】CNNVD-201711-720（CVE-2017-4938）

【漏洞详情】VMWare Workstation和Fusion都是美国威睿（VMware）公司的桌面虚拟计算机软件，前者提供可以同时运行多个不同的操作系统的虚拟机功能，后者是用于在苹果机（Mac）上运行Windows应用程序的虚拟机软件。

VMware Workstation 12.5.8之前的12.x版本和Fusion 8.5.9之前的8.x版本中存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（空指针逆向引用和崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.vmware.com/security/advisories/VMSA-2017-0018.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-720


【漏洞名称】Scilico I，Librarian 安全漏洞

【漏洞编号】CNNVD-201711-748（CVE-2017-1000237）

【漏洞详情】Scilico I，Librarian是美国Scilico公司的一套在线PDF文件管理系统。

Scilico I，Librarian 4.6及之前的版本和4.7版本中的ajaxsupplement.php文件存在服务器端请求伪造漏洞。攻击者可利用该漏洞重置用户密码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://i-librarian.net/article.php?id=9

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-748


【漏洞名称】Creolabs Gravity 缓冲区错误漏洞

【漏洞编号】CNNVD-201711-761（CVE-2017-1000173）

【漏洞详情】Creolabs Gravity是意大利Creolabs公司的一款开源的轻量级嵌入式编程语言。该语言支持程序编程、面向对象编程、功能编程和数据驱动编程。

Creolabs Gravity 1.0版本中存在堆缓冲区溢出漏洞。攻击者可利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/marcobambini/gravity/issues/172

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-761


【漏洞名称】libxls 缓冲区错误漏洞

【漏洞编号】CNNVD-201711-586（CVE-2017-2919）

【漏洞详情】libxls是一个用于读取Exce（xls）文件的C语言库。

libxls 1.3.4版本中的‘xls_getfcell’函数存在基于栈的缓冲区溢出漏洞。远程攻击者可通过发送恶意的XLS文件利用该漏洞执行代码（内存损坏）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://libxls.sourceforge.net/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-586
