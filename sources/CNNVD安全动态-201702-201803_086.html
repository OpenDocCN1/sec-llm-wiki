今日CNNVD共发布安全漏洞78个，更新安全漏洞14个。主要影响厂商为美国Adobe（34个）、美国Mozilla（9个）、美国Recurly（2个），主要影响产品为Adobe Acrobat DC解决方案（33个）、Mozilla Firefox Web浏览器（9个）、Recurly Client Python Library封装器（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】多款Adobe产品安全漏洞

【漏洞编号】CNNVD-201711-813（CVE-2017-16366）

【漏洞详情】Adobe Acrobat DC等都是美国奥多比（Adobe）公司的产品。Acrobat DC是一套桌面版PDF解决方案；Acrobat Reader DC是一套用于查看、打印和批注PDF的工具。Classic和Continuous是Acrobat DC和Acrobat Reader DC产品下载中心所提供的两种更新机制。

多款Adobe产品中存在安全绕过漏洞。远程攻击者可利用该漏洞绕过安全限制，执行未授权的操作。基于Windows和Macintosh平台的以下产品和版本受到影响：Acrobat DC (Continuous Track) 2017.012.20098及之前的版本；Acrobat Reader DC (Continuous Track) 2017.012.20098及之前的版本；Acrobat 2017 2017.011.30066及之前的版本；Acrobat Reader 2017 2017.011.30066及之前的版本；Acrobat DC (Classic Track) 2015.006.30355及之前的版本；Acrobat Reader DC (Classic Track) 2015.006.30355及之前的版本；Acrobat 11.0.22及之前的版本；Reader 11.0.22及之前的版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://helpx.adobe.com/security/products/acrobat/apsb17-36.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-813


【漏洞名称】Mozilla Firefox 安全漏洞

【漏洞编号】CNNVD-201711-437（CVE-2017-5427）

【漏洞详情】Mozilla Firefox是美国Mozilla基金会开发的一款开源Web浏览器。

Mozilla Firefox 52之前的版本中存在安全漏洞。攻击者可通过将chrome.manifest和其他引用文件放到主安装路径利用该漏洞添加任意软件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.mozilla.org/en-US/security/advisories/mfsa2017-05/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-437


【漏洞名称】Recurly Client Python Library 安全漏洞

【漏洞编号】CNNVD-201711-379（CVE-2017-0906）

【漏洞详情】Recurly Client Python Library是美国Recurly公司的一款用于Recurly的Python API封装器。

Recurly Client Python Library中的‘Resource.get’方法存在服务器端请求伪造攻击。攻击者可利用该漏洞控制API密钥或其他重要资源。以下版本受到影响：Recurly Client Python Library 2.0.5之前的版本，2.1.16之前的版本，2.2.22之前的版本，2.3.1之前的版本，2.4.5之前的版本，2.5.1之前的版本，2.6.2之前的版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://dev.recurly.com/page/python-updates

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-546


【漏洞名称】Apple iOS和macOS Sierra Security 竞争条件漏洞

【漏洞编号】CNNVD-201711-454（CVE-2017-7004）

【漏洞详情】Apple iOS和macOS Sierra都是美国苹果（Apple）公司的产品。Apple iOS是为移动设备所开发的一套操作系统；macOS Sierra是为Mac计算机所开发的一套专用操作系统。Security是其中的一个信息安全和隐私保护的组件。

Apple iOS 10.3.1之前的版本和macOS Sierra 10.12.5之前的版本中的Security组件存在竞争条件漏洞。攻击者可借助本地应用程序利用该漏洞发送特权XPC消息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/en-us/HT207797

https://support.apple.com/en-us/HT207798

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-454


【漏洞名称】Cisco ASA Next-Generation Firewall Services 安全漏洞

【漏洞编号】CNNVD-201711-679（CVE-2017-12299）

【漏洞详情】Cisco ASA Next-Generation Firewall Services是美国思科（Cisco）公司的一套运行在下一代防火墙产品中的模块化安全服务套件。

Cisco ASA Next-Generation Firewall Services中的创建默认IP封锁进程存在安全漏洞。在安装设备时，远程攻击者可通过向目标设备的本地IP地址发送流量利用该漏洞连接到设备的本地IP地址上。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bst.cloudapps.cisco.com/bugsearch/bug/CSCvd97962

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-679
