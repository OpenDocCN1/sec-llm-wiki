今日CNNVD共发布安全漏洞51个，更新安全漏洞45个。主要影响厂商为美国Microsoft（42个）、德国Siemens（3个）、加拿大BlackBerry（3个），主要影响产品为Microsoft Windows操作系统（34个）、Siemens SICAM RTUs变电站控制器（3个）、BlackBerry QNX Software Development Platform（SDP）软件开发平台（3个）。

今日需关注的典型漏洞如下:

【漏洞名称】Microsoft Windows Graphics组件信息泄露漏洞

【漏洞编号】CNNVD-201711-507（CVE-2017-11850）

【漏洞详情】Microsoft Windows 8.1等都是美国微软（Microsoft）公司发布的操作系统。Graphics是其中的一个图形驱动器组件。

Microsoft Windows中的Graphics组件存在信息泄露漏洞，该漏洞源于程序没有正确的处理内存中的对象。本地攻击者可通过登录受影响的系统并运行特制的应用程序利用该漏洞获取信息。以下版本受到影响：Microsoft Windows 8.1和RT 8.1，Windows Server 2012和R2，Windows 10，Windows 10版本1511，Windows 10版本1607，Windows 10版本1703，Windows 10版本1709，Windows Server 2016，Windows Server版本1709。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-11850

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-507


【漏洞名称】Siemens SICAM RTUs SM-2556 COM Modules 安全漏洞

【漏洞编号】CNNVD-201711-556（CVE-2017-12739）

【漏洞详情】Siemens SICAM RTUs是德国西门子（Siemens）公司的一款变电站控制器。SM-2556 COM Modules是使用在其中的一个用于LAN/WAN的通信模块。

Siemens SICAM RTUs SM-2556 COM Modules中存在安全漏洞。远程攻击者可借助受影响设备的集成服务器（80端口/tcp）利用该漏洞在受影响的设备上执行任意代码。使用以下固件的产品受到影响：ENOS00；ERAC00；ETA2；ETLS00；MODi00；DNPi00。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.siemens.com/cert/pool/cert/siemens_security_advisory_ssa-164516.pdf

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-556


【漏洞名称】BlackBerry QNX Software Development Platform 安全漏洞

【漏洞编号】CNNVD-201711-482（CVE-2017-3893）

【漏洞详情】BlackBerry QNX Software Development Platform（SDP）是加拿大黑莓（BlackBerry）公司的一套软件开发平台，专用于开发基于QNX系统的软件。

BlackBerry QNX SDP 6.6.0版本中的QNX SDP系统的默认配置存在安全漏洞。攻击者可利用该漏洞覆盖表格内容，调用任意函数。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://support.blackberry.com/kb/articleDetail?language=en_US&articleNumber=000046674

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-482


【漏洞名称】Android NVIDIA Thermal驱动程序权限许可和访问控制漏洞

【漏洞编号】CNNVD-201711-490（CVE-2017-6274）

【漏洞详情】Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。NVIDIA Thermal driver是其中的一个温度控制组件。

Android中的NVIDIA Thermal驱动程序存在提权漏洞，该漏洞源于缺少边界检测。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/pixel/2017-11-01#announcements

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-490


【漏洞名称】private_address_check ruby gem 安全漏洞

【漏洞编号】CNNVD-201711-381（CVE-2017-0904）

【漏洞详情】private_address_check ruby gem是一款基于Ruby的服务器端请求伪造攻击检查工具。

private_address_check ruby gem 0.4.0之前的版本中存在安全漏洞，该漏洞源于程序使用了Ruby的Resolv.getaddresses方法。攻击者可利用该漏洞绕过客户端请求伪造过滤器。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/jtdowney/private_address_check/commit/58a0d7fe31de339c0117160567a5b33ad82b46af

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-381
