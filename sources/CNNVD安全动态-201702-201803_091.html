今日CNNVD共发布安全漏洞59个，更新安全漏洞6个。主要影响厂商为美国Apple（16个）、美国Microsoft（10个）、美国Adobe（8个），主要影响产品为Apple macOS High Sierra操作系统（13个）、Microsoft Windows操作系统（9个）、Adobe Acrobat编辑和转换工具（8个）。

今日需关注的典型漏洞如下:

【漏洞名称】Apple macOS High Sierra PCRE 安全漏洞

【漏洞编号】CNNVD-201711-392（CVE-2017-13846）

【漏洞详情】Apple macOS High Sierra是美国苹果（Apple）公司的一套专为Mac计算机所开发的专用操作系统。PCRE是其中的一个正则表达式函数库。

Apple macOS High Sierra 10.13.1之前的版本中的PCRE组件8.40之前的版本存在安全漏洞。远程攻击者可利用该漏洞造成拒绝服务（应用程序崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/zh-cn/HT208221

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-392


【漏洞名称】Microsoft Windows Search 安全漏洞

【漏洞编号】CNNVD-201711-519（CVE-2017-11788）

【漏洞详情】Microsoft Windows Server 2016等都是美国微软（Microsoft）公司发布的操作系统。Search是其中的一个搜索组件。

Microsoft Windows中的Search存在拒绝服务漏洞，该漏洞源于程序没有正确的处理内存中的对象。远程攻击者可利用该漏洞造成拒绝服务。以下版本受到影响：Microsoft Windows Server 2016，Windows Server 2012 R2，Windows Server 2012，Windows Server 2008 R2 SP1，Windows Server 2008 SP2，Windows RT 8.1，Windows 8.1，Windows 7 SP1，Windows 10版本1703，Windows 10版本1607，Windows 10版本1511，Windows 10。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-11788

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-519


【漏洞名称】Adobe Acrobat和Reader 安全漏洞

【漏洞编号】CNNVD-201711-531（CVE-2017-16396）

【漏洞详情】Adobe Acrobat和Reader都是美国奥多比（Adobe）公司的产品。前者是一套PDF文件编辑和转换工具，后者是一套PDF文档阅读软件。

Adobe Acroba和Reader中存在安全漏洞。远程攻击者可利用该漏洞在当前用户的上下文中执行任意代码。基于Windows和Macintosh平台的以下产品和版本受到影响：Acrobat DC (Continuous Track) 2017.012.20098及之前的版本；Acrobat Reader DC (Continuous Track) 2017.012.20098及之前的版本；Acrobat 2017 2017.011.30066及之前的版本；Acrobat Reader 2017 2017.011.30066及之前的版本；Acrobat DC (Classic Track) 2015.006.30355及之前的版本；Acrobat Reader DC (Classic Track) 2015.006.30355及之前的版本；Acrobat 11.0.22及之前的版本；Reader 11.0.22及之前的版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://helpx.adobe.com/security/products/acrobat/apsb17-36.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-531


【漏洞名称】Oracle Fusion Middleware Oracle Tuxedo组件安全漏洞

【漏洞编号】CNNVD-201711-477（CVE-2017-10278）

【漏洞详情】Oracle Fusion Middleware（Oracle融合中间件）是美国甲骨文（Oracle）公司的一套面向企业和云环境的业务创新平台，该平台提供了中间件、软件集合等功能。Oracle Tuxedo是其中的一个用于开发、部署和管理任务关键型应用的组件。

Oracle Fusion Middleware中的Oracle Tuxedo组件的Security子组件存在安全漏洞。攻击者可利用该漏洞未授权访问、更新、插入或删除数据，造成拒绝服务，影响数据的保密性、完整性和可用性。以下版本受到影响：Oracle Tuxedo 11.1.1版本，12.1.1版本，12.1.3版本，12.2.2版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.oracle.com/technetwork/security-advisory/alert-cve-2017-10269-4021872.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-477


【漏洞名称】Apache Hadoop 安全漏洞

【漏洞编号】CNNVD-201711-385（CVE-2017-3166）

【漏洞详情】Apache Hadoop是美国阿帕奇（Apache）软件基金会的一套开源的分布式系统基础架构，它能够对大量数据进行分布式处理，并具有高可靠性、高扩展性、高容错性等特点。

Apache Hadoop 2.6.1版本至2.6.5版本、2.7.0版本至2.7.3版本和3.0.0-alpha1版本中存在安全漏洞。攻击者可利用该漏洞获取受HDFS透明保护的文件访问权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lists.apache.org/thread.html/2e16689b44bdd1976b6368c143a4017fc7159d1f2d02a5d54fe9310f@%3Cgeneral.hadoop.apache.org%3E

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-385
