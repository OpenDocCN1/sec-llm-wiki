# CNNVD最新漏洞（2017-11-09）

今日CNNVD共发布安全漏洞47个，更新安全漏洞30个。主要影响厂商为新西兰Catalyst IT（6个）、美国HPE（3个）、美国Cisco（3个），主要影响产品为Catalyst Mahara社交网络系统（6个）、HPE System Management Homepage（SMH）Software Web界面（3个）、Cisco IOS操作系统（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Catalyst Mahara 跨站脚本漏洞**  

**【漏洞编号】****CNNVD-201711-159（CVE-2017-1000137）**

**【漏洞详情】**Catalyst Mahara是新西兰Catalyst IT公司的一套社交网络系统。该系统包含博客、履历表生成器、文件管理器等。

Catalyst Mahara 1.10.0之前的1.10版本和15.04.0之前的15.04版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞弹出警告。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://mahara.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-159

  

**【漏洞名称】****HPE System Management Homepage Software 跨站脚本漏洞**  

**【漏洞编号】****CNNVD-201709-1367（CVE-2017-12544）**

**【漏洞详情】**HPE System Management Homepage（SMH）Software是美国惠普企业（Hewlett Packard Enterprise，HPE）公司的一个基于Web的界面。该界面可整合和简化对运行HP-UX、Linux和Microsoft Windows操作系统的HP服务器的单系统管理过程。

HPE SMH Software 7.6.1之前的版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://h20564.www2.hpe.com/hpsc/doc/public/display?docId=emr\_na-hpesbmu03753en\_us

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-1367

  

**【漏洞名称】****Cisco IOS和IOS XE Software DHCP relay子系统缓冲区错误漏洞**  

**【漏洞编号】****CNNVD-201709-1294（CVE-2017-12240）**

**【漏洞详情】**Cisco IOS和IOS XE Software都是美国思科（Cisco）公司为其网络设备开发的操作系统。DHCP relay是其中的一个用于实现在不同子网和物理网段之间处理和转发dhcp信息的功能的组件。

Cisco IOS 12.2版本至15.6版本和Cisco IOS XE Software中的DHCP relay子系统存在缓冲区溢出漏洞。远程攻击者可通过向受影响系统发送特制的DHCP Version 4(DHCPv4)数据包利用该漏洞造成拒绝服务（重新加载）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20170927-dhcp

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-1294

  

**【漏洞名称】****Android HTC bootloader 权限许可和访问控制漏洞**  

**【漏洞编号】CNNVD-201710-066（CVE-2017-0826）**

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。HTC bootloader是其中的一个启动加载程序。

Android中的HTC bootloader存在提权漏洞。远程攻击者可利用该漏洞获取或篡改信息，或造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/pixel/2017-10-01

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-066

  

**【漏洞名称】****IBM OpenPages GRC Platform 安全漏洞**  

**【漏洞编号】****CNNVD-201711-026（CVE-2017-1148）**

**【漏洞详情】**IBM OpenPages GRC Platform是美国IBM公司的一套用于管理企业风险和合规性挑战的治理、风险和合规性平台。该平台提供一组涵盖风险和合规性领域（包括操作风险、策略和合规性、财务控制管理的等）的核心服务和功能组件。OpenPages Loss Event Entry（LEE）application是其中的一个事件输入应用程序。

使用OpenPages LEE应用程序的IBM OpenPages GRC Platform 7.2版本和7.3版本中存在安全漏洞。攻击者可利用该漏洞获取敏感信息（包括私有API）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22009717

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-026
