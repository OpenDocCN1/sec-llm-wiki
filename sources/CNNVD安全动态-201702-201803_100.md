# CNNVD最新漏洞（2017-11-08）

今日CNNVD共发布安全漏洞48个，更新安全漏洞15个。主要影响厂商为美国Linux（14个）、美国Circle Media（11个）、爱尔兰Cesanta（7个），主要影响产品为Linux kernel内核（14个）、Circle with Disney网络监控管理设备（11个）、Cesanta Mongoose服务器（7个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Linux kernel 安全漏洞**  

**【漏洞编号】****CNNVD-201711-144（CVE-2017-16538）**

**【漏洞详情】**Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。

Linux kernel 4.13.11及之前的版本中drivers/media/usb/dvb-usb-v2/lmedm04.c文件存在安全漏洞。本地攻击者可借助特制的USB设备利用该漏洞造成拒绝服务（一般保护错误和应用程序崩溃）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.kernel.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-144

  

**【漏洞名称】****Circle with Disney 安全漏洞**  

**【漏洞编号】****CNNVD-201711-097（CVE-2017-2864）**

**【漏洞详情】**Circle with Disney是美国Circle Media公司的一套用于监控儿童上网行为的网络监控管理设备。

Circle with Disney中的身份验证令牌生成功能存在安全漏洞。攻击者可通过发送特制的网络数据包利用该漏洞获取有效的身份验证令牌，绕过身份验证。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.meetcircle.com/13577-general-help/whats-the-latest-app-and-firmware-version-of-circle?from\_search=19392044

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-097

  

**【漏洞名称】****Cesanta Mongoose 安全漏洞**  

**【漏洞编号】****CNNVD-201711-088（CVE-2017-2893）**

**【漏洞详情】**Cesanta Mongoose是爱尔兰Cesanta公司的一套嵌入式服务器。

Cesanta Mongoose 6.8版本中的MQTT数据包解析功能存在安全漏洞。攻击者可通过发送特制的MQTT数据包利用该漏洞造成拒绝服务（空指针逆向引用和服务器崩溃）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://cesanta.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-088

  

**【漏洞名称】****ImageMagick 安全漏洞**  

**【漏洞编号】CNNVD-201711-137（CVE-2017-16546）**

**【漏洞详情】**ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.7-9版本中的coders/wpg.c文件的‘ReadWPGImage’函数存在安全漏洞，该漏洞源于程序没有正确的验证WPG调色板中的色图索引。远程攻击者可借助畸形的WPG文件利用该漏洞造成拒绝服务（使用未初始化的数据和无效的内存分配）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/issues/851

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-137

**【漏洞名称】****IEEE P1735 加密问题漏洞**  

**【漏洞编号】****CNNVD-201711-226（CVE-2017-13092）**

**【漏洞详情】**IEEE P1735是一个专门用来加密电子设计的知识产权的标准。

IEEE P1735的实现存在安全漏洞。攻击者可利用该漏洞获取电子设计的知识产权。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://ieeexplore.ieee.org/document/7274481/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-226
