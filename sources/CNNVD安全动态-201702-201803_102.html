今日CNNVD共发布安全漏洞66个，更新安全漏洞2个。主要影响厂商为美国Cisco（15个）、美国Circle Media（7个）、美国F5（5个），主要影响产品为Circle with Disney网络监控管理设备（7个）、Cisco Aironet Access Points无线访问接入点设备（4个）、F5 BIG-IP LTM本地流量管理器（4个）。

今日需关注的典型漏洞如下:

【漏洞名称】Cisco Aironet Access Points IOS Software 信息泄露漏洞

【漏洞编号】CNNVD-201711-074（CVE-2017-12279）

【漏洞详情】Cisco Aironet Access Points是美国思科（Cisco）公司的一套无线访问接入点设备。IOS Software是其中的一套网络设备专用的操作系统。

Cisco Aironet Access Points中的IOS Software的数据包处理代码存在信息泄露漏洞。攻击者可通过向受影响的设备发送特制的IP数据包利用该漏洞检索内存中的内容。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bst.cloudapps.cisco.com/bugsearch/bug/CSCvc21581

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-074


【漏洞名称】Circle with Disney 命令注入漏洞

【漏洞编号】CNNVD-201711-095（CVE-2017-2890）

【漏洞详情】Circle with Disney是美国Circle Media公司的一套用于监控儿童上网行为的网络监控管理设备。

Circle with Disney 2.0.1版本中的/api/CONFIG/restore功能存在命令注入漏洞。攻击者可通过发送HTTP请求利用该漏洞注入操作系统命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.meetcircle.com/13577-general-help/whats-the-latest-app-and-firmware-version-of-circle?from_search=19392044

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201711-095


【漏洞名称】多款F5产品安全漏洞

【漏洞编号】CNNVD-201710-1359（CVE-2017-6161）

【漏洞详情】F5 BIG-IP LTM等都是美国F5公司的产品。F5 BIG-IP LTM是一款本地流量管理器；BIG-IP AAM是一款应用程序加速管理器。

多款F5产品中存在安全漏洞。攻击者可利用该漏洞绕过TLS保护，可能造成拒绝服务（资源耗尽）。以下版本和产品受到影响：F5 BIG-IP LTM 12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本，11.4.0版本至11.5.4版本，11.2.1版本；BIG-IP AAM 12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本，11.4.0版本至11.5.4版本；BIG-IP AFM 12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本，11.4.0版本至11.5.4版本；BIG-IP Analytics 12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本，11.4.0版本至11.5.4版本，11.2.1版本；BIG-IP APM 12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本，11.4.0版本至11.5.4版本，11.2.1版本；BIG-IP ASM 12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本，11.4.0版本至11.5.4版本，11.2.1版本；BIG-IP DNS 12.0.0版本至12.1.2版本；BIG-IP Edge Gateway 11.2.1版本；BIG-IP GTM 11.6.0版本至11.6.1版本，11.4.0版本至11.5.4版本，11.2.1版本；BIG-IP Link Controller 12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本，11.4.0版本至11.5.4版本，11.2.1版本；BIG-IP PEM 12.0.0版本至12.1.2版本，11.6.0版本至11.6.1版本，11.4.0版本至11.5.4版本；BIG-IP PSM 11.4.0版本至11.4.1版本；BIG-IP WebAccelerator 11.2.1版本；Enterprise Manager 3.1.1版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.f5.com/csp/article/K62279530

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-1359


【漏洞名称】CloudBees Static Analysis Utilities和DRY插件跨站脚本漏洞

【漏洞编号】CNNVD-201710-401（CVE-2017-1000103）

【漏洞详情】CloudBees Static Analysis Utilities是美国CloudBees公司的Jenkins（基于Java开发的持续集成工具）中的一个静态分析工具。DRY Plugin是其中的一个分析报告生成插件。

CloudBees Static Analysis Utilities和DRY插件中的Details视图存在跨站脚本漏洞。远程攻击者可利用该漏洞向该视图中注入任意的HTML。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://jenkins.io/security/advisory/2017-08-07/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-401


【漏洞名称】D-Link DSL-2740E 安全漏洞

【漏洞编号】CNNVD-201710-1304（CVE-2016-10699）

【漏洞详情】D-Link DSL-2740E是友讯（D-Link）公司的一款无线路由器产品。

D-Link DSL-2740E 1.00_BG_20150720版本中存在安全漏洞，该漏洞源于程序没有正确的过滤用户提交的输入。远程攻击者可利用该漏洞在浏览器中执行任意脚本代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.dlink.com.cn/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-1304
