今日CNNVD共发布安全漏洞61个，更新安全漏洞15个。主要影响厂商为美国IBM（8个）、美国Pivotal Software（4个）、中国亿中邮（1个），主要影响产品为IBM Daeja ViewONE文档查看器（3个）、Pivotal Cloud Foundry（PCF）云计算平台（4个）、Eyou Mail System电子邮件系统（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】IBM Daeja ViewONE 信息泄露漏洞

【漏洞编号】CNNVD-201710-1121（CVE-2017-1211）

【漏洞详情】IBM Daeja ViewONE是美国IBM公司的一款文档查看器，支持TIFF、PDF和基于Office的文档。IBM Daeja ViewONE Virtual、Daeja ViewONE Standard和Daeja ViewONE Professional都是它的不同版本。

IBM Daeja ViewONE中存在安全漏洞。本地攻击者可利用该漏洞获取敏感信息。以下版本受到影响：IBM Daeja ViewONE Professional 4.1.5.1版本，5.0.2版本，4.1.5版本，IBM Daeja ViewONE Standard 4.1.5.1版本，5.0.2版本，4.1.5版本，IBM Daeja ViewONE Virtual 4.1.5.1版本，5.0.2版本，4.1.5版本，5.0.0版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22008011

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-1211


【漏洞名称】Pivotal Cloud Foundry Runtime cf-release、UAA和Pivotal Cloud Foundry  Elastic Runtime 安全漏洞

【漏洞编号】CNNVD-201710-1133（CVE-2015-5173）

【漏洞详情】Pivotal Cloud Foundry（PCF）Runtime cf-release等都是美国Pivotal Software公司的产品。PCF是一套开源的平台即服务（PaaS）云计算平台，它提供容器调度、持续交付和自动化服务部署等功能。cf-release是PCF的一个发布版本。UAA是PCF的一个身份验证和管理服务终端。Pivotal Cloud Foundry (PCF) Elastic Runtime是PCF的一个运行环境。

PCF Runtime cf-release 216之前的版本、UAA 2.5.2之前的版本和PCF Elastic Runtime 1.7.0之前的版本中存在安全漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://pivotal.io/security/cve-2015-5170-5173

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-1133


【漏洞名称】Eyou Mail System 安全漏洞

【漏洞编号】CNNVD-201710-1137（CVE-2014-1203）

【漏洞详情】Eyou Mail System是中国亿中邮（eYou）公司的一套电子邮件系统。

Eyou Mail System 3.6之前的版本中的‘get_login_ip_config_file’函数存在安全漏洞。远程攻击者可通过向admin/domain/ip_login_set/d_ip_login_get.php文件发送带有shell元字符的‘domain’参数利用该漏洞执行任意命令。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.eyou.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-1137


【漏洞名称】Apache Portable Runtime Utility (APR-util) 安全漏洞

【漏洞编号】CNNVD-201710-1139（CVE-2017-12618）

【漏洞详情】Apache Portable Runtime Utility（APR-util）是美国阿帕奇（Apache）软件基金会的一个为上层应用程序提供可跨越多个操作系统平台使用的底层支持接口实用程序。

Apache Portable Runtime Utility (APR-util)1.6.0及之前的版本中存在安全漏洞，该漏洞源于程序没有验证‘apr_sdbm*()’函数使用的SDBM数据库文件的完整性。本地攻击者可利用该漏洞造成拒绝服务（越边界读取和崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://mail-archives.apache.org/mod_mbox/apr-dev/201710.mbox/%3CCACsi252POs4toeJJciwg09_eu2cO3XFg%3DUqsPjXsfjDoeC3-UQ%40mail.gmail.com%3E

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-1139


【漏洞名称】phpMyFAQ 跨站请求伪造漏洞

【漏洞编号】CNNVD-201710-982（CVE-2017-15735）

【漏洞详情】phpMyFAQ是phpMyFAQ团队开发的一套开源的完全数据库驱动的FAQ（问答）系统。该系统支持多语言、多种数据库等，并包含有内容管理系统、社区等模块

phpMyFAQ 2.9.9之前的版本中存在跨站请求伪造漏洞。远程攻击者可利用该漏洞更改词汇表。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/thorsten/phpMyFAQ/commit/867618110feb836e168435548d6c2cbb7c65eda3

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-982
