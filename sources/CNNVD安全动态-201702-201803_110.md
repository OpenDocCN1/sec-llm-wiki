# CNNVD最新漏洞（2017-10-30）

今日CNNVD共发布安全漏洞57个。主要影响厂商为意大利ProMinent（5个）、中国联想（4个）、美国HP（3个）。主要影响产品为ProMinent MultiFLEX M10a Controller Web管理界面（5个）、Lenovo Service Framework Android application应用程序（3个）、HP Intelligent Management Center PLAT管理平台（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****ProMinent MultiFLEX M10a Controller Web界面安全漏洞**  

**【漏洞编号】****CNNVD-201710-579（CVE-2017-14013）**

**【漏洞详情】**ProMinent MultiFLEX M10a Controller是意大利ProMinent公司的一款水处理控制器产品。Web interface是其中的一个Web管理界面。

ProMinent MultiFLEX M10a Controller中的Web界面存在安全漏洞，该漏洞源于注销函数只移除了客户端上的用户密钥。攻击者可利用该漏洞绕过安全保护机制，获取权限或冒充用户。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.prominent.com/  

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-579

  

**【漏洞名称】****Lenovo Service Framework Android应用程序安全漏洞**  

**【漏洞编号】****CNNVD-201710-587（CVE-2017-3761）**

**【漏洞详情】**Lenovo Service Framework Android application是中国联想（Lenovo）公司的一个基于Android平台的联想产品专用应用程序。

Lenovo Service Framework Android应用程序存在安全漏洞，该漏洞源于程序没有正确的过滤外部输入。远程攻击者可利用该漏洞注入命令，执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.lenovo.com/us/zh/product\_security/len-15374

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-587

  

**【漏洞名称】****HP Intelligent Management Center PLAT 安全漏洞**  

**【漏洞编号】****CNNVD-201710-1034（CVE-2017-12556）**

**【漏洞详情】**HP Intelligent Management Center PLAT是美国惠普（HP）公司的一套网络智能管理平台。该平台可提供整个网络范围的可视性，实现对资源、服务和用户的全面管理。

HP Intelligent Management Center PLAT 7.3 E0504P2之前的版本中存在远程代码执行漏洞。远程攻击者可利用该漏洞在受影响应用程序的上下文中执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.hpe.com/hpsc/doc/public/display?docId=emr\_na-hpesbhf03778en\_us

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-1034

  

**【漏洞名称】****Cisco IOS XE Software 安全漏洞**  

**【漏洞编号】CNNVD-201710-879（CVE-2017-12289）**

**【漏洞详情】**Cisco IOS XE Software是美国思科（Cisco）公司为其网络设备开发的操作系统。

Cisco IOS XE Software中的conditional, verbose debug logging for the IPsec功能存在信息泄露漏洞。本地攻击者可利用该漏洞显示系统日志文件中敏感的Ipsec信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20171018-cisco-ios-xe1

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-879

  

**【漏洞名称】****Oracle Database Server RDBMS Security组件权限许可和访问控制漏洞**  

**【漏洞编号】****CNNVD-201710-816（CVE-2017-10292）**

**【漏洞详情】**Oracle Database Server是美国甲骨文（Oracle）公司的一套关系数据库管理系统。该数据库管理系统提供数据管理、分布式处理等功能。RDBMS Security是其中的一个数据库安全存储组件。

Oracle Database Server 11.2.0.4版本、12.1.0.2版本和12.2.0.1版本中的RDBMS Security组件存在安全漏洞。本地攻击者可利用该漏洞未授权更新、插入或删除数据，影响数据的完整信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.oracle.com/technetwork/security-advisory/cpuoct2017-3236626.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-816
