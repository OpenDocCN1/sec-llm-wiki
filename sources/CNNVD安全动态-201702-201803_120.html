1.Android Media framework 信息泄露漏洞（CNNVD-201710-077）

Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Media framework是其中的一个用于多媒体开发框架。

Android中的Media framework存在信息泄露漏洞。远程攻击者可利用该漏洞获取敏感信息。以下版本受到影响：

-Android 7.0版本

-Android 7.1.1版本

-Android 7.1.2版本

-Android 8.0版本

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/pixel/2017-10-01

2.Ipswitch IMail Server 缓冲区错误漏洞（CNNVD-201710-443）

Ipswitch IMail Server是美国Ipswitch公司的一款运行于Microsoft Windows操作系统中的邮件服务器。

Ipswitch IMail server 12.5.5及之前的版本中存在基于栈的缓冲区溢出漏洞。远程攻击者可利用该漏洞执行任意代码。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://docs.ipswitch.com/_Messaging/IMailServer/v12.5.6/ReleaseNotes/index.htm#link8

3.QNAP QTS Helpdesk SQL注入漏洞（CNNVD-201710-349）

QNAP QTS Helpdesk是中国威联通（QNAP Systems）公司的一套Turbo NAS作业系统。该系统可提供档案储存、管理、备份，多媒体应用及安全监控等功能。Helpdesk是其中的一个帮助台程序。

QNAP QTS Helpdesk 1.1.12及之前的版本中存在SQL注入漏洞。远程攻击者可利用该漏洞获取有关Helpdesk应用程序的信息。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.qnap.com/en/security-advisory/nas-201709-29
