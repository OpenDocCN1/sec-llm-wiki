今日CNNVD共发布安全漏洞44个，更新安全漏洞63个。主要影响厂商为加拿大OpenText（6个）、美国Skybox Security（4个）、美国Linux（1个），主要影响产品为OpenText Document Sciences xPression解决方案（6个）、Skybox Manager Client Application应用程序（4个）、Linux kernel内核（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****OpenText Document Sciences xPression 安全漏洞**  

**【漏洞编号】****CNNVD-201710-437（CVE-2017-14759）**

**【漏洞详情】**OpenText Document Sciences xPression（前称EMC Document Sciences xPression）是加拿大OpenText公司的一套文档输出管理及客户沟通解决方案。该方案整合了企业的客户关系管理（CRM）、企业内容管理（ECM）和企业资源规划（ERP）系统，能够自动创作和发布产品指南手册、合同、商业信函等。

OpenText Document Sciences xPression 4.5SP1 Patch 13版本中存在XML外部实体注入漏洞。攻击者可利用该漏洞读取目录列表或系统文件，造成拒绝服务或实施跨站请求伪造攻击。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.opentext.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-437

  

**【漏洞名称】****Skybox Manager Client Application 权限许可和访问控制漏洞**  

**【漏洞编号】****CNNVD-201710-433（CVE-2017-14773）**

**【漏洞详情】**Skybox Manager Client Application是美国Skybox Security公司的一款网络安全风险分析工具的客户端管理应用程序

Skybox Manager Client Application 8.5.501之前的版本中存在提权漏洞。本地攻击者可利用该漏洞获取提升的权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lp.skyboxsecurity.com/rs/440-MPQ-510/images/Skybox\_Product\_Security\_Advisory\_9\_28\_17.pdf

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-433

  

**【漏洞名称】****Linux kernel 信息泄露漏洞**  

**【漏洞编号】****CNNVD-201710-421（CVE-2017-14991）**

**【漏洞详情】**Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。

Linux kernel 4.13.4之前版本中的drivers/scsi/sg.c文件的‘sg\_ioctl’函数存在存在安全漏洞。本地攻击者可利用该漏洞从未初始化的内核堆内存中获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://hg.graphicsmagick.org/hg/GraphicsMagick?cmd=changeset;node=b3eca3eaa264

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-421

  

**【漏洞名称】****多款WiFi产品WPA2 安全漏洞**  

**【漏洞编号】CNNVD-201710-380（CVE-2017-13077）**

**【漏洞详情】**WPA2是美国Wi-Fi联盟开发的一套Wi-Fi访问保护方案，包括安全协议和安全认证程序。

多个厂商提供的WiFi产品中的WPA2存在安全漏洞。攻击者可利用该漏洞在四次握手中重新安装成对加密密钥（PTK-TK）。以下产商提供的产品受到影响：Aruba Networks；Cisco；Espressif Systems；Fortinet, Inc.；FreeBSD Project；Google；HostAP；Intel Corporation；Juniper Networks；Microchip Technology；Microsoft Corporation；OpenBSD；Peplink；Red Hat, Inc；Samsung Mobile。更多详情请查看参考链接。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.wi-fi.org/security-update-october-2017

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-380

  

**【漏洞名称】****ImageMagick 安全漏洞**  

**【漏洞编号】****CNNVD-201710-394（CVE-2017-15015）**

**【漏洞详情】**ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.7-0 Q16版本中的coders/pdf.c文件的‘PDFDelegateMessage’函数存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（空指针逆向引用）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/issues/724

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-394
