今日CNNVD共发布安全漏洞44个。主要影响厂商为美国Google（2个）、美国ImageMagick Studio（2个）、美国HP（1个），主要影响产品为Google Go编程语言（2个）、ImageMagick图象处理软件（2个）、HP UCMDB Foundation Software资源管理软件（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Google Go 安全漏洞

【漏洞编号】CNNVD-201710-363（CVE-2017-15042）

【漏洞详情】Google Go是美国谷歌（Google）公司的一种针对多处理器系统应用程序的编程进行了优化的编程语言。

Google Go 1.8.4之前的版本和1.9.1之前的1.9.x版本中存在安全漏洞。攻击者可利用该漏洞实施中间人攻击，获取用户名称和密码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://golang.org/cl/68023

https://golang.org/cl/68210

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-363


【漏洞名称】ImageMagick 资源管理错误漏洞

【漏洞编号】CNNVD-201710-372（CVE-2017-15033）

【漏洞详情】ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.7-2版本中的coders/yuv.c文件的‘ReadYUVImage’函数存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（内存泄露）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/commit/ef8f40689ac452398026c07da41656a7c87e4683

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-372


【漏洞名称】HP UCMDB Foundation Software 代码注入漏洞

【漏洞编号】CNNVD-201710-369（CVE-2017-14353）

【漏洞详情】HP UCMDB Foundation Software是美国惠普（HP）公司的一套资源管理软件。该软件提供自底向上包括IT基础架构的自动发现、数据模型建立、服务映射定义和服务影响分析等功能。

HP UCMDB Foundation Software中存在远程代码执行漏洞。远程攻击者可利用该漏洞执行代码。以下版本受到影响：HP UCMDB Foundation Software 10.10版本，10.11版本，10.20版本，10.21版本，10.22版本，10.30版本，10.31版本，10.32版本，10.33版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://softwaresupport.hpe.com/km/KM02977984

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-369


【漏洞名称】WordPress Profile Builder插件跨站脚本漏洞

【漏洞编号】CNNVD-201710-355（CVE-2014-8492）

【漏洞详情】WordPress是WordPress软件基金会的一套使用PHP语言开发的博客平台，该平台支持在PHP和MySQL的服务器上架设个人博客网站。Profile Builder是其中的一个轮廓放样插件。

WordPress Profile Builder插件2.0.3之前的版本中的assets/misc/fallback-page.php文件存在跨站脚本漏洞。远程攻击者可借助‘site_name’、‘message’或‘site_url’参数利用该漏洞注入任意的Web脚本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/profile-builder/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-355


【漏洞名称】GNU Binutils Binary File Descriptor库安全漏洞

【漏洞编号】CNNVD-201710-374（CVE-2017-15025）

【漏洞详情】GNU Binutils（又名GNU Binary Utilities或binutils）是GNU计划开发的一组编程语言工具程序，它主要用于处理多种格式的目标文件，并提供有连接器、汇编器和其他用于目标文件和档案的工具。Binary File Descriptor（BFD）library（又名libbfd）是其中的一个以各种格式便携式操作对象文件的库。

GNU Binutils 2.29版本中的BFD库的dwarf2.c文件的decode_line_info存在安全漏洞。远程攻击者可借助特制的ELF文件利用该漏洞造成拒绝服务（除零错误和应用程序崩溃）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.gnu.org/software/binutils/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-374
