今日CNNVD共发布安全漏洞98个，更新安全漏洞38个。主要影响厂商为美国Microsoft（15个）、美国ImageMagick Studio（3个）、美国Google（2个），主要影响产品为Microsoft Windows操作系统（11个）、ImageMagick图象处理软件（3个）、Android操作系统（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】Microsoft Windows 权限许可和访问控制漏洞

【漏洞编号】CNNVD-201710-163（CVE-2017-11829）

【漏洞详情】Microsoft Windows是美国微软（Microsoft）公司发布的一系列操作系统。

Microsoft Windows中的Windows Update Delivery Optimization存在提权漏洞，该漏洞源于程序没有强制执行文件共享权限。本地攻击者可利用该漏洞覆盖文件。以下版本受到影响：Microsoft Windows 10版本1607，Windows 10版本1703，Windows Server 2016。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-11829

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-163


【漏洞名称】ImageMagick 安全漏洞

【漏洞编号】CNNVD-201710-130（CVE-2017-15218）

【漏洞详情】ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.7-2版本中的coders/png.c文件的ReadOneJNGImage存在内存损坏漏洞。攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/pixel/2017-10-01

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-130


【漏洞名称】Android Qualcomm SoC驱动程序权限许可和访问控制漏洞

【漏洞编号】CNNVD-201710-143（CVE-2017-11053）

【漏洞详情】Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Qualcomm SoC driver是其中的一个美国高通（Qualcomm）公司的芯片系统驱动程序。

Android中的Qualcomm SoC驱动程序存在权限许可和访问控制漏洞。攻击者可利用该漏洞获取提升的权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2017-10-01

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-143


【漏洞名称】Hitachi HIBUN Confidential File Decryption程序安全漏洞

【漏洞编号】CNNVD-201710-258（CVE-2017-10865）

【漏洞详情】Hitachi HIBUN Confidential File Decryption program是日本日立解决方案（Hitachi Solutions）公司的一套机密文件机密程序。

Hitachi HIBUN Confidential File Decryption程序10.50.0.5之前的版本中存在不可信的搜索路径漏洞。攻击者可借助目录下恶意的DLL利用该漏洞获取权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.hitachi-solutions.co.jp/hibun/sp/support/importance/20170929.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-258


【漏洞名称】EMC RSA Archer GRC Platform 安全漏洞

【漏洞编号】CNNVD-201710-272（CVE-2017-8025）

【漏洞详情】EMC RSA Archer GRC Platform是美国易安信（EMC）公司的一款企业IT治理和合规治理产品。该产品可以制定eGRC计划，用于管理企业风险、实现业务流程自动化等。

EMC RSA Archer GRC Platform 6.2.0.5之前的版本中存在任意文件上传漏洞。远程攻击者可通过向Web服务器上的任意路径发送附件利用该漏洞上传恶意的文件。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.emc.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-272
