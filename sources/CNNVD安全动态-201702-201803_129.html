今日CNNVD共发布安全漏洞77个。主要影响厂商为美国Microsoft（37个）、美国Apple（14个）、美国Google（8个），主要影响产品为Microsoft Windows操作系统（32个）、Android操作系统（8个）、Apple iOS操作系统（5个）。

今日需关注的典型漏洞如下:

【漏洞名称】Microsoft Windows Server Message Block服务器安全漏洞

【漏洞编号】CNNVD-201710-196（CVE-2017-11780）

【漏洞详情】Microsoft Windows是美国微软（Microsoft）公司发布的一系列操作系统。Server Message Block 1.0（SMBv1）server是其中的一个为计算机提供身份验证用以访问服务器上打印机和文件系统的组件。

Microsoft Windows中的SMBv1服务器存在远程代码执行漏洞。远程攻击者可通过向目标SMBv1服务器发送特制的数据包利用该漏洞在目标服务器上执行代码。以下版本受到影响：Microsoft Windows Server 2016，Windows Server 2012 R2，Windows Server 2012，Windows Server 2008 R2 SP1，Windows Server 2008 SP2，Windows RT 8.1，Windows 8.1，Windows 7 SP1，Windows 10版本1703，Windows 10版本1607，Windows 10版本1511，Windows 10。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-11780

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-196


【漏洞名称】多款Apple产品WebKit 安全漏洞

【漏洞编号】CNNVD-201709-1382（CVE-2017-7090）

【漏洞详情】Apple iOS、iCloud for Windows、iTunes for Windows、Safari和tvOS都是美国苹果（Apple）公司的产品。Apple iOS是一套为专移动设备所开发的一套操作系统；Safari是一款Web浏览器，是Mac OS X和iOS操作系统附带的默认浏览器。WebKit是KDE社区开发的一套开源Web浏览器引擎，目前被Apple Safari及Google Chrome等浏览器使用。

多款Apple产品中的WebKit组件存在安全漏洞。远程攻击者可利用该漏洞绕过同源策略限制，获取敏感的信息。以下产品和版本受到影响：基于Windows平台的Apple iCloud 7.0之前的版本；Safari 11之前的版本；tvOS 11之前的版本；基于Windows平台的iTunes 12.7之前的版本；iOS 11之前的版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/zh-cn/HT208113

https://support.apple.com/zh-cn/HT208116

https://support.apple.com/zh-cn/HT208140

https://support.apple.com/zh-cn/HT208112

https://support.apple.com/zh-cn/HT208142

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-1382


【漏洞名称】Android Motorola bootloader 权限许可和访问控制漏洞

【漏洞编号】CNNVD-201710-063（CVE-2017-0829）

【漏洞详情】Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Motorola bootloader是其中的一个美国摩托罗拉（Motorola）公司的装载程序。

Android中的Motorola bootloader存在提权漏洞。远程攻击者可利用该漏洞提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/pixel/2017-10-01

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-063


【漏洞名称】多款Cisco产品Firepower Threat Defense Software 安全漏洞

【漏洞编号】CNNVD-201710-060（CVE-2017-12245）

【漏洞详情】Cisco Appliance (ASA) 5500-X Series Next-Generation Firewalls等都是美国思科（Cisco）公司的防火墙产品。Firepower Threat Defense(FTD)Software是其中的一套入侵防御系统。

多款Cisco产品中的FTD Software 6.1版本和6.2版本的SSL流量加密过程存在拒绝服务漏洞。远程攻击者可通过发送恶意的Secure Sockets Layer (SSL)流量利用该漏洞造成拒绝服务（系统内存耗尽）。以下产品受到影响：Cisco Adaptive Security Appliance (ASA) 5500-X Series Next-Generation Firewalls；Firepower 2100 Series Security Appliances；Firepower 4100 Series Security Appliances；Firepower 9300 Series Security Appliances。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20171004-ftd

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-060


【漏洞名称】HPE BSM Platform Application Performance Management System Health 路径遍历漏洞

【漏洞编号】CNNVD-201709-1360（CVE-2017-13985）

【漏洞详情】HPE BSM Platform Application Performance Management System Health是美国惠普企业（Hewlett Packard Enterprise，HPE）公司的一套BSM平台的应用性能管理系统

HPE BSM Platform Application Performance Management System Health 9.26版本、9.30版本和9.40版本中存在路径遍历漏洞。远程攻击者可利用该漏洞获取信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://softwaresupport.hpe.com/km/KM02942065

【漏洞链接】
