今日CNNVD共发布安全漏洞41个，更新安全漏洞28个。主要影响厂商为美国Google（14个）、美国Intel（4个）、美国Microsoft（1个），主要影响产品为Android操作系统（14个）、Intel NUC7i3BNKCPU（中央处理器）产品（4个）、Microsoft Office办公软件（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Android Qualcomm Camera驱动程序安全漏洞

【漏洞编号】CNNVD-201710-134（CVE-2017-11063）

【漏洞详情】Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Qualcomm Camera driver是使用在其中的一个美国高通（Qualcomm）公司开发的摄像头驱动程序。

Android中的Qualcomm Camera驱动程序存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（空指针逆向引用）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/pixel/2017-10-01

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-134


【漏洞名称】多款Intel产品安全漏洞

【漏洞编号】CNNVD-201710-116（CVE-2017-5722）

【漏洞详情】Intel NUC7i3BNK等都是美国英特尔（Intel）公司的CPU（中央处理器）产品。

多款Intel产品中的系统固件存在安全漏洞。攻击者可利用该漏洞绕过完整性保护。以下产品和版本受到影响：NUC7i3BNK BN0049及之前的版本；NUC7i3BNH BN0049及之前的版本；NUC7i5BNK BN0049及之前的版本；NUC7i5BNH BN0049及之前的版本；NUC7i7BNH BN0049及之前的版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://security-center.intel.com/advisory.aspx?intelid=INTEL-SA-00084&languageid=en-fr

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-116


【漏洞名称】Microsoft Office 安全漏洞

【漏洞编号】CNNVD-201710-162（CVE-2017-11826）

【漏洞详情】Microsoft Office是美国微软（Microsoft）公司开发的一款办公软件套件产品。常用组件有Word、Excel、Access、Powerpoint、FrontPage等。

Microsoft Office中存在远程代码执行漏洞，该漏洞源于程序没有正确的处理内存中的对象。远程攻击者可利用该漏洞在当前用户的上下文中执行任意代码。以下产品受到影响：Microsoft Word Automation Services，Word 2016；Word 2013 SP1；Word 2013 RT SP1；Word 2010 SP2；Word 2007 SP3；SharePoint Enterprise Server 2016；Office Word Viewer；Office Web Apps Server 2013 SP1；Office Web Apps Server 2010 SP2；Office Online Server 2016；Office Compatibility Pack SP3。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-11826

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-162


【漏洞名称】IBM Content Navigator & CMIS 跨站脚本漏洞

【漏洞编号】CNNVD-201710-042（CVE-2017-1522）

【漏洞详情】IBM Content Navigator & CMIS是美国IBM公司的一款Web客户机，它支持从Web浏览器搜索和处理存储在世界各地的内容服务器中的文档。

IBM Content Navigator & CMIS 2.0.3版本、3.0.0版本和3.0.1版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞在Web UI中注入任意的JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22008162

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-042


【漏洞名称】Apache NiFi 安全漏洞

【漏洞编号】CNNVD-201710-152（CVE-2017-12623）

【漏洞详情】Apache NiFi是美国阿帕奇（Apache）软件基金会的一套基于数据流的数据处理和分发系统。该系统支持数据路由指示图的配置和转换以及系统中介逻辑等。

Apache NiFi 1.0.0版本至1.3.0版本中存在安全漏洞。攻击者可利用该漏洞上传带有恶意代码的模板，访问敏感文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://nifi.apache.org/security.html#CVE-2017-12623

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201710-152
