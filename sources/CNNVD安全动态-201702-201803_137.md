# CNNVD最新漏洞（2017-09-30）

今日CNNVD共发布安全漏洞90个，更新安全漏洞16个。主要影响厂商为美国IBM（7个）、美国Apple（5个）、美国Red Hat（4个）。主要影响产品为IBM Business Process Manager管理平台（2个）、Apple iOS操作系统（3个）、Red Hat JBoss A-MQ消息传递平台（4个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****IBM Business Process Manager 跨站脚本漏洞**  

**【漏洞编号】****CNNVD-201709-1183（CVE-2017-1424）**

**【漏洞详情】**IBM Business Process Manager（BPM）是美国IBM公司的一套综合的业务流程管理平台。该平台为业务的流程建模、组装、监控和部署提供了一系列的相关工具。

IBM BPM 8.5.7版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22005112

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-1183

  

**【漏洞名称】****Apple iOS和macOS Sierra Kernel 缓冲区错误漏洞**  

**【漏洞编号】****CNNVD-201703-1262（CVE-2017-2398）**

**【漏洞详情】**Apple iOS和macOS Sierra都是美国苹果（Apple）公司的产品。Apple iOS是为移动设备所开发的一套操作系统；macOS Sierra是为Mac计算机所开发的一套专用操作系统。Kernel是其中的一个内核组件。

Apple iOS 10.3之前的版本和macOS Sierra 10.12.4之前的版本中的Kernel组件存在安全漏洞。远程攻击者可借助特制的应用程序利用该漏洞执行任意代码或造成拒绝服务（内存损坏）。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://support.apple.com/zh-cn/HT207615

https://support.apple.com/zh-cn/HT207617

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201703-1262

  

**【漏洞名称】****Red Hat JBoss A-MQ Hawtio console 安全漏洞**  

**【漏洞编号】****CNNVD-201709-1161（CVE-2015-5184）**

**【漏洞详情】**Red Hat JBoss A-MQ是美国红帽（Red Hat）公司的一套开源的消息传递平台。该平台用于集成应用程序、终端和设备，并提供各种消息传递模式以支持实时消息传递。Hawtio console是其中的一个系统监控控制台。

Red Hat JBoss A-MQ中的Hawtio console存在安全漏洞。远程攻击者可利用该漏洞获取敏感信息。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.redhat.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-1161

  

**【漏洞名称】****Android 缓冲区错误漏洞**  

**【漏洞编号】CNNVD-201706-632（CVE-2015-9023）**

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。

Android中的PlayReady API存在缓冲区溢出漏洞。远程攻击者可利用该漏洞造成拒绝服务或执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2017-06-01

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-632

  

**【漏洞名称】****NVIDIA Windows GPU Display Driver 安全漏洞**  

**【漏洞编号】****CNNVD-201709-1134（CVE-2017-6271）**

**【漏洞详情】**NVIDIA Windows GPU Display Driver是美国英伟达（NVIDIA）公司的一套专用于Windows的图形处理器(GPU)显卡驱动程序。kernel mode layer handler for DxgkDdiCreateAllocation是其中的一个DxgkDdiEscape的内核模式层处理程序。

NVIDIA Windows GPU Display Driver中的kernel mode layer handler for DxgkDdiCreateAllocation存在安全漏洞，该漏洞源于程序在没有验证不可信用户的输入的情况下，将其用作因子。攻击者可利用该漏洞造成拒绝服务（除零错误）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://nvidia.custhelp.com/app/answers/detail/a\_id/4544

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-1134
