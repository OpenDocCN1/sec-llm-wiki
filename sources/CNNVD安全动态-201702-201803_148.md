今日CNNVD共发布安全漏洞94个，更新安全漏洞5个。主要影响厂商为美国VMware（3个）、美国SugarCRM（3个）、中国腾达（2个），主要影响产品为VMware vCenter Server虚拟化管理软件（3个）、SugarCRM Professional管理系统（3个）、Tenda W15E devices无线路由器（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****VMware vCenter Server 跨站脚本漏洞**  

**【漏洞编号】****CNNVD-201709-787（CVE-2017-4926）**

**【漏洞详情】**VMware vCenter Server是美国威睿（VMware）公司的一套服务器和虚拟化管理软件。该软件提供了一个用于管理VMware vSphere环境的集中式平台，可自动实施和交付虚拟基础架构。

VMware vCenter Server 6.5版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞注入恶意的Java脚本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.vmware.com/security/advisories/VMSA-2017-0015.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-787

  

**【漏洞名称】****SugarCRM 跨站脚本漏洞**  

**【漏洞编号】****CNNVD-201709-762（CVE-2017-14510）**

**【漏洞详情】**SugarCRM Professional是美国SugarCRM公司的一套开源的客户关系管理系统（CRM）的专业版。该系统支持对不同的客户需求进行差异化营销、管理和分配销售线索，实现销售代表的信息共享和追踪。Enterprise是企业版。Ultimate是旗舰版。

SugarCRM中存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的Web脚本或HTML。以下版本受到影响：SugarCRM Professional 7.9版本，7.8版本，7.7.2.3之前的版本，Enterprise 7.9版本，7.8版本，7.7.2.3之前的版本，Ultimate 7.9版本，7.8版本，7.7.2.3之前的版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.sugarcrm.com/Resources/Security/sugarcrm-sa-2017-008/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-762

  

**【漏洞名称】****Tenda W15E设备缓冲区错误漏洞**  

**【漏洞编号】****CNNVD-201709-757（CVE-2017-14515）**

**【漏洞详情】**Tenda W15E devices是中国腾达（Tenda）公司的一款双频无线路由器。

Tenda W15E设备15.11.0.14之前的版本中存在基于堆的缓冲区溢出漏洞。远程攻击者可利用该漏洞造成拒绝服务（Web UI无法访问和强制注销）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.tendacn.com/en/2018.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-757

  

**【漏洞名称】****Adobe Flash Player 安全漏洞**  

**【漏洞编号】CNNVD-201709-508（CVE-2017-11282）**

**【漏洞详情】**Adobe Flash Player是美国奥多比（Adobe）公司的一款跨平台、基于浏览器的多媒体播放器产品。该产品支持跨屏幕和浏览器查看应用程序、内容和视频。

Adobe Flash Player中存在内存损坏漏洞。远程攻击者可利用该漏洞在当前用户的上下文中执行任意代码或造成拒绝服务。以下版本受到影响：基于Windows、Macintosh和Linux平台的Adobe Flash Player Desktop Runtime 26.0.0.151及之前版本；基于Windows、Macintosh、Linux和Chrome OS平台的AFlash Player for Google Chrome 26.0.0.151及之前的版本；基于Windows 10和8.1平台的Flash Player for Microsoft Edge和Internet Explorer 11 26.0.0.151及之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://helpx.adobe.com/security/products/flash-player/apsb17-28.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-508

  

**【漏洞名称】****tcpdump ISO IS-IS解析器缓冲区错误漏洞**  

**【漏洞编号】****CNNVD-201709-658（CVE-2017-13035）**

**【漏洞详情】**tcpdump是Tcpdump团队开发的一套运行在命令行下的嗅探工具。该工具允许用户拦截和显示发送或收到过网络连接到该计算机的TCP/IP和其他数据包。ISO IS-IS parser是其中的一个路由协议解析器。

tcpdump 4.9.1及之前的版本中的ISO IS-IS解析器的print-isoclns.c文件的‘isis\_print\_id()’函数存在缓冲区溢出漏洞。远程攻击者可利用该漏洞造成拒绝服务（缓冲区越边界读取和应用程序崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.tcpdump.org/tcpdump-changes.txt

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-658
