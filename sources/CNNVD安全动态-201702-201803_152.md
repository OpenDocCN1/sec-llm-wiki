今日CNNVD共发布安全漏洞30个，更新安全漏洞42个。主要影响厂商为美国Google（1个）、美国IBM（1个）、中国威联通（1个），主要影响产品为Google Kubernetes管理系统（1个）、IBM Lifecycle Query Engine of Jazz Reporting Service查询引擎（1个）、QNAP QTS作业系统（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Google Kubernetes 安全漏洞**  

**【漏洞编号】****CNNVD-201709-635（CVE-2017-1002100）**

**【漏洞详情】**Google Kubernetes是美国Google公司的一套开源的Docker容器集群管理系统。该系统为容器化的应用提供资源调度、部署运行、服务发现和扩容缩容等功能。

Google Kubernetes 1.6.0版本至1.6.5版本中存在安全漏洞，该漏洞源于程序将Persistent Volumes (PVs)的默认访问权限设置为‘container’。攻击者可利用该漏洞下载VHD文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/kubernetes/kubernetes/issues/47611

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-635

  

**【漏洞名称】****IBM Lifecycle Query Engine of Jazz Reporting Service 安全漏洞**  

**【漏洞编号】****CNNVD-201709-632（CVE-2017-1490）**

**【漏洞详情】**IBM Lifecycle Query Engine of Jazz Reporting Service是美国IBM公司的一款Jazz Reporting服务的生命周期查询引擎。

IBM Lifecycle Query Engine of Jazz Reporting Service 6.0版本至6.0.4版本中存在安全漏洞。攻击者可利用该漏洞获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22008253

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-632

  

**【漏洞名称】****QNAP QTS 安全漏洞**  

**【漏洞编号】****CNNVD-201709-631（CVE-2017-13067）**

**【漏洞详情】**QNAP QTS是中国威联通（QNAP Systems）公司的一套Turbo NAS作业系统。该系统可提供档案储存、管理、备份，多媒体应用及安全监控等功能。

QNAP QTS 4.2.6 build 20170905之前的版本和4.3.3.0299 build 20170901之前的版本中存在远程代码执行漏洞。远程攻击者可利用该漏洞在QNAP NAS上执行命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.qnap.com/zh-hk/releasenotes/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-631

  

**【漏洞名称】****WordPress Event Expresso Free SQL注入漏洞**  

**【漏洞编号】CNNVD-201709-638（CVE-2017-1002026）**

**【漏洞详情】**WordPress是WordPress软件基金会的一套使用PHP语言开发的博客平台，该平台支持在PHP和MySQL的服务器上架设个人博客网站。Event Expresso Free是其中的一个事件管理插件。

WordPress Event Expresso Free 3.1.37.11.L版本中存在SQL注入漏洞，该漏洞源于‘edit\_event\_category’函数没有过滤用户提交的输入。远程攻击者借助‘$id’参数利用该漏洞执行任意的SQL命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/event-espresso-free/#developers

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-638

  

**【漏洞名称】****Joomla! Googlemaps插件安全漏洞**  

**【漏洞编号】****CNNVD-201709-630（CVE-2013-7429）**

**【漏洞详情】**Joomla!是美国Open Source Matters团队开发的一套开源的内容管理系统(CMS)，它提供RSS馈送、网站搜索等功能。Googlemaps是其中的一组Google地图插件。

Joomla! Googlemaps插件3.1之前的版本中存在安全漏洞。远程攻击者可通过向plugin\_googlemap2\_proxy.php文件中发送‘url’参数利用该漏洞执行XML注入攻击。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.mapsplugin.com/Google-Maps/Documentation-of-plugin-Googlemap/security-release-3-1-of-plugin-googlemaps.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-630
