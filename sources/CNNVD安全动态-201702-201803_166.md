# CNNVD最新漏洞（2017-09-05）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODY1OTM5OQ==&mid=2651436399&idx=1&sn=6fd159e58008d547f1da522280d53f9c&chksm=802ff447b7587d51f509c1e6369b26b99f2514730cba93bc649703c089ca1e20ff5cec1e3659&scene=126&sessionid=1681378005#rd](http://mp.weixin.qq.com/s?__biz=MzAxODY1OTM5OQ==&mid=2651436399&idx=1&sn=6fd159e58008d547f1da522280d53f9c&chksm=802ff447b7587d51f509c1e6369b26b99f2514730cba93bc649703c089ca1e20ff5cec1e3659&scene=126&sessionid=1681378005#rd)

今日CNNVD共发布安全漏洞10个，更新安全漏洞19个。主要影响厂商为美国NetApp（3个）、美国Apache（1个），主要影响产品为NetApp Data ONTAP操作系统（3个）、Apache Atlas核心功能治理服务（1个）、GraphicsMagick图象处理工具（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****NetApp Data ONTAP 安全漏洞**  

**【漏洞编号】****CNNVD-201709-033（CVE-2016-1895）**

**【漏洞详情】**NetApp Data ONTAP是美国NetApp公司的一套存储操作系统。该系统支持提升用户的企业应用程序性能和提高数据中心灵活性等。

NetApp Data ONTAP 8.2.5之前的版本和8.3.2P12之前的8.3.x版本中存在安全漏洞。远程攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://kb.netapp.com/support/s/article/ka51A0000004KdKQAU/NTAP-20170831-0003?language=en\_US

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-033

  

**【漏洞名称】****Apache 跨站脚本漏洞**  

**【漏洞编号】****CNNVD-201708-1327（CVE-2017-3150）**

**【漏洞详情】**Apache Atlas是美国阿帕奇（Apache）软件基金会的一套可伸缩和可扩展的核心功能治理服务。

Apache Atlas 0.6.0-incubating版本和0.7.0-incubating版本中存在跨站脚本漏洞。攻击者可利用该漏洞在浏览器中执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lists.apache.org/thread.html/4a4fef91e067fd0d9da569e30867c1fa65e2a0520acde71ddefee0ea@%3Cdev.atlas.apache.org%3E

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-1327

  

**【漏洞名称】****GraphicsMagick 安全漏洞**  

**【漏洞编号】****CNNVD-201709-023（CVE-2017-14103）**

**【漏洞详情】**GraphicsMagick是一套简单的图像处理工具。该工具对图像提供尺寸调整、旋转、加亮等功能。

GraphicsMagick 1.3.26版本中的coders/png.c文件的‘ReadJNGImage’和‘ReadOneJNGImage’函数存在安全漏洞，该漏洞源于程序没有正确的管理图像指针。远程攻击者可借助特制的文件利用该漏洞实施释放后重用攻击。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.graphicsmagick.org

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-023

  

**【漏洞名称】****EyesOfNetwork web interface 安全漏洞**  

**【漏洞编号】CNNVD-201709-040（CVE-2017-14118）**

**【漏洞详情】**EyesOfNetwork（EON）是一套开源的、免费的IT监控解决方案。该方案提供业务流程配置工具、在活动队列中发生事件时生成弹出窗口等功能。EyesOfNetwork web interface(又名eonweb)是其中的一个Web界面。

EON web interface 5.1-0版本中存在安全漏洞，该漏洞源于module\\tool\_all\\tools\\interface.php文件没有正确的限制exec调用。远程攻击者可通过向module/tool\_all/select\_tool.php文件发送带有shell元字符的‘host\_list’参数利用该漏洞执行任意命令。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.eyesofnetwork.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-040

  

**【漏洞名称】****unrar 路径遍历漏洞**  

**【漏洞编号】****CNNVD-201709-042（CVE-2017-14120）**

**【漏洞详情】**unrar(又名unrar-free或unrar-gpl)是使用在Linux中的一款解压缩软件。

unrar 0.0.1版本中存在目录遍历漏洞。攻击者可利用该漏洞将RAR v2归档文件解压到上层目录。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://github.com/0x11AL/my-exploits/tree/master/pocs/unrar-free

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201709-042
