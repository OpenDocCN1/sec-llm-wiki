根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞237个，漏洞新增数量有所上升。从厂商分布来看，其中IBM公司新增漏洞最多，共有33个；从漏洞类型来看，跨站脚本类的安全漏洞占比最大，达到12.66%。本周新增漏洞中，超危漏洞11个，高危漏洞23个，中危漏洞168个，低危漏洞35个。相应修复率分别为100.00%、86.96%、82.74%以及91.43%。根据补丁信息统计，合计202个漏洞已有修复补丁发布，整体修复率为85.23%

**1\. Android Qualcomm闭源组件缓冲区错误漏洞（CNNVD-201708-926）**   

Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Qualcomm closed-source components是其中的一个美国高通（Qualcomm）公司开发的闭源组件。

Android中的Qualcomm闭源组件存在缓冲区溢出漏洞。远程攻击者可利用该漏洞造成拒绝服务或执行任意代码。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2017-07-01

**2\. ****Cisco Wireless LAN Controller ****权限许可和访问控制漏洞（CNNVD-201704-279）**

Cisco Wireless LAN Controller（WLC）是美国思科（Cisco）公司的一款无线局域网控制器产品。该产品在无线局域网中提供安全策略、入侵检测等功能。

Cisco WLC 8.3.102.0版本中的Web管理界面存在拒绝服务漏洞。远程攻击者可利用该漏洞造成拒绝服务（设备重载）。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20170405-wlc3

**3\. ****Apple iOS Wi-Fi ****缓冲区错误漏洞（CNNVD-201704-237）**

Apple iOS是美国苹果（Apple）公司为移动设备所开发的一套操作系统。Wi-Fi是其中的一个无线上网组件。

Apple iOS 10.3.1之前的版本中的Wi-Fi组件存在缓冲区溢出漏洞。本地攻击者可利用该漏洞在Wi-Fi芯片上执行任意代码。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/zh-cn/HT207688

**4\. ****Pivotal Software Cloud Foundry ****输入验证漏洞（CNNVD-201706-475）**

Pivotal Software Cloud Foundry（CF）是美国Pivotal Software公司的一套开源的平台即服务（PaaS）云计算平台，它提供容器调度、持续交付和自动化服务部署等功能。cf-release和CAPI-release都是CF的发布版本。

Pivotal Software CF cf-release 203版本至231版本和routing-release 0.142.0之前的版本中的JSON Web Token (JWT)库存在安全漏洞。远程攻击者可利用该漏洞冒充其他用户。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.cloudfoundry.org/cve-2016-8218/
