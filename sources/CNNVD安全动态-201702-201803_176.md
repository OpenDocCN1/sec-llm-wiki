**1\. Linux kernel 缓冲区错误漏洞(CNNVD-201708-385) **

Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。

Linux kernel中的/drivers/isdn/i4l/isdn\_net.c文件存在缓冲区溢出漏洞。本地攻击者可利用该漏洞在应用程序的上下文中执行任意代码或造成拒绝服务。以下版本受到影响：

\-   Linux kernel 4.9版本

\-   Linux kernel 4.4版本

\-   Linux kernel 4.12版本

\-   Linux kernel 3.18版本

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://patchwork.kernel.org/patch/9880041/

**2\. Android Qualcomm Wconnect 输入验证漏洞(CNNVD-201708-889)**

Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Qualcomm Wconnect是其中的一个美国高通（Qualcomm）公司的PC机与手机连接工具。

Android中的Qualcomm Wconnect存在安全漏洞，该漏洞源于程序没有验证HCI命令长度的有效性。远程攻击者可利用该漏洞执行未授权的操作。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2017-07-01

**3\. ThinkPad Compact USB Keyboard with TrackPoint Driver 权限许可和访问控制漏洞(CNNVD-201708-382)**

ThinkPad Compact USB Keyboard with TrackPoint Driver是中国联想（Lenovo）公司的一款USB键盘的驱动程序。

ThinkPad Compact USB Keyboard with TrackPoint Driver 1.5.5.0之前的版本中存在提权漏洞。攻击者可利用该漏洞以管理员权限执行代码。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.lenovo.com/us/zh/product\_security/len-15061

**4\. ImageMagick 安全漏洞(CNNVD-201708-1067)**

ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.6-8版本中的coders/xcf.c文件的‘load\_level’函数存在安全漏洞，该漏洞源于程序缺少偏移验证。攻击者可借助特制的文件利用该漏洞造成拒绝服务（load\_tile内存耗尽）。

解决措施：目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.imagemagick.org
