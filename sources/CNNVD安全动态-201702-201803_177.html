今日CNNVD共发布安全漏洞85个，更新安全漏洞13个。主要影响厂商为美国Google（20个）、美国ImageMagick Studio（12个）、日本Teikoku Databak（1个），主要影响产品为Android操作系统（20个）、ImageMagick图象处理软件（12个）、TDB CA TypeA use software管理系统（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Android Qualcomm闭源组件缓冲区错误漏洞

【漏洞编号】CNNVD-201708-853（CVE-2016-5871）

【漏洞详情】Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Qualcomm closed-source components是其中的一个美国高通（Qualcomm）公司开发的闭源组件

Android中的Qualcomm闭源组件存在缓冲区溢出漏洞。远程攻击者可利用该漏洞执行任意代码或造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2017-07-01

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-853


【漏洞名称】ImageMagick 安全漏洞

【漏洞编号】CNNVD-201708-1058（CVE-2017-13146）

【漏洞详情】ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 6.9.8-5之前的版本和7.0.5-6之前的7.x版本中的coders/mat.c文件的‘ReadMATImage’函数存在内存泄露漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/commit/437a35e57db5ec078f4a3ccbf71f941276e88430

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-1058


【漏洞名称】TDB CA TypeA use software 安全漏洞

【漏洞编号】CNNVD-201708-976（CVE-2017-10824）

【漏洞详情】TDB CA TypeA use software是日本Teikoku Databak（TDB）公司的一套TypeA IC卡管理系统

TDB CA TypeA use software 5.2及之前的版本中存在不可信的搜索路径漏洞。攻击者可借助目录下恶意的DLL利用该漏洞获取权限。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.tdb.co.jp/typeA/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-976   


【漏洞名称】WordPress Easy Modal插件SQL注入漏洞

【漏洞编号】CNNVD-201708-850（CVE-2017-12947）

【漏洞详情】WordPress是WordPress软件基金会的一套使用PHP语言开发的博客平台，该平台支持在PHP和MySQL的服务器上架设个人博客网站。Easy Modal plugin是其中的一个弹出式窗口插件。

WordPress Easy Modal插件2.1.0之前的版本中的classes\controller\admin\modals.php文件存在SQL注入漏洞。远程攻击者可利用该漏洞提升权限，获取或更改数据库内容。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/easy-modal/#developers

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-850


【漏洞名称】Unity Technologies Unity Editor for Windows 安全漏洞

【漏洞编号】CNNVD-201708-974（CVE-2017-12939）

【漏洞详情】Unity Technologies Unity Editor for Windows是美国Unity Technologies公司的一款基于Windows平台的图形编辑器。

基于Windows平台的Unity Technologies Unity Editor中存在远程代码执行漏洞。远程攻击者可利用该漏洞执行代码。以下版本受到影响：Unity Technologies Unity Editor 5.3.8p2之前的版本，5.4.5p5之前的5.4.x版本，5.5.4p3之前的5.5.x版本，5.6.3p1之前的5.6.x版本，2017.1.0p4之前的2017.x版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://unity3d.com/cn/security#issues

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-974
