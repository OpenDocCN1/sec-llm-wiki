今日CNNVD共发布安全漏洞28个，更新安全漏洞4个。主要影响厂商为美国Google（17个）、英国Micro Focus（2个）、美国ImageMagick Studio（1个），主要影响产品为Android操作系统（17个）、Enterprise Server部署平台（2个）、ImageMagick图象处理软件（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Android Qualcomm组件安全漏洞

【漏洞编号】CNNVD-201708-888（CVE-2016-10392）

【漏洞详情】Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Qualcomm是使用在其中的一个美国高通（Qualcomm）公司的设备专用的高通组件。

Android中的Qualcomm组件存在安全漏洞。攻击者可利用该漏洞泄露内核内存。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.android.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-888


【漏洞名称】Micro Focus Enterprise Developer和Enterprise Server 路径遍历漏洞

【漏洞编号】CNNVD-201708-874（CVE-2017-7424）

【漏洞详情】Micro Focus Enterprise Developer和Enterprise Server都是英国Micro Focus公司的产品。Micro Focus Enterprise Developer是一套用于大型机的集成开发环境。Enterprise Server是一套大型机程序生产部署平台。

Micro Focus Enterprise Developer和Enterprise Server中的esfadmingui存在路径遍历漏洞。远程攻击者可利用该漏洞从系统上下载任意文件。以下产品和版本受到影响：Micro Focus Enterprise Developer 2.3 Update 1 Hotfix 8之前的2.3版本和2.3 Update 1版本，2.3 Update 2 Hotfix 9之前的2.3 Update 2版本；Micro Focus Enterprise Server 2.3 Update 1 Hotfix 8之前的2.3版本和2.3 Update 1版本，2.3 Update 2 Hotfix 9之前的2.3 Update 2版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://community.microfocus.com/microfocus/mainframe_solutions/enterprise_server/w/knowledge_base/29131/enterprise-server-security-fixes-july-2017

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-874


【漏洞名称】ImageMagick 缓冲区错误漏洞

【漏洞编号】CNNVD-201708-880（CVE-2017-12983）

【漏洞详情】ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.6-8中的coders/sfw.c文件的‘ReadSFWImage’函数存在基于堆的缓冲区溢出漏洞。远程攻击者可借助特制的文件利用该漏洞造成拒绝服务（应用程序崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/issues/682

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-880    


【漏洞名称】DokuWiki 跨站脚本漏洞

【漏洞编号】CNNVD-201708-883（CVE-2017-12980）

【漏洞详情】DokuWiki是德国软件开发者Andreas Gohr所研发的一款基于PHP的Wiki引擎，它主要用于中小团队和个人网站知识库的管理，并提供版本控制、全文检索和权限控制等功能。

DokuWiki 2017-02-19c及之前的版本中的/inc/parser/xhtml.php文件存在跨站脚本漏洞。远程攻击者可利用该漏洞创建或更改wiki，来执行JavaScript。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/splitbrain/dokuwiki/issues/2081

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-883


【漏洞名称】WordPress Photo Gallery by WD - Responsive Photo Gallery SQL注入漏洞

【漏洞编号】CNNVD-201708-886（CVE-2017-12977）

【漏洞详情】WordPress是WordPress软件基金会的一套使用PHP语言开发的博客平台，该平台支持在PHP和MySQL的服务器上架设个人博客网站。Photo Gallery by WD - Responsive Photo Gallery是其中的一个图片管理插件。

WordPress Photo Gallery by WD - Responsive Photo Gallery插件1.3.51之前的版本中存在SQL注入漏洞。远程攻击者可借助‘tag_id’参数利用该漏洞执行任意的SQL命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/photo-gallery/#developers

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-886
