今日CNNVD共发布安全漏洞8个，更新安全漏洞32个。主要影响厂商为美国Mozilla（3个），主要影响产品为LibSass解析器（3个）、GNU PSPP应用程（2个）、Mozilla Firefox Web浏览器（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Mozilla Firefox Venkman 安全漏洞**  

**【漏洞编号】****CNNVD-201708-846（CVE-2007-5341）**

**【漏洞详情】**Mozilla Firefox是美国Mozilla基金会开发的一款开源Web浏览器。Venkman是一个脚本调试器。

Mozilla Firefox 2.0.0.8版本中的Venkman脚本调试器存在远程代码执行漏洞。远程攻击者可利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bugzilla.mozilla.org/show\_bug.cgi?id=325761

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-846

**【漏洞名称】******LibSass 安全漏洞****

**【漏洞编号】****CNNVD-201708-836****（CVE-2017-12964）**

**【漏洞详情】**LibSass是一个开源的使用C语言编写的Sass（CSS扩展语言）解析器。

LibSass 3.4.5版本中的eval.cpp文件的‘Sass::Eval::operator()’函数存在安全漏洞。远程攻击者可利用该漏洞造成拒绝服务（栈消耗）。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

http://libsass.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-836

  

**【漏洞名称】****GNU Binutils Binary File Descriptor库安全漏洞**

**【漏洞编号】****CNNVD-201708-835（CVE-2017-12967）**

**【漏洞详情】**GNU Binutils（又名GNU Binary Utilities或binutils）是GNU计划开发的一组编程语言工具程序，它主要用于处理多种格式的目标文件，并提供有连接器、汇编器和其他用于目标文件和档案的工具。Binary File Descriptor（BFD）library（又名libbfd）是其中的一个以各种格式便携式操作对象文件的库。

GNU Binutils 2.29版本中的BFD库的tekhex.c文件的‘getsym’函数存在安全漏洞。远程攻击者可借助畸形的tekhex二进制文件利用该漏洞造成拒绝服务（基于堆的缓冲区越边界读取和应用程序崩溃）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.gnu.org/software/binutils/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-835    

  

**【漏洞名称】****GNU PSPP libpspp库安全漏洞**

**【漏洞编号】****CNNVD-201708-839（CVE-2017-12961）**

**【漏洞详情】**GNU PSPP是GNU计划开发的一个免费的用于数据采样、统计和分析的应用程序。libpspp library是其中的一个C语言库。

GNU PSPP 0.11.0版本中的libpspp库的data/sys-file-reader.c文件的‘parse\_attributes()’函数存在安全漏洞。远程攻击者可利用该漏洞造成拒绝服务（断言终止）。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.gnu.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-839

  

**【漏洞名称】****Exiv2 缓冲区错误漏洞**

**【漏洞编号】****CNNVD-201708-845（CVE-2017-12955）**

**【漏洞详情】**Exiv2是软件开发者Andreas Huggel所研发的一套用于管理图像元数据的C++库和命令行应用程序，它提供了快速容易读取和写入EXIF、IPTC和XMP多种格式的图像元数据

Exiv2 0.26版本中的basicio.cpp文件存在基于堆的缓冲区溢出漏洞。远程攻击者可利用该漏洞造成拒绝服务（缓冲区越边界写入）。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

http://www.exiv2.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-845
