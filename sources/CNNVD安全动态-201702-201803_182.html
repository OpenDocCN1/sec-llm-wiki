今日CNNVD共发布安全漏洞36个，更新安全漏洞11个。主要影响厂商为美国Cisco（14个）、美国Mozilla（6个）、美国IBM（1个）、，主要影响产品为Mozilla Firefox Web浏览器（6个）、Cisco Elastic Services Controller（ESC）模块化系统（4个）、IBM WebSphere Application Server（WAS）应用服务器产品（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Cisco Elastic Services Controller 信息泄露漏洞

【漏洞编号】CNNVD-201708-786（CVE-2017-6772）

【漏洞详情】Cisco Elastic Services Controller（ESC）是美国思科（Cisco）公司的一个开源的模块化系统。

Cisco ESC 2.3(2)版本中存在信息泄露漏洞，该漏洞源于程序没有充分的保护敏感数据。远程攻击者可利用该漏洞浏览敏感的系统配置文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bst.cloudapps.cisco.com/bugsearch/bug/CSCvd29408

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-786


【漏洞名称】Mozilla Firefox 安全漏洞

【漏洞编号】CNNVD-201708-802（CVE-2017-7806）

【漏洞详情】Mozilla Firefox是美国Mozilla基金会开发的一款开源Web浏览器。

Mozilla Firefox 55之前的版本中存在释放后重用漏洞。远程攻击者可利用该漏洞造成拒绝服务（崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.mozilla.org/en-US/security/advisories/mfsa2017-18/1

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-802


【漏洞名称】IBM WebSphere Application Server 信息泄露漏洞

【漏洞编号】CNNVD-201708-801（CVE-2017-1501）

【漏洞详情】IBM WebSphere Application Server（WAS）是美国IBM公司开发并发行的一款应用服务器产品，它是Java EE和Web服务应用程序的平台，也是IBM WebSphere软件平台的基础。

IBM WAS 8.0版本、8.5版本和9.0版本中存在信息泄露漏洞，该漏洞源于程序没有正确的保存Web服务安全绑定设置中更改的密码套件。远程攻击者可利用该漏洞获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22006810

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-801    


【漏洞名称】Drupal core 安全漏洞

【漏洞编号】CNNVD-201708-798（CVE-2017-6923）

【漏洞详情】Drupal core是Drupal社区所维护的一套用PHP语言开发的免费、开源的内容管理系统

Drupal core 8.3.7之前的8.x版本中存在安全漏洞。攻击者可利用该漏洞绕过安全限制，执行未授权的操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.drupal.org/SA-CORE-2017-004

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-798


【漏洞名称】Novell openSUSE 代码注入漏洞

【漏洞编号】CNNVD-201708-774（CVE-2011-0469）

【漏洞详情】Novell openSUSE是美国Novell公司的一套基于Linux的自由操作系统。

Novell openSUSE中存在代码注入漏洞。攻击者可利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bugzilla.suse.com/show_bug.cgi?id=679325

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-774
