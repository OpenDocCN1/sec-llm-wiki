今日CNNVD共发布安全漏洞54个，更新安全漏洞272个。主要影响厂商为美国Microsoft（25个）、日本Intercom（5个）、美国Cisco（3个），主要影响产品为Microsoft Windows操作系统（24个）、Intercom MaLion for Mac解决方案（5个）、Cisco Unified Communications Manager呼叫处理组件（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Microsoft Windows 10 Edge JavaScript引擎安全漏洞**  

**【漏洞编号】****CNNVD-201708-327（CVE-2017-8647）**

**【漏洞详情】**Microsoft Windows 10是美国微软（Microsoft）公司发布的一套新一代跨平台操作系统。Microsoft Edge是其中的一款系统附带的Web浏览器。JavaScript engines是其中的一个JavaScript引擎组件。

Microsoft Windows 10版本1703中的Edge的JavaScript引擎存在远程代码执行漏洞。远程攻击者可利用该漏洞在当前用户的上下文中执行任意代码，造成内存损坏。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-8647

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-327

**【漏洞名称】******Intercom MaLion for Mac 安全漏洞****

**【漏洞编号】****CNNVD-201708-217****（CVE-2017-10819）**

**【漏洞详情】**Intercom MaLion for Mac是日本Intercom公司的一款基于Mac平台的IT资产管理解决方案。

基于Mac平台的Intercom MaLion 4.3.0版本至5.2.1版本中存在安全漏洞，该漏洞源于程序没有正确的校验证书。攻击者可利用该漏洞窃听加密通讯。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.intercom.co.jp/information/2017/0801.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-217

  

**【漏洞名称】****Cisco Unified Communications Manager SQL注入漏洞**

**【漏洞编号】****CNNVD-201708-160（CVE-2017-6757）**

**【漏洞详情】**Cisco Unified Communications Manager（CUCM，Unified CM，CallManager）是美国思科（Cisco）公司的一款统一通信系统中的呼叫处理组件。该组件提供了一种可扩展、可分布和高可用的企业IP电话呼叫处理解决方案。

Cisco Unified Communications Manager中存在SQL注入漏洞，该漏洞源于程序在使用SQL查询语句之前，没有验证用户提交的输入。远程攻击者可通过发送特制的URL利用该漏洞更改或删除数据库表中的条目。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20170802-ucm

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-160

  

**【漏洞名称】****Metinfo SQL注入漏洞**

**【漏洞编号】****CNNVD-201708-306**

**【漏洞详情】**MetInfo是中国长沙米拓信息技术有限公司的一套使用PHP和Mysql开发的内容管理系统（CMS）。

Metinfo 5.3.18版本之前的5.x.x版本存在SQL注入漏洞。在网站开启伪静态（非默认开启）的情况下，攻击者可利用该漏洞获取数据库全部数据，获取管理员密码、服务器信息等内容，进而提升权限，执行任意操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.metinfo.cn/download/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-306

  

**【漏洞名称】****SLiMS 8 Akasia 安全漏洞**

**【漏洞编号】****CNNVD-201708-185（CVE-2017-12586）**

**【漏洞详情】**SLiMS 8 Akasia是一套开源的、免费的图书管理系统。

SLiMS 8 Akasia 8.3.1及之前的版本中存在任意文件读取漏洞。远程攻击者可利用该漏洞读取系统中的任意文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/slims/slims8\_akasia/issues/48

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-185
