今日CNNVD共发布安全漏洞23个，更新安全漏洞48个。主要影响厂商为美国ImageMagick Studio（5个）、美国Cisco（1个）、美国Microsoft（1个），主要影响产品为ImageMagick图象处理软件（5个）、Cisco Firepower System Software防火墙（1个）、Microsoft Windows操作系统（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】ImageMagick 资源管理错误漏洞

【漏洞编号】CNNVD-201708-234（CVE-2017-12435）

【漏洞详情】ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.6-1版本中的coders/sun.c文件的‘ReadSUNImage’函数存在内存耗尽漏洞。攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/issues/543

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-234


【漏洞名称】Cisco Firepower System Software 安全漏洞

【漏洞编号】CNNVD-201708-245（CVE-2017-6766）

【漏洞详情】Cisco Firepower System Software是美国思科（Cisco）公司的一款下一代防火墙产品（NGFW）。

Cisco Firepower System Software中的Secure Sockets Layer (SSL) Decryption and Inspection功能存在安全漏洞。远程攻击者可通过发送特制SSL数据包利用该漏洞绕过SSL加密和检测策略。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20170802-fpw

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-245


【漏洞名称】Microsoft Windows Edge 安全漏洞

【漏洞编号】CNNVD-201708-260（CVE-2017-8518）

【漏洞详情】Microsoft Windows 10和Windows Server 2016都是美国微软（Microsoft）公司的产品。前者是一套供个人电脑使用的操作系统，后者是一套服务器操作系统。Edge是其中的一款系统附带的Web浏览器。

Microsoft Windows中的Edge存在内存损坏漏洞，该漏洞源于程序没有正确的访问内存中的对象。攻击者可通过诱使用户浏览特制的网页利用该漏洞在当前用户的上下文中执行任意代码，造成内存损坏。以下版本受到影响：MicrosoftWindows 10版本1511，Windows 10版本1607，Windows 10，Windows Server 2016，Windows 10版本1703。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-8518

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-260


【漏洞名称】GNU Binutils Binary File Descriptor库安全漏洞

【漏洞编号】CNNVD-201708-230（CVE-2017-12451）

【漏洞详情】GNU Binutils（又名GNU Binary Utilities或binutils）是GNU计划开发的一组编程语言工具程序，它主要用于处理多种格式的目标文件，并提供有连接器、汇编器和其他用于目标文件和档案的工具。Binary File Descriptor（BFD）library（又名libbfd）是其中的一个以各种格式便携式操作对象文件的库。

GNU Binutils 2.29及之前的版本中的BFD库的bfd/coff64-rs6000.c文件和bfd/coff-rs6000.c文件的‘_bfd_xcoff_read_ar_hdr’函数存在安全漏洞。远程攻击者可借助特制的COFF图像文件利用该漏洞造成越边界栈读取。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.gnu.org/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-230


【漏洞名称】shadow 安全漏洞

【漏洞编号】CNNVD-201708-244（CVE-2017-12424）

【漏洞详情】shadow是一套用于维护Debian系统的工具套件。

shadow 4.5之前的版本中存在安全漏洞。攻击者可借助畸形的输入利用该漏洞造成该套件崩溃（缓冲区溢出或内存损坏）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/shadow-maint/shadow/commit/954e3d2e7113e9ac06632aee3c69b8d818cc8952

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-244
