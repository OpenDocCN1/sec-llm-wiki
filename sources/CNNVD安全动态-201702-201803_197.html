今日CNNVD共发布安全漏洞20个，更新安全漏洞26个。主要影响厂商为美国ImageMagick Studio（8个）、美国Linux（1个）、美国IBM（1个），主要影响产品为ImageMagick图象处理软件（8个）、Linux kernel内核（1个）、IBM Content Navigator Web客户机（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】ImageMagick 安全漏洞

【漏洞编号】CNNVD-201708-192（CVE-2017-12566）

【漏洞详情】ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.6-2版本中的coders/mvg.c文件的‘ReadMVGImage’函数存在内存泄露漏洞。攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/issues/603

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-192


【漏洞名称】Linux kernel 竞争条件漏洞

【漏洞编号】CNNVD-201708-211（CVE-2017-7533）

【漏洞详情】Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。

Linux kernel 4.12.4及之前的版本中的fsnotify实现存在竞争条件漏洞。本地攻击者可借助特制的应用程利用该漏洞获取权限或造成拒绝服务（内存损坏）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=49d31c2f389acfe83417083e1208422b4091cd9e

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-211


【漏洞名称】IBM Content Navigator 跨站脚本漏洞

【漏洞编号】CNNVD-201708-216（CVE-2017-1331）

【漏洞详情】IBM Content Navigator是美国IBM公司的一款Web客户机，它支持从Web浏览器搜索和处理存储在世界各地的内容服务器中的文档。

IBM Content Navigator中存在跨站脚本漏洞。远程攻击者可利用该漏洞向Web UI中注入任意的JavaScript代码。以下版本受到影响：IBM Content Navigator 3.0.0版本，2.0.3.5版本，2.0.3.6版本，2.0.3.7版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22003928

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-216


【漏洞名称】Splunk Enterprise和Splunk Light 跨站脚本漏洞

【漏洞编号】CNNVD-201708-191（CVE-2017-12572）

【漏洞详情】Splunk是美国Splunk公司的一套数据收集分析软件。该软件主要用于收集、索引和分析机器产生的数据，包括所有IT系统和基础结构（物理、虚拟和云）生成的数据。Splunk Enterprise是一个企业版。Splunk Light是一套专为小型IT环境而设计的自动日志检索与分析解决方案。

Splunk Enterprise和Splunk Light中存在跨站脚本漏洞。远程攻击者可利用该漏洞注入并储存任意脚本。以下产品和版本受到影响：Splunk Enterprise 6.5.2之前的6.5.x版本，6.4.6之前的.4.x版本，6.3.9之前的6.3.x版本；Splunk Light 6.5.2之前的版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.splunk.com/view/SP-CAAAPYC

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-191


【漏洞名称】GNU BinUtils Binary File Descriptor库安全漏洞

【漏洞编号】CNNVD-201708-222（CVE-2017-12459）

【漏洞详情】GNU BinUtils（又名GNU Binary Utilities或binutils）是GNU计划开发的一组编程语言工具程序，它主要用于处理多种格式的目标文件，并提供有连接器、汇编器和其他用于目标文件和档案的工具。Binary File Descriptor（BFD）library（又名libbfd）是其中的一个以各种格式便携式操作对象文件的库。

GNU Binutils 2.29及之前的版本中的BFD库的bfd/mach-o.c文件的‘bfd_mach_o_read_symtab_strtab’函数存在安全漏洞。远程攻击者可借助特制的mach-o文件利用该漏洞造成越边界堆写入，可能执行代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.gnu.org/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-222
