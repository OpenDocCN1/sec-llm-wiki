# CNNVD最新漏洞（2017-08-03）

今日CNNVD共发布安全漏洞20个，更新安全漏洞21个。主要影响厂商为美国Oracle（15个）、美国IBM（1个），主要影响产品为Oracle E-Business Suite（电子商务套件）（3个）、IBM WebSphere MQ（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Oracle Application Object Library 安全漏洞**  

**【漏洞编号】****CNNVD-201708-043（CVE-2017-10246）**

**【漏洞详情】**Oracle E-Business Suite（电子商务套件）是美国甲骨文（Oracle）公司的一套全面集成式的全球业务管理软件。Oracle Application Object Library（AOL，应用程序对象库）是其中的一个系统管理组件。

Oracle E-Business Suite中的Oracle AOL组件的Help子组件存在安全漏洞。远程攻击者可利用该漏洞未授权访问、更新、插入或删除数据，影响数据的保密性和完整性，以下版本受到影响：Oracle E-Business Suite 12.1.3版本，12.2.3版本，12.2.4版本，12.2.5版本，12.2.6版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.oracle.com/technetwork/security-advisory/cpujul2017-3236622.html

**【漏洞链接】**  

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-043

**【漏洞名称】******IBM WebSphere MQ Internet Pass-Thru 安全漏洞****

**【漏洞编号】****CNNVD-201708-009****（CVE-2017-1118）**

**【漏洞详情】**IBM WebSphere MQ是美国IBM公司的一款消息传递中间件产品。IBM WebSphere MQ Internet Pass-Thru（MQIPT）是一个基于WebSphere MQ产品的且用于实现远程站点与互联网之间进行消息传递的扩展。

IBM WebSphere MQIPT 2.0版本和2.1版本中存在安全漏洞，该漏洞源于程序没有正确的配置安全策略。攻击者可利用该漏洞造成拒绝服务（停止响应）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22006580

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-009

  

**【漏洞名称】****OpenEMR 安全漏洞**

**【漏洞编号】****CNNVD-201708-008（CVE-2017-12064）**

**【漏洞详情】**OpenEMR是OpenEMR社区所维护的一套开源的医疗管理系统。该系统可用于医疗实践管理、电子医疗记录、处方书写和医疗帐单申请。

OpenEMR 5.0.0及之前的版本中的library/edihi story/edih\_csv\_inc.php文件的‘csv\_log\_html’函数存在安全漏洞。攻击者可借助特制的名称利用该漏洞绕过访问限制。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/openemr/openemr/commit/b8963a5ca483211ed8de71f18227a0e66a2582ad

**【漏洞链接】**  

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-008

  

**【漏洞名称】****Cacti 安全漏洞**

**【漏洞编号】****CNNVD-201708-007（CVE-2017-12065）**

**【漏洞详情】**Cacti是Cacti团队的一套开源的网络流量监测和分析工具。该工具通过snmpget来获取数据，使用RRDtool绘画图形进行分析，并提供数据和用户管理功能。

Cacti 1.1.16之前的版本中的spikekill.php文件存在安全漏洞。远程攻击者可借助‘avgnan’、‘outlier-start’或‘outlier-end’参数利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://cacti.net/release\_notes.php?version=1.1.16

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201708-007
