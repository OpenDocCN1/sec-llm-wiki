今日CNNVD共发布安全漏洞102个，更新安全漏洞21个。主要影响厂商为美国IBM（9个）、美国NVIDIA（8个）、美国ImageMagick Studi（6个），主要影响产品为IBM InfoSphere Master Data Management（MDM）解决方案（5个）、NVIDIA GPU Display Driver处理程序（2个）、ImageMagick是美国ImageMagick Studio图象处理软件（6个）。

今日需关注的典型漏洞如下:

【漏洞名称】IBM InfoSphere Master Data Management 跨站请求伪造漏洞

【漏洞编号】CNNVD-201707-1582（CVE-2016-9714）

【漏洞详情】IBM InfoSphere Master Data Management（MDM）是美国IBM公司的一套用于帮助组织管理整个企业范围内的主数据（关于客户、供应商、产品和帐户的信息）的解决方案。该方案支持通过协作、操作和分析这三种主数据使用风格集中多个数据领域。

IBM InfoSphere MDM中存在跨站请求伪造漏洞。远程攻击者可利用该漏洞执行未授权的操作。以下版本受到影响：IBM InfoSphere Master Data Management 11.0版本，11.3版本，11.4版本，11.5版本，11.6版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22006608

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-1582


【漏洞名称】NVIDIA GPU Display Driver 安全漏洞

【漏洞编号】CNNVD-201707-1615（CVE-2017-6257）

【漏洞详情】NVIDIA GPU Display Driver是美国英伟达（NVIDIA）公司的一款图形处理器(GPU)显卡驱动程序。kernel mode layer handler是其中的一个内核模式层处理程序。

NVIDIA GPU Display Driver中的kernel mode layer handler存在安全漏洞。攻击者可利用该漏洞提升权限或造成拒绝服务（空指针逆向引用）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://nvidia.custhelp.com/app/answers/detail/a_id/4525

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-1615


【漏洞名称】ImageMagick 安全漏洞

【漏洞编号】CNNVD-201707-1592（CVE-2017-11751）

【漏洞详情】ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.6-4版本中的coders/xpm.c文件的‘WritePICONImage’函数存在安全漏洞。远程攻击者可借助特制的文件利用该漏洞造成拒绝服务（内存泄露）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/issues/631

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-1592


【漏洞名称】VMware vCenter Server 安全漏洞

【漏洞编号】CNNVD-201707-1612（CVE-2017-4919）

【漏洞详情】VMware vCenter Server是美国威睿（VMware）公司的一套服务器和虚拟化管理软件。该软件提供了一个用于管理VMware vSphere环境的集中式平台，可自动实施和交付虚拟基础架构。

VMware vCenter Server 5.5版本、6.0版本和6.5版本中存在安全漏洞。攻击者可利用该漏洞未经身份验证访问Guest Operating System。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.vmware.com/security/advisories/VMSA-2017-0012.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-1612

【漏洞名称】ProjeQtOr 安全漏洞

【漏洞编号】CNNVD-201707-1583（CVE-2017-11760）

【漏洞详情】ProjeQtOr（前称Project'Or RIA）是一套基于PHP的开源项目管理软件。该软件用于组织多个项目所需的各个功能，适用于IT项目。

ProjeQtOr 6.3.2之前的版本中的uploadImage.php文件存在安全漏洞。远程攻击者可通过上传由图像数据和脚本数据构成的.php文件利用该漏洞执行任意的PHP文件。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://projeqtor.org/en/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-1583
