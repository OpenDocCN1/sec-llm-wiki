今日CNNVD共发布安全漏洞98个，更新安全漏洞9个。主要影响厂商为美国Oracle（29个）、美国IBM（4个）、美国Zoho（3个），主要影响产品为Oracle E-Business Suite（电子商务套件）应用程序（6个）、IBM TRIRIGA Application Platform技术平台（3个）、Zoho ManageEngine Event Log Analyzer软件（3个）。

今日需关注的典型漏洞如下:

【漏洞名称】Oracle VM VirtualBox 安全漏洞

【漏洞编号】CNNVD-201707-1462（CVE-2017-10187）

【漏洞详情】Oracle Virtualization是美国甲骨文（Oracle）公司的一套软硬件虚拟化管理解决方案。Oracle VM VirtualBox是其中的一个虚拟机组件。

Oracle Virtualization中的VM VirtualBox组件5.1.24之前的版本的Core子组件存在安全漏洞。本地攻击者可利用该漏洞未授权更新、插入或删除数据，造成拒绝服务，影响数据的可用性和完整性。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.oracle.com/technetwork/security-advisory/cpujul2017-3236622.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-1462


【漏洞名称】IBM TRIRIGA Application Platform 跨站脚本漏洞

【漏洞编号】CNNVD-201707-1111（CVE-2017-1372）

【漏洞详情】IBM TRIRIGA Application Platform是美国IBM公司的一套用于部署TRIRIGA应用的技术平台。该平台提供了一组设计时和运行时组件，分别用于构建和运行其企业级应用，并支持客户特定的配置，而无需更改源代码。

IBM TRIRIGA Application Platform中存在跨站脚本漏洞。远程攻击者可利用该漏洞向Web UI注入任意的JavaScript脚本。以下版本受到影响：IBM TRIRIGA Application Platform 3.5.0版本至3.5.2.2版本，3.4.0版本至3.4.2.5版本，3.3.0版本至3.3.2.5版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22004675

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-1111


【漏洞名称】Zoho ManageEngine Event Log Analyzer 跨站脚本漏洞

【漏洞编号】CNNVD-201707-1410（CVE-2017-11685）

【漏洞详情】Zoho ManageEngine Event Log Analyzer是美国卓豪（Zoho）公司的一套系统、事件日志分析软件。该软件能够对全网范围内的主机、服务器、网络设备以及各种应用服务系统等产生的日志，进行全面收集和细致分析。

Zoho ManageEngine Event Log Analyzer 11.4版本和11.5版本中的事件数据的搜索和显示存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.manageengine.com/products/eventlog/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-1410


【漏洞名称】Avira Antivirus引擎安全漏洞

【漏洞编号】CNNVD-201707-1401（CVE-2016-10402）

【漏洞详情】Avira Antivirus engine是德国小红伞（Avira）公司的一款杀毒引擎。

Avira Antivirus引擎8.3.36.60之前的版本中存在安全漏洞。远程攻击者可利用该漏洞以NT AUTHORITY\SYSTEM权限执行代码，造成整数溢出和基于堆的缓冲区下溢。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.avira.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-1401


【漏洞名称】Dahua IP camera 缓冲区错误漏洞

【漏洞编号】CNNVD-201707-1180（CVE-2017-3223）

【漏洞详情】Dahua IP Camera是中国大华（Dahua）公司的一款网络摄像头。

Dahua IP Camera中存在基于栈的缓冲区溢出漏洞。攻击者可利用该漏洞在受影响应用程序上下文中执行任意代码或造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.dahuasecurity.com/en/us/index.php

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-1180
