今日CNNVD共发布安全漏洞26个，更新安全漏洞5个。主要影响厂商为美国Apple（23个）、美国Oracle（3个），主要影响产品为Apple iOS操作系统（16个）、Apple macOS Sierra操作系统（7个）、Oracle Sun Systems Products Suite系统产品套件（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】多款Apple产品WebKit 安全漏洞

【漏洞编号】CNNVD-201707-971（CVE-2017-7039）

【漏洞详情】Apple iOS、iCloud for Windows、iTunes for Windows、Safari和tvOS都是美国苹果（Apple）公司的产品。Apple iOS是一套为专移动设备所开发的一套操作系统；Safari是一款Web浏览器，是Mac OS X和iOS操作系统附带的默认浏览器。WebKit是KDE社区开发的一套开源Web浏览器引擎，目前被Apple Safari及Google Chrome等浏览器使用。

多款Apple产品中的WebKit组件中存在内存损坏漏洞。远程攻击者可借助特制的网站利用该漏洞执行任意代码或造成拒绝服务（内存损坏和应用程序崩溃）。以下产品和版本受到影响：Apple Safari 10.1.2之前的版本；tvOS 10.2.2之前的版本；iOS 10.3.3之前的版本；基于Windows平台的iCloud 6.2.2之前的版本；基于Window平台的iTunes 12.6.2之前的版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/zh-cn/HT207921

https://support.apple.com/zh-cn/HT207923

https://support.apple.com/zh-cn/HT207924

https://support.apple.com/zh-cn/HT207927

https://support.apple.com/zh-cn/HT207928

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-971


【漏洞名称】Apple macOS Sierra Intel Graphics Driver 安全漏洞

【漏洞编号】CNNVD-201707-974（CVE-2017-7036）

【漏洞详情】Apple macOS Sierra是美国苹果（Apple）公司为Mac计算机所开发的一套专用操作系统。Intel Graphics Driver是其中的一个显卡驱动。

Apple macOS Sierra 10.12.6之前的版本中的Intel Graphics Driver组件存在安全漏洞。攻击者可借助特制的应用程序利用该漏洞绕过内存读取限制。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/zh-cn/HT207922

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-974


【漏洞名称】Apple iOS Safari 安全漏洞

【漏洞编号】CNNVD-201707-1005（CVE-2017-2517）

【漏洞详情】Apple iOS是美国苹果（Apple）公司为移动设备所开发的一套操作系统。Safari是其中的一个Web浏览器组件。

Apple iOS 10.3.3之前的版本中的Safari组件存在安全漏洞。远程攻击者可借助特制的网站利用该漏洞伪造地址栏内容。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/HT207923

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-1005


【漏洞名称】Oracle Sun Systems Products Suite Solaris 安全漏洞

【漏洞编号】CNNVD-201707-1021（CVE-2017-3632）

【漏洞详情】Oracle Sun Systems Products Suite是美国甲骨文（Oracle）公司的一款Sun系统产品套件。Solaris是其中的一个类Unix操作系统。

Oracle Sun Systems Products Suite中的Solaris组件10和11版本的CDE Calendar子组件存在安全漏洞。攻击者可利用该漏洞接管组件，影响数据的可用性、保密性和完整性。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.oracle.com/technetwork/security-advisory/cpujul2017-3236622.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-1021


【漏洞名称】Oracle Java SE和Java SE Embedded 安全漏洞

【漏洞编号】CNNVD-201707-1024（CVE-2017-10193）

【漏洞详情】Oracle Java SE和Java SE Embedded都是美国甲骨文（Oracle）公司的产品。Java SE（Java 平台标准版）用于开发和部署桌面、服务器以及嵌入设备和实时环境中的Java应用程序；Java SE Embedded是一款针对嵌入式系统开发功能强大、可靠、可移植的应用程序的Java平台。

Oracle Java SE中的Java SE和Java SE Embedded组件的Security子组件存在安全漏洞。攻击者可利用该漏洞读取数据，影响数据的保密性。以下产品和版本受到影响：Oracle Java SE 6u151版本，7u141版本，8u131版本；Java SE Embedded 8u131版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.oracle.com/technetwork/security-advisory/cpujul2017-3236622.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-1024
