1. ImageMagick资源管理错误漏洞(CNNVD-201707-907) 

ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.6-1版本中的coders\pes.c文件的‘ReadPESImage’函数存在无限循环漏洞。攻击者可借助特制的PES文件利用该漏洞造成CPU耗尽。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/issues/537

2. Microsoft Windows Edge和Internet Explorer JavaScript引擎缓冲区错误漏洞(CNNVD-201707-474)

Microsoft Windows是美国微软（Microsoft）公司发布的一系列操作系统。Microsoft Edge和Internet Explorer（IE）都是Windows系统附带的Web浏览器。前者是最新操作系统Windows 10附带的默认浏览器，后者是Windows 10之前操作系统附带的默认浏览器。JavaScript engine是其中的一个JavaScript引擎组件。

Microsoft Windows中的Edge和IE 9、10和11版本的JavaScript引擎存在远程代码执行漏洞。远程攻击者可利用该漏洞在当前用户的上下文中执行任意代码，损坏内存。以下版本受到影响：

-   Windows Server 2012

-   Windows 8.1

-   Windows RT 8.1

-   Windows Server 2016

-   Windows Server 2012 R2

-   Windows Server 2008 SP2

-   Windows Server 2016

-   Windows 10

-   Windows 10版本1607

-   Windows 10版本1703

-   Windows 10版本1511

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-us/security-guidance/advisory/CVE-2017-8608

3. Huawei SMC2.0 输入验证漏洞(CNNVD-201707-653)

Huawei SMC2.0是中国华为（Huawei）公司的一套视讯管理解决方案。该解决方案同时支持H.323和SIP两种主流协议，支持计算机和手机等设备接入。

Huawei SMC2.0中存在输入验证漏洞，该漏洞源于程序没有充分的验证接收到的PKI证书。远程攻击者可利用该漏洞造成TLS模块拒绝服务。以下版本受到影响：

-   Huawei SMC2.0 V100R003C10版本

-   Huawei V100R005C00SPC100版本

-   Huawei V100R005C00SPC101B001T版本

-   Huawei V100R005C00SPC102版本

-   Huawei V100R005C00SPC103版本

-   Huawei V100R005C00SPC200版本

-   Huawei V100R005C00SPC201T版本

-   Huawei V500R002C00版本

-   Huawei V600R006C00版本

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20170705-01-tls-cn

4. 多款Lenovo产品Sierra Wireless WAN驱动程序权限许可和访问控制漏洞(CNNVD-201707-650)

Lenovo IdeaPadMiix 510-12ISK等都是中国联想（Lenovo）公司的笔记本电脑产品。Sierra Wireless WAN driver是其中的一个加拿大Sierra Wireless公司的无线驱动程序。

基于Windows 7、8和10平台的多款Lenovo产品中的Sierra Wireless WAN驱动程序存在本地提权漏洞。本地攻击者可借助未引用的服务路径利用该漏洞以管理员权限执行文件。以下产品受到影响：

-   Lenovo IdeaPad Miix 510-12ISK

-   Lenovo IdeaPad Miix 510-12IKB

-   Lenovo ThinkPad L450

-   Lenovo ThinkPad L460 Larue-2

-   Lenovo ThinkPad L560

-   Lenovo ThinkPad P40

-   Lenovo ThinkPad P50

-   Lenovo ThinkPad P50s

-   Lenovo ThinkPad P51s KBL

-   Lenovo ThinkPad P51s SKL等

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.lenovo.com/us/zh/product_security/len-12739
