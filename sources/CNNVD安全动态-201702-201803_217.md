# CNNVD最新漏洞（2017-07-20）

今日CNNVD共发布安全漏洞37个，更新安全漏洞16个。主要影响厂商为美国Juniper Networks（13个）、美国IBM（1个）、美国Google（1个），主要影响产品为Juniper SSG Series防火墙（5个）、IBM MQ Appliance一体机设备（1个）、Google Chrome for Windows Web浏览器（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Juniper SSG Series设备ScreenOS 跨站脚本漏洞**  

**【漏洞编号】****CNNVD-201707-623（CVE-2017-2339）**

**【漏洞详情】**Juniper SSG Series是美国瞻博网络（Juniper Networks）公司的一系列防火墙设备。ScreenOS是其中的一套操作系统。

Juniper SSG Series设备上的ScreenOS 6.3.0版本中Firewall+VPN存在跨站脚本漏洞。远程攻击者可利用该漏洞向其他用户（包括管理员）的管理会话中注入HTML/JavaScript内容，以管理员权限执行命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://kb.juniper.net/InfoCenter/index?page=content&id=JSA10782

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-623

**【漏洞名称】******IBM MQ Appliance 安全漏洞****

**【漏洞编号】****CNNVD-201707-753（CVE-2017-1318）**

**【漏洞详情】**IBM MQ Appliance是美国IBM公司的一款用于快速部署企业级消息中间件的一体机设备。

IBM MQ Appliance 8.0版本和9.0版本中存在安全漏洞。攻击者可利用该漏洞在系统上执行任意命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22003815

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-753

  

**【漏洞名称】****Google Chrome和Mozilla firefox for Windows Cisco WebEx Browser Extension 安全漏洞**

**【漏洞编号】****CNNVD-201707-864（CVE-2017-6753）**

**【漏洞详情】**Google Chrome for Windows是美国谷歌（Google）公司开发的一款基于Windows的Web浏览器。Mozilla Firefox for Windows是美国Mozilla基金会的一款基于Windows平台的开源Web浏览器。Cisco WebEx Browser Extension是应用在其中的一个美国思科（Cisco）公司的在线会议扩展插件。

基于Windows平台的Google Chrome和Mozilla firefox上的Cisco WebEx Browser Extension 1.0.12之前的版本中存在远程代码执行漏洞。远程攻击者可通过诱使用户访问恶意的Web页面或点击恶意的链接利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20170717-webex

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-685

  

**【漏洞名称】****Wireshark openSAFETY解析器安全漏洞**

**【漏洞编号】****CNNVD-201707-742（CVE-2017-11411）**

**【漏洞详情】**Wireshark（前称Ethereal）是Wireshark团队开发的一套网络数据包分析软件。该软件的功能是截取网络数据包，并显示出详细的数据以供分析。openSAFETY dissector是其中的一个openSAFETY协议解析器。

Wireshark 2.0.13及之前的版本和2.2.x版本至2.2.7版本中的openSAFETY解析器存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（崩溃或内存耗尽）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.wireshark.org/security/wnpa-sec-2017-28.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-742

  

**【漏洞名称】****Fiyo CMS SQL注入漏洞**

**【漏洞编号】****CNNVD-201707-755（CVE-2017-11419）**

**【漏洞详情】**Fiyo CMS是一套用于制作CMS模板的内容管理系统（CMS）。

Fiyo CMS 2.0.7版本中的/apps/app\_article/controller

/editor.php文件存在SQL注入漏洞。远程攻击者可借助$\_POST\['id'\]和$\_POST\['art\_title'\]利用该漏洞执行任意的SQL命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/FiyoCMS/FiyoCMS/issues/5

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-755
