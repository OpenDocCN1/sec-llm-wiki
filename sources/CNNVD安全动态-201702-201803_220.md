今日CNNVD共发布安全漏洞118个，更新安全漏洞9个。主要影响厂商为美国Microsoft（24个）、美国Google（24个）、美国Cisco（14个），主要影响产品为Android操作系统（24个）、Microsoft Windows操作系统（19个）、Cisco Elastic Services Controller（ESC）模块化系统（6个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Microsoft Windows Graphics 权限许可和访问控制漏洞**  

**【漏洞编号】****CNNVD-201707-454（CVE-2017-8556）**

**【漏洞详情】**Microsoft Windows是美国微软（Microsoft）公司发布的一系列操作系统。Graphics是其中的一个图形驱动器组件。

Microsoft Windows中的Graphics存在提权漏洞，该漏洞源于Graphics组件没有正确的处理内存中的对象。本地攻击者可借助特制的应用程序利用该漏洞以提升的权限在内核模式下执行任意代码。以下版本受到影响：Microsoft Windows Server 2016，Windows Server 2012 R2，Windows Server 2012，Windows Server 2008 R2 SP1，Windows Server 2008 SP2，Windows RT 8.1，Windows 8.1，Windows 7 SP1，Windows 10版本1703，Windows 10版本1607，Windows 10版本1511，Windows 10。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-us/security-guidance/advisory/CVE-2017-8556

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-454

**【漏洞名称】******Android libxml2 安全漏洞****

**【漏洞编号】****CNNVD-201706-605（CVE-2017-0663）**

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。libxml2是其中的一个基于C语言的用来解析XML文档的函数库组件。

Android中的libxml2存在远程代码执行漏洞。远程攻击者借助特制的文件利用该漏洞执行任意代码。以下版本受到影响：Android 4.4.4版本，5.0.2版本，5.1.1版本，6.0版本，6.0.1版本，7.0版本，7.1.1版本，7.1.2版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2017-06-01

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-605

  

**【漏洞名称】****Cisco Elastic Services Controller 信息泄露漏洞**

**【漏洞编号】****CNNVD-201706-360（CVE-2017-6697）**

**【漏洞详情】**Cisco Elastic Services Controller（ESC）是美国思科（Cisco）公司的一个开源的模块化系统。

Cisco Elastic Services Controller中的Web界面存在信息泄露漏洞，该漏洞源于程序没有充分的对受影响系统上的证书资源库执行访问控制。远程攻击者可利用该漏洞获取储存在受影响系统中的敏感证书的访问权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20170607-esc9

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-360

  

**【漏洞名称】****IBM Emptoris Services Procurement 安全漏洞**

**【漏洞编号】****CNNVD-201707-564（CVE-2017-1441）**

**【漏洞详情】**IBM Emptoris Services Procurement是美国IBM公司的一套采购管理系统。该系统能够控制并管理第三方服务类别的采购生命周期。

IBM Emptoris Services Procurement 10.x版本中存在安全漏洞，该漏洞源于不正确的访问控制。本地攻击者可利用该漏洞查看敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22005550

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-564

  

**【漏洞名称】****Apache OpenMeetings 跨站脚本漏洞**

**【漏洞编号】****CNNVD-201707-593（CVE-2017-7663）**

**【漏洞详情】**Apache OpenMeetings是美国阿帕奇（Apache）软件基金会所研发的一套多语言可定制的视频会议和协作系统，它支持音频、视频并允许用户查看每个与会者的桌面等。

Apache OpenMeetings中存在跨站脚本漏洞。远程攻击者可利用该漏洞在浏览器中执行任意代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://openmeetings.apache.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-593
