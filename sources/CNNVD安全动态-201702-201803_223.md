今日CNNVD共发布安全漏洞59个，更新安全漏洞66个。主要影响厂商为美国Microsoft（14个）、美国IBM（7个）、美国Google（7个），主要影响产品为Microsoft Windows操作系统（14个）、IBM Emptoris Sourcing解决方案（7个）、Android操作系统（7个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Microsoft Windows 安全漏洞**  

**【漏洞编号】****CNNVD-201707-439（CVE-2017-8589）**

**【漏洞详情】**Microsoft Windows是美国微软（Microsoft）公司发布的一系列操作系统。

Microsoft Windows中存在远程代码执行漏洞，该漏洞源于Windows Search处理内存对象的方式。远程攻击者可利用该漏洞在目标系统上执行任意代码或造成拒绝服务。以下版本受到影响：Microsoft Windows Server 2016，Windows Server 2012 R2，Windows Server 2012，Windows Server 2008 R2 SP1，Windows Server 2008 SP2，Windows RT 8.1，Windows 8.1，Windows 7 SP1，Windows 10版本1703，Windows 10版本1607，Windows 10版本1511，Windows 10。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-us/security-guidance/advisory/CVE-2017-8589

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-439

**【漏洞名称】******IBM Emptoris Sourcing 安全漏洞****

**【漏洞编号】****CNNVD-201707-526（CVE-2016-8953）**

**【漏洞详情】**IBM Emptoris Sourcing是美国IBM公司的一套寻源到合同解决方案。该方案通过在寻源决策时考察成本、风险和绩效等因素，帮助企业从供应商那里获得实惠的价格和更大的价值。

IBM Emptoris Sourcing中存在安全漏洞。远程攻击者可通过诱使用户访问特制的网站利用该漏洞将用户重定向到任意网站，实施钓鱼攻击，获取敏感信息。以下版本受到影响：IBM Emptoris Sourcing 9.5.x版本，10.0.0版本，10.0.2版本，10.0.4版本，10.1.0版本，10.1.1版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22005549

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-526

  

**【漏洞名称】****Android Media framework 安全漏洞**

**【漏洞编号】****CNNVD-201707-262（CVE-2017-0682）**

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Media framework是其中的一个用于多媒体开发框架。

Android 7.0版本、7.1.1版本和7.1.2版本中Media framework存在远程代码执行漏洞。远程攻击者可利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2017-07-01

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-262

  

**【漏洞名称】****SAP NetWeaver disp+work 安全漏洞**

**【漏洞编号】****CNNVD-201707-532（CVE-2017-9845）**

**【漏洞详情】**SAP NetWeaver是德国思爱普（SAP）公司的一套面向服务的集成化应用平台。该平台可为SAP应用提供开发和运行环境。disp+work是其中的一个任务分派器。

SAP NetWeaver 7.40版本中的disp+work 7400.12.21.30308版本存在安全漏洞。远程攻击者可通过发送特制的DIAG请求利用该漏洞造成拒绝服务（资源消耗）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.sap.com/index.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-532

  

**【漏洞名称】****McAfee Advanced Threat Defense 权限许可和访问控制漏洞**

**【漏洞编号】****CNNVD-201707-537（CVE-2017-4057）**

**【漏洞详情】**McAfee Advanced Threat Defense（ATD）是美国迈克菲（McAfee）公司的一套威胁检测和防御解决方案。该方案提供恶意软件分析、共享威胁情报和隔离受损系统等功能。

McAfee ATD中的Web界面存在提权漏洞。远程攻击者可借助GUI或GUI终止命令利用该漏洞获取提升的权限。以下版本受到影响：McAfee Advanced Threat Defense 3.10版本，3.8版本，3.6版本，3.4版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://kc.mcafee.com/corporate/index?page=content&id=SB10204

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-537
