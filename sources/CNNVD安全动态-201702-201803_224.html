今日CNNVD共发布安全漏洞24个，更新安全漏洞1个。主要影响厂商为美国Microsoft（13个）、美国Apache（2个）、美国Google（1个），主要影响产品为Microsoft Windows操作系统（10个）、Apache Solr搜索服务器（1个）、Android操作系统（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Microsoft Windows 安全漏洞

【漏洞编号】CNNVD-201707-483（CVE-2017-8563）

【漏洞详情】Microsoft Windows是美国微软（Microsoft）公司发布的一系列操作系统。

Microsoft Windows中存在提权漏洞。远程攻击者可借助特制的应用程序利用该漏洞获取提升的权限。以下版本受到影响：Microsoft Windows Server 2016，Windows Server 2012 R2，Windows Server 2012，Windows Server 2008 R2 SP1，Windows Server 2008 SP2，Windows RT 8.1，Windows 8.1，Windows 7 SP1，Windows 10，Windows 10版本1607，Windows 10版本1703，Windows 10版本1511。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-8563

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-483


【漏洞名称】Apache Solr 安全漏洞

【漏洞编号】CNNVD-201707-323（CVE-2017-7660）

【漏洞详情】Apache Solr是美国阿帕奇（Apache）软件基金会的一款基于Lucene（一个全文检索引擎的架构）的搜索服务器，它支持层面搜索、垂直搜索、高亮显示搜索结果、多种输出格式等。

Apache Solr 5.3版本至5.5.4版本和6.0版本至6.5.1版本中存在安全漏洞。攻击者可利用该漏洞绕过安全限制，执行未授权的操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://mail-archives.us.apache.org/mod_mbox/www-announce/201707.mbox/%3CCAOOKt53EgrybaD%2BiSn-nBbvFdse-szhg%3DhMoDZuvUvyMme-Z%3Dg%40mail.gmail.com%3E

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-323


【漏洞名称】Android NVIDIA Libnvparser 权限许可和访问控制漏洞

【漏洞编号】CNNVD-201707-340（CVE-2017-0340）

【漏洞详情】Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。NVIDIA Libnvparser是其中的一个美国英伟达（NVIDIA）公司开发的解析器。

Android中的NVIDIA Libnvparser组件存在提权漏洞。远程攻击者可利用该漏洞损坏内存，执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2017-07-01

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-340


【漏洞名称】Cisco Prime Network Software installation procedure 权限许可和访问控制漏洞

【漏洞编号】CNNVD-201707-389（CVE-2017-6732）

【漏洞详情】Cisco Prime Network Software是美国思科（Cisco）公司的一套用于网络管理员对网络的使用情况、运行状态等进行管理和配置并进行故障管理的网络分析软件。installation procedure是其中的一个安装配置程序。

Cisco Prime Network Software中的installation procedure存在提权漏洞，该漏洞源于程序没有正确的安装二进制文件并且没有正确的配置二进制文件的权限。本地攻击者可利用该漏洞将权限提升至root。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20170705-prime

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-389
