CNNVD最新漏洞（2017-07-06）

今日CNNVD共发布安全漏洞28个，更新安全漏洞8个。主要影响厂商为美国IBM（4个）、美国Dell（3个）、美国Linux（2个），主要影响产品为IBM Security Guardium数据保护平台（4个）、Dell Invincea-X防护工具（3个）、Linux kernel内核（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】IBM Security Guardium 信息泄露漏洞

【漏洞编号】CNNVD-201707-127（CVE-2016-0238）

【漏洞详情】IBM Security Guardium是美国IBM公司的一套提供数据保护功能的平台。该平台包括轻松自定义UI、报告管理和发现和流线化的审计流程构建器。

IBM Security Guardium中存在信息泄露漏洞，该漏洞源于程序以明文的形式传递查询请求中的敏感信息。攻击者可利用该漏洞实施中间人攻击，获取敏感信息。以下版本受到影响：IBM Security Guardium 9版本，9.1版本，9.5版本，10版本，10.1版本，10.1.2版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg21989124

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-127


【漏洞名称】Dell Invincea-X 权限许可和访问控制漏洞

【漏洞编号】CNNVD-201707-079（CVE-2016-9038）

【漏洞详情】Dell Invincea-X是美国戴尔（Dell）公司的一款恶意软件防护工具，它通过隔离执行或者下一代检测算法进行恶意软件防护。

Dell Invincea-X 6.1.3-24058版本中的SboxDrv.sys驱动程序功能存在本地提权漏洞。攻击者可利用该漏洞损坏内核内存，提升权限。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.dell.com/en-us/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-079


【漏洞名称】Linux kernel 安全漏洞

【漏洞编号】CNNVD-201707-112（CVE-2017-10810）

【漏洞详情】Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。

Linux kernel 4.11.8及之前的版本中的drivers/gpu/drm/virtio/virtgpu_object.c文件的‘virtio_gpu_object_create’函数存在内存泄露漏洞。攻击者可利用该漏洞造成拒绝服务（内存消耗）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=385aee965b4e4c36551c362a334378d2985b722a

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-112


【漏洞名称】Xen 安全漏洞

【漏洞编号】CNNVD-201707-114（CVE-2017-10923）

【漏洞详情】Xen是英国剑桥大学开发的一款开源的虚拟机监视器产品。该产品能够使不同和不兼容的操作系统运行在同一台计算机上，并支持在运行时进行迁移，保证正常运行并且避免宕机。

Xen 4.8.x及之前的版本中存在安全漏洞，该漏洞源于在发送SGI时程序没有验证vCPU数组索引。攻击者可利用该漏洞造成拒绝服务（hypervisor崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://xenbits.xen.org/xsa/advisory-225.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-114


【漏洞名称】Huawei Vicky-AL00A和Victoria-AL00A 安全漏洞

【漏洞编号】CNNVD-201707-070（CVE-2017-8172）

【漏洞详情】Huawei Vicky-AL00A和Victoria-AL00A都是中国华为（Huawei）公司的智能手机设备。

Huawei Vicky-AL00A Vicky-AL00AC00B157之前的版本和Victoria-VL00A Victoria-VL00AC00B157之前的版本中的lsub服务存在拒绝服务漏洞，该漏洞源于程序没有充分执行输入校验。攻击者可借助恶意的应用程序向特定接口发送特制的参数利用该漏洞造成拒绝服务（手机重启）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.huawei.com/cn/psirt/security-advisories/2017/huawei-sa-20170628-01-isub-cn

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-070
