今日CNNVD共发布安全漏洞40个，更新安全漏洞24个。主要影响厂商为美国IBM（12个）、美国Cisco（9个）、美国EMC（5个），主要影响产品为Cisco IOS和IOS XE操作系统（9个）、EMC RSA Archer GRC合规治理产品（5个）、IBM Security Guardium数据保护平台（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Cisco IOS和IOS XE Simple Network Management Protocol 安全漏洞**  

**【漏洞编号】****CNNVD-201706-1229（CVE-2017-6736）**

**【漏洞详情】**Cisco IOS和IOS XE都是美国思科（Cisco）公司为其网络设备开发的操作系统。Simple Network Management Protocol (SNMP)是其中的一个用于网络设备管理信息交换的简单网络管理协议。

Cisco IOS和IOS XE中的SNMP 1版本、2c版本和3版本中存在安全漏洞。远程攻击者可通过向受影响系统发送特制的SNMP数据包利用该漏洞在受影响的系统上执行任意代码或造成系统重启。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20170629-snmp

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-1229

  

**【漏洞名称】******IBM Security Guardium SQL注入漏洞****

**【漏洞编号】****CNNVD-201707-071（CVE-2017-1269）**

**【漏洞详情】**IBM Security Guardium是美国IBM公司的一套提供数据保护功能的平台。该平台包括轻松自定义UI、报告管理和发现和流线化的审计流程构建器。

IBM Security Guardium中存在SQL注入漏洞。远程攻击者可通过发送特制的SQL语句利用该漏洞查看、添加、更改或删除后端数据库中的信息。以下版本受到影响：IBM Security Guardium 10.0版本，10.0.1版本，10.1版本，10.1.2版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22004462

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-071

  

**【漏洞名称】****EMC RSA Archer GRC 跨站请求伪造漏洞**

**【漏洞编号】****CNNVD-201707-087（CVE-2017-4998）**

**【漏洞详情】**EMC RSA Archer GRC是美国易安信（EMC）公司的一款企业IT治理和合规治理产品。该产品可以制定eGRC计划，用于管理企业风险、实现业务流程自动化等。

EMC RSA Archer GRC中存在跨站请求伪造漏洞。远程攻击者可利用该漏洞执行未授权的操作。以下版本受到影响：EMC RSA Archer GRC 5.5.1.3.1版本，5.5.2版本，5.5.2.3版本，5.5.3.1版本，5.4.1.3版本。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.emc.com/en-us/index.htm

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-087

  

**【漏洞名称】****TOSHIBA Home Gateway HEM-GW26A和HEM-GW16A 安全漏洞**

**【漏洞编号】****CNNVD-201706-1243（CVE-2017-2234）**

**【漏洞详情】**TOSHIBA Home Gateway HEM-GW26A和TOSHIBA Home Gateway HEM-GW16A都是日本东芝（TOSHIBA）公司的家庭网关产品。

使用HEM-GW26A-FW-V1.2.0及之前版本固件的TOSHIBA Home Gateway HEM-GW26A和使用HEM-GW16A-FW-V1.2.0及之前版本固件的TOSHIBA Home Gateway HEM-GW16A存在安全漏洞。攻击者可利用该漏洞以管理员权限执行操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.tlt.co.jp/tlt/information/seihin/notice/defect/20170626/20170626.htm

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-1243

  

**【漏洞名称】****Best Practical Solutions Request Tracker 安全漏洞**

**【漏洞编号】****CNNVD-201707-061（CVE-2017-5944）**

**【漏洞详情】**Best Practical Solutions Request Tracker（RT）是美国Best Practical Solutions公司的一套企业级开源问题跟踪系统。该系统具有Bug跟踪、客户服务、自定义工作流等功能。

Best Practical Solutions RT中的dashboard subscription界面中存在安全漏洞。远程攻击者可借助已保存搜索名利用该漏洞执行任意代码。以下版本受到影响：Request Tracker 4.0.25之前的4.x版本，4.2.14之前的4.2.x版本，4.4.2之前的4.4.x版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://forum.bestpractical.com/t/security-vulnerabilities-in-rt-2017-06-15/32016

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201707-061
