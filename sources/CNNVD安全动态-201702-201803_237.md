今日CNNVD共发布安全漏洞26个，更新安全漏洞11个。主要影响厂商为中国福斯康姆（8个）、中国联想（3个）、美国Microsoft（1个），主要影响产品为Foscam C1 Indoor HD Camera高清IP摄像机（8个）、Lenovo A2010-a智能手机（3个）、Windows操作系统（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Foscam C1 Indoor HD Camera 缓冲区错误漏洞**  

**【漏洞编号】****CNNVD-201706-1211（CVE-2017-2851）**

**【漏洞详情】**Foscam C1 Indoor HD Camera是中国福斯康姆（Foscam）公司的一款无线高清IP摄像机。

使用2.52.2.37版本应用程序固件的Foscam C1 Indoor HD Camera中的Web管理界面存在缓冲区溢出漏洞。攻击者可通过发送特制的HTTP请求利用该漏洞覆盖任意数据，或执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.foscam.com/company/security-updates.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-1211

  

**【漏洞名称】******多款Lenovo VIBE手机权限许可和访问控制漏洞****

**【漏洞编号】****CNNVD-201706-1176（CVE-2017-3748）**

**【漏洞详情】**Android 6.0 Marshmallow是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Lenovo A2010-a等都是中国联想（Lenovo）公司的使用Android 6.0 Marshmallow操作系统的智能手机产品。

使用Android 6.0 Marshmallow之前的版本的多款Lenovo VIBE手机中存在提权漏洞。攻击者可利用该漏洞将权限提升至root。以下产品受到影响：Lenovo A2010-a；A2010-l；A2020a40；A2580；A3580；A3690；A3860(t-3)；A3860(ts-3)；A3890；A3910e70；A3910t30；A5600；A5890；A6020a40；A6020a41；A6020a46；A6020i36；A7600；A7600-m；K31-t3-s；K32c36；K52t38；K920；P1ma40；S1La40；A1600；A2560；A2800；A2860；A2880；A3000；A3500；A3600-d；A3600u；A3800-d；A3900；A6000；A6000-I；A6600；A6020i37；A6800；K30-E；K30-W-cu；K32c30；K80M；A7010a48；A7020a40；A7020a48；K50-t3s；K50-t5；K51c78；K52e78；P1c58；P1c72；X3a40；X3c50；X3c70；Z90-3；Z90-7。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.lenovo.com/us/en/product\_security/LEN-15823

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-1176

  

**【漏洞名称】****Microsoft Windows kernel 信息泄露漏洞**

**【漏洞编号】****CNNVD-201706-1221（CVE-2017-8554）**

**【漏洞详情】**Microsoft Windows是美国微软（Microsoft）公司发布的一系列操作系统。kernel是其中的内核。

Microsoft Windows中的kernel存在信息泄露漏洞，该漏洞源于程序没有正确的处理内存中的对象。攻击者可借助特制的应用程序利用该漏洞获取内存中的内容。以下版本受到影响：Microsoft Windows 7 SP1，Windows Server 2008 SP2和R2 SP1，Windows 8.1，Windows RT 8.1，Windows Server 2012和R2，Windows 10，Windows 10版本1511，Windows 10版本1607，Windows 10版本1703，Windows Server 2016。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-8554

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-1221

  

**【漏洞名称】****Red Hat CloudForms Management Engine 信息泄露漏洞**

**【漏洞编号】****CNNVD-201706-1226（CVE-2016-7047）**

**【漏洞详情】**Red Hat CloudForms Management Engine（CFME）是美国红帽（Red Hat）公司的一个IaaS（基础设施即服务）云服务解决方案的管理引擎。

Red Hat CFME中存在信息泄露漏洞。攻击者可利用该漏洞获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://rhn.redhat.com/errata/RHSA-2017-1601.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-1226

  

**【漏洞名称】****Piwigo SQL注入漏洞**

**【漏洞编号】****CNNVD-201706-1206（CVE-2017-10682）**

**【漏洞详情】**Piwigo是Piwigo团队的一套基于Web的相册软件。该软件支持照片发布、管理、多种浏览方式（类别、标签、时间）等。

Piwigo 2.9.1及之前的版本中的administrative后端存在SQL注入漏洞。远程攻击者可借助评论或状态页面中的‘cat\_true’或‘cat\_false’参数利用该漏洞执行任意SQL命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/Piwigo/Piwigo/commit/3dd6812412289a199564e63fffd0a9754010b9e0

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-1206
