# CNNVD最新漏洞（2017-06-28）

今日CNNVD共发布安全漏洞16个，更新安全漏洞14个。主要影响厂商为美国IBM（5个）、日本KDDI（4个）、美国Silicon Graphics（3个），主要影响产品为KDDI HOME SPOT CUBE无线路由器（4个）、Silicon Graphics LibTIFF文件库（3个）、IBM QRadar SIEM解决方案（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****IBM QRadar SIEM 安全漏洞**  

**【漏洞编号】****CNNVD-201706-1108（CVE-2016-9738）**

**【漏洞详情】**IBM QRadar SIEM是美国IBM公司的一套利用安全智能保护资产和信息远离高级威胁的解决方案。该方案提供对整个IT架构范围进行监督、生成详细的数据访问和用户活动报告等功能。

IBM QRadar SIEM 7.2.0版本至7.2.8 path 6版本和7.3.0版本至7.3.0 Path 1版本中存在安全漏洞，该漏洞源于在默认情况下程序没有要求使用保密性较高的密码。攻击者可利用该漏洞控制用户账户。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22004926

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-1108

**【漏洞名称】****KDDI HOME SPOT CUBE WebUI 操作系统命令注入漏洞**  

**【漏洞编号】****CNNVD-201706-1110（CVE-2017-2183）**

**【漏洞详情】**KDDI HOME SPOT CUBE是日本KDDI公司的一款家庭无线路由器产品。WebUI是其中的一个图形用户界面。

使用101及之前版本固件的KDDI HOME SPOT CUBE2中的WebUI中存在操作系统命令注入漏洞。远程攻击者可利用该漏洞执行任意的操作系统命令。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.kddi.com/english/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-1110

  

**【漏洞名称】****Silicon Graphics LibTIFF 安全漏洞**

**【漏洞编号】****CNNVD-201706-1101（CVE-2017-9936）**

**【漏洞详情】**Silicon Graphics LibTIFF是美国Silicon Graphics公司的一个读写TIFF（标签图像文件格式）文件的库。该库包含一些处理TIFF文件的命令行工具

Silicon Graphics LibTIFF 4.0.8版本中的tif\_jbig.c文件存在内存泄露漏洞。攻击者可借助特制的TIFF利用该漏洞实施拒绝服务攻击。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.libtiff.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-1101

  

**【漏洞名称】****fedora-arm-installer 权限许可和访问控制漏洞**

**【漏洞编号】****CNNVD-201706-1099（CVE-2017-7496）**

**【漏洞详情】**fedora-arm-installer是Fedora项目社区开发的一个二进制图像写入工具的安装程序。

fedora-arm-installer 1.99.16及之前的版本中存在本地提权漏洞。攻击者可利用该漏洞绕过安全限制。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://pagure.io/arm-image-installer/pull-request/10

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-1099

  

**【漏洞名称】****Cognito Software Moneyworks 安全漏洞**

**【漏洞编号】****CNNVD-201706-1105（CVE-2017-9615）**

**【漏洞详情】**Cognito Software Moneyworks是新西兰Cognito Software公司的一套跨平台的金融管理软件。

Cognito Software Moneyworks 8.0.3及之前的版本中存在安全漏洞，该漏洞源于程序将管理员密码写到全域可读的文件中。攻击者可利用该漏洞访问所有数据。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

http://cognito.co.nz/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-1105
