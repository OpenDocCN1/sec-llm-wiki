今日CNNVD共发布安全漏洞32个，更新安全漏洞9个。主要影响厂商为美国Cisco（12个）、美国IBM（5个）、美国Microsoft（3个），主要影响产品为IBM Sterling B2B Integrator软件（3个）、Microsoft Windows操作系统（3个）、Cisco IOS XR Software操作系统（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Cisco IOS XR Software 权限许可和访问控制漏洞**  

**【漏洞编号】****CNNVD-201706-998（CVE-2017-6718）**

**【漏洞详情】**Cisco IOS XR Software是美国思科（Cisco）公司的IOS软件系列（包括IOS T、IOS S和IOS XR）中的一套完全模块化、分布式的网络操作系统

Cisco IOS XR Software中的CLL存在提权漏洞，该漏洞源于程序没有正确的为二进制文件设置权限。本地攻击者可通过向受影响的设备发送特制的命令利用该漏洞覆盖文件系统上的二进制文件，将权限提升至root

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20170621-ios1

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-998

**【漏洞名称】****IBM Sterling B2B Integrator 信息泄露漏洞**  

**【漏洞编号】****CNNVD-201706-991（CVE-2017-1193）**

**【漏洞详情】**IBM Sterling B2B Integrator是美国IBM公司的一套集成了重要的B2B流程、交易和关系的软件。该软件支持与不同的合作伙伴社区之间实现复杂的B2B流程的安全集成。

IBM Sterling B2B Integrator 5.2版本中存在信息泄露漏洞。远程攻击者可通过使用HTTP GET请求利用该漏洞获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22004202

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-991

  

**【漏洞名称】****Microsoft Windows Graphics 信息泄露漏洞**

**【漏洞编号】****CNNVD-201706-1019（CVE-2017-8575）**

**【漏洞详情】**Microsoft Windows是美国微软（Microsoft）公司发布的一系列操作系统。Graphics是其中的一个图形组件。

Microsoft Windows中的Graphics存在信息泄露漏洞，该漏洞源于程序没有正确的处理内存中的对象。本地攻击者可借助特制的应用程序利用该漏洞获取敏感信息。以下版本受到影响：Microsoft Windows 10，Windows 10版本1511，Windows 10版本1607，Windows 10版本1703，Windows Server 2016。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-8575

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-1019

  

**【漏洞名称】****Drupal 安全漏洞**

**【漏洞编号】****CNNVD-201706-1004（CVE-2017-6922）**

**【漏洞详情】**Drupal是Drupal社区所维护的一套用PHP语言开发的免费、开源的内容管理系统。

Drupal 7.56之前的7.x版本和8.3.4之前的8.x版本中存在安全漏洞。攻击者可利用该漏洞绕过安全限制，执行未授权的操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.drupal.org/SA-CORE-2017-003

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-1004

  

**【漏洞名称】****Poppler pdftocairo 安全漏洞**

**【漏洞编号】****CNNVD-201706-977（CVE-2017-9776）**

**【漏洞详情】**Poppler是一个用于生成PDF的C++类库，该库是从Xpdf（PDF阅读器）继承而来。pdftocairo是其中的一个文件格式转换器。

Poppler 0.56之前的版本中的pdftocairo的JBIG2Stream.cc文件存在安全漏洞。远程攻击者可借助特制的PDF文档利用该漏洞造成拒绝服务（应用程序崩溃）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://github.com/danigm/poppler

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-977
