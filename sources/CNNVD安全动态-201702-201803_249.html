今日CNNVD共发布安全漏洞27个，更新安全漏洞19个。主要影响厂商为美国Google（15个）、美国Mozilla（5个）、美国Oracle（2个），主要影响产品为Qualcomm组件（15个）、Firefox浏览器（5个）、Oracle Sun Systems Products Suite产品套件（2个）。


今日需关注的典型漏洞如下:

【漏洞名称】Android Qualcomm组件安全漏洞

【漏洞编号】CNNVD-201706-907（CVE-2014-9955）

【漏洞详情】Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Qualcomm是使用在其中的一个美国高通（Qualcomm）公司的设备专用的高通组件。

Android中的Qualcomm组件存在安全漏洞。攻击者可利用该漏洞执行未授权的操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://source.android.com/security/bulletin/2017-06-01

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-907

【漏洞名称】Mozilla Firefox for Android 安全漏洞

【漏洞编号】CNNVD-201706-857（CVE-2017-7770）

【漏洞详情】Mozilla Firefox for Android是美国Mozilla基金会的一款基于Android平台的开源Web浏览器。

基于Android平台的Mozilla Firefox 54之前的版本中存在安全漏洞。攻击者可利用该漏洞伪造地址栏内容。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.mozilla.org/en-US/security/advisories/mfsa2017-15/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-857


【漏洞名称】Oracle Sun Systems Products Suite Solaris 权限许可和访问控制漏洞

【漏洞编号】CNNVD-201706-888（CVE-2017-3631）

【漏洞详情】Oracle Sun Systems Products Suite是美国甲骨文（Oracle）公司的一款Sun系统产品套件。Solaris是其中的一个类Unix操作系统。

Oracle Sun Systems Products Suite中的Solaris组件11版本的Kernel子组件存在本地提权漏洞。攻击者可利用该漏洞未授权读取、更新、插入或删除数据，造成拒绝服务，影响数据的保密性、完整性和可用性。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.oracle.com/technetwork/security-advisory/alert-cve-2017-3629-3757403.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-888


【漏洞名称】Symantec Web Gateway 跨站脚本漏洞

【漏洞编号】CNNVD-201706-881（CVE-2016-9096）

【漏洞详情】Symantec Web Gateway（SWG）是美国赛门铁克（Symantec）公司的一套网络内容过滤软件。该软件提供网络内容过滤、数据泄露防护等功能。

SWG 5.2.7之前的版本中存在跨站脚本漏洞，该漏洞源于程序没有正确的过滤用户提交的输入。远程攻击者可利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.symantec.com/security_response/securityupdates/detail.jsp?fid=security_advisory&pvid=security_advisory&year=&suid=20170313_00

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-881


【漏洞名称】多款I-O DATA Network Camera产品跨站请求伪造漏洞

【漏洞编号】CNNVD-201706-885（CVE-2017-2223）

【漏洞详情】I-O DATA TS-WPTCAM等都是日本I-O DATA DEVICE公司的网络摄像机。

使用1.19及之前版本固件的多款I-O DATA Network Camera产品存在跨站请求伪造漏洞。远程攻击者可利用该漏洞执行未授权的操作。以下产品受到影响：I-O DATA TS-WPTCAM；TS-WPTCAM2；TS-PTCAM；TS-PTCAM/POE；TS-WLC2；TS-WLCE；TS-WRLC。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.iodata.jp/support/information/2017/camera201706/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-885
