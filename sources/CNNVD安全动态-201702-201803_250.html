今日CNNVD共发布安全漏洞34个，更新安全漏洞4个。主要影响厂商为美国Linux（4个）、美国Apache（3个）、美国Fortinet（2个），主要影响产品为Linux kernel内核（4个）、Apache httpd服务器（3个）、Fortinet FortiOS操作系统（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】Linux kernel 安全漏洞

【漏洞编号】CNNVD-201706-805（CVE-2017-1000371）

【漏洞详情】Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。

Linux kernel 4.11.5版本中的offset2lib补丁存在安全漏洞。攻击者可利用该漏洞绕过栈防护页面，执行未授权操作。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.kernel.org/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-805

【相关通报链接】

CNNVD关于Linux内核本地权限提升漏洞情况的通报


【漏洞名称】Apache httpd 安全漏洞

【漏洞编号】CNNVD-201706-787（CVE-2017-7668）

【漏洞详情】Apache httpd是美国阿帕奇（Apache）软件基金会的一款专为现代操作系统开发和维护的开源HTTP服务器。

Apache httpd 2.2.32版本和2.4.24版本中的HTTP strict parsing changes added存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（段错误）。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://lists.apache.org/thread.html/55a068b6a5eec0b3198ae7d96a7cb412352d0ffa7716612c5af3745b@%3Cdev.httpd.apache.org%3E

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-787


【漏洞名称】Fortinet FortiOS 跨站脚本漏洞

【漏洞编号】CNNVD-201706-818（CVE-2017-7734）

【漏洞详情】Fortinet FortiOS是美国飞塔（Fortinet）公司开发的一套专用于FortiGate网络安全平台上的安全操作系统。该系统为用户提供防火墙、防病毒、IPSec/SSL VPN、Web内容过滤和反垃圾邮件等多种安全功能。

Fortinet FortiOS中存在跨站脚本漏洞。远程攻击者可利用该漏洞执行任意的脚本代码，窃取基于cookie的身份验证证书。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://fortiguard.com/psirt/FG-IR-17-127

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-818


【漏洞名称】GNU Binutils Binary File Descriptor库安全漏洞

【漏洞编号】CNNVD-201706-760（CVE-2017-9748）

【漏洞详情】GNU Binutils（又名GNU Binary Utilities或binutils）是GNU计划开发的一组编程语言工具程序，它主要用于处理多种格式的目标文件，并提供有连接器、汇编器和其他用于目标文件和档案的工具。Binary File Descriptor（BFD）library（又名libbfd）是其中的一个以各种格式便携式操作对象文件的库。

GNU Binutils 2.28版本中的BFD库的bfd/ieee.c文件的‘ieee_object_p’函数存在安全漏洞。远程攻击者可借助特制的二进制文件利用该漏洞造成拒绝服务（缓冲区溢出和应用程序崩溃）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.gnu.org/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-760


【漏洞名称】Lenovo XClarity Administrator 信息泄露漏洞

【漏洞编号】CNNVD-201706-790（CVE-2017-3745）

【漏洞详情】Lenovo XClarity Administrator（LXCA）是中国联想（Lenovo）公司的一套集中式的资源管理解决方案。该方案支持简化基础结构管理、加快服务器响应和提高Lenovo服务器系统性能等。

LXCA 1.3.0之前的版本中存在安全漏洞。本地攻击者可利用该漏洞访问用户密码的信息。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://support.lenovo.com/us/zh/product_security/len-13671

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201706-790
