# CNNVD最新漏洞（2017-06-19）

今日CNNVD共发布安全漏洞35个，更新安全漏洞8个。主要影响厂商为美国Adobe（19个）、美国Google（4个）、波兰Telaxus（4个），主要影响产品为Adobe多媒体播放器（9个）、Android操作系统（4个）、Telaxus EPESI管理系统（4个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Adobe Flash Player 安全漏洞**  

**【漏洞编号】****CNNVD-201706-683（CVE-2017-3076）**

**【漏洞详情】**Adobe Flash Player是美国奥多比（Adobe）公司的一款跨平台、基于浏览器的多媒体播放器产品。该产品支持跨屏幕和浏览器查看应用程序、内容和视频。

Adobe Flash Player中存在内存损坏漏洞。远程攻击者可利用该漏洞执行代码。以下版本受到影响：基于Windows、Macintosh和Linux平台的Adobe Flash Player for Desktop Runtime 25.0.0.171及之前的版本，基于Windows、Macintosh、Chrome OS和Linux平台Adobe Flash Player for Google Chrome 25.0.0.171及之前的版本，基于Windows 10和8.1平台的Adobe Flash Player for Microsoft Edge和Internet Explorer 11 25.0.0.171及之前的版本。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://helpx.adobe.com/security/products/flash-player/apsb17-17.html

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017060683

**【漏洞名称】****Android 安全漏洞**

**【漏洞编号】****CNNVD-201706-612（CVE-2016-10341）**

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。

Android中存在安全漏洞。攻击者可利用该漏洞执行未授权的操作。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://source.android.com/security/bulletin/2017-06-01

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017060612

  

**【漏洞名称】****Telaxus EPESI 跨站脚本漏洞**

**【漏洞编号】****CNNVD-201706-594（CVE-2017-9624）**

**【漏洞详情】**Telaxus EPESI是波兰Telaxus公司的一套基于PHP/Ajax框架的开源客户关系管理系统（CRM）。该系统提供日程管理、多用户地址簿、代办事宜等功能。

Telaxus EPESI 1.8.2及之前的版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的Web脚本或HTML。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://github.com/Telaxus/EPESI/commit/48fb5e81cd7a47d98bade092a5a72d8177621dbd

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017060594

  

**【漏洞名称】****Apache Ranger 跨站脚本漏洞**

**【漏洞编号】****CNNVD-201706-603（CVE-2016-8751）**

**【漏洞详情】**Apache Ranger是美国阿帕奇（Apache）软件基金会的一套为Hadoop集群实现全面安全措施的架构，它针对授权、结算和数据保护等核心企业安全要求，提供中央安全政策管理。

Apache Ranger 0.6.3之前的版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞执行任意JavaScript代码。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://cwiki.apache.org/confluence/display/RANGER/Vulnerabilities+found+in+Ranger

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017060603

  

**【漏洞名称】****IBM API Connect 信息泄露漏洞**

**【漏洞编号】****CNNVD-201706-678（CVE-2017-1379）**

**【漏洞详情】**IBM API Connect（又名APIConnect）是美国IBM公司的一套用于管理API生命周期的集成解决方案。该方案支持创建、运行、管理和保护API和微服务等。

IBM API Connect 5.0.0.0版本至5.0.7.1版本中存在信息泄露漏洞，该漏洞源于程序没有正确的处理发送到Developer Portal的请求。远程攻击者可利用该漏洞获取敏感信息。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22004714

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017060678
