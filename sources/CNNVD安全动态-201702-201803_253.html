根据国家信息安全漏洞库（CNNVD）统计，本周（2017年6月12日至2017年6月18日）安全漏洞情况如下：

本期导读

公开漏洞情况

本周CNNVD发布安全漏洞226个，与上周（208个）漏洞数量相比有所增加。

本周需要重点关注的是Microsoft Windows Search权限许可和访问控制漏洞（CNNVD-201706-556）和Microsoft LNK输入验证漏洞（CNNVD-201706-561）。攻击者成功利用上述漏洞可以获得与本地用户相同的用户权限，甚至能够控制受影响的系统。以下系统受到影响，建议用户及时下载补丁修复漏洞：

桌面系统：Windows 10, Windows 7 SP1，Windows 8.1, Windows RT 8.1 以及微软已经停止支持的Windows 8, Windows Vista 和 Windows Xp 

服务器系统：Windows Server 2016，2012，2008以及微软已经停止支持的Windows Server 2003。

接报漏洞情况

本周接报漏洞261个，其中信息技术产品漏洞（通用型漏洞）16个，网络信息系统漏洞（事件型漏洞）245个。


公开漏洞情况

根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞226个，与上周相比有所增加。从厂商分布来看，本周Microsoft公司新增漏洞最多，共有97个；从漏洞类型来看，信息泄露类的安全漏洞占比最大，达到20.80%。本周新增漏洞中，高危漏洞1个，中危漏洞112个，低危漏洞113个，无超危漏洞。相应修复率分别为100.00%、58.41%以及87.61%。根据统计，合计166个漏洞已有修复补丁发布，整体修复率为73.13%。

截至2017年6月18日，CNNVD发布漏洞总量已达94181个。

1.Microsoft Windows Search权限许可和访问控制漏洞(CNNVD-201706-556)

Microsoft Windows是美国微软（Microsoft）公司发布的一系列操作系统。Windows Search是一款硬盘搜索引擎。

Microsoft Windows中的Windows Search存在远程代码执行漏洞。远程攻击者可通过向Windows Search服务发送特制的SMB信息利用该漏洞提升权限，控制计算机。以下版本受到影响：

-Windows 10

-Windows 10版本 1511、1607和1703

-Windows 7 SP1

-Windows 8.1

-Windows RT 8.1

-Windows Server 2008 SP2

-Windows Server 2008 R2 SP1

-Windows Server 2012

-Windows Server 2012 R2

-Windows Server 2016

-Windows XP

-Windows Server 2003

-Windows Vista

-Windows 8

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-8543

2.Microsoft LNK输入验证漏洞(CNNVD-201706-561)

Microsoft Windows是美国微软（Microsoft）公司发布的一系列操作系统。

Microsoft Windows中存在远程代码执行漏洞。远程攻击者可借助特制的.LNK文件利用该漏洞执行任意代码。以下版本受到影响：

-Windows 10

-Windows 10版本 1511、1607和1703

-Windows 7 SP1

-Windows 8.1

-Windows RT 8.1

-Windows Server 2008 SP2

-Windows Server 2008 R2 SP1

-Windows Server 2012

-Windows Server 2012 R2

-Windows Server 2016

-Windows Vista

-Windows 8

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-8464
