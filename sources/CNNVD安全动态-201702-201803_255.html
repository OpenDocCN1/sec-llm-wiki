CNNVD关于微软多个重要漏洞的通报

2017年6月14日，微软（Microsoft）官方发布了涉及Windows操作系统、Edge浏览器、Office办公软件等产品共102个漏洞的安全更新（Security Updates）。同时，鉴于WannaCry勒索软件攻击事件中，大量微软停服的系统遭到攻击，微软此次专门针对已经停止支持的Windows XP、Windows Server 2003等操作系统发布了安全公告（Security Advisory）。此次发布的安全更新和安全公告中存在大量超危漏洞，且对已经停服的系统不会自动推送补丁，需要在微软下载中心进行下载。国家信息安全漏洞库（CNNVD）对此进行了跟踪分析，情况如下：

1、微软6月14日安全更新情况

微软本次发布的安全更新，主要针对仍在提供支持的Windows 10、Windows Server 2016、Office 2016等微软公司的产品，以及基于Windows系统的Adobe Flash Player。微软本次共发布了102个漏洞，其中9个超危漏洞涉及Adobe Flash Player。

微软安全更新链接如下，请受影响用户及时更新补丁修复漏洞：

https://portal.msrc.microsoft.com/en-us/security-guidance

2、微软6月14日安全公告情况

微软本次发布的安全公告，主要针对已经停止支持的Windows XP、Windows Server 2003、Windows Vista和Windows 8操作系统，提供了针对重要历史漏洞和最新漏洞的安全公告和修复补丁。

2008年10月至2017年3月相关安全公告共6个：

2017年3月至今相关安全漏洞共计22个：

上述安全公告中涉及的补丁不会自动推送，请用户参考如下安全公告，及时检查是否受到漏洞影响，下载补丁修复漏洞：

https://support.microsoft.com/en-us/help/4025687/microsoft-security-advisory-4025685-guidance-for-older-platforms?from=groupmessage


CNNVD将继续跟踪上述漏洞的相关情况，及时发布相关信息。如有需要，可与CNNVD联系。

联系方式: cnnvd@itsec.gov.cn
