根据国家信息安全漏洞库（CNNVD）统计，本周（2017年6月5日至2017年6月11日）安全漏洞情况如下：

本期导读

公开漏洞情况

本周CNNVD采集安全漏洞208个，是上周（101个）漏洞数量的两倍多。

本周国内厂商发布漏洞数量共计10个，其中联想公司发布6个，华为公司3个，摩莎公司1个。上述漏洞中，摩莎公司无线交换机Moxa AWK-3131A Wireless Access Point的超危漏洞尚未修复，请受影响用户关注厂商主页，获取最新的解决办法。

接报漏洞情况

本周接报漏洞615个，其中信息技术产品漏洞（通用型漏洞）4个，网络信息系统漏洞（事件型漏洞）611个。


公开漏洞情况

根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞208个，与上周相比有所增加。从厂商分布来看，本周Google公司新增漏洞最多，共有35个；从漏洞类型来看，缓冲区错误类的安全漏洞占比最大，达到9.62%。本周新增漏洞中，超危漏洞12个，高危漏洞27个，中危漏洞160个，低危漏洞9个。相应修复率分别为83.33%、44.44%、76.88%以及55.56%。根据统计，合计150个漏洞已有修复补丁发布，整体修复率为72.12%。

截至2017年6月11日，CNNVD发布漏洞总量已达93937个。

1. NovaBACKUP DataCenter Linux datamover模块输入验证漏洞(CNNVD-201704-738)

Linux version of NovaBACKUP DataCenter是德国NovaStor公司开发的一套用于Linux系统的数据备份解决方案。datamover module是其中的一个数据传输模块。

Linux version of NovaBACKUP DataCenter 09.06.03.0353之前的版本中datamover模块存在安全漏洞。远程攻击者可利用该漏洞执行命令。

解决措施：目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.novastor.com/

2. Adobe Acrobat和Reader 缓冲区错误漏洞(CNNVD-201704-653)

Adobe Acrobat和Reader都是美国奥多比（Adobe）公司的产品。前者是一套PDF文件编辑和转换工具，后者是一套PDF文档阅读软件。

Adobe Acrobat和Reader中的JavaScript引擎存在内存损坏漏洞。攻击者可利用该漏洞执行任意代码。基于Windows和Macintosh平台的以下产品和版本受到影响：

- Adobe Acrobat DC和Acrobat Reader DC Continuous 15.023.20070及之前的版本

- Acrobat DC和Acrobat Reader DC 15.006.30280及之前的版本

- Acrobat和Reader Desktop 11.0.19及之前的版本

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://helpx.adobe.com/security/products/acrobat/apsb17-11.html

3. Dolibarr ERP/CRM SQL注入漏洞(CNNVD-201706-139)

Dolibarr ERP/CRM是法国Dolibarr基金会的一套基于Web的企业资源计划（ERP）和客户关系管理（CRM）系统。该系统可用来管理产品、库存、发票、订单等。

Dolibarr ERP/CRM 5.0.3之前的版本中的user/index.php文件存在SQL注入漏洞。远程攻击者可利用该漏洞执行任意SQL命令。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/Dolibarr/dolibarr/commit/70636cc59ffa1ffbc0ce3dba315d7d9b837aad04

4. Microsoft Scripting引擎权限许可和访问控制漏洞(CNNVD-201704-717)

Microsoft Windows是美国微软（Microsoft）公司的一系列操作系统。VBScript engines是其中的一个VB脚本语言引擎。

Microsoft Windows中的VBScript引擎存在远程代码执行漏洞。远程攻击者可借助特制的Web站点利用该漏洞执行任意代码。以下版本受到影响：

- Microsoft Windows 10

- Microsoft Windows 10 1511

- Microsoft Windows 8.1

- Microsoft Windows RT 8.1

- Microsoft Windows Server 2012 R2

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-0158
