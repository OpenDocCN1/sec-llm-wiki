今日CNNVD共发布安全漏洞61个，更新安全漏洞32个。主要影响厂商为美国Google（11个）、美国Adobe（8个）、美国Oracle（4个），主要影响产品为Android操作系统（11个）、Adobe Acrobat PDF文件编辑和转换工具（8个）、Oracle Support Tools支持工具（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Android System UI 安全漏洞**  

**【漏洞编号】****CNNVD-201706-204（CVE-2017-0638）**

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。System UI是Android自带的系统界面。

Android 7.1.1版本和7.1.2版本中的System UI存在远程代码执行漏洞。远程攻击者可借助特制的文件利用该漏洞执行任意代码。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://source.android.com/security/bulletin/2017-06-01

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017060204

**【漏洞名称】****Adobe Acrobat和Reader 安全漏洞**

**【漏洞编号】****CNNVD-201704-643（CVE-2017-3047）**

**【漏洞详情】**Adobe Acrobat和Reader都是美国奥多比（Adobe）公司的产品。前者是一套PDF文件编辑和转换工具，后者是一套PDF文档阅读软件。

Adobe Acrobat和Reader中的JavaScript引擎的annotation-related API存在释放后重用漏洞。攻击者可利用该漏洞执行任意代码。基于Windows和Macintosh平台的以下产品和版本受到影响：Adobe Acrobat DC和Acrobat Reader DC Continuous 15.023.20070及之前的版本；Acrobat DC和Acrobat Reader DC 15.006.30280及之前的版本；Acrobat和Reader Desktop 11.0.19及之前的版本。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://helpx.adobe.com/security/products/acrobat/apsb17-11.html

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017040643

  

**【漏洞名称】****Oracle Automatic Service Request 安全漏洞**

**【漏洞编号】****CNNVD-201704-1180（CVE-2017-3620）**

**【漏洞详情】**Oracle Support Tools是美国甲骨文（Oracle）公司的一套Oracle支持工具。Automatic Service Request (ASR)是其中的一个为特定硬件故障提供案例生成的组件。ASR Manager是其中的一个能够接受资产发送的故障数据的子组件。

Oracle Support Tools中的ASR组件5.7之前的版本的ASR Manager子组件存在安全漏洞。攻击者可利用该漏洞控制组件，影响数据的可用性、完整性和保密性。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://www.oracle.com/technetwork/security-advisory/cpuapr2017-3236618.html

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017041180

  

**【漏洞名称】****Microsoft Outlook for Mac 安全漏洞**

**【漏洞编号】****CNNVD-201704-685（CVE-2017-0207）**

**【漏洞详情】**Microsoft Outlook for Mac是美国微软（Microsoft）公司的一款基于Mac平台的Office套件中所捆绑的电子邮件客户端软件。该软件可管理电子邮件、联系人和日历等。

Microsoft Outlook for Mac 2011版本中存在安全漏洞。远程攻击者可借助带有特定的HTML标签的特制email利用该漏洞伪造Web内容。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-0207

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017040685

  

**【漏洞名称】****Cisco FindIT Network Probe Software 信息泄露漏洞**

**【漏洞编号】****CNNVD-201704-1058（CVE-2017-6614）**

**【漏洞详情】**Cisco FindIT Network Probe Software是美国思科（Cisco）公司的一款FindIT网络管理器，用来监控和管理由Cisco 100至500系列产品构成的网络。

Cisco FindIT Network Probe Software中的Web用户界面的文件下载功能存在信息泄露漏洞，该漏洞源于程序没有对文件下载请求执行基于role的访问控制（RBAC）。远程攻击者可通过向受影响的软件发送特制的HTTP请求利用该漏洞下载和浏览任意系统文件。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://bst.cloudapps.cisco.com/bugsearch/bug/CSCvd11628

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017041058
