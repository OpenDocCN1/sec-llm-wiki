CNNVD最新漏洞（2017-06-07）

今日CNNVD共发布安全漏洞16个，更新安全漏洞14个。主要影响厂商为美国IBM（4个）、美国ImageMagick Studio（2个）、中国华为（1个），主要影响产品为ImageMagick图象处理软件（2个）、IBM Security Access Manager信息安全管理产品（1个）、华为P9 Plus智能手机（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】IBM Security Access Manager 信息泄露漏洞

【漏洞编号】CNNVD-201706-141（CVE-2016-3019）

【漏洞详情】IBM Security Access Manager是美国IBM公司的一款应用于信息安全管理的产品。该产品通过面向Web、移动和云计算的集成设备来实现访问管理控制。

IBM Security Access Manager 9.0版本中存在信息泄露漏洞，该漏洞源于程序使用较弱的加密算法。攻击者可利用该漏洞解密敏感信息。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg21988419

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017060141

【漏洞名称】ImageMagick 安全漏洞

【漏洞编号】CNNVD-201706-133（CVE-2017-9440）

【漏洞详情】ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.5-5版本中的coders/psd.c文件的‘ReadPSDChannel’函数存在内存泄露漏洞。攻击者可借助特制的文件利用该漏洞造成拒绝服务。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/issues/462

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017060133


【漏洞名称】华为P9 Plus 安全漏洞

【漏洞编号】CNNVD-201706-155（CVE-2017-8140）

【漏洞详情】华为P9 Plus是中国华为（Huawei）公司的一款智能手机产品。

华为P9 Plus VIE-AL10BC00B353之前的版本中的语音唤醒模块驱动程序存在双重释放漏洞。攻击者可通过诱使用户安装恶意手机应用利用该漏洞触发内存重复释放，导致系统重启或执行任意代码。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20170605-01-smartphone-cn

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017060155


【漏洞名称】SoftBank PrimeDrive Desktop Application 安全漏洞

【漏洞编号】CNNVD-201703-084（CVE-2017-2108）

【漏洞详情】SoftBank PrimeDrive Desktop Application是日本SoftBank的一套为PrimeDrive提供在线存储服务的客户端应用程序。

SoftBank PrimeDrive Desktop Application 1.4.3及之前的版本中存在不可信路径搜索漏洞。远程攻击者可利用该漏洞获取特权。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://www.softbank.jp/biz/news/cloud/170215/

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017030084


【漏洞名称】Dolibarr ERP/CRM SQL注入漏洞

【漏洞编号】CNNVD-201706-139（CVE-2017-9435）

【漏洞详情】Dolibarr ERP/CRM是法国Dolibarr基金会的一套基于Web的企业资源计划（ERP）和客户关系管理（CRM）系统。该系统可用来管理产品、库存、发票、订单等。

Dolibarr ERP/CRM 5.0.3之前的版本中的user/index.php文件存在SQL注入漏洞。远程攻击者可利用该漏洞执行任意SQL命令。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://github.com/Dolibarr/dolibarr/commit/70636cc59ffa1ffbc0ce3dba315d7d9b837aad04

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017060139
