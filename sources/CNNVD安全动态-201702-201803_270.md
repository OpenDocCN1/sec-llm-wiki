# CNNVD最新漏洞（2017-06-02）

今日CNNVD共发布安全漏洞36个，更新安全漏洞1个。主要影响厂商为美国HPE（6个）、中国华为（5个）、中国摩莎（3个），主要影响产品为HPE Aruba ClearPass Policy Manager解决方案（6个）、FusionSphere云操作系统（5个）、OnCell G3110-HSPA IP网关（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****HPE Aruba ClearPass Policy Manager 安全漏洞**

**【漏洞编号】****CNNVD-201705-1414（CVE-2017-5829）**

**【漏洞详情】**HPE Aruba ClearPass Policy Manager是美国惠普企业（Hewlett Packard Enterprise，HPE）公司的一个网络访问控制解决方案。

HPE Aruba ClearPass Policy Manager 6.6.5之前的版本中存在安全漏洞。攻击者可利用该漏洞绕过安全限制。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://www.arubanetworks.com/zh-hant/products/security/policy-management/

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017051414

**【漏洞名称】****华为FusionSphere和FusionSphere OpenStack 命令注入漏洞**

**【漏洞编号】****CNNVD-201706-010（CVE-2017-8135）**

**【漏洞详情】**华为FusionSphere和FusionSphere OpenStack（FSO）都是中国华为（Huawei）公司的产品，前者是基于OpenStack框架开发的云操作系统产品，后者是FusionSphere在ICT场景中的云平台软件。

华为FusionSphere和FSO中存在命令注入漏洞，该漏洞源于TCP监听端没有充分的校验输入的参数。攻击者可通过发送带有恶意命令的消息利用该漏洞获取root权限。以下产品和版本受到影响：FusionSphere V100R006C00版本，V100R006C10版本；FusionSphere OpenStack V100R006C00版本，V100R006C10版本。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20170531-01-openstack-cn

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017060010

  

**【漏洞名称】****多款摩莎产品跨站请求伪造漏洞**

**【漏洞编号】****CNNVD-201705-1239（CVE-2017-7917）**

**【漏洞详情】**摩莎OnCell G3110-HSPA等都是中国摩莎（Moxa）公司的产品，其中OnCell G3110-HSPA是一款工业级的IP网关，OnCell 5104-HSPA是一款工业级蜂窝路由器。

多款摩莎产品中存在跨站请求伪造漏洞，该漏洞源于程序没有充分的验证请求。远程攻击者可利用该漏洞修改设备的配置。以下产品和版本受到影响：摩莎OnCell G3110-HSPA 1.3 build 15082117及之前的版本；OnCell G3110-HSDPA 1.2 Build 09123015及之前的版本；OnCell G3150-HSDPA 1.4 Build 11051315及之前的版本；OnCell 5104-HSDPA；OnCell 5104-HSPA；OnCell 5004-HSPA。

目前厂商已发布了Moxa OnCell G31x0-HSPA和OnCell 5x04-HSPA的修复措施；Moxa OnCell G31x0-HSDPA和OnCell 5x04-HSDPA已停止更新，详情请关注厂商主页：

http://www.moxa.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017051239

  

**【漏洞名称】****Sudo 权限许可和访问控制漏洞**

**【漏洞编号】****CNNVD-201705-1405（CVE-2017-1000367）**

**【漏洞详情】**Sudo是软件开发者Todd C. Miller所研发的一套用于类Unix操作系统下并允许用户通过安全的方式使用特殊的权限执行命令的程序。

Sudo 1.8.6p7至1.8.20版本中存在提权漏洞。本地攻击者可利用该漏洞以root权限执行任意命令。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://www.sudo.ws/alerts/linux\_tty.html

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017051405

  

**【漏洞名称】****Red Hat CloudForms 安全漏洞**

**【漏洞编号】****CNNVD-201706-005（CVE-2017-2639）**

**【漏洞详情】**Red Hat CloudForms是美国红帽（Red Hat）公司的一套IaaS（基础设施即服务）云服务解决方案。该方案可创建、管理私有和公共云，并具备对应用程序生命周期的管理能力。

Red Hat CloudForms中存在安全漏洞，该漏洞源于程序没有验证服务器主机名称是否与证书中的域名匹配。攻击者可利用该漏洞欺骗Red Hat Virtualization (RHEV)或OpenShiftThe系统。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://access.redhat.com/errata/RHSA-2017:1367

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017060005
