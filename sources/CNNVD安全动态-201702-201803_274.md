今日CNNVD共发布安全漏洞18个，更新安全漏洞13个。主要影响厂商为美国Microsoft（8个）、美国Artifex Software（2个）、美国Fortinet（2个），主要影响产品为Windows操作系统（8个）、Artifex Software MuPDF PDF阅读器（2个）、Fortinet FortiPortal（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Microsoft Malware Protection引擎安全漏洞**

**【漏洞编号】****CNNVD-201705-1316（CVE-2017-8535）**

**【漏洞详情】**Microsoft Windows是美国微软（Microsoft）公司发布的一系列操作系统，Microsoft Forefront是应用在其中的一套面向企业的服务器安全特性解决方案。Microsoft Defender是一款应用在其中的杀毒软件。

多款Microsoft Windows中的Microsoft Forefront和Microsoft Forefront存在拒绝服务漏洞，该漏洞源于程序没有正确的扫描特制的文件。远程攻击者可借助特制的文件利用该漏洞造成拒绝服务。以下产品和版本受到影响：Microsoft Windows Server 2008 SP2和R2 SP1；Windows 7 SP1；Windows 8.1；Windows Server 2012 Gold和R2；Windows RT 8.1；Windows 10版本，10版本1511、1607和1703；Windows Server 2016；Microsoft Exchange Server 2013和2016。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-8535

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017051316

**【漏洞名称】****Artifex Software MuPDF 缓冲区错误漏洞**

**【漏洞编号】****CNNVD-201705-1325（CVE-2016-8728）**

**【漏洞详情】**Artifex Software MuPDF是美国Artifex Software公司的一款免费的、轻量级的PDF阅读器。

Artifex Software MuPDF 1.10-rc1版本中存在基于堆的缓冲区溢出漏洞，该漏洞源于程序没有充分的对用户提交的输入执行边界检测。攻击者可利用该漏洞在应用程序上下文中执行任意代码或造成拒绝服务。

目前厂商还没有提供此漏洞的相关补丁或者升级程序，建议使用此软件的用户随时关注厂商的主页以获取最新版本：

https://www.mupdf.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017051325

  

**【漏洞名称】****Fortinet FortiPortal 安全漏洞**

**【漏洞编号】****CNNVD-201705-1322（CVE-2017-7731）**

**【漏洞详情】**Fortinet FortiPortal是美国飞塔（Fortinet）公司开发的一款帮助Managed Scurity Service Provider(MSSP)操作基于云的安全管理和日志保留服务的产品。

Fortinet FortiPortal 4.0.0及之前的版本中存在安全漏洞。攻击者可借助Forgotten Password功能利用该漏洞获取敏感信息。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://fortiguard.com/psirt/FG-IR-17-114

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017051322

  

**【漏洞名称】****Linux kernel 安全漏洞**

**【漏洞编号】****CNNVD-201705-1321（CVE-2017-9242）**

**【漏洞详情】**Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。

Linux kernel 4.11.3及之前的版本中的net/ipv6/ip6\_output.c文件的‘\_\_ip6\_append\_data’函数存在安全漏洞，该漏洞源于程序没有及时的检测skb数据是否被覆盖。本地攻击者可借助特制的系统调用利用该漏洞造成拒绝服务。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=232cd35d0804cc241eb887bb8d4d9b3b9881c64a

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017051321

**【漏洞名称】****Apache Knox 安全漏洞**

**【漏洞编号】****CNNVD-201705-1308（CVE-2017-5646）**

**【漏洞详情】**Apache Knox是美国阿帕奇（Apache）软件基金会的一款用于Apache Hadoop部署的REST API和UI进行交互的应用程序网关。

Apache Knox 0.2.0版本至0.11.0版本中存在安全漏洞。攻击者可借助特制的URL利用该漏洞冒充其他用户，获取提升的权限，未授权访问数据。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://mail-archives.apache.org/mod\_mbox/knox-user/201705.mbox/%3CCACRbFyjtT7QQGHUzTRdbJoySbJb7tt4BDk5-r-VRn0GB0Kgvag%40mail.gmail.com%3E

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017051308
