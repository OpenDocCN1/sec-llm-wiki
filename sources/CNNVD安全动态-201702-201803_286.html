今日CNNVD共发布安全漏洞61个，更新安全漏洞7个。主要影响厂商为美国Cisco（19个）、美国Mimosa Networks（6个）、美国Industrial Light and Magic（LIM）（6个），主要影响产品为Cisco Remote Expert Manager Software远程管理软件（7个）、Mimosa Client Radios管理程序（6个）、LIM OpenEXR图像文件格式（6个）。

今日需关注的典型漏洞如下:

【漏洞名称】Cisco Remote Expert Manager Software 信息泄露漏

【漏洞编号】CNNVD-201705-906（CVE-2017-6642）

【漏洞详情】Cisco Remote Expert Manager Software是美国思科（Cisco）公司的的一款远程管理软件。该软件远程屏幕共享、屏幕注释和会话记录等协作功能。

Cisco Remote Expert Manager Software 11.0.0版本中的Web界面存在信息泄露漏洞，该漏洞源于程序没有充分的保护敏感信息。远程攻击者可通过向受影响系统上的软件的Web界面发送特制的HTTP请求利用该漏洞访问受影响系统上的敏感信息。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.cisco.com/

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017050906

【漏洞名称】Mimosa Client Radios和Mimosa Backhaul Radios 安全漏洞

【漏洞编号】CNNVD-201705-923（CVE-2017-9131）

【漏洞详情】Mimosa Client Radios和Mimosa Backhaul Radios都是美国Mimosa Networks公司的产品。Mimosa Client Radios是一个Mimosa多点解决方案的客户端设备的管理程序。Mimosa Backhaul Radios是一个宽带回程设备的管理程序。

Mimosa Client Radios 2.2.3之前的版本和Mimosa Backhaul Radios 2.2.3之前的版本中存在安全漏洞。远程攻击者可利用该漏洞执行命令，实施拒绝服务攻击。

目前厂商已经发布了升级补丁以修复此安全问题，详情请关注厂商主页：

http://www.mimosa.co/

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017050923


【漏洞名称】LIM OpenEXR 安全漏洞

【漏洞编号】CNNVD-201705-932（CVE-2017-9110）

【漏洞详情】LIM OpenEXR是美国Industrial Light and Magic（LIM）公司开发的一种图像文件格式，适用于高动态范围（HDR）图像。

LIM OpenEXR 2.2.0版本中的ImfHuf.cpp文件的‘hufDecode’函数存在安全漏洞。攻击者可利用该漏洞造成应用程序崩溃。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://github.com/openexr/openexr

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017050932


【漏洞名称】Linux kernel 安全漏洞

【漏洞编号】CNNVD-201705-953（CVE-2017-9074）

【漏洞详情】Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。

Linux kernel 4.11.1及之前的版本中的IPv6分片实现过程存在安全漏洞，该漏洞源于程序没有确定nexthdr字段是否与无效的选项有关。本地攻击者可通过制造套接字并发送系统调用利用该漏洞造成拒绝服务（越边界读取）。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=2423496af35d94a87156b063ea5cedffc10a70a1

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017050953

【漏洞名称】Apple iOS Security 安全漏洞

【漏洞编号】CNNVD-201705-781（CVE-2017-2498）

【漏洞详情】Apple iOS是美国苹果（Apple）公司为移动设备所开发的一套操作系统。Security是其中的一个信息安全和隐私保护的组件。

Apple iOS 10.3.2之前的版本中Security组件存在安全漏洞。攻击者可利用该漏洞绕过目标系统的证书验证。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://support.apple.com/HT207798

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017050781
