今日CNNVD共发布安全漏洞87个，更新安全漏洞7个。主要影响厂商为美国Google（6个）、美国Intel（6个）、美国Microsoft（4个），主要影响产品为Android开源操作系统（6个）、McAfee Network Data Loss Prevention（NDLP）网络数据丢失防护软件（6个）、Microsoft ASP.NET Core跨平台开源框架（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Android MediaTek touchscreen驱动程序权限许可和访问控制漏洞**

**【漏洞编号】****CNNVD-201705-734（CVE-2016-10274）**

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。MediaTek touchscreen是其中的一个触屏驱动。

Android 7.1.1之前的版本中的MediaTek touchscreen驱动程序存在提权漏洞。攻击者可借助本地恶意的应用程序利用该漏洞在内核上下文中执行任意代码。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://source.android.com/security/bulletin/2017-05-01

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017050734

**【漏洞名称】****McAfee Network Data Loss Prevention 安全漏洞**

**【漏洞编号】****CNNVD-201705-817（CVE-2017-4011）**

**【漏洞详情】**McAfee Network Data Loss Prevention（NDLP）是美国英特尔（Intel）公司（原McAfee公司）的一套网络数据丢失防护软件。该软件能够防止无意或恶意泄露客户数据、员工信息和知识产权信息，以及未授权传输信息。

McAfee NDLP 9.3.x版本中的服务器存在安全漏洞。远程攻击者可通过更改HTTP请求利用该漏获取会话/cookie信息。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://kc.mcafee.com/corporate/index?page=content&id=SB10198

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017050817

  

**【漏洞名称】****Microsoft ASP.NET Core 安全漏洞**

**【漏洞编号】****CNNVD-201705-737（CVE-2017-0247）**

**【漏洞详情】**Microsoft ASP.NET Core是美国微软（Microsoft）公司的一个跨平台开源框架。该框架用于构建Web一应用、物联网应用和移动后端等基于云的应用程序。

Microsoft ASP.NET Core中存在拒绝服务漏洞，该漏洞源于程序没有正确的验证Web请求。攻击者可利用该漏洞造成拒绝服务。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://github.com/aspnet/Announcements/issues/239

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017050737

  

**【漏洞名称】****Apache CXF Fediz 安全漏洞**

**【漏洞编号】****CNNVD-201705-762（CVE-2017-7661）**

**【漏洞详情】**Apache CXF是美国阿帕奇（Apache）软件基金会的一个开源的Web服务框架。该框架支持多种Web服务标准、多种前端编程API等。Apache CXF Fediz是其中的一个子项目，主要用于提供身份验证。

Apache CXF Fediz 1.4.0之前的版本、1.3.2之前的版本和1.2.4之前的版本中的多个插件存在安全漏洞。攻击者可利用该漏洞实施Cross Style Request Forgery攻击。以下插件受到影响：Spring 2，Spring 3，Jetty 8，Jetty 9。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://cxf.apache.org/security-advisories.data/CVE-2017-7661.txt.asc

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017050762

  

**【漏洞名称】****IBM QRadar 安全漏洞**

**【漏洞编号】****CNNVD-201705-688（CVE-2016-9750）**

**【漏洞详情】**IBM QRadar是美国IBM公司的一套利用安全智能保护资产和信息远离高级威胁的解决方案。该方案提供对整个IT架构范围进行监督、生成详细的数据访问和用户活动报告等功能。

IBM QRadar 7.2版本至7.3版本中存在安全漏洞。攻击者可利用该漏洞读取用户证书。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22003137

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017050688
