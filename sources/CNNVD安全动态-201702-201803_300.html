今日CNNVD共发布安全漏洞54个，更新安全漏洞9个。主要影响厂商为美国Microsoft（28个）、美国IBM（7个）、中国ASUS（4个），主要影响产品为Microsoft Windows系列操作系统（17个）、华硕路由器产品 RT-AC*和RT-N*（4个）、IBM Interact市场营销解决方案（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】Microsoft Windows kernel 权限许可和访问控制漏洞

【漏洞编号】CNNVD-201705-524（CVE-2017-0244）

【漏洞详情】Microsoft Windows是美国微软（Microsoft）公司发布的一系列操作系统。Windows kernel是其中的一个内核。

Microsoft Windows中的Windows kernel中存在提权漏洞。本地攻击者可通过本地登录受影响系统或诱使本地用户执行特制的应用程序利用该漏洞在内核模式中以提升的权限执行任意代码。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-0244

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017050524

【相关漏洞链接】

CNNVD关于Microsoft恶意软件防护引擎远程代码执行漏洞情况的通报

【漏洞名称】Microsoft Office 安全漏洞

【漏洞编号】CNNVD-201705-518（CVE-2017-0261）

【漏洞详情】Microsoft Office是美国微软（Microsoft）公司开发的一款办公软件套件产品。常用组件有Word、Excel、Access、Powerpoint、FrontPage等。

Microsoft Office中存在远程代码执行漏洞。远程攻击者可通过构建特制的EPS文件利用该漏洞在受影响的应用程序上下文中执行任意代码或造成拒绝服务。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-0261

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017050518


【漏洞名称】IBM Interact 跨站脚本漏洞

【漏洞编号】CNNVD-201705-562（CVE-2016-5888）

【漏洞详情】IBM Interact是美国IBM公司的一套市场营销解决方案。该解决方案能通过各种数据化特性开展实时互动并利用多个数据源和自主学习来优化消息传递。

IBM Interact中存在跨站脚本漏洞。远程攻击者可利用该漏洞在Web UI中注入任意JavaScript代码。以下版本受到影响：IBM Interact 8.6版本，9.0版本，9.1版本，9.1.1版本，9.1.2版本，10.0版本。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22002147

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017050562


【漏洞名称】ASUS RT-AC*和RT-N*设备跨站请求伪造漏洞

【漏洞编号】CNNVD-201705-572（CVE-2017-5891）

【漏洞详情】ASUS RT-AC*和RT-N*都是华硕（ASUS）公司的无线路由器产品。

使用3.0.0.4.380.7378之前版本固件的ASUS RT-AC*和RT-N*设备存在跨站请求伪造漏洞。远程攻击者可利用该漏洞执行未授权的操作。

目前厂商已经发布了升级补丁以修复此安全问题，详情请关注厂商主页：

http://www.asus.com.cn/

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017050572


【漏洞名称】Linux kernel 安全漏洞

【漏洞编号】CNNVD-201705-553（CVE-2017-8890）

【漏洞详情】Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。

Linux kernel 4.10.15及之前的版本中的net/ipv4/inet_connection_sock.c文件的‘inet_csk_clone_lock’函数存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（双重释放）。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://git.kernel.org/cgit/linux/kernel/git/torvalds/linux.git/commit/?id=657831ffc38e30092a2d5f03d385d710eb88b09a

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017050553
