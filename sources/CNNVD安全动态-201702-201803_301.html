今日CNNVD共发布安全漏洞85个，更新安全漏洞5个。主要影响厂商为美国NVIDIA（15个）、美国Google（10个）、美国Adobe（9个），主要影响产品为NVIDIA Windows GPU Display Driver（9个）、Android（7个）、Adobe Flash Player（7个）。

今日需关注的典型漏洞如下:

【漏洞名称】NVIDIA Windows GPU Display Driver 安全漏洞

【漏洞编号】CNNVD-201705-486（CVE-2017-0341）

【漏洞详情】NVIDIA Windows GPU Display Driver是美国英伟达（NVIDIA）公司的一套专用于Windows的图形处理器(GPU)显卡驱动程序。

NVIDIA Windows GPU Display Driver中的kernel mode layer (nvlddmkm.sys) handler for DxgDdiEscape存在安全漏洞。攻击者可利用该漏洞造成拒绝服务或提升权限。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://nvidia.custhelp.com/app/answers/detail/a_id/4462

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017050486

【漏洞名称】Android kernel UVC驱动程序信息泄露漏洞

【漏洞编号】CNNVD-201705-406（CVE-2017-0627）

【漏洞详情】Android on Nexus 5X等都是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套运行于Nexus 5X（智能手机）中并以Linux为基础的开源操作系统。kernel UVC Driver其中的一个内核USB视频捕获驱动程序。

多款Google设备上的Android中kernel UVC驱动程序存在信息泄露漏洞。攻击者可借助本地恶意的应用程序利用该漏洞未授权访问数据。以下设备受到影响：Nexus 5X；Nexus 6P；Nexus 9；Pixel C；Nexus Player。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://source.android.com/security/bulletin/2017-05-01

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017050406


【漏洞名称】Adobe Flash Player Advanced Video Coding引擎安全漏洞

【漏洞编号】CNNVD-201705-496（CVE-2017-3068）

【漏洞详情】Adobe Flash Player是美国奥多比（Adobe）公司的一款跨平台、基于浏览器的多媒体播放器产品。该产品支持跨屏幕和浏览器查看应用程序、内容和视频。Advanced Video Coding是其中的一个高级视频编码引擎。

Adobe Flash Player中的Advanced Video Coding引擎存在内存损坏漏洞。攻击者可利用该漏洞执行任意代码。以下版本受到影响：Adobe Flash Player 25.0.0.148及之前的版本，基于Macintosh平台的Adobe Flash Player Desktop Runtime 25.0.0.163及之前的版本。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://helpx.adobe.com/security/products/flash-player/apsb17-15.html

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017050496


【漏洞名称】Google gRPC 缓冲区错误漏洞

【漏洞编号】CNNVD-201704-844（CVE-2017-7860）

【漏洞详情】Google gRPC是美国谷歌（Google）公司开发的一个面向移动和HTTP/2设计的开源、通用的RPC框架，具有双向流、流控、头部压缩、单TCP连接上的多复用请求等特点。

Google gRPC 2017-02-22之前的版本中的core/ext/client_channel/parse_address.c文件的‘parse_unix’函数存在基于堆的缓冲区溢出漏洞。攻击者可利用该漏洞造成越边界写入。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://github.com/grpc/grpc/pull/9833

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017040844


【漏洞名称】Symantec Veritas NetBackup和NetBackup Appliance 安全漏洞

【漏洞编号】CNNVD-201705-471（CVE-2017-8856）

【漏洞详情】Symantec Veritas NetBackup（NBU）和NetBackup（NBU）Appliance都是美国赛门铁克（Symantec）公司的产品。前者是一套可以运行于多种操作系统中的企业级备份管理软件，后者是一款企业级备份管理设备。

Symantec Veritas NBU 8.0及之前的版本和NBU Appliance 3.0及之前的版本中存在安全漏洞。远程攻击者可借助bprd进程利用该漏洞执行命令。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://www.veritas.com/content/support/en_US/security/VTS17-004.html#Issue1

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017050471
