# CNNVD最新漏洞（2017-05-05）

今日CNNVD共发布安全漏洞55个，更新安全漏洞8个。主要影响厂商为美国Google（39个）、美国Cisco（4个）、中国Foxit（3个），主要影响产品为Android（27个）、Google Chrome（12）、Foxit Reader（3个）、Cisco Unity Connection（UC）（1个）。

**今日需关注的典型漏洞如下：**

**【漏洞名称】****Android Mediaserver 权限许可和访问控制漏洞**

**【漏洞编号】****CNNVD-201705-138（CVE-2017-0595）**

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Mediaserver是其中的一个多媒体服务组件。

Android中的Mediaserver存在提权漏洞。攻击者可借助本地恶意的应用程序利用该漏洞执行任意代码。以下版本受到影响：Android 4.4.4版本，5.0.2版本，5.1.1版本，6.0版本，6.0.1版本，7.0版本，7.1.1版本。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://source.android.com/security/bulletin/2017-05-01

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017050138

**【漏洞名称】****Android Qualcomm组件安全漏洞**

**【漏洞编号】****CNNVD-201705-139（CVE-2014-9946）**

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Qualcomm是使用在其中的一个美国高通（Qualcomm）公司的设备专用的高通组件。

Android 7.1.1之前的版本中的Qualcomm组件存在安全漏洞。目前尚无此漏洞更详细的信息，请随时关注CNNVD或厂商公告。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://source.android.com/security/bulletin/2017-05-01

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017050139

  

**【漏洞名称】****Google Chrome 安全漏洞**

**【漏洞编号】****CNNVD-201705-160（CVE-2017-5057）**

**【漏洞详情】**Google Chrome是美国谷歌（Google）公司开发的一款Web浏览器。

Google Chrome 58.0.3029.81之前的版本中存在安全漏洞。攻击者可利用该漏洞在浏览器上下文中执行任意代码，绕过安全限制并执行未授权的操作，造成拒绝服务或检索敏感信息。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://chromereleases.googleblog.com/2017/04/stable-channel-update-for-desktop.html

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017050160

  

**【漏洞名称】****Cisco Unity Connection 安全漏洞**

**【漏洞编号】****CNNVD-201705-202（CVE-2017-6629）**

**【漏洞详情】**Cisco Unity Connection（UC）是美国思科（Cisco）公司的一套语音留言平台。该平台可利用语音命令，以“免提”方式拨打电话或者收听留言。

Cisco UC 10.5(2)版本中的‘ImageID’参数存在未授权访问漏洞，该漏洞源于程序没有正确的过滤HTTP POST参数中用户提交的输入。远程攻击者可利用该漏洞访问文件系统中任意位置的文件。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://bst.cloudapps.cisco.com/bugsearch/bug/CSCvd90118

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017050202

  

**【漏洞名称】****Foxit Reader 安全漏洞**

**【漏洞编号】****CNNVD-201705-218（CVE-2017-8455）**

**【漏洞详情】**Foxit Reader是中国福昕（Foxit）软件公司的一款PDF文档阅读器。Foxit PhantomPDF是一个商业版。

Foxit Reader 8.2.1之前的版本和PhantomPDF 8.2.1之前的版本中存在安全漏洞。远程攻击者可借助PDF文档中特制的字体利用该漏洞获取敏感信息或执行任意代码。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://www.foxitsoftware.com/support/security-bulletins.php

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017050218
