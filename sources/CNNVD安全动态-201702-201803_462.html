根据国家信息安全漏洞库（CNNVD）统计，本周（2017年2月27日至2017年3月5日）安全漏洞情况如下：

本期导读

采集漏洞情况

本周CNNVD采集安全漏洞108个，与上周（211个）相比漏洞数量有所下降。本周Veritas Technologies公司新增漏洞最多，涉及到Veritas NetBackup Appliance备份管理设备及NetBackup Server备份管理服务器等设备。

接报漏洞情况

本周接报漏洞230个，其中信息技术产品漏洞（通用型漏洞）14个，网络信息系统漏洞（事件型漏洞）216个。


一、采集漏洞情况

根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞108个，与上周相比有所减少。从厂商分布来看，本周Veritas Technologies公司新增漏洞最多，共有8个；从漏洞类型来看，跨站脚本类的安全漏洞占比最大，达到12.04%。本周新增漏洞中,高危漏洞17个，中危漏洞81个，低危漏洞10个，无超危漏洞。相应修复率分别为29.41%、56.79%以及80.00%。根据统计，合计59个漏洞已有修复补丁发布，整体修复率为54.63%。

截至2017年3月5日，CNNVD漏洞总量已达90297个。

1.多款Veritas产品权限许可和访问控制漏洞(CNNVD-201703-019)

Veritas NetBackup Appliance等都是美国Veritas Technologies公司的产品。Veritas NetBackup Appliance是一款企业级备份管理设备；NetBackup Server是一套可以运行于多种操作系统中的企业级备份管理服务器。

多款Veritas产品中存在提权漏洞。攻击者可利用该漏洞以root或管理员权限在NetBackup服务器或与之连接的NetBackup客户端上执行任意命令。以下产品和版本受到影响：Veritas NetBackup Server和Client 7.7.2之前的版本；NetBackup Appliance 2.7.2之前的版本。

解决措施：目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://www.veritas.com/content/support/en_US/security/VTS17-003.html#Issue1

2.多款Intel处理器信息泄露漏洞(CNNVD-201702-926)

Intel Core i7 920等都是美国英特尔（Intel）公司的CPU处理器。

多款Intel处理器中存在安全漏洞。攻击者可利用该漏洞泄露JavaScript中的数据和代码指针。以下产品受到影响：

-Intel Core i7 920

-Intel Core i5 M480

-Intel Core i7-2620QM

-Intel Core i7-3632QM

-Intel Core i7-4500U

-Intel Atom C2750

-Intel Xeon E5-2658 v2

-Intel Celeron N2840

-Intel Core i7-6700K

-Intel Xeon E3-1240 v5

解决措施：目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://intel.com/

3.IBM Tivoli Storage Manager Server 缓冲区错误漏洞(CNNVD-201702-887)

IBM Tivoli Storage Manager Server是美国IBM公司的一套用于数据保护、空间管理和存档、业务恢复能力和灾难恢复等领域的存储管理软件解决方案。该方案通过自动化数据备份和恢复功能，减少数据丢失风险。

IBM Tivoli Storage Manager Server 7.1.1.0版本至7.1.7.0版本中存在安全漏洞。攻击者可通过使用特制的SQL查询语句利用该漏洞造成缓冲区溢出，在服务器上执行任意代码。

解决措施：目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg21998747

4.Linux kernel 权限许可和访问控制漏洞(CNNVD-201702-888)

Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。

Linux kernel 4.9.12及之前的版本中的ipc/shm.c文件的‘do_shmat’函数存在安全漏洞。本地攻击者可借助特制的shmget和shmat系统调用利用该漏洞绕过保护机制。

解决措施：目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://bugzilla.kernel.org/show_bug.cgi?id=192931

5.Siemens RUGGEDCOM NMS 跨站脚本漏洞(CNNVD-201702-913)

Siemens RUGGEDCOM NMS是德国西门子（Siemens）公司的一套用于监控、配置和维护RUGGEDCOM任务网络的企业级解决方案。

基于8080/TCP和8081/TCP端口上的Siemens RUGGEDCOM NMS 1.2之前的版本中存在跨站脚本漏洞。攻击者可利用该漏洞获取管理员权限。

解决措施：目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://www.siemens.com/cert/pool/cert/siemens_security_advisory_ssa-363881.pdf
