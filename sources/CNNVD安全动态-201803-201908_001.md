今日CNNVD共发布安全漏洞71个。主要影响厂商为WordPress（23个）、美国Linux（4个）。主要影响产品为WordPress 博客平台（23个）、Linux kernel 操作系统内核（4个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******WordPress i-recommend-this插件SQL注入漏洞****

**【漏洞编号】******CNNVD-201908-1173********（CVE-2014-10376）****

**【漏洞详情】**WordPress是WordPress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。i-recommend-this是使用在其中的一个用于在页面上点赞和投票的插件。

WordPress i-recommend-this插件3.7.3之前版本中存在SQL注入漏洞。该漏洞源于基于数据库的应用缺少对外部输入SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://wordpress.org/plugins/i-recommend-this/#developers

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-1173

  

**【漏洞名称】**************Linux kernel 代码问题漏洞************  

**【漏洞编号】**********CNNVD-201908-1146********（CVE-2019-15098）********

**【漏洞详情】**Linux kernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。

Linux kernel 5.2.8及之前版本中的drivers/net/wireless/ath/ath6kl/usb.c文件存在代码问题漏洞。该漏洞源于网络系统或产品的代码开发过程中存在设计或实现不当的问题。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://lore.kernel.org/linux-wireless/20190804002905.11292-1-benquike@gmail.com/T/#u

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-1146

  

**【漏洞名称】******DjVuLibre 缓冲区错误漏洞****

**【漏洞编号】**********CNNVD-201908-1211**************（CVE-2019-15144）******

**【漏洞详情】**DjVuLibre是一款DjVu（计算机文件格式）的开源实现，它包括DjVu文件查看器、浏览器插件、DjVu文件解码/编码器和其它实用程序。

DjVuLibre 3.5.27版本中存在缓冲区错误漏洞。该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://sourceforge.net/p/djvu/bugs/299/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-1211

  

**【漏洞名称】******ImageMagick Studio ImageMagick 资源管理错误漏洞****

**【****漏洞****编号****】********CNNVD-201908-1204（**CVE-2019-15140）****

**【漏洞详情】**ImageMagick Studio ImageMagick是美国ImageMagick Studio公司的一套开源的图像处理软件。该软件可读取、转换或写入多种格式的图片。

ImageMagick Studio ImageMagick 7.0.8-43 Q16版本中的coders/mat.c文件存在资源管理错误漏洞。该漏洞源于网络系统或产品对系统资源（如内存、磁盘空间、文件等）的管理不当。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://github.com/ImageMagick/ImageMagick/commit/f7206618d27c2e69d977abf40e3035a33e5f6be0

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-1204
