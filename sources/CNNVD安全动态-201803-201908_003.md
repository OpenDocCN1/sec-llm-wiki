今日CNNVD共发布安全漏洞70个。主要影响厂商为WordPress（31个）、德国eQ-3（5个）。主要影响产品为WordPress 博客平台（31个）、eQ-3 Homematic CCU2 中央控制单元（4个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******WordPress newstatpress插件SQL注入漏洞****

**【漏洞编号】******CNNVD-201908-1035********（CVE-2015-9313）****

**【漏洞详情】**WordPress是WordPress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。newstatpress是使用在其中的一个用于实时统计博客访问数据的插件。

WordPress newstatpress插件1.0.5之前版本中存在SQL注入漏洞。该漏洞源于基于数据库的应用缺少对外部输入SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://wordpress.org/plugins/newstatpress/#developers

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-1035

  

**【漏洞名称】**************eQ-3 HomeMatic CCU2和eQ-3 Homematic CCU3 访问控制错误漏洞************  

**【漏洞编号】**********CNNVD-201908-1090********（CVE-2019-9585）********

**【漏洞详情】**eQ-3 Homematic CCU3和eQ-3 HomeMatic CCU2都是德国eQ-3公司的一款智能家居系统的中央控制单元。

eQ-3 Homematic CCU2 2.47.10之前版本和eQ-3 Homematic CCU3 3.47.10之前版本中的JSON API存在访问控制错误漏洞。该漏洞源于网络系统或产品未正确限制来自未授权角色的资源访问。目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：https://www.eq-3.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-1090

  

**【漏洞名称】******Bento4 缓冲区错误漏洞****

**【漏洞编号】**********CNNVD-201908-1070**************（CVE-2019-15050）******

**【漏洞详情】**Bento4是一款用于读写MP4文件的开源的C++库。

Bento4 1.5.1.0版本中的Core/Ap4AvccAtom.cpp文件的AP4\_AvccAtom类存在缓冲区错误漏洞。该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：https://www.osisoft.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-1070

  

**【漏洞名称】******IBM API Connect 安全漏洞****

**【****漏洞****编号****】********CNNVD-201908-1086（**CVE-2019-4402）****

**【漏洞详情】**IBM API Connect（APIConnect）是美国IBM公司的一套用于管理API生命周期的集成解决方案。该产品支持创建、运行、管理和保护API和微服务等。

IBM API Connect 2018.1版本至2018.4.1.6版本中存在安全漏洞。攻击者可利用该漏洞造成拒绝服务。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www-01.ibm.com/support/docview.wss?uid=ibm10958193

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-1086
