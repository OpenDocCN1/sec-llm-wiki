今日CNNVD共发布安全漏洞49个。主要影响厂商为WordPress（30个）、印度Frappe Technologies（3个）。主要影响产品为WordPress 博客平台（30个）、Frappe Technologies Frappe Framework Web应用程序框架（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******WordPress twitter-cards-meta插件跨站请求伪造漏洞****

**【漏洞编号】******CNNVD-201908-694********（CVE-2017-18504）****

**【漏洞详情】**WordPress是WordPress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。twitter-cards-meta plugin是使用在其中的一个Twitter账户信息显示插件。

WordPress twitter-cards-meta插件2.5.0之前版本中存在跨站请求伪造漏洞。该漏洞源于WEB应用未充分验证请求是否来自可信用户。攻击者可利用该漏洞通过受影响客户端向服务器发送非预期的请求。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://wordpress.org/plugins/twitter-cards-meta/#developers

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-694

  

**【漏洞名称】**************Frappe Technologies Frappe Framework 跨站脚本漏洞************  

**【漏洞编号】**********CNNVD-201908-706********（CVE-2019-14967）********

**【漏洞详情】**Frappe Technologies Frappe Framework是印度Frappe Technologies公司的一款基于Python和JavaScript的元数据驱动的全栈Web应用程序框架。

Frappe Technologies Frappe Framework 10版本、11.1.46之前的11版本和12版本中存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://github.com/frappe/frappe/releases/tag/v11.1.46

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-706

  

**【漏洞名称】******floragunn Search Guard 信息泄露漏洞****

**【漏洞编号】**********CNNVD-201908-709**************（CVE-2019-13417）******

**【漏洞详情】**floragunn Search Guard是德国floragunn公司的一款用于Elasticsearch和ELK的开源插件，它主要提供加密、身份验证、授权管理和日志审计等功能。

floragunn Search Guard 24.0之前版本中存在信息泄露漏洞。该漏洞源于网络系统或产品在运行过程中存在配置等错误。未授权的攻击者可利用漏洞获取受影响组件敏感信息。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://docs.search-guard.com/6.x-25/changelog-searchguard-6-x-24\_0

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-709

  

**【漏洞名称】******ImageMagick Studio ImageMagick 资源管理错误漏洞****

**【****漏洞****编号****】********CNNVD-201908-714（**CVE-2019-14980）****

**【漏洞详情】**ImageMagick Studio ImageMagick是美国ImageMagick Studio公司的一套开源的图像处理软件。该软件可读取、转换或写入多种格式的图片。

ImageMagick Studio ImageMagick 7.0.8-42之前的7.x版本和6.9.10-42之前的6.x版本中的‘UnmapBlob’函数存在存在资源管理错误漏洞。该漏洞源于网络系统或产品对系统资源（如内存、磁盘空间、文件等）的管理不当。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://github.com/ImageMagick/ImageMagick6/issues/43

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-714
