今日CNNVD共发布安全漏洞99个。主要影响厂商为美国Cisco（21个）、美国CloudBees（21个）。主要影响产品为Cisco Enterprise NFV Infrastructure Software（NFVIS）软件平台（10个）、CloudBees Jenkins 集成工具（21个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Cisco Enterprise NFV Infrastructure Software 操作系统命令注入漏洞****

**【漏洞编号】******CNNVD-201908-558********（CVE-2019-1971）****

**【漏洞详情】**Cisco Enterprise NFV Infrastructure Software（NFVIS）是美国思科（Cisco）公司的一套NVF基础架构软件平台。该平台可以通过中央协调器和控制器实现虚拟化服务的全生命周期管理。

Cisco Enterprise NFVIS 3.6.2版本至3.8.1版本中的Web门户存在命令注入漏洞，该漏洞源于Web门户框架没有进行充分的输入验证。远程攻击者可借助恶意的输入利用该漏洞以root权限执行任意命令。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://bst.cloudapps.cisco.com/bugsearch/bug/CSCvm76628

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-558

  

**【漏洞名称】**************CloudBees Jenkins Configuration as Code插件信息泄露漏洞************  

**【漏洞编号】**********CNNVD-201908-497********（CNNVD-201908-497）********

**【漏洞详情】**CloudBees Jenkins（Hudson Labs）是美国CloudBees公司的一套基于Java开发的持续集成工具。该产品主要用于监控持续的软件版本发布/测试项目和一些定时执行的任务。Configuration as Code Plugin是使用在其中的一个Jenkins配置插件。

CloudBees Jenkins Configuration as Code Plugin 1.26及之前版本中存在信息泄露漏洞。该漏洞源于网络系统或产品在运行过程中存在配置等错误。未授权的攻击者可利用漏洞获取受影响组件敏感信息。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://jenkins.io/security/advisory/2019-08-07/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-497

  

**【漏洞名称】******cPanel 跨站脚本漏洞****

**【漏洞编号】**********CNNVD-201908-482**************（CVE-2016-10806）******

**【漏洞详情】**cPanel是美国cPanel公司的一套基于Web的自动化主机托管平台。该平台主要用于自动化管理网站和服务器。

cPanel 57.9999.54之前版本中存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://documentation.cpanel.net/display/CL/58+Change+Log

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-482

  

**【漏洞名称】******Google Chrome PDFium ExecuteFieldAction 资源管理错误漏洞****

**【****漏洞****编号****】********CNNVD-201908-504（**CVE-2019-5868）****

**【漏洞详情】**Google Chrome是美国谷歌（Google）公司的一款Web浏览器。PDFium是其中的一个开源PDF渲染引擎。

Google Chrome 76.0.3809.100之前版本中的PDFium ExecuteFieldAction存在资源管理错误漏洞。该漏洞源于网络系统或产品对系统资源（如内存、磁盘空间、文件等）的管理不当。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：http://www.googblogs.com/stable-channel-update-for-desktop-84/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-504
