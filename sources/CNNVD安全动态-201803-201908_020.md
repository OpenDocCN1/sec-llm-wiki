今日CNNVD共发布安全漏洞73个。主要影响厂商为美国Google（16个）、美国CloudBees（15个）。主要影响产品为Google Chrome 浏览器（16个）、CloudBees Jenkins（Hudson Labs）持续集成工具（15个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Google Chrome 资源管理错误漏洞****

**【漏洞编号】******CNNVD-201907-1645********（CVE-2019-5863）****

**【漏洞详情】**Google Chrome是美国谷歌（Google）公司的一款Web浏览器。

Google Chrome 76.0.3809.87之前版本中的WebUSB（Windows）存在资源管理错误漏洞。攻击者可通过诱使用户访问特制的网站利用该漏洞在系统上执行任意代码。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://chromereleases.googleblog.com/2019/07/stable-channel-update-for-desktop\_30.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1645

  

**【漏洞名称】**************CloudBees Jenkins Maven Release插件跨站脚本漏洞************  

**【漏洞编号】**********CNNVD-201907-1596********（CVE-2019-10360）********

**【漏洞详情】**CloudBees Jenkins（Hudson Labs）是美国CloudBees公司的一套基于Java开发的持续集成工具。该产品主要用于监控持续的软件版本发布/测试项目和一些定时执行的任务。Maven Release Plugin是使用在其中的一个项目发布插件。

CloudBees Jenkins Maven Release Plugin 0.14.0及之前版本中存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://jenkins.io/security/advisory/2019-07-31/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1596

  

**【漏洞名称】******Apache Subversion svnserve servers 代码问题漏洞****

**【漏洞编号】**********CNNVD-201907-1622**************（CVE-2019-0203）******

**【漏洞详情】**Apache Subversion是美国阿帕奇（Apache）软件基金会的一套开源的版本控制系统。该系统可兼容并发版本系统(CVS)。svnserve servers是其中的一个轻量级的独立服务器。

Apache Subversion svnserve servers中存在代码问题漏洞。远程攻击者可利用该漏洞造成拒绝服务。以下产品及版本受到影响：Apache Subversion svnserve servers 1.9.10及之前版本，1.10.0版本至1.10.4版本，1.11.0版本至1.11.1版本，1.12.0版本至1.12.0版本。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://subversion.apache.org/security/CVE-2019-0203-advisory.txt

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1622

  

**【漏洞名称】******D-Link 6600-AP和DWL-3600AP 缓冲区错误漏洞****

**【****漏洞****编号****】********CNNVD-201907-1626（**CVE-2019-14338）****

**【漏洞详情】**D-Link 6600-AP和DWL-3600AP都是中国台湾友讯（D-Link）公司的一款无线访问接入点设备。

D-Link 6600-AP和DWL-3600AP中存在缓冲区错误漏洞。该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：http://www.dlink.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1626
