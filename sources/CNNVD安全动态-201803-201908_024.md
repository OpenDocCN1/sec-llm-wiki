# CNNVD最新漏洞（2019-07-30）

今日CNNVD共发布安全漏洞66个。主要影响厂商为美国Veritas Technologies（4个）、美国Apache（3个）。主要影响产品为Veritas Technologies Resiliency Platform 解决方案（4个）、Apache VCL 云计算平台（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Veritas Resiliency Platform 跨站脚本漏洞****

**【漏洞编号】******CNNVD-201907-1476********（CVE-2019-14415）****

**【漏洞详情】**Veritas Technologies Resiliency Platform（VRP）是美国Veritas Technologies公司的一套数据保护解决方案。

Veritas VRP 3.4 HF1之前版本中存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.veritas.com/content/support/en\_US/security/VTS19-002.html#Issue4

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1476

  

**【漏洞名称】**************Apache VCL SQL注入漏洞************  

**【漏洞编号】**********CNNVD-201907-1470********（CVE-2018-11772）********

**【漏洞详情】**Apache VCL是美国阿帕奇（Apache）软件基金会的一套开源的云计算平台。

Apache VCL 2.1版本至2.5版本中存在SQL注入漏洞。该漏洞源于基于数据库的应用缺少对外部输入SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lists.apache.org/thread.html/ffde9f87d0730ba6d4e1242eda56c1f1d6d0802ee4eda36fc1be3aaa@%3Cannounce.apache.org%3E

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1470

  

**【漏洞名称】******Dolibarr ERP/CRM 代码问题漏洞****

**【漏洞编号】**********CNNVD-201907-1461**************（CVE-2019-11201）******

**【漏洞详情】**Dolibarr ERP/CRM是法国Dolibarr基金会的一套基于Web的企业资源计划（ERP）和客户关系管理（CRM）系统。该系统可用来管理产品、库存、发票、订单等。

Dolibarr ERP/CRM 9.0.1版本中存在代码问题漏洞。远程攻击者可利用该漏洞在主机设备上执行代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.dolibarr.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1461

  

**【漏洞名称】******Open edX platform 跨站请求伪造漏洞****

**【****漏洞****编号****】********CNNVD-201907-1467（**CVE-2016-10766）****

**【漏洞详情】**Open edX platform是一套开源的课程管理系统（CMS）。该系统可用于MOOCs（大规模网络开放课程）以及较小的课程和培训模块。

Open edX platform 2016-06-06之前版本中存在跨站请求伪造漏洞。该漏洞源于WEB应用未充分验证请求是否来自可信用户。攻击者可利用该漏洞通过受影响客户端向服务器发送非预期的请求。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://open.edx.org/announcements/cross-site-request-forgery-bug-edx-lms/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1467
