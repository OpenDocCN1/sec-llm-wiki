本期导读

公开漏洞情况

本周CNNVD采集安全漏洞265个，与上周（406个）相比减少了34.73%。

接报漏洞情况

本周接报漏洞1451个，其中信息技术产品漏洞（通用型漏洞）36个，网络信息系统漏洞（事件型漏洞）1415个。

一、公开漏洞情况

根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞265个，漏洞新增数量有所下降。从厂商分布来看，苹果公司新增漏洞最多，共有47个；从漏洞类型来看，缓冲区错误类的安全漏洞占比最大，达到18.87%。本周新增漏洞中，超危漏洞13个，高危漏洞45个，中危漏洞179个，低危漏洞28个。相应修复率分别为30.77%、73.33%、75.98%和82.14%。根据补丁信息统计，合计196个漏洞已有修复补丁发布，整体修复率为73.96%。

1. 多款Qualcomm产品缓冲区错误漏洞（CNNVD-201907-1166）

Qualcomm MDM9607等都是美国高通（Qualcomm）公司的产品。MDM9607是一款中央处理器（CPU）产品。MDM9650是一款中央处理器（CPU）产品。SDX20是一款调制解调器。

多款Qualcomm产品中的Video Firmware存在缓冲区错误漏洞。该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。以下产品及版本受到影响：

2. Apache Storm 代码问题漏洞（CNNVD-201907-1348）

Apache Storm是美国阿帕奇（Apache）软件基金会的一套采用Clojure（并发编程语言）开发的开源分布式实时计算系统。

Apache Storm 1.1.0版本至1.2.2版本中存在代码问题漏洞。攻击者可通过发送特制的请求利用该漏洞在系统上执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lists.apache.org/thread.html/3e4f704c4bd9296405a07a0290b8cbb6cbf5046e277efe6d93280a98@%3Cuser.storm.apache.org%3E

3. Apple macOS Mojave Disk Management组件和Security组件安全漏洞（CNNVD-201907-1197）

Apple macOS Mojave是美国苹果（Apple）公司的一套专为Mac计算机所开发的专用操作系统。Disk Management其中的一个磁盘管理组件。Security是其中的一个安全组件。

Apple macOS Mojave 10.14.6之前版本中的Disk Management组件和Security组件存在内存损坏漏洞。攻击者可利用该漏洞以系统权限执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/zh-cn/HT210348
