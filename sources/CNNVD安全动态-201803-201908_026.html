今日CNNVD共发布安全漏洞7个。主要影响厂商为美国Linux（13个）、Ahsay Systems（5个）。主要影响产品为Linux kernel 操作系统内核（13个）、Ahsay Systems Cloud Backup Suite 备份软件套件（5个）。

今日需关注的典型漏洞如下:

【漏洞名称】Linux kernel 缓冲区错误漏洞

【漏洞编号】CNNVD-201907-1403（CVE-2010-5332）

【漏洞详情】Linux kernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。

Linux kernel 2.6.37之前版本中的drivers/net/mlx4/port.c文件存在缓冲区错误漏洞。该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=0926f91083f34d047abc74f1ca4fa6a9c161f7db

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1403


【漏洞名称】IBM Daeja ViewONE Virtual 代码问题漏洞

【漏洞编号】CNNVD-201907-1381（CVE-2019-4456）

【漏洞详情】IBM Daeja ViewONE Virtual是美国IBM公司的一款基于HTML5的文档和图像查看器。该产品主要用于查看、注释和打印图像和文档。

IBM Daeja ViewONE Virtual 5.0版本至5.0.6版本中存在代码问题漏洞。远程攻击者可利用该漏洞泄露敏感信息或消耗内存资源。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10959177

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1381


【漏洞名称】Ahsay Systems Cloud Backup Suite 路径遍历漏洞

【漏洞编号】CNNVD-201907-1387（CVE-2019-10265）

【漏洞详情】Ahsay Systems Cloud Backup Suite是Ahsay Systems公司的一套基于云的备份软件套件。

Ahsay Systems Cloud Backup Suite 8.1.1.50之前版本中的/cbs/system/ShowAdvanced.do中的File Explorer页面存在路径遍历漏洞。该漏洞源于网络系统或产品未能正确地过滤资源或文件路径中的特殊元素。攻击者可利用该漏洞访问受限目录之外的位置。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.ahsay.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1387


【漏洞名称】WordPress Advanced CF7 DB SQL注入漏洞

【漏洞编号】CNNVD-201907-1389（CVE-2019-13571）

【漏洞详情】WordPress是WordPress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。Advanced CF7 DB是使用在其中的一个联系表单插件。

WordPress Advanced CF7 DB中存在SQL注入漏洞。该漏洞源于基于数据库的应用缺少对外部输入SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/advanced-cf7-db/#developers

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1389
