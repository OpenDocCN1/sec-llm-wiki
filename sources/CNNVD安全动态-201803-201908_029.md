今日CNNVD共发布安全漏洞23个。主要影响厂商为美国IBM（3个）、美国McAfee（3个）。主要影响产品为IBM Cloud Private 解决方案（3个）、McAfee Data Loss Prevention Endpoint 解决方案（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******IBM Cloud Private 安全漏洞****

**【漏洞编号】******CNNVD-201907-1286********（CVE-2019-4116）****

**【漏洞详情】**IBM Cloud Private是美国IBM公司的一套企业私有云解决方案。该产品主要基于Kubernetes和容器技术搭建。

IBM Cloud Private 2.1.x版本、3.1.0版本和3.1.1版本中存在安全漏洞。攻击者可利用该漏洞获取安装程序日志中的敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=ibm10885318

**【漏洞链接】**  

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1286

  

**【漏洞名称】******McAfee Data Loss Prevention Endpoint 命令注入漏洞****  

**【****漏洞****编号****】********CNNVD-201907-1300（**CVE-2019-3595）****

**【漏洞详情】**McAfee Data Loss Prevention Endpoint（DLPe）是美国迈克菲（McAfee）公司的一套集成式终端数据保护解决方案。该方案能够防止机密数据被盗和意外泄露，并提供针对文件处理和传输的安全策略、共享终端数据流控制和数据加密等功能。

McAfee DLPe 11.3.0之前的11.x版本中的ePO扩展存在命令注入漏洞。该漏洞源于外部输入数据构造可执行命令过程中，网络系统或产品未正确过滤其中的特殊元素。攻击者可利用该漏洞执行非法命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://kc.mcafee.com/corporate/index?page=content&id=SB10289

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1300

  

**【漏洞名称】**************Apple macOS 缓冲区错误漏洞************  

**【漏洞编号】**********CNNVD-201907-1285********（CVE-2019-8582）********

**【漏洞详情】**Apple macOS是美国苹果（Apple）公司的一套专为Mac计算机所开发的专用操作系统。

Apple macOS中的CTFramesetterCreateWithAttributedString方法存在缓冲区错误漏洞，该漏洞源于程序缺少对用户提交数据的验证。攻击者可借助恶意的文件或页面利用该漏洞泄露敏感信息。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.apple.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1285

  

**【漏洞名称】**************Mitsubishi Electric FR Configurator2 代码问题漏洞************  

**【漏洞编号】**********CNNVD-201907-1283********（CVE-2019-10976）********

**【漏洞详情】**Mitsubishi Electric FR Configurator2是日本三菱电机（Mitsubishi Electric）公司的一款变频器驱动配置应用程序。

Mitsubishi Electric FR Configurator2 1.16S及之前版本中存在代码问题漏洞，该漏洞源于程序没有过滤传递到XML解析器的输入。攻击者可利用该漏洞读取任意文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.mitsubishielectric.com/fa/download/software/drv/inv/vulnerability-protection/2019-001.pdf

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1283
