# CNNVD最新漏洞（2019-07-24）

今日CNNVD共发布安全漏洞89个。主要影响厂商为美国Apple（46个）、中国卓源软件（2个）。主要影响产品为Apple Safari 浏览器（23个）、卓源软件Jeesite 开发平台（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******多款Apple产品WebKit组件跨站脚本漏洞****

**【漏洞编号】******CNNVD-201907-1215********（CVE-2019-8658）****

**【漏洞详情】**Apple Safari等都是美国苹果（Apple）公司的产品。Apple Safari是一款Web浏览器，是Mac OS X和iOS操作系统附带的默认浏览器。Apple iOS是一套为移动设备所开发的操作系统。Apple tvOS是一套智能电视操作系统。WebKit是其中的一个Web浏览器引擎组件。

多款Apple产品中的WebKit组件存在跨站脚本漏洞。攻击者可借助特制的Web内容利用该漏洞在用户的Web浏览器中执行脚本。以下产品及版本受到影响：Apple iOS 12.4之前版本；基于Windows平台的iTunes 12.9.6之前版本；tvOS 12.4之前版本；Safari 12.1.2之前版本；macOS Mojave 10.14.6之前版本；watchOS 5.3之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/zh-cn/HT210356

https://support.apple.com/zh-cn/HT210346

https://support.apple.com/zh-cn/HT210351

https://support.apple.com/zh-cn/HT210355

https://support.apple.com/zh-cn/HT210348

https://support.apple.com/zh-cn/HT210353

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1215

  

**【漏洞名称】******卓源软件 Jeesite SQL注入漏洞****  

**【****漏洞****编号****】********CNNVD-201907-1249（**CVE-2019-1010201）****

**【漏洞详情】**卓源软件 Jeesite是中国卓源软件公司的一套开源的Java EE企业级快速开发平台。该平台包括系统权限组件、数据权限组件、数据字典组件、核心工具组件、视图操作组件、工作流组件和代码生成组件等。

卓源软件 Jeesite 1.2.7版本中的src/main/java/com.thinkgem.jeesite/modules/act/ActDao.java文件的‘updateProcInsIdByBusinessId()’函数存在SQL注入漏洞。该漏洞源于基于数据库的应用缺少对外部输入SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://jeesite.gitee.io/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1249

  

**【漏洞名称】**************Fortinet FortiOS IPS engine 信息泄露漏洞************  

**【漏洞编号】**********CNNVD-201907-1256********（CVE-2019-5592）********

**【漏洞详情】**Fortinet FortiOS是美国飞塔（Fortinet）公司的一套专用于FortiGate网络安全平台上的安全操作系统。该系统为用户提供防火墙、防病毒、IPSec/SSLVPN、Web内容过滤和反垃圾邮件等多种安全功能。IPS engine是使用在其中的一个入侵防御系统引擎。

Fortinet FortiOS IPS engine中存在信息泄露漏洞。该漏洞源于网络系统或产品在运行过程中存在配置等错误。未授权的攻击者可利用漏洞获取受影响组件敏感信息。以下产品及版本受到影响：Fortinet FortiOS IPS engine 5.00000版本至5.00006版本，4.00000版本至4.00036版本，4.00200版本至4.00219版本，3.00547及之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://fortiguard.com/psirt/FG-IR-19-145

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1256

  

**【漏洞名称】**************GoUrl.io GoURL Wordpress Plugin 代码问题漏洞************  

**【漏洞编号】**********CNNVD-201907-1264********（CVE-2019-1010209）********

**【漏洞详情】**GoUrl.io GoURL Wordpress Plugin是一款使用在WordPress中的比特币支付网关插件。

GoUrl.io GoURL Wordpress Plugin 1.4.13及之前版本中的gourl.php文件存在代码问题漏洞。该漏洞源于网络系统或产品的代码开发过程中存在设计或实现不当的问题。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/gourl-bitcoin-payment-gateway-paid-downloads-membership/#developers

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1264
