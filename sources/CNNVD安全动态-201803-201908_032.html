今日CNNVD共发布安全漏洞61个。主要影响厂商为中国福昕（9个）、美国IBM（2个）。主要影响产品为Foxit PhantomPDF 文档阅读器（9个）、IBM Spectrum Protect Backup-Archive Client 客户端程序（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】Foxit PhantomPDF 安全漏洞

【漏洞编号】CNNVD-201907-1152（CVE-2019-14209）

【漏洞详情】Foxit PhantomPDF是中国福昕（Foxit）公司的一款PDF文档阅读器。

Foxit PhantomPDF 8.3.10之前版本中存在安全漏洞。攻击者可利用该漏洞造成堆损坏。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.foxitsoftware.com/support/security-bulletins.php

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1152


【漏洞名称】IBM Spectrum Protect Backup-Archive Client 缓冲区错误漏洞

【漏洞编号】CNNVD-201907-1137（CVE-2019-4267）

【漏洞详情】IBM Spectrum Protect Backup-Archive Client是美国IBM公司的一套用于IBM Spectrum Protect文件备份、归档的客户端程序。

IBM Spectrum Protect Backup-Archive Client 8.1.0.0版本至8.1.7.1版本和7.1.0.0版本至7.1.8.5版本中存在缓冲区错误漏洞。攻击者可利用该漏洞在本地系统上执行任意代码或造成应用程序崩溃。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10884768

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1137


【漏洞名称】HPE IceWall SSO Agent Option和IceWall MFA 安全漏洞

【漏洞编号】CNNVD-201907-1135（CVE-2019-11989）

【漏洞详情】HPE IceWall SSO和HPE IceWall MFA都是美国惠普企业公司（Hewlett Packard Enterprise，HPE）的产品。HPE IceWall SSO是一款为用户提供身份验证功能的单点登录程序。HPE IceWall SSO Agent Option是一个基于代理的HPE IceWall SSO选项。HPE IceWall MFA是一套多因素身份验证解决方案。Agent module是其中的一个代理模块。

HPE IceWall SSO Agent Option和IceWall MFA (Agent模块 )中存在安全漏洞。攻击者可利用该漏洞造成拒绝服务。以下产品及版本受到影响：IceWall SSO Agent Option 10.0 (RHEL、HP-UX和Windows)版本，11.0 (RHEL)版本；HPE IceWall MFA 4.0EE MFA. Server LTU (Agent模块仅包含在MFA Proxy)，HPE IceWall.MFA4.0SE MFA. Server LTU (Agent模块仅包含在MFA Proxy)。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.hpe.com/hpsc/doc/public/display?docLocale=en_US&docId=emr_na-hpesbmu03941en_us

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1135


【漏洞名称】MicroStrategy Web 跨站脚本漏洞

【漏洞编号】CNNVD-201907-1130（CVE-2019-12453）

【漏洞详情】Microstrategy Web是美国Microstrategy公司的一套企业数据分析平台。该平台具有数据发现、数据可视化和报表生成等功能。

MicroStrategy Web 10.1 patch 10之前版本中的‘FLTB’参数存在跨站脚本漏洞。 该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www2.microstrategy.com/producthelp/10.10/Readme/content/web.htm

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-1130
