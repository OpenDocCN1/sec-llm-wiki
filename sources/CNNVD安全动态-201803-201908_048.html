今日CNNVD共发布安全漏洞44个。主要影响厂商为美国Apple（1个）、美国Artifex Software（1个）。主要影响产品为Apple iOS操作系统（1个）、Artifex Software MuPDF阅读器（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Apple iOS Messages组件输入验证错误漏洞

【漏洞编号】CNNVD-201907-283（CVE-2019-8664）

【漏洞详情】Apple iOS是美国苹果（Apple）公司的一套为移动设备所开发的操作系统。Messages是其中的一个用于发送的文本、照片和视频的应用程序组件。

Apple iOS 12.3之前版本中的Messages组件存在输入验证错误漏洞。攻击者可借助特制的消息利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/en-us/HT210118

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-283


【漏洞名称】Artifex Software MuPDF 缓冲区错误漏洞

【漏洞编号】CNNVD-201907-280（CVE-2019-13290）

【漏洞详情】Artifex Software MuPDF是美国Artifex Software公司的一款免费的、轻量级的PDF阅读器。

Artifex Software MuPDF 1.15.0版本中的fitz/list-device.c文件的'fz_append_display_node'存在缓冲区错误漏洞。该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://mupdf.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-280


【漏洞名称】WordPress VeronaLabs wp-statistics插件SQL注入漏洞

【漏洞编号】CNNVD-201907-272（CVE-2019-13275）

【漏洞详情】WordPress是WordPress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。VeronaLabs wp-statistics plugin是使用在其中的一个网站信息统计插件。

WordPress VeronaLabs wp-statistics插件12.6.7之前版本中的v1/hit端点存在SQL注入漏洞。该漏洞源于基于数据库的应用缺少对外部输入SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/wp-statistics/#developers

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-272


【漏洞名称】Teclib GLPI 跨站脚本漏洞

【漏洞编号】CNNVD-201907-249（CVE-2019-13239）

【漏洞详情】Teclib GLPI是法国Teclib公司的一套开源的IT资产管理套件。该套件包含设备状态管理、资产清单存储、管理流程和工作日志管理等功能。

Teclib GLPI 9.4.3之前版本中的inc/user.class.php文件存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/glpi-project/glpi/releases/tag/9.4.3

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-249
