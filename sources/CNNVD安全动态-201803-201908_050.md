# CNNVD最新漏洞（2019-07-03）

今日CNNVD共发布安全漏洞115个。主要影响厂商为美国Google（19个）、美国TRENDnet（8个）。主要影响产品为Android操作系统（19个）、TRENDnet TEW-827DRU无线路由器（8个）。  

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Android Framework 信息泄露漏洞****

**【漏洞编号】******CNNVD-201907-033********（CVE-2019-2104）****

**【漏洞详情】**Android是美国谷歌（Google）和开放手持设备联盟（简称OHA）的一套以Linux为基础的开源操作系统。Framework是其中的一个Android框架组件。

Android 8.0版本、8.1版本和9.0版本中的Framework组件存在信息泄露漏洞。攻击者可利用该漏洞获取敏感信息的访问权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2019-07-01

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-033

  

**【漏洞名称】******TRENDnet TEW-827DRU 命令注入漏洞****  

**【****漏洞****编号****】********CNNVD-201907-112（**CVE-2019-13154）****

**【漏洞详情】**TRENDnet TEW-827DRU是美国趋势网络（TRENDnet）公司的一款无线路由器。

使用2.05B11之前版本固件的TRENDnet TEW-827DRU中的apply.cgi文件存在命令注入漏洞。该漏洞源于外部输入数据构造可执行命令过程中，网络系统或产品未正确过滤其中的特殊元素。攻击者可利用该漏洞执行非法命令。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.trendnet.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-112

  

**【漏洞名称】**************Quest Software KACE Systems Management Appliance 输入验证错误漏洞************  

**【漏洞编号】**********CNNVD-201907-089********（CVE-2019-10973）********

**【漏洞详情】**Quest Software KACE Systems Management Appliance（SMA）是美国Quest Software公司的一款系统管理设备。该产品支持IT资产管理、服务器管理与监控、软件许可管理和补丁管理等功能。

Quest Software KACE SMA 8.0.x版本、8.1.x版本和9.0.x版本中存在输入验证错误漏洞。该漏洞源于网络系统或产品未对输入的数据进行正确的验证。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.quest.com/kace-systems-management-appliance/9.1/download-new-releases

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-089

  

**【漏洞名称】**************IBM Application Performance Management 安全漏洞************  

**【漏洞编号】**********CNNVD-201907-087********（CVE-2019-4131）********

**【漏洞详情】**IBM Application Performance Management（APM）是美国IBM公司的一套IT服务管理软件。该软件主要用于监控和管理云、内部部署和混合应用程序以及IT基础架构等。

IBM APM Base Private 8.1.4版本和Advanced Private 8.1.4版本中存在安全漏洞。远程攻击者可利用该漏洞对任意的域名进行服务器端DNS查询。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10957121

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-087
