今日CNNVD共发布安全漏洞34个。主要影响厂商为斯洛文尼亚Prima Systems（7个）、美国ImageMagick Studio（5个）。主要影响产品为Prima Systems FlexAir门禁控制系统（7个）、ImageMagick Studio ImageMagick图像处理软件（5个）。

今日需关注的典型漏洞如下:

【漏洞名称】Prima Systems FlexAir 授权问题漏洞

【漏洞编号】CNNVD-201907-014（CVE-2019-7666）

【漏洞详情】Prima Systems FlexAir是斯洛文尼亚Prima Systems公司的一款门禁控制系统。

Prima Systems FlexAir中存在授权问题漏洞。该漏洞源于网络系统或产品中缺少身份验证措施或身份验证强度不足。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://primasystems.eu/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-014


【漏洞名称】ImageMagick Studio ImageMagick 安全漏洞

【漏洞编号】CNNVD-201907-020（CVE-2019-13133）

【漏洞详情】ImageMagick Studio ImageMagick是美国ImageMagick Studio公司的一套开源的图像处理软件。该软件可读取、转换或写入多种格式的图片。

ImageMagick Studio ImageMagick 7.0.8-50之前版本中的coders/bmp.c文件的‘ReadBMPImage’函数存在内存泄露漏洞。攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/issues/1600

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-020


【漏洞名称】Tenable Network Security Nessus 代码注入漏洞

【漏洞编号】CNNVD-201907-027（CVE-2019-3962）

【漏洞详情】Tenable Network Security Nessus是美国Tenable Network Security公司的一款开源的系统漏洞扫描器。

Tenable Nessus 8.5.0之前版本中存在代码注入漏洞。该漏洞源于外部输入数据构造代码段的过程中，网络系统或产品未正确过滤其中的特殊元素。攻击者可利用该漏洞生成非法的代码段，修改网络系统或组件的预期的执行控制流。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://www.tenable.com/security/tns-2019-04

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-027


【漏洞名称】Palo Alto Networks MineMeld 跨站脚本漏洞

【漏洞编号】CNNVD-201907-009（CVE-2019-1578）

【漏洞详情】Palo Alto Networks MineMeld是美国Palo Alto Networks公司的一款威胁情报处理工具。该产品可以从多种来源提取指标，并将指标编译为与AutoFocus、PaloAltoNetworks下一代防火墙以及其他安全和信息事件管理（SIEM）平台兼容的多种格式。

Palo Alto Networks MineMeld 0.9.60及之前版本中存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://securityadvisories.paloaltonetworks.com/Home/Detail/153

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201907-009
