今日CNNVD共发布安全漏洞100个。主要影响厂商为美国IBM（21个）、美国Pulse Secure（8个）。主要影响产品为IBM InfoSphere Information Server on Cloud数据整合平台（3个）、Pulse Secure Pulse Connect Secure解决方案（7个）。

今日需关注的典型漏洞如下:

【漏洞名称】IBM InfoSphere Information Server on Cloud 跨站脚本漏洞

【漏洞编号】CNNVD-201906-1081（CVE-2019-4417）

【漏洞详情】IBM InfoSphere Information Server on Cloud是美国IBM公司的一套基于云的数据整合平台。

IBM InfoSphere Information Server on Cloud 11.5版本和 11.7版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞在Web UI中注入任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10887827

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-1081


【漏洞名称】Pulse Secure Pulse Connect Secure 输入验证错误漏洞

【漏洞编号】CNNVD-201906-1116（CVE-2018-20813）

【漏洞详情】Pulse Secure Pulse Connect Secure（又名PCS，前称Juniper Junos Pulse）是美国Pulse Secure公司的一套SSL VPN解决方案。

Pulse Secure Pulse Connect Secure 8.3R2.之前的8.3RX版本中的login_meeting.cgi文件存在输入验证错误漏洞。该漏洞源于网络系统或产品未对输入的数据进行正确的验证。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.pulsesecure.net/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-1116


【漏洞名称】Synology Calendar 操作系统命令注入漏洞

【漏洞编号】CNNVD-201906-1158（CVE-2019-11829）

【漏洞详情】Synology Calendar是中国台湾群晖科技（Synology）公司的一款运行在Synology NAS（网络存储服务器）设备上的文件保护程序。

Synology Calendar 2.3.1-0617之前版本中的drivers_syno_import_user.php文件存在操作系统命令注入漏洞。该漏洞源于外部输入数据构造操作系统可执行命令过程中，网络系统或产品未正确过滤其中的特殊字符、命令等。攻击者可利用该漏洞执行非法操作系统命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.synology.com/security/advisory/Synology_SA_19_12

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-1158


【漏洞名称】Advantech WebAccess/SCADA 缓冲区错误漏洞

【漏洞编号】CNNVD-201906-1076（CVE-2019-10987）

【漏洞详情】Advantech WebAccess/SCADA是中国台湾研华（Advantech）公司的一套基于浏览器架构的SCADA软件。该软件支持动态图形显示和实时数据控制，并提供远程控制和管理自动化设备的功能。

Advantech WebAccess/SCADA 8.3.5及之前版本中存在越界写入漏洞，该漏洞源于程序没有正确验证用户提供的数据长度。攻击者可利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.advantech.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-1076
