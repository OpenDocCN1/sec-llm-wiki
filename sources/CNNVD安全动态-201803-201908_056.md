今日CNNVD共发布安全漏洞23个。主要影响厂商为美国Google（4个）、美国IBM（4个）。主要影响产品为Google Chrome浏览器（4个）、IBM InfoSphere Information Server数据整合平台（2个）。  

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Google Chrome V8 安全漏洞****

**【漏洞编号】******CNNVD-201906-1054********（CVE-2017-5028）****

**【漏洞详情】**Google Chrome是美国谷歌（Google）公司的一款Web浏览器。V8是其中的一套开源JavaScript引擎。

Google Chrome 56.0.2924.76之前版本中的V8存在安全漏洞，该漏洞源于程序没有充分地验证数据。远程攻击者可利借助特制的HTML页面利用该漏洞泄露跨源数据。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://chromereleases.googleblog.com/2017/01/stable-channel-update-for-desktop.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-1054

  

**【漏洞名称】******IBM InfoSphere Information Server 安全漏洞****  

**【****漏洞****编号****】********CNNVD-201906-1071（**CVE-2019-4237）****

**【漏洞详情】**IBM InfoSphere Information Server是美国IBM公司的一套数据整合平台。该平台可用于整合各种渠道获取的数据信息。

IBM InfoSphere Information Server中存在安全漏洞。攻击者可利用该漏洞在恶意页面的HTML iframe标签中加载该受影响的应用程序。以下产品及版本受到影响：IBM InfoSphere Information Server 11.3版本，11.5版本，11.7版本；InfoSphere Information Governance Catalog 11.3版本，11.5版本，11.7版本；InfoSphere Information Server on Cloud 11.5版本，11.7版本。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10879825

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-1071

  

**【漏洞名称】**************McAfee Enterprise Security Manager 命令注入漏洞************  

**【漏洞编号】**********CNNVD-201906-1064********（CVE-2019-3630）********

**【漏洞详情】**McAfee Enterprise Security Manager（ESM）是美国迈克菲（McAfee）公司的一套安全信息和事件管理解决方案（SIEM）。该方案支持查看和分析威胁情报以及快速确定威胁的优先级并进行安全响应，并内置嵌入式合规框架。

McAfee ESM 11.2.0之前版本和10.4.0之前版本中存在命令注入漏洞。该漏洞源于外部输入数据构造可执行命令过程中，网络系统或产品未正确过滤其中的特殊元素。攻击者可利用该漏洞执行非法命令。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://kc.mcafee.com/corporate/index?page=content&id=SB10284

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-1064
