今日CNNVD共发布安全漏洞21个。主要影响厂商为中国联想（5个）、德国LiveZilla（5个）。主要影响产品为Lenovo Service Bridge应用程序（4个）、LiveZilla Server在线客服系统（5个）。  

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Lenovo Service Bridge 安全漏洞****

**【漏洞编号】******CNNVD-201906-935********（CVE-2019-6168）****

**【漏洞详情】**Lenovo Service Bridge是中国联想（Lenovo）公司的一款基于Windows平台的应用程序。该程序能够自动检测设备的序列号、设备类型和型号，以提供相应服务。

Lenovo Service Bridge中存在安全漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.lenovo.com/us/zh/solutions/len-27725

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-935

  

**【漏洞名称】******LiveZilla Server SQL注入漏洞****  

**【****漏洞****编号****】********CNNVD-201906-930（**CVE-2019-12960）****

**【漏洞详情】**LiveZilla Server是德国LiveZilla公司的一套免费的在线客服系统。该系统提供实时监测访客、离线留言、GeoTracking地图跟踪、访问统计、在线聊天等功能。

LiveZilla Server 8.0.1.1之前版本中functions.internal.build.inc.php文件存在SQL注入漏洞。该漏洞源于基于数据库的应用缺少对外部输入SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://forums.livezilla.net/index.php?/topic/10983-fg-vd-19-086-livezilla-server-is-vulnerable-to-sql-injection-ii/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-930

  

**【漏洞名称】**************HP Support Assistant 安全漏洞************  

**【漏洞编号】**********CNNVD-201906-923********（CVE-2019-6329）********

**【漏洞详情】**HP Support Assistant是美国惠普（HP）公司的一套为PC和打印机提供支持等功能的解决方案。

HP Support Assistant 8.7.50及之前版本中存在安全漏洞。攻击者可利用该漏洞获取系统权限并可以未授权修改目录或文件。 

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.hp.com/us-en/document/c06388027

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-923

  

**【漏洞名称】******Tenable Network Security Nessus 跨站脚本漏洞****  

**【漏洞编号】**********CNNVD-201906-925**************（CVE-2019-3961）******

**【漏洞详情】**Tenable Network Security Nessus是美国Tenable Network Security公司的一款开源的系统漏洞扫描器。

Tenable Network Security Nessu 8.4.0及之前版本中存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.tenable.com/security/tns-2019-04

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-925
