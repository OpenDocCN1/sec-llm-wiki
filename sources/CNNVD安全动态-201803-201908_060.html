今日CNNVD共发布安全漏洞31个。主要影响厂商为瑞士ABB（8个）、美国Apple（1个）。主要影响产品为ABB PB610设计软件（7个）、Apple AirPort Base Station无线路由器（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】ABB PB610 IDAL FTP server 缓冲区错误漏洞

【漏洞编号】CNNVD-201906-891（CVE-2019-7231）

【漏洞详情】ABB PB610是瑞士ABB公司的一款为CP600控制面板平台设计图形用户界面的软件。IDAL FTP server是其中的一个FTP（文件传输协议）服务器。

ABB PB610中的IDAL FTP server存在缓冲区错误漏洞。该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://library.e.abb.com/public/b0021d2ab9ba4e3ab14d7c2796f5908e/ABB-Advisory_3ADR010377_2.pdf

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-891


【漏洞名称】Micro Focus NetIQ Self Service Password Reset Software 信息泄露漏洞

【漏洞编号】CNNVD-201906-902（CVE-2019-11648）

【漏洞详情】Micro Focus NetIQ Self Service Password Reset Software是英国Micro Focus公司的一套基于Web的密码管理软件。

Micro Focus NetIQ Self Service Password Reset Software 4.4之前版本中存在信息泄露漏洞。攻击者可利用该漏洞泄露敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.netiq.com/documentation/self-service-password-reset-44/release-notes-sspr-44-p2/data/release-notes-sspr-44-p2.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-902


【漏洞名称】LiveZilla Server SQL注入漏洞

【漏洞编号】CNNVD-201906-905（CVE-2019-12939）

【漏洞详情】LiveZilla Server是德国LiveZilla公司的一套免费的在线客服系统。该系统提供实时监测访客、离线留言、GeoTracking地图跟踪、访问统计、在线聊天等功能。

LiveZilla Server 8.0.1.1之前版本中的server.php文件存在SQL注入漏洞。该漏洞源于基于数据库的应用缺少对外部输入SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://forums.livezilla.net/index.php?/topic/10980-fg-vd-19-082-livezilla-server-is-vulnerable-to-sql-injection/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-905


【漏洞名称】Apple AirPort Base Station固件安全漏洞

【漏洞编号】CNNVD-201906-913（CVE-2019-8573）

【漏洞详情】Apple AirPort Base Station是美国苹果（Apple）公司的一款无线路由器。

Apple AirPort Base Station固件中存在安全漏洞。远程攻击者可利用该漏洞造成系统拒绝服务。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.apple.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-913
