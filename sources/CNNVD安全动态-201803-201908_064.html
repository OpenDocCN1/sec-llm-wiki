CNNVD最新漏洞（2019-06-20）

今日CNNVD共发布安全漏洞85个。主要影响厂商为美国Cisco（25个）、日本Sony（3个）。主要影响产品为Cisco SD-WAN Solution解决方案（3个）、Sony Bravia TV智能电视（3个）。

今日需关注的典型漏洞如下:

【漏洞名称】Cisco SD-WAN Solution 命令注入漏洞

【漏洞编号】CNNVD-201906-797（CVE-2019-1624）

【漏洞详情】Cisco SD-WAN Solution是美国思科（Cisco）公司的一套网络扩展解决方案。

Cisco SD-WAN Solution 18.4.0之前版本中的vManage Web UI存在命令注入漏洞，该漏洞源于程序没有执行充分的输入验证。远程攻击者可通过向该设备进行身份验证并向vManage Web UI提交特制的输入利用该漏洞以root权限执行命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20190619-sdwan-cmdinj

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-797


【漏洞名称】Sony Bravia TV Photo Sharing Plus 参数注入漏洞

【漏洞编号】CNNVD-201906-771（CVE-2018-16593）

【漏洞详情】Sony Bravia TV是日本索尼（Sony）公司的一款智能电视。Photo Sharing Plus是其中的一个图片共享组件。

Sony Bravia TV 8.587及之前版本中的Photo Sharing Plus组件存在参数注入漏洞。该漏洞源于外部输入数据构造命令参数的过程中，网络系统或产品未正确过滤参数中的特殊字符。攻击者可利用该漏洞执行非法命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.sony.co.uk/electronics/support/articles/00201041

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-771


【漏洞名称】Symantec Data Loss Prevention 跨站脚本漏洞

【漏洞编号】CNNVD-201906-728（CVE-2019-9701）

【漏洞详情】Symantec Data Loss Prevention（DLP）是美国赛门铁克（Symantec）公司的一套数据防泄漏解决方案。该产品主要用于发现、监控和保护敏感数据等。

Symantec DLP 15.5 MP1及之前版本中存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.symantec.com/us/en/article.SYMSA1484.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-728


【漏洞名称】IBM API Connect 安全漏洞

【漏洞编号】CNNVD-201906-779（CVE-2018-1858）

【漏洞详情】IBM API Connect（APIConnect）是美国IBM公司的一套用于管理API生命周期的集成解决方案。该产品支持创建、运行、管理和保护API和微服务等。

IBM API Connect 5.0.0.0版本至5.0.8.6 iFix1版本中存在跨站请求伪造漏洞。远程攻击者可利用该漏洞执行恶意的未授权操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10794169

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-779
