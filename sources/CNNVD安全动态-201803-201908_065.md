# CNNVD最新漏洞（2019-06-19）

今日CNNVD共发布安全漏洞43个。主要影响厂商为美国IBM（6个）、美国Polycom（1个）。主要影响产品为IBM Maximo Asset Management解决方案（2个）、Polycom UC Software通信软件平台（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******IBM Maximo Asset Management 跨站脚本漏洞****

**【漏洞编号】******CNNVD-201906-688********（CVE-2019-4303）****

**【漏洞详情】**IBM Maximo Asset Management是美国IBM公司的一套综合性资产生命周期和维护管理解决方案。该方案能够在一个平台上管理所有类型的资产，如设施、交通运输等，并对这些资产实现单点控制。

IBM Maximo Asset Management 7.6版本中存在中存在跨站脚本漏洞。远程攻击者可利用该漏洞向Web UI中注入任意的JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10887563

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-688

  

**【漏洞名称】**************Polycom UC Software 信息泄露漏洞************  

**【漏洞编号】**********CNNVD-201906-687********（CVE-2019-10689）********

**【漏洞详情】**Polycom UC Software是美国宝利通（Polycom）公司的一套统一通信软件平台。该平台支持IM（即时通讯）、视频会议和语音通信等。

Polycom UC Software 5.9.2之前版本中存在信息泄露漏洞。该漏洞源于网络系统或产品在运行过程中存在配置等错误。未授权的攻击者可利用漏洞获取受影响组件敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.polycom.com/content/dam/polycom-support/global/documentation/insufficient-authentication-leakage-vvx-products.pdf

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-687

  

**【漏洞名称】******Securifi Almond 命令注入漏洞****

**【漏洞编号】**********CNNVD-201906-711**************（CVE-2017-8331）******

**【漏洞详情】**Securifi Almond是一款带有触控屏幕的无线路由器。

使用AL-R096版本固件的Securifi Almond、Almond+和Almond 2015中的端口转发功能存在命令注入漏洞。攻击者可利用该漏洞提交恶意的payload并控制设备。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.securifi.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-711

  

**【漏洞名称】******Advantech WebAccess/SCADA 缓冲区错误漏洞****

**【****漏洞****编号****】********CNNVD-201906-719（**CVE-2019-3953）****

**【漏洞详情】**Advantech WebAccess/SCADA是中国台湾研华（Advantech）公司的一套基于浏览器架构的SCADA软件。该软件支持动态图形显示和实时数据控制，并提供远程控制和管理自动化设备的功能。

Advantech WebAccess/SCADA 8.4.0版本中存在基于栈的缓冲区溢出漏洞。该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.advantech.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-719
