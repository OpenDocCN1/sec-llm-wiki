# CNNVD最新漏洞（2019-06-14）

今日CNNVD共发布安全漏洞34个。主要影响厂商为美国Intel（14个）、美国IBM（4个）。主要影响产品为Intel SGX driver驱动程序（1个）、IBM Connections社交软件平台（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Intel SGX驱动程序输入验证错误漏洞****

**【漏洞编号】******CNNVD-201906-565********（CVE-2019-0157）****

**【漏洞详情】**Intel SGX driver是美国英特尔（Intel）公司的一款SGX（Intel软件安全扩展）驱动程序。

基于Linux平台的Intel SGX驱动程序存在输入验证错误漏洞。本地攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://01.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-565

  

**【漏洞名称】**************IBM Connections 跨站脚本漏洞************  

**【漏洞编号】**********CNNVD-201906-582********（CVE-2019-4403）********

**【漏洞详情】**IBM Connections是美国IBM公司的一套社交软件平台。该平台提供高级分析和实时数据监测功能，并能通过IBMSmartCloud服务加快组织内外的网络协作。

IBM Connections 6.0版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞在Web UI中注入任意的JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10886079

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-582

  

**【漏洞名称】******Artifex Software MuPDF 代码问题漏洞****

**【漏洞编号】**********CNNVD-201906-577**************（CVE-2019-7321）******

**【漏洞详情】**Artifex Software MuPDF是美国Artifex Software公司的一款免费的、轻量级的PDF阅读器。

Artifex Software MuPDF 1.14版本中的‘fz\_load\_jpeg’函数存在代码问题漏洞。该漏洞源于网络系统或产品的代码开发过程中存在设计或实现不当的问题。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://mupdf.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-577

  

**【漏洞名称】******Polycom RealPresence Debut 信息泄露漏洞****

**【****漏洞****编号****】********CNNVD-201906-578（**CVE-2018-10946）****

**【漏洞详情】**Polycom RealPresence Debut是美国宝利通（Polycom）公司的一款企业级小型视频会议解决方案。

Polycom RealPresence Debut 1.3.0-66872之前版本中存在信息泄露漏洞。该漏洞源于网络系统或产品在运行过程中存在配置等错误。未授权的攻击者可利用漏洞获取受影响组件敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.polycom.com/content/dam/polycom-support/global/documentation/advisory-rp-debut-vulnerabilities.pdf

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-578
