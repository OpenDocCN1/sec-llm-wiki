# CNNVD最新漏洞（2019-06-10）

今日CNNVD共发布安全漏洞92个。主要影响厂商为美国Optergy（8个）、美国Dell（2个）。主要影响产品为Optergy Proton/Enterprise管理系统（8个）、Dell EMC OpenManage Server Administrator解决方案（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Optergy Proton/Enterprise 跨站请求伪造漏洞****

**【漏洞编号】******CNNVD-201906-282********（CVE-2019-7273）****

**【漏洞详情】**Optergy Proton/Enterprise是美国Optergy公司的一套企业建筑管理系统。

Optergy Proton/Enterprise 2.3.0a及之前版本中存在跨站请求伪造漏洞。该漏洞源于WEB应用未充分验证请求是否来自可信用户。攻击者可利用该漏洞通过受影响客户端向服务器发送非预期的请求。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://optergy.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-282

  

**【漏洞名称】**************Dell EMC OpenManage Server Administrator 代码问题漏洞************  

**【漏洞编号】**********CNNVD-201906-271********（CVE-2019-3722）********

**【漏洞详情】**Dell EMC OpenManage Server Administrator（OMSA）是美国戴尔（Dell）公司的一套系统管理解决方案。该方案支持在线诊断、系统运行情况检测、设备管理等。

Dell EMC OMSA 9.1.0.3之前版本和9.2.0.4之前版本中存在代码问题漏洞。该漏洞源于网络系统或产品的代码开发过程中存在设计或实现不当的问题。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://https//www.dell.com/support/article/us/en/04/sln317441/dsa-2019-074-dell-emc-openmanage-server-administrator-multiple-vulnerabilities?lang=en

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-271

  

**【漏洞名称】******VMware Workstation 资源管理错误漏洞****

**【漏洞编号】**********CNNVD-201906-278**************（CVE-2019-5525）******

**【漏洞详情】**VMware Workstation是美国威睿（VMware）公司的一套虚拟机软件。该软件提供可以同时运行多个不同的操作系统的虚拟机功能。

VMware Workstation 15.1.0之前的15.x版本中的Advanced Linux Sound Architecture后端存在资源管理错误漏洞。该漏洞源于网络系统或产品对系统资源（如内存、磁盘空间、文件等）的管理不当。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.vmware.com/security/advisories/VMSA-2019-0009.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-278

  

**【漏洞名称】******Panasonic FPWIN Pro 缓冲区错误漏洞****

**【****漏洞****编号****】********CNNVD-201906-281（**CVE-2019-6530）****

**【漏洞详情】**Panasonic FPWIN Pro是日本松下电器（Panasonic）公司的一套控制器编程软件。

Panasonic FPWIN Pro 7.3.0.0及之前版本中存在缓冲区溢出漏洞。该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.panasonic-electric-works.com/eu/plc-software-control-fpwin-pro.htm

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201906-281
