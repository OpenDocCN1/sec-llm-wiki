今日CNNVD共发布安全漏洞40个。主要影响厂商为美国CloudBees（10个）、美国Apple（7个）。主要影响产品为CloudBees Jenkins集成工具（10个）、Apple AirPort Base Station无线路由器（7个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******CloudBees Jenkins Artifactory Plugin 跨站请求伪造漏洞****

**【漏洞编号】******CNNVD-201905-1213********（CVE-2019-10321）****

**【漏洞详情】**CloudBees Jenkins（Hudson Labs）是美国CloudBees公司的一套基于Java开发的持续集成工具。该产品主要用于监控持续的软件版本发布/测试项目和一些定时执行的任务。Artifactory Plugin是使用在其中的一个用于发布、解析和发布可跟踪的构建工件的插件。

CloudBees Jenkins Artifactory Plugin 3.2.2及之前版本中的ArtifactoryBuilder.DescriptorImpl#doTestConnection存在跨站请求伪造漏洞。该漏洞源于WEB应用未充分验证请求是否来自可信用户。攻击者可利用该漏洞通过受影响客户端向服务器发送非预期的请求。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：  

https://jenkins.io/security/advisory/2019-05-31/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201905-1213

  

**【漏洞名称】**************Apple AirPort Base Station 缓冲区错误漏洞************  

**【漏洞编号】**********CNNVD-201905-1201********（CVE-2019-8581）********

**【漏洞详情】**Apple AirPort Base Station是美国苹果（Apple）公司的一款无线路由器。

使用7.9.1之前版本固件的Apple AirPort Base Station中存在缓冲区错误漏洞。该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/zh-cn/HT210090

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201905-1201

  

**【漏洞名称】******Xiaomi M365 scooter 授权问题漏洞****

**【漏洞编号】**********CNNVD-201905-1209**************（CVE-2019-12500）******

**【漏洞详情】**Xiaomi M365 scooter是中国小米科技（Xiaomi）公司的一款电动滑板车。

使用1.5.1之前版本固件的Xiaomi M365 scooter中存在授权问题漏洞。该漏洞源于网络系统或产品中缺少身份验证措施或身份验证强度不足。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.mi.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201905-1209

  

**【漏洞名称】******NVIDIA GeForce Experience Web Helper组件安全漏洞****

**【****漏洞****编号****】********CNNVD-201905-1228（**CVE-2019-5678）****

**【漏洞详情】**NVIDIA GeForce Experience是美国英伟达（NVIDIA）公司的一套显卡自动更新工具.该产品能够自动更新显卡驱动程序，并支持显卡性能管理和优化等。Web Helper是其中的一个Web助手组件。

NVIDIA GeForce Experience 3.19之前版本中的Web Helper组件存在安全漏洞。攻击者可借助特制的输入利用该漏洞执行代码，造成拒绝服务或泄露信息。 

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://nvidia.custhelp.com/app/answers/detail/a\_id/4806

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201905-1228
