CNNVD最新漏洞（2019-05-22）

今日CNNVD共发布安全漏洞52个。主要影响厂商为美国Computrols（9个）、美国Fortinet（3个）。主要影响产品为Computrols CBAS Web楼宇自动化系统（19个）、Fortinet FortiOS操作系统（3个）。

今日需关注的典型漏洞如下:

【漏洞名称】Computrols CBAS Web 加密问题漏洞

【漏洞编号】CNNVD-201905-840（CVE-2019-10855）

【漏洞详情】Computrols CBAS Web是美国Computrols公司的一套楼宇自动化系统。

Computrols CBAS Web中存在加密问题漏洞，该漏洞源于网络系统或产品未正确使用相关密码算法，导致内容未正确加密、弱加密、明文存储敏感信息等。以下产品及版本受到影响：Computrols CBAS Web 19.0.1之前版本，18.0.1之前版本，15.0.1之前版本，14.0.1之前版本，8.0.7之前版本，7.2.1-Beta之前版本，6.9.2之前版本，4.8.2之前版本，3.15.1之前版本。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.computrols.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201905-840


【漏洞名称】Fortinet FortiOS 缓冲区错误漏洞

【漏洞编号】CNNVD-201905-878（CVE-2018-13381）

【漏洞详情】Fortinet FortiOS是美国飞塔（Fortinet）公司的一套专用于FortiGate网络安全平台上的安全操作系统。该系统为用户提供防火墙、防病毒、IPSec/SSLVPN、Web内容过滤和反垃圾邮件等多种安全功能。

Fortinet FortiOS 6.0.0版本至6.0.4版本、5.6.0版本至5.6.7版本和5.4及之前版本中存在缓冲区溢出漏洞。该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://fortiguard.com/psirt/FG-IR-18-387

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201905-878


【漏洞名称】Mozilla Firefox和Mozilla Firefox ESR 安全漏洞

【漏洞编号】CNNVD-201905-829（CVE-2019-9800）

【漏洞详情】Mozilla Firefox和Mozilla Firefox ESR都是美国Mozilla基金会的产品。Mozilla Firefox是一款开源Web浏览器。Mozilla Firefox ESR是Firefox(Web浏览器)的一个延长支持版本。

Mozilla Firefox 66版本和Firefox ESR 60.6版本中存在安全漏洞。攻击者可利用该漏洞损坏内存或可能执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.mozilla.org/en-US/security/advisories/mfsa2019-13/

https://www.mozilla.org/en-US/security/advisories/mfsa2019-14/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201905-829


【漏洞名称】IBM MQ 安全漏洞

【漏洞编号】CNNVD-201905-864（CVE-2019-4039）

【漏洞详情】IBM MQ（IBM WebSphere MQ）是美国IBM公司的一款消息传递中间件产品。该产品主要为面向服务的体系结构（SOA）提供可靠的、经过验证的消息传递主干网。

IBM MQ中的错误记录功能存在安全漏洞。本地攻击者可利用该漏洞覆盖任意的MQ文件，造成拒绝服务。以下产品及版本受到影响：IBM MQ 8.0.0.0版本至8.0.0.11版本，9.0.0.0版本至9.0.0.5版本（LTS），9.1.0.0版本至9.1.0.1版本（LTS），9.1.0版本至9.1.1版本（CD）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10870492

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201905-864
