# CNNVD最新漏洞（2019-05-21）

今日CNNVD共发布安全漏洞31个。主要影响厂商为美国Emerson Electric（1个）、美国IBM（1个）。主要影响产品为Emerson Electric Network Power Liebert Challenger网络物理环境控制系统（1个）、IBM API Connect解决方案（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Emerson Electric Network Power Liebert Challenger 跨站脚本漏洞****

**【漏洞编号】******CNNVD-201905-801********（CVE-2019-12167）****

**【漏洞详情】**Emerson Electric Network Power Liebert Challenger是美国艾默生电气（Emerson Electric）公司的一套网络物理环境控制系统。

Emerson Electric Network Power Liebert Challenger 5.1E0.5版本中存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.emerson.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201905-801

  

**【漏洞名称】**************IBM API Connect 安全漏洞************  

**【漏洞编号】**********CNNVD-201905-819********（CVE-2018-1991）********

**【漏洞详情】**IBM API Connect（APIConnect）是美国IBM公司的一套用于管理API生命周期的集成解决方案。该产品支持创建、运行、管理和保护API和微服务等。

IBM API Connect 5.0.0.0版本至5.0.8.6版本中存在安全漏洞。攻击者可利用该漏洞泄露敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10871970

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201905-819

  

**【漏洞名称】******Deciso OPNsense和Rubicon Communications pfSense 访问控制错误漏洞****

**【漏洞编号】**********CNNVD-201905-827**************（CVE-2019-11816）******

**【漏洞详情】**Deciso OPNsense是荷兰Deciso公司的一套基于FreeBSD的开源防火墙和路由软件。Rubicon Communications pfSense是美国Rubicon Communications公司的一套基于FreeBSD的开源防火墙及路由平台。

OPNsense 19.1.8之前版本和Rubicon Communications pfSense 2.4.4-p3之前版本中的WebUI存在访问控制错误漏洞。该漏洞源于网络系统或产品未正确限制来自未授权角色的资源访问。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://forum.opnsense.org/index.php?topic=12787.0

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201905-827

  

**【漏洞名称】********多款Schneider Electric产品安全特征问题漏洞******

**【****漏洞****编号****】********CNNVD-201905-798（**CVE-2019-6821）****

**【漏洞详情】**Schneider Electric Modicon M580等都是法国施耐德电气（Schneider Electric）公司的产品。Schneider Electric Modicon M580是一款可编程自动化控制器。Schneider Electric Modicon Premium是一款用于离散或过程应用的大型可编程逻辑控制器（PLC）。Schneider Electric Modicon Quantum是一款用于过程应用、高可用性和安全解决方案的大型可编程逻辑控制器（PLC）。

多款Schneider Electric产品中存在安全特征问题漏洞。该漏洞是源于网络系统或产品中缺少身份验证、访问控制、权限管理等安全措施。以下产品及版本受到影响：使用2.30之前版本固件的Schneider Electric Modicon M580；Modicon M340（全部固件版本）；Modicon Premium（全部固件版本）；Modicon Quantum（全部固件版本）。

目前厂商发布了ModiconM580的修复措施，ModiconM340、ModiconPremium和ModiconQuantum的修复措施暂未发布，详情请参考厂商主页：

https://www.schneider-electric.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201905-798
