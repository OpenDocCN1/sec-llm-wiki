今日CNNVD共发布安全漏洞47个。主要影响厂商为中国福昕（22个）、美国Facebook（2个）。主要影响产品为Foxit Reader文档阅读器（22个）、Facebook HHVM虚拟机（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Foxit Reader和Foxit PhantomPDF for Windows 输入验证错误漏洞

【漏洞编号】CNNVD-201904-1278（CVE-2019-6753）

【漏洞详情】Foxit Reader和Foxit PhantomPDF都是中国福昕（Foxit）公司的一款PDF文档阅读器。

基于Windows平台的Foxit Reader 9.4.1.16828及之前版本，Foxit PhantomPDF 8.3.9.41099及之前版本和9.4.1.16828及之前版本中存在输入验证错误漏洞。该漏洞源于网络系统或产品未对输入的数据进行正确的验证。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.foxitsoftware.com/support/security-bulletins.php

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-1278


【漏洞名称】Facebook HHVM 安全漏洞

【漏洞编号】CNNVD-201904-1312（CVE-2019-3561）

【漏洞详情】Facebook HHVM（又名HipHop Virtual Machine）是美国Facebook公司的一款能够显著提高PHP加载动态页面性能的虚拟机。

Facebook HHVM 4.0.3及之前版本、3.30.4及之前版本和3.27.7及之前版本中存在安全漏洞，该漏洞源于程序没有进行充分地边界检查。攻击者可利用该漏洞越界访问内存。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://hhvm.com/blog/2019/04/03/hhvm-4.0.4.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-1312


【漏洞名称】Apple macOS Mojave APFS组件安全漏洞

【漏洞编号】CNNVD-201904-1277（CVE-2019-8534）

【漏洞详情】Apple macOS Mojave是美国苹果（Apple）公司的一套专为Mac计算机所开发的专用操作系统。APFS是其中的一个苹果设备专用的文件系统组件。

Apple macOS Mojave 10.14.4之前版本中的APFS组件存在安全漏洞。攻击者可借助恶意的应用程序利用该漏洞以内核权限执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/zh-cn/HT209600

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-1277


【漏洞名称】NetApp Element Plug-in for vCenter Server 信息泄露漏洞

【漏洞编号】CNNVD-201904-1298（CVE-2019-5492）

【漏洞详情】NetApp Element Plug-in for vCenter Server是美国NetApp公司的一款用于管理数据中心第三方元素的插件。

NetApp Element Plug-in for vCenter Server  4.2.3之前版本中存在信息泄露漏洞，该漏洞源于网络系统或产品在运行过程中存在配置等错误。未授权的攻击者可利用漏洞获取受影响组件敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://security.netapp.com/advisory/ntap-20190426-0001/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-1298
