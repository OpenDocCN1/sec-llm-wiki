今日CNNVD共发布安全漏洞37个。主要影响厂商为美国Pulse Secure（10个）、美国Dell（1个）、中国华为（1个）。主要影响产品为Pulse Secure Pulse Connect Secure解决方案（10个）、Dell EMC iDRAC9解决方案（1个）、Huawei P20智能手机（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Pulse Secure Pulse Connect Secure 跨站脚本漏洞

【漏洞编号】CNNVD-201904-1234（CVE-2019-11507）

【漏洞详情】Pulse Secure Pulse Connect Secure（又名PCS，前称Juniper Junos Pulse）是美国Pulse Secure公司的一套SSL VPN解决方案。

Pulse Secur PCS 8.3R7.1之前的8.3.x版本和9.0R3之前的9.0.x版本中的Pulse Secure Application Launcher页面存在跨站脚本漏洞，该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://kb.pulsesecure.net/articles/Pulse_Security_Advisories/SA44101

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-1234


【漏洞名称】Dell EMC iDRAC9 授权问题漏洞

【漏洞编号】CNNVD-201904-1252（CVE-2019-3707）

【漏洞详情】Dell EMC iDRAC9是美国戴尔（Dell）公司的一套包含硬件和软件的系统管理解决方案。该方案为Dell PowerEdge系统提供远程管理、崩溃系统恢复和电源控制等功能。

Dell EMC iDRAC9 3.30.30.30之前版本中存在授权问题漏洞，该漏洞源于网络系统或产品中缺少身份验证措施或身份验证强度不足。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.dell.com/support/article/us/en/19/sln316930/dsa-2019-028-dell-emc-idrac-multiple-vulnerabilities?lang=en

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-1252


【漏洞名称】Huawei P20 安全漏洞

【漏洞编号】CNNVD-201904-1269（CVE-2019-5283）

【漏洞详情】Huawei P20是中国华为（Huawei）公司的一款智能手机。

Huawei P20 Emily-AL00A 9.0.0.167(C00E81R1P21T8)之前版本中存在安全漏洞。在进入FRP重新设置手机过程中，攻击者可通过进入Talkback模式利用该漏洞绕过FRP功能。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20190424-01-frp-cn

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-1269


【漏洞名称】Dillon Kane Tidal Workload Automation Agent Enterprise Scheduler 参数注入漏洞

【漏洞编号】CNNVD-201904-1253（CVE-2019-6689）

【漏洞详情】Dillon Kane Tidal Workload Automation Agent是美国Dillon Kane公司的一款工作负载自动化平台的代理程序。Enterprise Scheduler是其中的一个企业计划程序组件。

Dillon Kane Tidal Workload Automation Agent 3.2.0.5版本中的Enterprise Scheduler存在参数注入漏洞，该漏洞源于外部输入数据构造命令参数的过程中，网络系统或产品未正确过滤参数中的特殊字符。攻击者可利用该漏洞执行非法命令。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.dillonkane.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-1253


【漏洞名称】Oracle Fusion Middleware WebLogic Server组件安全漏洞

【漏洞编号】CNNVD-201904-1251（CVE-2019-2725）

【漏洞详情】Oracle Fusion Middleware（Oracle融合中间件）是美国甲骨文（Oracle）公司的一套面向企业和云环境的业务创新平台。该平台提供了中间件、软件集合等功能。WebLogic Server是其中的一个适用于云环境和传统环境的应用服务器组件。

Oracle Fusion Middleware中的WebLogic Server组件10.3.6.0.0版本和12.1.3.0.0版本的Web Services子组件存在安全漏洞。攻击者可利用该漏洞控制组件，影响数据的完整性、可用性和保密性。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.oracle.com/technetwork/security-advisory/alert-cve-2019-2725-5466295.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-1251
