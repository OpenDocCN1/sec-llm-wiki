# CNNVD最新漏洞（2019-04-28）

今日CNNVD共发布安全漏洞89个。主要影响厂商为日本Cybozu（20个）、加拿大Sierra Wireless（13个）。主要影响产品为Cybozu Garoon办公系统（20个）、Sierra Wireless AirLink ES450调制解调器设备（13个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Cybozu Garoon 跨站脚本漏洞****

**【漏洞编号】******CNNVD-201904-1214********（CVE-2019-5947）****

**【漏洞详情】**Cybozu Garoon是日本才望子（Cybozu）公司的一套门户型OA办公系统。该系统提供门户、E-mail、书签、日程安排、公告栏、文件管理等功能。

Cybozu Garoon 4.6.0版本至4.10.1版本中存在跨站脚本漏洞，该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://kb.cybozu.support/article/35496/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-1214

  

**【漏洞名称】**************Sierra Wireless AirLink ES450 操作系统命令注入漏洞************  

**【漏洞编号】**********CNNVD-201904-1202********（CVE-2018-4061）********

**【漏洞详情】**Sierra Wireless AirLink ES450是加拿大Sierra Wireless公司的一款蜂窝网络调制解调器设备。

使用4.9.3版本固件的Sierra Wireless AirLink ES450中的ACEManager iplogging.cgi功能存在操作系统命令注入漏洞，该漏洞源于外部输入数据构造可执行命令过程中，网络系统或产品未正确过滤其中的特殊元素。攻击者可利用该漏洞执行非法命令。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.sierrawireless.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-1202

  

**【漏洞名称】******Dell EMC OpenManage System Administrator 安全漏洞****

**【漏洞编号】**********CNNVD-201904-1208**************（CVE-2019-3721）******

**【漏洞详情】**Dell EMC OpenManage System Administrator（OMSA）是美国戴尔（Dell）公司的一套系统管理解决方案。该方案支持在线诊断、系统运行情况检测、设备管理等。

Dell EMC OMSA 9.3.0之前版本中存在安全漏洞。远程攻击者可通过发送特制的请求利用该漏洞使用户无法访问系统（内存大量消耗和崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.dell.com/support/article/us/en/19/sln316915/dsa-2019-060-dell-emc-open-manage-system-administrator-multiple-vulnerabilities?lang=en

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-1208

  

**【漏洞名称】********IBM Jazz Reporting Service Lifecycle Query Engine 安全漏洞******

**【****漏洞****编号****】********CNNVD-201904-1211（**CVE-2019-4047）****

**【漏洞详情】**IBM Jazz Reporting Service（JRS）是美国IBM公司的一套用于发现跨项目报表的应用程序。该程序可与IBMRationalCLM的Rational解决方案（用于管理开发项目的所有生命周期）集成使用，CLM用户可在仪表板中访问JRS提供的报表，包括显示所有项目的状态，并跨应用程序、跨项目（甚至跨时间表）来汇聚数据。Lifecycle Query Engine是其中的一个生命周期查询引擎。

带有Lifecycle Query Engine的IBM Jazz Reporting Service (JRS) 6.0.6版本中存在安全漏洞。攻击者可利用该漏洞以访客身份执行日志文件并获取信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10882262

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-1211
