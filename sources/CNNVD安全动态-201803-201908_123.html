今日CNNVD共发布安全漏洞79个。主要影响厂商为英国Canonical（5个）、美国Broadcom（1个）。主要影响产品为Canonical Ubuntu Metal as a Service应云服务器部署和管理工具（3个）、Broadcom WiFi Chipset Drivers驱动程序（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】Canonical Ubuntu Metal as a Service 安全漏洞

【漏洞编号】CNNVD-201904-986（CVE-2014-1426）

【漏洞详情】Canonical Ubuntu Metal as a Service（MAAS）是英国科能（Canonical）公司的一套云服务器部署和管理工具。该工具可对大量服务器的硬件环境进行集中部署并管理。

Ubuntu MAAS 1.9.2之前版本中的‘maasserver.api.get_file_by_name’函数存在安全漏洞。攻击者可利用该漏洞下载任意文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://launchpad.net/maas/+milestone/1.9.2

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-986


【漏洞名称】Broadcom WiFi Chipset Drivers 缓冲区错误漏洞

【漏洞编号】CNNVD-201904-964（CVE-2019-9502）

【漏洞详情】Broadcom WiFi Chipset Drivers是美国博通（Broadcom）公司的一款无线网络芯片组驱动程序。

Broadcom WiFi Chipset Drivers中存在基于堆的缓冲区溢出漏洞。该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。

目前厂商已发布新版本，以修复此安全问题，详情请关注厂商主页：

https://www.broadcom.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-964


【漏洞名称】TArtifex Software MuJS 缓冲区错误漏洞

【漏洞编号】CNNVD-201904-980（CVE-2019-11411）

【漏洞详情】Artifex Software MuJS是美国Artifex Software公司的一款轻量级的JavaScript解释器，它用于嵌入到其他的软件中提供脚本执行功能。

Artifex Software MuJS 1.0.5版本中的jscompile.c文件的Number#toFixed() 函数和 numtostr函数存在基于栈的缓冲区溢出漏洞。该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.ghostscript.com/cgi-bin/findgit.cgi?da632ca08f240590d2dec786722ed08486ce1be6

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-980


【漏洞名称】Google Kubernetes 安全漏洞

【漏洞编号】CNNVD-201904-1030（CVE-2019-11243）

【漏洞详情】Google Kubernetes是美国谷歌（Google）公司的一套开源的Docker容器集群管理系统。该系统为容器化的应用提供资源调度、部署运行、服务发现和扩容缩容等功能。

Google Kubernetes 1.12.0版本至1.12.4版本和1.13.0版本中存在安全漏洞，该漏洞源于rest.AnonymousClientConfig()方法没有有效地删除rest.InClusterConfig()所加载的服务账户凭证。攻击者可利用该漏洞获取信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/kubernetes/kubernetes/issues/76797

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-1030
