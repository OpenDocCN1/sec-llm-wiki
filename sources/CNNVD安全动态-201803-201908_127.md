今日CNNVD共发布安全漏洞44个。主要影响厂商为美国CloudBees（7个）、美国Dell（2个）。主要影响产品为CloudBees Jenkins集成工具（7个）、Dell SupportAssist Client应用程序（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******CloudBees Jenkins Azure PublisherSettings Credentials Plugin 安全漏洞****

**【漏洞编号】******CNNVD-201904-901********（CVE-2019-10303）****

**【漏洞详情】**CloudBees Jenkins（Hudson Labs）是美国CloudBees公司的一套基于Java开发的持续集成工具。该产品主要用于监控持续的软件版本发布/测试项目和一些定时执行的任务。Azure PublisherSettings Credentials Plugin是使用在其中的一个支持使用Jenkins Crendentials API管理Azure PublisherSettings的插件。

CloudBees Jenkins Azure PublisherSettings Credentials Plugin 1.2及之前版本中存在安全漏洞，该漏洞源于程序将服务管理凭证以明文形式存储在credentials.xml文件中。攻击者可利用该漏洞查看这些凭证。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://jenkins.io/security/advisory/2019-04-17/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-901

  

**【漏洞名称】**************Dell SupportAssist Client 安全漏洞************  

**【漏洞编号】**********CNNVD-201904-907********（CVE-2019-3718）********

**【漏洞详情】**Dell SupportAssist Client是美国戴尔（Dell）公司的一款客户端应用程序。该程序提供自动化、主动和预测性技术进行故障排除等。

Dell SupportAssist Client 3.2.0.90之前版本中存在安全漏洞，该漏洞源于程序没有正确地检测来源。远程攻击者可利用该漏洞实施跨站请求伪造攻击。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.dell.com/support/article/cn/zh/cndhs1/sln316857/dsa-2019-051-dell-supportassist-client-multiple-vulnerabilities?lang=en

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-907

  

**【漏洞名称】******SonicWall Global Management System 访问控制错误漏洞****

**【漏洞编号】**********CNNVD-201904-889**************（CVE-2019-7476）******

**【漏洞详情】**SonicWall Global Management System（GMS）是一套全球管理系统。该系统可快速部署和集中管理Dell SonicWALL防火墙、反垃圾邮件、备份和恢复以及安全远程访问解决方案。

SonicWall GMS中存在访问控制错误漏洞。远程攻击者可利用该漏洞获取设备的访问权限。以下版本版本受到影响：SonicWall Global Management System 9.1版本，9.0版本，8.7版本，8.6版本，8.4版本，8.3版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://psirt.global.sonicwall.com/vuln-detail/SNWLID-2019-0004

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-889

  

**【漏洞名称】********BlackBerry Unified Endpoint Manager 代码问题漏洞******

**【****漏洞****编号****】********CNNVD-201904-925（**CVE-2019-8999）****

**【漏洞详情】**BlackBerry Unified Endpoint Manager（UEM）是加拿大黑莓（BlackBerry）公司的一套统一端点管理解决方案。该方案用于管理终端设备并查看其访问情况。

BlackBerry UEM 12.10.1a之前版本中的UEM Core存在代码问题漏洞，该漏洞源于网络系统或产品的代码开发过程中存在设计或实现不当的问题。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://support.blackberry.com/kb/articleDetail?articleNumber=000056241

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-925
