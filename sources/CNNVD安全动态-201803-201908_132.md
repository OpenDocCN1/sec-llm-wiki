# CNNVD最新漏洞（2019-04-15）

今日CNNVD共发布安全漏洞35个。主要影响厂商为美国IBM（3个）、美国F5（1个）。主要影响产品为IBM API Connect解决方案（2个）、F5 BIG-IP应用交付平台（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******IBM API Connect 安全漏洞****

**【漏洞编号】******CNNVD-201904-589********（CVE-2019-4203）****

**【漏洞详情】**IBM API Connect（APIConnect）是美国IBM公司的一套用于管理API生命周期的集成解决方案。该产品支持创建、运行、管理和保护API和微服务等。

IBM API Connect 5.0.0.0版本至5.0.8.6版本中存在本地文件包含漏洞。攻击者可借助Developer Portal利用该漏洞下载主机操作系统上的任意文件并可能实施服务器端请求伪造攻击。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10880569

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-589

  

**【漏洞名称】**************F5 BIG-IP 安全漏洞************  

**【漏洞编号】**********CNNVD-201904-578********（CVE-2019-6609）********

**【漏洞详情】**F5 BIG-IP是美国F5公司的一款集成了网络流量管理、应用程序安全管理、负载均衡等功能的应用交付平台。

F5 BIG-IP中存在安全漏洞。攻击者可利用该漏洞绕过限制，提升权限。以下版本受到影响：F5 BIG-IP 14.0.0版本至14.1.0.1版本，13.0.0版本至13.1.1.3版本，12.1.1 HF2版本至12.1.4版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.f5.com/csp/article/K18535734

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-578

  

**【漏洞名称】******WPA 安全漏洞****

**【漏洞编号】**********CNNVD-201904-567**************（CVE-2019-9494）******

**【漏洞详情】**WPA是美国Wi-Fi联盟（Wi-Fi Alliance）的一套Wi-Fi访问保护方案，包括安全协议和安全认证程序。

WPA3中存在安全漏洞。攻击者可利用该漏洞绕过安全限制，执行未授权的操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://w1.fi/security/2019-1/sae-side-channel-attacks.txt

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-567

  

**【漏洞名称】********NVIDIA Jetson TX2 安全漏洞******

**【****漏洞****编号****】********CNNVD-201904-586（**CVE-2019-5673）****

**【漏洞详情】**NVIDIA Jetson TX2是美国英伟达（NVIDIA）公司的一款嵌入式系统开发模块。

NVIDIA Jetson TX2中的内核驱动程序存在安全漏洞，该漏洞源于ARM System Memory Management Unit没有正确地检查错误的情况。攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://nvidia.custhelp.com/app/answers/detail/a\_id/4787

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-586
