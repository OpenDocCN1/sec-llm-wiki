今日CNNVD共发布安全漏洞47个。主要影响厂商为美国Juniper Networks（17个）、美国IBM（2个）。主要影响产品为Juniper Networks Junos OS操作系统（11个）、IBM BigFix WebUI Software Distribution应用程序（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Juniper Networks Junos OS 安全漏洞

【漏洞编号】CNNVD-201904-548（CVE-2019-0043）

【漏洞详情】Juniper Networks Junos OS是美国瞻博网络（Juniper Networks）公司的一套专用于该公司的硬件设备的网络操作系统。该操作系统提供了安全编程接口和Junos SDK。

Juniper Networks Junos OS中存在安全漏洞。攻击者可通过不断发送特制的SNMP数据包利用该漏洞造成RPD进程崩溃，导致拒绝服务。以下版本受到影响：Juniper Networks Junos OS 12.1X46版本，12.3版本，12.3X48版本，14.1X53版本，15.1版本，15.1F6版本，15.1X49版本，15.1X53版本，15.1X54版本，16.1版本，16.1X65版本，16.2版本，17.1版本，17.2版本，17.2X75版本，17.3版本，17.4版本，18.1版本，18.2X75版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://kb.juniper.net/InfoCenter/index?page=content&id=JSA10935&actp=METADATA

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-548


【漏洞名称】IBM BigFix WebUI Profile Management和IBM BigFix WebUI Software Distribution SQL注入漏洞

【漏洞编号】CNNVD-201904-526（CVE-2019-4012）

【漏洞详情】IBM BigFix WebUI Software Distribution和IBM BigFix WebUI Profile Management都是美国IBM公司的产品。IBM BigFix WebUI Software Distribution是一款软件分发应用程序。IBM BigFix WebUI Profile Management是一款配置管理应用程序。

IBM BigFix WebUI Software Distribution Site 23版本和IBM BigFix WebUI Profile Management Site 6版本中存在SQL注入漏洞，该漏洞源于基于数据库的应用缺少对外部输入SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10875490

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-526


【漏洞名称】McAfee DXL Platform和McAfee TIE Server 信息泄露漏洞

【漏洞编号】CNNVD-201904-537（CVE-2019-3612）

【漏洞详情】McAfee DXL Platform和McAfee TIE Server都是美国迈克菲（McAfee）公司的产品。McAfee DXL Platform是一套数据交换层平台。McAfee TIE Server是一款网络威胁防御服务器。

McAfee DXL Platform 5.0.1 HF2之前的5.x版本、4.1.2 HF3之前的4.x版本和TIE Server 2.3.1 HF1之前的2.x版本存在信息泄露漏洞，该漏洞源于网络系统或产品在运行过程中存在配置等错误。未授权的攻击者可利用漏洞获取受影响组件敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://kc.mcafee.com/corporate/index?page=content&id=SB10279

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-537


【漏洞名称】Paessler AG PRTG Network Monitor 跨站脚本漏洞

【漏洞编号】CNNVD-201904-560（CVE-2018-14683）

【漏洞详情】Paessler AG PRTG Network Monitor是德国Paessler AG公司的一款全功能网络监控管理软件。

Paessler AG PRTG Network Monitor 19.1.49.1966之前版本中的WEBGUI存在跨站脚本漏洞，该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.paessler.com/prtg/history/stable

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-560
