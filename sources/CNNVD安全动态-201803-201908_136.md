今日CNNVD共发布安全漏洞31个。主要影响厂商为中国联想（2个）。主要影响产品为Lenovo 510-15IKL台式电脑（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******多款Lenovo产品安全漏洞****

**【漏洞编号】******CNNVD-201904-304********（CVE-2019-6156）****

**【漏洞详情】**Lenovo 510-15IKL等都是中国联想（Lenovo）公司的一款台式电脑。

多款Lenovo产品中存在安全漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。以下产品受到影响：Lenovo 510-15IKL；510S-08IKL；IdeaCentre 300-20ISH；IdeaCentre 300S-11ISH；IdeaCentre 510-15ICB；IdeaCentre 510A-15ICB；IdeaCentre 620s-03IKL等。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.lenovo.com/us/zh/product\_security/len-26332

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-304

  

**【漏洞名称】**************Symantec Endpoint Encryption 权限许可和访问控制问题漏洞************  

**【漏洞编号】**********CNNVD-201904-307********（CVE-2019-9694）********

**【漏洞详情】**Symantec Endpoint Encryption（SEE）是美国赛门铁克（Symantec）公司的一套为台式机、笔记本电脑和可移动存储设备提供了高级加密和管理功能的软件。

Symantec SEE 11.2.1 MP1之前版本中存在提权漏洞，该漏洞源于网络系统或产品缺乏有效的权限许可和访问控制措施。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.symantec.com/en\_US/article.SYMSA1478.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-307

  

**【漏洞名称】******Capsule Technologies SmartLinx Neuron 安全漏洞****

**【漏洞编号】**********CNNVD-201904-310**************（CVE-2019-5024）******

**【漏洞详情】**Capsule Technologies SmartLinx Neuron是美国Capsule Technologies公司的一套医疗设备信息系统。

Capsule Technologies SmartLinx Neuron 2 6.9.1版本中的‘kiosk mode’函数存在安全漏洞。攻击者可通过使用键盘或其他HID设备利用该漏洞获取底层操作系统的全部管理员权限。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.capsuletech.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-310

  

**【漏洞名称】********INSIDE Secure TLS Toolkit 缓冲区错误漏洞******

**【****漏洞****编号****】********CNNVD-201904-329（**CVE-2019-10914）****

**【漏洞详情】**INSIDE Secure MatrixSSL是法国INSIDE Secure公司的一个针对小型应用程序和设备而设计的嵌入式、开源SSLv3协议栈。

Inside Secure TLS Toolkit 4.0.2及之前版本中使用的MatrixSSL的pubRsaDecryptSignedElementExt存在基于栈的缓冲区溢出漏洞，该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/matrixssl/matrixssl/releases/tag/4-0-2-open

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-329
