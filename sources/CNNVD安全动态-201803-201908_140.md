今日CNNVD共发布安全漏洞41个。主要影响厂商为美国Apple（25个）、美国IBM（4个）。主要影响产品为Apple iOS操作系统（18个）、IBM Cloud Private解决方案（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】**********多款Apple产品WebKit组件竞争条件问题漏洞********

**【漏洞编号】******CNNVD-201904-132********（CVE-2018-4266）****

**【漏洞详情】**Apple iOS等都是美国苹果（Apple）公司的产品。Apple iOS是为移动设备所开发的一套操作系统。tvOS是一套智能电视操作系统。Safari是开发的一款Web浏览器，是MacOSX和iOS操作系统附带的默认浏览器。WebKit是其中的一个Web浏览器引擎组件。

多款Apple产品中的WebKit组件存在竞争条件问题漏洞，该漏洞源于网络系统或产品在运行过程中，并发代码需要互斥地访问共享资源时，对于并发访问的处理不当。以下产品和版本受到影响：Apple iOS 11.4.1之前版本；tvOS 11.4.1之前版本；watchOS 4.3.2之前版本；Safari 11.1.2之前版本；基于Windows平台的iTunes 12.8之前版本；基于Windows平台的iCloud 7.6之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/kb/HT208932

https://support.apple.com/kb/HT208933

https://support.apple.com/kb/HT208934

https://support.apple.com/kb/HT208935

https://support.apple.com/kb/HT208936

https://support.apple.com/kb/HT208938

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-132

  

**【漏洞名称】**************IBM Cloud Private 安全漏洞************  

**【漏洞编号】**********CNNVD-201904-148********（CVE-2019-4143）********

**【漏洞详情】**IBM Cloud Private是美国IBM公司的一套企业私有云解决方案。该产品主要基于Kubernetes和容器技术搭建。

IBM Cloud Private 3.1.1版本和3.1.2版本中存在安全漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10878180

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-148

  

**【漏洞名称】******Plataformatec Devise 安全漏洞****

**【漏洞编号】**********CNNVD-201904-117**（CVE-2019-5421）******

**【漏洞详****情】**Plataformatec Devise是巴西Plataformatec公司的一款基于Warden的Rails身份验证解决方案。

Plataformatec Devise 4.5.0及之前版本中的‘Devise::Models::Lockable’类的‘\`#increment\_failed\_attempts’方法存在安全漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/plataformatec/devise/issues/4981

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-117

  

**【漏洞名称】********http-live-simulator 路径遍历漏洞******

**【****漏洞****编号****】********CNNVD-201904-119（**CVE-2019-5423）****

**【漏洞详情】**http-live-simulator是一款HTTP文件服务器。

http-live-simulator npm包1.0.5版本中存在路径遍历漏洞，该漏洞源于网络系统或产品未能正确地过滤资源或文件路径中的特殊元素。攻击者可利用该漏洞访问受限目录之外的位置。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/prahladyeri/http-live-simulator/commit/8e85a1be562248d0d616c0e5092a3d71bbf5fe5f

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-119
