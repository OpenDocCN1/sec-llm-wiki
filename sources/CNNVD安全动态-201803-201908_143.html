今日CNNVD共发布安全漏洞43个。主要影响厂商为中国群晖科技（20个）、意大利OverIT（4个）。主要影响产品为Synology DiskStation Manager操作系统（5个）、OverIT Geocall解决方案（4个）。

今日需关注的典型漏洞如下:

【漏洞名称】Synology DiskStation Manager 安全漏洞

【漏洞编号】CNNVD-201904-007（CVE-2018-13286）

【漏洞详情】Synology DiskStation Manager（DSM）是中国台湾群晖科技（Synology）公司的一套用于网络储存服务器（NAS）上的操作系统。该操作系统可管理资料、文件、照片、音乐等信息。

Synology DSM 6.2-23739-1之前版本中的synouser.conf文件存在安全漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.synology.cn/zh-cn/security/advisory/Synology_SA_18_33

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-007


【漏洞名称】OverIT Geocall 跨站脚本漏洞

【漏洞编号】CNNVD-201904-022（CVE-2019-5888）

【漏洞详情】OverIT Geocall是意大利OverIT公司的一套现场服务管理解决方案。

OverIT Geocall build 2:346977之前的6.3版本中存在跨站脚本漏洞，该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.overit.it/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-022


【漏洞名称】Grandstream GXP16xx VoIP 安全漏洞

【漏洞编号】CNNVD-201904-033（CVE-2018-17564）

【漏洞详情】Grandstream GXP16xx VoIP是美国潮流网络（Grandstream）公司的一款16XX系列IP电话。

Grandstream GXP16xx VoIP 1.0.4.128版本中的/cgi-bin/delete_CA脚本存在安全漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.grandstream.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201904-033


【漏洞名称】Google Kubernetes CNI Portmap Plugin 安全漏洞

【漏洞编号】CNNVD-201903-1234（CVE-2019-9946）

【漏洞详情】Google Kubernetes是美国谷歌（Google）公司的一套开源的Docker容器集群管理系统。该系统为容器化的应用提供资源调度、部署运行、服务发现和扩容缩容等功能。CNI Portmap Plugin是其中的一个插件。

Google Kubernetes中的CNI Portmap Plugin 0.7.5版本存在安全漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。以下版本受到影响：Google Kubernetes 1.11.9版本，1.12.7版本，1.13.5版本，1.14.0版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://kubernetes.io/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-1234
