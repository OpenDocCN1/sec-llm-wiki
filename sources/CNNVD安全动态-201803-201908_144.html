今日CNNVD共发布安全漏洞65个。主要影响厂商为美国IBM（11个）、美国Grandstream（9个）。主要影响产品为IBM Security Privileged Identity Manager解决方案（7个）、Grandstream GWN7000路由器（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】IBM Security Privileged Identity Manager 安全漏洞

【漏洞编号】CNNVD-201903-1205（CVE-2018-1625）

【漏洞详情】IBM Security Privileged Identity Manager（ISPIM）是美国IBM公司的一款身份监管解决方案（IBM Identity Governance and Management）中的身份管理产品。该产品主要用于保护、自动执行并审计特权身份的使用，以帮助抵御内部威胁并提高安全性。

IBM ISPIM 2.1.1版本中存在安全漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10879093

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-1205


【漏洞名称】Grandstream GWN7000 安全漏洞

【漏洞编号】CNNVD-201903-1221（CVE-2019-10656）

【漏洞详情】Grandstream GWN7000是美国潮流网络（Grandstream）公司的一款企业级VPN路由器。

Grandstream GWN7000 1.0.6.32之前版本中存在安全漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.grandstream.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-1221


【漏洞名称】VMware ESXi 安全漏洞

【漏洞编号】CNNVD-201903-1197（CVE-2019-5514）

【漏洞详情】VMware Fusion是美国威睿（VMware）公司的一套专用于在苹果机（Mac）上运行Windows应用程序的的虚拟机软件。

VMware Fusion 11.x版本中存在安全漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.vmware.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-1197


【漏洞名称】ImageMagick Studio ImageMagick 缓冲区错误漏洞

【漏洞编号】CNNVD-201903-1217（CVE-2019-10650）

【漏洞详情】ImageMagick Studio ImageMagick是美国ImageMagick Studio公司的一套开源的图像处理软件。该软件可读取、转换或写入多种格式的图片。

ImageMagick Studio ImageMagick 7.0.8-36 Q16版本中的coders/tiff.c文件的‘WriteTIFFImage’函数存在堆缓冲区溢出漏洞，该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/issues/1532

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-1217
