今日CNNVD共发布安全漏洞35个。主要影响厂商为英国Micro Focus（6个）、美国Jenzabar（2个）。主要影响产品为Micro Focus ArcSight Logger日志管理软件（6个）、Jenzabar Internet Campus Solution学校管理系统（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】**********Micro Focus ArcSight Logger 跨站脚本漏洞********

**【漏洞编号】******CNNVD-201903-901********（CVE-2019-3480）****

**【漏洞详情】**Micro Focus ArcSight Logger是英国Micro Focus公司的一套日志管理软件。该软件能够收集并整合来自任何日志生成来源的数据，用于日志管理、搜索、编制索引、报告、分析和保留。

Micro Focus ArcSight Logger 6.7之前版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://softwaresupport.softwaregrp.com/doc/KM03355866

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-901

  

**【漏洞名称】******Jenzabar Internet Campus Solution 安全漏洞****  

**【漏洞编号】********CNNVD-201903-913**（CVE-2019-10011）****

**【漏洞详情】**Jenzabar Internet Campus Solution（JICS）是美国Jenzabar公司的一套学校管理系统。该系统包括课程管理、招生管理、财务管理和人力资源管理等功能。

Jenzabar JICS 2019-02-06之前版本中的ICS/StaticPages/AddTestUsers.aspx页面存在安全漏洞。远程攻击者可利用该漏洞创建密码为1234的任意数量的账户。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.jenzabar.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-913

  

**【漏洞名称】******Atlassian Confluence Server 安全漏洞****

**【漏洞编号】**********CNNVD-201903-909**（CVE-2019-3396）******

**【漏洞详****情】**Atlassian Confluence Server是澳大利亚Atlassian公司的一套专业的企业知识管理与协同软件，也可以用于构建企业WiKi。

Atlassian Confluence Server中存在安全漏洞。远程攻击者可借助Widget Connector宏利用该漏洞执行代码。以下版本受到影响：Atlassian Confluence Server 6.6.12之前版本，6.7.0版本至6.12.3之前版本，6.13.0版本至6.13.3之前版本，6.14.0版本至6.14.2之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://jira.atlassian.com/browse/CONFSERVER-57974

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-909

  

**【漏洞名称】********Pivotal Software Concourse SQL注入漏洞******

**【****漏洞****编号****】********CNNVD-201903-930**（CVE-2019-3792）****

**【漏洞详情】**Pivotal Software Concourse是美国Pivotal Software公司的一套用于持续开发的软件交付控制系统。

Pivotal Software Concourse 5.0.1之前版本中的API存在SQL注入漏洞。远程攻击者可借助版本标识符利用该漏洞读取特权数据。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://pivotal.io/security/cve-2019-3792

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-930
