今日CNNVD共发布安全漏洞52个。主要影响厂商为美国F5（6个）、美国ImageMagick Studio（1个）、美国IBM（1个）。主要影响产品为F5 BIG-IP应用交付平台（6个）、ImageMagick Studio ImageMagick图像处理软件（1个）、IBM WebSphere Application Server应用服务器（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】F5 BIG-IP 安全漏洞

【漏洞编号】CNNVD-201903-859（CVE-2019-6603）

【漏洞详情】F5 BIG-IP是美国F5公司的一款集成了网络流量管理、应用程序安全管理、负载均衡等功能的应用交付平台。

F5 BIG-IP中存在安全漏洞。攻击者可借助畸形的TCP数据包利用该漏洞造成拒绝服务。以下版本受到影响：F5 BIG-IP 13.0.0版本至13.0.1版本，12.1.0版本至12.1.3版本，11.6.0版本至11.6.3版本，11.5.1版本至11.5.8版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.f5.com/csp/article/K14632915

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-859


【漏洞名称】ImageMagick Studio ImageMagick 缓冲区错误漏洞

【漏洞编号】CNNVD-201903-878（CVE-2019-9956）

【漏洞详情】ImageMagick Studio ImageMagick是美国ImageMagick Studio公司的一套开源的图像处理软件。该软件可读取、转换或写入多种格式的图片。

ImageMagick Studio ImageMagick 7.0.8-35 Q16版本中的coders/ps.c文件的‘PopHexPixel’函数存在基于栈的缓冲区溢出漏洞。攻击者可借助特制的图像文件利用该漏洞造成拒绝服务或执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/issues/1523

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-878


【漏洞名称】IBM WebSphere Application Server 安全漏洞

【漏洞编号】CNNVD-201903-862（CVE-2019-4046）

【漏洞详情】IBM WebSphere Application Server（WAS）是美国IBM公司的一款应用服务器产品。该产品是JavaEE和Web服务应用程序的平台，也是IBMWebSphere软件平台的基础。

IBM WAS中存在拒绝服务漏洞，该漏洞源于程序没有正确地处理请求报头。攻击者可利用该漏洞造成拒绝服务。以下版本受到影响：IBM WAS Liberty版本，9.0版本，8.5版本，8.0版本，7.0版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10869570

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-862


【漏洞名称】Mozilla Firefox 安全漏洞

【漏洞编号】CNNVD-201903-895（CVE-2019-9813）

【漏洞详情】Mozilla Firefox是美国Mozilla基金会的一款开源Web浏览器。

Mozilla Firefox 66.0.1之前版本中存在安全漏洞。攻击者可利用该漏洞任意读取和写入内存。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.mozilla.org/en-US/security/advisories/mfsa2019-09/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-895
