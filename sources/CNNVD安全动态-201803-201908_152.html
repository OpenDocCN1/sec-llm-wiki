今日CNNVD共发布安全漏洞151个。主要影响厂商为美国Flexera Software（3个）、美国Artifex Software（2个）、美国IBM（2个）。主要影响产品为Flexera Software FlexNet Publisher解决方案（3个）、Artifex Software Ghostscript解析器（2个）、IBM Content Navigator Web客户机（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Flexera Software FlexNet Publisher 安全漏洞

【漏洞编号】CNNVD-201903-819（CVE-2018-20031）

【漏洞详情】Flexera Software FlexNet Publisher（FLEXlm）是美国Flexera Software公司的一款授权关系管理解决方案（Entitlement Relationship Management Solution）中的软件授权管理核心组件。该产品可为软件与硬件生产商提供定价、打包和定制软件授权期限。

Flexera Software FlexNet Publisher 11.16.1.0及之前的版本中存在拒绝服务漏洞。远程攻击者可利用该漏洞造成lmgrd和厂商守护进程之间的heartbeat组件停止运行，关闭厂商守护进程。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://secuniaresearch.flexerasoftware.com/advisories/85979/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-819


【漏洞名称】Artifex Software Ghostscript 安全漏洞

【漏洞编号】CNNVD-201903-842（CVE-2019-3835）

【漏洞详情】Artifex Software Ghostscript是美国Artifex Software公司的一款开源的PostScript（一种用于电子产业和桌面出版领域的页面描述语言和编程语言）解析器。该产品可显示Postscript文件以及在非Postscript打印机上打印Postscript文件。

Artifex Software Ghostscript中存在安全漏洞，该漏洞源于在内部词典中可以使用superexec operator。攻击者可借助特制的PostScript文件利用该漏洞绕过-dSAFER限制，访问受限目录之外的文件系统。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.ghostscript.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-842


【漏洞名称】IBM Content Navigator 安全漏洞

【漏洞编号】CNNVD-201903-834（CVE-2019-4035）

【漏洞详情】IBM Content Navigator是美国IBM公司的一款Web客户机。该产品支持从Web浏览器搜索和处理存储在内容服务器中的文档。

IBM Content Navigator 3.0 Continuous Delivery版本中存在安全漏洞。攻击者可借助伪造的IBM Content Navigator网站利用该漏洞直接向Edit客户端发送请求，造成客户端下载该ICN网站的文档。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10869060

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-834


【漏洞名称】JFrog Artifactory 安全漏洞

【漏洞编号】CNNVD-201903-827（CVE-2019-9733）

【漏洞详情】JFrog Artifactory是以色列JFrog公司的一款开源的通用Artifact存储库管理器，它支持集群和高可用性Docker注册表，并提供端到端的用于跟踪从开发到生产的工件自动化解决方案。

JFrog Artifactory 6.8.7之前版本中存在安全漏洞。攻击者可利用该漏洞绕过白名单，获取Artifactory服务器的管理权限。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://jfrog.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-827
