今日CNNVD共发布安全漏洞25个。主要影响厂商为加拿大Threshold（5个）、美国HID Global（4个）。主要影响产品为Threshold eVisitorPass访客管理系统（5个）、HID Global EasyLobby Solo访客管理软件（4个）。

今日需关注的典型漏洞如下:

【漏洞名称】Threshold eVisitorPass 权限许可和访问控制漏洞

【漏洞编号】CNNVD-201903-608（CVE-2018-17494）

【漏洞详情】Threshold eVisitorPass是加拿大Threshold公司的一套访客管理系统。

Threshold eVisitorPass 1.5.5.2版本中的虚拟键盘启动菜单存在提取漏洞。本地攻击者可利用该漏洞关闭应用程序并启动其他进程。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://support.evisitorpass.com/Release_Notes.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-608


【漏洞名称】HID Global EasyLobby Solo 安全漏洞

【漏洞编号】CNNVD-201903-614（CVE-2018-17491）

【漏洞详情】HID Global EasyLobby Solo是美国HID Global公司的一套安全访客管理 (SVM) 软件。

HID Global EasyLobby Solo 11.0.4563版本中存在安全漏洞。本地攻击者可利用该漏洞在电脑上执行未授权的操作。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.hidglobal.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-614


【漏洞名称】Apache Hadoop 安全漏洞

【漏洞编号】CNNVD-201903-626（CVE-2018-11767）

【漏洞详情】Apache Hadoop是美国阿帕奇（Apache）软件基金会的一套开源的分布式系统基础架构。该产品能够对大量数据进行分布式处理，并具有高可靠性、高扩展性、高容错性等特点。

Apache Hadoop 2.9.0版本至2.9.1版本、2.8.3版本至2.8.4版本和2.7.5版本至2.7.6版本中存在安全绕过漏洞。攻击者可利用该漏洞绕过安全限制并执行未授权的操作。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://hadoop.apache.org/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-626


【漏洞名称】Five9 Agent Desktop Plus 访问控制错误漏洞

【漏洞编号】CNNVD-201903-604（CVE-2018-15509）

【漏洞详情】Five9 Agent Desktop Plus是美国Five9公司的一套基于云的联络中心软件。

Five9 Agent Desktop Plus 10.0.70版本中存在访问控制错误漏洞。远程攻击者可利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.five9.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-604
