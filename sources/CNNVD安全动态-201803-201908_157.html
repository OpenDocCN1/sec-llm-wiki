今日CNNVD共发布安全漏洞26个。主要影响厂商为丹麦CapMon（5个）、美国VMware（3个）、美国IBM（1个）。主要影响产品为CapMon Access Manager访问管理软件（5个）、VMware Workstation虚拟机（2个）、IBM WebSphere MQ中间件（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】CapMon Access Manager 访问控制错误漏洞

【漏洞编号】CNNVD-201903-586（CVE-2018-18256）

【漏洞详情】CapMon Access Manager是丹麦CapMon公司的一套访问管理软件。该软件支持应用程序白名单/黑名单、审计日志等功能。

CapMon Access Manager 5.4.1.1005版本中AccessManagerCoreService.exe和TaskTrayApplication.exe文件存在访问控制错误漏洞。本地攻击者可利用该漏洞获取管理员权限。

目前厂商已发布新版本，以修复此安全问题，详情请关注厂商主页：

https://capmon.dk/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-586


【漏洞名称】VMware Workstation 权限许可和访问控制漏洞

【漏洞编号】CNNVD-201903-580（CVE-2019-5511）

【漏洞详情】VMware Workstation是美国威睿（VMware）公司的一套虚拟机软件。该软件提供可以同时运行多个不同的操作系统的虚拟机功能。

VMware Workstation 15.x版本和14.x版本中存在提权漏洞。攻击者可利用该漏洞获取提升的权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.vmware.com/security/advisories/VMSA-2019-0002.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-580


【漏洞名称】IBM MQ Console 跨站脚本漏洞

【漏洞编号】CNNVD-201903-598（CVE-2018-1836）

【漏洞详情】IBM MQ（IBM WebSphere MQ）是美国IBM公司的一款消息传递中间件产品。该产品主要为面向服务的体系结构（SOA）提供可靠的、经过验证的消息传递主干网。

IBM MQ（CD）9.0.2版本至9.0.5版本和MQ（LTS）9.1.0.0版本至9.1.0.1版本中的控制台存在跨站脚本漏洞。远程攻击者可利用该漏洞向Web UI注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10734457

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-598


【漏洞名称】Fujitsu Wireless Keyboard Set LX901 GK900 receiver组件安全漏洞

【漏洞编号】CNNVD-201903-594（CVE-2019-9835）

【漏洞详情】Fujitsu Wireless Keyboard Set LX901 GK900是日本富士通（Fujitsu）公司的一款无线键盘。receiver是它的接收器组件。

Fujitsu Wireless Keyboard Set LX901 GK900中的receiver组件存在安全漏洞，该漏洞源于即使全部的合法通信都使用了AES，程序还会接收到未加密的2.4 GHz数据包。攻击者可利用该漏洞注入键击。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

http://www.fujitsu.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-594
