今日CNNVD共发布安全漏洞68个。主要影响厂商为美国Intel（40个）、中国联想（1个）。主要影响产品为Intel Graphics Driver for Windows显卡驱动程序（16个）、Lenovo Dynamic Power Reduction Utility实用程序（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Intel Graphics Driver for Windows User Mode Driver 安全漏洞

【漏洞编号】CNNVD-201903-518（CVE-2018-12210）

【漏洞详情】Intel Graphics Driver for Windows是美国英特尔（Intel）公司的一款适用于Windows平台的显卡驱动程序。User Mode Driver是其中的一个用户模式驱动程序。

基于Windows平台的Intel Graphics Driver中的User Mode Driver存在安全漏洞。本地攻击者可利用该漏洞造成拒绝服务。以下版本受到影响：Intel Graphics Driver 10.18.x.5059之前版本，10.18.x.5057之前版本，20.19.x.5063之前版本，21.20.x.5064之前版本，24.20.100.6373之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.intel.com/content/www/us/en/security-center/advisory/intel-sa-00189.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-518


【漏洞名称】Lenovo Dynamic Power Reduction Utility 安全漏洞

【漏洞编号】CNNVD-201903-577（CVE-2019-6149）

【漏洞详情】Lenovo Dynamic Power Reduction Utility是中国联想（Lenovo）公司的一款用于降低动态电源功耗的实用程序。

Lenovo Dynamic Power Reduction Utility中存在安全漏洞。本地攻击者可利用该漏洞以管理权限执行代码。以下产品受到影响：Lenovo ThinkPad X1 Carbon 20KH；ThinkPad X1 Carbon 20KG。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.lenovo.com/us/zh/solutions/len-25674

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-577


【漏洞名称】Red Hat libvirt 安全漏洞

【漏洞编号】CNNVD-201903-572（CVE-2019-3840）

【漏洞详情】Red Hat libvirt是美国红帽（Red Hat）公司的一个用于实现Linux虚拟化功能的Linux API，它支持各种Hypervisor，包括Xen和KVM，以及QEMU和用于其他操作系统的一些虚拟产品。

Red Hat libvirt中（通过QEMU代理）接收接口消息的方法存在空指针逆向引用漏洞。攻击者可利用该漏洞造成libvirtd崩溃，导致拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://libvirt.org/git/?p=libvirt.git;a=commit;h=7cfd1fbb1332ae5df678b9f41a62156cb2e88c73

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-572


【漏洞名称】LCDS LAquis SCADA 缓冲区错误漏洞

【漏洞编号】CNNVD-201903-575（CVE-2019-6536）

【漏洞详情】LCDS LAquis SCADA是巴西LCDS公司的一套SCADA（数据采集与监视控制）系统。该系统主要用于对拥有通信技术的设备进行数据采集和过程控制。

LCDS LAquis SCADA中存在越界写入漏洞。远程攻击者可借助特制的ELS文件利用该漏洞在当前进程的上下文中执行代码。

目前厂商已发布新版本，以修复此安全问题，详情请关注厂商主页：

https://laquisscada.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-575
