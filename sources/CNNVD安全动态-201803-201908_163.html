今日CNNVD共发布安全漏洞57个。主要影响厂商为美国Motorola（5个）、中国五指（2个）、美国IBM（1个）。主要影响产品为Motorola C1智能手机（5个）、WUZHI CMS内容管理系统（2个）、IBM API Connect解决方案（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Motorola C1和Motorola M2 命令注入漏洞

【漏洞编号】CNNVD-201903-254（CVE-2019-9117）

【漏洞详情】Motorola C1和Motorola M2都是美国摩托罗拉（Motorola）公司的一款智能手机。

使用1.01版本固件的Motorola C1和使用1.07版本固件的Motorola M2中存在命令注入漏洞。远程攻击者可借助特制的请求利用该漏洞执行任意的操作系统命令。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.motorola.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-254


【漏洞名称】WUZHI CMS 跨站脚本漏洞

【漏洞编号】CNNVD-201903-241（CVE-2018-17425）

【漏洞详情】WUZHI CMS是中国五指（WUZHI）公司的一套基于PHP和MySQL的开源内容管理系统（CMS）。

WUZHI CMS 4.1.0版本中存在跨站脚本漏洞。攻击者可借助‘我要提问’页面中的‘详细描述’字段利用该漏洞注入任意的Web脚本或HTML。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.wuzhicms.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-241


【漏洞名称】IBM API Connect 信息泄露漏洞

【漏洞编号】CNNVD-201903-260（CVE-2018-2009）

【漏洞详情】IBM API Connect（APIConnect）是美国IBM公司的一套用于管理API生命周期的集成解决方案。该产品支持创建、运行、管理和保护API和微服务等。

IBM API Connect 2018.1版本至2018.4.1版本中的consumer API存在信息泄露漏洞。攻击者可利用该漏洞获取其他用户的信息列表，包括email id、用户名等。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10794327

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-260


【漏洞名称】ImageMagick Studio ImageMagick 安全漏洞

【漏洞编号】CNNVD-201903-247（CVE-2019-7175）

【漏洞详情】ImageMagick Studio ImageMagick是美国ImageMagick Studio公司的一套开源的图像处理软件。该软件可读取、转换或写入多种格式的图片。

ImageMagick 7.0.8-25之前版本中的coders/pcd.c文件的DecodeImage存在安全漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/commit/1e6a3ace073c9ec9c71e439c111d23c6e66cb6ae

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-247
