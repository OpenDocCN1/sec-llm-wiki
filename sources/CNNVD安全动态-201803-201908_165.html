今日CNNVD共发布安全漏洞59个。主要影响厂商为美国Cisco（33个）、中国中天（10个）、美国TIBCO Software（1个）。主要影响产品为Cisco Application Policy Infrastructure Controller解决方案（1个）、中天网络科技OFCMS内容管理系统（10个）、TIBCO Software Jaspersoft JasperReports Server报表生成工具（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Cisco Application Policy Infrastructure Controller 访问控制错误漏洞

【漏洞编号】CNNVD-201903-203（CVE-2019-1690）

【漏洞详情】Cisco Application Policy Infrastructure Controller（APIC）是美国思科（Cisco）公司的一款自动化的基础架构部署和治理解决方案。

Cisco APIC中的管理界面存在访问控制错误漏洞，该漏洞源于程序缺少IPv6 link-local链接的访问控制机制。攻击者可利用该漏洞绕过默认的访问控制限制。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20190306-apic-ipv6

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-203


【漏洞名称】中天网络科技 OFCMS 安全漏洞

【漏洞编号】CNNVD-201903-194（CVE-2019-9610）

【漏洞详情】中天网络科技 OFCMS是中国中天网络科技公司的一套使用Java语言开发的内容管理系统（CMS）。

中天网络科技  OFCMS 1.1.3之前版本中存在安全漏洞。攻击者可利用该漏洞列出根目录下的文件夹并且可以跳转到其他目录。

目前厂商已发布新版本，以修复此安全问题，详情请关注厂商主页：

http://www.ofsoft.cn/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-194


【漏洞名称】TIBCO Software Jaspersoft JasperReports Server 安全漏洞

【漏洞编号】CNNVD-201903-201（CVE-2018-18815）

【漏洞详情】TIBCO Software Jaspersoft JasperReports Server是美国TIBCO Software公司的一款报表生成工具。该产品支持PDF、HTML、XLS、CSV和XML文件输出格式。

TIBCO Software Jaspersoft JasperReports Server中的ResourceForwardingServlet的doGet方法存在安全漏洞，该漏洞源于程序没有正确地过滤URLs。攻击者可利用该漏洞绕过系统上的身份验证。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.tibco.com/support/advisories/2019/03/tibco-security-advisory-march-6-2019-tibco-jasperreports-server-2018-18815

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-201


【漏洞名称】Xpdf 安全漏洞

【漏洞编号】CNNVD-201903-190（CVE-2019-9589）

【漏洞详情】Xpdf是Foo实验室的一款开源的PDF阅读器。该产品支持解码LZW压缩格式的文件以及阅读加密的PDF文件。

Xpdf 4.01版本中的PSOutputDev.cc文件的‘PSOutputDev::setupResources()’函数存在空指针逆向引用漏洞。攻击者可借助特制的pdf文件利用该漏洞造成拒绝服务（段错误）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://forum.xpdfreader.com/viewtopic.php?f=3&t=41262

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-190
