# CNNVD最新漏洞（2019-03-07）

今日CNNVD共发布安全漏洞90个。主要影响厂商为美国Google（33个）、美国Qualcomm（5个）、美国IBM（4个）。主要影响产品为Android操作系统（33个）、Qualcomm MDM9607中央处理器（2个）、IBM WebSphere Application Server应用服务器（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】**********Android 安全漏洞********

**【漏洞编号】******CNNVD-201903-093********（CVE-2019-2025）****

**【漏洞详情】**Android是美国谷歌（Google）和开放手持设备联盟（简称OHA）的一套以Linux为基础的开源操作系统。

Android中的Binder驱动程序存在提权漏洞。攻击者可利用该漏洞以提升的权限执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2019-03-01.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-093

  

**【漏洞名称】******多款Qualcomm产品访问控制错误漏洞****  

**【漏洞编号】********CNNVD-201903-137**（CVE-2018-11958）****

**【漏洞详情】**Qualcomm MDM9607等都是美国高通（Qualcomm）公司的一款中央处理器（CPU）产品。

多款Qualcomm产品中的Content Protection存在访问控制错误漏洞。攻击者可利用该漏洞获取敏感的键区输入数据的访问权限。以下产品受到影响：Qualcomm MDM9206；MDM9607；MDM9650；MDM9655；Qualcomm 215；SD 210；SD 212；SD 205；SD 410/12；SD 425；SD 427；SD 430；SD 435；SD 439；SD 429；SD 450；SD 615/16；SD 415；SD 625；SD 632；SD 636；SD 650/52；SDA660；SDM439；SDM630；SDM660；Snapdragon\_High\_Med\_2016。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2019-03-01.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-137

  

**【漏洞名称】******IBM WebSphere Application Server 跨站脚本漏洞****

**【漏洞编号】**********CNNVD-201903-088**（CVE-2019-4030）******

**【漏洞详****情】**IBM WebSphere Application Server（WAS）是美国IBM公司的一款应用服务器产品。该产品是JavaEE和Web服务应用程序的平台，也是IBMWebSphere软件平台的基础。

IBM WAS中存在跨站脚本漏洞。远程攻击者可利用该漏洞向Web UI中注入任意的JavaScript代码。以下版本受到影响：IBM WAS 9.0版本，8.5版本，8.0版本，7.0版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=ibm10869406

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-088

  

**【漏洞名称】********Apple macOS Mojave 缓冲区错误漏洞******

**【****漏洞****编号****】********CNNVD-201903-075**（CVE-2019-6220）****

**【漏洞详情】**Apple macOS Mojave是美国苹果（Apple）公司的一套专为Mac计算机所开发的专用操作系统。

Apple macOS Mojave 10.14.3之前版本中存在越界读取漏洞。本地攻击者可利用该漏洞读取受限制的内存。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/zh-cn/HT209446

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-075

  

**【漏洞名称】********Samsung Galaxy S9 安全漏洞******

**【****漏洞****编号****】********CNNVD-201903-140**（CVE-2019-6741）****

**【漏洞详情】**Samsung Galaxy S9是韩国三星（Samsung）公司的一款智能手机。

Samsung Galaxy S9中的captive portal存在安全漏洞。远程攻击者可利用该漏洞在当前用户的上下文中执行代码。

目前厂商已发布新版本，以修复此安全问题，详情请关注厂商主页：

https://www.samsung.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-140
