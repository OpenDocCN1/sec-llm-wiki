今日CNNVD共发布安全漏洞24个。主要影响厂商为美国Google（2个）、美国Joyent（2个）。主要影响产品为Google Kubernetes集群管理系统（1个）、Joyent Node.js网络应用平台（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】**********Google Kubernetes 安全漏洞********

**【漏洞编号】******CNNVD-201903-042********（CVE-2019-1002100）****

**【漏洞详情】**Google Kubernetes是美国谷歌（Google）公司的一套开源的Docker容器集群管理系统。该系统为容器化的应用提供资源调度、部署运行、服务发现和扩容缩容等功能。

Google Kubernetes中存在安全漏洞。攻击者可借助‘json-patch’类型的补丁利用该漏洞消耗过量的资源，导致拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://discuss.kubernetes.io/t/kubernetes-security-announcement-v1-11-8-1-12-6-1-13-4-released-to-address-medium-severity-cve-2019-1002100/5147

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-042

  

**【漏洞名称】******Joyent Node.js 安全漏洞****  

**【漏洞编号】********CNNVD-201903-038**（CVE-2019-5737）****

**【漏洞详情】**Joyent Node.js是美国Joyent公司的一套建立在Google V8 JavaScript引擎之上的网络应用平台。该平台主要用于构建高度可伸缩的应用程序，以及编写能够处理数万条且同时连接到一个物理机的连接代码。

Joyent Node.js中存在拒绝服务漏洞，该漏洞源于程序没有控制资源的消耗。攻击者可利用该漏洞造成拒绝服务。以下版本受到影响：Joyent Node.js 6版本，8版本，10版本，11版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://nodejs.org/en/blog/vulnerability/february-2019-security-releases/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-038

  

**【漏洞名称】******IBM SDK, Java Technology Edition 安全漏洞****

**【漏洞编号】**********CNNVD-201903-037**（CVE-2018-1890）******

**【漏洞详****情】**IBM SDK, Java Technology Edition是美国IBM公司的一款用于Java应用程序开发的软件开发工具包。

基于AIX平台的IBM SDK, Java Technology Edition 8版本中存在安全漏洞。本地攻击者可利用该漏洞注入代码并提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.ibm.com/support/docview.wss?uid=ibm10873332

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-037

  

**【漏洞名称】********Microsoft Windows 安全漏洞******

**【****漏洞****编号****】********CNNVD-201903-053**（CVE-2019-5921）****

**【漏洞详情】**Microsoft Windows是美国微软（Microsoft）公司的一套个人设备使用的操作系统。

Microsoft Windows 7版本中存在远程代码执行漏洞。远程攻击者可利用该漏洞在当前用户的上下文中执行任意代码或造成拒绝服务。

目前厂商已发布新版本，以修复此安全问题，详情请关注厂商主页：

https://www.microsoft.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-053
