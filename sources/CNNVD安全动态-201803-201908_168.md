今日CNNVD共发布安全漏洞33个。主要影响厂商为美国IBM（9个）、美国Dell（3个）。主要影响产品为IBM InfoSphere Information Governance Catalog解决方案（1个）、Dell RSA Authentication Manager身份认证软件（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】**********IBM InfoSphere Information Governance Catalog和InfoSphere Information Server on Cloud 安全漏洞********

**【漏洞编号】******CNNVD-201903-010********（CVE-2018-1875）****

**【漏洞详情】**IBM InfoSphere Information Server on Cloud和IBM InfoSphere Information Governance Catalog（IGC,InfoSphere Business Information Exchange）都是美国IBM公司的产品。IBM InfoSphere Information Server on Cloud是一套基于云的数据整合平台。IBM InfoSphere Information Governance Catalog是一套提供了全面的信息整合功能和IT资产管理的解决方案。该产品支持创建一个终端到终端信息的蓝图和不同类型的信息集成和治理等。

IBM InfoSphere IGC和InfoSphere Information Server on Cloud中存在开放重定向漏洞。远程攻击者可通过诱使用户访问特制的网站利用该漏洞伪造URL，实施钓鱼攻击，获取敏感信息或实施其他攻击。以下产品和版本受到影响：IBM InfoSphere IGC 11.3版本，11.5版本，11.7版本；IBM InfoSphere Information Server on Cloud 11.5版本，11.7版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10738911

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-010

  

**【漏洞名称】******Dell RSA Authentication Manager 安全漏洞****  

**【漏洞编号】********CNNVD-201903-029**（CVE-2019-3711）****

**【漏洞详情】**Dell RSA Authentication Manager是美国戴尔（Dell）公司的一套集中式二元身份认证软件。该软件可跨物理站点集中管理二元身份认证、安全令牌、方法和用户等。

Dell RSA Authentication Manager 8.4及之前版本中存在安全漏洞。攻击者可利用该漏洞获取域密码的值。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.dellemc.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-029

  

**【漏洞名称】******Amazon Ring Doorbell 安全漏洞****

**【漏洞编号】**********CNNVD-201903-005**（CVE-2019-9483）******

**【漏洞详****情】**Amazon Ring Doorbell是美国亚马逊（Amazon）公司的一款可视门铃设备。

Amazon Ring Doorbell 3.4.7之前版本中存在安全漏洞，该漏洞源于程序错误地处理了加密过程。远程攻击者可利用该漏洞获取视频和音频数据或插入伪造的视频。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.amazon.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-005

  

**【漏洞名称】********Adobe ColdFusion 安全漏洞******

**【****漏洞****编号****】********CNNVD-201903-023**（CVE-2019-7816）****

**【漏洞详情】**Adobe ColdFusion是美国奥多比（Adobe）公司的一套快速应用程序开发平台。该平台包括集成开发环境和脚本语言。

Adobe ColdFusion 2018 Update 2及之前版本、2016 Update 9及之前版本和11 Update 17及之前版本中存在安全漏洞。攻击者可利用该漏洞绕过文件上传限制，执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://helpx.adobe.com/security/products/coldfusion/apsb19-14.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201903-023
