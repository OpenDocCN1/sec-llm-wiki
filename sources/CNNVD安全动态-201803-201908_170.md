今日CNNVD共发布安全漏洞22个。主要影响厂商为美国Pivotal Software（4个）、美国McAfee（3个）。主要影响产品为Pivotal Software Pivotal Application Service应用程序管理软件（1个）、McAfee Agent客户端组件（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】**********Pivotal Software Pivotal Application Service 安全漏洞********

**【漏洞编号】******CNNVD-201902-1012********（CVE-2019-3777）****

**【漏洞详情】**Pivotal Software Pivotal Application Service（PAS）是美国Pivotal Software公司的一套应用程序管理软件。

Pivotal Software PAS 2.2.12之前的2.2.x版本、2.3.7之前的2.3.x版本和2.4.3之前的2.4.x版本中存在安全漏洞，该漏洞源于使用云控制器代理的应用程序管理器没有验证SSL凭证。远程攻击者可通过劫持云控制器的DNS记录利用该漏洞拦截发送到Cloud Controller的访问令牌，进而访问到云控制器中用户的资源。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://pivotal.io/security/cve-2019-3777

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-1012

  

**【漏洞名称】******McAfee Agent 安全漏洞****  

**【漏洞编号】********CNNVD-201902-1001**（CVE-2019-3598）****

**【漏洞详情】**McAfee Agent（MA）是美国迈克菲（McAfee）公司的一套提供了ePolicy Orchestrator（杀毒软件管理平台）与被管理产品之间的安全通信的客户端组件。

McAfee MA 5.x版本中存在安全漏洞。远程攻击者可借助特制的UDP数据包利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://kc.mcafee.com/corporate/index?page=content&id=SB10272

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-1001

  

**【漏洞名称】******Digium Asterisk Open Source 安全漏洞****

**【漏洞编号】**********CNNVD-201902-1006**（CVE-2019-7251）******

**【漏洞详****情】**Digium Asterisk Open Source是美国Digium公司的一套开源的电话交换机（PBX）系统软件。该软件支持语音信箱、多方语音会议、交互式语音应答(IVR)等。

Digium Asterisk Open Source 15.x版本和16.x版本中存在安全漏洞。远程攻击者可利用该漏洞造成Asterisk崩溃。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.asterisk.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-1006

  

**【漏洞名称】********Huawei P20 安全漏洞******

**【****漏洞****编号****】********CNNVD-201902-996**（CVE-2019-5306）****

**【漏洞详情】**Huawei P20是中国华为（Huawei）公司的一款智能手机。

Huawei P20 Emily-AL00A 9.0.0.167(C00E81R1P21T8)之前的版本中存在安全漏洞。攻击者可通过在使用FRP重新设置手机过程中删除激活锁利用该漏洞绕过FRP功能并获取手机的使用权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20190228-01-smartphone-cn

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-996
