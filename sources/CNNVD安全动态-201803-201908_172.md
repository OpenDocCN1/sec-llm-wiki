今日CNNVD共发布安全漏洞20个。主要影响厂商为美国NVIDIA（7个）、美国Cisco（2个）。主要影响产品为NVIDIA Windows GPU Display Driver驱动程序（7个）、Cisco RV110W Wireless-N VPN Firewall路由器（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】**********NVIDIA Windows GPU Display Driver 安全漏洞********

**【漏洞编号】******CNNVD-201902-982********（CVE-2019-5667）****

**【漏洞详情】**NVIDIA Windows GPU Display Driver是美国英伟达（NVIDIA）公司的一款专用于Windows平台的图形处理器（GPU）显卡驱动程序。kernel mode layer (nvlddmkm.sys) handler是其中的一个内核模式层处理程序。

NVIDIA Windows GPU Display Driver中的kernel mode layer (nvlddmkm.sys) handler（用于DxgkDdiSetRootPageTable）存在安全漏洞。攻击者可利用该漏洞执行代码，造成拒绝服务或提升权限（空指针逆向引用）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://nvidia.custhelp.com/app/answers/detail/a\_id/4772

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-982

  

**【漏洞名称】******Cisco RV110W Wireless-N VPN Firewall、RV130W Wireless-N Multifunction VPN Router和RV215W Wireless-N VPN Router 缓冲区错误漏洞****  

**【漏洞编号】********CNNVD-201902-988**（CVE-2019-1663）****

**【漏洞详情】**Cisco RV110W Wireless-N VPN Firewall等都是美国思科（Cisco）公司的一款企业级路由器。

Cisco RV110W Wireless-N VPN Firewall、RV130W Wireless-N Multifunction VPN Router和RV215W Wireless-N VPN Router中基于Web的管理界面存在缓冲区错误漏洞，该漏洞源于程序没有正确地验证用户提交的数据。远程攻击者可通过发送恶意的HTTP请求利用该漏洞在底层操作系统上执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20190227-rmi-cmd-ex

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-988

  

**【漏洞名称】******NetApp Clustered Data ONTAP 安全漏洞****

**【漏洞编号】**********CNNVD-201902-978**（CVE-2019-5491）******

**【漏洞详****情】**NetApp Clustered Data ONTAP是美国NetApp公司的一套用于集群模式的存储操作系统。

NetApp Clustered Data ONTAP 9.1P15之前版本和9.3P7之前的9.3版本中存在安全漏洞。攻击者可利用该漏洞泄露敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://security.netapp.com/advisory/ntap-20190227-0001/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-978

  

**【漏洞名称】********Koji SQL注入漏洞******

**【****漏洞****编号****】********CNNVD-201902-972**（CVE-2018-100216）****

**【漏洞详情】**Koji是一套RPM构建系统。

Koji中存在SQL注入漏洞，该漏洞源于程序在构造SQL查询语句之前没有充分过滤用户提交的输入。远程攻击者可利用该漏洞控制应用程序，访问或修改数据，或利用底层数据库中潜在的漏洞。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://pagure.io/koji/issue/1183

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-972
