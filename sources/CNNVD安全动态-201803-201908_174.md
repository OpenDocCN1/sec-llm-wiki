今日CNNVD共发布安全漏洞42个。主要影响厂商为美国Qualcomm（3个）、美国IBM（2个）、德国Gurock Software（2个）。主要影响产品为Qualcomm MDM9206中央处理器（3个）、IBM Content Navigator Web客户机（1个）、Cordaware bestinformed群发通知系统（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******多款Qualcomm产品安全漏洞****

**【漏洞编号】******CNNVD-201902-922********（CVE-2018-13913）****

**【漏洞详情】**Qualcomm MDM9206等都是美国高通（Qualcomm）公司的产品。MDM9206是一款中央处理器（CPU）产品。SDX24是一款调制解调器。SD 425是一款中央处理器（CPU）产品。

多款Qualcomm产品中的Display存在安全漏洞，该漏洞源于程序没有正确地验证数组索引。攻击者可利用该漏洞获取未授权的访问权限。以下产品受到影响：Qualcomm MDM9150；MDM9206；MDM9607；MDM9640；MDM9650；MSM8909W；MSM8996AU；QCS605；SD；210；SD 212；SD 205；SD 425；SD 439；SD 429；SD 615/16；SD 415；SD 625；SD 636；SD 650/52；SD 712；SD 710；SD 670；SD 820A；SD 835；SD 845；SD 850；SD 855；SDA660；SDM439；SDM630；SDM660；SDX20；SDX24。   

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.codeaurora.org/security-bulletin/2019/02/04/february-2019-code-aurora-security-bulletin

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-922

  

**【漏洞名称】****IBM Content Navigator 安全漏洞**  

**【漏洞编号】******CNNVD-201902-930**（CVE-2018-1979）**

**【漏洞详情】**IBM Content Navigator是美国IBM公司的一款Web客户机。该产品支持从Web浏览器搜索和处理存储在内容服务器中的文档。

IBM Content Navigator 2.0.3版本和3.0CD版本中存在安全漏洞，该漏洞源于程序使用存储在源码中的公用密钥来加密及解密用户凭证。攻击者可通过反编译Java .class文件利用该漏洞解密用户名和密码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.ibm.com/support/docview.wss?uid=ibm10788123

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-930

  

**【漏洞名称】**********Cordaware bestinformed Microsoft Windows client 安全漏洞********

**【漏洞编号】**********CNNVD-201902-927**（CVE-2019-6266）******

**【漏洞详****情】**Cordaware bestinformed是德国Cordaware公司的一套群发通知系统。

Cordaware bestinformed Windows客户端 6.2.1.0之前版本中存在安全漏洞，该漏洞源于不安全的SSL证书检测及访问模式。远程攻击者可利用该漏洞将加密连接降级到非加密连接。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.cordaware.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-927

  

**【漏洞名称】********Gurock Software Gurock TestRail 安全漏洞******

**【****漏洞****编号****】********CNNVD-201902-925**（CVE-2018-20063）****

**【漏洞详情】**Gurock Software Gurock TestRail是德国Gurock Software公司的一套基于Web的、用于QA和开发团队的测试用例管理软件。该软件支持创建测试用例、管理测试套件和协调测试过程等。

Gurock Software Gurock TestRail 5.6.0.3853版本中的图像上传表单存在任意文件上传漏洞。远程攻击者可通过上传带有可执行扩展名的图像利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.gurock.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-925

  

**【漏洞名称】********Flexera Software FlexNet Publisher lmgrd和vendor daemon组件安全漏洞******

**【****漏洞****编号****】********CNNVD-201902-907**（CVE-2018-20033）****

**【漏洞详情】**Flexera Software FlexNet Publisher（FLEXlm）是美国Flexera Software公司的一款授权关系管理解决方案（Entitlement Relationship Management Solution）中的软件授权管理核心组件。该产品可为软件与硬件生产商提供定价、打包和定制软件授权期限。lmgrd和vendor daemon是都是其中的组件。

Flexera Software FlexNet Publisher 11.16.1.0及之前版本中的lmgrd和vendor daemon组件存在远程代码执行漏洞。远程攻击者可利用该漏洞损坏内存。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.flexera.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-907
