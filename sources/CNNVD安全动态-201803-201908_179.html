今日CNNVD共发布安全漏洞51个。主要影响厂商为美国Cisco（15个）、美国IBM（7个）、中国华为（3个）。主要影响产品为Cisco HyperFlex Software文件系统（4个）、IBM Security Identity Governance and Intelligence解决方案（5个）、Huawei Mate20智能手机（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Cisco HyperFlex Software 访问控制错误漏洞

【漏洞编号】CNNVD-201902-793（CVE-2019-1664）

【漏洞详情】Cisco HyperFlex Software是美国思科（Cisco）公司的一套套可扩展的分布式文件系统。该系统通过云管理提供统一的计算、存储和网络，并提供企业级数据管理和优化服务。

Cisco HyperFlex Software 3.5(2a)之前版本中的hxterm服务存在安全漏洞，该漏洞源于程序没有进行充分的身份验证控制。本地攻击者可通过连接hxterm服务利用该漏洞获取集群上所有节点的root访问权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bst.cloudapps.cisco.com/bugsearch/bug/CSCvj95590

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-793


【漏洞名称】IBM Security Identity Governance and Intelligence 安全漏洞

【漏洞编号】CNNVD-201902-763（CVE-2018-1946）

【漏洞详情】IBM Security Identity Governance and Intelligence（IGI）是美国IBM公司的一套身份治理解决方案。该产品包括生命周期管理、访问风险评估和身份认证管理等功能。

IBM Security IGI中存在安全漏洞，该漏洞源于Security Identity Governance Virtual Appliance没有对保护机制使用较强的算法。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。以下产品和版本受到影响：IBM Security IGI  5.2版本，5.2.1版本，5.2.2版本，5.2.2.1版本，5.2.3版本，5.2.3.1版本，5.2.3.2版本，5.2.4版本，5.2.4.1版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10872142

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-763


【漏洞名称】Huawei Mate20 缓冲区错误漏洞

【漏洞编号】CNNVD-201902-789（CVE-2019-5296）

【漏洞详情】Huawei Mate20是中国华为（Huawei）公司的一款智能手机。

Huawei Mate20 HMA-AL00C00B175之前版本中存在越界读取漏洞，该漏洞源于对输入校验不充分。攻击者可利用该漏洞造成设备异常。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20190220-01-phone-cn

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-789


【漏洞名称】CloudBees Jenkins Script Security Plugin 安全漏洞

【漏洞编号】CNNVD-201902-776（CVE-2019-1003024）

【漏洞详情】CloudBees Jenkins（Hudson Labs）是美国CloudBees公司的一套基于Java开发的持续集成工具。该产品主要用于监控持续的软件版本发布/测试项目和一些定时执行的任务。

Jenkins Script Security Plugin 1.52及之前版本中的RejectASTTransformsCustomizer.java文件存在沙盒绕过漏洞。攻击者可利用该漏洞在Jenkins master JVM上执行任意脚本代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://jenkins.io/security/advisory/2019-02-19/#SECURITY-1320

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-776


【漏洞名称】Atlassian Fisheye和Crucible 跨站脚本漏洞

【漏洞编号】CNNVD-201902-768（CVE-2018-20240）

【漏洞详情】Atlassian Fisheye和Crucible都是澳大利亚Atlassian公司的产品。Atlassian Fisheye是一套源代码深度查看软件。Crucible是一套代码审查工具。

Atlassian Fisheye和Crucible 4.7.0之前版本中的administrative linker功能存在跨站脚本漏洞。远程攻击者可借助‘href‘’参数利用该漏洞注入任意的THML或JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://jira.atlassian.com/browse/CRUC-8381

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-768
