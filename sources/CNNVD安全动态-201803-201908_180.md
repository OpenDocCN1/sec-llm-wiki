# CNNVD最新漏洞（2019-02-21）

今日CNNVD共发布安全漏洞22个。主要影响厂商为美国ZOHO（5个）、美国Dell（1个）、中国华为（1个）。主要影响产品为ZOHO ManageEngine Netflow Analyzer宽带监控工具（3个）、Dell SonicWall SonicOS操作系统（1个）、Huawei Y9 2019智能手机（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******ZOHO ManageEngine Netflow Analyzer 路径遍历漏洞****

**【漏洞编号】******CNNVD-201902-745********（CVE-2019-8925）****

**【漏洞详情】**ZOHO ManageEngine Netflow Analyzer是美国卓豪（ZOHO）公司的一套基于Web的宽带监控工具。

Zoho ManageEngine Netflow Analyzer Professional 7.0.0.2版本中存在路径遍历漏洞。攻击者可利用该漏洞绕过限制并列出父目录。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.manageengine.cn

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-745

  

**【漏洞名称】****Dell SonicWall SonicOS 安全漏洞**  

**【漏洞编号】******CNNVD-201902-750**（CVE-2018-9867）**

**【漏洞详情】**Dell SonicWall SonicOS是美国戴尔（Dell）公司的一套专为SonicWall防火墙设备设计的操作系统。

Dell SonicWall SonicOS 5.9.1.10及之前版本中存在安全漏洞。攻击者可利用该漏洞下载导出的证书。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://psirt.global.sonicwall.com/vuln-detail/SNWLID-2018-0017

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-750

  

**【漏洞名称】**********Huawei Y9 2019 信息泄露漏洞********

**【漏洞编号】**********CNNVD-201902-753**（CVE-2019-5281）******

**【漏洞详****情】**Huawei Y9 2019是中国华为（Huawei）公司的一款智能手机。

Huawei Y9 2019 Jackman-L21 8.2.0.155(C185R1P2)之前版本中存在信息泄露漏洞。本地攻击者可利用该漏洞获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20190218-01-smartphone-cn

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-753

  

**【漏洞名称】********IBM Robotic Process Automation with Automation Anywhere 路径遍历漏洞 ******

**【****漏洞****编号****】********CNNVD-201902-751**（CVE-2018-2006）****

**【漏洞详情】**IBM Robotic Process Automation with Automation Anywhere是美国IBM公司的一套流程自动化解决方案。

IBM Robotic Process Automation with Automation Anywhere 11.0版本中存在目录遍历漏洞。远程攻击者可通过发送带有‘/../’序列的特制请求利用该漏洞向系统上传任意文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10794133

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-751

  

**【漏洞名称】********Google Chrome DevTools 注入漏洞******

**【****漏洞****编号****】********CNNVD-201902-749**（CVE-2019-5783）****

**【漏洞详情】**Google Chrome是美国谷歌（Google）公司的一款Web浏览器。Devtools是其中的一个开发调试工具。

Google Chrome 72.0.3626.81之前版本中的DevTools存在安全漏洞，该漏洞源于程序未充分地验证不可信的输入。攻击者可借助特制的HTML页面利用该漏洞泄露信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://chromereleases.googleblog.com/2019/01/stable-channel-update-for-desktop.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-749
