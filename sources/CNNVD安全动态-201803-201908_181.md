# CNNVD最新漏洞（2019-02-20）

今日CNNVD共发布安全漏洞41个。主要影响厂商为美国Intel（15个）、美国Red Hat（1个）、韩国LG（1个）。主要影响产品为Intel PROSet Wireless驱动程序（1个）、Red Hat JBoss Enterprise Application Platform中间件平台（1个）、LG Device Manager设备管理器（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Intel PROSet Wireless 缓冲区错误漏洞****

**【漏洞编号】******CNNVD-201902-704********（CVE-2018-12159）****

**【漏洞详情】**Intel PROSet Wireless是美国英特尔（Intel）公司的一款用于Intel PROSet无线网卡的驱动程序。

Intel(R) PROSet Wireless 20.50及之前版本中的命令行界面存在缓冲区溢出漏洞。本地攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.intel.com/content/www/us/en/security-center/advisory/INTEL-SA-00169.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-704

  

**【漏洞名称】****Red Hat JBoss Enterprise Application Platform 跨站脚本漏洞**  

**【漏洞编号】******CNNVD-201902-728**（CVE-2018-10934）**

**【漏洞详情】**Red Hat JBoss Enterprise Application Platform（EAP）是美国红帽（Red Hat）公司的一套开源的、基于J2EE的中间件平台。该平台主要用于构建、部署和托管Java应用程序与服务。

Red Hat JBoss EAP中的JBoss Management Console存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bugzilla.redhat.com/show\_bug.cgi?id=1615673

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-728

  

**【漏洞名称】**********LG Device Manager LHA.sys驱动程序安全漏洞********

**【漏洞编号】**********CNNVD-201902-699**（CVE-2019-8372）******

**【漏洞详****情】**LG Device Manager是韩国乐金（LG）公司的一款设备管理器。LHA.sys driver是其中的一个LHA.sys驱动程序。

LG Device Manager中的LHA.sys驱动程序1.1.1811.2101之前版本存在安全漏洞，该漏洞源于设备对象带有相关联的符号链接和开放的DACL。攻击者可借助特制的IOCTL请求利用该漏洞读取并写入任意的物理内存。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lgsecurity.lge.com/security\_updates.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-699

  

**【漏洞名称】********Micro Focus SUSE CaaS Platform 安全漏洞******

**【****漏洞****编号****】********CNNVD-201902-722**（CVE-2019-3682）****

**【漏洞详情】**Micro Focus SUSE CaaS Platform是英国Micro Focus公司的一套企业级容器管理解决方案。该产品主要用于部署、管理和扩展基于容器的应用程序及服务。

SUSE CaaS Platform 3.0版本中存在安全漏洞。攻击者可利用该漏洞访问权限较高的数据。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.suse.com/support/update/announcement/2019/suse-su-20190416-1/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-722
