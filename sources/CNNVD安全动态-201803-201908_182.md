今日CNNVD共发布安全漏洞66个。主要影响厂商为美国IBM（1个）。主要影响产品为IBM WebSphere Application Server应用服务器（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******IBM WebSphere Application Server 安全漏洞****

**【漏洞编号】******CNNVD-201902-677********（CVE-2018-1996）****

**【漏洞详情】**IBM WebSphere Application Server（WAS）是美国IBM公司的一款应用服务器产品。该产品是JavaEE和Web服务应用程序的平台，也是IBMWebSphere软件平台的基础。

IBM WAS中存在安全漏洞，该漏洞源于不正确的TLS配置。远程攻击者可通过实施中间人攻击利用该漏洞获取敏感信息。以下版本受到影响：IBM WAS 9.0版本，8.5版本，8.0版本，7.0版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10871672

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-677

  

**【漏洞名称】****ZoneMinder SQL注入漏洞**  

**【漏洞编号】******CNNVD-201902-670**（CVE-2019-8429）**

**【漏洞详情】**ZoneMinder是一套开源的视频监控软件系统。该系统支持IP、USB和模拟摄像机等。

ZoneMinder 1.32.3之前版本中的ajax/status.php文件存在SQL注入漏洞。远程攻击者可借助‘filter\[Query\]\[terms\]\[0\]\[cnj\]’参数利用该漏洞执行SQL命令。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://zoneminder.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-670

  

**【漏洞名称】**********Zabbix SIA Zabbix 安全漏洞********

**【漏洞编号】**********CNNVD-201902-671**（CVE-2016-10742）******

**【漏洞详****情】**Zabbix SIA Zabbix中存在安全漏洞。攻击者可借助‘request’参数利用该漏洞将用户重定向到外部的链接。以下版本受到影响：Zabbix SIA Zabbix 2.2.21rc1之前版本，3.0.13rc1之前的3.x 版本，3.1.x版本，3.2.10rc1之前的3.2.x版本，3.3.x版本，3.4.4rc1之前的3.4.x版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.zabbix.com/browse/ZBX-10272

https://support.zabbix.com/browse/ZBX-13133

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-671

  

**【漏洞名称】********MyBB Trash Bin插件安全漏洞******

**【****漏洞****编号****】********CNNVD-201902-664**（CVE-2018-14575）****

**【漏洞详情】**MyBB（MyBulletinBoard）是MyBB团队的开发的一套用PHP和MySQL开发的免费且基于Web的论坛软件。该软件具有简单易用、支持多国语言、可扩展等特点。

MyBB Trash Bin插件1.1.3版本中存在安全漏洞。攻击者可利用该漏洞实施跨站脚本攻击，恢复被删除的发布内容。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://community.mybb.com/mods.php?action=changelog&pid=1222

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-664
