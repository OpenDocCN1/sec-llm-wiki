今日CNNVD共发布安全漏洞57个。主要影响厂商为美国Microsoft（1个）、美国Symantec（1个）。主要影响产品为Microsoft Dynamics 365解决方案（1个）、Symantec Norton Password Manager应用程序（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Microsoft Dynamics 365 安全漏洞****

**【漏洞编号】******CNNVD-201902-566********（CVE-2018-8654）****

**【漏洞详情】**Microsoft Dynamics 365是美国微软（Microsoft）公司的一套适用于跨国企业的ERP业务解决方案。该产品包括财务管理、生产管理和商业智能管理等。

Microsoft Dynamics 365 (on-premises) 8版本中存在提权漏洞。远程攻击者可通过发送特制的请求利用该漏洞冒充Dynamics服务器上的用户。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2018-8654

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-566

  

**【漏洞名称】****Symantec Norton Password Manager 安全漏洞**  

**【漏洞编号】******CNNVD-201902-565**（CVE-2018-18365）**

**【漏洞详情】**Symantec Norton Password Manager是美国赛门铁克（Symantec）公司的一款密码管理应用程序。

Symantec Norton Password Manager 6.2.0.1078 (Android) 之前版本和6.2.309 (iOS) 之前版本中存在安全漏洞。本地攻击者可利用该漏洞伪造IP地址，执行恶意操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.symantec.com/en\_US/article.SYMSA1475.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-565

  

**【漏洞名称】**********CA Privileged Access Manager 安全漏洞********

**【漏洞编号】**********CNNVD-201902-621**（CVE-2019-7392）******

**【漏洞详****情】**CA Privileged Access Manager  3.2.1及之前版本、3.1.2及之前版本和3.0.x版本中存在安全漏洞，该漏洞源于程序没有对jk-manager和jk-status web服务进行充分的访问控制。攻击者可利用该漏洞访问敏感信息或修改配置。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.ca.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-621

  

**【漏洞名称】********Raisecom Technology GPON-ONU HT803G-07 命令注入漏洞******

**【****漏洞****编号****】********CNNVD-201902-619**（CVE-2019-7385）****

**【漏洞详情】**Raisecom Technology GPON-ONU HT803G-07中的/bin/WebMGR的‘newpass’和‘confpass’参数存在命令注入漏洞。攻击者可利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.raisecom.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-619
