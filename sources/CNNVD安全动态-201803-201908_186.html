今日CNNVD共发布安全漏洞47个。主要影响厂商为德国SAP（8个）、澳大利亚Atlassian（5个）、德国Siemens（4个）。主要影响产品为SAP HANA分析平台（1个）、Atlassian Jira管理系统（3个）、Siemens CP1604通信处理器（3个）。

今日需关注的典型漏洞如下:

【漏洞名称】SAP HANA Extended Application Service 信息泄露漏洞

【漏洞编号】CNNVD-201902-519（CVE-2019-0266）

【漏洞详情】SAP HANA是德国思爱普（SAP）公司的一套高性能的实时数据分析平台。该平台提供数据查询功能，支持用户对查询实时业务数据进行查询和分析。Extended Application Services是一个应用程序服务器、Web服务器和SAP HANA System内Web应用的开发环境。

SAP HANA Extended Application Services中存在信息泄露漏洞。远程攻击者可利用该漏洞获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wiki.scn.sap.com/wiki/pages/viewpage.action?pageId=510922950

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-519


【漏洞名称】Atlassian Jira 跨站脚本漏洞

【漏洞编号】CNNVD-201902-556（CVE-2018-20232）

【漏洞详情】Atlassian Jira是澳大利亚Atlassian公司的一套缺陷跟踪管理系统。该系统主要用于对工作中各类问题、缺陷进行跟踪管理。

Atlassian Jira 7.6.11之前版本和7.7.0版本至7.13.1之前版本中的labels widget gadget存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的HTML或JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://jira.atlassian.com/browse/JRASERVER-68614

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-556


【漏洞名称】Siemens CP1604和CP1616 安全漏洞

【漏洞编号】CNNVD-201902-520（CVE-2018-13808）

【漏洞详情】Siemens CP1604和CP1616都是德国西门子（Siemens）公司的一款通信处理器。

Siemens CP1604和CP1616中存在安全漏洞，该漏洞源于程序以明文的形式传递敏感信息。远程攻击者可利用该漏洞提取内部的通信数据或造成拒绝服务。以下产品和版本受到影响：Siemens CP 1616 2.7.2版本，2.1版本；Siemens CP 1604 2.7.2版本，2.1版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.industry.siemens.com/cs/ww/en/view/109762689

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-520


【漏洞名称】AVEVA Group plc InduSoft Web Studio和InTouch Edge HMI 安全漏洞

【漏洞编号】CNNVD-201902-532（CVE-2019-6545）

【漏洞详情】AVEVA Group plc InduSoft Web Studio和InTouch Edge HMI都是英国AVEVA Group plc公司的产品。InduSoft Web Studio是一套工业组态软件。InTouch Edge HMI是一款可扩展的人机界面应用程序。

AVEVA Group plc InduSoft Web Studio  8.1 SP3之前版本和InTouch Edge HMI 2017 Update之前版本中存在安全漏洞。远程攻击者可借助的数据库连接配置文件利用该漏洞在服务器设备上执行任意进程。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://sw.aveva.com/hubfs/assets-2018/pdf/security-bulletin/SecurityBulletin_LFSec133.pdf?hsLang=en

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-532


【漏洞名称】McAfee True Key Microsoft Windows客户端安全漏洞

【漏洞编号】CNNVD-201902-560（CVE-2019-3610）

【漏洞详情】McAfee True Key（TK）是美国迈克菲（McAfee）公司的一款身份验证应用程序。该程序支持面部信息识别和指纹识别等功能。

McAfee TK 3.1.9211.0及之前版本中的Microsoft Windows客户端存在安全漏洞。本地攻击者可借助特制的恶意软件利用该漏洞泄露敏感数据。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://service.mcafee.com/webcenter/portal/cp/home/articleview?articleId=TS102889

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-560
