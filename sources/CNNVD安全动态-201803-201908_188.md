今日CNNVD共发布安全漏洞343个。主要影响厂商为美国Google（4个）、美国Cisco（4个）。主要影响产品为Android操作系统（4个）、Cisco Web Security Appliance Web安全设备（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】**********Google Android 信息泄露漏洞********

**【漏洞编号】******CNNVD-201902-332********（CVE-2018-12006）****

**【漏洞详情】**Google Android中的Display功能存在信息泄露漏洞。攻击者可利用该漏洞访问泄露的数据。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.codeaurora.org/security-bulletin/2019/01/07/january-2019-code-aurora-security-bulletin

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-332

  

**【漏洞名称】******Cisco Web Security Appliance 安全漏洞****  

**【漏洞编号】********CNNVD-201902-309**（CVE-2019-1672）****

**【漏洞详情】**Cisco WSA 10.1.x版本和10.5.x版本中的Decryption Policy Default Action功能存在安全漏洞，该漏洞源于程序没有正确地处理由SSL所加密的流量。远程攻击者可利用该漏洞阻止进行SSL连接。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bst.cloudapps.cisco.com/bugsearch/bug/CSCvm91630

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-309

  

**【漏洞名称】**********多款Qualcomm Snapdragon产品安全漏洞********

**【漏洞编号】**********CNNVD-201902-331**（CVE-2018-11855）******

**【漏洞详****情】**多款Qualcomm Snapdragon产品中的OCE Code存在缓冲区溢出漏洞。攻击者可利用该漏洞执行代码或造成拒绝服务。以下产品受到影响：Qualcomm MDM9607；MDM9650；MDM9655；MSM8996AU；SD 210；SD 212；SD 205；SD 410/12；SD 636；SD 820；SD 820A；SD 835；SD 8CX；SDA660；SDM630；SDM660。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.qualcomm.com/company/product-security/bulletins

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-331

  

**【漏洞名称】********Binaryen 安全漏洞******

**【****漏洞****编号****】********CNNVD-201902-302**（CVE-2019-7703）****

**【漏洞详情】**Binaryen 1.38.22版本中的wasm-binary.cpp文件的‘wasm::WasmBinaryBuilder::visitCall’函数存在释放后重用漏洞。远程攻击者可借助wasm文件利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/WebAssembly/binaryen/issues/1865

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201902-302
