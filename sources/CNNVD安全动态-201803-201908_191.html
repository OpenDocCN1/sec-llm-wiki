今日CNNVD共发布安全漏洞27个。主要影响厂商为美国IBM（2个）、中国华为（1个）。主要影响产品为IBM Security Identity Manager解决方案（1个）、Huawei Honor V10智能手机（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】IBM Security Identity Manager 代码注入漏洞

【漏洞编号】CNNVD-201901-1066（CVE-2019-4038）

【漏洞详情】IBM Security Identity Manager（ISIM）是美国IBM公司的一套身份管理和治理解决方案。该方案可在整个用户生命周期内自动创建、修改、重新认证和终止用户特权，并支持基于策略的密码管理。

IBM ISIM中存在代码注入漏洞。攻击者可利用该漏洞入侵用户账户。以下产品及版本受到影响：IBM Security Identity Manager 6.0.0版本至6.0.0.20版本，IBM Security Identity Manager VA 7.0.0版本至7.0.1.10版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10869604

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201901-1066


【漏洞名称】Huawei Honor V10 安全漏洞

【漏洞编号】CNNVD-201901-1061（CVE-2019-5295）

【漏洞详情】Huawei Honor V10是中国华为（Huawei）公司的一款智能手机。

Huawei Honor V10 Berkeley-AL20 9.0.0.125(C00E125R2P14T8)之前版本中存在安全漏洞，该漏洞源于授权实现逻辑不合理。攻击者可利用该漏洞执行授权范围之外的操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20190131-01-phone-cn

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201901-1061


【漏洞名称】Keybase 权限许可和访问控制漏洞

【漏洞编号】CNNVD-201901-1055（CVE-2019-7249）

【漏洞详情】Keybase是一套基于PGP技术的、支持端到端加密的社交网络平台。

Keybase 2.12.6之前版本（macOS）中存在安全漏洞。攻击者可利用该漏洞该漏洞提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://keybase.io/docs/secadv/kb004

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201901-1055


【漏洞名称】FileChucker 输入验证漏洞

【漏洞编号】CNNVD-201901-1047（CVE-2019-7216）

【漏洞详情】FileChucker是一款基于AJAX的文件上传应用程序。

FileChucker 4.99e-free-e02版本中存在安全漏洞。攻击者可借助‘%’字符利用该漏洞绕过过滤器，上传任意类型的文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://encodable.com/filechucker/changelog/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201901-1047
