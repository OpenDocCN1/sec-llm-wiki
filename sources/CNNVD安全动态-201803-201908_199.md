今日CNNVD共发布安全漏洞17个，更新安全漏洞3个。主要影响厂商为美国IBM（2个）、德国Adiscon（1个）。主要影响产品为IBM API Connect解决方案（1个）、Adiscon Rsyslog系统日志收集库（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******IBM API Connect 安全漏洞****

**【漏洞编号】******CNNVD-201901-921********（CVE-2018-1976）****

**【漏洞详情】**IBM API Connect（又名APIConnect）是美国IBM公司的一套用于管理API生命周期的集成解决方案。该方案支持创建、运行、管理和保护API和微服务等。

IBM API Connect 5.0.0.0版本至5.0.8.4版本中存在安全漏洞。攻击者可借助REST API利用该漏洞获取高度敏感的信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10843130

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201901-921

  

**【漏洞名称】****Adiscon Rsyslog imptcp模块安全漏洞**  

**【漏洞编号】******CNNVD-201901-913**（CVE-2018-16881）**

**【漏洞详情】**Adiscon Rsyslog是德国Adiscon公司的一个用于收集系统日志的库。imptcp是其中的一个TCP系统日志模块。

Adiscon Rsyslog 8.27.0之前版本中的imptcp模块存在拒绝服务漏洞。攻击者可通过向imptcp套接字发送特制的消息利用该漏洞造成rsyslog崩溃。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/rsyslog/rsyslog/commit/0381a0de64a5a048c3d48b79055bd9848d0c7fc2

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201901-913

  

**【漏洞名称】**********GD Graphics Library 缓冲区错误漏洞    ********

**【漏洞编号】**********CNNVD-201901-920**（CVE-2019-6977）******

**【漏洞详****情】**PHP（PHP：Hypertext Preprocessor，PHP：超文本预处理器）是PHP Group和开放源代码社区共同维护的一种开源的通用计算机脚本语言。该语言主要用于Web开发，支持多种数据库及操作系统。GD Graphics Library是使用在其中的一个开源的用于动态创建图像的库。

GD Graphics Library 2.2.5版本中的gd\_color\_match.c文件的‘gdImageColorMatch’函数存在基于堆的缓冲区溢出漏洞。攻击者可利用该漏洞执行代码或造成拒绝服务。以下产品和版本受到影响：PHP 5.6.40之前的版本，7.1.26之前的7.x版本，7.2.14之前的7.2.x版本，7.3.1之前的7.3.x版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://php.net/ChangeLog-5.php

http://php.net/ChangeLog-7.php

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201901-920

  

**【漏洞名称】********Mumble 安全漏洞******

**【****漏洞****编号****】********CNNVD-201901-911**（CVE-2018-20743）****

**【漏洞详情】**Mumble是一套用于游戏中的语音通讯工具。该工具可以让玩家在玩游戏的同时进行实时的语音交流。

Mumble 1.2.19及之前版本（2018-08-31之前）中的murmur存在安全漏洞，该漏洞源于程序没有正确地处理多个并发请求。远程攻击者可通过发送大量的消息利用该漏洞造成拒绝服务（守护进程挂起和崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/mumble-voip/mumble/issues/3505

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201901-911
