今日CNNVD共发布安全漏洞77个，更新安全漏洞3个。主要影响厂商为美国Microsoft（49个）、德国SAP（12个）、美国Qualcomm（2个）。主要影响产品为Microsoft Windows 10操作系统（22个）、SAP Enterprise Financial Services解决方案（1个）、Qualcomm MDM9607中央处理器（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Microsoft Windows Jet数据库引擎安全漏洞

【漏洞编号】CNNVD-201901-124（CVE-2019-0584）

【漏洞详情】Microsoft Windows 10等都是美国微软（Microsoft）公司发布的一系列操作系统。JET Database Engine是其中的一个底层数据库引擎。

Microsoft Windows Jet数据库引擎中存在远程代码执行漏洞，该漏洞源于Jet数据库引擎不正确地处理了内存中的对象。远程攻击者可借助特制的文件利用该漏洞在系统上执行任意代码。以下系统版本受到影响：Microsoft Windows 10，Windows 10版本1607，Windows 10版本1703，Windows 10版本1709，Windows 10版本1803，Windows 10版本1809，Windows 7 SP1，Windows 8.1，Windows RT 8.1，Windows Server 2008 SP2，Windows Server 2008 R2 SP1，Windows Server 2012，Windows Server 2012 R2，Windows Server 2016，Windows Server 2019，Windows Server版本1709，Windows Server版本1803。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2019-0584

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201901-124


【漏洞名称】SAP Commerce 跨站脚本漏洞

【漏洞编号】CNNVD-201901-121（CVE-2019-0238）

【漏洞详情】SAP Commerce是德国思爱普（SAP）公司的一套电子商务解决方案。该产品包括产品内容管理、体验管理、个性化和订单管理等组件。

SAP Commerce 6.7之前版本中存在跨站脚本漏洞，该漏洞源于程序没有充分地编码用户控制的输入。远程攻击者可利用该漏洞在用户浏览器中执行任意脚本代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wiki.scn.sap.com/wiki/pages/viewpage.action?pageId=509151985

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201901-121


【漏洞名称】多款Qualcomm产品Cyrpto Services 权限许可和访问控制漏洞

【漏洞编号】CNNVD-201901-182（CVE-2018-11888）

【漏洞详情】Qualcomm MDM9607等都是美国高通（Qualcomm）公司的用于不同平台的中央处理器（CPU）产品。Cyrpto Services是其中的一个加密服务组件。

多款Qualcomm产品中的Cyrpto Services存在权限许可和访问控制漏洞。攻击者可利用该漏洞执行未授权的操作。以下产品受到影响：Qualcomm MDM9607；MDM9650；MDM9655；MSM8996AU；SD 210；SD 212；SD 205；SD 410/12；SD 425；SD 427；SD 430；SD 435；SD 439；SD 429；SD 450；SD 615/16；SD 415；SD 625；SD 632；SD 650/52；SD 820；SD 820A；SD 835；SD 8CX；SDM439；Snapdragon_High_Med_2016。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接:

https://source.android.com/security/bulletin/2019-01-01

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201901-182  


【漏洞名称】多款D-Link产品安全漏洞

【漏洞编号】CNNVD-201901-138（CVE-2018-20675）

【漏洞详情】D-Link DIR-822 C1等都是友讯（D-Link）公司的无线路由器产品。

多款D-Link产品中存在安全漏洞。攻击者可利用该漏洞绕过身份验证。以下产品和版本受到影响：使用v3.11B01Beta之前版本固件的D-Link DIR-822 C1；使用v3.11B01Beta之前版本固件的DIR-822-US C1；使用v2.22B03Beta之前版本固件的DIR-850L A*；使用v1.20B02Beta之前版本固件的DIR-880L A*；使用v2.22B03Beta之前版本固件的DIR-850L B*。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://securityadvisories.dlink.com/announcement/publication.aspx?name=SAP10101

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201901-138


【漏洞名称】Android 权限许可和访问控制漏洞    

【漏洞编号】CNNVD-201901-185（CVE-2018-9582）

【漏洞详情】Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。

Android中存在提权漏洞。攻击者可利用该漏洞获取提升的权限。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://source.android.com/security/bulletin/2019-01-01

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201901-185
