接报漏洞情况

本周接报漏洞747个，其中信息技术产品漏洞（通用型漏洞）15个，网络信息系统漏洞（事件型漏洞）732个。

一、公开漏洞情况

根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞206个，漏洞新增数量有所下降。从厂商分布来看，其中MacPaw公司新增漏洞最多，共有13个；从漏洞类型来看，跨站脚本类的安全漏洞占比最大，达到17.96%。本周新增漏洞中，超危漏洞0个，高危漏洞13个，中危漏洞136个，低危漏洞57个。高危、中危、低危漏洞相应修复率分别为100.00%、34.56%以及31.58%。根据补丁信息统计，合计78个漏洞已有修复补丁发布，整体修复率为37.86%。

截至2019年1月6日，CNNVD发布漏洞总量已达120098个。

1. MacPaw CleanMyMac X 输入验证漏洞（CNNVD-201901-045）

MacPaw CleanMyMac X是美国MacPaw公司的一款专用于macOS平台的清理工具。该产品能够清除计算机中的垃圾文件、历史缓存和日志等。

MacPaw CleanMyMac X 4.04版本中存在输入验证漏洞。本地攻击者可利用该漏洞修改系统上正在运行的内核扩展。

解决措施：目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://macpaw.com/cleanmymac

2.  MacPaw CleanMyMac X 输入验证漏洞（CNNVD-201901-044）

MacPaw CleanMyMac X是美国MacPaw公司的一款专用于macOS平台的清理工具。该产品能够清除计算机中的垃圾文件、历史缓存和日志等。

MacPaw CleanMyMac X 4.04版本中的helper service存在输入验证漏洞。本地攻击者可利用该漏洞以root用户身份修改文件系统。

解决措施：目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://macpaw.com/cleanmymac
