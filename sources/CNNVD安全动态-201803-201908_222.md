# CNNVD最新漏洞（2019-01-04）

今日CNNVD共发布安全漏洞68个，更新安全漏洞6个。主要影响厂商为美国MacPaw（13个）、美国FasterXML（11个）、美国IBM（4个）。主要影响产品为MacPaw CleanMyMac X清理工具（13个）、FasterXML Jackson数据处理工具（11个）、IBM InfoSphere Information Server数据整合平台（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******MacPaw CleanMyMac X 输入验证漏洞****

**【漏洞编号】******CNNVD-201901-047********（CVE-2018-4037）****

**【漏洞详情】**MacPaw CleanMyMac X是美国MacPaw公司的一款专用于macOS平台的清理工具。该产品能够清除计算机中的垃圾文件、历史缓存和日志等。

MacPaw CleanMyMac X 4.04版本中存在输入验证漏洞。本地攻击者可利用该漏洞以root用户身份修改文件系统。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://macpaw.com/cleanmymac

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201901-047

  

**【漏洞名称】******FasterXML Jackson-databind 安全漏洞****  

**【漏洞编号】******CNNVD-201712-478**（CVE-2017-17485）**

**【漏洞详情】**FasterXML Jackson是美国FasterXML公司的一款用于Java的数据处理工具。Jackson-databind是其中的一个具有数据绑定功能的组件。

FasterXML Jackson-databind 2.8.10及之前的版本和2.9.x版本至2.9.3版本中存在安全漏洞。远程攻击者可通过向ObjectMapper的readValue方法发送恶意制作的JSON输入并绕过黑名单利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/FasterXML/jackson-databind/issues/1855

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201712-478

  

**【漏洞名称】****IBM InfoSphere Information Server 访问控制错误漏洞**

**【漏洞编号】******CNNVD-201812-197**（CVE-2018-1899）**

**【漏洞详****情】**IBM InfoSphere Information Server是美国IBM公司的一套数据整合平台。该平台可用于整合各种渠道获取的数据信息。

IBM InfoSphere Information Server中存在访问控制错误漏洞。攻击者可利用该漏洞修改与InfoSphere Business Glossary相关的设置。以下产品和版本受到影响：IBM InfoSphere Information Governance Catalog 11.3版本，11.5版本，11.7版本；Information Server on Cloud 11.5版本，11.7版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10744029

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-197  

  

**【漏洞名称】********Microsoft Dynamics NAV 跨站脚本漏洞******

**【****漏洞****编号****】********CNNVD-201812-439**（CVE-2018-8651）****

**【漏洞详情】**Microsoft Dynamics NAV是美国微软（Microsoft）公司的一套专为中小企业设计的商务管理解决方案。该产品包括财务管理、生产订单管理、商务智能管理和库存管理等。

Microsoft Dynamics NAV 2016版本和2017版本中存在跨站脚本漏洞，该漏洞源于程序未正确过滤发给受影响的Dynamics NAV Server的特制的Web请求。远程攻击者可利用该漏洞当前用户的安全上下文中运行脚本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2018-8651

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-439

  

**【漏洞名称】********Google Kubernetes Dashboard 安全漏洞******

**【****漏洞****编号****】********CNNVD-201901-029**（CVE-2018-18264）****

**【漏洞详情】**Google Kubernetes是美国Google公司的一套开源的Docker容器集群管理系统。该系统为容器化的应用提供资源调度、部署运行、服务发现和扩容缩容等功能。Kubernetes Dashboard是一款基于Web的用于管理Kubernetes集群的通用界面。

Google Kubernetes Dashboard 1.10.1之前版本中存在安全漏洞。攻击者可利用该漏洞绕过身份验证，使用Dashboard的服务账户读取信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/kubernetes/dashboard/releases/tag/v1.10.1

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201901-029
