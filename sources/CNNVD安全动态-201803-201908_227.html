今日CNNVD共发布安全漏洞8个。主要影响厂商为美国Ansible（1个）、美国Artifex Software（1个）。主要影响产品为Ansible配置管理器（1个）、Artifex Software Ghostscript解析器（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Ansible Tower 信息泄露漏洞

【漏洞编号】CNNVD-201812-1172（CVE-2018-16879）

【漏洞详情】Ansible是美国Ansible公司的一款计算机系统配置管理器，它可用于发布、管理和编排计算机系统。Ansible Tower（又名Ansible UI）是其中的一个提供了用户界面（UI）、仪表板和REST API的任务控制应用程序。

Ansible Tower中存在信息泄露漏洞。远程攻击者可利用该漏洞获取敏感信息或造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://docs.ansible.com/ansible-tower/latest/html/installandreference/release_notes.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-1172


【漏洞名称】Artifex Software Ghostscript 安全漏洞

【漏洞编号】CNNVD-201812-1171（CVE-2018-19478）

【漏洞详情】Artifex Software Ghostscript是美国Artifex Software公司的一款开源的PostScript（一种用于电子产业和桌面出版领域的页面描述语言和编程语言）解析器，它可显示Postscript文件以及在非Postscript打印机上打印Postscript文件。

Artifex Software Ghostscript中存在安全漏洞。攻击者可借助特制的PDF文件利用该漏洞造成拒绝服务（无限循环）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://git.ghostscript.com/?p=ghostpdl.git;a=commitdiff;h=0a7e5a1c309fa0911b892fa40996a7d55d90bace

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-1171


【漏洞名称】Linux kernel 安全漏洞

【漏洞编号】CNNVD-201812-1166（CVE-2018-20511）

【漏洞详情】Linux kernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。

Linux kernel 4.18.11之前版本中的drivers/net/appletalk/ipddp.c文件的‘ipddp_ioctl’函数存在安全漏洞。本地攻击者可利用该漏洞获取敏感的内核地址信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://cdn.kernel.org/pub/linux/kernel/v4.x/ChangeLog-4.18.11

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-1166


【漏洞名称】74cms 安全漏洞

【漏洞编号】CNNVD-201812-1167（CVE-2018-20519）

【漏洞详情】74cms是中国迅易科技公司的一套基于PHP和MySQL的在线招聘系统。

74cms 4.2.111版本中存在安全漏洞。远程攻击者可通过修改职位搜索意向利用该漏洞读取或修改任意简历。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.74cms.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-1167
