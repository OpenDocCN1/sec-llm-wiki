今日CNNVD共发布安全漏洞81个，更新安全漏洞4个。主要影响厂商为美国Trend Micro（3个）、美国ZOHO（2个）、韩国Hancom（1个）。主要影响产品为Trend Micro OfficeScan for Windows反病毒软件（2个）、ZOHO ManageEngine OpManager监控软件（2个）、Hancom Office办公软件套件（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Trend Micro OfficeScan for Windows 安全漏洞****

**【漏洞编号】******CNNVD-201812-996********（CVE-2018-18331）****

**【漏洞详情】**Trend Micro OfficeScan for Windows是美国趋势科技（Trend Micro）公司的一套基于Windows平台的分布式反病毒软件。

基于Windows平台的Trend Micro OfficeScan XG版本中存在安全漏洞。攻击者可利用该漏洞修改文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://success.trendmicro.com/solution/1121674

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-996

  

**【漏洞名称】******ZOHO ManageEngine OpManager SQL注入漏洞****  

**【漏洞编号】******CNNVD-201812-993**（CVE-2018-20338）**

**【漏洞详情】**ZOHO ManageEngine OpManager是美国卓豪（ZOHO）公司的一套网络、服务器及虚拟化监控软件。

ZOHO ManageEngine OpManager 12.3 build 123239之前版本中的Alarms部分存在SQL注入漏洞。远程攻击者可利用该漏洞执行任意代码或未授权访问数据库中的信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.manageengine.com/network-monitoring/help/read-me.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-993

  

**【漏洞名称】****多款Hancom Office产品缓冲区错误漏洞    **

**【漏洞编号】******CNNVD-201812-999**（CVE-2018-5201）**

**【漏洞详****情】**Hancom Office是韩国Hancom公司开发的一款办公软件套件产品。常用组件有Hanword（文字编辑）、Hancell（电子表格）、Hanshow（演示文稿）等。

多款Hancom Office产品中存在堆溢出漏洞。攻击者可利用该漏洞造成程序崩溃或拒绝服务。以下产品和版本受到影响：Hancom Office 2018 10.0.0.8214及之前版本；Hancom Office NEO 9.6.1.10472及之前版本；Hancom Office 2014 9.1.1.4540及之前版本；Hancom Office 2010 8.5.8.1724及之前版本。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.hancom.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-999

  

**【漏洞名称】********Pulse Secure Access SSL VPN SA-4000 安全漏洞******

**【****漏洞****编号****】********CNNVD-201812-1008**（CVE-2018-20193）****

**【漏洞详情】**Pulse Secure Access SSL VPN SA-4000是美国Pulse Secure公司的一款VPN设备。该产品主要为中小企业提供远端安全存取解决方案。

Pulse Secure Access SSL VPN SA-4000 5.1R5 (build 9627)版本和4.2 Release (build 7631)版本中存在安全漏洞，该漏洞源于程序没有进行恰当的权限控制。攻击者可利用该漏洞提升权限，更改管理员密码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.pulsesecure.net/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-1008

  

**【漏洞名称】****Barracuda Message Archiver 跨站脚本漏洞**

**【漏洞编****号】****CNNVD-201812-1028****（CVE-2018-20369）**

**【漏洞详情】**Barracuda Message Archiver是美国梭子鱼（Barracuda Networks）公司的一套电子邮件归档解决方案。该方案支持索引和保存所有电子邮件，并能够增强运作效率和加强法规遵从的政策。

Barracuda Message Archiver 2018版本中的cgi-mod/ldap\_load\_entry.cgi模块的‘ldap\_user’参数的error\_msg exception-handling值存在跨站脚本漏洞。远程攻击者可利用该漏洞将恶意脚本注入客户端web应用程序请求。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.barracuda.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-1028
