今日CNNVD共发布安全漏洞121个，更新安全漏洞27个。主要影响厂商为美国Google（7个）、美国Logitech（4个）、美国F5（3个）。主要影响产品为Android操作系统（7个）、Logitech Harmony Hub遥控器设备（4个）、F5 BIG-IP网络设备（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Android 权限许可和访问控制漏洞****

**【漏洞编号】******CNNVD-201812-919********（CVE-2018-11964）****

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。

Android中的Yocto存在权限许可和访问控制漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.codeaurora.org/security-bulletin/2018/12/03/december-2018-code-aurora-security-bulletin

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-919

  

**【漏洞名称】******Logitech Harmony Hub 安全漏洞****  

**【漏洞编号】******CNNVD-201812-956**（CVE-2018-15720）**

**【漏洞详情】**Logitech Harmony Hub是美国罗技（Logitech）公司的一款远程遥控器设备。

Logitech Harmony Hub 4.15.206之前版本中存在安全漏洞，该漏洞源于程序的XMPP服务器含有两个硬编码的账户。远程攻击者可利用该漏洞获取对本地API的访问权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.myharmony.com/en-de/release-notes

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-956

  

**【漏洞名称】****F5 BIG-IP 安全漏洞**

**【漏洞编号】******CNNVD-201812-949**（CVE-2018-15330）**

**【漏洞详****情】**F5 BIG-IP是美国F5公司的一款集成了网络流量管理、应用程序安全管理、负载均衡等功能的多合一网络设备。

F5 BIG-IP 14.0.0版本至14.0.0.2版本、13.0.0版本至13.1.1.1版本和12.1.0版本至12.1.3.7中存在安全漏洞。攻击者可利用该漏洞干扰流量或造成BIG-IP系统发生故障，进而切换到设备组中的另一设备。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.f5.com/csp/article/K23328310

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-949

  

**【漏洞名称】********Elasticsearch Security 安全漏洞******

**【****漏洞****编号****】********CNNVD-201812-962**（CVE-2018-17244）****

**【漏洞详情】**Elasticsearch是荷兰Elasticsearch公司的一套基于Lucene构建的开源分布式RESTful搜索引擎，它主要用于云计算中，并支持通过HTTP使用JSON进行数据索引。Security是其中的一个数据保护组件。

Elasticsearch Security 6.4.0版本至6.4.2版本中存在安全漏洞。攻击者可利用该漏洞访问本应无法访问的信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://discuss.elastic.co/t/elastic-stack-6-4-3-and-5-6-13-security-update/155594

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-962

  

**【漏洞名称】****Brave 安全漏洞**

**【漏洞编****号】****CNNVD-201812-883****（CVE-2018-1000815）**

**【漏洞详情】**Brave是美国Brave Software公司的一款Web浏览器产品。

Brave 0.22.810版本至0.24.0版本中的content\_settings\_observer.cc文件的‘ContentSettingsObserver::AllowScript()’函数存在安全漏洞。攻击者可借助特制的网站利用该漏洞即便在脚本被禁止的情况下运行内联JavaScript代码，跟踪用户。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/brave/muon/commit/c18663aa171c6cdf03da3e8c70df8663645b97c4

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-883
