今日CNNVD共发布安全漏洞56个，更新安全漏洞1个。主要影响厂商为美国IBM（5个）、日本TOSHIBA（4个）、美国Pivotal Software（2个）。主要影响产品为IBM API Connect解决方案（3个）、TOSHIBA Home Gateway HEM-GW26A家庭网关（4个）、Pivotal Concourse交付控制系统（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】IBM API Connect 安全漏洞    

【漏洞编号】CNNVD-201812-812（CVE-2018-1973）

【漏洞详情】IBM API Connect（又名APIConnect）是美国IBM公司的一套用于管理API生命周期的集成解决方案。该方案支持创建、运行、管理和保护API和微服务等。

IBM API Connect 5.0.0.0版本至5.0.8.4版本中的members功能存在安全漏洞。攻击者可利用该漏洞将从受限的‘API Administrator’访问权限提升至‘Administrator’的全部访问权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10788339

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-812


【漏洞名称】TOSHIBA Home Gateway HEM-GW26A和TOSHIBA Home Gateway HEM-GW16A 安全漏洞

【漏洞编号】CNNVD-201812-808（CVE-2018-16198）

【漏洞详情】TOSHIBA Home Gateway HEM-GW26A和TOSHIBA Home Gateway HEM-GW16A都是日本东芝（TOSHIBA）公司的家庭网关产品。

TOSHIBA Home Gateway HEM-GW26A 1.2.9及之前版本和TOSHIBA Home Gateway HEM-GW16A 1.2.9及之前版本中存在安全漏洞。攻击者可利用该漏洞操作受影响的设备。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.tlt.co.jp/tlt/information/seihin/notice/defect/20181219/20181219.htm

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-808


【漏洞名称】Pivotal Concourse 安全漏洞

【漏洞编号】CNNVD-201812-856（CVE-2018-15798）

【漏洞详情】Pivotal Concourse是美国Pivotal Software公司一套用于持续开发的软件交付控制系统。

Pivotal Concourse 4.2.2之前的4.x版本中存在安全漏洞。远程攻击者可通过诱使用户点击特制的链接利用该漏洞访问用户在Concourse中的访问令牌。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://pivotal.io/security/cve-2018-15798

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-856


【漏洞名称】Microsoft Internet Explorer 脚本引擎安全漏洞

【漏洞编号】CNNVD-201812-806（CVE-2018-8653）

【漏洞详情】Microsoft Internet Explorer（IE）是美国微软（Microsoft）公司开发的一款Web浏览器，是Windows操作系统附带的默认浏览器。

Microsoft IE 9、10和11的脚本引擎中对内存对象的处理方式存在远程代码执行漏洞。远程攻击者可利用该漏洞在当前用户的上下文中执行任意代码，损坏内存。以下系统版本受到影响：Microsoft Windows Server 2012（Internet Explorer 10）；Windows 10版本1703，Windows 10版本1803，Windows 10版本1809，Windows 10版本1709，Windows 10，Windows 10版本1607，Windows Server 2019，Windows Server 2016，Windows 7 SP1，Windows 8.1，Windows RT 8.1，Windows Server 2008 R2 SP1，Windows Server 2012 R2（Internet Explorer 11）；Windows Server 2008 SP2 （Internet Explorer 9）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-us/security-guidance/advisory/CVE-2018-8653

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-806


【漏洞名称】Cisco Adaptive Security Appliances Software authorization子系统权限许可和访问控制漏洞

【漏洞编号】CNNVD-201812-818（CVE-2018-15465）

【漏洞详情】Cisco Adaptive Security Appliances（ASA，自适应安全设备）Software是美国思科（Cisco）公司的一套运行于防火墙中的操作系统。authorization subsystem是其中的一个授权子系统。

Cisco ASA Software中的authorization子系统存在提权漏洞，该漏洞源于程序没有正确地验证用户权限。远程攻击者可借助web管理接口利用该漏洞获取提升的权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20181219-asa-privesc

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-818
