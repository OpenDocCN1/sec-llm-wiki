今日CNNVD共发布安全漏洞31个，更新安全漏洞4个。主要影响厂商为瑞士ABB（4个）、英国Micro Focus（2个）。主要影响产品为ABB M2M ETHERNET网络分析设备（1个）、Micro Focus SUSE Linux Enterprise操作系统（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】ABB M2M ETHERNET 授权问题漏洞

【漏洞编号】CNNVD-201812-784（CVE-2018-17926）

【漏洞详情】ABB M2M ETHERNET是瑞士ABB公司的一款网络分析设备。

ABB M2M ETHERNET FW 2.22及之前版本和ETH-FW 1.01及之前版本中存在授权问题漏洞。攻击者可利用该漏洞上传恶意的语言文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://search.abb.com/library/Download.aspx?DocumentID=ABBVU-EPBP-R-5672&LanguageCode=en&DocumentPartId=2CSG299903R4052&Action=Launch

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-784


【漏洞名称】Micro Focus SUSE Linux Enterprise libqt5-qtbase 安全漏洞

【漏洞编号】CNNVD-201812-792（CVE-2018-19873）

【漏洞详情】Micro Focus SUSE Linux Enterprise是英国Micro Focus公司的一套企业版Linux操作系统。libqt5-qtbase是其中的一个用于处理字符串、XML等内容的库。

Micro Focus SUSE Linux Enterprise中的libqt5-qtbase的QBmpHandler存在拒绝服务漏洞。攻击者可借助畸形的BMP文件利用该漏洞造成拒绝服务。以下产品受到影响：SUSE Linux Enterprise Software Development Kit 12-SP4，Linux Enterprise Software Development Kit 12-SP3，Linux Enterprise Server 12-SP4，Linux Enterprise Server 12-SP3，Linux Enterprise Desktop 12-SP4，Linux Enterprise Desktop 12-SP3。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.suse.com/support/update/announcement/2018/suse-su-20184179-1/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-792


【漏洞名称】SUSE Linux Enterprise Module for Server Applications 缓冲区错误漏洞

【漏洞编号】CNNVD-201812-795（CVE-2017-5735）

【漏洞详情】SUSE Linux Enterprise Module for Server Applications 15版本中的‘Decode()’函数存在基于堆的缓冲区溢出漏洞。攻击者可利用该漏洞提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.suse.com/support/update/announcement/2018/suse-su-20184155-1/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-795


【漏洞名称】多款3S-Smart Software Solutions产品安全漏洞

【漏洞编号】CNNVD-201812-786（CVE-2018-20025）

【漏洞详情】多款3S-Smart Software Solutions产品中存在安全漏洞，该漏洞源于使用了不充分的随机数。攻击者可利用该漏洞影响数据的机密性和完整性。以下产品受到影响：3S-Smart CODESYS Control for BeagleBone，CODESYS Control for emPC-A/iMX6，CODESYS Control for IOT2000，CODESYS Control for Linux，CODESYS Control for PFC100，CODESYS Control for PFC200，CODESYS Control for Raspberry Pi，CODESYS Control RTE V3，CODESYS Control RTE V3（用于Beckhoff CX），CODESYS Control Win V3（CODESYS Development System setup的组成部分），CODESYS Control V3 Runtime System Toolkit，CODESYS V3 Embedded Target Visu Toolkit，CODESYS V3 Remote Target Visu Toolkit，CODESYS V3 Safety SIL2，CODESYS Gateway V3，CODESYS HMI V3，CODESYS OPC Server V3，CODESYS PLCHandler SDK，CODESYS V3 Development System，CODESYS V3 Simulation Runtime（CODESYS Development System组成部分）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.codesys.com/fileadmin/data/customers/security/2018/Advisory2018-13_CDS-62811.pdf

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-786


【漏洞名称】Advantech WebAccess/SCADA 缓冲区错误漏洞

【漏洞编号】CNNVD-201812-789（CVE-2018-18999）

【漏洞详情】Advantech WebAccess/SCADA是研华（Advantech）公司的一套基于浏览器架构的SCADA软件。该软件支持动态图形显示和实时数据控制，并提供远程控制和管理自动化设备的功能。

基于Windows 2008 R2 SP1平台的Advantech WebAccess/SCADA 8.3.2版本中存在缓冲区溢出漏洞，该漏洞源于程序没有对用户提交的输入执行充分的边界检测。攻击者可利用该漏洞在受影响应用程序的上下文中执行任意代码或造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.suse.com/support/update/announcement/2018/suse-su-20184179-1/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-789
