今日CNNVD共发布安全漏洞30个，更新安全漏洞7个。主要影响厂商为美国IBM（5个）、美国Google（4个）、日本NEC（4个）。主要影响产品为IBM Security Guardium数据保护平台（4个）、Google Go编程语言（3个）、NEC Aterm WF1200CR路由器（4个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******IBM Security Guardium 跨站脚本漏洞****

**【漏洞编号】******CNNVD-201812-711********（CVE-2018-1891）****

**【漏洞详情】**IBM Security Guardium是美国IBM公司的一套提供数据保护功能的平台。该平台包括自定义UI、报告管理和流线化的审计流程构建等功能。

IBM Security Guardium 10.0版本至10.5版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞在Web UI中注入任意JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10742865

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-711

  

**【漏洞名称】******Google Go 安全漏洞****  

**【漏洞编号】******CNNVD-201812-691**（CVE-2018-16873）**

**【漏洞详情】**Google Go是美国谷歌（Google）公司的一种针对多处理器系统应用程序的编程进行了优化的编程语言。

Google Go 1.10.6之前版本和1.11.3之前的1.11.x版本（GOPATH模式）中的‘go get’命令存在远程代码执行漏洞。远程攻击者可利用该漏洞执行恶意的命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/golang/go/issues/29230

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-691

  

**【漏洞名称】****NEC Aterm WF1200CR和Aterm WG1200CR 信息泄露漏洞**

**【漏洞编号】******CNNVD-201812-707**（CVE-2018-16192）**

**【漏洞详****情】**NEC Aterm WF1200CR和Aterm WG1200CR都是日本电气（NEC）公司的路由器产品。

使用1.1.1及之前版本固件的NEC Aterm WF1200CR和使用1.0.1及之前版本固件的Aterm WG1200CR中存在信息泄露漏洞。攻击者可利用该漏洞获取设备上的注册信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://jpn.nec.com/security-info/secinfo/nv18-021.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-707

  

**【漏洞名称】********WordPress 安全漏洞******

**【****漏洞****编号****】********CNNVD-201812-694**（CVE-2018-20147）****

**【漏洞详情】**WordPress是WordPress软件基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。

WordPress 5.0.1之前版本中存在安全漏洞。攻击者可通过修改元数据利用该漏洞绕过对文件删除的限制。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/news/2018/12/wordpress-5-0-1-security-release/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-694

  

**【漏洞名称】****Ansible 安全漏洞**

**【漏洞编****号】****CNNVD-201812-717****（CVE-2018-16876）**

**【漏洞详情】**Ansible是美国Ansible公司的一款计算机系统配置管理器，它可用于发布、管理和编排计算机系统。

Ansible中存在安全漏洞。在vvv+模式下，攻击者可利用该漏洞获取敏感数据。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ansible/ansible/pull/49569/commits/4c6d714aefb05366cb329e139214c89ebb364899

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-717
