# CNNVD最新漏洞（2018-12-17）

今日CNNVD共发布安全漏洞35个，更新安全漏洞29个。主要影响厂商为美国Intel（5个）、法国Schneider Electric（3个）、美国IBM（2个）。主要影响产品为Intel Solid State Drive Toolbox管理软件（1个）、Schneider Electric Eurotherm by Schneider Electric GUIcon编程软件（3个）、IBM DB2 for Linux管理系统（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Intel Solid State Drive Toolbox 安全漏洞****

**【漏洞编号】******CNNVD-201812-667********（CVE-2018-18097）****

**【漏洞详情】**Intel Solid State Drive Toolbox是美国英特尔（Intel）公司的一款用来浏览SSD（固态硬盘）信息的驱动管理软件。

Intel Solid State Drive Toolbox 3.5.7之前版本中存在安全漏洞。本地攻击者可利用该漏洞提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.intel.com/content/www/us/en/security-center/advisory/INTEL-SA-00205.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-667

  

**【漏洞名称】******Schneider Electric Eurotherm by Schneider Electric GUIcon 安全漏洞****  

**【漏洞编号】******CNNVD-201812-660**（CVE-2018-7815）**

**【漏洞详情】**Schneider Electric Eurotherm by Schneider Electric GUIcon是法国施耐德电气（Schneider Electric）公司的一套图形用户界面编程软件。

Schneider Electric Eurotherm by Schneider Electric GUIcon 2.0（Gold Build 683.0）版本中的c3core.dll文件存在类型混淆漏洞。远程攻击者可利用该漏洞在解析GD1文件时执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.schneider-electric.com/en/download/document/SEVD-2018-338-01/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-660

  

**【漏洞名称】****IBM DB2 for Linux 安全漏洞**

**【漏洞编号】******CNNVD-201812-662**（CVE-2018-1977）**

**【漏洞详****情】**IBM DB2 for Linux是美国IBM公司的一套基于Linux平台的关系型数据库管理系统。

基于Linux平台的IBM DB2 11.1版本中的‘scalar’函数存在拒绝服务漏洞。远程攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10788089

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-662

  

**【漏洞名称】********Dell EMC iDRAC7和iDRAC8 安全漏洞******

**【****漏洞****编号****】********CNNVD-201812-673**（CVE-2018-15776）****

**【漏洞详情】**Dell EMC iDRAC7和iDRAC8都是美国戴尔（Dell）公司的包含硬件和软件的系统管理解决方案。该方案为Dell PowerEdge系统提供远程管理、崩溃系统恢复和电源控制等功能。

Dell EMC iDRAC7和iDRAC8 2.61.60.60之前版本中存在安全漏洞。物理位置接近的攻击者可利用该漏洞访问u-boot shell。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.dell.com/support/article/us/en/04/sln315190/dell-emc-idrac-multiple-vulnerabilities-cve-2018-15774-and-cve-2018-15776-?lang=en

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-673

  

**【漏洞名称】****Micro Focus Fortify Software Security Center 安全漏洞**

**【漏洞编****号】****CNNVD-201812-686****（CVE-2018-7691）**

**【漏洞详情】**Micro Focus Fortify Software Security Center（SSC）是英国Micro Focus公司的一套软件生命周期安全性管理解决方案。该产品包括应用程序安全集中管理、自动化审计和风险管理等功能。

Micro Focus Fortify SSC17.10版本、17.20版本和18.10版本中存在安全漏洞。远程攻击者可利用该漏洞未授权访问数据。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://softwaresupport.softwaregrp.com/doc/KM03298201

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-686
