今日CNNVD共发布安全漏洞179个，更新安全漏洞30个。主要影响厂商为美国Adobe（87个）、美国Microsoft（38个）、德国Siemens（10个）。主要影响产品为Adobe Acrobat文件转换工具（87个）、Microsoft Windows 10操作系统（6个）、Siemens SINUMERIK 808D系统控制器（4个）。

今日需关注的典型漏洞如下:

【漏洞名称】Adobe Acrobat和Reader 缓冲区错误漏洞

【漏洞编号】CNNVD-201812-501（CVE-2018-19702）

【漏洞详情】Adobe Acrobat和Reader都是美国奥多比（Adobe）公司的产品。前者是一套PDF文件编辑和转换工具，后者是一套PDF文档阅读软件。

Adobe Acrobat和Reader中存在越界写入漏洞。远程攻击者可利用该漏洞执行任意代码。以下产品和版本受到影响：Acrobat DC（Continuous） 2019.008.20081及之前版本（Windows）和2019.008.20080 及之前版本（macOS），Acrobat 2017（Classic 2017）2017.011.30106及之前版本（Windows）和2017.011.30105及之前版本（macOS），Acrobat DC（Classic 2015）2015.006.30457及之前版本（Windows）和2015.006.30456及之前版本（macOS）；Acrobat Reader DC（Continuous）2019.008.20081及之前版本（Windows）和2019.008.20080 及之前版本（macOS）；Acrobat Reader 2017（Classic 2017）2017.011.30106及之前版本（Windows）和2017.011.30105及之前版本（macOS）；Acrobat Reader DC （Classic 2015）2015.006.30457及之前版本（Windows）和2015.006.30456及之前版本（macOS）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://helpx.adobe.com/security/products/acrobat/apsb18-41.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-501


【漏洞名称】Microsoft Internet Explorer 安全漏洞

【漏洞编号】CNNVD-201812-458（CVE-2018-8619）

【漏洞详情】Microsoft Windows 10等都是美国微软（Microsoft）公司发布的一系列操作系统。Internet Explorer（IE）是一款Windows操作系统附带的Web浏览器。

Microsoft IE 9、10和11中存在远程代码执行漏洞，该漏洞源于VBScript执行策略没有严格限制VBScript。远程攻击者可利用该漏洞以当前用户的权限运行任意代码。以下系统版本受到影响：Microsoft Windows Server 2012（Internet Explorer 10）；Windows 10版本1703，Windows 10版本1803，Windows 10版本1809，Windows 10版本1709，Windows 10，Windows 10版本1607，Windows Server 2019，Windows Server 2016，Windows 7 SP1，Windows 8.1，Windows RT 8.1，Windows Server 2008 R2 SP1，Windows Server 2012 R2（Internet Explorer 11）；Windows Server 2008 SP2 （Internet Explorer 9）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2018-8619

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-458


【漏洞名称】多款Siemens产品权限许可和访问控制漏洞

【漏洞编号】CNNVD-201812-603（CVE-2018-11462）

【漏洞详情】Siemens SINUMERIK 808D等都是德国西门子（Siemens）公司的数控机床系统控制器。

多款Siemens产品中存在权限许可和访问控制漏洞。远程攻击者可通过发送特制的身份验证请求利用该漏洞提升权限。以下产品和版本受到影响：Siemens SINUMERIK 808D 4.7版本，4.8版本；828D 4.7 SP6 HF1之前的4.7版本；840D sl 4.7 SP6 HF5之前的4.7版本；840D sl 4.8 SP3之前的4.8版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://cert-portal.siemens.com/productcert/txt/ssa-170881.txt

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-603


【漏洞名称】IBM BigFix Platform 安全漏洞

【漏洞编号】CNNVD-201812-610（CVE-2018-1474）

【漏洞详情】IBM BigFix Platform是美国IBM公司的一套动态的集成了消息内容驱动和管理系统的多技术平台。

IBM BigFix Platform 9.5版本至9.5.9版本和9.2版本至9.2.14版本中存在安全漏洞，该漏洞源于程序错误地验证用户提交的输入。远程攻击者可利用该漏洞注入任意HTTP包头，造成服务器返回拆分的响应。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10733605

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-610
