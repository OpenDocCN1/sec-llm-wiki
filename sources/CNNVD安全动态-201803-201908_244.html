今日CNNVD共发布安全漏洞62个，更新安全漏洞3个。主要影响厂商为美国CloudBees（6个）、日本Cybozu（5个）、美国Accusoft Pegasus Imaging（1个）。主要影响产品为CloudBees Jenkins集成工具（5个）、Cybozu Remote Service服务管理软件（4个）、Accusoft PrizmDoc HTML5 Document Viewer文档查看器（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】CloudBees Jenkins 安全漏洞

【漏洞编号】CNNVD-201812-386（CVE-2018-1000861）

【漏洞详情】CloudBees Jenkins（前称Hudson Labs）是美国CloudBees公司的一套基于Java开发的持续集成工具，它主要用于监控持续的软件版本发布/测试项目和一些定时执行的任务。LTS（Long-Term Support）是CloudBees Jenkins的一个长期支持版本。

CloudBees Jenkins 2.153及之前版本和LTS 2.138.3及之前版本中的stapler/core/src/main/java/org/kohsuke/stapler/MetaClass.java文件的StaplerWeb框架存在代码执行漏洞。攻击者可借助特制的URLs利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://jenkins.io/security/advisory/2018-12-05/#SECURITY-1193

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-386


【漏洞名称】Cybozu Remote Service 安全漏洞

【漏洞编号】CNNVD-201812-401（CVE-2018-16169）

【漏洞详情】Cybozu Remote Service是日本才望子（Cybozu）公司的一套用于访问才望子（Cybozu）内部系统的远程服务管理软件。

Cybozu Remote Service 3.0.0版本至3.1.0版本中的logo setting页面存在安全漏洞。攻击者可利用该漏洞在服务器上执行任意Java代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://kb.cybozu.support/article/34311/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-401


【漏洞名称】Accusoft PrizmDoc HTML5 Document Viewer 安全漏洞

【漏洞编号】CNNVD-201812-395（CVE-2018-15805）

【漏洞详情】Accusoft PrizmDoc HTML5 Document Viewer是美国Accusoft Pegasus Imaging公司的一款HTML5文档查看器。

Accusoft PrizmDoc HTML5 Document Viewer 13.5之前版本中存在XML外部实体注入漏洞。攻击者可利用该漏洞读取任意文件或造成拒绝服务（资源消耗）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://help.accusoft.com/PrizmDoc/v13.5/HTML/webframe.html#Release_v13_5.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-395


【漏洞名称】Pivotal Software RabbitMQ for PCF 安全漏洞

【漏洞编号】CNNVD-201812-393（CVE-2018-1279）

【漏洞详情】Pivotal Software RabbitMQ for PCF是美国Pivotal Software公司的一款开源的用于支持基于全局数据传送和高容量的数据监测的消息服务器。

Pivotal Software RabbitMQ for PCF（所有版本）中存在安全漏洞。远程攻击者可利用该漏洞猜测cookie，进而利用该cookie完全控制整个集群。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://pivotal.io/security/cve-2018-1279

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-393


【漏洞名称】Ubuntu 跨站请求伪造漏洞

【漏洞编号】CNNVD-201812-406（CVE-2018-4700）

【漏洞详情】Ubuntu是英国科能（Canonical）公司和Ubuntu基金会共同开发的一套以桌面应用为主的GNU/Linux操作系统。

Ubuntu中存在跨站请求伪造漏洞，该漏洞源于Common UNIX Printing System（CUPS）错误地处理了会话cookie随机数。远程攻击者可利用该漏洞获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://usn.ubuntu.com/3842-1/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-406
