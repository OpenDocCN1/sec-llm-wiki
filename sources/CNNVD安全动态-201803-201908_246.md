今日CNNVD共发布安全漏洞62个，更新安全漏洞19个。主要影响厂商为美国Google（20个）、美国IBM（9个）、美国McAfee（3个）。主要影响产品为Android操作系统（20个）、IBM Cúram Social Program Management解决方案（3个）、McAfee True Key应用程序（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Android 权限许可和访问控制漏洞****

**【漏洞编号】******CNNVD-201812-238********（CVE-2018-9538）****

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。

Android 8.1版本和9版本中的v4l2\_slice\_video\_decode\_accelerator.cc文件的V4L2SliceVideoDecodeAccelerator::Dequeue存在提权漏洞，该漏洞源于程序执行了错误的边界检测。攻击者可利用该漏洞提升权限（越界读取）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2018-12-01

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-238

  

**【漏洞名称】******IBM Cúram Social Program Management 安全漏洞****  

**【漏洞编号】******CNNVD-201812-287**（CVE-2018-1654）**

**【漏洞详情】**IBM Cúram Social Program Management（SPM）是美国IBM公司的一套社会计划管理解决方案。该方案支持终端到终端社会项目交付的过程。

IBM Cúram SPM中存在开放重定向漏洞。远程攻击者可通过诱使用户访问特制的网站利用该漏洞伪造展示的URL，将用户重定向到恶意的网站，进而获取敏感信息或实施其他攻击。以下版本受到影响：IBM Cúram Social Program Management 7.0.2.0版本至7.0.3.0版本，7.0.0.0版本至7.0.1.0版本，6.2.0.0版本至6.2.0.6版本，6.1.0.0版本至6.1.1.6版本，6.0.5.0版本至6.0.5.10版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10739027

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-287

  

**【漏洞名称】****McAfee True Key 安全漏洞**

**【漏洞编号】******CNNVD-201812-274**（CVE-2018-6755）**

**【漏洞详****情】**McAfee True Key（TK）是美国迈克菲（McAfee）公司的一款身份验证应用程序。该程序支持面部信息识别和指纹识别等功能。

McAfee TK 5.1.230.7及之前版本中的Microsoft Windows客户端存在安全漏洞。本地攻击者可借助特制的恶意软件利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://service.mcafee.com/webcenter/portal/cp/home/articleview?articleId=TS102872

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-274

  

**【漏洞名称】********多款SEIKO EPSON打印机和扫描仪安全漏洞******

**【****漏洞****编号****】********CNNVD-201812-280**（CVE-2018-0688）****

**【漏洞详情】**EPSON DS-570W等都是日本爱普生（EPSON）公司的产品。EPSON DS-570W是一款扫描仪。EP-10VA是一款打印机设备。

多款SEIKO EPSON打印机和扫描仪中存在开放重定向漏洞。攻击者可借助Web接口利用该漏洞将用户浏览器重定向到任意网站。以下产品和版本受到影响：使用2018年3月13日之前版本固件的SEIKO EPSON DS-570W；使用2018年3月13日之前版本固件的DS-780N；使用2017年9月4日之前版本固件的EP-10VA；使用2017年6月19日之前版本固件的EP-30VA；使用2017年8月1日之前版本固件的EP-707A；使用2017年8月7日之前版本固件的EP-708A等。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.epson.jp/support/misc/20181203\_oshirase.htm

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-280

  

**【漏洞名称】****Symantec Norton Password Manager for Android 跨站脚本漏洞**

**【漏洞编****号】****CNNVD-201812-260****（CVE-2018-18362）**

**【漏洞详情】**Symantec Norton Password Manager for Android是美国赛门铁克（Symantec）公司的一款基于Android平台的密码管理应用程序。

基于Android平台的Symantec Norton Password Manager 6.1.0.1045之前版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞向用户查看的网页注入客户端脚本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.symantec.com/en\_US/article.SYMSA1470.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201812-260
