# CNNVD最新漏洞（2018-11-28）

今日CNNVD共发布安全漏洞47个，更新安全漏洞7个。主要影响厂商为美国Oracle（1个）、美国TIBCO（1个）、荷兰PowerDNS（1个）。主要影响产品为Oracle Secure Global Desktop虚拟化产品（1个）、TIBCO Statistica Server作业服务器（1个）、PowerDNS DNSDist负载均衡器（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Oracle Secure Global Desktop Administration Console 跨站脚本漏洞****

**【漏洞编号】******CNNVD-201811-733********（CVE-2018-19439）****

**【漏洞详情】**Oracle Secure Global Desktop（SGD）是美国甲骨文（Oracle）公司的一款桌面虚拟化产品。用户可通过该产品访问服务器托管的应用程序和桌面。Administration Console是其中的一个管理控制台程序。

Oracle SGD中的Administration Console 4.4版本的helpwindow.jsp页面存在跨站脚本漏洞。远程攻击者可利用该漏洞在用户的浏览器中执行任意脚本代码，进而窃取基于cookie的身份验证凭证。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.oracle.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-733

  

**【漏洞名称】****TIBCO Statistica Server TIBCO Statistica组件跨站脚本漏洞**  

**【漏洞编号】******CNNVD-201811-710**（CVE-2018-18807）**

**【漏洞详情】**TIBCO Statistica Server是美国TIBCO软件公司的一套作业服务器，它提供了一个用于共享工作空间和可重用模板的治理框架。Statistica是其中的一个组件。

TIBCO Statistica Server 13.4.0及之前版本中的TIBCO Statistica组件的web应用程序存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.tibco.com/support/advisories/2018/11/tibco-security-advisory-november-26-2018-tibco-statistica-server

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-710

  

**【漏洞名称】****PowerDNS DNSDist 安全漏洞**

**【漏洞编号】******CNNVD-201811-731**（CVE-2018-14663）**

**【漏洞详****情】**PowerDNS DNSDist是荷兰PowerDNS公司的一款负载均衡器，它能够将流量分流到不同服务器，为用户提供最佳性能。

PowerDNS DNSDist 1.3.3之前版本中存在安全漏洞。远程攻击者可借助特制的DNS查询利用该漏洞将数据作为合法记录注入后端。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://dnsdist.org/security-advisories/powerdns-advisory-for-dnsdist-2018-08.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-731

  

**【漏洞名称】******Linux kernel 安全漏洞****

**【****漏洞****编号****】******CNNVD-201811-712**（CVE-2018-16862）**

**【漏洞详情】**Linux kernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。

Linux kernel中cleancache子系统清除索引节点的方式存在安全漏洞。攻击者可利用该漏洞获取被删除文件的内容。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lore.kernel.org/patchwork/patch/1011367/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-712

  

**【漏洞名称】****TOTOLINK A3002RU 跨站脚本漏洞**

**【漏洞编****号】****CNNVD-201811-717****（CVE-2018-13308）**

**【漏洞详情】**TOTOLINK A3002RU是吉翁电子（TOTOLINK）公司的一款无线路由器产品。

TOTOLINK A3002RU 1.0.8版本中的notice\_gen.htm页面存在跨站脚本漏洞。远程攻击者可通过修改“User phrases button”字段利用该漏洞执行任意JavaScript代码。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

http://totolink.net/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-717
