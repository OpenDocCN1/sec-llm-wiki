今日CNNVD共发布安全漏洞20个。主要影响厂商为美国Artifex Software（3个）、中国华为（1个）。主要影响产品为Artifex Ghostscript解析器（3个）、Huawei Emily-AL00A智能手机（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Artifex Ghostscript 安全漏洞

【漏洞编号】CNNVD-201811-658（CVE-2018-19477）

【漏洞详情】Artifex Ghostscript是美国Artifex Software公司的一款开源的PostScript（一种用于电子产业和桌面出版领域的页面描述语言和编程语言）解析器，它可显示Postscript文件以及在非Postscript打印机上打印Postscript文件。

Artifex Ghostscript 9.26之前版本中的psi/zfjbig2.c文件存在安全漏洞。远程攻击者可利用该漏洞绕过访问限制。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.ghostscript.com/doc/9.26/History9.htm#Version9.26

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-658


【漏洞名称】Huawei Emily-AL00A 安全漏洞

【漏洞编号】CNNVD-201811-655（CVE-2018-7961）

【漏洞详情】Huawei Emily-AL00A是中国华为（Huawei）公司的一款智能手机设备。

Huawei Emily-AL00A 8.1.0.167(C00)版本中存在安全漏洞，该漏洞源于程序没有正确的处理智能短信验证码。攻击者可通过诱使用户访问恶意网站或恶意App，并进行用户注册利用该漏洞后造成信息泄露。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20181121-02-smartphone-cn

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-655


【漏洞名称】Tryton 安全漏洞

【漏洞编号】CNNVD-201811-648（CVE-2018-19443）

【漏洞详情】Tryton是一套基于Python和PostgreSQL的通用应用平台，它是OpenERP（企业资源计划ERP和客户关系管理CRM系统）的一个独立分支项目，包含了财务管理、营销管理、客户关系管理等模块，可用于创建企业资源计划系统。

Tryton 5.0.1之前的5.x版本中的客户端存在安全漏洞。攻击者可通过实施中间人攻击利用该漏洞窃取用户会话。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://discuss.tryton.org/t/security-release-for-issue7792/830

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-648

【漏洞名称】Apache HTTP Server 安全漏洞

【漏洞编号】CNNVD-201811-656（CVE-2018-1333）

【漏洞详情】Apache HTTP Server是美国阿帕奇（Apache）软件基金会的一款开源网页服务器。该服务器具有快速、可靠且可通过简单的API进行扩充的特点。

Apache HTTP Server中存在拒绝服务漏洞。远程攻击者可通过发送特制的HTTP/2请求利用该漏洞造成拒绝服务。以下版本受到影响：Apache HTTP Server 2.4.18版本，2.4.20版本，2.4.23版本，2.4.29版本，2.4.33版本，2.4.30版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://httpd.apache.org/security/vulnerabilities_24.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-656


【漏洞名称】Pixman 数字错误漏洞

【漏洞编号】CNNVD-201811-657（CVE-2015-5297）

【漏洞详情】Pixman是一个开源的用于像素操作的软件库，它提供图像合成、图像光栅化等功能。

Pixman 0.32.8之前版本中的‘general_composite_rect()’函数存在整数溢出漏洞。攻击者可利用该漏洞造成使用pixman的应用程序崩溃或执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://bugs.freedesktop.org/show_bug.cgi?id=92027

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-657
