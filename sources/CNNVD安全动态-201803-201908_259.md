今日CNNVD共发布安全漏洞18个，更新安全漏洞1个。主要影响厂商为美国IBM（2个）、德国Paessler（2个）、美国Artifex Software（1个）。主要影响产品为IBM WebSphere Application Server（WAS）应用服务器（1个）、Paessler PRTG Network Monitor网络监控软件（2个）、Artifex Ghostscript解析器（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******IBM WebSphere Application Server 安全漏洞****

**【漏洞编号】********CNNVD-201811-639**（CVE-2018-1905）****

**【漏洞详情】**IBM WebSphere Application Server（WAS）是美国IBM公司开发并发行的一款应用服务器产品，它是Java EE和Web服务应用程序的平台，也是IBM WebSphere软件平台的基础。

IBM WAS 9.0版本中存在XML外部实体注入漏洞。远程攻击者可利用该漏洞泄露敏感信息或消耗内存资源。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10738721

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-639

  

**【漏洞名称】****Paessler PRTG Network Monitor 安全漏洞**

**【漏洞编号】******CNNVD-201811-633**（CVE-2018-19411）**

**【漏洞详情】**Paessler PRTG Network Monitor是德国Paessler公司的一套网络监控软件。该软件提供使用情况的监测、数据包嗅探、深入分析和简明的报告等功能。

Paessler PRTG Network Monitor 18.2.40.1683之前版本中存在安全漏洞，该漏洞源于程序没有检查或正确的检查用户权限。具有只读权限的攻击者可通过发送HTTP请求利用该漏洞创建具有读写权限的账户（包括管理员账户）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.paessler.com/prtg/history/stable#18.2.40.1683

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-633

  

**【漏洞名称】****Artifex Ghostscript 安全漏洞**

**【漏洞编号】******CNNVD-201811-635**（CVE-2018-19409）**

**【漏洞详****情】**Artifex Ghostscript是美国Artifex Software公司的一款开源的PostScript（一种用于电子产业和桌面出版领域的页面描述语言和编程语言）解析器，它可显示Postscript文件以及在非Postscript打印机上打印Postscript文件。

Artifex Ghostscript 9.26之前版本中存在安全漏洞，该漏洞源于在使用其他设备时，程序没有正确的检查LockSafetyParams。攻击者可通过调用.setdevice利用该漏洞绕过安全限制。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.ghostscript.com/doc/9.26/History9.htm#Version9.26

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-635

  

**【漏洞名称】******Google Chrome GPU 安全漏洞****

**【****漏洞****编号****】******CNNVD-201811-637**（CVE-2018-17479）**

**【漏洞详情】**Google Chrome是美国谷歌（Google）公司开发的一款Web浏览器。GPU是其中的一个图形处理器组件。

Google Chrome 70.0.3538.110之前版本中的GPU存在释放后重用漏洞。远程攻击者可利用该漏洞在浏览器的上下文中执行任意代码或造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://chromereleases.googleblog.com/2018/11/stable-channel-update-for-desktop\_19.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-637

  

**【漏洞名称】****Huawei Honor 7A和Honor 9 Lite 信息泄露漏洞**

**【漏洞编****号】****CNNVD-201811-638****（CVE-2018-7946）**

**【漏洞详情】**Huawei Honor 7A和Honor 9 Lite都是中国Huawei（华为）公司的智能手机产品。

Huawei Honor 7A 8.0.0.195(C00)之前版本和华为Honor 9 Lite 8.0.0.182(C01)之前版本中存在信息泄露漏洞。攻击者可通过在手机上进行特殊配置并诱使用户输入敏感信息利用该漏洞泄露敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20181121-01-phone-cn

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-638
