# CNNVD最新漏洞（2018-11-20）

今日CNNVD共发布安全漏洞62个，更新安全漏洞6个。主要影响厂商为中国中兴（5个）、中国联想（4个）、美国IBM（2个）。主要影响产品为ZTE ZXHN F670调制解调器（5个）、Lenovo Chassis Management Module（CMM）机箱管理模块（2个）、IBM API Connect解决方案（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******ZTE ZXHN F670 缓冲区错误漏洞****

**【漏洞编号】********CNNVD-201811-525**（CVE-2018-7359）****

**【漏洞详情】**ZTE ZXHN F670是中国中兴通讯（ZTE）公司的一款调制解调器。

ZTE ZXHN F670 V1.1.10P3T18及之前版本中存在基于堆的缓冲区溢出漏洞。攻击者可利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://support.zte.com.cn/support/news/LoopholeInfoDetail.aspx?newsId=1009383

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-525

  

**【漏洞名称】****Lenovo Chassis Management Module 安全漏洞**  

**【漏洞编号】******CNNVD-201811-521**（CVE-2018-9071）**

**【漏洞详情】**Lenovo Chassis Management Module（CMM）是中国联想（Lenovo）公司的一款机箱管理模块，它主要用于管理和配置已安装的Lenovo Flex System组件。

Lenovo CMM 2.0.0之前版本中存在安全漏洞。攻击者可利用该漏洞检索有关当前身份验证配置设置的信息（包括：密码长度、到期时间等）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.lenovo.com/us/zh/solutions/len-23806

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-521

  

**【漏洞名称】****IBM API Connect 安全漏洞**

**【漏洞编号】******CNNVD-201811-517**（CVE-2018-1779）**

**【漏洞详****情】**IBM API Connect（又名APIConnect）是美国IBM公司的一套用于管理API生命周期的集成解决方案。该方案支持创建、运行、管理和保护API和微服务等。

IBM API Connect 2018.1版本至2018.3.7版本中存在安全漏洞，该漏洞源于程序没有限制JSON载荷的大小。攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10733851

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-517

  

**【漏洞名称】******Google gVisor 安全漏洞****

**【****漏洞****编号****】******CNNVD-201811-561**（CVE-2018-19333）**

**【漏洞详情】**Google gVisor是一款使用Go语言编写的使用在Linux系统中的用户空间内核。

Google gVisor 2018-11-01之前版本中的pkg/sentry/kernel/shm/shm.go文件存在安全漏洞，该漏洞源于程序没有正确的处理引用计数。攻击者可利用该漏洞覆盖以root权限运行进程中的内存位置。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/google/gvisor/commit/0e277a39c8b6f905e289b75e8ad0594e6b3562ca

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-561

  

**【漏洞名称】****Foxit Reader 安全漏洞**

**【漏洞编****号】****CNNVD-201811-563****（CVE-2018-19341）**

**【漏洞详情】**Foxit Reader是中国福昕（Foxit）软件公司的一款PDF文档阅读器。

Foxit Reader 9.3.0.10826版本中的FoxitReader.exe文件的u3d插件9.3.0.10809版本存在安全漏洞。远程攻击者可利用该漏洞造成拒绝服务（越界读取）或获取敏感信息。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.foxitsoftware.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-563
