今日CNNVD共发布安全漏洞20个，更新安全漏洞24个。主要影响厂商为美国Polycom（2个）、美国IBM（1个）、美国ZOHO（1个）。主要影响产品为Polycom Trio商务会议电话（2个）、IBM Jazz Reporting Service（JRS）应用程序（1个）、ZOHO ManageEngine OpManager监控软件（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Polycom Trio Bluetooth子系统安全漏洞****

**【漏洞编号】********CNNVD-201811-510**（CVE-2018-14934）****

**【漏洞详情】**Polycom Trio是美国宝利通（Polycom）公司的一款Trio系列的商务会议电话。Bluetooth subsystem是其中的一个蓝牙子系统。

使用5.5.4之前版本软件的Polycom Trio上的Bluetooth子系统中存在安全漏洞，该漏洞源于程序没有执行正确的访问控制。远程攻击者可借助Trio的扩音器利用该漏洞在未经身份验证或用户不知情的情况下记录音频。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.polycom.com/content/dam/polycom-support/global/documentation/bluetooth-authentication-weakness-trio.pdf

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-510

  

**【漏洞名称】****IBM Jazz Reporting Service Report Builder 安全漏洞**  

**【漏洞编号】******CNNVD-201811-497**（CVE-2018-1639）**

**【漏洞详情】**IBM Jazz Reporting Service（JRS）是美国IBM公司的一套用于发现跨项目报表的应用程序，它可与IBM Rational CLM的Rational解决方案（用于管理开发项目的所有生命周期）集成使用，CLM用户可在仪表板中访问JRS提供的报表，包括显示所有项目的状态，并跨应用程序、跨项目（甚至跨时间表）来汇聚数据。Report Builder是其中的一个用于快速创建报表的工具。

IBM JRS的Report Builder中存在安全漏洞。攻击者可利用该漏洞越权获取敏感信息。以下版本受到影响：IBM JRS 5.0版本，5.0.1版本，5.0.2版本，6.0版本，6.0.1版本，6.0.2版本，6.0.3版本，6.0.4版本，6.0.5版本，6.0.6版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10731727

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-497

  

**【漏洞名称】****ZOHO ManageEngine OpManager 跨站脚本漏洞**

**【漏洞编号】******CNNVD-201811-502**（CVE-2018-19288）**

**【漏洞详****情】**ZOHO ManageEngine OpManager是美国卓豪（ZOHO）公司的一套网络、服务器及虚拟化监控软件。

ZOHO ManageEngine OpManager Build 123223之前的12.3版本中存在跨站脚本漏洞。远程攻击者可借助updateWidget API利用该漏洞注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.manageengine.com/network-monitoring/help/read-me.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-502

**【漏洞名称】******Sonatype Nexus Repository Manager 跨站脚本漏洞****

**【****漏洞****编号****】******CNNVD-201811-512**（CVE-2018-16619）**

**【漏洞详情】**Sonatype Nexus Repository Manager（又名NXRM）是一款maven仓库管理器。

Sonatype NXRM 3.14之前版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞在用户浏览器中执行任意的JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.sonatype.com/hc/en-us/articles/360010789893-CVE-2018-16619-Nexus-Repository-Manager-XSS-October-17-2018

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-512

  

**【漏洞名称】****Micro Focus NetIQ Access Manager 跨站脚本漏洞**

**【漏洞编****号】****CNNVD-201811-505****（CVE-2018-12480）**

**【漏洞详情】**Micro Focus NetIQ Access Manager是英国Micro Focus公司的一套资源访问控制解决方案。该方案可对本地和远程用户提供多重身份认证、数据加密、单点登录和SSL VPN等功能。

Micro Focus NetIQ Access Manager 4.4 SP3之前版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.microfocus.com/kb/doc.php?id=7023513

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-505
