# CNNVD最新漏洞（2018-11-16）

今日CNNVD共发布安全漏洞67个，更新安全漏洞53个。主要影响厂商为美国Google（16个）、德国Siemens（9个）、中国华为（5个）。主要影响产品为Android操作系统（14个）、Siemens SIMATIC S7-400逻辑控制器（2个）、Huawei eSpace 7950智能IP视频话机（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Android 缓冲区错误漏洞****

**【漏洞编号】********CNNVD-201811-453**（CVE-2018-9521）****

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。

Android 9版本中的NuPlayer2CCDecoder.cpp文件的parseMPEGCCData存在越界写入漏洞，该漏洞源于程序没有执行正确的边界检查。远程攻击者可利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2018-11-01

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-453

  

**【漏洞名称】****Siemens SIMATIC S7-400 输入验证漏洞**  

**【漏洞编号】******CNNVD-201811-490**（CVE-2018-16557）**

**【漏洞详情】**Siemens SIMATIC S7-400是德国西门子（Siemens）公司的一款用于制造和过程自动化领域的可编程逻辑控制器产品。

Siemens SIMATIC S7-400中存在输入验证漏洞。攻击者可通过向TCP 102端口发送特制的数据包利用该漏洞造成拒绝服务。以下版本受到影响：Siemens S7-400 6及之前版本(包括F)，S7-400 PN/DP 7版本(包括F)，S7-400H 4.5及之前版本，S7-400H 6版本，S7-410 8.2.1之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://support.industry.siemens.com/cs/ww/en/view/109476571

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-490

  

**【漏洞名称】****Huawei eSpace 7950 安全漏洞**

**【漏洞编号】******CNNVD-201811-493**（CVE-2018-7959）**

**【漏洞详****情】**Huawei eSpace 7950是中国华为（Huawei）公司的一款智能IP视频话机产品。

Huawei eSpace 7950 V200R003C30版本中存在安全漏洞，该漏洞源于程序使用了短秘钥。当用户使用SRTP进行通话时，攻击者可利用该漏洞实施中间人攻击，拦截并破解通话信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20181114-02-espace-cn

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-493

**【漏洞名称】******Cybozu Office 路径遍历漏洞****

**【****漏洞****编号****】******CNNVD-201811-478**（CVE-2018-0703）**

**【漏洞详情】**Cybozu Office是日本才望子（Cybozu）公司的一套基于Web的跨平台协同办公解决方案。

Cybozu Office 10.0.0版本至10.8.1版本中存在目录遍历漏洞。攻击者可利用该漏洞删除服务器上的任意文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://kb.cybozu.support/article/34088/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-478

  

**【漏洞名称】****IBM WebSphere Application Server 路径遍历漏洞**

**【漏洞编****号】****CNNVD-201811-496****（CVE-2018-1797）**

**【漏洞详情】**IBM WebSphere Application Server（WAS）是美国IBM公司开发并发行的一款应用服务器产品，它是Java EE和Web服务应用程序的平台，也是IBM WebSphere软件平台的基础。

IBM WAS（使用Enterprise bundle Archives (EBA)）中存在目录遍历漏洞。本地攻击者可通过诱使用户提取带有../序列的特制ZIP归档文件利用该漏洞写入任意文件。目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10730699

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-496
