今日CNNVD共发布安全漏洞35个，更新安全漏洞3个。主要影响厂商为德国Paessler（2个）、美国Apple（2个）、美国Dell（1个）。主要影响产品为Paessler PRTG Network Monitor网络监控软件（2个）、Apple iOS操作系统（1个）、Dell EMC RSA BSAFE Micro Edition Suite加密工具包（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Paessler PRTG Network Monitor 安全漏洞

【漏洞编号】CNNVD-201811-304（CVE-2018-19203）

【漏洞详情】Paessler PRTG Network Monitor是德国Paessler公司的一套网络监控软件。该软件提供使用情况的监测、数据包嗅探、深入分析和简明的报告等功能。

Paessler PRTG Network Monitor 18.2.41.1652之前版本中存在安全漏洞。远程攻击者可通过发送HTTP请求利用该漏洞终止PRTG Core Server Service。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.paessler.com/prtg/history/stable#18.2.41.1652

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-304


【漏洞名称】Apple iOS libxpc 安全漏洞

【漏洞编号】CNNVD-201811-333（CVE-2018-4404）

【漏洞详情】Apple iOS是美国苹果（Apple）公司为移动设备所开发的一套操作系统。libxpc是其中的一个Apple XPC库的开源实现。

Apple iOS 11.4之前版本中的libxpc组件存在安全漏洞。攻击者可利用该漏洞以系统权限执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://support.apple.com/en-us/HT208848

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-333


【漏洞名称】Dell EMC RSA BSAFE Micro Edition Suite 安全漏洞

【漏洞编号】CNNVD-201811-331（CVE-2018-15769）

【漏洞详情】Dell EMC RSA BSAFE Micro Edition Suite（MES）是美国戴尔（Dell）公司的一套加密工具包。该工具包可帮助开发人员实现稳定、安全的应用程序设计。

Dell MES 4.1.6.2之前的4.1.x版本和4.0.11之前的4.0.x版本中存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（服务崩溃）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.dell.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-331

【漏洞名称】IBM WebSphere Application Server安装检测工具跨站脚本漏洞

【漏洞编号】CNNVD-201811-332（CVE-2018-1643）

【漏洞详情】IBM WebSphere Application Server（WAS）是美国IBM公司开发并发行的一款应用服务器产品，它是Java EE和Web服务应用程序的平台，也是IBM WebSphere软件平台的基础。

IBM WAS 9.0版本、8.5版本和8.0版本中的安装检测工具存在跨站脚本漏洞。远程攻击者可利用该漏洞向Web UI中注入任意的JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10716857

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-332


【漏洞名称】Netwide Assembler 安全漏洞

【漏洞编号】CNNVD-201811-310（CVE-2018-19209）

【漏洞详情】Netwide Assembler（NASM）是一个基于Linux的汇编器，它能够创建二进制文件并编写引导加载程序。

NASM 2.14rc15版本中的asm/labels.c文件的‘find_label’函数存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（空指针逆向引用）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bugzilla.nasm.us/show_bug.cgi?id=3392522

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-310
