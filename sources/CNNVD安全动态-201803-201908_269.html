今日CNNVD共发布安全漏洞64个，更新安全漏洞2个。主要影响厂商为美国PrestaShop（3个）、美国IBM（2个）、美国VMware（2个）。主要影响产品为PrestaShop for Windows解决方案（1个）、IBM Spectrum Protect数据保护平台（1个）、VMware ESXi管理程序（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】PrestaShop for Windows 安全漏洞

【漏洞编号】CNNVD-201811-239（CVE-2018-19124）

【漏洞详情】PrestaShop for Windows是美国PrestaShop公司的一套基于Windows平台的开源电子商务解决方案。该方案提供多种支付方式、短消息提醒和商品图片缩放等功能。

基于Windows平台的PrestaShop 1.6.1.23之前的1.6.x版本和1.7.4.4之前的1.7.x版本中存在安全漏洞。远程攻击者可利用该漏洞写入任意的图像文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://build.prestashop.com/news/prestashop-1-7-4-4-1-6-1-23-maintenance-releases/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-239


【漏洞名称】IBM Spectrum Protect Client和Spectrum Protect for Virtual Environments 安全漏洞

【漏洞编号】CNNVD-201811-277（CVE-2018-1786）

【漏洞详情】IBM Spectrum Protect（前称Tivoli Storage Manager）是美国IBM公司的一套数据保护平台，它为企业提供单一控制和管理点，并支持对所有规模的虚拟、物理和云环境进行备份和恢复。IBM Spectrum Protect Client是它的客户端程序。Spectrum Protect for Virtual Environments是虚拟环境版本。

IBM Spectrum Protect Client和Spectrum Protect for Virtual Environments中存在拒绝服务漏洞。攻击者可利用该漏洞造成TCP/IP资源泄露，导致拒绝服务。以下产品和版本受到影响：IBM Spectrum Protect Client 8.1.0.0版本至8.1.6.0版本；IBM Spectrum Protect for Virtual Environments: Data Protection for Vmware 8.1.0.0版本至8.1.6.0版本，7.1.0.0版本至7.1 8.3版本；IBM Spectrum Protect for Virtual Environments: Data Protection for Hyper-V 8.1.0.0版本至8.1.6.0版本，7.1.0.0版本至7.1.8.0版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10738765

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-277


【漏洞名称】VMware ESXi 安全漏洞

【漏洞编号】CNNVD-201811-281（CVE-2018-6982）

【漏洞详情】VMware ESXi是美国威睿（VMware）公司的一种直接安装在物理服务器上，并将物理服务器划分成多个虚拟机的裸机虚拟化管理程序。该程序具有占用磁盘空间少、更高的可靠性和安全性等特点。

VMware ESXi 6.7版本、6.5版本和6.0版本中存在安全漏洞，该漏洞源于vmxnet3虚拟网络调节器使用了未初始化的栈内存。攻击者可利用该漏洞泄露信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.vmware.com/security/advisories/VMSA-2018-0027.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-281

【漏洞名称】Dell EMC RecoverPoint和RecoverPoint for Virtual Machines 安全漏洞

【漏洞编号】CNNVD-201811-290（CVE-2018-15772）

【漏洞详情】Dell EMC RecoverPoint和RecoverPoint for Virtual Machines都是美国戴尔（Dell）公司的产品。前者是一套灾难恢复和数据保护软件，后者是一套面向VMware环境的灾难恢复解决方案。

Dell EMC RecoverPoint 5.1.2.1之前版本和RecoverPoint for Virtual Machines 5.2.0.2之前版本中存在安全漏洞。攻击者可借助Boxmgmt CLI利用该漏洞消耗大量内存，造成系统运行缓慢或确定系统文件是否存在。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://support.emc.com/search/?text=RecoverPoint&searchLang=en_US&facetResource=DOWN

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-290


【漏洞名称】Open Ticket Request System 跨站脚本漏洞

【漏洞编号】CNNVD-201811-266（CVE-2018-19141）

【漏洞详情】Open Ticket Request System（OTRS）是德国OTRS集团的一套开源缺陷跟踪管理系统软件。该软件将电话，邮件等各种渠道提交进来的服务请求归类为不同的队列、服务级别，服务人员通过OTRS系统来跟踪和回复客户。

OTRS 4.0.33之前的4.0.x版本和5.0.31之前的5.0.x版本中存在跨站脚本漏洞。远程攻击者可通过操纵URL利用该漏洞执行JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://community.otrs.com/security-advisory-2018-09-security-update-for-otrs-framework/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-266
