今日CNNVD共发布安全漏洞36个，更新安全漏洞11个。主要影响厂商为美国Brocade（8个）、美国Google（6个）、美国IBM（3个）。主要影响产品为Brocade Fabric OS（FOS）操作系统（8个）、Android操作系统（6个）、IBM WebSphere Application Server（WAS）应用服务器（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Brocade Fabric OS 安全漏洞

【漏洞编号】CNNVD-201811-215（CVE-2018-6433）

【漏洞详情】Brocade Fabric OS（FOS）是美国博科通讯系统（Brocade）公司的一套使用在交换机和路由器等设备中的嵌入式操作系统。

Brocade FOS中的‘secryptocfg export’命令存在安全漏洞。本地攻击者可利用该漏洞绕过导出文件权限限制。以下版本受到影响：Brocade Fabric OS 8.2.1之前的版本，8.1.2f之前的版本，8.0.2f之前的版本，7.4.2d之前的版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.broadcom.com/support/fibre-channel-networking/security-advisories/brocade-security-advisory-2018-728

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-215


【漏洞名称】Android System 信息泄露漏洞

【漏洞编号】CNNVD-201811-229（CVE-2018-9540）

【漏洞详情】Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。System是其中的一个系统组件。

Android中的System组件存在信息泄露漏洞。攻击者可利用该漏洞获取敏感信息。以下版本受到影响：Android 7.0、7.1.1、7.1.2、8.0、8.1、9.0。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://source.android.com/security/bulletin/2018-11-01.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-229


【漏洞名称】IBM WebSphere Application Server（WAS）

【漏洞编号】CNNVD-201811-205（CVE-2018-1798）

【漏洞详情】IBM WebSphere Application Server（WAS）是美国IBM公司开发并发行的一款应用服务器产品，它是Java EE和Web服务应用程序的平台，也是IBM WebSphere软件平台的基础。Message Migration Utility（SIBMsgMigration）是一款数据迁移工具。

使用Message Migration Utility的IBM WAS中存在跨站脚本漏洞。远程攻击者可利用该漏洞在Web UI上执行任意JavaScript代码。以下版本受到影响：IBM WebSphere Application Server 7.0版本、8.0版本、8.5版本、9.0版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10730703

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-205

【漏洞名称】Philips iSite PACS和IntelliSpace PACS 安全漏洞

【漏洞编号】CNNVD-201811-201（CVE-2018-17906）

【漏洞详情】Philips iSite PACS和IntelliSpace PACS都是荷兰飞利浦（Philips）公司的用于医疗行业的放射学影像管理系统。

Philips iSite PACS和IntelliSpace PACS中存在安全漏洞。攻击者可利用该漏洞控制系统的组件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.usa.philips.com/healthcare/about/customer-support/product-security

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-201


【漏洞名称】Apache Hive 安全漏洞

【漏洞编号】CNNVD-201811-203（CVE-2018-1314）

【漏洞详情】Apache Hive是美国阿帕奇（Apache）软件基金会的一套基于Hadoop（分布式系统基础架构）的数据仓库软件。该软件提供了一个数据集成方法和一种高级的查询语言，以支持在Hadoop上进行大规模数据分析。

Apache Hive 2.3.3和3.1.0及之前的版本中存在安全漏洞，该漏洞源于Hive‘EXPLAIN’操作没有正确验证查询的权限。攻击者可利用该漏洞对任意表或视图执行‘EXPLAIN’并泄露表元数据和统计信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://lists.apache.org/thread.html/3da47dbcbf09697387f29d2f1aed970523b6b334d93afd3cced23727@%3Cdev.hive.apache.org%3E

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-203
