CNNVD最新漏洞（2018-11-08）

今日CNNVD共发布安全漏洞35个，更新安全漏洞29个。主要影响厂商为美国Google（5个）、美国TIBCO（5个）、美国IBM（3个）。主要影响产品为Android操作系统（5个）、TIBCO ActiveSpaces解决方案（1个）、IBM Cognos Analytics商业智能软件（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Android kernel ‘hidp_process_report’函数数字错误漏洞

【漏洞编号】CNNVD-201811-097（CVE-2018-9363）

【漏洞详情】Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。kernel是其中的一个内核。

Android kernel的bluetooth组件中的‘hidp_process_report’函数存在整数溢出漏洞。攻击者可利用该漏洞造成拒绝服务（越界写入）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2018-06-01

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-097


【漏洞名称】TIBCO ActiveSpaces administrative daemon组件跨站请求伪造漏洞

【漏洞编号】CNNVD-201811-109（CVE-2018-12411）

【漏洞详情】TIBCO ActiveSpaces是美国TIBCO一套提供内存计算、内存数据网格和容错数据存储的解决方案。administrative daemon（tibdgadmind）是其中的一个守护进程组件。

TIBCO ActiveSpaces中的administrative daemon组件存在跨站请求伪造漏洞。远程攻击者可利用该漏洞获取管理员权限，删除数据表，删除节点。以下产品和版本受到影响：TIBCO ActiveSpaces - Community Edition 3.3.0，3.4.0，3.5.0版本；TIBCO ActiveSpaces - Developer Edition 3.0.0，3.1.0，3.3.0，3.4.0，3.5.0版本；TIBCO ActiveSpaces - Enterprise Edition 3.0.0，3.1.0，3.2.0，3.3.0，3.4.0，3.5.0版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.tibco.com/support/advisories/2018/11/tibco-security-advisory-november-6-2018-tibco-activespaces

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-109


【漏洞名称】IBM Cognos Analytics Configuration 安全漏洞

【漏洞编号】CNNVD-201811-123（CVE-2018-1842）

【漏洞详情】IBM Cognos Analytics（前称Cognos BI）是美国IBM公司的一套商业智能软件。该软件包括报表、仪表板和记分卡等，并可通过分析关键因素与关键干系人等内容，协助企业调整决策。IBM Cognos Analytics Configuration tool是其中的一个配置工具。

IBM Cognos Analytics Configuration 11.0.0.0至11.0.12.0版本中存在安全漏洞。攻击者可利用该漏洞绕过OIDC命名空间签名验证。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

http://www-01.ibm.com/support/docview.wss?uid=ibm10738249

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-123

【漏洞名称】Dell OpenManage Network Manager 安全漏洞

【漏洞编号】CNNVD-201811-125（CVE-2018-15768）

【漏洞详情】Dell OpenManage Network Manager（OMNM）是美国戴尔（Dell）公司的一款网络管理器。该产品主要用于管理异构网络环境的全部生命周期。

Dell OMNM 6.5.0之前的版本中安全漏洞，该漏洞源于嵌入MySQL数据库使用不安全的默认配置。攻击者可利用该漏洞访问服务器文件系统上的文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.dell.com/support/article/cn/zh/cndhs1/sln314610/dell-openmanage-network-manager-security-vulnerabilities?lang=en

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-125


【漏洞名称】ZOHO ManageEngine Network Configuration Manager和OpManager 安全漏洞

【漏洞编号】CNNVD-201811-094（CVE-2018-18980）

【漏洞详情】ZOHO ManageEngine Network Configuration Manager和OpManager都是美国卓豪（ZOHO）公司的产品。ZOHO ManageEngine Network Configuration Manager是一套用于配置交换机、路由器、防火墙和其他网络设备的网络配置管理、网络变更和配置管理（NCCM）软件。OpManager是一套网络、服务器及虚拟化监控软件。该软件提供监视配置、告警和通知、监控报表等功能。

ZOHO ManageEngine Network Configuration Manager和OpManager 12.3.214之前的版本中存在XML外部实体注入漏洞。攻击者可借助‘RequestXML’参数利用该漏洞将本地文件传输到任意远程FTP服务器。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.manageengine.com/network-monitoring/help/read-me.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-094
