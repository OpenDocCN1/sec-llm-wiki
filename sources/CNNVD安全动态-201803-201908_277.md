# CNNVD最新漏洞（2018-11-05）

今日CNNVD共发布安全漏洞53个，更新安全漏洞6个。主要影响厂商为美国IBM（7个）、美国Apple（3个）、美国Microstrategy（3个）。主要影响产品为IBM Robotic Process Automation with Automation Anywhere解决方案（4个）、Apple tvOS电视操作系统（1个）、Microstrategy Web数据分析平台（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******IBM Robotic Process Automation with Automation Anywhere 安全漏洞****

**【漏洞编号】********CNNVD-201810-1582**（CVE-2018-1878）****

**【漏洞详情】**IBM Robotic Process Automation with Automation Anywhere是美国IBM公司和Automation Anywhere共同开发的一套流程自动化解决方案。

IBM Robotic Process Automation with Automation Anywhere 11.0版本中存在安全漏洞。攻击者可利用该漏洞获取Web请求中的敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10735977

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-1582

  

**【漏洞名称】****Apple tvOS IOKit 安全漏洞**  

**【漏洞编号】******CNNVD-201810-1580**（CVE-2018-4383）**

**【漏洞详情】**Apple tvOS是美国苹果（Apple）公司的一套智能电视操作系统。IOKit是其中的一个读取系统信息的组件。

Apple tvOS 12之前版本中IOKit组件存在安全漏洞。攻击者可利用该漏洞以内核权限执行任意代码（内存损坏）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://support.apple.com/en-us/HT209107

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-1580

  

**【漏洞名称】****Microstrategy Web 跨站脚本漏洞**

**【漏洞编号】******CNNVD-201810-1571**（CVE-2018-18775）**

**【漏洞详****情】**Microstrategy Web是美国Microstrategy公司的一套企业数据分析平台。该平台具有数据发现、数据可视化和报表生成等功能。

Microstrategy Web 7版本中的Login.asp页面存在跨站脚本漏洞，该漏洞源于程序没有充分的编码用户控制的输入。远程攻击者可借助‘Msg’参数利用该漏洞注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.microstrategy.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-1571

**【漏洞名称】******Schneider Electric InduSoft Web Studio和InTouch Edge HMI 缓冲区错误漏洞****

**【****漏洞****编号****】******CNNVD-201811-019**（CVE-2018-17916）**

**【漏洞详情】**Schneider Electric InduSoft Web Studio和InTouch Edge HMI（前称InTouch Machine Edition）都是法国施耐德电气（Schneider Electric）公司的嵌入式HMI软件包。该产品为HMI客户端提供读取、写入标签和事件监控功能。

Schneider Electric InduSoft Web Studio 8.1 SP2之前版本和InTouch Edge HMI 2017 SP2之前版本中的TCP/IP Server Task存在基于栈的缓冲区溢出漏洞。远程攻击者可利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://sw.aveva.com/hubfs/assets-2018/pdf/security-bulletin/SecurityBulletin\_LFSec130.pdf

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-019

  

**【漏洞名称】****ZOHO ManageEngine OpManager 跨站脚本漏洞**

**【漏洞编****号】****CNNVD-201811-028****（CVE-2018-18715）**

**【漏洞详情】**ZOHO ManageEngine OpManager是美国卓豪（ZOHO）公司的一套网络、服务器及虚拟化监控软件。

ZOHO ManageEngine OpManager 12.3版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.manageengine.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201811-028
