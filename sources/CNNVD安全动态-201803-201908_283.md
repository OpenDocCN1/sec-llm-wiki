今日CNNVD共发布安全漏洞15个。主要影响厂商为美国IBM（3个）、英国Sophos（2个）、美国Symantec（1个）。主要影响产品为IBM WebSphere Application Server（WAS）应用服务器（1个）、Sophos HitmanPro.Alert恶意软件扫描/删除工具（2个）、Symantec Veritas NetBackup（NBU）Appliance管理设备（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******IBM WebSphere Application Server CacheMonitor 跨站脚本漏洞****

**【漏洞编号】********CNNVD-201810-1276**（CVE-2018-1767）****

**【漏洞详情】**IBM WebSphere Application Server（WAS）是美国IBM公司开发并发行的一款应用服务器产品，它是Java EE和Web服务应用程序的平台，也是IBM WebSphere软件平台的基础。CacheMonitor是其中的一个缓存监视器组件。

IBM WAS CacheMonitor中存在跨站脚本漏洞。远程攻击者可利用该漏洞在Web UI中注入任意JavaScript代码。以下版本受到影响：IBM WebSphere Application Server Liberty版本，9.0版本，8.5版本，8.0版本，7.0版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.ibm.com/support/docview.wss?uid=ibm10729547

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-1276

  

**【漏洞名称】****Sophos HitmanPro.Alert 安全漏洞**  

**【漏洞编号】******CNNVD-201810-1264**（CVE-2018-3970）**

**【漏洞详情】**Sophos HitmanPro.Alert是英国Sophos公司的一款恶意软件扫描/删除工具。

Sophos HitmanPro.Alert 3.7.6.744版本中的0x222000 IOCTL handler功能存在内存泄露漏洞。攻击者可通过发送特制的IRP请求利用该漏洞造成内核内存泄露。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.hitmanpro.com/en-us/alert.aspx

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-1264

  

**【漏洞名称】****Symantec Veritas NetBackup Appliance 安全漏洞**

**【漏洞编号】******CNNVD-201810-1268**（CVE-2018-18652）**

**【漏洞详****情】**Symantec Veritas NetBackup（NBU）Appliance是美国赛门铁克（Symantec）公司的一款企业级备份管理设备。

Symantec Veritas NBU Appliance 3.1.2之前版本中存在安全漏洞，该漏洞源于程序未充分过滤用户提交的输入。远程攻击者可利用该漏洞以root身份执行任意命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.veritas.com/content/support/en\_US/security/VTS18-003.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-1268

**【漏洞名称】******xorg-x11-server 安全漏洞****

**【****漏洞****编号****】******CNNVD-201810-1266**（CVE-2018-14665）**

**【漏洞详情】**xorg-x11-server是多个厂商操作系统中所捆绑的X窗口系统显示服务器。

xorg-x11-server 1.20.3之前版本中存在安全漏洞。本地攻击者可利用该漏洞提升权限，进而以root权限运行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://gitlab.freedesktop.org/xorg/xserver/commit/50c0cf885a6e91c0ea71fb49fa8f1b7c86fe330e

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-1266

  

**【漏洞名称】****Advantech WebAccess 访问控制错误漏洞**

**【漏洞编****号】****CNNVD-201810-1272****（CVE-2018-17908）**

**【漏洞详情】**Advantech WebAccess是研华（Advantech）公司的一套基于浏览器架构的HMI/SCADA软件。该软件支持动态图形显示和实时数据控制，并提供远程控制和管理自动化设备的功能。

Advantech WebAccess 8.3.2及之前版本中存在访问控制错误漏洞。攻击者可利用该漏洞运行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

http://support.advantech.com/support/DownloadSRDetail\_New.aspx?SR\_ID=1-MS9MJV&Doc\_Source=Download

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-1272
