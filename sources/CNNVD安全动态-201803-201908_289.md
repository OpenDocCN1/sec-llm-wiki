今日CNNVD共发布安全漏洞34个，更新安全漏洞36个。主要影响厂商为美国IBM（3个）、美国Dell（3个）、美国Pivotal Software（2个）。主要影响产品为IBM Kenexa LCMS Premier on Cloud内容管理系统（1个）、Dell EMC Secure Remote Services虚拟软件（3个）、Pivotal Spring Framework应用程序框架（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******IBM Kenexa LCMS Premier on Cloud SQL注入漏洞****

**【漏洞编号】********CNNVD-201810-1054**（CVE-2017-1797）****

**【漏洞详情】**IBM Kenexa LCMS Premier on Cloud是美国IBM公司的一套可调节的用于开发、维护和提供高效的员工培训的学习内容管理系统 (LCMS)。

IBM Kenexa LCMS Premier on Cloud中存在SQL注入漏洞。远程攻击者可通过发送特制的SQL语句利用该漏洞查看、添加、修改或删除后端数据库中的信息。以下版本受到影响：IBM Kenexa LCMS Premier on Cloud 9.3版本，9.4版本，9.5版本，10.0版本，10.1版本，10.2版本，10.3版本，11.0版本，11.1版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.ibm.com/blogs/psirt/ibm-security-bulletin-ibm-kenexa-lcms-premier-on-cloud-is-affected-by-a-sql-injection-via-external-service-interaction/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-1054

  

**【漏洞名称】****Dell EMC Secure Remote Services 安全漏洞**  

**【漏洞编号】******CNNVD-201810-1049**（CVE-2018-11079）**

**【漏洞详情】**Dell EMC Secure Remote Services是美国戴尔（Dell）公司的一套远程服务虚拟版软件。该软件用于在EMC客户服务和用户的EMC产品、解决方案之间提供远程连接。

Dell EMC Secure Remote Services 3.32.00.08之前版本中存在安全漏洞，该漏洞源于程序以明文形式将数据库凭证存储在配置文件中。攻击者可通过访问配置文件利用该漏洞获取密码，进而访问应用程序数据库。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.dellemc.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-1049

  

**【漏洞名称】****Pivotal Spring Framework 安全漏洞**

**【漏洞编号】******CNNVD-201810-1051**（CVE-2018-15756）**

**【漏洞详****情】**Pivotal Spring Framework是美国Pivotal Software公司的一套开源的Java、Java EE应用程序框架。该框架可帮助开发人员构建高质量的应用。

Pivotal Spring Framework中存在安全漏洞。攻击者可利用该漏洞造成拒绝服务。以下版本受到影响：Pivotal Spring Framework 5.1版本，5.0.10之前的5.0.x版本，4.3.20之前的4.3.x版本，4.2.x版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://pivotal.io/security/cve-2018-15756

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-1051

**【漏洞名称】******Artifex Software Ghostscript 安全漏洞****

**【****漏洞****编号****】******CNNVD-201810-1058**（CVE-2018-18284）**

**【漏洞详情】**Artifex Software Ghostscript是美国Artifex Software公司的一款开源的PostScript（一种用于电子产业和桌面出版领域的页面描述语言和编程语言）解析器，它可显示Postscript文件以及在非Postscript打印机上打印Postscript文件。

Artifex Software Ghostscript中存在安全漏洞。攻击者可利用该漏洞控制程序。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

http://git.ghostscript.com/?p=ghostpdl.git;h=8d19fdf63f91f50466b08f23e2d93d37a4c5ea0b

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-1058

  

**【漏洞名称】****Opto 22 PAC Control Basic和PAC Control Professional 缓冲区错误漏洞**

**【漏洞编****号】****CNNVD-201810-1042****（CVE-2018-14807）**

**【漏洞详情】**Opto 22 PAC Control Basic是Opto 22公司的一套PAC（实时操作系统）编程软件。PAC Control Professional是它的专业版。

Opto 22 PAC Control Basic和PAC Control Professional R10.0a及之前版本中存在基于栈的缓冲区溢出漏洞。远程攻击者可利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.opto22.com/support/resources-tools/knowledgebase/kb87547

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-1042
