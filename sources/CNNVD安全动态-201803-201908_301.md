今日CNNVD共发布安全漏洞250个，更新安全漏洞96个。主要影响厂商为美国Cisco（51个）、美国IBM（18个）、美国ImageMagick Studio（7个）。主要影响产品为Cisco Webex Network Recording Player播放器（12个）、IBM Security QRadar Incident Forensics调查软件（2个）、ImageMagick图像处理软件（7个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Cisco Webex Network Recording Player和Cisco Webex Player 输入验证漏洞****

**【漏洞编号】********CNNVD-201810-199**（CVE-2018-15408）****

**【漏洞详情】**Cisco Webex Network Recording Player和Webex Player都是美国思科（Cisco）公司的用于播放视频会议记录的播放器。

基于Windows平台的Cisco Webex Network Recording Player和Cisco Webex Player中存在输入验证漏洞，该漏洞源于软件对Advanced Recording Format (ARF)和Webex Recording Format (WRF)文件验证不当。攻击者可利用该漏洞在受影响的系统上执行任意代码。以下产品和版本受到影响：Cisco Webex Business Suite WBS31 sites ? Webex Network Recording Player和Webex Player WBS31.23之前版本，Cisco Webex Business Suite WBS32 sites ? Webex Network Recording Player和Webex Player WBS32.15.20之前版本，Cisco Webex Business Suite WBS33 sites ? Webex Network Recording Player和Webex Player WBS33.4之前版本，Cisco Webex Meetings Online ? Webex Network Recording Player和Webex Player 1.3.37之前版本，Cisco Webex Meetings Server ? Webex Network Recording Player 3.0MR2 Patch 1之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20181003-webex-rce

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-199

  

**【漏洞名称】****IBM QRadar Incident Forensics 安全漏洞**  

**【漏洞编号】******CNNVD-201810-167**（CVE-2018-1647）**

**【漏洞详情】**IBM Security QRadar Incident Forensics是美国IBM公司的一套安全取证调查软件。该软件支持对疑似恶意网络安全事件进行深入取证调查，及修复网络安全漏洞。

IBM QRadar Incident Forensics 7.2版本和7.3版本中存在安全漏洞，该漏洞源于程序没有正确的限制被请求资源的大小。攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.ibm.com/support/docview.wss?uid=ibm10729705

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-167

  

**【漏洞名称】****ImageMagick 缓冲区错误漏洞**

**【漏洞编号】******CNNVD-201810-238**（CVE-2018-18023）**

**【漏洞详****情】**ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.8-13 Q16版本中的coders/svg.c文件的‘SVGStripString’函数存在安全漏洞。攻击者可借助特制的SVG图像文件利用该漏洞造成拒绝服务（缓冲区越界读取）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/issues/1336

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-238

  

**【漏洞名称】******Cloud Foundry Log Cache 安全漏洞****

**【****漏洞****编号****】******CNNVD-201810-231**（CVE-2018-1264）**

**【漏洞详情】**Cloud Foundry Log Cache是美国Cloud Foundry基金会的一套日志缓存解决方案。

Cloud Foundry Log Cache 1.1.1之前版本中存在安全漏洞，该漏洞源于在启动时程序将UAA客户端敏感信息记录到envstruct报告中。攻击者可利用该漏洞读取敏感信息，获取Log Cache UAA客户端的所有权限并可能控制Foundation。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.cloudfoundry.org/blog/cve-2018-1264/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-231

  

**【漏洞名称】****Pivotal Container Service 信息泄露漏洞**

**【漏洞编****号】****CNNVD-201810-233****（CVE-2018-15763）**

**【漏洞详情】**Pivotal Container Service是美国Pivotal Software公司的一款基于Kubernetes的容器服务。

Pivotal Container Service 1.2.0之前版本中存在信息泄露漏洞。攻击者可利用该漏洞获取IaaS凭证并利用该凭证执行操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://pivotal.io/security/cve-2018-15763

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201810-233
