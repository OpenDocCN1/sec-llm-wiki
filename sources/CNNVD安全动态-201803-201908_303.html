根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞265个，漏洞新增数量有所下降。从厂商分布来看，其中苹果（Apple）公司新增漏洞最多，共有24个；从漏洞类型来看，跨站脚本类的安全漏洞占比最大，达到15.85%。本周新增漏洞中，超危漏洞2个，高危漏洞19个，中危漏洞186个，低危漏洞58个。相应修复率分别为100.00%、94.74%、65.05%以及50.00%。根据补丁信息统计，合计170个漏洞已有修复补丁发布，整体修复率为64.15%。

1. 多款思科（Cisco）公司产品Video Surveillance Manager Software 安全漏洞（CNNVD-201809-1128）

Cisco CPS-UCSM4-1RU-K9等都是美国Cisco公司的联网保全与安全统一计算系统平台。Video Surveillance Manager（VSM）Software是使用在其中的一款视频监控管理器。

多款Cisco产品上的VSM Software 7.10版本、7.11版本和7.11.1版本中存在安全漏洞，该漏洞源于程序为root账户使用了未记录的默认静态用户凭证。远程攻击者可通过使用该账户登录受影响系统利用该漏洞以root用户身份执行任意命令。以下产品受到影响：

- Cisco CPS-UCSM4-1RU-K9

- Cisco CPS-UCSM4-2RU-K9

- Cisco KIN-UCSM5-1RU-K9

- Cisco KIN-UCSM5-2RU-K9

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20180921-vsm

2. IBM DB2 for Linux、UNIX和Windows 权限许可和访问控制漏洞（CNNVD-201809-991）

IBM DB2是美国IBM公司的一套关系型数据库管理系统。该系统的执行环境主要有UNIX、Linux、IBM i、z/OS以及Windows服务器版本。

基于Linux、UNIX和Windows平台的IBM DB2（包括DB2 Connect Server）中的Administrative Task Scheduler (ATS)存在提权漏洞。攻击者可利用该漏洞修改ATS使用的控制表，进而未授权访问用户数据。以下版本受到影响：

- IBM DB2 9.7版本

- IBM DB2 10.1版本

- IBM DB2 10.5版本

- IBM DB2 11.1版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10729983

3.多款苹果（Apple）公司产品Kernel 安全漏洞（CNNVD-201809-1160）

Apple iOS、macOS Mojave、watchOS和tvOS都是美国苹果（Apple）公司的产品。Apple iOS是为移动设备所开发的一套操作系统；macOS Mojava是一套专为Mac计算机所开发的专用操作系统；tvOS是一套智能电视操作系统；watchOS是一套智能手表操作系统。Kernel是其中的一个内核。

多款Apple产品中的Kernel组件存在安全漏洞。攻击者可利用该漏洞以内核权限执行任意代码（内存损坏）。以下产品和版本受到影响：

- Apple iOS 12之前版本

- Apple macOS Mojave 10.14之前版本

- Apple watchOS 5之前版本

- Apple tvOS 12之前版本

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/en-us/HT209139

https://support.apple.com/en-us/HT209108

https://support.apple.com/en-us/HT209107

https://support.apple.com/en-us/HT209106
