今日CNNVD共发布安全漏洞89个，更新安全漏洞25个。主要影响厂商为韩国Samsung（8个）、美国McAfee（2个）、法国HAProxy（1个）。主要影响产品为Samsung SmartThings Hub STH-ETH-250智能家居管理设备（8个）、McAfee True Key（TK）应用程序（2个）、HAProxy负载均衡服务器（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Samsung SmartThings Hub STH-ETH-250 video-core HTTP服务器缓冲区错误漏洞

【漏洞编号】CNNVD-201809-1071（CVE-2018-3915）

【漏洞详情】Samsung SmartThings Hub STH-ETH-250是韩国三星（Samsung）公司的一款智能家居管理设备。video-core HTTP server是其中的一个HTTP服务器。

使用0.20.17版本固件的Samsung SmartThings Hub STH-ETH-250的video-core HTTP服务器中对数据库字段的检索存在基于栈的缓冲区溢出漏洞。攻击者可通过发送任意长度的‘bucket’值利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.smartthings.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-1071


【漏洞名称】McAfee True Key Microsoft Windows客户端安全漏洞

【漏洞编号】CNNVD-201809-1020（CVE-2018-6700）

【漏洞详情】McAfee True Key（TK）是美国迈克菲（McAfee）公司的一款身份验证应用程序。该程序支持面部信息识别和指纹识别等功能。

McAfee TK 5.1.165之前版本中的Microsoft Windows客户端存在安全漏洞。本地攻击者可借助特制的恶意软件利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://service.mcafee.com/webcenter/portal/cp/home/articleview?articleId=TS102846

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-1020


【漏洞名称】HAProxy HPACK decoder 缓冲区错误漏洞

【漏洞编号】CNNVD-201809-1083（CVE-2018-14645）

【漏洞详情】HAProxy是法国HAProxy公司的一款开源的TCP/HTTP负载均衡服务器。该服务器提供4层、7层代理，并能支持上万级别的连接，具有高效、稳定等特点。HPACK decoder是其中的一个HPACK（HTTP2头部压缩算法）解码器。

HAProxy 1.8.14之前版本中的HPACK decoder的‘hpack_valid_idx()’函数存在越界读取漏洞。远程攻击者可利用该漏洞造成拒绝服务（崩溃）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.haproxy.org/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-1083


【漏洞名称】GNU Binutils Binary File Descriptor库缓冲区错误漏洞

【漏洞编号】CNNVD-201809-1034（CVE-2018-17360）

【漏洞详情】GNU Binutils（又名GNU Binary Utilities或binutils）是GNU计划开发的一组编程语言工具程序，它主要用于处理多种格式的目标文件，并提供有连接器、汇编器和其他用于目标文件和档案的工具。Binary File Descriptor（BFD）library（又名libbfd）是其中的一个以各种格式便携式操作对象文件的库。

GNU Binutils 2.31版本中的BFD库的‘bfd_getl32’函数存在基于堆的缓冲区越界读取漏洞。攻击者可借助特制的PE文件利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.gnu.org/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-1034


【漏洞名称】EspoCRM 跨站脚本漏洞

【漏洞编号】CNNVD-201809-1084（CVE-2018-17302）

【漏洞详情】EspoCRM是一套开源的基于Web的客户关系管理系统（CRM）。该系统提供销售自动化、社区和客户支持等功能。

EspoCRM 5.3.6版本中的views/fields/wysiwyg.js文件存在跨站脚本漏洞。远程攻击者可借助EspoCRM-5.3.6/EspoCRM-5.3.6/#Email/view/5b962f8e6f2e91033 URL利用该漏洞执行恶意的Javascript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/espocrm/espocrm/issues/1039

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-1084
