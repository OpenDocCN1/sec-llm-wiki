今日CNNVD共发布安全漏洞33个，更新安全漏洞5个。主要影响厂商为美国Pivotal Software（2个）、美国Honeywell International（1个）、中国福斯康姆（1个）。主要影响产品为Pivotal Application Service应用程序服务（2个）、Honeywell CT60移动数据终端设备（1个）、Foscam C1 Indoor HD Camera摄像机（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Pivotal Application Service Pivotal Applications Manager 安全漏洞****

**【漏洞编号】********CNNVD-201809-763**（CVE-2018-11088）****

**【漏洞详情】**Pivotal Application Service是美国Pivotal Software公司的一套支持持续交付的应用程序服务。Pivotal Applications Manager是其中的一个应用程序管理组件。

Pivotal Application Service 2.0.21之前的2.0版本、2.1.13之前的2.1版本和2.2.5之前的2.2版本中的Pivotal Applications Manager存在安全漏洞。攻击者可利用该漏洞访问CF admin凭证，从而提升到admin权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://pivotal.io/security/cve-2018-11088

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-763

  

**【漏洞名称】****多款Honeywell产品安全漏洞**  

**【漏洞编号】******CNNVD-201809-788**（CVE-2018-14825）**

**【漏洞详情】**Honeywell CT60等都是美国霍尼韦尔国际（Honeywell International）公司的移动数据终端（移动计算机）产品。

多款Honeywell产品中存在安全漏洞。攻击者可借助能够绑定到某服务的应用程序利用该漏洞获取系统权限，进而获取键击、密码、个人识别信息、图片、邮件或重要业务的文档的访问权限。以下产品受到影响：Honeywell CT60（Android 7.1版本）；CN80（Android 7.1版本） ；CT40（Android 7.1版本）；CK75（Android 6.0版本）；CN75（Android 6.0版本）；CN75e（Android 6.0版本）；CT50（Android 6.0版本）；D75e（Android 6.0版本）；CT50（Android 4.4版本）；D75e（Android 4.4版本）；CN51（Android 6.0版本）；EDA50k（Android 4.4版本）；EDA50（Android 7.1版本）；EDA50k（Android 7.1版本）；EDA70（Android 7.1版本）；EDA60k（Android 7.1版本）；EDA51（Android 8.1）版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.honeywellaidc.com/en/-/media/en/files-public/technical-publications/multi-product/ALLSKU-AND-ENUS-ZY.pdf

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-788

  

**【漏洞名称】****Foscam C1 Indoor HD Camera 信息泄露漏洞**

**【漏洞编号】******CNNVD-201809-759**（CVE-2017-2874）**

**【漏洞详****情】**Foscam C1 Indoor HD Camera是中国福斯康姆（Foscam）公司的一款无线高清IP摄像机。

使用2.52.2.43版本应用程序固件的Foscam C1 Indoor HD Camera中的Multi-Camera界面存在信息泄露漏洞。攻击者可通过向10001端口发送特制的请求利用该漏洞在未经身份验证的情况下检索敏感信息。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.foscam.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-759

  

**【漏洞名称】******Cloud Foundry Container Runtime 安全漏洞****

**【****漏洞****编号****】******CNNVD-201809-761**（CVE-2018-1223）**

**【漏洞详情】**Cloud Foundry Container Runtime是美国Cloud Foundry基金会的一款提供了统一的方式进行实例化、部署和管理Kubernetes集群的系统。

Cloud Foundry Container Runtime (kubo-release) 0.14.0之前版本中存在安全漏洞，该漏洞源于程序会将UAA and vCenter凭证泄露到应用程序日志中。攻击者可利用该漏洞使用这些凭证提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.cloudfoundry.org/blog/cve-2018-1223/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-761

  

**【漏洞名称】****Apache SpamAssassin 安全漏洞**

**【漏洞编****号】****CNNVD-201809-769****（CVE-2018-11781）**

**【漏洞详情】**Apache SpamAssassin是美国阿帕奇（Apache）软件基金会的一款开源的垃圾邮件过滤器，它为系统管理员提供了一个过滤器，并支持对电子邮件进行分类阻止垃圾邮件。

Apache SpamAssassin中的元规则语句存在安全漏洞。攻击者可利用该漏洞在系统上执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lists.apache.org/thread.html/7f6a16bc0fd0fd5e67c7fd95bd655069a2ac7d1f88e42d3c853e601c@%3Cannounce.apache.org%3E

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-769
