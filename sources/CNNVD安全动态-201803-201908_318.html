今日CNNVD共发布安全漏洞74个，更新安全漏洞5个。主要影响厂商为美国Microsoft（60个）、美国Red Hat（2个）、中国华为（2个）。主要影响产品为Microsoft Windows 10操作系统（36个）、Red Hat JBoss Enterprise Application Platform（EAP）中间件平台（1个）、Huawei ALP-L09智能手机（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】Microsoft Windows Edge 权限许可和访问控制漏洞

【漏洞编号】CNNVD-201809-506（CVE-2018-8463）

【漏洞详情】Microsoft Windows 10是美国微软（Microsoft）公司发布的一套新一代跨平台操作系统，它适用于PC和笔记本电脑、平板电脑以及手机等设备。Edge是其中的一个系统附带的默认浏览器。

Microsoft Windows 10版本1803中的Edge存在提权漏洞。远程攻击者可利用该漏洞获取提升的权限并跳出Edge AppContaine沙盒。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2018-8463

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-506


【漏洞名称】Red Hat JBoss Enterprise Application Platform 安全漏洞

【漏洞编号】CNNVD-201809-562（CVE-2016-7066）

【漏洞详情】Red Hat JBoss Enterprise Application Platform（EAP）是美国红帽（Red Hat）公司的一套开源、基于J2EE的中间件平台。该平台主要用于构建、部署和托管Java应用程序与服务。

Red Hat JBoss EAP 7.1.0之前版本中存在安全漏洞，该漏洞源于程序为/tmp/auth目录分配了不恰当的默认权限。本地攻击者可利用该漏洞连接到CLI并允许用户执行任意操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://access.redhat.com/errata/RHSA-2017:3456

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-562


【漏洞名称】Huawei ALP-L09 安全漏洞

【漏洞编号】CNNVD-201809-571（CVE-2018-7922）

【漏洞详情】Huawei ALP-L09是中国华为（Huawei）公司的一款智能手机产品。

Huawei ALP-L09 8.0.0.150(C432)之前版本中存在安全漏洞。攻击者可借助特制的应用程序利用该漏洞在受影响手机中执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20180911-01-smartphone-cn

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-571


【漏洞名称】PowerDNS Authoritative Server和PowerDNS Recursor 安全漏洞

【漏洞编号】CNNVD-201809-565（CVE-2016-7074）

【漏洞详情】PowerDNS Authoritative Server和PowerDNS Recursor都是荷兰PowerDNS公司的产品。PowerDNS Authoritative Server是一款DNS服务器。PowerDNS Recursor是一款域名解析服务器。

PowerDNS Authoritative Server和PowerDNS Recursor中存在安全漏洞，该漏洞源于程序没有充分地验证TSIG签名。攻击者可利用该漏洞实施中间人攻击，更改AXFR的内容。以下产品和版本受到影响：PowerDNS Authoritative Server 3.4.11之前版本，4.0.2之前版本；PowerDNS Recursor 3.7.4之前版本，4.0.4之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://doc.powerdns.com/md/security/powerdns-advisory-2016-04/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-565


【漏洞名称】IBM QRadar 操作系统命令注入漏洞

【漏洞编号】CNNVD-201809-569（CVE-2018-1571）

【漏洞详情】IBM QRadar是美国IBM公司的一套利用安全智能保护资产和信息远离高级威胁的解决方案。该方案提供对整个IT架构范围进行监督、生成详细的数据访问和用户活动报告等功能。

IBM QRadar 7.2版本和7.3版本中存在操作系统命令注入漏洞。远程攻击者可通过发送特制的请求利用该漏洞在系统上执行任意命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10729701

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-569
