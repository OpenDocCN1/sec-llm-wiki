# CNNVD最新漏洞（2018-09-12）

今日CNNVD共发布安全漏洞49个，更新安全漏洞14个。主要影响厂商为日本Micronet（5个）、美国Dell（5个）、韩国Samsung（2个）。主要影响产品为Micronet INplc SDK开发工具包（5个）、Dell EMC VPLEX Witness解决方案（4个）、Samsung SmartThings Hub STH-ETH-250智能家居管理设备（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Micronet INplc SDK 安全漏洞****

**【漏洞编号】********CNNVD-201809-427**（CVE-2018-0667）****

**【漏洞详情】**Micronet INplc SDK是日本Micronet公司的一款软件定义的PLC（可编程逻辑控制器）开发工具包。

Micronet INplc SDK Express 3.08及之前版本和Pro+ 3.08及之前版本中存在DLL预加载漏洞。攻击者可利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

http://www.mnc.co.jp/INplc/info\_20180907\_E.htm

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-427

  

**【漏洞名称】****Dell EMC VPLEX Witness 安全漏洞**  

**【漏洞编号】******CNNVD-201809-433**（CVE-2018-11078）**

**【漏洞详情】**Dell EMC VPLEX Witness是美国戴尔（Dell）公司的一套VPLEX系列数据中心虚拟化解决方案。该解决方案可在公共云和私有云之间移动应用程序、虚拟机以及数据，且不影响用户。

Dell EMC VPLEX Witness 5.4版本、5.5版本和6.0版本中存在安全漏洞。远程攻击者可利用该漏洞获取目标系统数据的访问权限并修改数据。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.dell.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-433

  

**【漏洞名称】****Samsung SmartThings Hub STH-ETH-250 video-core HTTP服务器缓冲区错误漏洞**

**【漏洞编号】******CNNVD-201809-442**（CVE-2018-3875）**

**【漏洞详****情】**Samsung SmartThings Hub STH-ETH-250是韩国三星（Samsung）公司的一款智能家居管理设备。video-core HTTP server是其中的一个HTTP服务器。

使用0.20.17版本固件的Samsung SmartThings Hub STH-ETH-250的video-core HTTP服务器的凭证处理器存在缓冲区溢出漏洞，该漏洞源于video-core进程错误地从用户控制的JSON载荷中提取字段。攻击者可通过发送任意长度的“sessionToken”值利用该漏洞执行任意代码或造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.smartthings.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-442

  

**【漏洞名称】******Cybozu Garoon 路径遍历漏洞****

**【****漏洞****编号****】******CNNVD-201809-432**（CVE-2018-0673）**

**【漏洞详情】**Cybozu Garoon是日本才望子（Cybozu）公司的一套门户型OA办公系统。该系统提供门户、E-mail、书签、日程安排、公告栏、文件管理等功能，并支持在三种语言（中、日、英）中自由切换。

Cybozu Garoon 3.5.0版本至4.6.3版本中的会话信息处理过程存在路径遍历漏洞。攻击者可利用该漏洞获取或修改服务器上的任意文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://cs.cybozu.co.jp/2018/006717.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-432

  

**【漏洞名称】****WAVM 安全漏洞**

**【漏洞编****号】****CNNVD-201809-469****（CVE-2018-16770）**

**【漏洞详情】**WAVM是一款WebAssembly虚拟机。

WAVM 2018-07-26及之前版本中存在安全漏洞，该漏洞源于new\_allocator分配调用失败。攻击者可通过向WAVM发送特制的文件利用该漏洞造成拒绝服务（应用程序崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/WAVM/WAVM/commit/88901f515facaf3698af9a6b53aef30322ae52c8

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-469
