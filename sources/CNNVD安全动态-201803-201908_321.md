# CNNVD最新漏洞（2018-09-11）

今日CNNVD共发布安全漏洞87个，更新安全漏洞10个。主要影响厂商为美国KONE（4个）、美国IBM（4个）、日本WESEEK（4个）。主要影响产品为KONE Group Controller（KGC）控制器设备（4个）、IBM Security Identity Governance and Intelligence（IGI）解决方案（2个）、WESEEK GROWI团队协作软件（4个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******KONE Group Controller 安全漏洞****

**【漏洞编号】********CNNVD-201809-352**（CVE-2018-15483）****

**【漏洞详情】**KONE Group Controller（KGC）是美国KONE公司的一款电梯组控制器设备。

KONE KGC 4.6.5之前版本中存在安全漏洞。攻击者可借助开放的HTTP端口利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接

https://www.kone.com/en/vulnerability.aspx

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-352

  

**【漏洞名称】****IBM Security Identity Governance and Intelligence 安全漏洞**  

**【漏洞编号】******CNNVD-201809-396**（CVE-2018-1757）**

**【漏洞详情】**IBM Security Identity Governance and Intelligence（IGI）是美国IBM公司的一套身份管理和治理解决方案。该产品包括了生命周期管理、访问风险评估和身份认证管理等功能。

IBM Security IGI 5.2.3.2版本和5.2.4版本中存在安全漏洞，该漏洞源于程序没有对评估应用程序执行身份验证。攻击者可利用该漏洞获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.ibm.com/support/docview.wss?uid=ibm10728883

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-396

  

**【漏洞名称】****WESEEK GROWI 跨站脚本漏洞**

**【漏洞编号】******CNNVD-201809-407**（CVE-2018-0655）**

**【漏洞详****情】**WESEEK GROWI是日本WESEEK公司开发的一套开源的团队协作软件。该软件具有资产管理、快速搜索和成员管理等功能。

WESEEK GROWI 3.1.11及之前版本中存在跨站脚本漏洞。远程攻击者可借助admin页面的应用程序设置部分利用该漏洞注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://weseek.co.jp/security/2018/07/31/growi-prevent-xss/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-407

  

**【漏洞名称】******多款I-O DATA产品安全漏洞****

**【****漏洞****编号****】******CNNVD-201809-402**（CVE-2018-0663）**

**【漏洞详情】**I-O DATA TS-WRLP、TS-WRLA和TS-WRLP/E都是日本I-O DATA DEVICE公司的网络摄像机产品。

多款I-O DATA产品存在安全漏洞，该漏洞源于程序使用了硬编码凭证。远程攻击者可利用该漏洞在设备上执行任意操作系统命令。以下产品和版本受到影响：使用1.09.04及之前版本固件的I-O DATA TS-WRLP；使用1.09.04及之前版本固件的TS-WRLA；使用1.09.04及之前版本固件的TS-WRLP/E。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.iodata.jp/support/information/2018/ts-wrlp/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-402

  

**【漏洞名称】****Online Receipt Computer Advantage 缓冲区错误漏洞**

**【漏洞编****号】****CNNVD-201809-416****（CVE-2018-0644）**

**【漏洞详情】**Online Receipt Computer Advantage（CRCA）是日本ORCA Management Organization公司的一套医疗会计软件。该软件支持电子病历管理和协作软件扩展等功能。

ORCA中存在缓冲区溢出漏洞。攻击者可利用该漏洞造成拒绝服务。以下版本受到影响：ORCA 4.8.0 (panda-client2) 1:1.4.9+p41-u4jma1及之前版本，5.0.0 (panda-client2) 1:2.0.0+p48-u4jma1及之前版本，5.0.0 (panda-client2) 1:2.0.0+p48-u5jma1及之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.orca.med.or.jp/news/vulnerability\_2018-07-18-1.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-416
