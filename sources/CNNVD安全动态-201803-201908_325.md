# CNNVD最新漏洞（2018-09-05）

今日CNNVD共发布安全漏洞48个。主要影响厂商为荷兰Philips（9个）、美国ImageMagick Studio（2个）、美国Google（1个）。主要影响产品为Philips e-Alert解决方案（9个）、ImageMagick图象处理软件（2个）、Android开源操作系统（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Philips e-Alert 输入验证漏洞****

**【漏洞编号】********CNNVD-201809-110**（CVE-2018-8850）****

**【漏洞详情】**Philips e-Alert是荷兰飞利浦（Philips）公司的一款针对MRI系统的电子警报解决方案，它主要用于监控MRI系统性能并发出警报。

Philips e-Alert R2.1及之前版本中存在输入验证漏洞。远程攻击者可借助特制的输入利用该漏洞更改控制流，任意控制资源或执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.usa.philips.com/healthcare/about/customer-support/product-security

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-110

  

**【漏洞名称】****ImageMagick 缓冲区错误漏洞**  

**【漏洞编号】******CNNVD-201809-091**（CVE-2018-16413）**

**【漏洞详情】**ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.8-11 Q16版本中的MagickCore/quantum-private.h文件的‘PushShortPixel’函数存在基于堆的缓冲区溢出漏洞。攻击者可利用该漏洞执行任意代码或造成拒绝服务（基于堆的缓冲区越界读取）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.imagemagick.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-091

  

**【漏洞名称】****Android  安全漏洞**

**【漏洞编号】******CNNVD-201809-120**（CVE-2018-9489）**

**【漏洞详****情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。

Android中存在安全漏洞。攻击者可借助WiFi广播利用该漏洞绕过权限检测，泄露有关用户设备的信息，例如WiFi网络名称，BSSID，本地IP地址，DNS服务器信息和MAC地址。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://source.android.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-120

  

**【漏洞名称】****Red Hat Openshift Container Platform 跨站脚本漏洞**

**【****漏洞****编号****】****CNNVD-201809-119****（CVE-2018-10937）**

**【漏洞详情】**Red Hat OpenShift Container Platform是美国红帽（Red Hat）公司的一款可帮助企业在物理、虚拟和公共云基础架构之间开发、部署和管理现有基于容器的应用程序的应用平台。nodejs是其中的一个建立在Google V8 JavaScript引擎之上的网络应用平台。

Red Hat Openshift Container Platform中存在跨站脚本漏洞，该漏洞源于程序没有充分的过滤用户提交的输入。远程攻击者可利用该漏洞在用户浏览器中执行任意脚本代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://github.com/openshift/console/commit/d56666852da6e7309a2e63a49f49a72ff66d309c

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-119

  

**【漏洞名称】****OpenSC 缓冲区错误漏洞**

**【漏洞编****号】****CNNVD-201809-080****（CVE-2018-16427）**

**【漏洞详情】**OpenSC是一款开源的智能卡工具和中间件。

OpenSC 0.19.0-rc1之前版本中存在越界读取漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://github.com/OpenSC/OpenSC/releases/tag/0.19.0-rc1

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201809-080
