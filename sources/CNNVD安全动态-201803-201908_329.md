今日CNNVD共发布安全漏洞45个，更新安全漏洞19个。主要影响厂商为韩国Samsung（8个）、美国Apple（7个）、美国Cisco（1个）。主要影响产品为Samsung Galaxy Apps应用商店程序（3个）、Apple iOS操作系统（5个）、Cisco Data Center Network Manager数据中心管理系统（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Samsung Galaxy Apps 权限许可和访问控制漏洞****

**【漏洞编号】********CNNVD-201808-937**（CVE-2018-10499）****

**【漏洞详情】**Samsung Galaxy Apps是韩国三星（Samsung）公司的一款使用在Samsung手机中的应用商店程序。

Samsung Galaxy Apps中URLs的处理存在提权漏洞，该漏洞源于程序没有正确的验证用户提交的数据。本地攻击者可通过获取低权限代码的执行权限利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.samsung.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-937

  

**【漏洞名称】****多款Apple产品WebKit 安全漏洞**  

**【漏洞编号】******CNNVD-201808-948**（CVE-2018-4265）**

**【漏洞详情】**Apple iOS等都是美国苹果（Apple）公司的产品。Apple iOS是为移动设备所开发的一套操作系统；Safari是一款Web浏览器，是Mac OS X和iOS操作系统附带的默认浏览器。iCloud for Windows是一款基于Windows平台的云服务。WebKit是其中的一个Web浏览器引擎组件。

多款Apple产品中的WebKit存在安全漏洞，该漏洞源于程序在对对象执行操作之前，没有验证该对象是否存在。远程攻击者可借助恶意的页面或文件利用该漏洞在当前进程的上下文中执行任意代码。以下产品和版本受到影响：Apple Safari 11.1.2之前版本；iOS 11.4.1之前版本；tvOS 11.4.1之前版本；基于Windows平台的iCloud 7.6之前版本；基于Windows平台的iTunes 12.8之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://support.apple.com/en-us/HT208934

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-948

  

**【漏洞名称】****Cisco Data Center Network Manager 路径遍历漏洞**

**【漏洞编号】******CNNVD-201808-953**（CVE-2018-0464）**

**【漏洞详****情】**Cisco Data Center Network Manager是美国思科（Cisco）公司的一套数据中心管理系统。该系统适用于Cisco Nexus和MDS系列交换机，提供存储可视化、配置和故障排除等功能。

Cisco Data Center Network Manager 11.0(1)之前版本中存在路径遍历漏洞，该漏洞源于在管理界面中程序没有正确的验证用户的请求。远程攻击者可通过发送带有路径遍历字符序列的恶意请求利用该漏洞在目标系统上查看和创建任意文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20180828-dcnm-traversal

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-953

  

**【漏洞名称】****Apache Traffic Server 安全漏洞**

**【****漏洞****编号****】****CNNVD-201808-926****（CVE-2018-8022）**

**【漏洞详情】**Apache Traffic Server（ATS）是美国阿帕奇（Apache）软件基金会的一款高效、可扩展的HTTP代理和缓存服务器。

Apache ATS 6.2.2版本中存在安全漏洞。攻击者可借助特制无效的TLS握手利用该漏洞造成段错误。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lists.apache.org/thread.html/ce404d2fe16cc59085ece5a6236ccd1549def471a2a9508198d966b1@%3Cusers.trafficserver.apache.org%3E

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-926

  

**【漏洞名称】****Adobe Creatie Cloud Desktop 安全漏洞**

**【漏洞编****号】****CNNVD-201808-930****（CVE-2018-12829）**

**【漏洞详情】**Adobe Creatie Cloud Desktop是美国奥多比（Adobe）公司的一套用于在Creative云会员管理中心管理应用程序和服务的应用程序。该程序支持同步和共享文件、管理字体以及访问商业摄影和设计的资产库。

基于Windows和macOS平台的Adobe Creative Cloud Desktop Application 4.6.1之前版本中存在安全漏洞，该漏洞源于程序没有正确的验证证书。攻击者可利用该漏洞提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://helpx.adobe.com/security/products/creative-cloud/apsb18-32.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-930
