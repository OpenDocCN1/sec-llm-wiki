今日CNNVD共发布安全漏洞56个，更新安全漏洞12个。主要影响厂商为美国IBM（3个）、意大利tecrail（2个）、Dell（1个）。主要影响产品为IBM Security Access Manager Appliance应用程序（1个）、tecrail Responsive FileManager开源文件管理器（2个）、Dell EMC RSA NetWitness Platform网络安全监控平台（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】IBM Security Access Manager Appliance 命令注入漏洞

【漏洞编号】CNNVD-201808-836（CVE-2018-1722）

【漏洞详情】IBM Security Access Manager Appliance是美国IBM公司的一款应用于信息安全管理的应用程序。该程序通过面向Web、移动和云计算的集成设备来实现访问管理控制。

IBM Security Access Manager Appliance 9.0.4.0版本和9.0.5.0版本中存在命令注入漏洞。远程攻击者可利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10719623

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-836


【漏洞名称】tecrail Responsive FileManager 安全漏洞

【漏洞编号】CNNVD-201808-826（CVE-2018-15536）

【漏洞详情】tecrail Responsive FileManager是意大利tecrail公司的一款使用PHP语言编写的开源文件管理器，它支持视频、图像和其它文件的上传和管理。

tecrail Responsive FileManager 9.13.4之前版本中的/filemanager/ajax_calls.php文件存在安全漏洞，该漏洞源于程序没有正确地验证归档文件中的文件路径。攻击者可借助特制的归档文件利用该漏洞覆盖任意文件。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.responsivefilemanager.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-826


【漏洞名称】Dell EMC RSA NetWitness Platform和RSA Security Analytics 安全漏洞

【漏洞编号】CNNVD-201808-833（CVE-2018-11061）

【漏洞详情】Dell EMC RSA NetWitness Platform和RSA Security Analytics都是美国戴尔（Dell）公司的产品。Dell EMC RSA NetWitness Platform是一套网络安全监控平台。RSA Security Analytics（SA）是一套安全智能分析平台。

Dell EMC RSA NetWitness Platform 11.1.0.2之前版本和RSA SA 10.6.6之前版本中存在安全漏洞，该漏洞源于不安全的模板引擎配置。远程攻击者可利用该漏洞以root权限在服务器上执行任意的命令。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.dellemc.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-833


【漏洞名称】xkbcommon 安全漏洞

【漏洞编号】CNNVD-201808-791（CVE-2018-15864）

【漏洞详情】xkbcommon是一个键盘键映射编译器和支持库。

xkbcommon 0.8.2之前版本中的xkbcomp/parser.y文件的‘resolve_keysym’函数存在安全漏洞。本地攻击者可通过提交特制的keymap文件利用该漏洞造成xkbcommon解析器崩溃（空指针逆向引用）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/xkbcommon/libxkbcommon/commit/a8ea7a1d3daa7bdcb877615ae0a252c189153bd2

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-791


【漏洞名称】Pimcore 跨站脚本漏洞

【漏洞编号】CNNVD-201808-818（CVE-2018-14059）

【漏洞详情】Pimcore是奥地利Pimcore公司的一套开源的用于创建和管理Web应用程序的Web内容管理平台。该平台集成了Web内容管理、电子商务框架和产品信息管理等应用。

Pimcore中存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://pimcore.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-818
