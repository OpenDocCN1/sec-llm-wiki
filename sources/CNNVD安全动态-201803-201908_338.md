# CNNVD最新漏洞（2018-08-22）

今日CNNVD共发布安全漏洞56个，更新安全漏洞3个。主要影响厂商为美国IBM（4个）、德国OXID eSales（2个）、美国Reprise（2个）。主要影响产品为IBM SDK集成工具包（2个）、OXID eSales OXID eShop内容管理系统（2个）、Reprise License Manager（RLM）许可证管理软件（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******IBM SDK 安全漏洞****

**【漏洞编号】********CNNVD-201808-580**（CVE-2018-1656）****

**【漏洞详情】**IBM SDK是美国IBM公司的一套用于创建、发现、调用和测试Web服务的集成工具包。

IBM SDK（Java Technology版本）6.0版本、7.0版本和8.0版本中存在安全漏洞，该漏洞源于Diagnostic Tooling Framework for Java (DTFJ)没有防范路径遍历攻击。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10719653

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-580

  

**【漏洞名称】****OXID eSales OXID eShop Paymorrow模块安全漏洞**  

**【漏洞编号】******CNNVD-201808-578**（CVE-2018-14020）**

**【漏洞详情】**OXID eSales OXID eShop是德国OXID eSales公司的一套电子商务内容管理系统。该系统包括B2C、B2B等模块。Paymorrow module是其中的一个支付模块。

OXID eSales OXID eShop的Paymorrow模块1.0.2之前的1.0.0版本和2.0.1之前的2.0.0版本中存在安全漏洞，该漏洞源于payment模块没有正确地使用eShop的结账步骤。攻击者可利用该漏洞修改收货地址。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://oxidforge.org/en/security-bulletin-2018-003.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-578

  

**【漏洞名称】****Reprise License Manager license editor 安全漏洞**

**【漏洞编号】******CNNVD-201808-629**（CVE-2018-15574）**

**【漏洞详****情】**Reprise License Manager（RLM）是美国Reprise公司的一套许可证管理软件。license editor是其中的一个证书编辑器。

Reprise RLM 12.2BL2及之前版本中的license editor的/goform/edit\_lf\_get\_data URL的‘lf’参数存在安全漏洞。远程攻击者可通过发送POST或GET请求利用该漏洞注入任意的Web脚本或HTML。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

http://www.reprisesoftware.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-629

  

**【漏洞名称】******Dave Gamble cJSON 安全漏洞****

**【****漏洞****编号****】****CNNVD-201808-597****（CVE-2018-1000217）**

**【漏洞详情】**Dave Gamble cJSON是一款轻量级的JSON格式解析器。

Dave Gamble cJSON 1.7.3及之前版本的cJSON库中存在释放后重用漏洞。攻击者可利用该漏洞造成拒绝服务（崩溃），损坏数据，甚至远程执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/DaveGamble/cJSON/issues/248

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-597

  

**【漏洞名称】****Open Microscopy Environment OMERO.server 信息泄露漏洞**

**【漏洞编****号】****CNNVD-201808-622****（CVE-2018-1000635）**

**【漏洞详情】**Open Microscopy Environment OMERO.server是一套开源的图像管理平台。该平台支持多种图像文件格式，并对图像进行管理、查看和编辑等操作。

Open Microscopy Environment OMERO.server 5.4.0版本至5.4.6版本中存在信息泄露漏洞。远程攻击者可利用该漏洞获取服务器的节点UUID，进而获取服务器的全部管理权限并可能禁用服务器。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.openmicroscopy.org/2018/07/26/omero-5-4-7.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-622
