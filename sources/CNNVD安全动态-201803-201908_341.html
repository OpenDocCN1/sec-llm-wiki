今日CNNVD共发布安全漏洞61个，更新安全漏洞60个。主要影响厂商为美国Adobe（11个）、美国Cisco（10个）、美国Trend Micro（3个）。主要影响产品为Adobe Flash Playe多媒体播放器（5个）、Cisco Web Security Appliance（WSA）Web安全设备（2个）、Trend Micro Control Manager（TMCM）管理中心软件。

今日需关注的典型漏洞如下:

【漏洞名称】Adobe Flash Player 权限许可和访问控制漏洞

【漏洞编号】CNNVD-201808-345（CVE-2018-12828）

【漏洞详情】Adobe Flash Player是美国奥多比（Adobe）公司的一款跨平台、基于浏览器的多媒体播放器产品。该产品支持跨屏幕和浏览器查看应用程序、内容和视频。

Adobe Flash Player中存在提权漏洞。远程攻击者可利用该漏洞获取系统权限。以下版本受到影响：基于Windows、macOS和Linux平台的Adobe Flash Player Desktop Runtime 30.0.0.134及之前版本，基于Windows、macOS、Linux和Chrome OS平台的Adobe Flash Player for Google Chrome 30.0.0.134及之前版本，基于Windows 10和8.1平台的Adobe Flash Player for Microsoft Edge and Internet Explorer 11 30.0.0.134及之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://helpx.adobe.com/security/products/flash-player/apsb18-25.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-345


【漏洞名称】Cisco Web Security Appliance 访问控制错误漏洞

【漏洞编号】CNNVD-201808-455（CVE-2018-0428）

【漏洞详情】Cisco Web Security Appliance（WSA）是美国思科（Cisco）公司的一套Web安全设备。该设备提供基于SaaS的访问控制、实时网络报告和追踪、制定安全策略等功能。

Cisco WSA中的账户管理子系统存在访问控制错误漏洞。本地攻击者可利用该漏洞绕过CLI subshell，在底层操作系统上以root权限执行系统级命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bst.cloudapps.cisco.com/bugsearch/bug/CSCvj93548

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-455


【漏洞名称】Trend Micro Control Manager 安全漏洞

【漏洞编号】CNNVD-201808-465（CVE-2018-10512）

【漏洞详情】Trend Micro Control Manager（TMCM）是美国趋势科技（Trend Micro）公司的一套集成了威胁检测和数据保护的管理中心软件。

Trend Micro Control Manager 6.0版本和7.0版本中存在安全漏洞。攻击者可通过操纵反向代理.dll文件利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://success.trendmicro.com/solution/1120112

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-465


【漏洞名称】OpenEMR 安全漏洞

【漏洞编号】CNNVD-201808-476（CVE-2018-15156）

【漏洞详情】OpenEMR是OpenEMR社区所维护的一套开源的医疗管理系统。该系统可用于医疗实践管理、电子医疗记录、处方书写和医疗帐单申请。

OpenEMR 5.0.1.4之前版本中存在安全漏洞。远程攻击者可通过向interface/fax/faxq.php文件发送特制的请求利用该漏洞执行任意命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.open-emr.org/wiki/index.php/OpenEMR_Patches

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-476


【漏洞名称】Atlassian Confluence Questions 跨站请求伪造漏洞

【漏洞编号】CNNVD-201808-494（CVE-2018-13394）

【漏洞详情】Atlassian Confluence Questions是澳大利亚Atlassian公司的一套专业的企业知识管理与协同软件，也可以用于构建企业WiKi。该软件可实现团队成员之间的协作和知识共享。

Atlassian Confluence Questions 2.6.6之前版本中的acceptAnswer资源存在跨站请求伪造漏洞。远程攻击者可利用该漏洞将评论修改成答案。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://jira.atlassian.com/browse/CONFSERVER-56283

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-494
