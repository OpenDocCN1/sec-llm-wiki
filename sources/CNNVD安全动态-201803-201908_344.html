CNNVD最新漏洞（2018-08-15）

今日CNNVD共发布安全漏洞29个，更新安全漏洞8个。主要影响厂商为美国IBM（3个）、美国Red Hat（2个）、中国威联通（1个）。主要影响产品为IBM UrbanCode Deploy（UCD）应用自动化部署工具（2个）、Red Hat RPM（RPM Package Manager）软件包管理器（2个）、QNAP QTS作业系统（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】IBM UrbanCode Deploy 路径遍历漏洞

【漏洞编号】CNNVD-201808-335（CVE-2017-1749）

【漏洞详情】IBM UrbanCode Deploy（UCD）是美国IBM公司的一套应用自动化部署工具。该工具基于一个应用部署自动化管理信息模型，并通过远程代理技术，实现对复杂应用在不同环境下的自动化部署等。

IBM UCD 6.1版本至6.9.6.0版本中存在目录遍历漏洞。远程攻击者可利用该漏洞更改UCD部署。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=swg2C1000374

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-335


【漏洞名称】Red Hat RPM 安全漏洞

【漏洞编号】CNNVD-201808-333（CVE-2017-7500）

【漏洞详情】Red Hat RPM（RPM Package Manager）是美国红帽（Red Hat）公司的一款命令行驱动的软件包管理器，它主要用于安装、卸载、验证、查询和升级计算机软件包。

Red Hat RPM中存在安全漏洞，该漏洞源于当目标路径是目录的符号链接时，rpm未能妥当处理RPM的安装。攻击者可利用该漏洞将目录重定向到任意位置并获取root权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/rpm-software-management/rpm/commit/c815822c8bdb138066ff58c624ae83e3a12ebfa9

https://github.com/rpm-software-management/rpm/commit/f2d3be2a8741234faaa96f5fd05fdfdc75779a79

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-333


【漏洞名称】QNAP QTS Helpdesk 命令注入漏洞

【漏洞编号】CNNVD-201808-340（CVE-2018-0714）

【漏洞详情】QNAP QTS是中国威联通（QNAP Systems）公司的一套Turbo NAS作业系统。该系统可提供档案储存、管理、备份，多媒体应用及安全监控等功能。Helpdesk是其中的一个帮助台程序。

QNAP QTS中的Helpdesk 1.1.21及之前版本存在命令注入漏洞。远程攻击者可利用该漏洞在受影响的应用程序中运行任意命令。以下版本受到影响：QNAP QTS 4.2.6 build 20180531及之前版本，4.3.3 build 20180528及之前版本，4.3.4 build 20180528及之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.qnap.com/zh-tw/security-advisory/nas-201808-13

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-340


【漏洞名称】Hikvision IP摄像机缓冲区错误漏洞

【漏洞编号】CNNVD-201808-338（CVE-2018-6414）

【漏洞详情】HikVision IP Cameras是中国海康威视（Hikvision）公司的网络摄像机产品。

Hikvision IP摄像机的Web服务器中存在缓冲区溢出漏洞，该漏洞源于不充分的输入验证。攻击者可通过向受影响的设备发送特制的消息利用该漏洞损坏内存，执行任意代码或造成进程崩溃。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.hikvision.com/en/Support/Cybersecurity-Center/Security-Advisory/431181228784397

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-338


【漏洞名称】OpenEMR SQL注入漏洞

【漏洞编号】CNNVD-201808-318（CVE-2018-15145）

【漏洞详情】OpenEMR是OpenEMR社区所维护的一套开源的医疗管理系统。该系统可用于医疗实践管理、电子医疗记录、处方书写和医疗帐单申请。

OpenEMR 5.0.1.4之前版本中的portal/add_edit_event_user.php文件存在多个SQL注入漏洞。远程攻击者可借助‘eid’、‘userid’或‘pid’参数利用该漏洞执行任意SQL命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/openemr/openemr/pull/1758

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-318
