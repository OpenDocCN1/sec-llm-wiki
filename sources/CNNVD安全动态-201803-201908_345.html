今日CNNVD共发布安全漏洞37个。主要影响厂商为澳大利亚NetComm Wireless（4个）、德国Nextcloud（2个）、美国Crestron Electronics（2个）。主要影响产品为NetComm Wireless G LTE Light Industrial M2M Router（NWL-25）无线路由器（4个）、Nextcloud通信应用平台（2个）、Crestron TSW-X60触摸屏设备（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】NetComm Wireless G LTE Light Industrial M2M Router（NWL-25）安全漏洞

【漏洞编号】CNNVD-201808-282（CVE-2018-14785）

【漏洞详情】NetComm Wireless G LTE Light Industrial M2M Router（NWL-25）是澳大利亚NetComm Wireless公司的一款工业级无线路由器产品。

使用2.0.29.11及之前版本固件的NetComm Wireless G LTE Light Industrial M2M Router（NWL-25）中存在安全漏洞。攻击者可利用该漏洞获取设备的目录。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.netcommwireless.com/product/nwl-25#Firmware

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-282


【漏洞名称】Nextcloud Server 输入验证漏洞

【漏洞编号】CNNVD-201808-275（CVE-2018-3776）

【漏洞详情】Nextcloud是德国Nextcloud公司的一套开源的自托管文件同步和共享的通信应用平台。Nextcloud Server是其中的一个服务器版。

Nextcloud Server 12.0.3之前版本和11.0.5之前版本中存在输入验证漏洞。攻击者可利用该漏洞使其进行的操作不会被记录在审核日志中。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://nextcloud.com/security/advisory/?id=NC-SA-2018-006

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-275


【漏洞名称】Crestron TSW-X60 安全漏洞

【漏洞编号】CNNVD-201808-287（CVE-2018-10630）

【漏洞详情】Crestron TSW-X60是美国Crestron Electronics公司的一款交互式触摸屏设备。

Crestron TSW-X60 2.001.0037.001之前版本和MC3 1.502.0047.001之前版本中存在安全漏洞，该漏洞源于设备默认禁用身份验证，并且没有任何启用提示。攻击者可利用该漏洞访问CTP控制台。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.crestron.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-287


【漏洞名称】Oracle Database Server Java VM组件安全漏洞

【漏洞编号】CNNVD-201808-278（CVE-2018-3110）

【漏洞详情】Oracle Database Server是美国甲骨文（Oracle）公司的一套关系数据库管理系统。该数据库管理系统提供数据管理、分布式处理等功能。Java VM是其中的一个Java虚拟机组件。

Oracle Database Server中的Java VM组件存在安全漏洞。攻击者可利用该漏洞控制组件，影响数据的可用性、完整性和保密性。以下版本受到影响：Oracle Database Server 11.2.0.4版本，12.1.0.2版本，12.2.0.1版本，18版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.oracle.com/technetwork/security-advisory/alert-cve-2018-3110-5032149.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-278


【漏洞名称】PHP Scripts Mall advanced-real-estate-script 跨站脚本漏洞

【漏洞编号】CNNVD-201808-299（CVE-2018-15189）

【漏洞详情】PHP Scripts Mall advanced-real-estate-script是印度PHP Scripts Mall公司的一套基于PHP和MySQL的房地产网站系统脚本。

PHP Scripts Mall advanced-real-estate-script中存在跨站脚本漏洞。远程攻击者可借助个人资料中的Name字段利用该漏洞注入HTML代码。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.phpscriptsmall.com/product/advanced-real-estate-script/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-299
