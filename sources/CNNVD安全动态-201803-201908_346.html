今日CNNVD共发布安全漏洞14个，更新安全漏洞1个。主要影响厂商为英国Micro Focus（2个）、美国Cisco（1个）、美国Red Hat（1个）。主要影响产品为Micro Focus NetIQ eDirectory身份管理基础平台（2个）、Cisco Thor decoder视频编/解码器（1个）、Red Hat Ovirt虚拟化管理平台（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Micro Focus NetIQ eDirectory 安全漏洞

【漏洞编号】CNNVD-201808-261（CVE-2018-7692）

【漏洞详情】Micro Focus NetIQ eDirectory是英国Micro Focus公司的一套结合了身份管理架构和目录服务技术的身份管理基础平台。该平台提供认证策略、数据备份和恢复服务、数据容灾等功能。

Micro Focus NetIQ eDirectory 9.1.1 HF1之前版本中存在安全漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.netiq.com/documentation/edirectory-91/edirectory9111_releasenotes/data/edirectory9111_releasenotes.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-261


【漏洞名称】Cisco Thor decoder 缓冲区错误漏洞

【漏洞编号】CNNVD-201808-267（CVE-2018-0429）

【漏洞详情】Cisco Thor decoder是美国思科（Cisco）公司的一款视频编/解码器。

Cisco Thor decoder commit 18de8f9f0762c3a542b1122589edb8af859d9813之前版本中存在基于栈的缓冲区溢出漏洞。本地攻击者可借助特制的Thor比特流利用该漏洞造成拒绝服务（段错误）并执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/cisco/thor/commit/18de8f9f0762c3a542b1122589edb8af859d9813

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-267


【漏洞名称】Red Hat VDSM 安全漏洞

【漏洞编号】CNNVD-201808-273（CVE-2018-10908）

【漏洞详情】Red Hat Ovirt是美国红帽（Red Hat）公司的一套开源的虚拟化管理平台，是RHEV（企业虚拟化平台）的开源版本，由ovirt-node客户端和overt-engine管理端组成。VDSM是其中的一个虚拟桌面服务器管理器，它促进了管理控制台以及主机之间的通信，同样还允许RHEV-M管理虚拟机以及存储、收集有关主机及客户机的性能统计数据。

Red Hat VDSM 4.20.37之前版本中存在安全漏洞，该漏洞源于程序没有保护对qemu-img的调用。攻击者可通过上传特制的镜像利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://gerrit.ovirt.org/#/c/93195/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-273


【漏洞名称】Hitachi Command Suite 安全漏洞

【漏洞编号】CNNVD-201808-264（CVE-2018-14735）

【漏洞详情】Hitachi Command Suite是日本日立（HITACHI）公司的一套统一管理存储系统。它提供存储资源管理、分层存储管理、性能与服务水平管理等存储管理功能。

Hitachi Command Suite 8.5.3版本中存在安全漏洞。远程攻击者可借助特制的消息利用该漏洞泄露信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.hitachi.co.jp/Prod/comp/soft1/global/security/info/vuls/hitachi-sec-2018-123/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-264


【漏洞名称】PHP Scripts Mall Myperfectresume/JobHero/Resume Clone Script 跨站脚本漏洞

【漏洞编号】CNNVD-201808-269（CVE-2018-15183）

【漏洞详情】PHP Scripts Mall Myperfectresume/JobHero/Resume Clone Script是印度PHP Scripts Mall公司的一套在线简历生成网站脚本。

PHP Scripts Mall Myperfectresume/JobHero/Resume Clone Script 2.0.6版本中存在跨站脚本漏洞。远程攻击者可借助Full Name和Title字段利用该漏洞注入任意的Web脚本或HTML。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.phpscriptsmall.com/product/resume-builder-script/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201808-269
