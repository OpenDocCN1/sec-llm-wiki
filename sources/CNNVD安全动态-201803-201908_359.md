# CNNVD最新漏洞（2018-07-30）

今日CNNVD共发布安全漏洞24个，更新安全漏洞20个。主要影响厂商为瑞典LOGICOOL（2个）、日本DHC（1个）、中国联想（1个）。主要影响产品为LOGICOOL Game Software游戏设备管理软件（1个）、DHC Online Shop App for Android在线购物应用程序（1个）、Lenovo System x服务器（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******LOGICOOL Game Software 安全漏洞****

**【漏洞编号】********CNNVD-201807-1895**（CVE-2018-0620）****

**【漏洞详情】**LOGICOOL Game Software是瑞典LOGICOOL公司的一套游戏设备管理软件。该软件用于管理鼠标、键盘、耳机和扬声器等设备。

LOGICOOL Game Software 8.87.116之前版本中存在不可信的搜索路径漏洞。攻击者可借助目录下恶意的DLL利用该漏洞获取权限。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.logicool.co.jp

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1895

  

**【漏洞名称】****DHC Online Shop App for Android 安全漏洞**  

**【漏洞编号】******CNNVD-201807-1893**（CVE-2018-0622）**

**【漏洞详情】**DHC Online Shop App for Android是日本DHC公司的一款基于Android平台的在线购物应用程序。

基于Android平台的DHC Online Shop App 3.2.0及之前版本中存在安全漏洞，该漏洞源于程序没有验证SSL服务器端的X.509证书。攻击者可借助特制的证书利用该漏洞实施中间人攻击，伪造服务器并获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://top.dhc.co.jp/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1893

  

**【漏洞名称】****Lenovo System x和IBM System x 安全漏洞**

**【漏洞编号】******CNNVD-201807-1885**（CVE-2018-9068）**

**【漏洞详****情】**Lenovo System x是中国联想（Lenovo）公司的一款服务器。IBM System x是美国IBM公司的一款服务器。

Lenovo System x 4.90之前版本和IBM System x 6.80之前版本中存在安全漏洞，该漏洞源于程序使用了硬编码凭证来访问SFTP服务器并且在IMM2文档中对该凭证进行了描述。攻击者可利用该漏洞获取FFDC所收集的管理模块日志及诊断信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.lenovo.com/us/zh/solutions/len-20227

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1885

  

**【漏洞名称】******Linux kernel 安全漏洞****

**【****漏洞****编号****】****CNNVD-201807-1888****（CVE-2018-10881）**

**【漏洞详情】**Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。ext4 filesystem是其中的一套ext4文件系统组件。

Linux kernel中的ext4 filesystem存在安全漏洞。攻击者可借助特制的ext4文件系统镜像利用该漏洞造成拒绝服务（‘ext4\_get\_group\_info’函数越界访问）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=6e8ab72a812396996035a37e5ca4b3b99b5d214b

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1888

  

**【漏洞名称】****NEC Platforms Calsos CSDX和CSDJ系列产品跨站脚本漏洞**

**【漏洞编****号】****CNNVD-201807-1899****（CVE-2018-0614）**

**【漏洞详情】**NEC Platforms Calsos CSDX和CSDJ都是日本NEC Platforms公司的远程监控设备。

NEC Platforms Calsos CSDX和CSDJ系列产品中存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的Web脚本或HTML。以下产品和版本受到影响：NEC Platforms Calsos CSDX 1.37210411及之前版本；CSDX(P) 4.37210411及之前版本；CSDX(D) 3.37210411及之前版本；CSDX(S) 2.37210411及之前版本；CSDJ-B 01.03.00及之前版本；CSDJ-H 01.03.00及之前版本；CSDJ-D 01.03.00及之前版本；CSDJ-A 03.00.00版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www.necplatforms.co.jp/product/enkaku/info180702.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1899
