今日CNNVD共发布安全漏洞19个，更新安全漏洞5个。主要影响厂商为美国IBM（5个）、中国盛大网络（1个）。主要影响产品为IBM Rational Software Architect（RSA）Design Manager软件设计和开发平台（4个）、PHPCMS内容管理系统（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******IBM Rational Rhapsody Design Manager和Rational Software Architect Design Manager 安全漏洞****

**【漏洞编号】********CNNVD-201807-1557**（CVE-2018-1587）****

**【漏洞详情】**IBM Rational Software Architect（RSA）Design Manager和Rational Rhapsody Design Manager都是美国IBM公司的产品。RSA Design Manager是一套基于Jazz技术的协作式软件设计和开发平台。Rational Rhapsody Design Manager是一款通过中心设计存储库对设计和模型进行存储、共享、搜索和管理的软件。

IBM Rational Rhapsody Design Manager和IBM RSA Design Manager中存在安全漏洞。攻击者可借助技术性的错误信息利用该漏洞获取应用程序和数据库的信息。以下产品和版本受到影响：IBM Rational Rhapsody Design Manager 5.0版本至5.0.2，6.0版本至6.0.5版本；IBM Rational Software Architect Design Manager 5.0版本至5.0.2版本，6.0版本至6.0.1版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=ibm10716029

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1557

  

**【漏洞名称】****PHPCMS 安全漏洞**  

**【漏洞编号】******CNNVD-201807-1568**（CVE-2018-14399）**

**【漏洞详情】**PHPCMS是中国盛大网络（Shanda）公司的一套基于PHP和Mysql架构的网站内容管理系统。该系统包括新闻、图片、下载、信息、产品等模块。

PHPCMS 9.6.0版本中的libs\\classes\\attachment.class.php文件存在安全漏洞，该漏洞源于PHPCMS程序在下载远程/本地文件时没有对文件的类型做正确的效验。远程攻击者可利用该漏洞上传并执行任意的PHP代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.phpcms.cn/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1568

  

**【漏洞名称】****FFmpeg 安全漏洞**

**【漏洞编号】******CNNVD-201807-1570**（CVE-2018-14394）**

**【漏洞详****情】**FFmpeg是FFmpeg团队的一套可录制、转换以及流化音视频的完整解决方案。

FFmpeg 4.0.2之前版本中的libavformat/movenc.c文件存在安全漏洞。攻击者可借助特制的Waveform音频文件利用该漏洞造成拒绝服务（应用程序崩溃和错零错误）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/FFmpeg/FFmpeg/commit/3a2d21bc5f97aa0161db3ae731fc2732be6108b8

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1570

  

**【漏洞名称】******MyBB New Threads插件跨站脚本漏洞****

**【****漏洞****编号****】****CNNVD-201807-1571****（CVE-2018-14392）**

**【漏洞详情】**MyBB（又名MyBulletinBoard）是MyBB团队开发的一套用PHP和MySQL开发的免费且基于Web的论坛软件。New Threads plugin是使用在其中的一个主题插件。

MyBB New Threads插件1.2之前版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://community.mybb.com/mods.php?action=changelog&pid=1143

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1571

  

**【漏洞名称】****Wireshark IEEE 802.11 protocol解析器安全漏洞**

**【漏洞编****号】****CNNVD-201807-1572****（CVE-2018-14370）**

**【漏洞详情】**Wireshark（前称Ethereal）是Wireshark团队开发的一套网络数据包分析软件。该软件的功能是截取网络数据包，并显示出详细的数据以供分析。IEEE 802.11 protocol dissector是其中的一个IEEE 802.11协议解析器。

Wireshark 2.6.0版本至2.6.1版本和2.4.0版本至2.4.7版本中的IEEE 802.11 protocol解析器存在安全漏洞。攻击者可利用该漏洞造成解析器崩溃（缓冲区越界读取）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.wireshark.org/security/wnpa-sec-2018-43.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1572
