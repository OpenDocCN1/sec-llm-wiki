今日CNNVD共发布安全漏洞9个。主要影响厂商为美国Oracle（6个）。主要影响产品为Oracle Fusion Middleware（Oracle融合中间件）业务创新平台。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Oracle Fusion Middleware Oracle WebLogic Server组件安全漏洞****

**【漏洞编号】********CNNVD-201807-1276**（CVE-2018-2893）****

**【漏洞详情】**Oracle Fusion Middleware（Oracle融合中间件）是美国甲骨文（Oracle）公司的一套面向企业和云环境的业务创新平台。该平台提供了中间件、软件集合等功能。Oracle WebLogic Server是其中的一个适用于云环境和传统环境的应用服务器组件。

Oracle Fusion Middleware中的Oracle WebLogic Server组件的WLS Core Components子组件存在安全漏洞。攻击者可利用该漏洞控制Oracle WebLogic Server，影响数据的保密性、可用性和完整性。以下版本受到影响：Oracle WebLogic Server 10.3.6.0版本，12.1.3.0版本，12.2.1.2版本，12.2.1.3版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

http://www.oracle.com/technetwork/security-advisory/cpujul2018-4258247.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1276

  

**【漏洞名称】****TeamViewer 安全漏洞**  

**【漏洞编号】****CNNVD-201807-1272（CVE-2018-14333）**

**【漏洞详情】**TeamViewer是一个套用于远程控制、桌面共享和文件传输的解决方案。

TeamViewer 13.1.1548及之前版本中存在安全漏洞，该漏洞源于程序将密码以Unicode格式存储在\[00 88\]和\[00 00 00\]分隔符之间的TeamViewer.exe进程内存中。攻击者可利用该漏洞获取敏感信息。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.teamviewer.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1272

  

**【漏洞名称】****XiaoCms X1 跨站请求伪造漏洞**

**【漏洞编号】******CNNVD-201807-1273**（CVE-2018-14331）**

**【漏洞详****情】**XiaoCms X1是一套基于PHP和MySQL并能够运行在Linux、Windows等平台上的轻量级内容管理系统（CMS）。

XiaoCms X1 20140305版本中存在跨站请求伪造漏洞。远程攻击者可借助admin/index.php?c=index&a=my URL利用该漏洞更改管理员账户密码。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

http://www.xiaocms.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1273

  

**【漏洞名称】******HTSlib 竞争条件漏洞****

**【****漏洞****编号****】****CNNVD-201807-1274****（CVE-2018-14329）**

**【漏洞详情】**HTSlib是一款使用C语言编写的用于访问SAM、CRAM和VCF等高通量测序数据的库。

HTSlib 1.8版本中cram/cram\_io.c文件存在竞争条件漏洞。攻击者可通过实施符号链接攻击利用该漏洞覆盖任意文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/samtools/htslib/issues/736

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1274
