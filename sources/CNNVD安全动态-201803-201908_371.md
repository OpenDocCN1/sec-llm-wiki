今日CNNVD共发布安全漏洞80个，更新安全漏洞5个。主要影响厂商为美国Adobe（40个）、美国Cisco（7个）、中国威联通（5个）。主要影响产品为Adobe Acrobat文件编辑和转换工具（39个）、Cisco Firepower System Software防火墙（2个）、QNAP Q'center Virtual Appliance虚拟设备（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Adobe Acrobat和Reader 缓冲区错误漏洞****

**【漏洞编号】********CNNVD-201807-1000**（CVE-2018-12771）****

**【漏洞详情】**Adobe Acrobat和Reader都是美国奥多比（Adobe）公司的产品。前者是一套PDF文件编辑和转换工具，后者是一套PDF文档阅读软件。

Adobe Acrobat和Reader中存在安全漏洞。远程攻击者可利用该漏洞执行任意代码（越界写入）。基于Windows和macOS平台的以下产品和版本受到影响：Adobe Acrobat DC(Continuous)2018.011.20040及之前版本，Acrobat 2017(Classic 2017)2017.011.30080及之前版本，Acrobat DC(Classic 2015)2015.006.30418及之前版本；Acrobat Reader DC(Continuous)2018.011.20040及之前版本，Acrobat Reader 2017(Classic 2017)2017.011.30080及之前版本，Acrobat Reader DC(Classic 2015)2015.006.30418及之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://helpx.adobe.com/security/products/acrobat/apsb18-21.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1000

  

**【漏洞名称】****Cisco Firepower System Software检测引擎安全漏洞**  

**【漏洞编号】******CNNVD-201807-1215**（CVE-2018-0385）**

**【漏洞详情】**Cisco Firepower System Software是美国思科（Cisco）公司的一款下一代防火墙产品（NGFW）。

Cisco Firepower System Software的检测引擎中安全套接层协议数据包的解析存在拒绝服务漏洞，该漏洞源于程序没有正确的处理SSL流量。远程攻击者可通过发动特制的SSL流量

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bst.cloudapps.cisco.com/bugsearch/bug/CSCvi36434

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1215

  

**【漏洞名称】****QNAP Q'center Virtual Appliance 命令注入漏洞**

**【漏洞编号】******CNNVD-201807-1199**（CVE-2018-0710）**

**【漏洞详****情】**QNAP Q'center Virtual Appliance是中国威联通（QNAP Systems）公司的一款用于在Microsoft Hyper-V、VMware ESXi和Workstation等虚拟环境中部署Q'center（QNAP NAS管理平台）的虚拟设备。

QNAP Q'center Virtual Appliance 1.7.1063及之前版本中的SSH存在命令注入漏洞。攻击者可利用该漏洞执行任意命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.qnap.com/zh-tw/security-advisory/nas-201807-10

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1199

  

**【漏洞名称】******Symantec Norton App Lock 安全漏洞****

**【****漏洞****编号****】****CNNVD-201807-1214****（CVE-2018-5239）**

**【漏洞详情】**Symantec Norton App Lock是美国赛门铁克（Symantec）公司的一套为移动设备提供安全防护功能的应用程序。

Symantec Norton App Lock 1.3.0.332之前版本中存在安全漏洞。攻击者可利用该漏洞绕过应用程序，阻止该程序锁住设备，从而获取设备的访问权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.symantec.com/en\_US/article.SYMSA1455.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1214

  

**【漏洞名称】****ZOHO ManageEngine Desktop Central 安全漏洞**

**【漏洞编****号】****CNNVD-201807-1227****（CVE-2018-11717）**

**【漏洞详情】**ZOHO ManageEngine Desktop Central（DC）是美国卓豪（ZOHO）公司的一套桌面管理解决方案。该方案包含软件分发、补丁管理、系统配置、远程控制等功能模块，可对桌面机以及服务器管理的整个生命周期提供支持。

ZOHO ManageEngine DC 100251之前版本中存在安全漏洞。攻击者可借助日志文件的访问权限利用该漏洞获取AD账户的Base64编码的用户名/密码，EAS账户的邮件设备及明文密码/用户名，Android设备的recovery\_password的明文密码，‘set’账户的明文密码，注册设备的地址，有关注册设备的重要信息（例如：系列号、UUID、型号）等。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.manageengine.com/products/desktop-central/vulnerability-in-log-files.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1227
