# CNNVD最新漏洞（2018-07-17）

今日CNNVD共发布安全漏洞55个，更新安全漏洞46个。主要影响厂商为美国Adobe（27个）、美国IBM（3个）、中国联想（2个）。主要影响产品为Adobe Acrobat文件编辑和转换工具（25个）、IBM Security Identity Governance and Intelligence Virtual Appliance解决方案（2个）、Lenovo Smart Assistant Android app应用程序（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Adobe Acrobat和Reader 缓冲区错误漏洞****

**【漏洞编号】********CNNVD-201807-1039**（CVE-2018-5056）****

**【漏洞详情】**Adobe Acrobat和Reader都是美国奥多比（Adobe）公司的产品。前者是一套PDF文件编辑和转换工具，后者是一套PDF文档阅读软件。

Adobe Acrobat和Reader中XPS文件的解析存在越界读取漏洞，该漏洞源于程序没有正确的验证用户提交的数据。远程攻击者可借助恶意的页面或文件利用该漏洞泄露敏感信息。基于Windows和macOS平台的以下产品和版本受到影响：Adobe Acrobat DC(Continuous)2018.011.20040及之前版本，Acrobat 2017(Classic 2017)2017.011.30080及之前版本，Acrobat DC(Classic 2015)2015.006.30418及之前版本；Acrobat Reader DC(Continuous)2018.011.20040及之前版本，Acrobat Reader 2017(Classic 2017)2017.011.30080及之前版本，Acrobat Reader DC(Classic 2015)2015.006.30418及之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://helpx.adobe.com/security/products/acrobat/apsb18-21.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1039

  

**【漏洞名称】****IBM Security Identity Governance and Intelligence Virtual Appliance 安全漏洞**  

**【漏洞编号】******CNNVD-201807-1182**（CVE-2017-1395）**

**【漏洞详情】**IBM Security Identity Governance and Intelligence Virtual Appliance是美国IBM公司的一套身份管理和治理解决方案。该产品包括了生命周期管理、访问风险评估和身份认证管理等功能。

IBM Security Identity Governance and Intelligence Virtual Appliance 5.2版本至5.2.3.2版本中存在安全漏洞，该漏洞源于程序没有正确的打开HHTTP Strict Transport Security功能。远程攻击者可利用该漏洞实施中间人攻击，获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22016869

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1182

  

**【漏洞名称】****Lenovo Smart Assistant Android app 安全漏洞**

**【漏洞编号】******CNNVD-201807-1174**（CVE-2018-9070）**

**【漏洞详****情】**Lenovo Smart Assistant Android app是中国联想（Lenovo）公司的一款用于控制Lenovo Smart Assistant智能音箱的基于Android平台的应用程序。

Lenovo Smart Assistant Android app 12.1.82之前版本中存在安全漏洞。物理位置临近的攻击者可利用该漏洞进入出厂检测模式并打开Web服务，并获取权限（例如：更改设置及运行代码）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.lenovo.com/us/en/solutions/LEN-22172

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1174

  

**【漏洞名称】******VMware Tools 缓冲区错误漏洞****

**【****漏洞****编号****】****CNNVD-201807-1191****（CVE-2018-6969）**

**【漏洞详情】**VMware Tools是美国威睿（VMware）公司的一套VMWare虚拟机自带的增强工具，它是VMware提供的用于增强虚拟显卡和硬盘性能、以及同步虚拟机与主机时钟的驱动程序。

VMware Tools 10.x版本和10.3.0之前版本中的HGFS存在越界读取漏洞。攻击者可利用该漏洞泄露信息或提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.vmware.com/security/advisories/VMSA-2018-0017.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1191

  

**【漏洞名称】****G DATA Total Security 缓冲区错误漏洞**

**【漏洞编****号】****CNNVD-201807-1173****（CVE-2018-10018）**

**【漏洞详情】**G DATA Total Security是德国G DATA Software公司的一套防病毒软件。该软件具有防钓鱼、防病毒和防垃圾软件等功能。

G DATA Total Security 25.4.0.3版本中的GDASPAMLib.AntiSpam ActiveX control ASK\\GDASpam.dll文件存在缓冲区溢出漏洞。攻击者可借助较长的‘IsBlackListed’参数利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.gdatasoftware.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-1173
