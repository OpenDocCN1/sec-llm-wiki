今日CNNVD共发布安全漏洞64个。主要影响厂商为美国Microsoft（53个）、美国Red Hat（2个）、美国Joyent（1个）。主要影响产品为Microsoft Windows 10操作系统（15个）、Red Hat Ceph分布式文件系统（2个）、Joyent Node.js网络应用平台（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Microsoft Windows Edge 信息泄露漏洞

【漏洞编号】CNNVD-201807-834（CVE-2018-8325）

【漏洞详情】Microsoft Windows 10是美国微软（Microsoft）公司发布的一套新一代跨平台操作系统，它适用于PC和笔记本电脑、平板电脑以及手机等设备。Edge是其中的一个系统附带的默认浏览器。

Microsoft Windows 10版本1803上的Edge中存在信息泄露漏洞，该漏洞源于程序没有正确的处理内存中的对象。攻击者可利用该漏洞获取信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2018-8325

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-834


【漏洞名称】Red Hat Ceph 安全漏洞

【漏洞编号】CNNVD-201807-961（CVE-2018-1128）

【漏洞详情】Red Hat Ceph是美国红帽（Red Hat）公司的一套Linux PB级分布式文件系统。该系统的主要目标是设计成基于POSIX（可移植操作系统接口）的没有单点故障的分布式文件系统，使数据能容错和无缝的复制。Ceph branches master、mimic、luminous和jewel都是不同的Ceph版本。

Red Hat Ceph中存在安全漏洞，该漏洞源于cephx身份验证协议没有正确的验证ceph客户。攻击者可利用该漏洞执行ceph服务所允许的操作。以下版本受到影响：Red Hat Ceph branches master，mimic，luminous，jewel。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://tracker.ceph.com/issues/24836

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-961


【漏洞名称】Joyent Node.js macaddress模块命令注入漏洞

【漏洞编号】CNNVD-201807-968（CVE-2018-13797）

【漏洞详情】Joyent Node.js是美国Joyent公司的一套建立在Google V8 JavaScript引擎之上的网络应用平台。macaddress module是使用在其中的一个Mac地址管理模块。

Joyent Node.js macaddress模块0.2.9之前版本中存在命令注入漏洞。攻击者可利用该漏洞注入任意的命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/scravy/node-macaddress/releases/tag/0.2.9

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-968


【漏洞名称】Atlassian Confluence 安全漏洞

【漏洞编号】CNNVD-201807-965（CVE-2018-13389）

【漏洞详情】Atlassian Confluence是澳大利亚Atlassian公司的一套专业的企业知识管理与协同软件，也可以用于构建企业WiKi。该软件可实现团队成员之间的协作和知识共享。

Atlassian Confluence 6.6.1之前版本中的attachment资源存在安全漏洞。远程攻击者可借助附件利用该漏洞在Mozilla Firefox Browser中伪造Web内容。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://jira.atlassian.com/browse/CONFSERVER-54906

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-965


【漏洞名称】Dspace 路径遍历漏洞

【漏洞编号】CNNVD-201807-970（CVE-2016-10726）

【漏洞详情】Dspace是一套开源的数字资产管理系统。该系统主要用于管理和发布由数字文件或“位流”组成的数据。

Dspace 3.6之前版本、4.5之前的4.x版本和5.5之前的5.x版本中的XMLUI功能存在目录遍历漏洞。攻击者可借助路径名之前带有一个冒号及两个或更多字符的themes/路径利用该漏洞利用该漏洞读取系统上的文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/DSpace/DSpace/releases/tag/dspace-5.5

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-970
