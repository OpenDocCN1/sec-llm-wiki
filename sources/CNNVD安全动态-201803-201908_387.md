# CNNVD最新漏洞（2018-07-03）

今日CNNVD共发布安全漏洞49个。主要影响厂商为美国ZOHO（4个）、俄罗斯SAFE'N'SEC（3个）、美国Ivanti（2个）。主要影响产品为ZOHO ManageEngine Applications Manager解决方案（1个）、SAFE'N'SEC SoftControl/SafenSoft SysWatch、SoftControl/SafenSoft TPSecure和SoftControl/SafenSoft Enterprise Suite应用程序（3个）、Ivanti Avalanche移动设备管理系统（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******ZOHO ManageEngine Applications Manager 跨站脚本漏洞****

**【漏洞编号】********CNNVD-201807-038**（CVE-2018-12996）****

**【漏洞详情】**ZOHO ManageEngine Applications Manager是美国卓豪（ZOHO）公司的一套IT运维管理解决方案。该产品具有应用性能管理、故障管理、报表生成和SLA管理等功能。

ZOHO ManageEngine Applications Manager 13 (Build 13780)之前版本中存在跨站脚本漏洞。远程攻击者可通过向GraphicalView.do发送‘method’参数利用该漏洞注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.manageengine.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-038

  

**【漏洞名称】****SAFE'N'SEC SoftControl/SafenSoft SysWatch、SoftControl/SafenSoft TPSecure和SoftControl/SafenSoft Enterprise Suite 安全漏洞**  

**【漏洞编号】******CNNVD-201807-021**（CVE-2018-13014）**

**【漏洞详情】**SAFE'N'SEC SoftControl/SafenSoft SysWatch、SoftControl/SafenSoft TPSecure和SoftControl/SafenSoft Enterprise Suite都是俄罗斯SAFE'N'SEC公司的能够主动防御恶意软件的应用程序。

SAFE'N'SEC SoftControl/SafenSoft SysWatch、SoftControl/SafenSoft TPSecure和SoftControl/SafenSoft Enterprise Suite 4.4.2之前版本中的safensec.com (SysWatch service)存在安全漏洞，该漏洞源于程序将密码存储为可恢复的格式。本地攻击者可利用该漏洞获取SysWatch密码并修改程序设置。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.safensoft.com/security.phtml?c=865#SNSVE-2018-2

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-021

  

**【漏洞名称】****Ivanti Avalanche 安全漏洞**

**【漏洞编号】******CNNVD-201807-019**（CVE-2018-8902）**

**【漏洞详****情】**Ivanti Avalanche是美国Ivanti公司的一套企业移动设备管理系统。该系统主要用于管理智能手机、平板电脑和条形码扫描仪等设备。

Ivanti Avalanche 5.3版本至6.2版本中存在安全漏洞，该漏洞源于程序使用单一的共享密钥加密模式来加密数据。攻击者可借助该共享密钥利用该漏洞访问存储的敏感信息（包括：Wi-Fi密码）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://community.ivanti.com/docs/DOC-68406

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-019

  

**【漏洞名称】******Micro Focus Secure Messaging Gateway Web administration组件操作系统命令注入漏洞****

**【漏洞****编号】******CNNVD-201807-017**（CVE-2018-12465）**

**【漏洞详情】**Micro Focus Secure Messaging Gateway（SMG）是英国Micro Focus公司的一套企业网络和消息系统出、入站保护软件。该产品包括病毒防护、反垃圾邮件、防DDos攻击和图像分析等功能。Web administration是其中的一个基于Web的管理组件。

Micro Focus SMG 471之前版本中的Web administration组件存在操作系统命令注入漏洞。远程攻击者可利用该漏洞在SMG服务器上执行任意的操作系统命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.microfocus.com/kb/doc.php?id=7023133

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-017

  

**【漏洞名称】****gpmf-parser 缓冲区错误漏洞**

**【漏洞编****号】****CNNVD-201807-026****（CVE-2018-13009）**

**【漏洞详情】**gpmf-parser是一款用于在MP4等视频文件中存储高频周期性传感器数据的gpmf格式文件的解析器。

gpmf-parser 1.1.2版本中的GPMF\_parser.c文件的‘GPMF\_Next’函数存在堆溢出漏洞。攻击者可利用该漏洞造成基于堆的缓冲区越界读取。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/gopro/gpmf-parser/issues/29

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201807-026
