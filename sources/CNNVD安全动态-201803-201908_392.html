今日CNNVD共发布安全漏洞30个，更新安全漏洞1个。主要影响厂商为美国IBM（4个）、美国TIBCO（3个）、美国F5（2个）。主要影响产品为IBM WebSphere Application Server（WAS）应用服务器（1个）、TIBCO Spotfire Analyst数据分析与挖掘平台（2个）、F5 BIG-IP网络设备（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】IBM WebSphere Application Server Liberty 信息泄露漏洞

【漏洞编号】CNNVD-201806-1350（CVE-2018-1553）

【漏洞详情】IBM WebSphere Application Server（WAS）是美国IBM公司开发并发行的一款应用服务器产品，它是Java EE和Web服务应用程序的平台，也是IBM WebSphere软件平台的基础。Liberty是WAS的一个动态服务器配置文件。

IBM WAS Liberty 18.0.0.2之前版本中存在信息泄露漏洞，该漏洞源于SAML Web SSO功能没有正确的处理异常。远程攻击者可利用该漏洞获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22016218

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-1350


【漏洞名称】多款TIBCO产品TIBCO Spotfire Client和TIBCO Spotfire Web Player Client组件安全漏洞

【漏洞编号】CNNVD-201806-1364（CVE-2018-5437）

【漏洞详情】TIBCO Spotfire Analyst等都是美国TIBCO软件公司的产品。Spotfire Analyst是一套数据分析和挖掘平台；Spotfire Desktop是一套专为探索数据设计的分析软件。Spotfire Client是其中的一个客户端组件；Spotfire Web Player Client是其中的一个基于Web的客户端组件。

多款TIBCO产品中的TIBCO Spotfire Client和TIBCO Spotfire Web Player Client组件存在安全漏洞。攻击者可利用该漏洞泄露消息。以下产品和版本受到影响：TIBCO Spotfire Analyst 7.8.0及之前版本，7.9.0版本，7.9.1版本，7.10.0版本，7.10.1版本，7.11.0版本，7.12.0版本；TIBCO Spotfire Analytics Platform for AWS Marketplace 7.12.0及之前版本；TIBCO Spotfire Automation Services 7.12.0及之前版本；TIBCO Spotfire Deployment Kit 7.8.0及之前版本，7.9.0版本，7.9.1版本，7.10.0版本，7.10.1版本，7.11.0版本，7.12.0版本；TIBCO Spotfire Desktop 7.8.0及之前版本，7.9.0版本，7.9.1版本，7.10.0版本，7.10.1版本，7.11.0版本，7.12.0版本；TIBCO Spotfire Desktop Language Packs 7.8.0及之前版本，7.9.0版本，7.9.1版本，7.10.0版本，7.10.1版本，7.11.0版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.tibco.com/support/advisories/2018/06/tibco-security-advisory-june-26-2018-tibco-spotfire-2018-5437

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-1364


【漏洞名称】F5 BIG-IP 安全漏洞

【漏洞编号】CNNVD-201806-1344（CVE-2018-5528）

【漏洞详情】F5 BIG-IP是美国F5公司的一款集成了网络流量管理、应用程序安全管理、负载均衡等功能的多合一网络设备。

F5 BIG-IP 13.0.1版本和13.1.0.4版本至13.1.0.7版本中存在安全漏洞。攻击者可利用该漏洞造成TMM重启并生成core文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.f5.com/csp/article/K27044729

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-1344


【漏洞名称】Fortinet FortiManager和FortiAnalyzer 安全漏洞

【漏洞编号】CNNVD-201806-1346（CVE-2018-1355）

【漏洞详情】Fortinet FortiManager和FortiAnalyzer都是美国飞塔（Fortinet）公司的产品。Fortinet FortiManager是一套集中式网络安全管理解决方案。FortiAnalyzer是一套集中式网络安全报告解决方案。

Fortinet FortiManager 6.0.0及之前版本和FortiAnalyzer 6.0.0及之前版本中存在开放重定向漏洞。攻击者可通过实施社会工程攻击利用该漏洞注入脚本代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://fortiguard.com/psirt/FG-IR-18-022

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-1346


【漏洞名称】Apache Pluto 安全漏洞

【漏洞编号】CNNVD-201806-1354（CVE-2018-1306）

【漏洞详情】Apache Pluto是美国阿帕奇（Apache）软件基金会的一套Portlet容器的运行时环境。

Apache Pluto 3.0.0版本中的PortletV3AnnotatedDemo Multipart Portlet war文件代码存在安全漏洞，该漏洞源于在上传文件时程序没有限制提交的路径信息。远程攻击者可利用该漏洞获取配置数据和其他敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://portals.apache.org/pluto/security.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-1354
