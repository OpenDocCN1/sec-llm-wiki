今日CNNVD共发布安全漏洞17个，更新安全漏洞55个。主要影响厂商为美国Intel（1个）、美国Automated Logic Corporation（ALC）（1个）、中国华为（1个）。主要影响产品为Intel Core-based microprocessors中央处理器（1个）、ALC WebCTRL自动化控制系统（1个）、Huawei HG255s-10无线路由器（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Intel Core-based microprocessors 安全漏洞

【漏洞编号】CNNVD-201806-895（CVE-2018-3665）

【漏洞详情】Intel Core-based microprocessors是美国英特尔（Intel）公司的酷睿系列中央处理器产品（CPU）。

Intel Core-based microprocessors中存在安全漏洞。攻击者可利用该漏洞获取数寄存器中存储的有关其他进程值。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.intel.com/content/www/us/en/security-center/advisory/intel-sa-00145.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-895


【漏洞名称】ALC WebCTRL 安全漏洞

【漏洞编号】CNNVD-201806-884（CVE-2018-8819）

【漏洞详情】ALC WebCTRL是美国Automated Logic Corporation（ALC）公司的一套楼宇自动化控制系统。

ALC WebCTRL 6.0版本、6.1版本和6.5版本中存在XML外部实体注入漏洞。攻击者可借助‘X-Wap-Profile’HTTP包头利用该漏洞泄露底层Web服务器操作系统上的文件内容。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.automatedlogic.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-884


【漏洞名称】Huawei HG255s-10 路径遍历漏洞

【漏洞编号】CNNVD-201806-894（CVE-2017-17309）

【漏洞详情】Huawei HG255s-10是中国华为（Huawei）公司的一款无线路由器产品。

Huawei HG255s-10 V100R001C163B025SP02版本中存在路径遍历漏洞，该漏洞源于程序没有充分的验证接收到的HTTP请求。远程攻击者可利用该漏洞在未经身份验证的情况下访问设备上的本地文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.huawei.com/cn/psirt/security-notices/2017/huawei-sn-20170911-01-hg255s-cn

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-894


【漏洞名称】PE client tools for Windows 安全漏洞

【漏洞编号】CNNVD-201806-881（CVE-2018-6516）

【漏洞详情】Puppet是美国Puppet实验室的一套基于客户端/服务器（C/S）架构的配置管理工具，它可用于管理配置文件、用户、cron任务、软件包、系统服务等。Puppet Enterprise是一个企业版。PE client tools for Windows是其中的一款基于Windows平台的用于控制、管理Puppet Enterprise的命令行工具。

基于Windows平台的PE client tools 16.4.6之前的16.4.x版本、17.3.6之前的17.3.x版本和18.1.2之前的18.1.x版本中存在安全漏洞。攻击者可借助特制的配置文件利用该漏洞加载任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://puppet.com/security/cve/CVE-2018-6516

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-881


【漏洞名称】Synology Calendar 授权问题漏洞

【漏洞编号】CNNVD-201806-893（CVE-2018-8927）

【漏洞详情】Synology Calendar是群晖（Synology）公司的一款运行在Synology NAS设备上的文件保护程序。

Synology Calendar 2.1.2-0511之前版本中的SYNO.Cal.Event存在授权问题漏洞。远程攻击者可借助‘cal_id’或‘original_cal_id’参数利用该漏洞创建任意事件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.synology.cn/en-global/support/security/Synology_SA_18_16

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-893
