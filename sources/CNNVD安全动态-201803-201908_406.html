今日CNNVD共发布安全漏洞56个。主要影响厂商为美国Google（18个）、英国Trend Micro（3个）、美国McAfee（2个）。主要影响产品为ndroid on Google Pixel和Nexus开源操作系统（17个）、Trend Micro OfficeScan反病毒软件（3个）、McAfee Network Security Management（NSM）安全解决方案（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】Android Qualcomm WLAN 缓冲区错误漏洞

【漏洞编号】CNNVD-201806-695（CVE-2018-5851）

【漏洞详情】Android on Google Pixel和Nexus是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套运行于Google Pixel和Nexus（智能手机）中并以Linux为基础的开源操作系统。Qualcomm WLAN是使用在其中的一个美国高通（Qualcomm）公司开发的无线局域网组件。

Google Pixel和Nexus设备上的Android中的Qualcomm WLAN中存在缓冲区错误漏洞。攻击者可利用该漏洞执行任意代码或造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/pixel/2018-05-01

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-695


【漏洞名称】Trend Micro OfficeScan 安全漏洞

【漏洞编号】CNNVD-201806-726（CVE-2018-10509）

【漏洞详情】Trend Micro OfficeScan是美国趋势科技（Trend Micro）公司的一套分布式反病毒软件。

Trend Micro OfficeScan 11.0 SP1版本和XG版本中存在安全漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://success.trendmicro.com/solution/1119961

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-726


【漏洞名称】McAfee Network Security Management 安全漏洞

【漏洞编号】CNNVD-201806-741（CVE-2017-3962）

【漏洞详情】McAfee Network Security Management（NSM）是美国迈克菲（McAfee）公司的一套能够实时监控整个网络中已部署的迈克菲入侵防护系统的网络安全解决方案。

McAfee NSM  8.2.7.42.2之前版本中的无需证书的身份验证机制存在安全漏洞。攻击者可借助未加盐的散列利用该漏洞破解用户密码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://kc.mcafee.com/corporate/index?page=content&id=SB10192

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-741


【漏洞名称】SAP Infrastructure和UI 安全漏洞

【漏洞编号】CNNVD-201806-733（CVE-2018-2428）

【漏洞详情】SAP Infrastructure和UI都是德国思爱普（SAP）公司的产品。SAP Infrastructure是一套IT基础架构管理解决方案。该方案能够发现并管理局域网内所有网络资产，并持续监控资产数据。UI是一套基于JavaScript的UI库，它集成了大量的UI控件。

SAP Infrastructure和UI中存在安全漏洞。攻击者可利用该漏洞访问信息。以下产品和版本受到影响：SAP Infrastructure 1.0版本；SAP UI 7.4版本，7.5版本，7.51版本，7.52版本，SAP UI 2.0版本（用于SAP NetWeaver 7.00版本）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wiki.scn.sap.com/wiki/pages/viewpage.action?pageId=495289255

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-733


【漏洞名称】Digium Asterisk Open Source 安全漏洞

【漏洞编号】CNNVD-201806-749（CVE-2018-12228）

【漏洞详情】Digium Asterisk Open Source是美国Digium公司的一套开源的电话交换机（PBX）系统软件。该软件支持语音信箱、多方语音会议、交互式语音应答(IVR)等。

Digium Asterisk Open Source 15.4.1之前的15.x版本中存在安全漏洞。攻击者可通过突然中断客户端链接或发送特制的消息利用该漏洞造成系统无法使用（无限循环）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://downloads.asterisk.org/pub/security/AST-2018-007.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-749
