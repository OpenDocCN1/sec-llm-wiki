CNNVD最新漏洞（2018-06-12）

今日CNNVD共发布安全漏洞93个，更新安全漏洞5个。主要影响厂商为美国Apple（49个）、印度PHP Scripts Mall（5个）、美国Trend Micro（4个）。主要影响产品为Apple macOS High Sierra操作系统（14个）、PHP Scripts Mall Schools Alert Management Script管理系统脚本（5个）、Trend Micro OfficeScan反病毒软件（4个）。

今日需关注的典型漏洞如下:

【漏洞名称】Apple macOS High Sierra Speech 安全漏洞

【漏洞编号】CNNVD-201806-628（CVE-2018-4184）

【漏洞详情】Apple macOS High Sierra是美国苹果（Apple）公司为Mac计算机所开发的一套专用操作系统。Speech是其中的一个语音识别组件。

Apple macOS High Sierra 10.13.5之前版本中的Speech组件的麦克风访问的处理存在安全漏洞。攻击者可利用该漏洞绕过沙盒限制，获取麦克风的访问权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/zh-cn/HT208849

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-628


【漏洞名称】PHP Scripts Mall Schools Alert Management Script SQL注入漏洞

【漏洞编号】CNNVD-201806-655（CVE-2018-12055）

【漏洞详情】PHP Scripts Mall Schools Alert Management Script是印度PHP Scripts Mall公司的一套学校管理系统脚本。

PHP Scripts Mall Schools Alert Management Script中的多个cgi存在SQL注入漏洞。远程攻击者可通过POST请求发送特制的数据利用该漏洞执行任意SQL命令。（多个cgi包括：contact_us.php、faq.php、about.php、photo_gallery.php、privacy.php等）

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.phpscriptsmall.com/product/schools-alert-management-system/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-655


【漏洞名称】Trend Micro OfficeScan TMWFP驱动程序安全漏洞

【漏洞编号】CNNVD-201806-639（CVE-2018-10506）

【漏洞详情】Trend Micro OfficeScan是美国趋势科技（Trend Micro）公司的一套分布式反病毒软件。TMWFP driver是其中的一个TMWFP驱动程序。

Trend Micro OfficeScan 11.0 SP1版本和XG版本中的TMWFP驱动程序的IOCTL 0x220004的处理存在安全漏洞，该漏洞源于程序缺少对用户所提交数据的验证。攻击者可借助低权限代码的执行权限利用该漏洞泄露信息（越界读取）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://success.trendmicro.com/solution/1119961

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-639


【漏洞名称】Cisco AppDynamics App iQ Platform SQL注入漏洞

【漏洞编号】CNNVD-201806-581（CVE-2018-0225）

【漏洞详情】Cisco AppDynamics App iQ Platform是美国思科（Cisco）公司的一款实时应用程序和业务性能监控解决方案。

Cisco AppDynamics App iQ Platform 4.4.3.10598 (HF4)之前版本中的企业控制台存在SQL注入漏洞。远程攻击者可利用该漏洞注入SQL语句。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://docs.appdynamics.com/display/PRO44/Release+Notes#ReleaseNotes-4.4.3.10598%28HF4%29Updates

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-581


【漏洞名称】IBM Security Identity Manager Virtual Appliance 安全漏洞

【漏洞编号】CNNVD-201806-646（CVE-2018-1453）

【漏洞详情】IBM Security Identity Manager（ISIM）是美国IBM公司的一套身份管理和治理解决方案。该方案可在整个用户生命周期内自动创建、修改、重新认证和终止用户特权，并支持基于策略的密码管理。IBM Security Identity Manager（ISIM）Virtual Appliance是ISIM虚拟应用程序。

IBM ISIM Virtual Appliance 7.0版本中存在安全漏洞。攻击者可利用该漏洞上传或传输在该环境中被自动处理的危险类型文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22013617

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-646
