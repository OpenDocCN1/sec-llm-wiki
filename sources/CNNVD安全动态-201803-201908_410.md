今日CNNVD共发布安全漏洞120个，更新安全漏洞19个。主要影响厂商为美国Cisco（28个）、美国Google（3个）、美国IBM（2个）。主要影响产品为Cisco Prime Collaboration Provisioning（PCP）通信服务软件（6个）、Android开源操作系统（3个）、IBM Robotic Process Automation with Automation Anywhere自动化解决方案（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Cisco Prime Collaboration Provisioning 权限许可和访问控制漏洞**

**【漏洞编号】****CNNVD-201806-393（CVE-2018-0322）**

**【漏洞详情】**Cisco Prime Collaboration Provisioning（PCP）是美国思科（Cisco）公司的一套基于Web的下一代通信服务软件。该软件对IP电话、语音邮件和统一通信环境提供IP通信服务功能。

Cisco PPCP 12.1及之前版本中的Web管理界面存在权限许可和访问控制漏洞，该漏洞该源于程序没有对Help Desk及User Provisioning角色强制执行访问限制。远程攻击者可利用该漏洞修改高权限账户的重要属性，获取提升的权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20180606-prime-access

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-393

  

**【漏洞名称】****Android NVIDIA Tegra X1 TZ 安全漏洞**  

**【漏洞编号】******CNNVD-201806-380**（CVE-2017-6294）**

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。NVIDIA Tegra X1 TZ是其中的一个处理器组件。

Android 2018-06-05之前版本中的NVIDIA Tegra X1 TZ存在安全漏洞，该漏洞源于程序没有执行边界检测。攻击者可利用该漏洞提升权限（越界写入）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2018-06-01

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-380

  

**【漏洞名称】******IBM Robotic Process Automation with Automation Anywhere 安全漏洞****

**【漏洞编号】******CNNVD-201806-386**（CVE-2018-1547）**

**【漏洞详情】**IBM Robotic Process Automation with Automation Anywhere是美国IBM公司和Automation Anywhere共同开发的一套流程自动化解决方案。

IBM Robotic Process Automation with Automation Anywhere 10.0版本中存在安全漏洞，该漏洞该源于在导出CSV文件时程序没有正确的编码输出。远程攻击者可通过诱使用户下载CVS导出文件利用该漏洞在用户设备上运行任意命令或程序。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22016197

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-386

  

**【漏洞名称】******McAfee Common UI ePO扩展安全漏洞****

**【漏洞编号】******CNNVD-201806-383**（CVE-2018-6670）**

**【漏洞详情】**McAfee Common UI（CUI）是美国迈克菲（McAfee）公司的一套用于管理McAfee产品的用户界面。ePO extension是其中的一个软件管理器。

McAfee CUI 2.0.2版本中的ePO扩展存在安全漏洞。远程攻击者可借助特制的HTTP请求参数利用该漏洞查看敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://kc.mcafee.com/corporate/index?page=content&id=SB10236

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-383

  

**【漏洞名称】****Micro Focus openSUSE Open Build Service 安全漏洞**

**【漏洞编号】****CNNVD-201806-389（CVE-2018-7689）**

**【漏洞详情】**Micro Focus openSUSE Open Build Service是英国Micro Focus公司的一套软件分发系统。该系统能够以自动、一致和可重复的方式从源代码构建和分发软件包。

Micro Focus openSUSE Open Build Service 2.9.3之前版本中的‘InitializeDevelPackage’函数存在安全漏洞，该漏洞源于程序缺少权限检测。攻击者可利用该漏洞修改无权写入的文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lists.opensuse.org/opensuse-buildservice/2018-06/msg00014.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-389
