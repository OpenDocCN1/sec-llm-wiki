# CNNVD最新漏洞（2018-06-08）

今日CNNVD共发布安全漏洞15个，更新安全漏洞12个。主要影响厂商为美国IBM（3个）、美国OnSSI（1个）、美国ZOHO（1个）。主要影响产品为IBM Security Access Manager Appliance应用程序（3个）、OnSSI Ocularis视频管理系统（1个）、ZOHO ManageEngine Applications Manager解决方案（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****IBM Security Access Manager Appliance 安全漏洞**

**【漏洞编号】****CNNVD-201806-353（CVE-2017-1480）**

**【漏洞详情】**IBM Security Access Manager Appliance是美国IBM公司的一款应用于信息安全管理的应用程序。该程序通过面向Web、移动和云计算的集成设备来实现访问管理控制。

IBM Security Access Manager Appliance 8.0.0版本至8.0.1.6版本和9.0.0版本至9.0.3.1版本中存在安全漏洞，该漏洞源于程序可能会将敏感信息储存在日志文件中。远程攻击者可利用该漏洞读取这些信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22012309

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-353

  

**【漏洞名称】****OnSSI Ocularis 安全漏洞**  

**【漏洞编号】******CNNVD-201806-344**（CVE-2018-3852）**

**【漏洞详情】**OnSSI Ocularis是美国OnSSI公司的一套用于中小型单站和多站点应用的、可扩展的视频管理系统。

OnSSI Ocularis 5.5.0.242版本的Ocularis Recorder功能存在拒绝服务漏洞。攻击者可通过发送特制的TCP数据包利用该漏洞终止进程，造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://onssi.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-344

  

**【漏洞名称】******ZOHO ManageEngine Applications Manager 安全漏洞****

**【漏洞编号】******CNNVD-201806-357**（CVE-2018-11808）**

**【漏洞详情】**ZOHO ManageEngine Applications Manager是美国卓豪（ZOHO）公司的一套IT运维管理解决方案。该产品具有应用性能管理、故障管理、报表生成和SLA管理等功能。

ZOHO ManageEngine Applications Manager 13（13740 build）之前版本中的CustomFieldsFeedServlet存在安全漏洞，该漏洞源于程序没有正确控制访问权限。攻击者可通过向服务器发送特制的请求利用该漏洞删除服务器上的任意文件并读取文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.manageengine.com/products/applications\_manager/issues.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-357

  

**【漏洞名称】******Cloud Foundry Loggregator 安全漏洞****

**【漏洞编号】******CNNVD-201806-346**（CVE-2018-1269）**

**【漏洞详情】**Cloud Foundry Loggregator是美国Cloud Foundry基金会的一套使用在Cloud Foundry云计算平台中的日志记录系统。

Cloud Foundry Loggregator中存在安全漏洞，该漏洞源于程序没有正确关闭TCP连接。远程攻击者可通过构建恶意请求利用该漏洞造成拒绝服务。以下版本受到影响：Cloud Foundry Loggregator 89.5之前的89.x版本，96.1之前的96.x版本，99.1之前的99.x版本，101.9之前的101.x版本，102.2之前的102.x版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.cloudfoundry.org/blog/cve-2018-1269/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-346

  

**【漏洞名称】****ABB IP GATEWA  跨站请求伪造漏洞**

**【漏洞编号】****CNNVD-201806-350（CVE-2017-7906）**

**【漏洞详情】**ABB IP GATEWAY是瑞士ABB公司的一套楼宇管理系统。

ABB IP GATEWAY 3.39及之前版本存在跨站请求伪造漏洞，该漏洞源于web服务器没有充分验证用户所发的请求。远程攻击者可利用该漏洞冒充用户发送请求。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://new.abb.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-350
