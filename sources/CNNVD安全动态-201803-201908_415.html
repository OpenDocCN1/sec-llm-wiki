今日CNNVD共发布安全漏洞69个，更新安全漏洞1个。主要影响厂商为中国华为（3个）、美国Google（2个）、美国Red Hat（2个）。主要影响产品为Huawei 1288H V5服务器（3个）、Google Chrome浏览器（2个）、Red Hat oVirt虚拟化管理平台（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】多款Huawei产品Intelligent Baseboard Management Controller 安全漏洞

【漏洞编号】CNNVD-201806-138（CVE-2018-7951）

【漏洞详情】Huawei 1288H V5等都是中国华为（Huawei）公司的不同型号的服务器设备。Intelligent Baseboard Management Controller（iBMC）是其中的一套嵌入式服务器智能管理系统。

多款Huawei产品中的iBMC存在安全漏洞，该漏洞源于程序没有充分的校验输入。远程攻击者可通过向受影响设备发送特制的报文利用该漏洞修改管理员密码，获取系统管理权限。以下产品和版本受到影响：Huawei 1288H V5 V100R005C00版本；2288H V5 V100R005C00版本；2488 V5 V100R005C00版本；CH121 V3 V100R001C00版本；CH121L V3 V100R001C00版本；CH121L V5 V100R001C00版本；CH121 V5 V100R001C00版本；CH140 V3 V100R001C00版本；CH140L V3 V100R001C00版本；CH220 V3 V100R001C00版本；CH222 V3 V100R001C00版本；CH242 V3 V100R001C00版本；CH242 V5 V100R001C00版本；RH1288 V3 V100R003C00版本；RH2288 V3 V100R003C00版本；RH2288H V3 V100R003C00版本；XH310 V3 V100R003C00版本；XH321 V3 V100R003C00版本；XH321 V5 V100R005C00版本；XH620 V3 V100R003C00版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20180530-02-server-cn

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201806-138


【漏洞名称】Google Chrome Blink 安全漏洞

【漏洞编号】CNNVD-201805-1033（CVE-2018-6134）

【漏洞详情】Google Chrome是美国谷歌（Google）公司开发的一款Web浏览器。Blink是美国谷歌（Google）公司和挪威欧朋（Opera Software）公司共同开发的一套浏览器排版引擎（渲染引擎）。

Google Chrome 67.0.3396.62之前版本中的Blink存在安全漏洞。远程攻击者可借助特制的网站利用该漏洞绕过Referrer策略，获取系统的访问权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://chromereleases.googleblog.com/2018/05/stable-channel-update-for-desktop_58.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-1033


【漏洞名称】Red Hat oVirt Ansible Roles 信息泄露漏洞

【漏洞编号】CNNVD-201805-1141（CVE-2018-1117）

【漏洞详情】Red Hat oVirt是美国红帽（Red Hat）公司的一套开源的虚拟化管理平台，是RHEV（企业虚拟化平台）的开源版本，由ovirt-node客户端和overt-engine管理端组成。Ansible Roles是其中的一个用于自动配置和管理oVrit数据中心的组件。

Red Hat oVirt Ansible Roles 1.0.5之前版本中存在信息泄露漏洞。本地攻击者可利用该漏洞获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.ovirt.org/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-1141


【漏洞名称】Mozilla Firefox 安全漏洞

【漏洞编号】CNNVD-201805-1063（CVE-2018-5151）

【漏洞详情】Mozilla Firefox是美国Mozilla基金会开发的一款开源Web浏览器。

Mozilla Firefox 60之前版本中存在安全漏洞。远程攻击者可利用该漏洞造成内存损坏或执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.mozilla.org/en-US/security/advisories/mfsa2018-11/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-1063


【漏洞名称】Adobe Acrobat和Reader 信息泄露漏洞

【漏洞编号】CNNVD-201805-1120（CVE-2018-4965）

【漏洞详情】Adobe Acrobat和Reader都是美国奥多比（Adobe）公司的产品。前者是一套PDF文件编辑和转换工具，后者是一套PDF文档阅读软件。

Adobe Acrobat和Reader中存在信息泄露漏洞。远程攻击者可利用该漏洞获取敏感信息（内存损坏）。基于Windows和macOS平台的以下产品和版本受到影响：Acrobat DC 2018.011.20038及之前版本，Acrobat 2017 2017.011.30079及之前版本，Acrobat DC 2015.006.30417及之前版本；Acrobat Reader DC 2018.011.20038及之前版本，Acrobat Reader 2017 2017.011.30079及之前版本，Acrobat Reader DC 2015.006.30417及之前版本。 

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://helpx.adobe.com/security/products/acrobat/apsb18-09.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-1120
