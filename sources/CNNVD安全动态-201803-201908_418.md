今日CNNVD共发布安全漏洞36个。主要影响厂商为中国普联（2个）、美国Amazon（1个）、美国Unisys（1个）。主要影响产品为TP-LINK IPC TL-IPC223(P)-6网络摄像机（2个）、Amazon Echo智能音箱（1个）、Unisys Stealth Solution解决方案（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****多款TP-LINK产品访问控制错误漏洞**

**【漏洞编号】****CNNVD-201805-996（CVE-2018-11482）**

**【漏洞详情】**TP-LINK IPC TL-IPC223(P)-6等都是中国普联（TP-LINK）公司的不同型号的网络摄像机产品。

多款TP-LINK产品中的/usr/lib/lua/luci/websys.lua文件存在访问控制错误漏洞，该漏洞源于程序使用了硬编码密码：zMiVw8Kw0oxKXL0。攻击者可利用该漏洞提升权限并泄露信息。以下产品受到影响：TP-LINK IPC TL-IPC223(P)-6；TL-IPC323K-D；TL-IPC325(KP)-\*；TL-IPC40A-4。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

http://www.tp-link.com.cn/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-996

  

**【漏洞名称】****Amazon Echo 安全漏洞**  

**【漏洞编号】******CNNVD-201805-993**（CVE-2018-11567）**

**【漏洞详情】**Amazon Echo是美国亚马逊（Amazon）公司的一款智能音箱设备。

Amazon Echo 2018-04-27之前版本中的reprompt功能存在安全漏洞。攻击者可利用该漏洞获取录制的用户语音。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.amazon.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-993

  

**【漏洞名称】******Unisys Stealth Solution Stealth Authorization Server 安全漏洞****

**【漏洞编号】******CNNVD-201805-994**（CVE-2018-7534）**

**【漏洞详情】**Unisys Stealth Solution是美国Unisys公司的一套基于软件的用于防止网络威胁和保护资产的解决方案。Stealth Authorization Server是其中的一个身份认证服务器。

Unisys Stealth Solution中的Stealth Authorization Server 3.3.017.0之前版本中存在安全漏洞，该漏洞源于存储有AES密钥的内存没有被加密并且使用垃圾回收机制对其进行清理。攻击者可利用该漏洞获取密钥的访问权限并实施中间人攻击或与Stealth端点进行通信。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://public.support.unisys.com/common/public/vulnerability/NVD\_Detail\_Rpt.aspx?ID=47

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-994

  

**【漏洞名称】******Zimbra Collaboration Suite 跨站请求伪造漏洞****

**【漏洞编号】******CNNVD-201805-1003**（CVE-2015-7610）**

**【漏洞详情】**Zimbra Collaboration Suite（又名ZCS）是美国Zimbra公司的一款开源协同办公套件，它包括WebMail、日历、通信录等。

Zimbra ZCS 8.6.0 Patch 10之前版本、8.7.11 Patch 2之前的8.7.x版本和8.8.8 Patch 1之前的8.8.x版本中的登录表单存在跨站请求伪造漏洞，该漏洞源于程序没有使用跨站请求伪造令牌。远程攻击者可利用该漏洞执行未授权的操作，并获取受影响应用程序的访问权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wiki.zimbra.com/wiki/Zimbra\_Security\_Advisories

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-1003

  

**【漏洞名称】****SchedMD Slurm 安全漏洞**

**【漏洞编号】****CNNVD-201805-1006（CVE-2018-10995）**

**【漏洞详情】**SchedMD Slurm是美国SchedMD公司的一套用于大型和小型Linux群集中的开源的和高度可扩展的集群管理和作业调度系统。

SchedMD Slurm 17.02.11之前版本和17.11.7之前的17.1x.x版本中存在安全漏洞，该漏洞该源于程序没有正确的处理user\_name字段和gid字段。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.schedmd.com/news.php?id=203

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-1006
