CNNVD最新漏洞（2018-05-31）

今日CNNVD共发布安全漏洞67个，更新安全漏洞13个。主要影响厂商为美国IBM（6个）、中国五指（2个）、韩国Samsung（1个）。主要影响产品为IBM Security Guardium Big Data Intelligence（SonarG）安全智能解决方案（5个）、WUZHI CMS开源内容管理系统（1个）、Samsung S7 Edge智能手机（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】IBM Security Guardium Big Data Intelligence（SonarG）跨站脚本漏洞

【漏洞编号】CNNVD-201805-973（CVE-2018-1376）

【漏洞详情】IBM Security Guardium Big Data Intelligence（SonarG）是美国IBM公司的一套大数据安全智能解决方案。该方案具有交互式数据探索、自动连接分析和用户活动分析等特点。

IBM Security Guardium Big Data Intelligence（SonarG）3.1版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞向Web UI中注入任意的JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22016512

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-973


【漏洞名称】WUZHI CMS 跨站脚本漏洞

【漏洞编号】CNNVD-201805-919（CVE-2018-11549）

【漏洞详情】WUZHI CMS是中国五指（WUZHI）互联科技公司的一套基于PHP和MySQL的开源内容管理系统（CMS）。

WUZHI CMS 4.1.0版本中的‘账号管理->会员中心->中文信息->普通会员’存在跨站脚本漏洞。远程攻击者可借助QQ号利用该漏洞注入任意的Web脚本或HTML。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.wuzhicms.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-919


【漏洞名称】Samsung S7 Edge 数字错误漏洞

【漏洞编号】CNNVD-201805-932（CVE-2018-10751）

【漏洞详情】Samsung S7 Edge是韩国三星（Samsung）公司的一款智能手机产品。

Samsung S7 Edge中对字符串的内存分配存在整数溢出漏洞。攻击者可借助畸形的OMACP WAP推送消息利用该漏洞造成内存损坏。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://security.samsungmobile.com/securityUpdate.smsb

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-932


【漏洞名称】MyBB ChangUonDyU Advanced Statistics插件跨站脚本漏洞

【漏洞编号】CNNVD-201805-980（CVE-2018-11532）

【漏洞详情】MyBB（又名MyBulletinBoard）是MyBB团队开发的一套用PHP和MySQL开发的免费且基于Web的论坛软件。ChangUonDyU Advanced Statistics plugin是使用在其中的一个论坛插件。

MyBB ChangUonDyU Advanced Statistics插件1.0.2版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/vintagedaddyo/MyBB_Plugin-ChangUonDyU-Advanced-Statistics/commit/8122c93f4c3b517b9d35338fe77ba91d9a6ac08a

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-980


【漏洞名称】md4c 缓冲区错误漏洞

【漏洞编号】CNNVD-201805-921（CVE-2018-11547）

【漏洞详情】md4c是一款基于C语言的Markdown（一种标记语言）解析器。

md4c 0.2.5版本中的‘md_is_link_reference_definition_helper’函数存在堆缓冲区溢出漏洞，该漏洞源于程序没有正确的处理循环的终止。攻击者可利用该漏洞造成基于堆的缓冲区越界读取。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/mity/md4c/issues/37

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-921
