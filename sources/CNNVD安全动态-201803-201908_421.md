# CNNVD最新漏洞（2018-05-30）

今日CNNVD共发布安全漏洞11个。主要影响厂商为印度PHP Scripts Mall（1个）、捷克mySCADA Technologies（1个）。主要影响产品为PHP Scripts Mall Naukri Clone Script系统脚本（1个）、mySCADA myPRO控制系统（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****PHP Scripts Mall Naukri Clone Script 安全漏洞**

**【漏洞编号】****CNNVD-201805-914（CVE-2018-11514）**

**【漏洞详情】**PHP Scripts Mall Naukri Clone Script是印度PHP Scripts Mall公司的一套基于PHP和MySQL平台的在线招聘系统脚本。

PHP Scripts Mall Naukri Clone Script 3.0.3及之前版本中的edit\_resume\_det.php文件存在安全漏洞。攻击者可利用该漏洞上传任意带有危险扩展名的文件。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.phpscriptsmall.com/product/naukri-clone-script/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-914

  

**【漏洞名称】****mySCADA myPRO 安全漏洞**  

**【漏洞编号】******CNNVD-201805-909**（CVE-2018-11517）**

**【漏洞详情】**mySCADA myPRO是捷克共和国mySCADA Technologies公司的一套工业可视化控制系统。

mySCADA myPRO 7版本中存在安全漏洞。远程攻击者可通过将从870000到875000的所有的‘prj’参数值通过t=0&rq=0请求发送到TCP 11010端口利用该漏洞泄露项目中的全部ProjectID。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

http://www.myscada.org

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-909

  

**【漏洞名称】******Linux kernel 安全漏洞****

**【漏洞编号】******CNNVD-201805-918**（CVE-2018-11506）**

**【漏洞详情】**Linux kernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。

Linux kernel 4.16.12及之前版本中的drivers/scsi/sr\_ioctl.c文件的‘sr\_do\_ioctl’函数存在安全漏洞。本地攻击者可利用该漏洞造成拒绝服务（基于堆的缓冲区溢出）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=f7068114d45ec55996b9040e98111afa56e010fe

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-918

  

**【漏洞名称】******WordPress MemberMouse SQL注入漏洞****

**【漏洞编号】******CNNVD-201805-912**（CVE-2018-11309）**

**【漏洞详情】**WordPress是WordPress软件基金会的一套使用PHP语言开发的博客平台，该平台支持在PHP和MySQL的服务器上架设个人博客网站。MemberMouse plugin是使用在其中的一个销售管理插件。

WordPress MemberMouse插件2.2.8及之前版本中的‘coupon\_code’参数存在SQL注入漏洞。远程攻击者可利用该漏洞转储WordPress MySQL数据库。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://membermouse.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-912

  

**【漏洞名称】****Creatiwity wityCMS 跨站脚本漏洞**

**【漏洞编号】****CNNVD-201805-915（CVE-2018-11512）**

**【漏洞详情】**Creatiwity wityCMS是一套基于PHP的面向模型-视图-控制器的轻量级内容管理系统（CMS）。

Creatiwity wityCMS 0.6.1版本中的‘General’菜单下的‘Settings’页面的‘Website's name’字段存在跨站脚本漏洞。远程攻击者可借助特制的网站名利用该漏洞注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/Creatiwity/wityCMS/commit/7967e5bf15b4d2ee6b85b56e82d7e1229147de44

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-915
