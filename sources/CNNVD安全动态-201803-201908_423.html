今日CNNVD共发布安全漏洞51个,更新安全漏洞4个。主要影响厂商为中国福昕（9个）、美国Artifex Software（5个）、中国华为（4个）。主要影响产品为Foxit Reader文档阅读器（9个）、Artifex MuPDF PDF阅读器（5个）、Huawei 1288H V5服务器设备（4个）。

今日需关注的典型漏洞如下:

【漏洞名称】Foxit Reader和PhantomPDF 安全漏洞

【漏洞编号】CNNVD-201805-795（CVE-2018-7407）

【漏洞详情】Foxit Reader是中国福昕（Foxit）软件公司的一款PDF文档阅读器。Foxit PhantomPDF是一个商业版。

Foxit Reader 9.1之前版本和PhantomPDF 9.1之前版本中存在类型混淆漏洞，该漏洞源于程序没有正确的验证用户提交的数据。远程攻击者可借助恶意的页面或文件利用该漏洞在当前进程的上下文中执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.foxitsoftware.com/support/security-bulletins.php

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-795


【漏洞名称】Artifex MuPDF 安全漏洞

【漏洞编号】CNNVD-201805-832（CVE-2018-1000040）

【漏洞详情】Artifex MuPDF是美国Artifex Software公司的一款免费的、轻量级的PDF阅读器。

Artifex MuPDF 1.12.0及之前版本中存在安全漏洞。攻击者可借助特制的文件利用该漏洞造成拒绝服务（崩溃）或影响程序流。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://mupdf.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-832


【漏洞名称】多款Huawei产品Intelligent Baseboard Management 安全漏洞

【漏洞编号】CNNVD-201805-820（CVE-2018-7942）

【漏洞详情】Huawei 1288H V5等都是中国华为（Huawei）公司的不同型号的服务器设备。Intelligent Baseboard Management Controller（iBMC）是其中的一套嵌入式服务器智能管理系统。

多款Huawei产品中的iBMC模块存在身份验证绕过漏洞，该漏洞源于程序含有身份验证逻辑错误。远程攻击者可通过向受影响产品发送特制的消息利用该漏洞泄露信息。以下产品和版本受到影响：1288H V5 V100R005C00版本；2288H V5 V100R005C00版本；2488 V5 V100R005C00版本；CH121 V3 V100R001C00版本；CH121L V3 V100R001C00版本；CH121L V5 V100R001C00版本；CH121 V5 V100R001C00版本；CH140 V3 V100R001C00版本；CH140L V3 V100R001C00版本；CH220 V3 V100R001C00版本；CH222 V3 V100R001C00版本；CH242 V3 V100R001C00版本；CH242 V5 V100R001C00版本；RH1288 V3 V100R003C00版本；RH2288 V3 V100R003C00版本；RH2288H V3 V100R003C00版本；XH310 V3 V100R003C00版本；XH321 V3 V100R003C00版本；XH321 V5 V100R005C00版本；XH620 V3 V100R003C00版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20180523-01-server-cn

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-820


【漏洞名称】IBM WebSphere Application Server for UNIX 安全漏洞

【漏洞编号】CNNVD-201805-804（CVE-2013-3024）

【漏洞详情】IBM WebSphere Application Server（WAS）for UNIX是美国IBM公司开发并发行的一款基于UNIX平台的应用服务器产品，它是Java EE和Web服务应用程序的平台，也是IBM WebSphere软件平台的基础。

基于UNIX平台的IBM WAS中存在安全漏洞，该漏洞源于程序没有正确为UNIX平台初始化进程。本地攻击者可通过发送特制的SOAP消息利用该漏洞执行任意命令。以下版本受到影响：IBM WebSphere Application Server 8.5版本，8版本，7版本，6版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?&amp;uid=swg21639553

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-804


【漏洞名称】NetApp OnCommand Unified Manager for Linux 安全漏洞

【漏洞编号】CNNVD-201805-824（CVE-2018-5487）

【漏洞详情】NetApp OnCommand Unified Manager for Linux是美国NetApp公司的一套基于Linux系统的ONTAP系统管理软件。该软件能够简化数据管理、监控存储系统基础架构并检测故障等。

基于Linux平台的NetApp OnCommand Unified Manager 7.2版本至7.3版本中存在安全漏洞。远程攻击者可利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://security.netapp.com/advisory/ntap-20180523-0001/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-824
