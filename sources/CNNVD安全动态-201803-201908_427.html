今日CNNVD共发布安全漏洞12个，更新安全漏洞1个。主要影响厂商为美国Microsoft（1个）、美国Red Hat（1个）、英国Micro Focus（1个）。主要影响产品为Microsoft Windows操作系统（1个）、Red Hat Undertow嵌入式Web服务器（1个）、Micro Focus Client for OES客户端软件（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Microsoft Windows 安全漏洞

【漏洞编号】CNNVD-201805-701（CVE-2018-8142）

【漏洞详情】Microsoft Windows 10、Windows Server 2016和Windows Server Version 1709都是美国微软（Microsoft）公司的产品。Microsoft Windows 10是一套跨平台操作系统，它适用于PC和笔记本电脑、平板电脑以及手机等设备。Windows Server 2016和Windows Server Version 1709都是服务器操作系统。

Microsoft Windows中存在安全功能绕过漏洞，该漏洞该源于程序没有正确的验证内核驱动器签名。攻击者可利用该漏洞绕过安全功能并向内核加载不正确签名的驱动程序。以下产品受到影响：Microsoft Windows Server 2016；Windows 10版本1607，Windows 10版本1703，Windows 10版本1709，Windows Server版本1709。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2018-8142

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-701


【漏洞名称】Red Hat Undertow 安全漏洞

【漏洞编号】CNNVD-201805-696（CVE-2018-1067）

【漏洞详情】Red Hat Undertow是美国红帽（Red Hat）公司的一款基于Java的嵌入式Web服务器，是Wildfly（Java应用服务器）默认的Web服务器。

Red Hat Undertow 7.1.2.CR1之前版本和7.1.2.GA之前版本中存在安全漏洞，该漏洞源于程序将用户输入用作HTTP包头值之前，没有充分的过滤和验证该输入。攻击者可利用该漏洞注入任意的PHP包头，造成响应拆分。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bugzilla.redhat.com/show_bug.cgi?id=CVE-2018-1067

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-696


【漏洞名称】Micro Focus Client for OES 缓冲区错误漏洞

【漏洞编号】CNNVD-201805-693（CVE-2018-7687）

【漏洞详情】Micro Focus Client for OES是英国Micro Focus公司的一套服务器客户端软件。该软件支持对Windows Server等平台中的文件进行传输或授权。

Micro Focus Client for OES 2 SP4 IR8a之前版本中的ncfsd.sys文件存在缓冲区溢出漏洞。本地攻击者可利用该漏洞提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.novell.com/support/kb/doc.php?id=7022983

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-693


【漏洞名称】MagniComp SysInfo 信息泄露漏洞

【漏洞编号】CNNVD-201805-697（CVE-2018-7268）

【漏洞详情】MagniComp SysInfo是美国MagniComp公司的一款支持多种平台的系统代理和查看器。该产品通过XML和HTML等形式提供详细的系统、软件和硬件清单，以及操作系统配置和存储资产管理配置信息等。

MagniComp SysInfo 10-H81之前版本（捆绑在BMC BladeLogic Automation和其他产品上）存在信息泄露漏洞。本地攻击者可利用该漏洞读取root账户（uid 0）拥有的任意文件或泄露敏感信息（密码散列、日志文件或密钥）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.magnicomp.com/sysinfo/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-697


【漏洞名称】Octopus Deploy 安全漏洞

【漏洞编号】CNNVD-201805-698（CVE-2018-11320）

【漏洞详情】Octopus Deploy是澳大利亚Octopus Deploy公司的一款用于.NET的开发部署的自动化工具。

Octopus Deploy 2018.4.4版本至2018.5.1版本中存在安全漏洞，该漏洞源于在部署日志中程序没有对敏感的Octopus变量进行模糊处理。攻击者可利用该漏洞获取敏感信息。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://octopus.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-698
