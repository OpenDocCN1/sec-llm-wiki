今日CNNVD共发布安全漏洞49个，更新安全漏洞24个。主要影响厂商为美国Adobe（15个）、美国ImageMagick Studio（4个）、美国Tenable Network Security（2个）。主要影响产品为Adobe ColdFusion动态Web服务器（5个）、ImageMagick图像处理软件（4个）、Tenable Network Security Nessus开源漏洞扫描器（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Adobe ColdFusion 安全漏洞**

**【漏洞编号】****CNNVD-201805-644（CVE-2018-4942）**

**【漏洞详情】**Adobe ColdFusion是美国奥多比（Adobe）公司的一款动态Web服务器产品，其运行的CFML（ColdFusion Markup Language）是针对Web应用的一种程序设计语言。

Adobe ColdFusion（2016年发布）Update 5及之前版本和ColdFusion 11 Update 13及之前版本中存在安全漏洞，该漏洞源于程序没有安全的处理XML外部实体。攻击者可利用该漏洞获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://helpx.adobe.com/security/products/coldfusion/apsb18-14.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-644

  

**【漏洞名称】****ImageMagick 缓冲区错误漏洞**  

**【漏洞编号】******CNNVD-201805-662**（CVE-2018-11251）**

**【漏洞详情】**ImageMagick是美国ImageMagick Studio公司的一套开源的图像处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.7-23 Q16 x86\_64 2018-01-24版本中的coders/sun.c文件的ReadSUNImage存在基于堆的缓冲区越界读取漏洞。攻击者可借助特制的SUN图像文件利用该漏洞造成拒绝服务（应用程序崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/issues/956

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-662

  

**【漏洞名称】******Tenable Network Security Nessus 安全漏洞****

**【漏洞编号】******CNNVD-201805-655**（CVE-2018-1148）**

**【漏洞详情】**Tenable Network Security Nessus是美国Tenable Network Security公司的一款具有较强可扩展性的开源漏洞扫描器。

Tenable Network Security Nessus 7.1.0之前版本中存在会话固定漏洞。攻击者可利用该漏洞在用户更改密码之后仍然拥有系统访问权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.tenable.com/security/tns-2018-05

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-655

  

**【漏洞名称】******D-Link DIR-550A和DIR-604M 安全漏洞****

**【漏洞编号】******CNNVD-201805-678**（CVE-2018-10968）**

**【漏洞详情】**D-Link DIR-550A和DIR-604M都是友讯（D-Link）公司的无线路由器产品。

D-Link DIR-550A和DIR-604M 2.10KR及之前版本中存在安全漏洞。攻击者可通过使用默认的TELNET账户利用该漏洞获取访问权限。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

http://www.dlink.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-678

  

**【漏洞名称】****Apache ORC 安全漏洞**

**【漏洞编号】****CNNVD-201805-669（CVE-2018-8015）**

**【漏洞详情】**Apache ORC是美国阿帕奇（Apache）软件基金会的一套列式存储系统，它支持数据压缩、ACID操作和索引功能等。

Apache ORC 1.0.0版本至1.4.3版本中存在安全漏洞。攻击者可借助畸形的ORC文件利用该漏洞造成使用ORC文件解析器的软件停止服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://orc.apache.org/security/CVE-2018-8015/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-669
