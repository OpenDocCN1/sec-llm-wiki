今日CNNVD共发布安全漏洞29个，更新安全漏洞8个。主要影响厂商为美国Intel（3个）、美国Pivotal Software（1个）、美国Linux（1个）。主要影响产品为Intel system Configuration utilities selview.exe系统配置实用程序（1个）、Pivotal Spring-integration-zip压缩/解压缩组件（1个）、Linux kernel内核（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Intel system Configuration utilities selview.exe和syscfg.exe 缓冲区错误漏洞**

**【漏洞编号】****CNNVD-201805-461（CVE-2018-3661）**

**【漏洞详情】**Intel system Configuration utilities selview.exe和syscfg.exe都是美国英特尔（Intel）公司的系统配置实用程序。

Intel system Configuration utilities selview.exe和syscfg.exe 14 build 11之前版本中存在缓冲区溢出漏洞。本地攻击者可利用该漏洞造成拒绝服务（崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.intel.com/content/www/us/en/security-center/advisory/intel-sa-00134.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-461

  

**【漏洞名称】****Pivotal Spring-integration-zip 安全漏洞**  

**【漏洞编号】******CNNVD-201805-452**（CVE-2018-1263）**

**【漏洞详情】**Pivotal Spring-integration-zip是美国Pivotal Software公司的一款使用在Spring中的压缩/解压缩组件。

Pivotal Spring-integration-zip 1.0.2之前版本中存在安全漏洞。攻击者可借助特制的zip（还包括：bzip2、tar、xz、war、cpio或7z）归档文件利用该漏洞写入任意文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://pivotal.io/security/cve-2018-1263

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-452

  

**【漏洞名称】******Linux kernel KVM 安全漏洞****

**【漏洞编号】******CNNVD-201805-459**（CVE-2018-1087）**

**【漏洞详情】**Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。KVM（Kernel-based Virtual Machine，基于内核的虚拟机）是用于其中的一种虚拟化基础设施。

Linux kernel中的KVM的虚拟机监视器处理异常的情况存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（崩溃）或提升权限。以下版本受到影响：Kernel 4.16版本，4.16-rc7版本，4.17-rc1版本，4.17-rc2版本，4.17-rc3版本。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.linux-kvm.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-459

  

**【漏洞名称】******多款Advantech产品缓冲区错误漏洞****

**【漏洞编号】******CNNVD-201805-441**（CVE-2018-8845）**

**【漏洞详情】**Advantech WebAccess等都是研华（Advantech）公司的产品。Advantech WebAccess是一套基于浏览器架构的HMI/SCADA软件。该软件支持动态图形显示和实时数据控制，并提供远程控制和管理自动化设备的功能。WebAccess Dashboard是其中的一个仪表板组件；WebAccess Scada Node是其中的一个监控节点组件。WebAccess/NMS是一套用于网络管理系统（NMS）的网络浏览器基础套件。

多款Advantech产品中存在基于堆的缓冲区溢出漏洞。攻击者可利用该漏洞执行任意代码。以下版本受到影响：Advantech WebAccess 8.2\_20170817及之前版本，8.3.0及之前版本；WebAccess Dashboard 2.0.15及之前版本；WebAccess Scada Node 8.3.1之前版本；WebAccess/NMS 2.0.3及之前版本。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.advantech.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-441

  

**【漏洞名称】****WordPress wp-live-chat-support插件跨站脚本漏洞**

**【漏洞编号】****CNNVD-201805-460（CVE-2018-11105）**

**【漏洞详情】**WordPress是WordPress软件基金会的一套使用PHP语言开发的博客平台，该平台支持在PHP和MySQL的服务器上架设个人博客网站。wp-live-chat-support plugin是使用在其中的一个即时聊天插件。

WordPress wp-live-chat-support插件8.0.08之前版本中存在跨站脚本漏洞。远程攻击者可通过向wp-json/wp\_live\_chat\_support/v1/start\_chat发送name和email输入字段利用该漏洞注入恶意的JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/wp-live-chat-support/#developers

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-460
