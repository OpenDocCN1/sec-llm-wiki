# CNNVD最新漏洞（2018-05-15）

今日CNNVD共发布安全漏洞37个，更新安全漏洞2个。主要影响厂商为美国Pivotal Software（7个）、美国Impinj（2个）。主要影响产品为Pivotal Greenplum Command Center大数据平台管理工具（7个）、Impinj Speedway Connect R420 RFID Reader识别器（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Pivotal Greenplum Command Center SQL注入漏洞**

**【漏洞编号】****CNNVD-201805-399（CVE-2018-1280）**

**【漏洞详情】**Pivotal Greenplum Command Center是是美国Pivotal Software公司的一款使用在Pivotal Greenplum中的大数据平台管理工具。

Pivotal Greenplum Command Center 2.5.1之前的2.x版本中存在SQL注入漏洞。远程攻击者可利用该漏洞注入SQL语句，获取数据库内容。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://pivotal.io/security/cve-2018-1280

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-399

  

**【漏洞名称】****Impinj Speedway Connect R420 RFID Reader 安全漏洞**  

**【漏洞编号】******CNNVD-201805-396**（CVE-2018-5304）**

**【漏洞详情】**Impinj Speedway Connect R420 RFID Reader是美国Impinj公司的一款用来识别和跟踪物体的识别器。

Impinj Speedway Connect R420 RFID Reader 2.2.2之前版本中的Web界面存在安全漏洞。攻击者可利用该漏洞将用户重定向到第三方应用程序或执行其他恶意操作。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.impinj.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-396

  

**【漏洞名称】******Xpdf DCT解码器安全漏洞****

**【漏洞编号】******CNNVD-201805-374**（CVE-2018-11033）**

**【漏洞详情】**Xpdf是Foo实验室开发的一款开源的PDF阅读器，它支持解码LZW压缩格式的文件以及阅读加密的PDF文件。DCT decoder是其中的一个DCT解码器。

Xpdf 4.00之前版本中的DCT解码器的Stream.cc文件‘DCTStream::readHuffSym’函数存在安全漏洞。远程攻击者可借助特制的JPEG数据利用该漏洞造成拒绝服务（应用程序崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://forum.xpdfreader.com/viewtopic.php?f=3&t=40842

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-374

  

**【漏洞名称】******Easy Hosting Control Panel 安全漏洞****

**【漏洞编号】******CNNVD-201805-390**（CVE-2018-6618）**

**【漏洞详情】**Easy Hosting Control Panel（EHCP）是一款开源的主机管理面板，它用于管理域名、电子邮件和ftp用户等。

EHCP 0.37.12.b版本中存在安全漏洞，该漏洞源于程序将密码储存为明文形式。攻击者可利用该漏洞获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.ehcp.net/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-390

  

**【漏洞名称】****LilyPond lilypond-invoke-editor 安全漏洞**

**【漏洞编号】****CNNVD-201805-388（CVE-2018-10992）**

**【漏洞详情】**LilyPond是一套开源的音频编辑软件。lilypond-invoke-editor是其中的一个用于调用编辑器的工具。

LilyPond 2.19.80版本中的lilypond-invoke-editor存在安全漏洞，该漏洞源于程序在启动由BROWSER环境变量指定的程序之前，没有验证字符串。远程攻击者可借助特制的URL利用该漏洞实施参数注入攻击。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://lilypond.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-388
