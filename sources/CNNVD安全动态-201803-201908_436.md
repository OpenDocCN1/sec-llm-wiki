今日CNNVD共发布安全漏洞49个，更新安全漏洞1个。主要影响厂商为美国Google（4个）、中国华为（3个）、美国Intel（3个）。主要影响产品为Android开源操作系统（4个）、Huawei iBMC智能管理系统（1个）、Intel NUC kits迷你型台式机（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Android NVIDIA Media Server 信息泄露漏洞**

**【漏洞编号】****CNNVD-201805-345（CVE-2018-6254）**

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。NVIDIA Media Server是使用在其中的一个多媒体服务器组件。

Android 2018-05-05 security patch level之前版本中的NVIDIA Media Server中存在信息泄露漏洞，该漏洞源于程序没有正确的执行输入验证。本地攻击者可利用该漏洞获取信息（越边界读取）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/pixel/2018-05-01

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-345

  

**【漏洞名称】****Huawei iBMC 安全漏洞**  

**【漏洞编号】******CNNVD-201805-342**（CVE-2018-7941）**

**【漏洞详情】**Huawei iBMC是中国华为（Huawei）公司开发的一套服务器嵌入式智能管理系统。该系统具有远程运维、故障诊断、智能化管理和标准化接口管理等功能。

Huawei iBMC V200R002C60版本中存在身份验证绕过漏洞，该漏洞源于程序没有正确的校验上传权限。攻击者可通过构造特制的消息向受影响的产品上传认证凭证利用该漏洞提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20180509-01-bypass-cn

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-342

  

**【漏洞名称】******Intel NUC kits系统固件安全漏洞****

**【漏洞编号】******CNNVD-201805-328**（CVE-2018-3612）**

**【漏洞详情】**Intel NUC kits是美国英特尔（Intel）公司的一款迷你型台式机。

Intel NUC kits中的系统固件存在安全漏洞，该漏洞源于程序没有充分的执行输入验证。本地攻击者可利用该漏洞提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.intel.com/content/www/us/en/security-center/advisory/intel-sa-00110.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-328

  

**【漏洞名称】******Synology Media Server SQL注入漏洞****

**【漏洞编号】******CNNVD-201805-353**（CVE-2018-8914）**

**【漏洞详情】**Synology Media Server是群晖科技（Synology）公司的一套媒体服务器软件。

Synology Media Server 1.7.6-2842之前版本和1.4-2654之前版本中存在SQL注入漏洞。远程攻击者可借助‘ObjectID’参数利用该漏洞执行任意的SQL命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.synology.cn/en-global/support/security/Synology\_SA\_18\_04

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-353

  

**【漏洞名称】****Zimbra Collaboration Suite mailboxd 安全漏洞**

**【漏洞编号】****CNNVD-201805-371（CVE-2018-10951）**

**【漏洞详情】**Zimbra Collaboration Suite（ZCS）是美国Zimbra公司的一款开源协同办公套件，它包括WebMail、日历、通信录等。mailboxd是其中的一个电子邮件组件。

ZCS 8.8.8之前的8.8版本、8.7.11.Patch3之前的8.7版本和8.6.0.Patch10之前的8.6版本中的mailboxd存在安全漏洞。攻击者可借助Admin SOAP API中的GetServer、GetAllServers或GetAllActiveServers调用利用该漏洞读取zimbraSSLPrivateKey。

目前厂商已发布升级补丁以修复漏洞，补丁获取链：

https://wiki.zimbra.com/wiki/Zimbra\_Security\_Advisories

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-371
