今日CNNVD共发布安全漏洞28个，更新安全漏洞6个。主要影响厂商为美国CloudBees（5个）、美国Dell（3个）、美国Brave Software（2个）。主要影响产品为CloudBees Jenkins集成工具（5个）、Dell EMC RSA Authentication Manager身份认证软件（2个）、Brave Web浏览器（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】CloudBees Jenkins S3 Plugin 跨站脚本漏洞

【漏洞编号】CNNVD-201805-213（CVE-2018-1000177）

【漏洞详情】CloudBees Jenkins（前称Hudson Labs）是美国CloudBees公司的一套基于Java开发的持续集成工具，它主要用于监控持续的软件版本发布/测试项目和一些定时执行的任务。S3 Plugin是使用在其中的一个用于将文件等上传到Amazon S3（云存储）中的插件。

CloudBees Jenkins S3 Plugin 0.10.12及之前的版本中的src/main/resources/hudson/plugins/s3/S3ArtifactsProjectAction/jobMain.jelly文件存在跨站脚本漏洞，该漏洞源于程序没有正确的转义展示在Jenkins UI上的文件名。当用户进行用户界面操作时，远程攻击者可通过控制上传文件的名称利用该漏洞在用户浏览器中执行JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://jenkins.io/security/advisory/2018-04-16/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-213


【漏洞名称】Dell EMC RSA Authentication Manager Security Console、Operation Console和Self-Service Console 安全漏洞

【漏洞编号】CNNVD-201805-219（CVE-2018-1248）

【漏洞详情】Dell EMC RSA Authentication Manager是美国戴尔（Dell）公司的一套集中式二元身份认证软件。该软件可跨物理站点集中管理二元身份认证、安全令牌、方法和用户等。RSA Authentication Manager Security Console是其中的一个安全控制台程序；Operation Console是其中的一个操作控制台程序；Self-Service Console是其中的一个自助服务控制台程序。

Dell EMC RSA Authentication Manager 8.3及之前版本中的Security Console、Operation Console和Self-Service Console存在安全漏洞。远程攻击者可利用该漏洞造成HTTP缓存中毒，进而将用户重定向到任意的Web域。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.dellemc.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-219


【漏洞名称】Brave 安全漏洞

【漏洞编号】CNNVD-201805-229（CVE-2018-10799）

【漏洞详情】Brave是美国Brave Software公司的一款Web浏览器产品。

基于Linux或其他平台的Brave 0.14.0之前版本中存在安全漏洞，该漏洞源于没有正确的处理较长的URL。攻击者可通过发送特制的请求利用该漏洞造成拒绝服务（应用程序挂起）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://brave.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-229


【漏洞名称】IceWarp Mail Server 路径遍历漏洞

【漏洞编号】CNNVD-201805-204（CVE-2015-1503）

【漏洞详情】IceWarp Mail Server是美国爱思华宝（IceWarp）公司的一款邮件服务器产品。该产品支持电子邮件归档、SmartAttach附件、自动迁移等。

IceWarp Mail Server 11.2之前版本中存在目录遍历漏洞。远程攻击者可通过向webmail/client/skins/default/css/css.php页面发送带有‘..’序列的‘file’参数或向webmail/old/calendar/minimizer/index.php文件发送带有‘.../.’序列的‘script’或‘style’参数利用该漏洞读取任意文件。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.icewarp.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-204


【漏洞名称】ImageMagick 安全漏洞

【漏洞编号】CNNVD-201805-225（CVE-2018-10805）

【漏洞详情】ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.7-28版本中的coders/ycbcr.c文件的ReadYCBCRImage存在内存泄露漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/issues/1054

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-225
