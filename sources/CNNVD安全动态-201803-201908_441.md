今日CNNVD共发布安全漏洞14个。主要影响厂商为美国IBM（1个）、美国Pivotal Software（1个）、美国Apache（1个）。主要影响产品为IBM Cognos Analytics商业智能软件（1个）、Pivotal Spring Cloud SSO Connector单点登录连接器（1个）、Apache Derby数据库管理系统（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****IBM Cognos Analytics 跨站脚本漏洞**

**【漏洞编号】****CNNVD-201805-191（CVE-2018-1413）**

**【漏洞详情】**IBM Cognos Analytics（前称Cognos BI）是美国IBM公司的一套商业智能软件。该软件包括报表、仪表板和记分卡等，并可通过分析关键因素与关键干系人等内容，协助企业调整决策。

IBM Cognos Analytics 11.0.0.0版本至11.0.10.0版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞向Web UI中注入任意的JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22016039

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-191

  

**【漏洞名称】****Pivotal Spring Cloud SSO Connector 安全漏洞**  

**【漏洞编号】******CNNVD-201805-190**（CVE-2018-1256）**

**【漏洞详情】**Pivotal Spring Cloud SSO Connector是美国Pivotal Software公司的一款用于Cloud Foundry的一款单点登录连接器。

Pivotal Spring Cloud SSO Connector 2.1.2版本中存在安全漏洞。攻击者可利用该漏洞对未绑定的资源服务器进行身份验证。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://pivotal.io/security/cve-2018-1256

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-190

  

**【漏洞名称】******Apache Derby 安全漏洞****

**【漏洞编号】******CNNVD-201805-192**（CVE-2018-1313）**

**【漏洞详情】**Apache Derby是美国阿帕奇（Apache）软件基金会开发的一套开源的数据库管理系统。

Apache Derby 10.3.1.4版本至10.14.1.0版本中存在安全漏洞,该漏洞源于程序没有正确的校验接收到的网络数据包。远程攻击者可通过发送特制的网络数据包利用该漏洞启动用户控制的数据库（位置和内容）。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://db.apache.org/derby/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-192

  

**【漏洞名称】******Liferay 安全漏洞****

**【漏洞编号】******CNNVD-201805-193**（CVE-2018-10795）**

**【漏洞详情】**Liferay是美国Liferay公司的一套基于J2EE的门户解决方案，它使用了EJB以及JMS等技术，并可作为Web发布和共享工作区、企业协作平台、社交网络等。

Liferay 6.2.x及之前版本中存在安全漏洞。攻击者可借助browser/liferay/browser.html?Type=或html/js/editor/fckeditor/editor/filemanager/browser/liferay/browser.html URI利用该漏洞上传或传输危险类型的文件。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.liferay.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-193

  

**【漏洞名称】****abcm2ps 缓冲区错误漏洞**

**【漏洞编号】****CNNVD-201805-203（CVE-2018-10771）**

**【漏洞详情】**abcm2ps是一款能够将音乐曲调从ABC符号转换为PostScript或SVG格式的命令行程序。

abcm2ps 8.13.20及之前版本中的parse.c文件的‘get\_key’函数存在基于栈的缓冲区溢出漏洞。远程攻击者可利用该漏洞造成拒绝服务（应用程序崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/leesavide/abcm2ps/commit/dc0372993674d0b50fedfbf7b9fad1239b8efc5f

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-203
