今日CNNVD共发布安全漏洞40个，更新安全漏洞6个。主要影响厂商为加拿大Sierra Wireless（2个）、法国Schneider Electric（2个）、中国联想（2个）。主要影响产品为Sierra Wireless AirLink GX400路由器（2个）、Schneider Electric Triconex Tricon MP 3008安全控制器（2个）、Lenovo System Update自动更新工具（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】多款Sierra Wireless产品安全漏洞

【漏洞编号】CNNVD-201805-163（CVE-2018-10251）

【漏洞详情】Sierra Wireless AirLink GX400等都是加拿大Sierra Wireless公司的路由器产品。

多款Sierra Wireless产品中存在安全漏洞。攻击者可利用该漏洞执行任意代码并完全控制受影响的系统（包括以root权限发布命令）。以下产品和版本受到影响：使用4.4.7之前版本固件的Sierra Wireless AirLink GX400；使用4.4.7之前版本固件的Sierra Wireless AirLink GX440；使用4.4.7之前版本固件的Sierra Wireless AirLink ES440；使用4.4.7之前版本固件的Sierra Wireless AirLink LS300；使用4.9.3之前版本固件的Sierra Wireless AirLink GX450；使用4.9.3之前版本固件的Sierra Wireless AirLink ES450；使用4.9.3之前版本固件的Sierra Wireless AirLink RV50；使用4.9.3之前版本固件的Sierra Wireless AirLink RV50X；使用4.9.3之前版本固件的Sierra Wireless AirLink MP70；使用4.9.3之前版本固件的Sierra Wireless AirLink MP70E。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.sierrawireless.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-163


【漏洞名称】Schneider Electric Triconex Tricon MP 3008 安全漏洞

【漏洞编号】CNNVD-201805-175（CVE-2018-8872）

【漏洞详情】Schneider Electric Triconex Tricon MP 3008是法国施耐德电气（Schneider Electric）公司的一款安全控制器产品。

使用10.0版本至10.4版本固件的Schneider Electric Triconex Tricon MP 3008中存在安全漏洞。攻击者可利用该漏洞将他的数据复制到内存中的任意位置。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.schneider-electric.com/en/download/document/SEVD-2017-347-01/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-175


【漏洞名称】Lenovo System Update 缓冲区错误漏洞

【漏洞编号】CNNVD-201805-174（CVE-2018-9063）

【漏洞详情】Lenovo System Update是中国联想（Lenovo）公司的一套系统自动更新工具，它包括设备驱动更新、Windows系统补丁更新等。

Lenovo System Update 5.07.0072之前版本中的MapDrv(C:\Program Files\Lenovo\System Update\mapdrv.exe)存在缓冲区溢出漏洞。攻击者可通过输入较大的用户ID或密码利用该漏洞执行任意代码或其他操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.lenovo.com/us/zh/solutions/len-19625

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-174


【漏洞名称】Red Hat 389 Directory Server 安全漏洞

【漏洞编号】CNNVD-201805-167（CVE-2011-0704）

【漏洞详情】Red Hat 389 Directory Server（前称Fedora Directory Server）是美国红帽（Red Hat）公司的一款企业级的Linux目录服务器。该服务器完全支持LDAPv3规范，具有可扩展、多主复制等特点。

Red Hat 389 Directory Server 1.2.7.5版本中存在安全漏洞。远程攻击者可通过发送空的更改请求利用该漏洞造成拒绝服务（崩溃）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://directory.fedoraproject.org/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-167


【漏洞名称】Dasan GPON家庭路由器命令注入漏洞

【漏洞编号】CNNVD-201805-188（CVE-2018-10562）

【漏洞详情】Dasan GPON是韩国Dasan公司的一款家用路由器产品。

Dasan GPON家庭路由器中存在命令注入漏洞，该漏洞源于用户再次访问/diag.html页面时路由器将因特网包探索器的结果保存在/tmp中并将它传输给用户。攻击者可通过向GponForm/diag_Form URI发送带有‘dest_host’参数的diag_action=ping请求利用该漏洞执行命令并检索输出。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://www.dasannetworks.com

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201805-188
