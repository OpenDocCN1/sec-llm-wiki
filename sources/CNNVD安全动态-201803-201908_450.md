今日CNNVD共发布安全漏洞30个，更新安全漏洞6个。主要影响厂商为美国IBM（5个）、美国Hyland Software（4个）、美国Google（1个）。主要影响产品为IBM Security QRadar SIEM解决方案（5个）、Hyland Perceptive Document Filters工具包（4个）、Google Guava Java 核心库（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****IBM Security QRadar SIEM 跨站脚本漏洞**

**【漏洞编号】****CNNVD-201804-1476（CVE-2017-1724）**

**【漏洞详情】**IBM Security QRadar SIEM是美国IBM公司的一套可对分散在整个网络中的数千个设备和应用中的日志源事件数据进行整合的解决方案。该方案可以原始形式存储每个活动，然后执行即时关联活动，以区分实际威胁和误报。

IBM Security QRadar SIEM 7.2版本和7.3版本中存在跨站脚本漏洞。攻击者可利用该漏洞向Web UI中注入任意的JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.ibm.com/support/docview.wss?uid=swg22015807

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-1476

  

**【漏洞名称】****Hyland Perceptive Document Filters 缓冲区错误漏洞**  

**【漏洞编号】******CNNVD-201804-1464**（CVE-2018-3851）**

**【漏洞详情】**Hyland Perceptive Document Filters是美国Hyland Software公司的一套文档转换工具包。该产品能够从文档中识别和提取元数据，并支持多种类型文档的转换。

基于Windows（32和64位）/Linux平台的Hyland Perceptive Document Filters 11.4.0.2647版本中存在缓冲区溢出漏洞。攻击者可借助特制的.doc文档利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.hyland.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-1464

  

**【漏洞名称】******Google Guava 安全漏洞****

**【漏洞编号】******CNNVD-201804-1461**（CVE-2018-10237）**

**【漏洞详情】**Google Guava是美国谷歌（Google）公司开发的一款包括图形库、函数类型、I/O和字符串处理等的Java核心库。

Google Guava 11.0版本至24.1.1版本（不包括24.1.1版本）中存在安全漏洞，该漏洞源于程序没有正确的检测客户端发送的内容及数据大小是否合理。远程攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://groups.google.com/forum/#!topic/guava-announce/xqWALw4W1vs/discussion

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-1461

  

**【漏洞名称】******Red Hat ovirt-engine API和administration web portal 安全漏洞****

**【漏洞编号】******CNNVD-201804-1468**（CVE-2018-1074）**

**【漏洞详情】**Red Hat oVirt Engine是美国红帽（Red Hat）公司的一套开源的虚拟化管理平台，是RHEV（企业虚拟化平台）的开源版本。ovirt-engine API是其中的一个管理接口；administration web portal是其中的一个基于Web的管理门户。

Red Hat ovirt-engine API和administration web portal 4.2.2.5之前版本和4.1.11.2之前版本中存在安全漏洞。攻击者可利用该漏洞获取Power Management管理证书，及电力管理系统的访问权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://access.redhat.com/errata/RHBA-2018:1219

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-1468

  

**【漏洞名称】****多款Apache产品安全漏洞**

**【漏洞编号】****CNNVD-201804-1472（CVE-2017-15691）**

**【漏洞详情】**Apache UIMA是美国阿帕奇（Apache）软件基金会的一套用于分析非结构化内容（文本、视频和音频等）的框架。uimaj等都是其中提供不同功能的组件。

多款Apache产品中存在安全漏洞。攻击者可利用该漏洞获取本地文件或其他内部内容。以下产品和版本受到影响：Apache uimaj 2.10.2之前版本，3.0.0-beta之前的3.0.0-xxx版本；Apache uima-as 2.10.2之前版本；Apache uimaFIT 2.4.0之前版本；Apache uimaDUCC 2.2.2之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://uima.apache.org/security\_report#CVE-2017-15691

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-1472
