今日CNNVD共发布安全漏洞81个，更新安全漏洞1个。主要影响厂商为美国Oracle（78）、美国Microsoft（1个）。主要影响产品为Oracle MySQL管理系统（28个）、Microsoft Windows 10和Windows Server Version 1709产品（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Oracle MySQL Server组件安全漏洞**

**【漏洞编号】****CNNVD-201804-1202（CVE-2018-2819）**

**【漏洞详情】**Oracle MySQL是美国甲骨文（Oracle）公司的一套开源的关系数据库管理系统。该数据库系统具有性能高、成本低、可靠性好等特点。MySQL Server是其中的服务器组件。

Oracle MySQL中的MySQL Server组件5.5.59及之前版本、5.6.39及之前版本和5.7.21及之前版本的InnoDB子组件存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（组件挂起或频繁崩溃），影响数据的可用性。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.oracle.com/technetwork/security-advisory/cpuapr2018-3678067.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-1202

  

**【漏洞名称】****Microsoft Windows 安全漏洞**  

**【漏洞编号】******CNNVD-201804-1282**（CVE-2018-1035）**

**【漏洞详情】**Microsoft Windows 10和Windows Server Version 1709都是美国微软（Microsoft）公司的产品。Microsoft Windows 10是一套跨平台操作系统，它适用于PC和笔记本电脑、平板电脑以及手机等设备。Windows Server Version 1709是一套服务器操作系统。

Microsoft Windows中存在安全功能绕过漏洞。攻击者可通过访问本地设备并运行恶意程序利用该漏洞绕过用户模式代码完整性（UMCI）策略。以下版本受影响：Microsoft Windows 10版本1709，Windows 10版本1709，Windows Server版本1709。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2018-1035  

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-1282
