今日CNNVD共发布安全漏洞42个，更新安全漏洞5个。主要影响厂商为美国Microsoft（13个）、美国F5（9个）、美国AMD（2个）。主要影响产品为Microsoft Windows 10操作系统（9个）、F5 BIG-IP LTM流量管理器（8个）、AMD driver-installation packages驱动安装包和Gaming Evolved products游戏优化产品（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Microsoft Windows 安全漏洞**

**【漏洞编号】****CNNVD-201804-633（CVE-2018-1016）**

**【漏洞详情】**Microsoft Windows 10等都是美国微软（Microsoft）公司发布的一系列操作系统。Microsoft Windows 10是一套个人电脑使用的操作系统。Windows Server 2008 SP2是一套服务器操作系统。

Microsoft Windows中存在远程代码执行漏洞，该漏洞源于字体库没有正确的处理特制的嵌入字体。远程攻击者可通过创建特制的内容利用该漏洞执行任意代码。以下版本受到影响：Microsoft Windows 10，Windows 10版本1511，Windows 10版本1607，Windows 10版本1703，Windows 10版本1709，Windows 7 S1，Windows 8.1，Windows RT 8.1，Windows Server 2008 SP2，Windows Server 2008 R2 SP1，Windows Server 2012，Windows Server 2012 R2，Windows Server 2016，Windows Server版本1709。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2018-1016

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-633

  

**【漏洞名称】****多款F5产品安全漏洞**  

**【漏洞编号】******CNNVD-201804-702**（CVE-2018-5511）**

**【漏洞详情】**F5 BIG-IP LTM等都是美国F5公司的产品。F5 BIG-IP LTM是一款本地流量管理器；BIG-IP AAM是一款应用程序加速管理器。

多款F5产品中存在安全漏洞，该漏洞源于用户在流量管理用户界面（TMUI）运行命令时，程序没有强制限制可执行的命令。攻击者可利用该漏洞提升权限。以下产品和版本受到影响：F5 BIG-IP LTM 13.1.0版本，13.0.0版本；F5 BIG-IP AAM 13.1.0版本，13.0.0版本；F5 BIG-IP AFM 13.1.0版本，13.0.0版本；F5 BIG-IP Analytics 13.1.0版本，13.0.0版本；F5 BIG-IP APM 13.1.0版本，13.0.0版本；F5 BIG-IP ASM 13.1.0版本，13.0.0版本；F5 BIG-IP DNS 13.1.0版本，13.0.0版本；F5 BIG-IP Edge Gateway 13.1.0版本，13.0.0版本；F5 BIG-IP GTM 13.1.0版本，13.0.0版本；F5 BIG-IP Link Controller 13.1.0版本，13.0.0版本；F5 BIG-IP PEM 13.1.0版本，13.0.0版本；F5 BIG-IP WebAccelerator 13.1.0版本，13.0.0版本；F5 BIG-IP WebSafe 13.1.0版本，13.0.0版本；F5 BIG-IP Enterprise Manager 3.1.1版本。  

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.f5.com/csp/article/K30500703

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-702

  

**【漏洞名称】******AMD驱动程序安装包和Gaming Evolved产品plays.tv服务安全漏洞****

**【漏洞编号】******CNNVD-201804-685**（CVE-2018-6547）**

**【漏洞详情】**AMD driver-installation packages和Gaming Evolved products都是美国AMD公司的产品。AMD driver-installation packages是一套用于AMD显卡的驱动安装包。Gaming Evolved products是游戏优化产品。plays.tv是其中的一个游戏录制和分享服务。

AMD驱动程序安装包和Gaming Evolved产品中的plays.tv服务1.27.7.0之前版本的plays\_service.exe文件存在安全漏洞，该漏洞源于程序没有正确的对用户执行身份验证。攻击者可利用该漏洞覆盖重要的系统文件，造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://plays.tv/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-685

  

**【漏洞名称】****Apple iOS和macOS High Sierra Status Bar 安全漏洞**

**【漏洞编号】****CNNVD-201804-684（CVE-2018-4173）**

**【漏洞详情】**Apple iOS和macOS High Sierra都是美国苹果（Apple）公司的产品。Apple iOS是为移动设备所开发的一套操作系统；macOS High Sierra是一套专为Mac计算机所开发的专用操作系统。Status Bar是其中的一个状态栏组件。

Apple iOS 11.3之前版本和macOS High Sierra 10.13.4之前版本中的Status Bar组件存在安全漏洞。攻击者可利用该漏洞在用户不知情的情况下访问麦克风。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/zh-cn/HT208692

https://support.apple.com/zh-cn/HT208693

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-684

  

**【漏洞名称】******VMware vRealize Automation 跨站脚本漏洞****

**【漏洞编号】******CNNVD-201804-701**（CVE-2018-6958）**

**【漏洞详情】**VMware vRealize Automation（vRA）是美国威睿（VMware）公司的一套云计算自动化软件。该软件支持自动交付个性化基础架构，跨多供应商、混合云基础架构进行部署，简化应用发布自动化和持续交付等。

VMware vRA 7.3.1之前版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞控制vRA用户的工作站。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.vmware.com/security/advisories/VMSA-2018-0009.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-701
