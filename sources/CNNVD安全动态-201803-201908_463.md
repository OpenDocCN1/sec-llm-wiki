今日CNNVD共发布安全漏洞49个，更新安全漏洞8个。主要影响厂商为美国Google（27个）、中国华为（4个）、美国Pivotal Software（2个）。主要影响产品为Android操作系统（27个）、Huawei Honor 8青春版智能手机（1个）、Pivotal Spring Framework应用程序框架（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Android 缓冲区错误漏洞**

**【漏洞编号】****CNNVD-201804-532（CVE-2018-3594）**

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Qualcomm MDM9206等都是美国高通（Qualcomm）公司应用于不同平台的中央处理器（CPU）产品。

Android 2018-04-05之前版本中的Qualcomm闭源组件存在缓冲区越边界读取漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。以下产品（汽车、手机和手表）受到影响：Qualcomm MDM9206；Qualcomm MDM9607；Qualcomm MDM9650；Qualcomm SD 210；Qualcomm SD 212；Qualcomm SD 205；Qualcomm SD 425；Qualcomm SD 430；Qualcomm SD 450；Qualcomm SD 615/16；Qualcomm SD 415；Qualcomm SD 617；Qualcomm SD 625；Qualcomm SD 650/52；Qualcomm SD 808；Qualcomm SD 820；Qualcomm SD 820A；Qualcomm SD 835；Qualcomm SD 845。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2018-04-01

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-532

  

**【漏洞名称】****Huawei Honor 8青春版Themes App 安全漏洞**  

**【漏洞编号】******CNNVD-201804-528**（CVE-2017-8154）**

**【漏洞详情】**Huawei Honor 8青春版是中国华为（Huawei）公司的一款智能手机产品。Themes APP是运行在其中的一款华为手机主题应用程序。

Huawei Honor 8青春版中的Themes App存在安全漏洞，该漏洞源于程序使用不安全的http协议下载某些主题包。攻击者可利用该漏洞实施中间人攻击，恶意修改下载的主题。以下版本受到影响：Huawei Honor 8青春版Prague-L31C576B172之前版本，Prague-L31C530B160之前版本，Prague-L31C432B180之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20170908-01-smartphone-cn

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-528

  

**【漏洞名称】******Pivotal Spring Framework 安全漏洞****

**【漏洞编号】******CNNVD-201804-563**（CVE-2018-1275）**

**【漏洞详情】**Pivotal Spring Framework是美国Pivotal Software公司的一套开源的Java、Java EE应用程序框架。该框架可帮助开发人员构建高质量的应用。

Pivotal Spring Framework中存在安全漏洞，该漏洞源于程序允许应用程序使用简单的内存STOMP代理通过WebSocket端点公开STOMP。远程攻击者可通过发送特制的消息利用该漏洞执行代码。以下版本受到影响：Spring Framework 5.0.5之前的5.0.x版本，4.3.16之前的4.3.x版本及已不支持的老版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://pivotal.io/security/cve-2018-1275

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-563

  

**【漏洞名称】******IBM WebSphere Portal 跨站脚本漏洞****

**【漏洞编号】******CNNVD-201804-531**（CVE-2018-1483）**

**【漏洞详情】**IBM WebSphere Portal是美国IBM公司的一套企业门户软件。该软件能够创建一个联接企业内部和外部的平台，可让员工、客户和供应商等通过该平台访问企业内部数据。

IBM WebSphere Portal 9.0.0.0版本至9.0.0.0 CF15版本和8.5.0.0版本至8.5.0.0 CF15版本中存在跨站脚本漏洞。攻击者可利用该漏洞向Web UI中注入任意的JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22015317

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-531

  

**【漏洞名称】****OpenText Documentum D2 Webtop 跨站脚本漏洞**

**【漏洞编号】****CNNVD-201804-567（CVE-2018-7660）**

**【漏洞详情】**OpenText Documentum D2 Webtop是加拿大OpenText公司的一套企业级内容管理系统。该系统通过创建、修改、跟踪等功能管理整个信息生命周期，其包括了多个扩展产品，如Documentum Web Publisher（Web内容管理）、Documentum Records Manager（记录管理）等。

OpenText Documentum D2 Webtop 4.6.0030 build 059版本中存在跨站脚本漏洞。远程攻击者可借助上传图像文件的名称利用该漏洞控制受影响的系统。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.opentext.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-567
