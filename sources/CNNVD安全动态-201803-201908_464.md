今日CNNVD共发布安全漏洞44个，更新安全漏洞7个。主要影响厂商为德国SAP（9个）、澳大利亚Atlassian（3个）、中国米拓（3个）。主要影响产品为SAP Disclosure Management管理系统（4个）、Atlassian Application Links插件（1个）、MetInfo内容管理系统（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****SAP Disclosure Management 安全漏洞**

**【漏洞编号】****CNNVD-201804-467（CVE-2018-2413）**

**【漏洞详情】**SAP Disclosure Management是德国思爱普（SAP）公司的一套自动化财务披露管理系统。该系统提供跨团队、跨地域、跨系统和跨数据源的协作式财务披露流程。

SAP Disclosure Management 10.1版本中存在安全漏洞，该漏洞源于程序没有对已认证用户执行必要的授权检测。攻击者可利用该漏洞提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://blogs.sap.com/2018/04/10/sap-security-patch-day-april-2018/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-467

  

**【漏洞名称】****Atlassian Application Links 跨站脚本漏洞**  

**【漏洞编号】******CNNVD-201804-484**（CVE-2018-5227）**

**【漏洞详情】**Atlassian Application Links是澳大利亚Atlassian公司的一款使用在Atlassian产品中用于创建连接到其他应用程序中的按钮的插件。

Atlassian Application Links 5.4.4之前版本中的多个管理应用程序链接资源存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的HTML或JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://ecosystem.atlassian.net/browse/APL-1361

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-484

  

**【漏洞名称】******MetInfo 跨站脚本漏洞****

**【漏洞编号】******CNNVD-201804-462**（CVE-2018-9985）**

**【漏洞详情】**MetInfo是中国米拓信息技术有限公司的一套使用PHP和Mysql开发的内容管理系统（CMS）。

MetInfo 6.0版本中的front page存在跨站脚本漏洞。远程攻击者可通过向管理员发送反馈信息利用该漏洞注入任意的Web脚本或HTML。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.metinfo.cn/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-462

  

**【漏洞名称】******ARM mbed TLS 缓冲区错误漏洞****

**【漏洞编号】******CNNVD-201804-460**（CVE-2018-9989）**

**【漏洞详情】**ARM mbed TLS（前称PolarSSL）是英国ARM公司的一款为mbed产品提供安全通讯和加密功能的产品。

ARM mbed TLS 2.1.11之前版本、2.7.2之前版本和2.8.0之前版本中的‘ssl\_parse\_server\_psk\_hint()’函数存在缓冲区越边界读取漏洞。攻击者可利用该漏洞造成拒绝服务（崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tls.mbed.org/tech-updates/releases/mbedtls-2.8.0-2.7.2-and-2.1.11-released

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-460

  

**【漏洞名称】****IBM WebSphere MQ 安全漏洞**

**【漏洞编号】****CNNVD-201804-477（CVE-2015-1957）**

**【漏洞详情】**IBM WebSphere MQ是美国IBM公司的一款消息传递中间件产品。该产品主要为面向服务的体系结构（SOA）提供可靠的、经过验证的消息传递主干网。

IBM WebSphere MQ 7.5.0.6之前的7.5.x版本和8.0.0.3之前的8.0.x版本中存在安全漏洞。远程攻击者可通过实施中间人攻击利用该漏洞获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg21960506

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-477
