今日CNNVD共发布安全漏洞43个，更新安全漏洞1个。主要影响厂商为美国Google（7个）、日本Buffalo（3个）、希腊Navarino（3个）。主要影响产品为Google Chrome浏览器（27个）、Buffalo WZR-1750DHP2路由器（3个）、Navarino Infinity解决方案（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Google Chrome Flash 安全漏洞**

**【漏洞编号】****CNNVD-201804-426（CVE-2018-6058）**

**【漏洞详情】**Google Chrome是美国谷歌（Google）公司开发的一款Web浏览器。Flash是其中的一个用于处理Flash的插件。

Google Chrome 65.0.3325.146之前版本中的Flash存在释放后重用漏洞。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://chromereleases.googleblog.com/2018/03/stable-channel-update-for-desktop.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-426

  

**【漏洞名称】****Buffalo WZR-1750DHP2 安全漏洞**  

**【漏洞编号】******CNNVD-201804-416**（CVE-2018-0556）**

**【漏洞详情】**Buffalo WZR-1750DHP2是日本巴法络（Buffalo）集团的一款路由器产品。

Buffalo WZR-1750DHP2 2.30及之前版本中存在安全漏洞。攻击者可利用该漏洞执行任意的操作系统命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://buffalo.jp/support\_s/s20180328.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-416

  

**【漏洞名称】******Navarino Infinity SQL注入漏洞****

**【漏洞编号】******CNNVD-201804-423**（CVE-2018-5384）**

**【漏洞详情】**Navarino Infinity是希腊Navarino公司的一套海事带宽管理和优化解决方案。该方案能够用于配备多种类型的船舶。

Navarino Infinity 2.1.7版本中存在SQL注入漏洞。远程攻击者可利用该漏洞注入SQL命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://navarino.gr/archives/6989

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-423

  

**【漏洞名称】******Dell EMC Avamar Server和EMC Integrated Data Protection Appliance Avamar Installation Manager 安全漏洞****

**【漏洞编号】******CNNVD-201804-411**（CVE-2018-1217）**

**【漏洞详情】**Dell EMC Avamar Server和EMC Integrated Data Protection Appliance都是美国戴尔（Dell）公司的产品。Dell EMC Avamar Server是一套用于服务器的完全虚拟化的备份和恢复软件。EMC Integrated Data Protection Appliance是一套基于磁盘的备份和恢复解决方案。

Dell EMC Avamar Server和EMC Integrated Data Protection Appliance中的Avamar Installation Manager存在安全漏洞。远程攻击者可利用该漏洞读取或更改Local Download Service (LDLS)凭证，或使用该凭证登录Dell EMC Online Support。以下产品和版本受到影响：Dell EMC Avamar Server 7.3.1版本，7.4.1版本，7.5.0版本；Dell EMC Integrated Data Protection Appliance 2.0版本，2.1版本。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.dellemc.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-411

  

**【漏洞名称】****Apache Solr DataImportHandler 安全漏洞**

**【漏洞编号】****CNNVD-201804-415（CVE-2018-1308）**

**【漏洞详情】**Apache Solr是美国阿帕奇（Apache）软件基金会的一款基于Lucene（一个全文检索引擎的架构）的搜索服务器，它支持层面搜索、垂直搜索、高亮显示搜索结果、多种输出格式等。DataImportHandler是其中的一个数据导入处理程序。

Apache Solr 1.2版本至6.6.2版本和7.0.0版本至7.2.1版本中的DataImportHandler的\`&dataConfig=<inlinexml>\` 参数存在安全漏洞。攻击者可利用该漏洞读取Solr服务器或内部网络的任意本地文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://issues.apache.org/jira/browse/SOLR-11971

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-415
