今日CNNVD共发布安全漏洞77个，更新安全漏洞68个。主要影响厂商为美国Google（35个）、美国McAfee（6个）、美国Brave Software（2个）。主要影响产品为Android操作系统（22个）、McAfee Network Security Management（NSM）解决方案（6个）、Brave Browser浏览器（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】Android 信息泄露漏洞

【漏洞编号】CNNVD-201804-342（CVE-2017-13290）

【漏洞详情】Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。

Android中的sdp_server.cc文件的sdp_server_handle_client_req存在信息泄露漏洞，该漏洞源于程序缺少边界检测。本地攻击者可利用该漏洞获取信息（越边界读取）。以下版本受到影响：Android 6.0版本，6.0.1版本，7.0版本，7.1.1版本，7.1.2版本，8.0版本，8.1版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2018-04-01

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-342


【漏洞名称】McAfee Network Security Management 安全漏洞

【漏洞编号】CNNVD-201804-368（CVE-2017-3971）

【漏洞详情】McAfee Network Security Management（NSM）是美国迈克菲（McAfee）公司的一套能够实时监控整个网络中已部署的迈克菲入侵防护系统的网络安全解决方案。

McAfee NSM 8.2.7.42.2之前版本中存在安全漏洞，该漏洞源于程序支持使用RC4加密密码。攻击者可利用该漏洞获取敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://kc.mcafee.com/corporate/index?page=content&id=SB10192

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-368


【漏洞名称】Brave Browser 安全漏洞

【漏洞编号】CNNVD-201804-400（CVE-2017-18256）

【漏洞详情】Brave Browser是美国Brave Software公司的一款Web浏览器。

Brave Browser 0.13.0之前版本中存在安全漏洞，该漏洞源于程序没有正确的处理窗口对话。远程攻击者可借助较大的输入值利用该漏洞造成拒绝服务（资源消耗）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://brave.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-400


【漏洞名称】FiberHome VDSL2 Modem HG 150-UB 安全漏洞

【漏洞编号】CNNVD-201804-360（CVE-2018-9249）

【漏洞详情】FiberHome VDSL2 Modem HG 150-UB是中国烽火（FiberHome）公司的一款调制解调器产品。

FiberHome VDSL2 Modem HG 150-UB中存在安全漏洞。攻击者可利用该漏洞绕过身份验证。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

http://www.fiberhome.com

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-360


【漏洞名称】IScripts EasyCreate 跨站脚本漏洞

【漏洞编号】CNNVD-201804-395（CVE-2018-9237）

【漏洞详情】IScripts EasyCreate是美国Iscripts公司的一套在线网站构建工具。该工具可用在服务器上为客户端提供网站构建服务，属于完全可以定制的。

IScripts EasyCreate 3.2.1版本中的Site Description字段存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的Web脚本或HTML。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.iscripts.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-395
