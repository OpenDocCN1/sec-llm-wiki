漏洞态势

根据国家信息安全漏洞库（CNNVD）统计，2018年3月份采集安全漏洞共1200个，Microsoft Windows 10成为黑客重要攻击目标。

本月接报漏洞共计461个，其中信息技术产品漏洞（通用型漏洞）61个，网络信息系统漏洞（事件型漏洞）400个。

重大漏洞预警

Cisco IOS Software和IOS XESoftware输入验证漏洞（CNNVD-201803-1022）、Cisco IOS Software和IOS XESoftware quality of service子系统缓冲区错误漏洞（CNNVD-201803-1038）、Cisco IOS XE Software安全漏洞（CNNVD-201803-1039）。成功利用上述漏洞的攻击者，可以对使用了IOS以及IOS XE系统的思科设备发送恶意的数据包，最终实现拒绝服务或远程代码执行，完全控制设备等。所有支持Smart Install client特性的IOS以及IOS XE设备都可能受漏洞影响。目前，思科官方已对该漏洞进行了修复，建议受影响的用户请尽快对系统更新进行防护。


漏洞态势

一、公开漏洞情况

根据国家信息安全漏洞库（CNNVD）统计，2018年3月份新增安全漏洞共1200个，从厂商分布来看，Microsoft公司产品的漏洞数量最多，共发布74个；从漏洞类型来看，跨站脚本类的漏洞占比最大，达到13.17%。本月新增漏洞中，超危漏洞26个、高危漏洞93个、中危漏洞938个、低危漏洞143个，相应修复率分别为53.85%、78.49%、72.07%以及67.83%。合计860个漏洞已有修复补丁发布，本月整体修复率71.67%。

截至2018年3月31日，CNNVD采集漏洞总量已达106638个。

1.Github Electron Protocol Handler操作系统命令注入漏洞（CNNVD-201803-199）

GitHub Electron是美国GitHub公司的一个应用程序开发框架。该框架支持使用JavaScript、HTML和CSS编写跨平台桌面应用程序。Protocol Handler是其中的一个协议处理程序。

Github Electron 1.8.2-beta.4及之前版本中的Protocol Handler存在操作系统命令注入漏洞。当用户在浏览器中打开electron协议处理程序时，攻击者可利用该漏洞执行命令。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://electronjs.org/releases#1.8.2-beta.5

2.CactusVPN for macOS 权限许可和访问控制漏洞（CNNVD-201802-748）

CactusVPN for macOS是摩尔多瓦CactusVPN公司的一款基于macOS平台的VPN软件，用于匿名访问互联网。

基于macOS平台的CactusVPN 5.3.6版本中存在提权漏洞。攻击者可利用该漏洞以root权限执行命令。

解决措施：目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.cactusvpn.com/

3.Google Chrome OS 缓冲区错误漏洞（CNNVD-201803-211）

Google Chrome OS是美国谷歌（Google）公司开发的一套基于Web的快速、轻量型的开源操作系统。

Google Chrome OS 53.0.2785.144之前版本中存在缓冲区溢出漏洞。远程攻击者可利用该漏洞在启动时执行任意命令。

解决措施：目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://chromereleases.googleblog.com/2016/09/stable-channel-updates-for-chrome-os.html

4.Cisco Secure Access Control System 输入验证漏洞（CNNVD-201803-261）

Cisco Secure Access Control System（ACS）是美国思科（Cisco）公司的一套安全访问控制系统。该系统可通过RADIUS、TACACS协议分别对网络访问和网络设备访问进行控制。

Cisco Secure ACS 5.8 patch 9之前的版本中存在输入验证漏洞，该漏洞源于程序没有安全的反序列化用户提交的内容。远程攻击者可通过发送特制的序列化Java对象利用该漏洞以root权限执行任意命令。

解决措施：目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20180307-acs2

1.EllisLab CodeIgniter SQL注入漏洞（CNNVD-201802-759）

EllisLab CodeIgniter是美国EllisLab公司的一套针对于PHP网站开发者使用的应用程序开发框架和工具包。

EllisLab CodeIgniter 2.2.4之前版本中的Active Record类的offset方法存在SQL注入漏洞。远程攻击者可利用该漏洞执行任意SQL命令。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/bcit-ci/CodeIgniter/commit/0dde92def6b9f276f05ff77abb07ead318f9ec23

2.Thycotic Secret Server Remote Desktop Launcher 信任管理漏洞（CNNVD-201803-281）

Thycotic Secret Server是美国Thycotic公司的一套密码保护软件。Remote Desktop Launcher是其中的一个远程桌面启动器。

Thycotic Secret Server 8.6.000010之前的版本中的Remote Desktop Launcher存在信任管理漏洞，该漏洞源于程序没有正确的清除包含有加密密码的临时文件。攻击者可利用该漏洞获取身份验证凭证。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://thycotic.com/products/secret-server/resources/advisories/cve-2014-4861/

3.Cisco ASR 5000 Series Aggregation Services Routers StarOS操作系统命令注入漏洞（CNNVD-201803-244）

Cisco ASR 5000 Series Aggregation Services Routers是美国思科（Cisco）公司的一款5000系列安全路由器设备。StarOS operating system是一套运行在其中的虚拟化操作系统。CLI是其中的一个命令行界面。

Cisco ASR 5000 Series Aggregation Services Routers中的StarOS操作系统的CLI存在命令注入漏洞，该漏洞源于程序没有正确的验证用户提交的输入。本地攻击者可通过向受影响的系统进行身份验证并向受影响的CLI命令注入恶意的参数利用该漏洞以root权限执行任意命令。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bst.cloudapps.cisco.com/bugsearch/bug/CSCvg38807

4.Schneider Electric Pelco Sarix Professional 授权问题漏洞（CNNVD-201803-045）

Schneider Electric Pelco Sarix Professional是法国施耐德电气（Schneider Electric）公司的一款视频监控设备。

使用3.29.67之前版本固件的Schneider Electric Pelco Sarix Professional中存在授权问题漏洞。远程攻击者可利用该漏洞绕过身份验证并获取管理员特权。

 Juniper AppFormix 2.7版本、2.11.3之前的2.11版本和2.15.2之前的2.15版本中存在提权漏洞。攻击者可利用该漏洞访问Python调试控制台并以root权限执行系统命令

7.Huawei Mate 9 Pro LON-AL00B NFC模块缓冲区错误漏洞（CNNVD-201803-301）

Huawei Mate 9 Pro是中国华为（Huawei）公司的一款智能手机产品。NFC（Near Field Communication）moudle是其中的一个近距离无线通讯模块。

Huawei Mate 9 Pro LON-AL00B 8.0.0.340a(C00)之前版本中的NFC模块存在缓冲区溢出漏洞，该漏洞源于程序缺少输入验证。攻击者可借助NFC读卡器等设备利用该漏洞注入恶意数据，造成拒绝服务（系统重启）或执行任意代码。

三、重大漏洞预警

3.1关于Cisco IOS Software和IOS XE Software多个漏洞情况的通报

本月CNNVD收到关于“Cisco IOS Software和IOS XE Software输入验证漏洞”（CNNVD-201803-1022）、“Cisco IOS Software和IOS XE Software quality of service子系统缓冲区错误漏洞”（CNNVD-201803-1038）、“Cisco IOS XE Software安全漏洞”（CNNVD-201803-1039）3个漏洞情况的报送。由于攻击者可对使用IOS以及IOS XE系统的思科设备发送恶意的数据包，最终实现拒绝服务或远程代码执行，完全控制设备等。国家信息安全漏洞库（CNNVD）对此进行了跟踪分析，情况如下：

  • 漏洞简介

思科IOS以及IOS XE是美国思科（Cisco）公司为其网络设备开发的操作系统，多用于思科交换机、路由器、防火墙等设备。

Cisco IOS Software和IOS XE Software输入验证漏洞（CNNVD-201803-1022），该漏洞源于程序没有正确的校验数据包数据，导致攻击者可通过向TCP 4786端口上发送精心构造的恶意数据包，最终实现远程代码执行。Cisco IOS Software和IOS XE Software quality of service子系统缓冲区错误漏洞（CNNVD-201803-1038、CVE-2018-0151），该漏洞源于程序没有正确的对数据包中的值执行边界检测，导致攻击者可通过向UDP 18999端口发送精心构造的恶意数据包，最终在目标设备上实现拒绝服务或远程代码执行。Cisco IOS XE Software安全漏洞（CNNVD-201803-1039、CVE-2018-0150），该漏洞源于系统内存在一个隐藏的15级别特权的账户，导致攻击者可能通过此账户默认的用户名密码远程登录受漏洞影响的设备，最终实现对设备的完全控制。

  • 漏洞危害

成功利用Cisco IOS Software和IOS XE Software输入验证漏洞、Cisco IOS Software和IOS XE Software quality of service子系统缓冲区错误漏洞的攻击者可在目标设备上远程执行代码或造成设备拒绝服务。成功利用Cisco IOS XE Software安全漏洞的攻击者可以用15级别特权的账户登录，完全控制设备。使用了IOS以及IOS XE系统的思科设备可能都会受到以上漏洞的影响。

  • 修复措施

目前，思科官方已针对该漏洞发布了固件更新，请用户及时检查产品型号是否受漏洞影响，请及时进行更新修补漏洞。
