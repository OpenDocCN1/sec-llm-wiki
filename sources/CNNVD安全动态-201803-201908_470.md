今日CNNVD共发布安全漏洞23个，更新安全漏洞39个。主要影响厂商为美国Apple（22个）、美国Intel（1个）。主要影响产品为Apple macOS Sierra操作系统（13个）、Intel 5th generation Intel Core Processors等中央处理器（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Apple macOS Sierra Kernel 安全漏洞**

**【漏洞编号】****CNNVD-201804-205（CVE-2017-7070）**

**【漏洞详情】**Apple macOS Sierra是美国苹果（Apple）公司为Mac计算机所开发的一套专用操作系统。Kernel是其中的一个内核组件。

Apple macOS Sierra 10.12.4之前的版本中的Kernel组件存在安全漏洞。攻击者可利用该漏洞绕过锁屏保护机制。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/zh-cn/HT207615

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-205

  

**【漏洞名称】****多款Intel产品安全漏洞**  

**【漏洞编号】******CNNVD-201804-108**（CVE-2017-5703）**

**【漏洞详情】**Intel 5th generation Intel Core Processors等都是美国英特尔（Intel）公司的不同系列的CPU（中央处理器）产品。

多款Intel产品上的平台中的SPI Flash配置存在安全漏洞。本地攻击者可利用该漏洞造成拒绝服务。以下产品受到影响：Intel 5th，6th，7th和8th generation Intel Core Processors；Intel Pentium and Celeron Processor N3520，N2920，N28XX；Intel Atom Processor x7-Z8XXX和x5-8XXX Processor Family；Intel Pentium Processor J3710和N37XX；Intel Celeron Processor J3XXX；Intel Atom x5-E8000 Processor；Intel Pentium Processor J4205和N4200；Intel Celeron Processor J3455，J3355，N3350和N3450；Intel Atom Processor x7-E39XX Processor；Intel Xeon Scalable Processors；Intel Xeon Processor E3 v6，v5，v4，v3和v2 Family；Intel Xeon Phi Processor x200；Intel Xeon Processor D Family；Intel Atom Processor C Series。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://security-center.intel.com/advisory.aspx?intelid=INTEL-SA-00087&languageid=en-fr

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-108
