今日CNNVD共发布安全漏洞28个，更新安全漏洞21个。主要影响厂商为美国IBM（8个）、韩国Samsung（5个）、美国ImageMagick Studio（2个）。主要影响产品为IBM Business Process Manager（BPM）管理平台（5个）、Samsung mobile devices等移动设备（5个）、ImageMagick软件（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】IBM Business Process Manager 跨站脚本漏洞

【漏洞编号】CNNVD-201804-048（CVE-2018-1384）

【漏洞详情】IBM Business Process Manager（BPM）是美国IBM公司的一套综合的业务流程管理平台。该平台为业务的流程建模、组装、监控和部署提供了一系列的相关工具。

IBM BPM 8.6版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞向Web UI注入任意的JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22012604

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-048


【漏洞名称】Samsung移动设备sensorhub binder服务缓冲区错误漏洞

【漏洞编号】CNNVD-201804-059（CVE-2018-9143）

【漏洞详情】Samsung mobile devices等都是韩国三星（Samsung）公司的发布的智能移动设备。Android M和N都是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的以Linux为基础的不同版本的开源操作系统。sensorhub binder service是其中的一个传感器和集线器的处理服务。

使用Android M(6.0)和N(7.x)版本的Samsung移动设备中的sensorhub binder服务存在堆溢出漏洞。攻击者可利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://security.samsungmobile.com/securityUpdate.smsb

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-059


【漏洞名称】ImageMagick 缓冲区错误漏洞

【漏洞编号】CNNVD-201804-066（CVE-2018-9135）

【漏洞详情】ImageMagick是美国ImageMagick Studio公司的一套开源的图象处理软件。该软件可读取、转换、写入多种格式的图片。

ImageMagick 7.0.7-24 Q16版本中的coders/webp.c文件的‘IsWEBPImageLossless’函数存在基于堆的缓冲区越边界读取。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/ImageMagick/ImageMagick/issues/1009

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-066


【漏洞名称】Microsoft Windows kernel 权限许可和访问控制漏洞

【漏洞编号】CNNVD-201804-001（CVE-2018-1038）

【漏洞详情】Microsoft Windows 7 SP1和Windows Server 2008 R2 SP1都是美国微软（Microsoft）公司发布的操作系统。Microsoft Windows 7 SP1是一套个人电脑使用的操作系统。Windows Server 2008 R2 SP1是一套服务器操作系统。Windows kernel是其中的一个系统内核。

Microsoft Windows kernel中存在提权漏洞，该漏洞源于程序没有正确的处理内存中的对象。攻击者可通过登录系统并运行特制的应用程序利用该漏洞以提升的权限执行任意代码。以下系统版本受到影响：Microsoft Windows 7 SP1，Windows Server 2008 R2 SP1。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2018-1038

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-001


【漏洞名称】WordPress Iptanus WordPress File Upload插件安全漏洞

【漏洞编号】CNNVD-201804-002（CVE-2018-9172）

【漏洞详情】WordPress是WordPress软件基金会的一套使用PHP语言开发的博客平台，该平台支持在PHP和MySQL的服务器上架设个人博客网站。Iptanus WordPress File Upload plugin是使用在其中的一个文件上传插件。

WordPress Iptanus WordPress File Upload插件4.3.3之前的版本中存在安全漏洞，该漏洞源于程序没有正确的处理短代码属性。目前尚无此漏洞的相关信息，请随时关注CNNVD或厂商公告。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/wp-file-upload/#developers

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201804-002
