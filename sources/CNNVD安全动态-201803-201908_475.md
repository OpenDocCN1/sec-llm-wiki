# CNNVD最新漏洞（2018-04-02）

今日CNNVD共发布安全漏洞51个，更新安全漏洞6个。主要影响厂商为美国Mozilla（14个）、美国IBM（3个）、美国CA（3个）。主要影响产品为Mozilla Firefox浏览器（13个）、IBM BigFix Remote Control远程控制系统（1个）、CA API Developer Portal应用程序（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Mozilla Firefox 安全漏洞**

**【漏洞编号】****CNNVD-201803-1101（CVE-2018-5128）**

**【漏洞详情】**Mozilla Firefox是美国Mozilla基金会开发的一款开源Web浏览器。

Mozilla Firefox 59之前版本中存在释放后重用漏洞。攻击者可利用该漏洞造成拒绝服务（崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.mozilla.org/en-US/security/advisories/mfsa2018-06/#CVE-2018-5128

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-1101

  

**【漏洞名称】****IBM BigFix Remote Control 加密问题漏洞**  

**【漏洞编号】******CNNVD-201803-1117**（CVE-2015-4953）**

**【漏洞详情】**IBM BigFix Remote Control是美国IBM公司的一套远程控制系统。

IBM BigFix Remote Control 9.1.2版本中存在加密问题漏洞。远程攻击者可通过实施中间人攻击利用该漏洞解密流量。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-304.ibm.com/support/docview.wss?uid=swg21972041

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-1117

  

**【漏洞名称】******CA API Developer Portal apiExplorer 跨站脚本漏洞****

**【漏洞编号】******CNNVD-201803-1128**（CVE-2018-6588）**

**【漏洞详情】**CA API Developer Portal是美国CA公司的一套为软件开发人员提供API（应用程序编程接口）查询功能的应用程序。apiExplorer是其中的一个API探测器。

CA API Developer Portal 3.5版本至3.5 CR5版本中的apiExplorer存在跨站脚本漏洞，该漏洞源于程序没有正确过滤用户提交的HTML代码。远程攻击者可利用该漏洞执行任意脚本代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.ca.com/us/product-content/recommended-reading/security-notices/ca20180328-01--security-notice-for-ca-api-developer-portal.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-1128

  

**【漏洞名称】******Google Chrome for Mac、Windows和Linux V8 安全漏洞****

**【漏洞编号】******CNNVD-201803-1097**（CVE-2018-6056）**

**【漏洞详情】**Google Chrome for Mac、Windows和Linux是美国谷歌（Google）公司开发的一款基于Mac、Windows和Linux平台的Web浏览器。V8是其中的一个开源JavaScript引擎。

基于Mac和Linux平台的Google Chrome 64.0.3282.167之前版本和基于Windows平台的Google Chrome 64.0.3282.167/168之前版本中的V8存在安全漏洞。远程攻击者可利用该漏洞绕过安全限制，获取未授权的访问权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://chromereleases.googleblog.com/2018/02/stable-channel-update-for-desktop\_13.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-1097

  

**【漏洞名称】****Apple macOS High Sierra Touch Bar Support 安全漏洞**

**【漏洞编号】****CNNVD-201803-1100（CVE-2018-4083）**

**【漏洞详情】**Apple macOS High Sierra是美国苹果（Apple）公司的一套专为Mac计算机所开发的专用操作系统。Touch Bar Support是其中的一个Touch Bar支持组件。

Apple macOS High Sierra 10.13.3之前版本中的Touch Bar Support组件存在安全漏洞。攻击者可利用该漏洞以系统权限执行任意代码（内存损坏）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.apple.com/en-il/HT208465

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-1100
