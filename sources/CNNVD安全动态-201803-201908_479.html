CNNVD最新漏洞（2018-03-28）

今日CNNVD共发布安全漏洞33个，更新安全漏洞18个。主要影响厂商为美国Dell（9个）、美国Apache（5个）、英国Micro Focus（4个）。主要影响产品为DELL EMC Isilon存储系统（9个）、Apache HTTP Server网页服务器（3个）、Micro Focus NetIQ Identity Manager解决方案（4个）。

今日需关注的典型漏洞如下:

【漏洞名称】Dell EMC Isilon OneFS 跨站请求伪造漏洞

【漏洞编号】CNNVD-201803-919（CVE-2018-1213）

【漏洞详情】DELL EMC Isilon是美国戴尔（Dell）公司的一套适用于非结构化数据的横向扩展存储系统。OneFS是运行在其中的一套操作系统。

Dell EMC Isilon OneFS中存在跨站请求伪造漏洞。远程攻击者可利用该漏洞执行未授权的操作。以下版本受到影响：Dell EMC Isilon OneFS 8.1.0.0版本至8.1.0.1版本，8.0.1.0版本至8.0.1.2版本，8.0.0.0版本至8.0.0.6版本，7.2.1.x版本，7.1.1.11版本，8.1.0.2版本。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.dellemc.com

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-919


【漏洞名称】Apache HTTP Server 安全漏洞

【漏洞编号】CNNVD-201803-937（CVE-2018-1303）

【漏洞详情】Apache HTTP Server是美国阿帕奇（Apache）软件基金会的一款开源网页服务器。该服务器具有快速、可靠且可通过简单的API进行扩充的特点。

Apache HTTP Server 2.4.30之前版本中存在安全漏洞。攻击者可通过发送特制的HTTP请求包头利用该漏洞造成拒绝服务（崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://httpd.apache.org/security/vulnerabilities_24.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-937


【漏洞名称】Micro Focus NetIQ Identity Manager communication channel 安全漏洞

【漏洞编号】CNNVD-201803-914（CVE-2018-7673）

【漏洞详情】Micro Focus NetIQ Identity Manager是英国Micro Focus公司的一套身份认证管理解决方案。该方案为帐户供应、用户自助服务、授权和Web服务等提供了基础，并支持数据共享和同步。communication channel是其中的一个通信功能模块。

Micro Focus NetIQ Identity Manager 4.7之前版本中的communication channel存在安全漏洞。攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.netiq.com/documentation/identity-manager-47/releasenotes_idm47/data/releasenotes_idm47.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-914


【漏洞名称】IBM Capacity Management Analytics 安全漏洞

【漏洞编号】CNNVD-201803-928（CVE-2015-7434）

【漏洞详情】IBM Capacity Management Analytics是美国IBM公司的一套用于管理和预测IBM zEnterprise基础架构（大型计算机）资源的使用情况的容量管理分析解决方案。

IBM Capacity Management Analytics 2.1.0.0版本中存在安全漏洞。本地攻击者可利用该漏洞获取加密的用户名和密码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg21974559

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-928


【漏洞名称】Apple CUPS 安全漏洞

【漏洞编号】CNNVD-201803-933（CVE-2017-18248）

【漏洞详情】Apple CUPS（Common Unix Printing System）是美国苹果（Apple）公司的一套开源的用于OS X和类Unix系统的打印系统。该系统基于Internet打印协议（IPP），提供大多数PostScript和raster打印机服务。

Apple CUPS 2.2.6之前版本中的‘add_job’函数存在安全漏洞。远程攻击者可通过发送带有无效用户名的打印请求利用该漏洞造成拒绝服务（崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/apple/cups/releases/tag/v2.2.6

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-933
