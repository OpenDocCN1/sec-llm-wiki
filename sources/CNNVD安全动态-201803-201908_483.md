# CNNVD最新漏洞（2018-03-23）

今日CNNVD共发布安全漏洞42个，更新安全漏洞7个。主要影响厂商为荷兰Philips（8个）、德国Geutebrück（6个）、美国NetIQ（3个）。主要影响产品为Philips IntelliSpace Portal（ISP）系统（7个）、Geutebrück G-Cam/EFD-2250和Topline TopFD-2125摄像机（6个）、NetIQ iManager应用程序（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Philips Intellispace Portal 输入验证漏洞**  

**【漏洞编号】****CNNVD-201803-772（CVE-2018-5474）**

**【漏洞详情】**Philips IntelliSpace Portal（ISP）是荷兰飞利浦（Philips）公司的一套心血管图像信息管理门户系统。该系统提供对回声影像的查看，并为医生提供单点访问功能。

Philips ISP 8.0.x版本和7.0.x版本中存在输入验证漏洞。远程攻击者可利用该漏洞执行任意代码或造成拒绝服务（应用程序崩溃）。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

http://incenter.medical.philips.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-772

  

**【漏洞名称】****Geutebrück G-Cam/EFD-2250和Topline TopFD-2125 授权问题漏洞**  

**【漏洞编号】******CNNVD-201803-761**（CVE-2018-7532）**

**【漏洞详情】**Geutebrück G-Cam/EFD-2250和Topline TopFD-2125都是德国Geutebrück公司的IP摄像机产品。

使用1.12.0.4版本固件的Geutebrück G-Cam/EFD-2250和使用3.15.1版本固件的Topline TopFD-2125中存在授权问题漏洞。远程攻击者可利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.geutebrueck.com//en\_EN/login.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-761

  

**【漏洞名称】******NetIQ iManager 跨站脚本漏洞****

**【漏洞编号】******CNNVD-201803-757**（CVE-2018-1347）**

**【漏洞详情】**NetIQ iManager是美国NetIQ公司的一款基于WEB的应用程序。可以使用无线设备管理、配置eDirectory对象。

NetIQ iManager 3.1之前版本中的管理Web界面存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.netiq.com/documentation/imanager-31/imanager31\_releasenotes/data/imanager31\_releasenotes.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-757

  

**【漏洞名称】******Delta Electronics WPLSoft 缓冲区错误漏洞****

**【漏洞编号】******CNNVD-201803-767**（CVE-2018-7494）**

**【漏洞详情】**Delta Electronics WPLSoft是Delta Electronics公司的一套用于编辑Delta DVP系列可编程逻辑控制器（PLC）的软件控制平台。

Delta Electronics WPLSoft 2.45.0及之前的版本中存在基于栈的缓冲区溢出漏洞，该漏洞源于程序使用了固定长度的栈缓冲区。远程攻击者可利用该漏洞执行代码或造成拒绝服务（应用程序崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.deltaww.com/Products/PluginWebUserControl/downloadCenterCounter.aspx?DID=5043&DocPath=1&hl=en-US

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-767

  

**【漏洞名称】****Linux kernel 安全漏洞**

**【漏洞编号】****CNNVD-201803-756（CVE-2017-18241）**

**【漏洞详情】**Linux kernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。

Linux kernel 4.13之前版本中的fs/f2fs/segment.c文件存在安全漏洞。本地攻击者可通过使用noflush\_merge选项利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=d4fdf8ba0e5808ba9ad6b44337783bd9935e0982

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-756
