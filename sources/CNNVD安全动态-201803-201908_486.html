1. Huawei Mate 9 Pro 数字错误漏洞（CNNVD-201803-291） 

Huawei Mate 9 Pro是中国华为（Huawei）公司的一款智能手机。

Huawei Mate 9 Pro LON-AL00BC00B139D版本和LON-AL00BC00B229版本中存在整数溢出漏洞，该漏洞源于程序没有校验外部的输入参数。攻击者可通过诱使用户安装特制的应用程序利用该漏洞执行恶意代码。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.huawei.com/cn/psirt/security-advisories/2018/huawei-sa-20180124-01-smartphone-cn

2. Microsoft SharePoint Enterprise Server 权限许可和访问控制漏洞(CNNVD-201803-487)

Microsoft SharePoint Enterprise Server是美国微软（Microsoft）公司的一套企业业务协作平台。该平台用于对业务信息进行整合，并能够共享工作、与他人协同工作、组织项目和工作组、搜索人员和信息。

Microsoft SharePoint Enterprise Server 2016中存在提权漏洞，该漏洞源于程序没有正确的过滤特制的Web请求。攻击者可通过发送特制的请求利用该漏洞获取提升的权限。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2018-0921
