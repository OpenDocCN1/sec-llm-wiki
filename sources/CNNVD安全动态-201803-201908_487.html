今日CNNVD共发布安全漏洞81个，更新安全漏洞7个。主要影响厂商为美国Google（26个）、美国SecurEnvoy（7个）、日本Omron（7个）。主要影响产品为Google Android操作系统（26个）、SecurEnvoy SecurMail应用程序（7个）、Omron CX-Supervisor控制器（7个）。

今日需关注的典型漏洞如下:

【漏洞名称】Android Qualcomm Diagchar 权限许可和访问控制漏洞

【漏洞编号】CNNVD-201803-616（CVE-2018-3561）

【漏洞详情】Android on Google Pixel和Nexus是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套运行于Google Pixel和Nexus（智能手机）中并以Linux为基础的开源操作系统。Qualcomm Diagchar是其中的一个美国高通（Qualcomm）公司的诊断驱动程序。

Google Pixel和Nexus设备上的Android中的Qualcomm Diagchar存在提权漏洞。攻击者可利用该漏洞获取权限（释放后重用）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://source.android.com/security/bulletin/pixel/2018-03-01

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-616


【漏洞名称】SecurEnvoy SecurMail 跨站脚本漏洞

【漏洞编号】CNNVD-201803-597（CVE-2018-7707）

【漏洞详情】SecurEnvoy SecurMail是美国SecurEnvoy公司的一款电子邮件应用程序。

SecurEnvoy SecurMail 9.2.501之前的版本中存在跨站脚本漏洞。远程攻击者可借助HTML格式的邮件信息利用该漏洞注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.securenvoy.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-597


【漏洞名称】Omron CX-Supervisor 缓冲区错误漏洞

【漏洞编号】CNNVD-201803-651（CVE-2018-7513）

【漏洞详情】Omron CX-Supervisor是日本欧姆龙（Omron）公司的一款可视化机器控制器。

Omron CX-Supervisor 3.30及之前版本中存在基于栈的缓冲区溢出漏洞。远程攻击者可借助畸形的项目文件利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.myomron.com/index.php?action=kb&article=1707

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-651


【漏洞名称】IBM Notes for Windows System Diagnostics service 安全漏洞

【漏洞编号】CNNVD-201803-367（CVE-2018-1437）

【漏洞详情】IBM Notes for Windows是美国IBM公司的一套基于Windows平台的协同办公软件。该软件具备电子邮件、日历、日程安排等办公功能。System Diagnostics service是其中的一个系统诊断服务。

基于Windows平台的IBM Notes中的System Diagnostics service存在安全漏洞。本地攻击者可利用该漏洞劫持DLL，在系统上执行任意代码或造成拒绝服务（崩溃）。以下版本受到影响：IBM Notes 9.0.1版本至9.0.1 FP10 IF1版本，9.0版本至9.0 IF4版本，8.5.3版本至8.5.3 FP6 IF15版本，8.5.2版本至8.5.2 FP4 IF3版本，8.5.1版本至8.5.1 FP5 IF3版本，8.5版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

http://www-01.ibm.com/support/docview.wss?uid=swg22014201

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-367


【漏洞名称】Pivotal Application Service Apps Manager for PCF 安全漏洞

【漏洞编号】CNNVD-201803-640（CVE-2018-1200）

【漏洞详情】Pivotal Application Service是美国Pivotal Software公司的一套应用程序管理软件。Apps Manager for PCF是其中的一个适用于PCF的应用程序管理器。

Pivotal Application Service 1.11.26之前的1.11.x版本、1.12.14之前的1.12.x版本和2.0.5之前的2.0.x版本中的Apps Manager for PCF存在安全漏洞。攻击者可借助特制的链接利用该漏洞读取文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://pivotal.io/security/cve-2018-1200

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-640
