# CNNVD最新漏洞（2018-03-14）

今日CNNVD共发布安全漏洞55个，更新安全漏洞15个。主要影响厂商为中国华为（21个）、日本Buffalo（3个）、英国Eramba（3个）。主要影响产品为Huawei DP300等终端（7个）、Buffalo WXR-1900DHP2路由器（3个）、Eramba应用程序（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****多款Huawei产品Signalling Connection Control Part模块缓冲区错误漏洞**  

**【漏洞编号】****CNNVD-201803-275（CVE-2017-17282）**

**【漏洞详情】**Huawei DP300等都是中国华为（Huawei）公司的产品。DP300是一款视频会议终端。RP200是一款视频会议一体机设备。SCCP（Signalling Connection Control Part）moudle是其中的一个信令链接控制模块。

多款Huawei产品中的SCCP模块存在缓冲区溢出漏洞，该漏洞源于程序没有充分的校验输入。攻击者可通过向受影响的产品重复发送畸形的数据包利用该漏洞造成服务异常。以下产品和版本受到影响：Huawei DP300 V500R002C00版本；RP200 V500R002C00版本，V600R006C00版本；TE30 V100R001C10版本，V500R002C00版本，V600R006C00版本；TE40 V500R002C00版本，V600R006C00版本；TE50 V500R002C00版本，V600R006C00版本；TE60 V100R001C10版本，V500R002C00版本，V600R006C00版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

http://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20180228-01-sccp-cn

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-275

  

**【漏洞名称】****Buffalo WXR-1900DHP2 缓冲区错误漏洞**  

**【漏洞编号】****CNNVD-201803-319（CVE-2018-0522）**

**【漏洞详情】**Buffalo WXR-1900DHP2是日本巴法络（Buffalo）集团的一款路由器产品。

使用2.48及之前版本固件的Buffalo WXR-1900DHP2中存在缓冲区溢出漏洞。攻击者可借助特制的文件利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

http://buffalo.jp/support\_s/s20180223.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-319

  

**【漏洞名称】****Eramba 跨站脚本漏洞**  

**【漏洞编号】****CNNVD-201803-310（CVE-2018-7997）**

**【漏洞详情】**Eramba是英国Eramba公司的一款开源的企业级IT治理应用程序。该程序具有IT安全、合规性审计分析等功能。

Eramba e1.0.6.033版本中的/importTool/preview URI的CSV file inclusion tab的错误页面存在跨站脚本漏洞，该漏洞源于程序没有正确的验证用户提交的输入。远程攻击者可通过导入特制的CSV文件利用该漏洞在用户浏览器中执行脚本。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

http://www.eramba.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-310

  

**【漏洞名称】****IBM Tivoli Business Service Manager 信息泄露漏洞**  

**【漏洞编号】****CNNVD-201803-288（CVE-2016-0286）**

**【漏洞详情】**IBM Tivoli Business Service Manager是美国IBM公司的一套企业级业务服务管理（BSM）解决方案。该方案提供了实时服务可视性和健康指示器、多个KPI历史时间分析和跟踪等。

IBM Tivoli Business Service Manager 6.1.0-TIV-BSM-FP0004之前的6.1.0版本和6.1.1-TIV-BSM-FP0004之前的6.1.1版本中存在信息泄露漏洞。远程攻击者可利用该漏洞获取管理员密码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg21986852

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-288

  

**【漏洞名称】****WordPress WP All Import插件跨站脚本漏洞**

**【漏洞编号】****CNNVD-201803-312（CVE-2018-0547）**

**【漏洞详情】**WordPress是WordPress软件基金会的一套使用PHP语言开发的博客平台，该平台支持在PHP和MySQL的服务器上架设个人博客网站。WP All Import plugin是使用在其中的一个文件导入插件。

WordPress WP All Import插件3.4.7之前版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞注入任意的Web脚本或HTML。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/wp-all-import/#developers

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-312
