今日CNNVD共发布安全漏洞9个，更新安全漏洞49个。主要影响厂商为美国Linux（1个）、美国Abine（1个）。主要影响产品为Linux kernel内核（1个）、Abine Blur应用程序（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Linux kernel 安全漏洞**  

**【漏洞编号】****CNNVD-201803-270（CVE-2018-8043）**

**【漏洞详情】**Linux kernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。

Linux kernel 4.15.8及之前的版本中的drivers/net/phy/mdio-bcm-unimac.c文件的‘unimac\_mdio\_probe’函数存在安全漏洞，该漏洞源于程序没有验证特定的资源。本地攻击者可利用该漏洞造成拒绝服务（空指针逆向引用）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=297a6961ffb8ff4dc66c9fbf53b924bd1dda05d5

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-270

  

**【漏洞名称】****Abine Blur Password Manager Extension 安全漏洞**  

**【漏洞编号】****CNNVD-201803-269（CVE-2018-7213）**

**【漏洞详情】**Abine Blur是美国Abine公司的一款私人账户管理应用程序。Password Manager Extension是其中的一个密码管理插件。

Abine Blur 7.8.2428之前的7.8.242\*版本中的Password Manager Extension存在安全漏洞。远程攻击者可利用该漏洞绕过Multi-Factor身份验证和macOS磁盘加密保护机制，从而获取敏感数据。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://abine.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-269

  

**【漏洞名称】****AFFLIB 安全漏洞**  

**【漏洞编号】****CNNVD-201803-268（CVE-2018-8050）**

**【漏洞详情】**AFFLIB（又名AFFLIBv3）是一个用于操作高级取证格式(AFF)文件的开源函数库。

AFFLIB 3.7.16及之前版本中的lib/afflib\_pages.cpp文件的‘af\_get\_page()’函数存在安全漏洞。远程攻击者可借助损坏的FF图像利用该漏洞造成拒接服务（段错误）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/sshock/AFFLIBv3/commit/435a2ca802358a3debb6d164d2c33049131df81c

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-268

  

**【漏洞名称】****BMC Remedy AR System 安全漏洞**  

**【漏洞编号】****CNNVD-201803-273（CVE-2017-18223）**

**【漏洞详情】**BMC Remedy AR System是美国BMC Software公司的一套用于IT部门的移动数字化企业管理平台。

BMC Remedy AR System 9.1 SP3之前的版本中存在安全漏洞。当Remedy AR Authentication被打开时，攻击者可利用该漏洞获取管理权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://communities.bmc.com/thread/165887

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-273

  

**【漏洞名称】****Foxconn femtocell FEMTO AP-FC4064-T 安全漏洞**

**【漏洞编号】****CNNVD-201803-271（CVE-2018-6312）**

**【漏洞详情】**Foxconn femtocell FEMTO AP-FC4064-T是富士康（Foxconn）公司的一款家用基站设备。

Foxconn femtocell FEMTO AP-FC4064-T AP\_GT\_B38\_5.8.3lb15-W47 LTE Build 15版本中存在安全漏洞，该漏洞源于特权账户使用了较弱的默认密码。攻击者可借助Web界面利用该漏洞打开TELNET服务，控制系统并获取用户通信。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

http://www.foxconn.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-271
