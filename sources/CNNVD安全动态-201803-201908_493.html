1. Cisco Prime Data Center Network Manager 跨站脚本漏洞（CNNVD-201803-262）

Cisco Prime Data Center Network Manager（DCNM）是美国思科（Cisco）公司的一套数据中心网络管理器。该管理器可对网络进行多协议管理，并对交换机的运行状况和性能提供故障排除功能。

Cisco Prime DCNM版本中的基于Web的管理界面存在跨站脚本漏洞，该漏洞源于程序没有充分的校验用户提交的输入。远程攻击者可通过诱使该界面用户点击特制的链接利用该漏洞在界面的上下文中执行任意脚本代码或访问基于浏览器的敏感信息。

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bst.cloudapps.cisco.com/bugsearch/bug/CSCvg81051

2. Citrix NetScaler Application Delivery Controller和NetScaler Gateway 路径遍历漏洞（CNNVD-201803-146）

Citrix NetScaler Application Delivery Controller（ADC）和NetScaler Gateway（前称Citrix Access Gateway Enterprise Edition）都是美国思杰系统（Citrix Systems）公司的产品。NetScaler ADC是一套服务和应用交付解决方案（应用交付控制器）；NetScaler Gateway是一套安全的远程接入解决方案。

Citrix NetScaler ADC和NetScaler Gateway中存在目录遍历漏洞。远程攻击者可通过发送特制的请求利用该漏洞遍历目标系统上的目录。以下产品和版本受到影响：

-   Citrix NetScaler ADC 10.5版本

-   Citrix NetScaler ADC 11.0版本

-   Citrix NetScaler ADC 11.1版本

-   Citrix NetScaler ADC 12.0版本

-   Citrix NetScaler Gateway 10.5版本

-   Citrix NetScaler Gateway 11.0版本

-   Citrix NetScaler Gateway 11.1版本

-   Citrix NetScaler Gateway 12.0版本

解决措施：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.citrix.com/article/CTX232161
