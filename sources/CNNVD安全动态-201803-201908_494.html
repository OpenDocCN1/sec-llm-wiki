今日CNNVD共发布安全漏洞66个，更新安全漏洞6个。主要影响厂商为美国Cisco（21个）、美国IBM（4个）、美国Linux（3个）。主要影响产品为Cisco Identity Services Engine（ISE）平台（7个）、IBM Application Performance Management-Response Time Monitoring Agent监控代理（2个）、Linux kernel内核（3个）。

今日需关注的典型漏洞如下:

【漏洞名称】Cisco Identity Services Engine 命令注入漏洞

【漏洞编号】CNNVD-201803-246（CVE-2018-0221）

【漏洞详情】Cisco Identity Services Engine（ISE）是美国思科（Cisco）公司的一款基于身份的环境感知平台（ISE身份服务引擎）。该平台通过收集网络、用户和设备中的实时信息，制定并实施相应策略来监管网络。

Cisco ISE中的CLI命令存在命令注入漏洞，该漏洞源于程序没有充分对用户输入中的CLI ISE配置命令执行输入验证。本地攻击者可通过认证为管理用户，发送CLI命令并向命令参数中注入恶意的输入利用该漏洞向底层操作系统中注入命令或造成用户会话挂起或断开。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bst.cloudapps.cisco.com/bugsearch/bug/CSCvg95479

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-246


【漏洞名称】IBM Application Performance Management-Response Time Monitoring Agent 跨站请求伪造漏洞

【漏洞编号】CNNVD-201803-232（CVE-2018-1442）

【漏洞详情】IBM Application Performance Management-Response Time Monitoring Agent是美国IBM公司的一款用于应用程序性能管理的程序响应时间监控代理。

IBM Application Performance Management-Response Time Monitoring Agent中存在跨站请求伪造漏洞。远程攻击者可利用该漏洞执行未授权的操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www-01.ibm.com/support/docview.wss?uid=swg22013500

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-232


【漏洞名称】Linux kernel 安全漏洞

【漏洞编号】CNNVD-201803-240（CVE-2018-7757）

【漏洞详情】Linux kernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。

Linux kernel 4.15.7及之前版本中的drivers/scsi/libsas/sas_expander.c文件的‘sas_smp_get_phy_events’函数存在内存泄露漏洞。本地攻击者可借助/sys/class/sas_phy目录下文件的读取权限利用该漏洞造成拒绝服务（内存消耗）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=4a491b1ab11ca0556d2fda1ff1301e862a2d44c4

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-240

【漏洞名称】Micro Focus Universal CMDB Foundation Software 信息泄露漏洞

【漏洞编号】CNNVD-201802-778（CVE-2018-6487）

【漏洞详情】Micro Focus Universal CMDB Foundation Software是英国Micro Focus公司的一套资源管理软件。该软件提供自底向上包括IT基础架构的自动发现、数据模型建立、服务映射定义和服务影响分析等功能。

Micro Focus Universal CMDB Foundation Software中存在信息泄露漏洞。远程攻击者可利用该漏洞获取信息。以下版本受到影响：Micro Focus Universal CMDB Foundation Software 10.10版本，10.11版本，10.20版本，10.21版本，10.22版本，10.30版本，10.31版本，4.10版本，4.11版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://softwaresupport.softwaregrp.com/document/-/facetsearch/document/KM03091097

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-778


【漏洞名称】多款Siemens产品安全漏洞

【漏洞编号】CNNVD-201803-228（CVE-2018-4840）

【漏洞详情】Siemens DIGSI等都是德国西门子（Siemens）公司的产品。Siemens DIGSI是一款微机保护装置的配置操作软件。EN100 Ethernet module IEC 61850 variant是一款以太网模块产品。

多款Siemens产品中存在安全漏洞，该漏洞源于程序没有对重要的功能执行身份验证。远程攻击者可利用该漏洞上传已更改的设备配置，覆盖访问授权密码。以下产品和版本受到影响：Siemens DIGSI 4 4.92之前版本，EN100 Ethernet module IEC 61850 variant 4.30之前的版本；EN100 Ethernet module PROFINET IO variant；EN100 Ethernet module Modbus TCP variant；EN100 Ethernet module DNP3 variant；EN100 Ethernet module IEC 104 variant。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://cert-portal.siemens.com/productcert/pdf/ssa-203306.pdf

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-228
