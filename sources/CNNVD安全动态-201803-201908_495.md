今日CNNVD共发布安全漏洞48个，更新安全漏洞2个。主要影响厂商为美国Digium（4个）、美国Linux（3个）、美国Red Hat（2个）。主要影响产品为Digium Asterisk软件（4个）、Linux kernel内核（3个）、Red Hat keycloak软件（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****Digium Asterisk 安全漏洞**  

**【漏洞编号】****CNNVD-201802-743（CVE-2018-7287）**

**【漏洞详情】**Digium Asterisk是美国Digium公司的一套开源的电话交换机（PBX）系统软件。该软件支持语音信箱、多方语音会议、交互式语音应答(IVR)等。

Digium Asterisk 15.2.1之前的15.x版本中的res\_http\_websocket.c文件存在拒绝服务漏洞，该漏洞源于程序没有正确的处理大小为0的WebSocket载荷。攻击者可利用该漏洞造成拒绝服务（崩溃）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://issues.asterisk.org/jira/browse/ASTERISK-27658

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-743

  

**【漏洞名称】****Linux kernel 安全漏洞**  

**【漏洞编号】****CNNVD-201802-772（CVE-2018-7273）**

**【漏洞详情】**Linux kernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。

Linux kernel 4.15.4及之前版本中存在安全漏洞，该漏洞源于floppy驱动程序使用printk调用来显示内存函数和全局变量的地址。攻击者可利用该漏洞读取dmesg中的信息，并使用该地址获取内核代码和数据的位置，绕过安全保护（例如：KASLR）。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.kernel.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-772

  

**【漏洞名称】****Red Hat keycloak 安全漏洞**  

**【漏洞编号】****CNNVD-201802-756（CVE-2017-12161）**

**【漏洞详情】**Red Hat keycloak是美国红帽（Red Hat）公司的一套为现代应用和服务提供身份验证和管理功能的软件。

Red Hat keycloak 3.4.2 final之前版本中存在安全漏洞。攻击者可通过构造恶意的密码重置请求利用该漏洞获取有效的重置令牌，造成信息泄露。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：  

https://github.com/keycloak/keycloak-documentation/pull/268/commits/a2b58aadee42af2c375b72e86dffc2cf23cc3770

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201802-756

  

**【漏洞名称】****WordPress Giribaz File Manager插件安全漏洞**  

**【漏洞编号】****CNNVD-201803-190（CVE-2018-7204）**

**【漏洞详情】**WordPress是WordPress软件基金会的一套使用PHP语言开发的博客平台，该平台支持在PHP和MySQL的服务器上架设个人博客网站。Giribaz File Manager plugin是使用在其中的一个文件管理插件。

WordPress Giribaz File Manager插件5.0.2之前版本中的inc/logger.php文件存在安全漏洞，该漏洞源于程序没有保护添加到log.txt文档的wp-config.php内容。攻击者可利用该漏洞获取敏感信息（例如：数据库凭证）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/file-manager/#developers

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-190

  

**【漏洞名称】****Google Chrome OS 安全漏洞**  

**【漏洞编号】CNNVD-201803-211（CVE-2016-5179）**

**【漏洞详情】**Google Chrome OS是美国谷歌（Google）公司开发的一套基于Web的快速、轻量型的开源操作系统。

Google Chrome OS 53.0.2785.144之前版本中存在安全漏洞。远程攻击者可利用该漏洞在启动时执行任意命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://chromereleases.googleblog.com/2016/09/stable-channel-updates-for-chrome-os.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-211
