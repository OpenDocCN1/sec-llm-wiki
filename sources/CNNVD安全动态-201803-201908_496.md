今日CNNVD共发布安全漏洞66个，更新安全漏洞2个。主要影响厂商为美国NVIDIA（5个）、美国Citrix Systems（4个）、美国Red Hat（2个）。主要影响产品为NVIDIA SHIELD TV游戏主机设备（5个）、Citrix NetScaler Application Delivery Controller（ADC）和NetScaler解决方案（4个）、Red Hat oVirt虚拟化管理平台（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****NVIDIA SHIELD TV TrustZone Software DRM应用程序安全漏洞**  

**【漏洞编号】****CNNVD-201803-175（CVE-2017-6296）**

**【漏洞详情】**NVIDIA SHIELD TV是美国英伟达（NVIDIA）公司的一款游戏主机设备。TrustZone Software是其中的一个系统范围的安全软件。DRM application是其中的一个数字版权管理应用程序。

NVIDIA SHIELD TV SE 6.2及之前版本中的TrustZone Software的DRM应用程序存在安全漏洞。攻击者可利用漏洞造成拒绝服务或可能提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://nvidia.custhelp.com/app/answers/detail/a\_id/4631

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-175

  

**【漏洞名称】****Citrix NetScaler Application Delivery Controller和NetScaler Gateway 跨站脚本漏洞**  

**【漏洞编号】****CNNVD-201803-145（CVE-2018-6811）**

**【漏洞详情】**Citrix NetScaler Application Delivery Controller（ADC）和NetScaler Gateway（前称Citrix Access Gateway Enterprise Edition）都是美国思杰系统（Citrix Systems）公司的产品。NetScaler ADC是一套服务和应用交付解决方案（应用交付控制器）；NetScaler Gateway是一套安全的远程接入解决方案。

Citrix NetScaler ADC和NetScaler Gateway中存在多个跨站脚本漏洞。远程攻击者可借助Citrix NetScaler界面利用该漏洞注入任意的Web脚本或HTML。以下产品和版本受到影响:Citrix NetScaler ADC 10.5版本，11.0版本，11.1版本，12.0版本；NetScaler Gateway 10.5版本，11.0版本，11.1版本，12.0版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.citrix.com/article/CTX232161

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-145

  

**【漏洞名称】****Red Hat oVirt 安全漏洞**  

**【漏洞编号】****CNNVD-201803-183（CVE-2018-1062）**

**【漏洞详情】**Red Hat oVirt是美国红帽（Red Hat）公司的一套开源的虚拟化管理平台，是RHEV（企业虚拟化平台）的开源版本，由ovirt-node客户端和overt-engine管理端组成。

Red Hat oVirt 4.1.9之前的4.1.x版本中存在安全漏洞，该漏洞源于当磁盘被移除时，程序没有清除数据。攻击者可利用该漏洞获取敏感数据。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.ovirt.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-183

  

**【漏洞名称】****Micro Focus Operations Orchestration Software 安全漏洞**  

**【漏洞编号】****CNNVD-201803-100（CVE-2018-6490）**

**【漏洞详情】**Micro Focus Operations Orchestration Software是英国Micro Focus公司的一套IT流程自动化解决方案。该方案能够自动化管理IT任务、运维和流程，以及通过生成文档和报告功能增强审计合规性。

Micro Focus Operations Orchestration Software 10.x版本中存在拒绝服务漏洞。远程攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://softwaresupport.softwaregrp.com/document/-/facetsearch/document/KM03103896

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-100

  

**【漏洞名称】****Samsung Display Solutions App for Android 安全漏洞**  

**【漏洞编号】CNNVD-201803-153（CVE-2018-6019）**

**【漏洞详情】**Samsung Display Solutions App for Android是韩国三星（Samsung）公司开发的一款基于Android平台的用于浏览Samsung显示设备的移动应用程序。

基于Android平台的Samsung Display Solutions App 3.02之前版本中存在安全漏洞，该漏洞源于程序没有加密传输的数据。攻击者可通过实施中间人攻击利用该漏洞伪造B2B内容。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.samsung.com  

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201803-153
