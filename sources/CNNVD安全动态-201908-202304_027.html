1.Apache Portable Runtime 缓冲区错误漏洞（CNNVD-202301-2413）

  Apache Portable Runtime（Apache可移植运行库）是美国阿帕奇（Apache）基金会的一个为上层应用程序提供可跨越多个操作系统平台使用的底层支持接口库。

  Apache Portable Runtime 1.7.0版本及之前版本存在缓冲区错误漏洞。攻击者利用该漏洞通过apr_socket_sendv()函数导致整数溢出，从而可以在栈缓冲区末端之外的地方写入数据。

  目前厂商已发布升级补丁以修复漏洞，参考链接：

 https://lists.apache.org/thread/5pfdfn7h0vsdo5xzjn97vghp0x42jj2r

2. WordPress plugin Widgets for Google Reviews 跨站脚本漏洞（CNNVD-202301-2320）

  WordPress和WordPress plugin都是WordPress基金会的产品。WordPress是一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。WordPress plugin是一个应用插件。

  WordPress plugin Widgets for Google Reviews 9.8之前版本存在跨站脚本漏洞，该漏洞源于在将某些属性回显至页面之前不会验证和转义这些属性。攻击者利用该漏洞可执行跨站脚本攻击。

  目前厂商已发布升级补丁以修复漏洞，参考链接：

 https://wpscan.com/vulnerability/7c4e51b3-87ef-4afc-ab53-9a9bbdcfc9d7

3. Dell Rugged Control Center 安全漏洞（CNNVD-202302-013）

  Dell Rugged Control Center是美国戴尔（Dell）公司的一个应用程序。该程序允许在设备上做一系列设置，例如应用程序设置、键盘背光设置、夜间模式设置、隐身模式设置、窗口设置、天线开关设置和 GPS 设置。

  Dell Rugged Control Center 4.5之前版本存在安全漏洞，该漏洞源于在服务端点中对用户的输入验证不当导致。本地低权限攻击者利用该漏洞可进行权限升级。

  目前厂商已发布升级补丁以修复漏洞，参考链接：

https://www.dell.com/support/kbdoc/en-us/000206103/dsa-2022-281-dell
