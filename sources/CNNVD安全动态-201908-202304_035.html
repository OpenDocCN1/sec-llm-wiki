一、公开漏洞情况

  根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞361个，漏洞新增数量有所下降。从厂商分布来看WordPress基金会新增漏洞最多，有36个；从漏洞类型来看，跨站脚本类的安全漏洞占比最大，达到18.28%。新增漏洞中，超危漏洞9个，高危漏洞53个，中危漏洞288个，低危漏洞11个。相应修复率分别为100.00%、94.34%、82.64%和90.91%。根据补丁信息统计，合计307个漏洞已有修复补丁发布，整体修复率为85.04%。

1.WordPress Plugin Paytium 跨站脚本漏洞（CNNVD-202212-3926）

  WordPress和WordPress plugin都是WordPress基金会的产品。WordPress是一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。WordPress plugin是一个应用插件。

  WordPress Plugin Paytium 4.3.6版本及之前版本存在跨站脚本漏洞，该漏洞源于程序没有清理和转义某些设置，攻击者利用该漏洞可以执行存储型跨站脚本攻击。

  目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wpscan.com/vulnerability/8ec76242-717d-4d2d-9c0f-3056cd7c2c90

2. NVIDIA vGPU Software 安全漏洞（CNNVD-202212-4187）

  NVIDIA vGPU Software是美国英伟达（NVIDIA）公司的一个用于为虚拟机提供GPU功能的管理软件。该软件支持多个虚拟机访问主机的GPU，为虚拟机提供图形性能和应用程序兼容性。

  NVIDIA vGPU Software 存在安全漏洞，该漏洞源于在虚拟GPU管理器中，没有验证用户输入，从而导致缓冲区溢出、数据篡改、信息泄露或拒绝服务。

  目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://nvidia.custhelp.com/app/answers/detail/a_id/5415

3. Esri Portal For ArcGIS 代码问题漏洞（CNNVD-202212-4112）

  Esri Portal For ArcGIS是美国环境系统研究所（Esri）公司的一种允许在组织内与其他人共享地图、场景、应用程序和其他地理信息的组件。

  Esri Portal for ArcGIS 10.9.1版本及之前版本存在代码问题漏洞。远程攻击者利用该漏洞伪造成正常的URL请求，从而可以在网络上监视受害者活动的IP地址。

  目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.esri.com/arcgis-blog/products/trust-arcgis/administration/portal-for-arcgis-security-2022-update-2-patch-is-now-available/
