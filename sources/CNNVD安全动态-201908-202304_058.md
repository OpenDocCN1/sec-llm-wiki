  根据国家信息安全漏洞库（CNNVD）统计，本周（2022年9月26日至2022年10月2日）安全漏洞情况如下**：**  

**公开漏洞情况**

  本周CNNVD采集安全漏洞340个。

**接报漏洞情况**

  本周CNNVD接报漏洞15328个，其中信息技术产品漏洞（通用型漏洞）24个，网络信息系统漏洞（事件型漏洞）92个，漏洞平台推送漏洞15212个。

**一、公开漏洞情况**

   根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞340个，漏洞新增数量有所下降。从厂商分布来看思科公司新增漏洞最多，有27个；从漏洞类型来看，SQL注入类的安全漏洞占比最大，达到10.88%。新增漏洞中，超危漏洞40个，高危漏洞134个，中危漏洞155个，低危漏洞11个。相应修复率分别为60.00%、70.15%、73.55%和100.00%。根据补丁信息统计，合计243个漏洞已有修复补丁发布，整体修复率为71.47%。

**1.****Amazon AWS Redshift JDBC Driver ****代码问题漏洞（CNNVD-202209-3090）**

  Amazon AWS是美国亚马逊（Amazon）公司的一款云计算平台，向个人、企业和政府提供一系列包括信息技术基础架构和应用的服务，如存储、数据库、计算、机器学习等等。

  Amazon AWS Redshift JDBC Driver 2.1.0.8之前版本存在安全漏洞，该漏洞源于在执行类实例化对象的操作时没有检查数据类型。

  目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/aws/amazon-redshift-jdbc-driver/commit/40b143b4698faf90c788ffa89f2d4d8d2ad068b5

**2. ****Google Chrome ****安全漏洞（CNNVD-202209-2779）**

  Google Chrome是美国谷歌（Google）公司的一款Web浏览器。

  Google Chrome 106之前版本存在安全漏洞，该漏洞源于在Assistant（搭载人工智能的虚拟助手）中存在内存释放后重用问题。

  目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://chromereleases.googleblog.com/2022/09/stable-channel-update-for-desktop\_27.html

**3. ****Microsoft Exchange Server ****安全漏洞（CNNVD-202210-001）**

  Microsoft Exchange Server是美国微软（Microsoft）公司的一套电子邮件服务程序。它提供邮件存取、储存、转发，语音邮件，邮件过滤筛选等功能。

  Microsoft Exchange Server存在安全漏洞。攻击者利用该漏洞可以提升权限。

  目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2022-41040
