公开漏洞情况

接报漏洞情况

  本周CNNVD接报漏洞2224个，其中信息技术产品漏洞（通用型漏洞）92个，网络信息系统漏洞（事件型漏洞）175个，漏洞平台推送漏洞1957个。









一、公开漏洞情况

  根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞375个，漏洞新增数量有所下降。从厂商分布来看Jenkins公司新增漏洞最多，有42个；从漏洞类型来看，跨站脚本类的安全漏洞占比最大，达到7.73%。新增漏洞中，超危漏洞30个，高危漏洞97个，中危漏洞228个，低危漏洞20个。相应修复率分别为66.67%、82.47%、61.84%和100.00%。根据补丁信息统计，合计261个漏洞已有修复补丁发布，整体修复率为69.60%。

1.WordPress plugin WP Visitor Statistics SQL注入漏洞（CNNVD-202207-2340）

  WordPress和WordPress plugin都是WordPress基金会的产品。WordPress是一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。WordPress plugin是一个应用插件。

  WordPress plugin WP Visitor Statistics 5.7版本及之前版本存在SQL注入漏洞。攻击者利用该漏洞执行SQL注入攻击。

  目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://wordpress.org/plugins/wp-stats-manager/#developers

2. Mozilla Firefox 缓冲区错误漏洞（CNNVD-202207-2407）

  Mozilla Firefox是美国Mozilla基金会的一款开源Web浏览器。

  Mozilla Firefox 90.0版本至102.0.1版本存在缓冲区错误漏洞，该漏洞源于在处理HTML 内容时出现边界错误。远程攻击者利用该漏洞可以创建特制网站，诱骗受害者打开它，触发内存损坏并在目标系统上执行任意代码。

  目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.mozilla.org/en-US/security/advisories/mfsa2022-28/

3. IBM Sterling Partner Engagement Manager 安全漏洞（CNNVD-202207-2468）

  IBM Sterling Partner Engagement Manager是美国IBM公司的一个自动化管理工具。

  IBM Sterling Partner Engagement Manager 6.1版本、6.2版本和 Cloud 22.2版本存在安全漏洞。攻击者利用该漏洞可以执行拒绝服务攻击。

  目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.ibm.com/support/pages/node/6606969
