  根据国家信息安全漏洞库（CNNVD）统计，本周（2022年6月27日至2022年7月3日）安全漏洞情况如下：

公开漏洞情况

  本周CNNVD采集安全漏洞481个。

接报漏洞情况

  本周CNNVD接报漏洞4070个，其中信息技术产品漏洞（通用型漏洞）169个，网络信息系统漏洞（事件型漏洞）532个，漏洞平台推送漏洞3369个。


 

一、公开漏洞情况

  根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞481个，漏洞新增数量有所上升。从厂商分布来看WordPress基金会新增漏洞最多，有48个；从漏洞类型来看，跨站脚本类的安全漏洞占比最大，达到8.52%。新增漏洞中，超危漏洞50个，高危漏洞116个，中危漏洞268个，低危漏洞47个。相应修复率分别为92.00%、76.72%、77.24%和68.09%。根据补丁信息统计，合计374个漏洞已有修复补丁发布，整体修复率为77.75%。

1.WordPress plugin HTML2WP 代码问题漏洞（CNNVD-202206-2581）

  WordPress和WordPress plugin都是WordPress基金会的产品。WordPress是一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。WordPress plugin是一个应用插件。

  WordPress plugin HTML2WP 1.0.0版本及之前版本存在代码问题漏洞，该漏洞源于在导入文件时没有进行授权和跨站请求伪造检查。攻击者利用该漏洞可以在远程服务器上传任意文件。

  目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wpscan.com/vulnerability/c36d0ea8-bf5c-4af9-bd3d-911eb02adc14

2. Mozilla Firefox 缓冲区错误漏洞（CNNVD-202206-2680）

  Mozilla Firefox是美国Mozilla基金会的一款开源Web浏览器。

  Mozilla Firefox 102版本和Firefox ESR 91.11版本存在安全漏洞，该漏洞源于Firefox存在内存损坏问题。攻击者利用该漏洞可以执行任意代码。

  目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.mozilla.org/en-US/security/advisories/mfsa2022-24/

3. Linux kernel 安全漏洞（CNNVD-202206-2868）

  Linux kernel是美国Linux基金会的开源操作系统Linux所使用的内核。

  Linux kernel存在安全漏洞。攻击者利用该漏洞通过nft_set_desc_concat_parse() 函数触发缓冲区溢出，从而导致拒绝服务并可能运行代码。

  目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/net/netfilter/nf_tables_api.c?id=fecf31ee395b0295f2d7260aa29946b7605f7c85
