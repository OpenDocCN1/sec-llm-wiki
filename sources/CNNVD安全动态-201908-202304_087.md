  根据国家信息安全漏洞库（CNNVD）统计，本周（2022年6月20日至2022年6月26日）安全漏洞情况如下：

  

**公开漏洞情况**

  

  本周CNNVD采集安全漏洞435个。

**接报漏洞情况**

  本周CNNVD接报漏洞5972个，其中信息技术产品漏洞（通用型漏洞）108个，网络信息系统漏洞（事件型漏洞）39个，漏洞平台推送漏洞5825个。

  

  

  

**一、公开漏洞情况**

   根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞435个，漏洞新增数量有所下降。从厂商分布来看Jenkins公司新增漏洞最多，有44个；从漏洞类型来看，跨站脚本类的安全漏洞占比最大，达到10.57%。新增漏洞中，超危漏洞31个，高危漏洞117个，中危漏洞274个，低危漏洞13个。相应修复率分别为87.10%、79.49%、72.99%和61.54%。根据补丁信息统计，合计328个漏洞已有修复补丁发布，整体修复率为75.40%。

**1.****WordPress Plugin VaultPress ****安全漏洞（CNNVD-202206-2230）**

  WordPress和WordPress Plugin都是WordPress基金会的产品。WordPress是一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。WordPress Plugin是一个应用插件。

  WordPress Plugin VaultPress 1.8.4版本存在安全漏洞，该漏洞源于VaultPress缺少对数据的过滤转义。攻击者利用该漏洞可以进行代码注入攻击。

  目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

  https://wordpress.org/plugins/vaultpress/

**2. ****Schneider Electric IGSS Data Server ****缓冲区错误漏洞（CNNVD-202206-2008）**

  Schneider Electric IGSS Data Server是法国施耐德电气（Schneider Electric）公司的一个交互式图形Scada 系统的数据服务器。

  Schneider Electric IGSS Data Server 15.0.0.22140 之前版本存在缓冲区错误漏洞，该漏洞源于产品存在边界错误。远程攻击者可以利用该漏洞发送特制消息，触发内存损坏并在目标系统上执行任意代码。

  目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://download.schneider-electric.com/files?p\_enDocType=Security+and+Safety+Notice&p\_File\_Name=SEVD-2022-165-01\_IGSS\_Security\_Notification.pdf

**3. ****Redis Labs Redis ****安全漏洞（CNNVD-202206-2252）**

  Redis Labs Redis是美国Redis Labs公司的一套开源的使用ANSI C编写、支持网络、可基于内存亦可持久化的日志型、键值（Key-Value）存储数据库，并提供多种语言的API。

  Redis v7.0版本存在安全漏洞。攻击者利用该漏洞通过组件 streamGetEdgeID 导致内存泄漏。

  目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

 https://github.com/redis/redis/commit/4a7a4e42db8ff757cdf3f4a824f66426036034ef
