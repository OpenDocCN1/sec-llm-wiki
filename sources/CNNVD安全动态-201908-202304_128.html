  根据国家信息安全漏洞库（CNNVD）统计，本周（2022年1月24日至2022年1月30日）安全漏洞情况如下：

公开漏洞情况

本周CNNVD采集安全漏洞481个。

接报漏洞情况

本周CNNVD接报漏洞1678个，其中信息技术产品漏洞（通用型漏洞）40个，网络信息系统漏洞（事件型漏洞）739个，漏洞平台推送漏洞899个。

重大漏洞预警

Polkit 安全漏洞（CNNVD-202201-2343、CVE-2021-4034）：成功利用此漏洞的攻击者，可在默认配置下提升本地用户权限。Polkit 0.92-0.115版本均受此漏洞影响。目前，Polkit官方已发布新版本修复了漏洞，请用户及时确认是否受到漏洞影响，尽快采取修补措施。

  根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞481个，漏洞新增数量有所下降。从厂商分布来看WordPress基金会公司新增漏洞最多，有35个；从漏洞类型来看，输入验证错误类的安全漏洞占比最大，达到16.63%。新增漏洞中，超危漏洞66个，高危漏洞163个，中危漏洞243个，低危漏洞9个。相应修复率分别为72.73%、71.17%、56.79%和100.00%。根据补丁信息统计，合计311个漏洞已有修复补丁发布，整体修复率为64.66%。

1. Apache ShenYu 代码注入漏洞（CNNVD-202201-2298）

Apache ShenYu是美国阿帕奇（Apache）基金会的一个异步的，高性能的，跨语言的，响应式的 API 网关。

Apache ShenYu 2.4.0 和 2.4.1存在代码注入漏洞，攻击者可利用该漏洞对目标设备进行代码注入，从而导致远程代码执行。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lists.apache.org/thread/3zzmwvg3012tg306x8o893fvdcssx639

2.  WordPress plugin 跨站请求伪造漏洞（CNNVD-202201-2204）

WordPress plugin是WordPress开源的一个应用插件。

Wordpress PluginSimple Download Monitor 中存在跨站请求伪造漏洞，该漏洞源于产品未强制进行nonce 检查。攻击者可通过该漏洞导致日志泄漏、删除日志、删除缩略图等操作。WordpressPlugin Simple Download Monitor  3.9.9 之前版本受该漏洞影响。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wpscan.com/vulnerability/e94772af-39ac-4743-a556-52351ebda9fe

3.  IBM Security Guardium Insights 输入验证错误漏洞（CNNVD-202201-2482）

IBM Security Guardium Insights是美国IBM公司的一套数据安全解决方案。该产品支持数据分析、威胁警报、数据安全性审计和本地数据监控等功能。

IBM Security Guardium Insights 存在安全漏洞，该漏洞源于输入验证不正确导致，IBM Security Guardium Insights 3.0受该漏洞影响。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.ibm.com/support/pages/node/6550866

五、重大漏洞预警

Polkit安全漏洞的预警

近日，国家信息安全漏洞库（CNNVD）收到关于Polkit 安全漏洞（CNNVD-202201-2343、CVE-2021-4034）情况的报送。成功利用此漏洞的攻击者，可在默认配置下提升本地用户权限。Polkit 0.92-0.115版本均受此漏洞影响。目前，Polkit官方已发布新版本修复了漏洞，请用户及时确认是否受到漏洞影响，尽快采取修补措施。

.漏洞介绍

Polkit是一个在类 Unix操作系统中控制系统范围权限的组件，通过定义和审核权限规则，实现不同优先级进程间的通讯。Polkit存在于所有主流的Linux发行版的默认配置中，攻击者可通过修改环境变量来利用此漏洞，进而提升本地用户权限 。

.漏洞影响

  成功利用此漏洞的攻击者，可在默认配置下提升本地用户权限。Polkit 0.92-0.115版本均受此漏洞影响。

.修复建议

目前，Polkit官方已发布新版本修复了漏洞，请用户及时确认是否受到漏洞影响，尽快采取修补措施。官方链接如下：
https://github.com/freedesktop/polkit/tags
