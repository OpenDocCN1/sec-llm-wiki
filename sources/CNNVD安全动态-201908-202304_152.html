1. WordPress 插件跨站脚本漏洞（CNNVD-202111-705）

WordPress是Wordpress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。WordPress插件是WordPress开源的一个应用插件。

WordPress plugin 存在跨站脚本漏洞，该漏洞源于 TheSimple Download Monitor 插件在将其输出到某些页面之前对帖子元数据处理不当导致，攻击者可利用漏洞使用低权限用户执行跨站脚本攻击。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wpscan.com/vulnerability/4bb559b7-8dde-4c90-a9a6-d8dcfbea53a7

2.  Microsoft 3D Viewer 代码注入漏洞（CNNVD-202111-813）

Microsoft 3D Viewer是美国微软（Microsoft）公司的一款简化且快速的图形编辑应用程序。

Microsoft 3D Viewer存在代码注入漏洞。该漏洞源于外部输入数据构造代码段的过程中，网络系统或产品未正确过滤其中的特殊元素导致。攻击者可利用该漏洞生成非法的代码段，修改网络系统或组件的执行控制流。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-43209

3.  Microsoft Windows Defender 代码注入漏洞（CNNVD-202111-834）

Microsoft Windows Defender是美国微软（Microsoft）公司的一套Windows系统附带的防病毒软件。

Microsoft Windows Defender存在代码注入漏洞。该漏洞源于外部输入数据构造代码段的过程中，网络系统或产品未正确过滤其中的特殊元素。攻击者可利用该漏洞生成非法的代码段，修改网络系统或组件的执行控制流。以下产品和版本受到影响：Microsoft Malware Protection Engine。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-42298

五、重大漏洞预警

Palo Alto Networks GlobalProtect安全漏洞

近日，国家信息安全漏洞库（CNNVD）收到关于Palo Alto Networks GlobalProtect安全漏洞（CNNVD-202111-988、CVE-2021-3064）情况的报送。成功利用漏洞的攻击者，可以绕过身份验证破坏目标系统进程，并在目标系统实现远程代码执行。PAN-OS 8.1.17以下版本均受此漏洞影响。目前，Palo AltoNetworks官方已经发布了版本更新修复了该漏洞，建议用户及时确认产品版本，尽快采取修补措施。

.漏洞介绍

Palo Alto Networks GlobalProtect是美国Palo Alto Networks公司的一套网络防护软件。该软件可提供防火墙监控及威胁预防等功能。Palo Alto Networks中的GlobalProtect 接口和网关接口存在安全漏洞，攻击者可利用该漏洞可中断系统进程，并获取 root 权限，进而对目标系统实现远程代码执行。

.危害影响

成功利用漏洞的攻击者，可以绕过身份验证破坏目标系统进程，并在目标系统实现远程代码执行。PAN-OS 8.1.17以下版本均受此漏洞影响。

.修复建议

目前，Palo Alto Networks官方已经发布了版本更新修复了该漏洞，建议用户及时确认产品版本，尽快采取修补措施。Palo Alto Networks官方更新链接如下：

https://docs.paloaltonetworks.com/pan-os/9-0/pan-os-admin/software-and-content-updates/pan-os-software-updates.html
