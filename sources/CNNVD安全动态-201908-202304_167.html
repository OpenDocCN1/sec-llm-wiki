一、公开漏洞情况

  根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞769个，漏洞新增数量有所上升。从厂商分布来看WordPress基金会新增漏洞最多，有37个；从漏洞类型来看，跨站脚本类的安全漏洞占比最大，达到16.64%。新增漏洞中，超危漏洞97个，高危漏洞253个，中危漏洞379个，低危漏洞40个。相应修复率分别为80.41%、87.75%、82.59%和80%。根据补丁信息统计，合计645个漏洞已有修复补丁发布，整体修复率为83.88%。

1.  Apache DB DdlUtils 代码问题漏洞（CNNVD-202109-1960）

Apache DB DdlUtils是美国阿帕奇（Apache）基金会的一个易于使用的小型组件，用于处理数据库定义(DDL)文件。

Apache DB DdlUtils 1.0 存在代码问题漏洞，该漏洞源于使用ObjectInputStream.readObject时没有验证输入数据是否可以安全地反序列化。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lists.apache.org/thread.html/r3d7a8303a820144f5e2d1fd0b067e18d419421b58346b53b58d3fa72%40%3Cannounce.apache.org%3E

2.  Eclipse Che 安全漏洞（CNNVD-202109-1903）

Eclipse Che是Eclipse基金会的一套基于Java的开源在线集成开发环境（IDE）。

Eclipse Che 存在安全漏洞，该漏洞源于Eclipse Che版本6的一些语言栈的构建存在不安全的HTTP端点。攻击者可利用该漏洞用任意的二进制文件替换原来的二进制文件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bugs.eclipse.org/bugs/show_bug.cgi?id=540989

3.  Linux kernel 输入验证错误漏洞（CNNVD-202109-1946）

Linux kernel是美国Linux基金会的开源操作系统Linux所使用的内核。

Linux kernel存在安全漏洞，攻击者可利用该漏洞访问超出边界的内存，从而导致系统崩溃或内部内核信息泄漏。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://access.redhat.com/security/cve/cve-2021-41864
