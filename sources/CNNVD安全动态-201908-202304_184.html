一、公开漏洞情况

根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞218个，漏洞新增数量有所下降。从厂商分布来看福昕公司新增漏洞最多，有26个；从漏洞类型来看，跨站脚本类的安全漏洞占比最大，达到14.22%。新增漏洞中，超危漏洞29个，高危漏洞84个，中危漏洞98个，低危漏洞7个。相应修复率分别为82.76%、90.48%、85.71%和100.00%。根据补丁信息统计，合计191个漏洞已有修复补丁发布，整体修复率为87.61%。

1. Microsoft Visual Studio Code 安全漏洞（CNNVD-202107-2185）

Microsoft Visual Studio Code是美国微软（Microsoft）公司的一款开源的代码编辑器。

Visual Studio Code 1.3.0之前版本存在安全漏洞，该漏洞源于Visual Studio Code 的非官方vcode -phpmd(又名PHP混乱探测器)扩展存在问题。攻击者可利用该漏洞通过特制的phpmd.command值执行任意代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://marketplace.visualstudio.com/items?itemName=ecodes.vscode-phpmd

2. Linux kernel安全漏洞（CNNVD-202107-2003）

Linux kernel是美国Linux基金会的开源操作系统Linux所使用的内核。

Linux kernel 5.13.5及之前版本存在安全漏洞，该漏洞源于Linux kernel内核允许用户通过rtas参数导致主机操作系统内存损坏，进而触发漏洞。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=f62f3c20647ebd5fb6ecb8f0b477b9281c44c10a

3. IBM AIX 权限许可和访问控制问题漏洞（CNNVD-202107-2147）

  IBMAIX是美国IBM公司的一款为 IBM Power 体系架构开发的一种基于开放标准的 UNIX 操作系统。

  IBMAIX 存在权限许可和访问控制问题漏洞，本地用户可以利用KornShell (ksh)中的漏洞来获得根权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.ibm.com/blogs/psirt/security-bulletin-vulnerability-in-ksh-affects-aix-cve-2021-29741/
