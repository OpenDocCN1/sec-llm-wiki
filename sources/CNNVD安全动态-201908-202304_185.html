漏洞态势

根据国家信息安全漏洞库（CNNVD）统计，2021年7月份采集安全漏洞共1827个。

本月接报漏洞8348个，其中信息技术产品漏洞（通用型漏洞）3666个，网络信息系统漏洞（事件型漏洞）7982个，其中漏洞平台推送漏洞5990个。

重大漏洞预警

微软多个安全漏洞：包括MicrosoftWindows DNS 代码注入漏洞（CNNVD-202107-776、CVE-2021-34458）、Microsoft Windows Kernel 代码注入漏洞（CNNVD-202107-776、CVE-2021-34458）等多个漏洞。成功利用上述漏洞的攻击者可以在目标系统上执行任意代码、获取用户数据，提升权限等。微软多个产品和系统受漏洞影响。目前，微软官方已经发布漏洞修复补丁，建议用户及时确认是否受到漏洞影响，尽快采取修补措施。

Sonicwall SRA/SMA SQL注入漏洞（CNNVD-202107-1057）：成功利用漏洞的攻击者可以在未授权的情况下窃取内部敏感账户信息，进而控制目标设备。SonicWall:Secure Remote Access 8.x、SonicWall:SecureRemote Access 9.0.0.10-26sv、SonicWall:Secure Mobile Access8.x、SonicWall:Secure Mobile Access 9.0.0.10-26sv等版本均受漏洞影响。目前，SonicWall官方已发布版本更新修复了漏洞，建议用户及时确认是否受到漏洞影响，尽快采取修补措施。

  1. 1.    SonicWall SRA/SMA SQL注入漏洞（CNNVD-202107-1057）

Sonicwall SRA和SonicwallSMA都是美国SonicWall（Sonicwall）公司的应用于企业管理安全接入的安全防护产品。

SonicWallSRA/SMA存在SQL注入漏洞，该漏洞允许远程未经身份验证的攻击者执行SQL语句，窃取内部敏感账户信息和其他会话相关信息，进而完全控制目标设备。成功利用漏洞的攻击者可以在未授权的情况下窃取内部敏感账户信息，进而控制目标服务器。SonicWall:SecureRemoteAccess8.x、SonicWall:SecureRemoteAccess9.0.0.10-26sv、SonicWall:SecureMobileAccess8.x、SonicWall:SecureMobileAccess9.0.0.10-26sv等版本均受漏洞影响。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://psirt.global.sonicwall.com/vuln-detail/SNWLID-2021-0017

  1. 2.    WordPress 插件代码问题漏洞（CNNVD-202107-255）

WordPress 插件是WordPress开源的一个应用插件。

WordPress的JoomSport存在代码问题漏洞，该漏洞源于joomsport版本在5.1.8之前，注册了未经认证和未经认证的用户，未序列化的用户输入从shattr POST参数，导致PHP对象注入问题。攻击者可利用该漏洞导致更严重的RCE问题。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wpscan.com/vulnerability/fb6c407c-713c-4e83-92ce-4e5f791be696

  1. 3.    VMware ESXi 授权问题漏洞（CNNVD-202107-698）

Vmware VMwareESXi是美国威睿（Vmware）公司的一套可直接安装在物理服务器上的服务器虚拟化平台。

https://www.vmware.com/security/advisories/VMSA-2021-0014.html

4.1微软多个安全漏洞的预警

近日，微软官方发布了多个安全漏洞的公告，包括Microsoft Windows DNS 代码注入漏洞（CNNVD-202107-776、CVE-2021-34458）、Microsoft Windows Kernel 代码注入漏洞（CNNVD-202107-776、CVE-2021-34458）等多个漏洞。成功利用上述漏洞的攻击者可以在目标系统上执行任意代码、获取用户数据，提升权限等。微软多个产品和系统受漏洞影响。目前，微软官方已经发布漏洞修复补丁，建议用户及时确认是否受到漏洞影响，尽快采取修补措施。
. 漏洞介绍
2021年7月14日，微软发布了2021年7月份安全更新，共116个漏洞的补丁程序，CNNVD对这些漏洞进行了收录。本次更新主要涵盖了Windows操作系统、Dynamics、Exchange Server、Microsoft Office、Windows Storage Spaces Controller、Bing、SharePoint Server等。CNNVD对其危害等级进行了评价，其中超危漏洞1个、高危漏洞有74个，中危漏洞40个，低危漏洞1个。微软多个产品和系统版本受漏洞影响，具体影响范围可访问https://portal.msrc.microsoft.com/zh-cn/security-guidance查询。

4.2 SonicWall SRA/SMA SQL注入漏洞的预警

近日，国家信息安全漏洞库（CNNVD）收到关于Sonicwall SRA/SMA SQL注入漏洞（CNNVD-202107-1057）情况的报送。成功利用漏洞的攻击者可以在未授权的情况下窃取内部敏感账户信息，进而控制目标设备。SonicWall:Secure Remote Access 8.x、SonicWall:SecureRemote Access 9.0.0.10-26sv、SonicWall:Secure MobileAccess 8.x、SonicWall:Secure Mobile Access 9.0.0.10-26sv等版本均受漏洞影响。目前，SonicWall官方已发布版本更新修复了漏洞，建议用户及时确认是否受到漏洞影响，尽快采取修补措施。

. 漏洞介绍

SonicwallSRA和Sonicwall SMA系列产品均是SonicWall公司应用于企业管理安全接入的安全防护产品。该漏洞允许远程未经身份验证的攻击者执行SQL语句，窃取内部敏感账户信息和其他会话相关信息，进而完全控制目标设备。

. 危害影响

成功利用漏洞的攻击者可以在未授权的情况下窃取内部敏感账户信息，进而控制目标服务器。SonicWall:Secure Remote Access 8.x、SonicWall:SecureRemote Access 9.0.0.10-26sv、SonicWall:Secure MobileAccess 8.x、SonicWall:Secure Mobile Access 9.0.0.10-26sv等版本均受漏洞影响。

. 修复建议

目前，SonicWall官方已发布版本更新修复了漏洞，建议用户及时确认是否受到漏洞影响，尽快采取修补措施。官方链接如下：
