根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞276个，漏洞新增数量有所下降。从厂商分布来看Atlassian公司新增漏洞最多，有23个；从漏洞类型来看，跨站脚本类的安全漏洞占比最大，达到15.58%。新增漏洞中，超危漏洞38个，高危漏洞77个，中危漏洞157个，低危漏洞4个。相应修复率分别为39.47%、76.62%、68.15%和75.00%。根据补丁信息统计，合计184个漏洞已有修复补丁发布，整体修复率为66.67%。

**1. ****WordPress SQL****注入漏洞（CNNVD-202007-153）**

WordPress是WordPress（Wordpress）基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。

WordPress CodePeople Payment Form for PayPalPro 1.1.65之前版本中存在SQL注入漏洞。该漏洞源于基于数据库的应用缺少对外部输入的SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/payment-form-for-paypal-pro/#developers

**2. ****Mozilla Firefox ****缓冲区错误漏洞（CNNVD-202007-119）**

Mozilla Firefox是美国Mozilla基金会的一款开源Web浏览器。

Mozilla Firefox 77版本中存在缓冲区错误漏洞。攻击者可利用该漏洞损坏内存并执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.mozilla.org/en-US/security/advisories/mfsa2020-24/

**3. ****F5 BIG-IP ****跨站请求伪造漏洞（CNNVD-202007-055）**

  F5BIG-IP是美国F5公司的一款集成了网络流量管理、应用程序安全管理、负载均衡等功能的应用交付平台。

  F5BIG-IP中的TrafficManagement User Interface (TMUI)存在跨站请求伪造漏洞，该漏洞源于程序没有正确验证用户输入。远程攻击者可借助特制HTTP请求利用该漏洞执行恶意操作。以下产品及版本受到影响：F5 BIG-IP 15.0.0版本至15.1.0.3版本，14.1.0版本至14.1.2.5版本，13.1.0版本至13.1.3.3版本，12.1.0版本至12.1.5.1版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.f5.com/csp/article/K31301245
