一、公开漏洞情况

根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞557个，漏洞新增数量有所上升。从厂商分布来看Intel公司新增漏洞最多，有70个；从漏洞类型来看，缓冲区错误类的安全漏洞占比最大，达到10.23%。新增漏洞中，超危漏洞17个，高危漏洞125个，中危漏洞400个，低危漏洞15个。相应修复率分别为100%、86.4%、88 %和73.33%。根据补丁信息统计，合计488个漏洞已有修复补丁发布，整体修复率为87.61%。

1. Microsoft Intune 代码注入漏洞（CNNVD-202106-535）

Microsoft Intune是美国微软（Microsoft）公司的一种基于Microsoft云的管理工具，是Microsoft Endpoint Manager的一部分。用于管理移动设备和操作系统。它旨在以保护企业数据的方式为企业和BYOD设备提供统一的端点管理。

Microsoft Intune存在安全漏洞。以下产品和版本受到影响：Intune managementextension。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2021-31980

2. Microsoft Office SharePoint 代码注入漏洞（CNNVD-202106-491）

Microsoft SharePoint是美国微软（Microsoft）公司的一套企业业务协作平台。该平台用于对业务信息进行整合，并能够共享工作、与他人协同工作、组织项目和工作组、搜索人员和信息。

Microsoft Office SharePoint存在安全漏洞。以下产品和版本受到影响：Microsoft SharePointEnterprise Server 2016,Microsoft SharePoint Server 2019,Microsoft SharePointFoundation 2013 Service Pack 1。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2021-26420

3. WordPress 插件 SQL注入漏洞（CNNVD-202106-389）

  WordPress插件是WordPress开源的一个应用插件。

  WordPressplugin Video Embed 1.0及之前版本存在SQL注入漏洞，该漏洞源于插件的一个id GET参数没有进行验证，允许低特权用户执行SQL注入。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wpscan.com/vulnerability/a8fd8dd4-5b5e-462e-8dae-065d5e2d003a

五、重大漏洞预警

微软多个安全漏洞预警

  近日，微软官方发布了多个安全漏洞的公告，包括WindowsDefender安全漏洞（CNNVD-202106-545、CVE-2021-31985）、Microsoft Office Excel安全漏洞（CNNVD-202106-503、CVE-2021-31939）等多个漏洞。成功利用上述漏洞的攻击者可以在目标系统上执行任意代码、获取用户数据，提升权限等。微软多个产品和系统受漏洞影响。目前，微软官方已经发布漏洞修复补丁，建议用户及时确认是否受到漏洞影响，尽快采取修补措施。
