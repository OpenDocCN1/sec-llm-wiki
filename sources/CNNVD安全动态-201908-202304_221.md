**一、公开漏洞情况**

根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞329个，漏洞新增数量有所上升。从厂商分布来看思科公司新增漏洞最多，有45个；从漏洞类型来看，跨站脚本类的安全漏洞占比最大，达到14.29%。新增漏洞中，超危漏洞41个，高危漏洞121个，中危漏洞151个，低危漏洞16个。相应修复率分别为92.68%、92.56%、80.13%和93.75%。根据补丁信息统计，合计286个漏洞已有修复补丁发布，整体修复率为86.93%。

**1. ****Apache OFBiz ****代码问题漏洞（CNNVD-202103-1262）**

Apache OFBiz是美国阿帕奇（Apache）基金会的一套企业资源计划（ERP）系统。该系统提供了一整套基于Java的Web应用程序组件和工具。

Apache OFBiz prior to 17.12.06 存在安全漏洞，该漏洞源于不安全的反序列化，攻击者可利用该漏洞可以完全控制ApacheOFBiz系统。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lists.apache.org/thread.html/r3c1802eaf34aa78a61b4e8e044c214bc94accbd28a11f3a276586a31%40%3Cuser.ofbiz.apache.org%3E

**2. ****Netgear****多款产品缓冲区错误漏洞（CNNVD-202103-1350）**

Netgear是美国网件（Netgear）公司的一款路由器，可以连接两个或多个网络的硬件设备，在网络间起网关的作用。

Netgear多款产品存在缓冲区错误漏洞。经过身份验证的攻击者可以利用该漏洞导致基于堆栈的缓冲区溢出。以下产品及版本受到影响：RBW30 before 2.6.2.2, RBK852 before 3.2.17.12, RBK853 before 3.2.17.12,RBK854 before 3.2.17.12, RBR850 before 3.2.17.12, RBS850 before 3.2.17.12,RBK752 before 3.2.17.12, RBK753 before 3.2.17.12, RBK753S before 3.2.17.12,RBK754 before 3.2.17.12, RBR750 before 3.2.17.12, and RBS750 before 3.2.17.12。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://kb.netgear.com/000063011/Security-Advisory-for-Post-Authentication-Stack-Overflow-on-Some-WiFi-Routers-PSV-2020-0467

**3. ****Cisco IOS XE Software ****代码问题漏洞（CNNVD-202103-1395）**

Cisco IOS XE Software是美国思科（Cisco）公司的一个操作系统。用于企业有线和无线访问，汇聚，核心和WAN的单一操作系统，Cisco IOS XE降低了业务和网络的复杂性。

Cisco IOS XE Software 存在安全漏洞，该漏洞源于受影响的设备在检查某些DNS数据包时发生逻辑错误。攻击者可利用该漏洞导致受影响的设备重新加载。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-alg-dos-hbBS7SZE
