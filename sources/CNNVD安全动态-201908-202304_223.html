1. VMware vCenter Server 安全漏洞（CNNVD-202103-927）

VMware vCenter Server是美国威睿（VMware）公司的一套服务器和虚拟化管理软件。该软件提供了一个用于管理VMware vSphere环境的集中式平台，可自动实施和交付虚拟基础架构。

vCenter Server 存在安全漏洞，攻击者可利用该漏洞导致远程代码执行。  

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://security.netapp.com/advisory/ntap-20210315-0001/

2. Linux kernel 安全漏洞（CNNVD-202103-961）

Linux kernel是美国Linux基金会的开源操作系统Linux所使用的内核。

Linux kernel through 5.11.6 存在安全漏洞，该漏洞源于fastrpc.c不阻止用户应用程序发送内核RPC消息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=20c40794eb85ea29852d7bc37c55713802a543d6

3. Adobe Acrobat 和 Adobe Acrobat Reader 安全漏洞（CNNVD-202103-1146）

Adobe Acrobat和Adobe Acrobat Reader都是美国奥多比（Adobe）公司的产品。Adobe Acrobat是一套PDF文件编辑和转换工具。Adobe Acrobat Reader是一款PDF查看器。该软件用于打印，签名和注释 PDF。

Adobe Acrobat 和 Adobe Acrobat Reader 存在安全漏洞，该漏洞允许CoolType任意堆栈操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://helpx.adobe.com/security/products/acrobat/apsb21-09.html
