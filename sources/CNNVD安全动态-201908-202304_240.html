1. Apache Nutch 代码问题漏洞（CNNVD-202101-2043）

Apache Nutch是Apache基金会的一个基于Java的可扩展的爬虫软件。

Apache Nutch 1.18之前版本存在代码问题漏洞，该漏洞允许攻击者查看应用程序服务器文件系统上的文件，并与应用程序本身可以访问的任何后端或外部系统进行交互。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lists.apache.org/thread.html/r7ddfd680aa7ea001ca8da63bb23e3f8caa095a8b4f2261e46bade5c7@%3Cdev.nutch.apache.org%3E

2. Mozilla Firefox 安全漏洞（CNNVD-202101-1513）

    MozillaFirefox是美国Mozilla基金会的一款开源Web浏览器。

Mozilla Firefox 85.0之前版本存在安全漏洞。攻击者可以利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.mozilla.org/en-US/security/advisories/mfsa2021-03

3. IBM Security Guardium 安全漏洞（CNNVD-202101-2469）

IBM Security Guardium是美国IBM公司的一套提供数据保护功能的平台。该平台包括自定义UI、报告管理和流线化的审计流程构建等功能。

IBM Security Guardium 11.2 存在安全漏洞，该漏洞源于不适当的访问控制，允许经过身份验证的用户获得根访问权。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.ibm.com/support/pages/node/6408630

四、重大漏洞预警

SonicWall SSL-VPN

安全漏洞的预警

    近日，国家信息安全漏洞库（CNNVD）收到关于SonicWall SSL-VPN安全漏洞（CNNVD-202101-2409）情况的报送。成功利用漏洞的攻击者可以在未授权的情况下实现远程代码执行，进而控制目标设备。Sonic SMA 8.0.0.4之前的版本均受漏洞影响。目前，SonicWall官方已发布版本更新修复了漏洞，建议用户及时确认是否受到漏洞影响，尽快采取修补措施。

.漏洞介绍

SonicWall是硬件防火墙设备、VPN网关和网络安全解决方案的制造商，SonicWall SSL-VPN是SonicWALL的一款Vpn连接方案，该产品应用于远程安全连接。

漏洞源于SonicwallSSL-VPN引入旧版本的Linux内核，导致攻击者可以构造恶意的http请求注入系统命令，成功利用漏洞的攻击者可以在受影响设备获得nobody用户权限并执行任意命令，最终完全控制目标设备。

.危害影响

成功利用漏洞的攻击者可以在未授权的情况下实现远程代码执行，进而控制目标设备。Sonic SMA 8.0.0.4之前的版本均受漏洞影响。

.修复建议

目前，SonicWall官方已发布版本更新修复了漏洞，建议用户及时确认是否受到漏洞影响，尽快采取修补措施。官方链接如下：

    https://www.sonicwall.com/
