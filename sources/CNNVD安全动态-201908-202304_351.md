今日CNNVD共发布安全漏洞27个。主要影响厂商为中国福昕（4个）、美国Apache（3个）。主要影响产品为Foxit Reader PDF文档阅读器（4个）、Apache Web服务框架（2个）。

**今日需关注的典型漏洞如下:**

  
  
  
  
  

**【漏洞名称】****Foxit Reader JavaScript引擎资源管理错误漏洞**

**【漏洞编号】******CNNVD-202001-843（CVE-2019-5126）****

**【漏洞详情】**Foxit Reader是中国福昕（Foxit）公司的一款PDF文档阅读器。Foxit PDF Reader 9.7.0.29435版本中的JavaScript引擎存在资源管理错误漏洞。攻击者可通过诱使用户打开恶意的文件利用该漏洞执行任意代码。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www.foxitsoftware.com/support/security-bulletins.php

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-202001-843

  

  
  
  
  
  

**【漏洞名称】****Apache CXF 安全漏洞**

**【漏洞编号】****CNNVD-202001-831（CVE-2019-12423）**

**【漏洞详情】**Apache CXF是美国阿帕奇（Apache）软件基金会的一个开源的Web服务框架。该框架支持多种Web服务标准、多种前端编程API等。Apache CXF 3.3.5之前版本和3.2.12之前版本（带有OpenId Connect JWK Keys服务）中存在安全漏洞。攻击者可利用该漏洞获取私钥和密钥凭证。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：http://cxf.apache.org/security-advisories.data/CVE-2019-12423.txt.asc?version=1&modificationDate=1579178393000&api=v2

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-202001-831

  

  
  
  
  
  

**【漏洞名称】******HPE Superdome Flex Server 安全漏洞****

**【漏洞编号】**********CNNVD-202001-840****（CVE-2019-11998）****

**【漏洞详情】**HPE Superdome Flex Server是美国惠普企业公司（Hewlett Packard Enterprise，HPE）的一款模块化服务器产品。HPE Superdome Flex Server v3.20.186之前版本中存在安全漏洞，该漏洞源于程序没有对管理员命令进行正确的输入验证。攻击者可利用该漏洞绕过安全限制，获取信息或造成拒绝服务。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://support.hpe.com/hpsc/doc/public/display?docLocale=en\_US&docId=emr\_na-hpesbhf03978en\_us

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-202001-840

  

  
  
  
  
  

**【漏洞名称】****WordPress LearnDash LMS 跨站脚本漏洞**  

**【****漏洞****编号****】****CNNVD-202001-826（****CVE-2020-7108）**

**【漏洞详情】**WordPress是WordPress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。LearnDash LMS是使用在其中的一个学习管理系统构建插件。WordPress LearnDash LMS 3.1.2之前版本中的ld-profile搜索字段存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://wpvulndb.com/vulnerabilities/10026

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-202001-826
