今日CNNVD共发布安全漏洞263个。主要影响厂商为美国Oracle（205个）、美国CloudBees（7个）。主要影响产品为Oracle Enterprise Manager管理平台（40个）、CloudBees Jenkins集成工具（7个）。

**今日需关注的典型漏洞如下:**

  
  
  
  
  

**【漏洞名称】****Oracle E-Business Suite iSupport 安全漏洞**

**【漏洞编号】******CNNVD-202001-767（CVE-2020-2661）****

**【漏洞详情】**（Oracle）公司的一套全面集成式的全球业务管理软件。该软件提供了客户关系管理、服务管理、财务管理等功能。iSupport是其中的一个基于互联网的客户支持应用程序组件。

Oracle E-Business Suite 12.1.1版本至12.1.3版本和12.2.3版本至12.2.9版本中的iSupport的Others组件存在安全漏洞。攻击者可利用该漏洞未授权访问、更新、插入或删除数据，影响数据的保密性和完整性。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www.oracle.com/security-alerts/cpujan2020.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-202001-767

  

  
  
  
  
  

**【漏洞名称】****Oracle Virtualization VM VirtualBox 安全漏洞**

**【漏洞编号】****CNNVD-202001-556（CVE-2020-2674）**

**【漏洞详情】**Oracle Virtualization是美国甲骨文（Oracle）公司的一套虚拟化解决方案。该产品用于统一管理从应用程序到磁盘的整个硬件和软件体系，可实现从桌面到数据中心的虚拟化。VM VirtualBox是其中的一个虚拟机组件。

Oracle Virtualization中的VM VirtualBox 5.2.36之前版本、6.0.16之前版本和6.1.2之前版本的Core组件存在安全漏洞。攻击者可利用该漏洞控制Oracle VM VirtualBox，影响数据的保密性、完整性和可用性。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.oracle.com/security-alerts/cpujan2020.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-202001-556

  

  
  
  
  
  

**【漏洞名称】******Huawei Mate 20 安全漏洞****

**【漏洞编号】**********CNNVD-202001-779****（CVE-2020-1840）****

**【漏洞详情】**Huawei Mate 20是中国华为（Huawei）公司的一款智能手机。

Huawei Mate 20 10.0.0.175(C00E70R3P8)之前的版本中存在安全漏洞，该漏洞源于程序没有进行充分的认证。本地攻击者可利用该漏洞泄露信息，影响手机的可用性。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20200115-01-smartphone-cn

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-202001-779

  

  
  
  
  
  

**【漏洞名称】****Adobe Experience Manager 跨站脚本漏洞**  

**【****漏洞****编号****】****CNNVD-202001-622（****CVE-2019-16467）**

**【漏洞详情】**Adobe Experience Manager（AEM）是美国奥多比（Adobe）公司的一套可用于构建网站、移动应用程序和表单的内容管理解决方案。该方案支持移动内容管理、营销销售活动管理和多站点管理等。

Adobe Experience Manager 6.0至6.5版本中存在跨站脚本漏洞。攻击者可利用该漏洞导致信息泄露。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://helpx.adobe.com/security/products/experience-manager/apsb20-01.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-202001-622
