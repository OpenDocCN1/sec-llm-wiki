**一、公开漏洞情况**

根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞265个，漏洞新增数量有所上升。从厂商分布来看Qualcomm公司新增漏洞最多，有28个；从漏洞类型来看，跨站脚本类的安全漏洞占比最大，达到16.98%。本周新增漏洞中，超危漏洞8个，高危漏洞95个，中危漏洞138个，低危漏洞24个。相应修复率分别为37.50%、80.00%、64.49%和87.50%。根据补丁信息统计，合计189个漏洞已有修复补丁发布，整体修复率为71.32%。

**1.  Apache Olingo 安全漏洞（CNNVD-202001-321）**

Apache Olingo是美国阿帕奇（Apache）软件基金会的一款用于实现Open Data Protocol（OData，开放数据协议）的Java库。

Apache Olingo 4.0.0版本至4.7.0版本中存在安全漏洞。攻击者可利用该漏洞调用任意URL（包括内部资源） 。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://mail-archives.apache.org/mod\_mbox/olingo-user/202001.mbox/%3CCAGSZ4d6HwpF2woOrZJg\_d0SkHytXJaCtAWXa3ZtBn33WG0YFvw%40mail.gmail.com%3E

**2.  Mozilla Firefox和Mozilla Firefox ESR 缓冲区错误漏洞（CNNVD-202001-185）**

Mozilla Firefox和Mozilla Firefox ESR都是美国Mozilla基金会的产品。Mozilla Firefox是一款开源Web浏览器。Mozilla Firefox ESR是Firefox(Web浏览器)的一个延长支持版本。

基于Windows平台的Mozilla Firefox 72之前版本和Mozilla Firefox ESR 68.4之前版本中存在缓冲区错误漏洞。远程攻击者可借助特制的网站利用该漏洞执行任意代码或造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.mozilla.org/en-US/security/advisories/mfsa2020-01/

https://www.mozilla.org/en-US/security/advisories/mfsa2020-02/

**3.  Android ashmem组件安全漏洞（CNNVD-202001-161）**

Android是美国谷歌（Google）和开放手持设备联盟（简称OHA）的一套以Linux为基础的开源操作系统。ashmem是其中的一个提供匿名共享内存功能的组件。

Android中的ashmem组件的‘calc\_vm\_may\_flags’函数存在安全漏洞。攻击者可利用该漏洞向共享内存中进行任意写入操作，提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.google.cn/security/bulletin/pixel/2020-01-01.html
