今日CNNVD共发布安全漏洞49个。主要影响厂商为美国Cisco（12个）、中国华为（3个）。主要影响产品为Cisco Data Center Network Manager管理系统（12个）、Huawei P30智能手机（1个）。

**今日需关注的典型漏洞如下:**

  
  
  
  
  

**【漏洞名称】****Cisco Data Center Network Manager SQL注入漏洞**

**【漏洞编号】******CNNVD-202001-038（CVE-2019-15984）****

**【漏洞详情】**Cisco Data Center Network Manager是美国思科（Cisco）公司的一套数据中心管理系统。该系统适用于Cisco Nexus和MDS系列交换机，提供存储可视化、配置和故障排除等功能。

Cisco Data Center Network Manager 11.3(1)之前版本中的REST API存在SQL注入漏洞，该漏洞源于程序没有充分验证提交到该API的用户输入。远程攻击者可通过发送特制的请求利用该漏洞执行任意的SQL命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20200102-dcnm-sql-inject

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-202001-038

  

  
  
  
  
  

**【漏洞名称】****Huawei P30 信息泄露漏洞**

**【漏洞编号】****CNNVD-202001-044（CVE-2019-19441）**

**【漏洞详情】**Huawei P30是中国华为（Huawei）公司的一款智能手机。

Huawei P30 10.0.0.166(C00E66R1P11)之前版本中存在信息泄露漏洞。攻击者可通过在局域网内发送命令利用该漏洞导致信息泄露。     

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20200102-02-smartphone-cn

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-202001-044

  

  
  
  
  
  

**【漏洞名称】******WordPress Postie 跨站脚本漏洞****

**【漏洞编号】**********CNNVD-202001-004****（CVE-2019-20204）****

**【漏洞详情】**WordPress是WordPress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。Postie是使用在其中的一个支持使用电子邮件发布帖子的插件。

WordPress Postie 1.9.40版本中存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/postie/#developers

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-202001-004

  

  
  
  
  
  

**【漏洞名称】****OpenCV 缓冲区错误漏洞**  

**【****漏洞****编号****】****CNNVD-202001-048（CVE-2019-5063）**

**【漏洞详情】**OpenCV是一款开源的、跨平台的、轻量级计算机视觉库。

OpenCV 4.1.0版本中的‘persistence’模式存在缓冲区错误漏洞。该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://opencv.org/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-202001-048
