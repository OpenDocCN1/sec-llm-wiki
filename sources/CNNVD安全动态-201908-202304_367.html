今日CNNVD共发布安全漏洞28个。主要影响厂商为德国MailStore（1个）、中国腾讯（1个）。主要影响产品为ezXML文档解析库（5个）、ZenPhoto管理系统（4个）。

今日需关注的典型漏洞如下:






【漏洞名称】MailStore Server和MailStore Server Service Provider Edition 授权问题漏洞

【漏洞编号】CNNVD-201912-1523（CVE-2019-10229）

【漏洞详情】MailStore Server是德国MailStore公司的一套电子邮件存储解决方案。该产品主要用于电子邮件归档、电子邮件管理和电子邮件存储等功能。MailStore Server Service Provider Edition是MailStore Server的服务版。
MailStore Server 9.6版本至11.2.1版本和MailStore Server Service Provider Edition 9.6版本至11.2.1版本中存在授权问题漏洞。该漏洞源于网络系统或产品中缺少身份验证措施或身份验证强度不足。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://help.mailstore.com/security/MAILSTORE-SA-2019-01.txt

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-1523







【漏洞名称】Tencent WeChat 命令注入漏洞

【漏洞编号】CNNVD-201912-1546（CVE-2019-17151）

【漏洞详情】Tencent WeChat是中国腾讯（Tencent）公司的一款在线社交应用程序。该程序支持发送语音短信、视频、图片和文字等。
Tencent WeChat中存在命令注入漏洞，该漏洞源于程序在执行系统调用之前没有正确验证用户提交的字符串。攻击者可利用该漏洞在当前进程的上下文中执行代码。
目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：
http://www.tencent.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-1546







【漏洞名称】Pure-FTPd 安全漏洞

【漏洞编号】CNNVD-201912-1525（CVE-2019-20176）

【漏洞详情】Pure-FTPd是一款FTP（文件传输协议）服务器。
Pure-FTPd 1.0.49版本中的ls.c文件的‘listdir’函数存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（栈耗尽）。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://github.com/jedisct1/pure-ftpd/commit/aea56f4bcb9948d456f3fae4d044fd3fa2e19706

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-1525







【漏洞名称】ZenPhoto 跨站请求伪造漏洞

【漏洞编号】CNNVD-201912-1541（CVE-2015-5595）

【漏洞详情】ZenPhoto是一套免费的图片库内容管理系统。该系统可管理图片，且支持音频、视频等多媒体。
Zenphoto 1.4.9之前版本中的admin.php文件存在跨站请求伪造漏洞。该漏洞源于WEB应用未充分验证请求是否来自可信用户。攻击者可利用该漏洞通过受影响客户端向服务器发送非预期的请求。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://www.zenphoto.org/news/zenphoto-1.4.9

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-1541
