# CNNVD最新漏洞（2019-12-30）

今日CNNVD共发布安全漏洞62个。主要影响厂商为中国磊科（7个）、法国ALE（3个）。主要影响产品为NETCORE Netis DL4323多功能调制解调器（7个）、ALE Alcatel-Lucent Omnivista 8770网络管理系统（2个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****NETCORE Netis DL4323 跨站请求伪造漏洞**

**【漏洞编号】******CNNVD-201912-1199（CVE-2019-20071）****

**【漏洞详情】**NETCORE Netis DL4323是中国磊科（NETCORE）公司的一款多功能调制解调器。

NETCORE Netis DL4323中存在跨站请求伪造漏洞。该漏洞源于WEB应用未充分验证请求是否来自可信用户。攻击者可利用该漏洞通过受影响客户端向服务器发送非预期的请求。

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：http://www.netis-systems.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-1199

  

**【漏洞名称】****ALE Alcatel-Lucent Omnivista 8770 安全漏洞**

**【漏洞编号】****CNNVD-201912-1183（CVE-2019-20048）**

**【漏洞详情】**ALE Alcatel-Lucent Omnivista 8770是法国ALE公司的一套网络管理系统。该产品包括警报通知、OmniPCX配置、性能分析和IP语音监控等功能。

ALE Alcatel-Lucent OmniVista 8770 4.1.2之前版本中存在安全漏洞。远程攻击者可利用该漏洞以SYSTEM权限执行代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www.al-enterprise.com/en/-/media/assets/internet/documents/sa-c0065-ov8770-rce-vulnerability-en.pdf

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-1183

  

**【漏洞名称】******WordPress 跨站脚本漏洞****

**【漏洞编号】**********CNNVD-201912-1163****（CVE-2019-20042）****

**【漏洞详情】**WordPress是WordPress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。

WordPress 5.3.1之前版本中存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://wordpress.org/news/2019/12/wordpress-5-3-1-security-and-maintenance-release/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912\-1163

  

  

**【漏洞名称】****GNU LibreDWG 资源管理错误漏洞**  

**【****漏洞****编号****】****CNNVD-201912-1145（CVE-2019-20010）**

**【漏洞详情】**GNU LibreDWG是GNU计划的一个用于处理DWG文件的C语言库。

GNU LibreDWG 0.92版本中decode.c文件的‘resolve\_objectref\_vector’函数存在资源管理错误漏洞。该漏洞源于网络系统或产品对系统资源（如内存、磁盘空间、文件等）的管理不当。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://github.com/LibreDWG/libredwg/issues/176

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-1145
