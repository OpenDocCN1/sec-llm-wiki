今日CNNVD共发布安全漏洞36个。主要影响厂商为美国IBM（7个）、美国Red Hat（1个）。主要影响产品为IBM Financial Transaction Manager for SWIFT Services金融事务管理器（4个）、Red Hat Ceph Storage存储平台（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****IBM Financial Transaction Manager for SWIFT Services 安全漏洞**  

**【漏洞编号】******CNNVD-201912-920（CVE-2019-4742）****

**【漏洞详情】**IBM Financial Transaction Manager for SWIFT Services是美国IBM公司的一款金融事务管理器产品。该产品主要用于监控、跟踪和报告金融支付和交易。

IBM Financial Transaction Manager for SWIFT Services 3.0.0版本中存在安全漏洞。远程攻击者可通过诱使用户访问恶意的网站利用该漏洞劫持用户点击操作。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www.ibm.com/support/pages/node/1135173

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-920

  

**【漏洞名称】****Red Hat Ceph Storage 输入验证错误漏洞    **

**【漏洞编号】****CNNVD-201912-946（CVE-2019-19337）**

**【漏洞详情】**Red Hat Ceph Storage是美国红帽（Red Hat）公司的一套可扩展的、开放性的软件定义存储平台。

Red Hat Ceph Storage 3版本中存在输入验证错误漏洞。该漏洞源于网络系统或产品未对输入的数据进行正确的验证。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：https://www.redhat.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-946

  

**【漏洞名称】******Cloud Foundry Cloud Controller API 信息泄露漏洞****

**【漏洞编号】**********CNNVD-201912-942****（CVE-2019-11294）****

**【漏洞详情】**Cloud Foundry是美国Cloud Foundry基金会的一套开源的平台即服务（PaaS）云计算平台。该产品提供容器调度、持续交付和自动化服务部署等功能。Cloud Controller API是其中的一个云控制器API（应用程序接口）。

Cloud Foundry Cloud Controller API 1.88.0版本中存在信息泄露漏洞。该漏洞源于网络系统或产品在运行过程中存在配置等错误。未授权的攻击者可利用漏洞获取受影响组件敏感信息。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www.cloudfoundry.org/blog/cve-2019-11294

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912\-942

  

  

**【漏洞名称】****Reliable Controls MACH-ProWebSys和Reliable Controls MACH-ProWebCom 跨站脚本漏洞**  

**【****漏洞****编号****】****CNNVD-201912-937（CVE-2019-18249）**

**【漏洞详情】**Reliable Controls MACH-ProWebSys和Reliable Controls MACH-ProWebCom都是加拿大Reliable Controls公司的一款楼宇自动化控制器。

使用8.26.4之前版本固件的Reliable Controls MACH-ProWebSys 2.15之前版本和使用8.26.4之前版本固件的MACH-ProWebCom 2.15之前版本中存在跨站脚本漏洞。远程攻击者可借助恶意链接利用该漏洞以用户身份执行命令。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：https://www.reliablecontrols.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-937
