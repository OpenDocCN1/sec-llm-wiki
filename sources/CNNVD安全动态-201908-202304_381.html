今日CNNVD共发布安全漏洞83个。主要影响厂商为美国CloudBees（28个）、法国Schneider Electric（9个）。主要影响产品为CloudBees Jenkins集成工具（28个）、Schneider Electric Modicon M580控制器（3个）。

今日需关注的典型漏洞如下:

【漏洞名称】CloudBees Jenkins Maven Release Plugin 代码问题漏洞

【漏洞编号】CNNVD-201912-816（CVE-2019-16549）

【漏洞详情】CloudBees Jenkins（Hudson Labs）是美国CloudBees公司的一套基于Java开发的持续集成工具。该产品主要用于监控持续的软件版本发布/测试项目和一些定时执行的任务。Maven Release Plugin是使用在其中的一个项目发布插件。

CloudBees Jenkins Maven Release Plugin 0.16.1及之前版本中存在代码问题漏洞。该漏洞源于网络系统或产品的代码开发过程中存在设计或实现不当的问题。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://jenkins.io/security/advisory/2019-12-17/#SECURITY-1681

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-816


【漏洞名称】多款Schneider Electric产品安全漏洞

【漏洞编号】CNNVD-201912-834（CVE-2019-6856）

【漏洞详情】Schneider Electric Modicon M580等都是法国施耐德电气（Schneider Electric）公司的产品。Schneider Electric Modicon M580是一款可编程自动化控制器。Schneider Electric Modicon Quantum是一款用于过程应用、高可用性和安全解决方案的大型可编程逻辑控制器（PLC）。Schneider Electric Modicon M340是一款用于工业过程和基础设施的中程PLC（可编程逻辑控制器）。

多款Schneider Electric产品中存在安全漏洞，该漏洞源于程序没有正确检查异常情况。攻击者可利用该漏洞造成拒绝服务。以下产品及版本受到影响：Modicon M580 2.80之前版本；Modicon M340 3.01之前版本；Modicon Premium 3.20之前版本；Modicon Quantum 3.52之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://www.se.com/ww/en/download/document/SEVD-2019-344-01/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-834


【漏洞名称】IBM API Connect 安全漏洞

【漏洞编号】CNNVD-201912-763（CVE-2019-4609）

【漏洞详情】IBM API Connect（APIConnect）是美国IBM公司的一套用于管理API生命周期的集成解决方案。该产品支持创建、运行、管理和保护API和微服务等。

IBM API Connect 2018.4.1.7版本中存在安全漏洞，该漏洞源于程序使用了较弱的加密算法。攻击者可利用该漏洞解密敏感信息。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://www.ibm.com/support/pages/node/1137460

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-763



【漏洞名称】Atlassian Crowd 跨站请求伪造漏洞

【漏洞编号】CNNVD-201912-753（CVE-2017-18107）

【漏洞详情】Atlassian Crowd是澳大利亚Atlassian公司的一套基于Web的单点登录系统。该系统为多用户、网络应用程序和目录服务器提供验证、授权等功能。

Atlassian Crowd 3.1.1之前版本中的Crowd Demo application存在跨站请求伪造漏洞。该漏洞源于WEB应用未充分验证请求是否来自可信用户。攻击者可利用该漏洞通过受影响客户端向服务器发送非预期的请求。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://jira.atlassian.com/browse/CWD-5091

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-753
