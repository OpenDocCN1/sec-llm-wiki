今日CNNVD共发布安全漏洞47个。主要影响厂商为美国Ansible（3个）、美国IBM（2个）。主要影响产品为Ansible配置管理器（3个）、IBM API Connect解决方案（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Ansible 信息泄露漏洞

【漏洞编号】CNNVD-201912-707（CVE-2019-19340）

【漏洞详情】Ansible是美国Ansible公司的一款计算机系统配置管理器。该产品可用于发布、管理和编排计算机系统。Ansible Tower是其中的一个提供了用户界面（UI）、仪表板和REST API的任务控制应用程序。

Ansible Tower中存在信息泄露漏洞。该漏洞源于网络系统或产品在运行过程中存在配置等错误。未授权的攻击者可利用漏洞获取受影响组件敏感信息。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：
https://www.ansible.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-707


【漏洞名称】IBM API Connect 安全漏洞

【漏洞编号】CNNVD-201912-703（CVE-2019-4444）

【漏洞详情】IBM API Connect（APIConnect）是美国IBM公司的一套用于管理API生命周期的集成解决方案。该产品支持创建、运行、管理和保护API和微服务等。

IBM API Connect 2018.1版本至2018.4.1.7版本中存在安全漏洞，该漏洞源于IBM API Connect Developer Portal的用户注册页面没有禁用密码自动填充功能。攻击者可利用该漏洞窃取用于注册的凭证。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://www.ibm.com/support/pages/node/1126833

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-703


【漏洞名称】ZOHO ManageEngine EventLog Analyzer 访问控制错误漏洞

【漏洞编号】CNNVD-201912-688（CVE-2019-19774）

【漏洞详情】ZOHO ManageEngine EventLog Analyzer是美国卓豪（ZOHO）公司的一套系统、事件日志分析软件。该软件能够对全网范围内的主机、服务器、网络设备以及各种应用服务系统等产生的日志，进行全面收集和细致分析。

ZOHO ManageEngine EventLog Analyzer Build 12110之前的10.0 SP1版本中存在访问控制错误漏洞。该漏洞源于网络系统或产品未正确限制来自未授权角色的资源访问。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://www.manageengine.com/products/eventlog/features-new.html#release

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-688



【漏洞名称】WordPress quiz-master-next 跨站脚本漏洞

【漏洞编号】CNNVD-201912-680（CVE-2019-17599）

【漏洞详情】WordPress是WordPress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。quiz-master-next是使用在其中的一个问卷调查插件。

WordPress quiz-master-next 6.3.5之前版本中存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://wordpress.org/plugins/quiz-master-next/#developers

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-680
