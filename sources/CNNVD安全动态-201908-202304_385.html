今日CNNVD共发布安全漏洞102个。主要影响厂商为德国Siemens（53个）、美国Intel（10个）。主要影响产品为Siemens SPPA-T3000 Application Server应用程序服务器（18个）、Intel Quartus Prime Pro设计环境（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】Siemens SPPA-T3000 Application Server 信息泄露漏洞

【漏洞编号】CNNVD-201912-648（CVE-2019-18331）

【漏洞详情】Siemens SPPA-T3000 Application Server是德国西门子（Siemens）公司的一款基于Java的应用程序服务器。

Siemens SPPA-T3000 Application Server（全部版本）中存在信息泄露漏洞。该漏洞源于网络系统或产品在运行过程中存在配置等错误。未授权的攻击者可利用漏洞获取受影响组件敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://cert-portal.siemens.com/productcert/pdf/ssa-451445.pdf

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-648


【漏洞名称】Intel Quartus Prime Pro 代码问题漏洞    

【漏洞编号】CNNVD-201912-574（CVE-2019-14604）

【漏洞详情】Intel Quartus Prime Pro是美国英特尔（Intel）公司的一套多平台设计环境。该产品主要用于可编程逻辑器件编程。

Intel Quartus Prime Pro 19.3之前版本中存在代码问题漏洞。该漏洞源于网络系统或产品的代码开发过程中存在设计或实现不当的问题。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://www.intel.com/content/www/us/en/security-center/advisory/intel-sa-00311.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-574


【漏洞名称】Octeth Oempro SQL注入漏洞

【漏洞编号】CNNVD-201912-568（CVE-2019-19740）

【漏洞详情】Octeth Oempro是美国Octeth公司的一套电子邮件营销软件。

Octeth Oempro 4.7版本中的Campaign.Get的‘CampaignID’参数存在SQL注入漏洞。该漏洞源于基于数据库的应用缺少对外部输入SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令。
目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：
https://www2.octeth.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-568



【漏洞名称】IBM Case Manager 跨站脚本漏洞

【漏洞编号】CNNVD-201912-668（CVE-2019-4426）

【漏洞详情】IBM Case Manager是美国IBM公司的一套用于管理案例的解决方案。该方案支持将内容、流程和人员相结合，并提供框架、关联性方法和集成工具以查看案例的全方位视图。

IBM Case Manager中存在跨站脚本漏洞。远程攻击者可利用该漏洞向Web UI中注入任意的JavaScript代码。以下产品及版本受到影响：IBM Case Manager 5.1.1版本，5.2.0版本，5.2.1版本，5.3CD版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://www.ibm.com/support/pages/node/1116087

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-668
