# CNNVD最新漏洞（2019-12-09）

今日CNNVD共发布安全漏洞39个。主要影响厂商为美国IBM（2个）、美国Dell（1个）。主要影响产品为IBM Planning Analytics解决方案（2个）、Dell Command Configure应用程序（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****IBM Planning Analytics 跨站脚本漏洞**  

**【漏洞编号】******CNNVD-201912-295（CVE-2019-4611）****

**【漏洞详情】**IBM Planning Analytics是美国IBM公司的一套业务规划分析解决方案。该方案支持自动化执行业务规划、预算和分析等流程。

IBM Planning Analytics 2.0版本中存在跨站脚本漏洞。攻击者可利用该漏洞向Web UI中注入任意的JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www.ibm.com/support/pages/node/1118565

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-295

  

**【漏洞名称】****Dell Command Configure 代码问题漏洞**

**【漏洞编号】****CNNVD-201912-275（CVE-2019-18575）**

**【漏洞详情】**Dell Command Configure是美国戴尔（Dell）公司的一款能够为业务客户端平台提供配置功能的应用程序。该程序中包含用于配置多种BIOS功能的命令行界面和图形用户界面。

Dell Command Configure 4.2.1之前版本中存在代码问题漏洞。该漏洞源于网络系统或产品的代码开发过程中存在设计或实现不当的问题。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www.dell.com/support/article/SLN319715

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-275

  

**【漏洞名称】******ShapeShift KeepKey 缓冲区错误漏洞****

**【漏洞编号】**********CNNVD-201912-270****（CVE-2019-18671）****

**【漏洞详情】**ShapeShift KeepKey是一款用于加密货币存储的电子钱包设备。

使用6.2.2之前版本固件的ShapeShift KeepKey中USB数据包的处理存在缓冲区错误漏洞。该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://github.com/keepkey/keepkey-firmware/commit/b222c66cdd7c3203d917c80ba615082d309d80c3

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912\-270

  

  

**【漏洞名称】****VMware ESXi和VMware Horizon DaaS OpenSLP 安全漏洞**  

**【****漏洞****编号****】****CNNVD-201912-263（CVE-2019-5544）**

**【漏洞详情】**VMware ESXi和VMware Horizon DaaS都是美国威睿（VMware）公司的产品。VMware ESXi是一套可直接安装在物理服务器上的服务器虚拟化平台。VMware Horizon DaaS是一套专为以云计算服务形式交付桌面和应用而构建的虚拟桌面平台。该平台提供多桌面模式和多数据中心管理等功能。OpenSLP是其中的一个IETF服务位置协议的开源实现。

VMware ESXi和VMware Horizon DaaS中的OpenSLP存在安全漏洞。攻击者可利用该漏洞执行代码。以下产品及版本受到影响：VMware ESXi 6.7版本，6.5版本，6.0版本；VMware Horizon DaaS 8.x版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www.vmware.com/security/advisories/VMSA-2019-0022.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-263
