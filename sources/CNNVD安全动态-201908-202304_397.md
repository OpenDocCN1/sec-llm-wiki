今日CNNVD共发布安全漏洞56个。主要影响厂商为爱尔兰TitanHQ（8个）、美国IBM（6个）。主要影响产品为TitanHQ WebTitan内容过滤器（8个）、IBM Cloud Pak System融合基础架构（6个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】****TitanHQ WebTitan SQL注入漏洞**  

**【漏洞编号】******CNNVD-201912-031（CVE-2019-19016）****

**【漏洞详情】**TitanHQ WebTitan是爱尔兰TitanHQ公司的一款Web内容过滤器。

TitanHQ WebTitan 5.18之前版本中的管理界面的一些功能存在SQL注入漏洞。攻击者可利用该漏洞获取该软件数据库中的敏感信息。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：https://www.titanhq.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-031

  

**【漏洞名称】****IBM Cloud Pak System 跨站脚本漏洞**

**【漏洞编号】****CNNVD-201912-049（CVE-2019-4226）**

**【漏洞详情】**IBM Cloud Pak System是美国IBM公司的一套具有可配置、预集成软件的全栈、融合基础架构。该产品支持跨混合云部署、管理和移动应用程序环境。

IBM Cloud Pak System 2.3版本和2.3.0.1版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞在Web UI中注入任意的JavaScript代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www.ibm.com/support/pages/node/1118487

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-049

  

**【漏洞名称】******Trend Micro Security 2020 安全漏洞****

**【漏洞编号】**********CNNVD-201912-017****（CVE-2019-15628）****

**【漏洞详情】**Trend Micro Security 2020是美国趋势科技（Trend Micro）公司的一套计算机安全防护软件。

Trend Micro Security (Consumer) 2020 16.0.1221及之前版本中存在DLL劫持漏洞。攻击者可利用该漏洞执行恶意的程序。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://esupport.trendmicro.com/en-us/home/pages/technical-support/1124011.aspx

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912\-017

  

  

**【漏洞名称】********Accusoft ImageGear 缓冲区错误漏洞******  

**【****漏洞****编号****】****CNNVD-201912-060（CVE-2019-5083）**

**【漏洞详情】**Accusoft ImageGear是美国Accusoft公司的一款用于图像处理的软件开发工具包（SDK）。

Accusoft ImageGear 19.3.0版本中的igcore19d.dll TIFdecodethunderscan功能存在缓冲区错误漏洞。该漏洞源于网络系统或产品在内存上执行操作时，未正确验证数据边界，导致向关联的其他内存位置上执行了错误的读写操作。攻击者可利用该漏洞导致缓冲区溢出或堆溢出等。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：https://www.accusoft.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201912-060
