公开漏洞情况

本周CNNVD采集安全漏洞263个，与上周（558个）相比减少了52.87%。

接报漏洞情况

本周接报漏洞912个，其中信息技术产品漏洞（通用型漏洞）14个，网络信息系统漏洞（事件型漏洞）898个。

一、公开漏洞情况

根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞263个，漏洞新增数量有所下降。从厂商分布来看思科公司和CloudBees公司新增漏洞最多，各有14个；从漏洞类型来看，资源管理错误类的安全漏洞占比最大，达到17.87%。本周新增漏洞中，超危漏洞14个，高危漏洞92个，中危漏洞132个，低危漏洞25个。相应修复率分别为71.43%、68.48%、75.76%和96.00%。根据补丁信息统计，合计197个漏洞已有修复补丁发布，整体修复率为74.90%。

1.  Apache Solr 代码问题漏洞（CNNVD-201911-1122）

Apache Solr是美国阿帕奇（Apache）软件基金会的一款基于Lucene（一款全文搜索引擎）的搜索服务器。该产品支持层面搜索、垂直搜索、高亮显示搜索结果等。

Apache Solr 8.1.1版本和8.2.0版本中存在代码问题漏洞，该漏洞源于程序没有安全地设置默认solr.in.sh配置文件的ENABLE_REMOTE_JMX_OPTS配置选项。攻击者可利用该漏洞向Solr服务器上传恶意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://lists.apache.org/thread.html/6640c7e370fce2b74e466a605a46244ccc40666ad9e3064a4e04a85d@%3Csolr-user.lucene.apache.org%3E

2.  NetApp ONTAP Select Deploy administration utility 代码注入漏洞（CNNVD-201911-1253）
NetApp ONTAP Select Deploy administration utility是美国NetApp公司的一款用于部署和管理ONTAP Select群集的管理实用程序。
ONTAP Select Deploy administration utility 2.11.2版本至2.12.2版本中存在代码注入漏洞。攻击者可利用该漏洞打开并使用特权账户。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://security.netapp.com/advisory/ntap-20191121-0001/
3.  IBM Security Identity Manager 代码问题漏洞（CNNVD-201911-1171）
IBM Security Identity Manager（ISIM）是美国IBM公司的一套身份管理和治理解决方案。该方案可在整个用户生命周期内自动创建、修改、重新认证和终止用户特权，并支持基于策略的密码管理。
IBM ISIM 6.0.0版本中存在代码问题漏洞。远程攻击者可通过诱使用户访问特制网站利用该漏洞在系统上执行任意代码。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://www.ibm.com/support/pages/node/1108695
