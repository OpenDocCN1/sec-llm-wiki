今日CNNVD共发布安全漏洞38个。主要影响厂商为中国联想（5个）、美国Google（2个）。主要影响产品为Lenovo System Interface Foundation通信软件（2个）、Google Chrome浏览器（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】Lenovo System Interface Foundation 安全漏洞

【漏洞编号】CNNVD-201911-1141（CVE-2019-6189）

【漏洞详情】Lenovo System Interface Foundation是中国联想（Lenovo）公司的一套用于与硬件设备进行通信的软件。

Lenovo System Interface Foundation 1.1.18.3之前版本中存在安全漏洞。攻击者可利用该漏洞加载未签名的DLL。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://support.lenovo.com/us/en/product_security/LEN-29198

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201911-1141


【漏洞名称】Google Chrome 缓冲区错误漏洞

【漏洞编号】CNNVD-201911-1169（CVE-2019-13724）

【漏洞详情】Google Chrome是美国谷歌（Google）公司的一款Web浏览器。

Google Chrome 78.0.3904.108之前版本中的Bluetooth存在缓冲区错误漏洞。攻击者可借助特制的网站利用该漏洞在系统上执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://chromereleases.googleblog.com/2019/11/stable-channel-update-for-desktop_18.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201911-1169


【漏洞名称】Code42 Software Code42 app 代码问题漏洞

【漏洞编号】CNNVD-201911-1146（CVE-2019-16860）

【漏洞详情】Code42 Software Code42是美国Code42 Software公司的一套企业级数据保护系统。该系统能够检测内部威胁，防止数据泄露、丢失。Code42 app是Code42的应用端程序。

基于Windows平台的Code42 Software Code42 app 7.0.2及之前版本中存在代码问题漏洞。该漏洞源于网络系统或产品的代码开发过程中存在设计或实现不当的问题。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://support.code42.com/Terms_and_conditions/Code42_customer_support_resources/Code42_security_advisories/Arbitrary_code_execution_on_local_Windows_devices

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201911-1146


【漏洞名称】Facebook HHVM 资源管理错误漏洞

【漏洞编号】CNNVD-201911-1150（CVE-2016-1000006）

【漏洞详情】Facebook HHVM（又名HipHop Virtual Machine）是美国Facebook公司的一款能够显著提高PHP加载动态页面性能的虚拟机。

Facebook HHVM 3.12.11之前版本中的‘serialize_memoize_param()’和‘ResourceBundle::__construct()’函数存在资源管理错误漏洞。该漏洞源于网络系统或产品对系统资源（如内存、磁盘空间、文件等）的管理不当。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：
https://hhvm.com/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201911-1150
