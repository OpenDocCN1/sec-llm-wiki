今日CNNVD共发布安全漏洞40个。主要影响厂商为美国NVIDIA（11个）、美国Broadcom（6个）。主要影响产品为NVIDIA Windows GPU Display Driver显卡驱动程序（5个）、Broadcom Brocade SANnav管理平台（6个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******NVIDIA Windows GPU Display Driver kernel mode layer handler 安全漏洞****

**【漏洞编号】**********CNNVD-201911-468****（CVE-2019-5690）****

**【漏洞详情】**NVIDIA Windows GPU Display Driver是美国英伟达（NVIDIA）公司的一款专用于Windows平台的图形处理器（GPU）显卡驱动程序。kernel mode layer (nvlddmkm.sys) handler是其中的一个内核模式层处理程序。

NVIDIA Windows GPU Display Driver（全部版本）中的kernel mode layer (nvlddmkm.sys) handler（用于DxgkDdiEscape）存在安全漏洞，该漏洞源于程序没有验证输入缓冲区的大小。攻击者可利用该漏洞造成拒绝服务或提升权限。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://nvidia.custhelp.com/app/answers/detail/a\_id/4907

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201911-468

  

**【漏洞名称】****Broadcom Brocade SANnav 日志信息泄露漏洞**  

**【漏洞编号】******CNNVD-201911-463（CVE-2019-16210）****

**【漏洞详情】**Broadcom Brocade SANnav是美国博通（Broadcom）公司的一套SAN管理平台。

Broadcom Brocade SANnav 2.0之前版本中存在日志信息泄露漏洞。该漏洞源于网络系统或产品的日志文件非正常输出。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www.broadcom.com/support/fibre-channel-networking/security-advisories/brocade-security-advisory-2019-869

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201911-463

  

**【漏洞名称】****IBM Cognos Analytics 代码问题漏洞**

**【漏洞编号】****CNNVD-201911-485（CVE-2018-1721）**

**【漏洞详情】**IBM Cognos Analytics是美国IBM公司的一套商业智能软件。该软件包括报表、仪表板和记分卡等，并可通过分析关键因素与关键人等内容，协助企业调整决策。

IBM Cognos Analytics 11.0版本和11.1版本中存在代码问题漏洞。远程攻击者可利用该漏洞泄露敏感信息或造成该Web服务器向任意域发送HTTP请求。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www.ibm.com/support/pages/node/1074144

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201911-485

  

**【漏洞名称】********TmaxSoft JEUS 路径遍历漏洞******

**【****漏洞****编号****】****CNNVD-201911-484（CVE-2019-17327）**

**【漏洞详情】**TmaxSoft JEUS是韩国TmaxSoft公司的一款Web应用程序服务器。

TmaxSoft JEUS 7 Fix#0版本至5版本和TmaxSoft JEUS 8Fix#0版本至1版本中存在路径遍历漏洞。该漏洞源于网络系统或产品未能正确地过滤资源或文件路径中的特殊元素。攻击者可利用该漏洞访问受限目录之外的位置。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：https://www.tmaxsoft.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201911-484
