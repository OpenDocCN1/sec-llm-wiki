# CNNVD最新漏洞（2019-11-06）

今日CNNVD共发布安全漏洞58个。主要影响厂商为美国Magento（7个）、LEAD Technologies（4个）。主要影响产品为Magento电子商务系统（7个）、LEAD Technologies LEADTOOLS图像处理开发工具包（4个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Magento 安全漏洞****

**【漏洞编号】**********CNNVD-201911-235****（CVE-2019-8227）****

**【漏洞详情】**Magento是美国Magento公司的一套开源的PHP电子商务系统。该系统提供权限管理、搜索引擎和支付网关等功能。

Magento 1.9.4.3之前版本和1.14.4.3之前版本中存在安全漏洞。攻击者可借助导入/导出功能利用该漏洞注入任意的JavaScript代码。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://magento.com/security/patches/supee-11219

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201911-235

  

**【漏洞名称】****LEAD Technologies LEADTOOLS 缓冲区错误漏洞**  

**【漏洞编号】******CNNVD-201911-240（CVE-2019-5084）****

**【漏洞详情】**LEAD Technologies LEADTOOLS是美国LEAD Technologies公司的一款图像处理开发工具包。

LEAD Technologies LEADTOOLS中的TIF解析功能存在缓冲区错误漏洞。攻击者可借助特制的TIF图像利用该漏洞执行代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：https://www.leadtools.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201911-240

  

**【漏洞名称】****IBM QRadar SIEM 跨站脚本漏洞**

**【漏洞编号】****CNNVD-201911-245（CVE-2019-4581）**

**【漏洞详情】**IBM QRadar SIEM是美国IBM公司的一套利用安全智能保护资产和信息远离高级威胁的解决方案。该方案提供对整个IT架构范围进行监督、生成详细的数据访问和用户活动报告等功能。

IBM QRadar SIEM中存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.ibm.com/support/pages/node/1103373

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201911-245

  

**【漏洞名称】********ARM Mbed OS CoAP library 输入验证错误漏洞******

**【****漏洞****编号****】****CNNVD-201911-196（CVE-2019-17211）**

**【漏洞详情】**ARM Mbed OS是英国ARM公司的一套专用于物联网的开源嵌入式操作系统。CoAP library是其中的一个约束应用协议（CoAP）库。

Arm Mbed OS 5.14.0版本中的CoAP library存在输入验证错误漏洞。该漏洞源于网络系统或产品未对输入的数据进行正确的验证。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://github.com/ARMmbed/mbed-os

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201911-196
