今日CNNVD共发布安全漏洞48个。主要影响厂商为美国Apple（19个）、美国IBM（2个）。主要影响产品为Apple iOS操作系统（11个）、IBM InfoSphere Information Server数据整合平台（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】多款Apple产品WebKit组件安全漏洞

【漏洞编号】CNNVD-201911-012（CVE-2019-8773）

【漏洞详情】Apple iOS等都是美国苹果（Apple）公司的产品。Apple iOS是一套为移动设备所开发的操作系统。Apple tvOS是一套智能电视操作系统。Apple iPadOS是一套用于iPad平板电脑的操作系统。WebKit是其中的一个Web浏览器引擎组件。

多款Apple产品中的WebKit组件存在安全漏洞。攻击者可借助恶意制作的Web内容利用该漏洞执行任意的代码。以下产品及版本受到影响：Apple iOS 13.1之前版本；iPadOS 13.1之前版本；Safari 13.0.1之前版本；tvOS 13之前版本；基于Windows平台的iTunes 12.10.1之前版本。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://support.apple.com/en-us/HT210603
https://support.apple.com/en-us/HT210604
https://support.apple.com/en-us/HT210637
https://support.apple.com/en-us/HT210635

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201911-012


【漏洞名称】IBM InfoSphere Information Server 跨站请求伪造漏洞

【漏洞编号】CNNVD-201911-049（CVE-2019-4407）

【漏洞详情】IBM InfoSphere Information Server是美国IBM公司的一套数据整合平台。该平台可用于整合各种渠道获取的数据信息。

IBM InfoSphere Information Server中存在跨站请求伪造漏洞。远程攻击者可利用该漏洞执行未授权的恶意操作。以下产品及版本受到影响：IBM InfoSphere Information Server 11.3版本，11.5版本，11.7版本，InfoSphere Information Server on Cloud 11.5版本，11.7版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://www.ibm.com/support/pages/node/959633

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201911-049


【漏洞名称】Sonatype Nexus Repository Manager 操作系统命令注入漏洞

【漏洞编号】CNNVD-201911-025（CVE-2019-15588）

【漏洞详情】Sonatype Nexus Repository Manager（NXRM）是美国Sonatype公司的一款Maven仓库管理器。

Sonatype NXRM 2.14.14及之前版本中存在操作系统命令注入漏洞。该漏洞源于外部输入数据构造操作系统可执行命令过程中，网络系统或产品未正确过滤其中的特殊字符、命令等。攻击者可利用该漏洞执行非法操作系统命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.sonatype.com/hc/en-us/articles/360033490774-CVE-2019-5475-Nexus-Repository-Manager-2-OS-Command-Injection-2019-08-09

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201911-025


【漏洞名称】SECUDOS DOMOS Log模块跨站脚本漏洞

【漏洞编号】CNNVD-201911-039（CVE-2019-18664）

【漏洞详情】SECUDOS DOMOS是德国SECUDOS公司的一套用于物联网设备的操作系统。Log是其中的一个日志模块。

SECUDOS DOMOS 5.6之前版本中的Log模块存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.secudos.de/news-und-events/aktuelle-news/domos-release-5-6

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201911-039
