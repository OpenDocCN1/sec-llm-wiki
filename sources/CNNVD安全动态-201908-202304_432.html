今日CNNVD共发布安全漏洞33个。主要影响厂商为美国IBM（7个）、美国Honeywell（1个）。主要影响产品为IBM Cloud Orchestrator解决方案（6个）、Honeywell IP-AK2控制面板（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】IBM Cloud Orchestrator 注入漏洞

【漏洞编号】CNNVD-201910-1460（CVE-2019-4396）

【漏洞详情】IBM Cloud Orchestrator是美国IBM公司的一套为云管理解决方案。该方案提供扩展内部和外部部署云服务以及应用程序接口和工具扩展与现有环境集成等功能。

IBM Cloud Orchestrator中存在注入漏洞。攻击者可利用该漏洞注入任意的HTTP头并造成响应拆分。以下产品及版本受到影响：IBM Cloud Orchestrator 2.5版本，2.5.0.1版本，2.5.0.2版本，2.5.0.3版本，2.5.0.4版本，2.5.0.5版本，2.5.0.6版本，2.5.0.7版本，2.5.0.8版本，2.5.0.9版本，2.4版本，2.4.0.1版本，2.4.0.2版本，2.4.0.3版本，2.4.0.4版本，2.4.0.5版本；Cloud Orchestrator Enterprise 2.5版本，2.5.0.1版本，2.5.0.2版本，2.5.0.3版本，2.5.0.4版本，2.5.0.5版本，2.5.0.6版本，2.5.0.7版本，2.5.0.8版本，2.5.0.9版本，2.4版本，2.4.0.1版本，2.4.0.2版本，2.4.0.3版本，2.4.0.4版本，2.4.0.5版本。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://www.ibm.com/support/pages/node/1096354

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1460


【漏洞名称】Honeywell IP-AK2 访问控制错误漏洞

【漏洞编号】CNNVD-201910-1479（CVE-2019-13525）

【漏洞详情】Honeywell IP-AK2是美国霍尼韦尔（Honeywell）公司的一款基于Web的、用于门禁系统的访问控制面板。

Honeywell IP-AK2 Access Control Panel 1.04.07及之前版本中存在访问控制错误漏洞。该漏洞源于网络系统或产品未正确限制来自未授权角色的资源访问。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.honeywell.com

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1479


【漏洞名称】libarchive 资源管理错误漏洞

【漏洞编号】CNNVD-201910-1468（CVE-2019-18408）

【漏洞详情】libarchive是一款多格式存档和压缩库。
libarchive 3.4.0之前版本中的archive_read_support_format_rar.c文件的archive_read_format_rar_read_data存在资源管理错误漏洞。该漏洞源于网络系统或产品对系统资源（如内存、磁盘空间、文件等）的管理不当。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/libarchive/libarchive/commit/b8592ecba2f9e451e1f5cb7ab6dcee8b8e7b3f60

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1468


【漏洞名称】MapR CLDB 安全漏洞

【漏洞编号】CNNVD-201910-1470（CVE-2019-12017）

【漏洞详情】MapR CLDB是美国MapR公司的一款容器位置数据库。
MapR CLDB代码中存在安全漏洞。攻击者可利用该漏洞在运行MapR CLDB的设备上执行任意代码并控制集群。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://mapr.com

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1470
