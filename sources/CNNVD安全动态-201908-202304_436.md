今日CNNVD共发布安全漏洞36个。主要影响厂商为美国Fortinet（3个）、美国Citrix Systems（1个）。主要影响产品为Fortinet FortiMail电子邮件安全网关（2个）、Citrix Application Delivery Controller应用交付控制器（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Fortinet FortiMail 访问控制错误漏洞****

**【漏洞编号】**********CNNVD-201910-1250****（CVE-2019-15707）****

**【漏洞详情】**Fortinet FortiMail是美国飞塔（Fortinet）公司的一套电子邮件安全网关产品。该产品提供电子邮件安全防护和数据保护等功能。

Fortinet FortiMail 6.2.0版本、6.0.0版本至6.0.6版本和5.4.10及之前版本中存在访问控制错误漏洞。该漏洞源于网络系统或产品未正确限制来自未授权角色的资源访问。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://fortiguard.com/psirt/FG-IR-19-237

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1250

  

**【漏洞名称】****Citrix Systems NetScaler Gateway和Citrix Application Delivery Controller 安全漏洞**  

**【漏洞编号】******CNNVD-201910-1274（CVE-2019-18225）****

**【漏洞详情】**Citrix Systems NetScaler Gateway（Citrix Systems Gateway）和Citrix Application Delivery Controller（ADC）都是美国思杰系统（Citrix Systems）公司的产品。Citrix Systems NetScaler Gateway是一套安全的远程接入解决方案。该方案可为管理员提供应用级和数据级管控功能，以实现用户从任何地点远程访问应用和数据。Citrix Application Delivery Controller是一款应用交付控制器。该产品具有应用交付控制和负载均衡等功能。

Citrix Systems NetScaler Gateway和Citrix ADC中存在安全漏洞。攻击者可利用该漏洞绕过身份验证，获取设备的管理权限。以下产品版本受到影响：Citrix ADC 10.5 build 70.8之前的版本，11.1 build 63.9之前的11.x版本，12.0 build 62.10之前的12.0版本，12.1 build 54.16之前的12.1版本，13.0 build 41.28之前的13.0版本；Citrix Systems NetScaler Gateway 10.5 build 70.8之前的版本，11.1 build 63.9之前的11.x版本，12.0 build 62.10之前的12.0版本，12.1 build 54.16之前的12.1版本，13.0 build 41.28之前的13.0版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://support.citrix.com/article/CTX261055

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1274

  

**【漏洞名称】****OpenEMR 跨站脚本漏洞**

**【漏洞编号】****CNNVD-201910-1248（CVE-2019-16862）**

**【漏洞详情】**OpenEMR是OpenEMR社区的一套开源的医疗管理系统。该系统可用于医疗实践管理、电子医疗记录、处方书写和医疗帐单申请。

OpenEMR 5.0.2.1之前的5.x版本中的interface/forms/eye\_mag/view.php文件存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://github.com/openemr/openemr/pull/2685

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1248

  

**【漏洞名称】********FusionPBX SQL注入漏洞******

**【****漏洞****编号****】****CNNVD-201910-1262（CVE-2019-16980）**

**【漏洞详情】**FusionPBX是一套可扩展、多线程的通信平台。该平台可作为呼叫中心服务器、传真服务器、voip服务器、语音邮件服务器、会议服务器和语音应用服务器等。

FusionPBX 4.5.7及之前版本中存在SQL注入漏洞。该漏洞源于基于数据库的应用缺少对外部输入SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接

https://github.com/fusionpbx/fusionpbx/commit/6fe372b3d4bb7ff07778d152886edcecc045c7ec

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1262
