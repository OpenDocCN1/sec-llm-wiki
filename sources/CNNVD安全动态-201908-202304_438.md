今日CNNVD共发布安全漏洞21个。主要影响厂商为美国Dell（1个）、美国Google（1个）。主要影响产品为Dell RSA Authentication Manager身份认证软件（1个）、Google Go编程语言（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Dell RSA Authentication Manager 代码问题漏洞****

**【漏洞编号】**********CNNVD-201910-1238****（CVE-2019-3768）****

**【漏洞详情】**Dell RSA Authentication Manager是美国戴尔（Dell）公司的一套集中式二元身份认证软件。该软件可跨物理站点集中管理二元身份认证、安全令牌、方法和用户等。

Dell RSA Authentication Manager中存在代码问题漏洞。该漏洞源于网络系统或产品的代码开发过程中存在设计或实现不当的问题。目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：https://www.dellemc.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1238

  

**【漏洞名称】****Google Go 信任管理问题漏洞**  

**【漏洞编号】******CNNVD-201910-1228（CVE-2019-17596）****

**【漏洞详情】**Google Go是美国谷歌（Google）公司的一款静态强类型、编译型、并发型，并具有垃圾回收功能的编程语言。

Google Go中存在信任管理问题漏洞。该漏洞源于网络系统或产品中缺乏有效的信任管理机制。攻击者可利用默认密码或者硬编码密码、硬编码证书等攻击受影响组件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/golang/go/issues/34960

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1228

  

**【漏洞名称】****Sangoma Technologies SBC 安全漏洞**

**【漏洞编号】****CNNVD-201910-1234（CVE-2019-12148）**

**【漏洞详情】**Sangoma Technologies SBC是加拿大Sangoma Technologies公司的一款边界会话控制器（SBC）。

Sangoma Technologies SBC 2.3.23-119-GA版本中存在安全漏洞。攻击者可利用该漏洞绕过身份验证并以不存在用户的身份进行登录，并获取数据库全部的访问权限，包括权限用户的创建。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：https://www.sangoma.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1234

  

**【漏洞名称】********Verodin 信息泄露漏洞******

**【****漏洞****编号****】****CNNVD-201910-1247（CVE-2019-10716）**

**【漏洞详情】**Verodin是美国Verodin公司的一套网络安全检测平台。该平台主要用于检测网络、端点、电子邮件和云控制的安全防护的有效性。Director是Verodin的控制台程序。

Verodin Director 3.5.3.1及之前版本中存在信息泄露漏洞。该漏洞源于网络系统或产品在运行过程中存在配置等错误。未授权的攻击者可利用漏洞获取受影响组件敏感信息。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.verodin.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1247
