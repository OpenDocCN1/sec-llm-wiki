今日CNNVD共发布安全漏洞53个。主要影响厂商为美国WiKID Systems（8个）、中国中华电信（5个）。主要影响产品为WiKID Systems 2FA Enterprise Server身份验证服务器（8个）、Chunghwa Telecom HiNet GPON光调制解调器（5个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******WiKID Systems 2FA Enterprise Server 跨站请求伪造漏洞****

**【漏洞编号】**********CNNVD-201910-1199****（CVE-2019-17118）****

**【漏洞详情】**WiKID Systems 2FA Enterprise Server是美国WiKID Systems公司的一款双因素身份验证服务器。

WiKID 2FA Enterprise Server 4.2.0-b2053及之前版本中存在跨站请求伪造漏洞。该漏洞源于WEB应用未充分验证请求是否来自可信用户。攻击者可利用该漏洞通过受影响客户端向服务器发送非预期的请求。目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：https://www.wikidsystems.com

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1199

  

**【漏洞名称】****Chunghwa Telecom HiNet GPON 安全漏洞**  

**【漏洞编号】******CNNVD-201910-1210（CVE-2019-15064）****

**【漏洞详情】**Chunghwa Telecom HiNet GPON是中国台湾中华电信（Chunghwa Telecom）公司的一款光调制解调器。

使用I040GWR190731之前版本固件的Chunghwa Telecom HiNet GPON存在安全漏洞。攻击者可利用该漏洞未经身份验证便可登录设备。   

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.cht.com.tw

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1210

  

**【漏洞名称】****YouPHPTube SQL注入漏洞**

**【漏洞编号】****CNNVD-201910-1214（CVE-2019-5119）**

**【漏洞详情】**YouPHPTube是一套基于PHP的视频网站系统。

YouPHPTube 7.6版本中的/objects/subscribeNotify.json.php文件的‘user\_id’参数SQL注入漏洞。该漏洞源于基于数据库的应用缺少对外部输入SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：https://www.youphptube.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1214

  

**【漏洞名称】********Horner Automation Cscape 输入验证错误漏洞******

**【****漏洞****编号****】****CNNVD-201910-1222（CVE-2019-13541）**

**【漏洞详情】**Horner Automation Cscape是美国Horner Automation公司的一套用于工业控制系统开发的编程软件。

Horner Automation Cscape 9.90及之前版本中存在输入验证错误漏洞。攻击者可利用该漏洞访问信息并执行任意代码。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://hornerautomation.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1222
