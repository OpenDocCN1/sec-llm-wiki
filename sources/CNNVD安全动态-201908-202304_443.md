今日CNNVD共发布安全漏洞245个。主要影响厂商为美国Oracle（136个）、美国Adobe（82个）。主要影响产品为Oracle MySQL数据库管理系统（29个）、Adobe Reader文档阅读软件（68个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Oracle MySQL Server 安全漏洞****

**【漏洞编号】**********CNNVD-201910-981****（CVE-2019-3003）****

**【漏洞详情】**Oracle MySQL是美国甲骨文（Oracle）公司的一套开源的关系数据库管理系统。MySQL Server是其中的一个数据库服务器组件。

Oracle MySQL中的MySQL Server 8.0.16及之前版本的InnoDB组件存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（挂起或频繁崩溃），影响数据的可用性。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www.oracle.com/technetwork/security-advisory/cpuoct2019-5072832.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-981

  

**【漏洞名称】****Adobe Acrobat和Reader 资源管理错误漏洞**  

**【漏洞编号】******CNNVD-201910-888（CVE-2019-8178）****

**【漏洞详情】**Adobe Acrobat和Reader都是美国奥多比（Adobe）公司的产品。Adobe Acrobat是一套PDF文件编辑和转换工具。Reader是一套PDF文档阅读软件。

Adobe Acrobat和Acrobat Reader中存在资源管理错误漏洞，攻击者可利用该漏洞执行代码。以下产品及版本受到影响：基于Windows和macOS平台的Adobe Acrobat DC（Continuous）2019.012.20040及之前版本，基于Windows和macOS平台的Acrobat 2017（Classic 2017）2017.011.30148及之前版本，基于Windows和macOS平台的Acrobat 2015（Classic 2015）2015.006.30503及之前版本；基于Windows和macOS平台的Acrobat Reader DC（Continuous）2019.012.20040及之前版本，基于Windows和macOS平台的Acrobat Reader 2017（Classic 2017）2017.011.30148及之前版本，基于Windows和macOS平台的Acrobat Reader 2015（Classic 2015）2015.006.30503及之前版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://helpx.adobe.com/security/products/acrobat/apsb19-49.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-888

  

**【漏洞名称】****Oracle Database Server Core RDBMS组件安全漏洞**

**【漏洞编号】****CNNVD-201910-1065（CVE-2019-2940）**

**【漏洞详情】**Oracle Database Server是美国甲骨文（Oracle）公司的一套关系数据库管理系统。该数据库管理系统提供数据管理、分布式处理等功能。Core RDBMS是其中的一个关系型数据库核心组件。

Oracle Database Server 12.1.0.2版本、12.2.0.1版本和18c版本中的Core RDBMS组件存在安全漏洞。攻击者可利用该漏洞未授权更新、插入或删除数据，影响数据的完整性。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www.oracle.com/technetwork/security-advisory/cpuoct2019-5072832.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-1065

  

**【漏洞名称】********Adobe Experience Manager 命令注入漏洞******

**【****漏洞****编号****】****CNNVD-201910-838（CVE-2019-8088）**

**【漏洞详情】**Adobe Experience Manager（AEM）是美国奥多比（Adobe）公司的一套可用于构建网站、移动应用程序和表单的内容管理解决方案。该方案支持移动内容管理、营销销售活动管理和多站点管理等。

Adobe Experience Manager中存在命令注入漏洞。攻击者可利用该漏洞执行代码。以下版本受到影响：Adobe Experience Manager 6.5版本，6.4版本，6.3版本，6.2版本，6.1版本和6.0版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://helpx.adobe.com/security/products/experience-manager/apsb19-48.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-838
