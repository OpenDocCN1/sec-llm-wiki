今日CNNVD共发布安全漏洞65个。主要影响厂商为美国IceWarp（7个）、美国Google（5个）。主要影响产品为IceWarp Mail Server邮件服务器（7个）、Google Chrome浏览器（5个）。

今日需关注的典型漏洞如下:

【漏洞名称】IceWarp Mail Server 路径遍历漏洞

【漏洞编号】CNNVD-201910-718（CVE-2010-5334）

【漏洞详情】IceWarp Mail Server是美国IceWarp公司的一款邮件服务器产品。该产品支持电子邮件归档、SmartAttach附件、自动迁移等。IceWarp Webclient是一个基于Web的IceWarp客户端程序。

IceWarp Webclient 10.2.1之前版本中存在路径遍历漏洞。该漏洞源于网络系统或产品未能正确地过滤资源或文件路径中的特殊元素。攻击者可利用该漏洞访问受限目录之外的位置。
目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：
https://www.icewarp.com

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-718


【漏洞名称】Google Chrome 安全漏洞

【漏洞编号】CNNVD-201910-751（CVE-2019-13697）

【漏洞详情】Google Chrome是美国谷歌（Google）公司的一款Web浏览器。
Google Chrome 77.0.3865.120之前版本中存在安全漏洞。攻击者可借助特制的网站利用该漏洞获取敏感信息。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://chromereleases.googleblog.com/2019/10/stable-channel-update-for-desktop.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-751


【漏洞名称】Red Hat wildfly-core 访问控制错误漏洞

【漏洞编号】CNNVD-201910-761（CVE-2019-14838）

【漏洞详情】Red Hat Wildfly是美国红帽（Red Hat）公司的一款基于JavaEE的轻量级开源应用服务器。wildfly-core是Wildfly使用的一个核心运行时程序。
Red Hat wildfly-core中存在访问控制错误漏洞。该漏洞源于网络系统或产品未正确限制来自未授权角色的资源访问。
目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：
https://www.redhat.com

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-761


【漏洞名称】Intel Active System Console 安全漏洞

【漏洞编号】CNNVD-201910-747（CVE-2019-11120）

【漏洞详情】Intel Active System Console是美国英特尔（Intel）公司的一款主动式系统控制台应用程序。

Intel Active System Console 8.0 Build 24之前版本中的安装程序存在安全漏洞，该漏洞源于程序没有进行充分的路径检查。攻击者可利用该漏洞提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://www.intel.com/content/www/us/en/security-center/advisory/intel-sa-00261.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-747
