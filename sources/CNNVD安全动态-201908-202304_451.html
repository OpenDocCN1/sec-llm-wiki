今日CNNVD共发布安全漏洞197个。主要影响厂商为美国Microsoft（58个）、美国Google（10个）。主要影响产品为Microsoft Windows操作系统（38个）、Android操作系统（10个）。

今日需关注的典型漏洞如下:

【漏洞名称】Microsoft Graphics组件信息泄露漏洞

【漏洞编号】CNNVD-201910-488（CVE-2019-1361）

【漏洞详情】Microsoft Windows和Microsoft Windows Server都是美国微软（Microsoft）公司的产品。Microsoft Windows是一套个人设备使用的操作系统。Microsoft Windows Server是一套服务器操作系统。Graphics Components是其中的一个图形组件。

Microsoft Graphics组件中处理内存对象的方式存在信息泄露漏洞。攻击者可借助特制的文件利用该漏洞获取信息。以下产品及版本受到影响：Microsoft Windows 7 SP1，Windows Server 2008 R2 SP1。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2019-1361

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-488


【漏洞名称】Android 安全漏洞

【漏洞编号】CNNVD-201910-341（CVE-2019-2114）

【漏洞详情】Android是美国谷歌（Google）和开放手持设备联盟（简称OHA）的一套以Linux为基础的开源操作系统。System是其中的一个系统组件。

Android8.0版本、8.1版本和9版本中的System存在安全漏洞。攻击者可利用该漏洞提升权限。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2019-10-01

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-341


【漏洞名称】Microsoft SharePoint 跨站脚本漏洞

【漏洞编号】CNNVD-201910-481（CVE-2019-1070）

【漏洞详情】Microsoft SharePoint是美国微软（Microsoft）公司的一套企业业务协作平台。该平台用于对业务信息进行整合，并能够共享工作、与他人协同工作、组织项目和工作组、搜索人员和信息。

Microsoft SharePoint中存在跨站脚本漏洞，该漏洞源于SharePoint Server没有正确处理特制的网络请求。远程攻击者可利用该漏洞在当前用户的上下文中执行脚本。以下产品及版本受到影响：Microsoft SharePoint Enterprise Server 2016，Microsoft SharePoint Foundation 2013 SP1。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2019-1070

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-481


【漏洞名称】Android Media Framework 安全漏洞

【漏洞编号】CNNVD-201910-333（CVE-2019-2184）

【漏洞详情】Android是美国谷歌（Google）和开放手持设备联盟（简称OHA）的一套以Linux为基础的开源操作系统。Media Framework是其中的一个多媒体开发框架。Android中的Media Framework存在安全漏洞。攻击者可利用该漏洞执行任意代码。以下版本受到影响：Android 7.1.1版本，7.1.2版本，8.0版本，8.1版本和9版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://source.android.com/security/bulletin/2019-10-01

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201910-333
