今日CNNVD共发布安全漏洞40个。主要影响厂商为美国F5（6个）、美国Adobe（3个）。主要影响产品为F5 BIG-IP应用交付平台（3个）、Adobe ColdFusion应用程序开发平台（3个）。

今日需关注的典型漏洞如下:

【漏洞名称】F5 BIG-IP 安全漏洞

【漏洞编号】CNNVD-201909-1109（CVE-2019-6654）

【漏洞详情】F5 BIG-IP是美国F5公司的一款集成了网络流量管理、应用程序安全管理、负载均衡等功能的应用交付平台。

F5 BIG-IP中存在安全漏洞。远程攻击者可利用该漏洞进行未授权的修改操作或造成拒绝服务。以下产品及版本受到影响：F5 BIG-IP 14.0.0版本至14.1.2版本，13.0.0版本至13.1.3版本，12.1.0版本至12.1.5版本，11.5.1版本至11.6.5版本。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://support.f5.com/csp/article/K45644893

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201909-1109


【漏洞名称】Adobe ColdFusion 命令注入漏洞

【漏洞编号】CNNVD-201909-1103（CVE-2019-8073）

【漏洞详情】Adobe ColdFusion是美国奥多比（Adobe）公司的一套快速应用程序开发平台。该平台包括集成开发环境和脚本语言。

Adobe ColdFusion 2018 Update 4及之前版本和ColdFusion 2016 Update 11及之前版本中存在命令注入漏洞。攻击者可利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://helpx.adobe.com/security/products/coldfusion/apsb19-47.html

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201909-1103


【漏洞名称】IBM QRadar SIEM 跨站请求伪造漏洞

【漏洞编号】CNNVD-201909-1074（CVE-2019-4262）

【漏洞详情】IBM QRadar SIEM是美国IBM公司的一套利用安全智能保护资产和信息远离高级威胁的解决方案。该方案提供对整个IT架构范围进行监督、生成详细的数据访问和用户活动报告等功能。

IBM QRadar SIEM中存在跨站请求伪造漏洞。远程攻击者可通过发送未授权的请求利用该漏洞进行网络枚举或执行其他攻击。以下产品及版本受到影响：IBM QRadar 7.3版本至7.3.2 Patch 3版本，7.2版本至7.2.8 Patch 16版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://www.ibm.com/support/pages/security-bulletin-ibm-qradar-siem-vulnerable-server-side-request-forgery-cve-2019-4262

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201909-1074


【漏洞名称】Dell Update Package Framework 代码问题漏洞

【漏洞编号】CNNVD-201909-1085（CVE-2019-3726）

【漏洞详情】Dell Update Package（DUP）Framework是美国戴尔（Dell）公司的一款用于更新系统组件的框架。该产品主要提供驱动程序、应用程序、BIOS和固件的安装程序。

Dell DUP Framework文件中存在代码问题漏洞。本地攻击者可通过诱使管理员运行可信的库，进而加载恶意的DLL利用该漏洞在用户系统上执行任意代码。以下产品及版本受到影响：Dell Update Package (DUP) Framework file 19.1.0.413版本（Dell EMC Servers），103.4.6.69版本（Dell EMC Servers），3.8.3.67版本 （Dell Client Platforms）。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://www.dell.com/support/article/cn/zh/cnbsd1/sln318693/dsa-2019-065-dell-update-package-dup-framework-uncontrolled-search-path-vulnerability?lang=en

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201909-1085
