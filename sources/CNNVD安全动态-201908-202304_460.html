今日CNNVD共发布安全漏洞31个。主要影响厂商为美国ImageMagick Studio（6个）、美国Microsoft（2个）。主要影响产品为ImageMagick Studio ImageMagick图像处理软件（6个）、Microsoft Internet Explorer（IE）浏览器（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】ImageMagick Studio ImageMagick 安全漏洞

【漏洞编号】CNNVD-201909-1049（CVE-2019-16710）

【漏洞详情】ImageMagick Studio ImageMagick是美国ImageMagick Studio公司的一套开源的图像处理软件。该软件可读取、转换或写入多种格式的图片。

ImageMagick Studio ImageMagick 7.0.8-35版本中的coders/dot.c文件存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（内存损坏）。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://github.com/ImageMagick/ImageMagick/issues/1528

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201909-1049


【漏洞名称】Microsoft Internet Explorer 安全漏洞

【漏洞编号】CNNVD-201909-1071（CVE-2019-1367）

【漏洞详情】Microsoft Internet Explorer（IE）是美国微软（Microsoft）公司的一款Windows操作系统附带的Web浏览器。
Microsoft IE 9、10和11中脚本引擎处理内存对象的方法存在远程代码执行漏洞。攻击者可利用该漏洞在当前用户的上下文中执行任意代码，造成内存损坏。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2019-1367

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201909-1071


【漏洞名称】Linux kernel 信息泄露漏洞

【漏洞编号】CNNVD-201909-1063（CVE-2019-16714）

【漏洞详情】Linux kernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。

Linux kernel 5.2.14之前版本中的net/rds/recv.c文件的rds6_inc_info_copy存在信息泄露漏洞。该漏洞源于网络系统或产品在运行过程中存在配置等错误。未授权的攻击者可利用漏洞获取受影响组件敏感信息。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://cdn.kernel.org/pub/linux/kernel/v5.x/ChangeLog-5.2.14

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201909-1063


【漏洞名称】ZZZCMS zzzphp 输入验证错误漏洞

【漏洞编号】CNNVD-201909-1072（CVE-2019-16722）

【漏洞详情】ZZZCMS zzzphp是一套内容管理系统（CMS）。
ZZZCMS zzzphp v1.7.2版本中存在输入验证错误漏洞，该漏洞源于所使用的黑名单过滤机制并不严格。攻击者可利用该漏洞执行任意代码。
目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：
http://www.zzzcms.com

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201909-1072
