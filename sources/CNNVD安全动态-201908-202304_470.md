今日CNNVD共发布安全漏洞55个。主要影响厂商为美国IBM（5个）、美国Symantec（1个）。主要影响产品为IBM Cognos Analytics商业智能软件（2个）、Symantec Norton Password Manager for Android应用程序（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******IBM Cognos Analytics 跨站脚本漏洞****

**【漏洞编号】******CNNVD-201909-723（CVE-2019-4342）****

**【漏洞详情】**IBM Cognos Analytics是美国IBM公司的一套商业智能软件。该软件包括报表、仪表板和记分卡等，并可通过分析关键因素与关键人等内容，协助企业调整决策。

IBM Cognos Analytics 11.1版本和11.0版本中存在跨站脚本漏洞。远程攻击者可利用该漏洞在Web UI中注入任意JavaScript代码。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www.ibm.com/support/pages/node/1073530

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201909-723

  

**【漏洞名称】**************Symantec Norton Password Manager for Android 信息泄露漏洞************  

**【漏洞编号】******CNNVD-201909-776（CVE-2019-12755）****

**【漏洞详情】**Symantec Norton Password Manager for Android是美国赛门铁克（Symantec）公司的一款基于Android平台的密码管理应用程序。

基于Android平台的Symantec Norton Password Manager 6.5.0.2104之前版本中存在信息泄露漏洞。攻击者可利用该漏洞未授权获取信息。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://support.symantec.com/us/en/article.SYMSA1493.html

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201909-776

  

**【漏洞名称】****WordPress icegram插件跨站请求伪造漏洞**

**【漏洞编号】****CNNVD-201909-733（CVE-2016-10962）**

**【漏洞详情】**WordPress是WordPress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。icegram是使用在其中的一个订阅插件。

WordPress icegram插件1.9.19之前版本中存在跨站请求伪造漏洞。该漏洞源于WEB应用未充分验证请求是否来自可信用户。攻击者可利用该漏洞通过受影响客户端向服务器发送非预期的请求。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/icegram/#developers

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201909-733

  

**【漏洞名称】****GitLab 访问控制错误漏洞**

**【****漏洞****编号****】****CNNVD-201909-728（CVE-2019-16170）**

**【漏洞详情】**GitLab是美国GitLab公司的一款使用Ruby on Rails开发的、自托管的、Git（版本控制系统）项目仓库应用程序。该程序可用于查阅项目的文件内容、提交历史、Bug列表等。

GitLab（企业版）中存在访问控制错误漏洞。该漏洞源于网络系统或产品未正确限制来自未授权角色的资源访问。以下产品及版本受到影响：GitLab 11.x版本，12.0.9之前的12.x版本，12.1.9之前的12.1.x版本，12.2.5之前的12.2.x版本。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://about.gitlab.com/2019/09/10/critical-security-release-gitlab-12-dot-2-dot-5-released/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201909-728
