今日CNNVD共发布安全漏洞111个。主要影响厂商为美国GitLab（29个）、美国IBM（1个）。主要影响产品为GitLab应用程序（29个）、IBM WebSphere Application Server服务器（1个）。

今日需关注的典型漏洞如下:

【漏洞名称】GitLab 跨站脚本漏洞

【漏洞编号】CNNVD-201909-338（CVE-2019-11547）

【漏洞详情】GitLab是美国GitLab公司的一款使用Ruby on Rails开发的、自托管的、Git（版本控制系统）项目仓库应用程序。该程序可用于查阅项目的文件内容、提交历史、Bug列表等。

GitLab（社区版和企业版）11.8.9之前版本、11.9.10之前的11.9.x版本和11.10.2之前的11.10.x版本中存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://about.gitlab.com/2019/04/29/security-release-gitlab-11-dot-10-dot-2-released/

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201909-338


【漏洞名称】IBM WebSphere Application Server 路径遍历漏洞

【漏洞编号】CNNVD-201909-396（CVE-2019-4442）

【漏洞详情】IBM WebSphere Application Server（WAS）是美国IBM公司的一款应用服务器产品。该产品是JavaEE和Web服务应用程序的平台，也是IBMWebSphere软件平台的基础。

IBM WAS中的Admin Console存在路径遍历漏洞。远程攻击者可通过发送特制的URL请求利用该漏洞查看系统上的任意文件（不包括内容）。以下产品及版本受到影响：IBM WAS 9.0版本，8.5版本，8.0版本，7.0版本。
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://www.ibm.com/support/pages/security-bulletin-path-traversal-vulnerability-websphere-application-server-admin-console-cve-2019-4442

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201909-396


【漏洞名称】WordPress charitable插件信息泄露漏洞

【漏洞编号】CNNVD-201909-311（CVE-2018-21011）

【漏洞详情】WordPress是WordPress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。charitable是使用在其中的一个在线捐赠平台构建插件。

WordPress charitable插件1.5.14之前版本中存在信息泄露漏洞。攻击者可利用该漏洞未授权访问用户和捐赠详情。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://wordpress.org/plugins/charitable/#developers

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201909-311


【漏洞名称】image crate for Rust 资源管理错误漏洞

【漏洞编号】CNNVD-201909-303（CVE-2019-16138）

【漏洞详情】image crate for Rust是一款基于Rust的图像编码/解码库。

image crate for Rust 0.21.3之前版本中存在资源管理错误漏洞。攻击者可利用该漏洞执行任意代码。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：
https://github.com/image-rs/image/pull/985

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201909-303
