今日CNNVD共发布安全漏洞115个。主要影响厂商为芬兰Mirasys（3个）、美国Sonatype（1个）。主要影响产品为Mirasys Video Management System视频管理系统（3个）、Sonatype Nexus Repository Manager仓库管理器（1个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******Mirasys Video Management System 路径遍历漏洞****

**【漏洞编号】******CNNVD-201908-1811********（CVE-2019-11029）****

**【漏洞详情】**Mirasys Video Management System（VMS）是芬兰Mirasys公司的一套监控视频管理系统。

Mirasys VMS 7.6.1之前版本和8.3.2之前的8.x版本中存在路径遍历漏洞，该漏洞源于程序没有正确处理AutoUpdateService的Download()方法。攻击者可借助‘..’序列利用该漏洞下载感兴趣的系统文件，包括：SAM数据库备份文件和Web.config文件。目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：https://mirasys.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-1811

  

**【漏洞名称】**************Sonatype Nexus Repository Manager 跨站脚本漏洞************  

**【漏洞编号】**********CNNVD-201908-1824********（CVE-2019-14469）********

**【漏洞详情】**Sonatype Nexus Repository Manager（NXRM）是美国Sonatype公司的一款Maven仓库管理器。

Sonatype NXRM 3.18.0及之前版本中存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://support.sonatype.com/hc/en-us/articles/360033999733-CVE-2019-14469-Nexus-Repository-Manager-3-Cross-Site-Scripting-XSS-2019-07-26

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-1824

  

**【漏洞名称】******WordPress gallery-by-supsystic插件跨站请求伪造漏洞****

**【漏洞编号】**********CNNVD-201908-1751**************（CVE-2016-10918）******

**【漏洞详情】**WordPress是WordPress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。gallery-by-supsystic是使用在其中的一个图片库插件。

WordPress gallery-by-supsystic插件1.8.6之前版本中存在跨站请求伪造漏洞。该漏洞源于WEB应用未充分验证请求是否来自可信用户。攻击者可利用该漏洞通过受影响客户端向服务器发送非预期的请求。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://wordpress.org/plugins/gallery-by-supsystic/#developers

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-1751

  

**【漏洞名称】******Elasticsearch Elastic APM agent for Python 安全漏洞****

**【****漏洞****编号****】****CNNVD-201908-1818********（**CVE-2019-7617）****

**【漏洞详情】**Elasticsearch Elastic APM agent for Python是荷兰Elasticsearch公司的一款基于Python的Elastic APM（应用程序性能监控）代理程序。

Elasticsearch Elastic APM agent for Python 5.1.0之前版本中存在安全漏洞。攻击者可利用该漏洞将被收集到的APM数据重定向到攻击者所选择的代理中。目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://discuss.elastic.co/t/elastic-apm-agent-for-python-5-1-0-security-update/196145

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-1818
