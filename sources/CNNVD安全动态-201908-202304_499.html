今日CNNVD共发布安全漏洞84个。主要影响厂商为美国Apple（2个）、美国Trend Micro（2个）。主要影响产品为Apple CUPS打印系统（2个）、Trend Micro Password Manager解决方案（2个）。

今日需关注的典型漏洞如下:

【漏洞名称】Apple CUPS 缓冲区错误漏洞

【漏洞编号】CNNVD-201908-1293（CVE-2019-8675）

【漏洞详情】Apple CUPS是美国苹果（Apple）公司的一套开源的用于OS X和类Unix系统的打印系统。该系统基于Internet打印协议（IPP），提供大多数PostScript和raster打印机服务。

Apple CUPS中的‘asn1_get_type’函数存在缓冲区错误漏洞。远程攻击者可借助特制的网络流量利用该漏洞造成CUPS崩溃。
目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：
https://github.com/apple/cups/commit/f24e6cf6a39300ad0c3726a41a4aab51ad54c109

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-1293


【漏洞名称】Trend Micro Password Manager 安全漏洞

【漏洞编号】CNNVD-201908-1300（CVE-2019-14684）

【漏洞详情】Trend Micro Password Manager是美国趋势科技（Trend Micro）公司的一套安全的密码管理解决方案。

Trend Micro Password Manager 5.0版本中存在安全漏洞。攻击者可利用该漏洞将任意未签名的DLL加载到已签名的服务进程中。
目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：
https://esupport.trendmicro.com/en-us/home/pages/technical-support/1123396.aspx

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-1300


【漏洞名称】WordPress 360-product-rotation插件跨站脚本漏洞

【漏洞编号】CNNVD-201908-1302（CVE-2019-15082）

【漏洞详情】WordPress是WordPress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。360-product-rotation是使用在其中的一个物品360度视图添加插件。

WordPress 360-product-rotation插件1.4.8之前版本中存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。
目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：
https://wordpress.org/plugins/360-product-rotation/#developers

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-1302


【漏洞名称】IBM InfoSphere Information Governance Dashboard和InfoSphere Information Server on Cloud 信息泄露漏洞

【漏洞编号】CNNVD-201908-1374（CVE-2019-4453）

【漏洞详情】IBM InfoSphere Information Server on Cloud和IBM InfoSphere Information Server都是美国IBM公司的产品。IBM InfoSphere Information Server on Cloud是一套基于云的数据整合平台。IBM InfoSphere Information Server是一套数据整合平台。该平台可用于整合各种渠道获取的数据信息。

IBM InfoSphere Information Governance Dashboard和InfoSphere Information Server on Cloud中存在信息泄露漏洞。攻击者可利用该漏洞泄露敏感信息。以下产品及版本受到影响：IBM InfoSphere Information Governance Dashboard 11.3版本，11.5版本，11.7版本；InfoSphere Information Server on Cloud 11.5版本，11.7版本。
目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：
https://www-01.ibm.com/support/docview.wss?uid=ibm10960169

【漏洞链接】

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201908-1374
