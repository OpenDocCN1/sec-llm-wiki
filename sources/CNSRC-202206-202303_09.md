D-Eye是一个支持Yara规则的应急响应工具，该工具支持部分勒索挖矿病毒的查杀，支持指定文件、目录、进程、外联IP扫描告警，支持基线信息扫描，Linux下支持空密码账户检测、SSH Server wrapper检测、SSH用户免密证书登录检测、主机 Sudoer检测、alias检测、Setuid检测、SSH登录爆破检测、主机Rootkit检测。该版本为spring漏洞预排查专版，支持spring漏洞扫描。

### D-Eyes应急响应工具说明

注：目前只支持64位操作系统，运行时Windows请以管理员运行，Linux请以root运行。Windows暂不支持对中文文件名的检测。本版本为spring漏洞预排查专版。

**挖矿：**

**僵尸网络：**

#### 二.yara规则添加方式：将写好的yara规则添加到 "yaraRules" 目录下即可

#### 三.工具使用方式

**1.文件检测模块参数介绍**

filescan/fs: 指定文件扫描功能

\-path/-P: 指定扫描路径(默认为“ C:// ”或者“ / ”)，如：‍windows‍版：“ -path C:// ”；Linux版：“ -path / ”

\-rule/-r: 指定单一规则扫描(可选参数)，即将yaraRules目录下的规则去掉后缀".yar", 如：“ -rule Ransom.Wannacrypt”

\-thread/-t：指定线程数(可选参数)，默认为5，如：“ -thread 1 ”

**  2.文件检测模块扫描方式：**

  （1）用全部规则对文件进行扫描（不指定rule参数即可），扫描结束后若发现漏洞会生成D-Eyes.xlsx

Windows：

D-Eyes filescan -path C:// -thread 3

Linux：

./D-Eyes filescan -path / -thread 3

缩简命令：

Windows：

D-Eyes fs -P C:// -t 3

Linux：

./D-Eyes fs -P / -t 3

**（2）用单一规则对文件进行扫描，扫描结束后若发现漏洞会生成D-Eyes.xlsx**

Windows:

D-Eyes filescan -path C:// -rule Ransom.Wannacrypt

Linux:

./D-Eyes filescan -path / -rule Ransom.Wannacrypt

缩简命令：

D-Eyes fs -P C:// -r Ransom.Wannacrypt

Linux:

./D-Eyes fs -P / -r Ransom.Wannacrypt

**3.进程模块**

 （1）参数介绍

processcan/ps: 指定进程扫描功能

\-pid/-p: 指定扫描路径，如：“-pid 6666” (可选参数，默认扫描全部进程)

\-rule/-r: 指定单一规则扫描(可选参数)，即将yaraRules目录下的规则去掉后缀".yar", 如：“ -rule Ransom.Wannacrypt”

（2）使用方式

Windows:

D-Eyes processcan                            //利用所有规则扫描全部进程

D-Eyes processcan  -pid 6666                 //利用所有规则扫描6666进程

D-Eyes processcan -rule Ransom.Wannacrypt    //用Wannacrypt规则扫描全部进程

Linux:

./D-Eyes processcan                          //利用所有规则扫描全部进程

./D-Eyes processcan  -pid 6666               //利用所有规则扫描6666进程

./D-Eyes processcan -rule Ransom.Wannacrypt  //用Wannacrypt规则扫描全部进程

缩简命令：

Windows:

D-Eyes ps                          //利用所有规则扫描全部进程

D-Eyes ps  -p 6666                 //利用所有规则扫描6666进程

D-Eyes ps -r Ransom.Wannacrypt     //用Wannacrypt规则扫描全部进程

Linux:

./D-Eyes ps                        //利用所有规则扫描全部进程

./D-Eyes ps  -p 6666               //利用所有规则扫描6666进程

./D-Eyes ps -r Ransom.Wannacrypt   //用Wannacrypt规则扫描全部进程

 (3) 进程外联IP：ip.config 配置文件说明

可将恶意ip添加到该文件当中，软件会自动检测是否有进程连接该IP。

ip.config 文件格式(换行添加即可)，如：

0.0.0.0

127.0.0.1
