安全公告编号:CNTA-2019-0003

01月08日，微软发布了2019年01月份的月度例行安全公告，修复了其多款产品存在的162个安全漏洞。受影响的产品包括：Windows 10 v1809 and Windows Server 2019（26个）、Windows 10 v1803 and Windows Server v1803（27个）、Windows 10 v1709 and Windows Server v1709（25个）、Windows 8.1 and Server 2012 R2（19个）、Windows Server 2012（18个）、Windows 7 and Windows Server 2008 R2（16个）、Windows Server 2008（16个）、Internet Explorer（1个）、Microsoft Edge（5个）和Office（9个）。

利用上述漏洞，攻击者可以执行远程代码，提升权限，绕过安全功能限制，获取敏感信息或进行拒绝服务攻击等。CNVD提醒广大Microsoft用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。
