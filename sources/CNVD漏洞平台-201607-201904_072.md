# Microsoft发布2018年10月安全更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU3ODM2NTg2Mg==&mid=2247486123&idx=1&sn=b39b5bade6eedabd1547fa00edf58ac9&chksm=fd773a62ca00b37463a1e85a7e4bbf56ccd03ef5caca72ea8d1a695f38e4ff4a2e5a249a61da&scene=126&sessionid=1681365911#rd](http://mp.weixin.qq.com/s?__biz=MzU3ODM2NTg2Mg==&mid=2247486123&idx=1&sn=b39b5bade6eedabd1547fa00edf58ac9&chksm=fd773a62ca00b37463a1e85a7e4bbf56ccd03ef5caca72ea8d1a695f38e4ff4a2e5a249a61da&scene=126&sessionid=1681365911#rd)

安全公告编号:CNTA-2018-0027  

10月9日，微软发布了2018年10月份的月度例行安全公告，修复了其多款产品存在的118个安全漏洞。受影响的产品包括Windows 10 v1809 and Windows Server 2019（19个）、Windows 10 v1803 Windows Server v1803（21个）、Windows 10 v1709 Windows Server v1709（21个）、Windows 8.1 and Windows Server 2012 R2（15个）、Windows Server 2012（14个）、Windows7 and Windows Server 2008 R2（14个）和WindowsServer 2008（14个）。

利用上述漏洞，攻击者可以提升权限，绕过安全功能限制，获取敏感信息，执行远程代码或发起拒绝服务攻击等。CNVD提醒广大Microsoft用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。
