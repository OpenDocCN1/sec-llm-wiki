# 上周关注度较高的产品安全漏洞(20180430-20180506)

**一、境外厂商产品漏洞**  
**1****、****Apple MacOS****提权漏洞**

macOS是苹果公司为Mac系列产品开发的专属操作系统。攻击者可以利用漏洞执行未经授权的操作，并获得较高的权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-08835

**2****、****Windows Host Compute ServiceShim****远程代码执行漏洞**

MicrosoftWindows 10等都是美国微软（Microsoft）公司发布的一系列操作系统。攻击者利用此漏洞会将恶意代码放入特制的容器映像中，如果经过身份验证的管理员导入（拉出），可能会导致使用Host Compute Service Shim库的容器管理服务在Windows主机上执行恶意代码

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-08834

**3****、多款****WECON****产品缓冲区溢出漏洞**

WECONLeviStudio HMI Editor和PI Studio HMI Project Programmer都是中国维控科技公司的人机界面编程软件。远程攻击者可借助特制的文件执行代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-08900

**4****、****Delta PMSoft****缓冲区溢出漏洞**

PMSoft是在由DELTAELECTRONICS,INC.开发类别Miscellaneous Shareware软件。攻击者可利用漏洞执行任意代码或导致应用程序崩溃。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-08899

**5****、****Apache Fineract SQL****注入漏洞（****CNVD-2018-08693****）**

ApacheFineract是美国阿帕奇（Apache）软件基金会的一套开源数字金融服务平台。远程攻击者可通过发送特制的SQL语句利用该漏洞查看、添加、更改或删除后端数据库中的信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-08693

**二、境内厂商产品漏洞**  
**1****、温州乔宇科技有限公司建站系统存在****SQL****注入漏洞**

温州乔宇科技有限公司是一家专注于高品质网站建设、微站开发、网络营销服务（SEO优化）为一体的创新级公司。攻击者可利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-06319

**2****、****Huawei E5771h-937****拒绝服务漏洞**

HuaweiE5771h-937是中国华为（Huawei）公司的一款便携式无线路由器。攻击者可通过向设备发送特定的HTTP请求利用该漏洞造成拒绝服务（webserver进程无法响应）。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-08877

**3****、****TPshop web****后门漏洞**

TPsho作为一款电商系统，被多个商家作为电商系统解决方案。攻击者利用该漏洞下载任意文件，扫描网络端口，攻击内部网络甚至远程命令执行。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-08791

**4****、****2345****安全卫士存在缓冲区溢出漏洞**

2345是一款保护用户安全上网的网络软件。攻击者可以利用该漏洞发送超长数据导致任意代码执行。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-06406

**5****、泰安星际网络科技有限公司建站系统存在****SQL****注入漏洞**

泰安星际网络有限公司是一家涉及网站建设、网站推广、网络营销、400免费电话等业务，以互联网技术为核心的高新技术企业。攻击者可利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-06938

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
