# 上周关注度较高的产品安全漏洞(20180416-20180422)

**一、境外厂商产品漏洞**  
**1****、****Oracle WebLogic Server WLS****核心组件反序列化漏洞**

OracleWebLogic server是一款应用服务器平台，用于构建和运行企业应用和服务。远程攻击者可利用漏洞在未授权的情况下远程执行代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-07811

**2****、****Yokogawa CENTUM and Exaopc****权限提升漏洞**

CENTUMCS 3000、CENTUM VP等都是横河的电机产品。本地攻击者可利用漏洞产生错误的系统或进程警报，或者阻止系统或进程警报显示。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-07299

**3****、****Microsoft Internet Explorer****远程代码执行漏洞（****CNVD-2018-07778****）**

MicrosoftWindows Server 2012等都是美国微软（Microsoft）公司发布的一系列操作系统。Internet Explorer（IE）是其中的一款Windows操作系统附带的Web浏览器。远程攻击者可利用该漏洞执行任意代码，破坏内存。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-07778

**4****、****Moxa EDR-810****命令注入漏洞**

MoxaEDR-810是一款具有防火墙/NAT/VPN和受管理第2层交换机功能的工业安全路由器。攻击者通过将OS命令注入“/goform/net\_WebCSRGen”uri中的CN = parm，从而提升特权，导致rootshell。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-07865

**5****、****LCDS LAquis SCADA****任意代码执行漏洞**

LCDSLAquis SCADA巴西LCDS公司的一套用于监控和数据采集的SCADA软件。攻击者可利用该漏洞执行代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-07745

 

**二、境内厂商产品漏洞**  
**1****、****POCMS****程序版本****v3.2.0****后台存在代码执行漏洞**

POSCMS系统是一款基于CodeIgniter框架的内容管理系统。攻击者可利用该漏洞执行代码，从而获取服务器控制权。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-05004

**2****、****Monxin v4.0****存在任意文件上传漏洞**

Monxin全网通商城系统是一款基于PC商城+手机商城+微信商城+线下收银，会员/订单/商品/库存线上线下全网数据实时同步的商城管理系统。攻击者可利用该漏洞解压木马文件，从而获取webshell。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-04999

**3****、****Finecms V5.3.0****后台存在远程命令执行漏洞**

FineCMS（简称免费版、企业版、公益版）是一款基于PHP+MySql+CI框架开发的高效简洁的中小型内容管理系统。攻击者可利用该漏洞写入木马脚本，从而获取服务器控制权。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-05005

**4****、推券客****CMS v1.8****存在代码执行漏洞**

推券客CMS是一个以PHP+MySQL进行开发的PHP淘宝客优惠券网站。攻击者可利用该漏洞上传木马文件，从而获取webshell。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-05171

**5****、****axublog****建站系统****v1.1.0****版本存在代码执行漏洞**

Axublog是一款PHP个人博客系统。攻击者可利用漏洞执行任意代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-05700

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
