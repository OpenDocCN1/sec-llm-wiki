# 上周关注度较高的产品安全漏洞(20180326-20180401)

**一、境外厂商产品漏洞**  
**1****、****Drupal core****远程代码执行漏洞（****CNVD-2018-06660****）**

Drupal是Drupal社区所维护的一套用PHP语言开发的免费、开源的内容管理系统。攻击者可利用漏洞实现远程代码执行攻击，从而影响到业务系统的安全性。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-06660

**2****、****Beckhoff TwinCAT****不可信指针引用漏洞**

BeckhoffTwinCAT系统软件可通过多PLC系统、NC轴控制系统、编程环境和操作站。攻击者利用漏洞可以提升对系统的访问权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-06288

**3****、****Cisco IOS****和****IOS XE****缓冲区溢出漏洞**

思科IOS是思科公司为其网络设备开发的操作维护系统。攻击者可利用漏洞导致设备重新加载、在设备上执行任意代码、导致设备无限循环。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-06774

**4****、****Siemens SIMATIC WinCC OA UIfor Android****和****iOS****访问绕过漏洞**

SiemensSIMATIC WinCC OA UI for Android和iOS都是德国西门子（Siemens）公司的产品。攻击者可通过诱使用户连接到攻击者控制的WinCC OA服务器，利用该漏洞读取或向应用程序文件夹中写入数据。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-06261

**5****、****Schneider Electric****多款产品弱加密算法漏洞**

SchneiderElectric Modicon Premium\\Modicon Quantum\\Modicon M340\\Modicon BMXNOR0200都是法国施耐德电气公司的可编程控制器产品。攻击者可利用漏洞导致缓冲区溢出。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-06519

**二、境内厂商产品漏洞**  
**1****、多款****Huawei****交换机存在授权不当漏洞**

HuaweiS12700是中国华为（Huawei）公司的企业级交换机产品。攻击者可利用漏洞导致信息泄露。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-06688

**2****、****UCMS 1.2****版本存在文件上传漏洞**

UCMS是一款简单的开源内容管理系统。攻击者可利用漏洞直接上传脚本木马文件，获取webshell。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-04289

**3****、****joyplus-cms****任意文件上传漏洞**

joyplus-cms（悦视频）是一套基于PHP和MySQL的开源视频后台管理系统。远程攻击者可利用该漏洞上传任意文件，执行代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-06780

**4****、珠海美天网页设计有限公司建站系统存在****SQL****注入漏洞**

珠海美天网页设计有限公司是致力于网页制作、网站推广的生产厂家和供应商。攻击者可利用漏洞获得数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-03948

**5****、网站安全狗存在****SQL****注入漏洞**

安全狗是一款集服务器安全防护和安全管理为一体的综合性服务器安全防护工具。攻击者可利用漏洞获得数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-03946

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
