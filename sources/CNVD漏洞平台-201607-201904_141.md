# 上周关注度较高的产品安全漏洞(20180312-20180318)

**一、境外厂商产品漏洞**  
**1****、****MikroTik RouterOS****缓冲区溢出漏洞**

MikroTikRouterOS是MikroTik公司基于Linux内核开发的一种路由操作系统。未经身份验证的远程攻击者可以利用此漏洞获取该系统的代码执行权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-05801

**2****、****Geutebruck IP Cameras****跨站脚本漏洞**

G-Cam/EFD-2250和ToplineTopFD-2125都是Geutebruck公司的一款高清摄像机。远程攻击者可利用漏洞执行任意代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-06023

**3****、****HP LoadRunner****和****Performance Center****远程代码执行漏洞**

HPE LoadRunner和PerformanceCenter都是美国惠普企业（Hewlett Packard Enterprise，HPE）公司的性能负载测试软件。远程攻击者可利用该漏洞执行代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-05577

**4****、****Microsoft Windows****远程协助信息泄露漏洞**

MicrosoftWindows是流行的计算机操作系统。攻击者可利用漏洞获取敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-06069

**5****、****Geutebruck IP Cameras SQL****注入漏洞**

G-Cam/EFD-2250和ToplineTopFD-2125都是Geutebruck公司的一款高清摄像机。允许攻击者利用漏洞更改存储的数据。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-06024

**二、境内厂商产品漏洞**  
**1****、华为多个产品越界写漏洞**

HuaweiAR120-S等都是中国华为（Huawei）公司的路由器产品。远程攻击者可通过发送异常的OSPF消息利用该漏洞造成拒绝服务（越边界写入和系统崩溃）。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-05550

**2****、****ShopsN v2.2.5****正式版前台****AppUploadController.class.php****页面存在文件上传漏洞（****CNVD-2018-02969****）**

ShopsN商城系统是上海亿速网络科技有限公司旗下产品，一款企业级商用标准全功能的允许免费商业用途的开源网店全网系统。允许攻击者利用漏洞上传脚本木马，获取Webshell。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-02969

**3****、****Shop7z****网上购物系统至尊版存在****SQL****注入漏洞**

Shop7z网上购物系统是ASP网上开店平台软件，提供全面的基于互联网解决方案的应用服务。攻击者利用漏洞可访问或修改数据库数据。

参考链接：hhttp://www.cnvd.org.cn/flaw/show/CNVD-2018-03486

**4****、****Huawei DBS3900 TDD LTE****弱加密算法漏洞**

DBS3900TDD LTE是中国华为（Huawei）公司的一款采用模块化设计的网络设备产品。远程攻击者可利用漏洞破解加密数据，导致信息泄露。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-06068

**5****、大米****CMS v5.9.9****存在代码执行漏洞**

大米CMS是一个免费开源的PC建站和手机建站集成一体化系统。该漏洞是由于系统未能对上传的文件内容进行充分过滤。攻击者可利用该漏洞上传木马文件，并获取webshell。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-03745

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
