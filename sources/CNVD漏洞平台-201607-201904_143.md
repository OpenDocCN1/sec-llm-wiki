# 上周关注度较高的产品安全漏洞(20180312-20180318)

**一、境外厂商产品漏洞**  
**1****、****Chrome OS****任意命令执行漏洞**

GoogleChrome OS是美国谷歌（Google）公司开发的一套基于Web的快速、轻量型的开源操作系统。远程攻击者可利用该漏洞在启动时执行任意命令。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-04876

**2****、****Cisco Identity Services Engine****命令注入漏洞（****CNVD-2018-05089****）**

CiscoIdentity Services Engine（ISE）是美国思科公司的一款基于身份的环境感知平台（ISE身份服务引擎）。本地攻击者可通过认证为管理用户，发送CLI命令并向命令参数中注入恶意的输入利用该漏洞向底层操作系统中注入命令或造成用户会话挂起或断开。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-05089

**3****、****IBM Application PerformanceManagement-Response Time Monitoring Agent****跨站请求伪造漏洞**

IBMApplication Performance Management-Response Time Monitoring Agent是美国IBM公司的一款用于应用程序性能管理的程序响应时间监控代理。远程攻击者可利用该漏洞执行未授权的操作。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-04991

**4****、****Adobe Shockwave Player****远程内存破坏漏洞（****CNVD-2018-05011****）**

AdobeShockwave Player是播放使用Macromedia和Adobe Director制作的网页内容的软件。远程攻击者执行任意代码或造成拒绝服务。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-05011

**5****、****Microsoft Windows kernel****权限提升漏洞（****CNVD-2018-05040****）**

MicrosoftWindows是美国微软（Microsoft）公司发布的一系列操作系统。攻击者可通过登录系统并运行特制的应用程序利用该漏洞在内核模式下执行任意代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-05040

**二、境内厂商产品漏洞**  
**1****、****JTBC****网站内容管理系统****(PHP)manage.inc.php****页面存在任意文件上传漏洞**

TBC网站内容管理系统(PHP)是一套可对现有模块进行扩充与克隆的网站系统核心。允许攻击者利用漏洞通过上传脚本木马，控制服务器权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-02519

**2****、****DedeCMS****后台缓存文件存在代码执行漏洞**

织梦内容管理系统(DedeCms)是一款PHP开源网站管理系统。允许攻击者利用漏洞生成的缓存文件被加载执行，导致可执行任意代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-02966

**3****、****Huawei Mate 9 Pro****内存释放漏洞**

HuaweiMate 9 Pro是中国华为（Huawei）公司的一款智能手机。攻击者通过诱使已获取root权限的用户安装精心设计的应用程序，可导致恶意代码执行。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-05336

**4****、叶凡网络建站系统存在****SQL****注入漏洞**

叶凡网络是集APP开发、H5开发、网站开发、微信开发及企业品牌宣传于一体的一站式服务企业是互联网综合服务提供商。攻击者可利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-02963

**5****、****YUNUCMS v1.0.6****后台存在代码执行漏洞**

YUNUCMS是一款三网合一、开源自带分站系统的内容管理系统。 攻击者可通过构造脚本代码写入配置文件，从而执行命令，获得服务器权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-02776

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
