# 上周关注度较高的产品安全漏洞(20180305-20180311)

**一、境外厂商产品漏洞**  
**1****、****Exim SMTP Mail Server****存在缓冲区溢出漏洞**

Exim是一个MTA（MailTransfer Agent，邮件传输代理）服务器软件。攻击者可利用该漏洞绕过了ASLR、PIE、NX等系统通用系统缓解措施，在受影响的应用程序上下文中执行任意代码，若攻击尝试失败仍可导致拒绝服务。

参考链接：http://www.cnvd.org.cn/webinfo/show/4433

**2****、****Siemens 300/400****系列****PLC****远程控制漏洞**

可编程控制器（即PLC）是一种新型工业自动控制装置。攻击者可以通过Siemens PLC通过102端口进行TCP通信，该脚本通过向PLC的102端口发送特定的报文可实现远程控制PLC的启停。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-26804

**3****、****Joomla! JS Support Ticket****跨站请求伪造漏洞**

Joomla!是美国OpenSource Matters团队开发的一套开源的内容管理系统(CMS)。远程攻击者可利用该漏洞执行未授权的操作，例如：注入HTML或编辑票据。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-02809

**4****、****Apache Traffic Server****权限提升漏洞**

ApacheTraffic Server（ATS）是美国阿帕奇（Apache）软件基金会的一款高效、可扩展的HTTP代理和缓存服务器。攻击者可利用该漏洞获取访问权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-04646

**5****、****Linux kernel****拒绝服务漏洞（****CNVD-2018-04627****）**

Linuxkernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。本地攻击者可利用该漏洞造成拒绝服务（空指针逆向引用）。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-04627

**二、境内厂商产品漏洞**  
**1****、网站安全狗****(IIS****版****)****存在****Webshell****绕过漏洞**

网站安全狗IIS版是一款集网站内容安全防护、网站资源保护及网站流量保护功能为一体的服务器工具。攻击者可绕过安全狗的过滤上传Webshell。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-02515

**2****、多款****Lenovo****产品****Fingerprint Manager Pro****硬编码密码**

LenovoThinkPad L560等都是中国联想（Lenovo）公司的电脑产品。攻击者可利用该漏洞访问系统。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-04363

**3****、****phpyun v4.3.1 Beta****存在重装漏洞**

PHP云人才系统（phpyun）是一个采用PHP和MySQL数据库构建的开源人才与企业求职招、聘解决方案。攻击者可利用该漏洞重装系统。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-02398

**4****、****ECShop 3.0****存在代码执行漏洞**

ECShop是一款B2C独立网店系统，适合企业及个人快速构建个性化网上商店。攻击者可利用该漏洞执执行代码，获取getshell。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-02771

**5****、海康科技终端特征管控系统存在未授权访问漏洞**

浙江海康科技有限公司专注于智能控制技术的研究、开发、设计、制造，是国内智能控制技术/产品提供商。攻击者可利用漏洞绕过权限认证，访问敏感目录或文件。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-02410

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
