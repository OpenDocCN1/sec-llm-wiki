# 上周关注度较高的产品安全漏洞(20180212-20180225)

**一、境外厂商产品漏洞**  
**1****、****Apache POI****拒绝服务漏洞（****CNVD-2018-03242****）**

ApachePOI是美国阿帕奇（Apache）软件基金会的一个开源函数库。攻击者可借助特制的WMF、EMF、MSG和宏或特制的DOC、PPT和XLS利用该漏洞造成拒绝服务（内存不足和无限循环）。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-03242

**2****、****Apache JMeter****远程命令执行漏洞**

Apache Jmeter是一款旨在为负载测试功能行为和测量性能的开源的Java应用程序。攻击者可利用漏洞执行任意命令.

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-03472

**3****、****CloudBees Jenkins MavenPlugin****中间人攻击漏洞**

CloudBeesJenkins是美国CloudBees公司的一套基于Java开发的持续集成工具。攻击者可利用该漏洞实施中间人攻击。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-03331

**4****、****Joomla! Component CW Tags SQL****注入漏洞**

Joomla!是美国OpenSource Matters团队开发的一套开源的内容管理系统(CMS)。攻击者可利用该漏洞危及应用程序，访问或修改数据，或利用底层数据库中潜在的漏洞。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-03430

**5****、****MozillaFirefox/Thunderbird/SeaMonkey****不可信搜索路径漏洞**

MozillaFirefox是美国Mozilla基金会开发的一款开源Web浏览器。远程攻击者可借助与.htm，.html，.jtx，.mfp或.eml文件位于相同文件夹中的dwmapi.dll木马执行任意代码和DLL劫持攻击。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-03431

**二、境内厂商产品漏洞**  
**1****、****SANGFOR AF****存在命令注入漏洞**

SANGFORAF是一款以应用安全需求出发而设计的下一代应用防火墙。攻击者可利用该漏洞执行任意系统命令并获取root权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-02782

**2****、网站安全狗****(IIS****版****)****存在上传绕过漏洞**

网站安全狗IIS版是一款集网站内容安全防护、网站资源保护及网站流量保护功能为一体的服务器工具。攻击者可绕过安全狗的拦截上传文件。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-01061

**3****、北京五岳鑫信息技术股份有限公司鑫****e****评网上评卷系统存在多个漏洞**

鑫e评校园版网上评卷系统是北京五岳鑫公司专为学校定制的校园级网上评卷软硬件全套解决方案。攻击者可利用该漏洞获得敏感信息，进一步获得网站服务器控制权。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-00864

**4****、联想防火墙存在弱口令和远程命令执行漏洞**

LFW800E是联想天工网络为中型企业用户网络安全应用开发的一款千兆智能防火墙。攻击者可利用该漏洞成功登录系统，获取敏感信息，上传webshell，获取服务器权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-01059

**5****、中科网威****ANYSEC****安全网关存在默认口令和远程命令执行漏洞**

ANYSEC-M6100是一款标准1U机架式VPN安全接入网关。允许攻击者登录后台，构造特定代码，远程执行命令，写入webshell，获取服务器权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-00863

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
