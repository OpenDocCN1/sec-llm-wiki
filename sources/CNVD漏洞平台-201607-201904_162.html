一、境外厂商产品漏洞
1、Android平台WebView控件存在跨域访问高危漏洞

WebView是Android用于显示网页的控件。攻击者利用该漏洞，可远程获取用户隐私数据（包括手机应用数据、照片、文档等敏感信息），还可窃取用户登录凭证。

参考链接：http://www.cnvd.org.cn/webinfo/show/4365

2、Google Android System组件权限提升漏洞

Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。远程攻击者可利用该漏洞执行任意代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-00650

3、Microsoft Windows Subsystemfor Linux权限提升漏洞（CNVD-2018-00519）

MicrosoftWindows 10和Windows Server Version 1709都是美国微软（Microsoft）公司的产品。攻击者可通过登录系统并运行特制的应用程序利用该漏洞执行任意代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-00519

4、派尔高(pelco) Sarix Pro网络摄像机set_param程序存在越权访问漏洞

pelcoSarix Professional是一款摄像机。攻击者利用漏洞无需认证即可远程开启ssh服务，从而完全控制摄像头。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-36467

5、PHP Scripts Mall SingleTheater Booking SQL注入漏洞

PHPScripts Mall Single Theater Booking是一款开源剧院脚本。远程攻击者可通过向admin/movieview.php文件发送‘movieid’参数利用该漏洞获取当前数据的用户名或敏感数据。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-00499

 

二、境内厂商产品漏洞
1、DeDeCMS v5.7 SP2正式版前台任意用户密码修改漏洞

DedeCms（织梦内容管理系统) 是一款PHP开源网站管理系统。攻击者可利用漏洞在前台会员中心绕过验证，修改任意用户密码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-00867

2、多多返利V8.3_UTF8正式版admin_mod_goods_list.act.php存在SQL注入漏洞

多多返利为电商返利、导购提供解决方案，是开源PHP返利网站系统。攻击者可利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-36953

3、WPS Office存在栈溢出漏洞

WPSOffice是由金山软件股份有限公司自主研发的一款办公软件套装。攻击者利用该漏洞在目标系统上执行恶意代码，远程安装恶意软件，进而可能控制整个操作系统。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-36825

4、SEMCMS_ASP_v4.5存在文件上传漏洞

SemCMS是一套开源外贸企业网站管理系统。攻击者可利用该漏洞上传脚本文件，获取网站控制权。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-36824

5、三今网络网站建设系统存在SQL注入漏洞

广州市三今网络技术有限公司是一家互联网应用服务供应商。攻击者可利用该漏洞获取数据库信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-37163

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
