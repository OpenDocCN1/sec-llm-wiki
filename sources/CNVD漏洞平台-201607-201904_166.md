# 上周关注度较高的产品安全漏洞(20180101-20180107)

**一、境外厂商产品漏洞**  
**1****、****Western Digital My Cloud NAS****设备跨站请求伪造漏洞**

Western Digital MyCloud NAS是一款网络连接存储设备。攻击者可将受害者的网络浏览器连接到My Cloud设备并执行未授权操作。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-00402

**2****、****ImageMagick****拒绝服务漏洞（****CNVD-2018-00102****）**

ImageMagick是一个用来创建、编辑、合成图片的软件，可以读取、转换、写入多种格式的图片。攻击者可通过特制mng图像文件利用该漏洞导致拒绝服务。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-00102

**3****、****Microsoft Windows Edge****和****Microsoft ChakraCore****远程代码执行漏洞（****CNVD-2018-00328****）**

Microsoft Windows 10和Windows Server 2016都是美国微软（Microsoft）公司的产品。远程攻击者可利用该漏洞在当前用户的上下文中执行任意代码，破坏内存。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-00328

**4****、****WordPress Oturia Smart GoogleCode Inserter****插件****SQL****注入漏洞**

WordPress是WordPress软件基金会的一套使用PHP语言开发的博客平台。远程攻击者可利用该漏洞在Web服务器的上下文中执行SQL查询语句。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-00355

**5****、****Apple macOS High Sierra IOKit****组件输入验证漏洞（****CNVD-2018-00184****）**

Apple macOS High Sierra是美国苹果（Apple）公司为Mac计算机所开发的一套专用操作系统。攻击者可借助特制的应用程序利用该漏洞执行任意代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-00184

**二、境内厂商产品漏洞**  
**1****、延吉市先导高科技开发有限公司易技网站构筑系统存在****SQL****注入漏洞**

延吉市先导高科技开发有限公司是一家计算机软件、硬件开发及网络服务、电子技术应用及开发等的现代化公司。攻击者可利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-36068

**2****、互联万维网网站建设系统存在****SQL****注入漏洞**

深圳市互通时代科技有限公司是一家致力于互联网技术服务网站。攻击者可利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-36178

**3****、明企科技网站建设系统存在****SQL****注入漏洞**

上海明企信息科技有限公司（明企科技）是从事网站建设、网络营销、域名主机及互联网应用开发。攻击者可利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-36329

**4****、****Huawei S7700****和****S9700****拒绝服务漏洞**

Huawei S7700和S9700都是中国华为（Huawei）公司的智能路由交换机。未经身份验证的远程攻击者通过发送超大报文到受影响设备，利用该漏洞可导致服务不可用。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-00339

**5****、****D-Link DSL-6850U****路由器远程命令执行漏洞**

D-Link DSL-6850U是友讯（D-Link）公司的无线路由器产品。攻击者可通过该默认凭证登陆路由器的Web管理界面，获得完整的shell权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2018-00175

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
