# 上周关注度较高的产品安全漏洞(20171218-20171224)

**一、境外厂商产品漏洞**  
**1****、****WebLogic Server WLS ****组件存在远程命令执行漏洞**

Oracle Fusion Middleware是美国甲骨文（Oracle）公司的一套面向企业和云环境的业务创新平台。攻击者可利用该漏洞控制组件，影响数据的可用性、保密性和完整性。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-31499

**2****、****Embedthis GoAhead Web****服务器远程命令执行漏洞**

Embedthis GoAhead是美国Embedthis软件公司的一款嵌入式Web服务器。远程攻击者利用该漏洞执行任意代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-37422

**3****、****PHP Scripts Mall Advance B2BScript SQL****注入漏洞**

PHP Scripts Mall Advance B2B Script是印度PHP Scripts Mall公司的一套基于PHP的B2B2交易网站脚本。远程攻击者可通过向文件发送参数的方式注入SQL命令。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-37288

**4****、美国网件****DGND3700/DGN2200****存在信息泄露漏洞**

DGND3700/DGN2200是美国网件公司的无线路由器产品。该漏洞是由于特权页面所致，攻击者可利用该漏洞在respnose注释获取敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-35653

**5****、****Windows WPAD****服务权限提升漏洞**

Microsoft Windows是美国微软（Microsoft）公司发布的一系列操作系统。攻击者可利用该漏洞远程控制Windows 系统，并且能够获取系统的最高权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-37690

**二、境内厂商产品漏洞**  
**1****、多款****Huawei****防火墙产品存在内存泄露漏洞**

Huawei USG系列产品及Secospace USG系列都是新一代专业入侵防御和防火墙产品。攻击者利用该漏洞可多次执行特定命令，触发内存泄露，最终导致设备重启。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-37507

**2****、****MetInfo 5.3.19****版本存在命令执行漏洞**

MetInfo是一套使用PHP和Mysql开发的内容管理系统。攻击者通过地址栏图标处上传文件，对应修改payload上传的图片文件名，即可获取webshell，获得服务器权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-35624

**3****、****SDCMS v1.2themecontroller.php****存在代码执行漏洞**

SDCMS是烟火网络自主研发的PHP三网合一网站管理系统。攻击者通过写入Webshell来获取服务器权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-35769

**4****、****EasySNS****极简社区****getgrouptopic****方法存在****SQL****注入漏洞**

EasySNS极简社区小组版为全新数据库架构和程序结构，以小组为基本单位组建互动社区。攻击者可利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-35792

**5****、皇家****100****电子商务系统存在****SQL****注入漏洞**

深圳市皇家网络科技有限公司提供企业级的电子商务物流系统和技术运维支持服务。攻击者可利用该漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-35760

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
