**一、境外厂商产品漏洞**  
**************************************************************************************************************************************************************************************************************************************************************************************************1、Spring AMQP与Spring Data REST存在远程代码执行漏洞**************************************************************************************************************************************************************************************************************************************************************************************************

Spring AMQP是基于Spring框架的AMQP消息解决方案，Spring Data REST可以在Spring Data存储库之上构建超媒体驱动的REST Web服务。攻击者可利用该漏洞实现远程代码执行攻击。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-27968  

http://www.cnvd.org.cn/flaw/show/CNVD-2017-27969

**************************************************************************************************************************************************************************************************************************************************************************************************2、Apache Tomcat存在信息泄露与远程代码执行漏洞**************************************************************************************************************************************************************************************************************************************************************************************************

Apache Tomcat是美国阿帕奇软件基金会下属的Jakarta项目的一款轻量级Web应用服务器。攻击者可能获取用户服务器上 JSP 文件的源代码，通过上传的JSP文件，可在用户服务器上执行任意代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-27472

http://www.cnvd.org.cn/flaw/show/CNVD-2017-27471

**************************************************************************************************************************************************************************************************************************************************************************************************3、Ctek SkyRouter身份验证绕过漏洞**************************************************************************************************************************************************************************************************************************************************************************************************

kyRouter是瑞典CTEK公司的一款用于管理无线IP连接的产品。攻击者可利用漏洞绕过身份验证限制进而访问应用程序。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-27938

**************************************************************************************************************************************************************************************************************************************************************************************************4、Schneider Electric InduSoftWeb Studio和InTouch Machine Edition远程代码执行漏洞**************************************************************************************************************************************************************************************************************************************************************************************************

nduSoft Web Studio和InTouch Machine Edition都是法国施耐德电气公司的一个嵌入式HMI软件包。远程攻击者可绕过服务器认证并触发任意命令的执行。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-27937

**二、境内厂商产品漏洞**  

**************************************************************************************************************************************************************************************************************************************************************************************************1、Brother DCP-J132W拒绝服务漏洞**************************************************************************************************************************************************************************************************************************************************************************************************

Brother DCP-J132W是Brother推出的打印机。使远程攻击者可通过发送大量HTTP数据包而导致打印机挂起（破坏其网络连接）。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-27958

**************************************************************************************************************************************************************************************************************************************************************************************************2、phpmywind cms存在任意代码写入漏洞**************************************************************************************************************************************************************************************************************************************************************************************************  

PHPMyWind是一款基于PHP MySQL开发，符合W3C标准的建站引擎。攻击者利用该漏洞获取服务权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-21484

**************************************************************************************************************************************************************************************************************************************************************************************************3、SchoolCMS后台ThemeController.class.php存在文件上传漏洞**************************************************************************************************************************************************************************************************************************************************************************************************

SchoolCMS是一款开源教务管理系统。远程攻击者可在后台利用主题功能，执行任意文件写入操作，获取Web服务器权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-21482

**************************************************************************************************************************************************************************************************************************************************************************************************4、NiuShop\_b2c\_data\_release存在多个漏洞**************************************************************************************************************************************************************************************************************************************************************************************************

NiuShop开源商城系统是山西牛酷信息科技有限公司的一套PHP的开源电商系统。攻击者可利用该漏洞危及应用程序，访问或修改数据，获取服务器权限等其他攻击。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-23258

**************************************************************************************************************************************************************************************************************************************************************************************************5、广州南方卫星导航仪器有限公司NETS9多星系统参考站接收机控制软件存在SQL注入漏洞**************************************************************************************************************************************************************************************************************************************************************************************************

NETS9是一款多星系统参考站接收机。允许攻击者利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-22786

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
