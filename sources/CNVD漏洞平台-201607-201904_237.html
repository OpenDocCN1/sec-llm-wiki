一、境外厂商产品漏洞
1、Joomla Ultimate Property Listing组件SQL注入漏洞

Joomla是一套使用PHP和MySQL开发的开源、跨平台的内容管理系统。攻击者可利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-18697

2、Oracle Java SE/JRockit远程漏洞（CNVD-2017-18230）

Java SE是一款用于开发和部署桌面、服务器以及嵌入设备和实时环境中的Java应用程序。允许攻击者利用漏洞影响机密性。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-18230

3、Linux kernel ‘mp_override_legacy_irq()’函数缓冲区溢出漏洞

Linux是一款开源的操作系统。允许本地攻击者利用漏洞提交特殊的请求，提升权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-17779

4、Google Android Qualcomm组件整数溢出漏洞（CNVD-2017-18949）

Android是美国谷歌公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。攻击者可利用漏洞执行任意代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-18949

5、Continental TCU存在缓冲区溢出和远程代码执行漏洞

TCU 是Continental AG（大陆集团）生产的现代汽车常用的，用于传输数据的2G调制解调器。攻击者可利用临时移动用户识别码（TMSI）远程访问与控制存储器，并在 TCU 基带无线电处理器上远程执行任意代码。攻击者可利用AT指令访问易受攻击的车辆系统，并在 TCU 基带无线电处理器上执行任意代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-18627

http://www.cnvd.org.cn/flaw/show/CNVD-2017-18628

 

二、境内厂商产品漏洞
1、广州市创科网络股份有限公司建站系统存在SQL注入漏洞

广州市创科网络股份有限公司是一家网站建设及网络营销服务的提供商。攻击者可利用漏洞获取后台管理员的账号密码，进行未授权操作。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-18704

2、迪普UMC统一管理中心存在St2-045远程命令执行漏洞

UMC统一管理中心是将隔离、分散的不同系统整合为一体化的管理平台。攻击者可利用该漏洞获取服务器权限，上传webshell。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-12070

3、PHPcmsV9.6最新版本后台存在文件包含漏洞

PHPCMS是一款网站管理软件。攻击者可以利用该漏洞包含一句话木马，获取网站服务器管理权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-10421

4、FineCMS前台tx参数存在代码执行漏洞

FineCMS是一款基于PHP+MySql开发的内容管理系统。远程攻击者无需登录即可执行任意代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-11821

5、D-Link DVG-5402SP VoIP路由器存在多个跨站请求伪造漏洞

D-Link DVG-5402SP VoIP是友讯（D-Link）公司的一款无线路由器产品。远程攻击者可利用该漏洞执行未授权的操作。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-18479

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
