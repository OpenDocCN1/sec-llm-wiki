**一、境外厂商产品漏洞**  
****************************************************************************************************************************************************************************************************************************************************************************************1、Apache Struts(S2-048)远程命令执行漏洞****************************************************************************************************************************************************************************************************************************************************************************************

Apache Struts是一款用于创建企业级Java Web应用的开源框架。该漏洞存在Struts2和Struts1一个Showcase插件Action Message类中，攻击者可通过构建不可信的输入实现远程命令攻击。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-13259

****************************************************************************************************************************************************************************************************************************************************************************************2、Siemens OZW672和OZW772中间人攻击漏洞****************************************************************************************************************************************************************************************************************************************************************************************

Siemens OZW672和OZW772都是德国西门子公司的楼宇控制器产品。允许攻击者在执行中间人（MITM）攻击时读取和操作TLS会话中的数据。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-12866

****************************************************************************************************************************************************************************************************************************************************************************************3、Cisco IOS和IOS XE SNMP远程执行代码漏洞（CNVD-2017-12528）****************************************************************************************************************************************************************************************************************************************************************************************

Cisco IOS是多数思科系统路由器和网络交换机上使用的互联网络操作系统。远程攻击者可通过发送构造的SNMP数据包使得SNMP服务缓冲区溢出，导致任意命令执行。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-12528

****************************************************************************************************************************************************************************************************************************************************************************************4、Microsoft Windows远程代码执行漏洞（CNVD-2017-12780）****************************************************************************************************************************************************************************************************************************************************************************************

Microsoft Windows是美国微软公司发布的一系列操作系统。攻击者可利用该漏洞在当前用户上下文中执行任意代码或造成拒绝服务。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-12780

****************************************************************************************************************************************************************************************************************************************************************************************5、Toshiba Home gateway HEM-GW16A固件存在硬编码凭证漏洞****************************************************************************************************************************************************************************************************************************************************************************************

TOSHIBA Home Gateway HEM-GW26A和TOSHIBA Home GatewayHEM-GW16A都是日本东芝公司的家庭网关产品。攻击者可利用该漏洞以管理员权限执行操作。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-12982

****************************************************************************************************************************************************************************************************************************************************************************************6、多款HP产品Conexant Systemsmictray64.exe信息后门漏洞****************************************************************************************************************************************************************************************************************************************************************************************

HP Elite等都是美国惠普公司的计算机产品。Conexant Systemsmictray64.exe是一个音频驱动内置键盘记录器。任何可以调用MapViewOfFile API的框架或者进程都能够通过用户的键盘输入信息静默的收集敏感数据，并在白名单机制下绕过杀毒软件检测。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-09590

**二、境内厂商产品漏洞**  
  

****************************************************************************************************************************************************************************************************************************************************************************************1、科汛KesionCms最新版本X2.0.170329后台存在任意文件上传漏洞****************************************************************************************************************************************************************************************************************************************************************************************

KesionCMS是采用ASP+ACCESS/MSSQL数据库架构开发的一套智能建站系统。攻击者可利用漏洞绕过文件扩展名校验，导致上传任意文件，获取服务器控制权。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-07413

****************************************************************************************************************************************************************************************************************************************************************************************2、D-Link DIR-615 Wireless N 300路由器验证绕过漏洞****************************************************************************************************************************************************************************************************************************************************************************************

D-Link DIR-615 Wireless N 300是友讯（D-Link）公司的一款无线路由器产品。攻击者可通过向login.cgi文件发送修改的POST请求利用该漏洞绕过身份验证。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-12934

****************************************************************************************************************************************************************************************************************************************************************************************3、泛微E-Mobile移动办公系统存在Struts2远程命令执行漏洞****************************************************************************************************************************************************************************************************************************************************************************************

泛微E-Mobile移动办公系统是一个移动办公平台。攻击者可以利用漏洞远程执行命令，获得服务器权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-07285

****************************************************************************************************************************************************************************************************************************************************************************************4、Eview GPS跟踪平台系统name参数存在SQL注入漏洞****************************************************************************************************************************************************************************************************************************************************************************************

Eview GPS跟踪平台系统是Eview公司的在线跟踪系统。攻击者可利用常用SQL注入工具，获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-07120

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
