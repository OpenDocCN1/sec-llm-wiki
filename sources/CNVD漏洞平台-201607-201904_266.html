一、境外厂商产品漏洞

1、Samba存在远程代码执行漏洞

Samba是运行于Linux和UNIX系统上实现SMB协议的软件。攻击者可以利用客户端将指定库文件上传到具有可写权限的共享目录，会导致服务器加载并执行指定的库文件。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-07432

2、Apple iOS和Safari WebKit内存破坏漏洞（CNVD-2017-07602）

Apple iOS是为移动设备所开发的一套操作系统；Safari是一款Web浏览器。远程攻击者可借助特制的Web站点利用该漏洞执行任意的代码或造成拒绝服务。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-07602

3、IBM Business Process Manager开放重定向漏洞

IBM Business Process Manager（BPM）是一套综合的业务流程管理平台。远程攻击者可通过诱使用户访问特制的Web站点利用该漏洞将用户重定向到恶意的Web站点，实施钓鱼攻击，获取敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-07530

4、Microsoft Windows SMB Server远程代码执行漏洞（CNVD-2017-07390）

Microsoft Windows Sever Message Block（SMB）是一个为计算机提供身份验证用以访问服务器上打印机和文件系统的组件。远程攻击者可通过向目标SMB服务器发送特制的数据包利用该漏洞在目标系统上执行任意代码或造成拒绝服务。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-07390

5、WordPress Spider Event Calendar SQL注入漏洞

WordPress是WordPress软件基金会的一套使用PHP语言开发的博客平台。远程攻击者可利用该漏洞执行任意的SQL命令。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-07215

 

二、境内厂商产品漏洞
1、浙江搜派信息科技派桑网络建站系统tid参数存在SQL注入漏洞

派桑网络建站系统是浙江搜派信息科技有限公司研发的一款建站系统。该漏洞产生的原因是未对tid参数进行有效过滤所致，攻击者可利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-04366

2、企信通客户管理平台viewChannerParamXml.jsp文件id参数存在SQL注入漏洞

企信通是使用java开发的一个专门针对企业客户量身定做的短消息增值业务。允许攻击者利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-06357

3、Wecon Technologies LEVI Studio HMI Editor堆缓冲区溢出漏洞

Wecon Technologies LEVI Studio HMIEditor是中国维控科技公司的一款人机界面中的编辑器。远程攻击者可借助特制的项目文件利用该漏洞造成设备无法响应，可能执行代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-07228

4、iGuardian安全卫士存在远程命令执行漏洞

iGuardian安全卫士是一种基于路由器并嵌入Linux 操作系统的应用软件。允许攻击者远程执行命令，获得服务器权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-04213

5、Vkflash图片轮播管理系统A_ID参数存在SQL注入漏洞

Vkflash图片轮播管理系统是一套基于RuoChi的Bcastr加工并二次开发而成的Flash图片轮播管理系统。允许攻击者利用该漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-04582

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
