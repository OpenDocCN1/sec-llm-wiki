# 上周关注度较高的产品安全漏洞(20170515-20170521)

**一、境外厂商产品漏洞**  
**********************************************************************1、Joomla! com\_fields组件存在SQL注入漏洞**********************************************************************

Joomla!是美国Open Source Matters团队的一套使用PHP和MySQL开发的开源、跨平台的内容管理系统(CMS)。远程攻击者无需任何身份认证，可获取数据库敏感信息，包括管理员登录信息并控制网站后台。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-06861

**********************************************************************2、Microsoft Office远程代码执行漏洞（CNVD-2017-06561）**********************************************************************

Microsoft Office是美国微软（Microsoft）公司开发的一款办公软件套件产品。攻击者可通过构建特制的EPS文件利用该漏洞在受影响的应用程序上下文中执行任意代码或造成拒绝服务。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-06561

**********************************************************************3、HP OpenCall Media Platform远程代码执行漏洞**********************************************************************

HP OpenCall Media Platform是一套用于开发和部署消息，门户和互动服务的语音和视频服务器。远程攻击者可利用漏洞特殊的请求，执行任意代码或查看系统文件内容。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-06865

**********************************************************************4、Oracle Primavera Gateway远程漏洞**********************************************************************

Oracle Primavera Products Suite是一款项目组合管理解决方案套件产品。攻击者可利用该漏洞未授权访问数据，造成拒绝服务（挂起或频繁崩溃），影响数据的可用性和保密性。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-06473

**********************************************************************5、Linux kernel权限提升漏洞（CNVD-2017-06844）**********************************************************************

Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。攻击者可借助特制的应用程序利用该漏洞获取权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-06844

**二、境内厂商产品漏洞**  
**********************************************************************1、Huawei AC6005/AC6605拒绝服务漏洞**********************************************************************

AC6005和AC6605都是中国华为（Huawei）公司的一款盒式无线接入控制器。攻击者可以向设备发送大量畸形报文，使设备内存泄露，导致拒绝服务攻击。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-06862

**********************************************************************2、枣阳市山水数码建站系统存在多处SQL注入漏洞**********************************************************************

枣阳市山水数码建站系统是一款网站建站系统。由于程序未能对用户提交的数据进行过滤，允许攻击者利用漏洞获取网站数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-06799

**********************************************************************3、Dahua Technology Authentication身份验证漏洞**********************************************************************

Dahua Technology Authentication是大华科技攻击生产的一款门禁阅读器。攻击者可利用该漏洞通过绕过预期的安全限制来获得未经授权的限制内容访问。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-06997

**********************************************************************4、青岛易软天创网络科技有限公司禅道项目管理软件后台存在设计缺陷漏洞**********************************************************************

禅道是开源免费的项目管理软件。允许攻击者利用后台sql查询功能写入webshell，获得服务器权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-04121

**********************************************************************5、中智西安招聘系统存在万能密码登陆漏洞**********************************************************************

中智西安招聘系统是一款简历信息保存和录入系统。攻击者输入万能密码 'or '1'='1 或者 'or'='or' 可以顺利登录系统，查看用户敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-04117

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
