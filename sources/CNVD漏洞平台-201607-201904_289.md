**一、境外厂商产品漏洞**  
**********************************************************1、三星TiZen系统存在多个高危漏洞**********************************************************

Tizen（泰泽）是两大Linux联盟LiMo Foundation和 Linux Foundation 整合资源优势，携手英特尔和三星电子，共同开发的一个开源的、标准化的基于Linux的操作系统。允许攻击者通过Tizen Store软件获取设备上的root权限并完全控制电视。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-03991

**********************************************************2、Cisco IOS和IOS XE Software ANI IPv6报文拒绝服务漏洞**********************************************************

Cisco IOS和IOS XE Software都是美国思科公司为其网络设备开发的操作系统。远程攻击者可利用漏洞发送特制的IPv6报文进行拒绝服务攻击。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-03847

**********************************************************3、Linux kernel ‘sg\_ioctl’函数拒绝服务漏洞**********************************************************

Linux kernel是一款开源的操作系统。本地攻击者可利用该漏洞进行拒绝服务攻击，使系统崩溃。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-03858

**********************************************************4、Microsoft Windows Hyper-V远程代码执行漏洞（CNVD-2017-03849）**********************************************************

Microsoft Windows是美国微软（Microsoft）公司的一系列操作系统。攻击者可借助特制的应用程序利用该漏洞在目标操作系统上执行任意代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-03849

**********************************************************5、Joomla JSP Store Locator组件id参数存在SQL注入漏洞**********************************************************

Joomla是一款开放源码的内容管理系统(CMS)。允许攻击者利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-01735

**二、境内厂商产品漏洞**  
**********************************************************1、威速V2视频会议系统sysId参数存在SQL命令执行漏洞**********************************************************

威速V2视频会议系统是一款视频会议系统。允许攻击者远程写入shell，获得服务器权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-01965

**********************************************************2、SemCms asp版搜索框存在SQL注入漏洞**********************************************************

SemCms是一套开源外贸企业网站管理系统。由于search参数缺乏过滤，允许攻击者利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-02060

**********************************************************3、iWebSNS企业社交网络平台前台存在无限制SQL注入漏洞**********************************************************

iWebSNS是一套基于LAMP开发构建的开源SNS(社交网络)软件。由于源码中servtools\\menu\_pop\\translate\_pri.php对t\_name,vid和tem变量未能严格过滤，攻击者可利用漏洞获得数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-01835

**********************************************************4、欧虎政务系统多个文件存在SQL注入漏洞**********************************************************

欧虎政务系统是上海欧虎网络科技有限公司的政府门户网站系统。攻击者可以利用漏洞执行任意SQL语句，获取敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-03872
