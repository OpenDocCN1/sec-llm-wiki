2017年03月27日-2017年04月02日

一、境外厂商产品漏洞
1、Microsoft Windows Server 2003 IIS缓冲区溢出漏洞

Microsoft Windows Server 2003 R2是美国微软（Microsoft）公司发布的一套服务器操作系统。攻击者可通过一个以“If: <http://”开始的较长header头的PROPFIND请求执行任意代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-03467

2、GNU Binutils拒绝服务漏洞

GNU Binutils是GNU计划开发的一组编程语言工具程序。攻击者可利用该漏洞造成拒绝服务（程序崩溃），也可能造成信息泄露。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-03448

3、Serv-U FTP/MFT服务器未授权的权限提升漏洞

Serv-U FTP/MFT Server都是一种使用广泛的FTP服务器程序。攻击者可利用漏洞获取Serv-U管理权限，并利用System Administrator账户上传和执行任意DLL，导致远程代码执行和信息泄露。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-03490

4、Siemens RUGGEDCOM ROX I存在多个漏洞

Siemens RuggedCom基于ROX的防火墙设备用于在恶劣环境中进行设备连接。攻击者可利用漏洞在10000/TCP端口的Web服务器上使用该用户的权限执行任意操作、读取任意文件获取敏感信息、获取文件系统的访问或更改设置权限等。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-03653

http://www.cnvd.org.cn/flaw/show/CNVD-2017-03652

http://www.cnvd.org.cn/flaw/show/CNVD-2017-03650

5、HP LoadRunner/Performance Center堆缓冲区溢出漏洞

HP Intelligent Management Center（iMC）是美国惠普（HP）公司的一套网络智能管理中心解决方案。攻击者可利用漏洞在应用程序上下文中执行任意脚本代码。失败的攻击会造成拒绝服务。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-03832

 

二、境内厂商产品漏洞
1、南京管鲍科技发展有限公司管鲍在线考试系统存在多个漏洞

南京管鲍科技发展有限公司管鲍在线考试系统是一款综合性考试系统。允许攻击者伪造一个相对应的cookie获得相应的权限，或进行用户的添加、更新和删除等操作。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-01969

http://www.cnvd.org.cn/flaw/show/CNVD-2017-01967

2、哈尔滨新中新电子股份有限公司校园一卡通系统存在SQL注入漏洞

哈尔滨新中新电子股份有限公司校园一卡通系统是一款数字校园的解决方案。允许攻击者利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-01427

3、深海捷Mixcall座席管理中心files参数存在远程命令执行漏洞

深圳市深海捷科技有限公司是一家专注于呼叫中心和融合通信产品研发、制造和销售的企业。由于admin/modules/recordmm/record.php文件中对参数的安全验证函数在admin的parent中，需要parent::_construct才能实现，而文件中却未调用父类的构造方法，导致files参数执行系统命令，获得服务器权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-01966

4、Huawei VCM5010存在多个漏洞

VCM5010是中国华为（Huawei）公司的一款视频内容管理平台。攻击者可以通过伪造HTTP请求来绕过身份认证、上传任意文件或进行命令注入攻击。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-03716

http://www.cnvd.org.cn/flaw/show/CNVD-2017-03717

http://www.cnvd.org.cn/flaw/show/CNVD-2017-03718

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
