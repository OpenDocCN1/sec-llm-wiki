**一、境外厂商产品漏洞**  
******************************************1、Microsoft Windows SMB TreeConnect响应拒绝服务漏洞******************************************

Microsoft Windows是美国微软公司发布的一系列操作系统。攻击者利用该漏洞通过诱使有漏洞的SMB客户端连接到一台恶意构造的 SMB 服务器，导致客户端操作系统系统崩溃。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-00819

******************************************2、Cisco WebEx浏览器插件远程代码执行漏洞******************************************

Cisco WebEx是浏览器扩展插件。攻击者利用漏洞通过magic字符串可在使用该插件的浏览器中执行任意代码。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-00743

******************************************3、Citrix Provisioning Services存在多个漏洞******************************************

Citrix Provisioning Services能够创建一套使用流技术传输物理和虚拟服务器的镜像。允许攻击者通过未指定的向量执行任意代码。

参考链接：

http://www.cnvd.org.cn/flaw/show/CNVD-2017-00794

http://www.cnvd.org.cn/flaw/show/CNVD-2017-00793

http://www.cnvd.org.cn/flaw/show/CNVD-2017-00796

******************************************4、Apache Groovy远程代码执行漏洞******************************************

Apache Groovy是美国阿帕奇（Apache）软件基金会的一种基于JVM的敏捷开发语言。攻击者可利用该漏洞在用户运行的受影响应用程序上下文中执行任意代码，可造成拒绝服务。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-00746

******************************************5、WordPress REST API插件内容注入漏洞******************************************

WordPress是一个以PHP和MySQL为平台的自由开源的博客软件和内容管理系统。远程攻击者可利用漏洞提升权限或执行内容注入操作。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-00746

**二、境内厂商产品漏洞**  
******************************************1、Phpems V3.1后台编辑器存在任意文件上传漏洞******************************************

PHPEMS是一个支持多种题型和展现方式的PHP在线模拟考试系统。攻击者可利用漏洞在后台上传任意文件，进而发起进一步攻击。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-12403

******************************************2、金鹊门业企业管理软件存在多处SQL注入漏洞******************************************

金鹊门业企业管理软件是一款综合性管理系统。攻击者可以通过该漏洞获取数据库信息，造成敏感信息泄露。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-12152

******************************************3、任子行IDC信息安全审计管理系统命令执行漏洞******************************************

任子行网络技术股份有限公司是中国最早涉足网络信息安全领域的企业之一。允许攻击者远程执行命令，获得服务器权限，构成信息泄露和运行安全风险。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-05624

******************************************4、米拓MetInfo V5.3.13后台存在写文件漏洞******************************************

MetInfo是一款采用PHP Mysql架构的企业网站管理系统。允许攻击者利用漏洞写入而已文件，获取网站服务器权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-12668

******************************************5、深圳鹏教项目管理系统存在Struts2远程命令执行漏洞******************************************

深圳鹏教项目管理系统是深圳市鹏教管理顾问有限公司的一款产品。远程攻击者利用漏洞可执行命令，获得服务器权限，构成信息泄露。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-12589

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
