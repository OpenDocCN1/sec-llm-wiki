本周漏洞态势研判情况

 

本周信息安全漏洞威胁整体评价级别为中。

国家信息安全漏洞共享平台（以下简称CNVD）本周共收集、整理信息安全漏洞200个，其中高危漏洞81个、中危漏洞109个、低危漏洞10个。漏洞平均分值为6.42。本周收录的漏洞中，涉及0day漏洞23个（占12%）。其中互联网上出现“Less Compiler任意代码执行漏洞、EasyPHPDevserver远程命令执行漏洞”零日代码攻击漏洞，请使用相关产品的用户注意加强防范。此外，本周CNVD接到的涉及党政机关和企事业单位的事件型漏洞总数771个，与上周（602个）环比增长22%。

本周重要漏洞安全告警


本周，CNVD整理和发布以下重要安全漏洞信息。

1、IBM产品安全漏洞

IBM iNotes是美国IBM公司的一套基于Web的电子邮件软件；Domino是一套用于托管社交商务应用的平台；IBM BigFixRemote Control是一套远程控制系统。本周，上述产品被披露存在信息泄露和跨站脚本漏洞，攻击者可利用漏洞泄露敏感信息和进行跨站脚本攻击。

CNVD收录的相关漏洞包括：IBM iNotes和Domino跨站脚本漏洞（CNVD-2016-11818、CNVD-2016-11819、CNVD-2016-11820、CNVD-2016-11821）、IBM BigFixRemote Control信息泄露漏洞、IBM BigFix Remote Control信息泄露漏洞（CNVD-2016-11744、CNVD-2016-11693、CNVD-2016-11814）等。目前，厂商已经发布了上述漏洞的修补程序。CNVD提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

2、Apple产品安全漏洞

Apple iOS是美国苹果（Apple）公司为移动设备所开发的一套操作系统。Safari是其中的一个Web浏览器组件。Apple macOS Sierra是为Mac计算机所开发的一套专用操作系统。Core Image是其中的一个图形过虑器框架。ImageIO是其中的一个用来执行常见的图像I/O操作的静态方法。Mail是其中的一个邮件模块。Apple WebKit是开源的web浏览器引擎。本周，上述产品被披露存在多个漏洞，攻击者可利用漏洞泄露敏感信息、执行任意代码或发起拒绝服务攻击等。

CNVD收录的相关漏洞包括：Apple iOSSafari拒绝服务漏洞、Apple macOS Sierra Core Image内存破坏漏洞、Apple macOSSierra ImageIO任意代码执行漏洞、Apple macOS Sierra Mail拒绝服务漏洞、Apple iOS和Apple macOS信息泄露漏洞、Apple WebKit存在多个内存破坏漏洞、Apple iOS andMac OS安全绕过漏洞（CNVD-2016-11549）、Apple iOS and Mac OS安全绕过漏洞等。其中，“Apple macOSSierra Core Image内存破坏漏洞、Apple macOS Sierra ImageIO任意代码执行漏洞、Apple WebKit存在多个内存破坏漏洞”的综合评级为“高危”。目前，厂商已经发布了上述漏洞的修补程序。CNVD提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

Apache Subversion是美国阿帕奇（Apache）软件基金会的一套开源的版本控制系统；Karaf是一个一个可以用于部署各种组件、应用程序的OSGi容器；Apache Hadoop是一套开源的分布式系统基础架构；Apache Tomcat是一个流行的开源JSP应用服务器程序；ApacheOpenOffice（OOo）是一款开源的办公软件套件。本周，上述产品被披露存在多个漏洞，攻击者可利用漏洞执行任意代码、绕过安全限制或发起拒绝服务攻击等。

 5、OIC Exponent CMS SQL注入漏洞（CNVD-2016-11771）

OIC ExponentCMS是美国OIC集团公司的一套基于PHP的免费、开源的模块化内容管理系统（CMS）。本周，OIC被披露存在SQL注入漏洞。攻击者可利用该漏洞执行任意SQL命令。目前，厂商尚未发布该漏洞的修补程序。CNVD提醒广大用户随时关注厂商主页，以获取最新版本。

关于CNVD

国家信息安全漏洞共享平台（China National Vulnerability Database，简称CNVD）是CNCERT联合国内重要信息系统单位、基础电信运营商、网络安全厂商、软件厂商和互联网企业建立的信息安全漏洞信息共享知识库，致力于建立国家统一的信息安全漏洞收集、发布、验证、分析等应急处理体系。

关于CNCERT

国家计算机网络应急技术处理协调中心（简称“国家互联网应急中心”，英文简称是CNCERT或CNCERT/CC），成立于2002年9月，为非政府非盈利的网络安全技术中心，是我国网络安全应急体系的核心协调机构。

作为国家级应急中心，CNCERT的主要职责是：按照“积极预防、及时发现、快速响应、力保恢复”的方针，开展互联网网络安全事件的预防、发现、预警和协调处置等工作，维护国家公共互联网安全，保障基础信息网络和重要信息系统的安全运行。
