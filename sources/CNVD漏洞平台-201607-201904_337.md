# 关于ntpd存在多个拒绝服务漏洞的安全公告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU3ODM2NTg2Mg==&mid=2247485393&idx=1&sn=d938302f40f7049a1c859c7c5a24eb1b&chksm=fd773718ca00be0e9e8e1e151bf362f69afdc017544553a3107394ee19faed71f37b207d776b&scene=126&sessionid=1681366007#rd](http://mp.weixin.qq.com/s?__biz=MzU3ODM2NTg2Mg==&mid=2247485393&idx=1&sn=d938302f40f7049a1c859c7c5a24eb1b&chksm=fd773718ca00be0e9e8e1e151bf362f69afdc017544553a3107394ee19faed71f37b207d776b&scene=126&sessionid=1681366007#rd)

安全公告编号:CNTA-2016-0060  

近期，国家信息安全漏洞共享平台（CNVD）收录了NTP安全公告中发布的多个拒绝服务漏洞。综合利用上述漏洞，攻击者可向NTPD受影响模块发送特制的数据包，可导致主服务崩溃，形成拒绝服务攻击，有可能对时钟同步网络基础设施造成较大影响。

**一、漏洞情况分析**  

Network Time Protocol（NTP）是用于使计算机时间同步化的一种协议，可使计算机对其服务器或时钟源（如石英钟，GPS等等)做同步化。把计算机的时钟同步到世界协调时，以确保网络中的数据交互能够顺利进行。NTPD（Network Time Protocol daemon）是一个操作系统守护进程，使用网络时间协议（NTP）与时间服务器的系统时间保持同步，主要用于主机与主机之间的时间同步。NTP发布安全公告修复了NTPD中存在的多个漏洞，漏洞分析情况如下：

**二、漏洞影响范围**

根据CNVD技术组成员单位——绿盟科技公司提供的监测数据。目前受到漏洞影响的NTP服务器IP数量达到21.4万个。其中，数量最多的国家是加拿大(占24.6%)，其次韩国(20.1%)，第三是美国（16.8%），其余数量较多的国家分别是俄罗斯联邦、中国、巴西、日本、英国、德国、法国等。中国大陆地区及港澳台地区受此漏洞影响的服务器IP数量超过1.3万台；其中，台湾地区、江苏省、北京市、香港地区等省份和地区数量较多。

**三、漏洞修复建议**  

目前，厂商已发布了升级版本修复该上述漏洞。但是，互联网上已经披露漏洞攻击利用代码，互联网服务提供商和相关用户应参照表1所示及时升级到最新版本。
