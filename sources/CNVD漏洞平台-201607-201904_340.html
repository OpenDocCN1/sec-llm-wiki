2016年11月14日-2016年11月20日

一、境外厂商产品漏洞
1、LynxspringJENEsys BAS Bridge权限提升漏洞

Lynxspring是一家美国公司。BAS Bridge是一个基于web的SCADA系统。LynxspringJENEsys BASBridge存在权限提升漏洞。攻击者利用漏洞以只读访问发送专门制作的命令到基于Web的应用程序，并在应用程序中进行更改。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-11246

2、Phoenix Contact ILC信息泄露漏洞

Phoenix Contact ProConOs和MultiProg都是德国菲尼克斯电气（Phoenix Contact）集团的用于工业PC机中的可编程逻辑控制器（PLC）。Phoenix Contact ILC PLC中存在信息泄露漏洞，由于敏感信息明文存储。攻击者利用该漏洞获取敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-10999

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-11119

3、Linux Kernel远程代码执行漏洞

Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。Linux Kernel存在远程代码执行漏洞，攻击者可利用该漏洞在应用程序的上下文中执行任意代码或破坏内核内存。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-11060

4、HPE Network Node Manager i (NNMi)远程代码执行漏洞

HPE Network Node Manager i（NNMi）是美国惠普企业（Hewlett Packard Enterprise，HPE）公司的一套网络管理软件。HPE Network Node Manager i(NNMi)存在远程代码执行漏洞，允许攻击者利用该漏洞执行HTML和脚本代码攻击。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-11191


二、境内厂商产品漏洞
1、昆石网络技术有限公司VoIP运营支撑系统name参数存在SQL注入漏洞

昆石网络技术有限公司VoIP运营支撑系统针对中小等规模VoIP运营业务提供的支撑系统。昆石网络技术有限公司VoIP运营支撑系统name参数存在SQL注入漏洞。攻击者可利用漏洞获得数据库信息。

参考链接：hhttp://www.cnvd.org.cn/flaw/show/CNVD-2016-06833

2、厦门科汛软件有限公司IMALL电子商务管理系统存在设计漏洞

厦门科汛软件有限公司IMALL是一款电子商务管理系统。厦门科汛软件有限公司IMALL电子商务管理系统存在设计漏洞。攻击者利用漏洞可获取数据库信息，删除数据库中任意订单数据。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-08374

3、合正协同内容管理系统存在SQL注入漏洞

合正网站群内容管理系统HZCMS是一套基于Java和XML技术的网站群内容管理软件。该产品存在SQL注入漏洞，攻击者可利用漏洞获得数据库信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-06832

4、天翎网络科技有限公司OA系统存在SQL注入漏洞

天翎网络科技有限公司开发了业务流程软件工具——myApps快速开发平台。由于'_flowName'参数缺乏过滤，允许攻击者利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-08577

5、多款华为防火墙设备存在拒绝服务漏洞

Huawei USG9580、9560和9520都是中国华为公司的USG9500系列防火墙设备。由于对DHCP报文的某些字段校验不充分，一个未经认证的攻击者可以向受影响设备发送特殊的DHCP请求报文，成功利用这个漏洞可以导致设备拒绝服务。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-11301

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
