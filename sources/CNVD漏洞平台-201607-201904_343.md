2016年11月07日-2016年11月13日

**一、境外厂商产品漏洞**  
************************************1、Microsoft产品发布安全更新************************************

11月8日，微软发布了2016年11月份的月度例行安全公告，共含14项更新，修复了MicrosoftWindows、Internet Explorer、Edge、Office、Office Services、SQL Server和WebApps中存在的67个安全漏洞。其中，5项远程代码更新的综合评级为最高级“严重”级别。

参考链接：http://www.cnvd.org.cn/webinfo/show/3970

************************************2、Apple Mac OS X安全绕过漏洞（CNVD-2016-10774）************************************

Apple Mac OS X是美国苹果（Apple）公司为Mac计算机所开发的一套专用操作系统。Apple Mac OS X 10.12版本中存在安全绕过漏洞。攻击者可利用该漏洞执行任意代码，获取敏感信息，造成拒绝服务，绕过安全限制，执行未授权操作。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-10774

************************************3、Oracle MySQL、MariaDB和PerconaDB提权漏洞************************************

Oracle MySQL、MariaDB和PerconaServer都是数据库管理系统。Oracle MySQL、MariaDB和PerconaDB中存在提权漏洞。攻击者可利用该漏洞获取root权限，完全控制系统。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-10748

************************************4、Siemens多款产品存在权限提升漏洞（CNVD-2016-10732）************************************

德国西门子股份公司创立于1847年，专注于电气化、自动化和数字化领域。Siemens多款产品存在权限提升漏洞。当受影响的产品未安装在默认路径“C:\\ Program Files \\ \*”下时，非挂牌服务路径可以允许本地Microsoft Windows操作系统用户提升权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-10732

  
**二、境内厂商产品漏洞**  
************************************1、格尔安全认证网关系统存在多处命令执行漏洞************************************

格尔安全认证网关为网络应用提供基于数字证书的高强度身份认证服务和高强度数据链路加密服务。格尔安全认证网关系统存在多处命令执行漏洞。攻击者利用漏洞可构造请求，执行任意命令，写入webshell，获取服务器权限，构成敏感信息泄露。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-09983

************************************2、北京远为软件有限公司安全隔离网关存在多处命令执行漏洞************************************

北京远为软件有限公司安全隔离网关是基于终端虚拟化技术和网络虚拟化技术的多网安全隔离系统。北京远为软件有限公司安全隔离网关存在多处命令执行漏洞。攻击者利用漏洞可执行系统命令获取敏感信息，进而可管理员权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-10878

************************************3、中科软科技保险业务系统存在SQL注入漏洞************************************

中科软科技保险业务系统是一款保险业务处理系统。通过挂接核保核赔管理和单证管理等功能，有效降低了企业的经营风险。中科软科技保险业务系统存在多处SQL注入漏洞。原远程攻击者利用漏洞可获取网站数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-08677

************************************4、用友UFO-UAPWS存在SQL报错注入漏洞（CNVD-2016-10770）************************************

用友UFO-UAPWS报表系统是面向企业的互联网解决方案。用友UFO-UAPWS存在SQL报错注入漏洞。攻击者利用漏洞可查看敏感信息，获取数据库信息，造成信息泄露。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-10770

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
