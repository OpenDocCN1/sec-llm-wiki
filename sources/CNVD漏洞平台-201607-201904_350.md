**境外厂商产品漏洞**  
******************************1、Oracle产************************************************************品发************************************************************布安全公告******************************

10月19日，Oracle发布了2016年10月份的安全更新，修复了其多款产品存在的253个安全漏洞。

参考链接：http://www.cnvd.org.cn/webinfo/show/3950

******************************2、Linux kernel本地权限提升漏洞（Dirty COW）******************************

Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。Linux Kernel本地权限提升漏洞，低权限的本地攻击者利用漏洞可获取其他只读内存映射的写权限，进而可导致权限提升执行进一步操作。。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-09672

******************************3、ISC BIND 9存在断言错误拒绝服务漏洞******************************

ISC BIND 9是美国Internet SystemsConsortium（ISC）组织所维护的一套DNS域名解析服务软件。ISC BIND 9存在断言错误拒绝服务漏洞。远程攻击者利用漏洞可向服务器发送畸形数据包，导致服务器断言失败退出。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-09673

******************************4、Joomla Ja-K2-Filter-And-Search组件存在SQL注入漏洞******************************

Joomla是一套基于PHP的开源内容管理系统(CMS)。JoomlaJa-K2-Filter-And-Search组件存在SQL注入漏洞。由于该组件在很多的Joomla网站中被使用，攻击者利用漏洞可使用Sqlmap对注入点进行SQL注入，构成敏感信息泄露。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-09609

  

**二、境内厂商产品漏洞**  
******************************1、海康威视Elisa Live IP camera存在XXE外部实体注入漏洞******************************

杭州海康威视数字技术股份有限公司Elisa Live IP camera是一款网络摄像机。海康威视Elisa Live IP camera存在XXE外部实体注入漏洞。攻击者利用漏洞可获取网站任意文件，严重的可获得服务器控制权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-09329

******************************2、广州市中大东日教育技术有限公司信息化管理系统************************************************************Bulletin/Msg\_Preview.aspx页面中zdbh参数存在SQL注入漏洞******************************

广州市中大东日教育技术有限公司教育信息化管理系统是提供了一体化的校园信息化解决方案。广州市中大东日教育技术有限公司信息化管理系统存在SQL注入漏洞。由于Bulletin/Msg\_Preview.aspx页面zdbh参数缺乏过滤，允许攻击者利用漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-06508

******************************3、协成智慧科技有限公司wifi开发系统存在SQL注入漏洞******************************

福州市协成智慧科技有限公司是一家集商用WiFi云平台开发、通信IT硬件集成与定制、大数据产品与服务于一体的商业WiFi生态链型企业。协成智慧科技有限公司wifi开发系统存在SQL注入漏洞，攻击者利用漏洞可获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-05892

******************************4、方正防火墙存在未授权访问漏洞******************************

方正防火墙是方正集团研发的一款维护信息安全的防护系统。方正防火墙存在未授权访问漏洞，允许攻击者利用该漏洞获取配置备份文件，未授权访问，可获取设备的敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-07646

******************************5、富士康Android手机固件存在后门漏洞******************************

富士康是一家组装Android智能手机的电子零件制造商。主要产品有平板电脑、笔记本电脑、智能手机等。富士康Android手机固件存在后门漏洞。由于负责启动Android操作系统的引导装载程序代码存在漏洞，攻击者利用漏洞可绕过身份验证机制，并获取设备的控制权限。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2016-09330

 

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
