# F5发布2023年2月季度安全通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU3ODM2NTg2Mg==&mid=2247492952&idx=1&sn=025bc86276e6e4ba7d841774e65586cf&chksm=fd74d591ca035c87350389bc7f953f67a8ed6abc0b0c469c281e9d902004e36529a9c7a86b64&scene=126&sessionid=1681365517#rd](http://mp.weixin.qq.com/s?__biz=MzU3ODM2NTg2Mg==&mid=2247492952&idx=1&sn=025bc86276e6e4ba7d841774e65586cf&chksm=fd74d591ca035c87350389bc7f953f67a8ed6abc0b0c469c281e9d902004e36529a9c7a86b64&scene=126&sessionid=1681365517#rd)

安全公告编号:CNTA-2023-00032月1日，F5公司发布了2023年第一季度的季度安全通告，修复了多款产品存在的17个安全漏洞。受影响的产品包括：BIG-IP（16个）、BIG-IP SPK（2个）、BIG-IQ（1个）、F5OS（1个）、APM Edge Client（2个）等。利用上述漏洞，攻击者可进行欺骗，绕过安全功能限制，获取敏感信息，提升权限，执行远程代码，或发起拒绝服务攻击等。CNVD提醒广大F5用户尽快更新至最新版本系统，避免引发漏洞相关的网络安全事件。
