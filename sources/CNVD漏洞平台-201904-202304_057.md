安全公告编号:CNTA-2022-002410月11日，微软发布了2022年10月份的月度例行安全公告，修复了多款产品存在的84个安全漏洞。受影响的产品包括：Windows 11（66个）、Windows 11 v22H2（66个）、Windows Server 2022（66个）、Windows 10 21H2（64个）、Windows 10 21H1（64个）、Windows 10 20H2 & Windows Server v20H2（64个）、Windows 8.1 & Server 2012 R2（50个）、Windows Server 2012（49个）、Windows RT 8.1（48个）、Microsoft Office-related software（6个）。利用上述漏洞，攻击者可以绕过安全功能限制，获取敏感信息，提升权限，执行远程代码，或发起拒绝服务攻击等。CNVD提醒广大Microsoft用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。
