# 关于南京众智维等10家单位具备支撑单位资格的公告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU3ODM2NTg2Mg==&mid=2247491321&idx=3&sn=572f8bfc5b38b086fa543df93334ef16&chksm=fd772e30ca00a726f1d45dbdeb66d8de0ef7ce529ffbc296dd11e0ddba78d6ffad58762897f5&scene=126&sessionid=1681365785#rd](http://mp.weixin.qq.com/s?__biz=MzU3ODM2NTg2Mg==&mid=2247491321&idx=3&sn=572f8bfc5b38b086fa543df93334ef16&chksm=fd772e30ca00a726f1d45dbdeb66d8de0ef7ce529ffbc296dd11e0ddba78d6ffad58762897f5&scene=126&sessionid=1681365785#rd)

安全公告编号:CNTA-2022-0007

       

根据《国家信息安全漏洞共享平台（CNVD）管理办法》以及《CNVD支撑单位能力要求》，CNVD完成了对申请加入技术组支撑单位，并进入考察期的单位能力考察工作。其中，南京众智维信息科技有限公司、杭州迪普科技股份有限公司、北京信联科汇科技有限公司、内蒙古云科数据服务股份有限公司、京东云安全和中国电信股份有限公司网络安全产品运营中心六家单位通过了技术组支撑单位的能力考察，具备CNVD技术组支撑单位资格。按照CNVD用户组支撑单位要求，CNVD完成了对用户组申请单位的产品或用户规模情况和相关证明材料的审核。深圳市华域数安科技有限公司、OPPO广东移动通信有限公司、济南博观智能科技有限公司和北京珞安科技有限责任公司四家单位满足CNVD用户组支撑单位相关要求，加入CNVD用户组单位。
