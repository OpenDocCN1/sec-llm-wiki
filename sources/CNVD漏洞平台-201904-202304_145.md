**一、境外厂商产品漏洞**

****1、********Apache Log4j2存在远程代码执行漏洞****

Apache Log4j是一个基于Java的日志记录组件。Apache Log4j2是Log4j的升级版本，通过重写Log4j引入了丰富的功能特性。该日志组件被广泛应用于业务系统开发，用以记录程序输入输出日志信息。Apache Log4j2存在远程代码执行漏洞，攻击者可利用该漏洞向目标服务器发送精心构造的恶意数据，触发Log4j2组件解析缺陷，实现目标服务器的任意代码执行，获得目标服务器权限。

参考链接：  

https://www.cnvd.org.cn/flaw/show/CNVD-2021-95919

****2、********Oracle MySQL Cluster输入验证错误漏洞（CNVD-2022-07919）****

Oracle MySQL Cluster是美国甲骨文（Oracle）公司开发的一个写可扩展、实时、兼容ACID的事务型数据库。Oracle MySQL Cluster存在输入验证错误漏洞，攻击者可利用漏洞执行任意代码。

参考链接：  

https://www.cnvd.org.cn/flaw/show/CNVD-2022-07919

****3、********HDF5存在拒绝服务漏洞（CNVD-2022-07233）****

HDF5是美国HDF公司的一套用于管理和存储不同类型数据的工具套件。该产品支持管理、操作、查看和分析数据，并生成可移植格式的文件。HDF5 v1.13.1-1存在安全漏洞，攻击者可利用该漏洞执行拒绝服务（DoS）攻击。

参考链接：  

https://www.cnvd.org.cn/flaw/show/CNVD-2022-07233

****4、********Cisco Security Manager跨站脚本漏洞（CNVD-2022-06386）****

Cisco Security Manager（CSM）是美国思科（Cisco）公司的一套企业级的管理应用，它主要用于在Cisco网络和安全设备上配置防火墙、VPN和入侵保护安全服务。Cisco Security Manager存在跨站脚本漏洞，该漏洞源于产品基于Web的管理界面未对用户输入数据的特殊字符做有效处理，攻击者可利用该漏洞在接口上下文中执行任意脚本代码或访问敏感的、基于浏览器的信息。

参考链接：  

https://www.cnvd.org.cn/flaw/show/CNVD-2022-06386

****5、********Quest KACE Desktop Authority XXE漏洞****

Quest KACE Desktop Authority是美国Quest公司的一款桌面管理软件。Quest KACE DesktopAuthority存在XXE漏洞，目前没有详细漏洞细节提供。

参考链接：  

https://www.cnvd.org.cn/flaw/show/CNVD-2022-06877

 

**二、境内厂商产品漏洞**

****1、********metinfo存在逻辑缺陷漏洞（CNVD-2022-03235）****

米拓企业建站系统（MetInfo ）是一款免费开源的企业级CMS。metinfo存在逻辑缺陷漏洞，攻击者可利用该漏洞登录后台，获取敏感信息。

参考链接：  

https://www.cnvd.org.cn/flaw/show/CNVD-2022-03235

****2、********TOTOLINK A3002RU跨站脚本漏洞****

TOTOLINK A3002RU是中国台湾吉翁电子（TOTOLINK）公司的一款无线路由器产品。TOTOLINK A3002RU中存在跨站脚本漏洞，该漏洞源于产品修改Description和Service Name字段的功能缺少对客户端数据的有效验证。攻击者可通过该漏洞执行客户端代码。

参考链接：  

https://www.cnvd.org.cn/flaw/show/CNVD-2022-06508

****3、********巡云轻论坛系统存在命令执行漏洞（CNVD-2022-01416）****

巡云轻论坛系统包含论坛、问答模块，采用JAVA MYSQL架构。巡云轻论坛系统存在命令执行漏洞，攻击者可利用该漏洞获取服务器控制权限。

参考链接：  

https://www.cnvd.org.cn/flaw/show/CNVD-2022-01416

****4、********TOTOLINK A3002RU跨站脚本漏洞（CNVD-2022-06507）****

TOTOLINK A3002RU是中国台湾吉翁电子（TOTOLINK）公司的一款无线路由器产品。TOTOLINK A3002R版本V1.1.1-B20200824中的tr069config.htm存在安全漏洞，允许攻击者利用漏洞通过修改“用户名”字段或“密码”字段来执行任意的JavaScript。

参考链接：  

https://www.cnvd.org.cn/flaw/show/CNVD-2022-06507

****5、********TP-Link TL-WR802N操作系统命令注入漏洞****

TP-Link TL-WR802N是中国普联（TP-Link）公司的一个无线路由器。TP-Link TL-WR802N V4存在操作系统命令注入漏洞，该漏洞源于TP-Link wifi routerTL-WR802N V4易受操作系统命令注入攻击。目前没有详细的漏洞细节提供。

参考链接：  

https://www.cnvd.org.cn/flaw/show/CNVD-2022-06908

 

说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
