> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU3ODM2NTg2Mg==&mid=2247491182&idx=1&sn=2fe7c708878b29e48de153ba1a92d70c&chksm=fd772ea7ca00a7b13ed0c47800f76e25de50af56efdc6a56d7c7685c03d3891d9e87f03c5089&scene=126&sessionid=1681365790#rd](http://mp.weixin.qq.com/s?__biz=MzU3ODM2NTg2Mg==&mid=2247491182&idx=1&sn=2fe7c708878b29e48de153ba1a92d70c&chksm=fd772ea7ca00a7b13ed0c47800f76e25de50af56efdc6a56d7c7685c03d3891d9e87f03c5089&scene=126&sessionid=1681365790#rd)

安全公告编号:CNTA-2022-0002  

  

2022年1月18日，Oracle发布了2022年1月份的安全更新，修复了其多款产品存在的497个安全漏洞。受影响的产品包括：Oracle Database Server数据库（4个）、Oracle Airlines Data Model（1个）、Oracle Big Data Graph（2个）、Oracle Communications Data Model（1个）、OracleEssbase（4个）、Oracle GoldenGate（3个）、Oracle Graph Server and Client（2个）、OracleNoSQL Database（1个）、Oracle REST Data Services（2个）、Oracle Secure Backup（2个）、Oracle Spatial Studio（1个）、Oracle TimesTen In-Memory Database（5个）、OracleCommerce（6个）、Oracle Communications Applications（33个）、OracleCommunications（84个）、Oracle Construction and Engineering（22个）、电子商务套装软件OracleE-Business Suite（9个）、Oracle Enterprise Manager（7个）、Oracle Financial Services Applications（48个）、OracleFood and Beverage Applications（1个）、中间件产品Fusion Middleware（39个）、Oracle Health Sciences Applications（8个）、OracleHealthCare Applications（4个）、Oracle Hospitality Applications（3个）、OracleHyperion（1个）、Oracle iLearning（1个）、Oracle Insurance Applications（7个）、OracleJava SE（18个）、Oracle JD Edwards（1个）、Oracle MySQL数据库（78个）、Oracle PeopleSoft（13个）、Oracle Retail Applications（1个）、Oracle Retail Applications（43个）、Oracle Siebel CRM（2个）、Oracle Supply Chain（10个）、Oracle Support Tools（4个）、Oracle Systems（11个）、Oracle Utilities Applications（13个）和OracleVirtualization（2个）。

本次安全更新提供了针对235个高危漏洞的补丁，有420个漏洞可被远程利用。CNVD提醒广大Oracle用户，请及时下载补丁更新，避免引发漏洞相关的安全事件。
