一、境外厂商产品漏洞

1、Mozilla Firefox ESR代码问题漏洞（CNVD-2021-99620）

Mozilla Firefox ESR是美国Mozilla基金会的Firefox(Web浏览器)的一个延长支持版本。Mozilla Firefox ESR存在代码问题漏洞，攻击者可利用该漏洞导致应用崩溃。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2021-99620

2、JT2Go和Teamcenter Visualization文件解析漏洞（CNVD-2021-100362）

JT2Go是一个3D JT查看工具，Teamcenter可视化软件使企业能够通过一个全面的可视化解决方案系列来增强其产品生命周期管理(PLM)环境。该软件允许企业用户在单一环境中访问文档、2D图纸和3D模型。JT2Go和Teamcenter Visualization文件解析漏洞，攻击者可利用该漏洞执行任意代码。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2021-100362

3、Accops HyWorks Windows Client整数溢出漏洞（CNVD-2021-100388）

Accops HyWorks是印度Accops公司的一个由软件和硬件组成的解决方案套件。用于从任何地方、任何设备和任何网络即时、安全地远程访问企业应用程序。Accops HyWorks WindowsClient存在整数溢出漏洞，攻击者可利用该漏洞在内核模式下执行任意代码或通过特制的I/O请求数据包导致拒绝服务。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2021-100388

4、Google Chrome file API代码执行漏洞

Google Chrome是美国谷歌（Google）公司的一款Web浏览器。Google Chrome存在安全漏洞，该漏洞源于在文件API中的释放后使用。远程攻击者可以利用此漏洞造成拒绝服务或在系统上执行任意代码。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2021-100603

5、Fortinet FortiOS访问控制错误漏洞

Fortinet FortiOS是美国飞塔（Fortinet）公司的一套专用于FortiGate网络安全平台上的安全操作系统。该系统为用户提供防火墙、防病毒、IPSec/SSLVPN、Web内容过滤和反垃圾邮件等多种安全功能。Fortinet FortiOS 和 FortiProxy autod守护进程中存在访问控制错误漏洞，经过身份验证的低权限攻击者可利用该漏洞通过结构自动化CLI脚本和自动脚本功能的特定精心配置将其权限提升到super_admin。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2021-100291


二、境内厂商产品漏洞

1、Huawei HarmonyOS输入验证错误漏洞（CNVD-2021-99981）

Huawei HarmonyOS是中国华为（Huawei）公司的一个操作系统。提供一个基于微内核的全场景分布式操作系统。Huawei HarmonyOS存在输入验证错误漏洞。攻击者可利用该漏洞导致设备重启。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2021-99981

2、WUZHI CMS SQL注入漏洞（CNVD-2021-99301）

WUZHI CMS（五指CMS）是一款高性能开源内容管理系统,支持LNAMP架构,适合门户网站、企业网站建站、手机网站、微信推广。WUZHI CMS 4.1.0版存在SQL注入漏洞。攻击者可通过/coreframe/app/order/admin/card.php中的keywords参数利用该漏洞进行SQL注入攻击。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2021-99301

3、Huawei HarmonyOS路径遍历漏洞

Huawei HarmonyOS是中国华为（Huawei）公司的一个操作系统。提供一个基于微内核的全场景分布式操作系统。Huawei HarmonyOS某个组件存在路径遍历漏洞。该漏洞源于网络系统或产品未能正确地过滤资源或文件路径中的特殊元素。攻击者可利用该漏洞访问受限目录之外的位置。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2021-99666

4、74CMS跨站脚本漏洞（CNVD-2021-99667）

74cms是中国迅易科技公司的一套基于PHP和MySQL的在线招聘系统。74CMS在v6.0.4版本存在跨站脚本漏洞，该漏洞源于 /index.php?m=＆c=help＆a=help_list＆key缺少对用户提供的数据和输出的数据校验过滤。攻击者可利用该漏洞在客户端执行JavaScript代码。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2021-99667

5、ASUS routers环境问题漏洞

ASUS routers是中国台湾华硕（ASUS）公司的一款路由器。ASUS routers存在安全漏洞，该漏洞源于路由器固件对HTTP数据包校验存在问题，未经身份验证的远程攻击者可利用该漏洞通过发送特制的HTTP数据包进行拒绝服务攻击。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2021-99877
