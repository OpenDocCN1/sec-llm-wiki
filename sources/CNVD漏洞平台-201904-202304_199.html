一、境外厂商产品漏洞

1、Axis P1425-LE-Network-Camera存在未授权访问漏洞

Axis是一家专为提供网络视频解决方案的IT公司。Axis P1425-LE-Network-Camera存在未授权访问漏洞，攻击者可利用该漏洞获取敏感信息。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2021-50959

2、Imagegear存在拒绝服务漏洞（CNVD-2021-50961）

ImageGear是一款图形图像处理软件，具有扫描，压缩，浏览，打印，添加注释，图片编辑等功能，可以使开发人员快速地开发出图像处理程序。Imagegear存在拒绝服务漏洞，攻击者可利用该漏洞造成拒绝服务攻击。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2021-50961

3、Westermo MRD-350存在弱口令漏洞

Westermo专注于设计和制造用于严苛环境中关键系统的数据通信产品。Westermo MRD-350存在弱口令漏洞，攻击者利用弱密码登录后台，获取敏感信息。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2021-55219

4、Google TensorFlow缓冲区溢出漏洞（CNVD-2021-64538）

Google TensorFlow是美国谷歌（Google）公司的一套用于机器学习的端到端开源平台。Google TensorFlow存在安全漏洞，攻击者可利用漏洞通过在所有类型为\"tf.raw_ops.MatrixDiagV*\"的操作中绑定对空指针的引用来导致未定义的行为。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2021-64538

5、IBM Cloud Pak for Security信息泄露漏洞（CNVD-2021-64548）

IBM Cloud Pak for Security是美国IBM公司的一款应用软件。一个开放的安全平台，可连接到您现有的数据源以产生更深刻的见解，并使您能够更快地采取自动化行动。IBM Cloud Pak for Security (CP4S) 存在信息泄露漏洞，该漏洞源于网络系统或产品在运行过程中存在配置等错误。攻击者可利用漏洞通过HTTP GET请求向未授权用户泄露敏感信息，这些信息可以用于对系统的进一步攻击。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2021-64548
