安全公告编号:CNTA-2019-0034

10月8日，微软发布了2019年10月份的月度例行安全公告，修复了其多款产品存在的206个安全漏洞。受影响的产品包括：Windows 10 1903 & Windows Server v1903（31个）、Windows 10 1809 & Windows Server 2019（32个）、Windows 10 1803 & Windows Server v1803（29个）、Windows RT 8.1（20个）、WindowsServer 2012（18个）、Windows 8.1 & Server 2012 R2（20个）Windows Server 2008（17个）、Windows 7 andWindows Server 2008 R2（21个）、Microsoft Edge（7个）、Internet Explorer（5个）和Microsoft Office-related software（6个）。

利用上述漏洞，攻击者可以获取敏感信息，提升权限，欺骗，绕过安全功能限制，执行远程代码，或进行拒绝服务攻击等。CNVD提醒广大Microsoft用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。

CVE-2019-1333

Windows远程桌面客户端远程代码执行漏洞

当用户连接到恶意服务器时，Windows远程桌面客户端中存在远程代码执行漏洞。成功利用此漏洞的攻击者可以在连接客户端的计算机上执行任意代码。要利用此漏洞，攻击者需要控制服务器，然后说服用户连接到该服务器。攻击者无法强迫用户连接到恶意服务器，需要通过社会工程、DNS中毒或使用中间人（MITM）技术诱骗用户连接。攻击者还可能危害合法服务器，在其上托管恶意代码，并等待用户连接。

VBScript远程代码执行漏洞

攻击者可以托管精心编制的网站，该网站旨在通过IE利用该漏洞，然后说服用户查看该网站。攻击者还可以通过添加可利用此漏洞的精心编制的内容，利用受损网站或接受或承载用户提供的内容或广告的网站。攻击者还可以在承载浏览器呈现引擎的应用程序或Office文档中嵌入标记为“可安全初始化”的ActiveX控件。

CVE-2019-1331

Microsoft Excel远程代码执行漏洞

利用此漏洞需要用户使用受影响的Excel版本打开构建的文件。

Web场景-攻击者利用此漏洞托管恶意网站，然后说服用户访问该网站，或者攻击者利用受损网站和/或托管其他提供商广告的网站。

电子邮件场景-攻击者发送精心编制的文件并说服用户在Outlook中打开该文件。

CVE-2019-1330

Microsoft SharePoint权限提升漏洞

Microsoft  SharePoint中存在权限提升漏洞。成功利用此漏洞的攻击者可以尝试模拟SharePoint服务器的其他用户。要利用此漏洞，经过身份验证的攻击者会向受影响的服务器发送精心编制的请求，从而允许模拟其他SharePoint用户。

安全更新通过更正Microsoft SharePoint清理用户输入的方式来解决此漏洞。
