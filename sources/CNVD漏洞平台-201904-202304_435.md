安全公告编号:CNTA-2019-0034

10月8日，微软发布了2019年10月份的月度例行安全公告，修复了其多款产品存在的206个安全漏洞。受影响的产品包括：Windows 10 1903 & Windows Server v1903（31个）、Windows 10 1809 & Windows Server 2019（32个）、Windows 10 1803 & Windows Server v1803（29个）、Windows RT 8.1（20个）、WindowsServer 2012（18个）、Windows 8.1 & Server 2012 R2（20个）Windows Server 2008（17个）、Windows 7 andWindows Server 2008 R2（21个）、Microsoft Edge（7个）、Internet Explorer（5个）和Microsoft Office-related software（6个）。

利用上述漏洞，攻击者可以获取敏感信息，提升权限，欺骗，绕过安全功能限制，执行远程代码，或进行拒绝服务攻击等。CNVD提醒广大Microsoft用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。
