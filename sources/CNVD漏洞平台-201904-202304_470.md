# Microsoft发布2019年7月安全更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU3ODM2NTg2Mg==&mid=2247486979&idx=1&sn=b77271f28e7ab7e81878aae0951abeb2&chksm=fd773ecaca00b7dcfcfe8c0e6bc2907c6f3a2b6d84039041878beb293ae19070128f85164db4&scene=126&sessionid=1681365880#rd](http://mp.weixin.qq.com/s?__biz=MzU3ODM2NTg2Mg==&mid=2247486979&idx=1&sn=b77271f28e7ab7e81878aae0951abeb2&chksm=fd773ecaca00b7dcfcfe8c0e6bc2907c6f3a2b6d84039041878beb293ae19070128f85164db4&scene=126&sessionid=1681365880#rd)

安全公告编号:CNTA-2019-0025

7月9日，微软发布了2019年7月份的月度例行安全公告，修复了其多款产品存在的240个安全漏洞。受影响的产品包括：Windows 10 1903 & Windows Server v1903（40个）、Windows 10 1809 & Windows Server 2019（40个）、Windows 10 1803 & Windows Server v1803（41个）、Windows RT 8.1（18个）、WindowsServer 2012（18个）、Windows 8.1 & Server 2012 R2（22个）、Windows Server 2008（20个）、Windows 7 andWindows Server 2008 R2（21个）、MicrosoftEdge（7个）、Internet Explorer（6个）和Microsoft Office-related software（7个）。

利用上述漏洞，攻击者可以提升权限，欺骗，绕过安全功能限制，获取敏感信息，执行远程代码或发起拒绝服务攻击等。CNVD提醒广大Microsoft用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。
