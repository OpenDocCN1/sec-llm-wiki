安全公告编号:CNTA-2019-0019

6月11日，微软发布了2019年6月份的月度例行安全公告，修复了其多款产品存在的344个安全漏洞。受影响的产品包括：Windows 10 1903 & Windows Serverv1903（42个）、Windows 10 1809 & Windows Server 2019（48个）、Windows 10 1803 & Windows Server v1803（46个）、Windows RT 8.1（35个）、WindowsServer 2012（33个）、Windows 8.1 & Server 2012 R2（35个）、Windows Server 2008（38个）、Windows7 and Windows Server 2008 R2（42个）、MicrosoftEdge（13个）、Internet Explorer（5个）和Microsoft Office-related software（7个）。

利用上述漏洞，攻击者可以获取敏感信息，提升权限，欺骗，绕过安全功能限制，执行远程代码，或进行拒绝服务攻击等。CNVD提醒广大Microsoft用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。

CVE-2019-0888

Microsoft ActiveX Data Objects远程代码执行漏洞

ActiveX Data Objects (ADO)处理内存中对象存在远程代码执行漏洞。成功利用该漏洞的攻击者可以使用受害者用户的特权执行任意代码。攻击者可以创建一个利用漏洞的网站，然后说服受害者用户访问该网站。安全更新通过修改ActiveX数据对象如何处理内存中的对象来解决该漏洞。

CVE-2019-0722

Microsoft Windows Hyper-V远程代码执行漏洞

当主机服务器上的Windows Hyper-V未能正确验证来宾操作系统上已验证用户的输入时，存在远程代码执行漏洞。为了利用该漏洞，攻击者可以在来宾操作系统上运行精心设计的应用程序，从而导致Hyper-V主机操作系统执行任意代码。

Microsoft  Windows Security Feature远程安全绕过漏洞

Netlogon消息能够获取会话密钥并对消息进行签名存在安全功能绕过漏洞。为了利用此漏洞，攻击者可以发送精心设计的身份验证请求。成功利用此漏洞的攻击者可以使用原始用户权限访问另一台计算机。

CVE-2019-0911

Microsoft Internet Explorer and Edge脚本引擎远程内存破坏漏洞

攻击者可以托管一个精心设计的网站，该网站旨在通过受影响的Microsoft浏览器利用该漏洞，然后说服用户查看该网站。攻击者还可以通过添加可利用该漏洞精心设计的内容，利用受到攻击的网站或接受或宿主用户提供的内容或广告的网站。攻击者还可以在承载浏览器呈现引擎的应用程序或Office文档中嵌入标记为“初始化安全”的ActiveX控件。
