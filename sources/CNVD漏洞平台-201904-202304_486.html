一、境外厂商产品漏洞

1、Ivanti LANDESK Management Suite开放目录漏洞

Ivanti LANDESK Management Suite（LDMS）是美国Ivanti公司的一套端点安全管理软件。Ivanti LDMS 10.0.1.168Service Update 5版本中存在开发目录漏洞。该漏洞源于网络系统或产品未对输入的数据进行正确的验证。攻击者可利用该漏洞获取信息或执行任意代码。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2019-16601

2、Vim&Neovim任意代码执行漏洞

Vim是从vi发展出来的⼀个文本编辑器，Neovim是⼀个基于vim源代码的重构项⽬。Vim&Neovim存在任意代码执行漏洞，攻击者可通过诱使用户使用vim或者neovim打开⼀个精心制作的文件，利用该漏洞在目标机器上执行任意命令。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2019-16596

3、Joomla! Harmis JE Messenger组件SQL注入漏洞

Joomla!是美国Open Source Matters团队的一套使用PHP和MySQL开发的开源、跨平台的内容管理系统(CMS)。Harmis JE Messengercomponent是使用在其中的一款个人消息管理组件，它支持收、发邮件和在线消息。Joomla! Harmis JEMessenger 1.2.2存在SQL注入漏洞，攻击者可利用该漏洞在数据库中执行任意SQL语句。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2019-16742

4、Microsoft Windows Kernel权限提升漏洞（CNVD-2019-16756）

Microsoft Windows和Microsoft Windows Server都是美国微软（Microsoft）公司的产品。Microsoft Windows是一套个人设备使用的操作系统。Microsoft Windows Server是一套服务器操作系统。Windows Kernel是其中的一个Windows系统内核。Microsoft Windows Kernel中存在权限提升漏洞，本地攻击者可通过登录系统并运行特制的应用程序利用该漏洞在内核模式下运行任意代码。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2019-16756

5、DVD Photo Slideshow Professional存在SEH缓冲区溢出漏洞

DVD Photo Slideshow Pro是一款简单实用,功能强大的电子相册制作软件。DVD Photo SlideshowProfessional存在SEH缓冲区溢出漏洞。由于在注册名称处未能校验输入的数据长度，攻击者可利用漏洞在应用程序的上下文中执行任意代码。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2019-15542

 

二、境内厂商产品漏洞

1、wecon LeviStudio存在dll劫持漏洞

福州富昌维控电子科技有限公司是一家专业从事自动化领域产品研究、开发与销售的高科技公司。wecon LeviStudio存在dll劫持漏洞，攻击者可以利用漏洞获取设备权限。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2019-14872

2、优酷视频pc客户端软件存在命令执行漏洞

优酷是阿里巴巴文化娱乐集团大优酷事业群下的视频平台。优酷视频pc客户端软件存在命令执行漏洞，软件PC客户端可以允许攻击者在客户端进程中注入可执行DLL文件，执行任意功能。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2019-14874

3、腾讯视频pc客户端软件存在命令执行漏洞

腾讯视频是在线视频平台，为用户提供高清流畅的视频娱乐体验。腾讯视频pc客户端软件存在命令执行漏洞，软件PC客户端可以允许攻击者在客户端进程中注入可执行DLL文件，执行任意功能。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2019-14875

4、金山pdf pc客户端软件存在命令执行漏洞

金山PDF是由金山办公软件有限公司出的一款针对PDF文件格式的阅读和处理工具。金山pdf pc客户端软件存在命令执行漏洞，软件PC客户端可以允许攻击者在客户端进程中注入可执行DLL文件，执行任意功能。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2019-14878

5、就业信息网存在任意文件上传漏洞

慧萌软件是致力于通过专业的产品和服务提升企业或政府机构的信息化管理水平。就业信息网存在任意文件上传漏洞，攻击者可以利用漏洞登陆后台录入信息，上传附件处存在任意文件上传漏洞，上传脚本文件可获得服务器权限。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2019-14880
