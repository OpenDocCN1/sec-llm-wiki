Vulhub靶场环境搭建

物理机：Windows 10

虚拟机：centos 7


安装centos7

参考链接：https://blog.csdn.net/qq_44714603/article/details/88829423

镜像文件可从多个地方下载，这里下载的是阿里云的

新建虚拟机过程省略，查看虚拟机配置

打开虚拟机

 


选择Install CentOS7

安装界面选择默认English就好，然后Continue继续

设置时间，选择Asia，城市选择上海，然后根据当前时间调整具体的时间，点击Done

设置键盘，默认的英文键盘，点击Done完成

设置支持的语言，选择English和简体中文，点击Done

安装资源，选择默认的local media本地媒体文件

选择安装界面（这里用的是minimal install）

字符界面选择minimal install或basic web server

图形界面选择server with GUI或GNOME desktop

选择安装位置（系统分区）

先选中我们的虚拟硬盘

选择自定义分区，然后点击done完成

这里选择标准分区，

点击左下角的+ 添加分区

分别创建/boot分区、swap交换分区、/根分区三个分区

分区完成，点击done

点击接受

KDUMP默认选择

设置网络和主机名

在host name处设置主机名，点击done完成

设置完成后点击Begin Installation开始安装

安装过程中需要设置root用户的密码

可以选择创建一个用户

安装完成点击reboot重启使用

CentOS7网络配置

ip addr查看网络

找到以太网卡配置文件

/etc/sysconfig/network-scripts/ifcfg-en***

网卡配置文件的名称在安装过程中网络与主机名设置的地方

编辑配置文件，将onboot的no改为yes

Vim下i命令进入编辑模式esc从编辑模式返回命令模式，:wq命令保存并退出

修改配置文件后重启网络服务

#service network restart

此时可以看有ipv4的地址了

在物理机联网的情况下测试ping百度，物理机没联网时可ping物理机ip测试连通性

搭建vulhub靶场

参考链接：   https://www.freebuf.com/sectool/226207.html

https://blog.csdn.net/aaron_miller/article/details/96478981


环境配置：

centos7(虚拟机)

网络模式：NAT模式

IP地址：192.168.60.130

Windows10(物理机)

IP地址：192.168.137.1

物理机联网


1.安装docker

参考链接：https://blog.csdn.net/Aaron_Miller/article/details/96100315


$ curl -fsSL https://get.docker.com |bash -s docker --mirror Aliyun


Docker --version //查看版本

# systemctl start docker //启动docker

#systemctl enable docker (设置开机启动，为了安全，不建议使用)

2.安装docker-compose

参考链接：https://blog.csdn.net/Aaron_Miller/article/details/96429762


1)离线安装

先到docker-compose下载docker-compose-linux-x86_64

可用pscp或其他方法传至虚拟机中，或直接下载至虚拟机中

Pscp -v 文件名 user@ip:/路径/        (-v参数是将本地文件复制到目标主机的某个目录下)

(#然后将该文件移到/usr/local/bin/目录下并改名为docker-compose)

#mv docker-compose-linux-x86_64 /usr/local/bin/docker-compose

(#给该文件添加执行权限)

#sudo chmod +x /usr/local/bin/docker-compose

#查看版本

#docker-compose --version

2)在线pip安装

#pip       install docker-compose

(#安装docker-compose)

(若没有pip先安装pip)

#yum -y install epel-release

#yum -y install python-pip

#pip --version       #查看pip版本

3.下载vulhub

1)离线安装

下载vulhub压缩包，上传至某一位置，这里上传至/root/目录下

创建一个vulhub目录并将该压缩包放进去，然后进入该目录

#mkdir vulhub &&mv master.zip vulhub/ &&cd vulhub

解压缩文件

#unzip master.zip


2)在线git安装

#git clone https://github.com/vulhub/vulhub.git


若没有git，先安装git

#yum -y install git


Vulhub的使用

1.先启用docker

#service docker start


检查服务是否正常启用

#systemctl |grep docker

2.启动靶场

1)选取环境

在vulhub漏洞环境中找到自己想要复现的漏洞，查看路径

或直接在虚拟机的vulhub目录下寻找想要复现的漏洞，进入漏洞环境目录

docker-compose.yml文件是设置漏洞环境的，比如靶场启用后漏洞的端口、账号、密码等

该文件定义组成应用的各个服务

2)启用环境

在对应的漏洞环境的目录下使用命令

#docker-compose build&&docker-compose up -d

或直接使用命令

#docker-compose up -d

由于docker-compose up -d命令运行后会自动查找目录下的配置文件，若配置文件存在则无需编译，若不存在则会自动运行编译，故该命令包含了docker-compose build

若更新了配置文件，则可手动使用docker-compose build命令重新编译靶场环境

关闭环境

#docker-compose down              #仍然需要在漏洞环境目录下执行


查看靶机运行端口

#docker ps       #查看运行服务端口


3)连通性

虚拟机ping docker是可通的

宿主机ping docker是不通的，因为不在同意局域网内，需要手动对宿主机添加一条路由

> route add -p 172.17.0.0 mask 255.255.0.0 192.168.60.130

添加路由后的连通性测试


然后就可以在靶场为所欲为了，加油吧少年，安全的道路还很漫长，Jack~
