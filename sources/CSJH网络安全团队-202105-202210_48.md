# 搭建vulhub靶场

参考链接：   https://www.freebuf.com/sectool/226207.html

https://blog.csdn.net/aaron\_miller/article/details/96478981

  

环境配置：

centos7(虚拟机)

网络模式：NAT模式

IP地址：192.168.60.130

Windows10(物理机)

IP地址：192.168.137.1

物理机联网

  

### 1.安装docker

参考链接：https://blog.csdn.net/Aaron\_Miller/article/details/96100315

  

$ curl -fsSL https://get.docker.com |bash -s docker --mirror Aliyun

![](../Images/3d30407f1ed9928b575e9e16e336f926.png)

![](../Images/0e6841cbb00117767063d4f264974082.png)

  

Docker --version //查看版本

![](../Images/8acf1f2cbd7d31f09319eaeb10e54eec.png)

\# systemctl start docker //启动docker

#systemctl enable docker (设置开机启动，为了安全，不建议使用)

![](../Images/fd5664709d3f78bc986a578337a3d43f.png)

### 2.安装docker-compose

参考链接：https://blog.csdn.net/Aaron\_Miller/article/details/96429762

  

#### 1)离线安装

先到docker-compose下载docker-compose-linux-x86\_64

可用pscp或其他方法传至虚拟机中，或直接下载至虚拟机中

Pscp -v 文件名 user@ip:/路径/        (-v参数是将本地文件复制到目标主机的某个目录下)

![](../Images/4d2de1e9f8f89394124f6f19fffb1468.png)

(#然后将该文件移到/usr/local/bin/目录下并改名为docker-compose)

#mv docker-compose-linux-x86\_64 /usr/local/bin/docker-compose

![](../Images/b507e8169b9866653eaeed162c47efcf.png)

(#给该文件添加执行权限)

#sudo chmod +x /usr/local/bin/docker-compose

![](../Images/5eeb60b7bc128abc16936aaebcf7f308.png)

#查看版本

#docker-compose --version

![](../Images/52d163d1312a7c2c947765dc36d7262f.png)

#### 2)在线pip安装

#pip       install docker-compose

(#安装docker-compose)

(若没有pip先安装pip)

#yum -y install epel-release

#yum -y install python-pip

#pip --version       #查看pip版本

### 3.下载vulhub

#### 1)离线安装

下载vulhub压缩包，上传至某一位置，这里上传至/root/目录下

创建一个vulhub目录并将该压缩包放进去，然后进入该目录

#mkdir vulhub &&mv master.zip vulhub/ &&cd vulhub

解压缩文件

#unzip master.zip

  

#### 2)在线git安装

#git clone https://github.com/vulhub/vulhub.git

  

若没有git，先安装git

#yum -y install git

  

### Vulhub的使用

#### 1.先启用docker

#service docker start

![](../Images/5f3ff9c790290b40ec863826258780a1.png)

  

检查服务是否正常启用

#systemctl |grep docker

![](../Images/f710ae38943f3b16257194cc5545e31c.png)

#### 2.启动靶场

##### 1)选取环境

在vulhub漏洞环境中找到自己想要复现的漏洞，查看路径

![](../Images/83b2d7de7fe72a6eaebd0cf06796f05a.png)

或直接在虚拟机的vulhub目录下寻找想要复现的漏洞，进入漏洞环境目录

![](../Images/fb9872504b851505952cf7a8c23e7ac9.png)

docker-compose.yml文件是设置漏洞环境的，比如靶场启用后漏洞的端口、账号、密码等

该文件定义组成应用的各个服务

![](../Images/32ab48e326f425d0dd2beaea89801174.png)

##### 2)启用环境

在对应的漏洞环境的目录下使用命令

#docker-compose build&&docker-compose up -d

或直接使用命令

#docker-compose up -d

由于docker-compose up -d命令运行后会自动查找目录下的配置文件，若配置文件存在则无需编译，若不存在则会自动运行编译，故该命令包含了docker-compose build

若更新了配置文件，则可手动使用docker-compose build命令重新编译靶场环境

![](../Images/966da74c805ec3084087880cb1d0d7d5.png)

关闭环境

#docker-compose down              #仍然需要在漏洞环境目录下执行

![](../Images/2ebe3e6c019ab44a8b058a659ce409fc.png)

  

查看靶机运行端口

#docker ps       #查看运行服务端口

![](../Images/5fce7c2ac060d0315c5895dbe091d4c7.png)

  

##### 3)连通性

虚拟机ping docker是可通的

宿主机ping docker是不通的，因为不在同意局域网内，需要手动对宿主机添加一条路由

![](../Images/5f4733d6846f60959812fad7e9e928c9.png)

\> route add -p 172.17.0.0 mask 255.255.0.0 192.168.60.130

![](../Images/ab1e71494948bd9dc99c89d0d3fadfb9.png)

![](../Images/ed444d58215cb9df97fa1e49cf696958.png)

添加路由后的连通性测试

![](../Images/d669bb3b1287fe51f761d63133181e40.png)
