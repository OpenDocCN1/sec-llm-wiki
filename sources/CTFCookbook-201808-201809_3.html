一、Web安全相关概念（已基本完成）

  1. 熟悉基本概念（SQL注入、上传、XSS、CSRF等）。

  2. 通过关键字（SQL注入、上传、XSS、CSRF等）进行Google/SecWiki学习；

  3. 阅读《精通脚本黑客》，虽然很旧但是入门还是可以的；

  4. 看一些渗透笔记/视频，了解渗透实战的整个过程，可以Google（渗透笔记、渗透过程、入侵过程等）；

    学习时长：2周

 

二、熟悉渗透相关工具

  1. 熟悉AWVS、sqlmap（已学习完成）、Burp、nessus、chopper、nmap（已学习完成）、Appscan等相关工具的使用。

  2. 了解该类工具的用途和使用场景，先用软件名字在Google/SecWiki上

    下载无后门版的这些软件进行安装、学习并进行使用，具体教材可以在SecWiki上搜索，例如：Brup的教程、sqlmap；

  3. 常用的这几个软件都学会了可以安装音速启动做一个渗透工具箱；

    学习时长：5周

 

三、渗透实战操作

   目的：掌握渗透的整个阶段并能够独立渗透小型站点。

  1. 首先把学校训练营的课程补好，下一步网上找渗透视频看并思考其中的思路和原理，关键字（渗透、SQL注入视频、文件上传入侵、数据库备份、dedecms漏洞利用等等）；

  2. 自己找站点/搭建测试环境进行测试，//233“自相矛盾？”

    记得用隐藏方法将自己隐藏之后再挑战；

    可以参考: 开源渗透测试脆弱系统；

  3. 思考渗透主要分为几个阶段，每个阶段需要做那些工作，形成自己的规范和流程。例如：PTES渗透测试执行标准；

  4. 研究SQL注入的种类、注入原理、手动注入技巧；

  5. 研究文件上传的原理，如何进行截断、双重后缀欺骗(IIS、PHP)、解析漏洞利用（IIS、Nignix、Apache）等，参照：上传攻击框架；

  6. 研究XSS形成的原理和种类，具体学习方法可以Google/SecWiki，可以参考：XSS；

  7. 研究Windows/Linux提权的方法和具体使用，可以参考：提权；

    实践时长：3周



 

四、关注安全圈动态

  1. 关注安全圈的最新漏洞、安全事件与技术文章。

  2. 通过SecWiki浏览每日的安全技术文章/事件；

  3. 通过知乎/微博/twitter关注安全圈的从业人员（遇到大牛的关注或者好友果断关注），天天抽时间刷一下；

  4. 通过feedly/鲜果订阅国内外安全技术博客（不要仅限于国内，平时多注意积累），没有订阅源的可以看一下SecWiki的聚合栏目；

  5. 养成习惯，每天主动提交安全技术文章链接到公众号进行积淀；

  6. 多关注下最新漏洞列表，推荐几个：exploit-db、CVE中文库、Wooyun（乌云）等，遇到公开的漏洞都去实践下。

  7. 关注国内国际上的安全会议的议题或者录像，推荐SecWiki-Conference。

    学习时长：长期

 

五、Windows/Kali Linux入门与掌握（已基本完成）

  1. 学习Windows/Kali Linux基本命令、常用工具；

  2. 熟悉Windows下的常用的cmd命令，例如：ipconfig,nslookup,tracert,net,tasklist,taskkill等；

  3. 熟悉Linux下的常用命令，例如：ifconfig,ls,cp,mv,vi,wget,service,sudo等；

  4. 熟悉Kali Linux系统下的常用工具，可以参考SecWiki，相关书籍《Web Penetration Testing with Kali Linux》、《鸟哥的Linux私房菜》、《Hacking with Kali》等；

  5. 熟悉metasploit工具，可以参考SecWiki、《Metasploit渗透测试指南》。

    学习时长：0

 

六、服务器安全配置（已基本完成）

  1. 学习服务器环境配置，并能通过思考发现配置存在的安全问题。

  2. Windows2003/2008环境下的IIS配置，特别注意配置安全和运行权限，可以参考：SecWiki-配置；

  3. Linux环境下的LAMP的安全配置，主要考虑运行权限、跨目录、文件夹权限等，可以参考：SecWiki-配置；

  4. 远程系统加固，限制用户名和口令登陆，通过iptables限制端口；

  5. 配置软件Waf加强系统安全，在服务器配置mod_security等系统，参见SecWiki-ModSecurity；

  6. 通过Nessus软件对配置环境进行安全检测，发现未知安全威胁。

    学习时长：2周

 

七、脚本编程学习

  1. 选择脚本语言Perl/Python（已基本完成）/PHP/Go（-ing）/Java（已完成）中的一种，对常用库进行编程学习。

  2. 搭建开发环境和选择IDE，PHP环境推荐Wamp和XAMPP，IDE强烈推荐Sublime，一些Sublime的技巧：SecWiki-Sublime；

  3. Python编程学习，学习内容包含：语法、正则、文件、网络、多线程等常用库，推荐《Python核心编程》，不要看完（已完成）；

  4. 用Python编写漏洞的exp，然后写一个简单的网络爬虫，可参见SecWiki-爬虫、视频；

  5. PHP基本语法学习并书写一个简单的博客系统，参见《PHP与MySQL程序设计（第4版）》、视频；

  6. 熟悉MVC架构，并试着学习一个PHP框架或者Python框架（可选）；

  7. 了解Bootstrap的布局或者CSS（已完成），可以参考：SecWiki-Bootstrap;

    学习时长：3周

 

八、源码审计与漏洞分析

  1. 能独立分析脚本源码程序并发现安全问题。

  2. 熟悉源码审计的动态和静态方法，并知道如何去分析程序，参见SecWiki-审计；

  3. 从Wooyun上寻找开源程序的漏洞进行分析并试着自己分析；

  4. 了解Web漏洞的形成原因，然后通过关键字进行查找分析，参见SecWiki-代码审计、高级PHP应用程序漏洞审核技术；

  5. 研究Web漏洞形成原理和如何从源码层面避免该类漏洞，并按检查流程整理成checklist。

    学习时长：5周

 

九、安全体系设计与开发（毕设考虑方向）

  1. 能建立自己的安全体系，并能提出一些安全建议或者系统架构。

  2. 开发一些实用的安全小工具并开源，体现个人实力；

  3. 建立自己的安全体系，对公司安全有自己的一些认识和见解；

  4. 提出或者加入大型安全系统的架构或者开发；

    学习时长：一年内长期
