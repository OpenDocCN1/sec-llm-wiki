F5隐写

![](../Images/2880034d2621ce3dc9b95ab972b4fc04.png)

一张名为“123456.jpg”的图片

hint：我该用什么来刷新呢？

  

![](../Images/f7a919e870941b535b41bef0a2991891.png)

思路

根据题目提示：一般用什么来刷新。

当然是用F5来刷新了呀

所以搜索一下F5隐写，在github上找到了利用工具：  

git clone https://github.com/matthewgao/F5-steganography

cd F5-steganography

java Extract ../123456.jpg -p 123456

然后查看生成的output.txt，flag就在其中~   

  

![](../Images/e14538bd4af4bcbf51f60064e6cf9f95.png)

  

OutGuess隐写

![](../Images/2880034d2621ce3dc9b95ab972b4fc04.png)

一张名为“angrybird.jpg”的图片

hint：guess guess guess不出你就out了！

![](../Images/adcfd7f8a558f858160b5760ed1fc1ae.png)

通过搜索，可以发现如下的信息：

![](../Images/4663cab7ce812a8b672ddcaf1d6b2e10.png)

思路

根据搜索的结果，判断本题为outguess隐写

但是非常尴尬的是，outguess的官网http://www.outguess.org

小编从来没有打开过，所以只能从csdn上找了一个

下载到本地后，进入outguess目录下，输入下面三条命令：

./configure

make  

make install

就可以使用outguess了

查看outguess的使用方法

使用outguess -r angrybird.jpg output.txt

然后查看output.txt就拿到flag了~
