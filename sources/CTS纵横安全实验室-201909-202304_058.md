### 2.nmap进行靶机端口服务扫描

```
nmap -sS -Pn -A -p- -n 192.168.100.9
```

```
\-sS  SYN 扫描，半连接
\-Pn  跳过Ping扫描阶段
\-A   全面扫描
\-p-  全端口
\-n   禁止DNS反向解析，如果单纯扫描一段IP，该选项可以大幅度减少目标主机响应时间
```

可以看到靶机开放了21/ftp、22/ssh、80/http端口
