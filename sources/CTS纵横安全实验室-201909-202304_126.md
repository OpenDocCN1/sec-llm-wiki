https://download.vulnhub.com/hackathonctf/ctf.zip

2.环境说明

目标ip：192.168.72.128

3.信息收集

基于arp\_scan进行本地扫描（确定靶机IP）

 arp-scan -l 

![](../Images/2ceaf4b8a496136d5e587c306165fdae.png)

  

基于nmap进行全端口半连接扫描

nmap -sS -p- 192.168.72.128

![](../Images/088a2f0d6461963cfcffafdd8488126b.png)

**4.漏洞利用**  

尝试通过浏览器登录主页面——失败！

![](../Images/3e420dd79e10023aec0e20db2199a642.png)

  

对常见web文件、目录进行探测（使用软件：御剑）

![](../Images/3db71aa0b6dd4bbcdc1f93ad1dad1f7c.png)

  

登录http://192.168.72.128/robots.txt查看内容

![](../Images/fe2f068a903ce8338b134af288d3d73f.png)

  

通过base64解密得到的字符串

得到：ssh-bruteforce-sudoit

注:ssh暴力破解root权限？

![](../Images/9cd2270af53be0b36fc89fdacd128488.png)

  

通过web目录暴力破解工具（gobuster），爆破存在的网页

gobuster dir -w /usr/share/wordlists/dirbuster/directory-list-1.0.txt -x html -u http://192.168.72.128

得到三个网页：index.html、ftc.html、sudo.html

参数解析：

    -w指定字典

    -x要查找的扩展名

    -u指定URL

    -t指定线程数（默认10）

![](../Images/bf689087e0dc42aff194bed117dfbb1b.png)

  

访问sudo.html得到下一个提示，

uname:test

![](../Images/47c901cec6f411d39e9ed1891d5cb5fa.png)

  

根据得到的用户名和之前的提示，对ssh进行暴力破解

使用工具：hydra

参数解析：

    -l 指定用户名

    -P 指定密码字典

    -s 指定非默认端口

    -f 破解到正确密码就停止

    -t 指定同时运行的线程数量

指令：

hydra -l test -P /usr/share/wordlists/rockyou.txt.gz ssh://192.168.72.128 -s 7223 -f -t 64

得到ssh的账号密码：test/jordan23

备注：因为前面进行端口探测时发现，ssh的默认端口22没有开放，所以猜测是未知  的7223端口进行爆破。

![](../Images/86234d47ea9f9bc13c668d57bdc862f7.png)

  

通过得到的ssh账号密码，登录靶机

![](../Images/12b187da614585944b37b0ac7b0b99d8.png)

  

切换到root用户，查看输入历史，得知切到root的方法

![](../Images/1710f57bc93b865f1a2b41016d3b3446.png)

  

通过指令：sudo -u#-1 /bin/bash 切换root成功！

![](../Images/6632860bd2b2ce02124633da4a9aa77f.png)
