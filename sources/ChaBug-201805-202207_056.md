*   前言
    

**因为学习当中需要用到低版本的Jdk，我下载了一个jdk7u67版本，当时兴致勃勃的双击下去之后，却遭遇到这样的一个错误**

![](../Images/7cab87407ce3dc0a314713f63416517b.png)

![](../Images/49671cbbb01048bd79272b82291441e0.png)

*   解决方法
    

**安装包pkg解压以后修改里面的判断版本的代码，然后在打包安装就可以了。**

## 操作步骤

*   将安装包JDK 7 Update 67.pkg解压成unpkg包
    

```
╰─➤  pkgutil --expand JDK\\ 7\\ Update\\ 67.pkg /tmp/jdk.unpkg
```

  

![](../Images/01725c12274a2d32b027defd38ae3b16.png)

  

*   进入jdk.unpkg，里面有个Distribution的文件，输入vim Distribution编辑此文件
    

![](../Images/a12b301e054b3cb77662fb00ec687895.png)

*   编辑文件，修改验证逻辑
    

![](../Images/0387e6ae3c05894c00d3ff31e879df0e.png)

```
function pm\_install\_check() {
  return true;
}
```

  

*   修改完如图
    

![](../Images/8579d7bbb9e55c6120eddab6ef862c01.png)

  

*   再次打包成pkg
    

```
pkgutil --flatten /tmp/jdk.unpkg /tmp/jdk.pkg
```

![](../Images/6002131a4a199818e5495b593e10b531.png)

*   安装低版本Jdk
