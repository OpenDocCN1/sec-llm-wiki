
# 查杀方式三：COPAGENT

由于VisualVM在环境中可能还需要配置JVM Connection远程调试，我在长亭一篇文章中发现了LandGrey师傅所写的内存马检测工具，经过在本地Tomcat测试，可以检测到我自己设置的内存马，而无需重启Tomcat服务（重启了内存马不就没了吗?）先贴上Git地址

```


```
https://github.com/LandGrey/copagent
```


```

我本地运行Tomcat服务，使用cop.jar工具，工具首先会识别你正在运行的应用列举出来由你自己选择ID，运行后会在.copagent目录生成结果

![](../Images/7d5c64386172e6dcc1ecdbd3913729ac.png)

在输出结果中，可以查看异常类，例如我的`1.jsp`和`X.AES_BASE64`，他会显示所有运行的类以及危险等级，比较高的可以进入目录查看代码进行分析

![](../Images/4fda7e3f4a01799f2c1382535f0b0b2b.png)

![](../Images/7413ad802898b0f197599f682b588d53.png)

在java或class文件夹会保存木马以及运行的类

![](../Images/5a2e1d195200bee5bf6b6ac99ce20f07.png)

![](../Images/0fca30495c558fe442adee037dc63dc9.png)
