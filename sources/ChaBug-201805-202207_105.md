## 分析

  

![](../Images/6486766dee7e1f0fad7c97215886de41.png)

在logincheck\_code.php中UID可控，当UID为1时，用户默认为admin管理员。![](../Images/d488dbd2dc5d08f98f02cda0334c250d.png)

在其后180行左右将信息保存到SESSION中。那么只要绕过了18行的exit()就可以了。

```
$CODEUID = $_POST["CODEUID"];$login_codeuid = TD::get_cache("CODE_LOGIN" . $CODEUID);if (!isset($login_codeuid) || empty($login_codeuid)) {    $databack = array("status" => 0, "msg" => _("参数错误！"), "url" => "general/index.php?isIE=0");    echo json_encode(td_iconv($databack, MYOA_CHARSET, "utf-8"));    exit();}
```

  

login\_codeuid 从redis缓存中`TD::get_cache()`获取`"CODE_LOGIN" . $CODEUID`，搜索下可不可控

include_once "inc/utility_all.php";include_once "inc/utility_cache.php";include_once "inc/phpqrcode.php";$codeuid = $_GET["codeuid"];$login_codeuid = TD::get_cache("CODE_LOGIN" . $codeuid);$tempArr = array();$login_codeuid = (preg_match_all("/[^a-zA-Z0-9-{}\/]+/", $login_codeuid, $tempArr) ? 当`$login_codeuid`为空时会`getUniqid()`生成一个存入redis缓存并且在最后echo出来。所以我们可以通过直接get请求`general\login_code.php`拿到`CODEUID`

使用之前的CODEUID即可绕过if条件的exit()。
