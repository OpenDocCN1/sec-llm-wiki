## 前言

什么是哥斯拉工具？

  

![](../Images/a2ae11f7d77613d29f7c0957b475f6a3.png)

哥斯拉是下一代webshell管理工具。  
学会编写哥斯拉插件，你不仅可以绕过waf，还可以编写更多的功能，甚至哥斯拉的服务端可以脱离webshell，在数据库中运行，如SqlServer的CLR。

首先简单阅读哥斯拉插件Api：

https://beichendream.github.io/godzillaApi/

接下来我们将简单的学习一下怎么搭建环境，并编写插件。在后续的文章中我们会编写带有实际功能的插件，本文我们只是简单了解一下。

  

### 新建一个哥斯拉插件项目 

首先打开IntelliJ IDEA，新建一个Java项目

![](../Images/bb7a1e818416f347d4408a51e9261388.png)

一直点Next

![](../Images/36f90bb01d6d77f2167bd069387fff61.png)

写一个项目名

![](../Images/1ffab9ebcd2a001b0b396fb96ebc6056.png)

新建好之后，点击项目配置

![](../Images/af9a710d46273824d4fef9f7ca4761bb.png)

点击加号

![](../Images/cb6aee60856ecb8aa0b52b3ed4f4557d.png)

![](../Images/146b977122640c2482d685ca09dc70ea.png)

选择哥斯拉Jar包的路径，并点击OK

![](../Images/519196b1e1741b5e2a39d42c1d6035c5.png)

选择依赖模式，编译

![](../Images/ba2a7c3e328812326e611cdc9ec0a2a5.png)

然后点击Apply应用即可

![](../Images/4e1d7a4834d38ae97671e89bc5d20b3d.png)

然后右击Src文件夹，选择新建一个包

![](../Images/cfa73efde320aa4209c58df176f3fb3f.png)

包名必须是以`shells.plugins.任意字符`为开头

包名的最后建议填入网络ID、作者名

![](../Images/524f79dbb78486470dcba99a3349e057.png)

我这里填`beichendream`

```
shells.plugins.你的网络Id
shells.plugins.beichendream

```
