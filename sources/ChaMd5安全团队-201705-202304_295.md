**EasyShell**

解题思路:

       格式化字符串，一次性修改五个地址。首先修改fini.array然后进行leave\_ret达到栈迁移的目的，这里会迁移到一个bss段上，然后在上面布置好read的rop，这里只需要控制rsi的为想写入的地址就可以了，其他的rdi和rdx的条件都有。输入之后再进行一次栈迁移，如果往第一次栈迁移的地方接着写入的化，会写到IO\_File上面去，这显然是不可以的。所以要把栈迁到另一个地方，刚好这里的rbp又是另一个bss段的地址。所以在read的那次rop的后面再写一个leave\_ret就可以了。然后在第二次的栈迁移的地方写入后续的rop调用mprotect，然后再写入shellcode就可以了。这个题我很迷的是，最后一步我最开始调用的不是mprotect,而是直接写的orw的rop，但是本地读出来了，远程就进入死循环了。本身题目就是静态编译，所以不存在什么libc的不匹配。

    }    var d uint64    d = 0x124BA92C4470357E    for _, k := range Bcontent {        d ^= k    }    // d = d ^ (d >> 16) ^ (d >> 32) ^ (d >> 48)    fmt.Printf("%x", d)}
