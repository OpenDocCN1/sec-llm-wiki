资格赛

自动化操作

  • 本部分比赛中为竞速比赛，因此我将获取下载链接，下载图片压缩包，准备图片，输入后提交secret这些步骤都写在了脚本中，以便节约人工操作时间。

  • 将所有可以提前完成的操作，均放在获取下载URL之前。

    • 初始化需要的所有numpy数组与Image

    • 载入原图采样数据

    • 显存同步

匹配过程

由于本题目中已知原图，切均为无损图片操作，所以我采用了抽取像素点匹配的方法。

  1. 将原图中按照 80 * 80 的区块读取相对位置的采样点 RGB 数据，存入 orig_image_table

  2. 下载并解压所有切片图片

  3. 读取切片图片存入 loaded_pieces_table，为最终拼图使用

  4. 对每个切片图片按相对位置抽取 10 个采样点，存入 compare_image_table

  5. (CUDA) 将每个切片图片 ID 作为一个 grid 下发到 do_compare 函数 （共下发 6400 个 grid）

  • threadsperblock 设置为 16*16 （可调整，不影响）

  • blockspergrid 设置为 math.ceil(80 / threadsperblock)

  • 完成通过以上设置之后 Kernel 函数中 cuda.grid(2) 获得的范围则成为 (0,0) 到 (79,79)，可以覆盖到所有切片。

  • (CUDA) do_compare 将对目前的切片图片采样与原图对应区块的采样比对，如果有3个点完全相同，就将图片ID存放到对应坐标的 result_table 中。

  • 将匹配完成的 result_table 复制回 Host 内存

  • 将切片放置到对应位置，并显示图片

    • 结果

    操作用时（秒）
    载入数据2
    图片匹配计算2
    在图中寻找正确的 secret+∞
    最终耗时43

    挑战赛

    匹配过程

    不要小看 GPU 啊！kora！

    在写完资格赛的代码之后，我发现小瞧了 GPU 的并行计算能力，于是在挑战赛简化了匹配方式，直接对全像素进行暴力匹配，以获得最好结果。

    1. 将所有图片读取到内存中，并复制到显存 （原图与25600个切片）

    2. 逐像素比对每个切片图片与原图中每个对齐位置，记录下相同（坐标，颜色）的点个数

    3. 找出原图中每个对齐位置上最大相同（坐标，颜色）点数量对应的切片图片编号

    4. 将切片放置到对应位置，并显示图片

    操作用时（秒）
    载入数据7
    图片匹配计算15
    最终耗时23
