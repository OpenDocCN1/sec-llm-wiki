# Vemon AID Puzzle

> By Henryzhao  
> 2019-12-26

本题目属于单任务计算逻辑简单，但数量巨大。同时通过恰当的任务分解，可以让每个任务的执行结果之间互不影响。因此在该题目中选择了 GPU CUDA 并行计算的方式进行解题。

## 关于 CUDA

https://docs.nvidia.com/cuda/cuda-c-programming-guide

我对于 CUDA 计算也是新手中的新手，本文中必然存在错误和可以优化的地方，欢迎各位巨佬指正！

建议没有了解过CUDA计算的巨佬们先阅读 https://www.jianshu.com/p/34a504af8d51 中的 `3. 编程模型` 以及 `3.1 线程层次结构` 部分。

下图是 Thread，Block 与 Grid 之间的关系。

在编写程序中，使用了 python numba 中的 cuda 组件（这样就不用写C了哈哈哈哈哈！）

## 资格赛

### 自动化操作

*   本部分比赛中为竞速比赛，因此我将获取下载链接，下载图片压缩包，准备图片，输入后提交secret这些步骤都写在了脚本中，以便节约人工操作时间。
    
*   将所有可以提前完成的操作，均放在获取下载URL之前。
    

*   初始化需要的所有numpy数组与Image
    
*   载入原图采样数据
    
*   显存同步
    

### 匹配过程

由于本题目中已知原图，切均为无损图片操作，所以我采用了抽取像素点匹配的方法。

1.  将原图中按照 80 \* 80 的区块读取相对位置的采样点 RGB 数据，存入 orig\_image\_table
    
2.  下载并解压所有切片图片
    
3.  读取切片图片存入 loaded\_pieces\_table，为最终拼图使用
    
4.  对每个切片图片按相对位置抽取 10 个采样点，存入 compare\_image\_table
    
5.  (CUDA) 将每个切片图片 ID 作为一个 grid 下发到 do\_compare 函数 （共下发 6400 个 grid）
    

*   threadsperblock 设置为 16\*16 （可调整，不影响）
    
*   blockspergrid 设置为 math.ceil(80 / threadsperblock)
    
*   完成通过以上设置之后 Kernel 函数中 cuda.grid(2) 获得的范围则成为 (0,0) 到 (79,79)，可以覆盖到所有切片。
    

*   (CUDA) do\_compare 将对目前的切片图片采样与原图对应区块的采样比对，如果有3个点完全相同，就将图片ID存放到对应坐标的 result\_table 中。
    
*   将匹配完成的 result\_table 复制回 Host 内存
    
*   将切片放置到对应位置，并显示图片

## 挑战赛

### 匹配过程

> 不要小看 GPU 啊！kora！

在写完资格赛的代码之后，我发现小瞧了 GPU 的并行计算能力，于是在挑战赛简化了匹配方式，直接对全像素进行暴力匹配，以获得最好结果。

1.  将所有图片读取到内存中，并复制到显存 （原图与25600个切片）
    
2.  逐像素比对每个切片图片与原图中每个对齐位置，记录下相同（坐标，颜色）的点个数
    
3.  找出原图中每个对齐位置上最大相同（坐标，颜色）点数量对应的切片图片编号
    
4.  将切片放置到对应位置，并显示图片

| --- | --- |
