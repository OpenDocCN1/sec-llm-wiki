babyRSA

解题思路
已知e，d，恢复n，其中n=pq，且p，q是相邻质数 首先ed = kφ(n) +1，然后用它的的脚本试几组数据不难测出 (ed-1)/φ(n) 是个五位数 于是 遍历所有可能，有224种 然后测试中发现一个神奇关系：phi = (p-1)(q-1)
p,q相近，则设p1=p=q
则p1 gmpy2.= iroot(phi,2)[0]+1
意外发现 (p1-p)*2 + 2 == q - p
所以p1 = (p+q)/2
那么q=nextPrime(p1)
然后遍历224种可能，解密，找结果包含’CTF‘的字符串

解题思路
其实是现学现卖https://www.codercto.com/a/35743.html
（全程手撸23333）
第零关：用他给的脚本
第一关：已知a,b,n,s0（图中的next）

即求裴蜀数
用欧拓求出s，然后seed = s*(next-b)%n
第二关：已知a,n,s0,s1

因为：s1 = s0a + c (mod n) 所以：b = s1 - s0a (mod n)
然后就是第一关内容了

第三关：已知n,s0,s1,s2
s1 = s0a + b (mod n) s2 = s1a + b (mod n)

s2 - s1 = s1m - s0m (mod n)
s2 - s1 = m(s1 - s0) (mod n) a = (s2 - s1)(s1 - s0)^-1 (mod n) (这里的-1次是模逆)
然后就是第二关的内容了

第四关：已知s0,s1,s2,s3,s4,s5
根据前面三关，显然我们只需要用着六个数求出n就行了
数论里面有一条很有用:如果有几个随机数分别乘以n，那么这几个数的欧几里德算法(gcd)就很可能等于n。
我们只需要取几个这样的值（X != 0但是X = 0 (mod n)）进行gcd运算，我们就可以解出n的值。这种是在模数未知的情况下十分常用的方法。
我们在此引入一个序列 – T(n) = S(n+1) - S(n):
t0 = s1 - s0
t1 = s2 - s1 = (s1a + b) - (s0a + b) = a(s1 - s0) = at0 (mod n)
t2 = s3 - s2 = (s2a + b - (s1a + b) = a(s2 - s1) = at1 (mod n)
t3 = s4 - s3 = (s3a + b) - (s2a + b) = a(s3 - s2) = at2 (mod n)
然后就有
t2t0 - t1t1 = (aat0 * t0) - (a*t0 * a*t0) = 0 (mod n)
然后我们就可以生成几个这样模是0的值
