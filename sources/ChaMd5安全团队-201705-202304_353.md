#### LCG

解题思路  
其实是现学现卖https://www.codercto.com/a/35743.html  
（全程手撸23333）  
第零关：用他给的脚本  
第一关：已知a,b,n,s0（图中的next）  

![](../Images/8e9b8d189704465e196229c828d99a8a.png)

即求裴蜀数  
用欧拓求出s，然后seed = s\*(next-b)%n  
第二关：已知a,n,s0,s1  

因为：s1 = s0*a + c (mod n) 所以：**b = s1 - s0*a (mod n)  
然后就是第一关内容了

第三关：已知n,s0,s1,s2  
s1 = s0*a + b (mod n) s2 = s1*a + b (mod n)

s2 - s1 = s1*m - s0*m (mod n)  
s2 - s1 = m(s1 - s0) (mod n) a = (s2 - s1)(s1 - s0)^-1 (mod n) (这里的-1次是模逆)  
然后就是第二关的内容了

第四关：已知s0,s1,s2,s3,s4,s5  
根据前面三关，显然我们只需要用着六个数求出n就行了  
数论里面有一条很有用:如果有几个随机数分别乘以n，那么这几个数的欧几里德算法(gcd)就很可能等于n。  
我们只需要取几个这样的值（X != 0但是X = 0 (mod n)）进行gcd运算，我们就可以解出n的值。这种是在模数未知的情况下十分常用的方法。  
我们在此引入一个序列 – T(n) = S(n+1) - S(n):  
t0 = s1 - s0  
t1 = s2 - s1 = (s1*a + b) - (s0*a + b) = a*(s1 - s0) = a*t0 (mod n)  
t2 = s3 - s2 = (s2*a + b - (s1*a + b) = a*(s2 - s1) = a*t1 (mod n)  
t3 = s4 - s3 = (s3*a + b) - (s2*a + b) = a*(s3 - s2) = a*t2 (mod n)  
然后就有  
t2*t0 - t1*t1 = (a*a*t0 \* t0) - (a\*t0 \* a\*t0) = 0 (mod n)  
然后我们就可以生成几个这样模是0的值
