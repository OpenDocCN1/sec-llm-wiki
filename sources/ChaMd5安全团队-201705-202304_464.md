### 0x00 介绍

MHN（Modern Honey Network），是一个用于管理和收集蜜罐数据的中心服务器。通过MHN，可以实现快速部署多种类型的蜜罐并且通过web可视化界面显示蜜罐收集的数据，目前支持的蜜罐类型有捕蝇草(Dionaea), Snort, Cowrie, glastopf等。据官方说法，目前经测试支持部署MHN服务器的系统有Ubuntu 14.04, Ubuntu 16.04, Centos 6.9，我部署的服务器版本是**Centos6.8**。

### 0x01 搭建

```
1.  `# on Centos or RHEL`
    
2.  `yum install -y git`
    
3.  `cd /opt/`
    
4.  `git clone https://github.com/threatstream/mhn.git`
    
5.  `cd mhn/`
    
6.  `./install.sh`
    
```

### 0x02 搭建中遇到的一些问题

由于install.sh安装脚本中需要安装Python2.7，如果原服务器使用Python2.6或者其他版本，会导致yum冲突，出现"no mudule named yum"错误：

```
1.  `vim /etc/yum`
    
2.  ` #/usr/bin/python`
    
3.  ` #/usr/bin/python2.6 #改为服务器原本使用的版本`
    
```

安装过程出现".ini file does not include supervisorctl section"错误：

```
1.  `vim install_elk.sh[install_supervisord.sh/install_hpfeeds.sh/install_mnemosyne.sh/install_honeymap.sh/install_mhnserver.sh/install_hpfeeds-logger-splunk.sh]`
    
2.  ` cd /etc/supervisor #新增`
    
3.  ` supervisorctl update`
    
4.  
    
5.  `echo_supervisord_conf > /etc/supervisor/supervisord.conf`
    
6.  `vim /etc/supervisor/supervisord.conf`
    
7.  ` [include]`
    
8.  ` files = /etc/supervisor/conf.d/*.ini /etc/supervisor/conf.d/*.conf`
    
```

出现"bind() to 0.0.0.0:80 failed address already in use"错误（由于服务器自身使用了apache占用80端口）：

```
1.  `ps -ax|grep httpd|cut -d ' ' -f2|xargs kill -9`
    
2.  `service nginx start`
    
```

执行"supervisorctl status"出现下列错误：

*   "honeymap FATAL can't find command '/opt/honeymap/server/server'"
    

```
1.  `git clone https://github.com/golang/net.git net`
    
2.  `mkdir /usr/local/go/src/golang.org`
    
3.  `mkdir /usr/local/go/src/golang.org/x`
    
4.  `mv net/ /usr/local/go/src/golang.org/x`
    
5.  `go build`
    
6.  `cd /etc/supervisor`
    
7.  `supervisorctl restart all`
    
```

*   出现"mhn-celery-worker FATAL Exited too quickly (process log may have details)﻿"错误
    

```
1.  `tail -f /var/log/mhn/mhn-celery-worker.err`
    
2.  ` supervisor: couldn't chdir to /root/mhn/server: EACCES`
    
3.  ` supervisor: child process was not spawned`
    
4.  `chmod 777 -R /root`
    
```

### 0x03 配置修改

```
1.  `vim /opt/mhn/server/config.py`
    
2.  ` SUPERUSER_EMAIL = 'sherlly666@qq.com' #用于登录MHN管理界面的用户名`
    
3.  ` SUPERUSER_PASSWORD = 'this_is_test' #用于登录MHN管理界面的密码`
    
4.  ` SERVER_BASE_URL = 'http://www.example.com' #部署MHN服务器的地址`
    
5.  ` HONEYMAP_URL = 'http://www.example.com:3000' #蜜罐攻击地图地址，默认3000端口`
    
6.  ` DEPLOY_KEY = 'QCIxjGiq' #随机生成`
    
7.  ` LOG_FILE_PATH = '/var/log/mhn/mhn.log' #log位置`
    
8.  `cd /etc/supervisor`
    
9.  `superbisorctl restart mhn-uwsgi`
    
```

### 0x05 树莓派蜜罐部署

  

*   SD卡格式化：使用SDFormatter工具->选项设置->逻辑大小调整（ON）
    
*   下载镜像：https://downloads.raspberrypi.org/raspbian/images/raspbian-2017-12-01/2017-11-29-raspbian-stretch.zip.torrent（https://www.raspberrypi.org/downloads/）
    
*   烧写镜像到SD卡：使用win32diskimager工具；
    
*   SD卡boot目录下新建ssh文件夹，开启ssh功能；
    
*   笔记本电脑无线网络设置：
    

![](../Images/edef622d148863e167dc6d86703fc5c5.png)

*   树莓派连接网线到电脑，通过arp -a确定树莓派ip地址为192.168.137.51：
    

![](../Images/d5e9dcfe16d31cc2bbe5e0e21c129fe0.png)

  

*   使用ssh工具（MobaXterm）连接：
    

```
1.  `用户：pi`
    
2.  `密码：raspberry`
    
3.  `端口：22`
    
```

![](../Images/cc517b4119af51e7c51dd8129e873713.png)

  

*   切换用户为root，允许root用户登录：
    

```
1.  `sudo passwd root`
    
2.  `sudo passwd --unlock root`
    
3.  `su root`
    
4.  `vi /etc/ssh/sshd_config`
    
5.  ` PermitRootLogin yes`
    
6.  `reboot`
    
```

*   静态ip设置：
    

```
1.  `vim /etc/dhcpcd.conf`
    
2.  ` interface eth0`
    
3.  ` static ip_address=192.168.137.152/24`
    
4.  ` static routers=192.168.137.1`
    
5.  ` static domain_name_servers=8.8.8.8`
    
6.  `reboot`
    
```

*   更换国内源：
    

```
1.  `vi /etc/apt/sources.list`
    
2.  ` deb http://mirrors.tuna.tsinghua.edu.cn/raspbian/raspbian/ stretch main contrib non-free rpi`
    
3.  ` deb-src http://mirrors.tuna.tsinghua.edu.cn/raspbian/raspbian/ stretch main contrib non-free rpi`
    
4.  `vi /etc/apt/sources.list.d/raspi.list`
    
5.  ` deb http://mirror.tuna.tsinghua.edu.cn/raspberrypi/ stretch main ui`
    
6.  ` deb-src http://mirror.tuna.tsinghua.edu.cn/raspberrypi/ stretch main ui`
    
```

*   远程桌面连接：
    

```
1.  `apt-get update`
    
2.  `apt-get upgrade`
    
3.  `apt-get install xrdp`
    
4.  `/etc/init.d/xrdp start`
    
5.  `update-rc.d xrdp defaults #开机自启`
    
```

*   时区设置：
    

```
1.  `dpkg-reconfigure tzdata`
    
2.  ` Asia/Hong Kong`
    
```

*   部署Dionaea蜜罐：
    

```
1.  `wget "http://xxxx/api/script/?text=true&script_id=3" -O deploy.sh && sudo bash deploy.sh http://xxxx YYYYYY`
    
```
