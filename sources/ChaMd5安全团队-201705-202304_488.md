# NSCTF “表情包” 详细writeup

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMTc1MjExOQ==&mid=2247484243&idx=1&sn=f673c5e2f0b6ce6a897ef38ab0d3a873&chksm=e89e2b8bdfe9a29d43a32fee4dc11425d52ee75649e3e058aca51bbff4eead138e01d82b673f&scene=126&sessionid=1681403624#rd](http://mp.weixin.qq.com/s?__biz=MzIzMTc1MjExOQ==&mid=2247484243&idx=1&sn=f673c5e2f0b6ce6a897ef38ab0d3a873&chksm=e89e2b8bdfe9a29d43a32fee4dc11425d52ee75649e3e058aca51bbff4eead138e01d82b673f&scene=126&sessionid=1681403624#rd)

偶尔打了一下NSCTF，其中大家比较蒙蔽的有一题，叫“表情包”，是常见的颜文字。

![](../Images/28fc9c4207a44ffce7c05bfbd108fdaa.png)

这种叫aaencode（可以把任意js编码成颜文字表情），然后在这里全选复制到浏览器的控制台里，运行就报错。

这不太科学，回想以前也是做过这样的题，南邮的网络攻防训练平台上(http://ctf.nuptsast.com/)也有一道aaencode的题目

![](../Images/afe10ec063db8490bc1342ec496ca778.png)

进去后，全选复制到控制台，也是报错，不过我想不至于都做不了吧，于是还是静下心来分析分析下，这里我推荐使用chrome浏览器，分析这些比较方便

![](../Images/6687894117b07788d41031a5d5d3cdcf.png)

发现是缺了一个定义，既然这样的话，我先找到一个正确的（也就是能还原的）aaencode编码，再对两者进行对比，看看缺少什么

找到一个网站http://utf-8.jp/public/aaencode.html对比下

![](../Images/559a367868d395edc1cc4941bc011a47.png)

发现南邮的一个表情少了一个字符，自己添加后，在控制台能正常输出。这一点增强了我做题的信心。

再对比下NSCTF的题目

![](../Images/32f98d3c5b4c915702531be3d65e93e7.png)

发现NSCTF的少了很多，

![](../Images/d65ac825316a1e6a298d59392dcce0b6.png)

查找元素，然后对着<p>右键Edit as HTML，然后看到了一些<em> </em>之类的，把整个<p>复制出来

![](../Images/a76e6c116acec9167876d26fa9f2bc53.png)

这里给出处理方法

1.  把<p> </p>去掉
    
2.  把//<em>´∇｀</em>/改为//\*´∇｀\*/
    
3.  把<em>改为\_
    
4.  把</em>改为\_
    
5.  把'\\'改为'\\\\'
    

最后在chrome（在火狐你就很难看到效果）里运行

![](../Images/1a7bb4f12fc8784c0a45feeb2f60373f.png)

运行后，虽然报错了，但是你还是可以点击那个VM

![](../Images/2cb4147a902e64a265b821c642c3e38f.png)

至此，就得到flag了。
