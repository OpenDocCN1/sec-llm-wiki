# 点进来，儿童节的礼物

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMTc1MjExOQ==&mid=2247484120&idx=1&sn=010e6287098b959fe320b498488bfd0d&chksm=e89e2a00dfe9a3168b68e061d9ce53af6e81854df58d193d719887e649268e60270b52e0218f&scene=126&sessionid=1681403631#rd](http://mp.weixin.qq.com/s?__biz=MzIzMTc1MjExOQ==&mid=2247484120&idx=1&sn=010e6287098b959fe320b498488bfd0d&chksm=e89e2a00dfe9a3168b68e061d9ce53af6e81854df58d193d719887e649268e60270b52e0218f&scene=126&sessionid=1681403631#rd)

         2017年6月1日，中国的第一部《网络安全法》正式实施了。该法律从各个方面规定了网络安全标准，是祖国献给每个公民的一份大礼。让我们一起来拆礼物吧！

    小编对《网络安全法》的理解主要有以下几点：

1.  加强了对公民个人信息的保护：想想这些年层出不穷的数据泄露事件，说不定你的身份证、家庭信息就存在哪个社工库呢。从现在开始，那些玩社工库的都小心点吧，只需要50条你就能体验到公安牌查水表了。
    
2.  加强了对未成年人的保护：以后国家会在这方面加大努力，我们的孩子不会再轻易地被那些乱七八糟的内容影响了（ps:若是因为孩子的技术太高超，而拦不住的锅国家不背）。
    
3.  加强了网络安全实名制，以后对于非实名用户，服务商们可以拒绝提供服务。
    
4.  商家必须提供安全的服务：都要求实名制了，商家的安全还能不提高？以前我们在某云上见过很多漏洞，商家们要么忽略要么不接。现在开始，各位老板们注意啦，再敢如此，有关部门就要请你去喝茶了。
