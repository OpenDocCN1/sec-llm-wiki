## flag被盗

打开题目，发现文件是一个数据包，下载数据包 ![](../Images/c693e62637e647aefe753b7f54aa10e2.png)

直接在这条数据包上右键追踪TCP流 ![](../Images/60c0e9a5159be2ed88ab491fc6b164da.png)

发现flag ![](../Images/d73966c6a317d7d6c7fcf40c0a73566d.png)

## 中国菜刀

下载压缩包，解压![](../Images/caaf4f81e98c854d00afe8e09aaafb49.png)

打开数据包，发现第五条数据包有个post请求，在上面追踪TCP流，发现一串base64编码![](../Images/68a866225d0a4b50f9ab27e16b7d5adc.png)

复制，用在线编码解码，得到一段代码如下,它的作用是读取c:/wwwroot目录下所有文件、目录的名字、大小、权限、以及最后一次的修改时间

```























php
```

继续向下分析，在下一个数据包里面发现了一个flag.tar.gz文件![](../Images/95e60f91c8341911c3ab51a59ae57628.png)

继续向下分析，又发现一个post请求，追踪TCP流，将其中的base64解码一下，代码如下，可以看到，它是用来读取3.php的内容的

```











php
```

在下个数据包中看到3.php是一句话木马，![](../Images/8883862a85d23d3b638f57ffeb608d9a.png)

继续分析将下一个数据包中的base64解码，发现是读取flag.tar,gz文件内容的 ，那么下一个数据包可能就能得到flag了![](../Images/6007648c51ac5af651d0a357a1dfb4f6.png)

由于flag.tar,gz是个压缩包，所以我们需要将字节流用压缩包格式查看，找到下一个数据包，在最下方右键显示分组字节流![](../Images/0c55b986bd45daa12fad9bb4907d9126.png)

将其解码为压缩包，由于要使X@Y不可见，所以设置开始为3，解码后即出现flag![](../Images/531f6d54621cea4dbeecb9bb83973c1a.png)

![](../Images/9dc38b573ef59c0cbb84a6b1902856f4.png)
