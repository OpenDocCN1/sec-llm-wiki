## 3.安装pip

pip 是“A tool for installing and managing Python packages.”，

也就是说pip是python的软件安装工具

```


安装：  sudo apt install python-pip
```

## 4.更改pip源

我们在进行Python开发时，经常会通过pip操作来安装一些packages，

但是由于网络速度非常慢，安装耗时长，所以我们需要把pip的源设置成国内的。

```


sudo mkdir ~/.pip/
```
