查看源码

index.php中要传入file,payload两个参数，对file参数进行过滤后include了$file指向的文件，再对payload检测后进行payload的反序列化。

hint.php中定义了两个类。Handle类中有一个私有变量 $handle 需要注意，同时在该类中调用了getflag()方法。Flag类getflag()方法中$token_flag被赋值为一个md5加密的随机数，与$token比较，强相等则读文件。

思路大体就是：构造序列化字符串，通过index.php的判断后反序列化读取文件内容。

构造序列化字符串需要注意的

php反序列化操作中函数参数存在用户可控部分时可能导致不可预测的问题，而这些问题大多数与魔术方法有关。

魔法函数

    __wakeup() 对象被反序列化时调用，用于执行一系列初始化操作
    __sleep() 对象被序列化时调用，用于清理对象
    __construct() 创建新对象时调用（反序列化时并不算创建新对象）
    __destruct() 对象被销毁时调用
    __toString() 定义一个类被当作String类型时的操作

这里我们看到使用了 _wakeup()，通过CVE-2016-7124 这个漏洞我们可以知道：当序列化字符串中表示对象个数大于真实的属性个数时会跳过_wakeup的执行。

php中变量引用

代码中需要进行强相等判断

if($this->token === $this->token_flag)

在上面我们看到

$this->token_flag = $this->token = md5(rand(1.1,10000));

想到可以通过变量引用来使两个变量值相等。

php允许两个变量指向同一个内容

<?php
$a="ABC";
$b =&$a;
echo $a;//这里输出:ABC
echo $b;//这里输出:ABC
$b="EFG";
echo $a;//这里$a的值变为EFG 所以输出EFG echo $b;//这里输出EFG
?>

对象的引用

<?php
class a{
var $abc="ABC";
}
$b=new a;
$c=$b;
echo $b->abc;//这里输出ABC
echo $c->abc;//这里输出ABC
$b->abc="DEF";
echo $c->abc;//这里输出DEF
?>

在php5中对象的复制是通过引用来实现的，也就是说

$b=new a;
$c=$b;
等效与
$b=new a;
$c=&$b;

知道这个我们就可以明白通过引用操作可以绕过强相等判断！

这里要注意Handle是私有变量

根据php官方文档：对象的私有成员具有加入成员的类名称，有保护的成员在成员名前加上'*'，加上的前缀在两侧都有空字节。

绕过parse_url()检测

在index.php中对payload进行了parse_url()操作

parse_url函数解析URL并返回一个关联数组，包含被解析URL中出现的组成部分。需要注意的是该函数不检测URL的合法性，只是将其分解，并且进行尽可能正确的解析。

<?php
$x = parse_url("http://localhost/index.php?name=tank&sex=1#top");
print_r($x);
$a = parse_url("http://www.baidu.com");
print_r($a);
$b = parse_url("123://baidu.www...cn");
print_r($b);
$c = parse_url("http:///www.baidu.com");
print_r($c);
?>
