在获取到shell后，一般情况下都不具有管理员权限，不能执行创建或者修改文件的命令，这时候就要用到提权了。

### 定时任务提权

在linux系统中，会以system权限执行定时任务。所以在获得shell后，可以利用定时任务以system权限执行某些命令。Crontab是LINUX和UNIX操作系统中的命令，用于设置周期性执行的指令。该命令可以读取标准输入设备中的指令，并将其存放在“crontab”文件中。通过设置crontab命令，可以在间隔固定时间，执行指定的系统指令或执行脚本。![](../Images/44842e42d242de87a0382aba15697669.png)

1.检查是否安装有crontab，使用命令crontab –l ，如果没有回显或显 示为 no crontab for *\**,即为安装有crontab；

![](../Images/1e8a0a8f33a3a85512664d067aa7b28d.png)

2.通过cat /etc/crontab命令查看crontab文件，可以看到crontab中有几条定时执行的命令和脚本，且为root权限；![](../Images/44842e42d242de87a0382aba15697669.png)

![](../Images/9411539dc586fe42adfe9232a548c9c3.png)

3.可以看到/tmp目录下有个shell.py脚本文件，每两分钟更新一次，可以通过修改该文件，使其执行需要的命令，如新建用户，通过新创建的用户登录即可实现提权。

### sudo提权

最常见的提权方式，sudo 是Linux下允许普通用户使用超级用户权限的工具，其配置文件为 /etc/sudoers。在该配置文件中可以定义执行sudo命令的账户、作为超级用户能够访问的应用程序、是否需要密码验证等。

用户使用su命令，输入密码即可将普通用户权限提升至root权限。

![](../Images/db87a0226dbd177bdc690f4b186dc8df.png)

输入sudo命令可显示命令帮助

![](../Images/3fda7a3e377abf555436f72aa79268ff.png)

### setuid 提权

黑客留后门的常用方法。  
set user id(setuid) 在Linux内核中允许一个进程以调用setuid程序的方式来改变自身的有效用户 ID，被设置了setuid 权限位的程序允许其他用户以该文件属主的身份来运行。该权限位常用于设置所有者为root的相关程序，让普通用户可以以root用户身份运行原本只有 root 权限才能运行的程序或命令。
