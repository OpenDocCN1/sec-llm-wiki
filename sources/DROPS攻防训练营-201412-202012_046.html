Brute Force 暴力破解

暴破学名：穷举法、枚举法。常用在密码的破解、网站路径搜寻等情况下使用。在网站路径搜寻方面，网站基本都没有限制，所以才有一大堆的扫后台扫目录的小工具；在防范登录密码暴力登陆方面，现在网站都做的很严谨，但是总有一些旧网站和马虎的程序员留给我们暴力破解的机会。

密码来源：1、常用弱口令，例如Top100、Top500 2、借助脚本生成小字典。 3、借助第三方网站（例如：caimima.net)，结合对方实际情况分析得到字典。

1、low级别：
先从最低等的学习吧。很熟悉又很友好的登陆界面，看到username和password框就感觉和常用网站登陆相比少了点什么，少了验证码！ 对，没有验证码是造成可暴力破解登陆的一个大洞，而且现在的有的网站中还是没有加入对暴破登陆的控制，所以看到不用输入验证码的网站直接傻瓜式的burpsuite跑一下说不定还是有收获的。
点开view_source查看一下代码：

代码中进行数据库sql查询前只对password进行了md5加密，没有对username进行过滤和检查，也没有加入任何验证和会话机制，于是产生了两个大大的洞——sql注入+暴破
万能密码：admin' and 1=1 # 密码位置任意 可成功登陆。
暴力破解：用burpsuite傻瓜式破解就可以了，果断设置127.0.0.1代理ip设置8080代理端口，直接proxy抓住包右键发送到intruder，positions设置暴破位置，payloads加载字典，开始start attack攻击，比较返回length从而判断哪个是正确账号密码。

抓包看提交的内容：?username=admin&password=123&Login=Login&user_token=71160ab704ab5b497373e99f1f8a8679
关闭重新打开浏览打开dvwa页面时候看源码会发现已经有这个user_token了，而且每次刷新它都会改变的，只要和服务器上的dvwa每次请求操作后都会在服务器重新生成重新发送给你的。当提交的user_token和服务器端的session_token不匹配时候，是不会继续往下执行代码的，这是个很不错的令牌机制，常用来防范burpsuite傻瓜式暴破和跨站请求伪造（csrf会在后面说）。

常用的除了token方法外，还有验证码验证的方法，对于比较简单的验证码机制（12306变态验证码除外）也同样可以用python的几行代码来搞定，具体方法参考：http://www.cnblogs.com/beer/p/5672678.html

Command Injection 命令行注入

这里说的命令是windows和linux下常用的操作命令。存在命令行注入的网站，恶意用户就能未经授权、随心所欲的执行操作系统命令。命令行注入能用的位置比较局限，需要web的应用程序调用系统命令作为参数的，才有机会插入自己的恶意命令。由于命令行中能用到的连接符号也就屈指可数的那么几个，放到shell中又不能进行编码，所以在防范措施上利用黑名单进行过滤，对输入内容进行严格的验证基本可以防范命令行注入的攻击。虽说防范方法很容易，但是还是需要了解如何利用的，说不定那天就碰上个这样的漏洞呢。

1、low级别：
题目让输入一个ip，果断127.0.0.1，然后返回了ping命令的信息。
看一下代码：

<?php 
if( isset( $_POST[ 'Submit' ]  ) ) { 
    // Get input 
    $target = $_REQUEST[ 'ip' ]; 
    // Determine OS and execute the ping command. 
    if( stristr( php_uname( 's' ), 'Windows NT' ) ) { 
        // Windows 
        $cmd = shell_exec( 'ping  ' . $target ); 
    } 
    else { 
        // *nix 
        $cmd = shell_exec( 'ping  -c 4 ' . $target ); 
    } 
    // Feedback for the end user 
    echo "<pre>{$cmd}</pre>"; 
} 
?>

可以看到，服务器通过判断操作系统调用shell_exec()来执行不同ping命令，但是对ip参数并未做任何的过滤，导致了严重的命令注入漏洞。
stristr函数搜索字符串在另一字符串中的第一次出现，返回字符串的剩余部分。php_uname('s')返回操作系统类型。

File Inclusion 任意文件包含

写程序时候去包含其他代码文件可以大大减少程序代码量，因为有包含所以才产生了文件包含漏洞。通过这个漏洞就想包啥包啥，想看啥看啥——只能看不能修改。包含文件的过程其实就是个文件代码执行的过程，所以结合文件上传漏洞上传带有恶意代码的文件，再去包含这个文件，就可以的达到很好的效果。
任意文件包含漏洞分类：本地文件包含和远程文件包含。涉及到的危险函数：include()、require()、include_once()、require_once()。 涉及到的php.ini设置：allow_url_fopen、allow_url_include。
四个危险函数区别：
require找不到被包含的文件时会产生致命错误，并停止脚本运行。
include找不到被包含的文件时只会产生警告，脚本将继续运行。
include_once与include类似，唯一区别是如果该文件中的代码已经被包含，则不会再次包含。
require_once与require类似，唯一区别是如果该文件中的代码已经被包含，则不会再次包含。

File Upload 文件上传

文件上传漏洞，通常是由于对上传文件的类型、内容没有进行严格的过滤、检查，使得攻击者可以通过上传木马获取服务器的webshell权限。所以对于网站的上传位置要格外小心。

1.low级别：
新建空的png和php文件，都可以上传，貌似没有限制上传的文档格式。
看源码：

$target_path  = DVWA_WEB_PAGE_TO_ROOT . "hackable/uploads/";
$target_path .= basename( $_FILES[ 'uploaded' ][ 'name' ] );
if( !move_uploaded_file( $_FILES[ 'uploaded' ][ 'tmp_name' ], $target_path ) )

$_FILES数组内容如下:

$_FILES['myFile']['name'] 客户端文件的原名称。
$_FILES['myFile']['type'] 文件的 MIME 类型，需要浏览器提供该信息的支持，例如"image/gif"。
$_FILES['myFile']['size'] 已上传文件的大小，单位为字节。
$_FILES['myFile']['tmp_name'] 文件被上传后在服务端储存的临时文件名，一般是系统默认。
$_FILES['myFile']['error'] 和该文件上传相关的错误代码。

basename() 函数返回路径中的文件名部分。
move_uploaded_file() 函数将上传的文件移动到新位置。
整个过程没有对文件类型进行检查，可随意上传，危险代码。

这个对文件类型进行了判断，上传png文件可上传，上传php文件上传不了。
