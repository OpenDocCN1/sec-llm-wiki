# 使用Fluxion搭建钓鱼热点破解WiFi密码

![](../Images/8ec6c1a791b2111071f730ead37f9274.png)使用Fluxion搭建钓鱼热点破解WiFi密码  
                          １．本次实验是基于kali2016.2版本环境  
２．安装Fluxion工具  
３．需要使用一个外接的无线网卡（某宝上有卖，买的时候注意要在kali下免驱，否则驱动的安装会很麻烦）![](../Images/11f5c9c0368c6b69cb949f4f8f3e0604.png "金属质感分割线")

首先下载fluxion

在终端内输入 git clone https://github.com/FluxionNetwork/fluxion.git  
其中可能会要求你输入github的账户和密码，注册输入就好啦  
其中如果出现无法定位软件包那你就换一个源试一下，我建议是换成阿里源，有时候是你虚拟机网络出了问题了，所以出问题后记得去ping 一下百度。

关于fluxion工具的换源网上有教程，这里就不赘述了，我们这里只涉及具体的操作。

打开终端，cd fluxion，进到fluxion目录下，然后ls 即列出所有文件  
![](../Images/00279b9d87ddd6bde0427435b0f61082.png)  
接着./fluxion.sh 运行这个文件  
![](../Images/68f2376c58e9f97be7765d552bc92a80.png)  
回车之后如图所示（运行./fluxion时，若出现提示错误时。就去安装相应的包）  
![](../Images/aeda2d64426f94fa4d97140c6bfc83de.png)  
有一些依赖没有安装的，fluxion未成功打开，fluxion也会提醒你安装，图片中红色的字体是需要安装的组件。  
安装好后，再重新运行./fluion就如下图所示  
![](../Images/1f092acac502e0b68b9bc39e24cc12e2.png)  
在这里我们选择Chinese中文，选中6，回车：  
![](../Images/ec833c13aa4278633eae91de94adb2fc.png)  
在这里我们选择指定信道：  
![](../Images/4fb4c406dee455bf894062a470dff99e.png)  
选择信道6,回车：  
![](../Images/637b54288d7096786e2b0bddc1a5e483.png)  
可以看到路由器的Mac地址和物理主机的Mac地址，然后选择好目标之后按Ctrl+C停止扫描，然后界面跳转如下：  
![](../Images/9f96297b554cdd56c1cb49d9786d7632.png)  
选择目标1（这里也只有这一个目标的说），回车：  
![](../Images/ced2642f63359ed16e58a864a016b855.png)  
接下来选择攻击选项，不用多想，按照推荐的来，选１回车：  
![](../Images/e88fa1439cab7bd1456a9306cc0250d3.png)  
之后这里会碰到一个选项叫你选择握手包的保存路径。你可以直接空格键跳过，这样握手包会保存在默认路径下。  
![](../Images/a583b7dea69a1a285a3291e12cd381b4.png)  
执行2操作，aircrack-ng开始抓取握手包。  
![](../Images/2659ae377d77d67c82f17a3bd87fc6cd.png)  
这里选择１，对所有用户发送deauth包攻击，接着会出现如下图所示的三个界面：  
![](../Images/5cea024bbcfca1cfdf13e78ec121fd39.png)  
待程序运行一段时间，一分钟即可，选中上图红色框界面，ctrl+c及时终止该进程，否则是该网络下的用户是无法上网的，而且我们也无法获得，我们接下来步骤需要用到的handshake包，之后我们会在右上角的终端，提示获得handshake握手包，如下图：  
![](../Images/9c1d2147768fc71112537cbda5cdf872.png)  
接着该窗口消失，主窗口跳转如下：  
![](../Images/03c8ec005f5f56e7d38faf70dda8926d.png)  
选择１创建一个ssl认证，回车：  
![](../Images/0620fd8831833058d0e56946ccca37e3.png)  
此时选择１，该选项即是我们实现钓鱼获取wifi密码的关键，回车如下：  
![](../Images/4d8516ae826604155c8c30b0651b40d9.png)  
这次，我们选择使用英语（因为汉语的话，我们试过会出现一些问题），然后就会弹出如下四个窗口：  
![](../Images/608b262872c72ca521331eef207e886e.png)  
并且建立虚假的AP，用户分配等操作，这时建立了一个虚假的AP，和真正的AP名字相同，但是没有密码，而且这个时候是没有办法连接到真实的AP的，所以用户会直接连接到我们做的虚假的AP上。  
![](../Images/2fc66d5275383296717e7d306a5db368.png)  
用户会在不知情的情况下连接到我们的wifi上，然后就会弹出如下界面：  
![](../Images/e78f19eb2689c8f0f0ed06d1a7c5b308.png)  
此时如果用户输入正确的密码，我们的四个进程会立刻结束，用户也会跳转到真正的wifi下，实现正常上网，而我们则会在刚才设置的路径下（我们选择的是默认路径）,生成一个包含wifi密码的.txt文件：  
![](../Images/c47d7331f6975abd378508e951897d6d.png)

到这里我们的操作就算完成了，呐，其间还是有些问题，比如我们的钓鱼界面的说服力就不是很大，未必在真实的环境下鱼会咬钩。    ![](../Images/96d3c4bc3dff72d3db48fd1ec868570b.png)
