**RSA算法简述**

```
1.  `① 选两个保密的大素数p和q。`
    
2.  `② 计算n=p×q，φ(n)=(p-1)(q-1),其中φ(n)是n的欧拉函数值。`
    
3.  `③ 选一整数e，满足1<e<φ(n)，且gcd(φ(n),e)=1。`
    
4.  `④ 计算d，满足d·e≡1 mod φ(n),即d是e在模φ(n)下的乘法逆元，因e与φ(n)互素，由模运算可知，它的乘法逆元一定存在。`
    
5.  `⑤ 以{e,n}为公开钥,{d,n}为秘密钥。`
    
6.  
    
7.  `加解密：如果明文比较长分段来处理`
    
8.  `加密为c=m^e mod n`
    
9.  `解密为m=c^d mod n`
    
```

需要注意点

1.  公钥和私钥互为逆元隐含着1<d<φ(n)< li="" style="box-sizing: border-box;"></d<φ(n)<>
    
2.  gcd(φ(n),e)=1(即φ(n)和e互素)则一定存在一组s1，s2使得s1\*φ(n)+s2\*e=1 **一般出题方式** pem文件：网络中的证书文件，里面藏着n，e用 `openssl rsa-pubin-text-modulus-inwarmup-inpublic.pem` 可以提取出来 flag.enc文件：被加密后的文件 .py文件：加密算法
    

**0x01模数分解**

```
1.  `得到φ(n)之后的计算原理：de=1 mod φ(n)且gcd(e,φ(n))=1 `
    
2.  `即de=k*φ(n)+1 ==> de+k*φ(n)=1`
    
3.  `分解思路：`
    
4.  `    直接分解：爆破（利用工具比较稳）`
    
5.  `    适用：n比较小的情况（512bit-768bit以内）`
    
6.  `    查询了解一下：http://factordb.com`
    
7.  `    利用公约数： 如果有2个n，并且2个n有相同的公约数`
    
8.  `    欧几里得算法时间复杂度为O(log n)即使是4096bit也是秒破。`
    
```

**低加密指数广播攻击**

```
1.  `c1=m^e mod n1`
    
2.  `c2=m^e mod n2`
    
3.  `c3=m^e mod n3`
    
4.  `在e=3时可以得到c_x=m^3 mod (n_1*n_2*n_3)`
    
5.  `对c_x开3次方可以的出明文。`
    
```

**0x03**共模攻击

```
1.  `说明：如果在RSA的使用中使用了相同的模n对相同的明文m进行了加密，那么就可以在不分解n的情况下还原出明文m的值。(e_1和e_2互素)`
    
2.  `c_1=m^(e_1)mod n`
    
3.  `c_2=m^(e_2)mod n`
    
4.  `需要：密文c_1,c_2 并且n相同.`
    
5.  ` 结果：`
    
6.  `c_1^{s_1}*c_2^{s_2}=m mod n`
    
7.  `s_1*e_1+s_2*e_2=1`
    
8.  `证明：gcd (e_1,e_2)=1 `
    
9.  `即存在s_1 ，s_2使得：`
    
10.  `s_1*e_1+s_2*e_2=1`
     
11.  `又因为： c_1= m^{e_1}mod n`
     
12.  `c_2= m^{e_2} mod n`
     
13.  `通过代入化简可以得出：`
     
14.  `c_1^{s_1}*c_2^{s_2}= m mod n`
     
```

识别：不只有一个c，有相同的n 例题 https://www.jarvisoj.com (very hard RSA)

**总结**

题目按照如下顺序测试 直接分解：适用n比较短，跑一下msieve 利用公因数：公因数分解有2个n比较大没有其他特征有限使用 查询：接着尝试查询 yafu：再尝试yafu 低加解密指数：如果e比较小，或者比较大，没有其他东西，试一下低加解密指数 共模攻击：2个密文，一个n2个不同的公钥互素 参考https://www.anquanke.com/post/id/84632
