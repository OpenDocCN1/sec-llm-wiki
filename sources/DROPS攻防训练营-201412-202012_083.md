下面对代码进行逐行分析，和知识点总结：  
  
    error\_reporting(0)  
  
这个函数主要是用来规定不同的错误级别报告，给出示范：  
  
    // 关闭错误报告  
    error\_reporting(0);  
  
    // 报告 runtime 错误  
     error\_reporting(E\_ERROR | E\_WARNING | E\_PARSE);  
      
     // 报告所有错误  
     error\_reporting(E\_ALL);  
      
     // 等同 error\_reporting(E\_ALL);  
     ini\_set("error\_reporting", E\_ALL);  
      
     // 报告 E\_NOTICE 之外的所有错误  
     error\_reporting(E\_ALL & ~E\_NOTICE);  
  
所以这行代码就是关闭所有错误报告  
  
    session\_start()  
  
Session\_start()这个函数开始一个会话或者返回已经存在的会话。这个函数没有参数，且返回值均为true。  
  
    require('./flag.php')  
  
在php中，可以在服务器执行php文件之前在该文件中插入一个文件的内容。include 和 require 语句用于在执行流中插入写在其他文件中的有用的代码。  
include 和 require 除了处理错误的方式不同之外，在其他方面都是相同的：  
require 生成一个致命错误（E\_COMPILE\_ERROR），在错误发生后脚本会停止执行。  
include 生成一个警告（E\_WARNING），在错误发生后脚本会继续执行。  
  
    if(!isset($\_SESSION\['nums'\]))

   {  
      $\_SESSION\['nums'\] = 0;  
      $\_SESSION\['time'\] = time();  
      $\_SESSION\['whoami'\] = 'ea';  
    }  
  
php5使用$\_SESSION\[‘xxx’\]=xxx注册SESSION全局变量。  
isset()函数用来检测变量是否设置，在这里我们打开题目链接，首次访问服务器，所以$\_SESSION\['nums'\]这个SESSION全局变量必然是没有任何东西的，所以$\_SESSION\['nums'\]为NULL，isset()函数返回False，加上！，条件成立，执行if语句中代码块的内容，初始化会话信息。在这里有一个关键点，$\_SESSION\['time'\] = time()，time()函数得到的是当前时间戳，时间戳是什么呢？就是从当前时间到林威治时间1970年01月01日00时00分00秒的总秒数。所以$\_SESSION\['time'\] = time()语句执行完毕，$\_SESSION\['time'\]为一个特别大的秒数，假设为time1（下文会用到）。  
  
    if($\_SESSION\['time'\]+120<time())

   {  
      session\_destroy();  
    }  
  
session\_destroy()函数为销毁所有会话信息。  
这段if语句，主要意思就是说明会话时间持续120s，但是在我最初理解这段代码的时候，我发现一个问题，就是$\_SESSION\['time'\]为time1，后面的time()函数又返回当前的时间time2，time1+120<time2时会话销毁，按照正常理解time1时间早，time2时间晚，time1加上120s如果大于time2，那就是说明超时了，会话进行销毁，但这里明显是小于号，所以当时我是百思不得其解，后来我突然想明白了，time1为一个稍比time2小的秒数，那么time1刚开始加上120肯定是比time2大的所以条件不成立，会话持续，随着访问的进行time2一直变大，time1不变，直到time1加上120小于time2的时候会话已经持续了120s，会话销毁，所以这么想一下子就理解了。  
  
    $value = $\_REQUEST\['value'\];  
    $str\_rand = range('a', 'z');  
    $str\_rands = $str\_rand\[mt\_rand(0,25)\].$str\_rand\[mt\_rand(0,25)\];  
  
这三行代码分别是第一行服务器接收一个value的值，这个值由我们自己post；第二行然后有一个$str\_rand变量表示字符'a'到'z'；第三行mt\_rand(0,25)表示从0-25中随机选取一个数字，有一个$str\_rands变量接收两个从$str\_rand中获取的字符，使用字符串运算符 . 把两个字符串联起来。  
  
    if($\_SESSION\['whoami'\]==($value\[0\].$value\[1\]) && sub      str(md5($value),5,4)==0)

   {

      $\_SESSION\['whoami'\] = $str\_rands;  
      echo $str\_rands;

分析这串if语句，首先分析条件，条件一：$\_SESSION\['whoami'\]==($value\[0\].$value\[1\])，如果我们传入的value的值的前两位和SESSION会话的$\_SESSION\['whoami'\]信息相等则条件成立，服务器初始化$\_SESSION\['whoami'\]的值为'ea'，所以我们第一次传入value='ea'即可。条件二：substr(md5($value),5,4)==0，substr(string,start,length)函数返回字符串的一部分，（参数string必需，规定要返回其中一部分的字符串；参数start必需，规定在字符串的何处开始；（正数 - 在字符串的指定位置开始；负数 - 在从字符串结尾开始的指定位置开始；0 - 在字符串中的第一个字符处开始）参数length可选，规定被返回字符串的长度。默认是直到字符串的结尾。（正数 - 从 start 参数所在的位置返回的长度；负数 - 从字符串末端返回的长度））  
在php里面 == 为弱类型判断，所以可以用数组绕过，即md5（数组）\==0，所以只要我们传入的vlaue为数组则条件二永远成立。  
关于弱类型的总结可以参照：https://www.cnblogs.com/Mrsm1th/p/6745532.html  
条件成立后进入if语句代码块，$\_SESSION\['nums'\]会话信息加一，$\_SESSION\['whoami'\]被随机两个字符赋值，并回显在屏幕上。  
  
    if($\_SESSION\['nums'\]>=10)
