# “安恒杯”河南省第三届信息安全与攻防技术大赛（HNCTF2018）完美收官

# 2018年5月20日12时，由河南省公安厅、河南省工业和信息化委员会、河南省教育厅联合指导，河南省计算机学会、CCF郑州、CCF YOCSEF 郑州共同主办，中原工学院承办，杭州安恒信息技术股份有限公司协办的“安恒杯”河南省第三届信息安全与攻防技术大赛（HNCTF2018），在中原工学院龙湖校区完美收官！

# 

![](../Images/4c0245a83ff2440bfcdd0163432c14ac.png)

# 5月19日，来自河南省高校和企业的43支战队共计129名比赛选手参与了线下攻防赛，经过9个半小时的激烈角逐，最终中原工学院“凌晨三点半”战队获特等奖，河南理工大学、河南警察学院、安阳工学院获得高校组一等奖，郑州信大天瑞信息技术有限公司、河南天祺信息安全技术有限公司、河南省金盾信息安全等级技术测评中心有限公司获得企业组一等奖，郑州大学、平顶山学院、河南大学等13所高校和河南金鑫信息安全等级技术测评有限公司、河南省电力公司、河南省鼎信信息安全等级测评有限公司等8家企业共计28支队伍获奖。

# 5月20日上午9点，在3号组团楼演播大厅举办了CTF技术报告会暨颁奖典礼，国内顶级CTF战队FlappyPig队长bibi做“CTF攻防经验”报告，360网络安全学院杜廷龙做“大安全视角下人才培养机遇与挑战”报告，永信至诚i春秋教研中心总监孙义做“安全技能竞赛人才培养指南”报告，安恒信息马腾飞做竞赛思路解析。本次报告会内容与CTF竞赛密切相关，干货满满，台下参赛选手和老师受益匪浅，收获很大。

![](../Images/096df390f460f71e3b739ea6ea8117ff.png)

# 上午11点颁奖典礼，出席颁奖典礼的嘉宾有河南省公安厅网络安全保卫总队调研员王志奇，河南省工业和信息化委员会网络安全处李建华处长，河南省教育厅科技处施晓春处长，麦士奎处长，河南省计算机学会周清雷理事长，中原工学院人事处郑秋生处长，中原工学院创新创业指导中心张鬲君主任，中原工学院教务处穆云超处长，杭州安恒信息技术有限公司高级副总裁袁明坤先生，杭州安恒信息技术有限公司河南分公司总经理徐安贵先生。各位嘉宾分别代表指导单位、主办单位、承办单位进行致辞并向获奖队伍和优秀指导老师颁奖，表示祝贺。

# 

![](../Images/85d936feba8110a33407e117efa226ea.png)

# 中午12点许，颁奖典礼结束并进行大赛集体合影，在大家开心的笑声中结束了本次大赛。

![](../Images/03088d9aa5d219a6eef3e950f93a6c55.png)

# 本次大赛得到了社会各界的好评和关注，为校际交流、校企交流、人才培养与选拔、推荐优秀的网络安全人才提供了良好平台，对实现人才从高校到企业的无缝对接，对高校和企业普及和推动网络安全技术，具有十分重要的积极作用。
