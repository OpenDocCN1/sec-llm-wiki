# “安恒杯”河南省第三届信息安全与攻防技术大赛2018年再度扬帆起航，将于5月19日至20日在中原工学院新郑龙湖校区正式打响！竞技战火重燃，来自河南省高校及企业的45支战队早已摩拳擦掌，亟待出发，将为大家带来激烈的年度科技盛宴。

  

* * *

![](../Images/4c0245a83ff2440bfcdd0163432c14ac.png)

  

# 本届大赛的预赛为线上赛，已于4月21日举办。决赛由预赛成绩排名前10的队伍以及其他受邀队伍组成。河南省信息安全测评企业全部组队参加决赛。决赛将在19日打响，从上午9点持续到晚上8点。20日上午将举办竞赛选手交流会，届时还会有来自360、安恒、永信至诚等公司的行业内专家，CTF全国顶尖技术大牛为大家做精彩的技术报告。

  

# 本次大赛由河南省公安厅、河南省工业和信息化委员会、河南省教育厅指导，河南省计算机学会、CCF郑州和CCF YOCSEF郑州联合主办，中原工学院承办，杭州安恒信息技术股份有限公司协办。

  

# 竞赛旨在进一步加强河南省网络安全人才培养和信息安全专业建设，促进社会对网络与信息安全知识的了解与普及，激发学生学习网络与信息安全的积极性，培养学生的创新意识、协作精神，提高从业人员应用网络与信息安全知识解决实际问题的能力，为校企交流、人才培养与选拔、推荐优秀的网络安全人才提供平台。
