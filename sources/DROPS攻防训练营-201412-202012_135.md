# Windows自带杀毒软件防护评分：0！

知名免费服务器安全软件-云锁发布《2014中国Windows服务器安全状态报告》，报告针对2014年中国Windows服务器市场安全情况进行了统计与分析。报告显示，Windows Server 2003的市场占有率继续高居榜首，CC攻击成为不法分子最青睐的攻击手段，教育科研行业成为最容易受到攻击的行业。整体而言，国内服务器仍处于十分危险的境地，安全防护措施基本停留在初级阶段，国内信息安全事业任重道远。

1、Windows服务器操作系统：Win2003 市场占有率仍稳居第一

虽然微软已经确认于2015年7月14日停止对Windows Server 2003的支持，但Win2003仍然牢牢占据绝大部分市场。预计明年微软正式停止对Win2003支持后，Win2003市场份额将会有一个较大回落。Win2012份额稍有扩大，由去年的1%提升至2%。

![](../Images/f271537a49acf9885621b875f40a1d70.png)  

2、Web服务器中：Apache保持第一，Nginx保持稳定增长

2014年活跃网站中，Apache Web服务器仍占据近四成市场份额，Nginx表现较为抢眼，提升至16%，微软IIS则保持第二名的位置。

![](../Images/c3100cfab846abad4a4e78837c8c1f88.png)  
3、新增网站服务器市场：云主机出货量快速提升

2014云主机表现抢眼，占网站服务器新增出货量43%。云主机因其具有部署快、弹性扩展力、按需收费的特点，受到越来越多用户的欢迎，而VPS作为云主机的前代产品正在逐步被淘汰，新增市场份额已经不足10%。

![](../Images/7cef420972c19e9c55e1962de4edbcb0.png)  

4、网络攻击升温： CC攻击成最常见攻击方式

随着信息技术的发展，国内服务器受攻击次数连年跃升，其中CC攻击成为黑客最惯用的伎俩，此外SQL注入攻击、XSS跨站攻击也是黑客常用的攻击手段。

![](../Images/6fea01b67d9e50b235c80c58c28c3bc8.png)  

5、最易遭受攻击的行业排名：教育行业排名第一

在2014年内，教育科研、网游、政府三大行业成为黑客的主要攻击目标，三大类型网站受攻击次数合计占比高达61%，大幅领先其他行业。

![](../Images/3ec6b1d15ec1dce7320161d9744aaefc.png)  

6、国际网络安全环境堪忧：境外攻击大幅上涨

2014年来自境外的网络攻击明显增多，其中大部分攻击针对中国企业和政府网站。由于攻击源来自境外，给追踪造成巨大麻烦。

![](../Images/f7aa293e1ad6c0b14787067d38bbb8f0.png)  
2014年，信息安全问题进一步蔓延，从年初的中国互联网DNS瘫痪事件，到携程“安全门”事件、OpenSSL心血漏洞、苹果“漏洞门”、好莱坞明星“艳照门”、Shellshock漏洞、摩根大通遭入侵、“贵宾犬”漏洞等，到最近的SONY影业遭黑客攻击事件，重大信息安全事故贯穿整个2014年。而对于用户庞大的Windows服务器市场，安全问题尤为突出，信息安全防护已经箭在弦上，刻不容缓。

  

众所周知，微软自Windows 8时代开始在系统内预装了自己的防病毒软件Microsoft Security Essentials，简称MSE，并且同样免费提供给Windows 7用户使用。

之前，MSE在用户心中留下不错的印象，但在权威安全机构AV-TEST所进行的最新测试中，MSE的评分却出现了下降，略微令人失望。

据介绍，AV-TEST的测试分为三项，分别针对防病毒软件的防护能力、运行性能以及易用性，每项满分为6，总计18分。

AV-TEST的报告显示，MSE的最终得分为9.5，其中防护能力一项为0分。

![](../Images/4d92d262980bc7bb24fbad2cb76a6e9c.png)  

需要注意的是，0分并不代表MSE已经变得弱不禁风毫无防护能力。相反，在最新的测试中，MSE抵御了77%的外部攻击，这一数据较之前使用Windows 7测试时的69%略有提升。

AV-TEST指出，作为一款系统自带的防病毒软件，MSE的综合能力还是相当不错，没有烦人的广告弹窗、无需注册、免费，只是在针对最新式病毒和恶意程序的查杀方面有所欠缺，希望微软能够加快更新步伐。
