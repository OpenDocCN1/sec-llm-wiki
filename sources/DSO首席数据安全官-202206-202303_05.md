# 国家数据局即将成立！数据安全人才培养迫在眉睫！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MTgwMzA2MQ==&mid=2247484227&idx=1&sn=9a2fb033be18918bc97864337b1d8272&chksm=cf612919f816a00f1d0aea8369f483ad250a26a622efe4198f7ee7208518cbb3fc6e36229040&scene=126&sessionid=1681266233#rd](http://mp.weixin.qq.com/s?__biz=Mzg4MTgwMzA2MQ==&mid=2247484227&idx=1&sn=9a2fb033be18918bc97864337b1d8272&chksm=cf612919f816a00f1d0aea8369f483ad250a26a622efe4198f7ee7208518cbb3fc6e36229040&scene=126&sessionid=1681266233#rd)

2023年3月7日，根据国务院关于提请审议国务院机构改革方案的议案，组建国家数据局，一个全新的机构即将诞生。

![](../Images/506b8bb63404217a5f7ae34f0b6e1c4e.png)

根据新华社报道，国家数据局将由国家发改委管理，为副部级单位，**负责协调数据基础制度建设，统筹数据资源整合共享和开发利用，统筹推进数字中国、数字经济、数字社会规划和建设等**。

![](../Images/cf2e64727c9008369fa3646e33a68b0c.png)

根据改革方案，中央网络安全和信息化委员会办公室承担：

*   研究拟订数字中国建设方案
    
*   协调推动公共服务和社会治理信息化
    
*   协调促进智慧城市建设
    
*   协调国家重要信息资源开发利用与共享
    
*   推动信息资源跨行业跨部门互联互通等职责划入国家数据局。
    

国家发展和改革委员会承担：

*   统筹推进数字经济发展
    
*   组织实施国家大数据战略
    
*   推进数据要素基础制度建设
    
*   推进数字基础设施布局建设等职责划入国家数据局。  
    

可以预计，由国家发改委统筹，组建国家数据局有利于解决数据分散治理问题，集中各方资源全面推进数字中国，**数字中国有望步入发展快车道，进而对数据安全市场带来重磅利好。**

  

![](../Images/0b4cc0c6f00f98e89b90b451e8eb0ff5.png)

**政策暖风频起 1500亿数据安全市场可期**

近年以来，国家从顶层规划和政策细则层面，频频出台相关政策文件，强化了数据安全作为数字中国建设核心底座的地位，**数据安全产业迎来了黄金发展期**。

  

3月5日上午，十四届全国人大一次会议开幕，总理在《政府工作报告》中指出，要加快建设现代化产业体系，其中包含大力发展数字经济，提升常态化监管水平，支持平台经济发展；加快传统产业和中小企业数字化转型，着力提升高端化、智能化、绿色化水平。数字经济、产业数字化再次被提及，数字化浪潮趋势明确。

  

早在2022年12月，《中共中央国务院关于构建数据基础制度更好发挥数据要素作用的意见》（下称“数据二十条”）正式发布，明确了坚持促进数据合规高效流通使用、赋能实体经济这一主线。

  

今年1月，工信部、国家网信办、国家发改委等16部门印发《关于促进数据安全产业发展的指导意见》，提出到2025年，数据安全产业基础能力和综合实力明显增强，数据安全产业规模超过1500亿元，加速数据要素市场培育和价值释放。

![](../Images/4aa8c8b5d6766acc1461eaf79627e188.png)

  

就在2月末，中国中央、国务院又印发了《数字中国整体布局规划》，明确了建设数字中国对于推进中国式现代化的核心地位，同时将数字安全屏障与数字技术创新体系并列为“两大能力”，凸显了数据安全在数字中国中的核心和底座作用。

  

相关研究机构预测，2023年两会已经召开，数字经济的发展定调不变，**预计未来数据要素、数据安全等领域有望迎来超预期政策落地，将对数据安全行业产生更多的实质性利好。**

  

![](../Images/0b4cc0c6f00f98e89b90b451e8eb0ff5.png)

**数据安全人才供需缺口大，人才培养迫在眉睫**

在当前数据安全产业快速发展的新形势下，人才缺失已成为企业数据安全建设的新难题。我国企业数据安全岗位大多由其他岗位人员兼职，专业数据安全人才缺口在百万级以上。这将直接影响数字中国建设，制约数据赋能和数据的安全、有序流动和开放共享等。因此，要让数据安全人才培训成为一种常态，健全数据安全人才培养体系，壮大数据安全人才队伍，培育大数据安全师等紧缺人才，这些力量将成为未来网络安全、数据安全的主力军。

  

**工业和信息化部作为数据安全行业的主管部门，指导下属单位工业和信息化部教育与考试中心培养数据安全相关人才**。
