树莓派的准备工作：


一、WiFi 网络配置


如果刷好了树莓派的系统直接在内存卡根目录里存放wpa_supplicant.conf

这个文件内容填写:

country=CN

ctrl_interface=DIR=/var/run/wpa_supplicantGROUP=netdev

update_config=1

 

network={

ssid="WiFi-A"

psk="12345678"

key_mgmt=WPA-PSK

priority=1

}

 

network={

ssid="WiFi-B"

psk="12345678"

key_mgmt=WPA-PSK

priority=2

scan_ssid=1

}


说明以及不同安全性的 WiFi 配置示例：#ssid:网络的ssid#psk:密码#priority:连接优先级，数字越大优先级越高（不可以是负数）#scan_ssid:连接隐藏WiFi时需要指定该值为1

 

二、开启 SSH 服务


和 WiFi 配置相似，同样在 boot 分区新建一个文件，空白的即可，文件命名为 ssh。注意要小写且不要有任何扩展名。




然后就可以连接到你自己的wifi下了！

ssh连接到树莓派  默认账号为pi 密码为raspberry(如果不知道ip的话可以从路由管理器里查看)
