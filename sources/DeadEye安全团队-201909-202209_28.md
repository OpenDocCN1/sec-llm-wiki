相信能点开看这篇文章的都知道oscp是什么了，就不过多解释了。Oscp(Offiensive Security Certified Proffessional) 是实战的渗透测试认证。以Kali Linux为操作系统，在23小时45分钟内攻破5台考试机器，并拿到他的最高权限。OSCP官网：https://www.offensivesecurity.com/pwk-oscp/

这里说一下我是快4月份报名的，之前也看了网上的一些考试攻略，最早了解到oscp认证是在套哥的FreeBuf上面看到的，因为想增强下自己权限提升的能力，就去报名了，报名的时候发现官网已经不一样了。课程升级到了2020版本，增加了很多的内容。

![](../Images/d2895f7e86d047222133e14cac75993d.png "对对对.png")

  

     这个对我来说是很不幸运的，教材有300多页一下子更新到了860页，像一本英语牛津字典，增加了更多关于AD渗透的课程和更多依赖性的LAB，最主要的是课程的价格也增加了。

  

![](../Images/42c6c4220c1fbd258fc349200a610196.png)

![](../Images/d5a8e8f6d13e03bc054d9b8bbd77e034.png)**OSCP考试认证指南**注册问题

第一个问题是注册的问题，注册的时候需要用到信用卡来支付考试费用，然后你需要一个邮箱，邮箱需要用你公司邮箱或者个人域名邮箱，大学的邮箱也可以的，最好邮箱的账号就是你的名字。没有得话可以申请一个zoho个人域名邮箱。这个搭建的时候可能会遇到点小坑，不过没什么难度。

要准备信用卡+护照+域名邮箱

网络问题

      

      网络如果有问题的话，也没办法做lab了，考试的话也会遇到网络的问题。所以做Lab的时候就先处理好，方法用的是上一个通过的学员的文章，用的IPsec/L2TP全局代理。首先你还是需要一个vps，vps可以选择vultr，google或者阿里云腾讯云都行。白嫖最好不是吗，搭建ipsec/l2tp可以参考下面那个文章，这样挂上之后打开虚拟机你直接ping谷歌就可以通了。

https://github.com/hwdsl2/setup-ipsec-vpn/blob/master/docs/clients-zh.md 

       

     期间我也是自己尝试了很多的方法，最后还是这个方法最好用，推荐大家使用。最后我的ping值是在300ms左右，其实ping高不高无所谓，不丢包就可以了。

Lab前准备

  

     在开始做lab之前，我先是跟着Dm学了一遍权限提升，目前授权的渗透基本都是点到为止，所以提权这个地方我练的就比较少了，之前提权我更喜欢用脚本去检查或者用msf自带的提权建议模块，不过这样真实环境中动静搞的有点大，一般会触发报警，所以先高强度的连续训练权限提升的能力就成了lab学习前的第一个准备，各种的服务提权。学缓冲区溢出是比较痛苦的，因为我是个web狗，基本没有怎么接触过，听缓冲区原理好像天书一样，堆栈，shellcode，期间问了不少的弱智问题，后悔大学没有好好学软件安全那门课了，又跟着练习了几个溢出题目，带着一大推问号和一堆工具的我感觉自己可以去实验室里面复现下了。

  

PWK教材在2020年2月左右升级成了2.0版本，教材860页，还有大概24小时左右的视频吧，前面讲的都挺基础的，后面讲了很多AD的内容不过也不是很深入，刚开始的时候问了Dm大佬，860页英文教材怎么看，他问我英语如何，我说不太好，他回我一句，那就别看了然后给了我一些github上的oscp note，链接放在文末了，看了下是国外的一个大佬写的，大致内容和教材教的差不多，谷歌一键翻译……(这里给英语一般的同学一个小技巧，英语不行就别看了，省的去翻译了)

       

      当然教材中有很多提权的方法和一些你可能没见过的小技巧，还是需要去看一下的，毕竟那是花钱买来的。新版的教材习题增加了，写习题和10台不同的靶机报告是可以在考试中增加5分的。（反正我没做，跟着Dm老师学习就很稳）不过新版本教材，习题大约有100道，而且难度不低，光做习题和看教材的话估计半个月就过去了。

  

Lab练习

  

     新版本拓扑大概是这样的。你有三台机器来做练习，win10, win2016域控，Debian。Win10机器上面是有缓冲区调试环境的。

![](../Images/ddc74ded347ce813d76d89be6513d3b1.png)

     我的Lab大约是做了3周吧，刚开始做lab还是有点难度，因为没怎么做过vulnhub和hackthebox，推荐大家还是先去刷一下那几个比较像的机器，思路基本都是固定的，nmap扫描端口+gobuster跑一些目录，拿到低权限shell，然后提权，比较符合传统的渗透测试方法，这个毕竟是靶机，和真实环境是不一样的，基本你做了初期的枚举就能找到一些入口的点。枚举！枚举！枚举！

      

     做Lab的时候基本就是searchsploit，oscp主要考察的就是漏洞利用，和修改exp能力，lab中的机器相对于ctf中的脑洞题来说要好很多，不过有一些机器存在脑洞。学生有一个学生论坛，上面会写一些提示来指引你，不过每次打开看基本都是做到哪里提问的和拿到了root之后来写一句我root了，这机器真棒，看了就想打人的话。

       

      我遇到解决不了的问题或者在论坛中也没法获得思路的时候就找dm描述下遇到的问题，因为官方是不允许透漏lab信息的，所以他只能给我一些思路，Try Harder,给我发一些文章让我看，引导我怎么进行下一步，我有时候会忽略点一些关键枚举信息，这样就节省了很多时间，更快的养成了oscp中的黑客思维。很快我基本上在20多天的时候拿下了30台左右机器。然后就遇到瓶颈了。因为有些机器是依赖机器了，你需要拿下A机器的权限并找到一些B机器上的信息才能拿下B,后面还有AD的机器。这个时候就得学一下AD了，其中有台新机器，我传cs马之后会立即被杀掉，win10机器上有个defender，内部有免杀神器，安排。可以随时问随时答还是比较好的，因为提权已经搞的差不多了，后续就研究依赖的机器和其他的4个网段了，报名了Dm的内网渗透班学习了域渗透的知识，这4个网段做的还是和真实环境很相像的，绕过杀软后快速横向渗透拿下了一台比较麻烦的机器，不过后续因为水平还不够的原因后面的机器还没拿下来。

  

       最后一周我就有点浮躁了，感觉我提权已经没什么问题 ，就静不下心来做机器了，期间还去学了会儿内网，然后又整理了一周的提权就报名考试了，考前给我来了个突击辅导，问了我很多真实渗透中的问题，感觉好像是在面试我一样…… 测试下我能力能否应对考试，回答的可能他不是很满意吧，但是抱着先考一次然后二战的心理就上战场了。

  

考试中提权基本没有遇到问题，比Dm给我练习的几个windows提权靶机要简单很多，但是可能我没枚举做的不到位，webshell有一台机器没有拿下，最终飘过……新版本的机器系统都升级了，考试的时候也会遇到windows server 2019提权,实验室里也有很多2019和2016，Linux考试中也不会出现内核提权的，所以提权能力也是考试最重要的一点。

![](../Images/d5a8e8f6d13e03bc054d9b8bbd77e034.png)**考试经验**

      考试预约要提前一周左右去约，星期天人会比较多，但是周一到周五的时间就比较多了，考试可以准备几瓶红牛，咖啡，保持一个清醒的状态。考试中遇到的兔子洞会比lab中的多，需要仔细辨别一下，oscp考察的还是比较全面的，需要有基本的代码修改能力，因为你在考试中msf只能使用在一台机器上，不确定能不能成功的话就先不要用msf去打，meterpreter shell也只能在一台机器上运行，所以考试中的反弹全部都用nc。

  

       考试会给你4台机器，一般是2个windows，2个linux，一个缓冲区溢出，缓冲区的25分是一定能拿到的，也就是在不写练习题的情况下还需要拿下一个25分和20分机器才能最少机器通关，有时候10分的题目可能会很难，因为10分题直接拿到就是root了，他会在10分上卡你，先拿自己有把握的机器。其实抽题也蛮看运气的，遇到一个兔子洞比较多的题目就尴尬了，还有就是那种枚举了之后依然没有思路的题目，多google多看htb上面的writeup。考试中的local.txt和proof.txt都要截图的，还有就是sqlmap和burpsuite pro是和Msf一样禁止使用的，自动化利用和商业软件都不可以，Nmap和dirb是可以随便用的，nmap中的脚本也一样。

  

       每个人的基础都不一样，可能有的人做了10天LAB就拿下了考试了，也可能做了很久还没拿下几台机器，前期如果没怎么渗透过的话去做一下vulnhub和htb的机器比较好。基础差的话，也可以来报个1对1辅导班，来针对性学习下技术，如果已经是练习时长两年半的渗透测试练习生的话，练一练提权一个月应该可以轻松拿下。
