颁发的电子勋章和CCIE一样，是在Acclaim平台颁布的。目前，已有上百家机构在通过 Acclaim 平台发送电子证徽，如微软、甲骨文、华为、西门子、思科、思杰、Autodesk、Facebook、VMware等，是一个权威的平台。

Q: 什么是电子徽章？

A: 电子徽章是一种网页版的认证标识。

 

Q: 电子徽章的优势有哪些？

A: 使用电子徽章，在网络上展示你所获得的有效认证是一种简单、诚信且易实时验证的分享方式。电子徽章为你的雇主，同事了解你所获得的认证及已获得验证的技能，提供真凭实据。

初识OSCP

第一次知道OSCP是在Kali官网看到的，出于好奇于是谷歌搜索，发现是一个挑战性极强，认可度和含金量都非常高的一个认证。它前期需要通过PWK教材的学习和在珍贵的（真的很贵）实验室环境上练习，然后预约考试，最后通过23.45小时的考试，获得认证。

看了很多国外大佬的博客，发现这么具有挑战和充满趣味的事情我怎么能落下呢？但是感觉真的好难啊。于是，我定了一个2020年将要实现的第一个目标，拿下OSCP！

开启OSCP 之旅

开始注册

填写注册页面需要全程英文填写，担心看不懂的同学不用怕，可以翻译APP帮解决。我先注册了一个月实验室访问，想法是先混套教材，慢慢学习再说。从注册付款成功后开始最快一个星期，可以拿到链接实验室的VPN和教材。收到教材是PDF和视频，由于知识产权，教材的细节处都是打了个人信息水印的，目的是防止外传。

网络问题

由于国内网络环境的特殊（你懂得）我在链接实验室时遇到的第一个问题就是延迟高，不稳定，丢包率高。我的头很大呀，实验室和考试网络环境是一样的，这样的网络环境考试肯定受影响，岂不是要凉凉？中国有句古话，兵来将挡水来土掩，这个问题怎么能难得了我呢？开始研究如何可以利用手上的VPS自己搭建一个“加速”工具。我试了很多方法，最终使用了配置IPsec/L2TP方案解决，优点是稳定、不易掉线、操作系统自带客户端、实体电脑链接后虚拟机电脑不用做任何配置，项目的网址是：https://github.com/hwdsl2/setup-ipsec-vpn/blob/master/docs/clients-zh.md，完美解决链接实验室的网络问题。

在实验室里遨游

实验室的环境是一个高度仿真现实世界的网络环境，很多机器之间相互都有关联，可以横向移动，这个就很刺激了。网络方面，一共有四个网段分别是Public、Dev、IT、Admin，其中Public网段的机器最多，我们首先连接的也是Public网段，其余网段需要在渗透过程中发现有network-secret.txt的机器，解锁网段才能访问。可以做跨网段攻击练习。

 


第一个星期看PDF和视频，讲的很细致实用，接下来的三个星期我通关了25台机器，解锁了两个网段，这时候已经有点手感了，实验室时间也到期了，感觉练习还不够，于是我一鼓作气续期了一个月的实验室访问权限，把剩下的机器和跨网段攻击好好练习一下。

 

第二个月因为年关将近，年前的那段时间其实已经没有第一个月效率高了。峰回路转，过年期间疫情原因取消了原本走亲戚、聚会活动，节省下来的时间这使我又可以投入到学习中了，这使我萌生了先考试一次试试的想法，我把考试提上了日程，接下来的这段时间又开始全身心准备考试。说实话，这段时间真有一种临战高考的状态。

总结的一点小经验

通关OSCP考试需要具备的知识和能力有，Web渗透测试基础知识、Linux运维知识、Win运维知识、C语言基础、汇编语言基础、Python简单编写能力、Bash简单编写能力、漏洞辨别能力、搜寻漏洞能力、漏洞源码修改能力、Kali常用工具熟练使用能力。想考试但是对自己没信心的可以先针对以上先熟悉一下。

无论考试还是实验室，让我感觉最真实的就是兔子洞了，像极了现实中应该存在漏洞的版本，但是被管理员修复了的情况，需要有极大的辨别能力，否则会被兔子洞浪费好多时间，我想这也是OSCP需要具备的一种能力。

考试的时候有5台机器，我的这次考试抽到的5个机器分别是缓冲区溢出机器、2个Win机器、2个Linux机器，考试的时候机器版本很新，提权需要费点功夫。

要注意的是现在考试不允许全程录屏了，考试过程中一定要按照递交报告的格式要求和截图要求收集报告素材！

linux 结果答案截图命令：

hostname && whoami && cat proof.txt && /sbin/ifconfig

windows 结果答案截图命令：

hostname && whoami.exe && type proof.txt && ipconfig /all


做完的靶机需要把得到的proof.txt粘贴到答题面板上。
