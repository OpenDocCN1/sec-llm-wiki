# 战火之下，乌克兰开发者还在加班提交代码！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NzI5NDM4Mw==&mid=2247490297&idx=1&sn=918c848e8beb38009118e83f9882a5f5&chksm=ea18f3b9dd6f7aaf8a3d7eedc61c356e0cad2a22ae7c1d7444e72e4ca2ce44cb985ffc3e4315&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1NzI5NDM4Mw==&mid=2247490297&idx=1&sn=918c848e8beb38009118e83f9882a5f5&chksm=ea18f3b9dd6f7aaf8a3d7eedc61c356e0cad2a22ae7c1d7444e72e4ca2ce44cb985ffc3e4315&scene=27#wechat_redirect)

![](../Images/1772d4145ad8c49dd7daa571f7b9819a.png)来自| InfoQ  编译｜核子可乐、燕珊虽然企业在强调人身安全最重要，但意外的是不少开发者还在坚持编写程序。  

乌克兰有着庞大的软件开发者社区，主要以远程方式为美国及欧洲等地的软件企业工作。据统计，2020 年乌克兰开发者总数约 20 万名，全球五百强企业中有五分之一在乌克兰设有远程开发团队。日前乌克兰陷入战火后，在艰难的环境下，不少开发者仍在坚持为雇主编写程序——白天支援当地防御，夜晚则写代码、提 PR。  

战火下，编程不辍

旧金山一家软件许可企业的首席财务官 Logan Bender 在上周在社交平台中感叹道，“没错，冒着猛烈的炮火与存亡压力，我们的哈尔科夫开发团队继续占据一处停车场向公司提交代码成果。”

他表示，“我们当然提醒他们马上停止开发，当务之急是告诉我们如何有效汇款和帮助他们办理离境签证。眼前的头等大事就是为他们提供力所能及的帮助。”Bender 还一直努力游说美国国防部门，希望能派遣武装警卫保护雇员们从冲突地区安全撤出。

根据总部位于阿姆斯特丹的软件开发外包公司 Daxx 介绍，2020 年乌克兰开发者总数约 20 万名，全球五百强企业中有五分之一在乌克兰设有远程开发团队。

旧金山博彩平台 Pogbet 创始人兼 CEO Eric Havagim 在接受采访时亦表示，“我们的乌克兰前端开发负责人已经前往利沃夫市郊 40 公里以外的父母家中，而且仍在提交 PR。明天一早，他就会返回利沃夫继续工作并参与抵抗战斗。”

但无论是哪个国家或地区陷入战争冲突，对于企业来说，他们最在意的仍将是当地员工的人身安全问题。“我们的思绪与所有受影响的人同在，我们的首要任务是确保所有员工及其家人的安全。”三星在最新的声明中称。

微软的声明亦提到，作为一家公司，“我们致力于保护我们在乌克兰的员工的安全，我们与他们保持联系，提供多种形式的支持，包括那些为了生命或安全需要离开乌克兰的人。”

开发者的日常

2022 年 3 月 3 日，基辅地区博罗江卡一处定居点被炮击摧毁。一位因职业原因要求匿名的乌克兰开发者接受了采访，谈到在战火之中继续工作确实困难重重。

这位开发者提到，“当战火燃上自己的国土，我们肯定很难把心思专注在工作上。”但他很感激雇主能理解这里的特殊情况。

“我想对所有关注乌克兰、与乌克兰共情的人们说声谢谢。” “现在，每个乌克兰人都在为着同一个目标而努力。在这里，大家都在挣扎生存、也在相互帮助……再次感谢全世界的支持。”

掌握 IT 技能的乌克兰人还做好了在家中走上另一条战线的准备。基辅当地数字营销机构员工正在与乌克兰数字转型部合作，联手对俄罗斯各实体发动网络攻击。目前，Telegram 上一个专门向众包程序员开放、计划对俄罗斯开展网络攻击的频道已经拥有近 100 万订阅者。

来自摩尔多瓦的软件开发商 Labs42 联合创始人 Alexandru Asimionese 谈起他在乌克兰西北部城市卢茨克的一位自由设计师伙伴：“他早上会去帮当地部队采购高蛋白食品，夜里则正常工作、为我们公司设计 Logo。他的工资是通过币安交易所用加密货币支付的。”另外一位创业经理人也提到，他的乌克兰女友正打算从海外回国支援当地战事，并利用战斗间隙继续为所在的科技企业工作。

乌克兰裔美国人 Daniel Berezovsky 是佛罗里达州应用程序开发商 sMiles 的联合创始人，他说道，“我们的基辅开发团队白天会协助普通民众和武装部队，忙完后则快速回到工作中来。”

“我有个朋友的公司在哈尔科夫设有办事处，那里的开发人员拿起武器加入了城市防御行动，同时把自己的妻儿家人撤离到乌克兰西部城市利沃夫周边。”

Berezovsky 提到，“这样的事迹在乌克兰各地都有出现，每一条战线上都不乏这样不屈的意志。”

“我们希望无论发生什么，都能留在这里”

乌克兰程序员 Serhiy Storchaka 是 Python 的主要贡献者之一，但战火发生时，他决定留下来。Andrew Svetlov 是另一位具备影响力的 Python 开发人员，从事异步网络支持，他也选择留在乌克兰。

“他们俩都不想离开他们的国家，即使面临着巨大的风险。”位于波兰波兹南的 Python 软件基金会驻地开发人员 Lukasz Langa 说道，他一直与上述两位开发人员保持联系，他指出 Storchaka 是近期 Python 的第二多产贡献者，从“有史以来”的维度看，也能排上前十。

Alex Molodkin 是游戏开发商 Weasel Token 的成员之一，其工作室位于基辅，目前正在开发游戏《Puzzles for Clef》。他目前还和亲人住在公寓楼里，因为祖母患有影响腿部的身体疾病，他们无法撤离或搬到避难所。

Molodkin 说他已经考虑过，“如果最坏的情况发生”，他会考虑搬迁，但希望这种情况不会发生。

“我们从未打算离开乌克兰，因为这是我们的土地。我们喜欢它。我们的朋友和家人都在这里。我们希望无论发生什么，我们都能留在这里。”Molodkin 说，“我们希望战争尽快结束，一切恢复正常。”
