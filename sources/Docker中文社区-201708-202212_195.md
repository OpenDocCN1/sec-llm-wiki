给大家推荐一些常用的 chrome 的插件，还是非常不错的，大家可以用起来看看。  

## 前言

相信很多人都在使用 Chrome 浏览器，其流畅的浏览体验得到了不少用户的偏爱，但流畅只是一方面， Chrome 最大的优势还是其支持众多强大好用的扩展程序（Extensions）。下面的很多插件都是工具插件，看完保证你工作效率、心情提高1倍。  
**1、****OneTab：一键合并 tab**  
Tab 过多的时候，要关闭浏览器的时候OneTab可以帮助你快速的保存、整理浏览器。  
![](../Images/75ff9a34b3664c343d2b5922e6102a67.png)  
**2、掘金：最新的技术动态**  
每次打开新的 tab 页面就可以看到最新、最热的技术文章。  
![](../Images/f09d026cf24829bbc6a195bb5a2302e4.png)  
**3、markdown here**  
超好用的 MD 编辑器，任何地方都可以把 MD 轻松的转换为富文本，我们可以把简书写好的文章（带md语法）直接复制到微信公众号啦。  
![](../Images/105b6e36af17254d6d48c2d1c4fcbaa8.png)**4、Adblock Plus：免除广告困扰**  
你是不是每次搜索百度前几个都是广告？有了它，你的搜索结果只有纯净。  
![](../Images/ac66e9fd9436871743b2737505da0f08.png)**5、LastPass：密码管理软件**  
LastPass，全球知名在线密码管理工具之一，采用军事级加密算法，支持自动填充网站用户名和密码，与朋友分享登录信息等实用功能，且在全平台同步免费，无需订阅 Premium，即可在手机、网页、电脑端同步你的所有 LastPass 信息。  
![](../Images/f5cdac6d5e8403af6428cd93b775368e.png)  
**6、二维码(QR码)生成器**  
在线的二维码生成器。最方便的用法是把当前的页面生成二维码，方便手机扫码快速访问。![](../Images/e804c766cad07b44f1a854ffc12cfd8b.png)  
  
**7、下载+**  
Chrome的下载管理在二级菜单里，进去很不方便。装了这个插件就可以直接看和管理，很好用。  
![](../Images/26f7a383909ca3daa0ac015382100316.png)**8、Github 加速器**  
一键加速 Github 访问速度，当 Github 访问慢的时候点击右键直加速，同时支持多个加速镜像。  
![](../Images/09007537261e765b21584f1b555af86b.png)  
**9、购物党**  
在线的比价工具，剁手党们赶紧装起来。  
![](../Images/1b377030469a7070260cc69fd79aa0db.png)

  

**10、新浪微博图床**  
  
简单好用的新浪微博图床,同时可以快速转换格式，HTML,UBB和Markdown等格式,支持浏览和删除历史记录。  
![](../Images/2be86b6a458af20644a006225eb764ed.png)  

**11、crxMouse Chrome Gestures**  
对于国产浏览器自带鼠标手势的功能，真觉得很方便！有了这款插件，也足够让你装B了。  
![](../Images/9d1dab5d2e46a4713c5243b140c7d4b7.png)  
**12、Imagus**  
图片放大镜的功能，在浏览新闻和博客的时候想右键看一下高清图，有了这个插件完全不用，鼠标悬浮就能看高清图片。  
![](../Images/498dd01d18e7a3b42b0cabec1c3ba2ff.png)  
**13、Save to Pocket**  
看到感兴趣的先收藏着，然后走哪儿都能看，并且它由各个平台的版本支持，同时可以自动去广告，只把关键的内容保存，这样非常方便各个平台阅读。  
![](../Images/de549edb56d3003050e0974fff5ab75c.png)  
**14、网页截图:注释&批注**  
网页截图，批注工具。  
![](../Images/ddd93bee27ff597d899d48e0d1739a67.png)  
**15、Image Downloader Chrome**  
想下载某个页面的图片，不用再去资源里面一个一个看了，直接安装这个插件，一键就可以下载。  
![](../Images/434eb5d9dad0ead960e965a2cbb09746.png)**16、Google翻译**  
Google翻译是一款由谷歌公司提供的网页划词翻译插件，它支持动态的划词翻译功能，也支持网页翻译，真是阅读外文网站的好帮手啊。  
![](../Images/c3f7f307d4b8499e225dbf52d8ca5fca.png)  
  
  
**17、Lucidchart Diagrams - Desktop：在线绘制多种图表**  
绘制各种流程图手头没有趁手的工具，直接试试这个工具哈。  
![](../Images/9d9320d6410d44092cc7cd8437754f99.png)  
**18****、New Tab Startup Quotes：学习成功人士的格言**  
每次打开新的 tab 都会有一个名人名言，不过是英文的，得思考一下才能理解其中的奥妙，如果你能做一个中文版就好了。  
![](../Images/0ab46ea866c8c2a454c25d9ab6778eca.png)**19、Search by Image：强大的以图搜图**  
发现了一个图片，但是不知道他是什么，或者想搜索一些类似的，那么就用这个插件。  
![](../Images/2d7e345028552c60508b84049dfa555c.png)

**20、为什么你们就是不能加个空格呢 **  
自动把网页中所有中文、英文、数字、符号之间插入一个空格  
![](../Images/3fcb5b1d9a63ee8fd5d69a4a157c287d.png)  
**21、Clear Cache**  
点击图标即可清除缓存、cookie等，开发必备！  
![](../Images/17cdf73a5b286fec49273dd8313be505.png)  
**22、JSON Viewer**  
JSONView 是一个方便查看 Json 结构的插件，展开，折叠，可以非常方便的查看接口返回数据。  
![](../Images/94cfff69e2164d195bf463b05d187ddc.png)  
**23、Postman**  
相信开发者朋友一定知道这款插件，非常方便的调用和调试 API 接口。  
![](../Images/6d5ca9c6351d0c80a9fa3189eda3c5d9.png)  
**24、Octotree**  
github上查看代码的时候总是一层层进入再出来，有点麻烦，有了这个插件，你可以想浏览本地 IDE 一样浏览 Github。  
![](../Images/2c0a3e3a3f5cd848e1c19f9e6ec5cacf.png)  
**25、Table of contents sidebar**  
Table of contents sidebar 可以让你在阅读很长篇幅的文章时候清晰的看到文章轮廓。![](../Images/97567467b8ba936745b1f6a796f5e0d2.png)  
**26、Tampermonkey**  
俗称‘油猴子’，方便的管理插件的插件，你试试就知道如何的优秀。  
![](../Images/5f5d1421a0a0289b532fbf6cfc9fd826.png)  
**27、Code Cola**  
Code Cola是一个可视化编辑在线页面css样式的chrome插件。  
![](../Images/3df62ed53bf6ee648a7234fb35263313.png)  
**28、WEB前端助手**  
FE助手：包括字符串编解码、图片base64编码、代码压缩、美化、JSON格式化、正则表达式、时间转换工具、二维码生成器、编码规范检测、页面性能检测、栅格检测、JS运行效率分析等等你日常生活中不可缺少的插件。  
![](../Images/17f12a2daf0d84b9682f2663a6e4651e.png)
