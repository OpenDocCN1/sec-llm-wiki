# IE浏览器终于"挂了"，立碑纪念！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NzI5NDM4Mw==&mid=2247484890&idx=1&sn=fcafc33dc36080be5e04d9da1fbdb0bf&chksm=ea18ec9add6f658c35dd4dcbba19e26f93ae562adc9481b47f34cf74189d19cc8147e6d1c054&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1NzI5NDM4Mw==&mid=2247484890&idx=1&sn=fcafc33dc36080be5e04d9da1fbdb0bf&chksm=ea18ec9add6f658c35dd4dcbba19e26f93ae562adc9481b47f34cf74189d19cc8147e6d1c054&scene=27#wechat_redirect)

![](../Images/ee6fb6d3b938f663bfbc546346f8bd54.png)

  

今年以来，Edge浏览器切换到Chromium生态并重装上阵，并强势地捆绑推送给了几乎每一个Win 10用户。  
这样的效果也是显而易见的——短短几个月里，Edge的市场份额直接从吊车尾冲到了Chrome的后面，占据了原本属于Firefox万年老二的位置。  
2020年9月PC浏览器数据显示，Edge的市场份额已经达到了8.84%。  
伴随着Edge浏览器的崛起，另一方面，微软也毫不留情地加快了杀死“备胎”IE浏览器的脚步。  
![](../Images/c39ee76d61a6d5b435423968ec53a813.png)  
今年8月17日，微软发布声明称，将于一年后停止所有Office 365办公应用中对IE 11浏览器的支持。  
10月13日，微软再次宣布，停止Office 2016的主流支持。  
与此同时，德国媒体Dr.Windows爆料称，微软目前已向仍在使用IE浏览器的组织及用户发出了新的电子邮件警告。  
![](../Images/6b35238751a1bb3060137d7adc40e6c2.png)  
其内容为：“您之所以收到这封邮件，是因为我们的报告显示，您的组织可能正在使用Internet Explorer访问‘我的应用程序’、‘我的帐户’、‘我的访问’和‘我的组’。”

**微软警告，从今年11月13日开始，将终止对Internet Explorer的“我的应用”、“我的账户”、“我的访问”和“我的组”的支持。**  
所以，理论上说，如果你继续使用IE浏览器，将无法再登录你的账户，IE的各项功能基本“残废”。  
因此，微软建议用户抛弃IE浏览器，使用新版Edge浏览器或者Chrome、Firefox。  
另外，在今年8月份的时候，微软也在宣布了一项逐步淘汰IE浏览器的计划。  
  
计划显示，**到2020年11月30日，该浏览器将永远退役**，微软不会再提供安全补丁、更新或支持。  
  
微软用实际行动证实了一件事情：IE浏览器的时代终结了。  
  
![](../Images/1df7591a73c6033246aa2635aae9fe89.png)  
不过，众所周知的是，许多企业用户仍然依赖IE浏览器来处理尚未实现现代化的古老Web应用。  
如果大家以后在遇到这种特殊情况，**可以考虑在新的Edge浏览器中启用IE兼容模式。**  
当你进入需要IE才能访问的网站时，可以在右上角菜单中打开 “更多工具” - “在IE模式下重新加载”。  
启用IE模式后，所有的IE功能都可以在Edge浏览器中调用，包括IE的开发者工具、ActiveX控件等。  
![](../Images/0929641c0e8ad97c92068dcb91768b77.png)  
实际上，这几年里微软一直在大力推Edge，IE浏览器早已沦为一个备用的“兼容性解决方案”。  
所谓“兼容性解决方案”，就是有一些网站必须要用IE，其他浏览器都不行，那迫不得已只能勉强用一下。  
曾经的王者，如今沦落至此。  
![](../Images/313f291423457c10603554e3ea4590ae.png)

时间回到25年前，1995年8月16日，微软推出了第一代IE。  
随后，它成为了全球占有率最高的网络浏览器，在2003年占据95%的市场份额，几乎完全垄断了市场。  
然而，自从IE6开始，安全风险、兼容性差，以及最严重的速度太慢问题，令IE浏览器屡遭批评。  
2006年，IE 6被评为“有史以来第八糟糕科技产品”。  
于是，在提供了二十多年的服务之后，IE惨被“亲爹”微软杀死了。  
![](../Images/ee6fb6d3b938f663bfbc546346f8bd54.png)  
IE停止支持的消息传出后，不少网友表示，还是有些怀念的。  
不过，如果现在要让你真的去用回IE，估计没几个人会答应。  
怀旧归怀旧，IE浏览器作为表现不佳的产品，被市场淘汰是早晚的事。  
![](../Images/4a3ff58bec76095f3dd69744971c0893.png)  
  
正如同HTML5替代Flash，Win10操作系统替代WinXP与Win7，IE浏览器虽然缔造过辉煌，却也无法抵挡滚滚向前的历史车轮。  
一个时代结束了，但是新的时代才刚刚开始。  
![](../Images/1e5bc78ff630a259765850bf38f1c09e.png)
