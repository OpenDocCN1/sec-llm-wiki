Kubernetes项目被GitHub封存到北极

原文：http://mp.weixin.qq.com/s?__biz=MzI1NzI5NDM4Mw==&mid=2247484647&idx=1&sn=446cf8ed19516c5caff9e40ed23bdcc0&chksm=ea18eda7dd6f64b1683e250374a3bcc414502ed81bba7f480f9b1da1d9265f32c1e1895b3a3b&scene=27#wechat_redirect

今年中旬GitHub把代码打包运往北极保存，此次代码大概21TB，精选的优质开源代码，对于Kubernetes、Linux这种统治级项目肯定也一并打包到北极来。




 

目前GitHub继续扩展封存计划，现在要在全世界4个位置，封存17,000个精选开源项目。除了精选集储存库会被打印在piqlFilm胶卷上保存外，另外，GitHub还在胶卷上打印了随机抽取的5,000个储存库，供未来的历史学家，能够以概括性角度，理解这个时代的开源开发者所创建开源项目。

 

GitHub提到，因为目前所有新软件项目，其中有99％的项目都依赖开源代码，也就是说，这17,000个储存库是当今技术的基础，为了确保这些极重要项目的可存取性，他们依照LOCKSS（Lots Of Copies Keeps Stuff Safe）原则，创建了4个精选集（Greatest Hits），分散放置在全球4个角落。

 

这4个保存GitHub精选集代码库的位置，其中3个是目前世界知名的知识保护设施，包括英国牛津大学的博德利图书馆、埃及亚历山大图书馆以及美国的史丹佛图书馆，而第4个位置则是在GitHub总部。

 

这些精选集胶卷捐赠，都包含了两卷经硬化处理的缩微胶卷，使用与北极封存计划Arctic Code Vault相同的胶卷，这些胶卷被放在精美的盒子中，盒子外有3D打印技术所创造的艺术品装饰。

 

之所以要用美丽的盒子来封存这些精选集，是GitHub听取顾问建议的结果，他们认为，随着时间的流逝，人类倾向保存视觉上吸引人的文物，而Long Now基金会执行董事Alexander Rose也说「如果不把他弄得漂亮一点，结果注定失败」，因此GitHub委托了同是艺术家和工程师的Alex Maki-Jokela，以人工智能和3D打印技术，将传统美学元素融入到装饰中，制作4个供博物馆收藏的盒子。

 

GitHub从2019年开始，积极地进行开源项目封存计划，在今年7月的时候，GitHub使用特别设计的piqlFilm胶卷和保险柜，将21 TB的开源程序码封存到北极圈中，预计保存一千年，项目被送至北极圈封存的开发者，在GitHub上都会获得Arctic Code Vault徽章。另外，GitHub正在进行的Project Silica，也是一个代码封存计划，利用雷射光改变玻璃材质，借助石英玻璃抗电磁干扰、抗水和抗热的特性，来长久保存6,000个最受欢迎的代码库。

 

不只是GitHub积极的进行封存计划，非营利组织Internet Archive，也大规模的备份GitHub代码库，除了将代码库，完整封存成WARCs以及Web ARChive文件之外，还使用git clone指令复制代码库，借以保存评论、问题和元资料。
