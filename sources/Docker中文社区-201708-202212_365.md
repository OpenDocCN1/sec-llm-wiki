# VMware发布基于K8s管理的第一个新产品Tanzu

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NzI5NDM4Mw==&mid=2247484091&idx=1&sn=142d5d7724409408d5e20d41ca18fb26&chksm=ea18ebfbdd6f62ed520606d0b88b1e4b9dc3bfc16705930e4f80f15924dfae0ba9985f105e20&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1NzI5NDM4Mw==&mid=2247484091&idx=1&sn=142d5d7724409408d5e20d41ca18fb26&chksm=ea18ebfbdd6f62ed520606d0b88b1e4b9dc3bfc16705930e4f80f15924dfae0ba9985f105e20&scene=27#wechat_redirect)

![](../Images/1675f336a43f2a4f4d1e71c85693bef2.png)

  

  虚拟化龙头VMware过去20个月大力并购了多家K8s新企业或产品线，甚至在年度大会前夕，宣布以27亿美元买下了Pivotal，在VMworld第一天，VMware终于发表了第一款K8s新产品Tanzu，可以用来管理多云跨云架构下的K8s集群。  

   VMware去年大砸5.5亿美元下了K8s项目两位创办人Joe Beda和Craig McLuckie创立的Heptio企业，不只买下了一套跨云K8s平台，也拥有了K8s社区意见领袖。今年7月则收购了AI跨云部署管理工具BitFusion.io，以及AI引擎企业Uhana，来强化对企业AI应用市场的布局。8月更是大采购，除了买下无服务器安全企业Intrinsic和网络安全企业Veriflow之外，又花了21亿美元买下另一家网络安全公司Carbon Black，以及今年最大宗并购，以27亿美元买下Pivotal。这几起并购，可以看出VMware快速从跨云大规模部署、安全管理与治理、新兴AI应用需求，来抢攻K8s市场的企图。   就在VMworld第一天，VMware终于揭露了第一个新的K8s产品线Tanzu，第一个产品就是VMware Tanzu Mission Control（Tanzu任务控制器）预览版，可以通过单一控制机制，来管理部署在各地的K8s集群，包括vSphere、公有云，代管K8s服务或企业自行创建的定制化Kubernetes。不只可以直接浏览这些集群，也可检视集群的容量，来进行备份和安全性配置等管理。

   
  VMware强调，Tanzu将利用开源软件来打造，尤其关键技术是利用K8s的Cluster API来串连K8s平台，提供K8s集群的全生命周期管理机制。另外，Tanzu可以整合到Bitnami应用程序市场，快速部署预先打包的K8s应用。可通过Sonobuoy来验证和控制所部署的K8s配置，确保部署的正确性。可通过VMware本身的跨云效能监控平台CloudHealth来进行优化，或将K8s集群的信息整合到VMware云端监控服务VMware Wavefront上，提供一站式的视觉化监控管理。目前也可搭配Heptio的备份或备援工具Velero，或结合Heptio的ingress控制器contour来进行大规模K8s集群的存取控制。 Tanzu界面：
