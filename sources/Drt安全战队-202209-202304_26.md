## 开始安装kali linux

玩过kali的人，其实在树莓派安装kali很简单的官方下载地址：https://www.offensive-security.com/kali-linux-arm-images/**我下载的是这个**![](../Images/b0bb60d954725862cc7dff51ea9c0fd4.png)

  

下载完成要解压出来，也可以校验一下是否下载时缺少什么吗**记得要叫下载好的文件解压出来**用win32diskimager工具可以在百度上下载到![](../Images/d8162539b0a6da9f8793ed4208cb3088.png)

## 插入树莓派启动即可

如果没有屏幕，可以插入网线，

![](../Images/85a6d60589fe0cbe150b0746d38215b8.png)用Xshell 6工具去连接ssh![](../Images/3c2bd54cffc0b6e333de6f8cb5cc6685.png)![](../Images/5a811c7fa03c5a3d65988960c9a82630.png)点击连接然后输入**账号默认是root密码是toor**看一下已经连接上去了![](../Images/3fbd3396a9b0626d611a50a78cac4323.png)

  

这个我就用他默认的源

  

```
deb http://http.kali.org/kali kali-rolling main non-free contrib
deb-src http://http.kali.org/kali kali-rolling main non-free contrib
```

运行命令进行更新

```
apt-get  update
apt-get  upgrade
```

安装远程

```
apt  install xrdp
```

启动

```
systemctl start xrdp
```

设置开机自启动

```
systemctl enable  xrdp
```

连接![](../Images/ac699d8e5df6980387b59411503abbc0.png)设置中文  

  

```
dpkg-reconfigure locales
```

![](../Images/424f8a71fa8362cc6ec3872311d45e74.png)**解决乱码问题**乱码是应为缺少字体安装字体

```
apt-get install xfonts-intl-chinese
apt-get install ttf-wqy-microhei
```
