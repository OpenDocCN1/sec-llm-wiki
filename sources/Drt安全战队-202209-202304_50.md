信息收集：

前言：个人认为，渗透测试的关键就在于前期的信息收集。

以下仅为自己的思路和手段，如有更多欢迎补充，微信号:Admin\_Ran

首先得到的信息：公司名称

我们可以通过企查查等平台找到该公司的网址

![](../Images/2d685d9d15c6d95bd7457ff7ae2d0b02.png)

一般得到的会有官网。

子域名收集两个思路

1.OneForAll

2.Virustotal(很少人知道，但是确实好用。)

3.Fofa

4.零零信安

首先介绍OneForAll，很著名的子域名收集工具，几乎没有落下的。

GitHub: https://github.com/shmilylty/OneForAll

![](../Images/ec2f26548d08aff35176ff0682939111.png)

这是基本的使用语法。

python3 oneforall.py --target example.com run

即可进行子域名探测。

过程会多次验证，所以效果很棒。

收集到的信息保存在results文件夹里，以csv的格式存储。

![](../Images/60bed913e91cbb4e5614f639ae72a455.png)

其次就是virustotal，最常用的功能就是进行病毒检测，但是我们一直忽略了很强大的一个功能，现在我们一步步走下去。

然后当我们收集到子域之后，我们可以进行的就有很多。

首先来到的是cms和状态码的识别。

我这里用到的Finger，个人感觉还可以，有其他推荐的可以进行补充说明，我的微信:Admin\_Ran

然后的步骤就是fofa（会员真的超值），为什么用fofa呢，因为他很多其他资产我们都不知道，也很有可能是渗透过程中的一个突破点。

查询语法在fofa.info自行查看

下面介绍我自己经常用的方法。

（1）ico搜索

一个企业为了统一性，大概率会统一标志，所以可以直接拖入ico进行搜寻。

![](../Images/a59f22acf9428ad89a4c598b9b051a38.png)

（2）C段

ip="xxx.xxx.xxx.xxx/24"

没什么可说的，在工作进行不下去的时候可以尝试C段渗透，万一有以外的惊喜呢。

（3）ICP备案资产

![](../Images/b372c312b651744c5f5108418dd82038.png)

还有一些其他比较常用的语法，如title, body等语法，都非常实用。

另外，相似的平台还有齐安信的鹰图平台，360的Quake平台，censys平台，傻蛋平台（shodan），等查询语法类似。

如果数据量比较多，可以对应的工具进行查询。

我用的FofaCollect

Github: https://github.com/tangxiaofeng7/Fofa-collect/

![](../Images/d4678918cd8266fb42aa19d25b08428f.png)

Ctrl+c导出即可，注意，需要fofa会员。

零零信安

这是一个刚刚发展的平台，和fofa，傻蛋平台差不多。

值得一提的是，不用自己做查询。

说完这些还有一点就是关于公众号，小程序的信息收集。

公众号，小程序的收集在edu src中比较常用，是一个经常不被关注的点。

![](../Images/4339464f466585b53bad99acc717cdda.png)

然后就是整合社会工程学字典，这里用到的cupp这个工具

sudo apt install cupp

![](../Images/022d1ad871c3705e9d132cf69d349167.png)

使用方法cupp –i

\[+\] Insert the information about the victim to make a dictionary

\[+\] If you don't know all the info, just hit enter when asked! ;)

\> First Name: 名字

\> Surname: 姓

\> Nickname: 外号

\> Birthdate (DDMMYYYY): 出生日期

\> Partners) name: 配偶名字

\> Partners) nickname:外号

\> Partners) birthdate (DDMMYYYY):生日

\> Child's name: 孩子姓名

\> Child's nickname:外号，小名 

\> Child's birthdate (DDMMYYYY): 出生日期

\> Pet's name: 宠物名字

\> Company name: 公司名称

\> Do you want to add some key words about the victim? Y/\[N\]: y

\> Please enter the words, separated by comma. \[i.e. hacker,juice,black\], spaces will be removed: 受害者名字，用逗号隔开

\> Do you want to add special chars at the end of words? Y/\[N\]: n

\> Do you want to add some random numbers at the end of words? Y/\[N\]:

\> Leet mode? (i.e. leet = 1337) Y/\[N\]: 

会在当前目录生成一个文件，在后期进行弱口令破解的时候有可能会用到。

一般我们只拥有公司的电话，这就需要进一步搜索引擎的社工语法，网上的文章一搜一大片，这里就不作说明（懒）

当我们确定目标之后需要对服务器进行端口扫描，nmap的语法选择这里这不做阐述，因为懒，如果对时间要求比较着急的话，这里推荐一个扫描工具masscan

特点是扫描速度快，但是精确度不高。

具体用法masscan -p 1-65535 1.1.1.1

然后就是下一不的漏洞扫描之类的乱七八糟的
