## 第二步 MySQL提权

### 写入动态链接库

写入动态链接库可以分为下面几种情形：

*   存在SQL 注入且是高权限
    
*   plugin（插件） 目录可写且需要 `secure_file_priv` 无限制
    
*   MySQL 插件目录可以被 MySQL 用户写入
    

#### 1、存在SQL注入

这个时候就可以直接使用 SqlMap 来上传动态链接库

**注：因为 GET 有字节长度限制，所以往往使用 POST 注入来写入**

```
sqlmap -u 
```
