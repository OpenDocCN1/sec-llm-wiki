最近想练一波内网渗透，于是就fofa批量了一波weblogic，挑了一个国外的机子 这里用工具发现存在漏洞CVE-2017-10271和CVE-2019-2725![](../Images/8ee6277e51e29bbd0b9c6500a5dbcf24.png)这里我选择了用CVE-2017-10271，先命令执行一波，发现是台Windows的机子![](../Images/6c7b8715426723714af58db88ec5b27b.png)先传个冰蝎shell上去吧![](../Images/85c18dea4379ab433098790160d15fe8.png)冰蝎连接成功，先内网信息收集一波![](../Images/8f0160d50ab0b8001bc6fbd5ebdbb99e.png)一台winserver2008的机子，我们可以抓到明文密码，并且存在域，打了303个补丁(丧心病狂) 查看一下有无杀软![](../Images/41f56597b1690fac998a714a0bdb09b9.png)不存在杀软，那么Beacon就不需要免杀处理，我们可以直接上线CS(这里上线的Beacon配置了云函数，所以外网ip是一直变的)![](../Images/72e10914156aec142beea2e103c906d6.png)

# 内网信息收集

上线首先做个进程迁移，选择一个常见的进程注入 、![](../Images/e1cf2e0ea9e0590587f5b11fd19e5a37.png)![](../Images/416be94b5e41787d753c66f451cb0b5f.png)这里我们进行内网信息收集 内网首先目标是打域控![](../Images/82ac5c675f4c08aab5aea6993947bf90.png)好家伙，6个域控，之后查看域管![](../Images/834f0d80ac2fbf0cb71631b60eeb2e20.png)这么多域管，意味着我们只要能拿到一个域管的权限，这个内网就能漫游了 首先来看看能不能在当前机子进行提权，因为前面303个补丁，我感觉都提不动了 经过提权尝试后，发现常规的提权洞都打了补丁，没办法，当前机子是管理员权限，并且没有杀软，先来抓一波hash![](../Images/bea7bfc88998235463700c7c58729968.png)![](../Images/8e960a589a32296385e398138d596a9c.png)接下来，使用CS自带的扫下内网存活![](../Images/eb159dc957fd242fec037e03139d2f28.png)出现了两个域控，目标非常明确了，那么下面尝试用抓取到的hash进行psexec横向移动 经过多次尝试后，发现两个域控均不能横向，且其他机子无果 下面直接上内网大杀器MS17010! 使用Ladon快速探测存在MS17010的主机![](../Images/837a68ed64505656798cdbe04f611e98.png)![](../Images/12d78bba473fed738896adf9abc4c1c9.png)初步探测两个域控均存在MS17010,这里使用Landon自带的exp,发现利用失败。既然这样，那么上线MSF吧

# MSF和CS联动

首先看了下，目标是出网机器![](../Images/66139b136a76cba8969db150e2672ae4.png)之后尝试使用frp，nps等常规代理想把流量代理出来，发现无果，猜测目标做了限制，那么我们直接用公网的msf吧。CS4.3版本移除了foreign/reverse\_tcp，所以我建立了一个foreign/reverse\_http的listener，msf监听后，CSspwan，成功获得一个meterpreter![](../Images/b1a022d00877d75e41f87fb521a038d9.png)下面我们添加路由

```


run get_local_subnets
```

![](../Images/b401978551f7c450bec099832ccdd2ac.png)那么对ip为10.0.10.1的域控用MS17010打一波 这里使用ms17\_010\_eternalblue这个exp一直打不成功 那么我们换个exp打![](../Images/4a77af0cfd044b94745eabaf1ec521b1.png)成功获得一个session！![](../Images/641eb72cc757d0d7674f722e393d2ca9.png)下面我们把这个刚刚获得的session转发回CS![](../Images/f1b7ec8b61c2d61f8137e005c82531e4.png)成功反弹![](../Images/27c32a41975465c5299f60925aeca437.png)

# 横向其他域控

我们已经拿下一台域控了，那么其他5台就可以都拿了 我们先对这一台做个信息收集 老样子先进程迁移一下![](../Images/dcc2cfada7c3ed05f5bb3aea7498c5da.png)抓下hash吧![](../Images/0607eb982870162dd54eb608c9b31071.png)好家伙，为空！！！！那么直接试下横向呢![](../Images/49aebcadc58e2d7690c744b50a2c6d17.png)也不行！回想在和MSF联动的时候，本地路由还有个26网段，那我们在基于当前域控再做一波内网探测![](../Images/310b200cbb6c0ca7878cef41f9870d60.png)又发现一个DC 再试试横向一下，仍旧失败![](../Images/d945b2c09ba5b2da8cff3d3a148d212e.png)后来尝试了ipc，wmi也不行 这时，我突然想到，既然已经拿到域控了，那么我自己创建个域管不就可以了吗![](../Images/b0123e860ea9c3b41571c8055343b7b8.png)![](../Images/486c21e2bc28cfe8b40ed87cd7740599.png)那么换域管登录，这里我尝试在拿到的域控切换，但是不行，那么我们就换那个跳板机吧![](../Images/efec57f21a93eed681ea775eaa608040.png)成功切换 那我们以域管身份的session进行横向![](../Images/de5671ce4110c2f56186b47cdd4afcc1.png)![](../Images/a311711dee45737a85725835b705e006.png)同样另一台域控![](../Images/79cc068e6894ecd78b581132cbdf2d85.png)在第三台域控可以抓取全部hash![](../Images/2b515b0e97bc31790163ff51383a54f8.png)![](../Images/9e0708a336597051d9560c337f6215e2.png)后面三台域控发现ping不到且探测不到，那么对已有的机子做个简单的权限维持后，本次内网渗透结束。
