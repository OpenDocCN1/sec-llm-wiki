**半自动化的资产收集：**  
域名/IP/需要交互的系统  
当拿到目标的时候，首先需要利用天眼查获取目标企业结构，有子公司就获取100%控股子公司，分别再查看其知识产权/网站备案：![](../Images/7b5f655338b6a55cde01cd824175b59a.png)  
例如拿到域名：A.com，B.com，C.com  
使用OneForAll对这些域名进行处理获取若干子域名。  
shmilylty师傅的项目OneForAll![](../Images/7f844de9546befe5c148984f2a6f09ab.png)  
使用Eeyes对OneForAll收集到的subdomain数据进行处理，获取其中真实IP并整理成c段。hihuang师傅的项目Eeyes![](../Images/5ce4f7aa2f0d8f6ac95bd8c5139a4e88.png)![](../Images/a4e08c9c3ed3de9c6e9e23d97253343a.png)同时cIPR可以将域名转为ip段权重，也可以做上述功能。  
canc3s师傅的项目cIPR![](../Images/f449621918eec770874262cd4d8d38ad.png)对C段IP的扫描，使用nmap对C段扫描速度有点慢，可以使用ServerScan或是fscan，外网扫描也很丝滑。  
Trim师傅的项目ServerScan![](../Images/6ce52d44cdbe70a493d4662d89895d09.png)shadow1ng师傅的项目fscan![](../Images/ac69ba62a389376c56549686965dffdf.png)APP中的域名/IP：  
在天眼查里面查到的企业关联信息，可以用这些企业信息在app商店里面搜索。  
也可以在官网的办公平台找找有无内部使用的app，如企业自研的办公软件。  
APP搜索平台  

![](../Images/113bc237b72cfb5e4695c3077e0ec288.png)

使用AppInfoScanner对拿到的APP进行信息收集。  
kelvinBen师傅的项目AppInfoScanner![](../Images/166f32bcb8e298635a486074fd239a46.png)使用Fofa搜集资产：  
例如杭州市HVV  

```
title\="杭州" && country\="CN" && region!\="HK" && region!\="TW" && region!\="MO" && type\="subdomain"
city\="Hangzhou" && country\="CN" && region!\="HK" && region!\="TW" && region!\="MO" && type\="subdomain"
body\="杭州市XXX" && country\="CN" && region!\="HK" && region!\="TW" && region!\="MO" && type\="subdomain"

```

这种搜法搜出来的目标较多，主要是为了配合后面的各大OA系统，Shiro等等的识别。  
Fofa的语法也比较多师傅们可以自行发挥。![](../Images/ef2908e5ca82f3085a2b9e6f88a46454.png)需要交互的系统：

```


site:xxx.cn inurl:reg 
```

**网站类：**urls列表

shihuang师傅的项目EHole

**交互类系统：**  
前期收集的小程序啊，公众号啊，APP啊，后台啊，要注册的系统啊，与后台有动态交互的系统啊。  
只能打开burp开始肝。关注文件上传，fastjson，shiro，注入，命令执行，反序列化(rO0AB)等等。  
其中推荐pmiaowu师傅的两款burp插件：BurpFastJsonScan和BurpShiroPassiveScan  
burp插件挂着，测试的时候防止漏掉。  
还有key师傅的基于BurpSuite的请求高亮标记与信息提取的辅助型插件HaE。  
攻防演练中敏感数据也能拿分。  

```


https://github.com/pmiaowu/BurpShiroPassiveScan
```
