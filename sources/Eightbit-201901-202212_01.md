# 16 异常停止

根据题目提示，异常停止，应该是有异常数据写入到了特殊的块中，从而引发异常停止。

首先筛选出Modbus协议；接着在Modbus数据包中寻找write single coil，观察发现192.168.3.130不断向192.168.3.164发出写入请求，因此推断192.168.3.130为上位机。继续分析数据包，筛选modbus.func\_code == 0x05，发现了第281帧，上位机发出请求，向data=0000 写入了 0x05信号，导致单线圈关闭。尝试提交，得到flag{281}。
