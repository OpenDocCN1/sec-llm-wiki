# 0x1 分支原因

1.  Oracle不会为openjdk的lts分支发布更新以及维护
    
2.  Oracle只会每个半年发布一次openjdk版本
    
3.  linux上有统一的组织/gnu/开源社区来维护openjdk的lts分支
    
4.  由于windows的复杂性,很多第三方公司都会提供openjdk的lts在封装版本
