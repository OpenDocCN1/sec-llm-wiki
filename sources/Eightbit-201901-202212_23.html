构建Android 内核比构建Android 系统简单许多，基本只需要安装官网给出的步骤走就可以了。

官网地址：https://source.android.com/setup/build/building-kernels




01

构建内核前提



在构建内核之前需要先AOSP构建完成。



02

repo方式



下载源代码和构建工具


mkdir android-kernel && cd android-kernel

repo init -u https://android.googlesource.com/kernel/manifest -b android-msm-wahoo-4.4-android10-qpr3

repo sync




构建内核

build/build.sh


内核二进制文件、模块和相应的映像位于 out/BRANCH/dist 目录下。


可能的错误


openssl/bio.h file not found



解决办法：sudo apt install libssl-dev。

soong_zip: cammand not found


soong_zip工具是由之前的安卓源码编译出来的，我们可以设置添加环境变量。


export PATH=/home/koifishly/WORKING_DIRECTORY/out/soong/host/linux-x86/bin:$PATH


总结

能编译成功，也能刷入到手机中，但是没有修改内核源码。



03

Git方式



https://source.android.com/source/building-kernels?hl=zh-cn

https://blog.csdn.net/qq1045553189/article/details/120956833


下载源码


首先需要看一下内核的版本，在上文编译AOSP10源码并刷入手机后，可以在手机中看到内核版本。



下载该内核版本对应的源码。


git clone https://aosp.tuna.tsinghua.edu.cn/android/kernel/msm.git

git checkout 9cb5a8813a81


编译



  • 设置编译环境


export PATH=$PATH:/home/koifishly/WORKING_DIRECTORY/prebuilts/gcc/linux-x86/arm/arm-linux-androideabi-4.9/bin
export PATH=$PATH:/home/koifishly/WORKING_DIRECTORY/prebuilts/gcc/linux-x86/aarch64/aarch64-linux-android-4.9/bin
export PATH=$PATH:/home/koifishly/WORKING_DIRECTORY/prebuilts/misc/linux-x86/dtc
export PATH=$PATH:/home/koifishly/WORKING_DIRECTORY/prebuilts/misc/linux-x86/libufdt
export PATH=$PATH:/home/koifishly/WORKING_DIRECTORY/prebuilts/misc/linux-x86/lz4
export ARCH=arm64
export CROSS_COMPILE=/home/koifishly/WORKING_DIRECTORY/prebuilts/gcc/linux-x86/aarch64/aarch64-linux-android-4.9/bin/aarch64-linux-android-
export CROSS_COMPILE_ARM32=/home/koifishly/WORKING_DIRECTORY/prebuilts/gcc/linux-x86/arm/arm-linux-androideabi-4.9/bin/arm-linux-androideabi-
export CC=/home/koifishly/WORKING_DIRECTORY/prebuilts/clang/host/linux-x86/clang-3289846/bin/clang


  • 编译


make wahoo_defconfig
make -j8


  • 编译完成后文件保存在 /arch/arm64/boot/Image.lz4-dt


错误

修改drivers/thermal/thermal_core.c文件。
