代理实现拓扑

一、功能

    proxychains 是一个支持http 、socks4 、socks5 代理的强大代理工具（支持身份认证）  chain是代理链的意思.    

二、配置参数说明

    1、配置文件存放在/etc/proxychains.conf中
    2、代理类型
     dynamic_chain     自动跳过死代理
     strict_chain      每个代理都使用户、不管死活
     random_chain    随便挑代理用
    3、代理dns请求
            proxy_dns
    4、跳过本地地址
            localnet 127.0.0.0/255.255.255.0
    5、超时时间
              tcp_read_time_out  15000   
             Tcp_connect_time_out 8000
    6、代理列表 代理开始的标记
            [ProxyList]
    7、代理格式
        type    host    port    [user    pass]
        socks5    127.0.0.1     1080

三、安装配置

修改apt源为阿里源  vim /etc/apt/source.list

安装    proxychains   apt-get install proxychains -y

 

我这里有一个谷歌云的国外服务，我本地服务器与谷歌云服务器通过建立ssh隧道建立socks5服务器连接ssh -N -f -D 1080 root@34.80.40.113   这里我将本地127.0.0.1的地址和1080端口作为socks服务的连接地址和端口，回车提示输入云服务器的密码

查看端口绑定状态，是否绑定成功

隧道建立完成之后，我就获得一个基于sock5通信的协议连接隧道修改proxychains的配置文件    vim /etc/proxychains.conf 做如下更改，保存退出。

代理连接测试，我这里请求的是google的官网首页。不进行proxychains代理的情况下，请求不成功。

进行proxychains代理，请求成功。并且首页被保存在root目录下。
