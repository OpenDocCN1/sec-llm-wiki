#### 三、安装配置

> 修改apt源为阿里源  vim /etc/apt/source.list

![](../Images/5400b4e581033a7a4b869a2967676680.png)

> 安装    proxychains   apt-get install proxychains -y

 ![](../Images/190aa476013b7ff50fab566b719d5c1c.png)

> 我这里有一个谷歌云的国外服务，我本地服务器与谷歌云服务器通过建立ssh隧道建立socks5服务器连接ssh -N -f -D 1080 root@34.80.40.113   这里我将本地127.0.0.1的地址和1080端口作为socks服务的连接地址和端口，回车提示输入云服务器的密码

![](../Images/05cb8e80efa4de390a58c1060cca20e8.png)

> 查看端口绑定状态，是否绑定成功

![](../Images/cb05920e7545ef399e3ec70b47749e84.png)

> 隧道建立完成之后，我就获得一个基于sock5通信的协议连接隧道修改proxychains的配置文件    vim /etc/proxychains.conf 做如下更改，保存退出。

![](../Images/c41201288a24b0f88567edbc64f2f2b2.png)

> 代理连接测试，我这里请求的是google的官网首页。不进行proxychains代理的情况下，请求不成功。

![](../Images/6f542b4430b3c98477ae6da0ab13564e.png)
