解压

tar xvJf dpdk-17.08.1.tar.xz

配置环境变量

export RTE_SDK=<dpdk主目录> 
export RTE_TARGET=x86_64-native-linuxapp-gcc

每次重启会需要重新配置环境变量，可以直接写到dpdk.rc中

进行配置

cd ~/.dpdk/usertools/
./dpdk-setup.sh

首次安装的操作系统会缺少某些重要的配置文件和编译库

sudo apt-get install libnuma-dev make

四步配置
（1）这里选择13（x86_64-native-linuxapp-gcc），进行编译
（2）编译完成后，选择16， 插入igb_uio模块
（3）选择19，配置大页内存（非NUMA），选择后会提示你选择页数，根据情况进行输入
选择27可以查看大页的情况
（4）绑定网卡，选择21，查看当前网卡状况
（5）选择网卡绑定，选择22
