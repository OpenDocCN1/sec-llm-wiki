# Linux Kernel 4.1.12 LTS发布

在公布且开放Linux Kernel 4.2.5版本下载之后，Linux核心开发者葛雷格·科罗哈曼（Greg Kroah-Hartman）向Linux用户分享了Linux Kernel 4.1 LTS的第12个维护版本。作为长期支持分支，Linux Kernel 4.1在未来两年时间内还将会收到关于补丁和安全修复的维护版本更新。根据附加简要日志，Linux Kernel 4.1.12 LTS和上个版本（4.1.11 LTS于2015年10月22日发布）仅相隔4天时间。

根据日志文件显示共计有54个文件改动，共有315处插入和189处删除，主要新增了对ARM64,PowerPC(PPC),Sparc和x86硬件架构的修复、改善AMD GPU驱动，更新包括I2C,MD,MFD,PINCTRL,网络（网口和PPPoE）和Xen等驱动。科罗哈曼表示：“我们宣布了4.1.12内核。所有4.1内核分支用户必须尽快升级。已经升级的4.1y Git树可在git://git.kernel.org/pub/scm/linux/kernel/git/stable/linux-stable.git linux-4.1.y，或者在网页浏览器中打开http://git.kernel.org/?p=linux/kernel/git/stable/linux-stable.git;a=summary进行查看。”
