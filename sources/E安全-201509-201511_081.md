# 2015杭州•云栖大会倒计时 十大亮点不容错过

> 距离2015杭州·云栖大会召开还有最后两天，从组委会获悉，昨天官方报名通道因人数爆满已提前关闭，有近20000开发者报名，逾3000家云上企业将到场。这也将成为国内外规模最大的一次云计算大会。
> 
> ![](../Images/a4f33b4c16f9e0c165b70e600d79feca.png "1")
> 
>   
> 
> 云计算和大数据技术正在释放科技的想象力，越来越多的企业先行者，开始在云平台上撬动世界的科技变革。而本次大会现场，到底会有哪些精彩内容？小编带你提前探营。
> 
>   
> 
> ![](../Images/f9734b4a721788f9ef1d6d5134a96c2e.png "1")
> 
>   
> 
> **亮点一：小咖们是本次大会的主角**
> 
>  
> 
> 之所以把这一亮点放在最前面，是因为无论多少大咖，多少知名企业，那些奋斗在一线的创业者和开发者，才是本次大会的真正主角，也契合了云栖大会“互联网、创新、创业”的主题。
> 
>   
> 
> 从阿里云官网看，包括小咖秀、格灵深瞳、云上安心等一大波互联网创新企业将亮相云栖大会，并发布“创业者，大梦想”的主题演讲。“正是通过他们的创新，云计算正在帮助更多的人，他们是改变世界的实践家。”阿里巴巴集团CTO王坚表示，云栖大会的主角永远都将是科技创新者，“云计算让世界变得更平，释放出人类的创造力，云栖大会就是创造力的集中展示平台。”
> 
>   
> 
> **亮点二：大咖来为创业者赋能**
> 
>  
> 
> 据悉，本次大会获得了浙江省政府的高度认可与支持，包括杭州浙江省省长李强、杭州市委书记赵一德等均会出席并发表重要讲话，这也显示出浙江省政府对创新创业和新技术发展的大力支持。而浙江省在响应总理“大众创业，万众创新”的号召下，正成为创业者的一片热土。
> 
>   
> 
> 此外，包括阿里巴巴集团董事局主席马云、阿里巴巴集团CTO王坚、阿里云总裁胡晓明等来自阿里集团内的大咖们也会悉数出席。
> 
>   
> 
> 大会当然也少不了各行各业的专家与学者代表：富士康集团总裁郭台铭、中国科学院院士潘建伟、海尔集团首席流程官佘敏、intel中国研究院院长吴甘沙、中国国际广播电视台总工程师王联、人民银行科技司副处长吴金海、中石化资深架构师陈海龙、华大基因研究院副院长方林、Gartner全球高级合伙人赵光博士……这样的阵容，堪比全球技术领域的“奥斯卡红毯”。
> 
>   
> 
> 这些大咖们的演讲与思想碰撞总能引发行业思考与讨论，他们的到来，也将为众多的创业者带来最前沿的资讯与技术分享。
> 
>   
> 
> **亮点三：云计算遍地开花**
> 
>  
> 
> 说完了人，我们再来看看大会十大展区上有哪些企业亮相。
> 
>   
> 
> 在智慧民生展区，云上贵州、数据浙江，北京市最高人民法院都带来了“智慧城市”发展的硕果。在智能物联展区，货车帮、阳光电源、德澜科技等企业将让人们看到，物联网距离我们的生活越来越近。在生命科学展区，华大基因、华康移动医疗等健康企业也悉数到场，一同探究人类基因的秘密。在DT技术展区，用友、东软、浪潮、中软国际等企业也将为创业者带去最新的产品与技术成果分享。
> 
>   
> 
> 此外，云聚金融、未来生活、云游纵横、云领视界和云栖小镇展区也将有一大波金融、游戏、O2O、多媒体以及创新企业出席。
> 
>   
> 
> 云计算的百花齐放，也将带来蝴蝶效应。从来自四面八方的参展企业和嘉宾看，云计算的赋能已经逐步深入到各行各业，开始从根本上影响和改变人们的生活。
> 
>   
> 
> **亮点四：计算无国界**
> 
>  
> 
> 组委会官方消息，大会吸引了超过200家海外科技创新企业参与，其中有20余家将在大会上展示创新创业成果，数量为历年最多。
> 
>   
> 
> 全球云计算市场正在高速成长，基于云计算平台的科技创新层出不穷。今年在科技创新领域非常火热的Docker和Mesosphere也将在云栖大会上展示成果。大会上专门为海外企业开辟展区，Intel、PCCW电讯盈科、新加坡电信、迪拜Meraas控股、迪拜主题公园等知名企业，以及Docker、Mesosphere、Quixey、Rovio、RemarkMedia等备受热捧的创业团队，将在国际展区中与国内外开发者交流展示基于云计算的创新。
> 
>   
> 
> ** 亮点五：逾30场分论坛，3场开发者大赛**
> 
>  
> 
> 云栖大会有30多场论坛，其中有十几场论坛由各个生态合作伙伴定制，比如英特尔、机器人学会、第一财经、用友、洛可可等等。不是阿里云，而是这些云计算的使用者恰恰成就了云计算。
> 
>   
> 
> 此外，大会围绕不同的主题，设置了垂直行业创新的论坛，比如电商、金融、游戏、医疗、多媒体、政务等等，但云栖大会并非推销阿里云的行业解决方案，而是让行业代表现身说法，直观呈现云计算如何改变行业固有的模式，带来新的价值。
> 
>   
> 
> 此外，还有天池数据大赛颁奖、创客+“诸神之战”决赛和阿里云开源编程马拉松决赛等三场“巅峰较量”将在14、15日的云栖大会上上演。创客+大赛上还有来自海外的创客，与国内创客同场竞技。
> 
>   
> 
> ** 亮点六：阿里云发布全新品牌定位**
> 
>  
> 
> 从北京T3航站楼、广州白云机场到杭州萧山机场，一路上都是本次云栖大会的广告，上面的宣传语似乎也提前泄露了阿里云全新的品牌定位：“计算，为了无法计算的价值”。
> 
>   
> 
> 除了这句“计算，为了无法计算的价值”的Slogan外，还有一系列以“移动互联”、“金融”、“赛事直播”、“生命科学”、“新能源”为主题的平面广告，这也是阿里云首次发出清晰的品牌声音，用另一种方式诠释了自己的实力以及更为普世的存在价值。
> 
>   
> 
> 以“生命科学：发挥计算的力量，革新基因测序技术，解码生命的奥秘”为例，中国是世界出生缺陷率最高发地区之一。每年1600万至2000万的出生人口中，有80万至120万出生缺陷儿。而基因测序能够显著降低新生儿的出生缺陷率。一个人的基因组检测大约会产生90Gb的数据，而40万个样本所需的庞大计算资源只有云计算才能提供。
> 
>   
> 
> ** 亮点七：国内首款量子通信产品或将问世**
> 
>  
> 
> 早在今年7月，阿里云就宣布联合中科院在上海成立一个全新的实验室，结合阿里云在经典计算算法、架构和云计算方面的技术优势，以及中科院在量子计算和模拟、量子人工智能等方面的优势，共同开展在量子信息科学领域的前瞻性研究，研制量子计算机。而据本次大会内部工作人员透露，双方的合作已经取得了实质性进展和技术突破，国内首款量子通信产品或将问世。
> 
>   
> 
> 此外，在7月22日的北京·云栖大会上，阿里云一口气发布了11款新产品，并预告了未来3个月内即将上线的10个产品和服务。而本次杭州·云栖大会恰恰与北京的大会相隔3个月，可以预见，15日上午的主论坛预告的重磅产品发布，也将延续北京·云栖大会时的密集和震撼程度。同时，阿里云还将针对业内热门的话题，发表自己的见解和产品，例如混合云、数据安全等等。
> 
>   
> 
> ** 亮点八：打造全球最high的开发者之夜**
> 
>  
> 
> 如果仅仅是学术研讨和技术的碰撞，远不能称之为“盛会”。这次云栖大会，阿里云在14日晚上还特别安排了“开发者之夜”。让“程序猿”和“工程师”在经历了一天的科技烧脑后，可以尽情放松，享受另一种云计算的魅力。
> 
>   
> 
> 当晚，来自中国本土的少女励志天团Lunar和来自韩国的女子流行演唱组合Bambino将彻底high翻现场。此外，由阿里云用户晨之科带来的全息投影技术也将在此环节亮相，但到底会把谁放上舞台，还要在当天揭晓。
> 
>   
> 
> **亮点九：各种呆萌、前沿、好玩的高科技都来了**
> 
>  
> 
> 本次大会不仅设置了机器人专场，参展的200余家企业和组织还将把自家最前沿的高科技产品与技术带来现场。小编获悉，呆萌的情感机器人Pepper也将出场。Pepper内置感情引擎，能够感知人类的情绪并做出反应。如果Pepper得到夸奖，它会变得很开心。或者你仰脸做出要亲它的姿势，Pepper也会仰脸回应。现场观众将有机会与它进行亲密互动。
> 
>   
> 
> 此外，据大会相关人士透露，现场还将有全息影像、VR(虚拟现实)、生物识别、深度学习等一系列炫酷科技供开发者们“脑洞大开”。
> 
>   
> 
> **亮点十：举办地云栖小镇什么来头**
> 
>  
> 
> 不同于其他办在会展中心的云计算大会，此次大会选择了名不见经传的“云栖小镇”，而云栖小镇不是景点也不是地名，它就像中关村不是“村”，硅谷不是“谷”一样。云栖小镇是一个云计算产业生态聚集地，位于杭州西湖南部。
> 
>   
> 
> 最初，阿里云在云栖小镇成立了创业创新基地，并与30逾家代表企业一同成立了云栖小镇联盟。在云栖小镇联盟成员中，既有20000余人的中软国际，也有仅有3个人的博客园，既有浙江省交通信息中心，也有玩蟹科技这样的网游创新企业。再后来，富士康、Intel、洛可可、创客、学术大牛等等纷纷入驻云栖小镇，这里也聚集了越来越多的创业者。这次大会，还特别设立了云栖小镇展区，包括淘富成真、上海交通大学等也将集中展示他们的创新成果。
> 
>   
> 
> 这就不难理解，将云计算大会办在这里，是希望更接地气儿，成为真正属于开发者和创业者的云计算大会。
