# 【智库】美国最新研究：利用物联网提高军事作战效能

> 近日，美国战略与国际研究中心发布题为《利用物联网提高军事作战效能》的报告，全文52页，概述物联网技术在军事领域的发展历史、应用和现状，并指出了不足之处和面临种种挑战，并提供了一些建议。
> 
> ![](../Images/f3f06279261b23f725743284e7094b7a.png)  
> 
> 物联网正在改变着组织机构对于日常业务和工业流程进行沟通、协作以及协调的方式。实践证明，对于那些需要管理大量的资产和协调复杂的、分布式进程的组织而言，采用物联网技术再适合不过。无论从监测工厂内的设备到跟踪供应链，还是对复杂并且时常有危险的工业流程进行自动化管理,物联网技术优化设备的性能，提高了效率，并有效保护工人的生产安全。
> 
>   
> 
> 早在几十年前,美国国防部(DoD)在开发传感器、计算机网络和通信技术方面发挥了关键作用。这些技术构成物联网的基础。在20世纪90年代末,美国就设想了以“网络为中心”的作战构想,认为必须整合物理、信息、认知这三者，增强信息共享和协作。这一作战设想推动了国防部近年来的改革，并推动了物联网相关技术在关键领域的应用。
> 
>   
> 
> 如今美国军方正致力于为其雇员、文官和军人提供商业智能手机的基本功能。国防部虽然将继续推动先进的传感器和控制系统的创新,但物联网技术的部署落后于其他日常工作,而物联网技术有望提高作战效能,并为国防部节省大量开支。
> 
>   
> 
> 如何使美军能够更好地利用物联网来提高作战效能？带着这个问题，我们启动了这个研究项目。我们的研究考察了现有军事物联网组件系统的不足之处，并试图找出部署更多广泛物联网技术所面临的种种挑战。我们的研究成果和建议来自于与29位政府和业内高管以及行业专家的深度访谈。
> 
>   
> 
> 当前物联网技术在军事领域的应用：在军事领域，部署物联网相关技术主要集中在作战应用上。C4ISR系统（指挥、控制、通信、计算机、情报、监视和侦察)使用了部署在各种平台上的数以百万计的传感器，为高级指挥官和为各军种作战人员提供态势感知能力。在射击指挥系统中,通过端到端部署网络化的传感器和数字分析工具，使得可对威胁实现完全自动化实时响应,精准定位并输出超强火力。
> 
>   
> 
> 军方也在非作战设备上也部署了一些物联网技术,用来提高后端流程的效率和有效性。国防后勤局和运输司令部使用电子标签来跟踪中央物流中心之间的运输并进行管理库存。物联网也应用到一些培训和模拟练习,通过网络激光和可穿戴接收器模拟现场作战。国防部还大力投资移动技术,包括战术运动战——作战人员和企业和其他非战术移动项目。
> 
> ![](../Images/7cd1509e2afc32026f0fa23f7cad05cc.png)
> 
> 主要障碍：然而,现有和计划军事物联网系统存在明显的不足之处。多数军事系统不能够充分利用物联网堆栈,包括从传感器连接到数字分析和自动响应。数据收集和共享往往不依靠网络化的传感器，但是依靠人工输入,并且不会对大量搜集而来的数据进行分析或投入使用。大部分有价值的物联网都依靠自动化技术,使得系统对数据的反应比人类更加快而且精确。目前而言，很少有军事系统能够实现全自动响应。
> 
>   
> 
> 在军事领域，物联网技术的开发、部署和应用，面临诸多难题。安全是最大的挑战。大量的简易设备和应用程序会增加电子和网络战的脆弱性。进一步部署物联网技术还需要在增强连通性、数字分析，提高互操作性方面进行更多投资。
> 
>   
> 
> 采用物联网还需要关键利益相关者的支持，但即使是最开放和远见的指挥官也很难理解并回答如何将新技术解决现有的难题。在私营部门,物联网解决方案可大幅节省成本。然而,军方不愿为了长远利益而将有限的预算用于前期开发和部署新设备和应用程序上。国防部与私营部门存在着文化冲突,国防部的知识产权和出口限制使私营技术部门望而却步。
> 
>   
>

> 一些建议：在军事领域，虽然应用物联网面临诸多挑战，但是物联网技术有望彻底改变现代战争。物联网数据和自动化技术可提高作战人员的杀伤力和生存能力，并降低成本和提高效率。在现代战争中，敌军正变得越来越强大，而美国国防预算面临全面削减的。物联网技术可以有助于美军适应当前这种情况。
> 
>   
> 
> 投资成本较低的物联网应用：美军开发和部署更多物联网应用会耗费大量时间；不过在物流网的某些领域，通过使用私营企业的现有技术和借鉴商业公司的运作方式，军方可节省大量费用。
> 
>   
> 
> • 状态检修：国防部应使用车载传感器改造其车辆，监控发动机性能和部件状态，以利于零部件的状态检修和按需订购，并减少意外故障的发生。
> 
>   
> 
> • 实时管理车队：通过采用物联网设备进行实时管理车队（包括地理位置，状态，燃油效率和重量和货物传感器），燃油成本可降低25％，船队利用率提高20％。
> 
>   
> 
> • 库存管理：部署电子标签和标准化条形码以追踪设备。这使得供应链实时可视，并使得军方可以按照实际需求订购配件及耗材。
> 
>   
> 
> • 基地管理和能源效率：智能温控器为用户节省10％-15％的加热和冷却费用;加热和冷却能源利用效率提高50%，则可以每年为国防部节省7亿美元的能源费用。投资更多物联网技术：如今国防部应该投资多个关键技术，以便未来更好地部署物联网。
> 
>   
> 
> • 扩展连通性：军方应投资于弹性的、灵活的能力，扩展在拒止环境下的网络连通性，包括高空通信中继平台，立方体卫星（小型卫星）技术和商业通信卫星（在适当情况下考虑）。
> 
>   
> 
> • 为商业现货设备和应用提供共同性安全保护:军方应该投资可用的新安全技术,以保障商业现货设备和应用的安全。这些技术包括云技术,可扩展的安全措施,而非保障个体系统的安全。
> 
>   
> 
> • 制定共同的标准和协议:如果要打造覆盖企业和国防部的物联网能力，广泛的共同标准和协议必不可少。标准和协议使得新的物联网设备得以集成到国防部的数字生态系统中。此外军方应该考虑召开开放性采办博览会:军方应当考虑在硅谷举办开放性技术博览会,要求科技社区就如何更好完成军事任务提供建议,而不是要求他们仅仅满足预定的要求。
> 
>   
> 
> • 技术试验台:军方应该考虑创建专用的技术试验台。该技术试验台由真实训练环境下的现役军人组成，寻求和试验可变革任务完成方式的技术，并加强作战人员和技术开发商之间的联系。
> 
>   
> 
> • 采用敏捷开发:敏捷软件开发(ASD)是创新技术公司的常见标准，强调用户和开发者进行不间断的双边沟通。它允许需求和能力得到频繁调整和更新，而传统的军事合同强调正式报告和更多监督。
> 
>   
> 
> • 平台即服务合同:军方应该与私人提供商保持联系，提供网络服务，而无需构建和维护基础设施,从而为供应商创造一个更灵活的框架以调整系统，便于国防部不断更新系统并整合最新的能力。
> 
>   
> 
> **结论：**物联网是一个创造价值和数据的工具。在私营部门,它正在改变产品和服务形成和发布的方式,以及管理和维护基础设施的方式。物联网在商业领域产生了重大影响，大大提高了效率和效能。国防部有望通过从与私营部门合作,采用私营部门的成熟方案，抓住机遇，并从中受益。
