WarBerry创建的目的：WarBerry为了“红队判研”（red teaming）而创建，因为在“红队判研”中，我们想在短时间内尽可能隐秘地获取更多信息。只要找到一个网络端口，插入即可。脚本的设计主要是通过找到避免网络内噪声被发现且尽可能有效的方法加以实现。WarBerry脚本集扫描工具于一体，从而实现该功能。

用法

获取所有选项和RPi使用：


安装

可选：将树莓派（RaspberryPi）的主机名更改为WarBerry。

sudo nano /etc/hosts

sudo nano /etc/hostname

重启WarBerry使更改生效

在/home/pi在/home/pi下创建目录

sudo mkdir WarBerry

在/WarBerry重创建结果子目录

sudo mkdir Results

通过克隆Git存储库下载WarBerry：

sudo git clone https://github.com/secgroundzero/warberry.git

重要

在MAC地址过滤的情况下，该工具默认列举/home/pi/WarBerry/warberry/discover下指定的子网。这样做是可以让工具运行地更快。如果要列举更多子网或在此文件添加子网，或在rest_bypass.py修改第154行，以便它不会从文件读取。
