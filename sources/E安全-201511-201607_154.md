# 如果我是赛门铁克公司下一任CEO

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MjA1MzkyNA==&mid=2655292931&idx=1&sn=8cf6ddf3c7bd616ca1b581bcc716e9d1&chksm=f02ff248c7587b5efde89198340d1201c0beb2d47f49e7a7bbc5f2fafef287d5f2bc11856ad6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655292931&idx=1&sn=8cf6ddf3c7bd616ca1b581bcc716e9d1&chksm=f02ff248c7587b5efde89198340d1201c0beb2d47f49e7a7bbc5f2fafef287d5f2bc11856ad6&scene=27#wechat_redirect)

> **2014年遗留的挑战仍然存在。赛门铁克公司必须强调服务、收购前景光明的初创企业、建立合作伙伴生态系统并简化自身产品与运营体系。**

**![](../Images/2f54df6ec7c4217bdc78419f1f5ecfc6.png)**

不久之前我读到彭博社发布的一篇文章，指出赛门铁克公司将削减其季度营收水平预期，同时宣布该公司CEO迈克尔·布朗即将离职。真是不幸的消息，事实上赛门铁克公司自2008年以来已经经历了四任CEO，而如今正期待着第五位掌门人的来临。

赛门铁克曾于2014年遇到过类似的CEO转换情况，我当时发布过一篇博文，表示我愿意出任CEO一职——很奇怪，赛门铁克方面一直没给我打过电话。不管怎么说，我今天早晨回顾了两年前提出的建议与赛门铁克面临的问题，并发现其中相当一部分至今仍未得到解决。有鉴于此，请允许我再次向赛门铁克董事会提交下面这份CEO申请攻略：

**1.****成为领先的托管与专业安全服务供应商。**这是我两年前提出的最为重要的一项建议。托管安全服务的发展速度已经达到传统产品销售增幅的两倍，而信息安全技能短缺则导致众多企业客户找不到可行的安全保护解决方案。正因为如此，戴尔SecureWorks（E百科：SecureWorks主要为客户提供安全服务、安全与风险咨询以及威胁情报等）等一系列方案才陆续涌现，旨在解决这项难题。与此同时，赛门铁克公司已经拥有相当强大的托管安全服务业务，因此其明显应该抓住这一机会。如果我是下一任CEO，我会加大这方面的投资力度，包括增加招聘规模、提振销售额及营销水平，同时在安全分析及事件响应等高附加值企业级托管服务领域有所建树。

![](../Images/d42dff0d1f41ec639e20cd20219cc4af.png)

**2.积极进行并购活动。**是的，我仍然坚持这一观点。就在赛门铁克公司经历CEO轮换并剥离Veritas（E百科：VERITAS软件公司的产品主要用于数据保护、应用高可用性和灾难恢复。）存储业务的同时，思科与IBM正在积极收购发展前景光明的企业，其中思科买下了OpenDNS、IBM则将Resilient Systems招至麾下。二者皆能够为现有组合提供额外价值，并进一步推动母公司在网络安全领域的表现。赛门铁克公司也掌握着可观的资金，因此完全有能力进军这一资产积累道路。

  

**3\. 精简、精简、再精简。**除了Veritas出售之外，我建议赛门铁克公司进一步剥离二级产品与服务以精简产品组合。目前仍有大量表现乏力的方案存在于企业之内。赛门铁克公司必须敲定其关注重点，向这些重点领域投资并将其余部分出售出去。好消息是，赛门铁克公司确实拥有相当丰富的出色产品，这能够有效确定销售对象范围。该公司应当能够为其找到很好的买家。

![](../Images/b38d3766bc39f6807e03a399c8aa62f2.png)

**4. 建立网络安全架构与生态系统。**赛门铁克公司已经开始利用自己的产品推进这项工作，但目前尚未吸引到其它网络安全供应商的参与。与此同时，思科、IBM、Splunk以及其它厂商则正在积极努力。这项工作必须引起新任CEO的高度重视，否则赛门铁克很可能发现自己被逐渐排除在企业级安全市场之外。

  

我曾在2014年时提出过其它一些建议，而且其目前仍然有效。不过考虑到时间的推移，我要新增以下两项观点：

**5. 高度关注端点安全。**好消息是，赛门铁克公司正是世界上规模最大的端点安全供应商。不过坏消息是，这一利润丰厚的市场正受到众多“新一代端点安全”供应商的冲击。尽管业界对这种过渡的宣传有些夸张，但必须承认，目前赛门铁克公司面临的真正威胁在于其它厂商推出的传统企业级杀毒工具替代方案，具体包括Carbon Black、Countertack、Cylance、Crowdstrike、DigitalGuardian、Invincea以及SentinelOne等等。赛门铁克方面需要捍卫这一立足根基，否则将失去生存的空间。尽管赛门铁克公司拥有强大的端点安全技术储备，但尽快收购其它初创企业应该会快速提升其竞争主动性。

  

**6. 扩大数据安全性发展机遇。**赛门铁克公司在这方面的表现还算不错，过去一年中其数据丢失预防方案的营收提升了约30%。然而，赛门铁克方面在市场上的表现还不够积极，而其本可以在这里建立领导地位。赛门铁克需要向数据安全类专业服务投入资金，认真进军数据安全CASB（Cloud Access Security Broker 云安全接入代理）市场，更为紧密地将其PGP资产与DLP技术相结合，同时与Box、微软以及甲骨文等数据管理领导厂商建立合作关系。只要投资方向准确，赛门铁克将能够在这一市场上强势登顶。

当然，投资银行家与华尔街投资人们仍然希望下一任CEO能够将赛门铁克整体出售给戴尔、惠普、微软或者甲骨文等业界巨头。这样的结果当然能够满足资本家们的贪欲，但就目前来看赛门铁克仍然有摆脱被收购命运的机会。

好了，我仍然还没当上这家市值数十亿美的企业的掌门人，但我认为自己提出的这些建议能够帮助赛门铁克重回正轨。所以，我调高了手机音量，以便他们打来邀请电话时我能及时发现——咱们共同期待吧～
