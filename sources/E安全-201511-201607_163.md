# 英国推出首套面向网络安全领域的扩展认证项目

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MjA1MzkyNA==&mid=2655292892&idx=3&sn=f396dc3ac34cc4b0b745cc0860a9a965&chksm=f02ff197c7587881828624f0bde6670ff50b2052493aa848771a4c7b1a07e3e76fde256b032b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655292892&idx=3&sn=f396dc3ac34cc4b0b745cc0860a9a965&chksm=f02ff197c7587881828624f0bde6670ff50b2052493aa848771a4c7b1a07e3e76fde256b032b&scene=27#wechat_redirect)

Cyber Security Challenge UK公司已经推出了英国国内首套面向网络安全领域的扩展项目认证（简称EPQ）方案。

这项已经正式亮相的认证旨在**帮助解决英国本土的网络安全技能人才缺失现状，其计划帮助高校学生对网络领域实现全面而深入的理解——从风险管理到数字化取证皆包含在内。**

根据(ISC)2方面的预测，**截至2020年全球网络安全人才缺口将达到150万**，而世界范围内各个国家都将面临规模日益增长的网络攻击威胁。另外，与这一行业及岗位相关的薪酬与福利水平亦水涨船高，其中**15%从业者的年薪超过10万欧元**；这一极具吸引力的数字无疑将吸引大量希望投身于其中的潜在安全人才。

“这项认证的出炉标志着网络安全行业在成熟度方面更上一层楼，” Cyber Security Challenge UK公司CEO斯蒂芬妮·达曼指出。“网络安全这一议题正变得越来越重要，而且这一结论也已经在各招聘企业及求职个人当中形成共识。大家不需要身为数学天才或者‘计算机极客’，也能够在这一领域找到理想的角色定位；网络安全的涵盖范围非常广泛，从风险管理到生物识别乃至行为分析。因此，我们需要吸引同样广泛的各类生源以填补这些职位。我要敦促那些在校学生在审视职业规划时认真考虑投身安全事务的可能性，当然也包括有计划转行的其他从业人员。”

这项认证由Cyber Security Challenge UK负责设计，同时亦受到包括(ISC)2在内的众多独立网络教育机构的支持。该认证将由Heart of Worcestershire学院负责管理并受到伦敦城市行业协会的审定。

基于国家职业标准（简称NOS）网络安全共识要求的EPQ认证属于一项三级资质（相当于AS级别），其价值高达70 UCAS点。EPQ认证亦被纳入英国各地的现有教育框架，可作为14-19文凭的组成部分或者独立资质。该项目的教育合作伙伴能够为任何个人提供课程——无论其身为在校学生还是已经工作。

EPQ不仅能够被直接纳入高校学业当中，亦可作为独立技能提供给通过Cyber Security Challenge UK公司注册的申请人。在校学生可以通过在线课程进行学习，并根据自身表现拿到由伦敦城市行业协会颁发的资质。
