### **2015 DockerCon Europe****大会**

本周众多Docker技术爱好者齐聚西班牙巴塞罗那，希望在这里聆听到迅猛发展当中的Docker行业为世界带来的最新最强音。下面就一起来看于此次大会上披露的各项重要发布内容。

  

  

![](../Images/9feb1db2cb3080dfc2dae4682a43983b.png)

**Docker Universal Control Plane**

**开发商名称****:** Docker有限公司

**产品价格****:** 尚未正式发布，目前处于beta测试阶段。

**关键特性****: **Docker Universal Control Plane 1.0是一套内部解决方案，用于对任意基础设施之上Docker化应用程序的计算、网络以及存储配置任务加以操作，并为开发人员提供敏捷性自助能力以实现应用程序的部署与管理。

**上市时间** -目前处于beta测试阶段。

**详细信息: **https://www.docker.com/universal-control-plane

  

  

![](../Images/622d14dba2f01cb683514a607a297dc1.png)

**HPE Helion Development Platform 2.0**

**开发商名称**** :** 惠普企业业务公司

**产品价格****:** 每台服务器每年485美元，提供每周五天、每天九小时技术支持。

**关键特性****: **使得开发人员能够部署微服务、将Docker容器打包为基于 Cloud Foundry的PaaS方案。其中包括Helion Code Engine，这是一项持续交付/持续部署服务，旨在以自动化方式实现代码的构建、测试与部署流程，从而通过Docker Trusted Registry将相关代码导入至Git库以及Cloud Foundry运行时环境。

**上市时间****:**已经上市

**详细信息: **http://www8.hp.com/us/en/cloud/helion-devplatform-overview.html

  

  

![](../Images/5685f7af824637eab208ded377fa5c1e.png)

**Bitnami Stacksmith**

**开****发商名称****:** Bitnami

**产品价格****:** 测试阶段免费试用，未来通用Beta版本将开始收费

**关键特性****:** Bitnami Stacksmith提供各类高质量、及时更新的辅助应用程序组件，可被用于Docker环境之内的开发与生产流程，帮助开发人员摆脱从零开始构建Docker组件的烦恼。

**上市时间****:** 已经上市

**详细信息: **https://stacksmith.bitnami.com/

**开****发商名称****:** 惠普企业业务公司

**产品价格****: **免费社区版；许可版本起步价格为599美元，支持五套容器环境

**关键特性****: **实现在HPE OneView中实现Docker容器主机自动化部署，帮助IT与DevOps人员快速在企业自有数据中心以及安全网络环境内部利用裸机基础设施配置Docker运行环境。

**上市时间****:** 已经上市

**Persistent Storage Services for Docker**

**开****发商名称****:** Rancher Labs

**产品价格****:** 这款产品属于Rancher解决方案的功能之一，目前该方案处于免费beta测试阶段。

**关键特性****:** Rancher推出的Persistent Storage Services for Docker旨在实现编排支持能力，帮助开发人员将存储元素部署至容器化应用程序当中，从而更为便捷地满足状态数据库与持久性存储的实际需求。

**上市时间****:** Persistent Storage Services for Docker已经于11月16日随同Rancher 0.45版本一同推出。

**详细信息: **http://www.businesswire.com/news/home/20151111006591/en

**Hyper-Converged Infrastructure Platform for Containers**

**开****发商名称****:** Rancher Labs与Redapt

**产品价格**：目前尚未公布

**关键特性****:** 通过与Redapt方面的合作，Rancher Labs打造出了一款面向容器环境的超融合型基础设施平台，旨在简化操作流程并降低构建成本，帮助用户更轻松地从零开始运行自己的私有容器服务。

**上市时间****:** 这款产品将于2016年上半年正式投放市场。

**详细信息: **http://www.businesswire.com/news/home/20151111006591/en

**Twistlock Container Security Suite**

**开****发商名称****:** Twistlock

**产品价格****:** 企业版前十台主机每主机每年1000美元，大规模部署可享受价格优惠。

开发者版永久免费，但最多支持两台主机。

**关键特性****:** Twistlock提供全面的安全漏洞管理、高级访问控制以及运行时防御机制，且贯穿整个容器开发与运行周期。

**上市时间****:** 已经上市

**详细信息: **http://www.twistlock.com/

  

  

![](../Images/ddabd3e0c0c264d394b543907b5c3e06.png)

**Portworx PWX**

**开****发商名称****:** Portworx有限公司

**产品价格****:** PWX社区版——免费——可实现涵盖三节点的Docker容器数据持久存储。

PWX企业版——每主机每年1000到5000美元，最多可支持九节点数据存储。

**关键特性****:** Portworx容器定义存储方案是第一款能够提供持久性集群化向外扩展软件存储功能的原生Docker存储产品，相关功能包括面向容器的细化克隆、快照、服务类以及高可用性机制。

**上市时间****:**2016年第一季度

**详细信息: **http://www.portworx.com/

  

  

![](../Images/ed58d7f8d9deaa0736a9779ecb1ff0ce.png)

**DCHQ On-Premise与DCHQ.io Hosted PaaS**

**开****发商名称****:** DCHQ有限公司

**产品价格****:**

*   DCHQ On-Premise
    

*   标准版——免费（最多支持1000套容器环境）
    
*   企业版——企业级技术支持、高可用性安装方案、最多支持25000套容器环境、可定制计价。
    

*   DCHQ.io Hosted PaaS
    

*   开发者版——免费（最多支持50套容器环境）
    
*   企业版——每月500美元（最多支持1000套容器环境）
    

**关键特性****:** DCHQ能够帮助企业客户对Java应用程序进行容器化。其集成了13套云/虚拟化平台，且允许开发人员在无需变更自身应用开发流程的前提下将其迁移至容器环境。目前已经实现的生产性应用管理功能包括应用监控、自动规模伸缩、备份与持续交付。

**上市时间** – 目前DCHQ On-Premise与DCHQ.io Hosted PaaS 3.0版本已经正式推出。

**详细信息: **http://dchq.co/dchq-on-premise.html
