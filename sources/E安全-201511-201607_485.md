# #OpParis首日战况：匿名者已经击垮3824个ISIS成员账号

> **就在向ISIS成员正式宣战后的一天之内，黑客组织“匿名者”已经成功拿下超过3800个ISIS成员及相关者之Twitter账户。**

  

![](../Images/4d0fd3e325081b4384a2018ebe87a374.png)  
  

作为全球最知名的黑客团体，匿名者已经快速聚集力量并为此次#OpParis行动创建了一个新的正式Twitter账户。另外，他们还建立一个全新网站，旨在汇总全部ISIS账户信息。

  

除了自行对ISIS Twitter账户进行扫描之外，该黑客组织还向有意参与的公众开放了该网站。任何发现过ISIS社交媒体账户的朋友都能够轻松对该数据库进行搜索，并上报新近出现的恐怖分子及其支持者。

  

该网站名为#opIceISIS，其定位是根据真实姓名、位置、照片、Twitter、Facebook以及YouTube账户整理出一份ISIS成员清单。

  

在本次巴黎恐怖袭击之前，匿名者组织就已经在今年早些时候的《查理周刊》袭击事件之后向ISIS宣战，而当时的行动代号为#OpISIS。当时，该组织总计揪出了数万个ISIS相关Twitter账户。

  

而在一天之内就击垮3800多个Twitter账户，看起来匿名者组织在探查恐怖分子方面投入了更大力量，希望最终能够将其彻底清理出社交网络。

  

就在本次巴黎恐怖袭击事件之前，Ghost Security Group——另一个神秘的黑客组织——透露称，他们追踪到某些已知ISIS成员持有总价超过300万美元/280万欧元的比特币。

  

随着匿名者不断将已知ISIS成员信息添加至其数据库当中，相关执法机构以及其它黑客团体也许亦将有能力追踪到更多相关账户甚至借此阻止即将出现的恐怖活动。
