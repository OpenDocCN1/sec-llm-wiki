# 战场上的网络武器 美国陆军将于2019财年发布CPCE

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MjA1MzkyNA==&mid=2655294726&idx=3&sn=a960ca48a770762f16b07926160eb633&chksm=f02fe94dc758605b193d7db0d5f1609ae930f17687b9628a45c77cf6e18acfb621c69d998d90&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655294726&idx=3&sn=a960ca48a770762f16b07926160eb633&chksm=f02fe94dc758605b193d7db0d5f1609ae930f17687b9628a45c77cf6e18acfb621c69d998d90&scene=27#wechat_redirect)

E安全1月5日讯 美国陆军正在设计新的指挥与控制联网基础设施，以连接烟道式系统，并将这些系统合并为一个系统——收集映射、火力信息，消除空域冲突、部队追踪技术和情报数据。

![](../Images/665b46d412d07ba317112b66f95ea36c.png "战场上的网络战 美国陆军将于2019财年发布CPCE-E安全")

指挥所计算环境（Command Post Computing Environment，CPCE）用来同步指挥中心的移动和固定应用程序，例如车辆数据和在前沿作战基地的汇总信息。

CPCE项目经理Jack Shane中校表示，目前，指挥与控制要素较为复杂，往往导致用户和系统管理员难以管理系统的集合，这会影响实时作战信息共享。美国陆军预期CPCE最终版本将于2019财年发布，并用于作战。

Shane表示，“过去，所有的用户界面必须有自己的基础设施。我们希望摆脱这些不同的系统，提供通用架构，这将大大减少系统负担。”

这种概念旨在升级过时、不太直观的用户图形界面（GUI）。

虽然士兵们善于在每个个别项目中共享数据，但要实现互操作和协同作战，士兵们要人工从一个系统上取出数据，然后再将数据以物理方式上传入另一个系统，这消耗了大量时间，也造成了人为出错的机会。支撑这些众多独立系统所需的基础设施庞大，也造成了指挥所的臃肿。士兵们需要更精简的集成系统。

Shane指出，其目的是减少互操作的中间工作量。他解释道，这一点尤为重要，因为各种指挥与控制技术是相互依赖的。

通过使用标准IP协议，该系统能促进互操作性，并使火力控制，Satcom网络和其它任务命令系统能更快速地互相通知与更新。

Shane解释称，例如，能更快速地评估先进野战炮兵战术数据系统（Advanced Field Artillery Tactical Data System，AFATDS ）的火力、部队追踪地址数据或任务指挥进展。

作战中，不断变化的部队位置数据很快传送到指挥与控制战场管理应用程序，例如未来指挥所（Command Post of the Future）。

移动数字地图通过高速卫星更新。移动数字地图可以快速刷新，从而传送不断变化的战斗车辆坐标。这种技术可能通过美国陆军目前正在开发的联合作战指挥-平台系统（Joint Battle Command – Platform system，JBC-P）实现。

JBC-P是下一代蓝军跟踪系统技术（Blue-Force Tracker），该技术使用更快的上行和下行卫星连接，被称为蓝军跟踪系统2或BFT 2。JBC-P减少延迟，使更新更快，让士兵立即了解快速移动的友军和敌军位置。

Shane表示，移动连接与简化的数据互操作性大大提高了美国陆军的远征行动。

他解释道，美国陆军计划将JBC-P用于美国陆军的多用途装甲车、Strykers、Bradleys和联合轻型战术车辆。

美国陆军的开发人员表示，CPCE将使陆军通过基于Web的技术开发应用程序，并供战术和作战指挥官使用。

美国陆军的一份声明指出，“使用政府授权的任何笔记本连接到适当的涉密网络，指挥官和工作人员可以登录基于Web的框架- Ozone插件框架（Ozone widget framework）访问这些应用程序。”

这些应用程序为指挥官提供三维视图，以便指挥官通过直观的数字化地图了解地面和空中报告、野战炮兵指挥、后勤、通报和事件报告的作战和情报。

将部队跟踪数据与情报信息合并也是JBC-P的基本要素。移动部队通过该系统可方便访问战术情报地面报告（Tactical Intelligence Ground Reporting，TIGER）系统。TIGER系统可供查看沿路的某个区域过去是否存在问题，或敌人的活动。

Shane表示，TIGER融入JBC-P，并让士兵即时访问相关作战详情。CPCE与数据分发系统集成，以便流量在系统间快速传递，并为指挥官提供机会更快速地制定明智的作战决策。通用的软件结构和IP协议也有利于快速交换信息。

Shane解释道，“所有系统将共享同一数据源。”

集成对美国陆军的“移动任务指挥”（mission command on-the-move） Satcom网络（被称为作战人员信息网- Warfighter Information Network，Tactical Inc. 2,或WIN-T）也很重要。在移动过程中共享信息极大地加快了作战机动战术。
