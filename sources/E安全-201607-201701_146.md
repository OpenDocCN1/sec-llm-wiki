# 特朗普上台， 美国网络安全将何去何从？

E安全11月10日讯 共和党总统候选人特朗普赢得美国大选将成为美国第45任总统。特朗普上台，对美国的网络安全意味着什么呢？

![](../Images/b4b5413152b4dc57411128ba09218f43.png "特朗普上台， 美国网络安全将何去何从？ - E安全")

特朗普政府会如何解决网络安全和加密问题，目前仍不明朗。有外媒上月报道，特朗普及其竞选团队一直在许多此类细节方面含糊其辞。在总统竞选辩论中，特朗普对情报机构认为俄罗斯政府针对DNC实施网络攻击的行为不予理睬。但是，特朗普却呼吁抵制苹果公司—但在苹果与联邦检察官就苹果是否应该被迫帮助当局解锁嫌犯的加密iPhone展开辩论时，他却未抵制。

就如同特朗普的许多其它计划，他的网络安全计划仍不完善，如下：

> *   由军方、执法机构和私营部门组成网络审查小组，由该小组立即审查所有美国网络防御和漏洞，包括关键基础设施。
>     
> *   网络审查小组将为不同的实体提供具体建议，以便实体采用最佳防御技术保护网络安全。审查小组还将定期随访联邦机构和部门。
>     
> *   网络审查小组将建立具体协议，并强制所有政府雇员接受网络意识培训，同时保留当前应对网络攻击的先进方法。
>     
> *   要求美国司法部成立联合任务部队联合联邦政府、各州和当地执法部门应对网络威胁。
>     
> *   命令国防部长和参谋长联席会议主席为改进美国网络司令部提出建议，同时关注网络域的进攻与防御。
>     
> *   培养进攻性网络能力，抵御国家和非国家攻击者，必要时，适当应对。
>     

特朗普政府未来计划将公开所有网络漏洞，保护所有重要的关键基础设施，并建立先进的网络防御和进攻系统。特朗普时代的美国网络安全走向E安全也将持续关注！
