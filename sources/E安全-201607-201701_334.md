# Cybersecurity Ventures报告：2021年全球网络犯罪成本将增加至6万亿美元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MjA1MzkyNA==&mid=2655294256&idx=3&sn=41f5bc40a2ac8deffbab5ecd3b742c5f&chksm=f02fef7bc758666d86bf508edc4854643c2001991b188f38691cb4ec2efba7994b0806f77e27&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655294256&idx=3&sn=41f5bc40a2ac8deffbab5ecd3b742c5f&chksm=f02fef7bc758666d86bf508edc4854643c2001991b188f38691cb4ec2efba7994b0806f77e27&scene=27#wechat_redirect)

E安全8月29日讯 预计到2021年，网络犯罪的成本可能达6万亿美元。全球的网络犯罪成本将继续呈增长态势，倒也不足为奇，因为此类非法手段泛滥。 Cybersecurity Ventures的分析表明，网络犯罪成本2012年可能会高达6万亿美元。（预计，2015年全球网络犯罪的年成本为3万亿美元）。

Ponemon Institute的创始人Larry Ponemon表示，安全专家质疑未来5年，网络犯罪成本将明显增加，可能以万亿美元的趋势增长。Larry Ponemon评论到，“一万亿美元真有可能”。

网络犯罪活动的增长趋势将增加全球在网络安全产品和服务方面的支出。预计未来五年（2017-2021）全球支出将累计增加超过1万亿美元。

犯罪活动将目标从计算机和移动设备不断扩展至物联网、交通和电网。

![](../Images/7804b173114837017c5ec0f4e6a19ab7.png)

研究人员预估的网络犯罪成本考虑了所有可能的破坏成本（与网络犯罪活动有关）：

> *   数据、被盗钱财的损害和破坏
>     
> *   窃取知识产权
>     
> *   窃取个人和财产数据，挪用公款
>     
> *   欺诈
>     
> *   丧失生产力
>     
> *   损害名誉
>     
> *   攻击后扰乱正常业务运行，取证调查
>     
> *   被入侵数据和系统的恢复与删除
>     

这里也考虑到了网络犯罪总成本的很大一部分因没有报告不计算在内的情况。

该报告强调当今缺乏有效的金融网络犯罪的执法机构。尽管执法机构在打击全球网络组织方面取得一定成功，但仍需不断努力应对不断增加的威胁。

美国已宣布全国进入紧急状态应对网络威胁。

报告指出，“从目前到2021年，世界网络攻击面将呈现数量级的扩展趋势。”
