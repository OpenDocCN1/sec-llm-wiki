# 【DefCon专题】安全赌注已达到史无前例的水平

**这个周末，全球黑客齐聚拉斯维加斯**

DEF CON 24大会的全部关注重点集中在连接安全与破坏两大层面。

黑客技术会议始终秉持两大基本方向：安全与入侵。而作为今年规模最大的黑客盛会，于8月4号到7号在拉斯维加斯召开的DEF CON 24大会自然也不例外。

“**安全赌注已经达到史无前例的水平**，”DEF CON物联网主题组织者之一Ted Harrington在接受采访时表示。“**在连接状态与连接传输之间，安全漏洞如今已经给人们的生活造成潜在影响。**”

一方面，众多安全技术爱好者与“白帽”黑客（即利用自身技能提升安全水平的黑客）正努力保护当前技术环境——Harringto就是一位白帽黑客，同时亦为独立安全评估者项目中的一名合作伙伴。另外亦存在着“黑帽”黑客（即通过入侵为自身牟取利益的黑客），他们的目标非常简单——破坏一切。

白帽与黑帽黑客都将参与到这场于拉斯维加斯巴黎/巴利度假酒店召开的盛会中来，其中黑客技术研究人员、技术爱好者以及对此抱有兴趣的业余人士只需支付240美元（仅接受现金）即可一探真实的黑客圈子。

“尽管DEF CON主要是一场面向及由研究爱好者参与的会议，”Harrington指出，“但由这一大会所带来的议题与成果将影响到主流生活方式中的几乎每一个层面。”

![](../Images/05e91bc2e829ab19dd66f4b26fd41bc1.png)

DEF CON大会最初诞生于1993年，而如今的会议虽然在形式上与之前基本类似，但在规模方面却要庞大得多。

不同环节设立有不同的探讨主题，其中涵盖了生物黑客、车辆黑客甚至是闭锁黑客等针对性各异的内容。在这些环节当中，开发商与企业会通过竞赛与活动的方式充分运用这股黑客力量——例如物联网主题下的Canary与FitBit项目。今年美国国防高级研究计划局（简称DARPA）同样准备了200万美元资金，用于创建一款新的具有AI功能的黑客软件。

另外这里亦设有黑客技术车间，各位企业与会者能够加入、听取并从黑客大师们那里了解到如何搞垮开发人员及其程序项目。车辆黑客车间还允许50名学员黑客“了解车辆系统及其联网原理。”

另外大会上还设有“面向新手的漏洞利用”车间，旨在帮助“参与者们在直接使用现成漏洞工具之外，真正理解程序的二进制层面运行原理以及如何攻击其薄弱之处，”即找到安全漏洞并编写攻击代码。

“DEF CON大会通常能够准确地反映技术领域的创新成果，这是因为其中相当一部分成果都与前沿安全问题密切相关，”Harriongto解释称。
