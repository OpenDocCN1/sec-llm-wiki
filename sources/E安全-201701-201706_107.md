# 移动加密市场强劲，未来5年规模将达到132亿元

E安全5月12日讯全球移动加密市场目前价值7.614亿美元，据印度普纳研究机构MarketsandMarkets预测，按照逾30%的年复合增长率，预计到2022年该市场的规模将达到29.2亿美元，即全球移动加密市场的规模未来5年将增长近3倍。该市场蓬勃发展对美国执法机构而言无疑是个“祸患”。

![](../Images/93af6a3575c21ad9d8cafe7314c9a745.png "移动加密市场强劲，未来5年规模将达到132亿元-E安全")

MarketsandMarkets发现，驱动移动加密市场发展的关键因素包括：

> *   企业智能手机和平板电脑的使用率提升；
>     
> *   需要满足严格的合规和法规要求；
>     
> *   人们日益关心数据安全和隐私问题；
>     
> *   企业不断采用基于云的移动加密解决方案。
>     

这份研究将该市场分为四大应用领域：

> *   全盘加密；
>     
> *   文件/文件夹加密；
>     
> *   通信加密；
>     
> *   云加密。
>     

## **联邦执法机构****为何黯然神伤？**

由于对基于硬件加密的需求不断增长，根据预测，全盘加密（或保护设备上的所有信息）将占据该市场最大份额，将在2022年前占据市场主导地位。

上周，科米（当时担任FBI局长）在参议院的证词中强调了这种趋势。科米的观点表明，由于通信安全技术（如加密）的使用率提高，联邦执法机构“连声叫苦”。

自从设备使用默认全盘加密以后，这给FBI近一半工作造成阻碍。从去年10月至今年3月，FBI审查员具有合法搜索令或法院命令对6000多台设备进行解锁，但在46%的案件中，FBI无法通过任何技术打开设备。

科米表示，FBI将该问题带来的阴影称之为“黑暗化”，未来这种现象还会阻碍更多工作开展。

## **北美、亚太市场看好**

北美地区移动加密公司云集，例如BlackBerry、MobileIron、Open Whisper Systems和Proofpoint。

MarketsandMarkets预计，鉴于该地区早期就采用新兴技术，未来仍将是最大的市场，但由于小中型企业越来越多地采用移动加密技术防止出现对关键企业数据的未授权访问和对保密信息的不道德使用，亚太市场将实现最快增长。而由于受消费者需求和监管要求的驱动，电信和医疗保健垂直行业将可能取得最快的增长。
