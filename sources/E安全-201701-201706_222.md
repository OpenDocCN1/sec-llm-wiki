# 哪些智能家居产品最易遭受入侵？

E安全4月11日讯 无论厂商如何宣称自己的智能家居产品有多智能，这类智能产品却逃不过易遭遇黑客攻击的事实。

如今，网络威胁格局千变万化，就连家中的电子锁也会遭受网络攻击。虽然越来越多的人担心有贼撬锁而更换了更为先进的智能电子门锁，看似坚不可摧，但却忽略了网络窃贼通过网络空间就能轻松打开智能门锁这样的威胁。

在门上装锁是为了防窃贼，道高一尺魔高一丈，总之是防不胜防！用户应保护高科技设备免遭网络威胁。

首先，互联网路由器和智能设备应使用不同的密码，并使用多因素认证作为附加保护措施，这一点很重要。除此之外，还应定期安装厂商更新，以确保在家中运行最新的安全系统。

### **未来****中国和美国****将成为****最大的智能家居市场**

Ovum发布的“智能家居设备预测：2016–21”显示，未来最大的智能家居市场将在中国和美国，因为这两个地区设备具有高可用性且消费者对智能家居服务和产品相对兴趣较高。

预计到2021年，智能家居设备销量将从2016年的2.24亿台增加到超过14亿台，尤其安全设备（例如摄像机、门锁和传感器）和实用设备（例如联网灯泡和智能恒温控制器）将带动销量。Ovum预测，每个使用智能家居的家庭平均将使用8.7台这类设备，这样一来，智能家居安装总量将达到40亿台。

美国域名服务器管理服务供应商Dyn曾遭遇DDoS攻击，幕后是多达10万台物联网设备构成的僵尸网络。为了降低此类攻击带来的影响，InsuranceQuotes 官员已经注意到一些最热门的智能家居产品容易遭受攻击。

### **智能家居应重视“多因子认证”**  

**智能中心：**家中的虚拟键。其作用是连接所有智能家用设备的中央监控站，出现异常时向紧急应对者发出警报。如果网络犯罪分子进入智能中心，他们就可以进入用户家中。智能中心也可能成为干扰发射台的受害者，干扰发射台主要用来阻塞各种智能产品和智能中心之间的信号。

**智能监控摄像头：**这类摄像头主要用来监控窃贼，然而这类设备也会成为网络犯罪分子窥视的工具。这些监控摄像头反过来可能会帮助窃贼掌握用户家中的情况，并了解最宝贵财产的存放位置。

*建议用户使用复杂的密码，并设置多因素验证，防止网络犯罪分子窥视。*

**智能锁：**这类锁旨在防止窃贼入室行窃，然而，某些锁容易遭到黑客入侵。

*建议用户经常修改密码，并设置多因素验证。除此之外，确保有备用钥匙，以免出现故障。*

**智能车库门：**这类车库门方便打开。然而，智能车库门容易遭遇黑客入侵，黑客可以通过车库门进入用户家中。

*建议用户使用复杂的密码，并使用以手动方式进入车库。*

**智能恒温器：**这类设备确实为生活提供了便利，而且有了这类设备，无需在寒冬下床调整室内温度。然而，若遭遇调皮的黑客入侵，黑客可能会在炎炎夏日加热或在严寒冬日开启制冷，使你的生活苦不堪言。

*建议确保设置密码加密，并设置多因素认证。*

**智能灯：**当家中无人或离开家时才意识到厨房灯打开时，智能灯总能派上用场。然而，如果这类灯被不法分子利用，可能会让用户整夜难免，将灯一开一关会浪费电。

*建议用户经常修改密码并设置多因素认证，以此控制家中的灯。*

**智能婴儿监视器：**有了智能婴儿监视器，初为人母人父的家长确实受益不少。然而，若这类设备被黑客利用，他们可能会朝婴儿大吵大嚷，并播放嘈杂的音乐。除此之外，这类设备还可能为绑架者提供情报。

*建议经常修改密码，不使用时将设备关闭。*

综上所述，建议大家尽量使用**多因素认证。**

### **智能家居要获得人们的信赖任重道远**

Assurant公司对2500名美国人展开调查，其调查结果显示，三分之二的调查对象认为，联网技术利大于弊。而且，Assurant在调查中发现，有些用户甚至因此产生忧虑。

> *   27%的调查对象称，他们担心智能家用设备坏了之后更换或维修费昂贵。
>     
> *   24%的调查对象表示，这类产品并不如预期的理想。
>     
> *   21%的调查对象担心自我排故的知识不够。
>     

Assurant调查了人们对智能家用产品的具体担忧。

> *   65%的调查对象担心或害怕网络犯罪分子盗窃身份；
>     
> *   62%的调查对象担心针对美国网络基础设施发起的网络攻击；
>     
> *   51%的担心电子邮件或社交媒体账号入侵；
>     
> *   42%的担心外国政府监听。
>
