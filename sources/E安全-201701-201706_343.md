# 2016年网络安全行业概述：融资交易额创历史新高，但年末后劲不足

*2016年世界各地的网络安全厂商共进行**了超过400项融资交易，但第四季度交易量呈现下滑趋势*

2016年，网络安全融资交易额创历史新高，第三季度亦成为过去五年来网络安全厂商融资交易活动最为密集的时段。然而在随后的第四季度中相关交易趋势开始放缓，期间仅进行76笔交易，成为自2013年第三季度以来交易量最低的季度。

2016年还诞生了一家新的网络安全独角兽厂商。Cylance公司在去年6月的D轮融资中筹得1亿美元，这标志着其市值已经正式突破10亿美元大关。而2015年出现的四家网络安全独角兽厂商则分别为Illumio、Okta、Tanium以及Zscaler。

去年创纪录的交易活动亦表明，伴随着一波又一波指向企业及政府部门的恶意攻击与黑客入侵，网络安全行业继续保持着可观的发展热度。投资者仍然主要关注处于早期发展阶段的网络安全企业（包括种子轮与A轮融资），这意味着在当前不断变化的网络威胁环境当中，我们仍然需要新型解决方案以帮助缓解甚至预测攻击活动。

### **年度投资金额与交易**

2016年网络安全领域出现了超过400笔融资交易，高于2015年全年的378笔。事实上，自2012年以来每年的网络安全厂商交易量都在不断攀升。其中2014年的涨幅最大，较2013年增长了近100笔。

2015年目前在金融方面仍是网络安全企业最为活跃的一年，行业总投资交易量高达近40亿美元。而去年的全年投资总额约为35亿美元。

2016年在网络安全领域出现了四笔大规模融资（金额超过1亿美元），分别为StackPath（1.8亿美元私人股本）、LogicMonitor（1.3亿美元增长股本）、Cylance（1亿美元D轮融资）以及Mobi Magic（1亿美元B轮融资）。而在2015年，行业内规模最大的五笔投资分别来自Tenable Network Security、Tanium、CloudFlare、CrowdStrike以及Illumio。

截至2017年2月7日，今年的网络安全领域已经出现了近30笔交易。其中规模最大的是端点安全厂商SentinelOne公司通过C轮融资筹得7000万美元。

### **季度投资金额与交易**

2016年第三季度网络安全厂商共完成114笔交易，这也是历史上首次实现单季度突破110笔交易。不过整个行业明显出现了后劲不足的倾向，2016年第四季度交易总量缩减至80笔，这是自2013年第四季度以来最低的同时段交易量水平，同时也带来自2014年第一季度以来最低的单季度交易金额水平。

![](../Images/266220c7877ed89824bec3d28009cd68.png "2016年网络安全行业概述：交易额创历史新高，但年末呈现放缓趋势-E安全")

### **各投资阶段交易比例**

总体来讲，各投资阶段所占的具体交易比例在过去五年内并未出现明显波动。平均而言，自2012年以来投资者完成的超过半数交易面向早期阶段（种子轮与A轮）。同样的，“其它”类别交易占比自2012年开始在整体交易份额中逐步攀升。“其它”类别具体包括可转换票据，这是一种常见于早期投资阶段中的交易方式。

![](../Images/7b704f541456762a172f0b9a0680d32e.png "2016年网络安全行业概述：交易额创历史新高，但年末呈现放缓趋势-E安全")

### **年度并购/上市情况**

去年，有不到90家网络安全公司进行了并购/上市，数量远低于2014年及2015年。印度公司Quick Heal Technologies是去年惟一一家进行首轮公开募股的网络安全企业。2017年，我们在截至2月7日的这段时间中已经迎来了8笔并购交易。这些交易包括对两家人工智能类网络安全技术厂商的收购。其中HPE公司于2月收购了Niara公司，而Amazon则于1月收购了Harvest.ai公司。

![](../Images/741d9933101c2acfcf9275605e1986be.png "2016年网络安全行业概述：交易额创历史新高，但年末呈现放缓趋势-E安全")

### **资金储备量最高厂商**

Tenable Network Security公司为目前资金最为雄厚的私营网络安全企业。而位列前五的其它厂商则包括Tanium、Lookout、OpenPeak以及Okta。
