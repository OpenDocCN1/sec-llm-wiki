# 英国政府出资2000万英镑为青少年提供网络安全培训

***网络学校计划（Cyber Schools Programme）旨在到2021年对5700名青少年加以培训。***

E安全2月13日讯 英国计划为成千上万青少年提供网络安全培训，旨在保护国家免受恶意攻击侵袭。

这项名为网络学校的计划将大力引导学龄儿童积累自身网络安全技能。

英国政府已经为这一课外学校计划筹备了2000万英镑资金预算，届时将有众多技术专家参与这批青少年的教学、测试与培训工作。

此项计划面向年龄在14到18岁且拥有各类不同教育背景的青少年，亦包括那些对网络安全工作缺乏了解的参与者。此项计划由英国文化、媒体与体育部（简称DCMS）负责管理，目标是到2021年至少培训5700名青少年完成相关课程。

根据Tech Partnership公布的数据，目前网络安全领域共有约58000名专家，每年产生的价值则高达220亿美元。

参与此项计划的学生们每周将投入4个小时接受教育。此项培训将包括课堂教学与在线教学两种形式。这项教育计划为期4年，同时提供模块化课程选项，这意味着年纪较大的学生只要符合标准亦可随时参与其中。

此项举措作为英国政府国家网络安全计划（National Cyber Security Programme）的组成部分，意在“找到、培养并快速追踪未来的网络安全专业人才”。

数字化与文化部部长Matt Hancock在今年2月11日的一份声明中表示：“这项前瞻性计划将使得数以千计最出色且最聪明的年轻人有机会在中学以外学习到尖端网络安全技能。我们决心帮助英国为当下以及未来的相关挑战作好准备，而这些课外俱乐部的出现将有助于找到并激励这些未来的人才。”

此项计划的受众为14岁的学生，整个课业周期为4年。其内容将以模块化形式提供，意味着年纪稍大的学生只要符合正确标准，亦可以随时随地加入其中。授业者将可以灵活决定如何以最适合的方式实施培训，而相关试水工作将从今年9月份开始——并在下一年通过监督与审查作出进一步改进。

另外值得一提的是其中亦包含刚刚公布的CyberFirst助学金资助计划，其到2020年将为最多1000名学生提供最高4000英镑助学金，旨在帮助其学习相关学位、安排升学或者参加时期学校，并根据会议要求尽可能在其毕业时提供国家安全相关职位。

2017年，CyberFirst计划尚有2500个剩余名额。另外英国亦组织有CyberFirst女生竞赛，参与基点的各支女生团队由13到15岁的姑娘组成，她们将以相互干扰的竞争方式破解一系列在线难题。

英国文化、媒体与体育部还支持各领先的关键性能源与运输基础设施企业培训并招聘最多50名16岁及以上高水平学员，借此保护其掌控下的基础服务设施免受网络攻击影响。这一“关键性部门网络安全学员计划（Cyber Security Apprenticeships for Critical Sectors Scheme）”目前已经正式开放，且主要面向那些对解决网络安全问题具有天赋性优势及抱有技术热情的群体。

另外，今年1月启动的网络再培训学院（Cyber Retraining Academy）也在帮助超过50名拥有出色资质的学员通过为期10周的强化培训课程快速涉足网络安全领域。
