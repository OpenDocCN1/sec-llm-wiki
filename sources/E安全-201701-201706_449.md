# IBM收购Agile 3 Solutions，旨在帮助各企业CEO理解网络安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MjA1MzkyNA==&mid=2655294864&idx=2&sn=5946f06746f23976c605b847f2ceddf9&chksm=f02fe9dbc75860cdcd4b8b848af0817b06bc48770d84522816bfea29d555d8b29ef77d012971&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655294864&idx=2&sn=5946f06746f23976c605b847f2ceddf9&chksm=f02fe9dbc75860cdcd4b8b848af0817b06bc48770d84522816bfea29d555d8b29ef77d012971&scene=27#wechat_redirect)

E安全1月26日讯 IBM公司指出，美国本土各类企业的CEO们将逐步意识到理解网络安全的重要意义并有所行动。

![](../Images/479f66c7782acac2c31b088b8d360243.png "IBM公司投资建立平台，旨在帮助各企业CEO理解网络安全-E安全")

本周一，蓝色巨人宣称对来自旧金山的Agile 3 Solutions公司进行收购——这是一家面向企业高层管理团队与行政领导层的数据可视化软件开发商。这款软件旨在帮助各位高管更好地理解并管理其企业所面临的实时网络威胁因素。

通过获取计算机代码并将其翻译成包含大量文本的仪表板，Agile 3 Solutions公司能够为不具备技术背景的用户提供泄露警报及其它安全通知内容的理解能力。

IBM方面援引Gartner公司得出的一项研究结论称，“**到2017年，80%的IT风险与安全企业都将开始向非IT类行政高管提交指标性资料; 然而，其中只有20%的内容能够为目标受众所理解及使用。**”

由IBM前成员Raghu Varadan创立的这家初创企业将在未来几个星期内完全收购交易，但具体收购价格尚不明确。另外，其产品将被纳入计算巨头的现有安全产品组合当中。在本次收购之前，Agile 3 Solutions公司此前曾作为商业合作伙伴与IBM方面开展协作。

当下存在的一个问题就是，在过去的几年里，面对越来越多的黑客攻击事件，企业却对网络安全问题不以为意。他们宁愿支付各类罚款、处理负面影响，然后再愚蠢地重蹈覆辙。

这一问题产生的原因是这些企业的业务不涉及安全服务。事实上，在运营过程中，网络安全只是企业的次要问题。因为企业高管在组织资源分配时，他们往往考虑到网络安全问题对企业不会产生直接影响，所以不愿意投入大量资金来解决此类问题。但是很显然，这一问题必然会间接且严重影响企业运营状况。

若是消费者的信任能决定企业的生死存亡，那么当客户数据被盗甚至是公司的知识产权受到侵犯时，消费者对企业的信任便会被削弱，进而导致企业业绩缩水。

那么我们如何才能让这些关键利益相关者意识到网络安全问题的重要性呢？方法之一就是为他们提供一个专门的工具，使他们可以从安全和风险的角度正确认识到企业所面临的问题性质。

IBM公司安全总经理Marc van Zadelhoff在关于Agile 3 Solutions收购案的一份声明中表示，“了解您最为核心的数据并掌握其所面临的外部或内部威胁因素，这两项将成为每一家企业未来实现正常运营的基本前提。”

根据Goldsmiths公司在2016年4月对1530名从业者进行的调查，超过90%的企业高管表示他们没有能力阅读并理解网络安全事故报告。

而国防承包商BAE Systems公司亦进行了另一项面向300名从业者的调查，结论发现40%的企业领导者对于其所在机构内所使用的网络安全协议缺乏清晰理解。

IBM公司数据安全负责人Nev Zunic表示，“Agile 3 Solutions软件能够从Guardium等其它产品处获取技术输出内容，并将这些输出结果转化为可由非技术受众所理解的信息，其中包括组织机构内的高管人员与商务经理。另外，其还有助于强调与敏感性信息资产相关的风险因素。”

随着IBM公司销售额连续十九个季度遭遇缩水，该公司已经开始将主要精力转向销售云计算与网络安全技术方案，旨在借此恢复业务表现。而对Agile 3 Solutions的收购自然也属于这一计划中的组成部分。

Zunic解释称，“我们的客户越来越需要理解其拥有的资产以及具体控制方式。考虑到PCI、PHI、PII以及GDPR等众多严格合规性监管要求的限制，我们的客户显然需要利用简化视图真正审视自己的数据。”

此次收购公告同时也标志着IBM完成了自2015年以来在安全领域的第20笔收购业务，其目的是为了重新定义公司在网络安全、数据分析、云数据和人工智能领域的业务布局。到目前为止，IBM转型之路依然十分艰难，因为就在上周，IBM宣布其连续19个季度收入下滑。不过好消息是，IBM的报告中表示，他们在转型期间一直强调的战略领域内的业绩正在持续增长，并有望最终阻止公司总体业绩下滑。
