树莓派推出两款新产品 RPi 3和RPi 3 Lite

E安全1月17日讯 英国慈善组织树莓派基金会（Raspberry Pi Foundation）Raspberry Pi Foundation推出两个新的树莓派产品。新推出产品名称为“计算模块3”（Compute Module 3）和“计算模块3 Lite”（Compute Module 3 Lite），是树莓派3（Raspberry Pi 3）的重塑版本，旨在为嵌入式设备开发人员提供方法，将树莓派作为设计基础，而无需适应相当笨重的树莓派设计（专为业余爱好者设计）。

Raspberry Pi Foundation 于2014年首次发布计算模块（Compute Modules），称首次将树莓派的外形变小，以兼容SODIMM板载内存插槽，其连接器可以按需自定义。计算模块还包含一些板载闪存，很显然是出于存储的原因。

这两个新模块保留了原来的概念，因此可以插入标准的DDR2 SODIMM插槽。基本模块售价30美元，使用的是与树莓派3相同的BCM2837处理器，因此处理器频率高达1.2GHz。此外，该模块采用了 1GByte的RAM和4Gbytes的非模块eMMC闪存。

 “Lite模块”将SD卡接口引入模块引脚，以便用户将其连接到eMMC或SD卡。除去闪存的价格为25美元。

Raspberry Pi Foundation还宣布推出计算模块IO板V3（Compute Module IO Board V3） — 允许用户对计算模块进行编程，并为计算模块提供HDMI和USB接口构建系统。

旧版的计算模块仍在售，价格为25美元，并可与新板兼容。

Raspberry Pi Foundation表示，“计算模块3”（CM3）在很大程度上与计算模块1（CM1）设计（遵循我们的设计指南）向后兼容。

“要注意的是，CM3比原始模块高1mm，处理器内核电源（VBAT）可以拉更多电流。因此，处理器本身在繁重的CPU负载下运行会比较热，因此，设计人员需要根据预期用例考虑发热问题。”
