**世界首条量子保密通信干线“京沪干线”正式开通，首次洲际量子通信实现**

  

  

![](../Images/0b98819f0cf7347c2e777ab0a56f38f0.png)  
*(长按*识别*图中二维码即可阅读详细内容)*

9月29日，世界首条量子保密通信干线——“京沪干线”正式开通；结合“京沪干线”与量子科学实验卫星“墨子号”的天地链路，我国科学家成功实现了洲际量子保密通信。这标志着我国已构建出天地一体化广域量子通信网络雏形，为未来实现覆盖全球的量子保密通信网络迈出了坚实的一步。

  

**暗网药头GalVallerius在前往美国参加世界胡子锦标赛后被捕**

  

  

![](../Images/d9c711f68d8dbb2bfcb6ab3d992c8dbd.png)  
*(长按*识别*图中二维码即可阅读详细内容)*

暗网药头Gal Vallerius在前往美国参加世界胡子锦标赛后被捕。这位38岁的法国人被指控担任黑网市场Dream Market（梦幻市场）的管理员，高级主持人和供应商，访问这个市场的人可以购买从海洛因到财务数据等各种不法东西。在8月31日抵达亚特兰大国际机场后，Gal Vallerius被捕，并且笔记本电脑被搜查。美国执法管理局探员称在电脑里发现了50万美元的比特币，还有一款名为OxyMonster的Tor安装程序和PGP加密密钥。

  

**DuoSecurity研究报告称：大量Mac运行过时固件，易受到严重威胁**

  

  

![](../Images/c17b5cedc31154c55700f37c020e4468.png)  
*(长按*识别*图中二维码即可阅读详细内容)*

来自 Duo Security 的研究报告称，大量的 Mac 电脑运行的都是过时的 EFI 固件，这意味着它们极易受到严重的威胁。这家安全公司分析了在生产环境中的 73324 台 Mac 电脑，结果发现 4.2% 的系统运行着过时的 EFI 固件。

**存在2年之久的Linux内核问题上升至高危漏洞，可允许攻击者破坏内存、提升特权**

  

  

![](../Images/9ef1475d96320f645408ace8a6fa840b.png)  
*(长按*识别*图中二维码即可阅读详细内容)*

Qualys 实验室研究人员近期发现一处存在 2 年之久的  Linux 内核 安全问题已上升至高危漏洞级别（CVE-2017-1000253、CVSS 分值为 7.8），允许攻击者破坏系统内存、提升特权。据悉，该漏洞最初由 Google 安全研究人员 Michael Davidson 于 2015 年 4 月发现。不过由于当时并未重视，因此该漏洞的修复程序没有移植到 Linux 3.10.77 长期发行版中。

**美司法部要求Facebook交出反特朗普示威者们的信息**

  

  

![](../Images/9bb7997853543a0e76751cb4e76f2857.png)  
*(长按*识别*图中二维码即可阅读详细内容)*

据外媒报道，美国司法部门的搜查令显示，其要求 Facebook 交出反特朗普示威者、甚至 6000 名给“DistruptJ20”Facebook 页面“点赞”的人们的信息。这是继 Web 主机托管服务提供商 DreamHost 被要求交出与“反特朗普就职典礼暴力抗议活动网站”有关联的用户信息之后的又一份搜查令，而 Facebook 选择了与 DreamHost 站在抵抗的同一战线。
