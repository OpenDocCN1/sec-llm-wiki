# 印度反黑客学院成立新公司HLSS，以填补网安人才空缺

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MjA1MzkyNA==&mid=2655296221&idx=2&sn=69104d531809d44b2c649b6f867d2202&chksm=f02fe696c7586f8097eb02e04d7a7bdf0f91c8ec3e04305fb37309325ce90e818e488f087ac0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655296221&idx=2&sn=69104d531809d44b2c649b6f867d2202&chksm=f02fe696c7586f8097eb02e04d7a7bdf0f91c8ec3e04305fb37309325ce90e818e488f087ac0&scene=27#wechat_redirect)

E安全9月19日讯 亚洲首个领先的反黑客学院E2LABS位于印度海得拉巴，该学院近日宣布创办新公司“HomeLand Security Solutions”（以下简称HLSS）。  

E2LABS致力于为印度调查机构、军事单位和政府机构提供顶尖的网络安全培训计划，并创立网络安全专业人才工作组，提升印度网络安全实力，使其有能力与世界强国（美国等国家）相抗衡。E2LABS拥有强大的客户基础（包含400多家蓝筹股跨国公司），其通过180余名专业人士和全球知名安全专家提供信息安全研究、咨询和培训。

**HLSS**

  

HLSS是E2LABS旗下子公司，是Mile 2在印度的独家授权经销商，同时还是国防解决方案和国家关键基础设施解决方案提供商。

> Mile 2是全球最大的信息安全认证机构，也是全球认可的网络安全杰出培训机构，从美国国防部、FBI、调查机构和全球有影响力的机构获得多项知名认证。

这类合作关系使HLSS有资本提供执行网络安全培训计划，并向接受印度调查机构培训的个人颁发认证，例如印度国家调查局、印度边防部队（BSF）、印度中央后备警察部队（CRPF）、军事单位、政府机构和私营机构。

![](../Images/aa457dfe74e224853d5c2d5d6baeb2ea.png "印度成立新公司HLSS以填补印度人才空缺-E安全")

过去十年，日益猖獗的网络攻击已经严重影响了全球的经济，网络犯罪分子有能力销毁机密数据，全球因恢复数据、执行调查等承担的损失高达几十亿美元。

### **HLSS的成立将减小安全人才缺口**  

全球网络威胁形势日趋严峻，而网络安全人员严重短缺，政府部门和行业（包括金融、医疗保健和零售行业）都存在网络安全人才需求。Cybersecurity Ventures公司预测到2021年全球范围内将因网络犯罪持续增长以及“安全人才输送渠道”匮乏而产生高达350万个网络安全职位缺口。

HLSS将在能力建设方面发挥重要作用，打造人才池，帮助印度处理网络恐怖主义和确保网络安全。

E2LABS 和HLSS的创始人兼董事长Qureshey成立这家新公司时表示，其目标是填补尖端培训和认证计划的人才空缺，并会通过经过测验的沉浸式培训计划帮助参与者掌握信息技术安全科学技术。

Qureshey还表示，特伦甘纳邦已经成为印度首个具有专门网络安全政策的邦，HLSS已成为印度特伦甘纳邦首家提供全球知名安全培训计划的公司。

根据2013年印度《国家网络安全政策》要求，印度政府将成立包含200万名网络安全专业人才的工作组。
