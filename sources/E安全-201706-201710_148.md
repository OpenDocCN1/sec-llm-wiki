# HDI全球保险公司推出：Cyber+ Smart制造企业新“网络保险”服务

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MjA1MzkyNA==&mid=2655295935&idx=4&sn=c7c32775717cc7c1b8c481038ce81676&chksm=f02fe5f4c7586ce23ad7f74af059d198fa53936634647ebb718eb4b8d7f2cfb75acbf1902cfa&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655295935&idx=4&sn=c7c32775717cc7c1b8c481038ce81676&chksm=f02fe5f4c7586ce23ad7f74af059d198fa53936634647ebb718eb4b8d7f2cfb75acbf1902cfa&scene=27#wechat_redirect)

E安全9月9日讯 据保险行业资讯网站Insurance Journal 9月8日报道，HDI全球保险公司新推网络保险产品“Cyber+ Smart”，旨在为制造业提供网络保险服务。  

Cyber+ Smart专为年营收高达3.5亿美元的美国制造公司打造。Cyber+ Smart属于合一限额承保，没有分项赔偿限额，并会解决投保方和其第三方的风险，包括业务收入损失、网络盗窃和网络敲诈。

![](../Images/db77b9deff1768dd75baea95e3c6836c.png "HDI全球保险公司推出：Cyber+ Smart制造企业新“网络保险”服务-E安全")

这个新推的网络保险产品将通过HDI最近宣布的E&S子公司HDI Specialty保险公司提供。

**该保险产品的特点包括：**

> *   投保流程简单（5个问题）；
>     
> *   24小时内精算费率指标；
>     
> *   最高承保能力：全球最高1000万美元（约合人民币6500万元）。
>     

HDI Global SE是一家国际工业保险公司，也是塔兰克斯集团（Talanx Group）旗下的公司。HDI Global SE在美国设有子公司HDI全球保险公司，主要提供商业财产保险服务，总部设在伊利诺伊州芝加哥。HDI Specialty保险公司是HDI全球保险公司的子公司。
