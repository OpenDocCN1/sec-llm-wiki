# 影子经纪人将每月披露两批NSA网络武器，要价400万美元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MjA1MzkyNA==&mid=2655295875&idx=1&sn=6cd61e4ef1810ad21046a13830e44838&chksm=f02fe5c8c7586cdec4f1722347ea523849eece7f5f23973a0fa3db8431ccf2b853251f69532a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655295875&idx=1&sn=6cd61e4ef1810ad21046a13830e44838&chksm=f02fe5c8c7586cdec4f1722347ea523849eece7f5f23973a0fa3db8431ccf2b853251f69532a&scene=27#wechat_redirect)

![](../Images/2017633a5c1b782369ff83355f7baf1b.png)

E安全9月7日讯 与美国国家安全局（NSA）存在关联的黑客组织“影子经纪人”（Shadow Brokers）从今年6月“开闸放货“，推出每月数据泄露服务,开始将逐月出售包括浏览器、路由器、手机漏洞及相关工具、以及SWIFT供应商和央行入侵等数据等等，并于7月份向客户出售一批新的被盗代码，而购买这些代码的客户需要支付不低于2.2万美元的酬金。9月6日，影子经纪人再发消息宣布数据泄露服务的调整情况：

> *   每个月泄露两批数据；
>     
> *   只接受Zcash，不接受门罗币（Monero），加密发送电子邮件；
>     
> *   仅使用加密电子邮箱，建议使用tutanota或protonmail，勿使用i2p、Bitmessage和ZeroNet；
>     
> *   9月会泄露NSA漏洞利用。
>     

![](../Images/9db0ded71afb3518a7e5fd0970961288.png "影子经纪人承诺一个月披露两批NSA网络武器，要价近400万美元-E安全")

时隔2个月，影子经纪人再现江湖承诺一个月会泄露两批NSA漏洞利用。

今年4月，影子经纪人公开泄露NSA漏洞利用，其中包括[五月大规模发作的勒索病毒——“WannaCry”](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655295245&idx=1&sn=bc2bc15d95a00843cea49b984442ddbf&chksm=f02feb46c7586250ffc9c7a8d97b0be9505dc0b0485d77df71167288307d5eed8f77a8295b28&scene=21#wechat_redirect)。WannaCry病毒侵袭了全球大约30万台电脑，给世界多地的医院、邮局、汽车工厂和政府机关带来了混乱。这支神秘的黑客组织如今只接受ZCash付款，并将要加抬高到近400万美元。

影子经纪人当前提供的9月数据及报价见下图：

![](../Images/d0d668e1f1887f36c7f6bf098b652cdf.png "影子经纪人承诺一个月披露两批NSA网络武器，要价近400万美元-E安全")

今年6月该组织首月推出月服务时要价100 ZEC，而如今 “狮子大开口”，要价16,000 ZEC，折合约391.408万美元。   

 ![](../Images/8fe35a05707d427c414e20cb60f1a060.png "影子经纪人承诺一个月披露两批NSA网络武器，要价近400万美元-E安全")

非营利组织GDI Foundation创始人里基·基弗尔斯表示，影子经纪人泄露了NSA漏洞利用“UNITEDRAKE”的手册。手册内容显示，UNITEDRAKE是针对Windows目标的扩展性远程收集系统。

![](../Images/4f053e2483fc2bc53d697e58642809a6.png "1504712503677034302.png")

![](../Images/5e36ac2c53a8c3bf7844f227330d3bbc.png "1504712600671007162.png")

![](../Images/7e43d896369bbcf4f8bee361218c6282.png "1504712357528066161.png")

据NSA承包商斯诺登先前泄露的文档显示，UNITEDRAKE为NSA精英黑客单位“特定入侵行动办公室”（简称TAO）所用。

![](../Images/0aa91d1cbebf930dda5835174da3d95e.png "影子经纪人承诺一个月披露两批NSA网络武器，要价近400万美元-E安全")

卡巴斯基2011年一份报告指出，他们将UNITEDRAKE识别为“EquationDrug”---是NSA“方程式组织（Equation Group）使用的主要间谍平台。

据传，影子经纪人通过每月的泄露服务敛财近9万美元，一些安全专家甚至怀疑该组织的动机并不是敛财。

![](../Images/4e5530dbac5c0be742da9e6e3577ccbd.png "影子经纪人承诺一个月披露两批NSA网络武器，要价近400万美元-E安全")  

![](../Images/1ce12ccfa35258b57c54e25baa910723.png "影子经纪人承诺一个月披露两批NSA网络武器，要价近400万美元-E安全")

虽然目前尚不清楚影子经纪人是如何掌握NSA网络武器的，但据报道，负责调查这些泄露事件的美国当局正在调查可能与该组织存在关联的前NSA内部人员。美国当局怀疑，NSA内部前特工或内部人员可能参与窃取并泄露NSA黑客工具。
