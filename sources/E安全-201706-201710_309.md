# NSA与网络司令部的拆分再生变数

关注E安全 关注网络安全一手资讯

E安全8月3日讯 美国政府问责署（GAO）周二发布报告指出，国防部并未最终决定是否结束NSA和美国网络司令部的“双帽”领导结构，并且国防部尚未满足国会要求的条件。  

去年《国防授权法》（NDAA）第1642节要求国防部长和参谋长联席会议主席共同保证结束所谓的“双帽”领导结构（四星上将迈克尔·罗杰斯兼任NSA局长和网络司令部司令），将不会对网络司令部的军事效能构成风险。

![](../Images/e4a49e48987ee8ad854e7d5fa7176e77.png "GAO报告：国防部尚未满足拆分NSA和网络司令部的条件-E安全")

GAO报告指出，截至2017年4月，国防部高层领导尚未决定是否应当结束“双帽”角色。并补充称，国防部领导层当时正在评估满足《国防授权法》第1642节要求所必需的步骤的资金。

NDAA这条规定要求国防部评估一旦“双帽”领导结构结束，网络司令部对NSA的作战依赖性，以及这两大机构各自履行职责的能力。这就要求国防部在结束“双帽”领导结构之前，进一步确定是否满足以下条件：

> *   部署了强大的作战基础设施，足以满足网络司令部和NSA各自独特的网络任务需求。
>     
> *   建立了强有力的命令与控制系统和流程，用于规划、防御并执行军事网络行动。
>     
> *   已具备收集情报和网络作战战场作战准备的能力。
>     
> *   已具备能力训练网络操作人员，测试网络能力，演练网络任务。
>     
> *   网络任务部队已达到完全作战能力。
>     

完全作战能力预计将于2018年9月实现。

此外，NDAA还要求国防部将网络司令部升格为联合作战司令部。有官员认为，当网络司令部升级为作战司令部，将具有更多能力影响政策和作战规划，包括界定网络域内的要求。

“双帽”结构的利弊及缓解风险措施

GAO这份报告评估了结束“双帽”结构的利弊，此外还提出一系列措施，可供国防部缓解结束这种领导结构带来的风险。其中一项措施是将网络司令部升格为联合作战司令部。其它缓解措施如下：

> *   NSA与网络司令部达成协议，确保在关键问题上协作。
>     
> *   133支网络任务部队实现全面作战能力。
>     
> *   开发持续的网络训练环境，提供真实的按需训练能力。
>     

报告还指出，2011至2016年，国防部已实施了GAO制定的15项（GAO共制定了27项）网络安全建议，成功率为56%，低于整个联邦政府机构实施GAO信息安全推荐的成功率（60%）。
