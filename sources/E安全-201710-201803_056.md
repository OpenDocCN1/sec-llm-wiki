# 美国GAO定义改变世界的五大技术：包括AI与区块链

E安全3月1日讯 美国政府问责局（简称GAO）在新的五年战略计划当中，要求联邦政府将更多研究与开发预算用于推动**五种**可能彻底改变社会的新兴技术成果。  

![](../Images/4b1843022ab86464e0992659482c0b93.png "人工智能与区块链定位为改变社会的技术成果-E安全")

## 

### 

**这五种元素可能彻底改变社会**

GAO 方面在报告当中探讨了当前影响政府与社会的各项技术趋势（作为其2023年发展规划中的组成部分），确定了未来五年内最有可能改变整个社会的技术成果：

> *   人工智能（AI）与自动化；
>     
> *   基因组编辑；
>     
> *   增强现实与大脑连接接口；
>     
> *   量子信息；
>     
> *   加密货币以及区块链。
>     

### **研究经费正在缩减**  

尽管此前美国联邦政府就已经对上述技术给予高度关注，但 GAO 官员们表示，相关研究经费的下降有可能影响这些技术在美国本土的发展进度。

此份报告指出，在2010财年研发支出达到**1470****亿**美元高峰之后，经过近十年的长期预算削减，例如封存、部门关闭以及一系列持续性决议，如今美国政府的可支配资金数额已经大幅下降。

报告认为，部分原因在于联邦政府预算正日益受到限制，而这部分资金正是技术研发的主要支持来源。联邦政府开支的限制提出了新的问题，即美国是否还能够维持目前的技术投资水平，是否有能力推动未来的科技进步。

问责局官员还指出，上述技术仍存在诸多不确定性。要充分发挥人工智能与量子技术等新兴成果的全部潜力可能仍需要多年时间，而区块链的使用对政府服务产生的不可预见影响也有待长期观察。这些担忧将进一步增加资金需求以对其进行深入研究。

报告认为，如果未持续关注并评估美国研发投资的有效性，联邦政府将很难最大限度利用当前有限的资源预算，将来美国可能无法利用这些将颠覆未来的各项重要科学技术。
