# 美国国家安全局通过Twitter发送秘密信息

间谍机构在利用公共渠道传递秘密信息这方面有着悠久的历史，类似于数字接收站或保密性广告这类信息流。

![](../Images/5cb4a2258105eed6fe429334bfd0976f.png "美国NSA通过Twitter发送秘密信息-E安全")

外媒《纽约时报》了解到这样一个事实，**美国国家安全局(National Security Agency)利用Twitter网向一名自称窃取了影子经纪公司机密情报的俄罗斯人发送了“近十多条”编码信息，并与这名俄罗斯人取得了联系。**

据报道，美国国家安全局告诉这名俄罗斯人，希望他能提前发布公开推文，不论是有意联系这名俄罗斯情报员，还是为了证实他自己也参与了此事， 但最终我们都希望能够进行双边谈话，促成合作。

**这些推文是在2017年全年公开发布的。推文内容非常隐秘，大部分是主观上陈述的事实真相，比如庆祝取得电报专利的第一百七十七周年纪念日。**

尽管如此，我们还尚未弄清楚在这些推文信息中，相比普通的工作岗位，有多少是专门为这些特殊的机密岗位而编写的。

美国国家安全局为了获得影子经纪公司的数据，向这名俄罗斯人支付了约10万美元的报酬，但当他向特朗普总统提交一份与俄罗斯有关的信息时，当然其中只有部分信息是有据可查的，所以这笔交易就中断了。

据报道，美国国家安全局怀疑这可能是俄罗斯政府在美国政府内部制造混乱行动的部分计划。

并且类似于这种做法在其他社交网络和其他机构中也普遍存在，当然，如果你没有将自己置身其中，你也就不可能会知道这些情报机构所执行的秘密任务是什么了！
