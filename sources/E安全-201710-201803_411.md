# 美军网安人才有何短板？

E安全11月10日讯 虽然美国陆军网络部队2017年9月底全面投入运作，但美国陆军仍在探索如何招募并留住人才，与私营企业和学术界“抢”人才。  

漏洞赏金咨询公司Luta Security的首席执行官Katie Moussouris（凯蒂·穆苏里斯）表示，国防部需要寻找“遵守规则，但却敢于打破常规”的人才。

![](../Images/6f051c68d98633b1260d07d949410dfe.png "1510226096209010653.jpg")

### 

**底层系统和软件是美网安人员短板**

在美国陆军网络冲突国际会议小组会议上，参与者表示，国防部有能力“打破常规”进行改革，但他们也承认美国与某些国家存在差距。网络培训组织机构SANS Institute的创始人Alan Paller（艾伦·帕勒）表示，虽然美国在武器战场占据优势，但中国和俄罗斯等国过去几十年在加大力度培养网络人才。安全博客Brian Krebs曾报道，俄罗斯相当重视网络安全人才培养。  

Paller表示，这些国家已经对以下三方面了如指掌，然而美国仍在摸索：

> *   加入网络部队的人员需了解底层系统和软件本身；
>     
> *   负责总体计划的网络部队需鉴别英才和庸才；
>     
> *   扩大计划的培养范围，让学生参与网络教育课程学习。
>     

美国陆军网络保护旅指挥官Paul Stanton（保罗·斯坦顿）上校解释称，如果不明白系统是如何连接的，就无法防御网络，对网络保护小组就起不到帮助的作用。但是，他指出，美国陆军的优势在于培养了有能力让团队为了共同的使命团结一心的领导者。他认为只要在队伍中继续培养技术专家，他有信心士兵能完成余下的任务。

### **未来三年网络安全人才将更专业**  

Paller还表示，美国能在三年之内开发人力资源将网络人才引入最需要的领域。然而，真正的问题在于剔除不具备这类专业知识的人员。
