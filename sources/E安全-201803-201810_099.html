FBI WARNING：黑客正在筹划全球银行劫案


FBI称黑客正在筹划全球 “ATM吐钞”计划，通过入侵银行或支付卡处理器，然后使用复制卡在几小时内从全球的提款机提取数百万美元。

DEF CON 2018：“Telltale URLs”信息泄露漏洞


德国安全分析师Konark Modi介绍了“Telltale URLs”的安全问题，访问这些URL的用户可打开特定字符串，查看、提取和更改个人信息。

前任NSA局长任职民营公司


CyberCube公司近日宣布，前NSA局长兼网络司令部司令Michael S. Rogers加入了该公司董事会。这是他退休后的第一个私营职务。


现任NSA局长谈人工智能的价值


现任美国NSA局长兼网络司令部司令Paul Nakasone发表讲话称，他认为人工智能和机器学习有助于美国情报界填补语言学家这一空白。

中东和非洲网络安全市场规模未来5年将大幅增长

MarketsandMarkets报告预测，中东和非洲的网络安全市场规模2023年有望从2018年的156.6亿美元增加到318.2亿美元。

DEF CON 2018：MacOS新漏洞


知名黑客Patrick Wardle发现MacOS新漏洞，其允许攻击者执行“合成鼠标点击攻击”，以绕过苹果的安全措施。


英国计划将退伍军人培训成 “网络战士”


英国国防部支持名为“TechVets”的计划，这项计划旨在对退伍军人进行再培训，以保卫英国网络的安全性。退伍军人的技能和经验可使社会受益。

DEF CON 2018：安卓手机漏洞满满


研究人员称25款安卓手机有47个漏洞，含root访问权限漏洞。受影响的手机有中兴、索尼、诺基亚、LG、华硕、Vivo、Oppo、阿尔卡特等。


医疗数据泄露将导致更大的社会问题

美国国防部前网络政策首席战略官Jonathan Reiber称，网络犯罪分子操纵医疗数据，尤其关键人物的数据，可能将成为最大的社会问题之一。

DEF CON 2018：美国众议员候选人易遭遇黑客攻击


安全专家Joshua Franklin领导的四人组研究人员，在会议上公布的一项研究：约三分之一美国众议员候选人网站存在严重安全漏洞。
