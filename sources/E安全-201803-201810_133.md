# 美国量子计划预算11亿美金将花在哪里？

### 

**美国量子法案成本估算**

过去一年里，美国华盛顿针对量子科学展开了大量讨论。美国政府和国会议员高度重视这项颠覆性技术，众议员拉马**·**史密斯于2018年六月提出“[国家量子计划法案（**H.R. 6227**）](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655299292&idx=1&sn=178cf707a251639746e3adf7c37d2e37&chksm=f02fda97c7585381e399319fe79fffec80ee29a9030471d6fdedb652f044c47c4eb16205f9d4&scene=21#wechat_redirect)”，并且得到众议院科学、太空和技术委员会的一致通过。但该法案仍在等待众议院、参议院、特朗普通过。美国国会预算办公室（简称CBO）近日已发布该法案成本估算，指出该法案未来四年将耗资**11亿**美元。

### **量子计划法案内容**

> *   制定10年“国家量子行动计划”，以加速美国的量子科学发展；
>     
> *   要求在白宫科技与技术政策办公室设立国家量子协调办公室，以帮助协调机构之间的研究；
>     
> *   授权美国能源部（DOE）、美国国家标准与技术研究院（NIST）和美国国家科学基金会（NSF）2019年~2023年投入**12.75**亿美元（约合人民币84.45亿元）增加的量子信息科学（QIS）研究资金。。
>     

此外，该法案还要求联邦机构更好地与私营部门共享研究成果，以促进量子发展、标准化以及劳动力方面的计划。

### 

**钱都将花在哪里？**

美国国会预算办公室关于这份10年量子计划法案的预算报告显示：

> *   美国能源部的量子信息科学研究中心每年将花费**1.25****亿**美元进行量子解决方案的基础研究；
>     
> *   NIST 每年将花费**8000****万**美元用于将 NIST 的研究扩展到量子应用的商业开发；
>     
> *   NSF 将每年花费**5000****万**美元用于 NSF 组织和运营研究和教育计划，包括联邦政府给高等学府的拨款。
>     
> *   美国国家量子协调办公室每年可能要花费**100万**美元，雇用五名工作人员，协调办公室负责的研究工作。
>     

美国国会研究服务中心2018年7月2日发布的一份报告显示，近年来，美国联邦政府每年在量子信息科学上的花费介于**2亿~2.5亿**美元之间。

DOE、NIST 和 NSF 2018年均获得此类活动的拨款。美国的现行法律没有为这些机构执行这些目的而设定具体的拨款金额。美国官员最近作证时表示，有必要增加资金，用于劳动力和软件开发计划，以促进新兴技术的发展。
