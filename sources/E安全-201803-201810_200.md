### 

**关于剑桥分析公司**

> *   2017年9月美国社交媒体巨头 Facebook 表示，俄罗斯曾在Facebook投入10万美元的政治广告影响2016美国大选。
>     
> *   2018年3月，政治咨询公司“剑桥分析”前雇员克里斯多夫**·**怀利爆料，“剑桥分析”曾在2016美国大选期间，利用 Facebook 上5000万名用户资料进行分析，向5000万名 Facebook 用户发送“专属”政治广告，左右选民投票。
>     
> *   2018年4月，Facebook 透露[剑桥分析公司非法收集并滥用其8700万用户的数据助推美国共和党竞选](https://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655298198&idx=1&sn=d6c97b390171443d7e2ef3028c2ec79c&chksm=f02fdeddc75857cbb235e6f0450dd8ea9944dace2a375f6dcaa9e425cb4125d094a82c8fd49f&scene=21#wechat_redirect)。这些数据可能被分成多个部分存储在世界各地，并且数据很可能存储在俄罗斯境内。
>     
> *   2018年5月中旬，剑桥分析在美国依据《破产法》第七章，在纽约向法院提交破产清算申请。
>     

### 

**剑桥分析前员工为特朗普2020连任竞选卖力**

据资深媒体 Quartz 的调查显示，**2018年2月**，美国 Cloud Commerce 公司首席执行官安德鲁**·**范**·**诺伊在美国内华达州成立了这家新的政治咨询公司 Data Propria，Data Propria 的领导层为剑桥分析的前产品负责人马特**·**欧兹科夫斯基。

![](../Images/b75f32cfd025b18a691230fc9bd7912b.png "特朗普2020连任竞选准备，“剑桥分析2”上线-E安全")

*关系图*

**Data Propria与剑桥分析类似**

Data Propria 公司的服务与剑桥分析类似，包括根据心理学通过数据分析选民，根据选民的态度、喜好和其它心理侧写调整投放广告或营销策略。

据美联社证实，至少有四名剑桥分析的前员工在这家新公司——Data Propria 任职，其中就有剑桥分析的前首席数据科学家大卫**·**威尔金森。

> 大卫**·**威尔金森，英国公民，曾在2016美国总统大选期间协助监督选民数据建模。

美国联邦选举法禁止外国公民指导、控制或直接或间接参与美国竞选活动的决策过程。

2017年3月，政府监督组织 Common Cause 向美国联邦选举委员会（FEC）提起诉讼，指控剑桥分析公司的外国雇员违反了该法律，但起诉书没有提到威尔金森。欧兹科夫斯基表示，威尔金森是承包商，不会参与 Data Propria 公司的美国政治活动。

**Cloud Commerce公司与特朗普的联系**

Cloud Commerce 公司曾在2017年收购了特朗普2020选举竞选经理布莱德**·**帕斯卡勒的媒体营销公司。

![](../Images/8236590e43fb6162dc78ea94a08e0d3e.png "特朗普2020连任竞选准备，“剑桥分析2”上线-E安全")

*特朗普2020选举竞选经理 布莱德·帕斯卡勒*

特朗普2020选举竞选经理布莱德**·**帕斯卡勒向美联社表示，他目前将重心放在2018年中期选举上，尚未开始2020选举活动的招聘工作。但据外媒报道，帕斯卡勒可能已经在为2020特朗普竞选连任做准备。

美联社报道称，其记者听到剑桥分析的前产品负责人马特·欧兹科夫斯基与一名人士在公开场合的对话，欧兹科夫斯基声称，他与特朗普2020选举竞选经理帕斯卡勒正忙于特朗普2020年的竞选工作，但当直接与美联社对话时，欧兹科夫斯基却否认参与下一届美国总统竞选活动。

欧兹科夫斯基承认与美国共和党国家委员会签署了2018中期选举活动的合同，并表示愿意接受任何工作，还指出他在特朗普2016年竞选中与特朗普2020选举竞选经理布莱德**·**帕斯卡勒有过密切合作。

![](../Images/af87f816e258e1e493859dad626b6239.png "特朗普2020连任竞选准备，“剑桥分析2”上线-E安全")

欧兹科夫斯基向美联社透露，这家新的政治咨询公司 Data Propria 有10名员工，其中三名为剑桥分析的前员工，但他们专注于竞选活动和数据分析，而不是行为心理学，他表示 Data Propria 不会朝心理测验学的方向走下去。

此外，这家新的政治咨询公司 Data Propria 与特朗普的竞选经理帕斯卡勒存在财务联系。帕斯卡勒是 Data Propria 母公司 Cloud Commerce 的股东之一。 过去一年，Cloud Commerce 围绕帕斯卡勒的前公司（现已更名为 Parscale Digital）进行重建。Cloud Commerce 最近提交给证券交易委员会的文件显示，帕斯卡勒是该公司的董事会成员。
