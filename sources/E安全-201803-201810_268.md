# 首届中国工业信息安全大会 | 做了哪几件大事儿？

2018年5月24日，由工业和信息化部指导，国家工业信息安全发展研究中心、工业信息安全产业发展联盟举办的首届中国工业信息安全大会在北京召开。本届大会主题为“筑工信安全，建网络强国”。

![](../Images/bdb528c0cd1c9cf2129cd4637ea46790.png)

### 

**工业信息安全未来展望**

会上，陈因总工程师就加快构建创新体系、持续提升保障体系、健全完善工作体系、加强人才队伍培养等方面，提出了工业信息安全工作的下一步思路和设想。

![](../Images/a099ae3c59956683bd4ace3ec1e5ea50.png)

梁斌副局长聚焦工业互联网安全，围绕工业互联网安全的重要意义、工业互联网安全工作情况、下一步工作思路和要求进行了介绍。

**国内外专家提出的观点、思路**

> *   中国科学院院士、工业信息安全产业发展联盟专家咨询委员会副主任房建成认为，工业信息安全已成为制造强国和网络强国建设的重要基础支撑，工业互联网安全作为工业信息安全的重要部分，已成为工业互联网发展进程中的“必修课”，是工业互联网健康发展的重要前提。
>     
> *   中国工程院院士、工业信息安全产业发展联盟专家咨询委员会副主任沈昌祥院士分享了可信计算在工业信息安全领域的最新应用情况。
>     
> *   国际电工委员会工业过程测量控制和自动化技术委员会（IEC/TC65）秘书长鲁迪**·**贝利亚迪（Rudy Belliardi）强调工控安全标准在工业信息安全建设中的重要性。
>     
> *   360企业安全集团吴云坤总裁分享了来自企业的最新工业信息安全行业实践。
>     

综合来看，专家们一致认为工业信息安全已成为具有战略性的国家重大安全问题，工业信息安全产业发展前景光明，将会成为下一个安全行业的“蓝海”。

### 

**工业信息安全整体形势“三增一新一短板”**

国家工业信息安全发展研究中心主任尹丽波就当前工业信息安全整体形势“三增一新一短板”作了详细分析与介绍。

![](../Images/ba8e2cc4ecb36a343a5876e495b2814d.png)

“三增一新一短板”，当前工业信息安全整体形势日趋严峻：  

一是，工业信息安全传统威胁呈现增加的趋势：

> 各种大规模、高强度的工业信息安全事件频频发生；爆出的安全漏洞和过去相比有大幅度的增加，尤其是2017年，我中心监测发现和处理研判的工控安全漏洞达到380个，我国暴露在互联网上工业控制系统数量增幅尤其明显，增速超过了全球平均水平，这些大量的暴露于互联网的工业控制系统和设备，相当大一部分都存在着高危的安全漏洞；工业控制系统和设备大量暴露在互联网上，已经成为世界各国工业信息安全的重要威胁和软肋，截至2017年12月，全球范围内暴露在互联网上的工业控制设备超过10万个。

二是，工业互联网的安全作为一个工业信息安全当中的新挑战，带来了一些新的问题和威胁：

> *   工业互联网平台的安全。
>     
> *   工业互联网设备和控制层面的安全问题。
>     
> *   工业大数据安全问题。
>     
> *   工业互联网网络层面的安全问题。
>     

三是，我国工业信息安全的产业发展短板更加突出，在高端电子信息技术的产品研发方面，仍有很大的缺失，同样在工业信息安全的产业方面，也存在着这样一些问题。产业生态尚不健全，核心技术的积累不够，安全服务能力亟待提升。安全运维、安全评估、安全设计与实施等服务能力不足，安全服务市场占有率较低。

**我国工业信息安全产业发展进入“快车道”**

![](../Images/c7369cfbfb0e346cc1384b262705d7e5.png)

国家工业信息安全发展研究中心副主任、工业信息安全产业发展联盟秘书长何小龙出席大会并表示，工业信息安全事关经济发展、社会稳定和国家安全。近年来，在工业互联网、工业云、工业大数据等产业发展需求的带动下，我国工业信息安全产业快速发展，市场规模显著提升。据工业信息安全产业发展联盟统计与调研结果显示，2017年我国工业信息安全市场规模较2016年增长53.6%，工业信息安全产业发展进入“快车道”。

![](../Images/3e7872712c0d5b47a9b27adff81572a2.png)

### 

**发布重磅研究成果**

**一、发布《工业信息安全概论》**

大会主办方国家工业信息安全发展研究中心、工业信息安全产业发展联盟发布了《工业信息安全概论》。本书作为国内第一本系统讲解工业信息安全的综合性普及读物，综合介绍了工业信息安全的发展现状、演进趋势、政策环境、应用形态和技术实践等各个方面的内容。

![](../Images/7c98dda4735488b8719af0a94edd86d3.png)

****二、**发布《中国工业信息安全产业发展白皮书》**

这是国内首份全面系统深入研究分析我国工业信息安全产业发展的报告。

**全国****规模最大的2018工业信息安全技能大赛正式启动**

中国工业信息安全大会主论坛举行了2018工业信息安全技能大赛启动仪式，大赛初赛即将于成都、哈尔滨、青岛、杭州、郑州5个城市为中心，分5个赛区进行。该大赛是目前国内规模最大、规格最高、影响最广的工业信息安全技能竞赛，有利于推动工业信息安全人才培养与选拔，进一步普及工业信息安全常识，提高工业信息安全防护技能，提升行业整体安全意识。

此次中国工业信息安全大会将持续至5月25日。
