# 五角大楼计划投资近100亿美元构建“JEDI云”

E安全4月27日讯  美国五角大楼方面已发布关于其“**联合企业国防基础设施云计划（JEDI 云）**”的第二份征求意见书草案，且该项目的总体采购价格可能逼近100亿美元（约合人民币628亿元）。

这个版本的“企业联合防御基础设施云计划”主要囊括2018年3月美国国防部公布征求意见书初稿之后，针对行业及政府提出的1000多个问题所收到的答复。

在第二份征求意见书发布约一年前，美国国防部长詹姆斯**·**马蒂斯曾经先后造访谷歌及 Amazon 等多家大型科技企业部。而此次发布的版本也将成为终稿前的最后一份草案。这份“JEDI云"征求意见书草案的终稿将于2018年5月发布。

**为选择“单一云提供商”给出解释**

美国政府联邦商业机会网站公布消息称，这份最新征求意见书草案确认称，这些合约将归属于“单一项目”，且“迄今为止已经出现的所有 JEDI 云及原有迭代版本皆不再继续使用”。

美国国防部委托 Cloud Executive Sterring Group 负责整合全部云采购事务，然而该内部团队最终作出了一项存在巨大争议的决定——将全部合约授予同一家云服务供应商。

**AWS或为最终赢家**

几个月以来，专家们一直将 Amazon Web Services 视为此份合约最终竞争力的承包商选项，特别是是考虑到 AWS 目前正在与 CIA 方面合作，且拥有强大的机密数据保护能力。

美国国会要求美国国防部方面在未来几个月内提交两份报告，概述其云发展战略以及为何造成单一供应商解决方案。在此次发布的修订版征求意见书草案当中，美国防部描述了其为何决定全面选择云方案。

![](../Images/0e7c33d56ac1903faa58019845318e4e.png "五角大楼发布第二份征求意见书草案，计划投入数十亿美元构建JEDI云-E安全")

**美国国防部发布声明**

美国国防部方面在其最新声明中解释到：

> “国防部缺乏对整体云基础设施进行协调的方法，行动人员及领导者几乎不可能以‘符合任务要求’的速度作出关键的数据驱动型决策，这将对结果产生负面影响。在缺乏现代化服务支持的情况下，行动人员及领导者被迫在上述能力之间做出选择，或者通过漫长的采购、部署与供应流程努力获取。由于内部部署计算与存储解决方案太过零散导致行动人员不得不面对单调枯燥的数据与应用程序管理流程，并因此严重削弱其快速访问、操纵及分析数据的能力以及战术优势。”

但国防部方面却拒绝发表书面资料，用以说明为何要将全部合约授予单一云服务供应商。

这份经过修订的征求意见书还提到，JEDI 云将与其它现有云项目“相辅相成”。征求意见书指出，“这亦不会排除未来可能出现的其它服务合约。”

五角大楼方面解释称，“只要提出的解决方案符合意见征求要求，提议者即可提出任何形式的联合/合作思路，”这意味着，美国国防部将接受来自各家云服务供应商及其它潜在 IT 承包商的参与与建议。
