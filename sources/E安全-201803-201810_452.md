# 你评估过一次云服务中断的损失吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MjA1MzkyNA==&mid=2655298237&idx=4&sn=a72b7a213d306be446992cf8351ebbd8&chksm=f02fdef6c75857e06dfa7cb1834fcfcd10815ebf4e0259f13330e3e8d609e0d4149236d95bf4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655298237&idx=4&sn=a72b7a213d306be446992cf8351ebbd8&chksm=f02fdef6c75857e06dfa7cb1834fcfcd10815ebf4e0259f13330e3e8d609e0d4149236d95bf4&scene=27#wechat_redirect)

E安全3月30日讯 Veritas Technologies 研究发现，**60%**的受访者都没有评估过一次云服务中断会给自己带来多少损失，由此可见，企业关于“云服务中断”方面的准备不充分。

![](../Images/2c7d9038895413e85bf64318df3947d6.png "你评估过一次云服务中断的损失吗？-E安全")

虽然云服务供应商可以提供基于基础设施服务级别的目标，但是该研究指出，除了不知道云服务供应商的责任外，许多组织都没有成功理解自己要如何才能在云服务中断时，确保他们的重要业务应用能得到恰当的保护。

### 

**了解什么是云服务中断**

Veritas Technologies 研究调查了全球1200个企业的IT决策者。研究表明:

> *   99%的 IT 决策者认为自己的组织将在未来12到24个月内把系统迁移到云；
>     
> *   27%的受访者希望把所有的本地基础设施外包到公共云服务中。企业将系统迁移到云的速度在加快，但在此之前有必要了解云服务突然中断会对业务产生什么影响；
>     
> *   36%的受访者期待每个月的中断时间少于15分钟，但实际上，31%的受访者都都经历过每月中断31分钟甚至更长的时间。
>     

### 

**云服务中断，谁负责?**

> *   59%的受访者认为，在云服务突然中断的时候，云服务供应商要承担主要责任。
>     
> *   83%的受访者认为他们组织的云服务供应商要确保云中的工作负载和数据的安全。
>     

虽然云服务供应商签署了服务等级协议，但是其责任主要存在于基础设施层级，云服务供应商有责任在云服务中断结束后恢复用户基础设施。

![](../Images/0d150356590130e83aecb1fab4f55193.png "你评估过一次云服务中断的损失吗？-E安全")

然而，客户还有其他基础设施服务中断之外的事情需要考量，如基础设施恢复后，应用重新上线的问题。重启服务期间应用的复杂性和服务中断期间数据丢失的数量都决定了应用恢复的时间，这或许比基础设施恢复需要的时间更长。企业或许要更具前瞻性，把应用恢复到本地数据中心或其他云中。这属于企业用户自身的职责范围，而非云服务供应商的责任。

Veritas 执行副主席兼首席产品主管称，许多组织显然对云服务中断缺乏了解，而服务的恢复是云厂商和企业双方的责任。企业的前瞻性决定了是否能从云服务中断中立刻恢复过来。准备得好就意味着中断时间短，经济影响小，其客户信任度损失小，对品牌的不良影响小。

不了解云服务中断会对业务有何潜在影响，用户并不能承担其带来的风险。但如果实施正确的业务弹性策略，就能极大地减少风险，便能乐享云服务的各种优势。
