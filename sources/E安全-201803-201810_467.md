# 美国政府各部门IT现代化财政预算明细

E安全3月26日讯 美国众议院当时时间3月22日通过综合拨款法案，这份长达2232页的法案将会在未来两年拨款近1.3万亿美元（约合人民币8.2万亿元）的资金，涵盖国防支出、IT 现代化、职业培训项目等。

![](../Images/e48e57e68e2883a7bc541ad402eb7a7b.png "美国众议院通过1.3万亿美元拨款法案 IT现代化预算为22.6亿美元-E安全")

美国国会同意拨款1.3万亿美元防止政府再度“关门”，随后交由参议院当地时间周五午夜前表决。如果美国国会不能及时通过临时拨款法案，美国政府将于当地时间24日零时再一次“关门”。这笔拨款中有几十亿将用在 IT 现代化方面。

美国各联邦机构的 IT 现代化改造预算，以支持联邦政府运行至2018年9月30日，即到2018财年结束。

### 

**升级老旧系统**

特朗普政府将 IT 现代化作为议程的重点，这一点在近期发布的《总统管理议程》中得到体现。此外，美国国会也提出升级老旧系统的建议。

美国白宫的 IT 议程核心为技术现代化基金（简称 TMF），该基金将在前六个月获得1亿美元的拨款，这远远不及特朗普要求的2.1亿美元。除了这1亿美元，预算中还包含用于 IT 现代化项目约22.6亿美元，约占综合拨款的0.17%。

具体预算如下：

**1、美国行政管理和预算局（OMB）**

技术现代化基金会也许只能获得**1亿**美元，但这并非 OMB 唯一依赖的政府资助机制。综合拨款中包括一笔1900万美元的款项，其在于提供必要的费用供联邦政府融合、高效利用信息技术。这些资金由OMB局长自行决定支付给任何机构。  

**2、美国财政部（USDT）**  

> *   美财政部将获得2400万美元的拨款，用以支持财政部财务报表审计和内部控制程序，包括 IT 现代化要求。
>     
> *   美国财政服务局将获得421万美元专门用在 IT 现代化上。
>     
> *   美国国税局（IRS）将获得**1.1亿**美元升级业务系统中使用的技术。但是，IRS必须向国会提交季度报告，详细说明相关费用及进度。  
>     

**3、美国人事管理局（OPM）**  

OPM将获得2100万美元用于IT现代化改造，其中一部分将用于信托基金联邦金融系统（FFS）的迁移或现代化改造。  

**4、美国劳工部（DOL）**  

美国劳工部将获得2077万美元用在 IT 现代化上。  

**5、美国社会保障管理局（SSA）**  

美国社会保障管理局将获得**2.8亿**美元，在2018年底之前用于现代化改造。

![](../Images/ae5b3be92d1935e30f4fbf180aa8069f.png "美国众议院通过1.3万亿美元拨款法案 IT现代化预算为22.6亿美元-E安全")

**6、美国住房及城市发展部（HUD）**  

美国住房及城市发展部将获得**2.67亿**美元用于进行 IT 现代化改造和维护。其中2.5亿美元将在下一财年结束时拨款到位，剩下的1700万美元则在2020年9月30日前到位。  

**7、美国农业部（USDA）**  

美国农业服务局将获得7800万美元用于 IT 项目，其中一半必须用于农业系统和其它农业项目交付系统的现代化改造和创新。

但是，机构领导动用这笔资金之前，美国国会拨款委员会希望审核费用超过2.5万美元的项目计划。  

**8、美国商品期货交易委员会（CFTC）**  

从现在起至2019年9月30日，CFTC 将获得4800万美元用在IT方面，但至少要在监察长办公室上花费270万美元。  

**9、美国司法部（DOJ）**  

这项综合拨款法案为司法部的信息共享计划预留了3500万美元，另外还允许司法部长从 IT 项目转移多达3540万美元支持该计划。

美国司法部将获得**1.01亿**美元的预算，其中只有500万美元用于 IT 项目。  

**10、美国国防部（DOD）**  

这份法案划给美国防部的预算不少，其中9100万美元将用于“开发、替换和维护”背景调查IT系统。2015年，OPM 系统遭遇大规模攻击之后，美国国防部负责构建一个安全IT系统处理相关问题。

这项综合拨款法案允许国防部长从运营和维护预算项目中拨出4600万美元，并从研发、测试和评估预算中拨出4500万美元支持该计划。  

**11、美国证券交易委员会（SEC）**  

SEC 在预算支出方面有一定的自由裁量权。但是，这项法案要求 SEC 今年至少要在IT计划上增加4500万美元的支出。  

**12、美国内政部（DOI）**  

该法案为内政部官员设立了6237万美元营运用资金，用于运营、维护、改进、网络安全和设备整合（如数据中心），可随时启用。  

**13、美国政府打印办公室（GPO）**  

GPO将获得854万美元用于IT开发和设备维修。  

**14、美国退伍军人事务部（VA）**  

VA 将获得超过**40.5亿**美元用于 IT 项目及维护工作，其中**3.28亿**美元将用于开发新系统。 此外，还包括一笔**7.82亿**美元的预算用于支持推出电子健康记录系统，这笔资金将在2020年9月30日前提供。
