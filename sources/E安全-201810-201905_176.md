# 震惊！ji32k7au4a83居然是最常见且最易被盗的密码？

**小编来报：**相信大家经常为设置什么样的密码更安全，且更容易让自己记住而头疼，也经常为自己的“小心机”而沾沾自喜，但是你的想法有没有与其他人“撞车”呢？近日，专家解释了为什么ji32k7au4a83的字符组合与多次数据泄露事件有关，跟小E一起了解一下吧！

  

据外媒报道，国际网络安全研究所的网络安全和白帽黑客专家表示，最近的一项调查显示，**“ji32k7au4a83”字符组合是使用最多的密码之一，但也是最脆弱的密码之一。**

 

![](../Images/f9c0f8f3a6c204a57e3e11400dfaa4a6.png)

  

**你可能会觉得，“ji32k7au4a83”看起来像一个随机的字符组合，比“password1”或 “qwerty12345”要复杂一些。**但专家说其实这是一个非常弱的密码。在注册密码时，如果你用“01234”、“password”或“querty”等密码，你会收到注册平台的提示：出于安全考虑，用户必须用字母和数字结合的新密码。此外，新密码还必须有一个合理的长度（不能太长或太短）。  

 

网络安全专家表示，ji32k7au4a83经常出现在数据泄露事件泄露的信息列表中。存储数据盗窃信息的Have I Been Pwned信息安全平台显示了使用这种字符组合的惊人频率。**该密码已被确认至少在140起数据泄露事件中出现，引起了网络安全人员的注意，他们一直想找到答案。**

 

![](../Images/586cdf3c9fde3ac8506dd740ad02f1a2.png)

  

原因很快就被发现了。**因为这个密码使用了汉语“注音符号”的拼音系统。**中国大陆地区自1958年推行汉语拼音方案以后停止推广使用“注音符号”，但目前注音符号仍为中国台湾地区汉字的主要拼读工具之一。  

 

**其实，组合的字符‘ji3’,‘2k7’,‘au4’,‘a83’对应的汉字为“我的密碼”。**

 

**ji3 = 我**

**2k7 = 的**

**au4 = 密**

**a83 = 碼**

通过使用注音键盘输入这些字符，系统将默认他们转化为拉丁字母，从而生成ji32k7au4a83的序列，因此，网络安全专家得出的结论是，**许多说普通话的用户犯了基本的安全错误，用了非常简单、很容易被猜到的密码。**

为了自己的账号安全，还是要设安全性高一点的密码哦！
