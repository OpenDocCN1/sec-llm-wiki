# 打脸美国！华为在布鲁塞尔的网络安全中心正式开幕

**小编来报：**美国一直声称华为会对国家安全造成威胁，但3月5日，华为在布鲁塞尔成立了网络安全透明中心。

  

据外媒报道，美国政府声称华为对国家安全构成威胁，华为对此进行了反击。周二，**这家中国电信巨头在布鲁塞尔成立了网络安全透明中心（Cyber security Transparency Centre）。**布鲁塞尔有欧洲的首都之称。

 

华为副董事长胡厚崑对欧盟和世界经济论坛的代表们表示：“信任需要建立在事实的基础上。事实必须是可验证的，而验证必则基于共同标准。我们相信这是面向未来数字化时代构筑安全信任的有效模式。”

 

![](../Images/884a7fc2796f16dea0c67b60e164f017.png)

  

在布鲁塞尔华为网络安全透明中心的开幕仪式上，胡厚崑强调信任、合作和共同标准是透明的基础。  

 

之前有消息称，华为正在考虑起诉美国政府，称其不公平地阻止所有联邦机构使用华为设备。

 

在上个月巴塞罗那举行的世界移动通信大会贸易展上，美国官员指责华为的设备受到中国政府的“潜在控制”。**尽管有人批评美国没有提供相关证据，但美国官员仍在游说盟国和全球电信运营商避开华为。**

 

![](../Images/7209e3e8508f8039da8466acd522ec87.png)

  

虽然英国和德国都是美国的盟友，但它们并没有屈服于美国，允许华为建立研发中心。  

 

随着华为继续争取外国市场并平息美国的指控，它还提出了在波兰建立安全测试设施。虽然今年1月，波兰当局以间谍罪逮捕了华为的一名员工。

 

据美联社报道，**网络安全透明中心“将成为政府机构、技术专家、行业协会和标准组织在网络安全方面进行合作的平台”，还允许客户和互联网公司测试华为的网络设备。**
