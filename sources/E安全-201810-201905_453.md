# Threat Stack收购Bluefyre以提升云基础构架安全性

**小编来报：**为提升运行中应用程序的安全性，Threat Stack在一次竞标中宣布收购Bluefyre。Threat Stack将利用Bluefyre的产品组合帮助开发者构建安全的云原生应用程序。

  

周四，Threat Stack表示，签订该交易是为了升级公司的产品组合与解决方案，尤其是为了帮助“开发者构建安全的云原生应用程序，该程序可用于在应用程序运行环境检测及预防威胁，包括在Kubernetes上运行的应用程序。”

 

财务细节尚未披露。

 

Bluefyre公司成立于2017年，总部位于马萨诸塞州波士顿，**专注于从控制平面到应用层的堆栈安全策略配置**。

 

作为Threat Stack Cloud Security Platform 和 Cloud SecOps 项目的一部分，Threat Stack计划集成Bluefyre的功能并在明年初发布。

 

![](../Images/f6b73c5ecac7a03e4ac11b71b6047bcc.png)

  

**而现有技术已具备云基础架构和安全功能**。Threat Stack表示，作为更广泛的DevSecOps项目的一部分，Bluefyre所提供的核心层安全解决方案一经集成，便可为顾客提供“完整，充足的堆栈安全可观察性，**包括控制平面、主机、容器、编配以及应用层**”。  

 

Bluefyre首席执行官兼联合创始人蒂姆·邦特尔（TimBuntel）以及联合创始人萨宾·托马斯（Sabin Thomas）将分别以“应用安全产品（Application Security Products）”与“应用安全工程（ApplicationSecurity Engineering）”新任副总裁的身份，加入Threat Stack。

 

Bluefyre团队会留在原来的城市，但将移至位于马萨诸塞州波士顿的Threat Stack总部。

 

邦特尔表示，“企业日益重视云应用程序的开发，而在整个开发及运行生命周期，实时监控与检测至关重要。**Bluefyre保护应用程序的功能增强了Threat Stack的云基础构架安全的可观察性，为DevOps及安全团队提供了一个可供深入观察及智能操作的工具**。”
