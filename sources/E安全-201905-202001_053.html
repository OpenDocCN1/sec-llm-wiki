1.风险公告


2019年12月1日，有研究人员发现PyPI上的python3-dateutil和jeIlyfish包带有恶意代码，实际上这两个带有恶意代码的包是仿冒的python-dateutil（目前最新2.8.1版本）和jellyfish（目前最新0.7.2版本，仿冒的版本第一个l是i的大写I），含恶意代码具体文件是：jeIlyfish/_jellyfish.py中的313到338行的代码，代码的扩展恶意行为主要是盗取本地的SSH和GPG的Key，并发送到指定的服务器，随后官方删除了该代码，相关讨论链接：


https://github.com/dateutil/dateutil/issues/984

https://github.com/jamesturk/jellyfish/issues/126


根据拿到的样本分析，植入的代码进行了Base64编码：



提取该代码段直接执行，会请求URL：urlopen('http://bitly.com/25VZxUbmkr')下载文件，该URL重定向跳转到：


http://gitlab.com/olgired2017/aeg_wandoo_dag_m3/raw/master/hashsum，下载的文件代码恶意行为就是包含盗取本地的SSH和GPG的Key，并POST发送到指定的服务器：68.183.212.246:32258。


2.影响版本


正常版本：

https://pypi.org/project/python-dateutil/

https://pypi.org/project/jellyfish/


带有恶意代码的仿冒版本：

https://pypi.org/project/python3-dateutil/（无法访问，官方已经下架）

https://pypi.org/project/jeIlyfish/（无法访问，官方已经下架）


根据版本记录，jeIlyfish仿冒发布了2个版本：

https://libraries.io/pypi/jeIlyfish

pip install jeIlyfish==0.7.0

pip install jeIlyfish==0.7.1


目前国内多个镜像服务器还能找到jeIlyfish-0.7.0.tar.gz和jeIlyfish-0.7.1.tar.gz存在恶意代码的版本。


根据版本记录，python3-dateutil 仿冒发布了11个版本：


https://libraries.io/pypi/python3-dateutil

pip install python3-dateutil==2.8.2

pip install python3-dateutil==2.8.3

由于发现后即被下架，目前国内镜像服务器暂未发现该包。


3.缓解措施


检查代码中是否包含恶意的jeIlyfish代码，其中第一个l实际是i的大写I，或是直接全局搜索代码库中是否含有以下关键字的文件：


“base64.b64decode(ZAUTHSS)”

“zlib.decompress(ZAUTHSS)”


友情提示：针对开源代码Python PyPI库的供应链攻击之前就有发生过，建议使用PyPI的Python环境做必要的恶意代码筛查，防止遭受恶意仿冒攻击。
