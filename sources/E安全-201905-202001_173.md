# 俄罗斯黑客竟然对同行下手？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MjA1MzkyNA==&mid=2655304905&idx=1&sn=adccf3d1e247bbefcef913d4c26cc8bc&chksm=f02fc082c7584994ca74c27ffd3584ed173b51429229b46605925de1cdd3f845c3f45de49dea&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655304905&idx=1&sn=adccf3d1e247bbefcef913d4c26cc8bc&chksm=f02fc082c7584994ca74c27ffd3584ed173b51429229b46605925de1cdd3f845c3f45de49dea&scene=27#wechat_redirect)

       据外媒报道，10月21日，美国国家安全局（National Security Agency ）和英国国家网络安全中心（National Cyber Security Centre ）发布公告称，来自俄罗斯的黑客组织Turla**“劫持”**了伊朗黑客组织APT34的命令与控制（command and control）设备以及运营设备。

![](../Images/7beace612b3fd88d73e96c8b31600f73.png)  
       在入侵成功后，Turla获得了APT34的受害者列表、目标系统访问凭据，以及各种恶意软件的源代码。在对这些恶意软件的源代码进行修改后，Turla可以使用自己的C＆C服务器向其发出指令。目前，**ATP34已经使用所窃取的Neuron和Nautilus恶意软件攻击了35个国家/地区的实体。**

  

![](../Images/3ac3a05c0ac809caf50eadbce19b3966.png)     据了解，Turla和APT34分别由俄罗斯政府和伊朗政府暗中支持，其中，APT34又被称为OILRIG，该组织自2014年起开始活动，主要攻击目标为金融、能源、电信和化工领域的关键基础设施。  
不过，俄罗斯和伊朗政府都对有关网络攻击的指控予以了否认。
