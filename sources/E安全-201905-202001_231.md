# 戴尔推出新一代安全存储设备

**小编来报：**近日，戴尔新推出了三款Dell EMC PowerProtect Data Domain系列安全存储设备。

  

据外媒报道，戴尔新推出了三款Dell EMC PowerProtect Data Domain系列安全存储设备，包括PowerProtect DD9900、DD9400和DD6900，以及PowerProtect DD虚拟版本中的软件定义设备。

  

![](../Images/8a7c5756a0bef2aa9ba9bffb3c70c5a7.png)

  

据了解，Dell EMC PowerProtect DD系列设备可支持企业进行网络恢复，并减少网络攻击所带来的影响。其Cyber Recovery功能还支持自动恢复数据。这三款新设备可储存的数据体量从48TB至1.25PB不等。相比前代产品，新产品的备份速度提高了38%，数据恢复速度提高了36%。

![](../Images/4ad06409f5b0aed65a24cb71c8ca16e3.png)

  

专家表示，混合多云环境、全球性数据中心和EB级规模数据将对未来的数据保护管理带来新挑战，而戴尔正致力于应对这些新挑战。
