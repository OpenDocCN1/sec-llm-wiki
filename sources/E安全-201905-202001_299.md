# 思科发布车载系统测试工具

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MjA1MzkyNA==&mid=2655304130&idx=1&sn=419b600d760a05781fbe66e14a2b7fdc&chksm=f02fc589c7584c9f62e510441cfd98bb579f670500509efd395f8c1b416985ab7f97325fdff7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655304130&idx=1&sn=419b600d760a05781fbe66e14a2b7fdc&chksm=f02fc589c7584c9f62e510441cfd98bb579f670500509efd395f8c1b416985ab7f97325fdff7&scene=27#wechat_redirect)

**小编来报 **这款测试工具名为4CAN，可以帮助技术人员检测车辆的CAN总线，从而发现车载系统漏洞。

  

据外媒报道，近日，思科发布了一款名为4CAN的开源测试工具，旨在帮助安全人员检测车载计算机系统中的漏洞。  

![](../Images/0c03b5252dc6d7baa75442da5bee184b.png)

  
据了解，现代汽车厂商会在车辆上安装大量的传感器，用于向车载计算机提供各类实时信息，并将车载系统连接至网络。**然而，在带来便利的同时，这些车载组件也为车辆带来了潜在安全风险**。专家称，黑客可以通过通过Wi-Fi、蓝牙或蜂窝通信协议来发起针对车载计算机系统的攻击。  

![](../Images/3540867ac33db45ac2f39c94956af7fa.png)

  
思科表示，车载计算机系统的核心是控制器区域网络（ControllerArea Network 简称CAN），而4CAN允许技术人员同时测试4条CAN总线，并大大简化了相关设置，以更好地帮助技术人员找出漏洞。工作人员披露，4CAN工具可以验证内部CAN总线通信的通信策略，并随机发送有效载荷，以检测用于控制/与车辆交互的CAN命令。  
据悉，思科已经发布了4CAN的开源版本，技术人员在得到Creative Commons Attribution Share-Alike许可授权后，便可从GitHub下载该产品。
