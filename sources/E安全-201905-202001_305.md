# 多家知名厂商将组建“机密计算联盟”

**小编来报：**该联盟将致力于推广相关安全技术，以提高企业网络安防水平。

  

据外媒报道，近期，多家云计算和相关硬件供应商宣布将共同组建机密计算联盟（Confidential Computing Consortium），以推广机密计算。该组织现有成员包括：**阿里巴巴、ARM、百度、谷歌云、IBM、英特尔、微软、红帽、瑞士电信和腾讯**。  

![](../Images/a8cd1090eed5f929cdc07152bc4aa6d5.png)

  
专家表示，机密计算基于硬件和软件的技术解决方案，帮助隔离计算机内存中的用户数据，以避免将其暴露于其他应用程序、操作系统或云服务器租户。  
据了解，该组织将着重推广可靠执行环境（trusted execution environment，简称TEE），即计算机CPU内存的硬件/软件强制私有区域。联盟成员称，TEE能确保只有特定应用程序可在其内部写入和读取数据，因此可用于保护云计算数据及普通程序数据。  

![](../Images/77fd43afd0bb5677f5e4ffed382559c4.png)

  
此外，该组织成员还将共享数种开源工具，包括：一、英特尔软件保护扩展（Intel Software Guard Extensions）软件开发套件，旨在避免特定代码与数据在硬件层被泄露或修改。二、微软开源飞地软件开发套件，旨在帮助构建TEE应用程序。三、红帽Enarx软件开发套件，旨在帮助研究人员创建和运行私有、可替换及无服务器的应用程序。  
据了解，Linux基金会将负责监督该组织活动。
