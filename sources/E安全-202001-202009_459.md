**1\. MetInfo存在文件上传漏洞**

  

漏洞介绍：

MetInfo是一款专业的企业级CMS建站系统。

  

漏洞危害：

MetInfo存在文件上传漏洞，攻击者可利用该漏洞获取网站管理员权限。

  

影响范围：

长沙米拓信息技术有限公司 MetInfo V7.0.0

  

修复方案：

更新对应补丁

  

来源：CNVD

  

**2\. Microsoft Internet Explorer远程代码执行漏洞**  

  

漏洞介绍：  
Microsoft Internet Explorer（IE）是美国微软（Microsoft）公司的一款Windows操作系统附带的Web浏览器。

  

漏洞危害：  
Microsoft IE 9、10和11中存在远程代码执行漏洞，该漏洞源于程序未能正确访问内存对象。攻击者可利用该漏洞在当前用户的上下文中执行任意代码，损坏内存。

  

漏洞编号:

CVE-2020-0640

  

影响范围：  
Microsoft Internet Explorer 10  

Microsoft Internet Explorer 9

Microsoft Internet Explorer 11

  

修复建议：  
更新对应补丁

  

来源：CNVD

**3.****phpMyAdmin SQL注入漏洞**

  

漏洞介绍：  
phpMyAdmin是phpMyAdmin团队的一套免费的、基于Web的MySQL数据库管理工具。该工具能够创建和删除数据库，创建、删除、修改数据库表，执行SQL脚本命令等。

  

漏洞危害：  
phpMyAdmin中存在SQL注入漏洞。该漏洞源于基于数据库的应用缺少对外部输入SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令。

  

漏洞编号：

CVE-2020-5504

  

影响范围：  
phpMyAdmin Phpmyadmin  

  

修复建议：  
更新对应补丁 

  

来源：CNVD

**5\. Microsoft Windows和Microsoft Windows Server权限提升漏洞**

Microsoft Windows 7 SP1

**6\. WebLogic远程代码执行漏洞**

  

漏洞介绍：  
最近Oracle官方发布补丁更新公告，披露了多个高危漏洞，其中涉及两个严重级别的WebLogic远程代码执行漏洞（CVE-2020-2546、CVE-2020-2551）。CVE-2020-2546：攻击者利用T3协议进行反序列化漏洞的利用，实现远程代码执行；CVE-2020-2551：攻击者通过IIOP协议远程访问WebLogic Server服务器上的远程接口，传入恶意数据，从而获取服务器权限并在未授权情况下远程执行任意代码。

  

漏洞危害：

成功利用该漏洞的攻击者可以对目标系统实现远程代码执行，进而控制WebLogic服务器。

  

影响范围：  
WebLogic 10.3.6.0.0  

WebLogic 12.1.3.0.0  
WebLogic 12.2.1.3.0  
WebLogic 12.2.1.4.0

  

漏洞编号：

CVE-2020-2546、CVE-2020-2551

  

修复建议：  
更新对应补丁

  

来源：CNVD
