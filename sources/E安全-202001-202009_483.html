1.  漏洞公告


2019年12月17日，Citrix发布了ADC（Application Delivery Controller）和 NetScaler （Citrix Gateway）10.*到13.*的版本存在远程代码执行的漏洞公告，漏洞对应CVE编号：CVE-2019-19781，相关链接：

https://support.citrix.com/article/CTX267027


官方针对该漏洞提供了解决方案用以缓解该漏洞，主要通过配置策略的方式加固系统，具体加固策略配置参考：

https://support.citrix.com/article/CTX267679（需要高版本浏览器访问）


近日，安恒应急响应中心监测到有持续对该漏洞关注的研究人员发布了阶段性的利用代码，该POC代码能实现路径遍历效果，但暂未达到代码执行效果，预计很快会有人开发出能实现远程代码执行效果的漏洞利用代码，建议还未进行缓解加固的用户尽快加固系统。


2.  影响范围


CVE-2019-19781漏洞主要影响以下版本：

Citrix ADC和Citrix Gateway 13.0版本

Citrix ADC和NetScaler Gateway 12.1版本

Citrix ADC和NetScaler Gateway 12.0版本

Citrix ADC和NetScaler Gateway 11.1版本

Citrix NetScaler ADC和NetScaler Gateway 10.5版本

3.  漏洞描述


根据目前公开的POC代码示例，主要通过构造“/../”路径读取“/vpns/”路径下的敏感文件，这也是加固策略增加访问控制的触发点。


4.  缓解措施


高危：目前漏洞细节和部分利用代码已经公开，建议及时参考官方缓解措施加固系统，增加访问控制措施。


缓解措施参考：

https://support.citrix.com/article/CTX267679（需要高版本浏览器访问）


友情提示：

Citrix相关产品历史上已经报过多个安全漏洞，建议使用该组件的企业经常关注官方安全更新公告。
