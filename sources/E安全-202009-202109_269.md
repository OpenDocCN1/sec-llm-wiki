# 微软2020年12月补丁星期二修复了58个错误，其中9个至关重要

**E安全12月11日  **据外媒报道，微软2020年12月周二的补丁安全更新解决了58个漏洞，其中22个是远程代码问题。

  

![](../Images/23ecec4bf8e4f6ee0d30e52dec3b0c04.png)

这些缺陷影响了多种产品，包括Microsoft Windows、Edge(基于EdgeHTML的)、ChakraCore、Microsoft Office、Services and Web Apps、Exchange Server、Azure DevOps、Microsoft Dynamics、Visual Studio、Azure SDK和Azure Sphere。

微软2020年12月例行发布的补丁中，**有9个漏洞被评为“严重”，46个被评为“高危”，3个被评为“中度”。**  

  

目前ZDI项目已经报告了六个漏洞，这个月修补的漏洞没有一个被公开或在发布时受到攻击。

  

![](../Images/a88b5bf4357a6c0d1dac1426e6f4dea0.png)

  

微软本月发布的最严重的问题是:

  

**CVE-2020-17132** - Microsoft Exchange远程代码执行漏洞。

  

**CVE-2020-17121** -微软SharePoint远程代码执行漏洞。

  

**CVE-2020-17095 **\- Hyper-V远程代码执行漏洞。  

  

**CVE-2020-16996** - Kerberos安全特性绕过漏洞。

  

**CVE-2020-17118 **\- Microsoft SharePoint远程代码执行漏洞。

  

**CVE-2020-17121 **\-微软SharePoint远程代码执行漏洞。  

  

微软发布的安全更新的完整列表可以在官方安全更新指南门户网站上找到。
