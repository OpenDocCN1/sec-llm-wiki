# 又在作妖！特朗普国家安全顾问：华为威胁是未来的“头号担忧”

**E安全11月18日**  据外媒报道，近日，美国国家安全顾问罗伯特·奥布莱恩(Robert O 'Brien)表示，中国华为是推进民主政治的“头号担忧”。

![](../Images/8d30baede7d2750b3d41142f5666c66d.png)

  

在上周举行的2020年全球安全论坛(2020 Global Security Forum)上，奥布莱恩在采访中提到了人们对全球5G网络使用华为设备的担忧，并指责这家陷入困境的公司可能会接入敏感网络，对其构成了情报威胁。

  

奥布莱恩说:“如果你相信民主，你关心我们的选举，这是我们前进的首要问题，所有民主国家都关心的是，中国可以利用华为在我们国家做什么，这真的很可怕。”

![](../Images/6e13c4b8b89bb702dffdb98c7ee215a1.png)

  

奥布莱恩详细指出，特朗普政府已经采取了一系列措施予以反击的华为，防止可能会给中国政府“打开后门，获取世界上的每一点数据”。  

  

奥布莱恩赞扬了特朗普政府向盟国施压，迫使其将华为设备排除在敏感网络之外的努力。他指出，他认为这是一些国家出于对数据隐私和安全的担忧，做出了这样的选择。

  

![](../Images/272d4a56e80a4caf4137b763b1941895.png)

奥布莱恩说:“真正发生变化的是，特别是欧洲人，还有许多亚洲人，他们的个人隐私数据将完全为中国共产党所有。”

  

美国联邦通信委员会(FCC)去年一致投票将华为列为国家安全威胁，并禁止美国电信集团使用FCC 85亿美元通用服务基金(Universal Service Fund)中的资金购买华为设备。

  

华为目前正在进行一场充满挑战的法律战。
