***漏洞详情***

**1.SaltStack 远程命令执行漏洞**

  

漏洞介绍：  
SaltStack是基于Python开发的一套C/S架构配置管理工具。

  

漏洞危害：  
近日SaltStack官方发布安全更新，修复了包括 CVE-2020-16846 远程命令执行漏洞在内的多个漏洞。在CVE-2020-16846 远程命令执行漏洞中，攻击者通过构造恶意请求，通过操作SaltStack API接口，从而执行命令并控制服务器。阿里云应急响应中心提醒SaltStack用户尽快采取安全措施阻止漏洞攻击。

  

漏洞编号：  
CVE-2020-16846

  

影响范围：  
SaltStack < 3002.1  
SaltStack < 3001.3  
SaltStack < 3000.5  
SaltStack < 2019.2.7

  

修复方案：  
及时测试漏洞修复的版本并及时升级。

  

来源:阿里云先知

**2.Tomcat WebSocket 拒绝服务漏洞**

  

漏洞介绍：  
Tomcat 是一个小型的轻量级应用服务器，在中小型系统和并发访问用户不是很多的场合下被普遍使用。

  

漏洞危害：  
Tomcat 未针对 WebSokcet 进行包长度校验，特制的 WebSocket 请求包将导致处理函数无限循环，最终导致服务停机并拒绝服务。

  

漏洞编号：  
CVE-2020-13935

  

影响范围：  
apache:tomcat :  
• 9.0.0.M1~9.0.36  
• 10.0.0-M1~10.0.0-M6  
• 8.5.0~8.5.56  
• 7.0.27~7.0.104

  

修复建议：  
及时测试并升级到最新版本

  

来源：360CERT

**3.Adobe Creative Cloud Desktop Application存在未明漏洞**

漏洞介绍：  
Adobe Creative Cloud Desktop Application是美国奥多比（Adobe）公司的一套用于在Creative云会员管理中心管理应用程序和服务的应用程序。该程序支持同步和共享文件、管理字体以及访问商业摄影和设计的资产库。

  

漏洞危害：  
Adobe Creative Cloud Desktop Application存在安全漏洞。攻击者可利用漏洞提升权限。

  

漏洞编号：  
CVE-2020-9669

  

影响范围：  
Adobe Creative Cloud Desktop Application <=5.1

  

修复建议：  
及时测试并升级到漏洞修复的版本。

  

来源：CNVD

**4.e-cology 8.0前台存在SQL注入漏洞**

  

漏洞介绍：  
e-cology是一款协同办公平台。

  

漏洞危害：  
上海泛微网络科技股份有限公司e-cology 8.0前台存在SQL注入漏洞，攻击者可利用漏洞获取数据库敏感信息。

  

影响范围：  
上海泛微网络科技股份有限公司 泛微e-cology 8.0

  

修复建议：  
及时测试并升级到漏洞修复的版本

  

来源：CNVD
