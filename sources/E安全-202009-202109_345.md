# 重新任命白宫“网络沙皇”的呼声越来越高

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MjA1MzkyNA==&mid=2655312890&idx=2&sn=0d8157fe2eadeeb8ed6e979d601ea645&chksm=f02fa7b1c7582ea7b027e1f8a9b3c0a2d8124938bd553490f8ce228196d559ff2140fb0805e2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655312890&idx=2&sn=0d8157fe2eadeeb8ed6e979d601ea645&chksm=f02fa7b1c7582ea7b027e1f8a9b3c0a2d8124938bd553490f8ce228196d559ff2140fb0805e2&scene=27#wechat_redirect)

**E安全11月13日讯**  据外媒报道，近日白宫内部要求恢复网络沙皇的压力正在增大，两党盟友在国会联合起来推动这一提议，而即将上任的新政府将专注于解决网络安全挑战。

![](../Images/1f507fefa80c80463543c36ec5e5e958.png)

![](../Images/c96207a5de0ebaed286d3f7444afa2af.png)

外部专家和盟友表示，他们对当选总统拜登(Joe Biden)将在白宫设立一个网络安全协调员的职位感到乐观。此前，特朗普政府在2018年取消了这个职位。

  

当时的国家安全顾问约翰·博尔顿表示，此举旨在减少官僚作风，但两党成员都对这一决定提出了批评，称这一决定剥夺了协调网络政策的关键机制。

  

随着新一届政府将于明年1月上台，议员们正在加紧努力建立一个国家网络主管职位，为联邦网络安全举措提供一个中央协调力量。

![](../Images/01d2b73030ddd58846fcf847c02a6085.png)

  

今年早些时候，网络阳光委员会(cyber Solarium Commission, CSC)提交了一份建议，建议在白宫设立一个国家网络主管，该职位的权力将比被取消的职位更大，并将得到参议院的批准。

  

众议院通过的2021年国防拨款法案中包含了设立这一职位的条款，但参议院今年早些时候批准的版本中没有。参议院的版本只是要求对设立这一角色的“可行性”进行“独立评估”。

![](../Images/448a4955b1cfddf0abdfbbcd6b9103fa.png)  

参议员安格斯▪金告诉记者，他希望议员们能够“解决分歧”，在未来几周内，众议院和参议院就各自的立法版本进行协商。

  

**专家表示，即将上任的拜登政府可能会增加任命国家网络主管的机会。**

  

![](../Images/cab4c8c33f8811d34b14e11d9ea3f292.png)

  

曾在国家安全委员会(National Security Council)担任奥巴马总统特别助理和网络安全协调员长达五年的迈克尔·丹尼尔(Michael Daniel)表示，他认为即将上任的拜登政府将“很有可能”会设立一个网络安全协调员的职位，无论该职位是否包括在国防法案中。

  

拜登竞选团队的发言人本周表示，即将上任的拜登政府计划把重点放在以下问题上:

  

恢复美国在网络空间的领导地位;

  

重新投资保障关键基础设施;

  

让在网络空间攻击美国的国家付出代价;

  

保障选举系统的安全。

  

曾在乔治·w·布什(George W. Bush)政府担任白宫首席信息官的佩顿(Theresa Payton)认为，无论哪个政党执政，白宫都需要一个网络安全方面的中央协调人物。
