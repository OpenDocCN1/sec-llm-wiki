# 基于安全考虑微软支持Win10部署阶段更新Defender反病毒软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MjA1MzkyNA==&mid=2655311460&idx=1&sn=67002916bf0facef9180a68c7cdec2f4&chksm=f02faa2fc75823393f52799edde40bcb3549fdcf7e2c2041b66ad6b13607e4707b0ae4d5e9ce&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655311460&idx=1&sn=67002916bf0facef9180a68c7cdec2f4&chksm=f02faa2fc75823393f52799edde40bcb3549fdcf7e2c2041b66ad6b13607e4707b0ae4d5e9ce&scene=27#wechat_redirect)

 E安全10月9日讯   近日，微软发布了一个新工具，旨在让用户可以更新最新版本的 Microsoft Defender 进而保护已安装的 Windows 10 和 Windows Server 安装映像。

![](../Images/ec67fe76e37cd8d46ea0e33235258dc9.png)

使用此工具应用的 Microsoft Defender 软件包包括每月更新和修补程序以及最新的安全情报更新。用户部署后，系统将更新目标Windows 安装映像上的反恶意软件客户端、引擎和签名版本。

  

![](../Images/955bba2e1bc6a77ffecfe4a5ac5c15df.png)

据了解，新工具为**32****位**和**64****位**架构提供，支持Windows 10(企业版、Pro版和家庭版)、Windows Server 2019和Windows Server  2016。

**“这些链接指向zip文件 Defender-update-kit- \[x86 | x64\] .zip。解压缩.zip文件以获取Defender更新包（defender-dism- \[x86 | x64\] .cab）和更新修补工具（defenderupdatewinimage.ps1），它们有助于操作系统安装映像的更新操作。”**

![](../Images/ab3027060a2764fcec76377102544823.png)

要运行该工具，只需运行 **DefenderUpdateWinImage.ps1**  Powershell脚本。  

![](../Images/d90250504c0d6e3d3f4cfb2f1c87ced9.png)![](../Images/25655f9ea3238d3f7ae3d78daedd6936.png)

**Microsoft解释：**

要运行此修补工具(DefenderUpdateWinImage.ps1)，您需要具有 PowerShell 5.1 或更高版本的 64 位 Windows 10 或更高版本的 OS 环境，它需要安装Microsoft.Powershell.Security 和 DISM 模块。

![](../Images/25655f9ea3238d3f7ae3d78daedd6936.png)

同时Microsoft提醒，在 Windows 系统新装部署的前几个小时中，用户可能会受到 Microsoft Defender 保护不足的影响，因为在安装系统镜像的时候可能会包含已经过时的反恶意软件。

  

在第一次反恶意软件软件更新完成之前，这些设备仍将处于保护之下。定期对操作系统安装映像进行维护，以更新 Microsoft Defender 二进制文件，可以最大限度地减少新部署中的这种保护漏洞。

![](../Images/b6dc21ace86240274e1cf81ca260aa50.png)![](../Images/25655f9ea3238d3f7ae3d78daedd6936.png)![](../Images/4a9b94ff1e7dc058dcf94b274fbc65ed.png)![](../Images/25655f9ea3238d3f7ae3d78daedd6936.png)

如何应用此更新，用户必须发出以下命令：

PS C:\\> DefenderUpdateWinImage.ps1 - WorkingDirectory -Action AddUpdate - ImagePath  -Package

要删除或回滚更新，用户需要运行以下命令：

PS C:\\> DefenderUpdateWinImage.ps1 - WorkingDirectory -Action RemoveUpdate - ImagePath 

显示已经安装的病毒库更新：

PS C:\\> DefenderUpdateWinImage.ps1 - WorkingDirectory -Action ShowUpdate - ImagePath
