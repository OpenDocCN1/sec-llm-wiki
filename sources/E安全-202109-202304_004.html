Windows 10 21H2将于 6 月终止服务

近日，微软提醒用户，多个版本的 Windows 10 版本 21H2 将在两个月后即2023年6月13日到达服务终止 (EOS)。

这适用于2021年11月发布的以下Windows 10版本：家庭版、专业版、专业教育版和工作站专业版。



微软在3月14日的初步公告中表示，“这些版本在2023年6月13日之后将不再接收安全更新。在此日期之后联系 Microsoft支持的客户将被引导将他们的设备更新到最新版本的 Windows 10或升级到 Windows 11以保持支持。”


到达服务终止日期后，运行家庭版和专业版的 Windows 10 21H2设备将不再收到安全和每月质量更新，其中包含针对最近发现的安全威胁的错误修复和补丁。


在一年前的2022年5月10日，多个其他版本（Home、Pro、Pro Education 和 Pro for Workstations）之后，面向企业和教育用户的Windows 10 20H2也将在下个月到达EOS。


Microsoft为客户提供了所有产品的完整列表，这些产品将在今年晚些时候终止支持或停用。


您可以在Windows 生命周期常见问题解答、  Windows 10服务常见问题解答以及生命周期策略搜索工具的帮助下找到有关 Windows 服务终止日期的更多详细信息 。




广泛部署的最新 Windows 版本

Windows 10 22H2（Windows 10 2022更新）已实现广泛部署，从2022年11月开始，所有人都可以通过 Windows 更新获得。


它目前提供给拥有运行Windows 10 20H2或更高版本且不受兼容性保留影响且未配置为延迟功能更新的合格设备的客户。


但是，微软将强制Windows 10 2022更新到运行Windows 10 20H2的消费者和非托管企业设备，直到它在今年 6 月到达 EOS。


微软表示：“为了帮助您保持安全和高效，Windows Update 将自动为处于服务终止期或即将终止服务的几个月内的 Windows 10消费设备和非托管企业设备启动功能更新。”



Windows 11 22H2（又名Windows 11 2022更新）现在也可广泛用于符合条件的设备，Redmond强制将其安装在运行 Windows 11 21H2的系统上，该版本即将于2023年10月10日终止服务日期。


 微软在 Windows 发布运行状况仪表板上解释道，“自 Windows 10以来，我们一直在通过自动更新帮助 Windows 用户保持最新状态并确保受支持的 Windows 版本的安全，我们正在为 Windows 11 使用相同的方法来帮助您保持安全和高效。一如既往，您将能够选择一个方便的时间让您的设备重新启动并完成更新。”
