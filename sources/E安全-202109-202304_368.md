# 紧急状况！针对乌克兰的大规模“网络混合战”已经开始

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MjA1MzkyNA==&mid=2655320575&idx=1&sn=d83f173154b130c206047c61f317c8f5&chksm=f02f85b4c7580ca29c9383e62c86189d65917a7103275e501059eff61f7aaa6a45fea4428aba&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655320575&idx=1&sn=d83f173154b130c206047c61f317c8f5&chksm=f02f85b4c7580ca29c9383e62c86189d65917a7103275e501059eff61f7aaa6a45fea4428aba&scene=27#wechat_redirect)

![](../Images/38b9e94a1a05aaa7de07d5b4b29d158a.png)

  

近日，乌克兰国防部和武装部队以及国有银行、Privatbank（乌克兰最大的银行）和 Oschadbank均遭到DDoS攻击。乌克兰国防部的网站已被 DDoS 攻击浪潮撤下。

 

从2022年2月15日下午开始，乌克兰多处信息资源遭到强大的DDOS攻击。特别是，这导致 Privatbank 和 Oschadbank 的 Web 服务工作中断。国防部和乌克兰武装部队的网站也遭到攻击。截至19时30分，银行网络资源工作已经恢复。来自国家网络安全系统主要的专家工作组正在采取一切必要措施来本地化和抵御网络攻击。

 

虽然Oschadbank 银行的网站最初仍然可以访问，但客户无法访问他们的网上银行账户。在撰写本文时，无法访问该金融机构的网站。

 

威胁行为者还攻击 Privatbank 并破坏其网站，威胁行为者添加了以下信息：“失败！私人银行 WAF 正在看着你”。

 

乌克兰战略通信和信息安全中心也在Facebook 上发布了一篇帖子，解释说 Privatbank 的客户无法进行支付，但攻击者并没有从他们的银行账户中窃取资金。

 

与此同时，情报机构乌克兰安全局（SBU）发布了的最新公告敦促公民保持冷静，批判性思考，只从官方渠道寻求新闻。“我们完全理解当前信息压力的动机——在乌克兰社会中散播焦虑，破坏对国家保护公民能力的信心，破坏我们的团结，” 该信函称。

 

“SBU 在社交网络、一些大众媒体、某些政客传播侵略国的叙述等方面看到了这种混合战争的表现。”该通知还声称，安全服务部门正在积极努力减轻这些威胁。

 

例如，本月早些时候， SBU在利沃夫拆除了一个机器人农场，声称该农场被用来管理 18,000 个假 mobilFre 帐户。

 

这些账户是从俄罗斯指示注册虚假社交媒体账户的，这些账户旨在传播旨在在民众中散布恐慌的谎言。其中包括声称在公共场所埋设地雷的虚假故事。这些账户还被用来制造与数千所学校和其他组织有关的炸弹威胁。

 

大约一个月前，俄罗斯对乌克兰发起了大规模网络攻势 ，用宣传信息破坏了十几个政府网站。随后，它向该国的目标发射了破坏性 的“WhisperGate” 恶意软件，旨在使其看起来像是出于经济动机的勒索软件，与 2017 年的 NotPetya 活动相呼应。
