# 被逼无奈？以色列缩减网络武器出口名单致NSO陷入死循环

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MjA1MzkyNA==&mid=2655319757&idx=1&sn=776e6dc5b57e8671d8644c0e40885cb5&chksm=f02f8a86c75803906c6fe944186812185f493bf806f0713f6428d880dd116d26ab8216e283ea&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655319757&idx=1&sn=776e6dc5b57e8671d8644c0e40885cb5&chksm=f02f8a86c75803906c6fe944186812185f493bf806f0713f6428d880dd116d26ab8216e283ea&scene=27#wechat_redirect)

导读

  

以色列国防部禁止向数十个国家出售监控软件和攻击性黑客工具。目前，以色列政府已将65个国家排除在出口清单之外，现在该清单仅包 37个国家。

 

出口清单目前仅包括澳大利亚、奥地利、比利时、保加利亚、加拿大、克罗地亚、塞浦路斯、捷克共和国、丹麦、爱沙尼亚、芬兰、法国、德国、希腊、冰岛、印度、爱尔兰、意大利、日本、拉脱维亚、列支敦士登、立陶宛、卢森堡、马耳他、新西兰、挪威、葡萄牙、罗马尼亚、斯洛伐克、斯洛文尼亚、韩国、西班牙、瑞典、瑞士、荷兰、英国和美国。

  

详细内容 

  

以色列媒体Calcalistech报道指出，以色列更新了允许本地公司向其销售网络安全工具的国家名单，总数从102个减少到37个。如果这种说法是真的，似乎以色列在批准销售网络工具方面非常宽容，并且知道NSO的所有销售。这份名单明显不包括部分之前可以获得这些工具的国家，而以色列公司经常向这些国家提供监视工具。

 

以色列国防部将摩洛哥、墨西哥、沙特阿拉伯或阿联酋等国从名单中删除，原因是它们滥用了从以色列国家统计局集团获得的监控软件。

 

在美国商务部工业和安全局 (BIS)宣布制裁四家开发间谍软件或销售民族国家行为者使用的黑客工具的公司之后，就决定删除该名单。这些公司是来自以色列的NSO Group和Candiru，以及Computer Security Initiative Consultancy PTE。另外还包括来自新加坡的LTD和来自俄罗斯的Positive Technologies 。

 

NSO Group和Candiru因开发和销售用于监视记者和活动家的监视软件而受到制裁。最近，苹果公司在美国联邦法院起诉 NSO Group及其母公司Q Cyber Technologies，指控其使用监视间谍软件Pegasus非法瞄准其客户 。

 

根据诉讼，NSO Group 应对使用零点击漏洞入侵Apple基于iOS的设备负责。这家监控公司开发的软件被用来监视活动家、记者、研究人员和政府官员。法律行动旨在永久阻止这家臭名昭著的公司入侵任何Apple软件、服务或设备。

 

“新名单将使以色列网络安全公司，尤其是那些销售攻击性网络工具的公司在极权主义政权或有侵犯人权记录的国家开展业务的问题变得更加复杂。” 以色列媒体Calcalistech总结道。

 

据悉，以色列网络安全部门目前的年收入为100亿美元，攻击性网络工具占销售额的10%。大约13%的网络安全公司在以色列运营，行业内29%的投资都投向了以色列的公司。
