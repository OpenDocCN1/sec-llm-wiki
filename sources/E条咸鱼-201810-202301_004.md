# 资源替换 + 加壳 + 更改数字签名 免杀操作

上面的操作编译完后依旧会被查杀，这里继续尝试免杀操作（PS：重复了前面的操作后，这边换了个名字，为lighthouse，操作都一样

1.  使用工具**Resource Hacker**替换版本
    

![](../Images/7887fd5b691f157186594560fe51d9b5.png)

2.  使用工具**VMProtect Ultimate**进行加壳
    

![](../Images/b2921a25a48682609b4adb80fa3163d8.png)

3.  使用工具**sigthief.py**进行签名
    

![](../Images/818eab25066f9839e9ae01cc605bb0da.png)

> Github：  
> https://github.com/secretsquirrel/SigThief  
> 用法：  
> python3 sigthief.py -i <提供正常签名的程序> -t <需要签名的程序> -o <完成后输出的文件名>

4.  扫描软件，并执行命令
    

![](../Images/dc0c1ad207c575f8a8ec1eeb320c1e2a.png)

```


privilege::debug
```
