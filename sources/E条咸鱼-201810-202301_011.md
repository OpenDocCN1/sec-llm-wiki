# 正文

在原始的样本中，是通过ms-msdt调用后，执行powershell

```
ms-msdt:
```

在一键生成word的脚本follina.py中，生成的payload是这样的

```
ms-msdt:
```

通过对比上下两条，发现原始的样本中，删除执行的powershell后没查杀，而一键生成的则还是会被查

于是将payload中的`IT_RebrowseForFile`改为`cal?c`,发现并未查杀。

```
ms-msdt:
```
