功能介绍

简单的介绍一下功能，其实就是 EduSrc这个平台上的，大学名字的爬取

爬取下来后，丢入bing搜索，然后通过获取搜索结果第一条，来获取学校主域名

接着写入数据库中，便于查询

魔改

但是他这里做的操作，是一步跑完，在进行下一步，而我更喜欢，跑一次，写一次数据，其次因为脚本方便性的缘故，我更偏向于写进txt里，因为这样前置工作不需要那么多

首先就是登录的部分，直接拿cookie即可

  4.     }

获取到查询结果后，进行主域名提取

  1. def school_domain(url):
  2.     for i in url:
  3.         if "edu.cn" in i:
  4.             d=str(i.encode('utf-8'))
  5.             ul=re.search('[a-zA-Z0-9]+.(edu\.cn|com\.cn)',d)
  6.             print("域名："+i+" 提取结果为："+ul.group())
  7.             insertfile(ul.group())
  8.             break

因为bing查询结果的关系，导致了脚本最后的结果有点奇怪，所以我加了一个if判断，判断域名中是否存在edu.cn

接着写入文件

  1. def insertfile(elapse):
  2.     domain_file=open("sub_domain.txt","a")
  3.     domain_file.write(str(elapse)+"\n")
  4.     domain_file.close()
