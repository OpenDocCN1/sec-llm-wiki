## 魔改

但是他这里做的操作，是一步跑完，在进行下一步，而我更喜欢，跑一次，写一次数据，其次因为脚本方便性的缘故，我更偏向于写进txt里，因为这样前置工作不需要那么多

首先就是登录的部分，直接拿cookie即可

```
1.  `headers = {`
    
2.  `    'User-Agent':'Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/80.0.3987.149 Safari/537.36',`
    
3.  `    "cookie":"此处填你登录edusrc后的cookie"`
    
4.  `    }`
    
```

接着给两个url，一个是bing，一个是edusrc的

```
1.  `url = 'https://src.sjtu.edu.cn/rank/firm/?page='`
    
2.  `bing = 'https://cn.bing.com/search?q='`
    
```

爬取学校名字

```
1.  `def schoolname(url):`
    
2.  `    for i in range(1,187): # 页数,1-187页`
    
3.  `        pageurl=url+str(i)`
    
4.  `        req = requests.get(pageurl,headers=headers)`
    
5.  `        tree = etree.HTML(req.text)`
    
6.  `        res = tree.xpath('//td[@class="am-text-center"]/a/text()')`
    
7.  `        print("爬取 %s"%(res))`
    
8.  `        schoolsite(res)`
    
```

爬取完一次后，进行域名查询

```
1.  `def schoolsite(n):`
    
2.  `    global bing`
    
3.  `    for i in n:`
    
4.  `        bingurl=bing+i`
    
5.  `        req = requests.get(bingurl,headers=headers)`
    
6.  `        tree=etree.HTML(req.text)`
    
7.  `        res=tree.xpath('//div[@class="b_caption"]/div/cite/text()')`
    
8.  `        res1=school_domain(res)`
    
```

获取到查询结果后，进行主域名提取

```
1.  `def school_domain(url):`
    
2.  `    for i in url:`
    
3.  `        if "edu.cn" in i:`
    
4.  `            d=str(i.encode('utf-8'))`
    
5.  `            ul=re.search('[a-zA-Z0-9]+.(edu\.cn|com\.cn)',d)`
    
6.  `            print("域名："+i+" 提取结果为："+ul.group())`
    
7.  `            insertfile(ul.group())`
    
8.  `            break`
    
```

因为bing查询结果的关系，导致了脚本最后的结果有点奇怪，所以我加了一个if判断，判断域名中是否存在edu.cn

接着写入文件

```
1.  `def insertfile(elapse):`
    
2.  `    domain_file=open("sub_domain.txt","a")`
    
3.  `    domain_file.write(str(elapse)+"\n")`
    
4.  `    domain_file.close()`
    
```
