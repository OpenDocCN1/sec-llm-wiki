# 0x01 MISC日志分析

打开压缩包，是一个 `.log`文件

![](../Images/35dce161dca944aaed194eaa78bdba1d.png)

解压后打开来看，是一串被sqlmap注入后的数据

![](../Images/e752bdc17fa994243885177ee50a68df.png)

直接忽略掉他注入 `information_schema`库的操作，看查询的地方

![](../Images/5e922b4a819487ae2cf547fe0ba54235.png)

因为是盲注的原因，所以不是字符串，我们只用看他的语句就好了，根据特征，定位这条语句

![](../Images/a32198e026f764a44aad67d903e13520.png)

也就是，语句中存在 `!=`的，表示当前是的 `ASCII`码是正确的，所以直接上python

```
1.  `import re`
    
2.  `file=open('flag.txt','r')`
    
3.  `pattern=re.compile(r'\),(.*?),1\)\)!=(.*?),0,1')`
    
4.  `for i in file:`
    
5.  `    check=pattern.search(i)`
    
6.  `    if check:`
    
7.  `        print(chr(int(check.group(2))),end='')`
    
```

运行后，就有flag了

![](../Images/5b7ed20bc2af8f2d6184e1db40e4bbad.png)
