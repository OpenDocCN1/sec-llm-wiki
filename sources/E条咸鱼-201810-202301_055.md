因为写在博客上的文章（部分）会给盗取，所以老早之前就写了一个加水印的程序

后来发现，因为防止文件名重复，我都是用一种随机的方式生成的文件名

```
1.  `filename=sys.argv[i]`
    
2.  `suffix=filename[-3:]`
    
3.  `temp_name=d.datetime.now().strftime("%M-%S")+"."+str(suffix)`
    
```

但是这样一来就会打乱文件顺序（因为我命名都是1 2 3 4这样），不好管理，所以就稍微修改了一下，发出来图一乐

先导入库

```
1.  `import os`
    
2.  `import sys`
    
3.  `import time`
    
4.  `import datetime as d`
    
5.  `from PIL import Image, ImageDraw, ImageFont`
    
```

因为一次性需要多个图片的问题，所以最开始写的时候想的是，文件拖过去就能执行了；获取文件名的方式就变成了

```
1.  `...`
    
2.  `for i in range(1,100):`
    
3.  `    filename=sys.argv[i]`
    
```

就一直循环，看有没有参数

接着设置水印内容

```
1.  `...`
    
2.  `text = "@blog.ernket.top"`
    
```

下面就是加水印的操作了（水印固定右下角）

```
1.  `...`
    
2.  `image = Image.open(filename)`
    
3.  `font = ImageFont.truetype('C:\\Windows\\Fonts\\微软雅黑\\msyh.ttc',18)`
    
4.  `layer = image.convert('RGBA')`
    
5.  `text_overlay = Image.new('RGBA', layer.size)`
    
6.  `image_draw = ImageDraw.Draw(text_overlay)`
    
7.  
    
8.  `text_size_x, test_size_y = image_draw.textsize(text,font=font)`
    
9.  
    
10.  `text_xy = (layer.size[0] - text_size_x, layer.size[1] - test_size_y)`
     
11.  `image_draw.text(text_xy,text,font=font,fill='#000000') #字体颜色`
     
12.  `after = Image.alpha_composite(layer,text_overlay)`
     
13.  `temp_name=d.datetime.now().strftime("%M-%S")+"."+str(suffix)`
     
14.  `after.save(temp_name)`
     
```

文件水印加完了，现在考虑的是文件名的问题，我的做法是删除源文件防止报 `文件已存在`的错误，然后在重命名 （也许可以直接覆盖吧，懒得写

```
1.  `...`
    
2.  `os.remove(filename)`
    
3.  `os.rename(temp_name,filename)`
    
4.  `print("[+] "+filename+" 已完成水印工作，正在替换文件名....  "+str(temp_name+" --> "+filename))`
    
5.  `time.sleep(1)`
    
```

到这就写完了，当然for循环的时候会报错，因为给的参数不同，加个 `try`就好了

```
1.  `import os`
    
2.  `import sys`
    
3.  `import time`
    
4.  `import datetime as d`
    
5.  `from PIL import Image, ImageDraw, ImageFont`
    
6.  
    
7.  `print("Auther:Elapse")`
    
8.  `for i in range(1,100):`
    
9.  `    try:`
    
10.  `        filename=sys.argv[i]`
     
11.  `        suffix=filename[-3:]`
     
12.  `        image = Image.open(filename)`
     
13.  `        text = "@blog.ernket.top"`
     
14.  `        font = ImageFont.truetype('C:\\Windows\\Fonts\\微软雅黑\\msyh.ttc',18)`
     
15.  `        layer = image.convert('RGBA')`
     
16.  `        text_overlay = Image.new('RGBA', layer.size)`
     
17.  `        image_draw = ImageDraw.Draw(text_overlay)`
     
18.  
     
19.  `        text_size_x, test_size_y = image_draw.textsize(text,font=font)`
     
20.  
     
21.  `        text_xy = (layer.size[0] - text_size_x, layer.size[1] - test_size_y)`
     
22.  `        image_draw.text(text_xy,text,font=font,fill='#000000')`
     
23.  `        after = Image.alpha_composite(layer,text_overlay)`
     
24.  `        temp_name=d.datetime.now().strftime("%M-%S")+"."+str(suffix)`
     
25.  `        after.save(temp_name)`
     
26.  `        os.remove(filename)`
     
27.  `        os.rename(temp_name,filename)`
     
28.  `        print("[+] "+filename+" 已完成水印工作，正在替换文件名....  "+str(temp_name+" --> "+filename))`
     
29.  `        time.sleep(1)`
     
30.  `    except:`
     
31.  `        break`
     
```
