# 0x01 论剑

图片下载下来后是这样的

![](../Images/83a0b0c745b295320160555a1bfc4294.png)

按一般套路，看到这种长宽不一致的先改了，拖入HxD中，找到 `FFC2`，三位后就是长宽了

![](../Images/b84f53491b525ec5da8daee293487cd5.png)

`0042`改为 `030D`后，图片就“拉长”了，但是后面有部分内容给打码了，看不清

![](../Images/4170ec85e2414bec3fd3d32ea8d66ca6.png)

在HxD中，我们还发现了一串8位一组的二进制（其实我不是这样发现的，我是在linux中用strings看到的，然后才去翻）

![](../Images/bd911c3419f8722dec0608bded9e5a6f.png)

在最后一部分，发现一个文件头和7z很像的标识，不同的是，前面两位不符合，把他修复一下

![](../Images/5386ddba4783027cedf212a19bfb34cf.png)

![](../Images/00e8bc50e456fbd6036328772454f627.png)

修复完后，用 `dd`分离出来

![](../Images/bcdb222dbce24d45705dfc75d84991ea.png)

解压发现，居然还有密码

![](../Images/77f40ed96888887a7862e235a54d77f6.png)

这时我们想起来，这个压缩文件上面还有一串二进制，把这串二进制转为10进制，然后ascii解码就可以了（我一开始试了摩斯电码，其实并不是），我为了方便转换就随手写了个脚本

```
1.  `file=open("e.txt")`
    
2.  `for i in file:`
    
3.  `    a=i.split(' ')`
    
4.  `    for e in a:`
    
5.  `        print("&#"+str(int(e,2))+";",end="")`
    
```

  

![](../Images/b2f27746e9dbda6d2f79b96895474ef5.png)

把这串字符串美滋滋的拿去在线解码，得到密码

![](../Images/0016f3a485e82ff6635e963fa9f47e25.png)

解压之后发现还是图片，按照图片1的做法，把长宽拉长就好了

![](../Images/9f1114f80b7af7521113ef055c9d7a7f.png)

第一张和第二张图片的字符串合在一起就可以了，我为了方便看，拿PS拼一起了

```
1.  `flag{666C61677B6D795F6E616D655F482121487D}`
    
```

![](../Images/fae80d17e86d3f2ffd5a8b5410e166e2.png)

但其实这个还不是真的flag，吐了，你需要把flag{}里面的内容拿去base16解码  

![](../Images/0859aa7a124230d455d7d07dc65fb779.png)

# 0x02 神秘的文件

打开压缩包，发现有两个文件

![](../Images/aee78bbdfbfcf5a2c1f03ed4a3af0c54.png)

第一张图logo.png分析了半天都没看出来是啥，而flag.zip又需要密码，压缩了logo.png看CRC32，文件是一样的，所以是压缩包明文攻击

> 明文攻击指的是有一个加密的ZIP和一个未加密的压缩包中包含的文件，由于同一个ZIP压缩包里的所有文件都是使用同一个加密密钥来加密的，所以可以使用已知文件推测出密钥并解密ZIP文件的攻击方式，相比暴力破解，这种方法在破解密码较为复杂的压缩包时效率更高。  所以拿工具 `ARCPPR`跑一下

![](../Images/ca44f2a5b7869008f29abca972c46b08.png)

![](../Images/671482fca209d6ce0516f10bdb6201f5.png)

拿到密码解压，得到一个.docx文件，内容是一个滑稽

![](../Images/11cfbe91c9b3a648e39dacec2b13e1df.png)

查看文件头发现是pk，把后缀改为zip

![](../Images/6f1e087f072c409b678a671b349cdeab.png)

打开后，在第二个文件夹里发现了flag.txt

![](../Images/bca227e905b8cf49d396794f70559da1.png)

打开是base64编码

![](../Images/2f7d8826f3d83541be45074c55daac0c.png)

拖去解码就有flag了

![](../Images/ea9f584e2191a70e78b51f78a1f31a60.png)
