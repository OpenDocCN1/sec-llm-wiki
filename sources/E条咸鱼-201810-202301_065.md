要注意的是，多线程带的参数不能是socket这类的，所以直接用下面这种写法是不可行的

```
1.  `conn,addr = server.accept()`
    
2.  `t = threading.Thread(target=ftpstart,args=conn)`
    
3.  `t.start()`
    
```

![](../Images/138a2e4e1b9d6cc6043542c28f875c69.png)

所以需要将conn和check\_close(检查有没有关闭服务的指令）设为全局变量

```
1.  `global conn`
    
2.  `global check_close`
    
```
