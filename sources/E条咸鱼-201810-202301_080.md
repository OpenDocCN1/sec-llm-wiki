抽空优化了一下脚本，优化的点有以下两点：

*   将原来 `input`的操作改为了选项，看起来更专业了
    
*   把原来大杂烩一样的数据显示优化了一下，起码是人看的
    

首先是第一点吧，原本Input的改为了选项

原本的代码是这样的:

```
1.  `url=str(input("木马url: "))`
    
2.  `parameter=str(input("木马参数: "))`
    
```

运行之后的效果是

![](../Images/ca91c1fe6d03181e2482523e39608b47.png)

捞的不行，所以就改了一下

```
1.  `from optparse import OptionParser`
    
2.  `use="Usage: Python <filename> -u <url> -p <passwd>"`
    
3.  `optParser = OptionParser(usage=use)`
    
4.  `optParser.add_option('-u','--url',action='store',type = "string" ,default=False,dest = 'url',help='Enter the url here')`
    
5.  `optParser.add_option('-p','--passwd',action='store',type = "string" ,default=False,dest = 'passwd',help='Enter the file password here')`
    
6.  `options,args = optParser.parse_args()`
    
7.  `if options.url!=False and options.passwd!=False:`
    
8.  `    url=options.url`
    
9.  `    parameter=options.passwd`
    
```
