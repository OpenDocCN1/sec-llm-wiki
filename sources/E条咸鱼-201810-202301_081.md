归档与系统之间文件复制  

1.    
    
    tar:归档工具 ，不带压缩 调用第三方压缩软件 压缩 tar 目标文件 使用相对路径
    
      
    
2.    
    
    将/etc/ 目录归档到/tmp/etc.tar
    
      
    

```
1.  `[root@localhost /]# tar -cvf /tmp/etc.tar etc`
    
2.  `命令用法: tar -<参数> <保存路径> <归档的目录>`
    
```

1.  调用压缩：
    

上面用了一种方法来压缩，但众所周知不止一种，所以这里又要多演示几个

*     
    
    tar + gzip : .tar.gz 将/etc 目录归档到/tmp/etc.tar.gz
    
    `tar-czvf<压缩后的路径><需要压缩的玩意>`
    
      
    

![](../Images/00b4d4920e068d9a82dd01b12421b45b.png)

![](../Images/2c02b4304c88e82ca1d94b3e54071d4b.png)

  

*   tar + bzip2 ：.tar.bz2 将/etc 目录归档到/tmp/etc.tar.bz2
    

`tar-cjf<压缩后的路径><需要压缩的玩意>`

![](../Images/e96f26c432bcc13661934dff59e5e5b4.png)

*   tar + xz : .tar.xz 将/etc 目录归档到/tmp/etc.tar.xz
