由于 红酒识别暂未封装服务端SDK，只能通过API调用(官方文档原话)，所以得自己通过API接口来获取token和识别数据 首先导入库

  1. import base64
  2. import urllib.parse #用于url编码
  3. import urllib.request
  4. import json
  5. import jsonpath
  6. from PIL  import Image,ImageDraw,ImageFont #将识别结果输出到图片中

在识别工作开始之前，我们得先用自己的 APIKey和 SecretKey来获取 access_token，很可惜的是，官方文档中这部分的代码也是 Python2的，所以我稍微改了一下让他3的环境下也能运行，下面是源代码

  1. import urllib.parse
  2. import urllib.request
  3. import sys
  4. import ssl
  5. api_key='' #自己输入
  6. secret_key='' #自己输入

  8. host = 'https://aip.baidubce.com/oauth/2.0/token?grant_type=client_credentials&client_id='+api_key+'&client_secret='+secret_key
  9. req=urllib.request.Request(host)
  10. req.add_header('Content-Type','application/json; charset=UTF-8')
  11. response = urllib.request.urlopen(req)
  12. print (response.read())

在输出结果中找到 access_token，复制粘贴就好了（当然可以直接解析然后只输出token，但是我懒）

有了access_token后，就可以开始识别工作了

首先先定义一下api接口的地址

  1. ...
  2. request_url = "https://aip.baidubce.com/rest/2.0/image-classify/v1/redwine"

在官方文档中有写这么一个玩意 

图片得base64编码后再发送过去，所以打开图片的时候得编码一次，接着url编码一次，才能作为数据发送

  1. ...
  2. filename = str(input("请输入图片名称: "))
  3. f = open(filename, 'rb') # b 为二进制打开 
  4. img = base64.b64encode(f.read()) #base64编码图片
  5. f.close()
  6. params = {"image":img}
  7. params = urllib.parse.urlencode(params).encode('utf-8') #url编码

写完上面的操作后，就可以开始尝试图片识别了

  1. access_token = '' #上面获取到的，填进去就完事了
  2. request_url = request_url + "?access_token=" + access_token
  3. request = urllib.request.Request(url=request_url, data=params)
  4. request.add_header('Content-Type', 'application/x-www-form-urlencoded') #添加头部
  5. response = urllib.request.urlopen(request) #访问接口
  6. content = response.read() #结果
  7. print (content.decode()) #得.decode()解码，不然看到的东西不是给人看的

效果图是这样的 

有了结果后，就可以开始做“把结果写到图片上”的操作了 首先先做准备工作

  1. ...
  2. pic_img = Image.open(filename)  # 打开图片
  3. draw = ImageDraw.Draw(pic_img)  # 调用ImageDraw模块在图片上画图
  4. ttfont = ImageFont.truetype("C:/WINDOWS/Fonts/AdobeHeitiStd-Regular.otf", 20) #设置字体

处理上面获取到的数据

  1. ...
  2. json_content=json.loads(content.decode('utf-8'))
  3. cn_name=jsonpath.jsonpath(json_content,"$..wineNameCn") #名字
  4. pic_from=jsonpath.jsonpath(json_content,"$..wineryCn")  #酒庄
  5. con_from=jsonpath.jsonpath(json_content,"$..countryCn") #生产地
  6. zl=jsonpath.jsonpath(json_content,"$..classifyByColor") #品种

开始写字

  1. x=203 #定义坐标轴X
  2. y=147 #定义坐标轴Y
  3. draw.text([x,y], "识别结果: " , "red", font=ttfont) #写字
  4. draw.text([x,y+20], "种类: "+str(zl),"red",font=ttfont) #写字，y轴+20，防止字重叠
  5. draw.text([x,y+40], "名字: "+str(cn_name),"red",font=ttfont) #写字
  6. draw.text([x,y+60], "出自: "+str(pic_from),"red",font=ttfont) #写字
  7. draw.text([x,y+80], "生产地: "+str(con_from),"red",font=ttfont) #还是写字

  9. pic_img.show() #将结果图输出出来
