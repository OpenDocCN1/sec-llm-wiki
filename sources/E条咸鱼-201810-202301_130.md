## TCP三次握手

![](../Images/20abbc69b1faa3cb31f4f9c9694533a5.png)

 "三次握手"是对服务器进行的协商的步骤  

### 过程

第一次握手：建立连接，客户端发送syn包到服务器，等待确认 （SYN：同步序列编号） 第二次握手：服务器确认客户的syn包，同时自己也发送一个确认包ACK给客户端 第三次握手：客户端收到服务器的SYN和ACK确认包，向服务器也发送一个ACK确认包，这个时候，客户端就和服务端完成了三次握手，TCP连接成功

## Python Socket库

socket - 套接字，应用程序通过套接字来向网络发出请求或者应答请求，是主机间可以通讯 Python中可以利用socket库来建立连接或者监听端口、开启服务

```
1.  `#coding:utf-8`
    
2.  `import socket`
    
3.  `s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)`
    
4.  `s.connect(('172.20.10.3',80)) #创建连接`
    
5.  `s.send(b'GET / HTTP/1.1\r\nHost: 172.20.10.3\r\nConnection: close\r\n\r\n')`
    
6.  
    
7.  `res = ""`
    
8.  `while True:`
    
9.  `    data=s.recv(1024) #只获取前1024位的内容`
    
10.  `    if data:`
     
11.  `        res+=data.decode() `
     
12.  `    else:`
     
13.  `        break #跳出循环`
     
14.  `print (res.encode('utf-8')) #输出内容`
     
15.  `s.close() #关闭套接字`
     
```

## ARP攻击

原理: ARP攻击就是通过伪造IP和MAC地址来实现的ARP欺骗，造成中间人攻击 因为ARP的特殊性，所以ARP攻击主要存在于局域网络中，大致的攻击流程如下

A（客户端)和C（服务端）为受害者，B为攻击者，B告诉A他是服务器，A觉得没毛病，于是就把B的MAC地址当作C的地址写进缓存表中了，B再去告诉C说他才是A，C也信了，于是乎A和C之间的通信，都是先发给B，然后再去发送给对方，B就做到了监控流量，以及伪造数据的功能了
