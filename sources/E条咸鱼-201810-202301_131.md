## 0x01 Python List类型

### 基本

列表是Python中最基本的数据结构，列表中每一个内容都会有一个索引的数字，第一位是从0开始计算，0,1,2这样以此类推 写法:

```
1.  `list=['one','two','three']`
    
```

结果:

```
1.  `>>> list`
    
2.  `['one', 'two', 'three']`
    
3.  `>>> type(list)`
    
4.  `<class 'list'>`
    
5.  `>>> list[1]`
    
6.  `'two'`
    
```

### 0x02 更新内容

列表的内容是可以 `增加`的 写法:

```
1.  `list=['one','two','three']`
    
2.  `list.append('four') #将four内容增加到列表list中`
    
```

结果:

```
1.  `>>> list`
    
2.  `['one', 'two', 'three', 'four']`
    
```

有增加就有删除，有两种删除数据的方法

```
1.  `>>> list`
    
2.  `['one', 'two', 'three']`
    
3.  `>>> del list[2] #第一种，删除索引为2的数据`
    
4.  `>>> list`
    
5.  `['one', 'two']`
    
6.  `---分割线---`
    
7.  `>>> list`
    
8.  `['one', 'two']`
    
9.  `>>> list.remove("two") #第二种，指定内容删除`
    
10.  `>>> list`
     
11.  `['one']`
     
12.  `>>>`
     
```

## 0x03 扩展（Python列表截取）

```
1.  `>>> list=['one','two','three'] #列表内容`
    
2.  `>>> list[2] #列表中第三个内容`
    
3.  `'three'`
    
4.  `>>> list[-2] #列表中倒数第二个内容`
    
5.  `'two'`
    
6.  `>>> list[1:] #从第二个开始截取列表`
    
7.  `['two', 'three']`
    
8.  `>>>`
    
```

## 1x01 Python 字符串小加密

```
1.  `def enc(key,message): #定义一个类`
    
2.  `    res="" #创建个空函数`
    
3.  `    for i in range(len(message)): #这里做一个for循环，循环次数为message这个字符串的长度`
    
4.  `        if message[i].isupper(): #判断该字符是不是大写`
    
5.  `            num = ord(message[i])-ord('A') #返回对应的 ASCII 数值`
    
6.  `             res += chr(ord('A')+(num+key)%26) #加密，返回当前整数对应的ascii字符`
    
7.  `        elif message[i].islower():`
    
8.  `            num = ord(message[i])-ord('a') #返回对应的 ASCII 数值`
    
9.  `            res += chr(ord('a')+(num+key)%26) #加密，返回当前整数对应的ascii字符`
    
10.  `    print res #将结果输出出来`
     
11.  `e1=input("Plz input Key: ")`
     
12.  `e2=input("Plz input Message: ")`
     
13.  `enc(e1,e2)`
     
```

`.isupper()`是判断该字符是否大写， `.islower()`则反之，判断是不是小写 `ord()`和 `chr()`，前者是将对应的ascii字符转换成数字，后者是数字转换成字符
