 先点开R1路由器 点击CLI，进入命令终端 这里要注意的是，这里的都是有密码的![](../Images/6e3b1a59d58533cbcfece4d9f2c38ab1.png)密码：

*   登录密码：cisco
    
*   进入特权模式密码：class
    

上面两个是cisco的通用密码，进去之后，先配置G0/1的IP

```
1.  `R1(config)#interface gigabitEthernet 0/0`
    
2.  `R1(config-if)#ip address 192.168.10.1 255.255.255.0`
    
3.  `R1(config-if)#no shutdown `
    
4.  `R1(config-if)#`
    
5.  `%LINK-5-CHANGED: Interface GigabitEthernet0/0, changed state to up`
    
6.  `%LINEPROTO-5-UPDOWN: Line protocol on Interface GigabitEthernet0/0, changed state to up`
    
7.  `R1(config-if)#`
    
```

## 解释一下命令

`interfacegigabitEthernet0/0` 

其中 interface是进入某端口的配置，gigabitEthernet则是类型，0/0就是端口号

`ip address`

是添加IP地址的意思，ip address的语法要求的是 `ip address<ip><netmask>`

`noshutdown`

意思就是打开端口，端口默认是关闭的，shutdown英文直译就是关闭，no shutdown就是关闭的反义词 <-满分解释

接着按照上面的IP表和命令，把其他2个口的IP给配置了 配置完成后，还有一步，就是把保存配置，首先先退出全局配置模式 

然后输入以下命令保存配置

```
1.  `R1#copy running-config startup-config `
    
2.  `Destination filename [startup-config]? `
    
3.  `Building configuration...`
    
4.  `[OK]`
    
5.  `R1#`
    
```

检查一下结果，R1部分的就配置完了

\-------------优秀的分割线---------------

小技巧，在使用设备的时候，经常会遇到命令打错了，然后等了一年，才给继续输入

![](../Images/14cc109062ece9488b77b7f2195e35ee.png)

这时候你可以通过按 `Ctrl`\+ `Shift`\+ `6`来结束，立马就能继续操作了

  

还有一个就是，有的命令太长了，记不下来，那么你可以通过<Tab>键来补全命令

  

例如上面的interface gigabitEthernet 0/0

  

有tab键补全的话，你只需要输入

int `<Tab>` g `<Tab>` 0/0就可以了

（上面的那个<tab>不输入，是按tab键)
