# 代码部分

首先看一下，steam的网站结构

  

![](../Images/877ab9dceeb682176c36339536332bed.png)

  

发现游戏名字是存在 `<divclass="responsive_search_name_combined">`下的再去看url链接`https://store.steampowered.com/search/?specials=1&page=1`其中page=1就是第一页的意思，所以整体思路就有了，先写一个页面的循环 

  

```
1.  `pageid = 1`
    
2.  `while pageid<599:`
    
3.  `    url = "https://store.steampowered.com/search/?specials=1&page=" + str(pageid)`
    
4.  `    res = requests.get(url)`
    
5.  `    soup = bs4.BeautifulSoup(res.text)`
    
6.  `    contents = soup.select('div[class="responsive_search_name_combined"]')`
    
```

  

这样，599页的steam游戏优惠的界面都会被requests请求一遍，并查找指定的元素,也就是存放游戏名的元素 接下来把游戏名抓取下来

  

```
1.  `for content in contents:`
    
2.  `    name = content.find("span",class_="title").string.strip()`
    
3.  `    print(name)`
    
```
