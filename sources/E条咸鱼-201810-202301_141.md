
翻译的字符长度是有限制的，测试出来的结果是不能大于4891，这里在def一个限制长度的

```
1.  `def max_length(content):`
    
2.  `    if len(content) > 4891:`
    
3.  `        print("翻译文本超过限制！")`
    
4.  `        return`
    
```

下面这个def是最重要的，因为直接输出的结果，是一大串列表属性的内容，如下图![](../Images/8951a651e9cdcc4df9e97e2141ad1637.png)看的就很难受，所以这里要把不必要的东西都过滤掉，只要翻译

```
1.  `def print_result(parm):`
    
2.  `    result = parm`
    
3.  `    str_end = result.find("\",") #查找字符串 \号开始,号结束`
    
4.  `    if str_end > 4:`
    
5.  `        print("翻译的结果为：",result[4:str_end]) #输出结果截取，只要翻译的一部分`
    
```

接下来就把上面定义的都给调用起来，分两块，一块是英译中，一块是中译英


汉译英差不多的，只是Url中的一些参数变了而已

