好好的一个vps说崩就崩，崩了重装也没什么问题，可是能选择的系统太低级了，不是源有问题就是无法建立ssl连接，蠢死了

安装

这里用的系统是 Ubuntu12.10x86_64ServerMinimalv1，系统自带的源是真的辣鸡，所以这里用清华的源[链接]

进入/etc/apt/source.list里面，把自带的源全部删除，把清华的源替换进去后更新即可

  1. root@Elapse:~# vim /etc/apt/sources.list
  2. root@Elapse:~# apt-get update

更新完后，不用着急下载脚本，先把机器环境配置好

先下载unzip

  1. root@Elapse:# apt-get install unzip

下载完后，解压缩文件就没问题了，但是后面通过wget下载压缩包的时候，发现无法建立SSL链接，一开始以为是命令的问题，于是进入sh脚本看

发现是有 --no-check-certificate这个参数的，所以命令没问题，尝试着更新了wget也没用，后来百度查到

当wget出现 Unable to establish SSL connection 这时你需要安装： apt-get install libssl-dev 当wget出现 Can’t connect to HTTPS URL because the SSL module is not available 你需要安装： apt-get install openssl

安装了libssl-dev后，才正常的wget了压缩包，接下来开始用脚本安装SSR服务端，使用下面这个命令，一条龙安装

  1. wget -N --no-check-certificate https://raw.githubusercontent.com/ToyoDAdoubi/doubi/master/ssr.sh && chmod +x ssr.sh && bash ssr.sh
