制作影子用户是作为后渗透的惯用手段，其隐蔽性强，权限大且免杀。今天我就来教大家详细的制作影子用户。



首先准备一个windows系统。

按下win键，输入cmd，右击并选择以管理员身份运行

在命令行中输入：net user [username$] /add

(其中的[]里面是新建用户名，后面加上$能net user 中不能发现改用户)

我们输入net localgroup 可以看到Windows系统里面的所以用户组。

接下来用net localgroup administrators [username$]  /add 命令来把自己的用户添加到管理员组。

虽然用net user 命令不能看到该用户，但在我们进入系统时能看见，我们也可以在控制面版的用户选项中看到这种用户。

此时，我们按下win+R,输入regedit，打开注册表

刚进入注册表的用户是没办法进行接下来的操作的。因为此时我们是无法找到我们所需要用到的目录的。按照以下目录找到sam文件

按照图中方法进入权限设置

选中administrators并赋予完全权限。
