**NEWS**

制作影子用户是作为后渗透的惯用手段，其隐蔽性强，权限大且免杀。今天我就来教大家详细的制作影子用户。

  

  

![](../Images/769c9e42d57751c404cf87e47cecfb4f.png)

首先准备一个windows系统。

![](../Images/d3c8a41e09177487ff81c907d69ff89d.png)

按下win键，输入cmd，右击并选择以管理员身份运行

![](../Images/cccd30c15e68aa8f79751205bd677f15.png)

在命令行中输入：net user \[username$\] /add

(其中的\[\]里面是新建用户名，后面加上$能net user 中不能发现改用户)

![](../Images/5f6962baf5ac6176ccb8f1e541de94b4.png)

我们输入net localgroup 可以看到Windows系统里面的所以用户组。

![](../Images/6cad6116a34940b8b4b0f66ef7aa120c.png)

接下来用net localgroup administrators \[username$\]  /add 命令来把自己的用户添加到管理员组。

![](../Images/ae5c4c08c7b3ff54db52b9ff9ec63e66.png)![](../Images/278f38708bbfd66b65fcf94ada53cfeb.png)

虽然用net user 命令不能看到该用户，但在我们进入系统时能看见，我们也可以在控制面版的用户选项中看到这种用户。

![](../Images/a04e8f407d5813554d7283619e4fcd9f.png)

此时，我们按下win+R,输入regedit，打开注册表

![](../Images/ae5a474f2b1821fb43fb36272e07f1f0.png)

刚进入注册表的用户是没办法进行接下来的操作的。因为此时我们是无法找到我们所需要用到的目录的。按照以下目录找到sam文件

![](../Images/d5c428209964a9f06eb12c792ab29a4f.png)

按照图中方法进入权限设置

![](../Images/e31bff8c4122aa8000a72b04011d50a4.png)

选中administrators并赋予完全权限。

回到注册表进行刷新。

![](../Images/23457a4194d1706d78631770729ff9e6.png)![](../Images/7e2d9851c355ddb1e1fcf9c5f33a0ad0.png)![](../Images/b9c0acbe6f9178c3b840379705160e48.png)

我们分别导出两种用户的地址和影子用户。

将管理员的"F"覆盖影子用户的"F"

![](../Images/89f3e1259b968a1441c80d144273fcb5.png)

删除影子用户

![](../Images/0efd7c9ad3115f41da25eaede9352f1c.png)

刷新界面

![](../Images/0e742afa448a4a63c594992bde2582e3.png)

然后分别导入影子用户和影子用户的地址。

到这一步为止我们的目的就已经完成了。

接下来就是验证影子用户。

![](../Images/2f775ea71537d41e1e901546cb9d544f.png)![](../Images/9334687718fd140626c139238b167982.png)

我们发现无论在哪里都无法找到影子用户。

因为无法打开其他用户登录模式所以我采用了远程登录进行验证。

![](../Images/9eb9f7af93d36c1bbe377de52be1928a.png)

首先查找本机IP地址

![](../Images/124f5a69187d4b02b9f49cb1e2aa04fe.png)![](../Images/99d38449222528e8691b9c68107beb7a.png)
