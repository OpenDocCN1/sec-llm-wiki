## ✔ 0x01 OA弱口令入口

* * *

  

![](../Images/c6c20fd9fdee5cec8b355836b8a8b607.png)

进入后台发现他们的上传功能全部关掉了，但是有企业微信推送模块

![](../Images/ecb6697df77dab27efe9114452f1aa31.png)

在该模块中获得两个重要的参数**CorpID**、**secret**，CorpID是企业号，企业微信的唯一ID，secret是管理组凭证，拥有这两个参数就代表了你拥有了企业微信的管理权限。  

* * *

## ✔ 0x02 构造请求进入企业微信  

* * *

### 2.1 通过CorpID与secret获取access\_token  

https://qyapi.weixin.qq.com/cgi-bin/gettoken?corpid\=id&corpsecret\=secrect

调用该接口，获取access\_token

![](../Images/6bddd58b8f7aa1894aaa5e902b44c80f.png)

### 2.2 通过acess\_token获取部门ID  

https://open.work.weixin.qq.com/devtool/query?e\=301002

将access\_token进行输入，获取部门信息

![](../Images/92c906ad3272b7042e4e9d2d6fccc66e.png)

### 2.3 构造请求，将自己的微信号加入企业微信  

将自己的微信信息POST进创建成员的URL

```
https://qyapi.weixin.qq.com/cgi-bin/user/create?access\_token\=ACCESS\_TOKEN
```

```
{
   "userid": "masterperng",
   "name": "法师",
   "department": \[partyid\],
   "mobile":"1388888888"
}
```

## ✔ 0x04 总结一下  

* * *

### 4.1 攻击者角度  

在我作为一名攻击者的角度来看，当获得了后台无法成功的getshell，可以去观察下是否有这种推送功能，比如企业微信、钉钉推送等等或者邮箱订阅，这些都可能有条件进行伪造进行鱼叉攻击，总之不要一棵树吊死，死找上传点去Getshell。

### 4.2 防守者角度

对于防守者，我想说的是
