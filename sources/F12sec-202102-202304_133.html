在我的面向搜索引擎的编程方法下，终于搞明白了Django的基本配置

配置文件：settings.py

路径映射：urls.py

本文需要修改这两个文件。

其中settings.py文件

# SECURITY WARNING: don't run with debug turned on in production!DEBUG = FalseALLOWED_HOSTS = ['*']

DEBUG默认是开的，上线的时候需要改为False

ALLOWED_HOSTS默认是空的，上线需要改为['*']允许所有地址访问。（该配置必须配置，否则在DEBUG为False情况下无法启动项目）

LANGUAGE_CODE = 'zh-hans'

这个是改为中文

TIME_ZONE = 'Asia/Shanghai'

修改时区

添加本项目


然后是urls.py文件

新版本已经去掉了url写法，改为了path，如果去查询博客一定要看博主写的是新版本还是旧版本。

这里意思很简单。

path('',hello)

第一个参数是指用户访问的路径，比如这里是空的，就代表主页，【域名/】这种形式

第二个是指将请求交给谁处理，这里是引入了方法

from edusrc.whitehat.views import hello

从whitehat文件夹的views文件中导入hello方法，意思是用户访问【域名/whitehat】会由whitehat/views.py中的hello来处理。
