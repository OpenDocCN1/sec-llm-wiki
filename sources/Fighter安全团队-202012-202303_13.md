## **一、Kali Nethunter**

### **1.1 概述**

安装这个有啥用？简单来说就是可以在你的手机平台上运行KALI Linux系统，实际用处，懂得都懂。在综合考虑的情况下，入手了一台Oneplus6，因此下面的刷入流程是以Oneplus6为参考标准。可完美刷入！官方推荐刷入机型列表：*https://www.kali.org/get-kali/#kali-mobile*  

### **1.2 刷机准备**

## **二、刷机过程**

### **2.1 线刷Oxygen10.3.2**

1.  安装好9008驱动。
    

![](../Images/c4f546dfed6039651c8dcb5119650e80.png)

  

2.  安装成功后，打开“MsmDownloadTool V4.0.exe”会显示如下数据：
    

![](../Images/c06b96c01c62436bbc384b2d12d79cab.png)

3.  手机拔出数据线后，彻底关机（长按关机键不放，直到熄屏）。
    
4.  按着音量上键不放，同时插入数据线到电脑。软件会自动识别，当显示“已连接”后，点击“start”，开始刷机。
    

![](../Images/692d8d6e12a59bd63f9bea7bfa2c1e74.png)

4.  线刷完成后，手机自动重启进去新系统。
    

![](../Images/a266b4d16567bf545bfb29fcb4e2378c.png)

### **2.2 解锁OEM**

1.  进去系统后，不用配置任何东西，一路跳过。（**不要插SIM卡**！**不要联网**！**不要设置指纹密码** ！）
    
2.  进入到“关于手机”，一直点击“版本号”直到开启“开发者模式”。
    

![](../Images/0ead4d1be27bffff4d1972159b50f526.png)

3.  打开“开发者选项”，开启“OEM解锁”和“USB调试”。
    
4.  手机通过数据线连接电脑，勾选“信任设备”，接着运行“解锁.bat”。手机重启后将会进入下面界面，通过音量键选择第二个选项，点击电源键来确认。
    

![](../Images/ffcf20389d818253a96713f1073e75e1.png)

5.  手机重启之后和之前一样，不用配置任何东西，一路跳过。（**不要插SIM卡**！**不要联网**！**不要设置指纹密码** ！）
    

### **2.3 刷入TWRP**

1.  打开“开发者选项”，开启“USB调试”。手机通过数据线连接电脑，勾选“信任设备”，运行 “刷入TWRP.bat”。 
    
2.  手机将重启进入如下页面。
    

![](../Images/fecae81c2912972cf5f71b7467aa9143.png)

3.  通过音量键选择“Recovery mode”模式，电源键确定，手机会重启进入临时TWRP。
    

![](../Images/4b636d58abde914f778548cc5508a88a.png)

4.  滑动进去主页面，选择“Wipe”，然后滑动进行“双清”，完成后返回再进行“格式化Data”。
    

![](../Images/741c276ed12348e77fa7ab7320c483c6.png)

### **2.4 刷入新系统**

1.  格式化操作完成后，回退到主页面。
    

![](../Images/1ebb6ae298c5c959bddf295162ccdb14.png)

2.  电脑运行“传入OTA包.bat”，等待完成后，进入“Install”，可以看到我们传入的刷机包。
    

![](../Images/a85848e8228b04080dbb3f639385fbac.png)

3.  点击刷机包，直接滑动确认刷入。
    

![](../Images/d7d98aafe6928933c18c0addbf716b3b.png)

4.  等到刷机完成后，点击“reboot”选择“B”分区之后重启进去新系统。
    
5.  进入系统后和之前一样，不用配置任何东西，一路跳过。（**不要插SIM卡**！**不要联网**！**不要设置指纹密码** ！）
    

6.  打开“开发者选项”，开启“USB调试”。手机通过数据线连接电脑，勾选“信任设备”，运行 “刷入TWRP.bat”，和上面的操作一样，进去TWRP页面。
    

![](../Images/cf6e250634b6ca8153fc5e08e20678ce.png)

### **2.5 解密Data和刷入Magisk**

1.  根据官方文档，需要刷入“Disable\_Dm-Verity\_ForceEncrypt\_11.02.2020.zip”文件。
    

![](../Images/24afb272e5b3aa82a6b553ce8051f540.png)

2.  运行“adb-push.bat”，会将所需安装包全部拷贝到“/sdcard”目录下。进入“Install”后可以看到这些文件。
    
3.  先点击“Disable\_Dm-Verity\_ForceEncrypt\_11.02.2020.zip”，滑动刷入。
    

![](../Images/8dd76dc17804b9fa52a8844ed6748ad4.png)

4.  接着点击“Install Images”切换，选择“OnePlus6Oxygen\_22\_OTA\_064\_all\_bate5\_boot\_magisk.img”镜像，刷入到“boot”分区。
    

![](../Images/3007667a0bac368e236cf5d309fe9359.png)

5.  重启手机进入系统，安装“Magisk-v23.0.apk”。查看是否获取了root权限，并重启一次手机。（如果重启卡REC，就再刷一次Magisk的boot）
    

### **2.6 刷入nethunter**

1.  数据线连接电脑，运行 “刷入TWRP.bat”，选择“Recovery mode”进去TWRP。再“Install”中刷入“nethunter-2021.4-oneplus6-oos-ten-kalifs-full.zip”。
    

![](../Images/b34d8a81c970be7c0049206f66f596cd.png)

2.  完成之后重启进入系统。（如果卡LOGO，也重新刷一下Magisk的boot）
    

![](../Images/3418cbd2ce5d4fd82f385f7c031d534f.png)

3.  进入系统后会发现，除了Magisk之外多了其他四个APP。
    

![](../Images/6d9f8943f40e3431925adf979f0f6233.png)

4.  配置好网络后，从F-Droid商店更新NetHunter应用，给NetHunter和终端权限，重启手机即可。
    

### **2.7 开启KALI桌面**

1.  进入“NetHunter”，选择“Kex Manager”：
    

![](../Images/15e109be8920b151e357fbc5dc0d40b7.png)

2.  配置VNC密码：
    

![](../Images/a3185cfd86692e0d9e1e0dabdd02b638.png)

3.  然后点击“START SERVER”
    

![](../Images/49b0d4988edd1e8241fa3ae6a665e2cc.png)

4.  打开“NetHunter Kex”，填写配置信息，点击“Connect”：
    

![](../Images/6c45842294019f98e902a233564e85e5.png)

5.  进入KALI 桌面：
    

![](../Images/a5e3e2bd2b309fdcfb83b6545292998b.png)

## **三、END**

对于刚接触刷机的小白来说，刷入Kali Nethunter还是比较困难的。因为网上的教程或多或少，要么就是有些细节问题没有交代清楚，要么是刷机资源找不到。毕竟安卓机型种类相对复杂，官方对内核的支持也不是很好，很多情况下还需要根据自己手机的情况，重新刷入内核。不过只要你手上有一台Oneplus6，即使是小白，按照上面的流程刷入，也不会有啥问题。
