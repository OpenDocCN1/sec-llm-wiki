** 前言  
**

    Vulhub是一个基于docker和docker-compose的漏洞环境集合，进入对应目录并执行一条语句即可启动一个全新的漏洞环境，让漏洞复现变得更加简单，让安全研究者更加专注于漏洞原理本身。  

 

  

01

—  

** **docker安装**  
**

其实使用Ubuntu跟着官方文档即可安装成功：  

https://vulhub.org/#/docs/run/  

  

但是我也知道，有些大佬们对kali比较狂热与执着。因此这篇文章还是发出来了。由于kali下搭建环境会有点坑，这里已经做避坑处理，大佬们放心按照步骤来。之前的测试环境是，在配置好kali源的kali2016.3-kali2020.2版本之间都可安装。  

  

1、curl -fsSL https://download.docker.com/linux/debian/gpg | sudo apt-key add -

![](../Images/76b5d181ee137a09c04ee10917a51ab3.png)

2、echo 'deb https://download.docker.com/linux/debian stretch stable'> /etc/apt/sources.list.d/docker.list

![](../Images/f57be8453fd73d8f5856d02f480eee02.png)

3、apt-get install apt-transport-https  ca-certificates  curl  gnupg2  software-properties-common

![](../Images/cfe47e0f99e794f86b4732b79ed11422.png)

选择Y执行，等待一段时间后，要手动阅读一段信息最后按q退出即可。直到出现：

![](../Images/70bea20ccd6cdd52f57a6010d1b78010.png)

Tab切换，选择yes就行了。如果出现字体乱码，切换一下字体重启就好了。  

4、apt-get update

![](../Images/bcafc2e51a52755b9dec7e8073f43427.png)

5、sudo apt install docker.io

![](../Images/1d6d098e72db8295e948665445d7cf2a.png)

6、检查docker安装情况：

![](../Images/8d7622e91f989b272afe4c32d9ec9438.png)

  

  

02

****docker-compose****

  

**下载docker-compose**：  

sudo curl -L https://github.com/docker/compose/releases/download/1.23.0-rc3/docker-compose-\`uname -s\`-\`uname -m\` -o /usr/local/bin/docker-compose

![](../Images/97b1e2e165c205fed01195697d5a7faa.png)

（如果网络太卡，可以试试手机热点。往往是因为网络问题导致下载失败。）  

安装Docker-Compose：  

sudo chmod +x /usr/local/bin/docker-compose  
查看版本 :docker-compose version   

![](../Images/4560f11b88d8733e4c179e97762e1fee.png)

** vulhub  
**

**下载vulhub**：git clone https://github.com/vulhub/vulhub.git

![](../Images/89c5b952b8d3bcd9c91fa17aa47162a8.png)

### **启动环境**：进入vulhub选择要复现的漏洞，如webmin：

![](../Images/1c02cf29d5f9aa9be53f36c2a06963ab.png)

**对靶场进行编译：**docker-compose build

**运行靶场：**docker-compose up -d

![](../Images/c43fb6b421127f0f1489e68cb4f10a3e.png)

### **移除环境：**docker-compose down

![](../Images/f83931e4e66fa9ca6e341e1a3747839e.png)
