# 上海街角咖啡沙龙之云安全分享会

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjA0NjgyMA==&appmsgid=200065879&itemidx=1&sign=4aaba703ed898d9588aa37e4fe53bfcd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjA0NjgyMA==&appmsgid=200065879&itemidx=1&sign=4aaba703ed898d9588aa37e4fe53bfcd&scene=27#wechat_redirect)

**云计算模式当前已得到业界普遍认同，成为信息技术领域新的发展方向。云计算带来巨大发展机遇的同时又有哪些安全隐患呢？3月15日下午1:30，让我们和讲师一起探讨交流吧，沙龙期待您的到来。**

**主讲嘉宾**：

沈勇，云安全联盟(CSA)上海分会的联席主席，具有十三年信息安全行业经验，持着多个安全职业认证包括CISSP，CISA，CCSK和AMBCI。

  

**地点：**

上海市长宁区愚园路1265号（近安西路）伊轩咖啡馆

  

**费用：**

场地由主办方免费提供，另点饮料要AA哦

  

**课程缘起：**

安全市场趋势，云计算安全问题正变得越来越重要；云计算让安全问题变得集中可控，关系到国家竞争力；云时代当头一棒，自会有40%企业注重云安全。

  

**课程背景：**

当前，全世界掀起了耕云播雨的热潮。“入云”，“建云”，“登云”，“驾云”，“腾云”的热浪一浪高过一浪。Google、IBM、微软等IT巨头们以前所未有的速度和规模推动云计算的普及和发展，大量学术活动裹挟着商务宣传，迅速将云计算概念加温，推上领导和企业家的日程; 媒体的热炒，更是把云计算推上了峰巅。拼命地为资本造势。

  

然而，炒作和鼓噪的“迷云”终会消散。云中阁楼总会落地。随着云规划，云纲要，云项目、云应用的逐步落地和落实。云计算的真面目已经越来越清晰，云计算的业务价值已经越来越明显地显现出来。

  

于是，中国也步入了云计算的快速发展行列。但是，在当前的云计算快速发展中，有一个十分值得提出的问题，就是：发展云计算不注重云安全。
