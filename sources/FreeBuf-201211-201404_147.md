# Web漏洞演练平台 – ZVulDrill

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=200056811&idx=2&sn=865a93731281466166bfab34b8f8979d&chksm=28f70d601f8084760b414ec49d7e7a575b60bc0a91dc7cc7585550ebdeeed7db462cbb47b2a3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=200056811&idx=2&sn=865a93731281466166bfab34b8f8979d&chksm=28f70d601f8084760b414ec49d7e7a575b60bc0a91dc7cc7585550ebdeeed7db462cbb47b2a3&scene=27#wechat_redirect)

**在学习和研究web漏洞的过程中对每一种漏洞都进行了测试，将其整理到了一块儿，于是有了一个简单的Web漏洞演练平台–ZVulDrill，各位安全测试人员可以亲身实践如何利用这个漏洞，同时也可以学习到漏洞的相关知识**

![](../Images/3134ab0770cab1670dfa1c073484ecf6.png)

  

![](../Images/dee7cf3d8426c8e542a5ac0a119870ae.png)

平台中有10个挑战，包含的漏洞有：

  

```
·SQL注入
·储存型和反射型XSS
·CSRF
·文件包含
·后台弱口令
·文件上传
·目录遍历
·权限跨越
```

  

以及一些推荐的拓展练习。

  

项目地址：https://github.com/710leo/ZVulDrill
