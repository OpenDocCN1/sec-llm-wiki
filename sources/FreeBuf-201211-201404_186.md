# PayPal总裁马库斯信用卡遭盗刷

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=200030738&idx=1&sn=dbaa229b4a38f8c58721a04762fd1cac&chksm=28f7a8991f80218fc1154ca5c4facca6a2ca757193728b11fe1195023ef982f6ccc02018e169&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=200030738&idx=1&sn=dbaa229b4a38f8c58721a04762fd1cac&chksm=28f7a8991f80218fc1154ca5c4facca6a2ca757193728b11fe1195023ef982f6ccc02018e169&scene=27#wechat_redirect)

**日前，PayPal业务总裁马库斯在twitter中称，他的信用卡详细信息被盗。“窃贼”用这些信息克隆出的信用卡大肆血拼。信用卡信息可能是他在最近去英国旅行期间在他住的旅店或者去的商店里刷卡消费时被盗的。窃贼然后克隆了信用卡并且大量购物。**

马库斯指出，他的信用卡采用了EMV（电磁电容）芯片技术，是目前在欧洲使用的更安全的系统。但是，这个技术不能阻止数据被窃和用于大量的不正当购物。

  

原文如下：

  

```
我在英国期间，我的信用卡（带有EMV芯片）被盗刷，发生了大量冒名虚假交易。假如商家使用的是PayPal的话，这样的事情就不会发生了
——大卫 马库斯（@davidmarcus）2014年2月10日
```

  

尽管信用卡信息被盗，马库斯还是不失时机地宣传他的公司的安全好处。他说，如果商家采用贝宝的支付方式，他的信用卡信息被盗的事情也许就不会发生。贝宝称，当消费者使用贝宝服务购物时，它不与商家共享信用卡和银行账号的信息细节。
