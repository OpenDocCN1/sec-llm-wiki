# VMWare拟15.4亿美金收购安全厂商AirWatch

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=200013451&idx=1&sn=f3005745fe67287f47606e5a98034b3c&chksm=28f064001f87ed167780a3c7e964b5d7a355cf1f28bb55f8f82bbfb6fa5e649055836778be8d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=200013451&idx=1&sn=f3005745fe67287f47606e5a98034b3c&chksm=28f064001f87ed167780a3c7e964b5d7a355cf1f28bb55f8f82bbfb6fa5e649055836778be8d&scene=27#wechat_redirect)

**VMWare 15亿美金收购安全厂商AirWatch。AirWatch是一家移动安全厂商，成立于2003年，全球1600员工，客户来自150个国家，主要竞争对手包括Cytrix, MobileIron和FrontRange。收购看点：虚拟化和移动安全的结合。**

随着企业需求的增长和技术的革新，越来越多的企业允许员工使用移动设备办公，为了确保员工使用智能手机和平板电脑的安全性，全球著名的虚拟机软件公司VMware表示将以**15.4亿**美金收购私人控股的移动安全公司AirWatch。

  

当然一些分析师认为这单交易其实完全是给黑莓公司构成一种威胁，因为黑莓公司长期以来一直致力于为企业寻找研究安全产品。也有人说这单交易可能在移动市场内掀起更多的收购热潮。

  

![](../Images/2ab5a70be5cd2b300c0017b73d7121cd.png)

  

VMware公司本身最近也进入了移动安全这个市场。它的主要业务是做虚拟化软件，它创建一个在操作行为上如同一个真正的电脑的虚拟机。这可以帮助企业削减IT成本，节省的服务器和存储空间等。  

  

```
“AirWatch将成为我们的移动业务的核心。”公司CEO帕特·基辛格（Pat Gelsinger）告诉路透社记者。“我们和AirWatch一起，将把我们在PC和桌面的优势带到移动领域。”
```

  

去年，IBM收购了移动设备管理公司的Fiberlink通信，而思杰系统公司在2012年收购了了Zenprise。  

  

UBS分析师阿米特巴巴帕西（AmitabhPassi）表示，此项交易将使黑莓更具挑战性，因为它现在面临着强劲的竞争对手，他同时表示，预计谷歌公司，苹果公司和微软公司都会寻求收购来加强自己在移动企业市场的地位。  

  

在纽约证券交易所上市后，一下午的交易，VMware的股价上涨了2.3％，达到99.57美元，此前该公司对于第四季度和当前季度营收都高于其最初的评估。  

**上亿美元的交易**

  

AirWatch，成立于2003年，将成为VMware的组成之一。他的1600多名员工的将继续如同以前一样在其岗位工作，AirWatch创始人兼CEO John Marshall继续担任其现有职位。AirWatch联合创始人兼董事长Alan Dabbiere将直接向VMware的CEO Pat Gelsinger负责。

  

总部位于亚特兰大的AirWatch，其竞争对手包括MobileIron和 FrontRange。该公司表示，其客户数量超过1万，其中包括，美国联合航空公司(United Airline)和雷诺(Renault)，另外，美国9大零售商也使用该公司产品。  

  

VMware表示，将出资约11.75亿美元现金及价值约3.65亿美元的分期付款和未既得股权承担。  

  

暨在2012年VMware收购了Nicira公司，一家网络虚拟化软件提供商。在这一年半的时间内，AirWatch是VMware第二家花费上亿收购的公司。

  

此笔交易预计将于今年第一季度末完成，2014年，AirWatch将能为VMware带来月7500万美元的营收。  

  

VMware表示，如果此次交易未能在6月1日前完成，公司将向AirWatch提供2500万美元的过渡性贷款。  

  

分析师马歇尔表示，AirWatch从风投公司Insight Venture Partners和Accel Partners处共融资2.25亿美元。该公司去年的营收应该在1.25亿-1.5亿美元之间。  

**市场估计**

  

相较去年而言，VMware现已和更多的企业客户和企业续约。

  

VMware还估计其第四季度营收为14.8亿美元，同比增长约20％。  

  

VMware预计，公司2014年第一季度营收在13.3亿-13.7亿美元之间，全年营收将在59.4亿-61亿美元之间。据汤森路透I/B/E/S分析师平均预计，该公司第一季度营收为13.4亿美元，2014全年营收将为59.5亿美元。
