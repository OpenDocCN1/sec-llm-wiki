# 新年伊始，微软再遭叙利亚电子军挑衅

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=100009051&idx=3&sn=982138fec6dd941fcfeae1da501a2a7b&chksm=26ed96d0119a1fc61b0a8fbc22c949ebf0dc6bf62a995c3930279f2f22da2bf5d286fc8330f3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=100009051&idx=3&sn=982138fec6dd941fcfeae1da501a2a7b&chksm=26ed96d0119a1fc61b0a8fbc22c949ebf0dc6bf62a995c3930279f2f22da2bf5d286fc8330f3&scene=27#wechat_redirect)

**在2014年初，微软再遭叙利亚电子军（****Syrian Electronic Army****，简称SEA）袭击，其Twitter账户@MSFTNews被黑客劫持，并发布SEA的消息。**

著名的叙利亚电子军又一次黑掉了微软发布新闻的Twitter账户–@MSFTNews，2014年初，叙利亚电子军还黑进Skype的官方推特账户和博客，发布抗议支持“美国国家安全局（NSA）”的监测计划的消息。

  

虽然微软已经快速删除了这些推文，大概花了一个小时来清除这些被攻击的证据。但是在这间隔时间里，叙利亚电子军已经保存了一系列证据，以下是相关信息的快照：

![](../Images/c702e73001708a9776c84922abfcae09.png)

![](../Images/dd5d90d30ce8b41b2e43967d7caea30f.png)

  

下面的第一则是SEA转发最近一次攻击Skype官方账户@Official\_SEA16后发布的消息：

```
“不要使用微软电子邮件(hotmail,outlook),他们会监视您的帐户并销售数据给政府。”
```

  

在微软的官方@MSFTNews账户发布了同样的消息，同时发布的微博显示：

```
“叙利亚电子军队就在这里！”。
```

  

我写的这些，没有任何新闻说明黑客是如何攻讦微软账户，Skype被劫持的原因也仍然是一个谜，但很有可能是攻击者袭击了某些管理员账户再来攻击这些账户的（例如鱼叉式网络攻击，或者各种形式复杂的社会工程学）

  

要知道攻击官方媒体或大企业的账户引起的反响是很强烈的！攻击者不仅可以利用它来宣传还可以传播恶意软件和服务链接。

  

美联社也报道，即使被袭击的时间间隔很短暂，但黑客发布的错误信息仍然带来了灾难性的影响。
