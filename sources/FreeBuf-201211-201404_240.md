# 美国警长给妻子电脑安装键盘记录器遭判刑

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=100008250&idx=1&sn=3085daa31ff4416dbf298fb17b4eddf1&chksm=26ed93b1119a1aa7aa2bff4c2d1a0add6f8dea036d8bf7bce9b8c8220dfaf6398aad7b92144b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=100008250&idx=1&sn=3085daa31ff4416dbf298fb17b4eddf1&chksm=26ed93b1119a1aa7aa2bff4c2d1a0add6f8dea036d8bf7bce9b8c8220dfaf6398aad7b92144b&scene=27#wechat_redirect)

**        去年也就是2013年4月22日，美国西维吉尼亚州Clay县的Miles J. Slack做了一个愚蠢的决定。当时他即将离婚，他对妻子和某个人的关系愈发感到忧心忡忡。**所以他在正常工作时间进入了妻子的办公场所，找到了她用的个人电脑，在键盘和主机之间安装了键盘记录器，以便一字一句地记录妻子电子的邮件内容和IM聊天记录，以及各种网站登录的用户名和密码。随后Slack离开了办公室，并没有被抓住。  

  

        但硬件键盘记录器容易被发现，更何况他安装键盘记录器的电脑属于西维吉尼亚州高等法院，而 Slack本人则是该县的最高执法官员。他的妻子则是Clay县的法院的地方官员，经常有机会接触到法院被告的财务细节，其中就包括他们信用卡的罚款信息。而Slack对妻子的邮件监视必然会收集到法院的的私人信息，这如果被法院发现了，必然会严惩不贷！

  

        情况更糟的是，Slack是个警察，而且不是一般的警察，他是Clay县的治安警长！ 他担任过Clay县副警长长达16年，2012年11月被选为Clay县的警长。他安装键盘记录器的时候，他任期才满三个月，如果该装置被发现了，他的职业生涯也会就此终止。

  

        5月6号，也就是不到三个星期的后，高等法院的技术人员在执行机器更换任务时发现了该按键记录器，当西维吉尼亚州警察向Slack询问此事时，这位警长“假装不知道键盘记录器是什么”后来政府提交给法庭的文件显示“执法人员的供词无价值”

  

       最终，Slack在他辞职的前几个月供出事件原委，承认联邦政府对他的“窃听”指控并最终被解雇。（ps:不作死就不会死啊…) 联邦检察官对此愤怒，并认为一个警长这样做基本上就窃听了整个司法部，并强硬要求宣判。更委婉说法“可能错误地与一个私人窃听另一位私人的罪行相提并论。”但Slack认为，这愚蠢的计划只是窃听他的妻子—并不是整个法院，他要求减轻处罚。

  

       在Slack前妻宽大处理的要求下，Slack被判两年缓刑和1000美元的罚款，和前妻拥抱后裁决。


    

        法官John Copenhaver,说道。
