# FreeBuf微信公众账号支持自动回复啦～

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=100007904&idx=2&sn=62044855f35106244ff4eaf00de92f93&chksm=26ee6d6b1199e47de735fc01a9b8efd193e3ba528f4618ac2a7b4fcb13ff4ba2b50452f1746c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=100007904&idx=2&sn=62044855f35106244ff4eaf00de92f93&chksm=26ee6d6b1199e47de735fc01a9b8efd193e3ba528f4618ac2a7b4fcb13ff4ba2b50452f1746c&scene=27#wechat_redirect)

![](../Images/7763cf49529d641eacc7349f7a0ffbd3.png)

  

功能如下：

1.  回复任意内容弹出帮助菜单  
    
2.  回复\[0\]访问本站
    
3.  回复\[1\]查看最新文章
    
4.  回复\[2\]查看随机文章
    
5.  回复\[3\]查看热门文章
    
6.  回复\[4关键字\]搜索文章
    
    如回复“4安全”，搜索与“安全”有关文章
    

  

后面我们还会增加小黄鸡功能，赶快体验一下吧～
