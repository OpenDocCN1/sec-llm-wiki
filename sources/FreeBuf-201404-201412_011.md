# 事件跟踪：有内鬼？黑客极有可能物理接触了索尼的网络

本周一，索尼影视（SONY Pictures）遭到自称为GOP（Guardians of Peace）的黑客组织攻击，索尼因此被迫关闭了企业的网络。而据最新消息，黑客组织GOP很有可能通过物理接触索尼公司的网络实现了此次入侵。

  

**事件回顾：黑客电影般情节再现**

  

据TheNextWeb网站报道，索尼影视公司的网络遭遇了一次很严重的攻击，如同电影里的黑客入侵场面，其公司里的每台电脑的屏幕都被篡改并显示同一张图片。

  

在遭遇黑客攻击之后，所有员工的电脑上都出现了一张同样的图片，上面写到：

  

```
Hacked by #GOP（由#GOP入侵）
```

  

黑客威胁称只要满足了他们的要求，他们就会自动停止攻击，如果不服从的话，他们会把其中的秘密数据公之于众。

http://www.freebuf.com/news/52758.html

  

**索尼公司机密文件已被黑客获取**  

  

根据员工的描述，目前公司的网络仍然处于中断状态，VPN也同样不能使用，很多员工在使用非技术方式继续工作中。在攻击发生后，SONY公司立即断开了与卡尔弗城和纽约的网络连接，这也在一定程度上影响到了公司的海外业务。

  

事件开始时，索尼员工登录网络时触发了黑客组织GOP的脚本，并显示了一张警告的图片。黑客留下一个链接，指向的内容是GOP黑客组织已经窃取并准备公布的索尼内部机密文件列表，其中包括：

  

```
私钥文件、源代码（cpp）、数据库密码、硬件库存清单和其他资产信息、网络拓扑图、产品概述、时间表和说明、财务相关文件和个人身份信息。
```

  

在一份声明中，索尼只承认了他们在调查IT部门，并拒绝讨论任何相关的详细信息。

  

索尼被黑当天，GOP保持了沉默，但随后有人代表小组开始通过邮件将有关信息告知了媒体。

**有内鬼：黑客极有可能物理接触了索尼的网络**  

黑掉索尼影视的黑客称他们正在努力制造“公平”。同时也有可靠资料显示，在此次入侵事件中有索尼公司内部员工在做内应。

  

GOP黑客组织在写给媒体的邮件中写道：

  

```
"We Want equality \[sic\]. Sony doesn't. It's an upward battle." 
我们要的是公平，Sony却没有，这是一场逐渐升华的战斗。
```

  

黑客们的真实目的仍然不得而知，但在Tweet上称索尼娱乐的CEO Michael Lynton为“罪犯”。
