# 黑客伪造Viber未接来电传播病毒

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=201600299&idx=4&sn=bea7eddb01e41dbc7778b72269440faa&chksm=2f1fbfa0186836b6d7a94adc0c283c5937241d808f0d47bf69ccd08ac7518adc9bb63c838d7c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=201600299&idx=4&sn=bea7eddb01e41dbc7778b72269440faa&chksm=2f1fbfa0186836b6d7a94adc0c283c5937241d808f0d47bf69ccd08ac7518adc9bb63c838d7c&scene=27#wechat_redirect)

Viber是一种智能手机用的跨平台网络电话及即时通讯软件，能在3G和WiFi网络上运作，类似于微信/QQ语音电话。近日，全球各地的众多Viber用户们都收到了一份虚假邮件，这些自称是来自Viber的邮件提醒你你有一个未接来电。邮件中会提供一个链接让你查收这个语音留言。

  

实际上，这封邮件并非发自Viber，而当用户点击邮件中的连接时，就会进入一个恶意网站，网站内包含恶意软件而非语音留言。

  

用户点击链接后就会自动下载一个文件，这份文件是用来检测用户目前使用的操作系统和浏览器的，如果你用的是Windows + IE的组合，就会下载另一个ZIP文件，这个ZIP压缩包中包含一个exe文件，当exe文件被双击执行时，系统便会进入一个Asprox僵尸网络。

  

![](../Images/a3ba03ad0dcca0cd5ba2769448729c2f.png)

  

一旦进入僵尸网络，黑客就控制能够电脑系统，他们能够进一步地在系统中安装恶意软件。他们可以装一些用于窃取用户敏感信息，包括系统中保存的密码。你的计算机操作系统还会借由僵尸网络被用来进一步发送和传播恶意软件。

  

Hoax-Slayer报告称这次的事件与之前曾冒充WhatsApp软件的邮件十分类似。另外有另外一部分的假冒Viber邮件包含的网址指向一个在线毒品网站。
