# 免费开源相册Piwigo <= v2.6.0 SQL注入漏洞（0day）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=201432808&idx=1&sn=6f1a3a0ad0544583510a601594122d4e&chksm=2f1a0c63186d8575eb1aa6fd78c82a4dae7f83a22ff152adff04cf1398131ac4fc5e79fbf87a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=201432808&idx=1&sn=6f1a3a0ad0544583510a601594122d4e&chksm=2f1a0c63186d8575eb1aa6fd78c82a4dae7f83a22ff152adff04cf1398131ac4fc5e79fbf87a&scene=27#wechat_redirect)

**Piwigo是世界上最著名的免费开源相册系统之一，由PHP+MySQL架构。由于该框架搭建方便，受到国内外的开发者青睐，近日，Piwigo <= v2.6.0爆出重要0day漏洞。**

漏洞成因,Piwigo相册系统的/piwigo/picture.php页面，没有完整的验证jQuery参数。攻击者成功利用该漏洞，可以获取数据库的全部信息，漏洞及其简单暴力。  

漏洞影响范围，Piwigo <= v2.6.0。
