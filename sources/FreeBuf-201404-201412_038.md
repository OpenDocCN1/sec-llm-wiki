# 中国电信的失误，俄罗斯发生路由信息泄漏

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=201413216&idx=3&sn=f9e2d26567691d220d77492803f266bf&chksm=2f1ac0eb186d49fd65f2154579a24fa8d05f23a8a83eb349f3a68689cbaae3aa8a26be2ccbf6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=201413216&idx=3&sn=f9e2d26567691d220d77492803f266bf&chksm=2f1ac0eb186d49fd65f2154579a24fa8d05f23a8a83eb349f3a68689cbaae3aa8a26be2ccbf6&scene=27#wechat_redirect)

**由于中国电信的失误，俄罗斯本土的网络流量在不断的向俄罗斯境外路由，这有可能会对俄罗斯的通信安全造成影响。****网络监测服务中心Dyn于周四在****博客****中写到，这次事件是由于边界网关协议（BGP）中存在错误引起的。**

自从去年中国电信和俄罗斯最大的移动通讯商Vimpelcom签署BGP邻居（BGP peering）协议之后该问题就多次出现。我们知道一些本土通信要想在其他的网络上传输信息就需要支付给中间通信运营商们高额的通信费用，而签署BGP邻居协议之后就可以节省下这笔支出，但是万万没想到危险也在随之而来。在这个协议框架之下，俄罗斯本土的网络流量会不断的路由到中国电信的路由器上。

  

**安全影响**

**Dyn的网络分析主管Doug Madory说**

```
此次事件影响并没有以往泄漏事件那么的重大。在此之前，印尼卫星（Indosat）泄露事件影响了全球的路由表；VolumeDrive几乎泄露了整个BGP的路由表。但事实上，由于此次的路由泄露事件当事人并不知道在他们的通信过程中存在着错误，所以这类看似较小影响的安全事件往往会比灾难性的事件持续更长时间。
```

  

![](../Images/13b0c1b917e2f61741f56a55a7a80d81.png)

**由于执法机构和黑客有能力监控路由通信，Madory建议网络运营商们留意并过滤他们接收到的路由信息。否则网络流量很容易被重定向，同时也会对网络安全通信和路由性能带来潜在的威胁。**
