# 有关部门修复了Instagram可以被访问的漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=200666275&idx=2&sn=4291e1d78a9ce27d92cfe6cebabb69d7&chksm=28ee7e281f99f73e14f0a0f5b8844d933aeb376339b3e3a5419ca24b09f68f3539df8cd79e8e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=200666275&idx=2&sn=4291e1d78a9ce27d92cfe6cebabb69d7&chksm=28ee7e281f99f73e14f0a0f5b8844d933aeb376339b3e3a5419ca24b09f68f3539df8cd79e8e&scene=27#wechat_redirect)

**今日Facebook旗下的照片分享服务Instagram被屏蔽，在社交网站如新浪微博上，Instagram搜索也被屏蔽。早在今年7月，Instagram的应用从国内主要第三方Andriod商店消失。目前还无法判断这次屏蔽是短期性还是长期性的。**

![](../Images/75986c194046d0850ef4dd9eea87cebd.png)

  

虽然目前还无法获得中国大陆一些特定用户的数据，但是可以确定的是在近几年该平台在中国已经是越来越流行。全球有超过200万的Instagram用户，但绝大部分都不是美国人。Instagram的消失并不是因为技术问题，因为它还可以继续在香港和其他国家使用。今年7月，Instagram的应用从中国主要第三方Andriod商店消失，但是对那些已经下载了这一app的用户来说还是可以继续使用的。

  

![](../Images/613bdc1dab73f21ed48e69c0f4f29256.png)

  

不少网名在微博上发表了自己对Instagram从中国的消失表示了强烈的不满，在一个分享超过4000次的微博帖子里指出，**Instagram现在也加入了许多在中国被封杀的国外服务器的行列中。**

```
“Instagram最终加入到了Facebook、Twitter、YouTube、Line 、Snapchat这一大家庭中，永别了。”
```

  

  

![](../Images/222c2b2dfbed812708561e1d6e37ed7a.png)

  

**该服务器一直广受大陆网民用户的好评，而这次被屏蔽的背后原因相关机构也没有给出明确的解释。目前还无法判断这次屏蔽是短期性的还是长期性的，至少暂时是无法使用了。**
