# 藏宝图：斯诺登公布NSA深度网络监控计划

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=200585081&idx=2&sn=7ac3abd168317c3bc80f825b2432ea1f&chksm=28ef3df21f98b4e40afdc6a358e906c8c45ca8f232c6b860326c501555310101659f2ae5d367&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=200585081&idx=2&sn=7ac3abd168317c3bc80f825b2432ea1f&chksm=28ef3df21f98b4e40afdc6a358e906c8c45ca8f232c6b860326c501555310101659f2ae5d367&scene=27#wechat_redirect)

**斯诺登在新提供的文档里，揭秘了美国国安局（NSA）的深度计划：“将整个网络的所有设备在任何地点、任何时间的动态都纳入监控中”。**

**近乎实时的、交互式的全球互联网地图**

美英两国都有着机密情报服务，它们拥有德国电信公司和其内部网络的机密接入点。负面新闻一直环绕着美国的NSA（国家安全局）和英国的GCHQ（国家通信总局），它们似乎也都窃听了德国的巨头们。其中，中枪的包括Stellar，Cetal和IABG三大网络运营商。  
明镜周刊报道称（以下事实均基于爱德华斯诺登提供的各类材料）：“藏宝图”程序允许各类机构获取整个网络架构的信息，以及随着各种随PC用户变动的私人路由信息定位图。

  

德国电信也被认为，在当前的网络里存在技术监控的接入点。它们在一张巨大的地图上仅仅被标记为红点，该地图由许多没有标记日期的幻灯片组成。Spigel警告说，该图可能会作为网络攻击的信息储备。

《纽约时报》是第一个指出这件事的，即“藏宝图”提供“近乎实时的、交互式的全球互联网地图”。同时，它收集了wifi网络和地理数据从而提供“30万英尺的网络视图”。这会涉及多达5千万个互联网供应商的独立地址。

  

**德国对监控事件表示严重抗议**

**Stellar这个巨头公司，表达了对美国和英国监控行为的愤慨：**

```
“这类网络攻击明显违反德国法律！”
```

  

Netcologne联合Deutsche声明，他们并不确定是否有数据泄露，但是其安全主管站出来宣称，“国外机密服务渗透进我们的网络是决不能忍受的事情。”  
他还声明了一点，

  

```
“我们正在寻找事件的蛛丝马迹，并也已经向当局报警。”
```

**GCHQ同时声明道，**

```
“为了保证我们行为的授权性、必要性和恰当性，所有的工作都是按照法律和政策框架严格执行的，并且我们接受了严厉的监管”。然而，他们仍然没有对最新的活动作出任何评论。
```

  

美国和德国也发生了争执，这是由于2013年斯诺登透漏有关NSA的信息后，监控情形恶化。

  

NSA在2002年就已经开始监控德国总理Chancellor Angela的电话。NSA间谍已经掌控了所有应该掌控的信息，自从那时起柏林就宣称过，其国防部藏匿了一个美国间谍。  

  

美国处于舆论风暴的中心，而德国也遭到了批判，merkel的对手抓住这一点对她进行打击，指责她对监控泄密事件表现得十分软弱。德国也被大量丑闻缠身，在8月，德国被媒体重重地记上了一笔，其国外情报局监控了土耳其达四年之久。
