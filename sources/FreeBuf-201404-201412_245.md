# Robin Williams死亡下的网络犯罪

加州马林县治安办公室称，美国著名喜剧演员Robin Williams在家因窒息于当地时间8月11日早上死亡。

  

骗子们总是利用无中生有的事情来欺骗众多的受害者，这一次他们利用喜剧演员Robin Williams的不幸身亡。通过Facebook上一段Williams在死亡之前就发布的一个假的永别视频来达到一定的目的。

  
据Symantec所说，你可能在主页上看到一篇被你的Facebook好友所分享的一篇假消息，骗子们便能通过发布这个消息从这位演员的死亡中获利。这篇消息声称是Robin Williams在这周自杀之前的最后一个通话的视频。 

  

```
“骗子和网络罪犯们经常利用引人注目的新闻标题来吸引受害者，当这个视频声称是来自于最受欢迎的BBC新闻网站时你也可能成为其中一名受害者"并没有这个视频，用户们在点击这个链接时进入的时假的BBC新闻网，就像许多社会上的犯罪一样，用户需要先执行操作才能查看内容，在这种情况下，用户在观看视频之前就先转发了。”
```

  

smantec安全响应管理员Satnam Narany在一篇博客中写到。一旦点击这个链接，用户们就会被要求分享这个假视频的链接，或者必须安装伪造的Facebook插件才能观看视频。

  

这个视频的标题：

  

```
Robin Williams用手机录下了他边上吊边用刀刺伤自己，他仍然可以让大家笑，但最终他会让大家泪流成河。
```

当你完成调查，骗子们便能从每一个完成调查或下载文件中获得利润。据Symantec所说，在骗局开始后48小时内这条关于Williams的死亡视频已经在Facebook上分享超过2400万次。骗子们仅仅时使用了简单的社会工程学伎俩——让人们点击恶意链接的方法来在Facebook用户中传播。

  

```
“多年以来，骗子们就是机会主义者从Amy Winehouse和Paul Walker到Miley Cyrus和Will Smith的假死亡，他们总想尽办法利用这些消息”。
```

  

Narang说，其中有一个例子是关于"Saturday Night Live"和"30 Rock"的明星Tracy Morgan在新泽西收费高速公路死亡的事故已经被证实为虚假信息。

  

Symantec建议互联网用户要警惕在社交媒体网站上的耸人听闻的故事，他还提到正在采取措施来阻止Facebook上的欺诈行为。Better Business Bureau也发出类似的警告：

  

```
"基本点击链接查看关于Williams信息或视频时让你下载一个播放器，那么这一定是一个病毒。"
```

  

悬停在一个链接上，你可以看到他真正的域名，在你点击他之前，悬停鼠标查看链接和不随便点击链接便可以不出现不熟悉的网站。

  

不要轻易相信你在互联网上的朋友，事实上你的朋友们也不会喜欢或分享骗局照片的链接。他们的帐户可能被黑客入侵，骗子们也可以使用另一个名为"点击劫持"的策略。

  

"点击劫持"技术可以用来诱骗你点击你通常不会点击的社交媒体链接。
