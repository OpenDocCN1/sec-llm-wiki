# FreeBuf茶话会：小而美的线下沙龙

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=200430074&idx=1&sn=e5ea3a0303d02d5010cf4c28b6d1e58e&chksm=28e9c3711f9e4a6713e380a7e7a08e49cecd8f6253b50fc2d32c07b09a051987fe2d0c221715&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=200430074&idx=1&sn=e5ea3a0303d02d5010cf4c28b6d1e58e&chksm=28e9c3711f9e4a6713e380a7e7a08e49cecd8f6253b50fc2d32c07b09a051987fe2d0c221715&scene=27#wechat_redirect)

**随着智能手机的普及,移动支付已经成为各大互联网企业及银行的必争之地，但是移动支付便捷的同时也带来了巨大的安全风险，DNS也是互联网基础设施中最薄弱的一环，连续的多次严重DDOS事件给广大的互联网用户带来了很大的影响。**本次FreeBuf茶话会将围绕这两个主题展开讨论：

  

```
1、目前移动支付端所遇到的常见安全问题与解决方案，以及在新的支付模式下安全需求及安全实现方式，内容包括或不限于：短信木马、蓝牙支付、NFC支付、生物鉴权等。
2、介绍DNS服务器常见的DDOS攻击手法和方式，解析防御的手段，并设计一个完整的防御体系。
```
