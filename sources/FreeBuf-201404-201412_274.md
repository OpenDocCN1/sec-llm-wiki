# 巴勒斯坦黑客为保家卫国入侵以色列电视台（视频）

近日，有哈马斯（Hamas）的黑客声称成功对以色列电视10频道进行程序破解，并植入了一段未预定的电视信息，“呼吁”以色列结束空袭。

  

巴基斯坦和以色列两国的冲突从现实到网络空间再到黑客团体，无处不在。包括匿名者，亦因抗议以色列杀害了许多无辜的平民而攻击以色列的政府网站。

  

**以色列的“达美乐披萨”的Facebook主页也被黑客恶意篡改，威胁伊拉克政府。**

  

```
“时间到了，2000多个火箭筒已经就位，攻击将要开始，伊拉克、特拉维夫、海法、耶路撒冷、阿什凯隆，阿什杜德。倒计时开始，以色列的终结……”
```

  

由于世界各地的电视台都有播放这次轰炸的场景，这一事件明显会引起一些安全社区组织的注意。Al-Qassam Brigades，巴基斯坦政治组织哈马斯派别人士，声称对以色列卫星电视10频道的网络攻击负责，黑客用自己的视频镜头替换了原有的媒体文件，中断原定节目，并传送一个未预定传输信号呼吁结束以色列在加沙的空袭。

  

![](../Images/324df0e161b7e60f6f1a24b3c1a72606.png)

  

黑客接管了以色列10频道的卫星几分钟，在这段时间内传播了受伤的巴勒斯坦人和哈马斯武装人员，并用希伯来文传播了下列信息：

  

```
“你的政府选择了开始这场战争。如果你的政府不同意我们的条款，那么请你准备好一个旷日持久的防空洞吧。”Ynetnews agency声明。
```

在视频播放中还传播了另一个宣传信息：

  

```
“如果你不想你的儿子成为囚犯或者被杀，那么赶紧喊他回家吃饭吧。”
```

  

到目前仍没有发现哈马斯这次攻击的任何细节，黑客很可能成功获取了频道10的服务器，利用发育系统的错误配置或者是对电视台目标人员的钓鱼攻击，具体手段尚且不知。

  

黑客们正试图将敏感问题舆论指向加沙，那里正有无辜的人正受到伤害。
