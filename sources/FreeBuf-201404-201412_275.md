# 数千万WordPress和Drupal站点存在DDoS风险

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=200393512&idx=2&sn=5903527ba35a5eaf17cdbb983929b462&chksm=28ea51a31f9dd8b53d573e8fe13c316a8d82e5af4298c59b53383897ad605ef9f9ab9b014cc2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=200393512&idx=2&sn=5903527ba35a5eaf17cdbb983929b462&chksm=28ea51a31f9dd8b53d573e8fe13c316a8d82e5af4298c59b53383897ad605ef9f9ab9b014cc2&scene=27#wechat_redirect)

近日白帽子Nir goldshlager发现了WordPress和Drupal存在DDoS攻击风险，受影响的版本为WordPress 3.5 – 3.9和Drupal 6.x – 7.x，根据为维基百科的数据，使用WordPress的站点可能超过6千万，更有超过100万的Drupal网站。

  

**漏洞影响范围：**

```
WordPress 3.5 – 3.9 默认配置
Drupal 6.x – 7.x 默认配置
```

**漏洞造成的影响：**

站点无法正常运行，CPU满负荷。
