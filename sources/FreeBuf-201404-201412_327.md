# 智能设备安全“新三观”：发现漏洞越多设备越安全

自家厨房里的罐头筒迅速变身覆盖几百米以外的无线Wifi，50块钱的USB数字电视接收器能接受飞机起降信息……这些看起来炫酷极致的极客实验，在另一方面正表明智能生活时代的安全面临着前所未有的挑战，意外的“惊喜”无处不在。

  

 “打破旧三观，建立新三观。”7月15日，在首届GeekPwn（极棒）安全极客嘉年华新闻发布会上，GeekPwn（极棒）全体组委会成员号召智能设备厂商树立全新的服务观、质量观、安全观，是为“新三观”。

  

“什么样的信息化产品和电子产品才是最安全的产品？被发现漏洞最多的产品才是最安全的产品。”GeekPwn（极棒）顾问团成员、启明星辰首席战略官潘柱廷的话让人耳目一新，“在智能时代不存在没有漏洞的产品，比起掩盖漏洞的存在更重要的是及早发现并且修正。我们的服务观应该是社交化、社区化的，身边的每一个你都可以发现不同的产品用法，帮助厂商不断的完善产品性能；质量观是动态的不断改进的，没有最好只有更好；安全观是在对抗中不断发现问题，在对抗中寻求动态平衡和完善。”

  

在潘柱廷看来，传统工业时代里，“质量三包”的服务观是商家服务好的标识；用了一百年的老桌子是产品结实质量好的最佳体现；不出任何问题的产品就是安全放心的。在信息化智能化时代里，产品会有很多意想不到甚至极端的用法，与传统工业时代不同，产品的服务、质量、安全正迅速被追求极致的极客群全面改变。然而，正如空气检测器也能变身监听器、手表也可以是游戏机等新玩法一样，产品观念正迎接空前的挑战。意想不到的使用方式，恰好帮助厂商不断完善、挖掘产品的更多价值。

  

潘柱廷介绍到，GeekPwn（极棒）安全极客嘉年华的初衷正在于推动智能设备行业“新三观”的建立。大会比较开放，没有太多限制，只是希望在某一方面走的比较极致，让大家想到一种极致。同时也为极客们提供一个尽情发挥才华的大舞台，也是“新三观”首次践行的最佳灵感大基地。如果参会极客能够把相应的智能设备，从原来不太成熟的状态转而发现不同的新用法，这就是一种极致的体现。问题越多，说明它越有价值，越好玩，大家一起玩起来，才能发现更多有极致有意思的创意。

  

此倡议一经提出就受到了谷歌、微软、联想、华为等智能设备厂商的热烈响应，他们甚至主动为大会提供相应设备供极客们任意挑战。与会智能设备厂商代表表示，“安全永远是在更利的矛和更坚的盾交错前进中实现的动态系统。智能设备的安全与广大用户息息相关。在本次活动中，主动提供产品设备供顶尖极客人才任意‘拆解找茬’。期望通过这些顶尖人才的全面出击，进一步打磨提升产品性能。归根到底，我们不放过任何一个完善产品的机会。希望通过更加主动的举措，给广大用户带来更安全、更丰富的产品体验。”

  

而GeekPwn（极棒）大会承诺，一旦在活动中发现了设备的安全性问题，按照规则会第一时间报告给厂商，并提供相应的修复建议供厂商尽快修复问题，安全问题的细节也不会对外公开透露，做到对厂商负责任。一次推动智能设备行业安全的行动正在健康稳步前进。

  

 “在此，我要向主动申请参加的智能设备厂商致以深深的敬意！”在发布会现场，作为首届GeekPwn（极棒）的主办方Keen Team负责人王琦说到，“谷歌、华为、联想等智能设备厂商以自身的实验促进了所有智能设备厂商安全意识的提升，是高度社会责任感和追求极致产品精神的最好体现。当一个品牌的手环被攻破时，并不意味着不安全，而是意味着这样的问题其他厂家同样存在，甚至更严重。”

  

据了解，首届GeekPwn（极棒）将聚焦智能家居、智能穿戴、智能交通、智能娱乐、手机平板等五大智能生活领域的安全问题，并设下300万人民币高额奖金池激励极客们尽情展示才华。其通过与智能硬件厂商负责任的合作，促进智能设备领域技术层面的跨越式发展，一定程度上填补了智能设备安全标准空白，是一场推动全民极客精神的安全极客嘉年华。

  

业界专家点评到，首届GeekPwn（极棒）在业内首倡“新三观”，这恰恰是极客追求极致精神的最佳体现。随着智能时代的全面来临，厂商、用户等有关“什么才是好的”产品观亟需重构。“新三观”恰逢其时的指出了新方向。而首届GeekPwn（极棒）的举办，为努力改变世界的极客们提供了一个展现才华的大舞台。云集世界顶尖极客团队的嘉年华，到底能带来大家什么惊喜，翘首期待10月24日在北京举办的GeekPwn盛宴的到来。
