# 再携手！FreeBuf成为HITCON 2014（台湾黑客年会）大陆地区唯一官方合作媒体

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=200288353&idx=1&sn=43f5e26f0820e78f7e6faadc7ed9d71b&chksm=28ebbaea1f9c33fc45b5e34d7a52a5b52f32a7bab995c499a5ffebcc20d577e1391881aaa77a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=200288353&idx=1&sn=43f5e26f0820e78f7e6faadc7ed9d71b&chksm=28ebbaea1f9c33fc45b5e34d7a52a5b52f32a7bab995c499a5ffebcc20d577e1391881aaa77a&scene=27#wechat_redirect)

2014年，FreeBuf黑客与极客与台湾HITCON再次携手啦！日前「Freebuf黑客与极客」正式成为「HITCON 2014台湾黑客年会」大陆地区唯一官方合作媒体（白金级）。  
**这是继FreeBuf与HITCON去年初次合作以来，两岸在网络安全领域交流的又一次深入。**

  

![](../Images/1ee9de684b5a77e991f8c9a0462b3e42.png)

  

今年8月，FeeBuf小编将前往台湾全程报道此次盛会，并带来**在线直播、独家见闻、专家访谈、花边爆料、宝岛风情、高清美照**（小编知道你们想要的，台妹必须有……）

  

**HITCON是什么？**

```
Hacks In Taiwan Conference 台灣駭客年會 (HITCON) 是台灣最大的駭客與資安技術研討會。

純技術的領域裡面沒有黑與白。我們認為駭客是代表著高超的技術、挑戰的精神。有別於一般商業性質濃厚之研討會，台灣駭客年會提供了一個舞台讓駭客們有機會與大家分享最新與最深入的資安技術，面對面交流經驗，自由的對談。

台灣駭客年會也舉辦了網路攻防競賽 (Wargame)，提供真實的網路環境和挑戰，讓參與人員能夠盡情發揮，在活動中學習並印證自己的能力。是駭客年會最大的特色之一。即時的 IRC 聊天頻道、綿羊牆等創新的安排，都是台灣駭客年會與眾不同之處。

在這一年一度駭客們的聚會，除了技術的分享，也能體驗到真正的駭客文化。我們歡迎所有對資訊安全有興趣的朋友，一同參與這每年一度的盛會。
```

**今年主题**

```
在這資訊發展快速的新時代中
我們面對的是無所不在的資安威脅及漏洞
舊的阻擋思維以不足因應
駭客不相信這世界有完美的無菌室
你應該學會如何適應並與威脅共存
讓我們一同進擊吧
```
