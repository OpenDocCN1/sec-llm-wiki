**酷狗音乐是中国最大最全的正版音乐提供商，是中国领先的数字音乐交互服务提供商，互联网技术创新的领军企业，致力于为互联网用户和数字音乐产业发展提供最佳的解决方案，公司的使命是成为亚太地区最大的数字音乐销售推广企业。**

**招聘岗位：安全工程师**

**岗位职责：**  

```
1、负责酷狗安全规范的制定；
2、负责酷狗安全工具和系统的开发和优化；
3、负责酷狗产品及网络的安全实施和部署优化；
4、负责酷狗安全风险的预案和行业跟踪。
```

**任职要求：**

```
1、计算机本科以上学历，具备至少2年以上互联网安全领域的工作经验；
2、熟悉各种攻击类型和安全措施的原理和应对方案；
3、拥有安全软件开发和业务系统架构能力；
4、精通各种常用的计算机编程语言及优化技巧；
5、积极进取，正直自信。
```

**地点：**广州天河区  

**附近交通：**地铁站科韵路，公交站BRT学院、棠下村
