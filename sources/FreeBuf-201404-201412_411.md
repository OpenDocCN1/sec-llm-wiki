# 美黑客组织Anonymous计划攻击世界杯赞助商

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=200232415&idx=1&sn=52906ea7f4a843605a863c7698d5e844&chksm=28f4df541f835642763ce9da208ae8633f8c589985960e8cfee415a532fda6b7bfad567aeb91&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=200232415&idx=1&sn=52906ea7f4a843605a863c7698d5e844&chksm=28f4df541f835642763ce9da208ae8633f8c589985960e8cfee415a532fda6b7bfad567aeb91&scene=27#wechat_redirect)

**全美第一的黑客组织Anonymous正在计划大规模网络攻击巴西世界杯赞助商！以抗议巴西政府在世界杯赛事上过度开销，而忽略当地底层居民生活的窘困，一位黑客这样告诉记者。**

上周，匿名者已经入侵了巴西外交部电脑，泄露了高度机密性的电子文件和文档。其中包括333封机密电子邮件，还有美国副总统拜登去年5月访问巴西时与巴西官员之间的对话内容。

  

事后，巴西外交部紧急关闭整个电邮系统，并通知3000个用户修改密码，目前巴西联邦警方已介入调查。

  

```
“我们已经在深夜进行过多次测试，看看哪些网站更容易下手。”一位Twitter名为Che Commodore的黑客说道，“我们已经制定了一套攻击计划。”
```

  

![](../Images/46047190b55e387eb5144dc9527ffa2e.png)

  

  

Che 还列举了将要攻击的赞助商列表：

  

```
“这次我们的目标是世界杯的赞助商，我们的目标有阿迪达斯(Adidas)、阿联酋航空(Emirates airline)、可口可乐( Coca-Cola Co )和啤酒巨头百威英博旗下的百威啤酒（Budweiser）。”
```

**截止到目前，这些赞助商还没有给予任何回应，但是匿名者正在进一步策划攻击事件，它将被认为是匿名者策划的最重要、最大的一次网络攻击。**

黑客用抗议画面涂鸦巴西世界杯世界足联(FIFA)网站

  

匿名者入侵了国际足联网站，国际足联网站主页取而代之的是一个YouTube视频，显示的是抗议者游行，和防暴警察释放催泪弹和橡皮子弹对抗议者开火。以显示警察的无情残暴，并要求人们通过不来巴西看世界杯来抵制巴西政府。

  

![](../Images/d6a2d69313261fef0df3b30602f87922.png)

  

视频显示抗议者高喊以下单词口号:

  

```
“Sem violencia!” — which means “Without violence!” in English"
```

  

黑客还重新编辑了网站标题：

  

**Nao Venha Pata a Copa No Brasil. Do not come to Brasil for the world cup**
