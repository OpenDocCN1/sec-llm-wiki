# NSA截获美国制造商的路由器并安装间谍软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=200205042&idx=3&sn=a71cb382f2b366ad266ee68af75a2b82&chksm=28f570791f82f96fad44286b79d1d93e1e2ef476ed8369ddb7f70d5fe3f62b6906c1abc50cc5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=200205042&idx=3&sn=a71cb382f2b366ad266ee68af75a2b82&chksm=28f570791f82f96fad44286b79d1d93e1e2ef476ed8369ddb7f70d5fe3f62b6906c1abc50cc5&scene=27#wechat_redirect)

**5月13日， 美国卫报记者格伦·格林沃尔德GlennGreenwald出版新书《No Placeto Hide: Edward Snowden, the NSA, and the U.S. SurveillanceState》披露美国国安局NSA监听丑行。**

**详情请点击Freebuf之前文章**。

  

在《无处藏身》这一书中提及，NSA习惯性地可以“收到”或者说截获到从美国出口到国外的路由器、服务器或者其他计算机网络设备，然后安装后面监听工具、后门装置，完了重新用工厂包装打包后再发往海外。从而NSA能够对这些设备的客户网络进行接入。GlennGreenwald在书中强调了NSA对路由器和其他网络设备种植后门这一方法的情有独钟，当然这也只是其执行庞大监听计划的冰山一角。

  

```
GlennGreenwald表示：“根据NSA的 Access andTarget Development部门在2010年6月的一份报告中可以发现一件很神奇的事，NSA经常会收到路由器、服务器和其他网络设备，巧合的是这些设备都将要出口。”
```

```
GlennGreenwald在书中提及：尽管美国政府一直禁止采购华为的产品，因为他们怀疑此间有天朝的后门。但是这从不妨碍美国政府来做相类的事情：对美国供应商提供的硬件设备进行“重包装”，然后发往全球各地。
```

```
GlennGreenwald在书中还表示：“天朝公司在其网络设备中植入了监听装置，真假犹未可知。但毫无疑问，美国一定是这样做了。”
```

```
“通过植入后门装置、监听工具，然后以出厂包装标准重新打包，继而发往国外。NSA从而可以访问相应设备的整个网络和用户。文件表明，情报的收集和获取就如同探囊取物一般（简直了）。GlennGreenwald在书中写道。
```

  

据GlennGreenwald，这份新的披露文件将在最近公布。而他的新书正是基于NSA前承包商Edward Snowden于2010年提供的一份文件，在文件中详细的介绍了NSA接收或者说拦截从美国出口的各种计算机网络设备。  

![](../Images/d83b5192b4e3488faaaa56a9ec46b664.png)

  

就当前现状看来，NSA一直与安全公司RSA合作，在其加密算中安置后门。但如果GlennGreenwald这一指控是确信无疑的话，这一切都明确暗示了一件事：许多美国企业都会被卷入这场事件，“难辞其咎”。  

  

通过植入后门的设备，NSA确实可以进入更为庞大的网络和用户中。

  

```
NSA报告表明，“在最近的一个案例中，一个经过供应链拦截并植入后门的设备在出口数月后向NSA隐蔽无线站点进行信息回传，这次回传使我们我可以远距离进入该设备进而监察整个网络。”
```

  

当然，自从棱镜门事件后，NSA本就是千夫所指，所以对于NSA内置后门的指控也就屡见不鲜了，德国报纸明镜周刊的一份报告称，美国情报机构截获航运的电子设备并在安置后门后交付，从而获得系统的远程访问权限。被植入后门的电子设备涉及计算机硬盘驱动器、路由器以及诸如思科、戴尔、西部数据、Maxtor、三星和华为的其他电子设备。
