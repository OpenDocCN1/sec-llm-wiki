# 新浪安全招聘高级研发工程师

**新浪公司是一家服务于中国及全球华人社群的网络媒体公司。新浪通过门户网站新浪网(SINA.com)、移动门户手机新浪网(SINA.cn)和社交网络服务及微博客服务新浪微博(Weibo.com)组成的数字媒体网络，帮助广大用户通过互联网和移动设备获得专业媒体和用户自生成的多媒体内容(UGC)并与友人进行兴趣分享。**

**工作地点：**

北京市海淀区中关村

  

高级研发工程师（帐号安全研发方向）

  

**职位描述：**

```
1、负责新浪（包括微博）帐号安全检测系统研发
2、负责大数据分析、分布式系统开发
```

**职位要求：**

```
1、至少两年以上服务器端开发经验
2、精通 PHP or JAVA 语言开发
3、熟悉 Linux 系统以及 shell 编程
4、有分布式系统开发经验者优先
```

  

**高级研发工程师（安全系统研发方向）**

**职位描述：**

```
1、负责安全检测分析以及防御系统的研发
```

**职位要求：**

```
1、至少两年以上服务器端开发经验
2、精通 Python 语言开发
3、熟悉 Linux/Uinx 系统
4、有安全相关系统研发经验者优先
```

  

如有意向，请将您的简历邮件发送到 chenyang#staff.sina.com.cn，邮件标题中请注明"【个人简历】+ 应聘职位"。
