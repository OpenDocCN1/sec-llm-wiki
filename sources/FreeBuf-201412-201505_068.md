# 美国RSA大会：围观“大事件”的主角

**RSA展会之内人头攒动，展会之外风云变幻。就在展会前两天里，先是听闻Raytheon宣布并购Websense，接着HP又宣布与FireEye建立联盟。这种大并购、大协同，往往消息突然在意料之外，细细思量又在情理之中，既让观者感到震撼，又觉得确实如本届RSA的Slogan一样——变化，是安全的常态。**

  

安天实验室在观会的同时，做了如下简单的分析整理，也“围观”了事件中几家厂商的展台。

**一、Raytheon并购Websense**

4月21日，Raytheon官网、美国彭博社等同发出新闻，美国军火商雷神公司（Raytheon）将出资19亿美元收购著名网络安全提供商Websense。雷神公司是美国大型的国防合约商，全球排行第五，而Websense的安全网关、Web安全、数据安全等具有完整的产品线和服务能力。军工复合体在美国整个产业体系中扮演着非常关键的角色，而今天他们正在向信息军工复合体演进。

  

![](../Images/7ea1789e04dd2c4902dc7dba76d16893.png "1.jpg")

  

Raytheon和Websense在合作之后，Raytheon在网络安全方面的业务将从以往偏向安全防御转向全球商用市场。而其整合后的业务纬度也将覆盖云端、终端、Web、网络等等方面。

  

Raytheon旗下的Raytheon Security Product出席了本次展会，作为Raytheon庞大体系的小分支，其低调的出现在南展区，并没有北展区的Websense高端大气。双方在RSA展会上摆出的资料已经打出了合作牌。

  

![](../Images/6c576cce12655364ee7943924ab12f8d.png "2.jpg")

  

Raytheon旗下的Raytheon Security Product

**二、HP与FireEye建立联盟**

紧接着，第二天，也就是4月22日，惠普（HP）对外宣布将和美国近年来最为亮眼的新锐安全厂商FireEye宣布成立全球首个基于事件响应和高级威胁服务的联盟。

  

![](../Images/1edb4273a0a82e35bea7f881957922c6.png "3.jpg")

  

在收购了多家安全公司后，HP在安全界也底气十足

  

![](../Images/16182d9b272b9bb2208b932dadc6c414.png "4.jpg")

  

新锐安全厂商FireEye

  

HP近年来大手笔收购了不少安全厂商，借此完善了自己的安全技术和业务，成为从IT基础建设、系统集成到安全整体防御的霸主之一；而FireEye一直高歌猛进，尽管其市值距离最高的百亿美金有明显下滑，但依然炙手可热。更连续稳居CyberSecurity Ventures TOP500的榜首。RSA展前连续发布APT30和APT28两个报告，可谓赚足眼球。  

  

这个合作具有鲜明的互补意义，HP尽管底蕴深厚，家底殷实，但难免沾染大企业病，而当今安全之理念则要求高度敏感、快速响应。HP的整体解决方案则犹如一个漫长的防线，对抗高价值威胁注定有所不足；而FireEye尽管触角广展，广泛延伸到西欧东亚等地，但与IT基础设施的结合还不算天衣无缝。

  

因此这种合作一方面可以改善HP的响应能力，另一方面也可以让FireEye更接底气。FireEye亦可以利用HP成熟的渠道体系和全球的分支机构将市场范畴向非洲、欧洲和中东等地迅速扩展。FireEye的M团队（即FireEye以10亿美金收购的Mandiant公司，曾发布APT1等著名报告）预期会在合作中发挥关键的价值。  

  

HP之前的合作风格一直以并购为主，不断用高价值收购完善自身技术的短板，但显然想从并购上吃掉FireEye，没有人有这样的底气。而FireEye在依然有强劲上升势头的情况下，且又是美国网络安全体系中一个重要的支撑点，肯定也会在一段时间内长期坚持独立发展的选择。所以双方采取了一个平等双赢的合作策略。

  

而HP和FireEye两家公司在RSA展会，都以高调的布置风格和姿态出现在“土豪聚集”的北展馆。HP作为集成商，在RSA展会一直主打安全整体解决方案。展位布局尽显大厂商风范，既张扬理念又体现文化。而在其组织的多场演讲和论坛中，也大量加入了APT检测防护的的相关内容。而FireEye可谓火力全开，基本是北展馆的中心地带。  

  

这样的并购合作大事件尽管在过去屡见不鲜，但同样彰显着变革的魅力，全球的网络安全市场的变革总在不断的发生。某些处于领域垄断地位的厂商需要扩展商业解决方案，而专业的网络安全厂商在发展到一定阶段时也需要寻找瓶颈的突破或是业务的扩大。而在这种大整合之中，我们在硅谷，同样看到一群新颖的安全创业公司蓬勃成长，各种新锐的尝试在工控、车联网等诸多新场景中细密展开。把这种产业图景结合来看，巨头间合作并购，宛如巨树枝叶参天；而大量新锐创新尝试，宛如根系蔓延深地，无所不在。  

  

也正是RSA展会期间，国内大量社保、医保系统的漏洞和信息泄露问题引发关注，国内信息化高歌猛进，安全投入不足的问题再度暴露凸显。长期合规安全观导向，使大量信息系统未能得到真正的安全检验。但此时，我们似乎发现，我们并未建立起足够的企业能力，来防御这条漫长而脆弱的战线。缺少真正扎实强大的巨头，缺少中坚骨干，安全创业后继匮乏，有限的安全创业也基本偏重于互联网和个人方向。作为大事件的旁观者，我们深知差距之大，作为安全产业的践行者，我们唯有加速前行。
