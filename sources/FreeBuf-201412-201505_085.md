# 举报腐败行为，证物被警方植入木马

**一位匿名人士向法院举报史密斯堡警局在内的“有关部门”腐败行为，受举报者委托的律师将证物存放在硬盘里寄送给警方。然而不久之后，警方将这片硬盘植入木马病毒后回寄。**

**回寄硬盘并赠送三个木马**

受举报者委托的是一名叫Matthew Campbell律师。在这次事件发生时，他试图把证物通过硬盘寄给法院检查的安全专家。当硬盘被还回来后，他震惊地发现硬盘里被莫名添加了四个木马病毒（有两个实例其实是同一种病毒，也可以称作三种）。该律师表示这种木马病毒绝不是因为偶然事件感染的。

  

**硬盘里面的木马安装在D:\\Bales Court Order下，其中包括：**

Win32:Zbot-AVH\[Trj\]：一个密码键盘记录器

NSIS:Downloader-CC\[Trj\]：一个连接黑客服务端的程序，外加一个下载者

Win32Cycbot-NF\[Trj\]：共两种实例，是后门程序

Campbell还指责警局还恶劣地删除了与此案相关的大量的邮件，详情见此处。本来案件要求警局交出所有相关的内部邮件，然而相关部门却玩起了毁尸灭迹，将相关邮件清除了个一干二净。

**事件进展**

Matthew Campbell表示，自己并不知道警局的人做了什么，同时他电脑里并不只有一个雇主，所有客户的档案都在里面，他不知道警局的人员是否甚至还有什么其他想法。

  

现在，律师正向法院状告警局蔑视法律的行为，并要求主法官尽快为他的雇主裁定案件。史密斯堡警局对此并未发表任何评论。
