# IIS最新高危漏洞（CVE-2015-1635/MS15-034）

漏洞名称：HTTP.sys远程执行代码漏洞 CVE-2015-1635

漏洞编号：CVE-2015-0345

发布日期：2015-4-15

受影响系统：

IIS6.0以上  
Microsoft Windows Server 2012 R2  
Microsoft Windows Server 2012  
Microsoft Windows Server 2008 SP2  
Microsoft Windows 8.1  
Microsoft Windows 8  
Microsoft Windows 7

**描述：**

微软于昨日修复了一批严重安全漏洞（![](../Images/afb9722bfdb60bd43c5d04eae1f8f94a.png)http://www.freebuf.com/news/64044.html），其中就包括Microsoft IIS远程代码执行漏洞（CVE-2015-034）。

  

通过该漏洞，攻击者可以在你的IIS服务器上执行系统命令。远程执行代码漏洞存在于HTTP协议堆栈(HTTP.sys)中，当HTTP.sys未正确分析经特殊设计的HTTP请求时会导致此漏洞。

  

成功利用此漏洞的攻击者可以在系统帐户的上下文中执行任意代码。对安装了IIS的服务器的网站管理员来说，请立即访问漏洞盒子在线检测是否存在漏洞，并建议立即打上安全补丁。
