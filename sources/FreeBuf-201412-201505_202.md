# 联通手机营业厅APP被Google诊断为恶意应用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=203844126&idx=1&sn=6f59f3272666e1d6b5993333f12ec77d&chksm=2f3df895184a71837567f74ef75cbfadbe952de3dac6ba0a06ef7af3a70771d61fcf32eeb5c8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=203844126&idx=1&sn=6f59f3272666e1d6b5993333f12ec77d&chksm=2f3df895184a71837567f74ef75cbfadbe952de3dac6ba0a06ef7af3a70771d61fcf32eeb5c8&scene=27#wechat_redirect)

近日有用户反映中国联通手机营业厅Android客户端被Google的应用验证功能诊断为恶意软件。Google称该应用“可能被用于监控”，并建议“立即卸载”。Google 的应用验证功能自 Android 4.2开始引入，主要防范用户自非Google Play商店渠道安装的恶意应用。
