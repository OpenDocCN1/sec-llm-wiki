# 渗透测试系统BackBox Linux 4.1发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=203089542&idx=1&sn=47b2c605daec8311acfc7239f3d45b79&chksm=2f01740d1876fd1b015f7b1ce88f6b944a938d94d5e0e811fe714e2f1f1bbc213d76e53a97c9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=203089542&idx=1&sn=47b2c605daec8311acfc7239f3d45b79&chksm=2f01740d1876fd1b015f7b1ce88f6b944a938d94d5e0e811fe714e2f1f1bbc213d76e53a97c9&scene=27#wechat_redirect)

**BackBox是基于Ubuntu的Linux发行版，它是一款用于网络渗透测试及安全评估的操作系统。新版本包括Linux 3.13内核，EFI 模式，匿名模式，LVM +磁盘加密程序，隐私的补充和armhf Debian软件包。**

![](../Images/1224715d36743c8c75318bac5c0ad38f.png)

**ISO镜像（32位和64位）可从以下位置下载：**

http://www.backbox.org/downloads

**新版本主要更新：**

```


预装Linux 3.13
```

**系统要求**

```


32位或64位处理器
```

**升级说明**

**安装命令**

```

```
