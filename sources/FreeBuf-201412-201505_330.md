# 漏洞追踪：如何检查并修复GHOST（幽灵）漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=203021488&idx=4&sn=cb3b8932482b5eaeb2db6e8c810d93e6&chksm=2f024e3b1875c72ddc265dc68349400e3183ccadfe1dfbacfcafe53bbb2360e97fac853639bd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=203021488&idx=4&sn=cb3b8932482b5eaeb2db6e8c810d93e6&chksm=2f024e3b1875c72ddc265dc68349400e3183ccadfe1dfbacfcafe53bbb2360e97fac853639bd&scene=27#wechat_redirect)

**编号CVE-2015-0235的GHOST（幽灵）漏洞是Qualys研究员发现的一个Linux服务上非常严重的安全漏洞，可以被利用来远程代码执行及本地权限提升。**

**![](../Images/0e62172b43724ca821cfc6cb32099b97.png "0.jpg")**

**漏洞简要描述**

该漏洞存在于 glic 库中的\_\_nss\_hostname\_digits\_dots() 函数，在nss/getXXbyYY.c这个文件中，gethostbyname()会使用这个功能。另外，这个漏洞本地远程都可以利用，要利用此漏洞，攻击者需要构造一个特定的 hostname 数据条给linux 上开放的服务，如果服务不对数据做安全处理，就会引发一个任意代码执行漏洞。

**下面列出了几个受影响的服务：**

```


procmail
```

你也可以用下面命令来查看你的 server 上有哪些服务依赖 glibc：

```

lsof | grep libc | awk '{print $1}' | sort | uni
```

**下面是各个系统的升级方法：**

**Centos/RHEL/Fedora 5,6,7**

```


yum update glibc 
```

**ubuntu**

```


sudo apt-get update
```
