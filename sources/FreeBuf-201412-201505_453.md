# 前美国空军成员DIY无人侦察机，可进行WI-FI密码破解、电话窃听

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=202107140&idx=3&sn=e9a14f19629c428beb455b8892e0c089&chksm=2f107b8f1867f29940b592bf0c1c4c536441d9def0f5c85309e079554917ec49aa7dc1980a50&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=202107140&idx=3&sn=e9a14f19629c428beb455b8892e0c089&chksm=2f107b8f1867f29940b592bf0c1c4c536441d9def0f5c85309e079554917ec49aa7dc1980a50&scene=27#wechat_redirect)

**近日，前美国空军成员Mike Tassey 和Rich Perkins成功DIY了一架无人侦察机，该无人侦察机可进行****WI-FI****密码破解、电话窃听、短信拦截等行为。**

![](../Images/646cfc60166ab8da00ddf49f69b816fb.png "0023ae6d001011c4d0a40d.jpg")

据Mike Tassey和Rich Perkins介绍，他们是在一间车库中利用一些现有的电子产品完成的这架无人侦察机。**目前它的起飞和降落都需要人的帮助，但它能够依照既定的程序飞行并模仿手机基站进行欺骗连接。****该无人侦察机配备了多根天线和蓝牙技术，来实现用户的通话和****WI-FI****监听和检测。**通过这些，它可以轻而易举的获得附近任何通讯工具的主要数据。   

MikeTassey 和Rich Perkins曾在法律允许的范围内做了表演测试，记录了某地区一些无意义的通话信息。

**功能广泛**

**目前这架无人侦察机的飞行范围约有50英里（约80公里），其实它的用途非常广泛，比如可以协助救援工作等**。

![](../Images/850d82eef89ac0076530ac3afa2d7a14.png "QQ截图20141218151224.png")

  

**在它的说明书中还有这样一段介绍：**

```


小型，开源，可以自己进行设计
```

**早在今年十月，以色列的研究人员就曾证明在黑帽子大会上已经有人使用激光和无人机进行网络入侵，并且由于无人机在车间就可以进行装配，对国土安全和公民隐私威胁十分严重。因此，研究人员警告称应尽量避免滥用这项技术。**
