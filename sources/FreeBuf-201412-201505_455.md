# 愤怒的索尼：索尼发动DDoS攻击反击黑客，向用户散布假冒种子

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=202085512&idx=3&sn=7f6a8dba5b916354fa8197ae6d2d83fa&chksm=2f10060318678f154116302097481093052857576d7d2e427748d24913aaf8e14b58d5fbfddd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=202085512&idx=3&sn=7f6a8dba5b916354fa8197ae6d2d83fa&chksm=2f10060318678f154116302097481093052857576d7d2e427748d24913aaf8e14b58d5fbfddd&scene=27#wechat_redirect)

![](../Images/3f9e68b5b35b3ae6e4256daf1f6abf76.png "55.jpg")

**索尼影视遭遇GOP黑客组织的攻击事件已经出现一段时间了，从黑掉索尼公司的网络、泄露电影信息、泄露公司员工敏感信息到向公司员工发送威胁邮件，索尼影视一直处于被动极为被动的局面。但是就在最近，索尼开始了“复仇行动”——索尼影视向所有分享泄露数据的网站发动了DDOS攻击，向用户散布假冒种子。一来防止信息和盗版电影进一步泄露，二来为了打击GOP黑客组织。**

**索尼影视发动DDOS攻击**

**虽然现在统计索尼影视因GOP攻击而造成的经济损失还为时尚早，但据一些专家初步估计，索尼影视至少损失了数亿美元。索尼影视怎么说也是一家好莱坞大公司，不可能任由GOP摆布吧？于是“以黑治黑”出现了……**

在FBI、火眼团队调查黑客在攻击事件中使用的格盘病毒的同时，索尼影视要求媒体不准再继续散播从它们公司泄露的数据。

![](../Images/939c7e502dfc656f7ad9ff00cca719fe.png "6.jpg")

**当然索尼影视所做的不仅仅是要求媒体不再散播其数据，它还向所有试图下载泄露信息的网民发起了复仇行动（小编：真是作死）。**

**据Recode报道，索尼影视寻求亚马逊AWS（Amazon Web Services）在新加坡和东京数据中心的服务器对泄露其信息的网站发动了DDOS攻击，以防止信息的进一步泄露。而****当网民们试图在种子网站上下载GOP窃取的信息时，他会收到假冒的种子（已经被索尼影视修改过）。**这种技术并不罕见，之前就有公司为了阻止网民在种子网站上下载盗版电影而使用过这类的DDOS攻击技术。

**受害者向攻击者发动DDOS攻击，这种反攻行为一直备受公众讨论，部分反对者称这种属于以黑治黑，是违法行为。但目前还没有相关法律给出明确解释。**

**黑客组织GOP再发威胁信息**

  

**索尼影视已经要求所有的媒体不准泄露其公司的数据，目前各大种子网站都无法下载索尼影视泄露的电影信息。索尼影视计划于12月25日在美国上映《The Interview》,该部电影是一部以刺杀朝鲜总统金正恩为题材的喜剧。索尼公司之所以把它安排在圣诞这天上映，是因为它想把这部电影作为一个礼物送给全国的观众。**

**但是，攻击者得知这一消息之后再次发出了恐吓，威胁广大的观众不要去看该部电影。难道攻击者真是来自朝鲜？**

**攻击者在Pastebin和其他的一些文本共享网站上发出一条恐吓信息，大致内容分为：**

```

世界将充满恐惧，请记住2001年9月11日；我们建议你到时候远离电影院，如果你的家就在附近，你也最好离开；所有的可能发生的后果都是由索尼影视造成，到时候全世界都会谴责索尼影视公司。
```
