# 朝鲜：黑客入侵索尼影视是正义之举

面对美国的指控，朝鲜政府于周日发表声明，否认其曾入侵索尼影视，但同时表示他们很支持黑客们的“正义”举动。至于黑客是谁，朝鲜认为可能是他们在海外的“支持者和同情者”。

  

**朝鲜：黑客入侵索尼是义举**

  

在一部索尼影视出品的未上映电影《刺杀金正恩》中，存在有损朝鲜总统金正恩形象的情节，此次GOP黑客组织的入侵正好解了朝鲜心头之恨。

  

朝鲜国防委员会发言人称，这部索尼拍摄的电影是在教唆恐怖主义行为，并且损害了朝鲜领导人的形象。朝鲜认为此次黑客事件是正义的举动，会使美帝国主义瓦解。

  

![](../Images/e81600dca8a96158621e628fb9922d3b.png)

  

在索尼影视公司遭到黑客攻击之后，美国将所有的矛头都指向了朝鲜——他们认为朝鲜就是这次攻击的幕后黑手。他们之所以这样推测，一方面是因为索尼拍摄的电影有损了朝鲜领导人金正恩的形象，朝鲜称这是一种“战争行为”，故事的内容很有敌对的性质；另一方面，朝鲜黑客组织强大，曾经制造了多起黑客事件。

  

**最新近况：黑客在曼谷？**

  

安全研究人员最新调查表明，攻击者通过泰国曼谷St. Regis五星级酒店网络将索尼影视的机密数据泄露到网上。泄露信息的时间是泰国时间12月2日中午12:25，也就是加利福尼亚时间12月1日的早晨。

  

具体是从客房还是大堂或者是其他的地方散播的现在还不清楚，当然不排除攻击者远程控制了这家酒店的网络。如果攻击者真的在St. Regis酒店的话，要想找到他相当困难。酒店的顾客很多，所有的人都可以使用酒店的无线网络。

  

另外，攻击者使用的IP地址是来自泰国的一所大学，但只是利用大学的开放网络发起攻击。
