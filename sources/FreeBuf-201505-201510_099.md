# 五角大楼又被黑，美国很愤怒

**五角大楼又被黑了，这一次被黑的五角大楼美食广场电脑暴露了员工的银行信息。**

就在八月，俄罗斯黑客刚入侵了五角大楼的机密电子邮件服务器。

  

据NBC新闻报道，美国官员称俄罗斯推出了一个“复杂的网络攻击”来破坏五角大楼的联合参谋部的非机密电子邮件系统。目前这个邮件系统已经关闭两周了。

  

官员还补充说，他们盗取了参与参谋长联席会议的4000位重要人员的信息。现在，五角大厦的美食广场的计算机系统被攻击者破坏又导致一部分雇员使用信用卡的财政信息曝光。

  

星期二，国防部的官方发言人Tom Crosson中校证实了这一事情。而且美国当局已经立即通知那些数据泄露的雇员。

  

![](../Images/33891a2dfed8d4b03505e29a6b90ca77.png)

五角大楼的保安局在过去的一周里收到了大量关于冒名使用五角大楼人员的信用卡的报告。

![](../Images/68c9bcbcb4ea7f64a14f8daf16fafaab.png)

  

不过Crosson说到现在还没有到底有多少职员被影响的信息，而且还不清楚是哪个食品广场被黑客攻击。

**多次遭黑客攻击**  

不得不说，美国政府已经被网络攻击了好几回，包括入侵人事管理办公室（OPM）和白宫的网络。纽约时报曾在八月发表文章说，在OPM被黑导致超过2亿人的消息被泄漏后，美国总统奥巴马决定报复中国。

  

奥巴马曾在四月签署了一项指令以限制经济来防止任何企图袭击美国利益的人。

  

在这个攻击消息发布的前几天，美国政府还在考虑制裁俄罗斯和中国黑客对美国造成的黑客活动。

  

**几个不愿透露姓名的美国官员透露，奥巴马政府已经在考虑惩罚那些黑客和针对美国的组织，最近他们提出了对那些攻击美国公司/政府的个人或团队的制裁。**
