谷歌和苹果的新一场撕逼大战

谷歌和苹果之间新的一场大战又开始了：即将于本月发布的新系统iOS 9中，苹果将允许用户在iphone和Ipad上安装广告屏蔽应用，此举不仅给发行商造成困扰：每年价值700亿美元的移动广告市场或将受此影响，而且也将加剧苹果与硅谷其他科技公司之间的紧张关系，因为苹果的这一举措可能会让更多苹果用户使用其自带的Safari浏览器。


但对于像谷歌这样的搜索引擎公司以及广告商来说，这他们可不干了！毕竟谷歌的收入主要来自广告，并且他的广告营销收入超过全球任何其它公司。总之，一句话：谷歌受广告屏蔽工具的威胁最大!

FreeBuf百科：App Transport Security

App Transport Security 简称：ATS，是iOS9和OS X El Capitan的一个新特性。iOS9使用ATS的目的是提高苹果操作系统的安全性以及在此操作系统上运行的任何应用的安全性。


众所周知，基于HTTP传输数据的网络请求都是明文，不言而喻，这将存在相当大的安全隐患。App Transport Security要求TLS (Transport Layer Security) 1.2或者更高，以保证客户数据的安全性。


谷歌帮开发者绕过苹果的加密

苹果的用户对广告商来说尤其具有吸引力：iPhone的售价通常高于Android手机，这种高消费人群通常被广告主喜爱。


那么谷歌会如何应对IOS 9的ATS机制呢？


谷歌在ADS开发者博客《应对 iOS 9 中的 ATS 机制》一文中称：谷歌致力于遵守行业标准（HTTP 协议），但不能保证通过谷歌平台发布广告的第三方广告网络或者自定义代码也能严格遵照这一协议，因此建议广告发布商添加一项例外来绕过苹果 ATS 机制使非 HTTPS 协议得以正常运作。


实际上谷歌也非常支持严格的 HTTPS 保护措施，包括苹果的 ATS 规则，只是谷歌目前提供的广告绝大多数依然是基于 HTTP 协议，为了避免被外界指责与苹果 ATS 背道而驰，谷歌只是建议开发者们在恰当的时候使用这项解决方案。
