# 德国联邦议院内网再遭黑客入侵

**德国联邦议院日前遭遇黑客入侵，是否造成数据泄露尚不清楚。在今年一月份，联邦议院和联邦总理府的网络也曾遭到黑客攻击。**

**不明身份黑客入侵了联邦议院内网**

德国联邦议院已公开承认其机构IT系统遭到了黑客的入侵。

  

据明镜周刊报道，联邦议院的IT职员在上周五发现有不明身份的黑客试图渗透进德国国会的内部网络，内部网络的数据系统中存储的都是一些高度敏感信息，但这些敏感信息是否泄露还不清楚。

**联邦议院部分系统暂时关闭**

![](../Images/94645ab09d817cc382e99f2be107f22f.png "66.jpg")

  

安全专家们认为此次黑客攻击事件相当严重，出于安全考虑，联邦议院的部分系统已经被暂时性关闭了。负责处理德国情报局和NSA间谍事件的联邦议院调查委员会系统也被关闭。

**关联事件：德国总理府和联邦议院遭黑客攻击**

2015年1月7日上午10左右，联邦议院和德国总理府网络先后瘫痪，疑似遭到黑客攻击。

  

随后，一个疑似来自乌克兰并自称“网络金雕”的黑客组织承认了入侵是由他们造成的。据称他们的目的是呼吁德国不要为乌克兰总理提供政治和财政支持。
