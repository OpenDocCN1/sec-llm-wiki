# 美军“明星战机”F-35出现雷达系统漏洞

**据报道F-35“闪电Ⅱ”（F-35 Lightning II）战斗机被爆其系统上出现了问题。**

**雷达系统出现问题**

F-35在战机世代上属于第五代战斗机，联合攻击战斗机是一款由美国洛克希德·马丁设计及生产的单座单发战斗攻击机，F-35主要用于前线支援、目标轰炸、防空截击等多种任务，并因此发展出3种主要的衍生版本，包括采用传统跑道起降的F-35A型，短距离起降/垂直起降机种F-35B型，与作为航空母舰舰载机的F-35C型。

F-35有四大关键机载电子系统——诺思罗普·格鲁曼公司的AN/APG-81有源相控阵雷达和光电分布式孔径系统（EODAS）、英航宇系统公司的综合电子战系统及洛-马公司的光电瞄准系统（EOTS）。目前由于F-35B型运行的是早期版本的系统，暂时还没有发现问题。

**根据Janes报道中称，在2015年底一个软件故障影响了F-35A战斗机AN/APG-81机载有源相控阵雷达在飞行中的功能实现，从而成为影响美国空军F-35A在2016年获得初始作战能力(IOC)的最大威胁。美国国防部空军F-35集成办公室主管Jeffrey Harrigian少将向 Jane表示，该漏洞会影响雷达系统稳定性。**

**漏洞正在修复测试**

Jeffrey Harrigian少将最终将其为“雷达稳定性”问题，所谓“雷达稳定性”是指雷达能够借助3i软件持续工作和运行的能力。五角大楼报告曝光了该战斗机电脑软件存在严重缺陷。比如，在融合、电子战和使用武器时，战斗机会显示模棱两可的威胁信号，应对威胁时能力也有限，而且还需要场外提供高精度目标坐标以进行精确攻击。

在这个过程中，雷达系统会收到错误信号迫使其重启系统。Harrigan称，洛克希德马丁公司已经发现该问题并正在修改。目前估计这个漏洞的补丁会在3月底完成，如果出现延时，那么对于初始战斗力（IOC）生成日期来说也会被推迟。爱德华兹F-35综合测试(ITF)试飞主管迈克 格拉斯(Mike Glass)表示，F-35战斗机首次空中开火的成功是多年计划的高潮。这次测试结果将用于未来测试，未来测试将评估战斗机的精确度性能和任务实效性能。

对于该漏洞，其官方并未透漏过多细节。而明年，将开展进一步的测试，届时战斗机将融合GAU-22/A系统与完整航空电子设备和任务系统性能。新测试将关注定性影响，包括炮火焰(枪炮发射时产生的可见光)的人为因素和飞行性能。
