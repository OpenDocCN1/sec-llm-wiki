**Weeman是一款运行在Python环境下的钓鱼渗透测试工具，与S.E.T社会工程学工具包功能有些类似，但这款工具简单易用，安装简单，可伪造HTML页面，也可被用来进行DNS欺骗攻击。**

**主要更新内容**

> 附加新的配置文件
> 
> 推出了新的框架（Weeman framework 0.1）
> 
> 新增命令行选项功能

**测试环境**

> Linux (any)
> 
> Mac (未测试)
> 
> Windows (未测试)

**安装环境**

> Python <= 2.7
> 
> Python BeautifulSoup 4
