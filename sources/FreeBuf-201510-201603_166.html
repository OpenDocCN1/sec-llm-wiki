BackBox是基于Ubuntu的Linux发行版，同时它也是一款用于网络渗透测试及安全评估的操作系统。

它被设计为快捷且易于使用，目前主要支持五种语言，分别是英语、德语、西班牙语、法语以及意大利语。同时该系统还提供了一份最低纲领的但完整的桌面环境，而这得益于它自己的软件仓库，该仓库总是同步到最新版本的、最常用且以合乎道德而闻名的黑客工具。

系统要求 

32位或64位处理器

512 MB的系统内存（RAM）

6GB的磁盘空间用于安装

显卡最低支持800×600的分辨率

DVD-ROM驱动器或USB端口

新版主要更新内容 

系统内核版本更新至4.2性能提升系统改进上游元件

修复前一版本出现的bug

改进匿名模式

云平台服务升级

新的和更新的黑客工具：wpscan、knockpy、nmap、zaproxy、set、guymanager、sqlmap、apktool、hashcat、can-utils、binwalk、openvas、phishing-frenzy

系统升级（适合所有用户）

sudo apt-get update

sudo apt-get dist-upgrade

sudo apt-get install backbox-tools

从以前的版本升级（backbox linux 4.x）请遵循这些指示：     

sudo apt-get update

sudo apt-get dist-upgrade

sudo apt-get install -f

sudo apt-get install linux-image-generic-lts-vivid linux-headers-generic-lts-vivid linux-signed-image-generic-lts-vivid

sudo apt-get purge ri1.9.1 ruby1.9.1 ruby1.9.3 bundler

sudo gem cleanup

sudo rm -rf /var/lib/gems/1.*

sudo apt-get install backbox-default-settings backbox-desktop backbox-menu backbox-tools --reinstall

sudo apt-get install beef-project metasploit-framework whatweb wpscan setoolkit --reinstall

sudo apt-get autoremove --purge

sudo apt-get install openvas sqlite3

sudo openvas-launch sync

sudo openvas-launch start
