# 挥手过安检：他借助植入手掌的芯片而成功登机

**近日在瑞典首都斯德哥尔摩阿兰达机场，安德里亚斯•斯约斯特罗姆 （Andreas Sjöström）借助皮下植入的智能芯片，成功登机。**

**成功登机**

现在你可以想象一下到机场登机，而你不需要带任何的证件是什么样子的。在瑞典首都斯德哥尔摩阿兰达机场，一名乘客安德里亚斯•斯约斯特罗姆 （Andreas Sjöström）就成功实现了这件事情，他凭借在皮下植入一个米粒大小的智能芯片然后成功登机。

  

![](../Images/9a865eaf0e3203fef6a7a806e698c4a1.png)

  

在定了飞往巴黎的机票之后，他将该机票信息上传到智能芯片中，繁琐的登记检查被智能芯片简化，只需手一挥即可过安检，接下来就坐在飞机的座位上等待飞机起飞。

  

**Sogeti公司数字技术咨询副总裁 Sjöström表示：**

![](../Images/b1e510f2e984e2b89ac7ac528d2c2eb7.png)

几周前我就将一块NFC芯片植入我手掌的皮肤下面。”

这块芯片中有他在北欧航空EuroBonus常旅客计划高级别会员信息，同时在机场的安全门也有NFC读卡器，这样Sjöström就不需要传统的方式登机了，只需将手腕轻轻一甩，读卡器就可以读取芯片中的信息了。根据The Telegraph报道，这种先进技术已经被使用，例如控制手机或者解锁门禁系统。而这种技术最方便的是，你不需要携带登机牌或者一些证明身份的文件。

  

![](../Images/00a8986e64bd22daac49030ba701e98b.png)

**之前尝试过解锁其它系统**

本次实验用到的是an xNT芯片，xNT是配备NFC 类型2 RFID标签(NFC Type 2 RFID tag)的小型可植入式设备。xNT极小，大约是2mm x 12mm。在 Schott 8625信号识别器用玻璃管中，xNT会在植入前经过环氧乙烷气体消毒。Amal Graafstra在接受mic采访时称：

![](../Images/b1e510f2e984e2b89ac7ac528d2c2eb7.png)

如果北欧航空打算让一部份愿意体验这个过程的乘客实现这一点，那么就需要提供记录乘客信息的NFC芯片。”

而像实验中用到的注射器、外科用的手套、芯片，这些都可以在网上直接订购。Sjöström表示这个手术过程其实没有什么痛苦，而当芯片和手部皮肤摩擦的时候，完全可以感受到芯片。

  

![](../Images/159730a447aa16dc347000a1b06840b3.png)

  

同时Sjöström称，这个设备在未来可以被制造出来，但很有可能设备安装在皮肤的外面而不是植入皮肤里面。

  

Sjöström最后表示说：

![](../Images/b1e510f2e984e2b89ac7ac528d2c2eb7.png)

我已经成功的尝试了其它方案，我曾利用芯片解锁过办公室的门禁系统。”
