# 继BBC“掉线”之后，世界多地区的WhatsApp也发生中断

**著名即时通讯软件WhatsApp在新年前夕出现了中断问题，许多人想用WhatsApp与亲戚朋友联系时，却发现其无法使用。**  

  

在阿联酋、印度、巴基斯坦、巴西、美国和欧洲国家的用户反馈信息称，软件服务出现了中断问题。

**DownDetector发现网站出现问题**

WhatsApp（英文全称WhatsAppmessenger）是一款目前可供iPhone手机、Android手机、Windows Phone手机、WhatsApp Messenger、Symbian手机和 Blackberry黑莓手机用户使用的、用于智能手机之间通讯的应用程序。

  

从格林威治时间12月31日下午4点28分（美国东部时间11：28）开始，专门监控互联网和移动服务的网站DownDetector发现，有关WhatsApp服务中断的报告频繁出现。

  

虽然有不少人都用WhatsApp和亲戚朋友分享新年祝福，但是却不能实现了。

![](../Images/268c82fa402526a50d60525a5252bede.png)

![](../Images/442a8d5e03ecbf1d7d3d027748b8c99e.png)

根据2015年的数据统计，WhatsApp在全球拥有大约9亿的用户数量。而事情开始以后，就有不少用户开始抱怨不能发送信息了。  

![](../Images/2cdb42da39dcbb5010359c448f523689.png)

**而之前****英国广播公司（BBC）****网站12月31日早晨因大规模的网络攻击而瘫痪。BBC在其推特上称，网站无法访问的原因是“技术问题”。BBC当时称，其正在致力修复网站。**  

  

这一网络攻击不仅让BBC主要的英语网站受到冲击，也影响了包括BBC中文网和网络播放器iPlayer广播和视频等网站，后来BBC又披露说，这一问题源自于一种名为“分布式拒绝服务”的攻击。不过BBC目前对是否该攻击造成了这些问题既没有确认，也没有否认。

**目前尚不清楚具体原因**

WhatsApp发言人在接受每日邮报（MailOnline）称：  

今天有很多人无法使用WhatsApp，目前我们正在恢复原来服务状态，并为由此引发的不便道歉。”

而WhatsApp今年曾经被评为保护用户数据最差的应用程序。在12月初，巴西法庭就曾下令在全国关闭WhatsApp服务。

  

暂时暂停服务引发150万巴西人注册Telegram Messenger，它是WhatsApp的竞争对手。此举在巴西国会引起了骚动，并激起人们冷嘲热讽。WhatsApp的发言人说：

我们很失望，法官竟然会惩罚超过1亿的巴西人，只是因为我们没办法把本来就没有的信息移交调查。”

但是目前WhatsApp并没有透露导致服务中断问题的原因。
