# 反恐黑客组织：ISIS为通信安全开发手机APP

**Ghost Security Group****称****，他们发现了一款ISIS开发的Android手机APP，这款APP是ISIS成员们为了安全通信而使用的。**

**曾帮助美国打击ISIS**

Ghost Security Group是一个反恐黑客组织，该组织参与了一系列针对ISIS激进分子的网络行动。

  

今年7月，该组织支帮助美国的执法部门和情报部门，成功挫败了ISIS在纽约和突尼斯的恐怖袭击阴谋。

  

专家们发现的这款Android app是通过流行的通讯软件（如Telegram）中的隐匿渠道进行传播的。ISIS的成员们开发的这款APP可以用来当作替代的通信渠道，根据报道，这款应用被用来宣传和分享ISIS组织的行动信息。

![](../Images/b1e510f2e984e2b89ac7ac528d2c2eb7.png)

他们想要建立一种比Twitter和Facebook更加安全的广播方式，” Ghost Security Group首席运营官Michael Smith II告诉《基督教科学箴言报》，”你会越来越多地看到，他们的重点会从开发渠道转移到在全球范围内控制他们材料的发放。”

**ISIS的网络能力**

Ghost Security Group的发现显示了ISIS的网络能力，这种能力之前也曾被一些杰出的专家们谈到过，包括F-Secure首席研究官Mikko Hypponen。

  

Hyppönen担心网络极端分子会渗透关键设施，导致严重后果。专家解释称，ISIS可能是首个具有对政府关键设施进行攻击的能力的恐怖组织，而且情况现在越来越糟糕，因为这个组织越来越意识到在网络空间展开攻击行动会更加有效。

  

在此期间，美国国会正在讨论商业产品和服务中加密技术所扮演的角色，和加密技术被激进组织滥用的情况。

  

![](../Images/fa7153a4628120dfe00a6039906de9df.png "ISIS-mobile-app-2.jpg")

  

全球的情报机构和执法部门都称，恐怖分子利用商业通讯平台中的加密功能策划恐怖袭击，包括11月13日发生在巴黎的枪击爆炸事件。

**Nasher应用**

今年8月，美国安全顾问发现了另外一款名叫Nasher的应用，同样由ISIS成员开发。这款应用同样通过非官方渠道传播。伊斯兰国使用这款Nasher记录报告、电台新闻和视频文件。

![](../Images/c5810b39b0073afc35eaeba6f771a08c.png "ISIS-mobile-app-download-page.jpg")

  

这款App的引导页已经被浏览了超过7,500次，但不知道有多少次下载。
