# 活动｜第四届全国网络与信息安全防护峰会召开在即

**2015年第四届全国网络与信息安全防护峰会（XDef安全峰会）将于2015年11月19-20日在湖北武汉举行。**

本届峰会将分两天（11月19-20日）进行，11月18日报到。本届峰会将重点分析新形势下面向网络安全威胁情报的基础检测能力构建、大数据分析、共享与安全事件分析技术。

  

同时，还将讨论就来自软、硬件基础设施及新型应用带来的后门、漏洞隐患，日益复杂的恶意代码、有组织的网络攻击威胁以及新形势下国家面临的重要信息安全挑战，针对性探讨国家网络与信息安全保障中面临的困境以及应对方案，同时还将就高素质网络空间安全人才培养问题进行重点研讨。

**本届峰会包括以下三个环节：**

**1、专家技术报告**

主会场特邀报告、全体报告及分会场报告近20场。  

  

**2、全国大学生信息安全类竞赛优秀作品展（设分会场1个）**

2015年全国大学生信息安全竞赛优秀作品15件（其中一等奖作品14件，二等奖作品1件），所有入选作品指导教师和优秀学生代表将到会与参会代表进行现场互动交流，部分作品将进行具体报告和演示。  

  

**3、网络空间安全人才培养论坛（设分会场1个）**

由专家小报告及研讨会组成，论坛主题为：网络空间安全人才创新实践能力培养与合作模式探讨。本论坛将邀请教育主管部门专家、知名高校信息安全专家、信息安全专业主管副院长或系主任、知名安全企业专家、社会人才培养项目负责人参与研讨，同时期待关注网络空间安全人才培养的相关专家积极参与。  

**会议演讲议题：**

本次会议将邀请阿里巴巴安全部副总裁杜跃进、腾讯安全平台部负责人杨勇（Coolc）、360企业安全集团总裁吴云坤、FreeBuf&漏洞盒子创始人袁劲松等安全界知名嘉宾将进行精彩的行业研讨和二十余场演讲。

本峰会由公安部网络安全保卫局、国家计算机网络应急技术处理协调中心 (CNCERT/CC)、教育部高等学校信息安全专业教学指导委员会指导。

  

武汉大学空天信息安全与可信计算教育部重点实验室主办，武汉大学计算机学院承办，信息保障技术重点实验室协办。

  

中国网络空间安全协会（筹）竞评演练工作委员会、中国网络空间安全协会（筹）人才与教育工作委员会筹备组等多家单位为支持单位。

  

《中国信息安全》、《信息网络安全》杂志、FreeBuf、看雪论坛网站等多家单位为本届峰会支持媒体。
