# 2016携程信息安全沙龙：甲方企业安全的力量与荣耀（8月20日）

由携程信息安全部主办，5位重量级企业演讲嘉宾会分享他们从未对外公布的企业安全实践经验。 

## 5大精彩议题及嘉宾介绍

1）云WAF与大数据实时分析实践

议题简介：如何在低成本和低风险的情况下给web服务做好快速、准确的安全防护工作。

演讲嘉宾：张亮-携程技术保障中心资深安全工程师

嘉宾介绍：负责web安全、网络安全、安全研发等工作，专注于高性能、大流量以及大数据下的安全工作。

2）携程业务安全前生今世

议题简介：针对携程业务安全过去及现在面临的问题，如何尝试解决的分享。

演讲嘉宾：闵杰-携程技术保障中心高级安全工程师

嘉宾介绍：负责业务安全的产品设计工作，主要面向黑产平台，反欺诈，用户安全画像等分向。

3）浅析唯品会产品安全加固方案

议题简介：讲述在唯品会，内部产品上的安全设计以及推广sdl流程中，我们所做的事情跟我们遇到的坑。

演讲嘉宾：方斌-唯品会安全测试经理

嘉宾介绍：唯品会安全应急响应中心负责人 

4）去哪儿网ELK安全监控中心的踩坑与实践

议题简介：分享去哪儿安全部门利用ELK搭建安全监控中心的探索和实践，以及管理安全事件。

演讲嘉宾：周军-去哪儿网安全工程师

嘉宾介绍：主要负责公司漏洞分析、运维安全和相关平台工具的研发工作。

5）点融网的一些安全实践

议题简介：在点融网安全构建中遇到的一些问题和解决方案，以及点融正在做的一些事。

演讲嘉宾：李文吉-点融高级安全工程师

嘉宾介绍：专注渗透测试，前某大数据公司安全研究员，点融谛听系统设计者之一。
