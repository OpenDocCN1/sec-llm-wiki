许多企业的安全工程师使用Nessus进行安全基线检查和合规性工作。通过这个脚本工具，你可以连接Nessus API进行扫描管理、启动、停止等工作。

依赖

需要Python 2.X 并且得安装 “requests”模块。具体安装文档可参见http://docs.python-requests.org/en/latest/user/install/

启动和帮助

python autoNessus.py   
python autoNessus.py -h  

认证

正确的URL和认证信息需要填写在脚本的52-56行

示例

列出所有扫描和ID

python autoNessus.py -l

启动第42号扫描

python autoNessus.py -sS 42

暂停42号扫描

python autoNessus --pause 42

注意事项

如果你需要启动一个已玩测的项目，你必须在第272行的列表中进行添加。
