# 明星安全扫描器公司Acunetix被黑了？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651061143&idx=1&sn=b858c0438f4265555a6bbe9ffbda8424&chksm=bd18691c8a6fe00a7a551ed9e9f9c2b94c8b8f552c03e998ba9369d8a45ff2c8ad4f450d653f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651061143&idx=1&sn=b858c0438f4265555a6bbe9ffbda8424&chksm=bd18691c8a6fe00a7a551ed9e9f9c2b94c8b8f552c03e998ba9369d8a45ff2c8ad4f450d653f&scene=27#wechat_redirect)

Acunetix公司出品过全球最流行的扫描软件之一是Acunetix Web Vulnerability Scanner。

**然而不幸的是，就在昨天（6月4日），Acunetix官网被克罗地亚黑客篡改。网站主页已不能正常显示，官方博客也不能使用。黑客可能在Acunetix服务器或者Web应用中发现了高危漏洞，所以才导致这次的网站被黑事件。  
**

**![](../Images/ab5367b72a4c3a20ab11e10cdae289d0.png)  
**

**FreeBuf百科：Acunetix**  

Acunetix是全球范围内最领先的Web应用安全扫描器，通过检测众多网站发现，有多达70%的网站有漏洞，可能导致公司机密数据被盗，如信用卡信息和客户名单。

**被黑快照**

![](../Images/07845b6a24ebe879316ab03ee9cbe6d5.png)  

在各位FBer们看到这篇快讯的时候，网站已不能打开了。据了解，黑页中的图片是克罗地亚总理奥雷什科维奇，黑客入侵原因目前还不清楚。

不过安全公司Acunetix被黑也许恰恰说明——任何网站都可能存在安全漏洞。
