# 2017年第一季度信息安全行业融资交易总额创新高

2017第一季度私有网络安全公司的融资交易数量，达到过去五年的最高水平。  

 WannaCry 恶意软件汹汹来袭，侵袭全球……如今，针对政府及各类企业的网络安全攻击事件不断增多，涉及的行业领域扩大，造成的危害也愈加严重。随着网络安全攻击的数量和规模不断扩大，政府及企业开始寻求对于网络、数据和设备的安全防护，个人投资者也以前所未有的力度，加大了对于网络安全公司的投资关注。

![](../Images/939f7b65f7dd57755f117ce75de77654.png)2017 Q1交易总额创新高

自2013年之后，2016年成为了信息安全领域投融资的高峰年；而随后的2017年第一季度，资金交易总额再创新高，足足比上个季度高出20%。

 专注于 IDaaS（身份认证和权限管理）的安全公司 Okta ，在今年四月的 IPO 之后市值达到15亿美元。而在此之前，已有多家私营安全公司估值超过 10 亿。目前在信息安全领域估值超过10亿的独角兽公司共计8家。

最近的一起大额交易发生在5月17日。这家安全领域“独角兽”公司 CrowdStrike，致力于为客户提供终端防护、威胁情报、事先／事后安全响应的 SaaS 服务。而在5月17日该公司在获得来自美国华平投资集团(Warburg Pincus)，Accel合伙公司(Accel Partners)，以及 CapitalG (原名 Google Capital)共计 1 亿美元的 B 轮融资后，公司整体估值达到 10 亿美元，成为了一家信息安全“独角兽”公司。

![](../Images/74d34e0247fb49951739e41404c5d6f5.png)

除了这些偶尔才可以见到的“过亿级”美元的融资轮（风投称为 Mega-Round ），现在的投资者正万分积极地投入到信息安全公司的早期项目中去（种子轮及A轮融资）。这个现象说明，在当前不断演进的网络威胁形势下，信息安全行业仍然渴望着全新的解决方案，来更好地实现安全威胁的应对，甚至实现对于安全攻击的事先预测。

信息安全初创企业的交易数量，自2013年开始逐渐增长。2016这一年，安全行业融资以超过400起交易，共计35亿美元的交易额创造了历史最高纪录；尽管在资金总额上与2015年相比，稍有回落，但15与16年的交易额都突破了30亿大关。按照目前的状态来看，2017的全年资金交易的活跃度应该都会保持在较高的状态，交易总额预计能够超越去年，接近2015年的历史最高值。

![](../Images/68ba72dd8e750ab6a022c7555c86447d.png)

今年截止 5月17 日已发生超过190起交易，其中出现了1起 Mega-Round —— CrowdStrike 公司的1亿美元 D 轮融资 。今年资金规模第二大的交易，当属 Armor Defense 公司在四月的 F 轮中获得的0.89亿美元融资，投资方包括了新加坡科技电信媒体公司(ST Telemedia )及史蒂文斯集团(The Stephens Group)。

另有两家安全公司获得超过0.6亿美元规模的融资：Verisys 公司在第一季度从Growth Equity获得了0.73亿美元融资，而 SentinelOne 在 C 轮中获得了0.7亿美元融资。

而在2016年，共计四家安全公司获得 Mega-Round ：

StackPath ：16年Q3获得1.8亿美元私募股权投资

LogicMonitor：16年Q2获得了1.3亿美元成长股权投资

Cylance：16年Q2 获得1亿美元D轮融资

Mobi Magic ：16年Q1获得1亿美元B轮融资

在2015年，获得Mega-Round 案例包括：Tenable Network Security 得到了由 Accel Partners 及 Insight Venture Partners 投资的2.5亿美元 B 轮融资，还有anium，CloudFlare，CrowdStrike 和 Illumio 公司也获得了Mega-Round。

![](../Images/939f7b65f7dd57755f117ce75de77654.png)季度融资纪录

基于季度融资统计，我们可以看到，信息安全初创企业获得的融资交易数量已经是历史上的季度最高纪录——约140家安全公司获得融资。自15年的第三季度开始，季度融资的交易数量开始超过100家（如果不算16年第四季度突然降至90家）。而17年第一季度中对于这些企业的总交易额均高于历史同期的交易额。

目前我们正处于17年的第二季度，已经可以看到在超过50起的融资交易中，这些安全公司成功获取了总额约6亿美元的融资金额。

## 企业的融资交易阶段 – 以早期阶段为主

自2013年开始，信息安全融资交易中超过50%的资金交易都发生在早期融资阶段（种子轮至A轮融资）。随着时间的变化 ，B轮之后的融资交易占比有所上升。而自2015年开始，包含债券及可转债在内的其他轮融资交易占比也随着整体交易的增长而有上升。

![](../Images/96089c11eb3e4e8bbdd10201e9cf5712.png)

![](../Images/939f7b65f7dd57755f117ce75de77654.png)最活跃风投

恩颐投资 ( NEA ) 和柏尚风险投资公司（ Bessemer Venture Partners ）当属自2013年来，信息安全领域最为活跃的风险投资者了。排名第三位的则应该是 Accel 合伙公司。

![](../Images/9553cd86326307b448a9dd5cce9f07a2.png)

![](../Images/939f7b65f7dd57755f117ce75de77654.png)获得最多融资的公司

获得风险投资最大青睐及资金支持的安全公司是 Tenable Network Security , 紧随其后的两家公司则是 Tanium 以及 Lookout 。
