# 警惕出现下一个“WannaCry”，安天发布CVE-2017-11780漏洞免疫工具

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651065688&idx=4&sn=94460aaf45d9547df55348100c9d2712&chksm=bd1f9fd38a6816c5ef932110386906ca17227a77c270dfda3b8c0af3e42790bc1c7067253f64&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651065688&idx=4&sn=94460aaf45d9547df55348100c9d2712&chksm=bd1f9fd38a6816c5ef932110386906ca17227a77c270dfda3b8c0af3e42790bc1c7067253f64&scene=27#wechat_redirect)

**近日，国家信息安全漏洞共享平台（CNVD）收录了Microsoft WindowsSMB Server远程代码执行漏洞（CNVD-2017-29681，对应CVE-2017-11780）。远程攻击者成功利用漏洞可允许在目标系统上执行任意代码，如果利用失败将导致拒绝服务。CNVD对该漏洞的综合评级为“高危”。综合业内各方研判情况，该漏洞影响版本范围跨度大，一旦漏洞细节披露，将造成极为广泛的攻击威胁，或可诱发APT攻击。**

安天提醒用户警惕出现“WannaCry”蠕虫翻版，建议根据本文中“受影响系统版本”和“微软官方补丁编号”及时做好漏洞排查和处置工作。目前，安天已紧急发布了应对该漏洞的免疫工具（工具下载链接：http://www.antiy.com/tools.html ）。另外，安天智甲终端防御系统及探海威胁检测系统等产品对类似机理的漏洞均有检测防御安全策略。

## **二、 防护解决方案**

### 2.1 安装微软官方补丁

用户可根据系统安装补丁编号排查是否已经安装官方补丁。

Windows 7系统操作如下：开始→控制面板→Windows Update→查看更新历史记录。

Windows10系统操作如下：Windows设置→更新和安全→历史更新记录（如下图）。

![](../Images/2633a499437684672c3485a8407bd2c3.png)

不同系统版本微软官方补丁编号、参考链接如下表（安全更新为本次漏洞的单独补丁，月度累积更新为补丁集合（含本次漏洞补丁））：

![](../Images/028a6bef7b91bc557467b8d1667d54ba.png)

### 2.2 临时防护步骤

2.2.1 由于相关原因不能及时安装补丁的详细防护步骤如下：

关闭网络，开启系统防火墙；

利用系统防火墙高级设置阻止向445端口进行连接（该操作会影响使用445端口的服务）及网络共享；

打开网络，开启系统自动更新，并检测更新进行安装；

2.2.2 Windows 7系统的处理流程举例：

1) 关闭网络。

![](../Images/9f9e1fa5ca968ca8ba169e2f59b22d58.png)

2) 打开“控制面板→系统与安全→Windows防火墙”，点击左侧“启动或关闭Windows防火墙”。

![](../Images/fc7864b046d347d6769466553bcc8f20.png)

3) 选择“启用Windows防火墙”，并点击确定。

![](../Images/bd73f37f0dc00900f633f213268dbdd4.png)

4) 点击“高级设置”。

![](../Images/dc9d92639d56054570c9e0320a3fd95b.png)

5) 点击“入站规则→新建规则”，以445端口为例。

![](../Images/650d3fdd12eceae6a4e59c4b8cb1874a.png)

6) 选择“端口”，点击下一步。

![](../Images/6ad0318e7c311ca7f49d3089e5804a67.png)

7) 选择“特定本地端口”，输入445，点击下一步。

8) 选择“阻止连接”，点击下一步。

![](../Images/b81bbaa8b4d9e79b2fda7e5fcec4cf7f.png)

9) 全选“配置文件”中的选项，点击下一步。

![](../Images/d453b03b7abe81f50f5ed749b7552423.png)

10) 在名称中可任意键入文字，点击完成即可。

![](../Images/dba77a42fa98efc474f7a046494a31d1.png)

11) 恢复网络。

![](../Images/f89ec56941e36ade6f02b3d239bf0031.png)

12) 开启系统自动更新，并检测更新进行安装。

![](../Images/88d0c0567f27f048b4f867179e639ba4.png)

13) Windows 7系统需要关闭Server 服务才能够禁用445端口的连接。

关闭操作系统的server服务：依次点击“开始 →运行”，输入services.msc，进入服务管理控制台。

![](../Images/ee0fcee7ae93fc9bccbec6e45ce38c89.png)

双击Server，先停用，再选择禁用。

![](../Images/e7e165e53f4c1321c9a05dcc402b4077.png)

![](../Images/4ff694bd4e999a70ccd26bb54a5fd9c1.png)

最后重启Windows 7。使用netstat –an查看445端口已不存在。

![](../Images/d2c12a1f1067a6980680039550766726.png)

注：在系统更新完成后，如果业务需要使用SMB服务，将上面设置的防火墙入站规则删除即可。

![](../Images/2f3a92020eb291b8321933aec9b3068b.png)

安天针对该漏洞发布的免疫工具可实现禁用系统服务、设置ipsec本地组策略等功能，提供通过阻断SMB连接使漏洞 （CVE-2017-11780/CNVD-2017-29681）无法触发的临时缓解方案。
