# 如何在32位系统中使用ROP+Return-to-dl来绕过ASLR+DEP

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651065542&idx=2&sn=3b1d86a95d14dfe05af38a356e19aca0&chksm=bd1f9e4d8a68175b3e3fe08f5600383564dd2be2eb5cb9214ed678e6986bb5dd6bff2ae3c10b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651065542&idx=2&sn=3b1d86a95d14dfe05af38a356e19aca0&chksm=bd1f9e4d8a68175b3e3fe08f5600383564dd2be2eb5cb9214ed678e6986bb5dd6bff2ae3c10b&scene=27#wechat_redirect)

**传统的利用****`return-to-plt+ROP`来绕过`ASLR + DEP`的技术需要知道库中函数的偏移地址，而在没有libc库的情况下可以使用`Return-to-dl-resolve`技术来达到动态获得库函数地址的目的，关于`dl-resolve`的技术细节请点击阅读原文了解详情。**
