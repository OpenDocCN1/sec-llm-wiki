# 特别企划 | 2017年安全公司并购案迭起，谁在押宝机器学习和人工智能？

**今年注定是大公司疯狂兼并的年份，而受到大公司青睐的小公司也大多布局在当下非常火热的领域——机器学习，人工智能，自动化技术。**

亚马逊收购圣地亚哥的创业公司—— Harvest.ai，意在增强自身的云威胁探测能力，而微软也出资 1 亿美元收购以色列的事件响应自动化公司 Hexadite。

而今年安全圈的并购案还不止于此。

## 1.CA 收购 Veracode （6.14亿美元）

![](../Images/c4b980688499ce5ba4af615a48f67352.png)

今年五月，美国 IT 公司 CA 以6.14亿美元收购 Veracode ，该公司主攻应用安全和渗透测试。

CA 在收购时表示，会将 Veracode 在产品上打造的更加有广泛性，来巩固其在 DevOps 市场上的安全能力。

维基百科对 DevOps 的解释：

> DevOps（Development和Operations的组合词）是一种重视“软件开发人员（Dev）”和“IT运维技术人员（Ops）”之间沟通合作的文化、运动或惯例。透过自动化“软件交付”和“架构变更”的流程，来使得构建、测试、发布软件能够更加地快捷、频繁和可靠。

CA 认为，Veracode 在应用测试上的经验，会将 CA 在以前 SaaS 上平台上的安全经验和 devops 技术相“结合”，这与该公司在年初收购 Automic 的情况类似。

本次收购符合常规流程，并将在2018年全部完成。

## 2\. 亚马逊 收购 harvest.ai（2000 万美元）

![](../Images/c1b9b05adacfd6115b0836ce00981e73.png)

AWS 不动声色地收购了来自圣地亚哥的 harvest.ai——前 NSA 工程师通过筹集 230 万美元建立了这家公司。

随后，根据 CNBC 上发布的声明，该公司理念与亚马逊的机器学习技术相符，可以为 AWS 创建新的 Amazon Macie 安全服务提供基础。

亚马逊表示，Macie可以增强 Microsoft Azure 的威胁检测能力，它现在已经可以保护存储在 S3 上的数据。今年晚些时候将会支持对其他数据的保护。

## 3\. 微软收购 Hexadite（1亿美元）

![](../Images/c0297c5c014752938cfac62008f72327.png)

今年6月，微软收购了以色列的网络安全公司 Hexadite。这家公司成立于2014年，利用 AI 和机器学习技术进行事件响应自动化。

微软表示，此次收购将会加强 Windows Defender 威胁防护的能力，护航 Windows 10。

微软副总裁 Terry Myerson 表示：

> Hexadite 的技术与人才将会增强我们现有的技术水平，并对微软的企业安全产品增加新的工具和服务。

根据微软安全部负责人 Bharat Shah 的说法，微软承诺将会额外再提供 10 亿美元的网络安全研究和开发经费。

## 4\. Rapid7 收购 Komand （未公开）

![](../Images/0439cbab558f1487ff30c46f8dcabce9.png)

安全业务分析公司 Rapid7 今年 7 月收购了 Komand 公司，这是一家位于马萨诸塞州的安全编排（ security orchestration ）和自动化的公司，成立于 2015 年 11 月，当时获得了 125 万美元的投资。

Komand 表示，公司旨在帮助企业自动完成重复性的任务，同时为信息共享提供交流的社区。

Rapid7 对此表示：

> 此次收购将会帮助公司研究自动化语义分析技术，并将为其安全和 IT 运营平台 Insight 助力。（包括自动化风险感知和修复，恶意软件调查和遏制，自动聊天回复）

## 5\. 思科收购 Observable Networks（未公开）

![](../Images/0bffbbfe28c6f382bebbdcac99c7a6c3.png)

思科宣布在今年 7 月收购圣路易斯的网络安全公司 Observable Networks 。

Observable Networks 成立于2014年，旨在为网络中所有用户，设备，流量提供透明化分析，同时使用机器学习技术记录异常情况，并对 AWS 和 Azure 之类的云环境提供支持。

近期，思科也推出了“intuitive network”和基于可预测行动的网络安全方案，推进云安全。

Observable Networks 将会安排到思科的安全业务部门，技术部分划入 Cisco Stealthwatch。

## 6\. Sophos 收购 Invincea （未公开）

![](../Images/f476b345c5037ccf37ea4753e892db19.png)

英国老牌安全公司 Sophos 以一亿美元的价格在今年 2 月收购了专注于终端检测和业务响应的 Invincea 公司。

位于印第安纳州的 Invincea 公司成立于 2009 年，成立以来，获得过美国军事研究机构 DARPA 的资助，同时与戴尔签署过 OEM 协议。

Sophos 表示，Invincea 的机器学习技术和无签名端点技术（signatureless endpoint technologies ）一直在第三方评测中名列前茅，其检测成功率和低误报率方面也一直表现良好。

## 7\. IBM 收购 Agile 3 Solutions （未公开）

![](../Images/3fe554d4e2207e2f0b604a070744ff9d.png)

截止到今年年底，IBM 将会完成对 Agile 3 Solutions 的收购，该公司专门开发针对公司高管使用的软件，

该公司主要开发针对企业管理者使用的数据分析软件。可以挖掘并可视化数据相关的业务风险。软件仪表盘上可以清楚显示哪些数据处于危险中，敏感数据的价值如何和哪些用户暴露在风险中。

前IBM工程师 Raghu Varadan 在2009年创立了 Agile 3 Solutions ，收购之后，其旗下的产品将会归入“IBM Data Security Services” 产品系列中。

## 是跟风还是确有实用？

”人工智能“，”机器学习“这些名词提出来的时间其实已经不短了，现在也是余温不散，从一开始的理论层次，也逐渐在一些领域落地，比如人脸识别，图像识别等等，这些都已经展示出了 AI 在某些封闭领域的巨大潜力。

无论是国内还是国外的互联网环境，也开始有很多大公司入局这些时下十分火热的领域。而在安全领域上，人工智能技术本身的攻防对抗也成为学术界的研究焦点。像微软，亚马逊这样级别、体量的大公司当然不会不知晓其中的战略意义，在做出收购决定前，想必也是做了一番调查，看到了新技术在安全领域的前景，欲扩大自己的技术积累与产品线，互联网行业花无百日红，一步跟不上，只想吃老底的话，还是很容易被更强劲的对手超越的。
