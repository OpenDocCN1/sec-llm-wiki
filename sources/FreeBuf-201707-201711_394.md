## 前言：

> 找回WiFi密码的工具很多，但是arigeddon却很少有人介绍，原理虽然和aircrack-ng类似，但是着实比它强大多了，而且跟新后功能更加强大，使用也方便，如果大家忘记了自己的WiFi密码，可以用此方法来找回原来的密码，本文只讨论技术，切勿他用，违者必究。

## 步骤演示：

### 第一步、在kali中安装airgeddon

运行环境：kali Linux 2017.1

需要设备：一个USB的外置无线网卡，有监听的功能。本人用的是8187L的无线网卡

安装：使用git命令下载项目源码

git clone https://github.com/vlslt0rlsh3r3/airgeddon.git

### （3）输入 ./airgeddon.sh 进入软件界面

![](../Images/d0f74acb7c2d7e2661ff4d470f8f586d.png)

![](../Images/fb20b6d0e66884c5c09327721d9c0f91.png)

按enter键继续下一步操作

### （4）运行查看缺少的依赖库

一般情况下，会有下图的bettercap显示是红的，表示没有安装上插件

我的安装好了所以是绿色的，显示OK

![](../Images/cce36cef9430747ef1cfeef86ca3d378.png)

接下来重新打开一个终端，输入apt-get install bettercap命令 安装缺少的bettercap插件

![](../Images/f6086254363a04a5676000fafcbfb5c0.png)

我的是已经安装好了，如果是第一次安装的话会问你是不是要安装，输入Y就可以了

注意：可能不同的电脑不一样，有些电脑可能还差别的插件没有安装，只需要

apt-get install 缺少的插件名称就可以安装好了

### （5）再次运行，进入Airgeddon的欢迎界面，并且检测的插件都是OK，按enter键进入下一步操作

![](../Images/097a95bf39ca7c12d3f8aff238b572a0.png)

第二步，开始破解之旅

### （1）插入外置的USB外置无线网卡，开启监听模式

![](../Images/74d3a5adc01fcb5bf9dec2d5f1b6d11d.png)

将网卡开启为监听模式

命令：airmon-ng start wlan0

![](../Images/d98130355fa8d725b8a34eb31e0f1632.png)

再次ifconfig看见网卡变成wlan0mon，说明成功开启了监听模式了

![](../Images/ab61a6eeee3d74e1e2a0f9abd369f8b4.png)

### （2）在回到刚刚开的airgeddon欢迎界面。Enter后会出现网卡的选择，选择外置的无线网卡wlan0mon ，下面光标输入2 回车

![](../Images/72a2ff5bd63bb774bce0f26165d64c88.png)

进入后输入5 回车，进入下一个握手包工具目录

![](../Images/3e4882eb09cb8286ba7638ba6171a16a.png)

再次输入5抓取握手包连续3个enter后进入WiFi扫描的界面

![](../Images/f6895c560a45d7243bd0bdda99f9c8b3.png)

WiFi扫描界面

![](../Images/b9fbc6807951bc0ee628135bb594f55d.png)

关闭WiFi扫描窗口，WiFi扫描的结果会在airgeddon中显示。

![](../Images/280373e6a3d4069baeb4d4b2143bdf3a.png)

选择要破解的WiFi序号31，回车

![](../Images/74f16f71c7cc2cb3dd3058818f8c24c9.png)

进入选择破解的菜单输入2回车

![](../Images/77f138e64ab85618ce5a5f3e18dad4d1.png)

进入到WiFi攻击抓包的界面，

原理：将对方的WiFi攻击断开，然后重新连接的时候抓取握手包

![](../Images/b2bda9b698b424be0e0fdfae4b23578b.png)

抓到握手包

![](../Images/8398b0f7d266e3642bc837b22c645368.png)

保存抓到的握手包

![](../Images/546f547ee2a774811c5cde05780dd6d5.png)

保存好了，输入7回到主菜单

输入6，进入破解的过程

这里有5个可用选项，一般只用前面两个就够了，
