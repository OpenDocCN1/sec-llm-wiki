## **教程开始:**

1.下载并且安装Java，已经安装了Java可以跳过

![](../Images/25dd608fdcb16a5cd9d347f4689e2a96.png)

2.如果你的计算机没有安装Microsoft .NET Framework 4.0框架，请去百度搜索下载安装，已经安装了Microsoft .NET Framework 4.0可以跳过。

![](../Images/68dd47cc6c21b01e0366b337084f1acc.png)

3.下载安装网络通给接下来的内网穿透做铺垫

![](../Images/c72dcc9f1f200fe8539f3d35ffb6b4ee.png)

下载进行安装，如果你没有网络通的帐号就去注册一个帐号，并且登录。

![](../Images/cdbbdc301cb4616596875d8c802d3d72.png)

然后打开CMD输入ipconfig,我的内网IP地址是:192.168.1.152

![](../Images/db1408e831532528b7673c247c0f3816.png)

然后点击添加映射,免费用户线路就选择美国1，名称你可以随便输入，内网IP就输入自己的内网IP地址，内网端口可以任意，但是不能冲突。

![](../Images/3720444aff1592c499befd8696a9aad1.png)

点击确定后，鼠标移到线路，右击选择复制外网地址

![](../Images/f33f4af86ba9e2f6e9910cfe6c3c78ab.png)

由上图可以得知，我的外网端口是29035

1.  打开SpyNote5.0点击Listen Port(监听端口)
    

![](../Images/090557323cbcf0f52d6b3e3e8edfce98.png)

输入2222添加监听端口-→Add,再输入29035添加上线地址的端口-→Add，再点击OK

![](../Images/4f78bb02a54f6535ea6d4d98c24826ee.png)

当如下图所示时，控制端就已经处于监听状态。

![](../Images/06c5543bc2f3eb3b3790e6868cda040f.png)

1.  点击BuildClient生成木马。
    

(1)Client Info设置木马的图标，版本号，名称：

![](../Images/89158858679918464018b6f60bc772ee.png)

(2)Dynamic DNS设置上线地址：

![](../Images/2e2279fb560b2410f657a0becc52935c.png)

(3)Properties设置对生成的木马进行一些特殊设置

![](../Images/68446cc790a761374ce9cecfaff3c100.png)

> Hide application是隐藏应用程序
> 
> Wi-fi Wakelock是锁定WIF
> 
> CPU WakelockI是常驻后台
> 
> Permission Root SuperSu是主动申请Root权限
> 
> Device Administration是请求激活设备管理器(防普通方式卸载)
> 
> Accessibility(Keylogger)是用于键盘记录
> 
> Set a Repeating Alarm是设置报警(应该是上线提示)

这里我就全选

(4)Merging App(捆绑APK)，就是和其他apk安装包进行捆绑

![](../Images/bf145c60c470d20b6eb3b14b8e07c04a.png)

因为捆绑有几率会因为被捆绑文件加固而捆绑失败，所以这里我就不捆绑。

(5)设置好一切后点击左上角的Build-→Build APK创建木马,会弹出一个这个

![](../Images/3fffbbf02a9e99d7e07e8ef3279e8553.png)

(6)我们就找到你SpyNote5.0的所在路径的根目录有个Patch的文件夹

![](../Images/6be40e63ee36911f302ed285200499eb.png)

(7)点击进入选择Patch-StaminaMode-release，然后点击打开

![](../Images/d170544153a4ca419b06f97b006c16c7.png)

(8)你点击打开之后下面就会出现一个绿色的进度条

![](../Images/73eb20b00db3d59dc59f80e196c2671c.png)

(9)生成完毕会自动打开一个文件夹里面有一个名字为client的apk文件就是你刚刚生成的木马。

![](../Images/2d299f9b0d873c1827669062c1abd812.png)

(10)现在我用我的手机(魅蓝5)安装刚刚生成木马，然后等待上线，安装打开后控制端这边就已经提示上线了，接下来就可以对这个手机进行一个远程的控制了。

![](../Images/05ae82f6879e70c84c8ecb485f957188.png)

## **主要功能:**

> File Manager：读取手机文件
> 
> SMS Manager：读取手机SMS短信
> 
> Calls Manager：读取手机通讯录
> 
> Contacts Manager：读取联系人
> 
> Location Manager：读取GPS位置
> 
> Account Manager：不详
> 
> Camera Manager：利用摄像头进行拍照
> 
> Audio Recorder：录音
> 
> Shell Terminal：不详
> 
> Applications：应用管理
> 
> Keylogger：键盘记录
> 
> Settings：设置
> 
> Phone：手机管理
> 
> Client：客户端管理
> 
> Chat：进行文本对话
