## 前言:

**这篇文章，俺会手把手教你当你遇到生僻字如何绕过QQ语音红包验证来领红包，主要思路是鄙人在这里(传送门)看到的，但是感觉他的那篇文章复述过程不是很完整，所以鄙人就给各位看官姥爷来一波小小的福利。**

## 需要工具:

QQ移动客户端的安装包，文章中的安装包的版本号为7.5.0.3430 (https://im.qq.com/mobileqq/)

![](../Images/9ab29583ac9ba989ad1ab78470775c51.png)

MT管理器2.0或者MT管理器公测版(手机应用商店都可以下载)

![](../Images/85e125b74cd9ab0719907cf92ad22ec5.png)

Android手机一台

### 1.下载QQ的安装包

![](../Images/fff2207b2efb40f1e7807fbeb5adf38a.png)

### 2.用MT管理器打开相应的下载路径，找到刚刚下载好的安装包

![](../Images/132dfd2491bf84ea087fa082a53b0475.png)

### 3.点击QQ安装包——点击查看

![](../Images/c17a15fedd4049fb0bad8326b192059c.png)

### 4.点击classes6.dex

![](../Images/e4298dc327c822f4679996c3810e9b72.png)

### 5.点击Dex编辑器

![](../Images/232dad07d510a65a476598f8d34f3c91.png)

### 6.点击右上角——搜索常量——内容输入”点击领取录制口令”——确定

![](../Images/7a34338984a656c7f933c4404824a887.png)

点击进去

![](../Images/3a2b29a1f10ac74d5fbce954e50eb75c.png)

这是进去后的样子:

![](../Images/f8b2ff5c8994044d660cb7016d9a8630.png)

### 7.点右上角——搜索常量——内容输入”点击领取录制口令”——确定

![](../Images/1b23e13dd119ea3f16da2c156dba0e67.png)  

点击进去

![](../Images/c90e62f72ab9fd5501eed8a8772dc63b.png)  

找到第108行的代码

```
if-ne v4 v6 :label_251
```

修改成

```
goto :label_251
```

goto语句也称为无条件转移语句

(![](../Images/dff56924a5ecb4322fce3eda49300ab9.png))

修改前:

![](../Images/8f906039cc1ac8ccebbfc1c4c9059746.png)  

修改后:

![](../Images/e00d017bf6a0f676ea791e8b67e48022.png)

### 8.修改好之后，点右上角选择保存

![](../Images/14f16f6e06daa158a000475315162d10.png)

![](../Images/bb01402be5a0815fb968977979e5b23f.png)

![](../Images/e6b2447981e0df01d088616072e05e94.png)

备足:MT管理器2.0是MT管理器公测版作者原来的作品，后来弃坑了，所以MT管理器2.0是免费的，而MT管理器公测版是需要激活VIP才能正常使用全部功能。

### 9.签名APK

![](../Images/b5389e26fa13c53dd906d1c596e2abe3.png)

![](../Images/d6160b80eb44c7bdcc886b9daa4ecfed.png)

再点击安装

![](../Images/e04fdc2c2f641cc62e89e3c71acd0606.png)

安装生成的APK，登陆QQ进行测试，注意一下这个修改并不是秒抢语音红包，虽然最近xp模块都不兼容秒抢语音红包，但是希望各位看官姥爷不要误解，如果各位看官姥爷你们需要秒抢红包的请自行去root手机，再卡刷XP框架，安装相应的秒抢红包查件，打勾重启即可(有几率会被腾讯封7天不能使用红包，请谨慎使用)。
