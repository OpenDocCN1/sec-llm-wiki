# Ubuntu安装Kali工具集：Katoolin

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651066708&idx=4&sn=0ece238d97eb48bca6a4a9cb6490338b&chksm=bd1f83df8a680ac9776e122ed7a42e776c295205dbfa3835303ebf2514b4f5d677bd959f4b35&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651066708&idx=4&sn=0ece238d97eb48bca6a4a9cb6490338b&chksm=bd1f83df8a680ac9776e122ed7a42e776c295205dbfa3835303ebf2514b4f5d677bd959f4b35&scene=27#wechat_redirect)

**在真实渗透环境下往往需要一个稳定、安全、可随时操作的环境，家中的电脑不能一直开着，而且还有解决公网IP的问题，这时候我们往往需要一台vps，但是市面上的vps往往并不支持安装kali系统，只有某些较贵的KVM构架vps可以不太稳定的安装kali系统，其他linux系统支持的渗透测试软体也并不全面，于是今天我为大家介绍一款可以直接在常见Ubuntu设备上安装全部kali工具集的程序katoolin。**

## 安装：

首先确保你的Python版本大于2.7

![](../Images/9544534bda4f9d651d3ae2eb4f05efec.png)

然后便开始安装

![](../Images/c469e31fcc04e8fdca213eb76fd96ba1.png)

# ![](../Images/ade1dadf97865552862732a8e3f043ff.png)

之后输入

> 1查看软件库
> 
> 2查看软件分类
> 
> 3安装经典菜单通知
> 
> 4安装kali菜单
> 
> 5帮助

我们先输入1查看软件库

# ![](../Images/a21604331056b442b7897abca330159e.png)

再输入1添加软件源完成后输入2更新源，输入back返回上级或gohome返回主页

接下来在主界面选择2 View Categories

# ![](../Images/61234ec463a280329ca29529cadb5a15.png)

输入对应数字查看软件列表并安装，或者直接输入0安装全部工具。

后面主界面的3和4用来安装菜单这里不做过多介绍。

> 另外注意 执行apt-get update前必须先在katoolin内删除软件源

这样很简单便安装了kali的全部工具集，是不是很方便呢。
