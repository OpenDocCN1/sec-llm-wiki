## 工具安装及使用

首先，使用下列命令将项目源码克隆到本地目录之中：

```
git clone https://github.com/AbedAlqaderSwedan1/ASWCrypter.git
```

切换到ASWCrypter项目目录：

```
cd ASWCrypter
```

接下来，使用下列命令运行工具的安装脚本：

```
chmod +x setup.sh or chmod 777 setup.sh
```
