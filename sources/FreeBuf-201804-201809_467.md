### **Kioptrix靶机过程**

先获取靶机IP： 192.168.1.138

**![](../Images/9ea7b968c4b3cedb14af51de826a98b5.png)**

nmap开路：

![](../Images/57709fe4d64d7ad1fd84aa1bbe7c9b85.png)

可以看到开启了多个端口，本菜本来是想以80端口做为突破口的，使用目录猜解工具走一波，为发现可利用目录

![](../Images/f8fb0d60fc88707b9dffcd182640ad7c.png)

在端口探测时也看到了有一个139端口 使用的是samba服务，然后你懂得！！

为了省事本菜就直接怼上扫描器了

![](../Images/34e0bb42bc353ec8c0f3b48780506f50.png)

![](../Images/0162ef4e3878c3e0ebec870be29132ed.png)

可以看到漏洞还是比较多的，本文以samba为突破口做进一步渗透，

我们利用samba对应的版本搜索互联网漏洞

![](../Images/7815c8dfcb6f621ab15e280f680edd40.png)

看到有一个远程代码执行的漏洞，查看该EXP

![](../Images/2ff4b6effb5db64be7b9cb93656cfe69.png)

使用命令：

```
cp /usr/share/exploitdb/exploits/multiple/remote/10.c /root/10.c
```

拷贝该EXP到本机root目录下

使用gcc编译该EXP

```
gcc 10.c -o fuck_samba
```

![](../Images/aaf8d4c138d7943bf6be432a7b5a76b2.png)

一切准备就行，直接执行该EXP拿shell。

![](../Images/cff4a58c2e63ea9e2c6d67ab7e0a4a41.png)
