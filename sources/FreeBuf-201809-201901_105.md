# 还在用工具激活系统？小心被当做矿机！

## 一、现象描述

**近日，深信服EDR安全团队捕获到一个伪装成激活软件WindowsLoader的病毒样本。经分析，该样本并没有激活功能，其主要功能是安装广告软件以及挖矿程序。**

挖矿程序会拉起系统进程并在其中注入挖矿代码，并循环监控taskmgr.exe进程，如果检测到taskmgr.exe进程则终止挖矿，使得受害者比较难以察觉。

![](../Images/c525f705b6c7828af55d538025c3fd01.png)

### 2.1 病毒母体

![](../Images/9e951b7dd775bcd47129ce76c89b3900.png)

### 2.4 activation.exe

首先在Local目录下新建cypjMERAky文件夹并将自己拷贝到下面。

![](../Images/2e32bf6d752c871a82c736e38d4852bc.png)

添加注册表自启动项。

![](../Images/21be74c2b604f138239dbeba1c937522.png)

![](../Images/3bc2e58634251bb79cd295080bdbd50e.png)

检测是否存在taskmgr.exe进程。

![](../Images/40c565b40d0c0222db614f14f9a81e37.png)

如果taskmgr.exe进程不存在则拉起系统进程wuapp.exe，参数为“ -a cryptonight -o stratum+tcp://xmr.pool.minergate.com:45560 -uminepool@gmx.com -p x -t 2”。

![](../Images/3d181dfe784b5ea3b907f7bb28cdd47c.png)

将挖矿程序注入到wuapp.exe进程。

![](../Images/7004dff3b79a6f7797aa5bc589d84112.png)

挖矿程序为开源的cpuminer-multi 1.2-dev。

![](../Images/26f2b1ea7726ad21f17c5f9d9d8089aa.png)

进入循环，守护注册表自启动项，并检测taskmgr.exe进程，如果检测到则终止wuapp.exe。

![](../Images/62882c1501b1b48d8ae447d113e6d5c0.png)

## 三、解决方案

（1）不从不明网站下载软件，不要点击来源不明的邮件以及附件；

（2）及时给电脑打补丁，修复漏洞；

（3）尽量关闭不必要的文件共享权限以及关闭不必要的端口，如：445,135,139,3389等；

（4）安装专业的终端/服务器安全防护软件，深信服EDR能够有效查杀该病毒。
