# 微软 Edge 浏览器爆高危漏洞，受控电脑可执行任意命令

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651071679&idx=2&sn=f0105fcf8e2096215c20b59b76cd618b&chksm=bd1fb6348a683f22e9f3e28ccf7bc09b8adc6957b37266c92fb1199a0a8a2be11b89ae1bcd17&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651071679&idx=2&sn=f0105fcf8e2096215c20b59b76cd618b&chksm=bd1fb6348a683f22e9f3e28ccf7bc09b8adc6957b37266c92fb1199a0a8a2be11b89ae1bcd17&scene=27#wechat_redirect)

**10月12日，有安全研究人员发布了Windows Shell REC（ CVE-2018-8495)）漏洞概念验证代码，受影响软件为Windows 10内置的Microsoft Edge，攻击者可以使用该代码通过Microsoft Edge浏览器在远程计算机上运行恶意代码。**

据了解，漏洞是由于Windows Shell处理URI时，未过滤特殊的URI，如拉起脚本的Windows Script Host的URI为wshfile，导致的RCE。

![](../Images/133047628678a1f89819eda6ea1014eb.png)

![](../Images/e8a41d5670a05e3656b4759702d70d8b.png)

当构造包含特殊URI的网页时，诱导用户打开点击，会弹出下面这个窗口，此时默认焦点位于ok按钮上，只有用户再按一次enter键，就会拉起脚本执行任意命令。

**该漏洞于10月9日曝光，级别属于“高危”。目前，微软已经发布修复补丁。**
