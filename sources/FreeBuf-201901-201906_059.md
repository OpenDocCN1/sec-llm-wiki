# ffuf：Go语言编写的高速Web Fuzzer

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651075465&idx=4&sn=3dad65e5f065cdb8d0fc74e2443f173e&chksm=bd1fa1028a6828141e6b11ccb86fa611398e441009311468a82b2b4d4f9125387e6001266f7f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651075465&idx=4&sn=3dad65e5f065cdb8d0fc74e2443f173e&chksm=bd1fa1028a6828141e6b11ccb86fa611398e441009311468a82b2b4d4f9125387e6001266f7f&scene=27#wechat_redirect)

**ffuf是一款Go语言编写的高速Web Fuzzer工具，该项目深受大型项目gobuster和wfuzz的启发。**

## 特性

一个字，快！

允许fuzz HTTP header值，POST数据和URL的不同部分，包括GET数名称和值；

支持静默模式（-s）；

模块化架构；

易于添加的过滤器和匹配器。
