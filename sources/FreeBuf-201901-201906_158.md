# 等级保护2.0研讨大会| 企业安全俱乐部「深圳站」议题征集

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651075041&idx=2&sn=4530f1ff079bbc30ca64307e7f3fa867&chksm=bd1fa36a8a682a7cc86e4779d6f05238f4c46692ada068f3389181671a5adfb64ae947c99a78&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651075041&idx=2&sn=4530f1ff079bbc30ca64307e7f3fa867&chksm=bd1fa36a8a682a7cc86e4779d6f05238f4c46692ada068f3389181671a5adfb64ae947c99a78&scene=27#wechat_redirect)

2018年12月28日，全国信息安全标准化技术委员会归口的《信息安全技术网络安全等级保护测评过程指南》等27项国家标准正式发布，为等保对象进行网络安全等级保护的落地实施进行了细化指引。

公安部网络安全保卫局处长祝国邦在网络安全论坛上透露，等级保护2.0标准即将出台，等级保护步入了一个新的阶段。

等级保护2.0的落地实施是一个涉及到多环节、体系化的工作。开展信息系统安全等级保护工作不仅是加强国家信息安全保障工作的重要内容，也是一项事关国家安全、社会稳定的政治任务。

等保进入2.0时代，将推动信息安全行业需求集中爆发，从产品端和服务端进行测算，新增市场需求超过百亿，行业迎来明显边际改善，利好全产品线的行业领先公司。等保2.0作为一个普适性的制度，范围更广、力度更大，不再只针对党政机关重要部门和央企国企等这些重点企业，所有的网络运营者都要落实，开展网络安全等级保护成为未来企业合规运营的必经之路，也是市场发展客户安全保障的刚需，更是企业品牌树立、可持续发展的重要保障。

**5月30日，「FreeBuf 企业安全俱乐部」系列沙龙活****动「等级保护2.0研讨专场****」将在深圳盛大开幕。**届时，活动现场将邀请业内知名等保机构及专家，以不同行业、不同企业特征为基础，助力企业等保落地、安全环境构建，推动我国网络安全保障体系建设。

![](../Images/b1f474664f71cf8deea6919fd7678aec.png)峰会主题

本次FreeBuf 企业安全俱乐部围绕等级保护测评、落实措施、规范管理、形势解读等方面展开讨论。等保即网络安全等级保护，指对网络和信息系统按照重要性等级分级别保护的一种工作。安全保护等级越高，安全保护能力就越强。通过开展等保工作，发现相关机构、单位和企业网络和信息系统与国家安全标准之间存在的差距，找到目前系统存在的安全隐患和不足；另一方面，通过安全整改，提高网络安全防护能力，降低系统被各种攻击的风险。等保筑起了我国网络和信息安全的重要防线。

等级保护政策极大促进了我国信息安全产业的发展。等级保护2.0是网络安全的一次重大升级，将催生国内信息安全市场将释放新的巨大需求。
