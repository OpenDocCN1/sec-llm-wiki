# 以数据为中心的安全体系建设 | 企业安全俱乐部议题前瞻

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651074868&idx=2&sn=8773a8edb04af7ecfdfb53d476c87904&chksm=bd1fa3bf8a682aa9543d47845eba666c36e3c72b917e40ff5f76e4891b4527ac44c81cab2d02&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651074868&idx=2&sn=8773a8edb04af7ecfdfb53d476c87904&chksm=bd1fa3bf8a682aa9543d47845eba666c36e3c72b917e40ff5f76e4891b4527ac44c81cab2d02&scene=27#wechat_redirect)

为解决数据隐私的保护问题，常见的方法是由用户对数据进行加密，把加密后的密文信息存储在服务端。当加密数据形成规模之后，对加密数据的检索成为一种迫切需要解决的问题。在云端数据被加密的前提下，**如何提供方便的搜索等相关服务，同时又能满足性能要求？**

近年来各国相继发布数据安全保护相关的法律法规。同时，用户的个人隐私信息安全问题也越发受到重视。作为网络运营者，企业要保护好用户个人隐私信息安全，保证合法合规，**从技术上如何确保业务方不会侵犯用户隐私****？**

网络资源访问的扁平化趋势加大了隐私泄漏与传播的风险，**怎样做好缺乏源码的二方三方库细粒度的客户端管控和审计？**随着数据分析挖掘、共享交易等新应用场景的出现，企业**围绕数据生命周期，如何构建数据的安全体系？**

2019年4月24日，即将在上海举办的「FreeBuf企业安全俱乐部」上，**来自阿里巴巴高级安全专家马建坤将为大家分享******《以数据为中心的安全体系建设》****，多维度助力企业构建完善的数据安全体系。

马建坤，曾负责阿里巴巴移动安全攻防研究，阿里巴巴vmp方案原创者。目前在钉钉负责泛端安全。
