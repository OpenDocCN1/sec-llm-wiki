# GitHacker：Git源码泄漏检测工具可恢复整个Git Repo

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651075849&idx=4&sn=ea2bac80f1fc658fff905ea7d56f2b06&chksm=bd1fa7828a682e946b8f98abea46846a02bacb8bf861ba9398bee09c68ccbf9a7abb1e7560d8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651075849&idx=4&sn=ea2bac80f1fc658fff905ea7d56f2b06&chksm=bd1fa7828a682e946b8f98abea46846a02bacb8bf861ba9398bee09c68ccbf9a7abb1e7560d8&scene=27#wechat_redirect)

**GitHacker是一个多线程工具，用于检测站点是否存在git源码泄漏，并能够将网站源代码下载到本地。值得一提的是，这个工具会将整个git repo恢复到本地，而不是像\[githack\]那样，只是简单的恢复到最新版本。如此一来，你就可以查看到开发人员的历史提交记录以及提交注释，以更好的掌握开发者的性格和心理，从而为进一步的代码审计奠定基础。**
