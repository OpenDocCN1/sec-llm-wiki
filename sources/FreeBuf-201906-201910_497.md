## 什么是Osmedeus？

![](../Images/76b00251046a19c2da9c9b1e3b6a09ad.png "1.png")

**Osmedeus允许您自动运行一系列令人敬畏的工具，以针对目标进行侦察和漏洞扫描。**

## 特点

> 子域扫描
> 
> 子域名TakeOver Scan
> 
> 目标截图
> 
> 基本侦察，如Whois，Dig信息
> 
> Web技术检测
> 
> IP发现
> 
> CORS扫描
> 
> SSL扫描
> 
> 头部扫描
> 
> 端口扫描
> 
> 易受攻击的扫描
> 
> 单独的工作空间用于存储所有扫描输出和详细信息记录
> 
> REST API
> 
> Web UI
> 
> 支持连续扫描
> 
> 通知
