# 404 Keylogger最新木马，盗取受害者浏览器网站帐号和密码

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651079803&idx=3&sn=f355f6a27be97837753a020f6a9faa1c&chksm=bd1fd6f08a685fe679217c9da23dadbbe50efa600c84302e4d22caba15c0d1dae0d0250678dd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651079803&idx=3&sn=f355f6a27be97837753a020f6a9faa1c&chksm=bd1fd6f08a685fe679217c9da23dadbbe50efa600c84302e4d22caba15c0d1dae0d0250678dd&scene=27#wechat_redirect)

**近日深信服安全团队捕获到一个最新的404 Keylogger木马变种，通过OFFICE文档嵌入恶意宏代码进行传播，盗取受害者浏览器的网站帐号和密码，深信服安全团队对此样本进行了详细分析，并获取到了黑客FTP服务器的帐号和密码，请大家提高安全意识，不要轻易打开未知的邮件附件及文档等。**

样本是一个RTF文档，里面嵌套了OLE对象，包含恶意宏代码，如下所示：

![](../Images/6b424e7f016f1aec223edc1f0a575dc9.png)

恶意宏代码，会启动PowerShell进程，从远程服务器上下载恶意程序，然后执行，相关参数，如下：

*   

```

```

分析下载的恶意程序，使用NET语言进行开发，首先会获取远程服务器地址：hxxps://paste.ee/r/RrkBF，如下所示：

![](../Images/616cc20c778f44d9f84d4110a9eb69a2.png)

读取远程服务器上的内容，如下所示：

![](../Images/33b91131a5bfa801a4c3f72c5718d828.png)

直接加载执行远程服务器上的脚本，如下所示：

![](../Images/455112de3c4afb139a6203f155e8486f.png)

解密去混淆远程服务器上的脚本之后，同样是一个NET编写的程序，如下所示：

![](../Images/f65d4bcf3b0733d1e48b180c9417c232.png)

该程序主要功能是键盘记录，盗取受害者浏览器网站上的帐号和密码，会结束受害者主机上的浏览器相关进程，如下所示：

![](../Images/ab9ab45b1cd01d331f7bb57619e7d63a.png)

对抗杀软，结束相关安全软件进程，相关的安全软件进程有一百多个，如下所示：

![](../Images/4adf06afc2404b16fe13c66fa15f29a9.png)

将记录的浏览器上网站，以及相关的帐号和密码，然后发送到黑客远程FTPd服务器，如下所示：

![](../Images/8610c6f0e27773eaea47264ed88cfea8.png)

该恶意程序还有截屏等操作，在分析该恶意程序的时候发现了黑客的FTP服务器地址，以及帐号和密码，登录进去，发现它已经盗取了部分受害者的主机信息，如下所示：

![](../Images/f8013b7772897b9d36c025fb98ffcf83.png)
