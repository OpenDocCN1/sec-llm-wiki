# 精彩大事件 | 2020上半年FreeBuf活动&报告计划新鲜出炉

在过去的2019年中，FreeBuf带给大家诸多精彩：甲方会员私享会、企业安全俱乐部、安全沙龙、FreeTalk，以及FIT大会全面升级而来的CIS 2019网络安全创新大会，各类活动的开展使我们与广大读者们有了更加紧密的联系。同时FreeBuf也联合业内多家知名厂商、信息安全相关单位发布了数篇深度研究报告，获得了众多好评与广泛关注。回望2019，我们步履坚实，2020年，我们将多维度多层次发展，探索更多可能。

  

很多小伙伴可能还在回味刚结束不久的CIS 2019网络安全创新大会，亦或为没有赶上之前的活动而扼腕叹息。不要着急，FreeBuf 2020上半年的活动&报告计划已新鲜出炉，第一时间献给热爱网络安全的你，新的一年将会更加精彩。让我们一起来看看吧~

![](../Images/928aa5e4c72658d00366ac4ae019bffc.png)

** One more thing **FreeBuf安全报告是由技术专家与分析师组成的专业团队，针对企业安全建设、威胁态势演进和安全产品调查等热门领域，聚焦企业安全体系架构、安全防护、检测、应急响应与调查取证、持续改进五大分类、44项细分类，通过科学研究方法产出的行业权威安全报告。每年6-8份具有高度前瞻性的调查报告，为众多企业及安全工作者们提供了有价值的参考材料。每一份研究报告的编写都需要来自各方面数据、案例的全面支持。在这里，我们也向广大安全厂商发出邀请，与FreeBuf 一起为行业输出数据翔实、更专业、更权威的安全研究报告。

如您所在公司有意参与上述2020上半年4份报告撰写，或有其他报告选题意向，欢迎通过本次调研向我们反馈沟通。
