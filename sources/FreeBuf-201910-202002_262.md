# uTorrent被多个杀软拦截，疑似捆绑推广行为导致

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651079435&idx=2&sn=c7546a60a5b27986c75c7c593060b5d3&chksm=bd1fd1808a68589654efb53cd7541c138f3856f5b9762e6858dfaf0c70e27f50b335edc106e4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651079435&idx=2&sn=c7546a60a5b27986c75c7c593060b5d3&chksm=bd1fd1808a68589654efb53cd7541c138f3856f5b9762e6858dfaf0c70e27f50b335edc106e4&scene=27#wechat_redirect)

**知名torrent下载客户端uTorrent近期发现遭到多个杀毒软件的封杀，包括Windows defender在内的一系列杀毒软件均将其标记为威胁，警告用户停止使用。**

![](../Images/d7f762baf4aa43827a3f494f84ae3c77.png)

![](../Images/643def2ca752b91590c08030314d8d76.png)

笔者在uTorrent官网下载最新版本的µTorrent Stable (3.5.5 build 45395)，上传到VirusTotal（一个免费的病毒、蠕虫、木马和各种恶意软件分析服务）检测，总共10项检测服务标记为威胁。其中Windows defender视其为“可能有害的应用程序”。

而uTorrent Web版本只有4项杀软服务标记为威胁。

不过默认情况下，Windows defender并不会检测或者阻止有害程序，需要手动开启“PUAProtection”功能。

### Windows 10开启/禁用PUAProtection

1.打开“Windows PowerShell（管理员）”

2.执行以下命令：

```


*   
*   

```
Set-MpPreference -PUAProtection Enabled /*开启*/Set-MpPreference -PUAProtection Disabled /*禁用*/
```


```

![](../Images/30c7bd289dbbe4218976e2795db650d3.png)

执行之后不会返回任何信息，再次运行`Get-MpPreference` ，查看“PUAProtection”一项中对应的值为“1”即表明已经开启“PUAProtection”。

![](../Images/6f41f989188c2281baf71d186ff0312c.png)

在开启该服务后，下载µTorrent应用文件均会被Windows defender拦截，警报级别为“严重”。

![](../Images/f570ad912be51af7aa10b802f173ba0b.png)

至于为何会被标记为威胁？根据反病毒厂商的说法，可能是由捆绑的广告或其他不需要的软件触发的。截止发稿之时，µTorrent官方并未对此作出回应。
