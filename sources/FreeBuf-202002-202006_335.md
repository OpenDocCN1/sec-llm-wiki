## 工具安装

### Debian安装（Debian / Ubuntu / KDE Neon）

如果你使用的是基于Debian发行版的操作系统平台，你可以使用Deb包来安装GDBFrontend。

广大用户可以使用下列命令完成工具安装：

*   
*   
*   

```
echo "deb [trusted=yes]https://oguzhaneroglu.com/deb/./" | sudo tee -a /etc/apt/sources.list > /dev/nullsudo apt updatesudo apt install gdbfrontend
```

通过apt完成安装后，我们还需要使用apt upgrade来完成新版本更新，获取更新的命令如下：

*   
*   

```
sudo apt updatesudo apt upgrade gdbfrontend
```
