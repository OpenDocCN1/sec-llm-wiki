# RSAC 2020创新沙盒冠军正式揭晓！SECURITI.ai解决隐私合规问题

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651080920&idx=1&sn=186fac79b9f2c9b3cf8d9910a197eb4f&chksm=bd1fda538a6853451ff5ed8b15da734905b780f43a40d120f3934d94b4d456e5d165eeaf66df&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651080920&idx=1&sn=186fac79b9f2c9b3cf8d9910a197eb4f&chksm=bd1fda538a6853451ff5ed8b15da734905b780f43a40d120f3934d94b4d456e5d165eeaf66df&scene=27#wechat_redirect)

**美国当地时间2月24日（北京时间2月25日），备受瞩目的全球盛会RSA 2020在旧金山正式开幕。在当天下午，这个被称为“网络安全风向标”的创新沙盒环节正式揭晓此次决赛冠军——SECURITI.ai，凭借在隐私保护与合规领域的技术创新和突破从十家初创企业中脱颖而出，拔得头筹，荣膺“RSAC 2020最具创新初创企业”。**

![](../Images/400389e6ee36dc794973b68bf81cbd99.png)

*图片来自：2020百度安全哥伦布之旅*

赛博英杰董事长谭晓生点评此次RSAC沙盒冠军，他认为：

> 对于这次Securiti.ai获奖，体现的就是“拿着金饭碗讨饭吃”，在安全行业这是非常正常的。安全产品从业者应该关注的不仅是产品的技术性，而更应该关注是否解决用户问题，真正满足用户需求。比如说合规，这就是用户的问题，GDPR给企业带来很大的压力，Securiti.ai在这个领域迈出了这一步，是比较好的。

Securiti.ai公司成立于2018年，总部位于美国加利福尼亚州的硅谷地区。Securiti.ai融资总额达到8100万美元，是十强名单中当前融资额最高的初创企业，所涉及的领域也是当前全球的热点。Securiti.ai引入了PrivacyOps的全新概念，旗下的产品套件Privacy.ai核心的三项能力包括个人数据关联报告的生成、可视化管理跨国企业的个人数据及数据泄露发生后及时通知受影响的数据主体。

Securiti.ai公司CEO Jalil 认为PrivacyOps是哲学、实践、跨功能协作、自动化和业务流程的组合，它提高了企业组织可靠且快速地遵守众多全球隐私法规的能力。目前，Securiti.ai已完成了对于欧盟GDPR、美国加州CCPA及巴西LGPD三项隐私合规法规的适配。
