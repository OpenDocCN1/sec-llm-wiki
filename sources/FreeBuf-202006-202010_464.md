# FCC再次以“国家安全”为由，试图将华为和中兴排除在外

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651087483&idx=2&sn=6707e7a3bcd01ffa16274b52d62cccc6&chksm=bd1ff0f08a6879e6e12e94e01d19ac1791acae85275e5f9573327e4d791773eefdaa1e5f91dd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651087483&idx=2&sn=6707e7a3bcd01ffa16274b52d62cccc6&chksm=bd1ff0f08a6879e6e12e94e01d19ac1791acae85275e5f9573327e4d791773eefdaa1e5f91dd&scene=27#wechat_redirect)

**![](../Images/a87827ce0962756ca613d09ec32b855f.png)**

**美国联邦通讯委员会（Federal Communications Commission）周二正式指定中国电信设备公司华为技术有限公司（Huawei Technologies Inc.）和中兴通讯（ZTE Corp.） 作为国家安全威胁，以保护美国通信网络，尤其是新兴的5G网络。**

去年，随着特朗普政府加大对华立场，美国商务部将华为列入了“实体名单”，禁止美国公司在未经美国政府特别许可的情况下将技术转让给华为，并在其他国家（包括澳大利亚，新西兰，日本）也禁止华为。

于是11月，FCC实施了一项规则，禁止将任何资金用于被视为国家安全威胁的供应商。

当时，它建议这些供应商应该包含华为和中兴。![](../Images/79295fbef57b1fa8f91ddb9945f20861.png)

接着在今年3月，美国总统唐纳德·特朗普签署了一项法律《安全和可信通信网络法案》

白宫简报发布会上说：“这项立法将禁止使用联邦资金向构成国家安全威胁的公司购买设备，从而有助于保护我们的电信基础设施。”

FCC主席Ajit Pai表示：“这项新法律批准了FCC最近通过的旨在帮助小型农村电信公司消除对制造商的依赖的制造商，现在，我希望国会将在这一成功的基础上继续前进，并迅速拨出必要的资金，偿还运营商更换任何被发现对国家安全构成威胁的网络设备或服务的费用。”

法律还制定了一项10亿美元的补偿计划，称为“安全和受信任的通信网络补偿计划”，以帮助规模较小的提供商从华为和中兴通讯中删除和更换违禁设备。

![](../Images/db63c3b0f776f2d83799b82fa78d069d.png)

周二美国联邦通信委员会主席Pai Ait Pai 在一份声明中，试图将华为与中兴正常的商业活动与国家间的网络威胁情报行为挂钩。并且强调，“我们不能也不会允许他国利用网络漏洞并损害我们的关键通信基础设施。”

这意味着，FCC每年83亿美元的通用服务基金中的资金不会用于购买华为或中兴的设备或服务。

该机构还干预了国会，行政部门，情报界，美国盟友以及其他国家通讯服务提供商的近期行动。
