工具安装（通过APT）

广大研究人员可以使用下列命令安装配置和使用paradoxiaRAT：

$ git clone https://github.com/quantumcored/paradoxiaRAT
$ cd paradoxiaRAT
$ chmod +x install.sh
$ sudo ./install.sh

sudo python3 paradoxia.py
