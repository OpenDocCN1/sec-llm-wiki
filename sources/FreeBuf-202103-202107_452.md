# 记一次渗透后运用多种方式提权实战

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651118722&idx=3&sn=ef5d82a49a474f157e94be77eda38878&chksm=bd1f4e098a68c71f240ad862621a8d208d2114114fc48e2abbb46f31e32e549fd2fb7cfa004d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651118722&idx=3&sn=ef5d82a49a474f157e94be77eda38878&chksm=bd1f4e098a68c71f240ad862621a8d208d2114114fc48e2abbb46f31e32e549fd2fb7cfa004d&scene=27#wechat_redirect)

近期在学习Linux提权，完成了vulnhub上的42challenge靶场。该靶场在web渗透阶段表现的中规中矩，但在获得shell后的提权过程中，表现很出色。提权题目设计的逻辑严谨（不会出现突然的脑洞让你卡住），注重基础知识的考察，要求的知识面也很广，涉及到密码破解、程序逆向分析、第三方应用提权、进程提权、ssh免密登录、Linux ACL访问控制权限等方面的知识，属于不可多得的精品之作，下面就开始这次靶场实战之旅。

![](../Images/af9cadc13a25fef7a8781f0b5780063d.png)

![](../Images/adffba5e53be129d4759af0017f809cb.png)发现就开放了2个端口，22端口显然不是这里突破的重点，重点应该是web端口。

## 七、进程提权

### 1、修改源文件提权

![](../Images/ea028400b82b0bbe0275d238b3cd92a1.png)

sudo因为没有密码，所以无法查看，suid没发现明显的线索，之前sudo -l和suid两种提权方式都试过了，这里应该考察其他方式了；

也没有考到计划任务提权；

![](../Images/8d2975b1c89846a0123b8bda8925bf42.png)运行下脚本pspy64试试；

![](../Images/b7505ce066c42cf4e718fbe2539ffc83.png)发现线索，uid=1003 就是pedro用户；

![](../Images/fb45eb4bf8f3497dec22b4c3fbf9cc58.png)

既然Reporting\_System\_Info.sh定期运行，于是想到如果能修改该程序的内容，那就可以获得shell。

![](../Images/0954fdf766c894083cf34cb65f3c2434.png)

图中后面的+号表示 Linux ACL访问控制权限，类似于 Windows 系统中分配权限的方式，单独指定用户并单独分配权限，这样就解决了用户身份不足的问题。

![](../Images/924452e4f4010c66f7cae9067d3be2aa.png)可以看到我们不能直接修改Reporting\_System\_Info.sh，但是根据源码，程序要运行Send\_Reporting\_Email.sh，我们可以伪造/home/maria/Send\_Reporting\_Email.sh这个文件，也同样会执行；

![](../Images/6ca9719332dcf38b2b4afb8ab97f957a.png)![](../Images/0bced10d7571ea8d2425d9078bd093a3.png)

到这里这一步提权完成，继续进行下一步；

### 2、修改python库文件提权

根据前面进程的监控发现；

![](../Images/b7505ce066c42cf4e718fbe2539ffc83.png)

![](../Images/6ef3ba3a9a66e5e5b7b6fbed39a10a07.png)![](../Images/e5ac50268240f4c767f860398f8b5d63.png)![](../Images/15b462694604817e68aac021d2fad163.png)

因为源文件不可以修改，思路是去修改源文件里调用的python库文件；

![](../Images/c8ed2bc1693514ed9e5cc41fa8d4efff.png)

找到库文件的位置，同时发现库文件是可以修改的；

写入shell，等待执行；

![](../Images/45b57c9b2f1c3bf2f9a6b7bb9e7427e0.png)反弹成功；

![](../Images/960b47fee3f14ce2f94c63f65b5d68f4.png)

到这里除了root外所有的用户都提权过一遍，加油！
