## HTTP PUT方法介绍

HTTP PUT方法最早目的用于文件管理操作，可以对网站服务器中的文件实现更改删除的更新操作，该方法往往可以导致各种文件上传漏洞，造成严重的网站攻击事件。在实际运用中，若必须启用该方法，则需要对该方法涉及的相关文件资源做好严格的访问权限控制。
