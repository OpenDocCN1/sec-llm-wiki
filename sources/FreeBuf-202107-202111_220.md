# 对Paradise勒索软件生成工具的研究分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651137545&idx=3&sn=62dee738910ee23b2e12edff8180fb55&chksm=bd1eb4828a693d94d0cb4f2d84243051440e44eea5f9e6a858e6bf3dd7cb14a4039733dda381&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651137545&idx=3&sn=62dee738910ee23b2e12edff8180fb55&chksm=bd1eb4828a693d94d0cb4f2d84243051440e44eea5f9e6a858e6bf3dd7cb14a4039733dda381&scene=27#wechat_redirect)

当今的恶意软件生成工具越来越多，新的恶意软件变种也越来越多。

2017 年，Paradise 勒索软件首次通过钓鱼邮件开始攻击，包含下载安装勒索软件的恶意 IQY 附件。勒索软件的第一个版本包含一些缺陷，安全研究人员利用该缺陷构建了免费解密工具，旧版勒索软件可以恢复文件解密。随后，攻击者更新恶意软件，通过 RSA 进行加密，这样在没有私钥的情况下就无法解密。

正如 BleepingComputer 在 2021 年夏天报道的，Paradise 勒索软件源码在 XSS.IS 黑客论坛上被泄露。

![](../Images/10a01a44680be4b1c30bfddfeb4b2051.png)

恶意软件生成工具是 .NET 写的，可以在本地和虚拟化环境中运行。

![](../Images/26f9cd1a68bf516fe73e578cfe3a91cb.png)

从泄露的源码来看，与 Microsoft VS 的默认结构类似，简单而精巧：

![](../Images/4911a585f1542d7bbb35f45f720e0085.png)

快速对代码进行分析后有一些发现。尽管生成的勒索软件会公开暴露，但为了阻碍分析人员和分析工具，攻击者仍然插入了大量的检查代码。

## 语言

源代码中可以找到开发人员写的注释，Google 认为是俄语。

![](../Images/3a6d935eccac24aea0012842c61d1de7.png)

## 用户名

Microsoft Visual Studio 提供了将源码编译为二进制文件的用户信息。信息被留存到 `.csproj`文件中，记录了编译和链接的环境设置。

![](../Images/760085c31c1502ac652e4e96a6f3f8bb.png)

## 配置

构建工具的某些配置是直接在源代码中配置的字符串，而非从外部的配置文件读取。可能是生成工具仅用于高级用户或者是攻击者内部使用而非合作方。

![](../Images/18f50bfd2fde298816eae3f8f31c036a.png)

## 名称

从字符串和配置信息的角度上看，分析人员相信该恶意软件生成工具确实是属于 Paradise 勒索软件。

![](../Images/2cdf6a7ddd18041fe506eaae212909ac.png)

![](../Images/913d8288480c33702ec8cd53b5907b80.png)

## 内存

即使使用不同的配置名称运行 Paradise 勒索软件，恶意软件也会在系统运行环境的内存中增加一个 `dp_main`。样本会查看字符串的计数项，以了解有多少进程在并行执行。

![](../Images/28f8f84215c247d7f185a82e208ed7e2.png)

## 持久化

虽然修改注册表自启动很常见，但 Paradise 勒索软件似乎会将自身复制到一个名为 DP（在 appdata 服务目录下）的特定目录中，并且看起来它总是以相同的方式命名恶意软件名称，与配置无关。

![](../Images/acd0ffe49cffc32cad65c2f0f9f4c71a.png)

## 删除卷影副本

勒索软件一般都会删除卷影副本，执行 `ProcessStartInfo psiOpt = new ProcessStartInfo(@"cmd.exe", @"/C sc delete VSS");`即可。

## C&C

攻击者向默认的 `/api/Encrypted.php`发送勒索相关信息。

![](../Images/9c59a78c5769ac868e7a3942f9bc72ab.png)

## 加密密钥

从 718 行开始，如下所示：

![](../Images/af7476a47c7f50e87d9ab7871539fd72.png)

如果失陷主机中没有密钥，Paradise 勒索软件会生成密钥并保存在本地。不幸的是，加密保存的过程做的无懈可击。

![](../Images/03378dacb625c4ddbf45a3f5c69777e9.png)

`SavePrivateKey`实际上保存的是加密的私钥和 RSA 的公钥。调用一个名为 `SavekeysToFiles`的新函数，将它们保存到一个名为 `DecryptionInfo.auth`的文件中。

![](../Images/64f0c6cc9a67b6f90e29ae019a3f7f3e.png)

Paradise 勒索软件作者仅加密大文件的前 10MB，而小文件的话会将文件切分成 117 个字节遍历处理。

## 结论

每个恶意软件的作者都会在编写源代码时保留一定的设计风格和设计模式。本次介绍了部分 Paradise 勒索软件的特征，希望对安全分析人员有所帮助。
