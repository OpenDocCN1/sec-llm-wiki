# 美国国务院遭网络攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651134400&idx=3&sn=05346fe6af99e86cd39d43a7b2c34491&chksm=bd1e8b4b8a69025dfc644f8d22af798f4a3ee178d5de0b6c6f1b9db44153cde1b310aa2ff26a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651134400&idx=3&sn=05346fe6af99e86cd39d43a7b2c34491&chksm=bd1e8b4b8a69025dfc644f8d22af798f4a3ee178d5de0b6c6f1b9db44153cde1b310aa2ff26a&scene=27#wechat_redirect)

8月21日消息，据Security Affairs报道，**美国国务院最近遭遇网络攻击**，国防部网络防御司令部正在通知受影响的个人。**目前尚不清楚攻击发生时间，但分析人士认为该事件发生在几周前。**

白宫记者杰基·海因里希（Jacqui Heinrich）告诉福克斯新闻，国务院当前的阿富汗撤侨任务未被影响。

路透社的消息人士也证实该攻击没有影响国务院的运作，国务院没有经历重大中断，也没有影响任何行动。

![](../Images/b9b82ecf8c4f11c8b2494cee94959bc3.png)“本署恪守保护信息的责任，并不断采取措施确保信息得到保护。出于安全原因考虑，我们目前不能讨论任何所谓的网络安全事件的性质或范围。”一名国务院发言人在一份陈述中表示。

上述记者指出，参议院国土安全委员会（Senate Homeland Security committee）**本月发布的一份报告将国务院的总体信息安全评级评为D**，**这可能是该模型中的最低评级**，称其在5个功能领域中的4个是无效的。

他表示，在某种程度上，可以通过国会通知的要求推断出这次攻击的范围。据联邦法律，**每个机构需要判定网络攻击或信息安全事件是否符合“重大事件”的标准，如果符合，他们必须在7天内告知国会。**
