# Gafgyt重用Mirai代码分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651130647&idx=3&sn=ceae28052fdf9a626ace480948669894&chksm=bd1e999c8a69108abf55d20adb6ddee90cdefb3a2124f2e126a9ae463f6491f2f21ae94ab81d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651130647&idx=3&sn=ceae28052fdf9a626ace480948669894&chksm=bd1e999c8a69108abf55d20adb6ddee90cdefb3a2124f2e126a9ae463f6491f2f21ae94ab81d&scene=27#wechat_redirect)

Gafgyt（又名Bashlite）是著名的恶意软件家族，主要针对物联网设备发起攻击，例如华为路由器、Realtek 路由器和华硕网络设备等。Gafgyt 还使用很多漏洞（CVE-2017-17215、CVE-2018-10561）用于载荷投递。

## 重用Mirai代码

近期，几个Gafgyt的变种重用了Mirai的一些代码模块：

> HTTP 洪水
> 
> UDP 洪水
> 
> TCP 洪水
> 
> STD 模块
> 
> Telnet 爆破

分析的样本是 4b94d1855b55fb26fc88c150217dc16a与 cd3b462b35d86fcc26e4c1f50e421add。

## HTTP 洪水

攻击者通过向攻击目标发送大量 HTTP 请求进行 DDoS 攻击。Gafgyt 使用了 Mirai 泄露的代码，下图显示了这种区别：

![](../Images/ee978144239e971e24161f7fb24ae7f2.png)

左侧是 Gafgyt 反编译的代码，右侧是 Mirai 的源码。

## UDP 洪水

攻击者通过向攻击目标发送大量 UDP 数据包进行 DDoS 攻击。Gafgyt 重用 Mirai 泄露的代码实现了 UDP 洪水的功能：

![](../Images/a4697e104837133420c3e8199006dfbb.png)

## TCP 洪水

Gafgyt 执行所有类型的 TCP 洪水攻击，如 SYN、PSH、FIN 等。在 TCP 洪水中，攻击者利用正常的 TCP 三次握手向受害者发送大量请求，导致服务器无响应。

![](../Images/c1682608991dfedff4046de2b3a4b560.png)

左侧为 Gafgyt 的 TCP 洪水模块，右侧是 Mirai 的类似代码。

## STD 模块

Gafgyt 包含将随机字符串（硬编码的字符串数组）发送到特定的 IP 地址，Mirai 也有类似的功能。

![](../Images/d83802f3b0a2353f824d687f7e2c3a31.png)

## Telnet 爆破

Gafgyt 除了洪水模块，还包含一些其他修改过的模块，例如 Telnet 爆棚模块。

![](../Images/59219914111f46f03f2c32d0d89dd6d5.png)

## 使用 CVE

Gafgyt 利用 IoT 设备的漏洞组建大规模僵尸网络，然后对特定的 IP 地址发起 DDoS 攻击。最近出现了很多 Gafgyt 的变种，例如 986633b0f67994a14e4ead3ee4ccbd73和 725097e3213efb6612176adefda3d64f。都包含了多个漏洞利用模块，像针对华为路由器（CVE-2017-17215）、Realtek 设备（CVE-2014-8361）和 GPON 路由器（CVE-2018-10561）的攻击。

![](../Images/ef7d48abb4d6b3396293cb4ae2d3df03.png)![](../Images/01319838e294d06a0afbbe32e47228de.png)![](../Images/fb5055d25597867e876746518e3281ae.png)Gafgyt 通常会使用 wget 获取载荷，再使用 chmod 赋予执行权限，最后执行该载荷。

![](../Images/9681adf92892a7f517eda56f896a7ce9.png)

恶意脚本执行逻辑：

> 使用 wget 获取载荷
> 
> 使用 chmod 赋予执行权限
> 
> 执行载荷
> 
> 删除载荷

![](../Images/963c1eac5b6a4c9646f432eff56aa1c3.png)

## 总结

恶意软件开发者不能总是开发全新的代码，研究人员发现恶意软件开发者会经常重用恶意软件泄露的源代码。
