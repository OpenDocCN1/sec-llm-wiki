# 微软即将在6月份彻底淘汰Internet Explorer浏览器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651166236&idx=3&sn=f6fcf4aefea300e4a746563f43351e4b&chksm=bd1e04978a698d814e14fc9ee8b8a18c439bf887b88a92cb9291e5ecea6fe9393d62b040087a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651166236&idx=3&sn=f6fcf4aefea300e4a746563f43351e4b&chksm=bd1e04978a698d814e14fc9ee8b8a18c439bf887b88a92cb9291e5ecea6fe9393d62b040087a&scene=27#wechat_redirect)

![](../Images/bcf14b292bffa39ad83978b2ecf529de.png)

近期，微软今天提醒Windows用户，他们将会在**今年6月份**从部分win10版本里**淘汰Internet Explorer浏览器**，取而代之的是基于Chromium的Microsoft Edge浏览器。不过淘汰Internet Explorer后，微软仍将通过内置的Internet Explorer模式（IE 模式）功能支持Microsoft Edge中基于Internet Explorer的旧网站和应用程序。

对此，微软也在公告中表示，未来Internet Explorer将会**被Microsoft Edge所替代**，对于某些版本的Windows 10，Internet Explorer 11桌面应用程序将于2022年6月15日停用。在停用后，Internet Explorer桌面应用程序将被禁用且不再受支持，并在启动时自动将用户重定向到Microsoft Edge，同时IE11的停用还是会对Internet Explorer 11桌面应用程序产生不小的影响。

如果要在Microsoft Edge中启用IE模式，用户必须转到edge://settings/defaultbrowser，打开“允许在 Internet Explorer 中重新加载网站”这一选项，然后重新启动 Web 浏览器。用户也可以通过阅读入门指南了解有关 IE 模式以及如何部署和过渡到新Microsoft Edge的详细信息 。

微软曾于2020年8月首次宣布了放弃对Windows 10和Microsoft 365中的Internet Explorer 11 网络浏览器的支持。在最初的公告之后，Microsoft于2020年11月30日停止了对Teams 的IE支持。Microsoft 还于2021年8月 17日终止了对跨 Microsoft 365 应用和服务的 Internet Explorer 的支持。

从那时起，那些仍在尝试连接到 Microsoft 365 的用户可能会面临连接失败和用户体验下降的问题。而最受欢迎的博客平台WordPress也在2021年 3月宣布计划放弃对 Internet Explorer 11 的支持，**因为该浏览器的使用率已降至1% 以下。**
