# 21万FB用户「跨越时空」共享CIS 2021春日大会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651165215&idx=1&sn=663a03f98b51599930392b4122c420d1&chksm=bd1e00948a698982080e771db16b2aa3ba853f70a09efa12b89443c42c5f0a81d8c93b6c4c6e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651165215&idx=1&sn=663a03f98b51599930392b4122c420d1&chksm=bd1e00948a698982080e771db16b2aa3ba853f70a09efa12b89443c42c5f0a81d8c93b6c4c6e&scene=27#wechat_redirect)

2022年3月9日至10日，「CIS 2021网络安全创新大会Spring·春日版」线上直播在温暖的春日中完美结束。本次大会由网络安全行业门户FreeBuf主办，主题为“刷新认知，安全生长”。

在目前关键的防疫节点，我们多方协调场地、时间、嘉宾，终于在历时两个月协商后，我们决定通过线下线上相结合的新形式为大家带来一场网络安全行业的知识盛宴。从线下录制到线上直播，我们努力以多元的方式呈现各类安全议题。

数说CIS 2021大会春日版，我们用数据呈现答案。
