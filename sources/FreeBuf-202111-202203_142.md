# 打满马赛克就安全？新技术已能够从像素化图像中还原文本信息

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651161861&idx=2&sn=0717578348566c5f09d73d2e048c3858&chksm=bd1e178e8a699e989bee0009f209784911b9f0775f9237f8c4f47579ce1b617d94db60e6cf37&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651161861&idx=2&sn=0717578348566c5f09d73d2e048c3858&chksm=bd1e178e8a699e989bee0009f209784911b9f0775f9237f8c4f47579ce1b617d94db60e6cf37&scene=27#wechat_redirect)

如今的图像处理技术，不仅能够将一张**高度像素化（也就是打了马赛克）的图像复原**，甚至能从中提取文本。

本周，安全公司Bishop Fox 的首席研究员丹·佩特洛（Dan Petro）表示，他已从像素化的文本图像中清楚地恢复了其中的字母信息。

去年，Jumpsec Labs分享了一个公开挑战，希望有人能够复原下图中的文本信息。

![](../Images/6046b1d4df23e4c9f19f6fb6d2f39058.png)

佩特洛在研究了各种像素化和去混淆技术后得出了一个解决方案，最终清晰再现了其中的文本内容，但应 Jumpsec 的要求，他只披露了其中的部分信息。

![](../Images/8a8805f58096b42e37c1b5c3668306d4.png)

虽然目前已存在一些用于增强人物或风景类像素化照片的技术，比如Google Brain，但还没有成熟的解决方案，**能够真正完全准确地恢复像素化图像中的文本**，同时消除多余的杂质像素。

![](../Images/7dd9c97aa6fcec9d0dc0bbbc3de2fdaa.png)

*△ Google Brain从提供的像素画图像中复原图像*

由于佩特洛成功破解了Jumpsec的挑战，促使他与 Bishop Fox 一起在 GitHub 上发布了一个**名为Unredacter的新开源工具**，并将他的详细研究结果公布在Bishop Fox博客文章中。下面的测试运行显示 Unredacter 从给定的像素化输入正确地复原了原始文本。

![](../Images/98a9475df6a76e3c9417eafec580effd.png)

虽然佩特洛表示，目前这些技术在实际运用场景中也没有想象中的好，还存在许多不足，但也给以像素化方式处理敏感信息这一行为敲响了警钟。他认为，使用诸如黑条直接覆盖掉敏感信息的方式要比通过像素化或者模糊化处理安全许多。

此外，研究人员也认为，在编辑文本时，**应将其作为图像来编辑**，而不是使用简单的HTML/CSS样式来掩盖。例如，使用与文本主体本身相同的背景颜色掩盖的文本，在高亮显示时可以很容易地显示出来。
