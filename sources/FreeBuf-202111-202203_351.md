# 黑客利用Log4Shell漏洞攻击比利时国防部

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651154748&idx=3&sn=77ef64a20352152d7f4fc1d7cd6b91ec&chksm=bd1efbb78a6972a177ad561c0c5ea8d4152a198f6753dcb1c68b1b583995332d96c600cf3a13&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651154748&idx=3&sn=77ef64a20352152d7f4fc1d7cd6b91ec&chksm=bd1efbb78a6972a177ad561c0c5ea8d4152a198f6753dcb1c68b1b583995332d96c600cf3a13&scene=27#wechat_redirect)

Security Affairs 网站披露，比利时国防部遭到了网络攻击，研究人员发现，威胁者似乎利用了Log4Shell漏洞。

![](../Images/e08b583c76e91c5123a84d472501804e.png)

此次网络攻击于上周四被发现，但是国防部一直到今天才披露了这一情况。随后比利时国防部发言人称，黑客利用了Log4j软件中被爆出的Log4Shell漏洞。并没有提供关于这次攻击更详细的信息。但据当地媒体报道，这一安全漏洞使国防部日常工作受阻数日。

比利时国防部长Ludivine Dedonder的发言人称：过去几天，国防部网络安全团队一直在努力工作，以确保其网络安全。为了防止未来发生类似事件，政府将继续投资于网络安全。

据悉，Log4Shell漏洞披露后，许多APT组织立即开始在其行动中利用该漏洞。
