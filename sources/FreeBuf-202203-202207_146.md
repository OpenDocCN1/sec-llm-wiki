# 新的DFSCoerce NTLM中继攻击允许攻击者控制Windows域

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651177186&idx=3&sn=3a3151c7b3a2dda63a62c51d33c14ce6&chksm=bd1e52698a69db7f12c6b7733e819b7cd118efd857e308e6c4fff54e8fd948a93cd9c34fa66e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651177186&idx=3&sn=3a3151c7b3a2dda63a62c51d33c14ce6&chksm=bd1e52698a69db7f12c6b7733e819b7cd118efd857e308e6c4fff54e8fd948a93cd9c34fa66e&scene=27#wechat_redirect)

Security Affairs 网站披露，安全专家发现了一种名为 DFSCoerce 的新型 Windows NTLM 中继攻击，**它允许攻击者控制 Windows 域。**

![](../Images/91ed53df81c1eb0899e1776b30d84acc.png)

DFSCoerce 攻击依赖分布式文件系统 (DFS)：命名空间管理协议 (MS-DFSNM) 来完全控制 Windows 域。分布式文件系统 (DFS)：命名空间管理协议为管理 DFS 配置提供了 RPC 接口。

安全研究员 Filip Dragovic 发布了一个新的 NTLM 中继攻击的概念验证脚本，该PoC基于PetitPotam 漏洞，并滥用 MS-DFSNM 协议而不是使用 MS-EFSRPC。

![](../Images/541cfccdbe5938c344381025ea4d1c59.png)

著名 CERT/CC 专家 Will Dormann 证实，**该攻击可能允许威胁攻击者从域控制器获取 Ticket Granting Ticket (TGT)。**

![](../Images/7595538f183b92acf7ad8bc84cf3b50a.png)

为了缓解该攻击，研究人员建议应遵循微软关于缓解 PetitPotam NTLM 中继攻击的建议，例如禁用域控制器上的 NTLM 并启用身份验证扩展保护 (EPA) 和签名功能，以及关闭 AD CS 服务器上的 HTTP。
