# Cloud Atlas 利用俄乌冲突话题进行攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651169083&idx=2&sn=a985dcaf5b50f0674f4431e23fb901c1&chksm=bd1e33b08a69baa652ef3d703b2f879e84499ae331e657ab54e3a82596d1d4385d40b85aeaa4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651169083&idx=2&sn=a985dcaf5b50f0674f4431e23fb901c1&chksm=bd1e33b08a69baa652ef3d703b2f879e84499ae331e657ab54e3a82596d1d4385d40b85aeaa4&scene=27#wechat_redirect)

几个星期以来，全世界的目光都集中在俄乌冲突上。西方国家对俄罗斯的银行和企业进行了多轮制裁，也在国际媒体上引起了热议。这也为攻击者提供了机会，利用相关话题进行针对性攻击。

近日，**研究人员发现冒充美国证券交易委员会（SEC）发送相关话题的恶意文档，研究认为是 Cloud Atlas 发起的攻击行动。**

该文档的内容大体是要求从俄罗斯客户处获取信息的要求：

![](../Images/79f83c2f733595a6a94f039d6493bcbc.png)

## *△**诱饵文档*

初期的时候，恶意文档的检出率非常低。

![](../Images/2eb62eec6b301d2a4132ea6a3ddfbfd7.png)

## *△**VirusTotal 检测结果*

接着深入分析 Payload 与相关攻击技术：

![](../Images/09a9c15d3ffd0e70deb48aa7da136aa2.png)

## *△**反汇编代码*

通常情况下，恶意文档都是一个 Dropper。在文档中，可以发现一个指向压缩文档的 URL 地址。

`hxxps://cvg[.]org/wp-content/uploads/2020/document.zip`

该压缩文件的检出率最初也很低：

![](../Images/55fff8f410379dcaaffb27563e3e2322.png)

## *△**VirusTotal 检测结果*

下载得到文件后，将程序安装进系统的（`%LOCALAPPDATA%\EdgeTools\edgecef.dll`）路径中，其中包括一些合法文件与恶意库文件（main）。

![](../Images/19aaa725eb1f995ae5737a0f04f07984.png)

## *△**包内信息*

之后，恶意样本就会向 C&C 服务器发起连接，将失陷主机的相关信息发送过去，并等待后续的命令。

研究人员认为该攻击是由 Cloud Atlas 发起的，该组织自 2014 年被发现时已经活跃了多年，经常使用恶意样本攻击大使馆、航空业组织等政府单位。
