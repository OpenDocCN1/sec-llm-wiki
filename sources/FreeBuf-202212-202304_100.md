# 针对 Web 服务器的 Golang 僵尸网络 GoBruteforcer

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651220037&idx=3&sn=bf72b97533d2aa06a6e7a4e514ab450d&chksm=e59f36ec1d59f77642a44907d375d48252edae7b4bd8f270498345c5c9d074aa59eb7cc7bc3d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651220037&idx=3&sn=bf72b97533d2aa06a6e7a4e514ab450d&chksm=e59f36ec1d59f77642a44907d375d48252edae7b4bd8f270498345c5c9d074aa59eb7cc7bc3d&scene=27#wechat_redirect)

研究人员近日发现了一个 Golang 开发恶意软件，并将其命名为 GoBruteforcer。该恶意软件主要针对 Web 服务，特别是 phpMyAdmin、MySQL、FTP 和 Postgres 服务。

  

## 

## **简介**

  

Golang 现在越来越来受到攻击者的欢迎，被用于开发个各种各样的恶意软件，包括勒索软件、窃密木马与远控木马等。

  

GoBruteforcer 就是一种用 Golang 编写的新型僵尸网络，主要针对 Web 服务，特别是 phpMyAdmin、MySQL、FTP 和 Postgres 服务。

  

GoBruteforcer 会扫描整个 CIDR 块，而不是单个的 IP 地址。发现主机存活后，GoBruteforcer 会通过暴力破解尝试入侵服务器。一旦获取访问权限，GoBruteforcer 就会立刻部署 IRC Bot。并且，留下 PHP WebShell 作为失陷主机的后门。

  

![](../Images/b8ed5fa37fc092f4185c2cc9eabe0091.png)GoBruteforcer 攻击链

  

服务器的 /.x/ 目录下的 cache\_init 文件，就是被发现植入的 GoBruteforcer 恶意软件。

  

![](../Images/0f6b87724c2d895ed594cd573e45b2da.png)失陷主机上的恶意软件

  

GoBruteforcer 恶意软件主要针对类 Unix 平台，支持 x86、x64 与 ARM 架构。

  

## 

## **扫描与系统访问**

  

GoBruteforcer 恶意软件样本使用 UPX 加壳，并且针对 CIDR 块内的主机进行扫描。

  

![](../Images/9cf8b9265a22ded36f4a6ef0fb9e234b.png)CIDR 块扫描

  

对目的 IP 地址来说，恶意软件对其进行扫描 phpMyAdmin、MySQL、FTP 和 Postgres 服务，每种服务都定义了单独的扫描模块。

  

![](../Images/c96e559e7924e1e660b836739247a1b0.png)

扫描不同服务的模块

  

在不同的扫描模块间，会共用端口扫描模块。

  

![](../Images/58cd765a0c4ff19037efd75e44d7f613.png)端口扫描功能

## **phpMyAdmin 服务**

## 

  

扫描 phpMyAdmin 服务时，GoBruteforcer 会尝试通过暴力破解入侵服务器。GoBruteforcer 内部携带了各种硬编码的凭据，如下所示：

  

![](../Images/0c04517fcb5f0103165f2bfd0d8114ad.png)硬编码凭据列表

###   

### **IRC Bot**

  

通过 phpMyAdmin 服务成功进入失陷主机后，GoBruteforcer 会进一步部署 IRC Bot。文件 fb5 与 ab5 分别是 x86\_64 和 ARM 架构的 IRC Bot，如下所示：

  

![](../Images/53b159d4f5d075a2e38a29955bce7ccb.png)x86 平台的 IRC Bot

  

![](../Images/5666f5b0a97688ffb8d1073923067794.png)ARM 平台的 IRC Bot

  

GoBruteforcer 恶意软件通过 IRC Bot 启用 C&C 通信，如下所示：

  

![](../Images/f45b6f40d77e03b73ce9986cf70204d6.png)IRC 的 C&C 通信

  

IRC Bot 也会设置定时任务进行持久化，如下所示：

![](../Images/7cf2dbb244596191e909e26717c27c66.png)

定时任务持久化

## **MySQL 与 Postgres 服务**

## 

  

扫描 MySQL 与 Postgres 服务时，GoBruteforcer 检查 3306 端口与 5432 端口是否打开。确认服务开放后，尝试使用各种凭据进行登录，如下所示：

  

![](../Images/93a582e0803a86396810daa2cbd73dc0.png)Mysql 登录尝试

  

![](../Images/b959416f3d2783e4d3e0bbe0d2d9109c.png)Postgres 登录尝试

## 

## **FTP 服务**

## 

  

确认 FTP 的 21 端口打开后，GoBruteforcer 会尝试使用 goftp 库进行连接尝试，如下所示：

  

![](../Images/4b6bfeb906eb3c905f713b8caff6414f.png)FTP 登录尝试

##   

## 

## **PostResult 模块与 WebShell**

## 

  

扫描完成后会调用 GoBruteforcer 的 PostResult 模块，其中包含一个硬编码链接如下所示：

  

![](../Images/c85930df817bb8f34d14d43813b3051d.png)硬编码链接地址

  

进一步分析该 IP 地址的目录，其中发现了名为 x 的 WebShell。该 WebShell 与名为 pst.php 的 PHP 文件相似。这个 WebShell 实际上具备 Reverse Shell 与 Bind Shell 的功能，如下所示：

  

![](../Images/4e36402a0d988af857d08406e389c36d.png)WebShell 功能

  

除此之外，WebShell 还提供了一个数据包生成工具。能够根据攻击者的控制生成定制化的数据包，例如主机、端口、超时时间等。攻击者可以利用这个工具，来深入地了解目标网络。

  

![](../Images/a0bd2299769131d239e862395fb2e7d6.png)数据包生成工具

## 

## **旧版本 GoBruteforcer**

## 

  

在研究人员分析 GoBruteforcer 攻击活动的时候，发现了旧版的 GoBruteforcer 样本文件。该版本的 GoBruteforcer 只针对 phpMyAdmin 服务进行攻击，且 VirusTotal 上为零检出。

  

![](../Images/8275c40f8861f87039b9cb05a6ae1d90.png)VirusTotal 检测结果

  

## **结论**

  

Web 服务器一直都是攻击者攻击的重点目标，如果存在弱口令会存在严重的安全隐患。GoBruteforcer 仍然在积极的开发升级中，不久的将来应该能够看到其他攻击 Web 服务的攻击技术。
