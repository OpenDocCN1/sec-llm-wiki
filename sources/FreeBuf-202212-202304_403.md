# Python 供应链攻击层出不穷，研究人员又发现一例

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651211935&idx=3&sn=9be436e9944ce42e4d21b37f774bf582&chksm=bd1dda148a6a53020cf27de250040ebd43be3adc0842af80ca71f63cd36f4b25306f4cb82448&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651211935&idx=3&sn=9be436e9944ce42e4d21b37f774bf582&chksm=bd1dda148a6a53020cf27de250040ebd43be3adc0842af80ca71f63cd36f4b25306f4cb82448&scene=27#wechat_redirect)

2022 年 12 月 9 日，研究人员在 PyPI 中发现又一个供应链攻击。2022 年 12 月 6 日名为 aioconsol 的 Python 包发布，同一天发布了三个版本。与此前披露的名为 shaderz 的 Python 包类似，并没有相关的描述信息。  
![](../Images/22817ad473278df62d76f81cbf751cfd.png)*【项目描述】*  
![](../Images/ff0b09b8a046449c39b23c327712bbda.png)*【版本发布】*  
该 Python 包的 2.0 版在 setup.py 脚本中包含恶意代码，将二进制内容写入名为 test.exe 的文件，这作为安装过程中的一部分。  
![](../Images/991be1b0da755330366959550ec4acea.png)*【2.0 版的 setup.py】*  
在 0.0 版本与 1.0 版本中，`__init__.py`脚本也有类似的恶意代码，如下所示：  
![](../Images/59d8046d8935e09ca1372ca1d8597efb.png)*【1.0 版恶意代码】*  
![](../Images/8425a0311eddf9d9fc3c5627bdb32c3d.png)*【0.0 版恶意代码】*  
VirusTotal 中部分引擎将该 EXE 可执行文件标记为恶意：  
![](../Images/81387555f9b3a828b830ae9623ef5b88.png)*【VirusTotal 检测信息】*

## **具体行为**

## 执行该 EXE 可执行文件，创建名为 stub.exe 的子进程。  

  
![](../Images/7b1d81016c9042c0cac9800d49a2e05f.png)*【进程运行】*  
程序在 `%USER%\AppData\Local\Temp\onefile_%PID_%TIME%`处释放多个文件：  
![](../Images/d7855b39e195e9186644cee08e7d2763.png)*【释放文件】*  
释放的可执行文件 stub.exe 被少数引擎检出：  
![](../Images/9b370bb79d26f7aae5da55460bca8457.png)*【VirusTotal 检测信息】*  
执行 test.exe 后，会将自身复制到 `%USER%\AppData\Local\WindowsControl`名为 Control.exe 以及释放 run.bat 的批处理文件。  
![](../Images/faed139842d4b5ef422cac8a5ec4d9ef.png)*【创建文件】*  
run.bat 脚本显示文件 Control.exe 的路径，确保在启动时运行。  
![](../Images/b9f821d29970e64f3e64a276744ba574.png)*【run.bat】*

##   

## **结论**

## 研究人员在不到一周的时间内两次发现针对 Python 的供应链攻击，这说明攻击者对这种攻击方式非常青睐。用户也需要高度警惕不明来源安装的 Python 包，其中很可能包含恶意软件。
