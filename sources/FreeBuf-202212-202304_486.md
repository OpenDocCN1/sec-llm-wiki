# CCSIP2022中国网络安全行业全景册（第五版）调研启动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjA0NjgyMA==&mid=2651206716&idx=1&sn=924df7a0fb38f9dc71e258e503da9388&chksm=bd1da6b78a6a2fa1b31e963bd01a0ce9fc6c8eb2fd96f633198cf2aef4c4b6abb35f8a560824&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651206716&idx=1&sn=924df7a0fb38f9dc71e258e503da9388&chksm=bd1da6b78a6a2fa1b31e963bd01a0ce9fc6c8eb2fd96f633198cf2aef4c4b6abb35f8a560824&scene=27#wechat_redirect)

即日起，FreeBuf咨询将正式启动 《CCSIP（China Cyber Security Industry Panorama）中国网络安全行业全景册（第五版）》调研工作。本次调研面向广大国内安全厂商，由厂商自主申报并填写信息征集表。经FreeBuf咨询团队审核后，厂商信息将入驻至《CCSIP 2022中国网络安全产业全景册（第五版）》，为企业安全建设及产品选型提供参考。

  

![](../Images/aa9d28cbd2a49f16574188d2cd792b66.png)

  

此前FreeBuf咨询累计发布《CCSIP中国网络安全行业全景图》四个版本，受到了行业的广泛关注与一致认可。为了更好地为企业提供网络安全产品选型参考，帮助企业了解中国网络安全技术与市场的发展趋势，FreeBuf咨询计划启动《CCSIP2022中国网络安全行业全景册（第五版）》，并在前四版全景图的研究基础上作出如下主要调整：

  

1.此次图谱将以全景册形式呈现，以保证清晰、直观、易检索的阅读体验。

  

2.为了更好地追踪各安全厂商最新的产品能力，适应各安全厂商服务范围的调整与变更，本次全景册收录的厂商将仅以本次申报为准。  

  

3.本次全景册将分别在21个一级类目下对1-2个星选厂商进行展开介绍，力求更好地帮助企业了解厂商动向，强化产品认知，从而为企业大类产品选型提供进一步参考。

  

与此同时，《CCSIP2022中国网络安全行业全景册（第五版）》 仍将以PDR网络安全模型为基础，并参考IPDRR安全框架和P2DR2模型，在基础的Protection(防护)、Detection（检测）、Response（响应）三层逻辑上优化出第4层，即“持续改进”，形成“防护——检测——响应——持续改进”的安全闭环。在核心模型之外，另增加了网络基础安全与业务场景2个大类，构建完整的企业网络安全建设链，以此作为CCSIP全景册的顶层设计逻辑。

  

在细分目录下，FreeBuf咨询团队将在原有的94个细分领域的基础上，新增5个细分领域，分别为：软件成分分析SCA、模糊测试、应用加固、API安全以及威胁狩猎，力求将市面上主流的网络安全厂商以主要产品类型为依据进行归类。

**研究方法**

**问卷调查：**通过问卷调查的形式获取企业的安全产品以及相应的自评信息，作为基础参考信息。  

**权威参考：**参考国内外网络安全领域的各类奖项、Gartner魔力象限以及专业机构发布的权威报告等，积累国内安全厂商和安全产品补充信息的数据库。

  

**专家分析：**由FreeBuf咨询顾问、市场分析师、安全智库专家组成专业的评审团队，对安全厂商进行归类与评审。
