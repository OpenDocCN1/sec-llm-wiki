1、  配置Kali系统IP为固定IP

首先点击虚拟机 编辑此虚拟机设置，将网络适配器模式由NAT模式改变为桥接模式

![](../Images/6219b91bd79d7b55eaf212b927ee30b2.png)

![](../Images/c568a34b2beaba8efcd346838ab04449.png)

开启虚拟机

先查看本机宿主机的ip

![](../Images/4582b78b0682cecca90fb9b0a0e8a52a.png)

  

我本机ipv4地址是192.168.0.103

默认网关是192.168.0.1

所以我们现在在kali打开终端

保持虚拟机和物理机在同一个网段

输入ifconfig eth0 192.168.0.105/24（因为我物理机ip的子网掩码位数是24）

     route add default gw 192.168.0.1

     \# echo nameserver 8.8.8.8 > /etc/resolv.conf 配置DNS地址

发现网络不可达

![](../Images/f07dc54e8fa29882685dded31914cf4f.png)

  

解决方法：打开网卡配置文件 root@S1xin:/\# vim /etc/network/interfaces

  

  

第 8 行下面加入下面两行代码 auto eth0      iface eth0 inet dhcp

![](../Images/6c4a1943022df062227e1c7e6e9691a8.png)

  

进入末行模式 wq保存并退出

重启后 重新配置

![](../Images/f5543f4678874e72685542e2f9d2bde9.png)

  

  

发现网络配置完成

现在进行永久ip配置

终端输入此命令vim /etc/network/interfaces

加入

iface eth0 inet static

 address 192.168.0.103

 netmask 255.255.255.0

gateway 192.168.0.1

用#将iface eth0 inet dhco注释掉

![](../Images/e1e4c21a2557a265907ead321c5af0d9.png)

2.配置DNS

输入vim /etc/resolv.conf

 在文档最后插入 DNS 地址

 Generated by NetworkManager

nameserver 8.8.8.8

![](../Images/5d6fa5ac4c264d1042d7065b1d39642a.png)

输入 systemctl restart networking #重启网络服务

前面发现我加入的ip错误 是192.168.0.105不是103所以重新加入下然后再重启网络服务![](../Images/79ec630b229b8997c244f14644352789.png)

  

Ifconfig查看下

![](../Images/cf5ff19bc0e1ecc510926f5df7bef73f.png)

  

已经配置完成

到这里固定ip和dns服务器就配置好了
