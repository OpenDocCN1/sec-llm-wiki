Kali安装中文输入法，火狐浏览器设置中文

Kali2019，安装好后，输入法是美式键盘，是没有中文输入法的，但身为龙的传人 我们怎么能不用中文输入法呢？浏览器怎么能全是英文呢。

在使用 Kali 进行一些搜索时没有中文输入法会变得非 常非常麻烦，但是我们在 Kali 中却并没有默认的中文输入法，我们在 windows 下普遍使用的输入法是 搜狗拼音输入法，但是在 Kali 中安装搜狗拼音输入法很麻烦。不管使用什么输入法，只要能输入中文即 可，下面给大家讲下如何在 Kali 中安装 ibus 中文输入法，ibus 安装简单，进行简单的配置即可使用

所以我们来给自己的kali安装ibus输入法和给火狐浏览器设置中文

PS：安装 ibus 输入法前，Kali 要配置好国内源，否则是没有办法安装的。

首先打开kali

![](../Images/44a754664300399ca1045cb6a63829c3.png)

输入apt-get install ibus ibus-pinyin

![](../Images/30fa90db99361f8ed73845fd16285971.png)

期间出现输入y/n  输入y

![](../Images/8a1ad62332af6ac9cb9a398588f055c4.png)

安装已经完成 重启kali机器

![](../Images/caf66f16fac5c90c637fca1cc635127a.png)

     设置系统语言，将汉语加入到输入源

![](../Images/9e66833b77313a6cdd1b081231a9b8f0.png)

![](../Images/9d54b368b9583c0b5e1dc0bfd0d1892e.png)

![](../Images/4b745fcce4a10187fb91ae925b7a6d99.png)

选择中文pinyin 添加

![](../Images/0baa33ebc1f7b280d0a864c77fa0c97d.png)

     打开终端 按win+空格键切换成中文拼音，然后输入

安装成功

![](../Images/80124eb58b0eb9e8d1cbfa17b904c4f5.png)

Ps：切换输入法按win+空格键  可随时切换

至此中文输入法安装完成

然后我们来将浏览器设置成中文

打开火狐浏览器

![](../Images/2f10962c4f8a251778cc1a5d933ef62e.png)

发现都是英文，这这，作为英语文盲，看着是真的头疼，英语好的同学们可以选择不换，哈哈哈

打开设置

![](../Images/c64c90df85bfe0f6fd1e1158175b24fd.png)

在设置里发现无法直接设置中文

所以 我们就要安装一个浏览器中文了

输入apt -y install firefox-esr-l10n-zh-cn

![](../Images/aace8db8421a84dafdc3012030221d76.png)

等待安装完成 发现安装完成

![](../Images/c36c6ba0659d43e8028339017a612b62.png)

  

这个时候我们再来打开浏览器设置

选择添加中文 为首选项

![](../Images/4bbd73d3abeb1d20b197de013f50f7d3.png)

     再重启火狐浏览器，发现已经设置好成中文了

![](../Images/869469c4844703a427b2c2568f4774be.png)

至此kali2019的浏览器中文设置完成
