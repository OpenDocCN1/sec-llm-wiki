1.kali系统的安装

首先选择图形化安装


选择中文简体

设置主机名


设置root密码


选择使用整个磁盘并配置lvm


选择推荐新手使用

选择是



后面都选择是，然后等待安装系统

这里选择用不使用网络镜像，等去kali里面再装国内镜像。也可以选择是{后面去配置国内源}。

选择是

选择/dev/sda

等待结束重启


       输入用户名密码登陆系统


至此Kali2019.1安装好

2安装vmtools实现物理机和Kali之间自由复制和拖拽文件

VMware Tools 的安装

 因为安装的时候没有使用镜像，所以现在没有镜像源，先安装下 VMware Tools，方便和物理机器互通并且进行一些源的设置和其他设置

首先点击虚拟机安装vmtools

打开vmtools文件


将这个tar压缩包选择复制到

点击主目录 选择提取到此处


将vmtools解压到此目录

点进去文件，然后选择在终端打开









执行 ./vmware-install.pl -d 加 -d 参数可一直选择默认，最后重启

随便在物理机复制一段文字


发现已经可以粘贴了，文件也可以和物理机随意互通 至此

Kali下的vmtools 已经安装完成


3配置 apt 国内源

打开终端，输入vim /etc/apt/sources.list进入镜像源配置，可以直接复制粘贴中科大的源插入最后一行


进入末行模式按wq 保存并退出

使用 apt 新的软件包源获取最新的软件包列表




使用 apt 新的软件包源获取最新的软件包列表

apt-update

发现我们之前加入中科大的源已经加载出来了

至此国内源安装完成



4做快照

点击虚拟机 快照 选择拍摄快照

  

可以看到可以恢复到拍摄的快照


至此快照拍摄完成

5正常获取更新列表和进行系统更新

此版本在获取更新列表和系统更新上面有问题


     终端输入apt install -y libgcc-8-dev mutter gcc-8-base libmpx2 mitmproxy安装编译环境


中途出现需要按键是 按y选择回车就行

     经过漫长等待


发现已经安装好了

重启下虚拟机 root@S1xin:~#reboot 再执行软件安装或系统升级就不会报错了。重启后，显示如下桌面

     这个壁纸看着很不爽，让我们换一个小小的壁纸



至此系统更新完成

现在我们来获取更新列表

先输入 apt update

再输入apt upgrade



安装内核头 linux-header 和编译工具 gcc、输入apt-get install gcc make linux-headers-$(uname -r)

期间出现 输入的 一直按y回车


安装完成后重启即可

至此 kali2019的系统更新完成
