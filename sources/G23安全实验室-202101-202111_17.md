2安装vmtools实现物理机和Kali之间自由复制和拖拽文件

VMware Tools 的安装

 因为安装的时候没有使用镜像，所以现在没有镜像源，先安装下 VMware Tools，方便和物理机器互通并且进行一些源的设置和其他设置

首先点击虚拟机安装vmtools

![](../Images/fa3ef5953564a06edb1981ae4809c83b.png)

打开vmtools文件

![](../Images/caedb47a9455695cc487fc365efacddd.png)

  

将这个tar压缩包选择复制到

![](../Images/3e5652114dc9cc85ccc13c4b77a67e1d.png)

点击主目录 选择提取到此处

![](../Images/a1bffe0476483bfd9054421c12294063.png)

  

将vmtools解压到此目录

![](../Images/5299a3195d78b3d0209c36e2ad6e8f98.png)

点进去文件，然后选择在终端打开

![](../Images/10f27f3ef6e1c9d3224b0da1f6722ab1.png)

5正常获取更新列表和进行系统更新

此版本在获取更新列表和系统更新上面有问题

  

     终端输入apt install -y libgcc-8-dev mutter gcc-8-base libmpx2 mitmproxy安装编译环境

  

![](../Images/21b0f30ce5c5a179fc03df4884287914.png)

中途出现需要按键是 按y选择回车就行

     经过漫长等待
