# 【硬件】反窃听检测——俄罗斯进口便携式非线性节点探测器Lornet24

Lornet-24是一种独特的、紧凑的、重量轻的非线性节点探测器，它以其紧凑的尺寸、优秀的人体工程学设计和轻盈的重量而闻名。由于其拥有1公分多点厚度的天线，它可以用于狭窄空间的检测。  
  

  

  

Lornet-24与其他非线探测器相比具有很强的竞争力。它可以使用连续探测和脉冲探测模式，具有可变的功率输出。自动频率选择允许在复杂的电磁环境中工作。它的输出功率对操作者的健康无害。在某些情况下，使得它在某些情况下比标准频率的探测器更有效率，但输出功率更大。

![](../Images/b40d325fd61ab04932327956610ff045.png)

  

  

  
  

LORNET-24设计用于检测各种含有半导体元件(二极管、晶体管、电路)的电子设备，如窃听窃拍设备、射频窃听器、录音设备、遥控设备、简易爆炸装置等。无论其开机或关机状态。

  
  
![](../Images/f7a2cfb5f64d5c915b1eddf344e05a5f.png)

  

Lornet-24探测器重量轻，符合人体工程学，它提供了声音和LED灯告警方式，使操作者可以在隐蔽的环境中进行搜索，它的便携性得到全球诸多用户的青睐。

![](../Images/85d5fa45177893130d0459e79d0638c1.png)

  
Lornet24探测器的工作原理是基于半导体元件的性质，半导体元件在被超高频探测信号探测时会产生相应的二次和三次谐波。人工合成的半导体元件具有较高的二次谐波信号，而天然合成的半导体元件(如金属、金属氧化物)具有较高的三次谐波信号。探测器分析产生二次和三次谐波的被检物体，从而识别其是否存在电子设备，或者金属氧化物的器材。

![](../Images/b40d325fd61ab04932327956610ff045.png)

  

Lornet-24探测器能够分析被捡物体反射信号的响应时间，并自动找到最佳的接收频率通道，无噪声和失真。即使在复杂的电磁环境中，在LN24探测器中实现的频率调谐算法自动选择正确的探测信号，解调信号的数字处理可以获得最大的灵敏度。这使得能够结合广泛的检测范围和可靠的识别发现的设备。

![](../Images/84cd435794c77f4e75a5feead7ef42e5.png)

  
输出功率自动控制方式大大简化了操作人员的操作。设备的LED指示灯同时显示二次和三次谐波信号强度。此外还可以通过内置扬声器或者耳机通过声音来判断二次和三次谐波的信号强度。

![](../Images/855ef443b1909f67552f979433331fa1.png)

技术规格：

1.探测信号：脉冲、不间断连续；

2.脉冲信号功率：10/0.3 w

3.灵敏度不低于 -108dbм (在相对于/噪声比 = 10时)

4.信号频段范围：2406—2414MHZ

5.内置电池最大工作时间(脉冲/连续)：不小于 4h /1.8 h

6.尺寸：39х10х4cm

7.重量：700g
