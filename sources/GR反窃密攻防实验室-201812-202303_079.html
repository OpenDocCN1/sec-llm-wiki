【硬件】反窃密检测设备—美国REI ANDRE便携式近场信号分析探测仪

ANDRE近场信号分析检测仪是一款用于检测周边环境射频传输的宽带信号数字接收器。检测频段覆盖10kHz至6GHz，能够通过屏幕直观的查看各种信号源，如无线电信号辐射源、红外线辐射源、可视光辐射源、电流载波辐射源等非法辐射源，可以有效帮助操作员发现窃听设备。ANDRE是OSCOR频谱分析仪的有效补充，操作员可在使用OSCOR频谱仪进行详细监测前使用ANDRE进行快速初步检测。


产品应用：

  • 能够对周围环境复杂的电场信号进行识别和检查，包括：Wi-Fi、蓝牙、手机信号、红外传输设备、漏磁信号设备、高频发射器以及各种非法辐射源等；

  • 可实现高性能的无线电信号接收以满足单位或个人的多种合法用途，比如：无线电爱好者、无线电教育机构、无线电设备生产企业。

  • 可检测和测量声音泄漏或超声波机械振动，比如：可以对墙壁进行声学泄露检测；

  • 可用于监控正在进行的会议，探测是否有遥控操纵设备；

  • 检测与排查干扰信号。



功能特色：

  • 直方图显示：ANDRE具有显示RF级别的信号强度直方图，用户选择的时间间隔范围为5秒至12小时。

  • 可观察数字、模拟和突发信号之间的差异，并使用音频和触觉反馈设置警报阈值；

  • 信号信息和频段详细信息：ANDRE频率计数器自动从最强信号中产生信号列表。信号频率以最强的信号开始列出，可以被指定为威胁，友好或未知信号。双击信号可获取更多的细节，包括频带分类信息；

  • 音频模式：ANDRE可以解调和播放实时模拟音频，可以记录、存储和播放十秒音频文件。实时音频屏幕显示接收信号强度的条形图；

  • 可查看时间表截图，播放解调音频，并在电脑上查看捕获的信号列表；

  •  轻便型： 轻巧便携，具有USB数据端口用于文件传输；

  • 易操作性：3.5英寸触摸屏，设置和操作均简单易用；

  • 附加探针自动探测，并显示合适的频段；

  • 探测频率范围从10KHz至6 GHz。


技术规格：

射频探测器：

  • 灵敏度：-75 dBm；

  • 步进衰减/增益控制：20dBm；- 10dBm；

音频：

  • 音频类型：可调节音量的内置麦克风；

  • 音调类型选择：“提高音量”、“稳定音调”、“关闭”3个选项；

显示屏：

  • 屏幕类型：3.5英寸电容触摸屏；

  • 屏幕亮度：高、中、低三档；

输入/输出：

  • USB 端口用于软件更新以及文件传输；

电源：

  • 供电方式：USB充电器；

  • 运行时间：一般每节电池可用5小时以上；

  • 充电时间：每节电池（充电80%）1.5小时，（充电95%）3.5小时；

  • 电池类型：Nitecore 18650可充电锂离子电池，型号# nl189，3.7V，3400mAh，12.6Wh；

  • ANDRE基础版标配2节电池；

  • ANDRE高级版配备4节电池及1个USB充电器；

运行环境：

  • 工作温度：-10℃~50℃

  • 电池充电温度：0℃~35℃

  • 储存温度：-20℃~50℃

注意：超过储存温度（＞40℃）会降低电池性能、缩短电池寿命。

物理规格：

  • 包装箱尺寸：15.9 x 37.8 x 47.0 cm；

  • 主机尺寸：8.7 x 14.4 x 2.5 cm；

  • 主机重量：0.3千克（带电池）；

  • basic版总重量：4.1千克；

  • advance版系统总重量：5.0千克；
