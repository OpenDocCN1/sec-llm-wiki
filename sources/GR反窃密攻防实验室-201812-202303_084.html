便携式非线性节点探测器 


非线性节点探测器一般用于环境物理安全检查，对所需的场合进行检测时，可以探测墙体、地板、门板以及绿植等本身不应存在电子器材的物体是否异常。当设备探测发现窃密器材时不管器材是否开机，都能通过显示、振动和声音等多种方式进行告警，让探测人员可以快速聚焦掩藏的目标。


非线性节点探测器ST-402功能简述

注：以下为厂商英文资料转机翻中文，与实际功能有出入之处，请按英文说明书为准。

应用领域：

非线性节点探测器专为寻找和探测隐藏在墙壁、地板、天花板、家具、固定装置或者隐藏于容器内的电子设备而设计。不论目标电子产品是射频的、有线的或是关闭状态的，都可以使用该产品探测发现。该产品广泛应用于寻找电子窃听产品，探测手机和SIM卡，检查包裹或者邮件中是否携带禁运物品或者危险的半导体产品。

操作模式：

NLJD ST 402 Cayman 具有以下操作模式：

主要操作模式：搜索（SEARCH）

辅助操作模式：音频（AUDIO）

服务模式：自适应（ADAPT）

名为搜索的主要操作模式用于检测非线性目标并根据16段条形指示的响应级别识别它们。

名为音频的辅助操作模式允许通过内置扬声器或耳机解调响应并收听响应。 在搜索模式下检测到响应时使用此模式。

适应服务模式用于优化特定电磁环境中的参数，从而最大限度保证搜索的有效性。 每次打开设备时都需要使用此模式。 建议在搜索过程中不时暂停，以重复此过程。 在调整过程中，天线必须远离电子设备和大型金属物体。

自适应模式

要激活此模式，请按住主机控制手柄上的■按钮（图7中的2），持续3-4秒。 天线必须远离大型金属物体以及任何被认为包含非线性元件的物体（通常最好将天线指向地板或天花板）。

适应需要10-15秒，所有指示灯同时在天线模块上点亮。但TUNING（调整）指示灯将自下向上依次点亮。同时，用户可以检查是否有任何LED指示灯损坏。自适应后，将根据表格1显示设备状态。与测试棒进行操作检查，ST 402 Cayman适应环境，就应该借助模拟非线性材料的测试棒检查其功能（图1中的1）。

为此，选择一个没有非线性元素或反射表面响应的区域，并在那里放置标记为红色的测试棒。

反复按下按钮（图7中的3），将接收器增益设置为TUNING（调整）指示灯的3个亮区，对应于中等灵敏度。

将天线指向测试棒并找到INPUT（输入）LEVEL（电平）Gauge bar（指示条）1的所有16个指示灯亮起的距离。对于处于正常工作状态且自适应调整的设备，此距离应不小于0.8 m。

使用带有蓝色标记的测试棒重复此过程。 在此过程中，找到INPUT LEVEL测量条2的所有16个指示灯被点亮的距离。 对于已经适应环境的正常工作设备，该距离应不小于0.3米。

如果发现任一距离小于上述各自的值，建议重新进行自适应步骤（见2.2）并重复上述检查。

如果两个距离都超过了所需的最小值，则该设备可以正常运行并准备就绪。

 

搜索模式

 

一旦ST 402Cayman准备好并证明其功能如上文2.1 - 2.3所述，它就可以投入使用。 激活后，设备将以SEARCH（搜索）模式启动，接收器增益默认设置为最大值，由TUNING指示灯的5个亮区显示。

SEARCH（搜索）模式是ST402的主要操作模式。操作员可以自行决定改变接收器增益，从而增加或减少检测范围。

增益可以随意调整，增量为8dB，在40dB范围内分为5个值; 每个增量对应于TUNING指示器的一个LED灯。 因此，如果所有五个LED灯都点亮，增益等于40dB，提供最大检测范围。 如果全部变暗，则增益为0dB，检测范围最小。 只需按一下TUNING按钮▲和▼（图7中的1和3），就可以增加或减少增益。

来自目标区域的返回信号电平显示在三个多段LED灯指示条中（图4中的1-3）。

INPUT LEVEL LED指示条1：（16个红色LED）显示半导体材料的返回信号电平。 该指示伴随着交替的声音警报。

INPUT LEVEL LED指示条2：（16个蓝色LED）显示MOM（金属/氧化物/金属）结构的返回信号电平。

INPUT LEVEL LED指示条3：（16个白色LED）显示反射表面（最可能是金属）的返回信号电平。

某种类型的响应越大，相应的输入电平指示条中LED灯就会点亮。

建议

使用NLJD通常会探测

l 封闭结构（墙壁，天花板，地板）内部的不同部分

l 各种不应含有半导体材料的物体

l 已知包含半导体元件（电子仪器，办公和家用电器，通信设备等）的物品通过其他方式进行检查。

在封闭结构上运行检查时，设置合适的接收器增益非常重要。 如果过多，则可能导致检测到墙后面的物体，这在无法进入相邻空间时可能是一个问题。 另一方面，如果增益太小，那么在封闭严实的结构中，具有弱响应的目标可能仍然未被发现。

在扫描墙壁和其他大型垂直结构时，建议以蛇形方式从顶部到底部移动天线，如图9所示。天线头应保持距离表面5-15厘米的距离。如果探测到了有效响应（多段LED仪表板中的所有LED灯都亮起），则应降低增益以确定响应目标的确切位置。

NLJD的主要任务是发现窃听设备，其提供的信号是由含半导体的电子元件和MOM结构在外壳、结点处等返回的信号。因此，应特别注意仅在红色LED指示条上观察到响应的扫描区域，以及在红色和蓝色多段LED指示条上都观察到响应的区域。应确定每次此类响应的性质并确定其来源。

如果同时有多个LED指示条响应，一个特别强烈，伴随着另一个相对弱的多的不规则响应，那么前者是真实的回应而后者只是假象; 建议降低增益或远离目标。

应在三个INPUT LEVEL LED指示条中没有任何响应的位置检查小尺寸物体，最好远离大型金属物体，支柱，机柜，保险箱等。

 

音频模式

AUDIO模式主要用于通过收听解调信号输出来分析目标响应。 这应该为操作员提供足够的信息来识别响应类型。

要从SEARCH（搜索）切换到AUDIO（音频）请按（图7中的2）。 然后天线头上的SEARCH（图4中的5）LED灯将关闭，AUDIO（图4中的6）LED灯将亮起。
