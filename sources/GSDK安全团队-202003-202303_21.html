01
项目介绍


该项目是网上找的“渗透攻击红队”出的内网渗透靶场项目，包含最新的漏洞：log4j2、CVE-2021-42287、CVE-2021-42278。本次实验模拟从外网打点到内网横向渗透最终拿到域控的过程，最大程度上还原真实的红队攻击。本次实验的拓扑图如下：




实验主机的基本配置


网上很多公众号上都没有介绍实验前主机的基本配置，之前也玩的别的内网渗透的靶场时候在网络配置上花了很多时间，昨天突然间找到了一个简单的方法，这里也分享一下：我们下载解压结束后，在虚拟机中打开即可，开机后使用配套给的密码即可打开实验所需的主机。


每一台主机都打开后，根据所给的网络地址段，直接编辑虚拟机的“虚拟网络编辑器”，修改本机的地址段即可


如：这里我们直接修改本机的“仅主机模式”为10.0.0.0/8网段。配置完成后，在同一个网段的主机互相ping通，即可开始实验。

内网横向


发现存在两个网段，猜测10网段是内网网段


注意：在实战的内网渗透中：如果是在 linux 环境下的内网渗透尽量形成全部 bash 和 python 化，因为Linux 都完全自带，而在 windows 下的内网渗透则尽量全部形成 powershell，bat、vbs 化，尽量不要过于依赖外部工具。


这里我们用bash来探测内网存活主机

for i in 10.0.1.{1..254}; do if ping -c 3 -w 3 $i &>/dev/null; then echo $i Find the target; fi; done


发现还有1台10.0.1.6的主机

为了方便后续操作，后面我们通过frp将流量带出来

在Kali上编辑frps.ini
