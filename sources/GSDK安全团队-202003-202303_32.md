# Drupal XSS漏洞（CVE-2019-6341）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzNTE0Mzc0OA==&mid=2247483965&idx=5&sn=f0c71f480d681a023e6af918ec5f3b3a&chksm=e8ead516df9d5c000b91dea877a1db680c7299596bb839a9c107038b5ebc0b9a45402ab8a9f7&scene=126&sessionid=1681443739#rd](http://mp.weixin.qq.com/s?__biz=MzIzNTE0Mzc0OA==&mid=2247483965&idx=5&sn=f0c71f480d681a023e6af918ec5f3b3a&chksm=e8ead516df9d5c000b91dea877a1db680c7299596bb839a9c107038b5ebc0b9a45402ab8a9f7&scene=126&sessionid=1681443739#rd)

**影响软件：**Drupal

**方式：**通过文件模块或者子系统上传恶意文件触发XSS漏洞

**参考链接**：Drupal 1-click to RCE 分析

**效果：**JS代码执行（Cookies 资料窃取、会话劫持、钓鱼欺骗、网页挂马等）

**漏洞复现：**

1、首先先来到http://ip:8080进行安装数据库等信息，全部选择默认安装即可。其中因为没有mysql环境，所以安装的时候可以选择sqlite数据库。

![](../Images/26cbf2400fbb6f0e7933e16659f8fb7e.png)

  

2、下载payload，

PoC参考：https://github.com/thezdi/PoC/tree/master/Drupal的PoC

![](../Images/0d4b1cd2a8938a0ba2ef1bde40eec2f7.png)  

![](../Images/043a201d07ff637799f378a0b72f07f3.png)

  

3、上传poc

该漏洞需要利用drupal文件模块上传文件的漏洞，伪造一个图片文件，上传，文件的内容实际是一段HTML代码，内嵌JS，这样其他用户在访问这个链接时，就可能触发XSS漏洞。

 

Drupal 的图片默认存储位置为/sites/default/files/pictures//，默认存储名称为其原来的名称，所以之后在利用漏洞时，可以知道上传后的图片的具体位置。

![](../Images/3cc18356bdb43002226760ced81c1f29.png)

  

4、上传成功后，访问IP:8080/sites/default/files/pictures/YYYY-MM ,后面的YYYY-MM 改成当前年月，如：  

http://192.168.10.151:8080/sites/default/files/pictures/2022-04/\_0  

（注意：GoogleChrome 和 FireFox 浏览器自带部分过滤 XSS 功能，所以验证漏洞是否成功时可使用 Edge 浏览器或者 IE 浏览器。）
