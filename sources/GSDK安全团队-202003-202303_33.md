# Grafana 8.x 插件模块文件路径遍历 (CVE-2021-43798)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzNTE0Mzc0OA==&mid=2247483965&idx=6&sn=f7d3c5750062c5b62608807dc7a7e6c3&chksm=e8ead516df9d5c008f154862ec8a54aa9f1ae6918b820e9c0e86c1d0d46b62cbb25f7f8dd322&scene=126&sessionid=1681443739#rd](http://mp.weixin.qq.com/s?__biz=MzIzNTE0Mzc0OA==&mid=2247483965&idx=6&sn=f7d3c5750062c5b62608807dc7a7e6c3&chksm=e8ead516df9d5c008f154862ec8a54aa9f1ae6918b820e9c0e86c1d0d46b62cbb25f7f8dd322&scene=126&sessionid=1681443739#rd)

**漏洞说明：**

Grafana 是一个多平台开源分析和交互式可视化 Web 应用程序。

2021 年 12 月，一位Twitter 用户披露了一个 0day 漏洞，未经身份验证的攻击者可以利用该漏洞通过 Grafana 8.x 的工艺 url 来加强 web 路径并下载任意文件。

 

**漏洞复现：**

先启动环境

![](../Images/d62d4511e1228b56eff84790576b22b3.png)

  

服务器启动后，可以浏览登录页面http://your-ip:3000，无此漏洞的凭证。

![](../Images/942100f5035b47760879a20db426298e.png)
