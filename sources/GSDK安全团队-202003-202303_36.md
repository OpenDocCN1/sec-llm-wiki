# ElasticSearch 目录穿越漏洞（CVE-2015-3337）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzNTE0Mzc0OA==&mid=2247483950&idx=1&sn=f1df9c7035bcf706f8a0e979703b4ca0&chksm=e8ead505df9d5c13ba7ce812a7e8fa33f70e0ed3f90c877096ebe86f6b1c6289888d162d4f3e&scene=126&sessionid=1681443739#rd](http://mp.weixin.qq.com/s?__biz=MzIzNTE0Mzc0OA==&mid=2247483950&idx=1&sn=f1df9c7035bcf706f8a0e979703b4ca0&chksm=e8ead505df9d5c13ba7ce812a7e8fa33f70e0ed3f90c877096ebe86f6b1c6289888d162d4f3e&scene=126&sessionid=1681443739#rd)

  

jre版本：openjdk:8-jre

elasticsearch版本：v1.4.4

影响版本：1.4.5以下/1.5.2以下

 

**漏洞原理：**

在安装了具有“site”功能的插件以后，插件目录使用../即可向上跳转，导致目录穿越漏洞，可读取任意文件。没有安装任意插件的elasticsearch不受影响。
