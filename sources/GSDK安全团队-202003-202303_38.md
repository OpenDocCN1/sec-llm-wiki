# YApi开放注册导致RCE

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzNTE0Mzc0OA==&mid=2247483950&idx=3&sn=a5f2665d3ca7649f0c9390a89ce72ea8&chksm=e8ead505df9d5c13a7663c3ef3932481157285ced71b8302a0fa7208b9ee4f17ea9d1dab2aba&scene=126&sessionid=1681443739#rd](http://mp.weixin.qq.com/s?__biz=MzIzNTE0Mzc0OA==&mid=2247483950&idx=3&sn=a5f2665d3ca7649f0c9390a89ce72ea8&chksm=e8ead505df9d5c13a7663c3ef3932481157285ced71b8302a0fa7208b9ee4f17ea9d1dab2aba&scene=126&sessionid=1681443739#rd)

**漏洞原理：**

YApi是一个API管理工具。如果注册功能开放，攻击者可以使用Mock功能执行任意代码。

 

**漏洞复现：**

启动一个YApi 1.9.2：

![](../Images/6f1e985fc3df2d98fffaa2b7f4530ecf.png)

  

环境启动后，访问http://your-ip:3000即可查看到YApi首页。

![](../Images/f4f110a2c476b89614a4053d40124e8e.png)

  

在首页下方找到登录/注册功能接口，或直接访问/login 路径进行登录和注册。

![](../Images/e402726d3d2bd8790929b65920928414.png)

  

登录之后进入个人空间，在右侧点击添加项目；

![](../Images/ac6a91786e76568f842db3e057b47456.png)

  

添加成功后进入项目，点击右侧同一位置有个“添加接口”

![](../Images/59af48975752cfdae857be5dac534c4a.png)

![](../Images/3e9211a7603169aca06f4ff7bdfda516.png)

  

添加完之后，打开接口，进入“高级Mock”功能，点击脚本，输入Poc，点击保存即可。

![](../Images/5ca4a17d1eeb4c2a634b5d3e4e0be7eb.png)

  

保存后回到预览tab页后，点击下面的Mock地址进行访问即可看到”whoami && ps -ef”这个命令成功执行，试想如果把这个命令换成恶意脚本下载的命令会如何呢？

![](../Images/3e195e838551ce15375dacce144b4594.png)
