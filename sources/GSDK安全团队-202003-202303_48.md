# Apache HTTPD 换行解析漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzNTE0Mzc0OA==&mid=2247483831&idx=3&sn=dc2e5c8d3a0b1b7a9abcd39ff8d01156&chksm=e8ead69cdf9d5f8a040dbe3e64c4e9617239ed4c7caed8768c149c6143fe74deecbdcfdfe490&scene=126&sessionid=1681443739#rd](http://mp.weixin.qq.com/s?__biz=MzIzNTE0Mzc0OA==&mid=2247483831&idx=3&sn=dc2e5c8d3a0b1b7a9abcd39ff8d01156&chksm=e8ead69cdf9d5f8a040dbe3e64c4e9617239ed4c7caed8768c149c6143fe74deecbdcfdfe490&scene=126&sessionid=1681443739#rd)

漏洞原理：

Apache HTTPD是一款HTTP服务器，它可以通过mod\_php来运行PHP网页。其2.4.0~2.4.29版本中存在一个解析漏洞，在解析PHP时，1.php\\x0A将被按照PHP后缀进行解析，导致绕过一些服务器的安全策略。
