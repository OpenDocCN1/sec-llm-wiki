2.换源技巧和安装应用的技巧：

这里作者使用的是kalilinux，所以这里我就用Kali Linux来进行换源操作了。

 

对于换源这里我被坑了好久，因为在这个控制台下换源复制很麻烦，之后我发现我们可以直接进入一个安装linux的文件夹下直接在windows平台用notepad++来进行更改，既方便，又灵活！

 

大概路径为：

C:\Users\Administrator\AppData\Local\Packages\KaliLinux.xxxxxxxxx(这个是随机的所以就用xxx来表示)\LocalState\rootfs\etc\apt\sources.list

 

这里作者用的源是中科大和163混合的：

deb http://mirrors.163.com/debian wheezy main non-free contrib

deb http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib

deb-src http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib

 

设置好源后我们进入bash

然后分别输入

sudo su 输入密码（默认：root）

apt-get update  更新源

一阵等待后即可使用。

 

3.对于渗透工具的安装

这里笔者推荐的是katoolin这个工具很方便是属于python（P.S. 使用之前请先预装python，和git（Kali里面不自带） 这里方式很多我就不多赘述了）

 

安装执行代码：

sudo su

git clone https://github.com/LionSec/katoolin.git && cp katoolin/katoolin.py /usr/bin/katoolin

chmod +x /usr/bin/katoolin #给予权限

sudo katoolin #打开katoolin

5.可视化中文问题：

在可视化操作界面中，我们可能会发现很多问题，比如中文乱码，这个问题很严重，这一步也必须做。

 

确定locales已经安装，用”apt-get install locales”命令；之后可用”locale -a”查看当前系统支持的字符集。
1. 在命令行输入”dpkg-reconfigure locales”。进入图形化界面之后，（空格是选中，Tab是切换，选中en_US.UTF-8和zh_CN.UTF-8，确定后，将en_US.UTF-8选为默认。 

 

 

和

2. 安装中文字体，”apt-get install xfonts-intl-chinese “和” apt-get install ttf-wqy-microhei”，这时发现网页不乱码，系统也不乱码。
3. 重启 。
