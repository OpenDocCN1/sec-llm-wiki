近来罗永浩称为「次世代即时通讯工具」的子弹短信掀起一阵巨浪。子弹短信横空出世，一度攀居 App Store 免费总榜第一名。同时，“子弹”也炸翻了创投圈，上线短短 7 天，子弹短信融资 1.5 亿，堪称史上最快完成的融资事件。

 

但是知乎有大神指出：子弹短信是基于网易云信 SDK demo 魔改但套壳聊天 UI ，还晒出了 Android  端 App 包名。本文的主要内容是讲解如何如何对 APK 进行反向编译。

**0 准备**

需要使用到谷歌提供的三个工具：apktool  、dex2jar、jd-gui。下载地址分别是：

\- apktool 下载地址：https://bitbucket.org/iBotPeaches/apktool/downloads

  

![](../Images/807a424f5d1dcd0ac48bde269bdd5f25.png)

\- dex2jar下载地址：http://sourceforge.net/projects/dex2jar/files/  

  

![](../Images/2554cd28a3f70b9107afef80905fe018.png)

\- jd-gui下载地址：http://jd.benow.ca/  

  

![](../Images/4f8359602bae44dbec527f6e2de4ca9b.png)

**1 工具介绍**  

\- apktool  作用：获取 apk 中所有资源文件

\- dex2jar 作用：将apk反编译成java源码（classes.dex转化成jar文件）

\- jd-gui 作用：查看APK中classes.dex转化成出的jar文件，即源码文件

 

**2 反编译过程**

1) 准备 APK 文件

这里我们拿子弹短信作为例子进行讲解。我们需要到锤子应用商店下载 子弹短信 的 APK 文件。

 

2) 获取应用程序的资源

一个 APK 安装包其实是个压缩包。其里面带有源代码、图片资源、配置文件 AndroidManifest..xml 等文件。我们首先需要使用到 apktool 工具。将下载的 apktool 工具包进行解压，解压后会得到3个文件：aapt.exe，apktool.bat，apktool.jar 。

 

![](../Images/024c261d1ced3c50dc6aa6d04bdb2316.png)

在 CMD 窗口中，执行命令 apktool.bat   d  -f    \[apk文件 \]   即可获取到资源文件。  

 

![](../Images/c95a0a528c0cb7d1ad97287b9fa4412e.png)

当 apktool 执行完任务之后，会发现目录下多了一个文件夹。  

 

![](../Images/fe588f0b4ce9323f184ae62c8fe14741.png)

文件夹里面能看到一个图片资源和配置文件 AndroidManifest..xml  

 

![](../Images/5f8d613ec97d7815d1dcedbf12eeb8dc.png)

3) 获取 jar 代码  

将需要反编译的 apk 后缀名改为 .rar，然后解压得到其中的 classes.dex 文件。这个 dex 文件是 Java 文件经过编译，然后通过dx工具打包而成。将 dex2jar 压缩包进行解压，再将子弹短信的 三个 dex 文件复制到文件夹中。可能 子弹短信使用到类太多，将 dex 进行分页处理。如果是只有一个 dex 文件，使用命令dex2jar class.dex  即可获取到 jar 文件。但是因为有多个 dex，那么需要同时将所有的 dex 文件进行转化。

 

![](../Images/2f155662a7091c027de79ad817c09cb9.png)

经过转化之后，我们可以看到有 两个 jar 文件  

 

 

![](../Images/ef0ff9cd51b0c8e204156ab107d96859.png)

4) 使用 jd-gui.exe 阅读 Java 代码  

双击打开 jd-gui.exe ，然后将 classes2\_dex2jar.jar 拖入到窗口中。

 

![](../Images/ef53611ccbf5305c2ba649114c28d264.png)

从代码的包名中，我们可以看到子弹短信确实使用到网易云信。  

 

到这里，教程就结束了。
