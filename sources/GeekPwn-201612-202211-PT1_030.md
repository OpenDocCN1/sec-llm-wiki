# 多年没打开的IE浏览器正式说再见，才发现它曾“输送”了上千CVE

你好多年没打开过的 IE 浏览器要彻底说再见了。

  

当地时间6月15日，微软正式停止对 Internet Explorer (IE) 的支持，这个诞生于1995年8月的浏览器，成为了历史洪流中的一朵浪花，也掀起了一波回忆杀。毕竟，几乎所有千禧年之前的网友，人生第一次网上冲浪，都是从 IE 浏览器开始的。

  

![](../Images/a1b83316ded33b90b46a19b29acab950.png)

  

严格意义上来说，IE 浏览器并非是互联网发展史上的第一代浏览器。能算得上第一代浏览器的是 Nexus，只是当时无法显示图片。随后又发展出了 Cello、NCSA Mosaic 、Netscape Navigator （网景浏览器）等，功能也从无法显示图片到能显示图片再到多平台兼容。1993年前后，网景浏览器一度占据了约90%的浏览器市场份额。

  

![](../Images/f0cca325afd3e659fda66655de89e830.png)

  

1995年，微软为了抢占市场，把 IE 整合到 Windows 95 操作系统中，让 IE 成为了每台电脑的默认浏览器。这样的捆绑策略让 IE 逐渐风靡全球，到 2002 年占据了 95% 的市场份额，成为当之无愧的浏览器一霸。

  

![](../Images/b7c68ad39fe176a8f061e37cb97e0aae.png)

![](../Images/ecce59470504a3ff07bdaf896b66dc43.png)

  
与浏览器一起如火如荼发展的是互联网和漏洞、病毒。2000年前后，病毒、DDoS、木马等开始肆虐，而刚有能力跑起来的互联网显然还没来得及考虑自身的安全问题。2001年发布的 IE 6 爆火之后，微软并没有趁胜追击，直到2006 年才发布IE 7。而这五年间，由于本身功能中就存在隐患，又是当时覆盖面最广的浏览器，IE 浏览器首当其冲，被各种病毒和恶意软件盯上。  
![](../Images/b57fa519e7b6a7b30b8001e29e6e4381.png)![](../Images/5c2a3a15f3d00471a64c6bd193c72356.png)  
远程代码执行、堆栈溢出等各种不同类型的漏洞频出，导致网页重定向、网页崩溃、静默安装木马、强制下载恶意程序以及用户隐私（如密码、历史记录、收藏夹等）泄露、虚假网页诱导、诈骗等，让很多用户怨声载道。据 CVE Details 网站记载，1999年以来，有CVE编号的 IE 相关漏洞共有 1168 个，而那些没上报的或者由微软内部发现的漏洞，数量可能更多。连微软的安全专家都吐槽，提醒用户不要把 IE 设为默认浏览器。  
![](../Images/7e39523414274176fb0e2353f8cf4bce.png)![](../Images/a68d39a9ee9ed5fd3c283df47ea1c913.png)  
浏览器可能会经历生死，但漏洞从不会缺席。Bug满满的IE已成为过去，IE风头正盛时的网页挂码、流氓软件等安全问题也随之而去，但如今的浏览器依旧面临着安全问题。2020年，IE 9、10和11还爆出了远程代码执行漏洞，利用漏洞能获得与当前用户相同的权限。而尽管Chrome及其他浏览器推出了沙盒机制以及其他防护措施来确保浏览器的安全性和稳定性，但2021年，浏览器的零日漏洞依旧创下纪录：Chrome 被曝出 14 个零日漏洞；Safari 的WebKit 被曝出 7个零日漏洞；尚在苟延残喘的 IE 也被曝出 4 个零日漏洞。比起零散的攻击，针对特定高价值群体的长期可持续性攻击（APT攻击）成为了当下浏览器漏洞利用的主要方向。  
![](../Images/281982fb50d0485b78fc86a492faaf47.png)  
考虑到一些报名系统、网银系统、政务网站等“年久失修”的网站仍旧默认使用 IE 浏览器，微软在如今主推的 Edge 中提供了兼容性工具，并承诺兼容支持**至少持续到2029年**。所以仅支持IE的网站依旧可以用旧有的 IE 模式加载，并利用这段时间完成迁移和更新。不过这个过程中，安全依旧是需要考虑的大问题。不知届时微软是否还会提供安全支持，也不知这些网站将如何追上时代的脚步。  
![](../Images/42a1aa3d220a3573886c69f4db15de86.png)  
互联网发展至今，IE 浏览器不是第一个退役的应用，但似乎是最触动一代人的一个。历史的车轮滚滚向前，当初网景浏览器的创始人之一——“浏览器之父”Marc Andreessen(马克·安德森) 已投身 Web3.0 和区块链技术，并认为这可能会重演上世纪90年代初的互联网崛起的景况。而如今区块链技术的相关安全问题，也已经凸显并逐渐引起关注。也许互联网是一场轮回，有网络就会有关于安全的攻防，不论有何变化，我们一直身在局中。 ![](../Images/d6af3e16658b0b21b3feeb30b72e08d7.png)
