会窃密的文档：SVCReady恶意软件利用钓鱼邮件和Word文档属性进行传播

原文：http://mp.weixin.qq.com/s?__biz=MzA3Nzc2MjIxOA==&mid=2650344733&idx=1&sn=27af9b9b4cf27247438a224ea580af85&chksm=8740b6d8b0373fceecea7d8e2005657160608d6c2fd99b99cfbe94a5d4761e2cce9699dfade6&scene=126&sessionid=1681310143#rd
钓鱼攻击常有，但新花样不常有。近日，惠普的安全研究员发布了一份报道，详细分析了4月底开始部署、5月份多次更新、6月初开始活跃并借助钓鱼邮件和word文档属性传播的新恶意软件SVCReady。
在攻击链中，隐藏了 shellcode 的Word 文档（.doc）作为附件添加到钓鱼邮件中。与许多其他恶意软件活动一样，这些文档包含用于执行恶意代码的 Visual Basic for Applications (VBA) AutoOpen 宏。但与其他 Office 恶意软件不同，该文档不使用 PowerShell 或 MSHTA 从远程服务器检索下一阶段的可执行文件，而是直接由VBA宏运行存储在文档属性中的 shellcode ，运行后会删除 SVCReady ，达到隐蔽的效果。


如图所示，shellcode存储在Word文档的属性中，由宏提取并执行。通过将宏从恶意 shellcode中分离出来，可以尝试绕过常见安全软件的检测。

具体的感染过程如下：
根据32位或64位系统架构的不同，shellcode 会加载到不同的变量中，在最终执行前存储在tino内存中，并使用 Windows API 的“虚拟保护”功能来获取可执行访问权限。而 SetTimer API 则会传递 shellcode 的地址并开始执行，让动态链接库（DLL）和重命名的rundll32.exe文件（主要为了逃避检测）加载到 %TEMP%目录。当这些文件运行时，SVCReady就会启动。


SVCReady 可以收集被感染系统上的数据，并且每五分钟与C2服务器进行通信。收集的数据包括用户名、计算机名称、时区和注册表详细信息（如计算机制造商、BIOS 和固件）等系统信息，以及正在运行的进程和已安装软件的信息。

SVCReady其他功能还包括：
  • 将文件下载到受感染的客户端
  • 截屏
  • 运行 shell 命令
  • 检查它是否在虚拟机中运行
  • 检查 USB 状态，即插入的设备数量
  • 通过计划任务长期潜伏
  • 运行文件
  • 在内存中使用 RunPeNative 运行文件


研究人员发现，与 C2 服务器的通信是通过 HTTP 进行的，但数据本身是使用 RC4 密码加密的。不过，他们在 2022 年 4 月末分析的第一个恶意软件样本中并未发现 RC4 加密。这表明SVCReady背后的开发者在5月还在积极改进软件。经过分析恶意样本中的文件，发现有图像与另一个名为TA551（又名 Hive0106 或Shathak）的组织使用的图像相似。也许TA551 和 SVCReady 背后的开发者使用了类似的模板和工具。

目前整个SVCReady恶意软件的利用还处于初期阶段，这份报告可以为后续的研究与防御提供参考。
