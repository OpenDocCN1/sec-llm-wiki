你最近在读什么？


作为一名安全研究员，平时要读的也许不仅仅是书，还有网页、代码、协议甚至说明书……

你为什么读书？

在字斟句酌或者语句转换之间，去找寻本质与原理；去挖掘隐藏在迷雾中的真相与真理；去揪出难以察觉的不合理……

第二十七个世界读书日来临之际，GeekPwn 安全实验室推荐了一份书单，供信息安全从业者和爱好者参考。



 

推荐人：资深漏洞鉴定师/吐槽大师


《TCP/IP详解 卷1：协议》


若想投身于网络安全，对网络基础协议的扎实理解和熟练掌握是必不可少的。这本书是该领域的权威著作。既可以通过本书系统了解各基础协议，也能在遇到实际问题时将其作为字典书查询。



Learn xxx the Hard Way 系列


例如：

Learn Python the Hard Way

Learn Ruby the Hard Way

这系列书的初衷是面向初学者的编程入门，但书中通过简单样例重复练习的方法，也很适用于已有编程功底的人快速上手一种新的语言。




 

推荐人：AI老法师/“少年黑客”之父


《深度学习》


此书被誉为AI圣经，是一部深度学习方面的经典综合书籍。可以用来做教材，也可以作为教材的补充材料。讲解深入浅出，兼具广度和深度。




 

推荐人：正襟危坐胸中有乾坤的师兄


《互联网企业安全高级指南》


这本书覆盖了从技术到管理，从生产网络到办公网络，从攻防对抗到业务风控，涉及安全领域的各个维度包括了30多个重要话题，为企业实施符合互联网特性的安全解决方案提供了实战指南。


《网络空间安全防御与态势感知》


本书是一部关于网络空间安全防御与态势感知的专题学术文章合集，全面覆盖网络空间安全态势感知研究的理论要点，并包括丰富的面向实践的实验数据和经验教训资料，对从事网络空间安全态势感知研究与开发工作的读者极具指导作用，对广大网络安全从业人员也有较大的参考价值。



 

推荐人：左手代码右手焊台的开发小哥


《深入理解计算机系统》


从程序员的视角详细阐述了计算机系统的本质概念，适合计算机专业的学生和从业者。书中包含大量已在Linux系统上编译和运行过的程序示例，可以在配套的网站做实验：

http://csapp.cs.cmu.edu/3e/labs.html


《C++ Primer》


适合有C基础和数据结构基础的C++初学者，推荐边看边实践。毕竟技术都是从一本本书和一行行代码中磨练得来的。




 

推荐人：上懂科学技术下知娱乐八卦的移动百科全书


《码书》


作为信息安全的基础和基石，密码技术是一门古老而又长新的学科。《码书》是一本关于密码3000年历史发展演变的科普书，作者是英国著名科普作家西蒙·辛格。书中包含军事战争、权力争斗、政治欺骗；烧脑的编码解码、精彩的故事都引人入胜。
