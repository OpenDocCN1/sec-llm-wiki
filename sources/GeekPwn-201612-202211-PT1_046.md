# 如果只用2500元就能开走一辆车，那么……

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3Nzc2MjIxOA==&mid=2650344161&idx=1&sn=21e6339940ce9fbb34d5fb1a095921aa&chksm=8740b124b037383209a966b7ca400a372c726ea783398195b197be420cb90cc429cc17184f8c&scene=126&sessionid=1681310266#rd](http://mp.weixin.qq.com/s?__biz=MzA3Nzc2MjIxOA==&mid=2650344161&idx=1&sn=21e6339940ce9fbb34d5fb1a095921aa&chksm=8740b124b037383209a966b7ca400a372c726ea783398195b197be420cb90cc429cc17184f8c&scene=126&sessionid=1681310266#rd)

如今很多汽车的进入系统都由原先的机械钥匙变为遥控系统。而随着RFID技术的广泛运用和汽车市场的需求，无钥匙进入系统又逐渐成为新的发展趋势。有了这个“无钥匙”功能，只要把智能钥匙带在身边，踏入指定范围，不需要拿出钥匙，汽车系统就会与随身携带的智能钥匙通信，识别出主人并自动开门，上车后只需按一个按钮就能启动点火开关。这其中涉及的过程，足以让很多安全研究员 DNA 大动。

  

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_2342935451629846528](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_2342935451629846528)

  

3月底，几名研究员在网上披露称本田和讴歌汽车存在“重放攻击”漏洞（CVE-2022-27254），可被利用解锁汽车，并在较短距离内启动汽车。2016 年至 2020 年间生产的本田思域 LX、EX、EX-L、Touring、Si 和 Type R 车辆都存在这个问题。

  

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_2342935961086787585](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_2342935961086787585)

  

由于本田和讴歌汽车的无线钥匙使用的是固定码，而且还没有加密。如果攻击者位于汽车附近，就可以监听并捕获key fob发送给汽车的RF信号，然后重新发送信号来获取汽车远程无钥匙系统的控制权限，进而开车门并点火。这一切用到的设备只有笔记本电脑、GNURadio开发工具包、Gqrx软件定义无线电（SDR）接收器软件、FCCID.io 网站和HackRF One SDR，总价还不到2500元。

  

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_2342941218244198401](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_2342941218244198401)

  

类似的问题其实并不少见。2019年，巴拉圭安全研究员Victor Casares 披露称本田雅阁、思域、讴歌等多款车存在无线钥匙重放攻击漏洞（CVE-2019-20626），钥匙未采用滚动码，而采用不安全的固定码，导致钥匙信号可以被重放。利用漏洞可以解锁车门、控制窗户、打开后备箱等。2009 年生产的讴歌 TSX、2016 年生产的雅阁 V6 Touring Sedan、2017 年生产的本田 HR-V、2018 生产的思域 Hatchback 以及 2020 年生产的思域 LX 都受到漏洞的影响。

  

![](../Images/753ceb4ebed1c32907274f6cf1382ec7.png)

  

2022年1月，国内安全研究员 Kevin2600也披露了类似的漏洞（CVE-2021-46145）。类似的问题，在2016年就有研究员在比亚迪汽车钥匙设计中发现了。同样是2016 年，外媒报道了一项实验，在该实验中，研究人员克隆了大众汽车钥匙，表示能用它解锁 1 亿辆汽车。

  

不过遗憾的是，本田知道了这些漏洞，却因为主要影响旧车型而不打算更新，只会在后续新车型推出时改进安全功能。对于车主来说，解决问题的唯一办法是让经销商重置智能钥匙。

  

同是3月份，还有另一个重放攻击漏洞（CVE-2022-27948）曝出，影响的是TESLA充电口盖。Tesla 超级充电桩的充电头上原本配备了按钮, 按钮可以通过发送无线射频信号打开充电口盖。同样因为传输的无线信号采用固定码，所以容易被截获。通过重放之前录制的无线信号，可以远程打开充电口盖。根据报道，这个漏洞早前就已被发现并在野利用，市面上已经在售卖专门解锁充电口盖的无线钥匙。由于攻击只能在局域网内发起，未展示技术细节， 且实施起来比较复杂，所以目前并没有针对这个漏洞的缓解措施。

  

![](../Images/d38d2ecdf159cf31077dfbc87e74b54f.png)

  

随着车联网的快速，汽车网络安全市场也不断壮大。报告显示，2024年，汽车网络安全市场预计将超过 8.371 亿美元。汽车网络总线上的数据和消息关乎车主隐私和操作安全；LIN、CAN、汽车以太网、FlexRay、Wi-Fi、5G 网络、蓝牙和专用短程通信 (DSRC) 等网络协议和通信，也牵涉到不同的安全问题；甚至连供应链上下游的安全风险也不能忽视。就在上个月，丰田因为一家供应商遭遇攻击，导致所有的日本本土工厂在3月1日停产一天，约13000辆汽车的生产受到影响。技术推动产品创新的同时，产品在实际应用中暴露出的问题，也不断推动着技术进一步提升。汽车安全研究人员，依旧要砥砺前行。
