出门在外，手机不主动连接陌生 Wi-Fi，就能保证安全吗？厂商更新修复了设备，就能放心地连公共Wi-Fi吗？不连Wi-Fi只用流量，是不是万无一失了呢？

这是一场以手机安全使用建议为线索的技术抬杠。

  
今天讲的这些技术并非仅限于手机使用，只是因为手机上对外的通讯接口或者模块特别多，所以把它串起来作为一个线索来进行攻防的讨论。今天我们主讲链路安全，也会涉及到其他一些数据泄露的方式。技术点涵盖**Wi-Fi安全、蓝牙安全、漏洞（设备漏洞、软件层面漏洞）以及指纹验证**等。要强调的是，虽然安全圈关于技术的探讨有时候会扯到“鬼故事”，但我今天的分享都围绕着真实的攻击与漏洞展开。  
链路攻击  
链路攻击整体呈一个金字塔形的结构，从下到上的攻击难度逐渐增加，攻击成本逐渐增高，防范难度也逐渐增大。  
  
  
![](../Images/7731456a191863b9cc8c3601d8e755aa.png)  
  
很多科普文章都会提醒用户，**不要连接陌生的 Wi-Fi**。因为恶意攻击者可能会通过伪造大小写不同的 SSID 等方式架设钓鱼 Wi-Fi，等受害者连接Wi-Fi之后进行链路劫持。  
![](../Images/e071578726843f6987a77f6d89aa2265.png)  
但其实，攻击者完全可以不修改 SSID的名字，而是设置一个跟公共Wi-Fi相同的SSID名字（例如星巴克）。只要确保 SSID 、验证方式及密码这三要素正确，就会有受害者自动连上这个伪造的Wi-Fi，遭受攻击。此外，攻击者还可以采用 WiFi deauth 攻击，让受害者与真实的WiFi热点断开连接，从而被迫连上假伪造的热点。这就是**伪造热点&WiFi deauth攻击。**  
对**钓鱼Wi-Fi和伪造热点&WiFi deauth攻击**来说，最好的防范方式就是不去连接公共场所的WiFi。但这也不意味着就能高枕无忧。这两层攻击只是手机链路攻击的最低两层。还有其他让人防不胜防的攻击。例如，会让人**在意识不到的情况下****连接攻击者 Wi-Fi ****的 karma 攻击。**  
![](../Images/433af35833a1975a3f8f0a79198fc9c7.png)  
Wi-Fi 客户端发现Wi-Fi热点有两种方式，一种是**被动扫描**，一种是**主动扫描**。其中，主动扫描就是设备会主动向外搜寻之前曾连接过的 Wi-Fi。就像是一个小朋友跑到大街上到处问你是星巴克吗？你是 CMCC 吗？如果对方回答是，那客户端设备就会尝试连接这个 Wi-Fi。这些公共Wi-Fi通常不需要密码验证，所以攻击者伪造Wi-Fi，利用这个协议层面的缺陷发起 Karma 攻击，就可以得逞。针对这种攻击，市面上大部分厂商已经修复、升级了设备，客户端不再对外进行主动扫描。但这是不是意味着新设备就安全了？并不是，还有更高层的** Mana 攻击。**  
![](../Images/285708237f28d96a3535c31d82b167fd.png)  
Wi-Fi 本身有个功能，就是隐藏 SSID。Wi-Fi 客户端如果想要连接隐藏 SSID 的 Wi-Fi，就不得不去主动扫描它所保存的隐藏 SSID 列表。攻击者就可以通过伪造一个隐藏 Wi-Fi，诱导客户端发出主动扫描，就可以实现攻击，跟 Karma 攻击类似。Mana 攻击与 Karma 攻击的主要区别就在于，Wi-Fi 的 SSID 是隐藏的还是公开的。  
有些操作系统在连接隐藏 Wi-Fi 的时候会有一个感叹号的提示，让我们不要使用隐藏Wi-Fi，这就是为了应对 Mana 攻击。另外，建议尽量不要使用公开验证的WiFi，就能在很大程度上避免 Karma和 Mana 攻击。要注意的是，如今我们在住酒店时，连接Wi-Fi后会发现跳出一个 web 页面，要求填写用户名密码，这也是一种公开验证的方法，也可能受到 Karma 或 Mana 的攻击。  
这几种方法都是链路攻击中利用协议弱点的通用攻击。这类攻击的特点，就是成本低，黑客只要买个设备和网卡就能发起攻击，用户作为个体还可以应对。**但金字塔再往上两层，以个人之力就难以防范了，那就是利用特定漏洞进行攻击。**  
![](../Images/9e66d1e16d4fc19e76e1729f3fe12e62.png)  
**第一类是利用网络设备漏洞的攻击，**比如家用/SOHO的路由器、防火墙、上网行为管理、VPN网关、网络交换机等，几乎市面上所有的主流设备都曾在极棒上被攻破过。一旦这类攻击发生在大型企业的网络当中，劫持链路，就会影响到大量的终端用户。  
![](../Images/5a3d7341eaa3877992ae45f781ae0d64.png)GeekPwn 2017 香港站  
要想应对这类攻击，只有依赖厂商去修复设备的漏洞。对普通用户来说，其实无能为力，顶多只能把 Wi-Fi 网卡关闭以绝后患。  
不用 Wi-Fi 只用数据流量也许安全性高一些，但这也不意味着100%的安全。  
**再上一层还有别的**链路攻击方式，也就是**针对运营商设备（例如基站）漏洞的攻击**。这是位于链路攻击金字塔塔尖的攻击方式。此外还有一些关于运营商专网的攻击，与车联网、IoT 相关。这些专网虽然与外部隔离，但内部时互通的。所以攻击者利用另外的设备，也有可能连接进内网，发起攻击。  
![](../Images/9412c7806cde9788b2ee4ba8341027a3.png)扫码可观看技术详解GeekPwn 2020 项目：谁劫持、篡改了我的4G通信  
在大家的印象中，运营商基站就是个大铁塔，也就是宏基站。而在我们生活中还有很多微基站，布置在电梯或者车库等信号不好的地方。这类微基站大部分是暴露在外面的，恶意攻击者只需要从墙上拿下来就可以实施攻击。  
此外，还有一些恶意攻击者会去买一些二手淘汰的设备或者申请一个新设备，攻破后把信号覆盖出去，就能劫持到数据流量传输的内容，甚至还有短信验证码等。  
对于这种攻击，同样只能依靠运营商和设备厂商修复漏洞。用户如果关闭Wi-Fi和数据流量，手机就相当于开了飞行模式，但依旧有隙可乘。  
  
其他数据泄露方式  
  
除了链路攻击、针对特定漏洞攻击，还有其他数据泄露的方式，例如**蓝牙和指纹解锁**。  
先说说**蓝牙攻击**。通常，用户想和蓝牙建立链接需要两个步骤，一个是**配对**，另一个是**获得蓝牙 profile 的授权**。曾多次参加极棒的海特实验室研究实现了绕过这两步提示，进行自动静默攻击。攻击者可以通过构造一个特殊的包来实现临时绑定，从而绕过蓝牙绑定提示（弹框），再通过特定厂商手机系统的漏洞绕过 profile 授权提示，直接获取对方手机的通讯录；如果没有漏洞无法绕过 profile 授权提示，也可以通过其他方式诱导用户点击授权确认。这种攻击一方面需要厂商修复漏洞，另一方面个人用户在授权的时候也需要留意授权提示框，不要随便点确认。  
![](../Images/a13fcfdc1a299bfef67b743735d48c99.png)扫码可观看技术详解  
就算Wi-Fi、数据、蓝牙都关闭了，让手机变成一个板砖，手机中的数据还是有可能被获取。  
在GeekPwn 2019 的现场，玄武实验室的选手破解了手机的指纹解锁：采集受害者在水杯上留下的指纹做成指模，直接解锁手机。更进一步，还能利用一张塑料卡解锁指纹验证手机。屏下指纹发出的光被卡片反射，再次传导到指纹传感器当中，就能够进行解锁。当然，这个漏洞目前已经被厂商修复。  
![](../Images/8ae9695bcf6c5dbb0abb9723b8ad21c2.png)扫码可观看技术详解GeekPwn 2019 项目：我只是喝了杯水，为什么他们就打开了我的手机  
总体来说，没有绝对的安全。安全建议和安全实践不是一成不变的，无论是企业厂商还是用户，在保护自身信息安全的时候，要根据不同的攻防情况选择对应的安全策略。用户为了自身的信息安全，也要尽量去选择那些更安全、更负责任企业的产品。  
  
Q&A  
  

**Q**

**SSID 都是自动连接的吗？**

  

**A**

自动连接的条件有三个要素：SSID 相同、加密方式相同、密码相同。这三个要素都满足的话，就会自动连接。

  

**Q**

**您是用什么系统来做渗透工作？**

  

**A**

对于我来说，很多时候直接用我的 Mac 笔记本就能攻击，因为很多的工具在MAC上跑的也都不错。易用性更好的话，就是Kali Linux。如果要更傻瓜式的话，例如研究Wi-Fi方面的渗透，可以买一个WiFi pineapple。

  

**Q**

**硬件设备的漏洞都是怎么发现的？**

  

**A**

虽说是硬件设备，但很多情况下都是硬件中的软件出了问题，最终还是代码层面的漏洞。例如，web 漏洞可以用常规的思路去研究；如果是二进制层面的研究，可以用读取器去读取芯片中的代码，然后再逆向、分析。

  

**Q**

**现在不太敢用安卓的手机去安装支付宝这种软件。从现在的情况来看，安卓手机确实是比iPhone风险更大吗？**

  

**A**

宽泛的讲会更大一点，但是多出来的风险还是由于软件分发所导致的。在 iPhone 上，我们装软件都必须从 APP store 上面去下载安装。安卓手机上软件的来源就不一定可控，就有时候会有一些用户直接从一些不好的分发渠道去获得软件，就有可能会下载到恶意软件。所以对于安卓用户来说，要从一些可信的渠道去安装，比如说一些官方的软件市场去下载应用，这样的话就可以把风险大幅降低。

  

**Q**

**现在个人信息泄露比较多，还建议开人脸支付吗？**

  

**A**

人脸识别是会带来意外的风险，但大多数支付场景，并不会把人脸验证作为唯一的判断依据，而是结合各种不同的风控策略。如果说支付时和某些风控策略不符，支付还是会被拒绝。所以说我们不能够单一的依靠一种认证技术去保证安全性，而是要结合各种不同的要素同时的去判断这个账户是否在一个合理的风险范围之内。
