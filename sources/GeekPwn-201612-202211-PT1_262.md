# GeekPwn与BSI(英国标准协会)建立战略合作伙伴关系

**GeekPwn（极棒）与 BSI（英国标准协会）正式达成战略合作伙伴关系。未来，双方将在安全培训、企业安全解决方案与行业标准等领域展开深入合作。**

  

**GeekPwn（极棒）**由 KEEN 于 2014 年发起并主办，至今已多次在中国上海、北京、香港、澳门以及美国硅谷、拉斯维加斯等多地成功举办。GeekPwn 是全球最有影响力的安全极客大赛之一，也是全球首个探索人工智能与专业安全的前沿平台。GeekPwn 已向上百家企业负责任地披露了近千个高危安全漏洞，切实提升了用户及企业自身的安全水平。

 

长期以来，GeekPwn 将安全研究积累的经验与前沿科学研究结合，持续为企业提供安全服务、帮助企业解决安全问题。通过对产品和系统中发现的安全漏洞进行总结与提炼，GeekPwn 转化为安全攻防新方向，并在 AI、云计算等跨领域实践中，结合真实案例，前瞻性地发现并消灭潜在的安全隐患。

  

**英国标准协会（British Standards Institution，简称“BSI”）**是全球领先的商业标准服务机构。作为国际标准化组织（ISO）的创始成员之一，BSI 参与建立了全球最值得信赖并得到广泛认可的 ISO 系列管理体系。每年颁布 3000 份左右的新标准，被广泛认可的信息安全领域相关标准（如 ISO27001）最早即由 BSI 编写制定。BSI 中国致力于在全国推广标准、认证、培训以及管理辅导等服务。

 

BSI 在信息安全、云计算安全、个人隐私保护等领域提供专业服务，为企业提供信息安全管理（ISO/IEC 27001）、云隐私保护认证（ISO/IEC 27018）等领域的整体解决方案以及定制化服务，有效规避风险，确保企业的健康数字运营。

 

**GeekPwn 与 BSI 此番战略合作，集双方所长，致力于为企业客户提供更为全面、专业的安全服务，提升企业安全能力。**
