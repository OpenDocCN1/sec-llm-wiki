“基础设施安全领袖圆桌会议（简称 P13）”，于 2017 年 CSS 上首次召开。13 家境内上市信息安全企业领袖悉数出席并共同发起了《网络安全产业中坚共识》（简称 P13 共识）的倡议。第二届基础设施安全领袖论坛（P16）除参与首届的 13 家企业外，还将新增三个企业领袖加盟。新一届 CSS 将着力推进 P16 领袖俱乐部的成立（上市企业协作共同体）与产业升级，共同为未来互联网行业发展持续赋能。

  

**最专业的平台助力网安产业蓬勃发展**

自创办以来，CSS 获得了诸多第一。第一届 CSS 促成了 BAT 首度同台，推动了安全+新生态圈的建立；第二届 CSS，作为国内的安全产业大会，CSS 第一次吸引了包括苹果、微软、高通、谷歌、思科、英特尔、McAfee、趋势 ZDI、Fireeye 等在内的国际巨头，量子通讯领军人物潘建伟院士也在峰会上首次公开分享量子通讯技术的安全产业应用价值。第三届 CSS 不但促成了世界头号黑客凯文·米特尼克的中国首秀，还设立了含金量比肩 BalckHat 的 TSec 腾讯安全探索论坛，促成了安全行业首个企业联盟 P13，获得了行业及媒体的广泛关注。
