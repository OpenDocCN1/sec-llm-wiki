有人曾问：我读过很多书，但后来大部分都被我忘记了，那**阅读的意义是什么**？

  

知友回答：当我还是个孩子时，我吃过很多的食物，现在已经记不起来吃过什么了。但可以肯定的是，它们中的一部分已经长成我的骨头和肉。阅读对思想的改变也是如此。

  

**关于 423 世界阅读日**

  

1616 年 4 月 23 日，西班牙最伟大的作家塞万提斯与英国最杰出的剧作家莎士比亚双双辞世。

  

1995 年，联合国教科文组织定 4 月 23 日为**“世界图书与版权日”**，又译作**“世界阅读日”。**

  

关于“世界阅读日”还有一个传说：美丽的公主被恶龙困于深山，勇士乔治只身战胜恶龙，解救了公主，公主回赠给乔治的礼物是一本书。**从此书成为胆识和力量的象征，4 月 23 日成为“圣乔治节”。**

**白帽黑客喜欢读什么书？**

![](../Images/fa88001671c35e25c1c79572f8444b57.png)

  

极棒小编最近在朋友圈发了条征集：**请大家推荐最近看过的书籍。**得到了许多朋友的用心推荐，小编要在此分享给大家。

  

![](../Images/e384e08b716e7505b28432cb2e1c2d51.png)

  

**推荐：《Metasploit 渗透测试魔鬼训练营》**

理由：当年我还是个菜鸟的时候，（现在也很菜鸟 2333），偶然读到了这本书，很棒，分享给在座的各位大佬。本书详细介绍了渗透测试的整体流程，对于想要学习渗透技术的初学者，通过本书可以了解到渗透测试的全貌。除了理论知识的讲解，随书还附带了实验环境，理论与实践相结合可以更好的理解渗透技术。

  

这本书从最初的信息收集到后期的后渗透阶段，以及最后的渗透测试报告撰写，都由涉猎，对于想学习渗透技术的同学是不二之选，强烈推荐。其中对于漏洞方面你可以接触到 Web 安全中的 SQL 注入等漏洞，浏览器漏洞，以及服务端软件的漏洞，涵盖范围广，可以窥的渗透技术中利用的漏洞全貌，为之后的深入学习打下坚实的基础。

  

![](../Images/53eae52926278f175fb28acac4002b55.png)

  

**推荐：《Python 编程：从入门到实践》**

理由：目前为止读的最有用的应该是《Python 编程：从入门到实践》，一开始学 python 是因为发现很多人都说 python 是最好的脚本语言，后来接触了 ctf 发现 python 是真的好用，信息安全的很多领域用 python。总而言之，对我目前学习生涯帮助极大，python 大法好 ![](../Images/f17e3d53449be08f24d374f5735ecf1a.png)![](../Images/f17e3d53449be08f24d374f5735ecf1a.png) 小白对入门书籍印象最深刻 ![](../Images/c4edbbc0287c9feef8afd6af9d7e7728.png)

  

![](../Images/14c4d445ad8170c7a5a8a7c673943454.png)

  

**推荐：《Python 核心编程》**

理由：这是一本可以把人带入真实 Python 世界的书，书中介绍了 Python 基础知识以及高阶只是，详尽，认真读一遍对于 Python 的了解达到百分之六十，剩下的百分之四十就是各种 Python 应用库。人生苦短，我用 Python。

  

![](../Images/a553446ece288f7604b8f77615411b81.png)

  

**推荐：《白帽子讲 Web 安全》**

理由：我读过的吴翰清的《白帽子讲 Web 安全》对我影响最大，体系化地了解安全，指引领进门，深化靠自身：讲得内容很有价值，方便更整体地了解安全这个水平领域。

  

对于程序员来说，经典代码的详解和方便操练的指导感觉还少了些，当然这样内容往往需要深入了解与一个安全点相关的知识及其工具链（如 JS、SQL），这远远超出了这样一本书厚度所能承载的，应该由程序员自己去补充和深化，这本书作为一个指引。

  

![](../Images/1416948b7bfd4e12d3bffc1a97c53833.png)

  

**推荐：《程序员面试金典》**

理由：推荐两本吧，《程序员面试金典》和《深度学习》这两本书对我的职业规划和研究方向产生相对大的影响。先说说第一本吧，这本书汇总了 150 个编程面试考题和解答，从二叉树到二分查找，涵盖了关于数据结构和算法最常见常用的面试题，还总结了面试流程，面试准备，行为面试和技术面试，特殊情况特殊处理，硅谷大公司面试揭秘，以及录用通知等，**这本书帮助了我毕业后很快的在某大公司找到了我满意的工作。**

  

![](../Images/e5289bd37fccf7487ae27929eb2fc4ec.png)

  

**推荐：《深度学习》**

理由：再说说《深度学习》，那时是我第一次接触人工智能，没有学习过机器学习，在朋友的推荐下读了这本书，书里囊括了数据还有相关概念的背景知识，同时也介绍了深度学习技术，也提供了研究方向，让我初步了解了人工智能需要的只是储备，同事也对人工智能产生了兴趣。

  

![](../Images/94ee3b9d3f4265916d198afee8a1acf9.png)

  

**推荐：《黑客之道：漏洞挖掘的艺术》**

理由：因为我本专业的远古，所以强烈推荐，还有《python 基础教程》，这两本因为时间原因就不细写推荐理由了。我想起第一次入群时听的第一场讲座《安全的人工智能离我们 还有多远》。希望极棒推荐一本人工智能安全的相关书籍，嘻嘻！

  

![](../Images/7d56ca5464203525aebd3770a9f492c4.png)

  

**推荐：《编码——隐匿在计算机软硬件背后的语言》**

理由：从简单的初中物理灯泡试验入手，到逻辑门，到晶体管，再到半导体，讲述了计算机的整个发展过程。读完此书，对于计算机的编码机制及运行原理会有个更深入的认识，为后续学习计算机系统、网络通讯等奠定基础。
