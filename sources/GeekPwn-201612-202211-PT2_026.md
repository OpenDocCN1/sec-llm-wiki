# 不用找了，你和好莱坞黑客的差距在这里

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3Nzc2MjIxOA==&mid=2650319193&idx=1&sn=7161690b7fe215259a8e5c84ce1f3139&chksm=8741129cb0369b8aa9cd75ed99b2adfa138cd13b209982c9fd86bab15f43b73d1d93167ef3e2&scene=126&sessionid=1681310386#rd](http://mp.weixin.qq.com/s?__biz=MzA3Nzc2MjIxOA==&mid=2650319193&idx=1&sn=7161690b7fe215259a8e5c84ce1f3139&chksm=8741129cb0369b8aa9cd75ed99b2adfa138cd13b209982c9fd86bab15f43b73d1d93167ef3e2&scene=126&sessionid=1681310386#rd)

**为什么美剧《黑客军团》能秒杀好莱坞电影里的的所有黑客？  
**  
因为剧中“采用”了诸多黑客工具，例如最流行的渗透测试工具 Kali Linux、入侵服务器程序 wget、获取汽车信息工具 Cambus Hacking、蓝牙扫描器等等。  
  
《黑客军团》号称每个网址和 IP 地址都能打开。

**但是，好莱坞也不曾放弃对黑客的形象通俗刻画。**

  

例如，2017 年上映的《王牌特工2：黄金圈》中黑客攻破防火墙：  
  

![](../Images/572e9c70e4ec376de5297f44efb9f7f1.png)

（请主动忽略右侧的脸）  
  
有人说，一般程序员写代码的时候，40% 的时间在欣赏窗外的风景，40% 的时间在绝望的思考哪里出了问题，10% 的时间在发呆，实际上只有 10% 的时间在写代码。  
  
当你在欣赏风景时，该如何像电影中的黑客一样假装自己的智商还在线呢？特别是就快过年回家了，身为安全工程师的你除了为家里人修电脑，是不是也希望能小试身手？  
  

![](../Images/2f392cde93dc0fc3c4a9b31d90590e05.png)  

  
这里给大家介绍三种不同情况下使用的“假装黑客”神器，  

  

> 伪装黑客测试的网站** GEEKTYPER**
> 
> 化身好莱坞黑客的 Linux 工具 **HOLLYWOOD **  
> 安卓终端桌面应用程序 **Aris**

  

希望让你在发呆的时候也被人称赞“**哇——好帅！你是黑客**”。

  

![](../Images/b2623a2a4120606fb9520a0a5683c40a.png)

GEEKTYPER

  

![](../Images/125b32806b740449577c7c297e428dc1.png)

  
**使用场景：全平台  
装 X 指数：★★★★★**  

  

电影中，黑客几乎不怎么用鼠标。还有种说法，“不用鼠标打开任意软件的黑客才是好黑客”。  
  
GEEKTYPER.COM 是一个模拟黑客打字的网站。当你回到家里，只用在键盘上随意敲击什么，屏幕就会出现一行行代码。当然它还有更多“攻击”功能，等你自己去发现！  

  

点击下方空白查看地址  
▼

访问网站 geektyper.com，这是一个在线平台，不需要下载哦。记得 Win 最好 F11 全屏！

 

HOLLYWOOD

  

![](../Images/9170403bd1f9494c9c53b4831b5ad039.png)

  
**使用场景：Linux 平台  
装 X 指数：★★★★☆  
**  
“好莱坞”作为这款工具的名字可以说是非常形象了。一旦这个脚本在你的 Linux 上运行起来，桌面就变成了具有强烈好莱坞风格的实时入侵场景。  
  
后台甚至能播放《碟中谍》的主题曲。  

  

点击下方空白查看安装  
▼

Ubuntu 用户可以直接 sudo apt install hollywood  
或者通过 github.com/dustinkirkland/hollywood 

Aris

  

![](../Images/4aeb14d79903056437187a2d5a971624.png)

  
**使用场景：安卓  
装 X 指数：★★★☆**  

  

很多人觉得这个“爱啪啪”很鸡肋，因为用户需要用命令行进行操作，哪怕是卸载应用这种简单的事情。  
  
但话说回来，这不正是“天才黑客”的路线吗？普通人怎么理解的了呢？跟其他“装黑客”应用相似，ARIS 能引入插件，其中有一个imCoding 就可以假装在写代码。  
  

点击下方空白查看下载

▼

尝试在 Google Play 中搜索 Aris - Terminal Launcher

**不得不说，这种演黑客的感觉真的是太棒了！是不是很像 GeekPwn 黑客大赛上那些技术高超的选手呢？**
