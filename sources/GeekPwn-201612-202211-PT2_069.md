# 程序员为什么故意留 bug？他的回答被赞了 2.4w 次

大概很多人还记得，已经过去了四分之三的 2017 年是鸡年。

  

![](../Images/3f5a1dec1c4cbc117bb9eff776c9552a.png)

  

然而，谁知道下面这十七只“鸡”在说什么？

  

![](../Images/63f5a9249d472db1ea9d44cf827a8dd3.png)

  

![](../Images/619a3a800be88a0e9fa8aa39fd8bbae0.png)

  

这是 **Chicken 语言**中“猫”的意思。不要小看了程序员的创造力，真的存在这种语言。

  

Chicken 是这种编程语言中唯一允许的关键词，它重复的次数和换行决定执行的具体操作。

  

![](../Images/3035c927edd1b4a0b6c01611f6194fae.png)

  

在很多人眼中，程序员都是一种神奇的存在。

  

![](../Images/f04cb978c91ce373254e92c69ebe879e.png)

  

好吧，也许没有那么“神奇”。

  

世界上有靠代码登上富豪榜的企业家微软公司创始人比尔·盖茨、Facebook 创始人马克·扎克伯格，也存在“不爱商业爱代码”、极客力 MAX 的苹果公司创始人之一史蒂夫·沃兹和“Linux 之父”林纳斯·托瓦兹。

  

![](../Images/95e4af26a9f3bec1ca0ddf25a1b0a781.png)

  

生活中当然也不乏程序员的身影。没错，就是那些找室友联系方式留的是一段代码、Wi-Fi 名是数学公式、背着“IT 业”出轨率最高的锅却还是单身狗的我我我们......

  

![](../Images/a5aff589896195500b496823b56f34a0.png)

  

程序员生来是为了解决 bug 的，同时也最怕遇到 bug，尤其怕人家说：

  

![](../Images/1ee7305ade54a880d033b67e1449b25f.png)

  

毕竟，传承多年的“程序员宝典”里面是这么说的：

  

![](../Images/3e5c87fbe43b9feb7ca1a6d61929a9c3.png)

  

看到这里，你不禁要问题目里说程序员故意留 bug 呢......这难道不是代码写多了，神经错乱了吗？

  

原来，这是知名英文问答社区 Quora 上的一个问题，并且收到了 72 个回答。Curtis Poe 也是回答者之一，作为一个资深码农的他，这个回答获得了 2.4w 个赞。

  

![](../Images/be86471cb445376b1f18be1d31fab7d1.png)

  

Curtis 回顾了自己曾经工作过的一家公司，在那里写的所有东西都会被老板检查一遍。

  

不仅如此，老板还总是对 Web 应用程序的布局提出修改建议，而机智的 Curtis 渐渐掌握了老板想要的 style，试图让老板称心如意。

  

**然而，剧情并不是这样发展的。**

  

![](../Images/ea92d1b834297687ead842f9f2f2e261.png)

  

Curtis 的老板依旧提出其他修改建议，有的甚至因为布局需要对后端进行重新改写。  

  

Curtis 和老板之间常常爆发争吵，结局往往是两败俱伤。

  

![](../Images/a478859392575c376d5d03643b1d27cd.png)

  

Curtis 越是写下详细说明，强调“**一切都是最好的安排**”，他越是感觉到挫败，因为老板总能找到需要改的地方。

  

直到有天，Curtis 顿悟出一个道理：那些修改建议其实源于老板想要通过“改进一些事情”而获得的成就感。

  

所以无论 Curtis 有多么认真努力，他总是无法写出能够让老板直接通过的东西。

  

![](../Images/ec50157954ef9e3350ce07d093ce4b9d.png)

  

自那以后，Curtis 开始故意在前端留下一些缺陷，例如选择难看的色彩搭配、让提交按钮出现的不合时宜，又或者段落间排列不整齐。

  

**“我总是故意留下一些东西，等他去发现。”**

  

![](../Images/7a64a601d9b2ed5a971f7a5845083adc.png)

  

于是老板发现问题，提出修改需求。

  

Curtis 就会回到工位上，完成他已经准备好了的“修改”，但是他并不会直接提交代码，而是默默开始下一个项目。

  

直到几个小时之后，他提交更新，老板无比欢乐。不久后，Curtis 还升职了，理由是“效率提升”。

  

这个故事告诉我们，产品经理是很需要成就感的职业。（![](../Images/b9998a383b298f01377fc13a2023584c.png) 这句是开玩笑的）
