# 搞事情！惠普电脑竟然内置键盘记录器

近日，国家有关部门发布了**惠普电脑存在隐藏键盘记录器的公告，呼吁用户及时安装更新、修复漏洞**。  

  

![](../Images/cd2fb38d1e1a4006999b51d585f31c4f.png)

  

这个安全问题最初由瑞士安全研究员 Thorsten Schroeder 在检查 Windows Active Domain 的基础设施时发现，惠普电脑音频驱动中存在一个内置键盘记录器监控用户的所有输入。

  

**键盘记录器**通常被用户于恶意软件和木马，攻击者通过这种方式窃取用户账户信息、信用卡号、密码等隐私信息。

  

即便键盘记录器这种羞羞的东西，如果你想要，还是能在亚马逊上找到卖家。

  

![](../Images/94a9ea2bdab513e551876dae4dc5be6e.png)

  

果壳网曾经发布过*《“键盘记录器”确实存在，而且比我们想象的强大得多》*一文，作者通过“一些渠道”订了一台 USB 版的键盘记录器，到货后发现还真是迷你呢。

  

![](../Images/e3f3a28359720a436d66b25cb3c17080.png)

  

作者惊讶地发现电脑系统并没有弹出有任何新硬件提示，安全软件也没有反应，连 U 盘提示都没有。简直不留一丝痕迹......

  

![](../Images/2d88da03cda3583fce50276432c36483.png)

  

而且打开记事本之后输入说明书上的密码之后，竟然还会出现使用菜单。

  

![](../Images/1ae12ca5e27539086b6aa5014f0aa33c.png)

  

作者测试发现，键盘输入的内容几乎全都能记录下来，除了略微误差之外，但是记下用户账号密码并不成问题。

  

其实键盘记录器不仅有硬件版，还有软件版。

  

![](../Images/be5bb3f366d83b4ca6e676bfcceb23da.png)

  

**那么问题来了，惠普电脑内置键盘记录器是要与用户为敌吗？**

  

原来是由于惠普电脑采用的 Conexant （科胜讯公司）的音频驱动“误将过去用于调试产品的音频代码留在了最终产品中”。

  

据了解，Conexant 是一家集成电路制造商。Conexant High-Definition (HD) Audio Driver 音频驱动程序用于帮助软件与硬件进行通信。

  

漏洞发现者 Thorsten 称，与 Conexant 音频驱动安装包一起安装在 Windows 系统中的还有 **MicTray64.exe 应用程序**，**能够对用户是否按下了音频相关的按钮加以确认。**

  

**惠普用户请注意，这个被记录为“CVE-2017-8360”漏洞，已经影响了 28 款惠普笔记本电脑和平板电脑，包括 EliteBook 800 系列、EliteBook Folio G1、Elite X2、ProBook 600 和400系列以及  ZBook 等型号。**  

![](../Images/8e739db6e6db98c0f07c5e089de04a27.png)

  

目前，惠普已经发布了闭关此调试功能的修复程序，在 5 月 14 日也发布了更新的修复驱动程序，将所有 Conexant 音频驱动中的“键盘记录器”源代码删除。

  

**如果你正在使用上述型号的电脑，请及时进行操作系统更新，也可以修复这个问题。**

  

**如何检测你的惠普电脑是否还有内置键盘记录器？**  

  

你可以检查电脑硬盘中是否有 

***C:\\Windows\\System32\\MicTray64.exe*** 或 ***C:\\Windows\\System32\\MicTray.exe***文件。

  

如果发现这两个可执行文件其中之一，你最好立刻**删除文件或者把文件重命名**，因为你的密码很可能已经被键盘记录器记录下来了。
