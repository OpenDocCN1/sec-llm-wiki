# 针对物联网设备的『王炸』终于出现了......

**一系列新的恶意攻击会让那些安全性差的物联网设备永久变砖。**

超越 Mirai 的 **BrickerBot **

  

  

Mirai 本意是日语“未来”，但是去年它以一个恶意软件的身份告诉大家“未来已至”。2016年9月20日网络安全博客 Krebs on Security 遭遇大流量 DDoS 攻击，法国网站托管商 OVH 也遭遇攻击以及 Dyn 公司网络被“史上最大规模” DDoS 攻击导致半壁美国网络断网。

![](../Images/4e8024087186d16ecb827f7153d717be.png)

Mirai 会让运行 Linux 的计算系统变成被远程控制的“僵尸网络”，而受 Mirai 感染的对象主要为**网络摄像头和家庭路由器**。在扫描得到 IP 地址后，Mirai 会利用超过 60 种常用默认用户名和密码识别出易受攻击的设备，然后登录这些设备。

但是现在出现了一种新的针对 IoT 的恶意程序 BrickerBot，安全公司 Radware 研究人员用蜜罐捕捉到节点遍布全球的两个僵尸网络，分别命名为 BrickerBot.1 和 BrickerBot.2。

![](../Images/f83c54af5a63b04a3fc0041222f25ee5.png)

PDoS (Permanet Denial of Service） ，中文译为永久拒绝服务攻击。这种攻击旨在破坏物联网设备和其他硬件的固件，其中一种攻击方法是攻击者对硬件管理借口进行远程或者物理管理。而BrickerBot 恰恰可以进行这种“灭门攻击”。

BrickerBot 能够感染基于 Linux 系统的路由器或者类似的 IoT 设备。一旦找到一个存在漏洞的攻击目标，BrickerBot 便可以通过一系列指令清除设备里的所有文件，破坏储存器并切断设备网络链接。

**考虑到修复成本以及时间等因素，受感染的设备便永久报废了。**

![](../Images/d4f985dc3277c3f5ad79b3249276239d.png)

目前，研究人员发现 BrickerBot.1已经不再活跃，而 BrickerBot.2 的杀伤力正与日俱增，几乎每隔两个小时就会被蜜罐记录。由于攻击之后并没有明显的标志，因此设备主人并不知道发生了什么，那些默认启用了远程登录协议以及默认密码的智能设备便会永久沉默了。

极棒 **安全建议 **

  

  

极棒实验室研究员为 IoT 用户支招：

1、更换默认密码；

2、关闭或者限制远程登录以及SSH，它们可能被攻击者滥用；

3、及时确保智能设备的更新。
