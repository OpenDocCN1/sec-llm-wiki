## 0x01 新增插件  

**1. GoPassPython ****  ![](../Images/134f2f7d28e079b4bd041ddb5863997e.png)**  

用于查询域名的备案信息，方便蓝队的信息收集工作。简易 Python 免杀。支持自定义 exe 图标，方便红队钓鱼。由@hututuZH 开发👏。

*   下载安装 pywin32-227.win-amd64-py2.7（完美兼容版本）
    
    > https://github.com/mhammond/pywin32/releases/tag/b227
    
*   配置 python 路径或使用名称（如 python2）。只支持 python2，完美支持 python 2.7.17
    
    ![](../Images/2fdb53f4fca7c8bb18a8a7a66bef1f45.png)
    
*   导入 CS 64 位 C 的 payload (attacks - > packages - > payload generator - > output: C) 进行免杀
    
    ![](../Images/f287bbd35b08fe1eb52ceec44cca74d9.png)
    

*   成功后会在根目录下 /dist 中生成 payload.exe 文件，其他版本可以自行打包根目录下 payload.py 文件
    
    ![](../Images/0a37a9c97d0ef78e8c952fd20d57abae.png)![](../Images/faecddc8cd9bda715fe354b8db3c22a7.png)
    

#### **2. IPFormat ****  ![](../Images/e70e96d4e5b0d3158cb6d21309b8a092.png)**

*   从文件中提取出所有的 IP 和域名，一键导入扫描配置。由@zhe 开发👏。
    
*   上传文件，左侧显示文件原始数据，右侧是解析后提取出的所有 IP/Domain，点击导入 Goby 开始扫描。
    
    ![](../Images/bf511286bde4114eeda1567f24058b0f.png)
    
*   目前支持的文件格式有：docx、pdf、txt、rtf、json、xml、html，如需要提取其他不支持的文件格式，可以直接将文件内容复制后粘贴到左侧输入框。
    
    ![](../Images/4a9586cae719fdb72e88d3d56139d304.png)
    
*   也支持点击链接按钮输入链接后，提取出该网页中包含的所有 IP/Domain。
    
    ![](../Images/c2194ba30ac0e1fec8417b04e0af48d5.png)
    

**3\. Rebound shell encryption tool   ![](../Images/fd3d4f22adba6661d72c3d332750b25a.png)**

通过 Base 64 加密对反弹 shell 语句的 EXP 进行加密处理。由@0ATKX 开发👏。  

*   输入反弹 shell 语句以开始加密。  
    
    ![](../Images/b21efc945d9ff8be1be80597ce07756e.png)
    

**4\. Get\_MSKB   ![](../Images/c7e68349d0352a5fe9c4ea168096f4f3.png)**

根据 Windows 系统遗漏的补丁获取可以利用的漏洞编号，方便红队人员提升权限。由@XiaoBai12138 开发👏。

*   打开 CMD > 输入 SYSTEMINFO > 复制全部结果 > 查询
    
    ![](../Images/31a239e145f6cbbfa21f86d7d975b289.png)
    

**5\. Dnslog   ![](../Images/91566787a3d2e4372f47db82ea977751.png)**

渗透时不知对方服务器是否出网，可对获取的域名发起请求，来判断是否出网。  

渗透时执行命令无回显，可执行 ping 命令对域名发起请求来判断是否执行成功。

由@XiaoBai12138 开发👏。

![](../Images/1f47427288b9d681738f2fa1e2dddc8e.png)

#### **6\.  CZ88****   ![](../Images/45f5706030053bbfd0dd0974021cf93f.png)**

输入 IP 地址，利用纯真数据库，批量查询归属地信息。由@青衫磊落 开发👏。

*   下载插件，如下位置打开插件入口
    
    ![](../Images/16cb595dbf8aff3fdc92ed47422ca1d2.png)  
    
*   在文本框输入 ip，多 IP 每行一个，点击右侧按钮进行查询。
    
    ![](../Images/ea221ad3f5e7f894d32741e27ae4c03f.png)
    

#### **7. ****AV\_List****   ![](../Images/11933408e05faeafb879e4eb221e23ac.png)**

用于查询 Windows 杀软进程。由@zering 开发👏。

*   使用 cmd 命令：tasklist /svc
    
    ![](../Images/bd8179169bfa3d097ed53221e27b9d8c.png)
    
*   复制结果粘贴或直接输入进程名，点击「识别」获取识别结果。
    
    ![](../Images/2a04e49f9e7dfd92b5000b126914374a.png)
    
    ![](../Images/865b08600ca23aebbab5c5d502d164e5.png)
    

#### **8.  ****Nikto   ![](../Images/d93651a4a61ce23433d68f1145b7babd.png)**

网络服务器扫描仪，检查 Web 服务器以发现潜在问题和安全漏洞。由@沉默 开发👏。

*   Github下载项目：https://github.com/sullo/nikto  
    
*   在配置页面配置 nikto 绝对路径。
    
    ![](../Images/144faa02b2a6a372cfc1f01d72081a1f.png)
    

#### **9\. Xcode ****  ![](../Images/7dc2027594a780db290d9a2f2b28d254.png)**

暴力破解Web服务器中的目录和文件。字符串编码及中文姓名转换成拼音字典。由@ettercap 开发👏。

[ettercap | 可进字符串编码解码及转换拼音字典的 Xcode](http://mp.weixin.qq.com/s?__biz=MzI4MzcwNTAzOQ==&mid=2247508151&idx=1&sn=a70eadddb70e509b77a41a006456e601&chksm=eb844b17dcf3c201a962dbd89529b0c9a764fda929d1d46537bdca64676f32a52f9592f41fc4&scene=21#wechat_redirect)

*   下载插件，从右侧工具栏拓展程序中使用。
    
    ![](../Images/ed5da9a253076fba7398cfaaff5e15f4.png)
    

**10\. Get\_virus   ![](../Images/870ebb60cd5307fb5e7da5073efb8ac9.png)**

恶意进程，病毒识别工具。由@二郎不吃药 开发👏。

![](../Images/0a7a1f449c76177baeb5606b511071f3.png)
