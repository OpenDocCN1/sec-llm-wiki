![](../Images/daae73c5becd7a497b33b3a04a02537f.png)![](../Images/187427360ef1947d38152f29c41e2752.png)Goby 新增在线调试主题、漏洞实时通知、敏感文件及  Web 目录探测、域名备案信息查询功能等插件。  

## 0x001 新增插件  

#### **1. ****Custom Theme****   ![](../Images/531e4ddc5037979b753d3413f5387f81.png)**

在线调试主题，一键生成主题插件。

*   使用
    
    ![](../Images/7eb03dea327a9f798aeb3bae85ccd947.png)
    
    > 在线调试主题教学可翻阅文末视频。
    
*   配置插件相关信息  
    
    ![](../Images/4de599aaa7a2c8ab0c084b4c287ab4c5.png)
    
*   打开右侧工具栏点击插件入口
    
*   在打开的插件页面中调试主题，配置相关信息。
    
    ![](../Images/1d842098e0cde6709f6c5211c332ef71.png)
    
*   主题信息配置完毕之后点击Generate按钮生成主题插件
    
    ![](../Images/d6bbba7107e4acda8be8da4b90fd8e86.png)
    
*   登录Goby，点击上传插件，将生成的主题插件包上传等待审核即可。
    
    ![](../Images/01926e084766ea12e034d474c9a9f292.png)![](../Images/758098628c1c00df89f2d254756024d3.png)
    

#### **2.  ****Ding 助手  **![](../Images/93001661ba880654acd8792480d6c832.png)

当扫描任务进行过程中，将扫描发现的漏洞通知到钉钉：一人扫描，多人跟进。

*   设置钉钉机器人，在钉钉群里，智能群助手功能下添加自定义机器人。
    
*   在配置页面配置钉钉机器人webhook接口相关项，开启插件，接收通知。
    
    ![](../Images/72371ae7dc759b9e4707c42d71c59707.png)
    
*   测试钉钉机器人是否配置正确，如下图：
    
    ![](../Images/6de8a2d2082ba91860c1a18a5f6c04f0.png)
    
*   第一步：点击工具栏插件按钮
    
*   第二步：如果配置错误，则需要将第二步中回显的ip填入下图对应位置
    
    ![](../Images/dc636b865d7871bd7e6b523c55deb4fd.png)
    
*   成功则如下图，钉钉助手收到消息
    
    ![](../Images/e9571260f0b80bb82b10a600705113eb.png)
    
    ![](../Images/9b72b80035a7be531ebf6ac5d16f4780.png)
    
*   测试成功后就可以开始扫描了，扫描过程中钉钉群便会收到漏洞信息
    
    ![](../Images/f750819677e27be54b1cc98d93926447.png)  
    

#### **3\.  PanelScan****   ![](../Images/ee688f6a143653c43bff6b4054c2942b.png)**

对常见中间件、CMS、开源框架等管理地址及敏感文件进行探测。

*   在 IP 详情页面执行插件
    
    ![](../Images/eaee11bd791ebb707e9bf194ad7f5ec2.png)
    
*   在 webfinder 页面执行插件
    
    ![](../Images/785ecc310f13d8a68c465ba8cd22d7f7.png)  
    

#### **4\. dirsearch ****  ![](../Images/df5ed444d18eb581c4dfc12bbb3477d1.png)**

暴力破解Web服务器中的目录和文件。

*   部署dirsearch及相关依赖
    

*   
*   
*   
*   

```
    //git 获取 dirsearch    git clone https://github.com/maurosoria/dirsearch.git    //安装所需的 python 依赖    pip3 install -r requirements.txt
```

*   配置插件
    
    ![](../Images/4b629d11182a27ca679fe3a66a9c2951.png)
    
*   在IP详情页面或webfinder页面执行插件
    
      
    

#### **5. 站长之家-ICP查询 ****  ![](../Images/b5c3d19bf8a86297497c0790efa78866.png)**

用于查询域名的备案信息，方便蓝队的信息收集工作。

*   使用
    
    ![](../Images/17c16c7049ac371f072accff0296c9e2.png)
