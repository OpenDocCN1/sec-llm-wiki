# **开始**

接到任务，分析一恶意APP，涉嫌盗取用户通讯录、短信、定位信息，并对中招用户进行勒索。

# **分析APP**

使用AndriodKiller查看了下APP申请的权限![](../Images/d0dc97360fb5513bee370dedfb23b4de.png "62313-m7onh46i48.png")可以看到基本都是敏感度很高的权限，模拟器中打开APP。![](../Images/14508bc005e6908407ec4ae821f29a43.png "40946-vgihz31krb.png")APP除了当前能看到的无其他页面，推测应是恶意团伙在三方通讯软件中诱导用户安装。APP打开后立即读取了通讯录及短信记录并发起了上传。![](../Images/55a4a4c8a87e19941f7c920127eff44e.png "05725-3ssq1txkf3y.png")尝试XSS，未收到结果，访问APP后端域名，管理员账户弱口令admin/123456。![](../Images/242296335d33afa7ece2b678d4125454.png "61826-61o87hwto7h.png")![](../Images/7a9abd4caac17c633ded3eabbd0165db.png "81578-iascimv333.png")界面很简介，功能点不多，包括了查看通讯录，联系人、短信、定位，并且数据在源源不断的更新。

# **查找漏洞**

由于可操作的功能点不多，<>都进行了实体编码，查看手机号通讯录的位置找到了SQL注入，![](../Images/242ec690cbebf111e005709e2a7fc9da.png "06719-sodv3vhhkb.png")使用了SQLMAP进行了脱库（授权状态下进行）。![](../Images/6693b94fc5773d5165c33fcfda88f829.png "43310-7opxanpbonp.png")数据库中的一些短信内容,揭示了该团伙后续变现手法。![](../Images/2ec0ac8f3d2572bf96e353d2ad619268.png "00008-6ps4t4mldio.png")![](../Images/6f8a37a88779464d82e13ef9b07d3a1f.png "34651-yok6htnjd4o.png")由于数据库不是root权限，无读写权限，os-shell失败，放弃了这条路，Dirsearch尝试fuzz目录。![](../Images/de6d1bb353563bece951b0266c4ffc76.png "11979-9vy0uff5m9n.png")成功收获网站备份

# **代码审计**

网站整体代码质量不高，使用D盾扫了下危险函数，发现一处上传文件的代码。![](../Images/50539148729b3cf3fa7a6236ef4675d1.png "89209-etrmfnbiti.png")找到了fileupload.php文件,开始进行本地审计测试。![](../Images/1ed195e931480c7ab60d48de7057822c.png "21946-o89zgrodv5.png")这段代码并未校验cookie，同时需要传递一个name参数，作为文件名，之后一路向下![](../Images/412a2e75e042518a7d72b5eef274c2ac.png "68951-tv09d4j3sdp.png")只要不满足那一堆if就可以到达文件上传处，很明显正常传文件也不是那么容易满足这堆条件，因此写POC直接上传即可。
