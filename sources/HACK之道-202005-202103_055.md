# 从溯源到拿下攻击者服务器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwMzIyMjYzNA==&mid=2247489348&idx=1&sn=ef71e80e39d63bac17794997416033df&chksm=96d3ec41a1a465570593622c76a326076cfd925d0a5e317d1457e593d3ecb1bfc0e9cf59485c&scene=126&sessionid=1681667065#rd](http://mp.weixin.qq.com/s?__biz=MzIwMzIyMjYzNA==&mid=2247489348&idx=1&sn=ef71e80e39d63bac17794997416033df&chksm=96d3ec41a1a465570593622c76a326076cfd925d0a5e317d1457e593d3ecb1bfc0e9cf59485c&scene=126&sessionid=1681667065#rd)

**起因：**

朋友突然告诉我他的服务器被冲了，让我帮忙看下：

![](../Images/ac8120cf4adccf8951ddb04dbee4aee0.png)

**分析源文件：**

首先在服务器发现一个php文件，非常可疑。可疑到什么程度？朋友的站架设在bbs里面，但是在html目录下存在一个php文件：

![](../Images/4278bd3c4ab806f0156772e49dad0d63.png)

进入后查看：

![](../Images/60f18243776814e1707ffee437e16075.png)

打开后发现是小透明师傅之前的反序列化马：

![](../Images/a0b9330b7aa9420050b6b5c5d6033103.png)

具体链接如下：

http://www.f4ckweb.top/index.php/archives/7/

并且我觉得我朋友还有点弱智，他把他的ssh账号密码放到了网站根目录下面：

![](../Images/1908e7dcb08c15b19780e7cd9492f483.png)

不被搞才怪，查看历史：

![](../Images/1088e0297dd20ad95c58f01fc75e8840.png)

**开始反制：**

目标站点打开后：

![](../Images/7efc12a59a26b1292779abcd4c56ea30.png)

fofa一顿搜索后发现目标存在宝塔面板：

![](../Images/8edf9e4acec78fb1418352b7064827ff.png)

思索了一会得出结论，不好搞。只能从web入手，先收集指纹，运气比较好直接从cookie里知道目标指纹信息了：

![](../Images/392f620c852c1b462f62b128c28bb6fd.png)

onethink默认后台是/admin.php,但是这个站点把后台地址改掉了：

![](../Images/a1c416911b7020b35c1cc88a71bf3394.png)

只能通过日志进行判断，构造url：/Runtime/Logs/Admin/20\_12\_07.log

![](../Images/d91848ec1d8d882b6b81768798b403a5.png)

打开后台地址：

![](../Images/9e0d96143928203be2408c1ad11345ad.png)

登录框存在注入：

![](../Images/7ae04e30dcbaca2a846220b4cb9027b6.png)

构造好payload:

username\[\]=IN (‘a’) union select 1,2,’’,4,5,6,7,8,9,10,11,12 – &username\[\]=111&password=&verify=90  
成功绕过登录：

![](../Images/3f5d6f001f6183b2850c4f455c88fbad.png)

得还是个杀猪盘，能控制开奖：

![](../Images/910439c78e9cfb4dddaa5b856b3e5b8b.png)

找到目标创建插件的地方，得到目标后台Getshell：

![](../Images/9181fc09b3a9df528054238b20bb5c55.png)

成功getshell:

![](../Images/103ea9242e687160c99fdf28c04096fb.png)

**后渗透：**

使用Restorator 2018 修改资源后得到木马：

![](../Images/687bbb31f0305951eeaa2f8d7b52ced9.png)

在webshell上部署flash弹窗：

![](../Images/432c783508beded24e8391ccba2450dc.png)

登陆后会弹出提示：

![](../Images/c0b4fe598ae4c11da47d6fc283d8a9f6.png)

一觉睡起来得时候目标已经上线几次并且掉线了。。。

![](../Images/1ac794f1b2e008a9c2d41494e4e840d8.png)
