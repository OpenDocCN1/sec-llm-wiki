### 当前功能

*    ICMP并发探测存活IP
    
*    对A段只进行网关探测
    
*    集成Xray POC扫描
    
*    解析Xray POC V1模版
    
*    并发探测主机端口服务
    
*    并发探测主机服务弱口令
    
*    服务弱口令探测模块 支持 SSH
    
*    服务弱口令探测模块 支持 Mysql
    
*    服务弱口令探测模块 支持 Mssql
    
*    服务弱口令探测模块 支持 Mongodb
    
*    服务弱口令探测模块 支持 Oracle
    
*    服务弱口令探测模块 支持 FTP
    
*    服务弱口令探测模块 支持 SMB
    
*    服务弱口令探测模块 支持 Redis 未授权
    
*    自定义Password字典 自动合并到程序内置
