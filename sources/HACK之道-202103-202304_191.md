# toppwdhash

一款常见密码哈希离线查询工具，包含算法类型 ：'md5', 'md5x2', 'md5x3', 'sha1', 'ntlm', 'mysql', 'mysql5', 'md5\_sha1', 'sha1\_sha1', 'sha1\_md5', 'md5\_base64', 'md5\_middle'；支持单个查询、批量查询、模糊查询、明文密码哈希生成等，后续可能加入更多功能。
