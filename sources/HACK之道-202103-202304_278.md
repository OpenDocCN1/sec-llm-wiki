#### **0x00 简要说明**

百度百科：Redis（Remote Dictionary Server )，即远程字典服务，是一个开源的使用ANSI C语言编写、支持网络、可基于内存亦可持久化的日志型、Key-Value数据库，并提供多种语言的API。

Redis因配置不当可导致攻击者直接获取到服务器的权限。

*   利用条件：redis以root身份运行，未授权访问，弱口令或者口令泄露等
