附上windows常用变量

  1. %APPDATA% :  列出应用程序数据的默认存放位置。
  2. %CD% :  列出当前目录。
  3. %CLIENTNAME% :  列出联接到终端服务会话时客户端的NETBIOS名。
  4. %CMDCMDLINE% :  列出启动当前cmd.exe所使用的命令行。
  5. %CMDEXTVERSION% :  命令出当前命令处理程序扩展版本号。
  6. %CommonProgramFiles% :  列出了常用文件的文件夹路径。
  7. %COMPUTERNAME% :  列出了计算机名。 
  8. %COMSPEC% :  列出了可执行命令外壳（命令处理程序）的路径。
  9. %DATE% :  列出当前日期。
  10. %ERRORLEVEL% :  列出了最近使用的命令的错误代码。
  11. %HOMEDRIVE% :  列出与用户主目录所在的驱动器盘符。
  12. %HOMEPATH% :  列出用户主目录的完整路径。
  13. %HOMESHARE% :  列出用户共享主目录的网络路径。
  14. %LOGONSEVER% :  列出有效的当前登录会话的域名控制器名。
  15. %NUMBER_OF_PROCESSORS% :  列出了计算机安装的处理器数。
  16. %OS% :  列出操作系统的名字。(Windows XP 和 Windows 2000 列为 Windows_NT.)
  17. %Path% :  列出了可执行文件的搜索路径。
  18. %PATHEXT% :  列出操作系统认为可被执行的文件扩展名。 
  19. %PROCESSOR_ARCHITECTURE% :  列出了处理器的芯片架构。
  20. %PROCESSOR_IDENTFIER% :  列出了处理器的描述。
  21. %PROCESSOR_LEVEL% :  列出了计算机的处理器的型号。 
  22. %PROCESSOR_REVISION% :  列出了处理器的修订号。
  23. %ProgramFiles% :  列出了Program Files文件夹的路径。
  24. %PROMPT% :  列出了当前命令解释器的命令提示设置。
  25. %RANDOM% :  列出界于0 和 32767之间的随机十进制数。
  26. %SESSIONNAME% :  列出连接到终端服务会话时的连接和会话名。
  27. %SYSTEMDRIVE% :  列出了Windows启动目录所在驱动器。
  28. %SYSTEMROOT% :  列出了Windows启动目录的位置。
  29. %TEMP% and %TMP% :  列出了当前登录的用户可用应用程序的默认临时目录。
  30. %TIME% :  列出当前时间。
  31. %USERDOMAIN% :  列出了包含用户帐号的域的名字。
  32. %USERNAME% :  列出当前登录的用户的名字。
  33. %USERPROFILE% :  列出当前用户Profile文件位置。
  34. %WINDIR% :  列出操作系统目录的位置。 
  35. [/size][/align][align=left][size=3]变量 类型 描述 
  36. %ALLUSERSPROFILE% 本地 返回“所有用户”配置文件的位置。 
  37. %APPDATA% 本地 返回默认情况下应用程序存储数据的位置。 
  38. %CD% 本地 返回当前目录字符串。 
  39. %CMDCMDLINE% 本地 返回用来启动当前的 Cmd.exe 的准确命令行。 
  40. %CMDEXTVERSION% 系统 返回当前的“命令处理程序扩展”的版本号。 
  41. %COMPUTERNAME%  系统 返回计算机的名称。 
  42. %COMSPEC%  系统 返回命令行解释器可执行程序的准确路径。 
  43. %DATE%  系统 返回当前日期。使用与 date /t 命令相同的格式。由 Cmd.exe 生成。有关 date 命令的详细信息，请参阅 Date。 
  44. %ERRORLEVEL%  系统 返回上一条命令的错误代码。通常用非零值表示错误。 
  45. %HOMEDRIVE%  系统 返回连接到用户主目录的本地工作站驱动器号。基于主目录值而设置。用户主目录是在“本地用户和组”中指定的。 
  46. %HOMEPATH%  系统 返回用户主目录的完整路径。基于主目录值而设置。用户主目录是在“本地用户和组”中指定的。 
  47. %HOMESHARE%  系统 返回用户的共享主目录的网络路径。基于主目录值而设置。用户主目录是在“本地用户和组”中指定的。 
  48. %LOGONSERVER%  本地 返回验证当前登录会话的域控制器的名称。 
  49. %NUMBER_OF_PROCESSORS%  系统 指定安装在计算机上的处理器的数目。 
  50. %OS%  系统 返回操作系统名称。Windows 2000 显示其操作系统为 Windows_NT。 
  51. %PATH% 系统 指定可执行文件的搜索路径。 
  52. %PATHEXT% 系统 返回操作系统认为可执行的文件扩展名的列表。 
  53. %PROCESSOR_ARCHITECTURE%  系统 返回处理器的芯片体系结构。值：x86 或 IA64（基于 Itanium）。 
  54. %PROCESSOR_IDENTFIER% 系统 返回处理器说明。 
  55. %PROCESSOR_LEVEL%  系统 返回计算机上安装的处理器的型号。 
  56. %PROCESSOR_REVISION% 系统 返回处理器的版本号。 
  57. %PROMPT% 本地 返回当前解释程序的命令提示符设置。由 Cmd.exe 生成。 
  58. %RANDOM% 系统 返回 0 到 32767 之间的任意十进制数字。由 Cmd.exe 生成。 
  59. %SYSTEMDRIVE% 系统 返回包含 Windows server operating system 根目录（即系统根目录）的驱动器。 
  60. %SYSTEMROOT%  系统 返回 Windows server operating system 根目录的位置。 
  61. %TEMP% 和 %TMP% 系统和用户 返回对当前登录用户可用的应用程序所使用的默认临时目录。有些应用程序需要 TEMP，而其他应用程序则需要 TMP。 
  62. %TIME% 系统 返回当前时间。使用与 time /t 命令相同的格式。由 Cmd.exe 生成。有关 time 命令的详细信息，请参阅 Time。 
  63. %USERDOMAIN% 本地 返回包含用户帐户的域的名称。 
  64. %USERNAME% 本地 返回当前登录的用户的名称。 
  65. %USERPROFILE% 本地 返回当前用户的配置文件的位置。 
  66. %WINDIR% 系统 返回操作系统目录的位置。
  67. %allusersprofile%--------------------所有用户的profile路径
  68. %Userprofile%-----------------------当前用户的配置文件目录
  69. %Appdata%--------------------------当前用户的应用程序路径
  70. %commonprogramfiles%-------------应用程序公用的文件路径
  71. %homedrive%------------------------当前用户的主盘
  72. %Homepath%------------------------当前用户的主目录
  73. %programfiles%----------------------应用程序的默认安装目录
  74. %systemdrive%----------------------系统所在的盘符
  75. %systemroot%-----------------------系统所在的目录
  76. %windir%----------------------------同上，总是跟systemroot一样
  77. %tmp%------------------------------当前用户的临时目录
