## 0x03入口突破;;’

首先对目标进行端口扫描，获取入口点：`nmap -T4 -sC -sV 192.168.52.20`![](../Images/f063fe1dcfbe314ad1147a3d41a695c8.png)发现开放22端口与8000,访问8000,发现是一个Laravel的网站。![](../Images/504599b83360e68235bc6c2c6620f38a.png)而这个版本的框架是存在一个rce漏洞的，即`Laravel <= v8.4.2 debug mode: Remote code execution (CVE-2021-3129)`。使用POC测试，发现的确可以成功利用使用一键化工具，写入一个webshell进去就行啦，蚁剑连接：![](../Images/2ab6815405809d7ddeee4624756dd57d.png)进入终端时发现，主机信息处有些特殊：`Linux 8e172820ac78 4.4.0-142-generic #168~14.04.1-Ubuntu SMP Sat Jan 19 11:26:28 UTC 2019 x86_64`猜测可能是docker环境，一般来说有以下两个方法：

1.  判断根目录下 `.dockerenv` 文件
2.  查询系统进程的`cgroup`信息

发现的确为docker环境![](../Images/b3852e66f800fa301f2c27530bf8fd4e.png)

## 0x04 docker逃逸

下面我们要做的就是docker逃逸了，不过目前我们仅仅是一个www权限，所以来进行提权。看了看版本信息，且目标机器存在gcc,此时我们完全可以使用内核提权![](../Images/fa4d7fc2136366cccba999949792fdbd.png)不过根据靶机的信息，我们这里也使用suid的方法进行提权。查找SUID提权的命令如下：`find / -user root -perm -4000 -print 2>/dev/null find / -perm -u=s -type f 2>/dev/null find / -user root -perm -4000 -exec ls -ldb {} ;`![](../Images/7c2bfa944fa2cb904ac20a7e9fbfdca9.png)发现存在一个shell程序，尝试运行该文件![](../Images/f8a0ae0f842a00cbecfa248cc75b581b.png)发现其就是在执行ps命令而已，此时我们可以使用路径劫持的方法，来获取一个高权限的shell,首先使用蚁剑反弹一个shell回来然后替换环境以获取到了一个root的shell.这里可以直接获取一个Cs的shell回来或者是MS的shell.![](../Images/0a5525821d9e28a0bd924944e633d8a0.png)这里为了方便起见，就没有在root的环境下获得会话。下面就是docker逃逸了，在之前我打类似的靶机的时候也遇到docker逃逸的情况，一般使用漏洞进行逃逸或者使用特权模式进行逃逸，我们这里使用特权模式进行逃逸。即当控制使用特权模式启动的容器时，docker管理员可通过mount命令将外部宿主机磁盘设备挂载进容器内部，获取对整个宿主机的文件读写权限，此外还可以通过写入计划任务等方式在宿主机执行命令。此时查看设备时，会发现拥有很多的设备。![](../Images/f00a020d9f1b26a7d3e8963b4ba992ca.png)然后新建目录并挂载目录：`mkdir /abc mount /dev/sda1 /abc`  
最终我们可以通过访问容器内部的/abc路径来达到访问整个宿主机的目的：`ls /abc`![](../Images/baf73df305da9be7b440796c4f941fe3.png)下面就是写文件或者写计划任务上线即可。![](../Images/b959a8891cd2997dbfc0c3fd799545d5.png)顺便获得了密码文件的内容。通过查看网卡信息，发现后面的`192.168.93.0`的网段以及本网段`192.168.52.0`,下面就是横向移动了。![](../Images/69f3f5dc490a0fd98499f71fa914fa16.png)

### 0x05内网横向

因为是上线的Cs所以我们很多操作不是很方便操作，所以我们先对`192.168.52.0`来进行测试，直接一个ping获取本网段的存活主机信息(可能不是很准确)`for k in $( seq 1 255);do ping -c 1 192.168.99.$k|grep "ttl"|awk -F "[ :]+" '{print $4}'; done`但是毫无反应，没关系，我们直接搞个sockets代理进去。![](../Images/6d6c43edcc7dabf5b0da7d65ef1b15bb.png)发现目标网段内具有30这个主机，我们再对其进行信息收集。发现其开放了8082端口访问之，发现是一个OA系统![](../Images/fd736868cfe2f603237be71bd5fc8797.png)下面就好说了，拿shell就可以了。首先伪造session登录后台。![](../Images/d307cde75423544dc03cff7668f4cbfc.png)然后附件添加一个存储![](../Images/a71444574af75d2d11cb9ce195327c5b.png)选择 组织-管理员-附件上传-txt，抓包修改![](../Images/95992ea6d12f7265276a0c5d752e517f.png)抓包修改，绕过黑名单 txt修改为 php.挂好代理，蚁剑成功连接![](../Images/6cd6eeb9e4d5785d571b204e9be3a26f.png)但此时我们是无法执行命令的，因为有杀软的缘故，我们执行命令会被拦截![](../Images/7d5348d645b887b9198e2124a4da02be.png)绕过方法就是使用自定义终端  
![](../Images/986bad74fc62f682242d1d33e27d7569.png)然后我们就可以执行命令了，因为第二个网段是出网的，所以直接powershel上线即可然后就是提权、抓密码一条龙![](../Images/310bc97f8748c3c2ad1c9b270d5de33b.png)

### 0x06获取域控

而且因为该机器使用域管理员来启动ＯＡ的缘故，机器上也存在域管信息，直接拿到域管密码。![](../Images/410d5df80a62ed98123c0a8367f938bb.png)通过`net view`发现其93段下面的其他机器![](../Images/365e54bafc44bfdd7d285f94db42951d.png)发现DC字样，因为我们已经有了域管的密码，直接横向过去![](../Images/73c0dd1e7db9ca292e616fb7a5e056d0.png)均失败，没关系我们使用`net use`来做，尝试关闭它的防火墙，然后再横向。![](../Images/34fd977153e30126b617654ebc4b5862.png)拿下域控。然后我们继续横向下一台机器，因为有火绒的存在，我们没有办法直接横向过去，我们选择使用`net use`的方法把我们的免杀马复制过去，然后在获取session。![](../Images/ab8232e9a07eb4b0f58f7e7bbc5168c9.png)至此整个域已经拿下。导出信息，方便以后学习。![](../Images/ba0e7a4606e7ebf120f18c1cad9d4869.png)转载于补天平台（白名单）![](../Images/765650245461ede31c9c447db97625b4.png)●[干货|渗透学习资料大集合（书籍、工具、技术文档、视频教程）](http://mp.weixin.qq.com/s?__biz=MzIwMzIyMjYzNA==&mid=2247490892&idx=2&sn=5820f8871f23ffc525a27e1c6ae1ae4c&chksm=96d3e649a1a46f5f88051b88fb05efd4cda4c885a4f47ac63795354cbfe5e3a93de747f3f10a&scene=21#wechat_redirect)
