# 实战 | 记一次Spring boot任意文件上传

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5MDU1NDk2MA==&mid=2247511734&idx=1&sn=440ab14fec0095dacdf8ec5e09e0394c&chksm=ec1cfb89db6b729fe00e4e6d0391eaaf694827bb9140156b357a7340e90352a6d2cb11089ae2&scene=126&sessionid=1681665974#rd](http://mp.weixin.qq.com/s?__biz=MzI5MDU1NDk2MA==&mid=2247511734&idx=1&sn=440ab14fec0095dacdf8ec5e09e0394c&chksm=ec1cfb89db6b729fe00e4e6d0391eaaf694827bb9140156b357a7340e90352a6d2cb11089ae2&scene=126&sessionid=1681665974#rd)

前提：

在一次项目中获取了一套通用系统

框架是Spring boot

启动是War包启动

之前拿是通过替换私钥拿的，但小部分还是没开公钥登录

![](../Images/be46ce375ccec4b3f3b4774b791dae1a.png)

这时候就有人说为什么不通过写在定时任务反弹shell

也试过，不会返回，所以这个方案就取消了

![](../Images/1d5e7c1d4b3b296aa16e5ab7fb202c94.png)

咋不直接上传，因为上传的文件是到另外一个端口，而且不解析

![](../Images/ab3ef8aa331d3c3bd6366e91e33437bb.png)所以就想到一个另外的思路，由于这套是通用的，包括他们安装目录也一样

替换他们的war包,先下载他们的war包

![](../Images/0c1cedef7054a325dc1ac8177164a2be.png)

![](../Images/bddc8da3d346210dd0d77c8af521e9c5.png)

把war用压缩格式打开，然后添加马子

![](../Images/2202cc56388c13356a14f599c9e00180.png)然后直接用burp上传抓包不太行，如图，会内容太大不显示，因为我们还是通过跨目录上传

![](../Images/f2ae29b056a90ab22f0fec060fafe221.png)所以写了个脚本

*   
*   
*   
*   

```
1.上传替换2.要定时任务执行kill杀死当前进程 pkill -f ***.war3.要启动war项目java -Dfile.encoding=utf-8 -jar ***.war --spring.config.location=application.properties
```

通用直接写脚本梭哈

![](../Images/47198092dac59db595f5164c0a1d28c9.png)这里脚本是设置了代理，看看返回的包

![](../Images/b63f97bf6c76f6f593ddf6f0178c992a.png)显示是上传成功，看看web项目

![](../Images/46f431f1f68871256e62d7f61a51a194.png)如果直接替换，不重启war包是没效果的，如图

![](../Images/a49fce1cc7d3dd256cfc60ef26a5bf82.png)总结：

实战没用，只是说对于通用系统，部分利用的点不能利用的情况下，可以这样弄。所以个人觉得鸡助。
