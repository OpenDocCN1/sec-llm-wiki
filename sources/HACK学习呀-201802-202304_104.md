# 漏洞利用

HackerOne 用户 deboc0n 向 Cloudflare 提交了一份报告，描述了https://sub.cloudflare.com域上的 CVE-2022–32409。

本地文件包含 (LFI) 在 OWASP 的 2021 年 10 大安全列表中被列为“最严重的 Web 应用程序安全风险”。

从本质上讲，导致此类弱点的错误允许攻击者通过精心设计的 HTTP 请求执行任意 PHP 代码。
