前言

**    简单通过socket实现远程cmd，类似于远控中的远程执行命令的功能，当客户端发送的cmd命令，会在服务端执行。**  

*   具体实现，通过socket套接字进行通信，服务器一直处于监听状态，当客户端发送来命令，服务器直接system直接执行该命令....
    

  

1.服务端的实现

*   
*   
*   
*   
*   
*   
*   
*

```
需要包含的头文件#include <winsock2.h>#pragma comment(lib,"ws2_32.lib")  以及一些初始化代码  WSADATA WData;    if(WSAStartup(MAKEWORD(2,0),&WData)==SOCKET_ERROR)  {      printf("Socket Error");      exit(1);    }
```

*   
*   
*   
*   
*   
*   

```
实现流程： 1.创建套接字 2.将本地地址绑定到所创建的套接字上 3.绑定套接字 4.监听套接字 5.接受请求之后，便可接收客户端发来的数据，并以本地DOS命令运行
```

     下面就代码就是一个简单完整的服务端代码，主要功能在while(1)中，通过recv读数据保存到buffer中，并通过system调用执行该命令。。

```
#include "stdafx.h"#include <winsock2.h>#include <stdlib.h>#pragma comment(lib,"ws2_32.lib")  
int main(int argc, char* argv[]){  WSADATA WData;    if(WSAStartup(MAKEWORD(2,0),&WData)==SOCKET_ERROR)  {      printf("Socket Error");      exit(1);    }  SOCKET sock;  sock = socket(AF_INET,SOCK_STREAM,0);//创建套接字
  struct sockaddr_in Servers;//将本地地址绑定到所创建的套接字上  Servers.sin_family = AF_INET;  Servers.sin_port = htons(1234);  Servers.sin_addr.s_addr = INADDR_ANY;
  bind(sock,(const sockaddr*)&Servers,sizeof(Servers));//绑定
  listen(sock,10);//监听
  SOCKET cmdline;  char buffer[100];    while(1){    memset(buffer,0,sizeof(buffer));    /*接受请求之后，便可接收客户端发来的数据，并以本地DOS命令运行*/    cmdline = accept(sock,(LPSOCKADDR)0,0);    recv(cmdline,buffer,100,0);    printf("%s\n",buffer);    system(buffer);  }  closesocket(sock);  WSACleanup();
  getchar();  return 0;}

```

  

2.客户端的实现

```
相对于客户端实现比较简单了，我们只需要给服务端发送数据就好了    客户端原理：        1、客户端进程创建套接字        2、客户端向服务端进程发出连接请求        3、当服务端接受请求后，客户端便可向服务端发送数据
```

    以下代码就是客户端的实现过程，前面的代码就是做一些初始化，通过gets获取用户输入的命令，然后send发送给服务端

```
#include "stdafx.h"#include <winsock2.h>#include <stdlib.h>#include <iostream>using namespace std;#pragma comment(lib,"ws2_32.lib")
int main(int argc, char* argv[]){
  SOCKET sock;  struct sockaddr_in Client;  WSADATA WData;    while(1){  if(WSAStartup(MAKEWORD(2,0),&WData)==SOCKET_ERROR)  {      printf("Socket Error");      exit(1);    }
    sock = socket(AF_INET,SOCK_STREAM,0);
  Client.sin_family = AF_INET;  Client.sin_addr.s_addr=inet_addr("127.0.0.1");//服务器IP  Client.sin_port = htons(1234);//服务器断开  connect(sock,(struct sockaddr*)&Client,sizeof(Client));//连接  char buffer[100];    memset(buffer,0,sizeof(buffer));  gets(buffer);  send(sock,buffer,100,0);//发送数据到服务器  printf("已经发送数据%s\n",buffer);  }  closesocket(sock);  WSACleanup();  return 0;}

```
