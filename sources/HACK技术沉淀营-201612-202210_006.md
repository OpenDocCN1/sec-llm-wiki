## 0x00 痛点分析 

团队协作文档编辑工具，有很多，类似著名的TX文档、shimo文档等，但是这些都会连接外网，不够保密。

平时在做项目时希望有一个私有环境下的团队协作编辑文档的环境，同时能够很方便地搭建，不依赖服务器在个人电脑上就能搭建。

## 0x01 CodiMD 

https://github.com/hackmdio/codimd

`CodiMD` 是一个开源项目，可实现 `MarkDown` 文档的协同编辑，功能与 `HackMD` 一致，用于实时在线协作编辑，非常适合需要多人合作记录重点信息的情况，部署极为简单，一台`Linux`虚拟机就可以安装成功。

## 0x02 CodiMD安装部署 

### 前期准备

使用`centos`、`ubuntu`均可，需要安装`docker`和`docker-compose`，记得关闭防火墙。

### 项目部署

https://github.com/hackmdio/codimd

官方文档介绍了多种部署方式，其中`docker`部署最为快捷，本文介绍此场景下部署`codimd`的流程。

之前的老教程多数会使用本地的数据库，最新的`docker`部署方式已经不需要自己创建数据库，可拉取一个`postgreSQL`数据库镜像作为替代，我们只需要创建并编辑一个`docker-compose.yml`。

```
version: "3"

"database-data:/var/lib/postgresql/data"

false

"3000:3000"


```

![](../Images/e3e5ef919308f4b33431f99b0fbc19ac.png)

接着运行`docker-compose up -d`

等待镜像拉取完毕并运行，使用以下命令查看运行状态

```

docker logs -f -t --tail 10  <codimd_container_id>
```

![](../Images/e4d004986452402914eefbec94169827.png)

访问虚拟机地址的3000端口，出现下面的页面成功。

![](../Images/95c4f923ce4b40e1f188a67b23c4f19a.png)

### codimd更新

可以通过查看项目版本号，来更改`docker-compose.yml`中`image`的版本号。

![](../Images/1bd19b18a0adf37149174bbb7a7e9b3d.png)

### codimd使用

1、点击登录，随便输入邮箱密码，点击注册。

![](../Images/a666d514c2b5d7d7c51b2bc80feb40c0.png)

2、成功注册后登录，点击新建笔记，

![](../Images/8a61f4f62c8659a37f71a35a69a277c7.png)

3、就可以十分便捷地书写`md`文档了，如果需要团队编写，直接将`url`发给团队即可。其他协作者可以放心大胆地使用，后台密码均进行了严格加密，密码防泄漏做得很好的。再说了，这是部署在内网中的，无所谓了。

![](../Images/4cc573976c18c4b5319376e15eeaf3d6.png)

4、随后导出，在弹出的网页按`ctrl+s`即可保存文件。

![](../Images/5b9c645be666e7c078762251023aebd5.png)
