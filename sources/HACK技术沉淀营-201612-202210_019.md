## 0x01 Kali录屏 

在渗透过程中，有时候需要录屏来记录我们的一举一动，但是各种录屏软件都不太好使，这里介绍一个kali中自带的录屏工具。

#### 命令行输入

```


recordmydesktop
```

如果需要录制声音，需要kali中带有声卡，我这里去掉了声卡，就用后者了。

![](../Images/fda703867eee944d4ec07683199d2b77.png)

录制出来的格式默认是`ogv`的，可以更改后缀成为`mp4`或者`mkv`

#### 注意

如果出现下面视频画面撕裂的问题：

![](../Images/60bf4ea37bb916856df1659d048c9fe4.png)

需要**将虚拟机****全屏****再进行录制**。

![](../Images/142ec2296500537691f1dfe68643954c.png)

## 0x02 Armitage 

> Armitage说白了就是MSF的图形化。如果你不想敲那么多命令，可以用这个。而且说实话这个工具logo长得实在是像CS，工具界面也很像，简直和CS是一对情侣。。

![](../Images/8338ac4634ae49e17f7e7953605bd62d.png)

### 工具安装

需要依赖MSF启动postgresql数据库

```


apt-get update 
```

![](../Images/55578b4efa4321c535e7689c25522b58.png)随后提示开启MSF的RPC，默认yes就行。

![](../Images/c7b783e9a1c177c00853fa9344f86e81.png)界面如下：

![](../Images/698336565fd22fcc6cfed4880456f2b8.png)可以看到很清晰地展示出了MSF的各大模块与其中的内容，说实话用了msf这么长时间，里面的内容都不如这个GUI界面来地直观，一目了然。

### Armitage简单使用

在上方的`Hosts`模块中可以找到有很多扫描方式，我这里用`Nmap Scan`进行演示

![](../Images/8ad4a2ab9b710d4acd2fe1c5b2d6a0c8.png)

MSF Scans就是调用了MSF对应的扫描模块

![](../Images/87658089404648914eb7e08b77f4847d.png)

随后扫出来之后可以在目标地址处看到目标

![](../Images/9b83a37caf704bcf5ddb12b45f3c55f1.png)

之后可以加载攻击模块进行相关攻击渗透，具体不再演示。

![](../Images/0dafee915eacdcda7e4f698fc5ef9ea9.png)
