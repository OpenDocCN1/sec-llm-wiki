我们现在想写一个程序，运行后能让程序窗口不断缩小

MFC与窗口句柄简单理解

窗口句柄是windows系统中有很多的窗口的唯一标识符，用于标识每一个窗口。说白了就是windows中运行的所有窗口的ID身份证号。

那么怎么定义呢，int a是让a变量来保存一个整型；那么窗口就是HWND a。

辅助理解

MFC(Microsoft Foundation Classes)是微软基础类库的简称，是微软的一个c++类库，主要封装了大部分的win32 API函数

其实就是说，微软帮我们封装好了很多的类与函数来让我们方便调用，不必要非得实现所有的功能，会更让我们去考虑代码的逻辑而不是重复的动作。

这种思想与python的库很类似，利用python编写程序的时候很多情况下都是直接调用别人写好的类似socks、requests库，subprocess库、内置的os库等等，而不需要去完成复杂重复的更底层的代码。那么这个HWND就是一个类似很方便的调用窗口句柄的类。

回到程序中，我们想要调用HWND，就需要引入一个头文件，#include <windows.h>，如下HWND a就是定义了一个a

#incude<stdio.h>#include<window.h>int main(){ HWND a; a = ?    return 0;}


现在给a进行赋值。a是一个窗口句柄，比如我怎么获取VX的窗口句柄呢？

方法一：通过spy++获取

VStudio里面有一个工具，Spy++，就可以获取当前系统的所有窗口句柄。

点开后发现里面有一大堆的窗口，点击上面这个望远镜图标，就是用来搜索窗口句柄的。

拖动这个瞄准镜一样的图标到VX上，就能获取，我这里VX的窗口句柄是00120E9E。

就可以将这个句柄放入到代码中：

#incude<stdio.h>#include<window.h>int main(){ HWND a; a =HWND(0x00120E9E); //注意这里前面加了0x，十六进制    return 0;}

方法二：利用FindWindow函数

刚才我们看到这个spy工具的窗口搜索中，有三个元素：句柄、标题、类名称。第一种方法是直接将句柄这个字段赋值给了a

还可以通过一个函数FindWindow(字面意思就是找窗口)来获取对应程序的窗口句柄。

FindWindow(L"类名称",L"标题")，也就是将上面获取的类名称和标题名填入函数对应的位置上，如下：

#include <stdio.h>#include <windows.h>int main(){    HWND a2;    a2 = FindWindow(L"WeChatMainWndForPC",L"WeChat");     eturn 0;}

我们给return 0这里加一个断点，调试可以看到，数值是一样的。

两种方法的区别

注意刚才我的VX窗口句柄是00120E9E，我重启一下句柄就会发生变化，但是标题和类名称还是这些个字符。

所以一般情况下，我们选择第二种方法来获取某个窗口的窗口句柄。

窗口不断缩小恶搞程序

获取到窗口的句柄，我们做神马？

类似FindWindow函数还有下面这些，根据英文字面意思就能明白是干什么的了，这就是MFC帮我们封装的功能，很方便。

MoveWindow()//移动窗口UpdateWindow()//更新窗口ShowWindow()//展示窗口CreateWindow()//创建窗口

现在来用一个MoveWindow()来实现某些功能。

MoveWindow(a2，500,400,10,10,true)//a2参数为hwnd窗口句柄//500与400为坐标//10为大小//true为重绘

综合这个函数，写出下面的代码并运行，发现我原先全屏的VX，变成了小窗口。按理说大小为10可以更小，但是VX有限制，最大就是700与500左右，我们可以通过截图软件来查看大小。

#include<stdio.h>#include<windows.h>int main() { HWND a2; a2 = FindWindow(L"WeChatMainWndForPC", L"WeChat"); MoveWindow(a2, 500, 400, 10, 10, true); return 0; }

同样的方法，可以测试一下别的窗口，比如Notepad++的窗口，可以看到就这么小了。。可能会有疑问说我明明设置的是一个正方形，怎么出来个长方形呢。

这是因为真正的窗口大小不是我们肉眼看到的大小，有一定的隐藏范围。


那么我们就可以简单地设计一个小程序，当用户点击1的时候，窗口逐渐变小；输入2的时候窗口逐渐变大。

 #include<stdio.h> #include<windows.h> int main() {  HWND a2;  a2 = FindWindow(L"Notepad++", L"*new 14 - Notepad++ [Administrator]");  printf("1.变小\n");  printf("2.变大\n");  int choice;  scanf_s("%d", &choice);  int x = 500;  int y = 500;   switch (choice) {  case 1:  while(y>10)  {  MoveWindow(a2, 600, 600, x -= 1, y -= 1, true);  }  case 2:  while (y < 1000)  {  MoveWindow(a2, 600, 600, x += 1, y += 1, true);  } }  return 0; }
