0x00 友情提示

这次的靶场就比较有意思了，纯黑盒测试。而且难度相比之前较大。

涉及到的知识点很多，因为篇幅较长，分两部分写哈。

http://vulnstack.qiyuanxuetang.net/vuln/detail/5/

目标：域控中存在一份重要文件。

本次环境为黑盒测试，不提供虚拟机账号密码。

0x01 环境搭建

同样的下载虚拟机，打开后不要开机。一定要先给每个虚拟机打一个快照。

新建一个仅主机vmnet5，网络段为192.168.93.0/24，此网段为内网网段。再新建一个vmnet6，模拟外网，网段任意。

机器开机

WEB(Centos)：将机器开机，更改为vmnet5后service network restart重启网卡。

WEB-1(Ubuntu)：开启后更改网卡为vmnet5

Win2012：开启后会提示15分钟内重启，不要担心，在15分钟内更改网卡为vmnet5并看ip能不能ping通就行了。

Win2008：开启后更改网卡为vmnet5

PC(Win7)：开启后更改网卡为vmnet5即可

0x02 外网渗透

已知Centos机器为WEB服务器，IP为192.168.1.110

一、端口与目录扫描

实战不要养成上来就端口与目录扫描的习惯哦，容易打草惊蛇。

python3 dirsearch.py -u http://192.168.1.110 -e* -x 301nmap -Pn -sT -p 1-1000,1080,3306,3389,6379,27017,8080,8888 192.168.1.110

二、4个攻击思路

1、爆破22与3306端口

前提是目标开启了数据库外连接。这里附上我常用的hydra爆破命令，爆破失败

hydra -L username.txt -P password.txt ssh://192.168.1.100 -I -f -t 16 -e ns -vV  #ssh改成对应要爆破的服务即可

2、访问页面找WEB常见漏洞功能点

如注入、登录框、包含、命令执行、SSRF等。

3、漏扫Joomla CMS

因为joomla CMS是国外三大著名CMS——wordpress、joomla、dupal之一，所以知名度较高，被黑客青睐导致漏洞较多，工具也多这里推荐几个。

1) 可以尝试使用msf的joomla模块

2) 可以尝试searchslpoit，寻找利用的加载到msf中

3) 可以用kali自带的joomscan工具，apt安装后可以用来信息收集
joomscan -u http://192.168.1.110

4、访问扫出来的所有目录，寻找后台与敏感信息

这里注意，访问页面一定要看源代码，不但有意外收获，而且我见过sql注入回显与页面颜色是一致的情况，而所有情况在源代码下都会暴露无遗。

通过访问相应码为200的1.php文件，发现了这是一个phpinfo文件，通过结合其他信息收集发现这个1.php所展示的内容是真的。省得我们去信息收集了。

还有一个README.txt，得知了joomla版本为3.9

同时在这里，我们发现了连接数据库的账号密码，有乱码我们用火狐浏览器依次按alt、v、c即可恢复正常。

其实还有一个小技巧，就是网站后面加个readme.txt，我们也可以将这个readme.txt加入dirsearch的字典中。

二、连接数据库getshell

连接数据库分为命令行连接和工具图形化连接，命令行链接，当然前提肯定是开启了数据库外连接。

mysql -u testuser -h 192.168.1.100 -p #按下回车后输入密码

图形化工具可用Navicat等

对于连接数据库getshell的方法有很多，这里列举几个：

1、通过日志写入webshell

show variables like '%general%';set global general_log = 'ON';

2、通过慢日志写入webshell

show variables like '%slow%';set global slow_query_log = 'ON';

3、修改or新建管理员账号密码进入后台

这里就推荐使用图形化工具来找了，通过命令行很麻烦。通过查找发现两张表存在账号：am2zu_users和umnbt_users。而且看到密码都是带盐值加密的，估计是CMS特有的加密方式，去MD5破解也不成功。于是尝试添加一个用户。到这里注意，添加用户的语句不要自己去编写，要按照CMS的格式来，介绍个小技巧如下图，然后更改一下账号和密码就行。

或者直接点击下面这个加号直接添加一行记录。

但是出了个问题，就是无法添加明文密码的账号，必须是加密的。遇到这种情况要么百度查Joomla账号密码加密方式，要么自己下载joomla源码进行代码审计。我果断选择前者[狗头]！

然后再替换密码之前，先保存原先的密码，记录一下，等我们写入一个木马之后替换回去就行。我这里尝试着替换了一下admin账号的密码，登录不进去，但是administrator的账号登录成功。

随后登录到joomla后台，这个错误不用去管，没事儿，已经成功登录了。点击这个扩展，选择Templates模板模块。


随后任意选择一个，我这里选择的第一个模板。

进入后两种思路，要么直接在index.php中插入一句话木马，不过这个方法可能会有一定的错误，如果插入一句话访问此文件发现500响应码，说明插入的内容影响了文件整体，需要更改一下这个木马的位置。实在不行，直接将index.php滞空替换成一句话也可以，只不过不建议，毕竟过于粗暴。。。

要么新建一个文件，例如404.php，内容为一句话木马或者冰蝎木马都行。我这里选择前者。

给index.php写入了木马后，就要去寻找index.php文件的路径，如果找不到，只能用新建文件了。结合刚才扫出来的目录，以及页面js信息，推断出index.php的路径为/templates/beez3/index.php

链接蚁剑成功

但是不能使用命令，直觉告诉我命令执行函数被禁止了。

首先我们要知道，蚁剑的虚拟终端原理，就是利用php的命令执行函数调用系统api进行操作的。所以遇到这种情况，极大可能为命令执行函数被禁止了。

回过头来看phpinfo文件信息，可以看到确实明确禁止了命令执行函数，限制地很严格。

三、Bypass disable_functions思路

1、黑名单绕过

这里就算了，几乎全被禁止了。

2、根据系统使用管道符、变量符号等绕过

当然在这里也不适用。

3、上传可执行文件直接运行

例如Linux上传ifconfig.c文件编译运行，windows上传cmd.exe运行等。但是这里也不适用，略显麻烦。

4、利用环境变量LD_PRELOAD绕过

简单说就是在Linux中的DLL文件来调用一些函数从而实现某些功能，我们可以用这个LD_PRELOAD环境变量来改变函数调用的优先级甚至替代原本的函数，类似于实现一个自定义函数，很像UDF提权的手法。可以称之为系统变量劫持函数来绕过disable_functions。

https://github.com/yangyangwithgnu/bypass_disablefunc_via_LD_PRELOAD

我们下载这两个文件，然后通过蚁剑上传

使用方法我们其实可以在下载的bypass_disablefunc.php里面查看到。

#cmd:执行的命令#outpath:读写权限目录#sopath:so文件的绝对路径例子：http://site.com/bypass_disablefunc.php?cmd=id&outpath=/tmp/xx&sopath=/var/www/html/bypass_disablefunc_x64.so

通过上面的使用方法，执行下方命令成功绕过。

http://192.168.1.110/templates/beez3/bypass_disablefunc.php?cmd=id&outpath=/tmp/123123&sopath=/var/www/html/templates/beez3/bypass_disablefunc_x64.so

5、使用蚁剑插件或者哥斯拉绕过

由于之前设置了仅主机，我们直接加一块NAT网卡，配置蚁剑代理就能够轻松下载插件了。

在这里点击右键，选择插件

然后选择一个绕过方式，这里是不是很熟悉~~然后直接点击start开始就行了。

可以看到右下角这里提示我们上传了两个文件.antproxy.php在网站根目录，.64937ant_x64.so在/tmp下，和我们之前上传的那两个文件异曲同工。

回到网站根目录刷新就可以看到.antproxy.php，复制一下这个名字。

蚁剑连接这个文件，密码还是之前的webshell密码

链接进去就可以愉快地使用命令了。简单的信息收集看到这台Centos机器是从内网映射出来的且不能出网。

经常用ubuntu搭建网站的同学肯定发现了一个问题，我目前拿到的这个用户是www-data，这不是ubuntu的web用户吗？？我打的机器明明是centos，应该是nginx或者apache用户啊。

这就涉及到了一个知识点，就是反向代理了。简单说，我们拿到的是centos的shell，但是获取到的信息都是另一台ubuntu的，内网中肯定存在一个ubuntu机器，并且它的ip是192.168.93.120。欲知后事如何，且看下回分解！

0x03 总结

刚才这么一套流程打下来，给人的感觉好像在看一本没看过的书，书中提到的关键典故、词语等都需要我们查询资料才能明白。
