## 0x00 NPS介绍

项目地址：https://github.com/ehang-io/nps

**NPS是Go语言编写开源的轻量级内网穿透服务器。分为客户端和服务端两个文件，具备web管理页面，与Frp类似。**

**NPS文件配置较为繁琐，而web管理页面用起来相当地方便。一般我们都用web管理页面来配置隧道，修改文件来加固配置。**

## 0x01 实验环境

攻击机：VPS(下文均以假设的1.1.1.1代替)   

靶机：Windows10、Kali、Centos7、Win7

## 0x02 基本实验步骤

### 配置nps服务端

1、攻击者在gitub上下载NPS

https://github.com/ehang-io/nps/releases/tag/v0.26.10

![](../Images/0f9c2c6ab530e68a916c28b62c4cd4cb.png)

![](../Images/bbbc04c6684af45b3af508969153a0c1.png)

2、在VPS**(下文均以假设的1.1.1.1代替)**上部署NPS服务端，即将`linux_386_server.tar.gz`解压后传到VPS上安装完毕。怎么传到VPS，方法太多啦，可以用终端工具的SFTP，也可以用命令`wget`、`curl`、`scp`等等。  

*   
*   
*   
*   
*   
*   

```
cd linux_386_serverchomd +x nps./nps installnps start #如果此命令启动不了，直接nps试试ufw allow 8080 #放开ubuntu8080端口ufw allow 8024 #放开客户端监听的端口
```

![](../Images/067d24b515fd33161c84b87c2970da2b.png)

  

3、访问http://1.1.1.1:8080，输入默认账号密码`admin:123`后登陆。随后点击客户端——新增，按照下图配置：

![](../Images/71822135584aa69180b49f5d7f35b387.png)

  

4、随后会自动跳转回之前看到的页面，然后我们点击这个`+`号展开

![](../Images/0dc9147e88893da4d9b48c7f00ff0250.png)

这一串命令就是需要转发的客户端执行的命令，如果是windows机器，改为`npc.exe`即可。  

*   
*   

```
./npc -server=1.1.1.1:8024 -vkey=hgnm5vc8m8f31e35 -type=tcpnpc.exe -server=1.1.1.1:8024 -vkey=hgnm5vc8m8f31e35 -type=tcp
```

### 创建日志文件与系统服务（可选）

我们都知道在开发的过程中，都有日志管理，例如著名的apache log4j2，go语言的log包，都可以创建日志库，用来记录我们的操作。如果没有日志，会很麻烦。

因为VPS上的NPS随用随装，所以这个操作可选，我就复制这位大佬的文章了~

**以下文字来源于：https://blog.csdn.net/nineya\_com/article/details/109830631 作者：\[玖涯\]**  

为实现将程序输出写入文件功能，编写实现了如下脚本放在`nps`根目录： 

*   
*   
*   
*   
*   
*   
*   

```
 #!/bin/bash home_dir=$(dirname $(readlink -f "$0")) logs_dir=$home_dir/logs if [ ! -d $logs_dir ]; then   sudo mkdir -p -m 755 $logs_dir fi $home_dir/nps >> $logs_dir/run-$(date "+%Y%m%d%H%M%S").log
```

使用vim创建service文件

`sudo vim /etc/systemd/system/nps.service   `

 nps.service内容：  [Unit] Description=Nps Service Documentation=https://nps.nineya.com After=network-online.target Wants=network-online.target  [Service] User=root Type=simple ExecStart=/bin/bash /www/wwwroot/nps.nineya.com/run.sh ExecStop=/bin/kill -s QUIT $MAINPID Restart=always StandOutput=syslog  StandError=inherit  [Install] WantedBy=multi-user.target

## 0x04 总结

1、NPS是Go语言编写开源的轻量级内网穿透服务器。主要分为客户端`npc`和服务端`nps`两个文件，具备web管理页面，与Frp类似。

2、配置的服务端要更改最基本的端口号、web服务界面的账密。

3、VPS上的ubuntu或者其他系统，注意开启防火墙才能访问web管理以及访问对应监听端口  

*   
*   
*   
*   

```
ufw allow 8888#其他系统firewall-cmd --permanent --add-port=8080/tcpfirewall-cmd --reload
```

4、对于内网web服务，推荐使用socks/http代理；对于SSH/RDP等服务，推荐使用tcp代理，其他协议代理，多实验多总结。
