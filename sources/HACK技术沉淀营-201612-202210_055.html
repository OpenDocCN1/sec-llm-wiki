0x02 快速搭建CS

1、CS需要java环境

 // JDK官网下载还要注册 亲测使用openJDK也完全可以 apt install openjdk-8-jre-headless java -version

2、将CS安装包直接通过SFTP拖进去，X-shell和Finalshell都支持。


3、ufw打开CS的端口

ufw allow 1998

ubuntu20默认是存在防火墙UFW的，我这里的CS端口改为了1998，可以vim teamserver自行更改。


4、之后即可链接成功。

 chmod +x teamserver nohup teamserver x.x.x.x password &

5、关闭CS

ps -aux | grep teamserverkill -9 <cs_pid>
