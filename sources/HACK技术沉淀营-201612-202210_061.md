## 0x01 virtual box骚操作：混杂模式

最近在用`VB：virtualBox`玩一些靶机，但是kali我懒得装在VB上了，直接用的`vmware`上的kali。

而将kali与VB上的靶机配通网络，其实很简单，方法很多，无非就是都桥接到自己的物理网卡，或者VB选择仅主机，VM桥接到VB的仅主机都行。但是下面这个方法，是我才知道的骚操作。

1、随便打开一个靶机，选择网络如下

![](../Images/7ed6615eeeced84179e13d165dd1d53c.png)

2、将连接方式改为桥接，然后选择高级，将混杂模式改为全部允许。这时候你会发现，**就算vmware上的虚拟机都是NAT模式的ip，也能ping通VB上的靶机。**  

![](../Images/217d6e28129bf055d9bea35355699b33.png)

3、简单解释一下混杂模式。混杂模式这个词我第一次听说还是学习arp中间人欺骗与攻击的时候。当时学到了一个词叫做嗅探，简单讲就是一种被动网络流量的收集。混杂是指一台机器的网卡能够接收所有经过它的数据流，而不论其目的地址是否为它。**其实我们熟悉的wireshark软件，就是用的混杂模式。**一般我们电脑网卡是默认非混杂的。  

## 0x02 Centos7配置静态ip

```
 vim /etc/sysconfig/network-scripts/ifcfg-ens33      #ens33是网卡名字，自行进行调整
```

1、首先配置网路前，先将虚拟网卡清理掉。输入下方命令，等待显示出命令提示符，然后重启CentOS 7即可关闭多余的3,4虚拟网卡

```
 systemctl disable libvirtd.service
reboot
```

![](../Images/855f4d07f28971e56ce9b5cb32a7e3cf.png)

2、输入以下命令进入文件进行配置

```
 cp /etc/sysconfig/network-scripts/ifcfg-ens33 etc/sysconfig/network-scripts/ifcfg-ens33.backup
vim /etc/sysconfig/network-scripts/ifcfg-ens33
```

将`BOOTROTO=dhcp`改为`BOOTPROTO=static`；再将`ONBOOT=no`改为yes

![](../Images/4766024293e91c69902e68ccc7924ad9.png)![](../Images/82b045abd423ad2bc5e75e34cb26fa9d.png)

再在`ONBOOT`下方添加以下内容，并退出保存

```
 IPADDR=192.168.91.100
GATEWAY=192.168.91.2
NETMASK=255.255.255.0
DNS1=114.114.114.114
DNS2=8.8.8.8
```

3、重启网卡，这三种命令任选一种

```
 systemctl restart network
service network restart
/etc/init.d/network restart
```

**注意：ifconfig和netstat依赖于net\_tools，有时候不能用，可以用ipaddr和ss来代替**

![](../Images/4000626de9607037d3db4852014c1823.png)

4、当网卡崩溃，无法重启时，确保IP地址不要重复，并尝试输入此命令调试

```
 systemctl stop NetworkManager
systemctl diable NetworkManager
systemctl start network.service
```

## 0x04 Kali配置静态IP

### 1、设置网卡信息

```
 vim /etc/network/interfaces #然后按照下图操作
```

![](../Images/cf61b52a43e7bbd8187397dda23647a2.png)

动态的话，将`static`改为`dhcp`

### 2、配置DNS

```
 vim
 /etc/resovl.conf #最多可以使用nameserver指定3个DNS服务器，对于这个文件的修改是即时生效的
domain
    nameserver 114.114.114.114

```

### 3、重启网络配置

```
 systemctl restart networking
或者
systemctl restart networking.service

```
