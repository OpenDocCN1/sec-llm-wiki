RDP，Remote Desktop Protocol，远程桌面连接协议。这是个人人皆知，耳熟能详的服务。对于这个协议的讨论，一直都是热点。

学习讲究一个词：循序渐进。在此总结一下基础的一些操作和相关的攻击、利用方式等。

0x00 侦察目标RDP与其端口号

1、通过进程查看

远程桌面连接服务的进程为TermService，如此来查看是否究竟开启了RDP，类似HVV的时候，端口号都是乱来的。只看3389是没什么作用的。

 tasklist /svc | findstr TermService #注意大小写别拼错了 netstat -ano | findstr 1448


2、注册表查询具体端口号

注意，这个方法不能判断对方是否开启RDP。

 REG QUERY "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp" /V PortNumber

别看上面这串命令这么长，但是其实相当理解。

REG QUERY #表示查询注册表 "HKEY_LOCAL_MACHINE\..."#就是路径 /V#查询特定注册表项 PortNumber#服务对应的端口号


3、通过更改注册表来修改默认3389端口号

有了上面的操作基础，改个端口号就不是问题了吧，下面这两个路径都行，二选一

 HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\Wds\rdpwd\Tds\tcp HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp

更改之后，无需重启什么的，直接查看就能看到。

wmic RDTOGGLE WHERE ServerName='%COMPUTERNAME%' call SetAllowTSConnections 1

0x03 RDP攻击方式

1、CVE-20120002(MS12-020)

漏洞简介

MS12-020为windows下2012年爆出高危安全漏洞，该漏洞是因为Windows系统的远程桌面协议（RDP， Remote  Desktop  Protocol）存在缓存溢出漏洞，攻击者可通过向目标操作系统发送特定内容的RDP包造成操作系统蓝屏，利用起来操作简单，危害极大，影响范围极广。

漏洞范围与条件

1、靶机具有MS12_020漏洞，windows2003、windows2008

2、靶机开启3389端口

我这里是Windows2008，必须是“允许运行任意版本远程桌面的计算机连接”，否则无法执行成功

漏洞复现

1、MSF搜索MS12_020漏洞，0号代表的是检测，1号代表的是攻击模块。这里选择1号并配置MSF参数


2、MSF执行攻击命令，对方直接蓝屏，攻击成功

漏洞修复

1、安装针对此漏洞的补丁，补丁连接https://docs.microsoft.com/en-us/security-updates/SecurityBulletins/2012/ms12-020?redirectedfrom=MSDN


2、3389不要开启任意用户连接，一定要选择身份验证的连接。这样MSF就无法攻击了，可以看到下方，一直没有成功


3、更绝对的防御，关闭3389，不过不太推荐这么去做，第二点就可以了


2、CVE-2019-0708

漏洞概述

Windows系列服务器于2019年5月15号，被爆出高危漏洞，该漏洞影响范围较广，漏洞利用方式是通过远程桌面端口3389，RDP协议进行攻击的。这个漏洞是2019年来说危害严重性最大的漏洞，跟之前的勒索，永恒之蓝病毒差不多。

漏洞范围

windows2003、windows2008、windows2008 R2、windows xp 、win7

漏洞复现

第一种：直接蓝屏

目标机器：windows2007 SP1，windows 2008 R2

这个简单，用MSF的payload即可

 search 0708 use 1 set rhosts 1 set target 2 #这个target只要设置成不对的，就直接报错蓝屏了



第二种：get system shell

这一种是MSF加载一个脚本run之后，就会返回一个meterpreter。而我实在是没有复现出来，网上说的人云亦云，什么下载更新msf的payload，然后就可以打成功，我都测试了一个遍，都不成功各种毛病。

所以为了不浪费大家时间，就不复现了，如果你复现成功请告诉我！不过个人感觉这个没有什么必要啦。一是因为成功率低，二是因为与其花费大量时间在别人制作的工具上，不如仔细研究一下原理。


3、hydra暴力破解rdp

介绍一些我常用的hydra命令，下面高亮的均为超级重点。

 hydra -L username.txt -P passwd.txt rdp://靶机ip -f -I -vV -t 16 -e ns  #这里面的rdp就是协议服务，可以提换成ssh、mysql、ftp等


这里顺便说一个小技巧，在爆破巴西或者西班牙服务器3389端口RDP服务的时候，可以在字典里面加上administrador
