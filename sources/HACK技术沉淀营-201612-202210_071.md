RDP，Remote Desktop Protocol，远程桌面连接协议。这是个人人皆知，耳熟能详的服务。对于这个协议的讨论，一直都是热点。

学习讲究一个词：循序渐进。在此总结一下基础的一些操作和相关的攻击、利用方式等。

## 0x00 侦察目标RDP与其端口号

### 1、通过进程查看

远程桌面连接服务的进程为`TermService`，如此来查看是否究竟开启了RDP，类似HVV的时候，端口号都是乱来的。只看3389是没什么作用的。

*   
*   

```
 tasklist /svc | findstr TermService #注意大小写别拼错了 netstat -ano | findstr 1448 
```

## 0x03 RDP攻击方式  

### 1、CVE-20120002(MS12-020)

#### 漏洞简介

MS12-020为windows下2012年爆出高危安全漏洞，该漏洞是因为**Windows系统的远程桌面协议（RDP， Remote  Desktop  Protocol）存在缓存溢出漏洞**，攻击者可通过向目标操作系统发送特定内容的RDP包**造成操作系统蓝屏**，利用起来操作简单，危害极大，影响范围极广。

#### 漏洞范围与条件

1、靶机具有MS12\_020漏洞，windows2003、windows2008

2、靶机开启3389端口

我这里是Windows2008，必须是“允许运行任意版本远程桌面的计算机连接”，否则无法执行成功

![](../Images/ca2bbc3e1024a993b9adf06fdbf39b2b.png)

#### 漏洞复现

1、MSF搜索MS12\_020漏洞，0号代表的是检测，1号代表的是攻击模块。这里选择1号并配置MSF参数

![](../Images/83b53fdbd25170d39bf2e3e1dbaa40cd.png)

  

![](../Images/fcf53f51c03ea1d9ce8ecf1ea6f81a32.png)

2、MSF执行攻击命令，对方直接蓝屏，攻击成功

![](../Images/dc9ce520d171305e37fb038467094581.png)

![](../Images/dae9953efca6e0cf338986971d0fb678.png)

#### 漏洞修复

1、安装针对此漏洞的补丁，补丁连接https://docs.microsoft.com/en-us/security-updates/SecurityBulletins/2012/ms12-020?redirectedfrom=MSDN

![](../Images/f77a131238136661c95459479aaa6c8f.png)

  

2、3389不要开启任意用户连接，一定要选择身份验证的连接。这样MSF就无法攻击了，可以看到下方，一直没有成功

![](../Images/b8c3e1e8d2811649b88ce9c0dbe103ab.png)

  

3、更绝对的防御，关闭3389，不过不太推荐这么去做，第二点就可以了

  

### 2、CVE-2019-0708

#### 漏洞概述

> Windows系列服务器于2019年5月15号，被爆出高危漏洞，该漏洞影响范围较广，漏洞利用方式是通过远程桌面端口3389，RDP协议进行攻击的。这个漏洞是2019年来说危害严重性最大的漏洞，跟之前的勒索，永恒之蓝病毒差不多。

#### 漏洞范围

windows2003、windows2008、windows2008 R2、windows xp 、win7

#### 漏洞复现

##### 第一种：直接蓝屏

目标机器：windows2007 SP1，windows 2008 R2 

这个简单，用MSF的payload即可

*   
*   
*   
*   

```
 search 0708 use 1 set rhosts 1 set target 2 #这个target只要设置成不对的，就直接报错蓝屏了
```

  

![](../Images/16490280a327d4dce9b1f6502efc170b.png)

### 3、hydra暴力破解rdp

介绍一些我常用的hydra命令，下面高亮的均为超级重点。

*   
*   

```
 hydra -L username.txt -P passwd.txt rdp://靶机ip -f -I -vV -t 16 -e ns  #这里面的rdp就是协议服务，可以提换成ssh、mysql、ftp等
```

| 命令 || 含义 |
| --- | --- |
| \-l(lower L) || 已知用户名 |
| --- | --- |
| \-L || 指定用户名字典文件 |
| \-p || 已知密码 |
| \-P || 指定密码字典文件 |
| **\-vV** || **显示爆破过程** |
| **\-f** || **爆破成功时停止** |
| **\-t** || **指定线程，默认是16，常用-t 4。过大会导致hydra崩溃** |
| **\-I(Upper i)** || **上次爆破过程中断，下次继续爆破会先等待10秒，-I就是跳过这10秒** |
| **\-e n** || **n为null，空密码试探** |
| **\-e s** || **s为same，密码与用户名一致** |
| \-e r || r为reverse反向，将用户名倒置 root——>toor |
| \-o || 保存输出结果 |
