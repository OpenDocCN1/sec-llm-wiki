复制下面这段代码粘贴到txt文件，将txt文件后缀改为ps1

 $computer=Get-WMIObject  Win32_ComputerSystem $computername = $computer.name $username = 'admin' #用户名 $password = '123.com' #密码 $desc = 'Local admin account' $computer = [ADSI]"WinNT://$computername,computer" $user = $computer.Create("user", $username) $user.SetPassword($password) $user.Setinfo() $user.description = $desc $user.setinfo() $user.UserFlags = 65536 $user.SetInfo() $group = [ADSI]("WinNT://$computername/administrators,group") $group.add("WinNT://$username,user")

执行脚本

运行此脚本，需要管理员权限。powershell对于脚本的执行有着严格的安全限制，默认是限制restricted

策略Policies：Restricted / AllSigned / RemoteSigned / Unrestricted / Bypass / Undefined。 所以不能直接使用者脚本，需要设置一下：

 Set-ExectutionPolicy Unrestricted
