## 0x00 Typora优化

众所周知，程序员编辑文档是用的Markdown语法。既能满足强迫症患者的文本编写，也能满足多种代码的格式编写。不仅如此，还能支持html文档，流程图，数学公式等等自动排版的功能，极大地提高了程序猿的工作效率。

这里先介绍两个比较好用的设置。

### 开启上标下标与行号

勾选之后，重启软件，格式里面就会出现上标下标，否则不会出现。测试：**2^(32)   2[32]**

![](../Images/a0fa1778ed9d50a3a44cf1f5e69e7b9c.png)  

### 高亮设置

Typora中只有一些加粗、删除线、标题设置，没有其他特别的强调设置了，这时候你就需要这么设置一下：

1、当我们点击文件——偏好设置——通用——打开高级设置，找到`conf.default.json`文件，找到截图位置，设置成自己善用的快捷键即可。

![](../Images/06a50ae2b496cdb6f90c149fad2880d5.png)

2、别忘了点击`Markdown`，选择高亮，下方还有个行号，可以让你的代码块出现行号更加整洁好看哈~

![](../Images/db907e7a6a9714c52f44f805ec895eff.png)

### 图片全部左对齐

我们截图的大小，不可能每次都一致，如果对设置不加一些配置的话，自己的笔记就会显得“歪七拧八”（效果图就不展示了，对强迫症患者不友好）。

当我们点击文件——偏好设置——外观——打开主题文件夹后，可以看到自己选择的主题的CSS文件，在最下方添加这么一段代码

```
 p .md-image:only-child{             #######注意第一行p后面有一个空格！！不能缺失！！#########
    width: auto;
    text-align: left;
}
```

即可将我们所有的图片左对齐，这样子看起来就整洁多啦~

![](../Images/490612b4eb56b02e67da52bcb6a3e466.png)

## 0x01 图片同步设置

对于刚刚上手typora的小白们，肯定不能够适应Typora的图片设置，这不仅仅是小白，就算是用了很多年的大白也在吐槽诟病这个设置。

**Typora图片设置到底咋了？**

一句话：Typora里面的图片严格定义了路径，一旦路径发生变化，图片再也不能加载。

这样的设置，首先对常用office或者wps的小伙伴不友好；其次就是对博客编写、笔记分享及其不方便，前期不设置好，分享的时候就要花大量的时间去整理才能分享出去，别人写10篇博客，你自己还在整理第1篇博客的图片，你说气不气？效率低下的你是不是很着急？

惨不忍睹，血的教训屡见不鲜。那么怎么才能够根治呢？

### 设置Typora图片上传功能

1、首先要确认一点，就是你的Typora要具备这个功能。也就是在Typora 0.11版本后才有的

2、下方的上传服务设定，选择上传服务——`PicGo(app)`，之后就先不管这里，一会儿再弄。

![](../Images/8255f3e46cf2e0d94907ef65d217c5c6.png)

### 下载PicGo

1、点击上图下方的`下载PicGo(app)`，会跳转到Github，这个项目我开始看的时候吃了一惊，15.6K的星星！快和MSF的star一样高了！

```
 https://github.com/Molunerfinn/PicGo/releases/tag/v2.3.0
```

![](../Images/ac50209184c5970aa381ff57062235e4.png)

2、选择对应操作系统的下载，然后安装，打开后默认是在后台，需要自己将其唤醒。之后，选择腾讯COS

![](../Images/7c7c27835977523f98449c5c24253d20.png)

可以看到这里有很多的设置选项，这里先不管，再继续往下走。

### 注册以及开启腾讯云的COS

OS，不仅仅是Operation System，也可以被定义为Object Saving(应该是...)，对象存储(这个我肯定！)。

1、打开腾讯云官网，用微信登陆，选择右上角的`控制台`

```
 https://cloud.tencent.com/
```

![](../Images/5541e8965bf43c30f8dc3c26670921f5.png)

2、点击左上角的云产品，搜索COS，就可以看到对象存储这个服务。

![](../Images/3dad2bd7b22b6d7466aa49cfa4ac78f3.png)

3、注册个账号，之后选择密钥管理

![](../Images/00e9803ed1eaeef5f8df4069b5983ff0.png)

4、访问后，可以看到有个高风险提示，什么意思呢，就是可以类比为你调用API的用户权限是什么，默认是最高权限，如果你一直用最高权限调用API，假设你的密钥泄漏，那就会造成很大的损失，这里请自行选择，我懒，我选择的是默认=-=

![](../Images/59342ceb855056735a13df72bf886a87.png)

5、之后，设置名字等等，最终会到这个界面，记好这些信息，将这些信息，前三行依次填入到之前说的PicGo配置里面。

![](../Images/2797cd28c323ad630ed90beba5caaa65.png)

![](../Images/7c7c27835977523f98449c5c24253d20.png)

6、后面的设定存储空间名和确认存储区域在哪里呢？如图所示，在这里创建新的存储桶对象，会有一个权限控制，也就是你所创建的存储bucket可以是私有，也可以是公开，我选择的是**公读私改**。

![](../Images/0ff3a18084135283860215b956100482.png)

![](../Images/3b16912b1f966f39b473d12e8acef518.png)

7、在存储桶列表里面可以看到上传的文件，这里也可以新建文件夹，不过无所谓了，如果你想分类不是那么详细的话，可以再新建一个存储桶嘛

![](../Images/9a60d860977eef7525858cb51e6c37bb.png)

8、当我们设置好PicGo的时候，再回到Typora，配置一下`PicGo路径`为你安装的`PicGo.exe所在路径`，然后点击验证上传选项

![](../Images/3f22257e5d1ef3ebb0a3c8c833aa8ad9.png)

9、出现这个界面就是成功

![](../Images/001c76d24f2f8c3fb3e9ff01ee4f8c5e.png)

10、之后再选择`上传图片`，以后我们每次截图复制的图像，都是默认上传上去了，就不用保存在本地了。

![](../Images/7b1f84eb4edc111ce8e83f123bb71bcb.png)

11、同时还可以看到我们的图片，路径变成了公网上的一个公开资源，你可以将其改成私有的。

![](../Images/cb37fe0f2cd23c950caffd76da01b8f9.png)

12、需要注意一点，初始个人用户会有6个月50GB的免费额度。之后的收费看腾讯云要求了。这里我说一句，有些人肯定会说，每个月还要收费怎么怎么样。告诉你，将你的自动续费视频会员的钱，抽烟喝酒打游戏的钱，用到这里提升效率不香吗？为什么就不明白“好钢用到刀刃上”这句要学会投资自己的名言呢？

![](../Images/0a35fd92aeb38ca9ae616a494a012110.png)

  

13、现在就可以愉快地使用Typora了，妈妈再也不用担心我`别人10篇博客发表我还在搞图片`了，用Typora写好一篇文章后，直接`Ctrl+/`，复制粘贴到博客、其他平台的Markdown即可！

![](../Images/9c2d21f774e336f0c1f336e54f689a6a.png)

  

  

## 0x02 技巧

### 字体变颜色

有些字我们想要变一下颜色咋办？其实很简单，typora默认编辑格式是html格式，我们加个`font标签`和`color属性`既可

这个字变成`<font color=blue>蓝色</font>`蓝色

`<font color=red>红色</font>`红色

  

### 按住Ctrl键在代码块中点击

用过编译软件，尤其是`VScode`的都懂，按住`ALT+鼠标左`键，可以实现一个功能，就是多个光标组合在一起。

那么在`Typora`中也是一样的道理，只不过只需要按住`Ctrl`键就可以。但是只能在代码块中使用哈。

![](../Images/9407b028f96e062ef4ac3a77d4eb28d8.png)

  

### 文件恢复

有时候，再怎么谨慎，也有不小心将typora笔记弄丢的时候。有一个兄弟晚上找我，说自己电脑硬盘炸了，坏了，于是自己的笔记全没了。

我一问，是typora，仔细想了想，还是有补救的方法。

![](../Images/405f3c2f71e07e50c141ba623ed1eaea.png)

![](../Images/7d79d5adb352d9bdd21b36d63077b396.png)  

也就是在这里，可以看到有一个恢复未保存的草稿。

![](../Images/9ebbc1e775bcdb4ebfb8439cfa7ff258.png)

这个功能其实就是类似于word文档的历史文件保存，但是它只会保存近两天的。注意，这个也不能完全恢复，但是最起码恢复了一些，有时候还是挺有帮助的。

可以把这个路径记录下来。到时候就明白了`C:\Users\$USER$\AppData\Roaming\Typora\draftsRecover`

![](../Images/8d336bb91f5d317545b738cf95e3821b.png)  

![](../Images/fc666c3dd05a8143e8ba3feb80ddfcc6.png)
