## 0x00 前言

相信大家都听说过"黑苹果"这三个字。我这里简单说一下

**“白苹果“**是指在正规苹果电脑上运行的Mac OS操作系统，在苹果官网购买的电脑都是白苹果。

**”黑苹果“**是指在非正规苹果电脑上运行的Mac OS操作系统，例如传统的Windows上运行的Mac OS操作系统，我们统称为黑苹果。

通俗点说，“白苹果”是正品、“黑苹果”就是非正品；但是苹果官方对黑苹果电脑不提供任何服务和责任，黑苹果存在各种不兼容的情况，不喜欢折腾的还是乖乖买白苹果吧，喜欢折腾的都成了黑苹果大神了。加油，努力钻研你也是一个黑苹果高玩！

我这里呢，就写一个简单的"盗版"黑苹果——在vmware workstations上安装macOS。

对于没有钱买mac的小伙伴来说，这是一个福音啊！按照下面步骤一步一步来，你也可以做到下图这样：

![](../Images/adc1076f3c2c8039509c22eaff1cc432.png)

## 0x01 安装与配置VM16

### 下载安装vmware

**下载地址：**https://download3.vmware.com/software/wkst/file/VMware-workstation-full-16.0.0-16894299.exe

**序列号：**

```
 ZF3R0-FHED2-M80TY-8QYGC-NPKYF
YF390-0HF8P-M81RQ-2DXQE-M2UT6
ZF71R-DMX85-08DQY-8YMNC-PPHV8
```

### 关键步骤1：安装unlocker

**默认安装好的VMware16没有MacOS选项**，需要先安装unlocker，下载地址：https://github.com/paolo-projects/auto-unlocker/releases

![](../Images/3c6aa99dd19a7146679b36597860d28f.png)

![](../Images/76d1cc0727f7b3eeafe1d4a4e0f90968.png)

  

### 关键步骤2：配置vmx文件

**1、编辑器打开vmx文件，然后在最后一行添加这三行代码**

```
 smbios.reflectHost \= "TRUE"
hw.model \= "MacBookPro16,1"
board-id \= "Mac-E1008331FDC96864"
```

![](../Images/a3333c6659cb5aedb76005ca9603a7f1.png)

2、这时可以在vmware上看到，可以选择安装mac了

![](../Images/78e8b4c338915d2e92091bae5a486ca7.png)

## 0x02 加载镜像安装macOS

> 前提说明：在安装之前， 磁盘要预留至少80GB空间，安装过程会比较卡，但是安装完毕后顺畅。

1、选择磁盘工具，进行划分分区等等

![](../Images/1b3a370b1d1c4322936e34bd44f8316b.png)

2、进去后选择`VMware Virtual SATA Hard Drive Media`，然后选择抹掉——名称无所谓，格式选择APFS，方案就是默认就行。

![](../Images/32bbbfb85dcddc57a775ff3bc9d169c9.png)

  

3、点击完上图的抹掉之后，点击左上角的关闭，退出来，选择第二个选项安装macOS

![](../Images/935ecbf452aece9ede518c0e2e7bb954.png)

  

4、选择硬盘就行了

![](../Images/fe31dcff62531ff3a1e0020e97c576a9.png)

  

5、选择国家或地区，迁移助理和AppleID都可以跳过，随后一路继续即可

![](../Images/02c299473cdf874342e4293e50501d19.png)

  

![](../Images/25efdc0d98223be82579a27d0e51478d.png)

  

![](../Images/5dbf8275dbd2be8b911292563353ae3c.png)

  

  

## 0x03 macOS安装vmware tools

1、安装好macOS后，因为我们现在的DVD正在占用这个镜像文件，先关机，然后

2、找到这个文件`darwin.iso`，这个文件俗称是“黑苹果全屏文件”，其实就是个vmware-tools自带的。

![](../Images/2a9a4ff479efe1a7c6a3718e4e513ec4.png)

  

3、设备安装vmware-tools这里选择这个`darwin.iso`然后开机

![](../Images/1c5cecebc89807e6acfa31190993793b.png)

  

4、会看到桌面上有一个VMware Tools

![](../Images/4b3779edc40f6d049b9062ec581ebdd0.png)

  

5、点击安装输入密码后，会出现这个界面。选择`打开安全性偏好设置`

![](../Images/0351db166fda9327014a4f17b37a5aad.png)

  

6、再点击下面这个锁

![](../Images/ad9acd4233710f3e7440e26342c058f0.png)

  

7、解锁后选择允许

![](../Images/4d57e32bb5379da9567379e65eb28636.png)

  

8、然后安装好之后重启即可，至此，全部安装完毕

![](../Images/11ed8a35b1eb00f2381277ba36056464.png)
