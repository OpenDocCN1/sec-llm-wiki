其实一直感觉kali这个渗透测试工具系统，有很多自己没有用过的小工具，有时候会达到出其不意的效果。打算以后Go语言学成之后，模拟编写一些关于这方面的工具。

这次先介绍一个小工具吧，kali自带的wafw00f。

这是个啥？

`Wafw00f`只是一个 Python 工具，它可以自动执行一组用于查找 WAF 的过程。Wafw00f 只是使用一组 HTTP 请求和方法查询 Web 服务器。它分析来自他们的响应并检测到位的防火墙。

说白了就是检测网站是不是存在waf的，并且如果有waf的话，会看waf的名称是什么。

## 常用命令

```
 wafw00f \-h
\-h, \--help 显示此帮助信息并退出
\-v, \--verbose 启用详细程度 \- 多个 \-v 选项增加详细程度
\-a, \--findall 查找所有 WAF，不要停止对第一个的测试
\-r, \--disableredirect 不要遵循 3xx 响应给出的重定向
\-t TEST, \--test\=TEST 测试一个特定的 WAF
\-l, \--list 列出我们能够检测到的所有 WAF
\--xmlrpc 打开 XML-RPC 接口而不是 CUI
\--xmlrpcport\=XMLRPCPORT 指定要监听的替代端口，默认为 8001
 \-V, \--version 打印出版本
```
