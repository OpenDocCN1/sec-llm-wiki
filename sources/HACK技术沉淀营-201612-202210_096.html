有时候kali内放置的文件以及安装的各种软件十分繁杂，难以分辨，如何高效管理呢？

当kali在运行和我们“肾透”过程中会产生很多的垃圾文件。如何正确的清理这些垃圾文件呢？

我是不熟悉Linux命令的小白，有无图形化的方便工具？

答案是当然有的。

stacer

stacer是一款图形化的垃圾清理和系统管理工具。有进程管理、开机启动项管理、可视化软件安装和卸载。对于不熟悉Linux命令的小白而言是非常友好的。

 apt-get install stacer


ncdu

清理日志文件或者其他文件都很好用

 apt-get install ncdu
 ncdu /var/log
 d   #删除
 s   #倒序
 q   #退出
