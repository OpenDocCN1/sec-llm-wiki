事情是这样的，我们经常在下载各种安装包，下载各种游戏安装包等等等等，都能看到一个叫做MD5校验值的东西，有时候这东西在官方网站上，有时候这东西在下载下来的文件里面。  

这是干嘛的？  

**用来校验文件完整性的。**  

如何验证？？

  

#### windows的certutil

我们经常可以看到下载一个文件，网页上写好了这个文件的MD5值，那么这个MD5值我们如何生成？？？？

利用系统自带的命令即可！

```
 certutil \-hashfile C:\\users\\xxx\\Desktop\\1.jpg md5
```

![](../Images/6be898c72eb3cc201b999ef3d9677289.png)

#### Centos7 / ubuntu的md5sum

```
 md5sum <filename>
```

![](../Images/e088196a3f9730231a4c6bbca1ed43d7.png)

#### kali的hashdeep

```
 hashdeep <filename>
```

![](../Images/33791afa84796319241c3abefb778046.png)

之后将生成的值，与官网提供的文件md5，SHA256等校验值进行对比即可。
