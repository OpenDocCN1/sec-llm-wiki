**简介**

由于在 VMware Cloud Foundation (NSX-V) 中使用 XStream 进行序列化而未经身份验证，黑客可以构造恶意数据包从而造成远程代码执行漏洞。VMware Cloud Foundation 3.x 和更具体的 NSX Manager Data Center for vSphere 6.4.13 及更高版本容易受到远程命令执行的攻击。利用该漏洞可获得 root 权限。**FoFa语法**title="VMware Appliance Management"**漏洞复现**
