小8开放API功能了！

小8机器人已经稳定运行两个月了，刚开始做小8微信机器人只是顺带做一下信息流的推送，后面发现小8可以有很多好玩的地方，例如在线扫描，只需要在手机上输入命令，即可进行扫描和收集资产。

现在小8开放自定义消息的API，基于api就可以控制小8给自己的微信发送消息。

公众号回复小8，加小8为好友，建议将小8置顶，方便查看消息。


私聊小8，输入api，可获得api地址(注意：地址独一无二，不可泄漏，不然其他人会通过此地址给你消息)
访问该地址就能收到小8发的消息了。


一行url即可调用小8发送消息，修改msg参数可自定义内容了。具体怎么用就看你的想象力啦！

  1. 例如可以给自己博客的评论加上此接口，新的评论在微信就能看到了

  2. 给CS上线加上此接口，新主机上线第一时间看到

  3. 对于bughunter 给资产监控加上此接口，新的资产一目了然！

  4. 给nuclei加上接口

    新建一个wechat.py文件，

    import requests
    api = "?msg="
    with open("output.txt") as f:    data = f.read()
    resp = requests.get("https://i.hacking8.com/wechat-api/xxxxxxxxxx",params={    "msg": data})print(resp)

    命令行命令

    echo "https://www.hacking8.com" | ./nuclei -t nuclei-templates -o output.txt && python wechat.py
