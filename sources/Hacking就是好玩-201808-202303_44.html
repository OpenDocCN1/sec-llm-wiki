httpx is a fast and multi-purpose HTTP toolkit allows to run multiple probers using retryablehttp library, it is designed to maintain the result reliability with increased threads.

httpx是一个多功能的http请求工具包，通常可以用它来批量探测资产的一些基本信息。

源码地址：https://github.com/projectdiscovery/httpx

支持的探针有

通常情况下，实现一个类似的工具是很容易的，如果用python来写

  1. import requests
  2. url = "https://x.hacking8.com"
  3. r = requests.get(url)
  4. resp = r.text
  5. status_code = r.status_code

就可以获得大部分探针的信息，但要做成一个工程化的软件，就要考虑更多问题。

如何处理go的并发，如何加快请求速度，如何进行原生http请求以及如何工程化的组织go的源码框架，看了httpx的源码，这些都挺有收获的，所以写一篇源码记录。

Go的并发处理

在http的请求中，最好对go协程的并发做一些限制，类似于 线程池的概念。

httpx使用了 https://github.com/remeh/sizedwaitgroup的库

使用也很简单，初始化之后，在要使用协程之前 wg.Add(),使用协程后 wg.Done()代表结束即可。

以上只是对协程数做了限制，如果还想对每秒并行的协程数量做限制，可以参考projectdiscover另一个项目 nuclei，它在使用了 sizedwaitgroup的基础上，还使用了 go.uber.org/ratelimit

使用更加简单

  1. package main

  3. import (
  4.     "fmt"
  5.     "time"

  7.     "go.uber.org/ratelimit"
  8. )

  10. func main() {
  11.     rl := ratelimit.New(1) // per second

  13.     prev := time.Now()
  14.     for i := 0; i < 10; i++ {
  15.         now := rl.Take() // 重点是它
  16.         if i > 0 {
  17.             fmt.Println(i, now.Sub(prev))
  18.         }
  19.         prev = now
  20.     }

  22. }

初始化后在协程中调用 Take()方法即可。

Pipeline 探针

http 1.1支持管道传输，例如在一个数据包中发送这样的包

  1. GET / HTTP/1.1
  2. HOST: 127.0.0.1

  4. GET / HTTP/1.1
  5. HOST: 127.0.0.1

  7. GET / HTTP/1.1
  8. HOST: 127.0.0.1

检测最后的返回是否合法。

  1. package httpx

  3. import (
  4.     "crypto/tls"
  5.     "fmt"
  6.     "net"
  7.     "strings"
  8.     "time"
  9. )

  11. // SupportPipeline checks if the target host supports HTTP1.1 pipelining by sending x probes
  12. // and reading back responses expecting at least 2 with HTTP/1.1 or HTTP/1.0
  13. func (h *HTTPX) SupportPipeline(protocol, method, host string, port int) bool {
  14.     addr := host
  15.     if port == 0 {
  16.         port = 80
  17.         if protocol == "https" {
  18.             port = 443
  19.         }
  20.     }
  21.     if port > 0 {
  22.         addr = fmt.Sprintf("%s:%d", host, port)
  23.     }
  24.     // dummy method while awaiting for full rawhttp implementation
  25.     dummyReq := fmt.Sprintf("%s / HTTP/1.1\nHost: %s\n\n", method, addr)
  26.     conn, err := pipelineDial(protocol, addr)
  27.     if err != nil {
  28.         return false
  29.     }
  30.     // send some probes
  31.     nprobes := 10
  32.     for i := 0; i < nprobes; i++ {
  33.         if _, err = conn.Write([]byte(dummyReq)); err != nil {
  34.             return false
  35.         }
  36.     }
  37.     gotReplies := 0
  38.     reply := make([]byte, 1024)
  39.     for i := 0; i < nprobes; i++ {
  40.         err := conn.SetReadDeadline(time.Now().Add(1 * time.Second))
  41.         if err != nil {
  42.             return false
  43.         }

  45.         if _, err := conn.Read(reply); err != nil {
  46.             break
  47.         }

  49.         // The check is very naive, but it works most of the times
  50.         for _, s := range strings.Split(string(reply), "\n\n") {
  51.             if strings.Contains(s, "HTTP/1.1") || strings.Contains(s, "HTTP/1.0") {
  52.                 gotReplies++
  53.             }
  54.         }
  55.     }

  57.     // expect at least 2 replies
  58.     return gotReplies >= 2
  59. }

  61. func pipelineDial(protocol, addr string) (net.Conn, error) {
  62.     // http
  63.     if protocol == "http" {
  64.         return net.Dial("tcp", addr)
  65.     }

  67.     // https
  68.     return tls.Dial("tcp", addr, &tls.Config{InsecureSkipVerify: true})
  69. }

HTTP 证书信息

go内置的网络库已经把tls信息获取并解析了，直接获取即可。

  1. package httpx

  3. import (
  4.     "net/http"
  5. )

  7. // TLSData contains the relevant Transport Layer Security information
  8. type TLSData struct {
  9.     DNSNames         []string `json:"dns_names,omitempty"`
  10.     Emails           []string `json:"emails,omitempty"`
  11.     CommonName       []string `json:"common_name,omitempty"`
  12.     Organization     []string `json:"organization,omitempty"`
  13.     IssuerCommonName []string `json:"issuer_common_name,omitempty"`
  14.     IssuerOrg        []string `json:"issuer_organization,omitempty"`
  15. }

  17. // TLSGrab fills the TLSData
  18. func (h *HTTPX) TLSGrab(r *http.Response) *TLSData {
  19.     if r.TLS != nil {
  20.         var tlsdata TLSData
  21.         for _, certificate := range r.TLS.PeerCertificates {
  22.             tlsdata.DNSNames = append(tlsdata.DNSNames, certificate.DNSNames...)
  23.             tlsdata.Emails = append(tlsdata.Emails, certificate.EmailAddresses...)
  24.             tlsdata.CommonName = append(tlsdata.CommonName, certificate.Subject.CommonName)
  25.             tlsdata.Organization = append(tlsdata.Organization, certificate.Subject.Organization...)
  26.             tlsdata.IssuerOrg = append(tlsdata.IssuerOrg, certificate.Issuer.Organization...)
  27.             tlsdata.IssuerCommonName = append(tlsdata.IssuerCommonName, certificate.Issuer.CommonName)
  28.         }
  29.         return &tlsdata
  30.     }
  31.     return nil
  32. }

检测virtualhost

检测是否是虚拟主机，方法很简单，将host换成一个随机值，和原来的返回进行比对，不一样则为虚拟主机。

当然比对的方法有很多，状态码，长度，单词数，行数，相似度等等。

  1. package httpx

  3. import (
  4.     "fmt"

  6.     "github.com/hbakhtiyor/strsim"
  7.     retryablehttp "github.com/projectdiscovery/retryablehttp-go"
  8.     "github.com/rs/xid"
  9. )

  11. const simMultiplier = 100

  13. // IsVirtualHost checks if the target endpoint is a virtual host
  14. func (h *HTTPX) IsVirtualHost(req *retryablehttp.Request) (bool, error) {
  15.     httpresp1, err := h.Do(req)
  16.     if err != nil {
  17.         return false, err
  18.     }

  20.     // request a non-existing endpoint
  21.     req.Host = fmt.Sprintf("%s.%s", xid.New().String(), req.Host)

  23.     httpresp2, err := h.Do(req)
  24.     if err != nil {
  25.         return false, err
  26.     }

  28.     // Status Code
  29.     if !h.Options.VHostIgnoreStatusCode && httpresp1.StatusCode != httpresp2.StatusCode {
  30.         return true, nil
  31.     }

  33.     // Content - Bytes Length
  34.     if !h.Options.VHostIgnoreContentLength && httpresp1.ContentLength != httpresp2.ContentLength {
  35.         return true, nil
  36.     }

  38.     // Content - Number of words (space separated)
  39.     if !h.Options.VHostIgnoreNumberOfWords && httpresp1.Words != httpresp2.Words {
  40.         return true, nil
  41.     }

  43.     // Content - Number of lines (newline separated)
  44.     if !h.Options.VHostIgnoreNumberOfLines && httpresp1.Lines != httpresp2.Lines {
  45.         return true, nil
  46.     }

  48.     // Similarity Ratio - if similarity is under threshold we consider it a valid vHost
  49.     if int(strsim.Compare(httpresp1.Raw, httpresp2.Raw)*simMultiplier) <= h.Options.VHostSimilarityRatio {
  50.         return true, nil
  51.     }

  53.     return false, nil
  54. }

http/https的识别转换

httpx默认会请求http/https两种协议，默认先请求https，如果失败了会再请求http，这样就能识别出使用了http还是https了。

编译分为三步，第一步签出代码，第二部安装go环境，第三部使用 goreleaser/goreleaser-action编译上传。
