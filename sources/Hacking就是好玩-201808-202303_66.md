# 安全信息流网站

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2NzcwNTY3Mg==&mid=2247483736&idx=1&sn=68f1542062edc443623581c3abaeec10&chksm=fc98687fcbefe169ccb2ee7b2088e10ab8f52464b14d633190a504bff60a20b900ef30f2b4ee&scene=126&sessionid=1681663022#rd](http://mp.weixin.qq.com/s?__biz=MzU2NzcwNTY3Mg==&mid=2247483736&idx=1&sn=68f1542062edc443623581c3abaeec10&chksm=fc98687fcbefe169ccb2ee7b2088e10ab8f52464b14d633190a504bff60a20b900ef30f2b4ee&scene=126&sessionid=1681663022#rd)

受困于每天刷很多网站浪费时间，于是五一花了几天时间将自己每天刷的信息做成了一个网站，每日推送信息，有安全类，有娱乐类，用了几天感觉还不错，再也不用一个个网站的打开了。

理想是作为干净的信息流推送工具，偏向安全圈的点点滴滴，为安全研究人员每日发现优质内容。

最近新加入了微博和twitter的爬虫，我关注的twitter和微博的大牛发言也能在网站上显示了。
