**0X01 如何快速过关新版本的羊了个羊**

下面演示更新后的羊了个羊，如何快速通过第二关

第一步，开启这个按钮，开始拦截，抓包

![](../Images/2cad89c1033747e9afe8b6a8bb63309f.png)

  

第二步，看到下面这个matchtype=3的包，慢一点，看下一步操作  

  

![](../Images/a4746be339cffdd5b2fa4d53b82cd589.png)

  

第三步，鼠标点击右键，选择Do intercept，再选择Response this request

这一步是查看这个请求的返回包，下一步要用

  

![](../Images/8f0ac7e9a41456a7f5f4065b25508864.png)

  

第四步，直到你看到下面这个包，注意看这两串值，map\_md5里面的值

第一行是第一关的地图

第二行是第二关的地图

聪明的你想到了，怎么改了吗？

  

![](../Images/2b9c5bbb86ab5d1c08184f298c1c9167.png)

  

第五步

把下面的值改成和上面的值一样即可，这样就是把第二关改成了第一关的地图

  

![](../Images/e3ceb092c8db2aa6ad3f2d2278ca2147.png)

  

接着把Intercept is On点一下，变成Intercept is off，就不用拦截包了  

第一关截图如下

![](../Images/bf0cd42e15e79eefafee54ae92e036f6.png)

  

第二关，如果你上面没遗漏步骤，你第二关就是和第一关一样的  

  

![](../Images/5aa1dd2b9800c26d9e6a3899c63c9743.png)

  

修改md5值红，就会把第二关改成和第一关一样，233333

![](../Images/8b5b0a315c2945ca636b1db8892829a9.png)

  

成功了，一样so easy

  

![](../Images/aa848d1d179e03f265806f63626a22ea.png)

  

**0X03 如何更快修改朋友圈排名呢**

如何快速成功朋友圈排名第一呢，来一个更简单的方法，依旧是改返回包  

  

第一步，点击查看历史排名，记得开启抓包哈，看到这个包，依旧是右键，查看返回包  

![](../Images/fbe70ef84b90103ddc7369650e68ff64.png)

  

右键选择，查看Response to this request

  

![](../Images/d029c27d8015fae719a87fb0c858c298.png)

  

第二步，当你看到这个包的时候，把daily\_count这个值改成你要显示的值  

比如我的是505358  

  

![](../Images/738d6096b6a21c695447e1d8af7a7c27.png)

  

我改成999999

  

![](../Images/902989d61654d28ba96e2f6ddbc57eaf.png)

  

然后，再看自己的好友历史排行榜就是999999了  

![](../Images/726d497ba105eb258c7974545bbccdd5.png)
