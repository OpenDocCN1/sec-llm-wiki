## 1、靶机介绍

靶机下载地址：https://www.vulnhub.com/entry/droopy-v02,143/  
靶机提示：  
Description  
Welcome to Droopy. This is a beginner's boot2root/CTF VM.  
The VM is set to grab a DHCP lease on boot。  
There's 2 hints I would offer you:  
1.) Grab a copy of the rockyou wordlist。  
2.) It's fun to read other people's email。  
靶机IP：10.8.0.108

## 2.端口发现

扫描靶机信息，发现只开放了80端口  
![](../Images/156fe97e4df08901b695cd2e9e0d8c39.png)

## 3.访问WEB

访问WEB，发现是个登录界面，尝试了下弱口令，万能密码都没有结果，那就先放一放  
![](../Images/83b9246189b7be9984218a8ea0f9b90f.png)

## 4.目录扫描

目录扫描，好多啊。。。  
![](../Images/f0b11e8645c0326291b09a83d3e6d752.png)  
![](../Images/30b07262184e90002e6b9c9a9324c4e6.png)  
依次查看这些目录，只在http://10.8.0.108/CHANGELOG.txt发现了Drupal版本应该是7.30，无其他可用信息  
![](../Images/1a40522b0ba288bbb776d1580c6a931a.png)  
记得Drupal7.X版本存在远程代码执行漏洞，查一下  
![](../Images/00003e1a7bac9262218ee7057b360d78.png)

## 5.Drupal漏洞利用

启动msf，search drupal，1为表单API注入，WEB也是一个登录表单，可以尝试一下  
![](../Images/b5f7e33967c4d2fed10877366f181107.png)  
use unix/webapp/drupal\_drupalgeddon2攻击模块，查看需要设置的参数  
![](../Images/11117f3c7962acb760042b15b374fb90.png)  
set rhosts 10.8.0.108设置目标ip地址，run，成功得到meterpreter  
![](../Images/58513a0fcdd000e32f2277354ad1d051.png)

## 6.渗透测试

升级一下shell，python -c 'import pty;pty.spawn("/bin/bash")'  
![](../Images/b66111ae3b0c890a58e187be8fc9ceaf.png)  
查看当前所有文件，sites/default/settings.php是个配置文件，在文件最下方记录了本机有一个drupal数据库，用户名为drupaluser，密码为nimda。  
![](../Images/b984f684ef53d611f6048777f070b877.png)  
![](../Images/10d7e6f46afbc7145ba93f88a48fdd47.png)  
利用用户名drupaluser，密码nimda，成功登录mysql数据库。  
![](../Images/366c36802b64d8c1454c85d3aca89462.png)  
在drupal数据库中找到users表  
![](../Images/bcd36ddefab39263dd60b29e560b30a5.png)  
![](../Images/3f2b4d0303a2df69bd7a0410e40d9a41.png)  
![](../Images/244a4d7ab14a2139810066ca075d7c13.png)  
![](../Images/5ef6357591d15ebf03b10d3e24d03fea.png)  
在users表里查找到了用户drupaladmin，密文密码$S$Ds5SgCrqwrbxJY36HldOHA3C9wWH0W3DXMkHSXBb7SsYVfhhlM7s，邮箱drupal@knight139.co.uk  
![](../Images/08d40facbd4fc1299b3e99686eb0688e.png)  
将$S$Ds5SgCrqwrbxJY36HldOHA3C9wWH0W3DXMkHSXBb7SsYVfhhlM7s写入到1.txt，使用提示的rockyou.txt字典，破解出密码为Password1。  
![](../Images/919679a8d48dfd172f76e15b2ff25349.png)  
![](../Images/e296e1425aaa6a05a375a7ebdf99cc08.png)  
利用用户名drupaladmin和密码Password1，成功登录WEB，继续搜集信息。  
![](../Images/32501d9b1e52a320b2c5e8f9ce67be19.png)  
一番找到后没有任何提示，还是回到shell再看看吧，又查找了好久也没有可利用的。。。最后只能尝试查询一下系统漏洞了  
![](../Images/89556d0dd5f3c941000dc6d470dfac2c.png)

## 7.提权

searchsploit linux 3.13 ubuntu 14.04查找到符合条件的exp，linux/local/37292.c  
![](../Images/6bfd614853ed1acff21acb157180fc10.png)  
将37292.c保存到本地，查看下靶机有gcc  
![](../Images/60e6236d387c6634af34081ec19a5415.png)  
![](../Images/4b014cd36c92f6641cc11888dc6ff74e.png)  
本机开启http服务，靶机下载37292.c到/tmp下  
![](../Images/ac3abd76cc110d1e4d5a6b35d0dcd2c4.png)  
![](../Images/6e925a2547fce52bffc7f101f77d58ab.png)  
赋权，执行，获得了root权限  
![](../Images/9eaeae16b16a53032540630421c0df6e.png)  
![](../Images/4244d91feda69c1c89b6ef4a09e2136c.png)  
![](../Images/148653fcae4c7f3b62a49f7043bb6cf9.png)  
本以为可以结束了，但是进入root目录下，只有一个dave.tc文件，并没有flag文件  
![](../Images/040497bc1b34ac75eda6d897aa90574e.png)

## 8.获得flag

find / -type f -name "flag\*"没有查找到flag，想到之前提示查看mail，是提示密码不超过11个字符包含academy，字典rockyou，没有其他线索了，那应该是对/root下的dave.tc解密  
![](../Images/16a8d79fc1ead0abd0bf4ce2d7997b9b.png)  
![](../Images/6dbb6229ea0e7a91659bfe2264ef6a9b.png)  
查看root下dave.tc文件，显示乱码，只能下载下来查看一下，先升级下shell，利用nc下载到本机，strings看了一下，没看出来是什么文件  
![](../Images/bfacd46b625c2d41c5457529d1063845.png)  
![](../Images/1b0a7aa908c96abab7fc99ca6b945dea.png)  
![](../Images/23971d3e7fca5cd894d02b334030e977.png)  
经过查询.tc文件是一个磁盘文件，可以用veracrypt解密，下载安装veracrypt  
![](../Images/4f134dd819ba7f3962da398e442e76c9.png)  
![](../Images/9a6ddce77f48877ed55d6f2b7d1c28ed.png)  
先利用cat /usr/share/wordlists/rockyou.txt | grep academy > dic.txt，过滤出包含academy的密码写入到新的字典dic.txt内  
![](../Images/350819bba61e79aa7da9939f3726d74f.png)  
得到密码etonacademy  
![](../Images/ba8001becadfb1e6de192dddb4800ac5.png)  
![](../Images/527db40bc92ae9c810cad7a72d3e369f.png)  
点击磁盘1，选择dave.tc文件，点击自动加载设备，输入密码etonacademy，选择HMAC-SHA-512，然后选择TrueCrypt模式，需要输入系统管理员密码  
![](../Images/f3b5baff7ac6d3fe6c5d9f12261d58d4.png)  
进入到/media/veracrypt1/目录下，发现.secret目录  
![](../Images/8063f79a87d02f8a5a0345c1efa3180a.png)  
![](../Images/c3e71275b69e071e330b41e017db6e4c.png)  
进入.secret又发现.top  
![](../Images/fe5e77fdbdac6c4c2c962d8dfe410ae3.png)  
进入.top终于看到flag了  
![](../Images/e5fa551149cfe404b7b98e61af565b98.png)  
需要root权限才可以查看flag.txt，总算拿到flag了。  
![](../Images/2c7fb2b3681837eb49720b874f1881a4.png)

## 9.总结

很有难度的一个靶场，打了好几天，走了好多弯路啊，不过有学习到了新的思路和知识点。
