## 前言

在从业这几年中明显感觉Java站点越来越多了，特别是在需要做代码审计的情况下，不懂Java真的感到束手无策，于是抱着不服输的劲开始了本系列，从Java基础到Java漏洞靶场到编写。

## JDK的下载和安装

### JDk的下载

打开Oracle的官网下载页面，https://www.oracle.com/java/technologies/downloads/，选择jdk8版本的

![](../Images/445f11d3887c6903e0292d35cc16238a.png)

在这里需要注意在jdk 8u191之后，增加了，com.sun.jndi.ldap.object.trustURLCodebase选项，默认为false，禁止LDAP协议使用远程codebase的选项，对在测试反序列化漏洞可能会造成影响，所以我们选择历史版本jdk 8u191下载

![](../Images/59581617a4beaf5a5efbccb75ae6ed1b.png)

![](../Images/7d3281ff16b8e0b18fa60d9e517d5e06.png)

下载的时候自行选择对应的系统进行下载，我所以的mac系统

![](../Images/d3a64fbfaf5bbab803fb7857769606a3.png)

### JDK安装

Mac系统的安装相对比较简单，直接打开dmg文件

![](../Images/a0374c6a8371cdd24eb64b7072640f80.png)

安装完成后，可以在终端打开/Library/Java/JavaVirtualMachines目录查看安装的Java，在这里我下载了两个Java版本，Java8、Java14

![](../Images/772e0d5c8ac937b03280409c7a3238f8.png)

因为现在安装了两个Java版本我们可以使用alias来进行管理，在.zshrc文件增加如下环境变量配置

```






export JDK8_HOME="/Library/Java/JavaVirtualMachines/jdk1.8.0_191.jdk/Contents/Home"
```

执行source ~/.zshrc进行加载,就可以使用jdk8和jdk14进行管理了

![](../Images/8e233c8fddd9c8f883c94409955470bc.png)

## tomcat的下载和安装

### tomcat下载

进入官网https://tomcat.apache.org/，选择download下的版本

![](../Images/827a88522b4d5bd1710491f7a2632f33.png)

一般下载最新的tomcat即可，如果使用过程中有其他问题还可以锻炼下排错哪里，要是不行直接可以下载后退一个版本

![](../Images/399f3d7e83aa805e2f8cf27ce952ec3f.png)

### tomcat安装

下载后将文件移到想存放的目录，然后进入Tomcat的bin目录下，右键打开终端

![](../Images/c0c9e44d9f00883225d6e7703ca538b7.png)

![](../Images/b8f9954d6db449bd81b53d6f23ed82e1.png)

将终端赋予catalina.sh，startup.sh，shutdown.sh等文件可执行权限

```

chmod +x shutdown.sh && chmod +x startup.sh && chmod +x  catalina.sh
```

这时候就可以执行 ./startup.sh就可以启动Tomcat了,输入127.0.0.1:8080进行验证

![](../Images/f1744c52ebecabcde2556f7b546ecc72.png)

![](../Images/0d2c8279ee4c77cdd22a9fcda065cd21.png)

关闭Tomcat执行./shutdown.sh

![](../Images/b57aae53886b38fbe655dfbb3a75ffe3.png)

## idea下载和激活

### idea下载

打开idea官网https://www.jetbrains.com/idea/ 选择历史版本2021.2.2，2021.2.2之后的版本使用试用功能都需要进行注册

![](../Images/41bb72b379694ef39bc70ef9ec1b67b8.png)

![](../Images/9dd0f9f6bdc0bf3db6e0fe329057337f.png)

![](../Images/95b481fe01b85790a618a5ec1b04bc90.png)

### idea激活

![](../Images/66728926b0c44afec5a6dd937dc8713b.png)

![](../Images/4b61f42f0cd47abc92f186fce6a85880.png)

![](../Images/92aa6e75a6098c7e3b91b8b1285316ba.png)

![](../Images/9b5c170a5c897819d5e5fd16acaa602a.png)

![](../Images/bdcc54a0eae51f27990ef61bf148e414.png)
