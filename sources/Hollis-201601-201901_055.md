我想大部分都知道 i++ 和 ++i的区别，i++ 就是先拿i来使用，之后再自增加1，而++i则是先自增加1，在拿i来使用，例如对于下面这两个语句，我敢保证大部分人都会做：

  

```
int i = 1
;println(i++)
```

  

```
int i = 1
;println(++1)
```

  

答案分别为 1,2。对于这个答案我猜大多数人都能答出来。不过 i++ 和 ++i 这两个操作，在内部是如何实现的呢？

  

我们先来看另外一个问题：

  

```
public static void main(String\[\] args) 
{int i = 1
;out
.println(i+++i++);out
.println(i);
```

  

这个比刚才那个难了点，答案分别是3，3。假如你对这个答案的由来了如指掌，那么你大不可必往下看，假如你不大理解或者想从底层的汇编指令的来了解这个操作，那么你可以看看我的解释。

  

首先我们先来看看 i++ 的题，主要是为了后面好解释点。

  

```
int i = 1
;println(i++);
```

  

这两行代码的部分汇编指令如下，注意，我只列出了几个重点的汇编语句：

  

```
ICONST\_1 //把常量 1 加载到栈顶
 1 //把栈顶的元素弹出，并赋值给局部变量表中位置为“1”的变量，此时指变量i。这两句就相当于 int i = 1;

//接下来执行第二行代码
 1  //把局部变量表中位置为“1”的变量加载到栈顶，即把i的值加载到栈顶
 1 1  //直接把局部变量表中位置为“1”的变量加1，即把 i 加1。注意，这条指令并没有修改操作数栈就把 i 加1了。
println (I)V  //把栈顶的元素打印出来，此时栈顶的元素是 1。所以打印的是 1
```

***注：可以左右拉动***

  

所以，此时打印的是1。

这下关于 i ++ 的懂了吧？

  

那我们来看看 ++ i 与  i ++  的汇编指令有什么不同。

  

```
int i = 1
;println(++i);
```

  

对应的部分重点汇编指令如下：

  

```
//和上面i++差不多，不过IINC 1 1 和ILOAD 1这两句的顺序调换了。

 1
 1 1 //直接把局部变量表中位置为“1”的变量加1
 1  //把位置“1”的变量压到栈顶，此时栈顶的元素是 2
println (I)V //所以打印的是2
```

接下来我们来分析这个程序

  

```
int i = 1
;println
(i+++i++);println(i);
```

  

这里先说一下，按照运算符号的优先顺序，i+++i++等价于 (i++) + (i++)。

  

对应的部分汇编指令如下：

  

```


//第一行 1

 1
 1 1
 1
 1 1
//把栈顶的两个元素弹出相加之后在把结果放回栈顶
println 

(I)V 1
println (I)V
```
