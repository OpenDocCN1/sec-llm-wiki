# 作为一名全栈开发，老板竟然让我修U盘。


  

身为一名全栈程序员

  

居然要我修电脑，修打印机。

  

你以为我会和领导说告辞？

  

不！

  

面对需求程序员永远不会说不！！！

  

而且我真的会，所以我都修了，我甚至还在公司教人用excel。

  

不就是偶尔修修电脑嘛，理工男应该多多少少都会点。

  

直到周六的时候，老板的助理跟我说

  

“你帮我看看U盘怎么了”

  

  

![](../Images/3f43b1e15c3a584d4f084a861a9ea6a3.png)

  

我一开始以为是那种假U盘，就是那种动不动标着128G，但实际容量只有几百M的U盘。我插到电脑上看了一下，没有任何反应，但是我扭了扭，就有反应了。可能这U盘有脾气，要摸一摸抚慰一下？

  

![](../Images/1de2ee1e25da66211d59684c19e6490b.png)

  

当然不是

  

以我多年的经验，其实也就几个月吧。肯定是插口的问题。

所以我拆开看了一下。

  

![](../Images/929dd5d61fe27c5d3a0cd1c915bb31d6.png)

  

没错，引脚断了，断了三根，不过我拆开的时候，全弄断了。

天啊，我要修这玩意吗？？

第二天周末，我陷入了沉思，这完全不属于我该做的了吧~~~

但是！！！

  

程序员永远不能说不！

  

我今天带着这玩意来上班了。

  

![](../Images/f252e9750a63dd5542ae2b59c458db3e.png)

  

  

开始点了几下，发现没用，点不上，要焊锡丝才行，但是我的已经用完啦。

上某宝看了一下。

  

![](../Images/2c4192564a0dc71e6d8bc74ac452871e.png)

  

看到这个价格，我心在滴血，就我这点工资。。

  

不，程序员永远不能说不！！

  

我想其他办法。

  

我一开始以为易拉罐是锡的，所以花了两块五的巨资买了瓶饮料。

  

![](../Images/acfbdb5b5c1c5d5b548d37b5ef7be2e7.png)

  

慢慢的一口一口的喝着，平时都没机会享受碳酸饮料，含着泪喝完。剪开。

  

![](../Images/d8ebc8ba0720bc0a18c06f94f2220122.png)

  

然后发现这不是锡！！

  

![](../Images/c664299786845729636b2d3ebc6c122a.png)

  

我有想过放弃，我的确胜任不了程序员的工作，我修不好U盘，给广大程序员朋友丢脸了，我也没必要在这行做下去了，准备提交辞呈。

  

但是，我的心中在呐喊：程序员永远不能说不！！

  

然后我换了个方式，找来一个电路板。（这里要感谢一下老板助理，为我提供了电路板）

从上面一点一点慢慢扣。扣除多余的锡。

  

![](../Images/1c371b1ec5369fe99f2759563ec5e846.png)

  

然后成功焊上去了。

  

![](../Images/86e77788f04f5714be018f519c4fd1b4.png)

  

虽然焊的不好看，但是看上去没问题了。

插电脑上试试。

  

![](../Images/0adc026b9aea4c047b7b80f4df5f2885.png)

  

U盘的头上撒发着绿光~。

没有问题！

封好！

  

![](../Images/0d1ea2927088ca54492e4a8a37cac4cf.png)

  

我再一次的为程序员这个群体赢回了尊严！

我们程序员，永远不会说不！！（骄傲）
