# 女程序员：秃头的富婆不好当

作为女生，和众多异性一同工作是怎样的体验？  
被照顾、还是被冷落；感到自在、还是感到尴尬；会更高效地工作、还是会束手束脚？  
事实上，上述情况都会存在，也可能不会发生。在我们新开设的栏目**《职场少数性别》**里，我们将寻找各个行业中，容易被忽视的少数性别群体，从另一个视角看待这份工作。  
第一期的主角，是以理性与逻辑闻名的职业——**女性程序员**。

  

  

  

  

1

  

 我受到照顾，也受到偏见   
Dodo，24岁，测试，深圳特长：头发

  

刚开始工作的一个月，因为对业务不熟悉，经常找同事答疑。男同事对我都很友好，会分给我一些不那么难的工作，要加班时也常常让我先走。

  

我一直把这些当作大家对我的照顾，直到一次偶然听到同事间的谈话：

  

“和女生在一起工作很开心吧？”

  

“也就那样，女生嘛，期待不用太高。”  

![](../Images/146787eb7ae66210054edd8081c1fc3c.png)

  

那一刻才意识到，在一个男生占绝对主导的行业里，遇到异性他们的第一反应是怀疑——女生真的写得好代码吗？

  

所以那之后我就没再向同事求助过，憋着一股劲要写出让所有人都认可的代码。程序员都很看结果，只要能拿出成绩来，男生对你的态度就会180°的转变，就像代码界的那句至理名言： Talk is cheap, show me the code.  
  

  

  

2

  

 面试官问我：你会喝酒吗？ 

  
angel，28岁，后端，武汉特长：一句话怼人  
  

在武汉这种二线城市，性别带来的影响很明显。

  

一次面试过程中，面试官一脸严肃地问道：“你会喝酒吗？不会喝酒减分。”我当时心里直翻白眼：“难道现在程序员也要陪酒了吗？”一句话把他怼回去：“我不陪男人喝。”

  

正式入职工作后，一些小事也成了问题。以前在大公司女程序员虽然不多但也不少，现在成了公司里唯一的女程序员，姨妈突袭时没法再找同事借卫生巾、男同事偶尔聊天时开车，我还要当作不经意地保持微笑。  

![](../Images/d3b0fd16e1442f1512013c874e3154fb.png)

  

跟同事一起走路也是，男生走得快，经常跑很远才注意到少了我。有时他们又对自己过分关照，比如夏天穿裙子漏一点大腿，男同事就不好意思找我说话。

  

哦对，第一天上班和组里男同事们一起吃午饭，饭后老大就私信我说：以后可以找公司别的女生一起吃饭。所以后来每到饭点，我就自觉去找前台行政姐姐们了。

## 

 程序员是有钱，但也不是人人有钱 

  

露露，26岁，前端，上海

特长：把月入5万的收入过成月入5千的生活

  

同学们知道我要去做程序员后的第一反应是：哇那你以后就要成为一个秃头的富婆了！

  

外人眼里，每个程序员都是深藏不露的大款。有一次买衣服我觉得价格贵了，销售问我是做什么行业的，我说程序员。对方翻了个白眼：“程序员那么有钱你还嫌贵。”  

![](../Images/c3ac62df771573ea85952431e0d2fa56.png)

  
我的岗位应届生工资在 15k-20k 之间，工作三到五年的是 30-38k。相比其他岗位，程序员的薪水是高一点，但也是每天加班熬夜换来的辛苦钱，轻易舍不得花。

  

程序员工作压力大，每个月最开心的时刻就是收到工资入账短信的瞬间。父母本来一直劝我回家考公务员，理由还是“稳定事少离家近”那一套，我被问烦了把工资单甩给他们，从此再没劝我回老家。男朋友爸妈知道我的收入也开心，觉得我事业有成，男朋友跟着我有着落了。  
  

  

  

4

  

 难的不是上班，是下班 

   

八爪鱼，25岁，上海，测试

特长：特能熬夜

  

程序员这行加班是常态，加班就意味着没有社交。公司男同事下班后还可以一起喝酒撸串打游戏，这就苦了我们这种单身程序媛。

  

也不是没试过和同事们一起活动，一次我和另一个姑娘还有男同事一起去 KTV，整晚男生们最兴奋的瞬间，是有人点了一首柯受良的《大哥》。当身边男同事嘶吼着唱出“我不做大哥好多年”时，我和那个姑娘从彼此的眼神里看到了想说的话：“下次一定不来了。”  

![](../Images/f1563e57289980e4cb007cbaae158189.png)

  

做程序员后，跟外界交流的机会明显少了，没有那么多狗血八卦可以分享。偶尔闺蜜聚会，自己搜肠刮肚想找出一个好笑的梗来暖场，却只能讲出“某公司数据库泄漏”这样的圈内新闻。

  

所以很多人说程序员比较宅，很多时候其实是“不得不宅”，在这一行做久了很容易感到孤独。深夜下班打车回家的路上，刷刷微博看看小红书，才能找到和真实世界接轨的感觉。

 化妆？真没那个必要 

  

子恒 ，26岁 ，北京，后端（java）研发工程师

特长：女生里最懂数码外设

  

我的项目属于生活娱乐相关，出点 BUG 可能就影响到上千万用户，所以每逢项目上线时都要熬夜盯后台看数据，特别紧张。工作四年，发际线都快赶上隔壁入行8年的程序大哥了。

  

带妆上班是不可能的，前后左右坐着的都是糙汉子，连个和自己比拼姿色的同性都没有。男生们也不在意我的形象，有次我换了新发型，一周之后坐在我对面的小哥突然说到：“你剪头发了？”  
 

![](../Images/f275da01e943068eef37f569efc97bb3.png)

  

不过偶尔开视频会议，打开摄像头的那一刻还是会被自己丑到，对自己的外貌也越来越不自信了。  

  

最直接的表现就是微信头像，以前还很喜欢用自拍、全身照来当头像，后来就慢慢变成半脸、侧脸，再到现在就只敢露个背影了。  

![](../Images/c59d656db3dbbb82e803c2a71edf072f.png)

 不是所有程序员都是996 

  

qiqi，24岁，北京，运维工程师

特长：准时下班

  

我毕业时手里有两份 offer，一份互联网大厂、一份国企银行。  

  

我对工作的要求是“工作是要有保障地混日子”。而互联网程序员替代性很强、抗风险能力并不高。所以最后选择了现在这家国企银行，虽然也要写代码，但也会负责项目管理等工作。和我一样，身边女生单纯做研发的不多，后期也多会转到产品经理或测试的岗位。

  

现在每天的作息是晚上12点睡觉，早上6点半起床，8点半到公司上班，下午5点半下班，作息时间比多数白领还要健康。

  

不是所有程序员都是996，还有我这种955。  
  

![](../Images/8c1898c72e66ae542360b979fa04f130.png)

 男朋友对我说：“你也太不女人了” 

  

小庆，28岁，北京，全栈开发

特长：与产品经理对骂百战百胜，但吵不赢男友

  

和一群男人工作久了，说话办事多少都带着点直男思维。

  

有一次和男朋友外出旅游，五天时间我就带了一条牛仔裤，做公关的男朋友打开我的行李箱时惊呆了，说了一句：“你也太不女人了。”

  

做程序的人习惯线性思维，男同事常常直来直去，只考虑项目和进度，女性程序员在沟通上的确会更好一些。  
但也有遇到过蛮不讲理的同事，尤其是把自己当上帝的那种测试，男程序就很头疼，无法沟通，又打不得骂不得。我的情况就好很多，男测试通常比较客气，面对女测试大家都是公事公办的样子。毕竟真要撕起来，我也没带怕的。  
![](../Images/de8c7b8168566dca8d14cf85ee24d61c.png)

 找个老实人嫁了？老实人早就被抢走了 

  

杨杨，26岁，北京，前端开发

特长：把天聊死

  

IT 圈子里，一般公司内部都能消化完，大部分是程序男找测试女配对，或者程序男找产品女配对，也有少部分程序男找程序女。

  

一般两个程序员在一起不会讨论技术，因为每个人都觉得自己的代码无懈可击，情侣讨论这个话题情绪很容易不稳定。我是觉得程序员男+测试女真的是真爱，因为自己经常被测试折磨得分分钟想切腹自尽。  

  

我对象也是码农。在这一行大家喜欢内部消化的原因，一是知根知底，交流起来更便捷，还能形成一套我们自己的语言。最重要的是，他的程序员式含蓄的浪漫只有我懂，正常男人的浪漫我反而觉得矫情。  

![](../Images/d699494443f93674b9f8b5deb7fb51a5.png)

  
另外一个原因是这份工作的确比较忙，也没时间交流。之前朋友介绍过一个音乐学院的男生，特别好看。但是因为那一阵子比较忙，我们约了两个月都没见一面，后来他把我删了，跟我朋友说我好像不喜欢他。真的冤枉啊我只是太忙了而已。

  

工作久了还有一个发现，外人看起来像“单身宅男”的男程序，很可能已经结婚、甚至孩子都有两三岁了，而且男性程序员的另一半普遍颜值都不错。其实很多时候不是程序员颜值差，而是他们的心思没有花在穿衣打扮上。只要另一半多多留意，每个“潜力股程序员”都是可以被改造的。

  

当然了，他们也都还挺有钱的。   

  

  

在结束之前，和大家分享几个创作过程中的趣事：

 ❷ 和另一位的对谈在深夜，聊了一半对方突然把电话挂掉，之后再无消息，两个小时后回复说：“不好意思，刚 debug 去了。”
