Java老矣，尚能饭否？

Java语言诞生于1995年，要追究起历史，可能比这还要早，早在1990，SUN公司的Java之父James Gosling等人就开发出了Java语言的雏形，最初被命名为Oak，后于1995年5月以Java的名称正式发布。


从95年至今，已经有24个年头。24年，足以让一个呱呱坠地的孩童长成一个风华正茂的少年。但是24年，对于日新月异的技术来说，已经够长了。


试想，24年前那些奋战在一线老码农们，现在还在写代码么？恐怕是个未知数。


而且，伴随着越来越多的新的开发语言的推出，如最近几年炙手可热的Python、Go、Kotlin等。


很多人开始担忧起来，尤其是很多从事Java开发的程序员们。Java到底还行不行？会不会被其他语言取代？


据最近一次编程语言排行榜（201902 TOIBE）统计结果显示，Java语言依然稳居第一。



那么，可以这么说：Java在未来的某一天可能会被取代，但是，这一天可能不会太近。毕竟至少目前还没有看到Java的替代者。


无论是服务端，还是移动端。目前Java的使用率都是排在第一的，这其中当然有Android的功劳。


最近的HackerRank 发布的开发者技能调查报告显示，2019年最值得学习的语言是GO语言。的确，GO语言确实很值得学习，但是作者认为，GO语言并不会直接取代Java。


Go 语言不会吞食底层到 C 和 C++ 那个级别的，也不会吞食到高层如 Java 业务层的项目。Go 语言能吞食的一定是 PaaS 上的项目，比如一些消息缓存中间件、服务发现、服务代理、控制系统、Agent、日志收集等等，没有复杂的业务场景，也到不了特别底层（如操作系统）的中间平台层的软件项目或工具。而 C 和 C++ 会被打到更底层，Java 会被打到更上层的业务层。（来自：左耳听风）


所以我之前说，GO语言是那些想多掌握一门语言的Java开发者最好的选择。


而且，目前Java生态体系完善的简直变态。无论是社区、开源、工业化标准、框架、开发工具等等都十分完备。


作者认为Java语言"尚能饭"的另外一个原因是，正因为Java语言的生态体系极其完善，所以真正能够做到彻底精通Java的Top级程序员越来越少。


很多人都停留在用的层面，就是所谓的"知其然，不知其所以然"。


道家云：有道无术、术可成。有术无道，止于术也正是这个道理。


这也是为什么我经常告诉我的粉丝们，要注重Java基础知识的学习。要多多深入底层。多多了解现象背后的本质。在学习的过程中多问自己问什么。


所以，我多次的推荐大家反复阅读《深入理解Java虚拟机》、《Java编程思想》、《Effective Java》等这些所谓的神书。推荐并不是人云亦云，而是真的需要反复揣摩与汲取。


以上，就是在昨天发布文章《2019年最值得学习的编程语言，竟然不是Java》之后有粉丝问我是不是Java不行了等问题之后的思考。
