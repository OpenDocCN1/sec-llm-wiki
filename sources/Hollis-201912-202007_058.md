# 从3000米高空，一跃而下…

![](../Images/9391e379c1cec36027fa3f3dc2962762.png)Hello，大家好，我是Hollis，今天是端午节假期的最后一天，今天这一条文章不是技术文章（想看技术文章的可以看今天推文的第2条，我放了一个我之前发在小号上面的文章）。写了很久技术文章，今天想划水一下，算是写的一篇游记吧，让你们了解下技术之外的我。  
**技术之外**我一直是一个比较喜欢挑战的人，比较典型的表现就是我喜欢尝试各种有些难度系数运动。  
就像我去游乐园，一定要玩玩过山车一样。之前有一次去迪士尼，体验<创极速光轮>这个项目，因为起步太快，把我的下巴都磕出血了，但是下来的时候我还是感觉很爽，要不是排队的人特别多，我真的想二刷、三刷。还有就是像攀岩、拳击、滑翔伞、赛艇、潜水、蹦极还有跳伞这些运动一直都在我的计划列表中。之前已经体验过了攀岩、赛艇、拳击还有滑翔伞，剩下的就是潜水、蹦极和跳伞没有体验过了。本来在去年五一放假的时候，去泰国玩的时候是准备进行潜水的，但是因为天气等原因没有玩上，还挺遗憾的。**作一名程序猿已经很辛苦了，所以我建议大家培养一下自己的爱好，不仅能够适当的满足一下自己，还可以激励自己更好的努力工作，哈哈哈....**  
**心心念念**最近，在端午节放假的时候，我又体验了一项新的运动，那就是我一直心心念念的——**跳伞**。因为我在杭州，离我最近的就是千岛湖有一个跳伞基地，所以就选择了这里。其实从很早之前我就想过去玩一下跳伞了，但是要不就是时间不允许，要不就是家里人不太同意。所以一直就没成行。最近的端午节终于没什么事儿了，也说服了家里人，于是就给自己安排了一波。![](../Images/af028b63d32ca7d2c241433b1374d4be.png)  
跳伞的项目玩的内容其实都差不多，无外乎就是坐飞机上升到固定的高度，然后和教练一起跳下来。而千岛湖也有很多家跳伞的俱乐部，大致的内容也都是一样的，定价也都差不多。主要有两个价位，分别是手持goPro相机拍摄、第三方摄影跟随拍摄。肯定是第三方跟随拍摄会贵一些，这种会除了教练以外还有一个摄影师跟随跳伞进行拍摄。我定的时间是6月26日，在前一天我们就到达了千岛湖的酒店入住。![](../Images/7de32967c9510cf07b25addfa91206ef.png)  
  
**一波三折**但是前一天一直在下雨，所以中间跳伞的工作人员打电话通知过一次。大致是告诉我们，因为6.25这天下雨了，所以6.25没有飞，6.26如果不下雨，那么上午需要先让原定6.25的游客先飞。所以，顺利的话，我们最早可以在6.26下午飞。不顺利的话就要顺延到6.27飞。果然，**墨菲定律**再一次应验了，第二天又通知因为有飞行考试，所以当天下午不能飞。好在到了下午3点多，通知可以飞了，但是要求5点之前赶到。（所以，建议大家如果想要体验跳伞的，还是要提前查好天气情况）因为酒店离机场有60+公里，驱车要1个小时，所以我们收拾收拾很快出发了。![](../Images/9db1f223a0c85c233fcf9976c4b3854e.png)  
但是路走到一半，在高速上，下大雨了，很大很大的雨，完全看不见路的那种。我们在下了高速以后联系工作人员询问是不是要返程，工作人员表示"还是先过去，如果天气好了的话还是可以飞的。"![](../Images/95243af2822f1ca2de21eb5bb3a1f615.png)  
我们继续赶路，过了几分钟，雨停了，天空放晴了，很晴朗，心情也是。等我们到了之后就直接进去了。这里还要提一下，如果有不飞的亲友想要陪同进到休息区，是需要额外收费的。![](../Images/0dcadf948b92de5a76eab16a7bcedd38.png)  
分别收两次，安检收20，休息室收20。为了怕家人因为不知道里面的情况而更加担心，我们还是选择了让家属陪同。  
**一跃而下**进去之后就是签署责任书，然后就是穿上装备。等待飞行。![](../Images/7b063a529934911415d73a53b0a8ba31.png)  
工作人员为了我的体重之后，默默的给我分配了一个比较瘦的教练...和我一起飞的还有一个小姐姐，独自一个人来的，很勇敢。上飞机之前，还有最后一个事宜，那就是会给讲解一些注意事项，动作挺简单的，就是自由落体的时候把自己身体摆成一个香蕉的形状。打开降落伞之后就可以张开双臂了。**我当时完全没有紧张，反而很兴奋。**![](../Images/5fdbd8907884348f585e6017298e2247.png)  
上了飞机之后，大概10几分钟就可以飞到11000英尺（3300米）的高空了。飞机在千岛湖上方会盘旋一会，然后就开始进行跳伞了。轮到我的时候，我还挺兴奋的，没有丝毫犹豫，坐在分机的舱门口，随着教练一起，一跃而下。![](../Images/d12f822a5513844ed197c6141d1fac95.png)  
刚开始下降的时候是不开降落伞的，大概有20-30秒的完全自由落体。这种感觉怎么形容的，就是完全没有感觉，整个人被风吹的呼吸都很困难，然后胳膊和腿都是麻木的。风在耳边疯狂的吹，人也在急速的下坠，比我之前玩过的任何一种跳楼机都要刺激。![](../Images/9eaaf5861bbb24e85856b82f29aa29dd.png)  
之后教练就会打开降落伞，之后就可以张开手臂，拥抱天空了。  
在天空中，可以俯瞰整个城市，穿过云层，还可以依稀的看到山川、河流，深切的感受到人类在大自然面前的渺小。**我还大喊了几声，感觉这个时候的呐喊，可以喊去所有的不如意。**![](../Images/55a497d1746dc0e65089d6854a77a290.png)  
在降落的过程中，有几次教练操控降落伞调转方向，我有种要被吹跑的感觉，因为风真的很大。教练们都很厉害，虽然那天风很大，但是还是可以安稳的降落到指定地点。降落点是一块草坪，会在草坪上滑行一段时间，所以强烈建议大家，带一条备用裤子，尤其是刚刚下过雨的天气。![](../Images/a76a0dd064f3dbe43e1db554b5dd3366.png)  
在安全着陆后，需要回到休息室等待视频。工作人员会把录制的原片以及剪辑后的大约1分钟的短片放到一个U盘里。（剪辑后的视频我上传到了视频号，文末有直达二维码）并且还会给颁发一个证书，证明我们来过。（教练和我还挺有缘，我叫Hollis，他叫Holly，...）![](../Images/887bca75eaeb8265ee138acb03d2e61d.png)  
在休息室，遇到了刚刚过来还在准备的游客，他们问我感觉如何，我只能用一个字"爽"来表达我的感受。实在是太爽了，男人啊（当然，有勇气的女孩子也一定要试试），这一辈子一定要体验一次；放下所有的东西，把自己完全交给天空与大地，然后大喊几声。**回来后，继续努力工作。**  
**有点后怕**最后，还是要说一下，这种游戏，其实还挺危险的，在上去之前我没紧张，开始飞的时候也没有太大的感觉。**但是在着陆之后，有点后怕...**
