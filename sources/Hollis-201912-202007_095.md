# 你知道荷兰旗问题吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650131238&idx=3&sn=fc9d7b051b1e1ab4375e7bc2450e0272&chksm=f36bd607c41c5f1128d61bff7cb9734c53f4791a31294dadeeb6295914cf5b4913b99ae21fd1&scene=126&sessionid=1681657558#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650131238&idx=3&sn=fc9d7b051b1e1ab4375e7bc2450e0272&chksm=f36bd607c41c5f1128d61bff7cb9734c53f4791a31294dadeeb6295914cf5b4913b99ae21fd1&scene=126&sessionid=1681657558#rd)

 荷兰旗问题又称三色排序，或者彩虹排序，![](../Images/2b3065526370334d99e0d95f493940c4.png)因为荷兰旗就三种颜色嘛，那这道题的问题就是给你三种颜色，按照给定的顺序排好。当然了，题目的问法各种各样，有的给数字，有的给字母，但本质都是一样的。比如给你一个只含有三个数字的数组：312312312231111122113，  
要求按照 1 2 3 的顺序排好，即：111111111222222222223333333333  
（请不要真的去数数，认真你就输了）![](../Images/149d9c43f057c548dec769e1eb82126c.png)![](../Images/a9e4247cee1b73d825e5b35aec8e60b2.png)![](../Images/df38170291721304fc3861e1a6230170.png)还是用我们经典的「挡板法」。在快排中，我们用了两个挡板把数组分成三个区域：

> <= pivot；未排序区间；> pivot

那么这里就要三个挡板，分成四个区域：

> 1, 2, 3, 未排序区间

### Partition

具体说来，用 i, j, k 这三个指针分一下：  
\[0, i): 存 1  
\[i, j): 存 2  
\[j, k\]: 未排序区间  
(k, array.length-1\]: 存 3这里 j 放在未排序区间的左边和右边都行，但基本上大家都是放左边，所以我们也没必要“标新立异”。

### 初始化：

i = 0;  
j = 0;  
k = array.length - 1;  
这样才能保证 1，2，3 的每个区间都为空。我们通过**观察指针 j 指向的元素**来不断缩小未排序区间，直到为空。

### 例子：1232312

![](../Images/2836d47582b05e29d3236fdd32b0b90a.png)为了好看，排好序的元素我们用 RGB 三原色标示一下。

### Step1.

指针 j 指向 1，而 1 应该放在 \[0, i) 区间内， 这里应该把指针 i 和指针 j 所指的元素交换一下，并且俩指针往前走。虽然在这步看来是否交换没什么区别，但是如果 i 和 j 之间有元素，就有区别了，比如 Step7.![](../Images/345f14f9cbfbda996d8cdfac092dcd53.png)

### Step2.

指针 j 指向 2，而 2 应该放在 \[i, j) 区间内，所以 **j++.**![](../Images/af62c5c7157c6c05f0ef555e26939f55.png)

### Step3.

指针 j 指向 3，而 3 应该放在  
(k, array.length-1\] 区间内，所以这里  
**j 和 k 指向的元素交换一下，并且 k--.**注意这里就不能 j-- 了，因为新换回来的元素还没瞧呢，不知道它是几。![](../Images/5a12ed7be0a650223c810ea9dcba6020.png)

### Step4.

指针 j 指向 2，同 Step2，直接移动指针 j 即可。![](../Images/5cbda733a1d4c07058a772038eef68dc.png)

### Step5.

继续移动指针 j。![](../Images/613a5e17c4f5c78322d13630a4f9096b.png)

### Step6.

同 Step3.![](../Images/a823d31e129ba34524c10d9ec195535a.png)

### Step7.

这一步就很明显看出来了，  
由于 1 应该放在 \[0,i) 区间，所以这里把指针 i，j 所指向的元素交换一下，并且 i++, j++.![](../Images/548b61cd3709bedccd6b63909220daa5.png)这样未排序区间为空，我们就排好了～![](../Images/f721e312b6912d6a413fa32c0eda5355.png)![](../Images/93de589839663f2ba1726f15beaaaeea.png)

### 时间复杂度

这个算法的 bottle neck 就在这个 while loop 里了，每次循环是 O(1)，总共是 O(n).

### 空间复杂度

O(1)![](../Images/f930a25b67802f9586fc94bd0a35dc8d.png)
