# 小学生五星分期，钉钉在线求饶

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650126351&idx=2&sn=d39afd05111bd21084770ffcbcfd6bdc&chksm=f36ba52ec41c2c38a1e06c4aefbac06cf0935833a890092e62e4031a3031a54185e9d317e622&scene=126&sessionid=1681657602#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650126351&idx=2&sn=d39afd05111bd21084770ffcbcfd6bdc&chksm=f36ba52ec41c2c38a1e06c4aefbac06cf0935833a890092e62e4031a3031a54185e9d317e622&scene=126&sessionid=1681657602#rd)

大家对2003年的“非典”事件还有多少记忆？  

  

小灰当时年纪还小，只是一个读高二的学生，但我对当时的很多生活片段仍然印象深刻。

  

那段时间，学校放了整整两个月的假，布置了一大堆作业。电视上也开通了一个新的频道 **空中课堂**，许多名校的老师开始在电视上为我们讲课。  

  

那时候的小灰年少无知，根本没有什么自制力，在放假期间天天宅在家里上网打游戏，对电视上的空中课堂几乎就没怎么认真看过。

  

但是好在天高皇帝远，小灰究竟是在家乖乖看电视上课，还是在摸鱼，学校老师是不知道的。

![](../Images/806f8f948521eab877bab9a4753d2da8.png)

  

  

历史总是惊人的相似，没想到在十多年后的今天，一场新的疫情改变了我们的生活节奏。

  

上班族们不得不远程办公，学生们也无法正常上学，于是“空中课堂”回来了，这一次不是在电视上，而是以阿里的产品 **钉钉 **作为平台，全国各地的教师秒变网络主播，通过钉钉直播来为学生上课。

  

在钉钉上远程讲课，小学生们要是不认真听课怎么办？别担心，这次时代变了。

  

以前你不能跟电视机里的人互动，但是在钉钉上，你要每天固定时间打卡，上课过程中老师还会给你提问，每天还要完成相应的作业......想摸鱼？不可能！

  

这届小学生表示：“我太难了......”  

  

![](../Images/059dd6d1dff1fcfab5d16d70f2bf971e.png)

  

但是，长江后浪推前浪，一代更比一代强。不知道是谁传出的消息，说App Store上的应用如果评分低于1分，就会被迫下架（实际上不可能低于1分）。  

  

于是，为了能让钉钉下架，从此脱离苦海不用上课，小学生们纷纷在App store上给阿里钉钉评分，评语里都是满满的“感激”之情：

  

![](../Images/87e686b4cf1b3826ddf9ffc3c16120c1.png)

  

![](../Images/24ff66f3fcd7f477aafb5fe163a3273d.png)

  

众人拾柴火焰高，原本在App Store上评分高达4.9分的阿里钉钉，最低曾经跌到了1.9分，目前稳定在2.4分：

  

![](../Images/aef374c9d96c706d2a9fd9cff01ca67f.png)

  

不得不说，这一届小学生，真的很行！  

  

小学生们的心情，小灰是充分理解的，在人生最快乐的年纪，谁不想愉快地玩耍呀？但是，你们是祖国未来的希望，好好学习是你们肩负的责任，可绝不能走上当年小灰的老路！

  

于是，小灰动动手指，果断给了钉钉一个五星好评。钉钉加油！
