# 开发者在行动！中国防疫开源项目登上 GitHub TOP 榜

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650126079&idx=1&sn=4c86887b86e1685e0e023aad5cea59c2&chksm=f36babdec41c22c890c7aa92c8c0d16c9f84ac94df2b67afff42b229326c875b6e6bcb6791e2&scene=126&sessionid=1681657610#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650126079&idx=1&sn=4c86887b86e1685e0e023aad5cea59c2&chksm=f36babdec41c22c890c7aa92c8c0d16c9f84ac94df2b67afff42b229326c875b6e6bcb6791e2&scene=126&sessionid=1681657610#rd)

用开发者们的方式支援这场没有硝烟的战争！  

![](../Images/df3fb5a7e2a6d0f879596a124fdb385a.png)整理 | 唐小引出品 | CSDN（ID：CSDNnews）

  

截止北京时间 1 月 28 日下午 15:47，全国确诊新型冠状病毒的数字已经到达了 4586 例，疑似高达 6973 例，医护人员们「逆行」奔赴疫情前线，快手、华为、百度、阿里、字节跳动等科技公司纷纷伸出援手，支援武汉等地。

疫情面前，众志成城，中国开发者们也都行动起来，譬如，火神山医院紧急招募 IT 运维志愿者在非常短的时间内便已到位。并且，近日，一个名为「wuhan2020」的开源项目登上了 GitHub Trending TOP 榜，已收获 1700+ Star。

![](../Images/939d860e3749721cecf70f4fe568ee46.png)

这是一个武汉新型冠状病毒防疫信息收集平台的开源项目，为什么会在 GitHub 上发起这样一个项目，其发起者撰文表示：「针对目前新型冠状病毒疫情，武汉及周边各市县均爆出物资供给不足的情况，而重大公共卫生事件在公共社会事件中属于较复杂的类型，统筹安排难度大，周期长，利用数字平台优势，让各供需方进行分布式自助对接可大幅提升效率，而目前信息采集与公布平台不一致，信息散乱很难进行有效沟通，大量图片信息不利于实时沟通。故发起该项目，旨在统一收集本次事件中相关事务处理方的信息，并利用开源和分布式协作优势实时更新并通报，提供各方的联系平台。」

![](../Images/1372f0faa1075233a897961ffc19e9b2.png)

wuhan2020 项目对各医院、酒店、工厂、物流、捐赠、捐款、预防、治疗、动态等信息进行统一收集汇总，并且还支持「需求发布」。

![](../Images/24681007d012501119ebfad4133c4183.png)

这让笔者不禁想起了 2018 年“长春长生”疫苗事件沸扬之时，一位程序员挺身而出追根溯源，花了 14 个小时找了一下长春长生们究竟卖到了哪里去。

今天，「wuhan2020」再次表示，「用技术的手段来支援这场战争，是我们开发者与程序员共同体所擅长的事情，利用数字化的优势做我们擅长的事情，我们乐此不疲。」

现在，欢迎所有开发者登陆 GitHub 一起加入，同心协力，共克时艰！
