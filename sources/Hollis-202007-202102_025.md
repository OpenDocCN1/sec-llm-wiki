# 蚂蚁金服开源的Ant Design 遭删库！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650153357&idx=1&sn=5f89ad5af686175f3d001d70f0faab20&chksm=f3683cacc41fb5ba63e8ffb958b22c2e1f924f301168431ff289aa4c3e32e92cdab1b2ce4337&scene=126&sessionid=1681657458#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650153357&idx=1&sn=5f89ad5af686175f3d001d70f0faab20&chksm=f3683cacc41fb5ba63e8ffb958b22c2e1f924f301168431ff289aa4c3e32e92cdab1b2ce4337&scene=126&sessionid=1681657458#rd)

  

大年初四，前端国货之光 Ant Design 被攻击删库了！犹记得 2018 年 Ant Design 在圣诞节暗藏的圣诞彩蛋带给了许多开发者莫大惊吓，如今时过境迁，在春节还在放假之时，Ant Design 的程序员被打得措手不及。

  
作者 | 沭七  
出品 | CSDN（ID：CSDNnews）

在程序员们还都放假过年之时，在 GitHub 上拥有数万 Star 的蚂蚁金服企业级 UI 设计语言和 React 组件库 Ant Design 横遭删库。

![](../Images/852a5c1e02976e544e18c9b7a43a79fe.png)

北京时间 2 月 15 日凌晨，Stack Overflow 有网友发问“Ant Design 发生了什么？被从 GitHub 上删除了”，其表示 Ant Design 在 GitHub 上的源码仓库被删除、官方网站无法访问，在 npm 中可以正常使用。

![](../Images/5aeb1e9c1c08b66d53ad7a4c2f682ed4.png)

对此，Ant Design 官方通过官方 Twitter 账号发表声明：“Ant Design 的 GitHub 存储库由于未知原因被删除，我们正在进行排查并寻求 GitHub 官方支持来帮助我们恢复。”

![](../Images/0bd528216684824509b41f90a53adc7b.png)

不过幸运的是，Ant Design 官方表示，“暂时没有用户受到此次事件的影响”，同时，“我们依然是 GitHub 上 Ant Design 项目的 owner（所有者），正在和 GitHub 一起努力找回项目。”

![](../Images/0059cbc3f6dfa57f044ce6e4b176e13a.png)

  

截止目前，Ant Design 的官网已经可以正常访问，GitHub 源码库也恢复访问。

![](../Images/fd83807892c7f0ceec33643e673d2707.png)
