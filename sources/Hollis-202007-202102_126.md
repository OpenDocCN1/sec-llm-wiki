# “对不起，因为鄙国法律要求，我不能合并你的代码”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650150190&idx=4&sn=95a1d6c64f517104698d909ceb469df3&chksm=f368080fc41f8119d64da8df286cfe3ccb43acda9ee05cf4335f607ab027e9823da67e904c5d&scene=126&sessionid=1681657478#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650150190&idx=4&sn=95a1d6c64f517104698d909ceb469df3&chksm=f368080fc41f8119d64da8df286cfe3ccb43acda9ee05cf4335f607ab027e9823da67e904c5d&scene=126&sessionid=1681657478#rd)

原创：程序员的那些事（id：iProgrammer）  

  

Arman Ahmadi 是一个伊朗开发者，他在 GitHub 上维护着一个「laravel-download-link」开源项目。  

  

![](../Images/4afc6c767001e4172fe01a7ef43f1000.png)

  

最近有个以色列开发者 Yehuda Neufeld 想提交一个增加新功能的 PR，但是被 Ahmadi 拒绝了。  

  

![](../Images/9fd7493e21e683289b0114f4d54da1ce.png)

  
Ahmadi 在回复中给出了拒绝理由：  
  
\> "谢谢你的好点子。不过非常抱歉，我不能合并你的代码。因为鄙国有法律规定，不能和以色列人或以色列政府有任何关系。希望你能理解，谢谢。"

  

![](../Images/f8e7d3c321a42d41feb5c1d62fba0318.png)

  

*(补充：我搜索了一下新闻，看到有媒体报道近年来以色列和伊朗之间存在军事冲突。或许是因为这个吧？？？)*  

  

Yehuda 则回复称：  
  
\> “真是个坏消息。我希望有朝一日贵国能移除这个限制，就如同鄙国未设置如此限制。不过我相信，伊朗 ZF 的限制并不代表你的个人观点。祝好运。”  

  

  

![](../Images/466477ee1e6add4888703038bd452603.png)
