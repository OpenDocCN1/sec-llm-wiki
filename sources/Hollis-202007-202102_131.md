# 卧槽，QQ号 也能改了！！！

还记得QQ吗？QQ 最近悄悄更新上线了一个新功能 —— QID 身份卡  
那这个 QID 到底有什么用处呢？根据 QQ 官方说明了解到，QQ 的这个 ID 身份卡就类似于微信号一样。

  

**好友除了通过 QQ 号来找到你之外，还能用 QID 找到你！**  
![](../Images/958ff6a8bec01bfe43a461cdea899a14.png)

  

以后再有添加好友，直接不用数字，只需要设置自己的 ID 号，就可以了。  
就和微信号一样，对于 QQ 用户们来说，就更加个性了。  
现在的QQ号码是越来越长了，短点的好点的号都成了“靓号”，而且价格还不便宜啊...  
随着这两天QID身份卡功能的上线，每个人都有了成为”靓号“的机会，而且是**独一无二的可自定义**的，相当于有了一次自定义QQ号的机会![](../Images/95efb020516ef50e0977ad8339ea6539.png)  
**修改方式：**  
扫描下方二维码，后台回复『QQ』，获取修改链接  
![](../Images/382b7e06c761217a6be45cb0f6076fee.png)  
获取链接后 “点击”，在跳转页面选 “允许” 。会自动打开 QQ。  
![](../Images/4bdd383160cf2b120ba0f30d227bd92c.png)  
进入 QQ 之后，下方点击 「立即设置 - 设置ID  - 立即生成」，就完成一条龙操作了。  
![](../Images/1a2f523ed535204bedb90c58bd187c01.png)  
赶快去抢注吧！
