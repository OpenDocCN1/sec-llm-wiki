# IDEA 2020年最后一个版本更新了，机器学习都整上了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650149571&idx=2&sn=460dfa524400bb79486e5b131eeba379&chksm=f3680fe2c41f86f492a33be91b49725f4c661125962c28c236e452905c3bf8b422fbcdc3be9d&scene=126&sessionid=1681657478#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650149571&idx=2&sn=460dfa524400bb79486e5b131eeba379&chksm=f3680fe2c41f86f492a33be91b49725f4c661125962c28c236e452905c3bf8b422fbcdc3be9d&scene=126&sessionid=1681657478#rd)

前段时间Java 开发申请神器 IDEA 2020.3 新版正式发布：![](../Images/c612a53e41c0a3b2e266406f8649373d.png)第一时间就在开发机上更新了新版本，并且完整体验了两周了。下面介绍一下这个版本的主要功能：

### 

### **1、全新的欢迎窗口，更加人性化**

IDEA 欢迎窗口全新升级，首页增加三个选项卡，一个用于设置 IDE 界面的 Customize，一个用于插件安装的 Plugins，一个于访问帮助和学习资源的 Learn IntelliJ IDEA，另外包括之前用于管理项目的 Projects。![](../Images/f71f569fa6bc58a86d4a7f714bc3bab1.png)这是特别提一下 **「Learn IntelliJ IDEA」** ，我们可以从首页打开进入Learn IntelliJ IDEA 页面。![](../Images/a855edb1dffe7658c0cd3d8b201fdd52.png)

Learn IntelliJ IDEA

在这个页面，你可以选择多个交互课程，从中学习 IDEA 基本功能，快捷键等等。如果你是一个 IDEA 初学者建议你多使用 **「Learn IntelliJ IDEA」**  功能，多加练习 IDEA 快捷键等功能，这可以成倍的提升你的编码效率。如果你使用其他版本的 IDEA，暂时不能升级，也没关系的。你可以安装一个插件 **「IDE Features Trainer」**，安装之后将会有上面练习功能了。![](../Images/9ef85cf7da9b5f655adff7315134f7ff.png)

### 

### **2、阅读器模式**

现在，我们如果打开二方包类、文件或者说其他只读文件，IDEA 将会默认在阅读器模式下打开。这个模式，注释内容将会被格式化，更加容易被阅读。![](../Images/cfe640af095f3daa3efc973d8ef8b3ff.png)点击右上的 **「Reader Mode」**，可以还原成之前的模式，并且按钮将会变成下方的形状。![](../Images/068db1c7b5055c1eed53de92ac37ab7f.png)

### 

### **3、窗口拆分更加方便**

之前 IDEA 中，如果我们想拆分窗口，打开两个编辑窗口，只能在选择菜单栏中拆分选项。![](../Images/d6089d0b37ebf1b64f29aff18e6d8aa3.png)之前拆分完成之后，左右两个窗口打开是同一份文件，我们还需要手动在左边切换文件。现在 IDEA 提供了 **「Split and Move Right」** 的功能，不用再额外操作切换。现在拆分更加方便，直接使用鼠标拖拽就可以了。![](../Images/875e35b283af3db2a1a5cd0af63ae883.png)

拖放选项卡

另外我们还可以把终端窗口移到从最小方移动到上方编辑窗口。![](../Images/b1a6749ffa533f3ecec8a9e18e29ca42.png)

### 

### **4、优化重构功能**

这个版本简化了重构的  **「Extract method」**  功能，无需重新打开一个新的窗口声明方法名，方法变量等。![](../Images/36c78ce0ca1bb1c58937eccc92a3d39b.png)

新的 Extract method 布局

另外这个版本重构的 **「Rename」** 功能，还可以选择将代码注释中的字符串一块一起 **「Rename」**。![](../Images/d0598fdfcba84179c55afcb0dbd9ac0a.png)

更新的 Rename 重构

不得不说使用 IDEA 重构代码真的是丝滑般体验~

###   

### **5、DEBUG 功能升级**

这个版本我们 debug 的时候，右边将会显示当前变量，直接点击，将会快速弹出变量的查看窗口。这下就不用跳到下方的调试窗口，或者打开变量查看窗口查看变量了。![](../Images/31d0c87b9fbfb6d01a87db5b1da0ab47.png)这个窗口双击变量的值，我们就可以快速修改变量，丝般顺滑。![](../Images/6d614b39360010fbc879c82dc3e9f286.png)

调试器交互式提示

另外，IDEA 新增一种 **「Inline Watch」**，可以在特定上下文环境中，仅仅显示一个变量中某一个值。![](../Images/151dd28c7af82050c1ef318b47392b02.png)

调试器内联监视

最后我们还可以在调试器中进行基本的内存分析：第一个功能是 Show referring objects，用于查找从对象到 GC 根的最短路径。第二个功能是 Calculate retained size，用于计算对象的保留大小并显示其保留集。![](../Images/764fc564a52980104bca5b916058ede4.png)

在调试器中显示引用对象

### 

### **6、代码提示更加智能**

这个版本代码补全引入机器学习技术，基于成千上万的真实用户的代码补全用法，对方法进行智能排序，使我们可以更加快速选择相应的方法。![](../Images/2139fa9a3611336351fe3140f634af17.png)

机器学习代码补全

现在全球 IDEA 使用者这么多，每天大量样本可以被用作机器学习，猜想 IDEA 后续版本推出更加智能的功能。

### 

### **7、Search Everywhere 优化**

这个版本我们可以在 Search Everywhere 窗口中，直接使用 git 提交记录哈希和消息、标记以及分支进行快速的查找。![](../Images/a564314e2adc163113150248769722ea.png)

随处搜索提交哈希

另外 Search Everywhere 窗口还支持简单的数学计算。![](../Images/d62190b1fe9728065cc3fbdaa1281673.png)

### 

### **8、优化 Java 15 新特性体验**

Java 15 引入 `Record`新语法，可以创建一个**「纯数据载体」**类，而我们无需编写 Geter/Setter 等方法。这个版引入一个转化操作，可以快速将 `Record`转换成普通 Java 类，方便我们快速降级。![](../Images/b155fb355db7ea25949bf1a0e33fdf89.png)

将记录转换为类

另外对于 Java 15 另一个新语法 `sealed`，这个版本补全、代码洞察和重构等功能。![](../Images/ec07ff9f4e65c2e9e36f1271d93830f2.png)

支持密封类

### 

### **9、其他改动**

1.  IDEA 自带数据库工具，现在可以支持使用 SQL 查询 MongoDB。
    

![](../Images/ca4d645dc798babf97ea3f8ca1cd23db.png)

使用 SQL 查询 MongoDB

2.  Lombok 目前成为 IDEA 官方内置插件，以后版本升级，再也不用担心 Lombok 插件不适配，导致全部代码工程一片红了。
    
3.  VSC 菜单升级优化，将会根据当前使用版本控制系统命名 VCS 菜单，并且当前菜单栏更加简洁。
    
    ![](../Images/5a523488bfbf3dd2e4bed552ffdbaf93.png)
    
    更新的 VCS 菜单
    
      
    

## **小结**

上面介绍只是这次改动一部分功能，全部功能点请查看 IDEA 官网。另外补充一点，IDEA 官方现在已经支持中文了：![](../Images/d14491b4e163099b50feab79a868acc8.png)如果你使用梯子打开，显示还是英文，那么可以将页面拉到最下面，重新选择语言。![](../Images/b90ec896e2a55bc2c834b0aa11123423.png)由于 2020.3 只是一个小版本，所以这次并没有额外增特别的加新功能。这次新版本主要还是优化 IDEA 用户体验，让开发者使用起来越来越流畅。2020 年还有一个月就过去看，IDEA 2021 版本相信很快就来了，期待这次大版本的功能升级。**「最后感叹一句，IDEA 牛逼🚀！」**
