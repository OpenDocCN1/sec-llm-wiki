# 💩 以一种代码已经被混淆的方式命名变量

如果我们键入的东西越少，那么就有越多的时间去思考代码逻辑等问题。*Good 👍🏻*

```
let a = 42;
```

*Bad 👎🏻*

```
let age = 42;
```

# 💩 不要写注释

反正没人会读你的代码。*Good 👍🏻*

```

# 💩 使用母语写注释

```

*Bad 👎🏻*
