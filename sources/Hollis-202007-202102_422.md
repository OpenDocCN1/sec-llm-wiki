# Spring Boot 2.3.3 稳定版发布！修复了这18个Bug！！

8月13日，SpringBoot悄悄的升级了一个新的版本，2.3.3.RELEASE正式对外提供了。

![](../Images/b72b4d2b8ffbf3860a9ddd1296d94dc8.png)

￼在maven仓库中，已经支持对2.3.3.RELEASE的引用了。

![](../Images/fd445382552d15ed8936a854d14c5e16.png)

￼这一版本中，新特性只有一个，但是同时修复了18个Bug。

### **新特性**

我们知道，Spring很早之前就已经对HTTP/2支持了。可以使用server.http2.enabled配置属性，在Spring Boot应用程序中启用HTTP/2支持。

但是，在早期，原生的JDK8是不支持HTTP/2协议的，所以，要想使用这个特性，需要有web服务器和应用环境的支持。

但是从8u252开始，ALPN层已经从Java 11向后移植到了Java 8。意味着，只要使用Java 8u252或更新版本，不再要求使用Conscrypt和Jetty就可以使用HTTP/2了。

### **18个Bug修复**

除了推出了一个新特性以外，Spring Boot 2.3.3.RELEASE还修复了18个Bug，

![](../Images/6df0633b9d5735fc6ee65ecd9b137bc4.png)

￼作者做了简单的翻译如下：

*   修复外部化配置忽略了SPRING\_APPLICATION\_JSON中的空值的问题
    
*   修复带有“-”的遗留端点id不能完全地迁移的问题
    
*   修复了当Reactor的调试代理初始化失败时，失败的原因被丢弃的问题
    
*   修复了如果环境有任何空属性，则OCI映像生成失败的问题
    
*   修复了LiquibaseEndpoint不报告来自父级上下文的更改集的问题
    
*   修复了应该由其他DispatcherServlet处理的请求会产生404响应的问题
    
*   修复了在war部署中，错误页面不处理异步异常的问题
    
*   修复了XADataSourceAutoConfiguration很难与DB2XADataSource一起使用，因为它没有URL属性的问题
    
*   修复了在配置等待终止周期时，TaskExecutorBuilder只使用秒级精度的问题
    
*   修复了在@ConfigurationProperties上设置ignoreInvalidFields=true也会导致未知字段被忽略的问题
    
*   修复了如果使用SpyBean ，将为每个IT类创建新的上下文的问题
    
*   修复了后台预初始化可能会导致Jackson2ObjectMapperBuilder的Kotlin检测警告被悄悄地删除的问题
    
*   修复了UndertowWebServerFactoryCustomizer不支持选项，但只有UndertowOptions 的问题
    
*   修复了WebMvcTest和WebFluxTest不包括Jackson模块bean 的问题
    
*   修复了CouchbaseCacheManager不能再使用自定义的CacheManagerCustomizer问题
    
*   修复了Kubernetes就绪探针端点返回404 的问题
    
*   修复了CouchbaseCacheConfiguration命令不正确的问题
    
*   修复了带有nullValue编译器选项的MustacheEnvironmentCollector在2.3.1版本中不再工作的问题
