# 从上市公司创始人，到吃瓜群众的娱乐谈资，他到底怎么了？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650136373&idx=1&sn=2fbb96a6af576c4112c1cd053952c4da&chksm=f36bc214c41c4b02609ec7bac5e0a701a0cae033c7ed2120a00419be765e1297c713a7c3020c&scene=126&sessionid=1681657542#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650136373&idx=1&sn=2fbb96a6af576c4112c1cd053952c4da&chksm=f36bc214c41c4b02609ec7bac5e0a701a0cae033c7ed2120a00419be765e1297c713a7c3020c&scene=126&sessionid=1681657542#rd)

而这次距离上一次登上热搜的时间，也就是10天而已。7月7日的凌晨6点，李国庆带着40多名"彪形大汉"闯进了当当，撬开保险柜，强行拿走资料，随后更是紧急发文，称自己将要接管当当了，希望俞渝配合自己的工作进度 。6个小时后，李国庆被拘留了，在这争分夺秒的期间，李国庆慷慨激昂，在微博上挥笔写就了一篇《来自李国庆的一封信》，这则微博在短时间内迅速被广泛查阅，点赞，评论。而网友们则在李国庆获得“李大炮”、“摔杯侠"等称号之后，又给他新增了一个头衔“2020年高考满分作文获得者”。![](../Images/5bfb8a6a9c933c3707aae8b9e54c4707.png)

十几年前，李国庆常常挂在嘴边的是还这句话"要将百姓从饭桌拉到书桌，让阅读无处不在，让文化无处不在"  

现在却干起了摔杯子，抢公章，撬锁的事情，**从过去的当当创始人到如今吃瓜群众眼里的娱乐明星，人们想不通的是李国庆到底怎么了？**  
  
  
**大摩女事件**1999年，李国庆和俞渝这对夫妻档创立当当，在两人长达十年的艰苦卓绝后，当当一路之顺遂，并占据了中国图书市场的大半壁江山。在当当上市的4天前，李国庆还发微博称：11年我们比翼齐飞，她注定要这么冲刺，是来自于我的压力，还是她自己内在的动力，我不知道这辈子怎么补偿她了。可当当在2010年12月在纽约交易所上市后，李国庆非但没有想着怎么补偿俞渝，反倒**正式开始了自己的放飞之路**。2011年的1月15日，李国庆在微博上发表了一段“摇滚歌词”，脏话连连，暗示负责运作当当上市的美国投行摩根士丹利故意压低发行价，让当当白白损失了9亿美元。![](../Images/5cc514b18e12afea285e145efbf89c72.png)

被如此暗讽的摩根士丹利当然也坐不住了，旗下的两名员工开始跟李国庆开骂，在这场骂战中，当当的不少内幕被两名员工接连爆出，当当账面负盈利，作假账，就连上市也是为了圈钱。  

舆论风嚣直上，网友们开始怀疑，身为当当的CEO，李国庆的人品和能力真的过关吗？当当的管理能力真的在线吗？仅仅两天，当当的市值就蒸发了约3.92亿美元。这头的俞渝眼睁睁的看着当当的股价狂跌，却也只能在朋友圈里抱怨。![](../Images/6e20a752b5e7343f4ddf54d8e3169864.png)

￼在娇妻的劝诫下，李国庆并没有及时止损，而是选择继续挑起事端。

两方骂战正酣之际，屏幕上的方向已经开始向生殖器进攻了，来来回回50多个回合后，双方终于迫于压力，道歉了。![](../Images/56fb7cbbc7d7e5d9bc0ff46c5f1f104c.png)

￼1月24日，当当网召开了媒体见面会，在媒体问到李国庆与"大摩女"的那场战争时，俞渝只能苦笑的表示支持，称李国庆“话糙理不糙，是企业家敏感，敢于发文的风格”。

3月，“大摩女”热度已过，但李国庆显然不甘心，又单方面开始了与大摩女的骂战，不过，这回终究是他一个人的战场，没人搭理，没人回应，最终李国庆落了个自讨没趣。  
  
  
**渣男洗白机**“大摩女”事件彻底结束后，李国庆转身回到当当开始与京东的价格战，刘强东宣布京东每本书要比当当便宜20% ，更是表示京东商城图书音像部门在未来三年内不准赚一分钱的毛利，于**李国庆把矛头对准了刘强东，他公开表示刘强东是傻大黑粗**，今年8月钱就烧完了，还自称当当比京东更强，还用三年？京东赚一个花4个。接着李国庆立即反击宣布当当图书降到全网最低，并斥资4000万元对电子商品及百货类商品降价，可换来的却是当当股价连续六天下降30%，在一连六个季度里出现近亿元的亏损，当当不得不以惨败收场。而在这期间，李国庆还拒绝了百度，腾讯的投资，让当当彻底失去了进入资本市场的资格。到了2015年，刘强东说要想变成电商第一。李国庆在四川电子商务论坛上便调侃道：我老劝刘总，你真是当上了中国电商老二，那就得了，那还要当什么第一？他说要当第一，我说你回去宿迁，在那里注册个公司，大肆卖假货不就行了吗？结果现在人家果真成了电商巨头，而当当却在2016年从纽约交易所退市了，市值只剩下5.6亿美元，比最高峰的23亿美元还缩水了75%。![](../Images/e78a0fb745821dc457b4c504e0e00355.png)￼**2018年的李国庆俨然不满足于过去所获得的"成就"了。所以他又为自己新增了一个标签“渣男洗白机”。**11月21日，在俞敏洪侮辱女性言论公开后，他公开支持俞敏洪，并称俞敏洪是在为企业家树立榜样，一个月后，针对昔日对手刘强东的“明尼苏达事件”，李国庆不仅表示支持，更是向广大网友一览无余的分享了自己的婚外性经验。“一次和女性发生关系前，捧着手问，我们不是爱情，你接受吗？一次坠入爱河，在泳池相拥前问：我们还没结婚，你接受上床吗？”李国庆“婚外性，划得来”的切身体会，不仅引发网友们的强烈谴责，更是荒唐的让中国妇女报都不得不站出来开怼。![](../Images/0998f70044a3431b4d2eef84c9011457.png)

￼当当束手无策，只能再次站出来给李国庆收拾烂摊子。

本以为这次教训，李国庆能安分一些，老老实实做好自己的位置，可吴秀波事件后，李国庆又站出来了，他不遗余力的为当事人洗白，“社会不会因为一个艺人的出轨受到伤害”。翟天临论文事件后，他更是直呼，“假论文假学历的实例很多，企业家的论文难道是自己写的？"**在李国庆一次又一次的在微博上发表意见时，他忘了一件事，身为当当的创始人，他代表的不只是自己，还有当当。**2019年2月，当当终于厌烦了，发布公告称李国庆不再担任当当网的任何职务，由俞渝兼任公司CEO。![](../Images/82170861bdb8f224053532781e4d69a6.png)

李国庆明白自己的大势已去，便装作坦然的接受了，在当当发布声明后不久，他在微博上写下《离开当当创办书友会的公开信》，表示自己正式离开当当。

相比较马云，刘强东等一代枭雄的退出，李国庆的退出多少有些不情不愿，不过如果李国庆就此风平浪静，那么这种离开也算是体面。**但李国庆终究是李国庆，要他做到偃息旗鼓，大约是不可能了。**  
  
  
**夫妻反目**2019年10月，在一则访谈节目中，他在公众面前摔杯怒斥俞渝用“逼宫”方式夺权，下台后，他更是在朋友圈开始手撕俞渝。![](../Images/34b12474ac0d541d1dd4be20e9b460ab.png)

￼“我和俞渝分居21个月，净身出户，只带走了一个茶壶，目前暂时住在别人家”。

对于李国庆的一面说辞，俞渝也忍不住了，她放出了一段大曝料，把以前那个口无遮拦，怼天怼地的李国庆直接变成了一个天上人间绝无仅有的大渣男。

1.  同性恋，有很多男宠
2.  患有梅毒
3.  拿走了含有俞渝父母存款的1.3亿现金
4.  摔杯子，甚至对俞渝使用过家暴
5.  不仅没尽到父亲的责任，更是把当当交给俞渝一个人承担
6.  李国庆哥哥吸毒嫖娼，，还曾多次入狱，其父亲更是跟陪睡保姆互舔

这则爆料不仅把李国庆拉到舆论最高点，更有网友戏称李国庆简直就是《致命女人》的男主三合一啊！不久后，李国庆的北大老师孙立平在个人公号上批评李国庆道，从为刘强东事件开始，说话越来越有刺激性了，你从当当出走后，更是一发不可收拾，整天唠叨的就是这点破事。李国庆对昔日恩师的话会听吗？不会！李国庆转头又写起了他极为擅长的小作文，通篇对俞渝的爆料进行逐一反击，但事有漏洞，恰巧被网友找出俞渝的爆料有大部分是事实。网友吃瓜乐呵呵，比起当当，他们更喜欢看这一场闹剧，只要有李国庆在，这场闹就不会结束。同年11月，两人的离婚案在北京开庭，李国庆要求平分股权，俞渝没到现场，只好作罢，直到2020年3月，法院提议将两人离婚案在网上开庭，俞渝才明确的表示拒绝 ，也就是说，直到现在，两人在法律上的关系依然是夫妻。![](../Images/e456462a407854ea0369f6f068c6abc8.png)

￼面对俞渝对离婚的一拖再拖，李国庆急了，4月，他带了四个大汉进入当当网夺取公章，在拿到47 枚公章后，李国庆单方面宣布自己全面接管当当。在公章被盗后，当当立即宣布所有公章作废。李国庆心有不甘，三个月后，他决定“故地重游” 。

![](../Images/03e5ae588c3c3a76a435993d722c12a6.png)

￼这一次，他做的更加彻底，李国庆再次诉诸武力，带20多人，清晨强行进入当当，撬开多处保险柜，拿走资料…

  
  
  
**真傻白甜？**不过在频频闯入当当的背后，李国庆真的如自己所说是个傻白甜吗？纵横商城多年的李国庆深谙法律知识，多次擅闯当当，却没动手，在把事情控制在小范围内的前提下还得到了最大关注，他如此做的目的恐怕只有一个，离婚。值得注意的是，在抢夺公章后，李国庆列出了自己控诉俞渝的三条罪状，一、疫情期间俞渝因管理问题导致当当60多名员工被集中隔离，200多名员工居家隔离二、俞渝掌管当当期间，大量裁员，造成公司严重的人才流失三、公司在连续五年盈利的情况下俞渝拒绝给股东们分红你以为李国庆只是单纯在为股东和员工们考虑，其实他只是为了拉拢人心。《告员工书》显示，李国庆和俞渝持有股权的比例为91.71%，而李国庆获得的支持票为53.87%。，而一旦离婚成功，股权平分，决定谁掌权的还就是那几个小股东。![](../Images/24eb64028bdc0e07f531647e0c2f7da7.png "-w759")

￼换句话说，只要拢住人心，那当当迟早还不是回到李国庆手里。

有人问：一个创造了百万亿市值公司的大佬，你说他跟傻白甜沾得上边吗？这我不知道，但是我们知道的是，**十几年前，那个励志要将百姓从饭桌拉到书桌，让阅读无处不在，让文化无处不在的少年，现在终于自己走进了人们的饭桌、让自己的八卦无处不在了**。
