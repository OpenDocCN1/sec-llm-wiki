# 汇报下《Java工程师成神之路》的进展

在我的读者中，相信有很大一部分人是通过我的《Java工程师成神之路》认识我的。通过《成神之路》让我们结缘了。《成神之路》是从2015年开始整理的第一版，那时候只是为了方便自己查缺补漏整理了一下自己准备学习的知识体系。随着后来慢慢发展，随着我自己的技术能力的提升， 我也一直在不断的完善这份知识体系。后来基本保持着每年整体更新一次的频率。最开始《成神之路》只是一些知识点组成的目录，很多人通过这个目录，可以知道自己处于什么样的阶段，可以快速的找到自己有哪些知识点是不了解的。后来我创建了公众号，于是有了一个和读者交流的平台，经常有读者和我聊天，大多数读者希望我能针对这个目录完善其中的内容。于是，2019年，我做了一个大胆的决定，开始了《成神计划》，主要包含两部分内容：1、将成神之路开源，邀请更多的读者一起参与建设。2、开始逐步完善其中的知识点，让《成神之路》不再是一份目录， 而是一份完整的知识体系。截止目前，这份开源在GitHub上面的《成神之路》，已经收获了20.8k个Star，根据这份资料制作出来的GitHub Page 和 Gitee Page 共收货了近50万的访问次数，总访客数达20万。除此之外，还有很多成神之路的系列文章，在全网也收获了很多的阅读。仅仅是我自己的博客上， 2018版和2019版这两个版本加一起的总阅读数就达到了20万。2020年，我和阿里云开发者社区联合出了一本电子版的《成神之路》，一经问世就一直在霸榜。这本电子书还因此获得了阿里云颁发的<最受开发者欢迎的电子书奖>奖项！在不知不觉中，这份我历时6年打造的成神之路，影响了几十万的Java开发者。很多人可能不知道Hollis是谁，但是却知道这份《Java工程师成神之路》我有很多次，收到的很多简历中，都会有面试候选人的github，我访问之后，发现很多人都star/fork了《成神之路》。而且，这份资料，也曾经被很多人抄袭、洗稿过，甚至有一些人打着原创的名义发表。甚至还有我认识的人，在这里我警告一下某些作者：我不是不知道、我也不是没办法追究，我只是懒得理你，别太过分了！出来混，还是给自己留一份脸面的要好。。。anyway，这些都不重要，重要的是这份资料真的帮到了很多读者。一直以来，很多读者问我成神之路打不打算出书。而且确实也经常有出版社联系我，想要和我合作出版这本书。现在，很高兴的告诉大家，关于《Java工程师成神之路》的成书计划已经在流程中了，因为这个系列内容实在是太多，所以可能最后会变成一个系列丛书。目前正在和博文视点一起打磨本系列丛书的第一本，即成神之路的基础篇。因为考虑到书籍的受众群体以及学习方式和开源文章不同，所以书籍的整体大纲会和开源的版本稍有差别，内容上会比目前开源的版本更加丰富一些。大家敬请期待！因为我最近工作很忙，所以只能抽周末的时间来修改、编辑书籍的内容，进度上可能会有些慢。不过不出意外的话，今年的晚些时候就会和大家见面。还有很多人问我，《成神之路》的github pages上面的有些目录没有链接是什么原因？那是因为有些内容我还在整理中，因为内容实在太多，大家请见谅。还有人问我，最近为什么《成神之路》的gitee pages打不开了，那是因为 Gitee Pages官方在做改造，服务暂停了，大家可以先在Github Pages上面学习。最后，还有一个小问题。那就是每个程序员都最最苦恼的问题————命名！我现在是想把《Java工程师成神之路》作为丛书名，所以，这个丛书下面的每本书的名字我就不知道应该叫什么了。或者还是直接叫《Java工程师成神之路——基础篇》？不知道大家有没有什么想法，欢迎留言。一经采用必有重谢！最后，感谢大家对Hollis的支持，感谢大家对《Java工程师成神之路》的认可！一起加油！！！**![](../Images/401c62bef39b755ead6240e3446038ca.png)技术交流群![](../Images/401c62bef39b755ead6240e3446038ca.png)**
