**场景描述**  

最近使用 Redis 遇到了一个类似分布式锁的场景，跟 Redis 实现分布式锁类比一下，就是释放锁失败，也就是缓存删不掉。又踩了一个 Redis 的坑……这是什么个情况、又是怎样排查的呢？本文主要对此做个复盘。

## **小结**

本文遇到的这个问题，主要是因为使用了不同的 RedisTemplate 来加锁和释放锁，而这两个 template 使用了不同的序列化方式，最终还是序列化带来的问题。当初真是草率了，而且一时还没测出来……对于生产环境，还是要慎之又慎：如临深渊，如履薄冰。
