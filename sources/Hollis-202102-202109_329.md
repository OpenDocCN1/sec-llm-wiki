# 不推荐别的了，IDEA 自带的数据库工具就很牛逼！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650159122&idx=2&sn=6811c1a2c6a5e5895fa9f4966ed35329&chksm=f3682533c41fac25f5879e950030d9f4bbabcdf2fc17be06557771b5ba9984bc26bac8d55666&scene=126&sessionid=1681657426#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650159122&idx=2&sn=6811c1a2c6a5e5895fa9f4966ed35329&chksm=f3682533c41fac25f5879e950030d9f4bbabcdf2fc17be06557771b5ba9984bc26bac8d55666&scene=126&sessionid=1681657426#rd)

MySQL 等数据库客户端软件市面上非常多了，别的就不介绍了， 其实 IntelliJ IDEA 自带的数据库工具就很牛逼，不信你继续往下看。本文以 IntelliJ IDEA/ Mac 版本作为演示，其他版本的应该也差距不大！

## 

## **1、打开数据库工具面板**

如果 IDEA 主页没有看到 Database 面板，可以在 View 菜单中依次调出 Database 菜单打开数据库工具面板。![](../Images/5c787e2a03d9e27fd63fe037527a6459.png)

## 

## **2、创建数据源**

打开 Database 数据库面板后，点击 ＋ 号根据提示选择对应的数据库创建一个数据源。从下面的列表可以看出，IDEA 数据库工具支持的数据库非常多，常用的主流的数据库都在里面。这里以 MySQL 数据库为示例创建一个数据源：![](../Images/998ccee9be71fd369b36d4728b28e172.png)选择 MySQL 后，会让你输入 MySQL 的连接信息。这里我以本地 MySQL 数据库作为演示，依次输入 MySQL 的  Host、端口、用户名、密码等必要连接信息，除此之外，你也可以切换到其他选项卡中输入更多高级连接信息。![](../Images/6e17c9438826dcb84f0a4b8e63ec8b48.png)可以点击 **Test Connection** 按钮可以进行连接测试，如果对应的 MySQL 驱动没有下载，根据 IDEA 弹出的下载提示会自动下载，如上所示，连接测试通过。点击上面的 MySQL 驱动名称链接可以跳到对应的数据库驱动设置中：![](../Images/034ed951df0691e34f3255209eaa5380.png)如上所示，可以选择更改驱动名称、驱动包，以及 JDBC 连接模板，这里全部默认不作更改。保存退出后，可以在 Database 面板看到本地 MySQL 数据库已连接。![](../Images/42bec8db74ff28e70c9179b5be1be38c.png)可以看到有 1 个数据库、272 个校对集、4 个用户。

## 

## **3、创建数据库和表**

先来创建一个数据库：![](../Images/4e001ff92aacb19e43d15f1e6fb9fd07.png)输入数据库名称、校对集：![](../Images/f99340d4da117a9941ed4680dad4a998.png)保存信息，数据库创建成功：![](../Images/62addb76effcf71a0f5292f38cc7a65a.png)在对应的数据库上右键，然后再新建一张表：![](../Images/72c5aee57bf2dfa11fb1071bd93b70eb.png)输入表名、注释，然后再增加几个字段：![](../Images/b0921a31c9202f1c6018272a99a80aaa.png)可以看到，字段各种常用的设置操作都有，非常方便。再点击 Execute 按钮在数据库中执行以创建一张表：![](../Images/bb6e8d3e3ab587d052698eeee67a1b99.png)可以看到，表中常用的信息全列出来了，十分直观！

## 

## **4、数据增删改查**

双击表名，可以进入表数据的增删改查等更多操作。右键，点击 **Add New Row** 菜单依次添加几行新数据。右键任何数据都可以快捷复制行、删除行、编辑等操作，当然，双击任何数据也可以直接编辑，然后提交事务保存。![](../Images/b42522058da1efd5c597d5a1fb1fe8b4.png)在查找框中直接输入 where 条件可以快速筛选数据：![](../Images/3798903861ea1ccd349506a69ae0da63.png)使用 Filter By 菜单还有更多的快捷操作：![](../Images/298f8aacabb17da2e5fac4333fa259ce.png)如上所示，列出了常用的基本筛选快捷操作，这些快捷操作还能使用剪贴板里面的信息，其中，“开发” 这个条件就是从剪贴板带过来的。也可以右键创建一个查询控制台：![](../Images/b9a0c7b8eac22b61f9d0373d84b62b55.png)在查询控制台中输入 MySQL 关键字都会得到快捷智能提示：![](../Images/8a967fe8a6c110bdc6c44bca6369be40.png)提示还包括数据库中的表名：![](../Images/4a74c7f906e167fdc64ecf3b9d264f0b.png)智能提示真的很好用，明显提升开发效率和开发幸福感，果断是英文不好的同学的神器。IntelliJ IDEA 果然是 Java 最智能的 IDE，这个名不虚传～![](../Images/a350070c12a00d72cfcc19114ae57ca5.png)在这里也可以很方便地对数据进行增删改查操作。还能进行全文搜索，右键表名开始：![](../Images/2051541c8f99c89087d04bcbe7f55764.png)比如我要搜索 "JDK"，条件中自动就把所有文本类型的字段自动带上了 like 条件：![](../Images/2205ce228beedaa17e8837f7edaee429.png)点击 Search 按钮：![](../Images/4aca5dc207ad2a29397223c17be82f74.png)找到 article 表中的一条记录，双击进入结果集：![](../Images/ce017172c1f26436d62f2d5cefaf987d.png)IDEA 数据库搜索真牛逼！

## 

## **5、SQL 生成**

在已有的表上面还能进行 SQL 生成操作，如生成表创建 SQL 语句：![](../Images/0b649f0c2b76ce913ce989f3da614bd4.png)![](../Images/52c798f25c7dc1c3b409137a44157a61.png)除了生成表创建语句，还能将数据库表中的所有记录导出，可以是 SQL、JSON、CSV、XML……有很多种导出格式，可以说十分强大！![](../Images/9a2d234d986abc017a8677e0cd3e7716.png)

## 

## **6、导出表模型**

右击对应的数据库表名称，可以导出数据库表模型：![](../Images/c46f3c3b5ab17c04c08eae6ce34fb47f.png)如下所示：这个模型信息虽然看起来很简陋，不能和 PowerDesigner 那么强大作比较，但也能把数据库所有信息很直观的列出来。![](../Images/e40c01231ce732077aab13acdfac7901.png)

##
