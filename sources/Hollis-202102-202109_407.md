# 清明出游，在高速上堵了16个小时。

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650157193&idx=1&sn=7878421419a7014436113cd9acde7787&chksm=f3682da8c41fa4bed5328c7eafdffede6ad0ee64d8f273bf965a931abe83e27790eca064f902&scene=126&sessionid=1681657438#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650157193&idx=1&sn=7878421419a7014436113cd9acde7787&chksm=f3682da8c41fa4bed5328c7eafdffede6ad0ee64d8f273bf965a931abe83e27790eca064f902&scene=126&sessionid=1681657438#rd)

清明节3天假期结束了，你们都干什么了？我出去转了一下。

  

但是这个清明节，我太累了。因为清明节3天假期，我有两天都在高速上。。**堵着。。。。**

  

清明节，听说江西婺源的油菜花不错，就带着家人想着从杭州开车过去转转，放松一下（结果是我想太多了）。  

  

但是，我低估了人们对节假日的热情。这个假期，我给"杭瑞高速"、"长深高速"、"溧宁高速"、"杭长高速"等各大高速做了一次"**压测**"。  

  

**压测结果是，我一共在路上被堵了16个小时。**

  

本来从杭州到婺源，车程的话也就4小时左右，但是，我们来回一共开了16个小时。**相当于，节假日的第一天，和第三天，我们都在高速上度过的。**  

  

在高速上，领略了各种**人文风光**，比如"快车道只开60码"、"应急车道呼啸而过"、"加塞不成破口大骂"、"错过出口勇敢倒车"、"服务区全被封禁"、"不知道近光灯是何物"。。。

  

我们在婺源待了"3天"，但是实际上真正的**有效时间**大概是1天半。

  

我们去了几个地方，李坑、汪口、月亮湾、篁岭、江湾等等几个地方。

  

其中我觉得月亮湾和江湾完全没啥必要去。。。就有点一般。

  

李坑和汪口是两个古村，话听讲解员讲讲当地的历史还挺有意思的。

  

江岭我们没去，本来计划要去的，但是因为当地人说**油菜花都已经没有了**，所以就没去。只有在篁岭看到了一点点油菜花。

  

晒几张图吧。。。虽然路上很辛苦，但是也还拍了几张（自认为）满意的照片。。。

这个石雕很有意思，是李坑的一个古宅门口的雕刻。大家能看懂他的寓意吗？其实是"万般皆下品、唯有读书高"、"书中自有颜如玉、书中自有黄金屋"

![](../Images/84e3d7d142edf0c351baf5d6ce847c89.png)

  

后来，我们还去一个朋友家坐了一会，朋友家就在汪口景区里面。他家是临河而建的一个四层小楼。有一个硕大的露台正对着河面，河对面就是山。真的是很美。

  

![](../Images/718d78f9ebe2d0a1c3721b298e64565d.png)

  

当我们穿过他家的屋子，走到露台的时候，几个同行的人。不约而同的发出了"哇哦。。。"的惊叹。真的是太羡慕了。

  

问了一下， 那个地方，地基+盖房子+装修，要好几百万。。。

  

唉，不说了，**继续挣钱。**  

  

最后，我再也不在节假日的时候开车出门了！再开车出门我就是狗！！！
