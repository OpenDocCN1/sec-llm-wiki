# 92年清华本科，做了30年技术，43岁在CTO的位置上被优化！找了一年多工作，有些迷茫！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650179126&idx=3&sn=59701f4f6c6bb90991b51abcd607e768&chksm=f3689b17c41f120158c93fa7a746170ad9a5412f367f7de7bce9a530395e79fa641bb55c8721&scene=126&sessionid=1681657293#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650179126&idx=3&sn=59701f4f6c6bb90991b51abcd607e768&chksm=f3689b17c41f120158c93fa7a746170ad9a5412f367f7de7bce9a530395e79fa641bb55c8721&scene=126&sessionid=1681657293#rd)

清华毕业以后从事什么工作，才不算辱没学历？

这是一个92届清华本科毕业程序员的故事：做了30年技术，43岁时在CTO的位置上被优化，找了一年多工作，45岁才到现在二线城市的小央企，还要等13年才退休。如今很迷茫，不知道自己还要不要继续负重前行，有一个小五届的清华师弟，现在已经去干外卖了……

![](../Images/5a460799359d73adeeea12853ddbc1cc.png)

楼主推心置腹，网友却不信，清华毕业生送外卖，谁信？

![](../Images/fca433f526e3b7fee457439ce581b38b.png)

有人说，92届的清华本科是人中龙凤，早就应该混得风生水起，财务自由了，还需要上班？

![](../Images/be67c4b24670e1f84ac08e2c80a35244.png)![](../Images/e33fd7c3449a3cf2ffff0aeb91197aaf.png)

有人说，送外卖是夸张说法吧？没准楼主已经财富自由，送外卖只是体验生活。

![](../Images/a9303e19b01d82ccbc44bf5084de8239.png)

也有人说，未必是假的。之前看新闻有个北大计算机专业的人，工资才八千。不可能每个人都能踩在风口上，时运不济的大有人在。

![](../Images/2b6cf6ce49bdab059046346b82040131.png)

有人说，自己认识一个83年清华计算机专业的叔叔，失业领低保十几年了，不是每个人都能赶上机遇。

![](../Images/9be1dec84d6b08a1ba3ba038299f7b9b.png)

有人说，自己认识一个清华毕业生去了美国摩托罗拉，后来被裁，去洗车店打工了。现在互联网码农工资高，只是赶上了时代红利，也有很多没赶上的，等反应过来年纪已经大了。

![](../Images/907a07b3fc2bc131fd846193cdd5ddba.png)![](../Images/6a50fe6f518c28d56d7bdb81d4fafa4b.png)

也有人说，没准那个师弟“送外卖”是“干外卖”，担任的是美团高管。

![](../Images/43241a4d01ffe80ad9bb9889ca8337d1.png)

再说了，就算送外卖，也是一种职业。

![](../Images/a8f3462b00172587adc7f1ba0a279bd7.png)

有人劝楼主，能进国企就是万幸了，疫情期间国际局势突变，先干好目前的事最重要。

![](../Images/055c785582fa83544ce0c8c74e18fdae.png)![](../Images/1baba97ca5b70b086c08d29bb73d2e85.png)

也有人建议楼主跳出所谓的铁饭碗圈子，发挥自己天赋，做自己喜欢的事情，必定会有惊喜收获 。

![](../Images/72621532b6bc127ece765f81751570bf.png)![](../Images/3c5c9e690db264d970ec7f4afb5af4f6.png)

有人让楼主做技术培训。

![](../Images/4881c026923ef9feb25bb421b94472df.png)

有人让他做职业经理人。

![](../Images/0eb4db47b465538f3449f971d8b6bf8b.png)

有人劝楼主尝试创业。

![](../Images/679e960537090f7fcaf12f89b4c51003.png)

还有人说，楼主现在的问题不是寻找事业的突破，而是寻找内心的安处。

![](../Images/542f8ca80811e2b66ee759ce634528c4.png)

从楼主的字里行间可以感受到他的焦虑和迷茫，在这个飞速发展的时代，即使是top1学校毕业的程序员，也可能在年近半百时被时代毫不留情地抛弃。

其实仔细分析，楼主也并非深陷泥淖，虽然他不能身居高位，但能在央企做到退休，已经比许多找不到工作的人强一百倍了。网友说得对，与其着急寻求事业的突破，不如先找到内心的安宁。此心安处是吾乡，只有内心得到了真正的平静和坦然，才能想清楚自己要什么，进而决定自己未来的走向。

如果一时不如意，千万别钻死胡同，天地很大，未来有很多可能性，说不定在某个时间点，遇到某个偶然的机会，你会突然间柳暗花明，走出僵局。
