01特别推荐

1.1  口吐芬芳助手
连接计算机内核和交互界面的桥梁叫做终端，在下面这样黑乎乎的窗口敲代码才有高级的感觉，很多操作系统都有终端，比如 Linux 的 terminal，mac 的终端。
不像输入法，在终端输入命令时提示很少，虽然有 tab 键敲错命令是时有发生的事儿。
敲错命令，删掉重敲，当你一再敲错的时候，内心相当崩溃的，心中一定会默念：What The F*ck，但是口吐再多芬芳都无法自动修改你敲错的命令。
昨天逛 GitHub 的时候，发现了一个神器：thefuck，这个神器就像专门为你们定制的，当你敲错命令时，只要大喊一声 fuck ，并输入 fuck 命令，你刚刚键入的错误命令就会自动修正。
开源地址：https://github.com/nvbn/thefuck
更强大是 thefuck 不仅能修复字符输入顺序的错误，在很多你想小嘴抹蜜的情况下，thefuck 依然有效，反正只要你因为命令的问题报错 fuck  就完事了。

1.2  开源 Airtable 替代品

开源 Airtable 替代品 ，将任何MySQL，PostgreSQL，SQL Server，SQLite＆MariaDB 转换为智能电子表格。

开源的地址：https://github.com/nocodb/nocodb

 

02本周热榜

2.1  Python 代码格式化程序

这个叫做 Black 的开源项目是一个「毫不妥协」的 Python 代码格式化程序。通过使用它，你可以放弃用手工的方式对 Python 代码格式化。Black 速度快、稳定，帮助你会为更重要的事情节省时间和精力。

开源地址：https://github.com/psf/black
2.2  编程语言实现所有算法
号称 GitHub 上最大的开源算法库。这个开源项目标是使用代码来记录、开发美观的、有用的和有趣的算法。编程语言涉及：Java、Python、Js 等。
开源地址：https://github.com/TheAlgorithms
2.3  强大的团队聊天应用
Zulip 是一种开源团队协作工具，结合了电子邮件和聊天的优点，使远程工作富有成效和愉快。成千上万的其他组织每天都在使用 Zulip。Zulip 是唯一一款专为实时和异步对话而设计的现代团队聊天应用程序。
Zulip 由来自世界各地的开发人员组成的分布式社区构建，有 74 多人，每人贡献了 100 多个提交。每月有超过 1000 名贡献者合并超过 500 次提交，Zulip 是最大和增长最快的开源团队聊天项目。
开源地址：https://github.com/zulip/zulip
2.4  Android 智能下拉刷新框架
一个安卓智能下列刷新框架：SmartRefreshLayout。打造一个强大，稳定，成熟的下拉刷新框架为目标，并集成各种的炫酷、多样、实用、美观的 Header 和 Footer。 
正如名字所说，这是一个「聪明」或者「智能」的下拉刷新布局，由于它的「智能」，它不只是支持所有的 View，还支持多层嵌套的视图结构。 
开源地址：https://github.com/scwang90/SmartRefreshLayout

   
2.5  一套电商系统
mall 项目是一套电商系统，包括前台商城系统及后台管理系统，基于 Spring Boot + MyBatis 实现，采用 Docke r容器化部署。
开源地址: https://github.com/macrozheng/mall
