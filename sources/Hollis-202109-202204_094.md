# 请立即卸载这款 IDEA 插件！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650176590&idx=3&sn=5179ad40cd6dc4606d170e5b39d2d7c6&chksm=f368616fc41fe87957f9ee3d9a35a339c8cd3b5495adaad969a9fda8afe33ef9e498309ed181&scene=126&sessionid=1681657305#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650176590&idx=3&sn=5179ad40cd6dc4606d170e5b39d2d7c6&chksm=f368616fc41fe87957f9ee3d9a35a339c8cd3b5495adaad969a9fda8afe33ef9e498309ed181&scene=126&sessionid=1681657305#rd)

IntelliJ IDEA ：优秀的 Java 开发 IDE 之一，这款优秀的工具是收费的。但不少人喜欢白嫖，看到收费提示，第一个想法可能就是 百度 -> 破解。  

![](../Images/46fb501f9f8a54ebeed3c7c66789b0dd.png)

当你在百度搜索 IDEA 破解版的时候，大多数网站会推荐给你一个插件叫做：BetterIntelliJ。

![](../Images/f12ba2434f9853da024a23b9426b0bd3.png)

这个插件号称可以将 IDEA 破解，一键激活到 2099 年。  

![](../Images/5fc8d9d7eb8f77e800808ac7ef08bd8b.png)

但是，最近这款插件爆出漏洞，该插件被恶意篡改，多个杀软已经开始报毒，插件官方目前已经下架并推荐正版。

且 Jetbrains 官方也已重视此事，为规避传播激活码升级为“传播病毒”，事态升级，请大家停止分享该插件，去官方渠道购买。

BetterIntellij.com 也发表了声明：

![](../Images/48a93e37db0c7750f978bbf26ec43629.png)

![](../Images/8eabcecaad5aaf9d225ec4edc6ee0580.png)

##   如何卸载BetterIntellij？

1\. 在菜单栏打开 File -> Setting

![](../Images/ce40e7e7747341b7f75c77f191252aeb.png)

  

2\. 打开 Plugins，在已安装列表中找到 BetterIntellij，点击鼠标右键，会弹出选择菜单，点击 Uninstall，便可卸载。

![](../Images/f9c53ca02b525ff07d390d5076a35422.png)

3\. 卸载完成后，点击重启 IDEA 即可。
