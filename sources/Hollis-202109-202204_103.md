# 把元素周期表也禁了？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650176363&idx=1&sn=f8ef8feef83d1b51327e1f529f32dbc2&chksm=f368664ac41fef5c4837d0a1e7f30b8646b8122cf761cf12614595e56cd7291d91a68c658cae&scene=126&sessionid=1681657309#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650176363&idx=1&sn=f8ef8feef83d1b51327e1f529f32dbc2&chksm=f368664ac41fef5c4837d0a1e7f30b8646b8122cf761cf12614595e56cd7291d91a68c658cae&scene=126&sessionid=1681657309#rd)

受俄乌局势影响，以美国为首的西方社会对俄发起新一轮的制裁，Oracle、SAP、Apple、Google 等美国主要的科技企业都宣布中止在俄业务，英特尔、AMD、戴尔、联想等硬件企业相继被外媒曝出已中断向俄供货。台积电也表示将遵守美国出口管制。

除了经济制裁和科技领域的产品服务“断供”外，西方文化、体育、音乐、学术、游戏等领域也加入了对俄制裁的大军，甚至连产自俄罗斯的宠物猫都在制裁对象之列。

![](../Images/7e61e2e6e00110ae2a45154e73cf659b.png)

此外，很多信息表明此次事件的影响已经延伸到了开源软件领域。

首先是部分开源相关的商业公司响应西方社会号召，开始切断或疏远与俄关系。

据俄罗斯本地媒体消息称，俄罗斯程序员或因为制裁而无法正常使用 GitHub。3 月 2 日 GitHub 的官方回应似乎印证了这一说法：“会确保全球开发者的正常访问，**同时也会遵守政府提出的出口管制和贸易法规。其中包括严格限制俄罗斯获得其维持侵略性军事能力所需的技术。**”

俄罗斯市场占比最高的移动操作系统 Sailfish OS 制造商 Jolla 公司宣布将[切断与俄联系](http://mp.weixin.qq.com/s?__biz=MjM5NzM0MjcyMQ==&mid=2650140626&idx=1&sn=d6147aac8954e69e78f038a743c43c99&chksm=beda34bc89adbdaa19d11b542b63c7d054ce7d01fa52bcf2acbe13e967156355577fe7e69785&scene=21#wechat_redirect)，寻求欧洲资本进行资产重组。基于开源 Sailfish OS 研发的 Aurora OS（中文名：极光）是俄罗斯官方军政部门指定移动操作系统，在俄各界广泛推广。

受到这次事件的影响，各大国际开源社区也对此作出了不同程度的反应，掀起了一股声援乌克兰的风潮。

Node.js 官网在各个语言版本的首页加入了声援乌克兰的标语，并加入了国际红十字会对乌克兰公开募捐的链接：

![](../Images/9e8a249e84f3751d6367b5942a0d47f3.png)

知名前端框架 React 也在官方网站中加入了声援乌克兰的横幅：

![](../Images/35a0fd2b77cdc2c7a9e4b7b58f3df2c4.png)

目前，“制裁俄罗斯、声援乌克兰”已经成为西方社会新一轮的“政治正确”运动，并且有愈演愈烈的趋势。越来越多的国际主流开源社区都收到了类似的“请求”，很多社区管理者不得不在舆论的压力下做出表态。

有业内人士分析，全球化的软件公司和云服务，给战争带来了新的“武器”，战力和舆论（包括指挥动员）也会呈现出互联网的放大效应，乌克兰的数字化转型部也在利用这些工具与效应。种种迹象也表明，这种效应也已经开始染指开源软件领域。

我们一直在说“开源无国界”，跨国界平等的创新与协作是开源世界最基础的行为准则，就算当前版本“被禁”（改变协议或不再分发），也不影响已经分发的开源版本。

但是当 Oracle、SAP、Apple、Google、GitHub 等国际科技巨头对俄的制裁举措让“科技无国界”的说法成为历史，当各大国际开源社区纷纷在政治立场上出来站队时，“开源无国界”的说法又将能剩下多少分量呢？
