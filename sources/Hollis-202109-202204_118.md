# 我最爱用的一款 Redis 可视化管理工具！好用到爆！！！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650176123&idx=2&sn=5c303a7b9cd920af8aae042fc79e46f1&chksm=f368675ac41fee4c45911297d8e1290cabb4c04f2758f567a5bd39d718360e227d6d61c5c750&scene=126&sessionid=1681657309#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650176123&idx=2&sn=5c303a7b9cd920af8aae042fc79e46f1&chksm=f368675ac41fee4c45911297d8e1290cabb4c04f2758f567a5bd39d718360e227d6d61c5c750&scene=126&sessionid=1681657309#rd)

今天来推荐一款我平常一直在使用的  Redis 可视化管理工具，真的非常不错，好用！我会通过和另外一款类似的工具 QuickRedis 作对比的方式来介绍。

QuickRedis 是一位好朋友给我推荐的一款开源免费的 Redis 可视化管理工具。在此之前，我和大部分小伙伴一样，平时使用的都是 Another Redis Desktop Manager 。

两者有很多共同点，比如都是开源的，都兼容 Windows、Mac、Linux(都是基于 Electron 实现的跨平台，因此占用内存都不小)，都支持直连、哨兵、集群模式。

在对两者进行了详细地对比之后，我发现 Another Redis Desktop Manager 是真的香！！！

在写完这篇文章，和朋友聊天后才发现他之前以为 Another Redis Desktop Manager 只是 Redis Desktop Manager 的简单升级。

![](../Images/dda9d37535090a3ebf4ecafb8d263e4b.png)

另外，Another Redis Desktop Manager 的作者也是真大佬！在知乎“有什么好用的 Redis 可视化管理工具？”提问下面，大佬直言目前市面上的 Redis 可视化管理工具都不怎么好用，于是，自己写了一个。或许这就是大佬吧！

## 

  

**二者对比**

下面我们来从资源消耗、界面、功能以及使用体验这四个方面简单对比一下二者。

### 资源消耗

可以看到，QuickRedis 占用的磁盘大小几乎是 Another Redis Desktop Manager 的 2 倍。

![](../Images/552acdb23ccf0136fcb17bd3e1fcc36b.png)

占用磁盘大小对比

使用两者直连 Redis 之后不作任何操作，QuickRedis 的内存消耗要比 Another Redis Desktop Manager 更大。

![](../Images/e464ed3e09571571e825c822bdc3a59d.png)

内存对比

### 界面

论两者界面的美观程度和流畅性来说， Another Redis Desktop Manager 是完胜 QuickRedis。并且，前者还支持深色模式，还可以自定义字体格式。

### 功能

两者提供的功能大同小异，不过，Another Redis Desktop Manager 要更完善一些。

两者都支持：

*   搜索功能
    
*   直连、哨兵、集群模式
    
*   键值对管理
    
*   命令行
    
*   ......
    

Another Redis Desktop Manager 还支持：

*   暗黑模式
    
*   SSH 私钥、SSL/TLS
    
*   命令执行日志
    
*   RedisJSON （Redis 对 JSON 数据类型的支持，允许从 Redis 中存储、更新和获取 JSON 值）
    
*   Redis>=6.0 的 ACL（Access Control List，用户权限管理）
    
*   ......
    

![](../Images/f2a5589e6458c19ec1a7afa161d1553a.png)

Another Redis Desktop Manager 对  RedisJSON 支持

Another Redis Desktop Manager 更新真的挺频繁的， Redis 的很多新特性也是很快就能 Cover。

![](../Images/294365e7d2c79e9d5f76664acb0a698a.png)

Another Redis Desktop Manager 更新历史

  

### 使用体验

虽然两者能够实现同样的功能，但是， Another Redis Desktop Manager 的使用体验明显要好很多。

就比如虽然两者都提供了命令行功能，但是 Another Redis Desktop Manager 在输入命令的时候会有提示，并且会显示出你在当前连接下最近执行的命令。

![](../Images/f5bbadfa31821dae692653819a67a818.png)

而且，Another Redis Desktop Manager 还提供了命令执行日志。命令行执行日志会显示出当前连接下 Redis 执行过的命令，超级棒！！！非常适合大家用来学习 Redis 命令。

![](../Images/7128218b630fa22f5c0ffef1a0e7f4ae.png)
