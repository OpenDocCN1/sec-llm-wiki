# 马化腾定义腾讯是"普通公司"，这波重新定义“普通”可还行......

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650174233&idx=1&sn=cb72945104156a6587bacfcc41cde03b&chksm=f3686e38c41fe72ea99dd1b22dd890f44ec6ab3047ac51b9999374fb83c3dfca5e4a970297b2&scene=126&sessionid=1681657325#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650174233&idx=1&sn=cb72945104156a6587bacfcc41cde03b&chksm=f3686e38c41fe72ea99dd1b22dd890f44ec6ab3047ac51b9999374fb83c3dfca5e4a970297b2&scene=126&sessionid=1681657325#rd)

![](../Images/83d5b0e4f3c5cc1c86c3dfa860f5646d.png)

  

大伙儿看了pony马的最新凡尔赛发言么？  

 

据媒体报道，在去年底的员工大会上，小马哥对2021年发生的一系列变化表达了自己的想法。

 

他说：

 

*腾讯只是国家社会大发展期间的一家普通公司；*

*是国家发展浪潮下的受益者；*

*并不是什么基础服务；*

*且随时都可以被替换。 *         

 

好家伙，这几句话下来直接就给鹅厂定义成“**普通**”公司了......

![](../Images/0083dd7d3fc8ad4fb1c3c454e62f77a0.png)

  

讲真，小马哥这种居安思危的想法是好的，可普通公司咱还是算了吧。**如果鹅厂都是普通公司了，那在座的各位岂不是在“****个人工作室****”上班？**

 

![](../Images/665d4b01a343904015dce507ed614a9b.png)

  

用天眼查app的话来说就是“**重新定义‘普通公司’**”？这么多控股网络可都实实在在摆在这儿——   

 

![](../Images/8c47d9340ac616805ccc59949eccb8c3.png)

  

![](../Images/61b4bb3f99667bf07f054f19a3c218e0.png)

  

这也不禁让码君想起了那些张口就是“**普通**”、“**还行**”、“**后悔**”的大佬们——

 

普通公司马化腾，北大还行撒贝宁。

不知妻美刘强东，才貌双全高晓松。

名下无房潘石屹，一无所有王健林。

只交朋友罗永浩，用情专一章子怡。

火星视角张一鸣，不会带货李佳琦。

人生失败周鸿祎，独自打拼王思聪。

反清复明吴三桂，下周回国贾跃亭。

 

![](../Images/660ec97fca46df3a1568ed8228f56a1f.png)

  

好巧不巧，有细心的网友发现“普通”公司鹅厂在小马哥的发言过后，**股价大涨超过4%**——

 

![](../Images/786ecdbacc2472d16821cbd5fb9f3f99.png)

  

**码君还在对着“普通”笑呢，聪明的股民已经抓紧建仓了**，只能说码君这波在第一层了。

 

而笑过之后大家也是纷纷对着小马哥的发言做起了阅读理解。

 

大胆的虎扑网友直呼小马哥“**没飘**”——

 

![](../Images/2a9a02cde62145b247b232c7be63d2d5.png)

  

而胆子更肥的网友，则直呼“**小马懂事**”——

 

![](../Images/0061ebd587308ff895e7a6f094172d1a.png)

  

连微博的“夹总”都认为小马哥这一波叫做**《格局》**——

![](../Images/d65d6b5422bba3b2e5dae61e6e760299.png)

  

![](../Images/b3905916fd3a15556867192adbd16fbb.png)

  

好了，格局归格局，咱们还是要讲一下事实的。

 

说来码君也挺好奇的，**难道小马哥真就认为鹅厂是个普通的公司么？**

 

鹅厂真的不是什么基础服务？随时都可以被替换？这种说法似乎有些牵强了......

 

码君翻了翻媒体报道，根据中国经济周刊所说，有不少互联网分析人士认为，**因为用户覆盖面广大，而且使用场景多、使用频次高，微信其实已经像水、电、电话信号一样，具备很强的“公共基础设施属性”。**

 

![](../Images/10195be403a13c6177e6d6576dc29223.png)

  

而且并不是所有的互联网应用都能在微信获得流量，像接受了腾讯投资的京东、拼多多、快手等app，可以将商品或视频的链接直接分享到微信。但淘宝、抖音曾经却无法像被腾讯投资的公司一样容易地在微信中获得流量。

 

就像下面这个网友所举的例子一样，**可能小马哥口中的“普通”，是和“普通外科医生”一样的“普通吧”**——

 

![](../Images/c5e69493406000a239568abb20eeeb2b.png)

  

其实不光是鹅厂自身的业务，连鹅厂的投资情况都不“普通”。

 

有媒体报道，截至2021年12月31日，腾讯是多家上市公司大股东，**初步统计多达48家**，包括美团、拼多多、蔚来等知名互联网公司，甚至还间接持有特斯拉股份。

 

而这48家上市公司市值只有多惊人呢？根据中国经济周刊报道，**2021年末，仅这48家上市公司的总市值就已经达到了11.62万亿元，是377家科创板公司总市值的1.86倍，四舍五入就是****两个科创板****了。**

 

![](../Images/63a5598cbd9e4cccfb187cd665b6e3e9.png)

 

在文章中，码君认为随着反垄断的进行，巨头们的日子会越来越难过，如今看来，**如何变得“普通”大抵是巨头们接下来必修的学分了......**
