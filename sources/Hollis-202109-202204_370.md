# 推荐两款工具给爱做实验的人

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650170378&idx=3&sn=54b3c8588221136ddb977358730652c7&chksm=f368792bc41ff03d29c0bed8a504cc3ed7b4ef372710d4bfa8ebca325a04bc39e77828bedfa8&scene=126&sessionid=1681657353#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650170378&idx=3&sn=54b3c8588221136ddb977358730652c7&chksm=f368792bc41ff03d29c0bed8a504cc3ed7b4ef372710d4bfa8ebca325a04bc39e77828bedfa8&scene=126&sessionid=1681657353#rd)

最近在研究 Graalvm，弄了个远程服务器作为实验环境，有的时候用公司的 mac 去连，有的时候用家里的 win 本去连，有的时候上下班路上一共两个多小时也想用手机连一连。 之前 ssh 的话 win 里面就用 **xshell **或者 **secureCRT**，个人感觉都不好用。mac 上的话要么自带的 terminal，要么 **FinalShell**，都感觉很不舒服。手机端就更没找到合适的连接工具了。 不过最近发现一款新的连接 SSH 的工具，**Termius**。 ![](../Images/0e073e90b4e796d1076bc5c47b2e2ed5.png) 居然全平台都支持！ ![](../Images/51365c5b5a76a5da5b30a6c83d0ea958.png) 而且你看侧边栏，还有 **SFTP**，其他功能用起来也是十分舒适，科技感十足。全平台支持这点就足够我选择这个工具了，再加上它的舒适性，以后终于可以随时随地连我的服务器进行各种实验咯！ 再由于研究 Graalvm 时，需要用到 **Java 11** 或者 **Java 17**，但服务器上肯定保留更常用的 **Java 8**。一想到要下载一堆不同版本的 JDK，然后还要配置 JAVA\_HOME，还要不断切换，头立刻就大了。 如果有一款能够方便帮我管理这些 jdk 的工具就好了，所以我发现了一个好用的工具，**sdkman**，不仅仅是 Java 的环境，其他环境也能够管理起来！ 拿 Java 举例，输入sdk list java即可看到支持的所有 Java 相关的 sdk。 ![](../Images/795c2447724eb731235908671e5d5d87.png) 比如我们想把 Java 17 下载下来，就输入sdk install java 17-open 下载安装和配置环境变量都是全自动的，稍等片刻，然后就会看到 jdk 已经自动切换到 17 了。 ![](../Images/c93e1085e2bf60b2edc34f851ec5f95c.png) 当然还可以再切回原来的版本，输入sdk d java  8.0.302-open 再看 jdk 版本已经变成了 8。 ![](../Images/825899062ea7a13dedc9dbe68c453833.png) 配合着 Terminus 和 sdkman，终于可以愉快地研究 Graalvm 技术啦！有的时候找到合适的工具完全可以事半功倍。
