优秀的国产Linux发行版不断涌现，今天我们来看一款最近非常火热的CutefishOS。

CutefishOS提供了Ubuntu系统上的可视化界面，非常精美，在国外 Linux 开源社区相当受欢迎。

CutefishOS发行版背后开发团队为可爱鱼科技，成立于 2021 年，是一家专注于 Linux 桌面端操作系统研发与服务的公司，可爱鱼寓意为热爱与美好。

CutefishOS 作为核心产品，是一款具有现代风格设计与实用的 Linux 桌面操作系统，可以满足在各种场景下的使用需求。

桌面的整体布局与 macOS 相似，追求简单、美观、实用。内置了谷歌浏览器、文件管理、设置、终端、计算器等常用的应用程序。同时支持 WPS、网易云音乐、搜狗输入法、网盘、QQ 音乐等办公及日用的常见软件。

![](../Images/f13346161336f4bc1b887169e73ad768.png)

Cutefish 桌面程序已在 ArchLinux 和 Manjaro 中上线，目前最新版本为 0.4 版，仅提供用于测试和开发目的的下载版，而日常使用的桌面环境正在积极开发中。

据悉，目前该项目已被翻译成 40 多种语言，并已经在 GitHub 上开源（安装需要 20 GB 的可用空间和至少 2 GB 的 RAM）。

官网：https://cn.cutefishos.com/

下载：https://cutefish-ubuntu.github.io/download/

**重点：CutefishOS 是一个开源项目，任何人都可以了解它的工作原理，参与协作。**
