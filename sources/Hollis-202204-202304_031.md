# 谷歌中国区裁员，N+9是谣言！

谷歌中国区宣布裁员，网传N+9 的赔偿。之后很快就被证实是谣言了，因为真实情况是：

**3.10号之前签字，给N+9 加上股票归属。也就是说，如果你在谷歌工作3年，那么这波直接补偿一年工资。更重要的是，没到手的股票都是可以归属的**

**![](../Images/aea22922798b1536350a5f65229b7f50.png)**

像之前的很多裁员，基本没到手的股票都直接回收了，不得不说谷歌这波是真的慷慨了。严重怀疑这波是在恶意补偿，扰乱市场。

**N+9 +股票，什么概念呢？就是保守估计也有40-50W吧。如果年限多的，可以开开心心的退休**了。

其实早在2月份的时候，谷歌就宣布会在全球范围内裁员1.2万人，并且说补偿会令大家满意，现在看来，确实做到了。

据说现在上海的谷歌员工有两种，一种是在裁员名单里，非常高兴地。另外一种是不在裁员名单中，表示非常羡慕的。

让员工高高兴兴的走，谷歌做到了，这才叫好聚好散。建议国内的互联网公司抓紧跟进。
