# 开发者危机！GitHub、GitLab 全部大裁员

科技圈呈现出了截然相反的模样。

一方面，ChatGPT 之火熊熊燃起，国内外各大公司都进入了 AIGC 的混战时刻。另一方面，裁员之寒潮不断，在微软、亚马逊、Google 等开启数万人大裁员之时，全球两大代码托管平台 —— GitHub 和 GitLab 也在同一时间开启了裁员模式。

北京时间 2 月 10 日消息，据 TechCrunch 等多家媒体报道，GitHub 将在财年结束前裁员 10%。当前，GitHub 拥有着 3000 名左右的员工，这意味着将裁员 300 名。GitHub 进入了只出不进的状态，宣布招聘冻结，并基于保护业务短期健康的目的，将进行内部调整。

为了节省开支进一步降低运营成本，GitHub 做了诸多的举措，包括：

*   全面转向远程办公。由于在世界各地的办公室利用率非常低，GitHub 将在租约到期或运营能力允许时关闭所有的线下办公室
    
*   将笔记本电脑的更新周期从三年改为四年，这一举措立即生效。
    
*   基于节省成本并简化跨公司和客户的对话的目的，采用 Microsoft Teams 来作为视频会议工具，这一举措将在 2023 年 9 月 1 日完成。同时，依然使用 Slack 作为日常协作工具。
    

在给员工的邮件中，GitHub CEO Thomas Dohmke 表示这是一个「艰难的决定」，但「持续的增长对每个企业都至关重要」：

对于 GitHub 而言，这意味着我们将继续在全球范围内帮助更多的开发者提高生产力，并拥抱变化适时而动。今天，我们是 1 亿名开发者的家园，我们必须成为未来世界 Developer First 的工程系统。人工智能时代已经开启，我们用 GitHub Copilot 引领变革。我们迎来了一个新的机遇——建立一个集成的、由 AI 驱动的 GitHub。

仿佛宿命般，与 GitHub 有直接竞争关系的 GitLab 也在同一时间宣布了裁员。GitLab 一直就以完全透明、全部远程办公而闻名。GitLab 宣布了裁员 7% 的决定。GitLab 当前拥有 1860 名员工，7% 意味着将有 130 名左右的员工被裁。该消息一出，GitLab 的股价下跌了约 12%。

GitLab CEO Sid Sijbrandij 在全员信中表示，「由于当前宏观经济环境异常艰难」，由此不得不来采取措施：

我曾希望通过重新调整支出的优先级来抵御日益严重的全球经济衰退。但不幸的是，我们依然需要采取进一步的措施，来使我们的支出速度与增长相匹配。

GitLab 提供了 N+4 的裁员补偿，并将基于员工的位置将医疗保健延长 6 个月，还将和第三方合作伙伴一起提供再就业支持。

GitHub 和 GitLab 同时裁员实在是给了开发者圈一记重创。作为全球开发者使用最多的两大代码托管平台，他们都很关注中国市场，都曾来到中国。感兴趣的朋友可以延伸阅读：
