# Apple商业网站封锁Firefox浏览器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650187875&idx=3&sn=b17b6201d3f1b69a5ee565718c7c395a&chksm=f368b542c41f3c5480063a43cf131704bca5d84a99a50e96cb21917438b91ee592327400bed5&scene=126&sessionid=1681657257#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650187875&idx=3&sn=b17b6201d3f1b69a5ee565718c7c395a&chksm=f368b542c41f3c5480063a43cf131704bca5d84a99a50e96cb21917438b91ee592327400bed5&scene=126&sessionid=1681657257#rd)

**[Hollis的新书限时折扣中，一本深入讲解Java基础的干货笔记！](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650180951&idx=1&sn=703dc4a8a3a1a1075915f1897ff07806&chksm=f3689076c41f1960aeeefea49a2625f92e45a6ae0c33b9ae1fc53d6eb3fde79e0b6a2d177292&scene=21#wechat_redirect)**出品 | OSC开源社区（ID：oschina2013）据外媒 Ghacks 报道，用户在 Mozilla Firefox 浏览器中打开 Apple 的商业网站 business.apple.com 时，会看到 “您的浏览器不受支持” 提示。所有最新版本的 Firefox 都会显示该消息，包括 Firefox Stable、Firefox ESR 和 Firefox Nightly。![](../Images/6ca128541367f60cf86b19f0daa273e3.png)从图中可以看到，business.apple 确实封锁了 Firefox 浏览器，并推荐用户使用使用 Safari、Microsoft Edge 或 Chrome 访问（经测试，大部分基于 Choromium 的零浏览器均可正常浏览）。Apple Business 中文站点倒是提及了 Firefox ，然而小编使用最新的 Firefox 102.0.1 也无法打开该网站。![](../Images/42347637f87e41fbd870e32f4e642102.png)苹果没有透露为什么不支持 Firefox，有些网友猜测也许是**技术限制，**导致苹果的商业网站不兼容 Firefox。但这说法毫无依据，毕竟 Firefox 和 Chrome 多年来都在统一战线制定 Web 标准，支持 Chrome 的网站都能用 Firefox 正常浏览，更何况是苹果这样的超级大厂。而且， business.apple 其实**可以用 Firefox 正常访问，只是把 Firefox 的 UA 封锁了**。用户可以通过将 Firefox 的用户代理（user agent - 用户代理，通常用作标识符，标记浏览器的名称、版本以及其他系统信息。）改成 Chrome （Chrome 在地址栏输入 chrome://version/ 查看 UA），用虚假的用户代理标识符来跳过 Apple 的封锁。具体操作方式如下：

  

*   在 Firefox 地址栏输入 about:config 然后回车，点击同意跳过警告。
    
*   搜索 general.useragent.override ，如果没有该选项，则点右侧的 + 号新建字符串。
    
*   新建 general.useragent.override 后，点击编辑，输入 Chrome 浏览器的 UA ，重启 Firefox 即可。
    

  

![](../Images/bb4b02bb6b9e7f2d461666d2df3dcaf1.png)该方法不仅适用于 business.apple 网站，浏览器被任意网站封锁，都可以通过修改 UA 来蒙混过关。 此外，Firefox 扩展商店已经存在一款 UA 切换器和管理器扩展，该扩展专门用来修改 UA ，以混淆网站收集到的浏览器和系统信息。
