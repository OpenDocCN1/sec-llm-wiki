# 疑似被Apple招安，PlayCover作者删库跑路

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650187782&idx=1&sn=586d9183e473def78ffcaf0e81b2d5a5&chksm=f368b527c41f3c3138bf95aeb52ccade272ab7c4c669059fb99501c9527d5aed452210639f1a&scene=126&sessionid=1681657257#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650187782&idx=1&sn=586d9183e473def78ffcaf0e81b2d5a5&chksm=f368b527c41f3c3138bf95aeb52ccade272ab7c4c669059fb99501c9527d5aed452210639f1a&scene=126&sessionid=1681657257#rd)

出品 | OSC开源社区（ID：oschina2013）**[Hollis的新书限时折扣中，一本深入讲解Java基础的干货笔记！](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650180951&idx=1&sn=703dc4a8a3a1a1075915f1897ff07806&chksm=f3689076c41f1960aeeefea49a2625f92e45a6ae0c33b9ae1fc53d6eb3fde79e0b6a2d177292&scene=21#wechat_redirect)**PlayCover 是一款能让任意 iOS App 在 M1 Mac 上运行的开源工具，源代码托管在 GitHub 上。但周日 V2EX 用户 @dingwen07 发帖称该仓库突然 404 了，疑似作者删库了。PlayCover 的 Discord 社区管理员表示现在 PlayCover 的作者联系不上，并称作者删库不是 Apple 公司的要求。![](../Images/c35d2b5108a007274cb757551ac612b8.png)因作者失联，目前关于删库的原因是众说纷纭，有网友认为这是 Apple 对作者施压，又或者把作者招安了（入职公司或收购了该软件） 。令又有网友爆料称：“因为有人拿着源代码编译之后上架 App Store 收费，所以作者把代码从 Github 上面下架了。”但具体原因尚未定论，GitHub 上已经有开发者 Fork 了该项目，称 “原始项目变得非免费和非开源，因此 Fork 了一个社区版本。”![](../Images/e2d3ac7b2724250e107917fd78d3ec6c.png)此外，目前 Discord 社区里有最新的 PlayCover 1.0.5 版本的 DMG，有用户在社区里下载了 1.0.5 ，此版本可运行而且**多了订阅功能**，不清楚是否为原作者增加的。相关链接：
