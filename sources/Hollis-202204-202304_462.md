# 瞬间5k+ star，马斯克以440亿美元收购Twitter并宣布将开源

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzE0NjcwMg==&mid=2650180211&idx=2&sn=aa26050eb04b628cdcaf600780667f7c&chksm=f3689752c41f1e444fed4ff1a54dbb8874dc2e682d1610e1f0dfc052dd0541c17c7fd3eead0d&scene=126&sessionid=1681657285#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzE0NjcwMg==&mid=2650180211&idx=2&sn=aa26050eb04b628cdcaf600780667f7c&chksm=f3689752c41f1e444fed4ff1a54dbb8874dc2e682d1610e1f0dfc052dd0541c17c7fd3eead0d&scene=126&sessionid=1681657285#rd)

文 | 罗奇奇  
出品 | OSC开源社区（ID：oschina2013据外媒 BBC 报道，特斯拉 CEO 马斯克已经以每股 54.20 美元、总价 440 亿成功地完全收购了 Twitter，该公司随后将成为一家私人控股实体。  
在新闻稿中，马斯克解释说，他将努力让 Twitter 变得比以往更好，并承诺将更加关注言论自由。

> 言论自由是民主运作的基石，而 Twitter 是数字城镇广场，人们在此讨论对人类未来至关重要的问题。
> 
> 我还希望通过使用新功能增强产品、使算法开源以增加信任、击败垃圾邮件机器人，以及对所有人进行身份验证，让 Twitter 变得比以往更好。
> 
> Twitter 具有巨大的潜力——我期待与公司和用户社区合作来解锁它。

![](../Images/accc18b8f41405aa1f47224ad452f76b.png)此前，4 月 15 日，马斯克在加拿大参加 Ted2022 活动时，曾表示 Twitter 的代码应该在 GitHub 上开源，以便公众对其进行检查。事实上，在宣布被马斯克收购的几个小时内， Twitter 的 GitHub 主页多了一个“the-algorithm（算法）”仓库，目前（4 月 26 日上午）该仓库还空无一物，但已经收获了 5K + 的 Stars 。![](../Images/b84587a9a00a61b2d5b06fc5532de728.png)仓库地址：https://github.com/twitter/the-algorithm** PS：**发稿前小编发现该算法仓库已被删除，链接显示 404 ，具体原因未知（或许 GitHub 判定为恶意刷 Star ？）。你怎么看？欢迎评论区讨论~
