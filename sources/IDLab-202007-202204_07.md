组态-探索组态密码

  

使用力控恢复工程，将sys文件夹下的UserInfor.dat每位异或0xff，即可看到明文的管理员密码。

#!/usr/bin/env python

 

\# -\*- coding: utf-8 -\*-

 

c = open('UserInfor.dat', 'rb').read()

 

c = ''.join(chr(ord(i)^0xff) for i in c)
