为什么现代数据格局的变迁使传统的网络安全方法不再有效

从日常新闻头条中我们隐约能够感觉到，如今数据泄露事件的发生频率和规模在显著增加。尽管现实令人不安，但考虑到企业收集和存储的数据量每年都在呈指数级增长，在这个大背景下发生这些并不令人意外。每天，全球人口都要创造约 250 亿亿字节的数据。2022 年底，全球每天创建、捕获、复制和使用的数据量达 97 zettabytes之巨（1 zettabyte 为 1 万亿千兆字节）。

这些数据蕴藏巨大的价值，自然也吸引了大量网络黑客。他们试图窃取或操纵数据，利用这些数据进行欺诈、倒卖或勒索赎金等犯罪活动。企业非常清楚数据面临的威胁，并大力投资网络安全措施。尽管如此，数据泄露事件仍在不断发生。要改变这种状况，我们有必要了解数据的格局在过去十年中发生了怎样的变化，以及这种变化如何使得传统的网络安全框架和方案失效。



2010年之前的数据格局

imperva.com/zh


在 2010 年以前，即智能手机的发明推动互联网大规模采用之前，企业拥有相对明确和受控的人员、流程和技术足迹，用于捕获、处理和存储数据。


曾几何时，收集数据的主要手段仍然依靠纸张。数据通常经由少数经过组织严格验证的员工（即数据录入员）操作。他们将这些数据统一输入到绿屏界面的应用程序中，这些应用程序将数据存储到寥寥几个可用的企业数据库中。所有这些数据处理操作主要在企业自己的数据中心内运行，由 IT 和安全团队控制。



2010年后的数据格局

imperva.com/zh


自 2010 年以来，由互联网行业发起，各企业大规模采用和经历的数字化变革，使我们处理数据的流程发生了重大转变。


如今，每一个企业都有成百上千人（有时候是直接的客户）可以通过网络和移动应用输入数据。这些用户往往未经验证，通常只需要一个电子邮件地址即可获得访问权限。集中式、单体和绿屏界面应用程序已经一去不复返了，取而代之的是通常使用数百个 API 服务构成的 Web 门户和移动应用。数据可能会分散且随机地存储在企业成百个存储的若干个中，它们可能是结构化的，也可能是半结构化的。这些应用程序和数据流负载会在各种数据中心环境（例如本地、云、混合环境）中运行。

上述所有这些综合在一起，创造了一个高度复杂的现代数据环境，即使对于拥有丰富经验、最成熟的网络和数据保护专业人员来说，也构成极大的挑战。与此同时，高度复杂的数据环境也为网络犯罪分子创造了更多访问的机会。虽然企业正在大力投资各种控制措施来克服数据安全的一些问题，但离实现真正的安全仍然存在很大的差距。


例如，“数据防泄露 (DLP) ”方案侧重于阻止内部用户而非外部攻击。“身份、访问管理及加密”方案则无法防范内部威胁或应对凭据被盗。网络和端点控制方案则在数据层无效。

这就是为什么组织需要摆脱被现代数据环境淘汰的传统网络安全框架，转而采用数据优先的网络安全方法。

以下是制定以数据为中心的安全策略时，需要重点关注的三个关键领域。



企业首先需要加强保护的，是通往其数据存储（即应用和 API）的网关。这项目需求中可以采用经过验证的 WAAP 解决方案来实现。成熟的WAAP解决方案，能够利用机器学习来最大限度地减少误报，这项目需求中可以采用经过验证的 WAAP 解决方案来实现。WAAP 方案应该具备强大的 API 安全功能，可以将 API 滥用的监控、检测和预防扩展到数据层；它还应该能够防御帐户接管攻击以及表单劫持等客户端攻击。目前在WAAP业界流行的黄金标准更是结合了“运行时应用自我保护 (RASP)”方案也添加其中，以保护应用程序/API 在其运行时环境中的安全，从而更好地抵御零日攻击和软件供应链攻击。



一旦这些应用和 API 服务得到更好的保护，接下来企业需要考虑使用以数据为中心的控件来保护数据层。这些控制措施需要应用于不同环境（本地、云和混合）中，需要对不同数据类型（结构化、半结构化和非结构化）都有效。



以数据为中心的关键安全控制

● 数据活动监控——对数据存储访问的精细监控。

● 数据访问风险分析——使用 AI/ML 和行为分析来识别异常和有风险的数据访问行为。

● 数据发现和分类——了解数据安全最大风险所关联的资产，即与PII 和其他敏感数据有关的数据

● 数据访问控制——不断审查数据存储访问权限，致力保持“最低授权”模型

● 数据加密——加密静态存储和传输中的数据，以防止窃取

● 数据标记——用非敏感数据替换敏感数据，用于非生产和 QA 环境

● 数据脱敏——屏蔽数据视图以满足数据安全和隐私的要求。数据标记和脱敏方案通常协同发挥作用

● 数据防泄漏 (DLP) – 将 DLP 功能扩展到外部用户、WebApp、API 及其后台数据存储

Imperva 推出的数据安全新平台 DSF 是一体化的数据安全平台，它可以不断汇集了最新的和最主流的数据安全控制，以弥补不断变化的数据格局所造成的管理缺失。提供对所有数据存储的数据访问的全面可见性，帮助数据安全、合规、治理和隐私团队更轻松地管理敏感和关键业务数据的生命周期，无论这些数据位于何处。这种统一的、以数据为中心的方法的主要好处是：它使这些团队能够在数据泄露发生之前了解和减轻有风险的数据访问和操作。



数据安全难题的最后一部分，是使安全运营中心 (SOC) 能够更有效地检测和响应现代数据环境中的安全事件。这要求安全方案能够以 SOC 团队及分析师可理解的方式提供以数据为中心的遥测数据。人工智能和机器学习可以帮助检测异常或有风险的数据访问，并提供情境化警报，从而消除猜测并加快响应速度。在应对数据泄露或疑似数据泄露时，了解数据访问的人员、内容、时间、地点、原因和方式至关重要。借助以数据为中心的遥测技术，您的 SOC 将轻松获得这些答案。


在当前的大环境下，企业成为数据泄露的受害者几乎是不可避免的。企业面临的情景不是“会不会”，而是“何时发生”。这就是为什么企业现在必须着手审阅网络安全战略，并立刻采用以数据为中心的方法。这么做不仅可以大大降低大规模数据泄露的可能性，还可以让企业做好准备与预案，以便在数据泄露发生时迅速做出反应。过去的经验教训告诉我们，正确快速的事件响应对于企业未来的健康和繁荣至关重要。
