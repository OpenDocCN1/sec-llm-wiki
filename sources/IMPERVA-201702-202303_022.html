Imperva再度荣膺Web应用和API保护领域魔力象限领导者

夏季即将结束，进入了应用安全市场的“魔力象限”评选季节。Gartner® 刚刚发布2022 年最新版的魔力象限™评选结果，我们自豪地宣布Imperva 再次被认定为Web 和 API 保护领域的领导者。




Imperva有着多年被评为该领域领导者的记录——在先前的评选体系下，连续7年成为“WAF 解决方案”的领导者；以“Web应用和API保护(WAAP)”这一新分类来计算，也有着 2 年的记录。以什么形式统计并不重要，名称与分类的改变只是在抓挠市场变革的表面而已，今年的魔力象限的评选结果的揭晓更有助于强调这一点。



成为应用安全市场的长期稳定的供应商，无疑是Imperva成功的一部分。由此，我们得以持续监测并捕捉很多网络安全威胁，并以结果和经验来改进安全策略，完善产品及方案来满足客户的需求。事实上，Imperva每天平均能够监测（并阻止）超过 260 亿次攻击。


Gartner将Web 应用防火墙领域魔力象限的评选扩展到WAAP范围，Imperva的解决方案也已经历发展，旨在将安全解决方案融合到 WAAP 市场中，以满足分散市场中更广泛的需求。在应用层WAF 中包含DDoS功能，是Imperva初次尝试这样的改变。在随后的 2019 年，随着对网络机器人Bot 缓解方案供应商的收购，更广泛深入的改变开始发生，这些变化都有助于增强针对在线欺诈等攻击行为的防护。在最近2 年，API相关的安全功能越来越多地整合到云 WAF 解决方案中。Imperva也参与了这一进程，并通过几次收购，成功地把相关产品及服务纳入我们的 WAAP 解决方案中。


Imperva 很清楚过去 10 年应用程序市场和威胁形势发生了多大变化。事实上，Imperva已经能够通过统一的平台来应对这些变化。Imperva的平台结合了同类最佳技术，来保护应用程序、微服务、API端点、无服务器程序和移动应用，上述这些应用服务在几年前甚至还不存在，或者需要多个供应商来解决相关的安全问题。


为了保护企业客户现在和未来的应用服务，可能涉及传统、混合和现代的环境，WAAP 方案需要阻止来自 DDoS、规避检测的机器人和 API 漏洞利用等等一系列高级的网络攻击。上述的挑战是Imperva决定提供具有多层安全性的单栈解决方案的原因，也是我们坚持持续改进 Web 应用程序和 API 保护的动力。我们的 WAAP 解决方案使客户能够以多种方式进行安全部署，从本地部署的设备到 SaaS交付的服务功能，保护云原生应用程序和完整的工作流，覆盖客户数据中以及 AWS、Microsoft Azure 和谷歌云(GCP)等多种云平台。虽然上述列举了很多，但我们相信这些是客户所应得到的保护。
