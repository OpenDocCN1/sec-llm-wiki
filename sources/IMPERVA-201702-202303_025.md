应用程序编程接口 (API) 已成为简化业务运营和增强客户数字体验的有用工具。随着采用API的应用变得愈加广泛, 它们也成为网络威胁领域中首当其冲的攻击对象。 API 相关的黑客攻击和数据泄露已经影响了所有行业所有区域的公司及组织。花费在技术补救和法律上的成本显着增加。为了减轻 API 带来的安全风险，公司必须着手制定符合成本效益的安全策略，实现对API服务的保护并降低安全补救成本。

  

**现今**** API ****安全形势概述**

根据Marsh McLennan最近发布的《量化 API 不安全成本》报告研究人员透露仅在 2020 年，金融服务行业的 API 使用量估计增长了 125%，医疗保健行业的API服务流量激增了 400% 以上。2021年，健康监测 API 的兴起又使得这个增长陡增至 941%，这些数字说明了当前 API 服务繁荣发展的趋势没有放缓的迹象。

  

随着企业扩大 API 的应用范围，降低随之而来的风险成本也在上升。 在过去几年中，多个知名组织成为 API安全事件的受害者，泄露了数十亿条个人和公司记录，导致了近千万美元的经济损失。随着 API 数量的不断增长、数据保护法规的扩大以及恶意行为者对攻击技术的改进，API安全事件增长的趋势将会加速——势必要求企业对稳健有效的 API 保护加大投入。

## **API ****不安全的代价**  

## 

来自Marsh McLennan 研究机构的人员将他们收集的 API 安全事件数据、原始 API 相关事件比例和漏报因素结合起来，估算出所有网络安全事件中与API 相关的比例为 4.1-7.5%。 基于这一比例范围，以下是他们总结的损失估计：

· 12-230 亿美元：API 相关网络安全事件在美国造成的年均损失

· 41-750 亿美元：全球与 API 相关的网络安全事件年均总损失

· 2.05-3.76亿美元：每年与 API 相关的网络安全损失保险赔偿金额

  

有关 API 不安全成本的更详细说明，以及按地域、公司收入和地理位置对 API 相关安全趋势和事件的深入分析，请访问https://www.imperva.com/resources/resource-library/reports/quantifying-the-cost-of-api-insecurity/下载，该报告量化分析了API 不安全成本。
