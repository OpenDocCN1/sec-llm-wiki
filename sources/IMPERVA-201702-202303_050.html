第五. 2021 年恶意机器人报告：互联网领域的疫情大流行


恶意机器人为什么值得关注

2020 年，互联网中有着创纪录的四分之一流量来自恶意机器人，它们对多个行业造成了严重破坏。2021 年恶意机器人报告显示，有57.1% 的流量来自先进的持久型机器人 (APB)。这些机器人通常通过循环访问随机 IP 地址、借助匿名代理、变换身份和模仿人类行为来避免检测，以前所未有的方式给网站带来麻烦。恶意机器人在圣诞和新年假期仍在持续危害互联网。


如何解决

Imperva 高级机器人保护 (ABP) 方案，能够保护电子商务平台免受例如Grinchbot那样恶意机器人的侵害。恶意机器人程序会滥用业务逻辑，占用带宽和服务，导致正常客户几乎无法购买。Imperva的ABP 方案，能够保护电子商务流量的正常访问，同时不会降低网站性能，从而确保最佳客户体验和业务连续性。高级机器人保护可以缓解所有 OWASP 自动化威胁，包括薅羊毛、帐户接管、网页抓取等等攻击。

对游戏行业的 DDoS 攻击为什么值得关注

游戏行业是网络攻击者的高价值目标；除了那些针对玩家、服务平台和游戏工作室的攻击，游戏服务端高规格的硬件机器本身就是用于加密货币挖矿的绝佳资源。完全没有编程知识的人都可以对单个游戏玩家甚或整个网络发起 DoS/DDoS 攻击。只需花费 10 美元，即可在线租用 “DDoS 即服务”，来发攻击，同时这类廉价服务甚至还附带提供技术支持。电竞赛事Fortnite 世界杯遭遇的攻击，也可能发生在你身上。

第三. 为什么数字时代的数据安全和隐私至关重要


为什么数据隐私值得您关注

多年来，人们一直信任银行和医疗保健等组织，由它们来保管和处理敏感的个人和财务信息。如今，在高度互联和数字化的世界中，访问数据的途径及大地丰富了，使得个人信息更容易遭受侵害。数据泄露对任何行业都可能造成严重后果，对于以信任为基础建立客群的企业而言，数据泄露事件更是灾难性的。新科技赛道的公司正对医疗保健领域的客户虎视眈眈，安全事件一旦公之于众，极有可能会侵蚀和伤害原有服务商与用户间的信任，对这个垂直领域的公司造成严重的财务影响。


如何解决

Imperva 数据隐私方案深入到情报层，直接处理和识别大量原始数据，使发现、分类和分析敏感数据变得更容易，同时成本更低。您完全可以针对特定类型的敏感数据，对组织的所有数据进行自动探查，并在需要时触发适当的操作。籍由此功能，组织可以自动化实现数据主体请求的响应，按需删除敏感的个人数据，并向审计证实操作的合规性。


第二. 软件供应链攻击：从表单劫持到第三方代码更改


如今，即使最严格的软件开发生命周期中，也不可避免地会引入漏洞。传统的应用程序扫描工具无法识别每个漏洞。越来越多的依赖和第三方软件组件被引入，使得应用和API 服务端点面临额外的风险，您需要主动控制的方案来减轻相关领域供应链攻击带来的影响。


如何解决

供应链攻击通常会先建立一个落脚点，接着会试图在您的网络中进行横向移动。您需要一种快速简便的方法，通过应用程序行为分析，以积极的安全模型来降低供应链攻击的风险。通过识别所有预期活动，可以轻松发现高风险和可疑行为。Imperva 的运行时应用自我保护 (RASP) 方案，采用轻量级安全插件清楚地分析应用程序内的活动，阻止不需要的操作。例如：当第三方库突然为 C2 建立外部站点的网络连接，RASP即能实现探测并阻止。RASP 保护应用、程序运行时、服务器、开源依赖和第三方库。Imperva RASP可以轻松地嵌入应用程序，在几分钟内完成部署；无需更改任何代码，并且不需要持续的签名更新。


第一. Imperva 如何保护客户免于 CVE-2021-44228 漏洞相关的攻击

为什么 CVE-2021-44228 值得关注

这个零日漏洞仅仅出现了几个星期，但它影响之大危害严重，迅速占领了公众视野。CVE-2021-44228 漏洞，允许未经身份验证的远程代码执行 (RCE)，对于所有采用 Java 程序承接工作负载的公司组织产生了重大的影响。安全团队正在争先恐后地修补软件并升级第三方组件，以满足对终端客户的 SLA 要求。针对该类漏洞，初始的网络攻击峰值达到大约 280K/小时，与其他零日 CVE一样，我们预计这个数字还会不断增长，因为在未来的几天和几周内，会有更多的攻击变种会被创建及发现。


如何解决

采用运行时应用自防护 (RASP) 方案，可以为企业提供更广泛的纵深防御策略，保护应用程序和 API服务端点。Imperva 的客户，特别是来自电子商务和电信行业的客户，通过采用 RASP方案，在应用紧急修补方面节省了数千小时工时，同时加快了安全软件开发生命周期。事实证明，在 Java 应用程序中部署了 RASP 的客户，能够完全避免 CVE-2021-44228 相关的 RCE 的影响。
