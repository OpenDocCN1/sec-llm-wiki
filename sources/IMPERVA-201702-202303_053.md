在上周，Imperva网络威胁研究团队观察研究了新近爆发的 CVE-2021-44228 漏洞危机，并对攻击进行了相关的数据统计。通过对Imperva全球网络流量进行分析，我们的团队发现新的变种并及时做了修补，我们还想在此分享一下在分析过程中我们发现的五件趣事。  

## 

******攻击和被攻击站点******上周以来，攻击者结合使用手动和自动工具，攻击了受 Imperva 云WAF 保护的 84,000 个站点。Imperva 云WAF 总共已阻止了超过 2,000 万次利用 CVE-2021-44228对这些目标站点的攻击尝试。Imperva 正在主动积极地与遭遇严重攻击的网站联系，与客户密切合作解决危机。我们将针对情况，创建与攻击相关的仪表板，提供客户数据报告和统计信息。******客户端分类******许多人或许还没有意识到，Imperva在云WAF中构建了高级客户端分类检测算法。客户端分类是我们整体安全防御系统的一部分，当然这个亮点也会体现在我们提供给客户的仪表板中。客户端相关参数包括 Web 浏览器名称（Chrome、Safari 等）以及开发工具（cURL、wget 等）等内容。![](../Images/42f247c55d9b4eb4c7ca21bf80fcc419.png)**在查看整体日志时，我们发现了与发起攻击流量的客户端相关的趣事**

*   分类中约有47% 的客户端是使用Go 编程语言开发的。这并不奇怪，因为 Go 语言很流行，有一个很棒的内置 HTTP 客户端库，并且是开发人员执行并发请求（goroutines、channels等）的一种简单且高性能的方式。 我们的分类中长尾客户端，种类繁多但每种发起的攻击流量并不大，这些客户端通常是用 Ruby 和 Python 编写的。
*   分类中约有 45% 的客户端被识别为自动化恶意机器人。从某种意义来说，它们与之前用于帐户接管、内容爬取、令牌欺诈等攻击的机器人是完全一样的。
