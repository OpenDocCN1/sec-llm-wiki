Gartner®刚刚发布了2021年度的“Web应用程序和API保护魔力象限”。尽管采用了新名称并且扩大了评议范围，但Imperva仍然被评为这个领域的领导者。并且，在愿景完整性方面，始终获得了最高的评分。

Imperva致力于保护所有场景下的企业应用(OP、云及混合部署)

想象一下8 年前的应用程序，您所能看到架构其实并不复杂：通常是在租用的数据中心内，vSphere虚拟机上运行的一个非常大的单体应用。而当时的API，通常还只是小型初创企业实现创新的工具。记得当年我们还曾与开发团队讨论过 SOAP的优势以及为什么转向REST还为时过早。Amazon Web Services彼时才刚刚开始为工程师提供认证计划。显然8年对于应用程序开发来说来说是很长很长的时间，我们共同见证了太多的变化。

然而，尽管8年以来发生了如此大的变化，今天许多Web应用程序仍然是当时构建的版本。正确迁移到云原生技术（例如无服务器功能）仍然需要大量有条不紊的规划，并且需要逐步持续的投资，以保障可以有效地构拥有RESTful和GraphQL API的应用。多年以来，Imperva一直专注于在为在数字化转型过渡中的组织提供安全性，其中绝大多数场景融合了传统和现代环境。这也是Imperva继续投资 Web 应用程序和 API 保护的一个关键原因。我们的客户可以通过各种方式部署这些保护方案：从自有的数据中心的设备到 SaaS平台，再到在 AWS、Microsoft Azure 和 Google Cloud Platform (GCP) ，都可以像本地部署一样实现防护。

但是，您无法简单地通过调整已有保护策略来保护所有现代企业的应用——需要有创新的方法来保护如今占大部分访问流量的API服务。Imperva 在 2021 年之前已经实现了客户的 API保护，在如今它更是成为重中之重。就在几个月前，Imperva添加了让客户在安全团队的视野之外发现API服务的功能。

为了确保我们的客户能够继续进行现代化改造，Imperva还收购了 CloudVector，以提供大型企业更高级的API安全保护功能；更重要的是，Imperva还从收购中获取了许多保护团队的专业知识。因为有效保护 API，需要深入了解开发的原理，以及了解如今的应用与8 年前开发的程序有何不同。

Imperva预测的2022年及以后的行业需求

Imperva能够很好地应对所有这些变化，我们自信拥有业界首屈一指的方案，我们可以保护客户避免新型攻击的侵害。同时，我们感谢Gartner报告对我们的认可，并非每个应用程序安全供应商，都有我们一样的能力，能够在一年内快速集成收购的产品。举例而言，Imperva的客户目前就可以使用之前由Distil Networks提供的高级机器人管理功能。我们期待 2022 年的报告，让大家一起见证Gartner 和市场的反馈，看到我们在 CloudVector团队的指导下取得了哪些成就。
