# “时间就是金钱”这句话据说出自本杰明·富兰克林，用来谴责懒惰的人浪费他们的工作时间。 作为美国的开国元勋之一，本杰明·富兰克林显然从未在网络安全领域工作过一天。在这个领域，面对越来越多的主动攻击者，以及不断扩大的潜在漏洞，很难以新鲜血液来填补数字世界中防守方的技能差距。 所有部门都很忙，并且资源捉襟见肘；即便企业确实看到了网络安全的必要性，如今很少有企业有着足够充裕的现金来投入其中。虽然企业的每个职能部门都面临着节省时间、金钱和资源的持续压力，但网络安全团队面临的挑战尤其严峻，他们在面对上述几种压力实现工作目标的同时，还必须保障不危及企业数字安全。

# ******可靠的监控解决方案******

采取“基于风险评估”的网络安全方法显然是第一步。 与被动响应的模式相反，数字安全部门必须假设网络犯罪是不可避免的。当前之所以推崇这种方法，是有着广泛统计数据支持的。当今，网络攻击正以每月6% 以上的速度增长。 最近的网络安全统计数据呼吁：公司的领导者必须采取行动认真对待风险管理，并要求他们对安全团队进行前期投资，以防止今后成倍追加费用以及对企业信息安全带来潜在的灾难。

如果像玩“打地鼠”游戏一样对待安全，则这样的实践会既昂贵又耗时。 来自领域及部门的知识，可能更侧重于事件响应，而不是先发制人的网络安全。 知识就是力量，通过增强安全意识创造降低风险的整体态势，使得企业和部门可以做到处变不惊，对攻击趋势、安全头条新闻和紧急情况都不会盲目响应。因为盲目响应会消耗宝贵的资源，同时开销不可预测的成本。

# ******确保减少误报******

我们不可能指望参与监控的安全团队能够对每一个潜在威胁都做出反应，因为每天类似的威胁可能会有数万个或更多。 他们需要对真实的、紧迫的和重要的事件做出反应，以优化(安全处置的)人力资源并防止告警疲劳，也即需要对由于不必要的扩散而无法管理的事件脱敏。

提供更准确、可操作的告警数据且误报更少的系统，对于节省时间和资源非常重要。 这意味着安全团队能够在明确的指导下做出响应：了解什么事件是重要的，并就如何反制提出明确的措施，而不是模糊的定位和含糊其辞的建议。 一个低误报的系统，为网络安全从业人员提供了高效处理日常无数事件的关键能力，使得他们能够专注地处理真正需要他们关心的安全事件。

# ******只为您使用到的工具付费******

您上次对所使用的安全工具进行审计是什么时候？根据 IBM Security 和 Ponemon Institute 在 2020 年发布的Cyber Resilience Organization报告，每个企业平均部署了多达45 种不同的安全解决方案和技术。审视您的实际需要，并将这些工具融合到合适的统一解决方案和一个集中管理界面中，这常常意味着大量的资金节省，并且能够减少维护、培训、调度和人力方面的投入。

# ******减少公司威胁形势******

如果您的每个同事都能尽可能少的接触风险，您自然能够大大限制安全威胁面。如果他们无法访问不安全的网站，那么这类危险就会从公司面临的威胁形势中消除。在整个企业中，应用有效的全局隐私设置，可以大大减少员工感染恶意软件或病毒的可能。实施零信任策略，只将特定的权限授予需要访问特定网站和或功能的人员，可以缓解甚至消除许多潜在问题。

部署配置有效的垃圾邮件拦截器，以清除电子邮件中所有可能包含的恶意链接。这是一种极好的预防策略，因为这些链接指向的很可能是包含恶意代码的网站，用于窃取凭据或安装恶意程序。只需少量投资，就可以在未来节省时间和开支方面的巨大浪费。

# ******网络安全自动化******

传统上，大部分网络安全操作都需要人工干预；然而，许多任务其实都可以自动化。例如，投入主机威胁情报的监控和检测系统，完全可以做到通过程序化方式实现网络威胁的检测、调查和分类。无论有无人为干预，系统都能够识别潜在问题、为事件分配紧急程度，然后提醒相关责任人，以便及时根据回复处置问题。

其他可能的网络安全自动化领域还有很多，我们在此仅举几例可能涵盖的功能：检测网络中已经存在的威胁、提取和收集数据生成报告、自动软件更新、查找和分类敏感数据、用户权限归属和证书管理。

分析您的投资回报很重要。通常有多少员工参与完成合规报告？每年在安全审计上花费多少工时？每年花在处理数据库日志上的平均时间是多少？使用正确的网络安全自动化系统，上述一切都很容易简化，对于许多其他任务也是如此。

自动化的实现，可以减少错误，优化决策，既使得流程高效又兼具成本效益。并且机器本质上是可以24/7/365运作的，还可以填补许多网络安全团队面临的行业人才短缺问题。

# ******员工的网络安全教育******

人为错误是最重要的网络安全漏洞之一。通常某个员工不经意犯下的错误，最终成为任何企业网络安全健康的最大威胁。在公司数据的处理流程中，减少犯人为错误的机会，本质上大大增强了企业信息安全。与人力资源部门一起策划基本的内部培训，让员工了解网络钓鱼诈骗的实施，以及良好的 IT 安全实践，以后可以大大节省事后补救的时间和资源。与勒索软件泄露的造成的成本和损失相比，花半天的时间剪辑含画外音的视频，制作一些易于理解的幻灯片，展示网络安全和公司政策的重要性，这些付出是完全值得的。

简单地通过节省人力和预算，也可以大大提升效率和改善安全状况。采取自动化手段、加强员工教育、实现(安全资源)整合，可以带来持久的财务和资源支出方面的重大影响。

现在小额的安全投入将会在未来赢得多方面的回报：节省时间、节省资源、节省金钱——此外还提供更好的企业安全态势，同时填补潜在的攻防水平差距。而通过各种手段提升效率节省企业资源，始终是能够同时节省时间和金钱的最佳方式。
