无论是被称为**“新常态”**还是“下一个常态” ，COVID-19 的时代影响着全球所有企业，并在后疫情时代加速了企业的**数字化转型**。无论是全渠道商务等零售行业新近趋势，还是像非接触式交易这样后 COVID时代才出现的业务方式，都表明了企业在加速走向数字化。

曾经有一段时间，在美国的与餐馆和其他食品相关的服务只能在网上交易。一家领先的在线交易供应商提供的报告透露：“在充满前所未有变化和挑战的2020年中，为企业拥抱数字支付提供了很不错的尝试机会。许多人第一次转移到网上办理业务，整个社会迎来了新的数字化转型。”为了维持全球业务，许多企业都将在线商务视为关键因素。在专注推进在线商务的同时，企业还投资Wi-Fi6 和 5G，利用新协议实现的更快网络来增强在线服务和移动端客户体验。  
同样，伴随后疫情时代数字化潮流，网络犯罪分子也顺势而动，他们通过机器人和其他“创新”威胁逐渐提高着网络攻击水平。Verizon 最新发布的 “2021 年数据泄露报告”证实了上述说法，“疫情已经影响了网络犯罪活动，网络攻击的重点强势转移到了实现居家办公的基础设施及服务上。在2020 年所有数据泄露中，有 39% 源于 Web 应用程序问题。”幸运的是，Imperva 发布了新的**WAF 网关版本 14.4.0.10**，不断提升服务安全性并降低风险，帮助我们的企业客户应对上述几类威胁。最新的WAF版本具有以下亮点： 

*   **高级机器人防护：**鉴于目前有**超过 24% 的互联网流量来自恶意机器人**，Imperva 在最新版本中将行业领先的机器人保护技术完全集成到其** Web 应用程序防火墙**解决方案中，以保护企业的应用程序和网站。 **高级机器人**防护功能的集成，使得实现真正的纵深防御得以实现，同时部署比以往任何时候都更容易、快捷和灵活。
*   **提升安全性和性能，适配数字协议：**更多企业实施全渠道战略，希望将客户体验从网络扩展到智能手机，应对这种需求，WAF优化了安全性和性能，更好地适配 HTTP2及TLS 1.3，支持从视频流到 3D 视觉效果等更多动态内容的投放。
