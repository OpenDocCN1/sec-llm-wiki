**0X00背景：**

**Weblogic Server远程代码执行漏洞（CVE-2021-2109），危害等级：高危。**

  

**【漏洞描述】**

Oracle WebLogic Server包含一个漏洞，该漏洞在输入传递到/console/console.portal时未正确验证。这可能允许经过身份验证的远程攻击者注入JNDI内容并执行任意代码。

  

**【漏洞编号】**

CVE-2021-2109

  

**【受影响版本】**

WebLogic 10.3.6.0.0

WebLogic 12.1.3.0.0

WebLogic 12.2.1.3.0

WebLogic 12.2.1.4.0

WebLogic 14.1.1.0.0

**0x02 Imperva WAF解决方案**

  

Imperva SecureSphere WAF可以通过配置以下自定义规则进行临时防护，后续ADC签名更新也将包含相应策略或者签名。

  

**Waf防护规则配置**

**1、【主项】->【配置】->【特征码】，按下列规则创建新的自定义字典：**

特征码名称：CVE-2021-2109: Oracle WebLogic Server - JNDI Injection RCE – 1

特征码规则：part="/console/consolejndi.portal",part="AdminServer",rgxp="\\bcom\\.bea\\.console\\.handles\\.JndiBindingHandle\\s?\\(.{1,200}\\;AdminServer"

协议：http、https

在哪个位置匹配：Parameters, Urls And Parameters, Url

 

特征码名称：CVE-2021-2109: Oracle WebLogic Server - JNDI Injection RCE – 2

特征码规则：part="/console/consolejndi.portal",part="AdminServer",rgxp="\\bcom\\.bea\\.console\\.handles\\.JndiContextHandle\\s?\\(.{1,200}\\;AdminServer"

协议：http、https

在哪个位置匹配：Parameters, Urls And Parameters, Url

 

特征码名称：CVE-2021-2109: Oracle WebLogic Server - JNDI Injection RCE – 3

特征码规则：part="/console/console.portal",part="AdminServer",rgxp="\\bcom\\.bea\\.console\\.handles\\.JndiBindingHandle\\s?\\(.{1,200}\\;AdminServer"

协议：http、https

在哪个位置匹配：Parameters, Urls And Parameters, Url

 

特征码名称：CVE-2021-2109: Oracle WebLogic Server - JNDI Injection RCE – 4

特征码规则：part="/console/console.portal",part="AdminServer",rgxp="\\bcom\\.bea\\.console\\.handles\\.JndiContextHandle\\s?\\(.{1,200}\\;AdminServer"

协议：http、https

**0x03 Imperva RASP解决方案**

 

Imperva RASP产品采用LangSec专利技术基于语义和上线文来进行安全防护，无需更新签名，默认可以防护该漏洞。如有需要，请联系Imperva中国团队试用。
