# 使用Advanced Bot Protection解决方案处理流量更强的攻击

六个月前，我们将**Advanced Bot Protection**解决方案集成到了Imperva的应用安全平台上。而此前，该解决方案是在我们收购Distil Networks后的一个独立平台上（Distil）运行的。为获得更好的性能和效率，在Distil上的现有客户正在迅速迁移到新的平台上，而且我们赢得新客户的速度也比以往更快。这些迁移工作仍在进行中，但我们很高兴地看到，**与传统的Distil平台相比，在集成的应用安全平台上，已经有更多的流量正在受到Advanced Bot Protection的保护**。

  

  

![](../Images/367a58109713f957be46bd7c44dba0e5.png)

  

**新冠肺炎疫情与恶意僵尸程序**

  

当下的僵尸程序问题比以往任何时候都要严重。Imperva的《恶意僵尸程序报告》显示，**2019年，由恶意自动化工具导致的流量增加了24.1%**。2020年疫情期间，因为居家办公人数的上升导致互联网流量增加，僵尸程序的影响力不容小觑。由于某些运营方使用恶意僵尸程序来获得用户未经授权的访问权限，使得凭证填充攻击正在上升。

  

**移除恶意僵尸程序可提升业务指标**

  

消除了网站、移动应用程序和API中的恶意自动化流量后，企业能看见立竿见影的效果，尤其是**对企业的电子商务交易转化率、航空公司访问预定率和账户欺诈等商业指标的改善最为明显**。此外，在降低了恶意僵尸程序流量所占用的基础设施成本后，企业还能**在提高网站安全性的同时，获得宝贵的投资回报率**。

  

**效率提升促进企业KPI增长**

  

**Imperva坚持改进检测方法以识别恶意僵尸程序**。长期以来，客户也看到了明显的效果。随着新技术的开发和部署，**企业所关注和追踪的多个KPI也取得了显著改善**。由于更多恶意僵尸程序被Imperva的Advanced Bot Protection解决方案所拦截，很多**企业追踪的KPI指标都上升了60-80%**。

  

**性能也很重要**

  

新客户在部署新的Advanced Bot Protection解决方案时也能有其他收获。**由于Imperva平台具有快速内容分发网络的性能优势，因此页面加载速度明显更快**。  

  

**安全性不受攻击速度影响**

  

当下，几乎所有攻击都是由自动化工具或某种类型的僵尸程序所发起的。**Imperva的Advanced Bot Protection解决方案具备超快的响应速度，能保护网络免受大规模的拒绝服务攻击、僵尸程序滥用、magecart攻击、OWASP 排名前10的网站所列出的所有攻击以及API攻击，确保企业安全**。在当前的商业环境下，自动化攻击需要自动化的解决方案，但是，僵尸程序攻击问题总是层出不穷。因此，在对抗复杂的僵尸程序攻击时，人们的专业经验也十分重要。
