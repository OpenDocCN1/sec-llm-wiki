# **关于Imperva公司**

Imperva是一家公认领先的网络安全供应商，提供世界一流的数据、应用、API安全解决方案。公司成立于2002年，总部位于美国加州红木海岸，在全球100多个国家拥有超过6000+直接客户和超过550+合作伙伴。其Web应用防火墙(WAF)产品自2014年起，在全球Gartner WAF魔力象限图中已经连续六年入选魔力象限领导者，同时在Forrester的DDoS、Runtime Application Self-Protection、Bot Management的报告中处于领导者品牌。
