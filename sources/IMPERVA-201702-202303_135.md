# 实战攻防线上研讨会 - 汇聚全球顶尖攻防技术的安全攻守道

3月6日，由Imperva组织的线上研讨会《实战攻防线上研讨会 - 汇聚全球顶尖攻防技术的安全攻守道》第一期《看不见的敌人，看得见的原理》圆满结束。近1000位小伙伴一道聆听了来自Imperva的资深技术专家刘沛旻以及观安无相实验室高级攻防专家尹建磊的精彩讲解。

**健全安全模型，补齐安全短板**

在刘沛旻的演讲中，重点介绍了需要完善的应用安全健全模型，并结合专项行动实践经验，论述了企业如何做才能补齐现有安全短板。

在知识分享部分，刘沛旻重点向小伙伴介绍了攻防演练与真实攻击的区别，攻防演练侧重提权内容而真实攻击则注重数据窃取与针对应用层开展的DDoS攻击。

尽管攻防演练成效显著，但从安全建设的长远规划来考虑，安全团队需要把单纯攻防上升为完善的安全模型，这也是Imperva首次向业界介绍的应用安全健全模型。

![](../Images/68a6c56283adfe9416451b5660ec3148.png)

在这个模型当中，网络安全的未来将从被动防御向主动防御转变，即从以签名为基础的网络威胁堵截向以白名单为主的防御模式转变，而网络安全的高级阶段则是DevSecOps。  

**了解攻击机制 填补系统漏洞**

观安无相实验室高级攻防专家尹建磊分享了近几年开展的专项行动及其背后意义，以攻击方的视角，‌‌向小伙伴分享了攻击、建营和达阵常用的战术，并结合历次专项行动中的经典案例，总结企业在安全防御方面的得失。他强调，运维不足是系统漏洞不能及时修补的原因，“打铁还需自身硬”，要扛得住攻击就要从内功练起。

每期内容如同专家分享的渗透步骤”踩点”、 “建营” 、“达阵”一样，本次系列线上研讨会四期活动也是环环相扣，由理论到实践，由Web到Code，由人工到自动化的分期介绍，后面三期小伙伴可以就感兴趣的议题持续关注及参与。
