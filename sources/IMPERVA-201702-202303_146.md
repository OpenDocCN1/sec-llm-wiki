Web应用程序的格局日新月异，最佳安全防护的实现，仰赖于工具也做出相应转变。近期Imperva在API安全、机器人防护、DDoS以及云WAF领域不断取得进步，在Gartner最新云Web应用程序与API防护(WAAP)安全评级中，Imperva位列三甲，可谓实至名归。  
Gartner*“2019年云Web应用程序防火墙服务的关键能力”*报告(2019 Critical Capabilities for Cloud Web Application Firewall Services)，从三个行业用例的角度对WAF供应商逐一考察。此份报告中，Imperva是唯一能够在三个场景中都做到数一数二的供应商，这三个用例包括：

*   面向公众的Web应用
*   API安全
*   Web-Scale核心商业应用

在所有场景评估中位列前两名的成绩中，值得一提的是Imperva还在“保护面向公众的**Web**应用程序和**API**”方面获得最高评分。以下，我们将逐条分析Imperva在各用例中的得分，详述这些评分意味着什么。**面向公众的Web应用程序**  
在*“面向公众的Web应用程序”*用例方面，Imperva获得了满分5分中的最高评分3.84分。面临的现状是，公司或组织机构在试图全面保护其公众的网站时，往往受资源掣肘。云WAF能够轻松部署，有着直观的界面，深度的安全覆盖，很好地解决了上述问题。约有90%的Imperva用户，采用了我们的开箱即用的安全策略作为缺省的防御设置措施。“设置完毕即可高枕无忧”的模式将客户安全方面的相关工作交由Imperva安全专家来处理。对于安全策略的具体调整，我们提供了一整套定制化安全规则，同时提供过滤规则设置方便实现自助操作，助力客户根据实际环境对策略加以调优。![](../Images/8c8547427e7583db4c72fc386ba4adba.png)图1：各供应商在“面向公众的Web应用程序”用例方面获得的评分**API安全**  
在*“API安全”*方面，Imperva获得了满分5分中的最高评分3.49分。作为数字化转型的基石，API的引入和实现，使得组织能够在创新架构下开发应用程序、实现B2B流程自动化、连接IoT设备，同时作为移动应用程序的后台服务而使用。随着越来越多的组织开启数字化转型进程，伴随着API服务的流行和繁荣，对API的攻击也在同步增长，愈演愈烈。我们在云应用程序安全系列（方案）中集成了API安全，轻松为您的API服务保驾护航。API安全应用了我们的CDN服务和DDoS防护能力，并且籍由相同的SaaS基础设施，在统一的门户界面下进行管理。Imperva高级副总裁Terry Ray在Imperva举办的“WAF主要趋势及要求”的在线研讨会中表示，“从API安全的角度考虑，你肯定希望它能与安全服务功能堆栈捆绑在一起，以方便你更好地了解、应对威胁。能够可视化地展现API端点的访问和状态，是我们比较看重的一项功能。这意味着无论在何时你部署了API，它可以随时得到更新，我们也可以保障API端点的安全。因为在大多数环境里API的更新极其频繁，这种情况下你肯定会不想通过Web应用程序防火墙来做调整，而是希望API安全防护能够自动跟紧运维一体化团队及其他人员对API变更的频度。”![](../Images/fcad6c7d0aaf1a5ada425a9129cfb300.png)图3：各大供应商在“API安全”用例方面获得的产品得分**Web-Scale核心商业应用**  
在*“Web-Scale核心商业应用”*用例方面，Imperva在满分5分中得到3.53分。这并不是参测厂商中的最高分，但我们对保护关键业务应用的理解是：保障应用始终可用，对用户友好，同时免受网络攻击。这就是为什么我们始终坚持提供可扩展基础设施，以及不断增设PoP点的原因。此外，这也是我们能够承诺业界领先的DDoS服务等级协议(SLA)，做到3秒DDoS防护的原因。同样，也是我们在去年收购Distil Networks，这家机器人防护领域全球领军企业的原因。这些都赋予我们不同往昔的能力，助力我们在不影响业务关键流量的前提下实现对网站、移动应用以及API接口的防护。![](../Images/9bde5889501d5f4d2f775a7f624dd24a.png)图2：各大供应商在“Web级关键业务应用程序”用例方面获得的评分**与Imperva这一业界公认的行业领先者共同进步**
