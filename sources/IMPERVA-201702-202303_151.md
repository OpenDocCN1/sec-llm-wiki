# 机器学习如何变革金融服务

人工智能 (AI) 渐渐融入我们的日常生活：决定我们从社交媒体看到哪些新闻、启动面部识别解锁智能手机，甚至能够向我们推荐音乐。作为AI一个分支的机器学习，也在逐渐地渗透进方方面面，改变着我们的生活方式和决策方式。**机器学习在金融行业的应用**业务变革方兴未艾，现代技术的进步更是加速了这种变革。机器学习通过分析历史数据和行为，来预测模式并作出决断，进而为客户提供定制产品和服务，其能力也已从零售行业实践的巨大成功所验证。从某种意义上来说，小额业务银行与机器学习的相遇可说是天作之合，这一说法相信没有人会质疑。正是有了机器学习，诸如征信防欺诈与信用积分这样的功能目前已经做到自动化。此外，银行也在利用机器学习与预测分析技术，向客户提供更加定制化的体验：推荐最新产品，实现动画聊天机器人，应对账户查询、支付账单这样的日常业务。此外，机器学习也在颠覆着保险行业。越来越多的互联设备能够提供客户行为的深层信息，保险公司可基于数据来设定保费标准并做出赔付决定。保险行业科技公司则力图利用这些技术为客户开发出增强版方案，让保险行业焕然一新。保险行业所蕴藏的变革潜能是巨大的，正如麦肯锡公司所言“保险行业正在向技术驱动型转变，巨大变革即将到来”。**金融贸易**没有哪个行业能像金融服务行业这样，拥有如此众多的历史性数据和结构化数据，机器学习技术则因此找到了最佳展示舞台。早在八十年代，投资银行就已经开始使用机器学习技术，在AI技术方面可以说是领风气之先。现在，投资者和基金经理仰赖AI驱动的市场分析做出投资决策，这也正为科技公司开发全新金融交易数字方案打开了方便之门。由AI驱动的解决方案鳞次栉比层出不穷，诸如利用模式匹配和深度学习技术的种种股票排行榜，这类定制投资策略的应用也仅仅是当今市场中上出现的众多创新产品中的一小部分。但是，技术虽然先进，类似由人工智能替代交易中的人工交互这样的想法并不现实。尽管资本交易中指标性定量投资占据了大半江山，但近期糟糕的市场表现暴露出模式匹配模型中存在不足，而这一模型确实是投资者做出决策的基础。这一情况表明，无论算法有多玄妙多炫酷，计算机仍然无法替代人类意识工作，特别是在金融市场机遇稍纵即逝的大背景下，抓住则生，错过则亡。**用于安全与合规目的的数据分析**在管理海量数据过程中，合规与安全成为金融组织不得不面对的两大最严峻挑战。随着数据的指数式增长以及合法访问的不断增多，使得内部数据泄露的可能性大为增长，仅仅对网络边缘进行保护使其免受攻击已经不够。此外，银行将大量数据存储在混合及多云环境中，这为网络犯罪分子染指重要资产提供了更多机会。总而言之，同样一组数据，既能为实现业务增长提供机会，也能为金融机构带来安全风险。数据分析在帮助公司应对挑战的过程中起到了定海神针的作用。这是因为机器学习技术可以发现异常用户行为，进而检测到可疑活动，从而能够最大程度地消除欺诈、洗钱以及数据泄露所带来的风险。同样，数据分析技术也可用于包括数据审计流程在内的合规活动中，通过减少人工参与减轻合规管理者的压力。**前瞻**鉴于机器学习及预测性分析技术仍将是金融服务行业倚重的技术，这些金融企业生成并存储的数据将呈爆炸性增长趋势。对这些数据、敏感信息资产以及业务运营本身的保护变得更具挑战。对于面临这些问题的金融服务公司来讲，只有采用新型安全技术才可以消除其在安全与合规方面所遇到的风险。**Imperva为您解忧****Imperva Data Security** 利用机器学习与数据分析技术，识别可疑数据访问并对威胁按优先级排序，助力企业消除来自内部和外部的安全风险。Imperva 针对典型用户访问数据表格和文件创建了基线，在异常行为转变为实际威胁之前，及时检测并发出预警。并且能够在数以百万计的报警中甄别出最为紧急的威胁，确保安全团队始终能够聚焦处理最具风险的事件。Imperva Data Activity Monitoring (DAM) 可跨多个存储站点、跨本地和云端，实现对整个企业交易数据库的可视化；对每个数据库进行细粒度审计记录，知晓“谁、什么事、什么时候、什么地方以及如何发生”等元素。** Imperva Application Security**提供全栈式应用安全解决方案，可对网页及API提供保护，确保系统正常运行及对用户的高可用性，避免运营中发生宕机状况。籍由集成的Cloud WAF, CDN, DDoS保护以及攻击分析技术，再加上Bot Management和运行时应用自防护方案 (Runtime Application Self-Protection, RASP), 您的业务将会通过内部以及网络边缘得到深度保护。如欲了解更多有关Imperva如何保护您的业务等相关内容，敬请浏览Imperva官方网站**www.imperva.com.**
