# CVE-2019-11043 PHP漏洞预警

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTYyOTUyOA==&mid=2247484628&idx=1&sn=ca22bea3aa5f624c3cb3e6ebaa3308aa&chksm=ea774c63dd00c575a8265e45037d4f39f70a5b3aacbdcd6fa25d99e8f31e8bf57d74c68008db&scene=126&sessionid=1681365361#rd](http://mp.weixin.qq.com/s?__biz=MzI1OTYyOTUyOA==&mid=2247484628&idx=1&sn=ca22bea3aa5f624c3cb3e6ebaa3308aa&chksm=ea774c63dd00c575a8265e45037d4f39f70a5b3aacbdcd6fa25d99e8f31e8bf57d74c68008db&scene=126&sessionid=1681365361#rd)

**0x00 背景**

10月22日，安全研究员在tweet上公布了一个PHP在Nginx上的远程命令执行漏洞(RCE)，具体PoC详见https://github.com/neex/phuip-fpizdam。

  

**0x01 漏洞影响范围**

·      PHP 7.3.11

·      PHP 7.2.24

·      PHP 7.1.33

  

**0x02 Imperva解决方案**

此攻击利用在URL(%0a)中插入非法的字节编码后进行漏洞利用。因此，此漏洞通过Imperva的默认策略进行防护。
