# FastJson远程命令执行漏洞威胁预警!

0x00 概述

Fastjson是阿里巴巴的开源JSON解析库，它可以解析JSON格式的字符串，支持将Java Bean序列化为JSON字符串，也可以从JSON字符串反序列化到JavaBean。近日曝光了FastJson远程命令执行高危漏洞利用代码已被公开，近期可能出现**利用该漏洞的批量攻击行为，**攻击者构造恶意代码可绕过FastJson的AutoType机制造成远程执行代码取得系统控制权。该漏洞影响FastJson 1.2.48以前的版本，官方已发布了修复版本。

0x01 威胁详情

本次远程执行代码漏洞的利用方式是通过使用 @type 指定java.lang.Class绕过AutoType机制。当FastJson使用默认的JSON解析器DefaultJSONParser对 @type 进行解析时，攻击者可以构造恶意代码通过java.lang.Class加载类直接注入到mappings，进而引发远程执行代码（如下图所示）。![](../Images/f604ae7001abf9425f761adb8b494d0c.png)

0x02 影响范围

FastJson 1.2.48以前的版本存在此漏洞 。

0x03 加固建议

建议将FastJson升级到不受影响的版本，如1.2.XX的版本升级到1.2.58。下载地址：http://repo1.maven.org/maven2/com/alibaba/fastjson/
