# Oracle WebLogic 漏洞安全公告

0x00 背景

*   2019年4月17日，国家信息安全漏洞共享平台(CNVD)收录了由中国民生银行股份有限公司发现的Oracle WebLogic wls9-async反序列化远程执行漏洞(CNVD-C-2019-48814)，该漏洞可使攻击者在未授权的情况下远程执行命令。目前，Oracle官方尚无相关补丁发布，漏洞细节未并公开。
    
*   国资委在4月21日追加通报，要求企业核查关于WebLogic XMLDecoder(CVE-2017-10271)漏洞的防御情况。
    

  

0x01 漏洞影响范围及说明

*   **CNVD-C-2019-48814**
    

o  WebLogic 10.X

o  WebLogic 12.1.3

上述版本的WebLogic中默认包含的wls9\_async\_response war包，为WebLogic Server提供异步通讯服务。由于该WAR包在反序列化处理输入信息时存在缺陷，攻击者可以发送精心构造的恶意HTTP 请求，获得目标服务器的权限，在未授权的情况下远程执行命令。

*   **CVE-2017-10271**
    

o  10.3.6.0.0

o  12.1.3.0.0

o  12.2.1.1.0

o  12.2.1.2.0

Oracle Fusion Middleware中的Oracle WebLogic Server组件的WLS Security子组件存在安全漏洞。使用精心构造的xml数据可能造成任意代码执行，攻击者只需要发送精心构造的HTTP 请求，就可以拿到目标服务器的权限。攻击者可利用该漏洞控制组件，影响数据的可用性、保密性和完整性。

  

0x02 漏洞处理建议

*   ** CNVD-C-2019-48814**
    

1.  删除wls9\_async\_response包，并重启WebLogic服务
    
2.  通过访问策略控制禁止URL访问路径为/\_async/的访问
    

*   ** CVE-2017-10271**
    

1.  升级Oracle 10月份补丁
    
2.  通过访问策略控制禁止URL访问路径未/wls-wsat/的访问
    

 

0x03 Imperva解决方案

*   **CNVD-C-2019-48814**
    

由于Oracle官方并未公布正式的安全公告及PoC内容，故Imperva暂时未有相关的ADC特征库更新，但是用户可以借助Imperva强大的自定义安全策略灵活的对此漏洞进行拦截。

  

1.   创建自定义策略

在Policies-Security下新建自定义类型未Web Application Custom的策略。

2.   配置策略规则

·    将Action动作选择未Block模式

·    选择HTTP Request URL条件，同时将/\_async/设置为条件值。

![](../Images/8c6b1266370554984097073e3cdcdd97.png)

3. 关联相关站点

通过Apply To选项卡将该策略有针对性的应用到需要防御的应用站点上即可。

![](../Images/bb5d61be47d069f67f00fd4f5e6a4203.png)

 注：Imperva Web Application Custom自定义策略提供43种匹配条件，用户可以根据自己企业实际情况，灵活组合使用，从而应对企业对安全防护的不同需求。

 

*   **CVE-2017-10271**
    

该漏洞拦截策略已在Imperva官方的ADC特征库中，请各位用户及时ADC即可。
