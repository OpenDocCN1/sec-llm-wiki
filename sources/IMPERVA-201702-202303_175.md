# Imperva 应用安全家族加入重要成员

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTYyOTUyOA==&mid=2247484441&idx=1&sn=497c723d5096df741b98090e374483aa&chksm=ea774caedd00c5b8870c824a5f525f8cfc9043d6b2334b8765a749a4c7c1439253f054195740&scene=126&sessionid=1681365371#rd](http://mp.weixin.qq.com/s?__biz=MzI1OTYyOTUyOA==&mid=2247484441&idx=1&sn=497c723d5096df741b98090e374483aa&chksm=ea774caedd00c5b8870c824a5f525f8cfc9043d6b2334b8765a749a4c7c1439253f054195740&scene=126&sessionid=1681365371#rd)

2018年Imperva收购了全球应用程序实时自我保护（RASP）领域绝对领导地位的解决方案提供商Prevoty。Prevoty的旗舰产品 Autonomous Application Protection是目前市场上最成熟的，经过市场验证的RASP解决方案（Prevoty获得了Cybersecurity Excellence Awards银奖）。今后Imperva将与Prevoty共同打造一个应用与数据安全的综合平台。

更重要的是，本次收购亦将为客户带来巨大利益。Imperva与Autonomous Application Protection的结合将使客户能够进一步了解其应用的活动情况以及用户对敏感信息的访问情况，进而使客户对其业务资产情况更为清晰明了，能够更深入的了解并降低其边缘、应用及数据库的安全风险。

通过产品的深度融合，两家安全创新团队亦将合并，形成强强联手，这将从根本上改变整个行业对应用程序和数据安全性的固有思路。在未来的展望中，我们将提升承载系统的运行数据可视化，将无数个单点数据转化为有价值的情报以及可操作的任务，智能地、自动化保护业务。Prevoty刚刚发布了两个实现这些目标的新功能：网络活动保护和弱密码保护。

Network Activity Protection功能帮助企业实现源自其应用、API与微服务的非法出站网络通信的监控与保护，且这一直是正在进行数字化转型企业的监控与安全保护盲点。在此功能的支持下，企业能够清楚看到各端点的应用通讯情况。

新发布的Weak Cryptography Protection功能，则支持使用特定的weak hashing算法（包括SHA-1、MD5）与加密密码（包括AES、3DES/DES、RC4）的监控与保护。在Autonomous Application Protection功能支持下，各应用可监控并强迫其遵守加密规定。

Imperva是保护数据与应用安全，抵御网络犯罪的先锋企业。部署Imperva产品使客户无需再在创新功能与安全保护之间抉择。更智能、更简洁的解决方案是应用与数据安全的未来趋势，Imperva会一直坚守并站在行业最前端。
