据悉去年上半年HTTPS已几乎达到临界点，这表示已有一多半的网络流量都被加密了。

流量加密的好处不用多讲，通过web服务器与客户端（浏览器）之间的相互认证，并且加密他们之间的信息交互，是对web安全保护最基本的功能，但还存在其它问题：

*   **如何知道自己的流量是否被充分加密？**
    
*   **如何才能让企业的HTTPS配置更为缜密？**
    
*   **只部署SSL是否足够保证数据安全？**
    

这里主要介绍提高企业网络服务器SSL/TLS部署安全性的方法，但最重要的是如何利用Imperva SecureSphere Web Application Firewall(WAF)实现所需的SSL Labs A+级防护。  

  

**提高SSL防护**

正确的部署HTTPS是一个较为枯燥的过程，有时对于经验丰富的安全团队来说也是较为棘手的工作，但只要能正确部署，就再不用担心不安全了。

现在有许多团队能指导企业进行SSL部署，并提供相关工具帮助评估企业SSL/TLS部署的安全水平。例如：OWASP Foundation制订了一组传输层防护参考手册，并为HTTPS实施提供了部分最佳实践指南。

无独有偶，近期涌现了大量的免费诊断工具，帮助企业对其SSL网络服务器配置与性能进行分析。部分工具可以提供基础信息并对增强HTTPS配置提供建议。另外一些则具有幕后优化功能，为企业的HTTPS配置提供更为深入的分析，包括SSL漏洞状态报告等。但真正能够成为评估SSL部署行业标准的工具是SSLLabs by Qualys。相信只要是使用过的用户都会承认这款工具是目前最具综合性与深入的分析工具。下面介绍一下该工具的工作方法。

 

**SSL Labs是如何进行web服务器测试的？**

SSL Labs会根据其SSL服务器评级准则对企业用户的网站进行评级。

简单的说就是，SSL Labs 主要关注两个方面：

*   **证书—** 验证其有效性与受信性；
    
*   **配置—** 检查服务器配置，并将其分为三类：
    
    **协议支持：**检查可用的SSL协议版本，即：下列五个版本中都支持哪些：SSL 2、SSL 3、TLS 1.0、TLS 1.1以及TLS 1.2；
    

**密钥交换支持：**检查密钥交换参数优势 ；

**加密算法支持：**检查所支持的加密算法套组，同时按优先服务器顺序从强到弱地列出加密算法。

SSL Labs将各分类评分综合得出总分，并将其转换为对应的等级。

最后，SSL Labs还对无法通过数值评估来表现的其它服务器配置项进行检查，确定是否有其它特征，如支持：TLS\_FALLBACK\_SCSV、OCSP stapling以及HSTS。注意，即使评分没有降级，但永远也拿不到A+的分数。

| 数值评估 || 等级 |
| --- | --- |
| 分数 >= 80 || A |
| 分数>= 65 || B |
| 分数>= 50 || C |
| 分数>= 35 || D |
| 分数>= 20 || E |
| 分数< 20 || F |

**SSL Labs –只是一个安全相关的工具？**

Imperva的许多用户及安全研究机构都曾无数次的就此产品及其重要性进行过讨论。最初大家都置疑SSL Labs的测试方法与有效性，但现在已成为了标配方法。是什么原因呢？

最初安全管理员都习惯用某种工具及其评分来了解自己的SSL/TLS部署的安全性，以及该如何避免被攻击或存在易受到SSL/TLS攻击的漏洞，如：Heartbleed、POODLE、Freak等，这些攻击会很容易导致后期遭受直接财务损失。这些功能都只针对安全性，并没有针对安全违规的功能检查，因此，现在的产品已开始具备安全违规检查功能。

企业用户开始意识到其网站等级以及SSL/TLS部署已成为众人皆知。同时，有越来越多的用户使用SSL Labs作为了解各自网站安全性的指导工具。这是一项重大变革。因为如果评级差，则可能对网站信誉造成负面影响（被用户认为不安全），并可能带来间接损失。

如果你在一个电商网站购物，发现该网站的网站安全评级被SSLLabs评为负级，那么你是否还能安心购物？那么你是否要再斟酌一下还要不要在该网站购物下订单呢？

**部署WAF获得SSL Labs A+评级**

既然了解了SSL Labs的重要性及其工作性质，建议为网站部署web application firewall（WAF），帮助企业实现A+评级。

只有部署了WAF，才能帮助企业尽快实现SSL Labs A+评级。部署WAF非常简单，因为不需要更改后台服务器，同时通过SSL配置管理工具，使SSL配置也变的简单起来。

  

**WAF的部署非常有用，特别是当用户有下列需求时：**

提高应用安全：如已获得了较好的SSL Labs评分，但希望在不会影响SSL Labs评分的前提下，能够扩大应用安全范围。

提高SSL Labs评级：如web服务器评分并不太理想，部署标准WAF可帮助提高安全评级。

 

**如何利用SecureSphere WAF取得SSL Labs A+评级？**

SecureSphere WAF新发布的13.0版产品，可直接帮助用户取得完美的SSL Labs A+评级。而该产品搭配缺省配置模板，方便用户轻松配置。

需要注意的是用户还需部署反向代理模式，即：透明反向代理或内核反向代理。只需要下面两个简单的步骤即可完成：

**1) ****查看缺省SSL设置**

在“Main”工作页面下，选择Setup > Global Object。然后在Scope Selection条下，选择SSL Settings并选择“SSL Labs A+ RP Server SideSSL Settings”模板，然后查看配置，并确保可接受此类设置。![](../Images/e89917e6d2a54506ef37414815f7e08a.png)*图2：在SecureSphere WAF中，设置自定义SSL设置或使用缺省设置，实现SSL Labs A+评级。*

 

**2) ****将设置应用到企业的各应用中**

在Main工作页面下，选择Setup > Sites。在Sites Tree栏中，选择需要保护的各项服务。在Reverse Proxy标签下，选择反向代理规则（KRP 或 TRP）下的“SSL Labs A+ RP Server Side SSLSettings”，然后点击Save按钮。![](../Images/2866eb28f59af2cce7b52b52fe7c27e3.png)

*图3：应用SecureSphere WAF设置后完成配置*

**只部署SSL就够了吗？**

不是的。所有的安全专家都承认仅部署SSL是不够的，因为SSL只是安全的一个方面。SSL/TLS仅用于确保安全连接，并不能保护应用免受任何类型的攻击。现在的攻击多种多样，如：技术攻击：SQL injections以及cross-site scripting，或商业逻辑攻击，如：site scraping及account takeover。

部署Imperva SecureSphere WebApplication Firewall后，可保护企业用户部署在云或预置方案中web应用的安全。同时还可帮助防止因企业用户违规而造成的连带损失、成本或品牌损害。
