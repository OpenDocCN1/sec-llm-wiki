# 2018 网络威胁防御报告： IT 安全发展趋势

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTYyOTUyOA==&mid=2247483881&idx=1&sn=4c3a5b78d98614c28847cc420648e3f0&chksm=ea77495edd00c048b437c8454b070442399cba4345975992913b64ab8de93d0382bd65403d76&scene=126&sessionid=1681365387#rd](http://mp.weixin.qq.com/s?__biz=MzI1OTYyOTUyOA==&mid=2247483881&idx=1&sn=4c3a5b78d98614c28847cc420648e3f0&chksm=ea77495edd00c048b437c8454b070442399cba4345975992913b64ab8de93d0382bd65403d76&scene=126&sessionid=1681365387#rd)

企业用户的安全困扰是什么？IT 安全专家们称他们最担心的是：恶意软件、鱼叉式网络钓鱼、移动设备保护、员工安全意识，同时他们还需要新技术来检测那些可绕过基于传统签名防御机制的各类威胁。

![](../Images/d0dc49f4e8159a5056ce5bf1df32e255.png)

  

过去几年里，网络攻击层出不穷。目前的数据显示企业被攻击的成功率呈逐年下降趋势，已从 79.2% 下降至 77.2%。![](../Images/17eb981b5a6ab27e86b8648219f999a0.png)

  

尽管如此，安全团队仍需克服众多困难和挑战。首先是缺乏经验丰富的 IT 人员。此外，员工安全意识较低，和数据崩溃问题日益严重。![](../Images/7f101a33c67f18420262f0b56f33d9ce.png)

  

由于云部署和云交付为网络安全带来了巨大挑战，安全格局也在不断变化。

例如，为混合云环境部署以下安全解决方案：

46% 的 DoS 和 DDoS 保护

47% 的特权帐户或访问管理

44% 的安全信息和事件管理

45% 的 Web 应用程序防火墙

![](../Images/b6534bb993ee5a778ab3ed266b7b149b.png)

  

企业愿意投资于用户和实体行为分析 (UEBA) 技术的三大动机包括：能够检测帐户劫持情况、特权访问权限滥用情况和防范内部威胁。

![](../Images/6353ccee8d8189b7545f8c8bea2b76ed.png)

  

企业安全团队开始意识到过去的防御机制无法再应对当今的威胁了。需要持续努力与投资部署综合性的安全解决方案。

  

尽管存在 WAF、数据库防火墙和数据加密等安全部署，要想保持数据安全，线上企业仍然需要数据安全保护帮助。

  

大部分企业希望能够提高威胁防御 (58%) 和威胁检测  (51%) 能力。另外，企业还愿意部署其它安全措施，如：提高威胁检测能力、减少非法流量、以及增加使用策略的执行力度。

> **完整的解决方案**

由于数据和应用程序漏洞的增多，IT 安全领域也在不断发展进步。安全团队必需要领先威胁一步，防患于未然。早期检测、流量分析、取证和可自定义策略等可以扭转企业的安全状况，即：从被动响应改为主动应对。
