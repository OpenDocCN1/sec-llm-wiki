# 想象无穷 远景无限

        2017年Imperva大中华区合作伙伴大会伴随着极具成都特色的川剧变脸表演圆满落幕。本次大会，来自大中华区华北、华东、华南、香港、台湾及蒙古等各地区的渠道商、代理商、合作伙伴和客户们齐聚四川成都，共同探讨展望未来合作的蓝图。此次大会是Imperva与中国合作伙伴之间最重要的一次对话， Imperva高层管理团队亮相与合作伙伴分享最佳实践、未来战略及合作基础等重要议题，为所有与会者带来借鉴和启迪。机遇当前，惟敏捷者进，惟远见者胜，此次大会的成功举办，预示着Imperva将携手每一位合作伙伴抢占先机，远景无限！  

  

![](../Images/2d32fe5da628944926264acd0a3a3e2a.png)

本次Imperva大中华区合作伙伴大会，Imperva带来了网页应用防火墙、数据库安全方案、未来信息安全趋势分析等诸多内容的讲解，不仅向远道而来的合作伙伴们详细阐述了Imperva的产品优势，更传递给了合作伙伴通力合作、共赢为先的基调，使更多合作伙伴及客户对Imperva更具信心。每一个演讲，都来自Imperva高层以及技术、产品部门大佬们的精心准备，通过这些信息的传递，使合作伙伴获取了更多有效信息、更多干货，从而达到习练、创造、进而分享的过程，使更大的市场份额能够认同Imperva的产品。

![](../Images/5a12ef32573d3bceef20ed3199472573.png)

同时，来自Imperva客户的体验讲解也十分具有亮点，东风悦达、华为、浦发银行作为国内的优秀企业，对Imperva的产品特点，应用领域都做了很深刻的剖析，这不仅代表了Imperva在大中华区受到广泛认可的一个缩影，更能够为同行业的其他企业明确了需求，给了Imperva和合作伙伴们极大的信心。

![](../Images/9c15d198ab7854335573933b26389e67.png)

在晚宴上，大中华区助理副总裁王曦瀚先生代表Imperva向全体来宾致以了诚挚的谢意，并向所有合作伙伴保证，Imperva将在2017年带领大家再创辉煌。同时，来自成都的表演艺术家们奉献了民乐合奏、川剧变脸、振奋人心的鼓舞、长嘴茶壶表演等丰富的极具地方特色的节目，受到了来宾们的一致赞许。

2017年Imperva大中华区合作伙伴大会已圆满落幕，Imperva与合作伙伴们将在2017年迸发出更强大的能量，在中国市场共创辉煌，带来一番更大的作为！
