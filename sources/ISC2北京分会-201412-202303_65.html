2015年3月26日晚19点30分，中关村某会议室已经座无虚席，足以见小伙伴们对Dustin和工控安全的热情！




Dustin也不负众望，给大家带来了一场丰盛的知识饕餮盛宴！


首先，Dustin介绍了工业系统的发展及趋势，我们幸运的正在历经第四次工业革命：


然后，Dustin从基本概念开始剖析，从技术视角和功能视角分别告诉大家什么是工业控制系统ICS：






并详细讲解了ICS的各种控制组件，例如：


SCADA(Supervisory Control And Data Acquisition)数据采集与监控系统；

Control Server 控制服务器；

RTU(Remote Terminal Unit)远程终端装置；

IED(Intelligent Electronic Device)智能电子设备；

PLC(Programmable Logic Controller)可编程逻辑控制器；

HMI(Human Machine Interface)人机界面；

Data Historian历史数据库；

I/O Server输入/输出服务器；


网络组件，例如：

Fieldbus Network现场总线网络；

Control Network控制网络；

Firewall工业防火墙；

Modem调制解调器；

Remote Access Point远程接入点；


具备了这些基础知识，Dustin开始讲述了ICS的架构，看下图：




基本概念及架构都有了，当然要寻找可攻击点，进行脆弱点分析了，Dustin介绍了从关键基础设施攻击到信息物理系统CPS的攻击。现有脆弱点可以分为两大类，即工业协议和第三方组件问题。


小伙伴们提出了疑问：那么这么多年工控系统的发展到底经历了多少攻击呢？Dustin给大家带来了漏洞发展态势分析，历年工控系统漏洞数在2012年达到顶峰，多达175个！而西门子系统由于广泛的普及率成为了重灾区。


好吧，那么刚刚提到的工业协议有那些脆弱性呢？请看下图：




Dustin从Modbus、Ethernet/IP到西门子S7都进行了分析阐述，并进行了渗透案例剖析分享。


巧的是plcscan.org的博主Z-One同学也来到了现场，Dustin还分享了博主录制的渗透攻击视频！


那这些攻击可以造成多大的影响啊？Dustin进行了影响范围分析，并顺手做了ZoomEye的广告，大家有兴趣可以登录http://ics.zoomeye.org 查看一下哦！


现在看看国家层面吧，我国对于工控安全机制的管理尚有待发展。美国着实走在了前面，不仅颁布了ICS安全管理框架并由国土安全部牵头和推动，还部署了安全防护及威慑方案！




是不是大开眼界呢？会议结束后，大家意犹未尽，交流讨论很久才离开。




本次活动由(ISC)²北京分会理事长兼财务长卢佐华倾力安排，感谢Dustin同学的精彩演讲，感谢费曼友情提供场地，感谢Z-One同学、各位小伙伴的热情参与！
