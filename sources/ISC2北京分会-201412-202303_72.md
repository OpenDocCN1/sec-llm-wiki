# (ISC)²北京分会于2014年11月成立（包含大量图片建议WIFI下查看）

很多人都要问，(ISC)²（读作: ISC-squared）是个什么组织，在北京搞个分会干嘛？

  

先从CISSP说起，这是信息安全从业人员的一个认证，全称是Certified Information Systems Security Professional，分为十大知识域，基本覆盖了信息安全的各个方面，是信息安全认证的“金牌标准”。该证书是美国的一个非盈利教育组织(ISC)²推出的，全称International Information Systems Security Certification Consortium，中文译名“国际信息系统安全认证联盟”。目前全球有超过10万会员，分布在160多个国家。

  

自1994开始20+年来，CISSP证书经久不衰，想进外企做信息安全，如果简历上没有CISSP字样，就可能不会出现在人力资源在网上搜简历的结果里。

  

随着信息技术的发展，新技术的引入，安全就要重新被思考，IT Security Guru网站的编辑Dan Raywood写了一篇文章提到：作为业界的一个问题，对于(ISC)²来说，会员有些中年化（middle aged）和过气（out of touch）。

  

英国有三个兄弟拍了一段视频来反驳，标题 I’m a C I Double S P，获得了2014年黑客奥斯卡最佳歌曲提名，展现了一个CISSP帮公司解决信息安全问题，然后一堆美女回家和他一起跳舞的奢靡场面。他们回应道：持有CISSP证书的人是有不同的背景和技能的，没有过时之说。

  

(ISC)²董事会主席Wim Remes在近期的一次访谈中被问到“证书对信息安全人员有多重要“？他的答复是：“我不太认同把证书作为工作岗位的一个要求。证书只是验证了知识和经验，但是没有证书的很多人同样也是称职的。证书给个人带来的价值远远超过在工作时可以多打一个勾，能够接触到信息安全社区才是成为(ISC)²会员的最大驱动力。”

  

关于问题“目前会员面临最大的信息安全方面的挑战是什么？”，Wim回答：“最常见的挑战是要把安全变得和业务相关。他们需要放弃纯技术讨论，能够在管理层的水平上沟通和讨论安全问题。目前大家的专注点都在风险管理。在2015年，CISSP的知识域会增加更多的新知识点，包括云计算、物联网和渗透测试。”

  

好了，前面摘引了业界的顾虑、响应，以及官方的答复。对于中国区会员，能做的事情就来了，那就是安全社区的参与，说白了就是圈子。(ISC)²有全球Chapter（分会）计划，目前韩国的最大，有5500会员，埃塞俄比亚最小，只有6名会员。我们认为，非洲的6个兄弟，他们如果能定期一起出来吃个饭，聊聊各自的工作和生活，也是很有意思的。

  

所以我们牵头成立(ISC)²北京分会的目的很简单，前提是证书并不意味着什么，主要是证书背后的你，不管是(ISC)²会员还是非会员，都可以加入，拓展在安全圈的人脉，一起交流、分享、互相学习，提升大家的职业发展。

  

(ISC)²北京分会在2014年10月24日获得(ISC)²总部批准，于2014年11月1日在北京邮电大学召开了成立大会，出席会员所在的公司包括微软、惠普、联想、华为、普华永道、中国电信、邮储银行、绿盟科技、软通动力、网御星云、凯迪新能源、CESI、NITSC、中国信息安全测评中心、IEESEC、Atsec、NARI、CyberArk、Rickfit、北京数字认证中心、谷安、希尔达、群环域、思睿嘉得、旭方道信等。
