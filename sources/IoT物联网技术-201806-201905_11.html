随着人工智能（AI）和物联网（IoT）技术的逐渐成熟，应用场景也越来越广泛，已经深入到我们生活中方方面面。


基于数据精细化运营的今天，每个实体店都想了解进店客流情况。


通过树莓派和摄像头硬件组合，结合人脸识别技术，我们可以轻松的统计和分析每天进店人流量，性别，年龄构成等。


整套技术方案无需购买服务器，全部基于阿里云技术实现，包含如下技能：

  • 树莓派 RaspberryPi 系统安装；

  • 摄像头硬件的开发（Python）；

  • 阿里云人脸识别 API 使用；

  • 阿里云IoT物联网平台的接入；

  • 阿里云数据存储和可视化开发能力。

注：由于硬件限制，仅限开发实战，非直接于商业的方案。
