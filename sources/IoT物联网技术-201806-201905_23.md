# 天猫双11 x 阿里云IoT海淘溯源计划

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTA4MzA0MA==&mid=2454919976&idx=1&sn=9611602bd7c39b3853ae55fe8a23a0bc&chksm=b16756678610df7197d7e6e2a29b95529ffb1521c3056d56841d8cfa92789acc67094b6268bc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5OTA4MzA0MA==&mid=2454919976&idx=1&sn=9611602bd7c39b3853ae55fe8a23a0bc&chksm=b16756678610df7197d7e6e2a29b95529ffb1521c3056d56841d8cfa92789acc67094b6268bc&scene=27#wechat_redirect)

从全球购买最优质的“宝贝”已经司空见惯，但海淘的距离远、过程长，要经历远洋运输、海关等一系列环节。在这个过程中谁来守护我们的商品呢？谁能确保她被轻拿轻放，不被摔到碰到，没有被淋湿，没有被暴晒呢？

 

科技的力量，竟然仅用一张小小的黑色卡片，就解决了我们上述的所有问题。这就是今年双11阿里巴巴放出的一个大招，***“IoT全球原产地溯源计划”***。

  

![](../Images/ab35f43ea17865a860e26e3fb9a193d4.png)

  

让国内消费者购买进口产品更放心，今年双11期间，天猫国际，联合菜鸟和阿里云将率先实现基于IoT技术、区块链技术的全球原产地溯源升级，***这在全球也尚属首例突破。***国内消费者收到商品后，通过手机淘宝扫一扫IoT货品追踪溯源码，即可查看进口商品完整的商品溯源实时信息。

  

![](../Images/1ae37645dfff50a0d92186187149aeef.png)

  

  

***安全溯源***

  

天猫国际携手中国检验认证集团CCIC，打造 “大数据+海外溯源验证”的智能溯源体系，在海外货源地，CCIC对海外商品生产企业进行多方位审核调查，对海外商品实施流通验证，对海外商品启运进行实地监装。同时借助IoT全球追踪技术，确保每一单商品都能看到大洋彼岸的原产地、货源地，从源头就真实可信赖。

  

![](../Images/b97a5f074238fb6f923839a096bfb25b.png)

  

  

***贴身守护***

  

阿里云IoT借助GPS+LBS技术，实现了对货物实时定位。从商家海外工厂提货开始，海外配送、港口发运、干线承运、入境清关、仓库上架、国内清关、国内配送等系列环节都将被菜鸟物流全程记录，并实时同步至溯源平台，是对过往全球原产地溯源只能看到静态信息的升级版。

 

依托于阿里区块链技术，通过双重认证和双向加密通道，给每个跨境进口商品打上唯一的“身份证”，全程保障鉴权安全和通道安全，为您购买的商品提供分秒不离左右的守护。

  

![](../Images/c60d3e1d093da9267baac2fce3211882.png)

  

  

***IoT时代，未来已来***

  

借助强大的阿里云计算平台能力，可以支撑百万级货物同时运输。未来，温度、湿度、承受压力等更多信息会被感知，商品也会得到更悉心的照料。

 

![](../Images/75408ac14e904c8460e1e846c42b134f.png)

  

IoT技术，正被应用于双11的各个领域，2018年可以称之为***双11的IoT元年***。借助科技的力量，让购买更放心，让消费更舒心。
