# TLink 工业物联网平台，支持云组态、实时计算、微信告警

**TLink 工业物联网平台**

TLink 工业物联网云平台是一个免费开放的设备连接平台，主要应用在工业领域，提供了**丰富的联网方式**，帮助企业运营者将 IoT 设备连接至云端，轻松实现对设备进行实时监管，并为用户快速实现物联网应用服务。

![](../Images/d023a03bae0e45b61b0063b5e8a98c9e.png)

  

部分已适配TLink 物联网平台的DTU设备和传感器。  

![](../Images/9cd4b06c58134f71e1304618e0e8e626.png)

  

**TLink 物联网平台使用**

  

**▌设备管理**

TLink物联网平台提供设备管理，设备分组，运行时数据监控，历史数据查询等功能。

![](../Images/6dbd25e9bee110df583ae121508c3906.png)

  

添加新设备到TLink物联网平台，配置链接协议，地理位置等信息。

![](../Images/4739e6db9cd21129912d3575a52b8fb4.png)

  

**▌实时计算流程编排**

实时计算是一种基于流的编程，它是一种将应用程序的行为描述为“节点”的一种方式。每个节点都有都有明确的业务功能，通过从流中的前一个节点接收消息来触发节点，并对该数据执行某些计算，然后可以将消息发送到流中的下一个节点。实时计算引擎负责节点之间的数据流。

  

TLink物联网平台提供了一个基于浏览器的**流编辑器**，可轻松使用面板中的各种节点将流连接在一起，形成一个可视化的计算模型。

![](../Images/f9d67a8d04654566957a6696ae722698.png)

  

**▌设备地图**

TLink物联网平台提供设备地图功能，将接入设备可视化展示在地图中。

![](../Images/3414453824c0462f6b5f82be6c82b001.png)

  

**▌触发器**

触发器功能依赖设备实时数据上报，也就是当设备发送数据到服务器的时才会判断触发器条件，满足条件就会触发。触发器有两个功能：**推送报警消息**（微信、短信、语音、邮件）、**转发数据控制设备**。

![](../Images/edb0431c1388443928eba6aee3f7d2a0.png)

  

**▌定时任务**

定时任务是指设定一个时间规则，执行转发设备数据的任务。你可以设置转发固定的数据，也可以转发其他传感器的数据，从而实现在不同协议的设备之间中转数据，平台会对数据进行协议封装再进行转发。

![](../Images/722e013272d4f4bc05a4bdb586d3266f.png)

  

**▌移动App**

TLink物联网平台提供标准化的Android和iOS应用。

  

![](../Images/e58a1a9e4487c10f69e5e026e2b1d3d4.png)

  

**▌云组态**

云组态和TLink平台的设备数据无缝打通，可以帮助你采用所见即所得的方式快速搭建物联网场景所需的设备控制面板、设备监控屏幕等简单的物联网应用，而这个过程甚至不需要你写一行代码。

  

![](../Images/dafa1ecc32367c2fc270583ea4a41d17.png)
