# 基于 IoT + 5G技术搭建 10万台电梯智能化运维物联网平台

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTA4MzA0MA==&mid=2454930204&idx=1&sn=19cc7f7af8af2fd56c72c89da8ee8602&chksm=b1670e5386108745f25c0c64da21a3ed106f2e00720af5608b25c97eced0ed048c1254db7159&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5OTA4MzA0MA==&mid=2454930204&idx=1&sn=19cc7f7af8af2fd56c72c89da8ee8602&chksm=b1670e5386108745f25c0c64da21a3ed106f2e00720af5608b25c97eced0ed048c1254db7159&scene=27#wechat_redirect)

  

随着近20年我国房地产的蓬勃发展，**电梯**已经成为人们现代生活中不可或缺的一部分，也是城市化建设中重要的建筑设备之一。据中国电梯行业协会统计，截至2022年底，我国电梯保有量为**990万台，电梯运营健康度，减少事故发生变得十分重要。**国内有接近约**1.5万多**家电梯安装维保单位，越来越多的企业进入智能化电梯运维保养的新赛道。

  

![](../Images/e5997d6e2e196e19187a7dc56c3c9844.png)

其中2018年，2019年，2020年，2021年，2022年电梯年产量累计值分别为71.9万台，117.3万台，128.2万台，154.5万台，145.4万台。

  

电梯智能维保对专业度要求较高，近年来**专业维保人员稀缺**；**设备联网难、联网成本高**等痛点；同时，市面上**维保质量参差不齐**，除了监管部门整治，维修环节也需要加强自身监管，这给运维和物业部门带来一定的成本压力。

  

物联网技术的发展给电梯等特种设备全时段运行监控带来了全新思路，包括**设备联网、数据上云，**电梯维保**数据协同监管、按需维保、电梯无感通行、扶梯AI行为识别等**技术手段，使得**覆盖全时段、低成本的监管**方案成为可能，从而满足政府安全监管、梯厂后市场服务、特种设备维保等多方需求。

  

![](../Images/105cefd0459c0c40d68c98fd5f6b3699.png)

  

  

**梯联网技术方向**

  

鲁邦通入局电梯物联网这个细分赛道时，全国乃至全球范围内存在电梯维保方面标准缺失，**电梯状态监测**和**预防式维护**两大核心功能处于缺位状态。鲁邦通选择组建技术团队深入电梯物联网领域攻坚技术难题：  
  
**首先，**因电梯安装位置在建筑物内，网络环境较为恶劣，鲁邦通以**5G+SD-WAN**的技术手段保障网络传输稳定，简化现场通信和组网的复杂度，降低配置及运维的难度；  
**第二，**在响应不同客户的定制化需求方面，鲁邦通以**自研aPaaS平台**为底座，通过低代码及平台能力支持多方协同的快速产品开发；  
**最后，**鲁邦通针对不同乘梯场景提供实际验证成熟的算法模型，让物业公司、维保公司、政府监管单位等可以精准监测电梯状态，并**识别电梯故障和乘梯异常行为**。**![](../Images/d096127af92ebe1ad32d3ae316509382.png)**借助鲁邦通提供的政府监管平台，当地部门在无需增加人手的情况下，可以监管全市的电梯安全运行，并顺利展开日常电梯维保监督工作。**维保公司、物业单位、政府监管部门**通过平台可以及时了解电梯状态，定期进行针对性保养以提高其使用效率，避免等到电梯故障时亡羊补牢。  
  

**产品架构**

  

鲁邦通在电梯行业提供基于**物联网、人工智能、云计算、大数据技术**，构建了连接电梯制造企业、物业单位、维保单位及政府监管部门的数字化协同治理生态体系。

  

经过与各大电梯制造企业多年合作，形成了丰富的电梯物联网产品体系，涵盖**电梯前装网关，电梯后装监控套件，AI安全场景监控**及**智能梯控设备**。

  

![](../Images/8b9b92be0833555ce7840cdd915e4812.png)

  

面向电梯安全治理，提供政府维保监管平台，联动维保企业和使用单位实现数据协同，通过数据在维保单位，使用单位及监管单位的流转，形成**多元共治**的电梯安全监管体系。

![](../Images/4fcf9f336459ad1baef5c78f14b07b11.png)

  

通过“物联网+电梯责任险+维保企业信用管理”助力**“按需维保”**新模式，赋能电梯维保市场运营数字化，推动电梯后市场服务变革。

**▌智能调度**

  

覆盖电话报警、一键求援、扫码报警、智能识别等多种报警方式，快速创建工单，多级别响应，支持调整合理调度，支撑救援有序开展。

![](../Images/3671ac0d801142c9225201995990ecf7.png)

  

**▌呼叫中心对接**

  

来电弹窗显示、来电历史及关联事件，根据业务人员忙闲情况，实现合理分派报警工单，提升处理效率。
