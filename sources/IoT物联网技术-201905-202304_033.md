# 国内 3 大物联网设备 OTA 服务选型指南

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTA4MzA0MA==&mid=2454929994&idx=1&sn=31d47a1bfbf785a6d13d69784ae65a5b&chksm=b1670f0586108613ed721a723ee0d5d7be09ef2acc3154bff441cdfcf788e6774f24ced5cc4c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5OTA4MzA0MA==&mid=2454929994&idx=1&sn=31d47a1bfbf785a6d13d69784ae65a5b&chksm=b1670f0586108613ed721a723ee0d5d7be09ef2acc3154bff441cdfcf788e6774f24ced5cc4c&scene=27#wechat_redirect)

  

![](../Images/4a9d6d3fb5f1ea1d483120b254a52dc3.png)

  

在物联网智能化如火如荼的进程中，数字化和智能化转型拥有庞大的市场空间，Strategy Analytics近期发布的研究报告《物联网蜂窝连接按空中接口和垂直行业划分》预测，到2025年物联网连接数将达到246亿设备。物联网这个大赛道激发了OTA平台的快速成长，使得越来越多企业关注到OTA这个细分领域，如何选择适合的OTA平台作为迈向智能化的第一步，是智能化进程是否顺利的关键。我们选取了IoT物联网行业内极具代表性的三个主流OTA 平台，就服务能力做横向对比。

  

  

***01******.***

**OTA 产品能力对比**

  

我们先来重温OTA的含义，OTA升级是指针对运行在硬件上的程序进行远程升级来完成软件版本的迭代，因此在OTA产品力对比中，产品针对不同操作系统，不同的硬件架构以及所需升级零部件的管理能力会各有侧重。

  

![](../Images/4ff2684a8662965545bb22c933e6427a.png)

  

**从服务内容比较：**

*   **百度**提供了专门的设备OTA服务的平台；
    
*   **阿里云**物联网云平台不止于OTA服务，更注重设备从接入到管理的流程，OTA只作为设备管理的一个子功能；
    
*   **艾拉比**提供专门的设备OTA服务平台，同时在设备侧也提供OTA方案服务。
    
      
    

由此看来，根据服务内容可以把OTA服务分为以互联网为代表的强生态物联网系统和独立的OTA专业平台两类。

  

**从产品定位和目标用户来看：**

*   **百度OTA**平台整合百度多项安全及云加速CDN技术帮助智能设备厂商提供高速、稳定、安全的物联网 OTA 解决方案；主要面向智能家居，可穿戴设备以及工业物联网提供OTA升级方案。  
    
*   **阿里云**物联网平台产品定位于为客户提供全托管的企业级实例服务，以设备管理和加速企业上云为主要目的帮助客户实现设备整个生命流程中的数据管理体系；平台主要服务于智能家居，消费电子及农业设备领域提供数据接入和管理能力。
    
*   **艾拉比**OTA平台更偏向升级的精细化管理，提供产品-零件关联，版本管理体系以及灵活的策略配置能力帮助各垂直行业设备建立OTA管理体系；服务涵盖汽车、家居、机器人、表计、安防、可穿戴以及工业等行业。
    

  

根据产品定位，三个平台的服务行业有差异也有重叠，用户按需选择需结合产品能力和商业模式做具体分析。

  

*   **百度OTA平台**设计独立专业的OTA平台，重点保障OTA升级的安全性以及流程的规范性。百度OTA平台目前提供Android和Linux设备的固件和应用升级，针对运行RTOS系统的物联网设备，可通过后续的版本迭代扩展。同步支持系统升级和应用升级。
    
      
    
    **核心功能：**百度OTA平台支持设备固件升级（FOTA）以及应用升级（SOTA），可对指定应用进行安装、更新、删除操作，兼顾设备安全性保护及功能优化迭代。自研在线差分技术配合设备端的升级能力可大幅度提升升级效率；灵活的下发条件配置，满足各类升级需求，实时数据分析助力掌握设备动态。
    

  

*   **阿里云物联网平台**依托阿里云强大的生态链，让接入到阿里云体系的用户借助阿里云物联网平台，完成设备的管理，赋能各行业。阿里云IoT平台产品主要侧重于设备管理和数据的监控处理，OTA作为其设备生命周期管理的一个功能项，若是和用户的升级场景以及整个OTA流程打通，部分功能略有不足。
    
      
    
    **核心功能：**阿里云物联网OTA子功能主要侧重在升级包管理，升级模块管理以及版本升级数据的查看，从功能层面可解决升级包的管理与下发。
    

  

*   **艾拉比OTA平台**专注OTA领域，OTA SaaS平台克提供一整套专业、安全、低门槛的OTA升级管理方案。作为专业的OTA解决方案商，有着较强的产品能力与行业方案落地经验。
    
      
    
    **核心功能：**艾拉比OTA SaaS平台支持设备固件升级（FOTA），应用升级（SOTA），配置文件更新等不同资源的升级，升级策略配置能力灵活强大，支持复杂设备或系统集成设备的精细化升级管理，自研在线差分技术，大幅度提升升级效率。
    

  

通过比较发现，阿里云物联网平台可实现较为基础的OTA功能，类似把OTA作为功能子项的物联网平台大都由此特点；而独立的OTA平台，如百度、艾拉比平台在OTA产品功能上可实现深度OTA。核心功能层面来看，百度和艾拉比都提出了差分升级技术，百度的差分技术主要应用在安卓系统的系统固件和应用程序上，艾拉比不仅支持安卓系统，同时也支持Linux，RTOS以及一些裸跑的单片机程序进行差分。

  

  

***02******.***

**OTA 商业模式对比**

  

百度安全OTA服务平台是通过激活设备数和设备消耗的流量进行计费，收取单个设备的license以及设备在下载升级资源过程中造成的流量消耗费用，用户实际使用进行扣费；

  

阿里云物联网平台是通过企业实例进行收费，即按月/年购买产品，便可使用该实例下包含的所有服务，如设备管理、物模型管理、OTA升级等服务，实例到期后需续费使用；

  

艾拉比OTA SaaS云平台的收费方式为激活设备数、CDN流量或设备下载次数，注册送免费体验套餐，免费额度用完后需要收取设备的license费用，以及设备在升级任务中消耗的CDN流量或者设备下载次数，两者选一进行收费。

***03******.***

**OTA 特色功能对比**

**百度云OTA服务**平台针对单芯片设备支持定制APK，签约购买即可获取适配产品的APK；支持对设备的系统和应用分别进行升级或者同时升级。

  

**阿里云物联网OTA服务**提供了升级包安全检测服务，这一额外收费服务，可以对升级包的安全性进行检测；动态升级模式支持用户创建一个动态升级的OTA任务，在任务有效期内可以新增或者减少需要升级的设备范围。

  

**艾拉比OTA平台**可以对多零件设备的升级进行精细化管理，可选择差分而非整包完成升级，特定行业可选购行业OTA管理平台来使用匹配度更高的管理能力。

  

  

***04******.***

**OTA 综合优劣势对比**

  

**百度云OTA服务**平台以安全为核心优势，拥有百度安全团队强大的研发能力及专利技术，整合百度多项安全及云加速技术，提供设备认证、防劫持、防破解、防篡改的全方位安全升级能力，从云到端，全方位守护设备安全。可进行私有化部署，提供定制化产品方案。

  

****劣势：****百度安全OTA服务平台的劣势在于适配单芯片设备，其中以安卓，Linux系统为主，对于嵌入式设备或者多零件升级需求的场景目前无法满足。需要签约合同，定制APK的费用较高。  

  

**阿里云物联网平台OTA服务**的优势在于背靠阿里云这一生态链，能与阿里云旗下其他产品生态共享，高效连接，并在实现OTA升级功能的同时，提供一整套设备管理平台，支持设备的物模型以及其它业务数据的扩展功能更全面、更强大。

  

**劣势：**在商业模式上，对仅仅有OTA需求的用户成本较大，用户需花费更多资金开通企业示例；在产品功能上，对部分行业多个零件升级的功能有所欠缺，如智能网联汽车，机器人等。由此看来，阿里云物联网平台适用于家居、农业等行业，一方面需要数据采集和设备管理，另一方面又有着OTA升级需求的使用场景，对只需要OTA服务的厂商不是明智之选。

**艾拉比物联网**SaaS云平台从专业的OTA服务提供商角度出发，用户无需签约即可免费体验使用，入门门槛低，上手快；平台自身支持单芯片、多芯片的设备接入，对复杂设备可自定义其升级方案；提供自研差分算法，解决用户升级空间资源不足的痛点；后续提供多种增值服务如安全加密，漏洞扫描可供客户灵活选用。

  

**劣势：**艾拉比OTA SaaS云平台目前可满足单零件设备和复杂设备的精细化升级管理，但对于单个设备来说管理流程相对复杂。对于聚焦于OTA领域的平台产品，若客户其他IoT服务目前能力较欠缺。

  

  

***05******.***

**总 结**

  

在当前物联网行业设备智能化迅猛发展的大背景下，OTA竞争也在不断加剧，不论是专注分赛道的垂直玩家还是互联网头部平台玩家都在积极拥抱变化。目前看来，虽然每款产品都无法完全满足用户需求，但都在为提供更专业，更具差异化，更契合市场的产品而不断探索，物联网OTA平台正在逐渐成熟，日趋完善。作为用户，首先要明确需求和客户定位，再通过试用体验去深度了解。
