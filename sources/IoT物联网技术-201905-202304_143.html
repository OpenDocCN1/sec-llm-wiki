2021 年下半年，在我的好友 TGO 鲲鹏会北京分会委员，马泷医疗集团 CTO 于游的推荐下，受“水滴风马产品公社”的邀请，我为某大厂几十位高 P 同学进行了一次《产品定位与规划》的全天课程培训。感谢水滴几位同学的帮助，在长达两个月的课程打磨过程中，我把自己多年来积累的知识体系进行了重构，并深入到底层逻辑的思考中，课程反馈也得到了高达 94% 的 NPS。课程结束后，我开始重新思考一些问题：这个世界的底层逻辑到底是什么？这个世界发展的新方向在哪里？我对自己的定位与规划又是什么？



外观世界：


什么在减少？


第一层，人口基数：国内人口红利已经结束，2021 年人口净增长仅录得 48 万。以后所有围绕人口数量增长的逻辑都将按下暂停键。


第二层，移动互联网用户：2021 年第三季度全球智能手机销售量下降 6.8%。2021 年中国市场智能手机销量约 3.14 亿部，仅增长 3%。2021 年网民数量已经超过了 10 亿，去除刚刚脱贫的人口及未成年人，基本见顶。


第三层，消费市场下沉：从手机专卖店到拼多多，从物流到外卖，下沉市场的辐射已经进入中盘阶段，也就意味着存量只会越来越少。


https://www.idc.com/getdoc.jsp?containerId=prCHC48831222


什么在增加？


第一，宏观政策：机遇和发展方向都写在了十四五规划里：加快壮大新一代信息技术、生物技术、新能源、新材料、高端装备、新能源汽车、绿色环保以及航空航天、海洋装备等产业。推动互联网、大数据、人工智能等同各产业深度融合，推动先进制造业集群发展，构建一批各具特色、优势互补、结构合理的战略性新兴产业增长引擎，培育新技术、新产品、新业态、新模式。


第二，设备与传感器：人口增量虽然越来越少，但是设备增量越来越多，随着我们生产生活中越来越深入的数字化，随着我们身边、家庭、工厂中越来越多的传感器的出现，假以时日，这些设备、传感器相关的数据必将占据人类社会所产生数据中的绝大部分。


第三，最后都是数据：人类的现代化历史就是人类的数字化历史。随着人类数字化的不断深入，无论人类社会跟随“人类之光”马斯克追求“硬科技”，还是跟随“666”扎克伯克走进“元宇宙”，如果说这个世界上还有什么指标仍然能够突破人类社会当前的发展瓶颈以指数级发展，答案只有数据。据推算，2020 年，全世界的数据量预计达到 44 个泽字节（ZB）。如果这个数是正确的，那么意味着它将会是可观测宇宙中星星数量的 40 倍。

什么是趋势？


第一，软件吞噬一切 Software is eating the world.

第二，开源吞噬软件 Open source is eating software.

第三，世界在加速数字化。

第四，世界数字化的增量大多都是时序（time-series）的。

按图索骥，答案已显现：


首先，所有和人口、网民相关的消费产业，不排除会有新的优秀的产品服务出现，但如果找不到新的增量（比如下沉，比如出海）基数，只能陷入内卷。


其次，无论是紧跟国内十四五规划，还是放眼全球科技发展，硬科技、物联网、工业互联网、新制造都将是继服务于消费者的互联网之后新的社会经济增长点。有什么领域和他们都有关，能享受到所有这些红利呢？


再次，以软件、开源的模式，围绕数据处理和应用的生意，已是大势所趋。


内观自我：


初入职场，有一次印象颇为深刻的公司内部培训，主题是《如何成为一个老师》，这里是广义的“老师”，其实是培训我们如何成为一个“讲师”，一个传授知识和经验给听众的“老师”。感谢当年刘宝老师的精彩课程，在我心中埋下了一个种子，让我对知识的传播产生了浓厚的兴趣，让我对如何成功的进行一场“讲课”，一场“演讲”产生了浓厚的兴趣。在 2019 年的 QCon 大会上，我进行了一场名为《从 0 到 1 开启一段技术创业之旅》的分享，录得了当时 QCon 大会破纪录的 100% 现场 NPS，此次之后，我开始在演讲之路上彻底放飞自我。


2014 年，自己历史的积淀，加上前老板与同事的支持，让我有幸与他们联合创立了融云。我们和几家友商一起从零到一在全球范围内开拓了一个崭新的“即时通讯云服务”市场，并带领融云做到了该领域的市场头部。在融云的创业过程中，一路走来，收获甚多：


  • 战略与产品定位、产品规划方面，经历了 to B / to D 业务从零到一的经验积累。在战略规划制定，Go to market 策略制定，产品路线图规划方面都历练出了实战经验。

  • 商业变现方面，经历了从 0 到数亿元收入规模的探索与实践。与公司市场销售团队配合，向他们提供最佳的售前与解决方案支持。

  • 合作和生态方面：中国 to C 互联网公司、非互联网行业的大型、超大型企业、政府机构，都是我的客户或者潜在客户，因此我联系与拜访过大量各行各业的 CTO、 CIO、IT 技术负责人；作为合作伙伴或者潜在的合作伙伴，长期以来与 SI、ISV 之间也有着很多良性互动；在演讲、布道的路途上，无论是 to B 企业服务公司，还是知名的投资机构，亦或媒体行业都有幸结识了许多优秀的朋友。


    凡是过往，皆为序章。为优质的产品和平台构建战略合作和开发者生态这样的角色让我有了新的使命感，让开发者成功、让客户成功，共赢的成就感让大脑神经再次活跃兴奋起来。


    到这里，一个名字已在我脑海中浮现出来：来自涛思数据的开源物联网时序大数据平台“ TDengine”。


   初识涛思数据的创始人陶建辉老师是在 2019 年的北京 GTLC 大会上，那是一个阳光明媚的日子，我和陶老师约在了 GTLC 会场丽都酒店的大堂见面，当时我是 TGO 鲲鹏会北京分会理事会的小组委员，负责新会员的面试工作。那天我与陶老师聊了很多很多，虽然内容已经有些许模糊，但陶老师的热情与滔滔不绝给我留下了深刻的印象，相信绝大多数认识陶老师的朋友也有同感。


关于 TDengine


  • 得益于创始人陶建辉老师多次创业的成功经验， TDengine 有极其精准的产品定位，所有设计专为时序数据库而来，Born to win。

  • 开源——目前最优秀、最先进的商业模式，Elastic、Databricks、Confluent、MongoDB、HashiCorp 几家开源上市公司都已经在全球资本市场得到了验证。

  • 经过几年的潜心研发和两年的市场验证，产品与技术均具备顶级的竞争力。


最近有很多人问我，陶老师是如何说服你加入涛思数据的？我想说：陶老师追求卓越的创业热情、“TDengine” 这样优秀的产品就是筑巢引凤的最好案例。



未来可期，只争朝夕，接下来我们要做什么？


首先，做好 DevRel (Developer Relations) 的事情，做好 Developer Advocate / Developer Evangelist 的事情


    作为一个曾经从 Beta 版开始写 .NET 的程序员，要说我心目中的 Evangelist 大神，非 Scott Guthrie 莫属，Gu 哥，对，请允许我叫他“谷哥”。谷哥从 2003 年开始围绕微软 .NET 话题写博客，靠一把好笔杆子（当然不是）一路走来从一名 .NET 程序经理直到现在成为微软 Cloud and AI Group 的执行副总裁。


   言归正传。目前国内有 PingCap 和 Agora 两家公司在 DevRel 方面虽然已经小有成效，但真正 Developer Advocate / Developer Evangelist 工作方面，受限于国内独(luo)特(hou)的开发者环境，几乎所有厂商的相关团队都还处于本土落地的摸索中。关于如何运营开发者社区生态，如何做好内容输出、如何服务好开发者、如何助力开发者成功的话题，我非常愿意和大家一起探讨、摸索。


其次，做好连接合作伙伴的事情


对于涛思数据来说，生态合作伙伴的范畴非常之广：


  1. TDengine 属于开源 Infra 领域，我们在很多领域就是那个 inside core，我们的生态就是与大量的产品、平台进行整合，被“集成”。所有的物联网、工业互联网产品、平台、解决方案，所有的互联网运维监控、APM 产品、平台都是我们的合作对象。

  2. 各行各业的 SI、ISV 厂商，只要是产品、解决方案里有和时序数据相关的，都有合作场景。

  3. 和 TDengine 形成上下游关系的产品组合，都是我们可以一起抱团合作的伙伴。

  4. 欢迎国内的各大云厂商，以开放的心态，引入 TDengine 产品提供云服务，亦乐见其成。


最后，为涛思数据和我的团队打个广告：


    我在涛思数据负责开发者技术生态团队，任职战略合作和开发者生态副总裁。虽然加入涛思数据只有短短两周，已经切身感受到了各部门同事的专业水准，传说中的各路精英，汇聚一堂，加之公司的扁平化管理、同事间简单直接的合作关系以及公司先进的企业文化和科学的管理方式让我如鱼得水。
