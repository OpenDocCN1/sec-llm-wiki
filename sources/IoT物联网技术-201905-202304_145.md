# IoT 物联网推动企业业务转型

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTA4MzA0MA==&mid=2454927547&idx=1&sn=bfc4aec0015539dcc8014adb7e51c417&chksm=b16775f48610fce21f2536abf49de94f6baaa97669b16c84e50cfe4f9bf8ed4f9cca13cd52c4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5OTA4MzA0MA==&mid=2454927547&idx=1&sn=bfc4aec0015539dcc8014adb7e51c417&chksm=b16775f48610fce21f2536abf49de94f6baaa97669b16c84e50cfe4f9bf8ed4f9cca13cd52c4&scene=27#wechat_redirect)

![](../Images/a5468e6acc084050894dbb1a1e0894dc.png)**IoT 的挑战**

  

虽然 IoT 确实可以带来许多商业利益，但很多企业还处在努力构建 IoT 应用程序的阶段。

**连接设备难度很大。**IoT设备(比如泵和阀门)需要通过操作技术来连接到本地应用程序。还有一些设备 (比如电子血压计)则根本无法进行连接。

  

**IoT 设备的多样性也增加了复杂性。**一些设备的 CPU 和磁盘相对较小，不像其他设备一样可以完整运行软件程序， 这种情况下云便显得格外重要。

  

企业也需要将精力**投入到****管理设备和不断扩建基础设施**方面。现在，数十亿台实体设备已经部署到家庭、工厂、油井、农田、医院、汽车、机械和成千上万的其他地方。这意味着企业必须管理部署在数据中心以外的基础设施。未来，服务器将迁移到云，同时互联设备将部署在本地 – 真正变得无处不在。

  

**收集和分析 IoT 数据也是一项挑战。**由于设备无处不在(包括间歇性连接的位 置)，客户很难为他们的 IoT 应用程序实时收集和分析数据。分析 IoT 数据的速度也很慢，因为这些数据中经常会包含很大的差距、损坏的信息和错误的读数。此外，通常需要为 IoT 数据添加时间和位置等信息，这也使得快速分析变得 更加困难。建立基本报告已然相当困难，进行更加复杂的 IoT 分析(比如机器学习)更是难上加难。

  

为了构建 IoT 应用程序，企业必须通过大量繁重的工作来连接和管理设备，分析 IoT 数据所需的工作量则更甚于此。
