# 国内云计算第一股关停 IoT 物联网云服务，数据不保留，企业被迫迁移存量设备

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTA4MzA0MA==&mid=2454927459&idx=1&sn=ee83c2701ed3a28e6c0ce046b0a31c50&chksm=b167752c8610fc3aaef93a7d21564fa0d0ab4d860874578bd9a3cdf98350d0cfa4f1d11ac16a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5OTA4MzA0MA==&mid=2454927459&idx=1&sn=ee83c2701ed3a28e6c0ce046b0a31c50&chksm=b167752c8610fc3aaef93a7d21564fa0d0ab4d860874578bd9a3cdf98350d0cfa4f1d11ac16a&scene=27#wechat_redirect)

近日，有读者反馈，收到 UCloud 官方通知，称其**物联网UIoT**公有云平台即将在2022年3月31日0时**下线**，**企业需尽快完成存量设备迁移，下线后所有数据都不再保留。**  

![](../Images/71a7ee0987ccd4590231a37b2ef78622.png)

  

UCloud 官方于2019年8月1发布**物联网UIoT**公有云服务，不到3年就宣布IoT云产品下线。

  

这让当初选择UCloud物联网平台的中小企业，不得不面临**设备迁移的窘境**。刚过完春节的程序员们深陷加班的苦海，需在一个月时间内，**重新选择云厂商IoT物联网平台**，完成设备端和业务系统的升级改造，并**推送设备固件升级**。

  

作为中小企业都应从中吸取教训，优先选择实力雄厚的云厂商，避免遭遇到类似**美团云****关闭**，**苏宁云****关闭**等黑天鹅事件。

  

**01****UCloud IoT 云产品**

  

2020 年1月，UCloud正式在上交所科创板挂牌上市，成为**中国云计算第一股**，也是中国A股市场第一家**同股不同权**的上市公司。开市后，风光无两，最高达到126元，市值接近570亿元。

  

随后UCloud陷入困境，一边是资本失去信心，二是大股东以及高管开始纷纷减持。目前股价维持在22元，**市值缩水80%**。

  

![](../Images/672e37e40df11d5964b12195dde0c29c.png)

  

UCloud **物联网通信云平台**（UIoT Core）为设备上云和产业互联网数字化转型提供重要支撑，架起设备与云服务连接的桥梁，平台支持海量设备的连接，方便设备数据上云；同时提供云端API，方便用户云端应用开发，缩短用户开发周期，减少运维成本。 

  

物联网通信云平台核心功能包括**设备管理、物模型、设备影子、规则引擎、文件上传、固件远程升级**等服务，可广泛应用于智慧城市、智能制造、智能家居、智慧农业、无人值守、新零售、智慧能源、智慧医疗等领域。

  

  

**02****IoT 物联网平台倒闭潮**

  

UCloud并非第一个关闭自家 IoT 物联网服务的企业，早在2020年移动消息推送上市企业极光，就**关闭**了仅运营一年多的**极光JIoT 物联网平台**。

  

![](../Images/a786a1e0a2b0ec1dc5f89b303de66fd4.png)

  

IoT物联网平台停止服务也不是国内独有的现象。据知名研究机构IoT Analytics 统计，在2021年全球范围出现了物联网平台“倒闭潮”，消失了近30%物联网平台型企业。

  

**03****云厂商引领 IoT 平台发展**

  

物联网云平台为用户提供稳定、智能的服务和应用程序，需要巨大的投入和坚定的战略，而平台的盈利回报期往往很长，导致大量公司无法负担而关闭服务。

  

除了关闭服务，一些IoT物联网平台公司选择转变商业模式，从连接设备和应用的PaaS云平台服务商，转为提供**垂直领域应用解决方案的服务商**，以获得更快的盈利。

  

这也导致**IoT物联网平台**市场进一步**向头部云厂商集中**。根据市场数据，

物联网平台市场排名前10位的公司占有65%的份额，而在2019年和2016

年，这一数字分别为58% 和44% 。

  

**AWS** IoT Core、**微软**Azure IoT Hub 、**阿里云** IoT 物联网平台**三巨****头格局**已形成，并以每年50%的增长率继续引领市场。三大云平台以服务的稳定性获得全球80%用户的信赖，不断发布新的产品和服务，以满足中小企业物联网应用的各种需求，使得物联网门槛不断降低，推动了整个物联网产业生态的形成。
