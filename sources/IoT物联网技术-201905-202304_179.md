# MQTT.fx 模拟 IoT 设备接入阿里云企业物联网平台

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTA4MzA0MA==&mid=2454926931&idx=1&sn=e53917f4c1a555b72db666259acb59c9&chksm=b1677b1c8610f20a0e87dd1be6ad3416529b408e46b7909fdc2f7c047709eb7de1f0009c5e74&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5OTA4MzA0MA==&mid=2454926931&idx=1&sn=e53917f4c1a555b72db666259acb59c9&chksm=b1677b1c8610f20a0e87dd1be6ad3416529b408e46b7909fdc2f7c047709eb7de1f0009c5e74&scene=27#wechat_redirect)

MQTT.fx是一款基于Eclipse Paho SDK，使用Java语言编写的MQTT客户端，支持Windows、Mac和Linux操作系统，可用于验证设备是否可与物联网平台正常连接，并基于 Topic 和 Payload 发布和订阅消息。

  

我们以MQTT.fx为例，模拟设备以 MQTT 协议接入阿里云 IoT 物联网平台的步骤。

  

**开通实例，创建产品，注册设备**

  

首先，我们登陆阿里云IoT 物联网平台控制台，购买企业实例。

 https://iot.console.aliyun.com 

![](../Images/e165038e7313c0423b420feefa1e7abc.png)

  

然后，根据业务情况选择适合的规格参数，并付款。

![](../Images/f55877cc7805865734c2d87bd5620e35.png)

  

支付完成，等待 IoT 企业实例部署完成，大约需要3分钟。

![](../Images/8748481e98c834e84131d8666e32241d.png)

  

进入企业实例，创建新产品：温湿度计。

![](../Images/1d5972c5cc0fd66ffef470dd61e5a914.png)

  

最后，基于温湿度计产品，注册一个设备。在设备详情，可以查看MQTT连接参数。

![](../Images/abae05b89f9d895974656645d8f94be8.png)

  

  

**MQTT.fx 模拟IoT设备建立连接**

  

打开MQTT.fx，创建新连接，并填入上图设备连接参数。  

![](../Images/1de6ee3089751e2c78944bef6b8e2716.png)

  

点击连接按钮，成功建立MQTT连接。

![](../Images/36c64f4f13a744b8b8627e287472bd5b.png)

  

在IoT物联网平台控制台，可以看到设备**在线**。我们测试实时网络延迟结果：14ms。

![](../Images/d09cc834bb583d52464a11b705eb8bfc.png)

  

在日志服务中，我们观察到一条设备上线日志。

![](../Images/7296841f853f5c4f7db3eb41c466349d.png)

  

**MQTT.fx 模拟设备发送数据**

  

在MQTT.fx工具的Publish面板，填入设备上报的Topic，选择QoS=1，以及Payload内容，点击发送。

![](../Images/6b1b71e28a4ec845e2ea8835db9b8e0f.png)

  

在日志服务，我们找到**设备到云消息**记录，并点击**查看**详情，可以观察到MQTT.fx工具上报的数据报文内容。

![](../Images/5d139b0c6baf8651bef3ecdf34a79618.png)

  

**MQTT.fx 订阅主题**

  

在MQTT.fx工具的Subscribe面板，输入订阅的Topic，并点击订阅。

![](../Images/360243a3cb759175795553a2c76e5f95.png)  

  

在日志服务里，我们看到一条**订阅**日志和对应的订阅Topic。

![](../Images/3ee0ac9ecbc47a1cd27713f382d9f2da.png)

  

在设备详情的**已订阅Topic列表**，我们看到一条订阅Topic。

![](../Images/5ae170844dde9a94333f6715654a5464.png)

  

****MQTT.fx **接收云端下行控制指令**

  

在设备详情的**已订阅Topic列表**，选择目标Topic，点击**发布消息**，并填写消息内容，**确认发送**。

![](../Images/3dfeabdeeb0595c8a47eab7eca69db23.png)  

  

在MQTT.fx的**Subscribe面板**，我们可以观察到云平台推送下来的消息Topic和Payload内容。

![](../Images/135e1f3ed85c40f8dba85bfd605a1bda.png)

  

在日志服务里，我们可以观察到完整的消息链路。

![](../Images/0cbf1ccafec237395acd93b5ca268545.png)
