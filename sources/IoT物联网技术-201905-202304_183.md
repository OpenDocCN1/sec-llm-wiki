**01******物联网市场将超万亿美元，数字孪生行业迎来风口****

  

据 GSMA（全球移动通信系统协会）预测，到 2025 年，全球物联网设备连接数将达到 251 亿个，市场规模将达到 1.1 万亿美元。

 

在 5G、新基建、云计算等基础设施高速发展的加持下，日益庞大的物联网市场，实时产生海量数据，业务复杂度翻倍，管理和决策的实时性成为难题。面对无数细分的应用场景，传统的系统管理、数据分析、信息呈现方式已经无法满足**“多数据、多变化”**的管理需求，而这一切，数字孪生可视化系统都可以做到。物联网行业对数字孪生的应用需求暴增，诞生巨大市场缺口。风口已来，普通开发者、中小企业该如何快速掌握**“数字孪生可视化”**真实力，踏上风口抢先入局？

 

**02********数字孪生可视化市场即将爆发，落地却门槛极高******

  

对于个人开发者、软件服务商来说，数字孪生可视化未来市场虽大，想要提前入局却困难重重。

  

**软件服务商、物联网供应商：**数字孪生可视化项目的研发成本高昂、项目周期漫长，更难的是数字孪生专业研发人才的稀缺，成本消耗巨大绝非中小企业所能支撑。拥有数字孪生可视化团队的企业，大多是基于游戏引擎技术栈开发，想要实现系统级可视化应用的实时数据驱动和双向交互，难度和代价极大，项目交付成为难题。

 

**个人开发者：**市面上的数字孪生可视化项目大多是大型企业项目制，普通开发者想要入局，且希望以最低的学习成本，获得高效的开发能力，产出适用度高的应用，但市面上却很难找到同时满足这三点的平台。

 

2018 年，拥有多年数字孪生可视化技术积累的 UINO 优锘科技，推出了面向物联网应用的数字孪生可视化开发和工具平台——ThingJS1.0。将自研自用的底层工具平台开放给全行业使用，铲平物联网3D可视化开发门槛，让每一家公司都能低门槛、高效率地开发出自己的数字孪生应用和场景。

在 ThingJS 平台上，UINO 为全行业提供了高效易用的数字孪生可视化开发引擎，包括一系列配套的工具组件和模型资源，为没有专业数字孪生可视化团队的物联网企业提供端到端技术解决方案，大幅降低数字孪生应用的开发门槛，节约成本投入，缩短了推向市场的时间，推动数字孪生技术的普及。

 

截至目前，ThingJS 平台在各行各业的支持下迅猛发展，已经与 40万开发者共创 34万个 3D 场景，赋能 9w 余企业实现数字化转型，实现 120万 代码全权托管。而在 2021 年，全新升级的 ThingJS 2.0 即将与大家见面，完成从面向物联网的 3D 可视化 PaaS 平台，到“一站式数字孪生服务平台”的硬核蜕变。

  

**03********IMAGINATION，为物联网赋予更多想象力******

爱因斯坦曾说过：imagination is more important than knowledge。在ThingJS平台上，34万开发者在创建智慧城市、智慧园区等物联管理场景，工业、农业、制造业等产业场景，甚至还有火箭发射基地和新年小游戏等场景。开发者们其实是在用代码和3D场景建造一个新的数字新世界，充满了想象力。

 

2021 年 12 月 18 日，UINO 优锘科技举办的「IMAGINATION」2021 ThingJS 开发者大会，以「真孪生·共建未来」为主题，向所有的开发者、用户展示场景效果更炫酷、功能扩展更灵活、开发方式更高效的 ThingJS 2.0，为各行业开发者的想象力创作提供**「通关密码」**。

**04********低门槛、强实力、全赋能，一站式数字孪生服务平台让数字孪生开发超简单******

  

在发布会当天，ThingJS 引擎技术专家向大家展示了 ThingJS API 2.0 的全新功能，展现了 UINO 想要打造全场景万物智联的技术底座的综合实力。

  

**低门槛：**相比游戏引擎开发技术栈，UINO 的 T3D 自研引擎，专为数字孪生场景打造。功能新增 45%，开放接口 1000+；1 秒加载，搞定上万模型批量渲染；一行代码，调用海量高频可复用功能；使用更简洁，只需 2 周学习就能熟练使用；0 代码开发平台的拖拉拽式操作更是只需 2 天就能入门；

  

**强实力：**ThingJS API 2.0 能力升级，支持跨引擎 Unity/UE4 的渲染能力，其他引擎千行代码能实现的功能，ThingJS 一行即可实现。此外，渲染性能、加载性能相比1.0有极大升级，更有独家专利算法加持，能实现超逼真大场景实时渲染。

  

**全赋能：**开发平台+全链工具+海量资源，一站式数字孪生服务平台，提供交付物联网可视化项目所需的一切支持。

**05**********ThingJS 2.0 一站式更爽快，数字化转型的通关密钥********

  

随后， ThingJS 平台各工具链的产品负责人也向大家展示了全新功能及未来展望，多款工具链优化升级，并搭配海量模型库，全方位共建数字孪生新生态。

  

**CityBuilder****：创建更好看的 3D 城市**

一款小白也能轻松上手的城市级 3D 场景编辑器。支持多源异构数据导入，提供城市乃至地球大尺度区域 3D 场景的快速搭建、加载、渲染。内有海量城市模板库，支持一键切换模板，快速构建高颜值 3D 城市。

 

**CampusBuilder****：让场景搭建成为你的主场**

帮助不懂 3D 建模的非专业人士快速搭建 3D 场景的工具。两万+模型，仅用“拖拉拽”轻松打造 3D 创意场景；支持工业、粮仓、港口、商场、学校、医院、交通、消防、机房等数十个行业。在未来，还将实现快速布点、绘制路线、环境渲染、数据互动等功能。

 

**TopoBuilder****：让逻辑世界触手可及**

一款简单易用、功能强大的 web 绘图工具，采用简单易用的交互方式，帮助用户快速绘制拓扑图、流程图、物联网、工业组态、IT 运维等多种场景下的视图。支持多人实时在线协作，打通 ThingJS灵活调用，轻松打造 2D 数字孪生场景。在未来，还将实现零代码、一站式完成 2D 场景开发。

 

**ThingDepot****：最可靠的模型场景生产、储存、使用工具**

将模型生产、存储、使用功能一网打尽，为专业美术人员提供光线图、动画、特效工具、场景编辑器等工具，普通用户也可以直接上传自己的模型文件，无需跳转其他平台。未来将实现页面上传、后台自动轻量化处理等更多便捷操作，大幅缩短模型生产周期，不仅开放了海量模型资源，更提供了超便捷的模型制作及特效功能。

 

在明年上半年，UINO 还将推出 AppDepot 应用插件库和 UIDepot UI 组件资源库，并将通过资源商店实现资源的众创众享，给ThingJS 的用户们更多资源支持，进一步降低使用门槛，拓展应用场景。

 

除了技术工具和虚拟资源，UINO 还正为物联网生态中的各家企业打造一个数字孪生的虚拟世界：**物联森友会**。在这个森世界里，物联网企业可以构建物联网方案阐述的数字孪生虚拟场景，和物联网商品的数字孪生版本，一方面让 ThingJS 用户快速找到合适的物联网产品和方案，一方面为所有物联网供应商提供一个能快速触达产业上下游生态，并有效展示自己的方案和产品的数字化虚拟世界。

 

充分开放、铲平物联网可视化门槛的 ThingJS2.0，将会在 “**一站式数字孪生服务平台**”的道路上持续探索，不仅成为企业数字化转型的通关密钥，也为个人开发者提供了低门槛、高效率的数字孪生可视化开发能力。现实世界有多大，数字孪生的世界就有多大，甚至，更大。UINO优锘希望能通过数字孪生平台的打造，让所有人都更好更容易地认知、管理和创造数字化的新世界。相信未来，ThingJS 会帮助更多开发者和软件厂商入局物联网，共建数字孪生的全新生态。
