*EMQ X*是基于 Erlang/OTP 平台开发的开源 IoT 物联网 MQTT 消息服务器。

  

MQTT 是轻量的 (Lightweight)、发布订阅模式 (PubSub) 的物联网消息协议。

  

EMQ X 设计目标是实现高可靠，并支持承载海量物联网终端的MQTT连接，支持在海量物联网设备间低延时消息路由:

  

*   稳定承载大规模的 MQTT 客户端连接，单服务器节点支持100万连接。
    
*   分布式节点集群，快速低延时的消息路由，单集群支持1000万规模的路由。
    
*   消息服务器内扩展，支持定制多种认证方式、高效存储消息到后端数据库。
    
*   完整物联网协议支持，MQTT、MQTT-SN、CoAP、LwM2M、WebSocket 或私有协议支持。
    
      
    

![](../Images/a6bd89ff82203896d5c899b8fa76a2b3.png)

  

** **EMQ X Cloud云托管****

  

EMQ X Cloud 作为全球首个全托管的 MQTT 5.0 公有云服务，提供了一站式运维代管、独有隔离环境的 EMQ X 接入平台服务。对于首次使用 EMQ X Cloud 的客户，我们为您准备了 一次 创建长达 180 天时长免费试用部署的机会。  

  

EMQ X Cloud 为应用程序及物联网设备提供安全可靠的双向通信能力:

  

*   南向连接海量设备，支持设备数据上云、设备相互通信；
    
*   北向可以将设备事件与消息数据存储至各类数据库与流处理系统中，同时支持调用云端 API 将控制指令下发至设备。
    

  

借助云服务商提供的基础计算设施，EMQ X Cloud 面向全球数十个国家与地区提供服务，为 5G 与万物互联应用提供低成本、安全可靠的云服务。

  

**华为云上托管 **EMQ X 服务****

EMQX 云托管控制台：

https://cloud.emqx.cn/console/

  

**1.创建EMQ X实例**

在EMQ X控制台，新建EMQ X托管实例，选择规格参数，会自动评估每小时的费用。点击**立即部署**，即可创建实例。

![](../Images/f70ecb9b8d246e7001ae5cf09e7f1a67.png)

  

选择华为云节点

![](../Images/b41321203529d35c9b1cc24a8df05c07.png)

  

EMQ X专业版，在华为云的华东-上海一区创建。  

![](../Images/d9e33ec054d50747177ad95ba67e85f5.png)

  

EMQ X托管实例运行中。

![](../Images/55f45a0e8ac4adca5e7549b56e5e3535.png)

  

**2.EMQ X实例概览**

EMQ X托管实例部署完成后，在实例概览里查看运行状态，规格参数，南向设备的连接地址和端口，北向应用对接API地址和App账号/秘钥。

![](../Images/260d1075415a0eb2e7ec38848d450a5e.png)

  

**3.添加认证信息**

在认证页面，可以添加用户名/密码，作为每个设备接入时的身份认证标识。如下图，为ck001和dk001两个设备创建账号。

![](../Images/f7d48fa1c998dc730cb846d462979159.png)

  

**4.通信Topic访问控制**

在访问控制页面，可以根据业务需要添加Topic和访问权限。在此新增了用于接收控制指令的主题: /biz/cmd/receive  ,设备上报数据的主题: /biz/data/post 。

![](../Images/551bf26cdbab823af13b8eb65a75d479.png)

  

**5.规则引擎**

在规则引擎页面，可以配置消息流转规则。如下图，把设备dk001上报的消息，转发到 /biz/cmd/receive 主题，这样订阅了该主题的设备，都会收到dk001的消息。

![](../Images/8a4b87dd946ef27acc9f2d3f46f4889a.png)

  

6.设备接入

使用MQTTX客户端来模拟dk001连接 EMQX实例，并向指定的Topic发布数据。![](../Images/04df0aafa84d71b0ca8fec8df7339848.png)

  

ck001连接 EMQX实例，就会实时接收到dk001流转过来的数据消息。

![](../Images/1d0308afa166d9889585e0353f3021ce.png)  

  

7.监控

在监控页面，可以实时查看 EMQX 实例的运行情况，连接的设备端列表，订阅的Topic列表。

![](../Images/3ad20d2a23c25b3fb18b6986b0dbe7ab.png)

  

点击客户端ID，可以查看设备连接的详细信息，如下图：  

![](../Images/d04ba5c0de77c7c0d42beff25c8f6396.png)

  

8.指标大盘

在指标页面，可以实时查看收发消息量，客户端连接数，订阅数。

![](../Images/5c5a364ee5b89428a5adbc94cd71cf0d.png)

  

9.运行日志

在日志页面，可以实时查看EMQX实例的运行日志，日志级别分为：**告警，错误，紧急**。

![](../Images/ddf04b2cc312c344cca017d29f5fd091.png)
