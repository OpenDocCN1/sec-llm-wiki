# 手把手教程｜SaaS Boost 安装避坑指南

随着亚马逊云科技[**SaaS Boost**](http://mp.weixin.qq.com/s?__biz=Mzg4NjU5NDUxNg==&mid=2247488338&idx=1&sn=1830c2454c93081a0b90a63c9ed44400&chksm=cf961de9f8e194ff2629cafed7ca8fc176937a77ccd21f8eb9aa3aa7b3003d1216451203dcd0&scene=21#wechat_redirect)在2021/05月正式官宣，越来越多的人会尝试安装体验此工具。但目前来看，**Github的官方指南还不够完善细致，存在很多“坑”，自己摸索可能会耗费很多宝贵时间**，为了节省大家在这方面的无意义浪费，将可能遇到的常见问题梳理在此文档中。  

  

**本篇文档中我们通过Cloud9来演示安装SaaS Boost**。

  

1.创建Cloud 9实例环境（推荐small机型）；

2.完成后，关闭默认临时凭证配置；

![](../Images/4f383c039787ea0656f46ec376417e52.png)

**Cloud9默认临时凭证为15分钟，但SaaS Boost通过CloudFormation模版进行安装期间过程会超过15分钟限制**，导致调用亚马逊云科技服务API时发生凭证失效，步骤中途失败退出。  

![](../Images/b64833fe6caf77624eebaa545fa27ff4.png)

3.对Cloud9关联EC2磁盘空间在线扩容至**20GB**或更多，通过重启简单生效；  

![](../Images/0d40bde1ba189a799e1455a52efa06ce.png)

**默认空间为10GB**，安装过程中会出现空间不足导致失败；  

![](../Images/c29fd067b9f375a9aba68ed726669184.png)

4.Cloud9终端环境中配置**Amazon configure**，**最好为管理员账户**；

     

5.安装如下环境工具：

*   Java 11 Amazon Corretto 11
    
*   Apache Maven
    
*   Amazon Command Line Interface version 2
    
*   Git
    
*   Node 14.15 (LTS)
    
*   Yarn
    
*   Java 11 Amazon Corretto 11
    

这里以Amazon Linux2为例，其它操作系统请参见官方文档；

https://docs.aws.amazon.com/corretto/latest/corretto-11-ug/downloads-list.html

安装命令：

sudo yum install java\-11\-amazon-corretto

完成后，设置当前Java环境为Corretto 11

sudo alternatives --config java

同时，在~/.bashrc中添加JAVA\_HOME环境变量

export JAVA\_HOME=/usr/lib/jvm/java-11-amazon-corretto.x86\_64  
source ~/.bashrc

![](../Images/a5a0b4ac736d45010f577a9e7b1a6d0a.png)

*   Apache Maven  
    
    分别执行如下命令安装
    
    sudo wget https://repos.fedorapeople.org/repos/dchen/apache-maven/epel-apache-maven.repo -O /etc/yum.repos.d/epel-apache-maven.repo  
    sudo sed -i s/\\$releasever/6/g /etc/yum.repos.d/epel-apache-maven.repo  
    sudo yum install -y apache-maven
    
*   Amazon Command Line Interface version 2
    
    Cloud9默认已安装
    
*   Git
    
    Cloud9默认已安装
    
*   Node 14.15 (LTS)
    
    Cloud9默认已安装了NVM位于当前用户主目录下，但Node版本较低：
    

![](../Images/2204c265225b0d1dbd96043a9c0f8c65.png)

 分别执行如下命令，安装并切换至当前版本为14.15.1

nvm install 14.15.1  
nvm use 14.15.1

![](../Images/461f1807b1ed2c6218fd15ad74027514.png)

*   Yarn
    
    分别执行如下命令，按照yarn
    
    curl --silent --location https://dl.yarnpkg.com/rpm/yarn.repo | sudo tee /etc/yum.repos.d/yarn.repo  
    sudo yum install yarn -y
    

  

6.当前～/environment目录下克隆SaaS Boost Github存储库代码；

git clone https://github.com/awslabs/aws-saas-boost ./aws-saas-boost

  

7.执行脚本，创建SaaS Boost环境

进入Amazon-saas-boost目录

![](../Images/449a5b9e89b22c331df4772952cf4719.png)

正式执行脚本之前，**务必确保当前所使用Java环境为前面所安装的Corretto 11；否则，执行命令切换并验证**

sudo alternatives --config java

![](../Images/7df16bf0e00080d76d8c1f153d9fca01.png)

不然，会遇到类似如下错误  

![](../Images/16bb00a976259f40bd106a7396a792cb.png)

运行脚本 sh install.sh启动安装，maven完成编译打包，过程大约3-5分钟

![](../Images/2c08ca230179f37aec43a60a1c297ddf.png)

若遇到如下security token错误，**建议显式设置相关环境变量再重试**  

export AWS\_ACCESS\_KEY\_ID=RoleAccessKeyID  
export AWS\_SECRET\_ACCESS\_KEY=RoleSecretKey

![](../Images/35afd2e3557cb76ccd2f8e4bd353a08f.png)

  

按照向导输入参数，**需要注意的两个地方**：

*   记住SaaS Boost环境名称参数，此处为test  
    

![](../Images/6c5c3c23a098e656bf642d883dbb7afe.png)

后续安装完成后，配置脚本步骤中会需要输入此名称

![](../Images/3aaa2647bde9f43c14a259fc5ece46b8.png)

*   输入用于收取SaaS Boost访问地址和初始用户名/密码的邮箱地址；  
    
*   如果启用指标和运营功能，则必须已经拥有QuickSight账户，而且需要输入您拥有的QuickSight账户区域，注意这不一定是现在创建SaaS Boost所使用的区域
    

![](../Images/0f26e50484ab8bc96d170419e9e1f4e9.png)

若不确定已拥有QuickSight账户所属区域，可随便输入，系统会返回正确的区域

![](../Images/b746a646dbd263df217e677815f15df0.png)

再次确认所有参数后，开始创建SaaS Boost环境，此过程大约20-25分钟

![](../Images/3b0667bc78e892e2ce6bd5de57d7734c.png)

至此，环境创建完成

![](../Images/acdfac858f25556b74caf0e9661feb90.png)

其它安装过程中可能遇到的错误

如下错误说明node当前使用版本不符合，**可能是重启Cloud9后导致**，通过nvm命令重新切换当前版本

![](../Images/9bfdca8bc3eb51b4b51cf5c7690b1dd7.png)

另外，所有安装过程中日志都统一存储在日志文件~/environment/aws-saas-boost/saas-boost-install.log。而且，CloudFormation控制台界面也可查看所有相关的后台过程

![](../Images/3b8251988443b4977d66161162891d05.png)

8.登录SaaS Boost环境

通过邮箱收到的访问入口，用户名/密码登录已部署好的环境

![](../Images/8abd4a66f323c79c918e5108ca963aa5.png)
