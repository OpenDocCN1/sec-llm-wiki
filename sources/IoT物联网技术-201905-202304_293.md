# 正式商用1年后，华为云 IoT Studio 退市，物联网平台降温！

3天前，[腾讯持股超10%，「**涂鸦智能**」赴美上市，将成为全球IoT 物联网云平台第一股！](http://mp.weixin.qq.com/s?__biz=MjM5OTA4MzA0MA==&mid=2454924116&idx=1&sn=340a01e207299b34c1488520e247699e&chksm=b167661b8610ef0ddeecd3b2824d55bed2607210773d7d9f6a3435070dc9e6a8aa6685671efe&scene=21#wechat_redirect)另一边，华为云IoT开发者服务**(IoT Studio**)计划于2021/03/31 23:00（北京时间）**退市**。  

  

3年前，阿里巴巴宣布**IoT物联网**成为阿里继**电商、金融、物流、云计算**后的第五个主赛道。物联网浪潮开始席卷各个领域，为各领域带来新的解释，也为整个市场带来了无限的机遇和挑战。

  

华为云，腾讯云紧随其后布局IoT物联网平台和服务，各种行业垂直物联网平台如雨后春笋爆发。经过3年高速发展，物联网领域厂商和行业平台进入到阶段性洗牌时期，本是行业客观规律，但却给相关产品消费者带来了麻烦：**当物联网平台服务关闭，相关智能设备将不得不面临丧失使用价值的尴尬境地。**

  

此类现象给物联网企业一个警醒: 产品研发要尊重物联网发展规律，**做好“善后”**准备，以保障企业自身和消费者的合法权益。

  

据不完全统计，国内物联网平台一度曾多达450家。如今已减至300家左右。初创企业资源有限，不太可能同时对接多个IoT物联网平台云服务，因为更换接口、标准都需要投入大量的人力、物力和财力。一旦创业企业决定转型甚至申请破产，没有人继续为服务器付费，那么应用程序很快就会停止工作，结果依然是消费者手中的产品变成“废物”。

  

碎片化是IoT物联网业务必须面对的挑战，数字化转型行业特性明显。平台方需要对产业有深入的理解，而中小企业则需要充分估计物联网碎片化特征可能带来的影响，尽快融入到相关的生态环境中。

  

站在巨人肩膀上，无疑是个好选择。我们推荐**出海**企业优先考虑AWS IoT和Azure IoT平台；在**国内开展物联网**业务或者进入**国内拓展物联网**的海外企业优先选择阿里云IoT物联网平台。
