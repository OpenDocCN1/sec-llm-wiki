1. 点击产品管理界面，找到已经创建的产品


2. 打开 mqtt.fx 软件界面，点击设置按钮进行配置


3. 查找开发文档中，登录的 IP 地址号和端口号两个参数，我们此处是 使用到的无证书的 IP 端口:

https://open.iot.10086.cn/doc/iot_platform/book/device-connect&manag er/MQTT/mqtt-device-development.html


4. 点击用户信息进行用户名、密码配置(其中 UserName 为产品 ID，Password 通过 Token 计算器进行计算)


5. 点击产品详情，查询产品 ID


6. 使用 Token 计算器生成密码 ，参数详见开发文档:

https://open.iot.10086.cn/doc/iot_platform/book/device-connect&manag er/device-auth.html


7. 将 Token 生成的密码复制在 MQTT.fx 的 Password 中，点击 OK


8. 回到主界面，点击 Connect，即可显示在线状态


9. 平台侧，设备管理界面，该设备也显示在线状态
