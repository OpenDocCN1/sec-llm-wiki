**  文 字 稿  **

  

1\. 点击产品管理界面，找到已经创建的产品

![](../Images/c5b95648649faa57aff639abbd177323.png)

  

2\. 打开 mqtt.fx 软件界面，点击设置按钮进行配置

![](../Images/0480f0d346fe376e312687d23c99e4e2.png)

  

3\. 查找开发文档中，登录的 IP 地址号和端口号两个参数，我们此处是 使用到的无证书的 IP 端口:

https://open.iot.10086.cn/doc/iot\_platform/book/device-connect&manag er/MQTT/mqtt-device-development.html

![](../Images/7ac8c17a57aa22367dcbb8aef92ed305.png)

![](../Images/6e0d687145a9e851608164ac5328b1d7.png)

  

4\. 点击用户信息进行用户名、密码配置(其中 UserName 为产品 ID，Password 通过 Token 计算器进行计算)

![](../Images/6e3cb1efb69e5613590578c17b3e0aae.png)

  

5\. 点击产品详情，查询产品 ID

![](../Images/2ae7fe93195516e697a4fdaa2688cf33.png)

  

6\. 使用 Token 计算器生成密码 ，参数详见开发文档:

https://open.iot.10086.cn/doc/iot\_platform/book/device-connect&manag er/device-auth.html

![](../Images/1343451e38230bbd91a27681a564402d.png)

  

7\. 将 Token 生成的密码复制在 MQTT.fx 的 Password 中，点击 OK

![](../Images/6d2d4c87091ec11390d67be4531141a3.png)

  

8\. 回到主界面，点击 Connect，即可显示在线状态

![](../Images/313a5e4c9c35d2a7bdcd610b3717a871.png)

  

9\. 平台侧，设备管理界面，该设备也显示在线状态

![](../Images/e22b336344b59e86d7d867c3eb6074f1.png)
