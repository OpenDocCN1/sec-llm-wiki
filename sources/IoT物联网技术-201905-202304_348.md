# 2020年国内 IoT物联网平台横向对比报告

金秋十月，丹桂飘香，中秋巧遇国庆！

  

值此佳节，我们为 IoT 物联网领域的广大开发者们带来了《**2020年国内 IoT物联网云平台横向对比报告**》。

  

此《报告》与Gartner和IDC评估报告不同，我们以开发者视角出发，面向中小型物联网企业 CTO，技术 Leader 等研发人员做技术选型参考。

  

**调研对象：**

阿里云、腾讯云、华为云、电信AEP、百度云

  

**调研方式：**

*   各云平台官网开发者**文档阅读**
    
*   开发实操：**设备接入、设备数据上报、数据转存、云端控制指令下行**
    

![](../Images/4b40efa5f57d2f74e1e85666956b70be.png)

  

**调研总结：**

利用5天假期，经过多位开发者实操反馈，我们得出如下结果：

  

**1.阿里云**

阿里云IoT物联网平台，依托于阿里云十年技术优势，支持主流物联网协议接入，丰富的设备端和云端的多语言SDK，开发文档结构清晰，最佳实践案例丰富，为开发者提供了虚拟设备模拟，在线调试，以及完整日志服务，细粒度的实时监控告警，内置数据分析和应用可视化搭建，一直是国内物联网平台的标杆。

  

得益于阿里云数据存储，大数据分析，可视化等丰富云产品；极度活跃的云栖开发者社区；完备的技术工单体系，阿里云IoT企业物联网平台是中小物联网企业IoT设备上云的首选平台。

  

**2.腾讯云**

腾讯云IoT物联网平台，起步较晚，借鉴了很多前辈经验，设备端SDK相对弱些，开发文档丰富，最佳实践案例一般，受限于腾讯云自身薄弱，数据流转能力最弱，优势在于腾讯连连微信小程序打通，极大便利智能家居场景，但涉足工业，农业，城市等复杂领域物联网场景的中小企业，需慎重选择腾讯云IoT平台。

  

**3.华为云**

华为云物联网平台，优势在于NB设备的LwM2M协议支持，但设备端和云端的SDK支持力度不足，开发文档结构一般，最佳实践案例少，配套云产品弱，以及默认不提供设备日志服务，为开发联调，设备异常排查带来极大不便，除华为合作伙伴交付项目外，中小企业慎重选择华为云IoT平台。

  

**4.天翼物联AEP**

天翼物联AEP平台，接入协议最为丰富，NB-IoT基站部署广泛，NB设备推荐选择天翼物联。但设备端仅有C SDK，云端仅有 Java SDK，开发文档少，且无最佳实践案例，开发者不友好，加之相关数据存储，分析等云上能力弱，非NB场景的中小企业不推荐选择天翼物联。

  

**5.百度智能云**

百度天工物联网平台，受困于百度颓势，整体投入不足，未见技术推广活动，设备端和云端的SDK匮乏，开发文档少，开发者生态薄弱，不推荐用于企业生产实践。
