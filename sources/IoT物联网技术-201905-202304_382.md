# 五大理由！建议你选择中国电信 CTWing 物联网平台？

5G大潮已至，万物互联不再只是传说，海量的物联网终端蕴含无限商机，吸引着越来越多的参与者。

   

顺应市场趋势，中国电信全面整合了自身的**云、网和生态**等优势资源，打造了**智能物联网开放平台（CTWing）**，并升级该平台为新基建互联使能平台，面向客户提供优质的平台服务，并联合全球合作伙伴，打造产业核心竞争力、共创商业价值。

 

CTWing由连接管理、应用使能和垂直服务三大板块构成，全球化、安全可信的端到端服务贯穿始终。

 

*   **连接管理**负责网络和卡的智能化管理
    
*   **应用使能**提供物联网开发的核心能力
    
*   **垂直服务**是平台能力向垂直行业的专属方案输出，如：智慧城市、车联网等
    

 

“全球连接、一点服务”、“开放创新、安全可信”、“数据感知、智能决策”......凭借着这些优势，中国电信CTWing平台正在成为越来越多人的选择。

 

**CTWing 到底有什么魅力？**

**我们一起来看看这五大理由。**

![](../Images/c97e457ec7c7cc8d9b466526a9f993ab.png)

  

***1***

**连接管理智能化，全球连接，一点服务**

  

  

智能连接管理是CTWing平台的基础核心能力，可面向全球客户提供智能化的物联网实体卡、虚拟卡、专用网络等智能化连接管理能力，可帮助客户快速定制并运营自有业务，管理卡的整个生命周期。

  

平台支持CDMA、VoLTE语音和短信业务，可进行定向语音、短信及大量断网、限速等连接控制，具备卡连接状态诊断等功能以及资费的配置、监控与业务查询办理等自助服务功能；平台还具备多种API，帮助客户二次开发。

 

![](../Images/bf9456f48f1e1f8f760ba799aca04aa8.png)

 

此外，平台还可提供B2B2C、定位服务、行业短信等增值服务以及国际eSIM、国际漫游等国际业务，并可提供VPDN、定向短信、定向流量、机卡绑定等多种服务，助力客户连接安全。

***2***

****应用使能平台化，降低开发门槛****

  

  

中国电信CTWing 应用使能能力板块，为物联网开发者构建了敏捷的开发服务平台，提供多种开发方式和工具，大幅降低了物联网产品开发门槛。

 

平台可提供一站式托管服务，用户可享受数据从采集、处理到存储的一站式服务。

 

平台具备 “终端管理”、“数据管理”、“规则引擎”等多项PaaS能力，支持8种主流物联网协议，具备完整的设备生命周期管理功能、安全可靠的数据管理等能力。

 

CTWing平台可对设备进行数字化建模，形成物模型，作为物联网开发的数据标准，提高开发的敏捷度。

 

![](../Images/9adb397f8db5dada17c78f56673e2ca3.png)

CTWing平台还构建了应用、终端的线上、线下闭环交易流程，帮助客户实现产品的加载、受理和售卖。通过云资源虚拟化技术，中国电信推出了天翼云与CTWing的融合产品，目前已上架云主机等12款云产品，可用于在CTWing上开发的应用部署、数据存储或其它用途。

 

此外，CTWing的应用使能服务能力还支持集约、分布式、私有化等多种服务方式，可根据客户需求灵活定制服务架构。

 

***3***

****端到端安全保障，信息交互更可靠****

  

  

CTWing平台继承了运营商服务高可靠、高安全的显性基因，具备高等级安全资质，融合了多种国密安全能力保障信息安全，平台可提供TLS/DTLS加密通道服务，并具备SM9认证和SIM ID认证等终端安全认证能力，可保证终端与平台之间可信可靠交互。

![](../Images/845de7f8c530c6910c3561bcdb07ec64.png)

CTWing运行于中国电信的天翼云之上，借助天翼云的强大能力，CTWing可提供7×24×365的全天候高性能服务，并依托天翼云的全国资源池，为客户就近服务，保证服务质量。

 

***4***

******终端接入便捷化，开发更简单******

  

  

CTWing 平台可提供标准接口、SDK及开发板等多种终端开发方案，帮助开发者快速对接平台。中国电信还与模组厂家联合推出了嵌入平台协议和SDK的通信模组，进一步简化终端开发工作，助力开发者快速实现终端与平台对接。

 

CTWing配套推出了由基板（MCU开发板）+传感器板+通信板组成的“积木式”终端开发板，是一种灵活性高、可扩展性强，成本低的开发方案。

***5***

****融入AI、视频能力，前沿服务更智能****

  

  

CTWing平台构建了开放式的能力汇聚、服务架构，实现了多种能力的汇聚、开放，平台用户可方便地开通、使用平台能力服务。

 

基于该架构，中国电信布局了AI、大数据、视频等多种前沿能力，形成了大数据湖、AIoT平台、视图云等能力板块，可提供AI语音/语义识别、车牌识别、人像识别、视频/图像存储、大数据分析等多种前沿能力服务。

![](../Images/33cb12dd3a49615e51fce0bf129fd33d.png)

中国电信积极拥抱新技术，在前沿技术领域秉承开放共赢的态度，未来将持续与AI、边缘计算、区块链、虚拟现实等领域的合作伙伴深度交流，通过CTWing实现能力的融合与输出，向客户提供更丰富的高新技术能力服务，帮助客户提升产品价值。
