# 全球物联网3A格局：AWS、阿里云IoT 引领Gartner发布的2020年全球物联网市场格局报告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTA4MzA0MA==&mid=2454921371&idx=1&sn=1bf88b8a1114208983b3f9e75cc98518&chksm=b1676dd48610e4c2047260003d4bdcbf10a16cf3195457d5dd414784ca0c4ab6da7eca1981a7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5OTA4MzA0MA==&mid=2454921371&idx=1&sn=1bf88b8a1114208983b3f9e75cc98518&chksm=b1676dd48610e4c2047260003d4bdcbf10a16cf3195457d5dd414784ca0c4ab6da7eca1981a7&scene=27#wechat_redirect)

近日，国际知名调研机构Gartner发布最新全球物联网平台竞争格局报告, 阿里云等成为最具竞争力的10家企业。Gartner 报告显示，**阿里云在物联网市场表现强劲，**提供了百亿级IoT设备的连接能力和上万个行业解决方案，已覆盖智慧城市、工业、医疗、航空等多个领域。

![](../Images/970456eb4dec5a109d6b1c3f98579951.png)

在这份最新《竞争格局：物联网平台供应商》年度调研报告中，Gartner对上百家科技公司进行分析，从产品格局、技术优势、生态布局等视角和维度进行对比，最终筛选出十家企业：**AWS IoT、微软Azure IoT**、**阿里云IoT****、**Automation Intellect 、AspenTech、CloudPlugs、Samsara、Samsung SDS、Toshiba、Tuya Smart。

  

不出意外，在云计算市场占据第一梯队的3A——亚马逊 AWS、微软 Azure 和阿里云也出现在该格局中并占据强有力的地位。亚马逊AWS 侧重在工业IoT领域，微软Azure重点投入制造业、能源、建筑等，而**阿里云IoT则聚焦在解决城市、交通、工业、医疗等领域的复杂跨域应用。**

对于阿里云IoT在物联网的竞争力，Gartner的评语是：

![](../Images/0f7e6919c0777741dec7cf0b2d96211f.png)

阿里云的竞争优势，在于它能将阿里巴巴集团的生态系统和能力 (如电商、金融、物流、云计算等) 整合到其物联网解决方案产品和市场进入策略之中。截至2019年，其物联网市场**拥有1万多个生态系统合作伙伴**，涵盖独立软硬件开发商、嵌入式制造商、行业解决方案提供商等，提供**超过2万个物联网解决方案和应用**。

  

阿里云瞄准建筑、园区、社区和城市等大规模物联网使用场景，借助其端到端物联网能力和内部解决方案团队，让更加精通各个领域的行业合作伙伴切入各个高度专业的物联网使用场景。

  

通过与物联网紧密交织在一起的计算和AI能力，阿里云建立了自己的竞争优势，着重**解决智慧城市、交通、工业、医疗、航空等领域的复杂跨域应用**，尤其擅长那些需要结合物联网数据和其他数据源、需要强大洞察信息支持的场景。
