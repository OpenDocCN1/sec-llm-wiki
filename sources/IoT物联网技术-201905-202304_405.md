# 美团，杀回共享充电宝！不为赚钱，只为抓住流量入口，拉新获客！

共享经济来到2020年，曾成功让**国民老公吃翔**的**共享充电宝模式已经跑通**，整个行业已经成熟，美团也终于等到了最佳的入场时机。

  

在过去的几年里，街电、小电、来电、怪兽充电迅速完成市场布局，形成了“**三电一兽**”的规模矩阵，并相继宣告盈利。TrustData数据显示，2019年街电、小电、怪兽、来电的市场份额分别为**28.6%、27%、25.1%和15.6%**，四家头部企业占据90%以上市场份额。

![](../Images/f7cad45cec3d04deac311a2524d21580.png)

来源：艾瑞咨询  

  

目前，美团共享充电宝项目已经开始疯狂地推活动，拉起了新一轮百城大战希望通过最擅长的人海战术快速实现美团共享充电宝的线下覆盖率，谋求打破三电一兽的格局。

![](../Images/34ebecfb30bf6a33427b28413340f47c.png)

  

美团APP已经支持通过扫一扫入口，进入共享充电宝租赁页面。用户的“美团信任分”需要达到一定分值，就可以享受免99元押金的优惠政策，同时还需要开通免密支付。在计费方式一栏，美团共享充电宝的收费标准为1.5元半小时，20元/天，封顶99元。

![](../Images/4db06b2effaa4d38dd27e420d8d78e67.png)

正如王兴所说：美团是没有边界的。

这一次，美团会再度成为共享充电宝行业终结者吗？
