# 消控宝-数字消防监控IoT物联网解决方案

消防通道占用造成的人身和财产损失的事件时有发生，河南、浙江、江苏等多地出台专项整治方案，以下场景可利用消控宝轻量级套装快速解决消防隐患大问题。

  

基于阿里云IoT物联网技术，打通消防“生命通道”。人工智能算法加持普通摄像头，智能识别消防通道占用、消控室人员离岗或睡岗等行为，杜绝消防隐患。

  

****1****  

           **消控宝解决方案**

  

**全过程感知**

隐患产生、隐患持续、隐患解除全过程实时消息推送，第一时间跟踪隐患处置情况

  

**隐患实况直播**

管理人员可在钉钉端实时查看现场视频，了解现场情况，及时调度响应

  

**关键信息存证**

隐患持续时间、报警时间、解除时间等处置全程关键信息存证，事后追责有依据

  

**消防隐患统计**

隐患数据定期统计推送，消防隐患心中有数

**杭州某智能小镇管委会 **面向小镇重点区域16幢建筑及5个消控值班室安装部署消控宝视频监控设备，实现隐患快速识别定位，15秒内触达消防责任人，处置过程全程留痕可追溯。解决小镇日常消防隐患依赖人工巡查，效率低、响应慢的弊端，帮助小镇实现数字消防新模式的探索，实现防火、灭火从被动响应向主动预防转变。
