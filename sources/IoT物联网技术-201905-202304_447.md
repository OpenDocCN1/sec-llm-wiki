# 《Azure IoT Hub 入门系列》- 概览

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTA4MzA0MA==&mid=2454920908&idx=1&sn=f8ad52efe3a00f7b2853cacced9e6891&chksm=b16753838610da959dd86d9a9f08688442b63c0a5472ea91048d573be15c02c0120b637244fa&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5OTA4MzA0MA==&mid=2454920908&idx=1&sn=f8ad52efe3a00f7b2853cacced9e6891&chksm=b16753838610da959dd86d9a9f08688442b63c0a5472ea91048d573be15c02c0120b637244fa&scene=27#wechat_redirect)

Azure 上的物联网产品涵盖了从设备接入到设备和云、云和设备的双向通信、数据在云中的存储、分析及最终的数据展示，使用Azure上的物联网产品进行组合，可以完成简单的或者复杂的物联网解决方案。

  

本文第一篇主要介绍Azure上的物联网产品概况，后边连续七篇介绍了Azure上最主要的物联网产品Azure IoT Hub，共分为7个章节，每个章节都带有10分钟左右的视频讲解和实际操作。

  

#### **1.了解Azure IoT Hub **

*   可缩放网关，解决海量设备双向通讯的问题；
    
*   提供证书，SAS令牌保证通信安全；
    
*   路由设备数据，通过可配置的规则，将设备到云的消息导流到不同的终结点；
    
*   提供设备管理的能力；
    
*   SLA 99.9%；
    
*   其他：便于开发，多种SDK，原生支持Azure很多其他产品等等；
    

#### **2.设备发送消息到云端(d2c)**

*   了解C2D/D2C消息；
    
*   了解IoT Hub中Device的概念
    
*   了解并下载Device SDK
    
*    使用Device SDK 向云发送遥测消息（模拟温湿度）
    
*    查看发送的数据
    

  

#### **3.使用消息路由将原始设备数据记录存档**

*   理解什么是消息路由，为什么要用消息路由
    
*   消息路由的类型
    
*   配置一个到Storage的消息路由，将原始设备消息存储到blob
    
*   配置一个到Storage的消息路由，当温度>30°C时，才存储下来
    

  

#### **4.设备上传日志文件/图片到 Azure Storage**

*   了解IoT Hub中文件存储在了哪里
    
*   使用Node.js Device SDK 上传TXT文件
    
*   在Storage中查看IOT设备上传的文件
    

  

#### **5.云发布消息到设备（direct method）**

*   了解云到设备的消息种类
    
*   了解Direct Method的使用场景
    
*   使用Direct Method方式在云端向设备发送控制指令
    

  

#### **6.了解设备孪生（device twin）**

*     服务端根据设备ID=”device01“ 修改tag，设置为region=”浦东“,plant="张江高科技园区"；
    
*     服务端查询plant=”张江高科技园区“的设备并将deviceid列出来；
    
*     设备通过reported属性修改connectivity=”cellular“   （当前联网状态为 移动网络）
    
*     服务端查询reported属性修改connectivity=”cellular“，并列出device id。
    

  

按照本系列文章学习，您可以快速入门Azure IoT Hub以构建大型物联网应用。
