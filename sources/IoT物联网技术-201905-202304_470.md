本文带领大家快速了解IoT物联网平台产品创建，设备注册，设备接入，数据上报，下行指令接收等功能。

## 1\. 准备工作

### 1.1 注册阿里云账号

浏览器打开 https://aliyun.com ，开通阿里云账号，并通过支付宝实名认证。

![](../Images/46ac732b47adbb520c66166ad5b5562f.png "image.png")

### 1.2 免费开通IoT物联网平台

在产品分类，找到物联网平台，进入产品官网，立即开通。

https://aliyun.com/product/iot

![](../Images/bbf358474dfce3cd4e8f7bbae00843fb.png "image.png")

## 2\. 控制台操作步骤

### 2.1 创建产品

进入物联网平台的**控制台**，**创建产品**。

所属品类选择**自定义品类**，数据传输选择**JSON格式**

![](../Images/4491416a6f1fc7524c0533e096509813.png)

  

### 2.2 产品功能定义

在**产品详情**页面的**功能定义**选项卡，添加**自定义功能**。

![](../Images/fac990c2676bc5e7bcda8c6813343b8d.png)

自定义功能定义包括

*   **属性**：**温度，湿度**；
    
*   **服务**：**开灯**；
    
*   **事件**：**温度过高报警**。
    

![](../Images/69738f67fbb532e362ba3ff364d829d6.png)

  

这里我们也可以**导入物模型**。

点击 **阅读原文** 获取 完整物模型JSON。导入前需要替换对应的产品productKey。

![](../Images/dc8d4c7e376707b38e3d58c8c549f7e9.png)

  

### 2.3 注册设备

在产品下注册设备，获得身份三元组，如下图。

![](../Images/2e9891a84a6ba389b75dc6417b0c339b.png)

## 3\. 微信小程序操作                  

### 3.1 设备上线

我们打开微信，**扫描小程序码**，进入小程序。

输入设备身份三元组，点击**设备上线**。

如下图，可以看到设备状态为**在线**，小程序log和设备详情页面 最后上线时间一致。

![](../Images/9c1ee94bb78fbaaa0d1b83c11d001098.png "image.png")

### 3.2 上报数据

在小程序界面，点击数据上报，我们看到模拟器**上报当前湿度，温度值**。

在控制台设备日志也可以查到本次消息详情，如下图。

![](../Images/730fb5f3736b7d3569378556c45061c8.png "image.png")

同时，在设备详情的**运行状态**，也能实时看到设备上报的数据。

![](../Images/e30fe6c2128dadf869ede692f2137c15.png "image.png")

### 3.3 订阅主题和数据下行

1.  在小程序界面，点击 **订阅主题**；
    
2.  然后我们再去控制台，**设备详情**页面的 **Topic列表**；
    
3.  找到对应的topic，点击**发布**消息。
    
4.  在发布消息页面，填写**消息内容**，点击**确认**。
    

我们就会看到在小程序端收到IoT控制台推送的消息，如下图。

![](../Images/a9327d3bb4bbd3dcd0b90b52d3cab20f.png "image.png")

同时在**日志服务，设备下行日志**，也可以看到完整的下行消息。

![](../Images/e24206105afc2489c94cab4449fe5529.png "image.png")

  

### 3.4 物模型-服务调用

在控制台的**在线调试**界面，我们选中小程序设备，选中功能**开灯(switch)**，输入参数{"status":"on"},点击发送命令。

小程序的灯，就会变亮。如下图。

![](../Images/266d2f1fa88bed43f50ba1435e80086d.png "image.png")

```
注: status选项有：on ,off ,blue ,green
```

![](../Images/2f7a2693508acb9887ce9c652eb470fe.png)

在**设备详情**的**服务调用**选项卡，也可以看到服务调用记录。如下图。

![](../Images/eb662be4a82dcbd3d2116cf5c3dc53c3.png "image.png")

### 3.4 物模型-事件上报

我们在小程序界面点击**告警**，就会生成一条事件告警。

在**设备详情**的**事件管理**选项卡上报当前的温度。如下图。

![](../Images/8b3444de8d68535ef314416008dd392e.png "image.png")
