# 南方电网 借助AIoT打造数字电网

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTA4MzA0MA==&mid=2454920392&idx=1&sn=30e56c99840685ec331682f749fa88a5&chksm=b16751878610d891c6e7e0b9eae37aa024225868401aeb89435d60d99833ffec4429dbecb621&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5OTA4MzA0MA==&mid=2454920392&idx=1&sn=30e56c99840685ec331682f749fa88a5&chksm=b16751878610d891c6e7e0b9eae37aa024225868401aeb89435d60d99833ffec4429dbecb621&scene=27#wechat_redirect)

7月22日，**南方电网数字电网研究院**

在广州挂牌成立，

成为**全球首家数字电网研究院**。

  

南网数研院是专注于智能化、数字化、信息化的高科技企业，将加快推动智能电网、数字南网建设，为南方电网公司生产经营、管理和发展提供全方位的网络安全和数字化支撑与服务。

  

当今，云计算、大数据、物联网、移动互联、人工智能等新技术迅速崛起与融合，形成推动社会变革的重要力量。南方电网公司敏锐地抓住时代机遇，从顶层设计、组织架构优化调整等多方面入手，布局数字化转型，推动公司向智能电网运营商、能源产业价值链整合商、能源生态系统服务商转型。

  

“数字技术的突破将颠覆传统电网的单一业态模式。”南方电网公司数字化部主任娄山表示，南方电网公司将运用云计算、人工智能、大数据、物联网等先进技术，改变企业生产、管理和服务模式，实现数字经济和平台经济的进一步发展。

**【智能配电网在2秒内实现“自愈”】**

![](../Images/f121b197f0deed819f1683c2a2d4ad24.png)

（刘世辉 摄）

依托国家863项目“智能配电网自愈控制技术”，全国首个智能配网自愈系统在广东佛山金融高新区投运，从停电到复电仅需2秒钟，供电可靠率达99.999%，吸引了美国友邦保险、日本富士通数据中心、中国人保南方信息中心等260余家知名企业落户。

![](../Images/f15b85cbce1c18053061d63c954ad1ab.png)

**【大数据也能“发电”】**  

**![](../Images/a43f303fda04eecec7e8846a44176a29.png)**

（刘德欣 摄）

  

在广东云浮500千伏卧龙变电站，搭载着激光雷达设备的固定翼无人机展开快速、远距离线路通道巡视。在机巡过程中，会对线路实现可见光、红外影像、高精度位置信息等大数据积累。通过对无人机回传数据的分析，实现设备状态可测量、可分析、可预判。

![](../Images/9bca2a0803085442a3b556d7148bdabd.png)

  

**【从40分钟到5分钟】**

![](../Images/4758d83f562efa4674cdf1e541c22d56.png)南方电网广东东莞供电局实现全国首例变电站5G远程控制无人机定点巡航，极大提高了停送电操作效率，操作时间从人工模式的40分钟缩短至5分钟以内，开创了变电站操作无人化的新模式。

  

**【智慧路灯亮了】**

**![](../Images/ff64330f4c91b4b211c795991ed04f11.png)**

![](../Images/778192c3014b128f5b22656a8fab6c2d.png)

近日，广州天河南二路一批新式路灯亮了。这些路灯保留了原有照明功能以外，加以“智慧”改造，可进行路况查阅、连接WIFI，搜索城市信息等操作，某些灯杆还配备了电动汽车直流充电桩。智慧路灯杆作为微基站的优质载体将为未来5G网络布局提供最佳途径，为广州进5G网络试点城市和智慧城市建设奠定了基础。

  

**【**“**最聪明”的变电站】**

![](../Images/3a5989d0cdaca98c06605a36519c4ead.png)

![](../Images/7711b3cacddb6728f784435a5bfc2ed8.png)

（汤子隆 摄）

南方电网广东中山供电局500千伏文山变电站同时投入4个智能巡检机器人，实现站内运维智能全覆盖、24小时运维。该变电站还高度集成监测、巡视、操作、维护、检修、安防、新能源等多领域的智能化技术。

![](../Images/700017f07080c40f48a63f0491506520.png)

  

**【湾区发展，电力先行】**

![](../Images/55ae427f2b419adb190a752a2ec293b2.png)

（黄志伟 摄） 

2019年3月，《南方电网公司关于服务粤港澳大湾区发展的重点举措》发布。紧紧围绕粤港澳大湾区“充满活力的世界级城市群、具有全球影响力的国际科技创新中心、‘一带一路’建设的重要支撑、内地与港澳深度合作示范区、宜居宜业宜游的优质生活圈”战略定位，提出了全力服务大湾区发展的26条具体措施。

  

![](../Images/391cf3f4ed84eb10d9d28e8109df95c4.png)

广东东莞松山湖综合能源示范区借助云计算、大数据、物联网、智能控制等先进技术，结合分布式能源电源布局、企业用户的供用能需求以及电动汽车运营要求，建立起集网络化、信息化、智能化于一体的能源信息共享平台。

![](../Images/8f9c8e70a814a7c140d6f4fc0420eb4d.png)

**2019.7  南网云平台上线** 

作为支撑南方电网数字化转型和数字南网建设的重要基础平台，南网云平台上线是南方电网实现云化、服务化、开放式IT架构升级的关键举措，为业务上“云”打下基础。
