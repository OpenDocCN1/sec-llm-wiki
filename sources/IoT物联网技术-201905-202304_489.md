# 《5G，未来已来》工信部5G宣传片

2019年6月，中国工信部向中国移动、中国联通、中国电信、中国广电颁发5G商用牌照，标志着我国正式步入了5G商用元年。  

《5G，未来已来》宣传片正式发布

📹 [https://v.qq.com/iframe/preview.html?width=500&height=375&auto=0&vid=w0890h0gu0m](https://v.qq.com/iframe/preview.html?width=500&height=375&auto=0&vid=w0890h0gu0m)

宣传片从小儿子捷克考古展开，依托于5G AR考古，5G网络与AR技术的结合，让考古变得更加科幻和有趣，古生物能够跃然于眼前。

  

通过5G网络，身在捷克小儿子可以直接与伦敦实验室进行远程视频通话，完成考古交流。

  

画风一转，身在河北的老爸通过5G网络与二儿子进行了视频通话，并且基于5G网络打造的智慧家庭成为了新的智慧大脑。

  

接下来在中国云南的一处课堂上，身在北京的老师依靠5G远程课堂完成一次形象生动地智慧化授课，智慧工厂、智慧能源、智能制造、智慧畜牧业、智慧农业、智慧交通、智慧港口、智慧物流等成为了现实。之后，大儿子乘坐5G自动驾驶的汽车接女儿放学，在车上，自己可以继续处理手里的工作。

  

在老爸的生日晚餐上，身在捷克的小儿子打来远程电话，用口琴为父亲献上一曲生日歌。

  

5G可以为我们带来更为智慧的生活，也可以让我们的亲情连接更加方便，不管在哪里，都好像就在身边。5G就是这样，可以让社会、生活更美好！
