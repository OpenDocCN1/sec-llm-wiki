# 网络安全的未锁之门：汽车后市场

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2MDk1Nzg2MQ==&mid=2247485372&idx=2&sn=fa9b8f36d7b00d3d9ffb369e8d268ddc&chksm=fc015776cb76de60ce419dcc45fbbe7b3e1f18fd5f4026486fc2649f8ad8cde503e8426f841d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU2MDk1Nzg2MQ==&mid=2247485372&idx=2&sn=fa9b8f36d7b00d3d9ffb369e8d268ddc&chksm=fc015776cb76de60ce419dcc45fbbe7b3e1f18fd5f4026486fc2649f8ad8cde503e8426f841d&scene=27#wechat_redirect)

“白帽”黑客通过售后汽车报警系统远程渗透车辆控制系统的成功，在网络安全界发出了新的警告。  

  

专家说，去年由英国一个研究小组进行的黑客攻击清楚地表明，可能必须征集整个汽车供应链，以确保未来的汽车安全-包括Tier 2甚至是汽配制造商。

  

能够通过汽车制造商无法控制的部件进入车辆，代表着网络安全领域的新局面。进行此类黑客攻击的英国白金汉Pen Test Partners的安全研究员Ken Munro 肯·蒙罗说，售后附加电子产品的广阔且不断增长的市场仍然是一个不受监控的活动领域。

  

蒙罗对《汽车新闻》说：“还有更多的漏洞。”  “以我的经验，原始设备制造商确实已经警醒了。但是他们已经在市场上有很多旧产品。“

  

“我关心的不是原始设备制造商，而是所有供应商和售后市场。”

  

**漏洞**

蒙罗说，笔Pen Test Partners通过加利福尼亚州Vista的Directed Electronics的警报系统以及俄罗斯的Pandora汽车警报系统入侵了车辆。Directed的产品包括在美国出售的Viper品牌汽车警报器。

  

Pen Test通常将所谓的“渗透测试”作为服务提供给希望对其安全性进行测试的公司。但是蒙罗说，他的公司不是为了客户而是为了挑战而入侵了汽车警报器。

  

Directed Electronics 电子公司在书面声明中说，Pen Test已将其漏洞通知了它。潘多拉汽车防盗系统无法置评。

  

定向电子产品市场总监Chris Pearson在书面声明中说：“我们感谢Pen Test Partners等组织的努力，使我们注意到此事，我们很高兴能够迅速成功地解决该问题。” “问题很快得到纠正。”

  

Directed Electronics表示，它相信 “没有暴露任何客户数据，并且在存在此漏洞的短期内，没有未经授权就被访问的任何帐户”。

  

Pen Test在为不同的汽车制造商和模型配备了研究人员购买的汽车警报器之后，在一项受控实验中进行了这项研究。

  

**Hacking结果**

  

结果因车辆和警报器品牌而异。但是，一旦系统遭到黑客入侵，研究人员便可以实时定位车辆。识别汽车类型和所有者的身份；禁用警报；解锁车辆；可能会窃听车辆的乘员；Munro说，在某些情况下，即使车辆在行驶中，也要杀死发动机。

  

以色列Hod Hasharon的Karamba Security董事长David Barzilai表示，Pen Test黑客行为并不令他感到惊讶。他说，安全黑客永远不会停止尝试对任何连接的设备进行任何不受保护的访问。

  

Karamba设置了Barzilai所谓的“蜜罐”诱饵，从而收集了有关黑客活动的情报，这些诱饵没有安全保护或容易猜到的密码连接到Internet。他说，在一个月内，每个诱饵记录了超过30万次骇客企图。

  

几乎可以肯定，所有这些尝试都是通过自动方式进行的。Barzilai说，黑客不一定知道他们要侵入哪种设备。但是，一旦机器人黑客获得了对设备的访问权限，任何运行复杂程序的设备（例如车辆中使用的程序）都将成为目标。

  

Barzilai说，Karamba的安全技术将于今年晚些时候投入其首批量产车辆中。他拒绝透露OEM客户。

  

另一个以色列供应商特拉维夫的Argus网络安全公司的营销总监Monique Lance莫妮克·兰斯说，她知道Pen Test的黑客行为。Argus是Elektrobit的一部分，Elektrobit由全球1级供应商Continental AG拥有。

  

兰斯说：“这只是增加连接性使OEM面临越来越高风险的另一个例子。” “这是对所有OEM的警告信号。”
