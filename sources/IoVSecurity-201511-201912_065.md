# AliOS互联网汽车操作系统安全思考与实践

整个汽车行业正在进行一个前所未有的产业升级的过程，这个过程其实和智能终端的产业升级过程十分相似。汽车变得越来越智能，网联化、智能化、共享化也成了各大主机厂和供应商在技术演进上的一个大的趋势。  

在由GRCC主办的“第四届中国汽车网络信息安全峰会”上，来自阿里 AliOS的高级安全专家钟伟先生为我们讲解了互联网汽车操作系统安全思考与实践。

![](../Images/3ff2b458468d5d1f694039c01d0dc49e.png)

在这样一个大的背景下，汽车本身也在发生着非常大的变化，从硬件的角度来讲，从传统的电子电路到现在的智能网联车身结构变得越来越复杂。一辆互联网汽车会拥有上百个ECU，更复杂的车内部件和更多的外部接口，这些外部接口既包括蓝牙、WiFi、NFC等这些进程通讯接口，也包括通过T-BOX里面的信息模组和远程的服务来实现互联的数据服务。在软件的维度上像车机、T-BOX、网关以及其它一些ECU它们上面的操作系统其实各不相同，整体呈现出一个异构计算的特征。同时越智能的ECU上面的软件规模越复杂。总体来说车的功能在迅速的升级，系统复杂性也在持续的提高。在安全的角度上来讲复杂性和安全性是相互矛盾的。体统的复杂化也带来了信息安全危险的持续提升。

因此，车辆的安全问题越来越受到整个行业的普遍关注，更多的厂商投入到车的安全实验当中来。目前主要通过问题驱动的方式来推动车在信息安全防护能力上面的提升。接着钟总为我们展示了一些关于车的安全实践相关案列。在安全行业重要的一面是通过技术类的攻击来获取商业上的利益。例如：通过刷隐藏低成本的开启只有高配车型才具备的功能。通过刷ECU来改变汽车公里数等。随着车的功能不断变化（如共享化）这种攻击会随着核心利益的迁移来快速演变。

首先钟总为我们演示了常见漏洞发现与利用过程和网联车攻击威胁分布。

![](../Images/7cdd4f59f59e157c37a56bae9b854ad6.png)

  

![](../Images/b5e25f4216ad9f5b33c8cf8f7b4862ce.png)

互联网汽车安全能力要素：在覆盖全面性上：1、智能与车辆网联密不可分。2、车机、TBOX、APP、TSP各智能节点需要分别覆盖3、从设计开发到生产运维需要全流程覆盖。在防御基础性上：1、亿级代码规模彻底消除漏洞的工程不可达性。2、缓解机制差异决定系统防护能力强弱。3、防御能力需要面向设备特点

针对性部署。在感知关键性上：1、部署的能力在实际车辆上否达到了预期效果？2、哪些用户的车辆可能已经不安全，需要尽快维护？3、感知威胁是安全运维的基础。

![](../Images/c09a342b77a83ee8b0334539b89be60a.png)

然后钟总给我们讲解了操作系统及支撑服务安全能力要求和操作系统及支撑服务漏洞检测。操作系统及支撑服务安全能力要求：1、在防御能力技术要求上：完整性保护能力要求、系统和用户数据保护能力要求、应用沙箱和权限控制能力要求、漏洞缓解机制能力要求、入侵检测与主动防御技术要求、漏洞修复及时性要求。2、在安全运营能力要求上：安全日志格式、安全事件定级、威胁感知可视化能力要求、风险处置能力技术要求、车用应用安全检测要求、车用应用市场安全防护要求。3、在接口与通讯安全要求上：密钥算法与强度要求、密钥存储安全要求、密钥访问环境安全要求、密钥与数据传输安全要求、密钥生成与配发安全要求、PKI体系覆盖要求。4、在系统云服务安全要求上：基础设施隔离技术要求、主机安全防护能力要求、应用安全防护能力要求、DDOS安全防护能力要求、主机安全访问能力要求、异常检测能力要求。

![](../Images/6271eb55c851e5e554ede191a9885db9.png)

操作系统及支撑服务漏洞检测：1、在系统基础漏洞检测上：系统固件及配置篡改漏洞检测、固件更新漏洞检测、可调试漏洞检测、密钥泄漏漏洞检测、权限失控漏洞检测、已知存量漏洞检测。2、在接口与通讯漏洞检测上：接口访问鉴权类漏洞检测、密钥硬编码漏洞检测、链路劫持漏洞检测、通讯凭据泄漏漏洞检测、通讯链路传输漏洞检测、重放攻击检测。3、在应用环境漏洞检测上：敏感数据泄漏检测、敏感日志泄漏检测、功能和服务未授权漏洞检测、核心算法和逻辑泄漏检测、文件下载替换漏洞检测、逻辑漏洞检测。4、在系统云服务漏洞检测上：身份与访问控制漏洞检测、边界安全漏洞检测、XSS检测、文件相关漏洞检测、Web注入漏洞检测、服务信息泄漏漏洞检测。

![](../Images/add2fea0f8e459772d4f3605583bb780.png)

最后钟总为我们介绍了阿里的AliOS网联车安全防御体系和智能网联汽车安全能力：1、在系统软件加固上：通过系统原防御和缓解机制控制漏洞可影响范围。2、在端到端安全防护上：IVI、T-Box、Gateway、App之间安全可信互联。3、在TSP安全防护上：防⽌TSP被攻破后导致全车辆受控。4、在供应链安全防护上：⾃动化检测来自不同供应商、渠道、应用市场的漏洞与恶意代码。5、在威胁感知上：实时感知全网车辆风险。6、在OTA上：快速修复安全漏洞，缩小攻击时间窗口。7在持续安全渗透上：以远程非接触车控为目标的持续渗透。
