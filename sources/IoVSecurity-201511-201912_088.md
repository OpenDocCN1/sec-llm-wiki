# 车联网隐私安全防护

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2MDk1Nzg2MQ==&mid=2247484792&idx=1&sn=622c511626bd8a15024d6ce260921bae&chksm=fc0155b2cb76dca4706ea2ce464a74be62c628bbb6053970b03ac89da1ecb041e8762a57211c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU2MDk1Nzg2MQ==&mid=2247484792&idx=1&sn=622c511626bd8a15024d6ce260921bae&chksm=fc0155b2cb76dca4706ea2ce464a74be62c628bbb6053970b03ac89da1ecb041e8762a57211c&scene=27#wechat_redirect)

  

广义的信息安全网络可以分为车内网络和车外网络两个部分，车辆网络是由网关将内部网络和外部网络隔离，内部网络主要是各种成像网络，包括LIN网络、MOST网络和CAN网络，外部网络比较复杂包括云、管、端和传感器等相关网络。车联网结构包括三个部分，分别是路边单元、车载单元和第三方可信权威机构。

由于车联网具有：组网灵活，网络规模不均衡；网络拓扑结构不稳定；无线信道和传输质量的可靠性差；有一定感知、计算和存储能力，能耗的限制较小等特征。导致广播的消息中含有大量隐私信息和车辆运动轨迹可预测性，从而产生车联网隐私问题。

  

![](../Images/81a34e32b009910f5ef5a1d9128e0676.png)

  

  

在“ 2019 第四届中国汽车网络信息安全峰会”上，我们请到了开源网安的车联网安全实验室高级研究员张海春详细为我们讲解了车联网隐私的安全防护。

目前的身份隐私保护方案是：基于对称密码学、基于公钥基础设施、基于身份签名、基于无证书签名、基于群签名等方式的匿名认证方案。这些方案会产生：可信权威机构行为不透明、撤销列表开销太大和认证效率太低等问题。而匿名方案、混合区域方案、基于模糊的方案等位置隐私保护方案，都有相应的问题。基于这些问题张总提出了一种基于区块链的身份隐私和位置隐私保护方案。

通过搭载一个车辆跟踪攻击平台，解决完全匿名化不足以保护车辆隐私问题，根据身份隐私和位置隐私需要达到的一些目标，来做出了基于区块链的匿名认证方案加基于区块链和队列通信的车辆隐私保护方案。这个方案可以保护车辆身份隐私和位置隐私，抵抗车辆跟踪攻击，不影响车联网应用的服务质量，实现条件隐私，可以在发生纠纷的时候便于责任的划分和仲裁。随后张总向嘉宾详细介绍了该方案是如何保护身份隐私和位置隐私的：

  

![](../Images/cece32230a3a41e05edfab50b102a676.png)

  

  

基于区块链的身份隐私保护方案，解决了权威机构透明度问题，保证认证安全性，实现条件隐私，高效的认证效率。方案整体架构分为汽车机构、执法机构和数字认证机构等三大机构。汽车机构是提供一定的计算能力，来实现一个基于工程量证明的一个共识机制。执法机构是审核来自车辆的身份信息，审核通过过后授权给数字认证机构向车上颁布证书或撤销证书。数字认证机构执行颁布或撤销证书。具体步骤如下：首先汽车根据自己的私钥产生能够证明自己身份的消息，然后把这些证明自己身份的信息资料提交给执法机构，执法机构审核过后就会授权数字认证机构颁布证书，所有的证书颁布布和撤销都会作为一个交易存储在区块链之中，并通过扩展的区块链结构来存储整个区块链中的数据。

基于区块链的位置隐私保护方案中：通过隐私调度算法，把大量同车道同方向的汽车形成一个队列，让最前面的汽车成为队长，所有队列的成员不是把消息发给单元，而是把消息发送给队长，队长把消息收集之后进行打包，定期的发送给各个单元。在这种情况下，整个队列对于恶意攻击者来说它的成员是没有任何区别的他是无法区分成员之中的区别，从而达到隐私保护的目的。通过隐私调度算法保证通信过程是安全的。具体步骤如下：车辆加入队列是要进行身份认证的，首先队长对周围广播队列建立就绪的消息，成员接受到消息之后，把自己相关私钥等信息发送给队长，表达加入请求，队长收到请求之后，把相应的请求加入的汽车赋予一个编号，把队内的私钥以及相关的规划秘钥发给队内成员，队内成员收到消息之后把自己的其他消息发给队长作为回复，表示已经确认加入队列。整个数据都是通过签名的，保证整个通信是足够安全的。
