# 卡车和网络安全：创新的关键

网络安全已成为汽车行业的热门话题。自2015年吉普切诺基网络攻击导致召回140万辆汽车以来，形成了AutoISAC，这使得在美国销售的汽车原始设备制造商和一级汽车能够分享网络攻击的最佳实践。

  

然而，虽然乘用车和轻型卡车正在联系，因此成为网络攻击的目标，卡车领先。

  

仅在2017年，就有超过7,210亿美元的货物运往北美的卡车运输，占该大陆所有货运价值的57％以上。这一统计数据说明了卡车运输业的重要性和重要性。货运为世界各地的无数公司和政府机构提供物流支柱 - 也可能成为网络攻击的主要目标。在全国范围内驾驶卡车广泛连接，例如向车队经理报告他们的位置和状态。连接系统总能吸引黑客。

  

今天的长途卡车是一个世界，除了大约十年前推出产品的车队。今天建造的平均长途卡车装满了连接的物联网设备，这些设备可以生成数据，帮助航运公司比以前更智能，更高效地运营。连通性在其他领域产生了重大影响，例如减少驾驶员疲劳，提高安全性和实现燃料的增量节约。这将提供无与伦比的效率，这将为整个国家带来巨大的经济价值。具有如此巨大的经济价值也会带来网络安全风险。

  

智能互联吸引了黑客

黑客卡车甚至更有利可图，奖励甚至比数据中心网络攻击更大。

  

针对卡车的黑客可以获取本地数据，对其进行修改，控制安全组件并从窃取货物中获得经济利益。他们可以执行赎金攻击或窃取公司信息（从卡车进入车队经理数据库）。

  

想一想，如果以70英里/小时的速度控制80,000磅的18轮车在高速公路上行驶可以被远程攻击者超越呢？

  

拥有权利的同时也被赋予了重大的责任

这是网络安全和安全相遇的地方，也是货运网络安全解决方案的新前沿。

  

货运业将网络安全从企业系统全面优先考虑到车辆本身，嵌入式内置网络安全提供适当的安全网。

  

运行时完整性技术可以阻止攻击尝试。从卡车出厂的那一刻起，引入自保护组件的货运架构可以保护联网车辆，而不依赖于连接或恶意软件。运行时完整性侧重于消除远程代码执行（RCE）风险，并在安全组件上自主工作，而不需要依赖统计算法，统计算法由于其启发式主干而无法始终可靠。

  

将先进车辆技术的投资与适当的网络安全技术相匹配，使卡车制造商能够确保车辆安全性和该行业的持续增长。具有开拓汽车和网络安全技术的远见和远见的制造商正在塑造其市场份额并为其汽车运营商提供竞争优势。
