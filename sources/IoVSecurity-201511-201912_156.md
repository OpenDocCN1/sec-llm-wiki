## 车辆E＆E架构特定网络安全功能配置策略

##### “Vehicle E&E Architecture Specific CyberSecurity Features Configuration Strategy”

**智能联网汽车的发展，使得整个汽车行业正面临着安全威胁的严峻挑战。为了保障联网汽车生态系统，我们必须采用最先进的****E****＆****E****架构特定的四层安全概念。**** ECU /****模块特定的安全功能定义（指定义的安全概念）是对汽车行业的挑战。**

**整个****E****＆****E****架构特定的广泛威胁建模提供了安全需求。我们将在已识别的安全需求上应用四层安全方法，指潜在附加路径来定义安全要求。我们提出了一种独特的方法来开发整个****E****＆****E****架构特定的安全概念。这种方法将有助于从整体车辆级安全概念中定义****ECU****特定的网络安全功能。通过这种方法，我们可以以经济有效的方式配置安全性要求，而不会牺牲架构特定的安全性兴趣****/****概念。在添加****/****删除任何车辆的基本功能****/****特征的情况下，安全配置矩阵将允许添加或删除安全功能。****ECU****特定的安全功能可以根据****ECU h / w****功能以及****E****＆****E****架构功能进行定制。**

关于车辆E＆E架构特定安全功能配置策略的详细信息，敬请期待来自TATA Motors的副总经理／网络安全专家Ashis Patra先生在本届ACSS2019的主题演讲 。

  

  

The whole automotive industry is facing the challenge of security threats due toupcoming connected car trends. To secure connected car eco-system we have toadopt state of art E&E architecture specific four layer security concept. **ECU/Module specific security featuresdefinition (w.r.t defined security concept) is a challenge to auto industry**.  

 

WholeE&E architecture specific extensive threat modelling provides securityneeds. We will apply four layer security approach w.r.t potential attach pathon the identified security needs to define security requirement. **We haveproposed a unique approach to develop whole E&E architecture specificsecurity concepts**. This approach will help to define ECU specific cybersecurity features from the overall vehicle level security concept. Through thisapproach we can configure security requirement in a cost effective mannerwithout sacrificing architecture specific security interest/concept. **Security configuration matrix** willenable addition or deletion of security features in case of adding/deleting anyof the vehicle’s basic functionality/features. ECU specific Security featurescan be customized based on ECU h/w capability along with E&E architecturalcapability.
