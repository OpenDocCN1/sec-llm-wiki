# 互联网科技巨头集体进入智能汽车市场 信息安全不容忽视

最近的几年来，智能汽车行业逐渐出现在人们的视线中，该行业的一些变化也时刻吸引着人们的关注。

在今年6月，工信部公布了《国家车联网产业标准体系建设指南(智能网联汽车)(2017年)》，提出根据智能网联汽车技术现状、产业应用需要及未来发展趋势，分阶段建立适应我国国情并与国际接轨的智能网联汽车标准体系。

对此，汽车企业也是动作频出。通用汽车计划于2018年启动无人驾驶出租车的商用；特斯拉已经通过量产车型累计了数十亿公里测试数据；上汽集团的互联网汽车批量进入市场；一汽集团、长安汽车计划2025年量产高度自动驾驶车辆等。

![](../Images/887d00b9fb42c5b076cb344af0a8116a.png)

除此之外，一些互联网和信息技术公司也争相涉足汽车领域，积极地进行产业链和供应链的布局。今年4月，百度宣布实施“阿波罗计划”，发力自动驾驶领域；谷歌则宣布其自动驾驶汽车测试已经超过300万英里；华为联合车企积极地推动5G通讯技术应用；小米也宣布与北汽集团达成战略合作协议，携手打造智能驾驶系统。

![](../Images/cf812e53e0944dda963f913377f8f668.png)

　　随着电子、信息、通信、人工智能等技术与汽车产业加速融合，汽车产品正加快向智能化、网联化方向发展。与此同时，智能网联汽车面临的信息安全挑战也备受业界关注。

**政策暖风频吹 智能网联汽车迎来发展新机遇**

　　就在《建设指南》发布的前一天，6月12日，在工信部指导下，汽车、通讯等多个行业98家单位联合成立了中国智能网联汽车产业创新联盟。工信部表示，将建立部际协调机制，制定智能网联汽车发展的战略规划，起草并出台产业发展整体指导意见。

　　此外，据媒体报道，《中国智能网联汽车产业发展总体推进方案》、《智能网联汽车使用公共道路进行测试的规范》也在研究之中，中国还将进一步打造“中国汽车人工智能2.0”体系。中国智能网联汽车产业初步确定了“三步走”的发展目标，到2030年，汽车DA(驾驶辅助)及以上级别的智能驾驶系统将成为新车标配，汽车联网率将接近100%。

7月28日，赛文交通网创始人兼CEO徐赫在由网秦组织举办的智能汽车安全和系统技术暨智能交通变革研讨会上介绍，2016年8月份，国家发改委和交通部发布了《推进“互联网+”便捷交通促进智能交通发展的实施方案》，这个重要文件对未来十年的交通部署进行了规划。

　　据了解，截至2017年7月，包括新一代国家交通网控制示范工程、智能交通核心技术监测平台及试验外场建设工程、智慧公路示范工程等已经有序地在各地展开工作，相关车辆测试的计划已经排到了几个月之后。徐赫认为，政府正在加大力度推进智能汽车行业的发展，从政策引导和合规保障出发，形成有序的市场发展环境，一定可以让智能汽车企业走得更远。

**迎接行业变革 企业亟需解决信息安全痛点**

　　顶层设计政策体系为智能网联汽车的发展创建了良好的发展环境，与此相关的大数据、云计算、人工智能等也在持续提供着技术保障。

　　与此同时，一个较为显著的问题是，汽车的网联化也极有可能彻底打开了黑客入侵智能网联汽车的通道。智能网联汽车与外部的每个接口都可能被恶意利用，每个控制单元都可能被黑客攻击、病毒感染，智能网联汽车的信息安全防护难度也因之而倍增。

　　据了解，汽车智能化的背后是各功能模块系统控制代码的爆发式增长，仅车载信息娱乐系统的代码量就很容易超过1亿行，而无人驾驶系统的代码量则更是远超2亿行以上。而与代码伴生的代码安全漏洞，则将致使智能网联汽车面临严峻的信息安全挑战。

　　因此，从长远来看，有志于在智能网联汽车领域发力的企业需做好长期的技术规划，以应对未来可能出现的信息安全等问题。行业人士普遍认为，一些在互联网安全领域深耕多年的企业在智能汽车市场或会迎来机会。

　　作为一家从智能手机安全领域起步的企业，网秦现在专注在智能汽车领域，在智能汽车安全服务方面，拥有先天优势。

　　网秦2015年通过投资芬兰的汽车软件与硬件集成方案提供商凌动科技进入智能汽车领域，他们将自己定位于服务者的角色，集成包括提供底层零部件的供应商，与科技公司一起，帮助一级供应商和车厂实现汽车的智能化。据网秦市场总监王宏明介绍，智能汽车具有独立的操作系统，像我们现在所用的智能手机一样，通过各种应用程序来扩展汽车的功能，如果没有底层的防范，会有安全风险。为此，网秦旗下凌动科技会根据企业需求，提供定制化的、安全性的软件+硬件集成服务。

　　凌动科技市场总监兼高级产品经理郭安祺表示，安全是相对的，没有绝对安全的状态。凌动对安全的理解是，安全的实现不是单纯一环的过程，就像自动驾驶不能只依赖一种传感器实现一样，其包含了两个层面的意义，第一是人身安全，人们是不是能够有安全出行的过程，人身在行车过程当中有没有受到威胁，车是不是安全；第二是信息安全，现在联网汽车和手机的互联一样没什么太多的隐私，隐私方面受到威胁。

**行业专家：未来会有更多科技互联网企业入局**

　　目前，汽车的产业结构在慢慢调整，最初主机厂商拥有绝对的话语权，但现在出行公司或一体化的服务公司，像特斯拉，实现了既能够生产整车，又可以提供一系列的数据服务，这种企业对于传统汽车厂商会产生一些挑战，商业模式的变化，导致整个产业结构转变在即。

　　智能汽车行业专家、《建约车评》创始人余建约表示，智能汽车技术上的变革会给行业带来巨大的影响。随着智能汽车时代的到来，硬件制造的附加值将大幅降低，厂商将进入到拥有强大计算力的人工智能的软硬件比拼之中。未来汽车行业内的竞争不仅是传统汽车产业的，也会有大量科技互联网行业入局，共同推动整个产业发展。

　　谈到人工智能技术在该行业的应用时，余建约表示，基于智能汽车所需的强大计算能力，人工智能将会首先在汽车行业得到大规模的应用。与此同时，智能汽车行业的发展还将会给交通设施、住宅市场等带来巨大变革。

　　此前，网秦创始人兼董事长史文勇表示，虽然目前很多科技互联网企业纷纷进入智能汽车领域，但整个市场格局依旧没有完全形成。

“我觉得两三年之后，市场格局形成之后，会有一套新的产业链结构出来，每个参与者均会在这个新的产业链结构中找寻到自己的位置，不管是传统的车厂，还是刚才说的互联网科技巨头，他们都会在整个的产业磨合过程中形成一个新的氛围。”史文勇说。
