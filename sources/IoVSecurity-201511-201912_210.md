# 智能网联汽车面对的七大问题

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2MDk1Nzg2MQ==&mid=2247484838&idx=1&sn=31d59377b817040cef2a7b96e162ec11&chksm=fc01556ccb76dc7aeffe8a3b316cff1e801dc07268385612b320eee6992e35b55e6a20a7b27a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU2MDk1Nzg2MQ==&mid=2247484838&idx=1&sn=31d59377b817040cef2a7b96e162ec11&chksm=fc01556ccb76dc7aeffe8a3b316cff1e801dc07268385612b320eee6992e35b55e6a20a7b27a&scene=27#wechat_redirect)

事件一：查理·米勒和克里斯·瓦拉塞克这两位白帽黑客通过互联网入侵了一辆Jeep自由光行驶过程。

事件二：两位黑客侵入克莱斯勒公司出品的Uconnect车载系统，远程通过软件向该系统发送指令，启动车上的各种功能。

事件三：宝马ConnectedDrive数字服务系统也遭遇了入侵事件，黑客能够利用该漏洞以远程无线的方式侵入车辆内部，并打开车门。

以上的三个独立事件可以看出，智能网联汽车从问世至今，面临着种种考验。一旦别有用心的人攻击了私人智能网联车辆，不仅仅是造成车内财物丢失或者车辆被盗，而且极有可能危及到司机和乘客的生命安全。

![](../Images/003633fcb9d60275dbf3fc6e86a50fbd.png)

近日，360智能网联汽车信息安全实验室发布了《2016年智能网联汽车信息安全报告》，重点对智能网联汽车面临的七种信息安全威胁，包括每种威胁可能引起的黑客攻击路径、攻击方法、造成的安全风险等进行了前沿的技术分析和风险提示。

智能网联汽车遭受的信息安全威胁主要包括ＴＳＰ安全威胁、ＡＰＰ安全威胁、Ｔ－Ｂｏｘ安全威胁、ＩＶＩ安全威胁Ｃａｎ－ｂｕｓ总线安全威胁、ＥＣＵ安全威胁、车内通信安全威胁等七种。同时报告也对每种威胁可能引起的黑客攻击路径、攻击方法、造成的安全风险等进行了前沿的技术分析和风险提示。
