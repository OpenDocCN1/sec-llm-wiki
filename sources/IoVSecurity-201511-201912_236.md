# 现代软件遭到黑客攻击 这只是开始 但不要惊慌

**现代汽车加入到被黑客入侵的汽车制造商名单中。**

有线杂志曾经故意入侵吉普车，而现代才修复了一个不让Blue Link app容易被侵入的漏洞。

  

Blue Link是一个连接的汽车应用程序，允许司机做各种事情，包括远程启动他们的车。从2016年12月至今年3月一个软件漏洞使应用程序让黑客有机会侵入。黑客可以利用这个漏洞来定位，解锁和启动车辆，而Rapid7网络安全公司，发现了这一情况。

  

现代和Rapid7的代表都表示，他们知道在漏洞被修补之前，并没有发生真正的盗窃案件。现代汽车美国发言人Jim Trainor表示：“这个问题对车辆安全没有直接的影响。 “现代并不知道有任何客户受到这一潜在漏洞的影响。”

  

虽然这不是网路黑客在汽车上的第一次攻击，但它并不涉及移动车辆，而是在2015年以后，菲亚特克莱斯勒汽车公司召回菲亚特克莱斯勒汽车出现类似问题。

  

这意味着这是最新的提醒，所有这些新的基于软件的汽车技术可能有一些安全漏洞。虽然原始设备制造商肯定会尽最大努力确保这些问题在导致车辆盗窃之前陷入僵局（或者更糟的是，由于黑客造成的坠机），消费者需要保持清醒能够意识到潜在的风险。

  

没有必要恐慌，但谨慎一点是好事。

  

现在还不是恐慌的时候，但是关注潜在的汽车安全威胁的消息不会有错。通过应用程序的车辆遥控器固然酷炫、方便，但是盗贼和其他凶手将利用软件安全漏洞来进行攻击。
