# 防火墙先驱者为汽车信息安全保驾护航

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2MDk1Nzg2MQ==&mid=2247484854&idx=2&sn=f63a7712ab396e3d4127704ca5966910&chksm=fc01557ccb76dc6a55437c5ebe7c279f78f270fbdb1c4948afc8450126a18c60a8dc0f89991c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU2MDk1Nzg2MQ==&mid=2247484854&idx=2&sn=f63a7712ab396e3d4127704ca5966910&chksm=fc01557ccb76dc6a55437c5ebe7c279f78f270fbdb1c4948afc8450126a18c60a8dc0f89991c&scene=27#wechat_redirect)

以色列开创公司防火墙的网络安全公司正在与汽车行业取得更大的进展。

  

全球第二大网络安全提供商Check Point软件技术有限公司正在为自动驾驶技术和连接汽车在汽车制造商提供更高的安全需求而定位，以增加全球汽车市场的销售额。

  

Check Point将领导一个由阿格斯网络安全有限公司和瓦伦斯半导体有限公司组成的工作组，以制定可设计为车辆电子架构的安全标准。如果工作组正在寻求安全的技术最终被汽车制造商和供应商所采用，那么它可以将Check Point扩大到业界的覆盖范围，超越已经有助于保护的云到车通信。

  

“每个网络安全公司都在关注它，但我不认为他们已经有很多进展，”彭博智能分析师Mandeep Singh表示，Check Point更深入推动汽车行业。 “这是一个很大的用例，但技术还处于起步阶段。”

  

技术联盟

  

该工作组是HDBaseT联盟的一部分，HDBaseT联盟是一个贸易集团，致力于促进瓦伦斯为电信业发明的技术，现在正在适应汽车。其主要优点是能够使用单根电缆将数据丰富的内容（如视频）移动到汽车的网络上，从而降低成本和重量。通用汽车公司是联盟的董事会，戴姆勒公司去年表示，将使用HDBaseT进行信息娱乐，先进的驾驶辅助和远程信息处理系统。

  

随着汽车变得更像计算机，数百万行代码和多个互联网连接，他们对黑客的脆弱性正在增长。这个风险在2015年被强调，安全研究人员表示，他们可能会闯入吉普车，并从高速公路上的司机控制。菲律宾克莱斯勒汽车公司（Fiat Chrysler Automobiles AV）召回140万辆汽车和卡车，这是第一次正式的安全行动，以应对网络安全威胁。
