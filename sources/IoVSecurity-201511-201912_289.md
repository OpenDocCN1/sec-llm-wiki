# 光明日报：为移动互联网业增添政策红利

移动互联网已经成为创新发展新领域、公共服务新平台和信息分享新渠道，催生了许多新兴业态。但移动互联网发展管理中体制机制有待完善、法治建设仍显滞后、政策扶持力度不够等短板也愈发突出。近期中办、国办印发了《关于促进移动互联网健康有序发展的意见》（以下简称《意见》），就是要以问题为导向，从顶层设计上为移动互联网发展赋能纾困，实现其健康有序发展。

　　消除数字鸿沟，为移动互联网培本固元。据工信部统计，到2016年10月末，我国移动互联网用户总数已达10.77亿，使用手机上网的用户数达到10.2亿。网民大国带来发展底气。但增长瓶颈开始浮现，网民红利逐渐消退，导致市场“寒冬”之感；更重要的是，这说明我们还有数亿同胞仍然徘徊在移动信息技术便利大门之外。2015年12月工信部发布“互联网+”行动计划，预计到2018年实现4G网络全面覆盖城市与乡村，80%以上的行政村实现光纤到户。《意见》再次强调，要为人民群众提供用得上、用得起、用得好的移动互联网信息服务，这对于缩小数字鸿沟，激发经济活力，将发挥重要的基础性作用。

　　维护网络安全为移动互联网发展提供良好环境。在我国，乘车出行、网上购物、汽车导航、转账支付，一部手机全能实现。但不容忽视的是，西方国家的网络监控和网络攻击危及国家安全；网络犯罪、网络恐怖主义肆虐，扰乱社会秩序；网络侵犯知识产权和个人信息泄露，侵犯企业与个人权益。因此，《意见》提出牢固树立正确的网络安全观和动态、综合防护理念，坚持以安全保发展、以发展促安全，全方位、全天候感知移动互联网安全态势，不断强化移动互联网基础信息网络安全保障能力。

　　核心技术创新是移动互联网发展重要突破口。我国已成为移动互联网大国，在市场发展上处于领先地位，但并不是移动互联网强国。当前，移动互联网核心和领先技术仍为美国等少数西方发达国家所垄断，不仅导致我们在核心技术上受制于人，也面临其在产品上埋藏后门、偷植木马的严峻安全风险。《意见》正视严峻现实，着重提出，坚定不移实施创新驱动发展战略，在科研投入上集中力量办大事，加快移动芯片等核心技术突破和成果转化，推动各系列标准制定，加紧人工智能等新兴移动互联网关键技术布局，尽快实现部分前沿技术、颠覆性技术在全球率先取得突破。

　　增强法治赋能与制度供给是重要保障。随着网络安全法的通过和电子商务立法进入快车道，我国正逐渐搭建网络空间法治的“四梁八柱”。《意见》对强化法治保障充分重视，明确提出制定修订互联网信息服务管理办法、关键信息基础设施安全保护条例、未成年人网络保护条例等行政法规；建立健全网络数据管理、个人信息保护等重点管理制度；完善移动互联网管理多部门执法协调机制，加快执法信息技术系统建设，提高对网络违法犯罪识别、取证、联动查处打击等能力。

　　在去年的网络安全和信息化工作座谈会上，习近平总书记提出了以人民为中心、更好造福亿万人民的网信事业发展观。《意见》为移动互联网发展添注政策红利，着力保障公民信息权利，提升我国骨干企业、科研机构在全球核心技术开源社区中的贡献和话语权，积极推动核心技术开源中国社区建设，从而真正实现信息惠民，正是对以人民为中心宗旨的生动体现，通过中国发展惠及全球民众。

　　（作者系中国社会科学院中国特色社会主义理论体系研究中心研究员）
