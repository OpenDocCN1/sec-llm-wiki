# 2016年及之后网络威胁前景趋势一览

到 2016年，网络犯罪分子的攻击目标将不再集中于硬件以及固件方面，而安全业界则需要更加努力以应对层出不穷的新型挑战。根据最近发布的《McAfee实 验室威胁预测报告》所言，安全威胁将进一步扩大到虚拟机、可穿戴设备以及其它攻击面当中。这份报告探讨了网络威胁前景趋势的演变方向，并对2016到 2020年的中期安全威胁走向做出评估。

  

这份报告当中包含有33位英特尔Security意见领袖的观点，希望以群策群力的方式帮助企业解决当前存在的威胁及其在未来可能发生的转变，英特尔Security旗下McAfee安全实验室副总裁Vincent Weafer指出。

  

　　即将到来的2016

这份2016预测报告覆盖了多种威胁类型，包括勒索软件、基础设施攻击、车载系统攻击以及面向销售与仓储系统的数据窃取活动等等。

　　• 硬件:尽管市面上的相关设施保护方案不断增加，但面向硬件与固件的攻击活动仍将继续存在。系统固件工具包亦可能会将目标转向虚拟机层面。

　　• 勒索软件:勒索软件已经成为一类持续增长的威胁形式，且主要影响匿名支付方案及网络环境。很多经验积累较差的网络犯罪分子将会选择勒索软件即服务等实现手段。

　　• 可穿戴设备:大多数可穿戴设备只存储一小部分信息，不过网络犯罪分子可能会利用它们破坏智能手机的管理机制。安全业界将需要对网络以及Wi-Fi软 件、操作系统内核、内存、用户界面、存储系统与本地文件、Web应用、虚拟机乃至安全与访问控制软件等潜在攻击面进行保护。

　　• 员工系统:攻击者可能会通过内部员工对目标企业发起入侵，具体途径包括突破员工的家庭安全系统等，从而借道访问企业网络。各企业将需要采取新型安全技术、创造有效的管理政策并启用经验丰富的安全保护技术人才，从而以高度警惕的态度应对这些新兴威胁。

　　• 云服务:攻击者能够利用存在漏洞的安全管理政策对其保护之下的云服务加以入侵。这些服务可能涉及商业策略、金融信息、资产组合战略、下一代创新、员工数据、收购意向以及资产剥离计划等各类敏感性数据。

　　• 车载系统:联网车载系统往往缺少良好的安全保护功能，这也使其成为网络攻击活动的潜在目标。汽车制造商及IT供应商将携手合作，以推出行业标准与解决 方案的办法保护各类汽车之内的攻击面，例如动力总成控制单元（简称ECU）、远程钥匙系统、高级驾驶辅助系统ECU、无钥匙进入、USB、OBD II、V2X接收器、智能手机接入以及远程连接型应用等等。

　　• 失窃数据仓库:在2016年面向失窃个人身份信息及用户名/密码数据的交易黑市将进一步增多。而大数据仓库技术在与失窃个人身份信息集相结合之后，将为攻击者带来极具价值的宝贵记录。

　　• 完整性攻击:针对特定系统与数据的选择性攻击活动已经成为最为可怕的新型攻击手段之一。此类攻击会拦截并修改事务或者数据内容，从而帮助恶意人士获得 收益。攻击者能够变更受害者的工资存款数额，并将多余存款直接转存至另一个账户。根据McAfee实验室的预测，网络窃贼在2016年年内将造成高达数百 万美元的损失。

• 共享威胁情报:各企业与安全供应商将进一步实现威胁情报共享。而通过推出相关法案，政 府能够与企业方面就威胁情报共享建立更为紧密的联系。这方面的最佳实践将持续增加，从而确保成功指标能够不断增长并用于推动保护效果的改善。另外，不同安 全厂商之间的情报共享活动也将有所增加。

  

　　展望2020年

展望2020年，McAfee实验室探讨了安全威胁在表现形式上的转变，其将如何实现、如何调整攻击对象以及安全业界该怎样应对这些挑战。

　　• 操作系统之下的攻击:随着操作系统以及应用程序在抵御常规攻击能力方面的不断增强，攻击者可能会将着眼点转移到固件及硬件层面。攻击者也许会访问资源并获取管理及控制功能的使用权限，从而实现更为广泛的目标操控能力。

　　• 检测逃避:攻击者将通过针对新的攻击面来逃避安全检测。此类难于检测的恶意活动包括加密渗透、非文件威胁、远程shell与远程控制协议利用、沙箱逃避恶意软件。而在操作系统之下的攻击行为中，其目标将主要面向BIOS、主引导记录（简称MBR）以及各类固件。

　　• 新型设备与攻击面:目前指向可穿戴设备与物联网的攻击活动还不太常见，但到2020年此类系统所拥有的庞大安装问题很可能达到足以吸引攻击者的水平。 虚拟化解决方案供应商及技术供应商将努力建立安全指导及行业最佳实践方案。他们还需要在设备架构之内建立起安全控制机制。

　　• 网络间谍活动以企业为目标: 黑客服务与恶意代码在黑市上的自由交易可能会使得网络间谍恶意软件开始逐步转向企业及公共部门，攻击者能够利用这些手段操纵市场走向并收集金融情报。

　　• 隐私领域的挑战与机遇:个人数字化数据的总量与价值将持续增长，并吸引更多网络犯罪分子。这可能引导新的全球化隐私监控升级。每个人都能够通过数据分享获取回报，而从这种“价值交换”机制发展而来的市场可能会彻底改变个人与企业管理数字化隐私的具体方式。

　　• 安全行业应对措施:安全业界将打造出更多切实有效的工具以纠正并检测复杂的攻击活动。行为分析将得到进一步发展，从而识别出那些可能意味着账户已遭窃 取的不合理活动。情报共享则将能够提供更好且更快的保护能力。云集成化安全方案能够增强控制力与可见性。自动纠正与检测技术则能为我们带来保护企业免遭常 规攻击的能力，这意味着IT安全人员可以将精力集中在应对那些关键性安全事故身上。

　　企业必须采取行动

　　要想成功应对未来的安全威胁，各企业必须关注更多、了解更多，同时加快自身对攻击活动的检测与响应速度，Weafer指出。企业必须充分利用全部现有人力及技术资源，而这也是我们惟一能够用来对抗未来安全威胁的有力武器。
