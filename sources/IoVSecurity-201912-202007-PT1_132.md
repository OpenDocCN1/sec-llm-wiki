原标题：深度：苹果干掉车钥匙

文 | 车东西 James

一年一度的苹果全球开发者大会WWDC今天凌晨拉开序幕，在主题演讲中，苹果发布了iOS、iPadOS、watchOS、tvOS和macOS的下一代操作系统，新版操作系统将在今年秋季开放更新。

在此次WWDC大会中，苹果对出行的重视程度提高了很多，总共用了7分半的时间讲述地图、CarPlay以及Car Key的更新。

其中，Car Key的更新最引人注目。在与支持Car Key的车辆配对之后，只需要将手机和门把手轻轻一碰，车门就能打开。将手机放进车内的无线充电板上，车辆就能启动。这项功能将在下个月正式上线，支持这一功能的首款车型是宝马5系，今年7月1日之后生产的除7系外的宝马全部车型都将支持Car Key功能。

如今，手机取代车钥匙已经不是一件新鲜事，但大多数车企都是用蓝牙或者移动网络实现解锁，这两种解锁方式在手机没有电、没有网络的情况的情况下完全无法使用，即便有这样的功能，车主也得带着车钥匙出门。

而苹果则采用了手机内置的NFC芯片解锁车辆，日常使用不需要网络连接，即便手机电量不足已经关机，还能坚持5小时为车辆解锁。可以说，苹果的这一解决方案能够彻底取代车钥匙。

实际上，NFC技术也并不新鲜，如今市面上有许多带有NFC功能的手机，可为什么少有车企做NFC车钥匙呢？苹果优势如何实现这项功能的？未来将如何发展？

车东西采访了多家车企的车联网工程师，得到了答案。

1、百年车钥匙将被手机取代 一碰即开锁

今天凌晨1点，苹果全球开发者大会WWDC正式拉开序幕。苹果发布了iOS、iPadOS、watchOS、tvOS和macOS的下一代操作系统，同时还宣布将在Mac电脑上采用苹果自研的处理器。

在主题演讲中，车东西总结了苹果三大有关汽车的更新，分别是CarPlay系统更新、地图更新、手机变车钥匙。

其中，用手机解锁车门是今年WWDC主题演讲中最亮眼的更新之一。手机轻碰门把手，车门自动解锁，这把“钥匙”还能与最多5个人共享，可以说非常炫酷。

![](../Images/84605da0ae98a6e6b729e458a43e5d82.png)轻碰门把手就能解锁

苹果在演讲中宣布，支持这项功能的首款车型将是2021款宝马5系。根据宝马官方公布的信息，这一功能还将扩展至今年7月1日生产的宝马1、2、3、4、5、6、8、X5、X6、X7、X5M、X6M、Z4等车型，但不包括旗舰轿车宝马7系。如果你还有一部2018年及之后发布的iPhone XR及更新机型或者Apple Watch Series 5，就能实现用手机解锁车辆。这项功能不一定要更新到iOS 14，现在的iOS 13也能使用这一功能。

首先，需要手机与车辆进行配对，配对成功后，会以一张卡片的形式存放在手机的钱包app中。

![](../Images/323e07115dc2f1f9da93788312866fda.png)钱包app中的车钥匙

如果驾驶员需要解锁车辆，将手机与门把手轻轻一碰，就能打开车门。这项功能和Apple Pay交通卡有着相似的体验，不需要点亮手机屏幕就能解锁。进入车内后，将手机放在无线充电板上，就能直接启动车辆。

![](../Images/85a054b297566ad7658b7b033cc41b7c.png)苹果Car Key功能

可能有人会担心，如果手机丢了怎么办？

在使用手机解锁车辆时，可以为车钥匙设置密码或者指纹/面部解锁，手机丢了也不会导致车辆丢失。如果没有为车钥匙设置密码，也能通过iCloud远程锁定车钥匙，降低财产损失。

此外，苹果的车钥匙功能还能通过iMessage与他人共享车辆的访问权限，也能随时取消他人的权限。在美国，如果将车辆授权给青少年驾驶员，还能限制车辆的加速、最高速度等参数，保障安全行驶。

![](../Images/f7b7deacbf3d8ad0c4f8e66515c8c1a7.png)可通过iMessage分享车钥匙

还有一个问题，如果手机没电了怎么办？

实际上，车钥匙和Apple Pay交通卡类似，即便手机电量完全耗尽已经关机，车钥匙还能坚持5个小时，在此期间可以解锁车辆，上车之后就能用无线充电给手机补电。

虽然手机取代车钥匙已经不是一件新鲜事，但大多数车企都是用蓝牙或者移动网络实现解锁，这两种解锁方式在手机没有电、没有网络的情况的情况下完全无法使用，即便有这样的功能，车主通常还是要带着车钥匙出门。

而苹果用NFC芯片解锁车辆，日常使用不需要网络连接，即便手机电量不足已经关机，还能坚持5小时为车辆解锁。可以说，苹果的这一解决方案能够彻底取代车钥匙。

2、苹果宝马推动行业规范制定 NFC解锁不简单

如今，在汽车行业内，除了用车钥匙解锁汽车以外，还有蓝牙、移动网络、NFC三种方式，其中NFC也可分为卡片式和手机NFC两种方式。这些解锁方式究竟哪一种能够取代车钥匙呢？

首先来说移动网络解锁。移动设备发送解锁指令到车辆的云端服务器，再由云端服务器发送给汽车，就能实现解锁。

不过，在网络连接不畅、移动设备没电的条件下都不能用，显然不是一个优秀的解决方案。

再来说说蓝牙解锁。当车上的蓝牙装置与车主的移动设备连接上以后，车门就会自动解锁。不过，为了安全起见，大部分蓝牙车钥匙解锁都需要掏出手机主动开锁或进行指纹、面部或者密码的认证。

不过，蓝牙的劣势也很明显，手机没电无法使用，为了安全还得打开app，即便人靠近了也不能保证100%连接成功。

看来，这两种解锁方式都无法真正取代车钥匙。而NFC卡片本身就相当于“车钥匙”，并没有体验上的提升。

一贯严谨作风的苹果当然不会用这些解决方案，因此采用了手机NFC解锁。不过，用手机NFC解锁汽车少有车企支持，为什么这么好的解决方案其他厂商都不做呢？

首先要明确一点，NFC技术并不仅用于开车门锁，还可以实现公交卡、门禁卡、银行卡的功能。这就对芯片的安全性提出了很高的要求。如果要调用手机的NFC功能，车企必须与手机制造商建立联系，需要车企共享车辆数据，还得手机厂商配合，这就为不少车企带来了麻烦。

做手机NFC车钥匙并不像开发app调用网络蓝牙那么简单，因此，跟谁合作也非常重要。

要合作首先考虑大厂，苹果还是大厂中非常优秀的合作伙伴，用户基数大，同时遍布全球。因此，无论哪家车企与苹果合作，都非常正常。

从实际使用上来说，手机NFC解锁面临的不仅是安全性问题。例如，不用网络连接意味着无法追踪，车辆解锁无法被侦测；同时，手机解锁车门之后如何判断钥匙在车外还是在车内，是否允许启动；此外，NFC卡片会不会被随意复制，车辆被滥用。如果这些问题无法解决，手机NFC车钥匙还是无法取代传统钥匙。

这一个个问题一家企业肯定难以解决，于是苹果联合宝马顺水推舟，开始推动行业规范的起草。

今年5月，汽车通信联盟（CCC）制定的Digital Key Release 2.0规范正式发布，这一规范主要由5条规定构成：

1、电子车钥匙要和实体车钥匙拥有相同的安全性和隐私保护。

2、车辆和移动设备间的互通性和用户体验需要保持一致。

3、能够实现进入车辆、打火、启动等等操作。

4、能够通过标准或自定配置让车主配对车钥匙，并且可以和朋友共享。

5、在低电量模式下支持解锁车辆，即便移动设备已经无法运行。

![](../Images/98fe8c6dc7b5f29f00c99be1b1928a1f.png)汽车通信联盟制定的Digital Key Release 2.0规范

从这5条标准可以发现，每一条标准都和苹果的车钥匙功能高度重合。

这里就要讲一个小故事了，目前，苹果公司的无线通信和产品生态系统部门的主管是SK Yong，而他的领英简介显示，他不仅在苹果任职，同时也是汽车通信联盟（CCC）的董事。

这就能解释为什么苹果与Digital Key Release 2.0中的每一条要求都高度契合了，是因为苹果直接参与了Digital Key Release 2.0规范的制定。这个结论正好和WWDC主题演讲中苹果软件高级副总裁Craig Federighi的说法一致。

那么，用移动设备NFC究竟是如何解锁汽车的呢？在Digital Key Release 2.0规范中，有详细的描述。

![](../Images/b239660f7c5a9cd7af98db77c0de595d.png)Digital Key Release 2.0规范中NFC与车通信的流程

首先，需要车主将车辆与移动设备NFC配对。这个过程需要连接网络，并且汽车制造商的服务器和移动设备厂商的服务器需要互联。在确认数据之后，汽车制造商和移动设备制造商会分别向用户反馈确认信息。

然后，确认信息在用户的移动设备中就会生成车钥匙的架构和程序，并且这个车钥匙程序被系统安全组件锁定，不能随意访问其中的数据。

当移动设备靠近车辆的NFC感应区域时，二者就会互相通信，移动设备中的加密数据发送至车辆，并与车辆保存的数据进行匹配，如果匹配成功，车门就会打开，反之就会继续保持锁定状态。

3、U1芯片精确定位 明年不掏手机也能开车门

今天凌晨的WWDC演示完成车钥匙功能后，苹果软件高级副总裁Craig Federighi还提到：从明年开始，iPhone配备的U1芯片将让苹果车钥匙功能更加便利，即使是放在裤包、背包里，不用掏出也能解锁车辆。这似乎才是苹果车钥匙的正确“打开方式”。

不过，Digital Key Release 2.0规范显示，不管移动设备内部如何计算，最终是由NFC芯片与车辆通信认证的。苹果难道要成为第一个破坏规矩的公司吗？

其实并非如此，在Digital Key Release 2.0规范中，还附有明年即将发布的3.0规范，其中就提到了使用超带宽芯片实现车辆解锁。

2019年9月，苹果发布了iPhone 11系列手机，在当时那场发布会上，苹果仅在演示文稿中展示了iPhone 11系列搭载U1芯片，但介绍iPhone 11系列的苹果高级副总裁Philip W. Schiller对这颗芯片只字未提。苹果官网也只用了一段文字描述了U1芯片。在iPhone 11系列发布后的大半年时间里，这颗神秘芯片究竟能干什么一直是人们讨论的焦点。

![](../Images/46f925647b4ec08cd707e43b3a528861.png)iPhone 11全系搭载U1芯片

这颗U1芯片是一颗超带宽芯片，类似Wi-Fi和蓝牙，能够以较小的功率在短距离范围内传输大量数据。因此，两台在iPhone 11进行AirDrop文件传输时，速度会更快。

除此之外，这颗芯片最厉害的一点是精确定位。

![](../Images/a7d6765d496758a4e987586d5ef925ed.png)拆解图片中的苹果U1超宽频芯片（红色方框内）

根据苹果官方网站的介绍，这颗U1芯片可以“让iPhone 11具备空间感知能力，可感应附近其他配备 U1 芯片的苹果设备，并准确判断出彼此的位置关系，你可以把它想象成覆盖你家整个客厅的GPS。”

回到WWDC的主题演讲，如果U1芯片能够和车辆联动，那么当驾驶员靠近车辆时，车辆会准确判断驾驶员在车辆的哪个区域。

例如，驾驶员带着手机站在车后方，此时有人试图拉开驾驶室车门，是无法解锁的，只能驾驶员自己拉开车门或者为全车车门解锁才能让其他人进入汽车。

实际上，不仅是苹果在用超带宽芯片，其他厂商也已经跟进。

去年8月，恩智浦就曾与大众汽车合作，开发用于高尔夫汽车的超带宽芯片，可以准确地为车钥匙定位。这样一来，就不可能使用车钥匙信号桥接破解车辆了。另外，恩智浦也希望在未来能够使用移动设备精准定位，同时解锁车辆。

结语：车企联合科技巨头推动汽车“四化”

苹果在WWDC中发布了Car Key功能，让移动设备成为车钥匙，能够让人们的生活不断简化，所有信息合于几个移动设备。虽然这不是苹果的首创，但这一设计非常人性化，相信也会有更多车企跟进NFC车钥匙的功能。

在汽车“四化”的道路上，车企自身虽有强大的力量，但力量还是太小，难以推动整个行业前进的步伐。而有了苹果、谷歌、特斯拉这样科技巨头的加持，才会让整个汽车行业进步更快，人们的出行体验才会提升更大。
