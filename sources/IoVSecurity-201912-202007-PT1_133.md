# 卡巴斯基和AVL合作开发安全的自动驾驶控制器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2MDk1Nzg2MQ==&mid=2247492518&idx=1&sn=63e34cd0468ebf21189fece94c01f547&chksm=fc02b36ccb753a7ac361c7a9c3c47ec6220527bd1ff25c89558196a8c5b4f409ba6f3ac65da0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU2MDk1Nzg2MQ==&mid=2247492518&idx=1&sn=63e34cd0468ebf21189fece94c01f547&chksm=fc02b36ccb753a7ac361c7a9c3c47ec6220527bd1ff25c89558196a8c5b4f409ba6f3ac65da0&scene=27#wechat_redirect)

网络安全公司和系统公司正在整合其软件和硬件，以提高自动驾驶汽车的安全性

  

卡巴斯基与AVL Software and Function合作开发了第一个成功的软件和硬件集成，以生产能够辅助自动驾驶汽车的电子控制单元（ECU）。

  

由以色列工程师帮助开发的KasperskyOS已被置入由AVL Software and Functions设计的单元中，该单元的设计安全可靠。可定制的开发平台旨在保护高级驾驶员辅助系统（ADAS）之间的通信并保护所有其他自动驾驶汽车功能。

  

![](../Images/31cea8b64a4968d4f5e3e24bd4ab60a8.png)

（图 \* 卡巴斯基办事处。 卡巴斯基办事处 照片：盖蒂）  

  

在这个时候，人们开始关注可以被远程控制的车辆的安全性。自动驾驶汽车可能对病毒或黑客等恶意因素开放，这可能会对乘客或道路上的其他汽车造成威胁。

  

由于大多数黑客利用系统中的代码错误，因此KasperskyOS将这些组件完全分开，并确保不会发生任何不必要的干扰。

  

目前，远程控制已准备就绪，可以用于OAM和1级供应商的原型项目。
