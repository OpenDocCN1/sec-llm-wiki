# 您的克莱斯勒被黑了吗？ 联盟宣布以色列因网络攻击而召回

克莱斯勒（Chrysler），道奇（Dodge）和吉普（Jeep）的制造商宣称，黑客可能会控制他们的某些汽车

  

汽车召回并非罕见，并且在世界范围内每周都会发生，但制造商宣布汽车容易被黑客入侵的召回无疑并不常见。直到本周，克莱斯勒，道奇和吉普的制造商宣布，黑客有可能夺取某些汽车的控制权，以色列才避免了此类事件。

  

根据公告，吉普2014年和2015年的切诺基和大切诺基车型都容易受到其广播和多媒体系统的攻击。

  

![](../Images/f157baab3d5c270ea321de347a41e5e5.png)

  

（图\* 吉普切诺基））

 

  

新闻稿说：“音响系统在安全性上有一定的漏洞，未经授权的第三方可能会使用该系统访问某些汽车的在线控制系统。”

  

根据新闻稿，召回还适用于克莱斯勒集团所属的其他私人进口到该国的车辆，包括道奇Charger，Challenger和Viper，这是该公司的超级跑车，最高时速可达280 kmh。
