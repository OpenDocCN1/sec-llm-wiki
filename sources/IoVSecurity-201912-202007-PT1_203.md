# 增强V2X网络安全新联盟成立

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2MDk1Nzg2MQ==&mid=2247489545&idx=2&sn=360e75e16f96c0d9be013c6a24eac822&chksm=fc0148c3cb76c1d541f6814bb377f3c02e3e0254921015ad67e91f9820590311e2b70cf27825&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU2MDk1Nzg2MQ==&mid=2247489545&idx=2&sn=360e75e16f96c0d9be013c6a24eac822&chksm=fc0148c3cb76c1d541f6814bb377f3c02e3e0254921015ad67e91f9820590311e2b70cf27825&scene=27#wechat_redirect)

**网络安全公司Accedian，数字基础设施安全专家New Context和V2X先驱Savari宣布了一项战略合作伙伴关系，以促进和促进下一代智能基础设施的经济安全性和繁荣。**

  

该联盟动员起来，将各个行业的无数传感器，应用程序，自动驾驶汽车和远程服务连接起来，从而为明天的运输和电气化基础设施创建了一个可靠，可靠且安全的基础。

  

运输业见证了网络，传感器和设备的爆炸式增长，推动了AI，物联网和4G / 5G技术的拼凑，使之本已迅速恶化的现代基础设施设计。智能基础设施重新构想并促使现代技术的集体想象力融合为社会所需的实际社会和经济利益。

  

Accedian将提供其基础技术Skylight，该技术可观察网络和应用程序事务，性能分析并检测实时的可疑，恶意和异常威胁行为。Skylight的可观察性将使基础架构能够利用车辆，交通管理系统和快速充电站等数据，并支持与智能城市启用相关的应用程序。这种智能数据流可用于V2G和C-V2X基础结构的更高层的分析平台以及自动化和编排平台。可观察到的应用程序和网络性能，以及边缘和核心云基础架构中的安全威胁检测，确保将正确的数据发送到正确的位置和正确的时间，从而促进智能，生态友好和更安全的智能城市基础设施。

  

“ Skylight提供了确定应用程序通信事务并检测高级，有针对性的网络漏洞和其他规避攻击（这些对于组织而言很难发现和阻止的攻击）所需的关键可观察性。简而言之，它提供了实现智慧城市基础设施生态系统所需的数字保障。” Accedian网络安全战略副总裁Michael Rezek说。

  

![](../Images/18bd16e6745968117336afe70c9b4c30.png)

  

New Context将利用其在公用事业，机器人和工业领域的工程远景数据架构解决方案中的专业知识，通过不断变化的规则手册来现代化下一代智能基础设施领域，以适应因国家，地区或州而异的数据。

  

New Context首席执行官丹尼尔·里德尔（Daniel Riedel）说：“可观察性和信任对于我们整合传感器，车辆和供应链的方式至关重要。” “这就是为什么这种伙伴关系对我们未来的基础架构至关重要。工业，公用事业和汽车公司将全部融合到一个生态系统中。数据必须能够安全可靠地通过它们，同时仍要保持所有跨法规合规性。我们很荣幸能跻身于在这一相互关联的领域中拥有丰富经验和深度的精选公司之列，而Accedian的Skylight和Savari将为我们提供透明度和信任度的可见性。”

  

萨瓦里（Savari）将继续朝着其使命前进，通过横跨车载，路边和云业务领域的V2X解决方案，使世界的道路更安全，更智能。如今，Savari已成为主要汽车制造商从2020年开始推出V2X的重要组成部分。由于这些汽车领导者占据了美国市场的30％以上和全球汽车市场的15％左右，因此Savari的V2X软件将为Advanced提供动力全球七分之一的汽车中的驾驶员辅助系统（ADAS）功能。

  

“ 5G的出现使V2X基础架构的部署得以更快地进行。现在是时候满足智能城市和汽车制造商对互联和自动驾驶汽车的需求了。我们很高兴能将三家公司的力量结合起来，为保险业创建一个平台框架，以满足全国范围的“零愿景”倡议。” Savari首席执行官Ravi Puvvala说。
