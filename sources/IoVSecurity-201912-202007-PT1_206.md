# 上游安全Upstream Security与Amazon Web Services共同提高汽车网络安全性

以色列赫兹里亚，2020年6月2日，美国新闻网/-基于云的汽车网络安全领域的领导者Upstream Security今天宣布，它已作为精选层技术合作伙伴加入了Amazon Web Services（AWS）合作伙伴网络。上游安全技术是汽车云网络安全的先驱，并释放了汽车数据的价值，从而确保互联车辆和移动服务安全，可靠并以最佳方式运行。借助其互联移动解决方案（CMS），AWS使汽车制造商和供应商可以构建可收集，处理，分析和处理互联车辆数据的应用程序，而无需管理任何基础架构。  

  

上游和AWS的合作伙伴关系将使使用AWS的汽车公司拥有在智能交通和互联车辆的新网络威胁形势中蓬勃发展所需的网络安全知识，功能和缓解技术。

  

“我们很高兴将上游安全性作为合作伙伴网络和汽车解决方案的一部分，” AWS汽车业务主管Bill Foy解释道。“上游公司以提供先进的网络安全解决方案而闻名，这些解决方案可帮助汽车客户改变其连接车辆的安全保护方式。”

  

上游加入了亚马逊合作伙伴网络，进一步增强了其数字和云功能，以提供行业领先的解决方案。作为AWS技术合作伙伴，上游AWS的基于软件的网络安全解决方案现在可以由汽车AWS客户-OEM以及联网的车队-用于检测针对横跨车辆本身，远程信息处理服务器和移动应用程序的联网车辆基础设施的网络威胁。

  

“与AWS的合作使我们能够为OEM和车队提供经过现场验证，可扩展且强大的网络安全解决方案，” Upstream联合创始人兼首席执行官Yoav Levy说。“我们希望通过提供上游和AWS Connected Mobility Solution的无缝，现成的集成来增强与AWS的合作。”

  

关于上游安全

  

上游安全是第一个基于云的网络安全解决方案，旨在保护互联车辆和智能移动服务免受网络威胁和滥用。上游的C4平台利用现有的汽车数据源来实时检测威胁，并提供AutoThreat（TM）Intelligence支持的网络安全见解，这是业内首个汽车网络安全威胁情报。上游安全由雷诺风险投资，沃尔沃集团，现代，Nationwide Insurance，CRV，Glilot Capital Partners和Maniv Mobility私人投资。
