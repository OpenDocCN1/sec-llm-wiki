# Green Hills Software将为高级车辆网关平台提供Excelfore的车载网络产品组合

Combination提供了金标准的汽车安全平台，并通过经过验证的对时间敏感的网络进行了集成和优化

  

  

![](../Images/4f360f14fce48e2aaebabae942fe9f8e.png)

  

加利福尼亚州弗里蒙特市和加利福尼亚州圣巴巴拉市-2020年5月12日-互联汽车技术的创新者Excelfore和全球高保证操作系统的领先企业Green Hills Software今天宣布达成一项全球协议，以启用Green Hills Software提供与Green Hills Software的INTEGRITY®实时操作系统（RTOS）及其嵌入式高性能TCP / IP v4 / v6网络堆栈集成和优化的Excelfore车载网络（IVN）堆栈和解决方案的广泛产品组合。这些解决方案共同提供了下一代车辆网关电子系统所需的基础安全性，安全性，性能和协议支持。  

  

集成和优化的Excelfore协议栈可与Green Hills Software提供的安全可靠的INTEGRITY RTOS配合使用，包括：

  

*   以太网AVB / TSN通话者/收听者
    
*   DoIP
    
*   某些/ IP
    
*   RTP / RTCP（包括IEEE 1733）
    
*   gPTP从站/桥接
    

  

Excelfore的堆栈将对时间敏感的网络连接到以太网，并为TCP / IP（互联网协议）提供了一套可靠的解决方案集，可将其连接到所连接车辆的边缘设备。

  

Green Hills Software业务开发副总裁Dan Mender表示：“强大的联网功能是下一代车辆网关设计的基本要求，它可以实现互联汽车的先进功能。我们将INTEGRITY RTOS与Excelfore网络协议栈集成在一起，可提供安全，可靠，高性能的用户体验，这对于当今先进的基于网络的车辆至关重要，并且迄今为止已成功在众多汽车OEM平台中进行了部署。”

  

Excelfore的首席技术官Shrikant Acharya表示：“数百万辆汽车现在包含使用Green Hills汽车平台创建的软件。客户对Green Hills Software的重视是提供了故障安全，稳定，高性能的安全解决方案。Excelfore协议栈与这些特性非常吻合，可以帮助Green Hills Software提供可靠的高吞吐量网络，这对于实现一流的联网汽车应用体验至关重要。

  

在整个汽车行业，Excelfore公司的eAVB/TSN运行在汽车原始设备制造商的摄像头、视频显示器、头单元和ECUs中，并使车载网络网关能够通过车载以太网TCP/IP接口提供对CAN、LIN和其他总线的访问。

  

**可用性**

  

与Green Hills Software的INT实时实时操作系统（RTOS）集成和优化的Excelfore车载网络（IVN）堆栈和解决方案现已上市。有关更多信息，请联系info@ghs.com或访问我们的网站https://www.ghs.com/go/excelfore。

  

**关于Green Hills软件**

  

Green Hills Software成立于1982年，是嵌入式安全保障领域的全球领导者。2008年，Green Hills INTEGRITY-178 RTOS是第一个也是唯一一个通过NIAP（由NSA和NIST组成的国家信息保证合作伙伴关系）认证的操作系统，达到EAL 6+，高健壮性，这是有史以来最高的安全级别软件产品。我们的开放式架构集成开发解决方案可满足需要军事认证的军事/航空，医疗，工业，汽车，网络，消费类和其他市场的深层嵌入式，绝对安全性和高可靠性应用。Green Hills Software的总部位于加利福尼亚州圣巴巴拉，欧洲总部位于英国。访问https://www.ghs.com上的Green Hills Software。

  

**关于Excelfore**

  

位于硅谷的Excelfore通过用于互联汽车，电动汽车和自动驾驶汽车的创新平台来解锁汽车数据。Excelfore产品包括用于车载网络的协议栈，以及用于OTA更新和数据收集的eSync™双向管道的完整实现。Excelfore的总部位于美国加利福尼亚的硅谷，并在中国，德国，日本和印度设有办事处。www.excelfore.com
