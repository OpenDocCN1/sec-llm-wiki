# 仲至信息 Secure by Design 荣获亚太区10大信息安全新创企业

摘要：由于物联网系统开发与整合即存在信息安全漏洞，导致安全防护难度提高，黑客正对家庭物联网、植入式医疗装置、汽车等高安全威胁商品发起猛攻，进而勒索高额金钱

  

![](../Images/5d79bcd7298373e59be4316903e6499a.png)

  

台北2020年5月13日 /美通社/ -- 由于物联网系统开发与整合即存在信息安全漏洞，导致安全防护难度提高，黑客正对家庭物联网、植入式医疗装置、汽车等高安全威胁商品发起猛攻，进而勒索高额金钱。各国政府积极建立并推动信息安全法规，信息安全市场蓬勃发展。有鉴于亚太地区信息安全市场与信息安全新创能量的快速成长，北美权威安全媒体 (Enterprise Security Magazine) 从创新技术解决方案、区域影响力等面向，于百家亚太地区信息安全相关新创公司，选出亚太区10大信息安全新创企业。仲至信息 (Onward Security) 从“Secure by Design”概念出发，以 IoT 与 IIoT 之整体解决方案获得青睐，为唯一入榜并获特刊独家专访 (Top 10 Enterprise Security Startups in APAC) 之新创企业，并与以色列、澳洲、日本、新加坡等优质企业并列此主题之10大亚太地区新创公司，足见仲至信息对物联网信息安全的努力与成果深获国际肯定。

  

关于仲至信息

  

仲至信息科技是连网产品信息安全合规解决方案的国际领导厂商，成立于2014年，除具备国际级的实验室外，更自主开发自动化 AI 信息安全合规产品，拥有多国专利与国际奖项，可提供政府单位、IoT/IIoT 设备商、金融、电信等产业客户取得信息安全认证，并发掘潜在的资安威胁与漏洞，保障重要资讯或产品安全，符合信息安全法规及产业标准的要求。

  

“Secure by Design”创新思维为企业建构产品自主信息安全检测体系  

  

仲至信息团队是一家专注物联网信息安全的新创公司，自主研发的自动化连网设备检测平台 HERCULES SecDevice 参与 Info Security Products Guide 举办的第15届 Global Excellence Awards “全球卓越奖”大赛，荣获“IoT 安全类”“Internet of Things (IoT) Security”与“工控安全类”“Industrial Control Systems (ICS) and SCADA”两类创新产品奖的肯定后，更同样以“Secure by Design”再次突破创新，入榜并获北美权威安全媒体《Enterprise Security Magazine》特刊独家专访。

  

众所周知，《Enterprise Security Magazine》作为最前瞻企业科技领导期刊之一，其所公布的年度亚太地区前10位最具竞争力的新创信息安全厂商，这份殊荣更是唯一获奖的物联网信息安全厂商，鼓舞激励了目前正在进军国际信息安全市场的仲至信息。在《Enterprise Security Magazine》Russell Thomas 专访中，仲至信息洪光钧总经理表示：「IoT 供货商专注其领域技术，聚焦提供客户高质量之产品；在研发、上市时程同时兼顾信息安全或法规的要求压力下，对于产品开发部门是非常大的挑战。如何在有限人力、时间、预算等资源，兼顾出货、质量、信息安全，是业者决胜的竞争力。仲至信息为企业建构产品自主信息安全检测体系，便在如此殷切需求下，因应而生。在安全软件开发生命周期 (SSDLC) 基础上，从客户角度，提供合规、服务、产品，满足企业管理与实际执行面之需要。”

  

专注物联网信息安全一站式产品安全合规解决方案

  

依 Gartner 预估，2020年 IoT 装置数量将超过200亿个，加上5G 技术、智慧家庭、工业4.0、自驾车、车联网等发展，场域应用与产品蓝图推展，引起黑客觊觎，过去常见攻击目标之信息系统漏洞与网页漏洞，逐渐转向高附加价值的行动装置数据窃取、破解汽车系统等。Cybersecurity Ventures 统计，2021年网络犯罪所造成的损失预计将达六兆美元。

  

洪光钧更补充：仲至信息立足为国际级信息安全公司，主要关键优势在于拥有深度与不断精进检测技术以及贴近市场需求的解决方案。值得一提的是，一家日本国际级电信客户，由于采购 IoT 产品类别众多，数量庞大，测试时间与资源难处理如此庞大数量；此公司试用了仲至信息的自动化测试工具 SecDevice，进行已知漏洞 (CVE) 扫描、网络漏洞扫描、通信协议模糊测试、阻断服务攻击 (DoS) 测试。由于 SecDevice 采用了“Machine Learning Based Fuzz Testing”技术，使过程除大量省却人力为客户自动产出详细修补建议报告外，并为该客户迅速建立 IoT 安全测试能力，将信息安全能量导入产品与制程，有效降低产品信息安全风险。另一家国际 IoT 大厂，仲至信息提供的一站式解决方案，从合规、体系管理、测试工具等层面着手，导入管理系统 SecFlow，管理开源软件的相关漏洞，同时采用自动化检测工具 SecDevice，达到最有效的未知漏洞自动发掘，满足网路安全法规与标准的要求，增益其商誉价值。

  

国际布局 AI 与5G 驱动开展

  

展望未来，仲至信息已布局国际市场，并陆续于海外设立办公室（分公司），更加速建立国际信息安全认验证中心，积极与跨领域系统集成商和连网设备制造商合作，聚焦于整体信息安全解决方案。藉由互补通路资源与专业能量，应用于智能制造、交通、医疗、金融及政府等领域，积极参与国际认证组织，搭配自主研发检测工具的加乘效果，以服务产品化，产品服务化的创新模式，凝聚汇集为坚实的智能信息安全生态圈。而仲至信息目前仍正在进行国际化与品牌化的工作，将仲至信息推展至亚洲优质的产品信息安全合规公司，并全力提升国际营销与塑造公司专业形象，同时，仲至信息也将投入更多的研发资源， 特别是5G与人工智能在IoT领域等应用的信息安全解决方案，并持续耕耘信息安全前瞻技术研发，期许仲至信息成为亚洲第一个具备AI信息安全合规核心技术能力的公司，洪光钧充满信心的为此专访做了宣示的结语。
