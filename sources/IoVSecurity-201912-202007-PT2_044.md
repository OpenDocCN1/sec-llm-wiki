# Car ConnectivityConsortium®（CCC）发布其数字密钥发布2.0规范

俄勒冈州比弗顿-（美国商业资讯）-2020年5月4日-  

  

Car ConnectivityConsortium®（CCC）今天宣布，其Digital Key Release 2.0规范已经完成，现在可供CCC成员使用。数字钥匙是一种标准化的生态系统，使移动设备能够以安全，隐私保护的方式在任何地方使用，以存储，认证和共享车辆的数字钥匙。

  

CCC总裁Mahfuzur Rahman表示：“ Digital Key Release 2.0是我们所有相关行业的资深会员为实现未来车辆出行而付出的努力的最高成果。” “ Release 2.0为车主提供了一种标准化且安全的方法，使车主可以使用自己的移动设备作为其数字密钥，并且支持多种使用模式。它还为Digital Key Release 3.0及更高版本奠定了基础，它将添加更多的用户友好功能。我对新兴的数字钥匙生态系统感到兴奋，在这里，使用智能手机作为汽车钥匙变得比如今使用相同手机的情况更普遍。”

  

**2.0版要点和用例**

  

Digital Key Release 2.0规范利用近场通信（NFC）技术在智能手机和车辆之间进行非接触式通信，并支持可扩展的体系结构以在不降低成本的情况下被大量采用。

  

车主将能够利用Digital Key Release 2.0的以下功能：

  

*   等同于物理密钥的安全性和隐私性
    
*   跨移动设备和车辆的互操作性和用户体验一致性
    
*   车辆出入，启动，动员等
    
*   通过标准或自定义权利配置文件与所有者配对并与朋友共享密钥
    
*   在低电量模式下支持移动设备，该模式下无法正常运行设备
    

  

数字密钥体系结构使用标准化的接口来确保移动设备制造商和车辆制造商在实现之间的互操作性，并且它使用基于标准的公钥基础结构来建立端到端的安全性。移动设备在安全元素中创建和存储数字密钥，以提供最高级别的保护，以免受基于硬件或软件的攻击。该体系结构还旨在允许车主在没有Internet连接的情况下访问其车辆，同时还允许车辆制造商添加需要Internet连接的功能以用于特殊功能。

  

下一代数字钥匙，版本3.0规范，正在开发中。它将利用低功耗蓝牙和超宽带无线连接来支持被动的，可感知位置的无钥匙访问，从而为车主提供更多便利和新功能。

  

CCC成员现在可以使用Digital Key Release 2.0规范。要访问规范或加入CCC，请访问www.carconnectivity.org/membership/how-to-join-ccc/。

  

关于汽车连接联盟

  

汽车连接联盟（CCC）致力于跨行业合作，以开发智能手机和车载连接的全球标准和解决方案。CCC的董事会成员包括宪章成员公司：苹果，宝马，通用汽车，本田，现代，LG，松下，三星和大众。该组织的100多名成员代表了全球汽车和智能手机市场的很大一部分。除了数字钥匙外，CCC技术产品组合还包括MirrorLink®和汽车数据。有关CCC项目和参与的更多信息，请访问www.carconnectivity.org。
