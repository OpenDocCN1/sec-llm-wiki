# 中国一汽与华为、腾讯、百度等开展深度合作 加速构建数字化转型生态

日前，中国一汽在长春举办了数字化大会。在大会上，中国一汽同华为、腾讯、百度、阿里云、IBM（中国）有限公司、NTTDATA等业界领先的数字化解决方案提供商签署深度合作战略协议。

  

![](../Images/4ec4f3ef0a09851343603646417d14ef.png)

根据协议内容，中国一汽与合作伙伴将秉承“创新、协调、绿色、开放、共享”的发展理念，紧密围绕技术、数据、人才、业务创新等领域开展深层次战略合作，加速构建数字化汽车生态体系。

华为：分享数字化转型创新实践，合作共建自主可控的数字化平台，基于华为5G工业互联网在车联网进行联合应用创新；

腾讯：共建价值链数据生态，构建网络安全云车端一体化平台，在车联网方面开展全面深度合作；

百度：在数字化环境下的车载安全及信息安全、基于智能网联汽车的数字化出行及各类车联网服务展开全面深入合作，同时进一步巩固和深化双方在自动驾驶领域战略合作，助力中国一汽的数字化转型战略；

阿里云：共建中国一汽公有云平台、深化高效透明的工作机制，联合创新汽车营销新零售模式；

IBM（中国）：在数字化转型咨询、生态云、供应链管理及OTD、产品质量管理、数据资产管理、项目群管理PMO及开发中心敏捷化、多云管理平台和服务、应用和数据的云迁移等方面进行深度合作；

NTTDATA（中国）：共创业务数字化领先实践，进行车联网服务生态孵化，开展数字化人才培育工作。

  

目前，中国一汽在智能网联项目上也在加大投入。3月，一汽启动建设了总规划面积26.6万平方米，总投资26.9亿元，主要由新能源试验区、智能网联试验区和被动安全试验区三个主区域构成的实验基地。中国一汽计划，到2025年成为世界一流的移动出行服务公司。以一汽红旗为例，该品牌计划在智能网联领域打造出较为领先的全场景平台架构。目前，在已经开始接受预定的红旗H9上，红旗已经搭载了最新的Smile 1.0智能网联系统。除了常规的功能以外，这套系统还整合了高级驾驶辅助系统、全场景控车等功能。
