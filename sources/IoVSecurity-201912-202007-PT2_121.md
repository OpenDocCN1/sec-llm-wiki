# 恩智浦为普及数字汽车钥匙铺平道路

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2MDk1Nzg2MQ==&mid=2247485924&idx=1&sn=61df8b7c5a0fb64bd24002820725d135&chksm=fc01592ecb76d03898dcc5dc5338e6fef86ffb0cef2496e1e1096984d0b05e47e6abef085bf9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU2MDk1Nzg2MQ==&mid=2247485924&idx=1&sn=61df8b7c5a0fb64bd24002820725d135&chksm=fc01592ecb76d03898dcc5dc5338e6fef86ffb0cef2496e1e1096984d0b05e47e6abef085bf9&scene=27#wechat_redirect)

**通过利用NFC和数字安全技术，可以通过更多设备实现安全的车辆访问。**  

  

  

  

恩智浦半导体的数字钥匙解决方案（DKS）使智能手机，密钥卡和其他移动设备能够与车辆安全地通信，存储，认证和共享数字钥匙，从而扩展了汽车出行的便利性。DKS启用了新功能，例如钥匙共享，多车访问和可配置的驾驶权限。现在，家人和朋友可以通过智能设备共享数字汽车钥匙，或者车队和共享汽车的公司可以通过云提供钥匙。该解决方案基于恩智浦汽车认证的安全元件和NFC芯片组，遵循汽车连通性联盟的（CCC的）标准化版本2，该架构得到了世界领先的汽车制造商，智能手机制造商和电子供应商的认可。

  

DKS由NXP的NFC芯片组和Secure Element技术组成，包括新的符合汽车标准的NXP Secure Element，可通过支持NFC的智能手机，智能钥匙扣或NFC智能卡（持有数字钥匙）来解锁和启动汽车。（见图）。它还可以与其他移动设备安全共享车辆访问权限，这是安全的车辆访问生态系统的高级功能。可以将其无缝添加到经典的远程或被动进入系统中。

  

![](../Images/949b945e2db1161b520aaab8d417d767.png)

  
*(\*通过将NFC和数字安全技术相结合，恩智浦的数字钥匙解决方案将汽车钥匙功能带入了更大范围的设备。（来源：恩智浦半导体）*

* * *

  

恩智浦安全元素在移动端和汽车端均启用了端到端安全性。嵌入式数字钥匙小程序利用CCC的标准化支持生态系统的互操作性。该解决方案包括NFC技术，即使手机电池电量不足，也可以触发汽车进入和驾驶员授权。

  

安全数字密钥管理也是实现免提智能汽车访问的基础，这将在CCC第3版中定义。因此，恩智浦将把其DKS与其汽车蓝牙（BLE）进行通信，以及最近宣布的Ultra-宽带（UWB）技术可实现精确和安全的本地化。

  

安全元素安全方案的关键部分是恩智浦的NCJ38A汽车级安全元素，这是一种专用的硬件和软件平台，具有先进的加密加速器以及物理和电气攻击抵抗能力。NCJ38A SE存储安全应用程序及其机密数据。

  

该软件平台与NXP Automotive JCOP 4.4操作系统一起作为开放Java Card平台提供给客户。客户可以选择订购通用身份验证小程序NCJ38xA，该程序支持各种M2M身份验证方法，加密密钥和数据存储。

  

该设备基于高频时钟Arm SC300内核，以及最新一代的NXP加密硬件协处理器和闪存模块，将安全应用程序的性能和安全性提高到一个新的水平。
