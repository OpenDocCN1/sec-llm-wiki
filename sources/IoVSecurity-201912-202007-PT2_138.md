# Karamba Security XGuard系统可防止车辆网络攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2MDk1Nzg2MQ==&mid=2247485857&idx=4&sn=8357f7c5da5e55cf3576d43f6f371f9a&chksm=fc01596bcb76d07d68ecd96f92670c09ce2124e8b792d04ae8ca8ced8022e618bfd3f9065a9c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU2MDk1Nzg2MQ==&mid=2247485857&idx=4&sn=8357f7c5da5e55cf3576d43f6f371f9a&chksm=fc01596bcb76d07d68ecd96f92670c09ce2124e8b792d04ae8ca8ced8022e618bfd3f9065a9c&scene=27#wechat_redirect)

黑客有可能破坏任何单个车辆的系统或其所有系统，从而对该车辆的驾驶员和附近人员造成危险。

  

以色列汽车网络安全公司Karamba Security在布卢姆菲尔德希尔斯设有办事处，Karamba成立于2016年，旨在通过在开发过程中安装在车辆中的软件来应对这种威胁。目前，它正在与日本信息娱乐系统供应商Alps Alpine合作，后者向奥迪，沃尔沃和底特律三大汽车制造商提供产品。它还与DENSO合作研究了论文。

  

Karamba Security的联合创始人兼研发副总裁Tal Ben-David说：“汽车网络安全是一个多层问题，需要多层解决方案。” “我们在开发车辆时提供附加软件。当该软件更新时，我们也会提供更新。”

  

第一层保护是Karamba VCode，它可以帮助制造商识别，确定优先级并减轻代码安全配置中的安全漏洞。

  

Karamba XGuard使用自动生成的控制流完整性和二进制文件白名单来在运行时验证设备二进制文件和内存使用情况，同时检测并阻止插入恶意代码的尝试。

  

其他Karamba系统会收集可疑数据，然后将其发送回OEM进行分析。

  

“当车辆受到网络攻击保护时，不仅驾驶员受到保护，OEM也受到紧急召回保护，”本·戴维说。他补充说，车辆并不是唯一需要网络保护的设备。

  

例如，连接到Internet的任何设备（例如公司的打印机）都应受到保护。

  

Ben-David说：“在任何可以成为企业整个网络门户的互联设备中都存在需求。”

  

为此，Karamba Security正在与Stanley Black和Decker以及Hitachi的监视摄像机部门合作，以改善其网络保护。
