# 如何在全球范围内制定5G安全标准

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2MDk1Nzg2MQ==&mid=2247485794&idx=3&sn=02b83859c565f8688e74a8b30b680866&chksm=fc0159a8cb76d0be5323a10e108c2d546ba12028441f00c80ef2af27c18dde39556e04a42a68&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU2MDk1Nzg2MQ==&mid=2247485794&idx=3&sn=02b83859c565f8688e74a8b30b680866&chksm=fc0159a8cb76d0be5323a10e108c2d546ba12028441f00c80ef2af27c18dde39556e04a42a68&scene=27#wechat_redirect)

随着构成5G的基础技术的发展，与国家和国际监管机构携手合作的各种行业团体已经合作确保下一代蜂窝的全球可扩展性。与前几代技术一样，这种统一的方法势在必行。在中国制造的设备需要在美国使用，在英国开发的架构需要东南亚的制造商可以复制，手机需要在瑞士的5G网络和南非之间漫游。

  

为了使所有这些都能正常工作，需要有一套定义5G的统一标准。相同的方法应该并且在一定程度上适用于网络安全，该网络安全可以保护世界各地通过5G网络传输的数据。

  

移动网络的网络安全遵循分层模型，并且可以按域分类。5G网络安全架构包括：

  

*   网络访问安全；
    
*   网络域安全；
    
*   用户域安全性；
    
*   应用程序域安全性；
    
*   和SBA域安全。
    

  

从标准级别融入5G的安全级别代表了其先前LTE的众多增强。这些增强功能包括：

  

*   更高的空中接口安全性；
    
*   更好的互连安全性；
    
*   改进的用户隐私保护；
    
*   并升级到256位加密。
    

  

正如GovCloud Network的首席执行官兼创始人Kevin Jackson在最近的一次华为研讨会上解释的那样：“全球标准化对于解决这一问题至关重要，因为竞争不在于技术本身，而在于您提供的服务，而是所有这些服务的主要内容，是客户数据和信息的安全性。缺乏一致的模式或规则也是对我们当前和未来电信基础设施网络安全的重大威胁。”

  

因此，在基于众多国际技术机构的工作并根据其他国家和国际政府组织的意见而开发的护栏的情况下，您如何将全球标准应用于动态，竞争激烈的市场？

  

  

独立验证在5G安全中的关键作用

  

  

德国在5G网络安全方面的方法是相对进步的，并且与独立验证的概念保持一致。德国电信监管机构Bundesnetzagentur总裁Jochen Homann在讨论德国将如何考虑5G供应商时说：“ Bundesnetzagentur采取的立场是，不应或可能专门排除包括华为在内的设备供应商。”

  

美国政府最近一直在敦促欧洲各国政府禁止其5G网络使用华为的基础设施，理由是中国当局可以利用该供应商的技术进行间谍活动。但是，根据Homann的说法，“ Bundesnetzagentur尚未收到针对华为的任何具体迹象。我们也不知道德国的任何其他机构已收到任何可靠的迹象，”霍曼补充说。

  

霍曼还表示，禁止华为进入该流程的决定将给德国移动运营商带来问题：“运营商都在其系统中使用华为技术。华为在这一领域也拥有大量专利。如果将华为排除在市场之外，这将延迟数字网络的推出。”他说。“如果华为满足所有要求，则可以参与5G网络的推出。Bundesnetzagentur不需要针对特定公司的任何要求。”

  

今年3月，华为在欧盟政府所在地布鲁塞尔成立了网络安全透明中心，以不断努力，以提供具体措施来确保其5G解决方案的网络安全。

  

轮值主席胡厚崑（Ken Hu）在开幕典礼上说：“信任必须基于事实，事实必须是可验证的，而验证必须基于共同的标准。我们认为，这是在数字时代建立信任的有效模型。”

  

该设施提供了一个物理空间，允许政府机构，技术专家，行业协会和标准组织访问一个平台，在此平台上，他们可以就安全问题进行协作。该中心为利益相关者提供端到端的网络安全实践，从策略和供应链到研发，产品和解决方案。访客可以亲身体验与华为产品和解决方案相关的网络安全，包括5G，物联网和云领域。该设施还为华为客户提供了产品安全测试和验证平台以及相关服务。

  

“该行业缺乏一套统一的安全技术标准以及验证系统。价值链的全球化使这变得复杂。数字产品包含来自许多不同国家的组件，这些组件具有许多不同的标准，或者根本没有标准。迫切需要在国家层面投资于安全标准和验证系统，以及专业资源和技能。”
