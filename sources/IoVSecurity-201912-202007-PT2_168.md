# SAE，ISO联合发布汽车网络安全工程标准草案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2MDk1Nzg2MQ==&mid=2247485713&idx=2&sn=da73e04e5849061467e2c2969c255624&chksm=fc0159dbcb76d0cdf295a3a449e7773cf084891b1723641ed7fd0c9d48c45c24c0fc99110406&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU2MDk1Nzg2MQ==&mid=2247485713&idx=2&sn=da73e04e5849061467e2c2969c255624&chksm=fc0159dbcb76d0cdf295a3a449e7773cf084891b1723641ed7fd0c9d48c45c24c0fc99110406&scene=27#wechat_redirect)

ISO / SAE 21434™标准将针对电气和电子车辆系统的开发实施一致的网络安全标准。

  

SAE International和ISO这两个行业组织于2月12日发布了新标准草案，概述了电动汽车开发和运营的网络安全实践。起草的标准说，它将提供“词汇，目标，要求和指导方针，作为整个供应链中共识的基础。”

  

根据两个小组发布的双重声明，草案“ ISO / SAE 21434™”以“ SAE J3061™：网络物理车辆系统的网络安全指南”为基础，并增加了更详细的方向和期望。新标准是由代表14个不同国家和82个公共，私营和政府部门的行业组织的专家开发的。

  

SAE International全球地面车辆标准主管Jack Pokrzywa说，他的团队与ISO的合作使他们能够开发“最高质量的规范，并得到该领域全球顶级专家的参与。” Pokrzywa在一份声明中说，他期待着未来在新兴技术标准方面的合作。

  

福特汽车公司和ISO / SAE联合工作组召集人的汽车网络安全经理说，新标准将为“整个汽车行业更加一致的网络安全实践”提供坚实的基础。

  

SAE网站表示，截至发稿时，起草的标准仍“未经批准”。这意味着它仍然可以随时更改，还不能用于合规性目的。

  

该草稿可供预览和购买：https://www.sae.org/standards/content/iso/sae21434.d1
