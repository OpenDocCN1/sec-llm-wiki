演讲题目：“ 针对汽车信息娱乐系统的常见攻击“

本演讲将首先着重分析高风险的车载接口（蓝牙，Wi-Fi /蜂窝，USB等），并介绍相关的攻击场景，这些接口可能会使系统遭受潜在的攻击。然后，将逐案详细说明可能的缓解措施。特别是，该演讲还将根据我们的项目经验总结一些有关汽车安全验证的最佳实践。

演讲嘉宾：陈陆海，安全架构师，系统软件开发集团，英特尔


Presentation Topic: " Common Attacks Against Car Infotainment Systems "

This talk will first focus on the analysis of the high-risk in-vehicle interfaces (Bluetooth, Wi-Fi/Cellular, USB, etc.) which may expose system to potential attacks, with the introduction of relevant attack scenarios. Then, the possible mitigations will be detailed case by case. Specially, the presentation will also summarize some best practices on automotive security validation from our project experience.


Speaker: Luhai Chen, Security Architect of Intel System Software Production Group, Intel Cooperation
