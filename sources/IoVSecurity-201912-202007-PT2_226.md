# 自动驾驶IoT的网络安全风险

无人驾驶汽车的共同驱动力可以追溯到几十年前。得知1920年代首次展示自动驾驶汽车，您可能会感到惊讶。从那时起，由于汽车，机械，电气和电子技术的进步，取得了长足的进步。然而，对于一个世纪前首次出现原型的东西来说，自动驾驶汽车一直很难真正流行起来。然而，计算机时代的到来为自动驾驶汽车注入了新的活力。物联网（IoT）的出现仅进一步扩大了可能性。在数十亿个互联设备的全球网络中，汽车仅成为一种节点。汽车与物联网之间的结合具有很多优势。然而，这也给自动驾驶汽车带来了一些网络安全风险。

  

**侵犯隐私**

  

![](../Images/cdaf9bfd8844de386342e2afd58d54bf.png)

  

自动驾驶汽车严重依赖传感器。随着市场需求推动自动驾驶汽车越来越先进，传感器的数量将不断增加。反过来，更多的传感器意味着更多的潜在黑客表面，并因此而暴露出个人身份信息（PII）的风险。

  

这种敏感的PII包括位置和行程数据，财务信息和车内娱乐偏好。如果落入他人之手，则该信息可用于进行财务欺诈和身份盗用。

  

**连接风险**

  

无人驾驶汽车由众多制造商生产，而制造商的数量只会持续增加。此外，每辆自动驾驶汽车都将依赖于多家供应商提供的技术。如果车辆的一个或多个组成系统存在缺陷，则网络罪犯可以利用它。

  

这是一个主要问题，因为网络安全问题通常是自动驾驶汽车的事后考虑。这为黑客创造了多种途径，以利用蜂窝网络和WiFi利用这些漏洞。危险不仅对汽车，乘员和运行汽车的系统，而且还威胁到汽车连接到的任何网络（例如家庭或企业网络）上的设备。

  

**移动应用程序漏洞**

  

![](../Images/40dc520007021729b866f5be05bca794.png)

  

Flickr / Blogtrepreneur

  

智能手机已迅速成为主要的个人计算设备。为了顺应这一消费趋势，设备制造商竭尽全力确保他们拥有一个移动应用程序，用户可以依靠该应用程序来连接，配置和/或操作设备。但是，这种便利性也为自动驾驶汽车引入了新的攻击媒介。

  

移动应用程序本身以及运行它们的iOS和Android操作系统都可以成为攻击者手中的工具。不良演员可以利用移动应用的漏洞来访问空调，风扇，座椅和方向盘。如果自动驾驶汽车是电动的，黑客甚至可以通过耗尽电池来使其静止。

  

**供应链网络安全漏洞**

  

联网的自动驾驶汽车制造商需要广泛的第三方供应商来提供使汽车运行所需的软件和硬件组件。但是，除非汽车制造商对其最关键的技术供应商强加了强大的网络安全要求，否则他们可能会无意中允许安全漏洞。

  

负责加速和制动等核心机制的与技术相关的组件必须满足最高的网络安全标准，并应进行定期的自动化测试，以确认系统仍在正常运行。

  

**无法应用安全补丁**

![](../Images/65fa7bc42b150fa86438222b0fb8eabf.png)

  

随着技术环境的发展，自动驾驶汽车随着时间的变化而变化，以前的安全系统可能容易受到新的安全风险的影响。部署该系统之前，未知的自动驾驶汽车可能还存在预先存在的网络安全风险。

  

为了抵御这些威胁，必须开发新的安全更新并将其应用于车辆系统。通常将通过无线通信网络访问更新。因此，任何持续的连接问题都可能意味着补丁可能无法尽快应用，这将为恶意行为者留下窗口。

  

**信息娱乐漏洞**

  

现代汽车拥有多种娱乐选择，而自动驾驶汽车在这方面也不例外。从流媒体到卫星导航，一切都为乘员带来便利。苹果和谷歌都拥有以车辆为中心的应用商店和信息娱乐系统。自动驾驶汽车系统还有机会连接到社交网络和支付应用程序，尤其是与以汽车为中心的需求有关，例如行程计划，停车和通行费。

  

尽管如此，这些平台仍使用敏感数据，这些数据对于汽车及其乘员的安全至关重要。因此，存在恶意软件攻击劫持或破坏自动驾驶汽车系统的危险。

  

**操纵安全关键控制**

  

如果自动驾驶联网汽车的网络安全控制受到威胁，则存在黑客操纵车辆的关键安全控制措施，从而导致事故，伤害或死亡的危险。例如，网络攻击者可能会破坏汽车的巡航控制系统，从而抑制制动和转向。

  

**偷车**

  

随着移动应用程序，无线钥匙扣和数字钥匙逐渐取代传统的车辆进入方式，它们创造了新的途径，精通技术的偷车贼可以通过这些途径未经授权进入车辆。

  

他们可以通过使用模拟无线钥匙并扩展信号范围的设备来拦截智能钥匙或智能手机与汽车之间的无线通信，从而实现这一目标。尽管最初将虚拟钥匙视为减少车辆盗窃的关键步骤，但事实证明，虚拟钥匙几乎与物理钥匙一样脆弱。

  

**内部威胁**

  

联网的无人驾驶汽车容易受到当今内部任何计算系统或设备所面临的最大威胁。内部人员具有知识，被信任并且可以访问车辆制造商的信息。内部人采取行动的动机千差万别，从破坏和人身伤害到欺诈和数据盗窃不等。检测内部人员对无人驾驶汽车的攻击具有挑战性，因为他们的行为可能不会引起人们的怀疑。

  

**设计的安全性**

  

汽车行业在为其联网汽车构建注重安全性的硬件和软件方面没有出色的记录。公平地讲，设计安全几乎是设备制造的每个子领域中的一个问题，也许是计算设备制造商的显着例外。

  

第一代自动联网汽车在安全性方面存在明显缺陷。安全编码和严格的安全测试通常会留到产品开发周期的最后阶段，因为这几乎没有时间来确保彻底识别和解决漏洞。专门用于网络安全事务的预算有限，从而加剧了这种情况。

  

了解网络安全风险和自动驾驶是关键

自动驾驶汽车带来了日益复杂的数字座舱系统，为乘客创造了令人兴奋的个性化体验。但是，这种舒适性和便利性带来了安全挑战。认识到这些自动驾驶汽车的网络安全风险是缓解风险的第一步。
