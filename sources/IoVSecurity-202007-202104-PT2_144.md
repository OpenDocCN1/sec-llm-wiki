# 汽车电子的网络安全风险

ISO / SAE 21434标准草案包括风险值和网络安全保证级别的概念。有什么不同？它们同样重要吗？

  

我喜欢暑假！如果我没有太多计划，可以享受自由和冒险的感觉，那就更多了。几年前，我和几个朋友一起去露营车旅行，我们正是这样做的。实际上，在COVID-19的情况下，带露营车旅行是一个不错的度假选择。唯一的问题是我不太喜欢开车。我宁愿计划下一个目的地，坐下来，放松一下，欣赏风景，聊天，睡觉或在抵达时醒来。我们还没有，但是自动驾驶汽车（AV）的技术正在迅速发展。我相信这只是时间问题。不幸的是，网络安全攻击也在增加。我是否应该担心一些讨厌的工程师可能会入侵我的车辆并开车将我送到办公室而不是我最喜欢的海滩？

  

  

即将发布的ISO / SAE 21434国际标准致力于道路车辆电气和电子（E / E）系统的网络安全。除了减少中断的风险外，该标准还将极大地改善车主的隐私并帮助保护汽车生产商及其供应链的知识产权（IP）和其他资产。由于没有信息安全就没有功能安全，成功的汽车黑客攻击可能会危及许多生命。因此，ISO / SAE 21434引用并补充了ISO 26262汽车功能安全标准。可以预料，可能导致高严重性后果的威胁方案应引起更多关注，并且可能需要制定规范并实施控制措施以降低风险。

  

在我以前的文章中，我介绍了OneSpin Solutions的新的6 Minutes of Security博客系列。在本文中，我将研究ISO / SAE 21434的两个特定方面，即风险价值和网络安全保证级别（CAL）的概念。

  

ISO / SAE 21434要求，对于任何已识别的威胁情况，必须确定风险值。此数字介于1（最低风险）和5（最高风险）之间。与威胁情形相关的风险取决于攻击的可行性及其影响。如果攻击需要一支由专业的黑客和昂贵的设备组成的团队，则与任何人都可以执行并造成相同破坏的攻击相比，这种风险将更低。在最坏的情况下，攻击很容易实施，并且会带来严重的后果。该标准未规定分析系统和计算风险值的特定方法，但确实提供了一些指导和示例。

  

网络安全保证级别（CAL）是可以与系统，组件或特定网络安全目标相关联的属性。有4个CAL，CAL1最不严格，而CAL4最严格。CAL是根据有关攻击及其影响的信息确定的。根据目标CAL，可以省略某些网络安全活动或不那么严格地进行。归类为CAL4的组件表示它可能适合执行需要高度安全保证和关键资产保护的关键功能。CAL对于根据目标保证级别定制网络安全活动以及简化供应链中利益相关方和各方之间的沟通非常重要。熟悉ISO 26262的工程师将看到CAL与汽车安全完整性等级（ASIL）之间的相似之处。

  

尽管CAL和风险值听起来很相似，但实际上却大不相同。CAL在标准的附件中进行了描述，该附件是内容丰富（相对于规范而言）的部分。这可能会在标准的第一个版本中发生变化。显然，CALs是制定该标准的委员会中一个有争议的话题，并且正在进行辩论。另一方面，风险值的概念及其确定是ISO / SAE 21434要求的一部分。此外，尽管CAL（至少在理想情况下）是恒定的，但风险值可能会在产品生命周期中发生变化。被认为过高的风险值可能会触发其他控制措施的实施，直到将其降低到可接受的水平。在产品运行期间，可能会发现一个新漏洞，从而增加了风险值。
