# Green Hills Software欢迎Argus网络安全进入其丰富的汽车合作伙伴生态系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2MDk1Nzg2MQ==&mid=2247497641&idx=1&sn=5df333ac30902433130f7fc35bf40d94&chksm=fc02a763cb752e75fc23202aeb0a5fe8727475f9fe50902273db4b5580cc3c448c733b39f1fc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU2MDk1Nzg2MQ==&mid=2247497641&idx=1&sn=5df333ac30902433130f7fc35bf40d94&chksm=fc02a763cb752e75fc23202aeb0a5fe8727475f9fe50902273db4b5580cc3c448c733b39f1fc&scene=27#wechat_redirect)

以色列特拉维夫和加利福尼亚圣塔芭芭拉，2020年7月29日/-嵌入式安全和信息安全领域的全球领导者Green Hills Software和汽车网络安全的全球领导者Argus Cyber Security宣布成为会员 将Argus Cyber Security引入一流技术提供商的Green Hills生态系统。

  

![](../Images/3ce0756139bd8366fd2343f581a6250e.png)

该合作伙伴关系是在成功的汽车客户合作之后进行的，其中Argus Control Flow Integrity产品已与Green Hills Software的业界领先的优化C / C ++编译器共同集成。从2021年开始，该联合解决方案将确保欧洲主要OEM的车辆中的安全关键型ECU的安全。利用Green Hills C / C ++编译器的现有安全保护功能，Argus Control Flow Integrity集成支持在瑞萨RH850处理器系列上运行的AUTOSAR Classic设备，从而提供了针对网络攻击的保护，例如误报为零的缓冲区溢出。

  

“通过为Green Hills编译器优化Argus控制流完整性，我们成功降低了汽车软件开发人员提高平台网络安全性的复杂性和时间，” Argus网络安全产品管理副总裁Nir Rozen说。

  

Green Hills Software EMEA业务开发总监Chris Tubbs说：“我们很高兴与Argus Cyber Security合作，并让他们加入我们一流的技术提供商丰富的生态系统。”

  

Argus Control Flow Integrity是Argus多层连接ECU保护和Argus Core ECU保护产品系列的一层。符合ISO 26262 ASIL B的规定，Argus Control Flow Integrity还可以保护车辆中安全关键的ECU（例如制动，ADAS等）免受网络攻击。此外，Argus Control Flow Integrity将与运行高级操作系统的ECU、AUTOSAR Classic和裸机ECU一起工作。

  

超过35年的时间，Green Hills编译器通过生成最快，最小和最可靠的代码来领导嵌入式行业。它们已通过ISO 26262 ASIL D认证，广泛用于运行裸机，AUTOSAR Classic，OSEK或更高级别操作系统的安全系统和ECU。Green Hill编译器为广泛的处理器中的C，C ++ 11，C ++ 14，C ++ 17，嵌入式C ++和GNU C / C ++扩展提供支持。
