# 中汽数据发布2021年车联网网络安全十大风险

新华网天津2021年5月7日电（张博）， 由中汽数据有限公司（以下简称“中汽数据”）主办的“车联网网络安全合规研讨会暨车联网网络安全十大风险发布会”在天津举行，来自整车厂商、零部件企业、车联网平台企业、网络安全企业等60余家企事业单位的150多位相关专家出席了本次发布会。

　　会上，中国汽车信息安全共享分析中心发布了2021年车联网网络安全十大风险，并有针对性地提出了保障车联网网络安全的防护机制。来自汽车行业第三方机构、主机企业、安全公司的14位专家被正式聘任为“车联网漏洞分析专家工作组”专家。

　　来自汽车、通信、安全等相关领域的专家在会上围绕国内外车联网网络安全合规机制、车联网漏洞挖掘技术、车联网网络安全防护等方面进行了深入探讨。

  

近年来，随着汽车智能化、网联化程度的不断提高，网络安全事件频发，智能网联汽车也面临越来越多的网络安全威胁。同时，车联网的安全攻击也呈现多样性，隐蔽性的特点。中汽数据有限公司（简称：中汽数据）长期从事汽车网络安全漏洞的研究工作，通过“中国汽车行业漏洞共享平台（China Automobile Vulnerability Database，简称CAVD）”收集了大量漏洞数据，并根据漏洞利用场景，进一步统计分析，形成2021年度车联网网络安全十大风险，向行业正式发布。结合公共互联网治理经验，在车型开发的全生命周期基础上，提出包含认证加密、访问控制等十大防护技术的安全防护解决方案。

![](../Images/575753cdcd80157e3313bc3c40069598.png)

未来，中汽数据将持续推进车联网网络安全研究，与国家政府机构、汽车行业同仁、权威安全公司加强合作，共同探讨汽车网络安全漏洞共享新机制，构建完善的车联网网络安全防护体系，推动我国智能网联汽车的健康可持续发展。
