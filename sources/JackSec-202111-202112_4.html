可以看到前几行关键代码涉及到的类有ChainedTransformer，ConstantTransformer，InvokerTransformer。先分析这三个类的构造方法和transform接口实现方法。

public class ChainedTransformer implements Transformer, Serializable {  static final long serialVersionUID = 3514945074733160196L;  private final Transformer[] iTransformers;  public static Transformer getInstance(Transformer[] transformers) {    FunctorUtils.validate(transformers);    if (transformers.length == 0)      return NOPTransformer.INSTANCE;     transformers = FunctorUtils.copy(transformers);    return new ChainedTransformer(transformers);  }  public static Transformer getInstance(Collection transformers) {    if (transformers == null)      throw new IllegalArgumentException("Transformer collection must not be null");     if (transformers.size() == 0)      return NOPTransformer.INSTANCE;     Transformer[] cmds = new Transformer[transformers.size()];    int i = 0;    for (Iterator it = transformers.iterator(); it.hasNext();)      cmds[i++] = it.next();     FunctorUtils.validate(cmds);    return new ChainedTransformer(cmds);  }  public static Transformer getInstance(Transformer transformer1, Transformer transformer2) {    if (transformer1 == null || transformer2 == null)      throw new IllegalArgumentException("Transformers must not be null");     Transformer[] transformers = { transformer1, transformer2 };    return new ChainedTransformer(transformers);  }  public ChainedTransformer(Transformer[] transformers) {    this.iTransformers = transformers;  }    public Object transform(Object object) {    for (int i = 0; i < this.iTransformers.length; i++)      object = this.iTransformers[i].transform(object);     return object;  }  public Transformer[] getTransformers() {    return this.iTransformers;  }}

该类中的构造方法是传入一个Transformer接口类的数组。transform方法中循环调用Transformer数组中实例的transform方法，并将返回的object作为下次循环的参数传入。（Chained是链接的意思）

可以看到，InvokerTransformer 类有两个构造方法，一个是只给methodName参数赋值其他参数为null，另一个是给三个参数都赋值；
transform方法是通过反射调用执行input对象的某个方法。这个类的作用就是调用反射
机制执行某个方法。

ConstantTransformer类的构造方法是传入一个对象；transform()接口实现方法也是直接将传入的对象返回。（Constant是常量的意思）我们可以用这个类获取到我们想要的类的对象。

回过头来看poc中这三个类的组合，new一个ChainedTransformer 对象，将transformers数组作为参数传入，transformers数组中是4个Transformer接口实现类。现在如果调用ChainedTransformer 对象的transform()方法，就会循环调用数组中对象的transform()方法，先调用ConstantTransformer的transform()方法获取Runtime类，然后调用Runtime类的getRuntime方法，再通过invoke反射调用exec，实现命令执行。
