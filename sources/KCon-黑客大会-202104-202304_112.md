**议题简介**

  

WoW64（Windows 32-bit on Windows 64-bit）是 Windows 操作系统的一个子系统，该子系统支持在 64 位的 Windows 操作系统上运行 32 位的可执行程序。

  

WoW64 最早出现于 XP64 时代，其原型甚至可以追溯到 32 位 Windows 操作系统的时代。网上有不少关于 WoW64 的公开利用方法，比如在 32 位进程中执行 64 位代码、通过自实现的 syscall 绕过 Ring3 HOOK 等。

  

本议题将详细介绍 WoW64 程序执行原理，总结已有的 WoW64 公开利用方法，并介绍一种未公开的 WoW64 利用方法。

  

利用该方法可以劫持目标进程的程序执行流程，甚至是在没有相应权限的情况下直接注册 InstrumentationCallback，配合 ROP 技术无需写入可执行内存就可以实现隐蔽的代码注入和执行功能。

  

最后，议题也将从防御者的角度讨论如何检测此类劫持技术。
