**候选议题**

  

公有云 k8s 攻防研究

  

![](../Images/5f0f6a8f05eaf1f013beee82d2690723.png)

**演讲者**

  

徐琪琪（lazydog），360政企安全高级攻防实验室安全研究员，拥有超过4年的安全研究及渗透测试经验，曾发现并报告了多个漏洞，并获得腾讯、Google、Kubernetes社区等厂商的公开致谢。

  

![](../Images/5f0f6a8f05eaf1f013beee82d2690723.png)

**议题简介**

  

kubernetes 是一个开源系统，用于自动化部署、扩展和管理容器化应用程序，在云和 kubernetes 的安全设计双重加持下，我们能否跨越叹息之墙深入窥探究竟。

  

本议题介绍了 k8s 云托管模式的攻击面，也带来了一些真实攻击案例，在公有云的模式下如果存在安全问题则可能会对多租户造成巨大影响。

  

本议题将包含如下内容：  

  

*1、k8s 安全能力预览*

对 k8s 的架构设计、原生安全能力的研究和探索公有云托管模式的攻击方式。

  

*2、攻击云厂商全局控制平面*

kubernetes 为云厂商提供了 cloud provider 控制器和聚合 api 的扩展能力使得 k8s 能够融合公有云基础架构，通过攻击全局控制层面攻击者可获得大量的租户凭证或远程下发恶意容器导致接管其他租户的集群。

  

*3、工作负载 agent 特权提升*

在全托管的模式下，租户的工作负载节点存在云厂商自动化运维的 agent，该 agent 提供包括容器运行时的升级及 kubelet 的凭据分发，在特定的攻击场景中可以利用此 agent 的攻击面来完成特权提升逃逸至 Host。

  

*4、kube-apiserver SSRF 对云元数据的威胁*

对 kube-apiserver 的安全研究及漏洞挖掘，我们发现并利用其原生安全能力的漏洞来完成窃取云控制器层面的元数据。
