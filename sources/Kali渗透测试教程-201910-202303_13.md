# 开源SOC实现（五）-SIEM日志处理

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NDYwMzI4Mg==&mid=2247485895&idx=1&sn=2c910a9cb4980c1cbcb289d75e5aa4de&chksm=eb10c5badc674cacbcc643b7ad746283bd799c890c4bddf4a588e0882d77e7cd291ea37022c1&scene=126&sessionid=1681659515#rd](http://mp.weixin.qq.com/s?__biz=MzI3NDYwMzI4Mg==&mid=2247485895&idx=1&sn=2c910a9cb4980c1cbcb289d75e5aa4de&chksm=eb10c5badc674cacbcc643b7ad746283bd799c890c4bddf4a588e0882d77e7cd291ea37022c1&scene=126&sessionid=1681659515#rd)

上一期通过Wazuh Server把终端日志收集到Graylog中，但是通过Graylog查看这些日志并没有没正确解析成key:value格式，使查看变得困难。

![](../Images/62f96dc71f03c7a4e0f249898de2e245.png)

接下来需要对日志存放的格式、索引进行分类处理。通过Graylog内置json extract进行处理  

点击日志末尾箭头按钮，选择Create extractor  

![](../Images/dd883b09d5af0fb27ca28f2dfde2067e.png)

选择JSON格式，点击Submit  

![](../Images/c478e357ba2bfbae6553221b224189b8.png)

在弹出窗口中把Key/value separator值修改成:

![](../Images/4af0866691a86d98ba6e0d9f93f29516.png)

点击Try按钮预览效果

![](../Images/ea62aa82ea1419e3f593f197868f82f4.png)

把Extractor title命名成wazuh-json，点击Create extractor  

![](../Images/d275260150efd6fc0cb96d061d24dfa6.png)

创建完成如下图所示  

![](../Images/eb02ca32c31c1b5e526090c9e1b69603.png)

通过SSH登录服务器，在Graylog上观察日志已经被解析成key:value格式  

![](../Images/7457b9092bacb73b1e78a491dccf8864.png)

接着创建告警索引，点击System-Indices  

![](../Images/c280b6adbc49faed0aa38ed05cbee009.png)

点击右上角Create Index set创建索引

![](../Images/0f4e39542eed91f0b20cde465232974b.png)

详细配置如下图所示，其中Title以及Description设置成wazuh alerts，Index prefix设置成wazuh-alerts

![](../Images/f078c1c7b86f4acbd31f3ff7f283ba34.png)

Index Rotation设置成一个G一个索引，满足20个索引时删除第一个索引，举个例子当wazuh-alerts\_21出现时就要删除wazuh-alerts\_0，为wazuh\-alerts\_21存储索引预留空间。

![](../Images/1d8c96db1355bd235e084b70c2c6f455.png)

创建完成索引如下图所示  

![](../Images/214edd693f831145d0bc3cfd61d1ff26.png)

点击查看索引详情

![](../Images/d9cdfbdf3be0cb7d04995f4aedecef62.png)

接下来需要创建Stream来把Graylog收到的告警转发到刚才创建的索引中，在Stream页面，点击右上角Create Stream

![](../Images/62f83566bde8937078e00b25a87576dd.png)

Title以及Description设置为wazuh alerts，Index Set选择刚才创建的索引wazuh alerts，勾选Remove matches from ‘All messages’ stream，点击Save

![](../Images/0b9a3af4b3069a97042b9b2a3e063ea9.png)

创建完成如下图所示，默认处于停止状态  

![](../Images/7b67ae31633d8e40369277fcfd374a15.png)

在启动该Stream前还需要对wazuh传来的日志手动打上标记以识别这个数据是wazuh传输的，点击System-Inputs，点击More actions，选择Add static field

![](../Images/a32b9a72b3948c643573acd911c262d4.png)

添加Field name字段为log\_source，Field value字段为wazuh

![](../Images/4da8cd9fcf5e679069dfa768b5bea117.png)

点击Add field，完成自定义字段添加  

![](../Images/91e98f95d666425868107aa29920538f.png)

查看新接收到日志中已经携带该字段

![](../Images/7d955415e73b0f3e43d124cb520bfc24.png)

最后在Stream界面中设置Rule，当日志中带有log\_source字段并且值为wazuh的数据会进入该Stream，点击More Actions，选择Quick add rule

![](../Images/b336701c77d6273b7f8c1c8555b6ff88.png)

在弹出窗口中配置参数，Field字段为log\_source，Type字段选择match exactly，value字段为wazuh  

![](../Images/02d98981b6360aad63da64b562767d66.png)

配置完成点击Save，点击Start Stream启动Stream，可以看到新接收到日志中日志左下角出现了数据流扭转存储信息

![](../Images/dacbbe6a24a3deebc1e11663f71ad75d.png)

这样就完成了SIEM日志处理的内容，接下来需要对SIEM可视化展示做一些配置，让你一目了然，欢迎订阅收看开源SOC实现（六）-Grafana Dashboard
