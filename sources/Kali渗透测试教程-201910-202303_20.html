Cuckoo 是一个开源的自动化恶意软件分析系统。

它用于自动运行和分析文件，并收集全面的分析结果，概述恶意软件在隔离的操作系统中运行时的行为。

它可以检索以下类型的结果：

  • 由恶意软件产生的所有进程执行的调用跟踪。

  • 恶意软件在执行期间创建、删除和下载的文件。

  • 恶意软件进程的内存转储。

  • PCAP 格式的网络流量跟踪。

  • 恶意软件执行过程中截取的屏幕截图。

  • 机器的完整内存转储。

Cuckoo Sandbox 由一个控制端组成，用于处理样本执行和分析。

每个分析都在一个全新的、隔离的虚拟机或物理机中启动。Cuckoo 基础设施的主要组件是一台Host主机（管理软件）和一些Guest访客机（用于分析的虚拟或物理机）。

Host 主机运行沙箱的核心组件，管理整个分析过程，而 Guest 是隔离的环境，恶意软件样本在其中真正安全地执行和分析。

相信大家都使用过微步、vt的沙箱，现在你也可以拥有一个属于自己的沙箱，对！他就是Cuckoo



为了让Cuckoo成功为我们分析恶意软件，需要以下组件

  • Host主机（这里指Debian10，安装Cuckoo管理软件）

  • Guest虚拟机（这里指Win7用于分析的虚拟机）

  • VMware Workstation（用于安装虚拟机）


Step1-【安装Cuckoo】

安装Debian10，具体步骤就不截图了，安装成功如下

安装各类库

sudo apt install libffi-dev libssl-dev libjpeg-dev zlib1g-dev swig

安装Mongodb和postgresql数据库

sudo apt install mongodb -ysudo apt install postgresql libpq-dev -y

安装anaconda用来承载python环境

https://www.anaconda.com/products/individual

下载安装，按照提示安装都是比较基础的英文应该看得懂

bash Anaconda3-2021.05-Linux-x86_64.sh

安装完成之后更新conda

conda update condaconda update anaconda

更新完成搜索所有版本python环境

conda search python

启动anaconda配置python环境

anaconda-navigator

等待几分钟之后环境就创建好了

进入该环境中安装python的相关库

pip install -U pip setuptools

安装完成之后安装pip2

sudo apt install python-pip

通过pip2安装cuckoo

pip2 install cuckoo

通过pip安装weasyprint

pip install weasyprint

安装完成之后更新conda

conda update --all

使用终端输入cuckoo之后可以出现以下输出代表cuckoo安装成功

接下来配置cuckoo让其可以正常运行


Step2-【配置Cuckoo】

首先在Debian10上面安装VMware Workstation，再准备一个Win7的ISO镜像

如何在Linux里面安装VMware Workstation以及创建虚拟机参考搜索引擎，安装完成如下


首选需要来配置一下网卡信息，在VMware Workstation标签edit-virtual network editor里有几张网卡，将vmnet1网卡修改成仅主机模式，网段不需要修改，这边分配到的是172.16.150.0/24网段

由于仅主机网卡下虚拟机不能上网，此时需要在Debian10中通过iptables转发该网段的流量

iptables -A FORWARD -o enp0s5 -i vmnet1 -s 172.16.150.0/24 -m conntrack --ctstate NEW -j ACCEPT  iptables -A FORWARD -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT  iptables -A POSTROUTING -t nat -j MASQUERADE iptables -A FORWARD -s 172.16.150.0/24 -d 172.16.150.0/24 -j ACCEPT

查看iptables

iptables -nvL

配置完成之后编辑cuckoo配置文件

/home/parallels/.cuckoo/conf/cuckoo.conf

主要关注几个字段

version_check = nomachinery = vmwarememory_dump = yesip = 172.16.150.1

其他均不需要修改，其中上面配置ip为安装完VMware Workstation后vmnet1网卡ip

修改完之后再来修改vmware配置文件

vmware.conf

主要修改以下几个字段

machines = cuckoo1interface = vmnet1vmx_path = /home/parallels/vmware/Windows 7 x64/Windows 7 x64.vmxsnapshot = snapshotplatform = windowsip = 172.16.150.128

其中vmx_path需要跟虚拟机的vmx路径一致，ip需要通过静态方式配置在Win7虚拟机上，等Win7虚拟机中配置配置好后（这一部分放到后面）需要打上快照并且快照名称需要为snapshot

这样子就完成了第二部分【配置Cuckoo】



接下来配置Win7虚拟机让其可以跟cukcoo联动进行恶意软件分析


Step3-【配置Win7虚拟机】

首先安装python2.7

离线安装setuptools，下载安装包setuptools-33.1.1，解压之后切换到目录进行安装

python setup.py install

安装成功之后下载pip-20.3离线压缩包进行安装，切换到该目录进行安装

python setup.py install

这样子就安装好了pip2

接下来离线安装pillow该库为python的截图库，用于恶意软件运行时截图

https://www.lfd.uci.edu/~gohlke/pythonlibs/#pillow

下载python2.7并且为64位的whl文件，离线安装

python install Pillow-6.2.2-cp27-cp27m-win_amd64.whl

拷贝cuckoo的agent到Win7虚拟机中，并且需要把后缀改成.pyw

/home/parallels/.cuckoo/agent

放入Win7虚拟机开机启动文件夹中

C:\ ProgramData\Microsoft\Windows\Start Menu\Programs\StartUp

接着重启虚拟机，查看任务管理器中是否有pythonw进程

关闭Win7虚拟机防火墙

关闭自动更新

关闭UAC

根据下图配置用户自动登录

为虚拟机打上快照

这样子就完成了第三部分【配置Win7虚拟机‍】



最后使用cuckoo加载配置好的虚拟机

cuckoo
