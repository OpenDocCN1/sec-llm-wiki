# 【Cuckoo】你也可以拥有自己的恶意软件分析系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NDYwMzI4Mg==&mid=2247485644&idx=1&sn=619d2b3311813bb192b8437998e55d75&chksm=eb10c4b1dc674da793719d6056f39c50b8385655c55894cf1dbd2837c5e7dbac648ae6f55cd4&scene=126&sessionid=1681659515#rd](http://mp.weixin.qq.com/s?__biz=MzI3NDYwMzI4Mg==&mid=2247485644&idx=1&sn=619d2b3311813bb192b8437998e55d75&chksm=eb10c4b1dc674da793719d6056f39c50b8385655c55894cf1dbd2837c5e7dbac648ae6f55cd4&scene=126&sessionid=1681659515#rd)

Cuckoo 是一个开源的自动化恶意软件分析系统。

它用于自动运行和分析文件，并收集全面的分析结果，概述恶意软件在隔离的操作系统中运行时的行为。

它可以检索以下类型的结果：

> *   由恶意软件产生的所有进程执行的调用跟踪。
>     
> *   恶意软件在执行期间创建、删除和下载的文件。
>     
> *   恶意软件进程的内存转储。
>     
> *   PCAP 格式的网络流量跟踪。
>     
> *   恶意软件执行过程中截取的屏幕截图。
>     
> *   机器的完整内存转储。
>     

Cuckoo Sandbox 由一个控制端组成，用于处理样本执行和分析。

每个分析都在一个全新的、隔离的虚拟机或物理机中启动。Cuckoo 基础设施的主要组件是一台Host主机（管理软件）和一些Guest访客机（用于分析的虚拟或物理机）。

Host 主机运行沙箱的核心组件，管理整个分析过程，而 Guest 是隔离的环境，恶意软件样本在其中真正安全地执行和分析。

Step2-【配置Cuckoo】

首先在Debian10上面安装VMware Workstation，再准备一个Win7的ISO镜像

![](../Images/0962913a977acd3ee693e5b093efc4ca.png)

如何在Linux里面安装VMware Workstation以及创建虚拟机参考搜索引擎，安装完成如下

![](../Images/101cf39935f18e8e8f906f0725515a78.png)

  

首选需要来配置一下网卡信息，在VMware Workstation标签edit-virtual network editor里有几张网卡，将vmnet1网卡修改成仅主机模式，网段不需要修改，这边分配到的是172.16.150.0/24网段  

![](../Images/342f806d6f3494ac32182030302eae33.png)

由于仅主机网卡下虚拟机不能上网，此时需要在Debian10中通过iptables转发该网段的流量  

*   
*   
*   
*   

```
iptables -A FORWARD -o enp0s5 -i vmnet1 -s 172.16.150.0/24 -m conntrack --ctstate NEW -j ACCEPT  iptables -A FORWARD -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT  iptables -A POSTROUTING -t nat -j MASQUERADE iptables -A FORWARD -s 172.16.150.0/24 -d 172.16.150.0/24 -j ACCEPT
```
