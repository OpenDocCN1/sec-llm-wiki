想重新搭建一个博客，在GitHub上面找了个看起来还不错的博客源码

项目地址

https://github.com/leopardpan/leopardpan.github.io.git

作者给的效果预览地址：leopardpan.cn


选定模版之后开始


按照作者给的步骤

最后开启jekyll的时候报错了


第一次出现了个Gem::LoadError的错误，具体的报错忘记保存，根据报错信息查找之前别人记录的说是Gemfile.lock里面的版本跟自己安装的不一样导致的，有点没什么头绪，之前都没怎么接触过ruby


于是照着尝试修改，修改完之后还是不可以，有看到有人说需要重新安装bundler

于是重现安装，重新安装出现新的报错信息

Cant find gem bundler (>= 0.a) with executable bundle

继续搜索

于是执行以下命令

gem install bundler -v "$(grep -A 1 "BUNDLED WITH" Gemfile.lock | tail -n 1)"

更新之后运行 jekyll server还是不可以

出现新的报错信息

/var/lib/gems/2.5.0/gems/bundler-1.16.1/lib/bundler/spec_set.rb:88:in `block in materialize': Could not find public_suffix-3.0.3 in any of the sources (Bundler::GemNotFound)

只能继续找

于是执行以下命令

gem install public_suffix --version 3.0.1

执行完一样报错，尝试更新一下bundle

bundle update

更新完之后再重新执行jekyll server发现终于可以了
