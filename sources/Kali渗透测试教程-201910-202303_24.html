什么是CVE-2021-1675


CVE-2021-1675是一个远程代码执行漏洞，允许具有普通用户帐户的攻击者接管运行 Windows Print Spooler 服务的服务器。默认情况下，它在 Active Directory 环境中的所有 Windows 服务器和客户端（包括域控制器）上运行。


漏洞影响范围


漏洞利用代码可能会导致 Windows 系统完全受到攻击。根据 HelpNet Security的说法，该漏洞影响 Windows Server（2004、2008、2008 R2、2012、2012 R2、2016、2019、20H2）和 Windows（7、8.1、RT 8.1、10）的版本。


在提供的POC中使用刚发布的预览版Windows11进行测试，复现成功。


如何预防


由于暴露的性质，所有系统（尤其是域控制器）都需要禁用 Print Spooler 服务，直到有可用的补丁可用并安装。注意：服务应该被禁用，而不是停止。如果只是停止，则可能会触发再次启动。

即使没有此漏洞，建议也避免在任何域控制器上运行打印后台处理程序服务，因为当威胁行为者有权访问具有无约束委派的用户时，它可用于将权限提升到域控制器计算机帐户
