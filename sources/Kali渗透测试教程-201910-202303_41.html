马上开始我们的教程


Step1：购买VPS，个人一直在使用vultr，感觉还可以，如果你也想使用vultr的VPS的话，这边顺便打个广告可以使用下面的链接进行注册

我是购买了下图这样的配置，系统是ubuntu16.04

几分钟之后VPS就安装好了，接下来我们可以使用SSH登录，我这边是使用XSHELL进行登入，成功登陆之后，先更新一下系统依赖项目录

apt-get update

更新完成之后我们来安装java环境，因为等下使用到的是CS3.8所以安装JDK1.8的环境，登入官网，注册个账号就可以下载，点击下面链接即可下载

https://www.oracle.com/technetwork/java/javase/downloads/java-archive-javase8-2177648.html

注意下载对应版本，下载完成之后，可以使用XFTP把刚才下载的压缩包传到服务器上面去

一会儿之后，文件传输完毕（我也不知道为什么传输会那么慢，知道的大佬可以告知一下，谢谢）

接下来，我们开始安装Java环境

tar xf jdk-8u152-linux-x64.tar.gzmv jdk1.8.0_152/ /usr/local/ln -s /usr/local/jdk1.8.0_152/ /usr/local/jdk

 vi /etc/profile

在/etc/profile中输入

  export JAVA_HOME=/usr/local/jdk/   export PATH=$JAVA_HOME/bin:$JAVA_HOME/jre/bin:$PATH   export CLASSPATH=.$CLASSPATH:$JAVA_HOME/lib:$JAVA_HOME/jre/lib:$JAVA_HOME/lib/tools.jar

保存退出，完成对文件的编辑，接下来我们使环境变量即时生效

source /etc/profile

这样子我们就完成了Java环境的配置，接下来我们查看一下Java的版本

java -version

我们从上图可以看到Java的版本为1.8.0_152，说明配置过程没有出错



Step2：我们注册一下域名，这里推荐免备案的域名，哪里买大家应该也都知道，不知道的可以私聊我

购买完域名之后，我们使用Dnspod进行域名解析，为什么使用这个呢，因为可以进行免费解析

点击添加域名之后，将购买的域名填入，注意的是不用加www或者是其他的，将你购买的域名写入即可

接下来，我们对该域名进行编辑解析记录

注意的是：我们需要添加一条A记录，将域名指向之前购买VPS主机的IP地址，添加完A记录之后，我们需要添加几条NS记录，NS记录的意思就是把该域名给哪一个name server解析

接着我们来看下图的配置，下图的A记录代表like.toxxx.xxx会解析到IP地址66.xx.xx.xx，下图中的几条NS记录代表将ns.toxxx.xxx丢给like.toxxx.xxx解析，即丢给66.xx.xx.xx去解析，这样子就完成了一个过程，即所有的NS记录最后都会丢给66.xx.xx.xx去解析


这样子我们就完成了域名解析相关的配置，接下来我们来校验一下是否配置正确，因为如果没有配置正确，那么将无法使主机通过DNS隧道上线


我们使用nslookup进行检测，如果回显如图所示，说明配置成功

nslookup server like.toxxx.xxx server ns.toxxx.xxx


其中第一条回显为VPS的地址，第二条回显的地址为0.0.0.0

底层用的是dns协议，而非http,https,或者udp…使用dns的好处，域名相对于ip有更强的隐蔽性，现在也有很多后门传输开始走DNS隧道了，比以往走HTTP、TCP等更难察觉
