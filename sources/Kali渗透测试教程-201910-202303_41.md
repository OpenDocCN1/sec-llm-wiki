Step2：我们注册一下域名，这里推荐免备案的域名，哪里买大家应该也都知道，不知道的可以私聊我

购买完域名之后，我们使用Dnspod进行域名解析，为什么使用这个呢，因为可以进行免费解析

![](../Images/02475f1bb158b4cfb4e7475d068a9174.png)

点击添加域名之后，将购买的域名填入，注意的是不用加www或者是其他的，将你购买的域名写入即可

![](../Images/a5c05d5387a22aaa2189191b35cb0c63.png)

接下来，我们对该域名进行编辑解析记录

> 注意的是：我们需要添加一条A记录，将域名指向之前购买VPS主机的IP地址，添加完A记录之后，我们需要添加几条NS记录，NS记录的意思就是把该域名给哪一个name server解析

接着我们来看下图的配置，下图的A记录代表like.toxxx.xxx会解析到IP地址66.xx.xx.xx，下图中的几条NS记录代表将ns.toxxx.xxx丢给like.toxxx.xxx解析，即丢给66.xx.xx.xx去解析，这样子就完成了一个过程，即所有的NS记录最后都会丢给66.xx.xx.xx去解析

![](../Images/4fc9680557b9ea48113a5340029f5fde.png)  

这样子我们就完成了域名解析相关的配置，接下来我们来校验一下是否配置正确，因为如果没有配置正确，那么将无法使主机通过DNS隧道上线

  

我们使用nslookup进行检测，如果回显如图所示，说明配置成功

*   
*   
*   

```
nslookup server like.toxxx.xxx server ns.toxxx.xxx
```

![](../Images/c92ff91b14f536f2c46a0abee9db3e1e.png)  

其中第一条回显为VPS的地址，第二条回显的地址为0.0.0.0

![](../Images/f0454d8c467d4ba1ff86477b9eda86b2.png)

这个时候我们的payload仅仅是作为一个beacon，因为我们没有告知payload跟我们进行交互，因为我们没有为其指定一个任务  

![](../Images/9d23fb9e282711b65dbf9b178653b729.png)

原理图就像这样子，判断是否有任务，如果有即可下载任务，在我们没有指定数据传输模式和任务的时候，payload仅仅是作为一个beacon

![](../Images/a6334e5ecaaffd1c517aa1c33e4dec1f.png)

接下来，我们将数据模式改为dns-txt，并为这个任务输入checkin命令，一个checkin命令是一个基本什么都没有干的空任务

![](../Images/f42995426f040ba1be03e63306eee6bf.png)

过了一会儿，我们就看到sent：8bytes，这个时候再来看一下目标主机上线的情况

![](../Images/03dab3f3abbc9ea36f2ad502b34ee45e.png)

这样子我们就完成了靶机通过dns隧道上线

底层用的是dns协议，而非http,https,或者udp…使用dns的好处，域名相对于ip有更强的隐蔽性，现在也有很多后门传输开始走DNS隧道了，比以往走HTTP、TCP等更难察觉
