进入正题：

首先安装Python2，相信大家很多都有了，就不介绍如何安装了，还没安装的小伙伴可以通过搜索教程安装，脚本中主要使用requests模块和BeautifulSoup模块，需要把这两个模块通过Python安装上

pip install requestspip install BeautifulSoup

数据库使用的是Mongodb，需要安装Python中pymango模块，发送邮件使用的是SMTP协议，需要安装Python中smtplib模块

pip install pymangopip install smtplib

实际上我并没有执行上面两条命令，可能是在安装别的工具的时候安装好了


安装完之后，修改脚本

第一处，其实也就一处，就是修改SMTP中发件人和收件人

此处使用QQ邮箱，首先先把SMTP服务器改成QQ的SMTP服务器smtp.qq.com，接下来设置发件人，填写上自己的QQ邮箱的账号和密码，注意此处密码并非为QQ密码，需要获取QQ邮箱的授权码作为密码

先开启上述服务，点击获取授权码，发送短信，点击我已发送接口获取授权码，将其作为密码填入脚本中密码处，即可配置完成


配置完成

使用Python运行脚本

python CVE.py

接着在收件邮箱就看到了发来的邮件信息

完成之后还可以结合Crontab定时任务进行每天定时推送CVE邮件信息

crontab0 7 * * * python CVE.py

人在家中坐，CVE情报邮件来！
