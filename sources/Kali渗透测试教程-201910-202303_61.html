欢迎回来，我们需要更酷一点

这篇文章就当作闲时娱乐的小乐趣吧，即使不会Python，你也可以使用Python发短信



登陆官网，注册账号，验证手机号

https://www.twilio.com/

注册完成，来到主面板，先获取一个免费的号码，用于该项目中通信使用，发短信，或者打电话

获取完电话号码，我们需要查看用户ID和TOKEN，等下会使用到

安装Python3，并且安装库twilio，安装完成之后，修改下面一段代码，将需要替换的字段值进行替换

from twilio.rest import Client
# Your Account SID from twilio.com/consoleaccount_sid = "ACXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX"# Your Auth Token from twilio.com/consoleauth_token  = "your_auth_token"
client = Client(account_sid, auth_token)
message = client.messages.create(# 接收号码    to="+86***********",# 发送号码，即刚才获取的免费号码    from_="+1**********",# 发送内容    body="Kali渗透测试教程!")
print(message.sid)

随着手机通知铃声一响，成功收到短信


但是，只发给自己也不大好玩，就看了一下官网，尝试发给别人，将代码中接受号码换了下，报错了，一查发现是地域限制，在官网中修改允许的发送地域，修改地址如下，可以直接复制到浏览器中访问

https://www.twilio.com/console/sms/settings/geo-permissions

添加了几个地域，再尝试发送，还是报错了，显示号码未认证

搜索了一下，发现接受号码需要认证，因为一开始接受号码为注册验证号码，所以不需要验证，可以在浏览器中访问如下网址，添加认证号码，还有一种不需要认证的方法，就是你需要购买他们的服务，还可以去掉短信前的服务名称

https://www.twilio.com/console/phone-numbers/verified

再次尝试发送短信，成功发送

所以，这种短信服务结合计划任务可以用于定时向某个人发送固定短信，就不用怕忘记给男/女朋友发送祝福短信，然后感情破裂，不过还是要自己发显得比较有诚意

最后在来一段代码，当然你也可以选择别的编程语言的，比如Java，C#之类的，其中Java代码如下

import com.twilio.Twilio;import com.twilio.rest.api.v2010.account.Message;import com.twilio.type.PhoneNumber;
public class Example {  // Find your Account Sid and Token at twilio.com/user/account  public static final String ACCOUNT_SID = "ACXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX";  public static final String AUTH_TOKEN = "your_auth_token";
  public static void main(String[] args) {    Twilio.init(ACCOUNT_SID, AUTH_TOKEN);
    Message message = Message.creator(new PhoneNumber("+15558675309"),        new PhoneNumber("+15017250604"),         "Kali渗透测试教程!").create();
    System.out.println(message.getSid());  }}
