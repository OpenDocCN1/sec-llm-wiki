author : n00B@khan
nfuzz.py 是个具备 / web目录扫描器 / post fuzz爆破 / curl -I / 功能的脚本
windows 下也具备颜色输出 ，本工具尽量用 python3 编译，python2 可能会报错

缺点：windows 下没有ctrl-c 终止程序

用法：

web目录扫描:python3 nfuzz.py -w /usr/share/wordlists/wfuzz/general/common.txt -u xxxxxxxxxxxx.com -t 5
post爆破（ FUZZ 占 位 符 和 -d 是 必 须 的 ，传 递 的 参 数 格 式 也 要 合 规 ）:python3 nfuzz.py -w password.txt -u xxxxxxxx.com -d "username=admin&password=FUZZ"
curl -I（个人用的比较多，所以添上了）:python3 nfuzz.py -u xxxxxxxxxxxxx.com -I
