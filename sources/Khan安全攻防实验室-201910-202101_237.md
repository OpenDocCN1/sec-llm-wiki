# 漏洞预警：Apache Solr 远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMjQ2NTQ4Mg==&mid=2247483766&idx=1&sn=4127d66dae7854f795eec8b6d67f580e&chksm=9acb4ad3adbcc3c5dd5f03c674ab775a3c9022fe82f609b27f6ad48a521eb50c254c8ef89a3d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMjQ2NTQ4Mg==&mid=2247483766&idx=1&sn=4127d66dae7854f795eec8b6d67f580e&chksm=9acb4ad3adbcc3c5dd5f03c674ab775a3c9022fe82f609b27f6ad48a521eb50c254c8ef89a3d&scene=27#wechat_redirect)

**00x01 漏洞背景**

Solr是一个独立的企业级搜索应用服务器，它对外提供类似于Web-service的API接口。用户可以通过http请求，向搜索引擎服务器提交一定格式的XML文件，生成索引；也可以通过Http Get操作提出查找请求，并得到XML格式的返回结果。2019年10月31日下午，安全研究员s00py在推特上发了一个solr远程代码命令执行的另外一种方法。链接中指出，需设置Set "params.resource.loader.enabled" as true.时，导致命令执行漏洞触发。**00x02 漏洞复现**  

修改core

    {

      "update-queryresponsewriter": {

        "startup": "lazy",

        "name": "velocity",

        "class": "solr.VelocityResponseWriter",

        "template.base.dir": "",

        "solr.resource.loader.enabled": "true",

        "params.resource.loader.enabled": "true"

      }

    }

已测7.0.1，7.7.2，8.1.1

1、升级Solr版本；  

2、对Solr后台进行身份认证，禁止未授权访问。
