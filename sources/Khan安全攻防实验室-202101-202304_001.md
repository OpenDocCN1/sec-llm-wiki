# 蓝队神兵利器 - Reportly

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMjQ2NTQ4Mg==&mid=2247490774&idx=1&sn=fef10e3962f7837bfa6c02603688bd30&chksm=67e8ea6a239a5acb92bbea88103f15d5d117565e3fc63ef729ec7babbe176422ae141101d602&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMjQ2NTQ4Mg==&mid=2247490774&idx=1&sn=fef10e3962f7837bfa6c02603688bd30&chksm=67e8ea6a239a5acb92bbea88103f15d5d117565e3fc63ef729ec7babbe176422ae141101d602&scene=27#wechat_redirect)

        这是一个能在云计算事件中帮助蓝队的工具。运行该工具时，研究人员将输入一个可疑的用户和一个时间段，并将收到一份报告，详细说明以下内容：

*   有关该用户的信息
    
*   该用户采取的行动
    
*   对该用户采取的行动
    
*   用户的登录和失败记录
    

  

使用方法

![](../Images/aa497134a72f179a0db508c5a9601194.png)

插入可疑用户的用户本名、以下列格式插入开始和结束时间：2022-11-16

我建议范围不要超过一个星期。

认证后，为了创建一个完整的报告，选择选项 "5"

![](../Images/d6977493df651ac105a98469b989513c.png)

        当报告准备好后，该工具将打印 "你的报告准备好了！"。报告是在可执行文件的目录下创建的。

Installation

        为了使用该工具，你将需要一个AzureAD应用程序，并具有以下授权的microsoft graph api权限：

*   AuditLog.Read.All  
    
*   GroupMember.Read.All  
    
*   RoleManagement.Read.Directory  
    
*   User.Read  
    
*   User.Read.All  
    

![](../Images/ce04945b1cc550cc1ae7420d25053dc0.png)

        要创建一个应用程序，请进入 "应用程序注册 "选项卡并选择 "新注册 "选项。

![](../Images/0b3bf2b663a2cfc5dfebc8efa0c44b17.png)

此外，在创建应用程序时，确保你将以下选项标记为 "yes"

![](../Images/c56c15b581a347f220a595b7d82638ce.png)

        你可以在应用程序的 "验证 "标签下找到这个属性，给应用程序添加一个secret。

![](../Images/58c57f3c0d16b14e3c544a6c821e59ca.png)

转到 "证书和secret"

添加一个secret

立即将secret复制到配置文件中（在你观看一次后，它就会消失）。

创建应用程序后，你需要填写config.cfg文件：

*   clientId = 应用程序ID
    
*   clientSecret = 应用程序的秘密
    
*   tenantId = 租户ID
