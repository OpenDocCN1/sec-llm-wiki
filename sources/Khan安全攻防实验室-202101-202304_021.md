# Gmail C2服务器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMjQ2NTQ4Mg==&mid=2247490623&idx=1&sn=52cde3e1212b204ab229bbe3d8488901&chksm=d368fb9207be522ae75d721933479ead39cb070b325e31c76a8f55b208d9761909fe04b2e891&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMjQ2NTQ4Mg==&mid=2247490623&idx=1&sn=52cde3e1212b204ab229bbe3d8488901&chksm=d368fb9207be522ae75d721933479ead39cb070b325e31c76a8f55b208d9761909fe04b2e891&scene=27#wechat_redirect)

        一个无法检测到的 C2 服务器，它通过 Google SMTP 进行通信以逃避防病毒保护和网络流量限制。

![](../Images/bf1d0428788f54700b457795b3edbc22.png)

        这个RAT通过Gmail SMTP进行通信（或者你也可以使用任何其他的SMTP），但Gmail SMTP是有效的。

         因为大多数公司都阻止未知的流量，所以Gmail的流量是有效的，并且在任何地方都是允许的。

```
1. 创建两个独立的Gmail账户。 2. 现在在两个账户上都启用SMTP（如果你不知道，请查看Youtube）。 3. 假设你已经创建了两个独立的Gmail账户并启用了SMTP    A -> 第一个账户代表Your_1st_gmail@gmail.com    B -> 第二个账户代表your_2nd_gmail@gmail.com 4. 现在进入server.py文件，在第67行填写以下内容。    smtpserver="smtp.gmail.com" (不要改变这个)    smtpuser="Your_1st_gmail@gmail.com"      smtpkey="your_1st_gmail_app_password"    imapserver="imap.gmail.com" (不要改变这个)    imapboy="your_2nd_gmail@gmail.com"5. 现在进入client.py文件，在第16行填写以下内容。    imapserver = "imap.gmail.com" (不要改变这个)    username = "your_2nd_gmail@gmail.com"    密码 = "your2ndgmailapp password"    获取 = "Your_1st_gmail@gmail.com"    smtpserver = "smtp.gmail.com" (不要改变这个)
```

  

Windows:

 1. 确保python3和pip已经安装，并且也安装了requriements。

 2. python server.py (在服务器端)

 

Linux:

 1. 确保所有的Requriements都已安装。

 2. python3 server.py (在服务器端)
