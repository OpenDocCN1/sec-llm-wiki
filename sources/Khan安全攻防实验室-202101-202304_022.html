        IpGeo 是一个 python 工具，用于从捕获的网络流量文件 (pcap/pcapng) 中提取 IP 地址，并生成包含有关数据包中每个 ip 的地理位置详细信息的 csv 报告。

python3 ipGeo.py


使用pip3安装所需的模块。

pip3 install coloramapip3 install requestspip3 install pyshark
