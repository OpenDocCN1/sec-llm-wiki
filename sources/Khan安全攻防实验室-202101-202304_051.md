# SSH PuTTY 登录暴力破解器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMjQ2NTQ4Mg==&mid=2247490491&idx=1&sn=88551cf9f48ef25694ac2d32b3e5b7c2&chksm=9acb501eadbcd9081018fa22713f4c8cb3b33289385f89f815bea8736748a113e5129e9f6620&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMjQ2NTQ4Mg==&mid=2247490491&idx=1&sn=88551cf9f48ef25694ac2d32b3e5b7c2&chksm=9acb501eadbcd9081018fa22713f4c8cb3b33289385f89f815bea8736748a113e5129e9f6620&scene=27#wechat_redirect)

        ssh-putty-brute.ps1是一个包装脚本，它使用 PuTTY 客户端（putty.exe或plink.exe）执行 SSH 登录暴力攻击。

## 用法和示例

该工具需要PATH 或当前工作目录中的putty.exe或plink.exe可执行文件。

以下是使用此工具的方法：

*   
*   
*   
*   
*   
*   
*   
*   

```
import-module .\ssh-putty-brute.ps1
# Usage:ssh-putty-brute [-h ip|ips.txt] [-p port] [-u user|users.txt] [-pw pass|pwdlist.txt]
# Examples:ssh-putty-brute -h 10.10.5.11 -p 22 -u root -pw P@ssw0rdssh-putty-brute -h 10.10.5.11 -p 22 -u root -pw (Get-Content .\pwdlist.txt)
```
