# iscsicpl autoelevate DLL Search Order 劫持 UAC 绕过 0day

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMjQ2NTQ4Mg==&mid=2247490222&idx=1&sn=fd49de87fd583e2b8f684268ecb00110&chksm=9acb510badbcd81de6f4d4f3bed38aecf293b521e768da6573906e8a1db9cdd1b4f1b5994386&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMjQ2NTQ4Mg==&mid=2247490222&idx=1&sn=fd49de87fd583e2b8f684268ecb00110&chksm=9acb510badbcd81de6f4d4f3bed38aecf293b521e768da6573906e8a1db9cdd1b4f1b5994386&scene=27#wechat_redirect)

当通过 SysWOW64 在 64 位主机上运行 32 位 Microsoft 二进制文件时，iscsicpl.exe 二进制文件容易受到 DLL 搜索顺序劫持漏洞的攻击。32 位二进制文件将在用户 %Path% 中搜索 DLL iscsiexe.dll。当启用自动提升时，可以使用代理 DLL 通过“iscsicpl.exe”执行代码来利用这一点。此漏洞已针对以下 Windows 桌面版本进行了测试：

*   Windows 11 企业版 x64（版本 10.0.22000.739）。
    
*   Windows 8.1 Professional x64（版本 6.3.9600）。
