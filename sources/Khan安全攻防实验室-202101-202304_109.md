```
用于搜索 Apache Tomcat 服务器的多线程工作人员。可能的多个目标源：通过 LDAP 查询从 Windows 域中检索计算机列表，以将它们用作目标列表。从文件中逐行读取目标。-tt/--target从选项中读取单个目标 (IP/DNS/CIDR) 。要测试的端口的自定义列表。测试/manager/html访问和默认凭据。--list-cves使用选项列出每个版本的 CVE
```
