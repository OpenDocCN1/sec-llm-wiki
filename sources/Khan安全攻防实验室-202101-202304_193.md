# VMware Workspace ONE Access RCE CVE-2022-22954

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMjQ2NTQ4Mg==&mid=2247489068&idx=1&sn=b46228d2ad0871f0ddac7be8de03a7d6&chksm=9acb5d89adbcd49f1c8f7504acb5ceb1dcb9da4f2cc10891cae50dbcfb50abfd49cc19c7f368&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMjQ2NTQ4Mg==&mid=2247489068&idx=1&sn=b46228d2ad0871f0ddac7be8de03a7d6&chksm=9acb5d89adbcd49f1c8f7504acb5ceb1dcb9da4f2cc10891cae50dbcfb50abfd49cc19c7f368&scene=27#wechat_redirect)

  

        VMware Workspace ONE Access and Identity Manager 包含一个由于服务器端模板注入而导致的远程代码执行漏洞。VMware 已将此问题的严重性评估为处于 严重严重性范围内 ，CVSSv3 基本得分最高为 9.8。

  

        具有网络访问权限的恶意行为者可以触发可能导致远程代码执行的服务器端模板注入。

解决

        要修复 CVE-2022-22954，请应用下方“解决方案矩阵”的“修复版本”列中列出的补丁程序。

  

https://core.vmware.com
