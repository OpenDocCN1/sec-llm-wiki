# Spring Cloud Gateway Actuator API SpEL 代码注入 (CVE-2022-22947)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMjQ2NTQ4Mg==&mid=2247488730&idx=2&sn=592e58fb91d7149d468cd6324914b31f&chksm=9acb5f7fadbcd669b2983ba5182df8ca9445fd6ff9a038b50b3796c1a65d7aa6217ce673e78c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMjQ2NTQ4Mg==&mid=2247488730&idx=2&sn=592e58fb91d7149d468cd6324914b31f&chksm=9acb5f7fadbcd669b2983ba5182df8ca9445fd6ff9a038b50b3796c1a65d7aa6217ce673e78c&scene=27#wechat_redirect)

  

        Spring Cloud Gateway 提供了一个库，用于在 Spring WebFlux 之上构建 API 网关。

        在 3.1.0 和 3.0.6 之前的版本中使用 Spring Cloud Gateway 的应用程序在启用、暴露和不安全的 Gateway Actuator 端点时容易受到代码注入攻击。远程攻击者可以发出恶意制作的请求，允许在远程主机上进行任意远程执行。

参考：

*   https://tanzu.vmware.com/security/cve-2022-22947
    
*   https://wya.pl/2022/02/26/cve-2022-22947-spel-casting-and-evil-beans/
