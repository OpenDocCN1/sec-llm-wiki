        Key Management Service（简称:KMS）

是一款支持Office2013,Office2016,Win7,Win8,Win10的本地离线激活工具  

  

        这个功能是在Windows Vista之后的产品中的一种新型产品激活机制，目的是Microsoft更好的遏制非法软件授权行为(盗版)。激活期限一般为180天，约6个月。

  

KMSpico可以激活：

  

Win 10 所有版本

Win 8.1 所有版本

Windows 8 所有版本

Windows 7 专业版/企业版

Office 2010 / 2013 所有版本

Windows Server 2008/2008 R2 标准版/数据中心版/企业版

Windows Server 2012/2012 R2 标准版/数据中心版/企业版
