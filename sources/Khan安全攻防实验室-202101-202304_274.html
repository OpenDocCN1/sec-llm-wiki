易受攻击的 URL 路径是： <grafana_host_url> /public/plugins/<“plugin-id”>其中<“plugin-id”>是任何已安装插件的插件 ID。

每个 Grafana 实例都预装了 Prometheus 插件或 MySQL 插件等插件，因此每个实例的以下 URL 都容易受到攻击：

解决方案和缓解措施

v8.0.0-beta1 和 v8.3.0 之间的所有安装都应尽快升级。

如果无法升级，在 Grafana 前运行反向代理来规范化请求的 PATH 将缓解该漏洞。例如，envoy 中的normalize_path设置。
