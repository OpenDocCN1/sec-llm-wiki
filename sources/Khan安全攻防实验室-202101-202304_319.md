## 执行方式

        Drupwn 可以运行，使用两种不同的模式，即枚举和利用。枚举模式允许执行枚举，而利用模式允许检查和利用 CVE。

  

支持：

  

        用户枚举

        节点枚举

        默认文件枚举

        模块枚举

        主题枚举

        支持Cookies

        支持User-Agent

        基本认证支持

        请求延迟

        枚举范围

        记录

        支持Socks和HTTP代理

        漏洞检查器

        CVE探索器

      

安装：  

  

*   
*   

```
pip3 install -r requirements.txtpython3 drupwn --help
```

  

or  

  

*   
*   

```
python3 setup.py installdrupwn --help
```

## 日志记录

生成的输出存储在/tmp/文件夹中。使用 docker 时，使用以下选项运行容器

```
\-v YOUR\_PATH\_FOLDER:/tmp/
```
