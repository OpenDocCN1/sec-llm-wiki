# SPAWN - Cobalt Strike BOF

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMjQ2NTQ4Mg==&mid=2247487319&idx=1&sn=e5b0009598a5f1cea7f9603ce2a5a777&chksm=9acb44f2adbccde46cc0ac6061ba047ec8b5df2a8edba4e9c897f8386bc394c3e55b5c65818e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMjQ2NTQ4Mg==&mid=2247487319&idx=1&sn=e5b0009598a5f1cea7f9603ce2a5a777&chksm=9acb44f2adbccde46cc0ac6061ba047ec8b5df2a8edba4e9c897f8386bc394c3e55b5c65818e&scene=27#wechat_redirect)

  

        Cobalt Strike BOF 产生一个牺牲进程，用 shellcode 注入它，并执行有效载荷。旨在通过使用任意代码保护 (ACG)、BlockDll 和 PPID 欺骗生成牺牲进程来逃避 EDR/UserLand 钩子。

  

功能

 

*   使用任意代码保护 (ACG) 生成牺牲进程，以防止 EDR 解决方案挂接到牺牲进程 DLL 中。
    

*   注入并执行shellcode。
