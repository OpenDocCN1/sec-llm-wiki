**特征**  

*   漏洞利用漏洞在最流行的路由器，比如`D-Link`，`Zyxel`，`TP-Link`和`Huawei`。
    
*   优化为从启用线程的列表中一次利用多个路由器。
    
*   简单的 CLI 和 API 使用。
