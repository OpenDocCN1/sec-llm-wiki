        此脚本尝试通过查看 URL 中的 Google Analytics ID 来获取相关域/子域。首先在网页中搜索Google Analytics的ID，然后使用ID请求builtwith和hackertarget

  

*   
*   
*   

```
->  "www\.googletagmanager\.com/ns\.html\?id=[A-Z0-9\-]+"-> GTM-[A-Z0-9]+->  "UA-\d+-\d+"
```
