第一题：简单隐写的附件.png

题目名称：简单隐写

题目内容：超级简单的隐写术

分值100

下载附件打开就是一张纯白的图片

打开图片先看详细信息图片宽度高度差太多了

修改高度 FF 再打开图片

得到一半的flag：flag{8f177eac1dff4

提示tips you really know LSB?

Hint LSB隐写

没有任何数据，应该是个假的hint

Binwalk 检测到图片存在隐写有多个文件

导出隐写文件

Binwalk 简单隐写的附件.png-e

Flag在音频文件中，将flag.wav导入到SilentEye解密

SilentEye

是一个跨平台的应用程序设计，可以轻松地使用隐写术，在这种情况下，可以将消息隐藏到图片或声音中。它提供了一个很好的界面，并通过使用插件系统轻松集成了新的隐写算法和加密过程

得到一个python反编译文件flag.pyc

使用python在线反编译不太行

感谢群里表哥推荐的uncompyle6

uncompyle6是一个原生python的跨版本反编译器和fragment反编译器，是decompyle、uncompyle、uncompyle2等的接替者。
安装
pip install uncompyle6


uncompyle6 -o flag.py flag.pyc
