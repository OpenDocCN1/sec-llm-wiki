21  ftp  主要看是否支持匿名，也可以跑弱口令

22  ssh 弱口令爆破

23  telnet  弱口令爆破

80  常见web端端口  以及是否为一些管理后台

161  snmp public 弱口令

389   ldap  是否匿名访问  

443  openssl 心脏出血以及一些web漏洞测试

445  smb 跑弱口令，检测是否有ms\_08067等溢出

875  rsync 是否匿名访问  可以跑弱口令

1433 mssql 跑一下弱口令

1521 oracle 跑一下弱口令

2601、2604 zebra路由，默认密码zebra

3128  squid 代理默认端口，如果没设置口令很可能就直接漫游内网了

3306  mssql 跑一下弱口令

3389 windows远程桌面 跑一下弱口令

4440  rundeck web   

4848 GlassFish web中间件 弱口令 ： admin/adminadmin

5432 postgres 跑一下弱口令

5900/5901/5902、 vnc跑一下弱口令

6379 redics 一般无认证、可直接访问

7001/7002 weblogic ，可直接跑弱口令

8080 tomcat 可以直接跑弱口令，tomcat有许多漏洞

8000-9090 都是一些常见的web端口，有些运维喜欢把管理后台开在这些非80的端口上，可以跑弱口令。

9000 fcig ficj php执行

9200 elasticserch --代码执行

9043 websphere 【web中间价】弱口令

11211 memcache 内存泄露

27017 mongodb 未授权访问

28017 mongodb 统计页面

50060 hadoop web
