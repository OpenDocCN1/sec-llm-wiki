表空间相关命令  
Sql语句执行的时候要加上分号  
创建表空间：

```
SQL>
 create tablespace test\_work2 datafile'/u01/app/oracle/oradata/abc.dbf'
3 size 10M AUTOEXTEND ON;
```

```

```
SQL> select file\_name,tablespace\_name from dba\_data\_files;
