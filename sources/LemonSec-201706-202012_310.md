# CTF杂项题解题思路

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMTA0MjQ4NA==&mid=2247486374&idx=3&sn=9663487bb2ed88b55600a7dc952e0dc3&chksm=f9e064fdce97edeb2d8713439f892d456287ac087133f8875ca41d03233869a3813bed2fd28a&scene=126&sessionid=1681663442#rd](http://mp.weixin.qq.com/s?__biz=MzUyMTA0MjQ4NA==&mid=2247486374&idx=3&sn=9663487bb2ed88b55600a7dc952e0dc3&chksm=f9e064fdce97edeb2d8713439f892d456287ac087133f8875ca41d03233869a3813bed2fd28a&scene=126&sessionid=1681663442#rd)

1.  下载压缩包解压
    
2.  如果是图片就先查看图片信息
    
3.  没有有用信息查看图片看是否是一个图片
    
4.  如果不是图片就将文件进行还原
    
5.  从还原文件中查找有用信息
    

例：这是一张单纯的图片

http://123.206.87.240:8002/misc/1.jpg 

（1）查看图片属性后没有任何有效信息

![](../Images/82b70f9bb4d0eb5439ffa02d3359ec22.png)

（2）用图片查看器也能打开，证明确实是图片

![](../Images/db91e51624dcbe5b50e1ec22105269e5.png)

（3）我们用WinHex或者Notepad++打开可以看到最后有一串规律的Unicode码

![](../Images/854119091a87c5b1ea06a766eb8ea1b1.png)

```
&#
```

  

（4）把得到的码用CTFCrak进行转码为Ascii就可以得到了

![](../Images/33b2b0b13384deda5ce39a2cebe19fca.png)

注：与Unicode有关的字符转换模式

Ascii　　---->　　Unicode　　　　　中文　　---->　     　Unicode　　

flag　　&#102;&#108;&#97;&#103;　　　　　　旗帜　　　\\u65d7\\u5e1c

 

例2：最危险的地方就是安全的

15584352907afc4ab69ef3c7ca3e905903f171a46d  
（1）下载后我们解压得到一个jpg格式的图片，查看图片信息

![](../Images/e7a751ed3cf8c594382ba7b2411c28fb.png)

（2）用图片查看器打开，可以看到打不开，我们就猜测这不是一个jpg格式的图片

![](../Images/d04e2ef9ab8a82d1b109a4ad3f6ae943.png)

（3）用Winhex打开，证实了我们的猜想

![](../Images/3be1c37f7bc8931d8231e061cf7464ef.png)

（4）此时我们就需要用foremost对文件进行恢复，可以看到恢复后的文件全是二维码图片

![](../Images/ed0786a8b146f4cafe4858bdf0907a3e.png)

（5）将恢复后的文件的列表并显示详细信息，我们局可以发现这个文件格式大小都不一样

 ![](../Images/4bfd7609e6ddbf3f5f42daff1fd3c9a0.png)

（6）查看其详细信息，可以发现有个备注了一段Base64加密的密文

![](../Images/4b167f720c08908048c857007590b521.png)

 ZmxhZ3sxNWNDOTAxMn0= 

（6）通过解密就可以得到flag

![](../Images/c05eb41c4fcbb21162395e7c4cfed552.png)
