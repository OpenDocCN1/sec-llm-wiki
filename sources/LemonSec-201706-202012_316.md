## 一、fuzzing

访问目标网址，“there is nothing ”，小编心想，没东西是不是可以不做了？  
当然是不可能了，年轻人想想就好了，何必当真呢

![](../Images/529ee5087806616d27a941a7ef7702f5.png)  
burp抓包查看响应情况，初看好像没什么，这个时候拼什么呢，拼的是小编的这份细心了，看见小编圈起来的了嘛，很有用哦  
![](../Images/c0a3c62846dc2a75174f4738abd79c34.png)  
伪造一个IP，查看响应，出现了一个“m4nage.php”，进行访问，继续抓包  
![](../Images/bb89d4a7878787c04f6c7aeb3f619c88.png)  
继续伪造IP，可以看到回显内容“show me you key”  
![](../Images/4006028f07ef54c6d7b89a20fda06256.png)  
任意构造一个key值，继续伪造IP，发包访问，可以看到回显了找到正确的key的方法  
![](../Images/bdd24b50bdd272ab089e8df55384f73d.png)  
破解key值得python代码如下，破解出来的key值为“ichunqiu618ok”  
  
import hashlib  
def md5(data):  
    m = hashlib.md5()  
    m.update(data)  
    a = m.hexdigest()  
    return a  
  
a = 'ichunqiu'  
b = 'abcdefghijklmnopqrstuvwxyz1234567890'  
for i in b:  
    for j in b:  
        for k in b:  
            for l in b:  
                for m in b:  
                    if md5(a+i+j+k+l+m)=='5a2a7d385fdaad3fabbe7b11c28bd48e':  
                        print a+i+j+k+l+m

传入正确的key值后，回显了一个php文件  
![](../Images/2be6d7cbcc932177e7c3037c006740b8.png)  
继续burp抓包，伪造IP访问，得到一个“x0.txt”文件  
![](../Images/f732c04d3a2a7194cfd4df634c0dd710.png)  
访问是一段php的源码函数，复制到本地，对代码进行修改，在最后对函数进行echo输出。  
![](../Images/804b00e7378ad41acc62859465dd7726.png)  
本地网页访问代码，即可得到flag信息  
![](../Images/88fd2810dbd51c7620628206912c6a2e.png)
