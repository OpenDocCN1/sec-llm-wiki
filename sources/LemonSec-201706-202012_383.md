开启3389：

REG ADD HKLM\\SYSTEM\\CurrentControlSet\\Control\\Terminal” “Server /v fDenyTSConnections /t REG\_DWORD /d 00000000 /f

——————————————————  
reg add “HKEY\_LOCAL\_MACHINE\\SYSTEM\\CurrentControlSet\\Control\\Terminal Server” /v fDenyTSConnections /t REG\_DWORD /d 0 /f

  

这2 行都试试，都可以的

  

  

  

关闭3389：

reg add “HKEY\_LOCAL\_MACHINE\\SYSTEM\\CurrentControlSet\\Control\\Terminal Server” /v fDenyTSConnections /t REG\_DWORD /d 0 /f
