metasploit内网渗透方面好多方式，这只是科普下xss在内网中的利用。

系统:KALI  

用到的工具：beEF+msf

 利用的IE漏洞是：http://www.rapid7.com/db/modules/exploit/windows/browser/ie\_execcommand\_uaf  

# MS12-063 

```
Automatic
IE 7 on Windows XP SP3
IE 8 on Windows XP SP3
IE 7 on Windows Vista
IE 8 on Windows Vista
IE 8 on Windows 7
IE 9 on Windows 7
```

用到的beef+msf  
  
先配置下：  

```
root@kali:~# cd /usr/share/beef-xss/
root@kali:/usr/share/beef-xss# ls
beef           beef\_key.pem  config.yaml  db          Gemfile       modules
beef\_cert.pem  bundle        core         extensions  Gemfile.lock
```

编辑下config.yaml  
把metasploit ：false改成true

![](../Images/6335f02b411e4bfde6d34a0973f1aaf3.png "psb1.jpg")

再进入extensions/metasploit/  
同样修改下config.yaml  
把host跟callback\_host 改成自己的IP  这里是220.128

![](../Images/53912cc4dbf8511590d22a0386446734.png "psb2.jpg")

再改动下custom   path：

![](../Images/1e13cdabaf352c27e4a85906b8fc6532.png "psb3.jpg")

这样beef已经配置好了。那就运行下metasploit

![](../Images/2685368a28d61e60c1200b4593393582.png "psb4.jpg")

运行msf后 数据库连接下，不然上线也会没有提示的。这里的pass 就是extensions/metasploit/config.yaml里面的pass

![](../Images/630b26c8f5ea05bc9a7dd1be429329a0.png "psb5.jpg")

这样就没有什么问题。我们可以先看一下beef.数据库只要连上了就不会出现msf的api错误的。

![](../Images/b8a3521f1ba57f43ac9954eeba145ff1.png "psb6.jpg")

进入beef  

![](../Images/9d3d1280992c49dfb618d4c956f4c334.png "psb7.jpg")

账号密码beef 配置文件里面有。beef:beef

![](../Images/4d3ace667bce8274e77c56d02ee7b093.png "psb8.jpg")

那beef已经都OK了。  
现在来搞下选择下要显示的页面：

![](../Images/651e0ad5a511327d2a53f58adb4b0e05.png "psb9.jpg")

hook.js  运行beef 显示出来的。  
别忘记运行下apache。

![](../Images/3f99d12696e20294966eb83e8cff33d6.png "psb10.jpg")

我们再进入msf  

```
use exploit/windows/browser/ie\_execcommand\_uaf
```

可以自己根据自己的要求来选择。  

```
show options
```

port可以自已改。  

![](../Images/b6a74ebadf013a940ca5ddad557eca08.png "psb11.jpg")

我用xp+ie7

![](../Images/8ed566a721fdca113becc0406c7c461f.png "psb12.jpg")

直接访问下我们的页面192.168.220.128/xss/  
beef就会显示出来了。  

![](../Images/6ad52c099c21876f6bc241175eb90948.png "psb13.jpg")

点击 commands-hookeddomain-REDIRECT BROWSER 让他重新跳转到我们msf生成的地址上。beef很多功能。  
把地址改成192.168.220.128:8080(msf生成的地址)

![](../Images/e1528c9b0c372a418a79e0272a96d811.png "psb14.jpg")

我们就会看到msf上面已经显示出来了。 回显了sessions
