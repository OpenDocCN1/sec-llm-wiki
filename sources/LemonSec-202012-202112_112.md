# 远离垃圾人、忘记垃圾事

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMTA0MjQ4NA==&mid=2247516748&idx=3&sn=d0a60406eaf1b1f3fefeb7c178bea33b&chksm=f9e3ed17ce946401f68f756e6f06eba2dacfa85e98483e21a1606fec698db462a3360355d403&scene=126&sessionid=1681663239#rd](http://mp.weixin.qq.com/s?__biz=MzUyMTA0MjQ4NA==&mid=2247516748&idx=3&sn=d0a60406eaf1b1f3fefeb7c178bea33b&chksm=f9e3ed17ce946401f68f756e6f06eba2dacfa85e98483e21a1606fec698db462a3360355d403&scene=126&sessionid=1681663239#rd)

生活中垃圾人很多，他们到处跑来跑去，身上充满了负面垃圾：充满了沮丧、忌妒、算计、贪心与不满，充满了见不得人好、愚昧无知、烦恼和失望。

远离垃圾人，别被垃圾影响生活，生活是自己的，从来不是活给别人看。

忘记垃圾事，不开心的事就忘记，从不喜欢回忆过去，没有值得怀念的过去。

故人已成陌路，从来不认识。

往事也不会被历史记载，我们都太渺小。

如果没能力把眼前的苟且过好，就暂时不要去想诗和远方。

其实生活从未变得轻松，是你在一点一点变得坚强。

要努力，但不要着急，凡事总有个过程。
