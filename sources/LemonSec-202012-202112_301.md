# 语言的意义取决于它本身的质量，越低劣的语句越没有意义

其实，除了我们的父母，兄弟姐妹，爱人，没有人有义务对你好。  
所以当你有一天，遇到你的同事朋友，他们说让你很难堪的话，让你不高兴的话，一定不要放在心上。你要相信，你自己在这个世界上是最独一无二的，别人给你言语上的伤害，那是最微不足道的。  
语言的意义取决于它本身的质量，越低劣的语句越没有意义。 所以，不要因为一些讨厌的话而感到不开心，要为有意义的生活庆祝。
