# 人生没有那么平坦，不过你也比你想象中的自己要厉害的多

在没经历过很多事情之前我一直觉得自己接受不了承受不住，但真正困境降临之后我又发现自己竟然次次都能顽强的挺过来，于是我开始清醒的认识到，幸福感是会被打破的，人生不会总一如既往的按照我们心中所想而发展，大多数的普通人都很难维持永恒的幸福感。  
但值得庆幸的是，人类也似乎拥有着超乎我们认知的承受能力，被风浪卷起之后仍旧可以平稳的软着陆，一切都会过去，人生没有那么平坦，不过你也比你想象中的自己要厉害的多。
