# 备忘录里的碎碎念

我发现随着年纪慢慢的增长，人真的会变。

  

长大了，不再会因为认识谁而感到荣幸或高兴，也不会因为想显摆什么而做出太刻意的行为。

  

更多的是想在家待着，听真正喜欢的歌，做真正感到舒服的事。不用绷着，也不用照顾别人的审美和情绪。

  

社交让人疲惫，我，逐渐peace，朴素享受生活。
