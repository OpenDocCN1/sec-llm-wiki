**3、sed常用命令收集：test.txt做测试**

如何去掉行首的.字符: 

```
sed-i ‘s/^.
```

  

在行首添加一个a字符: 

```

sed’s/^/a/g’    test.txt
```

  

在行尾添加一个a字符: 

```

sed’s/$/a/‘     tets.txt
```

  

在特定行后添加一个c字符:

```

sed ‘/wuguangke/ac’ test.txt
```

  

在行前加入一个c字符: 

```

sed’/wuguangke/ic’ test.txt
```

更多sed命令请查阅相关文档。
