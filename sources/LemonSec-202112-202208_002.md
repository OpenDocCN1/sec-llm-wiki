# Windows 10 远程桌面连接 CentOS 8

![](../Images/3b1e5596c54924b086d099e421b66217.png)本文介绍了如何使用 windows10 远程连接虚拟机桌面（已使用远程连接工具连接了虚拟机，如 xshell），亲测可用，不懂的地方欢迎交流！

## 1 安装 epel 库

先查看下虚拟机上是否安装 epel 库

```

rpm -qa|grep epel
```

![](../Images/d8510e6827e72cade254832e81c29f66.png)我已经安装了，如果没有安装，使用下面的命令进行安装

```

yum install epel-release
```

## 2 安装 xrdp

执行下面的命令，安装 xrdp

```

yum install xrdp
```

会出现一些提示，不需要管是什么，全部输入 y 就行了。安装好的结果如下：![](../Images/faf810b4bbacca91c14215a145fd4ff0.png)

## 3 安装 tigervnc-server

执行下面的命令，安装 tigervnc-server

```

yum install tigervnc-server
```

安装成功的结果如下：![](../Images/873aa47c89f77d3757d3d867db039705.png)

## 4 配置或关闭 SELinux

执行下面的命令查看 SELinux 状态

```

/usr/sbin/sestatus -v
```

![](../Images/37fdc5f31d8580f042f7fa42de0ec1ae.png)执行下面的命令，设置 SELinux 成为 permissive 模式

```

setenforce 0
```

然后再查看下 SELinux 状态![](../Images/8a6d6bcdb2e8bcccdd29cb90090d0da5.png)

## 5 关闭防火墙

执行下面的命令关闭 centos8 的防火墙（其他版本的可能不一样）

```

systemctl stop firewalld.service
```

然后执行下面的命令，查看下防火窗的状态是否关闭

```

systemctl status firewalld.service
```

![](../Images/7d3fdf7948548aac071417642d81c32d.png)

## 6 启动 xrdp 服务，并且设置为开机启动

执行下面的命令，启动 xrdp 服务

```

systemctl start xrdp
```

可以执行下面的命令，查看 xrdp 是否启动

```

systemctl status xrdp
```

![](../Images/8ecc39627950400ee4123f629e360269.png)执行下面的命令，设置 xrdp 开机自启动

```
systemctl enable
 xrdp
```

![](../Images/75f26d2e508c4ca60661ca00c0f34fda.png)

## 7 使用 windows10 连接

左下角搜索远程连接![](../Images/3597d87e4cc5225a11c179e9ce85c487.png)打开 Windows 远程连接，输入虚拟机的 ip![](../Images/fbd35f3b7fe61e079bed9a993f940d40.png)在弹出的 xrdp 用户验证界面，输入连接的用户名和密码就可以了~

![](../Images/e9db83582efa3a6cc25a90ecf8fb7e13.png)
