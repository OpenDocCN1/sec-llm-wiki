工欲善其事，必先利其器，方便好使的浏览器插件可以大大提高我们渗透测试的效率。以下是笔者比较常用的一些插件推荐，其中包含渗透测试、信息收集、代理、加密解密等功能。

  
![](../Images/39d11315f2a87d4e8c52ea9665ff3591.png)

## 1、Proxy SwitchyOmega  

轻松快捷地管理和切换多个代理设置，常用于Google Chrome。

  

![](../Images/340d9a0c075a90654451b465700d8ac7.png)

## 2、User-Agent Switcher  

该插件用于改变浏览器User-Agent 。

  

![](../Images/3c66db58d98294661c4425fac501e509.png)

  

## 3、FOFA Pro View

```
Fofa Pro View 插件会告诉您网站的托管位置（国家、城市）、IP 的所有者
```

```

以及开放的其他服务/端口。
```

![](../Images/c664063bcd2dad88ebf9df909d01f98a.png)

## 4、Shodan

Shodan 插件告诉您网站托管在哪里（国家、城市）、谁拥有 IP 以及哪些其他服务/端口是开放的。  

![](../Images/2f10c42002d58d93650fb7ddf8593d97.png)

## 5、Wappalyzer

查看网站使用的应用程序  

  

![](../Images/4bd3c2b765a750c1d37b99a172becfc3.png)

## 6、HackBar

攻城师必备工具，提供了SQL注入和XSS攻击，能够快速对字符串进行各种编码。  

  

![](../Images/b281505a2a299763f11458f5c0b48533.png)

## 7、IP Address Tool

实时查看自己的IP地址  

  

![](../Images/b3a7a651b3a3484fc7be66869be6a76d.png)

## 8、Cookie Hacker

快速cookie注入小插件  

  

![](../Images/a8cc800196cf7df4e84a978add810195.png)

## 9、Hack Tools

Hack-Tools是一款针对Web应用程序渗透测试的Web扩展，其中包含了大量测试工具，比如说XSS Payload和反向Shell等等。

![](../Images/d4f562ccf96d2501920d72a73c108baf.png)

## 10、IP Address Tool

此扩展允许您快速设置X-Forwarded-For HTTP头

  

![](../Images/c67c5acd3db10fb2f981c1a316b7b50a.png)

## 11、Chrome同步助手

不用挂vpn直接访问google搜索和商店等，实现Chrome账号同步和扩展自动更新。  

![](../Images/1e257280c8ae94f85cbe37ec1cf60c71.png)

## 12、FindSomething

在网页的源代码或js中找到一些有趣的东西

![](../Images/e7aff8460762fdc329e97656cd7d33bf.png)

## 13、ModHeader

修改http的请求头和响应头  

![](../Images/67ca7cfbb9450f83a01823288f657292.png)

## 14、FoxyProxy

轻松快捷地管理和切换多个代理设置。常用于Firefox。  

![](../Images/efcd81c6ecec27c5ce19fe75c58f3d86.png)

## 15、Penetration Testing Kit  

PTK仪表盘允许您分析客户端/服务器端技术并检查任何第三方库以获取现有的CVE，例如已知的漏洞。同时，它使您可以在浏览应用程序时快速访问有关所有框架和请求的信息。  

  

![](../Images/e3c1b17524201cd8febab38badfd4d1c.png)

## 16、Tampermonkey

Tampermonkey 是一款免费的浏览器扩展和最为流行的用户脚本管理器，它适用于 Chrome, Microsoft Edge, Safari, Opera Next, 和 Firefox。

![](../Images/fe1062995065f57e82e1514281024314.png)

  

## 17、Quick Javascript Switcher

一键开启/关闭js
