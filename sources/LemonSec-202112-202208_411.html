s等命令用于socket状态。他可以显示PACKET sockets，TCP sockets，UDP sockets，DCCP sockets，RAW sockets，Unix domain sockets。它比其他工具展示等多tcp和状态信息。

它是一个非常实用、快速、有效的跟踪 IP 连接和套接字的新工具。SS 命令可以提供如下信息：

  • 所有的 TCP 套接字

  • 所有的UDP套接字

  • 全部ssh/ftp/ttp/https连接

  • 所有连接到Xserver的本地进程

  • 使用状态（例如：connected，synchronized，SYN-RECV，SYN-SENT，TIME-WAIT）、地址、端口过滤

  • 所有的状态 FIN-WAIT-1 tcpsocket 连接以及更多

流行很多 Linux 发行版都支持 ss 以及许多监控工具使用的命令lnt等。

ss常用的状态状态：

establishedsyn-sentsyn-recvfin-wait-1fin-wait-2time-waitclosedclose-waitlast-acklistenclosingall : All of the above statesconnected : All the states except for listen and closedsynchronized : All the connected states except for syn-sentbucket : Show states, which are maintained as minisockets, i.e. time-wait and syn-recv.big : Opposite to bucket state.

ss dport OP PORTOP:是运算符PORT：表示端口dport：表示过滤目标端口、相反的有sport

有网友总结道：
测试ss比netstat慢好多，且netstat是遍历/proc下面每个PID目录，ss直接读/proc/net下面的统计信息。所以ss执行的时候消耗资源以及消耗的时间都比netstat少很多。还有就是ss会影响CPU，这个需要评估对业务的耗时影响，没有免费的午餐，大家选择自己觉得好用的就好~
