### 结果分析

我尝试使用高级会员账号进行查询

*   

```
`./goon_amd64_mac -mode fofascan -key port="7001" -num=-1`
```

得到了123W条数据![](../Images/328d0d6b061e0b140f7d4872020843de.png)在sublime中，使用正则截取每行出现的第一个ip

*   

```
`\d*\.\d*\.\d*\d\.\d*\:\d*`
```

符合 ip:port格式的是 122W条数据![](../Images/963321d2dd00f1fd16433c8c7d377acb.png)再通过去重得到result在sublime中排序edit - sort lines![](../Images/9c4a4d7cfc8a4318748b8b7bf84753cd.png)查找目标为

*   

```
`^(.+)$[\r\n](^\1$[\r\n]{0, 1})+`
```

替换为

*   

```
`\1\n`
```

![](../Images/7058c53a27f9d35a203ca9bd916fe8aa.png)  
最后得到了70W个结果![](../Images/d816e4e0295eb5117cdebdfd846f6d48.png)由于没有对结果进行处理，所以结果中存在大量重复ip，不过通过时间条件来扩大查询结果，这操作还是骚的。![](../Images/3dcfa5a31dd24eb9d4db16afe1b27346.png)

修复方式：

![](../Images/aafe671393f623958d13daf797ab86b4.png)  

1.  限制每个账号每小时对fofa服务器请求次数。（多个账号进行绕过）
2.  限制同一个IP对fofa服务器请求次数。（代理池绕过）
3.  取消普通会员及高级会员账号的before、after的条件查询。
