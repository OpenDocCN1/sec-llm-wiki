**网站历史URL获取****gau**   https://github.com/lc/gau**hakrawler** https://github.com/hakluke/hakrawler**waybackurls** https://github.com/tomnomnom/waybackurls**gospider** https://github.com/jaeles-project/gospider

```
`爬虫获取链接，运行20个站点每个站点10个爬虫``gospider -S domain.txt -o output.txt -c 10 -d 1 -t 20`` ``通过爬虫获取链接包含子域名``gospider -s "https://google.com/" -o output -c 10 -d 1 --other-source --include-subs`` ``对文件进行处理过滤出js文件``gospider -S urls.txt | grep js | tee -a js-urls.txt`
```

**XRAY 命令行批量扫描**针对单个域名进行子域名爆破，使用GAU提取链接，httpx验证存活，推送到XRAY进行爬虫扫描。

*   
*   
*   

```
`subfinder -d domain.com -silent | gau  --blacklist  png,jpg,gif,html,eot,svg,woff,woff2  | httpx -o 200.txt`` ``for i in $(cat 200.txt);do echo "xray scanning $i" ; ./xray webscan --browser-crawler  $i --html-output vuln.html; done`
```
