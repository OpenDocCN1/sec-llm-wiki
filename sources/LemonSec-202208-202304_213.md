# 记录一次wordpress渗透测试实战

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMTA0MjQ4NA==&mid=2247540121&idx=1&sn=7610d3106165d6ab617b78dc507e167e&chksm=f9e332c2ce94bbd4b40fb445ef3c8b43390bce84053b498f75845304f91b3ecc6afa0a63f159&scene=126&sessionid=1681663022#rd](http://mp.weixin.qq.com/s?__biz=MzUyMTA0MjQ4NA==&mid=2247540121&idx=1&sn=7610d3106165d6ab617b78dc507e167e&chksm=f9e332c2ce94bbd4b40fb445ef3c8b43390bce84053b498f75845304f91b3ecc6afa0a63f159&scene=126&sessionid=1681663022#rd)

0x00 前言  
昨天晚上，下班回到家正闲得没事做的时候，突然想起来之前和扣扣群里的群友玩游戏的时候群友搭了一个语音服务器，于是好奇心和职业病指引我去那个域名看看是啥网站，于是有了这一次的渗透之旅  
  
0x01 信息收集

群友的域名是这个: Xxxxxxx.top，是一个个人博客，群友也是一个代码人。看来这是他的个人博客，检测到浓度  

![](../Images/d6b46868419456529d4d22eff77407a5.png)

  

看了看用的是世界上最安全的wordpress，看来这站不好拿啊，一般wordpress的前台没啥问题，但是如果登陆到管理员后台基本上就寄了。

![](../Images/fbc5ee3331b558abd0191fb7e2efa1d7.png)

  

点击登陆

![](../Images/437796d072d83d9e0368b6ff0d0d0f2f.png)

  

冲田总司登录框，发现有注册

![](../Images/066cd948b543b34d9a42e290bc2ee554.png)

  

那就注册一个

![](../Images/8e4b49c976c64cf8d7c322c995ff1ddc.png)

  

登陆一下没什么功能，寄! 暂时没用了

![](../Images/7d2902d1185ddfbc27de1f701c255854.png)

  

那就扫一下端口，发现mysql部署在公网，好家伙，这不给你炸了

![](../Images/fa5cc6f6298142daf33b1eb12d6859cf.png)

  

我直接无语子，果然一般的代码人安全意识都没有那么好，毕竟不是安全人

![](../Images/d4046838c7091ab1303757ce3e4f5b5e.png)

  

  

0x02 开始渗透

  

随便整个mysql远程连接工具，找找管理员密码, WPS的账号信息存在wp\_users里面  

![](../Images/754e3dab32166b6992ab5c4cdb480679.png)

  

密码经过常人看不懂的加密了，我尝试修改了密码，发现其他账号是能成功修改的，但是唯独管理员修改了密码也提示错误，密码又解密不了，真是绝绝子.

  

好家伙，一时间竟没有了头绪，但是来都来了，又怎么能放弃呢。

![](../Images/85e333293d637895ade69ce6624215de.png)

  

接着翻了一下数据库，发现有一个wp\_usermeta的表很特殊，我怀疑这是不是分配用户权限的地方

![](../Images/58cb0363e509ad884667d29c6aaa12b9.png)

  

很快一个地方就引起了我的注意

![](../Images/8f65081d2af75685a02d2bb42ade1913.png)

  

本文盲去查了一下，发现是 帕瓦  的意思 !!!

![](../Images/f6ddf337752679b6981b86bc1e369473.png)

  

找到描述自己的那一部分，发现我的 帕瓦是普通用户，替换之

![](../Images/66515c1cbf1164bea6c09f1e3fde65cf.png)

  

再次登陆，权限拉满，这波芜湖起飞

![](../Images/740fd19853adcd1de7fbacd4ac1be9a8.png)

  

接下来就简单了，我已经看到shell在招手了，在后台修改主题文件的配置，加入一句话木马

![](../Images/a82cfbc87b567bd178cb484f48b7dc87.png)

  

访问一下，发现可以访问，路径为

*   

```
`url+/wp-content/themes/+主题名/+修改文件的文件名`
```

![](../Images/d1ead0c4d5ffde039586ec3b3b917cd6.png)

  

蚁剑一波带走 寄! 告知小伙伴，继续上班，话说我上午上班都在写博客，该吃午饭了O(∩\_∩)O

![](../Images/2c66ccb960445626a2008582dee8e35e.png)

  

  

0x03 总结

  

本次渗透过程比较简单，主要还是通过公网的3306成功爆破得到数据库数据，再通过对比数据库内容提升权限，然后使用wordpress后台通杀拿shell，完成渗透。

  

但是处处需要细心和耐心，否则有些东西就会错过导致渗透的失败。一开始我在访问主题文件的时候是403的，那个404.php一开始我也是被拒绝访问的，不知道是什么原因，直到最后才找到了一个能成功访问的php页面。

  

昨晚搞完都两点半了，渗透狗就是肝出来的。。。
