Cobalt Strike 是一款GUI的框架式渗透工具，集成了端口转发、服务扫描，自动化溢出，多模式端口监听，win exe木马生成，win dll木马生成，java木马生成，office宏病毒生成，木马捆绑；钓鱼攻击包括：站点克隆，目标信息获取，java执行，浏览器自动攻击等等。Cobalt Strike: C/S架构的商业渗透软件，适合多人进行团队协作，可模拟APT做模拟对抗，进行内网渗透。

**4.1启动cobaltstrike.jar**在Linux下，可以直接通过./cobaltstrike启动客户端，如下图。![](../Images/adafd9cbf89e07e816e88fdf24f6628f.png)填写团队服务器的IP地址、端口号、用户名、密码。在这里，登录的用户名可以任意输人，但要保证当前该用户名没有被用来登录Cobalt Strike服务器。在确认信息填写无误后，点击Connect连接服务端，这时候会出现指纹校验对话框，如下图。指纹校验的主要作用是防篡改，且每次创建Cobalt Strike团队服务器时生成的指纹都不一样。![](../Images/bf37ba2b548dba4837bca67b44d8e5f0.png)在客户端向服务器成功获取相关信息后，即可打开Cobalt Strike 主页面，Cobalt Strike 主页面主要分为菜单栏、快捷功能区、目标列表区、控制台命令输出区、控制台命令输入区。菜单栏：集成了Cobalt Strike的所有功能。快捷功能区：列出常用的功能。目标列表：根据不同的显示模式，显示已获取权限的主机及目标主机。控制台命令输出区：输出命令的执行结果。控制台命令输人区：输入命令。![](../Images/8c748f94183e7fb48a06d9796146b430.png)在Windows中，可以直接打开对应的客户端程序。![](../Images/b4e4c9e11126acb6f7cf3b411e092104.png)然后输入teamserver服务器的IP地址和密码进行连接即可。![](../Images/55d84b076d2a59cb664e2eadda10b22c.png)  
**4.2利用Cobalt Strike 获取第一个Beacon**1、建立Listener可以通过菜单栏的第一个选项”Cobalt Strike”进人”Listeners” 面板，如下图。![](../Images/3bb9b9d56e281a03078809d91e8fc8d3.png)也可以通过快捷功能区进入”Listeners” 面板，如下图。![](../Images/588dba9baba863e27b2b4e0b86687b58.png)单击“Add” 按钮，新建一个监听器，输人名称、监听器类型、团队服务器IP地址、监听的端口，然后单击“Save”按钮保存设置，如下图。![](../Images/573d3c747b0d53785d1cf71277c1fdaf.png)2、使用 Web Delivery 执行Payload单击 “Attacks” 菜单，选择”Web Drive-by”→”Scripted Web Delivery”选项，如下图。![](../Images/7403c091bcf79577d851d35f27d25aab.png)或者通过快捷功能区，打开“Scripted Web Delivery”窗口，如下图。![](../Images/a76266e3cf2620ccfb4b2204a5520dd8.png)保持默认配置,选择已经创建的监听器，设置类型为PowerShell,然后单击“Launch”按钮，如下图。![](../Images/7504bf77a944a30cc2f67b75e57adf56.png)最后，将Cobalt Strike生成的Payload完整地复制下来，如下图。![](../Images/a12467e847313113c09e542ffbe74e8c.png)
