# 分析

SSSvc.exe运行在50003端口上，默认监听0.0.0.0

![](../Images/b26eca6bcb38f4eab0cba2d449aefd58.png)

拉到dnspy中看一下

![](../Images/9e7c6d46eeb9e5d496202bcc4f9261a5.png)

main函数启动了一个SSCollect服务类。

![](../Images/699fdf689e275eea8b8d19cff09ed90c.png)

服务类调用了`ServiceWorker.StartService()`

![](../Images/e5988c25e43af766d0e5fd7743b14390.png)

新一个处理函数ServiceLifetimeFunction

![](../Images/58c0abd2229bf5133e97075a9df8152f.png)

这里调了`ServiceWorker.Start()`

![](../Images/2256b0e596b211e97ccc18898dbf02d0.png)

启动中调用`GrpcManager.StartGrpc()`开启监听gRPC。

继续看gRPC，在StartGrpc中，定义了四个服务

![](../Images/9a17e23f1d4ea658faa5ec0b61a2bcd7.png)

  

分别对应

1.  查询 -> QueryServiceImplementation
    
2.  站点列表 -> 站点列表服务实现
    
3.  ServiceOperations -> ServiceOperationsServiceImplementation
    
4.  站点控制 -> 站点控制服务实现
    

并且端口绑定在0.0.0.0:50003上

顺便点开一个服务来看看 QueryServiceImplementation

  

![](../Images/7ba7fbd006f0228debb80b7b28b73995.png)

服务运营服务实施

![](../Images/50f6592b5cde846d4131fcc75df7c5d6.png)

  

能看到grpc的远程调用函数实现。

先来试一下调用。创建一个csharp的grpc项目，可以直接用gRPC的example项目
