# 一、scp 命令详解

> \[Ubuntu\]系统中，`scp`是 secure copy 的简写，使用 `ssh`登陆服务器，可进行远程拷贝文件操作。与之相类似的命令有`cp`，`cp`可以在本机进行拷贝，却不能跨服务器进行拷贝，而`scp`传输是[加密]的，这可能会使拷贝速度减慢；`rcp` 是不加密的，`scp`是 `rcp` 的加强版。当你服务器端硬盘设定为只读时，用`scp`可以帮你把文件拷贝出来。再者，`scp`还非常不占资源，不会提高多少系统负荷，在这一点上，`rsync`就远远不及它了。虽然 `rsync`比`scp`会快一点，但当小文件众多的情况下，`rsync`会导致硬盘 I/O 非常高，而`scp`基本不影响系统正常使用。

```


scp【本地或远程文件的路径】【服务器用户名】@【服务器地址】：【远程或本地文件的路径】limit

： 限定用户所能使用的带宽，以Kbit/s为单位。
```

# 二、scp 命令使用

1.  从本地将文件传输到服务器
    

* * *

> scp【本地文件的路径】【服务器用户名】@【服务器地址】：【服务器上存放文件的路径】

```

scp -r /home/ds/Desktop/example0.txt eaibot@192.168.31.200:/home/eaibot/
```

2.  从本地将文件夹传输到服务器
    

* * *

> scp【本地文件夹的路径】【服务器用户名】@【服务器地址】：【服务器上存放文件的路径】

```

scp -r /home/ds/Desktop/example1 eaibot@192.168.31.200:/home/eaibot/
```

3.  将服务器上的文件传输到本地
    

* * *

> 这里，需使用`ssh`登陆服务器，方可进行远程拷贝文件操作。

> \[ssh\]【服务器用户名】@【服务器地址】  
> scp 【服务器用户名】@【服务器地址】：【服务器上存放文件的路径】【本地文件的路径】

```


ssh eaibot@192.168.31.200
```

4.  将服务器上的文件夹传输到本地
    

* * *

> scp -r 【服务器用户名】@【服务器地址】:【服务器上存放文件夹的路径】【本地文件的路径】

```
scp -r eaibot@192.168.31.200:/home/eaibot/example1 /home/ds/Desktop/
```
