0x02 背景

  

在公司打下来域控，用了一种好玩的方法做了权限维持（只要我进程不存在，你就永远也不知道我在哪）。  

  

特征极少，绕过了杀软，hids，nids，后门存活了两个多月。最终在威胁情报上遭遇了滑铁卢。

  

控制端C2是有几条威胁情报的，结合NIDS的流量，情报介入以后，异常外连直接被发现。于是诞生了这个工具（只要我不连接C2，威胁情报就永远发现不了我）

  

此处仅提供思路，可和DLL劫持、其他维权手段结合。在红蓝对抗的时候，能多一个选择~

0x04 功能

  

远端配置文件：

*   
*   
*   

```
`sleep:10``type:cmd``value:calc`
```

  
sleep：

*   

```
`休眠时间，下次获取服务端配置间隔（单位：秒）`
```

type：

*   

```
`sleep、cmd、up、exit四种`
```

  
**注：**value必填项，还没处理到这块，不需要value的随便填啥都可以  
  
sleep 不执行任何操作。![](../Images/c3488e8583de8157b053a19c2915a622.png)  
cmd 执行命令 value 为要执行的命令。![](../Images/616088778ecedd78c2ead9014e9bea23.png)  
up 执行shellcode上线 value为shellcode bin的16进制![](../Images/36ebfc0151a2d07e57b9199e190ebb4f.png)  
exit 退出进程。![](../Images/c1f2cb586cddbc53f5b3ed7dbc27d2c3.png)
