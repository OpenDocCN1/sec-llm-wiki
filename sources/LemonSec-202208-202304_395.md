# 多款 Linux 常用远程连接工具介绍

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMTA0MjQ4NA==&mid=2247536073&idx=2&sn=8a2770e18e7ab5c2a0471b975073d004&chksm=f9e32292ce94ab84672e6beab0687978f3d6c0a9ba5799a2050fa6f8e58a3c872b3082b66cea&scene=126&sessionid=1681663063#rd](http://mp.weixin.qq.com/s?__biz=MzUyMTA0MjQ4NA==&mid=2247536073&idx=2&sn=8a2770e18e7ab5c2a0471b975073d004&chksm=f9e32292ce94ab84672e6beab0687978f3d6c0a9ba5799a2050fa6f8e58a3c872b3082b66cea&scene=126&sessionid=1681663063#rd)

1、Xshell：xshell 是一个非常强大的安全终端模拟软件，它支持 SSH1, SSH2, 以及 Windows 平台的 TELNET 协议。Xshell 可以在 Windows 界面下用来访问远端不同系统下的服务器，从而比较好的达到远程控制终端的目的。![](../Images/3648b5201f74269f3fa6f9654ad098dd.png)  
官网：

```
https://www.netsarang.com/zh/xshell
```

2、MobaXterm：mobaxterm 的功能非常全面，几乎提供了所有重要的远程网络工具（比如 SSH、X11、RDP、VNC、FTP、MOSH 等），以及 Windows 桌面上的 Unix 命令（bash、ls、cat、sed、grep、awk、rsync 等），登录之后默认开启 sftp 模式。![](../Images/185de8463910406fee5a3409d9bbbe52.png)官网：❝大多企业运维都喜欢用它❞

```
mobaxterm.mobatek.ne
```

3、secureCRT：SecureCRT 支持 SSH，同时支持 Telnet 和 rlogin 协议。SecureCRT 是一款用于连接运行包括 Windows、UNIX 和 VMS 的理想工具。通过使用内含的 VCP 命令行程序可以进行加密文件的传输，网工应该很熟这个软件，经常使用它连接设备。

![](../Images/e913d44886826eb8fc382fbb84ccc22d.png)

  
官网：

```
https://www.vandyke.co
```

4、PuTTY：PuTTY 是 SSH 和 telnet 客户端，最初由 Simon Tatham 为 Windows 平台开发。用 MIT 许可证授权。包含的组件有：PuTTY, PuTTYgen,PSFTP, PuTTYtel, Plink, PSCP, Pageant, 默认登录协议是 SSH，默认的端口为 22。![](../Images/fd5be2264aff7dc00f06c68380442c93.png)官网：

```
putty.org
```

5、FinalShell：FinalShell 是一体化的服务器网络管理软件 (java 语言编写)，不仅是 ssh 客户端，FinalShell 还是功能强大的开发、运维工具，充分满足用户的开发运维需求。![](../Images/221ac23f6a649eff99dc8f8ca14695de.png)官网：❝可以直观的看出远程服务器的硬件运行情况❞

```
http://www.hostbuf.com
```

6、winSCP：WinSCP 是一个 Windows 环境下使用 SSH 的开源图形化 SFTP 工具客户端。同时支持 SCP 协议。它的主要功能就是在本地与远程计算机间安全的复制传输文件。

![](../Images/6dec639ce3d383687b2ed9db173bffa5.png)

  
官网：  

```
https://winscp.net
```

7、Termius：Termius是一款支持WINDOWS,MAC,和IOS平台的远程SSH工具，功能强大，且和teamviewer一样注册一个账号就可以在多个平台共享主机列表，一次配置后就可以跨平台使用，非常适合我们经常和云主机服务器打交道的朋友.![](../Images/38f135d5f264ddc8fc4480ee2108d5ff.png)  
官网：

```
https://www.termius.com
```

8、JuiceSSH：上面推荐的都是电脑上的SSH客户端，那么如果在外边，不方便用电脑，如何登陆服务器呢，在给大家推荐一个安卓手机的SSH客户端应用——JuiceSSH![](../Images/aa57a0850120d9313a8ce0cc3dc82743.png)  
官网：

```
https://juicessh.com
```
