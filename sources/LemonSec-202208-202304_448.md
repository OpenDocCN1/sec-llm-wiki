### 利用LogParser查看日志

https://www.microsoft.com/en-us/download/confirmation.aspx?id=24659![](../Images/02eff9ccfed7e1cd12cb6d540ade3a07.png)查询用户登录情况  

```
LogParser.exe -i:EVT "SELECT TimeGenerated,EXTRACT\_TOKEN(Strings,5,'|') AS USERNAME,EXTRACT\_TOKEN(Strings,5,'|') AS SERVICE\_NAME,EXTRACT\_TOKEN(Strings,5,'|') AS Client\_IP FROM 'C:\\Users\\wp\_bj\_windows\\Desktop\\安全.evtx' WHERE EventID=4624"
```

![](../Images/a77b89cd73f352a99836807ec1218ea8.png)查询登录成功的事件  

```
LogParser.exe -i:EVT –o:DATAGRID  "SELECT \* FROM 'C:\\Users\\wp\_bj\_windows\\Desktop\\安全.evtx' where EventID=4624"   
```

## 二. 检查异常端口进程  

目前连接

```

netstat  -ano| findstr "ESTABLISHED"    #已经成功建立的连接
```

![](../Images/91d96c00b7cf08bd26df244309fd32c5.png)msfinfo32  
![](../Images/c2fea2cb07820ec94785f18eb7eeefc3.png)利用wmic查看进程执行时的命令 约束条件 name  

```
Wmic process where name='sqlceip.exe' getname,Caption,executablepath,CommandLine ,processid,ParentProcessId  /value
```

或者pid

```
Wmic process where processid='2352' get name,Caption,executablepath,CommandLine ,processid,ParentProcessId  /value
```
