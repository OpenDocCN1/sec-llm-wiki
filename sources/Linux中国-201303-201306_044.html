Ubuntu 曾经的理想已不再？

原文：http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000587&itemidx=1&sign=0f93f662f83c38dd12ed8a179110b5d6&scene=27#wechat_redirect

　　九年前，Ubuntu 还不是全世界最流行的 Linux 操作系统，创始人 Mark Shuttleworth 在 Bug 收集列表里写下第一条记录：

Bug#1 微软拥有主流市场。

在新的桌面 PC 市场，微软拥有着主要的地位。这是 Ubuntu 以及其它操作系统都要去修正的 Bug。因为 Ubuntu 的哲学是，“我们的工作由一种信任所驱动：软件必须自由，而且能接受所有人的联结。

　　他当时还说，不自由的软件会让用户的地位下降，让能够影响社会的技术把持在软件所有者以及合同持有者的手中。

　　即便是现在，回顾当年 Shuttleworth 的誓言，都觉得十分理想——理想，要么让别人热血沸腾，要么让别人用更加现实的眼光来评判。许多理想主义以悲剧收场，也因此沾染上了美学的意义。但还有更多数量的理想，在坚持了一段时间后，默默地消失了。

　　九年后，Ubuntu 第一条 Bug 已经宣布“Closed”，换言之，这个 Bug 不再是修正的目标。为什么？是 Shuttleworth 改变了初衷吗？不一定，让我们看看他是怎么解释的：

如今个人计算的定义比 2004 年更加广泛：智能手机、平板电脑、可穿戴式设备以及其它的，还有许多设备混在一起，成为数字生活的一部分。从竞争的角度来透视，由于 iOS 以及 Android 在市场中取得份额，更广阔的市场带来了更加健康的竞争。

Android 也许我和你都当做第一选择的 Linux 系统，不过毫无疑问，一个开放的平台，能够为用户和行业提供实际上、经济上的影响。因此在个人计算领域，开源有着竞争以及好的表现。

即便我们仅仅在这样的转变中扮演了小小的角色，我仍认为，看到这种转变的发声，对于我们十分重要。因此，从 Ubuntu 的角度来看，这个 Bug 已经关闭。

　　Shuttleworth 的意思是，因为已经有别人成功挑战微软的地位，所以，现在 Ubuntu 的第一个 Bug，就无所谓要自己来修正。但不管怎么说，他仍旧是改变了初衷——iOS 是封闭的系统，Ubuntu 的哲学是让自由软件得以传播。

　　共同奔跑在同一理想的旅途中的人们，要树立一个超越的对象，这样跑起来才更加有动力，也更加有凝聚力。但现在，Shuttleworth 还能找到谁作为靶子呢？

　　或者说，走向商业化的 Ubuntu，需要证明自己的已经不是靶子，而是财务报表？
