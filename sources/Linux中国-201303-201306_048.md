# 谷歌Android正成为物联网标准操作系统

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000581&itemidx=4&sign=acd873f77800785384ef87711aade4a0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000581&itemidx=4&sign=acd873f77800785384ef87711aade4a0&scene=27#wechat_redirect)

**国外媒体日前发表分析文章称，在统治了移动操作系统市场之后，谷歌Android正在成为物联网的标准操作系统。以下为文章内容摘要：**肯· 奥亚德马利（Ken Oyadomari）是美国国家航空航天局（NASA）位于加利福尼亚州山景城艾莫斯研究中心的一名职员。他的办公室就像是智能手机的门诊部，工作台上到 处是从数十部智能手机上拆下的各种零件。

![](../Images/ed508ecd592a60521e144664247a47d0.png)

  
一个由年轻的工程师组成的小团队在这些电子配件中仔细挑选着，选择出那些跟纸牌大小相仿的主板--它们是多数电脑 产品的计算核心--但它们很快就将肩负其它的使命，在比垒球还小的航天器里扮演大脑的角色。通常制造和发射一颗人造卫星要花费数百万美元。但是奥亚德马利 的微型卫星之所以能够出名，是因为它们的造价在1.5万美元左右，而且价格还能够降低。奥亚德马利预计，高校理科学生、个人爱好者或是任何想要开展空间试 验的人都能负担得起这样的卫星。  
  
奥亚德马利的微型卫星又小又廉价的一个主要原因：是它们搭载着谷歌Android操作系统，类似于任何人购买的Android智能手机或平板电脑。按照使用量计算，Android已经是全球最流行的移动操作系统，Android手机与苹果iPhone 手机的销量比为4：1。数据事实上掩盖了Android的流行，因为在当今这个年代，但凡有电脑芯片的地方，背后都会寻觅到它的身影。已有三颗奥亚德马利 的微型卫星在近期进入了轨道。除此之外，咖啡机、游戏机、电冰箱、机器人收割机等各种各样的设备也都开始搭载Android操作系统。  
  
Android 正在成为“物联网”的标准操作系统。物联网已经成为硅谷的流行词汇，指用智能设备组建一个实体网络。只要植入芯片，无论是你脚上穿的鞋，还是喷气式飞机的 显示屏，都可以实现互联，从而组建一个庞大的网络。随着每一个这样的设备进入市场，谷歌在一个联网的世界进一步扩大了对苹果和微软在软件领域的领先优势。  
  
Android 的崛起，部分的源自于谷歌把这款软件免费提供给了设备制造者和开发者。谷歌指望着从Android手机和平板电脑的广告和其它服务中赚钱。Android 同时也是一款开源软件：任何人都可以摆弄代码，并把它应用于任何设备当中。美国国家航空航天局的工程师对Android进行调整使其耗电量更低，从而只用 很少的电量便可让卫星持续运转多天。奥亚德马利表示，“如果我们能够真正让卫星变得很小、确实廉价，就会有趣的发现许多人会在车库里能够摆弄这些玩意。”  
  
谷 歌在2005年收购了Android。Android是一款基于Linux开发的操作系统，在数据中心和极客群中广受欢迎。在收购Android之后，谷 歌对这款操作系统进行了简化，提升了能耗效率，使得它可以用更少的电量完成相同的任务。谷歌同时还为Android提供了更易于接入的界面，并增加了触摸 屏功能。批评者最初对这款系统不屑一顾，但凭借着免费和开源的优势，在苹果、黑莓和微软主导的市场中，Android还是吸引到了足够的手机厂商。到 2011年，在三星电子等厂商的大力推动之下，Android成为了最流行的移动操作系统。  
  
谷歌并不是唯一一家推出自己极简抽象派基于Linux的操作系统的科技公司。多年之前，英特尔也推出了一款名为“Moblin”的Linux操作系统；诺基亚则 推出了“Maemo”。此外，Palm的WebOS同样也以Linux为核心。操作系统市场最终的结局会是一家独大，就如同微软在上世纪90年代统治了 PC操作系统市场一样，科技公司最终会围绕着一款操作系统。除了服务器或PC的其它任何产品，目前都拥抱的是Android。  
  
非 营利组织Linux基金会执行理事吉姆·泽姆林（Jim Zemlin）表示，Android已自下而上征服了设备市场。根据市场调研公司IDC提供的数据，今年第一季度，Android在全球智能手机销量份额 达到75%，出货量达到1.62亿部。iPhone和iPad均搭载iOS操作系统，这款操作系统完全由苹果控制，而Android则可以兼容各种形状和 尺寸的硬件设备，各大品牌也在争相采用该系统。泽姆林说，“人们已知的各种尺寸的显示屏、移动处理器和传感器都已与Android共事。这就是网络效应。 所有人现在都可以对Android进行定制，让它适应所有的产品。”  
  
泽姆林还特意把中国汽车制造商上汽集团作为案例。通过一支大约6名软件开发者组成的团队，上汽集团开发出了一款Android车载资讯娱乐系统。泽姆林表示，“与他们一同参加车展的其他汽车厂商都拥有庞大的软件团队。这家公司只有6个人和Android。”  
  
云 计算服务公司Xively技术副总裁菲利普·德索特尔斯（Philip DesAutels）对物联网已有多年研究。Xively最近发布了一款云计算服务，能够简化数据传输流程。德索特尔斯表示，该公司的Android软件 下载量为iOS软件的5倍。德索特尔斯最欣赏的产品：一款基于Android的农业灌溉系统，可以利用农田里的微型防水电脑网络来监控水阀。德索特尔斯表 示，“通过Android操作系统，所有的一切都将非常节能。它让开发者能够轻松的处理用户界面和屏幕控制，也便于数据的输入和输出。相对于其它操作系 统，Android背后有一个更大的社区。”  
  
对微软而言，Android的崛起并不是 什么好事，因为自1996年开始，微软一直在推广自己的嵌入式系统Windows Embedded。这款操作系统已经被福特汽车，NCR收银机等产品采用。但是在智能手机和平板电脑市场，微软似乎错过了时间并错误的估算了自己的能量。 德索特尔斯表示，“我们对微软没有任何要求。”他接着说，有很多公司都在开发能与iPhone和iPad配合使用的智能电子计步器、联网LED灯以及其他 设备，但这些外设都有可能会运行Android或是更加简单的系统，因为苹果对让非苹果产品搭载iOS操作系统并不感兴趣。截至目前，苹果对此报道未置可 否。  
  
负责微软Windows Embedded业务的凯文·达拉斯（Kevin Dallas）表示，微软拥有更成熟、更复杂的技术。他说，“目前排名第一的商务平台依旧是Windows Embedded。”  
  
谷 歌Android部门前主管安迪·鲁宾（Andy Rubin）为这款系统的成功做出了重大贡献。鲁宾自己还在加利福尼亚州的洛斯阿尔托斯建立了一个孵化器，帮助朋友们开展项目。鲁宾曾向一个团队表示，汽 车产业对Android兴趣极大，但是谷歌并不希望与它们签署协议。很快，便有四位年轻人创办了一家名为CloudCar的创新公司，他们开发的车载信息 娱乐系统今年将开始对外销售。
