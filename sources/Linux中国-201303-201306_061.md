# Ubuntu 老大 ：在 Win8 问题上，微软没错

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000560&itemidx=3&sign=564fe5dd8f54269e18a2f34c1c60359f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000560&itemidx=3&sign=564fe5dd8f54269e18a2f34c1c60359f&scene=27#wechat_redirect)

　　尽管近年来微软与 Linux 的竞争从未停歇，不过就事论事，**Ubuntu 创始人、首席执行官 Mark Shuttleworth 还是对微软表示了赞许，他认为，微软关于 Windows 8 的决策是正确的**。

　　Shuttleworth 在 Ubuntu 开放周会议上表示，Windows 8 确实带来了很多创新，这种巨大的变革对于很多企业来说是绝对必要的。改变总是艰难的，但是他相信今后每个人都会习惯于新的 Windows。

　　当被问及对 Windows 8 的看法时，Shuttleworth 毫不吝啬赞美之词：“**大胆的抉择，正确的理念，虽然开局不利，但好戏才刚刚开始**。**改变是艰难的，不过其愿景是正确的，我很敬佩微软的远见和为之付出的努力**，但是他们的起步却并不顺利。”

　　此外，Shuttleworth 还夸奖了微软在云计算领域的工作，认为微软在这方面的战略是非常明智的。

　　Shuttleworth 的一席话或许令 Linux 粉丝震惊，是啊，去年 10 月 Ubuntu 12.10 发布的时候官方还建议那些不习惯 Windows 8 的用户不妨转投 Ubuntu 。不管 Windows 8 是不是一款优秀的操作系统，迄今为止其销量、用户满意度还真是十分契合 Shuttleworth 的那句话：**改变是艰难的。**
