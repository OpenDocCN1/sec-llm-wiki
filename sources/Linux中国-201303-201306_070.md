# 红帽CEO解读开源、OpenStack和Hadoop

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000547&itemidx=5&sign=002b90b6faa1748b287eddc2a1350675&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000547&itemidx=5&sign=002b90b6faa1748b287eddc2a1350675&scene=27#wechat_redirect)

红帽（Red Hat）首席执行官Jim Whitehurst认为，企业级软件厂商正处于一个转折点，他们要么去适应要么被动摇；他还指出，OpenStack需要企业的支持，Hadoop已经成为一个很强大的开源项目，并且在商业领域更加碎片化。

Whitehurst在2007年加入红帽之前，曾经担任过达美航空（Delta Airline）的首席运营官，以下是他的一些观点。

目前开源的状况是怎样的？

Whitehurst表示，开源已经进化成为一个领先的创新引擎。他解释说：“开源是一个不断发生创新的领域。开源最早是从复制其他东西开始的，但是现在开源已经处于领先位置。大数据和软件定义网络，都是开源的。开源领域有很多新东西出现。

企业级软件的未来是怎样的？

企业级软件市场是不断变化的，未来企业如何使用应用、企业将如何反应，这些都是我们还不知道的。今天，像Facebook、Amaozn和Google这样的企业走在前列，Whitehurst表示：“这么多的企业软件都是用来发现问题、然后构建一个定制化的解决方案。我们越来越多地使用通用的系统。”

Whitehurst将通用的系统（通过开源和廉价的硬件实现商品化）比作是最终做成内燃机的标准部件，一旦部件被标准化了，那么将掀起一股创新的浪潮。随着计算系统更多地商品化，企业级软件厂商的“利润池随之蒸发”，“这对于大多数基础设施软件厂商来说都是一个巨大的挑战”。

Whitehurst预测企业级软件厂商领域将发生根本性的变革。另一方面，企业级软件将被嵌入到服务提供商的服务中。例如，SAP和Oracle提供的功能特性，也许最后只是变成了像UPS这样的公司提供的服务的一部分。Whitehurst表示：“独立软件厂商（ISV）和企业之间的界线正在变得越来越模糊。很多企业将变成软件公司。通用电气（GE）拥有大量的软件，但是它并不是一家软件公司。”

在软硬件基础设施厂商中，只有IBM之前曾经驾驭过这种变革。IBM正在向基础设施堆栈的上层移动。Whitehurst指出，当他还在达美航空公司工作的时候，IBM是唯一一家在会议中谈论航空业而不是单纯谈技术的IT厂商。

还有一方面，企业级软件市场正在变得更加多样化。Whitehurst表示：“有很多很多软件公司在根据一个理念开发产品，而且构建成本低，基于AWS进行部署。这些公司并不需要太多的资金、销售和分销资源，因为他们把所有的成本都分离在外。这是一个很好的模式，但是企业级软件会变得更加分散化。”

Hadoop会有怎样的未来？红帽在Hadoop上将有什么样的动作？

关于Hadoop的未来，Whitehurst把大数据引擎和Linux做类比。他还看到了红帽的一些机会。“Hadoop的创新并不是针对企业级客户的。”因此，Hadoop被商业地分割为不同的组成部分，更好地针对不同企业。然而，需要注意的一个关键点是，Hadoop被商业化地分割了，但是开源项目并没有。“Hadoop将被大量采用。我可以预见到，Hortonworks和Cloudera将成为Hadoop领域的Oracle和IBM DB2。我还会预测，Hadoop将渗透到方方面面，它的价值越来越明显。”

红帽是否会自己创建一个Hadoop发行版？Whitehurst说：“目前我们还没有这方面的打算。”他指出，有太多的厂商在做Hadoop发行版。当被问及是否各种旨在将专用技术和开源技术融合的Hadoop发行版长期来看是否可行时，Whitehurst回答说：“推动一个专用技术路线图要比开源更困难一些，而要把两者都做好更是难上加难。你可能很难有一个清楚的营销策略，这个项目很好推动路线图。”为什么像EMC和VMware这样厂商会通过Pivotal创建一个Hadoop发行版？“所有价值都存在于数据之中。”Whitehurst指出，“EMC看到了这个价值”。

从OpenShift可以看到红帽在平台即服务方面的努力。OpenShift有25万个运行中的应用，并且都是运行在Amazon的AWS上。到目前为止最大的惊喜是什么？企业级客户需要针对私有云预置的OpenShift。“很多客户希望硬件和PaaS之间有更紧密的集成。”红帽的自动伸缩平台让人们看到了私有云和公共云平台即服务将得到企业的很多关注。

Whitehurst眼中的OpenStack

同时红帽也是OpenStack的一个主要支持者，OpenStack是一个最初由NASA和Rackspace发起的云操作系统技术。从表面看，红帽似乎在OpenStack方面发力较晚。Whitehurst表示，红帽在OpenShift和OpenStack的集成方面扮演了重要角色。他还补充说，在18个月前红帽当时对于OpenStack并不感冒。“OpenStack并不是围绕云基础设施的第一个成果，但是它拥有广泛的支持和参考标准。”

OpenStack可以抽象基础设施层，这样企业就可以控制成本和硬件的使用。很可能OpenStack最终将让客户能够自动地在提供商（例如Rackspace和AWS）和他们自己的基础设施之前进行切换。“从理论上讲，未来今年，应用层将变成不可知的。”

Whitehurst认为红帽在OpenStack上所扮演的角色有点类似于在Linux领域的角色。红帽将提供支持和稳定性。“我们将支持一个企业级的版本，并承诺提供10年的支持。”他指出，精确的时间线可能会有所不同。事实是，OpenStack具有新的功能特性，并且保持着快速的发布步伐。如果你是一家企业，你不会把软件补丁应用到更老的版本上。Whitehurst表示：“我们有大规模支持OpenStack的技术和信誉，我们最大的价值是长期稳定性。我们不会破坏接口，也不会破坏双向兼容性。”

这会让红帽成为一家没有创新的传统厂商吗？当被问及是否红帽现在正面对这个问题的时候， Whitehurst笑了：“红帽正在稳定的成长着。”不过，红帽并不会被认为是一家传统厂商，如果考虑到他们在OpenStack这样重新定义IT的技术领域所做的事情。要想给红帽做一个定义有点难。如果开源正在领先，那么红帽是推动技术商用化变革的关键厂商。而另一方面，红帽带来了让CIO们能够提前进行规划的稳定性。红帽似乎是介于两者之间，而且Whitehurst似乎对红帽所扮演的角色很满意。
