# MegaUpload创始人：Google和Facebook都侵犯了我的两步认证专利

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000519&itemidx=1&sign=ccd8f65915395229d02b73dd117af656&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000519&itemidx=1&sign=ccd8f65915395229d02b73dd117af656&scene=27#wechat_redirect)

两步骤认证似乎成为现在社交网站、即时通的一个安全认证的标准流程。**Megaupload创办人Kim Dotcom在Twitter上表示，他其实才是这个两步骤安全认证的发明者，早在1997年他就拥有这套认证方式的专利，并且表示Google、Facebook、Twitter等公司都侵犯了他的知识产权。**

![](../Images/14aae8e8a373f6f346e7c8c54a548af3.png)

  
Kim Dotcom是在他的Twitter上表示的，而且他的这项指控并非空穴来风，根据他所附上的链接，这份专利的编号为US 6078908 A，专利名称为Method for authorizing in data transmission systems。这份专利的拥有者为Kim Schmitz，这是他原本的本名。  
  
![](../Images/ea79a37aae9ffe8539244661e1de158a.png)  
  
如果还有人不清楚两步骤认证的话，可以到Google的说明网页看看，当你在电脑上登入时，需要通过另外一个可信任的装置，传送给你另外一组认证码，让你在电脑上登入。目的是通过双重认证来确保你的安全性。  
  

![](../Images/5b4b584cdaf7d2d3237f01833f38eb27.png)

  
其实在这之前，也有一些人宣称他们拥有两步骤认证的专利，不过Kim Dotcom拥有的这份专利是早在1997年就通过的，比这些社交网站成立都还早，因此有机会打挂现今所有用到两步骤认证的网站。  
  
虽然在专利内并没有明确的出现“两步骤认证”这样的字眼，而且在这份专利摘要的描述中，整个步骤有多达七、八步，不过，检视整个专利的过程，的确核心的想法是一致的。在那个年代虽然没有智慧手机，Kim Dotcom就想到用BB CALL或是手机简讯当做第二认证装置，来传递认证码，的确也展现了他的天才。而且，他新成立的 Mega云端服务，在成立之初也设计了超强的安全机制，他在资安方面的实力也不需怀疑。  
  
![](../Images/6d58de601dc6c05fe6ff008bfbe189de.png)  
  
Kim Dotcom在他的Twitter上后续还有提到，出于知识共享的理念，以及对于社交有益的想法，他过去从未想到要控告这些公司。不过现在他提到这件事，则是因为他开始认真考虑要控告他们了，因为美国政府正是这样对待他的。  
  
不过，这位传奇人物是否真的会杠上这些公司，或只是突然想抒发一下心情，恐怕还要观察下去。
