# 英特尔开源Linux OpenGL驱动快于苹果OS X驱动

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000519&itemidx=4&sign=c12b373fe97ace09034c0ba124148c4f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000519&itemidx=4&sign=c12b373fe97ace09034c0ba124148c4f&scene=27#wechat_redirect)

前两天我们发表了一篇文章 《可视化分析WEB访问：logstalgia》，其中提到了用弹珠游戏的方式实时显示WEB访问行为，所生成视频的技术技术是OpenGL，体现了OpenGL的十分强大，今天又有一则OpenGL的新闻：

**英特尔的开源Linux OpenGL驱动已经比苹果自己开发的OS X OpenGL驱动更快。**Phoronix在硬件规格基本相同的 Mac Mini（双核Intel Core i5，2GB内存，OS X 10.8.3）和运行Ubuntu 13.04的PC（四核Intel Core i5 2415M，2GB内存）上测试了英特尔集成显卡 HD 3000的跨平台 OpenGL 性能。 

![](../Images/82a746361b7334796978142be8209d04.png)

  
结果显示，开源Linux OpenGL驱动比苹果快30%以上，而最新的英特尔开源OpenGL驱动与苹果驱动的性能差距更大。
