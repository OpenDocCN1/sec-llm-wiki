# Windows 8 真可怜，连戴尔都不想要你了

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000493&itemidx=1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000493&itemidx=1&scene=27#wechat_redirect)

是的，Windows 8 已经可怜到连微软最亲密的合作伙伴们也开始“倒戈相向”。据 CNet 报道，戴尔在最近的一次电话会议上对分析人士称，Windows 8 令他们感到非常失望，它没能成功提振 PC 市场。

戴尔 CFO Brian Galdden 表示：“站在我们的角度上看，Windows 8 并没有如我们希望的那样成为加速 PC 市场发展的催化剂。”

更过分的是，他们不仅不和 Windows 8 玩，甚至还要重提 Windows 7——戴尔在本周四的财报会议上表示，目前大部分“商务”用户正处在“从 Windows XP/Vista 过渡到 Windows 7 系统”的转变初期。Galdden 对此表示：“我相信 Windows 7 在商务领域的比重将会越来越大，它将会带来新一轮的市场变革。” 

硬件方面，他提到了 Haswell 芯片：“新的芯片和 Windows 生态系统内的一些不错进展鼓励着我们，我们希望在未来几个月能为用户创造一些兴奋点。”

不过戴尔依然即将到来的升级版 Windows Blue 寄予厚望，也可以说是想办法多抓住一根救命稻草。

昨天，戴尔公布了今年第一财季财报。财报显示，在截至 5 月 3 日的这一财季，戴尔净利润为 1.3 亿美元，同比下降 79%；营收为 140.74 亿美元，同比下降 2%。

第一财季来自企业解决方案、服务和软件的营收同比增长 12%，至 55 亿美元，而总营收则同比下降 2%。包括 PC 在内的终端用户计算部门营收同比下降了 9%。不难发现，传统 PC 产品业务的营收在总营收的占比仍旧超过 60%，尽管如此，运营利润依然在加速下滑。为了加强企业业务，以便更好地与 IBM 和惠普竞争，戴尔正在加大对研发和销售的投资。

这是外患，还有内忧。近期，戴尔 CEO Michael Dell 和投资人 Carl Icahn 正在对戴尔发起竞购大战。第一财季不给力的业绩显然对 Michael Dell 有利——此前他提出以 244 亿美元的价格将戴尔私有化，希望将戴尔转型为一家企业计算服务提供商。

二人在戴尔未来的发展方向上的分歧非常明显，这也侧面印证了 PC 前景的黯淡和动荡。
