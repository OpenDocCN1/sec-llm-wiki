Mageia 3 发布

原文：http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000493&itemidx=4&scene=27#wechat_redirect

　　Mageia 是 Mandriva Linux 于2010年9月形成的分支,该发行版最近在 distrowatch 上的页面点击位于第2名。

　　与 Mandriva 这份商业实体所不同的是，Mageia 计划乃是一个社区项目及一个非盈利性组织，它的目标是开发一套自由的基于 Linux 的操作系统。

Mageia 3 包含以下更新：

  • 使用 LINUX 内核3.8.13，systemd 195

  • 默认使用 GRUB，而非 GRUB2

  • 使用 OverlayFS  构建  livecd

  • 安装支持  btrfs  分区格式

  • RPM 4.11 , Mandriva Linux 和 Mageia 开发的图形软件包管理软件 rpmdrake

  • Perl 已经被升级到 5.16.3，Ruby 已经被升级到 1.9.3。

  • 默认使用 Journalctl，您可以安装 rsyslog。

  • KDE 4.10.2 ，GNOME 3.6，LXDE 0.5.5，XFCE4 4.10，RazorQt 0.5.2，E17，

  • Libreoffice 4.0.3，chromium 26.0，Firefox 17.0.6

  • Wine 1.5.27

  • /usr 目录调整工作完成，参考这里 ，好像很多版本都在搞这个 UsrMove。Solaris 15 年前开始搞的项目，直到 solaris 11 才完成。呵呵。

服务器版本信息

  • puppet 2.7.21， 8.4.2，Corosync 2.3.0 ， Pacemaker 1.1.8

  • PostgreSQL 8.4；MariaDB （取代 MySQL )；BDB；CouchDB 1.2.1； Redis 2.6.5 ；MongoDB 2.2.2

  • Apache 2.4.4， Cherokee 1.2.101 ， lighttpd 1.4.32
