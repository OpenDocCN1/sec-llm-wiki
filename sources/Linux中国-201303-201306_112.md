# Google眼镜官方越狱！可以刷Ubuntu

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000481&itemidx=1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000481&itemidx=1&scene=27#wechat_redirect)

　　Google虽然不允许你转手Google眼镜，但是却没限制你怎么玩这款设备，甚至还鼓励开发人员对其进行越狱，以探索Google眼镜的更多用途。

　　在今天的Google I/O大会中，**Google X软件工程师**Hyunyoung Song和P.Y.Laligand向开发人员**演示了如何使用ADB或root模式操作让Google眼镜运行Android应用程序、Ubuntu系统**。

**　　Google眼镜可以看做是一款Android设备**，目前已经发售的2000副探索者版本运行的是Android 4.0.4系统，这意味着它和你正在使用的Android手机采用相同的OS。

　　在I/O大会“让你的保修作废：黑掉Google眼镜”环节，Laligand演示了如何激活Google眼镜的Android调试桥（Android Debug Bridge，ADB），在其上**运行标准的Android应用程序**，**它还能支持外接键盘、触摸板**。当然，Google眼镜的探索并非止步于此，**Google还演示了在Google眼镜上运行Ubuntu系统**。
