# Ubuntu 13.10将考虑使用Google Chromium替代Firefox

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000481&itemidx=2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000481&itemidx=2&scene=27#wechat_redirect)

　　昨天，Ubuntu Linux开发人员讨论了使用Google Chromium（Chrome开源版）替代Mozilla Firefox作为Ubuntu 13.10默认浏览器的可能性，结束了今天的讨论后，这件事情似乎就这么定了。

　　Ubuntu开发商Canonical希望将Chromium作为系统的默认浏览器，不过依然会在系统中提供Firefox，只是不再作为Ubuntu桌面的默认浏览器。

　　突然采用Chromium作为默认浏览器必然会带来很多不便，例如，需要从Firefox迁移数据，两款浏览器无法实现插件/扩展的迁移，Chromium不支持所有架构（例如PowerPC），不兼容Orca屏幕阅读器，没有原生PDF插件，在内存较低时性能不佳。

　　但是根据目前Canonical的态度，Ubuntu 13.10极有可能使用Chromium作为默认浏览器，理由是提供更好的用户体验，因为现在Chrome在功能上不逊色Firefox太多，在性能测试中表现却优于Firefox不少。此外，采用Chromium后Ubuntu在手机、平板机、桌面上的体验将更加一致。

　　Ubuntu 13.10将在9月5日发布Beta公开测试版，到那时我们就能知道Chromium是否是默认浏览器了。
