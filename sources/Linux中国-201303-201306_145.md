# 编外谈

昨天微信君吐槽了几句，得到了朋友们的安慰和鼓励，谢谢大家。:>

  

今天和大家说个事情：

  

微信君为这个公众微信开了一个微信群，原本想着因为公众微信很难交互所提供的一个交流场所。不过由于微信群这方面还有很大缺陷：

1、上限为40个

2、交流体验还不如qq群

3、最重要的是，在这里发言很危险！

所以，微信君决定今天开始，正式解散和取消这个微信群聊了。

  

上面提到微信群聊很危险，我来说说是为什么：

  

前天，微信君在微信群里面推荐了一个网络安全方面的公众微信，这本没什么，也得到了一些朋友的欢迎，至少没看到反对或者批评这个推荐。结果，第二天上午，微信君自己的微信账户就被举报了~~~然后一通混乱的申诉，什么申诉电话、网页申诉都试过了，经过漫长的等待，总算给解封了。

  

由于极度的抗议，腾讯总算是给了一个电话回馈：居然，就是因为有一个人举报了我，举报理由是“骚扰”，然后我就被封杀了。没有举报的信息内容作为证据，不能（或者不告诉我）谁举报的，也仅仅一个举报，而且也无任何通知，就被封杀了。

虽然，能够来电解释还算安慰，但是微信君还是觉得“地球很危险”啊，因为，决定关闭微信群，待以后相关机制良好后再考虑吧。
