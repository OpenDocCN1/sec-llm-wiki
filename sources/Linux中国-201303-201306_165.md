# Debian 7.0“wheezy”发布

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000401&itemidx=1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000401&itemidx=1&scene=27#wechat_redirect)

　　开发者按计划如期发布了Debian 7.0“wheezy”。相比与两年前的Debian 6.0，wheezy增加了12800 个新软件包，软件包总数共计37493个，更新了 20160软件包，删除了4125个软件包，在包管理软件中它们会被标记为“过时”。

**主要新特性包括：**

*   从X.Org 7.5更新到X.Org 7.7；
    
*   桌面环境GNOME 3.4、KDE 4.8.4、Xfce 4.8和LXDE；
    
*   LibreOffice 3.5替换 OpenOffice.org；
    
*   Calligra 2.4 替代KOffice；
    
*   GNUcash升级到2.4；
    
*   GIMP更新到2.8；
    
*   Linux kernel 3.2；
    
*   初步支持systemd；
    
*   提供蓝光光盘镜像；
    
*   包管理器支持多架构，如64位机器安装64位和32位软件，自动正确处理依赖关系；
    
*   改善多媒体支持功能；
    
*   支持AppArmor强制访问控制系统；
    

详细可参考发行注解。
