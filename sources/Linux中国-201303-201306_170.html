Chrome Office初体验：和微软Office对抗还嫩点

原文：http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000389&itemidx=3&scene=27#wechat_redirect

日前，Google发布一款基于Chrome浏览器的插件，可以让使用Chrome 27测试版及最新Dev开发版的用户直接在浏览器里阅读Word，Excel和PPT文档。这款最新插件叫做Chrome Office Viewer，之前这一功能一直是Chrome OS的一部分，现在在普通PC上也可以启用啦。有了这款插件，无论是在OS X上还是Windows上，你都能像使用Chrome OS一样，直接打开在线或者是本地的Office 文档进行工作。但是现在，它只支持只读模式。所以在使用上，它非常像Chrome内置的PDF功能，拥有工具栏按键，支持缩放，打印，保存。

这 款插件非常大，需要下载好几MB的安装文件。它包含了Google原生客户端，能提供原生代码运行的一个沙盒保护。它可以在离线断网状态下运行，也就是 说，在显示文件之前不需要预先请求例如微软Office web Apps服务（译者注：这是微软提供的Office在线版本，下同）或者Google的 Drive and Docs在线服务。

当然，目前这款插件还在Beta测试阶段，部分功能相对比较简单粗糙，使用过程中还存在许多的问题。我们试着用它打开一篇非常具有代表性同时也非常简单的Word文档，发现了很多明显的错误，例如，页眉、页脚丢失了，行号不对，字体不对，一些边框和阴影设置无法体现。

在微软Word里打开的文档，注意它本身使用的sans-serif字体以及页眉、页脚和两个完全独立标号的数字列表。

同 一篇文档在使用Chrome Office打开，只部分保留了serif 字体，两个数字列表错误地使用了连续的标号，页眉和页脚不见了，分页也变得不一样。而我们之前提到的在线服务版本Office Web Apps和Google Drive Apps（这两者几乎都是免费的），都能提供更加准确的展现。更重要的是，Office Web Apps可以支持在线编辑哦（Google Doc不能直接编辑原文档，而是需要转换到一个可编辑的在线表单。） 第三方的Chrome插件甚至可以让你使用Office Web Apps打开文档中链接的其它Office文档。

由此看来，即使离线模式对你来说非常重要，你也有其它更好的选择，例如微软的Office本身，假如你不想使用付费软件，免费的OpenOffice也能提供更好的精确性。

Office Web App完美展现了同一文档。

Google Drive的错误在于分页错了，但是字体，列表编号，页头页尾都正确显示了。

基于以上的试用测试，这款插件目前的使用价值还非常有限。但它的离线模式对Chromebooks来说却很重要，因为现在后者没有支持运行任何原生程序。但对于在线的OS X，Windows 或者Linux用户来说，毋庸置疑，他们还有其它更好的软件选择。

比这款插件本身更加让人感兴趣的是Google在后续如何发力。如果它能够加入编辑功能，将会成为Office的有力竞争者。就算本身还存在一些刚才我们说到的格式问题，届时也将会是一个不错的进行简单文字处理的工具。

当 然，Google也拥有这个开发方向所需要的技术人才。去年它收购了Quickoffice，这是一家为iOS和Android平台编写office应用 程序的公司。如果你试着体验一下这款插件，或许你会注意到其中有Quickoffice代码的影子。只要给Quickoffice现有的编辑功能加上一个 用户界面，那Chrome Office Viewer就会轻松的进化成一个Chrome Office应用程序。

这样的变化不仅改变了 Chrome Office Viewer，也将帮助Chromebooks的进步。现在，后者只是在看电视的时候同时用来看网页非常的方便，但是一旦它拥有了支持在线和离线工作的高 效率功能，不难想象，届时Google将同时在操作系统和办公软件领域对微软构成全面的威胁。
