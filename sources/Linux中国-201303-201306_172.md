# 安装Linux太麻烦，德国教育部扔掉感染病毒的电脑！

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000389&itemidx=2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000389&itemidx=2&scene=27#wechat_redirect)

德国IT杂志Heise报道（德文），德国Schwerin地区教育部门有170台机器感染了Conficker病毒，**他们的处理方法是简单把电脑扔掉，因为雇人清理（或安装Linux）太不划算。**

教育部门最初估计，桌面和服务器的病毒清除费用将高达13万欧元，虽然微软已经发布了Conficker病毒的一键删除工具。德国官方表示，这种病毒清除方式是不恰当的，没有符合效率和经济原则。采购新设备和安装花费了18.73万欧元税款。
