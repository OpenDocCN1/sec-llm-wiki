# 海盗湾现在是名副其实的“加勒比海盗”了

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000389&itemidx=1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000389&itemidx=1&scene=27#wechat_redirect)

上周，世界最大BT分享网站海盗湾的格陵兰岛域名被扣，随后它立即将网站迁移到了冰岛。但瑞典检察官周二的投诉让冰岛域名.is面临危险，迫使其再次寻找新家。这一次它找到了加勒比岛国圣马丁（Sint Maarten），注册了.sx域名(可正常访问)，正式成为**加勒比海盗**。

圣马丁岛面积88km²，分属于荷兰和法国，南部属于荷兰的海岛领地，北部则为一法属海外行政区域， 分别有4.1万和3.7万居民。
