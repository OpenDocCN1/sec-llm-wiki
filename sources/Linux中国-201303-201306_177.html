Ubuntu Touch现在仅基于Ubuntu 13.04创建

原文：http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000378&itemidx=1&scene=27#wechat_redirect

Ubuntu Touch 是 Canonical 公司为移动触摸设备开发的操作系统 ，Ubuntu Touch 采用的是原生代码而非像android一样使用 Java 虚拟机，所以安装的应用程序不会消耗过多内存，即使在低配置手机上也可以流畅运行。Ubuntu 同时支持使用 Qt/QML 开发原生应用，以及基于 HTML5 的 web 应用，这样 Ubuntu 的眼光是看得很长远。

按照目前的表现来看，未来 Ubuntu 手机的体验值得期待。

之前的版本是基于Ubuntu 12.10和Ubuntu 13.04为基础。ubuntu 13.04 正式发布以后，该系统现只基于Ubuntu 13.04 创建。

每日创建版本下载：http://cdimage.ubuntu.com/ubuntu-touch-preview/daily-preinstalled/current/
