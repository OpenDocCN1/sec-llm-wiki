# Amazon在京机房完成 阿里云、盛大云保重

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000378&itemidx=3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000378&itemidx=3&scene=27#wechat_redirect)

今天小道君@Fenng 透露：Amazon在北京的机房建设完成， 真是“该来的还是要来的”， 阿里云，盛大云，你们保重！听到这个消息的时候不管真假，第一时间想到的是Amazon云是真的厉害， 如果真有此动静，对阿里云和盛大云绝对是个很大的冲击。

### Amazon的云

Amazon自06年便开始云计算商用，大名鼎鼎的Cydia后台正是Amazon云技术。国外的用户可能更知道Amazon的价值，因为光AWS驱动的公司就有：Dropbox，Adobe，Twitter，NASDAQ，NASA……它比Google、苹果的云成就厉害多了，现在它的杀手锏是超低价格的个人云，其个人云存储服务Cloud Drive，可以享受5GB的免费空间，便捷地在云端保存视频、照片、文档和其他数字文件。高质价美，对于喜欢云同步的用户无疑是个很大的诱惑。

![](../Images/421c460da774662939f5eff554519905.png "Amazon_1")

### 国内的云

国内阿里云盛大云万网云目前是最知名的3家IaaS厂商，也是市场影响力和客户基数最大的厂商。说是这三家在第一阵营，并不一定代表他们做的很好，相反，都还是不及格。媒体评价: 目前看，阿里云的主要获取客户手段是BGP带宽和价格，而这两个都是资源导向。其抢夺了传统IDC的虚拟主机、VPS、小托管客户，但其对客户带来的价值方向并没有超远传统IDC服务商。

### 价格对比

Amazon云： Amazon EC2云主机，Amazon云计算的核心，每月可用750小时，无本地储存，只能搭配EBS存储服务使用，单价0.02美元每小时。一个月15美元。

新产品Amazon Glacie：云存储 可以帮助企业尤其是小型企业安全托管它们的备份和归档数据，并且以每GB 每月0.01美元的超低价格收取数据储存费。一个月10美元，但够用户储存任何数据了；打个比方，维基百科的数据是8.5 GB，它需要支付给Amazon Glacier 的费用一年还不到1美元！

盛大云：2000块钱能拿下一个云主机。适合中小站长的有超微主机（417元/年、）、微型主机（834元/年），在加上最低2M宽带（1080元/年），而且还可以按月、按小时付费。

阿里云：套餐少，但服务器配置都很高，拿下最便宜一台云主机至少要5000元以上。

### Amazon云很可怕的

无风不起浪，4月25亚马逊的另一个新举动给不少人带来了希望，给阿里盛大带来了灾难，因为在亚马逊的官方首页的“商品分类”一栏，赫然出现了亚马逊推出的一款针对个人应用的云存储服务“亚马逊Cloud Drive”，这也意味着这个云存储服务已经正式向中国用户开放。不知道这个消息和今天@Fenng 的消息有什么关系，如果Amazon真的在北京筹建机房的话，阿里云和盛大云要技术没技术、要价格没价格，小心血雨腥风！
