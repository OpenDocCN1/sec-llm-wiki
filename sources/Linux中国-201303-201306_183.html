Nginx 1.4.0 稳定版发布

原文：http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000373&itemidx=4&scene=27#wechat_redirect

nginx-1.4.0 稳定版发布了，该版本包含 1.3 中的所有改进，其中不少都是新特性，包括支持 WebSocket 连接的反向代理、OCSP stapling, SPDY 模块, gunzip filter 等等。Nginx 1.4.0 在 1.3.16 的基础上修复了两个 bug：

*) Bugfix: nginx could not be built with the ngx_http_perl_module if the
  --with-openssl option was used; the bug had appeared in 1.3.16.

*) Bugfix: in a request body handling in the ngx_http_perl_module; the bug had appeared in 1.3.9.
