# Mark Shuttleworth称半年发布一个新版是“行为艺术”

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000366&itemidx=2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000366&itemidx=2&scene=27#wechat_redirect)

　　Ubuntu 13.04 Raring Ringtai已于昨日发布，创始人Mark Shuttleworth接受采访回应了批评，称每半年发布一个新版本是“行为艺术”。

　　Shuttleworth在2010年作出了一个有争议的决策，决定将默认界面改为Unity。三年后，Shuttleworth依然充满信心，认 为是走在正确的方向上。Shuttlewort描述半年一版本的发布周期是“行为艺术”，建造了一个歌剧院每半年必须举行一次表演。对于选择开发显示服务 器Mir而不是采用Wayland，Shuttlewort说Mir为手机、平板和桌面创造了统一的显示服务器。对于与中国工信部合作开发 Kylin，Shuttlewort说本质上说出于本地化的考虑，整合中国的内容和社交网络。
