# Ubuntu 13.04 Raring Ringtail 发布

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000360&itemidx=1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000360&itemidx=1&scene=27#wechat_redirect)

　　Ubuntu 13.04 Raring Ringtail 正式发布了。虽然在 Ubuntu 官方网站首页上还没有消息，不过在 官方 wiki 里已经可以访问到发布通告信息了。

应该是 Ubuntu 现在正在热和的准备最后发布出消息的相关工作，而页面已经做好了放在服务器上了，所以我们可以访问到。

不过可以看到的是 Ubuntu 系列发行版中的 Kubuntu、Xubuntu、Edubuntu、Lubuntu、Ubuntu Studio 的这些版本中还有几个的发行信息没有准备出来。

此外 UbuntuKylin 这个中国版本的 Ubuntu 倒是在中国发布了相关的发布信息，不过现在 UbuntuKylin 国内的官网访问我这里悲剧了。哎……

　　Wiki 官方发布信息地址：https://wiki.ubuntu.com/RaringRingtail/ReleaseNotes
