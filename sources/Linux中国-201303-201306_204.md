# 自带Linux操作系统的的智能鼠标：EGO！

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000334&itemidx=1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000334&itemidx=1&scene=27#wechat_redirect)

  *插在电脑上，它让你的电脑拥有触摸屏；插在智能电视上，它是一个多功能遥控器和游戏手柄；插在投影仪上，它是电子教鞭，它就是全球首款智能鼠标EGO！     *

   什么都可以是智能的了，手表有智能的，眼镜有智能的，就连鞋子都可以是智能的，那么原本就与科技沾边的鼠标必然也要跟上这个智能趋势。虽然说科技已经进步到“无法无天”的地步了，但是我们在电脑上进行一些简单的操作的时候还是需要像往日一样使用复杂的设备、进行复杂的操作，这样就给工序、工作连续性和生产力带来了一定的阻碍。为了解决的这个问题，EGO！智能鼠标问世了。EGO！不仅仅是一款鼠标，更是一个可以让使用者与电脑产生更多互动、更方便的操控设备，使用户与数字生活融为一体。

   EGO！是全世界第一款智能鼠标，它强悍的功能可以让使用者与所有兼容PC进行互动，让用户与鼠标融为一体，获得更舒适、更强大的操控体验。EGO！鼠标支持2D和3D操作，并且内置闪存（2GB/4GB）可以存储文件，驱动程序与任何系统兼容，多操作系统无缝衔接（目前支持所有的桌面操作系统、智能电视、投影仪和数字白板。

   功能强大并没有给EGO！智能鼠标带来美观上的折扣，EGO！的外观与微软的Arc Touch鼠标有异曲同工之处，便携、时尚，无论是“俯卧”在手掌下还是握在手心里，都非常舒适，而且不区分左右手，左撇子用户可以顺利使用。

   为什么把EGO！叫做智能鼠标？**因为鼠标的内部内置一颗400Mhz的ARM处理器，运行Linux操作系统，内置2GB/4GB闪存存储空间。**除了具备传统鼠标的光学传感器来实现2D操作之外，EGO！鼠标内部还有加速器、陀螺仪、电子罗盘三个设备来实现3D操作。鼠标与电脑之间的采用蓝牙进行连接，使用micro-USB数据线进行充电和传输文件。

   用户下载配套的软件和应用程序之后，就会在桌面上显示一个QR码，利用EGO！上的摄像头扫描QR码就可以完成蓝牙配对，智能鼠标就可以使用了。将EGO！放在鼠标垫上，它就是一个普通的光学鼠标，但是只要用户把鼠标拿起来，它就变身一个3D鼠标，用户的任何肢体操作都可以对鼠标进行操控。如果用户的操作系统是Windows 7/8，还支持手势操作。同时，EGO！还会记录用户的使用习惯，悬空操作时将进入智能模式，打开网页时，自动为用户打开最常访问网页，比如说微博、人人网、水果社区等。

   利用EGO！智能鼠标的3D操作功能，游戏玩家将体验到更真是的游戏体验。打开《使命召唤》，你手中的鼠标不再是鼠标，它是游戏主角手中握着的枪！

   EGO！智能鼠标已经开发了两年，目前已经完成了Kickstarter众募融资，年中即发货。据开发者介绍，EGO！智能鼠标的主要目标客户将锁定为商业企业和教育机构，因为这样可以充分发挥EGO！的功能，当然也对普通消费者开放。（戳此）

   目前EGO！智能鼠标即将上市，有2/4/8GB内存和黑白红绿黄蓝色可选，更可更具用户需求自由定制鼠标外观。
