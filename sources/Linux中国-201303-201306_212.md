# GitHub项目大多不是开源项目

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000323&itemidx=4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000323&itemidx=4&scene=27#wechat_redirect)

代码共享平台GitHub已成为最流行的开源项目托管平台，但一项分析发现大多数项目使用的许可证条款不明确不清晰不一致，很难说它们究竟算不算开源项目。软件自由法律中心的 Aaron Williamson分析了GitHub上约170万个项目，发现只有14.9%的项目在其一级目录中有清晰的许可证声明。

而在有明确许可证的项目中，绝大多数首选的是MIT、BSD和Apache许可证，选择GPL许可证的不多。 Williamson 发现，大约6.1万个项目采用了GPL或LGPL许可证。MIT、BSD和Apache属于开源许可证，但不属于copyleft许可证。年轻一代的程序员不像RMS那么关心对其代码的使用限制，他们宁愿赠与代码不在意对方是否回馈代码。GPL许可证要求使用GPL代码的项目必须在GPL下授权。
