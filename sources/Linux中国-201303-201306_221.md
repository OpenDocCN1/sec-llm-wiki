# Chromebooks 的表现比Windows RT还要差

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000309&itemidx=2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000309&itemidx=2&scene=27#wechat_redirect)

自去年和Windows 8一起推出以来，Windows RT就没怎么能火起来。设备制造商的热情也渐渐被残酷的显示浇灭。**不过，对于微软的这款ARM操作系统来说，它的表现还不是最差的——在以Web为中心的产品市场中，有一款操作系统的表现比Windows RT还要"糟糕"——那就是Google家的Chrome OS。**

ZDNet的Ed Bott，在探索了NetMarketShaer的Chrome OS全球市场份额数据后发现，Chromebooks只占据了0.023%。面世已两年，其份额竟然比Windows RT头三个月还要少，对于Google来说，这未免有些"凄凉"。

与Windows 8所声称的3.31%相比，其境况似乎要更加糟糕。

当前有大量的PC制造商在生产低价的(250美元左右)ChromeBook，包括惠普、三星、宏碁和联想，且Google自己也在以1300美元的价格销售着更高阶的Chromebook机器。

尽管消费者有数款Chromebook可以购买，但有报到指出，自推出2年以来，其只售出了不到50万台(Surface RT为110万台)。

看来，消费者并不渴望一台带网页浏览器功能的低价本；相反，他们更愿意在平板和成熟的PC上花更多的钱。可以肯定的是，PC市场确实在转移(我们已经看到了出货量的下降)，但它并没有转向Chromebooks。
