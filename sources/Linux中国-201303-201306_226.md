# 野外使用Ubuntu系统控制的无人驾驶汽车

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000302&itemidx=1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000302&itemidx=1&scene=27#wechat_redirect)

　　这是国外博客iloveubuntu发布的信息，Ubuntu 成为该无人驾驶汽车的主角，国外的一些无人驾驶汽车基本上都把操作系统首选定为Linux，在德国无人驾驶汽车项目也选择Ubuntu。

　　这是巴西是目前在类似房车的无人驾驶汽车上做的实验，巴西圣埃斯皮里图州州立大学，无人驾驶汽车已经达到了一个可实用的阶段，该无人驾驶汽车使用ubuntu 作为基本的操作系统，为Unity桌面的版本，这也说明ubuntu 系统本身的稳定性和适用性。
