# 用树莓派节省国际漫游费

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000288&itemidx=3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000288&itemidx=3&scene=27#wechat_redirect)

如果你经常旅行，你是否已经习惯那些不合理的手机漫游费呢？然而，手机有时候是绝对必要的 —— 我们在海外工作或度假都不得不支付手机漫游费，因为我们需要与办公室保持联系，还要与世界各地的人谈论关于树莓派的相关事宜。（我们还想与母亲通话呢！）

Holger Leusch 、 Benjamin Reichel 和 Karina Hochstein 都面临这样的问题。更糟糕的是， Holger 经常要去柬埔寨，但是他的德国手机供应商甚至没有与柬埔寨电信运营商签订任何漫游协议，所以他根本无法继续使用原手机（号）。柬埔寨那勉强的通话质量、恶 心的带宽、延迟和断线令他难以忍受。实际情况是，他和我们一样，需要与办公室保持联系。

进入树莓派的领域吧：

![](../Images/de0a808346934c15ee7397b6d23a73af.png)

许 多人设身处地，可能会考虑买一个基于 SIP-GSM 的网关。 不过， GSM 网关可不便宜啊： Holger 研究发现，单个 GSM 端网关（你肯定需要2个，2个地点各1个网关），售价在 200 至 400 欧元不等。如果投入这么高的代价，打多少电话才能够本啊。所以，他们3人自己动手，最终选择方案包括：通过树莓派运行 RasPBX，华为 3G 无线上网卡， Asterisk 的华为 3G 无线上网卡驱动，以及 USB 模式转换工具。全套价值约 75 欧元。

Holger 说：

*现在，当有人在欧洲拨打我在德国的 GSM 号码时，首先我在国内的手机会响铃，5秒之后，将转接至我的柬埔寨手机。作为一个副产品，从现在起，我的柬埔寨朋友可以致电我的柬埔寨手机，最终与我的德国手机实现通话或是发短信，通话费很便宜…*

![](../Images/54d186b6e3f73d6904e9764c41f8d649.png)

跨 越了一万多公里，两个网关之间 64 kbps Asterisk “SIP trunk” 中继技术带来的连接质量真是棒极了，和我通话的人甚至都没有注意到我已身在海外。需要注意的是，英国通信管理机构 Ofcom 称，在一些国家，与 GSM 网关相关的电信法还比较模糊：

*Ofcom 近日澄清说，根据英国法律，只要是自己使用，用户（无论是企业或普通消费者）购买、安装和使用 GSM 网关是完全合法的。可是，任何人不得使用 GSM 网关设备向其他个人、组织或是商业机构提供通讯服务，否则不论网关设备的地理位置，或是连接到每个网关的终端用户数量，都将是违法行为。这一“商业”使用 禁令同样适用于移动网络运营商（MNO）和其他组织，因为移动运营商目前的牌照并没有拓展至 GSM 网关的安装和使用。*

基本 上，你可以在英国建立自己的网关 —— 但是如果你试图出售或是出租这一服务，你就惨了。不过，如果你想使用这个办法省下漫游费，移动网络运营商有时会采取进一步行动，例如，如果移动运营商怀疑 你将 SIM 卡用于 GSM 网关，运营商可能会停用该卡。因此，在采取此次行动之前，一定要仔细研究当地法规。

**ofGEEK：**

*RasPBX 是树莓派上运行的 Asterisk 和 FreePBX 的完整安装工具。*

*PBX (Private Branch Exchange) 用户级交换机*

*Asterisk 是一个开放源代码的软件 VoIP PBX 系统，它是一个运行在 Linux 环境下的纯软件实施方案,是一种功能非常齐全的应用程序，提供了许多电信功能，能够把你的x86机 器变成你自己的交换机，还能够当作一台企业级的商用交换机。*

*FreePBX 是一个最强大的 GUI （基于网页的）配置 Asterisk 的工具。它提供标准传统电话系统能做的任何事，加入大量的新功能。 FreePBX 之前被称为 Asterisk Management Portal ，是 IP 电话工具 Asterisk 的标准化实现，可提供 Web 配置界面和其他工具。*
