# Firefox对第三方Cookies的立场将变得更为强硬

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000272&itemidx=3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000272&itemidx=3&scene=27#wechat_redirect)

**无视广告商们的抱怨，将来的桌面版Firefox浏览器将默认阻止第三方的cookies，且桌面和Android版Firefox都将得到引擎下的数项改进。**截至目前，仅有苹果公司的Safari浏览器会默认阻止第三方的cookies。上周发布的Firefox 22(developer's channel)，也带来了这个功能。这意味着，该功能将很快遍及所有Firefox的用户。

![](../Images/426dad64478be2457fa243336f6691aa.png)Firefox 22默认阻止第三方的cookies(图片来源：Mozilla)

  
Firefox 22 Aurora默认阻止第三方的cookies，引起了广告界的关注。尽管Safari浏览器的这个功能已经有挺长的一段时间了，但其它主流的浏览器一直没有支持。在2月的时候，Mozilla首次宣布改变它们的第三方cookies跟踪政策。
