分析师:无“开始”按钮导致Win8低销量

原文：http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000272&itemidx=4&scene=27#wechat_redirect

微软针对触摸优化的全新Windows 8操作系统已发布有五个月之久了，不过无论你相信与否，至今依然有很多Windows 8用户无法忍受没有“开始”按钮，并因“开始屏幕”的用户体验而痛苦不堪。最近，市场研究公司 IDC 发布的一个新报告显示，今年前三个月的全球PC出货量同比下降了 13.9％，只有创低销量纪录的7630万台。


IDC解释称，不一样的 Windows 8 是导致产品销售不出去的重要因素，而“开始屏幕（Start Screen）”则是消费者和用户决定远离 新操作系统的关键原因之一。

IDC 分析师 O’Donnell 表示：“虽然一些消费者喜欢玩新鲜和带触摸功能的 Windows 8，但是用户而界面发生了重大的变化，熟悉的‘开始’按钮消失了，而且带触摸后高定价，让 PC 根本无法代替专门的平板电脑或其他更加具有竞争力的设备。”

更不幸的是，微软并不打算在新 Windows 中恢复“开始”按钮，并且“Windows Aero”界面甚至会消失得一干二净。因为微软已经表示，接下去所发布的新系统还会坚持“Metro 用户界面”和“开始屏幕”的基本路线不动摇。

目 前微软正在集中精力开发 Windows 8 首个重要的升级，Windows blue/8.1，通过不少泄露的系统截图表明，微软还会对用户界面进行 微调，比如在开始屏幕上添加更多的自定义选项，实现更多个性化功能。当然，已安装 Windows 8 的用户，也选择安装第三代软件恢复“开始”按钮。
