# HP发布Moonshot计划首次运行Linux系统

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000265&itemidx=4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000265&itemidx=4&scene=27#wechat_redirect)

| 纵观全球服务器市场，惠普是按营收计算的第二大厂商，仅次于IBM。然而这个市场正在发生剧变，Facebook和谷歌等公司正选择按自己的需求从低成本供应商那里定制服务器系统或是购买定制化设计，而不是从品牌厂商那里购买高端价格昂贵的服务器。如今惠普为了证明自己仍有开发先进技术的能力，惠特曼宣布推出Moonshot服务器，希望藉此证明惠普在技术领域的领先位置。“这将成为一场革命。”惠特曼在上月召开的年度股东大会上表示。“这并非渐进的创新，而是破坏性的创新。”Moonshot服务器产品线，基于英特尔Atom芯片，在未来也会有更多的芯片组计划。惠普承诺：将创建Moonshot超大规模软件定义服务器用于定制工作负载和生态环境。  
据惠普称，与大众市场服务器相比，这种最新服务器的价格要便宜77%，尺寸小80%，能耗少89%，每台Moonshot服务器可最多容纳1800个低能耗的英特尔芯片。惠普执行副总裁大卫·唐纳特利表示：“人们需要一种能以更加节能的方式来进行计算的方法。”这款服务器目标为云计算和软件定义服务器领域。惠普公司的企业集团总经理戴夫认为这是一款划时代的产品，当服务器行业10年后回顾其发展史时会发现Moonshot是一个极其重要的里程碑。据了解Project Moonshot的推出是惠普对于为超大规模环境设计的低功率服务器进行了近一年半时间的实验获得的结果。Project Moonshot是惠普在2011年11月首次推出的。这种服务器最初采用一种ARM服务器设计，后来扩展到采用英特尔低功率凌动处理器的高密度服务器。这种服务器的原型产品已提供给具体的用户进行测试。最终产品的推出已经推迟了多次。惠普希望减少新的服务器的耗电量和占地面积。惠普押注于Moonshot将吸引最大的社交媒体、云计算和电子商务网站，为这些网站提供支持的数据中心需要数量庞大的服务器。比如谷歌、 Facebook和亚马逊等公司已经建设了大型数据中心并且每天增加数千台服务器处理日益增多的网站和互联网请求。惠特曼认为这款全新的服务器产品能为传统数据中心带来革命性的变革。“Moonshot服务器能耗降低了89%,体积减少94%,而且成本也仅为原来的37%。Moonshot可以满足呈指数增长态势的云计算需求。只要有十家大型网络服务供应商将他们传统的服务器换代为Moonshot服务器，他们每年就能节省总价值1.2亿能源使用支出，并减少近100万公吨的二氧化碳排放量，相当于减少了18万汽车的尾气排放量。Moonshot可以说是革命性的创新产品。”不过与此前盛传服务器采用ARM芯片组不同，这款服务器使用的是英特尔Atom处理器，因此ARM和英特尔处理器很容易相互置换。惠普表示近期内不会立即发布基于ARM处理器的 Moonshot系统，但不排除未来发布此类架构服务器的可能。与此同时惠普还在扩展其芯片合作伙伴，如Applied Micro，Calxeda和德州仪器等。这款服务器对惠普公司意义重大，惠普寄望此款产品可以保证其在服务器领域的领先地位。惠普的这次赌博在于它发布的新的Moonshot系统是传统服务器开发周期的三倍。但对于惠普来说，Moonshot代表着企业的创新能力，同时证明自己仍然是一个服务器厂商的领导者，并保持与云客户的联系，渐渐的建立起自己的整套生态系统。惠普的CEO梅格·惠特曼(Meg Whitman)在网络直播开始时提到“brontobytes级的信息量”，并认为网络按照现在的发展是不可持续的。她说 “数据中心所需的空间，将有200个足球场那么大”，以满足未来的需求，电厂将会重建”。Moonshot计划也是在这样的情形下，经过多年的努力制造出来的，这套系统将削减在数据中心的空间和能耗。 惠特曼说“这是未来200亿网络硬件设备的基础”。总的来说，惠普正在搭建一个Moonshot服务器的“图书馆”和一个专为网络和设备对设备应用程序的架构。最初加入的客户包括Savvis公司，数据中心托管和云公司，Purdue大学。惠普的高官把Moonshot系统比作从Unix迁移到x86服务器上，并且创新的使用了刀片服务器。惠普的企业集团总经理戴夫·当纳特利(Dave Donatelli)说，其第一代Moonshot系统，已经有超过50个公测客户。第二阶段的Moonshot将创建一个软件定义的服务器。特利愤愤的说，当这个行业在回首过去的10年的时候，就会知道这次的Moonshot将是一次改变行业的事件。关键点：1、Moonshot服务器可以支持1,800台服务器。2、每个机箱部件共享冷却，电源和管理软件。3、Moonshot1500采用了英特尔的Atom S1200处理器。4、惠普正在跟ARM服务器供应商Calxeda合作，开发第一代ARM Moonshot服务器。Calxeda的发言人也表示，基于ARM的Moonshot服务器已经准备就绪。同时Calxeda也表示会根据HP的发布计划，在今年晚些的时候发布180个4核4U Moonshot服务器。5、起步价61875美元，45个HP Proliant Moonshot服务器和一个集成交换机。6、Moonshot系统首次运行Linux操作系统，但与Windows，VMware和传统企业应用程序兼容，因为它是基于X86基础的Atom。7、节能的数据是基于HP DL300服务器对比的。不过Moonshot服务器被市场所接受还需一段时间。惠普公司的上一款服务器产品Blade等待了很长时间才被市场广泛使用。此次，惠普公司希望到2015年Moonshot服务器可以占据15％的市场份额。根据惠普的说法，第一代Moonshot系统是当今美国专注于云计算的工作负载。该系统使用的是英特尔Atom处理器。更多的系统将会和众多合作伙伴合作，瞄准垂直分布市场从云计算到视频到分析，电信和游戏。一个全球一个全球的频道将会在下月推出。VIA
