# 明年今日Windows XP将被微软送上断头台

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000245&itemidx=1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000245&itemidx=1&scene=27#wechat_redirect)

明年的今天，就是Windows XP上断头台的日子。今天，距离微软结束对Windows XP的支持只剩364天了。**微软将从2014年4月8日起，停止为Windows XP用户提供热修复、产品更新及安全补丁等服务**。SP3是Windows XP最后一个服务包，其支持期限截止到2014年4月8日。

不过，2014年4月8日之后，你依然可以正常使用Windows XP，微软官方仅停止对其的支持服务。尽管如此，Windows XP支持的停止就是一个炸弹，届时，所有潜在的兼容问题和安全问题将让企业用户无处可躲。
