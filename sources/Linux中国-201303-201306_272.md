# Alienware X51原生内置Linux版Steam

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000232&itemidx=4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000232&itemidx=4&scene=27#wechat_redirect)

尽管在PC桌面平台上Windows系统依然独大，但是很多厂商在消费者选购旗下产品的时候会按照用户需求提供预安装Linux系统。**日前戴尔在其官方博 客中正式宣布旗下游戏PC Alienware X51中将预安装Ubuntu系统，玩家除了能够连接到Ubuntu的软件中心下载丰富的软件之外最大的亮点就是在系统自己中原生内置Valve最近基于 Linux的游戏平台Steam。**

目前这款基于Ubuntu系统的Alienware X51基本款售价为$599，当然如果你感觉这样的配置对于你来说性能还没有达标，那么你可以选择更高的配置进行DIY装配，比如采用Intel第三代Ivy Bridge Core i7处理器，显卡方面可以装备更高的N卡等等，最高能够达到$1049.
