# 美国缉毒局因无法破解iMessage加密表示很沮丧

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000232&itemidx=5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000232&itemidx=5&scene=27#wechat_redirect)

美国缉毒局（DEA）的官员因为无法破解苹果iMessage加密感到非常沮丧，因为这样就无法偷听犯罪嫌疑人。据CNET报道，在一份政府政府情报中，DEA表示想要破解iMessage是完全不可能的。这篇报告的题目为“iMessage：DEA监听的挑战”。

![](../Images/f65bc015ce192d69ef2c0b8474413691.png "dea-130404.jpg")  
DEA表示如果犯罪分子如果发送的短信，那么将会更容易被破解。苹果iOS平台安全性通常要比谷歌Android平台高很多，苹果也多次将安全性作为iPhone主要优势宣传。FBI的互联网犯罪投诉中心去年甚至向Android用户发布恶意软件警告。  
  
iMessage是苹果设备之间发送的加密信息，包括iPhone、iPad和Mac。iMessage在2011年发布，是iOS 5的主打功能之一。苹果公开宣传，所有发送和接受的iMessage都被加密过。苹果在今年1月宣布每天有超过5亿台iOS设备发送超过20亿条iMessage，其中还包括Mac电脑。现在iMessage允许用户在所有苹果设备上发送和接收安全信息。
