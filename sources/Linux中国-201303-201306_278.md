# 10个工具让你的 shell 脚本更强大

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000219&itemidx=1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000219&itemidx=1&scene=27#wechat_redirect)

### 10\. Bash Socket 编程 

你可以在bash中开启一个socket链接，并且传输数据。Bash有两个特殊的设备文件： 

*    /dev/tcp/host/port - 如果hostname，和port是合法的话，bash会尝试开启一个TCP连接。
    
*    /dev/udp/host/port - 如果hostname和port是合法的话，bash会开启一个UDP连接。
    

你可以利用这个技术来测试一台主机的端口是否是开启的，而不需要使用nmap或者port扫描器： 

![](../Images/05e7fc6646f467f40570b2ea80fef6a1.png)
