# Facebook Home程序推出：抢攻Android主屏幕

**Facebook今天将在加州Menlo Park召开新闻发布会，从今天的发布会来看，Facebook为Andorid手机提供新的体验，它是通过Facebook Home程序实现的。**Home的理念就是将内容优先展示给用户，它放在手机主屏上，用户再也不必点击程序才能查看。

  

Facebook CEO扎克伯格开始就说：“为什么要首先进入程序，然后才能看自己关心的人在干什么？”他认为将体验带到主屏更好，这样一来，大家就时时可以知道最新消息了。

Facebook Home启用后，来自Facebook动态消息（News Feed）的图片会覆盖到整个屏幕。扎克伯格称大家可以通过人而不是程序看见世界。拥有Home之后，大家可能就不再需要Facebook程序了。

在会上，扎克伯格强调Facebook没有推出手机，他说以Facebook为中心的设备可能会销售1000-2000万台。Home建立在现有的Android系统之上，可以将体验带给更多用户。

Home 只能用在Ice Cream Sandwich、Jelly Bean版本的Android系统上，也就是4.0及之后的版本，去年发布或者更新的手机都可以用。最开始程序只能用在Android机型上，包括 Galaxy S3和Note 2都能用。新推出的S4也可以用，还有HTC First也会装载Home。如果用户手机不是上述机型，但装备的是Ice Cream Sandwich或Jelly Bean系统怎么办？目前不清楚。

用户要获得Home很容易，从Google Play下载即可。手机上如果有Facebook程序，可以直接从程序内下载。每个月Home都会升级新功能。

“chat heads”是Home的主打功能，它可以让手机用户与朋友直接在主屏上通讯，不需要打开程序，可以同时与多人通讯。还有一个新功能叫“Cover Feed”。人们现在查看手机，一般首先会看到时钟、或者邮件摘要。如果安装Home服务并激活，情形会改变。只要打开手机，就能看到图片，可以从主屏一 则一则翻看。

Facebook高管称最终新服务会支持广告。Home服务不会进入苹果iPhone（iPhone玩家论坛）或者iPad设 备中。苹果iOS和Mac系统整合了Facebook功能，但扎克伯格说要让苹果iOS设备提供Home服务需要更密切的合作关系。这点可以理解，苹果的 系统是封闭的，Google Android则是开放的，任何人都能用，能修改，改变起来容易些。值得一提的是Facebook推出Home不是开发新版本Android，Home是 建立在Android之上的。我们不能说Home是操作系统，它只是一个程序，能改变Android主屏。

扎克伯格在发布会结束时畅想了未来，那是一个人们活在智能手机和平板中的世界，而不是台式机和笔记本。他说人们会看到今天看不到的电脑。

HTC针对Home推出HTC First手机，有红、淡蓝、白和黑四种颜色，手机于4月14日开售，定价99.99美元，从周四开始可以预订。虽然没有谈及补贴，但猜测可能要签订2年合约。

1点15分：Android是高度定制化的，你可以深度整合，修改很多体验。扎克伯格称：“今天，我们要谈谈新一类型的体验，手机主屏，它是手机体验的基石。”它有很多程序，叫Facebook Home。

1 点17分：Home是锁屏，手机的主屏上有来自Facebook的内容，这是自然的事情。所有的内容都是从后台加载的，你可以通过滑动查看内容，如果发现 一些东西比较喜欢，可以双击推荐（Like），用户可以从主屏点评。Facebook将锁屏和主屏称为“Cover Feed”，上面有一些提醒信息，它放在屏幕的上方。如果不感兴趣，滑动可以略过，如果感兴趣，可以点击互动并参与。
