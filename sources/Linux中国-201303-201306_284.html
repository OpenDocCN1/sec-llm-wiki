推旧陈新 Chrome将自主开发渲染引擎Blink

原文：http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000212&itemidx=2&scene=27#wechat_redirect


自从谷歌第一次发布自家的网页浏览器 Chrome 以来，其渲染引擎使用的便一直都是 WebKit 。今天谷歌宣称将停止使用 WebKit 作为 Chrome 浏览器的渲染引擎，但 WebKit 并不会马上被淘汰，而是作为全新渲染引擎“Blink”的后台技术。


在 Chromium 博客上，谷歌指出 WebKit 这些年一直都在为 Chrome 服务。不同于其他使用 Webkit 的浏览器，Chrome 使用的是是一种特殊的多进程结构，这就大大提高了系统的复杂性。谷歌认为这样的系统限制了 Chrome 团队的功能创新。

“我们做了一个艰难的决定。我们完全明白，引入一种全新的渲染引擎对整个互联网来说意味着什么。然而，我们认为，就像目前有多种浏览器一样，拥有多种渲染引擎将有助于创新。长远来看，这会对整个开放Web生态环境带来巨大好处。”

跟 Webkit 一样，Blink 的开发将采用公开源代码。网页开发这不用过分担心这次变革，谷歌称 Blink 的研发将集中简化代码，称“将移除7个构建系统并且删除超过7000个文件。”

今年二月，Opera 也宣称将会放弃自己的 Presto 渲染引擎，采用 Webkit 。在 Chromium 开发页面上，谷歌也指出 Opera 也将使用 Blink。
