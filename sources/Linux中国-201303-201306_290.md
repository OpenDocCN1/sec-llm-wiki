# 微友小调查的结果~谢谢大家

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000206&itemidx=2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000206&itemidx=2&scene=27#wechat_redirect)

今天早上给大家发了一个小调查，经过一天的回复收集，结果如下：

  

1、内容数量方面，大部分微友倾向于收到5篇文章，其次是4篇和6篇。

因此，每天会推送4-6篇文章。

  

2、内容长度方面，3/5的微友希望显示部分内容，2/5的希望显示全文。看来两种习惯的都不少。

因此，推送的文章太长则显示前面部分，否则显示全文（部分涉及到代码的文章在手机上显示效果不佳，也会只显示部分，并链接到原文）。

  

3、推送时间方面，选择早中晚的都基本相当，选择早上的略多。

因此，我们每天将在早上8点左右推送。

  

4、推送内容方面，技术、新闻、趣谈之类的都各有选择，基本上和我们目前的选材差不多。也有微友提到，可以做些系列专题、和资源下载推荐等，这些建议不错。

因此，我们会继续精选每日的文章，技术和非技术内容并重，并注意不发艰深的技术文章。

  

5、功能方面，希望添加：更强大的查询、查看历史消息、关键词检索和讨论组等功能。

目前除了讨论组，限于微信的API，暂时没有办法外；

历史消息我们会研究下如何实现；

查询和关键字检索，已经在现有微信平台上支持了，可能有的朋友还没用过？可以输入“help”查看下帮助，也有部分微友不是最新的4.5版本，因此看不到底部自定义菜单，可以升级看看？

当然，目前的查询功能确实也不够智能，这一点我们会继续改进算法。

  

  

最后，很多微友的回复，特别让我们感到感动，比如，有微友说，“**这里真心做的不错**”、 “ **这个公众帐号是我订阅中最好的一个**”、 “ **很喜欢linux中国!!!**”、 “ **加油啊我很喜欢这个**”等，溢美之辞，实在汗颜。

  

不过大家的鼓励，确实是我们做好这个微信公众平台和Linux中国的最大动力，这里，让我向大家说，“谢谢，谢谢你们的支持！”
