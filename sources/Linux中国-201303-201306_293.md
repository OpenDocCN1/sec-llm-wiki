# Firefox OS崛起或摧毁APP经济

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000198&itemidx=2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000198&itemidx=2&scene=27#wechat_redirect)

　　搜狐IT编译　　《福布斯》杂志刊文称，Mozilla推出Firefox OS向市场巨头Android和iOS双寡头开火，Firefox OS不必占据40-50%的市场，只要成为一个重要的第三替代平台即可.firefox OS可能会通过摧毁APP经济改变移动产业。

　　今年，声势浩大的巴塞罗那移动世界大会上弥漫着橙色味道，它是Firefox的标志色彩，Firefox是全球第二大浏览器。它的展位被人流淹没，宣传员跑来跑去忙个不停，因为Firefox带来了非常新的东西：免费、开源智能手机操作系统。

　　等下！我们还需要另一个智能手机操作系统吗？

　　三星和英特尔正在推动自己新的开源移动OS，名叫Tizen，在它的身后有许多残骸：Maemo、Limo、MeeGo，这些OS没有一个可以比肩Google Android和苹果iOS，两大巨头占了85%的市场。就连微软Windows Mobile也只能偏安3%的市场。

　　Firefox CEO Gary Kovacs是英勇无畏的，他说世界因为两个理由需要Firefox OS：一，它可以让运营商降低对Android和苹果的依赖，二者分别占30%的APP营收；二，它可以提供一种低成本方案让下一个20亿人进入互联网。

　　Firefox OS与传统操作系统iOS或者Android不同，它完全是用HTML5编写的，而HTML5是WEB的基本语言。程序从WEB上运行，深入手机硬件和数据，它还可以离线运行.firefox对内存的要求只有Android的一半，如此一来，运营商可以推出价格低于100美元的智能手机，相当于Android低端手机价的一半。

　　过去2年，Mozilla为Firefox OS投入了500名工程师.mozilla PC浏览器已经与Google达成交易，Kovacs可以将交易范围扩大到移动端，进而有可能收回成本。2011年Mozilla营收约1.63亿美元.kovacs正在与Google洽谈，但Google却不愿置评。

　　在巴塞罗那展会上，许多运营商捧场Firefox.telefonica及其它17家运营商计划销售Firefox手机，巴西、墨西哥、波兰都包括在其中。这些手机由LG电子、中兴通讯、华为和索尼制造.strategy Analytics预计Firefox OS到2013年底时将占全球智能手机销量的1%。

　　Telefonica开源网络服务主管Yotam Ben-Ami说：“Firefox可以让我们有机会用自己的服务竞争……绕过成本高的分销渠道。它没有必要占据40-50%的市场，它只需要让自己成为重要的第三替代平台即可。”

　　Mozilla说，大约有800万程序员知道如何用HTML5编程，而为iOS和Andorid编程的程序员只有几十万.telefonica指派几十名工程师与Mozilla合作，今年公司还分配几千万美元在拉美和欧洲营销产品。

　　Kovacs不能期待太高。通过摧毁APP经济，Firefox可能会改变移动产业，如同20多年前Netscape用开放网络冲垮AOL一样。成型的手机要到今年夏天才问世。如果手机难用，或者太慢，消费者可能会觉得多花点钱买其它手机更值得。
