# 国人的开源内核项目PKSM发布0.1版本！

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000189&itemidx=1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000189&itemidx=1&scene=27#wechat_redirect)

### 介绍

开源内核项目PKSM（Anon-Page Kernel Samepage Merging）针对KSM/UKSM的合并效率不高等不足，采用全新的处理机制和实现方式，非常高效的减少linux系统冗余内存，特别适合服务器和桌面系统应用。

项目主页：http://code.google.com/p/pksm/

作者微博：http://weibo.com/figo0406 

### 功能

### 1\. 对用户透明

> 自动添加所以用户进程的匿名内存块到PKSM中，不再需要从用户程序中返回内存给KSM。

### 2\. 高效的匿名内存页面检测

> 自动检测匿名内存块的创建和释放，使用新的算法和机制来直接控制内核创建/释放匿名的内存块。不再需要浪费CPU时间来遍历所有的VMA区域来查找可用的匿名内存块。KSM/UKSM浪费了很多CPU时间来遍历VMA来查找可用的匿名内存块，而PKSM则不需要。

### 3\. 全零页面判断Full Zero Page consideration

> 现在pksmd将全零内存块视作特殊的内存块，并将他们合并到一个特殊的不能交换的pksm zero page（从UKSM借用的）

### 4\. 周期性检查内存块的内容

> Pksm将经常变化的内存块放到FIFO列表中，周期性地检查其内存的校验值。默认每20分钟检查一次。

### 安装

如果可以自己编译内核，可以下载PKSM补丁并在内核编译时候打开它。

如果使用ArchLinux，你可以通过AUR来安装它： https://aur.archlinux.org/packages/linux-pksm/

### 使用

PKSM的相关控制参数和统计信息在以下目录中： /sys/kernel/mm/pksm

*   run 控制内核线程pksmd是否开启。缺省是开启的，如果你想关闭可以：echo 0 > run
    
*   pages\_shared 有多少个不同的物理页面处在被共享的状态
    
*   pages\_sharing 有多少个虚拟页面指向以上的共享页面，差不多可以等效看作你节省的内存。
    
*   page\_zero\_sharing 有多少个零页面被共享
    

*   您还可以通过/proc/meminfo信息查看到PKSM为您节省了多少物理内存。
    

> \[figo@figo ~\]$ cat /proc/meminfo
> 
> > KsmSharingPages: 45924 kB
