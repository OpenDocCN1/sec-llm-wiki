# BitNami.com：做开源服务器软件的应用商店

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000161&itemidx=1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000161&itemidx=1&scene=27#wechat_redirect)

软件蚕食世界，开源渗透软件。正如我们在开放一切的梦想中提到的那样，开放的力量正在逐步统治一切。开放力量的强大，得益于开源服务的完善，Github 为开源项目提供了托管空间，而 BitNami 则简化了开源服务器软件 / 框架的部署和安装，以往复杂的环境部署和安装过程只需几分钟就搞定。像通过开源变革了操作系统的 Linux，或者是变革了数据库市场的 MySQL 一样，这家公司在开源服务器软件部署安装方面的努力，将会改变企业应用市场的面貌。

日前，这家 Y Combinator 孵化的公司宣布，要将业务重心转移到打造类似 Google Play 或苹果应用商店那样的服务器软件应用商店上，为服务器软件客户提供消费者体验，这个想法的确强大。

对于许多优秀的开源软件的初学者来说，运行环境的部署配置是个问题。BitNami 正是这个问题的解决者。他可以将许多流行的开源软件及服务器环境打包成傻瓜式安装包，用户简单几步操作即可将软件部署到本地或远程服务器上。

BitNami 支持的开源软件与开发框架异常丰富，包括 Alfresco、Joomla!、Drupal、Redmine、Mediawiki、Wordpress、DokuWiki、Subversion、JasperServer、Trac、SugarCRM 等在内的 60 多种服务器软件，支持 WAMP、LAMP、MAMP、WAPP、LAPP、MAPP、Ruby、JRuby、Django、Tomcat、JBoss 等开发框架。

BitNami 实现快捷安装的关键是 BitNami Stack。后者是包括 web 应用及其所需一切组件（web 服务器、数据库、语言运行时）在内的集成软件包，具备开箱即用的能力。针对上述本地环境、虚拟环境以及云环境，BitNami Stack 可以提供传统的原生安装程序（Native Installers）、虚拟机镜像（Virtual Machine Image）以及云镜像（Cloud Image）。本地安装过程基本上都是自动化的，而虚拟镜像和云镜像则实现已进行预配置，里面还包含有一个 Linux 的最小化安装和一个 BitNami Stack。。而 BitNami Cloud Image 则支持以按需付费的方式运行 BitNami Stack。

BitNami 可支持的本地安装环境包括 Windows、Linux、Mac x86、Mac PPC 等；虚拟环境支持 VNware 最新版的 VirtualBox；云环境支持 Windows Azure 以及 Amazon EC2，以及 OpenStack、Cloudsstack 和 Eucalyptus 环境。

此前，BitNami 主要以 ISV（独立软件商）打包和专业服务的形式提供业务，但现在网站去年已经进行改版，令其感观上更接近于应用商店。此举虽然在实质上没有太多改进，但是却可以将依然强劲的桌面市场与 web 及移动市场连接了起来—若论起应用商店大的可能性，BitNami 显然充满潜力。

此外，BitNami 的这一举措还可以潜移默化企业客户的使用习惯。看吧，企业应用的部署安装也跟到商店挑选商品一样简单。

正因为如此，BitNami 的增长势头十分迅猛。去年的这个时候，其每月平均下载量是 10 万，而现在这个数字已经达到 100 万次。

当然，BitNami 还需要面对竞争对手的挑战。比如说应用商店平台 AppDirect。但是对于开发者用户来说这些都是好事，因为他们的努力，开发门槛将会得到进一步的降低。软件蚕食一切正稳步变成现实。
