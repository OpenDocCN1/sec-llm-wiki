# Mozilla 宣布开设 Firefox OS 应用工场

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000161&itemidx=3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000161&itemidx=3&scene=27#wechat_redirect)

　据外媒报道，Mozilla为了推进自家Firefox OS的发展，计划在接下来的几个月内开设3个应用软件工场。第一个工场将在下个月的20日在西班牙的马德里开设；第二个则将会在5月18日于哥伦比亚的波哥大开设；第三个则会在6月1日在波兰的华沙成立。

　目前，Mozilla正在寻求熟悉于HTML5和JavaScript开发的程序员。该家公司表示，他们将非常看重前来应聘的开发人员是否曾经有过 在 Chrome、WebOS或者BlackBerry上成功开发出网页软件的经历。另外，这些应聘者还必须要会西班牙语、波兰语或者葡萄牙语。

　　在工场成立之后，Mozilla会为在里面工作的人提供食物、饮料以及Firefox装饰品。而开发人员则将可以接触到Firefox OS Developer Preview(开发者预览版)手机。届时，开发人员将被要求为Firefox OS开发新软件或者Firefox版的现有软件。

　　据悉，Firefox OS设备将于今年夏天在全球18家通信运营商平台上发售。另外，包括LG、中兴、华为、索尼在内的多家手机制造商也将推出支持Firefox OS的手机。
