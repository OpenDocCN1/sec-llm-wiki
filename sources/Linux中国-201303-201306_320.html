Mark Shuttleworth 现身中国

原文：http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000161&itemidx=4&scene=27#wechat_redirect

　　2013年3月21日上午，著名 Linux 版本 Ubuntu 掌舵人 Mark Shuttleworth 现身中国，与中国工信部软件与集成电路促进中心 (CSIP) 及国防科技大学 (NUDT)，在北京宣布合作成立开源软件创新联合实验室，未来将开发为中国用户客制化的 Linux 版本 Ubuntu Kylin。

　　协议签约及揭牌仪式由中国开源软件推进联盟 (COPU) 主席、中国工信部软件与集成电路促进中心 (CSIP) 主任邱善勤博士、国防科技大学计算机学院院长廖湘科教授，Ubuntu 社区创建者 Mark Shuttleworth、中国开源软件推进联盟名誉主席及 Linuxpilot 专家顾问陆首群教授、中国开源软件推进联盟专家委员会副主任及 Linuxpilot 专家顾问倪光南院士等参加了签约仪式。

　　Mark Shuttleworth 是 COPU 智囊团高级顾问，也是 CCN 联合实验室的最初倡议者之一。Mark 介绍了 Canonical 公司牵头以社区方式开发的Ubuntu Linux 产品、开发中的支持一云多屏的云端一体化软体平台、基于最新云端作业系统开源架构的 OpenStack 解决方案、以及最新推出的手机和平板版本的 Ubuntu。联想、Dell、HP、Asus等主流 PC 厂商已经开始全面预装 Ubuntu，Google的工程师包括目前最流行的 Android 开发工程师，也都是在使用 Ubuntu。Canonical 是目前 Amazon Web Services 标准的 EC2 开源解决方案提供商，业界最有影响力的开源云架构 OpenStack 的开发，亦是在 Ubuntu 上进行的，HP 及 Dell 的云端运算方案都是采用 Openstack。

　　对于 Ubuntu Kylin，Mark表示 Ubuntu Kylin版本是针对中国个人电脑用户需求，并由来自工业和信息化部软件与集成电路促进中心和国防科技大学等中国科研单位以及社区的工程师们，合作推出的 Ubuntu 全新版本。业界广泛认为，中国这一动作是试图将其 IT 产业从西方软体业“断奶”之举，意在研发更多可替代外国作业系统的本土系统。“外国作业系统”自然是指Windows了，Ubuntu 此举可望同时为 Ubuntu 和中国都带来双嬴局面。
