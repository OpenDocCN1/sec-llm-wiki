# "Linux中国"的微信新功能：底部菜单出现啦

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000154&itemidx=1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000154&itemidx=1&scene=27#wechat_redirect)

在一周前公众微信平台就开放了自定义底部菜单的申请，我们第一时间提交了申请。

  

今天，这个功能偷偷的就开放了，我们第一时间将开发好的菜单功能上传，调试了一番，终于上线啦！

  

大家可以点击看看，目前只支持两个简单的功能：帮助和精选文章。接下来我们会根据微信所提供的API，继续开发新的功能上去。
