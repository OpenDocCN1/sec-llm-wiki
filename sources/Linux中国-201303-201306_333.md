# 谷歌应弃 Chrome OS 操作系统 10 大理由

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000136&itemidx=2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000136&itemidx=2&scene=27#wechat_redirect)

3月23日消息，据eWeek网站发表的一篇分析文章称，谷歌和Chrome OS操作系统都一起经历了有些动荡的生活。当谷歌发布这个操作系统的时候，Chrome OS是要成为改变谷歌业务、改变企业和教育者做工作的方式并且给Windows施加严重压力的产品。谷歌称，Chrome OS是每一个人都一直等待的基于云的产品。

但是，由于我们现在已经有时间实际使用Chrome OS并且看到运行这个软件的产品，这个操作系统根本没有兑现谷歌的承诺。

恰恰相反，Chrome OS暴露了它的真实状况：在软件领域没有一席之地的一直辅助的和不必要的操作系统。就像它的雄心勃勃想法一样，Chrome OS在谷歌和一次性潜在的客户中似乎是一种事后的想法。

因此，现在是谷歌撤销Chrome OS的时候。虽然谷歌不承认，但是，谷歌可能也有这种想法。谷歌最近宣布，Chrome部门负责人桑德尔·皮查伊(Sundar Pichai)将接管Android业务。此举并不是宣布撤销Chrome的一个途径。但是，这可能是第一步。我们希望如此。下面是谷歌应该取消 Chrome OS操作系统的10个理由。

**1\. 云还没有准备好**

现在没有任何迹象表明云计算已经为操作系统做好了准备。正如Chrome OS操作系统显示的那样，很难找到一个网站和离线功能的连接点。虽然这个操作系统受欢迎，但是，它的工作情况没有谷歌喜欢的那样好。Chrome OS有一些超前。

**2\. 开发者不关心**

开发者似乎确实不关心Chrome OS操作系统。他们确实在为Chrome浏览器制作一些应用程序，那是有帮助的。但是，没有人因为出售Chrome应用程序而发财。因此，几乎没有听说过有软件公司专门为谷歌的操作系统制作应用程序。这是一个大问题。

**3\. 重点在Android**

谷歌的皮查伊不应该在Chrome和Android方面浪费自己的时间。虽然谷歌是一家大公司，但是，它是一家谨慎的公司。谨慎的公司有受托的责任把自己的资源集中在最重要的项目上。现在，这个项目是Android，而不是Chrome。

**4\. 硬件产品水平低**

环顾Chromebook笔记本电脑市场，很难找到许多确实值得用户关注的产品。最新推 出的Chromebook Pixel笔记本电脑在设计上像个盒子。其显示屏有许多值得改进的地方。所有的型号都没有标准的LTE配置是很可笑的。其它厂商提供的产品更糟糕。硬件根 本就没有证明Chrome OS的价值。

**5\. 竞争太激烈永远不是一件好事**

环顾软件领域，Chrome OS操作系统有太多的竞争对手。苹果和微软都在提供能够做更多事情的软件平台，没有云的干扰。在硬件方面，有胜过Chromebook笔记本电脑的更好的、更薄的和更便宜的产品。对于Chrome OS来说，竞争太激烈了。

**6\. 类似产品已失败 Chrome OS也将如此**

把瘦客户机用作一个操作系统的替代产品的想法肯定不是新的想法。事实上，在过去的几十年来，这种想法已经进行了反复试验。然而，所有这些试验都失败了。谷歌将在什么时候认识到Chrome OS只是许多失败的产品线中的另一个产品？

**7\. 谷歌一直在努力 但是意义不大**

我们不要坐在这里说谷歌没有努力设法让Chrome OS腾飞。谷歌在过去的一年里一直在努力提高Chrome OS的市场知名度，同时改善其功能以吸引更多的用户。如果谷歌不是在努力这样做，很容易说它应该继续运行。但是，这些努力没有太大意义。

**8\. 企业和教育市场不关心Chrome OS**

Chrome OS成功的最佳机会是企业和教育市场。但是，有一个问题：这些市场似乎一点也不关心Chrome OS或者这个操作系统中的任何功能。谷歌在吸引企业用户应用Chrome OS方面做得很糟糕。因此，Chrome OS现在处于随波逐流的状态。

**9\. Linux社区无动于衷**

Chrome OS在推出时的吸引力是它是一个开源软件并且会吸引Linux用户。麻烦的是Linux用户没有利用许多时间设法改善这个操作系统。事实 上，Android和其它Linux发布版好像是Linux用户关注的焦点。如果谷歌不想撤销Chrome OS，最好希望Linux和开源软件社区开始更多地关注它。

**10\. Windows仍然是一个非常需要的产品**

Windows仍然是当前操作系统市场中的一个非常必要的产品。事实上，消费者和企业用 户、政府工作人员和教育工作者都依赖Windows软件。谷歌设法通过与Windows竞争获得更多的市场份额。现在，Chrome OS无路可走，除非谷歌采取宽容的举措和撤销这个操作系统。
