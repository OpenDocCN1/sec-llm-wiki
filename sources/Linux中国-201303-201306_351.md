# 英国政府规定首选开源技术

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000109&itemidx=2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000109&itemidx=2&scene=27#wechat_redirect)

　　采用开源技术已经是全球的趋势，英国政府最近就首次在政府服务设计手册(Government Service Design Manual)中，明文规定在架设一些提供公共服务的系统时，应该首先考虑开源软体。  

　　事实上早在2012年11月，英国政府内部就已经就采用开源技术发出了Open Standards Principles的指引，但这次却更进一步，将采用开源技术常规化。这次在政府服务设计手册中的When to use open source中，就明文指出政府必须在作业系统、网路软体、网页伺服器、资料库和程式语言方面，逐步以开源技术技术取代专属或闭源的技术。美国政府首席技 术长Liam Maxwell表示，这是为了避免被少数提供关键技术的厂商“骑劫”。

　　众所周知全球桌面作业系统的95%以上都是Windows、办公室软体基本上都是Microsoft Office的垄断局面，资料库的话大部分公司都选择Oracle。全世界电脑技术的命脉正被单一国家的少数企业所掌握，英国政府此举的目的是希望重新取 得技术的主导权。开源技术让任何人都可以取得任何关键技术的资讯，有效拉近国家之间的技术差距。
