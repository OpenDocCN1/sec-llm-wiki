Unity Tweak Tool 已经进入 Ubuntu 软件中心

原文：http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000104&itemidx=1&scene=27#wechat_redirect

在默认情况下，Ubuntu 有一些桌面设置默认值可能不太适合于自己，所以用户千方百计的想把桌面按照自己的喜好来进行设置，对于一般用户来说设置 Ubuntu 桌面感觉很吃力，所以有些桌面调整工具出现了。

其中 Unity Tweak Tool 就是其中的一款，这是一款功能强大的调整工具，它有一个友好、直观用户界面。Unity Tweak 已经发布了一个稳定的、可用的版本 0.0.3，现在已经登陆Ubuntu 13.04 软件中心。

启动应用程序，你会看到一些可配置选项的图标。
