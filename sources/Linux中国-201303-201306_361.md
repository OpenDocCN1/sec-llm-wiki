# 界面清新范儿 Ubuntu应用界面曝光

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000088&itemidx=1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000088&itemidx=1&scene=27#wechat_redirect)

　　在Ubuntu开发者社区放出这款最新触屏操作系统的SDK之后，在不知不觉中Ubuntu这个全新移动平台也正在诞生出自己的果实.canonical公司的Michael Hall在自己的私人博客放出了正在开发中的几款Ubuntu核心应用截图，包括了日历、天气等常规应用，也体现出了Ubuntu的个性化一面。

　　在Michael Hall的博客中，除了天气日历这类应用界面之外，还放出了几款看起来很有意思的小游戏、新闻阅读器、甚至还有一个有些匪夷所思的人头。这其实是Ubuntu开发者社区经理Jono Bacon，当你戳他的时候他就会开口说话。从目前的截图来看，Ubuntu整体给人的感觉都非常小清新，简约又带点现代感，希望在不断地修补与完善中，Ubuntu能为我们带来更多惊喜。
