我们的微信支持搜索了，请大家试试吧

原文：http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000069&itemidx=1&scene=27#wechat_redirect

开通微信几天了，今天完成了一个小功能，大家可以和我们的微信命令交互了。目前只支持查看最近精选文章、搜索精选文章。下一步我们还会逐步开发更丰富的交换功能。也欢迎大家提出你想要的功能给我们。


目前支持的命令如下：


更多 或 more

 -> 可以显示最近的精选文章（新闻、技术、访谈）

 -> 也可以直接输入“新闻、技术、访谈”来显示分类精选


帮助 或 help 或 ?

 -> 显示这个帮助信息


其它内容

 -> 搜索“Linux中国（http://linux.cn）”的精选内容
