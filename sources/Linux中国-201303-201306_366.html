谷歌启动“春季大扫除”：关闭Google Reader

原文：http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000069&itemidx=2&scene=27#wechat_redirect

　　北京时间3月14日上午消息，谷歌今天在官方博客发表题为《又一次春季大扫除》(A second spring of cleaning)的文章，宣布关闭包括Google Reader在内的多款服务。

　　该公司在文章中称：“我们2005年推出Google Reader，方便人们发现内容，并随时查看最喜爱的网站。尽管这款服务拥趸众多，但过去几年间，它的使用量已经下滑了。

　　因此，我们将于2013年7月1日关闭该服务。在接下来四个月里，对其他RSS服务感兴趣的用户和开发者可以使用Google Takeout导出订阅等数据。”

　　除Google Reader外，谷歌还将关闭Google Building Maker等其他多款服务，但它们的影响力均不能与Google Reader相提并论。

　　谷歌官方博客文章全文如下：

　　第二次春季大扫除

　　我们生活在一个全新的计算环境中，人手一台设备，有的甚至人手好几台。我们已经很久没有经历过这么快的变革了——很可能从个人计算40年前诞生 后，就再也没有过这种情况。要尽可能地把握其中的机会，就必须专注——否则，便会摊得太薄，从而失去影响力。所以，我们今天宣布再关闭一些业务，在此之 后，我们自2011年春季大扫除以来关闭的功能和服务总数已经达到70款：

　　——Apps Script将取消GUI Builder和5款UiApp widget，从而专心发展Html Service。其他的UI Service不会受到影响。在2013年9月16日前，GUI Builder将可继续使用。更多消息请参见我们在Google Apps Developer博客中发布的文章。

　　——CalDAV API将对列入白名单的开发者开放，但却会在2013年9月16日对其他开发者关闭。多数开发者的使用案例将由Google Calendar API妥善处理，我们推荐使用这个API。如果你是开发者，且Calendar API对你不起作用，请填写这张表格(https://docs.google.com/a/google.com/forms/d /19gOLSlkTzHi-zub3BkMv7Ot0JMLPj4YSxJUBseGAMSg/viewform)，告知我们你的使用案例，并索取只对 白名单开发者开放的CalDAV API。

　　——Google Building Maker帮助人们为谷歌地球和地图制作3D建筑模型。它将于6月1日退休，但用户仍然可以从3D Warehouse中访问和导出他们的模型。我们仍将扩大谷歌地球复杂而精确的新3D图像的可用度，人们仍然可以使用Google Map Maker向谷歌地图中增加轮廓和高度等建筑物信息。

　　——Google Cloud Connect是一款为云端工作提供便利的插件，可以自动将微软Office文档从Windows PC存储到Google Drive中。但在你的桌面上安装Google Drive却能以更高效的方式实现同样的目的——而且Drive不仅兼容Windows，还兼容Mac、Android、iOS设备。现有用户从4月30 日以后将无法再使用Cloud Connect。

　　——我们2005年推出了Google Reader，为的是方便人们挖掘和收藏自己喜欢的网站。虽然这款产品拥有一批拥趸，但近年来的使用量却在下滑。所以，从2013年7月1日 起，Google Reader将会退休。对其他RSS服务感兴趣的用户和开发者，可以在未来几个月用Google Takeout导出订阅列表等数据。

　　——从下周起，我们将停止支持黑莓版Google Voice应用。对于希望继续使用Google Voice的黑莓用户，我们推荐使用我们的HTML5应用，这款产品更安全，也更方便升级。我们的HTML5网站可以兼容黑莓6及更高版本。

　　——我们将放弃Search API for Shopping，这款产品可以方便开发者利用谷歌产品搜索数据开发购物应用。虽然我们认可这款车产品所提供的价值，但我们仍将集中精力通过Google Shopping提供更好的购物体验。我们将在2013年9月16日彻底关闭该API。

　　——从今天开始，我们将不再出售或提供Macintosh和Windows版Snapseed Desktop的更新。现有用户将可以继续下载这款软件，并与我们就支持问题取得联系。我们将继续免费提供iOS和Android版的Snapseed移动应用。

　　这些改变十分艰难，但通过集中精力，我们可以全神贯注地开发真正有助于改善生活的伟大产品。
