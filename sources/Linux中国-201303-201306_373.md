# 创始人为Ubuntu定位：Ubuntu应属于大众用户

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000055&itemidx=2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000055&itemidx=2&scene=27#wechat_redirect)

在过去的几个月中Ubuntu的稳定而快速地发展着，Ubuntu已经从一个深受大众喜爱的Linux发行版，演变至目前可以与苹果iOS和谷歌安卓一决高下的操作系统。但是并非所有的人都为此而感到高兴的，比如Ubuntu的创始人Mark Shuttleworth。**Mark Shuttleworth是对Ubuntu项目的影响最大的人，最近他通过博客表示，Ubuntu定位应该是大众用户，而非那些Linux的精英。Ubuntu需要将自身打造成为一个更加平民化的操作系统。**

Mark 解释说，Ubuntu的性质和演变以及广泛的用户决定了Ubuntu需将自身打造成为一个更加平民化的操作系统，以吸引更多的用户。他同时表示他不愿意为了一小群精英用户的需求而妥协。
