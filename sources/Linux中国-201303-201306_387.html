以 Raspberry Pi 为核心的物联网无线打印

原文：http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000025&itemidx=2&scene=27#wechat_redirect

Adafruit 这间公司的 DIY 创意真是无底限，他们这次推出新款的物联网（Internet of Things 简称 IoT）打印机，因为加上了 Wi-Fi 连接的功能，所以这个镭射切割的外壳其正面也改为了一颗可爱的云朵标示，背后也由两条线省略了前代所必需的网络线变成只剩下一条线的简约构造；更令人感到期待的，是他们将原本的 Arduino 核心，改为现在正在疯狂流行的 Raspberry Pi Model B，运行的是使用 Python 程序语言的 Raspbian Linux 系统，并且采用了 Python Imaging Library（PIL）这套影像程序库，提供处理印刷与图片的使用弹性。

基本而言，Adafruit 是建议使用者应该要具备 Linux 相关的程序设计知识，才能让你在 2.25 吋的收据纸上发挥各种天马行空的应用，但它们还是内建了几个基本的 Apps 在其中，像是印出每日天气的报告、数独游戏以及原本就有的印刷 Twitter 推文的功能等。这次这部加上 Wi-Fi 的物联网打印机，价位上相较于前代要价 US$100 的以太网络版本要贵了一些来到 US$189（约人民币 1,180 元）的价位，但随着购买数量达到 10 个以上价位还会有所调整 -- 不过尽管价位已经公布，但截至目前为止还未正式开卖。
