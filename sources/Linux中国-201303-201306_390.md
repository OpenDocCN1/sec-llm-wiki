# Raspberry Pi 庆祝一周岁生日

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000011&itemidx=1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000011&itemidx=1&scene=27#wechat_redirect)

前天，Raspberry Pi单片机迎来了一周年诞辰，这款售价22英镑的单片机是于2012年2月29日正式发布的，按照传统来看，今年并非闰年，所以只好在28日庆祝生日。在这一年中Raspberry Pi设备在全球范围内获得了相当不错的销售成绩。

这款微型Linux设备，在诸多领域都有相关应用，例如作为学校学生编程与技术方面的教材实例，也在这些领域取得了很好的成绩。Raspberry Pi出世第一天，基金会就选择了两家英国企业作为出售此设备的零售商，随后各路极客和热爱DIY、技术的用户在网上订购等待数周才拿到这款产品，一度出现 供不应求的局面。

Raspberry Pi基金会仍然坚持将主要目标集中在教育事业上，而没有着力面向企业市场将大部分产品卖给企业客户。基金会还积极与不同的组织联系，促成 Raspberry Pi推往学校，并且还在如英国教育技术展之类的盛会上展示。2013年1月份，谷歌又宣布购买15000款Raspberry Pi单片机设备，并且赠予英国学校，甚至有不少幸运的学生得到基金会创始人Eben Upton和谷歌执行总裁埃里克施密特的亲自授课。

Upton还因此入选MIT 35 Innovators，这是麻省理工学院评出的35岁以下年轻发明者奖。另一方面Raspberry Pi的发布还带动了英国的制造行业，将计算机的组装工作从远东带回到威尔士的制造工厂。
