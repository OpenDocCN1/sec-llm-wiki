# Mozilla宣布18家运营商承诺支持Firefox OS

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000008&itemidx=1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000008&itemidx=1&scene=27#wechat_redirect)

　　Mozilla宣布， 在巴塞罗那举行的2013移动世界大会上，18家移动运营商承诺支持Firefox OS。

　　这些运营商包括了中国联通，其它主要是南美和欧洲的运营商，如德国电信和西班牙电信。首批Firefox OS手机将由TCL（阿尔卡特）、华为、中兴和LG制造，全都采用高通的Snapdragon芯片组。Firefox OS是基于标准Web技术，允许HTML5应用直接在设备上运行，Mozilla相信Web技术可以帮助它追赶上Android和iOS，Mozilla 产品高级副总裁Jay Sullivan说，开发者很忙，没有时间学习新的编程语言，他们认为仅存的生态系统是Web，而Web开发者的数量远远多于其它平台。

　　Firefox OS手机将主要针对亚洲、拉美和东欧的新兴市场，这些市场仍然有许多人没有购买智能手机。
