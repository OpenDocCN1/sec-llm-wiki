# Kernel.org 即将改版

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000005&itemidx=2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000005&itemidx=2&scene=27#wechat_redirect)

　　Konstantin Ryabitsev（Linux基金会系统管理员，精通中文，俄罗斯籍）在今年 1 月份的时候寻求 Fedora Project 设计组的帮助，希望重新设计一个新的网站页面。按照他的话来讲，就是 kernel.org 目前的主页还是 1995 年的水平。

　　于是大家设计了几套方案，最终选定的方案目前已经上线进入测试，大家可以访问：https://x-www.kernel.org/ 来查看。网站由 Pelican 生成。截图见下：
