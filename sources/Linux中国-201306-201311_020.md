# Ubuntu创始人Mark获“老大哥奖”

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001435&itemidx=2&sign=1b5201de0b6bdf174add81d9659625d9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001435&itemidx=2&sign=1b5201de0b6bdf174add81d9659625d9&scene=27#wechat_redirect)

奥地利的老大哥奖（Big Brother Award）今年花落Canonical/Ubuntu创始人Mark Shuttleworth。也许你之前并没听说过它，这或许是因为它并非是什么光荣的奖项，老大哥奖主要是颁发给威胁个人隐私的政府和私人机构。

Ubuntu的Dash新增了一个功能，会将美国和英国用户的所有搜索请求发送到Canonical的服务器上，这引起了极大的隐私争议，自由软件基金会、电子前沿基金会等诸多机构都对Ubuntu进行了谴责。此次，Shuttleworth获得老大哥奖也与此有关。

![](../Images/755e68ef68c218d2d5d780e3bae35d98.png)Mark Shuttleworth，Ubuntu创始人。出生于1973年9月18日，是一名南非的企业家。2002年，他成为世界上第二名自资的太空游客，也是 首位进入太空的非洲人。马克目前居住于伦敦，并持有南非和英国双国籍。上世纪90年代的时候，马克已经是Debian早期开发者之一。

2001年，他成立了Shuttleworth 基金会，是一个致力社会创意的发展，同时资助南非的教育类开源软件项目。

2004年，他重返GNU/Linux世界，通过他的Canonical有限公司资助Ubuntu Linux的开发。

2005年，他成立了Ubuntu基金会，提供了一千万美元的启动资金，作为维持Ubuntu运作的应急储备。

2006年，他成为KDE的当前最高级赞助商。
