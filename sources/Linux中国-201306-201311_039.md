# 为什么苹果向用户免费提供OS X Mavericks

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001406&itemidx=4&sign=40e5798398a61c1b50388c4ea02204ad&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001406&itemidx=4&sign=40e5798398a61c1b50388c4ea02204ad&scene=27#wechat_redirect)

苹果新操作系统 OS X Mavericks相比以前版本的一个最大不同是它的价格——免费。

当然免费不是什么大不了，Windows 8.1对Windows 8用户是免费的，而Linux桌面系统多数从未收过费。而苹果历史上一直对升级版本收费。

在智能手机免费升级的时代，付费升级操作系统似乎也将成为过去。传统PC销售日益衰落，而苹果是一家靠出售硬件和在线服务获利的公司。苹果通过免费提供系统升级，鼓励用户更多去购买它的在线服务如 iCloud、iTunes Match和App Store应用，同时也鼓励用户投资购买新的苹果硬件——他们的系统将能在以后免费获得升级。

IDC的分析师Al Gillen认为，苹果此举或将开启操作系统定价的新范式。微软将会开始体会苹果新行动的压力，未来PC系统的升级费用也许也将会趋向于零。
