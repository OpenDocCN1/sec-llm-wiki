# Ubuntu创始人称将重点转往新兴市场

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001394&itemidx=2&sign=e3ff61c339e409bd9fc73e8c0524632b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001394&itemidx=2&sign=e3ff61c339e409bd9fc73e8c0524632b&scene=27#wechat_redirect)

2013年GMIC(全球移动互联网大会)硅谷站今日在美国旧金山开幕。开源操作系统Ubuntu的创始人Mark Shuttleworth表示，公司不久后会在韩国发布最新的系统版本，因为Ubuntu正在将市场的重点转往新兴市场。

Ubuntu(乌班图)是一个以桌面应用为主的Linux操作系统，并且已经推出适合手机和平板的移动版本Ubuntu Touch。Ubuntu的开发机构总部位于英国，而创始人Mark Shuttleworth是一位来自南非的企业家。
