# 南非教育部门禁止使用开源自由软件

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001323&itemidx=4&sign=73ccdca2826c3961ed8f3a2ea54011a6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001323&itemidx=4&sign=73ccdca2826c3961ed8f3a2ea54011a6&scene=27#wechat_redirect)

南非教育部门事实上禁止公立学校使用自由开源软件。

基础教育部发出的通知（PDF）强制要求参与计算机应用技术考试的考生使用微软的Office 2010或2013软件。如果微软发布新版的Office办公软件，那么旧版本将会逐步淘汰。

通知还要求所有学校的IT课程学习Delphi语言。Delphi语言以前一度流行过，但今天已经不是一个广泛使用的通用语言。

南非教育经费本已不足，新的政策被批评违反竞争，增加学生父母负担，将学生锁定在单一企业的产品上。
