# Mozilla研发Flash Player替代品：Shumway

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001323&itemidx=2&sign=22ce7602b71a666e821aa51de2e81f4f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001323&itemidx=2&sign=22ce7602b71a666e821aa51de2e81f4f&scene=27#wechat_redirect)

据国外媒体报道，丹麦程序员Henrik Gemal在自己的博客上宣布，Shumway已正式进入Mozilla代码库。这意味着现在Mozilla的用户无需另外安装Flash播放器，就能直接观看SWF文件了。

Shumway是由社区开发但得到Mozilla官方支持的一个开源项目，基于HTML5技术，能渲染SWFT格式文件，用JavaScript编写Flash虚拟机和运行库。

报道指出，Shumway与PDF.js项目一起，使用户能够在浏览器和沙箱里观看Flash和PDF文件，将大大提高安全性。
