# Nvidia降级Linux驱动特性以平衡Windows

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001296&itemidx=2&sign=35df076de24b1d5c4936640561767744&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001296&itemidx=2&sign=35df076de24b1d5c4936640561767744&scene=27#wechat_redirect)

Nvidia的Linux驱动拥有Windows驱动所没有的特性，但Nvidia可能认为Linux市场狭小维护成本高，所以为平衡起见移除了特性。

根据Nvidia Developer Zone论坛上的讨论帖，旧版本的Nvidia驱动支持4个显示屏，但一位Ubuntu 12.04 用户将驱动版本从v295升级到 v310后发现，只有三个显示屏点亮。新版驱动修改了同时支持的显示屏数量。

一位Nvidia员工回答称，这是为了让Windows和Linux驱动的特性能相同（原话是“feature parity”）。
