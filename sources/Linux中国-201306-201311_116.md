# 为什么我决定更多的在家办公

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001279&itemidx=3&sign=bdbd15482338dae6c5698ede1479f6ab&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001279&itemidx=3&sign=bdbd15482338dae6c5698ede1479f6ab&scene=27#wechat_redirect)

在Parse.ly公司，我们骄傲于有一个分布式的开发团队。我们的CTO，Andrew，还写了一篇精彩的文章阐述为什么完全的分布式团队是可行的。我们三分之二的团队分步在美国，加拿大，欧洲等地。但我们在纽约也有一个“总部”，这是我们的业务团队平时工作的地方。

这一切起始于纽约遭受“桑迪”飓风袭击。外部城镇跟我们位于曼哈顿的办公室联系中断，地铁全部停运。这意味着整整一周所有在纽约的员工都不得不在家工作。这篇文章不是要谈这对Parse.ly开发团队的影响，而主要是说从在办公室工作变成在家办公后，我的体验和感受。

![](../Images/f4686733ac6d3a0060540b79d5aafcd0.png)

当安德鲁和我最初创立这家公司时，有超过一年时间，我们都是在家或在咖啡店工作。我们租不起一个办公室，没办法，需要聚的时候，就在城市里的某个地方碰头，其它时间就在家里。回想起来，这是不可思议，在那样不能再糟糕的工作环境下，我们竟做出了那多么成绩。我们都没有住大的公寓，都是和别人合租着住。当我们需要碰头时，找到一个有WiFi能工作的地方真是很难。很多的会议本想着是一次高效的讨论，结果却因为没有WiFi变成无效率的头脑风暴。2009年那个时候并没有很多和其它创业公司合作的机会，也难找到创业空间或遇到想法相似的人。说这些就是想证明，虽然办公环境很重要，但不是必须的。Parse.ly是在最糟糕的情况下成立的，而现在的成就却是让我再自豪不过了。

对于是否应该在家办公，两方面都有很明显的理由。飓风过后，我总结了很多有利和不利的因素。然而，最大的一个认识是，在家办公需要有很好的自制力。

最简单的让自己在家保持工作纪律的方法是养成日常习惯。Toms Baugis，一位住在柏林的 Parse.ly 的工程师，在一篇发布在LifeHacker上的文章里说，日常习惯能提高一个保持高效工作的能力。我发现他正说到问题的关键处。

飓风时在家办公的那一周的前几天，我几乎就像是在过懒洋洋的周末。当有一个闲暇的周末时，我通常会懒散，做事慢悠悠。而那几天我发现自己在家只能完成一些琐碎的工作，完成不了太多的任务。我很快总结出，这是因为**工作需要形式**，我不在正确的状态中。我还处在懒散的周末模式中，没有进入到平时上班时工作模式中。我迅速的做了一些小的调整，帮助我进入正确的节奏。开始工作前先冲个澡，然后出去喝杯咖啡，顺便写下早上要完成的三件事。这帮我进入准备工作的状态，设定目前需要完成的工作目标。

就我从很多在家办公的人那里听到的，他们的一个最大的抱怨是家里有太多很容易让你分心的事。电视，装满食物的冰箱，舒适的床，电玩，没有直接的工作压力(来自同事和老板)，等等。分心的事招摇在屋子的每个角落，等待着你去上钩。如果你控制不住自己，它们必定是胜者。回想早先创立 Parse.ly 的日子，我记得那时**我把这些分心的事当成一种好事**。它们变成了我使用Pomodoro时间管理方法的工具。我使用各种的Pomodoro时间管理工具，来让我达到最大的工作效率。Pomodoro时间管理方法是指把大的任务分割成小块。以前在家工作时我一直在使用这种方法，但后来有了办公室后我发现不再需要它了。现在又回到家中，我才发现为什么上班时不需要，因为不断的有事情打搅你。Pomodoro时间管理方法能帮助你利用这些打搅，让你拥抱它们。你可以工作30分钟，然后用5分钟吃一个三明治。或工作一小时，然后打十五分钟的电脑游戏。总的来说，工作和玩乐全在同一个地方——太神奇了。

因为工作需要有一种形式，你的身体和大脑会学会认为这种形式是“在工作”。如果你限制自己去探索不同的工作环境，这可能会影响到你对问题的思考方式。在家中，你完全掌握你的地盘，你可以随意改变你的环境，同时也改变了大脑的工作方式。工作在办公桌上、沙发上、户外、咖啡馆，工作地点的选择会强烈的影响到你对手头工作的处理。我发现，越刻板的工作环境(例如做在办公桌前、办公椅上)，我也倾向于做一些具体实际的工作，而对琢磨一些需要探索的问题，我会选择在户外或在沙发上。

最后，差点忘了，在家工作意味着有更多的时间。我每天差不多花掉1.5小时在上下班的路上。在家工作就节省了1.5小时，这1.5小时能做很多事情，比如工作，锻炼身体，休闲娱乐等。

在家工作是事出有因。我承认无法做到像在办公室工作那样专注。然而，经过了数天的适应后发现，在家工作不仅是可行的，而还有很多好处。我做了一个计划，决定以后每周都必须在家工作一到两天。因为几乎每天都有会议，我不能拿出更多的时间。今后一两个月，我会不断的把更多的体验心得写出来。

欢迎大家谈谈你们自己的在家工作的技巧和想法。
