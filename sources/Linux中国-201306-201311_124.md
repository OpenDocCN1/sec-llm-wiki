# 我们正见证Ubuntu的衰落？！

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001272&itemidx=1&sign=d4fc6d439535e3f23c2bd1580e2417c8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001272&itemidx=1&sign=d4fc6d439535e3f23c2bd1580e2417c8&scene=27#wechat_redirect)

Datamation的一篇评论认为，我们正见证Ubuntu的衰落，去年是Ubuntu衰落的开始。作者给出的证据包括：Google趋势， Ubuntu和Canonical孤立于自由软件社区之外，缺乏有效规划。

去年与Ubuntu的第一年形成了鲜明对比。在2005-2007年，Ubuntu被认为是Linux桌面的最大希望，批评的声音很少，而Ubuntu也确实提高了桌面的可用性。

然而渐渐地，Ubuntu 和Canonical 开始孤立于自由软件社区的主流之外，因为对GNOME开发进度缺乏耐心，Canonical开发了自己的桌面Unity，Unity随后成为Ubuntu的核心，但其它主要发行版没有一个采用Unity。同样的情况一再发生，Upstart替代Init，Mir替代Wayland。Upstart和Mir都受控于Canonical，而Canonical也从一位受欢迎的成员变成了自由软件精神的破坏者。
