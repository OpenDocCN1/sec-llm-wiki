# 失望：Ubuntu 13.10不会整合GNOME 3.10

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001265&itemidx=1&sign=01982d4ec6f6673243d35df8d6a7690b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001265&itemidx=1&sign=01982d4ec6f6673243d35df8d6a7690b&scene=27#wechat_redirect)

Ubuntu 13.10发布第二个也是最后一个Beta测试版的同时，Ubuntu GNOME 13.10也进入了最后的测试阶段，但令人失望的是，它整合的还是GNOME 3.8，最终正式版也基本确定同样如此。

Ubuntu GNOME是一个主打GNOME桌面环境的分支系统，但**如果你带给大家的是一个已有六个月之久的老版本，还有什么意义呢？**

**Ubuntu 13.10的最终版定于10月17日发布，GNOME 3.10则已经从9月23日起分发给开发者。这就是说，Ubuntu有将近一个月的时间去整合新版本，完全来得及，但看上去他们并不打算这么做。**

也许可以归咎于时间紧迫，来不及做全面整合、测试，但的确会打击不少喜欢Ubuntu系统和GNOME桌面的用户。

就算冲着这么和谐的版本号也得加进去嘛。
