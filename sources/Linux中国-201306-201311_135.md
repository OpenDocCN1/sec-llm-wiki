# GNOME 3.10发布（多图）

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001251&itemidx=3&sign=bd3e3dd233872d806ffd464a90dbc8de&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001251&itemidx=3&sign=bd3e3dd233872d806ffd464a90dbc8de&scene=27#wechat_redirect)

开源桌面环境GNOME项目发布了GNOME 3.10（ISO镜像）。主要的新特性包括：初步支持Wayland显示服务器，Wayland设计取代X，被认为能带来更强的图形性能，其现代框架能为开发者提供更大的弹性。

提供了更安全的沙盒应用程序；重新设计的系统状态区；引入了标头列，将标题列与工具列整合为单一元素，给予内容更大的展示空间；软件搜索和安装工具 Software；新的地理位置架构，利用多种地理位置来源判断方位；支付高分辨率显示屏；Photos应用整合Flickr；以及大量新的应用程序，如基于OpenStreetMap的地图应用，支持ownCloud的笔记应用，Tweak Tool，默认搜索引擎DuckDuckGo的浏览器，支持 DjVu格式的Document Viewer，等等。下一个版本GNOME 3.12计划在2014年3月发布。![](../Images/75d8f1b3d0b383d688e1c9798009ed2f.png "header-bars.png")
