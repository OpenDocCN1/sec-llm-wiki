# Ubuntu 13.10将匿名化Dash用户搜索数据

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001235&itemidx=1&sign=22138ae5bf82f29cb739dd3d7f9670b1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001235&itemidx=1&sign=22138ae5bf82f29cb739dd3d7f9670b1&scene=27#wechat_redirect)

Ubuntu 12.10的Dash搜索功能引入了来自亚马逊的搜索结果，引发了用户隐私泄露的质疑。自由软件基金会主席RMS(Richard Stallman)也为此提出了批评。

现在，Canonical表示Ubuntu 13.10 Saucy Salamander将匿名化用户搜索数据。简而言之，数据会继续收集，但不收集用户身份信息。第三方服务如亚马逊将不会知道用户的详细信息。
