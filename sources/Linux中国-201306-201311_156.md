# 三星和Google荣登Linux内核代码捐献排行榜

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001208&itemidx=2&sign=a7cbcb0e61b9c052f415ec7b28370001&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001208&itemidx=2&sign=a7cbcb0e61b9c052f415ec7b28370001&scene=27#wechat_redirect)

近日由Linux基金会发布的Linux内核发展报告中指出三星和Google分别以第七名和第八名的排名出现在全球贡献最频繁企业排行榜中，仅次于红帽、英特尔、德州仪器、Linaro、SUSE和IBM。随着这些公司频繁的捐献，Linux基金会不断发展壮大，自2012年三月份的3.3版本发布以 来共计带了92000个变更。

对于大部分Linux开发者来说内核就是他们赖以生存的环境一部分，下面是全球企业贡献排行榜：

![](../Images/3f34c171aecc6cdb5455968005b280f7.png)

在2012年三月份发布的调查报告中显示Goolge是2005年就开始加入内核更新计划，在2010年10月份的时候贡献占比为1.5%，而三星则并未出现在前30名。
