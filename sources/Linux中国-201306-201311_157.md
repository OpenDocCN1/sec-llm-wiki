# 如何在Linux上添加或编辑文件系统的卷标

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001208&itemidx=3&sign=16140b1ea15e35ae5f8ed5f978194d21&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001208&itemidx=3&sign=16140b1ea15e35ae5f8ed5f978194d21&scene=27#wechat_redirect)

文件系统卷标并不是为了Linux操作系统正常运行所必需的，但当你有几个磁盘分区时文件系统卷标可以使你更容易去导航到那些磁盘分区。在这篇文章中我将展示如何在ext2，ext3和ext4磁盘分区中添加或**编辑Linux文件系统卷标**。

我的上网本装有3个操作系统：Windows XP，Linux Mint和Xubuntu。有时我想要在其它的操作系统上去查看一个文件系统的文件位置，有了文件系统卷标是非常方便的，就可以知道该打开哪个文件系统来找到所需文件。

### **查看Linux文件系统卷标**

首先让我们看一下哪些文件系统已经有了一个卷标，哪些还没有。你可以用**blkid**命令来查看你的文件系统信息。你需要以root身份运行这个命令去查看文件系统的全部信息。

sudo blkid -c /dev/null

在我的上网本里输出的信息是这样。

![](../Images/22b1a6a9a20d095275f4c6a8593e4cf2.png)

现在我用**lsblk**命令同样可以列出挂载在我当前系统上的某个文件系统。

lsblk

在我的Linux Mint 系统上输出的信息是这样。

![](../Images/ee71eb281b6cabcd392bfe5fad92cd07.png)

正如你看到的,在**blkid**和**lsblk**命令输出信息上，只有我的Windows分区是有卷标的，浏览文件管理器可以看到每一个分区都有一个通用的名称。

 ![](../Images/a71d1b57a2252ba8d4d44fdb04cef157.png "Unlabeled partition")

无卷标的分区

### **用e2label编辑Linux文件系统卷标**

查看**lsblk**命令的输出，我可以看到我的Linux Mint安装在/dev/sda3分区上，我的/home分区是在/dev/sda5分区上，而我的Xubuntu安装在/dev/sda7分区上。我用root身份运行e2label命令给在这些分区分配卷标。

sudo e2label /dev/sda3 Mint

sudo e2label /dev/sda5 Home

sudo e2label /dev/sda7 Xubuntu

现在看看**blkid**命令的输出，

![](../Images/626171cad32f6e2b47b963908bc9167b.png)

可以看到卷标已经被加上了。查看文件管理器，我同样可以看到我10.0GB的分区现在显示的是Xubuntu卷标。

![](../Images/af6d9f4939c02e00701471ea5acc892a.png "File system with label")

有卷标的文件系统

### **提示**

你同样可以用**e2label**命令来查看单独的分区卷标，如查看分区5.

sudo e2label /dev/sda5

删除分区5的卷标

sudo e2label /dev/sda5 ""
