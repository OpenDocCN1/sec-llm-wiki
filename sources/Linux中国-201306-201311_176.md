# Linux 3.12代号Suicidal Squirrel

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001180&itemidx=4&sign=f25dddd7de0b246b47cd9ae53f6482a0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001180&itemidx=4&sign=f25dddd7de0b246b47cd9ae53f6482a0&scene=27#wechat_redirect)

为了追思微软的Windows for Workgroups 3.11，Linus Torvalds为Linux 3.11起了一个代号“Linux for Workgroups”并设计了一个新的logo。

现在他也给正在开发的Linux 3.12起了带有自嘲意味的代号“Suicidal Squirrel（自杀的松鼠）”。此前他的工作站SSD发生故障导致Linux 3.12合并暂时停止。

公布新的代号显示他的工作站已经恢复，预计Linus会在未来几天发布 Linux 3.12-rc1。Linus表示，至少在可预见的未来几年内，不会有Linux 95发布。
