# 英特尔和Red Hat合作实现Gnome桌面的Wayland支持

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001169&itemidx=3&sign=ca58c6c7670eb3a9f1aea6dbc7b3acab&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001169&itemidx=3&sign=ca58c6c7670eb3a9f1aea6dbc7b3acab&scene=27#wechat_redirect)

在拒绝支持Canonica的Mir之后，英特尔宣布和Red Hat加强合作，为Gnome桌面实现Wayland支持功能。

Christian Schaller在博客上表示，Gnome将不使用Weston，而是使用 Gnome Shell作为 Wayland的合成器。

他解释说，移植到Wayland不是简单的用Wayland调用替代X调用，在许多情况下X中的功能要作为一个独立的库在Wayland中使用，而X处理的配置需要储存在其它地方。

英特尔和Red Hat的团队正着手为Fedora 20发布一个技术预览版，Wayland将作为一个选项提供给用户。
