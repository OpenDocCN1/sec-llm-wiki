# Fedora 20命名为Heisenbug

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001136&itemidx=3&sign=e5bc8a426a7812ac689406c702e1176c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001136&itemidx=3&sign=e5bc8a426a7812ac689406c702e1176c&scene=27#wechat_redirect)

Red Hat资助的社区发行版Fedora投票选出了Fedora 20的发布名字：Heisenbug。

Heisenbug这一名字源自物理学家Werner Heisenberg，特指一类程序bug，当有人试图对其进行研究之后它会消失或改变行为。

Fedora 20计划在11月发布。Fedora发行版最近起的名字与物理学有关联，如Fedora 19是薛定谔的猫。而在Fedora 20的投票中，Heisenbug险胜了Eigenstate，后者在物理学中意思是本征态。
