# 图说比尔-盖茨走过的峥嵘岁月

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001124&itemidx=1&sign=0444646d58a8a02b95cb8ac3f10bdf3d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001124&itemidx=1&sign=0444646d58a8a02b95cb8ac3f10bdf3d&scene=27#wechat_redirect)

斯蒂夫·鲍尔默宣布退休的同时，他的多年好友比尔·盖茨再度回到公众眼中。鲍尔默退休的具体原因尚不明确，但却暗示着鲍尔默自己和盖茨都认为他已经到了该放手的时候。许多人呼吁盖茨代替鲍尔默重登CEO宝座。毕竟是他创建了微软，在上世纪八九十年代用Windows把微软带上了个人计算机的垄断地位。

![](../Images/69158509c5c4f4c8f650e733ae1555a3.png)

但他不太可能重回微软CEO的位置。尽管盖茨仍是微软总裁，他在2008年离开微软转而专注自己的基金会，在世界范围内做着慈善事业。

盖茨在西雅图长大，他的父亲是一位律师。孩童时代的盖茨非常聪明，也执拗于自己的想法。

他是读着百科全书长大的。他想读什么书，父母就会提供什么书。根据《华尔街日报》中他的家庭档案信息来看，11岁的时候，他就凸显了超常的智力。

![](../Images/5457231d841aa4fc78037f435f38053a.png)

13岁的时候，他就读于西雅图的私立学校湖滨中学，也就是在那里他“邂逅”了电脑。

“在湖滨中学那段时间是我生命中最美好的时光，”他如是说。湖滨中学中配备电脑，盖茨和他的朋友保罗·艾伦在那里开始接触电脑。“我们在湖滨中学的经历和增长的见识让我们有信心大胆地创建公司，虽然当时没人支持我们——电脑芯片变得如此强大，电脑和软件将成为家家户户桌面上不可或缺的工具。”

![](../Images/324d4e5a38d9f3b313092ce61da61797.png)

从湖滨中学毕业之后，盖茨进入了哈佛大学。

在哈佛就读期间，盖茨结识了史蒂夫·鲍尔默。盖茨只在哈佛修行两年，便和保罗·艾伦一并辍学开始创立微软。

![](../Images/5b604c553231c2ee52df36610950fa7c.png)

盖茨和艾伦开始在新墨西哥的阿尔伯克基建立微软公司。

艾伦和盖茨为首款个人电脑MITS Altair建立了BASIC版本的编程语言。MITS全称为微仪系统家用电子公司(Micro Instrumentation And Telemetry Systems)，总部位于新墨西哥州的阿尔伯克基，所以微软诞生在那里。他们于1979年把公司迁址。艾伦1982年在检查出霍奇金式淋巴瘤之后离开微软，尽管病愈，仍没有再重回微软。
