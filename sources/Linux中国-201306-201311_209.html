点评6款让你痛不欲生的操作系统

网易科技：据国外媒体报道，经过多年的发展，现有的操作系统能够以更有效的方式帮助我们进行各种计算机操作。但在操作系统的演进过程当中，并不是每一个发布的操作系统都会使我们的生活变得更美好，许多版本的操作系统缓慢、呆滞和臃肿到令人尴尬。

你也许已经在脑中浮现了一两个让你头痛的操作系统，但实际上这样的操作系统的数量已经超过了你的想象。如果你觉得Win8让你痛苦，那下面的操作系统将让你痛不欲生。我们选取了6款最失败的操作系统进行点评。

Windows 1.0 - 1985

Windows 1.0是微软的第一个图形界面操作系统，不得不说这系统超级烂。微软公司最终放弃这个测试版本。最终向公众推出了bug丛生的Windows1.01。

MS-DOS4.0 - 1988

MS-DOS本身是一个优秀的操作系统。但是一个精英家庭，也经常会出现败类。微软推出MS-DOS3.3取得成功后，仍孜孜不倦的修改各种bug。于是微软公司1988年发布了MS-DOS4.0取代3.3版，但用户试用后迅速回滚到3.3版本。不断的程序崩溃和电脑死机让人一刻也不想使用MS-DOS4.0，当然这要归功于微软垃圾级的内存寻址编码。

JavaOS - 1996

Sun和IBM联手创建了用于嵌入式系统的Java OS，但是从一开始这就是一个非常糟糕的想法。 Java语言在那时效率是相当的低，这款用Java开发的操作系统仅仅存在了三年，就停止开发。然而，不过这启发了一些开源开发人员继续开发基于Java的操作系统，比如Jnode和JX。

Windows ME - 2000

微软发布Windows 2000后，因为某些令人无法理解的原因觉得有必要再发布另一个Windows版本。所以同年，被称为Windows ME（千禧年版）的操作系统上市了。然而，它是一款bug丛生，操作缓慢，极不稳定的操作系统。这款操作系统几乎让人失去了吐槽的勇气，微软卖了一年，就停止了这一产品的销售。

Lindows - 2001

这其实是一个伟大的想法：让Linux操作系统可以运行Windows应用程序。但这只是听起来伟大，事实上它是一场灾难。仅仅持续数月，该项目就被放弃。雪上加霜的是，Lindows公司被微软起诉。因为微软认为该公司名称侵犯了Windows商标。官司最终结局是微软公司收购了Lindows商标。

Windows Vista - 2006

Windows Vista，微软最近的败笔。它有时被称为第二版的Windows Me。 Vista是第一个使用目前Windows桌面UI设计的操作系统。然而，Vista运行非常缓慢，资源占用率超高，还有众多的硬件兼容性问题。迫使许多用户不得不重新安装Windows XP，直到Windows 7出现事情才有所改观。(秉翰)
