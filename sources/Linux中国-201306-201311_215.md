# Spiri：可编程的无人机——基于Ubuntu

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001112&itemidx=1&sign=8c015d2981d7806e8a95f633de723a1f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001112&itemidx=1&sign=8c015d2981d7806e8a95f633de723a1f&scene=27#wechat_redirect)

众筹网站平台Kickstarter有个名为“Spiri”的新的项目，次项目正在筹款打算制作一款可进行编程的无人机。Spiri是一款多功能的无人机，上面搭在有空气传感器，摄像头，无线网络，支持云计算，而且通过开放工具可以订制更多Linux设备。

![](../Images/b6c751ca5fe073a6d1f4d1ec946984ed.png)

创始人Patrick Edwards-Daugherty说；Spiri可以做很多事情，可以做快递，救援，洞穴探险，制图，也可以当作玩伴，园丁，检查员，记者，队友，或者就闲逛……反正任何事情都可以。

Spiri无人机运行的是Ubuntu Linux的ROS（机器人操作系统）拥有1GHz处理器，4GB内存，三轴加速度计。Spiri的每个旋翼四周还配备了碳纤维强化的保险杠，防止发生意外。

![](../Images/399a13c7c8512707204a7b8c260f2c50.png)

![](../Images/729da31dbf1ac57c37f9342e82db12a4.png)

目前Spiri已经筹集到了5.7万美元了，Patrick Edwards设定的目标是筹集到12.5万美元。
