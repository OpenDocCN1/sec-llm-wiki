# Ubuntu成功移植Xperia Tablet Z（多图）

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001080&itemidx=2&sign=ea4298e225ba903678c40179bf32f6f7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001080&itemidx=2&sign=ea4298e225ba903678c40179bf32f6f7&scene=27#wechat_redirect)

我们获悉，XDA开发者社区的大神，已经成功地将Ubuntu Touch操作系统，移植到索尼平板Xperia Tablet Z上。根据大神表示，目前这只是实验性移植，但是，大多数功能已经可以使用，比如ADB、显示、触摸屏、Wi-Fi、相机、音效、视频播放和应用程序运行等等。但是，大神mamenyaka也表示，Xperia Tablet Z的相机功能要启动之后等待一分多钟才能使用，否则就会报错。

![](../Images/47294e41f6b0d6f1ebf52459472c5db5.png "302427855UbuntuTouch2_www.kepfeltoltes.hu_.png")![](../Images/6fd880a57a4d44c913097f199f84fae8.png "UbuntuTouch02_www.kepfeltoltes.hu_.png")

另外，Ubuntu Touch一些自带程序，如计算器等，需要用户先打开浏览器上网，这些功能才能正常使用。

刷机有风险，Ubuntu Touch刷入Xperia Tablet Z，将完全清空存储空间，请事先备份数据。
