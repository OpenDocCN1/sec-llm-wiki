# Linux中国网站支持手机浏览了！

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001069&itemidx=2&sign=9d707e3a822a3db46971fdc696bfc3e9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001069&itemidx=2&sign=9d707e3a822a3db46971fdc696bfc3e9&scene=27#wechat_redirect)

近来随着手机浏览量的增加，我们对手机浏览器支持功能进行了改进。

目前，通过手机浏览器直接浏览本站，可以比较顺畅的访问帖子、文章和论坛及贴吧。当前的版本中，我们仅提供了匿名浏览的功能，更复杂的发帖及SNS功能，由于在手机浏览器上体验并不好，所以没有提供。

敬请大家用你的手机浏览器看看，如果发现有什么问题，请及时反馈给我们（目前还不能在手机上发帖，请回到电脑上来）。
