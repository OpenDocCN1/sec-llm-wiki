# Unix市场：还将存在衰退、竞争和利润

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001063&itemidx=3&sign=a779604683c1f7a860612d6f6d0e7374&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001063&itemidx=3&sign=a779604683c1f7a860612d6f6d0e7374&scene=27#wechat_redirect)

　　Unix，作为几十年来企业网络中的核心服务器操作系统，如今正处于缓慢下滑的状态.iDC预测，到2017年，Unix服务器营收将从2012年的102亿美元下滑到87亿美元，而Gartner则预测到2017年Unix市场份额将从2012年的16%下滑到9%。

　　IDC企业服务器部门研究副总裁Jean Bozman将Unix市场衰退归因于平台的迁移，Unix的主要竞争者Linux和Windows势头强劲，x86硬件变得更加高效和强大，并且更加廉价而易于维护；此外，大量的Unix专属应用如今也同样能运行在其竞争者的服务器上。

　　Gartner调研总监Errol Rasit也同意这个看法，他认为过去十年Unix疲软的主要原因是x86平台也可以运行很多Unix负载，并且更具性价比，吸引了大量用户从RISC向x86平台迁移。如今，x86技术吸引了大部分新的部署和创新，比如云计算以及分布式计算。

　　“用户面临的挑战是要了解Unix技术的发展趋势和供应商策略的细枝末节”，Rasit补充说：“然后将它们应用到自己独特的投资策略、应用程序和支持中，有些客户会继续在关键任务环境中的Unix系统上投资，而更多的客户因为IT生态系统的变化，以及迁移或整合策略，会逐渐剥离Unix系统。”

　　在Unix生态圈中，惠普动荡，Sun被甲骨文收购，IBM借机占据了更大的Unix地盘。分析机构Forrester副总裁Richard Fichera表示：“尽管Unix市场正在下滑，仍然存在着相当大的竞争，HP-UX已经丢给IBM巨大的市场份额；甲骨文同样遭遇了硬件的下滑，尽管他们的最新产品SPARC T5和M5服务器看起来极不平凡，特别是T5.”

　　据IDC调研，2012年全球Unix市场中IBM占据了56%的营收，甲骨文排在第二位，占据了19.2%，接下来是惠普，占据了18.6%，其他厂商占了两个百分点。

### **　　缓慢下滑，但不会消亡**

　　虽然Unix市场在长时间的、缓慢的萎缩，但没人能断言Unix会彻底消亡。

　　Gartner调研总监Errol Rasit还指出，在一些领域Unix仍旧是首选平台，例如电信行业应用的垂直软件、制造业和金融业、一些关键的向上扩展应用、安全和加密、以及一些要求低延迟和快速响应的环境。

　　“Gartner预测基于RISC和安腾架构的Unix服务器市场到2017年份额将从2012年的16%下滑到9%——缓慢但是持续的”，Rasit表示，为阻止下滑，Unix提供商需要获得更多的软件支持，但是，不断发展的Linux和Windows让Unix平台变得越来越没有吸引力。

　　惠普副总裁兼动能服务器总经理Randy Meyer表示，在可靠性方面，Unix服务器仍然具有明显的优势，例如，应用的自动容错功能让数据中心遭遇故障的时候还能给客户提供持续的运营。“很多系统或许有能力，但并没有被证明，特别是在罕见的情况下。如果系统不在极端的情况下进行测试，没人会相信它的可靠性，Unix系统能够提供三十年的可靠服务。”

　　惠普服务器首席技术官Kirk Bresniker补充说，如果移动和桌面设备宕机，只需要重启或者恢复系统，但是在关键任务平台，这简直是不能接受的风险。这就是为什么Unix还是关键任务的首选，因为它已经在过去三十年中证明了其可靠性。

### **　　Unix的未来**

　　IDC认为未来有几个领域将驱动Unix服务器的销售，包括电信应用、金融服务以及政府。这三个行业都曾大量应用的了Unix服务器，并且还将广泛的应用，特别是电信行业。除此之外，那些为Unix服务器设计定制应用的研发组织也需要购买或者租赁Unix服务器，以支持这些应用。还有哪些运行在Unix服务器上的大型单一系统镜像数据库，还将持续五到十年，因为将数据库迁移到其他平台往往过于昂贵。

　　Gartner则认为Unix未来的关键在于关键工作负载还会针对Unix平台持续优化。比如关系型数据库管理系统(RDBMS)，在软件收入方面，在Windows和Linux平台的RDBMS已经超过Unix。在2011年，RDBMS软件有25%部署在Unix平台，37%部署在Windows，30%部署在Linux平台。

　　但是，Gartner指出，在平均的部署规模上，Unix要比Windows和Linux要大。不过，如今x86系统也开始能够运行Unix的关键数据库环境，如甲骨文的Exadata和SAP HANA平台。

　　Forrester认为，即使最终Unix会消亡，也将是一个很长的、缓慢的过程。虽然对于软件开发商来说，在Unix和Linux之间迁移负载并不困难，但是对于大多数客户来说，自定义代码是个难题.unix系统对于很多用户软件还具有粘性，比如金融服务等行业，都有着大量的定制化应用。

　　此外，很多企业经营者有着规避风险和保守的心态，在很多情况下，Unix系统被用于关键任务，企业经营者更加重视风险，即使是迁移到Linux能获得更大的收益。forrester认为，从现在起的十年时间，Unix还将继续存在，会继续衰退，但还会存在着竞争，也会存在着利润。
