# 分析师：火狐操作系统前景不妙

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001039&itemidx=3&sign=56fec5953237016b3e56ed39d93a3b16&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001039&itemidx=3&sign=56fec5953237016b3e56ed39d93a3b16&scene=27#wechat_redirect)

据美国科技资讯网CNET报道，浏览器开发商Mozilla已经在美国、英国市场推出了火狐手机，尽管该公司表示这款手机吸引了众多消费者的注意，但业界分析师却对此持不同意见，他们并不看好这款手机的前景。以下是文章主要内容：

浏览器是否也能变成手机操作系统呢？火狐浏览器开发商Mozilla正为此而努力。该公司声称，其开发的小型、塑料材质的火狐手机已经吸引了众多消费者的兴趣。不过，分析师们却对此持不同意见，他们并不看好这款手机的前景。

火狐手机上市

尽管火狐手机刚上市不久，但这款手机已经进入了多个国家的销售渠道。起初，火狐手机仅在西班牙市场销售，后来拓展至委内瑞拉和哥伦比亚，现在这款手机又将进入eBay在美国和英国的销售站点。

市场研究机构Gartner分析师卡罗琳娜-米兰希（Carolina Milanesi）指出，Mozilla推出火狐手机能够产生两方面的作用，“首先这可以让Mozilla成功切入移动领域；其次这可以帮助移动运营商减少对低成本、同质化明显的Android手机的依赖。”

搭载火狐操作系统的Open手机即将登陆美国和英国市场，这款手机由Mozilla与中兴通讯联合打造，在美国和英国的售价分别为79.99美元和59.99美元。目前，Mozilla已经与西班牙、委内瑞拉、哥伦比亚的移动运营商达成了销售协议，不过现在仅有西班牙电话公司（Telefonica）开始了正式销售。

据Mozilla的首席开发者克里斯蒂安-赫尔曼（Christian Heilmann）透露，火狐手机受到了消费者的欢迎。他说：“用户的反馈非常积极，大多数人都表示，他们喜欢使用火狐手机。这款手机要么是他们的第一款手机，要么是其功能手机的更新替换产品。”

Mozilla移动设备高级副总裁兼亚洲区总裁李-刚（Li Gong）说：“在西班牙，一位来自中国的小伙甚至希望能购买100台手机带回香港。”

火狐手机的优势

据Mozilla介绍，火狐手机除了价格低廉的特点之外，其采用的火狐操作系统基于HTML 5和CSS3技术开发，因此开发者为其开发应用程序时，能做到像开发网站一样简单。

赫尔曼说：“编写火狐应用程序绝不会造成时间浪费。你能够非常轻松地将HTML 5应用程序搬至iOS平台，但是反过来却无法做的。”

此外，这款手机的亮点还包括可以直接向无线运营商缴费的应用程序内置购买方式，省略了使用信用卡的过程。该手机还保留着在新兴市场非常受欢迎的功能，比如内置的调频广播。

但火狐手机仅靠这些还无法取得成功。

分析师观点

市场研究机构Ovum首席电信分析师简-道森（Jan Dawson）指出，Mozilla无法说法美国或英国的移动运营商销售这款手机，本身就说明了该公司战略内在的局限性。他说：“与其他移动操作系统相比，我不知道火狐系统中有哪些能让人眼前一亮的东西。”

米兰希则指出，对Mozilla来说，过分依赖移动运营商或许并不是什么好事。她说：“很多手机品牌都依靠移动运营商来进行品牌塑造、市场推广，但结果他们只能听命于移动运营商的要求。我很期望Mozilla能够通过用户较高的忠诚度来创造需求。”

Mozilla将在今年底公布具体的移动战略，并有望在第四季度向巴西市场推出火狐手机，该手机将委托西班牙电信公司巴西子公司（Telefonica Brasil）进行销售。米兰希指出，巴西的进口关税非常高，这大幅提高了该市场的进入门槛。她说：“阿尔卡特也在巴西市场，这或许能够成为火狐手机的一大优势。”阿尔卡特目前也生产了搭载火狐系统的One Touch手机。

“我认为，我们肯定能在巴西市场取得突破。我们针对当地用户进行了多份调查，发掘出了当地用户的需求，比如在手机中内置调频广播。巴西的市场让人非常兴奋。”

猎狐陷阱

火狐手机会成为猎狐的陷阱么？

这很难预测。道森说：“当低价智能手机上市时，当前尚不饱和的智能手机市场会做出哪种反应，我们现在还很难预测。但从过去的情况来看，这种可能性非常大。”

他补充指出，Mozilla最大的挑战就是如何让火狐操作系统上的应用程序盈利。道森表示：“尽管Android系统在智能手机市场占据主导地位，但人们仍然愿意花更多的钱购买iOS应用程序。现在最关键的问题是，Mozilla如何说服开发者为火狐操作系统开发应用，并说服用户购买其应用。”

米兰希认为：“Mozilla推出火狐操作系统的想法是对的。如果该系统能在Android占智能手机市场40%的份额时推出，那么其成功的可能性非常大。但现在情况则复杂很多，因为中国手机厂商推动的Android手机最低售价仅为80-90美元，火狐的低价优势并不具吸引了。”

据Mozilla介绍，该公司从2014年开始，将与索尼合作在日本研发高端手机，同时在新兴市场如中国、印度、巴西等市场推广火狐手机。

不过，即便是在新兴市场，火狐手机同样面临诸多挑战。李刚说：“我们将它定位成低端手机，但在某些市场，它的价格并不便宜。以中国市场为例，如果我们想要在该市场取得成功，就必须实施不同的战略，推出不同硬件规格的产品。”

对Mozilla来说，当前最重要的是解决火狐操作系统知名度不高的问题。与Windows Phone不同，火狐操作系统无法获得充足的资金支持。另外，我们也不清楚网络开发者是否会像Mozilla声称的那样自愿开发HTML 5应用程序。

过去，Mozilla曾凭借新的桌面版和Android版火狐浏览器获得了丰厚的回报，但现在火狐手机却很可能成为Mozilla猎狐的陷阱。
