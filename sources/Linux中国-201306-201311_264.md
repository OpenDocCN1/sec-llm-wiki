# Debian：20岁生日快乐

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001029&itemidx=4&sign=65fe12c44b4ede689fc8c71fc4f21863&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001029&itemidx=4&sign=65fe12c44b4ede689fc8c71fc4f21863&scene=27#wechat_redirect)

Linux发行版本众多，虽然混乱但最大的好处就是用户们可以根据自己的喜好选择不同版本，并且获得截然不同的体验。今天，著名的发行版之一Debian迎来了20岁生日，一路走下来确实不易。1993年8月16日，Ian Murdock成立了“Debian Project”，这是一个完全免费的社区性质项目，旨在打造一套免费的Linux操作系统。

20年过去了，Debian算不上最好的Linux，但绝对是最有影响力的之一，也是最大的开源工程之一，也是很多流行的Linux发行版的基础，比如名声最大的Ubuntu，其实就是Debian的一个分支，95％左右的东西都是相同或者差不多的。

Debian被誉为是“通用操作系统”，已支持70多种语言，拥有2万多个软件包，支持10多种计算机架构。

Linux们可能扳不倒Windows，但正是它们，让我们的生活更加丰富多彩！
