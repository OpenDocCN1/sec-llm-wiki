# 浏览器战争：Chrome掌管世界 但中国依旧流行IE

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001011&itemidx=4&sign=aa27a6f99c27db6eb0fa77192a380f5a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001011&itemidx=4&sign=aa27a6f99c27db6eb0fa77192a380f5a&scene=27#wechat_redirect)

互联网帝国间的权力交替总是如此迅速，这一点同样发生在浏览器战场。下个月，谷歌的Chrome浏览器将迎来发布五周年的日子。在PC端由浏览器贡献的流量中，Chrome已经占到了43%。回顾五年前，Chrome刚推出时，IE浏览器还掌握着核心地位，当时占有68%的市场份额。如今，这个数字跌到了25%。

《经济学人》近日发布了一张反应全球各个国家和地区最流行的浏览器分布图。其中，蓝色区域代表IE浏览器在这个国家还占有主导地位。

![](../Images/40344e8089deb419750131642e22178d.png)

不同地区所流行的浏览器

毫无疑问，中国大陆地区依旧牢牢地被IE浏览器所掌控。其它IE占主流的地区还包括日本、丹麦的格陵兰岛、瑞士、利比亚、南非的大多数国家。

值得注意的是，虽然火狐浏览器近年来也出现下滑趋势，但在非洲的很多国家、北欧部分国家、伊朗、阿富汗和印度尼西亚等地却拥有领先地位。

纵观整个图表，Chrome已经凭借明显的优势征服了全球大多数的国家，尤其是在北美和南美地区。

回顾整个浏览器市场的发展路线图，20年前，全球最早一款可以综合显示图片和文字的浏览器Mosaic推出。后来，它的部分开发者于1994年发布了网景浏览器。但网景的领导地位很快被微软借捆绑Windows操作系统而推出的IE浏览器所威胁。

直到2010年，欧洲委员会要求微软必须为用户留下选择其它浏览器的机会时，火狐浏览器才开始逐渐走向大众视野。但如今，火狐又被Chrome抢去了更多用户。

其实，想要确定浏览器的市场份额并不容易。机构之间评判标准并不一样。比如在以用户数为标准的计算中，IE依旧是排名第一。不过，随着电子商务和视频网站的发展，流量的重要性更加明显。所以，按这个角度来看，Chrome显然更有优势。
