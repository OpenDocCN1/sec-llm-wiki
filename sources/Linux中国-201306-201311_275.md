# 为什么Mark Shuttleworth仍然花自己的钱去资助Canonical？

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001011&itemidx=2&sign=f7c7394c5cb3fda0b2e903267c7ebd35&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001011&itemidx=2&sign=f7c7394c5cb3fda0b2e903267c7ebd35&scene=27#wechat_redirect)

2004年Mark Shuttleworth创建Canonical时，他告诉雇员公司可以依赖他两年。然而，将近10年之后，Canonical仍然没有盈利，Shuttleworth依旧在花自己的钱资助Canonical运营。Shuttleworth的目前财富估计有5亿美元，主要来自于他在1999 年以5.75亿美元将其创建的数字证书公司出售给VeriSign。

虽然他希望Canonical最终能成为一家自负盈亏的公司，但他并没有威胁如果不盈利他就要将其抛弃。Shuttleworth最初希望Ubuntu能挑战微软在桌面的统治地位，但时至今日Windows市场占有率仍然高达93%，所有 Linux桌面发行版份额只有1%，也就无怪乎Canonical不能盈利。

桌面有微软，企业服务器有Red Hat，移动有苹果和三星，Shuttleworth承认，Canonical在桌面、企业和移动业务上的追求有点像是追逐彩虹，但Canonical并 不需要推翻业内的最强者才能盈利，它只需要开辟出它自己的一片天地。
