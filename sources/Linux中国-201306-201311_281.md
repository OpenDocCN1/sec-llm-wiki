# 加密移动应用Silent Circle提前删除所有邮件

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000998&itemidx=4&sign=138d75063e74cfb1e6fd9dfa7880618f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000998&itemidx=4&sign=138d75063e74cfb1e6fd9dfa7880618f&scene=27#wechat_redirect)

在前NSA合同工Edward Snowden使用的加密电子邮件服务Lavabit宣布关闭后不久，PGP作者Phil Zimmermann发布的智能手机加密服务Silent Circle宣布删除所有邮件，以防止美国政府迫使他们交出客户数据。

Lavabit创始人Ladar Levison指出， “如果你像我一样了解电子邮件，你可能就不会去使用它。”

Levison不是一位隐私决定论者，如果美国执法部门能通过透明的司法途径提出数据披露请求，他会愿意合作，但以国家安全名义的秘密数据披露请求则不在其中。

Silent Circle的电子邮件服务类似Lavabit，加密是可选的功能，但多数用户没有选择加密，Phil Zimmermann承认他们未提前预警就作出删除决定惹恼了部分客户，他希望客户能尊重他们的判断。Zimmermann本人已经很少用电子邮件，而更多使用加密移动通讯，因为电邮需要地方储存，它们不会消失，相比下发送加密信息则更为简单合理。
