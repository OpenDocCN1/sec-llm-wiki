# Lavabit创始人关闭了匿名邮件服务网络

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000991&itemidx=2&sign=3503491648d458972edd705e5bfaa72c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000991&itemidx=2&sign=3503491648d458972edd705e5bfaa72c&scene=27#wechat_redirect)

“我现在已经跟邮件‘分手了’。我认为，如果你也知道我对邮件所了解的，那么你将也不会再继续使用它了。”--这段话不是出自任何人之口，正是匿名邮件服务Lavabit创始人Silent Circle之口。

  

最近，Lavabit电邮服务宣布关闭。Circle表示，他宁愿关掉服务平台，也不乐意成为作出损害美国人民利益行为的“帮凶”。

  

媒体推测，斯诺登使用Lavabit很有可能是其关闭的最直接原因。据悉，斯诺登曾利用Lavabit电邮服务平台向《卫报》和《华盛顿邮报》提供了NSA机密监控项目的信息。虽然Lavabit断了斯诺登一条重要跟外界联系的重要方式，但支持他的人仍决定为其筹集每个月1.2万美元的日常费用。目前，这群人已经获得了9000万美元的资金。Levison则将这次斗争的胜利比成如同“在总统大选中中选”的感觉一样。他称，“如果我们赢了，那么我们是为（美国）每一个人赢的。”

  

而与此同时，由于Lavabit已经停止服务，所以现在福布斯可对外公开该平台具体运作的过程。不过，用户的数据以及私人密码都被受到保护。
