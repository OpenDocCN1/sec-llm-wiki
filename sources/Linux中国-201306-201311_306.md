# Faenza 1.3.1 发布 – 最漂亮的 Linux 图标主题

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000959&itemidx=3&sign=5d816439524dc1613d22ea17b41ccd3b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000959&itemidx=3&sign=5d816439524dc1613d22ea17b41ccd3b&scene=27#wechat_redirect)

Faenza 是一款我一直使用的图标主题，这款主题采用类似苹果一定设备的图标效果：圆角方块图标。该图标的更新速度也是相当的快，以提供更多的程序图标和图标改进。

Faenza 1.3.1 版本是 1.3 版本上做了一个小的改进，天气图标的更新。

安装 PPA 源，打开终端，输入命令：

> sudo add-apt-repository ppa:tiheum/equinox  
> sudo apt-get update && sudo apt-get install faenza-icon-theme

PPA 下载速度有时很慢，你可以直接下载图标包：

*   Gnome-look下载：http://gnome-look.org/content/show.php?content=128143
    
*   DeviantART下载：faenza-icon-theme\_1.3.zip（23.7M）
