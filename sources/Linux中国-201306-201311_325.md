# 3D 虚拟 Ubuntu Edge

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000927&itemidx=3&sign=44ce0831a6171e214bab9912379e2099&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000927&itemidx=3&sign=44ce0831a6171e214bab9912379e2099&scene=27#wechat_redirect)

　　Ubuntu Edge 最快在明年 5 月份大家才能拿到手，在这之前，大家只能看看官方放出的图片来解解馋。不过有爱好者是在按捺不住，通过已经放出来的图片，制作了 3D 虚拟环境下的 Ubuntu Edge，给准备购买 Ubuntu Edge 的爱好者们以更强的感受来感受 Ubuntu Edge。

　　3D 虚拟交互式 Ubuntu Edge 由 **Aerilius** 设计制作。托管在 Sketchfab 上，使用标准的 Web 技术，HTML5 和 WebGL 来渲染模型中的细节，实时展示模型的阴影光泽。大家可以点击下面的链接来在浏览器上体验一下：

*   http://sketchfab.com/show/c1d2b84d880741b189577ef5698112b0
    

　　如果感觉不错，您可以通过 indiegogo 上的 ubuntu-edge 筹款项目来捐赠购买一个。
