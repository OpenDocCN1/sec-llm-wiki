# Ubuntu手机系统会成为第四大手机系统吗

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000896&itemidx=5&sign=9b89a88193730350ec84168843b09c08&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000896&itemidx=5&sign=9b89a88193730350ec84168843b09c08&scene=27#wechat_redirect)

Ubuntu开发商Canonical发布了代号为Edge的智能手机，与其说是发布，倒不如说是这个项目的成立，因为该项目正式启动需要募集至少3200万美元(30天内)。 Ubuntu首款手机Edge外形设计方正有型，机身尺寸为64×9×124mm，配备了4.5寸蓝宝石材质屏幕，分辨率为1280×720像素，搭载多核心处理器，内存组合看起来很猛，即4GB RAM+128GB存储空间。

此外，该机还具备800万像素摄像头(前置200万像素)，运行双系统即Ubuntu mobile OS和Android，同时提供加速度计、陀螺仪、罗盘、气压计等功能，支持LTE 4G网络。

售价约600美元(折合人民币3680元)，并且出货时间为2014年5月。

目前，Ubuntu已经获得了世界各大运营商们的支持，在其Ubuntu运营商顾问团名单中包括德国电信、Everything Everywhere、韩国电信、意大利电信、 LG UPlus、葡萄牙电信、SK电讯等8家运营商，全部都来自于非美国地区。随着Verizon的加入，Ubuntu手机登陆美国的概率有所提高。目前，确认加入顾问团的运营商成员还包括中国联通和Smartfren。

意味着该公司将和这些成员一起，合作推进Ubuntu操作系统的开发。

### Ubuntu系统优势：手势操作+PC桌面二合一

作为一款备受瞩目的新手机系统，Ubuntu系统最大的特点是手势操作和手机PC二合一。它的手势操作几乎可以让手机没有任何虚拟按键都可以。左右上下边框都加入了手势操作。滑动左边框会出现侧边栏，其中包含了一些常用应用程序，正式版中应该可以自定义这一板块。这对单手操作来讲应该是非常有必要的设置，同时也能看出，未来Ubuntu系统或许会向着5英寸这类大屏手机发展。右边框滑动则会调出我们上一个推出的应用程序，无论是打电话还是玩游戏上网，都会快速的进入到上一个关闭的应用。这就大大减小了内存的压力，同时只需要一个响应动作就能完成。

同时，高配版Ubuntu手机具有与桌面系统互相转化的能力。当手机通过底座连接到外接显示器时，将会自动启动桌面模式，用户将可以直接操作桌面版Ubuntu系统，如同操作一台普通的Ubuntu电脑。

而在应用生态的培育方面，BlackBerry 10提供了四种应用开发和转制方式，Ubuntu也采用了类似的做法，试图最大限度地扩展应用的来源。Ubuntu的生态系统在很大程度上依赖网页应用。

Canonical表示，Ubuntu将采取网页应用与原生应用并举的做法。这意味着你可以使用基于HTML5技术开发的所有应用，例如Facebook、谷歌地图、Spotify和Twitter。Ubuntu手机操作系统还将向开发者提供完整的软件开发包(SDK)。

Canonical方面承诺为Ubuntu手机操作系统提供web应用提供深层API接口，让它们可以像原生应用一样安装到系统中独立运行，并使用各种系统服务。同时表示基于PhoneGap等方式构建的web应用应该可以直接在Ubuntu中运行。因此，Ubuntu手机操作系统可能并不会缺乏应用的支持。

对于同宗同源的Android来说(二者都基于Linux)，Ubuntu的确是个不可小觑的对手。

不过，Ubuntu一直都是一个相对松散和资金薄弱的团队，否则也不会需要在30天内募集至少3200万美元，作为该项目启动资金。

一位网友这样评价Ubuntu：这家公司在技术和创新能力上并不逊色于谷歌和苹果，只是缺乏一些商业基因。

### 即使不会将手机系统格局一分为四 也将是受小众用户追捧的恩物

今年MWC大展开始之前Ubuntu手机操作系统开发商Canonical就公布了触摸开发者预览版，同时还有Google Nexus等多款手机的ROM包放出。这也让我们再次看到了移动操作系统中的又一竞争对手。那么这个名不见经传的新系统又能否在市场上分到一杯羹呢？它会是第四大移动操作系统吗？

天使创业村投资总监朱业胜曾发表文章表示，在现在的市场格局下，光有一个还过得去的操作系统，显然还不足以脱颖而出、占有有一定影响力的市场份额，还需要一个生态系统的支持，这其中最重要的就是手机厂商的支持。

目前虽然Android拥有最多的支持厂商、占有最大的市场份额，但这些厂商心中都难免会犯嘀咕，希望能有多一个选择。

实际上这些手机大厂们最想走的路是苹果的路，能有iOS这样优秀、封闭而独有的操作系统，但iOS是因为有了多年的积累、沉淀和大量研发投入才有了它的现在，短时间内三星、华为们难以达成。

退而求其次，手机大厂们想要能有Android同样优秀的开源系统，同时又不希望它掌握在谷歌这样强势的控制者手中，有一个能够抗衡谷歌的选择。

所以，从手机厂商们的意图来看，要成为Android之外的备份操作系统Ubuntu是有一定机会的。但它除了面对上述如Tizen、 Sailfish等的竞争外，还有三个难关。

1、消费者的使用习惯

消费者在智能手机这几年的发展中已经形成了自己的使用习惯，所以Ubuntu的完全手势操作是否会得到消费者的青睐，还难以预料。

2、手机厂商和应用开发者的路径依赖

手机厂商和应用开发者们已经习惯了Android的生态环境，Ubuntu想要建立新的生态系统必须打破原有的路径依赖，这可能需要一段不短的时间，Android在面对竞争后会做出自己的反应。

3、大量的投入

做一个操作系统不容易，此前英特尔和诺基亚联合打造MeeGo平台，但最终以失败告终。它本身需要大量的资金投入、人力投入和时间积累，Ubuntu目前的基金规模、人员规模都比较小，能否支撑它的持续发展也是一个很大的问题。

Ubuntu想要大放异彩、与Android并驾齐驱看上去很困难，也许它会重复在PC领域的命运，成为一款有特色但只有小众用户追捧的手机操作系统。
