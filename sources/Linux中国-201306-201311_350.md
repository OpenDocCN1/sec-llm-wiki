# Firefox OS 也要刷版本：每季度一次大更新

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000888&itemidx=2&sign=282376f0efa7d142559f98b868bb42aa&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000888&itemidx=2&sign=282376f0efa7d142559f98b868bb42aa&scene=27#wechat_redirect)

Firefox浏览器一直在和Google Chrome角逐“版本帝”，是好是坏暂且不评论，但看起来Mozilla对这种政策很满意，正准备将其也用在Firefox OS移动操作系统上。

Firefox OS已经发布了1.0版本，正在拉拢更多合作伙伴，未来的发布规划也已制定：每季度发布一个重大功能版本(feature release)，每六周为此前的两个重大版本发布安全更新。

这也就是说，每个重大版本将享受为期半年的安全维护，然后就被抛弃。

这毫无疑问会成为最“勤快”的移动系统。事实上，安卓系统的更新脚步都已经慢下来，为的就是解决碎片化问题。
