# sar2html 2.4.0 发布

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000883&itemidx=3&sign=65eba7450beea1a440c13e4c878bf083&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000883&itemidx=3&sign=65eba7450beea1a440c13e4c878bf083&scene=27#wechat_redirect)

Sar2html 可以将 sar 程序执行的二进制结果数据转成图形的 HTML 格式，它提供了命令行工具、Web 接口和数据收集脚本。

sar2html 2.4.0 现在支持连接到服务器来捕获报告。

使用 sar2ascii 可从服务器 (HP-UX 11.11, 11.23, and 11,31, Redhat 3, 4, and 5, Suse 8, 9, 10, and 11, and Solaris 5.9 and 5.10) 收集 sar 数据。

For HP-UX servers, run "sh sar2ascii".

For Linux or Sun Solaris servers, run "bash sar2ascii".

这将在 /tmp 下生成名为 sar2html-hostname-date.tar.gz 的文件。Sar2html 包含三部分：sar2ascii, sar2html, 和 sar2html.php. 必须安装 Gnuplot 来支持 PNG。
