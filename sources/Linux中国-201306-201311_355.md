# Filemonitor 2.3.0 发布

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000883&itemidx=4&sign=878dc943d34e5927fd0301a2796dd30b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000883&itemidx=4&sign=878dc943d34e5927fd0301a2796dd30b&scene=27#wechat_redirect)

Filemonitor 2.3.0 优化了内存的使用，修复了 Stop 停止监控器更新的问题，修复了列选择问题。

FileMonitor 使用 Linux 下的 lsof 命令实时的监控文件的打开和关闭操作，并返回一个列表。
