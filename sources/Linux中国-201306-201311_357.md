# Linux 新闻网站 The H 关闭

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000877&itemidx=2&sign=a7adcaaa89d59bba767f3995651c122d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000877&itemidx=2&sign=a7adcaaa89d59bba767f3995651c122d&scene=27#wechat_redirect)

知名的Linux新闻网站The H宣布关闭，原因是无法将流量转变为收入，没有找到一个行之有效的商业模式。

The H表示将创建一个存档，让用户可以访问已发表的内容。

The H是德国著名IT网站Heise Online的英国版，2008年上线，2009年2月命名为现在的名字The H。
