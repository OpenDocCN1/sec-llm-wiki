# 详解显示日历信息的命令 cal 和 ncal（多图）

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000872&itemidx=1&sign=e74688281812f7d651a8b576fe47dc0e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000872&itemidx=1&sign=e74688281812f7d651a8b576fe47dc0e&scene=27#wechat_redirect)

　　Linux 里内置两个用来显示和校准日历的命令 cal 和 ncal。一旦你习惯使用它们，你会发现使用命令很多时候都比你运用鼠标在 GUI 的日历里查看要来的更迅速和方便。命令行下，有许多参数，这些参数能完成您所需要的所有关于日历的需求，目前来说，我还没有发现我需要显示的一种日历的需求是它没有的，哈。

　　下面，我就来和大家一起学习学习这些命令，这些命令我都在 Ubuntu Linux 日常使用：

**问1、如何显示当前月份的信息**

答：直接使用 cal 命令就可以，不需要添加任何参数

![](../Images/1e9ecbebad4b4a5ffaf139255acefba3.png)

当然，您使用 ncal 也会得到同样的效果：  

![](../Images/abc70e5eea44d522428898cd408f5097.png)

您可以看到整个当前月份的日历，当天日期是高亮显示的，您可以使用 -h 参数来关闭高亮。

**问2、如何竖向排列日期**

答：使用 ncal 命令同时添加 -J 参数

![](../Images/8da33fa234e4921d7b9396fc2f5e6e34.png)

**问3、想查询复活节日期**

答：使用 ncal 命令添加 -e 参数

![](../Images/6d1432edb5ff73c12b47bcade4a8dd32.png)

**问4、怎么显示 Julian 日历  
**

答：使用 cal 命令添加 -j 参数

![](../Images/7634317534a967e42bf274c8a5cd9885.png)

**问5、如何显示指定月份日历**

答：使用 cal 命令添加 -m 参数和月份

![](../Images/8d0ee58820ffed551bfbd58e7e8a4bd4.png)

　　默认情况下，您添加的 -m参数和月份为当年的月份，如果您希望看到指定的某个年的月份，您可以在后面添加四位数字的年份。  

![](../Images/a8e365d543e5f14da7996778303ad303.png)

**问6、如何同时显示前一个月本月和下一个月三个月的日历**

答：使用 cal 命令添加 -3 参数

![](../Images/5208745fcb96fc60eb33a265cbd2ff9e.png)

同样道理，您可以查看任意三个月的日历：  

![](../Images/509ca5d2230405febcd4852d27bf0fb7.png)

**问7、如何显示orthodox Easter 的信息**

答：使用 ncal 命令添加 -o 参数

![](../Images/69fee43fc1f7823a0511d504160e9b01.png)

**问8、如何显示国家代码**

答：使用 ncal 命令添加 -p 参数

![](../Images/0b2a9371dd570283c78872bf20dbf66f.png)

**问9、如何按自然月显示周信息**

答：使用 ncal 命令添加 -w 参数

![](../Images/69c97c7187243b9e8d46546f4147307a.png)

　　最下面的一行是下个月的信息。

**问10、怎么一下查看全年的日历**

答：使用 ncal 命令添加 -y 参数和 四位数的年份

![](../Images/a767b8e5ccdef11c0e42a2d02b605d31.png)

**问11、如何显示某个月和某个月前几个月和后几个月的日历**

答：使用 cal 命令添加 -m -B -A 参数和月个数

![](../Images/f0eb7a94c540b4b15195c9216a05ea8b.png)

　　显示结果上，您可以看出，我们想显示 4 月份和 4 月份前两个月和后两个月的日历。如果您想显示指定年份的日历同时在显示年份前后的几个月，那么直需要在添加 -y 参数和四位数的年份即可：  

![](../Images/bd32fe74ac09c8af93587223665f4af0.png)

　　从结果上我们看到，除了 2012 年整年外，我们还能看到 2011 年最后俩月和 2013 年前俩月的日历。

**问12、如何让 ncal 命令显示成  cal 命令的结果**

答：可以使用 -C 参数来完成这一点

![](../Images/344df90c8116138ee7d2f3d465260530.png)

　　同样，你可以使用 -N 参数来让 cal 命令看起来和 ncal 一样：  

![](../Images/9b2ec17332b91786a2609feab8b24a60.png)

**问13、如何让日历显示成以周一为每周第一天的样子**

答：使用 ncal 命令添加 -M 参数即可

![](../Images/7400a8573f9449c816edf91fd6e3ab27.png)

　　还有一个 -S 参数，可以按周日为第一天来显示

**问14、如何切换 ncal 命令为以前的显示方式**

答：使用 ncal 命令添加 -b 参数

![](../Images/0833849902e15c46dc20ca65c24819c3.png)

**cal 和 ncal 命令的一些其他相关信息**

　　虽然我们可以查看这两个的命令的 man page 来得到更多的信息，不过在这里，我还有一些其他信息要告诉大家。需要指定年份的时候，我们需要四位数的年份。不是所有的参数都可以同时使用的，比如 -y, -3, -1 他们之间是冲突的，如果同时使用，后面的参数会覆盖掉前面的参数。
