# Windows 操作系统垄断地位崩塌

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000866&itemidx=3&sign=f25d9b07d2b0e340c31023cf93db49d2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000866&itemidx=3&sign=f25d9b07d2b0e340c31023cf93db49d2&scene=27#wechat_redirect)

**腾讯科技讯**（云松）北京时间7月18日消息，据国外媒体报道，15年前PC产业如日中天，其核心技术Windows操作系统风头也是一时无二；15年后，PC在智能手机和平板电脑面前已经毫无优势，而Windows操作系统一家独大的局面也不复存在。

上世纪90年代末，有一家美国科技公司在全球绝对称得上是独领风骚，该公司几乎富可敌国，且技术实力相当雄厚，不仅在桌面操作系统方面独占鳌头，在其他软件领域的影响力也是蒸蒸日上。但是木秀于林，风必摧之，美国政府通过发垄断法律将这家公司拖入了一场旷日持久的诉讼案。没错，这就是当年的微软。

最终微软在这场诉讼案中败北，不得不接受严苛的法律约束。很多人都担心此案会给微软带来相当大的负面影响，怕这家偶像级的科技公司会因此案而裹足不前。但事实证明，在过去的15年里，最终让微软丧失全球个人电脑市场统治地位的并不是这场反垄断诉讼案，而是市场本身的变化。

从当时的形势来看，微软已经成为了全球科技界的焦点，几乎要打破历史，成为世界上第一个市值过万亿的公司。1999年微软市值达到了历史最高，根据标准普尔的数据显示，当时微软的记录是6205.8亿美元。如果把当时通货膨胀的因素也考虑在内的话，微软在1999年12月30日的总市值记录约等于今天的8500亿美元。但是互联网蓬勃发展带来的变化并不是微软能够掌握的。微软也不过是全球互联网大潮中一朵汹涌而美丽的浪花。

当年的反垄断案确实给微软带来了很多的损失，但却不是致命的。由于云计算、智能手机、平板电脑等新兴电子产品的出现和大范围普及，曾经叱咤风云的桌面操作系统也没有了当时的风光。只要电子产品能上网，能运行相关的程序，就基本能满足用户的需求，至于搭载的是什么操作系统并不重要。

通过下面的三个表格，我们可以非常客观地了解微软、惠普、戴尔、英特尔等科技巨头在互联网新浪潮前所面临的挑战。

全球互联网设备出货统计（2000年到2012年）

首先，看一下全球互联网设备出货统计：从2000年到2012年，虽然PC每年出货量维持在2亿台左右，但是智能手机和平板电脑出现之后，市场格局就发生了根本性变化的变化。现在PC的出货量和智能手机、平板电脑相比真可谓相形见绌。

![](../Images/e736932b8a1a7abe97e4b0d76346bc09.png)

全球主要平台的市场份额（2009年第一季度到2013年第一季度）

从表中可以看出，个人上网设备的多元化极大地削弱了Windows操作系统的统治地位。其实这种变化也是最近几年才出现的，三年前全球70%的PC搭载的都是Windows操作系统。现在，由于谷歌(微博)开发的安卓系通和苹果公司的iOS平台的大范围普及，Windows操作系统在全球市场的占有份额和以前相比几乎缩水30%到50%。最显著的变化就是，安卓在全球市场的占有额已经超过了Windows。

最后，看一下美国市场研究机构Asymco分析师霍拉斯•德蒂欧(Horace Dediu)的统计数据。PC业务不仅仅是在智能手机和平板电脑的井喷式销售数据面前显得“矮小”，PC业务本身已经出现了明显的下滑趋势。现在上网设备已经变的多元化，虽然PC技术已经相当成熟，但PC却并不是性价比最高、上网最方便的设备。PC的地位已被智能手机和平板电脑颠覆，个人电脑已经成为了专门的办公设备。

![](../Images/251a55238e5377a5adfb64cb0aa18f60.png)

搭载Windows操作系统的PC出货年增长率

通过上图我们可以发现，在iPad发布之前，搭载Windows操作系统的PC有着相当不俗的出货增长。但从2010年底开始，PC的出货增长率一直萎靡不振，近期还出现了明显的负增长。

实际上，对微软而言，也并不全是坏消息。微软在转型方面的表现的确可圈可点之处。而且微软的Office办公软件也是微软重要的创收来源。虽然谷歌和苹果也推出了自己的办公软件，但是尚未对Office构成致命威胁。

时光荏苒，微软的反垄断案已经过去15年了。曾经的垄断性产品——Windows操作系统再也不会被起诉垄断了，而和Windows操作系统息息相关的PC产业也是前景堪忧。
