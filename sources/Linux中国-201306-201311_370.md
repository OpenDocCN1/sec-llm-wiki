# Ubuntu VS Linux Mint，谁是Linux家族桌面系统之王？

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000860&itemidx=4&sign=936ead28490477a883f2ad135a4bfefe&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000860&itemidx=4&sign=936ead28490477a883f2ad135a4bfefe&scene=27#wechat_redirect)

　　Linux各发行版之间的殊死搏斗仍在继续，最近一段时间Datamation开始将关注重点放在Ubuntu与Linux Mint二者的优劣短长之上。哪一款更出色？他们认为这是个没有标准答案的问题，即所谓“情人眼里出西施”。

　　不过从桌面发行版的角度权衡，旁观者仍然把宝贵的支持票投给了Linux Mint。我个人一直没能适应Ubuntu使用的Unity桌面环境，而且与我拥有同样感受的用户并不在少数。自从Unity推出以来，丢下Ubuntu转投Linux Mint怀抱的使用者大有人在。

**　　大家的观点呢？您更偏爱Ubuntu还是Linux Mint？**

　　甫一上手，Ubuntu与Linux Mint给人的直观感受就完全不同。从色彩搭配到图标设计再到启动栏位置，Linux的每一款发行版都给用户带来彻底脱离于同类产品之外的独特体验。

　　不过二者之间的最大区别恐怕还是在各自的整体方针层面.ubuntu力图打造一款万事通型方案，旨在为台式机、Ubuntu TV以及智能手机等平台提供统一化系统环境。而作为竞争对手，Linux Mint则始终坚持自己的设计初衷--为用户提供卓越的桌面系统使用体验。

**　　细节对比：**

　　1.硬件兼容性：尽管大量报道众说纷纭，但Linux Mint与Ubuntu在硬件兼容性方面的表现可谓处于同一水平。由于Mint以Ubuntu为基础，因此二者的硬件检测成绩不相上下也在意料之中。

　　2.软件管理：Ubuntu在默认状态下缺乏PPA工具，不过幸福的是各类第三方PPA为用户带来了希望；不过总体而言，Ubuntu的软件管理机制对于新手用户不够友好。相比之下，Linux Mint的全新工具MintSources帮助用户广泛受益，使PPA管理、存储库维护及可视化流程变得更为轻松。

　　3.企业对社区：从技术角度看，Ubuntu与Linux Mint都属于以社区为技术基础的Linux发行版。双方都接受由企业提供的项目发展资金，但只有Ubuntu直接与企业赞助商打交道。这样看来，Linux Mint的独立性就显得更加突出。不过话说回来，二者都没能真正做到完全从社区用户的立场出发。事实上社区仅仅是一种资源输入途径，而非真正的贡献来源。

　　4.总结：尽管Linux Mint与Ubuntu双方都希望为新手用户带来良好体验并不断提高可用性，但其具体方针仍存在明显差异.ubuntu的跨平台策略令桌面用户逐步沦为二等翁（至少在感觉上是如此）.linux Mint则专注于桌面系统环境，以心无旁骛的姿态为世人打造理想的开源系统方案。

**　　平板设备上的发行版霸主**

　　说到Linux发行版，Tech Radar网站曾经对平板设备上的众多开源系统方案做出过一番综述。我有一台iPad，但从没尝试过在其上运行Linux系统。如果苹果公司仍然执意把iOS 7的风格弄成这种天真可爱状，我会认真考虑尝试Android平板。但在本篇文章的启发下，我当然也有其它选择作为参考：例如使用Ubuntu、OpenSUSE、Fedora或者Kubuntu。

　　Linux系统家族最突出的贡献在于，用户永远拥有大量不同类型的方案可以选择。不仅是台式机，平板设备拥有了这种特性也将为我们带来全新的体验空间。

　　我们有个好主意（事实已经证明其切实可行）：为什么不买一台x86平板，然后在上面安装Linux呢？毕竟只要平板设备本身确实采用x86架构，那么我们完全可以随心所欲向其中安装各种软件，对吧？因此，我们在这里先统计一下能够在平板上一展身手的Linux发行版名单。

　　我们弄来一台宏碁Iconia W500平板设备，该产品配备双核1GHz AMD-C50 CPu、2GB DDR3内存以及10.1英寸分辨率为1280 x 800的WXGA电容屏，外加AMD Radeon GMA 6250显卡与32GB SSD。

　　我们希望找到一款能够直接安装在平板设备上且第一时间满足我们全部功能需求的发行版，因此这次比拼的五位参赛选手也全部采用最新版本，它们分别是：Ubuntu、Android x86、Fedora、Kubuntu Active以及OpenSUSE。几款系统或通过U盘或加以安装从而运行在平板之上，我们则通过实际体验观察其各自表现。

**　　Linux的持久生命力**

　　有些人一直在质疑Linux在长远发展环境下的生存能力.christopher Cox结合自己的实践经验探讨了Linux的实用性，从而令这方面质疑不攻自破。我对他的观点深表赞同，因为Linux已经一次又一次证明了自身价值。反对者们仍将继续唱衰Linux的前景，但我们相信（实践也将证明）Linux还会继续陪伴在我们身边--谢天谢地。

　　但看看如今我们身边的设备……我的交换机运行着Linux系统、我的存储子系统以Linux为基础、我的手机也与Linux密不可分。没错，Linux不再只是一套内核、而是一种平台……不，我们更应该将其视为一家解决方案供应商！在Linux的帮助下，我们才拥有了足以解决实际难题的方案。而且不同于一般解决方案，Linux还是一种持久性解决机制，它所遵循的GNU公共许可为知识产权提供无限期保护，这是如今的专有许可软件根本无法企及的目标。换句话来说，Linux不仅充当着当下各类解决方案的核心部分，且永远不会由于企业的不当行为、运营失误或者收购活动而彻底离开我们。

　　Linux就在这里，屹立不倒、宠辱不惊。它默默做出贡献，帮助世人将日常生活变得更加美好。作为一位以Linux为基础编写软件与解决方案的开发人员，我为自己的工作感到自豪。
