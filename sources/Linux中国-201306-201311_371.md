# ffmpeg 图形化界面工具 traGtor

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000860&itemidx=5&sign=2516c818483ffd40554ee29893ade519&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000860&itemidx=5&sign=2516c818483ffd40554ee29893ade519&scene=27#wechat_redirect)

traGtor 是 ffmpeg 的图形化界面工具，可在 Linux 下使用。traGtor 使用 Python 和 GTK+ 引擎编写。

  

![](../Images/3e1f103b1e6f0f9c8f49fe6f9c065dfe.png)

在 Ubuntu 下的安装方法：

> wget http://repository.mein-neues-blog.de:9000/PublicKey  
> sudo apt-key add PublicKey  
> rm PublicKey  
> echo "deb http://repository.mein-neues-blog.de:9000/ /" | sudo tee -a /etc/apt/sources.list  
> sudo apt-get update  
> sudo apt-get install tragtor

来自：http://www.oschina.net/p/tragtor
