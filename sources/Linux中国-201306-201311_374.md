# 甲骨文将停止开发Sun虚拟化技术，但继续开发VirtualBox

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000857&itemidx=2&sign=b1a7cc4eb4df45e028c0b76462ccd0c3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000857&itemidx=2&sign=b1a7cc4eb4df45e028c0b76462ccd0c3&scene=27#wechat_redirect)

甲骨文很快将宣布停止开发Sun虚拟化技术的决定，终止开发的产品包括Sun Ray软件和硬件，甲骨文虚拟桌面客户端，以及虚拟桌面基础设施（VDI）产品线。

甲骨文表示，这一决定是将甲骨文未来的桌面虚拟化投资组合与核心业务战略紧密结合起来的结果，换句话说就是收回虚拟化技术方面的投资和资源，投入到其它业务上面。

未来，甲骨文将投入更多的精力在Oracle Secure Global Desktop 和 Oracle VM VirtualBox software上。
