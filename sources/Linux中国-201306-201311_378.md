# Ubuntu 13.10 桌面壁纸大赛已经正式开赛

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000843&itemidx=3&sign=8d3f9cd2c7dc7969bd652425990e1bb4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000843&itemidx=3&sign=8d3f9cd2c7dc7969bd652425990e1bb4&scene=27#wechat_redirect)

　　GNOME 3.9.4 开发版 (GNOME 3.10 Beta) 发布了，在这个 Beta 版本中，新增加浏览一个 Photos (GNOME Photos) ，这个工具用来显示本地和网络的照片，而且还具有对图片的一些简单编辑功能，不过它并不能作为照片编辑器和管理器来使用，因为它是通过 GNOME 在线帐号 (GOA) 连接到网络服务的。

　　在开发版中包含该工具，说明今年九月份即将发布的 3.10 版本将会包含此工具的最终版本。此外 GNOME 3.10 Beta 还对 Shell 做了一些改动 Chrome 对话框可一直显示在主窗口之上，扩展 Wayland 支持等。
