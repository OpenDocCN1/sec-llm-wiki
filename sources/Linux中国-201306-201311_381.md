# Android 联合创始人：版本碎片化被过于夸大

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000843&itemidx=2&sign=503aec92ea2e522baf238944139b792e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000843&itemidx=2&sign=503aec92ea2e522baf238944139b792e&scene=27#wechat_redirect)

　　北京时间7月13日上午消息，Android联合创始人里奇·麦纳(Rich Miner)本周在“麻省科技领袖委员会”举办的一次会议上表示，Android版本碎片化的问题被过于夸大。

　　业内人士认为，全球数千万Android设备采用多个不同的系统版本，这给应用开发者带来了困扰。不过麦纳表示：“坦白地说，我认为这是一个略微夸大的问题。”

　　麦纳目前是谷歌风投的合伙人。作为Android最初的开发者之一，他做出这样的表态并不令人惊讶。不过他所说的重点在于：由于全球 Android设备数量非常多，因此一定程度的版本碎片化是不可避免的。他表示：“请不要忘记，目前每天有150万台Android手机被激活，而整个市 场上有9亿台Android设备。”

　　不过麦纳表示，谷歌目前已更善于与多家不同的Android厂商和运营商打交道。而在大部分情况下，普通消费者不会注意到使用的系统版本。

　　他表示：“科技圈人士在阅读一些博客后可能会知道，不同版本缺少哪些功能。但如果你去问普通消费者当前的系统是否需要升级，他们可能会对现有的功能和性能感到满意。因此我不确定这是一个重要问题。”

　　Android版本碎片化是困扰谷歌已久的一个问题，从2008年Android系统推出时就已逐渐出现。很明显，手机厂商可以对Android系统进行订制，并用在自己的设备中。这已成为推动Android发展的重要动力。

　　不过谷歌本周报告称，Android 4.1和4.2“果冻豆”系统的市场份额已超过2.3“姜饼”系统，成为用户数最多的Android版本。“姜饼”推出于2010年底，目前主要被用于入门级Android设备。

　　麦纳表示，谷歌近期修复了Android系统的一些安全漏洞，这表明谷歌在与Android厂商的合作中正更聪明。他表示：“在Android 发展早期，谷歌和生态系统，即硬件厂商，需要学习。我认为谷歌现在已经更好，正如我们在最新安全更新中所看到的。谷歌发布了一个补丁，并很快推向所有硬件 厂商。”

　　不过他也表示，新版本的发布仍需要一定时间。“硬件厂商有时略显保守。他们需要确保这些版本得到验证和测试，运营商也是如此。毕竟，如果版本出现问题，接到用户投诉的将是Verizon或AT&T。”
