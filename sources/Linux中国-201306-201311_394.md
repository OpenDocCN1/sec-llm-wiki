# KDE 考虑三个月发布周期

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000818&itemidx=1&sign=5cc23e8da6dfb4c9517dbb68ca52087a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000818&itemidx=1&sign=5cc23e8da6dfb4c9517dbb68ca52087a&scene=27#wechat_redirect)

　　KDE项目正在考虑是否采用三个月的发布周期——即每隔三月释出一个新版。

　　KDE网站上公布了这项提议，表示主要的动机是减少发布之间的时间，以尽可能快的向用户提供新的功能，提议计划4.12版本开始转向三个月发布周期，其中两个月合并功能，一个月测试准 备发布。

　　例如KDE 4.12计划在2013年10月发布beta版，11月15日发布正式版，4.13从10月开始开发，明年2月15日发布正式版。在邮件列表上，发行版openSUSE开发者表达了反对意见，认为会影响打包质量增加维护开销。
