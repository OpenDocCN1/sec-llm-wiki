# Mark Shuttleworth 为自己开发的显示服务器 Mir 辩护

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000818&itemidx=3&sign=278b5072cdc1c2869cb459558bfc6005&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000818&itemidx=3&sign=278b5072cdc1c2869cb459558bfc6005&scene=27#wechat_redirect)

　　Canonica 创始人 Mark Shuttleworth 发表了一篇文章为Mir辩护。

　　Mir 是 Canonica 自己开发的显示服务器，即将于今年十月发布的 Ubuntu 13.10 将默认使用 Mir。

　　Shuttleworth 认为，存在竞争有益于健康发展，他相信 Mir 能比竞争对手（aka Wayland）发展更快，部分原因是他们可以自己做出决定，不受条条框框的限制。他举例说，一个严格僵化的协议只能扩充，Mir 及其 API 实现则可以随时间而演变，以改进性能，而一个已固定的协议则无法做到这一点。
