# 教学生认识云端技术的 PiCloud

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000783&itemidx=2&sign=6ff2ccd482d794ee36ea310741edbb95&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000783&itemidx=2&sign=6ff2ccd482d794ee36ea310741edbb95&scene=27#wechat_redirect)

　　一直以来云端技术都是高深技术，但多得硬体和软体的成本下降，现在一般人都可以接触得到此等技术了。有人就利用了56枚售价35美元的开源微型电脑Raspberry Pi，组成了一个低成本的Linux群集。

　　这个Linux群集名为PiCloud， 利用了LEGO作为“机箱”，制作它的是美国格拉斯哥大学电脑技术学院(School of Computing Science)，作为教材之用，让学生从中了解Amazon AWS等云端技术的运作。PiCloud共56枚的Raspberry Pi，收纳在LEGO制的四个机箱内，并以16条Ethernet连接。当中14条连3到Pi的网路，另外2条连至集线器。各Pi使用Raspbian Linux为作业系统，运行3个LXC虚拟机器。在PiCloud上连作的是lighttpd、lookbusy和Hadoop。
