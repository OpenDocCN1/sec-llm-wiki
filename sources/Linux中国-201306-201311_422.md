# RMS：千万别要孩子

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000777&itemidx=3&sign=5284ce3e1790cb47de2cb43e4cc05f49&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000777&itemidx=3&sign=5284ce3e1790cb47de2cb43e4cc05f49&scene=27#wechat_redirect)

作者介绍：理查德·马修·斯托曼，美国自由软件运动的精神领袖、GNU计划以及自由软件基金会的创立者。作为一个著名的黑客，他的主要成就包括Emacs及后来的GNU Emacs，GNU C 编译器及GDB 调试器。

我决定不要孩子。我小的时候，家里经常因为我吵架，我发现其他很多家里也都是这样。这样的家庭生活没有人会向往。长大后，我发现父母们经常谴责他们的孩子，不要跟我玩，甚至在我附近玩耍，他们认为这样会打搅我——我说不妨碍他们也不理会。谴责孩子成为了他们根深蒂固、不由自主的习惯。看到他们这样我很忧心，但我知道我也会成为这样的父母。面对一天到晚哇哇哭的孩子，我不可能不闹心和生气。

当然，很多人会告诉他们自己，“这事情只会发生在别人身上，我会比他们做的好；我会正确的处理这样的事情。”很显然，这种想法大部分都是错误的。我们不可能假设当大多数人都处理不好这种事情时自己能处理好。

![](../Images/9e39ee09725d8cb17a60fd011b733d17.png)

在美国，大多数的父亲都不得不非常努力的工作挣钱来供养他们的孩子。我不希望我的生活变成每天骑着单车去做那些人们告诉你的任何能挣钱的事情。

在美国，很大比例的父亲们最终选择离婚，之后很少去看望他们用所有时间去挣钱来养育的孩子。如此徒然的生活！但即使那些没有离婚的父亲也很少看他们的孩子，因为他们的工作太忙。

我相信，为了避免这些，我做出了一个明智的个人决定。但并非只有我个人应该这样做。所有人都可以。不要孩子对整个人类都是重大的贡献。我的这个决定使得到2050年地球上至少少出生5到10个人。

人口过剩给人类文明和整个生态环境带来了巨大危险。它造成了愈来愈大的人为产生的生态问题。人口的膨胀虽然在减缓，但没有停止。到2050年，人类人口预计会增加20到30亿，还不清楚去哪里为这些人找到足够的粮食和淡水。人口的增长还使得控制全球变暖变得更加困难。

因此，是否要孩子——对大多数人来说他们生命中最重要的决定——直接影响着将来人类资源的消耗。(Nina Paley said it graphically.)

不要孩子使得我能在其它方面做出贡献：启动GNU和自由软件运动。没有牵挂，我可以全身心的投入到那些看起来比某些人拿着钱让我去做的事情更正确的事业中去。你能读到这篇文章，是因为我的这个决定使得我能够去贡献一些人们喜欢的东西。

我非常希望你们也能做出我这样的决定，不要孩子。我不是希望所有人都不要孩子；我不是希望人类灭绝。根本不会有这样的危险；我希望这种呼吁能影响它的数字，而且是好的方面的影响。

![](../Images/7bcfef79bf0d60e11d5db50ec8e3afcb.png)

有人荒谬的说人口下降会十分的危险。他们声称，50年后，所有人都会过上安逸的生活，他们都不会多要孩子(就像发达国家今天的样子)，这样人类人口就会下降。如果这种情况持续1千年，人类就会灭亡。这真的可能吗？

首先，这种猜想无视全球变暖的天灾，无视自然界走向崩溃的趋势。30年后，我们大部分人将会发现食物和水成了问题，更别说避孕了。很难说那时大部分的人能过上像今天欧洲水平的不错的生活。所以，猜测到那个时候人口会下降——因为每个人都过的很舒适，这种可能性很小。

假设我们能够避免天灾，消除贫困，50年后，我们也许会到达每个人都喜欢小家庭的社会阶段。然而，50年后人类的寿命有可能会大大的增长。这意味着低出生率也能维持一个稳定的人口数量。人口过剩的现象变得很容易发生。

头等大事是避免全球变暖和自然界崩溃。不要孩子对此是有益的帮助，而且这会让你有更多时间做其它更多有助于此的事情。
