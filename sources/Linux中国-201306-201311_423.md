# Nginx首次成为全球Top1000网站最受欢迎Web服务器

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000777&itemidx=4&sign=bea51d2ef36f01ae52a587a9d338bb28&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000777&itemidx=4&sign=bea51d2ef36f01ae52a587a9d338bb28&scene=27#wechat_redirect)

Nginx 已被认为是快速且可靠的 Web 服务器。全世界越来越多的高流量网站在选择 Nginx 作为其网站的基石。

据 w3techs 7月 3 日的统计数据表明，在全球 Top 1000 的网站中，有 34.9% 的网站在使用 Nginx，这使得 Nginx 超越了 Apache，成为了高流量网站的最信任的 Web 服务器。

（译注：Top 1000 是指 Alexa 排名。）

![](../Images/a8e1dbcc7feafdfe8eae7ae58582ea90.png "web_server_ranking-1307")

几乎俄罗斯 2/3 的网站在使用 Nginx。在乌克兰、白俄罗斯、吉尔吉斯斯坦和哈萨克斯坦，还有那些 adult.xxx顶级域名的网站，Nginx 也是最流行的Web服务器。在德国和欧盟， Nginx 排第二位的时间已有很长了。

在总体流行度图表上，Nginx 最近的下降，是由于 w3techs 的样本数扩大所引发。Nginx 的受欢迎度实际上是在增加，从 2009 年的 3.6% 增长到目前的 14.2%。

w3techs 还制作了一张反应 Nginx 使用情况变化的图表（下图是部分截图），绿色横条表示“最近改用 Nginx ，之前在使用其他 Web 服务器”；红色横条表示“之前在用 Nginx，最近改用成其他 Web 服务器”。从下图可以看出，从 Apache 改用到 Nginx 的网站最多。但从 Nginx 改用到其他 Web 服务器的比例也不低。如今的站长比较灵活，易适应新情况。

![](../Images/3465a0a3acba10aa222440fb5aa842bf.png "Changes in the usage of Nginx")

Nginx 用户相对迅速切换到新版。在发布 Nginx 1.4 之后两个月，1.4 版的安装量在总量所占比例已超过 10%。而其他Web服务器还在挣扎着向用户证明其新版易于升级。比如 Apache，从2012年7月1日到2013年7月1日，Apache 2.4 安装量从 0.1% 增长到 1.3%，而 Apache 2.2 的安装量却是从 89.4% 增长到 92.8%。

在使用新技术后（比如 IPv6 和 SPDY），Nginx 已比竞争对手要快了。只有 Google Servers 的性能要优于 Nginx，不过那些服务器只是在为 Google 自己服务，其他独立站长并没有使用，所以没有造成多大威胁。

95.4% Nginx 的网站是使用 PHP，比普通水平要高。不过 Ruby 用户也喜欢 Nginx ，44.4% 的Nginx站点是永远了 Ruby。98.7% 的 Nginx 网站是运行在 \*nix 系统上，其中 Debian、 Ubuntu 和 Gentoo 比例排前三。

002 年俄罗斯 Rambler 网站首次部署 Nginx ，11 年后 Nginx 已达到一个重要的里程碑，我们也确信，它在将来还会走得更远。
