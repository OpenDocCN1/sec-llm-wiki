# Firefox再次在性能上打败Chrome

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000770&itemidx=2&sign=0df18892d5b06d7028aa9b4c51307421&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000770&itemidx=2&sign=0df18892d5b06d7028aa9b4c51307421&scene=27#wechat_redirect)

时隔多年，开源浏览器Firefox再次在性能上战胜Chrome。Tomshardware评测了Chrome 27、Firefox 22、IE10和Opera Next四大浏览器。评测对比了四大浏览器的启动时间、页面载入时间、JavaScript/DOM性能，HTML5/CSS3性能，硬件加速性能。

性能测试结果显示，Firefox 22以微小的优势战胜了Google Chrome，Opera Next（基于Chromium）第三，前三相差并不大，但IE10远远落在后面，仅仅略微胜过未更换引擎的Opera 12。在内存效率，可靠性、安全性和标准遵循方面，Firefox也领先于其它竞争对手，其次是Opera Next，Chrome 27、IE10和Opera12.
