# 为 Vim 添加 Sublime Text 的多重选取特性

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000764&itemidx=5&sign=46bb7a85f2eb3fa09c2dce4cfe91d16f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000764&itemidx=5&sign=46bb7a85f2eb3fa09c2dce4cfe91d16f&scene=27#wechat_redirect)

相信用过 Sublime Text 编辑器的朋友一定对它的“多重选取”功能印象深刻吧。 这项功能能够达到“一处编辑，多处更改”的神奇效果。如果你是一个 Vim 控， 那么不必羡慕 Sublime Text 用户，因为现在有了Multiple Cursors 这款 Vim 插件。

![](../Images/cf8feebf8b3cef669761b8a48fdba1c0.png)

在装好 Multiple Cursors 之后，通过按 `Ctrl + n` 来多重选取。一旦 选取完成，便可配合 Vim 既有的命令对其进行编辑处理。最后，按 `Esc` 可以 退出多重选取状态。

此外，你也可以使用 `MultipleCursorsFind` 命令通过正则表达式来进行 多重选取和编辑。

via http://linuxtoy.org/archives/vim-multiple-cursors.html
