# Linux Kernel 3.10 正式发布

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000764&itemidx=3&sign=6b67d4a2f507046998602d42d9da2bef&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000764&itemidx=3&sign=6b67d4a2f507046998602d42d9da2bef&scene=27#wechat_redirect)

　　经过10个RC候选版的测试后，Linux 3.10 Kernel今天正式发布了，据Linus Torvalds介绍，这是近年来Linux内核变化最大的一个版本。

　　相比Linux 3.9，**新版大部分的补丁都是驱动，几乎占据三分之二**，虽然没有新增重大的子系统，不过却有不少新功能，涉及内核、CPU调度器、内存管理、文件系统、网络、Block、Crypto、虚拟化、安全和Tracing/perf。

　　Linux Kernel 3.10官方下载：https://www.kernel.org/pub/linux/kernel/v3.x/linux-3.10.tar.xz
