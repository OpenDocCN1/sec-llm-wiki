# Firefox OS搅局：欲颠覆操作系统APP模式

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000757&itemidx=4&sign=d640c83249c354046e1fb62e57908b20&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000757&itemidx=4&sign=d640c83249c354046e1fb62e57908b20&scene=27#wechat_redirect)

在今年的亚洲移动通信博览会上，Mozilla——著名浏览器Firefox的拥有者，联合西班牙电信以及部分手机厂商，展示了搭载Firefox OS移动操作系统的智能手机。据 Mozilla移动设备高级副总裁宫力介绍，包括中兴、TCL等厂商推出的首批搭载Firefox OS操作系统的手机，将从7月开始在巴西、哥伦比亚、委内瑞拉、西班牙等国家上市销售。此外，LG、索尼等手机厂商也有意向推出搭载Firefox OS操作系统的智能手机。

能够得到全球主流手机厂商的支持，意味着Firefox OS已经敲开了移动操作系统市场的大门。

不过，作为移动操作系统的新兵，Mozilla要想带领Firefox OS真正进入这个被谷歌、苹果两大巨头把控的市场，还有很多难题需要解决，比如，如何快速建立并完善自己的生态系统。

欲颠覆传统APP模式

如今，由谷歌、苹果主导的Android、iOS两大移动操作系统的地位已经难以撼动。

据 Gartner相关统计数据显示，2013年第一季度，Android和iOS仍然牢牢把控着移动操作系统市场，二者的市场份额占全球九成以上。其中，搭 载Android的智能手机销量仍居第一位，约占全球智能手机销量总量的74.4%；搭载iOS的智能手机销量约占全球智能手机销量总量的18.2%。

两大巨头公司对移动操作系统市场的把控，让其他竞争者（尤其是新兵们）很难有抢眼的表现。

微 软Windows Phone阵营的艰难挺进，就是一个例证。Gartner的统计数据显示，在2013年第一季度，Windows Phone的销量约占全球智能手机总销量的2.9%，与Android和iOS相比仍不可同日而语，甚至以0.1%的微弱差距位列由黑莓主导的 BlackBerry操作系统之后。

Windows Phone高歌猛进了两年但迟迟未能打开局面的状况，向移动操作系统市场的新进入者们证实了一个道理：入局容易，搅局难——开发一款智能手机操作系统相对容易，但新建一个生态系统则实属困难。

在这种环境下，新兵Firefox OS如何搅局？

“Firefox OS是基于HTML5技术的完全开源的移动平台，而这正是我们的优势所在。”宫力在采访中强调。

据了解，Firefox OS是一款基于Linux的、完全由Html5支撑的“网页版”操作系统，可以直接运营网页版应用而无需下载。虽然与Android师出同门，但相比而言，Firefox OS更加开放。

宫力认为，Firefox OS基于HTML5的技术，使得应用开发更为简便。一方面，相比传统APP，WEB版应用的开发较简单；另一方面，开发者基于HTML5技术为Firefox OS开发一款纯WEB版的应用，这款应用将可以同时在Android和iOS上使用。

按 照以上逻辑，如果这种开发方式推广开来，传统的APP模式将有可能被颠覆。“这种方式有利于汇聚大批开发者，应用推广将不会成为Firefox OS操作系统成长的障碍。”宫力认为，这正是Firefox OS未来能够在移动操作系统市场立足的关键，它在建立生态系统过程中的最大阻力将被移除。

也正是这种更加开放的特性，Firefox OS能够吸引一批主流运营商和手机厂商的支持。“它的最大好处是提供了一个完全开放的平台。”中兴通讯执行副总裁何士友认为，这种可以直接运行网页版应用的特点，将为Firefox OS的成长壮大提供机会。

为什么从新兴市场入手

虽然Firefox OS已经得到了部分手机厂商及运营商的强力支持，但也有一些评论认为，“由于对网络连接严重依赖，所以基于HTML5技术开发的应用存在一定的缺陷，很难带来出色的表现，而这也许会成为Firefox OS的致命伤。”

带着这把双刃剑，Firefox OS有必要从市场边缘探路。从首批搭载Firefox OS操作系统的智能手机的上市计划中不难看出，这个移动操作系统市场的新兵正在以新兴市场为起点，开始它的探试、扩张计划。

实际上，这种扩张计划是安全而有效的。宫力认为，在大多数发达国家市场，智能手机的普及率已经比较高了，要想在这些地区的“换机市场”中撼动Android与iOS的地位，其难度可想而知。

而在新兴市场则不然。在这些市场，还存在着相当数量的功能机用户，随着移动互联网及其应用的渗透，这些用户必然愿意将手中的功能机更新换代为价格较低的智能手机。这意味着，Firefox OS可以从这些市场找到机会。

最 新的全球智能手机销售数据，也基本符合上述市场判断。据Gartner发布的数据显示，在今年第一季度，全球手机出货量稳定增长，智能手机继续侵占功能手 机的市场份额；亚太地区正成为全球手机销量增长的最大动力来源，在全球4.25亿部手机销量中，有2.26亿来自于亚太市场，而其他市场的手机销售量都有 所滑落。

不过，任何一个新兵要想真正成为这个市场的强有力竞争者，都不能只依靠低价产品长期徘徊在市场竞争的边缘，必须在中高端领域也有一席之地。

“以低价智能手机进入新兴市场，只是一个开始。”宫力强调，Firefox OS未来必将进入中高端市场。

据Mozilla首批合作运营商——西班牙电信的亚洲首席地区官Caspar Luyten介绍，到2014年，西班牙电信将与Mozilla合作，把Firefox OS推向至少24个国家，包括发达市场。

在不少手机厂商高管看来，除了Android、iOS之外，第三大移动操作系统仍有成长的机会，它可能是Windows Phone，也可能是Firefox OS这样的开放系统最终成长起来。

行 业内的这种判断说明，这个竞争加剧、潜力巨大、机遇广泛存在的移动操作系统市场，并没有真正走到“对两大巨头以外的参与者关上大门”的时刻。移动操作系统 之争，也许还会有更多的参与者。至于谁能赢得机会，只看它能否在短期内搭建并完善一个新的生态系统，并对这些庞大的资源进行有效整合。
