# UNIX大师Evi Nemeth在大洋洲外海失踪

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000751&itemidx=3&sign=41cad7e4d229ccfa6c76b591601733ad&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000751&itemidx=3&sign=41cad7e4d229ccfa6c76b591601733ad&scene=27#wechat_redirect)

计算机系统管理领域圣经《UNIX系统管理手册》和《Linux管理手册》作者、科罗拉多大学退休教授Evi Nemeth从6月4日起就失去联络，她与六位同伴乘着一艘名叫Nina的古老游艇，消失在新西兰和澳大利亚之间的海域。

![](../Images/b4e57e6cf13a46e1063217bb3170c785.png)

Evi Nemeth现年73岁，1971年获得数学博士学位，对密码学以及UNIX和Linux系统管理做出过重要贡献，退休后她经常驾驶着自己的帆船Wonderland在世界各地穿梭。
