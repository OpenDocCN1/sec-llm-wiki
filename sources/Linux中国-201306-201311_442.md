# Xen移交给The Linux Foundation的价值

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000747&itemidx=3&sign=65bdfdff260993fef1dc91d05e377644&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000747&itemidx=3&sign=65bdfdff260993fef1dc91d05e377644&scene=27#wechat_redirect)

4月份美国Citrix将开放源代码虚拟化管理程序“Xen”移交至The Linux Foundation，中立的非盈利性质组织“Xen Project”成为新的母体，其中企业成员除了Citrix以及使用Xen的Amazon Web Services以外，还有Google、Intel、AMD、Cisco、Samsung、Oracle等。  
  
　　参加国际会议“LinuxCon Japan 2013/CloudOpen Japan 2013”而来到日本的Xen.org的社区经理——Citrix公司的Lars Kurth先生，介绍了项目相关移交背景和Xen今后的计划。  
  
　　Lars Kurth先生  
  
　　为聚集志愿者而开放  
  
　　记者：请您讲讲把Xen移交给The Linux Foundation的过程吧。  
  
　　Lars Kurth先生(Citrix/Xen.org)：大约2年前，我们计划进行项目移交，目的是为实现更加开放的项目而聚集志愿者。2010年时有7家公司，到2012年时已经有15家公司参加，不仅Citrix公司，同时还有15家公司一起推动新的Xen Project项目。  
  
　　选择The Linux Foundation是中立的，同时是因为15家公司几乎都参加了The Linux Foundation，并且大家认为比较适合这个项目。  
  
　　记者：企业的参与和支持今后也会增加吗？  
  
　　Lars Kurth先生(Citrix/Xen.org)：比如像Calxeda这样目前尚未参与开发的企业正在新增参与进来，Calxeda是开发基于ARM的高度集成服务器芯片的新兴企业，现在正在通过Calxeda的服务器驱动——Xen进行验证。  
  
　　记者：谈到ARM，Xen是如何应对ARM的呢。  
  
　　Lars Kurth先生(Citrix/Xen.org)：原本Samsung将Xen移植到了ARM，现在ARMv7的虚拟化支持功能安装已经基本结束，目前处于通过各硬件进行验证的阶段。在即将发布的下一版本Xen 4.3中，将作为新功能列举对ARM服务器的支持功能。作为Citrix，也希望能作为企业解决方案参加进来。  
  
　　记者：ARM和Xen的搭配今后会越来越重要吧？  
  
　　Lars Kurth先生(Citrix/Xen.org)：关于ARM的笔记本PC，在Samsung的Chromebook等中搭配有很多Xen。并且，我想今后在网络设备中Xen也会增多，现在Citrix的NetScaler SDX中已经使用有Xen。Cisco参加了Xen Project，所以我对此也非常期待。  
  
　　记者：现在，Linux的虚拟化管理程序主要有Xen和KVM这2种，那么和KVM的关系如何呢？  
  
　　Lars Kurth先生(Citrix/Xen.org)：2个中都有各自所针对的解决方案，开发人数也大致相同，双方互相竞争又互相切磋。我想这是一种健康的状态。  
  
　　记者：Xen有哪些优于KVM的部分？  
  
　　Lars Kurth先生(Citrix/Xen.org)：一个是在安全方面的优势。Xen具有XSM(Xen Security Module)结构，可以直接实现虚拟机隔离。  
  
　　另外还有在存储及网络中通过专用管理域处理客户域I/O的分解功能。通过这一功能即使其中一个有故障或受到攻击，也能够保护主要的管理域。  
  
　　此外，在性能方面也有比较有利的部分，我想Amazon也充分利用了这一优势。  
  
　　记者：Xen在进入Linux内核主线之前，需要给Linux内核打Xen补丁，根据兼容性等问题Linux发行版有不支持Xen的版本吗？  
  
　　Lars Kurth先生(Citrix/Xen.org)：曾经进入过Linux内核主线，通过Ubuntu等现在支持Xen。另外，在CentOS社区和Xen Project、Citrix、Rackspace、Go Daddy中，正在推进面向CentOS 6的Xen包项目，我想RC版也会很快出来。  
  
　　Lars Kurth先生在LinuxCon Japan 2013的Xen展厅  

  
　　Xen 4.3的新功能演示  
  
　　和其他开放源码项目的合作进展  
  
　　记者：您认为Xen今后将会如何发展？  
  
　　Lars Kurth先生(Citrix/Xen.org)：我想会成为The Linux Foundation的Xen Project，并继续与其他开放源码项目开展合作。例如，期待在与组入Linux项目的合作中推进支持ARM。  
  
　　此外，如果参与的企业增加，实机测试和发布或许会更加活跃。近期还在都柏林的Google办公室开了Xen Project的编程马拉松，关于技术及发布等问题进行了讨论。  
  
　　记者：Xen Project今后应钻研的课题是什么？  
  
　　Lars Kurth先生(Citrix/Xen.org)：一个是让咨询委员会的运营更加顺畅，另外，还需要与想参加的企业联系，同时还需要进行宣传，特别是向以前用过Xen的用户宣传。  
  
　　以前所谓终端用户指的是经过Linux发行版的一种关系，今后将会直接联系起来。此外，还希望和CloudStack、OpenStack、OpenNebula等云结构软件构建更好的关系。  
  
　　成为中立性项目的价值  
  
　　David Nalley先生(Citrix/Apache CloudStack)  
  
　　记者：从CloudStack看觉得Xen Project怎样？  
  
　　Nalley先生：虽然CloudStack和哪个管理程序都是中立性关系，但是和Xen的合作增加仍然是一件开心的事。  
  
　　记者：CloudStack于2012年从Citrix移交至Apache Foundation，这样一来开发有所进展了吧？  
  
　　Nalley先生：应该说是有了戏剧性的进展，开发者与用户也在急剧增长，通过Ohloh进行的开放源码社区的活跃性调查也是这样，在Apache中也是“第二大急剧增长的项目”。  
  
　　顺便说一下，Apache CloudStack很快将发布4.1版本，追加了各种功能，我想一定会受到用户欢迎的。  
  
　　Xen也计划在6月份发布4.3版本，这个也有各种各样的新功能，支持ARM服务器也是新功能之一。此外，还支持上级版本QEMU，并改善了libvirt驱动等。  
  
　　记者：像CloudStack那样，Xen也有戏剧性增长吧？  
  
　　Kurth先生：我想是的。  
  
　　Nalley先生：由于成了中立性项目，所以我认为也会增长吧。
