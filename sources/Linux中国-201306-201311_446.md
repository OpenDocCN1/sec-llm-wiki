# 如何在 Linux 下格式化 USB 设备

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000739&itemidx=3&sign=08a892a3faebe5b9fb47c1accb37be00&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000739&itemidx=3&sign=08a892a3faebe5b9fb47c1accb37be00&scene=27#wechat_redirect)

　　很多时候，您的 USB 设备会出现一些错误。大多数时候这些错误可以通过重新格式化设备来消除。出现这种问题的时候，我会使用一个叫 GParted 的软件来重新格式化我的 USB 设备。如果您用 Ubuntu 的 Unity 管理界面，您需要安装一下 Gparted 工具。

**安装命令如下：**

> sudo apt-get install gparted

![](../Images/74c7847f6e93876ab0cf558a32e863e2.png)

　　在得到询问您是否继续的时候，键入 “Y” 来让安装继续。

![](../Images/162392011162f18bb6e33f743753ad07.png)

　　然后等待它下载安装完成。

　　安装完成后，您可以通过如下命令来使用它：

> sudo gparted

![](../Images/b6a6892fd5897b41284de74fe9abd490.png)

　　工具启动后，您可以在菜单中找到您的 USB 设备，点击您需要格式化的设备。

![](../Images/a315fb7be76d80e3d4b9821146e73ca0.png)

　　您可以用鼠标右键来点击您的设备，并选择 unmount 来卸载设备。然后再去格式化它。您可以选择以 “FAT32” 格式来格式化它。

![](../Images/b6218446d26493441e0532b30892c988.png)

　　当然了，格式化设备会导致您的数据丢失，所以在您备份好您的数据的情况下，确认这个操作。
