# 谷歌：被恶意软件感染的网站数量远远大于被攻击的数量

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000733&itemidx=2&sign=f12f4a5eb9777d1543519f63e6185ab1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000733&itemidx=2&sign=f12f4a5eb9777d1543519f63e6185ab1&scene=27#wechat_redirect)

在最新发布的透明度报告“安全浏览”(Safe Browsing)版块中，谷歌指出，现在，**网站被恶意软件感染的发生率要比直接被攻击的发生率高。**

![](../Images/69e98cfe4f2de797f1c9df34bafaaf54.png "Google_Transparency_report_Safe_Browsing_610x293.png")

在最新发布的透明度报告“安全浏览”(Safe Browsing)版块中，谷歌指出，现在，网站被恶意软件感染的发生率要比直接被攻击的发生率高。谷歌表示，通过“安全浏览”的监控，他们发现60%的网站被恶意软件感染，而40%的网站则遭到了钓鱼攻击攻击。

自2009年开始，网站攻击数量不断增加。到了2012年，这个数字从原来的几百个上升到了6000多个。不过到了今年6月，这个数字开始出现下降，目前谷歌检测到的只有3891个。

比较糟糕的是，一些看似安全的网站却已经被感染各种各样的恶意软件。在这个月月初期间，谷歌检测到了39247个被恶意软件感染的网站。现在，修复这些被攻击网站的工作刻不容缓。
