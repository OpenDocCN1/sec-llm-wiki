# 泄露消息证实：IE11支持WebGL和SPDY

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000733&itemidx=3&sign=4f0876bf70d065060da79ec3a5fd5c40&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000733&itemidx=3&sign=4f0876bf70d065060da79ec3a5fd5c40&scene=27#wechat_redirect)

如果IE10令你印象深刻，那你期待微软在周三的开发者大会上为IE11带来什么？**一则来自微软开发者网络(Microsoft Developer Network)订户的泄露消息，似乎证实了将在IE11中所包含的传闻已久的细节。**作为微软的下一个重要的浏览器版本，IE11将随着Windows 8.1在今年年底一同到来，且会纳入在Firefox和Chrome中早已提供的诸多功能。

![](../Images/622c836e7271765fb15953312ccb31be.png "UI-Responsiveness-Report_610x267.png")

根据微软新闻网站(Microsoft-News.com)的报道，IE11将包含对WebGL的支持。WebGL最初是从Firefox开始的一项标准，可使得图形硬件对浏览器的支持更加容易。与当年的"拒绝标准"相比，微软的态度有了明显的改变。

此外，作为微软政策的一个"半逆转"，IE11还将支持Google SPDY。SPDY是一个通过改变浏览器处理站点请求和headers来加快网页加载时间的协议。
