# 调查：移动端恶意软件一年疯长614%

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000733&itemidx=4&sign=42fd5e5fff7a47d747e2e5f0fd4e5dd7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000733&itemidx=4&sign=42fd5e5fff7a47d747e2e5f0fd4e5dd7&scene=27#wechat_redirect)

**在2012年3月到2013年3月之间，移动端的恶意软件增长率高达614%。**截止调查结束之前，移动端在这一年间的恶意软件数量为276259个。而在上一年，恶意软件增长率还只有155%。

![](../Images/3ccde84066fa74b35f63909a01290fbb.png "Screen_Shot_2013-06-25_at_6.33.02_PM_610x395.png")

近 日，调查公司Juniper Networks发布了最新的移动威胁报告。结果显示，在2012年3月到2013年3月之间，移动端的恶意软件增长率高达614%。截止调查结束之前， 移动端在这一年间的恶意软件数量为276259个。而在上一年，恶意软件增长率还只有155%。

Juniper对185万款移动软件及漏洞进行了分析。他们发现，**Android成为了移动端系统中存有恶意软件最多的一个系统--92%的恶意软件感染都发生在Android客户端上。**根 据Canalys统计，Android在全球智能手机市场中的份额高达60%，iOS和Windows Phone占有19%多和18%的市场份额。Juniper指出，造成这一现象的一大原因则是Android用户都不愿意将他们的系统更新到最新版本。 Juniper根据追踪调查获悉，在这个月内，只有4%的Android用户正在运行最新版本的系统。

当然这并不是说其他的系统并不存在任何的漏洞。Juniper指出，即便是全封闭的iOS系统也会存有会被攻破的漏洞。

根据Juniper的报告，大部分的恶意软件攻击都来自于SMS木马。据悉，**48%的攻击则都是由SMS木马引起，29%的恶意软件攻击则来自于虚假软件的安装，19%则来自于木马间谍恶意软件。**其中，Google Play、Skype、Adobe Flash、《愤怒的小鸟》出现恶意软件的频率最高。

Juniper就此还提出了一些建议。它表示，**用户应避免从第三方商城购买软件，还要即时升级系统，另外还不能授权软件获取个人信息的权力。**
