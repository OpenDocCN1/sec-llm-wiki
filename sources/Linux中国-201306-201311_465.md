# 海盗湾创始人被判入狱两年：入侵政府计算机

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000709&itemidx=3&sign=de16b58e265606a48a5c07a66bc17bac&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000709&itemidx=3&sign=de16b58e265606a48a5c07a66bc17bac&scene=27#wechat_redirect)

瑞典纳卡市(Nacka)地方法院周四裁定，文件共享网站海盗湾(Pirate Bay)联合创始人高特弗里德·斯瓦尔托姆·沃格(Gottfrid Svartholm Warg)需入狱两年，理由是入侵瑞典政府计算机，以及非法在线转账。沃格去年被从柬埔寨引渡回瑞典，随后便入狱服刑一年，原因是2009年因互联网盗版而被判刑。随后，瑞典多家机构对沃格提起非法入侵指控。纳卡市地方法院周四在一份声明中称：“沃格的入侵行动十分广泛，且技术高明，许多敏感系统遭到攻击。”

对于这些指控，沃格并未给予否认。对于该裁决结果，沃格的律师表示，将提起上诉。

据检方文件称，今年28岁的沃格非法在线转移了24200丹麦克朗(约合4300美元)。在另外几笔交易中，还试图转移总计683000欧元(约合915500美元)。

2003年，沃格与弗里德里克·尼吉(Fredrik Neij)创办了海盗湾网站，允许用户轻松共享大文件，包括电影和其他媒体内容。随后，海盗湾在瑞典和其他国家遭到了大量的版权诉讼。

2009年，瑞典法庭裁定沃格和其他几位联合创始人有罪，罪名是鼓励侵权。2010年，其他几位联合创始人提起上诉，刑期被减之4个月至10个月。沃格因病未能出席，因此法庭维持原判。

当前，海盗湾网站由一个未知集团运营，域名注册地位于荷属圣马丁。
