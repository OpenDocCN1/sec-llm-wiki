# GitHub融资背后的故事

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000704&itemidx=2&sign=41f9b187c09e1216bb2c0fcccfb21364&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000704&itemidx=2&sign=41f9b187c09e1216bb2c0fcccfb21364&scene=27#wechat_redirect)

创始于2008年的GitHub去年获得了一亿美元融资，当时在业内引起很大的反响。创始人Tom Preston-Werner昨天在Pandodaily的一个大会上发言，分享了GitHub融资背后一些不为人知的故事。

Tom和另两个联合创始人发起GitHub时可没指望过要把它做成一个大公司。GitHub有一定的盈利，让三个创始人在离开各自高薪职位之后仍然可以维持不错的生活水平，这就够了。他们把这个活计称为Lifestyle Business。

另外一个事实是最开始GitHub也只是一个小众市场，他们自己也没有觉得这可以做成一个规模化的商业。

这种想法的后果是，三个人从来没有动过找VC的念头。甚至，在他们“胸无大志”的预计中，未来是GitHub每年可以增加多少营收，他们三个可以各加多少工资，如何在银行户头答应的情况下慢慢多雇一些人。

“我们一开始觉得我们要按自己的节奏和想法打磨公司，不需要别人对我们的做法评头论足。”Tom说，“但是也不知道是什么时候开始，我们意识到不能一直这样没追求了。”

![](../Images/fd530f649619396b04d2e59729e43a2a.png "images_stories_demo_help_your_business_growth")

后来，三个人不再把营收装进自己的口袋，而是对GitHub重复投资，某一年的时间员工人数送14个加到55个——还没融资，幸运的是GitHub的营收也跟公司规模保持相应比例的增长。

> “我们对VC的态度很审慎。VC可以带来很多钱和资源，但是他们希望公司能以他们能理解的、觉得OK的方式去运作，如果你想剑走偏锋，可能就会有麻烦。”

这三个技术出身根本就不认识VC圈的人，没有融资的GitHub也活得好好的。然后就有VC找上门来了，Tom的说法是“不需要融资的公司都是最会赚钱的公司”。

> “融资对于初创企业是很艰难的。但是如果你能向世界证明你做的事情是有意义的，有人喜欢并愿意为它买单，那么你在和VC的沟通中就有话语权了。”获得一亿美元融资的前两天，Tom刚刚做爸爸。

几年前的三个程序员属于那种一人吃饱全家不饿的状态，浪漫得起，傲娇得起，可以牛逼哄哄地说“我不需要VC”。Tom提到的很有意思的一点是：如果他在当下的人生阶段——有老婆和一个刚刚出生的孩子——开始创业，可能第一时间就会想要找VC。
