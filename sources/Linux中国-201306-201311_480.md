# 为什么要用字符~来表示home目录

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000691&itemidx=2&sign=34f3ac9dbefb3e47fad12d4db4b2166e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000691&itemidx=2&sign=34f3ac9dbefb3e47fad12d4db4b2166e&scene=27#wechat_redirect)

在Unix风格的操作系统里(包括BSD, GNU/Linux 和 Mac OS X)，通常用波浪号“~”来表示当前用户的主目录(home目录)：例如，如果当前用户的home目录是/home/bloggsj，那么，输入 cd 或 cd ~ 或 cd /home/bloggsj 或 cd $HOME 都是等效的。这种习惯源自于1970年代流行的Lear-Siegler ADM-3A终端机，这种机器上波浪号和“home”键(用于把光标移动到最左端)正好在同一个键上。
