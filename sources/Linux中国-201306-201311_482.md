# 红帽2013峰会：关于Red Hat Enterprise Linux 7的一切

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000682&itemidx=3&sign=d56cf179cab39b5a306a9bbf07af3beb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000682&itemidx=3&sign=d56cf179cab39b5a306a9bbf07af3beb&scene=27#wechat_redirect)

　　红帽上周在美国波士顿召开2013年峰会，透露了Red Hat Enterprise Linux的未来。

　　Red Hat Enterprise Linux（RHEL）是Linux厂商的核心平台，上一次大规模更新还是2010年十一月的RHEL 6。红帽每隔两到三年就对RHEL进行一次重大发布，在去年峰会上就暗示今年可能发布RHEL 7。

　　据国外媒体报道，RHEL 7的发布日期尚未确定。红帽高层表示公司在RHEL 7上花费了很长时间精力。他强调RHEL 6与5仍然是很强劲的平台，即将更新并替换。RHEL 6.4是刚发布的，提供新的微软互操作性功能。

　　这表示红帽意识到RHEL 7还有大量问题需要解决，可用性方面还能再提升。

### XFS

　　至于功能方面，与之前的红帽版本相比，RHEL 7将更注重前端。

　　红帽另一高层表示，XFS文件系统在成为RHEL 7的默认选择，而不是EXT4。

　　之前还有讨论说可能Btrfs文件系统将在未来Linux版本中扮演重要角色，不过红帽目前表示确保Btrfs准备就绪，成为一个可选项。

　　从Linux内核来看，红帽暗示Linux 3.11将极有可能驱动RHEL 7。目前在Linux社区最新的可用内核是Linux 3.9,据称3.10也即将发布。

### Secure Boot

　　站在硬件角度，RHEL 7将支持UEFI与Secure Boot。

　　RHEL 7也将包括Hardware Error Reporting Mechanism（HERM），通过与各种不同硬件错误输入模式集成，提升服务器登录机制。

### 网络

　　关于RHEL 7的最大提升可能就是网络服务。

　　首先添加了Team Driver。红帽表示驱动器将多个网络接口结合到单个接口中。驱动器的目标是提供提升的吞吐量、网络冗余与简易管理。

　　精密时间协议PTP也将出现在Linux 7里。PTP已作为技术预览版在RHEL 6.4里出现，并能完全支持6.5.

　　如果时间就是金钱，那使用PTP准没错。红帽高层表示。

　　PTP适合高频率交易场景，因为它可确保对跨网络分布式时钟精确到亚微秒的同步。

　　RHEL 7里的另一大亮点是包含Open vSwitch支持。Open vSwitch是个开源的虚拟交换机。将在RHEL 6.5里成为技术预览版，在RHEL 7中获得完全支持。
