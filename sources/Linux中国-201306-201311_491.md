# 使用 Ubuntu builder 来构建自己的 Ubuntu发行版

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10000670&itemidx=1&sign=48eef298e297a80f44eefaad096adbe3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10000670&itemidx=1&sign=48eef298e297a80f44eefaad096adbe3&scene=27#wechat_redirect)

Ubuntu builder 是构建ubuntu 发版版本的一款工具软件，你可以选择制作一个自己的发型版本，可选择i386和amd64版本。

Ubuntu Builder 已经更新到 2.4.0，不再支持 Lucid Lynx 和 Oneiric Ocelot，修复了一些 bug 。

打开终端，输入以下命令来安装：

sudo add-apt-repository ppa:f-muriana/ubuntu-builder  
sudo apt-get update  
sudo apt-get install ubuntu-builder

安装后可以使用该程序来定制你自己的发行版啦！
