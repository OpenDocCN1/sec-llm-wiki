# TrueCrypt审计初步显示没有后门或恶意代码

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200139881&idx=3&sn=82d79f3d02ac77450573755abce0fb2f&chksm=28f1df2f1f865639b5ecf17e27f4ea91a6117e719772599574ba5b398629dfc372c83d8a3ad2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200139881&idx=3&sn=82d79f3d02ac77450573755abce0fb2f&chksm=28f1df2f1f865639b5ecf17e27f4ea91a6117e719772599574ba5b398629dfc372c83d8a3ad2&scene=27#wechat_redirect)

iSEC公布了加密软件TrueCrypt第一阶段的安全审计报告，初步分析显示TrueCrypt没有发现含有后门或其它故意加入的恶意代码的证据。

TrueCrypt是流行的加密软件，但从未进行过安全审计，在NSA大规模监控活动曝光之后安全研究人员发起了对TrueCrypt的完整安全审计，iSEC负责此次审计。研究人员在代码中发现了一些小的漏洞——例如TrueCrypt使用的迭代次数是1000或2000，不足以保护密码抵抗暴力破解攻击——但没有一个大到足以称之为后门。

第一阶段的安全评估重点是TrueCrypt 引导程序和Windows内核驱动等。第二阶段的安全审计将调查TrueCrypt加密套件、随机数生成器和关键密钥算法是否正确实现。
