# Python 2.7支持时间延长到2020年

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200139881&idx=2&sn=c6fd01f3aebdd4e9a77630aadaeaf5d6&chksm=28f1df2f1f8656394d8e58a39ce0edebf5b7d521ab204e4788bcc2cdbc2a873fd417e32c00e5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200139881&idx=2&sn=c6fd01f3aebdd4e9a77630aadaeaf5d6&chksm=28f1df2f1f8656394d8e58a39ce0edebf5b7d521ab204e4788bcc2cdbc2a873fd417e32c00e5&scene=27#wechat_redirect)

Python语言作者Guido van Rossum宣布Python 2.7支持时间延长到2020年。

Python 2.7是2.x系列的最后一个版本，它的继承者Python 3.0在2008年12月发布，但不兼容2.x系列，3.0的许多特性和语法向后移植到了2.6和2.7。Python 2.7的最新版本是2.7.6，2.7.7计划在2014年5月发布，2.7.8计划在2014年11月发布，2.7.9则是在2015年5月，之后将根据需要释出新版本，2.7的支持时间将最少为10年，2020年前会一直提供bug修正。
