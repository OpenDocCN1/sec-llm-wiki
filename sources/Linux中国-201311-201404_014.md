# OpenSSL项目一年只获得2000美元捐款

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200136170&idx=1&sn=4f505f358c09492fe63dbd2ea6854e4e&chksm=28f1eeac1f8667baa05bf9e18dc185e6bfaa2e409c100e7b8eddb80d58f95d1fe88e789bd02c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200136170&idx=1&sn=4f505f358c09492fe63dbd2ea6854e4e&chksm=28f1eeac1f8667baa05bf9e18dc185e6bfaa2e409c100e7b8eddb80d58f95d1fe88e789bd02c&scene=27#wechat_redirect)

全世界有无数公司依赖于开源加密库OpenSSL，其中不乏思科和雅虎这样的科技巨头。但如此重要的一个项目它每年获得的捐款却是少的可怜，连一名美国普通程序员的薪水都支付不起。

OpenSSL软件基金会董事长兼联合创始人Steve Marquess在邮件列表上透露， OpenSSL项目通常一年只收到2000美元捐款。

本周公开的Heartbleed高危漏洞增加了OpenSSL的曝光度，基金会收到了约200次捐款，总额约3000美元，捐款金额从0.02到300美元不等，其中有人多次捐款。他表示，所有的捐款将直接提供给OpenSSL项目团队。
