# 专家神论点：XP退役 侧面反映了美国的衰落

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200132923&idx=1&sn=1ff794a14bcc52799e4d40f3f34ea244&chksm=28f1f27d1f867b6bc9796d0a22d0e5eda9aa49a7d651cec3cdd736083f4fb4d403dff33ad376&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200132923&idx=1&sn=1ff794a14bcc52799e4d40f3f34ea244&chksm=28f1f27d1f867b6bc9796d0a22d0e5eda9aa49a7d651cec3cdd736083f4fb4d403dff33ad376&scene=27#wechat_redirect)

虽然很久前就知道微软的Windows XP系统要“退休”，但这一天真的来到的时候，还是让人深感不适。今天是微软XP操作系统“服役”的最后一天。之后，微软将正式停止对这一系统的安全更新，不再修补系统的安全漏洞。这引发了国内大量网民的安全担忧，甚至有工程师表示，一旦Windows XP停止服务，十分钟内用户电脑便会受到病毒感染。

Windows XP操作系统自2001年问世以来，已运行超过12年。12年间，微软公司已多次对“视窗”系统进行更新换代，最新版本是“Windows 8.1”。

作为微软历史上最为成功的操作系统，XP至今在全球仍有近30%的市场份额，而在中国，使用XP的用户的比例更是高达70%，用户总量超过2亿。考虑到中国这一特殊市场，微软中国此前表示已经采取特别行动，与包括腾讯在内的国内领先互联网安全及防病毒厂商密切合作，为XP用户选择升级到新一代操作系统之前，继续提供独有的安全保护。

一段时间以来，国内不少安全厂商也纷纷表态，承诺为用户继续提供安全防护，推出相关产品解决方案。业内专家表示：应对XP“后遗症”，最一劳永逸的办法是尽快推出国产操作系统替代XP，接管我国2亿台XP电脑用户的服务支撑。

经济之声特约评论员、北京邮电大学经济管理学院、信息经济与竞争力研究中心主任曾剑秋对此评论。

**经济之声**：微软方面表示，安装WindowsXP的电脑尽管不会突然停止工作，但是这款长达13年的产品已经不能满足互联网时代的需求，不足以应对层出不穷且变化多端的网络安全威胁，但是，与此同时，WindowsXP在中国还有2亿用户。大家说，微软XP“退休”，2亿中国电脑开始“裸奔”。微软单方面宣布停止服务是否合理？是否涉及侵害消费者合法权益？

**曾剑秋**：首先我认为这个事件没有那么严重，也不像那么夸张的说电脑要裸奔了。这个事情我个人看到，不应该要那么去太焦虑。首先我们对微软这个XP应该说有一个客观的比较理性的一个判断。XP它时间很长，十多年了，从技术发展的趋势来看它已经不符合时代潮流了。操作系统已经不再是PC、Windows这样的，XP这样的一个独霸独揽天下的时代。现在像安卓、移动互联网都起来了，所以这个应该看到技术发展它是很无情的，它是没有办法。
