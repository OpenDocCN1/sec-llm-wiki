# XP“退役”算什么？50万站点还用着Windows 2000呢！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200128491&idx=1&sn=1d6e83985aa709920f386cabae03d559&chksm=28f18cad1f8605bbe98fce8ab1b0ae83dea7e028eb289611701ec35c807f28c4cf373c6e856b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200128491&idx=1&sn=1d6e83985aa709920f386cabae03d559&chksm=28f18cad1f8605bbe98fce8ab1b0ae83dea7e028eb289611701ec35c807f28c4cf373c6e856b&scene=27#wechat_redirect)

4月8号过后，Windows XP将正式失去微软的官方技术支持。但根据Netcraft的月度统计，实际上，仍然有一大票网站用它作为托管系统。Netcraft的4月调查中，有近6000个网站仍在使用Windows XP作为其服务器操作系统，并且其中有1/3位于美国(其中更有14台为政府相关网站,包括犹他州政府的webmail系统)。

如果你觉得这样已经够糟糕了，下面还有更坏的消息。

相同的调查还显示，竟然有50万站点仍停留在更老的Windows 2000系统上！ 微软早已于2010年停止了对该系统的支持，而其中大多数平台都是采用的Microsoft IIS 5.0 web server软件——与之相对的是，XP平台上的IIS为5.1版本。

最后，本次调查还给出了Windows NT 4.0服务器平台的网站数：你猜有多少？5万个！(其中75%在挪威) 该系统搭载的是Microsoft IIS 4.0，而微软于2004年结束了对它的支持。
