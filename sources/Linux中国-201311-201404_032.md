# 你知道吗？BASIC语言已经有五十岁了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200124126&idx=3&sn=95bc58c5b6ae8f2b57d696e1ffb56296&chksm=28f19d981f86148e3e4b824179fd10dcdf1cb02d86e72819630c89d3fc24d27e11a9a8c95a9c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200124126&idx=3&sn=95bc58c5b6ae8f2b57d696e1ffb56296&chksm=28f19d981f86148e3e4b824179fd10dcdf1cb02d86e72819630c89d3fc24d27e11a9a8c95a9c&scene=27#wechat_redirect)

1964年5月1日凌晨4点，达特茅斯学院的一个地下室内，John Kemeny教授和一名学生程序员在邻近的终端上同时输入RUN，当他们运行的简单程序返回了正确答案，分时系统和BASIC编程语言诞生了。

![](../Images/199af2f3433acdc7034f0caa40320ce0.png)

（图片来自：http://en.wikipedia.org/wiki/File:AtariBasicExample.png）

Kemeny教授、Tom Kurtz教授和一群本科生共同合作，通过创造分时系统和BASIC语言为计算机带来了革命，他们的创新惠及了整个世界。

时至今日，BASIC仍然是一种流行的语言，许多新的语言也都受到了BASIC的影响，比如微软的Visual Basic。
