# 虚幻引擎4.1加入Linux和SteamOS支持

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200120410&idx=3&sn=f4500337c772e78f781b1a6ff2904303&chksm=28f1a31c1f862a0a28dd35c8f726f4f71b702241b0630e45b31dedbe34abf3bbc6346cb31179&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200120410&idx=3&sn=f4500337c772e78f781b1a6ff2904303&chksm=28f1a31c1f862a0a28dd35c8f726f4f71b702241b0630e45b31dedbe34abf3bbc6346cb31179&scene=27#wechat_redirect)

在CRYENGINE引擎加入Linux支持之后，另一个知名游戏引擎开发商Epic Game宣布虚幻引擎4.1加入对Linux和SteamOS的初步支持。

SteamOS是基于Debian的发行版。Epic Game在官方博客上示爱，“我们爱Linux”，称开发者现在可以为Linux和SteamOS平台打包和部署游戏。

有许多游戏工作室使用虚幻引擎制作3A级游戏，其中著名的虚幻引擎游戏包括了《质量效应》系列，《生化奇兵》系列、《无主之地》系列、《羞辱》和《神偷》等等。

CRYENGINE和虚幻引擎4都采用了订阅模式。
