# Ubuntu One文件服务将关闭

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200114509&idx=2&sn=4a4b07e321fb78ea81cbb6af6cde360a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200114509&idx=2&sn=4a4b07e321fb78ea81cbb6af6cde360a&scene=27#wechat_redirect)

Canonical的云存储服务Ubuntu One一直以来受到Ubuntu世界用户的欢迎，同时也是对抗Dropbox、Google Drive和OneDrive的有力竞争对手，不过今天Canonical宣布将要退出这场“免费存储大战”，并将停止提供Ubuntu One文件服务。
