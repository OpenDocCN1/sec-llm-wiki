# Windows XP寿命将近 企业用户依旧淡定

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200109736&idx=2&sn=a34d4c9de6306becd64b8f82b85bad2c&chksm=28f155ee1f86dcf8044a20651f16864db439683afaa3d250785583da868b71454da973682c15&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200109736&idx=2&sn=a34d4c9de6306becd64b8f82b85bad2c&chksm=28f155ee1f86dcf8044a20651f16864db439683afaa3d250785583da868b71454da973682c15&scene=27#wechat_redirect)

还有大约10天时间，微软就要正式停止对Windows XP提供支持了。如果说企业用户仍期望有较好的安全保证，那么或许Windows 7是最佳新选择。当然企业用户也依然可以坚守Windows XP，只是不会再有漏洞补丁发布，XP系统的安全威胁将日益严重。据微软所说，实际上企业用户也没有表现出任何的不安。

微软在很长一段时间内都在试着说服各组织、公司，尽快从陈旧的XP操作系统离开，选择更新版本的Windows系统。本月早前，微软还发布了一张图表用以解释XP升级在失去支持后，升级到新系统的必要性。微软甚至还特意开展过促销活动，为用户提供新版Windows PC的折扣。

不过现在看来，仍有数百万千万的设备在运行着即将过期的Windows XP系统，并且根本就不为微软将停止对此系统的支持而担心。微软英国Windows业务组的领导David Rodger在接受媒体采访时说：“我们没有看到任何的惊慌失措。许多组织会看到倒计时，现在他们可能已经在筹划下一步了。人们最终需要处理这一问题。” 虽然某些企业决定为用户继续提供安全风险方面的保护，不过Rodger认为这只是短期解决方案：“我们已经和一些大型组织探讨过，这是其中一个选择，但这并非长久之计，所以只能作为没办法的办法。”他建议企业尽快搬迁到更新的操作系统平台。“Windows 7是非常不错的操作系统，如果要说生产力、移动性、安全性和连通性，那么Windows 8.1是最佳选择——这款系统还对触控提供支持，同时也支持传统桌面环境。”

微软即将在4月8日停止为Windows XP系统在全球范围内提供后续支持，也就是说未来XP将不会再收到来自微软的系统更新，系统将遭受安全威胁，即便中国似乎是个例外。
