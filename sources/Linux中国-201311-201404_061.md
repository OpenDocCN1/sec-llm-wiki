# Ubuntu 14.04 Final Beta 测试版本发布已提供下载

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200107373&idx=3&sn=ae87d1107643393388fac09b15b07ad3&chksm=28f15e2b1f86d73d9d74724713cf30244b547c75ebeab4640b72ce72a872aa3dbc9a9af1dbf8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200107373&idx=3&sn=ae87d1107643393388fac09b15b07ad3&chksm=28f15e2b1f86d73d9d74724713cf30244b547c75ebeab4640b72ce72a872aa3dbc9a9af1dbf8&scene=27#wechat_redirect)

Ubuntu 14.04 Trusty Tahr 最后一个测试版本已经发布，并已提供下载，正式版本将在4月17日发布，在正式版本发布之前还有一个候选版本RC，在4月10发布。

该测试版本对 Unity 桌面有一大堆的改善。

![](../Images/1d8007d105e9e97160e86b445ac4011e.png)

注：这是 Ubuntu 14.04 唯一的测试版本，也是最后一个测试版本，尽管官方给出的是Beta 2版本号，因为在之前 Lubuntu、Kubuntu、Xubuntu发布过Beta1，但不包括 Ubuntu Unity版本。
