# OSTC 2014 见闻随笔

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200107373&idx=1&sn=5d5eec9201eaba2f69d148d4119aac50&chksm=28f15e2b1f86d73dfc25fc8dd67462a41115ed5d1999d41c425a63bc6df0dd56dbad4b084e0d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200107373&idx=1&sn=5d5eec9201eaba2f69d148d4119aac50&chksm=28f15e2b1f86d73dfc25fc8dd67462a41115ed5d1999d41c425a63bc6df0dd56dbad4b084e0d&scene=27#wechat_redirect)

今天一早就到了OSTC 2014的会场，基本上认真参加了一天的会议而没有睡觉。:>

说说我的感受吧。

 

### **最受欢迎的是Larry Wall先生**

从会议开始前的签名、合影，到Larry先生赢得了持续最长最响亮掌声的讲演（Larry的讲演是我见过真正的讲演稿，而不是国内大家惯常的PPT），甚至在下午会议间隙，还不断的有大把的人去包围他，要求合影，而Larry先生也态度极其温和，和其善良的夫人，来者不拒，和大家亲切合影。要不是我英语实在太渣，我都想上去和他聊两句——这是我这次会议的第一个悲哀：英文不好 :<

![](../Images/b4afe29f3ae5c6c49bee68f3c83b175d.png)  
专门让Larry给签名到小册子上，因为地方太窄了，Larry 签名前还专门琢磨了一下。

![](../Images/e6af4fac6296610a425f03dd5daf8afd.png)  
Larry演讲过程中不断切换到桌面的终端里面，瞧，这是WORKSPACE 14，话说我从来没建立过那里多的WORKSPACE呢。然后我发微博让大家猜Larry用的什么系统，大家猜了半天问我，我说也不知道，没好意思去问——结果被吐槽了:>

### **最被吐槽的腾讯讲演**

其实从会议前，大家就有不少人对腾讯的讲演内容有些不同的猜测或者期许。不过，结果发现在微博上被吐槽最多的就是腾讯的消息了，比如说，“内部开源”什么的，哈哈，恶意未必，不过也反映除了社区对腾讯的又爱又恨的态度。

### **草根化的大会**

会议前，蒋总就说了，这是第二次的OSTC，不要像过去一样，请来各种政府高官什么的，有意识的深入社区。这一点从各个开源社区都纷纷捧场可以看到出来，值得称许。不过，也有个别的演讲，包括演讲内容和控场能力，感觉确实还有需要仔细磨合的余地。此外，也感觉社区中真正的意见领袖还不够突出和显著，中国的开源界还很弱小。

### **我的渣渣手机**

好吧，这个是我个人的问题:<

具体大会的情况，我就不细说了。不过这次大会我还有第二个悲哀：手机太渣了。之前一直不是很在意手机拍照，反正手机相机启动得也慢，也没啥好偷拍的，所以根本无所谓。不过今天发现想拍点照片时，结果这渣手机，不但诸网友看不下去了，连我自己也痛悔不已，丧失了多少好镜头啊。:<

最后出来的时候，发现门口有一个展板，上面有咱“Linux中国”的LOGO，赶快拍下，哎，我的破手机哎。

![](../Images/29b249649c309a9d90761542268c1bb0.png)![](../Images/2552d33cbce19071269a995fb7f77224.png)  
好了，吐槽完毕啦~
