浦发银行，升级还是退步？

今天登录浦发银行个人网银，却突然发现已经无法登录了！

原来，昨晚浦发已经对其网上银行的安全控件进行了升级，不再支持 Linux 系统！

下午给客服打了个电话，对方也只能明确表示，目前就是不支持 Linux 系统了。

真不知道这到底是升级还是退步！

当年就是因为浦发银行的网银对 Linux 的支持好，才用的它。现在浦发却逆潮流而行，将 Linux 用户拒之门外，实在是搞不懂！

 

本来现在各家银行就承受着来自余额宝等理财产品的冲击，浦发这样搞，真是作死的节奏！

当然啦。人家肯定觉得咱浦发的 Linux 用户太少，完全不在乎。那我也只好准备销户了，反正这样一搞，浦发相比其他银行，对我而言已经没有任何优势了！
