# 印度泰米尔纳德邦政府部门考虑从XP迁移到Linux

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200095806&idx=4&sn=5309b3f501bd56ced5b5ed5b967fbc97&chksm=28f103781f868a6e02f63f57bb53ad49919445561c6fb9142d88e02ebb8442c4bdcd4df04229&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200095806&idx=4&sn=5309b3f501bd56ced5b5ed5b967fbc97&chksm=28f103781f868a6e02f63f57bb53ad49919445561c6fb9142d88e02ebb8442c4bdcd4df04229&scene=27#wechat_redirect)

印度媒体报道，微软将于下个月停止支持Windows XP，印度泰米尔纳德邦已建议所有政府部门从XP切换到自由软件BOSS Linux。BOSS代表Bharat Operating System Solutions。  
泰米尔纳德邦信息技术部在命令中称， BOSS Linux是开源操作系统，可以根据需要进行修改。它表示，相比购买闭源操作系统，切换到Linux发行版可以节省政府的大量资金。  
微软印度表示，它已经支持了Windows XP，现在是时候投入资源支持更新的技术。
