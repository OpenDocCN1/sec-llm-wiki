# Valve 刚宣布 SteamOS 基于 Debian 分支

SteamOS 这是一款完全基于 Linux 的游戏机系统，Valve 要发布基于 Linux 的游戏系统 SteamOS 由来已久。经过一段时间的开发，SteamOS 有了很大的变化才最终成为一款满足游戏的 Linux 系统。

![](../Images/5c856a3b85e4278bcd48e6eb5293996a.png)

一天前，Valve 宣布 SteamOS 是基于 Debian 的 Linux 发行版，在这款系统上已经做了很多工作，按照开源社区所使用的开放规则进一步的完善。

早在2013年12月 Valve 就发布了第一款测试版本（基于Debian wheezy (stable 7.1)），而第一个版本（ SteamOS 1.0 ）被称为“alchemist（炼金术士）” ，基于Debian ‘wheezy’ （稳定7.1 ）的分支。

很多人可能会想， SteamOS  为什么不基于其他系统，像 Ubuntu ，而是基于 Debian 分支，主要是因为  Debian 分支有 SteamOS 所需的东西能够更好的兼容游戏。
