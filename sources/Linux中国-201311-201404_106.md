# HackRF One在中国

HackRF是一款全开源的硬件项目，其目的主要是为了提供廉价的SDR(软件定义无线电)方案，作者Mike Ossmann在第一版HackRF Jawbreaker时通过Kickstart融资成功，之后Mike Ossmann开始进行了第二版HackRF One的开发。

![](../Images/06567a98a353ec0b04325792ad2e6e3a.png)

目前已经进入最后的阶段，这个开源项目的代码和文档都在github上，2014年3月13日一个名叫星天无限的中国厂商"提前"发布了HackRF One，现在已经可以在掏宝上购买，可以让那些错过Kickstart预定的黑客们可以有其他途径获得HackRF One进行hacking。

另外2014年3月15日的HFD(硬件自由日)将会有HackRF社区的contributor王康同学(不是原作者)来分享HackRF One的有趣故事。这次北京的HFD有2个场地，一个是由TUNA举办的，一个是由BLUG(北京GNU/LInux用户组)举办的。
