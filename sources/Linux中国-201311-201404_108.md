# 为维持基于XP系统的ATM运转 众多银行向微软支付高额费用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200080679&idx=1&sn=c45dc8aac7c88586588ec013671336b2&chksm=28f0c6611f874f77d84db521bb687f450930746a04ac620c6edab48d2fa49aebdb89a946388e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200080679&idx=1&sn=c45dc8aac7c88586588ec013671336b2&chksm=28f0c6611f874f77d84db521bb687f450930746a04ac620c6edab48d2fa49aebdb89a946388e&scene=27#wechat_redirect)

目前大部分的ATM取款机依然在使用Windows XP系统，在美国和英国的银行为了能够继续使用决定延长同微软的合作，在4月8日微软正式停止XP系统支付后通过支付额外费用的方式进行保持ATM机器正 常运转。援引路透社报道称英国五大银行（劳埃德银行集团，苏格兰皇家银行，汇丰银行，巴克莱银行和桑坦德英国）每家银行可能会向微软支付1亿美元用于维持 ATM机器安全运转，并且制定部署将ATM机器升级到最新系统。微软为此还为包括银行在内的大型企业提供了名为“Custom Support”的服务，能够帮助这些公司在XP停止服务之后推送最新的安全补丁和相关的升级部署。

![](../Images/23b462e5d11b71663eab9cd030e40bae.png)

此外在美国摩根大通表示将会在今年7月份开始升级旗下的ATM取款机的系统，整个部署升级项目有望在2014年底完成。摩根大通的发言人并未透露向微软支付了多少费用用于升级。包括美国银行和花旗集团在内的大型银行机构也表明将会同微软进行合作升级旗下的ATM机器，但是拒绝透露整个升级费用。
