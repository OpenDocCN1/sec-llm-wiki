Linux 基金会推出 Linux 入门 MOOC

原文：http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200068504&idx=1&sn=2f68b6f61d3ccb8d9341ee7b8cedbad1&chksm=28f0f6de1f877fc8583239eef2a32ee58f796bf2f447bd0509a17f51a175d5d517601a9d31c3&scene=27#wechat_redirect

Linux 基金会宣布将在 edX 平台上推出一系列 Linux 为主题的 MOOC 课程，通过专业水准的高质量 Linux 课程使得更多的人了解 Linux 系统。此次 Linux 基金会联合了来自 AT Computing, Enea, OlinData 及 SolutionWare 人员组成授权培训组，将在 edX MOOC 平台上推出一系列课程。和大多数 edX 上的课程一样，这个也是完全免费的。

首个课程为 Introduction to Linux （LFS101） 将于 2014 年第三季度上线。该课程将传授通过命令行和图形界面操作 Linux 系统的的方式，覆盖三个不同的发行版。

Linux 基金会将仍然通过自有平台推出免费 Webniar 及认证培训等针对从业人员的培训服务，和 MOOC 课程目标人群并不相同。
