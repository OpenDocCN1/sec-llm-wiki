# 传微软打算推出Android版IE浏览器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200066541&idx=2&sn=f946056511f7d67465db158843119fbb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200066541&idx=2&sn=f946056511f7d67465db158843119fbb&scene=27#wechat_redirect)

大部分统计机构的数据仍然显示，微软的IE浏览器仍是全球市占率最多的桌面浏览器。自2013年10月份，IE11发布以来，其全球范围内的市场份额就已经达到了21.73%，全部IE版本的份额加在一起，市占率则总共有59.19%。不过由于移动市场发展火热，国外媒体今天有消息称微软当前正准备推出Android版的IE浏览器。

Twitter用户@dovellonsky推文消息称，微软或将发布一款运行在谷歌Android平台之上的浏览器产品，Android目前是智能手机行业中市场占有率最高的移动操作系统。 外媒Technie News报道称，这可能是微软在移动应用领域迄今为止最为大型的项目之一。不过这项传言当前并没有可信的证据。这名Twitter用户也没有提供任何微软或谷歌方面的链接，并且承认“尚无公众资源”可确认此传言。即便此传言不可靠，或者也将促使微软考虑在其他平台上推广IE浏览器，毕竟智能手机市场实在有着很大的吸引力，也能成为微软掌握更多移动市场资源的重要筹码。
