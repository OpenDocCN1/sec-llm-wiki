# Linux版Chrome默认关闭视频加速理由是GPU驱动太烂

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200066541&idx=4&sn=093edf0cc39d747a7845592c1b512666&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200066541&idx=4&sn=093edf0cc39d747a7845592c1b512666&scene=27#wechat_redirect)

Google Chrome/Chromium开发者在短时间内不会默认启用Linux版浏览器的视频加速功能，理由是Linux上的GPU驱动太烂。Chrome的视频加速代码早就写好了，但默认永久禁用。有人向Google递交bug报告， 建议将视频加速支持的控制转移到GPU黑名单，由黑名单决定是否启用视频加速。

但Chrome开发者Jorge Lucangeli Obes 说，在Linux上支持GPU功能简直是噩梦，认为目前启用这项功能会影响浏览器的稳定。Google认为，即使是GPU白名单也会影响用户体验。 Google开发者的观点引发了争议，认为这一借口其实站不住脚，为什么Mozilla的开发者没有抱怨GPU驱动的问题？
