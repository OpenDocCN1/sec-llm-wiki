# 快速技巧：如何在 Ubuntu 13.10 下启用 VLC 桌面通知

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=200056188&itemidx=3&sign=496bb6f89ee5913eb7f3c3c4c654006b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=200056188&itemidx=3&sign=496bb6f89ee5913eb7f3c3c4c654006b&scene=27#wechat_redirect)

我必须说 VLC 是目前最好的视频文件播放器。VLC 播放器有许多隐藏特性你可能还不知道。其中一个就是桌面通知。在本教程中,我们将会看到**如何在 Ubuntu 13.10 和其它版本下启用 VLC 桌面通知**。

### 在 Ubuntu 下启用 VLC 桌面通知:

要想在 Ubuntu 下启用桌面通知,依照下面步骤进行:

#### 步骤 1:

打开 VLC 播放器。在顶部菜单内,进入 **Tools**，接着进入 **Preferences**。

**VLC->Tools->Preferences**

![](../Images/a8e0a5c636eca2290592b66dafd3dab1.png)

#### 步骤 2:

选择底部的 **All** 按钮:

![](../Images/42caf39adf08e36819ff28dfc7375a0f.png)

#### 步骤 3:

现在从左边栏中选择 **Control interfaces**。在这里,选择 **LibNotify Notification Plugin** 并保存。这个会在带 Unity 的 Ubuntu 中启用桌面通知。

![](../Images/78628a535e3685dba899315ec97d95e4.png)

默认通知会显示4000ms也就是4秒。你可以通过控制接口下的通知选项来更改。

![](../Images/5adf968d8ce0fdc04bd5392cf1b69a7c.png)

就这么简单！你可以在播放音频或者视频文件的时候看到通知。它与 Ubuntu 环境完美地整合在一起:

![](../Images/2ef73ef4b20832196abb413f5b2ebca3.png)

我希望这个启用桌面通知的快速技巧能使你的 VLC 更加 Ubuntu化，更加时尚化。你觉得如何?
