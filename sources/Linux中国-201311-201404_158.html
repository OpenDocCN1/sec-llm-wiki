Github 为开发者发布 Atom 文本编辑器

原文：http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=200053275&itemidx=2&sign=ca9685ac1692c8a72c05ceba91319022&scene=27#wechat_redirect

Github 今天发布了一个名为 Atom 的全新在线文本编辑器。编辑器采用全新域名 atom.io 运行。据说 Github 内部已经使用 Atom 六年时间。目前 Atom 暂时只接受邀请注册使用。

在文章 announcing the new editor today 中，Github 称 Atom 之前只是一个试验性项目，而后迅速发展成实用工具。而且 Atom 是完全开源，Github 鼓励开发者对它进行扩展。

Mac 版的 Atom 还在封闭测试中，而 Windows 和 Linux 构建版本 很快面世。你可以先在 Atom.io 网站上注册，随后几周内他们会给你邀请。
