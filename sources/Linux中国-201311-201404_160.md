# RSA年会上谷歌微软达成一致意见：云服务已足够安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200050135&idx=2&sn=91c868deb583ab3499e6d9f9556a5c1b&chksm=28f0be911f87378723894cc4496c5e91f3e14598d58dd584cbed5fc023b92b544d869a0d1219&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200050135&idx=2&sn=91c868deb583ab3499e6d9f9556a5c1b&chksm=28f0be911f87378723894cc4496c5e91f3e14598d58dd584cbed5fc023b92b544d869a0d1219&scene=27#wechat_redirect)

在周三于旧金山莫斯康会展中心召开的RSA年会(annual RSA Conference)上，Google和微软已经在某件事情上达成了一致，即“云服务现已足够安全，人们可以放心使用”。微软首席信息安全官Bret Arsenault、以及Google应用安全主管Eran Feigenbaum、云安全小组、独立安全专家Bruce Schneier、以及Verizon数据泄露风险小组专家Wade Baker等人均表明了同一立场。  

  

![](../Images/258c2ecba018d2e06cda49eba46f5cdb.png "2014_RSA_2014_cloud_security_panel_610x367.jpg")

  

由左至右：Bruce Schneier、独立安全分析师、Google方面的Eran Feigenbaum、Verizon代表Wade Baker、以及微软方面的Bret Arsenault。

Schneier表示，云安全完全取决于公司构建强大信任的能力：“本质上说，‘云’意味着你的数据存储在别人的硬盘上；而我，又是否该相信其他法律实体呢？这种信任水平与人们常年见到的是有所不同的。如果服务提供商撒了谎，我们的安全就是一纸空文”。
