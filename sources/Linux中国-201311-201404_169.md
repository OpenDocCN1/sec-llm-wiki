# 妈妈再也不用担心我的编程 学习游戏CodeCombat 开源

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200039540&idx=2&sn=a9ea3b8e2e9094e9a6854265b87878e9&chksm=28f067321f87ee24900ac612b781428478884162b37dc2ff216bbc8bc7e297935dfcd59e8877&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200039540&idx=2&sn=a9ea3b8e2e9094e9a6854265b87878e9&chksm=28f067321f87ee24900ac612b781428478884162b37dc2ff216bbc8bc7e297935dfcd59e8877&scene=27#wechat_redirect)

对于很多人来说学习代码是非常枯燥的事情，但如果将学习过程变成游戏的方式是否变得非常有趣了？曾共同合作在2008年发布中日学习应用Skritter 的George Saines, Scott Erickson和Nick Winter三名程序员在去年发布了名为“CodeCombat”的编程学习游戏，这是一款Web网页游戏。近日宣布该游戏正式开源。

![](../Images/be1d4f9f5691ad937e83bb5ec2450092.png)

在游戏中你将控制多个英雄进行作战，不过和传统使用鼠标控制不同的是里面所有英雄的动作都是需要使用Javascript代码进行触发。

团队在网页上写到：“你是否需要学习代码？你不再需要任何传统课程。你只是需要敲入大量的代码并享受愉快的游戏时间。这个游戏的内容就是让学习变得更有趣。”
