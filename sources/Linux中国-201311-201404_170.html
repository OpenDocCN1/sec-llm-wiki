Firefox OS，在利基市场匍匐前进

Android、iOS 和 WP，喜欢听新故事的人们看到这几个词或许有些厌倦了。来点儿新料吧，Firefox OS、Ubuntu ，还有 Sailfish OS 便是大鱼大肉之后的清新小菜，只是 Ubuntu 要等一阵子才有搭载机型，Sailfish OS 定位高端，只有一款 Jolla 手机问世，仅有 Firefox OS 看起来丰满一点儿。

只是在 Android 和 iOS 的阴影之下，连背靠大树的 WP、BB 和 Tizen 都活得并不轻松，更何况大腿还没别人胳膊粗的那些小众系统。距离 Firefox OS 手机问世近一年来，来看看 Firefox 的生存状况。

首先可以肯定的是，Firefox OS 份额很小，排在 Android、iOS、WP、BB 之后的“Others”之中，以至于市场调查机构 Gartner 都无法统计到具体的出货数量。之前我们的新闻倒是会关注一发售就被“抢购一空”的 Firefox OS 手机，销量多为几千台，成不了气候。

不过这并不是意味着 Firefox 手机没有人要，Mozilla 也算是有些影响力的组织，在和 Mozilla 关系不错的运营商 Telefonica 的势力范围内，Firefox OS 手机有着不错的表现。去年，Firefox OS 手机占到了委内瑞拉智能手机销量的 12%，哥伦比亚智能手机销量的 8% 以上。对于初生儿来说，能有这样的成绩已经很不错了。

低端、利基市场和运营商，这无疑是 Firefox OS 生存的关键词。在 Android 新手机基本迈入 1GB 内存的时代，Firefox OS 居然还支持最低 128 MB 的内存。而去年发布的几款 Firefox OS 手机的配置放在 Android 阵营的话，基本处于被淘汰的状态。更令 Firefox OS 感到危机的是，赖以生存的低价策略就要失效了，低端 Android 的价格下潜得非常厉害。所以，Firefox OS 生存空间被挤压得非常小，只能依靠运营商关系在委内瑞拉这样的小市场获得发展。

还有一个问题就是 Firefox 终端的体验问题，因为定位低端，这些手机通畅分辨率低，处理器老旧，难以提供优秀观感和性能，屏幕尺寸和拍照素质也离主流较远。Firefox OS 系统刚刚起步，还有非常多需要完善的地方，比如首批开发者版本 Firefox OS 手机 Geeksphone Peak 基本就处于不可用的状态。

不过想想 Android 刚出生的状况，Firefox OS 也不可能是一个含着金钥匙出生的富贵小子。好在 Firefox OS 诞生之初就获得了不错的资源支撑，使得其背后力量不像 Sailfish OS 或者 Ubuntu 那么单薄。除了已经推出了 Firefox OS 手机的中兴、Geeksphone、LG 和阿尔卡特之外，华为和索尼预计也将在今年推出自己的 Firefox OS 手机。单从这个阵容来看，还是颇为有实力的。

除了终端厂商支持，对于 Firefox OS 而言，更重要的一股势力是运营商，除了上文提到的，在西班牙、委内瑞拉、哥伦比亚和巴西有影响力的 Telefonica 之外，在波兰、希腊、匈牙利有影响力的 Deutsche Telekom，意大利的 Telecom Italia 等运营商也在支持 Firefox OS。对于 Web 有所偏重的 Firefox OS 是运营商卖数据流量的理想载体。

包括离我们较近的中国联通和富士康在内，支持 Firefox OS 的大厂商有 20 家左右。不过毕竟是生意，这些厂商在资源上对于 Firefox OS 的倾斜还非常有限，而 Firefox 需要完善的空间还有很多。

去年的消息是，Firefox OS 将会学习互联网速度，在系统上有三月一更新的速度，但是从今天得到的消息，中兴将要发布的 Open C 手机仅搭载 Firefox OS 1.3，看起来在系统完善上，Mozilla 做得还不够。

从 Windows Phone 在拉美和欧洲部分国家取得不错成绩来看，Firefox OS 的市场表现有很多类似的地方，这些新兴的较小市场更容易打开一些。至于中美日韩这些价值巨大的市场，要么门第森严，要么厮杀激烈，Firefox OS 想要正儿八经地占有一席之地谈何容易。

即使处于这么一个委身于较小国家低端市场的处境，Firefox OS 表示还将进入到平板以及智能电视市场中去，不过走都没学好就想跑明显不靠谱。

那么一个健康的系统所处的生态环境应该是有功能完善且稳定的系统做基础，有大厂商的高端机型来支撑，有活跃的开发者提供应用，同时还要有大批消费者为其买单。这么看的话，Firefox 一点都不占。

不过，Firefox OS 出生才一年而已。
