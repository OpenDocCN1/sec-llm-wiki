# 《Crysis》要走向Linux？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200035241&idx=1&sn=8824b9280754ca4bb52afc69660b78d3&chksm=28f070ef1f87f9f9c2e8f08c554a0173331fc00c5c5a3b6ba4f55a1bb6187abc68219a0c50e2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200035241&idx=1&sn=8824b9280754ca4bb52afc69660b78d3&chksm=28f070ef1f87f9f9c2e8f08c554a0173331fc00c5c5a3b6ba4f55a1bb6187abc68219a0c50e2&scene=27#wechat_redirect)

Crytek公司的游戏引擎CryENGINE已经发展了三代，以其先进的图形技术、高超的画面效果而著称，还在努力发展游戏主机，购买该引擎授权而开发的游戏也不在少数。如今，它正在走向Linux。

现如今，Linux平台上的高质量游戏依然极为罕见，只有《地铁：最后微光》比较拔群。Valve一直在努力将它们的游戏引入Linux，还带去了Steam，但都不以画质见长。

Crytek SDK开发包已经升级，加入了对Linux系统的支持，但暂时未透露更多内容，也不知道具体的开发方向，比如会让哪些游戏支持Linux？《Crysis》系列？

近日基于CryENGINE 3引擎的大作最值得注意的当属《星际公民》(还支持AMD Mantle)，不知道会不会跟着有Linux版本？
