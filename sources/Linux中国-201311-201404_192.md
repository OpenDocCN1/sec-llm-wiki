# Red Hat雇用CentOS开发者

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200024442&idx=1&sn=1e8d266bd5bdafe851d4c606d7eb125b&chksm=28f01a3c1f87932a7fe79ef38f76ef2fab699bb9d8e33180a5d8bc726b1078ae993df6a7bbcb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200024442&idx=1&sn=1e8d266bd5bdafe851d4c606d7eb125b&chksm=28f01a3c1f87932a7fe79ef38f76ef2fab699bb9d8e33180a5d8bc726b1078ae993df6a7bbcb&scene=27#wechat_redirect)

CentOS项目负责人Karanbir Singh和其他几位核心开发者现已成为Red Hat的全职雇员，他们专职于CentOS开发，不会参与Red Hat企业发行版的工作。

CentOS发行版本身并无变化，其开发过程和方法都非常透明，只是CentOS的身份变成了Red Hat资助的社区发行版，类似桌面发行版Fedora。

CentOS本质上是 Red Hat Enterprise Linux的免费版本，但如今Red Hat不只是一家Linux公司，CentOS没有威胁到Red Hat的核心商业模式。公司执行副总裁兼CTO Brian Stevens说，公司的未来计划是围绕着OpenStack，而不只是Linux。
