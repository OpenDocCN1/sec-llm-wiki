# 戴尔拒绝保修故障扬声器，归罪于VLC

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200022536&idx=3&sn=dc23ccf1bb8062c8364398dc09da888e&chksm=28f0214e1f87a858708c0c70610a5e95895b423b781113e977571454cda0417a930881cbaf71&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200022536&idx=3&sn=dc23ccf1bb8062c8364398dc09da888e&chksm=28f0214e1f87a858708c0c70610a5e95895b423b781113e977571454cda0417a930881cbaf71&scene=27#wechat_redirect)

开源多媒体播放器VLC有一项增大音量的功能，能使得音频有效输出功率超过100%，这项功能对于播放声音较低的视频文件非常有用。

然而，如果你在戴尔电脑上安装了VLC，即使是在保修期内，戴尔将会拒绝免费替换受损的扬声器，声称是VLC造成了破坏，而VLC的破坏不在保修范围内。

VLC资深开发者Jean-Baptiste Kempf则认为根本原因是戴尔使用了无法处理声卡输出功率范围内的扬声器，简单来说声卡最大输出功率是10W，而扬声器处理的最大输入功率只有6W，认为不可能是软件造成了硬件故障。
