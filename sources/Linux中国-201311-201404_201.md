# DARPA公开一系列软件源代码

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200021705&idx=3&sn=da01b790f51cb583e8fd163c55244a88&chksm=28f02d8f1f87a4991e1258d9a8c8a44d1497f6c758d1dfd482116f2dbdc18d4698f7b785e0f0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200021705&idx=3&sn=da01b790f51cb583e8fd163c55244a88&chksm=28f02d8f1f87a4991e1258d9a8c8a44d1497f6c758d1dfd482116f2dbdc18d4698f7b785e0f0&scene=27#wechat_redirect)

美国国防部高级研究计划署（DARPA）资助了许多大学和实验室开展基础和应用方面的研究，覆盖了各个领域，包括机器人、异常检测、数据科学、网际空间，等等。多数研究成果都以开源的方式公开，但在此之前并没有提供方便的方式让外界访问这些项目的源代码。

![](../Images/e4309be01617aa67a8af151bd7572877.png)  

现在，DARPA上线了 Open Catalog，列出了其资助的一系列软件的源代码和同行审议论文的下载地址，大部分项目的源代码都托管在Github上，少数托管在Google code或Apache上，大部分项目采用的是BSD许可证，允许私有项目在不披露源代码的条件下整合这些开源软件。
