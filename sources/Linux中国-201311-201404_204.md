# 视频展示 Ubuntu touch 多任务显示改进

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200016263&idx=3&sn=1a4725597b836ec5f8a7618d030b05dd&chksm=28f03ac11f87b3d77fe09b565bea3662ff753316d67e4bb24c44d65c81186ff3d4e206e55080&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200016263&idx=3&sn=1a4725597b836ec5f8a7618d030b05dd&chksm=28f03ac11f87b3d77fe09b565bea3662ff753316d67e4bb24c44d65c81186ff3d4e206e55080&scene=27#wechat_redirect)

来自国外博客 OMGUbuntu 的消息，Ubuntutouch 正在开发当中的一种多任务管理改进的方法。 Ubuntutouch 开发人员Michael Zanetti 展示新的预览行为：右边缘滑动，用于在移动操作系统上应用程序之间切换。

Ubuntu touch 目前提供两种不同的方法多任务程序切换。全屏应用程序可以通过’循环’从屏幕右侧的翻阅，显示所有打开的应用程序的缩略图。

一种 3D 的切换效果 – 类似于 Windows 7 中的 Aero Flip 3D 功能。
