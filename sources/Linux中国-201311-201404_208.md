# 朝鲜推出"红星OS" 疑似全盘抄袭Mac OS

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200015120&idx=1&sn=ca3f2efe1a49d7eba28ae42b4a963110&chksm=28f7c6561f804f4061ab2eab5d7e1967f9b3ffe18f0a7fefc26fdf323ae28e23874e9f90259b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200015120&idx=1&sn=ca3f2efe1a49d7eba28ae42b4a963110&chksm=28f7c6561f804f4061ab2eab5d7e1967f9b3ffe18f0a7fefc26fdf323ae28e23874e9f90259b&scene=27#wechat_redirect)

尽管Windows系统仍旧统治世界操作系统市场,但越来越多的消费者们也意识到了其他的可能选项,其中最具代表性的便是苹果的Mac OS X.这一新思路也影响了朝鲜,其最新发布的红星OS便几乎是Mac OS的翻版.

![](../Images/f9c9a2a02c8bb4d95980a9a09d8312ff.png)

该版本红星OS为此系统的第三代版本.上一代红星OS与Windows 7极为相似.这些红星OS 3.0的截图来自一位计算机教授Will Scott,他目前在平壤大学作客教书.据他表示,这一系统发布已有6个月时间,是基于Linux系统,或者直接基于苹果Mac OS系统所开发的.尽管朝鲜不允许普通民众接触英特网,然而大学以及其他公共机构可以上全国内部的网络.

![](../Images/1ed6a9fff1b0c2175d148859e531b2dc.png)

红星OS 3.0内置了一款由Firefox所改造的浏览器,被叫做"Naenara",意思是"我的国家"

![](../Images/35c5461147e97ca466295f2b5fce2ac5.png)
