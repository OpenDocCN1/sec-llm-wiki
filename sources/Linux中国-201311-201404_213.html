世界移动通信大会是世界上最大的移动通信行业会议，也是移动通信专家、爱好者和基础设备制造商的会议，Canonical 也将再次出席。

2014年移动通信世界大会将在2月24日西班牙巴塞罗那揭开序幕直到27日。

一年一度活动通常是各个公司推出新移动技术、新硬件和展现的机会。今年的主讲嘉宾包括马克·扎克伯格、WhatsApp的Jan Koum 和IBM首席执行官Virginia M. Rometty。分研讨会、小组讨论会和大会，整个为期四天的盛会。

什么要期待 Canonical
Canonical 开发人员在去年开发了预览版平板电脑和智能手机。今年似乎将提供更多的相同系统，但肯定有所改变和进步。

更加希望 ubuntu 在 MWC 上给我吗演示更加漂亮的移动 Ubuntu 系统设备？
Ubuntu 安装独特 WEB 应用程序，Ubuntu 在不同设备上的表现，TV、Phone、Computer。

希望在 MWC 上能看到 Unity 8 的闪亮登场？还有一些小厂家与 Ubuntu 合作带来的移动设备，会不会出蓝色版本。

拭目以待吧。会议议程可在官方网站上查看：http://www.mobileworldcongress.com/
