在现今我们都在使用 Linux，不知不觉中我们的生活每个角落都在使用 Linux，这里的 linux 是基于 Linux Kernel 的系统和设备。手机、平板、服务器、PC、甚至游戏机，Linux 无处不在。

2去年全球智能手机出货量近10亿：Android 占79%，已经成为绝对的霸主，而 android 的底层核心就是 Linux。全球前十大智能手机厂商中，除了苹果和诺基亚，其他厂商几乎都属于 android 阵营。

平板电脑市场，几乎就是 android 与 ios 之间的竞争，按生产厂家排名，苹果依然是霸主，但是按照系统出货量，android 依然是这一领域的赢家，而且 android 还在逐步蚕食 iso 的市场份额，2013年第二季度Android平板市场占有率为67%，iOS降至28.3%，Windows仅为4.5%，所以在平板市场以 linux 为内核的 android 依然占据主要地位。

服务器我们就不多说了，这个领域 linux 一直都是占据主要位置，另外说一个数据就是世界超级计算机几乎都是 Linux 系统。

在 PC 上 Windows 虽然依然是霸主，但是这个市场正在逐渐萎缩，慢慢的被智能手机和平板电脑挤占。这一衰落的市场就不用多说了。

另外一个就是游戏机方面 linux 也有不俗的表现：
在最近几年里，Linux以一种不同的形式获得了发展，那就是作为游戏系统的基础。而这其中的主要代表包括Android智能手机、Valve的SteamOS、迷你家用机Ouya、还有第四代的PlayStation。
Linux游戏玩家在2012年末迎来了一条重大消息：Valve宣布推出Linux版本的Steam测试版，这对于该平台无疑是一次首肯。

在Steam的Linux游戏库当中，目前共有超过270款兼容作品，尽管它们当中大多数是独立游戏而非3A级大作，但好在它们还在不断增长。而这都要多亏了Valve的Steam Machine项目。

对着Linux版Steam的发布，就有传言声称Valve打算开发一款Steam家用机。在随后的几个月，这些传闻大多数都成为现实，我们也看到了Steam Machine、SteamOS和Steam手柄的问世。

现在，任何人都可以使用SteamOS Beta来开发一部Linux游戏机。

2014 年 linux 还将继续开花，基于 linux 的新系统和设备将继续开花结果，其中就有大家关注和期望著名的系统项目和设备：

FireFox OS （Mozilla 公司）

Ubuntu phone （Canonical 公司）

Tizen （三星公司）

Sailfish （Jolla有限公司）
