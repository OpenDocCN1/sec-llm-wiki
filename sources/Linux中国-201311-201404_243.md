# FreeBSD 10.0发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=10015773&idx=3&sn=7c73e2fa3644a18beca131857d30e0a0&chksm=2384ef5b14f3664d4eea5dc8fe2b7dfaaaa2ef387742a21a47da890d9a24d585fe908b9e5e49&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=10015773&idx=3&sn=7c73e2fa3644a18beca131857d30e0a0&chksm=2384ef5b14f3664d4eea5dc8fe2b7dfaaaa2ef387742a21a47da890d9a24d585fe908b9e5e49&scene=27#wechat_redirect)

FreeBSD宣布发布FreeBSD 10.0-RELEASE。

![](../Images/b0f6bbb14ec4b7c2cedfd0cf0e58ca06.png "logo-red.png")

### 主要新特性

*   默认包管理工具pkg；
    
*   增强虚拟化，加入bhyve、virtio和原生准虚拟化驱动支持在微软的Hyper-V中把FreeBSD作为一个客操作系统；
    
*   在clang作为默认编译器的架构上不再安装GCC；
    
*   ZFS文件系统加入SSD的TRIM支持，支持高性能 LZ4压缩算法；
    
*   支持 Raspberry Pi；
