# 比特币亿万富翁出手拯救OpenBSD

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=10015727&idx=3&sn=5e83f7d2f2a8ac0b251da5dcb1a00df6&chksm=2384e8a914f361bfc011fd673c245758e0e3841dfccbeaa640ef3ec37b3776e083d6f4218e50&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=10015727&idx=3&sn=5e83f7d2f2a8ac0b251da5dcb1a00df6&chksm=2384e8a914f361bfc011fd673c245758e0e3841dfccbeaa640ef3ec37b3776e083d6f4218e50&scene=27#wechat_redirect)

OpenBSD基金会陷入了财务危机，如果没有更多经济援助将不得不关闭。现在，一位罗马尼亚的比特币亿万富翁宣布出手拯救了OpenBSD。

Mircea Popescu是比特币期权交易平台MPEx的拥有者，他的比特币净资产估计超过70万，根据目前的币值，只需要几十比特币就能足以为OpenBSD支付服务器电费。
