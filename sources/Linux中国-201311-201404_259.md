# Ubuntu 13.10让人又爱又恨的五件事

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=10015606&idx=1&sn=6402bc78711fac6cfb786aaf1004ddff&chksm=2384e83014f361268cb513c58f0c07fdeb586ced25287332598a84fb715d58897643d52fb0a0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=10015606&idx=1&sn=6402bc78711fac6cfb786aaf1004ddff&chksm=2384e83014f361268cb513c58f0c07fdeb586ced25287332598a84fb715d58897643d52fb0a0&scene=27#wechat_redirect)

Ubuntu 13.10发布前后引起了很大的反响。这个操作系统让Canonical达到了一个全新的等级，尤其是在2013年这样一个Linux大年。但现在已经尘埃落定，外界的声音也小了，让我们看看这个系统让你喜欢的五件事，和让你讨厌的五件事。

### 爱

![](../Images/4aa4e3536188263bad28eff77d065252.png)

**OpenStack APIs**:Ubuntu 13.10兼容OpenStack APIs。事实上，内部和外部Ubuntu-主机云现在与OpenStack APIs兼容。

![](../Images/88660f316fd2384f0855234f98ede245.png)

**GUI**: Unity的GUI正在从个人电脑到智能手机和平板电脑很好的转变。

![](../Images/e425855795e94f1a134f67a8a3253f08.png)

**升级后的Dashboard**: 为用户提供了搜索甚至是Ubuntu One cloud的Ubuntu Dash已经升级了。

![](../Images/7d761072e50d336b114daf0502786171.png)

**好用的Juju**: 在活泼的火蜥蜴中，您可以使用Juju在Linux容器或LXC中创建应用程序实例。

![](../Images/9c99d24693654beeea641cfd17c1cb22.png)

**GUI更加顺滑**:也许正因为它的多功能性,活泼的火蜥蜴的漂亮的用户界面比过去版本的用户界面更为顺滑。

### 恨

![](../Images/5e820e314c214c6a339ce16ebc591749.png)

**没有Mir**: Unity界面还没有从X.org转移到Mir 编译器。这是让很多人失望的主要的地方。

![](../Images/c9e1471e751ffee5831973217e645de4.png)

**没有MariaDB**: MySQL数据库的替代产品——MariaDB尚未被Canonical引入。这与其说让人失望，不如说是让人震惊,因为大多数其他发行版已经这么做了。Canonical的Ubuntu 13.10还在用MySQL作为LAMP的默认数据库。

![](../Images/344391ea0cadc6ef891a8c88a04a4f8e.png)

**老版本的landscape管理工具**:Canonical的landscape服务还不够先进，实际上，甚至比微软的跟着Windows发布的系统中心还要古老。

![](../Images/3866748cee90bfeb4651a4a869a89ef0.png)

**只支持两款手机**:现在只有Galaxy Nexus4和Galaxy Nexus智能手机支持Ubuntu 13.10。此外,这两个设备只能使用核心和shell程序。

![](../Images/13df1f5e100f73983646f023ffafe375.png)

**LXC仍然是测试版**: 我们说Juju和LXC一起使用,但LXC本身仍在测试模式。它今年2月应该能出一个稳定版。
