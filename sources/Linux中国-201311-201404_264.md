# Fedora 21 将没有别名

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=10015483&idx=1&sn=33b845204f289e55e9223d47767ef920&chksm=2384e9bd14f360abe8361eb2c55df775382b0243c27fb90079889aa6f08ea2101b8fdbe6cafe&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=10015483&idx=1&sn=33b845204f289e55e9223d47767ef920&chksm=2384e9bd14f360abe8361eb2c55df775382b0243c27fb90079889aa6f08ea2101b8fdbe6cafe&scene=27#wechat_redirect)

Red Hat资助的社区发行版Fedora去年庆祝了诞生十周年，而迎来新一年的Fedora发行版将发生两大变化：

*   Fedora将不再延续上半年一个版本下一 个版本的发布周期，Fedora 21将在2014年8月发布；
    
*   新版将改变命名策略，Fedora 21将没有名字。
    

![](../Images/cf0d455c0069d6eda06f61b0d86ea92c.png)

最近几年社区给Fedora发行版起了很有趣且相关的名字，比如Fedora 17叫Beefy Miracle，Fedora 18 是Spherical Cow，Fedora 19 叫Schrodinger's Cat，而去年12月发布的Fedora 20命名为 Heisenbug。延期发布和改变命名规则并不意味着Fedora社区出现了问题，它只不过在尝试重新发明自己。
