# 2014年关于Linux的三大预测

之前我们回顾了Linux在2013年的发展情况。相信读者一定会对Linux在2014年的发展情况比较关心。Linux.com网站近日对2014年的Linux做出了三大预测。一起来看看：

### 2014年Linux内核预测

Linux内核的开发速度是惊人的。对于Linux 3.2-Linux 3.9内核周期：

*   1100多名开发人员的贡献，包括个人和超过225家公司
    
*   70天的发布周期
    
*   每次发布10000个补丁　　
    
*   1600万行代码库每小时就有超过7个更新。
    

Linux 3.10内核的速度更快：

*   将近1400的贡献者　　
    
*   1700万行代码库每小时超过9个更新。
    

这个过程有严格的程序。贡献者并不受集中控制，并且任何人都可以做出贡献。贡献者来自三星、谷歌、富士通、博通、英伟达，甚至微软这样的公司，这就是为什么Linux内核是全宇宙的内核。他们不必等待别人来添加修复或特性，他们可以根据自己需要开发自己的产品。几乎相同的内核运行在微型嵌入式设备和超级计算机以及介于两者之间的任何设备。它运行在所有主要的硬件架构： x86、IA-64、Power、PowerPC、ARM、AMD64、MIPS、Sparc、S/390、Atmel、System z、Alpha等等。

另一个无价财富是任何人都可以使用：你可以下载最原始的内核：0.01版本。

2014年，Linux内核预测将吸引更多的企业和个人贡献者。甚至包括那些曾无视甚至敌视Linux和自由/开源软件的人，因为他们看到成为贡献者之后的价值，并且这一趋势将继续持续下去。

开发团队具有良好组织，关键人员消失不会削弱团队。总有一天Linus将退休，而这并不会是一个灾难性的事件。因为他已经建立了100多个子系统的层次结构维护者。Linus在2012-2013年只支持0.7%的补丁。Greg Kroah-Hartman、David Miller、Mauro Chehab、John Linville和Andrew Morton是五大补丁审批者。Linus甚至没有进入前20。尽管任何项目需要一个强有力的领导者来设定方向，做公众发言人，但除了Linus，不乏其他有较强个性的后来人。

### 2014年Linux桌面预测

评论家喜欢将每一年预测为Linux年。但是大多数情况下他们都没有将自己的预言变成现实，因为他们专注于零售桌面。遗憾的是，零售桌面的霸主一直都是微软Windows。这是一个耻辱！因为Linux是一个伟大的桌面操作系统。它的安全、高效、可靠和的比Windows更容易管理。

在任何情况下，很多人不需要使用太复杂的计算机。很多用户绕过电脑，完全支持智能手机和平板电脑。有谁发现超过70%的全球市场份额都是智能手机吗？Android运行在在Linux内核上。Android也支持平板电脑、集顶级设备、照相机、电视机、游戏机等等，以后也会支持更多的设备。

Android还支持小笔记本和上网本。有人大胆预测Android是Linux的变体，将最终推翻Windows桌面的“广大用户”。因为Android代表着可爱和友好，它的开放架构意味着实际竞争和成千上万的应用程序可供选择，以及智能手机和平板电脑用户已经懂得如何使用。

### 2014Linux预测：更多的工作机遇

Linux将持续快速入侵一切：汽车、通信、游戏、智能电网、工业自动化、智能家庭、教育、分布式科学研究、医学、农业... ...2014是Linux和自由/开源软件浪潮的开始。因此只要你有符合的技能，就会有更好的工作机遇。程序员总是供不应求。云管理员、Web开发人员、艺术家和设计师、工程师、作家等等——真正的繁荣刚刚开始，未来将是对所有角色的需求。
