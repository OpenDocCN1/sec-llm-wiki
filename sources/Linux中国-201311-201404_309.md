# Linux系统 whoami 命令 – 知晓当前登录用户

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10014928&itemidx=3&sign=ddb0e65a7e0ec407cedf16e9bcf71d42&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10014928&itemidx=3&sign=ddb0e65a7e0ec407cedf16e9bcf71d42&scene=27#wechat_redirect)

通常，在控制台的命令提示符下你会发现 **用户名已经被显示出来** 。但有一些 shell 默认情况下不会显示你的用户名，比如 **csh** 。所以这个命令最应该用在那些不能回显用户名的 shell 终端上。

### 怎么样运行 whoami

运行这个命令，你只需要输入 whoami 。下面的例子中我们使用的是 csh shell 终端。

```
% whoami
```

![](../Images/2c3159222bc9445009ad2c7757c8d155.png)

### Whoami 的参数选项

这个命令仅仅有两个参数选项： **–help** 和 **–version**。

```
% whoamin –help
```

![](../Images/2060b282e411a04e67513358bf46658d.png)

下面这选项会输出和 **man whoami** 命令一样的信息

```
% whoami –version
```

![](../Images/2b59ea1a3a73e6d729cd13140be1a487.png)

不同的是 **–version** 会显示你系统上 whoami 命令的版本信息

### 相似性

whoami 命令和 **id -un** 有相同的输出。它们都显示出当前用户的用户名。

```
% id -un
```

![](../Images/c63ed5376d6d7e1d545108e4afb010bf.png)

### 结论

whoami 命令也用于当你使用 su 命令（切换用户）时, 它能让你确认登录的用户名是否正确。whoami 和 who 命令不相同， who 命令会显示所有已经登录的用户名，而 whoami 不是。当你切换用户时，whoami 命令会显示会话所属的当前用户，而 who 命令会显示你切换前的那个源用户。
