Linux和开源已经在2013年开始悄悄主宰世界?

原文：http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10014827&itemidx=2&sign=99b79b76e4cafcba2845f19235034cd3&scene=27#wechat_redirect

提到Linux，很多人觉得它依旧不温不火，实际上在这个即将过去的一年，Linux和开源软件已经悄悄主宰了计算领域的各方面，这具体表现在开源项目遍地、Chromebook崛起、SteamOS备受瞩目、Android统治世界和云无处不在。

Linux在一些计算领域已经统治了不少年，比如说在超级计算机上，而在2013年，这个即将过去的一年，Linux和开源软件开始悄悄主宰了计算领域的各个方面，从汽车到云，再到终端用户计算等等。

或许这样的说法稍显渲染，但国外媒体ZDNET专栏作者Steven J. Vaughan-Nichols就是这么认为的，他在Linux上一直观察了20多年，他称用户总会涉及到Linux和开源软件参与的计算，这是无可避免的，而在2013年这一趋势更加明显。对此，Steven J. Vaughan-Nichols还总结了以下五个比较明显的方面。

1.开源软件是无处不在的

从目前来看，几乎很少有开发者不使用开源软件的，甚至微软也开始在开源上投入更多的精力和努力，比如说Node.js、使用JavaScript构建的工具或框架等等，是的，连微软现在也开始帮助建设Linux了。

更让人惊讶的是，一些大公司也开始以各种形式接受Linux基金会领导并建立开源项目，以统一他们的努力。仅在2013年，Linux基金会就汇集了AllSeen物联网联盟、OpenBEL开源生物研究、OpenDaylight SDN公司、开放虚拟化联盟和Xen虚拟化项目等等。

除了Linux基金会外，Facebook的开放计算机项目也把开放源码方法带到了数据中心， Juniper和Contrail也有自己的开源SDN，而Apache则继续拥有在大数据上的优势项目Hadoop等。

而且所有这些项目都还有一个令人称奇的共同点——这些不同的公司都在与他们的宿敌一起工作，他们在一起努力并不是因为被施了什么魔法，也并不是因为政治上的需要而必须在一起努力，这只是因为使用开源，能让他们在能够负担得起的基础上获得最好的软件。

2.Chromebook崛起

虽然谷歌基于Linux的Chromebook流行程度仍然不高，但有一些事实显示Chromebook正加速出现在人们的生活中。

Dell是最后一个主要OEM中没有生产Chromebook的厂商，但现在这一情况却发生了改变，它将会于2014年初发布自己的Chromebook。与此同时消费电子巨头LG也将发布一种新形态的Chrome OS设备：Chromebase，这是一个结合chrome的一体化PC，拥有21.5英寸显示屏和1920x1080全高清分辨率。

随着这些设备生产厂商的加入，未来Chromebook将会越来越多，这也意味着它出现在人们生活中的频率将会越来越高。

3.SteamOS：主流的Linux游戏平台到来

没有哪个公司在桌面上能像Vavle有如此大的转变，这个PC领域主要的公司革命性地推出了SteamOS，这是Debian Linux的一个分支。

或许其他公司会在linux和开源上进行投资，但Vavle并没有这么做，它对linux投入了全身心，目前Valve已发布自己的桌面Linux和Steam Machines。对于Vavle为什么要开发专用的linux游戏控制器呢？Vavle首席执行官Gabe Newell曾在今年早些时候指出，在PC领域，Windows 8对于每一个人来说都是一场灾难。

是的，对于现在的Valve而言，Linux是计算的未来。

4.云：Linux无处不在

你可以争论Linux是否在桌面领域崛起，但没有人可以否定linux在云计算方面的影响力。除了微软的Azure，其它主要的云计算软件平台，包括亚马逊的EC2云计算、谷歌计算引擎和各种OpenStack的实现，都是基于Linux和开源软件。

另外，由于大众需求，实际上Ubuntu、CentOS、SUSE Linux Enterprise Server （SLES）和OpenSUSE都可以在微软Azure上运行。

是的，如果你使用到云，那基本就意味着你在使用Linux。

5.Android的移动世界

在远离桌面PC的地方，Linux以另外一种形式存在——Android，经过这几年的发展，Android在智能手机流域已经超过苹果iOS成为最为流行的移动操作系统，并开始统治移动终端的用户计算。与此同时，随着个人电脑销量持续下跌，Android似乎很有可能成为在所有平台上最为流行的操作系统。

最后：从上面来看，在2013这一年，Linux和开源似乎都没有什么大故事，但实际上Linux和开源在计算的各个方面继续成长，并开始逐渐统治整个世界。正如linux基金会执行董事Jim Zemlin所言，2013年是Linux开始掌控的一年，是的，在未来的几年里，大家将会在越来越多的设备上看到Linux的身影。
