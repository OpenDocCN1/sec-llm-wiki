# 关于在 Ubuntu 上安装 SteamOS session

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10014654&itemidx=1&sign=860a098d910788340fdf8fc8152961a1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10014654&itemidx=1&sign=860a098d910788340fdf8fc8152961a1&scene=27#wechat_redirect)

SteamOS 测试版本已经发布了，对 Linux 命令熟悉的童鞋可以直接下载进行安装，注意是测试版本，所以免不了有 BUG，今天在 webupd8 上看到一篇文章是关于在 Ubuntu 上安装SteamOS session 的。SteamOS session 看起来更像是一个游戏玩家的桌面。

![](../Images/b7212c3175827054604ab141ab72e6be.png)

安装方法：

1、首先要确定你的电脑已经安装 steam 客户端，如果没有安装，可以在 Ubuntu 软件中心搜索安装，直接搜索 steam 就可以找到。据 webupd8 介绍，session 启动要加载这个客户端。

2、在 Ubuntu 上 SteamOS session 需要安装两个包。

*   SteamOS Compositor
    
*   SteamOS Modeswitch Inhibitor
    

下载这两个包之后安装，然后注销系统，选择“SteamOS”登陆：

![](../Images/b3708914db93a08cdc4544384adbdf9c.png)

卸载命令:

```
sudo apt-get remove steamos-compositor steamos-modeswitch-inhibitor
```
