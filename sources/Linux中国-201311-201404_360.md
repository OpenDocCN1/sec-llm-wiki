# 红帽发布首个RHEL 7测试版本

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10014121&itemidx=2&sign=1719f56e05c42bd9270a61b99bf045b6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10014121&itemidx=2&sign=1719f56e05c42bd9270a61b99bf045b6&scene=27#wechat_redirect)

Fedora是许多人最喜欢的Linux发行版之一。遗憾的是，它的下一个版本(20)，已经被推迟到本月下旬了。不过也有一个好消息，那就是——红帽推出了RHEL 7的首个测试版本。该公司表示："通过今天的发布，我们诚邀红帽的客户、合作伙伴、以及公众人士为这个最雄心勃勃的新版本提供反馈和意见"。

红帽表示：“Red Hat Enterprise Linux 7的设计宗旨，就是为未来的应用程序体系结构提供了支撑，同时为部署横跨bare metal、虚拟机、以及云基础架构提供了所需的灵活性、可伸缩性、以及性能”。

该公司还补充道："基于Fedora 19和更新的Linux 3.10内核，RHEL 7将为用户带来强大的新功能，并简化和自动化安装与部署、管理更简单、提升了易用性，同时保留了企业所期望的稳定性"。

由于RHEL 7首次用上了3.x的内核，这振奋了许多人的心——因为此前的企业版本只是采用了老旧、但是可靠的2.6x内核。这将提高性能、并添加对更多硬件的支持。

此外，XFS仍旧是默认的文件系统，最高支持500TB。不过ext4文件系统也会作为一个"技术预览"的选项而存在。换句话说，RHEL 7使得企业用户有了更多的选择。
