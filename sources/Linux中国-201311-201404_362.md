# SteamOS将于12月13日开放下载

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10014121&itemidx=1&sign=0a8766d54b856f5db6c4ed91cf192615&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10014121&itemidx=1&sign=0a8766d54b856f5db6c4ed91cf192615&scene=27#wechat_redirect)

Valve宣布：12月13日的时候，该公司将向300名幸运儿出货Steam Machine原型机，包括一个强大的Steam Controller、以及基于Linux的SteamOS。

对于没有"入围"的孩子们，也不要伤心，因为我们至少还有一个"安慰奖"——Valve也将于同一天，向所有人开放SteamOS的下载。

  

尽管该公司暗示过，新的操作系统不是那么容易安装——"除非你是一个勇敢的Linux黑客，不然我们还是建议你等到2014年下半年再试试"。更多的信息，就看Valve愿意在CES 2014上泄露多少了。
