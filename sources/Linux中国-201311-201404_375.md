# Linux中国翻译组（LCTT）募新

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10013996&itemidx=4&sign=1e4118a6627b1b5170678a8742c6a99c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10013996&itemidx=4&sign=1e4118a6627b1b5170678a8742c6a99c&scene=27#wechat_redirect)

LCTT是Linux中国社区（http://linux.cn/）的翻译组，负责从国外优秀媒体翻译Linux相关的技术、资讯、杂文等内容。

LCTT已经拥有二十余名活跃成员，并欢迎更多的Linux志愿者加入我们的团队。

项目地址： http://lctt.github.io/
