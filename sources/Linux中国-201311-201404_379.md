# 最受黑客欢迎的密码TOP 20：你中枪了吗？

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10013902&itemidx=2&sign=31d3a890832d02894739539854e90acb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10013902&itemidx=2&sign=31d3a890832d02894739539854e90acb&scene=27#wechat_redirect)

即使在经历了无数的黑客盗密事件之后，还是有很多人不知从中吸取教训，抑或是很多人根本不在意自己的账号密码是否安全！他们一直用着最简单最易记的密码，而这些往往也是账号密码被盗的主要原因。那么，你知道容易被盗，但又十分受欢迎的密码都有哪些吗？本文将为你揭开谜底。

10月4日，报道称Adobe公司系统遭黑客入侵，被盗的用户账号和密码达3800万！

另外，据英国广播公司（BBC）消息，“123456”是最受Adobe用户“欢迎”的密码，没有之一，使用这一密码的人数多达190万。

本周，Spiderlab实验室的安全专家表示其近来发现了一个盗窃200多万社交媒体账号密码的犯罪网络，目前正对其进行研究。

Spiderlab实验室相关人员称：“这些被盗密码中安全指数高的密码远远少于安全指数低的，被盗密码中多数密码都在“最受欢迎的密码”表单中！”

即使在这个安全问题泛滥成灾的时代，人们依旧更加注重简单易记，往往忽略了安全问题！
