# prettyping.sh: ping 之美

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10013879&itemidx=1&sign=950f7fff38bc7f298e77149392f6be6f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10013879&itemidx=1&sign=950f7fff38bc7f298e77149392f6be6f&scene=27#wechat_redirect)

ping 想必大家都不会陌生。当我们想要知道网络是否通畅时往往就会执行这个命令。 不过，默认的 ping 命令输出比较单调乏味。因此，国外的某个老兄编写了 prettyping.sh 这个脚本，它不仅会加点色彩，还会来点图示。总之，看起来有点特别 就是了。
