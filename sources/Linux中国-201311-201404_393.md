# Richard Stallman呼吁开发真正匿名的比特币替代

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10002565&itemidx=2&sign=d0fe4453735e38f1342789d8d2216b78&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10002565&itemidx=2&sign=d0fe4453735e38f1342789d8d2216b78&scene=27#wechat_redirect)

自由软件基金会主席Richard Stallman（RMS）暂时放下了他的自由软件运动传教职责，对目前火热无比的数字货币比特币发表了他的见解。RMS与致力于3D打印武器的Cody Wilson、比特币开发者Michael Parsons、歌曲“Bitcoin Baby”的演唱者Rachel出席了伦敦举行的Bitcoin Expo活动，他接受了俄罗斯媒体RT的采访。

 Stallman赞扬了比特币，称它允许人们不需要经过支付公司的许可将钱发送给另外一个人，“如果你想支持WikiLeaks，你现在可以用比特币”。 他说，比特币的一个潜在问题是逃税，他本人不支持逃税，但我们必须认识到最大和最有伤害性的逃税案例是法律的有效性。政府不敢让企业缴纳应该缴纳的税，不敢让富人上缴应该上缴的税，“我们如果真的要杜绝逃税，应该修改税法，让企业不能通过避税方法逃税。”他指出，比特币的一大弱点是没有匿名性，一切交易都记录在案，呼吁开发一个真正的匿名支付系统。
