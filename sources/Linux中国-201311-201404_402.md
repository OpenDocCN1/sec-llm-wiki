# 百度开源站点 (oss.baidu.com) 发布

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10002548&itemidx=3&sign=81b0038930546c59107f8fd38d2b7cca&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10002548&itemidx=3&sign=81b0038930546c59107f8fd38d2b7cca&scene=27#wechat_redirect)

百度开源站点： http://oss.baidu.com 已经于前几天悄悄发布，目前已经有了十余个百度的开源项目上线，包括：Itest、Ueditor、logcover等。

虽然目前开源项目尚不多，不过这是否已经代表百度在开源方面的一个积极态度？我们期待百度能更进一步的在开源方面做出贡献。
