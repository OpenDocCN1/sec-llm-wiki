# 谋智中国被发现“do some evil”

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001603&itemidx=3&sign=3ebfacbc2388645bf556832236718435&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001603&itemidx=3&sign=3ebfacbc2388645bf556832236718435&scene=27#wechat_redirect)

谋智中国开发的定制主页及快速拨号页扩展（xpi文件）被发现会修改用户的快捷方式，如果中国用户在主页建立了京东商城（www.jd.com）的拨号快捷键，那么该快捷键会被定向到一个返利链接（http://count.chanet.com.cn/click...www.jd.com”）。该扩展的中国开发者还非常幽默的在源代码里加了一个注解——“do some evil here”。
