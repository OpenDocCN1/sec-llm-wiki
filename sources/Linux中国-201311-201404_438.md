# Ubuntu 2013 开发者峰会于 11 月 19 日召开

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5NjQ4MjYwMQ==&appmsgid=10001557&itemidx=3&sign=c11463fb1e3735efb0d429dbef94ecff&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5NjQ4MjYwMQ==&appmsgid=10001557&itemidx=3&sign=c11463fb1e3735efb0d429dbef94ecff&scene=27#wechat_redirect)

Ubuntu 2013 开发者峰会是一个 Ubuntu 官方组织的会议。来自各行各业的 Ubuntu 使用者、开发者、设计师等等人员将参加会议。Ubuntu 2013 开发者峰会将于 11 月 19 日召开。

会议为期三天，11 月 21 日结束。

会议分为六大主题分开讨论：

*   app development
    
*   client
    
*   cloud and server
    
*   community
    
*   core
    
*   design
    

虽然分为六类，不过这些方面几乎涵盖了 Ubuntu 所有的方方面面。

另：第一天由 Mark Shuttleworth's 主持阶段为：14:00 - 15:00 UTC 。
