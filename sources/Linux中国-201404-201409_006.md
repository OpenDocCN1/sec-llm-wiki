# Linus Torvalds自曝：不爱折腾系统，也不是全才

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200698108&idx=3&sn=29dda68f8a1ca08cb384ea98158798e2&chksm=28ea53ba1f9ddaacb404f4fa36ab89c88f6b72d7fb53ea3189a1650d87d4fd942765d64a4292&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200698108&idx=3&sn=29dda68f8a1ca08cb384ea98158798e2&chksm=28ea53ba1f9ddaacb404f4fa36ab89c88f6b72d7fb53ea3189a1650d87d4fd942765d64a4292&scene=27#wechat_redirect)

本文主要是介绍了Linus Torvalds在DebConf 2014问答环节上的演讲要点。他谈到虽然自己在做内核相关的工作，但并不是全才，对一些系统维护问题也会感到很棘手；自己不喜欢折腾系统，一旦选用一个，就不愿再更换；他选择系统的标准就是可以让他快速进入工作环境。

Linus Torvalds在给粉丝签名

众所周知，Linus曾在2007年尝试过Debian系统，当时他感觉Debian安装很难。在近期举办的DebConf 2014问答环节上，Linus Torvalds现身回答了大家的一些提问。他说，从那之后再也没有用过Debian，不过现在感觉Debian应该安装会更容易些了。 

Linus谈到，自己对各种发行版没有多少兴趣，只要容易安装，能够快速进入办公状态，让自己开发内核就行。 当然，Debian过去安装可能确实比较难一些，但基于Debian的衍生版本Ubuntu以“易用”闻名，那Linus尝试过Ubuntu吗？事实上，Linus真的试过，不过立马就觉得Ubuntu不是自己的菜。 

Linus解释说，自己之前尝试过Ubuntu，但在Ubuntu上安装自己的内核比较困难，当自己 make install 编译内核的时候竟然不工作。如果编译内核都是问题，肯定不会继续使用。 

有人提到说Debian现在已经非常容易安装，建议Linus再尝试一下。Linus与大家分享了一个在运行多系统时的问题。他同时解释说，自己并不是全能人才，虽然在做Linux内核工作，大家也都认为他非常技术，但真正维护起机器来就有些“菜”了。 

Linus还自曝说，自己会经常换机器，换系统也是家常便饭，一年通常会来这么几次。 自己也维护着家里的电脑，不过并不经常升级，也不常换系统。自己不想在不同的机器上运行不同的发行版，对他来说，用一个发行版就够了，一旦用定一个系统，再换其他系统也很困难。他说自己曾尝试过在不同的机器上运行不同的操作系统，但一段时间下来，发现每个系统都有自己的更新/升级周期，让人随时受不了。
