# 12张Ubuntu 14.10壁纸竞赛（目前为止的）获奖壁纸

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200698108&idx=4&sn=794c23276a89956cfecc7d8d6ad541e2&chksm=28ea53ba1f9ddaac8c31bda25b23ccbb69839fb33765ccb5ddaf3beda86215c950be58e598dd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200698108&idx=4&sn=794c23276a89956cfecc7d8d6ad541e2&chksm=28ea53ba1f9ddaac8c31bda25b23ccbb69839fb33765ccb5ddaf3beda86215c950be58e598dd&scene=27#wechat_redirect)

让我们欣赏一组你在未来几个月会看到一大堆的图片吧。是的，在Ubuntu 14.10壁纸竞赛获奖者壁纸已经公布了。

嗯，可以说是宣布吧。到目前为止12张背景图片已经正式被应用在Ubuntu 14.10版本中了。

由四月份的获奖作者组成的评审团筛选了几乎400张图片，最终选择了出了视觉上丰富又多彩的一组。我知道我每6个月就要说一次这个，但是这一次的作品看起来还是那么的棒（不仅仅是因为当中一两张是我们的最爱！）。
