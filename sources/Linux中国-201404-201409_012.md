# 微软：为何学校应该选择基于Windows的机器?

在今天的一篇博客文章中，微软特别提到了那些在教室里选用Windows的学校。据这些学校所述，Windows为他们的IT管理提供了一个稳定和安全的平台。此外，Windows还允许教师们使用不同的设备，以及不同的课堂应用程序。显然，“生产力”是微软的拿手好戏，而这也是该公司向学校进行推销的主要卖点。

Windows的另一个长处是管理，因为学校IT人员能够一如既往地控制和监测这些设备。

作为对比，Android或iOS解决方案的实施，需要IT人员区别对待这些设备，甚至还要给人员作特殊的工具培训。

再比如，iPad或许能够很好地作为简单的视频或文本平台，但如果学生们想要生产出一份用于演示的纸张的话，iPad的使用就变得不那么理想了。

不过，Windows电脑不仅可以运行教育视频应用程序，而且可以在必要时切换回Office。显然，熟悉的本地办公体验能够极大地提升生产力。

  

最后，Windows PC也能够让教师和学生们轻松利用投影仪、数字化仪、以及U盘等硬件。相比于Android或iOS，Windows能够做到更无缝的衔接。

当然，校内校外的文化统一也非常重要，鉴于世界范围内的大多数企业都在使用Windows，教会学生使用“大平台”显然要更加实用得多。
