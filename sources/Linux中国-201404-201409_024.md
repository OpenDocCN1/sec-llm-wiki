# 桌面 Linux 操作系统不死

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200671158&idx=1&sn=2534d069569260a3be02d3638b97b41f&chksm=28e9c4f01f9e4de615d29115fbc291f5951cb7590cbd0ac3850c43cbb897a29da8692a1a71dd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200671158&idx=1&sn=2534d069569260a3be02d3638b97b41f&chksm=28e9c4f01f9e4de615d29115fbc291f5951cb7590cbd0ac3850c43cbb897a29da8692a1a71dd&scene=27#wechat_redirect)

如今，Linux出现在每个地方，从家用设备到领先市场的安卓移动操作系统，不一而足。可以说无处不在，但桌面端除外。桌面Linux操作系统一直没有建树，也有不少人称，“Linux桌面操作系统已名存实亡”。微软在桌面端的统治地位仍不可撼动，哪怕苹果强势冲击。难道桌面Linux操作系统就没有转机了吗？著名的Linux专家Jack Wallen日前撰文对此发表了自己的看法。以下为译文：

在Linuxcon 2014大会上，Linux之父Linus Torvalds被问及他最想要什么Linux版本。他的答案是桌面。多年来，Linux者一直声称要统治世界。在某些市场中，Linux确实做到了，例如Linux帮助Android成为移动OS霸主，以及对Chrome OS的发展功不可没。在桌面端，Linux还有很长的一段路要走。这个说法不太准确，我的意思不是“Linux在准备好进军桌面端前还有一段很长的路要走”，而事实上Linux已经为桌面端准备好了，只是一直没有找到合适的机会来到普通消费者身边。

Linus曾表示，桌面Linux已死，愿桌面Linux平安。在我看来，一切都有可能。

首先，我们若要谈桌面Linux，则必须知道桌面会不会死。实际上，桌面依然会存在，因为平板电脑和智能手机有太多事情无法做到。就以一些行业为例，包括：设计师、工程师、作家、建筑师和科学家等，从事这些行业的人，很难将自己的工作转换到移动平台。每天有数以百万计的人在依靠自己的桌面来进行相关的工作。

也有报告指出，PC的销售已经不再那么强劲了。这在很大程度上是由于Windows XP的退役，但也证明了很多人根本没有准备好放弃传统的工作方式，而这些也并不意味着PC销量回不到过去的辉煌。另一方面，太多消费者已经发现便宜的智能手机可以做的事情，以及他们需求：Facebook、电子邮件、购物、多媒体等，经过考量，他们并不需要一台成熟的台式机。所以，PC必须面对死亡的命运。可这不会发生的，因为，仍然有很多人在使用Windows XP，且用着2009年的QuickBook，即使他们都不再提供支持。而小企业根本无法跟得上时代变化的步伐，只要还能满足工作需求，一切都不那么重要。

现在，让我们讨论下桌面Linux操作系统。（桌面Linux使用者列表请看维基百科的资料）

没有人说Linux接管桌面是一件容易事，都知道这将是一个巨大的挑战。也有分析人士认为，桌面（包括桌面Linux）很快就会死亡。这一观点是假定在这样一个前提下的：

*   每个人都可以舒适地使用移动平台；
    
*   每个人都可以在移动平台上完成自己的工作；
    
*   美国也这样看；
    
*   美国重新设定一个软件标准；
    
*   Linux在桌面上并没有取得巨大飞跃；
    
*   Linux不是创新的领导者。
    

是的，移动平台已变得非常强大，尤其是在工作和个人生活方面。有时候在想，我们没有智能手机会怎么办？不过，移动平台可被桌面轻易的替换，智能手机和平台电脑只是对桌面起到一个很好地补充作用。

然而，很多专家提出的一个概念变得越来越正确，就是Linux开发者要停止为一般Linux用户开发，转而开始针对普通用户开发。我总结了一些普通用户在桌面上需求：

*   一个现代化、绿色的浏览器；
    
*   一个人性化的UI，且具有一个现代化的外观；
    
*   基于标准下的办公套件；
    
*   触摸屏功能
    

这么简短的清单对于普通来说真的够了么？基本是可以了，因为普通用户90%的需求都是可以在浏览器内完成的。例如Facebook、Twitter、基于Web的邮件、谷歌应用、网银/购物等，剩余的在办公套件中完成即可。还有一个游戏在哪里呢？那就是rub了。普通用户还可以在他们的智能手机上玩游戏。 

也有观点认为，90%的事情在Web浏览器中完成，已经是桌面Linux崛起的一个最佳时机。稳定、安全、可靠的平台，让用户的设备免受恶意软件和病毒的侵蚀。

自上个世界九十年代开始，我就一直在用Linux，并能很好地完成我的工作，且不需要第二个平台。

桌面不会死，我们仍需继续讨论桌面以及桌面Linux。如今，时机正佳，用户需求也有了，Lunix不会死且已准备就绪。
