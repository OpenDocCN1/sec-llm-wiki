# 轻量级标记语言 Markdown 欲标准化

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200667535&idx=4&sn=a26e20200938665437225d0be08b5628&chksm=28e9cac91f9e43dfbd78500ffb3b357fd7ba5f9df727d356751beeb545c6df74bd79f84a56df&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200667535&idx=4&sn=a26e20200938665437225d0be08b5628&chksm=28e9cac91f9e43dfbd78500ffb3b357fd7ba5f9df727d356751beeb545c6df74bd79f84a56df&scene=27#wechat_redirect)

近日，为了明确规范，避免兼容性差等问题，Markdown 希望制定一个明确的规范，使其标准化。

Markdown 是由 John Gruber 于 2004 年开发一种轻量级标记语言，它允许人们 “使用易读易写的纯文本格式编写文档，然后转换成有效的 XHTML 文档”。

正是因为简单易用的特点，目前 Markdown 已经被广泛运用在各种网站上，现在像是世界上最流行的博客平台 WordPress 和许多大型 CMS 都能很好的支持它。

但是在其诞生的 10 年来，由于缺乏明确的规范，导致其出现了多种用不同语言编写，致使其兼容性差，故如今 Markdown 打算制定一个标准的明确的规范。

补充：

据知乎消息“Markdown 标准化的阻碍在哪里？”：

> 最大阻碍来自作者自己。
> 
> 昨天 Standard Markdown 正式对外发布，Markdown 的作者 John Gruber 就在 Twitter 上各种表示自己很生气。**他认为 Markdown 之所以有今天的成就，应该归功于当初没有进行标准化**\[1\]**。**
> 
> John Gruber 昨天发邮件要求 Standard Markdown 改名字、关域名、道歉。Standard Markdown 今天就立马乖乖改名字、关域名、道歉了。\[2\]
>
