# Open webOS 已正式更名 LuneOS

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200660428&idx=2&sn=b4482a312d8da4472037b99a826be6e2&chksm=28e9ee8a1f9e679cb961889895d5e371b29ba96daf2601caeb626efd211e1f9f586c0489bdb4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200660428&idx=2&sn=b4482a312d8da4472037b99a826be6e2&chksm=28e9ee8a1f9e679cb961889895d5e371b29ba96daf2601caeb626efd211e1f9f586c0489bdb4&scene=27#wechat_redirect)

Open webOS项目还“活着”，并且进展相当不错。尽管距离上一个重大更新(Alpha 2)已有一年多，但是该该移植系统现在已经正式更名为LuneOS了。目前，该OS的最新版本已支持Nexus 4、Galaxy Nexus、Nexus 7(2012)、以及惠普的TouchPad。不过，开发团队表示，他们只会继续深入TouchPad和Nexus 4.

![](../Images/382dff3500ff30dc664a384348802a31.png "2014-09-02-image-7.jpg")

LuneOS的名字源于webOS早期的LunaSysMgr，之后的每个新版本都会被冠上某种咖啡饮料的名字，比如最新版就被叫做“Affogato”(阿芙佳朵)。

![](../Images/24211cd4a1d2950070f1f787f6512d4b.png "2014-09-02-image-8.png")

尽管该团队将精力集中到了上述两款设备上，但是他们也希望能够勾起其它厂商的兴趣，以便为更多的智能机和平板电脑做好适配支持。

![](../Images/84174c01daa6bb12c0304b6902cee511.png "luneos-webos_story.jpg")

LuneOS目前还有一些小问题需要解决，基本的app也只有浏览器、Preware、邮件、账户、以及日历等。该团队表示，他们计划在每月的月初发布一个新版本。

感兴趣的网友可移步至webos-ports.org。
