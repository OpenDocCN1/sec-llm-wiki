# 64位Chrome发布稳定版本

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200640170&idx=2&sn=a1f24447935e37779c2ce356a8f77b9a&chksm=28e9bdec1f9e34fa48f9a60a39b49eebc3b1fb6befbf866841dacaaf4b13fe26964aea149445&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200640170&idx=2&sn=a1f24447935e37779c2ce356a8f77b9a&chksm=28e9bdec1f9e34fa48f9a60a39b49eebc3b1fb6befbf866841dacaaf4b13fe26964aea149445&scene=27#wechat_redirect)

在测试版本中实验了两个多月的64位Google Chrome浏览器，今天跟着Google Chrome 37 稳定版的更新一起进入正式版渠道，使用Windows 7 、 8 的64 位操作系统用户可以试试看这个号称「更快」、「更稳定」、「更安全」的64 位浏览器。由于担心一些插件不兼容，目前使用32位稳定版的用户不会自动更新64位版本，需要手动下载。至于 Mac 和 Linux 版本，还未见到释出的下载链接。

依据Google 自己的说法：「 Google Chrome 64 位版本将可以提升15 % 的高画质YouTube 视频播放效能，并且在处理网页时比起32 位版本有两倍以上的稳定度，而且也可以更好的防御网络上针对浏览器弱点的攻击。」
