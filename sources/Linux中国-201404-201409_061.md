# 国产OS：做好政采市场足矣

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200626922&idx=3&sn=0e7996713f312fdcda5db7262e8c91de&chksm=28e969ac1f9ee0bae08a38ee1fd8ce695e1890459fe7214ce8f0fcb28a33e58794603632d9ea&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200626922&idx=3&sn=0e7996713f312fdcda5db7262e8c91de&chksm=28e969ac1f9ee0bae08a38ee1fd8ce695e1890459fe7214ce8f0fcb28a33e58794603632d9ea&scene=27#wechat_redirect)

昔日国产OS（操作系统）的龙头中科红旗以3800多万元出售给了大连一家名不见经传的公司，结束了纷纷扰扰的红旗Linux命运大讨论。也在同一周，龙鑫Linux操作系统更名为一铭Linux，发布了2.0版本。国产OS领域可谓热闹，但是在热闹之后我们不禁会问，红旗之后，还有谁在市场上能排 上名号？国产OS该怎么做？

### 国产OS数量不少

数一数当前市场上知名的国产OS，其实数量并不少。

有国家新闻出版广电总局力推的TVOS，专门为电视终端定制；有中科院软件所联合上海联彤研发的COS，据称是准备在机顶盒和手机终端上使用；有同州电子的960OS，也同样主攻移动终端；有中标麒麟Linux，是中标软件开发的民用“中标Linux”操作系统和国防科大研发的“银河麒麟”操作系统的合体，在桌面端和服务器端都有版本；有国防科大主研的“银河麒麟（Kylin）”，据说主要是军方使用；还有阿里云OS这样的国产OS新锐等等。

而能从中央政府采购网上查到的、进入国家正版软件采购目录的操作系统就包括8个品牌：Deepin、SPGnux、中标麒麟、中科方德、优麒麟、微软、阿里云和龙鑫（一铭）。这几个品牌的系统，在北京市采购网上还标出了采购价格：国产操作系统价格大致为300～600元，微软系统价格为1300～1600元。

现在，红旗Linux转让给大连五甲万京。据该公司董事长孙凯歌介绍，未来收购完成后，中科红旗品牌并不会消失，而会作为五甲万京的“平行公司”来运作。五甲万京同时还有自己的操作系统TNTOS Linux。

这样数一数，市面上说得出名号的国产OS就有10个以上，不能不说产品数量相当多。用户如果用国产OS，可选择的范围应该是比较大的。但是，实际的使用情况却不容乐观。据CNZZ的数据，今年7月份中国网民使用的操作系统中，windows占到80.96%，Linux占比只有0.14%。而上述提到的国产OS，基本上都是Linux操作系统。

根据操作系统市场的生存规律，通常一个市场只能容纳3～4个操作系统获得比较好的利益分配，形成各自的生态体系，达到正向循环。例如移动终端的Android、iOS、WP、Blackberry这四家，其实前两家的市占率加起来几乎达到了90%，而后两者还在持续投入资本打造生态系的过程中，情况并不乐观。桌面端的OS是微软一家独大，国产OS能在国内市场争夺的，是第一名之后的三四个名次。

### “吃好”政府采购市场

中央国家机关采购中心发出的关于国家机关禁止采购windows 8操作系统的通知，给国产OS发展提供了难得机遇。另外，采购部门还发出了其他助力国产OS的政策，例如在信息化采购项目中，投标方如果在投标计划书里注明投标项目预装国产OS，那么可以在评审的时候加分。这些都给国产OS发出了明确的信号：政府采购市场对国产OS大开绿灯。

那么，政府采购市场究竟有多大？据报道，2011～2012年是国家推行正版软件的两年，中央及地方政府机关采购操作系统、办公及杀毒软件这三类正版软件，共花费20亿元。到2013年11月底，各级政府机关采购操作系统、办公和杀毒软件金额达到了29亿多元。

赛迪智库对2011～2013年的数据研究分析认为，全国政府机关部门对于操作系统的采购一年花费大致在5亿元～7亿元。以当前国内运营较好的中标软件公司年收入1.4亿元为标准计算，来自政府机关的操作系统市场需求能勉强支撑3～5家操作系统开发企业。如果将采购需求扩大到国有企事业单位，市场容量将扩大不止2倍。

如此算下来，国产OS“吃”政府采购市场，基本能解决温饱问题。北京大学网络和软件安全保障实验室主任陈钟教授向《中国电子报》记者表示，中国政府采购信息化的规模不小，国产OS能把这个市场做好就很不错了。要在做好政府采购市场的过程中，把能力培养出来，把产品的质量磨炼出来。

政府采购的春风已经惠及国产OS。一铭软件董事长余时均告诉《中国电子报》记者，前不久公司在与另两家在业内比一铭更知名的国产OS的竞争中胜出，得到了联想公司的大单。而联想计算机和服务器预装国产OS，正是基于日前国家采购部门下发的支持国产OS的相关通知。这笔大单的规模，余时均预计一年有几百万台的出货量。这对于一铭软件是莫大的鼓舞，因为这家10年前就开始做Linux操作系统的公司，其实一直是靠其研发的翻译软件和其他应用管理软件来养活的，而不是国产OS。

国家版权局版权管理司副司长王志成就公开呼吁：“大家一定要积极支持国产软件的开发。一要重视，给他们公平的机会，在区别内外的时候千万别嫌贫爱富。二要从政策、技术指导、行业服务上要充分考虑国产软件的实际情况，给予合理的扶持。因为我们的底子薄，科技力量还不是很强，软件企业特别是民营企业光靠自己的打拼会受到很多限制。三要营造一个公平的市场竞争环境，国内国外一视同仁。四要使用国产软件，给国产软件提供更多修改完善服务的机会，这是最大的支持。”

### 希望寄托在民企

政府应带头使用国产OS。那么，如何将政府采购市场做好？其实不外乎是更好的服务，更好的产品体验，更灵活的体制机制。

余时均向《中国电子报》记者透露，一铭软件在联想项目的竞争中，产品报价是3家中最高的，之所以能拿下项目，只是因为一铭软件的OS运行更流畅，在兼容联想产品的硬件、外设上有更好的表现，而且还承诺在联想的每个系统灌装线上派出2名工程师进行指导，做好售后服务。相比较另两家竞标者，一铭软件既没有国家基金的支持，也没有国有资本的背景，完全是市场竞争中存活下来的企业。

做出能与Windows一争高下的国产OS，依靠的是有活力、有技术实力的企业。陈钟以华为举例道：“华为是中国企业创新发展的楷模，走的是创新-市场-创新的正循环。做国产OS，朝九晚五的企业是做不出来的。这种企业，国家给多少钱资助都不行。”

IDC研究经理潘永花持相同的观点。她告诉《中国电子报》记者，国产OS未来应找有技术实力的企业来做，而不是找有科研院校背景的企业。“因为内部缺少活力，而且很多企业是想借此时机向政府要基金支持。”她说。
