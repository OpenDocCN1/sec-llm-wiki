虎嗅：将在两个月内发布的国产桌面操作系统，靠谱吗？

原文：http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200622824&idx=1&sn=ce5444ccfb3477851bce85bc3c073934&chksm=28e979ae1f9ef0b88ae299f1ecf095e2f25dc0108f25cc913f7d06169be6447fd1c95b3fda82&scene=27#wechat_redirect

继微软的Windows 8操作系统、苹果iPad被政府采购拒之门外之后，国产自主操作系统的话题再次被提及。最近工程院院士倪光南则向媒体表示：

要把操作系统做出来，必须改变过去的做法，不是照搬以前模式，而是要把过去积累的资源整合起来，国家主导做一个统一的操作系统。

操作系统商业模式的创新很重要，整个中国智能终端操作系统应该营造一个统一的生态系统应用环境，“营造一个能够与谷歌、苹果、微软相抗衡的生态环境，这是我们成功的关键。

国产操作系统的突破，将首先从桌面操作系统开始，我国今年10月有望推出支持应用商店的国产桌面操作系统新版本。

各大媒体则更愿意将他那句“国产桌面操作系统最快10月发布”拿来作新闻标题。不过在讨论这个有望在未来两个月即发布的、带应用商店的桌面操作系统是否靠谱之前，先来看看目前市面上的主流操作系统研发历程和各自问题。

1、Windows系列

受到苹果OS X、谷歌Chrome OS强烈挑战的Windows操作系统，至今仍为绝大部分国人所习用。微软于4月取消技术支持的Windows XP操作系统使用的是NT5.1核心架构，目前的Windows 7使用了NT6.1架构，最近备受吐槽的Windows 8以及小众的Windows Phone移动操作系统，都使用了NT6.2核心架构。

从1993年微软NT3.1的首次发布，到2013年NT6.2核心的Windows8.1操作系统发布，微软用了整整20年的时间。如果算上1985年开始发布的Windows1.0，那么微软将自己的桌面操作系统推向全世界，用了29年的时间。

尽管微软在全世界的确切用户数无法知晓，但其桌面操作系统的老大地位是无可争议的。不过，微软在原Windows事业部主管辛诺夫斯基领导下开发的 Windows8因为涉及理念过于激进，令其在极简扁平化Metro（后改名“Modern”）界面、应用商店乃至操作方面都备受指责。而2012年6月 发布的Windows Phone 8 操作系统也遇到了应用匮乏、系统生态残缺的困境。目前微软刚刚宣布了其Windows Phone 商店的应用数量达到了30万款，但僵尸、垃圾应用依然是个令人头痛的问题。

2、苹果Mac OS X

Mac OS X的开发历史一点儿也不逊于Windows系统。苹果公司在1984年推出了第一款具有GUI界面的操作系统System 1.0，而微软推出的具有GUI的Windows 1.0则是在一年之后了。无怪乎电影《乔布斯》中，那个扮演乔布斯的艾什顿·库彻在电话中对比尔·盖茨怒吼对方是“小偷”。

但与微软在1987年即发布彩色版2.0相比，Windows苹果在1991年发布System7.0之前的操作系统都还是黑白的。而正如微软使用NT架构令其操作系统大行其道一样，苹果在1997年推出了Mac OS X8.0代替了System代号并大卖。从Mac OS X10.0开始，苹果使用了猫科动物来命名自家的桌面操作系统（PS：国内乐视则开始使用犬科动物来命名其UI代际）：

2001年3月 Mac OS X 10.0 Cheetah 印度豹/猎豹
2001年9月 Mac OS X 10.1 Puma 美洲豹
2002年8月 Mac OS X 10.2 Jaguar 美洲虎
2003年10月 Mac OS X 10.3 Panther 黑豹
2005年4月 Mac OS X 10.4 Tiger 虎
2007年10月 Mac OS X 10.5 Leopard 豹
2008年8月 Mac OS X 10.6 Snow Leopard 雪豹
2010年10月 Mac OS X 10.7 Lion 狮
2012年7月 Mac OS X 10.8 Mountain Lion 美洲狮/山狮

从2013年开始，苹果放弃使用猫科动物命名系统的作法，分别在2013年6月使用巨浪（Mavericks）、2014年6月使用优胜美地 （Yosemite）来命名新系统。苹果的OS X系统和生态在经历30年的发展后，逐渐完善，加上其完美的工业设计和越来越多的果粉追随，其拥趸正在逐渐追赶Windows系统。

苹果移动操作系统iOS经过7年的发展，已有100 万款应用，令iOS成为最完善的移动操作系统。苹果生产的Mac机支持Windows系统，意在令用户对两个系统产生对比，并平滑过渡至Mac OS X系统。

3、Linux

Linux操作系统由林纳斯·托瓦兹（Linus Torvalds）首次公布于1991年，是一款类Unix架构的操作系统。Linux系统有诸多分支系统，其中最著名的是小红帽（Red Hat）与乌班图（Ubuntu），国内有乌班图麒麟（Ubuntu Kylin）、红旗、蓝点等，其中后二者已经倒闭。目前号称风头正健的谷歌Chrome OS也是基于Linux开发。

Linux虽然发布较早，而且开源免费，但在桌面操作系统中发展较为缓慢。原因在于支持软件较少，更新速度太快，用户从其他系统转移过来还存在各种操作障碍，学习、维护成本也 较大，据报道：

在使用了10年的Linux操作系统之后，德国慕尼黑政府还是在不堪的情况下换回了Windows系统。因为慕尼黑政府官员发现，虽然Linux系统是免费的，但是他们要为这个系统开发和维护 一大堆应用程序，以保证工作的正常进行，系统省下来的钱都被应用程序吃掉了。此外慕尼黑的Linux系统用户很难与其他城市的Windows用户传输和分 享文件，因为他们使用的是不一样的应用程序，结果办事效率大大降低。

因此看来这款桌面操作系统如今看起来更适合极客们玩。

现在回到我们未来两个月可能看到的国产系统。这款操作系统如果有足够的投入、足够的行政能力推广，则非常有望替代现有国外桌面操作系统。但问题是：

1、由于开发（或说整合）时间很短，很难相信这会是一款完全从第一行代码写起的操作系统，它反而很可能是给Linux内核加一个壳而已，有多少成分会是“完全自主知识产权”还很难界定。

2、如果是基于公开核心代码的Linux开发的国产系统，就不要假“国家安全”之名去谈安全问题了。

3、办公软件如何解决？微软的Office套件从1985年开始基于Mac机研发第一代Word，Office3.0套件则发布于1993年，20年中迭代超过12次，苹果iwork则在2005年发布，也有近10年的更新历史。如果这个国产系统是基于Linux，那么还有永中、open office以及金山WPS可选。当然，发布于1989年的金山办公软件一定忘不了当年被Microsoft Office挤压，不得全面兼容后者的历史。更多大型图、影、音软件，恐怕依然无法在小众系统上运行。

4、系统不是你想做，想做就能做。未来整个生态系统的维护，是靠企业、用户自觉选择，还是靠行政能力在教育、经济领域强推？成本会是多少？

如果玩，请玩真的。
