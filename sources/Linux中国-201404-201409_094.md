# 中科红旗卖身内幕

陷入清算状态的中科红旗终于成功找到了下家。

　　8月14日下午，五甲万京信息科技产业集团(以下简称“五甲万京”)在北京召开小规模的媒体沟通会，宣布该公司以3862万元收购中科红旗。

　　五甲万京表示，公司将继续承担红旗Linux相关产品研发、销售、技术服务支持和品牌推广等工作。

　　该公司董事长孙凯歌介绍，未来收购完成后，中科红旗品牌并不会消失，而会成为五甲万京“平行公司”来运作。

### 　　五甲万京接盘

　　由于资金链断裂，中科红旗股东们今年2月宣布公司解散，员工劳动合同全部终止，公司进入清算程序。6个月后，中科红旗正式启动拍卖程序，而经过多轮竞购后，五甲万京最后胜出。

　　多数人可能对于五甲万京并不不了解。公开资料显示，这家公司成立于2002年，总部位于大连市，在大连市和内蒙古赤峰市两地拥有两个信息科技产业园，旗下产品有 TNTOS Linux 操作系统、小企鹅拇指计算机、IC集成电路(芯片)等。

　　对于为什么斥资近4000万获得中科红旗的资产，五甲万京董事长孙凯歌给出的解释颇显他对国产操作系统的情怀。

　　“中国红旗是中国计算机操作系统的旗帜，红旗不能倒，我不拿别人也会拿。”孙凯歌说，“我们的旗帜被人推倒了，失去的将是对整个产业的信心。因此，我决定不惜一切代价拿下红旗。”

　　据孙凯歌透露，他向到场参与竞价的公司高管授信了5000万元，并且“一旦竞价超过5000万元，我会在3秒钟内决定是否会继续加价。”

　　据了解，针对中科红旗资产的最终竞价是在7月26日进行的，当天有三家公司在经过专家组评审后，参与了最终的竞价，这三家分别是：成都勤智科技、普华基础软件、五甲万京。此前，曙光公司、中标软件也提出过收购的意思。

### 　　普华软件遗憾出局

　　据知情人士透露，成都勤智科技在竞价初期就显得实力不足，最终的竞价实际上是在普华基础软件和五甲万京之间展开。

　　双方在1862万元的底价上，按照每次增加100万元，展开了竞购。双方你来我往数个回合。普华基础软件最后一次给出了3762万元的报价，而五甲万京则在此基础上又增加了100万，即3862万元。

　　也许是看到了五甲万京的决心，普华基础软件最终决定不再加价。最终，五甲万京成为最后的胜出方，获得了中科红旗的资产。目前，五甲万京已向北京法院拨付2000万元支付中科红旗的员工欠薪。

　　在此之前，普华基础软件接盘中科红旗的呼声一度很高。今年6月，普华基础软件曾公开宣布接手中科红旗的客户技术服务工作，并接收了数十名中科红旗研发、技术支持和销售的核心员工。这曾被解读为整体接盘中科红旗前奏。

　　知情人士透露，在竞购当天的专家评审中，普华基础软件在技术、市场和完成中科红旗后续核高基项目等指标上实际上表现出色。但五甲万京“不惜一切代价”拿下的决心，并且不断给出更高的价格，最终帮助其赢得了竞购。

　　上述知情人士说，普华基础软件其实从母公司拿到的授信额是1.5亿元，但是五甲万京在竞购中表现出来的决心，还是让普华基础软件觉得理性退出才是好的选择。因为，收购中科红旗的资产最终还是一门生意，需要作出理性的抉择。

### 　　红旗品牌并不会消失

　　目前，五甲万京只是与中科红旗签订了资产收购协议，距离收购真正完成仍然需要一段时间。但对于中科红旗的发展规划，五甲万京已经有了初步的想法。

　　据五甲万京董事长孙凯歌介绍，未来收购完成后，中科红旗品牌并不会消失，而会成为五甲万京的“平行公司”来运作。除了做好中科红旗现有客户的服务和产品推广外，五甲万京还会投入资源进行新的产品开发。

　　孙凯歌表示，中科红旗需要稳健地发展，而实现盈利则需要一段很长的时间。他坦言：“中科红旗是一个大旗，扛起来，压力挺大。”

　　孙凯歌表示，未来将联合国内的软硬件企业建立中国操作系统的产业链，努力形成以北京为操作系统的研发、市场销售中心，赤峰为测试、产业化中心和孵化器园区，大连为教育学院和软件打包中心的红旗产业之城布局。

　　中国工程院倪光南院士对五甲万京收购中科红旗表示赞赏。他表示，五甲万京在Linux社区中有很好的口碑，并有很强的实力，相信他们在中国智能终端操作系统产业联盟的支持下，一定能使红旗这个品牌为国产操作系统发展作出更大贡献。

　　在倪光南看来，在国家重视信息安全的大环境下，政府和央企将会采用国产操作系统，而这将是国产操作系统的一个发展突破口。

　　据五甲万京官方网站介绍，五甲TNTOS Linux的设计目标是替代国外X86桌面系统，最终实现操作系统国产化。TNTOS Linux主要应用方向定位于政府及企事业单位的商业应用操作系统，以及行业定制的操作系统，也可用于个人个人用户的桌面操作系统。

　　实际上，TNTOS Linux与红旗Linux操作系统在产品和市场拓展的模式上很类似。但孙凯歌表示，未来这两项产品会独立发展，不会进行合并。

　　中科红旗工会主席贺唯佳对新浪科技表示，在他看来，普华基础软件是中科红旗的最佳接盘者，但他也接受目前的结果。

　　“我并不了解五甲万京收购中科红旗的真实目的，但不管怎样，这对于被拖欠工资的员工们而言是一件好事情。”贺唯佳说，五甲万京能否盘活红旗资产还是个未知数，但他希望五甲万京“能把红旗舞动得更好”。
