# 最新的英特尔Linux图形驱动程序可以在Ubuntu 14.04 LTS上使用了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200583291&idx=1&sn=c65f761898d7e679c051a3b757bc5c02&chksm=28e8933d1f9f1a2bb493aa3527b778c4c99649d12389fcc5c227a647fed40efa53e2c7934b1f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200583291&idx=1&sn=c65f761898d7e679c051a3b757bc5c02&chksm=28e8933d1f9f1a2bb493aa3527b778c4c99649d12389fcc5c227a647fed40efa53e2c7934b1f&scene=27#wechat_redirect)

**新版本的英特尔Linux图形安装程序可下载。**

这个开源工具提供了简单途径在Ubuntu中获取最新因特尔设备支持的图形和视频驱动。

在**版本1.0.6**中首次使其六月底发布的2014Q2图形堆栈可在Ubuntu 14.04中使用。

它也带来了更好的Bay Trail性能，节能优化，并且改善了对英特尔Broadwell芯片的支持。

对Linux用户来说，想要向Intel所说的那样“保持当前最新的改进、优化和修复”，最好的方法就是运行最新可用的堆栈。

### 下载

最新版本的图形安装程序支持Ubuntu 14.04 LTS和Fedora 20。Ubuntu 13.10的用户可以继续使用这个工具，但不能获取最新的驱动程序。

Ubuntu 14.04 LTS 32位或64位可用的的Deb安装包可在 01.org 网站下载，链接如下。
