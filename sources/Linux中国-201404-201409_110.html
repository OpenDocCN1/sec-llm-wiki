Docker融资4000万美元以上，估值达4亿美元

据GigaOM援引两位熟悉内幕人士的说法，最近炙手可热的容器管理初创企业 Docker 正在完成一轮高达 4000 万到 7500 万美元的融资轮，估值约达 4 亿美元，交易预计在几周内结束。

对于开发者来说，环境的安装和部署是脏累活。但那些脏累活是他要实现自己要做的事情的基础工作，所以不得不做。不过，近年来，业界正在作着简化此类事情的努力。此类努力有大小两个方向，大的方向是将整个计算环境视为一台计算机管理，如不久前获 1600 万美元融资的Mesosphere，其 Mesos 可以把所有数据中心和云资源管理整合为一个大的资源池。小的方向是小虚拟机化，将应用和应用的依赖封装进一个用户空间内，打包成容器。容器作为独立进程，可与其他容器共享内核—其效果上与虚拟机一样，但是颗粒度要更细（虚机只能独享内核）、更灵活高效。

Docker 就是走小虚拟机的方向。它是由 dotCloud 创建的一款开源应用引擎，它相当于是加在 LXC（LinuX Containers，一种轻量、基于容器、操作系统层的虚拟化技术）上的管道，通过高级 API 为进程单独提供了一个轻量级的虚拟环境。Docker 由管理容器的服务器守护程序（server daemon）、控制服务器守护程序的命令行客户端以及 Docker 镜像组成。正像其名字一样，Docker 镜像犹如一个个的集装箱，可以将一个个运行的应用打包并快速转移 / 复制到其他机器上，并且在守护程序的管理下，转移过去的容器中的应用在数秒钟之内即可启动运行，非常的方便快捷。

去年 1 月 Docker 曾进行了 1500 万美元的 B 轮融资，截止目前，其总融资额为 2600 万美元。最近，随着 Google、Spotify 以及 Red Hat 等大公司纷纷把容器作为简化基础设施管理和应用部署的有效方式，Docker 的发展势头非常猛。目前下载的 Docker 引擎数已达 275 万个，注册的 Docker 应用达 14000，在 33 个国家共有 90 个 Docker 小组，基于 Docker 的解决方案风头已盖过了早期的 PaaS。内幕人士称此轮融资完全是由希望拿到这艘集装箱货轮船票的外部投资者出资的。
