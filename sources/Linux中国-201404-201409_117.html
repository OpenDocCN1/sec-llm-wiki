真正的“Android + Linux”双系统迷你主机：VolksPC

一直以来，双操作系统的 PC 在市面上非常罕见，但自从移动操作系统开始变得更强大之后，很多可以同时运行两个操作系统的设备逐渐多了。安锋网 8 月 8 日消息，近日，一家国外厂商发布了一款名为 VolksPC 的设备，通过定制 MicroXwin 软件系统号称可以同时运行两个操作系统。

按照以往，在同一台机子上，大多操作系统无法同一时间一起运行，因为系统的格式和硬盘上的数据有所不同。比较实际的做法是，在不同的硬盘储存商单独安装每个操作系统，并在启动时选择不同的引导盘进入对应的操作系统。这样对于想玩双操作系统大多数用户都很不舒服，因为很多人电脑只有 1 个硬盘。

VolksPC 之所以诞生就是为了打破传统的思路，做到了同时引导和运行两个操作系统。其原始软件系统 MicroXwin 虽然看似微软 Windows，但不要被名字所欺骗了，其双系统支持并不支持 Windows。相反，它支持同时运行 Android 和 Debian Linux 操作系统。

用户可以同一时间启动 Android 4.2 Jelly Bean 和 Debian 7.0 Wheezy 操作系统，因此同时运行 Linux 和 Android 引用程序也没问题，唯一要做的只是在 Android 和 Linux 两个桌面环境之间切换，分别在两个桌面上使用不同的应用程序，但也是真正实现了两个操作系统同时运行。

VolksPC 设备只是一款迷你的 PC，体积大小与我们常见的路由器相仿，无法运行 Windows 是因为其内部硬件基于 ARM 芯片，而不是 AMD 或 Intel 的处理器。主要硬件 CPU 的具体型号为 Rockchip RK3066， Cortex-A9 双核，默认主频 1.4GHz，内置 1GB RAM。

其余配置还包括有 8GB 的储存空间、802.11n WiFi 模块，机身上设有 2 个 USB 2.0 接口、以太网接口、1x micro USB OTG 接口以及一个标准 HDMI 视频输出接口。

VolksPC 官方报价为 119 美元，约 730 元人民币，预计从 10 月份开始出货，不过目前该项目仍在 Indiegogo 上凑资，如果资金达不到 80000 美元可能会撤销项目。
