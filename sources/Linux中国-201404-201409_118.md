# Linux 基金会免费课程《Linux 导论》开课

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200570132&idx=4&sn=1f17d73b7784e1e86a96235d63408e2b&chksm=28e84e521f9fc744ea95b7343e2fbade07708e83420b8098c20b9f26a943c2cf4193a44fd5be&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200570132&idx=4&sn=1f17d73b7784e1e86a96235d63408e2b&chksm=28e84e521f9fc744ea95b7343e2fbade07708e83420b8098c20b9f26a943c2cf4193a44fd5be&scene=27#wechat_redirect)

**Linux 基金会与 edX 合作推出的 Linux 系列 MOOC 课程系列首个课程《Introduction to Linux》（Linux 导论，LFS101），已经在 8 月 1 日正式开课。**

Linux 基金会打算通过高质量 Linux 课程让更多的人了解 Linux 系统。本系列课程，与大多数 edX 上的课程一样完全免费。 

**本课程要求：**不论你以前是否接触过 Linux，也不论你目前是自由职业者或是在企业上班，只要熟悉计算机操作，就可以参加该课程。在完成该课程后，你将对 Linux 系统操作（图形界面和命令行）有较好的了解，使你能自由切换使用多种不同版本的 Linux 系统。

**关于培训导师 **  
Jerry Cooperstein 从 1994 年开始从事 Linux 相关工作，开发内核空间和用户空间，并全面负责 Linux 基金会的所有培训内容。他在核天体物理领域工作了 20 年，在多种超级计算机上开发先进仿真软件，同时从事本科生和研究生的教学工作。 Cooperstein 于 2009 年加入 Linux 基金会，任项目培训总监。
