# 报道称Windows Threshold将引入类似Ubuntu的虚拟桌面

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200558134&idx=4&sn=47804d06471cb76d67e75f9bcefcbfd6&chksm=28e87d701f9ff466a2801e3e65d8360428014e01360a4f2002aea312c035ca23bcb45a01e450&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200558134&idx=4&sn=47804d06471cb76d67e75f9bcefcbfd6&chksm=28e87d701f9ff466a2801e3e65d8360428014e01360a4f2002aea312c035ca23bcb45a01e450&scene=27#wechat_redirect)

在过去的几周里，有关Windows Threshold的细节也陆续变得清晰了起来。此前，我们曾谈论过Threshold的UI会与其它版本的Windows很不一样，就像当年从Windows XP迁移到Windows 7时的感觉。但在我们深入之前，请记住该系认仍处于早期开发阶段，很多功能或许会在后续更新中加入，也或许会在最终版本中被砍掉。

上图为Ubuntu Linux的虚拟桌面，Windows Threshold也将有类似的实现。

Windows Threshold实验中的功能仍处于早期发展阶段，因此在RTM之前的bug仍在所难免。据悉，微软将为下一代Windows带来虚拟桌面(virtual desktops)功能，该功能已在当前的Ubuntu和OS X等平台上出现，而Windows Threshold的功能会与Ubuntu更为接近。用户将能够通过任务栏上的图标激活该功能，并配有可在多个“桌面”进行跳转的快捷键。

对于未曾使用过虚拟桌面的用户来说，该功能有助于使用者轻松组织(摆放)不同内容并集中注意力。通过该功能，用户可在多个“桌面”间进行切换，在打开一个应用时，在另一桌面打开其他应用程序。例如，你可以在一个桌面打开Outlook、然后在另一个桌面(工作区)打开Web浏览器。

该功能非常适合屏幕较小或只有一台显示器的桌面设备，对于提高生产力有着非常显著的作用。对于微软来说，这将会是说服Windows 7和XP用户进行升级的一个重要理由。若Windows Threshold确定引入该功能，想必会吸引到不少注重生产力的高级用户。
