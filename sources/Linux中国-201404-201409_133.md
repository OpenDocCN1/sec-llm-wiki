# Linux Kernel 3.16 正式版发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200543378&idx=1&sn=c5ba8beb1317e4d4068049c85ee2149a&chksm=28e837d41f9fbec27acd7d0c93272c819ac2f8af6ea629dbf4611accc4a4e3578df4b95ce749&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200543378&idx=1&sn=c5ba8beb1317e4d4068049c85ee2149a&chksm=28e837d41f9fbec27acd7d0c93272c819ac2f8af6ea629dbf4611accc4a4e3578df4b95ce749&scene=27#wechat_redirect)

Linux Kernel 3.16 正式版发布，Linux操作系统的内核以C语言写成，符合POSIX标准，以GNU通用公共许可证发布。Linux最早是由芬兰黑客林纳斯·托瓦兹为尝试在英特尔x86架构上提供自由免费的类Unix系统而开发的。

详情如下：

mainline:3.16 \[tar.xz\]\[pgp\]\[patch\]\[view patch\] \[cgit\] 

Linux 3.16 内核主要包含如下新特性：

1.  支持 Nouveau Kepler re-clocking
    
2.  支持 Samsung Exynos multi-platform
    
3.  更好的支持 Jetson TK1 ARM
    
4.  在 Intel's P-State driver 中支持Broadwell
    
5.  Dell free-fall 驱动程序支持
    
6.  一个新的 Synaptics 输入驱动
    
7.  Blk-mq 多队列实现基本完成
    
8.  首次支持 GK20A
    
9.  AMD Radeon 图形驱动更快
    
10.  Intel Cherryview 支持
