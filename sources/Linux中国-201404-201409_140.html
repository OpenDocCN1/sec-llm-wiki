Windows在中国OS市场依然是“独孤求败”

原文：http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200538667&idx=4&sn=6d226d183f295d126e27fa4d6d621941&chksm=28efc16d1f98487b789aa1161e8a116e7a88ed3150277dd2acf25c834aa4df6f3152e6047544&scene=27#wechat_redirect

尽管此前有消息称，国内政府部门希望可以将自主研发的操作系统或者 Linux 系统取代 Windows，但这一想法目前显然是无法实现的。市调机构 CNCC 日前新发布的一份统计报告显示，Windows 在中国 OS 市场依然占据着绝对领导的地位。

这份统计报告日前通过CNTV报道指出，目前在中国市场，83.4% 的用户电脑上都安装着微软的 Windows 系统，这也就意味着，即使政府再如何努力推动 Linux 成为可替代的操作系统平台，在短期甚至是长期内也无法撼动 Windows 的地位。

同时，这份报告还提到，Linux 系统目前是国内政府官员的首选系统，不过仅安装在 0.1% 的电脑上，根据这项数据显然可以推测，Windows 在中国 OS 市场短期内应该不会出现具有威胁力的竞争对手。


不过，Windows 在中国的发展形势也有不妙的一面，目前中国绝大多数搭载 Windows 系统的电脑采用的都是盗版版本，这或多或少证实了微软前CEO 史蒂夫·鲍尔默此前自己进行的统计，在 10 个用户中就有 9 个的 Windows 许可证是盗版的。
