# openSUSE Factory成为滚动更新发行版

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200524840&idx=1&sn=368f6206fed48aebd46e501640c694ac&chksm=28efff6e1f987678f0aea9d291a5853abbd3412394620242fd1f55d8ba2116318d39dec8bf10&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200524840&idx=1&sn=368f6206fed48aebd46e501640c694ac&chksm=28efff6e1f987678f0aea9d291a5853abbd3412394620242fd1f55d8ba2116318d39dec8bf10&scene=27#wechat_redirect)

openSUSE项目宣布，Factory开发版本转变为采用滚动更新模式的独立发行版。openSUSE称，更新的软件包不会直接进入到Factory，而是需要经过自动和手动的检查和测试，证明其功能和值得信任后才会进入Factory。

openSUSE董事会主席Richard Brown认为，每日更新的Factory发行版将能简化预览和测试，有望吸引更多的用户和贡献者，能更快的修正bug和产生更高质量的最终产品。他表示，openSUSE Factory对他们至关重要，因为它是openSUSE和SUSE Linux Enterprise的基础。
