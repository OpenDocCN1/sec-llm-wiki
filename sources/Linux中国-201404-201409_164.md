# DNS根域名服务器 L 根镜像服务器引入中国

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200505621&idx=1&sn=24768c3964302165f4393d6bea29675e&chksm=28ef42531f98cb45b81c019ea1033806150253e34576d5a2a2af80493d72ed89ae7a3c9feca6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200505621&idx=1&sn=24768c3964302165f4393d6bea29675e&chksm=28ef42531f98cb45b81c019ea1033806150253e34576d5a2a2af80493d72ed89ae7a3c9feca6&scene=27#wechat_redirect)

中国北京，2014年7月25日，世纪互联公司与互联网名称与数字地址分配机构（The Internet Corporation for Assigned Names and Numbers，以下简称ICANN）开展合作，在中国增设**L根**域名服务器**镜像节点**。此举将整体提升域名系统（DNS）的安全性、稳定性以及容错性，缩短中国互联网用户查询域名的响应时间，并有助于抵御网络攻击、域名劫持和网络瘫痪等网络威胁。

互联网设备通过系列数字构成IP地址连接网络，对互联网用户来说，由名称构成的网络地址更便于使用和记忆。例如，"ICANN.org"相比IP地址2620:0:2d0:200::7更容易记。域名系统将域名与IP地址相对应，好比电话簿中人名与电话号码对应起来一样。目前，全球共有13个互联网域名根服务器系统，以字母A到M进行标识， L根服务器系统是其中之一。（LC注：而每个根服务器事实上又有多个镜像服务器。）

ICANN总裁兼首席执行官法迪.切哈迪对世纪互联在中国增设L根服务器镜像节点表示热烈祝贺。他说，双方的合作进一步增强了全球互联网的安全性、稳定性和容错性。

世纪互联"DNS开放网络计划"致力于建设稳定可靠的DNS基础设施，并与全国所有ISP和ICP实现开放互联。"北京是中国互联网普及率最高的一线城市，因此世纪互联决定首先在北京部署L根服务器镜像节点。"世纪互联集团总裁孟樸说："按照计划，我们很快将在全国主要城市部署更多根服务器镜像节点。"

世纪互联作为中国最大的互联网数据中心运营商，在全国40多个城市拥有80多个分布式数据中心。此次L根服务器镜像节点使用的硬件设施由世纪互联提供。世纪互联将确保其安全、稳定的运营，并向国内运营商免费提供服务。

ICANN副总裁兼亚太运营中心董事总经理郭又铨表示：ICANN很高兴与世纪互联开展合作，并将继续与中国企业和机构合作，将更多L根服务器镜像节点引入中国。
