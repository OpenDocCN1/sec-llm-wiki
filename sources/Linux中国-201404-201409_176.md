# EFF呼吁黑客帮助他们开发开放无线路由器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200488919&idx=1&sn=1b8b20f821f93b8e7c08e586e019f200&chksm=28ef0c911f988587b42464648706e262d2bbc1601a636b03eaedd26d7f6a5c55acfd9bfede35&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200488919&idx=1&sn=1b8b20f821f93b8e7c08e586e019f200&chksm=28ef0c911f988587b42464648706e262d2bbc1601a636b03eaedd26d7f6a5c55acfd9bfede35&scene=27#wechat_redirect)

电子前哨基金会（EFF）在纽约举行的 HOPE X (Hackers on Planet Earth) 大会上宣布发起开放无线路由器项目，并呼吁黑客社区帮组他们完成这一项目。

开放无线路由器具有现有路由器所没有的功能，比如你可以在路由器上同时设置加密和开放无线网络，开放网络向来访的客人或过路人开放互联网访问，同时保留加密的WPA2网络供自己家人和朋友同事使用；你还可以对开放网络设置带宽限制，避免流量超出限额。此外还有一些网络排队和安全方面的增强和改进。

路由器的软件将是基于CeroWRT开发的。
