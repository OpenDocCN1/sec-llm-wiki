# 俄罗斯正考虑撇开微软并自行开发软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200488919&idx=2&sn=5ee49b02a9aaad07aa99235284b5f493&chksm=28ef0c911f9885874489ff6c96eafe2e7ccf55eeb6e79f501a60834e1bacdd4bd1f54220d033&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200488919&idx=2&sn=5ee49b02a9aaad07aa99235284b5f493&chksm=28ef0c911f9885874489ff6c96eafe2e7ccf55eeb6e79f501a60834e1bacdd4bd1f54220d033&scene=27#wechat_redirect)

微软的Windows操作系统软件已经普及到了全球各个角落，无论是消费者还是政府都有采用。但如果你居住在俄罗斯，对Windows的这种依赖或许会被打破，因为当地政府正在考虑自主开发软件。由于美俄之间的政治形势时而会变得紧张，且美方最近刚宣布了对俄方的新一轮制裁，这使得俄罗斯在考虑通过限制使用微软软件，并以此作为对美国经济的“反击”。

当然，微软并不是俄方的唯一“反击”对象，惠普和甲骨文等企业也会受到影响。俄罗斯政府正在起草一份新的法案，这将推动政府机构和国营企业向本地软硬件供应商倾斜。

其想法是，政府应该支持本地供应商并购买其软硬件，而不是从美国地区进口商品。目前尚不清楚俄方是否有可信赖的Windows替代品，以及其它软硬件供应商是否能够提供相同级别的功能和安全性。

据报道，该法案的目的，只是“优先”考虑本土供应商，而不是彻底禁用进口产品。至于其日后会对美方造成多大的影响，仍然有待时间来检验。
