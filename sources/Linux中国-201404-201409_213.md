### 起源

“AOSC OS ”  Linux 发行版计划是由一个起源于**中学生**的开源爱好者社区——安同开源社区所维护的。

就在昨天，2014 年 7 月 10 日，安同开源社区正式宣布， AnthonOS发布了！这是这个计划的第一个成品。

安同开源社区起源于 2011 年 11 月，当初只有三名中学生参与其中，也只是对 openSUSE 这个发行版进行着简单的定制工作，后来又基于 Debian 衍生过一些版本。2013 年暑期社区决定通过对 Linux From Scratch 和 Beyond Linux From Scratch 的参考和学习，独立制作社区独立的发行版。这成为 AOSC OS 计划的开端。通过 AOSC OS 半年多的基础构建，2014 年 2 月，AnthonOS 和孪生的CentralPoint 服务器发行版开始 Beta 测试，CentralPoint 目前还在测试阶段中，因此不详细介绍。AnthonOS 通过今年 2月-6 月的四次 Beta 测试和一次 Release Candidate 发布，迎来了正式版。AOSC OS 计划终于在一年后迎来了第一个成品。

![](../Images/5e677d3f5f14d3f13ecae5f7569b84af.png)

AOSC OS 作为一个新生的发行版分支，社区开发组深知让人们去接受的难度。然而 AOSC OS，直至 AnthonOS 的发行，一直秉持一个不变的思维：**简化 。**

虽然目前的 AOSC OS 使用着 DPKG 包管理器（明年还将同时支持 RPM），配合 APT ，这样的组合非常类似目前 “Debian 系” 的发行版，但是 AOSC OS 和所谓 Debian 系有着根源上的巨大差异。与 Debian 把软件包根据用途细分的做法不同，AOSC OS 中的软件包并没有进行任何的拆分，也就是说， “gcc” 对应的就是 GNU 编译器集合，而不像当前的 Debian Wheezy 一样细分成 “fixincludes”, “lib32go0-dbg” 这样的一共 93 个包，从而尽可能去减少对于使用者的迷惑。我们深知这样可能会导致系统相应的肿大，但是我们认为，为了简化，这值得做。

因此我们认为这一年的努力，虽然可能无法将 AnthonOS 直接构建成一个能和 Debian，Fedora 之类相提并论的成熟发行版，但是我们坚信通过今后几年不懈的努力， AnthonOS，CentralPoint 都会变得越来越可靠和成熟，从而让更多人去接受。

### **AnthonOS ****特性**

这里通过几句话来描述 AnthonOS 的特性。

*   AnthonOS 有着可以和 Arch 相媲美的简化度  
    
*   AnthonOS 使用 systemd，保证了系统启动的速度和高度的可管理性  
    
*   AnthonOS 使用 DPKG/APT 进行包管理，让原来使用 Debian 或其衍生版本（包括 Ubuntu）的用户不至于不知所措  
    
*   AnthonOS 默认带有带有强大图形功能的 KDE (4.12.2) 桌面环境，配合各种图形化管理工具（如 Apper 和 KUser），让新手免于集中学习命令行使用的痛苦  
    
*   AnthonOS 默认带有编译器和各类基本的图形开发环境，方便开发者，并免于各类配置工作  
    
*   AnthonOS 在追求软件新颖的同时会考虑稳定性的需要，因此并不会完全滚动更新

### **开发花絮**

社区发行版的开发组成员由于种种原因的限制（比如学业）并没有条件可以同处一个工作室一般的环境中一起工作，更没有非常好的设备。社区的网络服务器和源镜像之类，都来自多家公司和学校的赞助。

而 AOSC OS 这个从源码构建的成果，正是在这个环境下完成的。无论在交流上，还是在硬件上，我们并不能 Deepin 之类有商业公司支持的大型社区或项目相提并论。但是我们相信社区的力量，通过大家的参与，这个项目一定会走得越来越好。
