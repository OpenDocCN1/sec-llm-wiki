# 直到Fedora 23才有可能默认启用Wayland

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200447842&idx=1&sn=647b2c387fae02ed8a77a841c3a888ea&chksm=28eeac241f992532fc8c6c1e539f9f1ff30891b106ff6ec5f944d10e3e4125787f329ddc5ada&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200447842&idx=1&sn=647b2c387fae02ed8a77a841c3a888ea&chksm=28eeac241f992532fc8c6c1e539f9f1ff30891b106ff6ec5f944d10e3e4125787f329ddc5ada&scene=27#wechat_redirect)

GNOME开发者、Red Hat的高级软件工程经理Christian Schaller在博客上谈论了Fedora支持Wayland显示管理器的现状和未来计划。

Fedora Workstation 21计划在下个月发布，开发者原计划在Fedora 21中，Wayland将能运行完整功能的桌面，但这一目标未能完成。

Wayland的功能还不完整，如XWayland不支持3D加速。在默认启用Wayland前，Fedora将需要发布一个版本，包含可选使用且功能完整的Wayland。

由于Fedora 21没有实现这一目标，他们计划延期到Fedora 22，这意味着Fedora 23将成为第一个默认启用Wayland的版本。
