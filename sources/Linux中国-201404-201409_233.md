# 树莓派杀手 - HummingBoard开始接受预定

SolidRun开始接受树莓派杀手设备的预定。这款树莓派杀手名称是HummingBoard。这款采用ARM处理器的HummingBoard，现在可以在SolidRun公司官网预定，预定价格45美元，其中包括各种接口，包括USB电源。SolidRun生产的HummingBoard，针对DIY用户，能够运行Android和各种Linux发行版，并且有各种各样的用途，包括搭建媒体中心、共享系统等等。整个装置体积足够小，足以放在手掌当中。

HummingBoard提供了多种连接选项，其中最多四个USB端口，以及一个mini PCIe插槽、一个HDMI端口，一个mini SATA端口，以太网接口，GPIO引脚，LVDS显示输出，数字和模拟音频，红外和相机接口。

SolidRun目前提供三个不同版本的HummingBoard可供选择：i1，i2和i2eX。 i1是入门产品，而i2内存容量和处理能力翻倍，i2eX是最高端产品，提供上面列出的所有连接选。这三款产品售价分别为45美元，75美元和100美元。
