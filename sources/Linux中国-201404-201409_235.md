# 微软云储存服务OneDrive被封锁

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200433219&idx=2&sn=44ab9ffe09b34b4fc69926fb770c2509&chksm=28ee65051f99ec1371365166afdb9b48a2011191fff3072c4c46f1268a938b9e952b985c77ba&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200433219&idx=2&sn=44ab9ffe09b34b4fc69926fb770c2509&chksm=28ee65051f99ec1371365166afdb9b48a2011191fff3072c4c46f1268a938b9e952b985c77ba&scene=27#wechat_redirect)

﻿在Line等服务遭到屏蔽的同时，软件巨人的云储存服务OneDrive也一并被封锁。

此举既出人意料但也不是没有前兆：微软与中国政府向来关系密切，然而最近中国政府对Windows 8和Office办公软件先后下达了禁令，而传闻禁止使用Windows 8的一个原因是其捆绑的云储存服务OneDrive。除了Web端被封锁外，用户在OneDrive移动客户端主页留言抱怨连不上服务器。

目前尚未看到微软对此的回应，而昨天微软宣布对Outlook和OneDrive启用完全正向加密和2048位密钥。
