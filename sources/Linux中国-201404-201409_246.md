# 政府机构禁止使用微软Office？这事情说不清

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200420961&idx=2&sn=cc71707b537115b39103f2eebff5ccb4&chksm=28ee15271f999c310fb6ddc6e2799bf5103b83c09b3d2bdb091b11dc7a4cb414a84275521e8d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200420961&idx=2&sn=cc71707b537115b39103f2eebff5ccb4&chksm=28ee15271f999c310fb6ddc6e2799bf5103b83c09b3d2bdb091b11dc7a4cb414a84275521e8d&scene=27#wechat_redirect)

国内媒体引用匿名消息来源称，部分中央机关及下属部门已经内部要求停止使用Office，转而使用国产办公软件系统。和此前的Windows 8禁令一样，Office禁令无法获得官方确认。微软则第一时间声明Office政府采购工作正常。

官媒新华社转载了中国网的报道称，包括财政部在内的发言人对这一报道感到惊讶，表示“并未接到类似规定或通知，报道不太准确”。但新华网的这篇转载已经删除，不知道是否代表着默认还是另有隐情。

Windows 8禁令的理由传闻是国家安全，但微软Office与国家安全联系不上，用国产办公软件替代更像是减少对微软办公软件的依赖。
