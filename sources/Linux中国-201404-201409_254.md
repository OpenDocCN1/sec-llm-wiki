# Ubuntu 14.10已经开始启动测试: "Utopic Unicorn Alpha 1"

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200409818&idx=2&sn=bab17d03caa2b070e3ad94c22691c827&chksm=28ee399c1f99b08aea0bb461a5e61f4b0b38e0428580fff503af80d29dc585d8dfe1c8b21506&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200409818&idx=2&sn=bab17d03caa2b070e3ad94c22691c827&chksm=28ee399c1f99b08aea0bb461a5e61f4b0b38e0428580fff503af80d29dc585d8dfe1c8b21506&scene=27#wechat_redirect)

如果你想体验最新版本的Ubuntu的话，代号命名为“Utopic Unicorn Alpha 1”版本的Ubuntu 14.10系统已经正式发布。一些可用于GNOME, Kubuntu的信息已经可以看到了，同时也有一些关于系统和软件更新的信息。

如任何一款预发布的软件测试版本一样，都想尽力去减少软件中的漏洞。如果你想为这个版本的系统做出点贡献，来帮忙找出即将发布的系统Bugs，你可以从Ubuntu 的网站上下载ISO文件。

据说，Alpha 1现在已经在进行测试工作了，并且鼓励用户在使用过程能对比以前遇到的一些问题，并反馈一些信息回复给开发团队。

现在的话，你可以在CDimage.Ubuntu.com每天获取最新的系统信息。
