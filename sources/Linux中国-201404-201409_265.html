自由开源壁纸软件 Wallch 4.15 发布

Wallch 是一款类似 Variety 的开源壁纸软件。使用 Qt5 建立，支持的桌面环境 Gnome 3、 Unity、 XFCE、LXDE 和 Mate，还具有时钟功能。

可对你文件夹中壁纸做旋操作。

Ubuntu 用户安装，有PPA可用，打开终端，输入命令：

sudo add-apt-repository ppa:wallch/wallch-4.0
sudo apt-get update
sudo apt-get install wallch

如要移除 wallch ，可用命令：

sudo apt-get remove wallch
