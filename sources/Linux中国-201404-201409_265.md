# 自由开源壁纸软件 Wallch 4.15 发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200397185&idx=3&sn=d0b752f3f3ab08f985dc10c23711591d&chksm=28edeac71f9a63d1ef61ea310e369380e3cbd30d5e06f1e91c238d55be02c8bfd248d46e9ad0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200397185&idx=3&sn=d0b752f3f3ab08f985dc10c23711591d&chksm=28edeac71f9a63d1ef61ea310e369380e3cbd30d5e06f1e91c238d55be02c8bfd248d46e9ad0&scene=27#wechat_redirect)

Wallch 是一款类似 Variety 的开源壁纸软件。使用 Qt5 建立，支持的桌面环境 Gnome 3、 Unity、 XFCE、LXDE 和 Mate，还具有时钟功能。

可对你文件夹中壁纸做旋操作。

Ubuntu 用户安装，有PPA可用，打开终端，输入命令：

```
sudo add-apt-repository ppa:wallch/wallch-4.0
sudo apt-get update
sudo apt-get install wallch
```

如要移除 wallch ，可用命令：

```
sudo apt-get remove wallch
```
