# Ubuntu GNOME 14.10 将默认使用 GNOME 3.12

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200384139&idx=3&sn=8a22059de7b21af3597f4c1fba5a4fe6&chksm=28eda5cd1f9a2cdba07cf2537ca299817eaeaf466126cbb9922507167c252ea895355f766f13&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200384139&idx=3&sn=8a22059de7b21af3597f4c1fba5a4fe6&chksm=28eda5cd1f9a2cdba07cf2537ca299817eaeaf466126cbb9922507167c252ea895355f766f13&scene=27#wechat_redirect)

GNOME Shell 3.12 和 GTK + 3.12 已经加入到 Ubuntu 14.10 建议库中学习。最有可能的是很快就会被添加到默认存储库中，因此用户将能够拥有最新版本的 Gnome 应用程序。

就目前而言，只有 GNOME Shell 和 GTK + 更新到 3.12 版本，而其他应用程序仍然是来自 GNOME 3.10 或以上。

另外 Ubuntu GNOME 14.10 将采用 GNOME 3.12 已经成为事实，GNOME 3.14 将在九月发布，这与10月发布的 Ubuntu 14.10 时间太过接近，所以没有时间去测试和优化。

但如果你使用的是 Ubuntu 14.10 每日构建版本，你可以通过 PPA 安装和测试 GNOME 3.14（目前尚在开发中）。两者 Ubuntu 14.10 和 GNOME3.14 均属于开发发布，建议不要安装在您的主系统上，因为可能会出现一些不可预料的问题。

在 Ubuntu 14.10 上添加 Gnome 3.14 的PPAs，运行命令：

```
sudo apt-add-repository ppa:gnome3-team/gnome3
sudo apt-add-repository ppa:gnome3-team/gnome3-staging
sudo apt-add-repository ppa:ricotz/testing
```

更新本地存储库索引：

```
sudo apt-get update
```

并执行正常的系统升级：

```
sudo apt-get dist-upgrade
```

如果需要移除上述PPA：

```
sudo apt-get install ppa-purge
sudo ppa-purge ppa:ricotz/testing
sudo ppa-purge ppa:gnome3-team/gnome3-staging
sudo ppa-purge ppa:gnome3-team/gnome3
```
