Conky Manager 是一款简单的图形化工具，用以管理 Linux 桌面 conky scripts。 Conky Manager V2 已经发布了全面更新用户界面和选项。

该应用程序窗口看起来更加直观和易于使用：

![](../Images/913eaef361551669eb2d07693d7c1a48.png)

Ubuntu 安装，有PPA可用：

```
sudo add-apt-repository ppa:teejee2008/ppa
sudo apt-get update
sudo apt-get install conky-manager
```
