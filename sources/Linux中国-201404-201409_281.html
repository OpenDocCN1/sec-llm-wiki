Ubuntu 及衍生版本用户如何安装 Docky 3.0

Docky 是一款类似于 MAC OS X 底部启动器的软件程序。同时，它可显示天气预报提供了一大堆 docklets，时钟和CPU使用情况，在某种程度上类似于 AWN 和 cairo-dock。

可用的最新版本Docky 3.0，最近已发布。

安装，有PPA可用，适用于几乎所有Ubuntu版本，终端输入以下命令：

sudo add-apt-repository ppa:ricotz/docky
sudo apt-get update
sudo apt-get install docky

卸载 docky 命令：

sudo apt-get remove docky
