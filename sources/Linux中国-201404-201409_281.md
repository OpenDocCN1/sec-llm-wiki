# Ubuntu 及衍生版本用户如何安装 Docky 3.0

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200381411&idx=3&sn=5811db221ce68bb46910a5a89be57fcc&chksm=28eda8a51f9a21b3347484db0f8f08eccda5f203de0272071932d2071948e1b0796b91f0fc8b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200381411&idx=3&sn=5811db221ce68bb46910a5a89be57fcc&chksm=28eda8a51f9a21b3347484db0f8f08eccda5f203de0272071932d2071948e1b0796b91f0fc8b&scene=27#wechat_redirect)

Docky 是一款类似于 MAC OS X 底部启动器的软件程序。同时，它可显示天气预报提供了一大堆 docklets，时钟和CPU使用情况，在某种程度上类似于 AWN 和 cairo-dock。

可用的最新版本Docky 3.0，最近已发布。

安装，有PPA可用，适用于几乎所有Ubuntu版本，终端输入以下命令：

```
sudo add-apt-repository ppa:ricotz/docky
sudo apt-get update
sudo apt-get install docky
```

卸载 docky 命令：

```
sudo apt-get remove docky
```
