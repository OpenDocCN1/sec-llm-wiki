友情提醒

请不要在虚拟机中安装使用和评测

由于Deepin 2014 以Compiz作为窗口管理器，Compiz在虚拟机中性能不佳，强烈建议各位将Deepin2014 直接安装在真实机器上，这样才能真正体验到Deepin 2014的华丽效果。

我们计划在未来的版本中，使用自己开发的窗口管理器代替Compiz，从而彻底解决这个问题。

概述

Linux Deepin项目现已正式更名为Deepin项目。

Deepin是一个致力于为全球用户提供美观易用，安全可靠的Linux发行版，Deepin团队基于HTML5技术开发了的全新深度桌面环境，以及音乐播放器，视频播放器，软件中心等一系列特色软件。

近年来，Deepin发展迅速，获得全球四十多个国家和地区用户的支持，累计下载量数千万次，并成为在Distrowatch上排名最高的中国Linux操作系统发行版。

Deepin 2014 RC与Beta版本相比，进行了如下更新和变化：

深度桌面环境我们对Deepin 2014 RC系统内部进行了全面优化，开机内存占用仅需500M，并且完善了系统内部消息的提示机制，使深度桌面环境更为轻巧灵敏。

为了让Deepin 2014 RC整体风格和外观趋于一致，我们完善深度系统主题。同时在该版本中新增了用户引导，通过生动、简单的引导，让新用户迅速掌握常用的各项操作。

控制中心

Deepin2014 RC 带来了全面完善的控制中心。

我们针对显示、网络、蓝牙和个性化等重要模块功能进行了全面完善，同时新增了网络代{过}{滤}理、切换系统语言和切换系统内置主题等多项实用功能。

软件管理

Deepin 2014 RC让Linux下软件管理变得前所未有的简单！

深度桌面环境已经支持启动器中直接右键卸载程序，也支持将启动器中的程序图标拖拽到垃圾桶中卸载。在原有软件仓库的基础上，我们新增了大量的第三方软件，打开深度软件中心可直接安装使用。

现在，在Deepin下的无论是安装还是卸载软件，不需要繁琐的Root认证和复杂的操作！

此外，Deepin项目在全球拥有60个以上的镜像源，你可以打开深度软件中心—选项页面，选择你连接速度最快的源，以便你能够快速的更新系统和安装软件。

社区参与

Deepin社区参与让Deepin 2014 RC更具魅力！

Deepin2014 RC默认搭载Deepin 2014壁纸大赛获奖作品，同时吸收了大量国内外社区用户提交的软件翻译和程序补丁，不断强大的Deepin社区推动着Deepin项目的不断发展和壮大！

安装

下载Deepin 2014 RC镜像后，请使用我们开发的深度启动盘制作工具来制作Deepin系统启动盘，详细安装教程见百科。

目前深度启动盘制作工具同时支持Linux、Windows和Mac平台，并且内置于Deepin2014 RC镜像中，你可以直接从镜像中提取或者单独下载使用。

注意：Deepin 2014 RC已经去除DeepinWin(Wubi)安装模式。
