# DNF 预期于 Fedora 22 取代 Yum

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200364507&idx=2&sn=5241c774dcf567a0b9375fe079574618&chksm=28ed6a9d1f9ae38b130fc900e39e2450c4d769be3ceae743f135b8e8d64305586bc9d4825f15&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200364507&idx=2&sn=5241c774dcf567a0b9375fe079574618&chksm=28ed6a9d1f9ae38b130fc900e39e2450c4d769be3ceae743f135b8e8d64305586bc9d4825f15&scene=27#wechat_redirect)

尽管 Fedora 21 还要到 10 月份才能发布，关于 Fedora 22 的功能提议已经开始，其中一个亮点既是用 DNF 替代 Yum 成为默认包管理工具。

DNF 从 Yum 分支出来，使用专注于性能的 C 语言库 hawkey 进行依赖关系解析工作，大幅度提升包管理操作效率并降低内存消耗。此外 DNF 还支持 Python 3。

要替换 Yum 成为默认包管理工具，还需要实现的有：

*   修改 Anaconda 安装器使其默认使用 DNF。
    
*   重新实现当下 yum-utils 里的工具。
    
*   提供 yum 到 dnf 的命令重定向方便用户迁移。
    
*   该变化对于使用图形化安装工具的用户来说是透明，现阶段 PackageKit 已经支持 dnf 可以随时切换(?)。
