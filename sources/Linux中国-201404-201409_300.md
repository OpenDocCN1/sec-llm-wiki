# 两名学生创建开源大脑信号存储设备

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200362030&idx=3&sn=80240aead9508071b3da3335096c538f&chksm=28ed73681f9afa7e8b48a6f97dd112b35d430faebe5840c1c6d86dd519b8f5acbb9c1269acdd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200362030&idx=3&sn=80240aead9508071b3da3335096c538f&chksm=28ed73681f9afa7e8b48a6f97dd112b35d430faebe5840c1c6d86dd519b8f5acbb9c1269acdd&scene=27#wechat_redirect)

在2011年毕业后，怀揣着对大脑领域探索的执着追求，Josh Siegle和Jakob Voigts两名大学生各自投资了6万美元创立了Open Ephys开源硬件公司，他们不断通过自己的创意和诸多知名企业达成合作，并成立生物传感开源社区，并在今天推出了一款开源设备用于研究存储大脑信号。截 止2014年他们成功生产了超过100款的主板，在动物大脑潜入电子芯片将这些动物的想法意识翻译出来，并能够将这些大脑信号保存下来。

这些主板能够实现将大脑信号进行放大、过滤、多路复用（multiplex）并最终形成数字化，而这四个步骤往往需要专业的集成电路（ICs）进行处理，售价往往相当的昂贵，而Open Ephys今天推出的这款开源设备在同样能够处理这四个步骤的情况下将成本降到最低，并有望将这些主板整合嵌入到移动设备上。
