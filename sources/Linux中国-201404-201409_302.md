# 如何成为坐拥百万的Web开发者？

我想出了一个成为坐拥百万的web开发人员的策略。剧透警告–你不必为此而成为一个Web开发者并以此为生。

这篇文章似乎在吹一个巨大的牛,但那不是我的本意 – 它是在考虑一个乍看起来像是可笑的白日梦的解决方案。（编辑添加）它也并不是该考虑的建议 – 只是我思考过程的文档记录以及我自己要去实现的东西。

## 为什么？

首先，为什么（要拥有这么多钱）？

资金，预算以及每天都盯着钱看是很无聊的，那么带着足够的奉献精神（不怕无聊）来记录我的金钱到达这样高的一个总额，如果没有一个推动力量是不可能做到的。你的理由可能是环游世界，逃离你当前的工作，还清你父母的抵押贷款，买一个阿斯顿马丁DB9或其他的什么东西。

我的理由很简单：我想在未来的某天开一家餐馆。

![](../Images/7b60f833269e9b298e77405fb79e8a41.png)

Photo by Aleksandr Slyadnev

我妈妈是一个了不起的厨师，她经常谈论着一件事情 — 她认为她现在年纪太大了不能再做厨师了（我并不这样认为），而我继承了美食家的基因，要努力去实现她的梦想。

我的百万资金能帮助我开始这件事情；餐饮业竞争惨烈，如果加入很可能迟早以失败告终。我能达成我的梦想的唯一出路在于，如果我可以通过其他方式获取我的生活费用。

值得注意的是，这不是快速致富，而是（非常）缓慢的致富。但事有先后：

## 确立一个目标

我30岁了，可能还有好几年的时间写代码，但是我没有魔法水晶球，我不知道在以后的20或30年会有什么样的机会出现。然而，我的目标是以我的名字拥有超过1,000,000英镑的存款，那样我就可以开始的餐饮生意了。没有一个目标，我将永远无法知道我能否成功，也不会知道如何才能做到。

那么，既然目标已经设置了，计划是什么？

## 存钱

![](../Images/0765c09f60533f2db826cbf6f359e226.png)

Photo by Tristan Martin  
为了将来，我可以存钱。为了达到我的目标，我每个月需要存多少钱：

```
1,000,000 / (20\*12) = ￡4166.67
```

在接下来的20年里，我可以在每个月往我的盒里存4,166.67英镑。这笔生意看起来不错，但并没有实际那么好。因为做到这样也许并不是那么容易，对吧？

大多数的人可能一个月都存不了4千美金，但是他们可能存400英镑一个月 — 或者是一个接近的数目如果他们愿意的话。对于一个WEB设计者或者开发者来说，那只是1-2天的花销。

```
( 400 \* 12 ) \* 20 = ￡96000
```

那么，在以后得20年里我可以很舒服地存差不多100 000英镑，而那差不多已经是目标的10%。为了能更接近目标一些，我又有了其他几个想法。

## 抑制我的恶习

![](../Images/4eaa92cb584e8a876dbed839beac2143.png)  
Photo by Alex Garcia

我常常喜欢在早上喝一杯咖啡，晚上喝点（甚至几杯）酒。

在上班的路上喝杯咖啡是很不错的–但不是必须的。大多数的工作场合会免费提供咖啡，在我早上离开家之前总会喝上一杯。无论如何，我完全可以少喝带咖啡因的东西。

如果我早上喝的咖啡花费大概2.5英镑，在酒吧里喝的2两杯酒花费10-15英镑，我可以节省几英镑到十或二十英镑一天。通过削减几个琐碎的花费，我们以保守的节省10英镑来算：

```
( (10 \* 7) \* 52 ) \* 20 = ￡72800
```

还不错。几个小的牺牲，在未来的二十年我可以节省额外的73k英镑。如果我吸烟我能节省的是它的两倍–尽管为了我的健康，很幸运我不吸烟。

## 投资

只是把钱藏在床垫下，钱是不会少的（但也不会变多）。正如?Pete Matthew在Meaningful Money Podcast中说的：  
“现金不是一种投资。”

我可以把168000英镑存到银行（节省10英镑每天，400英镑一个月持续超过20年）–这看起来还不错，但不管如何离我的100万英镑还差的太远。伴随着一点明智的投资，事情会变的有趣起来。

如果我一天拿10英镑存到有6%收益的基金里–这没什么特别但是这个收益率还不错–事情开始有起色，而这得益于混合收益的力量。

每年挣取的利润都会添加到原来存的基金上。这会使得原来的基金数变大然后下一年再赚取利润，再添加回原来的基金，这样每一年基金都会以指数增长。

## 混合收益的例子

这有一个混合收益的公式：

![](../Images/caae79b32ed8fc453b4097c71ba88103.png)

Source:http://www.moneychimp.com/

```
// Y = years, P = principal investment, r = rate, c = contribution Y = 20P = 0 // start with nothingr = 0.06 // 6% returnc = ( 10 \* 7 ) \* 52 = 3640 // annual contribution Balance = (0 \* (1 + 0.06)^20) + (3640 \* ( ((1 + 0.06)^21 - (1 + 0.06)) / 0.06))Balance after 20 years = 141,933.53
```

我可以增加我的潜在储蓄（通过减少不必要的花销），通过投资将资金从72,800英镑增加到142,000英镑–差不多两倍，不错！

作为一个Web设计者或开发者，能赚到上面的全国平均水平的薪资或者一个好的日常收益率，你可以节省的更多。让我们来看看节省400英镑每个月的时候混合收益的数目。

我是用这个方便的工具compound interest calculator from Moneychimp来计算以节省时间：

```
c = ( 400 \* 12 ) = 4800 a year savedbalance after 20 years = ￡187,165.09
```

如果你能存1000英镑每个月，在每年只有6%的收益的情况下，你可以在20年后拥有470k英镑。很有趣，不是吗？拥有470k“冰冷”的现金你会做什么呢？

## 从政府那领的钱

你可以投资你的劳动成果，但是从在政府工作的善良人员那里领取的金钱怎么处理？听起来不错？继续读下去……

如果你投资了养老金，政府会以减免税的方式给你一些钱。简单的说，如果你在养老基金里投了80英镑，政府会免费给你20英镑而使得资金变成100英镑。如果你是一个最基本的纳税人的话。但是如果你付了更多的税的话，按照按下面这个图（来自Money Saving Expert）你会获得更多的税收减免。

![](../Images/bc64f57ee89224ea3c26aed7bcaba166.png)  
退休金是一个巨大的课题–在这方面我一点都不专业。简单点来说就是–如果政府免费给你钱的话，收下它。

## 杠杆作用

如果投资明智，资金会越来越周转的开，但是利润率在当前还是相当低的，这会使得金钱的增长会变得很慢。杠杆作用–通过贷款–另一方面，会让事情变得令人兴奋。比如抵押贷款来买房，会让你的钱变的更有含金量。

![](../Images/74a4da3904f71dc8e3ad765d0f128de7.png)

Photo by tubb  
一个典型的贷款价值(LTV)投资产权比率是75%–那么，你需要有25%的存款然后用贷款（抵押）来获取剩余的75%。对于100,000英镑的房产，你需要25000英镑作为定金。

那么对于100k英镑的储蓄，你可以买四套房产，对于每一套房产你需要有25k的定金。随着时间的流逝，这些房产会升值，从某点上来说，每一套房产的价值会升到125k英镑 — 这只需要几年的时候，因为房产的价格每10年翻一番（甚至有时会升3或4倍）。不相信我？看一下优秀的房地产播客的最近的一段视频吧：Does property really double every ten years?  
如果每套房产升值25000英镑，那就意味着整个投资涨了100k英镑。这样的话初始投资回报率为100%（随着时间流逝）。这听起来要比每年6%的收益率要好，不是吗？当然还有抵押贷款要支付，但是这期间会有租户来付租金–按每个月来算，租金支付会超过抵押贷款。实际上，大多数的房产投资者在投资房产后的只是从租金上的回报（ROI）大概为10%–对资本增值来说那只是一个奖金而已！

## 自动化

攒钱是很困难的。实际上，在月底来计算我的资金金额的时候，资金收支基本为0的情况多的让我数不过来。如果什么也没剩下，那就什么也存不下，是吗？  
不是的。

拯救的唯一出路在于首先要投资你自己–然后把剩下的花在必须要花的地方，娱乐以及有意义的东西上。从我的经验看来，使之成为现实的唯一途径是自动化的过程–你没看到钱就不会错过钱。

这里有4步来实现雷打不动的自动化的投资你自己的过程：  
1.创建一个在线储蓄账户–你甚至不需要离开自己的办公桌就能办到；  
2.在你的发薪日往你当前的账户里存入一定量的钱（比如400英镑）以建立良好的存钱习惯；  
3.重新安排你所有的日常开销（租金，电话费，宽度，软件杂志订阅等）并把节省出的钱在同一天存入你当前的账户；  
4.只花费当月剩下的钱（哪怕没有剩下）。

当你积累了一个合理的数目的时候，你可以开始投资养老金或者购买像投资基金这样的项目–再次强调，我并不是一个专家所以我肯定会去寻求一个称职的财务顾问的意见。

## 我的策略

我已经列出了一些省钱的方法，通过明智的投资你可以做到。我也列出了我20年攒1000000英镑的目标，但是没有一个策略，何以称为一个目标？

值得注意的是,你不必是一个web开发人员或者设计师或者是银行家，医生或者律师；所有的需要的只是对你来说能起到作用的一点纪律性和一个体系。

我的策略要比只是一天存十几英镑或者一个月存几百英镑更积极主动一些：

我现在每个月存我净收入的50%。

我现在每个月拿3000英镑来做储蓄和投资。这让我在未来一年能投资36000英镑–这样我在投资有6%的收益的理财20年后将会增长到超过一百四十万。

但是实际上，我不知道我能不能保持那样的存款水平来存20年，因此我对我的策略变得反而担心。

我打算在接下来的10年每一年都去投资房地产。我的数据是基于1 – 2床位的公寓，伦敦外面一排连接着的房子–那里的房子价格相对便宜，租金收益率更高。10年以后，光是一年租金的收益就足以让我去买一套房产而不用靠存我自己挣的钱。不相信？看下下面的表格：

10年以后，10套房产的租金收益至少是25k英镑每年，这总是能超过（至少）一套房产一年的保证金。这个简单的计划没有把利率上升计算进来，但是也没有考虑到租金增加或任何资本增值。

如果这个计划有效果，10年的时间我的净资产就能达到1百万，剩下的10年我可以让它变得更多。

还记得房产价格（趋向于）平均每10年会翻一番吗？那也就意味着20年后，我的账户大概会有2百万英镑。此时，我可能会去度假并找一两天时间来冷静一下。
