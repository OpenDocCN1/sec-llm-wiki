# Linux Mint 17 Qiana正式发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200309040&idx=3&sn=4b118c43c47149d12f93c1fad514eebd&chksm=28ec42761f9bcb6007aeab9fad0e45395969183840d64f8fb296d00d69831ebe7f1d94fdc9eb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200309040&idx=3&sn=4b118c43c47149d12f93c1fad514eebd&chksm=28ec42761f9bcb6007aeab9fad0e45395969183840d64f8fb296d00d69831ebe7f1d94fdc9eb&scene=27#wechat_redirect)

Linux Mint是一个基于Ubuntu开发的作系统，Linux Mint团队创始于2006年，其目标是为家庭用户和企业客户提供免费、高效、易用、高雅的桌面操作系统，是Distrowatch排行榜上目前第一名的Linux发行版。

昨日，Linux Mint团队正式宣布新一代操作系统Linux Mint 17 “Qiana” Cinnamon发布，新系统同样基于Ubuntu 14.04编译，为桌面用户带来不少功能新特性，生命周期最长持续至2019年。

Linux Mint 17 Qiana更新如下：

— 软件更新管理器

— 驱动管理器

— 全新登陆界面

— 语言设置

— 更多的软件源

— 欢迎屏幕

— Cinnamon 2.2

— 系统改进

— 提升网络

— 修复Skype问题

— 为VLC开源播放器加入DVD播放功能

— 支持HiDPI高分显示屏

— 支持EFI启动模式

— 解决与某些英伟达GeForce GPU显卡挂起问题

— 支持从非PAE指令集CPU启动和运行

— 其他修复问题
