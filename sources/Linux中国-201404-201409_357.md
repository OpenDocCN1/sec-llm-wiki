# OpenSSL官网更新:锤子科技/华为/诺基亚位列三大“白金赞助商”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200307040&idx=1&sn=4e0334bc76b01b14d8f516289e5a3ff4&chksm=28ec4a261f9bc330d4521b0c3720481622fa5cd08c66e58e4871750142fdf41814ac8ec80bbf&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200307040&idx=1&sn=4e0334bc76b01b14d8f516289e5a3ff4&chksm=28ec4a261f9bc330d4521b0c3720481622fa5cd08c66e58e4871750142fdf41814ac8ec80bbf&scene=27#wechat_redirect)

在5月20日召开的《锤子手机发布会》上，老罗宣布将会把100万元门票收入捐赠给OPENSSL，以便激起其它吝啬的巨头们的“羞愧感”。而现在，我们发现OpenSSL已经对其官网上的“赞助商”页面进行了更新，锤子科技(Smartisan)与华为(HuaWei)、诺基亚均上榜，成为了它的“白金赞助商”(Platinum Sponsors)。

![](../Images/e5f9725684b8f542d2d74657fdc7fb7d.png "20140530 OPENSSL - Platinum Sponsors.png")

当然，除了上述三家“白金赞助商”，GlobalSign和Qualys Continuous Security两家公司也为之提供了“重点扶持”(Major Support)。

此外，Open Gear为其提供了“非常重要的支持”(Very significant support)；而PSW Group、Milton Security Group、以及Acano三家则为之提供了“重要支持”(Significant support)。
