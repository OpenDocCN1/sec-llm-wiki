# Red Hat CTO：开源软件所带来的5个商业优势

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200288008&idx=3&sn=323aa01bb75b002e6eb520c05bb71754&chksm=28ec1c4e1f9b955823e9212aca3d9efb8acad10e06da6c37c2699ab89366881ad3aca744519e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200288008&idx=3&sn=323aa01bb75b002e6eb520c05bb71754&chksm=28ec1c4e1f9b955823e9212aca3d9efb8acad10e06da6c37c2699ab89366881ad3aca744519e&scene=27#wechat_redirect)

开源软件不仅仅只是供你使用的软件，同时也是一种理解。如果企业CTO、CIO能够真的理解开源所带来的商业优势，那么开源的发展不会如此的缓慢。开源给你的带来的优势包括：开放的客户关系、获得创新技术、安全性等等。

一篇将开源贴上“奇妙但很可怕”标签的博客说：“目前有太多的CIO对于自己的组织使用了多少开源软件这一具体情况并不是很清楚。”一项对820名CIO进行的调查显示：62%的回复者认为他们所购买的商业软件中有一半会在接下来的5年内走向开源。如果你是一位打算投靠开源的CIO，那就继续往下读吧。

Brian Stevens 是 Red Hat 公司的CTO，Red Hat应该算得上是这个世界上开源解决方案的领头羊，而且也是第一家拥有亿万资产的开源软件公司。Red Hat 通过社区提供动力的方法为客户提供可靠高性能的云、虚拟化技术、存储技术、Linux® 和中间件技术。

正如 CIO Insight 说的那样：”一旦和高质量、高性能建立关系，开源的流行度就会像 CIO 和其它技术领导们所意识到的那样：开源能带来无限的创新和协作优势！“那么下面就来讲讲，CIO有哪些方式可以利用开源来提升开放、协作和创新呢？

### **1\. 开放的客户关系**

Red Hat CTO Brian Stevens说，企业买主想要的不止是软件，他们想要的是和供应商之间建立更完整的关系。正如Brian Stevens 那样：时常寻找一种创新方式来增加和上层客户之间那种微妙、坚固的关系，以至于成为客户生活中的一部分。花很多时间和精力让你的客户理解你的理念和挑战，这样有助于帮助你的客户更容易接受你。

![](../Images/06eda0ee9be9a772efb6e916c2652be4.png)

### **2\. 分享你的创新**

如果你向别人提供基于开源许可证的 App 或者软件的话，最好是把代码也给出去。因为它使用的是开源许可证，这就说明这个创意是属于全世界的。Stevens 说：我们认为不仅仅只有在 Red Hat 工作的6500个工作人员在使用这个代码，而是购买我们软件的所有客户在使用这个代码。要想构建一个能为客户带来高水平、灵活工作效率的操作平台的唯一办法就是——开源，这也是唯一能够让”创新“发芽生长的地方了。

![](../Images/489a343f52d5025022e046544af28eed.png)

### **3\. 安全第一**

之前就已经有研究表明开源软件的每千行代码里的缺陷实际上要比专有软件里的代码少得多，而且随着时间的推移，这两者间的优劣将还会处于模糊不清的状态。 Red Hat 认为只有合作才能增加安全基数。

虽然现在很多人试图彻底的看穿目前的数字经济，但是Stevens 指出这样一个事实：在这个形势下根本没有什么隐晦的东西，因为客户不会只依赖于一个供应商来建立安全代码。“我们认为Red Hat 是世界上最安全的平台之一，这也就是为什么它能够运行像Facebook、Twitter 和 Google这样的公司。”

![](../Images/8a29739bdd25cbfd88c85465eab4456d.png)

### **4\. 企业间强强联手**

Stevens 说，OpenStack 现在既兴奋但又觉得很无聊，在去年一年里，OpenStack 被大多数企业认定为建立一个大规模可伸缩的私人或公共云的最好解决方案。也正是企业这样的行为给OpenStack 做了广告。“一时间OpenStack 成为人们茶余饭后的谈资，他们在想，如何才能通过OpenStack 获得一个云部署呢？”随着谈资不断增加，这也有助于刺激 Red Hat ，并最终将 Red Hat 带入新的市场。可是面对供应商、云架构、经营规模等问题时，最后还是要回到开源问题上的。

![](../Images/b0b352fa14f802f530ee6931f807bc53.png)

### **5\. 改进数据和分析能力**

第一个数据路径应该有能力衡量、确保用户数据的安全性，这就是红帽收购 Gluster 之后是如何进入软件定义存储的。“随着数据更新速度快，之前遗留下来的硬件技术不能在降低成本的同时完成衡量和储存的任务。我们需要一个大规模的基于软件的规模和体系结构来完成更多的存储和访问工作。这基本上就构成了Red hat 存储的基础。”Stevens说。

一旦数据能够正常存储，第二部分工作就是数据分析。除了构建一个分析仓库之外，你可以在正确的存储层运行主要分析应用程序，为客户改善数据和分析功能。

![](../Images/db2ea85fcbaa70d79b054fe4ab136ea1.png)

开源的效果是相当明显的，这也就为开源技术提供了一个巨大的机会和需求，因为掌握开源技术就能让事情变得简单许多。新客户现在所面临的挑战是如何让他们公司内部真正掌握这些技能，当然，不仅仅是掌握技术技能，还要理解开源模型和它的意思。

> "You don't build an open source business; open source is not your business value but the path. You need to understand what problem you are solving for customers, and by and large the problem will determine that you use an open source platform to achieve it."  
> 你可以不建立一个开源业务，因为开源不是你的商业价值，但开源是一种路径。你需要了解为客户解决什么样的问题。总的来说，最终你会使用开源平台来处理这个问题。——Brian Stevens
