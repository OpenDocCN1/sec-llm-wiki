# CSDN CODE悬赏频道上线 架起开源项目需求与开发的桥梁

CSDN CODE今天正式推出“悬赏”频道(http://code.csdn.net/rewards)，这是CODE为开源社区提供的一套任务平台，通过需求发布和承接任务的形式来架起需求方与开发者间的桥梁。

5月21日消息 CSDN CODE今天正式推出“悬赏”频道( http://code.csdn.net/rewards)，这是CODE为开源社区提供的一套任务平台，通过需求发布和承接任务的形式来架起需求方与开发者间的桥梁。

![](../Images/c023076ea5b5c504cbf0f2cebe41c055.png)

图：悬赏频道首页截图

在CSDN CODE悬赏平台，悬赏的任务可以是跟开源相关的项目、征文、设计、比赛等内容。需求方可以自主发布自己的悬赏需求，而有相同需求的人可以用“加分”的方式来提高“赏金”，以鼓励更多的人参与完成任务。承接悬赏任务的人在任务完成后将会收到相应奖励。奖励数目由需求创建者和所有加分者自由决定。

![](../Images/bc495b8be662f1868d532ba5136e9c0e.png)

一直以来，开源项目的需求提出与开发都基本处于一种“自由+自发”的状态：开源开发者根据自己的市场调研结果或是从自身需求、兴趣出发来决定做什么项目，有需要的用户自行去寻找满足自己需求的开源项目来使用。对于那些开源项目的二次开发需求，用户则要么是通过联系开源项目作者来协商解决，要么寻找其他的外包途径。在这一过程中，无论是需求的提出，还是项目的后续开发，更多的都是单方面的行为，缺乏有效的沟通和市场验证。此外，在缺少足够需求信息和市场激励的情况下，开源项目要延续下去更多的是靠的开发者自身的兴趣和社区规范维持。

CSDN CODE悬赏平台的诞生有效调和了这一现状。通过类似“众筹+众包”的形式，一方面，由用户自发创建的需求反映了市场的实际需要，加分者越多的项目说明需求越旺盛，保证了项目的开发是有实际使用价值的。另一方面，不指定固定接包方的自由承接形式让需求方有了更多选择，不同接包方采取的不同策略、不同开发形式，可满足用户的多种需要。开发结束后，由需求方根据自身需要来评价和奖励接包方的成果，让每个有价值的方案都可以得到恰当的回报，开源开发者也能从中受益。

CSDN CODE平台一直致力于为国内开源事业提供一些有效的帮助。从开源项目托管，到开源资讯报道，再到现在的悬赏平台。我们在不断与国内开源社区、开源开发者和爱好者的接触当中，了解到他们的切实需求，从这些需求出发，结合我们自身优势，打造了这些产品。针对开源项目的悬赏平台是一种新的尝试，我们希望通过这样一种形式，让开源开发者和普通用户都能从中受益，让开源项目本身更贴近市场需求，也让普通用户更多的了解开源项目和开源社区。

CSDN CODE悬赏平台上的积分奖励未来将可以兑换实物产品、各种付费资源甚至现金等。这对开源开发者来说，无疑是一个极大的利好消息。

伴随本次悬赏平台上线，已经有多个悬赏任务发布，包括 腾讯开源项目征文大赛， CSDN-MoPaaS 开源应用开发大赛， BLUG T恤设计，基于 Blender的开源漫画策划等，感兴趣的读者可以登录CODE平台参与。
