# 橙色箱子中的云平台：Canonical发布Ubuntu Orange Box

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200259333&idx=5&sn=1f3c03561f56058120e98a26e0b77a3d&chksm=28f38c431f840555e327a139616300d2a8ebb7ac4b566fbae4a48715659ea4d89b00466b7729&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200259333&idx=5&sn=1f3c03561f56058120e98a26e0b77a3d&chksm=28f38c431f840555e327a139616300d2a8ebb7ac4b566fbae4a48715659ea4d89b00466b7729&scene=27#wechat_redirect)

在亚特兰大召开的OpenStack峰会上，Ubuntu Linux母公司Canonical创始人Mark Shuttleworth宣布了许多新鲜有趣的事物，包括全新的Ubuntu OpenStack云、以及Juju DevOps倡议。而下面要介绍的，就是其中最吸引人眼球的cloud-in-a-box硬件产品——Ubuntu Orange Box(橙箱)。

Ubuntu称，Orange Box是一个完整的移动集群，人们可以借助它来实现简单和低风险的OpenStack云基础设备部署，以便于测试或进行概念验证。

每个“橙箱”均包含了10个节点，每节点包含4核心、16GB内存、以及大容量的SSD存储。该产品预装了Ubuntu 14.04 LTS、MAAS、以及Juju。
