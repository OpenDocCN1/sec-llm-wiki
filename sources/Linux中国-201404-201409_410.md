# 甲骨文诉Android侵权对软件行业无利

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200246262&idx=2&sn=7d78f844487f67ceb8929c7ca8305eac&chksm=28f3b8b01f8431a6334f318f3abe3a8f7d18889a9c29f5806cef9aba7211bd4374fe2a138317&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200246262&idx=2&sn=7d78f844487f67ceb8929c7ca8305eac&chksm=28f3b8b01f8431a6334f318f3abe3a8f7d18889a9c29f5806cef9aba7211bd4374fe2a138317&scene=27#wechat_redirect)

据国外媒体报道，提供云技术相关服务为主的初创企业MuleSoft的创始人罗斯-梅森（Ross Mason）日前表示，甲骨文公司起诉谷歌公司Android系统侵犯其知识产权的官司对于全球软件行业来说是有百害而无一利。

此前，甲骨文公司指控谷歌公司的Android系统侵犯了该公司所拥有的应用程序编程接口（APIs）知识产权。应用程序编程接口是一种应用广泛的计算机语言，其能够使得计算机内部各不相同的程序实现彼此互相顺畅的交流。

梅森在接受Business Inside记者采访时表示，如果不同企业之间被鼓励使用彼此的应用程序编程接口进行通信交流，那么这些企业的服务水平将得到很大程度的提高。梅森所创立的MuleSoft公司目前市值8亿美元，其主营业务为提供应用程序编程接口服务，以允许基于云端的应用程序能够彼此通信交流。梅森向记者说到：“甲骨文公司同Android系统之间的纠纷对于应用程序编程接口本身来说没有任何积极的意义，另一方面我们还认为其对相关企业来说也将产生负面效应，受到上述官司的影响，客户同企业所提供的云服务之间的交流几乎将被冻结。”

当地时间5月9日，美国当地一家上诉法院将判决结果送交甲骨文公司，法院支持了甲骨文公司的诉讼主张。在此前较低级法院的判决中，法官认为Android系统并未侵犯甲骨文公司有关应用程序编程接口的知识产权。在诉状中甲骨文公司指控谷歌公司复制了Java程序中的应用程序编程接口，并将其使用在Android系统中，Java应用程序编程接口为甲骨文公司所有。

尽管此前有法庭陪审团支持甲骨文公司的诉讼主张，但法官判决甲骨文公司不能因此向谷歌公司主张任何索赔。根据路透社此前的报道称，当地时间5月9日上诉法院宣布撤销上述判决结果并将该案发回较低一级法院重审，上诉法院在判决结果中要求原法院重新裁定谷歌公司使用Java应用程序编程接口是否合乎公平的原则。

甲骨文公司的代理律师在接受Business Inside记者采访时表示，上述巡回法院的判决结果不会伤害甚至不会丝毫改变当下软件行业的格局和形势，原因在于许多程序编程接口规模过小且十分简单以至于其无法享受到知识产权法律法规的保护。另一方面，谷歌公司表示上诉法院的判决对于计算机及软件行业的发展将造成伤害。谷歌公司的观点受到了多数科技行业同仁的支持。

目前尚不清楚谷歌公司是否会向甲骨文公司支付赔偿金，而有分析人士谷歌很有可能向上诉法院重申该案，未来其也不排除将该案诉至美国高等法院的可能性。
