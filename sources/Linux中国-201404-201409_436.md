# 微软发布IE漏洞修复补丁 “出昏招”顺带拯救Windows XP

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200218960&idx=2&sn=a270e100c8fd7333b987259815733669&chksm=28f322161f84ab009b8edf8ce00c579cc4718bcc1f2a140ee833c40e1c97ccd8f5fb421db24a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200218960&idx=2&sn=a270e100c8fd7333b987259815733669&chksm=28f322161f84ab009b8edf8ce00c579cc4718bcc1f2a140ee833c40e1c97ccd8f5fb421db24a&scene=27#wechat_redirect)

早前，微软为自家流行的Web浏览器上，发现了一个影响相当深远的漏洞(IE6到IE11无一幸免)，并且可能导致攻击者攻破内存并执行任意代码。不巧的是，该公司刚在4月8号终止了对Windows XP的支持，但鉴于全世界仍有1/4的机器在运行该系统，微软仍然迅速采取了行动，并且为之发布了补丁。

但是，此举却被认为是微软的一记“昏招”。因为为了鼓励用户们向最新的平台迁移，该公司已经付出了多年的努力。

当然，如果微软“违背了诺言”，并且继续给XP来那么两个安全更新，用户的升级动机就会更加渺茫了。因为这是一个可怕而又危险的先例。

《福布斯》撰稿人Gordon Kelly在近期的文章中写道：微软刚刚才警告了所有Windows XP的用户，但是转眼又加了一句“别担心，我们在唬人”。

尽管微软将来的政策，现在还有待观察。但毫无疑问的是，它当前正在向人们传递着混杂的信息。
