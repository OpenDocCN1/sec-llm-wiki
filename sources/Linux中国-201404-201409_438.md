# Andrew Wulf：编程是条不归路

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200218960&idx=4&sn=a98ec6ffb6db422d88abb70c33ed5a1c&chksm=28f322161f84ab0096d78f21c923c7e8f7b271e465bba262e10a5d073df090a6224f1f6ac5ff&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200218960&idx=4&sn=a98ec6ffb6db422d88abb70c33ed5a1c&chksm=28f322161f84ab0096d78f21c923c7e8f7b271e465bba262e10a5d073df090a6224f1f6ac5ff&scene=27#wechat_redirect)

你热爱编程吗？如果你没有创立公司就别妄想成为CEO —— 但是成为CEO后，则很可能意味着不再写代码。

对于大多数技术职位而言，只要坚持写代码，你总会得到有限的提升。通常情况下，你需要一步一步地从初级程序员到高级程序员，再到首席程序员或软件工程师。可能你有机会继续升职为架构师，但是很多架构师都不再继续写代码。

如果你决定转到管理职位，情况则大不相同，升职的空间变得大了许多。我们公司的母公司的前任CEO在25年前开始踏上编程之路，后来成功地转到管理职位，此后15年，他一路升职，最终成为一家市值40亿美元的公司的CEO。10年以后，他有房有车，成功地退休了，过着无忧无虑的生活。与此同时，在我身边有很多差不多同他一起踏上编程之路的人，现在仍然只是高级软件工程师。

这公平吗？我无法回答。如果你热爱编程，有一份还不错的薪水并且你很享受你的工作，那么你还需要经常被提拔吗？并不是每个人都想要或能够创建一家公司（我在职场生涯的早期创建过两家）。有时，这一切让人感觉很不公平，因为不管你有多么强的编程能力，你的薪水甚至永远比不上一个普通的CEO。你甚至没有机会决定工作的内容和方式，直到有新的工作机会出现。或者你可以妥协，放弃编程，成为一个管理者。

我的前任经理在他5年前创办这家移动公司之前，已经做了15年的程序员。在公司创建并取得成功以后，他总是时不时地在其他人很忙碌的时候，修复一些bug或者对代码做一些轻微的修改，但是他不再以程序员的身份自居。最终，他得到了更好的职业机会，成为另一个洲的一家知名公司的等同于副总裁的职位，责任更重，但职场前景和薪水也更好了。我们部门将改编为市场部门，所以移动公司的技术内涵已经消失了。所有剩下的人都将会得到相同类型的工作和一份相近的薪水。这便是职场的野兽本性。

我想，作为一个程序员，如果足够幸运，可以在创业公司赚到一笔大钱。但实际上这样的机会少之又少。上世纪90年代中期，我曾成功与一家刚上市的公司签订了合约。我的邻居曾经在很多初创企业工作过，在他加入之前它们无一例外都处于失败的边缘，最终他收获了1200万美元。此后，他一直在一些小公司做程序员，因为他仍然热爱编程，并且对薪水没有要求了。大多数情况下，作为一个程序员，你仅仅拿着固定的薪水，可能还不多。在Google或其他大公司的程序员的收入，一般要比其他的普通程序员高，但是跟CEO或其他管理层相比，还是不值一提。

在我的第一家创业公司中，我作为一名首席程序员，同时还要同媒介、投资人打交道，应付招聘、福利和市场等等工作。这些过度消耗了我的精力。在第二家创业公司时，我更多地投入到编程中，而对其他事务的处理相对较少。我发誓我还想再像这样干一次！

我姐姐一开始在她公司里是一名程序员，但是六个月以后，她被调到了管理部门，现在她已经长期担任了高级副总裁。再一次印证，放弃编程，职场空间会更广阔。

如果你像我一样地热爱编程，你会发现你未来的职场升职空间很小。或许这很愚蠢，但是你可以在你喜欢的职业和薪水更高的职业之间选择一项。对于某些人来说，自己创办公司是更好的选择。而对于其他人来说，换一条职场路线，放弃编程是一个更好的选择。对于我来说，我热爱编程，但也不得不面对现实。

我曾经在夏威夷（一家咨询公司）工作过。周围的同事告诉我他们知道他们的薪水相对美国本土要低一些，但是他们认为在夏威夷工作本身就是一种福利！

不管你做什么，你必须要在自己热爱的和赚钱过日子之间找到平衡点，这并不容易。
