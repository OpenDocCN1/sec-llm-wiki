# Ubuntu for Android 将不再开发

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200186563&idx=3&sn=f06a44959cd6cdbd78b4dbc931c409cc&chksm=28f2a1851f8528930198ba4655155408cf447fc9868b01b57df344324ae7b12db2da7a46d982&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200186563&idx=3&sn=f06a44959cd6cdbd78b4dbc931c409cc&chksm=28f2a1851f8528930198ba4655155408cf447fc9868b01b57df344324ae7b12db2da7a46d982&scene=27#wechat_redirect)

Ubuntu for Android是一个让用户在安卓手机上完整体验Ubuntu系统桌面环境的项目，包括办公软件、上网冲浪、电子邮件、多媒体等等，但是几年来进展不大，Canonical已经决定砍掉它了。事实上，Canonical对这个项目根本就缺乏重视，几乎从未公布过什么具体信息，最早说的2012年底发布也是一拖再拖，还没有任何解释。事实上，即便你对该项目感兴趣也没有Beta测试供你体验，只能自己想办法，非常之复杂。

目前，Canoncial尚未官方宣布该项目的命运，不过Launchpad上的帖子已经明确表示“Ubuntu for Android将不再开发”，Canonical的前端开发工程师Anthony Dillon也确认了这一消息，界面设计师Matthew Paul Thomas则指出官网上的相关资料早就不更新了。

至于为何放弃，谁也不知道究竟为什么，但也不难猜测。拿手机运行完整桌面系统实在勉为其难，高配机型也无法流畅，而且手机那么小的屏幕实在不适合这么做。

需要注意的是，这个项目和魅族等正在做的手机版Ubuntu系统并无直接关系，后者是针对手机重新开发的移动系统，还是颇为值得期待的。
