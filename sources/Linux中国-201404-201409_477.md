# 无拘无束享受输入，搜狗输入法for Linux上线

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200160261&idx=1&sn=e1da5d3802e58281bdc72ad7985ddad5&chksm=28f20f431f8586558a2d7f04d90e60d1e85ae8fd169222f6c55013154b7cc44794d2ab2bd497&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200160261&idx=1&sn=e1da5d3802e58281bdc72ad7985ddad5&chksm=28f20f431f8586558a2d7f04d90e60d1e85ae8fd169222f6c55013154b7cc44794d2ab2bd497&scene=27#wechat_redirect)

Linux一直被IT技术大神当做工作必备系统，它自由、开放、有趣，且拥有着Windows系统无与伦比的稳定性和超强的系统核心。然而，当大家选择Linux系统汉化版时，经常因为其不佳的汉语输入体验，影响工作效率。近日，为了弥补这一缺憾，搜狗推出了搜狗输入法for Linux 1.0版，将其优势功能接入Linux系统，让有中文输入的地方就有搜狗输入法。 

### 智能云输入 让输入更准确

作为用户最多的智能拼音输入法，搜狗输入法的云输入功能通过搜狗强大的云计算能力，突破本地

限制，大幅提高输入准确率。据相关数据显示，云输入使得搜狗输入法长句输入准确率从61%提高到了84%，短句输入准确率从91%提高到了94%。此外，该版本的搜狗输入法沿袭了Windows版中“模糊音”与“拼音 纠错”功能，让用户输入的准确率进一步提升。  
![](../Images/260ad454a2072c92717907a31d6ff49e.png)

### 最全词库 让输入更简单

曾经在Windows系统使用过搜狗输入法的用户想必对其词库功能印象深刻，在搜狗输入法for Linux 1.0版中，同样加入了这一人气功能。同时，输入法会记录用户输出词，候选词条次序会根据使用情况进行变动，经常输入的字、词会靠前。新词、热词、生僻词高度覆盖，精准智能组词算法让用户畅想输入体验。  
![](../Images/c522129b19f53ce6cd34059d6e469d5c.png)

### 海量皮肤 让输入更乐趣 

搜狗输入法是所有输入法中，最早加入换肤元素的，是输入法换肤的“鼻祖”。在搜狗输入法的皮肤网站中，汇集了愈百万套或来自皮肤设计师、或来自网友的精美皮肤。如今，搜狗将换肤元素带到Linux系统，搜狗输入法for Linux 1.0支持大部分搜狗输入法windows版本的静态皮肤。此外，用户还可以根据自己喜好进行字体、拼音串颜色设置，在打字的同时享受输入的无限乐趣。  
![](../Images/de31c0ff85dc0483c652dd3c23891193.png)

据了解，本版本输入法是搜狗公司与Ubuntu Kylin团队基于小企鹅输入法框架、Qimpanel面板以及搜狗输入法引擎共同开发。搜狗相关负责人介绍，“搜狗公司与Ubuntu Kylin团队自2013年12月便启动合作开发‘搜狗输入法Linux版’，经过十余位资深工程师、产品经理、高级测试人员历时五个月的联合攻关，终于按时正式发布1.0版本。搜狗也希望通过本次合作，能够为广大Linux用户带来更加优异的输入体验。”
