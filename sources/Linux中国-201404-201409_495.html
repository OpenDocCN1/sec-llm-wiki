Ubuntu版本更新一路走来：朕就是这样的汉子

Ubuntu刚刚发布了最新的14.04版本，围绕这一版本的讨论早就不绝于耳，网友们对新版Ubuntu褒贬不一，喜欢的网友表示惊艳，不喜欢的网友说“Ubuntu的界面走上歪路，而且越走越远了”……

14.04版本变化真的那么大吗？Ubuntu是在越变越好还是真的“走上了歪路”？让我们来看一下14.04都有哪些新特性，并回顾一下Ubuntu版本更新历史上几个比较有代表性的版本，看看这个Linux家族的“明星”之一，是个怎样的“汉子”。

Ubuntu 14.04 LTS，开发代号 "Trusty Tahr"

发布时间：2014-4-17

版本介绍：作为一个长期支持版本，Ubuntu 14.04操作系统新增了大量新功能，UI界面方面改变也非常多。Ubuntu 14.04操作系统中加入了本地综合菜单功能，菜单不再以横条的形式在屏幕顶部显示。系统还采用了全新的锁屏界面，其风格类似于系统登录界面。

接下来我们再来回顾一下几个比较有代表性的Ubuntu版本。

Ubuntu 4.10，开发代号 "Warty Warthog"

发布时间：2004-10-20

版本介绍：Ubuntu 4.10 是Canonical基金的第一个Ubuntu版本。作为Ubuntu的首个发行版，Ubuntu 4.10突出特性是，简单而快速的安装，服务器的简约安装模式和0.9版本的Firefox。在其貌不扬的外表下，Ubuntu 4.10 用灵魂深深诠释了啥叫“低调奢华有内涵”。

Ubuntu 6.06 LTS，开发代号 "Dapper Drake"

发布时间：2006-06-01

版本介绍：这是Ubuntu 6.06 长期支持版，代号"Dapper Drake"，它在2006年6月1发行，2009年7月14日完成它的使命停止更新。这是Ubuntu 第一个长期支持版(LTS)。它采用了2.6.15的内核和GNOME 2.14桌面环境，引进了Live CD模式和安装CD合并到一张磁盘上，Live CD图形界面安装器，网络管理器用来建议切换无线和有线网络连接，集成了Humanlooks主题。

Ubuntu 8.04 LTS，开发代号 "Hardy Heron"

发布时间：2008-04-24

版本介绍：2008年4月24发布。这是Ubuntu的第二个长期支持版本(LTS)。该版本将设计最好的壁纸之一作为默认壁纸。Brasero烧录器和transmission BT下载客户端也被作为默认程序了。备受争议的Pulse Audio 成为新的默认系统声音配置。该版本也添加了Wubi 安装器。你可以使用Wubi 在不损坏你的windows硬盘分区情况下安装Ubuntu。

Ubuntu 9.10，开发代号 "Karmic Koala"

发布时间：2009-10-29

版本介绍：从该版本开始，Ubuntu慢慢开始转换档期。大量变化开始涌现Ubuntu。在Ubuntu Karmic 发行周期内，Canonical提出了100多页纸的建议，焦点于开发者修改较小的使用毛病。这是一个大动作，给Ubuntu后来发行版本增添了光辉。这个发行版本也引进了Ubuntu 软件中心—这受到了极大的关注。

Ubuntu 10.04 LTS，开发代号 "Lucid Lynx"

发布时间：2010-04-29

版本介绍：Ubuntu 10.04带来了最大量的改变。Ubuntu有了一个全新的商标。褐色主题第一次删除，换成了更为命令和舒服的“Light”主题。除此之外，Ubuntu 10.04 LTS的最大卖点是启动速度有了极大的提升。嗯，开始走”高大上“路线了。

Ubuntu 12.04 LTS，开发代号 "Precise Pangolin"

发布时间：2012-04-26

版本介绍：Ubuntu 12.04 LTS是一个非常出色的版本，着眼云计算，密谋大数据可以说是该版本的最大特点。 Ubuntu 12.04 LTS新功能包括调整生命周期，用更多的时间解决问题。将基础架构和平台方面的变化降至最低。目标驱动和连续的性能基准测试项目。一流的可用性，满足特殊互动需要。硬件类型的增强和认证，便于在数据中心部署。

Ubuntu 13.10，开发代号 "Saucy Salamander"

发布时间：2013-10-17

版本介绍：13.10桌面版新特性包括新版LibreOffice、RhythmBox和Firefox，搜索工具Smart Scopes将搜索范围从亚马逊扩大到了维基百科、reddit、Foursquare、eBay和Ubuntu One音乐商店，网络搜索功能可以在属性页关闭。服务器版的Server 13.10包含了最新版的OpenStack云架构软件，升级了Juju管理软件，可以帮助将软件部署到多个云服务上。

以上就是我们筛选的Ubuntu版本更新史上几个比较有代表性的版本。如果要查看Ubuntu的详细历史，可以登录维基百科，或者Ubuntu官网。

后记：

Ubuntu已经推出10年了。十年中它从引领时尚，站在开源推广的先锋，再到现在退居其二（第一是Linux Mint）。这十年一路走来，Ubuntu将Debian的APT包管理系统，发挥到极致，并极大的缩短了新手接触Linux的学习曲线和痛苦。Ubuntu也曾站在舆论的风口浪尖，它激进地推出Unity桌面环境和Mir，让传统的自由软件社区难以驾驭；它也曾因为在Unity上集成了Amazon服务，而被自由软件基金会的Richard Stallman指责。回顾这些历史，令我们感慨万千。对于Ubuntu是在越变越好，还是在错误的道路上渐行渐远，相信各位看官心里都有自己的判断。

作为旁观者，我只想说一句：Ubuntu，且行且珍惜！
