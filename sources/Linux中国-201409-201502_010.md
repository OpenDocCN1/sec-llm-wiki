# 微软开源 .NET CoreCLR

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=202945142&idx=2&sn=d976f2d0b8e5d9c5827b2a86854146f9&chksm=2f04893018730026470ce5fe54c871e464930f2ac78d14355993f3ac4c2f37b95f9743d66191&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=202945142&idx=2&sn=d976f2d0b8e5d9c5827b2a86854146f9&chksm=2f04893018730026470ce5fe54c871e464930f2ac78d14355993f3ac4c2f37b95f9743d66191&scene=27#wechat_redirect)

微软推行开源计划已有很长时间，在去年12月宣布.NET Core开源后，今天他们又向前迈了一大步，通过发布.NET核心公共语言运行时（CoreCLR）源代码的方式实现了.NET整个服务器开发环境的开源。 这次发布包括完整的CoreCLR，它可被当做.NET的“执行引擎”，包括RyuJIT、.NET垃圾回收机制、本地互操作以及许多.NET运行时的其他组件。 它运行于Windows 平台，未来数月将会实现对Linux和Mac的支持。

当你在.NET内核中运行ASP.NET 5应用时，除了要依靠CoreFX/BCL函数库外，CoreCLR就是负责执行你代码的组件。 微软称他们还将继续开源并让.NET运行时与服务器实现跨平台。此外，微软还将在3月18号与19号举办一次虚拟.NET会议，届时开发者将听到更多有关.NET内核的信息。

微软科技的开源向世界展示了微软正在敞开胸怀拥抱现代开发社区。之前，微软曾非常注意对每段代码的保密，但现在他们对社区代码共享有了更加开放的态度，所以开源CoreCLR只是微软开源计划的一个小小的印记。

访问CoreCLR的GitHub: https://github.com/dotnet/coreclr
