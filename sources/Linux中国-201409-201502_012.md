# 盖茨在其 Facebook 上贴了一张 Ubuntu 照片

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=202928857&idx=2&sn=0169332812e9104cc340c534a36f3b57&chksm=2f04499f1873c089c7157cfe0d52893c59c29ff5812a55b69fd64e6d1b584419b149158e638b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=202928857&idx=2&sn=0169332812e9104cc340c534a36f3b57&chksm=2f04499f1873c089c7157cfe0d52893c59c29ff5812a55b69fd64e6d1b584419b149158e638b&scene=27#wechat_redirect)

微软联合创始人比尔盖茨在其Facebook页面贴了一幅照片（如图），在下面写道“15年后，贫困国家的大部分人将能在网上上课”，Mark Zuckerberg对这个帖子点了赞，而其他人则注意到照片中的电脑运行的是Ubuntu操作系统。

看起来无论是Windows的创造者还是今天的微软，都在改变对待Linux以及开源的看法。微软最近还雇佣了两名知名开源人士：Mozilla的首席开发者大使Christian Heilmann和开放标准的支持者Aaron Gustafson。
