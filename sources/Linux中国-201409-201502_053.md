# Red Hat联合创始人谈自由、控制和GPL

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=202604076&idx=3&sn=fdf7797d5863ed5ca8f636d7c6e8291e&chksm=2f0f456a1878cc7c0cc01c48ade22f94ad7b8fc3063c65d92a1eeeefe4a5e052e7ce0bd12521&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=202604076&idx=3&sn=fdf7797d5863ed5ca8f636d7c6e8291e&chksm=2f0f456a1878cc7c0cc01c48ade22f94ad7b8fc3063c65d92a1eeeefe4a5e052e7ce0bd12521&scene=27#wechat_redirect)

自称“只是一名打字机销售员”和“邪恶资本家”的Red Hat联合创始人Bob Young在上周新西兰举行的linux.conf.au大会上谈论了自由、控制和GPL。

Young说，他最初是一名自由软件的怀疑论者，但编辑软件开发新闻邮件时，他反复听到开发者想要了解更多的自由软件信息。

到Linux 1.0发布时他开始接触Richard Stallman、Donald Becker等人，试图找出利他主义成功的原因。最终让他猛然醒悟的言论来自工程师：工程师认为自由软件让他们能控制自己的系统，而控制是私有软件开发商不愿意分享的。让用户能控制自己的系统是Red Hat成立的根本，也是该公司相对于私有软件商业模式的一大竞争优势。

时至今日，Red Hat仍然将让客户控制自己的系统视为最重要的事情，客户被作为公司的合作伙伴对待。

对于GPL许可证，Young提到RMS曾考虑将其开发的软件进入到公共领域（public domain），但发现公共领域概念无法防止滥用，比如无法防止公共领域软件成为私有软件。GPL及copyleft概念就是创造出来为公共领域软件提供法律保护。
