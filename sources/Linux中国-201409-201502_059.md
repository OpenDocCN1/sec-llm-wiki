# OpenFoundry 落幕，台湾开源活动或遭重挫

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=202578808&idx=4&sn=9d740204200d1b31725afa828272c21c&chksm=2f0f203e1878a92897ae1af8bf3e3bc9c28a257478147dd932e4ee74f846851ce951a22085db&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=202578808&idx=4&sn=9d740204200d1b31725afa828272c21c&chksm=2f0f203e1878a92897ae1af8bf3e3bc9c28a257478147dd932e4ee74f846851ce951a22085db&scene=27#wechat_redirect)

台湾开源活动重要推手 OpenFoundry（自由软件铸造场）将于年底吹熄灯号，台湾Linux核心高手也是成大资工系讲师黄敬群表示，以亚洲来说，OpenFoundry 是相当早推广开源的官方组织，对台湾的开源推广贡献良多。

OpenFoundry项目经理洪华超表示，OpenFoundry 结束原因为，由于OpenFoundry是台“科技部”补助三年一期的计划，“中研院资讯科技中心创新研究中心”配合“国家”政策拨补经费支持，“科技部”为了要重新分配资源，暂停将经费拨给自由软件，将于今年底终止OpenFoundry计划。

很多开源社区成立之初，都缺乏资源，包括了经费、人脉与经验等，OpenFoundry 透过长年举办技术推广课程、相关技术新闻与文章等，协助解决了开源软件社区在成立初期面临资源不足的问题，五倍红宝石创办人高见龙说。

OpenFoundry也协助开源社区筹办了多场开源研讨会，包括 COSCUP 开源人年会、PHP 与 Ruby 研讨会等，且提供了“中研院”国际会议厅等场地与赞助活动资金。

高见龙说，约5至6年前，台湾开源社区蓬勃发展时，一年内有10场以上的开源研讨会，如 Ruby 与 PHP 等，但当时因为开源社区缺乏场地资金来源，大部分都是靠 OpenFoundry 赞助。“如果没有 OpenFoundry，当时的活动根本办不起来。”高见龙说。

OpenFoundry 也提供法律服务，包括了自由软件授权条款研究、案例追踪、商业运用模式与政府政策研究等，此外，若遭遇法律疑问，OpenFoundry 也提供基本咨询或协助解决争端。

虽然自由软件可供免费使用，但是还是有复杂的授权程序，常常会因此产生纠纷，甚至是公司间的诉讼，因此，OpenFoundry 提供法律咨询，协助民众与许多新创公司等，避开耗时的法律诉讼，洪华超说。

黄敬群说，OpenFoundry 也发表了大量的科普文章，让更多人得以理解与运用开源与自由软件。高见龙也表示，OpenFoundry 非常有心要推广开源，还会定期向各界人士邀稿，再发送电子报等。

因此，洪华超说，由于 OpenFoundry 是台湾唯一推广大专院校以上使用自由软件的官方组织，一旦计划结束，开源社区顿时失去和政府之间的沟通桥梁、开源社区要举办研讨会时，也将无可以借用国际级会议厅的管道，且台湾将无官方组织持续推动开源活动。高见龙说，和“中研院”租借国际会议厅场地的费用，甚至只为市面上十分之一的价格。

未来，虽然 OpenFoundry 将于2015年底结束，但2014年6月成立的开放文化基金会，由开源社区集众人之力创立的，由高嘉良、赵柏强、郑鸿旗、黄隽与李柏锋担任董事，也能继续推广台湾的开源精神与活动等。而在政府方面，目前只剩下“教育部”的校园自由软件数位资讯推广服务中心（Oss Application Consulting Centre），交由“中华民国”软件自由协会承办，辅导国中小学使用自由软件。

“中华民国软件自由协会”理事洪朝贵表示，目前台湾政府以“拼经济”的观点来看自由软件，由于得不到具体在经济发展上的成果，所以不继续支持。建议日后改由“教育部”、“档案管理局”、“中小企业处”等单位以使用者而不是从生产者身份来推广，不但可以让参与者做起事来更方便，也可以让大家更容易看见自由软件的重要性。

高见龙说，若开源社区有借场地办活动的需求，五倍红宝石可以较低的价钱提供场地。他说，由于五倍红宝石为一群 Ruby 开发者社区所成立的公司，先前也获得很多 OpenFoundry 的帮助，因此，基于回馈的心，为了可以让 OpenFoundry 推广开源的精神延续下去，会提供活动场地来协助开源社区。

OpenFoundry 成立于2003年，最早的计划主持人的“中央研究院资讯科学研究所”院士李德财，现任计划主持人为国际知名即时操作系统大师也是“中研院”院士张韵诗，成立目的为扩大自由软件在台湾的应用幅度与研发能量，刚开始获得“经济部工业局”“自由软件产业推动计划”的补助，现在经费来源则是“行政院科技部”与“中研院资讯科技创新研究中心”。
