### 求2的32次方：

码农：

```
1.  System.out.println(Math.pow(2, 32));
    
```

黑客：

```
1.  System.out.println(1L<<32);
    
```

2B程序员：

```
1.  System.out.println(2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2\*2);
    
```

### 交换两个数：

码农：

```
1.  void swap(int &a,int &b)
    
2.  {
    
3.      int temp;
    
4.      temp\=a;
    
5.      a\=b;
    
6.      b\=temp;
    
7.  }
    
```

黑客：

```
1.  void swap(int &a,int &b)
    
2.  {
    
3.      a\=a^b;
    
4.      b\=a^b;
    
5.      a\=a^b;
    
6.  }
    
```

2B程序员：

```
1.  void swap(int a,int b)
    
2.  {
    
3.      int temp;
    
4.      temp\=a;
    
5.      a\=b;
    
6.      b\=temp;
    
7.  }
    
```
