# 2015年值得参与的5个开源项目

我们在生活中或多或少都有用到开源软件，也许你会想回馈一下这些社群，却不知道要参与哪些项目。现在网络上有无数的开源软件项目正进行着，即便我们之前的文章已经给过一些建议，要在其中挑选出最适合你参与的，可能并不是那么容易的事。

为了帮助大家找到最适合自己的项目，这里将会列出五项不同领域的开源项目，你可以考虑在2015年加入其中之一看看！也许这些项目并不是最有名或最厉害的，但他们都提供了相当有趣的挑战，参与它们同时也是你回馈社群的一个好办法！

准备好了吗？那我们就开始吧！

### BRL-CAD

如果3D建模对你而言是个有吸引力的主题，那么你大概也会对BRL-CAD有兴趣，它是一个功能强大且富有弹性的系统，不论你是程序员或是设计者应该都可以在其中找到独特的挑战。

在 BRL-CAD 的项目里，有许多问题正等着人们来解决，就像开发团队说的「从非常艰深的数学到最简单的杂务」都有。你可以挑选一些上选门坎较低，甚至数小时内就可以完成的工作；或者你有更高的目标，愿意花时间探索项目的核心部分。如果你是一位程序员，你也可以帮助他们使程序代码更加完善。

如果你有心想参与，可以到BRL-CAD的参与指南来获得更多信息。

### Speed Dreams

你喜欢竞速的感觉吗？你热爱游戏吗？如果是，Speed Dreams可能就是适合你参与的项目。它是一个3D的赛车模拟与竞速游戏，同时拥有 Windows 和 Linux 版本，而 Mac 版本也已经有大约95%的完成度。

你可能会问：该怎么参与？这项项目目前正在寻找更多开发人员、设计者以及文件撰写者的帮助，如果你是个游戏玩家，参与这项项目还可以把你对游戏与开源软件的热情结合在一起，可以说是一举两得！

### OpenMRS

能够直接服务到社会大众的软件也许不太常见，但 OpenMRS 正是其中之一。它是一个帮助医生与护理人员管理病人信息的开源平台。

这项项目正在寻求各种人的协助：从程序员、测试员、IT 人员、UI设计者到翻译人员都有它的需求。想对这项项目有所贡献的话，你可以加入它们的社群，藉由提出你的构想、新功能的建议或是帮助他们找出错误，来让这项项目更加完善！

### Audacity

Audacity 是一个非常有名的录音与混音软件，从2000年开始，它一直不断的在更新、进化，也有越来越多的使用者开始尝试 Audacity 带来的服务

就像大部分的开源软件，Audacity也需要各式参与者的协助。不仅是程序员或测试员，更需要撰写文件的人和翻译人员让更多国家的人接触Audacity。你也可以透过回报错误与提出建议的方式来对 Audacity 做出贡献。

### FLOSS Manuals

你也许不是一名程序员、测试员或设计者，但不论如何，我们都有基本的写作能力。在这种情况下，你也许可以看看FLOSS Manuals的信息。这项计划不仅汇集了众多自由开源软件的信息，它本身也是一个相当活跃的社群。

要加入FLOSS Manuals，你不需要从头开始撰写一本手册，你可以帮忙改进现有的文件，或是挑出错字。你也可以尝试校阅、编辑文件，甚至对整个项目提出改善的建议。上他们的网站来获得更多信息吧！
