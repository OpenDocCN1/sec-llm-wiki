# Windows 平台 Lisp 开发环境 Corman Lisp 开源

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=202158577&idx=3&sn=1dfed9c2d53409db7fb07c78d0b310f6&chksm=2f108ab7186703a198a29081780f52caf0187e23085609b5280601908b5397f4c34dbf3fb4b1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=202158577&idx=3&sn=1dfed9c2d53409db7fb07c78d0b310f6&chksm=2f108ab7186703a198a29081780f52caf0187e23085609b5280601908b5397f4c34dbf3fb4b1&scene=27#wechat_redirect)

Corman Lisp是Windows操作系统下的Common Lisp开发环境，Corman Lisp包含了一套Intel处理器下的Common Lisp原生代码编译器、80x86汇编和反汇编工具以及多窗口的文本编辑器。Corman Lisp支持运行在Windows系列操作系统上，如Windows XP、Windows 2000等。Corman Lisp全面支持Win32 API、全部的Windows API函数等。关于Corman Lisp的特性，可查看官网介绍。

目前，Corman Lisp最新版本已经开源，分发协议为MIT。

GitHub代码托管地址：https://github.com/sharplispers/cormanlisp。

著名Common Lisp程序员田春（@田春冰河）在其微博上发表评论说：

> Corman Lisp是所有平台上第一个免费的可以像C语言编译器那样把Common Lisp代码编译成小尺寸独立可执行文件的Common Lisp实现，如果好好维护，未来可超越Windows下的其它开源Common Lisp平台（SBCL, CCL, ECL）。
