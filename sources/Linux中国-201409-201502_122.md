# AMD 催化剂的 Linux 驱动打败 Windows 驱动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=202135921&idx=3&sn=a64eb0b4c97d0bd2fe667e7c5ddc2d62&chksm=2f1062371867eb211cf3dd0846b31f74408464c6316bf2adbb5addaaf48aa5f7d79ed8612cbb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=202135921&idx=3&sn=a64eb0b4c97d0bd2fe667e7c5ddc2d62&chksm=2f1062371867eb211cf3dd0846b31f74408464c6316bf2adbb5addaaf48aa5f7d79ed8612cbb&scene=27#wechat_redirect)

许多人可能还停留在AMD显卡对Linux支持很差的阶段，而现实是AMD的Linux支持在过去几年有了巨大飞跃，无论是性能还是可靠性。

Phoronix评测了最新的闭源Linux版和Windows的催化剂驱动，以及开源的Radeon Gallium3D驱动。

结果显示，在部分 OpenGL评测项目中，Linux版的催化剂在性能上打败了Windows。

而AMD的Linux开源驱动过去一年增加了很多新功能，包括OpenMAX/AMD视频编码支持，改进电源管理，等等。性能上的改进同样巨大。
