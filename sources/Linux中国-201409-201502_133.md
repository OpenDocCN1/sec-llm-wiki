# Chrome OS现已支持在窗口中运行Linux

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=202055661&idx=2&sn=54abf738365b8c9288fb856ed55f966b&chksm=2f1724ab1860adbd217c4c9ff5c389031bb77bded36122b4759245ad5a80e02521de09f84544&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=202055661&idx=2&sn=54abf738365b8c9288fb856ed55f966b&chksm=2f1724ab1860adbd217c4c9ff5c389031bb77bded36122b4759245ad5a80e02521de09f84544&scene=27#wechat_redirect)

Google的Chrome OS系统又迎来了一个实用更新。根据弗朗索瓦·博福特(François Beaufort)在Google+上的爆料，借助Crouton Chrome扩展，Chrome OS现已支持在窗口中运行Linux。当然，在使用该扩展之前，你需要先将自己的Chromebook设置成开发者模式(Develeper Mode)。

此前，Chromebook用户必须通过一个虚拟终端，才能在Chrome OS和Linux发行版之间来回切换。而现在，Crouton Chrome扩展将为用户带来更多的便利。
