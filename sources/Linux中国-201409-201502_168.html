第一款Ubuntu手机，将于2015年2月在欧洲正式发售

原文：http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=201889579&idx=3&sn=98fe8c9796a379e17d5134b239f21b86&chksm=2f14ac6d1863257b5a56bb0fa37e06ec75f018e469b435a74dada65153b4bcda616b45b5ce12&scene=27#wechat_redirect

据外媒 OMGUBUNTU报道，第一款Ubuntu手机将在2015年2月第二周正式在欧洲发售。发售的这款手机，由西班牙设备制造商Bq制造，这将是Ubuntu手机正式走向消费者市场的处女秀。

本款手机硬件配置信息如下：

  • 屏幕：4.5寸

  • 1.3 GHz Quad Core ARM Cortex A7 (MediaTek)

  • Mali 400 GPU @ 500 MHz (MediaTek)

  • 8GB eMMC存储

  • 1GB RAM

  • 电池：2150毫安

  • 支持双SIM卡

目前，Canonical并未说明该款手机的价格，但据判断不会超过Bq现销售的同等配置安卓手机的价格（149欧元），可能会比该价格更低。
