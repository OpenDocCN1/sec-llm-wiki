# Fedora 21 —— 满足你对 Linux 未来发展的想象

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=201700858&idx=1&sn=30f5a4a375e57674829d6a471028ffe9&chksm=2f198ebc186e07aad1202e0ef6f51c4024957a6dbec3b8af381e99a959d10e242caba4f8867f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=201700858&idx=1&sn=30f5a4a375e57674829d6a471028ffe9&chksm=2f198ebc186e07aad1202e0ef6f51c4024957a6dbec3b8af381e99a959d10e242caba4f8867f&scene=27#wechat_redirect)

如果你想知道企业版 Linux 未来的发展趋势，那么你应该看看红帽的社区 Linux 发行版，Fedora。延迟了几次之后，在这个月的12月9日，Fedora 正式发布了其最新版本Fedora 21，并带来了非常多的新特性和新理念。

![](../Images/43344fae69fb82a19f7f1f30ebe358b7.png)

长期以来，红帽公司一直在 Fedora 发行版上来常是最新的 Linux 和开源软件发展成果，与此同时，并不是所有人都喜欢 Fedora 选择的方向，比如，Fedora 的 init 系统 systemd 到现在仍饱受批评和争议，尽管如此，Fedora 仍然是 Linxu 阵营的领头羊，它意味着 Linux 发行版未来发展的方向。如果一个软件没有被 Fedora 收录，某种意义上来说，它也不会出现在其他主流 Linux 发行版中。

最新版本的 Fedora，也就是 Fedora 21，它的发布推迟了数次，有点姗姗来迟，但是，它运行的效果非常好。

与以往的重心放在桌面版有点不同的是，Fedora 现在以三种不同的子版本来发布： Fedora 21 Cloud, Fedora 21 Server, 和 Fedora 21 Workstation。

每一个子版本都提供给专门的用户来使用，但所有的子版本都共享同一个软件仓库，其中包括全新的 Linux 3.18 内核、RPM、yum、systemd 和 Anaconda 安装器。根据红帽的描述是“这个小型、稳定的组件集合创造出了一个基于 Fedora 的非常稳定的基本运行平台。

这次发布的新版本 Fedora 最指标的新特性主要有这些：

### Fedora 21 Cloud （云场景版）

Fedora 21 Cloud 提供私有云环境中的使用场景，像 OpenStack，AWS (Amazon Web Services) 使用的 AMIs（Amazon Machine Images) ，以及一个基础镜像来激活 Fedora 容器的创建。Fedora 21 Cloud 的重要特性有这些:

*   **适应云计算的模块化内核打包** – 为了节省空间，并且避免云部署过程中出现的规模膨胀，Fedora 21 Cloud 内核仅仅包含需要在虚拟环境中运行的最少模块。整个 Fedora 21 Cloud 的镜像大约比之前版本的 Fedora 体积减少了 25% 以上，并且为关键应用程序启用快速部署和因需弹性空间分配。
    
*   **Fedora 原子主机** – 这是 Fedora 带来的首个“原子型”主机，包括最小的软件包集合，这个镜像仅仅包含了被优化的能在 Linux 容器中使用所需要的最基本的运行时。 Fedora 原子主机允许“原子型”更新作为一个独立单元，简化更新管理，如果需要的话，还能提供滚动更新的能力，此外，它还包含了 Google 的容器集群管理系统 Kubernetes 用于编配，和用于一般容器管理的 Cockpit。
    

### Fedora 21 Server（服务器版）

Fedora 21 Server 子版本提供一个通用的基础平台来运行指标性的应用程序栈，为诸如网络服务器，文件服务器，数据库服务器甚至 PaaS(Platform-as-a-Service) 提供良好且弹性的运行基础。 Fedora 21 Server 带来了这些新特性:

*   **全新的管理功能** – Fedora 21 Server 引入了三项新技术(如下)来处理离散的基础设施安装服务以及管理。
    
*   Rolekit 提供一个用户角色不熟和管理工具来帮助管理员安装和配置专用的服务器角色。
    
*   Cockpit 是一个基于 web 的用户界面，可以用来配置，管理和监控服务器，它可以在远程的任何 web 浏览器上使用。
    
*   OpenLMI 是一个一个远程的管理系统，它提供构建在 DMTF-CIM (Distributed Management Taskforce – Common Information Model) 上的远程管理系统，并且为机器提供脚本管理功能, 兼容性查询和系统事件监控。
    
*   域控制器 (Domain Controller) – 这也是 Rolekit 提供的功能之一，Fedora 21 服务器版将 freeIPA 打包在内，为Linux / UNIX网络环境提供集成身份和身份验证解决方案。运行 Fedora 21 服务器版的机器可以无忧地提供中心化的统一身份验证、授权和帐户信息，通过存储用户、组、主机和其他必需的对象数据来管理网络安全。
    

### Fedora 21 Workstation（工作站版）

Fedora 工作站版 的设计目标是为普通的桌面用户和软件程序开发者提供一个平滑的体验，能开发能娱乐，满足所有常见的基础需求。 Fedora 21 Workstation 的新特性包括:

*   **简化软件安装** – 软件安装器是 Fedora 21 Workstation 的一个基础组件，新的软件安装器帮助用户非常快速且容易地选择他们需要的应用，它提供了弹性、快速的用户体验，手把手地带领用户将数量和质量都得到极大提升的大量 Fedora 应用安装在 Fedora 21 Workstation 中。
    
*   **支持 Wayland 技术**\- Wayland是一个非常强大的下一代显示服务器技术，已经有一个试验性的编译版本包含在 Fedora 21 中了，这允许开发者们来测试和集成他们的应用程序对 Wayland 的兼容性。
    
*   **开发助手(DevAssistant)** – 一个开发者的帮助中心，可以为大量的运行时和集成开发环境(IDE)自动化处理安装过程，开发助手还集成了 Fedora 软件集合，提供多个语言的不同版本而让你不用担心系统软件冲突。
    

Fedora 子版本众多，如果你初开始玩可能会不习惯，Fedora 21 默认的桌面是 GNOME 3.14.2，但是同时也提供了 KDE，LXDE，XFCE 等其他桌面，而很多忠实的传统 Fedora 用户也很喜欢用 MATE 桌面。

介绍完的同时，我也在我的老式 IBM ThinkPad 笔记本上试着安装了 Fedora 21 工作站子版本，可恨的是我那再常见不过的普通触摸板却驱动不起来了，而过去它在我的电脑上一切正常，可谓完美运行。（ps：在另外一台 Acer TravelMate 8481 笔记本上运行状况不错）
