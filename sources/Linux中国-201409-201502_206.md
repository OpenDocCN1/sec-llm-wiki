# 维护通知：本周六 Linux 中国将停机维护

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=201606775&idx=4&sn=feed697468093480412d1596d232456f&chksm=2f187d31186ff427a817403b461ef79d1f7a8b79000e59f7569f23426418527c95f878f06188&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=201606775&idx=4&sn=feed697468093480412d1596d232456f&chksm=2f187d31186ff427a817403b461ef79d1f7a8b79000e59f7569f23426418527c95f878f06188&scene=27#wechat_redirect)

各位朋友好，按计划本周六（2014/11/13）我们将对 《Linux 中国》的服务器进行维护，预计将全天停止访问，期间您可能遇到如下问题：

  

1、http://linux.cn 不能访问。

2、微信的菜单和交互功能不能使用。

3、上述功能工作不正常等问题。

  

请您耐心等待，我们将尽快完成维护，尽早上线。谢谢大家一直以来的支持！

  

—— 《Linux 中国》团队敬上
