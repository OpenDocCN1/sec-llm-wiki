### Fedora 21 Cloud

主要是私有云环境的使用，类似 OpenStack，亚马逊上的 AMIs，新的 "Atomic" 镜像都可以无缝运行在 Docker 容器中。

#### 云的内核包模块化

空间是非常珍贵的，硬件包括驱动，但是云版是不包括驱动的，云 SIG 和内核团队把内核分离成两个包，一个包括最小的可以运行虚拟环境的模块，另外一个包括最多的模块集合，更多通用软件的安装。F21 云镜像比 F20 小了 25%，可以更快的部署，而且能提供更多的空间给用户。

#### Fedora Atomic Host

在四月份的时候，Red Hat 宣布了Atomic 项目，致力于提供工具和一个无缝运行容器的操作系统模式。Fedora 21 首次提供一个 "Atomic" host。

当跟其他 Fedora 版本使用相同的 RPMs 时，Atomic host 可以让你回滚更新（如果需要）作为一个原子，使得更新管理更简单。

其他 Atomic 镜像包括 Kubernetes 和容器管理 Cockpit。

### Fedora 21 Server

Fedora 21 Server 集 Web 服务器，文件服务器，数据库服务器或者是 ISSA 服务于一身。

#### Fedora 服务器管理特性  

Fedora 服务器版本引入了新的服务器管理特性，使得离散的基础设施安装更简单。同时还引入了三个新技术来处理任务，权限包，Cockpit 和 OpenLMI。

*   Rolekit权限部署和管理工具包。
    
*   Cockpit 配置和监控服务器（多台服务器）的用户界面。可以通过 Web 浏览器远程访问。
    
*   OpenLMI 远程管理系统，构建 atop DMTF-CIM。
    

#### 域名控制器服务器角色

其中一个角色部署机制是 Domain Controller Service。

Domain Controller Service 包 freeIPA 集成了 Linux/UNIX 网络环境认证和身份认证解决方案。

### Fedora 21 Workstation

Fedora Workstation 是一款可靠、用户友好，面向笔记本电脑及台式机的强大操作系统。它可以满足广泛的开发需求，从编程爱好者或学生到企业环境中的专家。Fedora 现在更加专注更少的设置选项，更多的创新。选择一种 Fedora 的官方派生版可以简化你的需求，并将工作井井有条。

#### Web 服务集成

可以在一个更简洁的桌面运行 HTML5 Web 应用，可以让用户觉得就像在桌面运行原生扩展一样。

#### 支持高分辨率显示 (HiDPI)

技术永无止步，支持类似新硬件 ultrabook 模式或者是苹果的视网膜屏显示，提供最好的 HiDPI 显示体验。

#### 更令人兴奋的未来规划

Fedora Workstation 并不是不是终点，将会继续开发，把很多新领域新技术都集成到 Fedora 工作站版本（Linux 桌面）：

*   容器
    
*   更智能的虚拟机
    
*   更好的开发工具
    
*   改进工具包的集成
    
*   更多的 Web 集成
    
*   等等
