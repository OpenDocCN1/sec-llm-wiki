# Opera 浏览器正式发布首个 Linux 稳定版本

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=201517429&idx=2&sn=00aafa4dcd12b0621dafdcffeac906dc&chksm=2f1ed23318695b250621c9096540f98f12701e9ceec42647978542193b4185a81e060d3a366f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=201517429&idx=2&sn=00aafa4dcd12b0621dafdcffeac906dc&chksm=2f1ed23318695b250621c9096540f98f12701e9ceec42647978542193b4185a81e060d3a366f&scene=27#wechat_redirect)

著名的 Opera 浏览器在前两天（2014/12/3）首次正式释放出了让人期待已久的稳定版的 Linux 浏览器 Opera 26，这也是其首次发布稳定的 Linux 版 Opera。据 Opera FTP archive 上的归档来看，其 Linux 版本经历了十余年的开发， 在稳定版发布之前，一直都是测试版本。

这次发布的 Opera 版本号是 26，同时也释放出来了 Windows 平台和 Mac 平台下的 Opera 26，Linux 版本的 Opera 26 目前只支持 Ubuntu 系统，只有64位系统版本，也只有一个二进制的deb 包，包名是 opera-stable\_26.0.1656.32\_amd64，虽然 红帽粉，SUSE粉，Arch 粉等等有点失望，但是，deb 包来了， rpm 包还会远吗？诸位耐心等待即好。

这个版本的 Opera 是基于 Chromium 39 开发，从 Windows 版 Opera 15开始，其渲染引擎就由 传统的 Presto 转到了 Webkit 再后来又完全跟随 Google 的步伐，转到了 Blink 引擎，为此很多忠实用户惋惜不已或痛苦不堪，现在 Opera 已经在用和 Chromium 几乎一样的排版渲染引擎了。

*   发现功能 (可以分类显示一些新闻和文章);
    
*   图形化的收藏夹，同时支持分享书签;
    
*   改善的快速进入功能，同时用沙滩风格的方块替代了网页截图 (可选功能);
    
*   内置 PDF 阅读器;
    
*   支持 Pepper Flash (但没有内置进来);
    
*   鼠标滑过的网页预览功能(默认关闭，需自行打开);
    
*   支持 H.264 和 MP3 编码 ( Linux 平台上需要 FFmpeg 2.3+);
    
*   支持 HiDPI ;
    
*   改善的 Opera Turbo;
