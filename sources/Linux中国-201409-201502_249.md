# 电影《星际穿越》里的虫洞特效使用 Linux 系统设计

诺兰新作《星际穿越》正在各国热映，引发了新的一轮观影和讨论热潮，其中最受物理学家们关注的是片中的虫洞，引来不少批评之声。对于Linux用户来说，更有趣的是片中的黑洞是使用Linux系统来进行设计的。

观影者一般不会去关注电影后台制作使用的是什么软件和系统，而作为Linux迷来说确实对制作电影所使用的工具和系统感兴趣，多数人会认为大公司制作一般会选用功能强大的Mac OS X系统，但事实上并不是这样，在好莱坞使用Linux系统及软件制作电影已经很平常。
