# 地狱→炼狱→天堂，国产OS成功路上的必经过程

似乎，现在所有和国产操作系统有关的话听起来都是那么的有气无力，甚至有人认为国产OS就是个噱头。可细想，国产OS经历这么些年的发展，终于赶上政府大力推广的好时机，说不定它今后就能成为操作系统领域的黑马呢！

国内操作系统厂商思普企业集团董事长张龙先生于10月28日在中国操作系统应用推广大会上表示，国产操作系统（以下简称国产OS）的发展经历过一段艰难的日子，就拿思普的经历来说，思普的服务器曾经每天要遭到来自美国3万多次的攻击。而现在拨云见日，国产基础软件的春天已经来了。

![](../Images/ba649f77a20df08848ddc97ca5fdabc6.png)

事实真的像他说的那样，国产OS已经熬过寒冬迎来温暖的春天了？谁也不敢妄下结论，估计这答案只有时间可以来回答了。

### **国产OS是国人的硬伤**

我觉得一提到国产OS的时候，两个字可以形容国人复杂的心情：急，羞！

国产OS真正意义上开始研发，是始于1999年8月，中科红旗首次推出了红旗 Linux1.0版，最初主要是用于关系国家安全的重要政府部门。但彼时并没有向市场开放，以至于到后来已经完全没有实力可以和微软的 Windows 系统相抗衡了。随着最近几年关于国产OS的呼声日渐高涨，又重新唤起了中国人的民族主义思潮。只是，每每“千呼万唤难以始出来”的现象正在慢慢地将国人对本土操作系统的信心消耗殆尽。这其中滋味只有自己知道，多少是有些觉得窝囊的，无奈技术不给力，一时半时还拿不出有竞争力、有影响力的作品。

![](../Images/6d52f20a804d874c032023dbd3807760.png)

国产系统遭受境外网络的攻击，我认为这不完全是坏事。不管是软件产品还是硬件产品，在进入市场的初期，都会遭遇不同程度的外界干扰，这是必经之路。即使是苹果在成形之初也是受到外界嘲笑的。如果说，非得经过磨难才能证明自己价值的话，那么正在地狱里挣扎的国产OS必须还得经过长时间的炼狱过程才能进入天堂。

一款成功的国产OS 难产的原因不外乎：**1、技术不够；2、经济支持不够；3、制度不完善；4、氛围不浓。**但是，要想克服这几大因素谈何容易。经过这十几年来的发展，就算没有什么可以拿得出手的国产OS，至少也该亮亮自己的老底吧！下面我们就来瞅瞅到底有哪些虚张声势的国产OS，以及它们到底发展到什么程度了？

### **还处在“地狱”环节的国产OS都有哪些？**

**1\. 红旗 Linux**

红旗 Linux（1999年）的发展一直依靠政府扶持，比如，2006年中国31省市的政府采购中，80%的省市都选择安装了红旗的 Apatite。最新的版本是2013年发布的红旗 inWise 操作系统v8.0，提高了稳定性、易用性、硬件兼容性。

**状态：**其间有两年时间未推出新版本系统。该公司“因为管理原因”已于2014年2月10日解散。

**2\. 共创 Linux（2001年）**

其最新版本是共创标准桌面版2010。主要用途：用于政府部门，企业事业单位，个人应用领域。

**状态：**自2010年推出共创标准桌面版之后，一直没有最新的版本发行。 

**3\. 银河麒麟（2002年）**

银河麒麟基本上是一个完全为军用定制化的操作系统，虽说也推出了民用版本，但重心使命还是在军用上。目前用途：军民两用版本的操作系统

**状态：**与中标 Linux 合并，以“中标麒麟（NeoKylin）”的新品牌发布统一的操作系统产品。2014年8月，发布了其最新版本银河麒麟操作系统3.0。

**4\. 凝思磐石（2004年）**

虽然凝思磐石安全操作系统号称是具有自主知识产权的 Linux 安全操作系统，也推出了民用版本，不过也仅仅是推出了而已，更像是响应国家号召，无法很好的推广到民用。目前用途：用于军队、政府、电力和电信部门。

**状态：**毫无影响力。

**5\. 深度 Linux（2004年）**

深度系统已获得全球四十多个国家用户的支持，累计下载量达数千万次，并成为在 Distrowatch 上排名最高的中国 Linux 操作系统。2011年还建立起国内唯一拥有数十人员工的专供桌面 Linux 发行版的团队，并逐渐开始打造基于 Linux 系统的生态系统。2013年推出两个版本，2013年之后一年推出一个版本。目前用途：主要为民用版本，由于其源代码开放可控，安全性有保障，维护代价也较小，因此也有政府和企业用户，以及数码爱好者开发者使用。

**状态：**深度 Linux 的发展状况良好。2014年推出最新版本 Deepin 2014正式版，更新速度较快。

**6\. 雨林木风（2005年）**

雨林木风操作系统曾在2008年解散了工作室，但在2009年又再度进军操作系统领域。因为版权问题，选择了独立研发基于 Linux 的操作系统。目前，该版本操作系统与深度一样选取了开发者与数码爱好者市场，发展也逐渐走上正轨。

**状态：**最新版本是2012年10月发布的 StartOS 5.0 正式版。采用了全新的操作界面，并根据国人使用习惯，预装了常用的精品软件，更加符合中国人操作习惯。而其系统界面精仿 Windows 主题，改善了用户体验。

**7\. 思普 SPGnux 操作系统（2005年）**

SPGnux 操作系统是由总部位于云南省的思普企业集团于2005年起开始投资研发的操作系统。其产品包括 SPGnux 桌面操作系统、SPGnux 网络服务器操作系统、SPGnux 办公桌面系统、SPGmail 邮件系统等软件，提供中文、英文、阿拉伯语三种语言。

**状态：**思普 SPGnux 操作系统经历了10年的开发，在这期间，一直为了能够在政府系统采购上占据一席之地而不懈努力。发展势头可以说是以上所有几个所不能比及的。
