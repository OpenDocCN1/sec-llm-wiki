# 微软发布全新免费版Visual Studio 2013社区版

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=201142449&idx=2&sn=2f4a923c4d48d47f738dfabc140105e5&chksm=28e10bf71f9682e138b76ae3e3e061e6eeeaa53d91ec3b9621e6bcb1490a4e15fd7b9eab39f8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=201142449&idx=2&sn=2f4a923c4d48d47f738dfabc140105e5&chksm=28e10bf71f9682e138b76ae3e3e061e6eeeaa53d91ec3b9621e6bcb1490a4e15fd7b9eab39f8&scene=27#wechat_redirect)

微软已经宣布了一个新版本的Visual Studio，并且很大胆地将之免费提供，它就是全新的Visual Studio 2013社区版。

不过该版本有个明显的限制，那就是不能用于企业应用程序的开发。Visual Studio Community 2013是微软VS家族的最新成员，也是专门为学生、开源贡献者、小企业、初创企业、以及独立开发者们设计的一个虽然免费、但功能齐全的开发环境。

免费提供的Visual Studio Community 2013具备完整的可扩展性，包括了5000多个插件。

该版本包括了用于创建非企业跨平台(桌面、设备、云、Web、服务等)应用程序所需的所有特性，如编码效率、跨平台移动开发工具(Windows、iOS和Android)、以及对成千上万的扩展的完整访问。
