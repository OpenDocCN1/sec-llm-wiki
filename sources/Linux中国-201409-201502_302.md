# 计算机科学家要求最高法院裁决API不能被版权保护

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=201112700&idx=1&sn=c7d24eef283b66d051b548ae95eeccfd&chksm=28e0873a1f970e2ceb323765a9c7fccc2936f38927eba8174e2501ae7b1210c7f1cf09c102a1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=201112700&idx=1&sn=c7d24eef283b66d051b548ae95eeccfd&chksm=28e0873a1f970e2ceb323765a9c7fccc2936f38927eba8174e2501ae7b1210c7f1cf09c102a1&scene=27#wechat_redirect)

电子前哨基金会（EFF）代表77名计算机科学家请求美国最高法院审查一个灾难性的上诉法院裁决，该裁决认为API（计算机应用程序接口）能被版权保护，终结了数十年的法律先例和行业惯例。

今年五月，联邦巡回上诉法院法官裁决Java API受版权保护，推翻了另一位法官作出的API不受版权保护的裁决，引发了广泛争议。

此次签名的计算机科学家中包括了五名图灵奖得主，四名美国国家科技奖得主，以及ACM、IEEE和美国文理学院成员。其中含有 AppleScript、AWK、C++、Haskell、IBM S/360、Java、JavaScript、Lotus 1-2-3、S-DOS、Python、Scala、SmallTalk、TCP/IP、Unix和Wiki等计算机系统和语言的作者。
