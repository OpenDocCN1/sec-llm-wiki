# Adobe为Web设计人员推出开源文本编辑器Brackets

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=201049879&idx=2&sn=36ed0f63b4cfcc52db4983ae6ae5848a&chksm=28e7fc511f9075475d2df57ae3a82c5140812e842bd7988b684b1587cb52022d7c20b48a0883&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=201049879&idx=2&sn=36ed0f63b4cfcc52db4983ae6ae5848a&chksm=28e7fc511f9075475d2df57ae3a82c5140812e842bd7988b684b1587cb52022d7c20b48a0883&scene=27#wechat_redirect)

Adobe公司刚刚发布了Brackets 1.0，一款针对Web设计人员的免费开源文本编辑器，内置HTML，CSS和JavaScript，方便开发者进行HTML，CSS和JavaScript编程。 

*   **官方网站**：http://brackets.io/
    
*   **Github代码托管**：https://www.github.com/adobe/brackets

Brackets 1.0适用于Windows，Mac和Linux操作系统，为Web设计人员和开发人员提供针对性的功能，如实时预览，在浏览器视图和源代码之间轻松切换，在特定的代码位进行内联编辑工作，而无需弹出式窗口或其他选项卡。用户还可以下载和使用扩展，添加功能以帮助他们的工作流程，如Git整合和JSHint支持。

此版本还包括摘要预览，自动从PSD获取设计信息，比如颜色，字体，渐变，图片等等，并生成干净的CSS。Brackets作为一个开源项目，在三年前开始研发。那些想要自定义文本编辑器的用户，可以从Github上Brackets项目页面下载源代码并修改代码进行编译，来适合自己的需求。
