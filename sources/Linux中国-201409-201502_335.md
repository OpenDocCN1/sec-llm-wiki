# Mozilla将移植Firefox OS到树莓派

Mozilla基金会在其今年举办的Mozilla Festival活动发起了一个项目，号召开发者将Firefox OS移植到树莓派上。Mozilla相信，Firefox OS移动平台可以为开发者开发树莓派智能设备和应用提供便捷服务。
