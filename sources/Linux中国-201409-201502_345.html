Fedora 22 可能移植 Elementary OS Pantheon 桌面

原文：http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200927730&idx=3&sn=264a79ff3c8e9b5e5103d1f91c2490e7&chksm=28e5d2b41f925ba2424773c4a07b3f42d223226caaaba6a038e525b85513ae9ec05e6e1489ee&scene=27#wechat_redirect

Fedora 开发者正在考虑移植 Elementary OS 的 Pantheon 桌面。如果移植的事情得到肯定，Pantheon 桌面将可通过 Fedora 默认库安装，而这一切将会在明年发布的 Fedora 22 开始。

如果完成，它将为 Fedora 和 Fedora 爱好者带来实实在在的好处，Pantheon 桌面一款非常受欢迎的轻量级桌面环境。

另外值得一提的是，Pantheon 已经安装在 Gentoo Linux 上，而且它将很快将更好的支持 Arch Linux 并且 Elementary OS 开发人员正在将它带入 Debian 系统。

Pantheon 桌面是一款轻量级桌面，使用 gtk3 和 Vala 开发，Elementary OS 的默认桌面环境。它提供了一个dockbar，其定制版的Nautilus，以及其他许多变化，让其成为一款非常美丽的操作系统。
