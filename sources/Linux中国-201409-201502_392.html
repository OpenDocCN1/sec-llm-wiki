那些没能看到2015年曙光的开源/自由软件

自由软件和开源软件从出现在这个世界上的那个时间开始，就没少受到排挤，竞争压力可想而知。有些项目在做到一半的时候就觉得没有生存的希望，有的项目即使已经完工了，还是不得不停掉，原因就在于没有竞争优势。

一些开源项目在进行过程中突然中止，这倒并不是一件坏事，说明它被更好的项目替代了。下面就来看看今年的软件厮杀过程中哪些项目已经阵亡了，其中有些自由软件和免费的软件。

1、TrueCrypt 磁盘加密

TrueCrypt 开源加密文件和磁盘加密软件项目的经理在今年的5月份叫停了这一进程，并指出在 Microsoft 缩减对 Windows XP 支持之后，这一开发项目也就流产了。用于 Windows、Mac OS X 和 Linux 的工具已被很广泛的专业人员和客户所使用，通过动态加密的方式以确保敏感信息保密。TrueCrypt 的项目团队给出的建议就是将加密数据转换到其他程序上，例如 Microsoft BitLocker。

2、为 Windows 8 Metro 打造的 Firefox 浏览器

Mozilla 后来也在测试版里看到了为 Windows 8 Metro 打造的 Firefox 浏览器的微不足道的利润，Firefox VP Johnathan Nightingale 在今年的三月份写道：“本周早些时候，我要求我的工程部领导和发布经理将 Windows Metro 版本的 Firefox 浏览器项目下马，这个团队很优秀，工作很到位，但是估计只能运行这么一个 1.0 版本，应该将更加广阔的开发环境用在 Metro 平台之外。”

3、Ubuntu One 云存储服务

Canonical 公司在今年的6月1号就已经将它的 Ubuntu One 云存储服务关闭了，可以说是把这么个肥肉拱手让给了 Dropbox、Google Drive 和 EMC Syncplicity。内容服务上的用户文件到7月31日就会截止，客户付费账户将得到退款。

4、Ubuntu for Android

Ubuntu是最著名的Linux发行版之一，近年来Ubuntu在移动市场投入了不少精力，但并不总是事事如意。现在，Ubuntu的工程师确认了一条消息，Ubuntu for Android将会停止开发。实际上，Ubuntu for Android的官方介绍早已经不再更新，该项目一直处于半死不活的状态。

根据Muktware网站上的话来说： Ubuntu for Android项目发起于 2012年，主要是为了将Android Mobile 和Ubuntu Linux desktop整合到一起。但目前为止该项目已被搁置，不在积极开发状态。

5、Google Quickoffice

Google 公司宣布旗下的 Quickoffice App 将会在未来几个星期内，从 Google Play 和 Apple 的 App Store 中下架了。此举的原因是，Quickoffice 的功能已经整合了在 Google Docs、Sheets 和 Slide，所以 Quickoffice 作为一款程序商店中的独立 App 之意义也不大。

Google 指现有用户可以继续使用已安装的 Quickoffice，只是它不再会有新功能。而"新用户"则"不能再安装这个 App"，难道他们会遥控封锁自行下载 apk 档安装的人？总之，如果你还是喜欢 Quickoffice 多于 Google 文书处理 App 的话，可以即时下载 Quickoffice 备用啊。

6、LogMeIn Free 版本

LogMeIn 是一款基于Web的安全可靠的远程接入软件，它具有强大的控制功能，可以让用户在任何一个可以上网的电脑上免费的控制家中的PC或者办公室的PC。软件支持强大的256-bit SSL加密，双密码验证，RSA SecureID。

2014年3月起，LogMeIn Free 将不再可用。用户无法继续体验免费的远程访问功能。若要继续使用，需要购买 LogMeIn Pro 帐户订阅。作为之前试用过老用户，LogMeIn 将提供优惠的试订价，2 台计算机的订阅包售价 49 美元/年。新的 Pro 帐户将包括具有远程打印等高级功能的签名远程访问、文件传输和云数据访问，以及可提升体验的桌面和移动应用程序。
