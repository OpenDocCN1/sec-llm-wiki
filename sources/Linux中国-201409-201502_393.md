# Typecho：国人开源PHP博客系统，三年磨一剑！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200810287&idx=2&sn=abb28a26100ae2f2d3c00f71c48ee2f4&chksm=28e424691f93ad7fc6e464f0d700e98a8483ba808b6d2badaba1bd1c5c7f68b16f1e9390c89b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200810287&idx=2&sn=abb28a26100ae2f2d3c00f71c48ee2f4&chksm=28e424691f93ad7fc6e464f0d700e98a8483ba808b6d2badaba1bd1c5c7f68b16f1e9390c89b&scene=27#wechat_redirect)

Typecho是由国人开发的基于PHP的开源博客系统，遵循GPL Version 2许可证，近日刚刚发布最新版本1.0版本。Typecho具有轻量高效、稳定、简洁的特性，CPU和内存使用率消耗低，原生支持Markdown语法，支持部署在BAE/GAE/SAE等各类云主机。

据了解，Typecho的前身是由Typecho项目发起人70开发的开源博客程序Magike，在第一次WordCamp China活动上形成了最初的Typecho团队。团队成员来自天南地北，遵循敏捷开发的思路，通过邮件、IM沟通并制订开发计划，利用工作之余的闲暇时间完成各种工作。

至于为何Typecho，团队介绍说，这源自开发团队在精神层面上的洁癖和狂热。在使用博客程序的大部分时间里，使用者不需要高级复杂的系统，需要的是一个简单快速的博客平台。但在流行的开源程序中，能够满足这项要求的程序并不多，于是他们就自己动手开发一款有性格的博客程序，同时，也算是他们对“开源”的回报。
