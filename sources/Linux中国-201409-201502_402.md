# Linux中国 2014 线下沙龙（北京）报名开始

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200800339&idx=2&sn=2c7318b1329028b1cbe853f294910c9e&chksm=28ebc3151f9c4a03b58b05a9cfd24d304da6a85f317fda3f9dc9dd9fc2ce455406ad18366769&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200800339&idx=2&sn=2c7318b1329028b1cbe853f294910c9e&chksm=28ebc3151f9c4a03b58b05a9cfd24d304da6a85f317fda3f9dc9dd9fc2ce455406ad18366769&scene=27#wechat_redirect)

一年又将过去了，Linux 中国承蒙大家的支持，已经取得了一点点成绩。为了增进友谊，从线上走入线下，给大家创造更多的技术沟通和社交机会，我们诚邀各位新老朋友来参加我们的沙龙。

本次活动邀请了来自 CSDN、央视网、优才网等的技术高手为大家做技术分享，也是 Linux 中国建站以来第一次较大规模的线下聚会。

本次活动得到了互动出版、图灵社区、CSDN 等的鼎力支持，以及各个兄弟社区的协助，在此致以感谢！

请点击“**报名链接**”赶快报名吧，本次沙龙名额有限，报满为止。
