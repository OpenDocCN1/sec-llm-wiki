# Debian 8考虑停止提供GNU/kFreeBSD版本

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200783535&idx=1&sn=5e871985184060eb25d8a6b6d7ec4c6e&chksm=28eb8de91f9c04ff7f3ba4cb38c7faa16509b38011ad77a3f18bfadc86d0fa5606ff57a57bc6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200783535&idx=1&sn=5e871985184060eb25d8a6b6d7ec4c6e&chksm=28eb8de91f9c04ff7f3ba4cb38c7faa16509b38011ad77a3f18bfadc86d0fa5606ff57a57bc6&scene=27#wechat_redirect)

Debian 8 Jessie有可能停止提供Debian GNU/kFreeBSD——基于FreeBSD内核的版本。Debian除了Linux内核外，还有FreeBSD、Hurd和NetBSD内核版本，Debian Squeeze是第一个支持FreeBSD内核的Debian发行版。

Debian开发者正在邮件列表上讨论此事，停止发布GNU/kFreeBSD版的主要原因是该版本的质量欠佳。Debian将在11月1日或之后评估Debian 8 Jessie GNU/kFreeBSD版本的可行性，之后再做出正式决定。
