# 你不一定知道，如何重置CentOS 7的Root密码

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200780207&idx=1&sn=76c28e96d93824d130a33eb46d1967a9&chksm=28eb92e91f9c1bff7897141f895cf4d8e459a02ac67193e641ebb8cb1a020010c3296db23b1e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200780207&idx=1&sn=76c28e96d93824d130a33eb46d1967a9&chksm=28eb92e91f9c1bff7897141f895cf4d8e459a02ac67193e641ebb8cb1a020010c3296db23b1e&scene=27#wechat_redirect)

重置Centos 7 Root密码的方式和Centos 6完全不同。让我来展示一下到底如何操作。

1 - 在启动grub菜单，选择编辑选项启动

![](../Images/e22019096fb4c00a74c0118c940a5b24.png)

2 - 按键盘e键，来进入编辑界面

![](../Images/dee87278d6d51903148df12028ff7f96.png)

3 - 找到Linux 16的那一行，将ro改为rw init=/sysroot/bin/

![](../Images/ec5f43ce8a8f6aa4aa9ff9ee1b75437a.png)

4 - 现在按下 Control+x ，使用单用户模式启动

![](../Images/3c1f703f95ec288b01e0a6c4d33f07fc.png)

5 - 现在，可以使用下面的命令访问系统

```
chroot /sysroot
```

6 - 重置密码

```
passwd root
```

7 - 更新系统信息

```
touch /.autorelabel
```

8 - 退出chroot

```
exit
```

9 - 重启你的系统

```
reboot
```

就是这样！
