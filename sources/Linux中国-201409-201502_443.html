Windows Server 2003 也快被抛弃了

Windows XP已经被终结了五个多月，而它的服务器兄弟Windows Server 2003也命不久矣，将会在2015年7月14日彻底被放弃。Windows XP在桌面上的经典地位无可取代，Windows Server 2003在服务器上同样出类拔萃，很多追求稳定、朴实的用户都非常喜欢它(还支持4GB内存哟)。

IT服务公司Insight Enterprise的微软解决方案主管David Mayer就评价说：“Windows Server 2003是一套非常稳定、非常健壮的服务器操作系统。”

据他给出的数据，目前全世界的微软系统服务器中，大约39％运行的都是Windows Server 2003，也就是约2400万台，其中有940万台在美国。相应地，SQL Server等软件也是老版本流行，2005的用户就特别多(但它也会在2016年被放弃)。

虽然还有十个多月的时间，但鉴于服务器平台对各方面的要求都更高，更新换代更加谨慎，Windows Server 2003用户所面临的问题会更麻烦，会给大量企业用户造成无数的麻烦、隐患。——普通人没有安全补丁可以无所谓地裸奔，服务器可没那胆量。

可选的出路也不多，继续用本地系统那就是Windows Server 2012 R2，想上云端就是Windows Azure。前者很现代，很强大，但对硬件的要求也很高，而升级服务器可不像换台式机或者笔记本那么简单。
