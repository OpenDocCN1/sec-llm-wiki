开源办公软件LibreOffice四岁了

原文：http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200761939&idx=4&sn=427e9edec4aff9e292cf9d09cd6fe94e&chksm=28eb59151f9cd0038642145db597de5c770760261784960273097ece66d95106d4c7747541d9&scene=27#wechat_redirect

Linux基金会旗下的著名开源办公套件LibreOffice四周年了。四年前，2010年9月28日，一群开发人员从OpenOffice.org独立出来，开始了LibreOffice，他们的目标就是创造出比OpenOffice更好的办公套件。

当时Linux社区比不看好LibreOffice，认为他们和OpenOffice有太多的交叉，只会慢慢消失。但是LibreOffice超出了所有人的预期，现在LibreOffice套件在Liunx平台上已经远远超出了所有的竞争对手。而这一切只花了四年的时间。

比较世界上其他的重大开源项目，四年其实是个很短的时间，LibreOffice已经触及到了商业软件的市场。现在世界上已经有不少城市已经切换到LibreOffice而放弃原先的商业软件。

Linux基金会指出这四年间LibreOffice取得了令人难以置信的成就，现在LibreOffice已经是一个国际项目，由来自世界各地的数百名开发者和少量员工共同维护，LibreOffice的下一个目标是进军移动办公领域。

为了庆祝LibreOffice的生日，Linux基金会几天前发布了全平台支持的LibreOffice 4.3.2，这是目前最新的版本。

LibreOffice生日快乐！

LibreOffice 4.3 可用于以下操作系统和架构：

  • Linux x64 (deb)

  • Linux x64 (rpm)

  • Linux x86 (deb)

  • Linux x86 (rpm)

  • Mac OS X (Intel)

  • Mac OS X (x86_64 10.8 or newer required)

  • Windows
