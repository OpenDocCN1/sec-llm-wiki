Windows 9应该向Linux偷师的5大特性

微软将于9月30日召开新闻发布会，预计传闻已久的Window 9会与我们见面。根据此前泄露的截图来看，Windows 9将会添加通知中心等新特性，并且修复一些Windows 8双界面带来的混淆感。


从某种程度上来说，windows 9看上去借鉴了一些Linux（Ubuntu）的元素，事实上它还可以更彻底一些。Linux虽然并非是主流的消费操作系统，但很多亮点是值得学习的。如果微软想要Windows 9更成功，可以借鉴Linux的以下5个部分：

1. 一个桌面版的应用商店

Windows 8的巨大变化是集成了Metro界面，同时又加入了Metro应用程序商店。给用户带来的困惑是，进入应用商店下载的内容仅能在Metro界面下使用，而各种EXE应用仍需要在传统桌面用老方法下载，会令很多用户产生混淆感。

而 Linux的做法是集成了Package管理器、或者称之为桌面应用程序商店，你可以在其中找到任何应用程序。所以，既然微软提供了Metro应用商店， 为什么不再进一步添加传统桌面应用商店，来增强软件下载的体验呢？事实上，大部分Windows 8用户最常使用的仍是传统桌面、而非功能有限的Metro。

2. 更方便的软件更新形式

在Linux上，不仅仅可以下载Linux官方版本的软件，还可以通过软件存储库添加源，从软件开发商处直接接收最新的更新内容。也就是说，这是一个整体式、直接从软件商服务器获得更新的平台，不需要再单独运行某个应用的升级更新程序。

3. “总在最前”的功能

这听上去像是一个不起眼的小功能，但非常有助于增强操作体验。Linux对任何软件都添加了一个“总在最前”的功能，只要右键点击软件就会看到选项，能够方便地将当前应用显示在最前端。

4. Web应用集成

老 实说，大部分Windows用户仍倾向于使用传统的下载版桌面软件而不是Metro应用，但不能忽视的是Web应用也在逐渐流行，比如 Outlook.com或是网页版微博等等。Ubuntu意识到了这一点，可以将Web应用方便地放置于桌面、任务栏，可以显示通知内容，实现更轻型化的 体验。显然，微软对Web应用的支持落后了一些，其实完全可以抛弃“推广Metro应用”的固有想法，毕竟目前是一个体验为王的时代，强迫用户去使用一些 不好的服务，往往会适得其反。

5. 平铺式的窗口管理界面

Linux的平铺式窗口管理界面非常好用，能够方便地显示各个应用窗口的状态。这有点像是Windows 8全屏的Metro界面，只不过是应用在传统桌面上。如果Windows 9能够集成这个特性，那么将有助于提升传统桌面的操作效率。
