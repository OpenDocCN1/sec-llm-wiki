# TrueCrypt获得新生和新的名字

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200741785&idx=3&sn=1cf82c9664a47763269924113a92ec1b&chksm=28eb28df1f9ca1c9a862b1b0372575228c85d5e3cc61557ee75c957758cc43f2b5c72c2cae75&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200741785&idx=3&sn=1cf82c9664a47763269924113a92ec1b&chksm=28eb28df1f9ca1c9a862b1b0372575228c85d5e3cc61557ee75c957758cc43f2b5c72c2cae75&scene=27#wechat_redirect)

流行加密工具TrueCrypt背后的匿名开发者在今年早些时候突然宣布项目终止开发，并警告使用TrueCrypt不安全，软件可能包含未修正的安全问题。

TrueCrypt作者自己写的开源许可证对fork有很多限制，而TrueCrypt的一位开发者认为在参考TrueCrypt源代码的情况下重写并不需要太多工作。

现在，一群开发者宣布fork终止已经开发的TrueCrypt，创建CipherShed项目，将在标准的开源许可证下公开源代码。
