# 又一个意大利城市乌迪内市改用OpenOffice

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200719105&idx=2&sn=3e36dda82e43a12901df27eabfe45246&chksm=28ea80471f9d09516e40e8b924653896b20a2ffeb7c5bf638972ee3f4c9ae97c16701c87ecd8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200719105&idx=2&sn=3e36dda82e43a12901df27eabfe45246&chksm=28ea80471f9d09516e40e8b924653896b20a2ffeb7c5bf638972ee3f4c9ae97c16701c87ecd8&scene=27#wechat_redirect)

另一个人口只有10万的意大利城市乌迪内宣布将在今年年底切换到OpenOffice，以节省36万欧元的MS Office许可费，未来几年OpenOffice将成为该市默认的个人生产力工具。

旧电脑上安装的Microsoft Office将逐步淘汰用OpenOffice替代。市政府的一名顾问说，一些旧电脑还在使用微软早就停止支持的Office 2000，表示该市缺乏资源升级软件，而改用开源软件之后，工作人员将可以使用最新版的办公软件。
