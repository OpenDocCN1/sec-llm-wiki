# Qt公司正式成立

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200714202&idx=2&sn=5a8cb185e19a113b14a4169b9c057895&chksm=28ea9c9c1f9d158aa49bee62b23cc9e7352e33889b0377d8eb723b8e5e1715b5a10feb606d84&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200714202&idx=2&sn=5a8cb185e19a113b14a4169b9c057895&chksm=28ea9c9c1f9d158aa49bee62b23cc9e7352e33889b0377d8eb723b8e5e1715b5a10feb606d84&scene=27#wechat_redirect)

Digia公司正式宣布成立全资子公司The Qt Company，启用新的域名www.qt.io（中文站：http://www.qt.io/zh-hans/ ），统一开源和商业版本。

开源网站qt-project.org和商业版本网站qt.digia.com的内容将会逐渐合并到www.qt.io，www.qt.io/download下载页已统一了开源和商业版本的软件包。

Digia此前表示，彼此没有互动的开源和商业版本对Qt有弊无利，因为这就好象是自己人之间在互相竞争，而不是Qt与其它技术进行竞争。
