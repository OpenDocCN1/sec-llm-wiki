# 快讯：SUSE Linux再次换东家

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200711706&idx=3&sn=c8e437c6e84cf6b3a7af9e0481da6bac&chksm=28eaa55c1f9d2c4a9c028b70ab44d0841e51669179c1c2211f0c88cd15a43ac51bd768af6c27&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200711706&idx=3&sn=c8e437c6e84cf6b3a7af9e0481da6bac&chksm=28eaa55c1f9d2c4a9c028b70ab44d0841e51669179c1c2211f0c88cd15a43ac51bd768af6c27&scene=27#wechat_redirect)

SUSE Linux之前的母公司Attachmate集团被Micro Focus收购，这是SUSE的第3位东家。

第一次是2004年被Novell收购，之后Novell在2011年被私募公司Attachmate收购，这次Attachmate集团下包括SUSE，Novell，NetIQ和Attachmate四家公司一起总价12亿美刀的价格被Micro Focus收购，Micro Focus是一家主要为大公司提供软件和咨询服务的英国公司，主营业务跟老业务平台迁移和大型机软件平台有关。希望这次收购不会影响OpenSUSE社区。
