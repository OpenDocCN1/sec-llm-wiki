# 怎么在Linux发行版下列出所有安装了的包

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=200707233&idx=3&sn=ce8f8c4b58bb3073bc53e2a47f979ce9&chksm=28eab7e71f9d3ef1cf5c34782890b13ade5845b69c4df309307c092aab055e5e75d1382c8ce6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=200707233&idx=3&sn=ce8f8c4b58bb3073bc53e2a47f979ce9&chksm=28eab7e71f9d3ef1cf5c34782890b13ade5845b69c4df309307c092aab055e5e75d1382c8ce6&scene=27#wechat_redirect)

列出所有安装了的包的方法取决于你用什么发行版以及包管理器。

在这个教程里，我们将提供主流发行版的命令。

**注意**: 你可以用管道筛选或者用重定向符（>）来把结果重定向到一个文件。例子如下。

```
example | less
```

* * *

```
example > installed\_packages.txt
```

### Red Hat/Fedora Core/CentOS Linux:

```
rpm -qa
```

### Arch Linux:

```
pacman -Qq
```

### Ubuntu / Debian / Linux Mint:

```
dpkg --get-selections
```

* * *

```
dpkg --list
```

* * *

```
dpkg -l
```
