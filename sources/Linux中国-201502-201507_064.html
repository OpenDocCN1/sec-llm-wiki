Up Clock 的设计灵感来自于 Ubuntu Touch 锁屏时钟。

它允许用户选择10种不同的颜色，结合背景，更改显示的时间类型（12小时或24小时），调整透明度。

同时，还可以设置闹钟。

最新的版本 Up Clock 5.5，可以在 Ubuntu 15.10、Ubuntu 15.04、Ubuntu 14.04、Ubuntu 12.04 上安装，用户可通过 PPA 进行安装。

打开终端输入以下命令：

  1. sudo add-apt-repository ppa:apandada1/up-clock
  2. sudo apt-get update
  3. sudo apt-get install up-clock
