# Mandriva CEO称雇员诉讼迫使公司宣布破产

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=206423505&idx=3&sn=b520a9e0f3f6595151dc0f08800c4c5d&chksm=2f51fe9718267781d05919b06db99f358e63c559024872cc4ae6206a391e2b31ccb0d5a5bee9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=206423505&idx=3&sn=b520a9e0f3f6595151dc0f08800c4c5d&chksm=2f51fe9718267781d05919b06db99f358e63c559024872cc4ae6206a391e2b31ccb0d5a5bee9&scene=27#wechat_redirect)

法国Linux商业桌面发行版Mandriva正在破产清算，该公司CEO Jean-Manuel Croset接受采访时将公司的停业归罪于雇员的诉讼。Mandriva在2013年解雇了一些雇员，这些前雇员提起了诉讼并且赢得了官司。所以公司在2014年虽然收入大增，但却因为败诉只能宣布破产，法国 法庭命令该公司赔偿这些雇员数十万欧元。

Croset以机密为由没有披露诉讼的细节和雇员的名字。这或许只是Mandriva方面的一面之词，但众所周知 法国的法律确实更偏袒雇员而不是企业，企业家为此抱怨不已。
