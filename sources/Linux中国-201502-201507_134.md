# 渗透测试系统 Kali 推出 Docker 镜像

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=206351421&idx=2&sn=2fa2f7c011a8a37fd29484edbd6d56e1&chksm=2f50977b18271e6d8fe74f1c07c1757df956a5c832f72e7e62f90929431863cb61555c972272&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=206351421&idx=2&sn=2fa2f7c011a8a37fd29484edbd6d56e1&chksm=2f50977b18271e6d8fe74f1c07c1757df956a5c832f72e7e62f90929431863cb61555c972272&scene=27#wechat_redirect)

著名渗透测试团队Offensive Security推出Kali的官方Docker镜像。

一位用户表示非常期待得到Kali的Docker镜像，开发者Mati Aharoni回应说：“上周我们收到了一位资深渗透测试者的邮件，他希望官方能推出KaliLinuxDocker镜像，好方便在工作中使用”。

他继续说道，“Docker的好处在于，它能让Kali放置在一个漂亮的、干净的容器里，并且不会干扰你的guest文件系统”，“有了这个，你有完全的权限来访问所有运行了Docker的系统中的所有Kali包，这是相当长的一个名单。”因为， Docker镜像可以赋予系统管理员跨Windows、Mac和Linux服务器的简化管理能力。

Kali是渗透测试领域的明星，前身是BackTrack。这个Linux系统可不简单，它是预装了黑客攻击工具的专用安全平台。不过这里Kali的Docker镜像是最小化安装的系统，一些工具需要自己来逐个添加。

开发Kali的团队也非常厉害，exploit-db.com和Google Hacking Database都是他们在维护，他们还编写了《Metasploit: The Penetration Tester’s Guide》一书（国内译本：《Metasploit渗透测试指南》，译者：诸葛建伟）。
