# 外媒评论：原生安卓已死！

Android M精彩亮相，众多开发者在洛杉矶见证了大量新功能：应用权限控制、充电和续航优化、内存占用优化、App与网络无缝集成、移动支付、指纹识别、Google照片应用、离线地图……很激动人心是不是？

错了！

这些功能早晚都会在安卓手机上普及，但绝对不会是Google设想的方式。事实上，Google怎么规划的Android M根本无所谓，因为原生的Android M根本不会在流行的设备上出现，不管是三星Galaxy、HTC One，还是小米、华为。

Android M的关键改进最终仍然会进入这些手机，但绝对会比Google安排的2015年第三季度要晚得多。

是时候面对现实了：你见过几台智能手机跑着原生的Android？哪家手机是按照Google的思路去做的Android？

也许，只有Nexus系列。

![](../Images/b7099e5c4499e4d6b0dc3709cfe17d0e.png)

但是，Nexus 6实在是太大了，Nexus 5堪称梦幻手机却已经下架。

如果你很了解Android平台，或许会说，也有一些机器的系统几乎是原生的啊，比如说摩托罗拉Moto X 2014、索尼Xperia Z系列。没错，但问题是，它们毕竟不是真正原生的，尤其是缺少了一个最关键的地方：Nexus设备的流畅度。

进入2015年，硬件军备竞赛还在持续，八核处理器、4GB内存频频出现，但是卡顿仍然是哪怕安卓旗舰手机的老大难，比如优秀如Galaxy S6也会卡，Galaxy Note 4甚至更糟糕，绝大多数安卓手机都逃脱不了这个魔咒。

如果再从实际表现上对比一下2013年的Nexus 5，你会惊讶地感慨，为啥老设备反而更流畅、更快、更好？

![](../Images/756cd5bdb08ba15741fa381117de9a6e.png)

而且卡顿只是一个方面，还有更多麻烦。为了突出个性，第三方厂商都把Android界面改的“面目全非”：完全不同的图标、应用、动画、样式，甚至没有了应用抽屉。事实上，如果你是个很普通的用户，可能根本不知道自己的系统是安卓。

Cyanogen等优秀的第三方ROM一度是很忠于原生风格的，但时代在变，而变化的诱惑力太大，他们也都在纷纷地试图让用户忘了这是Google的安卓。

哦对了还有Android One，Google希望能在两年的时间里，按时为发展中市场的用户提供系统更新，但是，Android One并不是推广原生系统的最佳途径，毕竟它只是个廉价机，有自己的用户群，但终究为了成本和价格妥协太多，完全无法和旗舰机相比。

看起来我们不得不承认一个简单的事实：原生的安卓，Google话费无数心血、精心打磨的最完美的安卓，却是绝大多数人、绝大多数手机无缘享受的。

除非再诞生一个Nexus 5，否则原生安卓，或者安卓M，都只能是一个空中楼阁。必须要变一变了。
