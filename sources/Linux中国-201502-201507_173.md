# 我们开通了文章评论及打赏功能！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=205951339&idx=4&sn=c0bb2d69adc3e39faf02ad8b8361e209&chksm=2f5aaa2d182d233bb11f0d135f7842ff572684d41c9303a8b21ce5fab087bf370fe9110cc5a7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=205951339&idx=4&sn=c0bb2d69adc3e39faf02ad8b8361e209&chksm=2f5aaa2d182d233bb11f0d135f7842ff572684d41c9303a8b21ce5fab087bf370fe9110cc5a7&scene=27#wechat_redirect)

细心的粉丝可能注意到了，从前天开始，我们的微信公众号就赢来了一些新的功能：

*   **文章评论功能。**大家可以对文章进行针对性的评论了，这些评论经过审核后会显示给所有阅读者。在初期，我们会尽可能的将所有评论都展示给大家。不过稍嫌不足的是，这些评论不能彼此互动。
    
*   **文章打赏功能。**如果遇到您喜欢的文章，或者某篇文章确实帮您解决了问题，用评论来夸奖我们也许不足以表达您的心情，那么，您还可以打赏给我们。哈哈，不拘多少哦~
    

嗯，其实这些功能，只是锦上添花，我们希望能够通过坚持不懈的努力，为您提供更多的知识和技巧，也为开源做一些力所能及的事情。当然，这一切离不开大家的帮助，尤其是 LCTT 翻译组的诸位兄弟姐妹们的无私奉献！
