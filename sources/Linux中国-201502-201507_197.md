# 最后一个Windows，或让微软Windows业务重获新生

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=205719292&idx=2&sn=7c9d096f4971d5adca94e070e411baf6&chksm=2f5f3dba1828b4ac97eb178fbc028f0a91985df0c1dd1dab295551beecba2d5104e3ebec566e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=205719292&idx=2&sn=7c9d096f4971d5adca94e070e411baf6&chksm=2f5f3dba1828b4ac97eb178fbc028f0a91985df0c1dd1dab295551beecba2d5104e3ebec566e&scene=27#wechat_redirect)

今天看到微软宣布Windows 10将会是最后一个Windows，挺让我意外的。虽然早就猜到未来差不多会是这样，但多多少少有点令人诧异，因为没有预料到它会是在今年到来。微软CEO纳德拉的果断，以及微软公司的勇气让人佩服。 

这是一个必然的结果，时代不同了，就必须要换另外一种活法。就比如《教父》，第一代教父维多·柯里昂依靠帮助弱小者而赢得尊重，而第二代教父迈克尔·柯里昂在继承他父亲沉着、冷静、精明、坚强的性格基础上，又以冷酷无情而令家人寒心。这不能说迈克尔·柯里昂本性就是如此，而是时代不同了，他必须以这种做法来发展家族事业，否则柯里昂家族就会被其它家族吞并。

微软也是如此。在个人PC时代，人们为Windows而疯狂，在Windows 95发布之初，很多人连夜排队就是为了买个系统…微软在个人PC时代获得了巨大的成功，每隔一定周期更新系统，以光盘套装、企业授权形式攫取了大量利润。然而时过境迁，若是现在为买个系统再出现连夜排队，大家一定会质疑，这帮人是真疯了？还是时空穿越过来的？时代不同了，微软必然得换个活法。

但在换个“活法”上，不得不说微软CEO纳德拉的果断以及微软公司的勇气确实是值得佩服。毕竟，系统授权收入那一块还占着不小的收入份额；毕竟微软和谷歌、苹果还是不同——苹果主要靠硬件赚钱，谷歌主要靠搜索赚钱，就这么果断地放弃代代升级的赚钱方式，确实挺有勇气和明见的。

为何说他们明见？关闭一扇Window，或许就能打开一扇Door，往往越是免费的东西，人们的花费或许就越多。就比如网络游戏的免费，人均的花费远远超过卖点卡时代。人们之前开玩笑“微软也要学腾讯QQ会员做增值服务”，实际上取消授权转向服务收费的模式，不仅不会让微软在Windows业务上陷入困境，或许还会让它重获新生。

一方面是，进入移动互联网、云计算时代后，人们对更新手中的Windows设备缺乏兴趣，来自消费类设备许可收入实际上在不断滑坡，而放弃传统的卖光盘、卖授权方式，则能增加广告、搜索、游戏、服务和应用购买的潜在客户群，通过收割这些用户的“终身价值”让微软在新时代继续成长。

另一方面，云计算、物物相连的物联网时代，所谓“系统”的概念将逐渐消失，它仅仅是提供入口的作用，而通过云提供计算能力、提供服务则将成为主流。如果还按照上一个时代那样，人为的区分Windows XP、Windows Vista、Windows7，则是可能自寻死路。因为微软不仅将会受困诸如Windows XP或Windows 7一家独大带来的更新阻碍，还会让微软自己的服务和技术推广受到限制，从而让微软诸多梦想、概念处于“政令不出中南海”的局面。那个时候微软再让Windows再次成为核心的期待，将遥遥无期。

微软让Windows 10成为最后一个Windows，揭开了Windows业务的新篇章，带来了新的未来。
