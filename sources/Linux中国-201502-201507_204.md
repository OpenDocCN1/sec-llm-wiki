# 开源正在蚕食数据库市场

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=205649034&idx=3&sn=e98b5ecfb92d329b9634674bd0f2a4b7&chksm=2f5dcfcc182a46da7aae00d5a06f92d692513e5f8bc31bc81076f2b03f1880172a938000eaed&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=205649034&idx=3&sn=e98b5ecfb92d329b9634674bd0f2a4b7&chksm=2f5dcfcc182a46da7aae00d5a06f92d692513e5f8bc31bc81076f2b03f1880172a938000eaed&scene=27#wechat_redirect)

“关系型数据库市场一年的份额为90亿美元。我希望将它压缩到30亿美元，并占据三分之一的份额”，这是前MySQL首席执行官Marten Mickos曾经的豪言壮语。虽然在2008年被Sun Microsystems以10亿美元收购以前，MySQL的销售额大概只有1亿美元，并未达到Mickos的预期。但据InfoWorld报道，现在，他的预言似乎正在变成现实。

数据库市场规模巨大且增长迅猛。据IDC统计，整个数据库市场已经超过400亿美元，到2017年预计将达到500亿，如下图所示：

![](../Images/b279d1ba3f4ff0c27516533b3348ea3d.png)

从收入上看，大部分市场都由像Oracle和Microsoft SQL Server这样的专利数据库所占据。但是，Gartner最近发布的一份研究报告显示，开源数据库市场占有率占关系型数据库的25%。也就是说，开源数据库与专利数据库的市场占有情况并不像收入显示出的差别那么大。按照Gartner的说法，其潜在的影响是商业数据库产品增长率降低。实际上，事实正是如此。2014年，专利关系型数据库仅增长了5.4个百分点，而开源数据库市场增长了31%，达到了5.62亿美元。在一个超过400亿美元的市场中，25%的市场占有率却只有5.62亿美元的收入。因此，很容易想象，随着开源数据库市场份额的增加，整个数据库市场的收入会大幅降低。

下图是来自DB-Engines的数据库流行度统计：

![](../Images/c27deb0be7db9d61d0ffb3669c354836.png)

可以看出，除了个别情况外，开源数据库（包括关系型数据库和NoSQL数据库）流行度都有增长，而专利数据库流行度明显降低。以前，选择开源数据库往往意味着用健壮性和性能换取便利性。但现在，随着开源关系型数据库的成熟，它们已经被信息负责人、DBA和应用程序开发管理人员看作大多数新建企业应用的标准基础设施选项。另外，NoSQL市场也许会发生同样的变化，专利数据库市场会进一步被蚕食。
