# 谷歌推出高性能NoSQL数据库Cloud Bigtable

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=205637352&idx=2&sn=50ebd26d2b29ebab94a86c2dc35f1615&chksm=2f5dfdae182a74b855cc821e45e5094c28ffa9eb8668b813cb7008d140e7c151947a30297968&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=205637352&idx=2&sn=50ebd26d2b29ebab94a86c2dc35f1615&chksm=2f5dfdae182a74b855cc821e45e5094c28ffa9eb8668b813cb7008d140e7c151947a30297968&scene=27#wechat_redirect)

据科技博客TechCrunch报道，谷歌在周二推出了新款高性能NoSQL数据库Cloud Bigtable。

顾名思义，Cloud Bigtable基于谷歌Bigtable数据存储系统，但新增加了对分布式数据库Apache HBase应用程序接口的支持。Apache HBase本身基于谷歌的Bigtable项目，后者支撑着Gmail、谷歌搜索和Google Analytics分析服务。

谷歌承诺，Cloud Bigtable的延迟时间将限制在几毫秒(个位数)，每美元性能是HBase、Cassandra等类似数据库的两倍。由于Cloud Bigtable支持HBase的应用程序接口，所以它能够与分布式系统基础架构Hadoop生态系统中的现有应用相整合，但也支持谷歌的云数据分析工具Cloud Dataflow。

Cloud Bigtable目前还处于Beta测试阶段，面向所有开发者开放，但不提供服务品质协议(SLA)和技术支持。
