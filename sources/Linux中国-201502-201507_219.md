# OpenBSD 5.7发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=205451654&idx=1&sn=f3737d0bd7526bbada6b40346209427f&chksm=2f22cac0185543d6a700f518f2478a22a40ca3d63349a3f7408818fb08aca53032dd3d860d7a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=205451654&idx=1&sn=f3737d0bd7526bbada6b40346209427f&chksm=2f22cac0185543d6a700f518f2478a22a40ca3d63349a3f7408818fb08aca53032dd3d860d7a&scene=27#wechat_redirect)

OpenBSD 5.7于5月1日释出，发布主题曲是《Source Fish》。

主要新变化包括：

*   用自己开发的httpd server替代nginx httpd server
    
*   新的管理守护进程/服务的控制工具rcctl(8)
    
*   USB 3.0支持
    

软件方面的变化包括：

*   OpenSMTPD 5.4.4
    
*   OpenSSH 6.8
    
*   LibreSSL
    
*   mandoc 1.13.3
    
*   Chromium 40.0.2214.115
    
*   Mozilla Firefox 31.4.0esr 和35.0.1
    
*   Node.js 0.10.35
    
*   Emacs 21.4和24.4
    
*   GCC 4.8.4和4.9.2
    

详细变化可查看changelog。
