# Docker 的足迹正扩展到中国

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=205429120&idx=1&sn=64d5cbb6ebcbc9d8108e239f51333ca6&chksm=2f22a2c618552bd0f42c0b5ec2016f12d2b6e266e3168284da79a3aa1b4ca3a07f80cd7389e9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=205429120&idx=1&sn=64d5cbb6ebcbc9d8108e239f51333ca6&chksm=2f22a2c618552bd0f42c0b5ec2016f12d2b6e266e3168284da79a3aa1b4ca3a07f80cd7389e9&scene=27#wechat_redirect)

来自 Docker 官方的消息：我们很高兴地宣布, Docker 将扩大中国的新办事处并任命在中国的主管。该主管负责中国日常工作的运作并与美国管理层紧密合作扩展中国市场。我们正为服务于这个重要且快速成长中的中国社区角色积极物色适合的人选。

在过去的两年中，Docker 在技术上对满足中国市场成长步伐的需求做出了重要承诺。我们目前在中国有超过15个Docker聚集团体，随着Docker在该地区需求的迅猛发展，这个数字还在继续增长。我们还与多家公司合作，如百度，他们在搜索引擎中使用Docker，并参与了在该地区中的各种演讲活动。对Docker来说，中国是一个非常重要的市场，我们正在与社区合作，使Docker的应用更为广泛。

如果您想加入当地那些已在使用Docker的开发者或开发专业人士的行列，请在 Docker Hub 注册. 如果您对Docker Hub性能或者连接上有问题，请使用 DaoCloud 的代理, 这是我们社区中的一名使用者开发的。

我们已经察觉，另一家使用 Docker.cn 的组织。请注意，这个组织跟 Docker 没有过任何官方关系，也没有一起合作过任何项目。几个月来，我们一直在与 docker,cn 网站的业主沟通，试图让他们停止使用Docker的名字与商标，来避免用户混淆他们与Docker的关系。此事正由我们的法律团队处理。

很高兴有机会更好地支持您们的中国社区，提供您们需要在 Docker 上启动和运行的资源和工具。西安是我们即将在当地举行聚会之一，请来与我们一起传播和参与吧！ 请上微博，找到 Docker 和我们社区中的最新消息。
