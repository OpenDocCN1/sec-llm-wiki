# Linux 的 ‘sort’命令的14个有用的范例（一）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=205429120&idx=3&sn=8d9a3fc33a2e621f60db74f52bf8d36b&chksm=2f22a2c618552bd068146e2cbcb0456bb4807b0edde370b503dd0003ab92925ec05b8b129058&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=205429120&idx=3&sn=8d9a3fc33a2e621f60db74f52bf8d36b&chksm=2f22a2c618552bd068146e2cbcb0456bb4807b0edde370b503dd0003ab92925ec05b8b129058&scene=27#wechat_redirect)

Sort是用于对单个或多个文本文件内容进行排序的Linux程序。Sort命令以空格作为字段分隔符，将一行分割为多个关键字对文件进行排序。需要注意的是除非你将输出重定向到文件中，否则Sort命令并不对文件内容进行实际的排序(即文件内容没有修改)，只是将文件内容按有序输出。

本文的目标是通过14个实际的范例让你更深刻的理解如何在Linux中使用sort命令。

1、 首先我们将会创建一个用于执行‘sort’命令的文本文件（tecmint.txt）。工作路径是‘/home/$USER/Desktop/tecmint’。

下面命令中的‘-e’选项将启用‘\\’转义，将‘\\n’解析成换行

```
1.  `$ echo -e "computer\nmouse\nLAPTOP\ndata\nRedHat\nlaptop\ndebian\nlaptop" > tecmint.txt`
    
```

![](../Images/e890eadc05914e986ea1c03e5f006f58.png)

2、 在开始学习‘sort’命令前，我们先看看文件的内容及其显示方式。

```
1.  `$ cat tecmint.txt`
    
```

![](../Images/62ed66e1cb4ea4599c62a3bd76710816.png)

3、 现在，使用如下命令对文件内容进行排序。

```
1.  `$ sort tecmint.txt`
    
```

![](../Images/83b4198b1eb914fae5748a814b253e49.png)

**注意**：上面的命令并不对文件内容进行实际的排序，仅仅是将其内容按有序方式输出。
