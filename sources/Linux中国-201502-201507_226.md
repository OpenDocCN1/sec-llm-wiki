# 微软在Windows 10中引入包管理功能

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=205400402&idx=3&sn=b9b339d18931411cb51824f68effd211&chksm=2f22121418559b02253d87562a61ba44e9d93cc74d58eb52035dce4d2134748632f436fb852e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=205400402&idx=3&sn=b9b339d18931411cb51824f68effd211&chksm=2f22121418559b02253d87562a61ba44e9d93cc74d58eb52035dce4d2134748632f436fb852e&scene=27#wechat_redirect)

微软迈出了学习开源社区的重要一步：在Windows 10中引入了包管理功能PackageManagement自动化软件的发现和安装。

微软官方博客说，在Linux世界，用户熟悉的包管理器有Apt-Get、YUM和RPM。而Windows世界则存在大量的安装器技术，每一种都以它自己的方式去安装软件，如MSI、MSU、APPX等等。这对IT管理者构成了挑战，他们需要工具去自动化软件部署。

PackageManagement就是试图解决这个问题，它本质上是一个包管理聚合器。微软在Apache许可证下在GitHub上开源了被称为OneGet的包管理组件。但软件开发者在分析OneGet后认为，它仍然是一个愚蠢的下载器，不具有现代包管理器的功能。
