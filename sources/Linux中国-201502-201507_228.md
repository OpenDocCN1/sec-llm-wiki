# 无敌了，不需要操作系统就能运行 Python 了！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=205361839&idx=3&sn=28604d5286cc7e1104e3eacdfbe35eb1&chksm=2f21a9e9185620ffbe9be37645ded608e41470d6160f668de07d31159dc1097dd0ac4a46ccd3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=205361839&idx=3&sn=28604d5286cc7e1104e3eacdfbe35eb1&chksm=2f21a9e9185620ffbe9be37645ded608e41470d6160f668de07d31159dc1097dd0ac4a46ccd3&scene=27#wechat_redirect)

英特尔公司的内核黑客Josh Triplett正致力于让Python语言不需要操作系统就能运行，他和同事已设法让一个解释器在GRUB引导程序中运行。

让Python语言运行在引导程序中的动机是为了避免在测试硬件、BIOS、可扩展固件接口和ACPI时去写一次性的C代码程序。他在PyCon 2015上说，如果能不需要写任何C代码，他的生活将会更幸福。

他们的项目正式名称是BIOS Implementation Test Suite ，基于标准的 Python解释器，使用的是Python 2.7，以后可能考虑使用Python 3。
