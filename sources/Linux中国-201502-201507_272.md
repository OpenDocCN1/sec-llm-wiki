# NGINX 开源软件：走在历史的转折中

今天，我们宣布 NGINX Plus Release 6 (R6) 发布。这件事对我们的公司具有里程碑的意义，我想，此时此刻是回顾过去以及展望未来的好时机。

过去的12个月对于 NGINX 来说是忙碌的，我们作为一个项目，一个开发团队，一个公司，得到卓越的发展，使用我们软件的网站数量增长迅速。在10000个最繁忙的网站中，NGINX 是应用最广泛的 Web 前端工具。我们的用户以及贡献者都是世界上最有创造力的开发者——他们都来自于一些极具破坏力的新兴公司，如 Airbnb、Netflix、Uber。NIGNX 开源项目从100多次更新中吸取成长的养分，并且 NIGNX Plus 已经成长为一个高效的应用支付平台。

### **展望**

NIGNX 的未来会怎样？我们又会提供哪些应用支持？人们常说，历史会再现，但是不会循环往复，事物都会往好的方向发展。目前，我们看到面向服务概念架构的复苏，但 是，有个更现代、更简单、松散耦合的开发方式叫做微服务。我们经常在一个流动的、不稳定的、集装箱式的环境里构建应用，而对于托管服务和它们之间的通信交 流而言， NGINX 是一个稳定且可靠的基础。这些激发了我们很多的想法，并让我们思考未来 NGINX 的应用。

接下来的12个月，NGINX 开源项目会有一些新的功能。**NGINX 和 JavaScript**** 的故事一定会继续** —— 我们有 JavaScript 虚拟机的工作原型，它能为 NGINX 独特要求而实现高度优化，并且我们已经开始将它嵌入到 NGINIX 开源软件中。

我们的开发者社区是 NGINX 在开源世界取得成功的关键。我们知道，开发 NGINX 不容易，针对这种情况，**我们在接下来的几个月内会做出可插拔的模块 API**。我们的目标是让社区开发者创建和分发 NGINX 模块更加容易，通过给予用户更多的选择，去灵活地拓展 NGINX 开源核心。同时，我们还建立了开发者团队以支持社区的这种转变。

也许你已经阅读过我们**在 NGINX 开源项目中支持 HTTP/2 的计划**。我们知道这对于开发者来说是多么重要，并且我们会继续支持其他人在 NGINX 上做出创新，当然，HTTP/2 会建立在已有大量网站成功应用的 SPDY 之上。

### **NGINX Plus 的规则**

很多人都问到 NGINX Plus，它与 NGINX 开源项目又有哪些关系。NGINX 开源软件需要商业支持以拓展其软件功能，实现可持续发展，这就是我们开发 NGINX Plus 的原因。

两 个产品有很多重叠的部分，事实上，通过采用各种第三方开源软件模块，NGINX Plus 实现很多额外的功能，我们对此很满意。如果用户有维持自己用于综合应用交付的定制 NGINX 的专业技能、耐心和时间，那么 NGINX Plus 显然就不适合他们。然而，如果维护并支持一个应用交付平台不是你的核心竞争力，或者你希望你的技术资源直接应用于促进业务发展的领域，那么 NGINX Plus 以及相关服务就是你不二的选择。

感谢那些花钱购买 NGINX Plus 的人。你不但拥有了一个可以让价格与性能更加透明的应用交付平台，而且给远在莫斯科为 NGINX 开源软件和 NGINX Plus 保持高标准的工程团队给予了一份支持。

无 论你是商业用户，第三方开发者，NGINX 的支持者，或者只是一个 NGINX 开源软件的终端用户，我们都十分感谢您的支持。为了开发者、管理者和终端用户，我们一起将 Web 打造得更好。我们希望你能一直使用 NGINX ，作为回报，我们会持续提供强大的、轻量级的、高性能的软件将你的应用打造成伟大的产品。
