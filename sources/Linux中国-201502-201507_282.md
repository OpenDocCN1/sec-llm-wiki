# 喜欢Linux的青少年是什么样？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=204796105&idx=3&sn=27e09b43ac875b17bb0aee23e643e127&chksm=2f28cb8f185f429977baca80d29d03dea43c0b929a0e9e8ea08e18ab17e58e5785a2d090521f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=204796105&idx=3&sn=27e09b43ac875b17bb0aee23e643e127&chksm=2f28cb8f185f429977baca80d29d03dea43c0b929a0e9e8ea08e18ab17e58e5785a2d090521f&scene=27#wechat_redirect)

作者 Phil Shapiro 是一个教育家，过去的 26 年里，教授过幼儿园到研究生院的学生。目前在华盛顿的公共图书馆工作，帮助青少年和成人使用 Linux 系统。

当我在马里兰州 Takoma 公园的一家公共图书馆工作时，每周我都会和几百名青少年交流。我努力勾起他们的好奇心，引导他们思考并跟告诉他们一些有趣而且有用的网站。我尝试给他们指引方向来帮助他们实现某些创意或者追求事业成功，同时以便他们在世界上找到合适自己并且有意义的角色。

因此，几年前我很荣幸地获得了全市社区服务工作指导青年奖。

每周两次，每次三分钟，你只能选择正确的话来告诉你对面的年轻人，这真是一个有趣的挑战！作为一个校外教育工作者，我非常喜欢这种挑战。正所谓师傅领进门，修行在个人。我把思想的种子撒入他们的脑中，至于浇不浇水就要看他们了。

但是，有一天我发现我对一个即将8年级毕业的同学说：“当你上了高中，四处找找那些热爱Linux 的同学，你会发现他们是学校里最聪而且最有创意的学生。 ”

  

且慢，难道学校里边最聪明最有创意的学生真的是那些热爱 Linux 的同学吗？不过我友好的咨询建议有可能是错的。也许 Linux 爱好者在学校里并非都拔尖。我的判断是基于直觉，没有任何数据或者结论性事实支持。

不过，这里给出了我得出此结论的想法依据。正如持素食主义的青少年往往对世界上食物、生态和社会公正问题有更多的意识，同样的，热爱 Linux 的青少年也会对技术问题更敏感。他们更了解这个世界以及他们的角色，他们是一群喜欢逛 makerspaces 和 maker faires 的人。他们把世界改造成自己想要的样子，而不是委屈自己去适应世界。他们是真正的能工巧匠！他们有着不同思维方式，不安分，不拘泥于现状，能够给生活带来创造性革新。肆无忌惮的乐观和希望能够像传染病一样在他们之中蔓延！

几年之前，一个中学生过来找我，表示愿意帮我把电脑翻新成 Linux 系统并提供给家里没有电脑的同学使用。（我已经做这种类似工作一段时间了。）当我发现他已经知道了很多相关知识时，我问他：“是你的父母和亲戚向你介绍 Linux 的吗？”他回答：“不是，我在网上自学了很多开源的知识，这是我很感兴趣的东西。”

这个学生也积极参与了镇上其他的几个项目，而且是作为学生领袖。他已经选择成为对当地社区和国际社会上有积极作用的人。我相信能培养出一个出色的年轻人，他的父母功不可没，同样的，我也相信这个青年，因为他会大胆地设想并选择未来要走的路！

他是一个典型的爱好 Linux 的青少年吗？我给不了你答案，或许他就是。这有可能会成为某个博士的论文研究主题。但如果你要问我的直觉，那他就是一个典型的爱好 Linux 的青少年！
