# Ubuntu Touch 已经有超过 1200 款应用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=204673493&idx=2&sn=8488819ed06565b6a47bffdaa5ceeeaa&chksm=2f2f2a931858a385a91b43fa3ce1afa23a260df9472f4fb92cef0d177fc8b333de404a329488&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=204673493&idx=2&sn=8488819ed06565b6a47bffdaa5ceeeaa&chksm=2f2f2a931858a385a91b43fa3ce1afa23a260df9472f4fb92cef0d177fc8b333de404a329488&scene=27#wechat_redirect)

第一款 Ubuntu 手机 BQ aquaris E4.5 Ubuntu 已经发布，魅族也在MWC大会上展出了 MX4 的 Ubuntu 版手机，另外官方还有支持 LG Nexus 4 设备固件，还有一些非官方 Ubuntu touch 已经运行在 OnePlus One 和LG Optimus G 上。

尽管 Ubuntu touch 还是一个年轻的平台，现在已经有超过 1200 款应用程序已经可以在 Ubuntu touch 操作系统运行，包括一些重要的、常用的应用程序，如 Telegram，切绳子，TOX或GCompris。当然中国用户更加渴望国内的软件能够运行在 Ubuntu touch 上。

![](../Images/7fb4edf4fd7a3a3ba783b4a25f47cc9d.png)

1200不是一个大数目，但情况并不坏。在 Android 发布时，只有很少的本地应用程序，现在它已经是拥有最多应用程序的手机系统。

目前，Ubuntu touch 并没有一个官方的应用商店，但有一个非官方的应用商店允许你查看所有可用的应用程序。
