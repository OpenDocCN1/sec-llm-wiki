# 了解不一样的鸟哥

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=204420219&idx=3&sn=ae7ac604cb76189f4691dd3a19289028&chksm=2f330f3d1844862b85bcd5d07d7a6372a4bcd0b82fbd38cfffd012440d68c7519b1ee728a95a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=204420219&idx=3&sn=ae7ac604cb76189f4691dd3a19289028&chksm=2f330f3d1844862b85bcd5d07d7a6372a4bcd0b82fbd38cfffd012440d68c7519b1ee728a95a&scene=27#wechat_redirect)

我想大家知道鸟哥，都是通过《鸟哥的Linux私房菜》开始的，但大多数读者只了解鸟哥的这本书，其实对鸟哥的生活圈、技术圈了解得还不是很多。所以为了让大家更多的了解鸟哥，就从三个主题：书，技术、生活这三方面，对您做专访。我很高兴、也很荣幸能够代表人民邮电出版社做这样一个采访。

因为人民邮电出版社是做出版的，所以我们的采访就从书开始吧！

**小编：**您的书在人民邮电出版社出版，从上市到现在，已有４年，仅第三版销量达到２０万册，在我们分社的销售中排名前三甲，无论在出版圈还是在技术圈，都有很大的影响力。在大陆，成千上万的Linux的入门者都是学您的书长大的，然后进入Linux这个行当。我们很想知道鸟哥的Linux私房菜最强的优势在哪里，为什么可以四年销售20万册，依旧屹立不倒？

**鸟哥：**我的背景已经写在书里了，我的背景并不是资讯类的，是环境工程。当时接触Linux之前，我是连UNIX是什么都不知道。其实我是真的从什么都不懂，去学习它。这个情况就会导致我看很多文章的时候看不懂。举例来说，曾经看过一个朋友写，他说，如果你要完成NAT这个技术的话，要怎么做。我那个时候就想，什么是NAT，我完全不懂什么是NAT。所以在学习的过程当中遇到了很多的挫。

因为这套系统真的很有趣，所以应该不是只有我有兴趣。既然我遇到了这个问题，想必很多资讯方面的朋友也会遇到相同的问题。所以我在撰写这个文件的时候，就会把遇到这些问题时心里面的想法和压力转成比较有趣的语言来撰写它。因为自己也遇到一些挫折，所以会比较清楚入门者可能会发生的问题在哪些点，所以就会把这些点扩大、放大，来做一些说明。我猜会看我的书的大概都是初学者，曾经有很多专家都跑来跟我开玩笑说，你为什么书里面废话这么多。

很多专家也会给一些建议，我们会把专家的建议加入进来修改一下，让大家听得懂。我相信把大家的心声写出来是私房菜比较大的优势。

**小编：**您在写《鸟哥Ｌinux私房菜》之前会记笔记吗？

**鸟哥：**会。记笔记是一个很重要的过程和步骤。但是我发现一件事情，就是在记笔记的时候，通常是写keyword，因为来不及，就会写关键词，这个关键词写下的当下会懂，但是过一两个月之后，自己可能会看不懂当时在写什么，要很用力的回想。我自己的学习是这样，如果我的笔记是在当时上课或者研究的过程中写下来的东西，如果没有事后做整理的话，未来我自己会看不懂，我过去的经验是这样。所以我在写这些文件的时候，希望我自己以后看的时候能看得懂，所以这些文件会写得比较多一点，甚至当时在练习过程里面的一些想法，跟练习到哪些错误的步骤，这些错误可能是大家会发生的，这些地方会特别拿出来讲一讲。所以我确实是有做笔记的习惯。我们现在也在玩一些DHP或者是其他一些类似的语言，这些东西我们有流程图，或者有那些概念，我不是一个很聪明的人，我脑海里面不会有那些流程图出现，我就把它具体化画在笔记上，这个时候要去统计分析的话，对我自己来说会变得比较容易。

**小编：**希望学习Linux 的同学们看到这个访谈以后可以学习一下如何记笔记。

**小编：**您的网站在2013年以后就没有再更新过，《鸟哥的Linux私房菜》目前为止写到第三版，一直也没有做更新，这是广大读者比较关注的问题，也是人民邮电出版社比较关注的问题。您什么时候会开始更新网站？出第四版新书，讲解新版本的Linux。

**鸟哥：**其实有预感要改版是2013年就开始动手了，从开始改版大概是2014年初，但是写了第一章的一半以后，就因为一些琐事、工作上的事情，把这个工作延后了。我现在在教学上本身也遇到问题，我现在教学用的是最新版的centos第七版，书上是第五版，两个差了两个世代。所以在某些基础方面的知识和技能是一样的，但是在比较不同的管理的tool的差异非常大。大概预期会在今年暑假，希望八九月的时候可以把基础做好，看年底有没有机会把伺服器做一些调整，目前计划是这样。但是计划赶不上变化，所以跟大家说声抱歉。

**小编：**我们不管是出版方还是读者，都在2015年等待您的好消息，大家对你的期望值很大。

**小编：**现在大陆的很多书，包括鸟哥私房菜这本书，很多都出成电子书，可以方便携带，现在咱们出的书都很厚，为了便于携带，现在的有些技术书分成了精粹版和原版，精粹版是把精华出成小册子，原版是厚书，您可不可以也有一个精粹版的东西出来？

**鸟哥：**这个其实在第二版推出的时候我就在想，尤其是第三版，因为我们去大学演讲的时候，老师说，我是用你的书来上课，但是怎么讲都讲不完，因为资料真的太多了，里面又有一些跟认证方面无关的。我确实也在想，要把它分成部分来想，一个是自学书，另外一本是教学用书，把它分开。教材用书的话，可能会比较偏向设计成一个让学生填写答案的过程，只有老师才会知道答案，所以那本书里面是没有答案的，我是希望设计这样的一个训练本教材书。

**小编：**页数大概会有多少？

**鸟哥：**我希望至少能减少一半。

**小编：**我是希望有答案的，最好能有一个练习答案备用，万一学生真的是很需要答案的话。

**鸟哥：**其实是刺激学生拿到这本书的时候，他要自己去翻答案，最好是直接在上面可以写出答案，然后再去比较正确的答案。但是我不希望答案在上面直接找得到，所以我们可能会做成类似slide，让老师们上课的时候、教学的时候，可以搭配这样的课程。我认为，至少在教育界这样可能会有一些帮助，目前的想法是这样的。

**小编：Windows 10和Linux各自的优势在哪？将来普通用户会普及Linux系统吗？**

**鸟哥：**这个分很多层面，因为我也接触到一些小朋友，他们在做平常操作的时候，你问他：“你为什么不学其他的操作系统？”他的回答很简单：“我的桌机拿来，目的就是看A片，在这个情况下，很多的片子是for Windows only。”这样的情况下它的推广就不是那么容易，有兴趣的用户就会去使用它。只是我们不要太强调Linux永远是最好的，这倒不见得。这是见仁见智的问题，你有需要就去用它，没有需要的话，挑选其他的也没有什么不好。现在是自由开放，不要排斥其他的。各行各业或者是各种系统都有它实际存在的价值。

**小编：****您对未来Linux的前景怎么看？现在学Linux系统的人很多，你有没有什么经验分享给广大的学习者？**

**鸟哥：**在一般的家用桌机市场，Linux大家已经在用了，你如果到Android的官方网站去看，它会告诉你底层是Linux，其实大家已经在使用了。我过去在学Linux的时候，因为是有压力在身上的，我认为没有压力，人就会没有动力，因为地球的生物就是这样，只要没有压力，或者是没有动力，他自然就会被淘汰掉。我当初接触到Linux的时候也是很巧，就是因为学业上的计划压力，我就必须要把它学会，不然的话我交不了差，那时候就学会它。后来因缘际会之后，被邀请到去做一个Linux国际认证授课的讲师，其实人在学习的时候很有趣，人在学习的时候通常跟学习自己有兴趣的，自己没有兴趣的就会放在一边。但是当你是一个老师的时候，你就会发现，其实所有的东西你要广泛的教给大家，所以你要学的东西就变得很多。

**在这里我会建议大家几点：**

第一，有机会自己的话，自己要找一个project，训练自己把它完成；

第二，做人要鸡婆一点，我们的鸡婆是指，比如你有问题不能解，你过来求我帮助，如果你不会，你不想求我，我会觉得很有压力，你过来求我让我教你好不好，我教你的时候，为了把他教懂，就必须要用他的语言，或者要用更多的解释去解释不同的点，无形之中自己就会获得更多的收获。我一直是有这样的习惯，举个例子，以前在没有这么忙的时候，有读者写E-mail给我，说我遇到一个问题不会解怎么办，我跟他讲半天，他听不懂，我甚至说，你给我地址，我去帮你解决，解决之后我再告诉你问题在哪里，我曾经做过这样的事情。所以做人积极，主动去协助别人，这个时候对自己的成长也相当大的帮助。有压力其实是最重要的。

**小编：**有好多人刚开始很有兴趣去学Linux，但是中途他遇到重重的阻碍，可能就放弃了。现在学Linux的人很多，或者他学得不是很好，不是很通，他也有可能放弃。所以坚持下来的这些人，每次遇到问题都能自己解决掉，能坚持下去。

**鸟哥：**对。

**小编：****之前鸟哥是学习环境工程的，为什么当时你没有选择去做环境工程的职业，而走向了Linux的道路？**

**鸟哥：**我的指导教授曾经跟我说过，说他们在年轻的时候没有写透，我们那时候科技用的语言是用Fortran，他说没有学Fortran是很奇怪的事情，我一直没有搞懂他的意思。一直到博士班的时候要去做模拟，那个时候你再模试的时候，就要有很多code，这个code本身是在Linux上面，在Linux机器上跑的性能比在其他的上面好。我因为接触到一些计划，就会有这样的工作在，所以后来就接触到Linux这一块。它真的很有趣，Linux最早不是作为桌机，是做server和科学运算，但是要做科学运算的时候，我们主要是做平行运算，平均运算它会用到很多服务器，这个服务器会引导后面更多的网络方面的服务器，这个有很吸引人。在2000年左右，我们联系通常用E-mail，但是E-mail那时候的免费空间只有5M到10M的容量，很小，现在都是好几个G。如果我们有自己一台服务器的话，你要传多大的量，就可以自己去执行它。所以Linux对我们那个时候来说，它是一个很重要的角色，这样就开始迷上它，后来才一直转换跑道，学习Linux和它的操作应用方面。

**小编：****您2013年入伍，有过服役的过程，之前有没有让您很难忘的事情？**

**鸟哥：**台湾的正常男生是必须要服役的，我们那个年代服役要两年。去服役的过程，因为后来是抽到海岸寻访署，所以我们是在海边，去协助渔民，他们要出关或者是要直接进到港口的时候，我们要上船去检查一下，他们有没有其他夹带的非法物品。因为是24小时，渔民会不定时的出海，所以我们就必须要三个班去轮班。轮到凌晨那个班的时候是很可怕。

一个班大概4小时，所以我们是6个梯次在轮，但是一天至少要轮2班。轮到凌晨那班会比较可怕，因为凌晨的露水非常重，渔场要防止海水侵袭，所以上面会抹很多油漆，但是油漆是很滑的东西，我们在跳到船上去的时候就可能整个人跌下去。我曾经跳到渔船上去的时候，一个脚滑到，撞到腰，很痛苦。我们曾经也有其他的阿兵哥就直接摔到海里面去，风险高，所以我们是要求一定要穿救生衣，因为我也不会游泳，所以我会比他们还紧张。

**小编：**你们不会游泳，还要去查渔民。

**鸟哥：**对。所以那个印象非常深刻。

**小编：**肯定下次再也不想去做这件事了。

**鸟哥：**当然。

**小编：****最后一个问题，我们说一点轻松的。我们知道您有两个可爱的女儿，您一天工作也很忙，您是如何利用业余时间或者挤出来一些时间，去照顾您可爱女儿的？**

**鸟哥：**我是对自己要求一个礼拜至少有一天的家庭日可以陪小孩，家庭日有可能是礼拜六或礼拜天，要看学校的其他或者是我自己工作上面的安排。我至少强迫自己，即使没什么事，即使今天没有什么计划，也要陪着他们，看卡通，或者陪他们玩，玩积木，或者陪他们到公园去走走、逛逛。

**小编：**现在有些家长就做不到这样，忙的时候就会忘了，有的时候可能一个月才陪小孩玩一次。

**鸟哥：**我的小朋友年纪一个是3岁，一个10岁，也是很小，我曾经自己一个大男人带四个小朋友到公园去，吓死我了，我再也不干了。因为四个小朋友，有两个大的，他们会照顾自己，两个小的，一个3岁，一个4岁，追都追不回来，不过非常有趣，跟他们的关系就会比较亲密。

**小编：**今天因为时间关系，我们今天就采访到这里，非常感谢您一直以来对人民邮电出版社的支持与配合，希望多来大陆，我们人民邮电出版社会非常欢迎您，希望您更多的来大陆参加一些公益性的技术会议，带给大家更多的知识。谢谢！

**鸟哥简介**

鸟哥，台湾知名Linux网站站长台湾成功大学环境工程系博士，就学期间由于研究需要接触到Linux操作系统，又因实验室交接需求而建立“鸟哥的Linux私房菜”网站。因个人喜好“絮叨”，网站文章风格就此成形。曾任台湾多家知名Linux教育中心讲师，目前于昆山科技大学资讯传播系教授Linux相关课程。专长是Linux操作系统、网站规划与维护、网络安全，兴趣是写作与阅读，研究方向是网络应用整合。

其著作《鸟哥的Linux私房菜 （基础学习篇 第三版）》是两岸三地最畅销的经典Linux入门书，单册销量超过20万。
