很多时候，通过互联网发送或接收大文件和图片是一件令人头疼的事。压缩及解压缩工具正好可以应对这个问题。下面让我们快速浏览一些可以使得我们的工作更加轻松的开源工具。

### Tar

![](../Images/d679eb338a09d06222d9acd705b7bb8d.png)

Tar 由 'Tape archiver（磁带归档器）' 衍生而来，最初被用来在磁带上归档和存储文件。Tar 是一个 GNU 软件，它可以压缩一组文件（归档），或提取它们以及对已有的归档文件进行相关操作。在存储、备份以及传输文件方面，它是很有用的。在创建归档文件时，Tar 可以保持原有文件和目录结构不变。通过 Tar 归档的文件的后缀名为 ‘.tar’。

**基本用法如下：**

#### a) 创建归档 (c / --create)

```
1.  `tar --create --verbose --file=archive.tar file1 file2 file3`
    
```

或

```
1.  `tar cvf archive.tar file1 file2 file3`
    
```

![](../Images/67007844bfd32a8c07c3d51b6bd7c738.png)

创建一个归档

#### b) 列出归档文件内容 ( t / --list)

```
1.  `tar --list archive.tar`
    
```

![](../Images/e7d020a16d22d929e7c3d6ec883a849f.png)

列出归档中包含的文件

#### c) 提取归档 (x / --extract)

```
1.  `tar xvf archive.tar`
    
2.  
    
3.  `tar xvf archive.tar --wildcards '*.c'   -  从归档中提取后缀名为 *.c 的文件。`
    
```

![](../Images/3ddc4dd144db436ed13c185429da1677.png)

提取文件

![](../Images/740956b309cae25779707ee1756e6fc3.png)

只提取需要的文件

#### d) 对归档文件进行更新 ( u / --update)

```
1.  `tar uvf archive.tar newfile.c    -  假如归档的newfile.c  要比先前已经归档的新，则添加更新的 newfile.c 到归档里面.`
    
```

![](../Images/a0ef322c359dd93fc8f493a7c3e0b3a3.png)

更新一个归档

#### e) 从归档中删除文件 (--delete)

```
1.  `tar --delete -f archive.tar file1.c   `
    
2.  `- 从压缩包'archive.tar' 中删除文件'file1.c' `
    
```

![](../Images/c44b85364aadcfe4f91c59a20622c783.png)

删除文件

更加具体的使用方法请参考tar 主页。

### Gzip / Gunzip

![](../Images/903fd5ce6c1979aba439e1a019136eec.png)

Gzip 即 GNU zip，它是一个被广泛用于 Linux 操作系统中的压缩应用，被其压缩的文件的后缀名为'\*.gz' 。

**基本用法如下：**

#### a) 压缩文件

```
1.  `gzip file(s)`
    
```

每个文件将被**单独压缩**。

![](../Images/f7a13bff442e17fa38959fcc823e3353.png)

压缩文件

通常在压缩完成后，它会将原来的文件删除。我们可以使用 `-c` 选项来保留原来的文件。

```
1.  `gzip -c file > file.gz`
    
```

![](../Images/d88e33a94f04590e3c25aff780db357e.png)

压缩后保留原有文件

我们也可以将一组文件压缩到一个单独的文件中

```
1.  `cat file1 file2 file3 | gzip > archieve.gz`
    
```

![](../Images/242989e609e0764e0462daf0d31a5614.png)

压缩一组文件

#### b) 检查压缩比

被压缩文件的压缩比可以使用 ‘-l’ 选项来进行检验。

```
1.  `gzip -l archieve.gz`
    
```

![](../Images/9d8332d3d6ba876676b3dffb4269f7dd.png)

检查压缩率

#### c) 解压文件

Gunzip 用来解压文件，在这里，原有的（压缩）文件在被解压后同样会被删除。使用 `-c`选项来保留原始文件。

```
1.  `gunzip -c archieve.gz`
    
```

![](../Images/45a1ad307c11cbd60b82feb60e150697.png)

解压文件

gzip 加上'-d'选项 和 gunzip 对压缩文件有同样的效果。

更多细节可以从 gzip 主页 得到。
