Linux From Scratch 简介

用过了太多的发行版却仍旧没有找到你心中 Linux 该有的样子，或是不满足于简单的日常使用想要更进一步的了解 Linux，那么从零开始（From Scratch）动手构建你的 Linux 吧！

Linux From Scratch（简称 LFS）项目的核心是一份文档《Linux From Scratch》它提供了让你设计和编制你自己的系统的必要背景知识和指令，帮你一步一步地创建定制自己的 Linux 系统。不过，虽然本书提供了一个模板，能产生正确工作的系统，你完全可以改变指令来适合你自己。在解决了循环依赖关系和编译时错误等问题之后，我终于编制出一个定制的 Linux 系统。它的可操控性和可用性像当时存在的其他 Linux 系统一样完美。但是它是我自己的创造。自己组装起这样一个系统是非常有成就感的，仅次于自己创造每个软件。像这样定制的 Linux 系统并非只满足了用户的特定需求，也是程序员和系统管理员强化他们已有的 Linux 技能的理想学习机会。这个工程存在的一个重要目的就是帮你由内而外学习 Linux 系统是如何工作的。编制一套 LFS 系统会帮助你了解什么使 Linux 工作，这些东西又是如何协同工作并相互依赖的。

为了保持LFS的基本性和专注性，另一本书《Beyond Linux From Scratch》（BLFS）提供了在LFS的基础上，进一步完善Linux基本系统的指引。在BLFS中，读者可以学习到如何为系统增加网络、X桌面、声音、打印机和扫描仪支持。从5.0版开始，BLFS开始与LFS的版本号保持同步。

除了LFS和BLFS，还有描述交叉编译的《Cross Linux from Scratch》（CLFS）以及专注于安全的《Hardened Linux From Scratch》（HLFS）。
