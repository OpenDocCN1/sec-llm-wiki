### 删除一个大文件

我在生产服务器上有一个很大的200GB的日志文件需要删除。我的rm和ls命令已经崩溃，我担心这是由于巨大的磁盘IO造成的，要删除这个大文件，输入：

```
1.  `> /path/to/file.log`
    
2.  `# 或使用如下格式`
    
3.  `: > /path/to/file.log`
    
4.  
    
5.  `# 然后删除它 `
    
6.  `rm /path/to/file.log`
    
```

### 如何记录终端输出？

试试使用script命令行工具来为你的终端输出创建输出记录。

```
1.  `script my.terminal.sessio`
    
```

输入命令：

```
1.  `ls`
    
2.  `date`
    
3.  `sudo service foo stop`
    
```

要退出（结束script会话），输入 exit 或者 logout 或者按下 control-D。

```
1.  `exit`
    
```

要浏览输入：

```
1.  `more my.terminal.session`
    
2.  `less my.terminal.session`
    
3.  `cat my.terminal.session`
    
```

### 还原被删除的 /tmp 文件夹

我在文章Linux和Unix shell，我犯了一些错误。我意外地删除了/tmp文件夹。要还原它，我需要这么做：

```
1.  `mkdir /tmp`
    
2.  `chmod 1777 /tmp`
    
3.  `chown root:root /tmp`
    
4.  `ls -ld /tmp`
    
```

### 锁定一个文件夹

为了我的数据隐私，我想要锁定我文件服务器下的/downloads文件夹。因此我运行了：

```
1.  `chmod 0000 /downloads`
    
```

root用户仍旧可以访问，而ls和cd命令则不工作。要还原它用：

```
1.  `chmod 0755 /downloads`
    
```

### 在vim中用密码保护文件

害怕root用户或者其他人偷窥你的个人文件么？尝试在vim中用密码保护，输入：

```
1.  `vim +X filename`
    
```

或者，在退出vim之前使用:X 命令来加密你的文件，vim会提示你输入一个密码。

### 清除屏幕上的乱码

只要输入：

```
1.  `reset`
    
```

### 易读格式

传递\-h或者\-H（和其他选项）选项给GNU或者BSD工具来获取像ls、df、du等命令以易读的格式输出：

```
1.  `ls -lh`
    
2.  `# 以易读的格式 (比如： 1K 234M 2G)`
    
3.  `df -h`
    
4.  `df -k`
    
5.  `# 以字节、KB、MB 或 GB 输出： `
    
6.  `free -b`
    
7.  `free -k`
    
8.  `free -m`
    
9.  `free -g`
    
10.  `# 以易读的格式输出 (比如 1K 234M 2G)`
     
11.  `du -h`
     
12.  `# 以易读的格式显示文件系统权限`
     
13.  `stat -c %A /boot`
     
14.  `# 比较易读的数字`
     
15.  `sort -h -a file`
     
16.  `# 在Linux上以易读的形式显示cpu信息`
     
17.  `lscpu`
     
18.  `lscpu -e`
     
19.  `lscpu -e=cpu,node`
     
20.  `# 以易读的形式显示每个文件的大小`
     
21.  `tree -h`
     
22.  `tree -h /boot`
     
```
