# 红帽企业版更新：Red Hat发布RHEL 7.1

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=203859516&idx=2&sn=86e7e3aa70420c789e079b64ef75aeba&chksm=2f3a9d7a184d146c2393605370054bf578f5657d5354a17098223176d7e5c397fa514fe279f8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=203859516&idx=2&sn=86e7e3aa70420c789e079b64ef75aeba&chksm=2f3a9d7a184d146c2393605370054bf578f5657d5354a17098223176d7e5c397fa514fe279f8&scene=27#wechat_redirect)

在专注于Linux的企业中，Red Hat可以说是最成功的一家了。而其企业级的Linux发行版——Red Hat Enterprise Linux(简称RHEL)——在业内也有着相当高的口碑。今天，该公司发布了该发行版的最新版本(RHEL 7.1)，其中包含了改进的开发和部署工具，增强的互操作性和客观理性，并且带来了额外的安全和性能。

Red Hat高级副总裁Jim Totton解释到：RHEL 7.1是全球领先的企业级Linux平台，拥有灵活、安全、可靠、以及高性能等特点，支持Container Adoption、快速应用软件开发、对时间敏感的交易应用、甚至基于IBM Power系统架构的系统。

对于RHEL 7.1来说，其最大的变化就是Thunderbird电子邮件客户端。此外，新版还将OpenJDK的版本从7升级到了8，办公套件LibreOffice也没有被落下。
