# Wharf：专注 ContainerOps 的开源产品

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=203741523&idx=1&sn=7eb579fbf26e3aedaae79a9979b06385&chksm=2f38e215184f6b035b1a715f8e1b7f773f2a9591e709d1ef9346c9a55be6e123771e69a600c9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=203741523&idx=1&sn=7eb579fbf26e3aedaae79a9979b06385&chksm=2f38e215184f6b035b1a715f8e1b7f773f2a9591e709d1ef9346c9a55be6e123771e69a600c9&scene=27#wechat_redirect)

Wharf 是一个专注 ContainerOps 的开源产品，它不是要取代 DevOps 而是使用 Application Container 技术在开发、持续集成和部署之间建立一种新的管道。 使用 Application Container 比传统的 DevOps 更简单和容易，生产环境下的应用也因为 Application Container 的引入而产生了版本管理，使得从开发的版本管理到运维的版本管理行程了统一。

Docker 是目前最流行的 Application Container 解决方案，Wharf 目前支持 Docker Registry API V1， 通过 Organization 和 Team 管理企业内部的公有和私有的 Repository 。团队正在开发对于 Rocket 的 CAS (Content Addressable Storage) 的支持， 同时提供 Docker 和 Rocket 之间的转换。

Wharf 同时提供了 containerops.me 的 SSL 证书，在部署的时候通过修改 Hosts 文件既可通过 containerops.me 域名访问 Wharf 的服务。

团队会在后续的版本支持 Docker Registry V2 和同步 Docker Hub 镜像等功能。 同时在开发基于 Application Container 的持续集成服务器 Vessel ，可以在 develop 的分支下看到项目最新的进展： https://github.com/dockercn/vessel/tree/develop 。
