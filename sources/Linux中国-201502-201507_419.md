# 腾讯TOS系统开启内测：界面扁平化风格

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=203741523&idx=2&sn=bbcb576c1a570b219d874d4d69654f68&chksm=2f38e215184f6b03f598bb6901c5541bc0ce6b00990f66213b653230ba17a10a1951ec5e2c05&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=203741523&idx=2&sn=bbcb576c1a570b219d874d4d69654f68&chksm=2f38e215184f6b03f598bb6901c5541bc0ce6b00990f66213b653230ba17a10a1951ec5e2c05&scene=27#wechat_redirect)

2015年1月15日，腾讯ROM Tencent OS（以下简称“TOS”）曾启动内测招募活动，最终从6万报名者中选出200名内测体验官。而即日起，腾讯TOS正式启动内测活动，腾讯数码也在第一时间拿到TOS的内测体验包。界面风格上来看，腾讯TOS系统以简约为主基调，采用的是目前主流的扁平化设计风格，默认的壁纸以及部分系统应用图标与产品LOGO的主色调保持一致。

![](../Images/a7e8e8803e81f066975bf06b719daadf.png)

预装应用方面，目前腾讯TOS内测版仅有天气、文件管理、浏览器等系统层级应用嵌入，相对纯净的系统设计思路也让用户拥有更自主的选择权。

![](../Images/71d0d05d575939e9fe970fd0891ee86e.png)

从简单的测试体验来看，作为一款内测产品，腾讯TOS还有较多功能和设计有待挖掘与体验。

![](../Images/4b1b6f76e8f6a09d81947da478bf62eb.png)

就在昨天，腾讯TOS团队正式通过其公众账号亮相于众。TOS隶属于腾讯移动互联网事业群，该团队自2014年下半年开始组建，目前团队规模已经突破百人，其成员多数来自外部收购以及内部竞聘。

![](../Images/68f135129b28376823fddb04bea9c346.png)

至于腾讯重新推出定制系统则是为了弥补腾讯互联网生态链上的缺失，想要通过移动ROM抢占移动互联网入口。据了解，未来更多的智能平台产品会使用TOS系统，并不仅限于智能手机。目前TOS系统仍处于打磨阶段，未来会面向消费级市场，现在团队与硬件厂商的合作形式仍在探讨中。

此前腾讯曾经推出过自主系统Tita，而此次TOS系统并非Tita项目的再次启动，而是重新构建的新产品，在交互体验方面得以增强。
