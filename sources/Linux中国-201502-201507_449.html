爱过！果然是微软和Linux

Linux：我能最后问你一个问题吗？

微软：爱过！

放在鲍尔默掌权微软的时代，这还真难以想象。那个时候，Linux 就是鲍尔默口里的“癌症”。

不过，现在一切都在改变。去年 10 月，在旧金山的一个活动上，微软 CEO Satya Nadella 先开了口：微软爱 Linux（原话：Microsoft loves Linux ）。近几年，不仅给 Linux 贡献代码，还在微软公有云服务 Azure 上支持 Linux。据ZDNET消息，开发出最好用 Linux 版本 Ubuntu 的公司Canonical宣布，与微软、亚马逊就物联网平台达成合作，两家公司将向 Canonical 旗下物联网设备平台 Ubuntu Core 开放 API。

Snappy Ubuntu Core 是面向智能设备的平台，前不久刚刚被正式推出，可以运行存储在本地或依赖于云端的相同软件，而后者的最大好处就是可以让使用者避免频繁的定期升级。而保证联网设备有最新的安全补丁和固件修复，则是 Canonical 保证物联网安全的关键。

此前，Canonical 已经与亚马逊、微软、Google 达成过合作，不过主要还是在云服务领域。而 Canonical 希望能让 Linux 成为物联网更智能和可扩展的核心平台。目前，除了微软和亚马逊，Canonical 还和德国电信、MIPS 和 ARM 处理器提供商 Cavium、德州仪器和工业互联网联盟，保证 Canonical 在电信业、物联网底层设施和产业管理层面有合作伙伴的支持。

尽管竞争对手不少，但 Snappy Ubuntu Core 最大优势就是其目前已经拥有的用户基数。此前吗，无人机制造商 Erle Robotics，已经推出了运行于 Ubuntu Core 平台上的 Erle-Copter。除了能够运行第三方应用程序，还可以通过云端进行自我“更新”维护。

这二十多年，可真不是“爱你在心口难开”，微软和 Linux 是真的刀枪相向，发自内心地想赢下这一仗。《浪潮之巅》里曾提过，在 Google 上市前，微软一直把 Linux 作为最主要的竞争对手。那时候，PC 为王，互联网还不曾那么深刻的改写人类历史发展的轨迹。

但二十多年过去了，当初的必争之地——桌面操作系统，已经成了双方业务的一小部分，双方面对的都是更广阔的天地：互联网、移动互联网、云服务甚至物联网。最终，微软赢得了 PC 操作系统的胜利，Windows 操作系统依然运行在数以万计的 PC 设备上；但 Linux 基金会指出 ，“目前 Linux 几乎主导了除桌面外的所有计算领域。”

Satya Nadella 掌权的微软，更像是一位“商人”，在商言商，挣钱是第一位的，立场和信仰都是为盈利、赚钱服务的。现在的 Linux 不仅仅是对手，还是需要拉拢的合作伙伴。所以，除了背地里偶尔搞点小动作，没事挥挥专利的大棒，微软还要经常秀下恩爱。

对 Linux 的开源社区来说，微软的专利大棒阻碍了整个科技界的发展，可憎。最让人津津乐道的大概就是“ Windows 7 sins” （Windows 7 之罪）网站。但 Linux 的开源社区都不像微软这般“有钱有势”，要想在竞争中取胜还需要依仗大公司的帮助。

有时候，仔细想想，所谓的“开源精神”、“打击邪恶”，都是极客们的，大公司们可没这些“信仰”，挣钱、盈利、市场才是第一要务。竞争中占优的公司总是想以封闭提供更好的服务，以封闭滚更大的商业雪球；不占优的公司总是希望讲开源、开放的故事逆袭；而所有的公司都会考虑商业利益最大化。连苹果这么高冷的公司也会“看人下菜”，推广 Apple Pay 时，在美国市场联手支付宝，拉拢超级靠谱大队友；在中国市场牵手银联，占下政策的高地。

言归正传，再回到微软和 Linux，我还挺好奇，Satya Nadella 和微软有没有听过这样一句中国话：秀恩爱，死得快。
