# 为什么我们想要你下载开源软件时输入 “$0”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=203187190&idx=2&sn=d380033dcfcd60a16fce4d05a78cc91c&chksm=2f0058b01877d1a6d6e8038d78acd6cb338196ffc38331953d96c9efeeb873408e334b47684d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=203187190&idx=2&sn=d380033dcfcd60a16fce4d05a78cc91c&chksm=2f0058b01877d1a6d6e8038d78acd6cb338196ffc38331953d96c9efeeb873408e334b47684d&scene=27#wechat_redirect)

开源软件通常是免费提供给用户，但任何软件的开发都是有成本的，开源软件并不例外。

基于Ubuntu的Linux发行版elementary OS为了让用户知道开源并不意味着免费，修改了软件下载方式，以前用户可直接选择免费下载，而现在用户必须输入任意金额后才能下载，如果想要免费下载可以输入“$0”。

elementary OS官方博客解释说， 开发软件的成本巨大，为抵消开发成本有的公司会对软件收取数百美元，或要厂商为软件授权付费，或销售捆绑软件的昂贵硬件。其它公司则通过挖掘用户数据和向用户展示针对性广告的公司收费。

如果我们希望看到开源软件在全球增长，我们需要鼓励用户为软件开发付费，否则项目将会缺乏资金，而开发人员必须求助于秘密交易和广告，没有人想要这样一个未来。
