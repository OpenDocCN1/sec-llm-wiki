# 红旗 Linux 即将预装瑞星安全产品

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=203103990&idx=3&sn=f494d31c05e64af1677f23b8df870e60&chksm=2f0725b01870aca6b0b689b8a6732d6a85d494f447fea57119c124605c4358a34ec861079ed2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=203103990&idx=3&sn=f494d31c05e64af1677f23b8df870e60&chksm=2f0725b01870aca6b0b689b8a6732d6a85d494f447fea57119c124605c4358a34ec861079ed2&scene=27#wechat_redirect)

国产操作系统厂商红旗与瑞星日前联合宣布，双方已完成产品兼容性测试，即瑞星安全产品可在红旗Linux系统上使用。通过此次合作，红旗软件专门定制瑞星桌面安全版产品，并结合红旗软件系统本身的安全监控防护系统，保证用户安全放心的使用红旗Linux系统。

与此同时，根据不同安全级别需求，红旗软件也将陆续建立从硬件加电、系统安全引导、系统模块检查校验、上层防护启动等一套完整安全可信链，确保真正的用户信息安全。

瑞星公司副总裁张雨牧表示：“此番深度合作，标志着瑞星覆盖了市面上主流的Linux操作系统，对红旗全线产品及广大用户群来讲，安全等级将全面提升。”

针对此次合作，红旗软件总裁北南表示，“红旗将与瑞星等优质主流厂商合作，共创开放生态环境，建立安全性高、兼容性强的操作系统，促使产品应用更趋完善，真正赢得消费者认可。”

自去年正式重组上市以来，红旗软件先后与搜狗输入法、金山WPS、瑞星杀毒等市场占有率高的产品延展合作，这些软件应用厂商都将与红旗完成桌面端兼容性测试。
