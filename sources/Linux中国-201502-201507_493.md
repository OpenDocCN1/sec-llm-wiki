# “羞涩”的树莓派2怕闪光灯

据外媒报道，近段时间，Raspberry Pi 2引起了不小的风波，当中最大的原因当然是它在继续保持前身低价的传统下，功能上获得了大大的提升。不过有一点可能让一些使用者感到头疼的是，没法拍下它在电脑中运行的样子。据了解，Raspberry Pi 2似乎对Xenon的闪光灯特别敏感，第一位发现这个问题的用户将它称为“怕上镜”的家伙。

任何一款采用Xenon闪光灯的相机在对着设备闪光拍摄之后，设备的屏幕都会冻结几秒钟，然后开始重启。不过像LED闪光灯就不会发生这样的状况。

其实，芯片的光敏现象并不新奇，不过一般情况下，大部分厂商都会尽量避免这种情况的发生或将这种情况的发生概率降低到最小。在Raspberry Pi 2这个例子上，受影响的看起来应该是电源芯片。
