# 罗未：开源软件的存在逻辑

> \[编者按\]罗未，中国开源硬件项目豌豆机器小组(WRTnode machine team)发起人，OpenWrt项目中国社区的重要参与者，出身于行业软件领域，3年前转入硬件方向，经历过智能家居和路由器行业。作为国内开源社区和项目的直接参与者，雷锋网专门向罗未约稿，从一个开源社区的参与者和开源项目的发起者角度，向大家介绍一下，真实的开源社区是如何存在和运作的。
> 
> 作为一个在真实世界里长期存在，并发展壮大的组织，开源并不简单，但也不会比其它同样存在的组织更复杂。开源与商业是并存的，并非某些暗示的那样截然对立。了解一个真实的开源世界和开源理念，对于我们了解真实的网络世界，会是非常有帮助的一个开始。

在数年后，当他跟乔布斯谈笑风生的时候，亦或是RED HAT公司送来的一百万期权在纽交所屏幕上亮瞎双眼的时候，芬兰宅男Linus或许会回忆起自己1991年在一个由怪蜀黍组成的贴吧里发出的那个帖子：

> Hello everybody out there using minix- I'm doing a (free) operation system (just a hobby, won't be big and professional like gnu) for 386(486) AT clones.

正是这个弱弱的帖子，造就了后来全球范围内万千宅男意念的统一，仿佛一场时空畸变效应，穿越宇宙和物理的逻辑，成全了无数少年英雄青春挥汗，在互联网、硅谷和纳斯达克种种绚烂的喧嚣背后，落下那个神谕般的企鹅——QQ，哦sorry，不是QQ是：Linux。

当下的中国，大家都知道码农是个赚钱的饭碗，所有的逆袭屌丝和凤凰男几乎都是码农。遍布互联网的主流消息都是学哪门语言赚钱多，跳去BAT薪水翻几番；泥沙俱下中有一件事情几乎没人提起：抠腚，学名编程，本是所有人类发明的游戏中最让人沉溺的那一类。传说晋朝有位叫王质的人，一次进山打猎，遇到两位童子下围棋。他吃下童子给的一枚枣核，便不觉饥饿，观二童下棋，一盘棋罢，斧柄已完全烂掉，时间已过去百年。编程对特定人群来说，具有同样的功效：当你喜欢，你便全身心投入，然后你便忘记了时间和世界。

所以，在这个前提下，我们来讨论开源软件的生存逻辑，你便知道这里的出发点在哪里：真正的、纯粹的开源软件，只关乎于乐趣，和乐趣带来纯粹逼格。

但是光阴荏苒、白驹过隙，翩翩少年终究长大坠入成人世界。他们的作品逐渐成为某种重要的商业基石，以传统的开源社区为基础，在大型IT公司的技术投资背景下，泛商业化的开源社区演化出了一套完整的游戏规则。这套游戏规则融合了个人志趣、自我雇佣、个人成长与巨头角力，这样的一种运作机制，已经成为技术竞争的重要方法，贯穿于各大巨头的话语权争夺中，成为当今世界大型IT公司必备的商业策略。

### 个人参与者视角

个人在开源社区的活动，可以归纳为三种状态：

**个人志趣**即最为纯粹的爱好行为。

而**自我雇佣**则是成为社区的积极贡献者后，在社区的影响力的覆盖范围内，成为一个被广泛信任的技术个体供应商，而这种技术供应关系往往能成就全球范围内的交易，造就了许多技术市场上的独行侠。比如巴西售卖的某个路由器是由东莞某路由器厂商雇佣OpenWrt社区某爱沙尼亚活跃分子完成，大家各得其所，构建出一种天然全球化的社区协作模式。

第三种状态是个人完成社区的贡献以**展示其技术水准**，从而在职业生涯中获取更好的发展。这种方法也已经成为国内很多程序员跳槽的重要砝码。

### 商业组织视角

当我们聊到商业机构介入开源社区的时候，可以先参照一下这篇访谈 ，文中采访对象为Intel全职雇佣工程师，在Linux kernel开发者金字塔结构中属于约前100位的核心人员，而他的唯一工作，就是保持在Linux kernel社区中的位置。文中详细阐述了Linux社区技术管理的细节，在此不用敷述，我们更多地从商业逻辑来考量。Intel作为长期以来Linux的核心赞助商，对社区的投入不仅仅是钱，更有实实在在的技术贡献。其核心的目的可以有两种视角来归纳：一是作为全球最大的芯片供应商，必须保持与应用最广泛的操作系统的一致性和适配性；二是在面向未来的技术发展方向中，通过全方位地对Linux施加影响，保证自身技术绝对领先的地位。这两点的导向都是非常直接的商业价值和目的，Intel与Linux的关系，几乎是Intel商业策略中最为重要的一个部分。

同样的道理，我们看到在OpenStack、Hadoop等处于最具商业价值的开源软件社区中，在技术竞争层面，社区中的贡献和地位，几乎是巨头们最为猛烈聚焦开战的地方：OpenStack和Hadoop已经成为云计算和大数据的事实标准，谁在其中贡献和话语权大，自然说明谁能提供这个领域的更为优秀产品和服务。

强烈建议大家到Linux foundation的赞助商页面去看一下，那如电影结尾字幕一般华丽的十屏LOGO，几乎活脱脱的是一部当代IT业兴衰史。而当你在银牌赞助商的目录里看到摩根大通和路虎时，一时间你会困惑做金融的和做汽车的对Linux感兴趣是出于单纯的美好情感吗？转念一想你就懂了：基于Linux的高频交易系统或许正是摩根大通的黑科技印钞机，而Linux在汽车设计、仿真和汽车电子中的核心位置，也许正是路虎得以存活的救命稻草。

接下来你也许就领悟了：这便是开源软件和社区在全球商业逻辑下的核心规则，而也正是这种规则，把开源这件事情，变成了当代经济结构的一项基石——开源成为人类现代商业文明无法分割的一部分。

在这样的背景下，我们再来审视国内某新兴品牌把赞助某风口浪尖开源软件作为直接的PR手段这件事，仔细咀嚼可能会有一种二二的感觉。但是做人要厚道，人艰需不拆，不管你觉得是他们真无知还是假卖萌，总要让人有一个学习成长的过程不是，毕竟我们聊到的都是帝国主义老牌列强公司，我们的公司年纪还没有人家零头大，就犯错、就任性、就傻逼了，又能咋地？

而看完这篇文章的人，当你拿起手机，去银行取钱，然后乘坐地铁，林林总总，完成日常生活中的每一个转身，你或许会知道我们这个世界的技术和经济构建里，大多数细胞都被默默植入了开源软件的成分。这提醒着我们，这个世界上不是所有东西都是用直接经济契约来维系的，比如阳光、空气、爱情和开源软件。

**我们如果不能做到为之贡献，至少做到保持敬畏。**
