# Android 版的 VLC 发布1.0正式版

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=203015619&idx=2&sn=8922e92992fee6f7d71fab34840e2b72&chksm=2f05fe85187277935c1db3d2c21907fbdefe7908aa688cc8e6deb4d74e1c09433c838283f107&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=203015619&idx=2&sn=8922e92992fee6f7d71fab34840e2b72&chksm=2f05fe85187277935c1db3d2c21907fbdefe7908aa688cc8e6deb4d74e1c09433c838283f107&scene=27#wechat_redirect)

开源多媒体播放器VLC的Android版本终于脱离了beta发布了1.0正式版（Google Play商店尚未更新，可以直接到VLC 的开发商下载APK文件）。

VLC最早是为iOS平台开发了移动版本，但递交到苹果商业后遭到了拒绝，原因被认为是VLC采用的GPL许可证不兼容于苹果对所有iOS应用强制执行的DRM。在遭到拒绝后开发者转向了Android平台。
