### 安装以及配置

Linux 和 OS X 基本都可以通过源来安装，实在不行就下载源码编译，不难的。

安装好第一步是修改 OS 默认 shell：

```
1.  `chsh -s /usr/bin/fish`
    
```

然后就可以直接使用了，就是这么简单。你不需要面对 zsh 浩如烟海的配置文件，也不需要去 github clone 一个 “Oh My Zsh”。

当然如果你实在想配置，输入 `fish_config` 命令会启动 web 管理界面。

什么？逼格太低，非要手动配置。OK， `~/.config/fish/config.fish`这就是 fish 的配置文件，类似于 bash 的`.bashrc`。

我喜欢配置三件东西：

1.  问候语（配置`config.fish`）：
    

1.  `set fish_greeting 'Talk is cheap. Show me the code.'`
    

3.  命令行提示（在web界面配置，完成后会生成`~/.config/fish/functions/fish_prompt.fish`）：
    
    ![](../Images/2c5f46769b2847864b24f1d5c63e3a90.png)
    
4.  设置接受建议（第三条优势）的快捷键：
    
    修改`fish_prompt.fish`，增加一条语句：`bind \ej accept-autosuggestion`。同时按下alt和j将接受建议。
    

### 优势

#### 语法高亮

不存在的命令会显示为红色。

![](../Images/f21b1ee97059a15c00faa72e99c6a26b.png)

![](../Images/cfeca895e846943475f8b07afb416d69.png)

#### 通配符

集成`find`命令，递归搜索神器。

![](../Images/3bc545b4738568f5b89f549e181c12c3.png) 

#### 智能建议

当按下几个字母后，`fish`会有智能建议，按下向右箭头将接受建议。

![](../Images/121f41a38d6c17c2025a5f0dd37d87ab.png)

#### Tab补全

如果补全项超过1个，会列出全部以供选择。

![](../Images/7a7d62d59130c88c718948658cbdfd9c.png)

#### 变量

fish是通过`set`来代替“=”对变量赋值的。

![](../Images/b454db85a6d81309aaa6ac95001142f7.png)

将某目录加入到`PATH`中也是用`set`（配置`config.sh`）：

```
1.  `set PATH $PATH /home/mountain/shell`
    
```

  

#### Exports

fish没有export命令，需要用set -x来代替。如果需要擦除变量，就执行set -e。

![](../Images/e132c017cc42dd6b79110240b8a519d7.png)

![](../Images/e38bcf6e876c464c19378f01ca61f832.png)

  

#### 列表

有些变量有多个值，例如`$PATH`，`fish`会把所有值组装成一个列表，可以迭代或者通过下标访问。

![](../Images/beadf30219f233a324b312709a736367.png)

  

#### 命令替换

用法很简单，把命令放在括号里即可。

![](../Images/2d596e66739618c016dae54a2f6483bd.png)

  

#### 语法糖

fish 的常用关键字（if、switch、function 等）比 bash 高端、实用很多，但是考虑到公司的生产环境根本不可能安装 fish，导致脚本无法移植，所以对于这部分只能忍痛放弃。
