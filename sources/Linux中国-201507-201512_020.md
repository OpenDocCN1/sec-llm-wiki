# 微软宣布 Azure 已支持 Debian

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=400584045&idx=2&sn=bcac57a99dd08eaf4fbdd3b4c57e8189&chksm=34fc562b038bdf3dba3bbeadc5aec1f51226e57a9fb73de2d1be07e98e0a89b086268b80e85e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=400584045&idx=2&sn=bcac57a99dd08eaf4fbdd3b4c57e8189&chksm=34fc562b038bdf3dba3bbeadc5aec1f51226e57a9fb73de2d1be07e98e0a89b086268b80e85e&scene=27#wechat_redirect)

尽管许多Linux用户对微软很是反对，但事实上，这家公司也是Linux内核的一个重要支持者。尽管该公司此前曾看不起Linux，但是时间已经改变了一切。除了招募开源专家之外，该公司甚至还为世界上最流行的Linux分支（Android）开发应用。更不用说，Azure一直支持的少量Linux发行版了。今天，我们又获知了一个好消息，因为微软再次拥抱了Linux，并为Azure添加了对Debian的支持。

![](../Images/ce57958f1cd3839b64ee62e5b0d5877f.png)

是的，作为世界上最流行的Linux发行版之一的Debian，已经正式登陆Azure市场（与它一道的还有此前的Ubuntu、RHEL、openSUSE等）。

微软Azure高级项目经理Stephen Zarkos表示：

> 这个声明告诉向客户们传达了其今后能够在Microsoft Azure用上基于Debian的虚拟机的消息，并且可以选择由credativ打造的最新的Debian 7（代号wheezy）和Debian 8（代号jessie）版本。
> 
> credativ是一家成立于1999年的独立咨询和服务公司，它提供了全面的开源服务和技术支持，致力于推动开源软件的使用、支持和发展，并在英国、德国、荷兰、北美、印度有分支机构。
> 
> 作为一款被认可的发行版，Azure的Linux团队和开源开发支持团队已通过Azure Marketplace提供对Debian镜像的支持，我们在2015年7月宣布的支持政策中有提到过。
> 
> 微软将于credativ一道，在Azure Marketplace中提供最新的Debian版本镜像，同时在镜像的构建过程中保持透明和社区导向。
