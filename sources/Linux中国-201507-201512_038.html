为什么说 ChromeOS 胜过 Linux、Mac 和 Windows?

熟悉我的人经常指出：我在某些事情上态度有点顽固。不过，我在一个方面发觉自己屈服于现实的压力。我在本文中将证明为何我认为ChromeOS最后会在操作系统大战中胜出。


桌面操作系统很危险

就像耍弄尖利的棍子那样，轻松让你可以访问根或超级用户权限的任何操作系统可能都很危险。2015年，计算机安全面临的最大一个威胁就是坐在桌子跟前，在键盘上敲打。这就是为什么现在比以往更多的人倾向于使用平板电脑、智能手机和Chromebook作为其主要的计算设备。

所有这些设备都牢牢保护起来，访问任何对该设备来说很危险的内容都极难实现。无论你在Mac或Linux上运行rm -r /，还是在Windows安装什么东西，不太精通技术的人也实在有太多机会可以破坏安装的操作系统。

有一点要说明：我倒不是说每个人都应该丢弃现有的桌面操作系统。这么做轻则不切实际，重则可能会带来灾难。我要说的是，不管我们觉得ChromeOS怎样，对普通用户而言，从许多方面来看它都是获胜的操作系统。

Windows

不像能够娴熟地使用其系统的高级用户，我在这里指的是普通的Windows用户。这些人在其浏览器中有15个工具栏；在运行三个安全套件，不过安装以后没有一个套件更新过。要是遇到什么问题，经常跑到当地的PC修理店，救助技术员。

现在不妨更深入一步，认真看一下Windows 10。先抛开我个人对这个版本的看法不讲，我想探讨一些仍然原封未动的核心问题。

默认浏览器――众所周知，Edge浏览器并不总是正确地显示页面内容。到目前为止，坊间说法表明，大多数人在Windows 10上使用Chrome，而不是Edge。你也知道，这是ChromeOS提供的浏览器。

硬件兼容性――就像任何可以自动安装的操作系统一样，你得确保硬件与之兼容。我在这方面的经历表明了我以前在使用Windows 7和Windows 8时的经历――比较旧的外设和笔记本电脑基本上不兼容。需要你的ath9k无线芯片组可以正常工作?那就要碰运气了。有兴趣更改你触控板的行为？在我试用的测试机器上更改不了。我还听说，大多数与Windows 8兼容的笔记本电脑可正常工作，但是任何更旧的系统在特定部件方面完全凭运气了。硬件厂商的官方说法是，在兼容模式下试试其他驱动程序。就ChromeOS而言，操作系统内置到笔记本电脑中。上面有Made for Windows 10标识的笔记本电脑也是一样。

更新――尽管微软作出了最大的努力，但Windows 10无论怎样都没有提供完美无瑕的更新体验。我倒不是挑Windows的刺，OS X和Linux也是这种情况。从以往来看，Chromebook上的ChromeOS在更新方面没有任何重大问题。

OS X

Mac的支持模式与Chromebook很相似。两者的初衷都是为了尽量给用户提供方便，不过有些地方还是不一样。与Windows一样，Mac能够运行成千上万个软件。但是Mac还有自己的一堆问题让我颇为沮丧。

计划报废――这是PC厂商也在采用的一个花招。对这个做法本身我并不持异议，因为我认识到苹果(及其他厂商)需要确保公司盈利。不过，我确实觉得：尽管旧硬件还可以使用，却驱使人们购买新硬件，这纯属徒劳。比如说，尽管年头很长，但PPC Mac运行起来还是很棒，我认为仍有其价值。迄今为止，Chromebook没有遇到过这个问题。ChromeOS的另一个优点是，软件都在异地运行，在服务器上运行。所以，总的来说，新旧的Chromebook都有同样的体验，这归功于ChromeOS。

成本――Mac更贵一些。如果你是Mac用户，这不是问题，你觉得这没什么，因为它提供了你需要的那种端到端体验。但是如果你比较一下硬件规格，其他大多数PC完全更便宜。相比之下，Chromebook提供了更大的价格区间，因为硬件规格涵盖低端到高端的Pixel。

更新――客观地说，苹果的更新通常相当好。话虽如此，如果你没想到设置TimeMachine备份或类似的机制，帮助将系统恢复到原始状态，那么完全要靠你自己了。尽管就OS X而言，有些内容存储在云端，但是诸多软件不是这备份的一部分。ChromeOS同样将你的数据存储在云端。又由于所有ChromeOS软件围绕于浏览器，重新安装软件或寻找光盘都没有问题(如果你仍使用光盘的话。切记，iCloud旨在同步，Google Drive旨在存储，同步是事后才想起的)。

Linux

作为一个偏袒Linux的发烧友，我准备完全实话实说。桌面端Linux并不适合每个人。因为不存在Linux商店这样的地方，要是你遇到了问题，无法很快跑过去求助。寻求社区的帮助全靠你和你的能力。如果你与Linux提供商签有支持合同，那就另当别论。不过对家庭用户来说，万一你需要帮助，只好上Linux社区求助。

破坏安装――尽管这种情况在固定发布的发行版上很少发生，但还是会发生。有时候，是用户操作不当，有时候是更新出了岔子。在桌面端Linux上你能找到的与重置开关最相近的办法就是，自行解决问题，或者重新安装。就ChromeOS而言，几乎不可能搞砸。然而，就算你真搞砸了系统，只要重置笔记本电脑，就能搞定。

连接性――我发现就支持专有驱动程序可用性的大多数发行版而言，让你的无线设备运行起来相当简单。话虽如此，无法保证所有芯片组都会顺畅运行。因为外面有太多的选项，你需要先测试一下及/或研究一下，之后才可以将选择的发行版安装到笔记本电脑上。如果是Chromebooks，由于整个生态系统受到严格控制，所以无线设备可正常运行。Chromebook随带特定的芯片组，ChromeOS完全能检测到它。

Chromebook确实管用

在上述解释中，我决定谈谈每个平台存在的最大问题，以及为何Chromebook、或者说ChromeOS在完全极易使用方面更胜一筹。这并不意味着许多公司会在这个平台上做专业级的工作。毕竟，Linux、Windows和OS X在总体功能方面的本领比ChromeOS要强得多。但是说到只要访问Web服务(比如ChromeOS提供的服务)的那些用户，Chromebook大有意义。

尽管坊间盛传ChromeOS只用于小众领域，但ChromeOS不会安于一隅。谷歌走得更远，它提供了一款名为Chromebit的新产品。这位产品的价位是100美元，我认为我们会看到许多坚守旧操作系统不放的用户会改弦易辙。

至于我本人，我会继续大力支持Linux用户。不仅使用它，还为它提供支持。至于OS X 和Windows用户，我认为，在这方面有软件需要的那些人同样会继续使用那些平台。
