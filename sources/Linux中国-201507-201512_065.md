# 微软开源 Visual Studio Code

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=400425600&idx=2&sn=bea5cd3ef5ce5d5cac2dd8b767ea0def&chksm=34c239c603b5b0d07570c1c5122fd660ff4d1abe7786c06d26ce7f0212e44c1ebedc88cbd274&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=400425600&idx=2&sn=bea5cd3ef5ce5d5cac2dd8b767ea0def&chksm=34c239c603b5b0d07570c1c5122fd660ff4d1abe7786c06d26ce7f0212e44c1ebedc88cbd274&scene=27#wechat_redirect)

微软在纽约举行的Connect(); 2015开发者会议上宣布开源Visual Studio Code。

Visual Studio Code是基于 Chromium的跨平台代码编辑器，源码托管在Github上，采用的是MIT许可证。

此外，微软还发布了 Visual Studio GDB调试器扩展预览版，允许开发者远程调试Linux对象，包括物联网设备。

在此次大会上，微软还宣布了免费版的 Visual Studio Dev Essentials， .NET Core 5和ASP.NET 5的RC版，Visual Studio的云订阅，Visual Studio Marketplace，等等。

更多可浏览微软的开发者博客。
