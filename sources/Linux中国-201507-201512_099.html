好奇号：火星探索离不开 Linux

原文：http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=400291049&idx=3&sn=836569f097de98b195d660a86ff4ab3a&chksm=34c7cfaf03b046b9f7bb9df7d526839b7d99f92b7672e76c2a9daad1c10696b662cb6ce48e65&scene=27#wechat_redirect

在2012年8月成功降落火星之后，好奇号Curiosity探测器不断向地面传回大量酷炫和有趣的信息，对于很多非天文爱好者来说并不会太关注这方面的信息，但事实上这项伟大的火星探索任务有很多非常有趣的地方，比如需要地面的 Linux 主机的帮助。地球和火星之间的距离显然无法直接进行任何远程遥控，所以通常工程师需要在模拟器中预先编排隔天的活动，而整个模拟过程是在一台Linux 主机上完成的。目前所用的 Linux 发行版并不确定，不过看起来是 Xfce 桌面或者是一台 Red Hat 发行版。

Linux 系统在科研领域运用非常广泛，所以事实上在此类大型天文项目中部署使用 Linux 操作系统并不感到惊讶，如果真的使用Windows 10 系统才是令人感到惊讶。需要指出的是这些科学家通常是自己选择 Linux 作为开发环境，而并非机构强制要求的，最常使用的系统为 Scientific Linux, Debian, Red Hat, Ubuntu 等等。
