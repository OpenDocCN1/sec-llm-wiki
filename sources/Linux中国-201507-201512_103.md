# 11.20开幕：Oracle + MySQL 嘉年华群星云集

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=400280722&idx=3&sn=e98200a396e626ff85948169cc5fc725&chksm=34c7f7d403b07ec258d5c599b1382958db6c33b951f2b6aadb8264f6984c0b640685f1cfba5e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=400280722&idx=3&sn=e98200a396e626ff85948169cc5fc725&chksm=34c7f7d403b07ec258d5c599b1382958db6c33b951f2b6aadb8264f6984c0b640685f1cfba5e&scene=27#wechat_redirect)

由ACOUG用户组主办的“Oracle技术嘉年华”至今已是第五届，现在大会已经形成了以 Oracle + MySQL 两条主线，2015年大会更是空前汇集了两个领域的元老精英，共襄盛会。

  

在2015 OOW大会上，有两个重量级的产品更新发布，分别是：Oracle Database 12.2 Beta 和 MySQL 5.7 版本。在“Oracle技术嘉年华”大会上，来自旧金山的第一手技术线报将全面奉献给大家。

![](../Images/8ab36ac636593f9e34ff609f5349bbc9.png)  

在**Oracle数据库领域**，本届大会的重量级亮点嘉宾有：

  

1.  **来自原厂的专家**：甲骨文VP及大中华区技术产品事业部总经理：**吴承杨**，来自Oracle总部RWP团队的VP：**Andrew Holdsworth** ；
    
2.  **ACOUG用户组专家**：ACOUG的联合创始人&Oracle ACED，**盖国强** 和 **张乐奕**；
    
3.  **软件与服务前辈元老**：SQL Optimizer的发明者 **杜伟业**，国内服务业与社区的先行者**老白（徐戟）**；
    
4.  **云和恩墨的ACE团队**：技术总监 & ACED **杨廷琨**，ODU恢复软件作者 & ACE **熊军** 和 ACE **李真旭**；
    
5.  **在中国的外国人**：**Joel Perez**是南美的第一位Oracle ACED，他现在服务于云和恩墨，在中国工作；
    
6.  **培训领域明星团队**：Oracle最受欢迎的RWP培训明星 **曲卓（Christine）**、**董志平（Cary）**老师；来自恩墨学院的ACED **侯圣文** 和ACE **崔旭**老师；来自福州耕耘培训领域近10载的 **唐波** 老师；
    
7.  **SQL专家明星阵容**：Oracle ACED **崔华** 老师，ITPUB SQL大赛冠军 **罗海雄**，SQL大赛评委 **怀晓明** 老师，恩核总经理 **郑保卫** 博士；
    
8.  **Oracle年轻专家**：来自宝存科技的ACE-A和Oracle年轻专家** 戴明明**，来自云和恩墨的Oracle年轻专家 **李敏**；
    
9.  **一代怪侠男神和女神**：历经阿里巴巴、京东，现在落户Ebay的一代怪侠、调试专家 **吕海波 **；本届大会唯一的女嘉宾，江湖人称Oracle女神的Lunar，**张大朋**；
    

  

在**MySQL数据库领域**，本届大会的重量级亮点嘉宾有：

1.  **来自原厂的研发工程师**：**宋利兵** 和 **李海翔**，他们分别从事的是MySQL复制和优化器方面的研发工作，可以从源码谈功能；
    
2.  **ACMUG用户组创始人**：**周彦伟** 老师是MySQL用户组的创始人，在国内倡导了持续的MySQL分享活动；
    
3.  **源于阿里的内核级专家**：**楼方鑫** 和 **彭立勋**，楼老师自Ebay而阿里，自Oracle而MySQL踏出一条技术坦途；而彭立勋则是阿里MySQL方向的Oracle ACE专家，国内唯一的MariaDB源码提交者，国内为数不多的MySQL源码贡献者；
    
4.  **网易的内核级MySQL专家**：**姜承尧** 老师不仅是国产开源数据库InnoSQL的发起人。更著有系列畅销书籍《MySQL技术内幕：InnoDB存储引擎》、《MySQL技术内幕：SQL编程》等；
    
5.  **Oracle MySQL ACE团队**：国内第一位MySQL方向的Oracle ACED **简朝阳**，Oracle ACE网易专家 **姜承尧**，阿里巴巴ACE专家 **彭立勋**;
    
6.  **阿里京东与新浪系**：来自阿里巴巴的系统架构与优化大牛 **何登成** ，业内资深前辈级MySQL专家，从人人网到京东金融的 **刘启荣** 老师；新浪微博系专家：**杨尚刚**、**张博森**；
    
7.  **唯品会运维创新团队**：运维与工具软件专家 **聂超**；
    
8.  **创业团队**：平民科技（前支付宝技术专家）**楼方鑫**，新媒传信 **吴炳锡**；
    
9.  **图片系处理**：美图秀秀 **杨尚刚**，Nice社交 **董泽润**；
    

  

在**用户实践领域**，本届大会的重量级亮点嘉宾有：

1.  **金融领域资深专家**：**张晓丹** 恒丰银行科技部总经理，曾在中国工商银行数据中心（北京）总经理室工作，任IT基础设施及信息安全领域专家；**张磊** 京东支付业务数据架构负责人，主要负责京东金融支付业务数据架构工作，在支付行业有过多年的DBA和数据架构经历；
    
2.  **移动与电信核心系统**：江苏移动信息技术中心资深数据库专家 **戴建东**；浙江移动信息技术部数据库架构师 **郭岳**；中国电信四川省分公司数据库专家 **张明**;
    
3.  **数据架构与数据治理**：来自恩核中国的**郑保卫**博士，他在数据模型设计、数据治理方面经验丰富；来自华东计算所的**王金华**先生，他在数据架构设计、模型标准化等方面具丰富实践经验；
