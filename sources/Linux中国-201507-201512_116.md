# 微软宣布与红帽建立合作伙伴关系

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=400241881&idx=1&sn=768ef07c1f68d9b5ccca3c5d812b14b6&chksm=34c70f9f03b086890bb0bfe28e54976066eb8a211630fa44bb649467a17cee89b1b5f7ae49f9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=400241881&idx=1&sn=768ef07c1f68d9b5ccca3c5d812b14b6&chksm=34c70f9f03b086890bb0bfe28e54976066eb8a211630fa44bb649467a17cee89b1b5f7ae49f9&scene=27#wechat_redirect)

今天上午，微软和Red Hat宣布建立合作伙伴关系，这将提高微软Azure产品，为其客户带来企业级Linux当中领先的Red Hat产品 ，这将会让更多的企业转向微软云服务。该合作协议包括了为Red Hat和微软客户提供的许多新产品，其中包括：

向微软Azure客户提供红帽解决方案，包括RHEL的应用和任务，以及红帽应用平台产品，此外还包括RHEL和JBoss的中间件平台。这些解决方案集成了企业级支持，涵盖了混合云环境。在微软Azure平台上，Red Hat和微软联合为Red Hat产品提供支持，比其他公共云，提供更深入和更丰富的终端到终端企业支持体验。这方面的支持服务，将帮助企业提升把他们的红帽解决方案迁移到微软Azure云的信心。

另外，双方还将协作基于新一代.NET的应用开发能力，包括OpenShift和RHEL在内，跨红帽产品提供.NET技术。跨混合云部署统一工作负载管理，其中包括红帽CloudForms和微软的Azure，另外还提供系统中心虚拟机管理器，在Hyper-V和微软Azure上管理红帽Linux。双方预计将在未来数月内，支持从红帽CloudForms管理Azure工作负载。
