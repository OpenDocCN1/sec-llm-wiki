# 五款“已故”操作系统以及它们所带来的启示

颤抖吧，凡人！又一年万圣节到来，幽魂、鬼怪，众多不洁之物又开始在人间肆虐，所说在这一天已然故去的过往也将重新出现在我们身边。

值此良机，让我们点燃蜡烛、遮好镜面，并祭起各种稀奇古怪的仪式来回忆已经深埋泥土之下的操作系统英灵们。当然，这并不是为了悼念过去那些令人抓狂的简陋界面设计，而更多是想从它们对后世的影响以及自身特性当中总结经验。谁知道呢！也许这些古董操作系统的坟墓当中真隐藏着不少值得一探的秘密。

### **1.Windows XP**

Windows XP自诞生以来就注定要震惊全世界。诚然，直到发布其ServicePack 2版本，我们才真正迎来了如今的所谓XP操作系统，不过自2001年初次亮相之时其已经具备了清晰的基础构架。这当然是件好事，也正因为如此Windows XP才拥有如此可观甚至令人有些头痛的生存周期。

Windows XP之所以能够在很长一段时间当中保持强劲的生命力，在相当程度上还要归功于微软徒劳无功的“Longhorn”计划——后者包含有大量野心勃勃的新型功能设定。随着Longhorn项目一次又一次不断延期，更多人开始将精力及资源集中投入到自己已经熟悉且普及度极高的XP系统身上，同时对任何新版本变更投以蔑视的目光。

![](../Images/223259657ebb9e3b11e0ff7feac11f0a.png "Windows XP标志性的绿草蓝天壁纸")

*Windows XP标志性的绿草蓝天壁纸*

在经过了五年半的漫长开发周期之后，Longhorn项目最终于2007年以Windows Vista的面貌与广大用户见面。然而用户们对于这款微软志在取代XP系统的全新方案既讶异又不屑。总而言之，直到两年之后新一代Windows 7亮相，Windows XP的庞大用户基础才真正开始受到影响。又过了四、五年时间(具体要取决于实际调查对象)，Windows 7终于压倒XP成为全世界普及程度最高的操作系统。

时至今日，XP之后已经出现了四款Windows迭代版本，但这款已经问世达14年的陈旧操作系统目前在全球范围内仍然拥有12%的在线PC使用占比——根据Net Applications的统计。这还是在微软于2014年4月宣布彻底终止提供XP系统安全更新的前提之下——也就是一年半之前。

**经验教训：**别让你的软件拥有过分夸张的生命周期，否则它只会变成一只无比危险的千年老妖。

### **2.Windows RT**

当初微软公司刚刚公布Windows RT之时——最初曾被命名为Windows on ARM——人们可谓是群情沸腾，由此带来的无限可能性可算是想想就心潮澎湃。最终，以提高能源使用效率为主要诉求的ARM处理器架构——已经全面覆盖了移动设备领域——终于迎来了属于自己的Windows版本。

不过最终被摆在我们面前的Windows RT成品却成了操作系统领域的一个残酷玩笑。与Windows 8类似，Windows RT采用了双重面貌设计，即桌面界面外加现代UI方案。其桌面设计非常凑合，因为除了IE浏览器与微软Office之外无法支持任何其它传统Windows软件。Windows RT的用户们在专门面向触控操作所设计的新界面当中同样备感无力，因为微软公司根本没能拉起应有的潮流，这意味着开发人员压根不想为Windows Store构建拥有现代设计理念的新型应用。

![](../Images/4e6ef5a59db76b84e51a4b43d0551ffe.png "运行在微软Surface RT设备之上的Windows RT操作系统")

*运行在微软Surface RT设备之上的Windows RT操作系统*

作为已经走到生命尽头的操作系统，RT给人留下的印象就只有一款华而不实的Web浏览器外加零星几款已然陈旧的程序选项。与此同时，英特尔公司的凌动芯片快速赶上并顺利消除了x86架构与ARM之间的能源利用效率差距，这也彻底断绝了用户选择使用Windowson ARM的最后一点理由。

微软公司一直没能确切弄清自己到底要为Windows RT选取怎样的市场定位。而由此带来的结果就是，整个经过漫长考量的新型生态系统就此沦为历史车轮下的牺牲品。Windows RT平板设备根本无法升级至Windows 10，甚至就微软公司自己的Surface产品线都在迎来第三次迭代的同时放弃了Windows RT这一家族成员。

**经验教训：**Windows RT的幽魂正在哀怨地啜泣，目送Windows 10的通用应用与Windows Phone兼容性与自己彻底无缘；不过Windows RT的下场可谓“罪有应得”，因为它只是在合适的时机出现并狠狠折磨了用户一把——很遗憾但确实如此，其堪称荒谬的新型界面设计以及极为有限的软件支持能力都让人对其大为光火。总而言之，如果大家打算推动一套全新的生态系统，请千万别忘了自身业务的立足根基在哪里——正如俗谚所言，倒脏水的时候别连盆儿里的孩子一块泼了。

### **3.Mac OS**

![](../Images/974abb0361d5dcbf2c53508100b43d24.png "Mac OS凭借着当时令人眼前一亮的全图形界面而显赫一时")

*Mac OS凭借着当时令人眼前一亮的全图形界面而显赫一时*

苹果公司所创立的核心原则之一就是，PC设备——以及与其相关的整套技术体系——应当拥有令人愉快甚至堪称神奇的使用体验。这一愿景的存在使得初代Macintosh操作系统甫一问世即技惊四座。第一款苹果操作系统已经成为里程碑式的产品，它直接使得直观PC界面以及鼠标导航机制在家庭用户当中普及开来。

不过从负面角度讲，Mac OS为了达到这种神奇的效果而使用了大量技术措施及精妙的解决方案，旨在以超越时代的方式提供用户预期之外的系统表现，这也造就了一些缺陷。由于内存容量的限制，Macintosh用户需要为此而不断更换磁盘。

这有时候确实会给用户造成严重影响，但大多数使用者其实并不介意，因为屏幕上的用户体验实在太过出色、远远超出了那个时代任何其它竞争对手的水平。

**经验教训：**如果用户界面能够压倒竞争对手，即使软件本身存在问题亦能够受到广大用户的肯定。

### **4.IBM OS/2**

![](../Images/93d13c4cedc8a8868084187dd2dc7479.png "OS/2已然在客观层面上灭亡")

*OS/2已然在客观层面上灭亡  
*

在计算科学刚刚发展的早期阶段，IBM公司凭借着其强大的个人计算机产品线占据着市场上的统治地位。当初蓝色巨人与微软联手打造出了OS/2操作系统，其计划在于利用这款新型操作系统促进IBM方面的硬件销量。这一目标确实在一定程度上收到了效果，但最终OS/2的地位受到了微软发布的Windows 3.0版本的巨大冲击。在此之后，微软公司停止了OS/2的联合开发工作并专注于雕琢自己的Windows系统方案。而IBM方面则再也无法在操作系统领域与微软相匹敌。当然，专家们也曾经在早期讨论过微软Windows和OS/2操作系统到底孰优孰劣。

无论如何，OS/2已然在客观层面上灭亡，而微软也已经彻底战胜了IBM。

微软公司直到今天仍然将Windows与各类硬件产品相绑定，与此同时OS/2系统则以独立方式出售并专门根据IBM设备的销售需求进行设计。不过，这套方案在面向微软公司的时候则往往无法奏效——其完全不能对微软强势的销售套路相抗衡。自当年的Windows 95推出之后，OS/2的灭亡命运就已然注定。IBM公司于2000年淘汰了自身操作系统业务，但与如今的Windows XP一样，大家可能还会在一些陈旧的ATM设备或者小型企业的库存系统领域见识到OS/2的尊容。

**经验教训：**即使诸神也终有一天会跌落凡间。适应市场要求——而这也正是微软努力为Windows 8与Windows 10设定的发展目标——否则必将灭亡。

### **5.Linux阵营中的那些过往成员**

2015年，我们正式挥别了Mandriva——一款曾经红极一时的Linux发行版。这套Lnux版本一直以Mandrake的名头在市场上广受好评，直到2005年其被Conectiva公司所合并并改旗易帜为Mandriva。很多资深的Linux用户曾经就Mandrake或者Mandriva的消亡而扼腕叹息，甚至我身边也有不少同样对此表示遗憾的朋友。

![](../Images/8225cb403b3371222655981fed0c434e.png "只余骨架的企鹅，象征着Linux家族中又一位成员的陨落")

*只余骨架的企鹅，象征着Linux家族中又一位成员的陨落*

自从Canonical公司的Ubuntu于2004年正式亮相以来，Mandriva就彻底失去了其一直引以为傲的“易用型Linux”发行版的桂冠。而在七年之后，其发展已然彻底停顿。Mandriva仅仅是众多现已湮没无闻的Linux发行版中的一款，作为另一款由单一开发商支持的Linux版本，CrunchBang也于最近正式宣告消亡。

Linux在服务器世界也许算得上一股强大的力量，但其在桌面系统用户群体当中从未真正取得过规模性的成功。其开放特性吸引到众多开发人员为其创建自己的一套Linux发行版，但随后相关成果需要与成百上千的其它发行版激烈竞争以夺取这本就少得可怜的受众对象。因此不出所料，整个阵营当中总会有相当一部分版本随着时间推移而逐渐消失——甚至包括不少人气较旺的方案。

**经验教训：**大家可以赞赏某款Linux发行版，但最好别深陷其中不可自拔。因为没准其消失速度会比各位想象中的更快。

这就是我们今年的操作系统墓地探险之旅。如今PC世界仍在不断迈进……不知道明年的万圣节，我们又会迎来哪些新的“已故”成员呢?
