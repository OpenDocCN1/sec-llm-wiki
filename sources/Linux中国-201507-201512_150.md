### 引言

在本教程中，我已经收集了10个给 Linux 用户的有用工具，其中包括各种网络监控，系统审计和一些其它实用的命令，它可以帮助用户提高工作效率。我希望你会喜欢他们。

#### 1\. w

显示谁登录了系统并执行了哪些程序。

```
1.  `$ w`
    
```

![](../Images/90f803198597fdd53184a0e567447802.png)

不显示头部信息（LCTT译注：原文此处有误）

```
1.  `$ w -h`
    
```

显示指定用户的信息

```
1.  `$ w <username>`
    
```

![](../Images/f4bfe33a467ef62d3f8bdaebbc9fe4c7.png)

#### 2\. nmon

Nmon（nigel’s monitor 的简写）是一个显示系统性能信息的工具。

```
1.  `$ sudo apt-get install nmon`
    
```

* * *

```
1.  `$ nmon`
    
```

![](../Images/97f027225b3014043083716ae87481c1.png)

nmon 可以显示与 netwrok，cpu, memory 和磁盘使用情况的信息。

**nmon 显示 cpu 信息 (按 c)**

![](../Images/7cd26330ea42fb7ff5c79150bc307f14.png)

**nmon 显示 network 信息 (按 n)**

![](../Images/f891ab37845442664014caef9a66f9e3.png)

**nman 显示 disk 信息 (按 d)**

![](../Images/cd946e48df59673a3798b61688b8c2e2.png)

#### 3\. ncdu

是一个支持光标的`du`程序，这个命令是用来分析各种目录占用的磁盘空间。

```
1.  `$ apt-get install ncdu`
    
```

* * *

```
1.  `$ ncdu /`
    
```

![](../Images/5c901cc08ee564eb6526a4aa46682165.png)

最终的输出:

![](../Images/9c690758e37cdec27747c409bb105c8b.png)

按 n 则通过文件名来排序，按 s 则按文件大小来排序（默认的）。

#### 4\. slurm

一个基于网络接口的带宽监控命令行程序，它会用字符来显示文本图形。

```
1.  `$ apt-get install slurm`
    
```

例如:

```
1.  `$ slurm -i <interface>`
    
```

* * *

```
1.  `$ slurm -i eth1`
    
```

![](../Images/036d2dc274b5df8d835e5829acf85ce7.png)

**选项**

*   按 **l** 显示 lx/tx 指示灯.
    
*   按 **c** 切换到经典模式.
    
*   按 **r** 刷新屏幕.
    
*   按 **q** 退出.
    

#### 5.findmnt

Findmnt 命令用于查找挂载的文件系统。它用来列出安装设备，当需要时也可以挂载或卸载设备，它是 util-linux 软件包的一部分。

例子:

```
1.  `$ findmnt`
    
```

![](../Images/06cb43d13bed415bd4200c483e7ad1be.png)

以列表格式输出。

```
1.  `$ findmnt -l`
    
```

![](../Images/abc7530e956401d555ff0a1df1e28232.png)

列出在 fstab 中挂载的文件系统。

```
1.  `$ findmnt -s`
    
```

![](../Images/2f32afed5fbbd844d94847e3e22ec1ab.png)

按文件类型列出已挂载的文件系统。

```
1.  `$ findmnt -t ext4`
    
```

![](../Images/c26d03f1172f6e0590131f4d79234d71.png)

#### 6\. dstat

一种灵活的组合工具，它可用于监控内存，进程，网络和磁盘性能，它可以用来取代 ifstat, iostat, dmstat 等。

```
1.  `$ apt-get install dstat`
    
```

例如:

查看有关 cpu，硬盘和网络的详细信息。

```
1.  `$ dstat`
    
```

![](../Images/4599417a8d71d5c8eaf58babe8305c64.png)

**\-c** cpu

```
1.  `$ dstat -c`
    
```

![](../Images/54c140a50ff983867cdcb08f403a561c.png)

**\-d** 磁盘

```
1.  `$ dstat -d`
    
```

![](../Images/0ee388205379632ce3fd00183c4806a5.png)

显示 cpu、磁盘等的详细信息。

```
1.  `$ dstat -cdl -D sda1`
    
```

![](../Images/71e760985dd2961503194feff6ac6494.png)

#### 7\. saidar

```

```

例如:

```
1.  `$ saidar`
    
```

![](../Images/56e27bfc580c288ab5ecb4154bbde9eb.png)

启用彩色输出

![](../Images/062768f8284842ced96d453e50d63320.png)

#### 8\. ss

ss（socket statistics）是一个很好的替代 netstat 的选择，它从内核空间收集信息，比 netstat 的性能更好。

例如:

列出所有的连接

```
1.  `$ ss |less`
    
```

![](../Images/a49c81b257f22b3c4712d43609227926.png)

列出 tcp 流量

```
1.  `$ ss -A tcp`
    
```

![](../Images/e215f3e04eb7a2bb6c2328225a4de2df.png)

列出进程名和 pid

```
1.  `$ ss -ltp`
    
```

![](../Images/5d04e1522711f683cbf2e897f0469583.png)

#### 9\. ccze

一个美化日志显示的工具 :).

```
1.  `$ apt-get install ccze`
    
```

例如:

```
1.  `$ tailf /var/log/syslog | ccze`
    
```

![](../Images/86497f7fad7b17697c3c1e686e6e548d.png)

列出 ccze 模块:

```
1.  `$ ccze -l`
    
```

![](../Images/39af4c3cf2823931661d2a186c1c9b69.png)

将日志保存为 html 文件。

```
1.  `tailf /var/log/syslog | ccze -h > /home/tux/Desktop/rajneesh.html`
    
```

![](../Images/4a755198680768a5db0caec8e468e550.png)

#### 10\. ranwhen.py

一种基于 Python 的终端工具，它可以用来以图形方式显示系统活动状态。详细信息以一个丰富多彩的柱状图来展示。

安装 python（LCTT 译注：一般来说，你应该已经有了 python，不需要此步）：

```
1.  `$ sudo apt-add-repository ppa:fkrull/deadsnakes`
    
```

更新系统:

```
1.  `$ sudo apt-get update`
    
```

下载 python:

```
1.  `$ sudo apt-get install python3.2`
    
```

点此下载 ranwhen.py

```
$ unzip ranwhen-master.zip && cd ranwhen-master
```

运行工具。

```
1.  `$ python3.2 ranwhen.py`
    
```
