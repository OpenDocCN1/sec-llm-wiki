### 引言

在本教程中，我已经收集了10个给 Linux 用户的有用工具，其中包括各种网络监控，系统审计和一些其它实用的命令，它可以帮助用户提高工作效率。我希望你会喜欢他们。

#### 1\. w

显示谁登录了系统并执行了哪些程序。

```
1.  `$ w`
    
```

![](../Images/f618333531d27275c06c45d4f56edbc2.png)

不显示头部信息（LCTT译注：原文此处有误）

```
1.  `$ w -h`
    
```

显示指定用户的信息

```
1.  `$ w <username>`
    
```

![](../Images/8432e030723ab95275b73ee8bf6f46bc.png)

#### 2\. nmon

Nmon（nigel’s monitor 的简写）是一个显示系统性能信息的工具。

```
1.  `$ sudo apt-get install nmon`
    
```

* * *

```
1.  `$ nmon`
    
```

![](../Images/bff7560b9b508f906b17d9bcd028a814.png)

nmon 可以显示与 netwrok，cpu, memory 和磁盘使用情况的信息。

**nmon 显示 cpu 信息 (按 c)**

![](../Images/d3dd7a5f5a44ef31b704fd5261b5ecbf.png)

**nmon 显示 network 信息 (按 n)**

![](../Images/3c9398a47091fbd2743839a72eb073c9.png)

**nman 显示 disk 信息 (按 d)**

![](../Images/5b191b327b8c37133ce58e75876f80b1.png)

#### 3\. ncdu

是一个支持光标的`du`程序，这个命令是用来分析各种目录占用的磁盘空间。

```
1.  `$ apt-get install ncdu`
    
```

* * *

```
1.  `$ ncdu /`
    
```

![](../Images/b89720dac478551ea4347c036a1f1873.png)

最终的输出:

![](../Images/59019d23c42aaa0a33879da3aefa0a40.png)

按 n 则通过文件名来排序，按 s 则按文件大小来排序（默认的）。

#### 4\. slurm

一个基于网络接口的带宽监控命令行程序，它会用字符来显示文本图形。

```
1.  `$ apt-get install slurm`
    
```

例如:

```
1.  `$ slurm -i <interface>`
    
```

* * *

```
1.  `$ slurm -i eth1`
    
```

![](../Images/6f6398f4937aa4cf11c3639632f4c654.png)

**选项**

*   按 **l** 显示 lx/tx 指示灯.
    
*   按 **c** 切换到经典模式.
    
*   按 **r** 刷新屏幕.
    
*   按 **q** 退出.
    

#### 5.findmnt

Findmnt 命令用于查找挂载的文件系统。它用来列出安装设备，当需要时也可以挂载或卸载设备，它是 util-linux 软件包的一部分。

例子:

```
1.  `$ findmnt`
    
```

![](../Images/e3f8f6d61714391e55b6dac88c32c92f.png)

以列表格式输出。

```
1.  `$ findmnt -l`
    
```

![](../Images/20a6e6965bb51fd8dd4d6a0736301eda.png)

列出在 fstab 中挂载的文件系统。

```
1.  `$ findmnt -s`
    
```

![](../Images/1a0ba27b507c23f3e41f5aba15f84172.png)

按文件类型列出已挂载的文件系统。

```
1.  `$ findmnt -t ext4`
    
```

![](../Images/ee5e9972d158637d84a87262337ac34e.png)

#### 6\. dstat

一种灵活的组合工具，它可用于监控内存，进程，网络和磁盘性能，它可以用来取代 ifstat, iostat, dmstat 等。

```
1.  `$ apt-get install dstat`
    
```

例如:

查看有关 cpu，硬盘和网络的详细信息。

```
1.  `$ dstat`
    
```

![](../Images/69504c617a984789f2fcf1124a6fd36a.png)

**\-c** cpu

```
1.  `$ dstat -c`
    
```

![](../Images/7827ae5b60ee1ef5e0a02f43c004f4af.png)

**\-d** 磁盘

```
1.  `$ dstat -d`
    
```

![](../Images/737fbe36ea04fda958e57775497bdd75.png)

显示 cpu、磁盘等的详细信息。

```
1.  `$ dstat -cdl -D sda1`
    
```

![](../Images/96c982f5c5732eabab3f59a1aa49a98b.png)

#### 7\. saidar

```
1.  `$ sudo apt-get install saidar`
    
```

例如:

```
1.  `$ saidar`
    
```

![](../Images/a2b9021e2963fad1596aeaac8d90fbc2.png)

#### 8\. ss

ss（socket statistics）是一个很好的替代 netstat 的选择，它从内核空间收集信息，比 netstat 的性能更好。

例如:

列出所有的连接

```
1.  `$ ss |less`
    
```

![](../Images/2dbfee3c071e869e2cd798851c77f1d2.png)

列出 tcp 流量

```
1.  `$ ss -A tcp`
    
```

![](../Images/760b3026b95396c7d871764e6f0e9e20.png)

列出进程名和 pid

```
1.  `$ ss -ltp`
    
```

![](../Images/332cbb00d92b6392b22467d5060005e5.png)

#### 9\. ccze

一个美化日志显示的工具 :).

```
1.  `$ apt-get install ccze`
    
```

例如:

```
1.  `$ tailf /var/log/syslog | ccze`
    
```

![](../Images/91f9902f130bf5b6b22780ae06b4c2bb.png)

列出 ccze 模块:

```
1.  `$ ccze -l`
    
```

![](../Images/8a82d8265ebdecce6f1a5ea5576e80fe.png)

将日志保存为 html 文件。

```
1.  `tailf /var/log/syslog | ccze -h > /home/tux/Desktop/rajneesh.html`
    
```

![](../Images/b2ac9de38d0b2d0ab9bf9ac4a7f6d70b.png)

#### 10\. ranwhen.py

一种基于 Python 的终端工具，它可以用来以图形方式显示系统活动状态。详细信息以一个丰富多彩的柱状图来展示。

安装 python（LCTT 译注：一般来说，你应该已经有了 python，不需要此步）：

```
1.  `$ sudo apt-add-repository ppa:fkrull/deadsnakes`
    
```

更新系统:

```
1.  `$ sudo apt-get update`
    
```

下载 python:

```
1.  `$ sudo apt-get install python3.2`
    
```

点此下载 ranwhen.py

```
$ unzip ranwhen-master.zip && cd ranwhen-master
```

运行工具。

```
1.  `$ python3.2 ranwhen.py`
    
```
