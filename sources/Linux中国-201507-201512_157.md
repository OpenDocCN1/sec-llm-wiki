# 全新 GNOME Games：一款应用驾驭所有游戏

当看到标题的时候，某些用户可能会纳闷 GNOME Games 不是早已经上线了吗，不过今天要介绍的 GNOME Games 是一款非常卓越的全新应用。有别于旧款应用，全新的 GNOME Games 声称收集了用户能够安装的所有游戏，而且还包含一些用户从未尝试过的游戏新作。

制作该新应用的目的就是通过一款简单的应用程序收集所有好玩的游戏并允许玩家非常轻松的将其安装到系统中。自然这个过程并不简单，开发者 Adrien Plazas 在博文中写道：“你是否喜欢视频游戏，但却不喜欢在个人计算机上享受游戏体验的时候遭遇各种不稳定和恼人的问题？那么请继续阅读，我有一些好东西要跟你分享。”

在安装这款应用之后，用户可安装 GNOME 软件、Steam、运行在模拟器上的复古游戏、网页游戏和其他游戏内容，值得注意的是用户需要在安装模拟器之后可运行 NES、SNES、Game Boy 和 PC-Engine 的游戏。
