# 优麒麟和搜狗发布搜狗输入法 Linux 版 2.0 版

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=400031840&idx=1&sn=aa9d1e7effe06ca9aafd0c261ed49bed&chksm=34c43b2603b3b2309fa35c9196748c0b2c5b144d142f0a2c5644ab7a6b9b4947d8227775f998&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=400031840&idx=1&sn=aa9d1e7effe06ca9aafd0c261ed49bed&chksm=34c43b2603b3b2309fa35c9196748c0b2c5b144d142f0a2c5644ab7a6b9b4947d8227775f998&scene=27#wechat_redirect)

经过开发和测试同学的辛勤劳动，由Ubuntu Kylin团队与搜狗公司联合开发的搜狗输入法Linux版于2015年10月16日正式发布2.0版本。

  

升级日志如下：

*   新增双拼支持；
    
*   修复少数情况下焦点跳动问题；
    
*   改进部分桌面环境兼容性；
    
*   修复新建覆盖词库不生效问题；
    
*   调整tab切换界面控件顺序。
    

Ubuntu Kylin用户可通过系统升级功能或Ubuntu Kylin软件中心自动完成搜狗输入法升级，也可以通过搜狗网站或Ubuntu Kylin网站下载安装。
