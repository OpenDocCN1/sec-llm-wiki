# Emacs 寻找新的维护者

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=209643078&idx=3&sn=b2f609a533124628003c4ba6f9e62ba1&chksm=2f62dd001815541626f3d21e54e9dcaf272daa5247cf8551db1feb89e31e1fe7ac1e1becbc7a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=209643078&idx=3&sn=b2f609a533124628003c4ba6f9e62ba1&chksm=2f62dd001815541626f3d21e54e9dcaf272daa5247cf8551db1feb89e31e1fe7ac1e1becbc7a&scene=27#wechat_redirect)

9月21日，借着Emacs-25特性冻结的机会，主维护者（head maintainer）Stefan Monnier宣布引退。

Emacs社区开始寻找新的带头人。Stefan Monnier推荐了另一个主力维护者Chong Yidong，还有资深开发者自我推荐。

Emacs作者RMS也借此强调了Emacs替代非自由软件的使命，认为**维护者不应该拒绝只能工作在类GNU系统下的特性，不应该要求“必须加入Windows和OSX支持**”。RMS说，这是向贡献者施压去使用私有系统，而即使只是建议用户使用私有系统也是不道德的。

RMS进一步阐述，Emacs维护者永远也**不应该要求贡献者使用MacOSX或iOS之类的私有系统**。详细的讨论请浏览Emacs开发者邮件列表。
