Pear OS 复活：仿 Mac OS X 界面的 Linux 系统出“新版”了

原文：http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=209616471&idx=4&sn=cf81d3f9a287683ad34b1bbfa8bcb25c&chksm=2f6245111815cc0749af51d9df5ed53ad52693ae7ba3e80e876efef73e770e44689c508b303c&scene=27#wechat_redirect

还记得曾经以界面像极了Mac OS X而知名的Linux发行版Pear OS吗？尽管这个梨子系统已经沉寂了多年，但是仍然有人对它念念不忘，并且推出了基于Ubuntu 14.04LTS的克隆版本。在SourceForge上，葡萄牙开发者Rodrigo Marques已经上传了新版Pear OS的Live DVD ISO镜像。

1.jpg

其采用了与Pear OS相同的理念，基于Ubuntu 14.04 LTS（Trusty Tahr）打造。

2.jpg

为了让界面看起来更像Mac OS X，Pear OS将所有主题图标都照搬过来了（尽管明眼人还是能感觉出微小的违和感）。

3.jpg

在预装应用中，新版Pear OS提供了LibreOffice办公套件、Chromium浏览器、BleachBit系统清理工具、Spotify客户端、Mozilla Firefox浏览器、Gedit文本编辑器、Shotwell镜像查看器、Transmission BT下载器、VLC媒体播放器、以及多款来自GNOME Stack的组件。
