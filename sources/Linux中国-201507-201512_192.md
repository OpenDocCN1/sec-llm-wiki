# Ubuntu 15.10将发布 采用 Linux Kernel 4.2内核

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=209616471&idx=3&sn=bae557d7c76c8943e5b0ed713b05b1b3&chksm=2f6245111815cc07c51fdeea3a3ff4529253a26da6fedf38c0b85a1439a843dfa63d501b7794&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=209616471&idx=3&sn=bae557d7c76c8943e5b0ed713b05b1b3&chksm=2f6245111815cc07c51fdeea3a3ff4529253a26da6fedf38c0b85a1439a843dfa63d501b7794&scene=27#wechat_redirect)

Ubuntu 15.10目前已经达成了最终内核的冻结，此后不会再有这方面的升级，仅会有一些BUG的修复。实际上Ubuntu的开发周期与Linux内核并不同步，所以通常都不会采用最新版的Linux内核。Ubuntu 15.10所用Linux内核为4.2版。

一项开发工程在进入冻结阶段以后，不管是软件栈和内核都不会再有升级，这能够让开发者更好地进行测试，为最终发布做好准备。Ubuntu经常采用某个特别分支的内核，并且会持续使用，即便此后有新版本发布也不会随意升级内核，至少不会对非LTS版的Ubuntu做这种升级。而Ubuntu LTS版通常总是在新版中升级内核。

在Ubuntu 15.10完成内核冻结之后，我们就不会再看到什么内核的变化了，实际上这在几周以前就已经确定，只不过今天才最终确认。

来自Canonical的Joseph Salisburty几天前就表示：“我们即将在10月8日达成Wily Werewoft 内核冻结Kernel Freeze，若还有针对15.10的补丁，请尽快提交。按照内核冻结的最终期限，所有补丁需要遵守我们的SRU策略，存在错过发布的可能。”

最终版本的Ubuntu 15.10（Wily Werewoft）预计将在10月22日正式面市。
