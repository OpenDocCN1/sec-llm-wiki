# 新手可能不喜欢轻量级 Linux 发行版的几个原因

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=209616471&idx=1&sn=62fb36ad859ba9e69aedfe839f15b27c&chksm=2f6245111815cc072f0bd49939479341dfa3db6234653d1634a0183a0c1fda9c37a9fb23fc63&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=209616471&idx=1&sn=62fb36ad859ba9e69aedfe839f15b27c&chksm=2f6245111815cc072f0bd49939479341dfa3db6234653d1634a0183a0c1fda9c37a9fb23fc63&scene=27#wechat_redirect)

市面上有数百个 Linux 发行版，用户往往根据日常任务来选择某一款 Linux 发行版。一些大受欢迎的 Linux 发行版有 Ubuntu、Debian 和 Fedora 等。在其他几篇文章中，我也建议用户在开始使用 Linux 时，不妨选择一款轻量级发行版。不过在这篇文章中，我要谈论轻量级 Linux 发行版以及为何轻量级 Linux 发行版很烦人。虽然使用轻量级 Linux 发行版有诸多好处，但是我遇到博客读者不断吐槽也是个不争的现实。

### **Linux 发行版**

Linux 最初是作为一款面向基于英特尔 x86 架构的个人计算机的自由操作系统而开发的，但后来移植到了更多的计算机硬件平台上，比其他任何操作系统都要来得广泛。由于 Linux 具有自由、开源的特性，Linux 源代码被全球各地成千上万的开发人员所使用和修改。任何开发人员都能下载 Linux 的源代码，并且修改它，用于各种用途：无论私用还是商用。现在，由于这么多的 Linux 发行版，新手选择哪个 Linux 可能很麻烦，但是多亏了许多博客写手，让这种选择过程变得很简单、很轻松。当然，我们希望 Linux 对新手用户和高级用户来说都易于使用。

### **针对特定用户的 Linux 发行版**

一些最受欢迎的 Linux 发行版包括 Ubuntu、Debian 和 Fedora。如果新手想采用 Linux，如果你上网搜索一番，极有可能获得这三款 Linux 发行版。但是，作为一名新手，他不会直接切换到这任何一款 Linux 发行版，因为其外观对 Windows 用户来说很陌生。但是新的 Linux 用户可以借助外面许多易于使用的 Linux 发行版，开始探究一番。

### **为何轻量级 Linux 发行版阻碍你学用 Linux?**

轻量级 Linux 发行版比较小巧。虽然通常 Linux 发行版的大小在 1GB 以上，轻量级 Linux 发行版的大小却只有 500MB 到 800MB，有些甚至比这还要小巧。之所以比较小巧，是由于操作系统中包含的程序包数量比较少。对高级用户来说，没有大量已安装的程序包不是一个问题，但是对新手来说，这可能是个问题。

用户在捣鼓 Linux 系统时，需要配置不同的应用程序；在 Linux 中，大多数程序包需要安装另外一些程序包（即所谓的依赖项）。简单来说，应用程序的依赖项必不可少；要是没有依赖项，应用程序就无法正常运行或根本无法安装。比如说，如果你安装 XDM（Xtreme 下载管理器），它就依赖 Java。如果没有安装 Java，XDM 也就安装不了。新用户会觉得这是系统的问题，但是这完全是用户系统没有的那个应用程序的要求。轻量级 Linux 发行版并没有安装数百个程序包，安装在轻量级发行版中的每个应用程序大概都需要依赖项。有时候，依赖项在官方软件库中能找到，但许多时候却找不到。如果依赖项就在软件库中，终端会自动下载并安装它，以便应用程序正常运行，但要是在其它地方，应用程序就安装不了。

### **那么，为什么轻量级 Linux 发行版会受人喜爱呢?**

从才使用了一天的 Linux 用户，到 Linux 极客和专业人士，Linux 发行版为特定类型的用户作了精心维护。开发轻量级 Linux 发行版的想法是，仅仅使用操作系统中的一些特定、最常见/最常用的应用程序。轻量级 Linux 发行版只有平常每个用户在其机器上装有的几个基本应用程序，比如说互联网浏览器、音频/视频播放器、文件管理器、Office 套件和图像查看器等。谁都可以只安装任何轻量级发行版，就能准备上网冲浪、处理办公工作和播放音乐等 。刚安装好后，轻量级 Linux 发行版也没有大量的更新版需要下载。

不过使用轻量级 Linux 发行版确实有许多优点，比如可以立即安装它，不需要下载大量更新，而且轻量级 Linux 发行版运行起来更快。我总是在自己的 PC 上使用轻量级 Linux 发行版，那样万一我的主发行版（Ubuntu）受到了损坏，我就能从轻量级 Linux 发行版来恢复自己的数据。

### **结束语**

从文章标题来看，读者可能认为我讨厌轻量级 Linux 发行版，实则不然。我平时使用轻量级 Linux 发行版，而且钟爱轻量级 Linux 发行版，我觉得轻量级 Linux 发行版运行起来比装有数千个程序包的其他发行版更快。但是新用户根本不想看到：只要安装任何应用程序，就碰到依赖项错误。要是这一幕屡屡上演，那实在是太烦人了。
