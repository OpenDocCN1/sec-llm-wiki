# Linus Torvalds：2016 会是“ARM 笔记本之年”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=209588745&idx=3&sn=30cc5ec478702153a9745016cfae8a52&chksm=2f62294f1815a059a901e8ccf8b1562031c3a0aa4919474d5c8445e50e3c33ed269e5dda4f35&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=209588745&idx=3&sn=30cc5ec478702153a9745016cfae8a52&chksm=2f62294f1815a059a901e8ccf8b1562031c3a0aa4919474d5c8445e50e3c33ed269e5dda4f35&scene=27#wechat_redirect)

在爱尔兰都柏林举办的 Linux 大会（LinuxCon 2015）上，Linus Torvalds 在演讲中谈到了很多事情，包括安全、以及 Linux 在 ARM 硬件上的愿景。最近一段时间，Linux 内核开发社区经历了一些动荡，并且有几位大牛因为各种问题和不满而离开了项目团队。除了指责 Linus，他们还特地选择了在 LinuxCon 2015 前离开，以便消息能够在大会期间更好的传播。

尽管没有被问到这类问题，但是 Linus 还是谈到了其它一些事情。他通常很少做演讲，而是接受采访、或者在问答环节和与会者互动。

不过在本届 LinuxCon 大会上，他回答了英特尔“Linux 和开源技术首席” Dirk Hohndel 提到的几个问题。

值得一提的是，Chromebook 正在全球逐渐普及，且大量设备都是在 ARM 处理器上运行的。有趣的是，许多 Chromebook 的买家根本不关心设备配备了哪种处理器，所以 ARM CPU 很快就蔓延了开来。

据 Linux.com 报道，Linus 在会上说到：

> 我很高兴见到 ARM 被不断推荐，总有一天，我会拥有一台采用 ARM 处理器的机器。如果不是今年，那或许就是明年。2016 将会是 Linux 笔记本之年！

此外，Linus 还解释了目前所面临的“寻找 Linux 内核维护人员”的切实问题。这不是一个带有荣耀光环的工作，通常只是在每周的几天时间里回答几封电子邮件而已。

然而要找到有适当技能、并且又恰好有时间从事这一工作的人手，却并非一件容易的事。（有关 Linus 演讲的完整内容请移步至Linux.com 查阅）
