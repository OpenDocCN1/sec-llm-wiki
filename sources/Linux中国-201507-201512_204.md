### 安装 Xenlism Wildfire

Xenlism Theme 大约有 230 MB, 对于一个主题来说确实很大，但是考虑到它所支持的庞大的软件数量，这个大小，确实也不是那么令人吃惊。

#### 在 Ubuntu/Debian 上安装 Xenlism

在 Ubuntu 系列中安装之前，用以下的命令添加 GPG 秘钥：

```
1.  `sudo apt-key adv --keyserver keys.gnupg.net --recv-keys 90127F5B`
    
```

添加完成之后，输入如下的命令进行安装：

```
1.  `echo "deb http://downloads.sourceforge.net/project/xenlism-wildfire/repo deb/" | sudo tee -a /etc/apt/sources.list`
    
2.  `sudo apt-get update`
    
3.  `sudo apt-get install xenlism-wildfire-icon-theme`
    
```

除了主题之外，你也可以选择是否下载配套的桌面背景图：

```
1.  `sudo apt-get install xenlism-artwork-wallpapers`
    
```

#### 在 Arch 上安装 Xenlism

你需要编辑 Pacman 软件仓库。在终端中使用如下命令：

```
1.  `sudo nano /etc/pacman.conf`
    
```

添加如下的代码块，在配置文件中:

```
1.  `[xenlism-arch]`
    
2.  `SigLevel = Never`
    
3.  `Server = http://downloads.sourceforge.net/project/xenlism-wildfire/repo/arch`
    
```

更新系统并且安装：

```
1.  `sudo pacman -Syyu`
    
2.  `sudo pacman -S xenlism-wildfire`
    
```
