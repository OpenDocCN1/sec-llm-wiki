# 在 CentOS 7 中安装并使用自动化工具 Ansible

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=209546915&idx=2&sn=977fc21ab6d0af41a0877f664bb72184&chksm=2f6155e51816dcf3952a9166fc5cdec40d4a403974c6df6f741b4d905d838fba739401029870&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=209546915&idx=2&sn=977fc21ab6d0af41a0877f664bb72184&chksm=2f6155e51816dcf3952a9166fc5cdec40d4a403974c6df6f741b4d905d838fba739401029870&scene=27#wechat_redirect)

Ansible是一款为类Unix系统开发的自由开源的配置和自动化工具。它用Python写成，类似于Chef和Puppet，但是有一个不同和优点是我们不需要在节点中安装任何客户端。它使用SSH来和节点进行通信。

本篇中我们将在CentOS 7上安装并配置Ansible，并且尝试管理两个节点。

*   **Ansible 服务端** – ansible.linuxtechi.com ( 192.168.1.15 )
    
*   **节点** – 192.168.1.9 , 192.168.1.10
    

### 第一步： 设置EPEL仓库

Ansible仓库默认不在yum仓库中，因此我们需要使用下面的命令启用epel仓库。

```
1.  `[root@ansible ~]# rpm -iUvh http://dl.fedoraproject.org/pub/epel/7/x86_64/e/epel-release-7-5.noarch.rpm`
    
```

### 第二步： 使用yum安装Ansible

```
1.  `[root@ansible ~]# yum install ansible`
    
```

安装完成后，检查ansible版本：

```
1.  `[root@ansible ~]# ansible --version`
    
```

![](../Images/8f1bd4a3f8fac6a39c0871159d5e51e1.png)

ansible-version

### 第三步： 设置用于节点鉴权的SSH密钥

在Ansible服务端生成密钥，并且复制公钥到节点中。

```
1.  `root@ansible ~]# ssh-keygen`
    
```

![](../Images/938553fbfac6695383ea0354fe3ab290.png)

ssh-keygen

使用ssh-copy-id命令来复制Ansible公钥到节点中。

![](../Images/31568d5cc4d02075e0d1005aa43807ae.png)

ssh-copy-id-command

### 第四步：为Ansible定义节点的清单

文件 `/etc/ansible/hosts` 维护着Ansible中服务器的清单。

```
1.  `[root@ansible ~]# vi /etc/ansible/hosts`
    
2.  `[test-servers]`
    
3.  `192.168.1.9`
    
4.  `192.168.1.10`
    
```

保存并退出文件。

主机文件示例如下：

![](../Images/788449703d6f922a249716bfdc8c8a35.png)

ansible-host

### 第五步：尝试在Ansible服务端运行命令

使用ping检查‘test-servers’或者ansible节点的连通性。

```
1.  `[root@ansible ~]# ansible -m ping 'test-servers'`
    
```

![](../Images/febd74573b8d5da2622678feeb2dec5f.png)

ansible-ping

#### 执行shell命令

**例子1：检查Ansible节点的运行时间（uptime）**

```
1.  `[root@ansible ~]# ansible -m command -a "uptime" 'test-servers'`
    
```

![](../Images/da95b7cbd6c44bc6611e04f08b1c2081.png)

ansible-uptime

**例子2：检查节点的内核版本**

```
1.  `[root@ansible ~]# ansible -m command -a "uname -r" 'test-servers'`
    
```

![](../Images/a27778be23dacdf43d47b4f5ec68d6e9.png)

kernel-version-ansible

**例子3：给节点增加用户**

```
1.  `[root@ansible ~]# ansible -m command -a "useradd mark" 'test-servers'`
    
2.  `[root@ansible ~]# ansible -m command -a "grep mark /etc/passwd" 'test-servers'`
    
```

![](../Images/199c787052cd0cd904e9e44e0a7d9ada.png)

useradd-ansible

**例子4：重定向输出到文件中**

```
1.  `[root@ansible ~]# ansible -m command -a "df -Th" 'test-servers' > /tmp/command-output.txt`
    
```
