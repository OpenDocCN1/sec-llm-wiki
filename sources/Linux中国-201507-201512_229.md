# Ubuntu 15.10 会从此摘掉“乏味的升级版”这顶帽子吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=209514893&idx=2&sn=ffc63c2a70fd1d01832b5fecc3bd6cd6&chksm=2f60cacb181743ddd56140acf62e8c1b6359e7456513b40481d3660d6af567f3765abdc33d1e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=209514893&idx=2&sn=ffc63c2a70fd1d01832b5fecc3bd6cd6&chksm=2f60cacb181743ddd56140acf62e8c1b6359e7456513b40481d3660d6af567f3765abdc33d1e&scene=27#wechat_redirect)

想必你也知道情况。在过去这几年，每个重要和次要的Ubuntu升级版可以说一直很乏味。除了不断听到“我们何时最终会看到Unity 8”这句话外，没啥好报道的。实际上，我都不记得上一次Ubuntu推出激动人心的升级版是何年何月了。这本身颇能说明我们消费者和技术人员所处的境地。我们实际上期盼着能出现一个激动人心的版本。要是某家公司或某个平台在升级版中根本没有激动人心的东西，这个产品自然失去了吸引力。

Ubuntu就是这副德性。尽管桌面的现状已经很完善、可谓熠熠生辉，它还是失去了相当多的人气。导致这个现象的一部分原因是，最近四次升级相当平淡乏味。

然而，所有这些乏味的版本却有一个很大的利好因素。该发行版很稳定；这正是Ubuntu在过去这几年一直保持的本色――它是地球上最稳定的发行版之一。

这种情况即将发生变化，既往好的方向变化，又往坏的方向变化。可以说，我们即将迎来最后一个乏味的升级版：Ubuntu 15.10。

客观地说，来自Canonical的这下一个升级版并不像前几个升级版那么乏味。实际上，Wily Werewolf拥有一些相当酷的特性。当然，那些出色的特性会完全被用户界面很显然缺少变化这个缺点所掩盖。然而，一旦你揭开那个可靠的用户界面，特性就开始显露无遗。不妨看一下。

### **1.内核4.2**

官方的Ubuntu版本老早就应该加入4.x内核阵营了。遗憾的是，该版本对版本4.3来说来得太早了。不过，从3.x内核到4.x内核的改进对桌面来说太大了。平时使用触控板的那些人会看到Linux处理硬件的方式得到显著改进。除了明显的改进外，4.2内核还包括AMD GPU驱动程序、F2FS文件级加密、NCQ TRIM处理、队列自旋锁及更多特性。

### **2.OpenStack Liberty**

Ubuntu 15.10会随带OpenStack云软件的最新稳定版。至少可以说，针对Liberty的新的和经过更新的特性数量多得惊人。想了解完整的特性，可以看一下官方软件发布说明。

### **3.无状态持久性网络接口名称**

Linux互联网接口名称采用eth0这种形式已有多久了？反正我记不起有多久了。然而，版本15.10发布后，这一切都会发生变化。接口的新名称将会更全面（因而更具描述性）。这一项新特性将由udev 220-6ubuntu2来处理，最初可能会引起一点困惑（尤其是长期以来一直使用eth0、eth1、wlan0的那些人）。

变化已出现，还是适应变化吧！

### **4.GNOME栈**

自15.10起，Ubuntu GNOME栈终于会升级到几乎最新的3.16.x版本。这一幕早就该出现了，因为GNOME栈的众多部分已得到了大大改进，而Ubuntu仍落在其后面，这导致发布的GNOME程序包缺少一些重大的改进。另一个好处是，Wily会随带一个新颖得多（并得到改进）的GTK。

### **5.滚动条**

你可能会惊讶地发现15.10版本中有一个实际的明显变化。Unity中的滚动条终于改为由GNOME团队开发的那种滚动条。这是迫切需要的一处改进，因为Unity滚动条始终似乎有点像是设计错误。

关于15.10的重大变化就说这么多了，对Ubuntu来说15.10是最后一个乏味的升级版。除此之外，情况会开始变得真正有意思起来，因为Unity 8/Mir这对组合终于开花结果。到时，结果还很难说。等16.04发布后，桌面会出现显著变化，我们多年来享受的这一切出色的稳定性很可能被抛到窗外，至少暂时是这样。
