# LibreOffice 诞生五周年

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=209507749&idx=3&sn=9e1ea3d810112438fe3ef96f7a178a7c&chksm=2f60eee3181767f53d8ec6bcdb65d183e9cb137dd78498ca174502120875d80e6857345292b2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=209507749&idx=3&sn=9e1ea3d810112438fe3ef96f7a178a7c&chksm=2f60eee3181767f53d8ec6bcdb65d183e9cb137dd78498ca174502120875d80e6857345292b2&scene=27#wechat_redirect)

作为OpenOffice.org的一个分支，LibreOffice诞生于2010年9月28日， 其成员来自于OpenOffice社区。在那个时候，创建开源办公软件的分支是一个勇敢而必要的行动，因为社区相信在甲骨文的管理下OpenOffice 不会活多长时间。

在The Document Foundation的名义下，16名创建者发起了一个独立的自由软件项目，去履行Sun在10年前作出的承诺。

5年之后，LibreOffice已被视为是微软办公软件的主要竞争对手。意大利国防部已经宣布将从今年10月起在起15台PC上安装LibreOffice。
