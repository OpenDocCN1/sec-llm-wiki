# 桌面/移动端 Ubuntu 将获重大 UI 升级

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=209507749&idx=1&sn=89951ba3f14a2d8ab95e8d6ce0e2e8bd&chksm=2f60eee3181767f539768e2717ac98588ebe3a6a4364610535bf47198e2f5a4f4378df9e2df4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=209507749&idx=1&sn=89951ba3f14a2d8ab95e8d6ce0e2e8bd&chksm=2f60eee3181767f539768e2717ac98588ebe3a6a4364610535bf47198e2f5a4f4378df9e2df4&scene=27#wechat_redirect)

Steph Wilson今天早些时候在博文中透露Canonica正为广受赞誉的Ubuntu Linux桌面操作系统和Ubuntu Touch移动系统设计全新用户界面。在博文中透露公司致力于创建最佳的用户体验，尤其希望吸引更多的用户加入Ubuntu Linux和Ubuntu Phone，Canonica认为是时候对操作系统的用户界面进行完全的颠覆。

![](../Images/154d9ead03e6db777a83c850895dc84c.png "Convergence.jpg")

让消费者获得跨平台统一使用体验

![](../Images/8309391443bc4df24de51cad32706fd1.png "photo_2015-09-28_14-24-17.jpg")

定义了两种屏幕：主屏幕（左）和次屏幕（右）

![](../Images/786d9e7e6e471a772d92a927c3189edc.png "photo_2015-09-28_14-29-46.jpg")

所有的对话尽可能进入全屏模式

![](../Images/6e292ff8c83d6ac3f0deca7211aaecf7.png "desktop-2.jpg")

桌面安装器也进行了改善和简化

对于当前Ubuntu系统的发展公司定位是婴儿蹒跚起步阶段，但毋庸置疑的是所迈出的每一步都更加的坚定和踏实啊。在新用户界面上，语言设定、网络配置、时区调整、锁屏选项都得到了重新设计，与此同时，桌面版安装器也进行了改善和简化。

Steph Wilson表示：“我们坚信第一印象非常的重要，尤其是向用户首次介绍新产品。我们致力于在产品打开的时候有给人眼前一亮的感觉，通过设置向导来帮助用户非常易用的开始使用他们的新手机。”
