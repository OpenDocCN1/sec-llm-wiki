# DaoCloud 企业级容器技术峰会【上海站】

以 Docker 为代表的容器技术正在以一种不可阻挡的趋势席卷全球，其最大的过人之处在于统一了云端应用的交付方式，从而给企业 IT 转型带来变革性的思路，赋予企业 IT 以快速交付和持续创新的能力。2015年旧金山全球 Docker 开发者大会的主旋律定位为「进军生产环境」，可见容器技术正在成为企业 IT 投入和转型的重点。

作为业界领先的企业级容器云平台和解决方案提供商，DaoCloud 已经为金融、政府、制造、电信等行业客户提供容器技术的咨询服务和 IT 解决方案。为帮助更多行业客户及合作伙伴借助容器技术实现 IT 和业务转型，DaoCloud 将于2015年10月16日在上海国际会议中心举办主题为「变革应用交付，推动持续创新」的企业级容器技术峰会。

DaoCloud 诚邀您共同见证容器和企业 IT 的未来!

### 时间地点

时间：2015年10月16日 13:00-18:00

地点：上海国际会议中心长江厅（上海浦东新区滨江大道2727号）

### 大会亮点

*   亮点一：首次聚焦容器技术在企业级场景的应用实践
    

DaoCloud 企业级容器技术峰会首次聚焦金融、政府、制造等行业用户的需求，探讨容器技术如何帮助企业实现 IT 和业务的双转型。

*   亮点二：行业先行者现身说法，实战经验全面分享
    

DaoCloud 将邀请行业先行者，包括著名商业银行架构师、P2P 金融公司 CTO、金融大数据平台架构师等 DaoCloud 产品用户，现场分享他们基于容器技术重塑企业 IT 的实战经验。

*   亮点三：与数百位技术专家现场交流 
    

本次活动通过定向邀请和报名筛选的方法，聚集数百位来自全国各地的各行业的企业 IT 高管和专家，共同探讨容器技术的企业应用场景。

*   亮点四：加入 Container+ 联盟，与 DaoCloud 共赢容器时代新商机 
    

DaoCloud 希望能够通过 Container+ 联盟，联合更多产业链上下游的合作伙伴，共同为企业用户提供基于容器技术的云计算解决方案。
