# “叛逃”Windows:印度政府计划使用基于Debian的BOSS系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=209402614&idx=2&sn=f53baf050da38a4404f7ffdb299d037c&chksm=2f6701b0181088a69b2304a37b02cac0ffd512b44fd393c215d84596ead08c166bdd80df5650&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=209402614&idx=2&sn=f53baf050da38a4404f7ffdb299d037c&chksm=2f6701b0181088a69b2304a37b02cac0ffd512b44fd393c215d84596ead08c166bdd80df5650&scene=27#wechat_redirect)

受棱镜监控丑闻和政府网站受黑客攻击影响，印度政府计划“逃离”Windows系统，降低和停止对微软产品的依赖程度。援引DnaIndia.com网站报道，印度政府逐渐脱离对微软产品的依赖，将会使用名为“BOSS”（Bharat操作系统解决方案）的操作系统，目前主要由高级计算研发中心负责研发工作，过程中获得了古吉拉特技术大学和印度国防研究与发展组织(DRDO)的支持。

这听上去是一件好事，但事实上实际操作过程中会存在各种问题。该系统使用GNOME作为桌面环境，所以和Windows用户之间的交互会成为比较严重的问题，除非团队对其进行重大更新。

团队的目标是使用这款全新基于Linux的系统来全面驾驭包括军队在内政府所有工作，这无疑是一个艰巨的任务啊。开发者已经对该系统进行了削减和修改，但是真正应用到政府工作中依然需要很多的调整。
