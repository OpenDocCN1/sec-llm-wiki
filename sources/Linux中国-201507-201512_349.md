# 微软爱 Linux，微软资助 Linux 峰会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=209158662&idx=1&sn=357134407398baf25716ee326478307b&chksm=2f6bb940181c305692d6e1462e36da5f5f40f60a51062c7019171896c0754abf9fcc84b6f32c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=209158662&idx=1&sn=357134407398baf25716ee326478307b&chksm=2f6bb940181c305692d6e1462e36da5f5f40f60a51062c7019171896c0754abf9fcc84b6f32c&scene=27#wechat_redirect)

LinuxCon北美峰会在美国西雅图举行，这次峰会与往年一个明显的不同是：在一群群企鹅中间闪耀着软件巨人的身影，微软再次向世界宣布它爱Linux。

LinuxCon的赞助商除了我们熟知的几家公司如Red Hat、SUSE、IBM、英特尔和惠普外，还有微软，而会议最热门赠品之一印有“微软爱Linux”的文字——微软在宣传它的云计算服务支持Linux系统。对着拿微软赠品的人，一位与会者喊道，“不要拿它，你可能会得癌。”
