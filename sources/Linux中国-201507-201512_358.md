# 中国、俄罗斯的高科技巨头加入全球开源项目

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=209130796&idx=2&sn=30cf56c2509acdd1d2fcb886b2caf965&chksm=2f6b2e6a181ca77c73792385fea570fdcacd21f21843da527ce44a2f08fa09466f40a72fcfba&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=209130796&idx=2&sn=30cf56c2509acdd1d2fcb886b2caf965&chksm=2f6b2e6a181ca77c73792385fea570fdcacd21f21843da527ce44a2f08fa09466f40a72fcfba&scene=27#wechat_redirect)

来自中国和俄罗斯著名的高科技公司正在大踏步进入全球技术界的心脏地带。

阿里云，阿里巴巴旗下的云计算品牌，已经成为 Xen 项目顾问委员会的成员，成为了流行的开源 Xen 管理程序制造商。

Xen 说阿里云“已经开始修复漏洞有段时间了。”

Xen 项目顾问委员会成员有权力去“提出并投票表决 Xen 项目和验证基础设施的修改和补充”，可以成为项目的领导者并且可以“共享技术和市场上的优先权，批准项目的新战略。”而财政捐款则不是必须的。

Citrix、Google、CA、AWS、Oracle、Intel、Rackspace、ARM、NetApp、AMD 和 Linux 基金会也是委员会的成员。

阿里巴巴向董事会反映了他们在电子商务和云计算领域的 Xen 使用规模。毫无疑问的是，阿里巴巴有很多 Xen 应用案例可以向其他委员会成员和大众分享。

同时，在 OpenBSD 基金会，他们还得去银行兑现来自俄罗斯顶级的网络服务商 Yandex 的支票。Yandex 模仿的是 Google：它的搜索引擎占领了俄罗斯的搜索市场，同时也经营着邮件和地图服务，并且提供了浏览器和广告服务。

阿里巴巴和 Yandex 加入这些开源组织是为了建立技术生态系统并减少对美国科技公司的依赖。中国和俄罗斯在斯诺登事件发生后更加关注安全问题，这是他们更加依赖本土技术的原因。他们的科技巨头和美国的公司都加入了全球组织，技术隔离看起来更难实现了。
