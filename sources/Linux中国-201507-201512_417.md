### 简介

MyCli 是一个 MySQL 命令行工具，支持自动补全和语法高亮。也可用于 MariaDB 和 Percona。

### 安装

如果你已会安装 Python 包，那就简单了：

```
1.  `$ pip install mycli`
    
```

  
如果你是在 OS X 平台，那就用 homebrew：

```
1.  `$ brew install mycli`
    
```

如果你看了上面的还不会，那就戳这里看详细安装步骤。

### 用例

```
1.  `$ mycli --help`
    
2.  `Usage: mycli [OPTIONS] [DATABASE]`
    
3.  ` `
    
4.  `Options:`
    
5.  `  -h, --host TEXT         Host address of the database.`
    
6.  `  -P, --port TEXT         Port number to use for connection. Honors`
    
7.  `                          $MYSQL_TCP_PORT`
    
8.  `  -u, --user TEXT         User name to connect to the database.`
    
9.  `  -S, --socket TEXT       The socket file to use for connection.`
    
10.  `  -p, --password          Force password prompt.`
     
11.  `  --pass TEXT             Password to connect to the database`
     
12.  `  -v, --version           Version of mycli.`
     
13.  `  -D, --database TEXT     Database to use.`
     
14.  `  -R, --prompt TEXT       Prompt format (Default: "\t \u@\h:\d> ")`
     
15.  `  -l, --logfile FILENAME  Log every query and its results to a file.`
     
16.  `  --help                  Show this message and exit.`
     
```

### 示例

```
1.  `$ mycli local_database`
    
2.  `$ mycli -h localhost -u root app_db`
    
3.  `$ mycli mysql://amjith@localhost:3306/django_poll`
    
```
