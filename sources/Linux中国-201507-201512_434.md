# 《Google 开源项目风格指南》中文版

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=208849656&idx=4&sn=d7e9fed8952f90c7f2af3cca35814a16&chksm=2f6ef1be181978a8175102c211031056f5dd5b3e323de92c379b3d06a457193331c6e678b0d1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=208849656&idx=4&sn=d7e9fed8952f90c7f2af3cca35814a16&chksm=2f6ef1be181978a8175102c211031056f5dd5b3e323de92c379b3d06a457193331c6e678b0d1&scene=27#wechat_redirect)

每个较大的开源项目都有自己的风格指南： 关于如何为该项目编写代码的一系列约定 (有时候会比较武断)。当所有代码均保持一致的风格， 在理解大型代码库时更为轻松。

“风格” 的含义涵盖范围广， 从 “变量使用驼峰格式 (camelCase)” 到 “决不使用全局变量” 再到 “决不使用异常”。 英文版项目维护的是在 Google 使用的编程风格指南。 如果你正在修改的项目源自 Google， 你可能会被引导至英文版项目页面， 以了解项目所使用的风格。

> 项目地址：http://zh-google-styleguide.readthedocs.org/ 

本项目并非 Google 官方项目， 而是由国内程序员凭热情创建和维护。如果你关注的是 Google 官方英文版， 请移步 Google Style Guide。

已经发布了四份 **中文版** 的风格指南:

1.  Google C++ 风格指南
    
2.  Google Objective-C 风格指南
    
3.  Google Python 风格指南
    
4.  Google JSON 风格指南
    

本项目的仓库地址： https://github.com/zh-google-styleguide/zh-google-styleguide 欢迎更多志愿者参与。
