# 微软因“重大捐款”收到OpenBSD的感谢

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=208015673&idx=2&sn=741fd6c7a6fd09a5698e3d92256a1c26&chksm=2f7a2a7f180da36915df616dd1bbb973e19585b0c08e28b22ef38a4c05a3e6d45cc6634493e2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=208015673&idx=2&sn=741fd6c7a6fd09a5698e3d92256a1c26&chksm=2f7a2a7f180da36915df616dd1bbb973e19585b0c08e28b22ef38a4c05a3e6d45cc6634493e2&scene=27#wechat_redirect)

微软向OpenBSD捐了一笔数量可观的善款， 成为2015年度首位“金牌贡献者”。

  

OpenBSD Journal写道：“OpenBSD基金会非常高兴收到来自微软的重大捐款，这对基金会意义非同寻常。该捐款是对基金会在OpenSSH工程中所做贡献的认可。 这笔捐款也使微软成为2015年度OpenBSD基金会的首位金牌贡献者。”
