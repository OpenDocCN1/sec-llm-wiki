# 借助 Evolution Linux 的帮助来轻松安装 Arch Linux

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607345&idx=3&sn=8673bf4eb8de272cb49eb213d7d82d8c&chksm=bdce95378ab91c2123c6a65781adc1b6354d1b04b6631f6b3bb5d46e801199c71f2184d031c1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607345&idx=3&sn=8673bf4eb8de272cb49eb213d7d82d8c&chksm=bdce95378ab91c2123c6a65781adc1b6354d1b04b6631f6b3bb5d46e801199c71f2184d031c1&scene=27#wechat_redirect)

Arch Linux 是一个简单、轻量级、适合计算机水平较高用户使用的发行版，它允许用户通过自定义来打造属于自己的桌面系统。

Arch Linux 的安装对于普通用户来說一直很难。不过，国外有大神为 Arch Linux 的安装进行了优化，提供了更方便的安装方式，这就是 Evolution Linux 项目，其官网是： http://www.evolutionlinux.com/ 。

![](../Images/5f6b28ea74ba961ea55c5adf08e1c4b5.png)

以下为个人理解，供大家参考。

国外大神提供的这个名为 makeiso 的工具有几点很好！

1.  makeiso 提供了图形化界面。即在终端界面输入 startx 可以进入图形化界面。
    
2.  makeiso 提供了图形化的分区界面。
    
3.  makeiso 提供了多工作模式。
    
4.  makeiso 提供了浏览器。
    
5.  makeiso 提供多设备支持。优化了很多架构。
    
6.  makeiso 拥有很大的软件包仓库，括开源和闭源，拥有[黑客发行版本BlackArch Linux](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401431448&idx=1&sn=cc63ef92e614ed68e9ef61e127b7176e#rd)。
    

00x0 准备工作(需要选择最快的镜像)

因为在国内访问国外源的速度很慢。所以在安装之前我们需要设置一下国内的镜像地址。地理位置选择 China，就会自动选择对应的镜像网站。镜像列表： https://www.archlinux.org/mirrorlist/ 。

复制完成以后用 `pacman -Syy` 设置缓存。

编辑 `/etc/pacman.d/mirrorlist` 取消要测速镜像前的注释。

![](../Images/5afc37d14c0663ac973385347f8ba6d5.png)

00x1 初始化磁盘

```
1.  `fcfdisk /dev/sda`
    
2.  `mkfs.ext4 /dev/sdax`
    
3.  `mount /dev/sdax /mnt/boot`
    
```

需要注意 swap 命令：

```
1.  `mkswap /dev/sdax`
    
2.  `swapon /dev/sdax`
    
```

![](../Images/1d136fe6e97e9030f357fbadcd1c4564.png)

00x2 基础安装

安装 arch 的核心部分，bios 就不说了是用来引导的。大家可以去 /mnt 查看是否多出什么东西。

```
1.  `pacstrap /mnt base base-devel grub-bios`
    
```

将当前分区信息放入安装系统中：

```
1.  `genfstab -p /mnt >> /mnt/etc/fstab`
    
```

切换至安裝的系統目录：

```
1.  `arch-chroot /mnt`
    
```

进入安装系统内部：

```
1.  `useraddd -m -g users -s /bin/bash rabbit　　 ###用户设置`
    
2.  `mkinitcpio -p linux 　　　　　            　　 ###启动设置`
    
3.  `grub-install --target=i386-pc /dev/sda bios　###引导设置`
    
4.  `grub-mkconfig -o /boot/grub/grub.cfg`
    
```

第一次重启（注意退出 chroot 环境） makeiso 任务完成：

![](../Images/84a4ad0d8c6e9f1fe6ae47acdf4c650f.png)

00x3 系统设置

主机名设置

```
1.  `hostnamectl set-hostname iterlinux`
    
```

sudo 权限设置

```
1.  `nano /etc/sudoers`
    
```

启用网络（注意 Arch Linux 中是 dhcpcd）

```
1.  `systemctl enable dpcpcd(start)`
    
```

第二次重启（主要是提供网络，Arch Linux 高度依赖网络）

00x4 GUI设置

开源的 GUI 显示服务

```
1.  `pacman -S xorg xorg-xclock xorg-xinit xterm xorg-server-utils xorg-twn`
    
```

![](../Images/8ef3fa44c2efde06e56e6fefca433626.png)

桌面管理器（很重要，必須自启动）

```
1.  `pacman -S sddm cinnamon`
    
```

第三次重启（注意图形化设置是否正确）

![](../Images/59ceefbf847084140d2a4a6e98eb0e10.png)

00x5 字体设置

```
1.  `pacman -S ttf-freefont wqy-microhei ttf-dejavu ttf-droid cantarell-fonts adobe-source-han-sans-cn-fonts`
    
```

00x6 自定义软件

```
1.  `pacman -S fcitx fcitx-im fcitx-configtool xfce4-terminal nano chromium docky gedit leafpad net-tools tcping virtualbox docker chromium shadowsocks  `
    
```

这里介绍下自定义软件：

*   fcitx fcitx-im fcitx-configtool 输入法架构（同样的还有 ibus）
    
*   xfce4-terminal 终端界面（我熟悉的界面，类似 ubuntu、mint）
    
*   nano 文件管理器
    
*   chromium 谷歌浏览器
    
*   docky 类同 OSX 的辅助栏
    
*   gedit 文本输入器
    
*   leafpad 文本输入器（win 风格）
    
*   net-tools （基础网络组建包，包括了 ifconfig netstat route）
    
*   tcping (探测网络端口)
    
*   virtualbox （虚拟机）
    
*   docker （集装箱）
    
*   shadowsocks （ss）
    

 

敬请享受它吧，ArchLinux ~
