ZFS for Linux 进入 Debian 软件库

继 Arch Linux、Ubuntu、Fedora、Gentoo、Red Hat Enterprise Linux、CentOS 和 openSUSE 等发行版之后，Debian GNU/Linux 的软件库正式加入了 ZFS For Linux[1]，为操作系统提供原生的 ZFS 文件系统支持。

Debian 的不稳定通道加入的 ZFS For Linux 版本是 zfs-linux 0.6.5.6-2[2] 并不是最新上游版本，最新版本是 0.6.5.7[3]。Debian 对 ZFS 的支持算得上比较晚了，上个月发布的 Ubuntu 16.04 LTS 加入了对 ZFS 的正式支持[4]，而 Debian 的 ZFS 实现看起来借鉴了很多来自 Ubuntu 的实现。
