Ubuntu 手机平板迎来 Dash Browser

今天更新的 Google+ 动态[1]中，来自 Canonical 的开发者 David Callé 宣布为 Ubuntu Touch 移动系统的 Scopes 功能带来两款全新标签化设计的两款模型，并已经在社区上邀请有兴趣的用户进行尝鲜体验。

4465.jpg

针对 Ubuntu 16.10 的 Ubuntu 在线峰会2016的环节之一，部分 Ubuntu Touch 的开发者（包括 David Callé 等人）共同上线参与了名为“Scopes 设计演变”的在线环节。

Ubuntu Scopes 功能最大的特点是将 APP 与内容数据进行了剥离，按照屏幕界面主题分类提供来自多种渠道源的内容信息。用户可以直接在主屏幕上查看了解包括音乐、视频、新闻、社交、生活服务等多种信息。比如在新闻主题界面下，用户不用像以前只能单独点开单个媒体 APP 浏览新闻，而是将来自不同媒体机构的新闻报道直接以瀑布流形式呈现在界面上。

在 “NearBy” 的界面中，通过定位功能可以呈现用户所在地的天气、交通以及推荐附近吃喝玩乐的地方，也省去了点开不同 APP 并进行切换的麻烦。而在 “Today” 的界面中，会呈现用户经常使用的功能或经常需要查找了解的信息。

此外，Ubuntu Scopes 彻底省去了按键的命令设置，用户只需要在手机上下左右四个边界上 “滑动” 就可以出现不同类型的功能区，操作更加方便。因此，在用惯了安卓、看惯了 IOS 系统后，Ubuntu Scopes 这种 “快速视觉化” 的方式带给用户一种全新的体验感。

David Callé 表示 Ubuntu Touch 团队目前正致力于为 Scopes 推广名为 “Dash Browser” 的新功能，基本上就是将 Scopes 放到一个标签浏览器中便于访问。Dash Browser 具备丰富的自定义内容，此外团队也确认将会为更老的 Scopes 提供全新的视觉风格。

[2]

此外还有很多丰富的其他功能将会在年底之前（大概在未来6个月内）登陆 Ubuntu Touch 移动系统，除了 Dash Browser 和视觉风格重新调整之外，还包括 Scope 过滤器、全新的的搜索图标、多面板布局，Scope 预览和 Scope 卡片等等。
