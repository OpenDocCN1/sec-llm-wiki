# Ubuntu 16.04 LTS 现已正式支持 IBM LinuxONE 与 z Systems

> 4月22号的时候，Canonical 很高兴地宣布了 Ubuntu 16.04 LTS（Xenial Xerus）已正式支持 IBM z Systems 和 LinuxONE 大型机的消息。

该长期支持版本经历了六个月的开发，并且已经在4月21号那天正式发布了面向桌面、服务器和云端的 64位（amd64）、32位（i386）、ARM64（AArch64）、ArmHardFloat（armhf）、以及 PowerPC Little Endian（PPC64el）架构的版本。

![](../Images/8237de5e1ff66ce267f30c653ddbd07b.png "20160423 Canonical Ltd - Twitter.jpg")

*20160423 Canonical Ltd - Twitter.jpg*

今天，Canonical 隆重地宣布了 Ubuntu 16.04 LTS 的 s390x 移植版。它可以安装到 IBM 的 z Systems 和 LinuxONE 服务器上，为开发者和系统管理员提供了理想的云计算平台选择，包括OpenStack云部署。

虽然每个人都可以免费下载\[1\]面向 s390x 硬件架构的 Ubuntu 16.04 LTS Server 的 ISO 镜像，但 Canonical 给该操作系统的定价则是每年 19500 美元，并且提供24×7的 Ubuntu Advantage Advanced 支持、可靠性修复、以及定期安全更新服务。

如果你有兴趣在 IBM LinuxONE 和 z Systems 上运行 Ubuntu 16.04 LTS，可以注册\[2\]参加4月27号举办的“Discover the Cloud and Scale Out World of Ubuntu on IBM”网络研讨会。
