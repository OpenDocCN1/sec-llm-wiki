# 美国防部盛赞 Windows 10 的安全性，甚至建议雇员在家也安装 Windows 10

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607131&idx=1&sn=1967216e9a1191e9315431d3179479bd&chksm=bdce96dd8ab91fcbb6567339490bb91159b1b6fc1897ea4ded0d2036d0831d33ebffdef39bc5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607131&idx=1&sn=1967216e9a1191e9315431d3179479bd&chksm=bdce96dd8ab91fcbb6567339490bb91159b1b6fc1897ea4ded0d2036d0831d33ebffdef39bc5&scene=27#wechat_redirect)

微软 Windows 10 操作系统已经得到非官方的最大背书。这个背书来自其最大最重要的客户之一 - 美国国防部。美国国防部CIO（首席信息官） Terry Halvorsen 周五在一次新闻发布会上称赞了微软 Windows 10 操作系统。Terry Halvorsen 一直是美国国防部当中 Windows 10 操作系统最坚定的推手之一，并列举了 Windows 10 的两个优势，即 Windows 10 即装即用的安全性以及对云计算友好的 Azure 服务。

![](../Images/42284cb57eb691b4ce66d1e6f957fc76.png)

事实上，Windows 10 将成为美国国防部史上第一款有如此背书的操作系统。Terry Halvorsen 的名言是：“如果你在家里使用一台非 Windows 10 电脑，你就是对自己不公平，你应该迁移到 Windows 10。”

Windows 10 与 Azure 的紧密结合，也将让国防部的各种服务和机构设立安全且集成通信的独立云。Terry Halvorsen 对Windows 10 的热情，似乎已经说服了国防部关键人物，因为其中四大军事部门和机构，都准备在一年之内过渡到 Windows 10。

虽然2017年1月31日的最后期限可能听起来过于紧张一些，五角大楼的首席技术官似乎相信，至少国防部所有主要网络都将升级 Windows 10，大约占升级量的80%。
