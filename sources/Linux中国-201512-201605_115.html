每日开源新闻速递(2016/4/17)：不需要浏览器插件就可以运行 Skype 了

原文：http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607131&idx=2&sn=bd7d70cc5b278cfbd6eb12178479c858&chksm=bdce96dd8ab91fcb1553d7ea8da672fbb9b265476527bae18b5f1a2d917cb56823c1906b48c5&scene=27#wechat_redirect

  • 微软宣布在 Edge 浏览器中现在不需要下载安装任何插件就可以运行 Skype 了，这是通过内置的 ORTC 引擎实现的。此外，微软还说 Skype 将会支持更多的浏览器，包括 Google Chrome 和 Mozilla Firefox，这意味着在 Linux 平台上也将可以通过这些浏览器使用。

  • KDE 5.7 中的音量控制器将有大幅改进[1]，可以支持超过 100% 的音量调整。

  • Parsix GNU/Linux 8.0 (Mumble)[2] 结束支持期，它是一个基于 Debian 8.0 的发行版。建议尽快升级到 8.5，而它的 8.10 版本将在今年稍晚时候发布，到时候会配上 GNOME 3.20 环境。

  • 开源的多平台音乐播放器 Clementine 1.3 发布了最终版本，带来了大量更新。

  • Slackware 14.2 RC2 发布，寻找更多公测志愿者[3]。
