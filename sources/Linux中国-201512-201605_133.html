Linux 中国：每日开源新闻速递（2016/4/12）

原文：http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=417094798&idx=2&sn=09f3a2c7afb8ac9e24f254599beec808&chksm=3bc067c80cb7eedee219e89d7f5ab79fa9052071fcc7870865bb6b09554b02151b638919f01c&scene=27#wechat_redirect

  • 两位 Google 开发者向 W3C 提交了一份新的草案  WebUSB API[1]，可以使网页能直接操作 USB 设备，之前发布的 USB 设备不需要更新固件即可支持该 API。

  • 趋势科技的研究人员发现一种基于 JavaScript 的恶意软件 JS_JITON[2] 可以攻击路由器的 DNS 设置，大多数受感染的设备在 台湾（27%）、日本（20%）和中国（13%）、美国（8%）。

  • Mozilla Firefox 45.0.2 发布[3]，这是一个小的更新版本，修复了上个版本以来的五个 bug。

  • Linux 内核 4.6 发布 RC3 版本，已经可以下载[4]了。

  • Canonical 上周刚刚发布的 Ubuntu Touch OTA-10 发布了其第一个热修复 OTA-10.1，而 OTA-11 预计要在 Ubuntu 16.04 LTS 发布之后才会揭晓

  • Arch Linux 的用户们已经可以率先尝鲜三周前刚刚发布的 GNOME 3.20 了。

  • BQ 在几周后即将交付的 Ubuntu 平板现在仍然可以预定[5]。

  • Canonical 与 OpenSDS (

    开源驱动的软件定义存储Open Source-driven Software-Defined Storage

    )的著名开发公司 Nexenta[6] 达成合作，本次合作预期会显著提升 ZFS on Ubuntu 的性能。

  • 最新发布的 Unity Tweak Tool[7] 0.0.7 支持将 Unity 启动器放到屏幕底部，不需要再通过命令行来完成该设置调整了。

  • 来自 heise[8] 的消息，微软 Windows VISTA 将在一年后（2017/4/11）结束其支持期。

采编自： SoftPedia[9] 等。
