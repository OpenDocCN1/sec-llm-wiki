# Mozilla 新的浏览器项目基于 Chromium，这是要步 Opera 的后尘吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=417094798&idx=3&sn=52125c30c0c6e375a305117bb562ab6e&chksm=3bc067c80cb7eede1e5a68da4596e08f6b140ec3a1a13d303293e73bc069d3216d23837901a7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=417094798&idx=3&sn=52125c30c0c6e375a305117bb562ab6e&chksm=3bc067c80cb7eede1e5a68da4596e08f6b140ec3a1a13d303293e73bc069d3216d23837901a7&scene=27#wechat_redirect)

> 编译自：http://www.cnet.com/news/a-nail-in-the-coffin-for-firefox-mozilla-struggles-to-redefine-browser/   
> 作者： Stephen Shankland  
> 转载自：CNBETA http://www.cnbeta.com/articles/491491.htm

周五，Mozilla 公布了新的项目 Tofino\[1\]，在很多人听来，似乎是敲响了 Firefox 的丧钟。

实则不然，该项目名为 Tofino，却的确是对 Firefox 发起了挑战——至少还有大量用户在使用 Firefox 浏览器，即便相比谷歌的 Chrome，Firefox 正越来越暗淡。

![](../Images/022539d504429cfe74d2870188f287f9.png)![](../Images/31f41f1a1af088f559c6b6e6164b4126.png)

Mozilla 周五公布了有关 Tofino 项目的细节，并且提到 Mozilla 已经有个6人团队要考虑如何颠覆 Web 浏览器了。Firefox 项目高级副总裁 Mark Mayo 在 Project Tofino 博客\[2\]的首篇博文中提到：“我们对浏览器的要求，自 Firefox 1.0开始就变了很多。而某些新鲜的特性早就该有了。”

Tofino 这次并没有采用 Firefox 的核心技术 Gecko，而是使用名为 Electron 的外部项目，它建立于谷歌 Chromium 之上。这其实的确是让人颇感意外的，其意外程度就如同苹果宣布用 Android 来测试 iPhone 新界面一样。

当然了，现在 Mozilla 仍然很坚定地支持 Firefox 及其核心。不过 Tofino 团队决定将更快地推进工作，这也表明了在追赶 Chrome 的道路上，Mozilla 还是相当努力。但这对 Firefox 用户而言恐怕不是什么好的说法，虽然 Firefox 已经不似当年那般荣光，却依然在 web 界拥有一席之地。Firefox 团队帮助构建和扩展新的技术标准，让 Web 更快，另外还为之赋予了各种新的功能，如在线聊天、游戏，甚至虚拟现实。

Mayo 当然很清楚，Tofino 必然引来很多争议，甚至会让人认为 Mozilla 将抛弃 Gecko，犹如另外一家浏览器制造商 Opera 那样转而选择 Chromium。据说来自 Mozilla 内部的阻力也很大。

要考量 Chrome 现如今的强大，可以列举一堆浏览器产品都建立于 Chromium，不光是 Opera：韩国的三星、俄罗斯搜索巨头 Yandex、中国的百度、挪威初创企业 Vivaldi，还有更有趣的，由 Mozilla 联合创始人、前首席执行官 Brendan Eich 创立的初创公司 Brave Software。

![](../Images/76b2db3019d4e26fb17189a660115637.png "来自 StatCounter 的数据，当前 Chrome 的浏览器市场份额为 47%，Safari 以 13% 排在第二，Firefox 第三 9%")

*来自 StatCounter 的数据，当前 Chrome 的浏览器市场份额为 47%，Safari 以 13% 排在第二，Firefox 第三 9%*

实际上，Mayo 发布的公告还让 Mozilla 的一位工程师 Kyle Huey 很不爽——Huey 还在一封致全体 Mozilla 员工的邮件中抨击了 Mayo，认为 Mayo 操之过急。“许多人花了不少时间搞清楚，怎么以不会误导、不是给 Firefox 或者 Gecko 投不信任票的方式，来说明这件事。”Mozilla 还有个项目名为 Positron，采用的是 Gecko，而 Tofino 也可以抛弃 Electron 和 Chromium，只不过 Mayo 并未在公告中说明清楚。

Mayo 最终还是更新了他的公告，表示 Tofino 旨在对浏览器 UI 做实验，而非核心技术。Huey 此后没有再做出回应，不过他先前的邮件表明了 Mozilla 内部的坚持。Mozilla 也在声明中提到：“我们在开放的环境下工作，我们鼓励我们的社区分享他们的想法。有时这可能造成彼此之间的不同意见。这就是 Mozilla，这原本就是我们鼓励的。”
