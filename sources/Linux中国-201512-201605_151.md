# FreeBSD 10.3 正式发布，可从 ZFS 文件系统引导

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=416965850&idx=4&sn=9e45f351e024ebb7ea495ec3b4ef88ca&chksm=3bc65f9c0cb1d68a35072f2998eddb1af7596957907d6782b1ca6bcaa4c97e28a32a9587bf2c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=416965850&idx=4&sn=9e45f351e024ebb7ea495ec3b4ef88ca&chksm=3bc65f9c0cb1d68a35072f2998eddb1af7596957907d6782b1ca6bcaa4c97e28a32a9587bf2c&scene=27#wechat_redirect)

> 转载自：CNBETA http://www.cnbeta.com/articles/489419.htm

2016年4月4号，FreeBSD 项目组正式推出了基于 BSD 内核的 FreeBSD 10.3操作系统（其实上周就可以下载了）。

尽管它并不是一个 GNU/Linux 发行版，FreeBSD 仍是一个重要的开源项目（也是被广泛使用的 BSD 操作系统之一）。其在发行声明\[1\]中称，FreeBSD 10.3带来了诸多改进和新特性，比如 Linux 兼容性层已允许用户在 amd64（x86\_64）硬件上运行64位应用程序。

![](../Images/ad176516cea86577d5dbd76c2838f40b.png)

此外，UEFI 引导器也带来了更好的多设备支持、帧缓冲器驱动的通用图形适配器（UGA）和图形输出协议（GOP）处理改进、以及增加了对 ZFS 启动的支持。

CAM 目标层现已支持高可用性设置、完整地支持了英特尔 Skylake 及更新一些的芯片、16Gbpps 光纤通道适配器、以及 full Multi-ID（NPIV）功能。此外，FreeBSD 10.3 也能够在基于 UEFI 的系统上使用 ZFS 作为根文件系统了。

Intel FreeBSD Networking Group version 3.1.13-k 现已支持 ixgbe 驱动（以及 X552 / X550T），并且 reboot 实用工具已初步实现了一个 reroot 功能，允许用户挂载来自一个临时来源文件系统的 rootfs，而无需重启操作系统。

最后，mking 实用工具已支持 MBR 和 GPT 分区格式下的 NTFS 文件系统，xz archiver 已支持多线程压缩。此外还有 GNOME 3.16.2、TeXLive 2015、X.Org Server 1.17.4 等软件也相应更新了。
