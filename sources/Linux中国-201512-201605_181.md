# 庆祝三周年：Docker 推出面向 Mac/Windows 平台的测试版

今天是开源应用容器引擎（容器级虚拟化解决方案）Docker的三周岁生日，为了庆祝这个特殊的时刻，该公司特地推出了一个面向Mac和Windows平台的beta版本。其提供了一个集成且易于部署的环境，方便用户在Mac或Windows系统中构建、组装和“装运”应用程序，同时还给Docker Toolbox带来了诸多更新。该软件并不需要一台特定的机器，开发者们可以轻松在本地主机网络上运行容器。

![](../Images/89d536635e510a85e0c28ba7af36ffa5.png "Docker-600x535.png")

*Docker-600x535.png*

Docker还包含了一个面向容器的DNS服务器，且与Mac OS X和Windows网络系统结合在了一起。在Mac上，Docker甚至可以在连接至企业虚拟专用网时使用。

Docker for Mac能与Docker Toolbox在同一台机器上同时使用，允许开发者们继续使用该工具箱。然而在Windows平台上，你必须在使用Docker for  Windows前停用Toolbox。

如果你有兴趣加入该beta项目，可以在Docker官网上登记\[1\]并收到邀请。

📹 [https://v.qq.com/iframe/preview.html?vid=p01900ujtwj&width=500&height=375&auto=0](https://v.qq.com/iframe/preview.html?vid=p01900ujtwj&width=500&height=375&auto=0)

需要注意的是，Docker for Mac和Docker for Windows处于不同的开发阶段（尽管它们分享着许多重要的代码库）。

Docker for Windows刚开始会缓慢向用户推送，但最终会实现与Docker for Mac同样的功能。Docker for Windows当前仅提供了Windows 10版本，且支持Hyper-V。
