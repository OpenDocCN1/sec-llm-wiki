成为一个女程序员

我叫Sanni Oluwatoyin Yetunde，是Andela[1]公司的一个软件开发人员。是浓厚的兴趣，以及想要解决我们国家，准确的说是尼日利亚拉各斯城市的交通问题的渴望，鼓舞我进入编程领域。在我作为一个开发者的职业生涯中，我用伟大的理念解决过很多问题，在高科技会议发过言，担任过不同代码阵营的代码指导员，包括与Africa Code week[2], Rails Girls[3]的合作，并且自从我开始写代码，一年的大多时候我都会去参加Hackathons。

哦，对了，我是一个程序媛。

femalep-01

最后这个事实不应该是稀罕的，或者令人惊讶的，但通常多半，情况就是如此。早在我在大学学习计算机科学时，我就是一个大班级中为数不多的几个女生之一。那是我第一次觉得我确实是一个在以男性为主导的环境中的异类。

所以，高科技产业就是男性俱乐部咯？是的，这一领域明显男性更多。但是，我相信时代在改变。越来越多的女性正在进入高科技产业。这是必要的：毕竟，多样化的高技术员工队伍将有利于整个行业。

至于作为男性主导环境中的女性，我个人并没有想太多。我喜欢谈论互联网，技术和编程语言。我因代码而存在而呼吸。所以，工作场合的性别比例严重失调对我而言毫无关系。我关心的是和我一起工作的人是不是热爱他们的工作，我能不能得到平等的尊重和报酬，就像团队中的其他任何人一样。

femalep-02

听到一些女性在科技领域感到受歧视，或看到在工作场所中的性骚扰，让我分感悲哀。如果你性别为女，想在高科技工作，我不会用关于“brogrammer”文化的故事来打消你的念头。相反，请一定要专注于你的技术，因为技能胜于性别之别。

我相信，关心“高科技女性”的活动和组织可以促成更多的女性进入到我们的行业中来。对于初学者来说，有一种特殊的计算机网络方式，即会有女性来帮助你面对挑战，共享她们的经验。面向女性的高科技聚会可以帮助传播授权消息和技术领域女性的观点。不过，我觉得强硬力推“高科技女性”的理念可能是有害的，因为这样做其实突出了这个行业对于女性的确非常艰难的可能。这是一个微妙的平衡。

总体而言，成为一个女性开发人员，你只要像其他开发人员那样做事即可。在电脑前度过周末和熬夜，写代码，调试，以及开发你的个人项目。遵照教程，阅读文章和快速学习。掌握专门的术语。并且，如果你想探索你正在尝试构建的内容的核心的话，那么你将需要对计算机科学有一个广博和有效的理解。概括地说，花时间去学习所有你可以学习的内容。

关于编程我最喜欢的一点是，它允许你依靠自己去构建东西。这些东西可以是费劲的任务，也可以是简单和有趣的工作。工作本身需要大量的奉献和精密度，并且你还需要有高度的上进心。然后它会付给你难以置信的报酬。

是的，我忘了提这个旅程并不是一帆风顺的。决心，努力工作以及坚韧不拔的精神是众多因素中的关键因素。就像我的一个好朋友曾说过，“我只将我现在的生活看作是汪洋大海中的一杯水”。我才刚开始。我可以承受我想要的挑战，性别并不是障碍。我尊重我的同事——作为回报，他们同样尊重我。

前面我说过是交通问题激发我对编程的兴趣，而对于解决交通问题我采取的第一个方法是建立一个应用程序，通过这个应用程序用户可以发布更新他们当前的路况，从而让其他用户提前看到交通情况，避免拥堵。在不久的将来，我计划引入人工智能来让系统变得更有效和更高效。

对于每一个有抱负的女性开发人员，我要说的话是：你可以成为你想成为的任何人。不要让这个世界限制了你。如果你确实充满了激情，那么一定要忠于自我，坚持你的信念，那么最后即使是在最困难的情况下，你也会发现自己有能力来创建一个解决方案。
