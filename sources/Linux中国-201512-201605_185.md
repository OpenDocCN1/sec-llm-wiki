# Red Hat 成为第一家20亿美元收入的开源公司

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=416022018&idx=3&sn=e240683cd4a4b8a58a1d293d84a28ce8&chksm=3bd7c5440ca04c52ca5ede388f811b34a251a17a53ed947b1e7e9c7b58b857b42c03324953a2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=416022018&idx=3&sn=e240683cd4a4b8a58a1d293d84a28ce8&chksm=3bd7c5440ca04c52ca5ede388f811b34a251a17a53ed947b1e7e9c7b58b857b42c03324953a2&scene=27#wechat_redirect)

Red Hat 四年前成为第一家10亿美元收入的开源公司，现在它又成为了\[1\]第一家20亿美元收入的开源公司，它的市值\[2\]则超过了130亿美元。

Red Hat 的第四季度收入5.44亿美元，同比增长17%，服务订购费用4.8亿美元，同比增长18%。它的订购服务占了总收入的88%，去年的总收入20.5亿美元。

![](../Images/072fdeb176faa12123d033cd08c089be.png)

Red Hat 的收入主要来自向企业提供支持服务，它的软件基本上是免费的，它是 Linux 内核开发的主要资助者，雇佣了大量内核开发者，旗下的社区发行版 CentOS 是最受欢迎的服务器发行版之一。
