# Ubuntu 16.04 需要你的帮助，让 GNOME Software 更美观

> 转载自：CNBETA http://www.cnbeta.com/articles/483657.htm

Canonical 社区经理 Michael Hall 今天发表长博文，解释即将到来的 Ubuntu 16.04 LTS（Xenial Xerus）操作系统为何需要你的帮助让 GNOME Software 变得更加漂亮。

如果你日常有在关注 Linux 方面的新闻，定于4月21日正式发布的 Ubuntu 16.04 LTS 将会提供名为 GNOME Software 的新型图形化包管理器。

![](../Images/b9ec22840da7165e144ec52815050724.png)

正如名字所示，GNOME Software 是一款 GNOME 应用，但是考虑到 Ubuntu 事实上也是基于 GNOME 顶层开发的，所以在安装的时候不会出现很大的依赖性问题。Ubuntu 16.04 LTS 中将默认采用 GNOME Software 来替代逐渐过时的 Ubuntu Software Center。

尽管 GNOME Software 的 AppStream 元数据格式能够很好的胜任这份工作，但在提取主要 Ubuntu 软件库中现有软件包的元数据过程中存在一些问题。Hall 表示：“事实证明，数据的丢失和不正确导致软件包所用的应用图标出现错误。尽管大部分应用都已经拥有一个图标，这主要是因为此前没有严格执行规范，且在桌面环境中的尺寸和格式都比现在更加的宽松所导致的。”

因为目前存档中有很多 Ubuntu 软件包采用低分辨率的图标或者不支持格式（列表\[1\]内容非常多），所以无法在 GNOME Software 中良好显示，因此 Canonical 需要社区的帮助来共同完成图标的改进。目前在社区上 Hall 已经提供了详尽的指导步骤\[2\]邀请志愿者共同参与到改进 GNOME Software 的行列中。
