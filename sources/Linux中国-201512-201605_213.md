# Linux/Unix 桌面趣事：召唤一群企鹅在桌面上行走

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=412685339&idx=3&sn=a6f6e34cdd6a0e36088ab8e6b57564fb&chksm=3b852f5d0cf2a64b88c7cd3e5131a16d43b789c29ee5df36ae1808522aef063d2ff63d2f07ef&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=412685339&idx=3&sn=a6f6e34cdd6a0e36088ab8e6b57564fb&chksm=3b852f5d0cf2a64b88c7cd3e5131a16d43b789c29ee5df36ae1808522aef063d2ff63d2f07ef&scene=27#wechat_redirect)

XPenguins 是一个在窗口播放可爱动物动画的程序。默认情况下，将会从屏幕上方掉落企鹅，沿着你的窗口顶部行走，在窗口漂浮起来，踩上滑板，和做其他类似的有趣的事情。现在，你可以把这些可爱的小企鹅大军入侵别人的桌面了。

安装XPenguins

打开终端（选择程序->附件->终端），接着输入下面的命令来安装 XPenguins。首先，输入 `apt-get update` 通过请求配置的仓库刷新包的信息，接着安装需要的程序：

```
1.  `$ sudo apt-get update`
    
2.  `$ sudo apt-get install xpenguins`
    
```

我本地如何启动 XPenguins？

输入下面的命令：

```
1.  `$ xpenguins`
    
```

移动窗口时小心点，小家伙们很容易被压坏。如果你发送中断程序（Ctrl-C），它们会爆炸。

主题

要列出主题，输入：

```
1.  `$ xpenguins -l`
    
```

示例输出：

```
1.  `Big Penguins`
    
2.  `Bill`
    
3.  `Classic Penguins`
    
4.  `Penguins`
    
5.  `Turtles`
    
```

你可以用下面的命令使用其他的主题：

```
1.  `$ xpenguins --theme "Big Penguins" --theme "Turtles"`
    
```

你可以用下面的命令安装额外的主题：

```
1.  `$ cd /tmp`
    
2.  `$ wget http://xpenguins.seul.org/xpenguins_themes-1.0.tar.gz`
    
3.  `$ tar -zxvf xpenguins_themes-1.0.tar.gz`
    
4.  `$ mkdir ~/.xpenguins`
    
5.  `$ mv -v themes ~/.xpenguins/`
    
6.  `$ xpenguins -l`
    
```

示例输出：

```
1.  `Lemmings`
    
2.  `Sonic the Hedgehog`
    
3.  `The Simpsons`
    
4.  `Winnie the Pooh`
    
5.  `Worms`
    
6.  `Big Penguins`
    
7.  `Bill`
    
8.  `Classic Penguins`
    
9.  `Penguins`
    
10.  `Turtles`
     
```

已一个随机主题开始，输入：

```
1.  `$ xpenguins --random-theme`
    
```

要加载所有的主题并且同时运行，输入：

```
1.  `$ xpenguins --all`
    
```
