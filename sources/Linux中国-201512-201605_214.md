# Google Summer of Code 2016 启动：现接受学生注册申请

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=412447693&idx=4&sn=f492bebd04d2428fd625a36eb95ac770&chksm=3b89488b0cfec19de726724ec59b030593dbd1b2ba478214180eb9e875e748a87811c82ee423&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=412447693&idx=4&sn=f492bebd04d2428fd625a36eb95ac770&chksm=3b89488b0cfec19de726724ec59b030593dbd1b2ba478214180eb9e875e748a87811c82ee423&scene=27#wechat_redirect)

> 转载自：CNBETA http://www.cnbeta.com/articles/483641.htm

如果你是一名大学生，且对加入Fedora、KDE、LibreOffice或者VLC等开源项目充满憧憬，那么你应该注册Google的Summer of Code 2016项目\[1\]。

Google开源团队的Mary Radomile表示：“在成功举办12届之后，GSoC项目参与者有机会完全在线的方式参与到开源项目中。通过这个项目，学生不仅能通过成功贡献而获得相应津贴，而且能在导师的帮助下解决技术问题和解答心中疑虑。参与过该项目的多名学生都告诉我在项目中获得了实际经验，不仅磨炼了技术技能，而且增强了他们的自信心，扩展了社交网络和强化了个人简历。”

![](../Images/4222ac2cf158ccced1ab9ab750a95f05.png)

Radomile进一步说道：“有兴趣参加这项活动的学生自北京时间3月26日5点开始向编程网站提交申请。学生可以一一查看180个开源项目寻找适合你的。由于活动位置有限，我们推荐你提供详尽的项目建议书来增加你被选中的几率。我们的学生手册上提供了大量非常实用的建议，能够帮助你选择适合你的开源项目并参与到创建制作伟大应用程序的过程中。”
