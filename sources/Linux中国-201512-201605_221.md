# Ubuntu 16.04 LTS 将基于 Linux Kernel 4.4.4

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=411547876&idx=2&sn=6047ef4bb3d40d425d1d562397d410c1&chksm=3b9b83a20cec0ab4e5ea795dd1f203c34707b4d619acd1445e8b581917441074ca5df04dfd63&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=411547876&idx=2&sn=6047ef4bb3d40d425d1d562397d410c1&chksm=3b9b83a20cec0ab4e5ea795dd1f203c34707b4d619acd1445e8b581917441074ca5df04dfd63&scene=27#wechat_redirect)

> 作者： Marius Nestor   
> 转载自：CNBETA http://www.cnbeta.com/articles/482907.htm

Ubuntu 内核开发者 Joseph Salisbury 在每周通讯上宣布即将于4月21日发布的 Ubuntu 16.04 LTS (Xenial Xerus) 操作系统已经基于 Linux Kernel 4.4.4 LTS 版本（目前最新版本为4.4.5）。面向早期适配者和公测用户的 Ubuntu 16.04 LTS 的软件库中已经开始推送新内核版本 Linux-4.4.0-12.28，外媒 SoftPedia 成功完成了升级，过程一切顺利。

![](../Images/6fdd30911171c96f6717c50201b144da.png)

在2016年3月11日发布的每周通讯上 Ubuntu 内核开发者写道：“我们的 Xenial 内核已经重新基于 v4.4.4 版本，目前已经在存档的 -proposed 目录中进行测试，将会近期内推广至 -updates。请参与测试之后让我们知道结果。”

Ubuntu 16.04 LTS 发布日程：

*   Alpha 1--2015年12月31日
    
*   Alpha 2--2016年1月28日
    
*   特性冻结--2016年2月18日
    
*   Beta 1--2016年2月25日
    
*   用户界面冻结--2016年3月10日
    
*   Final Beta--2016年3月24日
    
*   内核冻结--2016年4月7日
    
*   发布候选--2016年4月14日
    
*   正式发布--2016年4月21日
