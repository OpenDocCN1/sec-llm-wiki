# 如果你喜欢 Fedora，那你肯定也喜欢 Korora

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=410627658&idx=1&sn=813b0657605d5831a8164f277e03b04b&chksm=3b65950c0c121c1a0d6caf9635ad3c0b3d9e63974b56f106efdf6ad5c7cd77a4e3c03200677e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=410627658&idx=1&sn=813b0657605d5831a8164f277e03b04b&chksm=3b65950c0c121c1a0d6caf9635ad3c0b3d9e63974b56f106efdf6ad5c7cd77a4e3c03200677e&scene=27#wechat_redirect)

> 译者： 布加迪

Korora 23\[1\]最终版已在上个月发布。它是一款基于Fedora的发行版，不仅让用户可以选择五种桌面环境，还有许多易于使用的改进之处。Fedora是红帽Linux企业版(RHLE)的社区版。

除非你在寻找最先进的桌面环境，否则Korora为你提供了所有的顶级桌面环境。你可以运行Cinnamon、GNOME、KDE、MATE和Xfce。

我测试了Korora的所有这些选项，对每个选项的表现感到很满意。下面我着重介绍MATE桌面版本上的“外观和感觉”这部分，因为MATE在Korora中的集成程度远胜过其他发行版，这给我留下了深刻印象。如果谁对当前的GNOME 3风格不满意，MATE分支是一种让人耳目一新的替代版。

![](../Images/a619aa8422b69ce10ddfe639a8a9b3f3.png "连不喜欢GNOME 3桌面的Linux用户对Korora版本也会有一种一见如故的感觉")

*连不喜欢GNOME 3桌面的Linux用户对Korora版本也会有一种一见如故的感觉*

Korora的开发人员的整体开发给人以相似的外观。Korora遵循Fedora设计，将面板放在屏幕顶部。这种一致性确实收到了成效。

我往往将顶部面板设计视作老派的Linux，因为我使用的许多发行版把面板放在屏幕底部。然而，把面板放在顶部位置这种做法在Korora中给人的感觉很自然，尤其对Cinnamon桌面版本来说更是如此。我使用其他发行版中的Cinnamon，惊讶地发现顶部面板并没有让我烦心。

![](../Images/115bc4d61d8ffa7d18f627c8708ba549.png "如果你喜欢Cinnamon桌面，就会非常喜欢Korora 23中集成了它")

*如果你喜欢Cinnamon桌面，就会非常喜欢Korora 23中集成了它*

Korora 23代号为Coral，拥有最新的稳定RPM Fusion代码库。这些社区程序包支持Fedora通常没有发布的功能特性，比如多媒体编解码器和专有的内核驱动程序。

**向Korora致敬！**

Korora发行版是一个日益壮大的项目，大概10年前由首席开发员Chris Smart开发，那时还叫Kororaa。其名称来自毛利语，意为“小企鹅”。他的目的是，在多个台式机上迅速安装同样的Gentoo Linux系统。该发行版刚开始只有两个版本：GNOME和KDE。Cinnamon、MATE和Xfce是后来添加上来的。

2007年年底，Smart叫停了这个项目，结果近三年后重新推出了该项目，改名为Fedora Remix。2013年发布版本18后，他将项目名称改为Korora。

Korora提供了许多讨人喜欢的功能特性，先从安装开始说起。安装过程轻松无忧。

使用Korora也很轻松。就算你不熟悉红帽或Fedora，照样可以使用Korora，不需要捣鼓一番。

**共同因素**

虽然安装和使用Korora方面几乎不需要什么捣鼓，但如果你想添加几个额外的功能特性，这款发行版确实需要一点特别的处理。那是由于它得遵守与Fedora社区有关的许可协议。

比如说，英伟达之类的专有软件驱动程序和谷歌Chrome之类的程序包并没有预先安装。想获得这些组件，可以使用系统菜单的控制中心里面的Pharlap设备管理器。

Korora的默认应用程序包括：Mozilla的Web浏览器、LibreOffice\[2\]套件、Shotwell照片管理器、Audacious音乐管理器、OpenShot视频编辑器和VLC媒体播放器。其他许多主流的Linux程序预先包含在相关的桌面版中。

比如说，Kdenlive视频编辑器与KDE版本相伴。MATE经典程序(比如Eye of MATE图像查看器)捆绑在该桌面中。你所钟爱发行版中使用的许多Linux应用程序也包含在所有Korora版本中。

**外观和感觉**

MATE有着老式GNOME那种熟悉的外观和感觉，但是底层也不乏Fedora的先进功能。默认情况下，桌面有两个面板。

![](../Images/ef8c2b4ce4d3c5e3d42e8a4b255c7108.png "Korora的MATE桌面版本其实为GNOME 2分支赋予了全新、现代的气息。它有两个面板以及你需要的所有经典Linux设计")

*Korora的MATE桌面版本其实为GNOME 2分支赋予了全新、现代的气息。它有两个面板以及你需要的所有经典Linux设计*

顶部面板在左侧有下拉菜单的启动器，可用于启动应用程序、pace和系统应用程序。右侧但并非中间的是几个图标，用来启动Caja文件管理器、MATE终端和默认的火狐Web浏览器。

最右边是常见托盘，放置着日历、音频和连接控件。该托盘里面也有一个启动器，用于启动Universal Access Preferences选择框。

底部面板有打开应用程序的窗口指示器、显示桌面按钮和工作区切换器。

默认情况下，一组生动的背景图像每几分钟就会滚动显示。方便是MATE的主旨。你前往的几乎每个区域只要右击鼠标，就可以访问导航命令或上下文菜单。

这包括桌面本身。右击访问的这种便利性是Xfce桌面的主要优点之一。添加这项特性让MATE得以集两种环境之众长。

**结束语**

Korora即开即用的理念是这款发行版不断变得更好的原因之一。如果你想有一种更好、更易于使用的Linux发行版，而不仅限于Fedora吸引企业用户的设计准则，那么你选择Korora的五种桌面版本中的任何一种都不会错。它基本上满足了用户的众多要求，没必要选择另一种发行版以获得你青睐的界面。

Korora恪守其使命。它之前承诺为新用户提供更容易使用的Linux，又为高级Linux用户承诺不牺牲功能或特性。现在看来，它确实做到了。
