# 微软将把 SQL Server 带到 Linux

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=407986005&idx=3&sn=a4e858a788bfa8f244bf5c46f331be75&chksm=3b4d64130c3aed057503335026570d2178c35a45ec3f8b4b634c5b44169a97a5277e064eda44&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=407986005&idx=3&sn=a4e858a788bfa8f244bf5c46f331be75&chksm=3b4d64130c3aed057503335026570d2178c35a45ec3f8b4b634c5b44169a97a5277e064eda44&scene=27#wechat_redirect)

> 转载自：网易科技 http://tech.163.com/16/0308/06/BHK81JTM000915BF.html

微软公司日前宣布，将向 Linux 系统开放旗下的数据库软件SQL Server。

![](../Images/537d13c325e1cb23ab6848efd827010e.png)

微软公司负责云与企业业务事业部的执行副总裁斯科特·格思里Scott Guthrie周一在博客上公布了这一消息\[1\]。红帽与 Canonical 两家 Linux 系统公司转发了该新闻。

Linux 版的 SQL Server 现在面向社区封闭式预览，感兴趣的用户需要递交申请等待通知\[2\]，正式版计划在2017年年中发布。

最流行的数据库软件现在都支持 Linux，如 MySQL、Oracle Database、PostgreSQL 等等，SQL Server 被普遍认为门槛最低。SQL Server 是微软的成功产品，尤其是在中小企业以及大企业下设的事业部中。但统治这个市场的仍是甲骨文公司，该公司的数据库产品可以说是财富500强公司中的标准。

微软公司过去一直表示，要将 Azure 云作为针对开源和非 Windows 软件的主要服务。把公司主要的服务器应用推广到 Windows Server 之外的操作系统上，让人感到非常吃惊。向 Linux 开放产品是微软态度的一大转变，但在财务上合乎情理。根据IDC的数据\[3\]，微软在数据库市场已经因甲骨文和IBM等对手的Linux产品而丢失了15%市场份额。此举对微软来说意义重大。
