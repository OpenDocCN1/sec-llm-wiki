看 VMware 的8大新品如何打造数字化企业

2月23日，VMware 在位于北京北四环融科资讯中心的办公室举办了2016年1季度新产品媒体发布会。不愧是移动化和云计算的行业领导者，VMware 这次一口气推出了8款产品的新版本，全面诠释了这家行业巨头在移动-云计算时代对于市场需求的理解和技术方向的引领。



Workspace ONE



VMware 这次产品发布的主题是“打造数字化企业（Enabling the Digital Enterpise）”，VMware 推出了一款全新的产品 Workspace ONE 来支撑这一理念，Workspace ONE 的定位是为企业员工提供一个数字化的工作空间。


首先 Workspace ONE 的定位是一个数字化工作空间的平台，它是用来解决企业数字化、移动化过程中存在的一些普遍性问题：统一身份认证、统一应用发布和移动设备管理。针对这些问题 Workspace ONE 提出了一个平台化的解决方案，来为企业的所有应用提供以下服务：

  • 统一身份认证：集成用户现有的企业身份认证系统，如 Microsoft Active Directory，所有的应用都可以通过 Workspace ONE 的桥接作用来统一使用现有的身份认证，并且实现所有应用的单点登录，提高用户体验。

  • 统一应用发布：企业用到的所有应用都可以在 Workspace ONE 平台上统一发布，包括：内部Web应用、公用云上的SaaS应用、Windows应用、手机或平板上的App、RDSH托管应用和远程虚拟桌面，员工通过自助式的应用发布门户（企业应用商店）就可以获得工作所需要的所有应用。

  • 移动设备管理：Workspace ONE 又是一个跨设备的平台，支持包括 Windows 10、Mac OS、iOS、Android 等多种操作系统平台，并且集成了 VMware AirWatch 的企业移动化管理方案，为每一位员工的数字化工作空间提从了全面的安全保障，真正体现了 VMware 任何应用、任何设备（Any Application, Any Device）的理念。


其次，Workspace ONE 上也集成了一整套的生产力工具，包括邮件、日历、文件分享（Content Locker）、社交聊天等，用户一安装 Workspace ONE 就能够利用这些工具快速建立起基本的工作空间。与智能移动设备中自带的邮件、日历、微信聊天等工具所不同的是，Workspace ONE 中的这些生产力工具是在安全沙箱的保护下运行的，具有企业级的安全性，能够更好地保护企业数据安全；并且通过 Workspace ONE ，用户可以把自带设备（BYOD）上的个人空间和工作空间完全隔离开来，更好地保护个人隐私。


根据 VMware 的介绍，Workspace ONE 有标准版、高级版和企业版三个版本，高级版中包括了 AirWatch 的功能，企业版在高级版的基础上增加了 Horizon 企业版的功能。自从2014年初收购了 AirWatch 之后，VMware 一直在进行终端用户计算产品线的整合工作，2015年底又收购了个人信息管理（PIM）厂商 Boxer，所有这些功能都被放进了 Workspace ONE。看来 Workspace ONE 是 VMware 整合了所有EUC产品线功能的一款产品，目前市场上类似的工作空间产品都没有 Workspace ONE 功能这么全，Workspace ONE 进一步加强了 VMware  在终端用户计算领域的领导者地位。


AirWatch 8.3



作为 Workspace ONE 的一个组件，AirWatch 也发布了最新版本8.3。作为企业移动化管理（EMM）方案的全球领导者，AirWatch 每个季度都会发布一个版本，这次的 8.3 版本有以下几个亮点。

  • 安全应用令牌机制（SATS - Secure App Token System）：SATS 技术能够实现全面覆盖个人电脑、本地移动和云应用的真正单点登录，无需密码或复杂的PIN码，VMware 正在为 SATS 技术申请专利。

  • 个人隐私保护计划（AirWatch Privacy First Program）：一般用户对自己的手机上安装 AirWatch 管理软件总是心存疑虑，AirWatch 8.3 中特别设置了一些内容来向用户解释 AirWatch 的隐私保护策略，让用户认识到 AirWatch 的移动管理系统将工作数据与个人资料分开，完全不会让企业 IT 部门获取个人信息，如个人电子邮件、照片等。

  • 行业模板：EMM 在每个行业的应用中都有一些特点，VMware 根据在这一行业的实施经验和客户反馈，总结了一些针对特定行业的最佳实践经验 ，把它们总结在行业模板中。应用行业模板，管理员能够快速设定应用程序、设备安全配置和策略。



Horizon 7


Horizon 7 是本次新产品发布的另一大亮点，VMware 在发布会上演示了 Horizon 7 中的即时桌面交付（Just-In-Time Delivery）技术，在这一创新技术下，用户的虚机不再需要预先准备，而是在用户登录时动态创建，整个过程只需要短短十几秒钟时间。VMware 的资料显示，利用这一技术创建 2000 个虚机只需要20分钟，而传统的 VDI 技术一般需要几个小时。


即时桌面交付采用了 vSphere 6 中的即时克隆（Instant Clone）技术，相信 Horizon 是第一个采用这项技术的软件。该技术从内存中一个现有的虚机直接克隆出一个新的虚机，新创建的虚机可以完全重用原虚机的内存镜像，只有发生新的内存改写时才需要复制那部分内存来进行写操作（Copy on Write）。当然，这样克隆出来的虚机都是一模一样的，再结合 VMware 的 App Volumes 技术，可以为每一个用户创建一个个性化的桌面，包括用户的个人数据、桌面设置、应用软件等都是用户可定制的。


即时桌面交付技术是让人惊艳的，我们觉得这是跟目前市场上的 VDI 技术完全不同的下一代虚拟桌面技术。去年 IDC 的分析报告第一次把 VMware Horizon 列为桌面虚拟化的市场领导者，这项技术将进一步加强 Horizon 的领先地位。


VMware 的高级产品经理傅纯一解释了这一创新技术给用户带来的价值：

  • 降低硬件采购成本：所有用户的桌面不再需要保存一个虚机镜像文件，只需要保存用户个性化的数据就行了，这可以大大减少对于存储空间的需求。

  • 提高虚拟桌面的安全性：只有当用户登录的时候才会动态生成桌面，退出时系统会马上删除刚才用过的虚机，这就减少了数据泄露的风险。

  • 简化管理复杂性：所有的桌面都是从同一台虚机克隆出来的，只需要在原始虚机上升级 Windows 补丁就可以让所有的桌面都获得安全更新。而且这种操作不影响用户的正常使用，用户下次登录桌面就可以用到升级过的操作系统。VMware 目前的确有部分客户由于虚拟桌面数量过多，每次 Windows 打安全补丁都要重构（recompose）桌面，非常费时，往往一个周末都做不完；将来采用 Horizon 7 的这项新技术的话，就可以解决这个问题。


VMware 在 Horizon 7 中也发布了全新的Blast Extreme 协议，以前版本的 Horizon 一直采用 PCoIP 协议，是由 VMware 与 Teradici 共同开发的桌面虚拟化协议。随着技术的发展，PCoIP 也暴露出一些局限性，所以 VMware 开发了一套全新的 Blast Extreme 协议，来更好地适应移动-云计算时代的需求。VMware 介绍了 Blast 协议的主要优点：

  • 广泛的客户端支持: Blast 协议基于H264，目前支持H264的硬件非常普遍；

  • 网络友好：既能利用 TCP 也能利用 UDP 来传输数据，充分利用两种协议的优点；

  • 使用更少的带宽：意味着 Blast 可以支持更多的用户，提供更好的用户体验；

  • 为云时代而设计：Blast 能够更好地适应各种网速状态，满足更多的应用场景需求；

  • 优化电池寿命：Blast 专门为移动设备做了优化。



App Volumes 3.0


跟随 Horiozon 7 一起发布的还有 App Volumes 3.0，这个产品也是 Horizon 企业版的一部分。App Volumes 来自于 VMware 2014 年收购的 Cloud Volumes，主要的功能是快速应用交付。在以前的版本中，App Volumes 都是一个单点产品。在这次发布的3.0中，VMware 把 App Volumes 和其他一些产品如 User Environment Manager、ThinApp 重新打包，把 App Volumes 变成了一个套件产品，并且分成标准版、高级版和企业版三个版本，估计是 VMware 为了市场销售需求而做的产品包装调整。


VMware 对于 App Volumes 3.0 的定位是应用生命周期管理，支持在各应用层进行生命周期管理，同时仍保留应用分层优势。它将提供有关应用生命周期管理的主要功能，例如自动化、灵活交付与监测、综合终端用户管理以及统一管理等。总之，该方案将显著加快应用交付，统一应用与用户环境管理，同时将存储与运营成本大幅降低70%，将管理镜像所费时间减少95%。



Horizon Air Hybrid-Mode


Horizon Air Hybrid-Mode 又是一个全新的产品，此前被称作 Project Enzo，在 VMworld 2015 上做过详细介绍。


Horizon Air Hybrid-Mode 提出了一种全新的云扩展架构，旨在把云端 VMware虚拟应用及桌面技术的经济优势与超融合基础架构的便捷性合为一体。该架构将由两大部分组成，云端的管理平台（Cloud Control Plane）以及在客户现场部署的基于 Smart Node 技术的超融合系统。

Horizon Air Hybrid-Mode 的优势包括：

  • 简便的开箱即用设置 — VMware Horizon Air 支持的超融合设备具备简便的即插即用特性，虚拟应用与桌面可以在1个小时内设置完毕并运行。

  • 以云速度创建与扩展桌面 — Horizon Air Hybrid-Mode 具有跟 Horizon 7 同样的即时桌面交付技术。

  • 无需维护 Windows 与无缝软件更新 — 通过对 Windows 镜像及应用进行即时的无缝软件更新，从此无需维护窗口。此外，新的产品特性与增强功能都是由 VMware 云端管理层完成，大简化了客户现场的管理。

  • 混合云的灵活性 — 应用与桌面工作负载可在内部数据中心与云端之间自如移动，所有一切均通过统一的 Cloud Control Plane 进行管理，并将云服务灵活应用于日常工作，或者作为桌面用量激增或灾备的应对方案。


Horizon Air Hybrid-Mode 提出了一种全新的桌面虚拟化部署模式，它的推出又一次展现了 VMware 作为云计算市场和技术领跑者的形象，但是这种使用模式毕竟是以前没有过的，是否能被市场和用户接受还有待时间的检验。



Virtual SAN 6.2


VMware 传统的强势产品线 SDDC 这次也发布了最新的 Virtual SAN 6.2，其中增加了很多高端存储才有的功能特性：

  • 重复数据删除与压缩：重复数据删除与压缩功能优化了全闪存存储容量，可将全闪存超融合系统每个可用GB的成本降至1美元，将存储效率提升高达10倍。

  • 纠删码（Erasure Coding）：该功能可以看作跨服务器的 Raid5/6 功能，能够用较少的存储空间来实现数据存储的可靠性。

  • 服务质量指定（QoS）：可以让管理员来指定某个应用能够消耗的存储性能（IOPS），从而保证关键业务或系统整体的数据访问性能。

  • 高级性能和容量监控：在 vSphere Web Client 原生提供完全集成的运维管理功能。


从 Virtual SAN 诞生至今，VSAN 6.2 已经是第四代的软件定义存储了。由于 VSAN 卓越的性能，自第一版 VSAN 发布以来，已在21个月内拥有了 3000 多名客户。



新一代超融合软件 HCS



借助于 VSAN 6.2，VMware 也推出了全新的超融合软件 HCS（Hyper-Converged Software），包括 vSphere、VSAN 和 vCenter Server。VMware 超融合软件将标准的 x86 服务器与本机硬盘转变为简单而稳健的超融合系统，有助于企业降低IT成本与管理复杂度，同时获得超凡性能。


随着 VSAN 6.2 的正式发布，VMware 也推出了新的超融合系统选项 VMware Virtual SAN Ready Node，这个选项能够让制造商们在服务器出厂时安装认证过VMware 超融合软件，以简初始安装配置，缩短客户交付时间。富士通、Hitachi Data Systems 和 Supermicro 是提供此类 VMware Virtual SAN Ready Node 的第一批服务器制造商。VMware Virtual SAN Ready Node 还可以捆绑软件许可证，或接受客户提供的许可证。此外，这些服务器制造商们还能够为客户提供软硬件的统一支持服务。


VMware Virtual SAN Ready Node 在 VMware 现有的超融合产品 EVO:Rail 和 EVO SDDC 的基础上为客户和合作伙伴提供了更多的超融合方案选择。



vRealize Suite 7


此次还发布了 VMware 云管平台 vRealize Suite 最新版本 7，VMware vRealize 产品家族是云管平台（CMP - Cloud Management Platform）领域的绝对行业领导者，始终在 IDC 的排行榜上占据第一的位置。


本次发布的vRealize Suite 7 有三个版本，分别对应客户的三个应用场景（见下图）：

  • 标准版：通过完善的监控管理和成本核算能力支持智能化运维；

  • 高级版：在标准版基础上加入自动化调配 (Provision) 能力，实现软件定义的数据中心；

  • 企业版：在高级版基础上加入应用监控和应用自动化能力， 让企业 IT 支持 DevOps，实现应用开发、测试、上线的无缝衔接和全程自动化。


VMware 又进一步解释了这几种版本分别对应企业 IT 云计算发展的成熟度：

  • 虚拟化：服务器虚拟化初级阶段。

  • 智能运维：随着数据中心规模的扩大，人工管理方式渐渐力不从心，这时候需要引入 vRealize Operations 和 vRealize Log Insight 来实现智能监控，引入 vRealize Business 来进行成本核算，从而实现智能运维管理。

  • 自动化 IT 以实现 IaaS：业务的发展对 IT 服务交付速度提出了更高的要求，这时候可以进一步引入 vRealize Automation 来自动化整个 IT 交付流程，把数据中心建设成一个私有云。

  • DevOps 就绪型 IT：互联网技术的发展要求企业能够持续地交付应用，这就要求开发、测试、运维这几个部门的配合更加紧密，通过 vRA 企业版的应用调配 (Application Provision) 能力可以自动化整个流程，让 IT 架构完美支持 DevOps。



vRealize Suite 既可以管理基于 vSphere 的工作负载，也可以管理运行于其他 Hypervisor 之上的虚机，也可以管理公有云上的负载。vRealize Suite 在版本7中推出了一种新的许可证 — 可移动许可单元（PLU - Portable License Unit），这种许可证可以灵活地在私有云和公用云管理之间切换，给予客户更大的灵活性。现在越来越多的企业遂渐把部分非核心工作负载迁移到公有云上，可移动许可证的推出顺应了这种趋势，保证企业将来向混合云转型没有任何障碍。


作为云计算管理平台vRealize 的旗舰产品vRealize Automation 7.0，顾名思义，它的主要功能是自动化地创建和管理 IT 基础架构。vRA7 的发布正是迎合市场的需求，从自动化能力的提高和易用性上，设计了许多业界领先的新功能：

  • 全面的自动化管理

  • 快速安装部署

  • 全面支持 NSX

  • 灵活支持异构云平台

  • 设计蓝图的共享和管理


跟以前的版本相比，vRealize Suite 7 在产品结构上做出了比较大的调整，我们看到的是 VMware 在积极地推进它的混合云战略，推动客户向混合云转型。



VMware 的这次产品发布又一次证明了它是当之无愧的行业领导者，一下子推出那么多创新产品和技术，提出新的云计算业务模式，在业界没有其他公司可以做到。参加这次媒体发布会，就像是参加了一次云计算技术的饕餮盛宴，我们又一次见识了很多新的技术成果。
