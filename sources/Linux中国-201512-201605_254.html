PCLinuxOS 是最佳的滚动发布发行版吗?

我知道这篇文章的标题已经让一些读者陷入了困惑的状态。我怎么敢认为 Arch 之外的发行版是“最佳的”滚动发布发行版呢?

我要提出反驳的理由：Arch 确实很出色，它的性能非常高，说明文档无比完备、翔实，不过它完全依赖于“Arch 方式”。这意味着，如果你想进一步了解 Linux 及其基础，Arch 很适合你。

另一方面，如果你只想要一款安装一次的操作系统，它在默认情况下已为你作好了准备，那么 Arch 可能不适合你。这时候，我认为 PCLinuxOS 大有用武之地。

安装很简单

在你看到建议删除不需要的程序包的那个屏幕之前，PCLinuxOS KDE 版本的初始安装与其他任何发行版几乎一样。我立刻喜欢上了这点。我觉得我在参与安装“对话”过程。以一种流畅的 GUI 格式提供这种安装也很有帮助。

之后，安装过程就跟你预期的那样顺畅。不过有一些小小的惊喜，许多人会喜欢。稍过片刻，你会看到一个窗口，可以在此选择引导装载程序和引导设备。没错，通过 GUI，你就可以决定要不要使用 GRUB、GRUB2 或 LILO。下一步，你可以选择引导之前的超时延迟。等一下，它变得更好了。同样在 GUI 里面，你可以开启/关闭 ACPI、SMP 和 APIC 支持。换成其他发行版，这通常需要手动输入，但现在默认情况下这出现在“高级”下面。

下一步，你会看到管理引导菜单这一选项。它对大多数人来说并不是很重要，不过如果你在运行多个发行版，这一点很方便。重启安装的系统后，下一步是选择时区，然后为你的时区选择本地或 UTC。

提示创建 root 密码的便利之一在于，你可以在本地、LDAP、Windows Domain、NIS 和 Kerbos 5 之间作一选择。这确实是 PCLinuxOS 的过人之处。

第一印象

我已引导进入到桌面环境本身，系统提示我需要更新系统，之后再安装新软件。很显然，这对新用户来说很有帮助。弹出窗口还包含完成这项任务的确切路径。

我确实想到的一点是，一旦我头一次完成引导，要是有某种自动更新功能，这会流畅得多。还有，为最终用户提供了按时间表更新的选择，这意味着由用户来掌控。所以，我能认识到这种方法的价值，但它并不适合每个人。

将更新版下载到全新安装的系统上花了我大概8分钟到10分钟，我用的是光纤互联网连接。考虑到有900多个更新要安装，我能理解为何这个过程费点时间。要是我没有提及时钟旁边有个更新工具窗口组件，那也未免太粗心了。你可以从那里打开 Synaptic，只要该窗口组件出现在你面前。更新速度取决于你无法掌控的许多因素。

处理这样的滚动发行版时，如果安装介质在安装之前并非定期更新，有时你会遇到大量的更新。幸好，这个过程快速又轻松。

设置和应用程序

PCLinuxOS 提供的设置异常广泛而全面。我原以为是通常的 KDE 设置，却惊喜地发现我可以轻松管理需要的几乎一切。总体上来说，从易用性的角度来看，它让人感觉很爽。我经常浏览的地方（以 KDE 为中心）是控制中心的服务与守护进程部分。我喜欢看看 GUI 里面有什么，因为它更容易直观地显示内容。

当然，我仍可以从命令行接口（CLI）禁用或启用什么功能，不过我喜欢这个提供的视觉对比。刚接触 Linux 的用户会喜欢能够从 GUI 来进行这番操作。就普通的控制中心而言，没有太多是你可以迅速轻松完成操作的，不需要知道特定的命令。

另外还有预先安装的应用程序。PCLinuxOS 并没有遗漏任何东西。它是一种发现软件的好方法。如果启动 PC 菜单，开始浏览应用程序，你在寻找的应用程序很可能已经安装。我发现 Dropbox、Skype、Filezilla、NitroShare、Calibre 以及用于科学、监测和财务等方面的无数软件都已安装，随时可以使用！

那么，可用软件的版本有多新呢?一些应用程序很过时了。比如说，Kdenlive 仍是版本0.9.10。在我的另一台 PC 上，我运行的是 Kdenlive 15.12.1。不过，如果想要稳定的体验，而不是新颖的功能，这倒算是公平的权衡。如果某人真想要新版本，可以找到兼容的 RPM，安装一个新版本。

速度和可靠性

通常我将 KDE 与功能联系起来，而不是与速度联系起来。不过我发现，运行 KDE 的 PCLinuxOS 响应迅疾。菜单会立马打开来，没有延迟。我可以迅速来回浏览设置，没有任何的滞后。考虑到这是在用来测试软件的英特尔凌动处理器上，这确实颇能说明问题。我还发现，启动时间完全可以接受。又由于能够一开始就能配置引导装载程序选择，整个过程就跟我希望的那样简单化。

我过去用过 PCLinuxOS，所以对它的可靠性很熟悉。除了个别应用程序因某种原因崩溃外，我发觉桌面环境相当稳定。即便安装了900个更新后，也是如此！除了硬盘故障外，你根本没必要再重装。如果你考虑到这个事实，就会觉得这确实是相当诱人的一种选择。

PCLinuxOS 的最终结果

自2008年以来，我就断断续续地使用 PCLinuxOS。如果你想要一款稳定的、安装一次就可以不管的发行版，选它保准没错。另外值得一提的是，除了其他版本外，还有 GNOME 和 MATE。结合其稳定性以及非常强大、乐于助人的社区，我能明白为何这些年来这款发行版依然很火爆。

我唯一要建议的地方就是，确保一些功能丰富的应用程序（比如 Kdenlive）版本能够更新点。倒不是说非得要最先进、最新潮，而是说鉴于这款发行版在向用户群推出新软件方面做得如此到位，不将一些应用程序做得更新颖一点似乎令人遗憾。

最后要说的是，我找不到在默认情况下安装的备份应用程序。在我看来，luckyBackup（PCLinuxOS 软件库中就有）将是这方面的一个合理选择。也许它安装在 Full Monty 版本中，我并不确定。

我的建议就是，试用一下 PCLinuxOS。它无论如何都不是一款很新潮的 Arch 衍生版，但这也增添了其魅力。就个人而言，我建议对它打量一番！
