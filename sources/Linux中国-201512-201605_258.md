# 在没有盗版的世界：Linux 桌面装机量占比可达40%

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=401542254&idx=1&sn=980721f95803e7b403182e806b27cd3e&chksm=34f337280384be3ee3f4c9bc9bf895f2255eccf5899d74544f061140ed96dfc8b24c0ef480c4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401542254&idx=1&sn=980721f95803e7b403182e806b27cd3e&chksm=34f337280384be3ee3f4c9bc9bf895f2255eccf5899d74544f061140ed96dfc8b24c0ef480c4&scene=27#wechat_redirect)

> 转载自：CNBETA http://www.cnbeta.com/articles/477019.htm

近日由奥斯陆大学经济学系博士生 Arne Rogde Gramstad 公布的 “Software Piracy and Linux Adoption” 研究报告\[1\]，发现了 Linux 系统装机量和软件盗版之间的潜在关联。在这份报告中引用了商业软件联盟（BSA）自2012年以来从104个国家收集的盗版软件信息，根据每个国家的政策和打击力度等原因，Windows 系统盗版率在40%至90%之间。

![](../Images/8229ef2aefaba00b52aeda7e00b368c8.png)

科研专家发现了为何盗版 Windows 系统会阻碍 Linux装机量发展（以各种形式）的三个原因。

1.  Windows 系统的非法拷贝非常低廉，且几乎可以完美替代官方原版。
    
2.  由于盗版问题猖獗，导致 Windows 系统的官方销售渠道会以更低的价格进行销售
    
3.  操作系统的装机量和网络外部性（是指连接到一个网络的价值，取决于已经连接到该网络的其他人的数量）存在关联，因此盗版 Windows 系统的存在可能会继续增加 Windows 系统和 Linux 系统之间的差值。
    

根据报道中显示 Linux 系统的装机量大约在 **2%**（桌面端），但是我们必须要说的是这是四舍五入的结果，实际的数据在**1%** 和 **2%** 之间。根据报道如果一个国家操作系统盗版率增加 **1%**，那么 Linux 用户占比就下降 **0.5%** 至 **0.65%**。换言之，如果世界上没有盗版操作系统，那么 Linux 的装机量将会在 **20%** 至 **40%** 之间。
