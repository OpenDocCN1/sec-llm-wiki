# Ubuntu 手机再添俩虎将：Xperia Z1、一加

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=401517243&idx=2&sn=461f5e90817598d5f8b8baa11d89d6a6&chksm=34f291fd038518eb42366029ccbd1c2f4a8789ea878cff84a21e5744528b21ecdd46c4f1a40e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401517243&idx=2&sn=461f5e90817598d5f8b8baa11d89d6a6&chksm=34f291fd038518eb42366029ccbd1c2f4a8789ea878cff84a21e5744528b21ecdd46c4f1a40e&scene=27#wechat_redirect)

> 转载自：CNBETA http://www.cnbeta.com/articles/476417.htm

联合魅族发布了PRO 5 Ubuntu版之后，Canonical刚刚又宣布，索尼Xperia Z1、一加OnePlus One也加入了Ubuntu大家庭。不过，它们并不是来自索尼和一加官方的新版本，而是Canonical为它们适配好了Ubuntu手机系统ROM，玩家可以选择刷入体验。

![](../Images/74b9cea18707618173a4e8d305c08626.png)

这其中既有Canonical官方的努力，也有社区和广大开发人员的贡献，当然还有索尼、一加本身对于开源的支持。

Canonical表示，针对这两款手机的Ubuntu移植工作将会尽快最终完成，并随时保持更新、消除Bug。
