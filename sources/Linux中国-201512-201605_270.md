1.  俄罗斯宣布有可能切换到 Linux , 以此来反击西方因克里米亚问题而实施的商业禁运。
    
    俄罗斯可能将成千上万台政府的电脑系统从 Windows 切换成 Linux\[1\] - TechRadar
    
    [普京的互联网顾问建议弃用 Windows](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401468439&idx=2&sn=14d2ae0ec661b123d79a5c5c6a9c1d84#rd?utm_source=index&utm_medium=more "普京的互联网顾问建议弃用 Windows") - Linux 中国

2.  Jack Wallen 写到：“对于 Linux 来说，占有桌面系统市场 1% 或者 99% 并不重要”
    
    为了 Linux 桌面系统奋斗是否真的很重要?\[2\] - TechRepublic
    
    ![](../Images/94819837dfee550da74bf61af05dcc0e.png)
    
3.  自从去年 12 月以来，参与 Linux 基金会的 HYPERLEDGER 计划的合作伙伴有了显著的增加
    
    Linux 基金会的 HYPERLEDGER 计划已经有了 30 个合作伙伴\[3\] - CoinDesk
    
    ![](../Images/b63443f53727388bd7d9e8acb6dc14df.png)
    
4.  Docker 的创始人和 CTO , Solomon Hykes 建议将 Alpine Linux 作为公司新的默认操作系统
    
    Docker 将会抛弃 Ubuntu 吗？\[4\] - InfoWorld
    
    Docker 官方镜像将会使用 Alpine Linux 替换 Ubuntu - Linux 中国 
    
    ![](../Images/546ad0339896358db9e88ac63715f423.png)
    
5.  Linux 基金会的合作项目 Node.js 基金会计划引入流行的第三方软件包“Express”
    
    Node.js 基金会计划引入社区里最流行的框架软件 Express 进行孵化\[5\]\- The Next Web
    
    [IBM 向 Node.js 捐赠 Express 框架，为 Express 丑闻画上了句号](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401468439&idx=3&sn=685c8a3bf2cdb8e5541cb936651c6f01#rd?utm_source=index&utm_medium=more "IBM 向 Node.js 捐赠 Express 框架，为 Express 丑闻画上了句号") - Linux 中国
