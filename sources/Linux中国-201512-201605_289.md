# htop 2.0 发布！支持多平台

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=401472325&idx=2&sn=11b0f4da9bb626b2e8084e1c4624d200&chksm=34f1c0030386491556a55b79f5d6f42bfd4c7dec40362746a4583859b37466704f239e686331&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401472325&idx=2&sn=11b0f4da9bb626b2e8084e1c4624d200&chksm=34f1c0030386491556a55b79f5d6f42bfd4c7dec40362746a4583859b37466704f239e686331&scene=27#wechat_redirect)

从 2.0 版开始，htop 现在是跨平台\[1\]的了。现在支持 Linux、FreeBSD、OpenBSD 和 Mac OS X 了，可以从 FOSDEM 2016 上的视频\[2\]和演讲\[3\]了解更多。 

此外，还有一些新功能：

*   如你使用 NCurses 6，可以使用鼠标滚轮进行滚动。
    
*   在设置屏中移动字段和列更优雅。
    
*   可以按下“e”来查看某个进程的环境变量设置。
    
*   重新打磨过显示界面，灵感来自 James Hall 的 vtop\[4\]。
    

此外，还有很多优化和错误修正。![](../Images/fef287c3dda156e6a46b616af3979708.png)
