# 免费才最贵：揭露「免费」Windows 10 的真实成本

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=401460076&idx=1&sn=cd81d4a235394090b51ee35e57aeec93&chksm=34f1f02a0386793c01ac3a26601e6322ec1b6af7b3cedf79167629db2ad610fe66f54396632d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401460076&idx=1&sn=cd81d4a235394090b51ee35e57aeec93&chksm=34f1f02a0386793c01ac3a26601e6322ec1b6af7b3cedf79167629db2ad610fe66f54396632d&scene=27#wechat_redirect)

> 谚语一直教育我们：世界上并没有免费的午餐。当微软公司宣布 Windows 10 操作系统将会免费发放时，不少人的第一时间想到的就是这句谚语。但随着微软公司不断地推动用户进行升级，人们逐渐发现 Windows 10 的真实成本原来就藏在一个人们难以意料的地方。

在 Windows 7 和 Windows 8 时代，用户总会采取直接或间接地方式为操作系统支付资金：他们要么直接独立购买系统，要么系统的价格已经涵盖在电脑价格当中。值得注意的是，在按日计算的情况下，Windows 7 和 Windows 8 的成本将会变得越来越昂贵。由于微软公司正想方设法地推动用户升级到 Windows 10，他们会尽可能让 Windows 7 和 Windows 8 用户的日子过得不那么舒坦。对于这两个操作系统的用户而言，他们需要承受的附加成本是生产力、灵活性和乐趣的逐步降低。

在 2016 年 2 月份之前，用户的成本已经达到了一个较高的水平。让用户感到苦恼的是，微软公司针对 Windows 7 和 Windows 8 用户的升级推送在被禁用后会自动重新设置为激活状态。随着时间的推移，升级推送通知会以弹出窗口的形式呈现。更让人抓狂的是，微软公司还对窗口上的选项进行了修改，提供给用户的选项由「马上升级」和「今晚升级」两项被修改成了只剩「马上升级」一项。

![](../Images/f5f95ac0f2993c927e734451b27a9f96.png)

此外，尽管用户一再强调自己不愿意作出升级，但微软公司还是会在未经用户许可的情况下自行下载 Windows 10 的完整安装包（4-6GB），并将其放置在一个隐秘的文件夹中。那些使用流量计费的网络用户恐将因此而承担高昂的流量资费。尽管 Windows 8 用户可以通过流量计算限制功能防止不幸的发生（Windows 7 用户就没这么幸运了），但他们势必不会在事前想到自己的电脑竟然会「偷跑」流量。

这一切还仅仅是事情的开始。在 10 月份的安装比率出现下降后，微软公司宣布他们针对拒绝升级的用户所发起的「战争」将于 2016 年 1 月份开始。微软公司在这段时间的所作所为证实了这场「战争」已经打响。

费尽心思的限制措施

尽管备受苛责，但微软公司还是执意在更新菜单下将 Windows 10 设置为「推荐」状态。这意味着在用户没有自行修改默认设置（绝大多数用户都不会特意修改）的情况下，他们的电脑将自动安装 Windows 10 系统。在这种情况下，用户只能在升级开始后再手动取消 Windows 10 的安装，系统不会在升级前让用户确认是否开始安装。

在这种情况下，或许只有深度技术爱好者可以确保自己不会被强制升级了，但事情并没有这么简单。Infoworld 的报告指出，即便是那些在升级开始后及时点击了取消按钮的用户也不能掉以轻心，因为升级进程将会在他们重启电脑后重新启动。

再者，许多用户根本就没有觉察出他们的电脑正在自行升级，因为 Windows 10 的升级程序会以最终用户许可协议（End-user Licence Agreement）的形式隐藏起来，系统会请求用户接受这项协议。尽管协议有请求接受的环节，但用户通常都会在无意识下点击接受按钮，很少有用户会对协议款项的细则进行深究。一旦你点击了接受按钮，Windows 10 的安装程序将会启动，你不能再手动取消安装。

确实，这些行为让用户感到无比苦恼。但不论如何，有仔细阅读习惯的用户还是可以避免系统出现自动升级的情况。微软公司也一再强调用户对此有所谓的「选择权」，尽管这意味着用户将一再被各种升级提示骚扰。除了自主进行手动设置之外，用户还可以向第三方工具寻求帮助。

![](../Images/ba623be3fe8865203d0cf39c23f783f0.png)

除了在 1 月份出现的各种升级措施以外，微软公司还对 Windows 7 和 Windows 8 的支持方式进行了修改。在 Windows 7 和 Windows 8 发售的时候，微软公司曾经承诺针对这两款系统的支持日期将分别持续至 2020 年 1 月 14 日和 2023 年 1 月 10 日。但在今年 1 月份，微软公司却对支持条款作出了修改：只有当用户不再对电脑芯片进行升级的情况下，支持条款才成立。

换而言之，想要享受微软公司的支持条款，用户需要一直将电脑的硬件维持原样直至 2020 或 2023 年，这显然并不现实。与此同时，如果说你新买了一台电脑，并希望给新电脑装上 Windows 7 或者 Windows 8 系统，微软公司会直接让系统的支持失活。这意味着你将不能再使用由微软公司提供的反病毒程序和安全补丁。因此，如果你希望安心使用自己的新电脑，你将不得不接受 Windows 10 系统。在 Windows 系统上线的 30 年历史中，微软公司还是第一次设定类似的限制。

尽管针对计算机硬件的限制目前仅针对商业用户，但却没有人能够保证微软公司在将来不会将类似的限制施加在大众消费者身上。

微软公司精心设计的把戏还不仅仅是这些。针对那些抱怨 Windows 10 将会通过遥感技术（其中一部分不能被禁用）对用户行为进行追踪的用户，微软公司提供了一个完美的解决方案：他们为 Windows 7 和 Windows 8 也添加了类似的追踪功能，因此用户的这个担忧将不再为升级构成障碍！

愈发紧缩的选择余地

微软公司的这一切精心设置只给 Windows 7 和 Windows 8 用户留下了这么几个选择：

1.  如果他们选择对电脑硬件进行升级，或者购置全新的电脑，微软公司所提供的支持服务将会失活。
    
2.  在升级提醒被禁用的情况下，用户将一而再，再而三地看到升级提醒的弹出窗口。
    
3.  每次启动电脑的时候都要面对自动启动的升级程序。
    
4.  硬盘需要永久性地为 Windows 10 安装包腾出 6GB 的空间，一旦安装包被删除，系统将自行重新下载。
    
5.  接受和 Windows 10 相同的用户追踪行为。
    

我们不能为这些限制措施贴上具体的价格标签，唯一可以确认的是这些措施将会给那些需要频繁使用 Windows 7 和 Windows 8 系统的用户（目前世界上有 65% 的电脑运行这两个系统）造成极其严重的骚扰。对这些用户而言，限制措施所造成的隐形成本非常高昂。

当然，微软公司也有自己的一套营销措辞。他们宣称用户如果觉得 Windows 10 的体验不佳，完全可以选择退回到 Windows 7 或 Windows 8 系统。但退回后的用户将不得不接受各种限制措施的骚扰。微软公司可不会因为你曾经「尝鲜」过 Windows 10 而对你网开一面，把你的限制措施关掉。

![](../Images/5fed7d705d51d9ac703aaecba2899a4e.png)

不得不说，这一切措施压根就和 Windows 10 是否好用没有关系。在各种限制措施的狂轰滥炸下，Windows 10 是否优于 Windows 7 或者 Windows 8 根本无关重要，这些限制措施所揭示的是微软公司对用户选择的不尊重。有些用户确实想要升级到 Windows 10，但无奈的是他们常用的一些重要程序和 Windows 10 会产生冲突。但微软公司却选择针对每一位 Windows 7 和 Windows 8 的用户施展无差别的针对措施，丝毫没有考虑这些特殊情况的存在。

在这种情况下，即便 Windows 10 能够实现覆盖 10 亿用户的目标（现在看来只是时间问题），这也仅仅是一次无比空洞的胜利。就因为微软公司的一个目标，Windows 7 和 Windows 8 的用户将被迫忍受高昂的使用成本。正如 BetaNews 的韦恩 · 威廉姆斯（Wayne Williams）所说：

「微软公司在未来宣告 Windows 10 所取得的辉煌成就的时候，在宣告 Windows 10 用户量再创新高的时候，这些数字都会成为浮云。这完全是一次无比空洞的胜利，微软公司根本就没有什么值得骄傲的。」

由此看来，免费的午餐确实并不存在。
