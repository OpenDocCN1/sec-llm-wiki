# 中标麒麟 Linux 联合打造全新云计算集装箱

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=401431448&idx=2&sn=95e19697c0e0867f1714fa26581ac209&chksm=34f160de0386e9c8748fe52d6e864ec44d28fd831d20a41462f4944d6cded175a8246af8feef&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401431448&idx=2&sn=95e19697c0e0867f1714fa26581ac209&chksm=34f160de0386e9c8748fe52d6e864ec44d28fd831d20a41462f4944d6cded175a8246af8feef&scene=27#wechat_redirect)

>   
> 作者： 中标麒麟

大数据时代，我国各地都纷纷成立了云计算中心、大数据中心。但是在移动互联网影响下，数据中心建设和应用的时间周期越来越短，很多基于集装箱设计的云计算中心开始出现。

**集装箱式的云计算中心就是将服务器，存储系统和网络设备装入金属集装箱并连接到数据中心的集群，其特点在于快速部署。目前惠普、戴尔、思科、世纪互联以及浪潮都推出了集装箱数据中心。**

云计算集装箱的出现为大规模的移动计算注入了全新的动力，甚至一些超大型数据中心也通过集装箱实现了快速部署。近日，国内领先的数据中心企业企商在线和操作系统企业中标软件就强强合作，打造了一部基于中标麒麟操作系统的全新云计算集装箱！

![](../Images/9796592bafffb2a0e7dfd490d49943ac.png)

根据中标软件副总裁、北京航空航天大学副教授兰雨晴博士介绍：该款集装箱采用全承载式整体钢结构框架，集成UPS,电池,配电,空调,消防,监控系统为一体，是一个功能完善且安全的数据中心，能够适应室外各种环境的应用，包括高海拔区域、沙尘污染、强降雨、水浸、高温日晒、地震、砖石坠落冲击、火灾以及恶意破坏。

![](../Images/512e75b916aef748a585f3c0703ea8ae.png)

根据这次集装箱的落地方，位于北京卢沟桥晓月数据中心的企商在线总裁王熠介绍：企商在线是一家国内领先的综合IDC解决方案提供商，是国内最早从事服务器租用业务、最早推出多功能虚拟主机业务、最早运营本地域外的数据中心、最早全权运营固网运营商数据中心的公司。企商在线目前拥有5家在京自主投资的T3+标准的数据中心和十五个以上的合作运营数据中心。近日，国内首家最大的基于熟人借贷的互联网金融产品――借贷宝已全面入驻该数据中心，是国内首个第三方IDC数据中心承载如此大并发交易额的案例。未来，企商在线，将借助此次合作契机，充分发挥云箱便捷、高效、节能、环保等优势，积极推动云箱在科研院所、智慧城市、智能社区、IDC扩建新建、灾备中心等方面的落地应用。

![](../Images/409b1289541999ead941080bd7f8f959.png)

发布会现场，中国工程院倪光南院士表示：国家正在大力发展云计算和大数据等相关先进产业，同时打造基于国产软件的自主可控安全产业。中标软件和企商在线这次联合发布云计算集装箱，**完全基于中标麒麟操作系统，是一个非常有价值的创举**；而一兰云联作为国内第一家中小商业银行IT/DT综合服务运营商，为此次发布的云计算集装箱在银行领域的推广应用，提供了快捷专业通道，希望三方合作能够进一步深入落实，为探索基于国产基础软件的更多实际应用带来成功的经验。

![](../Images/779cc88fa2e307b424137dca76f2f310.png)

发布会还请来了来自银行业和产业界的最终客户代表，金融领域客户表示：银行业非常重视云计算数据中心建设，希望结合国产软件走出一条高效安全的金融信息化道路，云箱的发布给银行业客户带来了新的选择，希望未来能带来更多更好的解决方案给客户。

从未来发展来看，包括IBM、惠普、CISCO、DELL、SGI、Oracle在内的厂商都开始提供集装箱式数据中心，而微软、Google的大型数据中心已经采用了这一形式。中标软件和企商在线的这次合作，第一次开创了基于国产基础软件的云集装箱产品尝试。我们有理由相信，强强联合的国产集装箱式数据中心将为数据中心的下一轮繁华绽放出璀璨的光芒！
