# grep 命令系列：使用 grep 命令来搜索多个单词

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=401379698&idx=3&sn=d96fd7028cea8896dc443f9050ee5c45&chksm=34f0aa3403872322fbc8d7a9820ffb1b0734de0c310852c8764ec4a4ea50a3dc8fb469e46293&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401379698&idx=3&sn=d96fd7028cea8896dc443f9050ee5c45&chksm=34f0aa3403872322fbc8d7a9820ffb1b0734de0c310852c8764ec4a4ea50a3dc8fb469e46293&scene=27#wechat_redirect)

要使用 grep 命令来搜索多个字符串或单词，我们该怎么做？例如我想要查找 /path/to/file 文件中的 word1、word2、word3 等单词，我怎么样命令 grep 查找这些单词呢？

[grep 命令支持正则表达式](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401351070&idx=3&sn=78181eda6115629072613e6b5718159d#rd)匹配模式。要使用多单词搜索，请使用如下语法：

```
1.  `grep 'word1\|word2\|word3' /path/to/file`
    
```

下的例子中，要在一个名叫 /var/log/messages 的文本日志文件中查找 warning、error 和 critical 这几个单词，输入：

```
1.  `$ grep 'warning\|error\|critical' /var/log/messages`
    
```

仅仅只是要匹配单词（即该词两侧是单词分界符，针对西方以空格分隔的语言而言）的话，可以加上 -w 选项参数：

```
1.  `$ grep -w 'warning\|error\|critical' /var/log/messages`
    
```

egrep 命令可以跳过上面的语法格式，其使用的语法格式如下：

```
1.  `$ egrep -w 'warning|error|critical' /var/log/messages`
    
```

我建义您们加上 -i (忽略大小写) 和 --color 选项参数，如下示：

```
1.  `$ egrep -wi --color 'warning|error|critical' /var/log/messages`
    
```
