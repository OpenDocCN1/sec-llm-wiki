# 【2015最佳运维图书评选】结果揭晓

2016年1月22日，由互动出版网及开放运维联盟共同举办的“2015最佳运维图书评选”活动落下帷幕。本次评选活动开展以来，受到广大运维同仁的积极参与，在IT运维圈引起不少关注，经过出版社精心选送、专家评审团评审和广大运维同仁的投票表决，《**IT运维之道**》、《**深度实践KVM**》、《**Python自动化运维**》等10本图书脱颖而出，成为“2015最佳运维图书”，现对评选结果予以公示。
