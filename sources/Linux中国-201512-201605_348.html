Linux 基金会悄悄移除社区推荐代表的资格

转载自： http://www.solidot.org/story?sid=46963

Linux 基金会是一个专注于宣传和标准化 Linux 和开源软件的行业组织，董事会大部分成员都是由企业会员选出：10人由白金会员选出（白金会员的年费是50万美元），3人由金级会员选出（年费是10万美元），1人由银级会员选出（年费5千到2万美元），还有2人由个人会员选出（年费99美元），他们是社区的代表。

但上周五，Linux 基金会悄悄改变了规则 [ http://www.linuxfoundation.org/about/bylaws ] （旧版本见此 [ http://web.archive.org/web/20150321165558/https://www.linuxfoundation.org/about/join/individual ] ），不再允许个人会员选举代表社区的董事。

内核开发者 Matthew Garrett 认为这与自由软件管理机构 [ http://sfconservancy.org/ ]Software Freedom Conservancy的执行董事 Karen Sandler 有关 [ https://mjg59.dreamwidth.org/39546.html ] 。她刚刚宣布将竞选 Linux 基金会董事 [ https://blogs.gnome.org/gnomg/2016/01/18/im-running-for-the-linux-foundation-board-of-directors/ ] 。

自由软件管理机构资助发起了对 VMware 的侵权诉讼，而 VMware 是 Linux 基金会的银级企业会员，它可能在幕后活动修改了规则，以免 Karen Sandler 当选后推动 GPL 执法活动。Linux 基金会最初是为 Linux 创始人 Linus Torvalds 提供稳定薪水全心投入内核开发而设立的，它很早就被指责只关注企业的利益 [ http://landley.net/notes-2010.html#18-07-2010 ] ，而不再关注开源社区。
