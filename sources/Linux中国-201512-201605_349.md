# Linux 盐计划：免费申请电脑试用 Linux，让你无忧折腾够

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=401317049&idx=1&sn=123137b6f7dcf7bd8faf10469661a6c1&chksm=34f7a7ff03802ee9a1a8c2f5b9c160fcfe0923e744000739202e9759193addc9cce0ca937ebc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401317049&idx=1&sn=123137b6f7dcf7bd8faf10469661a6c1&chksm=34f7a7ff03802ee9a1a8c2f5b9c160fcfe0923e744000739202e9759193addc9cce0ca937ebc&scene=27#wechat_redirect)

> 《庄子·至乐》有曰：万物皆出于机,皆入于机。

接触开源的最好办法无非是在自己的机器上装上 Linux ，装上 BSD， 装上各种开源软件实际亲身体验一下，然而大多数同学、开源爱好者只有一台电脑，平常都有学习和工作用途，保存有大量资料，物理机安装 Linux 不太现实，也不太方便，安装多系统又有较高门槛，且不放心，虚拟机安装使用得又不痛快，总觉得憋屈，放不开手脚。

考虑到这些因素，我们觉得**直接给你提供一台完好的电脑**，痛痛快快醉一场，潇潇洒洒闯一回，是接触 Linux 等开源操作系统最直接、最简单也最有效的方法。**物理机安装，磁盘想格就格，Linux 发行版想装哪个就装哪个，不用担心自己的数据安全，最高的硬件效率，最坦诚的开源体验，**想必是给初学者和开源小白用户接触 Linux 最有效也最舒服的方法了。

![](../Images/74a5893a0b21d265dd4362203209fc96.png)

**盐计划愿景  
**

考虑到 “欲为之而不心忍，为之而甚心痛” 的这些状况， Linux Story \[ http://www.linuxstory.org/ \]  社区特意发起“Linux 盐计划”，英文名称是“ls salt plan”，其中 ls 是 (((ls salt) salt) salt) salt…..的递归缩写。这个计划就是为了给所有想接触想使用 Linux ，自己没有多余电脑，玩虚拟机玩得不爽的开源爱好者准备的，开源社区的同学们可以向我们提交申请获得机器，自由体验各种 Linux 发行版。

然而安装使用 Linux 有较大概率会遇到的一个问题就是，驱动。市面上大量的电脑型号安装 Linux 过程中会遇到一些驱动问题（尤其是 Debian，Debian 坚持不收录非自由软件，包括不收录很多闭源的驱动），我们鼓励参与试用的用户解决了安装系统出现的驱动问题之后将解决过程分享出来，这样又可以给其他用这个型号电脑的用户使用 Linux 带来直接的帮助。最后整个 Linux 样机试用**计划的目标是积累一个数据库，包括市面上主要型号的电脑或者网卡、显卡在各种 Linux 发行版 （譬如 Ubuntu、openSUSE、Fedora、ezgo Linux等等）解决驱动问题的知识库**。这个知识库将造福开源社区，极大地帮助到想使用 Linux 但是第一步安装会遇到一些问题的普通用户，这将对 Linux 的普及和推广扫除一个最大的障碍。而这个解决问题的知识库，我们就把它比喻成 “盐”。

盐是人体必备，量不大但不可或缺，我们做的这个 Linux 样机试用也许可以成为开源社区的一把盐，真正帮助到想使用 Linux 有没有机器的用户，长久来看又能帮到想使用 Linux 但是会遇到各种问题的用户。我们希望将小白用户和有心接触 Linux 的用户接触开源的门槛降到最低。

**盐计划的意义  
**

这个牛必须要吹，事实上，**Linux 盐计划是国内开源社区从未有过的创举**，我们义务、自发地推广开源多年，但是有些先天问题这么多年以来始终无法解决。然而这一次我们准备好了，直接拿出大批机器供大家免费申请试用，一步到位地降低小白同学使用 Linux 的门槛，并且希望以此为契机，真正地让 Linux 和开源软件走近日常，走近实用。

**盐计划三步走  
**

2015年下半年的时候，我们做了一次尝试，Linux Story \[ http://www.linuxstory.org/ \]  社区与中科院开源协会 \[ http://www.opencas.org/ \] 合作，为社区的同学们免费提供电脑“折腾”，鼓励同学们安装使用 Linux ，这次活动的效果也给了我们很多信心，让我们下定决心继续走下去，并要做得更大更好。所以我们在2016年1月正式推出 Linux 盐计划。我们规划拿出超过一百台电脑供想尝试开源软件和 Linux 的人们免费申请使用，并且从 2016 年开始长期、持续地进行。

1.  Linux 盐计划第一期开始执行（2016年1月）。
    
2.  Linux 盐计划从第二期开始，稳定成为规律性、长期性、周期性的项目。
    
3.  Linux 盐计划伴随着一期一期的执行，开始稳定地为开源社区积累“Linux 之盐”。
    

**“柴米油盐”计划**

如果只是试用 Linux，解决安装系统的驱动问题，那我们做得还太少了。除了盐计划，Linux Story 社区还将陆续推出 “Linux 柴计划”、 “Linux 米计划”、 “Linux 油计划”，最后组成 “Linux 柴米油盐四大计划”，柴米油盐是居家必备，而Linux 柴米油盐四大计划，也是我们准备的开源四大宝，我们希望通过这四个计划，真正地让开源走到我们的身边，走进我们的生活，而不是在高冷的科研实验室，在冰冷的机房，在极客的炫耀中存在。我们坚持认为，只有在我们身边的技术工具才是真正有意义和有价值的，用户数只有极少量程序员和技术人员的开源是没有活力和生命力的。开源是一种精神、也是一种强大的工具，我们会通过坚持努力，让开源真正参与到社会，参与到生活的方式，让开源参与到改善我们的生活，改进我们的社会，改良我们的教育。这也是我们认为的开源的社会意义。

**盐计划主办方  
**

Linux 盐计划是一个开放的项目，活动由 Linux Story 社区 \[ http://www.linuxstory.org/ \] 、ezgo 社区 \[ http://ezgolinux.org/ \] 、中科院开源协会 \[ http://www.opencas.org/ \] 、北大开源协会和宏碁俱乐部共同发起和举办，目前还有 重庆 Linux 用户组 \[ http://www.chongqinglug.org/ \]  、Linux 中国 参与协办。同时欢迎更多的开源组织、高校开源社团和城市LUG与我们联系，加入 Linux 盐计划，一起为推广开源和 Linux 贡献我们的力量。（联络邮箱 ls ^^ linuxstory.og ，请将 ^^改为 @）

**申请要求及活动规则  
**

开源社区长期以来都是以近乎公益的志愿协作方式运作的，为了保证有限的资源能到达真正需要的朋友手中，考虑再三，我们还是设定了一些要求，随着资源越来越丰富，参与机型、志愿者和厂商越来越多，我们会越来越放开条件与限制。

1.  在校学生（不限中学生、专科、本科、研究生、博士生）或国内 IT 公司就职员工优先。
    
2.  所有样机最终需归还宏碁俱乐部，申请人取得机器，在使用过程中需爱惜电脑，不损伤，不拆解。
    
3.  不限安装的系统、不限发行版、推荐优先使用 ezgo 、Debian、openSUSE、Fedora、Ubuntu、FreeBSD等。
    
4.  为保障机器流动、让更多人受益，限定每次申请成功后，从取得机器到归还机器，使用时长 42 天。
    
5.  鼓励产生如下内容，但是不限于以下内容，最终目标是鼓励折腾，鼓励创造。
    

*   在使用 Linux 过程中遇到的兼容性问题，驱动问题及解决方案
    
*   硬软件配置问题，复杂的软件配置过程等问题
    
*   开源项目的创建于维护过程与心得及原创项目的项目介绍
    
*   其他与开源相关的有趣、有意义、有意思的内容
    

*   参与完试用之后，需提交一份使用过程的记录（形式为文章），提交给 Linux Story 社区，发表到 Linux  盐计划开源知识库中，协议为 cc 共创协议。（推荐 cc，但是以作者采用的实际协议为准），这也是这个项目的长期意义。
    

**活动奖励  
**

为了 鼓励参加活动的朋友创作出对开源社区有意义有价值的内容，Linux 盐计划的每一期都会设立一项大奖和多名鼓励奖。2016年第一期的大奖是 Iconia One 8 平板电脑一台。鼓励奖包括 新秀丽背包、Acer 无刻键盘、威戈背包等共计五份。奖项的确定由 Linux 盐计划委员会评定。Linux 盐计划委员会由 Linux Story 社区、中科院开源协会和北大开源协会核心贡献者组成。

**志愿者招募  
**

本次活动涉及机型数量众多，在此我们也向开源社区招募2名志愿者，主要负责与申请人的沟通，使用过程中撰写报告的指导，所以会需要一些 Linux使用的功底，最好是熟悉开源社区运作模式的学生。每名志愿者也将成为 LinuxStory.org 的开源顾问，并且将获得一份纪念奖品。有意的同学请邮件与 ls^^linuxstory.org（请讲^^替换成 @） 联络，如果能附上一段自我介绍或者简历、一些关于这个项目的想法就更好了。

**参与方法  
**

希望参与这个计划免费申请样机的同学们，请阅读这一节内容。希望参与活动组织的同学请参见上一节“志愿者招募”，**2016年第一期活动1月31日截止申请**。参与 Linux 盐计划免费申请样机试用的办法和流程是：

1.  请在本页面留言发表您的看法，并加入 Linux Story 读者交流群 （ 群号：**199872803**），同时欢迎关注我们的微信，获得项目和活动的最新进展（微信公众号id是：**linuxstory**）
    
2.  以 “**#参与 Linux 盐计划，申请电脑试用 Linux# + 姓名（或 id） + 单位 （或社区名称）**”为邮件标题向 ls^^linuxstory.org（请讲 ^^改为 @） 发送邮件发送邮件，邮件正文中包含您的自我介绍 + 申请样机的用途说明，我们会在一周之内做出回复，并最终通过 Linux 盐计划委员会评估是否通过申请，予以最终确认。为了提高申请效率，请您在不泄露个人隐私的情况下，尽可能向我们介绍您的背景。
    
3.  通过的同学会收到我们的邮件确认，同时展开取得样机试用样机的程序。
    

最后非常欢迎关心开源的同学留言，分享你的看法和倘若取得样机的使用方法，部分同学申请了机器不太清楚可以用来做些什么，你的留言可能帮到他，也会给我们活动主办方带来帮助。

**写在最后**

这次 Linux 盐计划是国内开源社区前所未有的开源推广计划，有的朋友记得早年 Ubuntu 用免费邮寄光盘的形式推广过 Ubuntu，花费不菲，但是效果颇好，这一次Linux Story 社区、ezgo 社区、中科院开源协会、北大开源协会、宏碁俱乐部、 重庆 Linux 用户组 、Linux 中国 一起携手，用前所未有的便利希望拉近 Linux 和开源与普通用户之间的距离。

最后还是那句话：爱她请把她留在身边。开源只有存在于我们的生活中才有意义，绝不只是 Geek 高冷的玩物。推广开源前路漫漫，我们希望开源是一种生活方式，一种思维模式，一种精神理念，存在于我们的生活和社会之中，用实实在在的努力和看得到的价值，让开源真正参与到社会，参与到生活的行进，让开源参与到改善我们的生活，改进我们的社会，改良我们的教育。这也是我们认为的开源的社会意义。
