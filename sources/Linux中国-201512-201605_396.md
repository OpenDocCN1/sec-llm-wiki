# 谷歌告诉甲骨文说 Android 现在受到 GPL 保护了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=401196732&idx=2&sn=b69a3036ab81bdd2a8a953da1755de5d&chksm=34f5fdfa038274ec07f390aa712b1f3993a0f459fb0d109fef62df9633193b531aac0e7899fd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401196732&idx=2&sn=b69a3036ab81bdd2a8a953da1755de5d&chksm=34f5fdfa038274ec07f390aa712b1f3993a0f459fb0d109fef62df9633193b531aac0e7899fd&scene=27#wechat_redirect)

> 来源：SOLIDOT 参考原文：http://www.solidot.org/story?sid=46802

谷歌在下一个版本 Android N 中用甲骨文的 JDK（Java Development Kit）的开源版本 OpenJDK 替代了它的 Java API 实现。甲骨文在 OpenJDK 项目中使用的是 GPL 许可证。

谷歌之后立即告诉了法庭，它已经发布了新版的 Android 平台，得到了甲骨文的明确授权，甲骨文在自由开源许可证 GPL 下授权了谷歌自由使用 OpenJDK。

谷歌与甲骨文的法律诉讼还会继续下去，但争论的焦点将围绕着旧版的 Android，新版的 Android 在谷歌看来是不受影响的。

谷歌说 Android N 已经发布是一个很有趣的声明，实际上它只是改了下源代码，正式的商业版本还要等待一段时间后才会发布。
