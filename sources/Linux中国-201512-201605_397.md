# Chirimen：Mozilla 发布基于 Firefox OS 的物联网单片机开放平台

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=401196732&idx=4&sn=6b6d776928a1a7e246a4d75cabd805bd&chksm=34f5fdfa038274ecb26a940b9dbc05ea4a6413874ed26a55572b5870e63d53d609d35e84f89c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401196732&idx=4&sn=6b6d776928a1a7e246a4d75cabd805bd&chksm=34f5fdfa038274ecb26a940b9dbc05ea4a6413874ed26a55572b5870e63d53d609d35e84f89c&scene=27#wechat_redirect)

> 来源：CNBETA 参考原文：http://news.softpedia.com/news/meet-chirimen-a-firefox-os-powered-iot-single-board-computer-developed-by-mozilla-498603.shtml作者： Marius Nestor  
> 编译文章：http://www.cnbeta.com/articles/464763.htm

身居Firefox和Thunderbird背后的Mozilla，今天发布了一款名叫Chirimen的单片机新品。而它最大的特色，就是采用了Firefox OS。Chirimen主要面向物联网方面的web开发者，并且提供了各种技术来拓展I2C和GPIO WebAPI，以便控制那些搭载Firefox OS 2.0或更高版本的设备。也就是说，开发者们能够借助浏览器技术来轻松开发现实世界中的小物件。

![](../Images/4e7c7b4347dc7c46b8c257364a5a8f01.png)

Mozilla日本社区项目网站写到：“我们将分享开放固件代码、板型设计、制造流程、API规范、以及所有必须的资源，感谢开发者在项目标准化方面的工作”。

规格方面，Chirimen开发版采用了瑞芯微RK3066 SoC、1GB DDR3 RAM、1GB NAND Flash、2组IC端口、2个UART端口、2个SPI端口、1个可配置GPIO端口、1个microSD卡槽、1个USB端口、以及1个USB microUSB OTG端口。

![](../Images/700f8d6701968bcde3675709ae3f2961.png)

Chirimen的大小仅为80x48mm，并且采用了红色的PCB板。此外，该开发板还提供了一个microHDMI母口，一个模拟输入和PWM端口，以及音频模拟/立体声输入输出。

其硬件设计是开放的，XX GPIO针脚允许开发者们连接和编程广泛的实体器件，比如LED、传感器、按键等。目前Mozilla暂未公布它的确切上市日期，但是价格会在$50美元左右。
