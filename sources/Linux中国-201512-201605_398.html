展望2016年，ChromeOS、Android 甚至是微软都将在 Linux 世界当中掀起新的浪潮。

Linux 新一年态势展望

随着2015年的全面落幕，现在也是时候对 Linux （以及更为广阔的自由与开源软件）世界做出未来趋势展望了。那么，我的这些预测能否在2016年中一一实现？谁知道呢！不过我还是要展望预测一下！

Linux 新一年态势展望

Wayland 仍然不受待见

没错，这就是我的观点。而且我敢把这话就撂在这儿，到2016年年末，大家仍然不会给 Wayland 什么好脸色。当然，也许会有这样或者那样千奇百怪的 Linux 发行版内置有 Wayland。不过，各大主流发行版？别闹了，冲着 Xorg 这事就没戏！

Wayland 仍然不受待见

Systemd 的适用范围将持续扩大

systemd 的适用范围将持续扩大，并逐步拓展至办公套件以及网络浏览器当中——好吧！这话根本不可信。不过说真的，这套小玩意确实会不断增加自己的疆土，并在新的一年中迎来更多新功能。总之，不管大家喜欢或者不喜欢，它都会在 Linux 社区中占有一席之地。

Systemd 的适用范围将持续扩大

Canonical 将撤出手机平台

在2016年当中，Canonical 的扩张速度将有所放缓，甚至完全停止——这里说的主要是其开发 Ubuntu 手机版的事。与此同时，该公司还将重新把注意力集中在 Ubuntu 的桌面与服务器版本身上。好啦好啦！我知道大家已经开始提出质疑之声了。不过，在我看来，这种方式能够让 Canonical 公司在市场上取得更大的成功（包括财务以及其它方面）。

Canonical 将撤出手机平台

Android 将迎来更多以桌面为核心的新增功能

2016年推出的下一个主要版本将增添新功能，从而使 Android 设备在使用感受上更接近于现代桌面操作系统。重要提示：应用程序将获得可移动且可堆叠的运行窗口。在此之后，相信新型 Android 笔记本电脑（以及配备键盘一同发售的平板设备）也将指日可待。

Android 将迎来更多以桌面为核心的新增功能

ChromeOS 将能够全面接入 Google Play 应用商店

让咱们再来说说谷歌，2016年 ChromeOS 将获得直接通过 Google Play 应用商店安装并运行 Android 应用程序的能力。尽管还不太可能支持应用商店中的全部现有移动应用产品，或者说无法像 Android 平板设备那么拥有通吃的能力，但其至少也能够与 Android TV 在这方面打个平手（也就是支持少数、但数量仍在持续增加的应用类型）——但可以肯定的是，此举无疑将让 ChromeOS 设备在浏览器之外获得更可观的发展空间。

ChromeOS 将能够全面接入 Google Play 应用商店

新的基于 Linux 的手机操作系统即将出现

尽管——或者说也许是因为——截至2015年年底除 Android 之外的其它 Linux 手机系统基本上全军覆没，因此新的一年，我们应该会迎来一款新型手机 Linux 系统，而且相信它能够翻起点浪来。那么，谁会成为这位后起之秀？这个我说不好，但我相信会有企业（或者组织）在这一领域给我们带来大大的惊喜。

新的基于 Linux 的手机操作系统即将出现

elementary， openSUSE， Fedora 将占据更可观的市场份额

Linux 世界有时候真的非常疯狂。上一秒钟，发行版 A 还在全球范围内广受追捧，而到了下一秒钟，发行版 B 却又横空出世并主宰一切。我认为新的一年当中，elementary OS、openSUSE 以及 Fedora 将从2015年年末仍然存在的各发行版当中杀出血路并占据可观的市场份额。那么，具体会占据怎样比例的市场份额？这个我说不好，但请大家记住我的观点，相信这一议题在2016年中值得关注。

elementary， openSUSE， Fedora 将占据更可观的市场份额

微软将扩张自身开源活动

2016年，微软公司将进一步提升其在自由与开源世界当中的推进力度。更多代码将遵循自由许可（或者至少是开源许可）推出，而 Linux 也将越来越多地被摆在软件帝国高层人员的议程当中。我们将亲眼见证微软公司在 Linux 与 FOSS 各相关会议上的积极表现，而 Linux 社区也将逐步接受这样的现实——听起来很怪，但这就是现实。

微软将扩张自身开源活动
