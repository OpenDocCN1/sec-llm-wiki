阿里云中间件产品 EDAS 正式商用， “互联网+ 中石化” 只需90天

1月6日，阿里云宣布旗下企业级互联网架构核心组件——企业级分布式应用服务（简称 EDAS ）正式商用，这也是国内首款商用的大规模企业级分布式应用服务。

今年7月，针对企业在上云时遇到诸如性能瓶颈、数据孤岛、重复开发等问题，阿里云发布了一套不受性能限制、可无限扩展、具有敏捷创新能力的企业级互联网架构解决方案，大大降低企业上云的成本。作为核心组件，企业级分布式应用服务 EDAS 经受了淘宝10年互联网架构磨炼，适合快速构建大规模分布式互联网应用，是阿里云中间件产品家族的重要成员。

目前，阿里云 EDAS 的案例已遍布政务、物流、车联网、运营商、大型民企等领域，中石化、红领创投、芒果 TV 等明星企业利用阿里云 EDAS 成功构建起自己的互联网服务。

具备单应用 5K 运维能力的一站式 PaaS 平台

阿里云 EDAS 是阿里巴巴超大规模互联网电商系统的结晶，沉淀了10年运维经验和大量运维工具，具备对单个应用多达5000台服务器规模的快速发布能力，包括个性化的 Beta 和分批发布机制。

EDAS 所提供的分布式服务框架，源自于阿里巴巴内部使用规模最大的中间件产品——HSF。自2007年诞生以来，HSF 服务框架就成为了阿里巴巴内部服务化改造的基础组件，其无中心化的架构体系、久经考验的性能以及良好的用户体验，支撑了生产环境所有系统的服务化调用，在阿里内部日均调用达千亿次，峰值调用达到每分钟30亿次。

作为以“应用”为中心的 PaaS 平台，阿里云 EDAS 的产品服务覆盖了从应用的创建到应用的部署与扩容，可实现对大规模互联网应用在发布和运行过程中的全面管理，同时能根据机器的负载及应用的业务指标，实现自动弹性伸缩功能。

此外，EDAS 还有许多独有的特性：提供标准的 Java Web 应用容器，集成多款成熟的互联网中间件，为企业级应用提供淘宝级的容器环境，全面兼容 Apache Tomcat；支持对 IaaS、容器、应用和业务的全方位监控，同时允许客户根据自己的业务场景，实现对应用业务报表大盘的定制；鹰眼监控系统能够分析分布式系统的每一次系统调用、消息发送和数据库访问，可精准发现系统的瓶颈和隐患。

互联网架构解决互联网的问题

对很多向互联网转型的大型企业和创业公司来说，传统的构架与指数增长的互联网在线业务无法匹配，当用户达到亿级的时候，网站过载、性能瓶颈、重复开发已经成为业务发展瓶颈，而传统的一些组件也难以适应互联网业务需求。

“互联网的问题要用互联网的架构来解决。”企业级互联网架构负责人蒋江伟表示，“由服务框架组成的阿里云分布式服务产品，抽离了相似的业务逻辑并单独部署，在需要时只需远程调用服务框架，大大节约了前端系统的开发成本，也提高了系统的可维护性和可扩展性。”

这套沉淀多年的企业级互联网架构由 EDAS 应用框架、MQ 消息队列、DRDS 分布式数据库这三剑客组成。随着阿里云 EDAS 的正式商用，企业将告别陈旧的内竖井式、烟囱式系统，在控制成本的前提下实现性能和可用性的线性提升。

一些知名企业如中石化、红岭创投、芒果 TV 已经利用阿里云 EDAS 构建了自己的互联网应用。

2015年4月1日，阿里云协助中石化搭建的工业品电商网站“易派客”正式上线。作为中石化首个互联网架构的电商平台，易派客从立项到上线仅用时3个月。

阿里云为中石化的电商场景量身定制了“去中心化”的分布式应用服务框架，能够处理2000－3000亿次调用服务，2万亿条业务调用链，管理4000次线性扩容和缩容。易派客订单中心、用户中心、支付中心、物流中心、呼叫中心等几大模块都在短期内构建完毕，并可随时随地扩容。

试运营10个月后，“易派客”成交额累计突破70亿元，相当于再造了一个 B2B 领域的1688。
