# CentOS 7 ARM 版正式发布：支持树莓派2/香蕉派/CubieTruck

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=400944113&idx=4&sn=eaa072f52e60fb245f7e100852080cf5&chksm=34f9d0b7038e59a1a163890098d95821ed898ee69aa6054d070285f49bee16c520fb8113f5a4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=400944113&idx=4&sn=eaa072f52e60fb245f7e100852080cf5&chksm=34f9d0b7038e59a1a163890098d95821ed898ee69aa6054d070285f49bee16c520fb8113f5a4&scene=27#wechat_redirect)

来自 CentOS 团队的 Karanbir Singh 宣布，基于 ARM 硬件架构的 CentOS 7 Linux 系统已经发布！

当前，除了 Twitter 上一则消息外，CentOS 开发者们并没有在他们的网站上对这个 ARM 版本有更多说明。

![](../Images/15f4483507e43801188f79fa2d89a875.png)

根据目前给出的下载链接看，该 CentOS 7 ARM 版可以工作在各种 ARMv7 设备上，预构建的二进制镜像包括了流行的树莓派2Raspberry Pi 2、香蕉派Banana Pi和 CubieTruck （这是一个国内团队的产品，闻名于国际）。

下载链接： http://mirror.centos.org/altarch/7/isos/armhfp/
