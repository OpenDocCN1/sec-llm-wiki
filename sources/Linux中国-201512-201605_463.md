# 全球首个互联网网页上线 25 周年

> 据国外媒体报道，蒂姆·伯纳斯·李Tim Berners-Lee的世界上首个“万维网”网页，于1990年12月20日在欧洲粒子物理研究所CERN上线。也就是说，今天是互联的25周岁生日。

  

![](../Images/06f3c2a104c0af3e6cc56dae369e01ee.png "全球首个互联网网页上线25周年 写了这些内容")

*全球首个互联网网页上线25周年 写了这些内容*

报道称，最初的网页是在欧洲粒子物理研究所（CERN）上线，但直到1991年8月才对外公开。

最初的网页内容也不过是对基于超文本的项目hypertext-based project如何实现的解释，可以这么说，当时的网页成为了现今互联网的基础。就连现在，仍有不少人都认为互联网就是网页，这当然是不对的。

25年过去了，万维网创始人伯纳斯·李仍投身于互联网事业，是万维网论坛的主导者。事实上，他正在努力保护网络的开放性，应对政府部门的内容检查和运营商破坏网络中立性的企图。

而当时的欧洲粒子物理研究所CERN的则将研究重点转向了粒子物理。

互联网是一个平台，而不是简单的文档集合。互联网已深入用户生活方方面面，从装进口袋的手机到虚拟头戴设备。但是，互联网的核心仍未发生改变。那就是成为一种动态工具，在全球范围内分享信息。
