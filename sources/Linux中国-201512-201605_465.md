**Linux** 已经在不知不觉中走到了我们生活中的各个角落，伴随着 Linux 的成功，**开源**文化也逐渐成了世界风潮。无论您是程序员、运维人，也无论您是资深高手、业界菜鸟，只要您不能对发生在身边的这一切熟视无睹，那么您一定对开源世界发生的事情、对技术圈热捧的新玩意、对历久弥新的那些经典工具，都可能会有兴趣去看看。  

  

也许您想要一个能不断给您带来开源技术文章、开源资讯热点的平台，因此，我的朋友们，向您推荐 “**Linux 中国**”（**https://linux.cn**）。

  

  

### **🐧 关于 Linux 中国**

* * *

  

  

> Linux 中国是一家创立于2003年的国内开源社区，主要关注方向在 Linux 推广、Linux 技术研究、Linux 业界事件的传播。Linux 中国通过网站、微博、微信和邮件列表等平台传播各种 Linux 技术和资讯，并组织了 LCTT 翻译组对国外的开源方面的文章进行大量翻译，得到了开源社区的支持。

  

官网： **https://linux.cn/** （点击“**访问原文**”即可直达）

  

### **🐧 关于 LCTT**

* * *

  

  

> LCTT，全称是：Linux.CN Translation Team，是由 Linux 中国的站长于2013年9月10日倡议发起的。会员有上百人左右，并有数十积极活跃会员。LCTT 成立以来翻译了来自国外的上千篇文章，得到业界好评。是国内开源网站有数的翻译组织之一。

官方网站： **https://lctt.github.io/**

志愿者群： **198889102**，验证信息：“**志愿者**” （仅限翻译志愿者加入）
