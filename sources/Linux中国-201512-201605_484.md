您或许刚刚接触到开源和 Linux，也或许已经是深谙开源之道、精通 Linux 的积年老手；您或许还在孜孜求学当中，也或许已经从 “Windows 八级钳工”改行到了 “Linux 车间”；您或许每天仍处于苦逼的 coding 中，也或许还在没白没黑地部署和升级系统、咬牙切齿的寻找被黑客攻击的蛛丝马迹。

  

无论是那种情况，也许您想要一个能不断给您带来开源技术学习、开源资讯热点的平台，因此，我向您推荐 “**Linux 中国**”（**https://linux.cn**）。

  

  

### **🐧 关于 Linux 中国**

* * *

  

  

> Linux 中国是一家创立于2003年的国内开源社区，主要关注方向在 Linux 推广、Linux 技术研究、Linux 业界事件的传播。Linux 中国通过网站、微博、微信和邮件列表等平台传播各种 Linux 技术和资讯，并组织了 LCTT 翻译组对国外的开源方面的文章进行大量翻译，得到了开源社区的支持。

  

官网： **https://linux.cn/** （点击“**访问原文**”即可直达）

  

### **🐧 关于 LCTT**

* * *

  

  

> LCTT，全称是：Linux.CN Translation Team，是由 Linux 中国的站长于2013年9月10日倡议发起的。会员约有百人左右，并有数十积极活跃会员。LCTT 成立以来翻译了来自国外的上千篇文章，得到业界好评。是国内开源网站有数的翻译组织之一。

官方网站： **https://lctt.github.io/**

志愿者群： **198889102**，验证信息：“**志愿者**” （仅限翻译志愿者加入）
