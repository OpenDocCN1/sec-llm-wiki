# 每日安全资讯：汽车成黑客主要攻击目标?大众成立安全公司

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608202&idx=3&sn=9e1ca86053801be750014f3214056c21&chksm=bdce8a8c8ab9039ae83f962dc8aa0f515096448062423503b72afdd8f0bae2644731d788ebb1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608202&idx=3&sn=9e1ca86053801be750014f3214056c21&chksm=bdce8a8c8ab9039ae83f962dc8aa0f515096448062423503b72afdd8f0bae2644731d788ebb1&scene=27#wechat_redirect)

  

北京时间9月15日消息，据外媒报道，随着汽车日趋计算机化，它们受到攻击的风险也在不断增加。这正是大众新成立一家网络安全公司，保护新一代汽车安全的原因。大众当地时间周三宣布，它将与一名以色列情报机关前主管合作，成立一家名为Cymotive Technologies的网络安全公司。目前尚不清楚大众在新公司中的投资，但安全专家警告称，联网汽车和自动驾驶汽车终有一天会成为黑客的主要攻击目标。

甚至大众的老车型也会受到攻击。上个月，研究人员称黑客可以通过远程控制钥匙系统对数百万辆大众汽车发动攻击。研究人员称，从理论上说，通过对汽车固件逆向工程，然后拦截从车钥匙发送给汽车的信号，他们能远程开启和锁紧车门。

研究人员表示，大众需要对汽车固件进行更新，解决存在的安全问题。大众当时表示，它将不断提高汽车安全性。

其他安全专家警告称，具有联网能力的新款汽车也存在安全缺陷。去年，两名黑客演示了对一辆2015年款吉普·切诺基的远程攻击。菲亚特·克莱斯勒后来召回了部分汽车，并向车主提供预装有更新包的U盘，修正存在的安全缺陷。

大众周三将提高车辆安全性的尝试称作“长期投资”。包括以色列安全机关辛贝特前掌门尤瓦·迪斯金(Yuval Diskin)在内的3名以色列安全专家将领导新成立的公司。迪斯金将出任新公司董事长，他在一份声明中说，“通过与大众合作，我们将打造一流的网络安全专家团队。”
