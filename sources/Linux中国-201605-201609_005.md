# 每日安全资讯：谷歌、Facebook等巨头逼迫美国交出互联网控制权

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608197&idx=5&sn=6180852fa7939a59dda9031d41516fb1&chksm=bdce8a838ab903951d64af4e8fbf8488a623b42a6e8194798ef4cad103bc99be94dd9a335213&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608197&idx=5&sn=6180852fa7939a59dda9031d41516fb1&chksm=bdce8a838ab903951d64af4e8fbf8488a623b42a6e8194798ef4cad103bc99be94dd9a335213&scene=27#wechat_redirect)

凤凰科技讯 北京时间9月14日消息，据外媒报道，多家知名科技公司呼吁美国国会把互联网“钥匙”交给国际社会。路透社刊文称，Facebook、谷歌和Twitter都签署了一封措辞强硬的公开信。

互联网诞生于美国，迄今为止美国商务部一直控制着互联网。但是，正在筹备阶段的一项计划将把全球互联网控制权由美国移交给被称作ICANN的非盈利组织。虽然ICANN位于洛杉矶，但移交之后，互联网将由国际社会共同控制。

美国共和党领导人坚决反对这一计划，称这会增加中国在互联网领域的影响力。美国参议员特德·克鲁兹(Ted Cruz)致函美国商务部、国家通信和信息管理局称，“这一提案将极大地增加外国政府对互联网控制能力，强化对内容的监管，使ICANN领导层采取不负责任的行为。”

公开信显示，谷歌、Facebook等知名科技公司认为移交互联网控制权是“必须的。稳定、具有互操作性的全球互联网对于我们的经济和国家安全至关重要，我们坚信完成控制权移交计划符合美国的最大利益”。据悉，雅虎、CloudFlare和亚马逊也签署了这封公开信。

许多推动互联网自由的组织也支持移交计划，但强调，任何一个国家或利益相关方都不应当对互联网的未来有过大控制权。互联网言论自由组织Internet Association总裁、首席执行官迈克尔·贝克曼(Michael Beckerman)春季发表声明称，“互联网产业正在评估这一提案，将支持维持多方共管模式的移交计划。互联网治理模式必须对所有利益相关方一视同仁。”另外一家互联网言论自由组织Internet Society也致函美国国会，明确表示支持移交计划。

美国国会计划当地时间周四就移交计划举行听证会，10月1日将进行投票表决。
