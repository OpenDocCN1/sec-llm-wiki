# Swift 3.0 发布！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608197&idx=2&sn=8bf00108e013862787c58ae6f9364cc5&chksm=bdce8a838ab90395c9f236d7f0ef568094b24a4f0ed375c95f85b761dbc8e9157b20adfa1594&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608197&idx=2&sn=8bf00108e013862787c58ae6f9364cc5&chksm=bdce8a838ab90395c9f236d7f0ef568094b24a4f0ed375c95f85b761dbc8e9157b20adfa1594&scene=27#wechat_redirect)

这是 [Apple 开源 Swift](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=400584045&idx=3&sn=7d00ccfcce252aa908a36581e28aeb29#rd) 之后首次发布\[1\]的重大版本。Swift 3 是一个重要版本，包含了多达上百项的主要改进，包括对语言核心和标准库的改进，Linux 版本增加了核心库，并首次发布了 Swift 包管理器\[2\]。

![](../Images/c4b69b42d3d2a9142f7fb912c8a7eac9.png)

Swift 3 不兼容于之前发布的 2.2 和 2.3，也就是说，之前为 2.2 和 2.3 开发的代码，需要经过修改才能运行在 3.0 上。具体的不兼容情况和迁移信息请参见： SE-0005 、 SE-0006 和迁移指南\[3\]。这些改变主要来自对标准库 API 的命名，也完全改变了导入 Objective-C API 到 Swift 的方式。不过 Xcode 8.0 代码迁移工具能自动处理许多必要的源代码变化。

Swift 3.0 的文档也相应更新了，更多语言细节可以参考这里\[4\]，或免费的 iBook。

平台支持方面，Linux 版本现在包括了 Swift 核心库\[5\]和 Swift 包管理器\[6\]。Ubuntu 14.04 和 15.10 用户可以下载\[7\]官方发布的二进制版本。而对 Mac 平台， Swift 3.0 会作为 Xcode 8.0\[8\] 的一部分出现。
