今天是 “AWS 技术峰会 2016 北京站”召开的第一天。不出所料，来参加大会的人非常的多，虽然并不是周末，但是依然来了几千人，以至于本来还算宽敞的北京国际饭店会议中心的三层楼里面都到处是人。不说三楼的主会场我根本挤不进去，就连二楼的转播大厅都坐满了人——最后终于手疾眼快地在别人走开后找到了一个位置。

 ![](../Images/f65ce61179a38cc94c27234ff46f4cb5.png)  

**好多的人，找个位置好难……**

  

说起来 AWS，大凡了解点云计算的人可能都知道，甚至在当前这个“逢会必谈云”的年代， AWS 的璀璨光彩已经掩盖住了 AWS 背后的 Amazon 公司。

  

> AWS 自 2006 年成立以来，便通过不断引领云计算技术创新，改变组织获取和管理IT基础设施的方式。如今，AWS 已拥有超过 1 百万个活跃客户，并可提供 70 多项服务，包括计算、存储、网络、数据库、分析、联网、通信、机器学习、移动、物联网、应用服务等。
> 
> ——引自 AWS 官方通报

  

作为云计算领域的领袖厂商之一，AWS 自然不需要我去溢美，不过，从 AWS 的发展和变化当中，我还是发现一些也许是下一步潮流的方向。

  

本次大会正式宣布了 AWS 落地的消息，**AWS 已经在今年的 8 月 1 日正式在国内展开业务了**，不过一直等到今天召开大会才开始庆祝这一喜讯。亚马逊AWS全球副总裁、大中华区执行董事容永康表示，“用户一直希望我们在中国建立AWS基础设施，以便他们可以在AWS上运行更多的工作负载、提升客户体验以及加速业务发展。” AWS 的北京区域是和光环新网合作落地的，据说**宁夏节点也已经在筹备中**了。

  

> 同时，在未来的几个月中，AWS 将按照“前店后厂”的模式，投入运营 AWS 在中国的第二个区域-AWS中国（宁夏）区域。
> 
> ——引自 AWS 官方通报

  

  

![](../Images/f882711524ccff538f65d83619583a6d.png)  
**满满的主题演讲**

  

今天一早，我驱车赶往 AWS 技术峰会2016 北京站的会场时已经稍微晚了一些。穿过人山人海，在展区走动时，突然发现一个有趣的东西：**USER GROUP**！——这是什么？难道 AWS 也有用户社区了，真是恕我孤陋寡闻，之前还从来没听说过云服务生态已经到了营造线下用户社区这个阶段了呢。

  

![](../Images/3f1de3dd4a16566539bc1deadc0a6cb3.png)  
**亚马逊 AWS 用户社区成长之路**

  

由于我参加过几次 Linux User Group 的活动，因此对 AWS 用户社区的情况很感兴趣。正好，用户组展位旁边有位美女主持人 Bekkii 在做介绍，遂上前向她了解了一下用户社区的发展情况。

  

![](../Images/bfee2e938d6471173acc8804d37e0d36.png)  
**美女主持人 Bekkii 画的好看吗？**

  

原来，AWS 的用户社区生态已经有几年的发展了。最初在美国、日本都有不少的用户、开发者自发建立的用户社区。我在网上搜索了一下相关信息，**仅在美国就有 56 个登记的用户社区**；而中国从 2014 年在上海建立了第一个用户社区之后，在广东也建立了用户社区，并在广州和深圳开展了线下活动。而今天，正好是**北京 AWS 用户社区成立**的日子，趁着大会招募新人，我也赶快去报名参加了（我才不会说我是为了小礼品的）。

  

![](../Images/9984fe6107325e66ec0a872555303e75.png)  
**AWS 用户社区的全球发展**

  

今年有个热炒的概念叫“**社群经济**”，各种相关的不相关的企业都纷纷给自己贴上“社群”的标签。不过，我认为，**社群是社区从线上返回线下的一个重要阶段**。而能够提供社群产生和发展的土壤，则代表整个生态体系已经完整而繁茂了。

  

目前，主流的云服务商在提供平台之外，还提供了云市场供第三方厂商开发和分发应用，这标志着云生态已经初步建立；而在此基础上，形成了广泛的用户群体，并由此**自发地构成各地的本地社群（用户社区），则代表着云生态的进一步成熟**。

  

之前和一位云服务方面的专家聊天说，现在的云服务越来越专业化，因此需要云服务提供商在提供服务和技术的基础上，进一步提供培训和认证，才能完善整个服务市场。而我觉得，能够在培训和认证的基础上，进一步形成用户社群才标志着整个生态系统的完善。

  

可喜的是，我们从 AWS 这里看到了这样的变化。由此，我也调查了其它一些云服务商的用户社群情况，包括微软、Salesforce 也都**不同程度的在建设用户社群**。

  

我想，我很快可以看到国内的各大云服务商建设和扶植各地的用户组的发展了。

  

**对了，明天全天大会还有多达八个分会场的技术干货，涉及到大数据、DevOps、云计算架构、云计算深度实践等主题，更是有大把的行业专家领衔演讲，你不来吗？**
