# 面向 Linux 新用户的八款最佳 Linux 发行版

Linux 新用户总是为一开始选择最佳 Linux 发行版而感到困惑。由于外头有数百款 Linux 发行版，所以这始终是件让人困惑的事情。不过，我会帮助你选择合适的 Linux 版本，以便你开始使用 Linux。我在本文中将逐一介绍面向 Linux 新用户的 8 款最佳 Linux 发行版。但在这之前，我建议你摈弃关于 Linux 的种种误解，比如 Linux 只适合极客或开发人员。正如我始终所说的那样，“既然 Linux 可以用在谷歌、Facebook 和亚马逊，它必然也可以运行在你的家用计算机。”

**选择一款 Linux 时要牢记的两个方面**

想知道什么 Linux 发行版最适合你，不需要知道太多的参数。只要牢记两个方面。首先是你的要求，其次是发行版的易用性。本文介绍的发行版并非最适合所有人，所以许多读者势必会寻找最适合自己的其他发行版。要紧的是如果你知道自己的要求，那就比较容易找到一款易于使用、又符合你要求的 Linux 发行版。所以，现在不妨看一下适合新用户的几大 Linux 发行版。

**1\. Linux Mint**

本文介绍的第一款发行版是 Linux Mint。大多数时候，这款发行版名列榜首，因为它具有稳定性、简单性和易用性。它不是像其他众多的 Linux 发行版那样专门针对某一种类型的用户，比如 Ubuntu Studio 专门针对多媒体爱好者。Linux Mint 基于Ubuntu，随带我们平常使用的几乎所有应用程序，比如用于上网冲浪的火狐、电子邮件客户软件 Thunderbird、Photoshop 的替代品 Gimp、微软 Office 的替代品以及文件管理器等。

Linux Mint 安装后即可使用。它意味着，预先安装的应用程序让 Linux Mint 在安装后立即可以使用。最大的亮点是默认的桌面环境：Cinnamon，不过它也有另外两个版本：XFCE 和 MATE。等一下，最近 KDE 版本也发布了。你可以在此\[1\]进一步了解 KDE 桌面环境。顺便说一下，KDE 赏心悦目。

不过我推荐 Linux 新用户使用 Linux Mint Cinnamon 版本。新用户使用 Cinnamon 势必会觉得极其自然。看一看下面 Cinnamon 桌面环境的屏幕截图。

**2\. Linux Lite**

Linux Lite 是非常轻巧、稳定、可定制的 Linux。它对用户友好，自 2013 年推出第一个版本以来已有了长足改进。与其他 Linux 版本一样，Linux Lite 也不随带各种桌面环境。它拥有的唯一桌面环境是 XFCE。提供单一版本并不意味着它不太强大或不太实用，它拥有其他任何基于 Ubuntu 的高级发行版拥有的同样功能。

吸引用户改用 Linux Lite 的另一个特色在于它很轻巧。XFCE 桌面环境非常轻盈，但外观很酷，这是由于它只有 955MB 大小，几乎只有 Linux Mint 的一半大小。

Linux Lite 已经随带用户平常使用的许多应用程序。它随带最新版本的火狐、Gimp 图像编辑工具、LibreOffice 办公套件、Thunderbird 电子邮件客户软件和 VLC 媒体播放器等。除了所有这些应用程序外，如果你想要更多的应用程序，默认软件库包括大量软件，通过 Synaptic 软件包管理器，就可以轻松安装这些软件。

Linux Lite 的最新版本是3.0。可以在此\[2\]看看 LinuxAndUbuntu 对 Linux Lite 3.0 的测评。

**3\. Zorin OS**

Zorin OS 的性能没有因外观感觉而打折。可高度定制的桌面环境让 Zorin OS 对 Linux 新手来说极其容易使用。Zorin OS 同样基于 Ubuntu，使用可高度定制的 Gnome 桌面和被开发团队称之为 Zorin Desktop 的 Avant Window 导航工具。

Zorin Desktop 是专门为 Windows 用户设计的。所有的外观感觉都非常类似 Windows 操作系统，所以任何 Windows 用户会觉得导航起来极其容易，而且借助 Linux 的强大功能，可以轻松处理所有的日常任务。开发团队提供支持的 Zorin 最新版是 Zorin OS 9。该团队为该操作系统提供两个版本，即 Zorin OS Core 和 Lite。Core 版本就是系统的核心，只预先安装了几个应用程序。Core 版本强烈推荐用于老式桌面电脑，而另外的 Lite 版本拥有大量预先安装的应用程序，它们用起来对 Linux 新用户来说一点也不困难。

**4\. Manjaro Linux**

如果你认为推荐给 Linux 新用户的只有基于 Ubuntu 的 Linux 发行版，那就错了。这里有 Manjaro Linux。它基于独特的Linux 发行版 Arch Linux。如果你之前从未听说过 Arch Linu（可能性比较小），那么不妨阅读 LinuxAndUbuntu 对 Arch 的测评文章。

好了，Manjaro Linux 也是一款非常友好的 Linux 发行版。要是用户已经熟悉 Windows 或其他操作系统，使用它不会有任何问题。它有诸多版本。我认为，我要说，Manjaro 支持几乎所有流行的桌面环境。所以对新老 Linux 用户来说，有诸多版本可以选用。为了帮助你安装，Manjaro 还提供了两个安装程序，所以安装起来很容易。如果你不熟悉一个安装程序，只要选用第二个安装程序，但要是你连第二个安装程序也不熟悉，可以上社区论坛寻求帮助。

Manjaro Linux 的最新版是 16.04.1。可以在此\[3\]了解 Manjaro Daniella 版本的新颖功能。

Manjaro Linux 的下载地址：http://manjaro.github.io/download/

**5\. Peppermint OS**

Peppermint OS 自 2010 年以来就存在了，它专注于速度和易用性。名称本身就定义了它与 Linux Mint 之间的关系。Peppermint OS 基于 Ubuntu，随带基于 LXDE 的桌面环境。它当然是一款对新手友好的 Linux 发行版，专注于提供轻量级系统，所以它只随带日常使用所需的应用程序。没有大量预先安装的应用程序。不过 Synaptice 软件包管理器可用来搜索其他众多软件包，并且安装到系统上。

该发行版还采用了将 Web 应用程序用作本地应用程序的概念。所以开发团队开发了名为“Ice”的应用程序，它可以直接在你的应用程序菜单里面创建 Web 应用程序启动器。这可以帮助你在自己的窗口中单独访问每个网站，可以通过桌面启动器（快捷方式）或应用程序菜单迅速启动。

Peppermint 的最新版本是 7。点击链接，即可深入了解最新的 Peppermint OS 7。

**6\. Elementary OS**

Elementary OS 是一款友好的Linux发行版，基于 Ubuntu，它采用了一种自定义的桌面环境 Pantheon。Pantheon 是一种对 Mac 用户来说很自然的桌面环境。它在桌面上有非常类似的应用程序窗口组件，对 Mac 用户来说感觉很熟悉。左上角是菜单，你可以在这里搜索所有已安装的应用程序。

它随带一些实用的常用应用程序，比如 Midori web 浏览器、媒体播放器、图像查看器等。Elementary OS 的最新稳定版是0.3.2 “Freya”。只可惜，Elementary OS 是我从来没评测过的 Linux 发行版之一。我将来肯定会评测 Elementary OS 即将发布的版本：“Loki”。

**7\. Ubuntu studio**

是的，我仍旨在为你介绍对新手友好的 Linux 发行版。Ubuntu Studio 是为了实现同样的目的。Ubuntu Studio 面向音频、视频和图形用户或专业人员。我之所以在对新手友好的发行版中提到它，是由于许多用户之所以没有使用 Linux，是由于他们喜欢其他操作系统上的多媒体内容。如果你是那些用户中的一个，别担心，你可以通过 Ubuntu studio 改用 Linux。与此同时，这款发行版很容易使用。顾名思义，它基于 Ubuntu，但它不仅限于此。Ubuntu Studio 是一款得到官方认可的 Ubuntu 衍生发行版。

Ubuntu Studio 使用 XFCE 桌面环境，所以速度快，在左上角的菜单里拥有一切特性。你可以通过该菜单浏览应用程序。它使用简单，也易于操控。系统里面已经安装了大量的应用程序，所以新用户不需要安装处理日常任务的应用程序。

**8\. Ubuntu**

再来说说 Ubuntu！本文中对新手最不友好的 Linux 发行版就是 Ubuntu，名次这么靠后有一些原因。大多数 Linux 用户之前是 Windows 用户，所以你也更有可能使用 Windows。Windows 用户在 Ubuntu 方面遇到的问题是，Ubuntu 使用一种独特的 Unity 桌面环境。这是极少数 Linux 发行版提供的桌面环境。用户可以在仪表板搜索所有的应用程序和在线内容。对新用户来说，使用 Ubuntu、更长久地坚持使用它来得比较难。

这并不意味着 Ubuntu 没有用。Ubuntu 是本人青睐的 Linux 发行版，我将它用于日常工作。问题是，一旦你熟悉了它，用起来就很容易。

我这个新手在 Ubuntu 方面面临的主要问题是，只有你将指针悬浮在窗口标题栏的上方，菜单按钮才会显示。另一个问题是，根本没有一键式最小化操作。我得进入到标题栏，才能最小化任何窗口，几乎所有的 Windows 用户都不熟悉这种操作。这确实有点烦人。遗憾的是，这些问题只是部分得到了解决。用户仍需要使用第三方应用程序或调整工具，打开这些基本功能。我一直搞不明白为什么这么微不足道的功能就不能放在通用设置管理器中。对于 Linux 新用户来说，这是个很折磨人的任务。

![](../Images/f2d6b88b10a1884ddb9a85e696186a45.png)

不过我不会阻止有谁从 Ubuntu 开始入手，但只是确保你知道关于它的一些必要情况。
