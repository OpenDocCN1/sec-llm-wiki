# 商务开源软件汇总：12 款卓越应用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608069&idx=3&sn=b9ed048a939ba6967d3c18e2c1d13d59&chksm=bdce8a038ab903157afac9e1da430901e4c19d728cf1c3dd19caf129c94156c5e7188572b88d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608069&idx=3&sn=b9ed048a939ba6967d3c18e2c1d13d59&chksm=bdce8a038ab903157afac9e1da430901e4c19d728cf1c3dd19caf129c94156c5e7188572b88d&scene=27#wechat_redirect)

根据Gartner公司的统计，2016年全年企业软件支出将达到3210亿美元，较上年增长4.2%。面对这样的状况，更多企业计划利用开源软件降低运营成本。事实上，由Black Duck Software发布的统计表明，2016年年内有65%的企业开始提升内部环境中的开源软件使用量。

考虑到较低的授权成本，大多数开源应用的总体拥有成本较专有软件更低。另外，开源软件还具备源代码自定义能力，足以满足企业的实际需求。再有，领先开源应用甚至提供闭源应用所不具备的功能。也有人认为，开源项目具备更理想的安全性，能够有效帮助企业免受供应商锁定的困扰。

![](../Images/ffc3e91d6aad29fc9273b1fa806a606d.png "面向企业的开源软件：12款卓越应用")

*面向企业的开源软件：12款卓越应用*

下面我们将着眼于开源许可领域中的最佳ERP、CRM、小型业务服务器、项目管理以及商务智能应用。

**1\. Apache OFBiz**

![](../Images/bec2aa4b2d50c8d437babb3013c25e1f.png)

作为Apache基金会的赞助项目，OFBiz(全称为‘Open for Business’)是一套功能齐全的企业自动化套件，其中包含企业资源规划(简称ERP)、客户关系管理(简称CRM)、电子商务、内容管理、计费与费率管理、供应链管理、制造资源规划以及企业资产管理等方案。OFBiz拥有丰富的说明文档及指导视频，其基于Java语言因此能够运行在任意支持Java SDK的系统当中，包括Windows、OS X、Linux以及Unix。

**2\. SugarCRM**

![](../Images/b61bd3b062392edc685337f7020d47c9.png)

作为Gartner公司魔力象限报告中的前瞻者方案，SugarCRM是一款基于Web的客户关系管理解决方案，适用于各类规模的企业。它的知名用户包括IBM、可口可乐、Bitdefender、Men’s Wearhouse等。

该软件每月每用户40美元起，同时提供免费的开源社区版本。要使用此社区版，大家需要使用运行有PHP以及MySQL、DB2、甲骨文或者Windows SQL Server等数据库的Windows、Linux或者Mac OS X Web服务器。

**3\. Odoo**

![](../Images/9dc5959718376ff920ad5b94bd08116d.png)

Odoo目前拥有超过200万用户，其中包括现代、达能、丰田等巨头级企业。这套方案囊括有电子商务、综合应用内容管理、CRM、进销存、销售点、财务、人力资源、库存、邮件营销、时间表以及在线聊天等功能。

感兴趣的朋友可以从GitHub处下载源代码，或者使用付费云服务。访问用户低于50名则可享受免费服务，额外用户每位每月24美元。

**4\. Zentyal**

![](../Images/b664b2c0aa6cbc1a16c74735ea2dd48b.png)

作为一款微软Exchange的替代方案，Zentyal是一套运行于Linux基础上的商业邮件服务器。它能够与Exchange及Active Directory相兼容，同时与移动设备同步。另外，它还包含杀毒、反垃圾邮件以及防火墙等安全功能，且支持Windows环境下的文件共享与打印机管理机制。该软件的开源版本名为“服务器开发版”。如果通过经销商购买，大家则可以每用户每月1欧元(具体根据所在地区而定)使用其云版本。

**5\. ClearOS**

![](../Images/7f0651b6d04851c58ed9b0a304c4de25.png)

ClearOS宣称属于“下一代小型商业服务器”，集成网络、VPN、服务器功能以及企业级安全，且提供易于使用的Web界面。它的客户包括谷歌地图、凯迪拉克、三星、丰田、施乐等众多知名企业。

ClearOS软件提供多个版本，其家庭与商业版本以付费方式订阅，同时拥有免费下载的社区版。另外，该公司还提供多种预配置硬件设备，价格由1199美元到34832.17美元不等。

**6\. Pentaho**

![](../Images/b53d104d5e16e280771c9ac5f41ec42c.png)

作为日立集团打造的方案，Penthaho是“一套全面的数据集成与业务分析平台”，目前的客户包括卡特彼勒、哈里伯顿、BR与纳斯达克。另外，它还能够支持多种数据源，包括Hadoop、NoSQL数据库以及各类分析型与关系型数据库。

Pentaho的开源版本可通过社区网站获取。另外，该公司还提供免费的三十天试用期，包括自定义可视化、培训、企业支持、咨询、认证以及技术支持等有偿服务。

**7\. Openbravo**

![](../Images/56b920fff134819bf35a79ea4b6f6626.png)

Openbravo主要负责满足大中型渠道零售商的业务需求。其中包含商品管理、供应链管理、报告、电子商务与移动功能，专注于为客户提供无缝化购物体验。

大家可以访问Code.Openbravo.com获取该软件的开源版本。该公司也提供有偿的企业及专业版本，可部署在内部或者云环境当中。付费版本能够提供开源版本所不具备的额外模块、分析以及应用程序监控功能。

**8\. iDempiere**

![](../Images/82c9e85b5610b48b1ee7c8cde2910eb1.png)

这套早期被称为ADempiere的ERP、CRM与供应链管理解决方案本身就属于Compiere的一套fork。iDempiere能够支持OSCi标准，能够支持多个组织、多种语言、多种货币以及多种财会格式。它基于Java语言编写，能够运行在Linux、Windows或者Mac OS X系统之上;另外，它还需要配合PostgreSQL或者Oracle数据库共同使用。

**9\. Jaspersoft**

![](../Images/f4c6c559bb5933a89169019ae8ab0f39.png)

作为“全球使用最为广泛的商务智能工具”，TIBCO Jaspersoft能够帮助客户基于可操作洞察结论快速做出决策。据该公司称，有94%的用户推荐使用Jaspersoft技术，有90%客户建议使用Jaspersoft支持。它的客户包括Groupon、Compass Health、CA Technologies、时代华纳有线电视公司等等。

除了免费的社区版之外，它同时提供免费的报告版、AWS专业版及企业版。另外，Jaspersoft可部署在内部环境或者云端，并与其它应用加以整合。部分版本还包含商务智能工具的移动访问能力。

**10\. xTuple**

![](../Images/ebeddd3b1b3838dc902f7692dd62aeed.png)

xTuple提供的ERP解决方案旨在帮助企业客户发展自身业务。xTuple软件可用于任意行业，但也具备针对具体厂家及经销商需求的版本。

xTuple软件的开源版本名为PostBooks，包含财会、销售、客户关系管理、采购、产品定义、库存、分销与制造能力。该软件的生产版、发布版与企业版需要付费，此外它还提供有偿培训及专业服务。

**11\. vTiger**

![](../Images/8b0544f1b428782b317c0e065d12ab44.png)

作为一套多合一解决方案，vTiger具备CRM、市场营销以及客户服务等功能，具体包括联系人管理、销售机遇追踪、工作流程自动化、客户门户、服务水平协议、支持、项目管理、报价及其它多种选项。

此软件提供销售版、支持版及终极版，各版本托管于云环境中且每用户每月起步价格为10美元。它的免费开源版目前下载数量已经超过450万次。另外，该软件还提供多种付费扩展。

**12\. Project Open**

![](../Images/b2b22c2e11e93031f7f74f6862d2031b.png)

作为下载数量已经超过100万次的高人气软件，Project Open提供企业级项目管理、专业服务自动化与IT服务管理经营。它赢得众多赞誉，且发展历程已经超过十年。

该软件拥有四种不同版本，包括面向中小型企业的免费标准版，包含LDAP集成、财务报告与数据仓库的付费专业版，囊括审计模块、一次性密码以及SAP功能的企业版，外加提供额外企业功能支持的扩展版。
