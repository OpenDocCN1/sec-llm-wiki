命令行工具

*   Bastet - 在命令行玩俄罗斯方块。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   Daily Reddit Wallpaper - 开机时将壁纸更换为 /r/wallpapers 或其它子版块的今日最高票壁纸。 ![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   Fishfry - 将 fish 的历史记录替换成为渗透测试人员量身定制的高效版本以及方便新手学习。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   htop - 带有改进的特性和用户体验的 top。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   Pacman4console - 在控制台玩吃豆人。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   Tmux - 它让你在一个终端中在多个程序间方便地切换，分离他们（保持在后台运行）并另一个终端中重新连接上去。以及还有好多事情可以做。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   十佳命令行工具
    
*   wicd-curses - 命令行 WiFi 连接管理器。
    

桌面环境

*   Budgie - Budgie 是一个面向现代用户思想设计的桌面环境，专注于简洁与优雅。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   Cinammon - Cinnamon 努力提供一种传统的用户体验。Cinnamon 是一个 GNOME 3 的 fork。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   GNOME Flashback - GNOME Flashback 是 GNOME 3 的一个 shell，最初叫 GNOME fallback 模式。桌面的布局和底层技术都与 GNOME 2 相似。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   Gnome - GNOME 桌面环境是一个有吸引力且直观的的桌面，同时有现代（GNOME）和经典（GNOME Classic）会话模式。 ![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   KDE Plasma - KDE Plasma 桌面环境是一个熟悉的工作环境。Plasma Desktop 提供现代桌面环境体验所需的所有工具，所以你可以从开始就充满生产力。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   LXDE - Lightweight X11 Desktop Environment （轻量化 X11 桌面环境）是一个快速且节能的桌面环境。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   LXQt - LXQt 是 LXDE 的 Qt 移植和即将到来的版本，轻量化的桌面环境。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   Mate - Mate 用传统隐喻给 Linux 用户提供一个直观又有吸引力的桌面。MATE 是 GNOME 2 的一个 fork。 ![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   Pantheon - Pantheon 是最初为发行版 elementary OS 创建的桌面环境，同时也是它的默认桌面环境。 ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   Unity - Unity 是 GNOME 的一个 shell，由 Canonical 为 Ubuntu 设计。 ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   Xfce - Xfce 体现了模块化和可重用的传统 UNIX 哲学。 ![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    

显示管理

控制台

*   CDM - 超简化，又功能丰富，用 bash 写就的登陆管理器。 ![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   Console TDM - 纯 bash 写就的 xinit 扩展。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   nodm - 简约的自动登陆显示管理器。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    

图形界面

*   Entrance - 基于 EFL 的显示管理器，高度实验性质。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   GDM - GNOME 显示管理器。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   KDM - KDE4 显示管理器（不再继续开发）。 ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   LightDM - 跨桌面显示管理器，可以使用任何工具集写就的各种前端。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   LXDM - LXDE 显示管理器，可以独立于 LXDE 桌面环境使用。 ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   MDM - MDM 显示管理器，在 Linux Mint 中使用， GDM 2 的一个 fork。 ![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   SDDM - 基于 QML 的显示管理器，KDE 4 的 kdm 的继任者；Plasma 5 以及 LXQt 推荐。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   SLiM - 轻量且优雅的图形化登录解决方案（不再继续开发）。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   XDM - 带有 XDMCP，主机选择支持的 X 显示管理器。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    

窗口管理

合成器

*   Compton - Compton 是一款独立的合成管理器，适合同没有原生提供合成功能的窗口管理器一同使用。 \[![](../Images/30e33c99833728514ac5cb510736f942.png)\] ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   Xcompmgr - Xcompmgr 是一个简单的合成管理器，能够渲染下拉阴影，使用 transset 工具的话，还可以实现简单的窗口透明。 ![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    

叠加式窗口管理器

*   2bwm - 快速的浮动窗口管理，有两个特殊边界，基于 XCB 库，由 mcwm 衍生。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   Blackbox - 快速，轻量化的 X 窗口系统窗口管理器，没有那些烦人的库依赖。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   Fluxbox - 基于 Blackbox 0.61.1 代码的 X 窗口管理器。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   Openbox - 高度可配置，带有可扩展标准支持的下一代窗口管理器。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    

平铺式窗口管理器

*   Bspwm - bspwm 是一个平铺式窗口管理器，将窗口以二叉树的叶结点的方式展现。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   Herbstluftwm - 使用 Xlib 和 Glib 的手工平铺式窗口管理器。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    

动态窗口管理器

*   awesome - 高度可配置，下一代 X 框架窗口管理器。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   dwm - X 动态窗口管理器。它以平铺，单片镜以及浮动布局的方式管理窗口。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   i3 - 完全重写的平铺式窗口管理器。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   spectrwm - X11 小型动态窗口管理器，很大程度上受了 xmonad 和 dwm 的启发。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
    
*   xmonad - 动态平铺式 X11 窗口管理器，用 Haskell 写就和配置。![](../Images/30e33c99833728514ac5cb510736f942.png) ![](../Images/78d3ebe8ee7821c1218fd10beb1918e7.png)
