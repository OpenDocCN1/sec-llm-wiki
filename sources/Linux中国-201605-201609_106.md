# 每日安全资讯：互联网勒索软件年利润估计可达94万6千美元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607997&idx=3&sn=e663af01e0cc30b169aa5a94c467f340&chksm=bdce8bbb8ab902ad9d38acedbab26c3c862b45e27621e0c6cc83f774c951ef6d9c61af82467e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607997&idx=3&sn=e663af01e0cc30b169aa5a94c467f340&chksm=bdce8bbb8ab902ad9d38acedbab26c3c862b45e27621e0c6cc83f774c951ef6d9c61af82467e&scene=27#wechat_redirect)

  

2家以色列安全公司研究了名为Cerber Ransomware的互联网勒索软件。运行这个复杂的勒索软件服务的犯罪集团每月可以从它们的非法活动当中获利7万8千美元，年获利高达94万6千美元。经过长时间的调查，这两家公司Check Point的和IntSights给出了一份技术报告。

这份报告显示，研发Cerber勒索软件选择了RAAS模式，即勒索到解锁服务，同时出租勒索软件套件给其他骗子作为其下线。感染Cerber之后的电脑解锁需要受害者支付1比特币（大约是580美元）。

Check Point表示，所有这些赎金全部由Cerber勒索软件开发者控制，勒索成功之后，开发者会向下线支付报酬。根据Check Point统计，单单在上个月，Cerber勒索软件在全球超过201个国家感染了超过15万台电脑。

通过跟踪这些感染和Bitcoin钱包，Check Point估计Cerber勒索软件开发者在2016年7月获利达到19万5千美元。其中，Cerber勒索软件开发者留下40%的利润，即7万8千美元，其余的利润分发给众多下线。
