# 开源新闻速递：Maui 第一个稳定版本发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607992&idx=4&sn=937b8142abcc4b0d3426b5fa73bda827&chksm=bdce8bbe8ab902a8e7c13e94a3a3785a477c55935e6edae4c4fef1c0f6ea1cd529d63b3cb1f7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607992&idx=4&sn=937b8142abcc4b0d3426b5fa73bda827&chksm=bdce8bbe8ab902a8e7c13e94a3a3785a477c55935e6edae4c4fef1c0f6ea1cd529d63b3cb1f7&scene=27#wechat_redirect)

今日关注

![](../Images/83637582a954943a54347c9d68842701.png)

Maui 第一个稳定版本发布。Maui 是 Netrunner Linux 的新名字，是基于 KDE Neon 的 GNU/Linux 发行版。KDE Neon 也是一个相对比较新的项目，可以作为附加在 Ubuntu 16.04 LTS (Xenial Xerus) 操作系统上的一层封装，也可以作为一个独立的基于最新的 KDE Plasma 桌面环境的 Live ISO 镜像文件下载使用。目前已经可以下载使用了。

图文摘要

![](../Images/d8a849f1dba2670ba2480b2f140083bb.png "2016.08.16是 Debian GNU/Linux 操作系统 23 周年纪念日。自从 1993.08.16 Debian GNU/Linux 的 0.01 版本发布以来，该操作系统共进行了14次正式发布。最近的发行版是 Debian 7.0 \"Wheezy\" 和 Debian 8 \"Jessie\"。下一个正式发布版本是 Debian 9 \"Stretch\"，预计会在年底发布。")

*2016.08.16是 Debian GNU/Linux 操作系统 23 周年纪念日。自从 1993.08.16 Debian GNU/Linux 的 0.01 版本发布以来，该操作系统共进行了14次正式发布。最近的发行版是 Debian 7.0 "Wheezy" 和 Debian 8 "Jessie"。下一个正式发布版本是 Debian 9 "Stretch"，预计会在年底发布。*

![](../Images/8b9f3082f5158c5aa4026617c8e27334.png "Linux kernel 4.7.1 发布。随后 Linux 内核 4.6.7 发布，这可能是 4.6 系列的最后一个版本，所有 4.6 系列内核的用户需要尽快更新到 4.7.1 版本。")

*Linux kernel 4.7.1 发布。随后 Linux 内核 4.6.7 发布，这可能是 4.6 系列的最后一个版本，所有 4.6 系列内核的用户需要尽快更新到 4.7.1 版本。*

![](../Images/8509f10a948ff7402a9f0587744e21cf.png "MidnightBSD 0.8 发布。该版本将系统编译器从 GCC4.2 切换到了 LLVM/Clang 3.3 。")

*MidnightBSD 0.8 发布。该版本将系统编译器从 GCC4.2 切换到了 LLVM/Clang 3.3 。*
