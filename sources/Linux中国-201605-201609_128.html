昨天，老王向大家介绍了一个新的公众号，美其名曰“副刊”，其实，老王是想着逐步过渡到该号的——但是还不太好说，不料，在新公众号的欢迎消息中漏了马脚。哈哈哈~


好吧，严肃的说，我说说为何这样做，以及目前这个“Linux中国”号怎么办？


建设这个新号的主要原因是，现在这个主号“Linux中国”，由于名称等原因，是没法认证的，以至于很多基本的 API 权限都没有，老王和微信官方哭诉也没用。比如说，大家看到我们的“福利签到”功能了吧，上面就没办法显示中奖者的 ID、头像之类的——因为我取不到——其实我也想显示出来啊，这样免的有些同学觉得奖品都哪里去了呢？我只能取到一个随机而不会重复的 OpenID。


那么将来这两个号会如何定位？我的考虑是：


“Linux中国”会沿袭目前的发文风格和选题标准，包括技术文章、新闻、评述和软文（很抱歉，能维持这个公众号乃至于整个 Linux 中国社区的运作，公众号的软文收入是很重要的一块。但是老王的底线是，完全不对标的软文和广告是不接的，已经拒绝了很多。请大家能理解。）


“LinuxCN”在粉丝不到30000之前，是不会接软文广告的，内容上也会挑选“硬货”给大家。


将来，两个号会并行运行，并分别有不同的侧重点，而“LinuxCN”会基于更丰富的 API 提供一些有趣的、个性化的功能。


有同学还说了，不是还有一些服务号嘛？——这个其实是老王的失误，服务号的场景明显不是很适合我们，至少我还没找到很好、很有趣的应用场景。所以，服务号目前的主要用途是，减少推送量，仅推送每周的最精华的分类内容给大家。


承蒙大家关注，仅仅一天，我们的新公众号就有了上千关注！这都是真爱啊。除了在公开这个号码之前进来的五位“先知”们（别问我，我也不知道他们是如何找到的），这些朋友都对“Linux 中国”信任有加的铁杆粉丝的——我在想，我有没有可以给1000人发放的礼品呢？——欢迎友商赞助。


说完了新公众号之后，我顺便说说签到抽奖的情况——什么？你还不知道“福利签到”是什么？好吧，我只能说，你错过了多少大奖啊。。


目前签到功能已经同步开放到“Linux中国”和“LinuxCN”上，你可以在两个号里面分别签到一次，这意味着，你有两倍的签到中奖机会！要不要在另外几个服务号也开放签到功能，老王还在犹豫。


最后，为了庆祝异步社区成立一周年，作为“异步社区”的合作伙伴，多承他们提供了大量的奖品，所以我们在最近几天的头条或次条文章中推出了评论点赞有奖的活动：您对文章的评论如果在文章发布24小时内得到的点赞最多，您就会得到一张“异步社区”的神奇的“样书券”——可以在“异步社区”兑换他们的任意一本书，是任意一本！活动截止只剩下两天了……
