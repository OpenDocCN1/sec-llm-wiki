# 每日安全资讯：FireEye奇葩裁员理由：中国黑客减少了，修复勒索软件太容易了……

FireEye作为曾经全球最大的互联网安全公司、安全界的神话之一，其员工规模已经扩大到3400名。而8月9日，FierEye宣布裁员，根据第二季度财报，FireEye决定裁掉300到400名员工。    

2013年9月，FireEye正式上市，交易首日股价就大涨80%。随后这家公司的股价又一路狂飙，2014年时从20美元涨到近100美元，市值一度超过130亿美元。可是如果近期你有关注过纳斯达克股市，应该就知道FireEye现如今的股价徘徊在17美元左右——这市值蒸发速度真可谓相当惊人，不是说好独角兽、香饽饽、中情局和财富500强企业的宠儿吗！问题出在哪儿？点我进传送门

据FireEye CEO Kevin Mandia称，业务收入骤降与过去一年中网络安全市场的发展息息相关，同时他也指出以下两点原因……

**裁员理由一：来自中国的网络攻击在下降**

FireEye的收入大部分来自于自家业务能力一流的分部——麦迪安网络安全公司，麦迪安网络安全公司通常被指派参与调查严重的数据泄露和国家支持的网络攻击。

这类的项目往往需要大量员工前去调查和清理，但自从去年9月签署了《中美反间谍协议》后，与中国相关的网络攻击数量已经逐渐下降，FireEye麾下的麦迪安网络安全公司也因此业绩下滑。

其实早在今年6月，FireEye就发布过一则报告，指出来自中国的网络攻击正在逐渐减少但是从未停止。可以看出FireEye正在努力找出他们收入下降的原因。

**裁员理由二：修复勒索软件太容易了**

FireEye收入减少的第二大原因是勒索软件的崛起。当很多公司被勒索软件感染，FireEye并没有在他们身上捞到很多利润。

对于安全专家来说，修复勒索感染是出了名的简单——类似于网管重启电脑。安全专家们即使无法破解勒索软件，也能做到备份数据，再清理一下系统。

虽然自从FireEye接受勒索软件清理业务以来，公司实现了盈利，但事实上已经影响到产生收入的总规模，低于向股东们承诺的预期收入。

FireEye在第二季度的实际收入为1亿7500万美元，低于预期的17800-18500万美元。真正受到影响的是FireEye股市，消息一经传出，FireEye的股价立马下跌16.2%，较去年同期已同比下降62%，堪称自由落体。
