鉴于某些考虑，我们决定为“Linux 中国”开一个副刊——**LinuxCN** 。

  

这个副刊，将：

  

*   每天推送，但是只推送最有价值的信息，宁缺毋滥
    
*   经过了微信认证，取得了所有必要的 API 支持，这意味着更丰富的功能，比如额外的抽奖机会（这个稍候两天推出）
    
*   不同于主号的一些东西  
    

  

为何这样做，暂时不说的理由。
