# 如何在 Ubuntu Linux 16.04 LTS 中使用多个连接加速 apt-get/apt

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607914&idx=3&sn=f4dd9b2062781db4487d8dfd6b5982e7&chksm=bdce8bec8ab902fab5e9e822f5cc2f9513750e3b80defd89b12c1451483ae5eafa255c3ffe9b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607914&idx=3&sn=f4dd9b2062781db4487d8dfd6b5982e7&chksm=bdce8bec8ab902fab5e9e822f5cc2f9513750e3b80defd89b12c1451483ae5eafa255c3ffe9b&scene=27#wechat_redirect)

我该如何加速在 Ubuntu Linux 16.04 或者 14.04 LTS 上从多个仓库中下载包的 apt-get 或者 apt 命令？

你需要使用到 apt-fast 这个 shell 封装器。它会通过多个连接同时下载一个包来加速 apt-get/apt 和 aptitude 命令。所有的包都会同时下载。它使用 aria2c 作为默认的下载加速器。

![](../Images/a2d38182c1a67272d0dde203bbbb8dcb.png)

安装 apt-fast 工具

在 Ubuntu Linux 14.04 或者之后的版本尝试下面的命令：

```
1.  `$ sudo add-apt-repository ppa:saiarcot895/myppa`
    
```

示例输出：

![](../Images/837106b713b9c64bbaf0e7f659500f59.png)

更新你的仓库：

```
1.  `$ sudo apt-get update`
    
```

或者

```
1.  `$ sudo apt update`
    
```

![](../Images/cedde70c070bc5297da354093c055330.png)

安装 apt-fast：

```
1.  `$ sudo apt-get -y install apt-fast`
    
```

或者

```
1.  `$ sudo apt -y install apt-fast`
    
```

示例输出：

配置 apt-fast

你将会得到下面的提示（必须输入一个5到16的数值）：

![](../Images/d92cfee2224b9603a4162756b1f1b2b6.png)

并且

![](../Images/0d89df4dafddd112444a15965e83197b.png)

你也可以直接编辑设置：

```
1.  `$ sudo vi /etc/apt-fast.conf`
    
```

> **请注意这个工具并不是给慢速网络连接的，它是给快速网络连接的。如果你的网速慢，那么你将无法从这个工具中得到好处。**

我该怎么使用 apt-fast 命令？

语法是：

```
1.  `apt-fast command`
    
2.  `apt-fast [options] command`
    
```

使用 apt-fast 取回新的包列表

```
1.  `sudo apt-fast update`
    
```

使用 apt-fast 执行升级

```
1.  `sudo apt-fast upgrade`
    
```

执行发行版升级（发布或者强制内核升级），输入：

```
1.  `$ sudo apt-fast dist-upgrade`
    
```

安装新的包

语法是：

```
1.  `sudo apt-fast install pkg`
    
```

比如要安装 nginx，输入：

```
1.  `$ sudo apt-fast install nginx`
    
```

示例输出：

![](../Images/e787a99e50281543656414a53dab4232.png)

删除包

```
1.  `$ sudo apt-fast remove pkg`
    
2.  `$ sudo apt-fast remove nginx`
    
```

删除包和它的配置文件

```
1.  `$ sudo apt-fast purge pkg`
    
2.  `$ sudo apt-fast purge nginx`
    
```

删除所有未使用的包

```
1.  `$ sudo apt-fast autoremove`
    
```

下载源码包

```
1.  `$ sudo apt-fast source pkgNameHere`
    
```

清理下载的文件

```
1.  `$ sudo apt-fast clean`
    
```

清理旧的下载文件

```
1.  `$ sudo apt-fast autoclean`
    
```

验证没有破坏的依赖

```
1.  `$ sudo apt-fast check`
    
```

下载二进制包到当前目录

```
1.  `$ sudo apt-fast download pkgNameHere`
    
2.  `$ sudo apt-fast download nginx`
    
```

示例输出：

```
1.  `[#7bee0c 0B/0B CN:1 DL:0B]`
    
2.  `07/26 15:35:42 [NOTICE] Verification finished successfully. file=/home/vivek/nginx_1.10.0-0ubuntu0.16.04.2_all.deb`

```

下载并显示指定包的 changelog

```
1.  `$ sudo apt-fast changelog pkgNameHere`
    
2.  `$ sudo apt-fast changelog nginx`
    
```
