    嘉宾阵容 


独家议题（部分）
  新炬网络

开发运维一体化PaaS平台建设

《软件自动化测试成功之道》、《软件性能测试诊断分析与优化》、《深入浅出性能测试与LoadRunner实战》作者、首席DevOps大师陈能技，将首度公开解读基于全球化DevOps运动趋势下的传统企业开发与运维一体化的转型实践，提出开发、QA、运维融合的DevOps能力矩阵模型，助力传统企业DevOps转型。同时讲述如何构建DevOps工具链，形成开发运维一体化PaaS平台，加速企业IT研发过程实现DevOps。

  百度

持续交付：新产品的成长思维

在“互联网+”时代，软件产品要满足快速增长的用户需求，高效快速的迭代转型必不可少，搭建高效的交付流水线更是势在必行。那么，百度内部如何做持续交付？度秘项目是怎么做的？本次分享可以一窥究竟。

  中国移动

“移动云”自动化运维实践

中国移动首次公开分享自有公众服务云的相关实践经验，其中涉及中国移动在技术架构、运维服务等方面的总结，以及在运维实践过程中对团队组建、技术沉淀、手段建设的分享。

  平安科技

全程回放：平安科技100T数据库升级

在面对100T的数据库升级时，如何确保纷繁复杂的各类关键核心系统升级前后的性能稳定？如何确保升级中或升级交付运行一段时间后出现严重问题时能尽快回滚到原版本库？如何快速定位和解决升级交付后出现的性能问题？平安科技将独家回放整个数据库升级全过程。

  唯品会

从无到有：唯品会运维系统建设的心路历程

唯品会内部干货，此次首度公开分享，全面解析唯品会运维系统的建设历程，以及CMDB、发布、监控、故障管理等方面的心路历程。还将分享唯品会在自动化运维方面的摸索，如何在ITIL和DEVOPS方面选取平衡。

  新浪

解密新浪：如何构建高并发的、百万用户级别的系统

彩票行业迎来互联网+时代，在2014年巴西足球世界杯出现数据爆发增长，彩票业务除了涉及用户投注，支付订单，还有大量的赛事分析数据，比分数据需要呈现给用户，如何利用MySQL数据库来应对数据高速增长的互联网彩票业务？并且在大型赛事开始之前进行数据库扩容？彩票业务的数据一致性如何保证？本次分享给您开拓下彩票行业的数据库运维思路。

  轻维软件

破局：传统企业自动化运维平台建设与实践

如今，任何企业都离不开IT运维的支持，尤其是亟需转型升级的传统企业。如何构建自动化运维平台帮助传统企业打破运维困局？就此，DBAplus社群联合发起人，OraZ数据库运维工具贡献者、首席数据库专家邹德裕将分享其基于互联网开源软件框架打造企业级集中化、自动化运维平台的实践经验。

  腾讯云

腾讯云CDB（for MySQL）平台在高可用的实践

随着腾讯云规模的不断壮大，CDB平台面临越来越多个性化的需求。本次演讲主要分享腾讯内部的CDB在应对高可用的挑战上，如何支持多种主从同步方式—异步、半同步、强同步：1、核心组件的构成和实现原理；2、HA架构以及切换流程。

  沃趣

Oracle Tool：Real-Time SQL Monitoring

SQL Monitor是每一个Oracle DBA都应该熟练掌握的工具，它是具有里程碑意义的SQL性能诊断工具。本演讲将介绍SQL Monitor工具的核心思想，帮助DBA快速地定位SQL瓶颈，同时还会介绍OWI性能诊断方法论，帮助DBA迅速定位故障根源。
