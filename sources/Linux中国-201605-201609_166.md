# 开源新闻速递：OpenSSH 7.3不再支持小于1024位的RSA密钥

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607898&idx=4&sn=b8c42eef1a4d686fea73b19d987ee172&chksm=bdce8bdc8ab902ca8a34e8b327791b21b9ca33fc4d172b2afc8d6cfb696455dc26a5dc206377&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607898&idx=4&sn=b8c42eef1a4d686fea73b19d987ee172&chksm=bdce8bdc8ab902ca8a34e8b327791b21b9ca33fc4d172b2afc8d6cfb696455dc26a5dc206377&scene=27#wechat_redirect)

今日关注

![](../Images/d19be30761957d74bca4f6dc7529facf.png)

OpenSSH 7.3正式发布。OpenSSH是提供给GNU/Linux和类UNIX操作系统的100%全套免费开源的SSH2.0协议的实现，预安装在SFTP的客户端和服务器中，也支持对SSH 1.3 和 SSH 1.5 协议的过渡。在这一版本中，将不再支持小于1024位的RAS密钥。

![](../Images/36df2628ffa4b6092e4caa272f1e9569.png "专为俄语用户设计的GNU/Linux操作系统ROSA Desktop Fresh R8发布，搭载了KDE 4, KDE Plasma 5, GNOME, 和 MATE 桌面环境，并进行为期两年的更新支持，一直到2018年。不过，采用的并不是最新版本的软件和GNU/Linux技术，而是Linux 4.1.25内核。")

*专为俄语用户设计的GNU/Linux操作系统ROSA Desktop Fresh R8发布，搭载了KDE 4, KDE Plasma 5, GNOME, 和 MATE 桌面环境，并进行为期两年的更新支持，一直到2018年。不过，采用的并不是最新版本的软件和GNU/Linux技术，而是Linux 4.1.25内核。*

![](../Images/32a9d1f881baf823bf8e8ac60ebec3e0.png "DragonFly BSD 4.6.0正式发布，比较显著的改进是首次提供了对UEFI的支持，对内置的NVMe SSD设备的支持，以及对SMP和网络的改进，对最新的显卡的支持等。")

*DragonFly BSD 4.6.0正式发布，比较显著的改进是首次提供了对UEFI的支持，对内置的NVMe SSD设备的支持，以及对SMP和网络的改进，对最新的显卡的支持等。*

![](../Images/353d5a4b618418d63387923a77f65624.png "KDE Plasma 5.7.3桌面环境已经可以使用了。KDE Plasma 5.7系列的更新速度是比较快的，在这一版本中，改善了一些核心组件，比如Plasma Desktop, Plasma Discover等，对VPN连接存在的一些问题也进行了修复。KDE Plasma 5.7.4 版本预计8.23号发布，敬请期待。")

*KDE Plasma 5.7.3桌面环境已经可以使用了。KDE Plasma 5.7系列的更新速度是比较快的，在这一版本中，改善了一些核心组件，比如Plasma Desktop, Plasma Discover等，对VPN连接存在的一些问题也进行了修复。KDE Plasma 5.7.4 版本预计8.23号发布，敬请期待。*

![](../Images/81cb15d3ab20e327a817254c80c92dcf.png "炫丽的Arc GTK主题已经可以从Ubuntu 16.10 (Yakkety Yak)的仓库中下载了。Arc GTK是使用GTK+ GUI工具集写的一个平面桌面主题，有三种不同的风格可供选择，Arc, Arc-dark, 和 Arc-darker, 还有透明元素。")

*炫丽的Arc GTK主题已经可以从Ubuntu 16.10 (Yakkety Yak)的仓库中下载了。Arc GTK是使用GTK+ GUI工具集写的一个平面桌面主题，有三种不同的风格可供选择，Arc, Arc-dark, 和 Arc-darker, 还有透明元素。*
