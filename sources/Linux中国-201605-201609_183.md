# 开源新闻速递：ArchEX Build 160724 发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607867&idx=3&sn=df30cf59d8665d8f4da3eff766c42da1&chksm=bdce8b3d8ab9022b917d30550ecc381461bec5cd2aa05931038873ff9468b9cf5ecdce77a266&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607867&idx=3&sn=df30cf59d8665d8f4da3eff766c42da1&chksm=bdce8b3d8ab9022b917d30550ecc381461bec5cd2aa05931038873ff9468b9cf5ecdce77a266&scene=27#wechat_redirect)

今日关注

![](../Images/1f3f7ae2da152214fa987b69245dcc53.png)

基于最新 Arch Linux 技术的 ArchEX Build 160724 发布，在这个发行版中包括了最新的软件包，比如Linux内核4.6.4。据该操作系统开发者 Arne Exton 称，这一版本在几乎所有机器上运行是最快的，鉴于Arch Linux是最轻量级、高度定制并且拥有一大批用户的操作系统，采用的LXDE桌面环境即便是在旧的PC机上也是运行最快的，我们有理由相信Arne Exton的话。

图文摘要

![](../Images/a54fce804d074eff64b35fd9a78149c6.png "openSUSE Tumbleweed 的用户目前已经可以使用最新的 KDE Plasma 5.7 桌面环境以及KDE应用16.04软件套件了，Linux内核也更新到了4.6.4。")

*openSUSE Tumbleweed 的用户目前已经可以使用最新的 KDE Plasma 5.7 桌面环境以及KDE应用16.04软件套件了，Linux内核也更新到了4.6.4。*

![](../Images/a2a9901a73a4b4dad8b2d3feef6ab29f.png "Linux Kernel 4.4.16 LTS 发布，进行了150多处改动。Solus系统的用户已经可以优先进行更新了。")

*Linux Kernel 4.4.16 LTS 发布，进行了150多处改动。Solus系统的用户已经可以优先进行更新了。*

![](../Images/e7fa979dd80f4aac18fabf69d275b901.png "Ubuntu Budgie Remix 16.04.1 发布，在这一版本中，采用了最新的Solus' Budgie桌面环境，还可以对全部磁盘进行加密，也可以对Home文件夹进行加密。另外，也可以选择任何你熟悉的语言来进行安装。还有一个好消息，这一版本引入了对快照打包的支持。")

*Ubuntu Budgie Remix 16.04.1 发布，在这一版本中，采用了最新的Solus' Budgie桌面环境，还可以对全部磁盘进行加密，也可以对Home文件夹进行加密。另外，也可以选择任何你熟悉的语言来进行安装。还有一个好消息，这一版本引入了对快照打包的支持。*
