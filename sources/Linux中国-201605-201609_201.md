# 开源新闻速递： Ubuntu 16.04.1 LTS 发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607840&idx=3&sn=17f756f3782a51d8375739727df3c0df&chksm=bdce8b268ab90230a8123a6ed3fdfa94d6075b6926e45724ede3412bf71102882cc90776f332&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607840&idx=3&sn=17f756f3782a51d8375739727df3c0df&chksm=bdce8b268ab90230a8123a6ed3fdfa94d6075b6926e45724ede3412bf71102882cc90776f332&scene=27#wechat_redirect)

今日关注

![](../Images/baf11c550850f46d3a7e1855026b37e4.png)

Canonical 宣布\[1\] Ubuntu 16.04 LTS （Xenial Xerus） 的第一个维护版本 16.04.1 发布，包括 Kubuntu 、Xubuntu、 Lubuntu、Mythbuntu、Ubuntu Studio、Ubuntu MATE、Ubuntu GNOME、Ubuntu Kylin 等分支也同样更新其安装镜像。如果你还在使用旧的  Ubuntu 14.04.4 等版本，你会收到一个升级提示——这是最后的安全地升级到 16.04 的机会了。

图文摘要

![](../Images/5a3b79810fed0edf42a0c8f7068d0fc0.png "VirtualBox 5.1.2 发布，对 RedHat 企业版 Linux 5 提供了更好支持。")

*VirtualBox 5.1.2 发布，对 RedHat 企业版 Linux 5 提供了更好支持。*

![](../Images/b69ddd5bbccb1baf33bfb8a645b3517a.png "在出去玩了一周之后，Linus 正式宣布 Linux Kernel 4.7 的发布。这一版本最大的新功能是提供了对 AMD 新发布的 Radeon RX 480 GPU 的支持。")

*在出去玩了一周之后，Linus 正式宣布\[2\] Linux Kernel 4.7 的发布。这一版本最大的新功能是提供了对 AMD 新发布的 Radeon RX 480 GPU 的支持。*

![](../Images/4ce85caa533367ee9e0f56e2002bdd47.png "经过漫长时间的等待，Mozilla Thunderbird 45 终于登陆 Ubuntu 了，你现在可以从 Ubuntu 官方仓库中下载安装了。")

*经过漫长时间的等待，Mozilla Thunderbird 45 终于登陆 Ubuntu 了，你现在可以从 Ubuntu 官方仓库中下载安装了。*

![](../Images/92230be74e236b759ec62d0d41eaecfc.png "Google 本周以前都是用 TypeScript 来编写其著名的 AngularJS JavaScript 框架，不过从现在开始，它创建了一个使用 Dart 语言开发的 AngularJS 分支 AngularDart，用于内部的 AdWords 等。这种分拆对于 AngularJS 和 AngularDart 来说应该都是个好消息。")

*Google 本周以前都是用 TypeScript 来编写其著名的 AngularJS JavaScript 框架，不过从现在开始，它创建\[3\]了一个使用 Dart 语言开发的 AngularJS 分支 AngularDart\[4\]，用于内部的 AdWords 等。这种分拆对于 AngularJS 和 AngularDart 来说应该都是个好消息。*
