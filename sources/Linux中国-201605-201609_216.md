# 再次说说“福利签到”的事情

福利签到活动已经开展了 52 天了，每天都是少则数百，多则上千的人来签到，幸运的人还有可能得到当日奖品。

  

不过，也有一些抓狂的同学表示，为毛签到这么久，啥奖品都没得到——从而质疑我们根本没有奖品发出。

  

**对此，老王良心表示，绝无弄虚作假，奖品足额发放，而且并无内定给谁。**

  

虽然我也想每个关爱我们的粉丝可以幸运的中奖，但是奖品毕竟有限，每天几份而已，签到的人却有几百上千，想必得不到奖品的人是大多数。这种运气的事情，本身就是得之我幸的事情啊。

  

这里有个小插曲，前两天有位陕西宝鸡的粉丝就愤怒的问我，为何从来没有中奖！老王回复解释了一番。然而，就在今天早上凌晨，他就**中奖了**！时间是 00:02 分。当时我正在微信后台，看到他发过来的截屏消息后，我能说我对此表示**瞠目结舌**么。

  

不过，我还是不断联系更多的合作伙伴提供更多、更丰富的奖品，比如下周我们就会增加来自“七牛”的抵扣券。如果小伙伴们有用七牛的服务的话，这可是真金白银——就算你不用，也可以送给朋友啊。其实，老王我也挺想要的，毕竟 Linux 中国也是用的七牛的服务，只是不能克扣奖品啊，所以小伙伴们万一中奖了可以考虑送给我哦……

另外，为了让大家更透明的了解签到及奖品发放情况，我专门做了一个页面，大家可以点击每天签到后那个“🏆”消息，就可以访问到一个页面，这个页面会显示当前的奖品领取情况。这里有一点要说明的是，限于微信给我们提供的接口，我们的程序只能取到一个加密的 ID，而无法知道签到者的名字、头像等。当然，我们在幸运粉丝领奖时，能够通过微信后台沟通时看到名字和头像（没有微信号）。
