# 开源新闻速递：Ubuntu 官方论坛遭遇了 SQL 注入攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607760&idx=3&sn=a128510e7e395e62775574c5ecc8f8f4&chksm=bdce8b568ab90240493aee3f537c7b79091fbc2afc025bcf7c1e63471d4907f32ff8114a7cea&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607760&idx=3&sn=a128510e7e395e62775574c5ecc8f8f4&chksm=bdce8b568ab90240493aee3f537c7b79091fbc2afc025bcf7c1e63471d4907f32ff8114a7cea&scene=27#wechat_redirect)

今日关注

![](../Images/9914420c672c60d0567f2489deb19d1d.png)

Ubuntu 官方论坛遭遇了 SQL 注入攻击，有人声称拥有了 Ubuntu 论坛数据库的一份拷贝。值得庆幸的是，Ubuntu 采用了单点登录技术，用户的密码作为一个随机的字符串并进行了加密存储。Canonical 保证攻击者无法侵入到 Ubuntu 的代码仓库中。

图文摘要

![](../Images/f723907e2bc302773cbc1b564e2a53d1.png "Canonical 发布了多项安全公告，对所有支持的 Ubuntu 操作系统进行了 Linux 内核漏洞修复。攻击者可以通过对 Linux 内核包中的内存管理器发起拒绝服务攻击，从而导致系统崩溃。")

*Canonical 发布了多项安全公告，对所有支持的 Ubuntu 操作系统进行了 Linux 内核漏洞修复。攻击者可以通过对 Linux 内核包中的内存管理器发起拒绝服务攻击，从而导致系统崩溃。*

![](../Images/d9cfefa9d0e19e9abb7e039b54082b63.png "基于 Slackware 14.2 的 SlackEX 发布，搭载了最新的 Linux 内核 4.6.4 和 KDE 4.14.21。")

*基于 Slackware 14.2 的 SlackEX 发布，搭载了最新的 Linux 内核 4.6.4 和 KDE 4.14.21。*

![](../Images/8a4d6cccc933551146dab46008682d52.png "Ubuntu GNOME 16.04.1 LTS 将从默认的安装包中去掉 GNOME Maps。因为 MapQuest 访问失效导致 Maps app 不能够正常工作。")

*Ubuntu GNOME 16.04.1 LTS 将从默认的安装包中去掉 GNOME Maps。因为 MapQuest 访问失效导致 Maps app 不能够正常工作。*
