# 开源新闻速递：Linux Mint 发布 17.3 升级包

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607754&idx=2&sn=bd2cf6c13426bf99f7a6b0b2aadc73fb&chksm=bdce8b4c8ab9025af22c44e027bc5cb7409996f930a10cfca15b98a005c9ac39e64d889156ef&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607754&idx=2&sn=bd2cf6c13426bf99f7a6b0b2aadc73fb&chksm=bdce8b4c8ab9025af22c44e027bc5cb7409996f930a10cfca15b98a005c9ac39e64d889156ef&scene=27#wechat_redirect)

今日关注

![](../Images/c5ca62d1d6f0dbb5c44e0d7cba91a12d.png)

在 Linux Mint 18 发布两周后，他们发布\[1\]了 17.3 升级到 18 的升级包，升级指南在此\[2\]。不过，如果你觉得 17.3 用的挺好的话，就没有必要升级到 Linux Mint 18，因为 Linux Mint 17 系列会一直支持到 2019 年。当然， Linux Mint 18 是基于 Ubuntu 16.04 LTS 的，其支持期是五年，直到 2021 年都会得到安全补丁和软件更新。

图文摘要

![](../Images/f7018a12097a774d02d8593047832633.png "预计今年秋天发布的 openSUSE Leap 42.2 将会搭载 GNOME 3.20，KDE Plasma 5.6，以及 Linux 内核 4.4 LTS。")

*预计今年秋天发布的 openSUSE Leap 42.2 将会搭载 GNOME 3.20，KDE Plasma 5.6，以及 Linux 内核 4.4 LTS。*

![](../Images/a079f0968b1515d87733688ac24ac567.png "GIMP 2.8.18 发布，这是一款在多款基于Linux内核的操作系统中自带的图像编辑器。修复了若干错误，完善了部分功能。软件的安装包的大小也压缩了至少20%。")

*GIMP 2.8.18 发布，这是一款在多款基于Linux内核的操作系统中自带的图像编辑器。修复了若干错误，完善了部分功能。软件的安装包的大小也压缩了至少20%。*

![](../Images/570177278d10549e2033441241c7d1ca.png "Linux Kernel 4.1.28 LTS 以及 Linux Kernel 3.18.37 LTS 都进行了更新。这两个版本都对网络协议和声音栈进行了完善。")

*Linux Kernel 4.1.28 LTS 以及 Linux Kernel 3.18.37 LTS 都进行了更新。这两个版本都对网络协议和声音栈进行了完善。*
