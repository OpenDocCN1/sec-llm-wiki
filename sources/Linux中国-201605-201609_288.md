# 全球 Linux 桌面份额勇破 2% ！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607691&idx=2&sn=9eb12b00d552b375318218a7bccd9ca0&chksm=bdce948d8ab91d9ba955848dd19276f0b20fb72c6b46a9ed886ad519005f80f4b9830c403928&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607691&idx=2&sn=9eb12b00d552b375318218a7bccd9ca0&chksm=bdce948d8ab91d9ba955848dd19276f0b20fb72c6b46a9ed886ad519005f80f4b9830c403928&scene=27#wechat_redirect)

![](../Images/518119a3f6acad85270c5b81f82ec187.png)

据市场调研机构的数据，在刚刚过去的六月份，Linux 桌面的全球市场份额突破了 **2%**——如果笔者没有记错的话，这是有史以来第一次达到 2%。

根据 Net Applications 的数据显示\[1\]， 之前 Linux 的桌面市场份额一直徘徊在 1% 到 2% 之间，在六月份首度突破，达到了 2.02%。

![](../Images/26bf2c3a3b3cc2e7de21329ca9277f70.png)

*Linux 桌面份额首破 2%*

以下是 Linux 桌面份额在这两年来的变化\[2\]：

![](../Images/6953f56859d4191c5636e83a88c9b94e.png)

*Linux 桌面份额变化*

不过，要是据 W3Counter 的统计数据\[3\]，这不是 Linux 桌面第一次突破 2% 份额。本月，Linux 的份额是 2.48%。而在之前几年，已经长期保持在 2% 以上的份额了。

![](../Images/626b0de5ec03ddb09491f6dd22534216.png)

需要说明的是，以上两家的统计数据都是依据浏览器对网站的访问进行统计的。
