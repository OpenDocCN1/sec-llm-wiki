# 开源新闻速递：Chrome 占有近 50% 的桌面份额

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607678&idx=3&sn=d8dfb3a38024a45a61b188d251b40663&chksm=bdce94f88ab91dee7bae8d065c2df8c57d3857553248e552a2fc14fde386e427c519e61ec7b6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607678&idx=3&sn=d8dfb3a38024a45a61b188d251b40663&chksm=bdce94f88ab91dee7bae8d065c2df8c57d3857553248e552a2fc14fde386e427c519e61ec7b6&scene=27#wechat_redirect)

今日关注

![](../Images/0694c5eb713e8a7e9aa88a19fc7dbbb8.png)

据调查机构 Net Applications 的报告， Google Chrome 即将在桌面端取得 50% 的市场占有率。而自从微软决定在 Windows 10 中采用新的 Edge 浏览器（5%）起，IE 的份额就越来越低，现在只略高于 30%。Firefox 将近 8%。

![](../Images/1a785ecf7ea7457a95b8d2256c2b4328.png "Google Chrom 48.65%，Internet Explorer 31.65%")

*Google Chrom 48.65%，Internet Explorer 31.65%*

*作为现存的最古老的 Linux 发行版， 也是笔者用过的第一个 Linux 发行版，Slackware Linux 刚刚发布\[1\]了 14.2。作为坚守传统的代表，该发行版是目前少数的仍旧不使用 systemd 的主流 Linux 发行版之一。虽然如此，这并不代表 Slackware 很陈旧，这次发布的新版本中使用了 Linux 4.4 内核、支持  LLVM/Clang 的 GCC 5.3 编译器、 PHP 5.6.23、Python 2.7.11 等。*

![](../Images/76e805cc83d1bb91b255037d8f6f1fad.png "著名的 Linux 滚动发行版例行发布了新的 ISO 镜像：Arch Linux 2016.07.01。新用户可以用它安装，一滚到位。")

*著名的 Linux 滚动发行版例行发布\[2\]了新的 ISO 镜像：Arch Linux 2016.07.01。新用户可以用它安装，一滚到位。*

![](../Images/541ab775449a371c87f589e80f35dadc.png "著名的微型 Linux 发行版 4MLinux 发布了 18.0。")

*著名的微型 Linux 发行版 4MLinux 发布\[3\]了 18.0。*
