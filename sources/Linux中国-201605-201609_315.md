# 开源新闻速递：FFmpeg 3.1 “Laplace”发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607633&idx=4&sn=9e148669f2bc7b1fa6ccfbd8f91c03af&chksm=bdce94d78ab91dc19fbac845b12ba4033dac22b11255f8a46acf8d4d8ee1d88851b2c7540ed6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607633&idx=4&sn=9e148669f2bc7b1fa6ccfbd8f91c03af&chksm=bdce94d78ab91dc19fbac845b12ba4033dac22b11255f8a46acf8d4d8ee1d88851b2c7540ed6&scene=27#wechat_redirect)

今日关注

经过四个月的开发，FFmpeg\[1\] 3.1 “Laplace”发布\[2\]，接替了之前的 FFmpeg 3.0 “Einstein”。差不多每三个月 FFmpeg 就会发布一个新版本。这个新版本更新了多数组件，包括：libavutil 55.27.100、libavcodec 57.48.101、libavformat 57.40.101、libavdevice 57.0.101、 libavfilter 6.46.102、 libavresample 3.0.0、 libswscale 4.1.100, libswresample 2.1.100、libpostproc 54.0.100 等等。推荐用户更新到这个最新的稳定版。

*Ubuntu 全系列收到一个安全更新：Ubuntu Security Notice USN-3016-1\[3\]，影响到 Ubuntu 16.04 及其分支。此外，15.10 及更低版本也受到同一影响：Ubuntu Security Notice USN-3017-1\[4\]。请 Ubuntu 用户马上升级\[5\]。*

![](../Images/6d68bf285239b67e52bab3a56485425b.png)  

Linus Torvalds 宣布\[6\] Linux 4.7 内核的第五个 RC 版本如期发布。正式版本按计划会在 7 月中旬发布。
