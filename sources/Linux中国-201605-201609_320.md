# Linux 移植版的游戏性能简直就是垃圾！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607627&idx=1&sn=5cef407a84388abe426469103f49d2ea&chksm=bdce94cd8ab91ddbdb246588aa96835a75f3f2b9b25ca7c4e3956bf03a80ba6a0f0e17825820&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607627&idx=1&sn=5cef407a84388abe426469103f49d2ea&chksm=bdce94cd8ab91ddbdb246588aa96835a75f3f2b9b25ca7c4e3956bf03a80ba6a0f0e17825820&scene=27#wechat_redirect)

最近，著名的测评网站 phoronix.com\[1\] 进行了三个 Windows 和 Linux 性能方面的测评： Windows vs. Linux AMDGPU-PRO / RadeonSI testing\[2\] 、GTX 1080 Windows vs. Linux results\[3\] 和 Intel Windows vs. Linux benchmarks\[4\]，通过将这三个测评的数据使用 OpenBenchmarking.org\[5\] 进行合并归一，可以得出一个令人伤心的结论：大部分游戏在 Linux 下的性能不及 Windows 。与原生的 Windows 游戏的性能相比，很多 Linux 移植版游戏的性能简直就是垃圾，或者说，就像垃圾一样。

![](../Images/d43a926d5047811668d18832ddf52dd8.png)

以下是一些游戏在 Windows 下和 Linux 下的性能比较：

![](../Images/504d3bb4edde8fbc6619409380bc3d3d.png "Phoronix 的老读者们都知道，Linux 版本的虚幻引擎（Unigine）演示的效果与 Windows 相比差距不少，不过过去了这些年，虚幻引擎在 Linux 下的测试性能已经接近了 Windows 版本了，这主要是因为 Linux 下的 GPU 驱动问题越来越少了。这是一个不多的好消息。")

*Phoronix 的老读者们都知道，Linux 版本的虚幻引擎Unigine演示的效果与 Windows 相比差距不少，不过过去了这些年，虚幻引擎在 Linux 下的测试性能已经接近了 Windows 版本了，这主要是因为 Linux 下的 GPU 驱动问题越来越少了。这是一个不多的好消息。*

![](../Images/36b633648307099d76fcebbc97a3ca0a.png "《Xonotic》是一个开源的跨平台第一人称视角的射击游戏，在 Linux 下的 Intel 驱动的性能差的令我们吃惊，不过其它的驱动看起来还好。我们考虑这里肯定有一些需要特定优化的地方。")

*《Xonotic》是一个开源的跨平台第一人称视角的射击游戏，在 Linux 下的 Intel 驱动的性能差的令我们吃惊，不过其它的驱动看起来还好。我们考虑这里肯定有一些需要特定优化的地方。*

![](../Images/d348f0e158c8e8eac11346b9ae9b5619.png "《古墓丽影》在 Linux 下的性能十分之糟，只有 Windows 下的一半左右。")

*《古墓丽影》在 Linux 下的性能十分之糟，只有 Windows 下的一半左右。*

![](../Images/d3c1b3600d6ec8dfa5bf978373323c0d.png "《超级房车赛：汽车运动（GRID Autosport）》在 Linux 下的性能只有 Windows 下的 60% 左右。") 

*《超级房车赛：汽车运动GRID Autosport》在 Linux 下的性能只有 Windows 下的 60% 左右。*

![](../Images/21e90f623e9cd61cb2df0c0e63971c23.png "Valve 的《Dota 2》 / Source 2 引擎的性能不错！这应该是整个测试中唯二让人满意的结果了。")

*Valve 的《Dota 2》 / Source 2 引擎的性能不错！这应该是整个测试中唯二让人满意的结果了。*

![](../Images/21d4975043b9d5b3b06099aa9da789ad.png "《中土世界:暗影魔多（Middle-Earth: Shadow of Mordor）》的 Linux 下的性能要比其它的 Linux 游戏稍好一些，但是仍然不能同 Windows 下的相比。")

*《中土世界:暗影魔多Middle-Earth: Shadow of Mordor》的 Linux 下的性能要比其它的 Linux 游戏稍好一些，但是仍然不能同 Windows 下的相比。*

![](../Images/83ea92fec3f57ae77e4e83978d6f0d42.png "《F1 2015》的性能也非常糟糕。")

*《F1 2015》的性能也非常糟糕。*

这简直太糟糕了，如此多的 Linux 游戏与其对应的 Windows 下的游戏相比性能差的不是一点半点，不管是什么显卡或驱动都是这样。希望过些时间下一代的游戏能够借助 Vulkan 提升其性能表现吧。
