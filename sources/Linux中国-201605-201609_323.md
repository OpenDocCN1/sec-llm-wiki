# 开源新闻速递：RaspAnd 发行版可以将树莓派 3 变成一台完备的 Android 计算机

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607622&idx=3&sn=643040e69bf3c75adff94839b04941a8&chksm=bdce94c08ab91dd61570eba8a1b833cf006a2ba8fc1e2c5fae81e8b82357a7ee435b6b16b9cd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607622&idx=3&sn=643040e69bf3c75adff94839b04941a8&chksm=bdce94c08ab91dd61570eba8a1b833cf006a2ba8fc1e2c5fae81e8b82357a7ee435b6b16b9cd&scene=27#wechat_redirect)

今日关注

![](../Images/aba0b6f4fb142e811ff059c34177b81c.png)

将 Android 移植到树莓派上的 RaspAnd 发行版今天发布\[1\]了 Build 160625，为树莓派带来了最新的 Android 6.0.1。

它支持树莓派 3B 和 2B，并支持树莓派 3 上的 WiFi 和蓝牙功能，可以将一台微小的树莓派单板计算机变成一台功能完备的 Andoird 计算机。它预装了 GAAPS (Google Apps) ，可以让使用者访问绝大多数的 Google 服务，包括： Google Play Store、Gmail、YouTube、Google 地图、Google Play Services 和 Hangouts 。

*ISRG 谴责 Comodo 试图注册 “Let's Encrypt”， “Let's Encrypt with Comodo”，“Comodo Let's Encrypt” 等三个商标，Comodo 是世界上最大的 CA 证书服务商之一。Comodo 随后表示\[2\]马上签署放弃这三个商标申请的申请。*

![](../Images/7abd9cfb045090aa312f144bc9cff4bf.png "Wine 1.9.13 发布，支持最新的 Unicode 9.0.0，通过 Firefox 47.0 带来了新的 Gecko 引擎，在 Direct3D 中支持更多的 Shader Model 5。")

*Wine 1.9.13 发布\[3\]，支持最新的 Unicode 9.0.0，通过 Firefox 47.0 带来了新的 Gecko 引擎，在 Direct3D 中支持更多的 Shader Model 5。*

![](../Images/12e3d9cbb664134babc8fb618fd4b3f9.png "基于 Ubuntu 16.04 的  Peppermint OS 7 发布，它包括了著名的冰站特定浏览器框架（Ice Site Specific Browser framework），可以让用户安装最新的 Mozilla Firefox、Chromium 和 Google Chrome 浏览器。")

*基于 Ubuntu 16.04 的  Peppermint OS 7 发布\[4\]，它包括了著名的冰站特定浏览器框架Ice Site Specific Browser framework，可以让用户安装最新的 Mozilla Firefox、Chromium 和 Google Chrome 浏览器。*

![](../Images/962bb2e497370b9ae77bb28fd6e3e117.png "Greg Kroah-Hartman 发布了最新的 Linux 4.6.3 内核以及最新的 LTS 内核 4.4.14 以及 3.14.73 LTS，包括多处网络方面的改进。")

*Greg Kroah-Hartman 发布了最新的 Linux 4.6.3 内核\[5\]以及最新的 LTS 内核 4.4.14\[6\] 以及 3.14.73 LTS\[7\]，包括多处网络方面的改进。*
