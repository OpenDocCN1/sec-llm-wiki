# 开源新闻速递：Xen 4.7 发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607610&idx=3&sn=f392a17764036416758bb7fbdab59ae2&chksm=bdce943c8ab91d2a4018e46c80b487aa87b2380f9785c13f24ac2ed151c01f51b2f5295e08c4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607610&idx=3&sn=f392a17764036416758bb7fbdab59ae2&chksm=bdce943c8ab91d2a4018e46c80b487aa87b2380f9785c13f24ac2ed151c01f51b2f5295e08c4&scene=27#wechat_redirect)

今日关注

经过八个月的努力开发，GNU/Linux 下的虚拟机监管软件 Xen 发布了 4.7，这是一个主要版本。

Xen 被广泛用于许多流行的云服务商，包括 AWS 、Rackspace 公有云和 Verizon 云等，为上千万用户提供了服务。

这个版本新增加了一个 XL 命令行接口，允许 PV 客户使用 PVUSB 设备，支持对 USB 设备、HVM 客户端、QEMU 磁盘后端（iSCSI、DRBD）等的热插拔。简而言之，就是不需要重启虚拟机就可以在其上添加或者删除磁盘。这一版本还去除了对 PV 设备的 512GB 限制，从而支持更多的应用和工作负荷。
