看起来大家签到的热情不够啊，到现在才不到四百人签到，而今天的大奖——价值 110.90 的、 W. Richard Stevens 的著作《**UNIX 环境高级编程**》还没有被领走！

  

就这这个机会，和大家聊聊签到福利的情况。

  

*   **每天什么时候签到合适？**其实这个真不一定，签到早未必有利，事实上，越晚签到，概率会相应高一点——当然，你要是过了23:59:59，那就是次日了。
    
*   **连续签到有好处么？**肯定有！但是，现在每天的奖品虽然很诱人，可是只有一份啊，所以只有一个幸运儿能得到。
    
*   **是否会流奖？**这个真发生过，由于有时候抽奖人数太少，奖品生生的被遗忘了，没人领到。
    
*   **签到没中奖怎么办？**把舍友/基友/女友/男友的手机拿来签到~  
    
*   **为什么不公开谁抽到奖品了？**两方面原因，一个是，我们的公众号没有获取参与抽奖的用户信息的 API 调用权限，所以，**从程序上**并无法知道是谁（那怕是名字）抽到奖品了，而中奖信息的确认是人工进行的，我们没有合适的途径来更新这个中奖信息；第二个是，这个其实涉及到了一些隐私，我觉得不太适合公开。当然，目前已经中奖的同学，我可以负责任的说，都已经得到奖品了，也有同学给我们晒出了奖品。
    
*   **有没有人中奖而不领？**有，但是我也不知道为什么不和我们联系——甚至删除了和我们的沟通信息，难道以为是骗局？
    
*   **奖品太少了！**是的，我也在准备增加奖品门类和数量，但是有些工作还没准备好，要是万一有 BUG ，我一气发出去那么多的奖品可就完了。
    
*   **如何才能增加中奖的幸运度？**嗯，抛开一些开玩笑的话不说，严格来说，总体上是基于随机概率的，但是有一些因素会提升中奖概率。这些因素包括：**1、连续签到；2、关注的时间越早；3、签到的时间越晚。**其实，本来我想加入一些更多的有趣因素，但是限于我们的公众号的权限，调取不到。。
