# 多达一千万个处理器核心的神威·太湖之光

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607596&idx=2&sn=893a87ebf0ce773fc123082fabb77d63&chksm=bdce942a8ab91d3cffa5df5259c2f1cbcfb04bda218a87daf0d3167c330cc5442bce3dc4922b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607596&idx=2&sn=893a87ebf0ce773fc123082fabb77d63&chksm=bdce942a8ab91d3cffa5df5259c2f1cbcfb04bda218a87daf0d3167c330cc5442bce3dc4922b&scene=27#wechat_redirect)

神威·太湖之光超级计算机由 40 个运算机柜和 8 个网络机柜组成。每个运算机柜比家用的双门冰箱略大，打开神威·太湖之光超级计算机柜门，4 块由 32 块运算插件组成的超节点分布其中。每个插件由 4 个运算节点板组成，一个运算节点板又含 2 块“申威 26010”高性能处理器。一台机柜就有 1024 块处理器，整台神威·太湖之光共有 40960 块处理器，每个处理器包含了 260 个核心，总共 10,649,600 核心。

![](../Images/ca30fc29795d8eeef6fa5c711a514488.png "申威 26010 众核处理器，包含了 260 个核心")

*申威 26010 众核处理器，包含了 260 个核心*

根据 HPC 的报道\[1\]，处理器包含了1个管理处理单元Management Processing Element (MPE)、1个内存控制器（MC） 和64个计算处理单元Computing Processing Elements (CPE)，MPE 和 CPE 是基于64位 RISC 架构的 SIMD 和错序微结构。MPE 能执行管理、通信和计算，而 CPE 主要执行指令计算。

神威·太湖之光的操作系统 Raise OS 2.0.5 是基于 Linux，包含了 C/C++ 和 Fortran 编译器、自动向量化工具、基础数学库，支持 OpenACC 2.0。

超算的 LINPACK 测序性能高达 93 petaflops，但 LINPACK 并不能反应实际应用；它的 HPCG 测试只有 0.371 petaflops，相比之下天河二号是 0.580 petaflops，泰坦是 0.322 petaflops，日本理化所的 K computer 是 0.460petaflops。下一代申威处理器据报道将使用28纳米工艺制造。
