SourceForge 远离糟糕的过去，但重建信任需要时间

开源项目托管网站 SourceForge[1] 曾有一段时间“恶名昭著[2]”，这些恶名包括：在可执行程序内捆绑推广软件，在网站上展示假的下载按钮等。

前不久 SourceForge 和 Slashdot 媒体被母公司 DHI Group 出售给了 BIZX LLC，而 BIZX LLC 决定采取措施重新赢得用户信任。摆脱糟糕的过去也许容易，但重建信任可能需要漫长的时间[3]。

SourceForge 和 Slashdot 总裁 Logan Abbot 抱怨媒体没有关注它采取的改善措施。他表示，SourceForge 已经移除了 99% 的欺骗性下载广告；正在推出举报系统允许任何用户举报不良广告；默认启用了 HTTPS（然而并没有？）；与 BitDefender 合作提供恶意程序扫描，每一个程序都经过了扫描，如果发现恶意程序或广告软件将会关闭下载。

自由软件基金会（FSF）今年4月对源代码托管平台进行了伦理评分[4]，GitHub 和 SourceForge 的评分是F，都被认为是不能接受的，被扣分的主要原因是：网站的重要功能必须使用非自由的 JavaScript 代码才能工作；为遵守美国政府的出口控制政策特定信息没有提供给所有国家。Abbot 对此表示，SourceForge 上托管了加密软件，他们必须遵守美国的加密出口控制政策，而 SourceForge 的大部分核心功能需要 JavaScript 才能工作。
