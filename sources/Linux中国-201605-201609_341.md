![](../Images/c83e69ec053348cdf018e331bdb7fda5.png "Chakra GNU/Linux 的用户可以对一些核心组件进行更新了。可以将桌面环境更新到 KDE Plasma 5.6.5，将内核更新到 Linux kernel 4.5.7，以及 Qt 5.6.1等，都可以从软件仓库中进行下载更新。")

*Chakra GNU/Linux 的用户可以对一些核心组件进行更新了。可以将桌面环境更新到 KDE Plasma 5.6.5，将内核更新到 Linux kernel 4.5.7，以及 Qt 5.6.1等，都可以从软件仓库中进行下载更新。*

 

![](../Images/e76643c2f60efc4703c7e2b7b00986b4.png "基于 Ubuntu 16.04 LTS 的 Ultimate Edition 5.0 LTS 发布。采用了 MATE 1.14.1 桌面环境。这是一个长期支持版本，会一直支持到2019年。不过目前只提供了64位机器的镜像。稍后会发布完整版本，支持32位机以及 GNOME 桌面环境。")

*基于 Ubuntu 16.04 LTS 的 Ultimate Edition 5.0 LTS 发布\[3\]。采用了 MATE 1.14.1 桌面环境。这是一个长期支持版本，会一直支持到2019年。不过目前只提供了64位机器的镜像。稍后会发布完整版本，支持32位机以及 GNOME 桌面环境。*

 

![](../Images/317991e2c1bd266cb1b258c4d9ab9dde.png "代号为“Lithium”的 Parrot Security OS 3.0 发布。Parrot Security OS 是一款基于 Debian GNU/Linux 的云友好的操作系统，专为各种安全渗透测试而设计。最新的发布提供了各种安装版本，不同版本可能有不同的桌面环境还有安全测试工具。已经可以进行下载了。详情见官网。")

*代号为“Lithium”的 Parrot Security OS 3.0 发布。Parrot Security OS 是一款基于 Debian GNU/Linux 的云友好的操作系统，专为各种安全渗透测试而设计。最新的发布提供了各种安装版本，不同版本可能有不同的桌面环境还有安全测试工具。已经可以进行下载了。详情见官网\[4\]。*
