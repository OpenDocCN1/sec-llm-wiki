# 2016年软件定义存储（SDS）技术沙龙

以云计算、大数据、移动和社交网络所引领的第三平台推动了存储市场技术的变革，软件定义存储市场迅速崛起。

华章科技书院联合VMware存储架构师叶毓睿先生以及Linux中国共同发起和组织了这次“2016软件定义存储技术沙龙”，这次沙龙以分享技术干货为主，我们邀请了：

>     
> *   高志国 联想基础云产品总监及联想超融合架构和产品的发起者
>     
> *   刘  通  Mellanox 公司亚太区市场开发总监兼国际高性能计算咨询委员会亚太区主席
>     
> *   张  瑾  飞康软件公司亚太区市场总监
>     
> *   李炫辉 绿芯（Greenliant）半导体系统科技有限公司副总裁

> *   朱荣泽 UMCloud/Mirantis解决方案架构师兼OpenStack/Fuel/Ceph代码贡献者
>     

共计十余位技术专家到现场为大家分享软件定义存储领域的最新技术、产品和应用实践。

技术分享结束后，我们将隆重发布由叶毓睿先生与国内18位来自存储领域最顶尖的技术专家撰写的《软件定义存储：原理、实践与生态\[1\]》一书，该书是软件定义存储（SDS）领域的集大成者和开创性著作，堪称“中国软件定义存储第一书”。

华章科技书院是机械工业出版社华章公司旗下的一个O2O组织，我们将以华章的出版业务和教育服务为依托，围绕技术、产品和商业等主题，以线上和线下相结合的方式，为中国广大的IT行业从业者提供国际前沿的技术趋势、深度的产品解读、敏锐的商业洞察，以及接地气的企业实战经验。我们将以信任和支持华章的行业专家和忠实读者为核心和主体，不定期举办各种活动，搭建一个共同交流的平台，提供更加优质的学习服务和体验。

 

幂次方学院（原优客工场商学院）作为优客工场创业生态圈的重要组成部分，将是一个重要的发展平台，为创业者及其企业在创业道路上提供从单项类到模块式以及综合性的各类创业管理实践课程，通过创新创业案例的收集调研、沉淀应用，打造中国创新创业教育案例库，服务创新创业人群~ 优客工场由万科集团外部合伙人、知名地产人士毛大庆先生发起，红杉资本、真格基金、创新工场、亿润投资、清控科创、诺亚财富等多个投资机构共同投资，与国内多位知名企业家联合创始成立。
