# 开源新闻速递：Linux 4.7 内核发布了第二个 RC 版本

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607487&idx=3&sn=83e9688dfdf892a3eb60a99078715b49&chksm=bdce95b98ab91caf8b6304783f556f5e0f27adb57c19da0e6487ecc7b26d682ce00afe70a007&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607487&idx=3&sn=83e9688dfdf892a3eb60a99078715b49&chksm=bdce95b98ab91caf8b6304783f556f5e0f27adb57c19da0e6487ecc7b26d682ce00afe70a007&scene=27#wechat_redirect)

今天关注

Linux 4.7 内核发布\[1\]了第二个 RC 版本。

被很多 Linux 发行版都作为默认桌面主题的 Arc GTK 主题\[2\]发布了相配合的图标主题  Arc Icon\[3\]，不过目前该图标主题还不够完整，缺少很多图标。不过该图标主题是依赖于非常流行 Moka 图标主题，所以如果你已经安装了 Moka 图标主题，那么缺失的图标会以 Moka 图标替代，否则就要默认的 GTK 图标替代。

![](../Images/c019eec704eef5c1db19a66af84ec529.png)

新闻摘要

*   DebEX\[4\] KDE Live DVD 160604 发布，它是基于 Debian GNU/Linux 8.4 开发的。
    
*   另外一个同样基于 Debian 的发行版 Q4OS\[5\] 发布了 1.4.11\[6\]。
    
*   Qt 5.7.0 发布\[7\]了 RC 版本，正式版本会在几周后发布。
    
*   Docker 发布\[8\]了 1.11 的第二个维护版本。 
    
*   Debian 发布了 Chromium 51 的多个重要安全补丁\[9\]，请用户尽快升级。
