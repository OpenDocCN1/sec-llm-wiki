# Linux 基金会宣布面向物联网设备的实时操作系统构建项目 Zephyr

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607414&idx=3&sn=6fca22f482de05f3b1f88d16716a9e74&chksm=bdce95f08ab91ce6d9af61348f339e6f96ead61436968139164aa1c9118fbef44fb2e7b35512&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607414&idx=3&sn=6fca22f482de05f3b1f88d16716a9e74&chksm=bdce95f08ab91ce6d9af61348f339e6f96ead61436968139164aa1c9118fbef44fb2e7b35512&scene=27#wechat_redirect)

>   
> 作者： 赵东辉

> 开源 Zephyr™ 项目旨在构建一款实时操作系统 (RTOS)；呼吁广大开发人员积极参与，帮助推进这个面向最小尺寸物联网设备的项目 

Linux 基金会\[1\]，一家支持通过开源推进大众创新的非盈利性组织，近日宣布启动 Zephyr™ 项目\[2\]。这个开源协作项目将把全行业的领导者联合起来，构建一个面向物联网的实时操作系统。 

![](../Images/652ed41774791eb68cf5cad962ccffb0.png)

Zephyr 项目的早期支持者包括英特尔® 公司（包括收购的 Altera Corporation 和 Wind River）、恩智浦半导体公司（包括最近并购的 Freescale）、新思科技有限公司和 UbiquiOS Technology Limited。Zephyr 项目诚邀对该技术感兴趣的其他公司加入。 

工业和消费类物联网设备需要可扩展、安全且支持无缝连接的软件。开发人员需要在高度模块化的平台上进行创新，后者要能够轻松集成各种架构的嵌入式设备。尽管对于嵌入式开发来说，Linux 已被证明是一款非常成功的操作系统，但一些物联网设备需要一款支持最小内存空间的 RTOS。这将为实时 Linux 提供补充，这种操作系统十分适合数据采集系统、制造厂以及为全球最复杂的计算系统提供关键基础设施的时间敏感型仪器和设备。 

Linux 基金会执行董事 Jim Zemlin 表示：“如今开发人员有许多平台可选。Zephyr 项目将提供一个支持最小尺寸物联网设备的模块化联网操作系统。我们诚邀开发人员参与到 Zephyr 项目中来，帮助推动可定制、嵌入式开源 RTOS 的发展，从而推动物联网发展。该项目由 Linux 基金会主持，我们期待 Linux 和 Zephyr 社区能够开展跨项目协作。”

在为嵌入式物联网设备构建操作系统时，模块化和安全性是主要考虑因素。Zephyr 项目优先考虑这些特性，支持原样使用 RTOS 或定制解决方案。该项目非常关注安全性，计划成立专门安全工作组并委派一位安全维护者。项目还提供广泛的通信和网络支持，初期将包括 Bluetooth、Bluetooth Low Energy 和 IEEE 802.15.4，并计划未来扩展更多通信和网络支持。

![](../Images/accd8994bbce6c18cccc3d95c8cdd77a.png)

Zephyr 项目旨在吸纳来自开源和嵌入式开发人员社区的意见，并鼓励围绕 RTOS 展开协作。该项目还将提供强大的开发工具，帮助推动 Zephyr RTOS 成为一流的物联网嵌入式技术。Zephyr 项目初期支持以下平台，未来还将支持更多架构选择： 

*   Arduino 101（英特尔® Curie™ 模块，包含 x86 和 Synopsys® ARC® EM 内核）；
    
*   Arduino Due (Atmel SAM3X8E ARM Cortex-M3 CPU)；
    
*   英特尔® Galileo™ Gen 2；
    
*   NXP FRDM-K64F Freedom 开发板 (Kinetis K64F ARM® Cortex®-M4 MCU)。
    

对 Zephyr 项目感兴趣的人员，请访问：www.zephyrproject.org\[3\].

关于 Linux 基金会

Linux 基金会是全球顶级开发人员和公司构建生态系统以加快开源技术开发与商用的首选组织。它正与全球开源社区联手解决最棘手的技术问题，并在共享技术方面作出了有史以来最大规模的投资。成立于 2000 年，Linux 基金会目前致力于提供工具、培训和活动来推动开源项目发展，其所产生的经济影响是任何一家公司都无法企及的。
