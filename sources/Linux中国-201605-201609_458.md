# 数人云操作系统 2.0 发布 在企业实践中将 Docker 技术快速落地

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607414&idx=2&sn=1d0f524b1682f1de8b3a8c64ff80da9f&chksm=bdce95f08ab91ce630ff096bb8460c6774decb009395d052ebe09b64ae2c3f9b3f6ca43d9f79&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607414&idx=2&sn=1d0f524b1682f1de8b3a8c64ff80da9f&chksm=bdce95f08ab91ce630ff096bb8460c6774decb009395d052ebe09b64ae2c3f9b3f6ca43d9f79&scene=27#wechat_redirect)

5月26日，数人云产品战略发布会在万达索菲特酒店拉开序幕，此次发布会不仅是一场围绕Docker技术的企业级技术盛会，更是一场关于容器与开源云计算技术实践的分享交流会。

![](../Images/ef03da16ebe8da3872683e92d9fb1ea8.png)

数人云CEO王璞在开场致辞中指出，2014年Docker技术逐步兴起，大量围绕Docker的创业公司以及诸多开源软件项目进一步丰满了容器技术的生态圈。容器技术的势头在今年继续火热，获得了整个行业以及谷歌、亚马逊、IBM、微软、红帽、VMware等IT巨头的支持与拥护。Docker技术的出现为以轻量级容器为核心的新一代PaaS平台提供了爆发式增长的机会，作为领先的云计算创新技术实践者，数人云正在帮助国内传统企业将新一代云技术快速落地在生产环境中。

![](../Images/5d07cdbdccb10b9b89285bdbd0271ceb.png)

数人云CEO王璞 

基于 Docker打造的新一代PaaS更加轻量和通用，改变了企业软件开发和运维的流程，使企业软件的交付方式变得更加便利。越来越多的传统企业客户开始依托新一代PaaS平台支撑其传统业务的转型，国内的互联网公司爱奇艺、去哪儿，IT巨头华为，以及浙江移动、平安科技这样的大型企业级客户都已经开始积极部署实践这项新技术。

当下正处于企业级IT更新换代的节点，数人云为传统企业提供了新一代基于云计算的IT架构，可以帮助传统企业更好地支持互联网相关业务。

数人云操作系统2.0发布

数人云CTO肖德时指出，数人云轻量级PaaS基于开源技术领域的最佳实践，经历了百万压力测试的验证。升级后的数人云操作系统具有应用管理，监控告警&日志查询，应用编排&应用目录，持续集成&镜像构建四大功能，实现了从私有代码管理到应用实例发布的全流程支持，全面支持Docker Compose编排，实现应用实例的灰度发布和自动扩缩。

![](../Images/277162f70d7354d840f2cb6502979fdf.png)

数人云CTO 肖德时 

在资源层，数人云支持企业级混合容器集群管理，通过Mesos以集群的方式统一管理各种私有／混合云主机，将主机变成一个资源池供用户使用，支持分布式集群管理架构。数人云操作系统屏蔽掉了许多硬件底层细节，使用户能够更加专注、高效地使用生产级别的容器环境。

不久前，数人云发布了行业落地解决方案——数人金融容器云。数人金融容器云实现秒级伸缩，帮助客户及时响应高并发等新型业务需求；同时，借助容器技术，数人金融容器云使应用的交付变得更加标准，极大地消除技术部署的局限性，提高客户产品的交付及运维效率。目前，数人金融容器云已经开始为众多金融客户提供部署，上海证券交易所架构师黄成在发布会上分享了上交所使用数人金融容器云的实践与心得。2016年数人云将继续发挥在金融容器云领域的优势，帮助国内金融企业快速进入下一代 IT 领域的容器浪潮。

![](../Images/36c9818969f3203abcc940539ab5ab1a.png)

数人云操作系统2.0发布 

注入更多的开源云计算技术

此次发布会宣布了三个好消息，首先，数人云获得思科容器管理平台Mantl团队的认可。Mantl 也是基于 Mesos 和 Docker 打造的，并在 Github 上开源。Mantl为用户提供了部署微服务平台所需的所有基础设施组件，通过将这些组件良好地配合运行，使用户免于编写用于整合这些组件的代码。Mantl 项目一经推出就受到极大的关注，在 Github 已经获得2千多次点赞。数人云已经跟思科在Mantl项目上深入合作，并在产品中融合了Mantl的核心经验。

同时，数人云也与VMware中国研发中心深度合作，积极参与 Harbor项目。Harbor是 VMware 中国研发中心开源的企业级Docker 镜像仓库项目，专门解决企业级 Docker 私有镜像仓库的需要。目前，Harbor已成功集成到数人云产品中，数人云是国内最早和Harbor项目进行对接的开源云计算公司，两家公司在产品集成方面进行了深度整合。 

此外，数人云还获得了新一代容器技术HyperContainer的支持，进一步推动了多元化容器技术进入数人云产品线的进程。

谈及未来，肖德时指出，2017年数人云将提供横跨多个IaaS的容器 PaaS服务，帮助中小企业以应用为导向消费云计算能力；并在2018年提供更加智能的云操作系统，数人云将具备机器学习能力，实现动态扩容弹性应用。 

关于数人云

数人云创始团队来自谷歌、红帽和惠普，在今年3月初公司完成A轮融资，由云启资本领投，思科、策源以及唯猎跟投。作为领先的云计算创新技术实践者，数人云致力于打造最轻量化的PaaS平台，将应用弹性做到极致。基于Docker+ Mesos，数人云实现一站式的微服务架构集群系统，最大化地帮助客户实现应用业务在云端的快速部署，解决从客户到云资源的最后一公里。
