# Redis 中国用户组成立了，欢迎加入！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607392&idx=4&sn=e58965c3238f325d106c589cf47da2b4&chksm=bdce95e68ab91cf0a3b6c2cd243f10c909a723f2e783c46c7dcaaabaafed42609cc959ddb7d7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607392&idx=4&sn=e58965c3238f325d106c589cf47da2b4&chksm=bdce95e68ab91cf0a3b6c2cd243f10c909a723f2e783c46c7dcaaabaafed42609cc959ddb7d7&scene=27#wechat_redirect)

很高兴地告诉大家，Redis 中国用户组（CRUG）\[1\]经过一个多月的紧张筹备，终于在 5 月 20 日这个美好的日子和大家见面了！我们诚挚地希望有更多的 Redis 爱好者加入到我们当中，共同致力于 Redis 技术的推广和应用，让 Redis 能够发挥更多的力量。

![](../Images/3eadc212dcc0718e5d5bd1add359c364.png)

首先，我们非常感谢 Antirez 等大神为我们开发出了这么好用的工具，也非常感谢 Rediser 们为 Redis 软件的持续更新、功能改善和性能提高付出的努力，以及为建立健全的文档而付出的辛勤努力。我们注意到随着互联网技术的日益普及，Redis 在国内被普遍应用，越来越多的人开始了解 Redis，越来越多的企业开始应用 Redis。但是对于 Redis Cluster 这些比较新的技术，在生产环境中还是使用较少的；在 Redis 的代码贡献上，还是鲜见国人的身影。所以，我们任重道远...

Redis 中国用户组\[2\]，是由国内互联网公司的 Redis 方面的一线工程师联合发起的非营利性技术组织。Redis 中国用户组的成立得到了核心发起人李强和许瑞的大力推动，无私地将他们从 2011 年运营至今的 redis.cn\[3\] 社区贡献出来，作为 Redis 中国用户组的官网\[4\]。不仅如此，我们还组建了 Redis 中国用户组的 QQ 群 （521503946）和微信群，给大家提供线上的技术交流渠道。并且， Redis 中国用户组也有了自己的官方微博（蓝V哦~）@Redis2016\[5\]。除此之外，我们还第一时间组织力量给 Redis 官方发出认证请求函，以期得到官方的认可和支持，并收到了 Redis 官方的认可和支持的答复！

Redis 中国用户组\[6\]，在国内作为 Redis 方面的一个核心组织，在今后的岁月里主要会从以下几个方面为持续推广普及 Redis 做出努力：

1.  延续 redis.cn\[7\] 的使命，坚持不懈的继续翻译来自 Redis 官网及相关网站的技术文章、期刊、新闻等，相信很多初学者都是从这里成长起来的；
    
2.  不定期地组织线上分享；
    
3.  不定期地组织线下交流活动、技术沙龙或联合举办技术大会；
    
4.  逐步开始运营 Redis 中国用户组的官方微信订阅号，推送经典技术文章、博客等；
    
5.  邀请 Redis 方面的技术大牛，讨论交流，并在 Redis 的代码贡献上持续发力；
    
6.  将来考虑以 Redis 中国用户组的名义出版系列书籍。
    

写在最后，我们真诚地希望更多的 Redis 用户或爱好者能加入到我们的行列中，一起努力，创造 Redis 美好的明天。

最后特别感谢 Redis 中国用户组核心成员（发起人）：李强（创业中）、张冬洪（微博）、王义成（阿里云）、许瑞（唯品会）、强昌金（去哪儿）、曹增涛（微博）、刘东辉（微博）、卓汝林（小米）、孙赫（今日头条） 等人。
