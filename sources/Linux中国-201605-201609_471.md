# 开源新闻速递：即将发布的 GNOME 3.22 的各个应用逐步就绪

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607392&idx=3&sn=5d45254e2cee7a01135310016eb9d726&chksm=bdce95e68ab91cf0d25937bc8083c34da52bc3418966cef8e32eb3afdaaabfc8f25e103783ff&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607392&idx=3&sn=5d45254e2cee7a01135310016eb9d726&chksm=bdce95e68ab91cf0d25937bc8083c34da52bc3418966cef8e32eb3afdaaabfc8f25e103783ff&scene=27#wechat_redirect)

头条消息

即将到来的 GNOME 3.22 中，各个主要应用都逐步就绪：比如，“游戏”应用会支持 Atari 2600 和 Atari 7800 游戏；“日历”应用可以使用拖放来移动事件；“控制中心”应用也重新打造了等等。

![](../Images/ef9dfaef3109eae3edde01183bb2f436.png)

Ubuntu 的 Mir 显示服务器将在 0.24 版本中完全支持 Vulkan API，在当前发布的版本 0.22.1 中已经初步支持了。更多详情\[1\]。

SeeedStudio\[2\] 发布了一款树莓派 3 的替代品：狗骨头之绿色无线版BeagleBone Green Wireless，内置 Wi-Fi 和低功耗蓝牙。该产品已经可以预定，零售价 $44.9。

![](../Images/fc731d2f4e8877d16fc2f90ce17389e6.png)

版本更迭

*   systemd 发布\[3\] 230 版本，这个版本中，systemd 所接管的解析器进程 systemd-resolved 将默认打开 DNSSEC。
    
*   Q4OS 1.4.10\[4\] 发布。它是一款基于 Debian 的发行版，采用 Trinity 桌面环境（TDE），新版本引入了“Bourbon”开始菜单，这是一个双面板的、可高度定制的开始菜单系统。  
    ![](../Images/78455172878773909332daa1348e03a1.png)
    
*    Mozilla Firefox 46.0.1\[5\] 已经放到了 Ubuntu 的软件库中，然而 Mozilla Thunderbird 的最新稳定版 45 并没有一同出现，目前 Ubuntu 软件库中仍然是很老的 Mozilla Thunderbird 38.8.0\[6\]，至于原因则不得而知。当然，你可以自己手工升级使用最新版本：`sudo apt-add-repository ppa:mozillateam/thunderbird-next`，`sudo apt-get update && sudo apt-get dist-upgrade`。
    
*   Ubuntu 16.04 LTS 中的 KDE 用的是 KDE Plasma 5.5 和 KDE Applications 15.12，然而最新的 KDE 版本已经是 5.6.4 了。不过， Kubuntu 和 KDE 开发者 Marcin Sągol 宣布\[7\] Kubuntu 用户可以不用等待了，可以使用如下命令来升级到最新的 KDE 5.6.4 ：`sudo apt-add-repository ppa:kubuntu-ppa/backports` ，  
    `sudo apt update && sudo apt -y full-upgrade` 。
