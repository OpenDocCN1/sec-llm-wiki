# 开源新闻速递：Fedora 年度大会 Flock 2016 将于 8 月召开

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607380&idx=2&sn=38b69a17177d6f208ae17e7621996215&chksm=bdce95d28ab91cc46555c5e514fcf05802966bd885abbaa37e5ec819725b763cbbbc5e562583&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607380&idx=2&sn=38b69a17177d6f208ae17e7621996215&chksm=bdce95d28ab91cc46555c5e514fcf05802966bd885abbaa37e5ec819725b763cbbbc5e562583&scene=27#wechat_redirect)

头条消息

一年一度的 Fedora Linux 大会 Flock 2016 即将\[1\]在 8 月 2 日 - 5 日在波兰召开。本次大会主要是彼此分享和讨论 Fedora 25 的开发。如果你希望参加该会议，现在预注册已经开放\[2\]了。

![](../Images/352f91c51468bdb4111447cac851af17.png)

 

版本更迭

*   Webconverger 发布\[3\]了 35.1，这次更新带有 Mozilla Firefox 46.0 和 Linux 4.5 内核。有很多基于 Linux 的发行版号称自己是最棒的 Web 
    
    信息亭kiosk
    
    平台（常用于网吧），但是 Webconverger 是这些之中最流行的一个，它是基于 Debian 的一个发行版。
    
*   Linux 3.14.70\[4\] 内核更新。
    
*   漂亮大方的 Linux 发行版 Pinguy OS\[5\] 即将关闭，其维护者 Antoni Norman 做了一个艰难的决定，大概是由于经济原因，他说\[6\]，“相比我的收获，这个项目耗费了我太多，这是一个无底洞。”  
    ![](../Images/208658bd2c8e58d9c850d34625cb9b09.png)
    
*   Git 2.8.3 发布，带来了包括子模块并行获取等超过20处的改进和修复。
    
*   Cinnamon 3.0.3 发布，它将是在即将发布的 Mint 18 "Sarah" 的默认桌面环境。
