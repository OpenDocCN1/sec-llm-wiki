# 开源新闻速递：第一届 LAS GNOME 大会即将召开

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607367&idx=2&sn=24acfc48c8ecbde96bdfd4b2cd584389&chksm=bdce95c18ab91cd729203497016d6ff6b586c319dd3f59e62f921a6644ba504a6f891acbcc92&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607367&idx=2&sn=24acfc48c8ecbde96bdfd4b2cd584389&chksm=bdce95c18ab91cd729203497016d6ff6b586c319dd3f59e62f921a6644ba504a6f891acbcc92&scene=27#wechat_redirect)

头条消息

GNOME 基金会宣布\[1\]即将召开第一届 LAS （Libre Application Summit） GNOME 大会，大会将在 9 月 19 日至 23 日于美国俄勒冈州波特兰市召开 。大会的主要目的是通过加强主要的 GNU/Linux 发行版和 Linux 内核之间的合作来推进 GNU/Linux 应用生态系统的发展。大会面向大小不等的开源应用开发者，包括参与开发各种 FOSS 的公司和个人，以便让他们可以分享他们知识，推进 GNU/Linux 软件项目的发展。

![](../Images/0e0dea8dfea45bcb9607303ec33513fe.png)

版本更迭

*   Manjaro ARM 16.05 正式发布，完全支持树莓派 2，开发团队正在努力开发支持蓝牙和 WiFi 的树莓派 3 版本。它是基于非官方的 Arch Linux for ARM 的衍生版。这个该项目的第一个稳定版本。
    
*   Linux 4.5.5 和 4.4.11 LTS 内核发布。
    
*   Enlightenment 开发者日 2016 大会刚刚结束， Enlightenment 就发布\[2\]了 0.20.8 版本。这是一个轻量级的漂亮的桌面环境。而备受期待的 0.21 还在努力开发中，当前还在 Beta 阶段。  
    ![](../Images/a889b59898f7f864602ca6bd7662075e.png)
    
*   pfSense BSD 防火墙 2.3.1 发布\[3\]，注意，这不是之前发布的 pfSense 2.3 Update 1（即 2.3-1），而是一个完整的维护版本，带来了超过100个更新。
