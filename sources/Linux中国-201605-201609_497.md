# 每个 Ubuntu 用户都应该知道的 Ubuntu 16.04 LTS 的十大新功能

开发了六个月后，Canonical在2016年4月21日正式发布了新的Ubuntu 16.04 LTS。现在它可供下载，安装到PC、笔记本和上网本上。

Ubuntu的这个版本是作为“长期支持”版(LTS)发布的，将在5年的时间内得到更新和安全补丁；在此期间，会发布多个单点版本(Ubuntu 16.04.1、Ubuntu 16.04.2和Ubuntu 16.04.3)。它还随带数量众多的变化，以及几项新的特性和功能。下面是每个Ubuntu用户都应该知道的新Ubuntu 16.04 LTS的10项功能。

**1.随带Unity 7.4和Compiz 0.9.12.2**

![](../Images/822b126d4f3d0bd8b31f0a4e2cd9833e.png)

作为Ubuntu 16.04 LTS的主桌面环境，Unity更新到了版本7.4;作为组合管理器，compiz更新到了版本0.9.12.2。 下面是Unity 7.4中出现的最显著的变化：

**Unity启动器可以移到屏幕底部**

![](../Images/11b896180c5a46ac433ee6b7c1973147.png)

Unity启动器不再无法移动。从Ubuntu 16.04开始，用户可以实现改变启动器的位置，可以将启动器移到屏幕底部，但是无法移到右边或顶部。打开终端，然后输入下面这个命令，即可将启动器移到屏幕底部：

```
1.  `gsettings set com.canonical.Unity.Launcher launcher-position Bottom `
    
```

如果你使用后，觉得不喜欢，还可以恢复到屏幕左边，只要运行：

```
1.  `gsettings set com.canonical.Unity.Launcher launcher-position Left `
    
```

**会话快捷方式添加到Unity Dash**

![](../Images/c9d130d52498ff64d514016a45bd9561.png)

现在用户可以从Unity Dash执行关闭、重启、锁屏、退出等操作。

**添加在菜单栏或本地“总是显示”应用程序菜单的选项**

![](../Images/f6a53cf4cd0e462e2fd2cbf42ede3576.png)

借助这个选项，你可以在菜单栏或窗口标题栏显示菜单，visiblity将始终被显示，鼠标悬浮在上面时就会出现。当然，你可以直接进入到所有设置>外观>标签行为，修改这项特性。

**Unity Dash中新的滚动栏**

![](../Images/231218b1dc6afd0a59d01c89d0eb059e.png)

工作空间切换器获得了快速列表

![](../Images/6127800ce1153715762c4fa0729ba39d.png)

现在，你只要鼠标右击Unity启动器中的工作空间快捷方式，就可以在工作空间之间轻松移动。你先确保启用了工作空间图标，然后进入到所有设置>外观>标签行为，即可启用它。

**Unity 7.4中出现的其他功能：**

*   表明多少个外部存储/垃圾窗口是开着的。
    
*   启动器上的外部存储可以使用快捷方式Alt+{数字键}来打开。
    
*   在设置->外观中，你可以选择菜单可用性始终显示还是鼠标悬浮在上面后才显示。
    
*   装入应用程序时，图标出现在启动器中。
    
*   Ubuntu主题已改进了客户端装饰(Client Side Decorations)支持。
    

**2.为用户显示关于软件更新的通知**

**![](../Images/62abb623e0376ca5c052272a09fa34b7.png)**

正如你从屏幕截图中可以看到的，Ubuntu 16.04 LTS会发送你需要安装的软件和操作系统更新的通知。该通知形式并不是交互式的；从近段时间，我们的观察情况来看，通知每隔几天就会随机性出现。

**3.基于长期支持Linux内核系列4.4**

**![](../Images/7b66ea25745c4e24e5491d92ce634152.png)**

Ubuntu 16.04 LTS随带长期支持Linux内核系列4.4.x的功能。它对系统稳定性、性能、电源效率和文件系统处理作了无数的改进，还支持更新颖的英特尔和AMD硬件。

*   改进了对英特尔Skylake处理器的支持
    
*   虚拟GPU驱动程序中支持3D
    
*   面向海盗船Vengeance K90的新驱动程序
    
*   支持TPM 2.0芯片
    
*   支持日志RAID 5
    

它还推出了针对罗技G29赛车方向盘的驱动程序，能够支持一些较新颖东芝笔记本电脑上的硬件特性。

**4.面向HUD的新键盘快捷键。**

**![](../Images/e9164f6dfb3f48a7c6fb4a6cc326644a.png)**

打开平视显示器(HUD)的默认快捷键由ALT变成了ALT+空格键。

**5.联机搜索默认情况下被禁用。**

**![](../Images/da142ac50472606f0da8cf75c57ec87c.png)**

近几年在隐私和安全方面，Ubuntu的Dash里面的联机搜索结果有相当大的争议。一些人甚至称之为“Ubuntu间谍软件”(这当然不准确)。在Ubuntu 16.04这个版本中，这项功能被禁用。当然，你总是可以进入到设置>安全与隐私>搜索，重新启用该功能。

**6.GNOME软件作为默认程序包管理器。**

**![](../Images/8cd3d9f8e90aff697abb2d7fcbd9c694.png)**

这个版本的Ubuntu丢弃了Ubuntu软件中心，改而换成了GNOME软件。GNOME软件出现在Ubuntu 16.04 LTS上是好消息，因为GNOME软件成了默认的软件管理工具，这意味着会有来自不同Linux发行版的更多贡献。

**7.apt取代apt-get。**

**![](../Images/796f87af95cd5f7881aa70884016a5fa.png)**

apt命令添加到Ubuntu 16.04 LTS中。APT是来自Debian项目的高级程序包工具，初衷是为了解决许多程序包管理问题，比如结束烦人的依赖项问题，许多人在基于Linux的操作系统的早期阶段都遇到过这种问题。

apt命令与apt-get命令没有太大的区别。你可以使用apt install取代apt-get install，可以使用apt search取代apt-cache search，不一而足。如果你使用apt命令安装了某个程序包，它会在终端显示进度条，显示安装过程的状态，这是个蛮有意思的功能。

**8.为桌面引入Ubuntu Snappy。**

**![](../Images/516e811ae5d3faac3251eea172825821.png)**

Ubuntu 16.04 LTS终于为Ubuntu带来了Snap程序包。Snaps可以说是Ubuntu平台上应用程序(桌面和移动版)的未来。

Snaps是一种新的方法，可以将应用程序包装后分发给Ubuntu用户。Snaps随带所有依赖项和库，所以哪些程序包和库安装在你的系统上并不重要。因而，一旦有最新版本的应用程序，用户可以第一时间安装。

**9.默认情况下支持ZFS。**

Ubuntu 16.04还在默认情况下增添了对ZFS的支持，不过它在默认情况下并没有启用。ZFS是一种流行的文件系统，用于存储数据。它采用了独特的设计方式，可以不断检查存储数据，确保没有受到损坏；多年来，ZFS一向是Linux社区的一个非常热门的话题。

**10.更新了一批核心应用程序。**

Ubuntu 16.04 LTS随带最新版本的默认应用程序。你可以获得Firefox 45、Thunderbird 38、LibreOffice 5.1、Files 3.14.2、Videos 3.18、Rhythmbox 3.3、GNOME Terminal 3.18、Eye of GNOME 3.18、Shotwell 0.22及更多应用程序。你还可以轻松安装需要的任何应用程序。

想了解该版本的更多信息，你可以参阅Ubuntu 16.04软件发布说明\[1\]。
