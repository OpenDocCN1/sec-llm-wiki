# 开源新闻速递：肖似 Window 10 的发行版 ChaletOS 16.04

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664607352&idx=1&sn=5203e154779a701550cb90bc43f80dc5&chksm=bdce953e8ab91c28cf47db4e35a19eda5be627024ca77e75a65cf6b010292b3f9fa49b890875&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607352&idx=1&sn=5203e154779a701550cb90bc43f80dc5&chksm=bdce953e8ab91c28cf47db4e35a19eda5be627024ca77e75a65cf6b010292b3f9fa49b890875&scene=27#wechat_redirect)

头条消息

有一款名为 ChaletOS 的发行版今天刚刚发布\[1\]了 16.04 LTS ，它是一款基于 Ubuntu 16.04 LTS 的发行版。这个发行版的主要目标是为那些前 Windows 用户们提供一个进入开源世界的便捷之路。它提供了一个名为起点Start Point的应用，设计用来帮助那些 Windows 用户们快速熟悉该系统，这个应用里面包括视频指引、教程和推荐应用等。

不过，对于有些 Windows 用户，可能希望看到熟悉的 Windows 界面，因此，ChaletOS\[2\] 的开发者 Dejan Petrovic 还发布了一个快速教程\[3\]，教给用户如何将他们的 ChaletOS 16.04 桌面转换为 Windows 10 外观。你只需要下载这个 Windows 10 图标包\[4\]即可将它变得和 Windows 10 一样。  
  
![](../Images/3520fd84e85a42686a115c17030a0aa6.png)

当然，就笔者的角度来看，就是不转换成 Windows 10 外观，看起来也挺不错的。

![](../Images/a7f66737233f5dd93b7693814d3bf847.png)

![](../Images/fa0c74d43c20d089374c825d993cf00a.png)

昨天 [Linux 4.6 内核刚刚发布](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607345&idx=1&sn=9a551101a679df430abe2f7a27f2df79#rd)，不到一天，Arch Linux\[5\] 和基于 Debian GNU/Linux 的 SparkyLinux\[6\] 也分别宣布他们支持了 Linux 4.6 内核。这两个发行版应该是第一批支持 4.6 内核的发行版。当然，Gentoo 也可以，只是需要你自己去搞定。不过我们并不太建议马上就尝鲜 Linux 4.6 内核，应该等待它进入各个发行版的稳定仓库再更新。

版本更迭

*   Wine 1.9.10 发布\[7\]，带来了 MAC OS 下的 Retina 高分辨率支持。
