# 每日安全资讯：密码保护有多重要，Cellebrite的破解工具告诉你

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608614&idx=4&sn=23d70c0f19e566bdd2956bde86d34b87&chksm=bdce88208ab901364256b147260d6fdedc575ff567b3d931960b032a6e13e0376e5043ec0466&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608614&idx=4&sn=23d70c0f19e566bdd2956bde86d34b87&chksm=bdce88208ab901364256b147260d6fdedc575ff567b3d931960b032a6e13e0376e5043ec0466&scene=27#wechat_redirect)

最近几年Cellebrite因其破解手机加密技术以及访问设备上存储的数据的能力而获得了大量关注。起初大家都认为Cellebrite就为FBI破解圣伯纳迪诺枪击案凶手的iPhone 5C的幕后支持公司，不过之后有报道反驳了这个观点。今天早些时候，ZDNet发表了一份报道显示了Cellebrite的破解工具究竟有多强大，相信你看了之后就明白了保护自己的重要性有多大了。

![](../Images/074dd6924d5b23e4e1416ee46e9ede9f.png)  

Cellebrite的UFED工具在全美的警局中使用。报道中引用的数据都是从一部运行iOS 8系统的iPhone 5中获取的。该手机没有加密，没有密码。

因为手机没加密，Cellebrite的UFED工具能够在几秒钟内访问手机内所有的数据。该手机只是简单地连上该设备，然后执法人员运行一次逻辑提取就可以下载手机存储器上的数据。

该报道提到这些数据包括短信息、音乐、App、备忘录、通话记录以及更多数据。可能与iTunes运作方式最重要的和最不一样的地方就是，UFED工具可以访问诸如配置文件和数据库文件。该工具甚至能够提取已经被删除的数据。

需要注意的是，该报道中展示的这款手机没有采取密码保护。Cellebrite称不可能破解有密码保护的iPhone 4S及之后的iPhone。iPhone 5S及之后的iPhone则更难破解，因为A7芯片内置的Secure Enclave协处理器。

![](../Images/ad6a3ebcdc6a7479a39e11ed5c9ef5ff.png)  
苹果与Cellebrite公司的关系也很有趣。尽管该以色列公司与政 府合作以获取iPhone手机的信息，但苹果本身也是Cellebrite的客户之一，因为苹果在其零售店中就是使用这个工具从iPhone中传输数据。

小伙伴们，记住了吧。一定要将手机设置密码保护，这对保护你的隐私非常重要。
