# 寻找 Linux 中国的真爱粉

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608610&idx=1&sn=ed31af97b1815717419283a46c6de484&chksm=bdce88248ab90132613cc97d9c376142359b6b8abec929aa28513ebd50e7586c37b193f00edc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608610&idx=1&sn=ed31af97b1815717419283a46c6de484&chksm=bdce88248ab90132613cc97d9c376142359b6b8abec929aa28513ebd50e7586c37b193f00edc&scene=27#wechat_redirect)

又是一年将尽时，老王今天突发奇想，想看看“Linux 中国”有多少真爱粉，于是就在我们的几个 QQ 群中发起了 “QQ 群费”：

  

![](../Images/aa55024a92b78cec8e05c9dec8365ff2.png)

  

我并没有说明收群费的目的和用途，但是短短几个小时，居然有 29 位真爱每人交了 **10 元 **的群费。虽然相比庞大的群友数量来说不多，但是这可是真金白银的人民币啊！这其实就是对 Linux 中国乃至于对老王我的无上信任！！

  

不过也有一些真爱表示——从来没有用过 QQ 钱包，强烈要求支持支付宝和微信钱包。支付宝我是没有的——那个东西是老婆大人才有的神器。

  

![](../Images/dc73c10053c1034268671906399d4939.png)

  

这次的真爱粉寻找活动将持续一天，也就是说到明天中午就截止了。  

  

最后，提前祝贺大家节日快乐吧，让我们明年继续相伴，Linux 中国将依然为您打造一个用心的开源技术社区。
