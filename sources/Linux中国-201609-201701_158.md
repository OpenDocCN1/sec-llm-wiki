# 每日安全资讯：Edge浏览器新Bug曝光：SmartScreen界面或被利用来欺诈

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608586&idx=4&sn=8324cd7a5b3f768e8badd6d1adad3d2d&chksm=bdce880c8ab9011a633195cba3c96ff651aa4d7433feacbc497fa8a627acb59de586ec381d8a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608586&idx=4&sn=8324cd7a5b3f768e8badd6d1adad3d2d&chksm=bdce880c8ab9011a633195cba3c96ff651aa4d7433feacbc497fa8a627acb59de586ec381d8a&scene=27#wechat_redirect)

  

尽管微软声称自家 Edge 是“最安全的浏览器”，但新发现的一个缺陷，却让骗子可以借助虚假的 SmartScreen 报错界面来忽悠人。在一份新报告中，阿根廷安全研究人员 Manuel Caballero 提到了他的新发现，欺诈者竟然可以强制 Edge 浏览器显示虚假的 SmartScreen 错误警告，然后提取用户的个人信息。

![](../Images/a50299db0c8cc1a18533ba870768291d.png)

SmartScreen 是一项用于保护 Edge 浏览器用户原理危险站点的功能，正常状态下的它如上所示。

![](../Images/928d95dbaa7e0fe91d3f053d15b9088a.png)

Caballero 披露，如果欺诈者成功地利用了这个 bug，即可显示一条本地警告消息，并替换上一个请求更多信息的链接，欺骗用户去点击（比如指向欺诈者精心设计好的、假冒的微软帮助站点）。

![](../Images/7ec3ff28a0445a7118df743875a416ba.png)

Manuel Caballero 表示：“我们创建了一个可以自动生成的、电话号码样式的链接，受害者可以‘一键呼叫’，这显然给诈骗者省了很多工夫”。

目前微软暂未回应是否已在着手修复 Edge 浏览器中的这个 bug，但愿该公司能尽快推出补丁。
