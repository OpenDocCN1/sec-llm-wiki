# 每日安全资讯：超过50%的上网用户在过去12个月内被黑

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608552&idx=4&sn=175a4cc5b19470316a835b4ad3e2ad3e&chksm=bdce886e8ab90178b1df2d9306d941397c4c5d566d1202059d0085068ec0f7d899322fb06b8d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608552&idx=4&sn=175a4cc5b19470316a835b4ad3e2ad3e&chksm=bdce886e8ab90178b1df2d9306d941397c4c5d566d1202059d0085068ec0f7d899322fb06b8d&scene=27#wechat_redirect)

  

TeleSign在美国进行的一项涉及1300名成年人的研究表明，在过去12个月中，不少于51％的消费者遇到了某种安全事件，包括黑客窃取密码或攻击个人帐户。这项调查显示，不少于31%的消费者认为他们的在线财产价值10万美元甚至更多，甚至是无价。这些价值也是黑客攻击的原因之一。  

研究表明表示，在线财产的价值随着年龄增长而增加。千禧一代在线账户及其相关资产的价值超过10万美元的比例仅为16%，GenXers一代这个比例跳涨到30%，婴儿潮一代这个比例是46%，沉默一代用户的这个比例高达50%。

更令人担心的是，71%的受访者承认在多个网站上使用相同密码，这也增加了帐户被黑风险。 调查显示，千禧一代有九个使用相同密码保护的帐户，所有其他世代合计为六个账户，所有受访者平均为七个账户。

大多数消费者拥有少于5个密码来保护他们的所有帐户，其中一半甚至在过去五年当中都没有更改密码。这次调查也发现了好的一面，使用双因素身份验证的人数在2015年和2016年之间增加了18%，现在有46%的消费者使用双因素身份验证。
