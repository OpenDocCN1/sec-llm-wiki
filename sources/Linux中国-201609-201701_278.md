进入《编程学习手册》之后，请从菜单模式切换到输入模式，然后输入：

  

```
1.  `/function`
    
```

  

**即先输入一个斜线“ `/`”，后面跟上你要查询的函数名称、语法结构等**。例如：

  

```
1.  `/array`
    
```

  

然后会列出包含该关键字的函数、语法等。

  

![](../Images/f56a5a8d5f25f77423a3c92d0c5186e9.png)  

*搜索 array*

  

点击第一个条目可以列出全部结果：  

  

![](../Images/48cb45314618253e91c86c36d850195b.png)  

*搜索 array 的全部结果*

点击其中你要找的函数即可访问具体内容：

  

![](../Images/cdc99f837b00c31a82b79f03aac7cf3b.png)  

*array 资料页*

  

如果你想限定查询某种语言，可以在后面用空格分隔加上语言名称（支持的语言列表如上）：

  

```
1.  `/function lang`
    
```

  

例如：

  

```
1.  `/array swift`
    
```

  

![](../Images/a33134264fadd699f2fe871018f2d3b3.png)  

*搜索 swift 里面的 array *

  

点击第一个条目列出该语言下的全部条目，如果下方列出的几个条目有你所需要的，也可以直接点击。
