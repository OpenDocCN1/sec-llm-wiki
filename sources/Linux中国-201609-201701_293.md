# CloudSort 夺冠，阿里云性价比高出 AWS 保持的世界记录三倍

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608467&idx=1&sn=6fbcfa2de01507cce48c8486221853fd&chksm=bdce89958ab90083758605c682ee78cdc303a0e072c7ae8181421cfe6f143902ac2f918ce68b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608467&idx=1&sn=6fbcfa2de01507cce48c8486221853fd&chksm=bdce89958ab90083758605c682ee78cdc303a0e072c7ae8181421cfe6f143902ac2f918ce68b&scene=27#wechat_redirect)

  

![](../Images/7334a46b0a3747c00f3faed06c3553ef.png)2016 年 11 月 10 日，Sort Benchmark\[1\] 在官方网站公布了 2016 年排序竞赛 CloudSort 项目的最终成绩。阿里云以$1.44/TB 的成绩获得 Indy（专用目的排序）和 Daytona（通用目的排序） 两个子项的世界冠军，打破了 AWS 在 2014 年保持的纪录 4.51$/TB。这意味着阿里云将世界顶级的计算能力，变成普惠科技的云产品。

CloudSort\[2\] 又被称为“云计算效率之争”，这项目赛比拼的是完成 100T 数据排序谁的花费更少，也是 Sortbenchmark 的各项比赛当中最具现实意义的项目之一。 

参与该项竞赛的团队由南京大学、阿里云、Databricks 公司联合组成，团队使用了阿里云官网在售的阿里云 ECS，并按照公开的按量付费价格来比拼性价比。由英特尔处理器、8G 内存、40G 云盘及 135G 规格的 SSD 云盘等日常配置构成的集群，最终实现了每 TB 仅花费 1.44 美元的最好成绩。

![](../Images/6eb482c03c63d221300c8a417ea0ae8a.png "阿里云在 Cloud Sort 上的最新成绩")

*阿里云在 Cloud Sort 上的最新成绩*

此前，CloudSort 项目的纪录保持者为加利福尼亚大学团队，通过 AWS 官网在售的 EC2 来完成，使用了英特尔处理器、122GB 内存，320G 规格的 SSD 存储。在 2014 年该团队的最好成绩是每TB花费4.51美元。 

负责阿里云参赛团队的研究员褚霸表示：“我们早就过了靠堆硬件的阶段，关键是让人人用得起，人人都会用，人人都能用。选择最合理的计算资源和算法，不断对算法进行优化，最大化地提高运行效率。想赢得比赛，你必须从供应链，操作系统，虚拟化，网络，存储到计算能力的每一个方面都处于世界前列。” 

阿里云资深总监李津说：“持续在底层技术上不断升级、释放技术红利，这也是阿里云敢于采取激进降价策略的原因。”       

去年，阿里云参加了以评测计算系统规模和效率为主的 GraySort 和 MinuteSort，并在这两项重量级比赛中打破了全部 4 项世界纪录\[3\]。今年，1.44$/TB 的成绩也打破了 AWS 在 2014 年保持的纪录 4.51$/TB，超越了 Google 官方在 2015 年公布的 1.54$/TB（未被列入大赛成绩）。

提到中国科技企业，过去的标签更多是抄袭、效仿、追随。但随着连续两年参赛，连续两年打破世界纪录，阿里云开始向世界证明，中国计算力量的潜力，中国技术人员正在进行一次又一次的技术探索。
