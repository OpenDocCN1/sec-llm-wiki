# 每日安全资讯：技术支持诈骗者利用谷歌Chrome浏览器两年前的bug行骗

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608450&idx=5&sn=207302ef708ae6094a7a44ef222807e1&chksm=bdce89848ab900926176aed6f5c973f91978fca0709c45ba1739603c532362958f535f5e1ffc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608450&idx=5&sn=207302ef708ae6094a7a44ef222807e1&chksm=bdce89848ab900926176aed6f5c973f91978fca0709c45ba1739603c532362958f535f5e1ffc&scene=27#wechat_redirect)

  

早在2014年7月，Google Chrome浏览器发现了一个错误，允许开发人员将数千甚至数百万个网址推送到浏览器的历史记录中。这个问题可能会导致电脑运行缓慢，因为它会占用电脑上大量资源。 Google已经意识到这个问题，但是决定将其标记为低级拒绝服务攻击，并且此后又推迟了解决方案。

今年，冒充技术支持人员的骗子们决定利用浏览器中这个未解决的bug，并利用它来诱骗人们交出他们钱财和个人信息。如果用户单击“防止此页面创建其他对话框”，将触发浏览器bug，来冻结系统，让被害人的电脑速度慢到爬行，冒充技术支持人员的骗子希望受害者会看到屏幕上闪烁的联系方式，以便销售不必要的产品，以及非法的服务，而偷窃被害人个人信息和财务信息。

解决这个问题唯一方法是访问任务管理器，然后终止Google Chrome浏览器进程。但是，如果电脑速度被卡到很慢，则可能需要让电脑重新启动，才能解决问题。
