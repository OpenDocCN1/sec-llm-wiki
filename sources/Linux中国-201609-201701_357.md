# 彭立勋：MariaDB 基金会的首位中国成员

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608425&idx=1&sn=db6704fb1b8845d461785d21b2f80c26&chksm=bdce89ef8ab900f9baae3cdf563ccd27490bf7f7dbf7bd72b14a6ce168c0a1442f9833c18918&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608425&idx=1&sn=db6704fb1b8845d461785d21b2f80c26&chksm=bdce89ef8ab900f9baae3cdf563ccd27490bf7f7dbf7bd72b14a6ce168c0a1442f9833c18918&scene=27#wechat_redirect)

10 月 19 日，MariaDB 基金会官方网站宣布：

  

> 任命阿里云数据库高级专家彭立勋为 MariaDB 基金会正式成员，负责全球 Replication 模块相关补丁的评审。

  

彭立勋也成为首位被 MariaDB 基金会引入的中国程序员。

  

![](../Images/9afbafacf302750b0e0041cfac9742ad.png)

  

彭立勋目前任职于阿里云计算有限公司，负责 RDS for MySQL 产品中的 MySQL 源码核心开发。业余时间，他还参与了 ACMUG（MySQL 中国用户组）的发起和组建，担任该组织的副主席及杭州地区的组织者。作为 MariaDB 基金会唯一的中国成员，彭立勋也将积极推进 MariaDB 在中国的普及。

  

![](../Images/e0220a7e660c59f733fe3c4b86e816f7.png)*（MariaDB 基金会的六位成员合影，前排中间是彭立勋）*  

  

此次入选，不仅是中国程序员的个人荣誉，更意味着中国公司对开源社区的贡献在国际上获得认可。MariaDB 基金会官网介绍：阿里云在数据库，特别是  MySQL 领域有着丰富的实践经验和解决方案。多年来，阿里巴巴集团内部广泛使用 MySQL 数据库。为回馈开源社区，阿里的程序员一直自发维护 MySQL，累计为 MySQL 社区贡献了近 300 个补丁。

 

MariaDB 是 MySQL 的分支。MySQL 被甲骨文收购后，MySQL 之父 Monty（Michael Wideneus）为保证有一个始终开源的兼容 MySQL 的分支可用，创立了 MariaDB，同时成立了非赢利组织 MariaDB 基金会。该基金会旨在为 MariaDB 项目、用户和开发者社区提供基础的架构支持。同时，交流数据库技术，包括标准的实现，和其他数据库之间的互操作性和和桥梁建设。经过四年运营， MariaDB 基金会已经建立起涵盖评审、合并、测试和发布在内的一整套产品运营机制。

 

阿里巴巴集团一直积极拥抱开源事业，无论是开源软件的应用、回馈以至自研技术的开源都非常活跃，目前维护的热门开源项目多达 115 个。捐赠的开源项目 JStorm 成为 ApacheStorm 里的子项目。RocketMQ 已经被 70 多家公司使用，Tengine 现在是九大最流行的 Web 服务器之一。就在不久之前，还开源了AliSQL、Weex 等重量级软件。

  

![](../Images/36d53a93108624c9d868fcbd97743805.png)  

  

阿里巴巴同时也是 FSF 基金会、Apache 基金会、Linux 基金会的重要成员， Xen 顾问委员会成员。阿里云还是开源组织 WebScaleSQL 的第五位成员。该分支是由 Facebook、 Google、LinkedIn 和 Twitter 四家互联网公司的数据库团队发起的以适应互联网场景为目标的 MySQL 分支。
