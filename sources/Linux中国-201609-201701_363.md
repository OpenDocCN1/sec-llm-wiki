# “让天下没有难用的流程”——H3 BPM10.0 在京盛大发布

上个世纪后期，人们开始关注流程，特别是在企业信息化技术不断发展的过程中，传统管理模式所带来的问题越来越突出。于是人们提出了流程管理的思想。BPM，即全面流程管理，逐渐成为企业管理的一个重要分支，在这一思想体系下企业的一切皆是流程，从最高层的全行业完整的多组织价值链，到中层的各种运营管理，直到底层的操作活动，均被看成是不同层次、不断交互、具有移动特征的流程。企业的竞争力被看成具有差异化优越特征的流程及其管理能力。比如H3 BPM就是因为拥有了具有不断创新能力的价值增值流程，或者说是拥有了以可持续价值增值流程为表现的企业能力载体。

近日，H3 BPM10.0 （H3业务流程管理系统10.0）发布会又在北京金隅喜来登酒店隆重举行。本次发布会以“让天下没有难用的流程”为主题，这是H3 BPM （www.h3bpm.com）在新的市场形势下对自我使命的重新定义，旨在专注于以产品持续提升为目标的自主性创新，致力于推动以流程驱动为核心的管理变革。

出席此次发布会的嘉宾有来自清华大学软件学院的流程管理专家闻立杰教授、全球最大中文IT社区CSDN首席数据分析师左建平、中国卫通集团信息中心主任兼《CIO新思维》系列图书主编李炜、开发者的网上家园博客园副总张昆、中国建设银行党慧芬女士、中国石油天然气集团公司吴顺成先生等近百位顶尖行业专家、优秀企业代表与主流媒体精英，他们共同见证了这场注定将颠覆中国BPM行业的信息盛会。

  

![](../Images/fd3d9b18022c19f90835dcf6cb044668.png)  

  

发布会上，H3 BPM的创始人兼CEO徐平俊先生（花名：书晶）在演讲中借用“流程再造之父”迈克尔·哈默的经典论断——对于21世纪的企业来说，流程将非常关键，优秀的流程将使成功的企业与其他竞争者区分开来——为我们讲述了H3 BPM创立初期的梦想：致力于成为21世纪卓越企业的金钥匙，帮助千千万万的企业提升管理效率，实现产业升级，成为行业的领导者，成功走向世界！

  

![](../Images/bcd6c36b65af0c4c37ac89b93032039f.png)  

  

为此，H3 BPM人专注研发，不断创新，致力于推动整个BPM行业的变革与颠覆。对于企业的流程实施来说，80%的成本源自需求沟通和项目管理。在2010年，H3 BPM的面世带动了整个BPM行业的革新，把BPM从中间件级产品变革为流程快速开发平台，大大降低了“需求沟通成本”，使BPM总体拥有成本从千万级降到了百万级。今天，H3 BPM10.0再次颠覆行业，把BPM从流程快速开发平台变革为运维级产品，让普通的IT管理员甚至业务人员即可轻松驾驭，再一次大幅降低BPM总体拥有成本，从百万级降至十万级，让BPM走下神坛。H3 BPM，让天下企业都用能用上BPM，创造至高的管理价值。

  

![](../Images/61e5035c65a1ef75b89ffd6cfca55a74.png)

  

另外，据了解，此次发布的H3BPM10.0版本采用全新的技术架构，近50人的研发团队，历时18个月，完成近200个业务化封装点及800个易用性优化点的开发，为软件开发者、企业管理者、企业IT人员带来更简洁易用、颠覆行业的BPM产品。  

我在现场实际操作了一下H3 BPM10.0的应用环境，可以说，众多独创技术、比OA更易配置，比EAI更易集成，比普通的BPM产品更具深度扩展与分析的能力，同样，像诸多互联网产品一样简单易用。颠覆行业的老旧传统，H3 BPM已然开启了中国BPM新时代！
