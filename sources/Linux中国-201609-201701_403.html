微软向Windows 系统 增加了14个新 Root CA。微软对此没有公开宣布，也没有在官方的 Microsoft Certificate Program 中列出新增加的受信任 Root CA。微软的这种不透明做法备受安全人员的批评，因为 Root CA 对通信安全至关重要。在14个新 Root CA中，有2个来自台湾的ePKI Root Certification Authority——台湾中华电信的CA。
