# 每日安全资讯： 微软悄悄增加14个新 Root CA

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608374&idx=3&sn=fddeb52599309c8e4329b1012d3c5053&chksm=bdce89308ab90026f8e006e9c16d05cf84091af76a51aa6eb44f6da0578ea83ce0e23e8e4d83&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608374&idx=3&sn=fddeb52599309c8e4329b1012d3c5053&chksm=bdce89308ab90026f8e006e9c16d05cf84091af76a51aa6eb44f6da0578ea83ce0e23e8e4d83&scene=27#wechat_redirect)

微软向Windows 系统 增加了14个新 Root CA。微软对此没有公开宣布，也没有在官方的 Microsoft Certificate Program 中列出新增加的受信任 Root CA。微软的这种不透明做法备受安全人员的批评，因为 Root CA 对通信安全至关重要。在14个新 Root CA中，有2个来自台湾的ePKI Root Certification Authority——台湾中华电信的CA。
