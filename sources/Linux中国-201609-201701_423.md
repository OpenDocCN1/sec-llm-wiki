# 每日安全资讯：斯诺登律师：前情报人员斯诺登的追随者会越来越多

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608343&idx=4&sn=113e3bb33dcdb2c9a830227ebe26ef42&chksm=bdce89118ab900074dedc0bdda5b260d8855a4fd06578fe05b8f54f669b8734070f3d8da9c50&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608343&idx=4&sn=113e3bb33dcdb2c9a830227ebe26ef42&chksm=bdce89118ab900074dedc0bdda5b260d8855a4fd06578fe05b8f54f669b8734070f3d8da9c50&scene=27#wechat_redirect)

据俄罗斯卫星网7日报道，美国前情报人员斯诺登在俄罗斯的律师阿纳托利·库切连纳认为，公开美国情报部门工作方式的斯诺登追随者将变得越来越多，因为人们不会对私人生活被侵犯无动于衷。此前有消息称，美国联邦调查局以涉嫌窃取用于入侵外国政府网络系统的程序代码为由逮捕了一名国家安全局的雇员。这名被捕者与斯诺登一样，属于博思艾伦公司（Booz Allen Hamilton）。

  

消息指出，被窃程序代码是由情报部门编写，用于侵入美国的主要对手国的电脑网络系统。美国检察院已经向51岁的哈罗德·托马斯·马丁提出指控。《华盛顿邮报》称，马丁将面临最高11年的监禁。

  

库切连纳表示：“斯诺登有很多支持者，他们都不会对美国情报部门的行为无动于衷，我们看到，追随者们越来越多，因为谁也不会忍受谎言。像斯诺登和马丁这些人，是为社会利益行动，是为美国和其它国家公民的自由和权利行动。”
