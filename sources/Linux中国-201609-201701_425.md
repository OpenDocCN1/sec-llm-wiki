# 每日安全资讯：部分地区出现新骗局：扫二维码缴违章停车罚款

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608336&idx=4&sn=5d57ea381ac922c64aa18b679a5f1c91&chksm=bdce89168ab90000a3b0b760c072c536852aa35ec902fe4a5932fec02dbdff6750982015eedd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608336&idx=4&sn=5d57ea381ac922c64aa18b679a5f1c91&chksm=bdce89168ab90000a3b0b760c072c536852aa35ec902fe4a5932fec02dbdff6750982015eedd&scene=27#wechat_redirect)

据中国之声《新闻晚高峰》报道，近日，部分地区出现了一种针对车主的新骗局。车主发现自己的车上被贴了罚单，上面还印有二维码快速缴费通道，而一旦车主扫码缴费，就落入了骗子的圈套之中。日前，多地反诈骗中心发布紧急通知，提醒车主防范一种专门针对司机的新型骗局。据介绍，近日部分地区出现了一种针对车主的新骗局，车主发现自己的车上被贴了“罚单”。在这张电子打印的罚单上面还有二维码快速缴费通道。扫描之后，会进入支付转账页面，然后引导车主转账缴纳“违章罚款”。

对此，反诈骗中心提醒，全国任何地区目前都没有在罚单上扫描二维码直接缴纳违章罚款的。因此，广大车主不要通过二维码支付任何“违章”费用！

警方表示，该案的诈骗手法较为罕见，利用扫码付款这一互联网支付手段结合伪造交警文书这一方式，比起传统诈骗有较强的迷惑性，群众容易上当受骗，社会危害相当大。

警方提醒，车辆如果因违停被交警部门拍照处罚，现场开具的应是《XX市公安局交通警察支队XX大队违法停车告知单》，而不是一张让人不知就里的“违章停车单”。其次，交警部门开具的违法停车告知单中会详细记录以下内容：一是发证机关、违法车牌号码、种类及车辆类型；二是违法时间、地点、违法行为、罚款金额以及处理地点等内容；三是处罚地址、执勤单位、执勤民警及单位盖章。市民要时刻保持警惕，避免上当受骗。
