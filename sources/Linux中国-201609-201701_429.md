# 每日安全资讯：阿桑奇宣布将在维基解密10周年之际对谷歌和美国大选进行泄密

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608329&idx=3&sn=a7efacc139b47a13143e5b81a610b7f5&chksm=bdce890f8ab900191b15fa3a2dfff005b968a3f0395de395d23eb1bb1cbf5eb60f5a14c41616&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608329&idx=3&sn=a7efacc139b47a13143e5b81a610b7f5&chksm=bdce890f8ab900191b15fa3a2dfff005b968a3f0395de395d23eb1bb1cbf5eb60f5a14c41616&scene=27#wechat_redirect)

  

维基解密网站10年前开始对外公布各种重大文件泄密，近期更宣布将对谷歌和美国大选内幕进行泄密。在10周年庆媒体发布会开始时，一则视频展示了维基解密网站上的10大泄密事件。10年内，维基解密共对外泄露了1000万份文件。维基解密创始人阿桑奇宣布，在接下来的10周将每周发布新的有关谷歌、军事行动、武器交易和大众监督方面的泄密内容。他还称将在11月8日大选前对美国总统选举进行泄密。

阿桑奇否认此举是为了攻击美国民主党总统候选人希拉里，并称“我为希拉里和特朗普感到遗憾，他们都被自己的野心所折磨。”

维基解密于2006年10月4日正式注册域名，12月28日发布第一份泄密文件，“十年过去了，但我们对世界主要领导人的了解却越来越少。”10大泄密事件短片里说道，“我们所知道的是他们想让我们知道的。”

阿桑奇未能亲自到达此次10周年庆现场，他自2012起便居住在伦敦的厄瓜多尔大使馆。但他通过一个视频告诉记者：“维基解密将建立一支队伍抵御外界的各种压力。”
