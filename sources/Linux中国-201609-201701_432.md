# 每日安全资讯：法国银行推出新型“动态密码”支付卡

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608324&idx=2&sn=65e3619232897d4433f649d6258c0390&chksm=bdce89028ab90014f6ba31945cbcd09170115a5faf99efbda3e9e9213b5105b7bef87e93d756&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608324&idx=2&sn=65e3619232897d4433f649d6258c0390&chksm=bdce89028ab90014f6ba31945cbcd09170115a5faf99efbda3e9e9213b5105b7bef87e93d756&scene=27#wechat_redirect)

  

每天几乎都有信用卡信息被盗的新闻报道出现。 为保护银行客户的信息安全，日前法国两家银行宣布，他们将推出一种称为 “动态密码（Motion Code）”的支付卡。 这些新型的卡片能够利用每小时自动变更一次随机码的微型显示屏来取代印刷在信用卡背面的静态印刷信用卡卡号。

![](../Images/1d92f27e8e0aa57c9eef17eb256f64b3.png)  

一旦卡片被盗，信用卡上的后三位数字就会迅速失效，从而防止信用卡被盗刷。 持卡人无需在其Web浏览器上安装插件，卡内规定的算法和刷新规则也将与特定服务器保持同步。

目前Google Pay、Apple Pay等数字钱包的出现进一步为用户提供了额外的安全性。
