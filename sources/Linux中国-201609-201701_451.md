# Linaro 作为白金会员加盟 Zephyr 项目

> 社区正在为物联网开发一个安全的开源的实时操作系统

为物联网构建实时操作系统的开源协作项目 Zephyr 项目\[1\]宣布，Linaro 有限责任公司以白金会员的身份加盟该项目。Linaro是一家为 ARM 架构开发开源软件的协作工程组织，也是全球性机构，其 35 个成员中不乏来自多个行业部门的龙头企业。

![](../Images/85674986bebaf18ee81e8663a5db6487.png)

Linaro 加入了由英特尔公司（包括其收购的企业集团阿尔特拉公司和风河系统公司）、恩智浦半导体公司（包括其最近与飞思卡尔合并的组织）以及美国新思科技公司等创始成员发起的 Zephyr 项目\[2\]。

作为白金会员，Linaro 将助力提升 Zephyr 的规格和项目计划，并为推动 Zephyr 项目成为物联网首要的多架构开源实时操作系统的目标做出贡献。Linaro 的参与特别有助于保证为该项目提供优质的 ARM 架构支持。

  “自公司成立以来，我们与 Linux 基金会就 Linaro 及其成员都很感兴趣的多个项目开展了密切合作。这些项目主要集中在基于ARM Cortex-A 的系统方面。”Linaro 公司的首席执行官乔治.格雷George Grey表示，“加盟 Zephyr 项目表明，对于减少微程序控制器操作系统的碎片化并帮助基于 ARM Cortex-M 的微程序控制器进入物联网和嵌入空间，Linaro 颇感兴趣。我们将 Zephyr 视为一项统一工程和一种结构中立的实时操作系统。Linaro 将会以 Zephyr 作为适用物联网和嵌入式市场的技术开发和测试的基础。”

 “物联网有望实现嵌入式技术的多层连通，”Linux 基金会的执行董事吉姆.策姆林Jim Zemlin说，“Linaro 不仅是嵌入式设备的全球领导者，而且对开源的能力认识深刻。看到 Linaro 与 Zephyr 项目其他成员的协作会如何影响物联网，我感到非常激动。”

**关于Zephyr™项目**

Zephyr 项目是一款小型可扩展的实时操作系统，在资源受限的系统上使用，可支持多种架构。要了解更多相关信息，请访问 www.zephyrproject.org\[3\]。

Zephyr 项目由 Linux 基金会\[4\]负责。该基金会被世界上顶尖开发商和公司选择构建可加速开放性技术开发和商业应用的生态系统。了解更多信息，可登录 www.linuxfoundation.org\[5\]。

**关于 Linaro**

Linaro\[6\] 是从事 ARM 生态系统中开源开发的领先合作组织。拥有 200 多名工程师，从事 ARM 架构的开源软件的巩固和优化工作。公司开发了开发者工具、Linux 内核、ARM 电源管理以及其他软件架构。Linaro 作为一个发行机构，希望通过开发上游软件为每个人提供最佳的软件基础，并减少无区别和昂贵的低水平碎片化现象。这种方法的有效性已从其日益增加的会员以及 Linaro\[7\] 一直名列对 Linux 内核 3.10 之后的版本贡献最大的全球前五家公司之一得到证明。

Linaro\[8\] 的全部工程工作向所有在线人员开放。欲知更多信息，请访问 http://www.linaro.org。
