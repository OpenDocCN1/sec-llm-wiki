# 在 Kali Linux 环境下设置蜜罐

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608228&idx=4&sn=b72dac3c5062b91a3451cd6c492c4848&chksm=bdce8aa28ab903b44ed147ab8246395d2bd294cd263a514963b8ab0d478ff1a3289cd31cd161&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608228&idx=4&sn=b72dac3c5062b91a3451cd6c492c4848&chksm=bdce8aa28ab903b44ed147ab8246395d2bd294cd263a514963b8ab0d478ff1a3289cd31cd161&scene=27#wechat_redirect)

Pentbox 是一个包含了许多可以使渗透测试工作变得简单流程化的工具的安全套件。它是用 Ruby 编写并且面向 GNU / Linux，同时也支持 Windows、MacOS 和其它任何安装有 Ruby 的系统。在这篇短文中我们将讲解如何在 Kali Linux 环境下设置蜜罐。如果你还不知道什么是蜜罐honeypot，“蜜罐是一种计算机安全机制，其设置用来发现、转移、或者以某种方式，抵消对信息系统的非授权尝试。”

![](../Images/9295772aa4b85677c13eb26aa12b211b.png)

下载 Pentbox：

在你的终端中简单的键入下面的命令来下载 pentbox-1.8。

```
1.  `root@kali:~# wget http://downloads.sourceforge.net/project/pentbox18realised/pentbox-1.8.tar.gz`
    
```

![](../Images/caa131fd84a77ec5f56b3eb34d7913f3.png)

解压 pentbox 文件

使用如下命令解压文件：

```
1.  `root@kali:~# tar -zxvf pentbox-1.8.tar.gz`
    
```

![](../Images/f6ab9eacb0c95fb3bc012decb134fc8e.png)

运行 pentbox 的 ruby 脚本

改变目录到 pentbox 文件夹：

```
1.  `root@kali:~# cd pentbox-1.8/`
    
```

![](../Images/8e19ac4030296a59b7cf1b4c5fca8659.png)

使用下面的命令来运行 pentbox：

```
1.  `root@kali:~# ./pentbox.rb`
    
```

![](../Images/1286d3de7e396593e5d1cd82134a519a.png)

设置一个蜜罐

使用选项 2 (Network Tools) 然后是其中的选项 3 (Honeypot)。

![](../Images/f6945c3299bb200755f3c247b6fb6cea.png)

完成让我们执行首次测试，选择其中的选项 1 (Fast Auto Configuration)

![](../Images/77b29fdef3960fb3c6d0ec1019d2c7ed.png)

这样就在 80 端口上开启了一个蜜罐。打开浏览器并且打开链接 http://192.168.160.128 （这里的 192.168.160.128 是你自己的 IP 地址。）你应该会看到一个 Access denied 的报错。

![](../Images/3d2f6df6f5bbd6cca9ae96010151b22a.png)

并且在你的终端应该会看到 “HONEYPOT ACTIVATED ON PORT 80” 和跟着的 “INTRUSION ATTEMPT DETECTED”。

![](../Images/a79f4e8240d97313541e94c48917c43d.png)

现在，如果你在同一步选择了选项 2 (Manual Configuration), 你应该看见更多的其它选项：

![](../Images/eb166d5b1456d9b26ac3da96d4858e93.png)

执行相同的步骤但是这次选择 22 端口 (SSH 端口)。接着在你家里的路由器上做一个端口转发，将外部的 22 端口转发到这台机器的 22 端口上。或者，把这个蜜罐设置在你的云端服务器的一个 VPS 上。

你将会被有如此多的机器在持续不断地扫描着 SSH 端口而震惊。 你知道你接着应该干什么么？ 你应该黑回它们去！桀桀桀！
