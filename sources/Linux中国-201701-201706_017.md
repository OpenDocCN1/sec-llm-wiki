# 【每日安全资讯】Linux曝出Samba安全漏洞 类似永恒之蓝

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609032&idx=4&sn=7786bc9c43da00f4b9b31d1857d4dc01&chksm=bdce8e4e8ab907582f3ed2a49dda124879afa1cf33a878d922ab387401cbdeed651c971da92f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609032&idx=4&sn=7786bc9c43da00f4b9b31d1857d4dc01&chksm=bdce8e4e8ab907582f3ed2a49dda124879afa1cf33a878d922ab387401cbdeed651c971da92f&scene=27#wechat_redirect)

27日消息：之前“永恒之蓝”让全世界的Windows系统都如临大敌，这让Linux和macOS的用户开始嘲笑Windows的安全性，然而苍天饶过谁，现在Linux也面临着新的安全危机。

据悉，安全公司在昨日紧急发布了Samba远程代码执行漏洞警报。Samba是被广泛应用在各种Linux和Unix系统上的开源共享服务软件，类似于Windows上的SMB服务。

![](../Images/f5579c81890ef3bb6e09ce66f34e9e2b.png)

和“永恒之蓝”利用SMB漏洞蠕虫式传播一样，Samba漏洞也将威胁Linux服务器、NAS网络存储产品以及路由器等IoT设备。

同时，由于Samba的逻辑漏洞更简单稳定，攻击工具也在网上公开，所以被黑客利用发起远程攻击的几率非常大。

安全公司建议使用源码安装的Samba用户，尽快下载最新版的Samba并手动更新，而使用二进制分发包的用户，则需要进行yum、apt-get update等安全更新操作。
