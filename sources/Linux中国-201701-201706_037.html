5 月 23 日，在云栖大会 · 成都峰会上，CNCF[1] 宣布阿里云正式成为金牌会员。阿里云表示将持续加大对云原生计算技术的支持，在推动云计算开放性和标准化方面发挥自己的力量。 

同时，阿里云容器服务宣布支持 Kubernetes 和 Docker 最新的 Swarm mode。这样，阿里云也成为中国唯一一家同时支持这两个最流行容器调度系统的中国云计算公司。阿里云产品总监汤子楠表示：“阿里云始终秉承对技术生态的全面支持，云端Kubernetes 的解决方案将给开发者多样化的选择。”

“非常激动，阿里云能成为金牌成员”，CNCF 执行董事 Dan Kohn 表示，“我们期待中国云计算工程师更多参与到国际云计算标准的制定中。”

CNCF[2]（英文全称：Cloud Native Computing Foundation）是 Linux 基金会[3]旗下专注于下一代云计算方案的子基金会。2015 年成立以来，一直致力于统一云计算的接口和相关标准，维护和集成开源技术，并支持编排容器化微服务架构应用。成员包括 Twitter、Docker、Google、Intel、Red Hat、IBM、SUSE 、思科等国际知名科技公司。目前，旗下核心项目有容器集群管理系统 Kubernetes , 容器管理系统 containerd , 微服务基础技术 gRPC/CoreDNS/Linkerd 等。

基金会成立以来，阿里云就密切关注并为 CNCF 旗下项目社区贡献代码。去年 Docker 宣布将 Docker Engine 核心组件containerd 开源，并捐赠到 CNCF，阿里云就参与到第一批的支持和建设者之中。阿里云首席架构师唐洪表示，“参与 CNCF，一方面是认同基金会所推动的云原生计算方向，另一方面也希望在基金会中更多地发挥中国科技企业的力量。” 阿里云有计划将基金会旗下相关项目集成到自身产品中，将云计算环境与开源社区紧密联系在一起，为全球开发者提供优质的技术服务。

阿里云作为社区与用户之前的平台桥梁，期望用户能够更快的将新技术应用到企业的新一代架构中，同时完成与云端平滑迁移、弹性的架构规划；2015 年，阿里云就在 Docker 社区版的基础上推出了阿里云容器服务。华大基因、上海证券交易所、中信集团、ofo 小黄车、深圳码隆科技等多家企业均是容器服务的客户。

去年 10 月，Docker 与阿里云达成合作[4]，协助 Docker 云服务落地中国，共同在企业市场推广容器技术。今年 4 月，阿里云发布了国内首款支持 Docker 企业版的产品 - 飞天专有云敏捷版[5]。
