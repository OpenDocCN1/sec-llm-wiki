# 【每日安全资讯】拥有5.6亿个密码的数据库遭到泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609012&idx=4&sn=fc9a9ae2e575bed10ff30121adce04fa&chksm=bdce8fb28ab906a4ce5197afcf7d0063631ac49a20b9bbd26b8bcbc2c2a8e2e9f6bf1979f220&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609012&idx=4&sn=fc9a9ae2e575bed10ff30121adce04fa&chksm=bdce8fb28ab906a4ce5197afcf7d0063631ac49a20b9bbd26b8bcbc2c2a8e2e9f6bf1979f220&scene=27#wechat_redirect)

据外媒报道，日前正在全球范围肆虐的WannaCry病毒又被曝出攻击并泄露了拥有5.6亿个密码的数据库。另外，该平台还被发现含有2.43多亿封邮件，它们几乎每一封都在其他网络攻击中出现过。按照安全研究中心MacKeeper的说法是，这很有可能是另外一个包含了来自多个源头--涵盖此前的数据攻击--的大型数据库。

![](../Images/44521957e92f7f8040dd0eba235a452e.png)

虽然数据被流传到网上已经不是什么新鲜事儿，但把它们放到一起、能让任何对其持有好奇心的人查阅却令人担忧。

![](../Images/811f7b03f193cd27e8528909169a3317.png)

MacKeeper指出，在他们研究过程中他们发现了313个分布在美国、加拿大、澳大利亚的大型数据库，由于这些数据库使用的都是云IP，所以目前无法确认其真正的持有人究竟是谁。对此，该机构向主机服务供应商发送了通知邮件，不过很显然这通常不是关闭数据库的最快办法。

据了解，这次发现泄露的数据库大小超过了75GB，当中包含的数据则都使用了可读的json格式，另外它还包含了至少不下10个先前已经曝光的数据库的数据，如LinkedIn、Dropbox、MySpace、Neopets、RiverCityMedia、Tumblr、MySPace、Lastfm等。
