# 极客漫画：精通正则表达式

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609006&idx=2&sn=f3364a3e3d89663bf00059dd4ab247c7&chksm=bdce8fa88ab906be2612164f94e10596c82601a5eae031a70da2667d6d00fbbb91fd6fcb0024&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609006&idx=2&sn=f3364a3e3d89663bf00059dd4ab247c7&chksm=bdce8fa88ab906be2612164f94e10596c82601a5eae031a70da2667d6d00fbbb91fd6fcb0024&scene=27#wechat_redirect)

![](../Images/22ad3f0060a3994647a28eba65f0a1c9.png)

一个人希望掌握所有的正则表达式，却耗费了大量的时间，不知室外世事变迁，早已换了一个时代。

这个漫画讽刺了一些初学者，希望掌握一些比较复杂的东西的所有内容后再去做事，却不知道，这些东西过于复杂，你花费的时间可能很快就一文不值，因为它们可能已经过时了。

开发并不要求你掌握所有的内容，更多的时候，你只要能够掌握一些常用的，在真正需要用到的时候，再去查询一些比较详细的、不常用的内容即可。毕竟，没有人要求你马上做完所有事情。
