# 【每日安全资讯】智能电表存安全隐患 黑客可监控你家用电情况

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608965&idx=4&sn=87a6333756cb200ba375c17f41879cfd&chksm=bdce8f838ab90695ee5f986d014bd55d94a0a2dafb9af5ad7d6f48f28f9fd2517d06dcffc5e6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608965&idx=4&sn=87a6333756cb200ba375c17f41879cfd&chksm=bdce8f838ab90695ee5f986d014bd55d94a0a2dafb9af5ad7d6f48f28f9fd2517d06dcffc5e6&scene=27#wechat_redirect)

如果你使用智能电表来监控你的用电情况，那么这也同时为黑客入侵预留了一个通道。根据堪培拉大学网络安全中心的Nigel Phair发表的论文（PDF），黑客完全能够入侵你家的智能电表，监控你家的用电情况已经确认你家多长时间处于闲置状态。

Phair向ABC透露：“大部分电表在生产制造过程中并没有妥善的考虑安全问题，因此缺乏足够的密码保护以及固件更新机制，从而确保智能电表处于最新稳定状态。”

水表和天然气表的数据传输通常是单向的，这就意味着只能向提供商发送数据，不过大部分的电表都是双向通讯的，因此成为了黑客攻击的目标。在波多黎各，已经有黑客攻击利用了这些智能电表，对收费进行重新编程，能够节省75%的电费。
