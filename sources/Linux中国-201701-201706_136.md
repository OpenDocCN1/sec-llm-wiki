# 如何在现有的 Linux 系统上添加新的磁盘

作为一个系统管理员，我们会有这样的一些需求：作为升级服务器容量的一部分，或者有时出现磁盘故障时更换磁盘，我们需要将新的硬盘配置到现有服务器。

在这篇文章中，我会向你逐步介绍添加新硬盘到现有 RHEL/CentOS 或者 Debian/Ubuntu Linux 系统的步骤。

推荐阅读： 如何将超过 2TB 的新硬盘添加到现有 Linux\[1\]。

重要：请注意这篇文章的目的只是告诉你如何创建新的分区，而不包括分区扩展或者其它选项。

我使用 fdisk 工具\[2\] 完成这些配置。

我已经添加了一块 20GB 容量的硬盘，挂载到了 `/data` 分区。

`fdisk` 是一个在 Linux 系统上用于显示和管理硬盘和分区命令行工具。

```
1.  `# fdisk -l`
    
```

这个命令会列出当前分区和配置。

![](../Images/71aaf33bc9186c3479b0846d49caf459.png "查看 Linux 分区详情")

*查看 Linux 分区详情*

添加了 20GB 容量的硬盘后，`fdisk -l` 的输出像下面这样。

```
1.  `# fdisk -l`
    
```

![](../Images/7e684fe1f56f29754dc3c40138a4706b.png "查看新分区详情")

*查看新分区详情*

新添加的磁盘显示为 `/dev/xvdc`。如果我们添加的是物理磁盘，基于磁盘类型它会显示为类似 `/dev/sda`。这里我使用的是虚拟磁盘。

要在特定硬盘上分区，例如 `/dev/xvdc`。

```
1.  `# fdisk /dev/xvdc`
    
```

常用的 fdisk 命令。

*   `n` - 创建分区
    
*   `p` - 打印分区表
    
*   `d` - 删除一个分区
    
*   `q` - 不保存更改退出
    
*   `w` - 保存更改并退出
    

这里既然我们是要创建一个分区，就用 `n` 选项。

![](../Images/07ec49b4def53fb2e6f09e2847ac4dde.png "在 Linux 上创建新分区")

*在 Linux 上创建新分区*

创建主分区或者扩展分区。默认情况下我们最多可以有 4 个主分区。

![](../Images/460b52c481aceb25fb94dd8add805e9b.png "创建主分区")

*创建主分区*

按需求输入分区编号。推荐使用默认的值 `1`。

![](../Images/653e4ec6a4f644f5b2d2ec643707dae3.png "分配分区编号")

*分配分区编号*

输入第一个扇区的大小。如果是一个新的磁盘，通常选择默认值。如果你是在同一个磁盘上创建第二个分区，我们需要在前一个分区的最后一个扇区的基础上加 `1`。

![](../Images/68a960806c3566b1895d46682f3e0d8d.png "为分区分配扇区")

*为分区分配扇区*

输入最后一个扇区或者分区大小的值。通常推荐输入分区的大小。总是添加前缀 `+`以防止值超出范围错误。

![](../Images/905c02d4094d0be3a1d6138abdcea616.png "分配分区大小")

*分配分区大小*

保存更改并退出。

![](../Images/8b2fcdece49458b40c6c090c1e5c1d00.png "保存分区更改")

*保存分区更改*

现在使用 mkfs 命令格式化磁盘。

```
1.  `# mkfs.ext4 /dev/xvdc1`
    
```

![](../Images/8249278bbeba7ce1c4686a98cafcd535.png "格式化新分区")

*格式化新分区*

格式化完成后，按照下面的命令挂载分区。

```
1.  `# mount /dev/xvdc1 /data`
    
```

在 `/etc/fstab` 文件中添加条目以便永久启动时自动挂载。

```
1.  `/dev/xvdc1  /data   ext4    defaults     0   0`
    
```

总结

现在你知道如何使用 fdisk 命令\[3\] 在新磁盘上创建分区并挂载了。

当处理分区、尤其是编辑已配置磁盘的时候，我们需要格外的小心。请分享你的反馈和建议吧。
