# 【每日安全资讯】有缺陷的在线教程导致了上规模的软件漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608954&idx=5&sn=7f13fe48c764f2c44e5646d72ccffd08&chksm=bdce8ffc8ab906ea47a7ee643cf227a7378fd0e1e3e4c3c96fe5421ca37e852281d4d4481f9e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608954&idx=5&sn=7f13fe48c764f2c44e5646d72ccffd08&chksm=bdce8ffc8ab906ea47a7ee643cf227a7378fd0e1e3e4c3c96fe5421ca37e852281d4d4481f9e&scene=27#wechat_redirect)

在线教程中的示例代码经常会被人直接拷贝到程序中，然而问题是并非所有的在线教程示例代码经过了充分的安全评估。德国的研究人员检查了 GitHub 上 6.4 万多个项目的 PHP 代码，发现了 117 个与有缺陷的在线教程相关的漏洞。

研究人员随后在 Google 上搜索“mysql tutorial”，“php search form”、 “javascript echo user input”等关键词后分析和评估了前五个搜索结果的教程示例代码，发现有 9 个教程含有 SQLi 和 XSS 漏洞。他们的研究报告（PDF）发表在预印本网站上。
