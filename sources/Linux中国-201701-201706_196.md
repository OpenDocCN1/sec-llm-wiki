# 【每日安全资讯】男子自学网络技术成黑客 融资平台充值1元提现5万

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608911&idx=5&sn=e8613f9f3ec0c6785a575588f6ae443c&chksm=bdce8fc98ab906df3949ebed078ec7be720040be344c5a3be9eca8b23d9046284a1cb07b9498&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608911&idx=5&sn=e8613f9f3ec0c6785a575588f6ae443c&chksm=bdce8fc98ab906df3949ebed078ec7be720040be344c5a3be9eca8b23d9046284a1cb07b9498&scene=27#wechat_redirect)

13日，记者从浙江省湖州市德清县人民法院获悉，去年，湖北男子王某利用自学技术、通过某软件对浙江某公司融资平台数据进行修改，充值1元后成功提现5万元，事发后王某向公安机关投案自首。最终法院判处王某有期徒刑三年，缓刑四年。

今年32岁的王某在湖北从事网络工作，由于对编程十分感兴趣，王某便利用该软件对网上的数据进行抓包。看到别人在数据包里写的代码，王某也会进行学习，遇到可修改的数据就会马上去尝试。

去年底，王某在网上意外发现浙江德清某公司旗下的融资平台有漏洞，即可以用该软件对计算机发送的数据进行修改。出于好奇，王某就在该平台进行了实名认证注册，并且绑定了自己的银行卡账号。

之后，王某就往平台里充值了1元钱，并用该软件将这1元钱的数据修改为5万元。之后王某立刻申请了提现，十多分钟后，平台就把5万元钱转到其银行卡上。

提现成功之后王某惴惴不安，次日下午，他决定把这笔钱给网站打回去。由于其注册银行卡账户已被公安机关冻结，王某只好换另一张银行卡把5万元充回。事后，王某向公安机关投案自首。
