# 【每日安全资讯】Firefox将增加一个设置区让用户控制内存使用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608901&idx=4&sn=30f2ac5059b479d9b7fd30dfdac60bb0&chksm=bdce8fc38ab906d5372745d7ba50e19a39a33e3a832424e9cc8d064b7cc54bfe93b0370e8cf0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608901&idx=4&sn=30f2ac5059b479d9b7fd30dfdac60bb0&chksm=bdce8fc38ab906d5372745d7ba50e19a39a33e3a832424e9cc8d064b7cc54bfe93b0370e8cf0&scene=27#wechat_redirect)

根据开发者上周五发表在 Bugzilla 上的一个帖子，Mozilla 将在 Firefox 中将增加一个性能设置区让用户控制内存使用。Mozilla 过去几年一直在模仿 Chrome，在简化的名义下剥夺了用户的许多选择，但市场份额并没有随之增加。现在，它看起来要回到过去，将更多选择权交给用户。

![](../Images/a7780fd5749e2b1763fa3bc69442cb8c.png)

开发者正在开发实现控制设置所需要的代码。根据他们的计划，用户将可以控制 UI 动画，网页预加载，内容进程数，等等。
