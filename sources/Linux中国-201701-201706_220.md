> *说实话，作为一个已经运作了 1500 天的微信公众号，发这样的一篇消息是挺尴尬的，但是……*

  

> 各位亲爱的读者们，由于我们被微信官方单方面取消了自定义菜单 API 权限，所以没办法向大家提供功能丰富的菜单了。我看到一些朋友对此感到懵圈，甚至还在交互信息中输入“菜单”来试图找回蒸发的菜单，我看了心里真是感觉百味杂陈，我不哭！
> 
>   
> 
> 还好，我们是打不倒的，在最初的时候，我们就设计了完整的输入交互系统。大家可以输入下述关键字来获取一样的功能。

  

❖ **分类栏目**　 ：直接输入“技术”、“开发”、“运维”、“新闻”、“访谈”、“分享”等关键字来显示网站上的分类精选文章；也可以输入“实时”来获取最新文章；

❖ **推送热点**　 ：输入“推荐”可获取最近访问量最高的微信推送文章；

❖ **推送直达**　 ：输入微信推送的文章的唯一 ID，或长按推荐文章图片上的二维码，可以直达该文章；  

❖ **网站注册**　 ：输入“邀请码”获得 Linux 中国网站（https://linux.cn/）的注册骑士码；

❖ **Linux 命令** ：直接输入Linux命令，可以查询命令帮助；  

❖ **关键字检索** ：试试输入你要搜索的关键字，我们会从网站和微信推送内容中搜索相关内容；

❖ **对话和询问** ：以“#”开头输入你要说的话，比如反馈、咨询、商务询价等，运营人员会尽量回复您。

  

最重要的，您随时可以输入一个大大的“?”来获取帮助，我们有什么新的功能都会通过帮助信息来告诉您！
