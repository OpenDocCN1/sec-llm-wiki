从代码贡献排行榜中可以发现，以 OpenStack 平台为业界所熟悉的 EasyStack（北京易捷思达科技发展有限公司）开始集中发力容器领域，而且选择了 Kubernetes 容器编排技术。

Linux 中国社区获悉，柏林 3 月 29 日 11 点，北京 3 月 29 日 17 点，EasyStack 在德国柏林举行的CloudNativeCon+KubeCon 容器大会上，正式发布了基于 Kubernetes 技术的容器集群产品 ESContainer。此举也使得 EasyStack 同红帽、Mirantis 一道成为全球三大同时具备 OpenStack 和 Kubernetes 产品的专业开源企业，也是中国首个 OpenStack + Kubernetes 专业开源企业。

德国柏林 CloudNativeCon + KubeCon 容器大会正在进行中

众所周知，2016 年是容器技术全面爆发增长的一年。全球两大容器开放标准组织——CNCF 基金会Cloud Native Computing Foundation和 OCI 开放容器项目联盟Open Container Initiative也都得到了长足的发展。就两大组织官方资料来看，EasyStack 从 2016 年就开始投入 Kubernetes 技术，并已相继加入了 CNCF 和 OCI 两大联盟。

“2017 年将是中国企业的容器实践元年。”EasyStack 联合创始人兼 CTO 刘国辉判断，“容器由于轻量化、快速、可移植的特色颠覆了 PaaS，成为部署云原生应用至关重要的技术。而容器的能力能否得到全面体现，取决于是否有一个强大的容器集群管理平台，目前大多数企业级的容器应用都部署在 OpenStack 之上，而 Openstack + kubernetes 将能更好地满足企业的开源云计算需求。”

一、Kubernetes 1.6 版本发布

2016 年是 Swarm、Mesos、Kubernetes 三大容器编排技术全面发力的一年。

其中，源于 Google 的 Kubernetes 由于最初充分利用了谷歌多年的架构和运维经验，自 2014 年开源以来，就吸引了一大批追随者和代码贡献者。2015 年，Google 联合 20 家企业共同成立了开源组织 CNCF 基金会，并同时发布了首个被编入 CNCF体系的开源版本—— Kubernetes 1.0。如今，Kubernetes 不仅仅是由谷歌背书的项目，更是收获了诸如微软、IBM、英特尔等一批 IT 巨头的拥趸，成为全球容器领域规模最大的聚合生态平台和最受瞩目的容器技术。

就在 3 月 28 日，Kubernetes 1.6 版本正式发布。新版本核心聚焦规模和自动化，最多可以支持 5000 个节点的集群，且动态存储供应特征进入稳定状态，RBAC、kubefed、kubeadm 和部分调度特性进入 beta 状态。

据 GitHub 跟踪统计，Kubernetes 代码贡献数量超过 Mesos 三倍以上；另一方面，在 GitHub Star 的热度对比图中， Kubernetes 也远超 Swarm。

二、OpenStack + Kubernetes 实现 1+1>2？

EasyStack 认为 OpenStack + Kubernetes 最大的特色是可以让 Kubernetes 与 OpenStack 深度融合，带来 1+1>2 的能力：ESCloud 专注于数据中心基础设施的管理和支撑传统应用业务的运行，ESContainer 专注于为企业新型应用的改造提供一站式平台，两者结合优势互补，成为新型的异构数据中心基础设施平台。

1）ESContainer 和 ESCloud 融合，Kubernetes 使用 OpenStack Keystone 作为用户管理系统，用 Keystone 作为统一用户管理平台，打通两个平台的认证体系。

2）ESContainer 可使用 OpenStack Cinder 卷作为持久存储后端，这样能充分利用 OpenStack 中已广泛支持的开源或主流商业存储设备，为容器提供持久存储能力，弥补目前 Kubernetes 对商业存储设备支持力度不够的问题。

3）ESContainer 可使用 Neutron LoadBalancer 作为服务的外部负载均衡器，充分提供对外服务的高可用性。

4）ESContainer 可直接使用 Neutron 二层网络作为网络驱动，用 Neutron 统一管理虚拟机和容器网络，减少多层 Overlay 带来的性能损失；同时由于虚拟机和容器处于同一个子网中，可做到虚拟机和容器应用的二层网络直通，适用于企业中传统业务和云原生业务共存并需要直接数据交换的场景。

5）ESContainer 可在裸金属以及虚机中部署容器集群使用 Nova ，创建出的虚拟机作为集群节点，可根据容器集群的整体负载情况，快速弹性扩缩不同级别的资源池。

此外，ESContainer 还可使用 Ceph 作为持久存储后端，为容器提供持久数据卷存储。

三、Kubernetes 将打通云计算数据中心最后一公里

据悉，EasyStack ESContainer 面向应用角度设计，自身提供应用管理服务，方便用户在平台中集中管理发布容器化应用;对于有状态应用场景进行优化，方便用户构建多层微服务化应用；支持无 Overlay 纯二层网络等多种网络方案，容器应用与虚拟化应用网络直通；增强监控与日志，面对庞大的容器集群，ESContainer 还提供了增强的多级的监控、日志管理。 

ESContainer 面向企业级容器化应用的管理和编排场景，产品提供包括自动化部署、强化的管理界面、应用商店，多级监控、支持虚拟机、可视化编排、物理机资源池的混合部署，并且与EasyStack的企业级 OpenStack 平台 ESCloud 深度整合融合，无缝的可视化使用 ESCloudIaaS 提供的计算、网络和存储资源以及丰富的软件基础设施，为云计算数据中心从以资源为中心到以应用为中心打通了最后一公里。

值得一提的是，EasyStack 的开源内核的云计算操作系统内核 ESCore 还专门为 ESContainer 进行提供经裁剪与优化的、提供适合为容器运行的定制化的操作系统，能够为容器集群带来更高密度的运行能力，同时提供了更加稳定高效的底层环境。

这也是继今年 1 月 EasyStack 获得 5000 万美元 C 轮融资、创中国开源领域最大单笔融资之后的首次重大产品发布，使得EasyStack 具备了而 Openstack + kubernetes 的开源云计算能力，从而更好地满足企业用户的云计算需求。
