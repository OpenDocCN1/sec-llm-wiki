# 【每日安全资讯】安装量最高PC程序排行出炉：Chrome居首、Flash播放器和Java均上榜

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608845&idx=4&sn=ec2ccbeca8b87e1bcc4b315a4a440f70&chksm=bdce8f0b8ab9061dc33449707d3d661ecff751b8c65232dc1f06f3e5dcac903ca2ba0e08796a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608845&idx=4&sn=ec2ccbeca8b87e1bcc4b315a4a440f70&chksm=bdce8f0b8ab9061dc33449707d3d661ecff751b8c65232dc1f06f3e5dcac903ca2ba0e08796a&scene=27#wechat_redirect)

近日安全公司Avast发布了其全球安装量最高的PC程序排行榜，谷歌的Chrome浏览器位居榜首，二三名分别是Adobe Reader阅读器和Flash播放器（Active X版本），火狐浏览器和Flash插件随后。令人堪忧的是，许多PC用户使用着较老版本的火狐浏览器、Flash或Java程序，极易遭受黑客攻击。

排行榜前十位完整榜单：

![](../Images/b2b7ffe14151e84ac527d2491f6a505a.png)

尽管大部分流行应用经常推出安全更新，但Avast指出相当比例的用户事实上并未安装软件的最新版本，使得大部分PC脆弱且容易遭受攻击。Avast指出，使用率高、与安全性相关的关键应用中（如火狐、Flash和Java），超过52%的版本是未及时更新的旧版本。用户长期忽视更新，或者新版本通常不能正常运行等原因，导致了此情况。过时的软件版本有大量漏洞为攻击者敞开后门。
