做开源项目，像是一场一个人修行。

从一个原始粗糙的想法开始，经过多少个日夜的挑灯奋战，多少次的演绎推理，多少次的推倒重来，熬呀熬，黑眼圈深了好几层，头发掉了好几把，才终于熬到项目框架初见雏形。

这一段奋斗的日子，能依靠的，只有自己想做点新东西的渴望。

好不容易把代码托管到 github 上，期待着自己能像 Linus 那样，凭着 Linux 一朝封神，十年寒窗无人问，一举成名天下知。但更多的时候，是没有人提 issue，没有人 Fork ，没有人 PR，连 Star 都没有的尴尬，仿佛是自始至终都是一个人的自嗨。

多少优质项目，因为维护成本问题，因为推广问题以及各种坑爹的琐事，无疾而终，落入茫茫的烟海。如果，再还有机会能重来就好了~

现在，UCloud 给你这样的机会！

UCloud 携手 Linux 中国，推出「用 UCloud 玩开源项目，免费还赚钱」主题活动。帮你搞定资金，搞定服务器部署，搞定推广资源，让你全身心专注于项目开发工作。

开源项目也能玩得风生水起！

step2：审核通过，代金券充值到相应账户（3个工作日内到账）；

step3：用代金券购买使用 UCloud 云产品；

活动二：用 UCloud 玩开源项目，赚钱！

分享，是“开源”的真谛。

UCloud 联合 Linux 中国，开展「开源项目云上部署」征文活动，我们给每位提交作品的开源作者准备了 300 元云服务代金券。若文章被 UCloud 官方转载，我们还将给予 500 元/篇的丰厚稿酬+全技术渠道推广资源，你的开源项目将被千万技术同学阅读、点赞、感谢、分享。
