# 如何在 Ubuntu 上用 Yocto 创建你自己的嵌入式 Linux 发行版

本文主要聚焦在如何使用 Yocto 在 Ubuntu 上创建一个最小化的 Linux 发行版。Yocto 项目在嵌入式 Linux 的世界非常著名，这是因为它用起来非常灵活、方便。Yocto 的目标是为嵌入式软硬件开发商创建自己的 Linux 发行版。本文我们将会创建一个可以运行在 QEMU 上的最小化的 Linux，并且在 QEMU 上实际运行。

开发机的基本条件

*   最少 4-6 GB 内存
    
*   最新版的 Ubuntu 系统（本文使用了 16.04 LTS）
    
*   磁盘剩余空间至少 60-80 GB
    
*   在创建 Linux 发行版之前先安装下面的软件包
    
*   下载最新的 Yocto（Poky 是其最小开发环境）稳定分支
    

```
1.  `apt-get update`
    
```

```
1.  `apt-get install wget git-core unzip make gcc g++ build-essential subversion sed autoconf automake texi2html texinfo coreutils diffstat python-pysqlite2 docbook-utils libsdl1.2-dev libxml-parser-perl libgl1-mesa-dev libglu1-mesa-dev xsltproc desktop-file-utils chrpath groff libtool xterm gawk fop`
    
```

![](../Images/45904e022d28b751b61053467d4452ee.png)

*Install prerequisites for Yocto*

如下所示，开发环境要安装的软件包将近 1GB 大小。

![](../Images/433e89d5d3789a02bbccce93de7ad9f3.png)

*Install the development packages*

在这个教程中，系统上克隆的是 poky 的 `morty` 稳定分支。

```
1.  ` git clone -b morty git://git.yoctoproject.org/poky.git`
    
```

![](../Images/ffe6d1e876bc62fd5ca46bf6ecd24bac.png)

*install poky*

进入 `poky` 目录，然后运行下面的命令为 Yocto 开发环境设置（设置/导出）一些环境变量。

```
1.  `source oe-init-build-env`
    
```

如下所示，在运行了 open embedded (oe) 的构建环境脚本之后，终端里的路径会自动切换到 `build`目录，以便进行之后行发行版的的配置和构建。

![](../Images/0283ca491ea1d16b2ca46eb77604bac2.png)

*Prepare OE build environment*

上面的截屏展示了在 `conf` 目录下创建的文件 `local.conf`。这是 Yocto 用来设置目标机器细节和 SDK 的目标架构的配置文件。

如下所示，这里设置的目标机器是 `qemux86-64`。

![](../Images/4d32fb70bdc716b30ffcde599414fb5e.png)

*Set the target machine type*

如下面截图所示，在 `local.conf` 中取消下面参数的注释符号。

```
1.  `DL_DIR ?= "${TOPDIR}/downloads"`
    
```

![](../Images/eaea37c2421d6b43cba6c283a2da5504.png)

*Configure local.conf file*

```
1.  `SSTATE_DIR ?= "${TOPDIR}/sstate-cache"`
    
```

![](../Images/97de4385fe17afcfb3b300b0b55c45aa.png)

*Set SSTATE\_DIR*

```
1.  `TMPDIR ?= "${TOPDIR}/tmp"`
    
```

![](../Images/45fdc9c8f57784de43fd3a4593ffb881.png)

*Set TMPDIR*

```
1.  `PACKAGE_CLASSES ?= "package_rpm"`
    
2.  `SDKMACHINE ?= "i686"`
    
```

![](../Images/3b8c622e63d3901add8a4495d2542a14.png)

*Set PACKAGE\_CLASSES and SDKMACHINE*

如下所示，在 `local.conf` 中为基于 Yocto 的 Linux 设置空密码和后续的一些参数。否则的话用户就不能登录进新的发行版。

```
1.  `EXTRA_IMAGE_FEATURES ?= "debug-tweaks"`
    
```

![](../Images/79be6443b4d0001267b34ba82bbbdea8.png)

*Set debug-tweaks option*

我们并不准备使用任何图形化工具来创建 Linux OS，比如 `toaster` （`hob` 已经不再支持了）。

Yocto 编译构建过程

现在运行下面的 `bitbake` 工具命令开始为选定的目标机器下载和编译软件包。

```
1.  `bitbake core-image-minimal`
    
```

![](../Images/76ee46f49c5177892749b6cb00003a6e.png)

*Start bitbake*

非常重要的是要在普通 Linux 用户下运行上面的命令，而不是使用 root 用户。如下面截图所示，当你在 root 用户下运行 bitbake 命令会产生下面所示的错误。

![](../Images/c0fd287d68bfa81d7ab207c5a29fa023.png)

*Do not run bitbake as root*

再一次运行导出环境变量的脚本（`oe-init-build-env`），重新执行相同的命令来启动下载和编译过程。

![](../Images/f80d6960c21870cc0e260e3fb02ebcdc.png)

*rerun commands*

如下所示，构建脚本组件的第一步工作是解析配置（`recipe`）。

![](../Images/77f3bab3cea526ecc8af05642569f4ff.png)

*Parse the build recipes*

下面的截图展示了构建脚本的解析过程。同时也显示了用来构建你的新的基于 yocto 的发行版的构建系统的细节。

![](../Images/2bc52e2eecd6b5a288595c2a4dccd190.png)

*Building proceeds*

在下载了 SDK 和必要的库之后，下一步工作是下载并编译软件包。如下截图展示了为构建新发行版而执行的任务。这一步将会执行 2-3 小时，因为首先要下载需要的软件包，然后还要为新的 Linux 发行版编译这些软件包。

![](../Images/6dbb44b2250104294bfc2bc9593b6aeb.png)

*Compilation will take several hours*

下面的截图表明了任务列表执行完毕。

![](../Images/a1ec0e4db96bbe7d9680ec4b0adf8165.png)

*Compilation*

为目标机器类型 `qemux86-64` 编译好的新镜像位于 `build/tmp/deploy/images/qemux86-64`：

![](../Images/0e21ce691f47a196a6653f03bdf3f45f.png)

*Build complete*

如下所示，上面的命令如果运行在 `Putty` 上会产生一个错误。

![](../Images/78ad0182cb7ca9650c1d1274baffa7e9.png)

*command error in putty*

通过 `rdp` 在 Ubuntu 平台上再次运行上面的命令。

![](../Images/0caf02fe153ad6971d6ef2b1ccc00bf5.png)

*Command works fine in rdp*

为运行新的基于 Yocto 的 Linux 发行版的 qemu 打开一个新屏幕。

![](../Images/5127a7587b452ca90e20ab1075c325fb.png)

*Open Quemu emulator*

下面展示了新发行版的登录界面，同时也显示了使用的 yocto 项目的版本号。默认的用户名是 `root` ，密码为空。

![](../Images/1b6c2783a75963cd7b23787863514b46.png)

*Linux distribution started*

最后使用 `root` 用户名和空密码登录新发行版。如下截图所示，在这个最小版本的 Linux 上运行了基本的命令（`data` 、 `ifconfig` 和 `uname`）。

![](../Images/4035e1521fd50eddba6dede7ef5a773c.png)

*Test the Linux distribution*

本文的目标是理解使用 Yocto 创建新的 Linux 发行版的过程。
