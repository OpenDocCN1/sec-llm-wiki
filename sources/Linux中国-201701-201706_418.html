介绍

目的

如果你想要将 XenServer 虚拟机作为远程桌面，默认的分辨率可能不能满足你的要求。

本篇的目标是提高 XenServer 7 GUI 虚拟机（VM）的屏幕分辨率

要求

访问 XenServer 7 系统的权限

难易性

简单

惯例

  • # - 给定命令需要作为 root 用户权限运行或者使用 sudo 命令

  • $ - 给定命令作为常规权限用户运行

指导

获得 VM UUID

首先，我们需要获得想要提升分辨率的虚拟机的 UUID。

  1. # xe vm-list 
  2. uuid ( RO)           : 09a3d0d3-f16c-b215-9460-50dde9123891
  3.      name-label ( RW): CentOS 7
  4.     power-state ( RO): running

提示：如果你将此 UUID 保存为 shell 变量会节省一些时间：

  1. # UUID=09a3d0d3-f16c-b215-9460-50dde9123891

关闭 VM

优雅地关闭 VM 或使用 xe vm-vm-shutdown 命令：

  1. # xe vm-shutdown uuid=$UUID

更新 VGA 的 VIDEORAM 设置

检查你目前的 VGA 的 VIDEORAM 参数设置：

  1. # xe vm-param-get uuid=$UUID param-name="platform" param-key=vga
  2. std
  3. # xe vm-param-get uuid=$UUID param-name="platform" param-key=videoram
  4. 8

要提升屏幕的分辨率，将 VGA 更新到 std （如果已经设置过，就不需要做什么），并将 videoram调大几兆，如设置成 16：

  1. # xe vm-param-set uuid=$UUID platform:vga=std
  2. # xe vm-param-set uuid=$UUID platform:videoram=16

启动 VM

  1. # xe vm-start uuid=$UUID

increased xenserver screen VM resolution
