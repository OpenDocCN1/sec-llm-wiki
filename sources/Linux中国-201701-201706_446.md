# 【每日安全资讯】谷歌警告一系列知名用户 可能会受到有国家资助的黑客组织攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608755&idx=3&sn=73fd82f50e7e56129d1d7eaa86240535&chksm=bdce88b58ab901a39c7b885b31e3d883eb24e07d58a4575bde51f04053999c853295fc7fe0b2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608755&idx=3&sn=73fd82f50e7e56129d1d7eaa86240535&chksm=bdce88b58ab901a39c7b885b31e3d883eb24e07d58a4575bde51f04053999c853295fc7fe0b2&scene=27#wechat_redirect)

谷歌的警告系统向一些知名用户发出警告，称他们可能会受到一个有国家资助的黑客组织的攻击。这些知名用户包括记者和作家，如《纽约时报》的专栏作家Paul Krugman、GQ杂志的记者Keith Olbermann，另外还有一些大学教授和安全研究员。谷歌的警告显示：“谷歌检测到有国家资助背景的黑客正在尝试窃取你的密码。”谷歌提示用户使用更高等级的密码和双重身份验证(2FA)。

谷歌发言人称此次的警告是针对发生在本月初的黑客攻击行为，谷歌没有在攻击发生时立即发出警告，是因为他们不想让黑客发现其检测系统。报道称黑客的攻击尝试没有成功，而几次成功的攻击也被谷歌立即解决。

这次的警告事件可能和与俄罗斯政府有关联的一项“钓鱼运动”有关，消息称此项目在特朗普赢得选举后就开始了。
