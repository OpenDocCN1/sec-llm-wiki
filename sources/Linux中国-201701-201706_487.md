# 【每日安全资讯】调查：逾三分之一中国网民愿为折扣透露隐私

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664608733&idx=5&sn=6a9673e4b23b661b6bebfcf8af1a458f&chksm=bdce889b8ab9018d62740508584184f66ae88c4f9d89df9d2aa26db8aa9c307811f3263a5a94&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608733&idx=5&sn=6a9673e4b23b661b6bebfcf8af1a458f&chksm=bdce889b8ab9018d62740508584184f66ae88c4f9d89df9d2aa26db8aa9c307811f3263a5a94&scene=27#wechat_redirect)

据俄媒报道，德国消费调研公司（GfK）的多国在线调查问卷结果显示，与其他国家相比，中国的网络用户更愿意为获得折扣等优惠透露个人信息。据俄罗斯卫星网报道称，这份在线调查问卷要求受访者选择他们对以下声明的认可程度：“我愿意分享自己的个人信息（如健康、财政状况、驾驶记录、用电情况等），以此换取低价或个人服务等优惠。”

报道称，38%的中国受访者对此表示完全赞同，表示完全不认可的只有8%。愿意以个人信息换取优惠的网络用户比例居高的国家还包括墨西哥（30%）、俄罗斯（29%）和意大利（28%）。

德国、法国、巴西、加拿大与荷兰的受访者最不愿意透露个人信息。
