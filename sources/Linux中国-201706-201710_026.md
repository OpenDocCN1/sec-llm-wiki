Keynote 嘉宾

![](../Images/5049e12d3b72084b2ad2799e8e6a098e.png)

*Nuritzi Sanchez*

GNOME 董事会主席，基金会核心成员，GNOME 董事会成员，核心成员。毕业于斯坦福大学，SF GNOME 项目联合创始人。Endless 的创始会员和经理。

![](../Images/db0507dd6ea5f17d895859827606c570.png)

*蔡德明*

《鸟哥的 Linux 私房菜》作者，台湾成功大学环境工程系博士，因实验室交接需求而建立“鸟哥的 Linux 私房菜”网站。曾任台湾多家知名 Linux 教育中心讲师，目前于昆山科技大学资讯传播系教授 Linux 相关课程。专长是 Linux 操作系统、网站规划与维护、网络安全，兴趣是写作与阅读，研究方向是网络应用整合。

标准演讲嘉宾

![](../Images/adc724d167875a73c5b862c0eba12c61.png)

*Lennart Poettering*

Lennart Poettering 就职于 Red Hat。他是 systemd 项目的创建者和维护者之一。之前开发过项目 PulseAudio 和 Avahi。他目前居住在德国柏林。

![](../Images/0e8f7d31edc8247b1b27c68297330616.png)

*王文睿*

计算机系博士学位、NW.js 项目创始人，该项目 github 上收藏高达 32.2K。此前从事过 MeeGo、Tizen 和 JNI xml 性能库的开发和数据中心解决方案服务。目前从事 Web 和浏览器技术开发工作。现在主要工作是开发和维护 Node-Webkit 项目。

 

![](../Images/3ce5373e17ff518002b645af6d97f7eb.png)

*刘 彪*

信息无障碍研究会的技术主管，是中国屈指可数的信息无障碍专家。精通计算机技术，拥有超过 10 年的 C/C++、PHP 经验，曾独立研发 PC 端屏幕阅读软件、构建面向障碍用户基于云的软件市场、创建并运营障碍群体辅助技术在线社区，对于 Linux 上的无障碍技术有一定研究。曾参与 W3C 的 WCAG2.0 中文版审阅工作、CSDN 信息无障碍知识库撰稿工作。

![](../Images/6d7e742470beef74c118106b4f429e40.png)

*Neil McGovern*

Neil McGovern 是一个长期的自由软件开发人员和开放社区活动家。他曾 Public Interest 的软件董事会任职。他是该组织的项目负责人，也是 Debian 项目负责人，目前担任 GNOME 基金会的执行董事。

![](../Images/81413e01ba1d71670669dad5231cd958.png)

*赵鑫磊*

先后在新浪和阿里巴巴工作近 8 年，特别擅长高性能、高可用分布式系统的架构设计（DAU 在千万级以上）。淘宝技术大学五星级内训讲师、阿里巴巴技术协会首席顾问。曾出版畅销技术书籍《Linux 就是这个范儿》并输出到港澳台地区，目前被浙江大学软件学院选择研究生教材。曾参与国内著名的 Linux 社区发行版 MagicLinux 的开发工作，是 1.5 和 2.0 版本的团队与项目负责人。曾担任国家高铁检票闸机系统国产化改造的核心技术专家，破解了早期德国 SB 公司检票闸机的磁读写模块，为国产化奠定了基础。

![](../Images/d50f6c60ce64d57c646da49a4ba020cd.png)

*Sriram Ramkrishna*

Sriram Ramkrishna 是 GNOME 基金会的前负责人、Libre 应用峰会的组织者。他于 1998 年加入 GNOME，并成为GNOME的元老之一。Sriram 曾在英特尔工作了 20 年，最初是一个存储工程的 devops，后来作为开源技术中心的工程经理，在英特尔的许多开源项目中担任工程师。

![](../Images/7859b5b0350820d0e6726cc01f62f9f0.png)

*Cosimo Cecchi*

Cosimo Cecchi 是 Endless 的副总裁，他于 2007 年加入 GNOME 项目并作为一名志愿者参与了开源社区，当时他正在佛罗伦萨大学学习计算机工程。之后Cosimo加入了Red Hat的桌面团队，为下一代GNOME桌面工作。在 Endless 里，Cosimo运用了他的创造力，他对像素完美的热爱，以及他在 GNOME 堆栈的各个方面的经验，创造了 Endless 的完美体验。

![](../Images/5f7922af9f3af04ac2e0f101e790127a.png)

*Hermet Park*

Hermet Park 是一名高级软件工程师，自 2009 年以来一直在三星电子的 Tizen 平台上工作。他专注于 Tizen UI 框架，并致力于改进 Tizen UX 和 UI、Tizen 图形系统以及方便的应用程序开发工具。此外，他还参与了三星移动、可穿戴设备和电视产品等项目。

![](../Images/f70fd4d3be3cc32efdd43a753afa2217.png)

*Fu Wei*

企业级 Linux 内核、嵌入式开发者，在 linux 内核，驱动，BSP，系统移植开发有很好的经验，并在 linux 内核的 U-boot/arm-trusted-firmware/UEFI/ACPI 固件的开发中有很丰富的经验。目前工作在 linux 内核的固件，ARM64 在 Fedora/RHEL 服务器方面，特别是在 RAS（Reliability, Availability,Serviceability）／APEI 领域。 

![](../Images/f6350bdff00a121c30fd13008e7372c4.png)

*祁 宇*

 

C++ 开源技术社区 purecpp 创始人，《深入应用 C++11》作者；十年 C++ 开发经验，对 ModernC++ 有深厚的积累和研究，Modern C++ 开源项目 rest\_rpc 和 iguana 作者。
