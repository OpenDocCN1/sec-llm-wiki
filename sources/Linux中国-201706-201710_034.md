# 【每日安全资讯】Cloudflare CEO宣布免费政策：DDoS攻击或成往事

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609506&idx=3&sn=822bcd0c88d6f6329d9cceb288866b78&chksm=bdce8da48ab904b23285df43d03b26c3a0e629d258ff97badd6e0e5abf33396674be6c0a5644&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609506&idx=3&sn=822bcd0c88d6f6329d9cceb288866b78&chksm=bdce8da48ab904b23285df43d03b26c3a0e629d258ff97badd6e0e5abf33396674be6c0a5644&scene=27#wechat_redirect)

知名互联网安全厂商 Cloudflare，宣布了一项可能将 DDoS 攻击扫入历史课本的新政策。周一的时候，该公司宣布将为每一位客户提供全新的“无计量缓解”（Unmetered Mitigation）服务，以帮助其应对每一场分布式拒绝服务（DDoS）攻击，而不论攻击的规模大小或严重程度、并且对免费使用其服务的客户也一视同仁。

![](../Images/6d9d5ecea8babb40e52b73d189228908.png)

Cloudflare 认为此举可带来互联网安全领域的公平竞争。自 1990 年代以来，这种非法行为给业界蒙上了一层长久的阴影。而现在，每个网站都可以地免费抵抗 DDoS 攻击了。

![](../Images/87bae071a572c771cf70719a8e023432.png)

此前，没有购买 Cloudflare（或其它安全企业）高价防护方案的客户，仍然不可避免大规模的 DDoS 攻击。而现在，Cloudflare 将利用自身的资源，帮助所有人对抗攻击 —— 且无论你付了多少钱。
