中国 Linux 内核开发者大会是 Linux 内核方面的纯技术研讨会。会议始于 2006 年，在国内 Linux 技术爱好者、业内公司及各高校的支持下已召开十一届。本次大会继承历届会议传统，聚焦、关注新兴热点技术性话题，旨在促进国内 Linux 内核社区的技术交流，相互学习共同成长，诚邀广大 Linux 内核开发者和学习爱好者参加本次大会。

本届大会由英特尔(中国)有限公司、IBM、南京富士通南大软件技术有限公司共同主办，清华大学协办。除此之外，感谢 Intel、IBM、富士通南大、阿里云、ARM 为本届大会提供赞助；感谢 IT 大咖说、Linux 中国提供媒体支持。

  

会议时间：2017.10.21 (周六) ～ 2017.10.22 (周日)
