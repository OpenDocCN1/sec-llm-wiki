> Google、Microsoft、AWS、IBM 四大公有云加入 CNCF;
> 
> 63% 的用户已在 AWS 上运行 Kubernetes；
> 
> 71% 的开发商已在云基础设施上部署 Kubernetes；
> 
> Kubernetes 已成为最受欢迎的容器编排工具之一。

  

种种迹象表明，Kubernetes 正在以迅猛的速度逐渐引领容器圈发展导向。现阶段，Kubernetes 的理念和架构已经广为人知，而这项开源技术也进入落地爆发的关键期，行业案例和部署实践显得尤为重要。

  

在中国，如何将各行业的成功案例给到更多希望部署 Kubernetes 的客户以参考，同时将中国已有的优秀实践经验推广到全球，这也是**中国 Kubernetes 用户大会（KEUC）**的创立意愿与宗旨。与此同时，本次大会对于 Kubernetes 从理论到落地推广、并走向国际化也有着极为深远的意义。

  

而正是看到了中国市场的巨大需求和潜力，继顶级开源盛会 LinuxCon+ContainerCon+CloudOpen（LC3）会议首次在今年 6 月登陆中国北京后，CNCF 又一次马不停蹄地将目光聚焦到了互联网巨头云集的新兴互联网福地：**浙江杭州**，为 Kubernetes 开发者、爱好者、落地厂商带来一场行业落地和技术盛宴。

  

  

**KEUC 背景介绍**

  

10 月 15 日，一场顶级的 Kubernetes 行业用户落地大会：**Kubernetes End User Conference （KEUC）**将在杭州举行。KEUC 大会将聚焦 Kubernetes 中国行业应用与技术落地，秉承开放协作、技术共享的宗旨，致力于为业界带来最新 Kubernetes 与容器技术、行业应用案例展示，以便为中国行业用户在业务部署方面带来更为精准的指引。  

![](../Images/2d5ab15ff2a0a5c00284f39fb5a2d387.png)

  

而 CNCF 作为主办方和钻石赞助商之一，将携手才云科技（Caicloud）、「K8sMeetup 中国社区」，通过全球化的视角及本土化的实践经验，结合金融、能源、电商、制造业、AI 等行业落地案例，一起为国内市场带来全球最新技术动态与趋势分析。

  

![](../Images/ad0df7b6e49137eaa10aa324ce90d1b5.png)

**行业 & 技术盛宴**

  

  

  

**KEUC**** 金融 / 能源论坛**

  

**金融板块** ：**重点关注金融企业云计算 IT 架构如何转型；推进 Fintech 落地的实践经验与案例。**

以云计算、大数据为核心的数字化建设作为金融 IT 架构转型的一项重要任务，目前正被金融机构纳入工作重点。传统金融数据中心正在分步实施云计算技术，并转型为快速部署、弹性扩展、快速响应、可计量、自服务的私有云平台；伴随 Fintech 技术的发展，分布式计算，大数据，人工智能也逐步落地到金融生产环境，Fintech 应用场景也成大家的关注焦点。

  

**能源板块**：**深度挖掘蕴含在能源企业中的 Cloud+黑科技。**

作为发展之本的传统能源行业，如何借助人工智能，云计算实现“供给侧”改革；面对高风险，恶劣的作业环境，借助“黑科技” 为安全生产保驾护航；在传统 IT 架构环境的产业升级和转型中，带来更好的安全可控和云计算实践。

  

****KEUC******电商 / AI 主题论坛**

  

**电商板块：****分享碰撞企业容器技术落地案例与实践。**

互联网行业引领着世界科技的前沿和发展，以电商为典型代表的互联网行业，如网易、京东、当当网、锦江电商，使用 Kubernetes 容器调度技术承载了绝大部分的应用和服务。从容器技术中获益的电商企业是如何从传统 IT 架构平滑转换到容器微服务架构，在开发、测试、生产、运维过程中大规模使用容器技术，企业为何如此契而不舍，过程中又积淀了哪些经验？

  

**AI 板块：****精彩呈现各公司人工智能甚至深度学习生产实践的探索与挑战。**

随处可见遍布各行各业的 AI+，已经成为企业竞争优势差异化的利器。AI 技术，作为 PaaS 平台服务，对上层业务，可以解决多少问题，可以带来多高价值，对下层资源，如何更大规模架构，如何充分挖掘数据，不同企业选择不同路径，设计不同架构，青睐不同算法。

  

****KEUC******IDC 云计算主题论坛**

  

**云计算板块：****拨云见日透视企业真实上云之路。**

热度持续不减的云计算技术已在不少企业落地，企业中云计算扮演了怎样重要的角色，为企业带来了哪些真实落地的收益？不同现状和特点的企业，在 Kubernetes、OpenStack 等眼花缭乱的云计算的技术框架面前，该如何考量如何选型？

  

**IDC 板块：****深度剖析公共云、行业云、私有云的不断融合与创新。**

IDC 从资源销售转型成为云服务销售，是云计算红利的最大受益者，面对五大公共云巨头的竞争压力，IDC 转型公共云怎样独辟蹊径，保持云上客户的忠诚度的同时，如何创新构建基于客户私有云和 IDC 公共云的真正可管理、可迁移、可调度的混合云。

**现场培训，备战 CKA！**

  

日前，CNCF 宣布了 20 余家 Kubernetes 认证服务提供商（KCSP）的创始成员名单，并公布专业人员现可注册报名新的认证 Kubernetes 管理员（CKA）计划和考试。

  

针对该考试，KEUC 独家举办 Kubernetes 集训营，时长 **4** 小时，集结 **3** 位业内技术大牛，涵盖**Kubernetes 架构、Kubernetes 网络和 Kubernetes 存储**三大课题。

![](../Images/97ce28fc0ecdc9b3443802ed52574c47.png)

**针对人群：**Kubernetes 学习中级者，即具有一定 Kubernetes 基础，想要在生产中使用 Kubernetes 或已有过 Kubernetes 实践经验、正在备战 CKA 考试的工程师。

**课题框架：**  

**Kubernetes 架构概述：**

*   Kubernetes 的前生今世
    

*   Kubernetes 的架构以及目标
    
*   Kubernetes 和 Mesos 架构比较
    
*   Kubernetes 与 Microservice
    
*   Kubernetes 上的日志收集与监控
    

  

**  Kubernetes 网络详解：**

*   Kubernetes 网络模型及 CNI 简介
    
*   常见 Kubernetes 网络插件
    
*   Ingress 及 Ingress Controller
    
*   Kubernetes 网络策略
    

  

**  Kubernetes 存储详解：**

*   Kubernetes 存储模型与实践
    
*   Kubernetes 动态存储管理与扩容
    
*   Kubernetes 存储插件原理与 CSI 简介
    
*   Kubernetes 块存储与本地存储管理
