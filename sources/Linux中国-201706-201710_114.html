导读

字符串处理是 shell 脚本的重点部分，因为shell 脚本主要的工作是和文件或者其他程序打交道，数据格式通常是文本文件，而处理没有统一格式的文本文件出奇地复杂，shell 命令中也有很多都是处理文本的。用 bash 处理文本的话，因为自身的功能有限，经常需要调用像 awk、sed、grep、cat、cut、comm、dirname、basename、expr、sort、uniq、head、tail、tac、tr、wc 这样命令，不留神脚本就成了命令大聚会。命令用法各异，有的很简单（比如 cut、tr、wc），看一眼 man 就会用；有的很复杂（比如 awk、sed、grep），用了好多年基本也只会用很少一部分功能。互相配合也容易出现各种各样的问题（比如要命的空格和换行符问题），难以调试，调用命令的开销也很大。而用好了 zsh 的话，可以大幅减少这些命令的使用（并不能完全避免，因为某些场景确实比较适合用这样的命令处理，比如处理一个大文本文件），并且大幅提升脚本的性能（主要因为减少了进程启动的开销，比如一次简单的字符串替换，调用外部命令实现比内部实现的时间要多好几个数量级）。

但也因此 zsh 的字符串处理功能出奇地复杂，可以说 zsh 的字符串处理功能，要比绝大多数编程语言自带的字符串函数库或者类库要强大（在不依赖外部命令的情况）。同时各种用法也稀奇古怪，很多时候简洁性和可读性是有矛盾的，很难兼顾。而 shell 的使用场景决定简洁性是不能被牺牲掉的，即使用 Python 这样比较简洁的语言来处理字符串，很多时候也只能写出冗长的代码，而 zsh 经常可以一行搞定（可能有人想到了 perl，好吧，我对 perl 并不熟悉，所以不做比较了），如果再加上适当地使用外部命令，基本可以应付大多数字符串处理场景。因为字符串处理的内容比较丰富，我会分多篇文章写。本篇只涉及最基础和常用的字符串操作，包括字符串的拼接、切片、截断、查找、遍历、替换、匹配、大小写转换、分隔等等。

字符串定义和简单比较，我已经在前一篇文章提过了，现在直接进入正题。

字符串长度

  1. % str=abcde
  2. % echo $#str
  3. 5
  5. # 读取函数或者脚本的第一个参数的长度
  6. % echo $#1

字符串拼接

  1. % str1=abc
  2. % str2=def
  4. % str2+=$str1
  5. % echo $str2
  6. defabc
  8. % str3=$str1$str2
  9. abcdefabc

字符串切片

字符串切片之前也提过，这里简单复习一下。逗号前后不能有空格。字符位置是从 1 开始算起的。

  1. % str=abcdef
  2. % echo $str[2,4]
  3. bcd
  4. % echo $str[2,-1]
  5. bcdef
  7. # $1 是文件或者函数的第一个参数
  8. echo ${1[2,4]}

字符串切片还有另一种风格的方法，即 bash 风格，功能大同小异。通常没有必要用这个，而且因为字符位置是从 0 开始算，容易混淆。

  1. % str=abcdef
  2. % echo ${str:1:3}
  3. bcd
  4. % echo ${str:1:-1}
  5. bcde

字符串截断

  1. % str=abcdeabcde
  3. # 删除左端匹配到的内容，最小匹配
  4. % echo ${str#*b}
  5. cdeabcde
  7. # 删除右端匹配到的内容，最小匹配
  8. % echo ${str%d*}
  9. abcdeabc
  11. # 删除左端匹配到的内容，最大匹配
  12. % echo ${str##*b}
  13. cde
  15. # 删除右端匹配到的内容
  16. % echo ${str%%d*}
  17. abc

字符串查找

子字符串定位。

  1. % str=abcdef
  3. # 这里用的是 i 的大写，不是 L 的小写
  4. % echo $str[(I)cd]
  5. 3
  7. # I 是从右往左找，如果找不到则为 0, 方便用来判断
  8. % (( $str[(I)cd] )) && echo good
  9. good
  11. # 找不到则为 0
  12. % echo $str[(I)cdd]
  13. 0
  15. # 也可以使用小 i，小 i 是从左往右找，找不到则返回数组大小 + 1
  16. % echo $str[(i)cd]
  17. 3
  19. % echo $str[(i)cdd]
  20. 7

遍历字符

  1. % str=abcd
  3. % for i ({1..$#str}) {
  4. >    echo $str[i]
  5. >}
  6. a
  7. b
  8. c
  9. d

字符串替换

按内容替换和删除字符。

  1. % str=abcabc
  3. # 只替换找到的第一个
  4. % echo ${str/bc/ef}
  5. aefabc
  7. # 删除匹配到的第一个
  8. % echo ${str/bc}
  9. aabc
  11. # 替换所有找到的
  12. % echo ${str//bc/ef}
  13. aefaef
  15. # 删除匹配到的所有的
  16. % echo ${str//bc}
  17. aa
  20. % str=abcABCabcABCabc
  22. # /# 只从字符串开头开始匹配，${str/#abc} 也同理
  23. % echo ${str/#abc/123}
  24. 123ABCabcABCabc
  26. # /% 只从字符串结尾开始匹配，echo ${str/%abc} 也同理
  27. % echo ${str/%abc/123}
  28. abcABCabcABC123
  31. % str=abc
  32. # 如果匹配到了则输出空字符串
  33. % echo ${str:#ab*}
  35. # 如果匹配不到，则输出原字符串
  36. % echo ${str:#ab}
  37. abc
  39. # 加 (M) 后效果反转
  40. % echo ${(M)str:#ab}

按位置删除字符。

  1. %str=abcdef
  3. # 删除指定位置字符
  4. % str[1]=
  5. % echo $str
  6. bcdef
  8. # 可以删除多个
  9. % str[2,4]=
  10. % echo $str
  11. bf

按位置替换字符。

  1. % str=abcdefg
  3. # 一对一地替换
  4. % str[2]=1
  5. % echo $str
  6. a1cdefg
  8. # 可以多对多（也包括一对多和多对一）地替换字符，两边的字符数量不需要一致。
  9. # 把第二、三个字符替换成 2345
  10. % str[2,3]=2345
  11. % echo $str
  12. a2345defg

判断字符串变量是否存在

如果用 [[ "$strxx" == "" ]] ，那无法区分变量是没有定义还是内容为空，在某些情况是需要区分二者的。

  1. % (( $+strxx )) && echo good
  3. % strxx=""
  4. % (( $+strxx )) && echo good
  5. good

(( $+var )) 的用法也可以用来判断其他类型的变量，如果变量存在则返回真（0），否则返回假（1）。

字符串匹配判断

判断是否包含字符串。

  1. % str1=abcd
  2. % str2=bc
  4. # 星号要在引号外边
  5. % [[ "$str1" == *"$str2"* ]] && echo good
  6. good

正则表达式匹配。

  1. % str=abc55def
  3. # 少量字符串的话，尽量不要用 grep
  4. # 本文不讲正则表达式格式相关内容
  5. # 另外 zsh 有专门的正则表达式模块
  6. % [[ "$str" =~ "c[0-9]{2}\de" ]] && echo a
  7. a

大小写转换

  1. % str="ABCDE abcde"
  3. # 转成大写，(U) 和 :u 两种用法效果一样
  4. % echo ${(U)str} --- ${str:u}
  5. ABCDE ABCDE --- ABCDE ABCDE
  7. # 转成小写，(L) 和 :l 两种用法效果一样
  8. % echo ${(L)str} --- ${str:l}
  9. abcde abcde --- abcde abcde
  11. # 转成首字母大写
  12. % echo ${(C)str} 
  13. Abcde Abcde

目录文件名截取

  1. % filepath=/a/b/c.x
  3. # :h 是取目录名，即最后一个 / 之前的部分，如果没有 / 则为 .
  4. % echo ${filepath:h}
  5. /a/b
  7. # :t 是取文件名，即最后一个 / 之后的部分，如果没有 / 则为字符串本身
  8. % echo ${filepath:t}
  9. c.x
  11. # :e 是取文件扩展名，即文件名中最后一个点之后的部分，如果没有点则为空
  12. % echo ${filepath:e}
  13. x
  15. # :r 是去掉末尾扩展名的路径
  16. % echo ${filepath:r}
  17. /a/b/c

字符串分隔

  1. # 使用空格作为分隔符，多个空格也只算一个分隔符
  2. % str='aa bb cc dd'
  3. % echo ${str[(w)2]}
  4. bb
  5. % echo ${str[(w)3]}
  6. cc
  8. # 指定分隔符
  9. % str='aa--bb--cc'
  10. # 如果分隔符是 : 就用别的字符作为左右界，比如 ws.:.
  11. % echo ${str[(ws:--:)3]}
  12. cc

多行字符串

字符串定义可以跨行。

  1. % str="line1
  2. > line2"
  3. % echo $str
  4. line1
  5. line2

读取文件内容到字符串

  1. # 比用 str=$(cat filename) 性能好很多
  2. str=$(<filename)
  4. # 比用 cat filename 性能好很多，引号不能省略
  5. echo "$(<filename)"
  7. # 遍历每行，引号不能省略
  8. for i (${(f)"$(<filename)"}) {
  9.     echo $i
  10. }

读取文件指定行。

文件 test.txt 内容如下：

  1. line 1. apple
  2. line 2. orange
  1. # 小文件或者需要频繁调用时，尽量不要用 sed
  2. % echo ${"$(<test.txt)"[(f)2]}
  3. line 2. orange
  5. # 输出包含 “ang” 的第一行
  6. % echo ${"$(<test.txt)"[(fr)*ang*]}
  7. line 2. orange
  9. # 输出包含 pp 的第一行，但从左截掉 “line” 4个字符。
  10. echo ${"$(<test.txt)"[(fr)*pp*]#line}

读取进程输出到字符串

读进程输出和读文件类似。

上边字符串相关的处理，直接把 $(<test.txt) 换成 $(命令) 即可。如果一定需要一个文件名，可以这样。

  1. # 返回 fd 路径，优先使用，但某些场景会出错
  2. % wc -l <(ps)
  3. 4 /proc/self/fd/11
  5. # 临时文件，会自动删除，适合上边用法出错的情况
  6. % wc -l =(ps)
  7. 3 /tmp/zshMWDpqD
