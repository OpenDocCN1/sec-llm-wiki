# 【每日安全资讯】黑客团队OurMine成功入侵维基解密网站

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609339&idx=4&sn=00a76100658a200f008b42c0f7aad00f&chksm=bdce8d7d8ab9046bc53c3ad77c0a22fefe9ab2d2265675ac06da562d62abd3e13bdd0416ed29&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609339&idx=4&sn=00a76100658a200f008b42c0f7aad00f&chksm=bdce8d7d8ab9046bc53c3ad77c0a22fefe9ab2d2265675ac06da562d62abd3e13bdd0416ed29&scene=27#wechat_redirect)

黑客团体OurMine此前攻击的目标主要是科技圈内的CEO、企业和新闻网站，通过社交账号存在漏洞来兜售自家的安全服务。今天，该黑客团队对维基解密网站（WikiLeaks.org）发起了攻击，目前主页面显示：“Hi，我们是OurMine（安全团队），不要担心我们仅仅只是为了测试你的...Oh等等，这并非一次安全测试！Wikileaks，还记得当时你是怎么挑衅要我们入侵试试的吗？”

在信息上继续写道：“Anonymous，还记得那时候尝试攻击wikileaks时候尝试使用假信息来人肉我们吗？那么如你所愿，我们能够单挑你们所有。让#WikileaksHack成为推特的热词吧。”
