# 【每日安全资讯】伪装Flash播放器恶意广告程序变种近日重现Mac平台

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609250&idx=3&sn=936a2af330beb474734e01bfd4a2f12f&chksm=bdce8ea48ab907b2a81ab32fa90b8df63ab807d882a6197ad8038c9f66d8e8ea78dfd20ccaf5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609250&idx=3&sn=936a2af330beb474734e01bfd4a2f12f&chksm=bdce8ea48ab907b2a81ab32fa90b8df63ab807d882a6197ad8038c9f66d8e8ea78dfd20ccaf5&scene=27#wechat_redirect)

近日安全研究机构Malwarebytes的计算机安全专家发现了一个古老的Mac平台恶意广告程序的新变种，他将其命名为“Mughthesec”。这种恶意广告程序OperatorMac家族恶意程序升级变种，计算机专家发现他能绕过苹果macOS系统的安装前程序验证安全机制。

![](../Images/9f07cea0252b375137d3d7e9204a2ade.png)

安全专家指出，Mughthesec可以将其伪装成一个Adobe Flash播放器安装程序，如果其检测到一个虚拟机器，其将会安装合法的拷贝，但如果是真实机器，它会安装上Advanced Mac Cleaner, Safe Finder,和Booking.com三个恶意广告程序。其将会劫持和拦截受感染系统的主页和域名，接下来它会修改浏览器默认搜索引擎为AnySearch，Advanced Mac Cleaner则出来提醒用户系统需要优化和修复问题。

如果感染的化，安全专家建议彻底清洁重装整个macOS系统。
