# 【每日安全资讯】英媒：中国将推出“牢不可破”的通信网络 将西方甩在身后

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609200&idx=5&sn=a5d1d246fffb84a83dacd1ddc0487f0c&chksm=bdce8ef68ab907e0c5b3e12e96e09ff8608c2bf328f086fad5b25c3153d69dca31d7dfc90601&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609200&idx=5&sn=a5d1d246fffb84a83dacd1ddc0487f0c&chksm=bdce8ef68ab907e0c5b3e12e96e09ff8608c2bf328f086fad5b25c3153d69dca31d7dfc90601&scene=27#wechat_redirect)

“中国即将推出一个牢不可破的通信网络”，英国广播公司(BBC)7月25日以此为题称，由于恶毒的黑客正组织更为复杂的攻击，中国将推出一个全新的通信网络。至少从某种意义上讲，任何针对这一网络的攻击都将很快被发现。报道称，这一通信网络采用了量子密码术，这一技术彻底改变了传统加密方法。这一在济南进行的项目被中国官媒称为里程碑。

![](../Images/a0eacc6473e253dc12cb6a12562b9f6f.png)

首创项目也是背后故事的一大章节：中国在一项欧美国家迟迟不愿投资的技术上处于领先地位。

在济南的网络中，“来自军方、政府、金融和电力部门的大约200名用户在肯定只有他们能阅读信息的情况下将能安全地发送信息”。

报道还称，中国对量子通信的推进意味着“这个国家正加大步伐发展应用程序，这些应用程序或使愈加脆弱的互联网变得更为安全”。而其他国家可能很快发现自己正从中国购买这些应用。

将西方甩在身后

如果量子通信有助于维护网络通讯安全，那么中国为什么可以遥遥领先？

“长期以来人们只是认为没有这个需求，”伦敦帝国理工学院教授Myungshik Kim表示。他补充说，目前尚不清楚这项技术是否存在商业市场。

他还表示：“目前编码系统的数学难度太高，以至于没有实施新技术的必要。”

报道称，这并不是一项新的研究，但中国的优势在于应用程序。

Anton Zeilinger教授是奥地利维也纳大学量子物理学家，同时也是该领域(研究)的先驱人物。他认为“欧洲已经错失了良机”。Zeilinger教授称他早

2004年就试图说服欧盟资助更多的量子项目，但收效甚微。“欧洲一直在拖延，这阻碍了我们的竞争力。”

报道称，美国和欧洲有基于量子密钥的网络运作，但多数都是作为研究项目展开，而不是与商业伙伴合作。

创建市场

BBC称，构建像济南网络这样的应用程序花费高昂，如果没有一个商业市场，很难得到投资者或政府的支持。

新加坡国立大学量子科技研究中心物理学家Valerio Scarani说：“我们不得不承认，当中国投资某些领域时，他们所拥有的财力和人力，在世界上除了美国军方，几乎没有(国家)可与之相比。”

报道称，济南网络并不是中国唯一正在发展的量子通信应用。去年，中国发射了一颗卫星用以测试无法连接电缆的远距离量子通信。而中国两大中心城市——北京与上海之间也建立了链接，两端可以沟通并知悉外人监听情况。

目前可能还不清楚量子通信是否真能取代传统加密技术，但它已经被广泛认为是“领先候选之一”。而当涉及到实际应用的建立和试验时，中国是主导国家。

Zeilinger教授说：“这是一种技术可以创造市场的情况。”

BBC认为，一旦这项技术被中国公司出售，国际银行可能是第一个排队(购买)的客户。
