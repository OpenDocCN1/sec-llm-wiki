《Linux Shell 脚本攻略（第 2 版）》结合丰富的实际案例介绍了如何利用 shell命令快速开发常规任务，如何凭借短短几个命令行从 Web 挖掘数据的 shell 脚本，如何通过 shell 脚本设置以太网和无线 LAN，以及如何利用少量命令的组合完成诸如文本处理、文件管理、备份等复杂的数据管理工作等。 本书面向初、中、高级 Linux 系统管理员和程序员，是编写 shell 脚本的绝佳参考资料。
