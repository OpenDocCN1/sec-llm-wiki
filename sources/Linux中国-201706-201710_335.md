# 【每日安全资讯】美俄共建网络安全小组 美国议员：还不如把投票箱寄到莫斯科

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609155&idx=3&sn=1af201a963d05bb61891aa0a4a0969e1&chksm=bdce8ec58ab907d33958b7d609c8b1fe934a03c1af3553b92a09185c985cd6faaee7565a8e04&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609155&idx=3&sn=1af201a963d05bb61891aa0a4a0969e1&chksm=bdce8ec58ab907d33958b7d609c8b1fe934a03c1af3553b92a09185c985cd6faaee7565a8e04&scene=27#wechat_redirect)

上周五召开的20国集团峰会上，美国现任总统特朗普在推文中表示和俄罗斯总统普京会面时候，讨论建立一个难以渗透的网络安全工作小组，避免干涉选举等事件再次发生。推文中写道：“普京和我讨论了成立网络安全小组的问题，以便保障安全，使黑客袭击选举或其他负面事件不再出现。”

![](../Images/743fce98744a9afd81b1e4cb2f7b6596.png)

但是特朗普并未就本次谈论的话题做更多的展开介绍。不过在20国集团峰会上，特朗普表示美俄关系是“时候向前迈进”，甚至还接受弗拉基米尔•普京(Vladimir Putin)否认俄罗斯干涉了美国选举的表述。特朗普表示：“我两次强烈追问普京总统有关俄罗斯插手我国选举的问题。他坚决否认有这回事。我已经发表了我的观点，”

针对特朗普在推特上同意和俄罗斯建立网络安全工作小组，亚利桑那州参议员约翰•麦凯恩(John McCain)、共和党人马可•鲁比奥(Marco Rubio)、民主党头号人物亚当•希夫(Adam Schiff)等等都表示强烈反对，并嘲讽道：“如果这是守卫我国选举的最佳防御，我们还不如把投票箱寄到莫斯科去。”
