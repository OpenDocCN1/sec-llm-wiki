# 【每日安全资讯】Let’s Encrypt 将于 2018 年免费提供通配符证书

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609148&idx=3&sn=6a23fb37eca61ae43befb2b267b2cf15&chksm=bdce8e3a8ab9072c7a097d9dd3d079b37dd6bc27654e35573e57da2784bd37ff887c0e5b6a67&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609148&idx=3&sn=6a23fb37eca61ae43befb2b267b2cf15&chksm=bdce8e3a8ab9072c7a097d9dd3d079b37dd6bc27654e35573e57da2784bd37ff887c0e5b6a67&scene=27#wechat_redirect)

旨在让每个网站都启用 HTTPS 加密的 Let's Encrypt CA 宣布将于 2018 年 1 月免费提供通配符证书（Wildcard certificate）。通配符证书是一种可被多个子域使用的公钥证书。这意味着，单个证书可用于提供多台服务器或一台服务器托管的多个子域名的网页加密，显著降低了个人和小型企业采用 HTTPS 的门槛。

Let's Encrypt 表示，它希望通配符证书能帮助 Web 加快实现 100% HTTPS。Let's Encrypt 前不久刚刚宣布签发了一亿个证书。
