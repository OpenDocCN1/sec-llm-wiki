# 【每日安全资讯】英国议会邮件系统遭到攻击 现禁用远程电子邮件访问

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609115&idx=4&sn=732da0fe352f3f06484b49961e45d7fc&chksm=bdce8e1d8ab9070bd57a2edb096a277bb6a7ac9fa0b8da56d3c5fecd45c430e6104320e19a03&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609115&idx=4&sn=732da0fe352f3f06484b49961e45d7fc&chksm=bdce8e1d8ab9070bd57a2edb096a277bb6a7ac9fa0b8da56d3c5fecd45c430e6104320e19a03&scene=27#wechat_redirect)

上周六英国议会议员Henry Smith在推文中表示，英国议会的邮件系统遭到黑客入侵，试图寻找那些薄弱且容易破解的帐号密码，从而获取议员、议员助手以及议会员工的电子邮件内容。本周五（6月23日），英国下议院发表声明表示预防措施，议员的远程电子邮件访问已经被禁用。

![](../Images/2ab5c029047584d76e50003204130603.png)

英国国会下议院发言人表示：“部分在威斯敏斯特之外的议员和员工无法访问他们的邮件账号。”英国议会已经配合英国国家网络安全中心进行全面的调查，并进一步锁定攻击网络。

![](../Images/55827d98165d9fd208e9000e6d554a00.png)

英国上议院自由民主党成员雷纳德（Chris Rennard）在推特上说：“伦敦威斯敏斯特遭遇网路攻击，议会邮件可能无法远程工作。”

![](../Images/abea270cd9922f67c45a12c9afe1f06c.png)

下议院发言人说，他们周五发现有未经授权者企图进入议会用户账户，并指出，电脑防御系统正在保护电邮账户。不过，正因为启动了防御系统，议员们才不能在威斯敏斯特以外的地区登入电邮账户，但在威斯敏斯特不受影响。

英国负责国际贸易的国务秘书利亚姆·福克斯（Liam Fox）告诉ITV 新闻，这次袭击是“对大家的一个警告。我们需要更多的安全和更好的密码。晚上你不会敞开你的家门。”
