传说中让一票开源粉翘首以盼、众望所归的开源盛会——LC3 在北京国家会议中心如火如荼地成功举行！作为 LC3 在中国的首秀，此次大会汇集了业内最顶尖的开源专家，迎得千位开源粉慕名近距离切磋，业界影响力实至名归！



话不多说，这就带大家一览现场盛况！

 

幸福爆表


经历了大半年漫长的等待，终于等到一众开源大咖漂洋过海，这对国内的小伙伴来说，无疑是最幸福的事儿啦！开源粉们个个幸福洋溢，指数爆表！


 

座无虚席


如此幸福满格的机会，自然不容错过。嘉宾演讲环节，千人坐席无一空置，会场列席率空前！

 



点燃热情


作为开场嘉宾，Linux 基金会执行董事 Jim Zemlin 简要介绍了基金会和中国开源技术的现状，其独有的个人魅力，燃起现场观众的热情，起到很好的暖场效果！

 

 

荣耀时刻


中国开源软件推进联盟主席陆首群教授，做了题为“我的开源之路”的演讲，与大家分享了自己与开源的点滴，其为开源事业做出的巨大贡献，赢得阵阵掌声。

 


更被 Linux 基金会亲自授予其“终身成就奖”，一度将大会推向高潮！

 


满满干货


OpenStack 基金会执行董事 Jonathan Bryce 介绍了该基金会的服务宗旨及在开源方面的贡献，着实让人大开眼界！



微软亚太研发集团中国区云计算与企业工程董事合伙人梁戈碧女士，做了题为“改变点燃创新”的演讲，阐述了微软对开源的重视程度，激情满满，极具感染力！

 


中国联通网络技术研究院周伟博士，发表了题为“基于开源的网络重构”的演讲，从电信运营商的角度分析了基于开源 SDN/NFV 云的网络重构，并分享了其对开源网络技术的趋势和挑战的看法，内容精彩，现场喝彩声不断！

 


思科系统工程首席技术官兼首席架构师 Dave Ward，演讲主题为“逻辑微服务基础设施的联网”，大谈如何缩小当前的基础设施网络/安全”和微服务逻辑基础设施之间的差距，以应对挑战和自动化。

 


才云科技 CEO 张鑫先生，以“如何让 Kubernetes 更智能”为主题展开演讲，分享了才云科技在推动Kubernetes智能化方面的经验和成就，令人折服！


 

华为战略和产业发展副总任旭东先生，则以“创建全云网络创新平台，拥抱数字化转型”为主题，为第一天的主题演讲环节画上了圆满句号！

 


Linus点亮媒体发布会

 


此次 LC3 发布会，是 Linux 和 Git 的创始人 Linus Torvalds 先生在中国的首秀，也是其第一次面对中国媒体，回答媒体记者提问时认真的样子，给五颗星都不嫌多！

 

 

作为开源界重量级大咖，Linus 不仅受到广大开源粉的爱戴与崇拜，还收获了许多同行的青睐！中国开源软件推进联盟主席陆首群教授就是其中的一位！陆教授早早便在媒体发布会门外等候，如愿见到 Linus 后更是乐得合不拢嘴，又是拥抱，又是赠书，激动之情难以言表！

 

 

看过了如此丰富精彩的盛大场面，您一定对 LC3 的专业性感同身受！未来，我们一起同行，继续为这场开源界盛会增砖添瓦吧！
