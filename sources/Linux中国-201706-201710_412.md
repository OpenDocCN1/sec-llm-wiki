6 月 28 日，以“开源·智能·未来”为主题，2017 中国开源产业峰会将在北京香格里拉饭店盛大开幕。面向广大开源云计算领域技术开发者，2017 中国开源产业峰会倾力打造开源云计算核心技术培训专场。

主办单位：北京软件和信息服务业协会、EasyStack

培训专场合作单位：K8S技术社区、Linux中国、开源云中文社区、日知录、云技术实践、IT大咖说

我不告诉别人这里有多少干货：

 

**课程1：OpenStack基础库的设计与实现**

  

![](../Images/92c6491cff5ba59ed51cb7928021f3e8.png)

演讲摘要：作为 OpenStack 所有项目的基础库，Oslo 通过提供高质量，稳定，一致的 API 为所有服务提供消息队列，数据库管理，配置项管理，访问控制等多项功能，对于 OpenStack 的稳定性，易用性，可扩展性等方面提供有力支撑. 这次分享将介绍 Oslo 项目的历史和现状，针对关键组件进行剖析讲解, 介绍最近两个版本的新功能及Pike版本正在做的工作。

**课程2：在OpenStack 上建立你的应用程序架构**

  

![](../Images/f8357919d13187318193a91ae44e68af.png)

演讲摘要：在使用者的眼里应用程序至关重要，对于程序开发者而言也是如此，但往往不了解 OpenStack 跟他手上的应用程序到底有和关系。而 OpenStack 这样的云的世界，又是如何提供架构与好处给他的应用程序。演讲中会提框架概念与供技术细节，让更多的使用者与应用程序开发者对于往 OpenStack 移动，有更深入的了解。希望透过此演讲让更多应用程序，能更清楚将面临的考量。

**课程3：Ceph 产品化**

  

![](../Images/ce292bbab6cbb6fd855b15d192cee0e9.png)

 演讲摘要：介绍整个 ceph 产品化的过程中遇到的问题和解决思路。课题包括存储技术选型，管理系统架构设计，功能开发，和性能优化等等。存储技术选型课题将探讨目前流行的开源分布式存储技术以及如何在这些技术当中选型。管理系统架构设计课题将探讨一个分布式存储的管理系统应该以怎样的架构来设计，需要考虑的因素以及解决方案。功能开发课题将分享在存储产品当中需要考虑到的一些关键功能，包括与商业存储的对比，以及实现思路。最后将展示 ceph 性能的优化思路，以及优化效果。

**课程 4：如何基于 Kubernetes 构建企业级容器云平台**

  

![](../Images/e328d7c43d0b3854eb345d70ec27fbe5.png)

 演讲摘要：本课程可由浅入深，帮助学员了解整个容器生态及应用落地实践等知识。具体包括：Kubernetes 基本概念详解，Kubernetes 高级特性，KubeCon Europe 2017 会议最新动态，如何构建Kubernetes容器云平台，如何在 Kubernetes 平台进行应用容器化落地。 

**课程5：从编译角度提升核心与平台的效能**

  

![](../Images/464a75cae42f60d933b5289f29d2ec7c.png)

演讲摘要：为了部署适当的 OpenStack 云计算平台，具备稳定的核心与效能优化的软件至关重要。深入地了解可明白所有的代码运行最终都会走到最底层与系统沟通。吴中如在技术实作的业界经验下，具有完整的系统软件概观去处理许多底层系统的问题需求。本次分享将从编译器的角度出发，思考如何采用不同且有效的策略来提升核心与平台的效能。

**课程6：OpenStack COA 认证介绍**

  

![](../Images/e6c853ddd26e2d97d797b37cb5a1bacb.png)

演讲摘要：自基金会宣布 OpenStack COA（Certified OpenStack Adminstor）认证考试上线起，引起了 OpenStack 圈内广大技术爱好者的热切关注，本次内容将围绕 OpenStack COA 认证体系相关话题，向学员详细介绍COA认证体系，COA 认证优势价值体现以及COA考试大纲。帮助学员更好的理解和通过 COA 认证。对想要深入了解 OpenStack COA 认证的学员，绝对不容错过。
