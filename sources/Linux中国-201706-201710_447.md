　作者　|　老王

  

备受关注的 LinuxCon 2017（北京）\[1\]即将在一周后在北京首秀，而国内已经连续举办了 11 届的中国 Linux 内核开发者大会（CLK）\[2\]也将在金秋十月的北京举办第 12 届。值此 Linux 界两大盛会举办之际，我特意收集了一些 Linux 内核方面的文章分享给大家。

让我们先以一篇漫画开端：《[漫画赏析：Linux 内核到底长啥样](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608812&idx=1&sn=deb7e886ab31547a9831ce8ae66020d3&chksm=bdce8f6a8ab9067c894511da7fda1b61dd5ab38aa4cf976377306cae94b1c053c5aef0b94db0&scene=21#wechat_redirect)\[3\]》，这篇并不算严谨的漫画，来自极客漫画站 TurnOff.us，由 LCTT 翻译组\[4\]进行汉化和点评，以有趣的方式向大众展示了内核里面都发生了些什么：

![](../Images/f3ce285d8c30e4769dd3c3ece622949a.png)

*Linux 内核都有啥*

当然， 作为非专业陈述，就不必深究细节了，但是这篇漫画成功地引起了诸多（伪）Linux 内核爱好者的兴趣。

如果你对 Linux 内核发生了兴趣，想要知道 [Linux 内核是如何构建的](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=209331296&idx=1&sn=8e4b71fd794b7cf8ca3f57e84151aa3c&scene=21#wechat_redirect)\[5\]，那这里也有[一篇文章](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=209331296&idx=1&sn=8e4b71fd794b7cf8ca3f57e84151aa3c&scene=21#wechat_redirect)\[6\]可以指导你，这是一篇由 GitHub 上 0xAX 写的一系列 Linux 内核文章\[7\]中的一篇， LCTT 成员 @mudongliang 参与了组织翻译。

此系列我们还翻译了数篇数据结构方面的文章，如：[双向链表](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607339&idx=1&sn=60aa25a08401c6a30a91e6f2f27dbcf2&scene=21#wechat_redirect)\[8\]、[基数树](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607361&idx=2&sn=1a8c48d70f200436a69363bf3bb75efc&scene=21#wechat_redirect)\[9\]、[位数组](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608026&idx=1&sn=c212296842b365df38af47f3bffd8d10&scene=21#wechat_redirect)\[10\]，这些在你做内核开发和研究时肯定会用到。当然，Linus Torvalds 大神向来以对进入内核的代码审核严苛而著称，比如说，他曾经就如何[写出具有 “good taste” 的代码](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608998&idx=1&sn=7aee26e04f1b4ccc9ed6b919a8abcd6a&chksm=bdce8fa08ab906b6bb87acf154c81adfbe26e3ddde86b9c6145f861dc1edea3beba28365269b&scene=21#wechat_redirect)\[11\]而发表过演讲。

说起来，现在内核的变化太快了，简直是日新月异，比如说，我们就注意到 [BPF 进入了 4.9 内核](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608590&idx=2&sn=ee2ef871b042926f2906fb97550e299d&chksm=bdce88088ab9011e0e1e78d98733e9265092ba37b34c0c1aaac3ef660f60adaf6dc5e64aa0fe&scene=21#wechat_redirect)\[12\]，它相当于 BSD 中的 DTrace 一样。另外，据闻 Linux 内核将新增一种异构内存管理\[13\]，将会加快 Linux 上的机器学习处理能力。

这么多的新特性的涌现，背后代表着大量的代码和贡献人员的辛勤付出。据 [2016 年度《Linux 内核开发》报告](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608046&idx=2&sn=b0a38c6c48b9636740d7824ce7be12e5&scene=21#wechat_redirect)\[14\]，自版本 3.18 于 2014 年 12 月 7 日发布以来，已合并了近 115000 个变更，这些贡献来自近 500 家公司的 5062 名开发人员。

当然，Linux 内核发展这么迅速，随着影响力的提升，也越来越引起各界的注意，比如说，华盛顿邮报就曾经批评 Linux “没有一个系统性的机制以在骇客之前发现和解决安全问题，或引入更新的防御技术”，“Linux 内核开发社区没有一个首席安全官”等等。针对这篇文章，LWN 上也有人对此进行了一些[回应](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607440&idx=1&sn=66877cddaee18f32c2e1f9e481feaa63&scene=21#wechat_redirect)\[15\]，并就一些问题进行了辨析和反思。

所以，现在 Linux 内核不仅仅需要更好的安全机制的出现和贡献者的努力，也需要[解决 Linux 内核代码审查人员短缺问题](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608436&idx=3&sn=b4b8e8ee5711a8cb3a158455a4398ac0&chksm=bdce89f28ab900e4a1e6833266c0b713af32c09b1c7742ce9b439e6ac8cd5ce975b21c1f1a11&scene=21#wechat_redirect)\[16\]。

前面说了很多 Linux 内核开发人员更关注的话题， 对于普通的 Linux 用户来说，可能更关注的是如何在 [CentOS](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608829&idx=1&sn=fbb18d39bed3a9decd5c097ead9a4421&chksm=bdce8f7b8ab9066d701cb69386c293341d28acb2d6a8afcbe16a57ccb638533cd5d26723c616&scene=21#wechat_redirect)\[17\] 和 [Ubuntu](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608807&idx=4&sn=cea79dcaa2d04d078a8551d9c5098da6&chksm=bdce8f618ab90677cde40a40389e5f2638cac55b4e973c65be73e87ced50b551866a31e09ab3&scene=21#wechat_redirect)\[18\] 上升级内核。不过，现在的内核已经支持[升级后不重启](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=202354129&idx=2&sn=db83645a93136445381ffcf0f14340d8&scene=21#wechat_redirect)\[19\]了，对于某些内核补丁，可以[热应用](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608540&idx=2&sn=d2443f2ab630a751d35c0fdb7266c4e3&chksm=bdce885a8ab9014cc43ccda4a1f25038ce37eb06854679f63f5f9743caf9abc56a0ab0da6da0&scene=21#wechat_redirect)\[20\]而不用重启。这对于生产环境中的 Linux 服务器很重要，比如 [Ubuntu](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608414&idx=2&sn=b7bba4a9dbef107e3934e4066ab6f459&chksm=bdce89d88ab900ce19677ece757c4b52ce4b6b852ed8be8cac5822bcf4f7f48a8d868ff0800f&scene=21#wechat_redirect)\[21\]、Oracle Linux\[22\] 等发行版已经支持了。

作为 Linux 的使用者，尤其是 Linux 服务器的运维人员，密切监控 Linux 的各项性能指标也是必需的工作，无论是[传统工具](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=208858725&idx=2&sn=31f1ebfa2d05ffb51aabf64da7b567ff&scene=21#wechat_redirect)\[23\]： top、ps、pstree、[vmstat](http://mp.weixin.qq.com/s?__biz=MzI1NDQwNDYyMg==&mid=2247484094&idx=2&sn=06dd1bd5c8b0ef2b09db2388b7eb231c&chksm=e9c4f3dfdeb37ac9dddfc7c726287f02aa0f068ff55622593e89d61ec0b592ff534719779135&scene=21#wechat_redirect)\[24\]、iostat\[25\]，还是 [htop](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401472325&idx=2&sn=11b0f4da9bb626b2e8084e1c4624d200&scene=21#wechat_redirect)\[26\]、 [nmon](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401237963&idx=3&sn=ed37f7305cb25647b30fa3deaea277f3&scene=21#wechat_redirect)\[27\]、[ntopng ](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=207267023&idx=3&sn=70181b50d9ac5291f6af5cbb5af027c1&scene=21#wechat_redirect)\[28\]这样的新工具；而且不但有 [cpustat](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608977&idx=1&sn=fa21506dd6ddd7f2f0a5386d49407e72&chksm=bdce8f978ab90681eb7a5ab219c1f5a60841068561c4faed8fb777c73107179ac6023163b5de&scene=21#wechat_redirect)\[29\]、[CoreFreq](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664608784&idx=1&sn=35113431fff4dd7a7056741c12742f28&chksm=bdce8f568ab90640748d54632f26562b66af41694db0c9b52e46deff1e25cb9be8a044292c28&scene=21#wechat_redirect)\[30\] 这样专门监控 CPU 的工具，也有各种大而全的全面监控系统，如 [Glances](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401250729&idx=3&sn=558cc09f57cfb4153b180f081303d16d&scene=21#wechat_redirect)\[31\]、[netdata](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664607754&idx=1&sn=967642127c7e7586ed70fa1ec9d05064&scene=21#wechat_redirect)\[32\]、 [Munin](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401323155&idx=3&sn=cf3475f2002f33e4f191a31d61f659a7&scene=21#wechat_redirect)\[33\]。总之，[用于监控的工具和系统不要太多了](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=401454912&idx=1&sn=debfa303d14770260eac4529bff15394&scene=21#wechat_redirect)\[34\]。
