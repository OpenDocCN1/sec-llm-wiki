# 升级、降价 还有酷炫的闪电立方 阿里云在上海云栖发了这些大招

数不清是今年第几次云栖大会了，每年在上海开云栖大会，阿里云都会发布一堆黑科技，这次也不例外。

这次的发布更加集中在面向大型企业客户，包括帮助企业快速迁移数据上云的“闪电立方”、智能迁移 Oracle 数据库上云的 ADAM、性能全面升级的新一代 ECS 实例规格族、提升企业办公效率的阿里云办公等，产品一个接一个，真是目不暇接。

小编就简单梳理了下这次上海云栖的产品发布，一起来看看阿里云带给了我们什么惊喜。

1、数据迁移服务“闪电立方”

亚马逊曾在 2015 年推出过名为 snowball 的大型数据迁移服务，通过行李箱大小的设备将企业本地数据迁移到云端，今天阿里云发布了一款类似的产品，命名为“闪电立方”，跟亚马逊的 snowball 相比，“闪电立方”的单体容量扩大了一倍，**单次服务支持最大 1PB 容量，传输速率更快**，同时支持端到端加密，更适合大批量传输数据、有数据位于分散位置或需要持续加载流数据的企业。此外，“闪电立方”的服务范围覆盖国内所有区域，并提供了专人上门服务，在价格上也支持按量付费，交付方式更为灵活。  

![](../Images/80404d2a00b0e50530dfe85dcdbfba70.png)

2、阿里云核心产品降价

降价是云栖大会的必备节目，这次云数据库 Redis 版（集群版）价格最高降幅 **35%**。云服务器 ECS 最新一代实例最高降幅 **31%**。具体细节可以看如下图表：  

![](../Images/9b29a673d2f958c597cc6c264b93d267.png)

3、新一代基于 Skylake 的 ECS 实例

ECS 实例也做了性能升级，这次采用了基于 Skylake 内核的处理器，新实例规格族包含通用型 G5、计算型 C5、内存型 R5 三个实例规格族，同时全面升级到 25Gb 网络,将网络吞吐能力提升到了 200%，这也是全球**首款基于 Skylake CPU x 25Gb 网络的实例**，相比上一代产品，**单实例计算核心数上限提升了近 60%**。

![](../Images/dbb6a8461d8124722f6fcd693efbe066.png)

4、ApsaraCache 开源  短连接性能提升30%

阿里云还宣布启动 ApsaraCache 项目开源。该项目分三批次开源功能。其中，第一批开源的是短连接性能优化和 Memcache 协议兼容。**短连接场景下，ApsaraCache 版本比 Redis 官方版本性能提升 30%。**ApsaraCache 预计在 6月邀请部分用户内测。阿里云 Code 平台和代码托管网站 Github 将在10月左右开放下载 ApsaraCache 源代码。

5、智能上云分析  Oracle 数据库上云神器 ADAM

为了方便用户更安全快速地在云上开展数据库业务，阿里云推出了业内首个覆盖数据全生命周期的应用与数据库迁移工具 Advanced Database & Application Migration（简称 ADAM），该服务使得企业能够将 Oracle 等数据库无缝迁移上云，在云上数据库 MySQL、PPAS、AnalyticDB 等开展业务。

迁移前，ADAM 可对本地事务、存储过程等检测后确认是否可以上云，随后给出云上匹配的数据库类型和应用迁移的代码更改建议，最后提供数据和应用程序迁移工具以便让割接平滑进行及自动化测试，整个过程便捷、高效。

![](../Images/5e2252a141ecb5190ebce92904a4570c.png)

6、阿里云推出企业级智能协同办公方案  云桌面、云 AP、云客服一应俱全

企业级办公市场向来是兵家必争之地，“钉钉”的横空出世改变了整个格局，如今阿里云也在逐步开放阿里巴巴创立 18 年来信息化实践的积累与经验。这次推出的智能协同办公平台------阿里云办公包括了阿里邮箱、云 AP、云投屏、音视频会议系统、云桌面、审批、设备安全、云客服等产品和服务，可覆 95% 以上的办公场景，帮助企业解决跨区域办公、企业数据安全、运维成本高等问题。

![](../Images/1952f59d0c0362546b32fed0ea255e5e.png)

7、面向物联网场景的数据库产品 HiTSDB

HiTSDB 高性能时间序列数据库，主要面向每秒千万数据点产生的物联网场景，可支持**每秒 1000 万时序数据点写入**；具备 PB 级别的数据存储能力，提供高效压缩算法，**整体存储成本降低 90%** ；提供时序数据插值计算，降精度计算，时间纬度聚合计算，空间纬度聚合计算的能力，百万数据点计算响应时间小于 5 秒。
