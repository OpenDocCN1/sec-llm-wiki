# 【每日安全资讯】谷歌将发现Android漏洞的悬赏奖金提升至20万美元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609049&idx=5&sn=f48b9b53838b180883fa53d84f7a65ba&chksm=bdce8e5f8ab90749809278252640ba40a1ce879bb4ccda21646acb1e3b73d0bf8a0404646f00&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609049&idx=5&sn=f48b9b53838b180883fa53d84f7a65ba&chksm=bdce8e5f8ab90749809278252640ba40a1ce879bb4ccda21646acb1e3b73d0bf8a0404646f00&scene=27#wechat_redirect)

6月4日消息，据国外媒体报道，在名为“Judy”的恶意软件侵害3650万Android手机之后数天，谷歌将发现Android操作系统漏洞的奖金提高至20万美元。 据电子安全公司Check Point称，有数十款恶意应用程序从Play Store被下载的次数达到450万次至1850万次不等。

在谷歌这个应用商店上架已经几年时间的一些受到恶意软件影响的应用程序已经被发现。

![](../Images/878f5ca29ee1472f255f95eb8e346909.png)

Judy就是被恶意应用程序开发者如何利用一个开放并且免费的移动操作系统的一个这样的案例。

大约在两年前谷歌启动了寻找Android漏洞的奖励计划，发现该操作系统漏洞的安全研究人员将获得谷歌的奖金。随后，谷歌会修复漏洞以避免出现未来的安全问题。不过至今为止，没有人能够提交有关Android核心组件的运行漏洞。
