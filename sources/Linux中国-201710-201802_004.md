刘遄老师早在高中时期便因为兴趣驱使而接触到 Linux系统并开始学习运维技术，还先后获得了红帽认证管理员、红帽认证工程师以及最顶级的红帽认证架构师等证书。刘遄老师对 Linux 技术发自肺腑的热爱和痴迷，是他多年以来一直从事 Linux 系统运维培训以及红帽认证课程培训的源动力。在这个行业的长期浸淫，也让他成长为国内开源行业颇具影响力的技术大 V。

刘遄老师针对 Linux 系统培训的教学思想相当具有前瞻性和独特性。他始终认为，一名优秀的IT技术培训讲师应该将技术知识进行提炼总结之后再传授给学生，而不能仅仅是一名技术知识的搬运工。

1． 异步社区：刘老师可以先简单介绍下自己以及书籍吗？

最早接触到 Linux 系统并开始学习是在高中时期，那会主要是凭借兴趣的驱使，后来便热爱的一发不可收拾。那个时候的网络还不像现在这么便捷，没有这么多丰富的资料和书籍，培训市场也不成熟，安装 Linux 系统都要用 6-7 张光盘才行，确实算吃尽了自学的“苦头”，这段学习经历后来形成了写书的初衷。

受益于良师益友的无私帮助，在 2012 年获得了 6 版本红帽 RHCE 认证，2015 年初又获得了红帽 RHCA 认证及 7 版本红帽 RHCE 认证，LPI 认证及 Linux 基金会成员。那时咱们国内（含中国香港、澳门及台湾地区）总共 RHCA 架构师也就 100 人，所以我也算是国内较早一批与 RedHat 结缘的技术人了。

这本《Linux 就该这么学》是一本由我从 2015 年初起笔编写的 Linux 系统书籍，由于深知水平有限且技术一般，加之自己是一个完美主义者，想把一切都做的更好，所以这本书付出了比正常编写 IT 书籍更多的时间。书籍在 2017 年 11 月份才算正式露面，也非常感谢读者们的热切支持，荣获了双 11、双 12 购物节 IT 品类书籍销量冠军，短短 2 个月内已经加印了 4 版次达到近三万册，销量较为喜人。

相比于当前常见的技术书籍，这本书我们更加注重实用性，绝不会将大段枯燥理论知识“扔”到书里，或者故意放上一些“深邃”的术语来吓唬住新手（除了能证明作者很厉害，别无它用），而是真正从新人的角度起笔来创作，让您学完每个章节都能有所收获是最大的目的，对得起读者花费的时间和购书款。是国内目前品质较高的 Linux 系统自学书籍之一。

2． 您作为一名高品质内容的输出者，一般每天是怎么度过的？

我认为高品质应该是以用户需求为基础的，如果用户不需要，也就不会去读，那么写作出来的内容即便花费的时间和精力再多也意义不大。另外我认为，作为一名合格的老师，不能仅仅成为技术的搬运工，而应该是优质内容的提炼者，需要结合自己的学习、工作经验，在原有内容基础上取长补短。所以我和团队一直在强调就是实用性，而不是为了写而去写。虽然书籍中出现的仅仅是“冰山一角”，但用户学会之后是有用就足够了，而没有必要把无用的都摆出来，反而让人找不到重点。

因此我每天的生活其实不会像读者想象中那样一直埋头苦干，闷头“闭门造车”的写书，很大一部分的时间都是在关注行业的动向，了解最新的技术。以及读者知道我自己也在讲在线培训，每天日常的备课和学员答疑是必不可少的。

3． 异步社区：您平时选择技术书籍有什么技巧吗？

我非常喜爱读书，比如以学习技术来讲，纸质书籍比现在网络上的文章品质要高很多，不至于出现严重的错误，而且内容连贯，比零散学习更加有效率，学到的知识更成系统，更扎实。尤其是为了创作《Linux 就该这么学》这本书，更是翻遍了市场上能买到的所有书籍，取长补短，吸取到了不少的有用经验。所以，坦白来讲，技术类书籍我已经没有什么选书经验了，只要没有的都会买一本回来看看。

4． 异步社区：我们关注到您也在创办自己的培训课程，与读者看书自学有什么区别吗？

我们的培训课程与看书自学实际上面向的人群是不同的。例如报名培训课程的同学首先普遍是零基础的，看书自学比较吃力，有些技术点参悟不懂或者做实验不明白原理，亦或者想考取红帽认证等情况，这些就都需要系统性的学习了。详细展开来讲内容太多，需要针对不同情况进行分析，因此如果读者对培训课程内容感兴趣的话可以看下我们的培训介绍视频：http://www.linuxprobe.com/training

5． 异步社区：新手在学习 Linux 系统时遇到问题，您推荐怎么解决？ 

其实在学习中遇到问题是很常见的情况，不光是我的学生，连我自己也碰到一些棘手的问题都会很头疼。所以首先来说，很多同学在遇到问题，或者实验出错后不好意思提问，怕别人笑话，这种心态是最不可取的。好在经过这么多年的“磨砺”也一路走来，确实总结了一套处理问题的方法，可供参考。

其次分析问题是那种类型的，技术性问题或非技术性问题，非技术性问题一般会团队间进行“头脑风暴”来解决，集思广益最后出方案。而技术性问题，也是同学们最常头疼的，我们通常推荐直接将问题“扔到” Google 中搜索，尝试找到历史中遇到过此类问题的提问和解决方法。同学们可能会问为什么推荐是 Google 而不是百度呢？虽然从正常生活的角度来看百度是更合适的，但是技术性问题目前搜索结果还是不太让人满意（你们懂我的意思）。顺便提一下，很多程序员有个“坏习惯”，问题解决后普遍做不到主动的“结贴”，也就是在帖子中说明自己解决问题的方法和思路，以便让后面人不走冤枉路，这种意识也正在慢慢形成，我们要有足够的耐心。

最后，当然是推荐快来加入读者群啦~我们目前 QQ 群中有超过四万名技术爱好者，在技术圈中算是人数众多了，而且大家都是在看《Linux 就该这么学》书籍的读者，所以您遇到的问题，其他同学可能早就遇到并解决过了~交流起来更加顺畅。

6． 异步社区：作为考试学霸，对即将考证书的同学有什么建议吗？

随着大数据、云计算、AI 等等高新技术的崛起，IT 行业及运维岗位出现了很大的人才缺口，但明显也能够感觉到人们的压力变得更大，因为想要获得更优厚的薪水就得有过人扎实的能力。对于红帽认证有没有用，以及是否适合自身，这需要分析后才能告诉大家。

首先，谈谈红帽认证的含金量问题，RedHat 即开源行业的领袖企业之一，RHEL、Centos 及 Fedora 系统的市场占有份额无可争议，红帽认证也是目前运维行业内最具含金量的认证。

其次，认证是否有用？对于学历、认证的无用论已经被人说了无数遍，从新闻报道“清华大学毕业卖猪肉”再到“博士生不懂下雨”。似乎很多人都觉得学历、认证都变成了一张白纸。但我们不能用个体的成功与否来映射出整体状态，每个人都要有自己的主见，不能该轻易忽悠。

话句话说，如果没有学历、没有认证，那就请你拿出更好的东西证明自己的能力（例如出书、做过的项目或者工作经验）。入职面试的时候，总不能空口一句“我有中级 Linux 系统操作水平，相当于红帽 RHCE 认证吧”，这实在不足以让人新服。而且同考场中还会有更多人敢说“我有高级（特级）Linux 系统操作水平，相当于红帽 RHCA 认证吧”，那么HR到底该信谁？

最后，红帽认证费用非常不低，确实不是每个人都适合、或必须考取！我一般建议是跨行业者或学生，之前没有从事过运维行业的更需要红帽认证的认可，作为推开IT行业大门的敲门砖。对于红帽认证是否值得考取，也不是一两句话能够讲清楚的，有兴趣的同学可以听下红帽讲座来详细了解下 http://www.linuxprobe.com/redhat-certificate

7.异步社区：大家知道您花费了近3年时间写作的这本《Linux就该这么学》，您对这本书未来有哪些期望？

对于正常著作一本 IT 书籍来讲，花费 3 年时间编写的《Linux 就该这么学》的确值得与大家分享下创作经历，这其中最主要的原因是我们对于书籍有着很高的期待，写作中对书籍有任何不满意都要重复修改。当然从书籍出版的销量就能看到读者也是非常认可书籍品质的。

对于《Linux 就该这么学》书籍未来的期待主要有三点。

首先，书籍会在官网持续更新下去，内容保持一致，提供最新 pdf 电子版文档节配套工具，每天的访问量能够达到 15000-20000人，年销量在 5 - 8 万册。

其次，通过书籍向线下发展，帮助更多培训机构、高校以及企业改进 Linux 系统培训课程，提供标准化的完善课件和资源，提高现有的课程培训水平。

最后，我们希望能够被读者一直喜爱，这也是我们的最大动力。

8.异步社区：您理想中的工作方式是什么样的？

在互联网时代，每个人都是超级个体，我心目中理想的工作首先是要找一帮志同道合的伙伴，有着共同鉴定的价值观、理想和目标，一起愉快的工作。

像美国硅谷的创业者一样，或许不需要固定的办公场所，我们集合全国各地有能力的人才一起通过互联网协同工作。随着出版书籍，越来越火热的培训项目以及线下合作伙伴的加入，我也已经用实际行动证明了这个想法是完全可行的。

另外工作是为了更好的生活，重复性高的工作我们尽可能交给机器去做，让团队成员有更多的时间享受生活，陪伴家人。终究会有一天，我们都可以实现不仅在家办公，更是可以整合更多的资源，成为超级个体。这样一来，我们不能摆脱了人与生产资料的物理限制，更是可以通过合理搭配来提供工作效率，有了一台电脑，就可以做任何你想做的事情——比如，我现在正躺在三亚的海滩上，完成了这篇专访。
