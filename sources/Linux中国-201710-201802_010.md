# 【每日安全资讯】调查发现人们优先考虑密码的安全性而不是方便

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610373&idx=5&sn=8844cf266ecdf44f64af27a6fbb0472b&chksm=bdce81038ab9081595e071b24c0b722f036c2b220ae0771fb829c1a947d51f248135a37fd5b8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610373&idx=5&sn=8844cf266ecdf44f64af27a6fbb0472b&chksm=bdce81038ab9081595e071b24c0b722f036c2b220ae0771fb829c1a947d51f248135a37fd5b8&scene=27#wechat_redirect)

![](../Images/ccca7deb7110023aca0d810fe70e780e.png)

IBM Security 调查了约 4000 名美国、亚太和欧洲的成年人，发现人们对密码的态度有所改变，对安全性的重视高于了方便性，尤其是当涉及到与金钱相关的应用时。调查还发现，生物特征身份认证日益成为主流；四分之三的千禧年一代接受生物识别，但不到一半使用复杂密码，41% 重复使用密码；亚太地区的人对生物识别的了解最深接受度最高；生物识别被认为比密码更安全；55 岁以上的人使用 12 个密码，而 Z 世代平均只有 5 个；千禧年一代更常用密码管理器，也更可能启用二步认证。
