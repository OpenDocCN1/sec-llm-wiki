# 【每日安全资讯】谷歌新成立Chronicle公司 专注网络安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610337&idx=6&sn=e88e51c219766e4b3b5fc1d8e08f57c9&chksm=bdce81678ab90871d7659bb7cc1ac05c8af6526a12244b1aff61a71d2b0e5c2fe405ef354648&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610337&idx=6&sn=e88e51c219766e4b3b5fc1d8e08f57c9&chksm=bdce81678ab90871d7659bb7cc1ac05c8af6526a12244b1aff61a71d2b0e5c2fe405ef354648&scene=27#wechat_redirect)

昨天，谷歌母公司Alphabet旗下再添一新子公司——Chronicle。

Alphabet旗下秘密实验室Google X宣布，一家全新公司从该部门剥离出来，该公司名为“Chronicle”，未来Chronicle将专注于网络安全，旨在为用户开发数字化“免疫系统”。谷歌Google X实验室主管阿斯特洛·特勒（Astro Teller）将未来Chronicle提供的服务称为“数字免疫系统”，Chronicle能够通过分析和存储大型企业内的相关安全数据，从而探测、发现来自网络上的潜在威胁。

![](../Images/794920fea8074feea5f8dd687321ce93.png)

该公司声称，使用谷歌的基础架构，Chronicle能够比现有系统更快地、更广泛地检测到网络安全威胁，这可能是尽早阻止黑客攻击的关键。

Chronicle创始人斯蒂芬·吉勒特（Stephen Gillet）表示，与当前的服务相比，Chronicle将能够帮助组织机构提供更为精准、更全面的安全服务。

吉勒特没有透露关于该项目的进一步细节，但其表示，该产品的早期测试版本已经在一些财富500强公司进行了测试。

据悉，Chronicle公司还将把谷歌的病毒扫描工具VirusTotal并入其产品线。谷歌在2012年收购了病毒扫描工具VirusTotal，VirusTotal作为谷歌旗下安全信息分享平台，拥有全世界最多的电脑病毒分析数据，每天接收到的安全信息超过100万份。

尽管VirusTotal被并入Chronicle经营的产品中，但预计VirusTotal的服务将继续开展，不会受此影响。
