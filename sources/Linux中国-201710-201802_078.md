# 【每日安全资讯】夏威夷导弹警报系统有一个令人困惑的界面

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610267&idx=5&sn=ea0ec0a631a5336fa90c625ed1b1e045&chksm=bdce829d8ab90b8b3e6ebbb454c2fed232b2e7cbbdd287988ffb7da9e95c760b766644ef8be3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610267&idx=5&sn=ea0ec0a631a5336fa90c625ed1b1e045&chksm=bdce829d8ab90b8b3e6ebbb454c2fed232b2e7cbbdd287988ffb7da9e95c760b766644ef8be3&scene=27#wechat_redirect)

上周六上午在夏威夷发出假导弹警报后，政府官员公布的新图像显示警报系统是多么混乱。警报系统的操作员不必按下按钮，而是点击选择列表上的链接。在这次交接测试中，员工错误点击了PACOM (CDW) - State Only选项，而不是点击应该点击的Drill - PACOM (CDW) - State Only选项。

这些选项许多名字是相似的，所以没有经过适当训练的员工很容易点击错误的链接，向公众发出弹道导弹威胁的警告。上周六上午8点，该员工只是测试内部导弹警报系统，而不发送给公众。这个测试是偶尔进行的，但是没有任何测试时间表。

尽管如此，还有第二个确认页面作为安全措施，询问员工是否确定要发送警报，他们也错误地按了“是”。自上周末事件以来，有百多万居民收到虚假警报，引发了大规模的恐慌，官员因此现在在名单上增加了“BMD False Alarm”选项，可以更快地通报虚假警报。

上周六，官员花费了近40分钟的时间纠正虚假警报，即使现在增加了BMD False Alarm，但是界面仍然看起来很混乱。美国联邦通信委员会星期天宣布，正在调查这起错误的导弹警报事件。
