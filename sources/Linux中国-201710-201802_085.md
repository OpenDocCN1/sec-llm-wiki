# 【每日安全资讯】以太坊骗局数据库可以帮助用户避免加密货币骗子

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610257&idx=5&sn=bef86c2040a2e0a97d7e1ba5fdf4d7c8&chksm=bdce82978ab90b81d71ee3b7ea6519c36b33e42dce040645ea64e532b3ad882d5f5737a7f87a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610257&idx=5&sn=bef86c2040a2e0a97d7e1ba5fdf4d7c8&chksm=bdce82978ab90b81d71ee3b7ea6519c36b33e42dce040645ea64e532b3ad882d5f5737a7f87a&scene=27#wechat_redirect)

![](../Images/6a55343826d75ae22df3d4054187f932.png)

加密货币和区块链市场目前正在经历的指数级增长，使这个领域成为各种黑客，恶意活动和网络钓鱼陷阱的滋生地。但是有一个漂亮的工具可以帮助用户摆脱这种麻烦。以太坊骗局数据库（EtherscamDB）是一个方便的网站，收集关于在线诈骗堆众包的信息，以引导新手和加密货币爱好者远离恶意骗局。

自去年推出以来，该网站共登记了2614个有欺诈性的网页，并将这些网页连接到223个不同的加密货币地址，这些地址被骗子用来存储被盗资金。幸运的是，其中大部分加密货币地址已经被封。

EtherscamDB指出，只有253个注册的潜在恶意网页当前处于活动状态。特别有用的是，EtherscamDB可以方便地显示攻击的确切性质，包括诈骗的原始URL，以及描述精确攻击方向的详细信息。

除此之外，该网站还有一个专门用于准确显示恶意链接所针对的公司/服务的字段。任何遇到全新加密货币诈骗的人都应该向EtherscamDB报告这种可疑活动。用户可以使用这个链接来做到这一点。
