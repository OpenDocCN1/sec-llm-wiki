# 【每日安全资讯】修复CPU漏洞后 i7版Surface Book重伤：SSD性能腰斩

最近，微软面向Surface产品也发布了修补Spectre和Meltdown漏洞的固件和Windows 10系统更新，PCWorld执行编辑Gordon Mah Ung 1月13日分享了他实测的性能损失情况。Gordon手中的是一台一代的Surface Book笔记本，当时微软称其是全球最强电脑、秒杀MBP云云。

配置上，i7-6700U、16GB LPDDR3内存、512GB三星950 Pro NVMe固态盘，固件更新前的CrystalDiskMark 5.5.0：

![](../Images/46c30b41c810cf3c6697f9a2a7fea799.png)

固件更新后：

![](../Images/aa8e9c65b7467e5ed1b477454213b908.png)

连续读写略有下滑，不过，4K写入暴跌了26%。

同时，高队列密度（Q32）下的4K读写则分别下滑了42%和39%。

因为此次漏洞可能会通过浏览器的方式注入脚本，Gordon还测了Edge JS性能。

![](../Images/f6543b4fc6292a198e9a7ce4a8076cc6.png)

![](../Images/989fe38f27d05ec859d2d1f452ee3a49.png)

固件更新后，JS性能下滑了4个百分点（从450到433）。

Gordon称，Intel所说的跟负载相关固然有道理，但是想，500ms之于1500ms是不可见，但类似的幅度，如果更新前复制图片要27秒，更新后要34秒，你还说无所谓？
