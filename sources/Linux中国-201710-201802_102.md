# 【每日安全资讯】程序员利用恶意软件攻击Mac与PC：时间长达13年

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610228&idx=4&sn=f77e3fd81806cede1f8ea740e7a6907b&chksm=bdce82f28ab90be4b685493194988f46ab2c1ce49c0530c6c388a5b0ef9515be05fc19ebdc1b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610228&idx=4&sn=f77e3fd81806cede1f8ea740e7a6907b&chksm=bdce82f28ab90be4b685493194988f46ab2c1ce49c0530c6c388a5b0ef9515be05fc19ebdc1b&scene=27#wechat_redirect)

一名计算机程序员因为使用恶意软件攻击数万台计算机而遭到指控，据悉这名程序员在攻击他人电脑之后会盗取个人身份，甚至制作未成年人色情影片。现年28岁的菲利普·杜拉琴斯基（Phillip Durachinsky）来自美国俄亥俄州北罗亚尔顿，本周三他因为使用名为Fruitfly的恶意软件攻击他人计算机而面临16项指控。

这个恶意软件会对macOS和Windows PC系统进行感染。自2003年起，杜拉琴斯基使用这个软件感染了数万人的计算机。而2003年时，杜拉琴斯基还只是一个少年。

代理助理检察长约翰·克洛南表示：“菲利普·杜拉琴斯基通过恶意软件攻击了数万台美国民众的计算机，并且盗取受害人的个人数据与通信记录。一直以来，司法部门都在努力打击这种以侵犯他人隐私为手段的网络犯罪活动。”

法庭文件记录显示，杜拉琴斯基创造了一个恶意程序，该程序能够记录受害人电脑的键盘敲击以及浏览器活动。另外，它还能够让杜拉琴斯基通过计算机的网络摄像头以及麦克风来对受害人进行监视与监听，甚至可以对受感染的计算机进行控制。

公诉人透露，当受害者在计算机上搜索与色情影片相关的关键词时，这个恶意程序就会被触发。被告人表示，他通过受害人电脑上的网络摄像头拍摄了数百万张图片。

美国第一助力律师大卫·席尔勒加表示：“这名被告人在超过10年的时间里，一直在偷窥来自美国各地的受害者，并且盗取他们的个人信息。”

这个名为Fruitfly的恶意软件曾经一度让网络安全研究人员感到非常困惑，因为这个恶意软件混合了新旧两种编程风格。甚至曾经有人一度怀疑这个软件是美国政府资助编写的，还有人认为它是一个间谍工具。

公诉人表示，此前这个恶意软件曾经多次被植入到凯斯西储大学的服务器上，于是司法部门开始介入。在经过调查之后，犯罪嫌疑人杜拉琴斯基遭到逮捕。美国联邦调查局（FBI）表示，美国能源部门网络、一家警察局和多个学校的网络上也发现了这个软件。

FBI特工史蒂芬·安东尼（Stephen Anthony）对这件事情的评论为：“杜拉琴斯基利用他高超的网络技能做了错误的事情，入侵了大量系统和个人计算机。联邦调查局想要赞扬那些让执法当局注意到这件事情的机构，正是这种合作的态度让当局能够将这名网络黑客绳之以法。”
