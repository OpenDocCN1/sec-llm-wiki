# 【每日安全资讯】多个比特币借记卡提供商根据Visa组织要求暂停服务

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610184&idx=4&sn=6461e3fb082c5ccdad0dd6add44424ce&chksm=bdce82ce8ab90bd8f99d70c852130f0803bee44dd916d667f2039ca760fd4c806b2640e28fd2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610184&idx=4&sn=6461e3fb082c5ccdad0dd6add44424ce&chksm=bdce82ce8ab90bd8f99d70c852130f0803bee44dd916d667f2039ca760fd4c806b2640e28fd2&scene=27#wechat_redirect)

几家预付费加密货币借记卡供应商突然中止服务之后，比特币社区正在萎缩，受影响的公司包括Bitwala，Cryptopay，Wirex和TenX。这些服务允许个人通过其中一家主要提供商发行的Visa和MasterCard借记卡，在传统的实体实体店当中使用比特币等加密货币进行付款。   

受影响的公司在推特上向客户表示，此举是由发卡行（代表Visa欧洲）采取行动的结果。 来自新加坡的TenX在推特上表示，它的发卡机构是位于直布罗陀的WaveCrest。 WaveCrest是否是上述所有公司的提供商尚不清楚。

其他比特币借记卡服务用户已经收到WaveCrest发送的电子邮件，通知他们必须立即关闭所有WaveCrest借记卡。电子邮件说： “我们WaveCrest是Visa预付卡的发卡机构，您通过我们的合作伙伴之一注册了该卡。Visa今天指示我们必须立即关闭所有WaveCrest发行的Visa预付卡。”

电子邮件接着说WaveCrest发行的卡将不再起作用，但是数字钱包当中的用户资金仍然安全，提供者是安全的。 Visa Europe在一份声明中表示，此举是由于WaveCrest不遵守VISA会员条例而引发。这一举措颠覆了一个蓬勃发展的行业与几个主要参与者。它也对用户造成了严重的后果，其中许多人依靠这些服务来进行日常支出。据报道，Twitter上的一些用户在没有资金的情况下被困在国外。
