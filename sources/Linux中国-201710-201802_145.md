# 【每日安全资讯】英国警方可以让人们用亚马逊Echo报案

目前智能扬声器已经在世界各地变得非常流行，因此，这种AI设备的使用范围正在扩大。现在英国兰开夏郡警方希望人们可以使用Echo智能扬声器报警，并且为用户提供最新警方信息。

这些信息更新包括失踪人员，通缉犯以及一个地区内的犯罪人数的信息。兰开夏郡警方还计划使用Alexa语音助手发送内部简报。这可以让官员及时了解突发事件，或只是聆听每日犯罪日志。

但实验最有趣的方面是受害者和证人有可能通过自己家中的Echo报案。兰开夏郡警方创新负责人罗布·弗拉纳根（Rob Flanagan）告诉警务学院会议：“我们应该能够通过使用语音识别或语音技术来减少对呼叫中心的需求，并实际上为社区提供他们需要的信息而不需要进入警局寻求帮助。”

尽管执法部门和Alexa之间的这种整合对于公众来说很方便并且可以减少公众资源占用，但是对犯罪的隐私影响以及将警察公报发送到系统上的担忧已经上升，这主要是因为对话被记录并存储在亚马逊的服务器上。

在2016年12月，阿肯色州本顿维尔的警方向亚马逊发出搜查令，要求搜查亚马逊服务器上属于一位谋杀嫌疑人的Echo录音，该公司拒绝了警方要求，认为这些信息受到美国宪法第一修正案的保护。最终，被告允许将证据交给检察官。去年11月，对这位嫌疑人的谋杀指控被撤销。
