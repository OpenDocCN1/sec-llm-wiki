# 【每日安全资讯】外媒：欧洲最大追债公司之一数据遭黑客入侵

据德国《南德意志报》报道，欧洲最大追债公司之一EOS Group瑞士分公司的一名匿名消息人士透露，该公司数万名客户的个人数据遭黑客入侵。

今年4月初，该名消息人士曾向报社提供了总内存为3GB的3.3万余份文件。文件内容包括债权人和债务人的姓名、注册地址以及欠债数额。信息泄漏波及数万人，其中大多数人住在瑞士。

报道指出，文件内容包括债务人的详细医疗记录、身份证和护照复印件、信用卡对帐单、通讯信息和私人电话号码。消息人士表示，黑客利用公司IT安全系统漏洞侵入EOS公司服务器访问这些文件。

据瑞士政府个人信息保护全权代表洛布希格尔主张，追债公司通常需要债务人的姓名、地址和公开的银行信息用以讨债。他表示，收集存储个人医疗信息是违法的。

EOS公司代表表示，公司已将数据泄漏的情况告知瑞士政府和客户，并开始全面检查。
