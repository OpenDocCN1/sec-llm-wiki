# 【每日安全资讯】微软OneDrive网页宕机近12个小时：波及全球用户

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610062&idx=3&sn=5f322c21182e92159a15de3174dab4cd&chksm=bdce82488ab90b5ef7dd208489c2f842d53816c80d55415ae74a236ab6d66b26c4daae62aae9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610062&idx=3&sn=5f322c21182e92159a15de3174dab4cd&chksm=bdce82488ab90b5ef7dd208489c2f842d53816c80d55415ae74a236ab6d66b26c4daae62aae9&scene=27#wechat_redirect)

曾经一度多头参与、各种拼免费大存储的网盘在市场竞争和政策干预下，开始逐步转向海外早已通行的付费路径，且留存的品牌也骤减，所以对普通消费者，更有种“且行且珍惜”的悲愤感。据外媒报道，约在北京时间上周日晚上23：30分，微软OneDrive出现登陆故障。

从DownDetector的地理位置统计来看，欧洲影响最密集，其次是北美东西部的沿海地区以及包括墨西哥、印度等地。

![](../Images/7f41024877f0186298cf3287bc88b09c.png)

随后，微软火速响应，发布故障提示，称Web页面故障，PC客户端和手机客户端仍可以正常访问。

在大约北京时间凌晨3点，微软重启了一些故障服务器，但凌晨4点，微软再次预警称，重启并没有解决全部问题。

时间到了凌晨5点半，微软称仍在对故障服务部署更新。

凌晨7点半，微软称部署配置更新并不顺利，有新的问题需要解决。

终于在今早接近10点的时候，OneDrive的服务终于全部恢复正常。

也就是说，此次OneDrive故障处理用时接近12小时，幸亏是周末晚间，不然必然会引发很多依赖Win10工作的人士更大的不满。
