据外媒报道[1]，曾经被视为开源先驱的德国慕尼黑市，在尝试了 15 年的 Linux 和开源软件后，最终还是撑不下去了，正式决定重返 Windows。

该市议会已经以 50：25 投票通过，将拿出 8900 万欧元翻修 IT 基础设施。其中，4930 万欧元（约合 3.86 亿人民币）用于将市政公共电脑全部切换到 Windows 10 操作系统，还有 3970 万欧元用于 IT 经费配套其它 IT 类工作。部署工作预计将于 2020 年完成。

市议会称，相比使用基于 Linux 的系统，切换到 Windows 将能让源兼容应用和硬件驱动变得更容易，也能节省必须并存 Windows 和 Linux 的费用。（引自开源中国）

以下摘录自 Solidot ，整理了近十年来慕尼黑与 Linux、微软之间的「恩怨」。

开源城市后续发展：慕尼黑继续，维也纳后退 （2008 年 06 月 05 日）

德国慕尼黑市议会在 2003 年决定抛弃 Windows 和 MS Office，全面换用自由软件；其后奥地利维也纳政府也在 2005 年选择了一个 Linux 发行版。几年过去了，这些开源城市的状况如何？

慕尼黑继续执行它的开源政策，他们甚至自己开发了开源软件——WollMux。但维也纳却退回到 Windows 的怀抱，将耗资 800 万欧元迁移到 Windows Vista 系统。

慕尼黑迁移到 Linux 的计划超过预期（2011 年 12 月 19 日）

德国慕尼黑市议会在 2003 年决定抛弃 Windows 和 MS Office，全面换用 Linux 和开源软件。现在 LiMux 项目宣布超过了目标，慕尼黑已经将 9000 台 PC 迁移到 LiMux 客户端，而原计划是到 2011 年迁移 12,000 - 15,000 台 PC 中的 8500 台。Microsoft Office 也几乎全部被卸载，安装了 OpenOffice.org 3.2.1。剩余的 3,000 台 PC 将在明年迁移到 LiMux。

慕尼黑换用 Linux 后节省 4 百万欧元[2] （2012 年 03 月 29 日）

慕尼黑市长乌德Christian Ude称，该市的 IT 设施自从 Windows NT 和 Office 迁移到 Linux 和 OpenOffice 后节省了 400 万欧元，与此同时每月的故障单数量从 70 减少到 46。慕尼黑节省 280 万欧元的软件授权费，由于 Linux 与 Windows 7 相比硬件需求较低，因此又节省了 120 万欧元的硬件升级费用。

慕尼黑如何拒绝鲍尔默赶走微软[3] （2013 年 11 月 24 日）

和微软分手很难，只要问问 Peter Hofmann 就知道了。Hofmann 负责德国慕尼黑市从 Windows 和 Office 迁移到开源替代的项目。该项目花了十年才完成，期间微软 CEO 鲍尔默Steve Ballmer甚至亲自游说市长但遭到无情拒绝。

慕尼黑称迁移到开源项目节省了一千万欧元，Hofmann 强调该项目的目的从来不是为了钱而是为了自由。他说，如果你做这一切是为了钱，那么随后肯定会有人指出你的成本计算不正确。他称，慕尼黑迁移到开源替代的主要目的不是钱而是独立。独立意味着远离私有的闭源软件如 Windows 和 MS Office。慕尼黑议会在 2002 年下令研究从 Windows 迁移到 GNU/Linux OS 和 OpenOffice 的可行性，2004 年迁移正式展开，计算机系统迁移到定制的 Ubuntu  发行版 LiMux 和 OpenOffice。

德国慕尼黑考虑用 Windows 替换 Linux[4] （2014 年 08 月 19 日）

德国慕尼黑市用了十年时间才用Windows和Office迁移到开源替代LiMux和OpenOffice。现在，由于使用中遇到的各种问题，尤其是来自慕尼黑市长大人Dieter Reiter的抱怨，该市正在考虑回到微软的怀抱，但议会仍然在坚持，认为对LiMux的批评只属于个人意见（德文）。慕尼黑副市长Josef Schmid告诉《南德意志报》，用户的投诉促使该市重新考虑终端软件。80%的慕尼黑市工作人员在办公室里使用LiMux操作系统，Schmid声称工作人员多数都饱受开源软件之苦。刚刚当选市长的Dieter Reiter是该市开源计划的反对者，认为开源技术落后于微软，存在互操作性和软件兼容问题。

慕尼黑市长透露返回 Windows 的初步费用[5] （2014 年 10 月 17 日）

德国慕尼黑市用了十年时间从 Windows 迁移到开源替代品 Linux，但新上任的市长 Dieter Reiter 则希望回到 Windows 的怀抱。市议会还没有决定，它计划先进行研究，评估下哪种操作系统和软件——包括私有和开源——最能适合其需求。现在，市长Dieter Reiter 回应慕尼黑绿党的询问，透露了返回 Windows 的初步费用。Reiter 称，迁移到 Windows 7 将需要替换 1.4 万工作人员所有的电脑，所需费用预计为 350 万欧元，这一数字没有包含软件许可证和基础设施费用。Reiter 说，迁移到 Windows 8 更贵。他指出，返回到 Windows 意味着将一笔勾销迁移到 Linux 和 OpenOffice 的 1400 万欧元投资，正在实现的项目，支持，培训，Linux 特定软件的授权，等等都将需要被搁置。Reiter 还透露，迁移到 Linux 节省了 1100 万欧元的软硬件费用，因为 Linux 操作系统的硬件需求没有较新版本的 Windows 高。

慕尼黑讨论放弃 Linux 转投 Windows 10  （2016 年 11 月 10 日）

德国慕尼黑市花了十年时间从 Windows 和 Office 迁移到开源替代品——基于 Ubuntu 的 LiMux 和 OpenOffice。现在，慕尼黑市的政客正在辩论是否放弃 Linux 再次转投微软的怀抱——这一次是 Windows 10。慕尼黑市政府曾是拒绝 Windows 的最大组织之一，时任微软 CEO 鲍尔默Steve Ballmer甚至亲自游说市长却遭到无情拒绝。但现任市长 Dieter Reiter 委托的一份报告则建议向所有政府部门提供 Windows 10 和 Microsoft Office，给予工作人员选择是使用 LiMux 还是 Windows。

慕尼黑计划 2020 年切换到 Windows  （2017 年 02 月 14 日）

德国慕尼黑市在 2003 年宣布 1.4 万台政府电脑将从 Windows 和 Office 切换到开源替代 LiMux 和 OpenOffice，2013 年它完成了切换。但仅仅过了几年 Windows 又准备回归。慕尼黑行政和人事委员会上周推荐重组 IT 设置，到 2020 年全部切换到基于 Windows 的客户端架构。慕尼黑市在使用开源替代中面临的一个严重问题是兼容性问题，人力资源部门使用的甲骨文和 SAP 系统都需要 Windows，展示时非 Windows 也会遭遇问题。欧洲自由软件基金会主席 Matthias Kirschner 认为，这些问题不是使用开源软件导致的，而是管理和组织不善的问题。慕尼黑市政府雇员在使用中大部分的抱怨与旧版本软件相关，是组织问题导致了缓慢升级。

慕尼黑市 IT 负责人对回归 Windows 感到惊讶  （2017 年 03 月 12 日）

慕尼黑市计划到 2021 年重新投入微软软件的怀抱，该市的 IT 负责人 Karl-Heinz Schneider 对此决定表示惊讶，称没有令人信服的技术理由抛弃 Linux 和 LibreOffice 重新使用 Windows 和 Microsoft Office。Schneider 称，慕尼黑已经解决了 Linux 上运行业务线软件和与外界交换文档的兼容性问题。这些兼容性理由是该市政客决定重新使用微软软件的关键理由。他指出他们已经解决了兼容性和互操作问题，使用 LiMux 和 LibreOffice 不再存在大的技术问题。他的说法呼应了慕尼黑绿党和自由软件欧洲基金会对于抛弃 LiMux 的批评，两个组织认为 LiMux 是慕尼黑 IT结构性和组织问题的替罪羔羊。

慕尼黑将在 2020 年切换到 Windows （2017 年 11 月 14 日）

慕尼黑市议会的行政委员会决定在 2020 年切换到 Windows。社民党议员 Anne Hübner 称，慕尼黑因为决定使用 Linux 和 LibreOffice 脱离微软的魔爪而闻名于开源世界，但计划从没有真正实现。Hübner 称该市一直挣扎于 LiMux 的普及，用户不满意，而公共部门的软件基本上只支持 Windows 。她估计 800 个左右程序中大约有一半不支持 Linux，其它的程序则需要大量的努力和权宜方法。她说在寻找变通方法上的投资和努力不怎么成功。慕尼黑市议会将于 11 月 23 日就迁移到 Windows 举行投票，占议会多数的社民和保守党联盟已经表示支持，最终结果预计于委员会的结果一致。

慕尼黑从 Linux 切换到 Windows 10 将花费 5000 万欧元（2017年11月24日）

德国慕尼黑市透露，从 Linux 切换到 Windows 10 将需要花费 5000 万欧元。慕尼黑市计划花 8900 万欧元翻修 IT 基础设施，其中 4930 万欧元用于 Windows 10 客户端系统，310 万欧元用于测试和培训。慕尼黑市曾因为从 Windows 切换到 Linux 而闻名。市议会称，相比使用基于 Linux 的系统，切换到 Windows 将能让源兼容应用和硬件驱动变得更容易，也能节省必须并存 Windows 和 Linux 的费用。在切换到 Linux 后，议会仍然有五分之一的 PC 运行 Windows，原因是部分应用程序只能运行在 Windows 上。
