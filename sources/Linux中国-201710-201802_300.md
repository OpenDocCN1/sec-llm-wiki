# 【每日安全资讯】Firefox新功能测试：可警示网站是否遭遇黑客攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609906&idx=4&sn=ba1f54a3863e9a335fdc6b5c80325019&chksm=bdce83348ab90a228ffa529efd0ddb1b9d687f9a7481ab85424bfc7ecbf95f39e32ab086fb8d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609906&idx=4&sn=ba1f54a3863e9a335fdc6b5c80325019&chksm=bdce83348ab90a228ffa529efd0ddb1b9d687f9a7481ab85424bfc7ecbf95f39e32ab086fb8d&scene=27#wechat_redirect)

不久前，Firefox Quantum 浏览器引入了一些新特性和安全改进。不过现在看来，该公司还计划增添更多的功能 —— 比如发现某个要访问的网站被黑客入侵、成为了数据泄露的受害者之后，Firefox 就会向你发出警告。据悉，Mozilla 会采用“Have I been Pwned”网站提供的数据 —— 该网站提供了数据泄露的索引，如果用户的凭证在黑客攻击中被攻破，就会通知他们。  

![](../Images/34c17580c9a06e801c7ac17a486d5420.png)

虽然这项功能仍处于早期阶段，但是感兴趣的网友们可以前往 Github 编译，并将它添加到 Firefox 中体验一番。需要指出的是，目前该功能仅使用与 Firefox 开发版。  

![](../Images/a6ed63b0453203eea0b8c349c2f671fa.png)

昨天，“Have I been Pawned”安全专家 Troy Hunt 在 Twitter 上宣布了这则新消息。此前已有许多网站遭遇过数据泄露，但目前暂不清楚 Mozilla 会何时向用户正式推出这项功能。
