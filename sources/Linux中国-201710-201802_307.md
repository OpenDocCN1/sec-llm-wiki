# 【每日安全资讯】Linux 4.14 发现能导致数据丢失的严重 Bug

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609895&idx=4&sn=3b311e2c55c62261ea85377d95b1d608&chksm=bdce83218ab90a3793a3e05817566b382ff3c7ec849958e02c9c9e6f5c11a5411151d1fcc7e6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609895&idx=4&sn=3b311e2c55c62261ea85377d95b1d608&chksm=bdce83218ab90a3793a3e05817566b382ff3c7ec849958e02c9c9e6f5c11a5411151d1fcc7e6&scene=27#wechat_redirect)

多名 Bcache 用户在邮件列表和 Gentoo 的 Bugzilla 上报告，他们在更新到 Linux 4.14 后发生了文件系统损坏，数据全部丢失的严重事故。如果数据没有备份的话这无疑将会是灾难。Bcache 是块缓存(block cache)的缩写，允许将较快的储存设备如 SSD 作为较慢的存储设备如机械硬盘的读写缓存使用，它充当了一种本地加速器来改进性能。Bug 是在 74d46992e0d9 中引入的，稳定版内核维护者 Greg Kroah-Hartman 表示将会尽快释出更新。
