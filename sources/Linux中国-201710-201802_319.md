导读

数值计算并非 zsh 的强项，但应付一些简单的场景还是没问题的。并且 zsh 提供一个数值计算库，里边有一些比较常用的数学函数。

\[1\]整数和浮点数类型

Zsh 中通常不用指定变量类型，但也可以指定。对数值计算来说，区分整数和浮点数是很重要的，不指定变量类型会带来不方便。

```
1.  `# 整数`
    
2.  `% integer i=123`
    
3.  `# (t) 用于输出变量类型`
    
4.  `% echo ${(t)i}`
    
5.  `integer`
    
6.  
    
7.  `# 浮点数`
    
8.  `% float f=123.456`
    
9.  `% echo ${(t)f}`
    
10.  `float`
     
11.  
     
12.  `# 注意一旦指定了变量类型，类型就不会变了，除非再重新指定其他类型，或者用 unset 删除掉 `
     
13.  `# 如果把浮点数赋值给整数变量，会取整`
     
14.  `% i=12.34`
     
15.  `% echo $i`
     
16.  `12`
     
17.  `% a=-12.34`
     
18.  `% echo $a`
     
19.  `-12`
     
20.  
     
21.  `# 整数是 64 位的带符号整数（在 32 位系统下也是）`
     
22.  `% echo $((-2 ** 63)) $((2 ** 63 - 1))`
     
23.  `-9223372036854775808 9223372036854775807`
     
24.  
     
25.  `# 浮点数是 64 位带符号浮点数（在 32 位系统下也是）`
     
26.  `% echo $((-1.79e-308)) $((1.79e308))`
     
27.  `-1.79e-308 1.79e+308`
     
```

\[2\]运算符

数值计算主要是在 `(( ))` 或者 `$(( ))` 中进行的，在 `$[ ]` 或者 `$var[ ]`（可用于数组索引的计算）中也能进行一部分，这里统一使用小括号。

```
1.  `% integer i=123`
    
2.  `% float f=123.456`
    
3.  
    
4.  `# $(( )) 会计算后返回数值`
    
5.  `% echo $((i*f))`
    
6.  `15185.088`
    
7.  
    
8.  `# (( )) 用于判断数值比较的结果`
    
9.  `% ((i < f && i + 1 > f)) && echo good`
    
10.  
     
11.  `# 在 (( )) 中也可以给变量赋值`
     
12.  `# (( )) 中的语法类似 c 语言，变量名前不需要 $，等号两边可以有空格`
     
13.  `% float result`
     
14.  `% ((result = i / f))`
     
15.  `% echo $result`
     
16.  `9.963063764e-01`
     
```

\[3\]数学函数

Zsh 包含了一个数学模块，如果需要使用数学函数，需要先加载 `zsh/mathfunc` 模块。

```
1.  `% zmodload -i zsh/mathfunc`
    
2.  
    
3.  `% echo $((sin(0) + ceil(14.4)))`
    
4.  `15.0`
    
```
