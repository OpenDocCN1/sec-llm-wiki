IBM 、Global Cyber Alliance 和 Packet Clearing House 合作推出了\[1\]免费的 Quad9\[2\] 公共 DNS 服务（9.9.9.9），它将会屏蔽对僵尸网络、钓鱼攻击和其它恶意主机相关联的域名查询。Quad9 的工作与其它免费的公共 DNS 相似，但不会返回已识别为恶意的域名解析。

什么是 Quad9？

Quad9 是一个免费的、递归的任播 DNS 平台，为最终用户提供强大的安全保护，高性能和隐私保护。

![](../Images/f3b24f0311fa04afc75dab4d4720647e.png)

安全性

Quad9 会阻止已知的恶意网域，阻止您的计算机和物联网设备连接恶意软件或网络钓鱼网站。无论何时，一个 Quad9 用户点击网站链接或输入地址到网页浏览器时，Quad9 将该网站与 IBM X-Force 威胁情报数据库中的 400 多亿个网页和图像想对比。 Quad9 还可以从 18 个额外的威胁情报合作伙伴那里获取信息，以阻止最终用户和企业风险面临的大部分威胁。 

性能

Quad9 系统分布在全球 70 多个地点，到 2018 年将有 160 多个地点。这些服务器主要位于互联网交换点，这意味着获得查询答案所需的距离和时间低于几乎任何其他解决方案。这些系统不仅分布在人口众多的地区，也分布在世界各地，这意味着服务不佳地区的用户可以发现 DNS 查询速度显着提高。系统是“任播”的，即查询将自动发送到最近的操作系统。

隐私

系统不会收集个人身份信息。最终用户的 IP 地址不会被存储到磁盘上，也不会被分发到应答的设备之外。 Quad9 是一个专门用于 DNS 服务操作的非营利组织，没有其他的二级收入来源，组织的核心章程是提供安全，快速的私人 DNS。

和 Google 的 DNS 服务相比较

Quad9 相比 Google 的 公共 DNS 服务 8.8.8.8，其响应延迟时间更长，但 Quad9 项目成员表示通过缓存和增加节点将有助于减少延迟。GCA 的 Phil Rettinger 称，Quad9 注重隐私保护，不会记录发出请求的地址，只保存地理位置数据，目的是为了跟踪特定恶意域名相关的请求。
