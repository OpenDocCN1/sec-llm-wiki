如何运作一个技术社区？| COSCon'17特辑

你的开源项目该如何吸引贡献及关注？该如何增加用户？项目社区该如何发展及运营？甚至能够赚钱养活自己？COSCon'17的开源大神们告诉你！


最近和一位长期专注于贡献参与开源社区，并曾任国际顶级开源基金会董事的朋友聊天，谈到了一个有趣的话题：经营一个社区与运营一个社区，有什么区别？到最后我俩并没有达成一致的看法。只能简单的说，他认为经营与运营是两个不同的概念，而我认为运营是包含在经营之中的一部分。

因此，在考虑这篇文章的标题时，我选择了第三个词汇“运作”，当然还可以有很多其他的选择：组织、操盘、培养、发展、贡献、参与，不同的词汇其实代表着不同的心态，不同姿态，以及不同的社区运作状态。

作为一家致力于成为“社区的社区”的组织，开源社在创办至今的3年时间里，与非常多的开源社区、技术社区，结成了紧密的联系，建立了深厚的友谊。在策划这次的“2017中国开源年会”时，我们就想到要把各个社区的朋友请来，大家各自从不同的角度，聊聊自己对于社区的看法，交流各种看到、听到、发起和亲身参与的社区故事。最终希望能够回答一个“没有标准答案的问题”：如何运作一个技术社区？


本次大会关于技术社区的演讲，大致可以分为以下三类：


俯瞰、观察类



林旅强

华为LiteOS运营总监

开源社联合创始人


来自台湾的林旅强，现在在大陆的华为公司工作，在两岸三地都参与过多项开源社区的活动，并与两岸三地开源社区的组织者，有着长期的交流。不同的土壤、不同的文化，生长出了不同的开源社区。在11月18日下午[如何运作一个社区]分会场的第一场演讲，就是由他带来的《对两岸三地/大中华地区开源社区的发展观察》。相信会吸引很多听众的关注。


陈世欣

PyChina发起人

Ahaschool联合创始人


接下来国内开源社区、技术社区大家都非常熟悉的陈世欣，为大家剖析《中国开源社区发展的困境和机会》，作为 PyChina 的创始人，陈世欣在 Python 社区有11年的运营经验，是中国 PyCon 大会的主要组织者。业余时间创办并管理了7个有影响力的社群，每年举办10多次大会，30多次活动，广受好评。由他来为大家分析运营社区的经验教训；公益性社区运营的困难；未来社区的发展机会，以及随着时代的变化，社区运营需要做的调整。相信一定会干货满满，令人期待！


实战经验类


许式伟
七牛云创始人/CEO

七牛云创始人/CEO许式伟，同时也是一位技术大牛，社区大牛，是国内最早的 Go 语言布道师，以及 ECUG 社区的创始人。ECUG 即 Effective Cloud User Group（实效云计算用户组），从2007年第一届在珠海举行至今，已成功举办十届了。作为曾经的 Erlang China User Group，如何转向云计算，以及如何转向更加广阔的分布式架构、Go 语言、容器化、大数据、高效运维等诸多领域？在这一转变的过程中：变的是修为、不变的是境界；变的是焦点、不变的是初心；变的是场景、不变的是突破；变的是视界、不变的是执着；变的是身份、不变的是方向。本次演讲，将为您带来《细数 ECUG 发展历程：一个实效云计算技术干货分享社区的成长故事》。


姜军

Ruby China 管理员

RubyConf China组织者


来自 Ruby-China 社区的姜军，网名 “jasl”，RubyConf China 组织者，致力于 Ruby 语言在国内的推广。作为一线软件开发工程师，业余时间为 Ruby on Rails 等知名框架贡献过代码，也为开源社区贡献过很多项目。这次他带来的题目，是《如何组织一个社区技术会议》，一个非常务实，同时也非常有技术含量的题目。事实上，作为一个已经成功举办了九届的技术大会，其中的经验，尤其是姜军以工程师的思维方式去总结、去尝试改善整个活动组织的过程，是非常有价值的。


王兴宇

Linux 中国开源社区联合创始人

ChinaUnix 社区联合创始人


《如何以翻译贡献参与开源社区》，同样是一个实战性质很强的话题。Linux 中国开源社区联合创始人，ChinaUnix 社区联合创始人，王兴宇也是大家的老朋友了。他将结合 Linux 中国开源社区旗下的 LCTT 翻译组的运营体验，谈谈开源贡献者如何以翻译贡献入门和参与开源活动。对于想要跨入开源社区大门的新朋友，听了这场演讲，相信会有很多的收获。


刘于瑜 Miya

猿生态联合创始人

freeCodeCamp China发起人


另外还有两场含金量很高的”闪电演讲”，也值得关注。一场是来自 FreeCodeCamp 社区的刘于瑜 Miya，为大家介绍 FreeCodeCamp 社区的发展历程，作为一个风靡全球的免费自学编程平台，FreeCodeCamp 中文社区成立于2016年4月，致力于推动“人人皆可编程”, 《创建一个人人都有使命感的社区》，他们在线下推动 Code for City 的故事，一定会引起你的兴趣。


陈欧侃

红旗软件社区专员

Linux人社区管理员


另一场来自开源社的老朋友，北京红旗软件社区专员，Linux 人社区管理员陈欧侃的演讲《如何贡献 Linux 社区-甘苦谈》，因为身体的原因，他将邀请自己的朋友，代替他发表一篇闪电演讲。谈谈他参与社区这十几年来的一些经历和心得，以及怎样为 KDE 桌面环境中文化做贡献，最后介绍一下 Linux 人社区正在力挺的酷猫开发计划和校园联络大使计划。


企业与社区类


李剑峰
优麒麟核心开发者

优麒麟是基于 Ubuntu 的开源操作系统，并且是得到 Ubuntu 认可的官方衍生版，从诞生至今，它经历了怎样的转变，以它为核心的开源社区又是如何抓住机遇、迎接挑战、发展壮大？来自优麒麟团队的李剑峰，将为大家带来《优麒麟社区的成长、机遇与挑战》。


王剑峰
GoodERP 公司总经理


王剑峰曾任 OpenERP 中文社区的社区经理，后来又发起创立了 GoodERP 项目，同时担任 GoodERP 公司总经理。在这次的《GoodERP 开源项目介绍》中，王剑峰将会简述 GoodERP 如何借助 Python 语言的简洁、优雅特性实现 ERP 开源项目的大规模协同开发。希望能够吸引更多专业或业余的 Python 开发者参与到这个项目中来。用更快实现、更易维护的技术来解决身边的问题，一起构建一个“中国用户数最多的开源ERP”。


李成银

360技术委员会委员

360开源委员会主席


互联网企业如何运营开源项目?来自360公司的李成银，前端专家，著名的 Thinkjs 开源软件的作者，将会为大家分享《360开源之路》，在企业内部，如何搭建开源平台，如何帮助开源项目孵化，如何运营开源项目，以及如何通过内外部的各类技术活动来推广开源项目？相信这些话题，将会吸引很多想要开源的企业，前来交流、一起探讨。


钟源

ThoughtWorks 人才品牌总监


最后介绍的一场演讲《技术驱动组织的社区运营与雇主品牌》，看起来似乎离题最远，其实却是从一个非常独特的角度，探讨了企业与社区的关系。在人力资源领域具有9年的从业经验，目前担任 ThoughtWorks 人才品牌总监的钟源，将会给大家分享，作为一个企业的HR，是如何看待社区的？2016年以来，在近零成本的情况下，Thought Worker参与及主办开发者系列活动近150场，平均每4个技术人员就有一个社区讲师。他们是怎么做到的？为何他们要做这些？收益又是什么？会有什么风险吗？如果你是一家IT公司的HR，你一定会想来听听这场演讲。当然，作为社区中人，我们也非常好奇，那些HR们，是如何看待我们的呢？
