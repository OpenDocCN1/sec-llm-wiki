第一天下午：顶级开源项目的成长故事


Apache CarbonData 成长故事


陈亮
VP, Apache CarbonData


陈亮是极少数华人在Apache软件基金会担任顶级项目副总裁的先行者，他有10多年大数据和BI项目开发和实践经验，对大数据开源技术(Hadoop,Spark,CarbonData等)有深入理解。


Apache CarbonData 是一种索引的柱状数据格式，用于快速的大数据分析，如 Apache Hadoop、Apache Spark 等。


CarbonData是中国本土公司发起的首个Apache顶级项目，陈亮将在演讲中分享 CarbonData 背后成长的故事：

1.华为开启CarbonData项目的背景是什么？这个项目的价值是什么？

2.如何决策将CarbonData开源到Apache基金会，以及开源前的准备工作?

3.CarbonData从孵化到毕业成为Apache顶级项目的经验分享？


更多信息，请参考：carbondata.apache.org


摘要: Apache CarbonData是一种新的高性能数据存储格式，针对当前大数据领域分析场景需求各异而导致的存储冗余问题，CarbonData提供了一种新的融合数据存储方案，以一份数据同时支持“任意维度组合的过滤查询、快速扫描、详单查询等”多种应用场景，并通过多级索引、字典编码、列存等特性提升了IO扫描和计算性能，实现百亿数据级秒级响应。


Apache Kylin 成长之路


史少锋

Apache Kylin PMC & Committer

Kyligence技术合伙人/高级架构师



史少锋现任Kyligence技术合伙人，高级架构师，Apache Kylin PMC & Committer; 之前在eBay, IBM, Sybase工作多年，曾参与Eclipse，CloudFoundry等开源项目的开发。


Apache Kylin 是一个开源的分布式分析引擎，提供 Hadoop 之上的 SQL 查询接口及多维分析（OLAP）能力以支持超大规模数据，最初由 eBay Inc. 开发并贡献至开源社区。它能在亚秒内查询巨大的 Hive 表。


从第一个由国人主导并贡献到Apache基金会的开源项目，到今天得到国内外众多公司使用，Apache Kylin一路走来遇到过不少困难，也得到许多人的支持和帮助；演讲者将跟大家分享这个心路历程，带您走进来自中国的神兽项目。


Apache RocketMQ 顶级项目之路

- 产品、社区、生态


冯嘉

Apache RocketMQ 联合创始人


冯嘉，Apache RocketMQ 联合创始人，PMC member/Committer，Linux Open Messaging标准发起人，社区布道者，阿里巴巴高级技术专家，Aliware MQ主架构师。他具有丰富的分布式软件架构、高并发网站设计、性能调优经验，拥有数十项分布式、推荐领域的专利。开源爱好者，关注分布式、云计算、大数据领域。，社区布道者。


Apache RocketMQ 是阿里巴巴贡献给开源社区的消息中间件项目，是一款分布式的消息和流数据平台。


RocketMQ是阿里巴巴在2012年开源的第三代分布式消息中间件，起源于阿里巴巴中间件技术部，以其高性能，低延时和高可靠的特性承载了历年双十一交易峰值（2016年为17万笔/秒），在整个生产链路上都有着稳定和出色的表现。同时，随着RocketMQ进入Apache，整个生态已经覆盖了大数据，流计算，日志等领域，众多的集成项目让RocketMQ有了连接Spark，Flume，Ignite，Storm等平台的能力。本次分享会从产品、社区、生态着手，重点讲述RocketMQ在孵化过程中的那些故事。

第二天早上：项目技术介绍


Apache Griffin 大数据质量方案介绍


郭跃鹏

Apache Griffin项目发起者&Committer

eBay资深主任工程师


郭跃鹏，Apache Griffin项目发起者和 Committer，eBay资深主任工程师。有超过15年的数据服务行业经验，曾就职于华为，目前在eBay大数据服务部门,专注于大数据平台上提供稳定及时有效的数据服务应用架构设计和开发。


Apache Griffin 是构建的 Apache Hadoop 或 Apache Spark 之上的数据质量保证平台。


在大数据、云计算、流式计算为基础的分布式环境下,数据本身的质量问题越发重要。Apache Griffin 项目是eBay发起并贡献给Apache社区的数据质量方案。它试图提供一套可扩展,可伸缩的框架来解决数据质量的几个典型问题:如数据的精确性问题、一致性问题、合法性问题、时效性问题、唯一性问题,以及完整性问题。本次主题主要讲解面临streaming和batch的企业数据环境, Apache Griffin是如何通过提供一整套的流程来定义,测量并汇报数据质量, 以试图解决数据质量问题。同时介绍架构设计, 核心组件的设计与考量等等。最后会通过自助服务来阐述Apache Griffin在eBay 1.2PB的数据环境下的应用场景及流程.

Apache Weex 极致体验优化: 长列表渲染架构的演进


冯成晓

阿里巴巴无线技术专家

Weex核心开发者


冯成晓（隐风），阿里巴巴无线技术专家，2013 年加入阿里巴巴无线事业部，一直致力于提升 Web 在客户端内的性能和用户体验，致力于 Web 开发效率和 Native 体验的融合， 参与设计和开发了阿里内无线 Hybrid 框架 WindVane，同时也是阿里移动动态化解决方案 Weex 的核心开发者之一，目前主要负责 Weex 的整体交互体验创新， 平时关注的技术领域主要有 iOS 和 Web，闲暇时喜欢玩游戏。


长列表是移动平台上非常常见的一种展现和交互形式， 本次分享主要回顾 Weex 在长列表渲染架构上经历的多次技术变迁，介绍其中遇到的困难和解决方案， 对 Weex 最新长列表组件 recycle-list 进行原理上的深入剖析，最后通过和各个平台的多项性能指标对比，总结目前 Weex 在长列表渲染上的体验提升和未来发展。
