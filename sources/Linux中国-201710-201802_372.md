分会场  

  

**顶级开源项目成长的故事**

  

来自本土孵化的 Apache 项目一线工程师和主管为你分享在世界久享盛名、以高质量著称的 Apache 基金会治理下是如何一步一步艰难砥砺而行，终成正果的历程。他们有：

**Apache CarbonData** 是一种索引的柱状数据格式，用于快速的大数据分析，如 Apache Hadoop、Apache Spark 等。

**Apache Griffin **是构建的 Apache Hadoop 或 Apache Spark 之上的数据质量保证平台。

**Apache Kylin Apache Kylin™**是一个开源的分布式分析引擎，提供 Hadoop 之上的 SQL 查询接口及多维分析（OLAP）能力以支持超大规模数据，最初由 eBay Inc. 开发并贡献至开源社区。它能在亚秒内查询巨大的 Hive 表。

**Apache RocketMQ **阿里巴巴贡献给开源社区的消息中间件项目，是一款分布式的消息和流数据平台。

**Apach Weex** 历经波折，终于选择在 Apache 生根，中间经历了什么？这个跨平台的移动开发平台如何筚路蓝缕，走向未来。

除了上述几个立足于全球顶级社区的本土原生开源项目之外，我们更请到了 DevOps 领域里的**全球顶级开源项目 Jenkins 的创始人 K.K. (Kohsuke Kawaguchi) **与你分享**黑客觅食记 -- 围绕开源项目创建一家公司**。你想和他面对面交流吗？

**压轴好戏：主题演讲大神面对面**

  

  

![](../Images/2d63584c61c8aa950fff8646171b0b4a.png)Nuritzi SanchezGNOME基金会主席

  

  

GNOME 是目前 Linux 主流默认的桌面系统，在开源界有着独特的地位，在全球拥有无数拥护者，Gnome 基金会新晋董事会主席分享她在开源社区运营方面的经验。

Nuritzi 已经是第二次当选为 GNOME 基金会的委员会主席，她是 GNOME Engagement 团队的核心成员，是 GNOME SF（美国旧金山的线下活动）的创始人，Nuritzi 所工作的公司叫做 Endless，是一家致力于让计算机能够无障碍的被访问，Nuritzi 带领团队为 Endless 做国际化，且维系一个健壮的社区，她对技术充满热情、善于社交、并且认为自由和开源软件对于改变世界起到了非常基础的作用。

  

  

![](../Images/9bb2ccaff2f433d476ac0ea35c28dccf.png)NiclasHedhmanApache软件基金会前任副总裁

  

  

房间里的大象，人们对于开源的态度是熟视无睹。铁屋子需要有人开一道缝，见一道光，那么揭开这道缝的无疑只能是前 Apache Ploygene 副总裁—NiclasHedhman。 以下是 Niclas 自己关于社区参与方面的介绍：

我创立了 OPS4J（Java 开放参与软件），致力于真正的开放式开发场景，在此场景下人人皆平等，没有任何的政治。OPS4J 还是相对成功的，特别是针对 OSGi 技术来讲，有上百的贡献者开发了几十个大大小小的项目。我一直在大量参与 Apache 软件基金会的工作，事实上从其创立之间就参与其中，参与贡献了十几个项目，大量参与孵化的工作超过 5 年，刚刚从 Apache Polygene VP 的位置上退下来。

Niclas 依旧展示其独有的洞察力，这次给我们带来的题目是《技术宅神们的进化》

在过去的 35 年间，我们看到了技术宅神们的崛起，以及和技术宅神们差一些的崛起，这些人们的日渐增多背后的原因是什么？这些宅神们的日常是什么样的？经常在哪里聚会？有何特征？激励他们的方式是什么？在如此不稳定的环境中，那些技术宅神获得了世人的承认和青睐？

我之所以这么描述，是希望以诙谐幽默的方式来进行轻松的表达，但是话题本身是非常严肃的，我试图告诉大家我们这个行业中所存在的严重浪费情形。计算机工程的黄金时代即将终结，那么代替我们的将会是什么？

Niclas 对于自己此次演讲的介绍和解释：是的，我打算以幽默的方式表达，之所以这么做是想突出的表现软件开发这个行业的混乱，目的是希望大家能够停下来，仔细的想象...

智人（Homo Sapiens）的意思是：智慧的人，或现代人，具备能力使用工具，懂得沟通，可以精通多门语言，而且还懂得区别对待。

宅神（Homo Nerdis ）是一种新的人种，从智人进化过来的，具备制造机器，而这些机器可以使用工具并懂得沟通，精通的语言是使用各种各样的机器语言。

宅神又有多个子分类，有代码宅神、编程宅神、开发宅神、脚本宅神、DevOps 宅神等等。

这次分享涵盖了如何从一个代码撰写者蜕变为程序员，然后进化为开发者，脚本小子是如何思考的？他们懂得撰写软件吗？DevOps 所思考的是能够运行的软件才是创建应用。这是一个令人困惑的世界，特别是在 20 世纪 90 年代初之后，而且行业的炒作正在愈演愈烈，我的假设是“IT”或“软件工程”现在太广泛了，以捕捉到正在发生的事情的相关性。

我也会涵盖诸如“程序员让电脑运行的更快”、“开发者接手了程序员的工作，并让它运行的慢下来”、“DevOps 则是试图让其即使是在 100 台电脑上运行也会变得更慢“。最后我则会提到目前很多人都存在的问题，这些人包括来自 Twitter、Google、以及阿里巴巴等大型互联网公司。

因此我预测未来我们的这个行业正在面临覆灭，愚蠢的人们所创建的技术非常的难用，需要比他们聪明好几倍的人才能使用。所有的这一切，都时不可待，现在就得改变。

  

![](../Images/9e11ff6c8959bfc69ae47f410f4bcf96.png)霍泰稳极客邦科技创始人兼CEO

  

有没有人知道，InfoQ 是由社区所驱动的？所有的文章和新闻、电子书均是来自志愿者、爱好者的支撑？霍泰稳先生一向称自己是社区的运营者！你想不想知道一家逼格如此之高的媒体网站的内容和质量是如何把控的？而且还是由志愿者所组成的社区模式？

霍泰稳先生是 InfoQ 中文站的联合创始人兼 CEO。有多年的软件开发经验和媒体从业经历，以技术传播为己任，关注企业软件开发领域的变化与创新。曾先后参与《程序员》杂志、《MSDN 开发精选》杂志、《开源大本营》图书和《开源技术选型手册》2008 版图书的策划编辑工作。

2014 年创办极客邦，收购 InfoQ 中国业务，并通过StuQ斯达克学院（在线教育平台）、EGO超级极客邦（高端技术人组织）等业务致力于构建全球最具影响力的技术人学习和交流平台，让技术人学习和交流更简单。

![](../Images/a35d1d5c0d74bc5becb7511ddb227cdc.png)梁莉 KylieFreeBSD基金会董事

  

FreeBSD 的社区治理模式是出了名的严苛、精心而著称，是很多社区开发模式取经的对象，这其中背后的机理，绝不能错过。走进 FreeBSD 及背后的基金会 FreeBSD，一个世界上有历史的（1993 年），最大的也最成功的开源项目之一 。如果你玩过索尼的 PlayStation 4，那么恭喜你使用过 FreeBSD；如果你拥有一款 iPhone，哈，你也和 FreeBSD 有了亲密接触。那么这个开源项目是怎么运行的呢？FreeBSD 基金会又在中间扮演了个什么角色？作为国人怎么走进这个开源社区的呢？FreeBSD 基金会唯一一位中国董事梁莉（Kylie Liang) 将在 2017 中国年会上分享她是如何走进 FreeBSD 社区以及背后的基金会。

现任微软云计算与企业事业部高级产品经理，主要负责开源软件（比如 Ansible，容器）在公有云以及私有云的业务。在加入微软之前，梁莉在英特尔开始了她的职业生涯，领导过内核驱动的开发以及开源虚拟化软件等项目。梁莉拥有中国科学院计算技术研究所的工学硕士学位。同时梁莉也于 2016 年被选举成为 FreeBSD 基金会董事。梁莉已积极投身于开源领域数年，与开源社区有紧密合作，她将在中国和当地社区共同推动 FreeBSD 项目的开发以及推广。
