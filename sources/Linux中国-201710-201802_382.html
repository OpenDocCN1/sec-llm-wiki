谈到程序员，大家的第一印象也许是话少闷骚且呆板…总之，溢美之词鲜有人会用在程序员身上。

然而更贴近事实的情况是，程序员的地位早已是水涨船高。

在不久前结束的 2017 杭州云栖大会上，一位杭州阿姨在现场招婿，并且点名只要程序员，这一消息引起了圈内外的一阵热议。两年类似的新闻在最近两年屡见不鲜，程序员早已摆脱了曾经的“弱势”群体形象，而这一群体也已经摇身一变成为众人眼中神圣而又伟大的职业。

的确，程序员拥有魔术师般的神奇，指尖代码就能改变世界，而同样，他们的世界也并非波澜不惊。

据不完全统计，全球有数千万程序员，竞争的激烈程度可见一斑，坊间甚至有传出这么一条鄙视链：写汇编的鄙视写 C 的，C 程序员的鄙视 C++，C++ 鄙视 Java 和C#，Java 和 C# 相互鄙视，Python 和 Ruby 相互鄙视，Scala、JRuby、Clojure 一起鄙视 Java …

同是天涯沦落人，相煎何太急！

不仅如此，每位程序员成长的背后都一段血泪史：

五花八门的编程语言，哪个最热门？

什么行业、什么岗位的薪资更高？

各个专业领域的技术趋势是什么？

如何才能更快速的踏上技术进阶之路，拓展自己的视野，走向人生巅峰？

……

何以解忧？正所谓知己知彼百战不殆，唯有更懂自己、更了解行业，才能更快更好的提升自己！

而现在，程序员是时候发出自己的声音了。
