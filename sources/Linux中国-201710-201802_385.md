# 【每日安全资讯】谷歌为电子邮件用户提供硬件密匙 保护他们免遭黑客毒手

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609749&idx=5&sn=3a76db221d44fdacb8e437685abe1648&chksm=bdce8c938ab90585cd50ee11f926964a53f3447dfd2ace969a093c917d933b072dce35cbbd0a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609749&idx=5&sn=3a76db221d44fdacb8e437685abe1648&chksm=bdce8c938ab90585cd50ee11f926964a53f3447dfd2ace969a093c917d933b072dce35cbbd0a&scene=27#wechat_redirect)

密码不完美，任何在数据泄露后不得不重新设置密码的人都有切身体会。但生物识别技术也并非完全可靠。谷歌也知道这一点，随着黑客和骗子威胁越来越多，甚至是国家和政府支持的攻击者，Google电子邮件用户也有可能发生这种情况。

现在，搜索巨头认为它可以阻止最复杂的黑客。搜索巨头希望为风险账户提供一个全新的保护层，而不是取消密码。这个保护层就是售价40美元的2个USB密匙，每个约20美元，是Google所谓的高级保护计划的核心，谷歌公司打算让用户电子邮件帐户尽可能免遭黑客毒手。

这种U盘行为很像你收件箱的物理键。无论何时登录帐户，Google将提示使用密码卡作为双因素身份验证设备。将其插入USB接口或按下蓝牙按钮，用户将被授予对帐户的访问权限。即使是最厉害的黑客在没有物理密匙的情况下，也无权访问用户帐户。

尽管任何人都可以注册该计划，但谷歌计划首先将重点放在被国家赞助黑客攻击的帐户上。所以政界人士，记者和商界领袖都会先在优先名单上，其他人可能要排队等待一会儿了。
