# 8 家企业上榜！Gartner 新发 OpenStack 全球竞争格局报告

      云计算市场竞争最为激烈的莫过于 OpenStack 市场。据悉，全球 OpenStack 基金会会员多达 145 个，仅白金会员和黄金会员就有 31 个。那么，问题来了——它们当中哪些是战略性投入，哪些是跟随性投入，这些企业的 OpenStack 实力如何，市场竞争格局怎样？

  

近日，Gartner 发布了《竞争格局：2017年 OpenStack 分发和支持服务市场》（Competitive Landscape: OpenStack Distributions and SupportServices Market,2017）报告（以下简称 Gartner 2017 OpenStack 竞争格局报告），在分析 OpenStack 全球市场趋势的同时，还圈出了8家OpenStack企业并点评竞争格局。可以说这是 145:8，这 8 家企业按照公司名称英文字母排序分别是：

  

Canonical，EasyStack（易捷思达），HuaWei（华为），Mirantis，Oracle、Red Hat、SUSE、VMware。

意味着什么呢？

  

  

***1*** ****145:8 是怎样激烈的竞争格局？****

  

  

我们先来普及一下Gartner的主要报告类型：魔力象限（Magic Quadrant）、竞争格局（Competitive Landscape）、市场指南（Market Guide）、酷供应商（Cool Vendor）、技术成熟度曲线（Hype Cycle）等。

  

Gartner 用魔力象限这一模型评估企业的执行能力和视野宽度，一般情况下，偏重于成熟期产品的企业市场地位，这一阶段的产品解决方案最为稳定，市场竞争也最为激烈。

  

而相对的，Gartner 在新兴市场一般用市场指南报告，此阶段 Gartner 认为对企业做竞争定位分析意义不大，更重要的是定义这个市场本身，以便客户对新兴技术进行投入判断。

  

而介于之间的应该就是 Gartner 竞争格局报告了。

  

一般情况下，新兴市场走向成熟阶段，企业产品方案相对稳定，市场竞争趋于明朗化。这时，全球第一梯队已经崭露头角，竞争力强弱已然显现，但还没有用魔力象限模型去逐一分析第一梯队企业各自的市场地位。换句话说，竞争力报告就是 Gartner 在一片混战的企业当中画了一个圈，将有技术含量、有市场地位、符合发展趋势的第一梯队企业展现在客户面前，便于客户通过这些代表性企业的产品特性、技术实力、投入方向、生态建设甚至客户案例去了解整个市场的趋势，并帮助客户按照自身业务需求和未来市场预期去选择相匹配的企业。

  

145:8，可以说这 8 家企业就是 Gartner 从全球混战的 145 家提供 OpenStack 技术的企业当中圈出的第一梯队。而且 Gartner 在 2017 OpenStack 竞争格局报告里也说了，随着 OpenStack 的发展，市场整合不可避免。毕竟每个市场不可能容下所有玩家，玩家的集中化意味着市场的成熟化，对于保护客户投资来讲也是一种良性循环。

  

  

***2*** ****中国企业 EasyStack 和华为何以上榜？****

  

  

值得一提的是，OpenStack 全球第一梯队的 8 家企业中有 2 家中国企业——EasyStack 和华为。

  

是否在你意料之中？

  

这份 Gartner 2017 OpenStack 竞争格局报告中提到重要市场发现之一就是，中国市场有越来越多的客户对 OpenStack 感兴趣，以及活跃的中国 OpenStack 供应商。

  

根据最近的 OpenStack 用户调查，中国在 OpenStack 部署数量方面排名全球第三（与加拿大持平）。在 11 月初即将在悉尼召开的 OpenStack Summit 中 SuperUser（超级用户）的评选中，入围的四家当中就有三家中国企业：中国银联，中国铁路和腾讯。目前，近一半的 OpenStack 黄金会员是中国公司，三家中国电信运营商都加入黄金会员，这表明 OpenStack 在运营商基础架构中的重要地位。

  

从这个思考维度来看，2 家中国企业入选基本客观地体现了中国在全球市场的格局。

  

Gartner 2017 OpenStack 竞争格局报告还提到另一个重要发现，即 OpenStack 和容器的集成趋势，并强调了容器（特别是 Kubernetes）和 OpenStack 从社区、技术、企业到案例上的紧密配合，以便从业务应用和基础设施两个层面来共同配合更好地满足客户的需求。应该看到，随着 OpenStack 基金会关注更多地开源社区和项目，如 Cloud Foundry、Kubernetes、Apache Hadoop / Spark 等，头部 OpenStack 企业的战略也在趋于多样化，为其他开源项目和产品提供更多的支持服务。

  

因此 Gartner 的结论是，未来是否具备竞争力将取决于企业将 OpenStack 与其他相关软件垂直整合的能力，以及产品化能力和方案组合的能力。

  

先来看看 EasyStack。

  

从 Gartner 的这个论断来看，EasyStack 成为 8 大企业之一，并不只是因为在 OpenStack 核心代码贡献中多次名列全球 TOP10，也不只是因为拿下了中国 OpenStack 十大用户当中的 50%，从而形成了从技术研发到案例落地的商业闭环。更重要的一点在于，它的技术产品战略也紧扣多样化开源趋势，率先推出了垂直整合的相关产品。

  

Gartner 2017 OpenStack 竞争格局报告中就提到，除了 OpenStack 之外，EasyStack 还进入了 Kubernetes、Docker 和 Ceph 等其他开源软件领域，在今年推出了基于 Kubernetes 的轻量级容器集群、企业级 Container Linux，基于 OpenStack 的人工智能平台、行业云平台，混合云平台以及针对中小型企业的超融合产品 ESCloud Express，可以说较为全面的产品线已经将未来趋势垂直整合其中。

  

再来看看华为。

  

电信运营商的广泛采用和市场的进一步扩大，是 Gartner 2017 OpenStack 竞争格局报告中第三个重要的市场发现。Gartner 认为，除了 NFV 之外，运营商市场大热的边缘计算、IoT 和 5G 同样可以为 OpenStack 企业带来新的机会。

  

华为的入选除了它是 8 个白金会员中唯一一个中国企业，同样在多项 OpenStack代码贡献排名当中名列 TOP10 之外，华为为德国电信、西班牙电信、Orange、中国电信和华为公有云自营公司提供了基于 OpenStack 公有云。毫无疑问，运营商市场一直是华为的优势市场。

  

  

***3***** **Oracle 和 VMware 上榜在意料之外？****

  

Oracle 和 VMware，有点出乎意料？两个典型的在封闭商业环境中成功的软件企业，怎么会投入开源 OpenStack 的怀抱？应该说，这份竞争力报告因此也透露出闭源拥抱开源已是大势所趋。  

  

看看微软最近的转变就完全释然：那个几年前还和 Linux 剑拔弩张的企业，在云时代突然 180 度大转弯，开始拥抱开源。因为，微软已经意识到在 Azure 公有云上，超过一大半的应用都跑在 Linux 之上。而在这个多云的世界里，包括 OpenStack 在内的更多开源技术更是风雨欲来。

  

VMware从2012年起就加入OpenStack 基金会，并推出VMware Integrated OpenStack（VIO）将两种技术集成为客户提供多种选择，比如将 vSphere 虚机和工作负载导入 OpenStack，以便像 OpenStack 实例一样管理；在 VMware vRealize Suite 云管平台中提供更深入的集成功能；添加 NFV 功能以迎合电信运营商市场。

  

应该说，无论 VMware 是否情愿，在客户选择开源的大趋势下也必然会考虑集成和纳管。

  

Oracle 于 2013 年加入 OpenStack 基金会，Oracle OpenStack 被定位为企业级管理软件，用于部署和管理私有云和混合云。一方面，Oracle 为 OpenStack 投入企业应用支持，诸如支持数据库和 Oracle RAC 的数据库即服务（DBaaS），这也为 Oracle 提供了云原生应用的市场新机会；另一方面，Oracle 也在打将 OpenStack 工作负载迁移到 Oracle Cloud 的主意。不过，不论如何在电信、金融和高教领域还是有了 Oracle OpenStack 的客户，虽然它们可能并非单独购买。

  

总之，在 Gartner 2017 OpenStack 竞争格局报告中，同时出现了 2 家中国企业和 2 家闭源企业，确实是一个值得思考的话题。
