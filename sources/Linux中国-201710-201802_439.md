# 【每日安全资讯】谷歌微软"互殴"：寻找对方软件中漏洞 这是好事吗

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609663&idx=4&sn=75a75c3ddda1190e6dbb73b0c3899cec&chksm=bdce8c398ab9052fb0898fe387480885f3ea1a191605d582fe8fc85d775b0f62299c913d9619&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609663&idx=4&sn=75a75c3ddda1190e6dbb73b0c3899cec&chksm=bdce8c398ab9052fb0898fe387480885f3ea1a191605d582fe8fc85d775b0f62299c913d9619&scene=27#wechat_redirect)

据Engadget报道，从历史上看，谷歌与微软的关系就不太好。谷歌此前曾公开发布过这家竞争对手的软件漏洞，这是可以理解的，而微软显然对此感到十分不满。现在，微软和谷歌的软件漏洞大战已经明面化。微软在谷歌Chrome浏览器中也发现了一个漏洞，虽然谷歌在beta版中修复了漏洞，但公开发行版本用了1个月才解决问题。

![](../Images/9d13a0fa0a2d1067527df44ec5904dfa.png)

  

不过，在Chrome浏览器公开发布之前，谷歌立即在GitHub上发布了修复方案。只是微软表示，虽然这个漏洞修复办法并没有解决问题。该公司认为，在漏洞被公开之前，就应该首先用补丁修复。微软的担忧有一定道理，谷歌花了一个月的时间来修补特殊的Chrome漏洞。对于黑客来说，这让他们有足够的时间来发现和利用它。在浏览器中修复漏洞之前，在GitHub上对漏洞进行修复可能不是最好的方案。

尽管如此，我们是否真的从谷歌和微软的“互殴”中获益呢？当然，这些问题正在被确认和纠正，这是一件好事。而类似友好的竞争当然是有帮助的。但这可能已经超出了“友好”的范围，并在这一过程中开始危及用户安全。也许这两家公司是时候重新考虑他们的方法了。
