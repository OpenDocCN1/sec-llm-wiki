# 【每日安全资讯】东芝受恶意攻击导致NAND生产线停产：预估少生产40万TB容量

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609656&idx=4&sn=523784c96e5abaa55b855565dbb035a6&chksm=bdce8c3e8ab90528626fc3768b0cd352a37c3589b345820f54f4c1c7ca5e7687591f4d1cd2f6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609656&idx=4&sn=523784c96e5abaa55b855565dbb035a6&chksm=bdce8c3e8ab90528626fc3768b0cd352a37c3589b345820f54f4c1c7ca5e7687591f4d1cd2f6&scene=27#wechat_redirect)

援引DigiTimes报道，东芝的NAND部门近日遭受了非常严重的恶意攻击，被迫关闭NAND生产线数周时间，这将导致近阶段公司NAND闪存的供应比较紧张。

![](../Images/2d44135bd08ec9ebcb1141465d590cb6.png)

  

DigiTimes消息称为了清除恶意程序，东芝公司的NAND生产线将停工3-6周时间才能恢复正常供应，预估将减少10万个wafers产量。PCGamesN网站预估假设这段停产时间正常生产，能够带来5000万个芯片或者40万TB的NAND闪存。

近年来由于智能手机和服务器的需求不断增大，NAND的售价也水涨船高。但是由于NAND厂商在生产规模和成本上没有太大的突破，因此供应相对来说偏低的。而最新的3D NAND技术目前只有三星公司投入商用。
