> 这个简单教程教你如何测试你应用的功能。

自动化测试用来保证你程序的质量以及让它以预想的运行。单元测试只是检测你算法的某一部分，而并不注重各组件间的适应性。这就是为什么会有功能测试，它有时也称为集成测试。

功能测试简单地与你的用户界面进行交互，无论它是网站还是桌面应用。为了展示功能测试如何工作，我们以测试一个 Gtk+ 应用为例。为了简单起见，这个教程里，我们使用 Gtk+ 2.0 教程的示例。

基础设置

对于每一个功能测试，你通常需要定义一些全局变量，比如 “用户交互时延” 或者 “失败的超时时间”（也就是说，如果在指定的时间内一个事件没有发生，程序就要中断）。

```
1.  `#define TTT_FUNCTIONAL_TEST_UTIL_IDLE_CONDITION(f) ((TttFunctionalTestUtilIdleCondition)(f))`
    
2.  `#define TTT_FUNCTIONAL_TEST_UTIL_REACTION_TIME (125000)`
    
3.  `#define TTT_FUNCTIONAL_TEST_UTIL_REACTION_TIME_LONG (500000)`
    
4.  `typedef gboolean (*TttFunctionalTestUtilIdleCondition)(gpointer data);`
    
5.  `struct timespec ttt_functional_test_util_default_timeout = {`
    
6.  `  20,`
    
7.  `  0,`
    
8.  `};`
    
```

现在我们可以实现我们自己的超时函数。这里，为了能够得到期望的延迟，我们采用 `usleep`函数。

```
1.  `void`
    
2.  `ttt_functional_test_util_reaction_time()`
    
3.  `{`
    
4.  `  usleep(TTT_FUNCTIONAL_TEST_UTIL_REACTION_TIME);`
    
5.  `}`
    
6.  
    
7.  `void`
    
8.  `ttt_functional_test_util_reaction_time_long()`
    
9.  `{`
    
10.  `  usleep(TTT_FUNCTIONAL_TEST_UTIL_REACTION_TIME_LONG);`
     
11.  `}`
     
```

直到获得控制状态，超时函数才会推迟执行。这对于一个异步执行的动作很有帮助，这也是为什么采用这么长的时延。

```
1.  `void`
    
2.  `ttt_functional_test_util_idle_condition_and_timeout(`
    
3.  `     TttFunctionalTestUtilIdleCondition idle_condition,`
    
4.  `     struct timespec *timeout,`
    
5.  `     pointer data)`
    
6.  `{`
    
7.  `  struct timespec start_time, current_time;`
    
8.  
    
9.  `  clock_gettime(CLOCK_MONOTONIC,`
    
10.  `                &start_time);`
     
11.  
     
12.  `  while(TTT_FUNCTIONAL_TEST_UTIL_IDLE_CONDITION(idle_condition)(data)){`
     
13.  `    ttt_functional_test_util_reaction_time();`
     
14.  
     
15.  `    clock_gettime(CLOCK_MONOTONIC,`
     
16.  `                  &current_time);`
     
17.  
     
18.  `    if(start_time.tv_sec + timeout->tv_sec < current_time.tv_sec){`
     
19.  `      break;`
     
20.  `    }`
     
21.  `  }`
     
22.  
     
23.  `  ttt_functional_test_util_reaction_time();`
     
24.  `}`
     
```

与图形化用户界面交互

为了模拟用户交互的操作， Gdk 库\[1\] 为我们提供了一些需要的函数。要完成我们的工作，我们只需要如下 3 个函数：

◈ `gdk_display_warp_pointer()`◈ `gdk_test_simulate_button()`◈ `gdk_test_simulate_key()`

举个例子，为了测试按钮点击，我们可以这么做：

```
1.  `gboolean`
    
2.  `ttt_functional_test_util_button_click(GtkButton *button)`
    
3.  `{`
    
4.  `  GtkWidget *widget;`
    
5.  
    
6.  `  GdkWindow *window;`
    
7.  
    
8.  `  gint x, y;`
    
9.  `  gint origin_x, origin_y;`
    
10.  
     
11.  `  if(button == NULL ||`
     
12.  `     !GTK_IS_BUTTON(button)){`
     
13.  `    return(FALSE);`
     
14.  `  }`
     
15.  
     
16.  `  widget = button;`
     
17.  
     
18.  `  if(!GTK_WIDGET_REALIZED(widget)){`
     
19.  `    ttt_functional_test_util_reaction_time_long();`
     
20.  `  }`
     
21.  
     
22.  `  /* retrieve window and pointer position */`
     
23.  `  gdk_threads_enter();`
     
24.  
     
25.  `  window = gtk_widget_get_window(widget);`
     
26.  
     
27.  `  x = widget->allocation.x + widget->allocation.width / 2.0;`
     
28.  `  y = widget->allocation.y + widget->allocation.height / 2.0;`
     
29.  
     
30.  `  gdk_window_get_origin(window, &origin_x, &origin_y);`
     
31.  
     
32.  `  gdk_display_warp_pointer(gtk_widget_get_display(widget),`
     
33.  `                           gtk_widget_get_screen(widget),`
     
34.  `                           origin_x + x, origin_y + y);`
     
35.  
     
36.  `  gdk_threads_leave();`
     
37.  
     
38.  `  /* click the button */`
     
39.  `  ttt_functional_test_util_reaction_time();`
     
40.  
     
41.  `  gdk_test_simulate_button(window,`
     
42.  `                           x,`
     
43.  `                           y,`
     
44.  `                           1,`
     
45.  `                           GDK_BUTTON1_MASK,`
     
46.  `                           GDK_BUTTON_PRESS);`
     
47.  
     
48.  `  ttt_functional_test_util_reaction_time();`
     
49.  
     
50.  `  gdk_test_simulate_button(window,`
     
51.  `                           x,`
     
52.  `                           y,`
     
53.  `                           1,`
     
54.  `                           GDK_BUTTON1_MASK,`
     
55.  `                           GDK_BUTTON_RELEASE);`
     
56.  
     
57.  `  ttt_functional_test_util_reaction_time();`
     
58.  
     
59.  `  ttt_functional_test_util_reaction_time_long();`
     
60.  
     
61.  `  return(TRUE);`
     
62.  `}`
     
```

我们想要保证按钮处于激活状态，因此我们提供一个空闲条件函数：

```
1.  `gboolean`
    
2.  `ttt_functional_test_util_idle_test_toggle_active(`
    
3.  `     GtkToggleButton **toggle_button)`
    
4.  `{`
    
5.  `  gboolean do_idle;`
    
6.  
    
7.  `  do_idle = TRUE;`
    
8.  
    
9.  `  gdk_threads_enter();`
    
10.  
     
11.  `  if(*toggle_button != NULL &&`
     
12.  `     GTK_IS_TOGGLE_BUTTON(*toggle_button) &&`
     
13.  `     gtk_toggle_button_get_active(*toggle_button)){`
     
14.  `    do_idle = FALSE;`
     
15.  `  }`
     
16.  
     
17.  `  gdk_threads_leave();`
     
18.  
     
19.  `  return(do_idle);`
     
20.  `}`
     
```

测试场景

因为这个 Tictactoe 程序非常简单，我们只需要确保点击了一个 GtkToggleButton\[2\] 按钮即可。一旦该按钮肯定进入了激活状态，功能测试就可以执行。为了点击按钮，我们使用上面提到的很方便的 `util` 函数。

如图所示，我们假设，填满第一行，玩家 A 就赢，因为玩家 B 没有注意，只填充了第二行。

```
1.  `GtkWindow *window;`
    
2.  `Tictactoe *ttt;`
    
3.  
    
4.  `void*`
    
5.  `ttt_functional_test_gtk_main(void *)`
    
6.  `{`
    
7.  `  gtk_main();`
    
8.  
    
9.  `  pthread_exit(NULL);`
    
10.  `}`
     
11.  
     
12.  `void`
     
13.  `ttt_functional_test_dumb_player_b()`
     
14.  `{`
     
15.  `  GtkButton *buttons[3][3];`
     
16.  
     
17.  `  guint i;`
     
18.  
     
19.  `  /* to avoid race-conditions copy the buttons */`
     
20.  `  gdk_threads_enter();`
     
21.  
     
22.  `  memcpy(buttons, ttt->buttons, 9 * sizeof(GtkButton *));`
     
23.  
     
24.  `  gdk_threads_leave();`
     
25.  
     
26.  `  /* TEST 1 - the dumb player B */`
     
27.  `  for(i = 0; i < 3; i++){`
     
28.  `    /* assert player A clicks the button successfully */`
     
29.  `    if(!ttt_functional_test_util_button_click(buttons[0][i])){`
     
30.  `      exit(-1);`
     
31.  `    }`
     
32.  
     
33.  `    functional_test_util_idle_condition_and_timeout(`
     
34.  `         ttt_functional_test_util_idle_test_toggle_active,`
     
35.  `         ttt_functional_test_util_default_timeout,`
     
36.  `         &buttons[0][i]);`
     
37.  
     
38.  `    /* assert player B clicks the button successfully */`
     
39.  `    if(!ttt_functional_test_util_button_click(buttons[1][i])){`
     
40.  `      exit(-1);`
     
41.  `    }`
     
42.  
     
43.  `    functional_test_util_idle_condition_and_timeout(`
     
44.  `         ttt_functional_test_util_idle_test_toggle_active,`
     
45.  `         ttt_functional_test_util_default_timeout,`
     
46.  `         &buttons[1][i]);`
     
47.  `  }`
     
48.  `}`
     
49.  
     
50.  `int`
     
51.  `main(int argc, char **argv)`
     
52.  `{`
     
53.  `  pthread_t thread;`
     
54.  
     
55.  `  gtk_init(&argc, &argv);`
     
56.  
     
57.  `  /* start the tictactoe application */`
     
58.  `  window = gtk_window_new(GTK_WINDOW_TOPLEVEL);`
     
59.  
     
60.  `  ttt = tictactoe_new();`
     
61.  `  gtk_container_add(window, ttt);`
     
62.  
     
63.  `  gtk_widget_show_all(window);`
     
64.  
     
65.  `  /* start the Gtk+ dispatcher */`
     
66.  `  pthread_create(&thread, NULL,`
     
67.  `                 ttt_functional_test_gtk_main, NULL);`
     
68.  
     
69.  `  /* launch test routines */`
     
70.  `  ttt_functional_test_dumb_player_b();`
     
71.  
     
72.  `  /* terminate the application */`
     
73.  `  gdk_threads_enter();`
     
74.  
     
75.  `  gtk_main_quit();`
     
76.  
     
77.  `  gdk_threads_leave();`
     
78.  
     
79.  `  return(0);`
     
80.  `}`
     
```
