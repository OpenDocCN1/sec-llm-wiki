# 阿里云发布 Elasticsearch 云服务

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664609619&idx=2&sn=59c15c40b750e57c8790d7a312787664&chksm=bdce8c158ab9050379aae7ec043a336c3e2cf60b2adc96ad3e7dbbe7c8371420c4e160c4da96&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664609619&idx=2&sn=59c15c40b750e57c8790d7a312787664&chksm=bdce8c158ab9050379aae7ec043a336c3e2cf60b2adc96ad3e7dbbe7c8371420c4e160c4da96&scene=27#wechat_redirect)

![](../Images/2da7d25ba618011f7c6ee6d47e1f358a.png)Elasticsearch 是基于 Apache Lucene 的搜索和分析引擎，是现阶段最受欢迎的开源软件之一。目前已经超过了 1.4 亿次下载，广泛应用于日志分析、安全业务分析、全文检索等领域。

  

10 月 14 日，阿里云宣布与 Elastic 公司建立合作伙伴关系，联合发布阿里云 Elasticsearch 产品。 

本次发布的阿里云 Elasticsearch 产品基于开源版 Elasticsearch、集成 X-Pack 商业插件以及 Kibana，为客户提供更好的稳定性、更高的性能、更快速的弹性伸缩能力、以及更丰富的功能，包括企业级权限管控、可视化数据分析、安全监控告警、自动报表生成、机器学习等功能。 

阿里云 Elasticsearch 现阶段会提供多达 6 种规格的计算节点以及 SSD 的存储服务。收费方式上，支持小时级计费的按量付费方式，并在未来会推出包年包月付费模式。同时，秒级交付和弹性扩容的特性将更好地满足大中型企业高速增长的业务需求。

针对国内用户，阿里云 ELasticsearch 默认提供了 IK 分词插件等一系列中文场景化的插件，并将集成阿里巴巴自研的中文 NLP 模块，同时提供全天候的中文技术支持服务。除此之外，阿里云 Elasticsearch 默认提供 Kibana 的可视化操作界面，并将所有的存储和计算环境全部放在专有网络 VPC 内，为客户的数据提供更安全可靠的保障。

下一步，阿里云 Elasticsearch 将逐步完善多种数据存储类产品的打通和接入，将数据的汇集、分析、检索、数据监控、报表分析、机器学习等功能做到更加简单、快捷和低成本。同时，阿里云将积极参与到 Elasticsearch 开源社区中，共享技术进步。

Elasticsearch 是基于 Apache Lucene 的搜索和分析引擎，是现阶段最受欢迎的开源软件之一。目前已经超过了 1.4 亿次下载，广泛应用于日志分析、安全业务分析、全文检索等领域。
