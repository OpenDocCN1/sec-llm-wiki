# 【每日安全资讯】Ubuntu Snap Store发现恶意程序

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664611101&idx=4&sn=ebc1f0d644367ec0396a6fa18e0ccedd&chksm=bdce865b8ab90f4d1a88ee423595eaff9447d5470f0087049f3c6e3aa9b1db420f5e9e4f718c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664611101&idx=4&sn=ebc1f0d644367ec0396a6fa18e0ccedd&chksm=bdce865b8ab90f4d1a88ee423595eaff9447d5470f0087049f3c6e3aa9b1db420f5e9e4f718c&scene=27#wechat_redirect)

Ubuntu Snap Store 发现了多个捆绑挖矿程序的应用，都是同一名用户上传的。Ubuntu Snap Store 没有审核机制，任何人都可以上传 snap 打包的应用，这就为恶意程序创造了机会。被发现捆绑挖矿程序的应用是 2048buntu 和 Hextris，由用户 Nicolas Tomb 上传，这名用户上传的所有软件包都已经移除以等待进一步的调查。

![](../Images/1cd53f869db212acbad543a1276d8e81.png)

其中 2048buntu 是 fork 自开源应用 2048，而 2048buntu 则是以私有软件的名义递交到应用商店的。 2048 使用的 MIT 许可证允许以私有软件的名义分发，只需要保留版权通知，但不清楚 2048buntu 是否保留了版权通知。
