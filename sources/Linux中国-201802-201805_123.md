# 【每日安全资讯】最新的Ubuntu 18.04 LTS可运行在任天堂Switch上

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610989&idx=3&sn=aa182f22670bbfa5298b75537c85fb7f&chksm=bdce87eb8ab90efd90ea18cf5e1527b97c70eac64099de1513331bbe79c8329b78b277484054&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610989&idx=3&sn=aa182f22670bbfa5298b75537c85fb7f&chksm=bdce87eb8ab90efd90ea18cf5e1527b97c70eac64099de1513331bbe79c8329b78b277484054&scene=27#wechat_redirect)

有人刚刚在Nintendo Switch游戏机上安装了最新发布的Ubuntu 18.04 LTS（仿生河狸）操作系统。 GBAtemp游戏社区某位用户发布了一张照片，内容是Canonical最新的Ubuntu 18.04 LTS（仿生河狸）操作系统运行在任天堂Switch上，可以看到GNOME桌面和全新欢迎屏幕以及全新桌面布局。

但是在默认情况下没有硬件加速，这意味着打开窗口并在打开的应用程序之间切换时，事情会变得非常缓慢。但是，在从特定PPA构建最新的Mesa / LibDRM之后，GNOME桌面的性能得到了显着改善。

这位用户表示，有些东西显然效果不错。例如，音量按钮可以立即使用，环境光线传感器也正常工作，但是比较烦人，因为它会使屏幕变得过亮。当然，触摸输入也可以直接使用。

另一方面，蓝牙无法正常工作，所以在运行Ubuntu 18.04 LTS时，将无法将任何外设连接到Nintendo Switch，但可以通过SSH连接到Nintendo Switch，以安装各种游戏模拟器，如Dolphin和RetroArch。

在Nintendo Switch上运行Linux并不是什么新鲜事，因为在发现Nvidia Tegra X1芯片中的错误之后，failover黑客团队展示了在游戏控制台上运行的Debian GNU / Linux操作系统，但运行了最新的Ubuntu 18.04 LTS（仿生河狸）并非易事。
