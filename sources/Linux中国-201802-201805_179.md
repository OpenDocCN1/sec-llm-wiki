# 【每日安全资讯】为什么裸照泄露事件会持续发生？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610895&idx=4&sn=4b15b9374f9e4c3b66ff97edeaeb717c&chksm=bdce87098ab90e1f930e34be6e64f91d15e9d266d74c5beb86ecdf7eb734614712bcdcab0113&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610895&idx=4&sn=4b15b9374f9e4c3b66ff97edeaeb717c&chksm=bdce87098ab90e1f930e34be6e64f91d15e9d266d74c5beb86ecdf7eb734614712bcdcab0113&scene=27#wechat_redirect)

一系列裸照泄露事件始于2014年，当时黑客成功侵入了数十位名人的云计算账户，窃取了一些私人内容，这些内容最终在网络上流传开来。尽管黑客们已经被逮捕，但这些天来，裸照的泄露仍在继续，越来越多来自世界各地的明星的私人内容被公开，被数百万的互联网用户访问。![](../Images/0c8063005f39badb8d8e67cb59c4255c.png)

你可能会认为，在2014年的丑闻之后，名人会更加注意保护他们的数据，但事实证明没有。而这一切都可以归结为三个基本原因。

1.人们仍然会拍裸照

裸照泄露的发生很大程度上是因为裸照一开始就存在。没错，黑客确实破坏了名人的账户，但如果没有什么值得窃取的东西存储在云里，就不会有令人尴尬的泄露事件发生。

2.黑客手段更为复杂

另一方面，黑客也在转向更复杂的技术，窃取凭证，并访问存储这些照片的云账户。大多数的攻击行为都是在网络钓鱼诈骗中发生的，这些诈骗涉及电子邮件，并要求重新设置密码。黑客们在第三方服务器上托管了由苹果提供的页面，并促使名人上钩，然后窃取他们的信息，访问账户，提取存储在云中的数据。

值得记住的是，像苹果和谷歌这样的公司永远不会要求你输入密码，所以如果你收到这样的邮件，就有可能是网络钓鱼的陷阱。

3.用户不关心他们的安全

第三个原因或多或少来自于另外两个原因，因为正如之前所说的，互联网用户并不太在意，或者根本不关心他们的网络安全。但是，当涉及到敏感数据时，比如X级的内容、信用卡信息或简单的个人信息，毫无疑问，至少应该采取基本的预防措施。

现在最好的解决办法是让科技公司自己开发更高级的程序来规避这些问题，当然，用户更需要提高网络安全的意识。
