# 【每日安全资讯】AMD承认Zen架构安全漏洞:将会加快修复

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610756&idx=5&sn=9030fcd1703a45d4d6bd24aaee6c87a3&chksm=bdce80828ab90994594fb6ca6200f1941983d33a08d65c5a0fa45456da512808855f3856a778&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610756&idx=5&sn=9030fcd1703a45d4d6bd24aaee6c87a3&chksm=bdce80828ab90994594fb6ca6200f1941983d33a08d65c5a0fa45456da512808855f3856a778&scene=27#wechat_redirect)

【PConline 资讯】上周AMD的Zen被曝有12个安全漏洞，业内很多人都猜测可能是竞争对手使诈，然而前两天AMD就官方回应了这件事情，Zen架构的CPU确实存在这样的安全漏洞，并且会尽快把漏洞修复。  

![](../Images/81b6037ac35898a8a24bed2a51047ad1.png)

AMD强调这次的漏洞和之前的“熔断”、“幽灵”没有关系，这次新的安全漏洞是部分芯片组而非Zen架构CPU本身，包括AM4（X370、B350、A320等）、TR4（X399）。

AMD初步将漏洞划分为三类，分别是“Masterkey”、“RyzenFall/Fallout”和“Chimera”，前两者涉及安全芯片，后者则涉及芯片组。  

![](../Images/bcf11507d412f7e2f0074caa11329d36.png)

![](../Images/77f8b3bba9d29a954424d49f9f7c89c6.png)

上述三种漏洞AMD都称能通过升级BIOS解决。但大多用户实际上都不懂升级BIOS或者不关注BIOS的，所以这些漏洞对于这部分用户来说很可能会是持续的潜在安全隐患。
