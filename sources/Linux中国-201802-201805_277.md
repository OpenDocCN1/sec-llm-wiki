# 【每日安全资讯】黑客组织Guccifer 2.0疑意外证实了自己跟俄罗斯的关系

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610747&idx=4&sn=bef2cd2bf17ffe3957f2d70536662fd3&chksm=bdce80fd8ab909eb49c11ef16125458fb13dcd1f347c562fd539d1955c7e9c3838c654516ee2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610747&idx=4&sn=bef2cd2bf17ffe3957f2d70536662fd3&chksm=bdce80fd8ab909eb49c11ef16125458fb13dcd1f347c562fd539d1955c7e9c3838c654516ee2&scene=27#wechat_redirect)

据外媒报道，以攻击DNC服务器闻名的黑客组织Guccifer 2.0似乎已经证实了人们曾认定的一件事：它的总部在俄罗斯。长期以来，许多人都相信Guccifer跟俄罗斯存在关联，但由于使用了VPN以及其他技术所以很难证实这点。

然而当这匹“独狼”忘记使用VPN的时候，它似乎偶然曝光了自己，获悉，Guccifer黑客的IP地址被发现来自莫斯科且跟俄罗斯的情报机构GRU有关系。

目前还不清楚Guccifer 2.0的确切身份，但研究人员能够确定的是，这个偶然曝光的IP地址曾经为一名为位于莫斯科Grizodubovoy街的GRU总部工作的官员使用过。

![](../Images/51dbb451752d8c37102b646d2a35748d.png)

外媒Daily Beast指出，这次的曝光进一步证实了俄罗斯曾在2016年干预美国总统大选的事实。

这也不可避免地让人们质疑普京在美总统大选中所扮演的角色。美相关部门曾多次试图找出黑客的源头，但最终却都因为不一致的信息而否决了先前的假设。
