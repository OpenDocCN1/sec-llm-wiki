# 【每日安全资讯】被盗的Apple ID在“暗网”黑市上售价为15美元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610624&idx=5&sn=b133e0db5058f77c0b2883a0157921c9&chksm=bdce80068ab90910b9302b1a398ffca510b28ca93fbb3ec033bb51d3e5ad580e50f58e872658&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610624&idx=5&sn=b133e0db5058f77c0b2883a0157921c9&chksm=bdce80068ab90910b9302b1a398ffca510b28ca93fbb3ec033bb51d3e5ad580e50f58e872658&scene=27#wechat_redirect)

国外网站对秘密的“暗网”黑市进行了调查，结果发现，对于网络犯罪者来说，想要购买一个人的完整在线身份只需要花费不到 1200 美元。在这些在线身份中，Apple ID 苹果账户的售价为 15.39 美元。与其他账户相比，Apple ID 的售价还是很高的。

![](../Images/7b689a2182d57112e0c6a5a282557d0b.png)

  

拥有 Apple ID 后，可以访问 Apple Music，以及 iCloud 等。暗网将 Apple ID 列为“娱乐登陆信息”，Netflix 的账户为 8.32 美元，Twitch 账户的价格为 2.08 美元，Ticketmaster 账户的价格为 2.07 美元。

  

![](../Images/d3c503da4c4aa012475849e0b3bc438e.png)

![](../Images/91a74ae707d647f27693672dea504e9a.png)

社交媒体方面，脸书 FB 的价格最高，5.2 美元。领英、推特、Instagram 账户分别是 2.07、1.66 和 1.28 美元。Gmail 和雅虎账户的价格都是 1.04 美元，AOL 账户的价格却很高，达到了 4.16 美元。

其他方面，在线购物网站的账户价格也很高，梅西百货的账户为 15.34 美元，eBay 和 Amazon 的价格分别是 12.48 和 9 美元。最后就是金融服务了，Paypal 账户登陆价格高达 247 美元，西联登陆账户为 101 美元。其他在线银行、信用卡、借记卡信息都在 50-160.15 美元之间不等。
