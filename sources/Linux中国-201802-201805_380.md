# 使用“微信读书”来订阅《Linux中国》公众号更爽

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610583&idx=2&sn=fdcf86cf4f709236d09f617826f7736b&chksm=bdce80518ab90947ff13fee8487570830de6f7a9311758e1439e9a4ac274e805945d7a9ef708&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610583&idx=2&sn=fdcf86cf4f709236d09f617826f7736b&chksm=bdce80518ab90947ff13fee8487570830de6f7a9311758e1439e9a4ac274e805945d7a9ef708&scene=27#wechat_redirect)

大家可能已经订阅了太多的公众号，已经对“订阅号”文件夹的红点感到了麻木。即便是您已经将某个公众号置顶，但是重点关注的公众号的推送到达之时，也没有任何提醒。而这种将文章阅读和聊天功能混在一起的做法，更是会让你对阅读长文心有犹豫。

而现在，有个更好一些的阅读体验：您可以将您喜欢的公众号放到“微信读书”里面去订阅，这样您可以：

*   在该公众号推送时，第一时间得到提醒（前提是您允许“微信阅读”发送提醒）
    
*   您可以聊天和阅读两不误，而不用将正在阅读的文章置顶（回头读完还得记着取消置顶，好麻烦……）
    
*   您的评论无需审核即可展示给您的“微信读书”中的好友；您正在订阅的微信公众号、您的点赞、您的转推，都可以被您的 “微信读书”中的好友所看到
    

阅读的版式效果和微信中几乎一样，除了没有阅读进度记录，几乎完美了。

此外，还有一个真金白银的好处，就是你在“微信读书”中对公众号的阅读时长，也是计入的“微信读书”的，那么你知道阅读时长是有书币奖励的不？

那么怎么才能添加您喜欢的公众号到“微信读书”呢？

1.  首先，您得下载安装“微信读书”，这是由微信官方推出的 app。（本条木有收到广告费……）
    
2.  您在微信中阅读到一篇文章，就比如本文吧，您可以点击文章右上角菜单，显示分享菜单，点击“在微信读书中阅读”即可在“微信读书”中打开文章：  
    
    ![](../Images/656230c159bcae0f7a6324b73f26021f.png)
    
3.  打开之后，点击文章右上角的“加入书架”：  
    ![](../Images/27d2e50118f014488c200f517c8be80f.png)
    
4.  这样，公众号就加入到你的书架了：  
    
    ![](../Images/b48cf89311c092659223141e66836ce6.png)
    
5.  您还可以点击该公众号文集右上角的分享菜单，将其推荐到“发现”当中：  
    
    ![](../Images/520f2ada9fa93fd5a5d58e99a301399a.png)
    
6.  这样你的朋友们就可以看到你的推荐了：
    
      
    
    ![](../Images/bc660afd7160826ec2f31243d5f6d086.png)
    
7.  至于评论、点赞、转推等功能，就留给你自己试试啦。
    

怎么样，要不要将“Linux中国”放到“微信读书”中试试？
