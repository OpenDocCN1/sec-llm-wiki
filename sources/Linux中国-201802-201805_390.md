# 【每日安全资讯】根据欧盟“被遗忘权”法律 Google已收到240万个网址删除请求

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610564&idx=4&sn=39df3abd5e786067bf2eddab95ddad17&chksm=bdce80428ab90954af90c6fadd3e392f97daddad13e33e09649926fed6f59c9bb6cde5d80175&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610564&idx=4&sn=39df3abd5e786067bf2eddab95ddad17&chksm=bdce80428ab90954af90c6fadd3e392f97daddad13e33e09649926fed6f59c9bb6cde5d80175&scene=27#wechat_redirect)

自欧盟“被遗忘权”法律2014年5月推出以来，谷歌已收到超过240万次要求从其搜索引擎中删除网址的的要求。这份新数据来自Google扩大其透明度的最新报告，其中还添加可追溯到2016年1月的新数据。

此外，新数据还将显示：私人和非私人个人（如政府官员或公司提出请求）的细目，请求的内容，网站的内容和内容退市率。这些要求背后的原因中，“专业信息”几乎占四分之一（24%），其次是“自编”10%，犯罪和专业错误率分别为8%和7%。 Google还概述了收到的请求示例，请求的原因以及得到的结果。

大约三分之一的移除请求与社交媒体和目录服务有关，约21％是与新闻媒体和政府网站相关的网址，大部分涉及某人的法律历史。

Google已发布其关于该主题的研究报告草稿，其，名称为“被遗忘的三年”，该报告也已提交给同行审阅。

欧洲法院于2014年5月制定了“被遗忘权”法律，允许欧洲人要求Google等搜索引擎从结果中删除有关自己的信息。那么搜索引擎就必须检查这些信息是否不准确，不适当，不相关还是过度曝光，以及公共利益是否存在其中。
