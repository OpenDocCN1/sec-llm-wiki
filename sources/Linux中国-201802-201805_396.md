# 【每日安全资讯】GitHub 停止支持弱加密

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610558&idx=5&sn=193b8b85a6e567bdc0bb43406a40ed12&chksm=bdce81b88ab908ae6779a91a46f41d1381306382b89077e6288986ac7902fde832e7648e9c68&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610558&idx=5&sn=193b8b85a6e567bdc0bb43406a40ed12&chksm=bdce81b88ab908ae6779a91a46f41d1381306382b89077e6288986ac7902fde832e7648e9c68&scene=27#wechat_redirect)

GitHub 通过官方博客宣布了网站的多个变化，从即日起 github.com 和 api.github.com 停止支持弱加密标准（TLSv1/TLSv1.1，SHA1）； Gist 服务停止支持匿名，从 3 月 19 日起创建 Gist 代码片段需要注册，GitHub 此举是因为该服务被滥用创建垃圾信息问题和 pull request 标签支持绘文字和悬停描述。
