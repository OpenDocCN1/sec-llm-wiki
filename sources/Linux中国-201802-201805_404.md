# 【每日安全资讯】担心密码被撞库？用1Password检查一下吧！

网络时代，用户需要针对各项服务设置不同的密码来保障安全，但这对于记性不佳的人们并不友好，更别提近年来屡次曝光的大规模数据库失窃事件。好消息是，密码管理器软件为我们提供了一个相对轻松的解决方案。如果你担心常用密码已在脱库事件中被泄露，那么不妨用 1Password 来验证一下。

![](../Images/d9d559de2da0b25f24b4d23fdb06e458.png)

作为一项备受欢迎的服务，即日起，1Password 可以告诉你当前使用的密码，是否已经在过去的泄露事件中被曝光过。

除了通常的“复制”、“显示/隐藏”、“大写”三个按钮（以及显示密码强度）之外，它还新增了一个“检查密码”的按钮。

![](../Images/a7fd4501011be21659f548d605c909a7.png)

Hunt 刚刚在前一天放出了第二版的“Pwned Passwords”密码集，而 1Password 在第二天就刷新跟进了。

如果密码不幸被撞库，那么 1Password 会提示“哦，找到了”。如果强度足够安全，它就会给出一个笑脸 ——“没找到，放心浪”。

如果你对 Hunt 的 5 亿泄露密码数据库和 1Password 团队是如何检查密码并确保用户安全的幕后工作感兴趣，还请翻阅 Agile Bits 的这篇博客文章(https://blog.agilebits.com/2018/02/22/finding-pwned-passwords-with-1password/)。
