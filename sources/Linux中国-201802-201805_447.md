# 【每日安全资讯】Salon 网站向启用广告屏蔽的用户提供了挖矿的选项

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610472&idx=5&sn=c993f4813ef711af0526abee061f6f14&chksm=bdce81ee8ab908f85090e3ab19a1ec90862c7f1e078e8612ecd2314b8d7a872aadfd3fb9b2eb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610472&idx=5&sn=c993f4813ef711af0526abee061f6f14&chksm=bdce81ee8ab908f85090e3ab19a1ec90862c7f1e078e8612ecd2314b8d7a872aadfd3fb9b2eb&scene=27#wechat_redirect)

![](../Images/47a02766c7dfb493ad9d77350364d405.png)

大多数网站的收入主要来自广告，而广告屏蔽工具的流行令网站的这一主要收入来源面临风险。一部分网站已经开始尝试利用浏览者的 CPU 去挖掘数字货币如门罗币，但这种不告诉用户悄悄挖矿的行为受到了很多批评。现在，Salon 网站正大光明的询问启用广告屏蔽的用户是否愿意挖矿。启用广告屏蔽的用户浏览网站时会弹出一个窗口，询问用户是否愿意关闭广告屏蔽或者继续屏蔽广告但允许它利用空闲计算资源挖矿。Salon 的 FAQ 称它只使用一小部分 CPU 资源，而测试显示它运行的 Coinhive 脚本使用了大约 50% 的 CPU 资源。
