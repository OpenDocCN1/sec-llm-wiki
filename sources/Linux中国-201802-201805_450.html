内置命令包含在 bash shell 本身里面。我该如何在 Linux / Apple OS X / *BSD / Unix 类操作系统列出所有的内置 bash 命令，而不用去读大篇的 bash 操作说明页？

shell 内置命令就是一个命令或一个函数，从 shell 中调用，它直接在 shell 中执行。 bash shell 直接执行该命令而无需调用其他程序。你可以使用 help 命令查看 Bash 内置命令的信息。以下是几种不同类型的内置命令。

内置命令的类型

☉ Bourne Shell 内置命令：内置命令继承自 Bourne Shell。
☉ Bash 内置命令：特定于 Bash 的内置命令表。
☉ 修改 Shell 行为：修改 shell 属性和可选行为的内置命令。
☉ 特别的内置命令：由 POSIX 特别分类的内置命令。

  1. $ help
  2. $ help | less

另外一种选择是使用下列命令：

  1. compgen -b
  2. compgen -b | more

查看 Bash 的内置命令信息

运行以下得到详细信息：

  1. help command
  2. help read

要仅得到所有带简短描述的内置命令的列表，执行如下:

  1. $ help -d

查找内置命令的语法和其他选项

使用下列语法去找出更多的相关内置命令：

  1. help name 
  2. help cd 
  3. help fg 
  4. help for 
  5. help read 
  6. help :

样例输出：

  1. :: :
  2.  Null command.
  3.  
  4.  No effect; the command does nothing.
  5.  
  6.  Exit Status:
  7.  Always succeeds

找出一个命令是内部的（内置）还是外部的

使用 type 命令或 command 命令：

  1. type -a command-name-here 
  2. type -a cd 
  3. type -a uname 
  4. type -a : 
  5. type -a ls

或者：

  1. type -a cd uname : ls uname

样例输出：

  1. cd is a shell builtin
  2. uname is /bin/uname
  3. : is a shell builtin
  4. ls is aliased to `ls --color=auto'
  5. ls is /bin/ls
  6. l is a function
  7. l ()
  8. {
  9.  ls --color=auto
  10. }

或者：

  1. command -V ls 
  2. command -V cd 
  3. command -V foo
