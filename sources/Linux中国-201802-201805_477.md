# 【每日安全资讯】Mozilla 宣布物联网开放框架

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664610417&idx=4&sn=3264bb760633fc76ae63cf896685440e&chksm=bdce81378ab90821e8b059758c165702bf342c71807ee55c649f01a8d4a92c6252be946bc7bb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664610417&idx=4&sn=3264bb760633fc76ae63cf896685440e&chksm=bdce81378ab90821e8b059758c165702bf342c71807ee55c649f01a8d4a92c6252be946bc7bb&scene=27#wechat_redirect)

Mozilla 宣布了 Project Things，连接物联网设备的开放框架。Mozilla 称，物联网设备过去几年日益流行，但相关厂商都是各自为政，没有单一的标准允许不同设备之间互相通信。每家厂商通常都是创建出只工作在自家品牌产品的定制私有应用。

如果未来的物联网设备将这一状况持续下去，那么价格将会一直维持在高点，市场将会一直呈现碎片化，增长将会放缓。消费者不应该被锁定在特定产品、特定的品牌或平台。Mozilla 相信物联网的未来应该更像是开放 Web。

未来的物联网应该是去中心化的，应该将权力和控制交到使用设备的用户手中。这就是它发起 Project Things，创建去中心化的开放标准框架和服务，注重安全、隐私和互操作性的原因。
