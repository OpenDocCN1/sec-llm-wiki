# 【每日安全资讯】Google Chrome 70将继续在地址栏隐藏www但不省略 m

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664612065&idx=5&sn=1dd3ba89a2eeb0bb5cfc0823d5d38b64&chksm=bdcefba78ab972b162a745afecd2f86c0b182377d483cb6a6d957075cb11379e263ab02db4e5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664612065&idx=5&sn=1dd3ba89a2eeb0bb5cfc0823d5d38b64&chksm=bdcefba78ab972b162a745afecd2f86c0b182377d483cb6a6d957075cb11379e263ab02db4e5&scene=27#wechat_redirect)

Google 在本月初释出的 Chrome 69 中引入了一项受争议的改动：隐藏网址中的 WWW 和 m。然而， www.example.com 和 example.com 是有区别的，它们很可能是不同的网站，Google 的做法会带来安全隐患，用户可能会更容易的被钓鱼网站欺骗。

在引发争议之后，Google Chromium 产品经历 Emily Schecter 表示他们听取了社区反馈，决定 Chrome 70 将作出一些改动：继续省略 WWW 但不省略 m。

这个调整和不调整几乎不存在差别。Schecter 声称他们计划启动相关的标准化讨论。
