# 【每日安全资讯】省时省力！Facebook开发AI自动找漏洞

对于互联网公司来说，网站出现技术漏洞是在所难免的事情。不过，寻找漏洞的工作总是非常耗时耗力，那么如何才能“完美”的解决这个问题呢？

据报道，日前Facebook开发了一个名为SapFix的人工智能工具，它可以自动扫描代码寻找漏洞，然后测试不同的补丁，并向工程师推荐最佳的修补方案。

![](../Images/b084d03e67884ba268f7ecf4500a6721.png)

Facebook开发AI自动找漏洞（图片源自网络）

Facebook开发团队表示，这是第一次在Facebook这种规模的代码库中，通过自动的端对端测试和修补来部署机器生成的修复方案，这是AI混合模式的重要里程碑，进一步证明了基于搜索的软件工程可以降低软件开发的阻力。  

![](../Images/a6ce330f15e22b0a1ae9ad62b70ce5ab.png)

Facebook开发AI自动找漏洞（图片源自网络）

Sapienz是Facebook之前的自动化漏洞发现工具，而SapFix既可以与之配合使用，也可以独立使用。在配合使用时，SapFix可以针对Sapienz发现的问题推荐解决方案。

据悉，这些工具可以帮助小团队开发更加强大的产品，也可以帮助大公司节约很多时间。好消息是，Facebook计划向外部开发者分享这个AI工具，以解决大家共同的烦恼。
