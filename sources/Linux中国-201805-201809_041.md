> 在你安装的 Linux 发行版中默认就包含了一些别名。

Linux 命令行别名非常适合帮助你提高工作效率。更好的是，在你安装的 Linux 发行版中默认就包含了一些别名。

这是 Fedora 27 中的命令别名的示例：

![](../Images/37ef2c9f36b5cfa6c0c734af19271ac2.png)

这个 `alias` 命令列出了已有的别名。设置别名也十分简单：

```
1.  `alias new_name="command"`
    
```

这里有 15 个命令行别名，可以节省你的时间：

1、安装任何应用实用 / 应用程序：

```
1.  `alias install="sudo yum install -y"`
    
```

在这里，根据每个用户的偏好，`sudo` 和 `-y` 是可选的：

![](../Images/03675fa368ed600b7b6a0154471fb21b.png "install alias.png")

*install alias.png*

2、更新系统：

```
1.  `alias update="sudo yum update -y"`
    
```

3、升级系统：

```
1.  `alias upgrade="sudo yum upgrade -y"`
    
```

4、切换 root 用户：

```
1.  `alias root="sudo su -"`
    
```

5、切换到 “user” 用户, 其中 `user` 设置为你的用户名：

```
1.  `alias user="su user"`
    
```

6、显示列出所有可用端口、状态还有 IP：

```
1.  `alias myip="ip -br -c a"`
    
```

7、`ssh` 到你的服务器 `myserver`：

```
1.  `alias myserver="ssh user@my_server_ip”`
    
```

8、列出系统中所有进程：

```
1.  `alias process="ps -aux"`
    
```

9、检查系统的服务状态：

```
1.  `alias sstatus="sudo systemctl status"`
    
```

10、重启系统服务：

```
1.  `alias srestart="sudo systemctl restart"`
    
```

11、按名称杀死进程：

```
1.  `alias kill="sudo pkill"`
    
```

![](../Images/83b709cb8a362887950976a9e63e0be0.png "kill process alias.png")

*kill process alias.png*

12、显示系统系统总使用内存和空闲内存 ：

```
1.  `alias mem="free -h"`
    
```

13、显示系统 CPU 框架结构、CPU 数量、线程数等：

```
1.  `alias cpu="lscpu"`
    
```

14、显示系统总磁盘大小：

```
1.  `alias disk="df -h"`
    
```

15、显示当前系统 Linux 发行版本（适用于 CentOS、Fedora 和 Red Hat)：

```
1.  `alias os="cat /etc/redhat-release"`
    
```
