# 【每日安全资讯】Let's Encrypt Root 获得了所有主要机构的信任

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664611795&idx=4&sn=e40fb529e1b08d45e07221b004bf3cea&chksm=bdce84958ab90d83019ca687866da551b65914f65eea4c1045f58e7b70b41b99f73eb6c8479d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664611795&idx=4&sn=e40fb529e1b08d45e07221b004bf3cea&chksm=bdce84958ab90d83019ca687866da551b65914f65eea4c1045f58e7b70b41b99f73eb6c8479d&scene=27#wechat_redirect)

旨在让所有网站启用 HTTPS 的 Let's Encrypt 项目宣布，它的 Root 证书 ISRG Root X1 于 7 月底获得了所有微软产品的信任，这意味着现在它的 Root 证书被所有主要 Root 程序的信任，包括微软、Google、Apple、Mozilla、Oracle 和 Blackberry。

![](../Images/ffe11bfc81cd6a7f1c0eba5a7cfc7011.png)

对这个非赢利机构来说这是一个重要的里程碑。

Let’s Encrypt 称，虽然所有较新版本的操作系统、浏览器和设备都直接信任它的证书，但许多旧版本仍然没有直接信任 Let’s Encrypt CA，其中一部分会升级到信任其证书的新版本，但还有很多不会升级。要等待它们彻底消失可能至少需要五年时间。
