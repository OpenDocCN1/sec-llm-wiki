# 【每日安全资讯】寄光盘，“中国黑客”干的？美炒作“中国黑客”又找到奇葩角度

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664611757&idx=4&sn=25e285b4d57ff99049fa3fcb9f700d76&chksm=bdce84eb8ab90dfd7be5e71e04c18578c263d3d1093e7880307b317bdb43736041928d3ae0bd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664611757&idx=4&sn=25e285b4d57ff99049fa3fcb9f700d76&chksm=bdce84eb8ab90dfd7be5e71e04c18578c263d3d1093e7880307b317bdb43736041928d3ae0bd&scene=27#wechat_redirect)

【环球时报综合报道】为了炒作“中国黑客”话题，美国总能找到各种新奇的角度。美国科技网站Engadget 7月30日的报道称：“中国黑客试图通过邮寄CD光盘，入侵美国政府电脑”。

![](../Images/4edfd606cd31b9aaf7e397a98f2fa825.png)

报道称，“来自中国的黑客”正向美国各州政府官员邮寄充斥恶意软件的迷你CD，美国政府安全机构“跨州信息共享和分析中心”近期发布警告，详细披露了“中国黑客”骗局：一个盖有中国邮戳的包裹内含有杂乱来信和一张小CD，后者含有一系列内置恶意脚本文件的Word文档。当受害者用电脑打开这些文档时，脚本文件开始在电脑上运行并有可能危害其内部系统。  

虽然听起来匪夷所思，但美国媒体正儿八经地分析其“危害”。美国科技博客网站TechCrunch称，邮寄老式包裹是“最简单但也最令人难以对付的网络攻击方式之一”。“跨州信息共享和分析中心”还称，迄今为止，一些州的档案馆、历史协会和文化事务厅都收到了明确寄给它们的来信。但尚不清楚这些机构内是否有人上当并将CD插入政府计算机。  

Engadget网站称，“尽管不清楚其确切意图，但这种试图攻击美国州政府的伎俩似乎不怎么奏效，因为寄送者无法确定政府电脑是否配置光驱，更何况能读取迷你CD的光驱。为何不邮寄U盘呢？”

中国政府多次表示，坚决反对一切形式的黑客攻击行为。Engadget网站最后也承认：“其实，目前并无指向确切幕后罪犯的线索。然而，中国黑客向来具有针对美国有关机构发起以探索而非窃取信息或获利为目的的攻击行为。此类行为或许更侧重于了解美国各州政府，为未来攻击做好准备。”
