# 【每日安全资讯】打击学历造假问题 意大利卡利亚里大学把毕业证书搬到了区块链上

毫无疑问，区块链会不断前进、发展，至少教育领域已经意识到了这一新兴技术的重要性和影响力。最近，意大利卡利亚里大学（University of Cagliari）宣布将为今年毕业班学生颁发基于数字区块链的学位证书。

**学位欺诈问题比大多数人想象的还要严重**

如今，学位欺诈问题已经引起了社会严重关注，有的人会在简历中添加虚假信息，有的人会从第三方购买虚假学位，这些问题已经对就业市场产生了重大负面影响，不少企业和雇主受到欺骗和伤害。

更令人担忧的是，一些人拿着虚假文凭试图进入医疗保健行业，他们甚至会编造护士、麻醉师和医生的学历文凭欺骗医疗机构，这无疑会给社会带来巨大危害。

![](../Images/be8022c3bafb9f786b76b90813bec505.png)

据报道称，目前只有五分之一的企业雇主会审核应聘者的学历资质。根据一名美国联邦调查局前特工透露，美国有很多提供虚假文凭证件的公司，他说道：  

“雇主在检查文凭文件的事后没有做到尽职尽责的调查，所以才让一些人钻了空子，而验证所有应聘者学历文凭的真实性，本身也是一件很困难的事情。”

实际上，区块链技术能够很好解决这一问题，因为如果将学历证书放到区块链上，所有信息均是公开的，不仅易于搜索查找，而且无法篡改。这样一来，企业雇主就可以轻松验证应聘者的学历真实性，而且很快就能判断出他们声称的学历学位是否与实际情况相符。

麻省理工学院早就把学位证书搬到了区块链上

意大利卡利亚里大学并不是第一个在区块链上颁发学位证书的高等学府，此前麻省理工学院已经开始向计算机科学专业的毕业生颁发基于区块链的学位证书了。很显然，这些毕业生已经享受到安全的数字化学位带来的好处。

值得一提的是，领国印度也开始在教育机构部署区块链技术——印度联邦政府建设的印度理工学院已经推出了自己的区块链项目IndiaChain，此项目已经开始在该校孟买校区试运行了。

未来几年，区块链技术势必会在更多行业里发挥作用，也肯定会有越来越多的高效选择利用这一新兴技术打击虚假学位问题，让学生能够保护好自己来之不易的学位证书。
