# 【每日安全资讯】Tim Berners-Lee 的拯救互联网计划：重新去中心化

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664611549&idx=4&sn=0f093de3f7c709952390eeb144c2d977&chksm=bdce859b8ab90c8debd87c97b39da7d95e303d0a51bdfa92105901e44df65a3799a673002b51&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664611549&idx=4&sn=0f093de3f7c709952390eeb144c2d977&chksm=bdce859b8ab90c8debd87c97b39da7d95e303d0a51bdfa92105901e44df65a3799a673002b51&scene=27#wechat_redirect)

万维网之父 Tim Berners-Lee 爵士从未从其发明上获利，他对从假新闻到大规模监视的状况非常不满。他想要拯救互联网，他的想法非常简单：重新去中心化。他与一小群开发者正在开发名为 Solid 的新平台，设计给予个人而不是企业去控制他们自己的数据。

Berners-Lee 称他们正构建一个全新的生态系统。 Solid 技术尚未为大众使用做好准备。但其愿景如果能成功运作的话，将能极大的改变 Web 现有的权力动力。

该系统设计让用户能控制访问他们在 Web 上产生的数据和内容，用户能选择数据如何被使用，而不是让 Facebook 和 Google 想怎么做就怎么做。Solid 的代码和技术开放给所有人。

Berners-Lee 不是这场革命的领导者，根据定义，去中心化 Web 不应该有领袖，但他是一个强有力的武器。他认识到去中心比最早发明万维网还要困难。他说，万维网发明之初，那么根本没有人，因此没有利益攸关方会抵制。但现在有数以亿计的美元在那里。
