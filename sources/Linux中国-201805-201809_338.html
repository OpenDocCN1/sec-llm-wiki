按时间顺序快速列出主要协同编辑器的演变。

正如任何这样的清单一样，它必定会在一开始便提到被誉为“所有演示之母the mother of all demos[1]”，在这个演示里道格·恩格尔巴特Doug Engelbart[2]早在 1968 年就描述了几乎所有软件的详尽清单。这不仅包括协同编辑器，还包括图形、编程和数学编辑器。

一切都始于那个演示，只不过软件的实现跟不上硬件的发展罢了。

软件发展的速度比硬件提升的速度慢。——沃斯定律

闲话少说，这里是我找到的可圈可点的协同编辑器的清单。我说“可圈可点”的意思是它们具有可圈可点的特征或实现细节。

项目日期平台说明
SubEthaEdit[3]2003-2015？仅 Mac我能找到的首个协同的、实时的、多光标的编辑器， 有个在 Emacs 上的逆向工程的尝试[4]却没有什么结果。
DocSynch[5]2004-2007？建立于 IRC 之上！
Gobby[6]2005 至今C，多平台首个开源、稳固可靠的实现。 仍然存在！众所周知 libinfinoted[7] 协议很难移植到其他编辑器中（例如： Rudel[8] 不能在 Emacs 上实现此协议）。 2017 年 1 月发行的 0.7 版本添加了也许可以改善这种状况的 Python 绑定。 值得注意的插件: 自动保存到磁盘。
Ethercalc[9]2005 至今Web，JavaScript首个电子表格，随同 Google Docs[10]。
moonedit[11]2005-2008？？原网站已关闭。其他用户的光标可见并且会模仿击键的声音。 包括一个计算器和音乐定序器。
synchroedit[12]2006-2007？首个 Web 应用。
Inkscape[13]2007-2011C++首个具备协同功能的图形编辑器，其背后的“whiteboard” 插件构建于 Jabber 之上，现已停摆。
Abiword[14]2008 至今C++首个文字处理器。
Etherpad[15]2008 至今Web首款稳定的 Web 应用。 最初在 2008 年被开发时是一款大型 Java 应用，在 2009 年被谷歌收购并开源，然后在 2011 年被用 Node.JS 重写。使用广泛。
Wave[16]2009-2010Web， Java在大一统协议的尝试上失败。
CRDT[17]2011特定平台在不同电脑间可靠地复制一个文件的数据结构的标准。
Operational transform[18]2013特定平台与 CRDT 类似，然而确切地说，两者是不同的。
Floobits[19]2013 至今？商业软件，但有对各种编辑器的开源插件。
LibreOffice Online[20]2015至今Web免费的 Google docs 替代品，现已集成到 Nextcloud[21]
HackMD[22]2015 至今？商业软件，开源[23]。灵感来自于（已被 Dropbox 收购的) hackpad。
Cryptpad[24]2016 至今Web ?Xwiki 的副产品。服务器端的加密的、“零知识” 产品。
Prosemirror[25]2016 至今Web， Node.JS“试图架起消除 Markdown 文本编辑和传统的所见即所得编辑器之间隔阂的桥梁。”不是完全意义上的编辑器，而是一种可以用来构建编辑器的工具。
Qill[26]2013 至今Web， Node.JS富文本编辑器，同时也是 JavaScript 编辑器。不确定是否是协同式的。
Teletype[27]2017 至今WebRTC， Node.JS为 GitHub 的 Atom 编辑器[28] 引入了“门户”的思路 ，使得访客可以夸多个文档跟踪主人的操作。访问介绍服务器后使用实时通讯的点对点技术（P2P），基于 CRDT。
Tandem[29]2018 至今Node.JS？Atom、 Vim、Neovim、 Sublime 等的插件。 使用中继来设置基于 CRDT 的 P2P 连接。多亏 Debian 开发者的参与，可疑证书问题[30]已被解决，这使它成为很有希望在未来被遵循的标准。
