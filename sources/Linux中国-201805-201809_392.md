# 【每日安全资讯】逆向工程暗黑破坏神

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664611445&idx=5&sn=555164a3f8984010edd64a5e298a2465&chksm=bdce85338ab90c25853b0d8d282e17581b840da708c37719bf1b3863919e7f71dddda05e45d3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664611445&idx=5&sn=555164a3f8984010edd64a5e298a2465&chksm=bdce85338ab90c25853b0d8d282e17581b840da708c37719bf1b3863919e7f71dddda05e45d3&scene=27#wechat_redirect)

1996 年发布的《暗黑破坏神》被誉为史上最佳游戏之一，暴雪在 2001 年停止了对游戏的更新。没有源代码，社区的开发者要想让游戏支持新硬件是非常困难的。暴雪没有对外披露游戏源代码，但它向两家开发商提供了源代码去开发扩展和 PS 移植版本，而索尼有一个不好的名声是它经常会泄漏开发商的源代码。暗黑破坏神也不例外。在泄漏的游戏源代码的帮助下，有开发者发布了逆向工程版本《Diablo devolved》。该版本没有提供游戏素材，玩家仍然需要有游戏的原始拷贝才能使用这个版本。
