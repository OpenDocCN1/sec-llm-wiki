# 【每日安全资讯】Emsisoft Browser Security扩展：帮你识别恶意网站

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664613108&idx=4&sn=43b781f9ecaf945e9ca4397120fc4821&chksm=bdceffb28ab976a4b1c10e4e4b21e3b6bbbc78d2e0d5d8a7624aa4e12d901026df1bfb8f537b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664613108&idx=4&sn=43b781f9ecaf945e9ca4397120fc4821&chksm=bdceffb28ab976a4b1c10e4e4b21e3b6bbbc78d2e0d5d8a7624aa4e12d901026df1bfb8f537b&scene=27#wechat_redirect)

今天要向大家介绍的Emsisoft Browser Security扩展程序，目前已经在Chrome和Firefox浏览器上线，可以为用户提供额外的防恶意网站的保护。这款扩展程序能够从各种网络钓鱼源中提取大部分数据，但也允许用户报告狡猾的网站。

![](../Images/08e76876b509e32f234cd35cf17bc7e7.png)

这款浏览器扩展程序可以帮助你识别钓鱼电子邮件，在用户点击邮件中的URL链接正式跳转之前，该扩展会对URL进行检查，如果发现问题就会发出警告。目前该扩展程序仅适用于Chrome和Firefox用户，但Emsisoft正在开发Edge版本。 Emsisoft还指出，当您使用扩展程序或报告潜在的非法网站时，不会收集任何个人数据。
