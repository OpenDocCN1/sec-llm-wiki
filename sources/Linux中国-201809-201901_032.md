# 【每日安全资讯】少年黑客篡改平台余额 提现80余万元被批捕

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664613043&idx=4&sn=02a61b6aa0735dc2f43bb6211f11a29b&chksm=bdcefff58ab976e34273f72eb59b8769438ff03bddb231ed5ca07c65da36b43f8884832f86ea&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664613043&idx=4&sn=02a61b6aa0735dc2f43bb6211f11a29b&chksm=bdcefff58ab976e34273f72eb59b8769438ff03bddb231ed5ca07c65da36b43f8884832f86ea&scene=27#wechat_redirect)

北京晨报讯（记者 黄晓宇）近年来，随着网络技术普及和发展，黑客中未成年人的数量越来越多，涉案手法日益多样化。近日，海淀区人民检察院对涉嫌盗窃罪的未成年犯罪嫌疑人王某某依法批准逮捕。

![](../Images/883affaac3e0e88d3937aee38858993d.png)

  

经依法审理查明，王某某系黑龙江省某市高三在校生，其利用课外时间自学计算机知识，自初中开始就为一些公司修补漏洞获取报酬，在圈内小有名气。2017年8月至2018年5月期间，其利用Windows系统漏洞获取了北京某计算机公司旗下的游戏点卡销售平台的最高控制权，修改平台账户余额并提现至自己的财付通和支付宝内。王某某通过这种方式分15次提现，共计提现80余万元，据王某某交代，所得钱款除了借给朋友外，主要用于购买服务器等计算机设备和吃喝玩乐。

检察官表示，网络世界虚拟而迷人，切勿深陷其中迷失自己，走向犯罪的深渊；相关网络企业内部也要积极消除网络安全方面的隐患，防患于未然。
