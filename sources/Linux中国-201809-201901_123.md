# 很多作为互联网从业者，我相信你一定听说过 Linux 。作为开源软件的传奇，服务器端操作系统的霸主，移动端设备的基础设施，Linux 是所有开发者心目中的神。其作者 Linus Tovalds 更是因 Linux 成为无数开发者心目中的英雄。

**但是，知道 Linux 和真正上手 Linux ，又有很大的差距。**

一提到 Linux ，你心目中一定都是这样的命令行窗口。 

![](../Images/2818fd2f32689a25763b70648e27235e.png)

一条条闪的人眼花缭乱的命令；让你无所适从的命令行界面，这些因素，让你从一开始就对 Linux 产生了恐惧。太多没有章法的 Linux 教程，让初学者们失去了学习的耐心和信心。

接管了这个世界的 Linux

作为一个互联网从业者，你应该，也必须掌握 Linux 。毕竟，Linux 不仅仅接管了互联网，更是接管了这个世界。上到我们所熟悉的网站，超过三分之一的网站使用 Linux 来托管；  

  

![](../Images/f8edd955bc7a961f1031b12d1f413916.png)

下到我们的手机， 移动端设备市场占有率最大的 Android 正是基于 Linux 而写就的；而互联网的未来，物联网 IOT， 更是有大量的设备和系统都是基于 Linux 开发的。

  

![](../Images/df02cd4587059f8ba9be2b9382d2a268.png)

可以说，如果你想要在这个世界生存，你就离不开 Linux，更离不开 Linux 所构建的应用生态。

学好 Linux，很难么？

提到 Linux， 大多数人都退却了。是的，我们已经熟悉了 Windows 下的鼠标点击、拖拽的操作，熟悉了可视化的操作界面。

但是，如果你不是一个甘愿被别人所制作的简单工具所慢慢驯化的人，你就应当来学一学 Linux ，来掌握真正值得掌握的东西。Linux 其实并不难，你差的，只是一个好的教材罢了。目前互联网上鱼龙混杂的教程，让你从一开始，就失去了学好 Linux 的可能。

一本好的 Linux 教程应该是什么样的？

一本好的 Linux 教材，应当照顾到学生的学习进度，能够帮助到学生快速上手 Linux ，再帮助学生从最常见的用法开始，循序渐进，逐渐接触到企业级的应用。让学员能给从小白开始，一路走到 Linux 初级运维工程师，掌握最基础的 Linux 运维的操作。

从内容的设置上，应该尽可能的考虑到各层次学生的水平，既有基础的环境配置，帮助学生快速开始使用 Linux ，又应当提供了常见的企业应用，如 Apache 、Nginx、MySQL、VSFTPd、SQUID 等软件的使用。

这样的教程，才能够做到帮助学生学会 Linux、 学好 Linux 。

《 Linux 就该这么学》整合了刘遄老师多年 Linux 教学的经验，并结合大家学习过程中的重点和难点，安排了丰富的学习内容。

在章节安排上，《Linux 就该这么学》根据学生的情况，提供了从基础到实战的内容。

1.  **部署虚拟环境安装 Linux 系统**：第一章带领学生学习如何部署 Linux，从用中学，从学中用，帮助学生以最深刻的方式学习和理解 Linux。
    
2.  **新手必须掌握的 Linux 命令及管道符、重定向与环境变量**：第二、三章带领学生学习 Linux 最基础的命令、管道符、重定向、环境变量等信息，帮助学生掌握 Linux 最基础和强大的用法，让学生从一个 Linux 用户向一个 Linux 运维工程师转变。
    
3.  **Vim 编辑器与 Shell 命令脚本**：第四章着重讲解在 Linux 中最常用的编辑器 —— Vim ，任何一个发行版都会包含vim，以及运维工程师们必备技能 —— Shell 脚本，一个合格的 Linux 运维工程师，必须能够编写自己的 Shell 脚本。
    
4.  **用户身份与文件权限及存储结构与磁盘划分**：第五、六章则着重关注文件。在 Linux 中，万物皆文件，想要用好 Linux ，你就必须明确和理解 Linux 中的文件系统、文件权限、存储、磁盘等信息。掌握了这些用法，再复杂的问题都可以轻松的找到解决的思路。
    
5.  **使用 RAID 与 LVM 磁盘阵列技术**：在企业中使用 Linux 时，数据安全是非常重要的，了解 RAID 技术，将帮助你更好的在工作中做好数据安全的备份，为数据安全提供保障。
    
6.  **iptables 与 firewalld 防火墙**： Linux 在企业应用中一般作为服务端操作系统提供服务，因此，安全也是非常重要的话题，借助 iptables 和 firewalld ，你可以更加简单的进行网络方面的安全防护。
    
7.  **使用 ssh 服务管理远程主机**：在云计算盛行的大环境下，远程管理服务器成为了主流，因此，掌握 SSH 服务的应用，可以帮助你管理好云上的服务器。
    
8.  **常用企业应用的使用**：在完成了基础内容的教学后，《Linux就该这么学》还介绍了大量企业中常用的应用，包括Apache、vsftpd、Samba、BIND、DHCP、Postifx、Squid、iSCSI、MariaDB、PXE无人值守安装、LNMP 等服务，帮助学生在了解了基础后，掌握 Linux 实战能力，从而能够成为一个合格的初级 Linux 运维工程师。
