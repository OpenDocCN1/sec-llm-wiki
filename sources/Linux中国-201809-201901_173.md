# 【每日安全资讯】搜索引擎Startpage推出“Anonymous View”功能：更妥善保护隐私

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664612770&idx=5&sn=c0e0abe91160b9425a35a279d145dec4&chksm=bdcef8e48ab971f29d21d22ad3a64fcce6eb1589893e305a988781c2e5be11b37306c7b1daf0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664612770&idx=5&sn=c0e0abe91160b9425a35a279d145dec4&chksm=bdcef8e48ab971f29d21d22ad3a64fcce6eb1589893e305a988781c2e5be11b37306c7b1daf0&scene=27#wechat_redirect)

隐私搜索引擎Startpage近期宣布推出“Anonymous View”（匿名视图）新功能，用户在上网过程中可以防止被跟踪。这项新功能类似于其他代理服务，不过通过更改JavaScript脚本防止浏览器和设备足迹，从而更妥善地保护用户隐私。

![](../Images/376ada74483c5c013756733f49149306.png)

Startpage首席执行官Robert Beens表示：“通过这项功能创新，我们能更妥善地保护用户隐私。有别于其他搜索引擎，匿名视图非常易于使用。同用户浏览器的隐身模式（incognito mode）不同，匿名视图可以真正的提供全方位的保护。它整合了隐私搜索和隐私上网的特性。”

![](../Images/70ad4a646b833bd14cc3ac1e90750ae2.png)

用户可以充分利用这项新功能来执行搜索，并且在每个搜索结果中点击匿名视图模式访问。在用户点击这个按钮之后，Startpage会检索页面，并向用户提醒任何可能追踪到你的JavaScript脚本。在其帮助页面中，Startpage指出Anonymous View提供的保护比VPN服务更稳妥，因为VPN无法抵御浏览器和设备识别。
