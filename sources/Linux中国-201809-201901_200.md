# 【每日安全资讯】任天堂的Switch bootROM硬件缺陷解决方案已被攻破

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664612723&idx=6&sn=b2fade58b3e064e175b4efc6f364ee2b&chksm=bdcef8358ab97123ede9b55b342797968210f97615fd39313546b68b0aac9f91ca2285c54588&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664612723&idx=6&sn=b2fade58b3e064e175b4efc6f364ee2b&chksm=bdcef8358ab97123ede9b55b342797968210f97615fd39313546b68b0aac9f91ca2285c54588&scene=27#wechat_redirect)

本周任天堂发布了Switch的System Update 6.2.0，尽管更新的更新日志被简单列为“一般系统稳定性改进以增强用户体验”。这本身可能听起来有点无害，但玩家很快就发现厂商正在试图解决之前在Nvidia Tegra bootROM中发现的缺陷，这一操作是通过重建安全启动过程完成的。

除了解决硬件缺陷之外，任天堂还将“CDN下载”的测试过程结束，这是一种用于识别任天堂eShop上新发布的游戏的方法，为了访问该平台，每个人都必须升级到System Update 6.2.0。

当然，在任何猫捉老鼠游戏中，许多人都在等待黑客对最新的发展做出最快的响应。看上去6.2.0更新的修补工作并不是很有效，很快黑客就只用了几天的时间证明该版本被成功破解，同时还在Twitter秀了一把密钥。
