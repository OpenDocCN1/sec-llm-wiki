什么是 RAM

计算机内存是能够临时或永久存储信息的物理设备。RAM 代表随机存取存储器，它是一种易失性存储器，用于存储操作系统，软件和硬件使用的信息。

有两种类型的内存可供选择：

◈ 主存◈ 辅助内存

主存是计算机的主存储器。CPU 可以直接读取或写入此内存。它固定在电脑的主板上。

◈ **RAM**：随机存取存储器是临时存储。关闭计算机后，此信息将消失。◈ **ROM**： 只读存储器是永久存储，即使系统关闭也能保存数据。

方法-2：使用 /proc/meminfo 文件

`/proc/meminfo` 是一个虚拟文本文件，它包含有关系统 RAM 使用情况的大量有价值的信息。

它报告系统上的空闲和已用内存（物理和交换）的数量。

```
1.  `$ grep MemTotal /proc/meminfo`
    
2.  `MemTotal:        2041396 kB`
    
3.  
    
4.  `$ grep MemTotal /proc/meminfo | awk '{print $2 / 1024}'`
    
5.  `1993.55`
    
6.  
    
7.  `$ grep MemTotal /proc/meminfo | awk '{print $2 / 1024 / 1024}'`
    
8.  `1.94683`
    
```
