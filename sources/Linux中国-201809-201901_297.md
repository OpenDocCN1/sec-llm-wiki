# 【每日安全资讯】研究人员实现在指纹里编码秘密信息

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664612515&idx=5&sn=53ba6fd7a63a7617e061e27760a0cf20&chksm=bdcef9e58ab970f374c6623875aaf28ac84f482e383f7d40e104a95339e10eb7ad3b02b9920c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664612515&idx=5&sn=53ba6fd7a63a7617e061e27760a0cf20&chksm=bdcef9e58ab970f374c6623875aaf28ac84f482e383f7d40e104a95339e10eb7ad3b02b9920c&scene=27#wechat_redirect)

指纹不只是代表一个人的身份，它也许还能传递信息。中国复旦大学的研究人员在《IEEE Transactions on Image Processing》上发表论文，描述了如何在指纹里编码秘密信息的方法。

指纹中的某些特征如沟脊和分叉图案可以编码信息，研究人员首先将想要编码的秘密信息编码到多项式数学方程式，这些秘密信息可以是一个网址或“同一个地方上午十点见”，然后将秘密信息映射到指纹螺旋特征中的一系列 2D 点。

![](../Images/8ae3603837115c23276c264623092ed0.png)

所有数据点合并创建一个指纹的全息图，只有掌握密钥的人才能从指纹里重构多项式，解码信息。
