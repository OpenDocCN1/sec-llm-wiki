# 【每日安全资讯】赛门铁克Norton ConnectSafe将于11月15日停服

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664612428&idx=5&sn=9b625c64ec4c3303043b4ce4188e0a54&chksm=bdcef90a8ab9701c016a9bbd7142a06c10af7dbb493980a1c2bda9bed231d91a4f1061d4cf8a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664612428&idx=5&sn=9b625c64ec4c3303043b4ce4188e0a54&chksm=bdcef90a8ab9701c016a9bbd7142a06c10af7dbb493980a1c2bda9bed231d91a4f1061d4cf8a&scene=27#wechat_redirect)

赛门铁克于 2010 年推出了 Norton DNS 服务，并于 2014 年将其重命名为 Norton ConnectSafe。 该服务是在诸多互联网巨头企业开始推出免费公共 DNS 服务时推出的。赛门铁克承诺，其服务将让用户的互联网连接比 ISP 的默认 DNS服务更安全、更快速、更可靠。

![](../Images/24d3628f863384613331023f97feed1e.png)

该服务支持多个 DNS IP 地址，旨在保护用户免受恶意 Internet 流量和活动的侵害，并可选择作为成人内容和其他非家庭友好内容的阻止程序。

现在，赛门铁克宣布将于 2018 年 11 月 15 日关闭 Norton ConnectSafe 服务，届时使用 Norton ConnectSafe DNS 服务器的设备将无法再连接到 Internet 站点和其它互联网服务。如果有在使用 Norton ConnectSafe 的用户建议尽快更换到其它公共 DNS。
