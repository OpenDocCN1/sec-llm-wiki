【每日安全资讯】PHP 危矣？Zend Engine 团队宣布脱离 Rogue Wave

Zend Engine 是一个开源脚本引擎，因作为 PHP 语言的重要核心而闻名。PHP 的两位主要贡献者 Andi Gutmans 与 Zeev Suraski 在1999年开发了 Zend Engine ，并成立 Zend 技术公司。之后，该公司陆续推出 Zend Studio 集成开发环境、Zend Framework 开发框架、Zend Optimizer 优化器等产品，被誉为“ PHP 推动者”。

2015年，Zend 技术公司被 Rogue Wave Software 收购，2016 年 Andi Gutmans 离开 Rogue Wave 加入 AWS 。

2018年10月17日，Zeev Suraski 在其个人博客上表示，非常感激 Rogue Wave 在过去的三年里一直庇护着他和团队进行 Zend Engine 的相关开发工作。不过，Rogue Wave 最近做出了一项战略决策，将其后续工作重点放在 Zend Server 部分。因此，Zeev Suraski 和他的团队 - 包括 Dmitry Stogov、Matthew Weier O'Phinney 和 Enrico Zimuel 决定将离开公司并寻找新的机会。

据悉，除了 Zend Engine ，Zeev Suraski 和其团队目前还领导着 Zend Framework、Apigility 和 Zend Expressive 等组件的开发工作，这些产品均归属于 Rogue Wave 。他们的退出，让许多 PHP 开发者和爱好者对 PHP 的未来表示担忧。Zeev 在推特上回复称，他们正在探索是否有其他方式能继续为 Zend Engine 和 PHP 8 做出贡献。
