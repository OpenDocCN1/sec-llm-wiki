Nat Friedman, Future CEO, GitHub‍

  

Nat 是微软的全球副总裁，负责开发人员服务团队，众所周知，他也将在未来接任 GitHub 首席执行官。他热衷于打造能够取悦开发者的产品。2011年, Nat 与 Miguel de Icaza 共同创立了Xamarin 公司, 并在2016年微软收购后担任首席执行官。在早年的职业生涯中, Nat 曾担任Novell Linux 业务的首席技术官, 于1999年与 Miguel 共同创办 Xamarin, 并于1997年共同创立并担任 GNOME 基金会主席。Nat 有麻省理工学院的计算机和数学两个学位, 之后的27年一直不间断地在编写软件。Nat 是一个狂热的旅行者, 活跃的天使投资人，同时还是一个小飞机飞行员。

**Nat 说：**

  

微软在 Satya Nadella 的带领下，变成了一家新的公司, 这家新公司将开源和开发者 (这也是微软收购 Xamarin 这个跨平台开发工具的最主要原因）放在公司日常运作的核心位置。在过去的几年中, 微软将公司的未来下重注在开源和与社区合作之上。开源是微软构建开发工具、提供微软公有云 (Azure) 服务，以及投资社区的最重要的基石。

 

很多人可能不知道，在收购 GitHub 之前, 微软已经是是 GitHub 上最活跃的组织, 拥有超过2万名员工参与项目贡献。微软员工目前已经对开源软件项目进行了200万多次提交 (Commits)。微软的许多产品 (例如 VS Code、. NET Core、TypeScript 等) 都是在 GitHub 上公开开发和维护的。VS Code 是我们最受欢迎和被广泛使用的开发工具之一, 它比 GitHub 上的任何项目都拥有更多的贡献者。同时, 微软员工还积极参与了二千多个开源项目, 如 Kubernetes、Hadoop、Python、Moby、React、Linux 内核等等。

 

这次微软收购 GitHub 坚定地重申了开源对微软和微软客户有多么重要。开发人员是解决世界上最紧迫挑战的中心, 每个开发人员都需要能够协作、共享代码并在彼此的工作成果上精益求精。目前已经有超过2800万名开发人员在 GitHub 上进行了协作, 它几乎是每个国家的所有用户在使用的8500万多个代码库的家。这就是开源以及 GitHub 的真实力量 。
