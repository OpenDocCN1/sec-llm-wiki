# 【每日安全资讯】Chrome严苛规范扩展程序：2019年启用两步身份认证

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664612189&idx=3&sn=0c312d9febf02bbb1df1fcbcbc924a50&chksm=bdcefa1b8ab9730dfbba6dc44f439eaf781d85aec13a2ee3d41ca2f5a89155aa1721d803a4cd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664612189&idx=3&sn=0c312d9febf02bbb1df1fcbcbc924a50&chksm=bdcefa1b8ab9730dfbba6dc44f439eaf781d85aec13a2ee3d41ca2f5a89155aa1721d803a4cd&scene=27#wechat_redirect)

Chrome扩展程序极大的丰富了我们的上网体验，带来了更个性化的外观、功能、效率体验。近日谷歌启动新一轮打击行动，阻止扩展程序获得合理范围之外的那些权限。本周一，Google宣布了一系列扩展程序规范，确保进一步规范和管理扩展程序。

![](../Images/2ca2748c46f6a33263e173138fc035c5.png)

这些扩展新规包括：

● Google允许用户对扩展程序进行限制，使其仅限于某些特定网站。此外用户也可以设置要求扩展每次运行必须要征询用户的许可。

![](../Images/cd9992705bf08486df9993d133003b8d.png)

● Google将会对那些需要调用浏览器之外能源的扩展程序进行严苛规范，并且拒绝底层编程代码被混淆以致于很难阅读的扩展

● Google要扩展程序开发人员在2019使用两步身份验证，以使某些人更难以劫持该帐户以分发错误版本的扩展程序。

![](../Images/b1ed8a45c99ab4a111f40d647935e527.png)

两步身份验证功能允许Chrome扩展程序开发人员针对想要破坏其帐户并将其扩展程序的恶意副本推送到商店的攻击者添加额外的保护层。根据Wagner的说法，“我们从Chrome网上应用店阻止的超过70％的恶意和政策违规扩展包含混淆代码。”
