中国 Linux 内核开发者大会是 Linux 内核方面的纯技术研讨会。会议始于2006 年，在国内 Linux 技术爱好者、业内公司及各高校的支持下已召开十二届。本次大会继承历届会议传统，聚焦、关注新兴热点技术性话题，旨在促进国内 Linux 内核社区的技术交流，相互学习共同成长，诚邀广大 Linux 内核开发者及爱好者参加本次大会。 

本届大会由南京富士通南大软件技术有限公司、英特尔（中国）有限公司、国际商业机器（中国）投资有限公司共同主办。除此之外，感谢富士通南大、Intel、IBM、阿里巴巴、润云科技为本届大会提供赞助；感谢 Linux 宝库、Linux 中国社区提供媒体支持。


会议时间：2018.10.14（周日）

会议地点：南京大学（鼓楼校区）科技馆 1F/2F

报名方式：大会官方网站 http://www.ckernel.org （点击“查看原文”），请完整填写资料，出现“我们已收到您的报名”之后表示报名完成。审核通过后，组委会将向您发送确认函。收到确认函（邮件形式）的人员，方可参加本次大会。
