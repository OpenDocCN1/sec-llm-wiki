# 【每日安全资讯】白帽黑客扬言直播周末删掉扎克伯格Facebook账号

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664612154&idx=5&sn=cecaf16e5ef8ef01a93a38af89d6f625&chksm=bdcefa7c8ab9736a4e6a9b578ea56991d577f7deb700efdebf758348138ffce4b6cd5738a053&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664612154&idx=5&sn=cecaf16e5ef8ef01a93a38af89d6f625&chksm=bdcefa7c8ab9736a4e6a9b578ea56991d577f7deb700efdebf758348138ffce4b6cd5738a053&scene=27#wechat_redirect)

据外媒报道，一位拥有 2.6 万粉丝的“白帽”黑客近日扬言，要举办一场删除 Facebook CEO 个人账号的流媒体直播。从这位“Chang Chi-yuan”的自我介绍来看，他在 2016 Line Corp“除虫奖赏名人堂”中被列为“特殊贡献者”。他的个人经历也很是有趣，据说因为入侵交通系统、只花 1 元新台币（约 3 美分）购买了一张车票，而被当地公交公司给提告了。此外，这位“白帽”还公布了 Facebook 对其漏洞报告的回应函截图。

![](../Images/06e709debbfab62730e11570db874fa2.png)

外媒指出，Chang 此前还写过利用黑客技术来谋利的文章。Facebook 有一个持续的“除虫奖赏”计划，宣称会在认定后、向主动汇报其服务漏洞的安全研究人员发放奖励。

![](../Images/69b501bc026b05f0e56d46256d4e161b.png)

当然，即便这位“白帽”本次得逞，也算不上开了先例。毕竟树大招风的扎克伯格，早就已经习惯了被轮番攻击了。比如 2011 年的时候，一名黑客就利用小扎的账号发布了一条状态更新。
