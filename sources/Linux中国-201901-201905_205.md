这个我们已经多次讨论过。但是，我还要简要介绍一下它。截至目前，还没有官方的 Google 云端硬盘的 Linux 客户端，我们需要使用非官方客户端。Linux 中有许多集成 Google 云端硬盘的应用。每个应用都提供了一组功能。

我们过去在网站上写过一些此类文章。

这些文章是 DriveSync\[1\] 、[Google Drive Ocamlfuse 客户端](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664613362&idx=3&sn=bf09fa52c71f75e0b19cd9001812c3ae&chksm=bdcefeb48ab977a28179b374f6c7ecfa1925724e791ec9696518da2c3934c574a108c62f791e&scene=21#wechat_redirect)\[2\] 和 在 Linux 中使用 Nautilus 文件管理器挂载 Google 云端硬盘\[3\]。

今天我们也将讨论相同的主题，程序名字是 ODrive。

ODrive 是什么？

ODrive 意即 Open Drive。它是 Google 云端硬盘的图形客户端，它用 electron 框架编写。

它简单的图形界面能让用户几步就能集成 Google 云端硬盘。

如何在 Linux 上安装和设置 ODrive？

由于开发者提供了 AppImage 包，因此在 Linux 上安装 ODrive 没有任何困难。

只需使用 `wget` 命令从开发者的 GitHub 页面下载最新的 ODrive AppImage 包。

```
1.  `$ wget https://github.com/liberodark/ODrive/releases/download/0.1.3/odrive-0.1.3-x86_64.AppImage`
```

你必须为 ODrive AppImage 文件设置可执行文件权限。

```
1.  `$ chmod +x odrive-0.1.3-x86_64.AppImage`
```

只需运行 ODrive AppImage 文件以启动 ODrive GUI 以进行进一步设置。

```
1.  `$ ./odrive-0.1.3-x86_64.AppImage`
```

运行上述命令时，可能会看到下面的窗口。只需按下“下一步”按钮即可进行进一步设置。

![](../Images/27f2c57d622b8a5bd0be742aa91c1b71.png)

点击“连接”链接添加 Google 云端硬盘帐户。

![](../Images/5b463e3a6b58290e5ed3c74c9c2ca2c9.png)

输入你要设置 Google 云端硬盘帐户的电子邮箱。

![](../Images/527e0b440a1650cd28399f07f18199f3.png)

输入邮箱密码。

![](../Images/ed94287a69bbdf08e482331679bf173e.png)

允许 ODrive 访问你的 Google 帐户。

![](../Images/c48b871f2f74f83b73f232ce0712ffba.png)

默认情况下，它将选择文件夹位置。如果你要选择特定文件夹，则可以更改。

![](../Images/48a0da9709e2fdbb2552591caaccc45c.png)

最后点击“同步”按钮开始将文件从 Google 下载到本地系统。

![](../Images/ebcf3d3ffc298b531498327cda67868c.png)

同步正在进行中。

![](../Images/5d839c8c9f0390d782ba8433293c319e.png)

同步完成后。它会显示所有已下载的文件。

![](../Images/b14edace7126c130b6752a5c19310998.png)

我看到所有文件都下载到上述目录中。

![](../Images/c4a776f585911b37df2e46ebc10e2c99.png)

如果要将本地系统中的任何新文件同步到 Google 。只需从应用菜单启动 “ODrive”，但它不会实际启动应用。它将在后台运行，我们可以使用 `ps` 命令查看。

```
1.  `$ ps -df | grep odrive`
```

![](../Images/e54ac4235f99fec03e900fd87abe7587.png)

将新文件添加到 Google文件夹后，它会自动开始同步。从通知菜单中也可以看到。是的，我看到一个文件已同步到 Google 中。

![](../Images/c27c96c0ad2b23e12344683100726c0d.png)

同步完成后图形界面没有加载，我不确定这个功能。我会向开发者反馈之后，根据他的反馈更新。
