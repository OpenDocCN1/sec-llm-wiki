读这些书，不再为技能点发愁

推荐理由

这本书是一本 Python 入门书，以习题的方式引导读者一步一步学习编程，从简单的打印一直讲到完整项目的实现，让初学者从基础的编程技术入手，最终体验到软件开发的基本过程。每一章的格式基本相同，以代码习题开始，按照说明编写代码并运行，然后再做巩固练习。

推荐理由

这本书是编程入门类的畅销书，面向所有层次的 Python 读者。全书分两部分：基础篇与实战篇。基础篇介绍了用 Python 编程所必须了解的基本概念，实战篇将理论付诸实践，讲解如何开发三个项目，并帮读者解决常见编程问题和困惑。随书代码还能帮助读者更高效地练习程序。这本书帮助众多读者成为了有扎实基础的 Python 程序员，收获了很多好评。

推荐理由

这本书以丰富的例子、通俗易懂的语言、简单的图示，详细地介绍了 Java 开发中重点用到的多种技术。从基本概念到实际案例应用均有详细的介绍。这本书还附带了长达 60 小时的教学视频、源代码和PPT电子教案，另外专门提供了论坛为读者解答问题。作者有多年的开发和教学经验，先后为40多家大中型企业做过培训，在 Java 培训方面享有很高的知名度。

推荐理由

这是一本非常高效且精炼的 Web 前端开发入门书。结合大量实战开发经验，将前端开发知识系统化整理，浓缩精华，直击初学者的痛点。 全书共分为三大部分，HTML：学习网页的结构。CSS：学习网页的样式。JavaScript：学习网页的行为。随书配备了在线教程、在线问答、面试练习题以及各种素材资源，为读者提供全方位的学习服务。


推荐理由

JavaScript 这门语言简单易用，很容易上手。但其语言本身有很多复杂的概念，即使是经验丰富的 JavaScript 开发人员，如果没有认真学习的话也无法真正理解它们。这本书直面当前 JavaScript 开发者“不求甚解”的大趋势，深入理解语言内部的机制，全面介绍了 JavaScript 中常被人误解和忽视的重要知识点。这套书共分为上、中、下三卷。上卷介绍了“作用域和闭包”以及“this 和对象原型”；中卷介绍了“类型和语法”以及“异步和性能”；下卷介绍了 JavaScript 入门知识和对 ES6 及未来发展趋势的展望。


推荐理由

这本书是知名度颇高的 Linux 入门书《鸟哥的 Linux 私房菜基础学习篇》的新版，全面而详细地介绍了 Linux 操作系统。作者曾任台湾多家知名 Linux 教育中心讲师，专长是 Linux 操作系统、网站规划与维护、网络安全。这本书内容丰富全面，基本概念的讲解非常细致，深入浅出。各种功能和命令的介绍，都配以大量的实例操作和详尽的解析，是学习 Linux 的一本入门好书。


推荐理由

这本书以探索之旅的形式，从在浏览器中输入网址开始，一路追踪了到显示出网页内容为止的整个过程，以图配文，讲解了网络的全貌，帮助读者理解网络的本质意义，理解实际的设备和软件，进而熟练运用网络技术。非常适合计算机、网络爱好者及相关从业人员阅读。


推荐理由

这本书包含了丰富的示例，图文并茂，以容易理解的示例阐释了算法，旨在帮助程序员在日常项目中更好地发挥算法的能量。书中的前三章将帮助你打下基础，带你学习二分查找、大 O 表示法、两种基本的数据结构以及递归等。余下的篇幅将主要介绍应用广泛的算法，具体内容包括：面对具体问题时的解决技巧，比如，何时采用贪婪算法或动态规划；散列表的应用；图算法；K最近邻算法。适合所有程序员、计算机专业相关师生以及对算法感兴趣的读者。


推荐理由

作为算法领域的参考书，这本书全面介绍了关于算法和数据结构的必备知识，并特别针对排序、搜索、图处理和字符串处理进行了论述。书中均有算法的完整 Java 代码，而且这些代码实现采用了模块化的编程风格，读者可以方便地加以改造。这本书的一个亮点是它的配套网站，提供了代码实现、测试数据、练习、教学课件等多种资源，浏览起来十分方便。

信息化时代，计算机的发展日新月异。刷脸支付、语音识别、机器翻译等智能应用层出不穷，极大地方便了人们的生活。但是，作为计算机专业的学生，你真的了解这些神奇的功能是如何实现的吗？你知道下一代黑科技产品将会出现在哪个领域吗？如果你的答案是“No”，那么，你真的需要好好了解一下你所在的计算机世界了！

读这些书，让视野更上一层楼


推荐理由

《浪潮之巅（第三版）》是在数字时代，IT 人非读不可，而非 IT 人也应该拜读的作品。这本书除了讲述科技企业的发展规律，对于华尔街如何左右科技公司，以及金融风暴对科技产业的冲击，也多有着墨。此外，这本书也着力讲述很多对尚在普及或将要发生的，比如微博和云计算，以及下一代互联网科技产业浪潮的判断和预测。如作者所言：“科技的发展不是均匀的，而是以浪潮的形式出现。每一个人都应该看清楚浪潮，赶上浪潮，如此，便不枉此生。”

推荐理由

从 2001 年起，MIT 每年都会公布“10大突破技术”，即 TR10（Technology Review 10），并预测其大规模商业化的潜力以及对人类生活和社会的重大影响。《科技之巅+科技之巅2》汇集了麻省理工科技评论对 2012-2017 年共 60 大全球突破性技术的深度剖析，如特斯拉自动驾驶仪、360°自拍、刷脸支付等等，能够帮助计算机学生了解世界科技的发展前沿和未来的研究方向。


推荐理由

《人工智能简史》用一本书的篇幅，讲述人工智能的发展史，几乎覆盖人工智能学科的所有领域。包括人工智能的起源、自动定理证明、专家系统、神经网络、自然语言处理、遗传算法、深度学习、强化学习、超级智能、哲学问题和未来趋势等。这本书将人工智能这个物种的家世渊源、名字由来、出身血脉、派系争斗、繁衍进化甚至基因变异等，梳理得清清楚楚，绝对是人工智能时代不可不读的科普好书。  


推荐理由

这本书是硅谷创业之父 Paul Graham 的文集，以新的视角展示了当今IT技术浸透下的世界。主要介绍黑客的爱好和动机，讨论黑客成长、黑客对世界的贡献，以及编程语言和黑客工作方法等所有对计算机时代感兴趣的人的一些话题。书中的内容不但有助于了解计算机编程的本质、互联网行业的规则，还会帮助读者了解我们这个时代，认识黑客大脑内部的世界，充满了离经叛道的洞见与实践的智慧。

推荐理由

计算机编程教会人如何思考，而计算机科学对于实现高效的程序设计至关重要。这本书以简明扼要的形式介绍了计算机科学的重要知识点，尽量少涉及学术概念，着力将抽象理论具体化，复杂问题简单化，既适合程序员巩固编程基础，也适合普通读者了解计算思维，学会用高效的方法解决问题。


推荐理由

深度学习自 2006 年被正式提出后，得到了巨大发展，使人工智能产生了革命性的突破。《深度学习》是一本凡研究深度学习都知道的一本书，是深度学习领域奠基性的经典教材。内容主要包括深度学习的预备知识、现今已成熟的深度学习方法和技术，以及某些具有前瞻性的方向和想法，即深度学习未来的研究重点。《深度学习》适合各类读者阅读，包括相关专业的大学生或研究生，以及不具有机器学习或统计背景、但是想要快速补充深度学习知识，以便在实际产品或平台中应用的软件工程师，是一本需要放在案头反复研读的经典书籍。


推荐理由

数学在信息产业中的应用越来越广泛，语音识别、机器翻译等神奇的问题都是用数学解决的。“数学之美”最初是从 2006 年起在 Google 中国的官方博客——谷歌黑板报上连载的系列文章，获得上百万次点击，得到了读者的高度评价。《数学之美》把高深的数学原理讲得更加通俗易懂，让非专业读者也能领略数学的魅力。作者在第二版中，特别增加了针对大数据和机器学习的内容，以便满足人们对当下技术的学习需求。

推荐理由

英语一向是程序员阅读源码和英文IT文档的拦路虎。这本书是专门针对开发人员的英语读解能力训练项目，设置了不同的难易度目录，读者可根据自己的英语水平进行针对性的学习。书中借助 新IT媒体风格的报道，提供有趣且有益的知识，内容和形式都贴合一线程序员需求，提供了“语言和技术”的双保险。

计算机的世界是丰富多彩的，既充满了乐趣，也充满了困难与挑战。同学们不妨静下心来，选几本好书，细细品味计算机世界的魅力。
