# 【每日安全资讯】新一批845GB账密数据库流出：含250亿条纪录和22亿组唯一登录凭证

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664613316&idx=4&sn=29703038dcb62ace3a258bf4e243960b&chksm=bdcefe828ab97794e034d462479f6655a78f61b5179c7d8258a93687315da60a951f51468e2a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664613316&idx=4&sn=29703038dcb62ace3a258bf4e243960b&chksm=bdcefe828ab97794e034d462479f6655a78f61b5179c7d8258a93687315da60a951f51468e2a&scene=27#wechat_redirect)

上月早些时候，黑客社区曝出了一个 87GB 的庞大数据库（Collection #1）。安全研究人员 Troy Hunt 指出，其中包括了大约 7.73 亿个电子邮件地址、以及 2100 万组密码。然而最新爆料称，近日又有一个 845GB 的数据库流出（Collection #2-5），其中包含了惊人的 250 亿条记录，涉及 22 亿组唯一用户名和密码。

![](../Images/755b3e33e133611d387363529d59da6c.png)

与 Collection #2-5 相比，Collection #1 都显得有些微不足道。

安全研究人员称，转储的大部分数据，涉及雅虎（Yahoo）、领英（LinkedIn）、网络随身碟（Dropbox）等公司的旧漏洞，但也有部分数据相对较新。

*物联网安全公司 Phosphorus.io 创始人 Chris Rouland 在接受《连线》（Wired）采访时称，这是他们见过的最大的泄露数据库集合。*

更糟糕的是，其已在黑客社区中广泛流传。Rouland 表示,截至昨日，它已被超过 130 人“续种”、下载量超过 1000 次。

*可能的情况是，某些大型黑客早就对这部分数据进行了充分的利用。在传递了多年之后，有人最终决定将它编译成大型的文件转储。*

即便如此，这些数据仍可能被一些小型黑客所利用，比如发起针对个人社交媒体账户的入侵行动。

*如不确定自己的隐私信息是否在列，可参考 Hasso Plattner Institute 提供的查询工具。*

至于将来是否还有更多的数据流出，目前暂不得而知。
