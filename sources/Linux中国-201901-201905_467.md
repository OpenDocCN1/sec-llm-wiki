# 【每日安全资讯】建筑工地上的大型机械设备极容易被黑客入侵

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664613180&idx=4&sn=f31758a46e7be86fc0f5b2f2ef9b9586&chksm=bdcefe7a8ab9776c3fda80f9f5131dc81a456cf0670db348731f1fa4e4f16efc428ba6b7b45e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664613180&idx=4&sn=f31758a46e7be86fc0f5b2f2ef9b9586&chksm=bdcefe7a8ab9776c3fda80f9f5131dc81a456cf0670db348731f1fa4e4f16efc428ba6b7b45e&scene=27#wechat_redirect)

黑客入侵建筑工地，并控制施工车辆进行大肆破坏。这听起来像是好莱坞大片，但不幸的是这是现实生活中发生的场景。趋势科技（Trend Micro）研究人员Federico Maggi和Marco Balduzzi上周进行了演示，如何成功入侵并控制建筑工地上的起重机进行各种任务。如果黑客利用这种方式完全可以肆意破坏建筑工地。

![](../Images/ecd245a8c188f2eb1cddcd7d6750957c.png)

图片来自于 Federico Maggi

在这篇论文今天发表之前，两位安全专家接受了外媒福布斯的采访，谈及了攻击后可以做什么以及为何他们为此担心。基本上这段对话有点像是一次非常奇怪的公路旅行。两位专家坐在红色的大众POLO上，参观了意大利十多个建筑工地并同负责施工的经理进行了交谈。

观看视频：https://v.youku.com/v\_show/id\_XNDAxNTE5NzA2OA==.html?spm=a1z3jc.11711052.0.0&isextonly=1

在交谈中他们回忆起和名为Matteo的施工队长的打赌。首先经理Matteo被要求关闭现场唯一能控制起重机的发射器，并且使起重机处于“停止”状态。然后两位安全专家通过笔记本电脑、一些无线电硬件、特制的攻击脚本成功控制了起重机，不仅开动起来而且还能进行起重作业。

随后他们到访了14个建筑施工工地，除了起重机之外还成功控制了挖掘机，铲运机和其他大型机械的设备。研究人员在周二公布的福布斯案前的一篇论文中写道，其后果包括“从盗窃和勒索到破坏和伤害”。
