正在寻找基于终端的游戏来打发时间么？来看看 2048-cli 吧。

你好，欢迎来到今天的 Linux 命令行玩具日历。每天，我们会为你的终端带来一个不同的玩具：它可能是一个游戏或任何简单的消遣，可以帮助你获得乐趣。

很可能你们中的一些人之前已经看过我们日历中的各种玩具，但我们希望每个人至少见到一件新事物。

今天的玩具是我最喜欢的休闲游戏之一 2048[1] （它本身就是另外一个克隆品的克隆）的命令行版本[2]。

要进行游戏，你只需将滑块向上、向下、向左、向右移动，组合成对的数字，并增加数值，直到你得到数字为 2048 的块。最吸引人的地方（以及挑战）是你不能只移动一个滑块，而是需要移动屏幕上的每一块。（LCTT 译注：不知道有没有人在我们 Linux 中国的网站上遇到过 404[3] 页面？那就是一个 2048 游戏，经常我错误地打开一个不存在的页面时，本应该去修复这个问题，却不小心沉迷于其中……PS.,怀旧的话，我特意将本文的“阅读原文”替换成了 2048 游戏……JS载入或许有点慢，稍等或刷新）

它简单、有趣，很容易在里面沉迷几个小时。这个 2048 的克隆 2048-cli[2] 是 Marc Tiehuis 用 C 编写的，并在 MIT 许可下开源。你可以在 GitHub[2] 上找到源代码，你也可在这找到适用于你的平台的安装说明。由于它已为 Fedora 打包，因此我来说，安装就像下面那样简单：

  1. $ sudo dnf install 2048-cli

这是这样，玩得开心！
