# 【每日安全资讯】目前美国已掌握数TB的维基解密数据

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664613158&idx=4&sn=8a5f869ecd949322f80ae457064bb644&chksm=bdcefe608ab97776c5c864118daa80a5a0fa3af2b7c2fe9f2bed703b1c177e7001bd00e5c844&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664613158&idx=4&sn=8a5f869ecd949322f80ae457064bb644&chksm=bdcefe608ab97776c5c864118daa80a5a0fa3af2b7c2fe9f2bed703b1c177e7001bd00e5c844&scene=27#wechat_redirect)

援引外媒去年11月报道，根据检方提交的法庭文件意外显示维基解密创始人朱利安·阿桑奇（Julian Assange）已被美国司法部以未指明的罪名起诉。此后美国联邦调查局（FBI）再次确认正在对维基解密进行调查，在华尔街日报的报道中美国司法部对引渡阿桑奇表示乐观。随后部分机密文档被曝光，暗示维基解密和阿桑奇对政府和企业发起了黑客攻击。

目前针对阿桑奇的指控并未正式公布，但从曝光的文档显示这些罪行应该和俄罗斯黑客行动以及DNC电子邮件有关。目前美国政府正对包括数十台维基解密的计算机、硬盘和电子邮件账号进行调查，其中涉及当前和前任主编的相关数据，以及涉及和俄罗斯黑客交换DNC电子邮件的信息。从2009年至2017年，通过一系列搜查令、传票，设备查封和合作证人，美国联邦政府已经收集了大量维基解密运营期间的数据。  

为了不被引渡到美国，阿桑奇已经在厄瓜多尔驻伦敦大使馆的一个小房间里躲了六年时间，其最初的目的则是为了逃避瑞典方面对其的强奸指控。不过后来瑞典撤销了这一指控，但阿桑奇在英国仍面临着保释中逃跑的指控。阿桑奇担心，如果他离开大使馆那么美国可能会以间谍罪的罪名引渡他。据称，去年，美司法部曾考虑对维基解密和阿桑奇提起刑事诉讼，指控他们与2010年泄露的外交电报和军事文件有关。

在过去12年的时间里，维基解密称其通过网站发布了1000多万份政府机密文件。虽然在前美国总统奥巴马领导下的司法部拒绝就维基解密公开敏感机密信息提出指控并称他们的工作性质类似于新闻业，但现在在特朗普总统领导下的司法部已经表现出重新审视此案的态度。
