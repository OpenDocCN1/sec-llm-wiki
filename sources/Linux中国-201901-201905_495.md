# 【每日安全资讯】Ethereum Classic 疑遭双花攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664613120&idx=4&sn=4b88800bd83c39c8c7b2c4b68c0f1247&chksm=bdcefe468ab97750a39fd53d188473883131b7ba28514df84953e06935cfbc0144a242b266a5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664613120&idx=4&sn=4b88800bd83c39c8c7b2c4b68c0f1247&chksm=bdcefe468ab97750a39fd53d188473883131b7ba28514df84953e06935cfbc0144a242b266a5&scene=27#wechat_redirect)

Coinbase 报告数字货币 Ethereum Classic 遭遇了双花攻击，攻击者窃取了大约价值 50 万美元的数字货币。Ethereum Classic 官方账号则对此存疑，称矿机制造商 Linzhi 正在测试它的第一款 Ethereum ASIC 矿机。 Coinbase 安全工程师 Mark Nesbitt 称，他们观察到了 Ethereum Classic 区块链反复的深度重组，有大约 88,500 个 ETC 被双花。

![](../Images/65110772240d73a244ae9bbce49d1115.png)

双花或回滚攻击通常是指 51% 攻击，即攻击者在控制了大部分区块链算力之后可以创建任意分支，用新的区块链取代旧的区块链，逆转已完成交易，从而实现数字货币的多次花费。
