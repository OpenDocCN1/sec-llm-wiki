DevOps、容器及软件定义基础设施（SDI）
作者/来源：SUSE / Peter Lees

当前，数字时代为中国及其他亚太地区的企业带来了巨大机遇：成功实现数字化转型的企业，能够提升其在全球市场的竞争力。IDC 预测，今年亚太地区的企业在数字化转型上的开支将超过 3,758 亿美元，中国将成为整个亚太地区最大的数字化转型市场，2019 年支出总额将占到亚太地区的 60% 以上。为了提升客户服务质量和效率，越来越多的企业在实时信息和服务等相关技术的开发和应用上进行投资，特别是在物联网、数据分析、人工智能、机器学习和机器人等技术领域。

因此，各行各业正在积极调整和优化其IT策略，以应对不断提升的客户需求并保持前沿的创新技术能力。通过重组IT架构、实施新技术、加强基础设施等方式，提升自身的灵活性和效率。

作为行业领导者，我们认为确保 IT 成功转型的因素主要有三点：DevOps、容器及软件定义基础设施Software-Defined Infrastructure（简称 SDI）。

DevOps：开发和运维之间的粘合剂

DevOps 正在改变软件开发和部署。DevOps 是一个全新的IT概念，旨在打破传统孤岛式的软件开发模式，让开发、测试和运维团队之间实现良好的沟通与整合。这个概念的创新之处在于：如果软件开发人员和运维人员能紧密合作，那么应用程序的构建、测试和部署将会更节省时间和成本，而且更加有效和可靠。开发和运维团队的协作可以加快新功能的部署，将创意产品更快、更密集地推向市场。

Facebook 是DevOps 早期的采用者之一，该方法让这家科技巨头能够持续开发、改进、整合和快速测试其应用程序。Facebook 为全球超过 20 亿用户服务，而 DevOps 正是其满足客户期望并改善用户体验的关键因素。

预计在 2017 年至 2023 年，亚太地区 DevOps 市场规模将以 20.2％ 的年复合增长率扩大。据《中国 DevOps 现状调查报告（2019）》显示，中国已有 14.13% 的企业开始在组织内局部范围尝试 DevOps；46.65% 的企业在组织内较大范围推广DevOps 实践并且初见成效。致力于为客户提供更优质更快捷服务的企业，需要部署 DevOps 来促进内部功能的开发协作，使整个软件开发的流程和业务目标相符、与客户需求保持一致。

容器：更快、更轻、潜力无限

容器通常与 DevOps 一同运行以提升虚拟化的效率。容器技术的环境是独立的，与其他环境相隔离，其代码拥有独立运行所需要的所有内容。简言之，企业可以将应用程序分解成独立的松散耦合功能，通过容器更快交付、更频繁更新和运行。

Kubernetes 是全球化的容器管理系统，被首席信息官公认为是容器管理的业界标准——尤其是在支持 DevOps 运行的场景下。Kubernetes 将应用程序容器分解为逻辑“包”，以实现简单、快速的管理和发现。它还可以自动化部署并扩展容器化的应用程序。无论是在企业内部还是在云端，通过利用打包的 Kubernetes 平台，企业能快速、密集、大规模地提供软件产品和服务。

到 2020 年，应用容器市场规模预计将超过 27 亿美元。此外，据SUSE 的研究显示，27％ 的受访机构已经部署容器化应用程序，44％ 的受访机构计划将在未来 12 个月内开始使用。

SDI：更灵活灵敏的数据中心

预计软件定义基础设施（SDI）将在未来更受到重视。95％ 的受访机构认为，容器会成为数据中心的未来。过去数据中心是由硬件架构来构建的，这种架构未免过于僵化，无法满足快速迭代的现代应用程序的需求。相比之下，SDI 更专注于软件创新，提供更加灵活和灵敏的数据中心架构。

计算、网络和存储能力由动态、易于使用的资源池统一提供。这些资源池可以根据工作负载或用户需求快速部署，管理也相对轻松。使企业 IT 团队能够腾出精力，专注于开发和新业务与新功能的管理。

得益于 SDI，无论是初创公司还是财富 500 强企业都能有效降低设置和配置管理的成本。企业将不再需要购置昂贵的专有硬件，而是通过软件来提供先进的功能和自动化操作。

拥抱 IT 转型

实现 IT 转型，需要综合考虑经营策略、人员、流程、工具、投资等诸多因素。然而，仅仅了解这些还是不够的。

SUSE 的研究显示，DevOps、容器和 SDI 是大多数企业转型策略中的关键因素。这三种技术已经存在了一段时间。其中，云计算和 SDI 的发展已步入了第二个十年；DevOps 于 2008 年被首次提出，Linux 容器也于同年亮相。现在，IT 转型可以说万事俱备了，但真正能实现的秘诀在于如何将所有因素有效整合。好在，中国和其他亚太地区的企业都早已翘首以盼，做好迎接IT转型的准备了。
