# 网易云首倡中台方法论，发布全链路中台技术方案

当前数字经济领域最受关注的技术趋势当属中台，到底中台对企业发展的意义何在，企业应当如何建设中台？

7 月 26 日，网易云在本届云创峰会上给出了完整的答案，从组织、技术、方法论的角度系统阐述了网易杭州研究院的中台实践与成果，并发布了全链路大数据产品和轻舟微服务产品，分别为企业构建数据中台和在线业务中台提供完整的技术和方法论支持。

在主题演讲中，网易副总裁、网易杭州研究院执行院长汪源首次介绍了网易对中台的理解，他表示：

> “中台的本质是业务能力的沉淀，它对于企业提高需求响应、降低定制成本、实现弹性稳定、实现系统互通、提升运营效率和降低资源成本具有独特的优势，而中台的成功建设，需要组织、技术和相应的方法论的支撑，同时由于业务的复杂性，企业往往还需要借助专业的咨询服务，才能顺利建设中台。”

据悉，网易是业界唯一通过设立研究院专职培育创新业务的公司，网易杭州研究院（以下简称杭研）同时肩负着能力沉淀和业务创新两大职能，成功孵化了网易考拉、网易严选、网易云音乐、网易云等业务。由于发展的业务众多，杭研天然具备建设各种共性能力的诉求，很多能力自然而然就建设成了中台的形式。汪源认为，这些能力（中台）的沉淀，能够帮助企业驾驭云计算、微服务、大数据、人工智能和物联网等技术革新成果，并形成核聚变的能量，促进企业数字化创新，推动产业发展乃至社会经济升级。

明晰中台内涵与实践路径，首提技术核聚变

随着 IoT 将互联网能力延伸到生产端，例如基于 IoT 的网易疾风工业智能平台让工业企业解决生产管理顽疾，企业对新技术、新数据价值的挖掘愈发期待，中台的价值也被更多企业关注。在国内，一些原本的平台，也随之摇身一变成了所谓的技术中台、算法中台、移动中台、研发中台，汪源将之称为“中台乱象”，他表示，中台必须具备业务属性，没有业务属性的，即使支撑多个前台业务，比如一堆技术组件，也只是平台而不是中台。在汪源看来，所有的中台都是业务中台，数据中台是业务中台的特殊形式，而用户中台、内容中台则是数据中台的特殊形式。

由于当前数字技术革新很快，明确技术概念的职责与内涵，对技术项目的成功实践至关重要。中台也是如此，如果概念过于宽泛，或者混淆，企业容易对中台失去信心，从而在数字化创新中错失良机。汪源的梳理，为企业对中台的判断提供了直观的标准。“网易除了有能力，也有责任来分享中台经验。”汪源说。

对于中台的建设，汪源认为，组织、技术和方法论三者不可或缺。从组织的角度，他认为，中台需要整合资源，让懂业务的人参与，其次，在 BU、BG、企业、集团各个层次都可以建设中台，但必须是各层次的一把手工程，否则难以调配资源。

技术层面，建设在线业务中台需要微服务、DevOps、分布式事务和云原生技术体系的支撑，建设数据中台则需要指标管理、数据服务、元数据管理、数据仓库开发与管理、数据质量管理、数据安全管理、数据资产管理，以及大数据计算引擎、数据集成/同步/交换引擎、敏捷 BI 系统等一整套典型的支撑技术。

作为能力的沉淀，除了工具，中台无疑需要流程/规范/方法论。目前业界存在许多相关的方法论，如六边形理论、领域驱动设计（DDD）、指标设计方法论等，但大都与技术相关，在中台组织层面尚无成熟的方法论。基于杭研的实践经验，汪源在业界首次提出了一套完整的中台组织方法论。

根据参与人员的差异，汪源把不同类型的组织总结为“胖中台组织”、“标准中台组织”和“平台组织”——标准中台组织由各个能力组和工具、规范/流程/方法论组成；当标准中台组织对业务的介入程度不足以支撑中台的实现，就需要更加接近业务的定向组来参与，这就形成了胖中台组织；而能力臻于成熟，工具、流程都实现标准化，标准中台组织也可以退化成平台组织。换言之，三个角色并非一成不变，而是处在动态变化之中。事实上，不仅仅是杭研，很多大型互联网公司都或多或少经历过类似的重组。与会者认为，中台组织方法论的梳理，为中台组织的建设和未来拨开了迷雾。

对于中台的发展，汪源还总结了一个“数字技术核聚变”的模型。他表示：数据中台汇聚和整合业务数据，产生洞察指导业务创新，在线业务中台支撑业务围绕领域交汇，不断引入新技术，创造新数据，为数据资产增值裂变提供动力支持，数据中台和在线业务中台共生共存，形成数字技术核聚变的巨大能量，推动产业跳跃式进化。

全链路大数据产品发布，数据中台可实现 100% 标签覆盖

为了全面支撑企业数据中台建设，为业务应用提供统一的数据和服务，网易发布了全链路大数据产品——网易猛犸 6.0。网易大数据总经理余利华分享了一个真实的客户案例：某客户在供应链系统、VIP App 和商品运营系统中看到的同一款产品毛利分别是32%、28%、38% 三个迥然不同的数字，这给数据分析工作造成了极大的困惑。余利华指出，目前企业在大数据实践中存在指标口径不一致、数据重复建设、取数效率低、数据质量故障频繁、成本指数级增长等五大痛点，这导致了企业80%的工作都与数据分析无关，而数据中台就是瓦解这一症结的良方。

![](../Images/1d8dd6a8a976d8777fe44a73db58c692.png "图：网易大数据总经理 余利华")

*图：网易大数据总经理 余利华*

网易大数据此次发布的猛犸 6.0，在此前的 Hadoop、数据集成、任务运维、实时开发、离线开发产品基础上，新增了指标系统、数据服务、数据地图、数据质量中心、资产管理中心、数据仓库开发与管理等全新的系统，这就实现了数据中台的全链路打通，实现全链路数据质量监控、全链路数据资产分析、全链路数据发现。

这些系统的能力，以指标系统为例，猛犸 6.0 能够 100% 消除指标口径不一致，让指标数量缩减 50%，并且理解一个指标的含义的时间缩短80%。

而据汪源介绍，猛犸 6.0 已经成功应用于网易考拉等业务，通过数据中台的建设，实现了 100% 的数据产品指标覆盖、99.8% 的数据可用率、100% 的自助取数和 20% 的成本节省。

“有了全链路大数据产品，企业可以将 80% 的工作投入商业分析，直接产生业务价值，而数据开发、数据治理只需占用 20% 的工作量。”余利华总结说。

轻舟微服务平台升级，突破在线业务中台的异构挑战

在线业务中台有助于业务能力复用、加速业务创新和促进数字化转型。现实的问题是，信息隔离、数据隔离等因素，阻碍着在线业务中台的建设。网易云基础服务总经理陈谔认为，异构系统整合，包括兼容、通信和系统间事务一致性，和多供应商建设，包括多团队协作、软件资产沉淀，是目前企业在建设在线业务中台过程中遇到的最大障碍，而网易轻舟微服务新品的发布，正是要通过 Service Mesh、分布式事务框架 GTXS、全新 API 网关与原有轻舟产品的整合，完成全栈化在线中台技术体系升级，帮助企业完成业务架构的进化，支撑业务快速创新。

![](../Images/baa2748c6ea1b4b2ee64843e47c1dd98.png "图：网易云基础服务总经理 陈谔")

*图：网易云基础服务总经理 陈谔*

陈谔介绍，轻舟 Service Mesh 基于 CNCF（云原生计算基金会）的 Istio 和 Envoy 等主流开源技术构建，可以实现 Java、Python、NodeJS、Golang 和 PHP 等不同技术栈的兼容和通信，能够与已有微服务框架 NSF 统一管控、互相发现、互相调用，并且支持容器、虚拟机和裸机部署，将异构系统的支持实现到了业界领先的程度。在性能方面，轻舟 Service Mesh 也实现了时延降低 50% 的优化效果，以便更好地满足在线业务的用户体验。GTXS 则通过声明式事务框架，实现了对开发人员更加友好的分布式事务方案，保证了不同微服务的数据一致性，与常用的 TCC 模式相比，接入效率提升了 85%，目前已在工商银行、网易严选等大型生产环境中稳定运行。

据汪源介绍，在网易内部，通过电商、音乐等在线业务中台的建设，实现了需求响应效率提升 100%、应用部署效率提升 280%、软件产品质量提升 52% 的效果，其中电商应用日均部署 1374 次，音乐应用日均部署 492 次。

为了确保这些复杂技术在企业落地应用，网易云为客户提供了全流程的服务，覆盖 DevOps 最佳实践、可扩展性架构设计、微服务化拆分、治理建设、技术支持和高级运维等各个层面。其中，咨询服务已经在工商银行、国家电网、申万宏源、大华科技、德邦快递、百胜中国等企业的云平台建设、中台建设和架构演进等项目中开花结果。
