2019 年 5 月 28 日， 国内领先的中立云计算服务商 UCloud 优刻得（以下简称 UCloud）在北京召开以“中立安全、赋能产业”为主题的 UCloud 用户大会暨 Think in Cloud 北京大会。
作者/来源：优刻得

2019 年 5 月 28 日， 国内领先的中立云计算服务商 UCloud 优刻得（以下简称 UCloud）在北京召开以“中立安全、赋能产业”为主题的 UCloud 用户大会暨 Think in Cloud 北京大会。面对走向纵深的产业互联网，UCloud 强调做“不和用户竞争的云”，针对七大重点行业，推出行业定制化解决方案；发布重磅产品与布局全球基础设施，建立云计算底层硬实力；开放云计算差异化核心能力，首次公布“+U 合作伙伴计划”；并携手 5G、工业互联网等领域合作伙伴，以云计算为基石和底座，共同打造赋能产业的新生态。

UCloud优刻得品牌全新升级

中立安全，推出七大行业解决方案

本次大会上，UCloud 进行品牌升级，启用中文名称“优刻得”，并发布“优刻得中立云，不和用户竞争的云”品牌标语。UCloud 创始人兼 CEO 季昕华表示 UCloud 专注云服务，不涉足用户业务，“中立安全”是 UCloud 赋能产业的核心理念。“优刻得”中文名称即表明面向产业的积极态度，也蕴含“优秀的云立刻可以得到”的意义。

UCloud 创始人兼 CEO 季昕华

季昕华认为，产业升级将包含相互融合促进的三个阶段，第一阶段是产业数字化，利用云计算等新一代信息技术，提高产业运行效率；第二阶段是产业互联网化，传统产业与互联网深度融合，让互联网成为各行业的核心能力；第三阶段是产业智能化，人工智能实际应用在产业领域，全面实现产业智能化。针对产业升级三个阶段，UCloud 围绕CBA（Cloud、Big data、AI）战略，布局了全线云产品、安全屋可信数据流通平台、UAI 人工智能赋能平台。

在深耕行业的基础上，UCloud 在本次大会上公布了七大行业解决方案，分别是智慧城市、智能互联汽车、智慧媒体、新零售、智慧教育、智慧金融、智能制造。工业富联、湖南广电、亿咖通、格林深瞳等各行业领军企业，已在各自场景中应用，为产业升级创造价值。

重磅产品与基础架构，在云计算核心地带冲出一片蓝海

产业互联网用户对云计算核心产品——云主机的需求最高，针对海量需求，UCloud发布“快杰”新一代云主机。“快杰”新一代云主机在计算、网络和存储三大领域进行了全面升级。平台运算性能提升16%；云盘 I/O 性能提升 50 倍，IOPS 最大可达 120 万，顺序吞吐提升 18 倍，延迟降低至 0.1ms；内网转发能力到达 1000 万 PPS，外网最大带宽提升至 10G，为上一代的 10 倍。在卓越性能的基础上， “快杰”新一代云主机的价格与市场普通云主机持平。可为视频渲染、视频弹幕、MMORPG 游戏、 Oracle/SQL Server 数据库等高性能业务场景，提供更高性能的基础能力。

UCloud 发布“快杰”新一代云主机

除此之外，UCloud 关键产品密集创新：AnycastEIP 全球加速与防海量 DDoS 攻击，DDoS 攻击防御能力提升至 200G 级别。智能网关 SDN Box，帮助企业一键打通网络，轻松部署混合云。Serverless 系列也新推出 USQL 数据湖分析工具、 StepFlow工作流服务两项产品。USQL 数据湖分析工具，轻松完成面向海量数据的数据建模，极大降低使用大数据的门槛和成本；StepFlow 工作流服务，以可视化的方式快速编排流程、构建新业务，极大提升研发效率。在云计算产品核心地带，UCloud 以用户需求为导向，以技术创新为驱动，凭硬核实力冲出一片蓝海。

云计算基础设施的稳定和可靠，是云计算公司的底层实力，UCloud 长期投入基础设施建设，积淀了对于云计算基础架构的深度洞察和设计能力，提供综合性的企业级云计算基础架构解决方案。在数据中心资源层面，UCloud 全球运营 30 个可用区、 500+CDN 节点、104 个维护节点；在基础网络层面，UCloud 联结洲际 POP 点、城域网、多业务传输网、流量调度网等四大宏观网络;在虚拟网络层面，UCloud 推出 VPC3.0，包含 UXR 特性的智能网关，以及支持 IPv6 的 VPC 架构等特性；在运营支撑层面，UCloud 实现了对监控、资源管理、自动化交付、SER 运维支撑在内的全方位运维管理体系。

开放差异化核心能力，全面聚能产业力量

传统产业才是云计算的主流用户。产业互联网的海量市场空间和复杂业务形态，要求云厂商和产业链上各环节进行高效合作。在本次大会上，UCloud 联合创始人兼 COO 华琨首次公布了 UCloud“+U 合作伙伴计划”。他强调 UCloud 不做业务，不和用户竞争；不做应用类 SaaS，天然不会和合作伙伴竞争。华琨表示，UCloud 将全面开放云计算差异化核心能力，联手合作伙伴赋能产业。包括经过大规模验证的专有云、渠道云、合营云、海外云、UCloudStack 私有云、数据安全屋、罗马、数据方舟等全线特色云产品、上万家优质企业客户资源、数百人的直销团队、解决方案及认证培训、覆盖全球的全套云基础设施。

UCloud 联合创始人兼 COO 华琨

“我们有一种业内稀缺的能力，可以很快地帮合作伙伴搭建一套大型公有云，而且相对门槛还最低。”除了专有云外，华琨还重点介绍了专有云的多种形式，比如渠道云，合作伙伴可以通过 API 直接连到 UCloud 数据中心和设备商，搭建一套自定义的云，也可以与 UCloud 合作，共同运营合营云。合作伙伴只需要一线的服务对接，后端从底层架构到运维管理，全都由 UCloud 负责。

华琨表示，UCloud 坚持中立、纯粹做云，天生被集成，将以云计算为基石和底座，全面聚能产业链各方力量，共同推动产业互联网的发展。与行业 ISV /系统集成商/硬件厂商合作开发行业解决方案；与运营商、大型企业合作“一站式”输出云能力;与硬件代理商、IT服务商合作云产品市场营销；与技术公司、软件厂商合作打造行业性 PaaS 平台；与孵化器、园区、投资机构合作扶持创新企业。目前，UCloud 已经与中国移动、中航信、北京政务云等客户进行了深度合作。

布局未来，探索5G、边缘计算、工业互联前沿领域

5G 将给中国产业互联网带来跨越式发展的爆发机会。UCloud 和中国移动、中国联通已在 5G 领域紧密合作，率先进行了多项 5G 环境下的创新应用测试，并探索5G边缘计算，布局边缘云数据中心、IoT 平台、ODN 平台。本次大会上，UCloud 联合无人驾驶公司图森未来、AR 产品与服务商亮风台、云游戏公司念力科技、智能交通公司径卫视觉、上海陈天桥脑疾病研究所等，成立 5G 创新应用联盟，联合 5G 生态合作伙伴，孵化 5G 创新应用产品。 

制造业转型升级是国家战略，打造工业互联网平台、发展智能制造，需要依托云计算强化工业基础、提升创新能力。UCloud 以边缘计算基础平台、UAI 人工智能平台、云化大数据平台、物联网云平台等四大平台能力，打通制造业从生产现场、云平台到前端应用的全流程。目前 UCloud 已与全球领先的制造企业富士康、工业互联网平台智能云科、数据软件提供商宇动源等全面合作，赋能工业互联网。

产业互联网浪潮正澎湃而来，云计算作为产业互联网基础设施，将与 5G、工业互联网、人工智能、物联网等新技术深度融合，为产业互联网的转型升级提供新动能。UCloud 秉持“中立安全”理念，做不与用户和合作伙伴竞争的云，以硬科技实力驱动创新、以开放合作拓展市场、以中立服务赋能产业，将助力更多梦想者，实现产业数字智能化，为中国产业互联网创造更大价值。
