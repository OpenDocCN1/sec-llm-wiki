# 多中心化的世界正在兑现：Hyperledger 如何帮助现代数字经济

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664614245&idx=1&sn=77899b0da3186f1ca51190960bb32253&chksm=bdcef2238ab97b3559db8c7f94f5c9dede79585fde63248d379b2cdac155cb2ec4d90c86e736&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664614245&idx=1&sn=77899b0da3186f1ca51190960bb32253&chksm=bdcef2238ab97b3559db8c7f94f5c9dede79585fde63248d379b2cdac155cb2ec4d90c86e736&scene=27#wechat_redirect)

引言

> “我经常一早起来，又发现世界各地有哪个机构、公司推出了 Hyperledger 的项目，即便事前我们几乎不知情”。
> 
> Linux 基金会 Hyperledger 执行董事 Brian Behlendorf

区块链技术是可以让这个世界更美好的，当然革掉现在金融的革命这个可能有点不太现实，但是就像当年发明治疗心脏病的副作用一样，区块链本身还是有更为重要作用的，比如食物溯源、供应链、医疗健康、学历认证等等，为社会的信任构建发挥至为重要的作用。那么来自 Linux 基金会旗下的 Hyperledger 对区块链的表述是无与伦比的。

Linux 基金会在吸引大公司和小公司为共同 IP 合作方面享有盛名。这些分布式账本可以追溯到很久以前，比特币的一些基础算法、拜占庭容错机制甚至是智能合约在20世纪80年代就已经存在。Hyperledger 将所有这些整合在一起，让 IBM 和英特尔这样的公司，和颠覆性的初创公司一起参与进来，让区块链技术真正发挥作用。 

自从互联网诞生以来，除了互联网本身，没有比区块链技术更广泛、更根本的革命性技术了。区块链是一种通过共识建立起来的、与“智能合约”系统和其他辅助技术相结合的对等分布式账本。这些技术可以一起用于构建新一代的交易应用。这些应用的核心是建立信任、责任和透明度，同时简化业务流程和法律限制。

分论坛主题介绍

  

![](../Images/9a8d54bd75a2576c76dfd1cb6407f231.png)

Linux 基金会旗下的 Open Source Summit，囊括所有主流创新的开源技术领域和相关项目，作为近几年最为炙手可热的技术——区块链，当仁不让的是 Linux 基金会要大力主推的内容，更何况区块链技术天生的开源基因，以及旗下的 Hyperledger 项目的野蛮生长，服务于全球各个行业。6月底，在 Open Source Summit 大会上，又能给中国的区块链从业者带来何种惊喜了呢？

正如开篇引言中所述，区块链正在走向更为广泛的用途，那么航空运输业、传统IT基础设施、正在势头上的边缘计算、以及最为适用的金融行业，都有区块链大量的应用。落地的案例绝对是今年的看点： 

首先出场的是 ChainNova 的**谢文杰**先生，他带来的演讲是区块链赋能智能航运：正如我们所知，航运业占据了全球贸易的 90%，但因其复杂的业务流程，导致其发展缓慢，且效率低下。今天，Jay 将介绍一些区块链对航运业升级领域带来的重大影响，并说明传统航运业如何通过区块链改变其商业模式和进行转型，创造更大的价值。在本演讲中，Jay 将采用中国最大的航运公司的成功实践案例，来阐明区块链如何帮助在航运领域实现突破。这些突破中包括了对全球航运集装箱进行实时动态信息追踪。通过使用区块链，航运公司可确定航运资源并对其进行数字化处理，从而让人们能够以更加有效的方式开展物流与贸易金融业务。 

来自 FlowChain 的 **Jollen Chen** 带来了 Flowchain 如何利用区块链技术构建分布式网络存储：Flowchain 旨在实现区块链，以提供适用于物联网的分布式账本技术。为此，Flowchain 提出了虚拟块技术，用于确保以近即时方式实现分块数据处理。借助虚拟块技术，Flowchain 可以集成 IPFS 和 Hyperledger Fabric，以开发分布式网络存储，确保实时数字资产交易和商店已验证交易。在本演讲中，Jollen 将展示如何利用 Flowchain、Hyperledger Fabric 和 IPFS 开源技术实现所述的系统。

金融行业，除了发币、ICO 之外，其实还是有很多事情可以做的，比如安全、隐私和所有权问题使全世界大部分最有价值的数据无法充分利用。来自光之树(北京) 技术有限公司的首席执行官：**Sarah Zhang** 带来了如何利用区块链和加密技术为各个机构、公司和消费者启动隐私保护和包容性金融服务：安全、隐私和所有权问题使全世界大部分最有价值的数据无法充分利用。我们希望通过结合分布式账本、智能合约、加密技术及 TEE（可信执行环境）解决这个问题，从而开启“数据租用”，最重要的是，保护多个数据源的数据联合计算，避免披露原始数据。Points 的网络已经连接了超过 20 亿数据项，可用于在安全的计算框架下实现数据协作。Points 最近与中国中原银行建立了合作关系，该银行在中国人口最多的省份（1 亿）运营，其中一半服务对象是该省农村地区的薄文件人群。合作目的在于构建基于区块链的数据基础架构，以促进跨平台联合数据分析，实现更好的风险分析和定向市场营销等。

上周给大家介绍了边缘计算，也提到了边缘计算中的安全问题，这在很多场景下都是技术人员头痛的问题，还好区块链领域也有人想到了这个问题，来自北京的北京世纪诚链科技有限公司首席技术官，也是 Linux 内核开发界的知名人士，**Zhenlong Zhao** 将带来了如何使用区块链构建强大的边缘：如何构建强大的物联网系统边缘是一个关键问题。考虑了两层架构，分为思维和反射，边缘在人的反射中心起作用，而 AI 就像大脑。此外，基于区块链的边缘将可信数据上传至 AI 系统，而具有基本规则的智能合约则提供了自我决策能力。

Zhenlong Zhao 将介绍以上提到的架构，尤其是如何利用区块链构建边缘可信、分布式安全且智能自我决策的层。**Hansom Jing** 将详细介绍建立可信访问环境的关键技术，该环境负责身份识别、入侵检测、数据清理、使用基于矢量的肖像的安全增强、Intel SGX、ARM TrustZone 和拜占庭共识。同时他还将讨论采用多链的各种物联网网络的复杂数据集成情况。

在数字互联网世界中，超级账本 Hyperledger 是一个不能忽视的项目。Hyperledger 是一个旨在推动区块链跨行业应用的开源项目，由 Linux 基金会在2015年12月主导发起该项目，成员包括全球金融，银行，物联网，供应链，制造和科技行业的领头羊。

经过三年的发展，截止到2019年5月，Hyperledger 在全球有270多个会员，旗下共有13个项目。区块链的 Keynote 将由 Linux 基金会 Hyperledger 执行董事 **Brian Behlendorf** 亲自演讲，他这次带来了2019年开源区块链在中国的发展：去年，亚洲涌现出了大量的开发人员，负责为企业采用并创建智能合约与分布式账本应用。

这些公司正在构建基于区块链的系统，在全球范围内改变着数据与信息流。例如，腾讯构建了企业级区块链基础设施服务平台；阿里巴巴将区块链应用于非盈利组织、产品溯源以及其他领域；百度发布了中国首个区块链支持的资产安全项目，以及基于区块链的 ABS 交易所。

相对于其它的区块链项目，Hyperledger 就是更为细致的技术细节实现，如：  

**通过 Hyperledger Cello (HLC) 构建区块链即服务**：HyperledgerCello (HLC) 是一个区块链配置与操作系统，可帮助人们高效使用并管理区块链。它支持多个基础设施，包括 Docker、Kubernetes、vSphere 与 Swarm。使用 Cello，区块链的开发人员与操作人员可从零开始，快速构建区块链即服务 (BaaS) 平台。本演讲将介绍 Hyperledger Cello 的关键功能，并展示如何使用 Hyperledger Cello 来管理 Hyperledger Fabric 的部署与炼码生命周期。此外，演讲还将展示如何监控区块链平台。分享嘉宾分别是来自 IBM 的 **Tong Li** 和 VMware 的 **Haining Henry Zhang**。

**Hyperledger Fabric Operator 更快速、更简单的区块链联盟管理方式**：在实际工程中，用户建立完整的架构联盟并不容易。我们将架构资源迁移到了 Kubernetes 中， 然后实现了 Fabric Operator，用于以更云原生的方式管理各种资源类型的不同阶段。

1.由 Kubernetes 实现的 Fabric Operator 如何工作？

2\. Fabric 组件的插件设计理念是什么？

3\. 为什么使用 Operator 管理 Fabric 资源？

4\. Operator 可以为我们控制哪些 Fabric 逻辑对象，每个逻辑对象有哪些复杂状态？

5\. 不同组织如何通过 Operator 建立一个联盟？

分享嘉宾是来自百度的架构师 **Haodong Chen**。

**在 Hyperledger Fabric 上创建您的第一个智能合约**：来自 IBM 的开源贡献者 **SwethaRepakula** 和 **Morgan Bauer** 将会带来：当提到区块链时，人们往往首先想到的两种技术就是比特币和以太坊。很多人对公共网络耳熟能详，但却对 Hyperledger Fabric 等许可区块链平台知之甚少。Fabric 是一个开源区块链平台，专为企业用例而设计。Morgan 和 Swetha 将介绍 Hyperledger Fabric 的架构，并详细说明事务工作流、共识机制和智能合约功能。他们将演示端到端应用如何在 Fabric 上运行，并在此过程中介绍许可平台的优势。与会者将能够从中获得相关知识，准备好开始在 Hyperledger Fabric 上进行首次开发。

**安装适用于联盟区块链的“Hardware Wallet” - 利用英特尔 SGX 保护 Hyperledger Fabric 节点私有秘钥**：来自阿里巴巴的 **MengzheYang**，会介绍：区块链技术涉及到大量的加密。如何保护核心密钥的安全是该技术一直以来面临的挑战。Hyperledger Fabric 支持使用 HSM 保护节点密钥，但是，这一异构硬件存在成本高和部署困难等问题。我们已经基于英特尔 SGX 技术开发出一种密钥保护机制。我们认为这款即将内置于所有英特尔 CPU 的硬件安全解决方案非常适合保护联盟区块链中的节点私有密钥，也值得通过开源技术应用和推广。本演讲主要分为三个部分：

1.介绍 golang 加密库的修改内容。

2.介绍如何通过实施 Fabric 的插件式 bccsp 模块桥接 Fabric 区块链和 Enclave。

3.介绍为什么在 BaaS 场景下选择插件式 bccsp。

最后，作为 KubeCon + CloudNativeCon + Open Source Summit 三大开源盛会合一的点题之作，将云原生的核心 Kubernetes 和 Hyperledger 项目结合在一起：**多租户与区块链：在 Kubernetes上部署 Hyperledger Fabric**，光是看标题就让人振奋不已：HyperledgerFabric 是一个开源企业级分布式账本技术 (DLT) 平台，主要为许可区块链设计。它为开发人员提供了构建区块链应用程序的框架。将 Hyperledger Fabric 等多组件系统部署到生产是一项挑战。另一方面，Kubernetes 是一个可移植、可扩展的开源平台，用于自动化容器应用程序的部署、扩展和管理。它支持多租户，使开发人员能够高效地开发和测试区块链应用程序。与会者将了解到所有关于 Hyperledger Fabric 和 Kubernetes 的信息，以及同时使用这些信息时，Hyperledger 和 Kubernetes 如何为处理区块链事务提供一个强大、安全的平台。分享嘉宾是来自 IBM 的 **Tong Li**。
