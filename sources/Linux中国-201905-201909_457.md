近日，全球最大开源社区Apache软件基金会Apache Software Foundation（ASF）公布新活跃成员Member，阿里云技术专家张乎兴入选。全球共有 771 位 ASF 成员，中国仅 13 位。

ASF 是全球最大的开源基金会，目前拥有 300 多个开源项目，涵盖人工智能和深度学习、大数据、云计算、物联网和边缘计算等众多领域。其中包括阿里发起的 1 个顶级项目 Apache RocketMQ，2 个孵化项目 Apache Dubbo 和 Apache Weex。

2014 年，张乎兴开始从事阿里巴巴集团 Tomcat 核心开发和运维工作，同时参与 Apache Tomcat 开源项目。2016年，他成为 Apache Tomcat提交者Committer，是 Tomcat 社区 20 年来首位中国的提交者，2017 年成为 Apache Tomcat PMC 成员，2018 年作为 Apache Dubbo（incubator）创始成员及 PPMC，带领 Dubbo 加入 Apache 孵化器。

张乎兴表示，希望借助 ASF 帮助中国的开源软件、开发者和全世界建立更广泛深入的连接，提升中国开源软件的国际影响力。

事实上，阿里巴巴与 ASF 渊源颇深。2015 年，阿里巴巴正式加入 ASF，此后陆续向社区捐赠 RocketMQ、WeeX、Dubbo 项目。2017 年 9 月，RocketMQ 从 Apache 社区正式毕业，成为 Apache 顶级项目。目前，Dubbo 项目也即将毕业。
