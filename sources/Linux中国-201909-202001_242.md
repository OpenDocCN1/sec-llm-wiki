# 如何拥有一个 Windows 10 和 Debian 10 的双系统 | Linux 中国

在无数次劝说自己后，你终于做出了一个大胆的决定，试试 Linux。不过，在完全熟悉 Linux 之前，你依旧需要使用 Windows 10 系统。幸运的是，通过一个双系统引导设置，能让你在启动时，选择自己想要进入的系统。在这个指南中，你会看到如何 如何双重引导 Windows 10 和 Debian 10。

前提条件

在开始之前，确保你满足下列条件:

◈ 一个 Debian 10 的可引导 USB 或 DVD◈ 一个快速且稳定的网络（为了安装更新以及第三方软件）

另外，记得注意你系统的引导策略（UEFI 或 Legacy），需要确保两个系统使用同一种引导模式。

第一步：在硬盘上创建一个空余分区

第一步，你需要在你的硬盘上创建一个空余分区。之后，这将是我们安装 Debian 系统的地方。为了实现这一目的，需要使用下图所示的磁盘管理器：

同时按下 `Windows + R` 键，启动“运行程序”。接下来，输入 `diskmgmt.msc`，按回车键。

![](../Images/0996a45f2efd759db1679994ed3c2d85.png)

*启动“运行程序”*

这会启动“磁盘管理”窗口，它会显示你 Windows 上所有已有磁盘。

![](../Images/9d4a85c284ed6c125dcfec3c9d6ef669.png)

*磁盘管理*

接下来，你需要为安装的 Debian 系统创建空余空间。为此，你需要缩小其中一个磁盘（卷）上的分区，从而创建一个未分配的新分区。在这个例子里，我会从 D 盘中创建一个 30 GB 的新分区。

为了缩小一个卷，右键点击它，然后选中选项 “缩小Shrink volume…”。

![](../Images/a29a5cfbe0b23f93ad6a2cda9e736c1a.png)

*缩小卷*

在弹出窗口中，定义你想缩小的空间大小。记住，这是将来要安装 Debian 10 的磁盘空间。我选择了 30000MB（大约 30 GB）。压缩完成后，点击“缩小Shrink”。

![](../Images/72c9eb3f10161f12450422e93fda6f83.png)

*缩小空间*

在缩小操作结束后，你会看到一个如下图所示的未分配分区：

![](../Images/9a2b5b5c0752bf0def016f8c3e21436b.png)

*未分配分区*

完美！现在可以准备开始安装了。

第二步：开始安装 Debian 10

空余分区已经创建好了，将你的可引导 USB 或安装 DVD 插入电脑，重新启动系统。记得更改 BIOS 中的引导顺序，需要在启动时按住功能键（通常，根据品牌不同，是 `F9`、`F10` 或 `F12`中的某一个）。这一步骤，对系统是否能进入安装媒体来说，至关重要。保存 BIOS 设置，并重启电脑。

如下图所示，界面会显示一个新的引导菜单：点击 “Graphical install”。

![](../Images/9c082753c4a90a8091e9b7eb91f05999.png)

*图形化界面安装*

下一步，选择你的偏好语言，然后点击 “继续Continue”。

![](../Images/103948fde96db58a3dac05a0ab2de52d.png)

*设置语言-Debian10*

接着，选择你的地区，点击“继续Continue”。根据地区，系统会自动选择当地对应的时区。如果你无法找到你所对应的地区，将界面往下拉， 点击“其他Other”后，选择相对应位置。

![](../Images/59c4ee3b7160c72e431a3324d7738931.png)

*选择地区-Debain10*

而后，选择你的键盘布局。

![](../Images/144eeea38c682480eea7233d005ee550.png)

*设置键盘-Debain10*

接下来，设置系统的主机名，点击 “继续Continue”。

![](../Images/94a9b8fba6fb309006b952dcbdaaf886.png)

*设置主机名-Debian10*

下一步，确定域名。如果你的电脑不在域中，直接点击 “继续Continue”按钮。

![](../Images/83562aa43419c1c727233d72671fdffc.png)

*设置域名-Debian10*

然后，如图所示，设置 root 密码，点击 “继续Continue”。

![](../Images/24de8355043aad3e6dd0e57bd770a12b.png)

*设置 root 密码-Debian10*

下一步骤，设置账户的用户全名，点击 “继续Continue”。

![](../Images/ce2e49d67382b52c836024004d84cf82.png)

*设置用户全名-debain10*

接着，设置与此账户相关联的用户名。

![](../Images/1c0abecb27c7500e4bfa8eeb1dc8ce97.png)

*指定用户名-Debian10*

下一步，设置用户密码，点击“继续Continue”。

![](../Images/a647a856ecbfe2eb9fa09ff0caec2c5b.png)

*设置用户密码-Debian10*

然后，设置时区。

![](../Images/d1c06c474a71faa62ffce22660d79ff1.png)

*设置时区-Debian10*

这时，你要为 Debian10 安装创建分区。如果你是新手用户，点击菜单中的第一个选项，“使用最大的连续空余空间Use the largest continuous free space”，点击“继续Continue”。

![](../Images/7104376475421f991f1038d5263e501e.png)

*使用最大的连续空余空间-debian10*

不过，如果你对创建分区有所了解的话，选择“手动Manual” 选项，点击 “继续Continue”。

![](../Images/fd8dcd918368fe7eb0fa51599bd65893.png)

*选择手动-Debain10*

接着，选择被标记为 “空余空间FREE SPACE” 的磁盘，点击 “继续Continue” 。接下来，点击“创建新分区Create a new partition”。

![](../Images/f303bdeaf4ec7b57dcf886c500901482.png)

*创建新分区-Debain10*

下一界面，首先确定交换空间大小。我的交换空间大小为 2GB，点击 “继续Continue”。

![](../Images/d8a951cf704398ff20f974a14c793459.png)

*确定交换空间大小-debian10*

点击下一界面的 “主分区Primary”，点击“继续Continue”。

![](../Images/6621133405bc2702c2eae3eddd162bad.png)

*磁盘主分区-Debian10*

选择在磁盘 “初始位置beginning” 创建新分区后，点击继续。

![](../Images/dedd024cc8f98c0a717eedaa95b2cc0a.png)

*在初始位置创建-Debain10*

选择 “Ext 4 日志文件系统Ext 4 journaling file system”，点击 “继续Continue”。

![](../Images/7936cb610633e9db9638e72bfec52cf1.png)

*选择 Ext4 日志文件系统-debain10*

下个界面选择“交换空间swap space” ，点击 “继续Continue”。

![](../Images/eff9c1c8091b5269dbcb093108cf8803.png)

*选择交换空间-debian10*

选中 “完成此分区设置done setting the partition”，点击 “继续Continue”。

![](../Images/f4e5d376a693c8ea33c3097e8844d303.png)

*完成此分区设置-debian10*

返回磁盘分区界面，点击 “空余空间FREE SPACE”，点击 “继续Continue”。

![](../Images/bb4b26d284aa69c85b30877b5b44bdb0.png)

*点击空余空间-Debain10*

为了让自己能轻松一点，选中 “自动为空余空间分区Automatically partition the free space”后，点击 “继续Continue”。

![](../Images/5cdf9f2ab50ffa7bf036eda4db5122ff.png)

*自动为空余空间分区-Debain10*

接着点击 “将所有文件存储在同一分区（新手用户推荐）All files in one partition (recommended for new users)”。

![](../Images/c267af95fac5706cabb68b80b4de8350.png)

*将所有文件存储在同一分区-debian10*

最后， 点击 “完成分区设置，并将改动写入磁盘Finish partitioning and write changes to disk” ，点击 “继续Continue”。

![](../Images/4f9e59f496e919d4bef70fd3b17a130a.png)

*完成分区设置，并将改动写入磁盘*

确定你要将改动写入磁盘，点击 “是Yes”。

![](../Images/2291c77cb41a6ea0b282fcce016c84f5.png)

*将改动写入磁盘-Debian10*

而后，安装程序会开始安装所有必要的软件包。

当系统询问是否要扫描其他 CD 时，选择 “否No” ，并点击 “继续Continue”。

![](../Images/7fe19869864fb83c6e80d2d8326d29b1.png)

*扫描其他CD-No-Debain10*

接着，选择离你最近的镜像站点地区，点击 “继续Continue”。

![](../Images/5566e2617e848e8ea1df84ee0244f13e.png)

*Debian-镜像站点-国家*

然后，选择最适合你的镜像站点，点击“继续Continue”。

![](../Images/d929d46d4ecfc4d16050110b7dfceeec.png)

*选择镜像站点*

如果你打算使用代理服务器，在下面输入具体信息，没有的话就留空，点击 “继续Continue”。

![](../Images/817b67beba8d18f9f16696bad487c27d.png)

*输入代理信息-debian10*

随着安装进程的继续， 你会被问到，是否想参加一个软件包用途调查。你可以选择任意一个选项，之后点击“继续Continue”，我选择了“否No”。

![](../Images/561943f631f1541644c7765c0b3baabe.png)

*参与调查-debain10*

在软件选择窗口选中你想安装的软件包，点击“继续Continue”。

![](../Images/b138c5a46cfcd92eca5d7ff2d8e66e74.png)

*软件选择-debian10*

安装程序会将选中的软件一一安装，在这期间，你可以去喝杯咖啡休息一下。

系统将会询问你，是否要将 grub 的引导装载程序安装到主引导记录表（MBR）上。点击 “是Yes”，而后点击 “继续Continue”。

![](../Images/994a6dc5d109c9b39e01b2328e09356d.png)

*安装-grub-bootloader-debian10*

接着，选中你想安装 grub 的硬盘，点击“继续Continue”。

![](../Images/76669abf0ffba22b037687bb961db06a.png)

*选择硬盘-安装 grub-Debian10*

最后，安装完成，直接点击 “继续Continue”。

![](../Images/47fdbdcdef4deab51b45dd71209df5d0.png)

*安装完成-重新启动-debian10*

你现在应该会有一个列出 Windows 和 Debian 的 grub 菜单。为了引导 Debian 系统，往下选择 Debian。之后，你就能看见登录界面。输入密码之后，按回车键。

![](../Images/4e017adf13774096dae742d873dc7c7d.png)

*Debian10-登录*

这就完成了！这样，你就拥有了一个全新的 Debian 10 和 Windows 10 双系统。

![](../Images/250c4baa8df536506ce3b0a5e4ad8ff4.png)
