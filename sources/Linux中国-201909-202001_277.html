微软承认新 BUG：使用持久性内存的设备会出现启动缓慢问题 | 每日安全资讯

在支持文档中，微软承认使用持久性内存的部分设备可能会出现启动缓慢的情况。
作者/来源：安华金和

在近日更新的官方支持文档中，微软承认了存在于 Windows 操作系统中的一个 BUG，不过所幸的是普通消费者并没有受到负面影响。在支持文档中，微软承认使用持久性内存的部分设备可能会出现启动缓慢的情况。

微软解释道：“在你配置了使用大容量内存（包括持久性内存）的 Windows 设备之后，计算机启动的时间可能会比预期的时间更长。此外在启动后短时间内，会增加 CPU 使用率的情况。当应用程序快速连续释放并重新分配大范围的内存时，CPU 使用率就会增加。”

该公司补充说这是一个已知问题，以后的更新将配合针对启动程序的其他优化措施以解决此问题。正如前文所述，大部分普通消费者并不会受到影响，受影响的 Windows 系统包括：

◈ Windows Server IoT 2019 Standard
◈ Windows Server IoT 2019 Datacenter
◈ Windows Server 2019 Standard
◈ Windows Server 2019 Datacenter
◈ Windows Server 2016 Standard
◈ Windows Server 2016 Datacenter
◈ Windows 10 Pro for Workstations

微软解释说只有在内存模式中使用持久性内存，才会触发这个BUG。如果将这项功能设置为存储设备，能够像正常操作系统一样启动。微软解释道：“持久性内存被广泛应用于 Windows 客户端和 Windows 服务器。如果你配置的系统使用包含持久性内存的大容量内存，可能需要额外的启动时间。在重启和 runtime 释放内存的时候，系统必须要清除所有持久性内存才能继续使用。”
