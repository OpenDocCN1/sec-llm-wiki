# 优麒麟 19.10 正式发布—百尺竿头，更进一步 | Linux 中国

北京时间 2019 年 10 月 18 日，优麒麟团队很高兴地宣布优麒麟Ubuntu Kylin开源操作系统最新版本 19.10（版本代号 Eoan Ermine ）正式发布。此次发布的新版本在系统内核、桌面环境、特色应用等全新升级的同时，进一步优化提升应用组件稳定性，修复了定时关机功能概率性失效、多屏切换时窗口管理器异常等 80 多个重要问题，从而为用户提供更加高效稳定的使用体验。特别是全新开发的软件中心和控制面板，将使软件管理和系统配置更加便捷。同时发布的还有 Ubuntu 19.10、Lubuntu 19.10、Xubuntu 19.10、Ubuntu Mate 19.10 等开源发行版。

本次发布的增强版本中集成了全新升级的控制面板，对系统设置功能进行了重新的精细化分类，方便用户更快的进行设置功能的查找和操作，同时操作界面也更加简洁，线条图标更具透视感，将给用户提供更好的使用体验:

![](../Images/84d6afd5d906c613b537d51f93c561e7.png)

本次新版本中麒麟软件中心也进行了大幅度的改造升级，导航和布局进行了重新设计实现，使软件安装、升级和卸载操作更加直观便捷，全新的启动动画和界面主题也将给用户的使用带来更多乐趣。目前在飞腾 ARM 平台已经投入使用的安卓兼容应用管理功能，将在 X86 兼容环境就绪后直接对接，敬请期待：

![](../Images/f659a333cd8ae54e9740a6efa4b3e977.png)

变更清单

内核

而在内核方面，本次版本升级到 5.3，提供了大量改进、优化和新的硬件支持：

◈ 支持 Intel Speed Select，以便在某些 Xeon 服务器上更轻松地进行电源调整；◈ 支持 AMD Radeon Navi 显卡，例如 AMDGPU 驱动程序中的 AMD Radeon RX5700；◈ 支持 Zhaoxin x86 处理器，以及对功率不对称 CPU 中的利用夹紧机制的支持；◈ 0.0.0.0/8 范围内 1600 万个新 IPv4 地址；◈ Inter HDR 显示支持；◈ 在 Nouveau 中提供 TU116 支持；◈ MacBook 和 MacBook Pro 键盘支持；◈ RISC-V 代码改进；◈ 任务调度程序中的利用率限制支持；◈ EXT4 得到了速度的提升，用于不区分大小写的查找。

更多特性，请参考：https://kernelnewbies.org/Linux\_5.3。

桌面

在桌面环境层，针对用户的反馈和建议，添加了连接隐藏 wifi 的功能，并修复了一系列系统 bug，提升用户的使用体验：

![](../Images/4b271e4a9387debc89e00556f274c1a3.png)

（1）开始菜单

◈ 修复定时关机功能概率不生效问题；◈ 新增部分翻译；◈ 增加对安卓兼容分类的支持。

（2）任务栏

◈ 解决打开多个应用程序，应用占满任务栏并显示异常的问题；◈ 解决任务栏的关于中版权显示错误的问题。

（3）通知区域

◈ 解决点击时间和日期设置后显示控制面板界面的问题；◈ 解决内存泄露的问题；◈ 解决任务栏大小改变后，托盘图标大小改变不正确的问题；◈ 解决托盘应用的提示信息显示错误的问题；◈ 修复日历按钮上错误的主题效果；◈ 解决日历假期时间和实际不同步的问题；◈ 解决 2100 年 12 月时日历界面显示错误的问题；◈ 解决每年的一月不显示月的问题；◈ 解决鼠标悬浮在日历后，日历大小发生改变的问题；◈ 解决在扩展屏的情况下，日历位置显示不正确的问题。

（4）登录程序

◈ 当前用户生物特征数目为 0 时不显示生物特征登录按钮；◈ 登录界面使用指纹，当只插入一个设备时，默认选中当前设备；◈ 添加获取用户默认指纹设备的命令；◈ 修复切换用户时使用指纹登录显示不正确的问题；◈ 修复存在多个用户时，无法切换用户的问题。

（5）锁屏

◈ 修复当用户名较长时，会启动多个锁屏，且无法输入密码的问题；◈ 修复在双屏模式下锁屏显示不全且可能卡死的问题；◈ 修复在设置桌面背景为自动切换时锁屏显示背景为白色的问题； ◈ 修复在使用输入法时锁屏，输入法会显示在锁屏之上的问题；◈ 修复锁屏概率性出现无法输入密码的问题；◈ 添加切换用户时自动锁屏；◈ 屏幕保护程序设置为图片文件夹时显示黑屏的问题；◈ 修复在锁屏时弹出新窗口，锁屏失去焦点且无法输入的问题。◈ 适配安卓兼容

（6）窗口管理器

◈ 解决多屏切换时窗口管理器崩溃的问题；◈ 解决与 gsettings-desktop-schemas 冲突的问题。

（7）文件管理器

◈ 修复在使用列表视图模式时奔溃的问题；◈ 修复文件管理器设置需手动刷新后才能生效的问题。

（8）主题

◈ 全新的壁纸以及系统主题更新。

应用

在特色应用方面，进行了全面的功能升级和 bug 修复，提升了稳定性和实用性，主要的更新包括：

（1）麒麟软件中心

◈ 全新的启动动画，并优化动画效果；◈ 修复源更新后，加载主界面时间长的问题；◈ 修复了启动时加载标题的问题；◈ 修复了焦点刷新导致输入法闪烁的问题；◈ 添加访问服务器的各个接口的超时判断，5秒连接不上则会超时；◈ 添加数据库访问锁，解决偶现的多个线程同时访问报错卡死；◈ 优化源地址添加功能，解决几种失败情况会提醒添加成功问题，增加对添加源的判断，已存在或已包含的进行提醒；◈ 优化帐号注册中邮箱格式判断，添加同一邮箱只能注册一次的检测和提醒；◈ 修复注册的邮箱长度限制太短；◈ 修复通过软件商店客户端安装的软件未记录到“我的软件”中问题；◈ 更改界面皮肤，修改所有界面风格，修改部分用户交互，更直观；◈ 合并首页，宝库，Win 替换三个界面，简化界面布局，更易用；◈ 添加 Android 软件模块，为 Kydroid（kylin android 兼容）提供 APK 包管理，包括安卓软件的下载，安装，升级和卸载。

（2）麒麟助手

◈ 为系统信息每个条目增加错误页面；◈ 麒麟助手和控制面板功能分类整合，去掉冗余功能；◈ 更新多国语言翻译。

（3）麒麟天气

◈ 支持城市自动定位；◈ 修复星期字段有错误的 bug；◈ 应用图标从主题获取。

（4）麒麟影音

◈ 支持界面缩放；◈ 添加音频均衡器和过滤器；◈ 去掉测试代码和冗余代码；◈ 增加远程控制播放的 dbus 接口。

（5）网络小程序

◈ 添加连接到隐藏 Wi-Fi 网络的功能按钮，始终位于无线网络列表最后一个；◈ 插拔无线网卡/网线时，界面即时更新；◈ 连续点击网络列表中的某个网络，项目高度在 60 和 110 之间切换；◈ 无线网络源更新时，网络列表即时更新。

在定制应用方面，新版 WPS 实现 PDF 文件阅读和插入公式功能，搜狗输入法可以对离线词库进行导入导出，更多功能更新只为给用户最好的日常办公体验：

（1）金山 WPS

![](../Images/fa47bb65da9c0fc5c2a2eecc08d21c02.png)

◈ 支持插入和编辑公式；◈ 支持以附件形式插入DOC/DOCX/XLS/XLSX/PPT/PPTX 等格式文档；◈ 支持账号级别的文档加密；◈ 优化打印设置，解决一些真实打印效果与设置不符的问题；◈ 优化打印效率；◈ 修复插入矢量图后，输出为 PDF，矢量图变为位图的问题；◈ 修复排版，字符测量的区域错误问题；◈ DBF 格式的 IO 采用 GBK 编码；◈ 打开 DIF 文件支持猜编码；◈ 优化xlsx文件的打开效率；◈ 优化表格计算效率；◈ 修复双击 PPS/PPSM/PPSX 放映格式文件打开，放映没有置顶的问题；◈ 修复用幻灯片方式放映 PDF 时，弹出黑框的问题；◈ 修复 PDF 加载字体失败，导致崩溃的问题。

（2）搜狗输入法

◈ 新增离线词库 Windows、Linux 导出、导入、清空功能。
