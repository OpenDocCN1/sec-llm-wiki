第一、活动背景

Ubuntu 是一个可将PC和物联网设备连接到服务器和云的平台。包含了一整套用于开发，配置，管理和服务编排的企业级工具。自 Ubuntu 第一个版本 Ubuntu 4.10（代号 Warty Warthog）发布以来，而 Ubuntu 19.10（Eoan Ermine）将是十五周年纪念版。新版系统不仅拥有常规的软件版本升级，还有令人兴奋的新功能。

第二、活动介绍

Ubuntu19.10 新系统的常规升级部分：Linux 内核 5.3，GNOME 3.34 桌面环境，桌面外观改进。新功能特性：

  • 实验性 ZFS 文件系统安装选项，

  • 系统镜像集成 Nvidia 显卡驱动，

  • Snap 应用迎来主题支持，

  • 采用 LZ4 压缩算法减少系统启动时间。

本次发布派对除了介绍新系统外，还有其他值得期待的亮点：

MicroK8s，是一个高效、轻量级的K8s发行版，已支持主流的 42 个 Linux 发行版，专为开发者、IoT 边缘计算以及工作站开发测试 K8s 所打造。支持 Linux、Windows、Mac OS 等系统环境。发布派对当天将会有 Ubuntu 的工程师现场分享 MicroK8s 相关内容。

联想 ThinkPad X1 Carbon 2019 Ubuntu 版展示：Ubuntu 致力于为开发者提供一个用户体验友好的 Linux 系统环境，经过 Canonical 认证的笔记本机型可以避免系统适配的问题，开箱即用，更容易的管理系统固件及驱动更新，LTS 版本可享受5年安全更新支持，Ubuntu 18.04 LTS 可拥有长达 10 年的安全维护支持。


与此同时，我们也邀请了部分 Linux 社区开发者、Linux 大咖、Linux 用户小组成员等嘉宾亲临闲场作技术分享、交流，如你想了解更多最新、最前沿的 Linux 系统、技术等内容，参加本次发布会将是一个不错的选择。



在 15 周年版 Ubuntu 将会有哪些新变化？欢迎加入 Ubuntu Release Party（发布派对）。
