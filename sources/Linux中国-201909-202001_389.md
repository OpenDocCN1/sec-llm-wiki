# 数据显示没有什么浏览器能够阻止 Google Chrome 称王 | 每日安全资讯

微软正在努力使基于 Chromium 的 Microsoft Edge 浏览器能够正式与用户见面，但从市场数据上看，没有什么能真正阻止 Google Chrome 成为世界之王。NetMarketShare 提供的统计数据表明，谷歌浏览器正接近创下新纪录。上个月，谷歌浏览器的市场份额从 8 月份的 67.22％ 上升到 68.47％，创下新高，距离 70％ 的市场份额更近了一步。

Mozilla 的 Firefox 仍然是第二名，离第一名距离还很远。尽管如此，Firefox 在 9 月份也设法将其市场份额从上个月的 8.43％ 提高到8.72％。

![](../Images/fbbdd51845a09f0564d32582756ff1ee.png)

*not-even-the-chromium-microsoft-edge-can-stop-google-chrome-527658-2.jpg*

目前，Microsoft Edge 的市场占有率为 5.87％，低于 8 月份的 6.34％，而不再具有新功能和改进功能的浏览器 Internet Explorer 下降至 6.14％。

Internet Explorer 的淡出并不令人感到意外，但对于微软而言，更令人担忧的不仅是 Microsoft Edge 无法增长，而是 Google Chrome 以超快的速度做到了。

尽管另一个内核的 Microsoft Edge 版本即将推出，Windows 10 集成哪个内核的 Edge 目前还是未知数，一方面微软也很难说服用户切换到他们的浏览器，他们需要找到一种有效的方式来告诉人们 Windows 10 预装的浏览器与 Google Chrome 一样好。但是到现在为止，这似乎都是不可能完成的任务。
