微软今天宣布，Edge Canary 79 中将 Defender SmartScreen 保护扩展到“潜在有害应用程序”（PUAs）下载中。
作者/来源：安华金和

基于 Chromium 的 Microsoft Edge 浏览器已经整合了 Microsoft Defender SmartScreen，当用户访问恶意网站或者下载恶意文件的时候能够提供妥善的保护。微软今天宣布，Edge Canary 79 中将 Defender SmartScreen 保护扩展到“潜在有害应用程序”（PUAs）下载中。

Chrome 使用 Google Safe Browsing 来保护用户免受危险网站和文件的侵扰，而基于 Chromium 的 Edge 浏览器则是使用Microsoft Defender SmartScreen，在 Edge 浏览器的服务类目中的“Privacy and services”已经默认启用。

注意：有意或无意地关闭安全设置，会导致 Edge 和 Chrome 将所有下载标记为恶意下载。因此除非你明确知道自己在做什么，否则就不要禁用这个选项。
