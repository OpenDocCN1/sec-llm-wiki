# Windows 7/8.1 新补丁藏猫腻：悄悄搜集数据 | 每日安全资讯

Windows 10 系统备受争议，除了功能界面设计、层出不穷的 Bug、扰民的更新补丁之外，还有很重要的一点就是对隐私的侵犯，尤其在国外一直是焦点所在。按照微软的说法，Windows 10 系统搜集用户使用数据，是为了完善系统、修复缺陷、增强体验，但是很多用户并不买账，微软也逐步调整，放弃了很多数据的搜集，并将选择权交给用户。

但是没想到，微软又盯上了 Windows 7、Windows 8.1 两款老系统。

今年 7 月份就有人发现，微软推送的 Windows 7 更新补丁里包含数据搜集相关代码，但是 KB 知识库文章却未提及。

现在，微软 9 月份的补丁中如法炮制，而且这次“中招”的不仅是将在年初退役的 Windows 7，还包括要到 2023 年初才会停止支持的 Windows 8.1，而且微软依然没有任何明确说明和解释。

目前能找到的相关信息，只有一个 Windows 7 兼容性更新知识库 KB2952664里提到，该更新会对参加 Windows 用户体验改善项目的系统进行诊断，评估 Windows 生态兼容状态，帮助微软确保应用与设备兼容所有的 Windows 更新。

但是关于 Windows 8.1，暂时没有任何相关信息。

如果你还在使用 Windows 7、Windows 8.1，不想被微软“刺探”，可以禁用以下计划任务：

◈ \\Microsoft\\Windows\\Application Experience\\ProgrAMDataUpdater◈ \\Microsoft\\Windows\\Application Experience\\Microsoft Compatibility Appraiser◈ \\Microsoft\\Windows\\Application Experience\\AitAgent
