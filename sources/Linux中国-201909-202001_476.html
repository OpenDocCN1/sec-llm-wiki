继 WPS Office 2019 For Linux 个人版上次发布以来，今天，WPS 2019 又发布了新的更新版本 11.1.0.8865 。本次发布的最大亮点是，首次在 Linux 版本上支持了公式功能——这是金山公司为 Linux 版本专门全新打造的。

新公式助力学术办公

伴随着这次新版本的发行，在 Linux 平台首次引入了公式插入功能，便捷高效、灵活易用。针对文档中插入复杂公式的应用需求，该功能将帮助用户更加舒适地将复杂多变的公式内容精准地落实到文档当中。 

文档中插入附件

新版的 WPS 中将能够支持在文档中直接嵌入其他形式的文档，实现 WPS 与 DOC/DOCX/XLS/XLSX/PPT/PPTX 等形式文档的高效整合与无缝切换。为一些特定化的文档展现提供更加便捷的解决方案。 

加密方式推陈出新，致力保障文档安全

本次更新后，用户将可以在 Linux 端对文档进行账号级别的加密。所有文档均可以账号为基础进行精细粒度的权限划分，用户完全可以灵活地控制每个账号对此文档的阅读、编辑、复制、打印、另存等权限。并且我们在权限设置的流程上做出了最大程度的优化，保证用户能用最直观简洁的操作，完成复杂的文档权限编辑。 

其他更新

除此以外，此处更新还包括：优化打印设置，解决一些真实打印效果与设置不符的问题，优化打印效率；优化表格计算效率；以及修复若干错误。
