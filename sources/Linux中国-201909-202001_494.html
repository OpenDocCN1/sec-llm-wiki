为了提高隐私和性能，从 2019 年 9 月下旬开始，Mozilla 将在 Firefox 浏览器中默认为美国用户推出并启用 DNS over HTTPS（DoH）。在过去两年中进行了许多实验之后，Mozilla 决定在 Firefox 中默认打开 DoH。该公司相信，他们的“用户将受益于加密 DNS 流量的更大保护”。Firefox 浏览器将在启用该功能时会向用户发出提示，并允许他们选择退出。

今天在博客文章中，Mozilla 表示，让他们感到惊讶的是，已经有 70 多万用户在 Firefox 发布版本中启用了 DoH。在向美国市场发布 DoH 之前，他们曾经表示“尊重企业配置并尊重用户对父母控制设定上的选择”。

Mozilla 表示他们将在后备模式下部署 DoH，这意味着，如果域名查找使用 DoH 失败，那么 Firefox 将退回并使用操作系统默认 DNS 进行查找。

在合作伙伴的选择上，Mozilla 倾向于使用 Cloudflare for DoH，因为他们同意签署强有力的隐私协议，因此美国的一些 Firefox 用户很快就会使用 Cloudflare DNS，但这可能会在未来发生变化。
