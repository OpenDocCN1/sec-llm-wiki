不借助 Wine 和云服务：新项目能让 Linux 完整运行微软 Office 套件

现在有人可以不借助 Wine、云服务或者 GNOME on WSL，就能流畅运行微软 Office 完整功能。根据网友在推特上晒出的两段视频，展示了在 Ubuntu 20.04 系统中运行 Word 和 Excel。创建整个项目的开发者 Hayden Barnes 在演示中表示这两款应用程序都“非常好用”。尽管 Barnes 表示目前没有公布细节的原因是还需要努力完善整个体验，不过他确认微软 Office 应用是在 Linux 容器中运行的。

来源：cnBeta.COM

> 硬核老王点评：非常令人惊喜的突破，期待研究者进一步完善后公开。如果能在 Linux 上获得完美的微软 Office 体验，想必对 Linux 桌面的推广极有好处。

神秘人士将《马里奥64》完全移植到 PC，运行效果完美

不需要任何模拟器，可以直接通过 DirectX 运行在 PC 上。可以自动适配显示器分辨率，甚至还支持 Xbox手柄。总之就是一个彻头彻尾的 PC 移植版《马里奥64》。《马里奥64》的反编译代码文档此前被公开到了 Github 上。据猜测，这个项目可能是基于 2019 年成功反编译的《马里奥64》代码，让程序员可以更加清楚地看到游戏内部结构。

来源：3DMGame

> 硬核老王点评：“开源”的好处。

Mozilla Firefox 76 稳定版发布：引入 Lockwise 密码管理

新版本中引入的 Lockwise，此前名为 Firefox Lockbox，不过新版本变得更加智能。该功能允许用户生成、管理和保护所有流媒体服务、杂货店的外卖的帐号密码，以及其他在新冠疫情期间有所帮助的密码。Lockwise现在还可以为更多网站生成安全密码（至少12个随机字母、数字和符号）。新版本还带来了“画中画”功能，即小窗口播放视频，以便用户在不同的应用程序中执行多任务。

来源：cnBeta.COM

> 硬核老王点评：虽然市占比不如 Chromium 家族，但是 Mozilla Firefox 对安全和隐私的追求非常值得赞赏。

Google 为桌面版 Chrome 浏览器带来实时字幕功能

在 Android 平台的 Pixel Phones 上推出实时字幕功能后，谷歌现在又将该功能带到了各个操作系统平台上的 Chome 浏览器上。这意味着，如果用户在无障碍设置中启用“实时字幕”开关，Chrome 浏览器将自动检测正在播放的媒体内容中的语音，并为浏览器中播放的所有媒体生成字幕。

来源：cnBeta.COM

> 硬核老王点评：实时字幕其实在（国外）早期的有线电视中就有，Youtube 上也有，现在在 Chrome 浏览器上支持了，对于原本无字幕的媒体还是很有用的。不过，是否可以支持中文，这一点还不确定。

128 核心 CPU 问世：12 通道 DDR5＋PCIe5.0、性能超顶级 Intel 至强

2016 年才成立的斯洛伐克创业公司 Tachyum 今天抛出一枚重磅炸弹，宣布了全新的 128 核心 Prodigy 处理器，号称“性能可超越 Intel 最快的至强，同时功耗仅有十分之一”。Tachyum Prodigy 号称是全球第一颗“通用处理器，因为它在单独一颗硅片内，集成了通用目的处理器、高性能计算、AI 人工智能、DML 深度机械学习、可解释人工智能、生物人工智能等等，基于并行多处理器环境，可简化编程模型和环境。不过目前产品还在纸面上，目前只流片成功了 64 核心的 T864，预计今年内投入量产。

来源：快科技

> 硬核老王点评：虽然尚未流片，但是如果真能打破 Intel 的霸主地位，那非常值得期待。

Popcorn 开源项目因 DMCA 通知被 GitHub 关闭

美国电影协会向 GitHub 递交了 DMCA 删除通知，称开源项目 Popcorn Time 广泛侵犯了电影和电视节目的版权。GitHub 之后根据要求关闭了 Popcorn Time 的开源库。这一做法引起了争议，因为 Popcorn Time 本身并不包含任何侵权材料，但作为一种工具它确实能帮助用户访问侵权材料。作为一种工具，Popcorn Time 整合了 BT 下载和流媒体播放器，能提供类似 Netflix 的盗版内容流媒体服务。

来源：solidot

> 硬核老王点评：工具是无罪的？
