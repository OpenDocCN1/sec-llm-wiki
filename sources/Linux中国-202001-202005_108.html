Oracle 提交补丁 可使 Linux 内核引导提速 6%-49%

Oracle 开发者在邮件列表中指出，该补丁扩展了 padata，使其可以处理多线程作业。此补丁的改进同时也使启动虚拟机的时间缩减，这对于云计算环境来说非常重要。

来源：开源中国

对于通常的 Linux 系统来说，对内核引导速度的提升并不敏感，但对于大量运行容器的云计算环境来说意义重大。

微软开源 Rust/WinRT 方便使用 Rust 构建 Windows 应用

该项目和 C++/WinRT 一脉相承，用标准语言和编译器为 Windows 运行时构建语言投影，从而方便 Rust 开发人员调用 Windows API，更轻松地使用 Rust 构建各类 Windows 应用和组件。目前 Rust/WinRT 还处于早期预览状态。

来源：开源中国

看来微软对 Rust 相当青睐啊。

使用 Wayland 在 Android 10 上运行 KDE Plasma 5

有开发者使用专为 Android 打造的 Wayland Server 项目 Sparkle 实现了在 Android 10 上运行 KDE Plasma 5。

来源：开源中国

重要的不是能不能在手机上运行 Linux 显示服务器，而是有没有合适手机上使用的操作系统。

Netmarketshare 报告显示 Windows 10 操作系统却有下降

在本月的报告中，Windows 10 的份额为 56%，低于此前的 57.34%。Windows 整体份额的下降是来自于一个意想不到的领域：Linux 桌面的使用份额从 1.36% 飙升至 2.87%。

来源：cnBeta.COM

Linux 桌面的使用份额总是在百分之几的比例上变化，说实话，就目前的操作系统的格局来看，很难对 Linux 桌面的份额抱大的期望。

报告称 Google Meet、Microsoft Teams 和 WebEx 收集了大量客户数据

《消费者报告》分析了 Google Meet、Microsoft Teams 和 WebEx 的隐私政策，发现它们收集的数据可能比很多人意识到的要多。需要明确的是：《消费者报告》并不是说这些应用不安全，但是通过同意这些服务的隐私政策，就等于让谷歌和微软等公司获得了大量的个人数据。

Facebook 应对反垄断质疑：允许北美用户向其他平台迁移数据

借助这款工具，Facebook 用户便可将该公司服务器上的数据直接转移到 Google Photos 等平台。美国和加拿大用户从本周四开始即可使用这款工具。Facebook 之前已经在欧洲和拉美等地推出同样的工具。

来源：新浪科技

我们也需要有这种对垄断性的应用/服务的制裁。

树莓派 3/4 已被成功刷入 Win10 ARM 系统

在 2019 年，就有关于黑客开发者正在研究将 Windows 10 ARM 桌面系统刷入树莓派的消息。该项目取得了更大的进展，Windows 10 被移植到树莓派 4，尽管它目前仅支持 1 GB 内存。Windows 10 在树莓派 4上的运行速度比 3 快约 50％。

来源：IT 之家
