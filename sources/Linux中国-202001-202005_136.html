Laminas 项目（以前称为 Zend 框架）托管到了 Linux 基金会 | 新闻

Linux 基金会将为 Zend 框架社区提供一个供应商中立的家，继续为下一代 Web 服务和 API 推进 PHP 工具，同时维护现有的 Zend 框架组件，包括 Apigility 和 Expressive 子项目。

Zend 框架是一组专业的 PHP 包，可用于使用 PHP 5.6+ 开发 Web 应用程序和服务，它使用广泛的语言功能提供 100％ 面向对象的代码。

该项目已经获得了令人难以置信的支持，提交了 120 万次，每年发布数百个版本，并累积有数千名贡献者。该项目在电子商务、娱乐、嵌入式和医疗等环境中累积安装了 4 亿个安装，每年增加超过 1.4 亿个。

随着社区希望为下一代 web 服务和 API 发展自己的 PHP 工具，现在是为项目定制开放治理结构的好时机，这种治理结构可以让社区持续几十年。因此，Zend 框架需要一个具有开放治理结构的中立论坛，支持这种级别的采用和创新，并将重点放在新 web 服务和 API 的工具上。

在一年前，Linux 基金会与 Zend Technologies、Rogue Wave Software 一起宣布 Zend 框架正在过渡到 Linux 基金会，并在新的治理框架下改名为 Laminas 项目。 

Laminas 项目是 Linux 基金会托管的最新项目之一。Linux 基金会将为 Zend 框架社区提供一个供应商中立的家，继续为下一代 Web 服务和 API 推进 PHP 工具，同时维护现有的 Zend 框架组件，包括 Apigility 和 Expressive 子项目。

有关 Zend 框架和 Laminas 项目发展的更多信息，请阅读长期贡献者 Matthew Weier O’phinney 的博客文章。
