新冠肺炎疫情导致数百万人居家办公，对此谷歌决定暂停向 Chrome 浏览器和 Chrome OS 操作系统增加新功能，以保证软件尽可能平稳运行。

3 月 18 日，Chrome 开发团队在一条推文中承认，公司“调整后的时间表”导致公司在“即将推出的 Chrome 和 Chrome OS 发布”上遇到停顿。

“我们的目标是保证它们能继续稳定、安全、可靠，为了所有依赖它们的人。”谷歌将会在疫情期间“优先与安全相关的更新”，其中一些更新将在接下来的 Chrome 80 中推出。

TheVerge 当天报道对此评论称，当团队变得分散时，很难平衡 Chrome 的稳定性和新功能，因此谷歌明智地选择了前者，在充满压力的疫情期间，避免让未知的风险干扰依赖 Chrome 工作的人们的生活。
