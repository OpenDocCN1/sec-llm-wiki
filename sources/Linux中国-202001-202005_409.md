# Mac 平台威胁数量已超过 Windows | 每日安全资讯

防病毒软件开发商 Malwarebytes 今天公布了 2020 年恶意软件预估报告，表明 Mac 平台的恶意软件正变得越来越普遍。在每个端点检测到的威胁数量上，Mac 首次超过 Windows PC。Malwarebytes 检测到 Mac 平台共有 11 个威胁，而 Windows 用户只有 5.8 个。而在 2018 年，Mac 平台每个端点仅检测到 4.8 个。

Malwarebytes 表示，2019 年 Mac 平台的整体威胁率增加了 400%，其中主要原因是 Mac 用户群数量的增加。Malwarebytes 声称，在 Mac 上检测到的平均威胁数量已经“大大超过”了 Windows。

这可能是因为，随着 2019 年市场份额的增加，Mac 成为网络犯罪分子更具吸引力的目标。此外，macOS 的内置安全系统并未像对待恶意软件一样对广告软件和 PUP 进行严厉打击，这为这些边界程序的渗透打开了大门。

广告软件总体而言在 2019 年更加激进，针对 Windows，Mac 和 Android 设备上的消费者和企业终端。总共检测到 2400 万Windows 广告软件和 3000 万 Mac 威胁，其中最主要的消费者威胁检测属于广告软件系列。

去年加密货币犯罪造成损失激增近 1.6 倍 达 45 亿美元

北京时间 12 日消息，区块链数据分析公司 CipherTrace 的最新分析显示，2019 年加密货币犯罪造成的损失超过 45 亿美元，较 2018 年的 17.4 亿美元增长了近 160%。过去一年中，由黑客攻击造成的损失下降了 66%，而诈骗和内盗给加密货币用户和投资者带来的损失增加了五倍以上。
