![](../Images/8476e088f59bc6b10039e1c88e07085e.png)了解一下 setV，它是一个轻量级的 Python 虚拟环境管理器，是 virtualenvwrapper 的替代产品。\-- Sachin Patil

这一年多来，我的 bash\_scripts 项目中悄悄隐藏这 setV，但现在是时候该公开了。setV 是一个 Bash 函数，我可以用它代替 virtualenvwrapper。它提供了使你能够执行以下操作的基本功能：

◈ 默认使用 Python 3◈ 创建一个新的虚拟环境◈ 使用带有 `-p`（或 `--python`）的自定义 Python 路径来创建新的虚拟环境◈ 删除现有的虚拟环境◈ 列出所有现有的虚拟环境◈ 使用制表符补全（以防你忘记虚拟环境名称）

安装

要安装 setV，请下载该脚本：

```
1.  `curl https://gitlab.com/psachin/setV/raw/master/install.sh`
```

审核一下脚本，然后运行它：

```
1.  `sh ./install.sh`
```

当安装 setV 时，安装脚本会要求你引入（`source`）一下 `~/.bashrc` 或 `~/.bash_profile` 的配置，根据你的喜好选择一个。

用法

基本的命令格式是 `setv`。

创建虚拟环境

```
1.  `setv --new rango  # setv -n rango`
2.  
3.  `# 或使用定制的 Python 路径`
4.  `setv --new --python /opt/python/python3 rango  # setv -n -p /opt/python/python3 rango`
```

激活已有的虚拟环境

```
1.  `setv VIRTUAL_ENVIRONMENT_NAME`
```

```
1.  `# 示例`
2.  `setv rango`
```

列出所有的虚拟环境

```
1.  `setv --list`
2.  `# 或`
3.  `setv [TAB] [TAB]`
```

删除虚拟环境

```
1.  `setv --delete rango`
```

切换到另外一个虚拟环境

```
1.  `# 假设你现在在 'rango'，切换到 'tango'`
2.  `setv tango`
```

制表符补完

如果你不完全记得虚拟环境的名称，则 Bash 式的制表符补全也可以适用于虚拟环境名称。

参与其中

setV 在 GNU GPLv3下开源，欢迎贡献。要了解更多信息，请访问它的 GitLab 存储库中的 setV 的 README 的贡献部分。

setV 脚本

```
1.  `#!/usr/bin/env bash`
2.  `# setV - A Lightweight Python virtual environment manager.`
3.  `# Author: Sachin (psachin) <iclcoolster@gmail.com>`
4.  `# Author's URL: https://psachin.gitlab.io/about`
5.  `#`
6.  `# License: GNU GPL v3, See LICENSE file`
7.  `#`
8.  `# Configure(Optional):`
9.  ``# Set `SETV_VIRTUAL_DIR_PATH` value to your virtual environments``
10.  `# directory-path. By default it is set to '~/virtualenvs/'`
11.  `#`
12.  `# Usage:`
13.  `# Manual install: Added below line to your .bashrc or any local rc script():`
14.  `# ---`
15.  `# source /path/to/virtual.sh`
16.  `# ---`
17.  `#`
18.  `# Now you can 'activate' the virtual environment by typing`
19.  `# $ setv <YOUR VIRTUAL ENVIRONMENT NAME>`
20.  `#`
21.  `# For example:`
22.  `# $ setv rango`
23.  `#`
24.  `# or type:`
25.  `# setv [TAB] [TAB]  (to list all virtual envs)`
26.  `#`
27.  `# To list all your virtual environments:`
28.  `# $ setv --list`
29.  `#`
30.  `# To create new virtual environment:`
31.  `# $ setv --new new_virtualenv_name`
32.  `#`
33.  `# To delete existing virtual environment:`
34.  `# $ setv --delete existing_virtualenv_name`
35.  `#`
36.  `# To deactivate, type:`
37.  `# $ deactivate`
38.  
39.  `# Path to virtual environment directory`
40.  `SETV_VIRTUAL_DIR_PATH="$HOME/virtualenvs/"`
41.  `` # Default python version to use. This decides whether to use `virtualenv` or `python3 -m venv` ``
42.  `SETV_PYTHON_VERSION=3  # Defaults to Python3`
43.  `SETV_PY_PATH=$(which python${SETV_PYTHON_VERSION})`
44.  
45.  `function _setvcomplete_()`
46.  `{`
47.  `    # Bash-autocompletion.`
48.  `    # This ensures Tab-auto-completions work for virtual environment names.`
49.  `    local cmd="${1##*/}" # to handle command(s).`
50.  `                         # Not necessary as such. 'setv' is the only command`
51.  
52.  `    local word=${COMP_WORDS[COMP_CWORD]} # Words thats being completed`
53.  `    local xpat='${word}'                 # Filter pattern. Include`
54.  `                                         # only words in variable '$names'`
55.  `    local names=$(ls -l "${SETV_VIRTUAL_DIR_PATH}" | egrep '^d' | awk -F " " '{print $NF}') # Virtual environment names`
56.  
57.  `    COMPREPLY=($(compgen -W "$names" -X "$xpat" -- "$word")) # compgen generates the results`
58.  `}`
59.  
60.  `function _setv_help_() {`
61.  `    # Echo help/usage message`
62.  `    echo "Usage: setv [OPTIONS] [NAME]"`
63.  `    echo Positional argument:`
64.  `    echo -e "NAME                       Activate virtual env."`
65.  `    echo Optional arguments:`
66.  `    echo -e "-l, --list                 List all Virtual Envs."`
67.  `    echo -e "-n, --new NAME             Create a new Python Virtual Env."`
68.  `    echo -e "-d, --delete NAME          Delete existing Python Virtual Env."`
69.  `    echo -e "-p, --python PATH          Python binary path."`
70.  `}`
71.  
72.  `function _setv_custom_python_path()`
73.  `{`
74.  `    if [ -f "${1}" ];`
75.  `    then`
76.  ``        if [ "`expr $1 : '.*python\([2,3]\)'`" = "3" ];``
77.  `        then`
78.  `            SETV_PYTHON_VERSION=3`
79.  `        else`
80.  `            SETV_PYTHON_VERSION=2`
81.  `        fi`
82.  `        SETV_PY_PATH=${1}`
83.  `        _setv_create $2`
84.  `    else`
85.  `        echo "Error: Path ${1} does not exist!"`
86.  `    fi`
87.  `}`
88.  
89.  `function _setv_create()`
90.  `{`
91.  `    # Creates new virtual environment if ran with -n|--new flag`
92.  `    if [ -z ${1} ];`
93.  `    then`
94.  `        echo "You need to pass virtual environment name"`
95.  `        _setv_help_`
96.  `    else`
97.  `        echo "Creating new virtual environment with the name: $1"`
98.  
99.  `        if [ ${SETV_PYTHON_VERSION} -eq 3 ];`
100.  `        then`
101.  `            ${SETV_PY_PATH} -m venv ${SETV_VIRTUAL_DIR_PATH}${1}`
102.  `        else`
103.  `            virtualenv -p ${SETV_PY_PATH} ${SETV_VIRTUAL_DIR_PATH}${1}`
104.  `        fi`
105.  
106.  `        echo "You can now activate the Python virtual environment by typing: setv ${1}"`
107.  `    fi`
108.  `}`
109.  
110.  `function _setv_delete()`
111.  `{`
112.  `    # Deletes virtual environment if ran with -d|--delete flag`
113.  `    # TODO: Refactor`
114.  `    if [ -z ${1} ];`
115.  `    then`
116.  `        echo "You need to pass virtual environment name"`
117.  `        _setv_help_`
118.  `    else`
119.  `        if [ -d ${SETV_VIRTUAL_DIR_PATH}${1} ];`
120.  `        then`
121.  `            read -p "Really delete this virtual environment(Y/N)? " yes_no`
122.  `            case $yes_no in`
123.  `                Y|y) rm -rvf ${SETV_VIRTUAL_DIR_PATH}${1};;`
124.  `                N|n) echo "Leaving the virtual environment as it is.";;`
125.  `                *) echo "You need to enter either Y/y or N/n"`
126.  `            esac`
127.  `        else`
128.  `            echo "Error: No virtual environment found by the name: ${1}"`
129.  `        fi`
130.  `    fi`
131.  `}`
132.  
133.  `function _setv_list()`
134.  `{`
135.  `    # Lists all virtual environments if ran with -l|--list flag`
136.  `    echo -e "List of virtual environments you have under ${SETV_VIRTUAL_DIR_PATH}:\n"`
137.  `    for virt in $(ls -l "${SETV_VIRTUAL_DIR_PATH}" | egrep '^d' | awk -F " " '{print $NF}')`
138.  `    do`
139.  `        echo ${virt}`
140.  `    done`
141.  `}`
142.  
143.  `function setv() {`
144.  `    # Main function`
145.  `    if [ $# -eq 0 ];`
146.  `    then`
147.  `        _setv_help_`
148.  `    elif [ $# -le 3 ];`
149.  `    then`
150.  `        case "${1}" in`
151.  `            -n|--new) _setv_create ${2};;`
152.  `            -d|--delete) _setv_delete ${2};;`
153.  `            -l|--list) _setv_list;;`
154.  `            *) if [ -d ${SETV_VIRTUAL_DIR_PATH}${1} ];`
155.  `               then`
156.  `                   # Activate the virtual environment`
157.  `                   source ${SETV_VIRTUAL_DIR_PATH}${1}/bin/activate`
158.  `               else`
159.  `                   # Else throw an error message`
160.  `                   echo "Sorry, you don't have any virtual environment with the name: ${1}"`
161.  `                   _setv_help_`
162.  `               fi`
163.  `               ;;`
164.  `        esac`
165.  `    elif [ $# -le 5 ];`
166.  `    then`
167.  `        case "${2}" in`
168.  `            -p|--python) _setv_custom_python_path ${3} ${4};;`
169.  `            *) _setv_help_;;`
170.  `        esac`
171.  `    fi`
172.  `}`
173.  
174.  `# Calls bash-complete. The compgen command accepts most of the same`
175.  `# options that complete does but it generates results rather than just`
176.  `# storing the rules for future use.`
177.  `complete  -F _setvcomplete_ setv`
```
