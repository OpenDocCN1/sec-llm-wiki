谷歌称 2017 年抵御了史上最大的 DDoS 攻击

谷歌云团队今天透露了一个此前未披露的 DDoS 攻击，该攻击早在 2017 年 9 月就针对谷歌服务进行了攻击，攻击速度达到了 2.54 Tbps，是迄今为止有记录以来最大的 DDoS 攻击。谷歌表示攻击来自中国的网络。

来源：zdnet

苹果可能已经放弃了 Linux 广泛使用的开源打印系统 CUPS

苹果于 2002 年在 Mac OS X 上采用了 CUPS，并在 2007 年聘请了其作者 Michael Sweet。Sweet 2019 年 12 月离职成立新公司。当时虽然还有两名工程师仍在负责 CUPS 的开发，但现在开源 CUPS 代码库现在处于停滞状态。整个 2020 年，CUPS Git 仓库只有一个提交，这与 Sweet 还在苹果工作的 2019 年的 355 次提交和上一年的 348 次提交形成鲜明对比。

来源：theregister

![](../Images/932990915dba2e7829d92ef8ca5a355d.png)

众多网络通信方面的改进正来到 Linux 5.10

Linux 5.10 有大量的网络改进：支持在内核中使用BTF，并在启动时通过用户模式驱动机制提前加载它们；支持可睡眠的 BPF 程序和其他 BPF 增强功能；内核现在允许超过 255 个 IPv4 多播接口。

来源：kernel
