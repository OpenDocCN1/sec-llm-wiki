KDE Plasma 5.20 发布

一些 KDE Plasma 5.20 的亮点包括：对 KWin 窗口管理器/合成器进行了大量的修复，包括一些Wayland的修复；改进的通知；对KDE系统设置进行了不同的重新设计和添加，从SMART监控到更好看的界面；各种任务管理器和系统托盘的改进。

来源：kde

拍一拍：KDE 仍然是那么迷人。

Canonical 推出高可用性的 Micro-Kubernetes

Canonical 的 MicroK8s 是一个易于运行和安装的迷你版 Kubernetes。而现在 Canonical 又为其增加了自主高可用（HA）集群。在新发布的 MicroK8s 中，一旦有三个或更多的节点进行集群，HA 就会自动启用，数据存储会在节点之间自动迁移，以在发生故障时保持法定数量。

来源：zdnet

拍一拍：Canonical 逐渐从一家 Linux 发行商转变为云基础设施开发商。

谷歌警告 Linux 内核存在严重的 “BleedingTooth” 蓝牙缺陷

谷歌公布了一个影响 Linux 5.9 以下支持 BlueZ 的 Linux 内核版本的蓝牙协议栈的高严重性缺陷 CVE-2020-12351 的细节，建议更新到 Linux 内核 5.9。

来源：zdnet

拍一拍：虽然在服务器环境中蓝牙使用不多，但是这个潜伏已久的缺陷可能会导致很多依赖蓝牙的 Linux 设备的严重问题。
