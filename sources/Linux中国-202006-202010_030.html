AMD Radeon 图形驱动占到了 Linux 内核的 10.5%

根据最新的 Linux 5.9 Git 树记录，内核包含有 2049 万行代码，以及 358 万行代码注释和 372 万空行，总共 2781 万行。其中 AMDGPU 图形驱动占据的比例最高，共有 216 万行代码，以及 24.7 万行代码注释和 10.9 万空行，共 251 万行，占到了内核的约 10.5%。相比之下，NVIDIA "Nouveau"驱动只有 14.9 万行代码，2.56 万行注释和 1.99 万空行。

微软出手封杀泄露的 Windows XP 源代码

Mega 网盘的源码打包文件已经被撤下，微软似乎还出手干预了部分谷歌的搜索结果页和种子网站。不过，Windows XP 源代码早在 2001 年就开始面向学术圈共享，以互相检查确保安全性。

美国“网络司令部”正试图破坏世界上最大的僵尸网络

最近几周，美国军方发起了一项行动，以暂时破坏被称为世界上最大的僵尸网络 Trickbot —— 这个网络也被用来投放勒索软件，至少由 100 万台被劫持的电脑组成。美国军方官员们说这是 2020 年美国大选的首要威胁之一。但是 Trickbot 运营者已经开始重建他们的僵尸网络，并继续参与在新的目标上部署勒索软件。
