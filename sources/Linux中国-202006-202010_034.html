Software AG 遭勒索索要超过 2000 万美元

Clop 勒索软件团伙入侵 Software AG ，对文件进行加密，索要超过 2000 万美元。在谈判失败后，Clop 在暗网上公布了该公司的数据截图。2000 多万美元的勒索要求是有史以来勒索软件攻击中最大的勒索要求之一。Software AG 是德国第二大公司，全球最大的软件公司之一。

来源：zdnet

拍一拍：这么大的企业，还是软件企业，都会被击倒。

谷歌计划放弃对开源项目 Knative 的控制权

Knative 最初是谷歌开发的一个开源项目，它提供了在 Kubernetes 之上部署、运行和管理无服务器、云原生应用的组件。谷歌正计划对 Knative 的治理结构进行一些重大改变：包括委员会席位由个人担任，增选到 7 名成员等。

来源：siliconangle

拍一拍：之前谷歌将 Istio 交给一个另外创建的组织，而非承诺的 CNCF，引来社区诸多不满，这应该是一个回应吧。

Chrome 改变缓存机制以保护用户隐私

如果用户重新访问了同一个网站或使用相同资源的网站，浏览器可以直接从内部缓存里加载资源，无需重新下载文件。这一缓存机制最近几年被广告商和分析公司利用去跟踪用户，能发动跨站搜索攻击和实施跨站跟踪等等。从刚刚发布的 Chrome 86 开始，Google 引入了名为“缓存分区”的新机制阻挡对缓存机制的攻击。以前资源的存储键只有一个项，现在将包含三个项，包括域名、当前帧和网址。

来源：solidot

拍一拍：浏览器厂商和广告商对用户的隐私争夺战此起彼伏，而很多用户却漠然视之。
