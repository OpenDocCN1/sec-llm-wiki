微软发布 VSCode 的树莓派和 ChromeBook 官方版本

微软官方构建的 Visual Studio Code 现在可用于 Linux Armv7 和 Arm64 设备。而基于 VS Code 开源代码构建的开源版本，已经能够在 Chromebook 和树莓派上使用了一段时间了。

来源：zdnet

拍一拍：虽然这些 ARM 板子的功能可能不足以满足所有开发者的需求，但远程开发扩展包可以在需要时提供访问更强大的开发环境。

Paragon 力求尽早将其 NTFS 驱动写入 Linux 内核中

早在8月份，文件系统驱动厂商 Paragon 软件公司就表态希望把他们的 NTFS 驱动整合到 Linux 内核中，这比现有的 NTFS Linux 驱动会带给 Linux 用户更大的惊喜。

来源：cnbeta

拍一拍：现在的 NTFS 驱动也就是能用而已，期待尽快进入主线。

苹果向曾操控公司网络的白帽黑客支付 28.8 万美元

专注于网站安全的 20 岁研究人员萨姆-库里说，他和他的团队总共发现了 55 个漏洞。这些漏洞让他能够控制苹果核心基础设施，并从中窃取私人电子邮件、iCloud 数据和其他私人信息。在库里报告了这些漏洞后，苹果公司迅速修复了这些漏洞，时间跨度为三个月。到目前为止，该公司已经处理了大约一半的漏洞，并承诺为这些漏洞支付 28.85 万美元。

来源：arstechnica

拍一拍：这就厉害了，真是幸福的白帽子。
