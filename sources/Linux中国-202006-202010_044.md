ARM CPU 将在 2022 年放弃对 32 位运算的支持

最近 ARM 公司透露 ARM CPU 将放弃对 32 位应用的支持。这对用户没有太大的影响，因为过去的几年里，32 位应用和软件一直在缓慢地被淘汰。苹果从 2015 年开始要求应用支持 64 位架构，2017 年，苹果完全放弃了对 64 位设备上 32 位应用的支持。去年，谷歌开始了自己对 64 位计算的推动，规定新的应用和应用更新必须支持 64 位。

来源：cnbeta

> 拍一拍：一转眼 32 位都被淘汰了。

谷歌开始在 Google Chrome 中加入 HTTP/3 和 IETF QUIC 支持

IETF 早在 2015 年就推出了 HTTP/2，它带来的一大改进就是支持复用。但是，它采用了 TCP 作为传输协议，丢失的数据包仍然会造成活动事务的延迟。通过采用 QUIC，HTTP/3 可以进一步改善传输过程。之前谷歌只支持自己的 QUIC 实现，现在谷歌表示，IETF QUIC “在 TCP 上明显优于 TLS 1.3 的 HTTPS”，因此在其浏览器中启用了对 IETF QUIC 的支持。

来源：cnbeta

> 拍一拍：期待尽快确定 HTTP/3 规范和普及开来。不过，连 HTTP/2 还尚未普及。

GIMP 首次支持 AVIF 图像

AVIF 是一种非常有前途的图像格式，基于免版税的 AV1 技术，已经被 Firefox 和 Google Chrome 等 Web 浏览器支持。相比较 WebP 和 JPEG 等格式，AVIF 的压缩能力明显更好。AVIF 支持全分辨率下的 10 位和 12 位色彩，以及高动态范围（HDR）。AV1 还使用了一种新的压缩技术：从色度到亮度，所以 AVIF 可以提供更小的文件大小和更清晰的边缘。

来源：cnbeta

> 拍一拍：新的图像格式好是好，可惜就像 WebP 一样，要取得普遍支持还比较难。
