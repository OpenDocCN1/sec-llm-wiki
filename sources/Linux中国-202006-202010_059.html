谷歌设立研究基金寻找浏览器 JavaScript 引擎中的错误

该计划用于支持使用“模糊测试”来识别漏洞。模糊测试技术在大的科技公司内部被广泛使用，但很少被独立安全研究人员使用，因为模糊测试的计算成本很高。这些安全研究人员通常在在公共 bug 赏金平台上提交 bug 几个月后才会得到报酬，而且报酬也不一定能保证覆盖任何初始成本与租用大型云计算资源来执行大规模的模糊操作。谷歌表示，它创建了这项研究补助金来解决这个特殊的问题。该计划所支持的 JavaScript 引擎不仅仅包括 V8 引擎，也包括了其它主流浏览器所使用的引擎。

Linux 内核 5.10 更新优化 EXT4 文件系统

改善了某些场景下的文件覆盖特性。这可以为多线程写入，特别是随机覆盖提供显著的性能提升。在 PPC64 虚拟机上，模拟 pmem（DAX）设备，随机写入的性能提升了 10 倍左右。在 x86 虚拟机上，观察到约 2 倍的性能改进。

微软将 Edge 开发者工具放入 VS Code

这个新的扩展允许开发者在微软的 VS Code 中使用 Edge 浏览器内的元素和网络工具来修复网站的样式、布局和 CSS 问题。这样当开发人员从开发任务转到调试任务时，就不需要在编辑器和浏览器之间切换。用户现在可以连接到一个现有的浏览器实例，启动一个新的浏览器或一个无浏览器窗口、在任务栏中也没有图标的无头浏览器。
