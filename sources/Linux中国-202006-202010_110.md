# Linux Foundation开源软件大学人才激励计划正式启动

Linux 基金会一直致力于为全世界培养更多的开源人才，通过扩大技术人才的多样性推动全球开源创新。为了实现这一目标，Linux 基金会自 2011 年开始，每年都会启动 LiFT 奖学金计划，为有潜力的、热爱学习的开发人员、系统管理员、开源新手提供培训机会，让更多人了解开源、参与开源。![](../Images/ce5e66eecc97513f56bfc7213dcd0e4e.png)自 2011 年以来，Linux 基金会已经颁发了 600 多个培训奖学金，价值数百万美元。2020 年，国际参与奖学金计划的申请达到 1155 个。本年度最受欢迎的奖学金类别是 **Open Source Newbies**，其次是 **SysAdmin SuperStars** 和 **Women in Open Source**。目前，Linux 基金会培训的奖学金计划国际部分的征集和评选都已经圆满结束了，每位获奖者对开源的兴趣和热爱都令人印象深刻。比如，刚毕业的大学生 Isabel，是一位初入开源的新人，她不仅自学用 Python 创建了一个开源的洪水预测项目，同时还对改善公共教育充满热情，她希望通过开发开源软件，为所有受限于教育资源的人，增加学习的机会。  
![](../Images/3a49d048f66ce49cc488471ff29db3eb.png)还有很多像 Isabel 一样的人，积极加入开源，得到帮助，并希望能够通过自己的力量帮助别人。了解更多获奖者的开源故事，点击这里。近些年来，随着中国的开源力量不断发展壮大，2020 年秋，Linux 基金会的奖学金计划也将在中国正式启动！欢迎中国大陆及港澳台地区的朋友们积极参与。秋季是中国学生们新学年的开始，也是收获的季节。Linux Foundation 开源软件大学的人才激励计划始于 Linux 基金会奖学金计划，同样致力于为 IT 行业的人才提供顶尖的开源培训机会，扩大开源社区内技术的多样性，希望所有对开源感兴趣的人都能通过此计划有所收获。![](../Images/d368092c84b132daca9586a9b448ec5e.png)Linux Foundation 开源软件大学是 Linux 基金会中国区培训官网，是 Linux 基金会亚太区与开源中国强强联手、共同打造的技术交流平台，核心理念是为中国培养更多的开源软件人才，不断推动国际技术交流和人才交流。基于这个理念，Linux Foundation 开源软件大学人才激励计划申请人，可以来自任何行业，从事任何工作，不管你是否有技术背景，是否了解过开源，只要填写表单，表现出对技术的热情和开源的兴趣，就有机会入选。每个入选者可以从 Linux 基金会开源软件大学中选择**任一个课程学习**，所有类别的入选者在完成培训课程后，还可以**免费参加 Linux 基金会提供的任何认证考试**，费用全部由 Linux 基金会开源软件大学承担。   Linux基金会开源软件大学为**大学生、职场萌新、女性开源力量、开源技术人才、开源社区明星、开源志愿者、开源爱好者、开源小白**这8种类别的人才提供免费的学习和考试机会。点击这里进入申请页面，了解更多。为了提高大家参与的积极性，人才激励计划的入选者除了获得免费的课程学习与认证考试机会外，还有机会实现一个与开源有关的心愿，比如参加一次开源大会、获得开源项目的曝光机会、上一堂自己感兴趣的技术公开课等等，只要与开源相关，我们都会尽力满足。开源人才激励计划为每个对开源感兴趣的人打开了一扇窗，参与进来，你就有机会获得最权威的培训，深入了解开源世界，Linux基金会开源软件大学将在开源之路上与大家一路同行，共同成长。
