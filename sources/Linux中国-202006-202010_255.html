早在 2017 年，我就写过为什么 D 语言是开发的绝佳选择的文章。但是 D 语言中有一个出色的功能我没有充分的展开介绍：通用函数调用语法(Universal Function Call Syntax)（UFCS）。UFCS 是 D 语言中的一种语法糖，它可以在类型（字符串、数字、布尔值等）上链接任何常规函数，就像该类型的成员函数一样。

如果你尚未安装 D 语言，请安装 D 语言编译器，以便你可以自己运行 D 代码。

看一下以下示例代码：

  1. // file: ufcs_demo.d
  3. module ufcs_demo;
  5. import std.stdio : writeln;
  7. int[] evenNumbers(int[] numbers)
  8. {
  9.     import std.array : array;
  10.     import std.algorithm : filter;
  12.     return numbers.filter!(n => n % 2 == 0).array;
  13. }
  15. void main()
  16. {
  17.     writeln(evenNumbers([1, 2, 3, 4]));
  18. }

使用你喜欢的 D 语言编译器进行编译，查看这个简单示例应用做了什么：

  1. $ dmd ufcs_demo.d
  2. $ ./ufcs_demo
  3. [2, 4]

但是，使用作为 D 语言的内置功能的 UFCS ，你还可以自然方式编写代码：

  1. ...
  2. writeln([1, 2, 3, 4].evenNumbers());
  3. ...

或完全删除现在多余的括号，使 evenNumbers 看起来像是一个属性：

  1. ...
  2. writeln([1, 2, 3, 4].evenNumbers); // prints 2, 4
  3. ...

因此，完整的代码现在变为：

  1. // file: ufcs_demo.d
  3. module ufcs_demo;
  5. import std.stdio : writeln;
  7. int[] evenNumbers(int[] numbers)
  8. {
  9.     import std.array : array;
  10.     import std.algorithm : filter;
  12.     return numbers.filter!(n => n % 2 == 0).array;
  13. }
  15. void main()
  16. {
  17.     writeln([1, 2, 3, 4].evenNumbers);
  18. }

使用你最喜欢的 D 语言编译器进行编译，然后尝试一下。如预期的那样，它产生相同的输出：

  1. $ dmd ufcs_demo.d
  2. $ ./ufcs_demo
  3. [2, 4]

在编译过程中，编译器自动地将数组作为函数的第一个参数。这是一个常规模式，使得使用 D 语言成为一种乐趣，因此，它与你自然而然考虑代码的感觉非常相似。结果就是函数式编程。

你可能会猜出这打印的是什么：

  1. //file: cool.d
  2. import std.stdio : writeln;
  3. import std.uni : asLowerCase, asCapitalized;
  5. void main()
  6. {
  7.     string mySentence = "D IS COOL";
  8.     writeln(mySentence.asLowerCase.asCapitalized);
  9. }

确认一下：

  1. $ dmd cool.d
  2. $ ./cool
  3. D is cool

结合其他 D 语言的功能，UFCS 使你能够编写可重用的代码，并在不牺牲便利性的情况下自然地进行编写。

是时候尝试 D 语言了

就像我之前写的那样，D 语言是一种很棒的开发语言。从 D 语言的下载页面可以很容易地进行安装，因此请下载编译器，查看示例，并亲自体验 D 语言。
