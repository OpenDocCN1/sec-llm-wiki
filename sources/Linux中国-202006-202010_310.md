软件定义一切，而开源正在“吞噬”软件。

使用开源技术，如同站在巨人的肩膀之上，既免于重复造轮子，又能基于此不断创新。而开源技术能够在全球范围内快速推广，并被越来越多的企业、组织所应用，离不开 Linux 基金会这样的开源组织。

在全球范围内，每年都会召开多场开源技术峰会，广大的开源组织、IT巨头、行业领域、技术大咖和开源技术爱好者汇聚一堂，共同见证开源领域的新技术、新应用和新趋势。 

![](../Images/b88e548cc155633da4989c468989d5d5.png)

疫情突袭，在 CNCF 和全球开源志愿者共同努力下，“Cloud Native + Open Source Virtual Summit China 2020 中国线上峰会”将于 2020 年 7 月 30 日 - 8 月 1 日隆重召开。

作为开源界最负盛名的旗舰会议，本届线上 KubeCon 2020 迎来众多重磅级开源大咖，下面就请跟随笔者的视角，一起来了解下他们的风采吧！

![](../Images/85c31f007897c2296ad0eef06e979e42.png "Jim Zemlin - Linux 基金会执行董事")

*Jim Zemlin - Linux 基金会执行董事*

作为 Linux 基金会执行董事，Jim Zemlin 每年都会来到中国积极地宣传、推广开源技术，他在 Linux 基金会的丰富工作经历，使得他对技术行业保有全球视野和独到的见解。Jim 对开源有着深刻的理解，在本届开源峰会中，他将带来哪些最新洞察，特别值得期待。

![](../Images/e6e9a6b623f185958ff9322c31fcc377.png "Dan Kohn - Linux 基金会公共卫生总经理")

*Dan Kohn - Linux 基金会公共卫生总经理*

作为 Linux 基金会的核心基础架构计划（CII）的重要创始成员，Dan Kohn 带来的主题分享是《躲在黑暗中》，他将带来哪些前沿观点和新鲜视角，尤其在疫情在全球爆发的当下，云原生能够带来哪些帮助，值得深思。

![](../Images/14002fcf6d6293a8a9ccb921a209cfae.png "Priyanka Sharma - CNCF 总经理")

*Priyanka Sharma - CNCF 总经理*

Priyanka Sharma 是 CNCF 新任总经理，本次线上 KubeCon 2020 将是她的中国“首秀”。Priyanka 参与过多个 CNCF 项目，如 Jaeger 和 Vitess。她认为，走向 DevOps、走向云原生、走向 Kubernetes 是大势所趋，并将持续产生影响。

![](../Images/8cc43f096fd9e7922faac5e9fba4e79b.png "Cheryl Hung - CNCF 生态系统总监")

*Cheryl Hung - CNCF 生态系统总监* 

作为 CNCF 生态系统总监，Cheryl Hung 的任务是通过发展社区和为最终用户宣传来增加 Kubernetes 和 Cloud Native 的采用率。 

在本次线上开源峰会中，Priyanka Sharma 将携手 Cheryl Hung 发表联合主题演讲，两位女性开源代表会带来哪些新鲜观点，将成为本届峰会一道亮丽的风景线。

![](../Images/309f2cc5d055396e40b0aee088229de4.png "Vulk Coop - Owner/Senior Factotum")

*Vulk Coop - Owner/Senior Factotum*

Vulk Coop 是开源倡导者，自 1994 年起就使用 Unix 1.0 版本和 GNU Tools，致力于改进用户使用体验，包括协作、应用程序、开发工具、API 等，Vulk Coop 将联手 Dan Kohn 带来《介绍：BoF 电信用户组》主题分享。

![](../Images/f7467aa0070b47e5729c2a32017d87f4.png "Erin Boyd - 红帽高级首席工程师")

*Erin Boyd - 红帽高级首席工程师*

Erin Boyd 是 Kubernetes 项目贡献者和 Apache Ambari 提交人，也是 CNCF SIG 存储项目的积极贡献者，并担任 CNCF SIG 存储联席主席。Erin 关注如何在无状态、混合、多云环境中启用存储。

![](../Images/aba14e93ba5e3e9657b0bab183ff7e27.png "Alex Chircop - StorageOS CEO")

*Alex Chircop - StorageOS CEO*

Alex Chircop 是 StorageOS 的创始人和首席执行官，同时也是 CNCF SIG 存储的联席主席。在本次云原生大会上，Alex 将携手 Erin 带来有关云原生存储的介绍。

![](../Images/8efac712bad936969167fa283fd80af8.png "Mitch Connors - 谷歌软件工程师")

*Mitch Connors - 谷歌软件工程师*

在过去 15 年中，Mitch Connors 曾在 F5 和 Amazon 等企业工作，这使得他对软件开发人员的需求有了一个全面的认识。Mitch热衷将技术创新带给开发者，他将带来的分享是《单体已经死了，单体万岁！》。

![](../Images/8e3b2d52c20d8c99d21cca3669448258.png "Kiran Mova - MayaData 首席架构师、共同创始人")

*Kiran Mova - MayaData 首席架构师、共同创始人*

Kiran Mova 宣传开源文化和开源执行模型，是 OpenEBS-CNCF 项目的主要创始人、维护者和贡献者。在本届线上峰会中， Kiran 带来的主题分享是《介绍+深入了解：OpenEBS 存储引擎》。

![](../Images/167e71ac052fe804832192e040f05961.png "Ricardo Aravena - Rakuten SRE 经理")

*Ricardo Aravena - Rakuten SRE 经理* 

Ricardo Aravena 是 CNCF SIG-Runtime 和 Kata Containers 项目贡献者之一，在过去 20 多年的工作经历中，Ricardo 曾在 Cisco 和 VMware 等公司担任要职。在本次云原生大会中，他带来的分享是《介绍：CNCF SIG-Runtime》。

除此之外，还有来自 VMware、Datewire、Splunk、EIotl、IBM、Sysdig、American Express、SUSE、Styra、Upbound、NYU、LINBIT、Dynatrace、Aqua Security 等科技企业的开源大咖，将在三天的大会中带来精彩的技术分享。持续关注 KubeCon 2020 大会官网「cncf.lfasiallc.cn」，更多国外开源大咖陆续更新中…… 

“Cloud Native + Open Source Virtual Summit China 2020 中国线上峰会”官网免费注册通道现已开启，诚邀全球开源技术爱好者报名参会，共同聆听全球开源领袖带来的前沿技术与云原生最新应用。
