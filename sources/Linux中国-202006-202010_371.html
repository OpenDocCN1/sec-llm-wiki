由 CNCF 与全球开源志愿者共同发起的 “Cloud Native + Open Source Virtual Summit China 2020中国线上峰会”（KubeCon 2020），将于 2020 年 7 月 30 日 - 8 月 1 日隆重举办。

作为 CNCF 的旗舰会议，来自全球领先开源社区和云原生社区的使用者和技术大咖聚集于此，大会官网「cncf.lfasiallc.cn」已经上线，本次线上峰会门票免费，诚邀全球各地的开源精英报名参会，共同探索云原生的未来和方向。 

作为开源界最负盛名的旗舰峰会，自 2018 年 KubeCon+CloudNativeCon 首次落地中国以来，CNCF 每年都在中国举办云原生技术大会。大会每年都能吸引来自美国、日本、印度在内的五大洲 48 个国家的开源精英前来参会，相互交流、学习。

受疫情影响，Cloud Native + Open Source Virtual Summit China 2020 将首次于线上召开。大会吸引了全球众多 IT 巨头的加盟，包括华为、阿里巴巴、腾讯、微软、Google、IBM、百度、京东、ORACLE、VMware、网易、蚂蚁金服、美团、红帽、SUSE、TARS Foundation、LFAI、Linux Foundation 开源软件大学、易捷行云、EMQ、FUTUREWEI、青云QingCloud、虚云科技等科技企业及其技术专家带来的有关云原生最新应用和干货分享。 

首届云原生在线峰会将重点围绕云原生和微服务等时下热门技术领域展开，涵盖应用程序+开发、服务网络、无服务、定制+扩展、CI/CD、机器学习+数据、存储、安全+身份+策略等重大议题，以洞察云原生未来的发展趋势，为广大的开源精英答疑解惑。 

首届在线版 KubeCon 大会，在为期 3 天的时间里，为所有的参会嘉宾带来近 100 个与云原生相关的技术干货分享，诚邀全球各地的开源组织、企业、技术专家及开源爱好者报名参会，共同探索云原生的未来和方向。 

此外，大会特地增设「云端展厅」，与会嘉宾在倾听全球开源技术大咖带来精彩分享的同时，还能云端“逛展”，一览全球 IT 巨头有关云原生的最新应用和最佳实践。 

本次大会仅对提前报名的参会嘉宾开放，还没报名的小伙伴儿要抓紧了，登录 Cloud Native + Open Source Virtual Summit China 2020 大会官网「cncf.lfasiallc.cn」，提前锁定这场开源界最负盛名的旗舰会议，共同开启云原生下一个十年。
