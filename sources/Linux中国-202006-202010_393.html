在 Linux 中有很多永远循环（或直到你决定停止）的方法，你可以在命令行或脚本中执行此操作。

for 和 while 命令使这件事非常容易。关于相应的语法和策略，只有几件事要牢记。

使用 while

最简单的永远循环之一是使用 while 命令，后面跟上条件 true。你不必使用诸如 while [ 1 -eq 1 ] 之类的逻辑或类似的测试。 while true 测试表示循环将一直运行，直到你使用 CTRL-C 停止循环、关闭终端窗口或注销为止。这是一个例子：

  1. $ while true
  2. > do
  3. >   echo Keep running
  4. >   sleep 3
  5. > done
  6. Keep running
  7. Keep running
  8. Keep running
  9. ^C

你也可以使用 while : 做同样的事情。这里的关键是 : 总是返回成功，因此就像 while true 一样，此测试永远不会失败，并且循环会继续运行：

  1. $ while :
  2. > do
  3. >   echo Keep running
  4. >   sleep 3
  5. > done
  6. Keep running
  7. Keep running
  8. ^C

如果你在脚本中插入了无限循环，并想提醒使用它的人如何退出脚本，那么可以使用 echo 命令添加提示：

  1. while :
  2. do
  3.         echo Keep running
  4.         echo "Press CTRL+C to exit"
  5.         sleep 1
  6. done

使用 for

for 命令还提供了一种永远循环的简便方法。虽然不如 while true 明显，但语法相当简单。你只需要在有界循环中替换参数即可，它通常类似于 “c 从等于 1 开始递增，直到 5”：

  1. $ for (( c=1; c<=5; c++ ))

不指定任何参数的情况下：

  1. $ for (( ; ; ))

没有起始值、增量或退出测试，此循环将永远运行或被强制停止：

  1. $ for (( ; ; ))
  2. > do
  3. >    echo Keep running
  4. >   echo “Press CTRL+C to exit”
  5. >    sleep 2
  6. > done
  7. Keep your spirits up
  8. Keep your spirits up
  9. Keep your spirits up

为什么要永远循环？

在现实中，你不会想永远循环下去，但一直运行直到想要回家、工作完成或者遇到问题才退出并不罕见。任何构造为无限循环的循环都可以设置为根据各种情况退出。

该脚本将一直处理数据直到下午 5 点，或者说检查发现第一次超过 5 点的时间：

  1. #!/bin/bash
  3. while true
  4. do
  5.   if [ `date +%H` -ge 17 ]; then
  6.     exit        # exit script
  7.   fi
  8.   echo keep running
  9.   ~/bin/process_data     # do some work
  10. done

如果要退出循环而不是退出脚本，请使用 break 命令而不是 exit。

  1. #!/bin/bash
  3. while true
  4. do
  5.   if [ `date +%H` -ge 17 ]; then
  6.     break       # exit loop
  7.   fi
  8.   echo keep running
  9.   ~/bin/process_data
  10. done
  11. … run other commands here …

总结

永远循环很容易。指定要停止循环的条件却需要花费一些额外的精力。
