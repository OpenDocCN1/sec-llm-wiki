Linux App Summit（LAS）由国际两大主流自由软件桌面环境 GNOME 和 KDE 联合主办，旨在通过将所有参与创建优秀 Linux 应用程序用户体验的开发者聚集在一起，加速 Linux 应用程序生态的增长。LAS 已备受全球开源爱好者的关注。

麒麟团队已连续两年受邀参加 LAS 峰会并发表主题演讲，优麒麟对应用生态及开源社区所做出的贡献受到了国际开源大咖的一致认可，UKUI 桌面环境产生了进一步的全球影响力。此外，优麒麟社区作为 LAS 的社区合作伙伴，也与 KDE 和 Gnome 社区组织一起积极推动 Linux 应用生态发展。

2021年，由于受全球疫情的影响，Linux App Summit 2021（LAS）计划在5月以线上交流的形式呈现，目前 LAS 面向全球开发爱好者的参与通道已经开启。对于中国开发爱好者来说是一次难得与全球开发爱好者分享经验进行学习交流的机会，优麒麟社区希望感兴趣的优客积极报名参加。
