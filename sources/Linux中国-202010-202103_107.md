列表类型

LaTeX 中的列表是封闭的环境，列表中的每个项目可以取一行文字到一个完整的段落。在 LaTeX 中有三种列表类型：

◈ `itemize`：无序列表(unordered list)/项目符号列表(bullet list)◈ `enumerate`：有序列表(ordered list)◈ `description`：描述列表(descriptive list)![](../Images/c053fb20aeef1fc64fe49611010812bb.png)

创建列表

要创建一个列表，需要在每个项目前加上控制序列 `\item`，并在项目清单前后分别加上控制序列 `\begin{<类型>}` 和 `\end`{<类型>}`（将其中的`<类型>` 替换为将要使用的列表类型），如下例：

![](../Images/c053fb20aeef1fc64fe49611010812bb.png)

itemize（无序列表）

```
1.  `\begin{itemize}`
2.  `    \item Fedora`
3.  `    \item Fedora Spin`
4.  `    \item Fedora Silverblue`
5.  `\end{itemize}`
```

![](../Images/77b61210703b6f84e2c6671b2fd2ae63.png)

![](../Images/c053fb20aeef1fc64fe49611010812bb.png)

enumerate（有序列表）

```
1.  `\begin{enumerate}`
2.  `    \item Fedora CoreOS`
3.  `    \item Fedora Silverblue`
4.  `    \item Fedora Spin`
5.  `\end{enumerate}`
```

![](../Images/d94c33728d01f5342fcc9eda82912eea.png)

![](../Images/c053fb20aeef1fc64fe49611010812bb.png)

description（描述列表）

```
1.  `\begin{description}`
2.  `    \item[Fedora 6] Code name Zod`
3.  `    \item[Fedora 8] Code name Werewolf`
4.  `\end{description}`
```

![](../Images/27c0b6c0f49e5ee56d949e85845bfd4e.png)

![](../Images/c053fb20aeef1fc64fe49611010812bb.png)

列表项目间距

可以通过在导言区加入 `\usepackage{enumitem}` 来自定义默认的间距，宏包 `enumitem` 启用了选项 `noitemsep` 和控制序列 `\itemsep`，可以在列表中使用它们，如下例所示：

![](../Images/c053fb20aeef1fc64fe49611010812bb.png)

使用选项 noitemsep

将选项 `noitemsep` 封闭在方括号内，并同下文所示放在控制序列 `\begin` 之后，该选项将移除默认的间距。

```
1.  `\begin{itemize}[noitemsep]`
2.  `    \item Fedora`
3.  `    \item Fedora Spin`
4.  `    \item Fedora Silverblue`
5.  `\end{itemize}`
```

![](../Images/3caae40b3c9f222edb696825c62fb155.png)

![](../Images/c053fb20aeef1fc64fe49611010812bb.png)

使用控制序列 \\itemsep

控制序列 `\itemsep` 必须以一个数字作为后缀，用以表示列表项目之间应该有多少空间。

```
1.  `\begin{itemize} \itemsep0.75pt`
2.  `    \item Fedora Silverblue`
3.  `    \item Fedora CoreOS`
4.  `\end{itemize}`
```

![](../Images/dd7087396227166bfa7762b855f14e18.png)

![](../Images/c053fb20aeef1fc64fe49611010812bb.png)

嵌套列表

LaTeX 最多最多支持四层嵌套列表，如下例：

![](../Images/c053fb20aeef1fc64fe49611010812bb.png)

嵌套无序列表

```
1.  `\begin{itemize}[noitemsep]`
2.  `    \item Fedora Versions`
3.  `    \begin{itemize}`
4.  `        \item Fedora 8`
5.  `        \item Fedora 9`
6.  `        \begin{itemize}`
7.  `            \item Werewolf`
8.  `            \item Sulphur`
9.  `            \begin{itemize}`
10.  `                \item 2007-05-31`
11.  `                \item 2008-05-13`
12.  `            \end{itemize}`
13.  `        \end{itemize}`
14.  `    \end{itemize}`
15.  `    \item Fedora Spin`
16.  `    \item Fedora Silverblue`
17.  `\end{itemize}`
```

设置列表样式

下面的例子列举了无序列表的不同样式。

```
1.  `% 无序列表样式`
2.  `\begin{itemize}`
3.  `    \item[$\ast$] Asterisk`
4.  `    \item[$\diamond$] Diamond`
5.  `    \item[$\circ$] Circle`
6.  `    \item[$\cdot$] Period`
7.  `    \item[$\bullet$] Bullet (default)`
8.  `    \item[--] Dash`
9.  `    \item[$-$] Another dash`
10.  `\end{itemize}`
```

![](../Images/85f94621a90126d10f622244eda76687.png)

有三种设置列表样式的方式，下面将按照优先级从高到低的顺序分别举例。

![](../Images/c053fb20aeef1fc64fe49611010812bb.png)

方式一：为各项目单独设置

将需要的样式名称封闭在方括号内，并放在控制序列 `\item` 之后，如下例：

```
1.  `% 方式一`
2.  `\begin{itemize}`
3.  `    \item[$\ast$] Asterisk`
4.  `    \item[$\diamond$] Diamond`
5.  `    \item[$\circ$] Circle`
6.  `    \item[$\cdot$] period`
7.  `    \item[$\bullet$] Bullet (default)`
8.  `    \item[--] Dash`
9.  `    \item[$-$] Another dash`
10.  `\end{itemize}`
```

![](../Images/c053fb20aeef1fc64fe49611010812bb.png)

方式二：为整个列表设置

将需要的样式名称以 `label=` 前缀并封闭在方括号内，放在控制序列 `\begin` 之后，如下例：

```
1.  `% 方式二`
2.  `\begin{enumerate}[label=\Alph*.]`
3.  `    \item Fedora 32`
4.  `    \item Fedora 31`
5.  `    \item Fedora 30`
6.  `\end{enumerate}`
```

![](../Images/c053fb20aeef1fc64fe49611010812bb.png)

方式三：为整个文档设置

该方式将改变整个文档的默认样式。使用 `\renewcommand` 来设置项目标签的值，下例分别为四个嵌套深度的项目标签设置了不同的样式。

```
1.  `% 方式三`
2.  `\renewcommand{\labelitemi}{$\ast$}`
3.  `\renewcommand{\labelitemii}{$\diamond$}`
4.  `\renewcommand{\labelitemiii}{$\bullet$}`
5.  `\renewcommand{\labelitemiv}{$-$}`
```

![](../Images/c053fb20aeef1fc64fe49611010812bb.png)

总结

LaTeX 支持三种列表，而每种列表的风格和间距都是可以自定义的。在以后的文章中，我们将解释更多的 LaTeX 元素。
