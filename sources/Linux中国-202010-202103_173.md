Flash 停止工作影响大连铁路的新闻已传到国外

![](../Images/f94ef25a77112a46b7478b889b18ba59.png)

前段时间，Flash 终于划上了句号，各个主要浏览器都禁用或取消了 Flash 插件的使用。根据一份数据，目前仍有大约 2% 的网站在使用 Flash。不过，这个统计应该只包括了运行在互联网上的网站，而在企业内部网络上可能还有更多的 Flash 在使用，因此，波及面可能要更广泛。

令人稀奇的是，铁路也会受到 Flash 停止工作的影响。据大连铁路自己报道，大连铁路的部分系统内也使用了 Flash，因此，在 Flash 停止工作的当天，这些系统也纷纷陷入瘫痪。这件事最魔幻的还不是居然没有任何人想起来在 Flash 停止工作前进行升级改造，而是花了二十多个小时采用了 Ghost 的操作系统（盗版？）来降级解决 Flash 停止工作的问题，从而继续使用！事后，大连铁路还就此发了一篇表扬稿，结果被网友们群嘲。

现在，这个笑话已经传播到国外。真是让人汗颜。

pip 停止支持 Python 2

![](../Images/beca752432c54b8509169d21f294f617.png)

经过几年的宣传和迁移之后，Python 2 已于 2020 年结束了支持，在 2020 年 4 月时，Python 社区发布了 Python 2 的最后一个版本，社区最终选择了一个特殊的版本号 2.7.18 来告别 Python 2，这个版本号近似于自然常数 e。

而作为 Python 的软件包管理器，pip 在刚刚发布 pip 21.0 中，也正式停止了对 Python 2 的支持。也就是说，如果你还在因为某些原因使用 Python 2，那你还是继续使用 pip 20 就好了。

Python 社区对 Python 2 的放弃终于缓缓拉上了帷幕，不过继续使用 Python 2 的人也有各自的不得已。

尽管遭受到了 SolarWinds 网络攻击，但微软的 Azure 业务反而可能会受益

![](../Images/dc92afbbd34a2a050a6dd8dffce1bf34.png)

我们前段时间报道过 SolarWinds 入侵事件，包括微软在内的各大 IT 公司也纷纷中招，其中传闻微软还被窃取了 Windows 10 的源代码。不过按微软的说法，Windows 的安全体系并不依赖于源代码的保密，所以微软评估对客户的影响不大。因此，网络安全社区也并没有对微软有多少指责。

不过，令人有些意想不到的是，由于 SolarWinds 这样的事件波及面很广，很多企业纷纷感觉将数据和业务放在云服务上是个更好的选择，因此，分析师认为，微软 Azure、AWS 等云服务商的业务会因此而增长。

我觉得，虽然云服务商这些年来也屡屡出现大型服务故障，但是相对于企业本身的投入和相应的风险，最终企业会越来越多的选择云服务。可以说，上云已经是普遍趋势了。
