银河麒麟操作系统宣称其已达国内最高安全等级

麒麟软件 日前发文宣称，“银河麒麟操作系统已经通过并达到国内最高安全等级” —— GB/T 20272 等保四级。该标准是评测国内操作系统安全等级资格的标准。麒麟软件称，“自 2009 年第一次通过安全等级测评开始，银河麒麟到目前已经大满贯地通过了 —— 5 次，始终位列国产操作系统的最高安全等级。……成为最高等级已达十年”。

硬核老王点评：其它的 Linux 发行版，你们还好吗？

AWS 宣布创建 Elasticsearch 和 Kibana 分支

据 solidot 报道，继上周 Elasticsearch 和 Kibana 宣布更改许可证，旨在禁止 AWS 等云服务商使用它的软件作为一种服务提供给客户之后， AWS 宣布它将创建和维护 Elasticsearch 和 Kibana 的一个“真正开源”的分支，继续使用 Apache 2.0 许可证，而且它在 Elasticsearch 上的所有改进都递交到上游。

硬核老王点评：Elasticsearch 和 MongoDB 为什么改许可证你心里没数吗？早知今日何必当初。

Linux 现已完全可以在 Mac mini M1 上使用

据 twitter 消息，Corellium 公司的 CTO 称，已经可以从 USB 启动一个完整的 Ubuntu 桌面了。网络是通过 USB 盘支持的。稍后会将修改推送到 GitHub上，并发布教程。
