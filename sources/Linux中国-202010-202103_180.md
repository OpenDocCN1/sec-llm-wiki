银河麒麟操作系统宣称其已达国内最高安全等级

![](../Images/b9d7359bca39cacb53d993db1a7ba375.png)

[麒麟软件](https://mp.weixin.qq.com/s?__biz=MzAwMjYyMDc3MQ==&mid=2649538519&idx=1&sn=7efb6ebbd0c7e087107d0faada75c9b1&scene=21#wechat_redirect "https://mp.weixin.qq.com/s?__biz=MzAwMjYyMDc3MQ==&mid=2649538519&idx=1&sn=7efb6ebbd0c7e087107d0faada75c9b1&scene=21#wechat_redirect") 日前发文宣称，“银河麒麟操作系统已经通过并达到国内最高安全等级” —— GB/T 20272 等保四级。该标准是评测国内操作系统安全等级资格的标准。麒麟软件称，“自 2009 年第一次通过安全等级测评开始，银河麒麟到目前已经大满贯地通过了 —— 5 次，始终位列国产操作系统的最高安全等级。……成为最高等级已达十年”。

AWS 宣布创建 Elasticsearch 和 Kibana 分支

![](../Images/68de68de60f00e4d4e57d78d22e88bb6.png)

据 solidot 报道，继上周 Elasticsearch 和 Kibana 宣布更改许可证，旨在禁止 AWS 等云服务商使用它的软件作为一种服务提供给客户之后， AWS 宣布它将创建和维护 Elasticsearch 和 Kibana 的一个“真正开源”的分支，继续使用 Apache 2.0 许可证，而且它在 Elasticsearch 上的所有改进都递交到上游。

Linux 现已完全可以在 Mac mini M1 上使用

![](../Images/74d1500d76e40620a24116036d4e3fef.png)

据 twitter 消息，Corellium 公司的 CTO 称，已经可以从 USB 启动一个完整的 Ubuntu 桌面了。网络是通过 USB 盘支持的。稍后会将修改推送到 GitHub上，并发布教程。
