One centOS 倒下了，Ten centOS 起来了

据 腾讯工程技术 称，“TencentOS Server，是腾讯针对云场景研发的 Linux 操作系统。……使用免费，安装量已超过 500 万，用户可持续获得腾讯 OS 团队的更新维护和技术支持。TencentOS Server 包含腾讯 OS 团队自研的 TencentOS 内核……包含 TencentOS Server 2 和 TencentOS Server 3 两个版本，用户态分别基于 RHEL 7 和 RHEL 8 定制研发而成。”

硬核老王点评：让我数数，有几个云厂商推出了自己的 CentOS 替代版本了？

红帽宣布面向 16 个系统以下的小型生产环境免费提供 RHEL

据 cnbeta 报道，红帽宣布扩大了开发者计划，现在个人的 RHEL 开发者订阅支持 16 个系统以内的生产环境。此前，该计划只允许以“开发”为目的免费访问 RHEL，但现在可以在该 16 个系统限制以内的生产环境中使用。虽然并不算特别慷慨，但这至少可以安抚那些目前在少量服务器上运行 CentOS 8 用于生产目的的企业。

硬核老王点评：亡羊补牢是不是有用呢？

多个 Linux 发行版考虑移除 Chromium 软件包

据 solidot 报道，Google 称，他们在最近的审计中发现部分基于 Chromium 的浏览器使用了原本只给 Google 使用的 Google API 和服务，其中最主要的是同步账号的 Chrome Sync API，它决定移除这些 API 的访问，声称这是为了改进用户数据安全。Linux 发行版开发者表示过去十年他们一直这么做的，如果无法使用 Google 的同步功能，那么继续维护 Chromium 软件包也没有什么价值了。Chrome 的工程总监在回复中表示他们的决定不会改变。Slackware Linux 和 Arch Linux 都表示考虑从仓库移除 Chromium。
