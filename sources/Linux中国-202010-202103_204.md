Linus 破例在 Linux 5.11 内核中允许英伟达显卡驱动加塞

![](../Images/70080a20f7134143a448796fe0d296e9.png)

据 cnbeta 报道，曾因闭源驱动对英伟达爆粗口的 Linus Torvalds，刚刚宣布了 Linux 5.11 内核版本的一项重要变动。按照计划，Linux 5.11 稳定版内核将于 2021 年 2 月份到来，且开发团队通常不会在合并窗口结束后注入新的功能代码。不过在本周末的 Linux 5.11 - rc4 候选发布版本到来前，Linus Torvalds 很高兴地宣布将为 Linux 5.11 内核添加对英伟达 RTX 30 系列 Ampere GPU 的驱动支持。作为在合并窗口之后的一次罕见代码添加，这部分内容是完全独立的，且不会对现有的 Nouveau 驱动支持造成影响和相关风险。

> 硬核老王点评：在挨骂这么多年之后，英伟达终于有所转变了，Linus 也破例马上接受这些驱动。

![](../Images/e5ed455d9098211a3f72311aa2ad15b6.png)

Windows 应用的兼容层 Wine 6.0 正式版发布

![](../Images/662f38e2a14d807cc7acb30fbe6f04b6.png)

据 solidot 报道，该版本代表了一年的开发努力和超过 8300 个变化。它包含了大量的改进，主要变化的方面是：核心模块用 PE 格式构建；实现了一个实验性的 WineD3D 的 Vulkan 渲染器；支持 DirectShow 和 Media Foundation；重新实现了文本主控台等等。

> 硬核老王点评：Wine 对 Linux 非常重要，尤其是国内某些对 Linux 不友好的厂商的一些应用，都需要 Wine 才能运行。

![](../Images/e5ed455d9098211a3f72311aa2ad15b6.png)

Ubuntu 21.04 中准备修复一个十多年的 BUG

![](../Images/bac58c2ca2224cc09d80e9dffd7b7d88.png)

据 cnbeta 报道，和很多其他发行版本不同，Ubuntu 默认创建的用户主目录包含多个世界可写权限。该 BUG 早在 2006 年就已经被提交，现在终于被 Ubuntu 安全技术负责人标记为已修复。最初在 2006 年有人认为，世界可写主目录能够让 Ubuntu 在多用户环境中更加方便，因为它使多个用户在共享桌面上共享文件变得更加容易。但 Ubuntu 目前在公共云和服务器领域拥有大量的客户和用户群，这种权限在当今的互联环境中可能会带来灾难。

> 硬核老王点评：为了方便而放弃的安全措施，这事要是在 Debian ，我觉得不会发生。还好终于在十多年后意识到了错误。
