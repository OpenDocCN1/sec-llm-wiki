监控 docker 容器镜像

```
1.  `root@linuxtechi ~}$ docker ps -a`
2.  `CONTAINER ID        IMAGE                 COMMAND             CREATED             STATUS   PORTS                             NAMES`
3.  `9ab9aa72f015        ubuntu                "/bin/bash"         14 seconds ago      Exited (0) 12 seconds ago                  suspicious_shannon`
4.  `305369d3b2bb        centos                "/bin/bash"         24 seconds ago      Exited (0) 22 seconds ago                  admiring_mestorf`
5.  `9a669f3dc4f6        portainer/portainer   "/portainer"        7 minutes ago       Up 7 minutes   0.0.0.0:9000->9000/tcp      trusting_keller`
```

包括 `portainer`（docker 容器镜像），所有已退出和当前正在运行的 docker 镜像都会显示出来。下面的 Portainer GUI 屏幕截图显示了相同的情况。

![](../Images/c0ea3dbb86d60620590c346423b081a2.png)

![](../Images/60a9c23361d974ba0551f4eb75843fc7.png)

监视事件

单击 portainer 网页中的“Events”选项，如下所示。

基于 docker 容器活动生成和创建的各种事件将被提取并显示在此页面中.

![](../Images/bc203272f50e71882ce8bdc22626672e.png)

*Container-Events-Poratiner-GUI*

现在检查并验证“Events”部分是如何工作的。创建一个新的 docker 容器镜像 `redis`，如下所述，在 docker 命令行检查状态：`docker ps –a`：

```
1.  `root@linuxtechi ~}$ docker ps -a`
2.  `CONTAINER ID        IMAGE                 COMMAND                  CREATED              STATUS         PORTS                    NAMES`
3.  `cdbfbef59c31        redis                 "docker-entrypoint.s…"   About a minute ago   Up About a minute         6379/tcp                 angry_varahamihira`
4.  `9ab9aa72f015        ubuntu                "/bin/bash"              10 minutes ago       Exited (0) 10 minutes ago                            suspicious_shannon`
5.  `305369d3b2bb        centos                "/bin/bash"              11 minutes ago       Exited (0) 11 minutes ago                            admiring_mestorf`
6.  `9a669f3dc4f6        portainer/portainer   "/portainer"             17 minutes ago       Up 17 minutes         0.0.0.0:9000->9000/tcp   trusting_keller`
```

单击顶部的“Event List”刷新事件列表，

主机状态

Portainer 中的仪表板

到目前为止，我们已经在“Local”部分看到了基于 portainer 的各种特性。现在跳到所选 Docker 容器镜像的“Dashboard”部分。

在 Portainer 的网页中单击“EndPoint”选项时，会出现以下窗口：

![](../Images/23a07ed4d681a00161acf398aae6b65c.png)

*End\_Point\_Settings*

对于主机容器镜像，此仪表板有许多状态和选项。

![](../Images/60a9c23361d974ba0551f4eb75843fc7.png)

Stacks

单击此选项可提供任何堆栈（如果有的话）的状态。因为这里没有堆栈，所以显示为零。

![](../Images/60a9c23361d974ba0551f4eb75843fc7.png)

Images

单击此选项可提供主机中可用的容器镜像。此选项将显示所有活动和退出的容器镜像。

![](../Images/cfa2defd44afed45d386f713bccf0da5.png)

*Docker-Container-Images-Portainer*

例如，再创建一个“Nginx”容器并刷新此列表以查看更新：

```
1.  `root@linuxtechi ~}$  sudo docker run nginx`
2.  `Unable to find image 'nginx:latest' locally`
3.  `latest: Pulling from library/nginx`
4.  `27833a3ba0a5: Pull complete`
5.  `ea005e36e544: Pull complete`
6.  `d172c7f0578d: Pull complete`
7.  `Digest: sha256:e71b1bf4281f25533cf15e6e5f9be4dac74d2328152edf7ecde23abc54e16c1c`
8.  `Status: Downloaded newer image for nginx:latest`
```

下面是刷新后的镜像界面：

![](../Images/cbb309a7edd751f6635322dcf027dbe7.png)

*Nginx\_Image\_creation*

当 Nginx 镜像处于 `stopped`/`killed` 状态时，docker 的容器镜像会改变为 `unused` 状态。

注：你可以看到这里所有的镜像的细节都非常清楚，比如内存使用，创建日期和时间。与命令行选项相比，从这里维护和监视容器将非常容易。

![](../Images/60a9c23361d974ba0551f4eb75843fc7.png)

Networks

此选项用于网络操作。例如分配 IP 地址、创建子网、提供 IP 地址范围、访问控制（管理员和普通用户）。下面的窗口提供了各种可能选项的详细信息。根据你的需要，可以进一步去自行研究这些选项。

![](../Images/09d3b658f9177836217b8f7fd2ea9de7.png)

*Conatiner-Network-Portainer*

输入所有各种网络参数后，单击“create network”按钮即可创建网络。

![](../Images/60a9c23361d974ba0551f4eb75843fc7.png)

Container

此选项将提供容器状态。此列表将提供有关活动的和未运行的容器状态的详细信息。此输出类似于 docker ps 命令选项。

![](../Images/74357579010fc334fb3bee2873ead72a.png)

*Containers-Status-Portainer*

在该窗口中，通过选中复选框并选择上述按钮可以根据需要控制容器停止和启动。一个例子如下：

例如，“CentOS”和“Ubuntu”容器都处于停止状态，现在可以通过选中复选框并点击“Start”按钮来启动它们。

![](../Images/f270d0f135e9fa26d9454b6997b5049e.png)

*start\_containers1*

*start\_containers2*

Portainer 中的设置选项

到目前为止，我们已经在“Local”部分看到了基于 portainer 的各种特性。现在跳到所选 Docker 容器图像的“Settings”部分。

在 Portainer 的网页中单击“Settings”选项时，可以使用以下的配置选项：

![](../Images/60a9c23361d974ba0551f4eb75843fc7.png)

Extensions

这是一个简单的 Portainer CE 订阅程序。详细信息和用途可以从附加的窗口中看到。这主要用于维护相应版本的许可证和订阅。

![](../Images/36ff40a3bc1de7424878ef5b8533006d.png)

*Extensions*

![](../Images/60a9c23361d974ba0551f4eb75843fc7.png)

Users

在本例中输入你的想好的用户名比如“shashi”和你选择的密码，然后点击下面的“Create User”按钮。

Endpoints

此选项用于端点终端管理。终端可以添加和删除，如附加窗口中所示。

Registries

此选项用于注册管理。由于 docker hub 有各种镜像的注册，因此此功能可用于类似的目的。

Settings

此选项用于设置以下各种选项，

◈ 设置快照间隔◈ 设置自定义徽标◈ 创建外部模板◈ 安全功能，如：为非管理员禁用和启用 bin 挂载，为非管理员禁用/启用权限，启用主机管理功能

下面的屏幕截图显示了出于演示目的启用和禁用的一些选项。一旦全部完成点击“保存设置”按钮保存所有这些选项。
