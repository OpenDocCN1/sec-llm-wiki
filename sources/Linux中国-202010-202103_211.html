程序员手握 2.2 亿美元就是想不起密码

据 凤凰网 报道，托马斯是一名在德国出生，目前居住在旧金山的程序员，他还剩下两次机会来猜测一个密码。截至本周，这个密码价值大约 2.2 亿美元。这个密码能够让解锁一个小型加密硬盘 IronKey，里面包含一个有 7200 个比特币的数字钱包的私人密钥。IronKey 硬盘给用户提供了 10 次密码尝试机会，全部尝试失败后将锁定硬盘，永久性对内容加密。他已经尝试了自己最常用的 8 种密码组合，但是都失败了。托马斯说，“我就躺在床上想密码，然后用新想出的密码到电脑上尝试，但是不管用，我就再次陷入绝望。”

忘记密码的不只有托马斯。洛杉矶企业家亚萨尔称，这些年来，他花费了数百小时来尝试重新打开数字钱包，里面包含了他在比特币发展初期开采的数千枚比特币。他已经把包含比特币的硬盘放在了真空袋中，眼不见心不烦。“我不想每天都被提醒：我现在的财富只是我本可以拥有财富的零头。”亚萨尔称。

Flash Player 中国特供版开始推送

据 快科技 报道，12 日 Adobe 正式结束了 Flash 的生命周期之后，重橙网络官方微博宣布，今天中国特供版的 Flash Player 已经更新。根据重橙网络此前发布的公告，由于技术支持原因，本次及后续更新版本的 Flash Player 在 Windows 7 以下（不包含 Windows 7）、Linux、Mac 操作系统中不再支持视频格式内容的播放功能，其他原有功能可正常使用。

硬核老王点评：这种“特殊待遇”真是让人心情复杂。

微软的大部分官方服务都已经迁移到 Azure 云端

据 cnbeta 报道，五年前，微软的大部分核心服务都没有迁移到 Azure 云上；五年后的今天，该公司宣布包括 Office 365、Xbox Live 和 Bing 等所有微软官方服务即将全部在 Azure 上运行。早在 10 年前，微软就承诺将 Office 365 迁移到 Azure。目前 Microsoft 365 的大部分服务都运行在 Azure 基础设施上。Exchange Online 和 Outlook.com 的邮箱存储也正在向标准的 Azure 基础设施转移。

硬核老王点评：那些早些年觉得云计算只是个笑话的人，想不到如今云计算已经吞噬了整个互联网了吧。
