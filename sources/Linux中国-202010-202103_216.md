Linux 内核开发人员考虑剔除对更多老旧平台的处理器支持

![](../Images/dd8c9243966521600993a22df848bd00.png)

据 cnbeta 报道，随着 Linux 5.10 走入长期支持（LTS），内核开发人员也对未来五年的平台支持展开了探讨，比如剔除干线内核项目中的大量旧款 CPU 的支持。包括 ARM 在内的缺乏生命迹象的老旧 CPU 架构，都可能在未来的 Linux 主线内核版本中被抛弃。

> 硬核老王点评：正如我之前评论的，确实，目前 Linux 内核内不缺驱动，是时候放下这些过时的包袱了。

维基百科诞生二十年

![](../Images/e27956f4ef1aa8546ba48a6bd9875208.png)

据 solidot 报道，维基百科将在 1 月 15 日迎来它的二十岁生日。它是有史以来规模最庞大、阅读量最多的百科全书。维基百科包含了数百种语言撰写的 5500 多万篇文章，每一篇都由志愿者编写。根据 Alexa 网站排名，它是全世界第 13 大受欢迎的网站。维基百科是一个不同寻常的地方，它没有股东，没有产生亿万富翁，没有广告。

> 硬核老王点评：这么有价值的一个乌托邦项目，可惜太难访问了。

![](../Images/fa8d1ce56e0e42258daf81f180440288.png)

Linux 版 Firefox 84 已默认为部分用户开启硬件加速功能

![](../Images/bf614e7899ace6600b4a2b4348f51324.png)

据 cnbeta 报道，适用于 Linux 的 Firefox 84 版本可谓是该浏览器发展历程中的一个重要里程碑，因为它默认为部分 Linux 用户开放了硬件加速功能。Firefox 84.0 已经为 Gnome/X.org 提供了 WebRender（后台支持硬件加速），而在后续的 85.0 版本中还会添加对 Gnome/Wayland 的支持。

> 硬核老王点评：Linux 上桌面性能不佳，这个锅终究还是驱动的。
