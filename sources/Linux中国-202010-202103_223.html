微软押注 Windows 10X 对抗 Chrome OS

据 cnbeta 报道，Windows 10X 基于 Windows Core OS，这是一个新的模块化版本的 Windows 10。通过这个新的操作系统，微软将放弃各种传统组件，如控制面板或 Windows 文件资源管理器，从而让这个系统更加的轻巧，并且更容易更新。微软的目标是消除一切能让 Windows 10 PC 使用起来繁琐的东西，并摆脱谷歌多年前在 Chromebook 的优秀广告中所强调的所有烦恼。

硬核老王点评：微软的 Windows 10X 或许有一定的市场空间，不过谷歌在 10 年前就发布了第一款 Chromebook，有明显的先发优势，微软能否成功仍是未知数。

加密挖矿僵尸网络现在正在窃取 Docker 和 AWS 凭证

据 zdnet 报道，据判该僵尸网络与一个名为 TeamTNT 的网络犯罪组织有关，该组织在 2020 年夏天首次被发现在错误配置的容器平台上安装加密货币挖矿恶意软件。TeamTNT 是第一个实现了专门收集和窃取 AWS 凭证功能的加密挖矿僵尸网络。趋势科技研究人员表示，自去年夏天首次被发现以来，TeamTNT 组织的恶意软件代码已经得到了相当大的更新。现在，TeamTNT 在窃取 AWS 凭证的代码基础上，还增加了一个收集 Docker API 凭证的功能。

硬核老王点评：随着加密货币的持续火爆，这种利用僵尸网络来挖矿的滥用行为将会更多。

联想宣布了新的 ARM 笔记本

据 softpedia 报道，联想希望成为首批带来运行在 ARM 上的新设备的公司之一，近日联想宣布了新的 IdeaPad 5G 笔记本电脑。它采用了 2018 年高通骁龙 8cx 处理器，并不是最新一代的芯片。这款笔记本电脑支持 5G 和 4G LTE，采用了无风扇设计，提供了长达 20 小时的续航时间，搭载了 Windows 10 操作系统。这款 5G 笔记本现在还没有发布日期和价格。

硬核老王点评：苹果的 ARM 笔记本发布之后，业界对 ARM 的热情更加高涨，只是不知道为什么会采用这么老的芯片。
