无线网络联盟宣布了 20 年来的最重大的一次升级：Wi-Fi 6E

![](../Images/a5665467f6d52a284d98afd24addc9be.png)

据 cnbeta 报道，当前市售的许多无线路由器，已支持 2.4GHz 和 5GHz 的双频 Wi-Fi 应用。不过即将上市的 Wi-Fi 6E 产品进一步拓展了 1/3 的 6GHz 频段，使得可用无线信道提升到了四倍。Wi-Fi 6E 之所以能够迎来如此重大的升级，得益于可用于消费电子设备的无线频段的巨大扩展。

> 硬核老王点评：基础设施的进步，才是这个世界进步的引擎。

![](../Images/ac3217621142729471ca3b010f2b1f6c.png)

红帽宣布收购容器安全初创企业 StackRox

![](../Images/da5fe6e91794edf11bcf73ceb5c0fadf.png)

据 cnbeta 报道，2018 年的时候，IBM 以 340 亿美元的高价收购了红帽，并积极向混合云战略转型。最新消息是，红帽于近日宣布了收购容器安全初创企业 StackRox，以推动 IBM 的多云/混合云环境下的业务发展。红帽指出，本次收购很适合并入该公司的 OpenShift 解决方案。与此同时，StackRox 将继续为包括亚马逊 AWS、微软 Azure、以及谷歌云等在内的其它平台提供支持。

> 硬核老王点评：尽管以企业级 Linux 产品和服务而被人们所熟知，但红帽近年来也在努力向云端迁移。

![](../Images/ac3217621142729471ca3b010f2b1f6c.png)

红帽 OpenShift 同时支持 Windows 和 Linux 容器

![](../Images/d3b7cdeb3a510ed281d2deaecf34745d.png)

如今，在 Azure 上运行的 Linux 虚拟机和容器比 Windows 服务器上的虚拟机的数量要多得多。但是，用一个界面管理 Linux 和 Windows 容器并不是那么容易。现在，红帽公司通过 OpenShift 使 Kubernetes 管理这两种工作成为可能。你将能够协调红帽企业 Linux 和 Windows 作为应用程序的构建块运行，并支持 .NET Core 应用程序、.NET Framework 应用程序和其他 Windows 应用程序。

> 硬核老王点评：Linux 和 Windows 终将会融合起来，不论是桌面环境，还是底层应用。
