红旗 Linux 桌面操作系统 V11 社区预览版发布

据 快科技 报道，红旗 Linux 桌面操作系统 V11 将于 1 月 10 日开放预览版的下载，新版本具有良好的硬件兼容，支持多款国产自主 CPU 品牌，同时还具有丰富的外设支持及海量的易用生态软件，打造全新的 UI 设计风格，带来更灵动的视觉效果和便捷的操作体验。红旗 Linux 桌面操作系统 V11 基于 debian 10.6 开发，内核版本 4.19。

硬核老王点评：原来红旗 Linux 还在继续前进啊。

错误配置的 Git 仓库导致日产北美公司的源代码被泄露

据 zdnet 报道，日产北美公司在运行 Bitbucket Git 服务器时，使用了默认凭证 admin/admin，其开发和使用的移动应用和内部工具的源代码被泄露。日产公司已经承认了该事件，并称在调查之中。无独有偶，瑞士研究人员在 2020 年 5 月发现了一个类似配置错误的 GitLab 服务器，泄露了奔驰各种应用和工具的源代码。

硬核老王点评：不要使用默认凭证！不过从另外一个方面看，软件发行时，为什么会提供及其简单的默认用户名和密码呢？为什么不能采用一种机制在软件安装时强制要求设置符合标准的密码呢？

微软 Edge 浏览器已有 6 亿客户使用，谷歌 Chrome 浏览器仍遥遥领先

据 softpedia 报道，微软在一则招聘广告中说“随着 Edge 的普遍使用，已经覆盖了 6 亿客户”，微软正在利用这则广告寻找一名新的首席软件工程师来从事浏览器的工作。目前还不清楚微软所说的客户是指实际用户还是已经安装了该应用的设备。

硬核老王点评：不能不说微软将 Edge 浏览器内核换成 Chromium 引擎是一个妙招，让它也可以运行在非 Windows 平台。
