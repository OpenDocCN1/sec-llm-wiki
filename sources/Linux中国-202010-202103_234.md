使用 JavaScript 编写的 Windows 95 能在多个平台运行

![](../Images/8fc86cdab094cea9d05dceb09d64b29f.png)

据 cnbeta 报道，Slack 的开发者 Felix Rieseberg 两年前以 Electron 应用的方式发布了 Windows 95 系统，它是完全使用 JavaScript 编写的。在随后不断的更新中使其能够运行《毁灭战士》等经典游戏。现在他又推出了新版本，能够让这个 Windows 95 Electron 在 Windows、macOS 和 Linux 上运行。

> 硬核老王点评：无所不能的 JavaScript，居然把当年的经典操作系统复现出来了。

![](../Images/26752aaf38fcfee907055a1e7bdadc45.png)

LibreSSL 难以取代 OpenSSL

![](../Images/6a5eb1c356aa819ed2115dbf6d20ad15.png)

据 solidot 报道，由于 SSL 基础设施软件中存在的缺陷引来了业界震动。这促使了 Linux 基金会发起了 CII 倡议，资助关键基础组件的开发和维护。而 OpenBSD 项目创建了 OpenSSL 分支 LibreSSL。该分支之后被 OpenBSD 发行版使用并活跃开发至今。然而，Linux 世界并不买账，OpenSSL 得到了更大程度的支持，让 OpenSSL 项目解决了它的许多长期问题，它更安全也更稳定了。

结果是很少有 Linux 发行版迁移到 LibreSSL。Alpine 和 Gentoo 发行版尝试提供 LibreSSL，其中 Alpine 很快就返回到了 OpenSSL；而 Gentoo 对 LibreSSL 的支持将在今年 2 月结束。Gentoo 开发者指出，LibreSSL 相比 OpenSSL 并没有提供多少好处，反而增加了更多成本。

> 硬核老王点评：这个结果令人错愕，残缺而陈旧的软件居然能焕发新生，胜过新的继承者，可见软件惯性有多大。

美监管机构考虑允许联邦特许银行发行和推广稳定币

![](../Images/0b9e7b8a591ed653f1f8f8a7296768d5.png)

据 cnbeta 报道，美国货币监理办公室在一封解释函中称，联邦特许银行和储蓄协会可考虑借助公共区块链和稳定币开展结算业务。这意味着，只要遵循现有的法律，银行就可自行选择利用公共区块链来验证、存储、记录和结算。或者运行自己的加密节点，并将关联的稳定币用于获得许可的支付活动。

> 硬核老王点评：看来美国的银行业也坐不住了。
