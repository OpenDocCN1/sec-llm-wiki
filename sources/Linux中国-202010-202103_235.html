知名品牌发现投放的几亿互联网广告费没什么用

据 solidot 报道，当宝洁公司停止投放 2 亿美元的互联网广告，该公司没发现业务结果有变化。当大通银行将广告展示从 40 万个网站减少到 5 千个网站，它没发现业务结果有变化。当 Uber 放弃 1.2 亿美元推广应用安装的广告开支，它没有发现应用安装率有变化。而早在 2012 年当 eBay 停止投放搜索广告，它也没有观察到业务结果有变化。营销人员可以花更少的钱获得相同的结果；或者更聪明的花钱获得更好的结果。数字广告和点击的大数据并没能转化成更多的商务活动和销售。

拍一拍：所以，互联网广告经济的基础从一开始就不存在吗？

Google 雇员宣布工会组建计划

据 solidot 报道，Google 雇员宣布与美国通讯业工人组织组建工会。该工会将对所有 Alphabet 雇员和合同工开放，其目标是解决正在发生的问题，如工资差距、报复，以及受争议的政府合同。组织者表示，“工会是建立在 Google 雇员多年的勇敢组织的基础之上，从对抗实名政策，到反对 Project Maven、抗议给性骚扰的高管数百万美元奖金，我们亲眼看到了集体行动时 Alphabet 的反应。”

拍一拍：这个工会的成立可能会限制高管的权力，同时也会在整个硅谷引发类似的举动。到目前为止，硅谷公司基本上没有成立工会。

微软计划对 Windows 进行一次“全面的视觉年轻化”

据 slashdot 报道，在微软最近发布的一则招聘启事中，微软对该职位的描述中提及，“以协调和提供一个全面的视觉年轻化的 Windows 体验，向我们的客户发出 Windows is BACK 的信号，并确保 Windows 被认为是给客户的最好的操作系统体验。”微软后来悄悄地删除了对这个“全面的视觉年轻化”的提及。

拍一拍：无论开源和云计算有多么耀眼，微软始终没有忘记其立身之本是操作系统。
