# 用 Linux 让旧 MacBook 重获新生 | Linux 中国

最近，我偶然找到了一台 2011 年底的老款 13 英寸 MacBook Pro，有 125GB SSD 和 8GB 内存。我曾带着这台机器去世界各地旅行，当年，我开了很多场会议、研讨会或演示，分享 JBoss 技术带来的各种 AppDev 优势。

在验证了它的电池能用，充了电，重新安装了一个新的 OS X 之后，我发现 Safari 浏览器的版本受限于旧的安全规范，这意味着它现在无法连接到很多 HTTPS 网站。这就使得这个解决方案失效了。

这个老伙计该怎么处理呢？

自从我作为开发人员专门在 Linux 工作站上工作以来已经有几年了。我只使用 Fedora，所以我决定尝试在这台 MacBook Pro 上安装它的最新版本。

我只花了一个多小时就用下面的步骤让 Fedora 33 在这台笔记本上工作了。

![](../Images/d6f802dd7f26ce51046ab541c849a5db.png)

下载 Fedora 33 并创建一个临场 USB

第一步是找到正确的安装 Fedora 的方法。这台机器有一个 CD 插槽，所以可以刻录一个 ISO 并从它启动，但我选择直接使用可启动的 USB 方式。

我登上了另一台 MacBook，访问了 Fedora Workstation 网站，它有 Fedora Media Writer 的链接。点击你的机器类型的图标（在我的例子中是苹果标志），你会得到一个安装包。

![](../Images/06fbd00d6c2bd021bab5d5778e6b42ad.png "Fedora Media Writer download screen")

*Fedora Media Writer 下载界面*

开始安装，可以看到一个引导你完成安装过程的图形用户界面（GUI）。选择 Fedora Workstation 33 选项。

![](../Images/adb28dc377ae80e81bf00499f19ef88a.png "Fedora Workstation download in Fedora Media Writer")

*在 Fedora Media Writer 中下载 Fedora Workstation*

接下来，选择右上角的“Create Live USB”选项。

![](../Images/efa991c104c9a8388408a328e314a280.png "Create Live USB button")

*创建 Live USB 的按钮*

镜像将开始下载，你将看到一个下拉菜单来选择安装位置。

![](../Images/3e23d30e209041f3782b862943623eb3.png "Downloading Fedora Workstation")

*下载 Fedora Workstation*

插入一个有足够空间的 U 盘，下载完成后，就可以选择它并在上面安装镜像。完成后，关闭 GUI，取出 U 盘。

![](../Images/d6f802dd7f26ce51046ab541c849a5db.png)

安装 Linux

将你创建的 U 盘插入 MacBook Pro 左侧的端口，并按住 `Cmd` 键左侧的 `Option`（或 `Alt`）键的同时重新启动。这将打开一个启动机器的选项菜单：使用 EFI 选项，因为那是 USB 镜像。

笔记本电脑将从 USB 设备启动，你可以按照正常的 Fedora 安装过程进行。如果你能将 MacBook Pro 插入网线连接，会有帮助，因为它的 Broadcom WiFi 设备无法开箱即用。

![](../Images/348f1d599dcb8c96eea0b834c19125ac.png "MacBook Pro")

*MacBook Pro*

你现在也可以将 Fedora 安装到你的硬盘上，并将它永久地放在你的机器上。

![](../Images/3be6bb622700357967dccd802c234dee.png "Installing Fedora on MacBook Pro")

*在 MacBook Pro 上安装 Fedora*

一旦安装程序完成，重新启动机器，Fedora 33 现在应该是启动选项。

![](../Images/c38d27723bf6a9e9fc49a4e9a43aa93b.png "MacBook Pro booting into Fedora")

*MacBook Pro 启动到 Fedora*

唯一缺少的就是 WiFi 驱动，所以要保持网线连接，安装你正在运行的内核的开发包，并为该内核构建 `broadcom-wl` 驱动。

验证你需要用于 WiFi 的卡。

```
1.  `$ lspci -vnn -d 14e4:`
```

在输出中会有几项，包括如下内容：

```
1.  `Network controller [0280]: Broadcom Inc. and subsidiaries....`
2.  
3.  `Subsystem: Apple Inc. AirPort Extreme...`
```

安装一个仓库来拉取 Broadcom 相关的部分：

```
1.  `$ su -c 'dnf install -y http://download1.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm'`
```

接下来的部分很有趣：如果你查看正在运行的内核时，你会看到 `v5.9.8-200.fc33`，但是你要使用开发内核包来构建你的 Broadcom 无线驱动。所以，你需要安装 `v5.8.15-301.fc33`（在写这篇文章的时候可用）。使用 `uname -r` 检查它们，并使用 `sudo dnf list kernel` 列出已安装的内核包：

```
1.  `$ sudo dnf list kernel`
2.  `kernel.x86_64                     5.8.15-301.fc33`
3.  `kernel.x86_64                     5.9.8-200.fc33`
```

安装开发包：

```
1.  `$ sudo dnf install -y akmods kernel-devel-5.8.15-301.fc33`
```

![](../Images/011287b2f4394304706ff0fd71fdc427.png "Installing development packages")

*安装开发包*

安装 Broadcom 无线软件包：

```
1.  `$ sudo dnf install -y broadcom-wl`
```

构建内核模块：

```
1.  `$ sudo akmods`
```

![](../Images/6599abbdac46f795801769ef34525166.png "Building the kernel module")

*构建内核模块*

重新启动你的机器，你应该可以看到无线驱动（`wl`）。

```
1.  `$ lsmod | grep wl`
```

在 Fedora 中设置你的无线连接：

![](../Images/1a57d9971b0d60f7d9949cb066ba5ca3.png "Set up wireless connection")

*设置无线连接*
