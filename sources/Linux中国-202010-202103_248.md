Windows XP 终究成为了过去，Windows 7 成为用户不想放弃的不支持的操作系统

![](../Images/dbd31c436597a3a99e3e53aafe760d52.png)

据 softpedia 报道，Windows XP 是一款超级成功的操作系统，这一点毋庸置疑，尽管微软在 2014 年 4 月放弃了它，但用户仍然不准备放弃它。一些用户采取了安全措施，而另一些用户则在这方面什么都没做，所以他们的电脑依然容易受到潜在的攻击。在正式消亡 6 年多后，它的市场份额已经跌破 1%，很多仍在运行 Windows XP 的设备不再连接到互联网。但坏消息是，Windows 7 现在取代了 Windows XP 的位置，成为用户不想放弃的不支持的操作系统。

> 拍一拍：不能不说，微软做操作系统真的很成功，被废弃的多年前操作系统仍旧在某个角落悄悄的运行着。

![](../Images/d6f802dd7f26ce51046ab541c849a5db.png)

新蠕虫病毒会把 Windows、Linux 服务器变成门罗币矿机

![](../Images/810c89dbc5a2f4666334824137f0d58f.png)

据 cnbeta 报道，自 12 月初以来，一种新发现的、基于 Golang 的自我传播的恶意软件一直在 Windows 和 Linux 服务器上主动运行 XMRig 加密货币矿机程序，以在受感染的设备上偷偷挖掘加密货币门罗币。它可以通过用弱密码强行使用面向公众的服务（如 MySQL、Tomcat、Jenkins 和 WebLogic 等）传播到其他系统。

> 拍一拍：所有内部服务都应限制登录条件，并使用多因素认证。

![](../Images/d6f802dd7f26ce51046ab541c849a5db.png)

Microsoft Word/Google Docs 转换问题导致众议员错过诉讼文档提交时限

![](../Images/d3594242825dfe2249d0955c921ff6a6.png)

据 cnbeta 报道，现任美国总统唐纳德·特朗普的第二个任期已经化为泡影，但他和他的幕僚与共和党人士还是觉得能抢救一下。美国众议员原本计划在联邦法院提起诉讼，但因诉讼文档提交时间过晚而受挫。他们称在准备过程中，遇到了 Google Docs 和 Microsoft Word 之间软件版本出现多次技术上的不兼容，导致编辑困难和文字表达出现问题，因此委托律师请求法庭允许原告晚一小时提交法律文本。

> 拍一拍：看看，文档的兼容从未如此重要过，都影响到一个超级大国的政治和世界局势了。
