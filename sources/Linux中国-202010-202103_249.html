程序员开发抢茅台脚本，两天刷榜 GitHub 后谢幕

据 快科技 报道，据说 1499 元的飞天茅台转手就能赚上千元。各大电商平台为了提高人气，时不时也会来一批原价 1499 元的飞天茅台让网友抢购，大家都要拼手速、网速。有人开发了 Python 脚本号称要让大家跟黄牛站在一个起跑线上。这个脚本的主要功能是自动登录电商平台 -> 定时自动预约茅台 -> 定时开始自动抢购。脚本发布之后，迅速在 GitHub 上火爆，30-31 日这两天内就斩获 4000 多星好评。不过吗，该脚本昨天清空了，下架的原因不清楚，作者只留下了“see you later”一句话。

拍一拍：虽然不知道为什么被清空，不过估计不会被开除吧。

MIPS 架构厂商日渐式微，Linux 报告其漏洞遭遇困难

据 cnbeta 报道，昨天 Linux 内核提供了 MIPS 体系架构的一系列漏洞补丁，补丁开发者杨嘉勋承认了 MIPS 的悲哀现状：“由于如今大部分 MIPS 的 CPU 厂商都已经消亡，这让我们无法和他们确认漏洞状态，所以我们会默认将漏洞显示为‘未知’，并在 cpu-probe.c 中进行覆盖。”

拍一拍：我觉得 Linux 内核太对旧硬件“恋恋不舍”了，应该考虑将这些人群稀少、年份久远的硬件相关的部分放到一个陈旧分支里面，逐步放弃支持。

SolarWinds 黑客访问了微软源代码

据 solidot 报道，上个月微软披露在其系统中发现了与 SolarWinds 黑客攻击有关的恶意软件。微软现在公布了最新的调查结果：它探测到了部分内部账号的可疑活动，其中一个账号访问了其源代码，这个账号并没有修改源代码的权限，它也没有发现任何代码被修改。

拍一拍：还好只是被“看”了一眼。不过这一波 SolarWinds 事件看来还没完，美国网络安全和基础设施安全局表示，所有仍在运行 SolarWinds Orion 平台的美国政府机构，必须在年底前更新到最新的 2020.2.1HF2 版本。
