你的汽车可能会记录更多的数据，而你却不知道

![](../Images/e72e0812902b29d39e8d38f0f1ec81e2.png)

据 theverge 报道，来自车辆的信息已被用来破案，以及用于更邪恶的目的。你的车，取决于它有多新，有什么功能，可能会在你不知情的情况下收集各种数据，包括位置数据、车门何时被打开，甚至是你的声音记录。

> 拍一拍：汽车数据安全是一个尚未被大众注意到的数据泄露漏洞。

科技日报评选出“2020 年国际十大科技新闻”

![](../Images/06257c533e08ff61b0fb4b317ab4f8bf.png)

据 科技日报 报道，27 日，由科技日报社主办、部分两院院士和媒体人士共同评选出的 2020 年国内、国际十大科技新闻揭晓。入选的 2020 年国际十大科技新闻分别是：全球加速新冠疫苗研发；目前最强逆转艾滋病病毒潜伏方法发现；科学家发现宇宙物质起源之谜首个佐证；迄今最大规模人类遗传变异体目录公布；马斯克发布可实际运作的脑机接口；室温超导在超高压下首次实现；快速射电暴在银河系内起源首次确定；“阿尔法折叠”精准预测蛋白质三维结构；“基因魔剪”首次治愈两种遗传性血液病；中国嫦娥五号“揽月”而归。

微软与 Parallels 合作将 Windows 10 带到 Apple Silicon

![](../Images/0989e925edd2689359745487a10f089d.png)

据 softpedia 报道，苹果在上个月推出了基于 ARM 的定制化 M1 芯片，现在开发社区正在不分昼夜地将他们的应用带到这个平台上。Parallels 也开始了自己的软件工作，应该是将 Windows 带入苹果硅的世界，不久前，该公司公布了第一个预览版构建，允许用户提前尝试整个事情。事实证明，Parallels 在苹果硅上运行 Windows 并不是孤军奋战，因为微软自己也帮助该公司做到了这一点。

> 拍一拍：看来微软对于 ARM 芯片的兴趣真是浓厚，或许这为微软的 Surface 支持更多 CPU 架构可以提前探路。
