发布 5 年多了：依然可以免费升级 Windows 10

![](../Images/73dd6bb23d802b44a60f32d589f297a4.png)

据 cnbeta 报道，2015 年微软曾承诺开放一年时间供正版 Win7/8/8.1 用户免费升级到 Win10，可随后大家发现了一些也许有意也许无心的漏洞，除了盗版系统可以洗白外，免费升级的口子在 2016 年 7 月之后依然留着，甚至直到现在还有效。

> 拍一拍：“一年免费升级”就是一套营销借口，这和微软之前有意放纵盗版流行是一个套路，这样做大 Win10 用户基数。

![](../Images/9bad18f6351dc8b99d0e4faef931f1f8.png)

Ruby 3.0.0 释出，性能提升 3 倍

![](../Images/0eba1acaab36a00c08fb305976f6a04a.png)

据 solidot 报道，Ruby 语言项目在圣诞节这天释出了一个大的更新版本 Ruby 3.0.0。新版本的一个重要目标是大幅提升性能，速度要达到上一个大版本 Ruby 2 的 3 倍。测试显示 Ruby 3 在 NES 游戏模拟工作负荷中的单线性能确实达到了 Ruby 2 的 3 倍。新版的变化包括改进了 MJIT 性能，实验性角色模型 Ractor，重新设计单行模式匹配，IRB 中粘贴长代码的速度是 Ruby 2 的 53 倍，等等。

> 拍一拍：Ruby 是一门非常有趣的语言，就是一直性能不是很好，而现在 PHP 的速度都在起飞，Ruby 3 的速度提升是一个很大的利好消息。

今年美国大选未出现政客电子邮件泄漏，很大程度归功于物理安全密钥

![](../Images/e80d6fed4c9d34e90aeda20a26744d41.png)

据 cnbeta 报道，今年美国总统选举期间并没有出现电子邮件泄漏事件，而这可能归功于小小的 USB 安全密钥。在过去四年里，有一件小事或者说一个习惯正逐渐养成。那就是政治家、竞选工作者、以及他们的家人和好友都开始使用 USB 硬件密钥来登录电子邮件账户和其他在线服务。而且谷歌为销售这些硬件提供了非常便捷的平台，可供用户挑选的产品也非常丰富，包括来自 GoTrust, TrustKey 和 Yubico 厂商的产品。

> 拍一拍：物理安全比密码安全更可靠，而现实需求才能推动安全措施需求。
