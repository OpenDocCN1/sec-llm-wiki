谷歌的多项服务 14 日出现全球性大规模宕机

据谷歌的服务状态页面显示，Google 绝大部分服务都在 12 月 14 日下午 7:55 左右报告发生了严重宕机事故，受影响的服务包括 Gmail、日历、文档、硬盘、Google Chat、Google Meet、Blogger，甚至还有 YouTube 等等。该故障历时约 1 小时，目前已恢复。据称是内部存储配额问题导致的事故。

在该故障发生后，微信朋友圈开始流传一张图，一本书《SRE:Google 运维解密》被丢到垃圾桶。而谷歌提出 SRE 理念就是为了提高运维可靠性。

来源：solidot

知名险资豪买 1 亿美元比特币，有望撬动 6000 亿美元需求

上周四，美国 169 年历史的万通互惠披露购买了价值 1 亿美元的比特币，成为最新一家涉足加密货币资产的主流公司。

摩根大通指出，这笔投资表明，对比特币的接纳正从家族办公室和富有的投资者蔓延到保险公司和养老基金等机构。摩根大通策略师称，如果美国、欧元区、英国和日本的保险公司和养老基金将 1% 的资产配置为比特币，这将导致对比特币的需求增加 6000 亿美元。根据 CoinMarketCap 的数据，比特币目前市值在 3500 亿美元左右。

来源：cnbeta

拍一拍：意图杀死中心化的比特，终将也成为巨头们的比特币。

新的 VS Code 更新带来了一系列的功能和 5242 个修复

微软新的 VS Code 1.52 是 2020 年的最后一个版本，直到明年 2 月初才会有另一个版本。这次发布的 VS Code 都是在节日季来临之际进行的“大扫除”。VS Code 团队指出，“在我们所有的 VS Code 仓库中，我们关闭了（分流或修复）5242 个问题，这甚至比我们在 2019 年 10 月的上一次大扫除迭代期间关闭的 4622 个问题还要多”。

在这个版本中，由社区驱动的功能更新包括一个带有文字换行的差异编辑器来显示代码的变化，一个排除哪些扩展在 VS Code 中造成问题的功能，更好的键盘快捷键，以及一个在管理器中撤销和重做文件操作的功能。

来源：zdnet

拍一拍：微软发力开源之后，这个软件巨头的动作真是令之前老牌的开源编辑器瞠目结舌。
