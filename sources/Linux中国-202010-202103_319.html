不满 CentOS 转向，联合创始人创建 Rocky Linux 新项目

前两天，CentOS 项目宣布，CentOS 8 将于 2021 年底结束，而红帽会将赞助投入到 CentOS 项目组去年发布的 CentOS Stream 上。原本的红帽企业版 Linux（RHEL）的下游发行版 CentOS 将不再有后继版本，而 CentOS Stream 和 CentOS Linux 不同，是一个滚动发行版，而且是作为 RHEL 的上游出现，换言之，CentOS Stream 是一个实验将要放入到 RHEL 特性的“测试版”

这引起了开源社区许多议论，很多 CentOS 用户表示了不满，甚至还发布了一个 centos.rip 网站来讽刺这件事。CentOS 的创始人 Gregory Kurtzer 也用行动表示了不满，发起了名为 Rocky Linux 的新项目，希望将 CentOS 延续下去。该项目在尚未上次任何实际代码之前，已经得到了 2000 多个星标。

14 年前发布的古董级赛扬单核 CPU 超频到了 8.4GHz

赛扬 D 347 是一款发布于 2006 年的单核处理器，现在早就被人遗忘了。但在超频玩家手中，这颗处理器是个宝，日前它又被超频到了 8.37GHz，相比 3.06GHz 的基础频率提升了 170% 多。创造这个纪录的玩家是中国超频玩家 ivanqu0208，他在华硕主板上将处理器的频率超到了 8362.21MHz，并通过了认证，在 Hwbot 上排名第二。

Cloudflare 和苹果等合作推出 ODoH 改进 DNS 隐私保护

为了保护用户隐私 IETF 标准化了两种协议 DNS over HTTPS（DoH）和 DNS over TLS（DoT）去加密 DNS。但 DoH/DoT 的推出也引发了两个问题，其一是 DNS 的中心化引入了单点故障，其二是解析器仍然可以将所有查询关联到客户 IP 地址。

为了更好的保护用户隐私，Cloudflare、Fastly 和苹果的工程师合作开发了新的协议 ODoH。ODoH 加入了一个公钥加密层以及客户端和 DoH 服务器之间的网络代理，确保只有用户才能访问 DNS 信息及其 IP 地址。Cloudflare 的公共 DNS 服务器 1.1.1.1 已经能支持 ODoH 查询。Firefox 已经表达了支持 ODoH 的意愿。

来源：solidot
