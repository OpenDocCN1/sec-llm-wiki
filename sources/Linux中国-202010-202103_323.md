谷歌允许外部贡献者参与到 Fuchsia OS 开发当中

![](../Images/d0c4162b2c8de0cfad776c39e81aaccd.png)

Fuchsia 是一个长期项目，旨在创建一个通用的、开源的操作系统。在公开开发了 Fuchsia 四年后，谷歌宣布扩大 Fuchsia 的开源模式，让公众更容易参与该项目。

目前看起来 Fuchsia 像是微内核模式，但不追求最小化，它有一个 POSIX API 的子集来帮助移植，并大量依赖异步通信来减少延迟。

然而，该操作系统远未完成。它已经支持一组有限的基于 x64 的硬件，你也可以用 Fuchsia 的模拟器进行测试。

安全公司 FireEye 被国家级黑客入侵

![](../Images/c9296b3e647d63102e52d959a6910dcf.png)

FireEye CEO 称，攻击者使用了非常新而且复杂的技术，窃取了公司红队使用的渗透测试工具。安全公司通常会有蓝队和红队，蓝队防御，红队进攻，而红队会开发出一些自己进攻用的测试工具，这次被窃取的就是这些工具。

FireEye 声称这些失窃的工具并非基于零日漏洞的利用，并已经在 GitHub 公开了检测出这些工具的特征，以用于防御这些工具的攻击。

来源：cnbeta

> 拍一拍：被窃取之后，就公布了相应的攻击拦截和识别特征，这样真的很好。

希捷发布全新 RISC-V 处理器，让机械硬盘性能暴涨 3 倍

![](../Images/98d6a140f1ff87eac0d2ef86a10b6e46.png)

硬盘巨头希捷公布了基于 RISC-V 架构设计的两款全新处理器，可加快数据中心和边缘的实时分析。其中一款支持开放标准的内核，旨在实现高性能，已在机械硬盘中完成了功能验证。与当前解决方案相比，新的高性能内核可将实时的、关键的硬盘工作负载性能提升高达 3 倍，另外还支持高级伺服算法，用于控制磁头在邻近磁道之间的移动，可实现更精细的定位。

来源：cnbeta

> 拍一拍：果然技术的进步永无止境啊，没想到机械硬盘的性能还能有这么大的提升。
