开源代码托管平台 GitHub 迎来了期待已久的深色模式

开源代码托管平台 GitHub 在本周宣布了一系列更新，不过最让熬夜写代码的开发者们感到欣喜的，莫过于期待已久的深色模式。官方表示，深色模式有助于缓解过亮的屏幕对用户造成刺激，以及为开发者提供跨文本编辑器、集成开发环境和终端的更加一致的体验。

来源：cnbeta

拍一拍：终于，都黑了，其中的绿色按钮最好看了~

Qt 6.0 正式发布

本次更新带来了 Quick 3D 和其它图形堆栈改进，围绕 Vulkan 和其它现代图形 API 的更多工作，用于额外库的软件包管理器，下一代 QML 支持、C++ 17、工具、以及主机 / 平台等改进。

并非所有 Qt5 模块都已被移植到了 Qt6 中，某些功能可能要等到 6.1 / 6.2 或更高版本才会引入，比如多媒体、蓝牙、虚拟键盘等。如果你希望获得更完整的体验，建议还是暂时停留在 Qt 5.15 版本，直到新版工具包的发布。

来源：cnbeta

惠普推出数据科学软件包

惠普今天为部分移动工作站和笔记本电脑提供了全新的 Ubuntu Linux 发行版本。这不仅仅只是在设备上预装了 Ubuntu 20.04 LTS OEM 版本，而且还预装了大量数据科学库、开发人员工具、Docker 容器支持以及其他功能。此外还包括 NVIDIA 的 RAPIDS 和 CUDA 组件，专有的驱动程序以及 TensorFlow，Keras，PyTorch 等通用机器学习库。

来源：cnbeta
