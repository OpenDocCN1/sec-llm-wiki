在 Azure 节点任务管理器上玩俄罗斯方块

销售 Linux 硬件十多年的 Linux PC 供应商 ZaReason 宣布关闭

![](../Images/0f12e659694d61ad1e2311cbc2d4df0f.png)

据外媒报道，ZaReason 是一家总部位于加州的笔记本电脑/台式机/服务器供应商，在长期经营并成为早期精品 Linux PC 供应商之后成为了 COVID-19 大流行的最新受害者。

他们不仅要在跟 System76、Purism、Tuxedo 电脑等日益激烈的竞争中竞争，同时还要面对更多直接来自联想和戴尔等公司的 Linux 预装设备。然而今年的新冠大流行成为了他们最后的战斗，他们被迫在 11 月底永久关门。

来源：cnbeta

> 拍一拍：有些可惜，不过现在的 PC 市场已经不同以往了，普通 PC 支持 Linux 支持也几乎不会遇到问题，因此，没有突破就难免倒下。

Richard Stallman 出席线上 EmacsConf 2020

![](../Images/5368ebb85cb66289fc0cbdd819117cb2.png)

今年的 EmacsConf 2020 是在线上举办的，是“关于 Emacs、Emacs Lisp 和记忆键序列的快乐会议”。67 岁的 Richard Stallman 出席了会议，他说，1976 年他“在 Guy Steele 的帮助下”创建了第一个 Emacs 编辑器，然后在 1984 年创建了 GNU Emacs。

在关于 GNU Emacs Lisp Package Archive（ELPA）历史的演讲之后，他回答一些问题，其中他被问到：

Q：你用的是GNU/Linux的哪个发行版，是 guix 还是其他？

RMS：Trisquel。

Q：如果你知道你明天会被公共汽车撞到，你会留下什么建议来管理 Emacs 和它的未来？

RMS：专注于保持社区的强大，以捍卫自由。如果可以选择让更多的人开发软件或捍卫软件，选择后者。小心地守护你的灵魂......😛

Q：你介意分享你的 Emacs 配置文件吗？

RMS：配置文件属于个人隐私，不会分享。

来源：slashdot
