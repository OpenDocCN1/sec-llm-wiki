用树莓派破解了特斯拉钥匙

![](../Images/e1b3c1647470c16382a3dd762ee566ad.png)

一位比利时博士生使用树莓派通过劫持蓝牙钥匙扣并重新编程的方式，成功夺取了一辆特斯拉 Model X SUV 的完全控制权。特斯拉此后发布了一个软件更新，以防止这种攻击。

由于攻击是通过蓝牙完成的，因此可以在 5 米外以无线方式获得控制权。这已经是他第三次“成功利用钥匙扣并获得汽车的使用权。此前他还能克隆出钥匙扣......”

来源：tomshardware

> 拍一拍：漏洞总是会有的，但是这其实反映出来新科技底下的各种不确定性。

AWS 雇佣 Rust 编译器团队负责人 Felix Klock

![](../Images/864aa373fa3c274f46e0be8bfc4c3965.png)

AWS 开源团队表达了对 Rust 语言的强烈兴趣。亚马逊开发者称他们越来越多的用 Rust 构建关键基础设施如 Firecracker VMM，因为它的开箱即用功能减少了满足公司高安全标准所需要的时间和精力，同时又能提供类似 C 和 C++ 的运行时性能。

AWS 对 Rust 语言是如此喜欢以至于它还赞助了该项目，甚至还开始雇佣了 Rust 和 Tokio 开发者确保他们拥有进一步改进 Rust 所需的时间和资源。

来源：solidot

17 年后，OS X 通知器应用 Growl 退役

![](../Images/c270feae224035aa47cff715ca5494bc.png)

Growl 是 OS X 的一个通知系统，从 2004 年就存在了。随着苹果新硬件平台的宣布，开发者普遍转向苹果的通知系统，以及缺乏明显的方法来改进 Growl，以超越它的现状和未来，因此，开发者们宣布 Growl 从今天开始退役。他们建议开发者们过渡离开 Growl。

来源：slashdot
