开发者在 M1 Mac 上成功虚拟化运行了 Arm 版本的 Windows

![](../Images/f4b4ebb418d6ffb8aaf372f965b14877.png)

这证明 M1 芯片能够运行微软的操作系统。开发者表示，当在 M1 Mac 上进行虚拟化时，“Windows ARM64 可以很好地运行 x86 应用程序。虽然没有 Rosetta 2 那么快，但也接近了”。

目前，采用 M1 芯片的 Mac 不支持 Windows，也没有像英特尔的 Mac 那样的 Boot Camp 功能，但支持 Windows 是很多用户希望看到的功能。

利用开源的 QEMU 虚拟机，开发者能够在苹果 M1 芯片上虚拟出 Arm 版本的 Windows，而且没有使用仿真。由于 M1 芯片是定制的 Arm SoC，因此无法再像之前基于英特尔的 Mac 那样，使用 Boot Camp 安装 x86 版 Windows 或 Windows 应用。

Perl 项目治理新规

![](../Images/99bed767ddf9365a2240cfaf906b79f5.png)

Perl 语言项目的新治理模式已接近成型。Python 项目的治理模式与 Python 项目采用的模式相似，将由两个实体参与治理：一个由几十人组成的核心团队，以及一个三人组成的指导委员会。核心团队制定规则，投票选出两个团队的成员，将实质性的决策权授予指导委员会。指导委员会有着广泛的权力，可以对语言、解释器和其它组件的开发做决定。

美国联邦通信委员会维持对飞行期间手机语音通话的禁令

该机构周五在一份四段式的命令中称，这个想法遭到了飞行员和空姐的强烈反对。美国联邦通信委员会（FCC）在 2013 年提议允许在 1 万英尺以上进行移动电话通话，采用欧洲和其他地方遵循的做法。

但这一提议立即引起了强烈的反击，旅客、空姐、国会议员和其他人士都表示，他们对乘客在飞行中用手机通话的想法![](../Images/ceabfe046dfbc353885a2f57f30a4216.png)感到不安。有一个团体提出，“如果乘客使用手机，有可能会引起空怒”。
