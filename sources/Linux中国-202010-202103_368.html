PHP 8.0 发布：支持 JIT 编译器，性能提升明显

PHP 8.0 引入了可选的 JIT 编译器，将现有的 JSON 支持集成到核心（不再是可选），并增加了对属性、联合类型，静态返回类型和其他附加语言的支持。

相比较 PHP 7.4 稳定版，PHP 8.0 在性能上大约改进了 10%。

验证码服务 hCaptcha 普及度达到 15%

提供区分机器人和人类检测服务的 hCaptcha 宣布它在整个互联网的普及度达到了 15%。超过了 Google 的 reCAPTCHA。Google 的商业模式是广告，收集用户数据日益引发了隐私方面的担忧。而 hCaptcha 不出售个人数据。

今年上半年，提供 CDN 安全防护服务的云服务商 Cloudflare 宣布从 reCAPTCHA 切换到了 hCaptcha。

来源：solidot

黑客勒索曼联：不给钱不让进系统

曼联俱乐部上周遭到了黑客攻击，黑客控制了俱乐部的计算机系统，导致工作人员无法接入网络。据称黑客要求得到数百万英镑。英国国家网络安全中心已经介入提供技术援助。但直到 26 日，曼联工作人员依然无法进入自己的工作邮件系统。
