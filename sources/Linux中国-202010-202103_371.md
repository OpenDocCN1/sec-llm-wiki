Windows 10 可能会在明年支持运行 Android 应用

![](../Images/1a0329b948d847d1f4d17bf7b50a608a.png)

人们普遍认为，应用上的劣势扼杀了 Windows Phone 生态系统。谈到优质应用的数量，微软的 Windows 10 桌面生态系统也不是那么好，而为了解决这个问题，微软正在研究一种解决方案，允许 Windows 10 用户直接运行 Android 应用。

来源：cnbeta

> 拍一拍：在 Linux 桌面上可以采用 Anbox 运行 Android 应用，但是也并未见到 Linux 桌面生态因此有太多改善。不知道微软此举会有多大用处。

AWS 中断致使一大块互联网瘫痪

![](../Images/167364e689ea69bb88e8dfea7488c5f0.png)

AWS 美东一区正在经历一场重大的故障，影响了其他一些 AWS 服务。而具有讽刺意味的是，这也影响了 AWS 服务健康仪表板。

亚马逊的互联网基础设施服务，是许多网站和应用程序的支柱，因此，AWS 的故障影响了大部分的互联网服务。

来源：theverge

> 拍一拍：原本是“互联”网，却越来越集中化，所以，近些年来，大型互联网基础设施出现问题导致大规模灾难事故的新闻屡见不鲜。

法国要求科技巨头缴纳数字税

![](../Images/13309f0fdaaa1df32a82568d8f1c923f.png)

法国税务当局推出一项新的数字服务税，并开始要求美国科技巨头缴纳巨额税款。这一新的税项激怒了美国。法国官员、公司高管和顾问表示，最近，Facebook 和亚马逊等公司都收到了法国有关部门要求缴纳 2020 年税款的通知，另外还有多家公司接到了通知。

华盛顿方面表示，征收数字服务税是一种不公平的贸易做法，因为它在很大程度上影响的是美国企业。

来源：solidot

> 拍一拍：科技巨头在推动科技进步的同时，也带来了垄断和对小公司创新的打压。
