Librem 5 Linux 智能手机开始量产，向客户发货

![](../Images/1d430db2ba869491834e77e67963a07d.png)

Librem 5 运行与 Purism 的笔记本电脑和迷你 PC 相同的 PureOS 操作系统。Librem 5 具有独特的硬件功能，包括用户可拆卸的蜂窝调制解调器、WiFi 卡和电池。

与 Librem 笔记本电脑一样，Librem 5 也具有外部硬件切断开关，可以切断蜂窝调制解调器、WiFi/蓝牙、前后摄像头和麦克风的电源，这样用户就可以控制这些设备的使用时间。所有的硬件开关也可以一起被触发，以启用“锁定模式”，该模式还可以禁用 GPS、加速度计和所有其他传感器等等。

Librem 5 的另一个独特功能是融合：能够将 Librem 5 连接到显示器或笔记本电脑底座上，并将其作为台式电脑使用，运行与 Librem 笔记本电脑上相同的全尺寸桌面应用程序。

Librem 5 售价 $799，5.7″ IPS TFT，3GB 内存，32GB 存储，i.MX8M (Quad Core) max. 1.5GHz。

GIMP 诞生 25 周年

![](../Images/fd129136dfabcca1af40feaaf0c6ee7d.png)

从 GIMP 作为一个开源图像编辑器开始，进而引发 GTK（GIMP 工具箱）的诞生以及发展成为一个自成体系的项目，被成千上万的开发者使用到今天已经 25 年了。

多年来，GIMP 一直在酝酿一个期待已久的 3.0 大改版，在这过程中，大量的将程序现代化的工作要做。GIMP 2.99.2 于本月早些时候发布，在步往 GIMP 3.0 的路途中依然有不少麻烦，开发团队表示现在远比以往更加繁忙，但现阶段 GIMP 3.0 是否会在春季 GTK 4.0 发布之前出货还有待观察。

基于 Firefox 的 Chrome OS 替代方案：Ubuntu Web Remix

![](../Images/ca2fc84abc84290b722ed3bacbaebf29.png)

打造了 Ubuntu Unity 发行版的团队的这周推出了 Ubuntu Web Remix。这个操作系统提供了类似 Chrome OS 的体验，这要归功于一个简化的用户界面和一套预装的应用程序，包括 Firefox 浏览器，一些来自 /e/ 的 Web 应用程序，以及 Anbox，一个允许你在 Linux 中运行 Android 应用程序的工具。

并没有 Chromebook 所提供的长电池寿命、云备份和许多其他功能，但这一个专注于隐私的、开源的谷歌 Chrome OS 的替代品。
