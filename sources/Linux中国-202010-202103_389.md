微软宣布安全芯片 Pluton，使 Windows PC 无法被黑客攻击

![](../Images/b81f20031b33b9d221c00e64618a1f84.png)

微软的 Pluton 是可信平台模块（TPM）的替代者，本质上是微软对苹果和谷歌类似努力的回应。两者已经分别公布了 T2 和 Titan M，为他们的设备提供安全芯片，现在微软投资 Pluton 以保护 Windows 生态系统。

Pluton 设计通过将安全性直接构建在 CPU 中，消除了该通信通道被攻击的可能性。这一项目得到了 AMD、英特尔和高通的支持。

谷歌在 Android 消息测试版中推出 RCS 端对端加密功能

![](../Images/99a684139e5eda73775c41e435d3d228.png)

谷歌推动全面废弃 SMS 并用 RCS 取代的计划用了两年时间，全球（中国除外）的每一个安卓用户现在都可以使用取代短信的下一代短信标准了。但目前还不知道 iPhone 是否打算采用 RCS 标准。

谷歌通过其 Android Messages 应用直接向任何安装它并将其作为默认短信应用的人提供 RCS 聊天服务，并启用一项关键的隐私功能：端到端加密。这意味着运营商和谷歌都无法读取这些消息的内容。

这是一个巨大的隐私胜利，因为这可能意味着在全球绝大多数人使用的智能手机平台上，短信的事实上的替代者将在默认情况下是私密的。

Mozilla 在全球推出火狐浏览器中的 DoH 前展开公众咨询

![](../Images/0f5bb4d09b5459fa876e463569e291d4.png)

Mozilla 今天开启了一个罕见的公众咨询期，讨论如何在 Firefox 内部实现对有争议的以隐私为中心的 DNS-over-HTTPS（DoH）协议的支持。

英国政府官员、执法机构和当地的 ISP 批评 Mozilla 开发并想要推出 DoH，他们说这一功能可以帮助嫌疑人绕过企业防火墙和家长控制屏蔽列表，甚至将 Mozilla 提名了当地 ISP 联盟的“互联网恶棍”奖。

尽管该协议对用户的个人隐私有很多好处，但互联网服务提供商和执法机构却大声反对。虽然美国也有反对意见，但最终美国许多 ISP 建立了自己的 DoH 服务器。
