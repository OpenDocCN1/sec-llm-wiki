据传 SUSE 将进行 IPO，高达 60 亿美元

多年来，SUSE几经易主。首先，它在 2004 年被 Novell 收购。然后，Attachmate 在微软的一些资助下，于 2010 年收购了 Novell 和 SUSE。随后在 2014 年，Micro Focus 收购了 Attachmate，SUSE 被分拆为一个独立的部门。随后，EQT 在 2019 年 3 月以 25 亿美元从 Micro Focus 手中收购了 SUSE。

彭博社报道，EQT 正计划对 SUSE 进行 IPO，规模可能达 60 亿美元，当前 IPO 谈判还处于非常初步的阶段。SUSE 对此没有评价。

Cerebras 的晶圆大小的芯片比 GPU 快 1 万倍

Cerebras 制造了世界上最大的计算机芯片 WSE。通常，芯片制造商通常会从直径为 12 英寸的硅锭上切下一块晶圆，在芯片工厂进行加工，硅片被切成数百个独立的芯片。但 Cerebras 公司却将这种晶圆加工成一个个巨大的芯片。芯片的每一块被称为核心，以一种复杂的方式与其他核心相互连接。

单个 Cerebras CS-1 高达 26 英寸，拥有 1.2 万亿个晶体管。而英特尔 1971 年的第一款 4004 处理器有 2300 个晶体管，昨天公布的 Nvidia A100 80GB 芯片才有 540 亿个晶体管。

这意味着以前需要数月时间训练的 AI 神经网络，现在可以在 Cerebras 系统上几分钟内完成训练。

微软针对 Linux 服务器推出 Defender 防护软件

早在 6 月份，微软就发布了面向 Linux 的微软 Defender 高级威胁防护（ATP），供普通用户使用。现在，微软改进了 Linux 版本的 Defender ，增加了端点检测和响应（EDR）功能的公开预览。

它并不是一个你可以在独立的 Linux 桌面上运行的微软 Defender 版本。它的主要工作仍然是保护 Linux 服务器免受服务器和网络威胁。

拍一拍：微软真正盯上的不是 Linux 桌面，是 Linux 服务器啊。
