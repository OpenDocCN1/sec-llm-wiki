PingCAP 完成 D 轮 2.7 亿美元融资，创造全球数据库历史新的里程碑

PingCAP 成立于 2015 年，是一家企业级开源分布式数据库厂商。由 PingCAP 创立的分布式关系型数据库 TiDB，具备「分布式强一致性事务、在线弹性水平扩展、故障自恢复的高可用、跨数据中心多活」等企业级核心特性。

2020 年 5 月， TiDB 推出 4.0 版本。截止到 2020 年 10 月，TiDB 项目在 GitHub 上已总计获得超过 25000 颗星，近 1200 位开源代码贡献者。CNCF 2019 年年度报告提到，PingCAP 在 2019 年 CNCF 全球代码贡献排行榜中名列第六。PingCAP 已成为全球知名的开源软件厂商。

来源：PingCAP

拍一拍：恭喜 PingCAP，一家五年的中国的开源数据库公司，能取得这个成绩非常可喜可贺。

Mozilla 的 Servo 项目交由 Linux 基金会维护

今年早些时候，Mozilla 宣布进行大规模裁员以及砍掉了多个项目，很多人都在猜测 Servo 项目是否被波及。今早 Mozilla 和 Linux 基金会发布联合声明，宣布 Servo 网页引擎的相关开发工作交由 Linux 基金会托管和继续推进。

Servo 由 Rust 编写，被 Mozilla 认为是“下一代”网页引擎，此举还得到了三星和 Let's Encrypt 等其他行业利益相关者的支持。

来源：cnbeta

拍一拍：“瘦身”成功的 Mozilla，也许丢弃了负担，也许丢弃了希望。

比特币 2017 年 12 月以来首次突破 17000 美元

最大的数字货币比特币突破 17,000 美元，为近三年前该加密货币泡沫破裂后以来首次。比特币今年上涨了一倍多，周二在纽约盘中一度上涨 2.2%，至 17,067 美元。比特币曾在一年内从 2017 年 12 月的历史高位近 20,000 美元一度跌至低点 3,136 美元。

来源：新浪美股

拍一拍：市场过热情绪显然不利于区块链发展，这背后巨鲸推动的痕迹太明显了。
