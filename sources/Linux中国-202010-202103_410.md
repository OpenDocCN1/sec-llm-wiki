64 岁的 Python 之父表示退休后太无聊，正式加入微软

![](../Images/f9dd3c224731f18669129544add28973.png)

作为 Python 的创建者，Guido van Rossum 一直致力于 Python 社区的维护，不过去年 10 月，在 Dropbox 公司任职六年半后，他宣布退休，并退出 Python 核心决策层。

他在 Twitter 上表示，觉得退休太无聊了，所以已经加入了微软开发部门，至于做什么，太多选择了，不过可以肯定的是，无论做什么都会让 Python 变得更好，而且不仅是在 Windows 上，还有开源。

据悉，Guido van Rossum 加入微软后将与 Typescript/C# 创始人 Anders、VS Code/Eclipse 创始人 Eric、Linux GNOME 作者 Miguel 共同任职于微软全球资深副总裁潘正磊团队中。

微软今天正式终止 Windows 7 嵌入式系统支持

![](../Images/16a5325bdf755cd6ae1850bbb5ec742f.png)

在年初正式停止支持 Windows 7 系统（简称 Win7）扩展支持之后，微软日前宣布另一个版本的 Win7——Windows Embedded Standard 7（WES7）也将在 10 月 13 日停止支持。

WES7 是微软面向 IoT 物联网等嵌入式市场推出的操作系统，发布于 2015 年，比 Win7 晚了 6 年，有 WS7E、WS7P 两个版本。

来源：cnbeta

> 拍一拍：过期的嵌入式系统要么不能更新，要么直接丢掉。
