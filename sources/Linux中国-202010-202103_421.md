.NET 5.0 正式版发布：应用可在 ARM64 设备上原生运行

![](../Images/f3a21d5c68082807fa0cdbbd920d6474.png)

微软今天发布了 .NET 5.0 正式版。自首个预览版发布以来微软已经进行了广泛的内部部署，除了在 .NET 5.0 上运行 .NET 网站外，Bing 也在使用这个新平台。

微软希望 .NET Framework 开发者能够迁移他们的代码和应用到 .NET 5.0 上，为明年发布的 .NET 6.0 将 Xamarin 开发者过渡到统一平台奠定基础。

梵蒂冈图书馆频繁遭黑客攻击

![](../Images/1790f4d75300bd24b60832bc1c229414.png)

梵蒂冈使徒图书馆拥有八万个极为珍贵且价值不菲的历史藏品，其中，包括现存最古老的圣经，米开朗基罗的绘画、伽利略的著作等。梵蒂冈使徒图书馆自 2012 年开始启动数字化进程，已有 25％ 的历史资料被数字化。

该图书馆每月都会发生 100 次黑客在线攻击。世界各地的图书馆、档案馆以及其他文化研究机构都在逐步启动数字化模式。但随着网络安全问题的加剧，这种数字化形式也为历史藏品带来了巨大的安全威胁。

NPM 包被发现窃取敏感的 Discord 和浏览器文件

![](../Images/dcf1fd716ebe889477442939f1fcd79f.png)

在一个名为 Discord.dll 的 JavaScript 库中发现了恶意代码。

一旦安装，discord.dll 将运行恶意代码来搜索开发者电脑中的某些应用程序，然后检索其内部的 LevelDB 数据库。
