英国注册机构要求公司停止使用包含 HTML 结尾标签的公司名

![](../Images/1970b2aec12395c4e9650c866ebb2cbb.png)

一位英国软件工程师为他的咨询业务想出了“一个有趣好玩的名字”：`"">`。英国官方的公司注册机构“在姗姗来迟地意识到可能会带来安全风险后，迫使该公司改名”。

然后该工程师将公司改名为“THAT COMPANY WHOSE NAME USED TO CONTAIN HTML SCRIPT TAGS LTD”。他说，他并没有意识到注册机构实际上容易受到他使用的极其简单的技术的影响。

Debian 13 代号确认为 Trixie

![](../Images/126e423967722416eda06613aef0cf61.png)

和以往相同，Debian 系统代号是从《玩具总动员(Toy Story)》电影中的角色派生的，来自其中的蓝色恐龙。

Debian 11 叫做“Bullseye”，第一个里程碑“过渡和构建基础冻结”将会发生在 2021 年 1 月 12 日；Debian 12 叫做“Bookworm”，将会在 2023 年发布；而 Debian 13 将会在 2025 年发布。

微软 Edge 浏览器正在消费者和企业界取得进展

![](../Images/c0c331ec4f5eac2c849e918679bb6e38.png)

微软宣布用谷歌开源的 Chromium 的渲染引擎取代 Windows 10 的默认网页渲染引擎，这让科技行业震惊不已。老 Edge 失败的原因有很多，但其中一个重要原因是谷歌在网络上的主导地位，另一个原因是 Edge 网络商店中缺乏扩展功能。

通过采用 Chromium 引擎，微软已经解决了所有这些问题，Edge 现在得到了更频繁的更新。另外，由于微软进行了大量的资源和功耗改进，Edge 的速度比 Chrome 要快。

NetMarketShare 表示，Edge 现在是第二大最受欢迎的网络浏览器，而 StatCounter 的报告则显示，Edge 将很快击败 Firefox。

来源：cnbeta

> 拍一拍：没想到放弃了自己的核心的 Edge 浏览器居然取得了意想不到的成功。
