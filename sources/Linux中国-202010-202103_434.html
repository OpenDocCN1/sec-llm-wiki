RansomEXX 勒索软件的 Linux 版本被发现

这标志着一个主要的 Windows 勒索软件首次被移植到 Linux 上。

RansomEXX 是一种相对较新的勒索软件，今年 6 月初首次被发现。它已被用于攻击德克萨斯州交通部、柯尼卡美能达公司、美国政府承包商泰勒科技公司、蒙特利尔的公共交通系统，以及最近针对巴西法院系统的攻击。它们猎取大型目标以寻找大额报酬，因为它们知道一些公司或政府机构在恢复系统时无法承受停机。

Canonical 拿下 OpenStack 云计算电信大单

俄罗斯最大的移动网络 MTS 即将在基于 Canonical 的 Charmed OpenStack 云软件构建的私有云上运行。MTS 拥有超过 8000 万的移动用户。

Canonical 的 Charmed OpenStack 云运行在 Metal-as-a-Service（MAAS）、Juju Operator Lifecycle Manager（OLM）、OpenStack Charms 和 Ceph 开源存储栈的组合上。

去年，Canonical 与英国电信（前英国电信）赢得了一份合同，使用 Ubuntu Linux 和 OpenStack 在英国和全球范围内部署 5G。

委内瑞拉建立国营加密货币交易所 VEX

委内瑞拉已推出国营加密货币交易所，将支持石油币（PTR）、比特币（BTC）、莱特币（LTC）和达世币（DASH）。据委内瑞拉加密监管机构 Sunacrip 在政府媒体门户网站上发布的声明，其国营加密交易所被命名为委内瑞拉交易所（VEX）。VEX 将使用“P2P 技术”，也可以通过政府发行的加密钱包应用程序 PetroApp 进行访问。
