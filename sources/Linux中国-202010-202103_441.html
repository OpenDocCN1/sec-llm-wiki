Python 的受欢迎程度首次领先于 Java

最新的 Tiobe 指数表明，35 岁的 Python 首次超过了 Java，成为第二受欢迎的编程语言。Python 是数据科学和机器学习项目的首选，现在仅次于 C。

这是 Tiobe 指数近 20 年的历史上，第一次出现 Java 和 C 语言不是两大顶级语言的情况。

在 7 月份开发者分析机构 RedMonk 的编程语言受欢迎程度排名中，Python 也从 Java 手中抢走了第二名。不过，RedMonk 将 JavaScript 列为顶级语言。这是 RedMonk 的前两名首次不由 Java 或 JavaScript 组成。

Adobe 正式在其流行的 PDF 产品中废止所有 Flash 组件

Adobe 在 2020 年 12 月 Flash 正式死亡之前，已经在其 Acrobat 和 Reader 等 PDF 产品的最新版本中删除了所有 Flash 组件。以前，Acrobat 中有一些选项或按钮可以从依赖 Flash 的表单文件中收集用户的回复，现在已经被一个辅助工具栏替代。

这些删除是整个行业在今年年底前从主流浏览器中消除 Flash 的努力的一部分。Adobe、苹果、Facebook、谷歌和 Mozilla 在 2017 年宣布将在 2020 年 12 月前结束对浏览器中 Flash 的支持。

Linux Mint 构建自己的 Chromium 浏览器

多年来，Linux Mint 一直使用 Ubuntu 构建的 Chromium 版本。但 Ubuntu 的开发商 Canonical 发布的 Chromium 版本开始从 APT 兼容的 DEB 包迁移到 Snap 打包格式。

Snap 通过整合需要加载的不同库来减少依赖问题，但也存在容量过大启动过慢的缺陷。Canonical 强推 Snap 打包格式的做法已经在社区引发了争议。

而 Linux Mint 早些时候宣布不会安装任何 Snap 应用，它现在决定利用源代码构建自己的 Chromium 版本。

来源：solidot

拍一拍：Snap 有好处，但是其负面作用也需要认识到。我认为 Mint 的这种做法是对的，对于这种本身就很庞大的重要软件，采用 Snap 之类的封装软件包浪费严重。
