Windows 7 仍是第二大最受欢迎的操作系统

数据分析公司 NetMarketShare 透露，Windows 10 的用户又有了新的提升，它从上个月的 61.26% 上升到 64.04%。Windows 7 的市场份额也有所下降，上个月 Windows 7的市场份额从 22.77% 下降到 20.41%。更糟糕的是，有些人还在使用 Windows XP，市场份额为 0.87%。

Linux（多个发行版）从 1.14% 上升到 1.65%。

来源：netmarketshare

拍一拍：我说什么好呢，Linux 桌面也就是比过气多年的 XP 强点。

多方市场调查数据表明 AMD 正蚕食英特尔 CPU 市场份额

根据 Statista 的分销统计，AMD 的处理器市场份额在第三季度达到了 37.3％。这是自调查期开始（2012 年开始）以来的最高水平。英特尔的市场份额为 62.6％，是同期的最低水平。

根据 Steam 的软硬件调查显示，今年 10 月份有 25.79% 的 Windows 游戏玩家使用 AMD 的 CPU，而竞争对手英特尔的占比为 74.21%。在过去五个月（自 6 月以来）中，Steam 数据显示逐渐向 AMD 倾斜。

来源：cnbeta

拍一拍：或许 AMD 市场份额超过英特尔的一天不远了。

电影行业：VPN 和 Tor 对合法流媒体平台构成威胁

电影协会表示，VPN、DNS 伪装和 Tor 网络等规避服务会对合法的流媒体服务构成直接威胁。在提交给美国贸易代表的评论中，电影行业组织强调了全球各地的各种盗版挑战。

来源：slashdot

拍一拍：不可否认，VPN 等对于隐私和安全有一定意义，但是也常常被用来做一些非法活动。
