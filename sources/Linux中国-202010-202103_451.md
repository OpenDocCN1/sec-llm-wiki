课程简要介绍

![](../Images/6520a46f6ed372ff925e4b123b5934ac.png)

入门阶段

本阶段针对没有 Linux 基础的初学者，使之可以对 Linux 有初步了解并掌握使用 Linux 的能力，并培养其对 Linux 和开源技术的兴趣

![](../Images/6520a46f6ed372ff925e4b123b5934ac.png)

进阶阶段

本阶段针对已经完成入门阶段学习或具有同等能力的学员，分别根据其职业发展规划，设计两条路线：开发工程师和运维工程师。

◈ 开发工程师：针对使用 Linux 进行开发或为 Linux 环境开发应用的工程师。主要介绍如何在 Linux 环境下进行开发、调试和部署等技能。◈ 运维工程师：针对需要管理和运维 Linux 服务器的工程师。分别就主要服务部署和运维、监控和安全管理、自动化运维和虚拟化技术等方面深入浅出地进行讲述。![](../Images/6520a46f6ed372ff925e4b123b5934ac.png)

高阶阶段

完成了入门阶段，并分别掌握了进阶阶段的开发和运维技能的学员，可以进一步提升技能为 SRE，掌握 DevOps、CI/CD 和架构设计等技能。
