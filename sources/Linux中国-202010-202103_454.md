龙芯和比亚迪合作推出龙芯笔记本

 

![](../Images/074d7920899f102565f7bf877d0bfa5c.png)

 

龙芯中科宣布和比亚迪合作推出龙芯笔记本电脑。笔记本采用的处理器是 14 纳米工艺主频 1.5Ghz 的龙芯 3A4000，集成了漏洞防范设计、硬件国密算法、安全可信模块与安全访问控制机制，其性能据称与 AMD A8-7680 使用的挖掘机核心相似。

笔记本的其它组件包括：景嘉微JM7201 GPU，8G DDR4 内存，256G SSD，操作系统支持龙芯操作系统、麒麟OS、UOS MIPS 版本系统等。龙芯是基于 MIPS 架构，不支持 Windows。

龙芯中科董事长胡伟武表示，14 纳米（CPU）和 28 纳米（GPU）对九成应用足够了。

来源：solidot

互联网档案馆开始为 Wayback Machine 用户提供注释 

![](../Images/d7cfe2b763cd83c51adb43b5a9abdc13.png)

事实核查组织和起源网站有时会引用 Wayback Machine 中存档的网页的信息，现在互联网档案馆已经开始为 Wayback Machine 用户提供其中的一些注释。

数字历史值得保存，但也认识到提供对来自不同来源的虚假和误导性信息的访问问题。通过提供方便的上下文信息链接，可以给世人带来更好地理解的 Wayback Machine 中阅读的历史内容。

来源：cnbeta

> 拍一拍：Wayback Machine 是一个非常有价值的服务，而现在的这个注释有助于让其更有价值。

Linux Kernel 5.10 将清理英特尔集成众核架构的 2.7 万行代码

![](../Images/652a841d9b93076366e562a51a62cac9.png) 

Linux Kernel 5.10 的第二个候选版本将会在今天晚些时候发布，不过内核维护人员 Greg Kroah-Hartman 今天发出了推迟请求，主要原因是移除包括 Xeon Phi 在内的英特尔 MIC（集成众核架构）驱动。

英特尔在 2013 年添加了 MIC 代码，此后经历了一段持续改进的短暂时光。这些设备已经停产了多年，并且英特尔不再希望维护该代码，特别是对于从未大规模交付的硬件。

来源：cnbeta

> 拍一拍：早该这样做了，Linux 内核中的垃圾驱动可能太多了吧，现在 Linux 内核已经不需要代码行数证明自己了。
