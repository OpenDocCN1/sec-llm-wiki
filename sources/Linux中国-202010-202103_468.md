iOS 14 即将推出的反追踪提示功能在法遭遇反垄断投诉

从明年年初开始，iOS 14 将要求应用获得用户的选择加入许可之后才可以收集他们的随机广告标识符。据悉，广告商利用该标识符向用户发送个性化广告并跟踪他们的广告活动的效果。

据《华尔街日报》报道称，广告公司和出版商已向法国竞争主管部门投诉苹果，称加强的隐私保护措施将不利于竞争。投诉称，苹果的许可提示的措辞将导致大多数用户拒绝跟踪他们的设备的广告标识，而这可能会导致收入损失。

不希望应用访问其设备广告标识符的用户可以进入“设置>隐私>跟踪”并关闭“允许应用请求跟踪”。

维基媒体将迁移到 GitLab

维基媒体基金会是美国的非营利组织，托管着维基百科等网站，已经决定将他们的代码仓库从 Gerrit 迁移到 Gitlab。

维基媒体基金会称，虽然 Gerrit 的工作流程在很多方面都是同类产品中最好的，但它的界面在可用性方面存在缺陷，而且它的工作流程也与主流的行业实践不同。这导致越来越多的个人和团队选择放弃使用 Gerrit，而使用第三方托管，如 GitHub。目前维基媒体在 GitHub 上已经包含 152 个项目，研究团队有 127 个项目。虽然 Gerrit 也是开源的，而且也在不断改进，但带来的麻烦让维基媒体必须选择新的代码仓库。

为了避免使用第三方代码托管破坏协作，决定整体迁移到 GitLab。

研究人员已经提取了加密更新各种英特尔 CPU 的密钥

该密钥可以针对任何基于英特尔 Goldmont 架构的芯片提取，无论是赛扬、奔腾还是 Atom。这些密钥可以解密英特尔提供的微代码更新，这些更新用以修复安全漏洞和其他类型的错误。拥有一个更新补丁的解密副本可能会让黑客对其进行逆向工程，并精确地了解如何利用它所修补的漏洞。该密钥还可能允许英特尔以外的其他方（比如说恶意黑客或业余爱好者）用自己的微代码更新芯片，尽管该定制版本无法在重启后存活。

据称，这是英特尔处理器历史上第一次可以在内部执行你的微代码并分析更新。

英特尔称，用于验证微代码的私钥并不驻留在硅片中，攻击者无法在远程系统上加载未经验证的补丁。
