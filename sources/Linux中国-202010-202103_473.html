Linux 基金会和 edX 的报告还研究了 COVID-19 对开源技术产业的影响。

通过开源实现大规模创新的非营利组织 Linux 基金会和值得信赖的学习平台 edX 发布了 2020 年开源工作岗位报告(Open Source Jobs Report 2020)，研究了开源人才的需求和开源专家的趋势。

尽管流行病毒肆虐，但对开源技术技能的需求依然强劲。公司和组织继续加大对开源技术人才的招聘力度，同时为现有员工提供更多的培训机会，以填补技能的缺口。93% 的招聘经理表示很难找到开源人才，63% 的受访者表示他们的组织已经开始用贡献代码或其他资源支持开源项目，原因非常明确，就是为了招聘具有这些软件技能的人士，这比 2018 年（只有 48%）有大幅的提升。DevOps 也成为招聘经理们最想为企业填补的角色（65% 的受访者正在寻求招聘 DevOps人才），DevOps 在本报告的历史上首次成为最具需求的开发人员的第二位（59%）。现在 74% 的雇主会为员工承担认证考试的费用，远高于 2018 年的55%，2017 年的 47% 及 2016 年的 34%。

 “2020 年对我们所有人来说都是困难的一年，但令人鼓舞的是，开源继续提供丰富的机会。”Linux 基金会执行董事 Jim Zemlin 说，“Linux 基金会和我们的会员将继续努力提供技术的进步让所有人也能受惠，并且会同时努力使开源教育机会更加广泛。”

《2020 年开源工作岗位报告》是 Linux 基金会第八次参与的这项研究，也是首次与 edX 合作制作。上一次的调查是在 2018 年。这次的报告与过去的第 5、6、7 份一样，调研重点涵盖了开源软件的各个方面；而第 1~4 份报告相对更针对于 Linux 专业人员。

《2020 年开源工作岗位报告》研究了开源职业的趋势，探讨了哪些技能是最需要的、开源专业人员的驱动力是什么、以及雇主如何吸引和留住专业人才。 

“作为开源组织的一员，edX 知道这些技能对于推动全球创新技术项目的重要性。”edX 总裁兼联合首席执行官 Adam Medros 说。“例如，在我们的 Open edX 平台上工作的技术专家正在为其发展做出贡献，并为人们提供创新的在线学习方式，帮助他们达到理想的学习目标。我们希望这份报告中的信息能够让开源专业人员对这个行业的前景有一个清晰的认识，为他们加入和创建团队的决策上，及为组织的员工培训和投资的决策上提供充分的参考。”

《2020 年开源工作岗位报告》的主要发现包括：

◈ 具备资格的开源人才仍然紧缺。93% 的招聘经理表示难以找到具备足够开源技能的人才，高于两年前的 87%。
◈ DevOps 的崛起：DevOps 专业人员已经成为市场上最抢手的工作角色，65% 的公司表示希望雇佣更多的 DevOps 人才，高于 2018 年的 59%。
◈ 由于 COVID-19 的影响，招聘人数减少，但没有停止。尽管出现了疫情和经济放缓，但 37% 的招聘经理表示，他们将在未来6个月内招聘更多熟练的IT专业人员。
◈ 在线培训在 COVID-19 期间越来越普及。现在有 80% 的雇主表示，他们为员工提供在线培训课程以学习开源软件，而两年前只有 66%。
◈ 认证考试越来越重要。52% 的招聘经理更倾向于雇佣拥有专业证书的人士，高于两年前的 47%。
◈ 云技术现在是炙手可热的技术：在知识领域方面，招聘经理报告表示，开放云技术的知识影响最为显著，70% 的招聘经理更有可能雇用具有这些技能的专业人员，高于 2018 年的 66%。

这份报告收录了来自全球各地企业、中小企业（SMB）、政府组织和人事机构的超过 175 名招聘经理的数据，以及全球 900 多名开源专业人士的回复。
