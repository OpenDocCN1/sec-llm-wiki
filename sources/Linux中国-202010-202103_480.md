30 行代码：让 27 吨发电机原地爆炸

这是十年前美国国安部进行的一项秘密实验。在美国爱达荷州的测试场地上。黑客模拟者将大约 30 行代码（约 140 KB的文件）推进保护继电器中，不到 23 秒，机器就已经开始摇晃。又过了几秒钟，发电机开始冒黑烟，最后直接爆炸。

来源：快科技

研究发现大部分开源初创企业都在硅谷以外成立

最近有研究显示这些公司大多都不在硅谷，甚至可能不接受创投基金和类似投资的参与。Runa Capital 所提出的 ROSS 指数列出了 GitHub 上拥有公共存储库的增长最快的初创创业公司，其中发现在 2020 年的排行之中，有 90% 以上是在硅谷以外成立的公司，当中有很大部分来自欧洲。

来源：cnbeta

Linux Kernel 5.10 首个候选版本发布

新增代码 70.4 万行，删除 41.9 万行。目前，5.8 依然是 Linux 内核最大的发布版本。

Linux Kernel 5.10 的改进重心是对文件系统和其他存储功能方面的优化，为 AMD Zen 3 处理器提供各种新功能，继续推进 Big Navi / Radeon RX 6000 系列开源驱动的工作，增加对 Purism Librem 5 智能手机的主线支持，XFS 文件系统修复了 “Year 2038”问题的。

来源：cnbeta
