youtube-dl 被从 GitHub 移除

在 GitHub 收到 RIAA 的 DMCA 取缔通知后，youtube-dl 的 GitHub 仓库已经下线。一同被下线的项目还有它的 17 个复刻分支。

该通知声称：“该源代码的明确目的是：(i) 规避 YouTube 等授权流媒体服务所使用的技术保护措施，(ii) 在未经授权的情况下复制和传播我们的会员公司所拥有的音乐视频和录音。”

现在该项目创作者要提出反诉，希望能在 GitHub 上恢复 youtube-dl。

六款冒充 Flash 安装程序的恶意应用绕过苹果审查

这是六周内苹果公证程序第二次被绕过。第一批成功通过公证流程并被列入新版 macOS 白名单的恶意应用是在 8 月底被发现的。

应用公证是苹果在今年年初正式推出的一项最新安全保护措施。它是要求 Mac 应用开发者将自己的应用提交给苹果公司进行一系列自动安全扫描，检查是否有恶意软件或其他恶意代码模式。经过公证的应用可以通过简单的点击打开和安装，而不会出现任何警告或弹窗。

来源：zdnet

拍一拍：即便如苹果的审查流程，也会被人利用和绕过。

Mozilla Firefox 82 因杀毒软件而崩溃

Firefox 似乎不能与安装在 Windows 设备上的各种防病毒产品很好的相处。

在安装了赛门铁克和趋势科技开发的软件的设备上，浏览器在启动时就会崩溃，有人声称，即使启用了Windows 10 默认的 Windows Defender 防病毒保护功能，也会发生这种情况。

不过这个问题在 Firefox 83 beta 中得到了解决。

拍一拍：相信这是一种误会，但是这反映出 Firefox 目前的自动推出策略可能有一定的问题。
