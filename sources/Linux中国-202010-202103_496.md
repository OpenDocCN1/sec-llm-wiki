微软发布 Edge for Linux 的预览版本

微软正式发布了基于 Chromium 的 Edge for Linux 预览版本，感兴趣的 Linux 开发者可以直接到 Edge Insider 网站（Dev 渠道）下载 .deb 或 .rpm 包。Edge for Linux 目前支持 Ubuntu、Debian、Fedora 和 openSUSE 发行版。微软称，技术预览版本主要针对想要构建和测试网站和应用在 Linux 上表现的开发者。

来源：solidot

> 拍一拍：终于发布了，很多人都很关注 Edge for Linux 的发布。

勒索软件黑帮向慈善组织捐款

自称 Darkside 的黑客在暗网上公布了用比特币捐款给两家慈善组织的税务收据，表示要将勒索所得“让世界变得更好”。Darkside 曾表示，根据他们的原则，其不会攻击医院、学校、政府或慈善机构。他们向两家慈善组织“儿童国际”和“水项目”分别捐赠了 0.88 比特币，相当于 10,000 美元。“儿童国际”组织表示，“如果捐赠款项和黑客有关，我们不会要。”

来源：solidot

> 拍一拍：这些慈善捐款可能是 Darkside 品牌宣传活动的一部分，其目的是将自己塑造成不同于普通罪犯的形象。

PayPal 称将接受加密货币，比特币一度大涨 5%

据市场消息，Paypal 将允许用户在平台上购买、销售和持有加密货币。报道称，Paypal 已在纽约州金融服务部门处获得加密货币执照。交易平台 Coinbase 报价显示，比特币站上 12500 美元/枚，日内涨近 5%，创 2019 年 7 月以来新高。

来源：cnbeta

> 拍一拍：BTC 价格受消息影响的越少，才能越说明 BTC 的基本支撑面的稳定。
