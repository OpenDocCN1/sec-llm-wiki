COPR 是个人软件仓库 集合，它不在 Fedora 中。这是因为某些软件不符合轻松打包的标准；或者它可能不符合其他 Fedora 标准，尽管它是自由而开源的。COPR 可以在 Fedora 套件之外提供这些项目。COPR 中的软件不受 Fedora 基础设施的支持，或者是由项目自己背书的。但是，这是一种尝试新的或实验性的软件的一种巧妙的方式。

本文介绍了 COPR 中一些有趣的新项目。如果你第一次使用 COPR，请参阅 COPR 用户文档。

![](../Images/aced5e85da4f5cdf5879ad159601ba7e.png)

Wike

Wike 是一个用于 GNOME 桌面的维基百科阅读器，在 GNOME Shell 中集成了搜索功能。它提供了对 在线百科全书 的无干扰访问。它的界面很简约，但它支持在多种语言之间切换文章、书签、文章目录、黑暗模式等。

![](../Images/93d38a146ba16b6a57cd360c232aa00e.png)

![](../Images/aced5e85da4f5cdf5879ad159601ba7e.png)

安装说明

该 仓库 目前为 Fedora 33、34 和 Fedora Rawhide 提供了 Wike。要安装它，请使用这些命令：

```
1.  `sudo dnf copr enable xfgusta/wike`
2.  `sudo dnf install wike`
```

![](../Images/aced5e85da4f5cdf5879ad159601ba7e.png)

DroidCam

我们正生活在一个混乱的时代，被隔离在家中，我们与朋友和同事的大部分互动都发生在一些视频会议平台上。如果你已经有一部手机，就不要把钱浪费在价格过高的网络摄像头上。DroidCam 让你将手机与电脑配对，并将其作为专用网络摄像头使用。通过 USB 线或通过 WiFi 进行连接。DroidCam 提供对摄像头的远程控制，并允许缩放、使用自动对焦、切换 LED 灯和其他便利功能。

![](../Images/7c384719a09916be32107f8b8844e161.png)

![](../Images/aced5e85da4f5cdf5879ad159601ba7e.png)

安装说明

该 仓库 目前为 Fedora 33 和 34 提供了 DroidCam。在安装之前，请更新你的系统并重新启动，或者确保你运行的是最新的内核版本，并安装了适当版本的 `kernel-headers`。

```
1.  `sudo dnf update`
2.  `sudo reboot`
```

Droidcam 依赖 `v4l2loopback`，必须从 RPM Fusion 自由软件仓库 手动安装。

```
1.  `sudo dnf install https://download1.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm`
2.  `sudo dnf install v4l2loopback`
3.  `sudo modprobe v4l2loopback`
```

现在安装 `droidcam` 软件包：

```
1.  `sudo dnf copr enable meeuw/droidcam`
2.  `sudo dnf install droidcam`
```

![](../Images/aced5e85da4f5cdf5879ad159601ba7e.png)

Nyxt

Nyxt 是一个面向键盘、可无限扩展的 Web 浏览器，专为高级用户设计。它在很大程度上受到 Emacs 的启发，因此用 Common Lisp 实现和配置，提供熟悉的按键绑定（Emacs、vi、CUA）。

其他不能错过的杀手锏是一个内置的 REPL、树形历史、缓冲区代替标签，还有更多。

Nyxt 与网络引擎无关，所以不用担心页面会以意外的方式呈现。

![](../Images/c0306f149bee6c97e30f7c783422e1f7.png)

![](../Images/aced5e85da4f5cdf5879ad159601ba7e.png)

安装说明

该 仓库 目前为 Fedora 33、34 和 Fedora Rawhide 提供了 Nyxt。要安装它，请使用这些命令：

```
1.  `sudo dnf copr enable teervo/nyxt`
2.  `sudo dnf install nyxt`
```

![](../Images/aced5e85da4f5cdf5879ad159601ba7e.png)

Bottom

Bottom 是一个具有可定制界面和多种功能的系统监控器，它从 gtop、gotop 和 htop 获得了灵感。因此，它支持 进程 监控、CPU、RAM 和 网络 使用监控。除了这些，它还提供了更多奇特的小部件，如 磁盘容量 使用情况，温度传感器，和 电池 使用情况。

由于小部件的可自定义布局以及 可以只关注一个小部件并最大化它，Bottom 可以非常有效地利用屏幕空间。

![](../Images/2923742fdddcdfeac77fdb06ae4a93b4.png)

![](../Images/aced5e85da4f5cdf5879ad159601ba7e.png)

安装说明

该 仓库 为 Fedora 33、34 和 Fedora Rawhide 提供了 Bottom。它也可用于 EPEL 7 和 8。要安装它，请使用这些命令：

```
1.  `sudo dnf copr enable opuk/bottom`
2.  `sudo dnf install bottom`
```

使用 `btm` 命令来运行该程序。
