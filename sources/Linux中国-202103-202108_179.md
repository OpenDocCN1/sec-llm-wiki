如果一切顺利的话，周日 Linus Torvalds 将会发布 Linux 5.13 稳定版，而不是发布 5.13-rc8 测试版并把最终版本再推后一个版本。不管是哪种情况，Linux 5.13 很快就会发布，而且会有很多新功能。

在合并窗口结束后，我们照例发布了 Linux 5.13 的功能概述。但是，对于那些不记得在 4 月底到 5 月初的合并窗口期间所有这些变化的人来说，这里回顾了这个下一个内核版本中最突出的变化：

◈ 对苹果 M1 SoC 和 2020 硬件平台的初步支持，尽管这种支持仍然是早期的，对苹果 M1 GPU 等还没有主线支持。◈ 经过多年的开发，Landlock Linux 安全模块已经合并入主线，支持无特权的应用程序沙箱。◈ 对 Alder Lake S 图形的初步支持，以及许多使其进入 Linux 5.13 的 Alder Lake 启用代码，如对 Perf 和其他领域。◈ AMDGPU FreeSync HDMI 支持现在进入了主线，允许在 HDMI（v2.1 之前）连接上实现 FreeSync，而不仅仅是通过 DisplayPort。◈ 对 Aldebaran 作为下一代 AMD CDNA 加速器的初步支持。◈ 一个新的英特尔冷却驱动，允许在比系统默认温度更低的阈值下对 CPU 进行降频。◈ 一个通用的 USB 显示驱动，用于将树莓派 Zero 变成一个基于 USB 的显示适配器。◈ 对 IO\_uring 的更多性能增强，它在整个开源生态系统中不断得到采用。◈ 支持 Realtek RTL8156 和 RTL8153D 网络适配器。同时在音频方面也有一些新的 Realtek 硬件支持。◈ 亚马逊的 Luna 游戏控制器现在由 XPad 驱动支持。◈ 对较新的微软 Surface 笔记本电脑的触摸板和键盘支持，以前需要使用树外的内核代码。◈ 对主线内核的 Clang 控制流完整性支持（CFI），可以增强安全性而仅有少量运行时开销。◈ 作为另一项内核安全改进，将每个系统调用的内核堆栈偏移量随机化。
