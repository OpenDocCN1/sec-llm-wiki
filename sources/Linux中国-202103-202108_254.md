# 想成为 Linux 工程师？物联网方向你值得考虑

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664635150&idx=1&sn=8580738accd81985761b3ef8f814efc1&chksm=bdcf20488ab8a95e34b632d59771ee581c528d8b3f31fbf7941a5c318570181d310a24038883&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664635150&idx=1&sn=8580738accd81985761b3ef8f814efc1&chksm=bdcf20488ab8a95e34b632d59771ee581c528d8b3f31fbf7941a5c318570181d310a24038883&scene=27#wechat_redirect)

很多同学问我，如何才能成为一个专业从事 Linux 的工程师。基于我的经验，如果只是使用 Linux，那还不能算是专业的 Linux 工程师。就 Linux 专业领域，无非是开发方向和运维方向。单就开发方向而言，无论是从事内核开发、系统应用程序开发，还是物联网/嵌入式开发，其实都是不错的选择。  

  

但是，内核开发和系统应用开发往往需要更深入的专业经验。相对而言，物联网开发的门槛更低一些，而物联网的应用场景更广泛，职业发展道路也更广阔。所以，我认为，选择物联网的研究方向是一个不错的选择。

  

你可能会问我**物联网都有哪些职业方向？有没有靠谱的渠道学习？**趁此机会我来给大家讲讲。

  
物联网方向的职业发展通道主要包括**研究型岗位、研发型岗位、技术型岗位和技能型岗位**4类：  
【技能型岗位】工作内容主要是**系统部署实施、运维管理等技术支持服务**。【技术型岗位】工作内容主要是负责**物联网系统规划、设计、集成、技术咨询**。  
【研发型岗位】工作内容主要是负责**物联网软硬件系统的开发**。【研究型岗位】工作内容主要是**底层软硬件技术的研究**。  
研究型人才主要从事底层软硬件技术的研究，通常需要研究生层次，入行壁垒高，而**研发型、技术型和技能型岗位是企业需求量最大最紧缺的人才**。  
小编非常推荐华为ICT学堂的物联网培训，**华为专家团分别对标技能型、技术型和研发型岗位能力要求，搭配同级别的华为物联网工程师认证，精心打造了对应的3门岗位实战营，让你师从华为专家，掌握前沿技能、夯实基础的同时，还能考取华为认证，部分实战营还赠送物联网全套开发板或海思双目开发板**（电子发烧友有福咯~）
