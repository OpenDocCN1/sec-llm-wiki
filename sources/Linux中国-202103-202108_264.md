Flutter 是一个流行的开源工具包，它可用于构建跨平台的应用。在文章《[用 Flutter 创建移动应用](https://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664624290&idx=1&sn=d40d4d61237e4e0e2af3a1ae22348d6c&chksm=bdcecbe48ab942f2656ffd24ac64e54cff3e7e67485b7fb94f4f5ed6dff96534a38b098e7c0f&scene=21#wechat_redirect)》中，我已经向大家展示了如何在 Linux 中安装 Flutter 并创建你的第一个应用。而这篇文章，我将向你展示如何在你的应用中添加一个列表，点击每一个列表项可以打开一个新的界面。这是移动应用的一种常见设计方法，你可能以前见过的，下面有一个截图，能帮助你对它有一个更直观的了解：

![](../Images/0b70f75b5c48ca05de99ca82365c8563.png "Testing the Flutter app")

*测试 Flutter 应用*

Flutter 使用 Dart 语言。在下面的一些代码片段中，你会看到以斜杠开头的语句。两个斜杠（`//`）是指代码注释，用于解释某些代码片段。三个斜杠（`///`）则表示的是 Dart 的文档注释，用于解释 Dart 类和类的属性，以及其他的一些有用的信息。

![](../Images/e6fa15b8dc6f2b925f83e5fd7d4923da.png)

查看Flutter应用的主要部分

Flutter 应用的典型入口点是 `main()` 函数，我们通常可以在文件 `lib/main.dart` 中找到它:

```
1.  `void main() {`
2.  ` runApp(MyApp());`
3.  `}`
```

应用启动时，`main()` 会被调用，然后执行 `MyApp()`。 `MyApp` 是一个无状态微件（`StatelessWidget`），它包含了`MaterialApp()` 微件中所有必要的应用设置（应用的主题、要打开的初始页面等）：

```
1.  `class MyApp extends StatelessWidget {`
2.  ` @override`
3.  ` Widget build(BuildContext context) {`
4.  `   return MaterialApp(`
5.  `     title: 'Flutter Demo',`
6.  `     theme: ThemeData(`
7.  `       primarySwatch: Colors.blue,`
8.  `       visualDensity: VisualDensity.adaptivePlatformDensity,`
9.  `     ),`
10.  `     home: MyHomePage(title: 'Flutter Demo Home Page'),`
11.  `   );`
12.  ` }`
13.  `}`
```

生成的 `MyHomePage()` 是应用的初始页面，是一个有状态的微件，它包含包含可以传递给微件构造函数参数的变量（从上面的代码看，我们传了一个 `title` 变量给初始页面的构造函数）：

```
1.  `class MyHomePage extends StatefulWidget {`
2.  `  MyHomePage({Key key, this.title}) : super(key: key);`
3.  
4.  `  final String title;`
5.  
6.  `  @override`
7.  `  _MyHomePageState createState() => _MyHomePageState();`
8.  `}`
```

有状态微件（`StatefulWidget`）表示这个微件可以拥有自己的状态：`_MyHomePageState`。调用 `_MyHomePageState` 中的 `setState()` 方法，可以重新构建用户界面：

```
1.  `class _MyHomePageState extends State<MyHomePage> {`
2.  ` int _counter = 0; // Number of taps on + button.`
3.  
4.  ` void _incrementCounter() { // Increase number of taps and update UI by calling setState().`
5.  `   setState(() {`
6.  `     _counter++;`
7.  `   });`
8.  ` }`
9.  ` ...`
10.  `}`
```

不管是有状态的，还是无状态的微件，它们都有一个 `build()` 方法，该方法负责微件的 UI 外观。

```
1.  `@override`
2.  `Widget build(BuildContext context) {`
3.  ` return Scaffold( // Page widget.`
4.  `   appBar: AppBar( // Page app bar with title and back button if user can return to previous screen.`
5.  `     title: Text(widget.title), // Text to display page title.`
6.  `   ),`
7.  `   body: Center( // Widget to center child widget.`
8.  `     child: Column( // Display children widgets in column.`
9.  `       mainAxisAlignment: MainAxisAlignment.center,`
10.  `       children: <Widget>[`
11.  `         Text( // Static text.`
12.  `           'You have pushed the button this many times:',`
13.  `         ),`
14.  `         Text( // Text with our taps number.`
15.  `           '$_counter', // $ sign allows us to use variables inside a string.`
16.  `           style: Theme.of(context).textTheme.headline4,// Style of the text, “Theme.of(context)” takes our context and allows us to access our global app theme.`
17.  `         ),`
18.  `       ],`
19.  `     ),`
20.  `   ),`
21.  `        // Floating action button to increment _counter number.`
22.  `   floatingActionButton: FloatingActionButton(`
23.  `     onPressed: _incrementCounter,`
24.  `     tooltip: 'Increment',`
25.  `     child: Icon(Icons.add),`
26.  `   ),`
27.  ` );`
28.  `}`
```

修改你的应用

一个好的做法是，把 `main()` 方法和其他页面的代码分开放到不同的文件中。要想将它们分开，你需要右击 `lib` 目录，然后选择 “New > Dart File” 来创建一个 .dart 文件：

![](../Images/6bdf5f042f58287b4476b6d94a6974d9.png "Create a new Dart file")

*创建一个新的 Dart 文件*

将新建的文件命名为 `items_list_page`。

切换回到 `main.dart` 文件，将 `MyHomePage` 和 `_MyHomePageState` 中的代码，剪切并粘贴到我们新建的文件。然后将光标放到 `StatefulWidget` 上（下面红色的下划线处）, 按 `Alt+Enter` 后出现下拉列表，然后选择 `package:flutter/material.dart`：

![](../Images/68fb7cf31d4dcf51ed0b59a5d7cea5cb.png "Importing Flutter package")

*导入 Flutter 包*

经过上面的操作我们将 `flutter/material.dart` 包添加到了 `main.dart` 文件中，这样我们就可以使用 Flutter 提供的默认的 material 主题微件。

然后, 在类名 `MyHomePage` 右击，“Refactor > Rename...”将其重命名为 `ItemsListPage`：

![](../Images/16130e107ba022c831f2b394575b69df.png "Renaming StatefulWidget class")

*重命名 StatefulWidget 类*

Flutter 识别到你重命名了 `StatefulWidget` 类，它会自动将它的 `State` 类也跟着重命名:

![](../Images/3fb216c50c186e172523bd4816377b87.png "State class renamed automatically")

*State 类被自动重命名*

回到 `main.dart` 文件，将文件名 `MyHomePage` 改为 `ItemsListPage`。一旦你开始输入, 你的 Flutter 集成开发环境（可能是 IntelliJ IDEA 社区版、Android Studio 和 VS Code 或 VSCodium），会给出自动代码补完的建议。

![](../Images/b32ce0d8fcef9abe9e4ea07298089e4a.png "IDE suggests autocompleting code")

*IDE 建议自动补完的代码*

按回车键即可完成输入，缺失的导入语句会被自动添加到文件的顶部。

![](../Images/616c0929a3858375dac670a0194d2b26.png "Adding missing import")

*添加缺失的导入语句*

到此，你已经完成了初始设置。现在你需要在 `lib` 目录创建一个新的 .dart 文件，命名为 `item_model`。（注意，类命是大写驼峰命名，一般的文件名是下划线分割的命名。）然后粘贴下面的代码到新的文件中：

```
1.  `/// Class that stores list item info:`
2.  `/// [id] - unique identifier, number.`
3.  `/// [icon] - icon to display in UI.`
4.  `/// [title] - text title of the item.`
5.  `/// [description] - text description of the item.`
6.  `class ItemModel {`
7.  ` // class constructor`
8.  ` ItemModel(this.id, this.icon, this.title, this.description);`
9.  
10.  ` // class fields`
11.  ` final int id;`
12.  ` final IconData icon;`
13.  ` final String title;`
14.  ` final String description;`
15.  `}`
```

回到 `items_list_page.dart` 文件，将已有的 `_ItemsListPageState` 代码替换为下面的代码:

```
1.  `class _ItemsListPageState extends State<ItemsListPage> {`
2.  
3.  `// Hard-coded list of [ItemModel] to be displayed on our page.`
4.  ` final List<ItemModel> _items = [`
5.  `   ItemModel(0, Icons.account_balance, 'Balance', 'Some info'),`
6.  `   ItemModel(1, Icons.account_balance_wallet, 'Balance wallet', 'Some info'),`
7.  `   ItemModel(2, Icons.alarm, 'Alarm', 'Some info'),`
8.  `   ItemModel(3, Icons.my_location, 'My location', 'Some info'),`
9.  `   ItemModel(4, Icons.laptop, 'Laptop', 'Some info'),`
10.  `   ItemModel(5, Icons.backup, 'Backup', 'Some info'),`
11.  `   ItemModel(6, Icons.settings, 'Settings', 'Some info'),`
12.  `   ItemModel(7, Icons.call, 'Call', 'Some info'),`
13.  `   ItemModel(8, Icons.restore, 'Restore', 'Some info'),`
14.  `   ItemModel(9, Icons.camera_alt, 'Camera', 'Some info'),`
15.  ` ];`
16.  
17.  ` @override`
18.  ` Widget build(BuildContext context) {`
19.  `   return Scaffold(`
20.  `       appBar: AppBar(`
21.  `         title: Text(widget.title),`
22.  `       ),`
23.  `       body: ListView.builder( // Widget which creates [ItemWidget] in scrollable list.`
24.  `         itemCount: _items.length, // Number of widget to be created.`
25.  `         itemBuilder: (context, itemIndex) => // Builder function for every item with index.`
26.  `             ItemWidget(_items[itemIndex], () {`
27.  `           _onItemTap(context, itemIndex);`
28.  `         }),`
29.  `       ));`
30.  ` }`
31.  
32.  ` // Method which uses BuildContext to push (open) new MaterialPageRoute (representation of the screen in Flutter navigation model) with ItemDetailsPage (StateFullWidget with UI for page) in builder.`
33.  ` _onItemTap(BuildContext context, int itemIndex) {`
34.  `   Navigator.of(context).push(MaterialPageRoute(`
35.  `       builder: (context) => ItemDetailsPage(_items[itemIndex])));`
36.  ` }`
37.  `}`
38.  
39.  
40.  `// StatelessWidget with UI for our ItemModel-s in ListView.`
41.  `class ItemWidget extends StatelessWidget {`
42.  ` const ItemWidget(this.model, this.onItemTap, {Key key}) : super(key: key);`
43.  
44.  ` final ItemModel model;`
45.  ` final Function onItemTap;`
46.  
47.  ` @override`
48.  ` Widget build(BuildContext context) {`
49.  `   return InkWell( // Enables taps for child and add ripple effect when child widget is long pressed.`
50.  `     onTap: onItemTap,`
51.  `     child: ListTile( // Useful standard widget for displaying something in ListView.`
52.  `       leading: Icon(model.icon),`
53.  `       title: Text(model.title),`
54.  `     ),`
55.  `   );`
56.  ` }`
57.  `}`
```

为了提高代码的可读性，可以考虑将 `ItemWidget` 作为一个单独的文件放到 `lib` 目录中。

现在唯一缺少的是 `ItemDetailsPage` 类。在 `lib` 目录中我们创建一个新文件并命名为 `item_details_page`。然后将下面的代码拷贝进去：

```
1.  `import 'package:flutter/material.dart';`
2.  
3.  `import 'item_model.dart';`
4.  
5.  `/// Widget for displaying detailed info of [ItemModel]`
6.  `class ItemDetailsPage extends StatefulWidget {`
7.  ` final ItemModel model;`
8.  
9.  ` const ItemDetailsPage(this.model, {Key key}) : super(key: key);`
10.  
11.  ` @override`
12.  ` _ItemDetailsPageState createState() => _ItemDetailsPageState();`
13.  `}`
14.  
15.  `class _ItemDetailsPageState extends State<ItemDetailsPage> {`
16.  ` @override`
17.  ` Widget build(BuildContext context) {`
18.  `   return Scaffold(`
19.  `     appBar: AppBar(`
20.  `       title: Text(widget.model.title),`
21.  `     ),`
22.  `     body: Center(`
23.  `       child: Column(`
24.  `         children: [`
25.  `           const SizedBox(height: 16),`
26.  `           Icon(`
27.  `             widget.model.icon,`
28.  `             size: 100,`
29.  `           ),`
30.  `           const SizedBox(height: 16),`
31.  `           Text(`
32.  `             'Item description: ${widget.model.description}',`
33.  `             style: TextStyle(fontSize: 18),`
34.  `           )`
35.  `         ],`
36.  `       ),`
37.  `     ),`
38.  `   );`
39.  ` }`
40.  `}`
```

上面的代码几乎没什么新东西，不过要注意的是 `_ItemDetailsPageState` 里使用了 `widget.item.title` 这样的语句，它让我们可以从有状态类中引用到其对应的微件（`StatefulWidget`）。

![](../Images/e6fa15b8dc6f2b925f83e5fd7d4923da.png)

添加一些动画

现在让我们来添加一些基础的动画：

1. 找到 `ItemWidget` 代码块（或者文件）2. 将光标放到 `build()` 方法中的 `Icon()` 微件上3. 按 `Alt+Enter`，然后选择“Wrap with widget...”

![](../Images/e8da6efc57f3d608e02ff02a81fb28bc.png "Wrap with widget option")

*查看微件选项*

输入 `Hero`，然后从建议的下拉列表中选择 `Hero((Key key, @required this, tag, this.create))`：

![](../Images/d798f2bcd4d1bfee14ffce0f81d63b63.png "Finding the Hero widget")

*查找 Hero 微件*

下一步, 给 Hero 微件添加 `tag` 属性 `tag: model.id`：

![](../Images/78b49c3feb46f5921a04998a6d0b7234.png "Adding the tag property model.id to the Hero widget")

*在 Hero 微件上添加 tag 属性为 model.id*

最后我们在 `item_details_page.dart` 文件中做相同的修改：

![](../Images/393a1a9e925e9a538509ce12bc1b2f3b.png "Changing item_details_page.dart file")

*修改item\_details\_page.dart文件*

前面的步骤，其实我们是用 `Hero()` 微件对 `Icon()` 微件进行了封装。还记得吗？前面我们定义 `ItemModel` 类时，定义了一个 `id field`，但没有在任何地方使用到。因为 Hero 微件会为其每个子微件添加一个唯一的标签。当 Hero 检测到不同页面（`MaterialPageRoute`）中存在相同标签的 Hero 时，它会自动在这些不同的页面中应用过渡动画。

可以在安卓模拟器或物理设备上运行我们的应用来测试这个动画。当你打开或者关闭列表项的详情页时，你会看到一个漂亮的图标动画：

![](../Images/0b70f75b5c48ca05de99ca82365c8563.png "Testing the Flutter app")
