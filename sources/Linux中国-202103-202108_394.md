# 优麒麟 20.04 LTS Pro 发布

北京时间 2021 年 4 月 22 日，优麒麟团队很高兴地宣布优麒麟（Ubuntu Kylin）开源操作系统 20.04 LTS Pro 版本正式发布。优麒麟 20.04 Pro 是基于 20.04 长期支持版本的更新，官方将提供 5 年的技术支持。

优麒麟 20.04 Pro 版本默认搭载最新 **Linux 5.10 LTS **内核，新增自主研发的**麒麟音乐、麒麟录音、麒麟摄像头、麒麟桌面安装程序、麒麟蓝牙、麒麟传书、麒麟U盘启动器、麒麟计算器、麒麟扫描**等** 9** 款应用软件。通过进一步优化动画效果、重构主题框架控件样式，带来更酷炫更统一的视觉体验。同时，默认集成 **26** 个 CVE 漏洞修复补丁，修复大量桌面环境和应用软件方面等已知问题，大幅提升系统稳定性和安全性，从而为用户提供更加高效稳定的使用体验。欢迎小伙伴们下载使用，并反馈您的使用体验和优化意见。

全新内核升级

  

集成最新 Linux 5.10 LTS 版本内核，带来了许多功能增强和更多的设备支持。同时，提供 Linux 5.4 LTS 版本内核，用户可以在 Grub 界面选择任一版本内核进行体验，满足更多场景下的用户使用需求，进一步提升系统的兼容性。

![](../Images/eae5fd8b30d4aa432963e4f57f185736.png)

Linux 5.10 LTS 重要更新：

*   支持 SoundBlaster AE-7 ；
    

*   支持 Nintendo Switch Joy Cons 和 Pro 控制器；  
    
*   支持 Sega Saturn 控制器；
    

*   提供对 AMD Zen3 处理器的硬件监视支持；
    
*   提供对联想 X1 平板电脑轨迹点和按钮的多点触摸支持；
    
*   提供对即将推出的 USB 4 规范的成熟支持；
    
*   Tiger Lake GPU 改进；
    

**系统性能提升**  

通过优化桌面组件和应用的资源调度策略，充分利用硬件的调节接口，降低系统功耗。同时，通过深度优化桌面组件和应用的内存占用，提升系统运行流畅度，增强系统整体性能，为更多入门级设备提供澎湃动力，带来更高效的使用体验。  

![](../Images/30afb09682ccb4c94c04d663f09dcd07.png)

**麒麟桌面安装程序**

全新的桌面安装程序对 UI 界面进行改版，同时大幅提升安装速度，优化安装体验，不仅让萌新小白们轻松上手优麒麟，同时也让一直陪伴优麒麟的小伙伴们眼前一亮。  

![](../Images/bffc7c56f4a62338c4d096659d11d617.png)

**麒麟软件商店**  

  

经过UI升级和功能重构后，麒麟软件商店在用户可视性方面做到了化繁为简，提高了页面利用率。并且在新版麒麟软件商店中应用的下载更加容易、应用的管理也更加轻松便捷。

![](../Images/3256be729ad8d862fad22f7809f9a0bd.png)

**麒麟音乐**

基于 QT5 开发的一款简单音乐播放器，它涵盖了多种音频格式的播放工具，界面简单，操作快捷。支持自定义歌单，小窗口模式等功能。

![](../Images/154c173cf31fb9e80a08e38af5d3bc2a.png)

**麒麟录音**基于 QT 开发的一款简单易用的录音软件，支持 MP3 和 WAV 等音频格式，支持文件列表的播放和删除。相较于同类录音软件，具有 mini 模式和实时显示声音频率大小等功能，多方位满足您的录音需求。  
![](../Images/b5f200375ad771489334dfe321922614.png)**麒麟摄像头**

基于 V4l2 开发的相机应用，操作简单，界面友好，支持绝大多数摄像头设备，具有拍照和录像以及在相册中显示照片的功能。  

![](../Images/30e32b75098f528d97703c5b5af222bf.png)

优麒麟团队不断加大应用生态的投入力度，已自主研发 20 余款麒麟系列应用，此次新版本中除以上 3 款媒体应用外，还带来了 6 款用户需求较高的自研应用，将为大家的工作和生活提供便利和帮助：

  
![](../Images/4689ce827a93f749480360896f69b40a.png)**丰富应用生态**

为积极解决用户生态问题，在优麒麟 20.04 Pro 版本中，软件商店上架了QQ音乐、腾讯视频、百度网盘、百度输入法、迅雷下载、360 浏览器等近 **30 **款三方主流软件，并提供 Crossover 解决方案，使优麒麟能够兼容运行 Windows 应用，进一步丰富优麒麟的生态软件。

![](../Images/dc5a3519caf92c32ba27481cca2a9176.png)**更新方式**

目前，优麒麟用户和其他 Linux 爱好者均可以通过优麒麟官网或镜像站在线下载安装优麒麟 20.04 LTS Pro 版本。

1\. 通过官网下载安装：

https://www.ubuntukylin.com/downloads/

麒麟桌面安装程序注意事项：

1）多系统安装请注意备份好重要数据；

2）Windows用户多系统安装时，需关闭 BitLocker 功能；

3）不支持加密和逻辑卷；

4）不支持设置为系统保留用户名（如root）；

5）如安装失败，可进入试用模式，选择开始菜单中ubiquity程序进行安装。2\. 已装 20.04 和 20.04.1 正式版的用户直接升级：  

$ sudo apt update

$ sudo apt full-upgrade

  
  
  
  
  

优麒麟官方一直积极从各个渠道汇总大家的反馈建议，并针对存在的问题进行记录和处理。对于系统使用过程中遇到的任何问题或者建议，欢迎大家通过系统中用户反馈程序、微信交流群、QQ交流群、官方邮箱、优麒麟社区论坛等方式反馈。官方将根据各组件新增功能及bug修复的情况不定期发布系统更新，让我们一起努力，打造更好用的 Linux 桌面操作系统！

  

温馨提醒：

为了优麒麟用户更好的使用体验，及时获取技术支持和问题反馈，今后优麒麟操作系统将重点维护长期支持版本。建议优麒麟用户将历史版本或短期支持版本升级至最新长期支持版本，以获得优麒麟开源操作系统最佳的使用效果。
