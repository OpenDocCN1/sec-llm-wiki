深度 20.3🔗 news.itsfoss.com 已经发布了一段时间，做了一些基本的改进和细微的视觉变化。

但是，如果你想在 Ubuntu 上面获得最新的深度桌面体验？UbuntuDDE Remix 21.10 “Impirish Indri” 终于登场了。

这可能是新年伊始第一周中令人兴奋的发布之一吧？

![](../Images/2b07d0de45842cb3401a7bbfe9e3cca9.png)

UbuntuDDE Remix 21.10：有什么新内容？

该版本的关键亮点是增加了最新的深度桌面。你应该还会发现一个更新的 Linux 内核、Calamares 安装程序、更新的应用程序、新的壁纸，以及其他改进。

下面让我介绍一下这些基本的变化。

![](../Images/2b07d0de45842cb3401a7bbfe9e3cca9.png)

Ubuntu 21.10 & Linux 内核 5.13

![](../Images/fbde383c6bdc97996d65374d73103966.png)

Linux 内核 5.13🔗 news.itsfoss.com 是一个必不可少的升级，它包括了一些硬件改进和安全增强。

具体来说，UbuntuDDE Remix 21.10 采用了 Linux 内核 5.13.0-22。

而且，这是建立在 Ubuntu 21.10🔗 news.itsfoss.com 的基础上的。因此，在这里你也可以得到 Ubuntu 21.10 的改进和功能。

![](../Images/2b07d0de45842cb3401a7bbfe9e3cca9.png)

最新的深度桌面环境

有了最新的深度桌面，你也可以期待最新的软件包，包括更新的深度商店等等。

![](../Images/4bc4f5e6ea68d1a1baa72b8585f5edfd.png)

新的壁纸应该可以让你使桌面看起来很有美感。

![](../Images/e97a61dccc56cb6305f9cf7c507dd998.png)

![](../Images/2b07d0de45842cb3401a7bbfe9e3cca9.png)

更新的软件包

Firefox 95.0 是默认的网页浏览器。LibreOffice 7.2.3.2 是默认的办公应用程序。

此外，你会发现其他几个与深度操作系统相关的软件包已经更新到最新版本。

![](../Images/2b07d0de45842cb3401a7bbfe9e3cca9.png)

其他改进措施

不仅仅限于新增加的内容，你还会发现针对 UbuntuDDE 和上游深度桌面体验的错误修复。

你可以通过 官方公告博文🔗 ubuntudde.com 了解更多关于该版本的信息。

![](../Images/2b07d0de45842cb3401a7bbfe9e3cca9.png)

下载 UbuntuDDE Remix 21.10

你可以从其官方网站上抓取 ISO 文件并安装。如果你想了解任何已知的问题，或获得帮助，你可以看看他们的 论坛或群组🔗 ubuntudde.com。
