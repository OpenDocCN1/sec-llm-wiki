2021 年 12 月 29 日，在优麒麟社区和海河实验室研发团队的共同努力下，首个支持 RISC-V 架构的 Ubuntu Kylin 20.04 Pro 版本终于发布啦！

RISC-V

作为首个可以完全自由免费使用的架构，RISC-V 容许添加自有指令集拓展以实现差异化发展，在近年越来越受大家的青睐。这也是我们开发 Ubuntu Kylin 20.04 Pro RISC-V 版本的初衷，给企业和开发者提供一个不受限制的使用环境。

当然，虽然 RISC-V 有着如此明显的架构优势，但其短板也很明显，那就是应用生态系统不够完善。此次优麒麟 RISC-V 版本的发布，自带 20 多款自研软件，在一定程度上丰富了 RISC-V 应用生态系统，为使用 RISC-V 的开发者和企业提供一定的便利，而未来我们也会持续的致力于 RISC-V 的生态系统建设，为其带来更多的可能性。

版本特性

1. 全新的内核：Linux Kernel 5.11 版本
2. 稳定的工具链：glibc 2.31、OpenJDK 11、rustc 1.41、GCC 9.3、Python 3.8、ruby 2.7.0、perl 5.30、golang 1.13、Qt 5.12
3. 美观的桌面环境：UKUI 3.0
4. 丰富的桌面应用：浏览器 epihany-brower 3.36.4、办公套件 calligra 3.1.0，以及麒麟系列应用

正在修复的已知问题

1. 控制面板修改密码后，授权窗密码仍为原密码
2. 只有一个用户的时候显示用户类型为标准用户
3. 无法重启、关机、休眠、睡眠
4. 使用过程中偶现键鼠失灵（推荐把键盘插在 USB CONN 1 下层接口，出现问题后需要重新拔插键盘/鼠标）
5. 用 win+方向键调整文本编辑器位置后关闭再打开，编辑器大小改变

目前 Ubuntu Kylin 20.04 Pro RISC-V 版本已在官网 https://www.ubuntukylin.com/downloads/ 上线，欢迎各位爱好者下载体验！
