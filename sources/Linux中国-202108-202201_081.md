Pop!\_OS 无疑是 最好的 Linux 发行版🔗 itsfoss.com 之一，也是目前面向 Linux 新手（和游戏玩家）推荐的热门选择之一。

如果你不喜欢非 LTS 版本，你应该坚持使用 Pop!\_OS 20.04 LTS🔗 itsfoss.com。但是，如果你想看看最新和最棒的更新，那么，Pop!\_OS 21.10 终于就绪，可以下载了！

别忘了，Pop!\_OS 21.10 的发布是为明年 4 月的 Pop!\_OS 22.04 LTS 的潜在功能清单打的前站，你可以期待一下。

![](../Images/c9ca99fa7c76d87b0b7e603d18db3e45.png)

Pop!\_OS 21.10 有什么新功能？

请注意，即使 Pop!\_OS 21.10 将 GNOME 40 作为最重要的变化之一，也应该会有类似于 Pop!\_OS 21.04 的 COSMIC 桌面体验🔗 news.itsfoss.com。

也就是说，在 Pop!\_OS 21.10 中有一些关键的变化，应该会增强你的 Linux 桌面体验，并使你更轻松。

![](../Images/c9ca99fa7c76d87b0b7e603d18db3e45.png)

新的应用程序库

在 Pop!\_OS 21.10 中，全屏应用程序菜单已被一个单独的可搜索窗口取代。这应该不那么碍事，而且很方便。

![](../Images/b013686ee7f3f24e93674dab232b55e2.png)

这不仅仅是 System76 对 GNOME 40 的独特调整，在功能上它应该比传统的全屏应用菜单提供更多的好处。

例如，新的应用程序库应该可以增强多显示器的体验，让你在你关注的屏幕中快速搜索一个应用程序，而不是占用整个屏幕。

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_2180458283474485249](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_2180458283474485249)

它还可以让你快速搜索应用程序（或根据你的搜索查询过滤它们）。不仅仅限于已安装的应用程序，它还会显示可以使用 Pop!\_Shop 安装的应用程序。

![](../Images/698805d1da5890f506dc0a76ae1e5b55.png)

你可以使用工作区右侧的 “应用程序(Applications)” 按钮访问应用程序库，或执行四指向右滑动，按 `Super+A` 也行。

![](../Images/c9ca99fa7c76d87b0b7e603d18db3e45.png)

System76 用自己的存储库取代 Launchpad

如果你一直在关注我们，你可能已经知道了 System76 将 PPA 软件库转移到其系统之中🔗 news.itsfoss.com。

![](../Images/12124a4192e78a95ecd24d4c7d7f09f5.png)

总的来说，这应该有助于他们控制软件包，并比 Ubuntu/Canonical 的默认仓库更快地推送更新。

![](../Images/c9ca99fa7c76d87b0b7e603d18db3e45.png)

GNOME 更新

从 GNOME 3.38.4 跳到 40 应该会引入几个 GNOME 40 改进🔗 news.itsfoss.com，至少对核心应用程序是这样。

一些值得注意的改进包括设置中的 Wi-Fi 排序，这意味着，可用的网络将按照活动连接、先前连接和信号强度的顺序显示，以按有用顺序呈现可用 Wi-Fi 网络。

你还可以注意到在你搜索某些东西后，文件中的自动补全功能。

![](../Images/c9ca99fa7c76d87b0b7e603d18db3e45.png)

最新的 Linux 内核及 NVIDIA 驱动程序

![](../Images/bb6be8ea3160cf378102be43e9e1f1a9.png)

众所周知，Pop!\_OS 比许多其他发行版更快地推送最新的 Linux 内核。Pop!\_OS 21.04 已经在运行 Linux 内核 5.15🔗 news.itsfoss.com，而 Pop!\_OS 21.10 继续使用它。

在这里，Pop!\_OS 21.10 带来了 Linux 内核 5.15.5，并且还打包了最新的可用 NVIDIA 驱动程序，以便与较新的硬件保持最佳的兼容性。

![](../Images/c9ca99fa7c76d87b0b7e603d18db3e45.png)

全新安装

![](../Images/61d95e24ea353a56c1f7650c95897176.png)

每当 Pop!\_OS 从恢复分区安装时，它让你选择“全新安装(Refresh Install)”。

通过这种方式，你可以重新安装 Pop!\_OS，而不会丢失主目录中的文件。如果有什么东西不能工作，而你又不能排除故障，重新安装应该会使事情恢复到默认状态，这时它就会派上用场。

![](../Images/c9ca99fa7c76d87b0b7e603d18db3e45.png)

对 Pop!\_OS 升级的改进

![](../Images/718eba0eb21cc80bae239cb91d8953c9.png)

*如果你没有设置任何东西，为用户显示的一个新的默认图标*

通过 Pop!\_OS 21.10，你还会有更好的升级体验。

为了方便起见，Pop!\_OS 在升级发行版时对其行为做了一些改变。其中一些是：

◈ 自动禁用用户添加的 PPA 以避免升级冲突。◈ 现在在升级发行版之前会更新恢复分区，如果使用恢复分区第一次没有成功，之一可以给你一个可以轻松地重新安装发行版的媒介。![](../Images/c9ca99fa7c76d87b0b7e603d18db3e45.png)

用于树莓派 4 的技术预览版

截至目前，这还是针对树莓派 4 的实验，但你可以下载 ARM 平台的技术预览版。

他们计划在未来的 Pop!\_OS 版本中引入 Pop!\_Pi。

![](../Images/c9ca99fa7c76d87b0b7e603d18db3e45.png)

关于 Pop!\_OS 21.10 的想法

Pop!\_OS 一直在努力使桌面 Linux 的体验尽可能可靠，同时拥有一些最新的软件包。

通过 Pop!\_OS 21.10，更新的桌面环境、Linux 内核和可用性改进使这次升级变得有用。

如果你正在使用一个非 LTS 版本，你肯定应该考虑尽快升级。请注意，在你进行升级之前，你应该备份你的数据。

![](../Images/c9ca99fa7c76d87b0b7e603d18db3e45.png)

下载 Pop!\_OS 21.10

你可以找到两种用于 Pop!\_OS 21.10 的不同 ISO ，一种用于 NVIDIA，另一种用于 Intel/AMD。

请前往 官方下载🔗 pop.system76.com 页面，下载你需要的 ISO。

如果你已经安装了 Pop!\_OS 21.04，在他们的官方公告之后，你应该很快收到升级通知，或者前往系统设置并应用升级。

如果你使用的是终端，输入以下命令：

```
1.  `sudo apt update`
2.  `sudo apt full-upgrade`
3.  `pop-upgrade release upgrade`
```

你也可以阅读他们 官方公告帖子🔗 blog.system76.com 中提到的细节。
