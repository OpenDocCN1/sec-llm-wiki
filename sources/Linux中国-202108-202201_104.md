> GNOME 新的“文本编辑器”正在增加新的功能，有可能在下一个 GNOME 桌面版本中取代 Gedit。

Gedit 是 GNOME 桌面环境的默认文本编辑器。它是一个受欢迎的编辑器，也是一个便捷的文本编辑器，以简单的用户界面提供了所有的基本功能。

但是，随着 GNOME 的发展，有了一个新的“文本编辑器”（LCTT 译注：没错，就叫“文本编辑器(Text Editor)”），虽然它还没有取代 Gedit。但让我们来看看它的下一个版本，在即将到来的 GNOME 42 版本中，它进行了大量改进，有可能取代 Gedit。

Christian Hergert🔗 twitter.com 在他的 博文🔗 blogs.gnome.org 和 Twitter 上分享了它的很多细节。

在这篇文章中，让我介绍一下 GNOME 文本编辑器的那些新改进。

![](../Images/72cc485d6890c6b3b7a9bbe4d5455174.png)

偏好设置对话框卷土重来

作为其上一个版本中的实验的一部分，偏好设置对话框被移到了侧边栏，

![](../Images/d3b37cd8b63369ade3aed81f39a5d9d7.png)

但是，事实证明，它并不那么方便和好看。

因此，偏好设置对话框又回来了（如下图所示），其目的是与其他 GNOME 应用程序的设计语言相融合，而不显得笨拙。

![](../Images/752573c4b27401be4a8a001b73e570e4.png)

*鸣谢：Christian Hergert*

在我看来，这很不错，与侧边栏的实施相比，应该用户体验更好。

![](../Images/72cc485d6890c6b3b7a9bbe4d5455174.png)

改进的 “弹出式” 打开功能

![](../Images/93fefce4f11ede76173afc1b6b5712f9.png)

*鸣谢：Christian Hergert*

当你试图打开一个最近的文件或搜索某个东西时，会出现一个弹出式窗口来快速查找任何最近的文件，而不需要启动一个新的对话框。

这节省了时间，是一个不错的功能。在即将发布的“文本编辑器”中还进行了一些细微的改进，显得更苗条、更便捷。

换句话说，你会发现它改进了键盘导航，只需按下 `Ctrl + K`，就可以寻找你想要的文件。

![](../Images/72cc485d6890c6b3b7a9bbe4d5455174.png)

引入重新着色支持

即将发布的 GNOME 文本编辑器可以让你轻松地应用不同的风格模式（或主题），而改变整个应用程序。

博文中提到了更多关于它的内容：

> 本周最直观的工作是引入了重新着色支持。它建立在 libadwaita🔗 gnome.pages.gitlab.gnome.org 之上，并使用一个 CSS 提供者来覆盖主题中的颜色。我希望在不远的将来，libadwaita 会有一个重新着色的 API，为我们提供这个功能。

下面是一个应用样式表时的例子：

![](../Images/6dde7689b18caeac4677e0e0b9fa0d3e.png)

*鸣谢：Christian Hergert*

它有一些自带的主题，而且你还可以找到更多的主题。你可以在 Christian 的博客文章中找到更多截图：

![](../Images/0287461751ac2e036baf129cdadc72dd.png)

*鸣谢：Christian Hergert*

你可以看看 博客文章中的更多内容🔗 blogs.gnome.org，还可以发现一些其他的技术变化，和一个由 Christian 设计的 vim 仿真的复活节彩蛋。

![](../Images/72cc485d6890c6b3b7a9bbe4d5455174.png)

GNOME “文本编辑器”会取代 Gedit 吗？

到现在为止，官方还没有确认这一点。然而，看一下 Gedit 的开发活动🔗 gitlab.gnome.org（目前有 41 个 alpha 版本），在过去的几个版本中没有明显增加变化，这可能意味着新的 GNOME “文本编辑器”将在GNOME 42 中取代 Gedit。

事实上，正如其 GitLab 页面🔗 gitlab.gnome.org 中所提到的，GNOME 的新文本编辑器计划正式取代 Gedit，但它会在 GNOME 42 中发生吗？它的开发者 Christian Hergert 在他的博客中提到：

> 随着我们为 GNOME 42 的准备工作而进行的竞赛，文本编辑器🔗 gitlab.gnome.org 在过去的几周里已经成型。

这可以被认为是一个暗示，GNOME 42 可能会包含这个新的文本编辑器。

不仅仅是 GNOME，KDE 也对 Kate 进行了改造🔗 news.itsfoss.com，增加了针对开发者的功能。你将会有很多 开源的文本编辑器🔗 itsfoss.com 可以选择。

当它发布时，我们将继续关注它。你怎么看？
