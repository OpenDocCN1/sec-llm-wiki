谷歌的 UI 工具包 Flutter 在创建移动、网页和桌面的跨平台应用程序方面越来越受欢迎。

Flutter🔗 flutter.dev 不是一种编程语言，而是一个软件开发工具包。Dart🔗 dart.dev 是 Flutter SDK 下面使用的编程语言。

Flutter 是谷歌开源的 Fuchsia OS、谷歌 STADIA 以及许多其他软件和移动应用背后的主要框架。

如果你想使用 Flutter 进行开发，本教程将帮助你在 Ubuntu 和其他类似 Linux 发行版上搭建好你的环境。

![](../Images/8b0b76602f5c98c55f0b92a4f12e2206.png)

在 Ubuntu 和其他 Linux 上用 Snap 安装 Flutter

在 Linux 上安装 Flutter 最简单的方法是使用 Snap。如果你使用的是 Ubuntu，你已经有了 Snap。对于其他发行版，请确保 启用 Snap 支持🔗 itsfoss.com。

打开终端🔗 itsfoss.com 并在终端中使用以下命令来安装 Flutter：

```
1.  `sudo snap install flutter --classic`
```

你会在你的终端上看到类似这样的东西：

![](../Images/18b3f16b5597d90ba1bd85240e6e2cd3.png)

一旦安装完成，就是验证它的时候了。不仅仅是 Flutter 的安装，还要验证 Flutter 正常运行所需满足的每一个依赖关系。

![](../Images/8b0b76602f5c98c55f0b92a4f12e2206.png)

验证 Flutter 的依赖项

为了验证 Flutter 正确工作所需的每一个依赖项，Flutter 有一个内置选项：

```
1.  `Flutter doctor`
```

这个过程开始看起来像这样：

![](../Images/a7ca144cddb2d284b9ba18a42e268d46.png)

而它完成时像这样：

![](../Images/cb0eab74432e80260be0ace7e12e2885.png)

正如你所看到的，我们需要 Android Studio 来工作。所以让我们来安装它。我们该怎么做呢？用 Snap在 Linux 上安装 Android Studio🔗 itsfoss.com 也是毫不费力的。

![](../Images/8b0b76602f5c98c55f0b92a4f12e2206.png)

安装并设置好 Android Studio

在终端中，使用下面的命令来安装 Android Studio：

```
1.  `sudo snap install android-studio --classic`
```

![](../Images/5ea45bc0c58a0119a60c0ad02d9fa71d.png)

安装完毕后，从我们的操作系统菜单中打开 Android Studio。

![](../Images/a1afa89d3c2fd07db4e6f71a6a0bf6df.png)

就快完成了。现在是配置 Android Studio 的时候了。

![](../Images/fbbb7c150f719530e2bddc3e996879e4.png)

点击下一步，如果你不想让事情复杂化，就选择“标准(standard)”。

![](../Images/1aa792d0c4405bf7b346ac8600cbd4af.png)

选择你喜欢的主题（我喜欢“暗色(Darcula)”的）。

![](../Images/6ab2af2ab8fb05a41770c75e984f9a84.png)

确认一切正常，然后点击“下一步(Next)”。

![](../Images/a940da3de322c883b988549acab625d2.png)

最后，点击“完成(Finish)”按钮。

![](../Images/4e168d7f8249b05cd9f719a3f313964b.png)

然后等待，直到下载完成。

![](../Images/1ffe169f4b82fe5f31cf4d79cc551d19.png)

![](../Images/8b0b76602f5c98c55f0b92a4f12e2206.png)

创建一个 Hello World Flutter 应用样本

在 Android Studio 中，进入项目，选择“新建 Flutter 项目(New Flutter Project)”。Flutter SDK 路径会默认设置。

![](../Images/5c742acc2331313626d7ff622057eacd.png)

在这里，神奇的事情开始出现了，这是你设置你的项目名称的地方，在这个例子中，它将被称为 “hello\_world”。

让我们选择三个可用的平台。Android、iOS 和 Web。最后，点击“完成(Finish)”。

![](../Images/937dc21006a0ce863205d1bb4ea0bb61.png)

项目中的主文件位于 `lib/main.dart`，如下图所示：

![](../Images/6ed9b5386a6172a6afa792b92fcc6111.png)

选定后，擦除文件中包含的所有内容，并将其改为本示例代码：

```
1.  `// Copyright 2018 The Flutter team. All rights reserved.`
2.  `// Use of this source code is governed by a BSD-style license that can be`
3.  `// found in the LICENSE file.`
4.  
5.  `import 'package:flutter/material.dart';`
6.  
7.  `void main() => runApp(MyApp());`
8.  
9.  `class MyApp extends StatelessWidget {`
10.  `  @override`
11.  `  Widget build(BuildContext context) {`
12.  `    return MaterialApp(`
13.  `      title: 'Welcome to Flutter',`
14.  `      home: Scaffold(`
15.  `        appBar: AppBar(`
16.  `          title: const Text('Welcome to Flutter'),`
17.  `        ),`
18.  `        body: const Center(`
19.  `          child: Text('Hello World'),`
20.  `        ),`
21.  `      ),`
22.  `    );`
23.  `  }`
24.  `}`
```

重要的是，这只是向你展示 Flutter 是如何工作的，如果你确信要学习这种美丽而不可思议的语言，这里有 文档🔗 flutter.dev 可以看到更多关于它的信息。尝试它！

最后，选择 “Chome Web” 设备，并点击“运行(Run)”按钮，如下图所示；并看到神奇的效果！

![](../Images/3952861b39bf6477b225e6280b8fa7e5.png)

你可以如此快速地创建一个 Flutter 项目，真是不可思议。跟你的 Hello World 项目打个招呼吧。

![](../Images/e3d3b4fd5a0fa9570f456547175debfd.png)

![](../Images/8b0b76602f5c98c55f0b92a4f12e2206.png)
