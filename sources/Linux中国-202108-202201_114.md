在任何的 Linux 发行版上，你都有近乎无限的定制选项，在视觉上最明显的区别就是定制的主题。让我们来看看一些具有深色模式的 GTK 主题。

是的，我们在过去曾介绍过 最佳 Linux 主题🔗 itsfoss.com，但这一篇是专门介绍深色主题的。曾几何时，只有程序员和系统管理员喜欢深色模式，但现在已经不是这样了。深色模式也受到了普通人的喜爱，因此我为像你这样的 Linux 桌面用户编制了这个深色主题列表。

如果你不熟悉设置桌面环境的主题，你可以看看我们的 在 GNOME 中安装主题🔗 itsfoss.com 指南。

本文仅供参考，这并不是一个排名列表。

![](../Images/1127c2154d8c80e0968c8ea6bab59be5.png)

1、McMojave

![](../Images/bc8b7aa58b46dc7c3f8451f939a3e4b2.png)

*The stock image of how McMojave looks*

McMojave🔗 github.com 是一个 GTK 主题，其灵感来自于 macOS 风格的用户界面。显然这个主题是提供给深色模式的，但它也有浅色模式，嗯……，提供给任何可能想要它的人。

McMojave GTK 主题显然支持基于 GTK 的桌面环境，如 Pantheon、Gnome、XFCE、Mate 等。但是，这个主题也 适用于 KDE 用户🔗 github.com。

为了让你的桌面环境看起来与 macOS 非常相似，你还可以安装 McMojave 圆形图标主题🔗 github.com 以获得更完整的体验。

![](../Images/1127c2154d8c80e0968c8ea6bab59be5.png)

2、Yaru

![](../Images/5e90eae52bdfc790288d33196a92a5f8.png)

*A screenshot of the default Yaru theme on Ubuntu 21.10*

Yaru🔗 github.com 是 Ubuntu🔗 ubuntu.com 的默认 GTK（GNOME）主题。该主题的深灰色点缀着橙色，及少许黑色让我觉得很有吸引力。

现在，你可以让 Arch Linux 上的 GNOME 看起来像 Ubuntu。( ͡° ͜ʖ ͡°)

![](../Images/1127c2154d8c80e0968c8ea6bab59be5.png)

3、Pop

![](../Images/c92c0a11d15d7c5cc0b74c12e3b195e3.png)

*A look at how the Pop GTK theme looks on Pop!\_OS*

Pop GTK 主题🔗 github.com 是由 System76🔗 system76.com 为他们基于 Ubuntu 的 Linux 发行版 Pop!\_OS🔗 pop.system76.com 创建的主题。

如果你喜欢 System76 对 GNOME 在深色模式下的表现，你可以在你选择的 Linux 发行版中试用 Pop GTK 主题🔗 github.com。

如果想获得完整的 Pop-esque 的外观和感觉，在安装主题的同时，还可以安装 System76 提供的 Pop 图标🔗 github.com。

![](../Images/1127c2154d8c80e0968c8ea6bab59be5.png)

4、Nordic

![](../Images/f2a861965c2ca90bcbdea7c1190483f0.png)

*Nordic GTK theme preview*

你是一个喜欢简单的、有点扁平化的设计方法以及一些灰色或更多灰色的人吗？不妨看看这个基于 北欧风调色板🔗 github.com 的主题。

Nordic🔗 github.com GTK 主题给你的正是这样的感觉。一个基于北欧风调色板的 GTK 主题，设计简单。

![](../Images/1127c2154d8c80e0968c8ea6bab59be5.png)

5、Ultimate-Maia

![](../Images/4159c0822a1a0b803ac1bcdaa2aa27a5.png)

*Stock screenshot of the Ultimate-Maia theme*

Ultimate-Maia🔗 github.com 是一个基于 Google 的 Material 主题🔗 material.io 设计理念的 GTK 主题。这个主题有一个精细而独特的外观和感觉，特别是有各种不同的强调色可供选择。

![](../Images/1127c2154d8c80e0968c8ea6bab59be5.png)

6、Graphite

![](../Images/5a06a384cb215e2d9b1e09b8fb4b9343.png)

*A look at Graphite’s flat, rounded and gray characteristic*

Graphite🔗 github.com 是一个 GTK 主题，它为你的桌面环境（尤其是 GNOME）提供了一个完全独特的外观，同时保持了你的桌面环境的独特性，就像以前一样。这是一个值得一看的东西。

![](../Images/1127c2154d8c80e0968c8ea6bab59be5.png)

7、Qogir

![](../Images/34fe236a6da4f5811fd546e5f5f27535.png)

*Customization options available with Qogir GTK theme*

Qogir🔗 github.com 是一个采用了扁平化设计的 GTK 主题。Qogir 主题为你提供的不仅仅是标题按钮、复选框、单选按钮、开关等自定义选项。

![](../Images/1127c2154d8c80e0968c8ea6bab59be5.png)

8、Layan

![](../Images/160f2620f89f5bd9cd54afd20f102a4d.png)

*Lyan – A very rounded-corners GTK theme*

你会很高兴知道，这个列表中还包括 Layan🔗 github.com，这是一个强调平滑、圆角的 GTK 主题，带有气泡的美感。Layan 主题也继承了 Google 的 Material 设计🔗 material.io 指导方针的设计理念。

![](../Images/1127c2154d8c80e0968c8ea6bab59be5.png)

9、Juno

![](../Images/5ba95319eb6b6ec5a3c229c89238b2d9.png)

Juno🔗 github.com 是我发现的另一个最好的对深色模式友好的 GTK 主题之一。有些人可能喜欢它的漆黑本质，有些人可能不喜欢。但是，如果你有一台 OLED 笔记本或电脑显示屏，Juno 感觉是为你而生的。

![](../Images/1127c2154d8c80e0968c8ea6bab59be5.png)

10、Ant 主题

![](../Images/8bc1f792a8744cf8239068412052b225.png)

*Ant themes’ available options for customization of window appearance*

Ant🔗 github.com 是一个 GTK 主题，它从 macOS 的布局和用户界面元素中获得了一些灵感，在我看来，Ant 主题很好地实现了这一切。

![](../Images/1127c2154d8c80e0968c8ea6bab59be5.png)

11、Equilux

![](../Images/966ba56ffd3a68ec6daac06fbb14f082.png)

Equilux🔗 github.com 主题给你一个漂亮的主题，带有精细的深色模式。这个主题能很好地与 GNOME 及 GNOME 的复刻融合在一起。我不会太多地描述这个主题，它简单而优雅。

![](../Images/1127c2154d8c80e0968c8ea6bab59be5.png)

12、Orchis-dark

![](../Images/119480768e98403d4f46c7de4013eff6.png)

*Orchis Dark*

Orchis Orchis-dark🔗 www.gnome-look.org 是超酷的 Orchis 主题的深色变体。它为桌面提供了带有圆角和流畅界面的 iOS/macOS 触感。只需看一眼，你就可以立即猜到。

![](../Images/1127c2154d8c80e0968c8ea6bab59be5.png)

13、Elementary X

![](../Images/3ee30f582a0de495448e3dcdbd99e20d.png)

*A look at Elementary X GTK theme with the settings panel open*

Elementary X🔗 github.com 是基于 elementary OS🔗 elementary.io 团队为定制 GNOME 外观而开发的 GTK 主题。顺便说一句，elementary OS 是一个基于 Ubuntu 的 Linux 发行版。

![](../Images/1127c2154d8c80e0968c8ea6bab59be5.png)

总结

这篇文章中列出的主题都是非常漂亮的，而且你的选择也不限于这里列出的那些。还有其他成千上万的主题。
