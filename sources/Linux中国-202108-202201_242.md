Python 作为一个编程语言，具有简单、易学，对运维友好的特性。对于运维工程师来说，学习 Python 可以帮助运维工程师更好的完成运维工作，同时借助 Python 生态，开发出更加强大的 Python 脚本，提升运维和开发的效率。

就在下周，Linux 中国为广大的运维工程师，带来了一个免费的线上训练营。

![](../Images/93d552128fc0158c2e6e9411fdd216e0.png)

为什么需要学习 Python？

对于运维工程师来说，Python 强大的表现力和更易于组织的代码，可以让你的运维工作更加井井有条。你可以用 Python 来更简单地完成过去用 Bash 能做的事情，也可以使用 Python 来完成 Bash 不能或很难完成的事情。不仅如此， Python 的丰富社区支持，可以帮助你完成任何你想要完成的事情。
