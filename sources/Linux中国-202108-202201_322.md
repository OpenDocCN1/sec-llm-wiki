微软允许第三方浏览器在其商店上架

![](../Images/e8667a07372bc8dff4ba27e36e15768a.png)

随着 Windows 11 的推出，微软商店也进行了彻底重构，其中最大的变化之一是微软解除了一些限制。微软已经改变了 关于浏览器引擎的政策🔗 news.softpedia.com，允许浏览器使用自己的引擎在微软商店发布。Mozilla 对这一变化表示赞赏，并说 Firefox 将在今年年底前在微软商店中提供。其他大型浏览器也有可能在微软商店上线，虽然 Google 还没有对此发表看法。此外，微软不再阻止第三方商店在微软商店中上市，所以像 Epic 游戏商店这样的“店中店”也可以下载了。

> 老王点评：微软是越来越开放了，与之形成鲜明对比是水果铺子了。

![](../Images/33684ba6d907498dfadc89ba1f2dc8ea.png)

Canonical 推出适用于嵌入式显示器的 Ubuntu Frame

![](../Images/72ade29b793a77c44451472e741131d3.png)

这款新产品旨在为开发者提供一种方法，使其能够轻松地在信息亭等嵌入式显示器上构建和部署应用程序。据该公司称🔗 ubuntu.com， Ubuntu Frame 意味着开发者不需要集成和维护部分解决方案，如 DRM、KMS、输入协议或安全策略。Ubuntu Frame 与 Flutter、Qt、GTK、Electron 和 SDL2 等工具包兼容，它还为基于 HTML5 和 Java 等的应用程序提供了解决方案。Canonical 称，“它的可靠性已经在现场得到了广泛的测试，相关技术已经开发了 7 年多。”为确保设备在其整个生命周期内得到支持，Ubuntu Frame 将被支持 10 年。

> 老王点评：相比其手机版本，我觉得这种瞄准信息亭的解决方案更有前景。

![](../Images/33684ba6d907498dfadc89ba1f2dc8ea.png)

微软官方提供绕过 TPM 检查安装 Windows 11 的方法

![](../Images/b051740203dface975931f9de29ca4d6.png)

为了避免人们通过使用非标准化的第三方脚本来破坏他们的系统，微软发布了一个 新的支持网页🔗 support.microsoft.com，提供了一个官方方法来绕过 TPM 2.0 和 CPU 检查。但微软一再提醒，在不支持的硬件上安装 Windows 11 伴随着一些隐患。这一方法至少需要 TPM 1.2，但是如果你连这个都没有，还是需要一个第三方的方法来 绕过所有 TPM 检查🔗 gist.github.com。

> 老王点评：强制限制硬件这种做法并不好，如果因为缺乏某些硬件，导致功能和安全性降级，用户应该有自行承担的决定权。
