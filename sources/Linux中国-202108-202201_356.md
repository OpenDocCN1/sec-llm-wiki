Linux 基金会自从 2011 年开始，每年都会启动 LiFT 奖学金计划，为那些有理想、热爱学习的开发者、系统管理员、开源新手等免费提供培训机会，让更多的人了解开源、学习开源、参与开源。2010 年以来，Linux 基金会已经颁发了 1100 多项奖学金，价值数百万美元。

2021 年 LiFT 奖学金评选已经圆满结束了，很多申请者都令人印象深刻，充满着对开源的热情和开源精神。比如正在攻读计算机科学硕士学位的 George Gognadze，George 在格鲁吉亚建立了第一个报告欺凌行为的网络应用程序，并参与了许多当地的技术活动。他希望能够与社区中的其他人分享他从这项奖学金中获得的知识，并开始为更广泛的开源社区做出贡献。 

![](../Images/9655bcd4e64f7fd4153a5921c88eb4a9.png "George Gognadze  LiFT奖学金2021年度得奖者")

*George Gognadze  LiFT奖学金2021年度得奖者*

除了 George 之外，还有很多不同行业、不同社会身份的人想要学习开源，积极加入开源，在不同的领域为开源贡献力量。访问此链接🔗 www.linuxfoundation.org了解更多的获奖者。

Linux 基金会开源软件学园是 Linux 基金会亚太区与开源中国强强联手，共同打造的技术交流平台，核心理念是为中国培养更多的开源软件人才，不断推动国际技术交流和人才交流。人才激励计划旨在为 IT 行业的人才提供开源培训的机会，扩大开源社区内技术的多样性，为 IT 人才成长提供清晰的路径。

2020 年，Linux 基金会开源软件学园人才激励计划在中国首办，受到中国大陆和港澳台地区开发者的广泛支持，最受欢迎的奖学金类别是开源爱好者、开源小白和大学生等。访问此链接🔗 training.linuxfoundation.cn可查看去年优秀入选者。 

2020 年 Linux 基金会开源软件学园人才激励计划涌现出了很多优秀的开源人才，比如易迩山同学，在初中对开源有了模糊的认识，大学时“重新发现”了 GNU/Linux 的自由世界，并且对开源社区的运作方式有了更深的理解。如今，他活跃于 Deepin 和 Manjaro 的论坛，经常在 GitHub 上为开发者们提供反馈，并且在 AUR 上维护着一些软件包。虽然现在他还只是一个非 IT 行业的开源爱好者，但是始终乐意为开源社区贡献自己的一份力量。

2021 年 Linux 基金会开源软件学园人才激励计划进行升级，与去年相比，今年扩大评选人群范围，从社会身份和技术水平对奖学金类别进行分类，无论来自任何行业、从事任何工作，是否和技术有关，只要对技术有兴趣和渴望，填写表单，就有机会入选。 

今年可供选择的奖学金类别有学生、开源萌新、开源老手、技术达人、开源创业者、社区领袖、开源志愿者、女性开源力量共八种，每个人可以根据自己的情况选择符合身份的奖学金类别，填写申请表格。由于奖项评选以表格为主，所以真诚填写会增加获奖可能。

![](../Images/d8d95aef873492db17372cf551568be6.png)

入选者可以在 Linux 基金会开源软件学园中任意选择一门课程学习，并免费参加一次 Linux 基金会提供的任何认证考试，学习和考试费用由 Linux 基金会开源软件学园承担。优秀的申请者还会获得Linux基金会开源软件学园颁发的开源明星奖项。入选者除了能得到奖学金外，还能实现一个开源心愿，如改简历、内推等工作机会、故事分享和社区曝光等媒体资源、成为 GVP 项目、参加公开课和活动。 

Linux基金会开源软件学园人才激励计划为热爱开源的人提供了进修机会和展示的平台，每个人都有可能获得奖学金，欢迎各位开源爱好者积极参与，在开源领域展示自己的能量。
