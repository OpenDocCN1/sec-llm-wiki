# 如何在树莓派 4 上安装 Ubuntu 桌面系统 | Linux 中国

革命性的树莓派(Raspberry Pi)是最受欢迎的单板计算机。它拥有基于 Debian 的操作系统，叫做 树莓派操作系统🔗 itsfoss.com(Raspberry Pi OS)（原名 Raspbian）。

还有其他几个 可用于树莓派的操作系统🔗 itsfoss.com，但几乎所有的都是轻量级的，适合于树莓派设备的小尺寸和低端硬件。

随着标榜 8GB 内存和支持 4K 显示的树莓派 4B 的推出，情况发生了变化。其目的是将树莓派作为常规桌面使用，并在更大程度上成功地做到了这一点。

在 4B 型号之前，你可以 在树莓派上安装 Ubuntu 服务器🔗 itsfoss.com，但桌面版本却无法使用。然而，Ubuntu 现在为树莓派 4 提供了官方的桌面镜像。

在本教程中，我将展示在树莓派 4 上安装 Ubuntu 桌面的步骤。

首先，快速了解一下运行要求。

![](../Images/e48b69c035331eabb91ff8cf48a4f7ae.png)

在树莓派 4 上运行 Ubuntu 的要求

![](../Images/4e62ae066450dc900c9dd37300630857.png)

以下是你需要的东西：

1\. 一个能够联网的 Linux 或 Windows 系统。2. 树莓派镜像工具🔗 github.com ：树莓派的官方开源工具，可以在你的 SD 卡上写入发行版镜像。3\. Micro SD 卡：最低使用 16GB 的存储卡，推荐使用 32GB 的版本。4\. 一个基于 USB 的 Micro SD 卡读卡器（如果你的电脑没有读卡器）。5. 树莓派 4 必备配件，如 HDMI 兼容显示器、Micro HDMI 连接到标准 HDMI（A/M） 接口的电缆🔗 www.raspberrypi.org、电源（建议使用官方适配器）🔗 www.raspberrypi.org、USB 的有线/无线键盘和鼠标/触摸板。

最好能够提前 详细阅读树莓派的要求🔗 itsfoss.com 。

现在，闲话少叙，让我快速带领你完成 SD 卡的镜像准备。

![](../Images/e48b69c035331eabb91ff8cf48a4f7ae.png)

为树莓派准备 Ubuntu 桌面镜像

树莓派提供了一个 GUI 应用程序，用于将 ISO 镜像写入 SD 卡中。这个工具还可以自动下载兼容的操作系统，如 Ubuntu、树莓派操作系统等。

![](../Images/745cfb594a4b6c17b32fb8f969f331c3.png)

*下载并将操作系统放入 SD 卡的官方工具*

你可以从官方网站上下载这个工具的 Ubuntu、Windows 和 macOS 版本：

◈ 下载树莓派镜像工具🔗 www.raspberrypi.org

在 Ubuntu 和其他 Linux 发行版上，你也可以使用 Snap 安装它：

```
1.  `sudo snap install rpi-imager`
```

安装完毕后，运行该工具。当你看到下面的界面时，选择 “选择操作系统(CHOOSE OS)”：

![](../Images/c8f487d568d56b9d7a42189510943e1a.png)

*镜像工具：选择首选操作系统*

在“操作系统(Operating System)”下，选择 “其它通用的操作系统(Other general purpose OS)”：

![](../Images/04c4cf01c3ed5a234dba9705c2ac21e5.png)

*镜像工具: 其他通用的操作系统*

现在，选择 “Ubuntu”：

![](../Images/781d3ade125652e3f8b9ef31ea930b45.png)

*镜像工具：发行版 - Ubuntu*

接下来，选择 “Ubuntu Desktop 21.04（RPI 4/400）”，如下图所示。

![](../Images/9368b98e96ead272a44e359017035571.png)

*镜像工具：发行版 - Ubuntu 21.04*

> 注意：
> 
> 如果你没有一个稳定的网络连接，你可以 从 Ubuntu 的网站上单独下载 Ubuntu 的树莓派镜像🔗 ubuntu.com。在镜像工具中，在选择操作系统时，从底部选择“使用自定义(Use custom)”选项。你也可以使用 Etcher 将镜像写入到 SD 卡上。

将 Micro SD 卡插入读卡器中，等待它挂载。选择“存储设备(Storage)”下的 “选择存储设备(CHOOSE STORAGE)”：

![](../Images/035a3f579ef67e6ab11001f462c4fa3d.png)

*镜像工具：选择存储设备（SD 卡）*

你应该可以根据存储空间大小，识别你的 Micro SD 卡。这里，我使用的是 32GB 的卡：

![](../Images/c3a6fcb1a77f38462db651b21ba95d4a.png)

*镜像工具：选择 SD 卡*

现在点击“写入(WRITE)”：

![](../Images/39fe3742183268291a33a6655bac9380.png)

*镜像工具：镜像写入*

如果你已经备份了 SD 卡上的内容或是一张新卡，你可以直接进行：

![](../Images/acdc85f07db4e8a6aee520ea37c999be.png)

*镜像工具：镜像写入确认*

由于这需要 sudo🔗 itsfoss.com 的权限，你必须输入密码。如果你从终端运行 `sudo rpi-imager`，就不会出现这种情况：

![](../Images/5b5fd23560a0373e0124f902e3d3d4b1.png)

*镜像工具：镜像写入授权需要密码*

如果你的 SD 卡有点旧，这将需要一些时间。如果它是一个新的高速 SD 卡，就无需很长时间：

![](../Images/f76310acdacb2911dcd8cf8027d457af.png)

*镜像工具：写入镜像*

为确保镜像写入成功，我不建议跳过验证：

![](../Images/8f16569567c1482cec9370f81edea67a.png)

*镜像工具：验证写入*

写入结束后，会有以下确认提示：

![](../Images/248b2e78af6f99475f094c00fdeffb17.png)

*镜像工具：写入成功*

现在，从你的系统中安全移除 SD 卡。

![](../Images/e48b69c035331eabb91ff8cf48a4f7ae.png)

在树莓派上使用装有 Ubuntu 的 MicroSD 卡

已经成功了一半了。与常规的 Ubuntu 安装不同，无需创建一个临场安装环境。Ubuntu 已经安装在 SD 卡上了，而且几乎可以直接使用了。让我们来看看这里还剩下什么。

![](../Images/e48b69c035331eabb91ff8cf48a4f7ae.png)

第 1 步：将 SD 卡插入树莓派中

对于第一次使用的用户来说，有时会有点困惑，不知道那个卡槽到底在哪里？不用担心。它位于电路板背面的左手边。下面是一个插入卡后的倒置视图。

![](../Images/7fdec0b3edc01b6de749243190a6d42b.png)

*树莓派 4B 板倒置，插入 Micro SD 卡*

按照这个方向将卡慢慢插入板子下面的卡槽，轻轻地插，直到它不再往前移动。你可能还会听到一点咔嚓声来确认。这意味着它已经完美地插入了。

![](../Images/b25a1e3b4cd72c9bb47a9a3efb5d06ea.png)

*树莓派 SD 插槽在板子背面的左侧*

当你把它插进去的时候，你可能会注意到在插槽中有两个小针脚调整了自己的位置（如上图所示），但这没关系。一旦插入，卡看起来会有一点突出。这就是它应该有的样子。

![](../Images/3d83943879c465e83425647b525466a5.png)

*树莓派 SD 卡插入时有一小部分可见*

![](../Images/e48b69c035331eabb91ff8cf48a4f7ae.png)

第 2 步：设置树莓派

我无需在这里详细介绍。

保证电源线接头、微型 HDMI 线接头、键盘和鼠标接头（有线/无线）都牢固地连接到树莓派板的相关端口。

确保显示器和电源插头也已正确连接，然后再去打开电源插座。我不建议把适配器插到带电的插座上。参考 电弧🔗 www.electricianatlanta.net。

确认了以上两个步骤后，你就可以 打开树莓派设备的电源🔗 itsfoss.com。

![](../Images/e48b69c035331eabb91ff8cf48a4f7ae.png)

第 3 步：在树莓派上 Ubuntu 桌面的首次运行

当你打开树莓派的电源，你需要在初次运行时进行一些基本配置。你只需按照屏幕上的指示操作即可。

选择你的语言、键盘布局、连接到 WiFi 等：

![](../Images/5a4bb9ab8a2f8917f417b581251a5b26.png)

*选择语言*

![](../Images/ba93693a1df30de3cd4097afcbe8e9d8.png)

*选择键盘布局*

![](../Images/5a350eaa6d4560e6f5a07c13a132995e.png)

*选择 WiFi*

你可以根据需求选择时区：

![](../Images/45e3e930ebc6472608590e577682ddc7.png)

*选择时区*

然后创建用户和密码：

![](../Images/e2190d9459ea5c08d86c499f99432d4d.png)

*输入所需的用户名和密码*

之后的步骤将配置一些东西，这个过程需要一些时间：

![](../Images/62c570cf6b305041fbc58a154fc295a9.png)

*完成 Ubuntu 设置*

![](../Images/0c6c3e9ef19ab0a8664379e403850970.png)

*完成 Ubuntu 设置*

系统会重新启动之前需要一些时间，最终，你将会来到 Ubuntu 的登录界面：

![](../Images/7c860da223d597beed795e495d3d5be5.png)

*Ubuntu 的登录界面*

现在，你可以开始享受树莓派上的 Ubuntu 桌面了：

![](../Images/d8a6b8cd3694b172cedbd70b5edd4e4f.png)

*树莓派上的 Ubuntu 桌面*

![](../Images/e48b69c035331eabb91ff8cf48a4f7ae.png)

总结

我注意到一个暂时的异常情况。在进行安装时，我的显示器左侧有一个红色的闪烁边界。这种闪烁（也有不同的颜色）在屏幕的随机部分也能注意到。但在重启和第一次启动后，它就消失了。

很高兴能够看到它在树莓派上运行，我非常需要 Ubuntu 开始为树莓派等流行的 ARM 设备提供支持。

希望这个教程对你有所帮助。如果你有问题或建议，请在评论中告诉我。
