用过 Linux 的人大多都见过 Linux 载入内核时显示在屏幕上的小企鹅。你了解这只小企鹅吗？

![](../Images/4b537d45b4897d9dc405981172eba2f3.png)

这个小企鹅是 Linux 的吉祥物，是 Linux 内核 2.0 评比出来的，它的名字叫做 Tux🔗 en.wikipedia.org。大多数人相信，“Tux” 这个名字来源于Torvalds UniX。上图是当时评比中选的Larry Ewing所绘。它有几个常见变形的样式，我最喜欢比较有质感的 水晶版🔗 en.wikipedia.org：

![](../Images/cdb2f339d5dedb0f0a9d897a0e13fb27.png)

Linux 内核的不同版本，曾经有过一些变形，比如：

在 2.6.29 的 Linux 内核中，为支持拯救袋獾🔗 zh.wikipedia.org运动 Tux 被临时地替换成 Tuz🔗 zh.wikipedia.org。

![](../Images/d47b8ca0c809cc0ad993376bd4488ace.png)

而在 3.11 版本的 Linux 内核，为了纪念 windows for workgroups 3.11，Linus 将该版本的内核命名为 Linux for workgroups🔗 linux.cn，Tux 打了一支 Windows 的旗帜 :D 。

![](../Images/eacaae8df6a8fb3067295152d9e0ed9f.png)

甚至你在 PS3 上安装 Linux，都会显示不一样的小企鹅们：

![](../Images/ae8d0525d84392325fbdfeb09871648d.png)

Linux 启动时显示的小企鹅的数量，就是你的 CPU 个数，你最多见过几个？欢迎分享给我们。
