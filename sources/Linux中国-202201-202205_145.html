作者：张戈

同行都说 SUSE 这步棋，正落在棋眼。 

两件事，让稳重的 SUSE 在 2021 年很是兴奋。在收购 Rancher 后，SUSE 已成为企业级 Linux、容器、Kubernetes 和边缘计算领域最具亲和力的开源公司。另一件事也激活了 SUSE 的每一个细胞：成为首家支持欧拉开源社区的国外企业，而且率先发布了基于 openEuler 的商业发行版——SUSE Euler Linux。

SUSE 改变了想法

“SUSE 一直在寻找契机，一个 SUSE 本土化战略落地的契机。”刘恺是 SUSE 欧拉项目负责人，他所说的契机，就是基于 openEuler 发行版的 SUSE Euler Linux。早在 2017 年，SUSE 就在讨论落地中国的本土化战略，谋划能否将 SUSE Linux 技术引入中国。

SUSE 欧拉项目负责人 刘恺

刘恺强调的是 SUSE Linux 技术，而不是 SUSE Linux 产品。两者虽是强耦合，但也并非不可分割。“中国市场有独特的应用需求、技术特点、市场规则，SUSE 一直希望能推出更加契合中国市场的企业级 Linux 产品。”

对 SUSE Linux Enterprise Server 这款产品进行改造，就是这家公司最初的想法。SUSE 是全球第一家企业级开源 Linux 操作系统供应商，系统稳定性坚如磐石，支撑关键业务游刃有余。这也使其成为第一家为 IBM、SAP 等著名厂商提供 Linux 系统的合作伙伴。 

SUSE 向来重视中国市场。从 2016 开始，SUSE 已经成为华为的第二大软件供应商。SUSE 在全球有三大研发中心，北京就是其一。即便如此，SUSE中国版 Linux 产品的研发，最初还是希望交给德国团队，毕竟 SUSE 的产品管理体系一直位于德国总部。 

但很快 SUSE 就改变了想法。 

契机在于 openEuler 的出现——与其对 SUSE Linux Enterprise Server 进行改造，让他穿上汉服，不如以 openEuler 为技术底座，将 SUSE Linux 技术植入融合。这一想法让 SUSE 中国颇为兴奋。

SUSE 中国拿到产品决策权

确实如此。

SUSE 中国独立承担起一个产品研发的端到端过程是一次重大的变革，甚至在全球科技企业中也几无先例。在全球科技企业的本土化战略中，不乏在中国设立研发中心的例子，但所谓“中心”，多为全球研发体系的一颗螺丝钉，这就如软件架构师与码农之间的差距。

SUSE 显然不同。SUSE Euler Linux 的推出，意味着 SUSE 中国首次拿到了产品决策权。其在中国本土决策、本土设计、本土研发，在市场拓展初期，也主要面向中国本土销售。意义何在？正如刘恺所说：“SUSE 在正确的时间，推出了正确的产品。甚至友商都说，SUSE 这步棋正在棋眼。” 

SUSE 的选择

在此稍作产业背景展开。服务器操作系统主要包括 Windows、Linux 和 Unix 三大技术流派，其中 Linux 处于绝对主导地位，据赛迪顾问《中国服务器操作系统市场研究报告》显示，2021 年其市场占有率达到了 79.1%。在 Linux 阵营中，Red Hat、Ubuntu、SUSE 又是最具影响力的三大中坚力量。 

与此相比，中国本土的服务器操作系统起步稍晚，1999 年之后才陆续诞生了一批企业。但早期产品并无多少技术含量可言，多是基于 CentOS、Ubuntu 的美颜、换脸，所谓自主研发，也多停留在替换和修改内核、组件，集成应用软件包层面。

改变出现在 2019 年前后。

“SUSE 不想在泥坑中打滚。彼时 openEuler 的诞生改变了中国本土操作系统企业各自为营的格局。”刘恺说。

openEuler 并非 SUSE 的唯一选择，但似乎又是唯一的选择。当时，底层技术的创新突破成为中国业界的主流思维，国内也的确出现了多个类似的开源社区，但这些社区或是过于以市场为导向，或是有肉眼可见的天花板，甚至言过其实，始终停留在 PPT 阶段。

openEuler 的动作显然要快很多。openEuler 源于 EulerOS 这一华为居安思危的“备胎”，但华为并不想“一手掌控”。2019 年，华为将 EulerOS 正式开源，并发起了欧拉开源社区，2021 年又将 openEuler 相关能力捐献给开放原子开源基金会。

这正与 SUSE 的想法吻合。SUSE 本身就具有丰富的社区运营经验，而且深谙开源社区的沟通方式和合作文化——不可太过独断，也不能过于随意。 

openEuler 虽然年轻，但很符合 SUSE 的价值观，其运营状态正如《论语》所述的“君子和而不同，君子群而不党”。对小白开发者没有冷嘲热讽，对不同观点也没有口诛笔伐；更没有顺我者捧、逆我者踢的双标态度。

最硬核的操作系统

正是基于此，2021 年 7 月，SUSE 首次推出了基于 openEuler 的商业发行版，一年之后，SUSE Euler Linux 2.0 版本即将发行。这一版本已明显带有 SUSE 独特的技术标签。

基于 openEuler 22.03 LTS 的商业发行版预发布仪式

“SUSE 一直在与欧拉开源社区探讨如何有所为而有所不为。”企业级开源操作系统的内核就不少于千万行代码，而且涉及桌面、图形界面，以及存储、网络、 OpenStack 等诸多领域，“SUSE 要握紧拳头，突出核心竞争力。”刘恺说。

“突出底层开发能力”就是 SUSE 的核心竞争力之一，也是 SUSE 中国找到的另一个“棋眼”。或者说，SUSE 要做最硬核的 Linux 操作系统。这就像三把锁、 6 秒破百的坦克 300 和 Jeep 牧马人，甚至是奔驰大 G 等硬派越野车。 

以此为技术主线，SUSE 将支持鲲鹏、飞腾、海光、Intel、AMD 等芯片；第一时间支持新增芯片，并将其功能发挥到极致。同时，所有 SSD 硬盘和 HDD 硬盘的异构组合，也将被 SUSE 发挥出最佳性价比。热数据将被首先调度至 SSD 固态硬盘，冷数据则将被传送至 HDD 机械硬盘。SUSE 还针对网络应用环境优化了 TCP 协议性能和容错性，并提供了高吞吐、低延迟的网络存储能力。 

换句话说，SUSE Euler Linux 2.0 以及后续版本，都将成为芯片、整机等硬件最友好的操作系统。SUSE 将成为企业数字化转型的“精算师”，帮助用户榨干花在计算、存储、网络等硬件上的每一分钱，甚至让 600 元的 IT 支出发挥出 1000 元的价值。

沿着这一技术主线，SUSE 成立了欧拉开源社区首个商业技术支持中心，并携手 Intel 联合组建了 Intel Arch SIG。前者将为 openEuler 社区版用户提供技术支持，或帮助其平滑迁移至商业版；后者则搭建了 Intel 和欧拉开源社区合作的桥梁，毕竟 x86 架构依然是现在的主流平台，SUSE 扮演“使能者”角色也再合适不过。

欧拉开源社区首个商业技术支持中心成立仪式 

对此，刘恺最后说道：“谈不上谁比谁更聪明，但中国人肯定最勤奋。只要扎扎实实地坚持技术投入，中国有能力研发出全球领先的操作系统。当然， SUSE 不会局限于打造最硬核的 Linux 操作系统，每一次创新都可能成为 SUSE 的下一个新赛道。”
