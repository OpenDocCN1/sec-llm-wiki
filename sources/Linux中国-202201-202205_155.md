当然，有很多文本编辑器或代码编辑器可以使用。一些流行的包括 Eclipse、Visual Studio Code🔗 itsfoss.com、PyCharm🔗 itsfoss.com、Atom🔗 itsfoss.com、IntelliJ🔗 itsfoss.com，以及 Sublime Text🔗 itsfoss.com。

但是你想尝试一些有趣的东西，完全专注于给你一个极简的体验吗？

来认识一下 Lite XL 编辑器。

说实话，在上周之前我对它一无所知。但是，它以其 极简主义的设计 和它 在编码时有多么快 成功地惊到了我，但最重要的事实是它与 Visual Studio Code 相似。

所以，在开始之前，让我告诉你，如果你是一个 Visual Studio Code 粉丝🔗 itsfoss.com，你绝对应该试试 Lite XL。它可能不是绝对的替代品，而是类似使用场景的精简版。

![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

Lite XL：用 Lua 编写的轻量级文本编辑器

Lite XL 是一个用 Lua 编写的有趣的开源文本编辑器（特别是为建立轻量级应用而定制）。

它也可用于 Windows、Linux 和 macOS。但是，有这么多 现代文本编辑器🔗 itsfoss.com，为什么还要有个 Lite XL？

![](../Images/429b55111297af5ef933311a0e02ec1a.png)

*Lite XL Customize Configuration*

通常情况下，大多数时候我们并不关心文本编辑器会消耗我们系统的资源。然而，在创建 Bash、Python 或任何其他类型的脚本时，你会依赖文本编辑器，而它的资源效率越高越好。

当然，文本编辑器并不像其他一些应用那样对资源要求很高。但是，如果这对你很重要的话，我观察到的情况是这样的：

Lite XL 只使用了 3MB 的磁盘，并消耗了大约 20MB 内存，而 Visual Studio Code 使用将近 550MB 内存。

你能看到这些类似的编辑器之间的这种奇妙的差别吗？

不仅仅是资源使用量，它也是高度可定制的。

请注意，在不同的系统配置下，资源占用的统计数字会有所不同。

![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

Lite XL 的特点

![](../Images/6b3f817bf34e26cf835b967c007049df.png)

根据现有的官方信息，其最受欢迎的一些功能包括：

◈ **跨平台：** 它目前可以在 Windows、Linux 和 macOS 上使用。◈ **轻量级：** 正如我们之前所描述的，它的使用量几乎没有超过 10MB 的内存。◈ **可扩展：** 作为一个极简的产品，并不意味着不能定制。Lite XL 可以通过一些可用的插件来扩展其功能，例如，类似 Visual Studio Code 的智能提示🔗 github.com。◈ **多光标编辑：** 在 Lite XL 中，你可以使用多个光标进行编辑，这听起来很美妙。◈ **集成的终端：** 像 Visual Studio Code 一样，Lite XL 实现了它的终端。◈ 支持高分辨率显示。◈ 更多的颜色主题。◈ 支持硬件加速渲染。![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

如何在 Linux 中安装 Lite XL

Lite XL 为 Linux 发行版提供了一个 AppImage 文件。你可以按照我们的 AppImage 指南🔗 itsfoss.com 来开始使用。

你可以在其 GitHub 仓库🔗 github.com 中找到这个 AppImage 文件。

当你前往其 GitHub 发布区，直接进入 “资产(Assets)” 区并下载 `LiteXL_x86_64.Appimage` 文件。

![](../Images/67b6ec4155528ca0c9b47e55a14d5290.png)

*Downloading Appimage file*

AppImage 文件将被下载到你的下载目录中，因此，在双击该文件之前，请验证它是否允许作为程序执行。

![](../Images/0888bb0a1cbc2521e771914c362d7a0f.png)

*Verifying execution permissions*

这就好了! 现在你可以双击该文件，开始在你的系统中使用 Lite XL。
