迫不及待地想尝试 Ubuntu 22.04 LTS？那么，它终于可以下载和升级了。（LCTT 译注：升级还要等几天，还存在一些小问题）

它带来了 大量令人印象深刻的功能🔗 itsfoss.com，其中 GNOME 42 和树莓派桌面支持是其主要亮点。

现在，它已经就绪。在你决定尝试之前，让我们花点时间来看看这个版本最重要的变化。

![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

Ubuntu 22.04 LTS 的新变化

Ubuntu 22.04 是一次主要版本升级，其包括了桌面环境的改进、视觉上的变化和一些新增的功能。

如果你正在使用 Ubuntu 20.04 LTS，想知道它们之间的区别，你可以查看我们的《Ubuntu 20.04 vs Ubuntu 22.04 LTS🔗 itsfoss.com》文章来了解。

毫无疑问，这是一个 长期支持🔗 itsfoss.com(Long-Term Support) （LTS）版本。所以，你可以期待它维护更新到 2027 年，也就是五年的支持。一些最显著的变化包括：

![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

1、强调色的选择

虽然大多数基于 Ubuntu 的 Linux 发行版提供了设置强调色的功能，但你必须使用 GNOME 优化🔗 itsfoss.com(GNOME Tweaks) 才能做到。

![](../Images/ab83eaefd2ae63453cce6f99413528a2.png)

现在，在 Ubuntu 22.04 中，你可以轻松地设置你所选择的强调色，它会影响到文件夹、通知区和桌面体验的其他元素。

![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

2、GNOME 42

![](../Images/6cbbc41f0b8023220ba04750cc6649c8.png)

期待已久的桌面环境升级来了。虽然 Ubuntu 22.04 的 GNOME 实现并不提供水平停靠区，但会有其它好处加成。

你应该能够在 Ubuntu 22.04 LTS 中体验到所有 GNOME 42 的优点🔗 news.itsfoss.com。不幸的是，你仍然会发现几个版本号是 41 的应用程序。

开发者提到，他们需要更多的时间来测试使用 libadwaita🔗 news.itsfoss.com 的应用程序。

话虽如此，在你继续阅读时，我也会提到 GNOME 42 所带来的有趣的更多功能。

![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

3、新的屏幕截图工具

![](../Images/845a8740edb7a1e8496db8ff6332443f.png)

与 Ubuntu 20.04 LTS 不同，你不能用 `PrtScrn`（或任何其他指定的快捷键）来直接抓拍全屏图片。

相反，如果你按下快捷键来截图，就会弹出来这个新的截图工具。

这不仅体验更加直观，而且还支持屏幕录制。因此，这是一个相当令人激动的变化！

![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

4、深色模式的改进

虽然我们已经有了深色模式，但它并不是一个完美的系统级实现。

感谢 elementary OS 6🔗 news.itsfoss.com，GNOME 42 受到启发，实现了系统级的深色模式，更好地融合在一起以保持一致性。

![](../Images/a2683dbbcb50c96e7f49ac522ffa0da6.png)

![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

5、Firefox 变成了 Snap 版本

![](../Images/002d776832a981e81a58469b7469e859.png)

从 deb 包到 Snap 的过渡已经进行了一段时间了。

在 Ubuntu 22.04 中，Firefox 现在将默认以 Snap 包出现，在 Mozilla 的共同努力下，旨在推动更快的安全更新，并确保无需维护许多东西即可实现跨发行版的支持。

沙盒化的 Firefox 体验也应该可以提供更好的安全性。

你可以在这个 论坛帖子🔗 discourse.ubuntu.com 中阅读更多关于该决定背后的信息。

![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

6、桌面图标出现在底部

![](../Images/f6e0a8841bd8b21c679a9d4de11f0839.png)

默认情况下，桌面图标可以在右上角的区域看到，靠近停靠区。

现在，在 Ubuntu 22.04 中，默认的桌面图标位置已经被改为底部。你可以通过“外观(Appearance)”设置中的选项来改变这一点。

![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

7、缩小停靠区的能力

如果你不喜欢停靠区占据了整个左侧区域，你可以改变它。

你需要禁用“外观(Appearance)”调整中停靠区设置下的“面板(Panel)”模式，如下图所示：

![](../Images/cd04d0b0b11d8286e2aaf37797cbae6f.png)

这将分离出停靠区，并提供现代桌面体验的浮动效果。

![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

8、树莓派桌面支持

Ubuntu 22.04 是第一个也可用于树莓派的桌面 LTS 版本。

随着 zswap 的引入🔗 news.itsfoss.com，树莓派的性能应该会在 Ubuntu 22.04 中得到显著提升。

它甚至可以 在 2GB 的树莓派 4 变体型号上运行🔗 news.itsfoss.com。你可以在你的树莓派上测试这些改进。

![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

9、使用 Ubuntu Advantage

![](../Images/ef65ab3aed915de548b5348403296e64.png)

Ubuntu Advantage 是为企业和商家提供的高级订阅，无需重新启动即可获得重要的安全更新。

对于大多数桌面用户来说，这不是什么有用的东西。然而，如果你想获得 Ubuntu Advantage 订阅，并将你的系统接驳到它，你可以通过导航到“软件 & 更新(Software & Updates)”下的 Livepatch 部分轻松做到这一点。

![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

10、Linux 内核 5.17 和 Linux 内核 5.15 LTS

Linux 内核 5.15 LTS🔗 news.itsfoss.com 是一个重要的升级，它改进了 NTFS 驱动，对即将到来的英特尔独立显卡提供了初步支持，并有更多的性能改进。

对于你的桌面计算机，你应该注意到 Linux 内核 5.15 开箱即用。

Ubuntu 服务器版也采用了 Linux 内核 5.15 LTS。

然而，Ubuntu 22.04 也在最新一代认证设备（OEM）上使用了 Linux 内核 5.17🔗 news.itsfoss.com。

因此，在这个版本中，Ubuntu 根据产品的不同打包了多个内核。

![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

11、RISC-V 的现场镜像

从 Ubuntu 22.04 开始，你会发现单独的可用 RISC-V 架构的现场镜像(live image)。

![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

其他变化

除了上面提到的主要变化外，升级后的其他一些重大变化包括。

◈ 较新的软件包，如 OpenSSL 3.0、Ruby 3.0、Python 3.10、PHP 8.1 等。◈ 更新的应用程序，包括 Firefox 99、LibreOffice 7.3 和Thunderbird 91。

你可以看一下它的 官方发布说明🔗 discourse.ubuntu.com 来探索所有的技术变化。

![](../Images/dc0d4716967814328adb0eed4abfb93a.png)

下载或升级到 Ubuntu 22.04 LTS

如果你想通过使用 ISO 进行全新安装来体验新的 LTS 版本，请前往下面链接的官方网站进行下载。

> 下载 Ubuntu 22.04 LTS🔗 ubuntu.com

而当它的更新可用时，你可以参考我们的 升级指南🔗 itsfoss.com。

> 注意： 你可以进行全新的安装，但是你还不能升级到 Ubuntu 22.04 LTS（由于 snapd 和 update-notifier 软件包的错误有待修复）。你应该在接下来的几天里收到更新通知。
