前两天跟一个大佬交流，他直言，K8s 就是未来的 Linux 操作系统。  

  

操作系统一般有存储、网络、进程管理、进程调度、系统调用API等功能。

 

类似的，K8s 也提供了云原生下的存储、调度、网络、声明式 API 等功能，还提供了很多运维相关的能力，如备份、扩缩容、负载均衡等。
