最近，深度操作系统刚刚发布了 20.05，它添加的 人脸识别功能🔗 linux.cn 引来了社区的关注。

抛开人脸识别的准确度、可靠性，以及是否实用等问题，我们是否可以在其它的 Linux 系统中也获得人脸识别/解锁的的功能呢？

答案是肯定的。这就是本文要介绍的 Howdy 提供的功能。

Howdy 是什么？

据该项目的说明🔗 github.com：

Howdy 为 Linux 提供了 Windows Hello™ 式的认证方式。使用内置红外发射器和摄像头，结合面部识别功能来证明你是谁。

它使用中央身份验证系统（PAM），适用于任何需要密码的地方，如登录、锁屏、sudo、su 等等。

安装

对于 Ubuntu/Linux Mint，可以添加第三方仓库安装：

  1. sudo add-apt-repository ppa:boltgolt/howdy
  2. sudo apt update
  3. sudo apt install howdy

对于 Debian Linux，请在 发布页🔗 github.com 下载 deb 安装包：

  1. wget https://github.com/boltgolt/howdy/releases/download/v2.6.1/howdy_2.6.1.deb

然后使用以下命令安装：

  1. sudo dpkg -i howdy_2.6.1.deb  # 请将文件名代替为你下载的文件名
  2. sudo apt install --fix-broken # 使用 --fix-broken 安装缺失的依赖

对于 Fedora Linux，通过 COPR 仓库安装：

  1. sudo dnf copr enable principis/howdy
  2. sudo dnf --refresh install howdy

对于 Arch Linux 和 openSUSE 请参照其 仓库的说明🔗 github.com。

安装时，会自动下载依赖包和 dlib 的模型。请保证网络通畅。

配置

安装后，运行如下命令来编辑配置文件：

  1. sudo howdy config

请将配置文件中的 device_path = /dev/xxxx 改成你的摄像头路径，它通常是 /dev/video0。

如果 /dev 下没有 videoX设备，请检查摄像头驱动是否已经安装。

Howdy 需要了解你的长相，以便以后能识别你。运行如下命令来添加一个面部模型：

  1. sudo howdy add

如果没有出错，我们应该可以通过识别你的脸来运行 sudo。打开一个新的终端，运行 sudo -i 来看看它的运行情况。

排错

解决 Howdy 在 GNOME 锁屏界面不工作的问题

复制如下文件：

https://github.com/boltgolt/howdy/blob/caf244ce297d27d40168c40571b0fad6f7ee2596/src/compare.py

将 /lib/security/howdy/compare.py 代替即可。
