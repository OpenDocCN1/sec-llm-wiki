> Kali Linux 在 2022 年的第一次升级带来了明显的视觉更新和一个新的“全都有”离线 ISO。

2022 年的第一个 Kali Linux 版本来了。

Kali Linux 在 2021 年做了许多改进，包括 Linux 内核升级、新的黑客工具、实时虚拟机支持（Kali Linux 2021.3🔗 news.itsfoss.com）、苹果 M1 支持等等。

让我们来看看 Kali Linux 2022.1 版本中的主要亮点。

![](../Images/b25b7a8617f78524037ba52a4e5e727d.png)

Kali Linux 2022.1 有什么新内容？

从这个版本开始，Kali Linux 团队决定对他们每年的 20xx.1 版本（每年的第一个版本）进行明显的视觉更新。

因此，Kali Linux 2022.1 的更新带来了视觉上的刷新和其他新的增加和改变。

![](../Images/b25b7a8617f78524037ba52a4e5e727d.png)

主题更新

![](../Images/bb9b3fb7edb138ed647c6f6cbdefc94a.png)

随着最新的升级，你可以看到一些新的桌面、登录和启动屏幕的壁纸。

安装程序的主题也得到了视觉上的更新，使其具有现代的外观。

总的来说，通过主题更新、新壁纸和细微的布局变化，你可以期待从 UEFI/BIOS 启动菜单到桌面的统一用户体验。

![](../Images/96ad9f513e09bed251a488f83bdeaee8.png)

浏览器的登录页面也有了视觉上的更新，让你可以访问 Kali 文档和工具，以及通常的搜索功能。

![](../Images/9ebe864dbcd25ce2978e7fd2a36d469d.png)

![](../Images/b25b7a8617f78524037ba52a4e5e727d.png)

新的 “全都有” ISO

Kali Linux 现在将提供一个新的分发方式，提供一个独立的离线 ISO，包括了 “kali-linux-everything” 软件包的所有内容。

这个产品的目的是让你下载一个离线 ISO，而不需要在安装后单独下载软件包。

它应该对偏远地区的教育机构使用 Kali Linux 进行道德黑客学习很有帮助。

考虑到它是一个大的 ISO 文件（大小达 9.4GB），你只能通过 BitTorrent 找到这个 ISO。

![](../Images/b25b7a8617f78524037ba52a4e5e727d.png)

对 VMware 的 i3 桌面的改进

如果你在带有 i3 桌面环境的虚拟机上使用 Kali Linux，一些客户功能是默认禁用的。

现在，这些功能，如拖放、复制/粘贴已经默认启用，可以给你更好的开箱即用的 i3 虚拟机的体验。

![](../Images/b25b7a8617f78524037ba52a4e5e727d.png)

其他改进

除了关键的新增功能外，Kali Linux 2022.1 还带来了新的工具和整体改进。其中一些值得强调的包括。

◈ 在 Kali 设置屏幕中使用带有合成语音的无障碍性改进。◈ 新的工具，如 dnsx、email2phonenumber、naabu、proxify 等等。◈ 可用于 ARM64 架构的新软件包，包括 feroxbuster 和 ghidra。◈ Linux 内核 5.15🔗 news.itsfoss.com。◈ 你现在可以使用 kali-tweaks 中的设置来启用传统的算法、密码和 SSH。◈ 对 shell 提示符进行了调整，删除了骷髅头图标、退出码和后台进程数量的显示。

总的来说，这个版本对桌面和树莓派的重大改进值得期待。

你可以通过 官方公告🔗 www.kali.org 了解更多细节。

![](../Images/b25b7a8617f78524037ba52a4e5e727d.png)

下载 Kali Linux 2022.1

你可以前往其 官方网站🔗 www.kali.org，选择你打算下载的平台。

值得注意的是，“全都有” 的版本只能通过种子下载。所以，你得用 Torrent 客户端🔗 itsfoss.com。

如果你已经使用 Kali Linux，你可以使用以下命令进行快速更新：

```
1.  `echo "deb http://http.kali.org/kali kali-rolling main non-free contrib" | sudo tee /etc/apt/sources.list`
2.  `sudo apt update && sudo apt -y full-upgrade`
3.  `cp -rbi /etc/skel/. ~`
4.  `[ -f /var/run/reboot-required ] && sudo reboot -f`
```
