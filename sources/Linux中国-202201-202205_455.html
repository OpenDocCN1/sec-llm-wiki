与大流行病作斗争，造成了生产新电脑所需的微芯片的短缺。此外，一些较新的专有操作系统提高了它们的硬件标准（LCTT 译注：Windows 11，别扭头看别人）。这个难题为我们这些在日常生活中使用 Linux 的人创造了一个机会。

延长硬件的生命周期

长期以来，Linux 一直以延长老旧硬件的寿命而闻名。这种能力对那些每天使用电脑的人来说是个福音。

在过去的一年里，我已经帮助许多人使用 Linux 翻新和 改装旧电脑🔗 opensource.com。基于 Linux 的电脑耗电更少，启动速度更快。Gnome🔗 www.gnome.org 桌面很好，但许多旧电脑更适合 LXDE🔗 www.lxde.org 或 XFCE🔗 xfce.org 环境，它们运行需要较少的资源。

像 FreeGeek🔗 opensource.com 和 Kramden Institute🔗 opensource.com 这样的组织已经把弥合数字鸿沟作为他们的核心使命，并以此为目标。这些团体对旧电脑进行了再利用，使它们不被当成垃圾填埋，而是把它们送到需要它们的用户手中。没有 Linux，就没有这些项目。

DD-Wrt🔗 dd-wrt.com、OpenWrt🔗 openwrt.org 和 Tomato🔗 www.freshtomato.org 都是 Linux 解决方案，使旧的网络硬件不被当成垃圾丢弃，并同时为用户的路由器提供更多的安全、隐私和性能。

借助 GalliumOS🔗 galliumos.org 和 Mrchromebox.tech🔗 mrchromebox.tech，即使是 Chromebooks 在谷歌停止支持后也能获得新的生命。

新的机会

Linux 创造了一些本来不存在的机会。学生和业余爱好者都在没有投资的情况下开始了计算机科学的成功事业，这要归功于他们在旧电脑上学到的经验。这些系统运行企业级软件，如 LAMP🔗 en.wikipedia.org 栈，它促进了向 “Web 2.0” 的过渡。它是最早的 Web 开源软件栈之一。今天，它为 WordPress、Drupal 和 Joomla 系统提供了动力。事实上，Linux 为超过 96% 的世界前 100 万台 Web 服务器提供动力。Linux 还管理着 嵌入式系统🔗 opensource.com、电子阅读器、智能电视、智能手表 等等🔗 opensource.com。Linux 是世界上远远 超过 70%🔗 gs.statcounter.com 的智能手机的操作系统。甚至美国国家航空航天局（NASA）今年在火星上创造历史的 毅力号🔗 mars.nasa.gov，也是由 Linux 驱动的。

为当今大多数应用提供动力的云计算，没有 Linux 就不可能存在。今天的大多数 Web 和智能手机应用都在基于 Linux 的 容器🔗 opensource.com 中运行。即使在微芯片短缺和专有系统成本高昂的情况下，进入云服务行业的人也有机会学习开源的操作系统和软件。

未来

但最恰当的是，Linux 和开源为 联合国可持续发展目标🔗 opensource.com 提供了动力。随着大流行的继续，Linux 仍然是一个重要的资源。
