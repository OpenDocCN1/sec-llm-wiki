在整个上世纪 80 年代和 90 年代，DOS 是桌面之王。世界各地的程序员不满足于 DOS 的专有版本，他们共同创建了一个名为 FreeDOS 的开源版本，该版本于 1994 年首次推出。FreeDOS 项目🔗 www.freedos.org 在 2021 年及以后还在继续发展。

我们发表了几篇关于 FreeDOS 的文章，以帮助新用户开始使用 FreeDOS 和学习新程序。以下是去年我们最受欢迎的几篇 FreeDOS 文章。

![](../Images/d112bc6eabd9912a55568a59dec8f341.png)

初学 FreeDOS

你是 FreeDOS 的新手吗？如果你想了解如何启动和运行 FreeDOS 的基本知识，请查看这些文章：

◈ [开始使用 FreeDOS](https://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664636011&idx=4&sn=d959764287a7e219f2363dab51c0eeef&chksm=bdcf252d8ab8ac3b2707c5e334f3b5a261ff5c2ceb324c43e8f4794dbaeb6e22e59d275acaf4&scene=21#wechat_redirect)：它看起来像复古计算时代，但 FreeDOS 是一个现代的操作系统，你可以用它来完成事情。◈ [FreeDOS 如何启动](https://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664636187&idx=2&sn=6fe16ffd036d47d3f4494a666d9fb665&chksm=bdcf245d8ab8ad4b807d1b83b585f38503c70a1e29c1c8d98f7f59689fda443393195c195445&scene=21#wechat_redirect)：了解你的计算机是如何引导和启动 FreeDOS 的，从开机到命令行提示符。◈ [用纯文本配置 FreeDOS](https://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664645189&idx=4&sn=2829a6f95947003d1d30f41acc3aefdc&chksm=bdcf79038ab8f015dd678666569d04cba6f9556b75629fd84d1601cbaceba2c75a1eef9c04f6&scene=21#wechat_redirect)：学习如何用 `fdconfig.sys` 文件来配置 FreeDOS。◈ 如何用 CD 和 DIR 浏览 FreeDOS🔗 opensource.com：只需掌握两个命令，`DIR` 和 `CD`，你就可以在命令行中浏览你的 FreeDOS 系统。◈ [在 FreeDOS 中设置和使用环境变量](https://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664644116&idx=4&sn=414fbf630deaac096776f0c4a0f92638&chksm=bdcf05528ab88c440e13ae7d6fcf3dcd165ff00b324f5f255f36d1608285c2b861110181bb4d&scene=21#wechat_redirect)：环境变量在几乎所有的命令行环境中都有用，包括 FreeDOS。![](../Images/d112bc6eabd9912a55568a59dec8f341.png)

Linux 用户的 FreeDOS

如果你已经熟悉了 Linux 的命令行，你可能想试试这些在 FreeDOS 上创造类似环境的命令和程序：

◈ [给 Linux 爱好者的 FreeDOS 命令](https://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664645748&idx=2&sn=27cde7ee7c94da28f94738ed2eae1c6d&chksm=bdcf7f328ab8f6247c9721870a307a632d654470cad3816c31a0151fce45c028297a22c9a69e&scene=21#wechat_redirect)：如果你已经熟悉了 Linux 的命令行，可以试试这些命令来帮助你轻松进入 FreeDOS。◈ 在 FreeDOS 中像 Emacs 一样编辑文本🔗 opensource.com：如果你已经熟悉了 GNU Emacs，你应该在 Freemacs 中感到很自在。◈ [在 Linux 和 FreeDOS 之间复制文件](https://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664636794&idx=3&sn=78d72a649446520c609e3c64cb6d86c3&chksm=bdcf1a3c8ab8932a0e06daaa970cf0b675f09a8f7e17136d4d2c55d4ffeca3a5ebd2c796f33c&scene=21#wechat_redirect)：学习如何在 FreeDOS 虚拟机和 Linux 桌面系统之间传输文件。◈ [如何在 FreeDOS 上归档文件](https://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664637056&idx=3&sn=1184f128e889fcfd79bd8057ff53f555&chksm=bdcf19c68ab890d0e13e8104e26a4807f7570903441d1d1929c2ddd2e66df35ae288a2a53fd1&scene=21#wechat_redirect)：这是 FreeDOS 版本的 `tar`，在 DOS 上归档的标准方法是 Zip 和 Unzip。◈ 在 FreeDOS 上使用这个怀旧的文本编辑器🔗 opensource.com：让人联想到 Linux ed(1)，当你想用老式的方法编辑文本时，Edlin 是一种乐趣。![](../Images/d112bc6eabd9912a55568a59dec8f341.png)

使用 FreeDOS

当你启动进入 FreeDOS，你可以使用这些很棒的工具和应用来完成工作或安装其他软件：

◈ 如何使用 FreeDOS 的文本编辑器🔗 opensource.com：FreeDOS 提供了一个用户友好的文本编辑器，叫做 FreeDOS Edit。◈ 在 FreeDOS 上听音乐🔗 opensource.com：Mplayer 是一个开源的媒体播放器，通常可以在 Linux、Windows、Mac 和 DOS 上找到。◈ [在 FreeDOS 上安装和删除软件包](https://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664644617&idx=3&sn=eddd89989dfcc0ff7fb26ae74de01863&chksm=bdcf7b4f8ab8f2599719dd8b78591b7092fcf1973a44f7b8ea3ab392433205c254587601e94e&scene=21#wechat_redirect)：了解如何使用 FDIMPLES，即 FreeDOS 包管理器，在你的 FreeDOS 系统上安装和删除软件包。◈ 为什么我喜欢用 GW-BASIC 在 FreeDOS 上编程🔗 opensource.com：BASIC 是我进入计算机编程的起点。我已经很多年没有写过 BASIC 代码了，但我对 BASIC 和 GW-BASIC 永远怀有好感。◈ 用 Bywater BASIC 在 FreeDOS 上编程🔗 opensource.com：在你的 FreeDOS 系统上安装 Bywater BASIC，并开始尝试使用 BASIC 编程。

在其近 30 年的历程中，FreeDOS 一直试图成为一个现代 DOS。如果你想了解更多，你可以在 [FreeDOS 简史](https://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664637546&idx=2&sn=57a3002785911a7c57bcbfd179bc1b22&chksm=bdcf1f2c8ab8963a3084a243ce0303782e4f47f8fe150f55ca3f321b9948cdef3498492ccaa4&scene=21#wechat_redirect) 中阅读关于 FreeDOS 的起源和发展。另外，请看 Don Watkins 关于 FreeDOS 的采访：一个大学生是如何创立一个自由和开源的操作系统🔗 opensource.com。

如果你想尝试 FreeDOS，请下载 2021 年 12 月发布的 FreeDOS 1.3 RC5。这个版本有大量的新变化和改进，包括更新的内核和命令 shell，新的程序和游戏，更好的国际支持，以及网络支持。从 FreeDOS 网站🔗 www.freedos.org下载 FreeDOS 1.3 RC5。
