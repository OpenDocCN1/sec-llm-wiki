2021 年对于 Kubernetes 来说是令人兴奋的一年，这些文章证明了这一点。从有趣的界面到家庭实验室再到开发环境，看看我在 2021 年最喜欢的 K8s 文章。

如果你对基本原理感兴趣，这篇 介绍 Linux 上的容器🔗 opensource.com 的文章从内到外阐明了 Linux 容器的工作原理。你是否想获取一些乐趣？安装 minikube 并开始使用 DOOM 游戏作为界面🔗 opensource.com 来管理它。另一个选择是 kubectl🔗 opensource.com，这是一个更传统的 Kubernetes 控制 CLI。

即使你只在你的 Linux 家庭实验室🔗 opensource.com 上运行 Kubernetes，你也可以使用 Terraform 和 Helm🔗 opensource.com 等工具来自动化日常操作。这创造了一个 更好地掌握 Terraform🔗 opensource.com 的机会。

生活中可以确定的几件事之一是，计算机会以奇怪而有趣的方式出错。用 Prometheus 和 Grafana 监控你的 Kubernetes 集群🔗 opensource.com，看看它是如何出错的。使用 Grafana Tempo 的分布式跟踪🔗 opensource.com来监控里面运行的应用。通过引入 Chaos Mesh🔗 opensource.com 在 Kubernetes 中造成有意的混乱，来监控你监控的性能。

如果你正在开发在 Kubernetes 上运行的应用，Quarkus 可以帮助你开发和测试🔗 opensource.com。使用 Java 的开发者 可以在 Kubernetes 上使用容器运行🔗 opensource.com 应用。像 Tackle-DiVA🔗 opensource.com 这样的工具有助于将应用移植到容器中。

像所有成功的开源项目一样，Kubernetes 的部分价值是一个强大的 生态系统🔗 opensource.com。比如 KubeEdge 项目🔗 opensource.com，它有助于将计算和数据更接近终端用户。在使用 Kubernetes 一段时间后，你甚至可能想 成为 Kubernetes 维护者🔗 opensource.com。

有这么多有趣的 Kubernetes 内容可供学习，可能很难将它们全部看完。不过，对于系统管理员和开发人员来说，优秀的 Kubernetes 资源是必须的。请阅读这些精选的内容。
