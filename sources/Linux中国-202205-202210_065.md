CubyText：实验性知识管理应用

![](../Images/0511222e3338a042c2d73142f05ff42d.png)

*cuby text*

CubyText🔗 github.com 是一款自由开源的跨平台知识管理应用，还处于早期开发阶段。

📢 该项目的第一个版本于 9 月 12 日上线。所以，它是真的新啊。

你可以在 Linux、macOS 和 Windows 上试用它。 .deb 文件可用于 Linux。

该项目的有趣之处在于其类似于 Notion 的用户界面与块编辑器的概念。开发者为这个工具建立了一个 块编辑器🔗 github.com，以便能够组织内容。

![](../Images/0faf73d3f14a94876233ae00425ae439.png)

*cuby text*

因此，你在此处添加的任何内容都是按块组织的。它支持带有 Markdown 标记的富文本，因此你可以轻松地增强你的笔记。

此外，你可以添加选项卡以快速创建更多笔记以及一目了然地了解信息。你还可以在上面的截图中注意到待办事项列表。

看起来很有趣，对吧？

如果你好奇，请前往它的 GitHub 页面🔗 github.com 并为你的平台下载适当的包进行测试。
