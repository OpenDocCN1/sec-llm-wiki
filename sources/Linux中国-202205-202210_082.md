# Lapce：一个开发中的快速、轻量级的开源代码编辑器 | Linux 中国

 ![](../Images/63dfe67297492ef9e5bbe972d85125ab.png)**导读：**Lapce 是一个用 Rust 构建的开源代码编辑器。它正处于早期开发阶段，但看起来很有前途！　 　![](../Images/fcd7407f490b546f3d04a28e37ab574f.png)本文字数：1022，阅读时长大约：1分钟  

有很多开源的代码编辑器可用于 Linux。

你对换一种选择有什么看法：一个专注于性能的基于 Rust 的开源代码编辑器？

它应该是激动人心的，对吗？

Lapce 就是这样一个正在开发的项目，它的目标是开发出一个功能丰富、速度快的代码编辑器，作为微软的 Visual Studio Code 的替代品。

开发者还提到，它的灵感来自于 Xi-editor🔗 github.com（它已不再处于活跃开发状态）。

![](../Images/d887a1fa4b6ff61b8e076a0a133a4a30.png)

Lapce 处于 pre-alpha 阶段

![](../Images/e2a05784f43ec2b4faeb56ccf0b7bff0.png)

*lapce 编辑器*

虽然 Lapce 还不是一个完整的产品，但它有很多东西可以提供。

因此，随着稳定版本的接近，我们得到的东西应该是有趣的。

值得强调的功能包括：

◈ 命令面板（快速操作）。◈ 自定义用户界面字体、标题高度、字体阴影、滚动宽度等。◈ 内置终端。◈ 类似 Vim 的模态编辑。◈ 连接到远程计算机。◈ 代码语法高亮，代码不全，以及类似功能。◈ 插件系统。◈ 深色/浅色模式。

虽然它专注于性能，但在用户体验方面看起来不错（尽管它不完整）。

![](../Images/3195b989147af8c9642fcad8118e65b3.png)

如果用户能够获得一个代码编辑器所期望的所有基本功能，以及一个性能更好的应用，Lapce 很快就会成为一个受欢迎的选择。

![](../Images/d887a1fa4b6ff61b8e076a0a133a4a30.png)

下载 Lapce

Lapce 在 Linux、macOS 和 Windows 中有 pre-alpha 版本。

对于 Linux，你只需要下载并解压 tar.gz 包，然后使用 GUI 或终端运行 Lapce 可执行文件。

目前，它正在积极开发中。你可以为你的平台下载软件包并进行测试，但你应该预期会出现 bug 和新的版本。探索它的 GitHub 页面🔗 github.com 以获得更多信息。

> Lapce🔗 lapce.dev

我在 Pop!\_OS 22.04 LTS 上试用了它，发现用户界面冻结了几次。然而，它所提供的功能似乎令人印象深刻。
