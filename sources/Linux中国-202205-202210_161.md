8 月 23 日，赛昉科技举办 2022 新产品发布会，发布两款重磅新品：全球首款量产高性能 RISC-V 多媒体处理器——昉·惊鸿7110（JH7110），和全球性能最高的量产 RISC-V 单板计算机——昉·星光 2（VisionFive 2），推动 RISC-V 在高性能应用领域渐入佳境。

中国工程院院士倪光南为发布会做开场致辞。倪院士表示，要实现芯片产业自主可控的目标，必须要打破主流 CPU 架构垄断的格局，RISC-V 的出现为推动中国芯片产业发展提供了新的机遇。生态发展是决定 RISC-V 从物联网迈向高性能应用领域的关键，需要社会各界的共同努力。

![](../Images/8d5b8ff15788b70e91838439f02ddde0.png)

全球首款量产高性能 RISC-V 多媒体处理器

赛昉科技创始人兼 CEO 徐滔全面揭秘了赛昉科技新一代多媒体处理器——JH7110。作为一款高性能、低功耗、多功能的基于 RISC-V 的应用处理器芯片，JH7110 采用成熟的台积电 28nm 工艺，搭载 64 位高性能四核 RISC-V CPU，工作频率 1.5GHz，2MB 的二级缓存。值得一提的是，JH7110 集成 3D GPU、H.264/H.265 视频编解码 IP 及 ISP IP，是一款功能强大的多媒体处理平台。

![](../Images/d201e07ad359c977c76fa703fb8c5b73.png)

根据实测，JH7110 CPU 稳定工作频率达 1.5GHz，Coremark 跑分达到 5.09，是目前市场上 RISC-V 量产芯片中性能最优的产品。此外，JH7110 提供更加强大的 GPU 处理能力，在 400MHz 的 GPU 工作主频下，使用业界标准的 GPU benchmark – GLmark2 测试，相比单板计算机领域应用广泛的主控芯片，JH7110 的实测数据达到其 4 倍以上。

功耗方面，JH7110 被划分为 8 个可独立开关的电源域，CPU 频率可通过软件调节，客户可完全按照应用场景和性能需求设置最有效的芯片工作场景，以实现 PPA 平衡。休眠状态下，JH7110 功耗为 120mW；在单板计算机应用场景，JH7110 满负荷工作，动态功耗为 4100mW；在软路由、NAS的应用场景，用户不需要 GPU 和视频编码，而需要双网口工作，用户可通过软件控制模块开关，此时实际功耗会下降到 3100mW。

值得一提的是，JH7110 拥有强大的多媒体支持能力。JH7110 集成了赛昉科技自研的低功耗 ISP，提供强大的 H.264/H.265 编解码能力，支持双路 1080P@30fps 编码，1 路 4K@60fps 或 4 路 1080P@30fps 解码；支持 JPEG 编解码；显示输出可支持 2 路 4K 双屏显，6 种图层叠加显示；集成的 GPU 渲染能力可达 2400MPixels/s。

徐滔表示，通过更快的响应速度和更流畅的图像处理，JH7110 可以给游戏玩家带来极好的游戏体验，另外，普通用户也能够在常用的桌面环境，如 Debian、OpenHarmony 中获得流畅的使用体验，为 JH7110 的多应用场景奠定了基础。

![](../Images/8d5b8ff15788b70e91838439f02ddde0.png)

全球性能最高的量产 RISC-V 单板计算机

基于 JH7110，赛昉科技发布了全球首款高性能、低成本且集成 3D GPU 的量产 RISC-V 单板计算机——VisionFive 2。

VisionFive 2 搭载 JH7110 多媒体处理器，拥有极强的计算能力和图形处理能力；配有完整的音视频接口：DVP、MIPI、HDMI、音频立体声接口；两个网络接口；40-pin 全功能 GPIO，可兼容各种主流开发板的通用外设模组；同时提供 PCIE、USB、SDIO 外设的扩展接口。

![](../Images/e8d1ae580e1693142f3019179a4b2e70.png)

与目前已有 RISC-V 开发板相比，VisionFive 2 性能最高，功能最全。徐滔介绍，目前，在 VisionFive 系列开发板上，已移植完成的 Linux 发行版有 Ubuntu、Fedora、OpenSUSE、Debian、ArchLinux、AltLinux、Gentoo、Lubuntu 等操作系统，正在移植的有 OpenHarmony、Deepin、优麒麟等。此外，VisionFive 系列开发板已全面支持 Python，Java 等高级语言，同时，支持 JavaScript 编程的方舟编译器很快将在 OpenHarmony 操作系统下问世，助力用户高效地开发各种应用。

强大的性能、丰富的外设接口、丰富的软件生态，给予 VisonFive 2 无限潜能。据现场展示，在播放高清视频的同时，VisionFive 2 能流畅地进行 3D 渲染和运行 3D 游戏，画面效果引人入胜，功能齐备令人交赞。

据悉，VisionFive 2涵盖2GB、4GB、8GB三个版本，对应价格分别为55美元、65美元、85美元（均不含税），价格已逼近市场上其他架构的开发板。此外，赛昉科技还将开启为期两个月的众筹让利活动，用户最高可享七五折优惠。

VisionFive 2的众筹将率先在全球最知名的众筹网站Kickstarter上开启。用户进入kickstarter.com后在主页搜索VisionFive 2即可获悉众筹详情。

“VisionFive 2真正意义上填补了RISC-V高性能开发板的空白，我们希望以最普惠的价格，让全球的RISC-V关注者和商业客户，来体验和评估这款高性能的RISC-V产品。”徐滔如是说。

![](../Images/8d5b8ff15788b70e91838439f02ddde0.png)

推动 RISC-V 高性能应用持续落地

JH7110 通过严格的可靠性测试，满足商规、工规完整的测试标准，可被广泛应用于消费类电子和工业控制领域。发布会现场，徐滔介绍了基于JH7110完整的云电脑和笔记本电脑解决方案。JH7110 完美支持远程桌面传输，支持双屏、三屏异显，很好地满足行业用户云电脑产品需求。

强大的 GPU 与多媒体能力，使 JH7110 具备了支持桌面操作系统的能力，赛昉科技与合作伙伴开发设计的笔记本电脑解决方案，采用电池供电，通过PCIE和USB进行必要的通讯外设扩展，支持前置摄像头、2K 液晶触摸屏，是一套竞争力十足的入门级笔记本电脑解决方案。

赋能开源硬件，JH7110 持续获得青睐。不久前，开源硬件厂商 Pine64 宣布推出基于 JH7110 的 RISC-V 单板计算机Star64。据悉，Star64 配置 1 个 PCIe 接口，2 个千兆网口，GPIO 和 USB 3.0 数据接口。

比派科技总经理王赞梅表示，赛昉科技此次推出的 JH7110，可以为开源社区带来更多的创新力和原动力，香蕉派开源社区将基于 JH7110 推出新一代开发板，并携手赛昉科技共同打造生态软件系统。

在燃气管网智能系统及网络安全方面，赛昉科技及威努特将基于 JH7110 联合开发具有完全自主知识产权的工业互联网安全产品。目前，该款产品已进入现场测试阶段，将推广覆盖到城市燃气项目，助力港华智慧能源提升燃气管网系统的防护能力，夯实基础设施数据安全。

港华燃气工程质量与建设副总裁席丹表示，港华智慧能源在内地 300 多个城镇运营管道燃气项目，客户数超过 4000 万户。将 JH7110 应用于工业级网络安全系统中，确保港华智慧运营平台关键设施的信息安全，提升安全等级，实现安全、可靠、稳定的燃气供应，为智慧燃气的实现保驾护航。

创新驱动产业变革，赛昉科技的一小步，RISC-V 前进的一大步。此番 JH7110 和 VisionFive 2 的量产，意味着 RISC-V 向高性能应用领域迈出了坚实一步，为国产芯片的发展注入了强心剂。
