# 全球首款高性能、低成本的开源 RISC-V 单板计算机即将发布

推动 RISC-V 走向高性能应用领域，是赛昉一直努力的方向。从 RISC-V IP，到芯片，再到开发板，赛昉科技持续投入，坚持做全球范围内最高性能的 RISC-V 产品。现在，我们又取得一些突破，与大家分享。追求卓越性能，8 月 23 日下午两点，2022 年赛昉科技新产品线上发布会将重磅开启。前 100 名线上报名观众均有好礼相送。发布会精彩环节抢先看：**全球首款量产的高性能 RISC-V 多媒体处理器接受订货**该款芯片功能强、性能高、功耗低，我们将用实测数据为您一一解密。此外，还会带来该款芯片在商业和工业领域完整的解决方案、应用参考设计和落地项目。**全球首款高性能、低成本的开源 RISC-V 单板计算机重磅首发**这是全球性能最高、也是全球首款集成 GPU 的 RISC-V 单板计算机，而它的售价也被压低到极致，我们的目标是为业界带来最普惠的高性能RISC-V产品。**开发板众筹让利活动正式开启**为回馈广大 RISC-V 开发者，我们将进行为期两个月的众筹让利活动。凡通过众筹购买新推出的 RISC-V 单板计算机的用户，能收获更高的价格折扣和更早的到货时间。**RISC-V 软件生态持续繁荣**基于自研的芯片和开发板，我们持续构建 RISC-V 软件生态，为用户打造良好的开发环境，我们将呈现丰富的生态进展。活动还邀请了行业内多位重磅嘉宾，为 RISC-V 生态发展建言献策。
