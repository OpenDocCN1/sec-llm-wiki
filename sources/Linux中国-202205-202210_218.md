作为 最轻量级和最灵活的 Linux 发行版之一🔗 itsfoss.com，Peppermint OS 现在提供一个基于 Devuan 的 ISO，可以让高级用户对他们的系统有更多的控制。

随着他们发布了 Peppermint OS 11，他们放弃使用 Ubuntu🔗 news.itsfoss.com 作为基础，而使用 Debian，使 Peppermint OS 更加稳定和可靠。

那么，首先 Devuan 是什么？

Devuan 是 Debian 的一个分叉，没有 systemd，所以用户可以拥有移植性和选择的自由。

是否使用 systemd 经常发生争论，这就是为什么我们有一个 无 systemd 的 Linux 发行版🔗 itsfoss.com 的列表，但只有少数几个可以提供开箱即用的精良体验。

现在，基于 Devuan 的 Peppermint OS 版本应该是这个列表中令人振奋的补充。

如果你想要一个无 systemd 的发行版，给你的操作系统更多的自由，这应该是一个不错的尝试。

别担心，Peppermint OS 的 Debian 版将会继续存在。所以，你可以期待基于 Devuan 和基于 Debian 的 ISO 都可以使用。

![](../Images/f96379dd1a15c3a93ceb1dffd4b3e9a3.png)

你需要无 systemd 发行版吗？

systemd 是一个初始化系统。当你启动你的 Linux 机器时，初始化系统是最先启动的程序之一，并将一直运行到你使用电脑为止。

但 systemd 不仅仅是一个初始系统🔗 freedesktop.org，它还包含其他软件，如 logind、networkd 等，用于管理 Linux 系统的不同方面。

总的来说，它演变成了一个复杂的初始模块。虽然它使许多事情变得简单，但在一些用户看来，它是一个臃肿的解决方案。

因此，有用户开始喜欢 Devuan 这样的选项。而且，Peppermint OS 的开发者现在正试图通过使用 Devuan 作为另一个版本的基础，来改善桌面用户的体验。

![](../Images/f96379dd1a15c3a93ceb1dffd4b3e9a3.png)
