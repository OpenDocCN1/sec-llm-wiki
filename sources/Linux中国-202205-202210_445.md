# 隐藏功能！在 DuckDuckGo 搜索引擎中，你可以做这 25 件有趣的事情 | Linux 中国

 ![](../Images/07ac4920a35fa3c3489e849af7b876b3.png)**导读：**如果你是一位 DDG 狂热粉，你可能会喜欢用这些小技巧来提升你的搜索体验。　 　 　 　 　 　 　 　 　本文字数：2496，阅读时长大约：3分钟  

比起无处不在的 Google，有些搜索引擎替代品更加尊重隐私🔗 itsfoss.com，而 DuckDuckGo 就是其中之一。

最近，这个搜索引擎有了很大的改进，搜索一般网页十分顺畅。在搜索本地地点方面，则还远不及 Google。

不过，DuckDuckGo（简称为 DDG）有一些很酷的功能，大部分用户还没注意到。如果你是一位 DDG 狂热粉，你可能会喜欢用这些小技巧来提升你的搜索体验。

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

1、跳转到特定网页

在你最喜欢的网站名称前输入 `!` 即可直接进入这个网站。则类似于 Google 的 “运气不错” 功能，但用 DDG 的话来说，这就叫 “叹号搜索”。

有一些网站有缩写形式，开始输入时便会提示。

![](../Images/5cc72b7d44662c646e726c362a698f9c.png)

*duckduckgo bang feature*

在网站名后面输入搜索词，就可以直接抵达那个网站的搜索结果处。

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

2、文本转 ASCII

Figlet 是一个 有趣的 Linux 命令🔗 itsfoss.com，可以将任意文本转换为漂亮的 ASCII 画格式。

在任意搜索词前输入 `figlet`，就会显示 ASCII 输出。无需打开终端。

![](../Images/46f3d084253c1d1e83d4c7c5d65f0a21.png)

*Figlet in DDG*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

3、检查社交媒体的状态

在某个人的 Twitter 名前加上 `@`，就会显示 TA 的状态（关注者等）。

![](../Images/c890076649463ec0fdd44ade78aae85c.png)

*Itsfoss Twitter*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

4、生成强密码

输入 `password` 并加上需要的字符数，就可以生成一个独特的强密码。

![](../Images/b192787be2c59bc5c53858a60d6aa2ce.png)

*Generating password in DuckDuckGo*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

5、生成随机密码短语

输入 `random passphrase` 可生成一段密码短语，通常长度为 4 个词。

![](../Images/925a472f9192fdd4ba2b5d0400714972.png)

*Random Passphrase*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

6、获取一份速查表

在需要看速查表的搜索词后面，可输入 `cheatsheet`。如果要搜索的东西有速查表，就会立即显示在搜索页面。

![](../Images/9853a2fba493b45e7ecab1e36b24bc54.png)

*Vim Cheatsheet*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

7、通过色码获取颜色

输入 `color` 并加上你想查的颜色的十六进制码，便可显示这个颜色。

![](../Images/86a14aa71ff84543f548fb94e27559df.png)

*Color*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

8、生成随机数

搜索 `random number` 会输出一个 0 到 1 之间的随机数。

![](../Images/25dbc6fb3938ffc82b27979350261052.png)

*Random Number*

你也可以指定需要的范围。

![](../Images/a04075e306c8fb14ba2622426152f213.png)

*Random Number between 1 and 1000*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

9、转换为二进制等形式

输入一个二进制数并加上 `binary`，可将其从二进制转换为十进制。

![](../Images/9d9df7e05f056efa0024fef5c463b882.png)

*Binary to Decimal*

类似地，它也能用于十六进制和八进制，但我不清楚它们的处理逻辑。

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

10、寻找韵词

输入 `what rhymes with` 并带上要找同韵词的词语。作诗能力变强了，对吧？

![](../Images/f6ce4c06f223e0f6f3493d6c85e19f9c.png)

*What rhymes with rain*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

11、获取拉马努金数、圆周率等常数

输入想获取数值的常数名，便可在搜索结果中看到它。

![](../Images/82655319ee27659313a87a65f1019e91.png)

*Ramanujan Number*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

12、查询现在谁在太空中

输入 `people in space` 获取当前在太空中的人员名单。同时还会显示他们在太空中居住的时间。

![](../Images/720b3a90728b0c67154da8613b518ec4.png)

*People in Space*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

13、查询网页是否无法访问

如果你想知道某个网站是你无法访问了，还是大家都无法访问了，只需在搜索词中输入 `is xyz.com down`。

![](../Images/df4e894c5426038c139cf9c08eb95cc9.png)

*Is down?*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

14、获取特定话题的名言

输入一个词并带上 `quotes`，就会显示与这个词相关的名言。

![](../Images/8b17bb2e4e0258d662fa0aba8e9a930b.png)

*Get quotes in DDG*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

15、获取占位文本

搜索 `lorem ipsum` 就可以获取 5 段占位文本。对 Web 开发者应该会有用。

![](../Images/53c8537f4e11c769ef96949b4246c705.png)

*Lorem ipsum*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

16、获取任意月份的日历

在年、月、日后面输入 `calendar`，就会为你显示该月份的交互式日历。

![](../Images/7b68ba472f3687ce8b9c197383576fcd.png)

*Calendar*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

17、生成二维码

在文字、链接等后面输入 `qr`，就会生成对应的二维码。

![](../Images/d3892e73722da1e8c8f7d4249562b050.png)

*QRCode*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

18、获取一些 CSS 动画

搜索 `css animations` 以获取一些 CSS 动画例子。

![](../Images/67150a5f94e52bab7b6cafd0b0e7b2c8.png)

*CSS Animations*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

19、展开短链接

如果有一个 Bitly 链接或其他短链接，但不确定它指向哪里，不必再跳转到充满垃圾信息的网页了，只需展开短链接，看看真正的网址。

在短链接后面输入关键词 `expand`，就会显示真正的目标 URL。

![](../Images/f92e37d4de70ad997c70ce06dd924997.png)

*Expand Link*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

20、获取特殊字符的 HTML 代码

搜索 `html chars`，可以获取一份很长的列表，上面有 HTML 实体及其描述，按下后会在结果中显示更多信息。

![](../Images/572689f98ea28a3b40b8a2fc56a95dda.png)

*HTML Chars*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

21、我用这东西干啥？

这功能没什么用。如果你输入 `why should I use this?` ，它就会在搜索结果顶部显示 `cause it's awesome`。显然，DuckDuckGo 在说他自己。

![](../Images/4c6dc0685096a00a85d02639ca22f3c8.png)

*Why should I use this?*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

22、转换大小写

大小写都可转换。`lowercase <大写搜索词>` 就会显示小写的结果

![](../Images/256f5f757f559ab7216b5112cd2945dd.png)

*Lowercase*

`uppercase <小写搜索词>` 就会显示大写的结果。

![](../Images/07bb018d5044dfad2e79baeef784384a.png)

*Uppercase*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

23、编码 URL

搜索 `encode` 并加上 URL，就会给出编码后的结果

![](../Images/5a95c67b92d9bf93387ad0a9de3a54df.png)

*URL Encode*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

24、Motherboard

搜索 `Motherboard` 就会看见左侧的 DuckDuckGo 的 logo 变了。它会显示选好的几个随机 logo。

![](../Images/34cb5c708330bf69e6ced605767523a6.png)

*Motherboard*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)

25、获取 HTML 色码

搜索 `color codes` 便可获得一份颜色表。一样，这个功能多为 Web 开发者和设计师所用。

![](../Images/25b22926b84d3b9506f22881fbc8fb9e.png)

*Color Codes*

![](../Images/ac75af0de0b87a99650fda9bfd2b744b.png)
