Mozilla Firefox 是一个让我对开源大开眼界应用程序。这对我来说，诚然不算是转折点，而只是累积效应中的一部分。因为是几个开源应用程序逐渐吸引我注意力，我已经不好分辨到底哪个程序的吸引力更大。但这却最终导致我彻底转向 Linux，并且从此之后再未回头。其实在我有意识地全面转向开源之 前，我就已经切换到使用火狐浏览器，而且一直是一个狂热的火狐用户。我的手机系统一直使用 Firefox OS，直到这个项目被放弃。不过有趣的是，我并不特别地认为自己是火狐的粉丝 。我从那时到现在一直 在使用火狐，这是因为从许多方面来说它都是最佳的浏览器。接下来是我认为应该马上 改用 Firefox🔗 getfirefox.org 的五个原因。

![](../Images/ca7e11e2327b496f900ed4f97ff92ec9.png)

1、Firefox 专注您的隐私

Firefox 的维护者是 Mozilla 基金会🔗 foundation.mozilla.org，这是一个完全不以您的个人信息为关注动机的非营利组织。Mozilla 不关心您搜索的内容、访问的网站或您在网站上逗留的时间。因为，简单而言，这跟本不是 Mozilla 的商业模式。但它显然是许多其他流行浏览器的商业模式。（我是不是知道的有点多了?）

即使您不并反对浏览器以隐私为由跟踪您的活动，您可能有过这样的经历:只是曾经一次性购买过某件不寻常的礼物，就导致您访问的每个网站都试图向您兜售该物品。互联网很大，所以有时根据用户的兴趣来重组它似乎是一个好主意。我承认，如果我所有的搜索信息都可以“开源”给软件供应商，可能他们会提供更有关联的结果。但话又说回来，我宁愿主动选择这种优化;而不想让他们以及许多其他未知因素一起，替我做出决定，我则完全是被动的。

  

![](../Images/b83b77fe2110eec4487ed2d17f16e2e4.png)

*Firefox 中的隐私 (Seth Kenlon, CC BY-SA 4.0)*

Mozilla 的数据政策是这样的: 尽量少拿、保持安全、毫无隐藏。🔗 blog.mozilla.org

不止如此，Firefox 还提供了帐户 监控🔗 monitor.firefox.com，这是 Mozilla 的一项可选服务，如果您的任何在线帐户因大 规模数据泄露而受到损害，它就会提醒您。另外，Mozilla 使用开源的 Wireguard 提供付费 VPN 服务， 因此无论何时、何地您都可以安全地浏览。

![](../Images/ca7e11e2327b496f900ed4f97ff92ec9.png)

2、Firefox 可以使用容器

很难相信的是，曾经有一段时间，当时领先的网页浏览器没有标签页功能。在上世纪 90 年代末和本世纪 00 年代初，当您想同时访问两个网页时，您必须打开两个单独的浏览器窗口。Firefox（以及之前的 Mozilla 浏览器）是标签页界面的早期使用者。

标签页是现在浏览器的标配，但是通过 Firefox 的扩展，标签页界面的功能有了有趣的新变化。由 Mozilla 自己开发的 Firefox 多帐户容器插件🔗 github.com 可以将每个标签页变成浏览器中的一个隔离的“容器”。

![](../Images/dfbd4d405d1c78a878ec9768c6bc67be.png)

*Firefox 中的容器化标签页 (Seth Kenlon, CC BY-SA 4.0)*

例如，假设您的雇主使用谷歌应用，但您信不过谷歌，担心它接触您的个人信息。您可以使用多账户容器插件来隔离您的工作活动，这样一来，谷歌仅仅能够触 及您的职业生活，而无法访问您日常生活中的任何部分。

您甚至可以使用两个不同的帐户打开同一个网站，此外由于标签页是用颜色标识的，因此无论您是要隔离网站还是只是在浏览器中添加新的视觉提示，这都很有帮助。

![](../Images/ca7e11e2327b496f900ed4f97ff92ec9.png)

3、Firefox 的用户界面设计

尽管我们人类可能对新事物更感兴趣，但在熟悉又可靠的东西中，我们能找到更多的舒适感。多年以来，Firefox 不断更新其界面，并且拥有了相当多的创新，而这些创新现在已经成为非官方的行业标准。但就总体来说，它一直保持不变。Firefox 的用户界面保留了您认为理所当然的所有标准惯例。

当您下载文件时，系统会提示您选择让 Firefox 如何处理该文件。根据您的选择，您可以在适当的应用程序中打开文件或将其保存到硬盘上。您可以选择让 Firefox 记住您的选择，并作为您将来的选择，或者让它继续提示您重新选择。

![](../Images/8349684e5278a4938f797822a990de21.png)

*Firefox用户界面设计 (Seth Kenlon, CC BY-SA 4.0)*

当您需要应用程序菜单时，可以在现代的“汉堡包式”的菜单中找到它，或者您可以按 `Alt` 键在 Firefox 的窗口顶部显示传统菜单。

无论您是否是 Firefox 的长期用户，其中的一切都看起来很熟悉，因为它建立在多年的用户界面设计经验之上。在可以创新的地方，它就会去创新，但是如果这些创新会违反直觉，将不会被采用。

![](../Images/ca7e11e2327b496f900ed4f97ff92ec9.png)

4、Firefox 的开发者工具

回溯万维网的早期，您可以浏览到任何网站并查看其源代码。仅仅这样做几次，就很有可能学习到 HTML 的很多知识。一切都是公开的、透明的、显而易见的，而且相对简单的。

互联网已经逐渐演变成为一个强大的 基于云的超级计算机🔗 www.redhat.com，现在从网站中提取有意义的上下文，有时需要的不仅仅是其底层标记的文本转存。为了确保每个人都可以对网站的功能进行逆向工程（和正向工程），Firefox 在浏览器中集成了一套功能强大的开发工具。

![](../Images/01e08233b633990a084d33140658b148.png)

*开发者工具 (Seth Kenlon, CC BY-SA 4.0)*

虽然这最初是基于 Firefox 的创新（在 2006 年推出的 Firebug🔗 getfirebug.com），但现在许多浏览器都具备了开发者工具功能。然而，并非所有的开发者工具都一样，正是 Firefox 的开发者面板使 Firefox 成为我进行网页设计和用户体验测试的首选浏览器。

![](../Images/ca7e11e2327b496f900ed4f97ff92ec9.png)

5、Firefox 是开源的

最为重要的是，Firefox 是完全开源的。这是一个优秀的浏览器，并且对您毫无隐藏。除了保持互联网开放，教育人们了解互联网，并推广日常工作的开源解决方案之外，它没有不可告人的动机。(《Ulterior Motive》是芬兰乐队成员 Emppu Vuorinen 的专辑《Guitar Heroes》中的一个作品。也许是玩了个双关语的梗)。用现在的网络语言说，一个开源浏览器能有什么坏心思呢。

![](../Images/8bb50519c69978b870606e02fa2a1cdc.png)

*Firefox 是开源的 (Seth Kenlon, CC BY-SA 4.0)*

您可以为 Firefox 做出贡献。您可以对您不喜欢的部分提交报告。您可以看到与互联网交互时运行的代码。几十年来，Firefox 一直在支持开放互联网。它忠于其自身开放的原则，并且可以说已经迫使几个竞争对手走向开源。如果 Firefox 没有抬高公众的期望，我想其他的浏览器是不可能选择开源的。

作为一款优秀的浏览器，火狐是现代互联网上的具有影响力的力量。它可以在您的桌面和移动设备上运行，因此想让自己轻松一点，就安装个 Firefox 吧🔗 getfirefox.com。
