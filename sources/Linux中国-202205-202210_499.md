# ProtonMail 改名为 “Proton”，致力于提供一个隐私生态系统 | Linux 中国

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664654592&idx=4&sn=fef1f13ac59da5dc54b27d5b1fbead70&chksm=bdcf5c468ab8d5509127783c5412bcac1b72323e60ee949c7c6360e6da1ecc72804e81e402f4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664654592&idx=4&sn=fef1f13ac59da5dc54b27d5b1fbead70&chksm=bdcf5c468ab8d5509127783c5412bcac1b72323e60ee949c7c6360e6da1ecc72804e81e402f4&scene=27#wechat_redirect)

 ![](../Images/e951c07210128cfba26a314707b0fe2f.png)**导读：**ProtonMail 宣布了重塑后的品牌，包括新网站、新名称、新的定价计划、新的 UI 和其他变化。本文字数：1192，阅读时长大约：1分钟  

ProtonMail🔗 itsfoss.com 将自己重新命名为 “Proton”，以将其所有产品囊括在统一的品牌下。

注意，别把它和 Steam 的 Proton（它也简称为 Proton）混淆哦！

换句话说，ProtonMail、ProtonVPN 和它的任何服务将不再有单独的产品页面。

![](../Images/1068e007ab220b67eb36df89bd31d3bc.png)

Proton：一个开源隐私生态系统

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_2420666757293146113](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_2420666757293146113)

Proton 将拥有一个新的统一平台（新网站），你可以在其中访问所有服务，包括：  

◈ Proton 邮件◈ Proton VPN◈ Proton 网盘◈ Proton 日历

现在，新的登录会话将会被重定向到 `proton.me` 而不是 `protonmail.com`、`mail.protonmail.com`、`protonvpn.com` 等等。

不仅限于名称/品牌，整体的强调色和现有的用户体验，也将受到影响。

![](../Images/43f9324ad630fb2606ddf4b34af46609.png)

现在，你只需一次付费订阅即可获得全部服务，而不必单独升级 VPN 和邮件。这也意味着，经过这次改变，高级订阅的价格变得更加实惠了。

![](../Images/28da93685bfe4db16950c670afcf1d67.png)

总体而言，让 “Proton” 成为隐私生态系统，是为了吸引更多对技术细节不感兴趣的用户来了解它是如何运作的。

你可以在其新的官方网站（proton.me🔗 proton.me）上查看所有详细信息。

新网站看起来更干净、更有条理，并且更具商业吸引力。

![](../Images/1068e007ab220b67eb36df89bd31d3bc.png)

本次更改的内容

你可以期待有一个焕然一新的用户界面，包括新的品牌和新的网站。

![](../Images/0a9a8a977d20f136d28d96bd2c5b7427.png)

*proton*

除此之外，Proton 还提到它改进了服务之间的集成，以获得更好的用户体验。

![](../Images/a37a75ada67c4fe770be93f50e20ce8b.png)

如果你已经在使用 ProtonMail，你可能知道，他们正在主动建议现有用户激活 “@proton.me” 帐户，这也是本次更改的一部分。

你可以选择将新电子邮件地址 xyz@proton.me 设为默认值，它更短，看起来也更有意义一些。

◈ 旧的电子邮件地址不会消失，只是额外提供了新地址（@proton.me）。◈ 现有的付费订阅者应该可以免费获得存储空间提升。◈ 升级了网页和移动应用中的用户体验。◈ 新的官方网站（你将被自动重定向到它以进行新会话）。◈ 新的定价计划，为 Proton 网盘提供更多存储空间。
