# 每天使用开源的 9 种方法 | Linux 中国

 ![](../Images/4dc0de1738d0e033c9b0eb9fbe38da67.png)**导读：**你可能会惊奇地发现，那些你每天使用的工具竟是开源的。　 　 　 　 　 　 　 　 　 　 　 　 　 　 　 　![](../Images/b049093edfece3ab0d9abb6de1f4397c.png)本文字数：2660，阅读时长大约：4分钟  

最近，我受邀介绍网络上可用的免费和开放资源。这次演讲是当地为保持我们社区的正常运转而做出的部分尝试 —— 由我家附近的 圣文德大学(St. Bonaventure University) Foster Center🔗 www.sbu.edu 赞助。我分享的一些资源不是开源的而是免费的，但许多工具是开源的。

看到有不少人知道我所提到的工具真的很有趣。很多人并不知道他们每天使用的工具都是开源的，并且他们还可以与他人分享。

![](../Images/b54a5b36f32de62ea64c8cf0010aca07.png)

开源浏览器

使用网络需要一个好的浏览器，而 Firefox 是开源的🔗 opensource.com，这一点很多在场的人并不清楚。除了是开源，Firefox 还具有强烈的隐私意识，这是许多用户越来越关注的问题。不过，有趣的是，即使是微软的新浏览器也是基于开源 Chromium 项目的。

![](../Images/b54a5b36f32de62ea64c8cf0010aca07.png)

开源网络隐私

通常，保护你的隐私和改善你的网络体验的另一种方法是使用 uBlock Origin 来阻止广告。根据他们的网站：

> uBlock Origin 是一个免费、开源、跨平台的内容过滤浏览器扩展——主要旨在以一种高效、用户友好的方法消除隐私侵犯。

其代码采用 GPL v. 3.0🔗 github.com 许可证。

电子前沿基金会(Electronic Frontier Foundation)（EFF）还维护 Privacy Badger🔗 privacybadger.org———— 这是一个根据 GPL v.3.0 许可的网络浏览器扩展程序。根据他们的 GitHub 存储库，它是：

> 一个可以自动学习阻止隐形的跟踪器的浏览器扩展程序。Privacy Badger 没有一个要阻止的列表，而是根据它们的行为自动发现跟踪器。

除了隐私之外，我的演讲还分享了安全密码的重要性。我的听众了解到了 Bitwarden🔗 github.com。许多人不知道如何生成安全密码、区分不同网站的密码以及如何安全地存储它们。我演示了该软件如何创建密码并使用 Bitwarden 将这些密码存储在云中。我解释了用户如何通过浏览器插件、台式机和笔记本电脑应用程序以及在安卓或 iOS 移动设备上访问这些凭证。

![](../Images/b54a5b36f32de62ea64c8cf0010aca07.png)

开源通讯工具

本次演讲中，我谈到了通讯工具在我们生活中的无处不在，但同时它本身固有的不安全性。观众不知道 Signal🔗 opensource.com。我已经使用 Signal 几年了，并经常鼓励其他人将其视为一个安全的消息传递平台。在 Linux、macOS、Windows、安卓🔗 play.google.com 和 iOS🔗 apps.apple.com 上 安装 Signal🔗 signal.org 很容易，它提供了出色的 文档🔗 support.signal.org 支持，对不同的操作系统都有着详细的安装说明。Signal 使用你现有的手机号码，只要它可以发送和接收短信和打电话。当你第一次在手机上设置 Signal 时，它会在你的通讯录上搜索同样使用 Signal 的联系人。

![](../Images/b54a5b36f32de62ea64c8cf0010aca07.png)

开源办公工具

如果不提及我最喜欢的内容创建工具 LibreOffice🔗 opensource.com，那么关于开源工具的介绍是不完整的。尽管它很受欢迎，但还是有许多人并不知道它的存在以及使用它所带来的自由。我每天都用它来写文章。我使用它来做表格而不是 Excel，有时我用它来做演示文稿。你可以在 Linux、macOS 和 Windows 上下载并安装它。LibreOffice 的优点之一是你真正拥有自己的文档，不需要昂贵的程序来访问它们。

![](../Images/b54a5b36f32de62ea64c8cf0010aca07.png)

开源博客软件

WordPress🔗 opensource.com 是我最喜欢的博客引擎，你可以通过多种方式使用它，无论是分享你对世界大事的看法、为你的 学生🔗 opensource.com 提供低成本写作平台，还是在网上为你的 业务🔗 opensource.com 做宣传。

![](../Images/b54a5b36f32de62ea64c8cf0010aca07.png)

开源媒体库

在创建内容时，你需要可以轻松合法共享的图片来说明你的作品。OpenClipart🔗 openclipart.org 是我的首选。这里有数以千计的各种流行格式的图片，可以放在你的 LibreOffice 文档和博客文章中。此外，你可以通过 知识共享🔗 search.creativecommons.org(Creative Commons) 找到你可以分享的图片，并注明适当的出处。知识共享提供的许可，使共享变得更容易。它是版权的延伸，让分享图片变得更容易。但请务必熟悉许可证之间的细微差别。

![](../Images/b54a5b36f32de62ea64c8cf0010aca07.png)

开源视频会议

疫情改变了会议和聚会的模式。正如 Chris Hermansen此处🔗 opensource.com 所报告的那样，Jitsi、Big Blue Button 和其他一些软件已经彻底改变了我们互动和学习的方式。

![](../Images/b54a5b36f32de62ea64c8cf0010aca07.png)

开源教育资源

开放教育资源解放了学习。通过 OER Commons🔗 www.oercommons.org，你可以找到满足你需求的内容，从学前班到研究生和专业学位，它是公开许可的，因此你可以使用它并与他人分享。麻省理工学院（MIT）开放课件提供了麻省理工学院几乎所有的本科生和研究生项目内容，均根据知识共享 非商业性共享方式🔗 ocw.mit.edu 许可提供。OpenStax🔗 openstax.org 是莱斯大学的一项开放教科书计划，提供经过同行评审的教科书，这些教科书已公开许可并免费提供。

![](../Images/b54a5b36f32de62ea64c8cf0010aca07.png)

开源播客工具

播客已成为了解最新 开源新闻🔗 opensource.com 的好方法。你有没有想过做自己的播客？我熟悉一些很棒的开源工具能够帮你实现这一目标。Audacity🔗 opensource.com 是我最喜欢的录音应用程序。我用它来翻录我的课堂教学、记录访谈和试验音效。它是一个 16 轨音频编辑器，你可以通过多种方式使用它。如果你有话要说或有技能要传授，你应该使用 Open Broadcaster Software🔗 opensource.com（OBS）。

![](../Images/b54a5b36f32de62ea64c8cf0010aca07.png)
