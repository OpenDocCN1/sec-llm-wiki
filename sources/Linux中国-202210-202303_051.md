在这篇文章中，我们将介绍如何在笔记本电脑或台式机上一步一步地安装 elementary OS 7，并附有截图。它基于最新和稳定的 Ubuntu 22.04 LTS。

elementary OS 7 的代号为 “Horus”，并带来了很多改进，例如：

◈ 改进了 AppCenter 和安装所有需要的应用。◈ 改进了侧载和可选商店（Flathub）的体验。◈ 最新的 GNOME Web 43，支持创建网络应用。◈ 快速获得操作系统和应用的更新◈ 电源配置文件管理◈ 应用描述的改进![](../Images/5d186b079553f95fd17c3b8b7381b9a8.png)

elementary OS 7 的系统要求

◈ 双核 64 位处理器◈ 4GB 内存或更多◈ 32GB 硬盘◈ 互联网接入◈ 可启动的 USB 驱动器（4GB 存储空间）

闲话少说，让我们进入安装步骤：

![](../Images/5d186b079553f95fd17c3b8b7381b9a8.png)

1）下载 elementary OS 7

使用下面的官方网址来下载 ISO 文件。

> 下载 elementary OS 7 ISO🔗 elementary.io

ISO 文件下载完成后，将其刻录到 USB 驱动器，并使其可启动。

在 Windows 操作系统中，用 Rufus 制作可启动的 USB 驱动器。在 Linux 中，请参考以下网址：

> 如何在 Ubuntu/Linux Mint 上创建可启动的 USB 驱动器🔗 www.linuxtechi.com

![](../Images/5d186b079553f95fd17c3b8b7381b9a8.png)

2）用可启动介质启动系统

现在用可启动的 USB 驱动器启动目标系统。从 BIOS 设置中把启动介质从硬盘改为 USB。当系统用 USB 驱动器启动时，我们将看到以下页面。

![](../Images/03cff43544c3e547e33630c81aeee75a.png)

![](../Images/5d186b079553f95fd17c3b8b7381b9a8.png)

3）选择安装语言

选择你喜欢的语言，然后点击“选择(Select)”。

![](../Images/e7877edcae1024aa5bf2460f9f68893b.png)

![](../Images/5d186b079553f95fd17c3b8b7381b9a8.png)

4）选择键盘布局

在这一步，你将被要求选择键盘布局，然后点击“选择(Select)”。

![](../Images/7a488a74d965dda849a0fe5f78d8b991.png)

![](../Images/5d186b079553f95fd17c3b8b7381b9a8.png)

5）尝试或安装 elementary OS

我们将看到下面的页面，在这里我们必须选择安装类型。它给了我们以下选项：

◈ 试用演示模式(Try Demo Mode) – 试用 elementary OS 7 而不安装◈ 擦除磁盘并安装(Erase disk and Install) – 安装程序将擦除整个磁盘并自动创建所需分区。◈ 自定义安装（高级）(Custom Install (Advanced)) – 它将给我们一个选项来创建自定义分区。

在这篇文章中，我将使用第二个选项（擦除磁盘并安装）。

![](../Images/07ca77d4461b7847aa2f271dbd32a0cf.png)

点击“擦除磁盘并安装(Erase disk and Install)”。

在下面的屏幕上，选择要安装操作系统的驱动器，然后点击“擦除并安装(Erase and Install)”。

![](../Images/747f042abb657d7c88d0a0473e6ff35f.png)

如果你想对设备的驱动器进行加密，那么点击“选择密码(Choose Password)”，否则点击“不加密(Don’t Encrypt)”。

![](../Images/c1a2a17ee36c0b3c888225671288f8e3.png)

![](../Images/5d186b079553f95fd17c3b8b7381b9a8.png)

6）安装进度

正如我们在下面看到的，安装已经开始，并且正在进行中。

![](../Images/80bd5e235a0801c666e3d5ba2ed2a389.png)

安装完成后，安装程序将提示重启系统。

![](../Images/3a604b5e0d14ed72c5fba39cd1b41d68.png)

点击“重启设备(Restart Device)”，不要忘记从 BIOS 设置中改变启动介质，以便用磁盘启动。

![](../Images/5d186b079553f95fd17c3b8b7381b9a8.png)

7）创建本地用户并设置主机名

当系统在安装后启动时，系统会提示你输入本地用户的详细信息和系统的主机名。

根据你的要求指定这些细节。

![](../Images/64f952f6d990f717f949c7560193babb.png)

点击“完成设置(Finish Setup)”。

在下面的页面中，你将被提示输入你在上面创建的本地用户凭证。

![](../Images/a58ba9789b1edcab397b48630cbd1569.png)

输入凭证后，点击回车。

![](../Images/5d186b079553f95fd17c3b8b7381b9a8.png)

8）elementary OS 7 欢迎页

我们将看到下面的欢迎页。

![](../Images/bbee8bb083d91e4ad864b7eaa31d89bb.png)

选择“跳过所有(Skip All)”。

![](../Images/dda9d863c061165dd27ec9a3bc27ab7a.png)

点击“开始使用(Get Started)”，然后我们会看到下面的桌面。

![](../Images/279f5e6d164cd50fe94b5ebedd19caca.png)

很好，这表明你已经成功地在系统上安装了 elementary OS 7。这就是本指南的全部内容，请探索这个令人兴奋的 Linux 发行版并享受其中的乐趣吧😊。
