ChatGPT🔗 chat.openai.com 是一个在当下十分流行的聊天机器人，它可以与用户进行互动，用户就像在对话一样。

最近，关于 ChatGPT 的新闻时常出现在人们的视野之中，有时是关于 ChatGPT 的坏消息。

不难看出，ChatGPT 有其两面性。事实上，对于任何人工智能的实现都同样如此。

一方面，ChatGPT 这一工具的巨大潜力给许多人留下了深刻的印象。但另一方面，因人们对它的滥用/误用，导致 ChatGPT 在科技界引起了轩然大波。

人们对 ChatGPT 滥用/误用太多了，以至于其创建者 OpenAI🔗 openai.com 开发了一种工具来检测 ChatGPT 的使用情况，这个内容可以进一步访问 此网页🔗 news.itsfoss.com。

现在，我注意到在一个 Reddit 讨论中，一位开发人员提到了一些有趣的事情。

一个用户名为 HorrorPills🔗 github.com 的开发人员已经开始为 ChatGPT 开发 GNOME 扩展。

这听起来非常有趣，让我们继续来看看吧。

![](../Images/0fc61a38af263226d620e631026deb35.png)

这个扩展仍在开发中：让我们持续保持关注吧！

![](../Images/c4459e6a1074912492cca3ea348ede67.png)

*chatgpt gnome extension*

这是一个 GNOME 桌面扩展，将 ChatGPT 添加到了桌面的 系统托盘(system tray) 中。

现在，这个 GNOME 桌面扩展还处于未完成的状态，它已经具有了基本的功能，但仍存在一些错误。

正如它的开发者 所说🔗 www.reddit.com 的那样：

你需要有一个 ChatGPT 帐户，才能使用这个扩展程序，并且需要用到你的键盘，才能进行定位，因为现在这个扩展的光标功能还有很多问题。

此外，这个扩展对 GNOME 43 的支持也很不完整，他们提供了一个临时的修复程序，并将这个进一步完善的任务添加到此扩展的后续开发中。

如果你喜欢的话，你可以试试这个扩展。你可以通过它的 GitHub 仓库🔗 github.com，来获取运行它所需的所有说明和文件。

它的开发人员还 表示🔗 www.reddit.com：当这个扩展变得更加稳定时，他们会将这个扩展发布到 GNOME 扩展 网站🔗 extensions.gnome.org 上去。

此外，开发人员还 透露🔗 www.reddit.com：他们在未来可能会实现 KDE Plasma 的 ChatGPT 扩展。
