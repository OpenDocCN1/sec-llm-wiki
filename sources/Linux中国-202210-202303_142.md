> 一个不错的 GNOME 扩展：Colorblind Filters，它为色盲用户带来了许多调整选项。

无障碍是计算和操作系统的一个重要方面。它包括对视力障碍、色盲和许多其他健康症状的管理设置。流行的 Linux 桌面环境，如 GNOME 和 KDE Plasma，具有无障碍设置，以帮助所有这些情况。

感谢 GNOME 扩展生态系统，有大量的专门扩展可以帮助这些用户。我遇到的其中一个扩展是“Colorblind Filters”🔗 extensions.gnome.org。

![](../Images/6664dfb08d5ce38a0a06f4bcad3cfd56.png)

Colorblind Filters – GNOME 扩展

根据维基百科，"色盲通常涉及无法区分红色和绿色的深浅。遗传性色盲症没有治疗方法。如果色盲是由其他疾病引起的，治疗潜在的原因会有帮助。"。

因此，你有可以调整你的 Linux 桌面设置的选项是很重要的。

![](../Images/6664dfb08d5ce38a0a06f4bcad3cfd56.png)

设置扩展程序和 Flatpak

首先，确保你已经启用了 Flatpak 和 GNOME 扩展。并且安装了扩展管理器。你可以参考这个关于如何 设置 flatpak🔗 www.debugpoint.com 和启用 GNOME 扩展🔗 www.debugpoint.com 的详细指南，或者从终端运行以下命令（对于 Ubuntu、Linux Mint 等）。

```
1.  `sudo apt install flatpak`
2.  `sudo apt install gnome-software-plugin-flatpak`
3.  `flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo`
4.  `reboot`
5.  
```

对于 Fedora 用户，使用以下命令。

```
1.  `sudo dnf install flatpak`
2.  `sudo dnf install gnome-software-plugin-flatpak`
3.  `flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo`
4.  `reboot`
```

完成后，安装扩展管理器：

```
1.  `flatpak install com.mattjakeman.ExtensionManager`
```

![](../Images/6664dfb08d5ce38a0a06f4bcad3cfd56.png)

安装扩展

从应用菜单中打开扩展管理器。搜索 “colorblind”。并安装该扩展（见下图）。

![](../Images/3036436f9ea54703bb243e5247c5200c.png)

*安装扩展*

安装后，你可以在系统托盘上看到一个小眼睛图标。你可以点击它来启用预定义的颜色过滤器。

![](../Images/4a45d6810f2bb55c7ccbb8f3a4afdba6.png)

*Colorblind Filters 扩展托盘图标*

右键点击眼睛图标以获得更多设置。这个扩展带来了色盲集合、模拟和额外选项的所有必要定制。目前有以下选项：

◈ 纠正和模拟（具有高对比度）◈ 红色盲◈ 绿色盲◈ 蓝黄色盲◈ 额外的调整◈ GBR 和 BRG 的通道混合器◈ 亮度反转◈ 颜色反转

![](../Images/19d2b9379cf17576c0a2c678e041e0ea.png)

*Colorblind Filters - 选项*

使用最适合你的眼睛的那个。

![](../Images/6664dfb08d5ce38a0a06f4bcad3cfd56.png)

总结

我认为苹果的 macOS 和 iOS 已经实现了比 Windows 或 Linux 更好的无障碍。然而，Linux 桌面在这些应用和扩展方面也不落后。另外，还有一些专门的 Linux 发行版，如 “Accessible Coconut🔗 www.debugpoint.com”，它是为专门的需求而建立的。

我希望 Colorblind GNOME 扩展对你日常使用 Linux 和 GNOME 桌面有帮助。

干杯。
