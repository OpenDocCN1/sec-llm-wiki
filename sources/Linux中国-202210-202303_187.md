# Fedora 38 将发布 Budgie 和 Sway 官方定制版 | Linux 中国

我们期待着它们在 Fedora 37 时出现，但在 Fedora 38 中终于来了！

早在 2022 年 5 月，Budgie 项目的主要开发者 Joshua Strobl 宣布🔗 www.reddit.com，Budgie 已被提交到 Fedora 中。

遗憾的是，在那之后不久，我们并没有看到任何官方 Fedora 定制版🔗 spins.fedoraproject.org 发布的迹象，尽管它在 Fedora 37 发布🔗 news.itsfoss.com 期间进入了 Fedora 软件库。

但现在有了。

随着 Fedora 38 的发布，看起来我们会得到一个 Budgie🔗 blog.buddiesofbudgie.org 的官方定制版，同时还有一个 Sway🔗 swaywm.org 窗口管理器的定制版。

![](../Images/4c0c08cd024b13d98ee8dcc1ab856265.png)

Fedora Budgie 和 Sway

在 最近的一次会议🔗 lists.fedoraproject.org 上，Fedora 工程和指导委员会（FESCo）投票决定将 Budgie 和 Sway 窗口管理器的 Fedora 官方定制版纳入 Fedora 38 的发布中。

根据 Budgie 和 Sway 的初步修改建议，我们可以期待很多变化。

对于 Budgie：

◈ Fedora 38 将提供 Budgie 桌面环境，包含一套核心应用程序，如用于更新/软件包管理的 GNOME “软件”应用、一个文本编辑器、一个网页浏览器和一个终端。◈ 它还将使用 Materia GTK🔗 github.com 和 Papirus🔗 github.com 图标主题，整个系统采用 GTK 主题设计。◈ Budgie 定制版还将采用 lightdm + slick-gtk-greeter，以获得更直观的用户问候体验。

对于 Sway 定制版：它旨在提供一个极简体验，只包括默认配置之上的一些元素。

预期时间：随着 Fedora 38 的开发在未来几个月内的加快，你可以期待这些定制版在 2023 年 4 月期间出现。当然，会有预装了 Budgie 和 Sway 的单独 ISO 文件。

因此，我认为看到 Budgie 与 Fedora 的体验会非常吸引人，特别是当 Budgie 的开发似乎正在发生一些有趣的变化。
