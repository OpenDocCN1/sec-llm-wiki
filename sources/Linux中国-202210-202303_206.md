# Unity 正在积极开发，预告 7.7 版 | Linux 中国

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664672994&idx=2&sn=f6a1a5a3601a01a07299848a72dd9777&chksm=bdcf95a48ab81cb2beaaf3bc84fdcf83269408e57e4e50d9bd973b3d027eee984805e0eb2d62&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664672994&idx=2&sn=f6a1a5a3601a01a07299848a72dd9777&chksm=bdcf95a48ab81cb2beaaf3bc84fdcf83269408e57e4e50d9bd973b3d027eee984805e0eb2d62&scene=27#wechat_redirect)

 ![](../Images/5c5b161803a67e2787647685a912744d.png)**导读：**Unity 7.7 版的更新计划为该桌面环境带来一些视觉上的改革。　 　 　 　 　 　 　 　 　 　 　 　![](../Images/4a28f981f4a90d5cd7bbe1d6cbe32338.png)本文字数：1342，阅读时长大约：2分钟  

Unity，经典的桌面环境，从 2010 年到 2017 年都是 Ubuntu 的一部分，将收到一个大的新版本。你可以期待它在 2023 年的某个时候发布，但目前还没有具体的发布日期。

但不是由 Canonical🔗 canonical.com 发布。

如果你不知道： Unity 的开发由一位年轻的开发者 Rudra Saraswat🔗 about.ruds.io 接手，他也是 Ubuntu Unity🔗 ubuntuunity.org 衍生版的创造者，这是 Ubuntu 的一个官方特色版。

在最近的一篇 博文🔗 unityd.org 中，Rudra 向我们揭示了 Unity 7.7 的一角和即将到来的各种改进。

让我带你看看这些。

![](../Images/025ea78d9bfb08b0f3b38af8a496fb17.png)

Unity 7.7 值得期待的地方

![](../Images/b3bf5025a1c93e92c5f7d7bbd92f4be3.png)

*unity 7.7 一窥*

这次披露的内容有很多，其中包括：

◈ 更新的欢迎应用程序◈ UWidgets◈ 改进的仪表盘◈ 面板的调整◈ 增强的通知指示器![](../Images/025ea78d9bfb08b0f3b38af8a496fb17.png)

更新的欢迎应用程序

![](../Images/7778bde95a64a93d38008a49f5368fc9.png)

一个新的欢迎应用程序将被引入 Unity，它基于 Ubuntu Flutter 社区开发的原型（用 Flutter🔗 flutter.dev 编写）。

这个应用程序将不只限于一个发行版，而是适用于 Unity 所支持的所有发行版。

![](../Images/025ea78d9bfb08b0f3b38af8a496fb17.png)

UWidgets

![](../Images/183989b19cc2f7de9b94efa8d96dd8ac.png)

终于有了，Unity 桌面上的小部件？像 KDE 一样？

好吧，在 Unity 中引入用 Python 编写的小部件，应该很简单就可以设置（只是复制几个文件的问题）。

屏幕截图展示了一堆小部件，如时钟、系统监视器、Spotify 的小部件等等。

这还不是全部，Rudra 还提到：

> 我们将为 UWidgets 建立一个网页商店/仓库，在那里你可以提交你自己的小部件，或者下载并试用 Unity 7.7 上所有这些令人惊叹的小部件。

这应该会使用户更容易找到和下载小部件！

![](../Images/025ea78d9bfb08b0f3b38af8a496fb17.png)

改进的仪表盘

![](../Images/87b059abe4507dd7fd1a66ba22574f73.png)

仪表盘(Dash)也被刷新了，新的设计基于 Unity 7 的原始设计概念（在 Canonical 放弃它之前）。

按照截图，它应该不会占用大量的屏幕空间，而且还很有用。

![](../Images/025ea78d9bfb08b0f3b38af8a496fb17.png)

面板的调整

![](../Images/fdc1709de67ea8b46db6a1d822268796.png)

现在的面板比之前的版本略大且更精致。

![](../Images/025ea78d9bfb08b0f3b38af8a496fb17.png)

增强的通知指示器

![](../Images/6bb9bb3c0b91486d90ba652112b96309.png)

这对 Unity 来说是一个巨大的可用性改进；用户现在终于可以利用一个适当的通知指示器了。

它将显示与你的应用程序、系统和更多相关的基本通知。

![](../Images/025ea78d9bfb08b0f3b38af8a496fb17.png)

其他变化

![](../Images/b06225b19a2e1c26c88cf860323c54ba.png)

一些更有用的技术改进包括：

◈ unity-control-center 的外壳 UI 得到了改进◈ 默认的面板不透明度降低到 0.75◈ 默认的启动器图标尺寸被缩小了◈ 启动器按钮（Ubuntu 图标）被替换为半透明的图标，类似于 Ubuntu Unity 21.04 的启动器按钮。
