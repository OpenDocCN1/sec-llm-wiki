# 紧急消息：由于阿里云服务故障，Linux.cn 不可访问

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664672256&idx=2&sn=f0b537bf193737912fcebff4c2d8755e&chksm=bdcf97468ab81e50c5964498ae29d271eaf9e48ed774abf3123af1b3a2bec897007b3fc73739&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664672256&idx=2&sn=f0b537bf193737912fcebff4c2d8755e&chksm=bdcf97468ab81e50c5964498ae29d271eaf9e48ed774abf3123af1b3a2bec897007b3fc73739&scene=27#wechat_redirect)

在今天上午 10:46 分，阿里云香港的 C 可用区出现严重故障，致使托管在此的 Linux 中国的官网（https://linux.cn/）至今（现在是 15:30）不能访问。

特此向诸位朋友说明。

目前阿里云仍不能给出具体恢复时间，但其状态页面显示一切正常。
