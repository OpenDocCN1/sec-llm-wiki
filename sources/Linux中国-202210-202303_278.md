> 了解 for 循环结构和你在控制它时拥有的选项，这样你可以对如何在 Lua 中处理数据做出聪明的决定。

在编程中，迭代是一个重要的概念，因为代码通常必须多次扫描一组数据，以便它可以单独处理每个项目。控制结构使你能够根据通常在程序运行时动态建立的条件来指导程序的流程。不同的语言提供不同的控制，在 Lua🔗 opensource.com 中，有 `while` 循环、`for` 循环和 `repeat until` 循环。本文介绍 `for` 循环。我将在另一篇文章中介绍 `while` 和 `repeat until` 循环。

![](../Images/4e5768e8b392a5f43eebede2384f3bce.png)

for 循环

`for` 循环接受已知数量的项目并确保处理每个项目。“项目”可以是数字，它也可以是一个包含多个条目或任何 Lua 数据类型的表。语法和逻辑有点灵活，但语法允许这些参数，每个参数本质上描述了一个计数器：

◈ 计数器的起始值◈ 停止值◈ 你希望计数器前进的增量

例如，假设你有三个项目并希望 Lua 处理每个项目。你的计数器可以从 3 开始一直持续到 1，增量为 -1。这呈现为 3、2、1 的计数。

```
1.  `mytable = { "zombie", "Halloween", "apocalypse" }`
2.  `for count = 3, 1, -1 do`
3.  `  print(count .. ": " .. mytable[count])`
4.  `end`
```

运行代码以确保所有三个项目都得到处理：

```
1.  `$ lua ./for.lua`
2.  `3: apocalypse`
3.  `2: Halloween`
4.  `1: zombie`
```

这段代码有效地“反向”处理了表，因为它是倒数。你可以正数：

```
1.  `for count = 1, 3, 1 do`
2.  `  print(mytable[count])`
3.  `end`
```

此示例从最低索引到最高索引处理表：

```
1.  `$ lua ./for.lua`
2.  `1: zombie`
3.  `2: Halloween`
4.  `3: apocalypse`
```

增量

你也可以更改增量。例如，也许你想要一个没有万圣节盛况的僵尸启示录：

```
1.  `mytable = { "zombie", "Halloween", "apocalypse" }`
2.  `for count = 1, 3, 2 do`
3.  `  print(mytable[count])`
4.  `end`
```

运行代码：

```
1.  `$ lua ./for.lua`
2.  `zombie`
3.  `apocalypse`
```

该示例打印了 1 和 3，因为第一个计数是 1，然后递增 2（总共 3）。

![](../Images/4e5768e8b392a5f43eebede2384f3bce.png)

计数器

有时你不知道需要 Lua 遍历数据的次数。在这种情况下，你可以将计数器设置为由其他进程填充的变量。

另外，`count` 这个词不是关键字。为了清楚起见，这正是我在示例代码中使用的内容。程序员通常使用更短的名称，例如 `i` 或 `c`。

```
1.  `var = os.time()`
2.  `if var%2 == 0 then`
3.  `  mytable = { var }`
4.  `else`
5.  `  mytable = { "foo", "bar", "baz" }`
6.  `end`
7.  `for c = 1, #mytable, 1 do`
8.  `  print(mytable[c])`
9.  `end`
```

此代码创建一个变量，其中包含启动时的时间戳。如果时间戳是偶数（除以 2 时模数为 0），则只将时间戳放入表中。如果时间戳是奇数，它将三个字符串放入一个表中。

现在你无法确定你的 `for` 循环需要运行多少次。可能是一次或是三次，但没有办法确定。解决方案是将起始计数设置为 1，将最终计数设置为表的长度（`#mytable` 是确定表长度的内置快捷方式）。

可能需要多次运行脚本才能看到这两个结果，但最终，你会得到如下结果：

```
1.  `$ lua ./dynamic.lua1665447960`
2.  `$ lua ./dynamic.lua`
3.  `foo`
4.  `bar`
5.  `baz`
```

带 pairs 和 ipairs 的 for 循环

如果你已经阅读了我关于 表迭代🔗 opensource.com 的文章，那么你已经熟悉了 Lua 中最常见的 `for` 循环之一。这个使用 `pairs` 或 `ipairs` 函数来迭代一个表：

```
1.  `mytable = { "zombie", "Halloween", "apocalypse" }`
2.  `for i,v in ipairs(mytable) do`
3.  `  print(i .. ": " v)`
4.  `end`
```

`pairs` 和 `ipairs` 函数“解包”表并将值转储到你提供的变量中。在此示例中，我将 `i` 用于 索引，将 `v` 用于 值，但变量名称无关紧要。

```
1.  `$ lua ./for.lua1: zombie2: Halloween3: apocalypse`
```

![](../Images/4e5768e8b392a5f43eebede2384f3bce.png)

for 循环

`for` 循环结构在编程中很常见，由于经常使用表和 `pairs` 函数，因此在 Lua 中非常常见。了解 `for` 循环结构和控制它时的选项意味着你可以就如何在 Lua 中处理数据做出明智的决定。
