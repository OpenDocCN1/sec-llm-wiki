# Kali Linux 发布今年最后一个版本 | Linux 中国

Kali Linux 是一个开源的、基于 Debian 的发行版，专注于渗透测试和安全审计。

它由各种工具、配置和自动化脚本组成，以帮助你实现这一目标。

作为今年的最后一个版本，Kali Linux 2022.4 与其 前一个版本🔗 news.itsfoss.com 相比有许多改进。

让我带你了解这个版本。

![](../Images/4e5768e8b392a5f43eebede2384f3bce.png)

🆕 有什么新变化？

![](../Images/6a3a385e3d35e3671d00e1dc592d65e7.png)

*kali linux 22.04*

Kali Linux 2022.4 以更新的形式早早带来了圣诞礼物；这里有一些快乐的东西！🎄

◈ Linux 内核 6.0◈ 返回微软 Azure 市场◈ 支持 Pine 64 的 PinePhone◈ 新的桌面环境◈ QEMU 镜像◈ 新的工具![](../Images/4e5768e8b392a5f43eebede2384f3bce.png)

支持 Pine 64 的 PinePhone

![](../Images/9f0fa3ec76343117183b0f72dc19c436.png)

*kali linux nethunter pro on pinephone pro*

Kali Linux 现在已经正式支持 Pine 64 的 PinePhone 和 PinePhone Pro。

这种支持是以一种新的以移动为重点的发行版的形式出现的，名为 “Kali NetHunter Pro”。

他们把它标记为 Kali Linux 和 NetHunter🔗 www.kali.org 的一个新的起点；这个发行版已经为移动设备进行了优化，可以从 SD 卡上与主操作系统一起双启动。

此外，他们还暗示未来将发布 Kali NetHunter Pro 的替代版本。

这些版本将以 Plasma Mobile 为特色，同时提供了新的安装程序，可以将 Kali NetHunter Pro 安装到设备的内部闪存中。

![](../Images/4e5768e8b392a5f43eebede2384f3bce.png)

返回微软 Azure 市场

![](../Images/5c02c2c692e9f7c409bf78867e37a736.png)

*kali linux 22.04 Azure Marketplace*

在离开 Azure 市场很长时间后，Kali Linux 终于被 添加回来🔗 azuremarketplace.microsoft.com 了。

Kali Linux 背后的公司 Offensive Security🔗 www.offensive-security.com 提到，借助 kali-cloud build-scripts🔗 gitlab.com，现在发布过程已经自动化了。

用户现在将享受与他们的 亚马逊 AWS 镜像🔗 aws.amazon.com 相同的一致性水平。

![](../Images/4e5768e8b392a5f43eebede2384f3bce.png)

新的桌面环境

![](../Images/92d8d5d4116020e2dd210a86746eef55.png)

*kali linux 22.04 with gnome 43*

通常情况下，Kali Linux 使用轻量级的 Xfce 桌面环境作为其默认的桌面环境。

但现在，它也支持最近的 KDE Plasma 和 GNOME。

在 Plasma 方面： Kali Linux 现在采用了 KDE Plasma 5.26；改善了整体的桌面体验，并引入了许多调整和改进。

在 GNOME 方面： 包括了 GNOME 43🔗 news.itsfoss.com 的常规增强，他们也增加了一些自己的调整。

在 adw-gtk3🔗 github.com 项目的基础上增加了一个新的基于 GTK3 的主题，并加入了一些 Kali 的调整。

然后，新的 GNOME 文本编辑器取代了 Gedit，并带有一个更新的 Kali 主题。

![](../Images/4e5768e8b392a5f43eebede2384f3bce.png)

QEMU 镜像

他们还在预生成的镜像库中增加了一个新的 QEMU 镜像🔗 qemu-project.gitlab.io，希望它能让人们更容易在 Proxmox Virtual Environments🔗 www.proxmox.com、virt-manager🔗 virt-manager.org 或 libvirt🔗 libvirt.org 等自托管环境中部署 Kali Linux。

![](../Images/4e5768e8b392a5f43eebede2384f3bce.png)

🛠️ 其他变化/改进措施

除了上述变化，还有其他几个值得注意的变化：

◈ 增强了对 Kali NetHunter 的蓝牙支持。◈ 增加了 Kali 对树莓派镜像烧录工具的支持。◈ USBArmory MKII 中的 u-boot 引导加载器已经更新到 2022.10。◈ 更新了各种 Kali 文档。◈ 新的工具，如 bloodhound.py🔗 bloodhound.py、certipy、rizin-cutter 等等。◈ 重新打造了 Kali Linux 的社交媒体渠道。

你可以通过 发布公告🔗 www.kali.org 来了解更多技术细节。

![](../Images/4e5768e8b392a5f43eebede2384f3bce.png)
