# Linux Lite 6.2 发布 | Linux 中国

Linux Lite 是一种流行的轻量级的类 Windows 发行版，为用户提供了一个熟悉的操作系统感受。

最新版本 Linux Lite 6.2 基于 Ubuntu 22.04 LTS，对 UI 进行了各种更改以及各种错误的修复。

![](../Images/e1355156346b7c78ee40b42511ee175c.png)

Linux Lite 6.2：有什么新功能？

![](../Images/56889029a8d4b4a91bfbc001193763e3.png)

*linux lite 6.2 desktop*

此版本的 Linux Lite 侧重于用户界面调整和错误修复，并对一些应用程序进行了更改。

一些主要亮点包括：

◈ 更新的图标◈ 新壁纸◈ Shotcut 视频编辑器◈ 删除微软 Teams◈ LibreOffice 7.3.6.2◈ Linux 内核 5.15![](../Images/e1355156346b7c78ee40b42511ee175c.png)

Shotcut 取代 OpenShot

![](../Images/d2102c26f95f697325edcf9862c18cf5.png)

*linux lite 6.2 shotcut video editor*

是的，Shotcut🔗 shotcut.org 现在取代了 OpenShot🔗 www.openshot.org，成为 Linux Lite 6.2 上的默认视频编辑器。

OpenShot 之所以被删除，是因为它不能很好地与 Ubuntu 22.04 配合使用，而如果没有一个好用的视频编辑器，用户将不得不自己寻找一个。

Shotcut 无疑是一款出色的视频编辑器。所以，应该是一个不错的选择。

![](../Images/e1355156346b7c78ee40b42511ee175c.png)

微软 Teams 已删除

另一个重大变化是微软 Teams 不再包含在发行版中。

其原因是微软停止了 Linux 应用程序，转而支持一个渐进式 Web 应用程序版本。

我们之前的报道可以让你更深入地了解：

> 微软决定放弃 Teams 的 Linux 应用，代之以渐进式Web应用🔗 news.itsfoss.com

![](../Images/e1355156346b7c78ee40b42511ee175c.png)

更新的图标和新壁纸

![](../Images/f6599c69d6cdb36a10bfc29ecb1dd461.png)

*linux lite 6.2 new wallpapers*

Linux Lite 6.2 具有最新的 Papirus🔗 github.com 图标集以及一系列新的 Linux Lite 主题壁纸。

这应该会给发行版带来用户可能喜欢的焕然一新的外观。

![](../Images/e1355156346b7c78ee40b42511ee175c.png)

◈ 任务管理器的更新◈ 改进了 Lite 升级应用程序中的结束对话。◈ 各种应用程序的最新更新、错误修复等。
