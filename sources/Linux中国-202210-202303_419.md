# Xubuntu 22.10 的新变化 | Linux 中国

Xubuntu 是基于 Xfce 的 Ubuntu 官方版本。

它也是最好的轻量级 Linux 发行版之一。

随着最新的 Xubuntu 22.10 “Kinetic Kudu” 版本，你可以看到改进的桌面环境、添加的功能，以及全面的细化。

![](../Images/d200e0b351fb489071e647f81afa83b9.png)

Xubuntu 22.10 的新变化

![](../Images/961ab6e27da234ef7f45b0e3195b6551.png)

*Xubuntu 22.10 home*

Xubuntu 22.10 带来了一些令人兴奋的升级。一些亮点包括：

◈ Xfce 4.16（或 Xfce 4.17 开发版）◈ Catfish 的外观进行了更新。◈ 更新了新图标，弃用了 elementary-xfce-darker 主题。◈ Mousepad 搜索历史。◈ Thundar 文件管理器的改进。◈ Xfce 任务管理器。

> 💡 Xubuntu 22.10 将支持九个月，直到 2023 年 7 月。如果你想要稳定性而不是功能，你应该首选使用 LTS 版本🔗 itsfoss.com。

![](../Images/d200e0b351fb489071e647f81afa83b9.png)

Xfce 4.17 开发版还是 Xfce 4.16？

Xubuntu 22.10 的发行说明说它专门提供了 Xfce 4.17 开发版本。

但是，当我安装 Xubuntu 22.10 的 beta 版本（并将其更新到最新版本）时，只具有 Xfce 4.16。

![](../Images/984188230523ef44185b126a4c733627.png)

不确定他们是否退出了 Xfce 4.17 开发版本，或者 Xfce 4.16 现在是否存在。

![](../Images/d200e0b351fb489071e647f81afa83b9.png)

Catfish 外观

![](../Images/36768bc5bc371445c039ab0d9b40b03b.png)

*xubuntu catfish*

Catfish 是 Xubuntu 上的一个文件搜索工具。通过新的升级，它具有焕然一新的外观，并做了底层的改进。

与你搜索的文件交互时，你还会获得一个“打开方式”上下文菜单。

![](../Images/cb836d7ad69777599b8ea68ade8a2b86.png)

Catfish 还添加了一些细微而有用的功能。

![](../Images/d200e0b351fb489071e647f81afa83b9.png)

GNOME 43 软件应用

在值得注意的应用程序更新中，GNOME 的最新软件中心是一个不错的选择。这是 Xubuntu 22.10 的外观：

![](../Images/82b95544936cc39a0cedf0d436a1ac4a.png)

当然，它可能无法与 Xfce 上的其他应用程序保持一致，但我认为你应该不会介意。

![](../Images/d200e0b351fb489071e647f81afa83b9.png)

图标更新

随着 elementary-xfce 0.17 图标更新，有许多新图标和更简洁的选项，可提供一致的 Xubuntu 桌面体验。

![](../Images/baf5e820393c8cd059e612038d8b7a1e.png)

此外，elementary-xfce-darkest 主题图标包已被弃用。

![](../Images/70116c55a5b235b7e655d2e015a1c95f.png)

![](../Images/d200e0b351fb489071e647f81afa83b9.png)

任务管理器右键选项

![](../Images/eda572170e7ec66fe3a23a0541da872a.png)

你现在可以将完整的进程路径复制到剪贴板。这对于需要从命令行进行故障排除或停止操作很有用。

![](../Images/d200e0b351fb489071e647f81afa83b9.png)

其他增强功能

![](../Images/5fcd595b8ff73865fa096cfb37ab8708.png)

还有其他几个值得注意的变化，包括：

◈ Linux 内核 5.19。◈ Firefox 浏览器 105。◈ `Alt-Tab` 视图通过更突出的图标进行了改进。◈ 马赛克拼图添加到 SGT 拼图系列。◈ Mousepad 文本编辑器现在包括搜索历史记录，以及更多调整。

要了解有关更改的更多信息，请查看 官方发行说明🔗 wiki.xubuntu.org。

![](../Images/d200e0b351fb489071e647f81afa83b9.png)

下载 Xubuntu 22.10

你可以从 Ubuntu 的中央镜像库🔗 cdimage.ubuntu.com 或它的 官方网站🔗 xubuntu.org 下载最新的 ISO 文件。
