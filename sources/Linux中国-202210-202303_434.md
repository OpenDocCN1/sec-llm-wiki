# Kubuntu 22.10 的新变化 | Linux 中国

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NjQ4MjYwMQ==&mid=2664668669&idx=2&sn=06cbc2fc81d1b1e2bae79c9b5cc0a8e9&chksm=bdcfa6bb8ab82fad27c9bed4a018a94a8d50f942bf24270fa46db9ce322684ab7cc5564a04bb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NjQ4MjYwMQ==&mid=2664668669&idx=2&sn=06cbc2fc81d1b1e2bae79c9b5cc0a8e9&chksm=bdcfa6bb8ab82fad27c9bed4a018a94a8d50f942bf24270fa46db9ce322684ab7cc5564a04bb&scene=27#wechat_redirect)

 ![](../Images/2f44ab90d3d92bd7a1ddffb1192a2771.png)**导读：**Kubuntu 22.10 可能不是最令人兴奋的升级。但是，它包括了一些有用的变化。　 　 　 　 　 　![](../Images/29de72941c2d15e834cee0367c989fa8.png)本文字数：1418，阅读时长大约：1分钟  

Kubuntu 是 Ubuntu 的一个官方版本，它在一个精致的 KDE 驱动的软件包中提供了很多功能。

Kubuntu 22.10 的发布带来了各种改进和一个 KDE Plasma🔗 kde.org 的更新版本。

让我们来看看这个版本的亮点。

![](../Images/7f2e6ecf1178dd6b309b8a901f464f0a.png)

Kubuntu 22.10 有什么新变化？

![](../Images/35afaf34566b72a6e1c0e6ffa8ad2852.png)

*Kubuntu 22.10 桌面*

Kubuntu 22.10 带来了很多更新，其中一些重要的更新包括：

◈ KDE Plasma 5.25◈ Linux 内核 5.19◈ PipeWire◈ Firefox 104◈ Qt 5.15.6

> 💡 Kubuntu 22.10 将被支持九个月，直到 2023 年 7 月。如果你想要稳定而不是功能，你应该更喜欢使用 LTS 版本🔗 itsfoss.com。

![](../Images/7f2e6ecf1178dd6b309b8a901f464f0a.png)

KDE Plasma 5.25

![](../Images/c2527632ed2babe093b441ae94dc20cd.png)

*Kubuntu 22.10 KDE 版本*

尽管最近 KDE Plasma 5.26🔗 news.itsfoss.com 已经发布了，但 Kubuntu 22.10 还是搭载了 KDE Plasma 5.25。

然而，KDE Plasma 5.25 与 5.24 相比仍然是一个重大的更新，它包含了很多改进，例如，加强了对触摸板/触摸屏的支持，升级了用户界面等等。

你可以阅读我们对 KDE Plasma 5.25 的报道来了解更多。

> KDE Plasma 5.25：颜色、主题和其他改进🔗 news.itsfoss.com

另外，你可以期待 KDE Plasma 5.26 作为一个小版本发布，而不是作为 Kubuntu 22.10 发布的一部分。

![](../Images/7f2e6ecf1178dd6b309b8a901f464f0a.png)

默认采用 PipeWire

像大多数基于 Ubuntu 22.10 的发行版一样，PipeWire🔗 pipewire.org 是这个版本的 Kubuntu 的默认音频/视频处理器。

它取代了 PulseAudio🔗 www.freedesktop.org，众所周知，它与 Ubuntu 22.10 不兼容。

![](../Images/7f2e6ecf1178dd6b309b8a901f464f0a.png)

Linux 内核 5.19

![](../Images/a4f2fd9b6287d46595bd3e786a7d941a.png)

*Kubuntu 22.10 Linux 内核 5.19*

Kubuntu 22.10 采用了最新的 Linux 内核 5.19，这应该会带来对 ARM SoC 和 Arc Alchemist GPU 的支持、Btrfs 的各种改进、对 AMD RDNA3 图形的初步支持等等。

![](../Images/7f2e6ecf1178dd6b309b8a901f464f0a.png)

测试用的 Wayland 会话

![](../Images/554a09399ca4cf831a2be23a0d8fed15.png)

*Kubuntu 22.10 Wayland 会话切换器*

Kubuntu 22.10 具有对 Plasma Wayland 会话的初步支持，但它仅用于测试目的，并不是一个完整的集成。

![](../Images/52e00ba01e7ab00ecc93d0db4a2c87de.png)

*Kubuntu 22.10 Wayland 会话信息*

![](../Images/7f2e6ecf1178dd6b309b8a901f464f0a.png)

其他升级

其他一些更新包括：

◈ 自定义桌面重点颜色◈ 默认浏览器是 Firefox 104 Snap◈ Qt 5.15.6◈ LibreOffice 7.4◈ 改进的应用程序商店

要探索更多关于该版本的信息，请参考 官方发布说明🔗 wiki.ubuntu.com。

![](../Images/7f2e6ecf1178dd6b309b8a901f464f0a.png)

下载 Kubuntu 22.10

你可以从 Ubuntu 的中央镜像库🔗 cdimage.ubuntu.com 或其 官方网站🔗 kubuntu.org 下载最新的 ISO。

> Kubuntu 22.10🔗 kubuntu.org

它的官方网站可能需要一段时间来提供 ISO。
