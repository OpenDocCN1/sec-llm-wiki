# VirtualBox 7.0 发布，支持安全启动和全加密虚拟机 | Linux 中国

 ![](../Images/b036ec244b59a437f1e6ae8ae104e1a3.png)**导读：**VirtualBox 7.0 是自其上次大版本更新以来的一次重大升级。有一些不错的进步！　 　 　 　![](../Images/db479e93403b147cf622bb44fd486255.png)本文字数：1329，阅读时长大约：2分钟  

对 VirtualBox 来说，这是一次大的升级。这个版本值得关注，因为我们在最近几年没有看到过它的大版本更新。

对于那些不熟悉 VirtualBox 的人来说，它是一个由 甲骨文公司🔗 www.oracle.com 开发的虚拟化软件。

随着 VirtualBox 7.0 的推出，增加了许多新功能。

让我们来看看其中最关键的一些。

![](../Images/3bb10f1394620378796c298b2f309f1e.png)

VirtualBox 7.0 的新内容

![](../Images/e93a579860aff16a86cfd5a61c897155.png)

*virtualbox 7.0*

VirtualBox 7.0 是一次有益的升级。有图标更新、主题改进，以及一些关键的亮点，包括：

◈ 一个显示运行中的客体(Guest)的性能统计的新工具。◈ 支持安全启动。◈ 支持全加密虚拟机(Full VM Encryption)（通过 CLI）。◈ 重新设计的新建虚拟机向导。![](../Images/3bb10f1394620378796c298b2f309f1e.png)

通过命令行管理的全加密虚拟机

虚拟机（VM）现在可以完全加密了，但只能通过命令行界面。

这也包括加密的配置日志和暂存状态。

截至目前，用户只能通过命令行界面对机器进行加密，未来将增加不同的方式。

![](../Images/3bb10f1394620378796c298b2f309f1e.png)

新的资源监控工具

![](../Images/fb0e3c9286160d73ffb89bab6bb7fab6.png)

*VirtualBox 7.0 的资源监控*

新的实用程序可以让你监控性能统计，如 CPU、内存使用、磁盘 I/O 等。它将列出所有正在运行的客体的性能统计。

这不是最吸引人的补充，但很有用。

![](../Images/3bb10f1394620378796c298b2f309f1e.png)

改进的主题支持

对主题的支持在所有平台上都得到了改进。在 Linux 和 macOS 上使用原生引擎，而在 Windows 上，有一个单独的实现。

![](../Images/3bb10f1394620378796c298b2f309f1e.png)

对安全启动的支持

VirtualBox 现在支持安全启动，增强了对恶意软件、病毒和间谍软件的安全性。

它还将防止虚拟机使用损坏的驱动程序启动，这对企业应用非常重要。

使用那些需要安全启动才能运行的操作系统的用户现在应该能够轻松创建虚拟机了。

![](../Images/3bb10f1394620378796c298b2f309f1e.png)

其他变化

VirtualBox 7.0 是一次重大的升级。因此，有几个功能的增加和全面的完善。

例如，新件虚拟机向导现在已经重新设计，以整合无人值守的客体操作系统安装。

![](../Images/15f5572b7f89148521c858527624bee2.png)

*virtualbox 7.0 无人值守的发行版安装*

其他改进包括：

◈ 云端虚拟机现在可以被添加到 VirtualBox，并作为本地虚拟机进行控制。◈ VirtualBox 的图标在此版本中得到了更新。◈ 引入了一个新的 3D 栈，支持 DirectX 11。它使用 DXVK🔗 github.com 来为非 Windows 主机提供同样的支持。◈ 支持虚拟 TPM 1.2/2.0。◈ 改进了多显示器设置中的鼠标处理。◈ Vorbis 是音频录制的默认音频编解码器。

你可以查看 发行说明🔗 www.virtualbox.org 以了解更多信息。

如果你正在寻找增强的功能，如更好的主题支持、加密功能、安全启动支持和类似的功能添加，VirtualBox 7.0 是一个不错的升级。
