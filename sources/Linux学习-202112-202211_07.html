Linux玩游戏,你没听错,我就是要在Linux上整几个简单的经典游戏玩一下。

1.俄罗斯方块

“

俄罗斯方块是俄罗斯软件工程师 Alexey Pajitnov 于 1984 年创建的流行益智游戏。该游戏的流行于 90 年代。

“

Bastet 这个名字是bastard和Tetris这两个词的组合。可以算是传统俄罗斯方块的改良版。

“

在 Debian 和 Ubuntu 的发行版（发行版）上安装 Bastet，请使用以下命令：

sudo apt install bastet
“

如果你在运行 Fedora、RHEL 或 CentOS，请使用以下命令：

sudo dnf install bastet
“

输入bastet运行游戏

2.Pacman4 控制台

“

游戏场景非常简单，你只需要在迷宫中导航角色吃豆人并收集所有白色圆圈而不会被鬼吃掉。

“

要安装 Pacman4Console，执行下面的命令

sudo apt install pacman4console
“

输入pacman4console运行游戏

3.nSnake贪吃蛇

“

如果你是 90 年代或 2000 年代出生和长大的，诺基亚 Snake 游戏可以被视为传奇。nSnake 将帮助你在 Linux PC 上重温童年回忆。

“

要在 Debian 或 Ubuntu 的发行版上安装 nSnake,执行下面的命令

sudo apt install nsnake
“

如果你在运行 Fedora、CentOS 或 RHEL，执行下面的命令

sudo dnf install nsnake
“

输入nsnake运行游戏

4.term2048

“

2048 由程序员 Gabiele Cirulliie 在 2014 年开发，当时他只有 19 岁。游戏一发布在 GitHub 上,就很火爆。

“

要在 Debian/Ubuntu 的发行版上安装 2048, 执行下面的命令

sudo snap install term2048
“

输入term2048运行游戏

5.nudoku数独

“

数独是一个益智游戏，你会得到一个 9×9 的方格板，其中的值是部分划分的。你的目标是填充单元格，使数字在任何给定的行和列中只出现一次。

“

要在 Debian 或基于 Ubuntu 的 Linux 系统上安装 Nudoku,执行下面的命令。

sudo apt install nudoku
“

对基于 Fedora、CentOS、RHEL 或 RHEL 的系统使用以下命令。

sudo dnf install nudoku
“

输入nudoku运行游戏
