Linux有很多的软件,但是在桌面操作软件生态,还是不如Windows,有些软件只有Windows版本没有对应的Linux版本,如果我们想在Linux系统上运行exe程序,就需要借助一些第三方的软件,下面我就介绍一下用Wine运行exe软件的教程.

什么是wine

Wine(Wine Is Not an Emulator)是一个能够在多种 POSIX-compliant 操作系统（诸如 Linux，macOS 及 BSD 等）上运行 Windows 应用的兼容层。Wine 不是像虚拟机或者模拟器一样模仿内部的 Windows 逻辑，而是將 Windows API 调用翻译成为动态的 POSIX 调用，免除了性能和其他一些行为的内存占用。

安装：

首先看一下操作系统版本位数。

安装 Wine 使用apt

ubuntu@ubuntu0:~$ sudo apt install wine64

安装后,查看Wine版本

ubuntu@ubuntu0:~$ sudo wine --version

我们已经成功安装了 Wine，但是在开始在 Wine 中安装应用程序之前，我们必须先了解几个原则以及如何设置 Wine。

ubuntu@ubuntu0:~$ sudo winecfg

单击安装。

现在通过单击安装来安装 Gecko。将会创建一个 wineprefix 并打开 Wine 设置窗口。

$HOME/.wine/c_drive

每个新程序都应安装到新的 wineprefix 目录中。我们可以手动创建和管理多个 wineprefix来隔离不同的软件安装位置。

安装一个Windows微信体验一下

安装winetricks

Winetricks是一个辅助脚本，用于下载和安装在Wine中运行某些程序所需的各种可重新分发的运行时库。可能包括使用封闭源代码库替换Wine组件。

> sudo apt install winetricks

下载微信

下载微信后用wine运行WeChatSetup.exe

> wine WeChatSetup.exe
