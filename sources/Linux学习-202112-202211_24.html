Linux Lite是一个基于Debian和Ubuntu开发的Linux发行版。其配有经过修改的、轻量级的Xfce桌面环境，并包含一组以Lite命名的自有应用程序，对新手用户较为友好。它是一个轻量级且用户友好的发行版，专为 Linux 初学者特别是从 Windows 迁移的用户而开发。

“

Linux Lite提供了一个简单而熟悉的桌面环境，Windows 用户可以轻松使用。如:左下角经典的开始菜单。它提供高度定制的轻量级桌面体验XFCE桌面环境。此外，它还附带一组预装的 Lite 应用程。

下载 Linux 精简版

“

官方下载Linux Lite 6.0(https://www.linuxliteos.com/)。DVD ISO 约为 2.1G，仅提供 64 位 ISO。

“

安装Linux Lite(建议最低的硬件配置)。

  • 1GB 内存
  • 1.5 GHz 处理器
  • 20GB硬盘空间
  • 1366×768 屏幕分辨率。

Linux Lite 主要特性

用户界面

“

XFCE是默认的桌面环境，桌面布局简约，非常类似于 Windows 7 / 10 桌面，因此新用户可以轻松驾驭和找到自己想要的功能。

可用的应用程序

“

Linux Lite功能齐全。它提供一些预装的应用程序，安装系统后就可以直接使用。Linux Lite 中默认包含的一些应用程序：

  • 谷歌浏览器
  • VLC 媒体播放器
  • LibreOffice 套件
  • GIMP
  • 虚拟屏幕键盘
  • PDF 查看器和文档编辑器
  • 截图工具
  • 等等

安全

“

Linux Lite 还带有内置且高度可配置的Firewalld你可以通过 GUI 轻松管理的防火墙。你可以启用它并选择要打开的端口。

支持

“

Linux Lite 提供了一个大型论坛社区，当你遇到问题需要支持时，可以上去找答案。此外还提供了Linux Lite 帮助手册

初学者可以玩玩 Linux Lite

“

鉴于它与 Windows 10 桌面共享的 UI 相似性，对熟悉Windows系统的用户就特别友好。

Linux Lite 的几个优点

优雅简约的桌面

“

Linux Lite提供XFCE桌面是轻量级的，不会占用太多 RAM 或 CPU。

Linux Lite 欢迎界面

“

登录后Linux Lite,将显示一个弹出式欢迎屏幕，其中包含有关如何开始使用的几个选项。例如，你可以选择更新软件包、安装驱动程序、创建还原点等等。有一个支持部分，可让你通过各种途径获得支持，例如在线论坛和帮助手册。

易于定制

“

XFCE默认情况下允许你对外观和风格进行自定义。你可以更改桌面背景、图标的外观、小部件等等。

还可以运行linux命令

如:运行htop

“

展示系统资源占用情况。
