‍Canonical 在博客中宣布在 Windows 的 Linux 子系统（WSL）上发布 Ubuntu Preview 版本。Ubuntu Preview 基于最新的 Ubuntu 22.10 “Kinetic Kudu” 每日构建版本，它很新，但并不稳定。
Ubuntu 长期以来一直是适用于  Windows 的 Linux 子系统合作伙伴，如果你使用原始的 Windows 11 ，wsl --install 默认安装的正是 Canonical 的 Linux 发行版。当然，用户也可以选择其他发行版 —— 比如 OpenSUSE 和 Debian、Alma Linux ，但这些系统都需要手动指定，而 Ubuntu 却已经简单到可以通过 Microsoft Store 和 Ubuntu Preview 直接启动和运行。
而这次，Canonical 在通过相对友好的用户界面，将最新的 Ubuntu 每日构建版本（基于 Ubuntu 22.10 Kinetic Kudu）提供到 WSL 中 。Ubuntu 22.10 “Kinetic Kudu” 稳定版将于今年十月中旬发布，目前还在开发中。也就是说，WSL 中基于 Ubuntu 22.10 的每日构建版本会拥有最新最前沿的功能，但同时也是一个未经测试、无法用于生产的版本。Canonical 也在公告中直言：“不建议将其用于生产开发。它可能不稳定并且会有错误。”
想尝试 Ubuntu Preview 的朋友可以查看 Canonical 的公告或微软的 WSL 安装教程。
公告：https://ubuntu.com/blog/explore-whats-in-store-ubuntu-preview-on-wsl
