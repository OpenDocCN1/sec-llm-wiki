你喜欢哪种终端仿真程序，你是喜欢轻量级呢，还是探索全部功能和可定制化的选项？或者只使用发行版给的默认选项？



今天来介绍一个超炫酷的终端模拟器——tabby，Tabby是一个基于 TypeScript 开发的终端模拟器，适用于 Windows，macOS 和 Linux。该模拟器高度可配置，包括但不限于：主题、快捷键以及配色方案。它可以作为PowerShell ISE、PuTTY、macOS Terminal.app 和 iTerm 的替代品。

Tabby不是新的 shell，也不是 MinGW 或 Cygwin 的替代品。它也不是轻量级的，如果你想要轻量级的可以选择Conemu或Alacritty。

Tabby 具有以下特性：

  • 集成的 SSH 客户端和连接管理器

  • 集成的串行终端

  • 主题设计和色彩方案

  • 完全可配置的快捷键

  • 分割窗格

  • 记忆你的标签

  • 支持 PowerShell（和 PS Core）、WSL、Git-Bash、Cygwin、Cmder 和 CMD

  • 通过 Zmodem 在 SSH 会话中直接传输文件

  • 完全支持 Unicode，包括双角的字符

  • 在 Windows 上有适当的 shell 体验，包括标签完成（通过 Clink）。

  • 为 SSH secrets 和配置提供集成的加密容器



Tabby功能

  • V220终端+各种扩展

  • 多个嵌套的拆分窗格

  • 选项卡可放于任意一侧

  • 可选的可停靠窗口，有一个全局生成热键

  • 进程检测

  • 进程完成时的通知

  • 自定义 shell 配置文件

  • 可选的 RMB 粘贴和复制选择（PuTTY风格）



SSH客户端

  • 带有连接管理器的 SSH2 客户端

  • X11和端口转发

  • 自动跳转主机管理

  • 代理转发（包括 Pageant 和 Windows 原生 OpenSSH 代理）

  • 登录脚本


Tabby还有许多插件和主题都可以直接从Tabby中的设置中安装：

  • clickable-links：使终端中的路径和URL可点击

  • docker：连接到Docker容器

  • title-control：允许通过提供要删除的前缀、后缀和/或字符串来修改终端选项卡的标题

  • quick-cmds：快速向一个或所有终端选项卡发送命令

  • save-output：将终端输出记录到文件中

  • sync-config：将配置同步到Gist或Gitee

  • clippy：一个一直让你烦恼的示例插件

  • search-in-browser：使用从Tabby选项卡中选择的文本打开默认系统浏览器



目前，Tabby已经在Github上标星 1.3K，累计分支 23.9K（Github地址：https://github.com/Eugeny/tabby）
