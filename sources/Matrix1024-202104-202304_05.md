# 0x01 信息收集与探索

使用Nmap对靶场地址进行端口嗅探，发现对外开放80端口，且为Windows操作系统。

![](../Images/e9726cee0e964e1684a258c91dc52f89.png)

查看80端口Web页面如下，未发现敏感信息。

![](../Images/b0072c43348705a66d53047438451538.png)

使用nikto对Web服务进行漏洞扫描，发现其IIS版本为6.0，开启了DAV服务，允许使用危险的HTTP方法。

![](../Images/3b35c6c02b4120a0b8ff1bb25a4a6b37.png)

使用Dirsearch对http://10.129.95.234/进行目录扫描，发现/\_vti\_bin/等敏感目录，通过上面Nikto漏扫发现是存在Dos攻击漏洞的。

![](../Images/fa26ad415a5f371b186102449004fcc5.png)

使用Searchsploit对IIS 6.0版本进行漏洞发现，发现存在以下漏洞，因为开启了WebDAV众多方法，着重考虑。

![](../Images/e8006a2d8b7b97bda139b18ebe7ab806.png)

搜索了解“Microsoft IIS 6.0 - WebDAV 'ScStoragePathFromUrl' Remote Buffer Overflow ”漏洞，发现其对应CVE-2017-7269漏洞编号，在MSF有相关利用模块。

![](../Images/a7e5374538f46a4225f31ee3742dca57.png)
