# 0x01 信息收集与探索

使用Nmap对靶场地址进行端口嗅探，靶场对外开放22、25、80、110、111、143、443、993、995、3306、4445、10000端口，操作系统类型为Linux。

![](../Images/b7261ca40d388d8ac706cf2fd88b5919.png)

查看80端口，自动跳转至443端口，发现其为Elastix组件。

![](../Images/b0456174670b6a3d102e7f97be9ea76e.png)

查看SSL证书，未发现有用信息。

![](../Images/bb597522b4a7011413ddf6130ad18a24.png)

使用Diresearch对https://10.129.104.193/进行目录扫描，发现部分敏感信息。

![](../Images/8e8cd43a843ff0ba5e77bcd303f8204f.png)

在https://10.129.104.193/admin/config.php页面发现登录口，退出登录操作时跳转至401未认证页面，在左上角可以看到FreePBX的版本为2.8.1.4。

![](../Images/fda4d735c72b0ad6244703bc7f202a4c.png)

![](../Images/fea6c09599554fe85c3d5f75ecd32564.png)

通过目录扫描还发现https://10.129.104.193/vtigercrm/登录页面，版本为vtiger CRM 5.1.0。

![](../Images/98856b1fc1675e2be8727c6102d31ad1.png)

使用searchsploit对Elastix进行搜索，发现存在可利用漏洞，分别进行漏洞利用。![](../Images/c9d3b708eccac1ec25df0ff2577e49c1.png)

尝试利用FreePBX 2.10.0 / Elastix 2.2.0 - Remote Code Execution漏洞，修改脚本如下，但是无法填入extension变量的值（查看payload该字段在URL中拼接），无法反弹shell成功。

![](../Images/436da3865fa4a8451669e6e117c134e2.png)

![](../Images/5191dd78d633931eed5c69edd443983d.png)

尝试利用Elastix 2.2.0 - 'graph.php' Local File Inclusion漏洞，查看文件，payload为 /vtigercrm/graph.php?current\_language=../../../../../../../..//etc/amportal.conf%00&module=Accounts&action。

![](../Images/5b07e8e843dd6326bfb8fc210b4fb9eb.png)

利用该漏洞，访问https://10.129.104.193/vtigercrm/graph.php?current\_language=../../../../../../../..//etc/amportal.conf%00&module=Accounts&action页面，获取到数据库及Web登录凭据。

![](../Images/47e8a4fc6ccd1064918391910ebca61d.png)

![](../Images/d2861127b4d90bd3d5237bd177ec7cdb.png)

![](../Images/893b64dda8c5b4a0ac41d01f1d3c9f35.png)

![](../Images/0d7f44ce8f7f4ae5c3a46cbd4ceedb02.png)

查看漏洞利用方式并进行利用，在https://10.129.1.226/vtigercrm/modules/com\_vtiger\_workflow/sortfieldsjson.php?module\_name=../../../../../../../../etc/passwd%00页面，成功包含出用户列表信息。

![](../Images/9a64df50c8df09acf6fb7ee79e880100.png)

访问https://10.129.1.226/vtigercrm/modules/com\_vtiger\_workflow/sortfieldsjson.php?module\_name=../../../../../../../../etc/shadow%00页面，发现未具备root权限。

![](../Images/817e802d2df68df3ce9a90bfa550f66c.png)

访问https://10.129.104.193/vtigercrm/modules/com\_vtiger\_workflow/sortfieldsjson.php?module\_name=../../../../../../../../home/fanis/user.txt%00页面，成功获取到user.txt文件。

![](../Images/344a1a89509b02e9496451c3c1a01f47.png)

# 0x02 权限获取

根据上述找到的extension值再次修改FreePBX 2.10.0 / Elastix 2.2.0 - Remote Code Execution脚本。

![](../Images/5720f011925abc25961378d398737cdc.png)

Kali监听，运行漏洞利用脚本，成功反弹shell。

![](../Images/2c762f0d80b712b97917c35c9f982c39.png)

查看shell信息，为低权限账户。

![](../Images/62f1277bc0a2b7a5c5fa9c0d6957516b.png)

执行sudo -l命令，发现有很多免密执行root权限的文件，利用FreePBX 2.10.0 / Elastix 2.2.0 - Remote Code Execution的提权方式进行提权。

![](../Images/73b29c86f18fbc300355993924d289b3.png)

![](../Images/8d80975942c80c0f1230300db6e59c9b.png)

成功获取root权限，并获得root.txt。
