# VMware服务端模板注入漏洞在野利用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NzYxMjI5OA==&mid=2247484794&idx=1&sn=b0422615fd36106ce68fb8eb644694fc&chksm=c06e6a1ff719e309b4503cb83a4f59ba08d064a8c971529c422932af12e2f955ff8e1eeec8ad&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5NzYxMjI5OA==&mid=2247484794&idx=1&sn=b0422615fd36106ce68fb8eb644694fc&chksm=c06e6a1ff719e309b4503cb83a4f59ba08d064a8c971529c422932af12e2f955ff8e1eeec8ad&scene=27#wechat_redirect)

  

4月6日，vmware官方公布了最新的安全公告，敦促用户修补 8 个不同严重程度的漏洞。其中包含了CVE-2022-22954服务端模板注入漏洞。这个漏洞是VMware Workspace ONE Access和Identity Manager中的一个远程代码执行漏洞，CVSS评分9.8分，影响VMware Workspace ONE Access和VMware Identity Manager 2个广泛使用的软件产品。攻击者可以利用该漏洞可以触发服务端的模板注入，最终实现远程代码执行。当前该漏洞POC已被公开。

**受影响版本**

VMware Workspace ONE Access (Access)

VMware Identity Manager (vIDM)

VMware vRealize Automation (vRA)

VMware Cloud Foundation

vRealize Suite Lifecycle Manager

![](../Images/ce926ead36569e178c3de25fd07543b5.png)

根据安全公司Bad Packets公布的信息来看，当前已捕获到该漏洞的在野利用。通过该漏洞，攻击者将可能用于勒索和挖矿病毒的传播。

![](../Images/3fc0d0e7cc1d36d516b076825fdf14ad.png)

根据部分安全人员表述，可能很快会看到勒索软件团伙开始利用该漏洞在网络中横向传播。因此建议用户及时修复该漏洞。
