# 移动设备流量转发在近源渗透中的应用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NzYxMjI5OA==&mid=2247484369&idx=1&sn=0c99d96a9fc2a8704fbe2a94e87f378d&chksm=c06e6cb4f719e5a2722eeca10baa41a6f3e3013c0d059bec8a0e4d28ec21427cc96536440dae&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5NzYxMjI5OA==&mid=2247484369&idx=1&sn=0c99d96a9fc2a8704fbe2a94e87f378d&chksm=c06e6cb4f719e5a2722eeca10baa41a6f3e3013c0d059bec8a0e4d28ec21427cc96536440dae&scene=27#wechat_redirect)

移动设备：手机、平板、树莓派等

近源渗透：包括社会工程学、物理接近、无线电弱点

场景：攻击者通过社工或无线电弱点获得目标网络环境，但由于物理环境限制，需利用手段将网络环境转发，以便于远程攻击者利用网络环境进行攻击。

![](../Images/59747e13831757178dac637a5d6e8f61.png)

  

一、准备工作

1.安装了NPS服务端的公网服务器。

https://github.com/ehang-io/nps/

2.Kali NetHunter 或 树莓派

  

二、树莓派的流量转发

思路： 

    若目标内网不出网，网口接目标网络，WIFI接公网热点，使用WIFI网络连接公网服务器。

     若目标内网出网，网口接目标网络，使用目标网络连接公网服务器。

  

目标内网出网：

1.设置ssh服务开机自启

update-rc.d ssh enable

ls -l /etc/systemd/system/multi-user.target.wants
