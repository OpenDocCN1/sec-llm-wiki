# Linux DirtyPipe权限提升漏洞（CVE-2022-0847）复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NzYxMjI5OA==&mid=2247484327&idx=1&sn=dd816785dc3a740e45ad13bad8e3fd7d&chksm=c06e6cc2f719e5d414f927b61685e03db33bcd55168b4f3b4529bd2f67dd2461158c7083a81c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5NzYxMjI5OA==&mid=2247484327&idx=1&sn=dd816785dc3a740e45ad13bad8e3fd7d&chksm=c06e6cc2f719e5d414f927b61685e03db33bcd55168b4f3b4529bd2f67dd2461158c7083a81c&scene=27#wechat_redirect)

0X01 漏洞描述

    3月7日，国外的安全研究员马克斯·凯勒曼发布博客，披露了一处存在于Linux 内核中的本地提权漏洞CVE-2022-0847。

    CVE-2022-0847是存在于Linux内核5.8及之后版本中的本地提权漏洞。攻击者通过利用此漏洞，可覆盖重写任意可读文件中的数据，从而可将普通权限的用户提升到特权root。CVE-2022-0847 的漏洞原理类似于CVE-2016-5195脏牛漏洞（Dirty Cow），但它更容易被利用。漏洞作者将此漏洞命名为“Dirty Pipe”。

0X02 影响版本

    5.8 <= Linux 内核版本 < 5.16.11 / 5.15.25 / 5.10.102

    更新升级 Linux 内核到以下安全版本：
