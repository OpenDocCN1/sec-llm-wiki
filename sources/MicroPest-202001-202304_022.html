    昨天晚上，去做了核酸检测，阴性，转阴了。

    上午，去了单位，一片寂静，走廓里只ZW的门开着，她在坚守，我们还没全军覆没。隔着门打了声招呼(没敢靠近)，互置问候。电话问候了几个办公室同事，没中者越来越少了。

几天隔离，办公室中落了一层灰，开窗打扫；泡上一杯茶，冷风中的办公室空阔清冷，静谧无声，适合工作......

今天效率挺高的，运气也不错，解决了问题：Ghidrathon（Ghidra扩展），就是今天所记录的重点。昨天的CentOS7中python2.75替换成3.86的，只是今天其中的一个步骤，但方法不够简捷，后来找到网上一个更简便的，给出地址：https://mp.weixin.qq.com/s/C3qU1xzrBkoYfMaQTfjhoQ。今天发现包括昨天在内的都是无用功，代表着事物发展的规律：否定之否定，就是这无数次的否定所需要的积累才有了今天零的突破，曲折浪费而无聊。

这里，记录下这个扩展的安装过程：

1、准备好 jdk-17、gradle7.6、ghidra10.22、ghidrathon；

2、将kali升级到最新状态；

3、卸掉openjdk:apt-get remove openjdk*；

4、将准备好的jdk-17添加到JAVA_HOME中，直至java --version：

5、将准备好的gradle7.6添加到GRADLE_HOME中；

6、将两者加入到/etc/profile中；并source重启一次；

7、安装 apt-get install virtualenv；

8、解压ghidra和Ghidrathon；

7、cd ghidra; 

virtualenv -p python3 venv; 

source venv/bin/activate; 

8、启动gradle：

cd Ghidrathon

gradle -PGHIDRA_INSTALL_DIR=/XXXXX/ghidra

9、此时在当时目录下生成个dist目录，里面有个ghidra_10.2.2_PUBLIC_20221222_ghidrathon.zip的文件,将它copy到ghidra/Extentions/Ghidra目录下；

10、启动ghidra：

./ghidraRun

成功了。

至此，整个过程完成。
