今天感觉好很多了，头还是有点晕晕，咳嗽也有点多，干咳无痰、一咳还牵动胸腔共振，不敢用力，应该还是有炎症。看了下身边，经常锻炼的人这一波得少，加强锻炼身体很有必要。

闲着无事，记录一下，“一个在Centos7中安装java17和python3的过程”，没什么技术，只是备忘下怕找起来不方便。

下载好jdk-17和python3.86在目录中；

1、yum install -y jdk-17_linux_x64_bin.rpm;

2、vi /etc/profile，添加如下

export JAVA_HOME=/usr/java/jdk-17.0.5

export PATH=$PATH:$HOME/bin:$JAVA_HOME/bin

export CLASSPATH=.:$JAVA_HOME/lib/dt.jar:$JAVA_HOME/lib/tools.jar:$JAVA_HOME/jre/lib/rt.jar

3、source /etc/profile

4、java --version，安装成功java。

5、tar -xvf python3.86.tar; cd python3.86

6、mkdir /usr/local/python3

7、./configure --prefix=/usr/loca/python3

8、yum -y install zlib*

9、vi Modules/Setup

找到#zlib zlibmodule.c -I$(prefix)/include -L$(exec_prefix)/lib -lz；去掉该行的注释，保存；

10、make && make install

11、mv /usr/bin/python /usr/bin/python_bak

12、ln -s /usr/local/python3/bin/python3 /usr/bin/python

13、python -V ; 成功变成3.86了。


配置成功后，pip3用不了，需进一步配置，

14、PATH=PATH:HOME/bin:

15、PATH=PATH:HOME/bin:/usr/local/python3/bin

这时pip3就可以使用了。
