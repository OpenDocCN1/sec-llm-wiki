    Arya可用于生成定制的伪恶意软件文件，以触发AV和EDR工具。

  

    YARA规则是安全研究人员必不可少的工具，可帮助他们识别和分类恶意软件样本。他们通过描述恶意软件代码中的模式和字符串来做到这一点，这些模式和字符串可以帮助分析师识别已知或新的威胁。YARA规则也经常集成在商业检测工具中，或在内部用于检测企业网络上行为不端的二进制文件。

  

    但是，如果我们没有正在为其编写规则的恶意文件怎么办？如果我们想创建一个基于YARA作为输入的“恶意软件”文件怎么办？Arya的工具就可以。

  

**一、arya**

    Arya会生成旨在触发YARA规则的伪恶意文件。该工具读取给定的 YARA（.yar后缀）文件，使用Avast的yaramod包（YARA 解析引擎）解析它们的语法，并构建一个伪“恶意软件”文件，YARA规则中所需的字节以触发输入规则。 

![](../Images/e4a67f7f9e9b166b249690a1dd986d5c.png)

    该工具的目标是生成一个定制的伪恶意文件，检测传感器(如AV 或 EDR)会识别为输入YARA规则想要检测的恶意软件文件。为了实现这一目标，我们不仅要从输入的YARA规则中添加必要的签名、字符串和字节，还要添加一些真正的“修饰”，如PE头、增加outfile熵、添加x86字节码和函数入口/出口 汇编代码。所有这些都有助于AV/EDR触发过程，并绕过它们可能有的一些启发式检查。  

  

![](../Images/9bc1b47a84647364bcc8674a2ca0652b.png)

    

    研究人员也可以使用Arya来生成伪恶意文件，使用YARA规则作为构建块。这些文件可以用来构建将被识别为特定恶意软件的文件。例如，如果您没有Zeus恶意软件样本，但您想检查您的AV对它的反应？没问题，将Zeus YARA规则加载到Arya 并生成您自己的类似“Zeus”的伪恶意软件，AV/EDR工具会将其识别为Zeus。

  

**二、arya操作**

    YARA文件（.yar 扩展名）是包含一个或多个 YARA 规则的文本文件。在这个项目中，我们使用yaramod将 YARA 规则转换为由 Python 对象表示的规则列表，然后可以使用它来访问规则的内部内容，例如字符串、类型、条件等。Yaramond 将 YARA 规则解析为 AST 或抽象语法树。

  

    通过结合使用Observer和Visitor设计模式来遍历抽象语法树。对于代码经过的每个节点，它将确定需要放置哪些字节和字符串以及放在哪里，以便在它遍历的子树中触发条件。因此，这个树将产生一个字符串映射和可能的偏移量来放置它们；它还可以在文件中保留一些，这些文件将被传递给placer机制进行进一步处理。

Arya 的主要目的是触发恶意软件检测引擎。为了做到这一点，我们必须考虑在这些 AV 和 EDR 引擎的内部工作中重要的一些事情。

  

首先要考虑的是本机字节码熵。这一点很重要，因为当前的杀毒软件会测量文件代码的熵，以检查它是否被打包、加密或混淆。

  

输出文件中没有任何规则指定要放置什么的“empty holes”是由另一个恶意软件的x86字节码填充的。用户可以指定他们想要从中获取字节码的任何恶意软件/文件（使用选项 -m 并指定文件名）。

  

这里要考虑的另一个问题是 x86 函数，特别是函数计数。今天，各种各样的反病毒和检测软件可能会检查潜在恶意文件中的功能数量。如果一个文件的功能超过了一个标准编号就会被认为是恶意的。因此，决定添加尽可能多的函数入口段和出口段，同时保持它们在代码中的正确顺序。

1、第一步

sudo apt update

sudo apt install yara cmake

git clone https://github.com/claroty/arya

cd arya

pip3 install -r requirements.txt

  

2、第二步

Run Arya considering the following args:

*   `-i [INPUT_DIRECTORY] OR [INPUT_FILE]`
    
*   `-o [OUTPUT_FILE_NAME]`
    
*   `--header` - Adds the first 2048 bytes of conficker at the start of the file.
    
*   `-r` - Run recursively on all of the files under [INPUT_DIRECTORY]
    
*   `-m [MALWARE_FILE]` - Use the file [INPUT_DIRECTORY] as the base for the output.
    

  

    3、第三步：生成

python3 src/arya.py -i example\_rules/ -o MalwareAryaDefault.exe
