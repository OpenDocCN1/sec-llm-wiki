# 记录任何 Linux 进程访问了哪些文件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NDcxMDQzNA==&mid=2247486897&idx=1&sn=c7cc4ddced65b7d23b65629a1349896d&chksm=a682db7c91f5526ab204057ba52a03ce4916cf5daca46b074dcba5ecfe6e093c7d5ce8b8d9fa&scene=126&sessionid=1681666270#rd](http://mp.weixin.qq.com/s?__biz=MjM5NDcxMDQzNA==&mid=2247486897&idx=1&sn=c7cc4ddced65b7d23b65629a1349896d&chksm=a682db7c91f5526ab204057ba52a03ce4916cf5daca46b074dcba5ecfe6e093c7d5ce8b8d9fa&scene=126&sessionid=1681666270#rd)

Whatfiles 是一个 Linux 实用程序，它记录另一个程序在您的系统上读取/写入/创建/删除的文件。它还跟踪目标进程创建的任何新进程和线程。

理由：  

长期以来，我一直对缺少一个简单的实用程序来查看进程从哪些文件接触`main()`到退出而感到沮丧。无论您是不信任软件供应商还是担心恶意软件，了解程序或安装程序对您的系统所做的操作都很重要。`lsof`只观察一个时刻，而且`strace`很大而且有些复杂。

  

编译：

git clone https://github.com/spieglt/whatfiles.git

cd whatfiles

make

make install

  

## 利用：

*   基本使用，启动`ls`并将输出写入当前目录中的日志文件：
    
    `$ whatfiles ls -lah ~/Documents`
    
*   指定输出文件位置`-o`：
    
    `$ whatfiles -o MyLogFile cd ..`
    
*   包括调试输出，打印到标准输出而不是日志文件：
    
    `$ whatfiles -d -s apt install zoom`
    
*   附加到当前正在运行的进程（需要 root 权限）：
    
    `$ sudo whatfiles -p 1234`

Whatfiles 除了 C 标准库和 Linux 内核头文件之外没有任何依赖项，因此这些应该是相当可移植的。目前仅支持 x64、x86、ARM32 和 ARM64。x64 二进制文件在 Mint 20 上编译，x86 在 Ubuntu 16 上编译。ARM 版本在具有普通 Raspbian 和 64 位 beta 的 Raspberry Pi 4 上编译。
