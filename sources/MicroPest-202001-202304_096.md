    国庆到了，祝伟大祖国的生日快乐！同时分享个恶意代码的静态分析工具。这个工具可以静态地分析 windows、linux、macos的可执行文件以及APK文件。对一个py能完成这么多功能，我觉得挺不错的，可以下载感受下。

  

**一、下载、安装**  

  

https://github.com/CYB3RMX/Qu1cksc0pe

  

pip3 install -r requirements.txt

  

python3 qu1cksc0pe.py --install

  

**二、运行**

python3 quicksc0pe.py -h

![](../Images/41576598526f94223a5b399c628f550d.png)

  

1、正常分析  

Usage: `python3 qu1cksc0pe.py --file suspicious_file --analyze`

![](../Images/d7e06b11a902b4f3f3d0cd01e5512612.png)

  

2、多个分析

Usage: `python3 qu1cksc0pe.py --multiple FILE1 FILE2 ...`

![](../Images/a3ac4d0e0836e35bc7039ff7d76d6e65.png)

  

3、Hash扫描

Usage: `python3 qu1cksc0pe.py --file suspicious_file --hashscan`

![](../Images/9fc368806f7e84767bd72218f80dc592.png)

  

4、文件夹扫描

Supported Arguments:

*   `--hashscan`
    
*   `--packer`
    

Usage: `python3 qu1cksc0pe.py --folder FOLDER --hashscan`

![](../Images/7b8b2731e234e33e7ba6bf775e3fddf8.png)

  

5、VirtualTools 扫描

Report Contents:

*   `Threat Categories`
    
*   `Detections`
    
*   `CrowdSourced IDS Reports`
    

Usage for --vtFile: `python3 qu1cksc0pe.py --file suspicious_file --vtFile`

![](../Images/86faf45dce2dbc8bb693d87f4c6ca33d.png)

  

6、文件扫描

Usage: `python3 qu1cksc0pe.py --file suspicious_document --docs`

![](../Images/8cd4bd61bbd97ee8e5977e6c6ccf3955.png)

  

7、程序语言检测

Usage: `python3 qu1cksc0pe.py --file suspicious_executable --lang`

![](../Images/7c7df9fa49f342edb1709513b2d62742.png)

  

8、交互式shell

Usage: `python3 qu1cksc0pe.py --console`

  

9、域名  

Usage: `python3 qu1cksc0pe.py --file suspicious_file --domain`
