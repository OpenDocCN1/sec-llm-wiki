# 一、寻 EIP: 32位汇编方法

    首先介绍使用 x86 Assembly (32位)指令定位 EIP 的方法。有两种方法，根据您可能面临的情况和限制，它们都是有用的。这两种方法都可以达到发现 EIP 的目的。我将详细介绍的第一个方法比第二个稍微小一个字节。这两种方法实现了完全相同的目标，即在 EAX 寄存器中存储 EIP 值。这两种方法都是空(0x00)字节。您会使用一个而不是另一个的原因归结为您可能遇到的大小或字符限制。

  

## 1、方法1: 使用 FPU 指令

这个方法首先利用x87浮点运算器寄存器来获得EIP的值。下面的基本汇编代码将EIP的值存储在EAX寄存器中。  

| 

```


1
```

 || 

```
\[SECTION .text\]

BITS 32

global \_start

\_start:
fldz
fnstenv \[esp\-0x0C\]
pop eax
add al, 0x07
```

 |
| --- | --- |

为了激活 FPU 寄存器，执行fldz指令。该指令将常量值 + 0.0推送到FPU寄存器堆栈(ST (0))。在此过程中，初始化FPU 寄存器，并将EIP的当前值存储在FPU指令指针偏移量(FIP)寄存器中。图1详细说明了FPU寄存器的结构。

![](../Images/427b5e680e37551655661da8aa748e98.png)

图1:内存中的保护模式 x87 FPU 状态映像，32位格式

  

下一条指令将FPU寄存器存储在指定的地址。因为EIP值使用fnstenv指令存储在FIP寄存器中，偏移量为0x0C。指定ESP-0x0C的目标，以便将FIP值存储在当前的ESP地址。接下来，该值从堆栈中弹出并存储在EAX寄存器中。由于从EIP存储在FPU的FIP寄存器到它被弹出到EAX之间已经执行了几个字节的指令，所以有必要调整这个值来表示EIP 的当前值,0x07被添加到AL寄存器中。使用AL寄存器可以避免使用NULL字节。

## 2、方法2: 使用跳转和调用

第二种方法只比第一种方法长一个字节。为了获得EIP，这个方法使用一系列跳转和调用，导致EIP的值存储在EAX中。  

| 

```


1
```

 || 

```
\[SECTION .text\]

BITS 32

global \_start

\_start:
jmp label2
label1:
jmp getEIP
label2:
call label1
getEIP:
pop eax
```

 |
| --- | --- |

在上面的代码中，执行跳转到label2，这是一个调用 label1的调用指令。当一个调用被执行时，返回地址，下一条指令的地址，被推送到堆栈。然后执行跳转到getEIP，它将返回地址弹出到EAX。

# 三、结论

已经详细介绍了根据目标架构查找EIP或RAX的几种方法。如果您希望执行与您的shellcode交互的其他操作，那么动态获取这些值很重要。由于ASLR无法动态查找EIP/RIP，因此无法解码、复制或以其他方式修改您的代码。
