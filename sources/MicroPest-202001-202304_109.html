    在 shellcode 能够定位或使用任何 Windows api 之前，必须定位 kernel32.dll 的基地址。值得庆幸的是，有一个技巧已经存在了相当长的时间。该方法使用 Win32线程信息块(TIB)定位程序环境块(PEB)来定位 InInitializationOrderModuleList，它包含 kernel32.dll 的基地址作为它的第二个列表条目。

图 5：LOSD 指令递增 ESI 以指向下一个列表条目
