# 通过回调注入shellcode

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NDcxMDQzNA==&mid=2247485810&idx=1&sn=c702a25c83822a0b9db5a30500a077ab&chksm=a682dfbf91f556a95e110e190ddaf975b853c94eabb88ee9c8d4477a0624a10f6b5c5a17a890&scene=126&sessionid=1681666305#rd](http://mp.weixin.qq.com/s?__biz=MjM5NDcxMDQzNA==&mid=2247485810&idx=1&sn=c702a25c83822a0b9db5a30500a077ab&chksm=a682dfbf91f556a95e110e190ddaf975b853c94eabb88ee9c8d4477a0624a10f6b5c5a17a890&scene=126&sessionid=1681666305#rd)

    我们上篇文章讲了什么是回调函数（如果不清楚，请往前翻），现在我们来看看CallBack Function的专业解释：“简单来说，这是一个通过函数指针调用的函数。当我们向需要回调函数的参数传递一个函数指针时，一旦函数指针被用来调用这个函数，它指向的是回调被执行了。这可以被滥用来注入 shellcode 而不是函数指针”。

  

    其特点就是加强：**隐蔽执行、动态加载**。

  

    这项技术在“a Lazarus (![](../Images/abb1a83119d04892c3a2be6329397865.png)) Shellcode Execution”中被使用（引用自NCC Group Research & Technology）。

  

**一、木马样本 **   

    这是一个vc木马程序，通过调用外部dll（kernel32）的api函数EnumUILanguages来实现加载shellcode，此api函数的原功能是什么不重要，重要的是它具有一个参数可以指定回调函数，作者利用这点把shellcode的地址作为回调函数，当调用api函数后，shellcode也被随之加载。这种手法在一些vc木马也有一些应用，比如通过调用一些具有回调函数的窗体类api也能达到类似的效果。所以，实现方法有很多，关键是调用具有回调函数的api。之所以这么麻烦以获取一段代码的执行，我想目的还是为了躲避杀软检测。

**二、windows下可以利用的回调函数**  

    我们可以使用很多 Win32 api 来注入 shellcode，本文就介绍一些这样的在 Windows 10上使用的api。

  

# **1、分析 API**

    例如，我们从 user32.dll 获取函数 EnumWindows，第一个参数 lpEnumFunc 是指向 WNDENUMPROC 类型的回调函数的指针。

| 234 || BOOL  EnumWindows(  WNDENUMPROC lpEnumFunc,  LPARAM      lParam); |
| --- | --- |

    该函数将参数传递给一个名为 EnumWindowsWorker 的内部函数。

  

![](../Images/7ea624530e5b43da137283102a698aea.png)

    第一个参数是回调函数，在这个函数内部调用回调函数函数指针，这样就可以传递与位置无关的 shellcode。  

![](../Images/8f69044b374ac08df924eed81e6c71ad.png)

    通过检查引用，我们可以看到其他 api 使用了 EnumWindowsWorker 函数，使它们适合执行 shellcode。  

![](../Images/e9c0e4fc6ccd1a9417854c4c4cc12592.png)
