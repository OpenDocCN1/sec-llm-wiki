    BinaryAI，是一个二进制文件的神经搜索引擎，由腾讯安全基恩实验室开发，旨在帮助安全研究人员在给定的二进制文件的自定义范围内匹配最相似的源代码。


一、简介

    BinaryAI 提供了三种访问 BinaryAI 搜索引擎框架核心 api 的方法。

    1、Python SDK：BinaryAI 为用户提供了编写自定义工具来分析二进制文件的能力。https://binaryai.readthedocs.io/en/latest/binaryai.html#

 

    2、IDA插件：提供了一个 IDA 插件来帮助逆向工程分析 IDA Pro 用户界面。插件使用户只需点击几下，就可以从云中数百万个函数的源代码或任何自定义范围中应用 BinaryAI 检索结果到 IDA Pro 加载的文件中。


    3、命令行工具：命令行工具现在可以方便用户上传或匹配二进制文件中的所有函数。


    现在为用户提供了一个网站 binaryai.tencent.com ，使得配置他们的检索列表和管理他们的功能集更加容易，根据特定分析的需要。我们已经为您创建了一些函数集，请在https://binaryai.tencent.com/explore页面查看。

 

二、安装

1、以IDA插件为例

pip install --upgrade binaryai

# then you can add the binaryai plugin into $IDAUSR

binaryai install_ida_plugin

将插件放入IDA的Plugins中。

 

2、申请令牌

https://binaryai.tencent.com/apply-token，以Email来申请，会将一个Toke发到你的申请邮箱中。在使用前要将此Token放于如下图中，

Token：令牌；

Url：指定BinaryAI web服务的端点；

Funcset：是用户可以创建的一组函数。用户可以将函数上传到某个函数集，这样用户就可以自行定义检索范围。新发布的版本允许用户上传他们的默认功能集。

Topk：指定用户检索函数时的结果数量。

Minsize：指定函数的最小基本块大小。如果要匹配或检索的函数的基本块大小更小，则不会自动应用结果。

Threshold：检索结果中物种得分最低。如果要匹配或检索的函数收到的分数低于阈值，则不会自动应用结果。
