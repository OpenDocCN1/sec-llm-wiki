**一、环境、程序**

地址：https://github.com/rootm0s/WinPwnage

  

这是一个py程序，基于py2和py3的，  

如果是2，要pip install -r requestments.txt；

如果是3且低于3.4的，同上；如果高于，则不需要；

  

这个py程序可以打包成exe可执行文件，如下操作：  

pip3 install pyinstaller

pyinstaller --onefile main.py
