    【正文】进程伪装，指的修改任意一个指定进程的信息，是它的信息在系统中的显示是另一个进程的信息，这样看来，指定的进程就像是被伪装的进程一样，因为进程信息相同，但实际上，它还是原来的进程，做着原来的进程操作。

  

    本文就是要介绍进程伪装的技术，实现在 32 位系统和 64 位系统上的进程伪装。

**二、实现原理**

    进程伪装的原理不是很复杂，就是修改指定进程的进程环境块 PEB 中的进程路径以及命令行信息，即可达到进程伪装的效果。

  

具体实现原理分析如下：

*   首先，我们根据进程的 PID 号打开指定进程，并获取进程的句柄。
    
*   然后，我们要从ntdll.dll中获取 NtQueryInformationProcess函数的导出地址，因为 NtQueryInformationProcess函数没有关联导入库，所以只能动态获取，这个函数是这个程序功能实现的关键步骤。
    
*   接着，使用NtQueryInformationProcess函数获取指定进程的进程基本信息PROCESS\_BASIC\_INFORMATION，并从中获取指定进程的进程环境块PEB。
    
*   然后，我们就可以根据进程环境块中的ProcessParameters获取指定进程的RTL\_USER\_PROCESS\_PARAMETERS信息，因为PEB的路径信息、命令行信息存储在这个结构体中。
    
*   最后，我们开始对指定进程PEB中路径信息、命令行信息进行更改，实现进程伪装。
    

  
**三、源码**  

// 修改指定进程的进程环境块PEB中的路径和命令行信息, 实现进程伪装

1.  `BOOL DisguiseProcess(DWORD dwProcessId, wchar_t *lpwszPath, wchar_t *lpwszCmd)`
    
2.  `{`
    
3.  ` // 打开进程获取句柄`
    
4.  ` HANDLE hProcess = ::OpenProcess(PROCESS_ALL_ACCESS, FALSE, dwProcessId);`
    
5.      typedef\_NtQueryInformationProcess NtQueryInformationProcess \= NULL;
    
6.  
    
7.  ` PROCESS_BASIC_INFORMATION pbi = { 0 };`
    
8.  ` PEB peb = { 0 };`
    
9.  ` RTL_USER_PROCESS_PARAMETERS Param = { 0 };`
    
10.  ` USHORT usCmdLen = 0;`
     
11.  ` USHORT usPathLen = 0;`
     
12.  ` // 需要通过 LoadLibrary、GetProcessAddress 从 ntdll.dll 中获取地址`
     
13.  ` NtQueryInformationProcess = (typedef_NtQueryInformationProcess)::GetProcAddress(`
     
14.  ` ::LoadLibrary("ntdll.dll"), "NtQueryInformationProcess");`
     
15.  
     
16.      // 获取指定进程的基本信息
     
17.  ` NTSTATUS status = NtQueryInformationProcess(hProcess, ProcessBasicInformation, &pbi, sizeof(pbi), NULL);`
     
18.  
     
19.      /\*注意在读写其他进程的时候，注意要使用ReadProcessMemory/WriteProcessMemory进行操作，
     
20.  `每个指针指向的内容都需要获取，因为指针只能指向本进程的地址空间，必须要读取到本进程空间。`要不然一直提示位置访问错误!    \*/
     
21.    
     
22.  ` // 获取指定进程进本信息结构中的PebBaseAddress`
     
23.  ` ::ReadProcessMemory(hProcess, pbi.PebBaseAddress, &peb, sizeof(peb), NULL);`
     
24.  
     
25.  ` // 获取指定进程环境块结构中的ProcessParameters, 注意指针指向的是指定进程空间中`
     
26.  ` ::ReadProcessMemory(hProcess, peb.ProcessParameters, &Param, sizeof(Param), NULL);`
     
27.    
     
28.  ` // 修改指定进程环境块PEB中命令行信息, 注意指针指向的是指定进程空间中`
     
29.  ` usCmdLen = 2 + 2 * ::wcslen(lpwszCmd);`
     
30.  ` ::WriteProcessMemory(hProcess, Param.CommandLine.Buffer, lpwszCmd, usCmdLen, NULL);`
     
31.  ` ::WriteProcessMemory(hProcess, &Param.CommandLine.Length, &usCmdLen, sizeof(usCmdLen), NULL);`
     
32.  ` // 修改指定进程环境块PEB中路径信息, 注意指针指向的是指定进程空间中`
     
33.  ` usPathLen = 2 + 2 * ::wcslen(lpwszPath);`
     
34.  ` ::WriteProcessMemory(hProcess, Param.ImagePathName.Buffer, lpwszPath, usPathLen, NULL);`
     
35.  ` ::WriteProcessMemory(hProcess, &Param.ImagePathName.Length, &usPathLen, sizeof(usPathLen), NULL);`
     
36.    
     
37.  ` return TRUE;`
     
38.  `}`
