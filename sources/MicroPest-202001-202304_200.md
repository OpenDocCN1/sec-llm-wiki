**题目描述：**

**1、The challenge description mentions that web browsers and password managers.**

**2、The challenge description emphasises that the owner of the system is an *environmental* activist; **

  

**一、第一个Flag：**

**1、查看镜像：**

![](../Images/7813eef5e2992de4a06ae8a657c71f6b.png)

采用第1个建议，操作系统为 Win7 SP1 x64；

  

**2、查看进程：**

![](../Images/d29ae4cbe335305dcc3164a762dbaeef.png)

挑战描述中提到了 web 浏览器和密码管理器。通过 pstree 插件检查运行中的进程，发现 Chrome 和 KeePass 密码管理器在转储时都在运行。让我们从 Chrome 开始。  

  

放大看看，

![](../Images/d745148fbf7c289e1639678f05fc338c.png)

发现有Chrome.exe和KeePass.exe程序存在。

  

我们将所有对象的列表转储出来，放入一个文件中，以供搜索之用。

  

**3、提取文件对象信息：**

![](../Images/366d84c259afabb4ddc5092110996112.png)

内容导出到filescan.txt中。  

  

在filescan.txt中查找Chrome的镜像位置，

![](../Images/fb420bab78864d33dbcc58394aaefb78.png)

  

**4、转储内存Chrome：**

![](../Images/6179a8647e61daff0c13ec7fa7ec7e5e.png)

形成文件，

![](../Images/2caf51b82d129e9a970e0ffa10b4bb58.png)

打开这个dat文件，  

![](../Images/02560055e1c95d093010c6e6aa1b2599.png)

原来是个SQLite 3的数据库文件；找个数据库工具打开它，

![](../Images/a820586731569e35aa1b3a44e5a58806.png)

我们看到 MEGA 文件共享网站被访问; 下载这个文件；

![](../Images/01f75235a14ddd24484956313878077b.png)

原来是important.zip。

![](../Images/85218c172839be2a0c3dbbb456f9c4a8.png)

我们看下压缩包内的提示“Password is SHA1(stage-3-FLAG) from Lab-1.Password is in lowercase.”，这句话提示我们密码要到上一个内存取证题去找这个Flag在小写处理后再作Sha1运算得到密码，我们来看看上一个Flag是什么？  

![](../Images/6b1fe6032bd373a92a06187112b6a1dd.png)

我们计算下，

![](../Images/ee028007d4a11b0267f8d1334fb70a0a.png)

计算得到sha1，  

6045dd90029719a039fd2d2ebcca718439dd100a

作为密码输入压缩包，解压打开图片，得到Flag，

![](../Images/ac9c094bd1ffec0bf4cc4ded6038ee30.png)

```
flag{oK\_So\_Now\_St4g3\_3\_is\_DoNE!!}
```
