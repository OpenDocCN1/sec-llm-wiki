         **二、下载安装**  

以kali为例：

git clone https://github.com/thewhiteh4t/FinalRecon.git

cd FinalRecon

pip3 install -r requirements.txt

  

会用到python3的pip3，程序会提示你必须要这个。

  

pip3的安装，apt-get install python3-pip
