    这不是一篇教大家做“坏事”的文章，而是我们在实战中经常听到C&C（Command and Control），尤其是在黑客所用的木马控制环境中。


    那到底什么是C&C，我们没有见识过，这也成为我们绕不开的结；只有见识过了，我们才能心中无惧，应付自如。下面，请跟随我来一睹它的模样。


声明：你利用本文章所做的坏事，后果自负，与本作者无关。


    我们选取的平台是：基于Kali下的。


    Covenant是一个.NET命令和控制框架，旨在突出.NET的攻击面，使进攻性.NET商业工具的使用更加轻松，并充当红队成员的协作命令和控制平台。


    Covenant是一个ASP.NET Core跨平台应用程序，其中包括基于Web的界面，该界面允许多用户协作。


一、安装

(1):git源：

git clone –recurse-submodules https://github.com/cobbr/Covenant    

(2)：安装dotnet core：

https://docs.microsoft.com/zh-cn/dotnet/core/install/linux-package-manager-debian10（参考）


1）注册 Microsoft 密钥和源

1、wget -O- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > microsoft.asc.gpg


2、sudo mv microsoft.asc.gpg /etc/apt/trusted.gpg.d/


3、wget https://packages.microsoft.com/config/debian/10/prod.list


4、sudo mv prod.list /etc/apt/sources.list.d/microsoft-prod.list


5、sudo chown root:root /etc/apt/trusted.gpg.d/microsoft.asc.gpg


6、sudo chown root:root /etc/apt/sources.list.d/microsoft-prod.list


2）安装 .NET Core SDK

1、sudo apt-get update

2、sudo apt-get install apt-transport-https

3、sudo apt-get update

4、sudo apt-get install dotnet-sdk-3.1

注意，这里是3.1SDK了


(3)运行启动：

进入Covenant目录下的Covenant


dotnet build


dotnet run 


    游览器打开https://localhost:7443进入控制面板，首次进入的话需要先注册，注册完毕后关闭注册，新建账户要管理员添加:


二、功能模块

作者在github是有说明每个模块的用途：https://github.com/cobbr/Covenant/wiki


界面：

分为一个总览，9个子模块；


(1):Listeners


(2)：Launchers

0-1：InstallUtil（通过InstallUtil启动Grunt，例：InstallUtil.exe /U file.dll）

0-2：MSBuild（命令行方式启动，例：msbuild.exe file.xml）

0-3：PowerShell（通过Powershell启动Grunt）

0-4：ShellCode（用donut转换grunt成shellcode）

0-5：Binary（.NET程序集，生成格式为exe文件）

0-6：Wmic（例：wmic os get /format:”file.xsl”）

0-7：Regsvr32（例：regsvr32 /u /s /i:file.sct scrobj.dll）

0-8：Mshta（例：mshta file.hta）

0-9：Cscript（例：cscript file.js）

0-10：Wscript（例：wscript file.js）


以上10种启动方式在生成的时候可以选择三种方式的模板

1-1：GruntHTTP：使用HTTP协议同C2 server进行通信

1-2：GruntSMB：使用命名管道

1-3：Brute：使用爆破
