3、那就再聊下amsi：

AMSI 可以用来检测 PowerShell、VBScript、JScript 等语言开发出来的恶意脚本，这个 API 是开放的，谁都可以调用，所以反病毒软件就可以使用此技术来在运行脚本的时候检测是否存在恶意代码和恶意行为（即使是这个脚本做了很大程度的混淆和变形）。


假如说这是一个恶意 PowerShell 脚本：

function Invoke-Evil
{
    Write-Host 'pwnd!'
}

这个恶意脚本很容易被检测，那么我们来混淆一下看看：

function Invoke-Evil
{
 $code = "IABXAHIXAaQB0AGUALQBIAG8AcwB0ACAAJwBwAHcabgBkACEAJwAgAA=="
 $newcode = [System.Text.Encoding]::Unicode.GetString(
        [Convert]::FromBase64String($code))

 Invoke-Expression $newcode
}

实际上这两个脚本的执行结果和第一条一样，都是在屏幕上输出一个 pwnd!，但是很明显，这样的混淆明显增大了反病毒软件的检测难度，于是 AMSI 应运而生。
