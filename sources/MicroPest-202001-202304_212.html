    Maldet 也被称为 Linux Malware Detect（LMD），它是一种 Linux 恶意软件扫描程序，用于处理共享托管环境中的常见威胁。它使用来自网络边缘入侵检测系统的威胁数据来提取主动攻击的恶意软件，并生成用于检测的签名。听起来很复杂，使用越来却很容易。LMD使用的签名是MD5文件哈希和HEX模式匹配，它们也可以轻松导出到任意数量的检测工具，例如ClamAV。



一、下载安装

https://github.com/rfxn/linux-malware-detect

或者

wget http://www.rfxn.com/downloads/maldetect-current.tar.gz


解压下载的文件：

tar -zxvf maldetect-current.tar.gz

文件夹中有一个 install.sh 脚本，此时执行该脚本：

sudo ./install.sh

如果安装成功，你将收到通知和 Maldet 的安装位置。默认是安装到 /usr/local/maldetect/ 路径下的。


二、配置使用

    Maldet安装完成后将在其默认安装目录下创建出一个 conf.maldet 配置文件，我们可以使用 gksu、nano、vim 等文本编辑器对其进行配置。下面是一些 Maldet 的配置选项示例。


1、邮件提醒

    在检测在恶意软件时进行邮件通知：

  • 将 email_alert 设置为 1

  • 在 email_addr 添加你的电子邮件地址

  • 将 email_ignore_clean 设置为 1，可以在自动清除恶意软件时忽略警报邮件。


2、隔离选项

    检测到恶意软件时要执行的操作：

  • 将 quarantine_hits 设置为 1 可以自动隔离恶意软件和受影响的文件

  • 将 quarantine_clean 设置为 1 可以自动清除受影响的文件（不推荐）

  • 将 quarantine_suspend_user 设置为 1 可以暂停受影响的账户（不推荐）

    以上只是配置示例，conf.maldet 配置文件中还有许多选项可以配置，大家按自己需求调整之后保存即可。


3、手动扫描恶意软件

    除定期进行的自动扫描外 Maldet 还可以手动执行扫描任务，只需执行如下命令：

sudo maldet --scan-all /folders/

    扫描完成后会自动生成一个报告，可以查看哪些文件受到影响。


4、还原被隔离的文件

    如果你发现有文件被错误隔离，可以使用以下命令来还原：

sudo maldet –restore FILENAME


5、自动扫描

   在Maldet的安装过程中，cronjob功能也将安装到 /etc/cron.daily/maldet，这样就可以自动扫描主目录以及最近每天更改的任何文件和文件夹。


6、帮助

常用的列出来：

    -b，--background
      在后台执行操作，非常适合大型扫描
      例如：maldet -b -r / home /？/ public_html 7

    -u，-更新[--force]
       从rfxn.com更新恶意软件检测签名

    -d，--update-ver [--force]
       从rfxn.com更新安装的版本

    -m，--monitor用户|路径|文件
       使用inotify内核级文件创建/修改监视来运行maldet
       如果指定了USERS，请监视用户homedir的UID> 500
       如果指定了FILE，则将从文件中提取路径，行间距
       如果指定了PATHS，则必须是逗号分隔的列表，不要使用WILDCARDS！
       例如：maldet --monitor用户
       例如：maldet --monitor / root / monitor_paths
       例如：maldet --monitor / home / mike，/ home / ashton

    -k，--kill
       终止监测服务

    -r，-scan-recent PATH DAYS
       扫描最近X天创建/修改的文件（默认值：7d，通配符：？）
       例如：maldet -r / home /？/ public_html 2

    -a，--scan-all路径
       扫描路径中的所有文件（默认：/ home，通配符：？）
       例如：maldet -a / home /？/ public_html

    -c，--checkout文件
       将可疑恶意软件上传到rfxn.com进行审查并哈希成签名

    -l，-log
       查看maldet日志文件事件

    -e，--report SCANID电子邮件
       查看最新扫描或特定SCANID（可选）的扫描报告
       通过电子邮件将报告发送到提供的电子邮件地址
       例如：maldet --report
       例如：maldet-报告列表
       例如：maldet --report 050910-1534.21135
       例如：maldet --report SCANID user@domain.com

    -s，-恢复文件| SCANID
       将文件从隔离队列还原到原始路径或从中还原所有项目
       特定的SCANID
       例如：maldet --restore /usr/local/maldetect/quarantine/config.php.23754
       例如：maldet --restore 050910-1534.21135

    -q，-隔离区SCANID
       隔离报告SCANID中的所有恶意软件
       例如：maldet --quarantine 050910-1534.21135

    -n，--clean扫描
       尝试从报告SCANID清除并恢复恶意软件点击
       例如：maldet --clean 050910-1534.21135

    -U，--user USER
       设置在指定用户下执行，非常适合从用户隔离区恢复或
       查看用户报告。
       例如：maldet --user none --report
       例如：maldet --user nobody --restore 050910-1534.21135

    -co，--config-option VAR1 = VALUE，VAR2 = VALUE，VAR3 = VALUE
       设置或重新定义conf.maldet配置选项的值
       例如：maldet --config-option email_addr = you @ domain.com，quar_hits = 1

    -p，--purge
       清除日志，隔离队列，会话和临时数据。


7、更新

    LMD发行版的更新不会自动安装，但可以使用--update-ver选项安装。有充分的理由认为这是
没有自动完成。发行版本的最新更改始终可以在以下位置查看：
http://www.rfxn.com/appdocs/CHANGELOG.maldetect

    LMD签名通常每天更新一次或更频繁取决于来自LMD检出功能的入侵威胁数据，IPS恶意软件提取等来源。LMD安装中的签名更新每天通过带有--update的默认cron.daily脚本执行选项，可以随时手动运行。
