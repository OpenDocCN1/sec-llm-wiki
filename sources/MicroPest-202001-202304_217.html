二、简介

    dazzleUP是一款用来检测由于 Windows 操作系统中的错误配置和缺少更新而导致的权限提升安全漏洞的工具，可以用来帮助渗透测试人员进行权限提升，可以在window系统中查找脆弱面进行攻击。dazzleUP 检测到以下漏洞。


工具包括两部分检查内容，exploit检查和错误配置检查。


1、Exploit Checks

dazzleUP 的第一个特性是，在寻找缺失的补丁时，它使用 Windows Update Agent API 而不是 WMI (与其他类似)。dazzleUP 检查以下漏洞：


  • DCOM/NTLM Reflection (Rotten/Juicy Potato) Vulnerability

  • CVE-2019-0836

  • CVE-2019-0841

  • CVE-2019-1064

  • CVE-2019-1130

  • CVE-2019-1253

  • CVE-2019-1385

  • CVE-2019-1388

  • CVE-2019-1405

  • CVE-2019-1315

  • CVE-2020-0787

  • CVE-2020-0796


    当目标系统是微软目前支持的 Windows 10操作系统(包括1809、1903、1909和2004)时，dazzleUP 会进行漏洞检查。如果在不支持的操作系统上运行，dazzleUP 会警告您“ dazzleUP 不支持目标系统构建编号，传递缺少的更新控件... ”。


2、Misconfiguration Checks

dazzleUP 为每个 Windows 操作系统检查以下错误配置：


  • Always Install Elevated

  • Credential enumaration from Credential Manager

  • McAfee's SiteList.xml Files

  • Modifiable binaries saved as Registry AutoRun

  • Modifiable Registry AutoRun Keys

  • Modifiable Service Binaries

  • Modifiable Service Registry Key

  • %PATH% values for DLL Hijack

  • Unattended Install Files

  • Unquoted Service Paths
