# 工具：自动快速识别恶意软件

    一直在致力于寻找一种方法来自动快速识别恶意软件，尤其是在一堆文件时；如果能做到简单快速自动地识别，那真是一件很爽的事情。

  

    最近，找到一个近似于能胜任这项使命的工具软件：Capa，一个命令行的工具。

  

    依靠这个工具，我们期望可以快速分类未知的二进制文件，以获得第一眼的洞察力和指导进一步的分析步骤，从而达到自动快速识别恶意软件的目的。

  

    我们以MalwareAnalysis-Labs的例子Lab01-01.dll来说明：

![](../Images/bcefd85b925299f4dc40a4989a0a1960.png)

我们通过ida来发现了其中的若干重要函数，

*   创建一个互斥对象，以确保只有一个实例在运行
    
*   创建一个 TCP 套接字 
    
*   连接到端口80上的 IP 地址127.26.152.13
    
*   发送和接收数据
    
*   将接收到的数据与字符串进行比较、执行
    
*   创建一个新进程
    

  

    我们认为恶意软件有能力执行这些行为。通过结论，我们可以推断恶意软件是一个后门，可以运行硬编码 C2服务器指定的任意程序。

  

    当然，恶意软件分析很少是直截了当的，一般可以通过包含成百上千个函数的二进制文件传播。

  

    然而，通过足够的实践，我们可以从 API 调用、字符串、常量和其他特性的重复模式中识别出程序中的功能。通过 Capa，我们证明了我们的一些关键分析结论实际上是可以自动执行的。该工具提供了一种通用而灵活的方式来编纂专家知识，并使其可供整个团队使用。当你运行 Capa 时，它会像人一样识别特征和模式，产生高级别的结论，从而推动后续的调查步骤。例如，当 Capa 认识到非加密 HTTP 通信的能力时，这可能是您需要转向代理日志或其他网络跟踪的提示。

  

**二、介绍Capa**

    当我们针对示例程序运行 Capa 时，下图中的工具输出几乎可以说明一切。主表显示了此示例中所有已识别的功能，左侧的每个条目都描述了一个功能。右侧关联的命名空间有助于对相关功能进行分组。Capa 的工作非常出色，描述了我们在前面讨论过的所有程序功能。

![](../Images/6c94199b975568949eaf1b273b603acd.png)

  

   我们发现 Capa 提供很好的结果。下图显示了 Capa 关于“ create TCP socket”结论的详细输出。在这里，我们可以检查二进制文件中 Capa 发现相关特征的确切位置。稍后我们将看到规则的语法——同时，我们可以推测它们是由结合了低层特性的逻辑树组成的。

![](../Images/4b4663c5e6388e33859af75c54d26862.png)

  

    Capa 由两个主要部分组成，用于对未知程序进行算法分类。首先，代码分析引擎从文件中提取特性，例如字符串、反汇编和控制流。其次，逻辑引擎查找以通用规则格式表示的特性组合。当逻辑引擎找到匹配时，Capa 报告规则描述的功能。

  

1、特征提取

    代码分析引擎从程序中提取低级特性。所有这些特征都与人类可能识别的特征一致，比如字符串或数字，并使 Capa 能够解释其工作。这些特性通常分为两大类: 文件特性和反汇编特性。

  

    文件特征是从原始文件数据及其结构中提取出来的，例如 PE 文件头。通过在整个文件中滚动可能会注意到这些信息。除了上面讨论的字符串和导入的 api 之外，还包括导出的函数和节名。

  

    从文件的高级静态分析中提取反汇编特征——这意味着反汇编和重构控制流。下图显示了选定的反汇编特性，包括 API 调用、指令助记符、数字和字符串引用。

![](../Images/cb0ddedba4e81c82e7d701f90ef57a38.png)

  

    因为高级分析可以区分程序中的函数和其他作用域，所以 Capa 可以在适当的详细级别上应用其逻辑。例如，当在不同的函数中使用不相关的 api 时，它不会被混淆，因为 Capa 规则可以指定它们应该独立地与每个函数匹配。

  

2、Capa规则

Capa 规则使用特性的结构化组合来描述可以在程序中实现的功能。如果所有必需的特性都存在，Capa 就会得出结论认为程序包含了这个功能。

  

Capa 规则是 YAML 文档，其中包含元数据和用于表示逻辑的语句树。其中，规则语言支持逻辑运算符和计数。在下图中，“ create TCP socket”规则表示数字6、1和2以及对 API 函数 socket 或 WSASocket 的调用必须出现在单个基本块的范围内。基本块将汇编代码分组在一个非常低的级别，使它们成为匹配紧密相关的代码段的理想位置。除了在基本块中，Capa 还支持函数和文件级别的匹配。函数作用域将反汇编函数中的所有特性联系在一起，而文件作用域包含整个文件中的所有特性。

![](../Images/53d0d965e5eee8d1c773614da2e108f1.png)

  

下图突出显示了允许 Capa 向其用户显示高级别、有意义的结果的规则元数据。规则名称描述标识的功能，而名称空间将其与技术或分析类别关联。我们已经在 Capa 的输出功能表中看到了名称和名称空间。元数据部分还可以包含作者或示例之类的字段。我们使用示例来引用文件和偏移量，在这些文件和偏移量中，我们知道存在某种能力，从而支持对每个规则进行单元测试和验证。此外，Capa 规则可以很好地记录现实世界中的恶意软件中的行为，所以可以随时保留一个副本作为参考。

![](../Images/54ccd3d8cd39390d93bbe3dfa62156ae.png)

  

为了使 Capa 的使用尽可能简单，牛人们为 Windows、 Linux 和 OSX 提供了独立的可执行文件。这个工具是用 Python 编写的，源代码可以在 GitHub 上找到。

  

**三、用法**

1、识别运行 Capa 的程序中的功能并指定输入文件:

Capa filename  

  

2、分析32位 shell 代码:

Capa -f sc32 filename

  

3、最详细的输出：

Capa -vv filaname

  

4、特定的规则，过滤：

Capa -t "create TCP socket" filaname

  

5、帮助：

Capa -h
