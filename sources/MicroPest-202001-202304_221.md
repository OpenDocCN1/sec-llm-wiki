    今天，介绍个微软出品的东西，**Project ****Freta****：一个 Linux 版的免费内存取证和 Rootkit 检测服务**。

  

    今年7月初，微软刚刚发布了一个免费的在线服务项目 Project Freta，微软官方对其的描述为：“微软研究院开发的免费服务，用于检测Linux系统内存快照中的操作系统和传感器破坏证据，例如rootkits和高级恶意软件。”据悉，Project Freta基于云计算，工作原理是捕捉虚拟机中运行的操作系统图像，并上传到云端分析处理。

![](../Images/2aef0c74efbe21ea2cf6e1a417d45990.png)

  

该项目以玛丽.居里的出生地命名；

  

    微软已经部署这套系统，以使小型和大型企业能够发现隐藏的恶意软件和内核rootkit。只需点击一下按钮，您需要做的就是将您的 linux vm 快照文件上传到您的帐号项目里，它将自动显示结果。目前，该系统支持超过4000个内核版本。

  

    Project Freta 支持四种内存镜像：Hyper-V 内存快照 (.vmrs文件)、LiME镜像(.lime文件)、物理内存的Elf核心转储(.core文件)和原始物理内存转储(.raw文件)。该项目的分析服务，包括进程、全局值和地址、内存文件、调试的进程、内核组件、网络、ARP 表、打开的文件、打开的套接字和 Unix 套接字。
