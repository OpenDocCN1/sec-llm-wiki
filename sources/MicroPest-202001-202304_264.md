# 确认样本upx\_linux是32位还是64位的程序？

readelf -a upx\_linux，下图可以看到为64位程序；

![](../Images/953f6050295a4f34602540ff793b7d3e.png)

上图为ELF文件头，前四个字节为标识：7f 45 4c 46，意思就是：ELF，下图：

![](../Images/c82affd93ed0db5f26b3eeb4e4749046.png)

第5个字节标识：为1，则32位；为2，则为64位；

这里建议用010editor这个编辑器，它提供了很多脚本可以自动地识别出文件格式，能对当前字段进行说明。

 

②上传IDA服务端程序到虚拟机linux，因为我们要用IDA进行远程调试，如图：

![](../Images/5a8c9c96608beeebf2ba2958cb6a279e.png)

因为这里的文件是64位的，所以将linux\_server64上传到root目录下；同理，如果是32位，就上传linux\_server，并将两文件赋运行权限，因为要运行程序；

chmod +x linux\_server64

chmod +x upx\_linux

 

将linux\_server64运行起来，

![](../Images/1b381ed925fb87ee239975be7f3cc3ce.png)

运行起来了，后端监听23946端口；
