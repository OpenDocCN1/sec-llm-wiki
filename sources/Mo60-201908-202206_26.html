继承的好处 :
子类可以继承父类的属性及方法 , 并允许覆盖父类的方法或新增方法.
通过自然界的比喻就是,通过"进化"来获得新特性, 同时不影响旧物种.

PHP 是单继承的：子类只能继承一个父类

序列化和反序列化

序列化是将变量转换为可保存或传输的字符串的过程；反序列化就是在适当的时候把这个字符串再转化成原来的变量使用。这两个过程结合起来，可以轻松地存储和传输数据，使程序更具维护性。
PHP 中的序列化和反序列化分别通过函数serialize()和unserialize()即可实现。serialize()的参数可以是resource类 型外的所有变量类型，最常见的是用来序列化对象，unseialize()将serialize的返回结果作为参数，进行反序列化，得到原对象。

序列化就是把本来不能直接存储的数据转换成可存储的数据，并且不会丢掉数据格式

反序列化就是把序列化的数据，转换成我们需要的格式

<?phpclass Test{  public $name;  public $age;    public function __construct($name,$age){    $this->name=$name;    $this->age=$age;  }}//序列化$data=serialize(new Test('Mo60',20));echo $data; //输出 O:4:"Test":2:{s:4:"name";s:4:"Mo60";s:3:"age";i:20;}
//反序列化var_dump(unserialize($data));//输出 object(Test)#1 (2) { ["name"]=> string(4) "Mo60" ["age"]=> int(20) }?>

魔术方法

系统在特定时机自己调用的方法

__construct(): 构造方法,new 实例时,自动调用

__destruct(): 析构方法,对象销毁时自动调用


__get(属性名): 当访问私有或者受保护的属性时触发,该方法有一个参数为属性名

__set(属性名,属性值): 外部设置私有或者保护的属性时调用,两个属性一个参数名一个参数值

<?phpclass Test{  public $name='Mo60';  protected $age=20;  private $height=180;    //当访问私有或者受保护的属性时触发,当外部访问age时将age值返回  public function __get($name){    if($name=='age')    {      return $this->age;    }    else    {      return $name;    }  }    //外部设置私有或者保护的属性时调用,外部设置height修改height的值  public function __set($name,$value){    if($name=='height')    {      $this->height=$value;    }  }}$Test=new Test();echo $Test->age;//输出收包含的属性age$Test->height=185;//修改私有的值?>

__unset(属性名): 当销毁一个私有或者保护的属性时触发

__isset(属性名): 当用isset,或empty判断一个私有或者保护的属性时触发

<?phpclass Test{  public $name='Mo60';  protected $age=20;  private $height=180;    //销毁一个私有或者保护的属性时触发,外部unset age时unset age  public function __unset($name){    if($name=='age')    {      unset($this->age);    }  }  //isset,或empty判断一个私有或者保护的属性时触发,  public function __isset($name){    return isset($this->$name);  }  }$Test=new Test();unset($Test->name);//可以在外部销毁公共属性unset($Test->age);//销毁受保护的属性var_dump(isset($Test->height));//isset私有的属性,为设置__isset时判断任何非public属性都为false?>

__toString() 在echo一个对象的时候触发,需要return一个字符串

<?phpclass Test{  public $name='Mo60';    public function __toString(){    return $this->name;  }}$Test=new Test();echo $Test;//触发__toString()方法?>

__call(方法名,方法参数) 调用一个不存在的方法时触发两个参数一个方法名,一个方法的参数

<?phpclass Test{  public function __call($name,$arr){    var_dump($name);    var_dump($arr);  }}$Test=new Test();$Test->Mo60(1,2,3);?>

__sleep()序列化一个对象的时候调用,返回值必须是一个数组,属性中写你要序列化的成员属性名

__wakeup()反序列化一个对象的时候调用,执行一些初始化方法可以写到这个函数中

<?phpclass Test{  public $name;  public $age;  public $height=180;    public function __construct($name,$age){    $this->name=$name;    $this->age=$age;  }  //实例化时只返回name,age  public function __sleep(){    return array('name','age');  }  //反序列化时给属性重新赋值  public function __wakeup(){    $this->name='JunMo';    $this->age=22;    $this->height=185;  }}//实例化$Test=new Test('Mo60',20);//序列化 触发了__sleep()echo $data=serialize($Test);// O:4:"Test":2:{s:4:"name";s:4:"Mo60";s:3:"age";i:20;}//反序列化 触发了__wakeup()var_dump(unserialize($data));//object(Test)#2 (3) { ["name"]=> string(5) "JunMo" ["age"]=> int(22) ["height"]=> int(185) }?>

__clone()克隆对象的时候触发,可以对克隆出来的对象属性做一些操作

<?phpclass Test{  public $name;  public $age;  public $height;    public function __construct($name,$age,$height){    $this->name=$name;    $this->age=$age;    $this->height=$height;  }  //对克隆出来的对象属性做一些操作  public function __clone(){    $this->name=$this->name.'clone';    $this->age=$this->age+5;    $this->height=$this->height+1;  }}$Test=new Test('Mo60',20,180);$clone=clone $Test; //克隆对象触发 __clone方法var_dump($clone);?>

单例模式

单例模式是面向对象语言里最常用、也是最简单的一种模式。

单例就是单个实例，单个对象的意思，就是说我们去实例化一个类的时候，不管调用多少次，都永远只有一个实例, 不会有多个，这样就节省了内存分配开支。

  构建一个PHP的单例类需要以下要求：

构造函数为private，防止外部代码new此对象。构造函数为final可以禁止子类覆盖。拥有一个静态成员变量来保存自身实例。拥有一个返回自身实例，公共且静态的方法，此方法负责只产生一个实例，如果已经有一个实例则直接返回。为了防止对象被克隆，还要重写__clone()方法

<?phpclass RandStr{  //单例  private static $instance=null;  //构造方法私有化,禁止外部实例化，final防止继承  private final function __construct(){}  //克隆方法私有化,防止克隆  private function __clone(){}    //创建一个静态方法,来生成当前唯一实例  static public function getInstance(){    //判断静态属性$instance是否保存实例    if(self::$instance==null)    {      //如果没有,创建实例并返回      return self::$instance=new self();    }    //如果已保存有当前实例,直接返回      return self::$instance;  }  public function Rand(){    $str=str_shuffle('abcdefghijklmnopqrstupwvsyzABCDEFGHIJKLOMNIPQRSTUPWVSYZ0123456789');    return $str=substr($str,0,5);  }}//获取实例$Test=RandStr::getInstance();echo $Test->Rand();//调用方法?>

抽象类

注意事项

  • 抽象类不能实例化对象

  • 抽象类存在的目的是为了让子类继承

  • 抽象类和普通类定义方法一样,只不过加了关键字abstract

  • 抽象类里面一般要有抽象方法,抽象方法用来让子类实现的,子类必须实现否则会报错

  • 抽象类只能是 public protected

  • 抽象类如果有参数,参数有默认值,那么实现该方法的时候参数和默认值都要有

  • 抽象类可以继承抽象类,子类实现的实现的时候所有抽象方法必须实现

<?phpabstract class Father{  abstract public function age($age); //已实现的方法，没有方法体}abstract class Test extends Father{  //参数有默认值,实现方法必须也要有  abstract public function name($name='NULL');}//继承抽象类,所有方法必须实现class Son extends Test{  public function name($name='NULL'){    echo 'Hi '.$name;  }  public function age($age){    echo 'You age '.$age;  }}
$Test=new Son();$Test->name('Mo60');$Test->age(20);?>

接口

  • interface 接口 implements 实现

  • 接口中所有方法都是抽象方法所以abstract 可不写，接口方法只能是public

  • 接口中只能规定方法,不能规定属性,接口中可以定义常量

  • 一个类可以实现多个接口，用逗号隔开

  • 一个类可以先继承父类然后在实现接口

  • 接口可以继承接口但是里面所有方法都要实现

<?php//接口的定义interface NumBerMultiply{  function multiply();}
//继承接口,实现时要实现所有方法interface NumBerAdd extends NumBerMultiply{  // 接口中定义的所有方法都必须是公有的抽象方法，所以public 、abstract 可不写  function add();}
interface NumBerMax{  function numMax();}
class NumBer{  public function numMin(){    return min(mt_rand(1,10),mt_rand(1,10),mt_rand(1,10));  }}// 一个类可以先继承父类然后在实现接口,可以实现多个接口，用逗号隔开class Person extends NumBer implements NumBerAdd,NumBerMax{  public function add(){    return mt_rand(1,10)+mt_rand(1,10);  }    public function numMax(){    return max(mt_rand(1,10),mt_rand(1,10),mt_rand(1,10));  }    public function multiply(){    return mt_rand(1,10)*mt_rand(1,10);  }}?>

异常

try尝试执行某一块代码,如果出现异常情况,那么需要手动抛出异常(throw),抛出异常后会被catch捕获到

  • try-catch是一种结果一个try必须对应至少一个catch

  • try和catch之间不能有任何代码

<?phpclass NumRand{  public function __construct(){    $this->num1();    $this->num2();  }    public function num1(){    if(mt_rand(1,10)>5)    {      throw new Exception("num1错了",1);//抛出异常,定义错误信息以及编号    }  }     public function num2(){    if(mt_rand(1,10)>5)    {      throw new Exception("num2错了",2);//抛出异常,定义错误信息以及编号    }  }}
try{  new NumRand;}catch(Exception $e){  echo '文件位置'.$e->getFile().'<br />';  echo '行号:'.$e->getLine().'<br />';  echo '错误信息'.$e->getMessage().'<br />';}?>
