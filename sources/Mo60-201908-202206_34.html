foreach在PHP5和PHP7中的区别：

在PHP 5中，当foreach开始循环执行时，每次数组内部的指针都会自动向后移动一个单元，但在PHP 7中则不是。在PHP 7中，按照值进行循环时，foreach是对数组的复制操作，在循环过程中对数组的修改不会影响循环行为，但在PHP 5中会有影响。

<?php require __DIR__.'/flag.php';if (isset($_POST['answer'])){     $number = $_POST['answer'];     if (noother_says_correct($number)){         echo $flag;     }  else {         echo "Sorry";     } } 
function noother_says_correct($number) {     $one = ord('1');     $nine = ord('9');     # Check all the input characters!     for ($i = 0; $i < strlen($number); $i++)     {         # Disallow all the digits!         $digit = ord($number{$i});         if ( ($digit >= $one) && ($digit <= $nine) )         {             # Aha, digit not allowed!             return false;         }     }     # Allow the magic number ...     return $number == "3735929054"; }

ord() 返回字符串的首个字符的 ASCII 值。
弱比较 :在进行比较运算时，如果遇到了0x这类字符串，PHP会将它按十六进制解析。


通post变量接收值,通过noother_says_correct函数去判是否存在1-9的数字然后去跟3735929054进行判断是否一致,也就是说要获取flag要传入的值不等于数字且要等于3735929054


解题

3735929054的十六进制值为0xdeadc0de,这里存在php弱类型比较问题，即"0xdeadc0de" == "3735929054",POST数据answer=0xdeadc0de即可获取flag
