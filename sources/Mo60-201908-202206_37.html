前言

遇到内网环境，外网只能访问端口80，使用常规lcx等反弹工具也会被各种安全软件拦截，这个时候就需要一款内网代理和端口转发工具，直连内网。

安装和配置reGeorg

reGeorg下载地址 https://github.com/sensepost/reGeorg

reGeorg采用python脚本编写，需要urllib3模块

python -m pip install urllib3
pip  install  urllib3

reGeorg使用

先将reGeorg的对应脚本上传到服务器端，reGeorg提供了PHP、ASPX、JSP脚本。

我这里是个php环境将reGeorg里的php文件上传至服务器,直接访问显示“Georg says, 'All seems fine'”，表示脚本运行正常。

在cmd下运行命令
python reGeorgSocksProxy.py -u (上传reGeorg脚本的地址) -p (本地监听的端口)

python reGeorgSocksProxy.py -p 1234 -u http://xxx.com/tunnel.nosocket.php

配合Proxifier

我这里是中文版的,可以自己去网上下载,打开Proxifier代理工具设置代理：Profile-proxy servers：设置：127.0.0.1:1234 socks5代理。

端口为你刚刚执行的监听端口

代理规则其实就相当于指定那个软件的流量经过代理，哪些不经过代理，一般情况下我们需要使用浏览器访问内网的网页，所以就需要给浏览器配置经过代理，其他不需要代理的软件就这设为direct模式（不经过代理）

现在在shell查看内网ip地址,得到内网地址为192.168.100

连接内网3389

打开本地远程桌面，右击mstsc.exe用Proxifier中的Proxy SOCKS 5 127.0.0.1打开。

输入内网地址192.168.1.100成功连接

Proxifier则会显示数据交互：

通过代理，对内网进行渗透

右击cmd.exe用Proxifier中的Proxy SOCKS 5 127.0.0.1打开。
