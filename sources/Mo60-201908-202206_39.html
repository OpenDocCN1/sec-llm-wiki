fofa介绍

FOFA是白帽汇推出的一款网络空间搜索引擎，它通过进行网络空间测绘，能够帮助研究人员或者企业迅速进行网络资产匹配，例如进行漏洞影响范围分析、应用分布统计、应用流行度排名统计等。

官网：https://fofa.so/

官方文档：https://fofa.so/help

fofa使用小贴士

注意：FOFA搜索关键词不区分大小写,支持的逻辑运算符包括：= ，==，!= ，&&，||。

domain

domain="baidu.com"  搜索百度所有的子域名


title

title="管理登入" 搜索标题中含有管理登入的网站


host

host=".gov.cn" 从url中搜索包含.gov.cn的网站


ip

ip="111.111.111.111" 搜索指定IP上的相关信息

支持IP段搜索ip="111.111.111.1/8"ip="111.111.111.1/16"ip="111.111.111.1/24"

header

header="ASP.NET" 搜索http响应头中含有ASP.NET的网站和IP


server

server="nginx" 搜索Nginx服务器

body

body="<script>alert(1)</script>" 搜索html正文中含有“<script>alert(1)</script>”关键词的网站和IP

port

port!=80 搜索端口不为80端口的服务

country

country="CN" 搜索位于中国的IP

cert

cert="google" 搜索证书(https或者imaps等)中带有google的资产

city

city="Beijing" 搜索北京的服务器 注:搜索城市时填写城市的全称,首字母必须大写!

protocol

protocol="ftp" 搜索ftp协议


os

os="windows" 搜索所有windows主机

ports

ports="80,21" 搜索同时开启80端口和21端口的IP

app

app="dedecms" 搜索dedecms

app="安全狗" 搜索使用安全狗的服务器


FOFA可以从不同维度搜索网络组件，例如地区，端口号，网络服务，操作系统，网络协议等等。目前FOFA支持了多个网络组件的指纹识别，包括建站模块、分享模块、各种开发框架、安全监测平台、项目管理系统、企业管理系统、视频监控系统、站长平台、电商系统、广告联盟、前端库、路由器、SSL证书、服务器管理系统、CDN、Web服务器、WAF、CMS等等，详细信息可见（https://fofa.so/library）。更多规则可见文档 https://fofa.so/help

适应场景

例如IIS出来了一个高危漏洞，受影响的版本号为IIS7.5,我们需要去本公司可能受此漏洞影响的IIS服务器，那么我们可以使用高级查询语句server=="Microsoft-IIS/7.5" && domain="xxx.com"，搜索结果即为本公司域名下的所有子域名可能存在IIS7.5版本漏洞的URL，安全人员可以对结果进行检查，及时修复漏洞。
