## 信息收集

我们在VM中需要确定攻击目标的IP地址，需要使用使用netdiscovernmap获取目标IP地址：

```


nmap -sP 192.168.1.0/24 -T4
```

![](../Images/00227cdbda1c5ae355b6ec4d9ae61a6e.png)

我们已经找到了此次CTF目标计算机IP地址：192.168.1.7

  

我们开始探索机器。第一步是找出目标计算机上可用的开放端口和一些服务。

  

因此我在目标计算机上启动了nmap全端口T5速度扫描：

```


nmap -sS -sV -A -T5 -p- 192.168.1.6
```

![](../Images/f971d7004ce5ba65787adacc40d179fd.png)

![](../Images/e3da6e0c5ca41d257ce3a6a7ea0f0376.png)

图中可以看出，目标计算机上有3个可用的开放端口。由于目标计算机上的端口21存在匿名登陆，我们首先来检查应用程序。

```


\# ftp 192.168.1.6
```

![](../Images/f65fa63cbde20c0b10e55fad9a975c02.png)

ftp匿名登陆anonymous/anonymous 下载到一个网络包lol.pcap；

![](../Images/e05262bef28acd44a505dcd5472ed1be.png)

在通过 WireShark 进行分析时，我们刚刚发现了一段揭示了一些重要信息的文本。

![](../Images/3259700e3b9bb91533ee726d82074231.png)

上面写着你已经找到了`sup3rs3cr3tdirlol`，让我们尝试访问这个目录。

![](../Images/e3f51e861336f8427c126f933e7872b9.png)

有个文件，下载下来，看下内容strings roflmao；

![](../Images/06e81edded32876053654dca20878820.png)

访问目录http://192.168.1.6/0x0856BF发现有两个文件夹。一个说是好运，第二个包含密码。

![](../Images/f7ec354659e16227810c9fac439aad08.png)

这里我将 Pass.txt 作为字符串添加到密码文件中，并将 which\_one\_lol 也添加到密码和用户名文件中，然后使用hydra爆破ssh；

这里有几个坑点：

1、它的密码就是直接给出的，所以不要把文本内容输进去；

2、SSH 会存在超时的问题，如果提示`Connection refused`请稍等几分钟再尝试；

3、密码必须要输入到文本中，不能直接作为密码使用；

```
hydra -L user.txt -P passwd.txt ssh://192.168.1.6
```

![](../Images/aa4feaccdc1331c1526eba7f9848926f.png)

我们已经成功获得了 SSH 登录的密码。现在让我们继续登录系统。

```

```
