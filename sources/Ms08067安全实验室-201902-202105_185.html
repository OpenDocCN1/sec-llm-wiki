最后总结一下：

1、 MySQL 数据库里面的数据是弱类型，弱类型在四则运算时字符型会被当做 0来处理。

2、 MySQL 中的‘’和 NULL 是两种不同的值。

3、 ‘’（空字符）在遇到运算符时也会被当做 0 来处理。

4、 MySQL 中的暗黑语法一定要去了解，说不定就是一个万能密码。例如这次的Poc 就是利用 MySQL 的弱类型，从而使得查询条件最终变成 username=0
