## Start Kali Linux virtual machine

*   
*   

```
gcloud compute images create kali -source-uri gs://bucket-name/kali.tar.gzgcloud compute instances create kali -image kali -machine-type n1-standard-1 -zone us-central1-b
```

*   \-machine-type 指定GCE类型
