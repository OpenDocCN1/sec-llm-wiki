6.  输入通配符\* ，Linux会把第一个列出的文件名当作命令，剩下的文件名当作参数
    
    *   
    *   
    *   
    
    ```
    >id>root* （等同于命令：id root）
    ```
    
    ![](../Images/1ade378f53dae7c0fff079db51b23e05.png)
    
7.  增加字母来限定被用来当作命令和参数的文件
    
    *   
    *   
    *   
    *   
    *   
    
    ```
    >ls>lss>lsss>1*s (等同于命令：ls lss lsss)
    ```
    
    ![](../Images/725d84fb6f2f6a14be99b90a1ff1373d.png)
    
    ![](../Images/cb99f2a41c4db4573cfa535a0e1b0986.png)
    
8.  联合知识点⑦，通过rev来倒置输出内容
    
    *   
    *   
    *   
    
    ```
    >revecho 1234 > v*v （等同于命令：rev v）
    ```
    
    ![](../Images/91b86f6380776a6430d6574b542e0a87.png)
    
    ![](../Images/d2379cbabd0692d097f45115c3f297b1.png)
    
9.  通过增加ls的-h（把文件大小显示成1k 1M 等形式）参数来让调整-t（根据时间排序）参数的位置，我们之后需要用到rev倒置输出。所以需要列出这样形式的文件名
