# 【VulnHub】Raven: 2 靶机的渗透测试

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU1NjgzOTAyMg==&mid=2247485309&idx=1&sn=1a6a7efa4843f07ea0d380975b59a146&chksm=fc3fbe7ccb48376a75dd6d9c08bb554ff444b968422994e240fe4751224a98a399e95624a50b&scene=126&sessionid=1681572546#rd](http://mp.weixin.qq.com/s?__biz=MzU1NjgzOTAyMg==&mid=2247485309&idx=1&sn=1a6a7efa4843f07ea0d380975b59a146&chksm=fc3fbe7ccb48376a75dd6d9c08bb554ff444b968422994e240fe4751224a98a399e95624a50b&scene=126&sessionid=1681572546#rd)

> 本文作者：**是大方子**（Ms08067实验室核心成员）

**总结与反思：**

1. 使用netdiscover探测内网存活主机

2. PHPMailer的漏洞反弹得到shell

3. Python版的EXP修改

4. 查看wordpress的wp-config.php配置文件得到数据库账号密码

5. MySQL版本 <= 5.7.14 5.6.32 5.5.51   可以利用UDF提权

6. KALI对EXP的编译

7. 给程序chmod u+s 增加suid权限，可以以root权限运行

8. 利用带有suid标志的find命令进行命令执行拿到root shell

 

靶机下载地址：https://download.vulnhub.com/raven/Raven2.ova

 

Raven 2是一个中等难度的boot2root 虚拟靶机，在多次被攻破后，Raven Security采取了额外措施来增强他们的网络服务器安全以防止黑客入侵。

总共4个flag需要找出!

先将靶机导入并开机.

![](../Images/165777451ccb40ee1c12f5d71029d74b.png)

利用netdiscover对eh0网卡进行探测

netdiscover \-i eth0

![](../Images/22069a9c1e9574acbfbe98a2fca70db0.png)

这里可以通过经验判断192.168.61.135就是靶机的IP地址。

nmap -A 192.168.61.135

![](../Images/a9760840b3f33657b041849d56cb35c7.png)

通过nmap的信息可以看出这个就是靶机的IP地址

通过上面的信息我们可以看到，靶机开放了22，80，111这3个端口。

我们先看80端口

![](../Images/e275f6ce5203c5c57987b157dde42a72.png)

看到是一个网站，所以我们就先进行目录的爆破，这里我用gobuster

gobuster -u http://192.168.61.135 -w /usr/share/wordlists/dirb/common.txt

![](../Images/1eb6f2694a2c596d545b8e8d6a2d7428.png)

这里先看下vendor

这个网站是存在目录遍历的

/var/www/html/

![](../Images/8231e0f5cd65e964e4307b2fe8f10e07.png)

![](../Images/6a44a48a59ed210e4e84bace1dcc58e7.png)

查看到EXP的内容

也可以用exploit-db.com进行搜索exp

https://www.exploit-db.com/exploits/40974

通过exploit-db的查询我们知道这个漏洞的编号为CVE-2016-10033

然后我们查下漏洞资料：https://www.anquanke.com/post/id/85295

这个漏洞是因为邮件地址能够包含用引号括起来的空格，这样可以进行攻击参数的注入

我们我们在网站主页上看到的邮件页面地址为：http://192.168.61.135//contact.php

接下来我们把EXP的内容进行下载编辑

修改内容如下：

1. 开头加上

#!/usr/bin/python

\# -\*- coding: utf-8 -\*-

![](../Images/e5bd1b46387c6d4576b841b73bda37f0.png)

2. 修改target地址为靶机的CONTACT页面地址：http://192.168.61.135/contact.php

修改backdoor为’/sdfz.php’,默认的backdoor.php执行时无法生成（原因可能是如介绍说这个靶机多次被攻击增加了安全性，这类敏感字肯定会被ban）

![](../Images/efb837d87c81efa502a22a1b41fcad96.png)

3. 修改payload的内容

![](../Images/f0cbcab7d1f755d4951ef83b72b0b380.png)

4. 运行后出现如下错误，只要pip install requests-toolbelt即可

![](../Images/534301714a3ad24d32b260c8e1ab65a1.png)

5. 然后KALI nc监听下对应的端口

![](../Images/7d135be431f144f565f6dd73098ec923.png)

6. 然后我们访问下http://192.168.61.135/contact.php，这样就会执行我们的payload在目录下面生成sdfz.php

7. 然后我们在访问下http://192.168.61.135/sdfz.php

8. 这个时候我们就会得到反弹的shell

![](../Images/b1bc4842e3af56dbef1b0861ece68d3a.png)
