# WebGoat靶场系列---WebGoat安装

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU1NjgzOTAyMg==&mid=2247484080&idx=1&sn=bb55a74c4280f9d384217bd3e66f641d&chksm=fc3fbbb1cb4832a7faeaf10e997b766126ed922dd8d9e83e08e1feac60a1ccdb2bb32a602c8f&scene=126&sessionid=1681572571#rd](http://mp.weixin.qq.com/s?__biz=MzU1NjgzOTAyMg==&mid=2247484080&idx=1&sn=bb55a74c4280f9d384217bd3e66f641d&chksm=fc3fbbb1cb4832a7faeaf10e997b766126ed922dd8d9e83e08e1feac60a1ccdb2bb32a602c8f&scene=126&sessionid=1681572571#rd)

![](../Images/d4e79efd2c732bbd6e445e5fa86b60f0.png)

WebGoat是OWASP组织研制出的用于进行web漏洞实验的Java靶场程序，用来说明web应用中存在的安全漏洞。WebGoat运行在带有java虚拟机的平台之上，当前提供的训练课程有30多个，其中包括：跨站点脚本攻击（XSS）、访问控制、线程安全、操作隐藏字段、操纵参数、弱会话cookie、SQL盲注、数字型SQL注入、字符串型SQL注入、web服务、Open Authentication失效、危险的HTML注释等等。WebGoat提供了一系列web安全学习的教程，某些课程也给出了视频演示，指导用户利用这些漏洞进行攻击。

GitHub地址为：

https://github.com/WebGoat/WebGoat

使用WebGoat的方式有很多,我们以常用的两种方式进行安装。

*   Web Applications Project靶机
    
*   Windows安装
    

  

**0X01 ****Web Applications Project**

  

1.  下载OWASP
    
    https://sourceforge.net/projects/owaspbwa/files/
    

直接进入网站选择需要的版本下载(以1.2.7版本为例)   

![](../Images/d1e073685723c6390cb839ecad5c702b.png)

    

    2.下载/安装虚拟机

虚拟机可以从以下链接下载,内附激活码，安装完成后输入激活码激活，然后设置成以管理员方式运行。

https://pan.baidu.com/s/1jRSm-6fgqk2\_mghKpj4Xxg

提取码：u1x6

![](../Images/947315c91cb7dc35b868ca936ec87ce4.png)

  

    3.将下载好的OWASP解压缩,然后使用虚拟机打开并开机，用户名root,密码owaspbwa，默认的IP地址是会在开机的时候提示出来。

![](../Images/1f80922a5187550fb9b755e2934cccc9.png)

输入提示的IP地址10.10.10.129，第一个就是我们需要的WebGoat。

![](../Images/b8d63557d81a2b783c969cf302a41cb6.png)

点击打开，按提示输入账号密码,也就是我们的虚拟机开机的账号密码。至此，已经成功的安装好了OWASP Broken Web Applications 虚拟机，当然里边不止包含WebGoat,还包含各种WEB渗透环境供大家选择。

![](../Images/7c2ef721c7274208cefdb077c9664cf1.png)

  

![](../Images/9131736190ce732219c712c7bf9d3390.png)

  

**0X02**  **Windows下安装WebGoat**

1.下载安装JDK，选择适合自己系统版本的。

https://www.oracle.com/technetwork/java/javase/downloads/jdk8-downloads-2133151.html

![](../Images/db7ab676892a85a9f4e9c58b6569483b.png)

下载安装完成后，需要配置环境变量，电脑右键属性---高级系统设置---环境变量。

![](../Images/fd7f0ca133a3133a9e1e0cd0b11506c1.png)

新建系统环境变量,变量名为’JAVA\_HOME’,变量值是jdk的安装路径

![](../Images/9718ef5d22f75e0e527579dd6bf961ab.png)

新建一个系统变量,名为“CLASSPATH”，变量值

’ .;%JAVA\_HOME%\\lib\\dt.jar;%JAVA\_HOME%\\lib\\tools.jar;’的系统变量，注意前面的点号和分号。

![](../Images/5807583c505837146ae1d99116186be9.png)

修改系统变量’Path’，然后点击新建，添加“%JAVA\_HOME%\\bin”和

“%JAVA\_HOME%\\jre\\bin”两个系统变量。

![](../Images/4cbb33da6f72cdc3837b469d465676ca.png)

![](../Images/fb082d37ad2eac2eeab42c6561513615.png)

![](../Images/c645036e624482d05010d53baefbab40.png)

最后打开运行窗口,输入CMD,打开命令行窗口输入java, javac验证安装是否正常。

![](../Images/c00854c32c5cc9e2aae43276d45b7456.png)

  

2\. 安装WebGoat

https://code.google.com/archive/p/webgoat/downloads  

网盘：https://pan.baidu.com/s/1HcT0ArKd-7CYzYldvxySEg  

提取码：9gpn

![](../Images/d75628729694c5ac4aadea3f30fc357f.png)

解压文件之后,进入tomcat文件夹,将文件路径复制下来,然后设置环境变量(和Java环境变量设置方式相同)变量名为’CATALINA\_BASE’和’CATALINA\_HOME’,变量值都为tomcat所在文件的路径。

![](../Images/e59eb36446f3d89132c1e3751669a4ee.png)

![](../Images/1fbda21952b6d92a2adf0af58cc217c3.png)

接下来,编辑’Path’变量

![](../Images/988df8d433b8dd2407b7c64ed912742e.png)

![](../Images/ba8975abf7d7d8c7e50a15280dd4bae5.png)

然后以管理员身份运行命令提示符，进入到WebGoat中tomcat的bin目录下,输入service.bat install(我这里已经安装过了,所以会提示指定服务已存在)。

![](../Images/6d1bc64dbbf9523fb3f8af4e51771f14.png)

输入startup,启动tomcat。

![](../Images/9ab5cffbea204d1b28ef823ff9f65783.png)

然后进入WebGoat目录,打开webgoat批处理文件

![](../Images/2ca0e8f96418a675d91fcb7a6ce48106.png)

输入http://localhost/WebGoat/attack即可弹出WebGoat的登陆界面,输入账号密码均为guest，即进入WebGoat页面。

![](../Images/df84bb5987661c7ff617e1dec7593c10.png)

![](../Images/37e455ed2d8c90be8cd544b609eafdcf.png)
