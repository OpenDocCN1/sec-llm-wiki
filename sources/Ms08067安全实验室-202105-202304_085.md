# 腾讯推出全新 Linux QQ 并正式上线官网，版本号 3.0.0

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU1NjgzOTAyMg==&mid=2247505620&idx=3&sn=d48fec4befcba64a8ef9851b972deaf7&chksm=fc3c6fd5cb4be6c3290b10cc2d3dab8d16c6bea0ea7e9d80c9ab27cc533bb5256494eed1e72f&scene=126&sessionid=1681572282#rd](http://mp.weixin.qq.com/s?__biz=MzU1NjgzOTAyMg==&mid=2247505620&idx=3&sn=d48fec4befcba64a8ef9851b972deaf7&chksm=fc3c6fd5cb4be6c3290b10cc2d3dab8d16c6bea0ea7e9d80c9ab27cc533bb5256494eed1e72f&scene=126&sessionid=1681572282#rd)

12 月 30 日消息，基于 NT 架构的全新 QQ Linux 版已结束内测，并正式为其推出官网（https://im.qq.com/linuxqq/index.shtml），并为所有用户提供下载。

新版本提供了deb、rpm、Applmage三种格式的软件包，同时也支持Arm64 平台。

![](../Images/e2c09ffe3d66fd86127bbf79c79defb2.png "腾讯推出基于 NT 架构的全新 Linux QQ 并正式上线官网，版本号 3.0.0")

> *   如何选择安装包？
>     
> *   QQ Linux 版 目前支持 x64（x86\_64、amd64）、arm64（aarch64）两种架构，每种架构支持 Debian 系、Red Hat 系、其它发行版中的一种或几种（未来可能继续扩充）。每一次发布均会提供架构和发行版的若干种组合支持的安装包，可按下面所述的规则进行选择。  
>       
>     每一个安装包会按照形如如下的格式命名：  
>     linuxqq\_3.0.0-100\_x64.rpm  
>     \[产品名\] \[---版本号---\]\[架构\]\[格式\]  
>       
>     1、选择架构：  
>     根据你所使用的机器硬件架构选择相应的兼容架构类型（可通过 uname -a 查看）x64（x86\_64、amd64）、arm64（aarch64）  
>       
>     2、根据你所使用的 linux 发行版选择格式：  
>     ![](../Images/28216ca2bd685dc1acac2015899d9ca0.png "腾讯推出基于 NT 架构的全新 Linux QQ 并正式上线官网，版本号 3.0.0")
>     
> *   如何安装？
>     
> *   QQ Linux 版 目前支持 x64（x86\_64、amd64）、arm64（aarch64）两种架构，每种架构支持 Debian 系、Red Hat 系、其它发行版中的一种或几种（未来可能继续扩充）。每一次发布均会提供架构和发行版的若干种组合支持的安装包，可按下面所述的规则进行选择。  
>     RPM  
>     sudo rpm -ivh linuxqq\_3.0.0-100\_arm64.rpm  
>       
>     DEB  
>     sudo dpkg -i linuxqq\_3.0.0-100\_x64.rpm  
>     或  
>     sudo apt install -y linuxqq\_3.0.0-100\_x64.rpm  
>       
>     AppImage  
>     chmod +x linuxqq\_3.0.0-100\_x64.AppImage  
>     ./linuxqq\_3.0.0-100\_x64.AppImage
>     
> *   如何卸载？
>     
> *   QQ Linux 版 目前支持 x64（x86\_64、amd64）、arm64（aarch64）两种架构，每种架构支持 Debian 系、Red Hat 系、其它发行版中的一种或几种（未来可能继续扩充）。每一次发布均会提供架构和发行版的若干种组合支持的安装包，可按下面所述的规则进行选择。  
>     RPM  
>     sudo rpm -e linuxqq  
>       
>     DEB  
>     sudo dpkg -r linuxqq
>

下面是 QQ Linux 3.0.0 版本更新内容：

1、新增夜间模式并支持跟随系统，享受更沉浸的聊天体验；

2、新增 QQ 截图能力，快捷方便，提升办公效率；

3、新增群应用功能，图片、文件轻松传送，群聊更高效；

4、新增全局搜索能力，进一步提升内容搜索效率。

IT之家获悉，QQ for Linux 版采用全新架构，以 QQ NT 技术架构驱动，支持消息、小世界、QQ 空间板块等。
