在网上看了很多破解教程，基本都不能破解现在的nessus，所以自己研究了一份教程分享给大家。



安装破解Nessus



安装



下载好安装包和插件之后在opt目录下创建个文件夹方便后面使用。


10.4之后的版本我目前无法破解我用的是10.3，想要10.3可以关注公众号询问。




把下载好的吉祥三宝放进去




开始安装

dpkg -i /opt/nessus/Nessus-10.3.0-debian9_amd64.deb




启动nessus服务

systemctl start nessusd



访问https://localhost:8834/


选择Managed Scanner，然后点击Continue



选择Tenable.sc，然后点击Continue



设置你的用户名密码（密码只输入一次没有确认密码 小眼睛点开看清楚自己的密码）



等会加载完就是这样



破解


关闭nessus服务

systemctl stop nessusd



利⽤Vi命令修改下面这两个文件

vi /opt/nessus/var/nessus/plugin_feed_info.incvi /opt/nessus/lib/nessus/plugins/plugin_feed_info.inc



更新插件包



更改文件属性


chattr +i /opt/nessus/var/nessus/plugin_feed_info.incfind /opt/nessus/lib/nessus/plugins/ -name "*.*" | xargs -i chattr +i {}chattr -i /opt/nessus/lib/nessus/plugins/plugin_feed_info.inc


这个过程比较漫长耐心等待



启动nessus服务


systemctl start nessusd



等待初始化



破解成功



Nessus开机自动启动

systemctl enable nessusd.service

完了尽量把kali挂起不要关机

因为每次开机都会重新初始化很麻烦
