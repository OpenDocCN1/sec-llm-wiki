一.什么是SQL注入

  
  
  
  
![](../Images/ff1bd079526120668b90fc2a306703a3.png)![](../Images/c45af9614916575a37f63cd7ca7daf33.png)

  

  SQL注入即是指web应用程序对用户输入数据的合法性没有判断或过滤不严，攻击者可以在web应用程序中事先定义好的查询语句的结尾上添加额外的SQL语句，在管理员不知情的情况下实现非法操作，以此来实现欺骗数据库服务器执行非授权的任意查询，从而进一步得到相应的数据信息

  

tisp:通俗来说就是原本的SQL语句拼接了我们写的数据被数据库当作成代码执行了.

**union select(****联合查询****)**

  

*   
*   
*   
*   
*   

```
联合查询的含义:把两条SQL语句查询到的结果一起输出出来.根据以上图片所致数据库在执行的代码:select * from admin where id = '1'order by 3--+qwe'
知道了有三个字段 我们构造字段数满足相同字段数的条件:select * from admin where id = 1 union select 1,2,3
```
