**Agenda**

  

  

1.**【论文分享】Good Bot, Bad Bot: Characterizing Automated Browsing Activity**

*   **Presenter: **邢云鹏
    
*   **Conference: **S&P 2021
    
*   **Authors:** Xigao Li, Babak Amin Azad, Amir Rahmati, Nick Nikiforakis
    
*   **Abstract: **The authors set up a distributed honeypot system, deployed real World Wide Web applications, and conducted a 7-month measurement experiment to record and analyze the network robot traffic. The researchers used the data collected to identify more than 70,000 malicious cyberbots.
    
*   **Link to paper: **https://ieeexplore.ieee.org/document/9519384
    

  

2.**【论文分享****】Drifuzz: Harvesting Bugs in Device Drivers from Golden Seeds**

*   **Presenter: **马哲宇
    
*   **Conference:** USENIX Security'22
    
*   **Authors: **Zekun Shen, Ritik Roongta, and Brendan Dolan-Gavitt, NYU
    
*   **Abstract: **Drifuzz is a hardware-free concolic-augmented fuzzer targeting WiFi and Ethernet drivers that proposes a technique for generating high-quality initial seeds, which they call golden seeds, that allow fuzzing to bypass difficult code constructs during driver initialization.
    
*   **Link to paper: **https://www.usenix.org/system/files/sec22-shen-zekun.pdf
