**Agenda**

  

  

1.**【论文分享****】Not that Simple: Email Delivery in the 21st Century**

*   **Presenter: **仓永康弘
    
*   **Conference:** USENIX ATC'22
    
*   **Authors: **Florian Holzbauer, Johanna Ullrich, Martina Lindorfer, Tobias Fiebig
    
*   **Abstract: **This article primarily investigates the deployment status of email in the real world and evaluates the security features and DNS configurations of email senders by sending experimental emails to 11 different configurations of email recipients. It also measures the support for IPv4 and IPv6 versions from different vendors.
    
*   **Link to paper: **https://www.usenix.org/system/files/atc22-holzbauer.pdf
    

  

2.**【论文分享】**Enhancing DNN-Based Binary Code Function Search With Low-Cost Equivalence Checking

*   **Presenter: **王元达
    
*   **Conference: **TSE'23
    
*   **Authors:** Huaijin Wang, Pingchuan Ma, Yuanyuan Yuan, Zhibo Liu, Shuai Wang, Qiyi Tang, Sen Nie, Shi Wu
    
*   **Abstract: **This paper proposes a solution for enhancing the top-k ranked candidates in DNN-based binary code function search using a low-cost and comprehensive equivalence check, named BinUSE, which can effectively reduce false alarms and improve the accuracy of binary code search tools.
    
*   **Link to paper: **https://ieeexplore.ieee.org/document/9707874
