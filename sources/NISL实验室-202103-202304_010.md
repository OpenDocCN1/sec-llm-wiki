**Agenda**

  

  

1.**【论文分享****】Hope of Delivery: Extracting User Locations From Mobile Instant Messengers**

*   **Presenter: **郎峙煜
    
*   **Conference:** NDSS'23
    
*   **Authors: **Theodor Schnitzler, Katharina Kohls, Evangelos Bitsikas, Christina Popper
    
*   **Abstract:**
    
     This paper presented a novel timing side-channel in popular instant messengers, allowing to distinguish different receivers and their locations by sending them instant messages.
    
*   **Link to paper: **https://www.ndss-symposium.org/wp-content/uploads/2023/02/ndss2023\_s188\_paper.pdf
    

  

2.**【论文分享】**VulHawk: Cross-architecture Vulnerability Detection with Entropy-based Binary Code Search

*   **Presenter: **孙铭扬
    
*   **Conference: **NDSS'23
    
*   **Authors:** Zhenhao Luo, Pengfei Wang, Baosheng Wang, Yong Tang, Wei Xie, Xu Zhou, Danjun Liu and Kai Lu
    
*   **Abstract:**
    
     This paper proposes a novel intermediate representation function model, which is an architecture-agnostic model for cross-architecture binary code search.
    
*   **Link to paper: **https://www.ndss-symposium.org/wp-content/uploads/2023/02/ndss2023\_f415\_paper.pdf
