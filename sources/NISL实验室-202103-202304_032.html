Agenda



1.【论文分享】SCALE: Automatically Finding RFC Compliance Bugs in DNS Nameservers

  • Presenter: 张丰露

  • Conference: NSDI 2021

  • Authors:

    Siva Kesava Reddy Kakarla, Ryan Beckett, Todd Millstein, George Varghese

  • Abstract:

    This paper proposes black-box tests on main-stream DNS nameserver implementations and analyzes their RFC-compliance bugs.

  • Link to paper:

    https://www.usenix.org/system/files/nsdi22-paper-kakarla.pdf

2.【论文分享】IJON: Exploring Deep State Spaces via Fuzzing

  • Presenter: 石英昊

  • Conference: SP 2020

  • Authors:

    Cornelius Aschermann, Sergej Schumilo, Ali Abbasi, Thorsten Holz

  • Abstract:

    This paper proposes an annotation mechanism for stateful greybox fuzzing, solving state exploration challenge by using these manual annotations.

  • Link to paper:

    • https://ieeexplore.ieee.org/stamp/stamp.jsp?tp=&arnumber=9152719
