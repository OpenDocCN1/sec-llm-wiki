**Agenda**

  

  

1.**【论文分享****】**Web Cache Deception Escalates!

*   **Presenter: **王一航
    
*   **Conference:** USENIX Security 2022
    
*   **Authors:**
    
    Shi Seyed Ali Mirheidari, Matteo Golinelli, Kaan Onarlioglu, Engin Kirda, Bruno Crispo
    
*   **Abstract:**
    
    This paper proposes a a novel WCD detection methodology that forgoes testing prerequisites, and utilizes page identicality checks and cache header heuristics to test any website.
    
*   **Link to paper:**
    

    https://www.usenix.org/system/files/sec22summer\_mirheidari.pdf

2.**【论文分享】**Non-Distinguishable Inconsistencies as a Deterministic Oracle for Detecting Security Bugs

*   **Presenter: **殷婷婷
    
*   **Conference: **CCS 2022
    
*   **Authors:**
    
    Qingyang Zhou, Qiushi Wu, Dinghao Liu, Shouling Ji, Kangjie Lu
    
*   **Abstract:**
    
    This paper proposes a novel static method for detecting security bugs based on a new concept called Non-Distinguishable Inconsistencies (NDI).
    
*   **Link to paper:**
    

https://dl.acm.org/doi/pdf/10.1145/3548606.3560661
