Agenda



1.【论文分享】Frameshifter: Security Implications of HTTP/2 -to -HTTP/1 Conversion Anomalies

  • Presenter: 梁越嘉

  • Conference: USENIX Security 2022

  • Authors:

    Bahruz Jabiyev, Steven Sprecher, Anthony Gavazzi, Tommaso Innocenti, Kaan Onarlioglu, Engin Kirda

  • Abstract:

    This paper presents the first systematic exploration of HTTP/2-to-HTTP/1 protocol conversion anomalies and their security implications

  • Link to paper:

    https://www.usenix.org/conference/usenixsecurity22/presentation/jabiyev


2.【论文分享】FuzzJIT: Oracle-Enhanced Fuzzing for JavaScript Engine JIT Compiler

  • Presenter: 牟思睿

  • Conference: USENIX Security 2023

  • Authors:

    Junjie Wang, Zhiyi Zhang, Shuang Liu, Xiaoning Du, Junjie Chen

  • Abstract:

    This paper presents a novel fuzzing technique, FuzzJIT, for explosing JIT compiler bugs in JavaScript engines.

  • Link to paper:https://www.usenix.org/conference/usenixsecurity23/presentation/wangjunjie
