**1.【学术报告】****Measuring the Practical Effect of DNS Root Server Instances: A China-Wild Case Study****（14:00-15:00）**

  
**会议地址（**需要注册）**： ****APAC DNS FORUM 2022**https://apacdnsforum.my/   
**演讲人**:  张丰露（清华大学网研院硕士生）**摘要: **互联网的根——根域名服务器在全球部署了很多镜像节点，而且数量还在增长，究竟效果如何？我们对此进行了大规模测量，并将在ICANN组织的 APAC DNS 论坛上介绍我们的研究结果和发现。

DNS root servers are deployed using multiple globally distributed anycast instances, and the scale of instances across the globe has been rapidly growing. We introduce a measurement study that investigates the practical effect of root server instances deployed in the Chinese mainland.
