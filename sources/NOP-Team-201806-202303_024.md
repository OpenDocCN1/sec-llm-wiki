```
/*unlink操作的实质就是：将P所指向的chunk从双向链表中移除，这里BK与FD用作临时变量*/#define unlink(P, BK, FD) {                                            \    B = P->fd;                                   \    A = P->bk;                                   \    B->bk = A;                                  \    A->fd = B;                                  \    ...}
```

```
B->bk != P || A->fd != P  P -> fd = *P - 0x18P -> bk = *P - 0x10
B -> bk = *P - 0x18 + 0x18 = *PA -> fd = *P - 0x10 + 0x10 = *P  B = P->fd;                                   \A = P->bk;    
B->bk = A;                                  \*P = *P - 0x10 
A->fd = B;*P = *P - 0x18
```
