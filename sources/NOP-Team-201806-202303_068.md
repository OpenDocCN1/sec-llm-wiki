我们看一下nc 反弹的 shell 

![](../Images/2734f474456b7936f0cc05d82d737cab.png)

![](../Images/73714cbbb28c48ad80cab7b9a74e0f08.png)

使用 python 的 pty 来转换为 交互式shell

*   `python3 -c 'import pty; pty.spawn("/bin/bash")'`
    
*   也可以使用`python3 -c "__import__('subprocess').call(['/bin/bash'])"`
    

![](../Images/258f17f6d3fc3194d953713c672d6112.png)

可以看到su这种交互式命令已经可以执行了，我们尝试一下代码补全

![](../Images/18ab5cae9c2410098da91c7f45a1554b.png)

看来代码补全还是不行，查了资料，可以使用 stty 来进行优化，将哑 shell 转换为全能shell

在 python3 -c 'import pty; pty.spawn("/bin/bash")' 后的shell中输入 `Ctrl+z`

> Linux 中Ctrl + c/d/z 看着都差不多，但是还是有不一样的含义
> 
> *   Ctrl + c 强制中断程序的执行，进程终止
>     
> *   Ctrl + d 发送EOF信号，很多程序接到这个信号后会停止
>     
> *   Ctrl + z 将任务中止，其实就是将这个任务暂停
>     

![](../Images/bad80372b92e0f6be773c84dc1a1a259.png)

可以看到，nc反弹的shell放入了后台，界面退回到了攻击主机原本的shell 

*   `echo $TERM` 获取 term值
    
*   `stty -a` 获取 rows 和 columns 的值
    

![](../Images/750d5b9a311d7f1148a8cbea26170056.png)

*   `stty raw -echo` 关闭输入回显
    
*   `fg` 进入前台，就是把刚才中止的nc连接捡回来
    

![](../Images/15da74bcaa1e0b121ccf51b4d3feb60b.png)

*   `reset`
    
*   `export SHELL=bash`
    
*   `export TERM=xterm-256color`
    
*   `stty rows 24 columns 80`
    

![](../Images/7f8886d3b0138fff5743457d5c024154.png)
