MS 11-080 漏洞提权

1
漏洞基本信息

“

对应的补丁信息：

kb2592799 发布时间：2011年10月11日

受攻击系统： windows xp & windows 2003_32|64 bit

具体信息:

https://docs.microsoft.com/zh-cn/security-updates/Securitybulletins/2011/ms11-080


”
2
   Notice！！！

“

这个漏洞利用对于中文版本是一个DoS 漏洞，会蓝屏，并不一定会特权提升

对于英文版本可以成功提权。使用时候一定要注意！

”
3
查找EXP

“

我们去数据库搜索一下相关的利用EXP

可以看到有python和ruby的版本的exp

我懂python，所以我们来使用Python版本的吧

我们也可以去上面的exp github上看一下

PS: 这里我还要强调一下，这个github 中的任何已经编译好的程序都不能保证没有后门

这里还是采用Kali 中查询到的开源的Python2版本

”
4
编译EXP

如何编译成可执行文件呢？

在RAT 远程控制那篇文章中我有写过，大家可以去参考一下

这里我们需要的是Python2，

需要安装

Pyinstaller

https://pypi.python.org/pypi/PyInstaller/2.1


Pywin32

http://sourceforge.net/projects/pywin32/files/pywin32/Build%20219/

这个编译过程需要windows上

一般来说我，我们需要在与目标相同环境下进行编译，这样才能保证成功率，所以我们就在windows 2003 上配置环境进行编译


配置好环境后，我们开始编译exp

python pyinstaller --onefile 18176.py


5
提权开始
“

18176.exe -O 2k3

可以看到成功提权至System权限！


PS： 这里我还是提醒一下大家，这个漏洞我用同样的环境做过两次实验，一次蓝屏，一次就像上面这样，大家提权要慎重！

”
