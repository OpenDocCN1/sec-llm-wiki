“难得开源并且强大的漏洞扫描器”


在大家看文章之前，我需要讲述一下这几天我关于OpenVAS的一个经历

在上一篇文章写完之后我就开始写接下来的文章，不过我发现创建扫描策略的时候无法选择 NVT，选择就会提示未知的错误，此时我开始排查，发现是 OpenVAS Manager的问题，缺少文件，启动不了，导致整个Openvas都没有办法使用

之后我便开始卸载OpenVAS ，准备重新安装

apt purge openvas*

遗憾的是卸载完之后再次安装还是有问题，没有办法，我又重新安装了Kali

这次一下就可以安装成功，虽然偶尔在启动上OpenVAS Manager还是会失败，不过可以使用 service openvas-manager start  来启动，而不会失败


重点来了： 推荐大家在安装前把虚拟机做好快照，做完快照再进行安装，安装失败就再安装一次

 

OpenVAS 结构

在进行配置和扫描之前，我们需要来了解一下OpenVAS的结构信息

上面这个图片就是OpenVAS 的一个组成框架，给大家看这个是想提醒大家如果以后自己写漏洞扫描器时候可以参考这个来写

下面我就简单介绍一下各个角色


OpenVAS Manager

控制scanner和其他manager的中心组件

控制中心数据库，保存用户配置及扫描结果

客户端使用基于XML的无状态OMP协议及其通信

集中排序筛选，使客户端获得一致展现

 

OpenVAS Scanner

具体执行NetworkVulneralility Tests（NVTS）

NVTS每天通过Feed更新

受Manager控制

也是最为重要的一个部分

 

Greenbone Security Assistant（GSA）

提供Webservice，可以通过浏览器访问来进行控制manager

 

OpenVAS CLI

omp命令行工具，可实现批处理控制manager

 

NVT’s

NetworkVulnerability Tests

存放了大量的漏洞测试代码，用来给Scanner调用

 

Results & Configs

作为存储和配置，对于扫描策略，

扫描事项等一系列的配置信息

扫描的结果，漏洞情况等


Web GUI

web接口是我们操作OpenVAS的主要方式，使用我们之前设置的账号密码进行登录就可以

OpenVAS 在不断地更新中，当时我学习的时候主页还不是这样的，下面我们就来使用一下

 

全局配置

首先我们要对于全局进行一个配置

进入MySettings 后是这样的一个界面

此时就需要我们对其中的参数进行自定义的修改了，点击🔧扳手按钮

其中的语言项默认会使用浏览器的语言，也就是系统语言，我安装的英文版的Kali，所以也就不选择中文了

我们只需要把第一张图标注的几处配置一下就可以，因为扫描策略我们还没有制定，制定完之后在来填写这些，填写完之后点击save就可以了

 

扫描配置

可以看到其中已经有了自带的8种配置

如果大家要对一个设备不了解的时候可以采用其中的一些配置（fulland fast 比较推荐）

其中可以看到策略的Family和 NVT 的数量，相比于我之前学习的，两者的数量已经有了很大提升

以上这些也都可以点击下载按钮来下载下来，当然如果有已经配置好的扫描策略，可以点击左上角的箭头来导入进来！（图片上没有截到）

 

不过如果像我们之前那样已经做了相当充分的信息收集，我们就应该目标的操作系统，应用程序等去自定义一个扫描的配置

 

DIY 配置

我们把metasploitable2作为目标进行扫描吧

已知metasploitable2是一个基于Ubutnu的Linux主机，其中开放了很多服务

我们可以基于已经存在的两种策略进行配置，第一个就是完全空的，第二个其中已经包含了很多family和NVT，既然我们要自定义，就选择第一个

点击这个小扳手，我们进行相关配置

映入眼帘的是各种漏洞选择项，其中还有每一种漏洞项包含多少NVT，可以看到每一项都有上百个NVT

大家需要注意的是，openvas更新十分迅速，可能大家在看到这个界面的时候已经更多了，此时我们配置的策略还会不会与时俱进的更新呢？？

这个就是我要说的了！！

大家应该可以看到上图中我圈出来的两个图标，第一个是斜上角号，第二个是向右

每一个漏洞选项都有一个这个选项，如果我们选择的是斜上角的符号，此时配置的选项，在将来导入的时候也会有实时的更新，就像CISCO这一项，现在的NVT个数为 647，可能以后就会变成700个，那么，如果我们选择的是斜上角的这个图标，那么当这一项变成700个的时候，我们导入之前的配置的时候，再进行扫描CISCO配置也会是700 个NVT

 

说明了这个选项后，我们就来针对目标进行一个配置吧

还有很多就不全都截图了

大概选择了两万个NVT

扫描的策略已经完成了，下面我们可以来看一看其他的一些配置，比如扫描调度等

先来看Alerts报警

这个选项主要就是用来设置一下什么时候进行提醒，提醒的内容有哪些，这个选项就不详细的配置了

 

接下来是Schedules

设置扫描调度后，可以自动化地在某一个时间点实行扫描任务

 

ReportFormat

这个选项是报告的格式，openvas支持很多种格式，比如我们喜欢的PDF，不过此时我们还没有进行扫描，一会有结果就会看到了

此时我们就开始扫描吧

按照图中点击Tasks，创建任务

点击这个三角的符号就可以进去扫描状态了

可以看到已经开始了，我们等待就好了（过程很慢）

对于这个报告，我们还可以导出

如果我们要直接给相关的安全人员或者运维人员，我们比较喜欢使用pdf格式，因为这个格式不会因为设备的不同而文字格式发生变化

选择格式后点击绿色下载按钮就开始下载了

上面就是下载下来的报告，可以看到足足35页
