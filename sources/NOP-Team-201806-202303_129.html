背景

背景就是大家的一个共识问题，网上99%的RAT都是带有后门的（此处不包括 Github等）

谁也不想自己的劳动成果被别人夺走，对于已经授权的渗透测试来说甚至就是灾难


技术


（1）编程语言：Python 3

         就一个原因：简单。   但是！！！！ 这里有一个致命的大坑，就是编译出来的文件实在是太大了，大家使用一下就会发现了

         还有一个缺陷就是编译环境必须要自己提前搭建好，有时候这是一个复杂的问题

         经历了重重磨难后我才明白为什么大家都用C/C++来开发各种恶意软件

（2）通信层面： TCP

         很多RAT现在已经开始使用 HTTP(s)，DNS 等来进行控制了，不过我本身就是搞Web的，想尝试一下古老的TCP协议

（3）GUI or Console ： 命令行形式

         我本来是想搞GUI，或者Web UI，不过时间实在是不太够，所以只能委屈大家使用命令行了

（4）与Msf相比有何优势？

         在我看来除了服务端部署简单没有什么优势，现在这个版本还十分初级，连RAT的门槛都没迈进

         这个服务端（控制端） 可以部署在任何主机上 Windows/Linux/Mac OS，这个msf也能做到，不过在vps上部署MSF还是要费很大劲的，我这个就比较简单了。 （如果此处有人说端口转发，我一定要告诉你你没有办法保证你的内网主机时刻开启着）


功能

获取系统信息（系统具体版本）

  1. 反弹shell

  2. 上传文件

  3. 下载文件

  4. 屏幕截图

  5. 执行一定的Python3代码

  6. 键盘记录


功能短板

  1. 没有持久化

  2. 没有检测杀毒软件的功能

  3. 没有提权功能

  4. 只能控制一台主机，没有做Session机制

  5. 。。。


安装方法

要想安装这个RAT，就必须在Windows 上部署以下各项，以下都在Windows10 上测试没有任何问题

   1. Python3
   2. pip
   3. pip install Pillow
   4. pip install pyinstaller
   5. pip install pythoncom
   6. pip install win32api

   7. 安装PyHook3
       这一步说实话需要如果你不按照我说的做可能会有点复杂
        1） 安装swig ，并且配置环境变量 （已经打包）配置环境变量你肯定会吧，我就不介绍了 
        2） 安装 VS 2015 并且配置C++环境
        下载地址： https://www.visualstudio.com/zh-hans/vs/older-downloads/  安装选项见图片
        3） 安装PyHook3
     pip install PyHook3

   8. 修改地址和端口，以及键盘记录地址，打包成二进制文件(如果你想加上图标，自行查询一下)
    pyinstaller -F client.py
