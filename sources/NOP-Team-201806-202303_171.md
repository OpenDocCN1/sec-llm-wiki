**安装中文输入法**

Kali的系统自己是不带中文输入法的，所以需要手动安装，毕竟很多时候我们需要在Kali的系统上查一些资料

作为一个"过来人"（掉坑的人），我来给大家推荐一下吧  

\--- 搜狗输入法时最顺手的，不过不推荐，安装过程网上有（大概就是先下载安装包，之后安装，再添加Ubuntu的源，进行缺少组件的安装），不过会出现一个问题，用一段时间后就会突然不好使了！之后网上就没有任何资料解决了。。。

\--- ibus-pinyin （推荐），这个也是我现在正在用的，是安装比较简单而且使用起来比较好的一款

安装方法

    1.更新  

    apt-get update  

    2.安装  

    apt-get install ibus ibus-pinyin

    3.重启  

    init 6  

    4.添加输入法  

    设置--区域和语言--点击加号--搜索汉语(pinyin)--添加即可  

    5.调用ibus输入法  

    Ctrl + 空格  

    这下应该就可以了吧！

\--- google-pinyin （不推荐）这个安装也比较简单，不过在进行联想的时候，跟中国人的思维很多时候都不一样！

笔记本模式

如果你用笔记本物理机安装的Kali，可以打开笔记本模式，不然电池会消耗很快的！

\---------------------

启动笔记本模式

小脚本：

#!/bin/bash

currentMode=$(cat /proc/sys/vm/laptop\_mode)

if \[ $currentMode -eq 0 \]

then

echo "5" > /proc/sys/vm/laptop\_mode

echo "Laptop Mode Enabled"

else

echo "0" > /proc/sys/vm/laptop\_mode

echo "Laptop Mode Disabled"

fi

将以上的内容保存为一个脚本 1.sh

之后给他权限

chmod a+x 1.sh

./1.sh

**显卡驱动**

总结一句话，不要安装显卡驱动！

如果你是虚拟机，那显卡驱动对你来说没有任何意义

如果你是物理机，显卡驱动会让你的系统直接崩溃
