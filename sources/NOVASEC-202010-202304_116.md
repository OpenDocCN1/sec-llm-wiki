**0x02 原理简介  
**

引用原文的话术，进行翻译了下，看官大概大概看看吧：

安全产品通过在Windows内核（PsSetCreateProcessNotifyRoutineEx）中注册回调来监挺进程创建操作。这个内核回调是在插入初始线程时调用的，而不是在创建进程对象时调用的。

有些产品使用写时扫描方法，其中包括对文件写入的监视。比如记录已写入的文件，推迟实际检查，直到 IRP\_MJ\_CLEANUP 发生（例如，文件句柄关闭）。利用write->map->modify->execute->close的行为将破坏完全依赖IRP\_MJ\_CLEANUP检查的写入扫描。

 

 

像我这种菜鸡看到这里有点懵逼，接着往下看看行为是怎么样的吧。

 

 

绕过流程如下：

1、将目标二进制文件写入磁盘，保持句柄打开

2、将文件映射为image section

3、使用节句柄创建进程对象

4、使用相同的目标文件句柄，隐藏磁盘上的文件

5、在进程中创建初始线程（此时，内核中的进程创建回调将启动。磁盘上的内容与image的内容不匹配。此时检查文件将导致错误的属性）

6、关闭句柄，触发IRP\_MJ\_CLEANUP，此时安全产品开始检查文件（因为我们已经隐藏了正在执行的内容，所以此时的检查将导致错误的属性）

```
git clone https://github.com/jxy-s/herpaderping.gitcd .\herpaderping\git submodule update --init --recursiveMSBuild .\herpaderping.sln
```
