# **2、Cross-Domain Policy File (Flash)**

# 这道题讲的是flash跨域，Domain为\*，表示允许任何第三方域跨域请求。

![](../Images/974cc9104bd86526760f9343de29542f.png)

  

效果如下：

先修改/var/www/evil/xdx.as文件

![](../Images/f481ab8e1d91c1343225fed28c1ded52.png)

编译xdx.as为xdx.swf，然后将xdx.php跟xdx.swf放到/var/www

![](../Images/3beb7ecb78e3436efd8544f141037a75.png)

  

对xdx.php这个进行访问，以POST请求进行访问，然后会自动创建一个xdx.log。

![](../Images/2b67b8d0ac4928283da611f2dddf98f9.png)

  

我们用cat查看会发现，只要输入一次post请求，log那边就会写入一次。

![](../Images/28418fbf10b9504b29b086e3dc2a3b5f.png)

本题我网上找到，其实大概是要去服务器访问日志那边看的，但是我没找到，我就做了一个这个。如果有表哥们找到日志的话，麻烦说一下。

  

另：xdx.as生成swf很坑...

1、需要32位的jre，跟flex-sdk

2、需要在flex-sdk文件里的bin找到jvm\_config将java\_home修改为自己的目录，不然的话会一直报无法找到jvm，记住：要用/，不要用\\。

![](../Images/dc25064ffcb05c25a55f0f23fbc8ec3d.png)

3、在生成swf的时候，也会报错，需要在flex\_sdk\\frameworks里找到flex-config.xml，将<static-link-runtime-shared-libraries>Flase</static-link-runtime-shared-libraries>里的flase改为true即可。

![](../Images/3b53f45946f3253a1938e28fdcc3a5d7.png)

![](../Images/a590960ece52bd72a1baa80a5b4ebb85.png)
