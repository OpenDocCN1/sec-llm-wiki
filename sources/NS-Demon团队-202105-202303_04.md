# **1 漏洞信息**

| 漏洞名称 || 远程代码执行漏洞 |
| --- | --- |
| 漏洞编号 || CVE-2017-9805 |
| --- | --- |
| 危害等级 || 高危 |
| 漏洞类型 || 中间件漏洞 |
| 漏洞厂商 || Apache |
| 漏洞组件 || Struts2 |
| 受影响版本 || 2.1.2 <= Struts2 <= 2.3.33，2.5 <= Struts2 = 2.5.12 |
| 漏洞概述 || REST plugin是其中的一个处理传入URL请求的插件。攻击者可以通过构造恶意XML请求在目标服务器上远程执行任意代码。漏洞的成因是由于使用XStreamHandler反序列化XStream实例的时候没有执行严格的过滤导致远程代码执行。 |
