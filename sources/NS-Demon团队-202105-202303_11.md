# **1 漏洞信息**

| 漏洞名称 || 远程代码执行漏洞 |
| --- | --- |
| 漏洞编号 || CVE-2017-5638 |
| --- | --- |
| 危害等级 || 高危 |
| 漏洞类型 || 中间件漏洞 |
| 漏洞厂商 || Apache |
| 漏洞组件 || Struts2 |
| 受影响版本 || 2.0.0 <= Struts2 <= 2.3.32 |
| 漏洞概述 || 该漏洞是由于上传功能的异常处理函数没有正确处理用户输入的错误信息，导致远程攻击者可通过修改HTTP请求头中的Content-Type值，构造发送恶意的数据包，利用该漏洞进而在受影响服务器上执行任意系统命令。 |
