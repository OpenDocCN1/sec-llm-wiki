# **1 漏洞信息**

| 漏洞名称 || 远程代码执行漏洞 |
| --- | --- |
| 漏洞编号 || CVE-2016-3081 |
| --- | --- |
| 危害等级 || 高危 |
| 漏洞类型 || 中间件漏洞 |
| 漏洞厂商 || Apache |
| 漏洞组件 || Struts2 |
| 受影响版本 || 2.3.20 <= Struts2 <= 2.3.28，其中2.3.20.3和2.3.24.3版本没有漏洞。 |
| 漏洞概述 || S2-032漏洞是一种影响Apache Struts web应用程序框架的远程代码执行（RCE）漏洞。此漏洞允许攻击者通过发送特制的HTTP请求在服务器上执行任意代码。这可能被利用来获得对服务器的未经授权的访问，从而可能导致系统的完全破坏。 |
