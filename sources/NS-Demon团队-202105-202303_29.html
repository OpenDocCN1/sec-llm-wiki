Enum4linux

Enum4linux 是一种工具，旨在从 Windows 和 Linux 操作系统（包括网络上的 SMB 主机）中检测和提取数据或枚举。Enum4linux 可以发现以下内容：

  1. 域和组成员身份

  2. 用户列表

  3. 设备上的共享（驱动器和文件夹）

  4. 目标上的密码策略

  5. 远程目标的操作系统


使用Enum4linux 简单的枚举

获取数据库权限

由于外网无法连接数据库，即使是phpmyadmin也无法进入，所以还需要在内网获取数据库权限。

find 寻找配置文件

寻找config文件，有无记录数据库密码

find / -name "*config*"

发现存在dbconfig文件夹

里面有phpmyadmin.conf文件

查看发现数据库密码

连接数据库

mysql -uroot -p TogieMYSQL12345

开启远程连接

由于数据库不能远程连接，为了方便登录查看数据库数据，可用参考以下几种思路

  1. 开启数据库外联

  2. 上传具有数据库连接功能的webshell，进行查看

  3. 进行流量代理

这里由于是靶场环境，我选择直接开启外连

进入指定的数据库

use mysql

对所有ip都运行访问（将 % 替换为ip地址，即为允许指定ip进行访问）

grant all privileges on *.* to root@'%' identified by 'TogieMYSQL12345';

刷新配置

flush privileges;

成功连接
