# Weblogic管理控制台未授权远程命令执行(CVE-2020-14882、CVE-2020-14883)漏洞复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4ODYyMDMzOA==&mid=2247486991&idx=1&sn=2877bb059e506456daa3f13b6dcadfb7&chksm=cff91a52f88e93444f81ecfb9ffc0a09fdfc95305e8697c8cf21e739a1096bc883a7a508dd22&scene=126&sessionid=1681443973#rd](http://mp.weixin.qq.com/s?__biz=Mzg4ODYyMDMzOA==&mid=2247486991&idx=1&sn=2877bb059e506456daa3f13b6dcadfb7&chksm=cff91a52f88e93444f81ecfb9ffc0a09fdfc95305e8697c8cf21e739a1096bc883a7a508dd22&scene=126&sessionid=1681443973#rd)

  

**概述**

CVE-2020-14882 允许未授权的用户绕过管理控制台的权限验证访问后台，CVE-2020-14883 允许后台任意用户通过 HTTP 协议执行任意命令。使用这两个漏洞组成的利用链，可通过一个 GET 请求在远程 Weblogic 服务器上以未授权的任意用户身份执行命令。

  

  

**受影响版本**

Oracle WeblogicServer 10.3.6.0.0

Oracle WeblogicServer 12.1.3.0.0

Oracle WeblogicServer 12.2.1.3.0

Oracle WeblogicServer 12.2.1.4.0

Oracle WeblogicServer 14.1.1.0.0

**漏洞复现**

访问漏洞URL：http://192.168.1.136:7001/console/login/LoginForm.jsp，发现需要登录。

![](../Images/3aec15edbf662523f68ff32f3c097054.png)

![](../Images/b9e2d472fd3ecfe592709862695a5787.png)
