# Spring Cloud Gateway 远程代码执行漏洞复现（CVE-2022-22947）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4ODYyMDMzOA==&mid=2247484734&idx=2&sn=ff3d3309c3607ab9420ee6bccc824e31&chksm=cff91163f88e987541c0ae83cb0b2a5ffca12b9079048c8014b7f13759b1c98a862cb4327e93&scene=126&sessionid=1681443983#rd](http://mp.weixin.qq.com/s?__biz=Mzg4ODYyMDMzOA==&mid=2247484734&idx=2&sn=ff3d3309c3607ab9420ee6bccc824e31&chksm=cff91163f88e987541c0ae83cb0b2a5ffca12b9079048c8014b7f13759b1c98a862cb4327e93&scene=126&sessionid=1681443983#rd)

0x00 漏洞描述

  

Spring Cloud Gateway 是基于 Spring Framework 和 Spring Boot 构建的 API 网关，它旨在为微服务架构提供一种简单、有效、统一的 API 路由管理方式。

  

Spring Cloud Function SpEL 表达式注入漏洞，发生在 Spring Cloud Gateway 应用程序的 Actuator 端点，远程攻击者在无需认证的情况下，构造特定的数据包，在header中添加"spring.cloud.function.routing-expression"参数并携带 SpEL 表达式，成功利用此漏洞可实现任意代码执行。

  

漏洞编号：CVE-2022-22947

  

0x01 影响版本

  

Spring Cloud Function

3.1.0

3.0.0 至 3.0.6

3.0.0 之前的版本

0x03 漏洞复现

  

抓包，根据提示，访问 /Actuator 端点

![](../Images/23880a5b9fb22b43ea42638bb8023669.png)

查看 /actuator/gateway/routes/

![](../Images/752bcfde3a31fff71bbce794fdcbe55f.png)

返回的路由信息表明，当访问 index 时，路由到 http://example.com:80

  

这时要构造包含恶意的路由，使用POST请求，请求头要有Content-Type: application/json，请求体中的内容是创建名为 test 的路由，让他去执行我们的 whoami 命令。

0x04 防护方案

  

如果不需要Actuator功能，可以通过management.endpoint.gateway.enable：false配置将其禁用；

  

Spring Cloud Function  3.1.x 用户应升级到 3.1.1+；3.0.x用户应升级到3.0.7+。
