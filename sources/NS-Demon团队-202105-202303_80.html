前言


本篇文章意在给一些没有挖 SRC 经验，但是又有想法要打榜的人提供思路，先提供下我最近挖漏洞盒子 SRC 的排名。

〇、搜索语法基础


在正式进行本文章之前，我们需要了解一些常用的百度、必应、谷歌搜索语法的知识点，考虑到有些人无法科学上网，这里以百度搜索语法为例，当然如果条件允许的话强烈推荐使用谷歌搜索语法。

1. 搜索 url 中包含 id 参数的搜索结果：inurl:"?id="

2.查看指定站点的搜索结果：site:taobao.com

3.搜索在网页描述栏关键字中出现指定文字的搜索结果：intext:"伊拉克"

4.搜索在网页标题中出现指定文字的搜索结果：intitle:"政府"

5.查找网页中包含指定文件格式的搜索结果：filetype:pdf

6.查找不要出现某些关键字的搜索结果“-csdn”，或者只发过来只要某些关键字的搜索结果“+csdn”。

在学会了以上的一些基础的搜索语法之后，我们就可以对其进行组合，让搜索结果更加贴近我们的需求。比如我们要搜索指定标题中，不包含指定站点的搜索结果。

intitle:"学校" -site:"baidu.com"

关于搜索语法的说明就到这里就结束了，下面开始正式进入到 SRC 挖掘的部分，需要我们灵活地变化和使用搜索语法，最好还要学会爬虫。

这里奉献一些我经常使用到的标题关键词：

intext:"学"、intext:"院"、intext:"中"、intext:"医"、intext:"电"、intext:"工"、intext:"司"、intext:"中学"、intext:"大学"、intext:"小学"、intext:"园"、intext:"有限"、intext:"家具"、intext:"设备"、intext:"文具"、intext:"药"、intext:"科技"、intext:"智能"、intext:"能源"。

一、挖掘SQL注入


挖掘 SQL 注入站点使用到最多的语法是 inurl:"?id="，我们在这个语法的基础上再添加一些其他的语法就能获取更多的 url。

比如说 inurl:"?uid=" intitle:"中学"

又比如说 inurl:"?uid=" intitle:"电子"

总之，需要我们灵活地去变更搜索语法之间的搭配。当然，如果我们是手工去检查的话十分消耗时间，我们可以根据以上的搜索语法去写爬虫的脚本，来进行批量获取包含 id 的 url。

如果我们细心点击 url 的时候，还会发现有时候的一些搜索结果并不符合我们的搜索语法，比如说我在搜索inurl:"?uid="的时候，他经常会有些不包含参数的 url，因此我们在爬虫时，考虑到效率，还要对这些 url 进行特殊处理，不能与包含参数的 url 存放在一起。


综合上面几点，我们写的 url 爬虫脚本必须要访问 url 之后再获取解密后的 url，并且还要对不包含参数的 url 进行特殊处理。

二、挖掘身份证信息泄露


挖掘身份证信息泄露使用到最多的语法是 filetype:xls，我们在这个语法的基础上再添加一些其他的语法就能获取更多的 url，比如说 filetype:xls intext:"学" 身份证。我挖掘身份证信息泄露漏洞的时候是手工的，因此我这里是采用谷歌语法进行搜索，即使有人工验证也不怕。

挖掘身份证信息泄露的优点是比较无脑的，不需要任何编程技术也可以做到，但缺点是漏洞盒子审核信息泄露的时候太慢了，差不多半个月才会审阅信息泄露漏洞，因此只推荐前期的时候进行挖掘，不推荐在后期进行挖掘，不然很有可能导致信息泄露的分数变为下个月的分数了，对我们打榜十分不利。


三、一些心得


最后总结一下挖 SRC 需要注意的几点：

  1. 注意时间，因为漏洞盒子的审阅速度很慢，靠近月底提交的洞会变成下一个月的分数了，所以建议在上一个月的月底开始提交，持续到本月的月中。

  2. 持续交洞，挖 SRC 就是拼速度的过程，保持交洞频率，保证在开始审阅漏洞后有持续的分数保证在榜上。

  3. 如果是零基础，先从简单的开始挖起，慢慢熟练搜索语法，并自己总结出挖洞技巧，学有所成。
