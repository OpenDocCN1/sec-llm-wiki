0x00 XXE原理

  

XXE 又称为 XML 外部实体注入，当服务端接收和解析了来自客户端的 XML 数据并且没有进行严格的控制，就会造成 XXE 漏洞。XML 是一种类似于 HTML 的可拓展标记语言，可以用来标记数据、定义数据类型。

  

0x01 XXE危害

  

XXE 会造成文件读取、命令执行、内网端口扫描、攻击内网网站等危害。

  

0x02 XXE成因

  

解析 XML 时允许引用外部实体。以 PHP 为例，在 PHP 里面解析 XML 使用到的函数是 libxml ，在其 libxml 小于 2.9.0 的版本中，允许解析 XML 外部实体内容。

0x04 XXE防范 

  

1.过滤掉用户提交的 XML 数据。

2.配置 XML 处理器去使用本地静态的 DTD。

3.针对 PHP，也可以通过将 libxml 版本升级到2.9.0 或者更高的版本。
