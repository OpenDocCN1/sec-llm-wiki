权限不够做弹 powershell 的操作，需要提权，才可以进行域内信息收集

这里采用 ms14-58 提权



接下来进行域内信息收集，ICMP 协议探测

ipconfig /allnet config workstation                      # 当前登录域netsh advfirewall set allprofiles state off # 关闭防火墙net time /domain                       # Ping获取域控IPnltest /dsgetdc:          # 也可以获取域控IPnet view /domainnet view                                 # 域内主机net user /domain                         # 域内用户net group "domain admins" /domain        # 域管理员net group "domain controllers" /domain   # 域控
