**0x02 Log4j介绍**

Log4j是apache的开源日志记录组件，log4j是基于Apache Software License发行的可靠、快速、可扩展的日志框架。log4j具有高可配置性，可以在运行的过程中通过外部文件配置它。log4j能够根据不同的级别优先权来过滤日志，并且提供了一种机制，能够将日志记录直接写到控制台，文件，数据库，UNIX系统日志等。  

17年也曾爆出相关漏洞,CVE-2017-5645:ApacheLog4j反序列化漏洞。

  

**Log4j2RCE远程命令执行漏洞原因：**

Apache Log4j 2是对Log4j的升级，它比其前身Log4j 1提供了重大改进，并提供了Logback中可用的许多改进，被广泛应用于业务系统开发，用以记录程序输入输出日志信息。是目前较为优秀的Java日志框架。由于Apache Log4j2某些功能存在递归解析功能，攻击者可通过构造指定的恶意请求，触发远程代码执行从而获取服务器权限。  

  

**Log4j2RCE 漏洞影响范围：**

受影响应用可能如下：Spring-Boot-strater-log4j2

Apache Struts2

Apache Solr

**0x03 Log4j2远程命令执行漏洞代码分析**

Log4j2远程命令执行漏洞其实是JNDI注入，调用的是名为LDAP的轻量级目录访问协议，全称：LIGHTWEIGHT DIRECTORY ACCESSProtocl，也称之为目录数据库。JNDI被称为命名服务接口。

  

**JNDI注入原理：**

1.  客户端代码使用了lookup，参数可控。
    
2.  有LDAP服务，可指定远程加载地址为任意代码地址。
    
3.  在客户端访问LDAP服务不存在的对象。
    
4.  客户端从指定地址下载恶意代码到本地执行。
