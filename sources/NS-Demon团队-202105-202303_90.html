0x01 前言
肾透工程师70%的事件都是在收集信息。。。我们需要一份完整的信息收集清单

0x02 WEB系统
IP站点
真实IP包含真实地理位置，以及真实的系统服务
方法：站长之家，爱站，多地ping等
域名/子域名
很多时候主站防护做得很好，但其他子域名下的站点就不好说了
方法：oneforall,layder子域名挖掘，各种在线子域名探测
站点目录
后台目录发现，敏感目录泄露
方法：dirsearch，御剑，依托强大的目录字典
CMS识别
快速识别站点CMS指纹，便于我们使用各种通用漏洞，快速拿shell
方法：御剑CMS，TEST404，云悉，whatapp等
WAF识别
进攻方来识别防守方的盾。第一时间识别出盾是什么品牌、什么材质，才能有针对性的用什么样的矛来进攻或者来绕过，做到有的放矢。
方法：WAFW00f,sqlmap,各种报错
旁站C段
旁站：在同一IP上的其他站点
C段：处于同一网络C段的站点
工具：fofa、shodan、nmap  192.168.1.1/24
web中间件
web系统部署需要依赖一定的中间件，tomcat,apache,nginx,确定之后可查询各种解析，任意文件读取等漏洞
工具：fofa、Wappalyer插件，各种报错等
JavaScript
前端JS中常常包含一些未公开的敏感信息接口，业务逻辑，加密算法，Ajax请求
工具：
BurpSuite  Target => Site Map => 找到要提取 script 的地址右键 => Engagement tools => Find scripts
JSFinder

0x02 服务器系统
系统类型版本
linux or window，各版本之后的相对应漏洞
工具：fofa、nmap等各种工具
协议端口
ssh，ftp，mysql等各种服务对应端口，经典永恒之蓝win7 smb服务445端口
工具：nmap
归属厂商
关注厂商发布的最近漏洞，各种漏洞预警
工具：天眼查，爱企查，企查查。

0x03 APP客户端
自动化基本信息
app注册ID，厂商等，需自动化取证工具
工具：雷电手机快取
API接口信息
BurpSuite抓包重放，http history
反编译代码审计
直接反编译代码审计，大佬的操作
