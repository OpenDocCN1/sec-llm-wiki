**踩坑第二点**

如果出现

*   
*   

```
E:Could not get lock /var/lib/apt/lists/lock -open(11:Resource temporarily unavailable)E:Unable to lock directory /var/lib/apt/lists/
```

不用去上网搜，通常一个重启可以停止那些进程，网上通常让你用kill命令进行杀死进程或者用rm命令来解决，但我试过不实用，重启就好。
