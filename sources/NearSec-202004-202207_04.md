# 【安全风险】Windows配置不当可能导致被攻击者恶意关机/重启或用户账户泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5NjQ0NTE4NA==&mid=2247484498&idx=1&sn=c76cf17a7f54f0f90935938ac3dadb82&chksm=fe63d53dc9145c2bc05d2d225e0a307bace20c654e883827b45f67cd555cb52edc493060c688&scene=126&sessionid=1681653762#rd](http://mp.weixin.qq.com/s?__biz=MzU5NjQ0NTE4NA==&mid=2247484498&idx=1&sn=c76cf17a7f54f0f90935938ac3dadb82&chksm=fe63d53dc9145c2bc05d2d225e0a307bace20c654e883827b45f67cd555cb52edc493060c688&scene=126&sessionid=1681653762#rd)

近期团队小伙伴在进行全网RDP回扫时发现几个有意思的现象

建议企业针对自身进行排查  

  

在大于等于Windows Server 2012版本的服务器中，有部分存在配置不当，导致在RDP登录界面出现了关机/重启按钮，可能导致被攻击者恶意关机/重启服务器，对业务造成破坏。

  

如下图：

![](../Images/b8aa0fec0f3a5c23cc90350e681d091a.png)

  

![](../Images/20c479acf0dafdcdc9ba435e7d052ee9.png)

![](../Images/4cf8ed3423c725ccc3d58438c2d9a002.png)

  

![](../Images/4a961141420465045a3ca764c611b042.png)

  

![](../Images/cb01b3dc01987161dea8d5f36ca65630.png)

  

解决方案：打开“本地组策略编辑器”——“计算机配置”——“Windows设置”——“安全设置”——“本地策略”——“安全选项”中找到“关机:允许系统在未登录的情况下关闭”

  

![](../Images/28ccbcff716cea0db78fa81174a4acee.png)

  

  

  

还有部分配置不当，导致在RDP登录界面出现了主机上的所有用户账号，导致攻击者可以定向针对其他用户进行口令爆破或碰撞攻击。

  

如下图：

![](../Images/353d363b215deead3ecfeb3b71977248.png)

  

![](../Images/b9ae563d3e73f95c7ea596baee1ef62b.png)

  

![](../Images/dc0f1e555c3a11ec82e66708069804f8.png)

  

![](../Images/94716103a050c8382c58cd99dd0b12e1.png)

  

![](../Images/b3e326884a3467890e6f10f158ff79ab.png)

  

解决方案：打开“注册表管理器”，在“计算机\\HKEY\_LOCAL\_MACHINE\\SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\Policies\\System”下将“dontdisplaylastusername”修改为“1”  

![](../Images/369b195d741697e5e29af5e08a9844b7.png)
