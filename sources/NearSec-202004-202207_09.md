# Tips：BurpSuite中设置NTLM认证

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5NjQ0NTE4NA==&mid=2247484361&idx=1&sn=8982455ce87e56099d81ce9261708988&chksm=fe63d2a6c9145bb027e6a6b0b21abe2783b151e1f91faf8b2f0d1961242279144fc868a371c3&scene=126&sessionid=1681653762#rd](http://mp.weixin.qq.com/s?__biz=MzU5NjQ0NTE4NA==&mid=2247484361&idx=1&sn=8982455ce87e56099d81ce9261708988&chksm=fe63d2a6c9145bb027e6a6b0b21abe2783b151e1f91faf8b2f0d1961242279144fc868a371c3&scene=126&sessionid=1681653762#rd)

  

客户系统环境比较特殊，需要登录NTLM认证后，才能访问系统，所以在漏洞测试中遇到了以下情况

  

正常访问：网页NTLM认证 >> 访问系统 >> 登录系统 >> 不抓包一切正常

异常访问：网页NTLM认证 >> 访问系统 >> 抓包 >> 提示401访问被拒绝

  

![](../Images/1d3bb713737606158761bf301ba30bc7.png)

  

User options >> Connections >> Platform Authentication >> Add  

  

![](../Images/acdd4678bfdc878f0f997ec5ea12673f.png)

  

添加新的配置，认证方式选择NTLMv2，然后重新发送请求就ok了  

  

![](../Images/a120de8d859868dd7de2592579a673aa.png)
