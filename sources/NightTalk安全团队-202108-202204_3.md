# 0x01 前言

此方法利用创建一个DOCX文档，并使用远程加载DOTM模板文件去执行恶意宏命令。

# 0x02 利用

## 制作恶意远程宏模版

Attacks→Packages→MS Office Macro

![](../Images/867821ff8815696dca789f32f32a27af.png)

复制获取到的VB代码后打开word 勾选开发工具选项

![](../Images/ed40b0aa4f13f6bd7a8e498a59b1ec16.png)

开启开发工具后，将该文档另存为 `dotm` 宏模版文件。打开 开发工具→Visual basic复制恶意代码到`ThisDocument` （这里用的演示代码是弹计算器。）

![](../Images/f2c0833d394e265a8919b4c614eabfaa.png)

测试运行。打开此恶意模版文件，并启用宏。正常运行。

## 制作远程加载恶意宏模版的docx文件

将刚刚制作好的恶意模版文件部署到服务器后，新建word文件随便选择一个模版使用保存文件

![](../Images/a8109d1056639121df68e90ba41b4e05.png)

另存为后，修改为zip后缀，进行解压

  

![](../Images/10f129abb07d864f91a06e6abb1186a9.png)

路径:word/\_rels,找到settings.xml.rels文件，修改Target属性

![](../Images/b761b3ff777c5fb57c970db442a6e7dc.png)

修改好后，把文件用zip重新压缩回去，并重新命名后缀为docx。

![](../Images/37f91e4202c5c717e22ed58af1b68abf.png)

打开此文件即会远程加载部署在服务模板文件，启用宏即可正常运行。

# 0x03 总结

## 步骤

docx远程加载宏的利用步骤简述如下

1.  制作包含宏的恶意模版文件（.dotm）。
    
2.  将恶意模版文件上传至服务器。如Github等公共文件平台。
    
3.  新建并保存一个使用任意模版的docx文件。
    
4.  解压docx文件，修改 `word\_rels\settings.xml.rels`文件的Target属性，将其指向部署恶意模版文件的服务器。
    
5.  使用zip格式压缩文件，并重新命名后缀为docx。
    
6.  重新打开docx文件，并启用宏。
    

docx文件无法执行宏代码，发送docx文件可使对方放松警惕。加上使用公共平台去托管恶意文件减少暴露服务器的机率。
