# 让你强无敌的 JavaScript 逆向高阶课来袭

2020 年初正式推出的 JavaScript 逆向系列课^(\[1\]) 在未做付费广告的情况下赢得了近 800 名工程师的青睐。

![](../Images/94d169f609cda33490ccef0a56a417a0.png "null")

我们也在努力服务大家，在课程正式发售后收集大家的建议和意见，针对不易懂的知识点或者需详细介绍的内容推出了 4 篇补丁文章：

1.逆向过程中遭遇加密算法，我该怎么办？2.学逆向，你应该准备的 JS 语法知识都在这！3.Hook｜你带着老婆出了城，吃着火锅还唱着歌，突然就被麻匪劫了4.手把手教你用 ReRes！

还有 1 次答疑直播。

逆向系列课针对的是初级和刚刚踏入中级门槛的爬虫工程师，对于已经熟练掌握 JavaScript 逆向操作的朋友来说，这就是个开胃菜。大家的期盼非常明了：

•**我要看那种难的，越难越好**•**要贴近工作实战，你们的风险我不管，我就要看真刀真枪的那种案例**•**各大验证码产品中收集的浏览器指纹有哪些？怎么看，怎么伪造？**•**听说现在很多⽹站不⽤常⻅的AES、DES之类的算法进行加密，⽽是用一些魔改过的加密算法，甚至是自研加密算法，这种情况该怎么办？**•**滑块验证码中的滑动并不是难题，但鼠标轨迹怎么搞？怎么样才能得到通过率超过 90% 的轨迹算法？**•**点选、拖动、空间判断等五花八门的验证码破解思路究竟是什么？**•**个个都说控制流平坦化令人头疼，而且还有很多暗坑，我希望能够应付自如**•**听说 AST 语法树是突破控制流平坦化的利器，具体如何操作？**

大家的需求我们已尽数收入囊中，权衡左右后推出了这次的 **JavaScript 逆向高阶课**。

那么问题来了，**这次高阶课到底讲什么呢**？

既然是 JavaScript 逆向的内容，那么肯定是围绕着 JavaScript、围绕着大家关注的技术点或者需求展开。这次课分为 3 个部分：

1.**加密和混淆的绕过实战与分析思路**2.**常见验证码的绕过实战与分析思路**3.**混淆代码的还原实战和暗坑讲解**

大家在课程中将会看到以下这些场景或案例：

![](../Images/c4b7a329b1e4986eaa8d4d6463c8d052.png "null")![](../Images/fe41cce71fedb75a5b426e5c18305dd3.png "null")![](../Images/fda3fddd348bf508802f9a648c3b2ed2.png "null")![](../Images/90a3c609b2cfc2f6befb2762a8d97f69.png "null")

看到这里你可能会有疑问：为什么都是验证码，R 数的加密参数、A 里的加密参数这些不讲吗？

实际上验证码才是集反爬大成于一身的产品，在突破验证码产品的过程中，你就会学到 R 数和 A 里常用到的那些反爬虫手段绕过之法，所以建议你们不要重复问这个问题了。要突破这些验证码，我们需要解决几个问题：

1.**网站那么多，验证产品那么多，如何掌握构建通过率超 90% 的鼠标轨迹生成方法？**2.**如何知道⽬标⽹站的反爬中用了哪些浏览器指纹？**3.**如何伪造看起来很真实的浏览器指纹？**4.**如何调试动态代码？**5.**如何找到加密值对应的计算方法？**6.**如何从高度混淆的代码中捋清逻辑？**

上面这些搞清楚之后，相信你的新问题也随之而来：**说了那么多，课程大纲是怎么样的？**

**本次 JavaScript 逆向高阶课课程大纲如下**：

**一、加密和混淆的绕过实战与分析思路**

1、密码学加密算法

2、加密入口的特征和分析思路

3、加密过程的特征和分析思路

4、几种高级爬虫工程师必须会的 hook 形式

5、特征和分析总结

**二、常见验证码的分析思路与解决方案**

1、不定长的中英数字混合验证码的企业级解决方案

2、滑动拼图验证码的企业级解决方案

3、文字点选验证码的企业级解决方案

4、验证码产品中的轨迹、指纹、混淆等技术总结

**三、混淆代码的还原实战和暗坑讲解**

1、初识抽象语法树（AST）

2、使用抽象语法树（AST）增强代码阅读性

3、使用抽象语法树（AST）破坏逗号表达式的反断点调试

4、使用抽象语法树（AST）突破复杂的控制流平坦化混淆

5、如何调试动态的 JavaScript 代码

6、代码混淆和抽象语法树（AST）总结

**学完课程之后，你大概率会有如下收获：**

•客户端指纹的原理和具体参数以及对应的破解之法•高通过率的鼠标轨迹模拟算法和具体实现•滑动拼图验证码的破解之法•点选验证码的破解之法•类 12306 迷之点击图中指定安全帽验证码的破解之法•控制流平坦化原理和实际应用场景•R 数、A 里级别高复杂度控制流平坦化踩坑实录和拆解之法•自定义加密算法和古典加密算法的解读•保住地中海头发的 JavaScript 代码 Hook 技巧

这个过程中，你能听到文安哲对**浏览器指纹**方面的**思考和研究**，看到对验证码**验证核心**——**用户操作记录**的解读和生成技巧，体验到 R 数、天验验证码和 A 里在用的**控制流平坦化技术的威力**，还有条理清晰地**拿出破解之法时的畅快**！

高阶课里会详细讲解控制流平坦化破解招数。例如编写一个程序，将那些被控制流平坦化“转换”得令人头疼的 JavaScript 代码还原成**相对易读**的样子，然后**顺着代码和思路**突破这些反爬虫措施。这里还会提到如何**避开控制流平坦化中常用的陷阱**，如果不避开这些，你的程序在还原代码时就很可能会出错，甚至卡在一个死循环中无法脱身——正所谓高手过招，拼的就是细节！

加密算法方面主要讲解一些古典密码学的相关内容，**据说很多防御体系中都有它们的踪影**。

JavaScript 中的 Hook 方法在《JavaScript 逆向系列课》中有讲解，但这里的内容会更详细，教你更快、更方便、更**保护头发**的 Hook 技巧。

**掌握高阶课内容之后，市面上的 Web 端反爬虫产品对你来说应该都不是什么大问题了！**
