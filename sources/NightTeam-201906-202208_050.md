# 请为幽默的东鸽打 Call  

很多同学表示 hook 不好理解，因为 hook 直译过来是钩子的意思。钩子和编程并没有什么关联，难免造成理解上的弯路，遂我打算换个方式来描述 hook。

![](../Images/82f0928fcf66ac658b67bd37deb023eb.png "null")

首先从现实生活来讲，hook 就是**拦路打劫**。对于原程序来说：

**你带着老婆**

**出了城**

**吃着火锅还唱着歌**

**突然就被麻匪劫了！**

![](../Images/b9ba1f1ea1911a501818c6b634da2c9c.png "null")

hook 在这里指的就是**麻匪**，换到以前那就是**山贼**。当然，山贼也是有台词的：

**此路是我开 **

**此树是我载 **

**要想从此过 **

**留下买路财**

在计算机角度来说，**hook** 原本是 **Windows** 系统中的一种**机制**。在对特定的系统事件进行 hook 后，一旦发生事件，hook 程序就会在原程序之前捕获到消息，取得**一手消息**。

你想想，县长奉命上任，在上任之前谁也没有见过县长。麻匪盯着县长上任的必经之路，只要县长上任就一定能够比城里的黄老爷先遇到县长。

![](../Images/ad2430e7f9feebac2a3ce903ee5feb88.png "null")

麻匪劫下县长的火车，杀人夺状后自己假扮县长。这样一来，鹅城县长上任一事不受影响，但却在麻匪手里走了一遭。

听起来很像 Python 的装饰器，在原函数的外层加了一个函数，原函数被调用时优先权却在装饰函数手里。

这里我们通过一个流程图来理解 hook 过程中，调用方、原函数与 hook 函数的关系：

![](../Images/fef8afa812443b6cbf507ff132663738.png "null")

调用方和原函数的是直接关联的，调用方调用原函数，原函数启动执行。我们在它们之间加了一个 hook 函数，hook 到传入的参数后为所欲为，但为了保证系统正常运行，我们在得到参数后便返回原函数。这正是张麻子顶替马邦德的过程。

**JavaScript 逆向中，hook 是怎么做的呢？**

我们通过 JSON.stringify 的 hook 来了解具体的操作方式。JSON.stringify 的作用是将一个对象转换为字符串，常用于与服务端交换数据时。假设请求时需要将 `{"name": "sfhfpc", "pwd": "39ik-0ake-2jz3", "client": 1, "_sign": "298zudju27zyeh58zmgj293ozl48zjr829zmg92="}` 这样一个对象发送给服务端，那么很有可能需要在 JavaScript 代码里构造这样一个对象并将其转换为字符串的形式，最后发给服务端。

既然知道有这样的过程，那么我们就编写一个 hook 函数，对 JSON.stringify 进行 hook。也就是比 JSON.stringify 先一步获得消息，然后在为所欲为后将原函数（JSON.stringify）返回。具体的 hook 代码如下：
