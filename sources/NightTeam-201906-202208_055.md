# 这本书适合哪些朋友？

这本书的目标读者分为两个阵营：**爬虫**和**反爬虫**。

爬虫工程师自然不用多说，大家最期待的正是对反爬虫技术的剖析和绕过实战。

反爬虫的设计者和实施者遍布于各个岗位，它可以是**前端工程师**、**后端工程师**、**移动端研发**甚至是**产品经理**。他们能够**从书中了解到爬虫工程师常用的技术手段和思路**，知道**哪些防护措施容易被突破**、**哪些措施的绕过难度会更高**以及**如何限制爬虫**，从而**设计出适合的反爬虫策略**。
