# 人机验证

见名知义，人机验证是用于区分人类与自动化程序的简称。在 21 世纪，人机验证的具体表现形式之一就是验证码。市面上常见的验证码类型有：

1.图片中的字符验证码2.需要人为操作的验证码3.需要主观意识判断的验证码

第 1 种，字符验证码。

  

![](../Images/8396015fb4349339483537cccbe46d4f.png "null")

  

  

![](../Images/52ca5fa1b1148d5380851d5a15c3dfb3.png "null")

  

看起来好像比较容易通过，实际应用中开发者会在此基础上进行扭曲和变种

  

![](../Images/b878e358eba867176d16736eb30c5b84.png "null")

  

为其加上各种各样的干扰信息，直到人也难以分辨。

第 2 种，需要人为操作的验证码，例如点击、拖拽、滑动等，这种验证码简称行为验证码。

  

![](../Images/e211a11800826c03ff7611e7d45665b1.png "null")

  

常见的有滑动验证码和拼图验证码，随着时间的推移和技术的进步

  

![](../Images/397ce1bc1cd7e59918762ae7b968b3b6.png "null")

  

又衍生出了更为扭曲的版本，直到人也难以分辨。

第 3 种，需要主观意识判断的验证码，常见的有点选验证码、按迹拖拽验证码和空间验证码。

  

![](../Images/7f0c8c5e0c7e6d46fdb5af08b1a34e6d.png "null")

  

  

![](../Images/41dbecbda79bc561cad29c7bf43d0b7f.png "null")

  

  

![](../Images/3b8a17a925e9581359c161160c1ee308.png "null")

  

通过验证的前提是具有较高的分辨能力，目前它还没有发生过大型扭曲

  

![](../Images/95e5584c767d5b826695dbc80dbd18c3.png "null")

  

人类比较容易分辨但程序实现变得更难。

  

![](../Images/a5a06fce0eeb2032112d5da775609a3b.png "null")

  

以目前网上的资料和技术普及程度来说，第 1 种验证码的难度相对较低，稍微花一些时间翻阅资料就能够编写出对应的深度学习代码。

第 2 种和第 3 种难度逐渐上升，这里考验的除了分辨能力之外还有操作轨迹和风控，也就是在进行验证过程中鼠标的移动轨迹和客户端指纹等信息。

  

![](../Images/1c73fe8c6d3b3829f07631d9b40f7ac2.png "null")

运营小弟韦世东对鼠标轨迹有过一定的研究，对目前网络上已有的轨迹分析和模拟文章做了一些实验，但在真正使用时也难以达到合格的通过率。

> 数据：合格的通过率理应为 80%，韦世东实验数据中最好的为 60%，实验对象为国内电商巨头的登陆页滑动拼图验证码。

![](../Images/4eb52d3c69504359cce54245267b5bd1.png "null")

# 骚操作

骚操作英文直译 SaOperation，这里形容的是开发者将原本的康庄大道改为布满陷阱的荆棘小道的行为。

  

![](../Images/fb02f9e935ff7163fedc904b9a53f65a.png "null")

  

具体表现形式为：

•经过高度混淆的 JavaScript 代码•经过高度混淆且动态变化的 JavaScript 代码•融合了知名或自定义加密算法的高度混淆且自动化变化的 JavaScript 代码

团队队员深入讨论之后，决定由国内**某知名企业**的一线爬虫工程师**文安哲 sml2h3** 主导课程设计和内容制作，在 《JavaScript 逆向系列课》的基础上延伸出一套内容较深的 JavaScript 逆向课，这里我们称之为《JavaScript 逆向高阶课》

**团队推出这套高阶课的目的，是希望加速爬虫领域的技术发展，让整体的瓶颈突破时间变得更短。**

> 运营小弟韦世东补充：当然，还要赚钱。

课程将**围绕着人机验证和骚操作展开**，**课程总纲**如下：

•客户端指纹的原理和具体参数以及对应的破解之法•高通过率的鼠标轨迹模拟算法和具体实现•滑动拼图验证码的破解之法•点选验证码的破解之法•拖拽验证码的破解之法•类 12306 迷之点击图中指定安全帽验证码的破解之法•图片旋转验证码的破解之法•空间验证码的破解之法•控制流平坦化原理和实际应用场景•控制流平坦化踩坑实录和拆解之法•自定义加密算法和古典加密算法的解读•保住地中海头发的 JavaScript 代码 Hook 技巧

> 提示：课程总纲非课程最终目录，有可能会变动。

这个过程中，你能听到文安哲对**浏览器指纹**方面的**思考和研究**，看到对验证码**验证核心**——**用户操作记录**的解读和生成技巧，体验到 R 数、天验验证码和 A 里在用的**控制流平坦化技术的威力**，还有条理清晰地**拿出破解之法时的畅快**！！！

  

![](../Images/97fef91c6c2b37f25e51676424e657f4.png "null")

  

  

![](../Images/f3677370fda42f7acd2d27a6e71ae703.png "null")

  

高阶课里会详细讲解控制流平坦化破解招数。例如编写一个程序，将那些被控制流平坦化“转换”得令人头疼的 JavaScript 代码还原成**相对易读**的样子，然后**顺着代码和思路**突破这些反爬虫措施。这里还会提到如何避开控制流平坦化中常用的陷阱，如果不避开这些，你的程序在还原代码时就很可能会出错，甚至卡在一个死循环中无法脱身——正所谓高手过招，拼的就是细节！

加密算法方面主要讲解一些古典密码学的相关内容，**据说很多防御体系中都有它们的踪影**。

JavaScript 中的 Hook 方法在《JavaScript 逆向系列课》中有讲解，但这里的内容会更详细，教你更快、更方便、更**保护头发**的 Hook 技巧。

**掌握高阶课内容之后，市面上的 Web 端反爬虫产品对你来说应该都不是什么大问题了！**
