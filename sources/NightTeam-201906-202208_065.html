夜幕团队成立的那个夜晚，团队就商量好了：「半年内不再增加人手」。我们的想法是合力推动爬虫领域的进步和发展，增加人手是一件磨人的事，于是便将精力放在了内容输出上。

我们计划出几套免费的系列教程，这些教程都跟爬虫息息相关。这么做一方面是想要扩大团队影响力，另一方面是想传播比较成体系的技术知识。

团队成立前韦世东和路飞学城有接触，聊过 JavaScript 逆向系列课的事，但书稿琐事繁多，就暂且停下来了。国庆收假后团队考虑自己录制视频，也就是上周推出的《JavaScript 逆向系列课》。

这个课很火，我们还没花过一毛钱推广费，短短几天内就已经有 400 人缴费了。

开源此 SDK 的人叫 sml2h3，外号哲哥，是一位爬虫/逆向工程师，目前在企查查工作。平时他空闲时间比较多，所以经常在群里解答一些 JS 逆向相关的问题。偶尔，他也会做一些逆向 JS 的视频直播，破解一些常见的、恶心的反爬虫措施，并且科普一些网上极难找到的技巧。

由于某数的反爬非常烦人、更新很频繁，他「无奈」之下，弄了一个自动化破解的工具（不开源），从此以后某数的反爬对他仿若无物，反爬技术更新对他来说一点感觉都没有，可以说是非常牛逼了。
