SVG 是 WEB 开发中广泛应用的一种内容呈现载体

「矢量」的特点使得它越来越受到前端开发者的欢迎。

你可能会想

1、我是一名前端，这跟我有什么关系？

  

2、我是一名爬虫工程师，我为什么要看 SVG 的知识？

3、我是一名后端开发者，学习 SVG 对我有什么帮助？

4、我是个信息安全工程师，SVG 能为我带来什么？

5、UI 设计和产品经理 ……

![](../Images/44d59f6e6be5ba22eb28a0a528e38395.png)

  

没错，从上面的疑问来看，SVG 顶多跟前端开发者有关，至于爬虫工程师、后端开发者、信息安全工程师好像并不会跟它打交道。  

  

互联网中的每个岗位都是互相关联的。前端是「门面」，他们用了 SVG，其他部门就有可能要了解 SVG。聪明的开发者会将手中物体的每一个特性发挥到需要它的地方。

  

举个例子

  

![](../Images/9f44c7c0d69386b6212a0d6ced4c5a2f.png)

夜幕运营团队发现近期访问异常，突发很多有规律的流量。这些流量并没有为平台带来利益，看起来就像羊毛党，运营小韦将这个问题反馈给运维和后端小唐，小唐排查后发现这就是近期服务端压力大增的原因，猜测应该是爬虫程序造成的。

![](../Images/9f44c7c0d69386b6212a0d6ced4c5a2f.png)

这个问题现在转交到信息安全工程师小周手上，经过技术手段排查，确定是高频的爬虫程序，但对方使用了段广泛的 IP 代理，无法采用封 IP 的反爬虫方法。

![](../Images/9f44c7c0d69386b6212a0d6ced4c5a2f.png)

邻座的人工智能工程师小崔凑过来说：要不这样吧，爬虫不是爬取我们平台的文字内容嘛，这边可以使用一些手段让他拿不到完整数据，这样对方就不会再爬了。

![](../Images/9f44c7c0d69386b6212a0d6ced4c5a2f.png)

这个想法也得到了爬虫组小陈、小戴和小蔡的赞许，但究竟用什么方法呢？前端小张说，不如用 SVG 映射吧！利用 SVG 坐标和矢量的特性，将 SVG 中描述的文字与页面进行映射，这样对方爬到的数据就会不完整，前端方面执行起来也比较简单。

![](../Images/2e3a37a3072e86acd08e7527ce5e50f2.png)

![](../Images/df593e2262b5b6990886c5a018b706c8.png)

大家商量过后，便把这个想法告诉了产品经理小冯，于是便设计了一套 SVG 反爬虫方案。  

  

![](../Images/860944999158b6dee2da334f6da88773.png)

![](../Images/4c535d02985ce1f7837728a5860fd694.png)

现在你知道 SVG 对不同岗位的影响了吗？

  

  

还有，小冯这帮人设计的 SVG 反爬虫很有效，对方现在放弃爬取了。
