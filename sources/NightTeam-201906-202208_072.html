背景

你是否因为深度学习这几个字就有点望而却步了？

你是否因为听闻需要高深的数学知识就马上想逃离了？

你是否因为艳羡别人娴熟的使用深度学习框架而黯然叹气呢？

以上的广告词是不是特别熟悉，这次咱们不用998的价格，只要有一台电脑，就可以跟着本次教程，轻松实现一个可以用来做图片分类的深度学习分类模型！操作时只需要简单地在网页上点几下就行了！

准备

相信听说过深度学习的你应该知道，深度学习是有个叫“模型”的东西的，这个模型相当于一个小宝宝，需要经过不断地教育、学习之后才会识字，而这个教育、学习的步骤，在深度学习领域里叫做“训练”。

但与现实中的爸爸教儿子不同的是，模型的训练速度取决于处理器，处理器的处理速度越高，训练的速度就越快。

这个处理器，我们生活中最常见的就是 CPU 和 GPU 了，那么它们两个里谁用来训练模型更快呢？

如果你觉得是 CPU 更快的话，那就大错特错了。

如果把 CPU 比喻成房间，那么坐在这个房间里办公的人就都是 985/211 毕业、拥有各种牛逼光环的大佬。大佬们虽然计算速度很快，但毕竟人少，而训练模型这个事情对他们而言又太简单了，所以让他们来干这个活其实并不合适！

那么 GPU 是什么样的呢？同样把 GPU 比喻成房间的话，那么坐在这个房间里办公的人就都是刚毕业的实习生，由于招实习生实在是太便宜了，所以老板就招了几千个实习生来干活。虽然实习生们的计算速度不像大佬们那么快，但是训练个模型还是绰绰有余的，所以让他们来干这个活，效率就比 CPU 高到不知道哪里去了。

所以，如果你有一个强力的显卡（GPU），请做好以下准备：

•Linux 系统•你的显卡•nvidia-docker•Docker 镜像：nvidia/digits:latest

着重说明一下，nvidia-docker 是为了虚拟化显存所使用的一种 Docker 技术，但很遗憾，它暂时不支持 Windows 和 MacOS 系统，所以我们需要一个安装了 Linux 系统的电脑。

nvidia-docker 的安装方式可以看一下它的 GitHub 仓库：https://github.com/NVIDIA/nvidia-docker。

如果你没有强力的显卡（GPU），但你有一个人多（核心数多）的 CPU，那你可以做好这些准备：

•Docker 镜像：rquintino/digits-cpu:latest

除了上面这些以外，不管你是哪一种情况，你都需要准备这些：

•Docker•docker-compose•要用来分类的图片

关于 Docker 的安装方法，这里就不加以详细说明了，不会的同学可以看看 Docker 的官方文档。

开搞

拉取镜像

在完成了 Docker 的安装之后，我们需要使用命令拉取我们今天的主角 Digits。

如果你选择了 GPU 路线，可以使用 docker pull nvidia/digits:latest 命令进行拉取；

如果你选择的是 CPU 路线，那么就用 docker pull rquintino/digits-cpu:latest拉取吧。

执行命令后你应该会看到类似下面这样的输出：

编写 docker-compose 文件

准备好一个合适的存放目录后，我们创建一个名为 docker-compose.yml 的文件，然后在里面写上以下内容：

version: '2.3'services:  train:    image: nvidia/digits:latest    runtime: nvidia    ports:      - "5000:5000"      - "6006:6006"    volumes:      - ./imgs:/work/images

注意了，上面这段内容中有个 image: nvidia/digits:latest 的部分，如果你选择的是 CPU 路线，这个地方你需要改成 image: rquintino/digits-cpu:latest；如果你选择的是 GPU 路线，那么直接这样用就行了。

前置工作

在 docker-compose.yml 所在目录，执行 docker-compose up -d 命令，这样 Digits 的 Web 服务就跑起来了，使用浏览器打开 http://127.0.0.1:5000，就可以看到下面这样的界面：

这就是 Digits 的主界面了，页面非常清爽，只有三个tab页菜单：

•Datasets —— 我们的数据集，就是我们预先准备的数据集，比如图片类的数据•Models —— 模型列表•Pretrained Models —— 之前训练过的模型

初始配置

填写数据集名字，由于本文用来演示的是一个用来识别给定的图片里是猫还是狗的分类模型，所以我们的数据集名字就起个 dog_vs_cat 吧~
