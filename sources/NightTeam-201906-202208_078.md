## 背景

你是否因为**深度学习**这几个字就有点望而却步了？

你是否因为听闻**需要高深的数学知识**就马上想逃离了？

你是否因为艳羡别人**娴熟的使用深度学习框架**而黯然叹气呢？

以上的广告词是不是特别熟悉，这次咱们不用998的价格，只要有一台电脑，就可以跟着本次教程，轻松实现一个可以用来做**图片分类**的深度学习分类模型！操作时只需要简单地在网页上点几下就行了！

## 准备

相信听说过深度学习的你应该知道，深度学习是有个叫“模型”的东西的，这个模型相当于一个小宝宝，需要经过不断地教育、学习之后才会识字，而这个教育、学习的步骤，在深度学习领域里叫做“训练”。

![](../Images/ce728c6e12eed5c5a63153b7c3479eb0.png)

但与现实中的爸爸教儿子不同的是，模型的训练速度取决于处理器，处理器的处理速度越高，训练的速度就越快。

这个处理器，我们生活中最常见的就是 CPU 和 GPU 了，那么它们两个里谁用来训练模型更快呢？

如果你觉得是 CPU 更快的话，那就大错特错了。

如果把 CPU 比喻成房间，那么坐在这个房间里办公的人就都是 985/211 毕业、拥有各种牛逼光环的大佬。大佬们虽然计算速度很快，但毕竟人少，而训练模型这个事情对他们而言又太简单了，所以让他们来干这个活其实并不合适！

那么 GPU 是什么样的呢？同样把 GPU 比喻成房间的话，那么坐在这个房间里办公的人就都是刚毕业的实习生，由于招实习生实在是太便宜了，所以老板就招了几千个实习生来干活。虽然实习生们的计算速度不像大佬们那么快，但是训练个模型还是绰绰有余的，所以让他们来干这个活，效率就比 CPU 高到不知道哪里去了。

* * *

所以，如果你有一个强力的显卡（GPU），请做好以下准备：

•Linux 系统•你的显卡•nvidia-docker•Docker 镜像：`nvidia/digits:latest`

> 着重说明一下，nvidia-docker 是为了虚拟化显存所使用的一种 Docker 技术，但很遗憾，它暂时不支持 Windows 和 MacOS 系统，所以我们需要一个安装了 Linux 系统的电脑。
> 
> nvidia-docker 的安装方式可以看一下它的 GitHub 仓库：https://github.com/NVIDIA/nvidia-docker。

如果你没有强力的显卡（GPU），但你有一个人多（核心数多）的 CPU，那你可以做好这些准备：

•Docker 镜像：`rquintino/digits-cpu:latest`

除了上面这些以外，不管你是哪一种情况，你都需要准备这些：

•Docker•docker-compose•要用来分类的图片

> 关于 Docker 的安装方法，这里就不加以详细说明了，不会的同学可以看看 Docker 的官方文档。

## 开搞

在完成了 Docker 的安装之后，我们需要使用命令拉取我们今天的主角 Digits。

如果你选择了 GPU 路线，可以使用 `docker pull nvidia/digits:latest` 命令进行拉取；

如果你选择的是 CPU 路线，那么就用 `docker pull rquintino/digits-cpu:latest`拉取吧。

### 编写 docker-compose 文件

准备好一个合适的存放目录后，我们创建一个名为 `docker-compose.yml` 的文件，然后在里面写上以下内容：

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
version: '2.3'services:  train:    image: nvidia/digits:latest    runtime: nvidia    ports:      - "5000:5000"      - "6006:6006"    volumes:      - ./imgs:/work/images
```

注意了，上面这段内容中有个 `image: nvidia/digits:latest` 的部分，如果你选择的是 CPU 路线，这个地方你需要改成 `image: rquintino/digits-cpu:latest`；如果你选择的是 GPU 路线，那么直接这样用就行了。

### 前置工作

在 `docker-compose.yml` 所在目录，执行 `docker-compose up -d` 命令，这样 Digits 的 Web 服务就跑起来了，使用浏览器打开 `http://127.0.0.1:5000`，就可以看到下面这样的界面：

![](../Images/e049230e6e9f47c68c2320a9ba025c21.png "null")

这就是 Digits 的主界面了，页面非常清爽，只有三个tab页菜单：

•Datasets —— 我们的数据集，就是我们预先准备的数据集，比如图片类的数据•Models —— 模型列表•Pretrained Models —— 之前训练过的模型

### 初始配置

点击 `Datasets` ，如图所示：

![](../Images/9df8e71122dc9dfd63208a15744906fc.png "null")

填写数据集名字，由于本文用来演示的是一个用来识别给定的图片里是猫还是狗的分类模型，所以我们的数据集名字就起个 `dog_vs_cat` 吧~

![](../Images/732c96cc1a4f8e885f3427fcc06260a7.png "null")

按下 `Submit` 按钮后，就会进入到数据集配置界面了。

![](../Images/e88ca820be2c2d9ae21925666342c4fa.png "null")

需要注意的是 `Training Images` 这个设置，记住，我们是在 Docker 环境下，所以我们要填写的就是在`docker-compose.yml` 里写的那个被映射进容器的 `/work/images` 目录。

### 准备数据

现在，我们就来准备一下用来训练模型的图片吧。

![](../Images/f3a12a1ee0143d50e1bc844de3a2bd76.png)

打开搜索引擎，使用如图所示的插件，就可以迅速下载图片。

由于我们现在做的是一个识别图片里是猫还是狗的分类模型，所以我们搜索 `cats` 和 `dogs` 这两个关键词就好了，可以看到，搜到了非常多的同类型图片。

注意：图片下载完后要放到 `imgs` 目录下，并且区分放置，`imgs` 目录会在 `docker-compose.yml` 所在的目录下自动生成。

> 如果你想让模型帮你分出其他的图片，只需要把猫和狗的图片换成你想要的其他类型的图片就可以了。

* * *

完成下载之后的目录差不多长这样：

*   
*   
*   
*   
*   

```
digits/├── docker-compose.yml└── imgs    ├── cats    └── dogs
```

记住，`cats` 目录和 `dogs` 目录里的图片数量要大致相等，因为我们并不希望我们的模型看太多某一个类型的图片，那样会起到反效果。

搞定图片之后，我们回到 Web 界面继续操作吧。

![](../Images/ac50790a4dcf383a8273284dd5de07d2.png "null")

按照前面说的，填好 `Training Images` 这个图片配置路径、数据集名，然后点击 `Create` 按钮，图片数据集就创建成功了。

![](../Images/c86cc1926177d60c133f474f72cb7e29.png "null")

然后我们返回主界面，选择 `Models`，创建一个新的分类模型（`Classification`）。

![](../Images/73f2e92e9ba06b396e98d6a8d0f8eece.png "null")

### 配置模型

点击创建模型之后，我们会进入到模型配置界面，这里默认会选中我们刚刚准备好的数据集：`testset`。

![](../Images/05bc252d6c34049bb3b3b3033dc35b45.png "null")

简单配置一下：

1.选择 `Standard Networks`2.选择 `Caffe`（CPU 版本可能默认就会选中 Caffe 的深度学习框架）3.选择 `GoogLeNet` 网络结构（因为理论上越新的网络，分类的效果越好，在这三个选项里 `GoogLeNet` 是最新的）4.填写模型名字：`catvsdog`

![](../Images/bb5322d2d209bc67c4b3a66499787928.png "null")

配置好了之后点击 `Create` 按钮，就可以开始训练了。

### 正式训练

训练正在进行时，页面上会出现迭代的效果：

![](../Images/e7e96d2c1334a867535a62b3e0347f4c.png "null")

这里会显示出当前整体的实时状态，我们需要注意的是 Loss、Accuracy 等关键数值。

> 页面右上角可以看到一个进度条，那是模型迭代的进度，等到它达到 100% 的时候就是完成了我们设置的 30 次迭代。
> 
> 由于我是用自己的 Mac 来进行操作的，所以只能演示 CPU 路线的版本，预计这个训练至少要持续好几个小时，但选择 GPU 路线的同学们可能 20 分钟左右（可能更快）可以完成了。

### 使用模型

![](../Images/1eb67ca172d523b1b827310ba0c99bc3.png "null")

训练好模型后我们就可以试试效果了，选择最新的模型版本（`Select Model` 处，数字越大越新），然后上传一张图片进行测试。

![](../Images/2d0f9ada112f178b6693540252bdedff.png "null")这里我上传了一张 GitHub 的 Logo，看起来效果还是挺不错的，才训练了 3 次迭代，这个模型就可以大致区分出图片里的是猫还是狗了，是不是很厉害？

> 在通常情况下，随着训练的迭代次数增长，识别的准确率会越来越高。

## 总结

本次主要从 Nvidia 的 Digits 框架入手，用可视化的方式来实践机器视觉中的分类模型，只用点几下就可以轻松地实现一个深度学习算法。

但仅仅是这样而已的话，是不能做到更多更厉害的操作的，所以建议有兴趣的同学还是要进一步地探究和学习底层的部分，切莫只做调包侠、调参侠。
