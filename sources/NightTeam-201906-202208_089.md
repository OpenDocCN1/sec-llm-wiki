# 商业级4G代理服务器搭建指南【导语】

在从传统方式获取到的IP已经大面积进风控名单的当下，**一些较为严格的网站、APP已经无法使用普通的代理IP来进行灰黑产操作或采集数据了**，在“搞”它们时，高质量的IP是必不可少的。  

但目前代理IP商们常用的获取IP的方式，基本就是下面这几种（都是传统方式）：

1.  机房+专线
    
    由于专线的IP通常已经能被识别出属于机房使用了，在风控系统中通常都是属于被降权、屏蔽、监控的对象，IP质量有高有低，但大部分都算低质量的IP。
    
2.  机房＋PY交易
    
    PY交易可以使代理IP商获得N个民用宽带套餐，或是直接在单个套餐上允许拨号N次，通过多拨的方式获取到N个IP。
    
    这种IP的话，质量就比较高了，因为通常是和正常用户的IP混在一起的，所以很难被区分。
    
    但由于成本问题，代理IP商通常不会在靠近市中心的地区这么弄，如果你有仔细观察的话，其实会发现他们的得到的IP要么是在郊区、要么就是一个运营商专门给划分的IP段。
    
    所以，这种IP在经过一段时间的使用后其实还是会有问题（也就是开头所说的情况），只不过做风控的也不敢直接把这些IP都给封了，不是明显属于纯代理IP用途的那些IP最多就只是给个降权，该出验证码就出验证码这样子。
    
3.  云服务器＋多弹性公网IP
    
    这种IP和第一种一样，能被识别出是属于机房使用的，小的厂商还好点，大的那些（阿里云、腾讯云之类的）厂商基本都是拿IP一查就能看到是属于哪个厂商使用的了，IP质量极低，碰到风控基本就GG。
    
4.  全网扫描
    
    使用NMAP之类的扫描器，扫遍全网的常见代理服务器端口，以获得一些在搭建时忘记修改端口或设置密码的代理服务器。
    
    这种IP就看运气了，虽然有些会是民用宽带的IP，但在国内的这个网络环境下，大部分IP都是服务器的，各种云厂商的居多，毕竟…小白多嘛。
    
    而且因为扫代理的人实在太多了，基本上只要有一个新的冒出来就会被用到烂（指原本还只是被降权的被用到封IP），如果买的这种代理IP，基本上大厂的网站、APP你是别想搞了，IP质量极低，而且极其不稳定。
    
5.  爬免费代理IP网站上的代理IP
    
    这种实际上跟上一种是一模一样的，只不过素质上来讲更差一些，干的就是个倒卖的活。
    

那么，从上面可以看出， 除了第二种以外，其他的方式获取到的IP基本都不靠谱，但第二种由于使用量大、使用时间较长等问题，实际上已经能被识别出来大部分了，在风控系统中的真实用户概率是肯定没有正常IP高的。

那么，要怎么样才能得到更高质量的IP呢？很简单，虽然有线的IP已经被开发得差不多了，但是蜂窝网络的还没有呀！

国内目前在使用蜂窝网络做代理IP拿出来卖的屈指可数（目前只知道一个多贝云），虽然在之前的《5G的到来会对垂直爬虫产生怎样的影响？》中我有提到过，目前是有做灰、黑产的人用蜂窝网络的IP来干了点什么事情的，但毕竟用的人依然不算多，还是有很大的开发空间的。

但是直接买多贝云的4G代理的话，虽然人家IP量大、地区丰富，还不需要你来维护，但是毕竟使用成本还是挺高的。对于需求量小的朋友来说太贵了、不太合适，所以了解一下如何自己搭建还是很有必要的。
