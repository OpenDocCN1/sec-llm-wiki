Q:何谓“空指针“：  

  

空指针是计算机中常见的术语（对于空指针值，一般的文档中倾向于用 NULL 表示，而没有直接说成 0。但是我们应该清楚：对于指针类型来说，返回 NULL 和 返回 0 是完全等价的，因为 NULL 和 0 都表示 “null pointer”（空指针）。一句话， 空指针是什么，就是一个被赋值为0的指针，在没有被具体初始化之前，其值为0）。因为挑战赛一开始也相当于初始化，从0开始，即名为“空指针”。
