# CirculateBUSD 项目Rugpull 损失227万美元事件分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MDcxNTc2NA==&mid=2247484561&idx=1&sn=b41a1f3d02094beec3c305ee9e83fee1&chksm=cf71b60af8063f1c593951bac625d60f333cb684862a476803b522296415fac0d5845be2b617&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg4MDcxNTc2NA==&mid=2247484561&idx=1&sn=b41a1f3d02094beec3c305ee9e83fee1&chksm=cf71b60af8063f1c593951bac625d60f333cb684862a476803b522296415fac0d5845be2b617&scene=27#wechat_redirect)

根据NUMEN链上监控显示，新加坡时间2023年1月12日下午 14:22:39 ，CirculateBUSD项目跑路，损失金额227万美金。该项目资金转移主要是管理员调用CirculateBUSD.startTrading，并且在startTrading里面的主要判断参数是由管理员设置的未开源合约SwapHelper.TradingInfo返回的数值，之后调用SwapHelper.swaptoToken转走资金。

![](../Images/06e8e3d00d51f11c6df4ca2f77b9e118.png)

**事件分析**

首先调用了合约的startTrading（https://bscscan.com/address/0x9639d76092b2ae074a7e2d13ac030b4b6a0313ff），在函数内部调用了SwapHelper合约的TradingInfo函数，详细代码如下。

![](../Images/361f08e370a4654693b36d44e230238d.png)

![](../Images/48d5eaa0d4a453ddc824e6878259b1c1.png)

上图是tx的调用栈，结合代码可知TradingInfo里面只是一些静态调用，关键问题不在这个函数。继续往下分析，发现调用栈中的approve操作和safeapprove对应上。接着又调用了SwapHelper的swaptoToken函数，结合调用栈发现这是个关键函数，转账交易在这个call里面执行的。通过链上信息发现SwapHelper合约并不开源，具体地址如下：

https://bscscan.com/address/0x112f8834cd3db8d2dded90be6ba924a88f56eb4b#code‍

 尝试逆向分析一下。首先定位函数签名0x63437561。

![](../Images/eb9d7e1188e6d7aca4ffaa9af7399227.png)

定位到这个反编译之后的函数，因为看到调用栈触发了转账，所以尝试寻找transfer等关键字。

![](../Images/00a1c4c138c1647716107de8e6980587.png)

于是定位到函数的这一分支，首先stor\_6\_0\_19，先把这部分读出来。

![](../Images/b4870d7ce06266cca77392676b5b5dd6.png)

此时获得了转账to地址，0x0000000000000000000000005695ef5f2e997b2e142b38837132a6c3ddc463b7，发现该地址和调用栈的转账to地址一致。

![](../Images/da66d97a460b1d773fc9e48d71ed0ef2.png)

仔细分析这个函数的if和else分支，发现如果走if是正常兑换。因为通过插槽得到stor5是0x00000000000000000000000010ed43c718714eb63d5aa57b78b54704e256024e，这个合约是pancakerouter。后门函数在else分支，只要传入的参数和stor7插槽存放的值相等即可触发。

![](../Images/517622c6776ce58f4469d591800fc193.png)

这个函数就是修改插槽7位置的值，而且调用权限只有合约的owner可以。

![](../Images/002cdd9f5b4bce0645b40f84694fc39e.png)

以上所有分析足以判断这是一个项目方跑路事件。

**总结**

NUMEN实验室提醒用户投资的时候需要对项目方的合约进行安全审计，未验证的合约中可能存在项目方权限过大或者直接影响用户资产安全的功能。这个项目存在的问题只是整个区块链生态的冰山一角，用户投资和项目方开发项目时一定对代码进行安全审计，NUMEN专注于为web3生态安全保驾护航。
