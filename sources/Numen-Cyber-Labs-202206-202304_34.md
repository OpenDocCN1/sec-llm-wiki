# 亚洲数字银行与BitDATA Exchange，Numen 及Huawei Cloud，共拓Web3.0 时代数字资产生态新发展

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MDcxNTc2NA==&mid=2247484484&idx=1&sn=95bf69f447e4c05fb1cfdd73e1c7d3f5&chksm=cf71b6dff8063fc9f109128f521536a95ebac9387add48115342688a62dd3f4a9f374d7b4a3a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg4MDcxNTc2NA==&mid=2247484484&idx=1&sn=95bf69f447e4c05fb1cfdd73e1c7d3f5&chksm=cf71b6dff8063fc9f109128f521536a95ebac9387add48115342688a62dd3f4a9f374d7b4a3a&scene=27#wechat_redirect)

(吉隆坡8 日讯）亚洲数字银行有限公司（持牌纳闽投资银行，注册号：LL16434）(AsiaDB)与BitDATA Exchange，Numen Cyber 及 Huawei Cloud 共同签署了一项合作备忘录（MOU），四方将基于Web3.0 时代大背景下为数字资产领域的新发展共推新方案、共拓新模式、共建新生态。  

在此合作备忘录下， BitDATA Exchange、Numen Cyber、AsiaDB Bank 将为 Huawei Cloud提供 Web3 专业知识，以开发未来的商业机会；而Huawei Cloud 作为技术伙伴，将为项目规划和推行提供技术解决方案。此外，BitDATA Exchange 将在遵守新加坡金融管理局法规的大前提下，提供法币到加密货币的转换，以促进 Web2 顺利桥接到 Web3，并作为 AsiaDB 的流通量供应商，而 Numen Cyber 专注于 Web3 安全解决方案。

此合作备忘录签署仪式是于吉隆坡的华为云客户解决方案创新中心（CSIC）举行，由亚洲数字银行董事局主席刘绪铭先生，BitDATA Exchange 首席执行官及创始人王凯先生，Numen Cyber Tech首席技术官及创始人Chris Zheng，及马来西亚华为云与AI业务部副总裁林志雄先生共同签署完成。

在谈到此次合作时，刘绪铭表示：“以万物互联+客户为中心“为核心概念的Web3.0 时代的到来，为金融机构特别是数字银行的创新发展带来了广阔的空间。亚洲数字银行此次与来自新加坡的金融科技伙伴一起搭建新生态，以数字金融产品创新为重心、以数字资产开发升值为核心，不断为来自全球的企业及个人用户创造价值、与用户共享价值。

王凯先生表示：“通过此次四方合作将为Web3.0 的技术发展奠定基石。BitDATA Exchange 作为Web2 和Web3 的连接器帮助Web2 应用转换到Web3，同时华为云为Web3 行业提供全面的云基础实施服务；Numen Cyber将为Web3 安全提供全方位的保驾护航能力。相信在多方共同努力下，Web3 将在东南亚乃至全球市场爆发！“
