# Curve Finance 遭攻击！事件分析来啦！

事件发生于8月10日，NUMEN实验室通过链上交易分析和推特消息发现，著名项目Curve被攻击。然而本次攻击并不同于常见的合约漏洞攻击或者闪电贷攻击，而是DNS遭劫持攻击。访问的Curve. Finance网页端遭转向至黑客的恶意网址，黑客在他们的页面上放置了恶意的攻击合约，用户在网页端授权时，实际是授权给了黑客部署的合约地址，黑客可以直接将用户钱包内的钱转走。黑客在以太坊上总计获取了57.3万美金资产。

近期安全事件频发，黑客的攻击手法也层出不穷，下面我们也一起看看本次攻击事件(举例说明)。

第一步：

因为DNS遭劫持攻击，访问的Curve. Finance网页转向到了黑客的恶意网址，用户在交易时要先进行授权，实际是授权给了黑客的攻击合约，授权后用户就成为了黑客待宰的羔羊。

![](../Images/4b66f92044ff11f3ebf64f21c0940357.png)

![](../Images/2776e7e732f18ed6dde525f28ff4dfed.png)

第二步：

当黑客攻击合约地址有了用户代币授权后，就可以直接调用攻击合约中的转账函数将用户钱包中的代币转移的自己指定的地址。

![](../Images/760080de9fb6e9222dd68670ea4b84fc.png)

第三步：

黑客将攻击获利的代币通过一些去中心化交易所进行兑换，并通过Tornado.Cash进行转移。

![](../Images/36fd3c78f5b566f57d0d358c22a79899.png)

  

  

**官方通告：**

目前Curve官方也发布通告，已经发现问题并恢复，建议用户使用https://curve.exchange/ethereum/，暂时不要使用https://curve.fi/，如果过去几小时已经向黑客攻击合约地址授权的提醒用户尽快去取消授权。
