## PHP strcmp绕过

  

查看网页源码有所提示  
![](../Images/5603cbf52fc15b9536a486444995c4fe.png "image")  
一般在php中通常使用 == 和 strcmp 来进行判断两个字符串参数相等的，但是strcmp有个特点，当strcmp的两个字符串参数相等的时候会返回0；但如果把string和array相比较的话，strcmp也会返回0。这里猜测是使用strcmp之类的来判断密码的。

  

当字符串相等时返回0，把他变成array数组，那么也同理返回0，从而达到绕过

  

```

源码
<input name="pass" value="" type="password">
修改后
<input name="pass\[\]" value="" type="password">
使pass参数变成array
```

  

![](../Images/9d201db2a5a9e6fa82b6ba4d559a978d.png "image")

## ltrace命令跟踪进程调用库函数情况

  

### 1、ltrace简介

  

ltrace命令 是用来跟踪进程调用库函数的情况

  

### 2、kali安装

  

```
apt-get install ltrace \-y
```

  

![](../Images/892ba0398ef9c2f5200239b5497a3bc4.png "image")

  

### 3、常用指令

  

```
\-a
 对齐具体某个列的返回值。\-c
 计算时间和调用，并在程序退出时打印摘要。\-C
 解码低级别名称（内核级）为用户级名称。\-d
 打印调试信息。\-e
 改变跟踪的事件。\-f
 跟踪子进程。\-h
 打印帮助信息。\-i
 打印指令指针，当库调用时。\-l
 只打印某个库中的调用。\-L
 不打印库调用。\-n, \--indent\=
NR 对每个调用级别嵌套以NR个空格进行缩进输出。\-o, \--output\=
file 把输出定向到文件。\-p
 PID 附着在值为PID的进程号上进行ltrace。\-r
 打印相对时间戳。\-s
 STRLEN 设置打印的字符串最大长度。\-S
 显示系统调用。\-t, \-tt, \-ttt
 打印绝对时间戳。\-T
 输出每个调用过程的时间开销。\-u
 USERNAME 使用某个用户id或组ID来运行命令。\-V, \--version
 打印版本信息，然后退出。\-x NAME treat the global NAME like a library subroutine
```
