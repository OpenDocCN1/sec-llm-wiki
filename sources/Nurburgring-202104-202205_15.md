## 一、搭建Docker

### 1、安装Docker依赖包

```
sudo apt update
apt -y install curl gnupg2 apt-transport-https software-properties-common ca-certificates
```

![](../Images/9594e2e42dc6b5721df286ab16f2f5d2.png)

### 2、导入用于签署Docker软件包的Docker GPG密钥  

```
curl \-fsSL https://download.docker.com/linux/debian/gpg | sudo apt-key add \-
```

![](../Images/3f5579d78b4d16014ed6f47b1868f32e.png)

### 3、将Docker储存库添加到Kali Linux系统中  

```
到/etc/apt/sources.list.d/目录下
新建docker.list
deb \[arch\=amd64\] https://download.docker.com/linux/debian buster stable //把内容复制进去
```

![](../Images/f9d46b2cd913ee6f6b97a5b2221a7b55.png)

### 4、在Kali Linux上安装Docker  

```
sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io
```

![](../Images/6977cac7fb6cfbfe0d73b16dfdd3a816.png)

### 5、解决sudo问题使用  

使用以下命令将docker组添加到系统中，而无需任何用户，将用户帐户添加到组中，以非特权用户身份运行

```
sudo usermod \-aG docker $USER
newgrp docker
```

![](../Images/db25a38a443a07e1127c8ddcce4e9dbb.png)

### 6、检查安装的Docker版本  

```
 docker version
```

![](../Images/99eb42653edeaa194f6d90890f77c0fe.png)

### 7、安装docker-compose  

```
apt install docker-compost
```

![](../Images/6e4ac31b788ecd3138aaf4c42358dfde.png)

验证一下  

```
docker-compose version
```

![](../Images/5d75b4fafeb6a3db0234b38828f06e1a.png)

## 二、搭建ARL(Asset Reconnaissance Lighthouse)资产侦察灯塔系统  

### 1、Docker镜像拉取（安装方法一）

```
docker pull tophant/arl
```

![](../Images/1d083ee35651822a1dd3df7a91f31f3e.png)

### 2、github直接下载（安装方法二 建议！）  

```
git clone https://github.com/TophantTechnology/ARL
```

![](../Images/1e94fcf0663bf37dac388a8aea3043fe.png)

### 3、开启容器  

```
cd ARL/docker/
docker-compose up -d
```

![](../Images/4c785cda8d570ef3841006ebbea495d8.png)

### 4、可以看到报错了，解决报错  

```
docker volume create \--name\=arl\_db
```

![](../Images/791430cb43f91549468ed84aae5f9ec0.png)

### 5、启动登录灯塔  

```
docker-compose up -d
```

![](../Images/5b1bed15709010127b9ca7d8b9b915d5.png)
