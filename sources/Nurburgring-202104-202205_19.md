# 内网穿透Neo-reGeorg的使用  

## 网络 拓扑图![](../Images/a14a1087451b5363b761346eb0c73099.png "image-20210518232504311.png")使用环境

  

目标机不出网，可以在边界服务器上设置代理就可以访问目标机的整个内网网段。

## reGeorg简介

  

reGeorg是一个内网穿透工具，基于socks5，而且支持众多脚本。因为使用频繁，所以较多的杀软都会拦截，需要做免杀处理。

  

免杀reG下载地址：https://github.com/L-codes/Neo-reGeorg

  

此工具还做了加密，所以很多特征都没有了

## 使用方法

#### 一、输入密码生成加密脚本

```
 python3 neoreg.py generate \-k tenet
```

  

![](../Images/8254262a4fa604f872dea4134a8fa1bb.png "image-20210518233516499.png")![](../Images/b108e47d1eb43f7fe7c86ee17eb9114d.png "image-20210518233546583.png")

文件生成的目录

![](../Images/1462706655f5ae062ac645fc6175d137.png "image-20210518233644268.png")

#### 二、选择相应的脚本放入边界服务器中

放入WWW目录下，前提是要可以访问到的

![](../Images/d9a07b677297d18d50310709aab0aa25.png "image-20210518234023842.png")

  

可以尝试访问看下，没有出错就说明没有问题

![](../Images/21f93d270ee35ea1e8725a24a3ecda70.png "image-20210518234227565.png")

#### 三、Kali内做转发

成功转发，访问自己的1080端口即可

```
python3 neoreg.py \-k tenet \-u http://192.168.137.131/tunnel.php
```

![](../Images/23a34bf65a3ce588880744b9ad2edace.png "image-20210518234442763.png")

打开浏览器设置代理，即可访问10.10.10.132主机的80端口![](../Images/2f67e9b2da2e960d74003674ff3c03c4.png "image-20210518235037395.png")![](../Images/1df82beacd3521bf2765f9bdefc31bd1.png "image-20210518235111325.png")

#### 四、proxychains代理使用nmap

```
vim /etc/proxychains.conf
```

  

![](../Images/ae6d17fc67b32c8ed31f4c4e1a5a0182.png "image-20210518235414212.png")

这里nmap不能用root权限，切换一下普通权限扫描，成功

![](../Images/ea581c17942b9991c5d9686245569036.png "image-20210518235831778.png")
