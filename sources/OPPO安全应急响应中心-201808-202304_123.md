# 以技术构筑隐私堡垒，OPPO从源头守护安全之道

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyNzc4Mzk3MQ==&mid=2247488513&idx=1&sn=59aff4b92c31e5a9ac4d452975b59a59&chksm=fa7b154dcd0c9c5bd941235e5e23a852fd7dd795ac6d3432f19e9d62aaec580cce61ccdeab4d&scene=126&sessionid=1681377696#rd](http://mp.weixin.qq.com/s?__biz=MzUyNzc4Mzk3MQ==&mid=2247488513&idx=1&sn=59aff4b92c31e5a9ac4d452975b59a59&chksm=fa7b154dcd0c9c5bd941235e5e23a852fd7dd795ac6d3432f19e9d62aaec580cce61ccdeab4d&scene=126&sessionid=1681377696#rd)

近几年频频爆出的用户数据与隐私泄露新闻，让数据安全与隐私保护成为了热门话题，开始受到社会各界的广泛关注。对于科技企业而言，安全与隐私已成为持续发展需要关注的重点领域。安全与隐私合规融入业务生命全周期的需求，让企业更加重视员工安全素养的提升。

 

OPPO一直以来都十分重视在安全与隐私合规方面的投入。OPPO高级副总裁、首席运营官曾元清曾在“OPPO安全与隐私宣传周”上表示：“产品安全和用户的隐私保护，是OPPO一直以来都非常重视的焦点，也是我们对用户的承诺。OPPO不是因为外部监管的要求才这样做，而是我们从骨子里就认为，这是我们必须要做到的事情。OPPO的所有产品，安全与隐私合规是放在第一位的，是最基本的，也是最重要的品质。”

 

**聚焦员工安全素养提升，从源头守护产品和服务的安全与隐私**

 

![](../Images/084dfdf6d5b8e8323d004510e1d46c50.png)

**\*OPPO安全与隐私周活动现场**

  

OPPO一直以来都十分重视对员工安全意识的培养。自2019年开始，OPPO每年举办“安全与隐私宣传周”活动，以持续一周的线上“安全知识竞赛”及线下安全意识宣贯活动为核心，通过创新学习模式及趣味游戏等形式，强调信息安全与隐私保护的重要性，构建安全与隐私合规文化，实现从“要我合规”到“我要合规”的思维转变，提升OPPO全体员工的安全与隐私合规意识，从源头守护产品和服务的安全与隐私。第三届安全周活动于10月22日圆满落幕，持续一星期的线上安全知识竞赛热度不减，在意识培养及话题讨论方面获得了广泛关注。

  

![](../Images/0c075fa2b15ca177c7aa94c07d284dfc.png)

**\*OPPO安全与隐私周活动现场**  

  

**不断加大安全与隐私技术投入，建立OPPO安全生态体系**

 

OPPO致力于为用户打造安全可靠的产品和服务。OPPO安全从组织建设、流程制度、技术工具三个维度入手，打造个人信息保护技术，搭建安全管理体系框架。针对用户端外的个人信息保护，OPPO安全以六层防御系统为基础，打造可靠、可信、智能化的数据安全防御体系。

 

未来，OPPO安全团队将继续围绕用户安全隐私保护，为用户提供安全、可信、合规的应用产品，在行业生态安全建设的道路上持续探索，让用户能更清晰的感受到可信赖、有担当的OPPO。
