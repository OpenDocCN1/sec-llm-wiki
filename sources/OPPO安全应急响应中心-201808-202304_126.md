# OPPO携手德勤联合发布《移动应用（APP）个人信息保护白皮书》

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyNzc4Mzk3MQ==&mid=2247488447&idx=1&sn=d2210e284a909b67ef3b4b7c112cef82&chksm=fa7b12f3cd0c9be5c1351cd4247281b76ddb5fb04ef24524dc855c430591fa3ab9800c75efe3&scene=126&sessionid=1681377696#rd](http://mp.weixin.qq.com/s?__biz=MzUyNzc4Mzk3MQ==&mid=2247488447&idx=1&sn=d2210e284a909b67ef3b4b7c112cef82&chksm=fa7b12f3cd0c9be5c1351cd4247281b76ddb5fb04ef24524dc855c430591fa3ab9800c75efe3&scene=126&sessionid=1681377696#rd)

2021年10月27日，由OPPO主办的“2021 OPPO开发者大会（ODC21）”在上海举行。OPPO数据与隐私安全负责人刘桃松和德勤中国风险咨询安全风险服务合伙人肖腾飞在会上联合发布《移动应用（APP）个人信息保护白皮书》，希望将OPPO对个人信息保护的思考和实践经验分享给公众，共建移动应用个人信息保护生态。

![](../Images/047fd4cc28d2434f158f79428808cc22.png)

![](../Images/63014488984e688e7a904acfc148a76c.png)

随着移动互联网的快速发展与智能手机的广泛普及，移动应用已深入到大众衣食住行的方方面面，尤其在疫情防控过程中，发挥了重要作用。同时，移动应用作为用户数据收集的主要入口之一，其个人信息保护问题已备受国家和社会重视。

  

OPPO作为智能手机厂商及移动应用平台方，长期积极推动移动应用业务的个人信息保护工作开展。在持续的业务实践中，OPPO时刻关注个人信息保护领域的最新变化，洞察移动应用产业现状，紧跟我国立法动态及监管趋势，聚焦消费者的痛点问题和产业面临的机遇与挑战，结合自身业务特点，逐步建立起一套移动应用安全治理的实践体系。本着科技为人，以善天下的理念，OPPO与德勤联合编写并发布此白皮书。

  

![](../Images/6739fe8964a2423dac707122219e4e95.png)

  

本白皮书围绕着移动应用个人信息保护分为五个部分。

*   第一部分基于近三年来公开的数据，重点分析移动应用产业现状与趋势、个人信息保护特征和新技术的应用对移动应用个人信息保护带来挑战和机遇。
    
*   第二部分基于我国个人信息保护法律制度框架逐步形成的背景，对近两年来监管部门开展的专项监督活动和侵犯个人信息的判罚趋势进行分析，并对《个人信息保护法》生效后的监管与司法诉讼的趋势进行研判，呈现我国的个人信息保护治理环境。
    
*   第三部分结合德勤、OPPO和公开的数据，展现我国网民对移动应用个人信息保护的关注点。
    
*   第四部分重点以OPPO在移动应用个人信息保护的实践作为蓝本，分享如何开展个人信息保护工作。
    
*   第五部分以行业生态视角提出倡议，以及为消费者总结一些实用的个人信息保护建议。
    

  

移动应用行业个人信息保护的实践之路道阻且长，但千里之行始于足下。希望本白皮书的发布，可以为消费者、开发者带来新的借鉴与鼓舞。OPPO将持续打造安全可靠的产品和服务，并与广大消费者、开发者一道共筑个人信息保护生态，让科技缔造美好生活。
