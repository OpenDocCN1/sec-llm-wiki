### **AI安全研究员**

//

  

**岗位职责：**

1.  负责公司相关产品的AI攻防研究及方案制定；
    
2.  探索及跟踪AI安全业界前沿技术。
    

  

**岗位要求：**

1.  具备扎实的理论和算法基础，对常见机器学习算法有深入的理解；
    
2.  熟悉主流的机器学习及深度学习框架；
    
3.  在模型鲁棒性、对抗样本攻防领域有深入的研究；
    
4.  对AI安全方面有浓厚兴趣，有成功的案例或者发表过相关学术论文；
    
5.  在语音、图像、文本方向有实践经验（加分项）；
    

  

**工作地点：**深圳、成都

  

//

### **高级安全AI算法工程师**

//

  

  

**岗位职责：**

1.  负责大数据和AI技术用于恶意文件检测，作弊和欺诈流量识别等，提高现有的对抗效果
    
2.  探索及跟踪对抗样本攻防、AI滥用等技术前沿，研究和提升AI模型抗恶意样本的能力
    

  

**岗位要求：**

1.  本科及以上学历，计算机、信息安全、人工智能、数据挖掘等相关专业背景3.有扎实的数学基础，熟悉常见的机器学习算法和深度学习算法，3年以上机器学习/深度学习/数据挖掘实战经验
    
2.  代码能力较好，至少熟练掌握一种开发语言（Python/Scala/Java/C++等）
    
3.  至少熟练掌握一种分布式数据处理框架（Hadoop/Hive/Spark/Storm等）和一种机器学习框架（Tensorflow、PyTorch、Caffe等）
    
4.  熟悉模型可解释性、模型鲁棒性、对抗样本攻防等技术优先
    
5.  熟悉攻击检测、恶意软件、垃圾邮件、反作弊、反欺诈等安全背景知识优先
    

  

**工作地点：**成都

  

  

//

### **安全算法专家**

//

  

  

**岗位职责：**

1.  恶意文件/流量/行为等安全大数据分析，算法和数学模型设计；
    
2.  入侵行为、攻击行为、异常行为特征及模式识别；
    
3.  根据安全场景选择合适的算法并推动该算法在安全系统里的落地实现，包括但不限于联动HIDS、NIDS、RASP、WAF、恶意攻击等。
    

  

**岗位要求：**

1.  计算机（机器学习、人工智能等方向）、数学、统计学或相关专业本科及以上学历，
    
2.  5年以上工作经验，扎实的理论和算法基础，对常见数据挖掘、统计和机器学习、深度算法有深刻的理解；
    
3.  熟悉Hadoop／spark／storm等大数据框架使用，熟悉Caffe／TensorFlow／MXNet／Torch等机器学习及深度学习框架的使用；4、有机器学习、人工智能、自然语言处理等领域全球领先企业的工作经验；
    
4.  具有入侵及威胁检测、数据泄漏、恶意软件、僵尸网络等相关安全技术的优先。
    

  

**工作地点：**深圳

  

  

//

### **计算机视觉安全算法专家**

//

  

**岗位职责：**

1.  人脸识别安全对抗、图像视频等敏感信息检测等计算机视觉、深度学习算法的研究和应用；
    
2.  基于应用场景，完成算法设计，实现和调优，推进算法落地；
    
3.  负责跟进行业前沿技术发展趋势，跟踪国际最新算法发展方向和相应技能；
    

  

**岗位要求：**

1.  计算机或相关专业本科及以上学历，3年以上人脸识别相关经验；
    
2.  熟练掌握python/C/C++编程，熟悉linux开发环境；
    
3.  熟悉常用图像算法相关深度学习框架，对深度学习技术有深度了解和丰富实战经验;
    
4.  拥有国际顶尖学术论文，有人脸活体检测等实际项目经验者优先；
    

  

**工作地点：**深圳

  

  

//

### 高级安全算法工程师

//

  

**岗位职责：**

1.  负责OPPO互联网服务业务安全风险问题的分析、建模，处置策略的制定和风控效果运营；
    
2.  基于每天百亿级用户行为，分析和挖掘海量数据，发现用户行为模式与规律，构建相关的算法模型；
    

  

**岗位要求：**

1.  计算机（机器学习、人工智能等方向）、数学、统计学或相关专业本科及以上学历，
    
2.  熟悉python、scala、R、Java、C/C++中的一种或多种编程技术。
    
3.  熟悉大数据处理技术，对大数据开源组件有使用经验，至少熟悉hadoop/hive/spark/flink其中一项，善于学习应用业界领先数据架构和技术
    
4.  熟悉数机器学习算法，包括数据清洗、统计学习、分类聚类算法。能够验证算法效果，将算法应用于安全业务；
    
5.  有一定的安全风控策略开发或对抗经验；
    
6.  善于学习，善于从数据中发现并解决问题；
    
7.  有风控研发经验者优先，对风控行业有自己思考的优先
    

  

**工作地点：**深圳
