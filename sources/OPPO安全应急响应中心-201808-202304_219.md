# OPPO 安全应急响应中心正式加入事件响应与安全团队论坛

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyNzc4Mzk3MQ==&mid=2247486327&idx=2&sn=d448b9ce702b1fe4e09a7dcf330e6d38&chksm=fa7b0a3bcd0c832d980a8b7c16b1a681a49e3efa5627a17ad2f3d36a75626ef93bfd02262b7a&scene=126&sessionid=1681377737#rd](http://mp.weixin.qq.com/s?__biz=MzUyNzc4Mzk3MQ==&mid=2247486327&idx=2&sn=d448b9ce702b1fe4e09a7dcf330e6d38&chksm=fa7b0a3bcd0c832d980a8b7c16b1a681a49e3efa5627a17ad2f3d36a75626ef93bfd02262b7a&scene=126&sessionid=1681377737#rd)

  

  

  

近期，OPPO安全应急响应中心正式加入**事件响应与安全团队论坛Forum of Incident Response and Security Teams（FIRST）**，成为其国际成员之一。

  

  

作为服务于全球、软硬服一体的全球化互联网企业，**OPPO一直以来都非常重视自身产品和业务的安全问题，也一直致力于保障用户安全，坚持以用户安全和隐私保护为核心，打造一个绿色生态、合作共赢的立体安全防护体系**。OPPO安全应急响应中心在此次申请过程中展示了在漏洞和安全事件上快速响应能力、对安全规范制度的严格遵守、安全技术的研究发现及安全设施的建设等内容。

  

加入FIRST，既代表着OPPO安全应急响应中心得到了国际组织的认可，也代表着OPPO重视安全并将持续在安全领域加大投入的决心。未来，OPPO安全应急响应中心将携手全球各地的安全组织单位共同维护网络安全，建设全球化的安全防护体系。

  

![](../Images/22f20cec9a990906b7614c133600f412.png)  

  

  

FIRST成立于20世纪90年代，是一个国际联盟信任的计算机应急响应小组，负责合作处理计算机安全事件,促进事故预防计划。它汇集了各种各样的计算机安全应急响应团队，覆盖政府、商业、军队和教育机构等。

  

通过其在“事件预防”方面的协调与促进,能够刺激事件快速反应,促进成员之间的信息共享。FIRST目前拥有超过500名成员,分布在非洲、美洲、亚洲、欧洲和大洋洲。
