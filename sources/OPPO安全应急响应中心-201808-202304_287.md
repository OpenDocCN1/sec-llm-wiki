# OPPO安全与百度安全全达成合作，建立联合安全实验室

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyNzc4Mzk3MQ==&mid=2247485436&idx=1&sn=dcd8e8edca173e1a03849538e94a4147&chksm=fa7b06b0cd0c8fa644b0409ed050ee46b3e28b11533631bcbed9013c39a316a607e1787229f9&scene=126&sessionid=1681377762#rd](http://mp.weixin.qq.com/s?__biz=MzUyNzc4Mzk3MQ==&mid=2247485436&idx=1&sn=dcd8e8edca173e1a03849538e94a4147&chksm=fa7b06b0cd0c8fa644b0409ed050ee46b3e28b11533631bcbed9013c39a316a607e1787229f9&scene=126&sessionid=1681377762#rd)

  

2020年4月， OPPO安全与百度安全签署合作协议，整合双方优势资源，联合建立和运作“百度安全与OPPO安全联合实验室”，推动移动互联网安全和AI安全产业发展。

![](../Images/737fb6b817565996457cedfbdbb2a824.png)

此次OPPO安全与百度安全签署合作协议，共建联合安全实验室是双方优势互补、通力协作一个重要里程碑， 标志着双方的合作进入深化、高效轨道。双方将发挥各自业务能力和安全技术优势，在自动化安全检测、隐私保护技术、AI安全攻防、AIOT安全标准等多个领域进行多维度、多层次协同攻关，努力建设新兴技术领域安全防护与合规检测能力及AIOT安全攻防体系，推动移动互联网安全及AI安全产业的快速发展，携手打造智能互联生态安全防护高地，为全球用户持续提供安全、可靠的服务。
