# 以用户隐私安全为中心 OPPO成立子午互联网安全实验室

当前，5G、IoT、AI等前沿技术的应用落地正推动着社会的进步，物联网技术的发展和普及为人类生活带来了便利，也埋下了个人隐私、个人财产、人身等多方面安全隐患，一次小的安全事故也有可能导致数亿人信息泄露等严重安全事件的发生。

随着OPPO手机全球化，互联网业务的逐步发展，目前，OPPO累计日活用户超过3亿， 业务形态也多种多样，软件商店，主题商店，浏览器，云服务，IoT设备等业务逐步发展形成规模，OPPO用户群体与互联网业务已然成为全球智能互联体系的重要组成部分。

面对日益严峻的网络安全局势，OPPO始终坚持以用户安全为使命，更愿主动肩负起作为手机厂商应构建手机行业安全生态的社会责任。

以保护用户安全与隐私为初心，真正立足于用户信息安全保障需求，OPPO成立了子午互联网安全实验室。用责任兑付信任，致力于打造用户信息安全品牌与智能互联下的安全防护体系。

为智能硬件注入“安全”基因

截至2018年12月，我国互联网用户规模达到8.29亿、移动互联网用户规模达7.24亿，CNNIC预测，移动互联网用户规模到2022年达到11亿。同时，到2021年，全球接入互联网的物联网设备预计将达到160亿，由5G+物联网构建的万物互联场景，正在深刻改变互联网的安全格局，10亿级用户与百亿级智能设备通过智能手机，实现高效高速链接。

万物互联时代，智能设备的安全直接关系到用户的财产、隐私、甚至生命安全。OPPO子午互联网安全实验室以用户为中心，将防护线延续到智能设备领域，旨在为IoT设备提供安全监测、漏洞监测能力，并解决隐私安全、数据安全、设备安全等问题。目前初步形成了安全能力，并将持续推动IoT安全测试技术的深入研究与安全开发规范的快速落地。

用户思维重塑安全边界

用户信息安全高于一切。今年3月成立以来，OPPO子午互联网安全实验室构建了一只跨业务、跨系统的数据和隐私保护团队，发力用户隐私保护研究。团队对标国际，希望通过科学规范的安全管理流程与先进技术形成健全的用户隐私保护体系架构。

OPPO子午互联网安全实验室从用户角度出发，在合规的基础上，全面优化隐私数据采集、处理流程与规范，并突破一系列合规检测技术壁垒，强制用户个人数据保护策略落地。使OPPO在为用户提供优质可靠的服务的同时，充分保障用户的知情权与选择权，实现用户对个人信息的控制，并提供全方位的数据保护措施，为用户建立稳固的安全防线，以责任来兑付用户的信任。

![](../Images/92552c1b7d99f77da5dcdf416623b878.png)

攻防对抗反哺业务安全

OPPO子午互联网安全实验室着力打造一支具备安全特种作战能力的蓝军，跟踪并研究业界前沿安全技术，聚焦于 OPPO 业务安全。于此同时，发力解决5G、大数据、AI等安全问题，构建覆盖连接、系统、应用、设备等手机和互联网关键领域的纵深防御体系，持续输出高性能、高可靠的攻击防御、态势感知、风险控制及威胁检测等安全防护产品，反哺OPPO品牌平台生态。

OPPO子午互联网安全实验室从“攻”的视角打磨“防”的手段，在攻防对抗中不断增强产品“抵抗力”，协助提升业务系统安全性，完善平台安全系统能力，为保障用户信息安全构筑铜墙壁垒。

产学联合共建安全平台

移动互联网时代，网络安全态势时刻都在发生变化。而面对当前新的网络安全形势，客观上要求打破行业与企业、技术与人才之间的壁垒。

下一步，OPPO将积极联动各大高校开展建设联合安全实验室，将领先的行业实践经验引入高校研究，和各大高校一起推动面向互联网新兴安全技术领域的校企合作科研项目。于此同时，积极参与和推动手机行业安全生态的建设，为用户提供更安全的手机服务和互联网应用服务，为行业培养更多优秀的网络安全人才，以推动网络安全行业的健康持久发展。
