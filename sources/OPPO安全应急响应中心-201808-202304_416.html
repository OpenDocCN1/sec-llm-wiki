OSRC 迎中秋、庆国庆 双倍奖金活动重磅推出

值此中秋、国庆双节之际，OSRC重磅推出双倍奖金活动，更有Find X、R17、O-Free无线耳机等各种礼品，惊喜不断，等你挑战！

一、活动时间

2018年9月15日 —— 2018年10月14日

二、活动内容

活动一：活动期间，所有提交的漏洞均可享受双倍奖金


提供特殊重大漏洞，最高奖励50000元。核心业务定义如下（详情请参考OSRC网站漏洞评级与奖励标准）：

OPPO官网、OPPO商城、OPPO软件商店、OPPO游戏中心、OPPO广告联盟、OPPO云服务、OPPO会员、OPPO社区、OPPO开放平台、OPPO营销平台、ColorOS、OPPO+、OPPO浏览器、OPPO主题商店。


威胁情报收取说明：

①　威胁情报将根据完整性及其影响打分。

②　鼓励核心业务相关的漏洞和情报。

无效威胁情报包括：

①　不涉及安全问题的bug。包括但不限于产品功能缺陷、页面乱码、样式混编、静态文件目录遍历、应用兼容性等问题等。

②　无法利用的漏洞。 包括但不限于没有实际意义的扫描器漏洞报告（如 Web Server 的低版本）、 Self-XSS、 无敏感信息的 JSON Hijacking、 无敏感操作的 CSRF、无意义的异常信息泄漏、内网 IP 地址/域名泄漏。

③　无法重现的漏洞、不能直接体现漏洞的其他问题。包括但不限于纯属用户猜测的问题。

④　其它危害过低的漏洞、OSRC已掌握的威胁情报。


活动二：额外奖励

活动结束后，根据活动期间的漏洞金额排名，额外赠送以下礼品：

①　排名第一的白帽子，赠送Find X 波尔多红手机一部（价值4999元）；   

②　排名第二的白帽子，赠送R17手机一部（流光蓝 or 倪光紫）（价值3499元）； 

③　排名第三至五名的白帽子，赠送O-Free无线耳机一副（波尔多红）（价值699元）；     

④　排名第六至十名的白帽子，赠送ikbc C87 or c104机械键盘一个（任选一款）（价值400左右）。


三、注意事项

漏洞处理流程，请参考《OPPO外部威胁情报处理流程 v1.1》，也请仔细阅读《OPPO安全应急响应中心平台服务协议》，以避免由此带来的风险。


最后，OSRC祝愿各位中秋国庆双节快乐、阖家幸福！
