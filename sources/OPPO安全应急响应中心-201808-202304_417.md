# 2018年8月OSRC奖励公告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyNzc4Mzk3MQ==&mid=2247483696&idx=1&sn=643cb9b20f73e8acbce20af475b019a9&chksm=fa7b007ccd0c896a320e5eeed7fde7ad0fb5e3f60524614488754ae8c89176c4c50de4870a35&scene=126&sessionid=1681377823#rd](http://mp.weixin.qq.com/s?__biz=MzUyNzc4Mzk3MQ==&mid=2247483696&idx=1&sn=643cb9b20f73e8acbce20af475b019a9&chksm=fa7b007ccd0c896a320e5eeed7fde7ad0fb5e3f60524614488754ae8c89176c4c50de4870a35&scene=126&sessionid=1681377823#rd)

OPPO安全应急响应中心（OSRC）于2018年8月15日正式上线，得到了大家的广泛关注和参与。截止8月31日，在半个月的时间内，共有**40余位**国内外安全专家通过OSRC平台提交了**202个**安全漏洞或威胁情报。非常感谢各位安全专家的关注和支持，帮助OPPO提升安全防护水平，共同保障OPPO亿级用户的安全。

根据OSRC漏洞奖励规定，现对8月份提报漏洞的安全专家发放相应奖金，超过1000的可自行选择现金或等值京东卡购物卡，1000以下的发放等值京东购物卡，现金最迟在十月初可到账，京东购物卡9月下旬可到，如未收到奖励请联系我们（security@oppo.com）。
