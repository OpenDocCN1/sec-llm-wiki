# 【煮酒论剑议攻防】安全群英会圆满举行

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTk5NDMyMw==&mid=2652093889&idx=1&sn=77165a31ed12ccb30419b6f2f5e576a2&chksm=bcd5eb7d8ba2626b95d1c1d932dfdb1cfc7f36f6d52238377cc47100c1101a56a63f5b7e4705&scene=126&sessionid=1681321541#rd](http://mp.weixin.qq.com/s?__biz=MjM5OTk5NDMyMw==&mid=2652093889&idx=1&sn=77165a31ed12ccb30419b6f2f5e576a2&chksm=bcd5eb7d8ba2626b95d1c1d932dfdb1cfc7f36f6d52238377cc47100c1101a56a63f5b7e4705&scene=126&sessionid=1681321541#rd)

![](../Images/b9b207f8aaebd36358544fe61d05ecb0.png)  

为更好地促进国内互联网安全企业的交流互动，提升我国互联网、特别是移动互联网安全技术的快速发展，OWASP中国联合OneASP于12月3日在上海麦腾集创空间成功举办了“煮酒论剑议攻防”技术沙龙。活动得到了广大OWASP会员及国内相关企业的积极响应，不仅邀请了众多安全领域资深专家到场演讲，还吸引了国内互联网安全领域的精英们参会，现场气氛活跃。

作为本次沙龙的主要议题，参会人员围绕攻防及企业安全人才培养等开展了全面的互动和交流。其中，来自OWASP中国、OneASP、北京白帽汇科技、梆梆安全、(ISC)²上海分会等协会、企业的技术负责人在各自的演讲中就企业安全之道、安全防护堡垒的构建、移动安全、网络安全的攻防对抗、安全人才发展等行业热点、难点话题进行了深入的分析和解读。演讲嘉宾的发言，信息量大、实践指导作用强，得到了与会者的积极响应，台上台下的良好互动也充分达到了促进沟通、交流、学习的活动目的。

为了更进一步加强技术交流，后续OWASP中国会在全国举办更多技术沙龙，感谢OWASP中国会员的支持与鼓励，期待与您携手前行！
