随着移动互联网技术的发展，我们在享受科技带来的美好生活时，安全也成为急需要面对的问题，为此**SecZone**携手**移动互联网安全技术国家工程实验室**计划于金秋10月在深圳虚拟大学园举办一场安全顶级盛宴- **ASC2016移动物联网安全高峰论坛**。

通过本次会议，活动主办方希望立足“ASC移动物联网安全高峰论坛”这一平台，更有力地汇聚我国互联网安全技术领域的优质资源，集合国内外应急响应专家及S-SDLC流程专家形成合力共同推进我国移动物联网安全技术的快速发展；同时希望更有力地帮助我国企业加快提升网络安全建设水平，更好地促进全行业的健康发展。

目前大会已经进入倒计时阶段，现在我们就来盘点一下即将参会的安全大咖们。

演讲嘉宾：**Steve Kosten ** 

演讲主题：Integrating Security into an Agile RapidDeployment Lifecycle

议题简介：Many organizations struggle to effectively incorporate security in anagile environment.  A secure, agile,rapid development and rapid integration SDLC using appropriate technologies andapproaches is possible.  In thispresentation, we will talk about how security may be successfully injected intoan agile rapid deployment environment using both dynamic and static assessmenttools;  this approach most efficientlyidentifies security vulnerabilities prior to deployment.

演讲嘉宾：**Ajin Abraham ** 

演讲主题：Simplifying Mobile Application Security Assessments with MobSF

议题简介：In this talk I will introduce an extendable,and scalable web framework called Mobile Security Framework or MobSF forSecurity analysis of Mobile Applications.MobileSecurity Framework is an all-in-one open source mobile application(Android/iOS) automated pen-testing framework capable of performing static,dynamic analysis and web API testing. It supports Android and iOS binaries aswell as zipped source code.

演讲嘉宾：**李建蒙**  

演讲主题：如何安全地做敏捷开发？

议题简介：敏捷开发越来越流行，但是，同时也会带来问题。如何能够通过敏捷开发快速地发布新产品和新特性的同时尽量避免安全问题的引入是一个挑战。在本次演讲中，我将会介绍我们是在敏捷开发流程中的每一个阶段如何提高产品安全的，包括：培训、识别威胁、构建自动化扫描，改进编译过程和制定发布标准等。

演讲嘉宾：**王建  **

演讲主题：车载网络安全问题研究

议题简介：从“架构层”阐述车载网络安全问题来源，资产及漏洞，威胁及风险评估，最后介绍入侵检测在车载网络安全领域的应用。
