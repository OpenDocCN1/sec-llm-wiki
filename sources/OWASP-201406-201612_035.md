# 会前高端培训报名启动--ASC 2016移动物联网安全高峰论坛

由SecZone联合OWASP中国、CSA云安全联盟特别组织策划的首届ASC移动物联网高峰论坛（2016年10月25日-26日深圳）开幕在即。

同时，为了给予参会者提供更好的学习交流机会，本次论坛主办方于10月23-24日专门组织安排了一场课程名为“网络安全大师，掌控较少人知道的网络攻击（WebSecNinja，Master the Lesser KnownWebAttacks）”的会前高端培训。培训由资深安全顾问/OWASP Project Leader AjinAbraham主讲，将重点介绍反映文件下载（RFD）、突变XSS（mXSS）、JSON劫持等一系列在现有书籍、培训、课程记录和其他场合很少涉猎的网络攻击技术和案例。Ajin Abraham在应用程序安全领域拥有近10年的安全研发和研究经验，曾多次受邀参加ClubHack、OWASP AppSec AsiaPac、BlackHat Europe等国际级安全会议并发表演讲。

培训时间：10月23-24日

培训费用：4999元/2天（含税）

授课语言：英语

培训地点：深圳

报名方式：邮件至[open@seczone.org](mailto:open@seczone.org)

了解论坛和培训详情，请密切关注SecZone微信发布的最新信息。

                             

**会议时间：**2016年10月25-26日

**会议地点：**深圳虚拟大学园

**会议形式**：移动物联网主题演讲

                 移动物联网设备展览

                 会前高端培训

**主办单位：**SecZone互联网安全研究中心
