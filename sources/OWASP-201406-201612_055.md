# ASC 2016移动物联网安全高峰论坛

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTk5NDMyMw==&mid=2652093729&idx=1&sn=7e6a8ff3ecde0ddcae1b6c8b1414ff9e&chksm=bcd5eb9d8ba2628b1da6c2af9a734a31bebb0d2c12d858b6b30ffd16ee85c18a0c72ba2dd122&scene=126&sessionid=1681321547#rd](http://mp.weixin.qq.com/s?__biz=MjM5OTk5NDMyMw==&mid=2652093729&idx=1&sn=7e6a8ff3ecde0ddcae1b6c8b1414ff9e&chksm=bcd5eb9d8ba2628b1da6c2af9a734a31bebb0d2c12d858b6b30ffd16ee85c18a0c72ba2dd122&scene=126&sessionid=1681321547#rd)

本次论坛计划于2016年7月20日-21日在深圳举行，将以“移动物联网入口安全——移动设备&移动连接平台安全技术探讨”为主题，广泛邀请苹果、三星、谷歌、华为、Facebook、阿里巴巴、腾讯、百度等重要移动门户入口平台的代表和国内外众多移动物联网安全领域的专家学者、技术人员、设备厂商参加会议，共同探讨如何提升移动设备、移动连接平台安全保障等热点、难点议题，并对移动物联网安全领域各大厂商的安全技术、产品、解决方案进行全面的展示，为业界提供一个难得的互动交流机会。![](../Images/53a564d96e2917b808b296b0984e8813.png)
