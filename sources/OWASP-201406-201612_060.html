强化审核,数足开班--2016国际安全认证开源培训推出升级计划

原文：http://mp.weixin.qq.com/s?__biz=MjM5OTk5NDMyMw==&mid=2652093708&idx=3&sn=35349d81f9c75e605ac94599c4acd34f&chksm=bcd5ebb08ba262a6279d21c026c552677f3e119b77a197d805d8a926e45dcdc86d5ee16dfd9d&scene=126&sessionid=1681321547#rd


互联网安全学院重磅推出覆盖全年的“国际安全认证开源培训项目”。自2016年1月起，已成功开办了6期，吸引了国内众多互联网安全领域专业人员踊跃参加。为了更好地实现培训目标，满足广大学员的培训需求，保证每一位学员都能达到较好的培训效果，互联网安全学院自6月起全面推出国际安全认证开源培训升级计划，实行“强化审核、数足开班”新模式，并将培训地点增至北京、上海、深圳、苏州、武汉和成都、广州等7个城市。

“数足开班”模式具体规则如下：

  1. 每个培训地点的报名审核通过人数达到30人即组织开班

  2. 报名结束后30-60天内安排培训。

  3. 加强对报名人员的审核，确保参与培训人员的综合素质水平，并针对OWASP企业会员、应用安全联盟成员、OWASP个人高级会员、CWASP学员优先审核。

  4. 报名状态及开班信息请于官方微信中查询

CISSP

CISSP（Certified information System Security  Professional, 注册信息系统安全认证专家）是目前世界上最权威、最全面的国际化信息系统安全方面的认证，由国际信息系统安全认证协会(ISC)2组织和管理，(ISC)2在全世界各地举办考试，符合考试资格的人员在通过考试后被授予CISSP认证证书。

4天

CISA

国际注册信息系统审计师（Certified Information Systems Auditor，简称CISA）是由信息系统审计与控制协会（ISACA）授予的关于信息系统审计、信息安全和信息系统控制相关的知识及技能的国际认证。

4天

CSSLP

注册软件生命周期安全师（Certified Secure Software Lifecycle Professional）(CSSLP®) 是信息安全行业唯一一个针对保障整个软件开发生命周期安全性的认证。从概念到规划、运行、维护直至废弃处理，此资格认证制定了在软件开发的各个阶段保证其安全性的行业标准和最佳实践。CSSLP 认证旨在验证考生在整个软件开发生命周期 (SDLC) 保障应用安全的能力，包括从信息收集到安全软件的编码、测试、发布及维护，以及供应链及软件采购方面。

4天
