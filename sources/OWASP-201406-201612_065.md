# 关注人才培养，就是关注行业未来

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTk5NDMyMw==&mid=2652093692&idx=2&sn=d57c3e1581adbcf9f69639306c5e766a&chksm=bcd5ea408ba263560562ba2751805b98e824fdcef385761754f36283685f6dc80c8badc30c75&scene=126&sessionid=1681321550#rd](http://mp.weixin.qq.com/s?__biz=MjM5OTk5NDMyMw==&mid=2652093692&idx=2&sn=d57c3e1581adbcf9f69639306c5e766a&chksm=bcd5ea408ba263560562ba2751805b98e824fdcef385761754f36283685f6dc80c8badc30c75&scene=126&sessionid=1681321550#rd)

**OWASP 2016亚洲峰会开设人才培养分论坛**

“网络空间的竞争，归根结底是人才竞争”。当前，我国已有7亿网民和庞大的网络系统，而我国的网络安全人才培养规模和能力还远远不能适应发展需要。为此，加强网络安全人才的培养已经成为了国家推进网络信息产业发展的重要战略举措。正是在这样的背景下，即将于5月21日在湖北武汉召开的OWASP 2016亚洲峰会专门开设了人才培养分论坛，将通过来自国内外业界和高校的专业人士、专家学者的沟通、交流，共同探讨新形势下加强我国网络安全人才培养的重点、热点和难点，为改革网络安全人才培养模式、提升网络安全人才培养水平提供更新鲜的想法和更创新的思路。

据峰会举办方介绍，本次人才培养分论坛的设立得到了业界和社会的积极响应。目前，已有湖北大学、中南财经大学、武汉科技大学等30多家来自全国各地的高校报名参加本次论坛，并纷纷表示希望通过论坛与国内更多的网络安全企业和机构形成长效合作机制，以“产学研”结合的方式进一步加强网络安全人才培养的专业性、针对性和实效性。同时，国内外众多网络安全企业和机构也对参与本次论坛表现出了非常高的积极性。其中，Compass Security AG CEO Ivan Butler先生、OWASP中国主席Rip先生、HP全球安全技术主管王文君先生、以及红客训练营创始人张绍浪先生等行业专家将分别从安全试验平台建设、源代码安全教育、新型安全人才培养、软件安全经理培养以及信息安全高端人才培养等多个角度，和与会者分享国内外网络安全人才培养的成功经验、创新模式和发展趋势。

作为国际知名网络安全峰会，由OWASP中国主办， SecZone承办的OWASP 2016亚洲峰会将于今年5月21日在湖北武汉纽宾凯新时代国际酒店举行，将有来自国内外互联网安全领域的权威专家、专业人士近500人齐聚一堂，围绕“互联网+网络空间安全”的主题，共同探讨在“互联网+”时代如何提升Web应用、移动互联网、物联网等核心平台的安全技术水平等行业热点话题。欲知大会详情，请登陆[http://www.owasp.org.cn/OWASP\_Conference](http://www.owasp.org.cn/OWASP_Conference)，并请关注OWASP中国官方微信报名。
