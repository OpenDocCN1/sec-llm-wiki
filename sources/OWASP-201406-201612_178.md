# 开源POC/EXP平台推介---Beebeeto

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTk5NDMyMw==&mid=200743587&idx=4&sn=83666c7b5621454b210ff485bd8e6952&chksm=29314c1f1e46c5094aa51e9dfa574e7ced67565381e3be621c00a5fc6ed9a5a3f3dd07b73b95&scene=126&sessionid=1681321560#rd](http://mp.weixin.qq.com/s?__biz=MjM5OTk5NDMyMw==&mid=200743587&idx=4&sn=83666c7b5621454b210ff485bd8e6952&chksm=29314c1f1e46c5094aa51e9dfa574e7ced67565381e3be621c00a5fc6ed9a5a3f3dd07b73b95&scene=126&sessionid=1681321560#rd)

Beebeeto是由众多安全研究人员所共同维护的一个规范化的开源POC/EXP平台，安全研究人员可以在互联网上获取漏洞信息，然后按照BB2开发标准编写出相应的POC/EXP提交，就这个过程从漏洞分析、编程、Code-review多方面来提升自身能力，与此同时还为大家提供了一个开放、自由交流的平台。

网址：http://www.beebeeto.com/

OWASP会员请联系ivy@owasp.org.cn 获取beebeeto网站邀请码。
