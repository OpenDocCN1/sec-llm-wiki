# 互联网金融&金融互联网安全专题沙龙

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTk5NDMyMw==&mid=200480629&idx=4&sn=77b1e1b6f2592963bc77ac4a786d94b6&chksm=293541c91e42c8df72f535912ad4b75dd335737b56e44300bb145b005c8d5a448cc207653b61&scene=126&sessionid=1681321563#rd](http://mp.weixin.qq.com/s?__biz=MjM5OTk5NDMyMw==&mid=200480629&idx=4&sn=77b1e1b6f2592963bc77ac4a786d94b6&chksm=293541c91e42c8df72f535912ad4b75dd335737b56e44300bb145b005c8d5a448cc207653b61&scene=126&sessionid=1681321563#rd)

互联网金融&金融互联网的蓬勃发展，作为业务技术支撑的Web平台和移动平台，伴随业务的高速发展，安全风险成倍增加。

 

本次沙龙主要围绕当前互联网金融、金融互联网的业务安全热点技术开展，主要结合目前金融行业、互联网行业在互相渗透过程中，业务安全所面临的风险来讨论的。

活动议题包含以下内容：

l 金融互联网业务安全 

l 互联网金融业务安全

l 移动支付安全

l 手机安全和移动web安全

l Web apps隐私、Web服务和数据存储

l Web应用安全

l 如何有效进行安全开发

l 漏洞分析：代码审查、渗透测试、静态分析

l 新技术、新方法、新工具

l 实际操作和软件安全

l 企业安全

l 其他和OWASP和应用安全相关的主题

沙龙名称：金融互联网&互联网金融 安全专题沙龙

沙龙时间：2014年9月25日14:00-18:00

沙龙人数：50-80人

沙龙地点：中国北京 国家会议中心205A

**演讲嘉宾介绍**

汪德嘉博士：

通付盾（PayEgis Inc.）创始人、董事长兼首席执行官。数据分析专家、国际计算机学会(ACM)资深会员。时空码的发明者。拥有十多年美国硅谷软件公司(Oracle, Acosta, VISA, IBM，Lyris及Tulando)的总体设计、产品开发及管理经验，并在硅谷多次参与早期创业(TrueDemand、PlaySpan、M-Factor)，都被世界500强公司收购。历任工程师，主任工程师，总架构师，总监及总裁等职位。拥有美国Universityof Wisconsin at Madison数学博士、中科院软件研究所理学硕士、中国科学技术大学概率统计学士。拥有二十多项国内外技术专利。
