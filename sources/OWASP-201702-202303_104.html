2月24-28日RSA2020大会隆重召开，作为OWASP项目的真爱粉， 大家肯定想知道RSA Session都有哪些OWASP元素呢？



1. Defending Serverless Infrastructure in the Cloud, Eric Johnson, February 25, 2020, 3:40PM- 4:30PM



2. 10 Things I Wish Every Developer Knew about Security, Christopher Romeo, February 26, 2020 8:00AM - 8:50AM



3. Using Open Source and OWASP to Build an Application Security Program, Christopher Romeo, February 27, 2020 9:20AM -10:10AM




01

DevSecOps State of the Union

包含了OWASP Serverless Top 10项目。该项目研究了无服务器环境下OWASP Top 10十大安全风险的情况，提供了在无服务器环境下识别和防护OWASP Top 10十大安全风险的基本参考。


02

Defending Serverless Infrastructure in the Cloud

包含了OWASP Top 10项目和OWASP Dependency-Check项目。OWASP Top 10项目总结了应用程序的十大安全风险，当前版本为2017年版。OWASP Dependency-Check项目提供了一个开源的软件成分分析（SCA）工具，可以帮助用户在软件开发项目中识别软件所依赖的组件是否带有已知安全漏洞，是对OWASP Top 10中“使用带有已知漏洞组件”风险的有力支撑。


03

10 Things I Wish Every Developer Knew about Security

来自OWASP Triangle Chapter的负责人Chris Romeo在大会发表了“10 Things I Wish Every Developer Knew about Security”议题演讲，从“人”的角度探讨了开发人员需要了解的安全知识。正如Chris Romeo在本议题所说：OWASP is a treasure trove of security resources。



来吧，一起看看下面的OWASP项目：



1. OWASP Top 10项目，项目网址：https://owasp.org/www-project-top-ten/

2. OWASP ProActive Controls项目，项目网址：https://owasp.org/www-project-proactive-controls/

3. OWASP API Security Top 10项目，项目网址：https://owasp.org/www-project-api-security/

4. OWASP Cheat Sheets项目，项目网址：https://owasp.org/www-project-cheat-sheets/

5. OWASP Dependency-Track项目，项目网址：https://owasp.org/www-project-dependency-track/

6. OWASP Dependency-Check项目，项目网址：https://owasp.org/www-project-dependency-check/

7. OWASP ZAP项目，项目网址：https://owasp.org/www-project-zap/
