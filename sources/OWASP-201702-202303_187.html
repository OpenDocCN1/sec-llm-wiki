1. 定义和实现安全的编码实践；

2. 就应用程序和基础结构的安全控制提供技术领导、解决方案设计和动手开发支持；

3. 评估、测试、实施和支持第三方安全工具；

4. 通过进行渗透测试和漏洞评估, 识别新的安全威胁；

5. 跨职能协作, 并与各级领导层互动, 以收集安全控制的需求、设计和实施；

6. 构建自动化解决方案, 确保应用基础架构的安全；

7. 与工程团队紧密合作, 将安全编码实践作为工程文化的一部分；

8. 参与安全事件调查。

任职要求：

1、计算机科学本科及以上或同等学历；

2、3年以上应用程序安全经验；

3、3年以上使用至少一种语言(如 python、ruby、java 等) 编写代码或脚本的工作，能够理解和推理用 java 编写的代码；

4、英语能力较强，能作为工作语言。

二、安全技能

1、对安全基础知识有较强的理解 (比如最小权限、攻击面减少、使用加密等)；

2、了解 Web应用程序威胁(例如 OWASP Top 10)、常见攻击和缓解措施；

3、了解应用基础架构威胁、常见攻击和缓解措施；

4、熟悉 DAST、SAST和 IAST工具；

5、有了解安全开发生命周期 (例如威胁建模)的优先；

6、在安全监控工具 (如预警逻辑, 威胁堆栈等) 的经验者优先；

1、以客户为中心的态度；

2、高度协作和影响技能；

3、愿意指导内部或外部团队中的其他成员；

4、获得相关认证的优先（CWASP L2、CWASP CSSP、CWASP CSSD、CISP、CISSP）。


岗位名称：安全架构师（招聘3人）

工作地点：合肥

职位描述：

作为应用程序安全架构师, 您将领导企业开发人员、QA和产品设计团队一起紧密协作地完成安全相关的活动, 在快速发展的敏捷开发环境中推动整个开发和测试过程中S-SDLC相关的安全实践和技术解决方案。该角色将侧重于在复杂和快速的开发环境中设计和指导安全体系结构、应用程序和基础结构设计、开发实践和测试方法的实施。作为优秀的安全架构师，在安全体系结构实践、安全编码实践、安全测试工具、通用开发和QA流程、敏捷方面拥有强大的专业知识, 能给企业安全方向带来愿景。

岗位职责：

1、熟悉应用程序安全、安全体系结构，以及以S-SDLC为核心的安全活动开发安全指标和度量方法、标准，能指导企业完成相应的安全活动；

2、协助完成软件部署、集成和业务功能相关安全功能设计和解决方案；

3、评估系统架构, 以确定潜在的安全威胁和漏洞并确定其影响；

4、与相关方协调并监控补救活动；

5、提供相关修复应用程序漏洞的指导和建议；

6、推荐并促进有针对性的应用程序安全培训, 包括开发和实施安全代码培训计划, 以突出软件漏洞和防御措施；

7、建立相关流程和方法, 以提高信息安全的透明度；

8、在整个S-SDLC生命周期内进行应用程序安全测试质量保证 (QA), 以验证测试过程；

9、保持对常见安全漏洞、攻击媒介、攻击方法和补救技术的深入了解；

10、通过设计和构建原型、概念证明、确保架构签收、提供设计文档和标准以及创建用户情景来推动安全要求。

任职要求：

1、计算机科学本科及以上，或同等学历；

2、10年以上的经验, 包括在安全架构、应用和网络渗透测试、安全软件开发和/或 QA 方面的详细技术知识和实践实践；

3、详细了解Web、移动和客户端应用程序安全漏洞、攻击方法和对策技术；

4、具有广泛的攻击类和漏洞检测类软件、其工作原理和传播方法的经验；

5、有代码评审的经验；

6、了解现有的安全测试工具技术，比如SAST，DAST和IAST等；

7、有部署和使用多种开源和商业安全开发和测试工具 (代码扫描仪、模糊扫描、在安全测试中使用代理等) 的经验；

8、有针对特定环境和用例构建安全测试工具和脚本的经验, 以及为演示问题而制作概念验证的能力；

9、有将安全设计和安全开发实践引入敏捷开发环境、QA团队和产品的经验方法等；

10、对安全应用程序体系结构、加密技术、加密和密钥管理、应用程序权限的认证和控制以及相同的实现具有专业知识；

11、熟悉 Web应用程序开发和编程语言（如java）。曾有编程经验, 有与产品经理、QA团队和应用程序开发人员合作的经验；

12、能够执行威胁建模或使用其他风险识别技术；

13、优秀的技术文档技能；

14、获得相关认证的优先（CWASP L2、CWASP CSSP、CWASP CSSD、CISP、CISSP）。

开源网络安全技术有限公司

开源网络安全技术有限公司（简称：SecZone）成立于2013年5月，是国内软件安全行业创领者和领先的软件安全开发生命周期（S-SDLC）解决方案提供商，专注于软件安全领域技术研究。SecZone团队由来自思科、微软、惠普、Google、华为等行业顶级的安全专家组成，团队成员从业经验均为10年以上。SecZone总部在深圳，同时在北京、武汉、合肥、成都、南宁设有分支机构。

SecZone始终以自主创新为发展源动力，以S-SDLC解决方案为核心，以S-SDLC平台为载体，向不同行业的客户提供覆盖软件开发全生命周期的软件安全开发咨询和落地服务，包括但不限于安全开发培训、安全需求识别、安全架构设计、安全代码实现、安全确认、安全审核及安全运营的完整业务生态，同时提供配套的工具链支持。帮助客户提升软件安全开发能力，构建安全可靠的软件产品。

未来，SecZone将持续聚焦软件安全领域，努力成为全球软件安全领域极具竞争力的领导品牌。
