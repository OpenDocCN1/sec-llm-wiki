# **从蜜罐到欺骗防御**

20:10-20:50  王文君

**王文君**

**议题大纲**

近年来，数据泄漏、网络攻击等呈爆发态势，勒索软件、APT攻击等新型攻击方式也日渐猖狂。面对威胁，传统的基于边界防护不能及时准确的检测和防范，这时可以考虑将基于仿真欺骗技术引入纵深防御链条，使之能1）低误报率的提供实时有效威胁报警 2）高交互性的仿真系统拖住攻击者 3）基于虚拟化的可编排技术实施自适应动态欺骗 4）作为安全情报提供方与其它已有安全投资一起协同保护企业安全。
