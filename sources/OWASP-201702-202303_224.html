OWASP AppSec最新工具项目分享

在2018年10月12日结束的OWASP AppSec USA 2018大会中，一些新的OWASP工具类项目在大会上得到了展示。为了让OWASP中国区域的会员们了解到这些项目，OWASP中国初步整理了相关项目的信息，并分享给大家。


01





OWASP Amass项目

OWASP Amass项目是一个基于Go语言的深度DNS枚举和网络映射工具。它能够帮助企业组织其呈现和暴露在互联网上的安全盲点，并提供30个被动数据源来分析目标域的DNS命名空间。


02





OWASP Code Pulse项目

OWASP Code Pulse项目提供的工具，能够让应用安全测试进程明确地告知测试人员应用程序的哪些部分已被测试。Code Pulse以可视化方式实时呈现测试覆盖率信息，便于测试人员了解应用程序的哪些部分已被覆盖。同时，基于覆盖范围，实时反馈覆盖率给测试人员，以帮助测试人员轻松调整测试活动。


03





OWASP Dependency Track项目

OWASP Dependency Track项目提供的工具，可以帮助企业组织在节约时间成本的同时，保障其软件中使用的第三方组件和开源组件的安全性。同时，Dependency Track是一个软件构成分析（SCA）平台，它能够跟踪企业组织创建或使用的所有应用程序中使用的第三方组件，并主动识别安全漏洞。


04





OWASP Glue Tool项目

OWASP Glue Tool项目提供的工具，旨在帮助企业在执行DevSecOps和安全测试时不会降低原有的软件开发进度。Glue Tool可以协调运行多个SAST工具、DAST工具。作为自动化进程的一部分，它会自动将扫描结果提交给JIRA或其他跟踪系统，以便解决这些问题。


05





OWASP SEDATED项目

OWASP SEDATED项目（英文全称为：Sensitive Enterprise Data Analyzer To Eliminate Disclosure）侧重于防止敏感数据（如：用户凭据和令牌）被推送到GitHub。开发人员不断推动对GitHub的更改，这可能将包含敏感数据的信息提交到GitHub。SEDATED能够捕捉这些敏感数据和防止敏感数据泄露。


有关项目的更多信息，请关注OWASP中国的后续报道。
