CWASP CSSP培训成果上海某日资企业安全从业者

  

　**培训效果**　

开阔眼界，了解了很多以前不知道的工具

知道了自己在那方面的知识有欠缺需要学习

对如何改善工作流程有了一个大致的概念

　**实际运用**　

已经开始逐步实现公司内产品开发的**安全测试左移。**

我们公司现在已经有两个人参加完CWASP CSSP的相关培训和考试。

**在培训后根据学到的一些安全部署安全测试左移的知识，向公司提案后，经过约半年左右的实践目前已经基本上可以在不影响开发release速度的情况下进行安全测试了****。**我们公司现在采用scrum的模式进行产品开发，一个sprint的周期约为2周

**目前已经实现：**

1.  开发式样确立后与其他功能测试同步进行安全测试观点的梳理和测试式样的编写工作。（原本是在实装后进行测试要比开发晚一个sprint，由于发布的时候还没有进行安全测试，产品release的时候存在安全风险。）
    
2.  在开发完成并实装后，可以与功能测试同时进行公司内的安全测试并与功能测试在同一周期完成测试。完全不影响scrum的进度。这样的高效率也得到了开发团队的一致肯定，*现在基本上不会有开发人员以影响开发进度的理由要求简化安全测试内容。*
    

  

**下阶段目标：**

1.  将安全测试左移到开发式样确立之前，在**需求分析阶段**分析出需求本身的安全风险
    
2.  在开发式样确立阶段，提出可能存在的安全隐患，帮助**开发人员在开发过程中**提升安全意识防止漏洞发生。
    

　**培训改善建议**

*   现在4天的课程实在是有点赶，开发和测试的一些技巧基本上没有时间演示
    
*   适当延长1天培训时间，增加个1000的费用问题其实不大

![](../Images/aac8135522ddc1e15c4f8cbf79b9636d.png)**CWASP CSSP 架构**

CWASP CSSP认证课程以软件安全开发生命周期（S-SDLC）为核心，内容根据SecZone在网络安全、互联网、金融、通信等行业的软件安全开发实践积累和专家经验总结而成。认证内容注重软件安全开发全生命周期的方法论与应用技术，紧密结合当前主流的网络安全和软件开发工具、技术和流程。

**CWASP CSSP 认证单位**

**中国信息安全测评中心，**是我国专门从事信息技术安全测试和风险评估的权威职能机构。依据中央授权，测评中心的主要职能包括：负责信息技术产品和系统的安全漏洞分析与信息通报；负责党政机关信息网络、重要信息系统的安全风险评估；开展信息安全服务和专业人员的能力评估与资质审核等。

**CWASP CSSP 分类**CWASP CSSP主要从事网络信息系统软件开发的相关工作，其具备一定的软件安全开发知识和技术，能在软件开发生命周期中提供必要的安全保障。根据认证者的基础不同， CWASP CSSP共分为两种，两个认证无先后顺序：

*   注册软件安全开发人员（Certified Secure Software Developer，简称CWASP CSSD）。证书持有人员主要从事软件开发领域的工作。
    
*   注册软件安全专业人员（Certified Secure Software Professional，简称CWASP CSSP）。证书持有人员主要从事软件开发领域的技术与管理工作。
