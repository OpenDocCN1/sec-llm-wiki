CWASP CSSP （Certified Secure Software Professional）系经中国信息安全测评中心认定的软件安全专业人员，是对我国网络信息系统软件开发人员安全开发能力实施的一种资质评定。 CWASP CSSP主要从事网络信息系统软件开发的相关工作，其具备一定的软件安全开发知识和技术，能在软件开发生命周期中提供必要的安全保障。证书持有人员主要从事软件开发领域的技术与管理工作。

注册软件安全专业人员（Certified Secure Software Professional，简称CWASP CSSP）面向金融、互联网、通信、能源、政府等所有涉及到软件开发、软件平台运营的公司、部门及个人。面向软件开发生命周期相关人员，并需具备至少三年相关工作经验：

*   软件架构师、软件开发工程师、软件测试工程师；
    
*   应用程序安全专家、渗透测试人员；
    
*   团队领导和经理、信息安全经理、软件项目经理、IT总监/经理；
    
*   其他从事软件开发生命周期专业人员。
    

**个人收益**

•    具备当今全球软件研发行业主流的“软件安全开发全生命周期（S-SDLC）”相关技术与技能。

•    掌握软件安全开发全生命周期中各环节核心实践的关键技术内容和技能；

•    进一步提升就业的核心竞争力，获得更多领军企业的工作机会；

•    获得由中国信息安全测评中心颁发的人员资质认证。

  

**企业收益**

•    为建立自有的软件安全开发流程配置人员基础和技术储备；

•    在软件研发过程中尽可能消除软件安全风险，降低后期软件安全漏洞弥补和事件响应的成本投入；

•    避免软件安全漏洞，保障企业形象，维护市场声誉；

•    提资增效，为获得中国信息安全测评中心的“信息安全服务（安全开发类）资质”奠定人员基础；

•    维护并践行《国家网络安全法》，响应并落实《国家网络空间安全战略》
