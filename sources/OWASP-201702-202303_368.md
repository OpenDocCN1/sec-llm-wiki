# SecZone参与第四届国家网络安全宣传周广东省活动

作为今年国家网络安全宣传周期间的重头戏之一，“2017第四届广东省网络安全宣传周暨网络安全技术及成果展示会”9月18日在广州正式拉开帷幕。SecZone携手OWASP中国、应用安全联盟（ASC）、国测CWASP CSSP培训认证、WAF测评等合作组织及网络安全行业服务方案亮相。

![](../Images/eb3a115c581c45d88eb1374e063a2c10.png)

国家网络安全宣传周迄今已举办四届，今年网络安全宣传周于9月16日-24日在全国范围内统一举行，主题是“**网络安全为人民，网络安全靠人民**”，由中央宣传部、中央网信办、教育部、工业和信息化部、公安部、中国人民银行、新闻出版广电总局、全国总工会、共青团中央等九部门共同举办。据悉，主办方将在广东全省范围内组织开展网络安全宣传教育活动，展示和推广网络安全技术，普及网络安全知识和防护技能。展示会分为云计算和大数据安全、智慧城市、公共网络领域安全控制、电子政务安全、关键信息基础设施安全、金融网络安全、智能制造、网络娱乐安全等8个功能区，汇集160多家参展企业

**SecZone****作为国内首个独立、开源、专注于应用软件安全的互联网安全研究与创新机构**，积极响应国家号召，已连续多届参与国家网络安全宣传周系列活动。为普及全民网络安全意识、强化软件研发机构应用软件安全开发知识、促进我国网络安全产业发展进程提供了巨大助力。

![](../Images/dcbc1716b1b55dfb65b3509fa0df13d7.png)

“**没有软件安全，就没有网络安全**”。SecZone秉承**创新**、**融合**、**开拓**的宗旨，不断吸收国内外最新、最专业的软件安全技术，并创新性运用于国内各个行业的软件研发工作体系中，从应用软件层面推动国内互联网安全技术的发展。

**OWASP 中国**

OWASP是一个开源的、非盈利的全球性安全组织，致力于应用软件的安全研究。目前OWASP全球拥有220个分部近六万名会员，共同推动了安全标准、安全测试工具、安全指导手册等应用安全技术的发展。近几年，OWASP峰会以及各国OWASP年会均取得了巨大的成功，目前OWASP 中国已有会员6000余人，举办国内安全活动100多场。

  

**应用安全联盟**

应用安全联盟是由行业专家、应用安全厂商、应用安全行业用户的代表共同成立的认同开源安全技术以及最佳实践安全标准的非盈利组织。作为一个专业的应用安全群体，我们致力于建立行业应用安全基准、促进行业技术交流，为厂商、用户、安全从业人员提供技术指导。

  

  

**CWASP CSSP认证**

为积极贯彻《网络安全法》、《国家网络空间安全战略》的相关要求，推进国内软件研发领域的整体软件安全研发能力发展，系统性提升我国软件研发领域从业人员的软件安全开发意识及专业水平，中国信息安全测评中心推出“注册软件安全专业人员”（Certified Secure Software Professional，简称 CWASP CSSP）培训认证体系。该体系覆盖了软件安全开发全生命周期（S-SDLC：Secure Software Development Life Cycle）各环节的知识点。
