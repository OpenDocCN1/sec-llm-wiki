为积极贯彻《网络安全法》、《国家网络空间安全战略》的相关要求，推进国内软件研发领域的整体软件安全研发能力发展，系统性提升我国软件研发领域从业人员的软件安全开发意识及专业水平，中国信息安全测评中心推出“注册软件安全专业人员”（Certified Secure Software Professional，简称CWASP CSSP）培训认证体系。该体系覆盖了软件安全开发全生命周期（S-SDLC：Secure Software Development Life Cycle）各环节的知识点。

CWASP CSSP已在深圳、杭州、武汉、成都等地成功开班，吸引了政府机构、通讯行业、金融行业、互联网行业、教育行业的软件研发团队、软件供应商、安全团队和高校学生的积极参与。参培学员均表示提高了对软件开发过程中有关软件安全威胁的认识，掌握了软件安全开发的相关技术，对实际的研发工作有巨大帮助。CWASP CSSP 合作伙伴也在各地积极展开培训工作，持续助力！

CWASP CSSP 

注册软件安全专业人员

注册软件安全专业人员（Certified Secure Software Professional，简称CWASP CSSP）面向金融、互联网、通信、能源、政府等所有涉及到软件开发、软件平台运营的公司、部门及个人。面向软件开发生命周期相关人员，并需具备至少三年工作经验：

  • 软件架构师、软件开发工程师、软件测试工程师；

  • 应用程序安全专家、渗透测试人员；

  • 团队领导和经理、信息安全经理、软件项目经理、IT总监/经理；

  • 其他从事软件开发生命周期专业人员

  CWASP CSSP  4200元/人

   费用包含：培训费、考试费、认证费、三年证书维持费、教材费

CWASP CSSD

注册软件安全开发人员

注册软件安全开发人员（Certified Secure Software Developer，简称CWASP CSSD）,面向金融、互联网、通信、能源、政府等所有涉及到软件开发、软件平台运营的公司、部门及个人，包括：

  • 高校学生；

  • 软件开发人员；

  • 软件测试人员；

  • 软件运维人员；

  • 软件开发运营团队经理、项目经理等。

 CWASP CSSD  1000元/人

   费用包含：培训费、考试费、认证费、三年证书维持费、教材费
