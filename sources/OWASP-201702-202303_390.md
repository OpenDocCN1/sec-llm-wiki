**成都 CWADP CSSD 第一班**

培训项目：CWASP CSSD （注册软件安全开发人员）

培训时间：2017年8月9-10日

考试时间：2017年8月11日

培训地点：成都 028-62614069

  

**CWASP CSSD****注册软件安全开发人员**（Certified Secure Software Developer）**，**面向金融、互联网、通信、能源、政府等所有涉及到软件开发、软件平台运营的公司、部门及个人，包括：  

*   高校学生；
    
*   软件开发人员；
    
*   软件测试人员；
    
*   软件运维人员；
    
*   软件开发运营团队经理、项目经理等。
    

![](../Images/eafbea446f5128c141f5eb0abad05c1f.png)

**CWASP CSSP****注册软件安全专业人员**（Certified Secure Software Professional），面向金融、互联网、通信、能源、政府等所有涉及到软件开发、软件平台运营的公司、部门及个人。面向软件开发生命周期相关人员，并需具备至少三年工作经验：  

*   软件架构师、软件开发工程师、软件测试工程师；
    
*   应用程序安全专家、渗透测试人员；
    
*   团队领导和经理、信息安全经理、软件项目经理、IT总监/经理；
    
*   其他从事软件开发生命周期专业人员
