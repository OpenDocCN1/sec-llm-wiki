CWASP CSSP暑期班！

CWASP CSSD 注册软件安全开发人员

2天培训+0.5天考试 1000元/人  


CWASP CSSP 注册软件安全专业人员  

 4天培训+0.5天考试  4200元/人 


发证机构：中国信息安全测评中心


CWASP CSSD 面向对象

注册软件安全开发人员（Certified Secure Software Developer，简称CWASP CSSD）,面向金融、互联网、通信、能源、政府等所有涉及到软件开发、软件平台运营的公司、部门及个人，包括：

  • 高校学生；

  • 软件开发人员；

  • 软件测试人员；

  • 软件运维人员；

  • 软件开发运营团队经理、项目经理等。

CWASP CSSD 知识体系

  • 应用安全威胁：主要介绍以“OWASP TOP 10”系列为核心的应用安全威胁及应用安全威胁实例。

  • S-SDLC流程：主要介绍软件安全开发全生命周期的流程及安全管控措施。

  • 软件安全开发：主要介绍软件开发过程中涉及到的安全技术知识和实践。

CWASP CSSP（注册软件安全专业人员）旨在系统性的丰富和完善软件开发专业人员关于软件开发生命周期各环节的专业知识和能力。适用于软件开发生命周期各环节中的专业人员。

CWASP CSSP 面向对象

注册软件安全专业人员（Certified Secure Software Professional，简称CWASP CSSP）面向金融、互联网、通信、能源、政府等所有涉及到软件开发、软件平台运营的公司、部门及个人。面向软件开发生命周期相关人员，并需具备至少三年工作经验：

  • 软件架构师、软件开发工程师、软件测试工程师；

  • 应用程序安全专家、渗透测试人员；

  • 团队领导和经理、信息安全经理、软件项目经理、IT总监/经理；

  • 其他从事软件开发生命周期专业人员

CWASP CSSP 知识体系

  • 应用安全威胁：主要介绍以“OWASP TOP 10系列”为核心的应用安全威胁及应用安全威胁实例。

  • S-SDLC：主要介绍软件开发过程中有关S-SDLC流程、实施和成熟度模型的知识。

  • 软件安全架构设计：主要介绍软件架构设计过程中有关设计安全和威胁分析的安全知识及实践。

  • 软件安全开发：主要介绍软件开发过程中涉及到的安全技术知识和实践。

  • 软件安全测试：主要介绍软件测试过程中有关安全测试的基本知识与流程，渗透测试的知识。

  • 软件安全部署：主要介绍软件安全部署过程中有关软件部署过程、软件自身安全和基础环境安全的知识。
