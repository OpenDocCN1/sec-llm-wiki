# 新增活动 | 高校网络安全人才培养

网络安全人才市场供求严重失衡，毕业生收入高居计算机行业榜首，人才市场缺口已在50万以上，且每年的需求缺口仍然不断增大。

国内暂时没有成熟的网络安全应用型人才培养体系与机制，也没有成形的网络安全教学产研模式。高校网络安全教学师资/项目型师资奇缺,教学实验内容陈旧，与网络安全技术的飞速发展严重脱节。

  

*   时间：7月7日 9:00-12:00
    
*   地点：深圳  报名审核通过后邮件通知
    
*   组长：王厚奎
    
*   形式：圆桌式；主题演讲+面对面分组讨论
    

**主讲嘉宾：**王厚奎，OWASP中国广西区域负责人****

硕士研究生，CISP（CISO）、NISP、网络规划设计师、等保测评师、NSACE网络信息安全讲师、中国信息安全测评中心CISI讲师。现任南宁职业技术学院副教授、广西网络信息安全服务研究院副院长，是中国计算机学会、广西信息安全学会、广西网络信息安全协会会员。拥有8年信息安全实践经验和教学人才培养经验，涉及网络管理、信息安全与风险管理、网络攻防、渗透测试，对国内高校网络安全人才培养有深入认识。

王厚奎从2010年起积极参与OWASP中国地区工作，曾先后参与OWASP中国组织、开展的“OWASP Application SecurityVerification Standard Project (ASVS) ”、“OWASPHacking-Lab Project”、“OWASP Internet of Things Project”等多个项目。  

  

**研讨框架：**

*   高校网络安全人才培养的特征
    
*   行业市场网络安全用人才实际需求
    
*   高校网络安全人才培训的选择与道路
    
*   与OWASP中国联合培养实用性网络安全人才的实践与心得
    

**活动议程：**

09:00-09:30 嘉宾入场签到

09:30-10:15 高校人才培养特征与行业需求

10:15-10:30 茶歇

10:30-11:00 高校人才培养的疼与苦

11:00-11:30与OWASP中国开展人才培养的实践与心得

11:30-12:00 自由讨论

12:00 -12:05合影&结束
