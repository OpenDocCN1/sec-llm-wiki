# 中国信息安全测评中心与SecZone联手打造CWASP系列认证

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTk5NDMyMw==&mid=2652093896&idx=1&sn=af0e45bb07572ff0311d741cb6d7fce5&chksm=bcd5eb748ba262623454b32931ed0a894d45ff0894107794889156eaf5ae482a4950d043920e&scene=126&sessionid=1681321541#rd](http://mp.weixin.qq.com/s?__biz=MjM5OTk5NDMyMw==&mid=2652093896&idx=1&sn=af0e45bb07572ff0311d741cb6d7fce5&chksm=bcd5eb748ba262623454b32931ed0a894d45ff0894107794889156eaf5ae482a4950d043920e&scene=126&sessionid=1681321541#rd)

        为了进一步提升国内软件行业的安全竞争力，加强国内软件安全领域从业人员的安全意识及专业水平，中国信息安全测评中心（以下简称“测评中心”）与深圳开源互联网安全技术有限公司（以下简称“SecZone”）共建软件安全专业人员认证体系。该体系基于软件安全开发生命周期（S-SDLC：Secure Software Development Life Cycle）整理出的一套适应于广大软件开发人员的知识体系，此项认证的目的在于提高我们软件开发人员整体的安全意识及安全开发技能，加快我国软件安全专业人员的系统培养，不断开拓创新，为广大软件安全人员提供优质、专业的服务。 双方将在**CWASP CSSD**（**注册软件安全开发人员**）、**CWASP CSSP**（**注册软件安全专业人员**）、**CWASP CSSI**（**注册软件安全讲师**）课程开发、培训管理、市场推广等方面开展全面、深入的合作，共同推动国内CWASP认证体系的建设和相关业务的健康有序发展。

        根据协议，双方将共同建立CWASP CSSD、CWASP CSSP、CWASP CSSI认证体系，及相关的专家指导委员会、认证考试中心和培训管理中心；推进认证相关的培训课程开发，形成包括教学课件、学员手册（教材）、教师手册、案例练习册、实验手册等在内全套教学内容；并建立起涉及授权培训机构、组织招生教学、管理教务、课程质量管理体系、讲师队伍管理等多个环节的授权培训体系。

       测评中心是我国专门从事信息技术安全测试和风险评估的权威职能机构，是国家信息安全保障体系中的重要基础设施之一，拥有国内一流的信息安全漏洞分析资源和测试评估技术装备，建有漏洞基础研究、应用软件安全、产品安全检测、系统隐患分析和测评装备研发等多个专业性技术实验室。在本次合作中，国测中心将充分发挥自身的资源优势和平台优势，负责CWASP系列认证体系和标准的建设及专家指导委员会、授权认证考试中心等相关机构的组建和管理，并对项目实施实行全流程的质量监管，确保认证的规范性和权威性。

      深圳开源互联网安全技术有限公司（SecZone），致力于软件安全开发生命周期（S-SDLC：Secure Software Development Life Cycle）的技术研究、推广等，提供咨询、培训、服务、产品等解决方案。在本次合作中，SecZone将充分发挥自身的专业优势和市场优势，作为CWASP CSSD（注册软件安全开发人员）、CWASP CSSP（注册软件安全专业人员）、CWASP CSSI（注册软件安全讲师）认证业务的全国独家授权培训管理中心，具体负责在全国范围内组织开展CWASP CSSD、CWASP CSSP、CWASP CSSI培训业务。

相关培训业务的细节也将于近期在SecZone官方网站、微信发布，敬请留意。
