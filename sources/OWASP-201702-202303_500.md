# OWASP中国启动2017年重点项目

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTk5NDMyMw==&mid=2652093896&idx=2&sn=68a5fea44b01aa996d3b7b01592e74bb&chksm=bcd5eb748ba26262baae0119c3934f779f66cc05d820b0670b8c6f7221d999a7e6e0b0f97e55&scene=126&sessionid=1681321541#rd](http://mp.weixin.qq.com/s?__biz=MjM5OTk5NDMyMw==&mid=2652093896&idx=2&sn=68a5fea44b01aa996d3b7b01592e74bb&chksm=bcd5eb748ba26262baae0119c3934f779f66cc05d820b0670b8c6f7221d999a7e6e0b0f97e55&scene=126&sessionid=1681321541#rd)

![](../Images/b9b207f8aaebd36358544fe61d05ecb0.png)2017年是OWASP中国发展进入第二个十年的起步之年。全年，OWASP中国将继续秉持专业、开放、服务、共赢的根本宗旨，进一步积极完善安全技术体系，促进业界交流合作，加强专业人才培育，为推动我国乃至全球的互联网安全技术和产业发展做出更积极的贡献。其中，OWASP中国将集中推进实施两大重点项目**：**

1、**全面启动OWASP重要技术文档编译工作**

该项目将集中力量对OWASP Developer GuideProject、OWASPCode Review Guide Project、OWASP Application SecurityVerification Standard Project (ASVS)等重要技术文档的最新版本进行编译，内容涉及开发、测试及全生命周期管理等SDLC各不同阶段，为广大业界同行提供最前沿、最系统的技术资料。

**2、全面启动OWASP安全意识TOP TEN项目**

该项目旨在通过对国内公开的最新、最真实的安全事件进行收集、分类和分析，形成年度安全意识TOP10并予以发布，以引起大众对安全的高度关注，进一步有效提升全民安全意识。
