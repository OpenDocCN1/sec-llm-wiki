# 对LiqunKit工具的调查与结论

昨晚同事反馈了我一个消息，说是这个jar工具有后门，然后我就今天午休的时候午觉没睡就深入看了下。

![](../Images/402284cf558554119b7f2cda18b06ad3.png)

  

从网上找到一个报毒的文件，解压后查到一个可疑的hta文件，sethc.exe文件实际为cmd.exe程序，属于系统的正常文件。

![](../Images/702798ad630285847b14bfe3e0ebdf47.png)

  

打开后发现实际运行的是powershell脚本内容：

![](../Images/995319bef3877401ded76f8850beedc4.png)

  

一层层解密得到如下：

![](../Images/36c365b8f96f89086b09cca39dc70a65.png)

  

最终异或35后进行解码，分配内存执行shellcode。

![](../Images/1a15009ee7e45cf5c3afbb2a300d2fc4.png)

  

实际的shellcode如下，很明显的CS的shellcode特征。

![](../Images/6c1ded72995d1b3b431dfc10522e195f.png)

  

回连地址为time.date-windows.com，hta文件在野外最早出现时间为2021年5月12日，关联到多数据库利用工具MDUT，时间是2021年6月17日。

![](../Images/469f4c589b98c5d22f2e108b68b4a290.png)

![](../Images/016b21d3474a6b0870031e9455d66312.png)  

  

time.date-windows.com早已经过期了，但是昨天11月30日又被人重新注册了。

![](../Images/9f333683ba0beb017fda9b4e629d4fb7.png)

![](../Images/25c26f1b083dede44d0debdcfe964ce7.png)

  

  

后续LiqunKit作者也发了更新，表示是从MDUT工具直接克隆过来的，这个文件LiqunKit作者自己也不清楚。

![](../Images/c276b790073f3f849da78c875bbdad35.png)

  

然后就是一个劲的怀疑，甚至于不调查就开始下阴谋论的结论。

![](../Images/fe20ae185b5534d7125fe1931ff6ac8a.png)

![](../Images/4c695ba18fa99a5592adadca100fb057.png)

![](../Images/5a2bd1a3628fe858f3da0eb820fcad14.png)

  

后续经过调查发现是个意外事件，最初来源的项目里的hta文件没有被留意到，就一起打包上传了，也不是啥国外阴谋论。但是要注意的是这个文件是单独放置的，MDUT项目的逻辑里并没有代码会加载执行它，可以理解为一个被遗忘的测试文件（毕竟很多安全人员也会生成一些测试的payload），经过实际分析cs木马也很简单，回连域名早已经过期了，目前github项目已经删除了对应文件。

![](../Images/9d15cf2222551ce8f26e4c13b910430e.png)
