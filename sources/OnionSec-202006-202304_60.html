对于恶意Office文档发现仅包含VBA源代码，而没有已编译的代码（P-Code）。我们称这种技巧为“VBA Purging”技术，此类文件更有可能逃避反病毒检测。



VBA Purging技术

恶意Office文档将其VBA代码存储在“复合文件二进制格式”（Compound File Binary Format & CFBF）文件流中，每个VBA模块、类都存储在其自己的模块流中。模块流包含与版本和实现有关的PerformanceCache数据（已编译的VBA代码，也称为P-Code），其后是CompressedSourceCode数据（已被微软的专有算法压缩过的VBA源代码数据）。 


在2016年，Vesselin Bontchev暗示了一种可以删除/更改已压缩的VBA源代码并执行P-Code的技术。在2018年底，该技术被称为“VBA stomping”。我们当时的研究表明，在保持VBA源代码完整、随时可以执行的同时，也可以删除PerformanceCache数据(已编译的VBA代码，也就是P-Code）。我们称这种技术为“VBA purging”(缓存清除)。


PerformanceCache数据和CompressedSourceCode数据之间的边界由每个模块流的MODULEOFFSET定义，该MODULEOFFSET是存储在每个模块流的dir流中的一条记录。 


要删除PerformanceCache数据，必须删除其字节，以便CompressedSourceCode数据从位置0x0000（流的开头）开始。模块流的大小必须相应减小，并且MODULEOFFSET记录必须指向0x0000位置。


PerformanceCache数据也存在于_VBA_PROJECT流和SRP流中，VBA purging技术意味着要从_VBA_PROJECT流中删除PerformanceCache数据，并完全删除SRP流。

VBA Purging工具

有一些工具可以创建Office文档，而无需依赖微软Office组件，例如.NET库EPPlus，使用此库创建的Excel文档不包含性能缓存数据。VBA专业开发人员还使用了一些商业工具，像这些工具一样，可以在发行前清理其文档。我们不能确切地知道在此文档上使用了什么工具来实现VBA Purging，但不仅仅是将其保存在PowerPoint中。当使用MS Office创建带有VBA代码的文档时，它将包含PerformanceCache数据和CompressedSourceCode数据。缺少PerformanceCache数据意味着该文档是使用其他工具创建/清除的。



检测

删除恶意文档的性能缓存数据可以减少反病毒检测的机会。以下是一个示例。沃尔玛的红队在其演示文稿中使用了恶意文档a668657023e2c9c12dabad14c8f905e4。它在VirusTotal（2019年12月27日）上进行了44/61次检测：


模块流包含PerformanceCache和CompressedSourceCode数据。然后，沃尔玛的红队通过用空字节覆盖CompressedSourceCode变量来“VBA stomped”该文档。这导致VirusTotal的检测率大大降低（他们在2018年4月进行测试时为7/58对比36/59）。当我们采用沃尔玛的红队案例删除PerformanceCache数据时，我们还发现VirusTotal的检测率较低（2019年12月22日为16/58）：


当然，这只是VirusTotal上的一个示例。与在VirusTotal上进行静态AV扫描相比，在生产环境中使用完全可操作的杀软时，你的体验可能会大不相同。


杀软不是唯一会受到VBA Purging负面影响的技术，IDS和YARA规则同样也会影响，因为它们会依赖于仅在PerformanceCache数据中找到的字符串来作为检测点。例如，通常在恶意Office文档的VBA源代码中用于创建ActiveX对象（例如HTTP对象）的字符串CreateObject只会出现在PerformanceCache数据中。有IDS和YARA规则依赖于此字符串的存在。不过它也出现在VBA源代码中，但由于经过压缩，它没有作为完整的字符串出现在CompressedSourceCode数据中。



结束语

VBA Purging会使用VBA代码从Office文档中删除PerformanceCache数据，而不会影响代码执行。它可能会影响杀软检测，并且肯定会影响IDS和YARA规则的有效性，这些规则依赖于仅在PerformanceCache数据中找到的字符串。如果你使用或开发这样的规则，我们鼓励你根据这里提供的信息对它们进行审查。与VBA stomping不同，VBA Purging并不是攻击者的明显标志，有一些合法的工具可以创建没有PerformanceCache数据的文档或将其从现有文档中删除。
