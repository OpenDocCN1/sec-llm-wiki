**疑惑**

提个问题，当在Windows系统上发现这个文件夹时会存有疑问，Mac OS中zip压缩包文件中中的\_\_MACOSX隐藏文件夹里面有什么？  

  

当用户使用Mac OSX中的内置zip压缩器压缩文件时，它会在提取的zip中创建一个名为“ \_\_MACOSX”的额外文件夹。所以现在的问题是这些文件是干嘛的？换个角度则是对于安全研究来说，有没有帮助？

  

\_\_MACOSX的信息

\_\_MACOSX”包含正在压缩的文件夹结构的复制，其中隐藏文件以点开头，而不是实际文件。这些“隐藏”文件不是空的，它们是保存元数据的二进制文件。

  

隐藏文件是以AppleDouble格式编写的（RFC 1740），该格式最初用于在Unix系统上存储其他元数据，利用file命令可得到文件的原格式，即使不知道原格式，也可以通过十六进制数据查看获取一些信息。

unzip -d swop SWOP2013\_and\_GRACoL2013\_ICC\_Profiles.zip

file swop/\_\_MACOSX/.\_GRACoL2013\_CRPC6.icc

\# swop/\_\_MACOSX/.\_GRACoL2013\_CRPC6.icc: AppleDouble encoded Macintosh file

  

实践一下，hvv期间从公开渠道拿到的一个样本（非涉密），解压后出现了\_\_MACOSX文件夹，表明最后一个接触该文件的用户是在MacOS环境，以下提供的案例里记录了文件的一些元数据，表明是用户是通过Chrome从阿里云存储下载的该样本文件，而且来源也记录下来了，不得不说比Windows上信息要全，溯源可以参考下。
