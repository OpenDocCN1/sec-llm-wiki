# 页面构建器插件ELEMENTOR中的漏洞影响了超过400万个WORDPRESS网站

当在软件开发中报告新的安全漏洞时，它将启动漏洞测试之间的竞争在负责纠正该专家与想要利用该漏洞的网络犯罪分子。对于最常用的产品（例如某些WordPress插件），这一点尤其值得注意。  

  

全球最受欢迎的插件之一Elementor提出了一个名为XSS Authenticated Reflection的漏洞，利用该漏洞，威胁行为者可以在WordPress上运行脚本从另一个站点站点以部署恶意活动，例如盗窃访问凭据。

  

漏洞测试专家提到，该漏洞取决于例如使用搜索框在易受攻击的站点中加载脚本的情况。下面描述了一种可能的利用场景：

*   威胁参与者为攻击创建了专门设计的URL
    
*   当受害者遵循URL时，将运行外部站点上托管的脚本。
    
*   黑客将向目标用户发送链接，以从受攻击的网站窃取其凭据
    

此漏洞已在WordPress漏洞数据库中报告，该平台包含有关在内容管理系统及其最受欢迎的插件中发现的任何漏洞的更新信息。管理员报告说，为了避免在野外进行开发，概念证明至少要到2月12日才会公开。

  

该漏洞由安全公司Impenetrable.tech发现，并 尽快将其报告给Elementor编辑。WordPress视觉生成器开发人员立即修复了该漏洞。漏洞完成修复后，便会公开披露。

  

国际网络安全研究所（IICS）的漏洞测试专家提到，该漏洞影响Elementor 2.8.4及更早版本。新版本2.8.5必须从WordPress网站的管理界面进行更新。登录后，您会在WordPress页面上找到更新链接；否则，您可以从网站管理员侧边栏更新插件。
