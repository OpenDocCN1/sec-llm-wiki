新发行版KALI LINUX 2020的最佳功能

Kali Linux的开发人员，这是世界上最广泛使用的黑客操作发行版之一，刚刚宣布发布了Kali 2020.1，这是今年的第一个主要操作系统更新，它有望包括多项更改和实质性改进，对所有人有用渗透测试者和道德黑客。


对于开发此发行版的最新版本，用户的反馈至关重要。换句话说，Kali Linux 2020.1中包含的每个新功能都是由于需要使用发行版的早期版本来聆听道德黑客的行为。下面，我们将回顾此新版本中突出显示的一些改进。


更改为默认密码

有关发行版以前版本的主要抱怨是使用默认的<< root >>用户来访问它。以前，对Kali Linux的默认访问凭据（用户/密码）是root / oror，这是一种非常不安全的措施。随着版本2020.1的发布，默认情况下已实现了kali / kali访问凭据，代表了实质性的安全性增强。

安装发行版的新方法

现在可以从相同的ISO映像安装新版本的Kali Linux。该图像将不需要Internet连接，并且道德黑客的专家和发烧友将能够自定义其发行版中的元素（桌面，工具等）。


此外，开发人员还提供了两种安装发行版的新方法：一个用于从网络上安装Kali的映像和一个“实时”映像，这将使用户无需在PC上安装发行版即可访问Kali Linux。

从您的移动设备进行安装

开发人员还包括对其移动系统的改进。一个示例是带有ARM处理器的设备，尽管使用的方式有限，但仍允许使用新版本的Kali。

主题更新

该发行版的外观在Kali Linux 2020.1中也进行了更新，包括夜间模式，图标，应用程序和菜单设计的更改。 

KALI-UNDERCOVER的改进

出于安全原因，许多道德黑客专家采用Kali-Undercover，该功能可在发行版界面中产生美观的变化，使其看起来像Windows系统。在新版本中，此功能已得到改进，使其与Windows系统的界面更加相似，因此将很难区分两者。
