这是用Python 3为GTFOBins编写的独立脚本。您可以搜索可以用来绕过系统安全限制的Unix二进制文件。这些二进制文件可能会被滥用

得到f \*\* k

突破受限制的外壳，提升特权，传输文件，生成绑定和反向外壳等...

这些功能来自https://github.com/GTFOBins/GTFOBins.github.io，所有贡献都归功于其各自的贡献者。它们被简化（不需要环境变量）并突出显示了语法。

**下载**

git clone https://github.com/t0thkr1s/gtfo

**安装**  
该脚本具有2个依赖项

*   colorama
    
*   pygments
    

安装依赖项

python3 setup.py install

python3 gtfo.py \[binary\]
