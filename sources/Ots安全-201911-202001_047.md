# 针对Microsoft-NSA加密漏洞发布的概念验证漏洞– CVE-2020-0601

微软披露了有史以来最严重的Windows漏洞之一后不到一天，安全研究人员就发布了PoC Exploit，该文章解释了攻击者如何通过加密模拟互联网上的任何网站或服务器来利用Windows CryptoAPI Spoofing错误。

  

微软在一月补丁周二的安全公告中披露了该漏洞的严重性。它已发布了安全更新，以解决影响其Windows操作系统的广泛的加密漏洞。

  

“信任机制是互联网运行的基础-CVE-2020-0601允许成熟的威胁参与者颠覆这些基础。“ – NSA技术总监Neal Ziring说。

  

这是国家安全局首次向Microsoft报告错误，这与Eternalblue SMB漏洞（该机构至少秘密保存了五年，然后被一个神秘组织泄露给公众）不同，该漏洞在2017年引起了WannaCry威胁。

  

**是什么使CVE-2020-0601变得更加严格和重要？**

*   Windows CryptoAPI（Crypt32.dll）验证椭圆曲线密码术（ECC）证书的方式中存在一个欺骗漏洞。
    
*   由于CVE-2020-0601，可以创建看似来自受信任证书颁发机构的伪造数字签名。
    
*   成功的利用还可以使攻击者进行中间人攻击，并在与受影响软件的用户连接上解密机密信息。
    

“此漏洞的根本原因是微软代码中椭圆曲线密码术（ECC）的错误实现”。–安全研究员Tal Be'ery说。

  

ECC依赖于不同的参数。这些参数已针对许多曲线进行了标准化。尽管易受攻击的Windows版本检查三个ECC参数，但它们无法验证第四个ECC参数，这称为基点生成器（称为“ G”）。

  

该失败是Microsoft实施ECC的结果，而不是ECC算法本身的缺陷。检查安全专家的详细分析以获取更多说明。

  

GitHub上现在有一些概念证明。kudelskisecurity已发布并演示了第一个漏洞利用程序，并演示了一个测试网站用于我们自己的目的\[风险自负\]。该网站使用通过PoC漏洞“签名”的证书。

  

另一位安全研究人员Saleem Rashid创建了一个POC代码来伪造TLS证书，并允许攻击者建立一个看起来像合法证书的网站。

  

**更新和补丁：**

Windows Defender已收到用于检测活动利用尝试的更新。根据Microsoft的说法，此漏洞会影响Windows 10，Windows Server 2019和Windows Server 2016 OS版本。

  

像CrowdStrike这样的防病毒软件可检测CVE-2020-0601的漏洞利用，并显示证书颁发机构，恶意证书的SHA-1和ECC曲线参数。

  

安全供应商甚至可以通过Windows Event Manager – CveEventWrite函数提供检测签名。

  

补丁程序是降低风险的唯一综合手段。强烈建议您前往以下位置安装最新的软件更新：

  

Windows设置→更新和安全性→Windows更新→单击“检查PC上的更新”。
