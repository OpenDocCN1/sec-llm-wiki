# 英特尔修复了性能分析工具中的严重缺陷

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247484476&idx=1&sn=6c516dcf239851aeb02b03f861b9e0c8&chksm=9bae4d77acd9c461170d08a380860764e7551501fcd24e09b86cd8959a748a99ed05b6dba3f2&scene=126&sessionid=1681670238#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247484476&idx=1&sn=6c516dcf239851aeb02b03f861b9e0c8&chksm=9bae4d77acd9c461170d08a380860764e7551501fcd24e09b86cd8959a748a99ed05b6dba3f2&scene=126&sessionid=1681670238#rd)

英特尔在其名为Intel VTune Profiler的性能分析工具中警告存在严重漏洞。如果利用此漏洞，则攻击者可以对对手执行特权升级攻击，从而使他们可以提升权限并未经授权地访问目标系统。

  

VTune Profiler（以前称为VTune Amplifier）是面向串行和多线程应用程序开发人员的软件性能分析应用程序。尽管该应用程序支持Windows，Linux和Android平台，但英特尔表示更新8之前的Windows英特尔VTune Profiler版本受到影响。

  

英特尔安全更新称：“更新8之前的Windows英特尔VTune Amplifier驱动程序中对驱动程序的不当访问控制可能会使经过身份验证的用户潜在地通过本地访问启用特权升级，” 。

  

该漏洞（CVE-2019-14613）是由英特尔内部发现的，其CVSS评分为8.2（满分10）。英特尔敦促用户更新至适用于Windows的英特尔VTune Profiler更新8，该更新于2019年11月22日发布。

  

作为定期更新的一部分，英特尔还发布了补丁程序，以解决四个“中”严重性漏洞和一个“低”严重性漏洞。

  

**其他缺陷**

其中之一是英特尔图形处理器（包括其Core，Xeon，Pentium，Celeron和Atom品牌）中的中度拒绝服务漏洞（CVE-2019-14615），该漏洞可能导致信息泄露（受影响的完整列表）芯片组在此处）。

  

该漏洞源于某些处理器的“某些数据结构中的控制流不足”，并且可以由具有本地访问权限的未经身份验证的用户利用。

  

Windows的英特尔SNMP子代理独立版的安装程序中存在另一个中等严重性漏洞（CVE-2019-14600），该工具允许用户使用简单网络管理协议（SNMP）与受管服务器上的子代理进行通信。该缺陷源于不受控制的搜索路径元素，可能会导致特权升级。英特尔没有发布修复程序，而是表示将停产该产品，并建议用户“尽快卸载或停止使用。”

  

英特尔还在Windows 的英特尔RAID Web控制台（RWC）3中修复了一个中级漏洞，该漏洞使用户可以配置英特尔RAID控制器（位于操作系统和存储驱动器之间的卡或芯片）和安装在磁盘驱动器上的磁盘驱动器。一个系统。该漏洞（CVE-2019-14601）源自RWC安装程序中的不当权限，并可能通过本地访问启用特权升级。英特尔建议将Windows的RWC 3更新到7.010.009.000或更高版本。

  

其他缺陷包括英特尔芯片组设备软件 INF实用程序（CVE-2019-14596）中的信息泄漏缺陷和英特尔数据分析加速库中的低严重性漏洞（可以启用信息泄漏）（CVE-2019-14629）。

  

补丁发布是在英特尔于12月披露了对现代英特尔CPU 的新攻击之后的一个月，该攻击可能使攻击者通过改变其电压从受影响的处理器中提取高度敏感的信息（例如加密密钥）。这次攻击被称为“ Plundervolt”，主要围绕英特尔软件防护扩展（SGX），这是一组内置于英特尔CPU中的与安全相关的指令代码。英特尔SGX将敏感数据（例如AES加密密钥）屏蔽在“隔离区”内，这些隔离区与其他CPU内存在物理上是分开的，并受到软件加密的保护。
