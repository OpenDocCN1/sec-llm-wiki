# 苹果向所有研究人员开放其仅邀请漏洞赏金计划

正如苹果在今年8月承诺的那样，该公司今天终于向所有安全研究人员开放了其漏洞赏金计划，向向公司报告iOS，macOS，watchOS，tvOS，iPadOS和iCloud中的漏洞的任何人提供金钱奖励。

  

自三年前推出以来，苹果的漏洞赏金计划仅根据邀请向选定的安全研究人员开放，并且仅因报告iOS移动操作系统中的漏洞而获得奖励。

  

但是，在今年8月的一次黑客会议上，苹果公司Apple安全工程和体系结构负责人IvanKrstić 宣布了该公司即将推出的扩展漏洞赏金计划，其中包括三个主要亮点：

*   最高奖励从20万美元大幅增加到150万美元，
    
*   接受其所有操作系统和最新硬件的错误报告，
    
*   为所有研究人员开放该程序。
    

  

从今天开始，所有安全研究人员和黑客都有资格在“以标准配置的iOS，iPadOS，macOS，tvOS或watchOS的最新公共可用版本”中发现并以负责任的方式披露有效的安全漏洞时，有资格获得现金奖励。正如Krstić在Twitter上首次宣布的那样。

![](../Images/2cdb3d8f735a844ef0770dc8a79ee3f0.png "1577616638677289.jpg")

即使提交了有效的安全漏洞，研究人员也需要遵循一些基本的资格规则以获取奖励，其中包括直接向Apple安全团队报告详细信息，而无需向公众披露任何内容，直到公司发布补丁并提供清晰的报告和工作成果为止。利用。

  

如上面的漏洞赏金支付图表所示，只有那些提交严重致命的，可零点击的内核代码执行漏洞的人才能获得100万美元的奖励，这些漏洞可能使目标设备得到完整，持久的控制。

  

更重要的是？除了获得最高100万美元的奖励外，苹果还将向那些在公开发布前发现并报告其预发布软件（测试版）漏洞的人提供50％的奖金，使最高奖励达到150万美元。

  

除此之外，Apple现在还将为合格的奖励金额额外支付50％的奖金，用于报告公司在其先前版本的软件中修补的“回归”漏洞，但在开发人员Beta或公共Beta版本中“错误地”引入了该漏洞。

  

Apple Security Bounty计划还旨在鼓励黑客公开披露在Apple产品中发现的安全漏洞或将其出售给Zerodium，Cellebrite等私人供应商的黑客。和处理零时差漏洞的Grayshift。
