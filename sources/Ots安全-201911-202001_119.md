# GozNym恶意软件背后的黑客被盗窃1亿美元

美国司法部宣布，一个国际组织的网络犯罪组织的三名成员被判入狱，该组织主要是针对美国企业和金融机构的数百万美元盗窃案被判入狱。

  

犯罪分子利用GozNym银行木马在2015年至2016年间在全球主要在美国和欧洲闯入了4,000多台受害者计算机，并从他们的银行帐户中欺诈性地窃取了近1亿美元。

  

今年5月，欧洲刑警组织捣毁了GozNym背后的网络犯罪网络，美国针对该组织的十名成员发了指控，其中五人当时被捕，而包括GozNym开发商在内的另外五名则留在了运行。

  

在星期五在匹兹堡的联邦法院中，该组织的成员之一克拉西米尔·尼科洛夫（Krasimir Nikolov）因在该计划中担任“帐户接管专家”而被判入狱39个月以上，并被判处一段时间。现在被转移到保加利亚。

  

现年47岁的尼科洛夫于2016年9月被保加利亚当局逮捕，并于2016年12月被引渡到匹兹堡，以面对联邦政府的刑事共谋，计算机欺诈和银行欺诈指控。

  

美国司法部在一份新闻稿中说：“尼科洛夫使用了GozNym恶意软件捕获的受害者被盗的网上银行凭证来访问受害者的网上银行帐户，并试图通过电子转账到由同谋控制的银行帐户中来窃取受害者的钱。”

  

周五被判刑的另外两名GozNym小组成员Alexander Konovolov和Marat Kazandjian也参与了该计划，分别被判处七年和五年徒刑。两人均在格鲁吉亚被捕并被起诉。

  

Konovolov是GozNym网络的主要组织者和负责人，该网络控制着41,000多台受感染的计算机，并使用地下在线犯罪论坛招募了网络犯罪分子，而Kazandjian是他的主要助手和技术管理员。

  

GozNym是一个臭名昭著的银行木马，它是通过结合两个已知的功能强大的木马而开发出来的，Gozi ISFB恶意软件（2012年首次出现在银行木马中）和Nymaim（木马下载器也可以用作勒索软件）。

  

该恶意软件主要通过大规模的垃圾邮件活动传播以攻击受害者的Windows PC，然后等待受害者将其银行密码输入他们的网络浏览器，对其进行捕获，然后使用它们闯入受害者的银行帐户并以欺诈方式将资金转移到他们的计算机上。自己的帐户。

  

GozNym恶意软件网络是通过“ Avalanche”防弹服务托管和运营的，该管理员的管理员于2016年11月在乌克兰被捕。

  

美国律师斯科特·布雷迪（Scott W. Brady）表示：“这种新范式涉及与世界各地愿意与信任的执法合作伙伴进行空前的合作，这些伙伴分享我们的目标，无论他们身在何处，都可以搜寻，逮捕和起诉网络罪犯。”

  

该网络犯罪网络的受害者主要是美国企业及其金融机构，其中包括位于宾夕法尼亚州西部地区的许多受害者，尽管美国司法部没有透露任何名字。
