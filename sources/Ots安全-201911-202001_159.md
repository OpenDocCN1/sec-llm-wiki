# 影响范围

所有使用了`wp_where()`函数和参数可控的SQL查询均值受到影响，前台后台均存在注入。

![](../Images/2e165c02eab99b0466ac9ec3cc331c7d.png)

需要登录的点可以配合之前写的《某cms审核的部分页面未授权访问》利用POST来绕过登录进行注入。

例如

```
http://php.local/public/index.php/weixin/message/_send_by_group
```
