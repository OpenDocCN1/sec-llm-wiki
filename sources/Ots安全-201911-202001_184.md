# 芝加哥学生被控编写代码以传播ISIS宣传

美国当局逮捕了DePaul大学的学生Thomas Osadzinski，因为据称他为ISIS建立了定制的Gentoo Linux发行版。  

  

芝加哥DePaul大学的一名学生Thomas Osadzinski（20岁）被捕，因为据称他为ISIS建立了定制的Gentoo Linux发行版，他现在可能面临长达20年的监禁。

  

怀疑这名芝加哥学生提供了支持伊斯兰国恐怖组织（ISIS）的宣传内容。

  

Osadzinski开发了Python脚本，该脚本允许组织的支持者和成员自动保存通过社交媒体共享的ISIS宣传材料。该学生与组织成员共享了他的脚本，以帮助传播ISIS的宣传，他还向他们提供了使用机器人的大规模自动化程序。

  

Osadzinski还开始为恐怖组织开发轻量级的Gentoo Linux发行版。

  

“我将开始一个非常有价值的新项目，我将开发一个定制的Gentoo Linux版本，该版本是为ansar \[ISIS支持者\]设计的，它可以在任何计算机上运行，并且非常轻巧，快速和安全。”该学生告诉卧底。FBI代理商在3月的在线讨论中。

  

该学生旨在加强Linux Gentoo发行版，以防止被他定义为“十字军情报局”的情报局的黑客入侵。

  

Osadzinski向另一位FBI秘密特工提供了他正在准备的Gentoo Linux发行版的屏幕快照，并承诺将“很快为ansar \[ISIS支持者\]使用”。

  

“这将是非常安全的，在伊斯兰世界中，它将仅浏览\[Social Media Platform 1\]。如果安装的东西较少，则更难破解操作系统。”

  

由于难以学习强化Linux发行版的原因，该学生无法完成他的工作。

  

据Cyberscoop称，  Osadzinski还曾为Blackberry Cylance担任软件测试员两个月。

  

如果该学生因分发宣传材料以支持ISIS而被判有罪，将面临最高20年的监禁。
