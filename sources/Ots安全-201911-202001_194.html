地址为：http://ip/index.php?m=xdcms&c=data&f=delete&file=

这个功能原本是删除备份文件夹的，但是可以通过../进行目录替换来删除任意文件夹

原始码如下：

public function delete(){
    $file=trim($_GET["file"]);
    $dir=DATA_PATH.'backup/'.$file;
    if(is_dir($dir)){
        //删除文件夹中的文件
        if (false != ($handle = opendir ( $dir ))) {
            while ( false !== ($file = readdir ( $handle )) ) {
                if ($file != "." && $file != ".."&&strpos($file,".")) {
                @unlink($dir."/".$file);
                }
            }
            closedir ( $handle );
        }
        @rmdir($dir);//删除目录
    }
    showmsg(C('success'),'-1');
}

通过GET参数文件获取目录名，然后进行判断是否是目录，如果是，则删除目录下的文件再删除目录，如果不是，直接返回 success

//安全过滤函数
function safe_html($str){
    if(empty($str)){return;}
    $str=preg_replace('/select|insert | update | and | in | on | left | joins | delete |%|=|/*|*|../|./| union | from | where | group | into |load_file
|outfile/','',$str);
    return htmlspecialchars($str);
}
