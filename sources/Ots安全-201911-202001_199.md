# 新的Sim卡缺陷让黑客劫持了您的手机– SimJacker

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247483864&idx=4&sn=4518f81f5ef250c958ae9eda78b9708b&chksm=9bae4893acd9c185b92db159289a94d6cc6f07e0b2def72c9deb1286a8fcbd6233f3008d4a86&scene=126&sessionid=1681670253#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247483864&idx=4&sn=4518f81f5ef250c958ae9eda78b9708b&chksm=9bae4893acd9c185b92db159289a94d6cc6f07e0b2def72c9deb1286a8fcbd6233f3008d4a86&scene=126&sessionid=1681670253#rd)

网络安全研究人员今天发现了一个新的严重漏洞的存在，该漏洞以前在SIM卡中未发现，它可以使远程攻击者仅通过发送SMS消息即可破坏目标手机并监视受害者。

  

此漏洞被称为“ SimJacker”，存在于大多数SIM卡中嵌入的一些名为S @ T Browser（动态SIM卡工具包）的软件中，该软件已在至少30个国家/地区被移动运营商广泛使用，无论使用哪种手机，都可以使用此漏洞。受害者使用。

  

一家与政府合作的独立私营公司至少两年来一直在积极利用SimJacker的漏洞对不同国家的手机用户进行有针对性的监控。

  

S @ T Browser是SIMalliance Toolbox Browser的缩写，是一种应用程序，它作为SIM Tool Kit（STK）的一部分安装在包括eSIM在内的各种SIM卡上，旨在允许移动运营商提供一些基础的和附加的订阅服务。为客户提供无线服务。

  

由于S @ T浏览器包含一系列STK指令，例如发送短消息，建立呼叫，启动浏览器，提供本地数据，执行命令以及发送仅通过向设备发送SMS即可导致的数据，该软件提供了一个运行时环境，用于在手机上启动恶意软件命令。

  

**Simjacker漏洞如何工作？**

AdaptiveMobile Security研究人员在今天发布的一项新研究中发现了该漏洞，只需使用包含特定类型的间谍代码的SMS消息，即可使用价格为10美元的GSM调制解调器在目标设备上执行以下列出的各种任务，从而利用此漏洞。

*   恢复目标设备位置和IMEI信息，
    
*   通过代表受害者发送虚假信息来传播虚假信息，
    
*   通过拨打保费率号码进行保费率欺诈，
    
*   通过命令设备呼叫攻击者的电话号码来监视受害者的周围环境，
    
*   恶意软件的传播，迫使受害者的手机浏览器打开恶意网页，
    
*   通过断开SIM卡e进行拒绝服务攻击
    
*   获取更多信息，例如语言，收音机类型，电池电量等。
    

研究人员解释说：“在攻击过程中，用户完全不知道自己收到了攻击，信息已经被提取出来，并且信息已被成功删除。”

“在没有目标移动用户的知识或同意的情况下，随着时间的流逝，获得了成千上万个设备的位置信息。但是，Simjacker攻击可以并且已经扩展为执行其他类型的攻击。”

![](../Images/e4b562697624cdd9590412d02eb098c5.png)

“这种攻击也是独特的，因为从逻辑上可以将Simjacker攻击消息归类为完全恶意软件的负载，尤其是间谍软件。这是因为它包含SIM卡必须遵循的说明列表。”

  

尽管预计将在今年10月发布技术细节，详细文档和有关漏洞概念的证明，但研究人员表示，他们观察到几乎所有制造商（包括Apple，ZTE，Motorola，三星，谷歌，华为，甚至带SIM卡的物联网-Il。

  

研究人员称，所有手机制造商和型号都容易受到SimJacker的攻击，因为此漏洞使用了集成到SIM卡中的过时技术，该技术自2009年以来就没有更新过，这可能使一个以上的风险更大。十亿人。

  

**Simjacker漏洞被利用**

![](../Images/fd7c7662172d79a13ce15fdaa85dfce7.png)

研究人员说，Simjacker攻击效果很好，并且已经成功使用了很多年，“因为它结合了先进的接口和黑暗技术，表明移动运营商不能依赖于已安装的安全功能”。

  

“ Simjacker对运营商和移动用户无疑是危险的，这可能是主要移动网络上存在的最复杂的攻击，”自适应移动安全技术首席技术官Ketal MacDade在一份新闻稿中说。

  

“这是主要的警告信号，表明敌对行动者正在以日益复杂和创新的方式进行大量投资，以破坏网络安全。”这威胁到客户，移动运营商的安全和信任，并影响整个国家的国家安全”。

  

此外，既然已经公开披露了此漏洞，研究人员希望黑客和其他攻击者“在其他领域进行这些攻击”。

  

研究人员以负责任的方式透露了GSM协会（代表移动运营商社区的商业组织）以及SIM联盟（代表SIM / UICC卡的主要生产商）的此漏洞的详细信息。

SIMalliance意识到了这个问题，并向安全SIM卡制造商提供了有关S @ T推送消息的建议。

  

移动运营商还可以通过设置分析和阻止包含S @ T浏览器命令的可疑消息的过程来立即消除这种威胁。

  

作为潜在的受害者，如果移动设备的用户使用安装了S @ T浏览器技术的SIM卡，则该用户似乎无能为力，除非要求更换其SIM卡，并且该设备已获得专利安全功能。
