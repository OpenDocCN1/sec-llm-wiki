如果您想进行黑客攻击，或者您是一个学期的学生，那么您需要了解有关在互联网上匿名的所有知识。由于人们会犯错误并留下痕迹，因此100％匿名是非常困难的。但是，仅通过使用下面显示的以下两种方法，您就很难使某人跟踪您。所以这是匿名工具


我推荐的两种方法是使用两个最著名的模块：

  • Anonsurf

  • Macchanger

Anonsurf是由Parrot Sec团队开发的用于Kali Linux的隐身和IP更改脚本。这些是制作Parrot OS的人。该脚本将在后台运行，并不断更改您的IP地址，以便在通过IP地址进行跟踪时成为匿名用户。Anonsurf使用两项主要服务在Internet上匿名。一个是Tor，另一个是iptables，它是用于管理IP地址的Linux服务。这是Github上的开放存储库。


Macchanger是内置的Kali Linux工具，可以更改您的mac地址。它具有许多功能，从随机mac地址到特定的mac地址。Anonsurf和macchanger可以帮助您保持匿名。


因此，让我们开始在Kali Linux中安装和设置Anonsurf和Macchanger

使用Anonsurf隐藏IP地址

步骤1：在kali Linux中打开终端，并使用以下命令从Github克隆Anonsurf存储库

git clone https://github.com/Und3rf10w/kali-anonsurf.git

步骤2：更改目录，并将执行权限授予anonsurf存储库。您可以使用以下命令执行此操作：

cd kali anonsurf

chmod + x ./installer.sh

步骤3：拥有脚本的执行权限后，立即运行anonsurf脚本，如下所示：

sudo ./installer.sh

步骤4：现在，安装将开始，并且将安装依赖项。请等待安装完成。

步骤5：安装完成后，键入help命令以获取该工具所有可能选项的列表：

anonsurf help

步骤6：现在，使用start命令启动Anonsurf服务。完成后，您的IP地址将定期更改。

anonsurf start

恭喜，现在您的系统IP已隐藏，您将更接近匿名。我们需要隐藏的第二件事是您系统的MAC地址。

使用Macchanger更改Mac地址

简短版本：

因此，快捷方式和较不详细的方式将如下所示

ifconfig wlan0 down
macchanger -r wlan0
ifconfig wlan0 up

较长的深入版本：

步骤1：关闭网卡

使用以下Linux命令关闭网卡

ifconfig device down


使用ifconfig命令查找您的设备名称。（用您的设备名称替换设备）

它将是eth0，eth1等

或wlan0，wlan1等


第2步：设置随机Mac地址


现在要为您的网络设备设置随机MAC地址，请输入以下命令：

macchanger -r eth0

由于我的网络设备是eth0

如上图所示，我的mac地址已更改为随机的mac地址。这也称为mac地址欺骗。Macchanger将向您显示永久，当前和更改的MAC地址。


要检查所有命令，请使用帮助选项：

macchanger -h

注意：系统重启后，永久MAC地址将恢复。

步骤3：打开网卡：

ifconfig eth0 up

由于我的设备名称是eth0

Viola您的mac地址已更改为随机的mac地址。


步骤4：恢复默认的Mac地址

如果要还原永久性的mac地址，请使用以下命令：

macchanger –p eth0

步骤5：欺骗特定的Mac地址

您还可以使用以下命令来欺骗特定的MAC地址：

macchanger -m [欺骗MAC地址] eth0

macchanger -m XX：XX：XX：XX：XX：XX eth0

此处XX：XX：XX：XX：XX：XX：XX应替换为目标mac地址


如果收到以下错误：

错误：无法更改MAC：接口是否打开权限：无法分配请求的地址

现在，由于IP和MAC都被隐藏了，因此您已成为真正意义上的匿名者。


更改IP地址和Mac地址如何使我匿名？

您的IP地址和MAC地址是可以找到您的唯一标识符。您的系统数据以及位置都可以借助您的MAC地址和IP地址进行跟踪。因此，当您更改mac和IP地址时，很难跟踪您。此外，从技术上讲，您的设备应在一定时间间隔后不断更改地址，以使您永远无法被正确跟踪。将您的MAC地址更改为随机或特定的MAC地址称为MAC欺骗。


常见问题：

1）这是完全验证的方法吗？

不，如果有人真的想追踪您，他们会，但是他们将不得不花费大量金钱和精力。


2）更改您的mac地址合法吗？

是的，只要您不在公司，就没有法律限制。在公司中，您将必须咨询相应的IT部门
