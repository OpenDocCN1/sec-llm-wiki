**对于Microsoft的咨询，此问题具有以下描述：**

Windows无法正确处理内存中的对象时，存在拒绝服务漏洞。成功利用此漏洞的攻击者可能导致目标系统停止响应。

  

要利用此漏洞，攻击者必须登录到受影响的系统并运行特制应用程序，或诱使用户打开网络共享上的特定文件。该漏洞不允许攻击者直接执行代码或直接提升用户权限，但可用于使目标系统停止响应。

  

该更新通过更正Windows处理内存中对象的方式来解决该漏洞。”

  

为了滥用此漏洞，我们将基于提供给Microsoft的漏洞利用不同的描述。从技术上讲，我们的描述可能不如Microsoft的描述准确，但是我们的方法可能允许外面的人利用此漏洞超越DOS。

  

Windows 10 1909上存在创建任意文件夹的情况。这种特定情况允许特权较低的用户在系统中的任何位置创建具有任何选定名称的空文件夹。我们创建的文件夹继承了其DACL，因此我们找不到解决此问题的方法来执行特权升级。但是，我们能够利用任意文件/文件夹创建内容来造成蓝屏死机（BSoD）。我们测试的最新版本是Windows 10 1909（OS Build 18363.778）64位。

  

**描述**

特权较低的用户（“攻击者”）具有对文件夹c：\\ Users \\ attacker \\ AppData \\ Roaming \\ Microsoft \\ Windows的完全控制。这样，他就可以将文件夹重命名为c：\\ Users \\ attacker \\ AppData \\ Roaming \\ Microsoft \\ Windows2。

  

如果用户/攻击者执行了上述重命名操作，则可以遵循特定的情况和操作，以强制NT AUTHORITY \\ SYSTEM重新创建以下文件夹：

*   
*   

```
c：\ Users \ attacker \ AppData \ Roaming \ Microsoft \ Windows \ Recentc：\ Users \ attacker \ AppData \ Roaming \ Microsoft \ Windows \ Libraries
```

攻击者可以用指向系统某处不存在的文件夹的符号链接替换这些文件夹。当NT AUTHORITY \\ SYSTEM尝试重新创建文件夹“ Recent”和“ Libraries”时，将遵循这些符号链接并创建不存在的文件夹。这样，攻击者可以在系统中的任何位置创建具有选定名称的文件夹。
