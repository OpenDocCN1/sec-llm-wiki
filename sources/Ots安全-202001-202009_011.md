# 伊朗黑客被指控窃取航空航天和卫星跟踪数据

此外，在长达数年的恶意软件攻击之后，美国财政部也批准了伊朗攻击组织APT39。

美国司法部今天指控三名伊朗黑客在一场旨在窃取与美国航空航天和卫星技术及资源有关的关键数据的运动中的作用。这是美国司法部三天以来第三次指控伊朗网络攻击者。

  

据说34岁的Pourkarim Arabi，25岁的Mohammad Reza Espargham和34岁的Mohammad Bayati都是伊朗居民和国民，据称他们代表伊朗伊斯兰革命卫队（IRGC）参加了身份盗窃和黑客入侵的协调运动。指定的外国恐怖组织。

  

起诉书称，他们的竞选活动大约从2015年7月开始，一直持续到至少2019年2月，并针对美国和国外的众多组织。被告一次拥有一个超过1800个在线帐户的目标列表，其中包括一些属于航空航天或卫星技术组织以及澳大利亚，以色列，新加坡，美国和英国的国际政府组织。

  

作为入侵的一部分，被告使用社会工程学来识别在航空航天和卫星领域工作的真实美国公民，他们可以在网上使用其身份。然后，他们冒充了这些人，并使用其偷来的身份注册电子邮件地址，并购买了域名和黑客工具，以进一步努力。攻击者创建了鱼叉式网络钓鱼电子邮件，看起来好像来自受害者。美国司法部解释说，他们使用这些工具来传播恶意软件，并向攻击者提供未经授权的访问目标计算机和网络的权限。

  

一旦进入组织内部，他们便使用黑客工具来维护访问权限，提升特权并窃取IRGC所需的数据。攻击者成功入侵了多个目标网络，导致盗窃了包括卫星跟踪公司以及卫星语音和数据通信公司在内的公司的敏感商业数据，知识产权和个人数据。

  

在另一起案件中，两名伊朗国民于9月16日被控针对针对新泽西州以及美国，欧洲和中东其他地区的计算机的网络入侵活动。据称30岁的Hooman Heidarian和34岁的Mehdi Farhadi窃取了数百TB的数据。在某些情况下，这些行动是出于政治动机或受伊朗的要求。在另一些情况下，被告则在黑市上出售了被盗的数据，以谋取金钱收益。

  

美国司法部报告说，他们窃取的信息通常包括与国家安全有关的机密通信，外交政策情报，非军事核信息，航空航天数据，人权激进主义者信息，受害人金融信息和个人身份数据以及知识产权，包括未发表的科学研究。

  

在另一起案件中，两名黑客于9月15日被指控在美国各地破坏网站，以报复2020年1月美国的军事行动，该行动杀死了伊斯兰革命卫队圣城部队（Qism Soleimani）（也是美国指定的外国恐怖分子）负责人Qasem Soleimani组织。两人均被控以一项共谋蓄意损坏受保护计算机的罪名和一项蓄意损坏受保护计算机的罪名。

  

同一天，美国国土安全部（DHS）网络安全和基础设施安全局（CISA）和联邦调查局发布了警报警告，其中一名针对伊朗的恶意攻击者瞄准了多个美国联邦机构和美国网络。该报告指出与先锋小猫威胁组织有关联，该组织被认为与伊朗政府有联系，并表示攻击者正在利用与VPN基础设施有关的CVE来获取对目标网络的访问权限。

  

美国财政部外国资产控制办公室今天对本周的活动进行补充，对伊朗攻击组织APT39，与该组织有联系的45人和一家前线公司实施了制裁。财政部报告说，伊朗政府开展了长达数年的恶意软件运动，以伊朗持不同政见者，新闻记者和国际旅行公司为目标。

  

领先的公司Rana Intelligence Computing Company通过发起针对包括政府和个人在内的已知对手的网络攻击和恶意软件运动，推进了伊朗情报和安全部（MOIS）的目标。报告说，在拉那的幌子下，MOIS在伊朗虐待和监视其本国公民方面发挥了关键作用。
