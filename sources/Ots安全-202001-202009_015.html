Microsoft发布了9月的安全更新，以修复关键级别漏洞，该漏洞是Microsoft Exchange Server中的远程执行代码漏洞（CVE-2020-16875）。


考虑到相关的PoC 最近已出现在Internet上，强烈建议用户尽快进行更新以进行保护。

Microsoft Office团队的“ File：Microsoft Exchange（2019年至今）.svg”在CC BY-SA 4.0下获得许可

由于对cmdlet参数的验证不正确，攻击者可能通过向受影响的Exchange服务器发送包含特殊cmdlet参数的电子邮件来触发此漏洞。成功利用此漏洞的攻击者可以在受影响的系统上以系统特权执行任意代码。值得注意的是，成功利用此漏洞的前提是拥有可以作为Exchange角色进行身份验证的用户权限。


受影响的产品版本

  • Microsoft Exchange Server 2016累积更新16

  • Microsoft Exchange Server 2016累积更新17

  • Microsoft Exchange Server 2019累积更新5

  • Microsoft Exchange Server 2019累积更新6


解

Microsoft已在每月安全更新中修复了此漏洞。
