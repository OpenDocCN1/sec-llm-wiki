# 利用蓝牙设备的BLURtooth漏洞进行窃取数据

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247488292&idx=3&sn=039cd4eece2f29f4d6de7a802489021b&chksm=9bae5a6facd9d37969a644befc65d61c51aed95f5399d859cdc22715ab086c009aa8621b23ed&scene=126&sessionid=1681670147#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247488292&idx=3&sn=039cd4eece2f29f4d6de7a802489021b&chksm=9bae5a6facd9d37969a644befc65d61c51aed95f5399d859cdc22715ab086c009aa8621b23ed&scene=126&sessionid=1681670147#rd)

黑客可以利用蓝牙设备中的BLURtooth漏洞发起中间人（MiTM）攻击并窃取机密信息，访问经过身份验证的服务

安全研究人员发现了一个新的蓝牙漏洞，该漏洞使黑客能够在智能手机，IoT设备等蓝牙设备上执行中间人（MiTM）攻击，并窃取机密信息或访问经过身份验证的服务。

  

该漏洞是由洛桑联邦理工学院（EPFL）和普渡大学的院士组成的研究小组发现的。研究人员将这个新的蓝牙漏洞命名为“ BLURtooth”。

  

BLURtooth漏洞已被授予唯一标识符CVE-2020-15802，但是MITER和NIST尚未更新其漏洞数据库。蓝牙的交叉传输密钥派生（CTKD）中存在BLURtooth漏洞，该漏洞为支持蓝牙低功耗（BLE）和基本速率/增强数据速率（BR / EDR）的双模设备（即智能手机）设置身份验证密钥。）运输方式。

  

研究人员说，黑客可以利用BLURtooth漏洞来覆盖并降低用于配对设备的LTK或链接密钥（LK）加密密钥的强度。一旦黑客降低了密钥强度或删除了加密密钥，他们就可以轻松地对目标设备执行中间人（MiTM）攻击。

  

“易受攻击的设备必须允许对BR / EDR或LE传输中的至少一个进行配对或绑定，而无需进行身份验证或密钥强度很弱，才能透明地进行，以防止受到攻击。“例如，可能可以通过BR / EDR或LE上的JustWorks配对与某些设备配对，并覆盖其他传输器上的现有LTK或LK。当这导致加密密钥强度降低或使用未认证的密钥覆盖已认证的密钥时，攻击者可以获得对本来不受限制的配置文件或服务的额外访问。”

  

研究人员说，以前已配对但当前未配对的蓝牙设备也可能受到范围内的攻击者的MITM攻击。“如果伪造另一台设备身份的设备在传输中配对或绑定，并且CTKD用于派生密钥，然后覆盖强度更高或使用身份验证创建的现有密钥，则可能会访问经过身份验证的服务，”

  

SIG表示还没有针对BLURtooth漏洞的补丁。同时，它建议“可能易受攻击的实施对Bluetooth Core Specification 5.1及更高版本中规定的CTKD进行限制。”
