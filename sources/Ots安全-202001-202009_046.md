# 微软最终在2021年1月之前终止对Adobe Flash的支持

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247488235&idx=4&sn=4f0624164d8b6bfd37a1c89270831fd0&chksm=9bae5ba0acd9d2b681d23aac1e46a517966da72030b5713c03141fb66da9d575004263f2d656&scene=126&sessionid=1681670147#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247488235&idx=4&sn=4f0624164d8b6bfd37a1c89270831fd0&chksm=9bae5ba0acd9d2b681d23aac1e46a517966da72030b5713c03141fb66da9d575004263f2d656&scene=126&sessionid=1681670147#rd)

微软今天表示，它将最终在2021年1月之前终止对Web浏览器的Adobe Flash Player支持，并确认于2017年7月与苹果，Adobe，Facebook，Google和Mozilla共同发布了协调一致的公告。

  

Adobe 表示 2020年12月31日后将不再更新和分发Flash Player。

  

之所以做出这一决定，是因为仍在使用Flash Player的人数在不断减少，并且是因为更安全，性能更好的开放技术（例如HTML5，WebGL和WebAssembly）。

  

微软程序经理Suchithra Gopinath今天说：“按照这一计划，微软将在2020年底终止对Microsoft Edge（包括新的Microsoft Edge和Microsoft Edge Legacy）和Internet Explorer 11的Adobe Flash Player支持。”

  

根据Microsoft的变更时间表，Adobe Flash删除将随着Microsoft Edge v88的发布而生效，与此同时，它将在Chromium项目的Google Chrome v88中进行。

  

此时间轴与其他主要Web浏览器（包括Apple  和  Mozilla）背后的供应商宣布的时间轴一致。

  

默认情况下从2021年1月开始禁用

Gopinath补充说：“在2020年12月之后，您将不再收到来自Microsoft的适用于Microsoft Edge传统和Internet Explorer 11的'Adobe Flash Player安全更新”。

  

“从2021年1月开始，默认情况下将禁用Adobe Flash Player，并且将阻止2020年6月发布的所有版本低于KB4561600的版本。”

  

在2020年秋季，该公司将通过Windows Update，WSUS和Microsoft Update Catalog发布“用于删除Adobe Flash Player的更新”，该更新将从所有Windows设备上永久永久删除Flash。

  

希望在正式支持终止之前删除Flash支持的客户将能够从Update Catalog下载更新并在其系统上运行该更新后使用该更新。

  

用户一旦将更新部署到计算机上将无法卸载-首先，它将在2021年初是可选的，Microsoft将在接下来的几个月内开始推荐该更新。

  

一旦Flash终止支持，Microsoft还将从其所有下载平台中删除与Flash相关的可下载资源。

  

在2021年夏季，将通过Windows 10平台上的最新“累积更新”并通过Windows 10平台上的最新“累积更新”从Microsoft Edge（旧版）和Internet Explorer 11中删除所有专门控制Adobe Flash Player行为的API，组策略和用户界面。 Windows 8.1，Windows Server 2012和Windows Embedded 8 Standard上的“ Internet Explorer 11累积更新”或“每月汇总”。

作为企业用户的Edge插件使用

根据一个Adobe 宣布，谁仍然需要使用Flash Player的商业授权和支持功能的内部业务系统的企业用户可以接触到公司的正式授权经销合作伙伴，HARMAN。

  

微软还表示，借助专用的Microsoft Edge和Internet Explorer插件，客户仍将能够在企业环境中运行此类软件解决方案。

  

微软表示：“为帮助这类客户，Microsoft Edge将允许Adobe Flash Player通过IE模式功能作为插件加载。”

  

“从本质上讲，Internet Explorer 11也将允许此操作。一旦从Microsoft提供的Adobe Flash Player中进行切换，它将被视为任何其他第三方插件，并且不会从Microsoft获得客户支持。”
