# 黑客正在出售企业、银行、政府的900台Citrix服务器访问权限

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247488129&idx=6&sn=1f0dbe6f56853744578abc20a2a0ff68&chksm=9bae5bcaacd9d2dc95de79101803577e5dc81f01dc988c55cc90eb08df7d2331e651d5552791&scene=126&sessionid=1681670152#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247488129&idx=6&sn=1f0dbe6f56853744578abc20a2a0ff68&chksm=9bae5bcaacd9d2dc95de79101803577e5dc81f01dc988c55cc90eb08df7d2331e651d5552791&scene=126&sessionid=1681670152#rd)

黑客正在出售对900台Citrix服务器的访问权限，其中包括全球范围内大公司的XenMobile服务器。

几天前，我们报告了如何在Citrix软件中发现跨站点脚本（XSS）漏洞，该漏洞使远程黑客可以接管Citrix运行的服务器。我们还报告了Citrix System XenMobile服务器中的一个严重缺陷，该缺陷使黑客能够窃取机密信息。这些漏洞似乎已被威胁参与者野蛮地利用。

![](../Images/f74a89d47667726e7f14d99b008a79b7.png)

黑客在暗网黑客论坛上出售了多达900台Citrix服务器的访问权限。这份清单是由银行安全研究人员首先报告的，他们指出，列出的Citrix服务器包括一家位于美国的合作银行，以及世界各地的政府组织，电信和IT服务公司。

  

Threat Actor正在销售900多个Citrix访问权限。

  

在受害者中，有美国的是信用合作社银行🇺🇸，以及来自世界各地的不同国家的政府，电信，IT和云公司。

  

Citrix Systems服务器为全球许多大型高科技公司的网站提供支持，包括许多美国公司。Citrix提供了用于虚拟化，计算机网络建设和云计算服务的软件解决方案，包括开源XenMobile服务器。据估计，目前全球至少有230,000个组织使用Citrix的某些解决方案。

  

Citrix没有对最新的数据泄露新闻发表评论。银行安全部门未提供有关谁进行挂牌交易或出售价格的任何进一步信息。

  

一周前，另一位黑客在一个黑暗的网络黑客论坛上投放了一个广告，以出售一个Citrix数据库，据称该数据库包含该公司客户的大约200万条记录。该数据库名为citrix\_leads\_vivo，以2.15比特币出售（按当前汇率约合20,000美元）。
