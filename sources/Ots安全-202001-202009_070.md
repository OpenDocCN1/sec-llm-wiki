# 伊朗黑客冒充记者诱骗用户安装恶意软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247488038&idx=3&sn=a6e1587a44ae86fff840b7f8de2e6408&chksm=9bae5b6dacd9d27b86b7c981abc6f89e810a3ef7a18a2d0f591edf5bc3d015e3c8ee8e0d75b9&scene=126&sessionid=1681670152#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247488038&idx=3&sn=a6e1587a44ae86fff840b7f8de2e6408&chksm=9bae5b6dacd9d27b86b7c981abc6f89e810a3ef7a18a2d0f591edf5bc3d015e3c8ee8e0d75b9&scene=126&sessionid=1681670152#rd)

一个以政府，国防技术，军事和外交部门为目标的伊朗网络间谍组织现在冒充新闻记者通过LinkedIn和WhatsApp接近目标，并用恶意软件感染他们的设备。以色列公司Clearsky

详细介绍了“迷人小猫” APT小组的新策略，“从2020年7月开始，我们已经确定了该小组的一个新的TTP，使用电子邮件以及WhatsApp消息模拟了'Deutsche Welle'和'Jewish Journal'。他们的主要平台来接近目标并说服他们打开恶意链接。”

Clearsky在周四的分析中指出，此事态发展是威胁者首次通过WhatsApp和LinkedIn进行水坑攻击，其中还包括给受害者打电话。

  

在公司就其网站上的冒名顶替行为和水坑漏洞向德意志维尔发出警告后，德国广播公司证实：“迷人小猫冒充的记者在过去几周没有向受害者或以色列的任何其他学术研究人员发送任何电子邮件。” 至少从2017年12月开始，

迷人的小猫（也被称为APT35，Parastoo，NewsBeef和Newscaster的别名）之前已与一系列秘密活动联系在一起，目的是窃取人权活动家，学术研究人员和媒体的敏感信息。

![](../Images/3d3a8ec55437bbd3d79ffa85a4c15ef3.png)

漏洞（在本例中是嵌入受感染的Deutsche Welle域中的恶意链接）通过WhatsApp传播了信息窃取者恶意软件，但在诱使受害者首先通过久经考验的社交工程方法以诱骗他们之前学者在在线网络研讨会上发表演讲。

Clearsky解释说：“通信始于发送给目标的电子邮件，并开始了对话。” “与目标进行简短对话后，迷人的小猫攻击者请求将对话移至WhatsApp。如果目标拒绝移至WhatsApp，则攻击者将通过伪造的LinkedIn个人资料发送消息。”

  

在一种情况下，攻击者甚至采取了消息传递和呼叫受害者的步骤来获得目标的信任，并随后通过聊天中较早共享的恶意链接，引导该人完成连接到网络研讨会的步骤。

尽管APT35可能已经有了新的诡计，但这并不是伊朗黑客首次使用社交媒体渠道监视感兴趣的人员。

在2014年被iSIGHT Partners（现为FireEye拥有）发现的为期三年的“ Operation Newscaster ”中，该威胁演员被发现创建了虚假的Facebook帐户和虚假的新闻网站，以监视美国的军事和政治领导人。，以色列和其他国家/地区。

Clearsky研究人员说：“在这次运动中，我们观察到攻击者愿意使用WhatsApp呼叫和合法的德国电话号码直接与受害者通电话。这种TTP并不常见，并且危害了攻击者的虚假身份。” 。
