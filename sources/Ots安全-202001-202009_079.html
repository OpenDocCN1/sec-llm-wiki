介绍

在渗透测试期间，遇到Cisco网络设备的配置文件并不罕见。它可能是配置备份，位于网络中的某些计算机上。它可能是包含Cisco配置片段的控制台日志输出（例如，来自PuTTY）。或者，我们可能会突然闯入某些配置有默认凭据的思科设备。

攻击者获得对Cisco设备的访问权限后，首先要做的是他们通过运行show running或show running-config命令从设备中提取当前配置。攻击者通常在寻找敏感信息，例如存储的凭据，SNMP社区字符串，网络配置详细信息等。

凭据自然是寻找的最有趣的东西，并且多年来，思科已经开发出许多用于在其设备中存储密码的不同方法。因此，名称为Cisco密码类型。

常见的思科密码类型

在以下各节中，我们将按从最不安全（最容易破解）到最安全（最难破解）的顺序，依次浏览所有这些密码类型：


免责声明：本文中的所有示例和速度测量都是在配备GPU和4个CPU内核的标准现代笔记本电脑上进行的。

让我们跳到它。

思科0型密码

Cisco密码类型0基本上是明文密码。没有加密也没有混淆。这是在思科设备中存储密码的最古老，最不安全的方法。永远不要使用它。

以下示例显示在Cisco配置中找到的类型0密码：

username admin privilege 15 password 0 P@ssw0rd

如您所见，实际上没有什么要破解或解密的。我们可以清楚地看到admin用户的密码为P @ ssw0rd。

思科7型密码

这种密码类型使用Vigenère密码，本质上是一种简单的字母替换加密。该算法是可逆的，因此无需破解就可以立即将其解密为纯文本。

以下示例显示在思科配置中找到的7类密码：

username admin privilege 15 password 7 0236244818115F3348

解密Cisco 7型密码

有许多免费的工具可用于解密7型密码。这里有些例子：

  • https://www.question-defense.com/2011/08/17/perl-script-to-decode-cisco-type-7-password-hash

  • https://gist.github.com/jayswan/1927995

  • https://github.com/theevilbit/ciscot7

例如，要使用Ciscot7 Python脚本解密上述7类密码，只需运行：

wget https://raw.githubusercontent.com/theevilbit/ciscot7/master/ciscot7.py
python ciscot7.py -d -p 0236244818115F3348

我们可以立即看到密码是P @ ssw0rd。

在线上也有许多 用于这种类型密码的解密器 。但是我们强烈建议不要使用它们，以避免将敏感的客户信息（凭证）透露给第三方。

思科4类密码

该密码类型是在2013年左右设计的，最初的计划是使用PBKDF2（基于密码的密钥派生功能版本2）算法。但是由于实现问题，它最终以某种方式仅是不加盐的SHA256的一次迭代。

以下示例显示在Cisco配置中找到的类型4密码：

username admin secret 4 ds4zcEBHQMiiscBff5JmSaUctdI8fVdmGU18HAtxOCw

使用John解密Cisco 4类密码

开膛手John将此密码类型识别为Raw-SHA256。要破解它，我们必须首先将其转换为以下john friendly格式并将其保存在文件中：

admin:ds4zcEBHQMiiscBff5JmSaUctdI8fVdmGU18HAtxOCw

然后，我们可以使用字典来破解它，例如：

john --format=Raw-SHA256 --wordlist=/usr/share/wordlists/rockyou.txt --fork 4 hashes.txt

请注意，由于我们有4个CPU内核，因此可以使用--fork参数在4个实例中运行john ：

使用Hashcat解密Cisco 4类密码

Hashcat将此密码类型识别为哈希模式5700。要破解它，我们可以继续使用相同的john friendly格式，然后可以使用字典来破解它，例如：

hashcat -m 5700 --username -O -a 0 hashes.txt /usr/share/wordlists/rockyou.txt

请注意，通过使用-O参数（优化的内核），我们将大大提高速度。但这也将密码长度限制为31个字符。

从上面的截图我们可以看到，平均 速度约为114万每秒密码尝试。在我们看来，用john破解该哈希值似乎要快得多。

思科5型密码

这种密码类型是在1992年左右引入的，本质上是带有Salt的MD5哈希的1000次迭代。盐长4个字符（32位）。对于现代计算机，这还不够困难，因此在许多情况下都可以成功破解。

以下示例显示在Cisco配置中找到的类型5密码：

username admin secret 5 $1$jUfy$2TVVXJ8sy.KO8ZhAKfIHt/

使用John解密Cisco 5型密码

开膛手John将此密码类型识别为md5crypt。要破解它，我们必须再次首先将其转换为以下john friendly格式并将其保存在文件中：

admin:$1$jUfy$2TVVXJ8sy.KO8ZhAKfIHt/

然后，我们可以使用字典来破解它，例如：

john --format=md5crypt --fork=4 --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt

从上面的截图我们可以看到，平均 速度大约是155000每秒的密码尝试。

使用Hashcat解密Cisco 5类密码

Hashcat将此密码类型识别为哈希模式500。要破解它，我们可以继续使用相同的john friendly格式。然后，我们可以使用字典将其破解，例如：

hashcat -m 500 --username -O -a 0 hashes.txt /usr/share/wordlists/rockyou.txt

请注意，通过使用-O参数（优化的内核），我们将大大提高速度。但这也将密码长度限制为31个字符。


从上面的截图我们可以看到，平均 速度约为120万每秒密码尝试。在我们的案例中，比约翰好得多。

思科8型密码

此密码类型是失败的密码类型4的正确实现。这次，它确实使用PBKDF2算法和10个字符的盐（80位）。本质上，它是SHA256的20,000次迭代，与以前的密码类型相比，这更难破解。

以下示例显示在Cisco配置中找到的类型8密码：

username admin secret 8 $8$dsYGNam3K1SIJO$7nv/35M/qr6t.dVc7UY9zrJDWRVqncHub1PE9UlMQFs

使用John解密Cisco 8型密码

开膛手John将此密码类型识别为pbkdf2-hmac-sha256。要破解它，我们必须再次首先将其转换为以下john friendly格式并将其保存在文件中：

admin:$8$dsYGNam3K1SIJO$7nv/35M/qr6t.dVc7UY9zrJDWRVqncHub1PE9UlMQFs

然后，我们可以使用字典来破解它，例如：

john --format=pbkdf2-hmac-sha256 --fork=4 --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt

从上面的截图我们可以看到，平均 速率大约是1200每秒的密码尝试。不多。

使用Hashcat解密Cisco 8型密码

Hashcat将此密码类型识别为哈希模式9200。要破解它，我们可以继续使用相同的john friendly格式。然后，我们可以使用字典将其破解，例如：

hashcat -m 9200 --username -a 0 hashes.txt /usr/share/wordlists/rockyou.txt

从上面的截图我们可以看到，平均 速率大约是11600每秒的密码尝试。在我们的案例中，它肯定比john快，但总体而言并不是很快。

思科9型密码

此密码类型使用Scrypt算法。Scrypt是专门设计的，即使在具有许多GPU或硬件ASIC的大规模破解平台上，破解也非常困难。这是由于Scrypt需要大量内存才能执行其功能。

以下示例显示在Cisco配置中找到的类型9密码：

username admin secret 9 $9$nhEmQVczB7dqsO$X.HsgL6x1il0RxkOSSvyQYwucySCt7qFm4v7pqCxkKM

使用John解密Cisco 9型密码

开膛手John将此密码类型识别为scrypt。要破解它，我们必须再次首先将其转换为以下john friendly格式并将其保存在文件中：

admin:$9$nhEmQVczB7dqsO$X.HsgL6x1il0RxkOSSvyQYwucySCt7qFm4v7pqCxkKM

然后，我们可以使用字典来破解它，例如：

john --format=scrypt --fork=4 --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt

从上面的截图我们可以看到，平均 速率大约是1400每秒的密码尝试。不多。

使用Hashcat解密Cisco 9型密码

Hashcat将此密码类型识别为哈希模式9300。要破解它，我们可以继续使用相同的john friendly格式。然后，我们可以使用字典将其破解，例如：

hashcat -m 9300 --username -a 0 --force hashes.txt /usr/share/wordlists/rockyou.txt

请注意，--force由于哈希模式9300对于我们的特定设备标记为不稳定，因此我们必须提供参数。

破解技巧

使用KoreLogic自定义规则

开膛手John包含非常有用的规则集，用于生成称为KoreLogic的密码。此规则集起源于DEFCON 2010竞赛，是从模式或传统词典攻击失败时生成密码的好方法。

要使用它，只需创建一个具有以下模式的字典，例如：

infosec
infosecmatter
infosec matter

将其保存到patterns.txt文件中。然后只需像这样运行john：

john --wordlist=patterns.txt --rules=korelogic ...

开膛手链约翰与哈希猫

尽管已进行了一些努力将上述KoreLogic规则转换为Hashcat，但结果只是局部的。幸运的是，我们可以将开膛手John和Hashcat链接在一起，使其完全使用KoreLogic规则。

只需使用stdout上的开膛手John生成密码，并使用如下管道将其输入Hashcat：

john --wordlist=patterns.txt --rules=korelogic --stdout | hashcat ...

相同的方法可以用于我们以john格式创建的任何规则集。
