# Microsoft发布解决Windows 8.1和Windows Server 2012 R2系统中的特权升级漏洞

Microsoft本周发布了针对Windows 8.1和Windows Server 2012 R2系统的带外安全更新，该更新解决了Windows Remote Access中的两个特权升级漏洞。

  

微软于8月解决了这两个漏洞，2020年8月补丁周二的安全更新修复了Windows 10，Windows 7和Windows Server 2008、2012、2016、2019和Windows Server 1903、1909和2004中的漏洞。

  

8月19日，Microsoft宣布提供带外更新，以解决Windows 8.1和Windows Server 2012 R2中的漏洞。IT巨人敦促用户尽快应用安全更新。

  

第一个特权提升漏洞（称为  CVE-2020-1530）与Windows远程访问不适当地处理内存的方式有关。

  

攻击者一旦在受害者系统上获得执行，便可以利用此漏洞，然后可以运行经特殊设计的应用程序以提升特权。

  

第二个漏洞被称为CV E-2020-1537，是Windows远程访问错误地处理文件操作时存在的特权提升漏洞。然后，在受害系统上具有代码执行权限的攻击者可以运行特制应用程序。

  

该安全更新通过确保Windows远程访问正确处理内存和文件操作来解决特权提升漏洞。

  

“ Microsoft宣布为Microsoft 8.1和Windows Server 2012 R2的所有受支持版本提供安全更新4578013，” Microsoft的通报中写道。“运行Windows 8.1或Server 2012 R2的客户应安装更新，以使其产品免受此漏洞的影响。运行其他版本的Microsoft Windows或Windows Server的客户无需采取任何措施。”
