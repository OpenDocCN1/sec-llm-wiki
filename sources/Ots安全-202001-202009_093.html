如果网络使用Mac地址过滤器阻止未经授权的访问怎么办？Mac地址过滤如今在学校，学院，办公室等中普遍使用，以防止外部用户使用它。但这是一种高度安全的方法吗？答案是不。绕过Mac地址过滤器非常容易。


同样在这里，我们使用airmon-ng和airodump-ng绕过过滤器。让我们开始教程：首先启动airmon-ng以启动监视模式。要开始监视，请输入以下命令：

sudo airmon-ng start wlan0


这将启动监视模式。现在我们要在终端上查看监视，以便我们可以根据结果分析网络。为此，请发出命令

sudo airodump-ng mon0


现在，它将列出所有可用的SSID。它还将在开头列出相应的bssid。现在，我们要做的是，列出要过滤的macs要连接到的SSID的所有信息。因此，使用以下命令：

sudo airo­dump-ng -c 4 -a –bssid 00:00:00:00:00:00 mon0

在这里，我们使用“ -c 4 ”来指定我们正在寻找的SSID在通道号4上，而我们使用“ -a ”来指定我们仅需要连接到该网络的客户端的详细信息。这还将共享当前正在使用网络的用户的mac地址。airodump-ng将显示连接到它的所有用户的mac地址。因此，现在仅剩下一项任务。我们将mac地址更改为我们获得的mac地址之一，以便我们可以成功连接到网络。为此，我们将使用macchanger。


现在，该mac地址肯定会在白名单上，这就是他使用网络的原因。在以下屏幕截图中，您可以看到名为Station的列。


现在，让我们将其更改为白名单中的mac地址之一。但在此之前，我们必须停止监视接口，然后执行以下命令：

sudo airmon-ng stop wlan0

之后，使用macchanger欺骗mac地址：

mac­cha­nger -m xx:Xx:Xx:xx:xx:xx wlan0

将以下命令替换为您需要欺骗的新mac地址，就这样，您的mac地址就被欺骗了。现在，您可以成功连接到SSID，而不会出现任何问题。


注意：

有时可能会导致具有相同Mac地址的 2台PC 连接到同一网络的问题。如果您确实想连接到网络，则别无选择，只能冒险。
