中间人攻击（MITM）是攻击者可以从受害者那里窃取用户凭据的最简单方法之一。基本上，攻击者所做的是，他将以某种方式与受害者建立联系，并通过他路由受害者的流量。现在，攻击者可以分析受害者发送的数据包，以窃取其凭据和其他有价值的东西。最常见的方法之一是在Kali-Linux中使用ettercap或_ Evil twin的攻击。我们将在这里看到如何使用邪恶双生子攻击。


在实际情况下，当您的PC扫描可用的Wi-Fi网络时，如果有2个具有相同SSID（或相同名称）的网络，则PC将仅显示1个对您的Wi-Fi卡具有较强信号的网络。这意味着，如果我们比路由器更靠近受害者，那么我们可以创建一个具有相同名称的Wi-Fi热点，并且受害者的PC将自动连接到我们。然后，我们可以使用DHCP3将流量从我们的PC路由到Internet。因此受害者永远不会知道我们正在他和互联网之间进行游戏。创建真正的SSID的邪恶双胞胎就可以解决问题，因此命名为邪恶双胞胎攻击。让我们看看我们如何使用邪恶的双胞胎在中间攻击中做人：


1）创建airmon-ng监控界面。使用此命令执行此操作：

sudo airmon-ng start wlan0


这将启动监视模式，通常为mon0或mon1。现在我们需要将监视结果转储到我们的终端。


2）要转储结果，我们使用airodump-ng：

sudo airodump-ng mon0


这将在您的终端上显示许多信息，例如可用的Wi-Fi网络，频道，用户，Mac地址等。现在，从列表中，例如，如果有一个名为“公共Wi-Fi”的热点，我们需要创建它邪恶的双胞胎。


3）为此，我们使用airbase-ng：

sudo airbase-ng --essid "Public Wi-Fi" -c 1 mon0


现在，这将启动一个新热点，名称为“ Public Wi-Fi”，这是真正的热点。现在我们要做的是，将Deauth攻击发送到真实的Wi-Fi网络，以便连接到该网络的所有用户都将断开连接并加入我们的邪恶双胞胎。


4）要进行deauth攻击，我们使用：

sudo aireplay-ng -0 0 -a XX:XX:XX:XX:XX:XX mon0


现在，这将继续对路由器进行deauth攻击，直到我们按ctrl + c为止。XX：XX：XX：XX：XX：XX是路由器的MAC地址。因此，如果我们继续进行deauth攻击（例如20秒），则足以使用户断开连接并重新连接到我们的邪恶双生网络。而已。我们将受害者连接到PC。


现在，您可以配置DHCP3将数据包路由到Internet，或者可以使用Kali-Linux中的Social Engineering Toolkit窃取密码。您也可以使用Wireshark进行相同的操作。有时，出于安全原因，SSID将被隐藏，或者使用Mac地址过滤网络。
