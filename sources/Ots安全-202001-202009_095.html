在此版本中，Kali Linux团队引入了以下概述的各种新功能。


Kali Linux切换到ZSH作为默认Shell

在此版本中，Kali Linux团队开始了从默认Bash shell切换到ZSH的计划。


在下一版本Kali Linux 2020.4中，默认外壳将自动切换到ZSH，以便用户可以从许多插件，主题和其他功能（例如路径扩展，自动目录更改和自动建议）中受益。


Kali Linux团队解释说：“您可以使用bash进行很多高级操作，并对其进行自定义以执行更多操作，但是ZSH允许您执行更多操作。这是一个很大的卖点。”


在此发行版中，bash仍将是默认的shell，但是ZSH也将由Kali团队创建的新配置进行安装。

ZSH好处

对于安装全新安装的Kali用户，您只需输入“ zsh”命令即可试用ZSH shell 。


对于升级到2020.3的用户，您首先需要使用以下命令安装ZSH Shell：

sudo apt install -y zsh zsh-syntaxhighlightingzsh-autosuggestions

对于这些升级，要使用由Kali创建的新ZSH配置，您需要将其复制到您的家庭中：

cp /etc/skel/.zshrc ~/

如果发现喜欢使用ZSH并将其设置为默认外壳，则可以使用以下命令：

chsh -s /bin/zsh


工具图示

在此版本中，Kali菜单中的每个工具现在都将具有新的主题图标，如下所示。


“在过去的几个发行版中，我们一直在展示获取更多主题工具图标的进展。现在我们可以说，如果您使用默认工具列表（kali-linux-default），则菜单中的每个工具（然后是额外的几个！），现在应该有自己的图标，” Kali Linux小组在有关新版本的博客文章中指出。

如何获取Kali Linux 2020.3

要安装Kali Linux 2020.3的新版本，您可以下载支持完整安装或实时发行版的ISO映像。


对于从先前版本进行的更新，可以使用以下命令进行升级：

echo "deb http://http.kali.org/kali kali-rolling main non-free contrib" | sudo tee /etc/apt/sources.list

sudo apt update && sudo apt -y full-upgrade

[ -f /var/run/reboot-required ] && sudo reboot -f

然后，您可以使用以下命令检查升级是否成功：

grep VERSION /etc/os-release
