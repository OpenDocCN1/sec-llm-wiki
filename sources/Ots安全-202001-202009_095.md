在此版本中，Kali Linux团队引入了以下概述的各种新功能。

  

**Kali Linux切换到ZSH作为默认Shell**

在此版本中，Kali Linux团队开始了从默认Bash shell切换到ZSH的计划。

  

在下一版本Kali Linux 2020.4中，默认外壳将自动切换到ZSH，以便用户可以从许多插件，主题和其他功能（例如路径扩展，自动目录更改和自动建议）中受益。

  

Kali Linux团队解释说：“您可以使用bash进行很多高级操作，并对其进行自定义以执行更多操作，但是ZSH允许您执行更多操作。这是一个很大的卖点。”

  

在此发行版中，bash仍将是默认的shell，但是ZSH也将由Kali团队创建的新配置进行安装。

要安装Kali Linux 2020.3的新版本，您可以下载支持完整安装或实时发行版的ISO映像。

  

对于从先前版本进行的更新，可以使用以下命令进行升级：

[ -f /var/run/reboot-required ] && sudo reboot -f
