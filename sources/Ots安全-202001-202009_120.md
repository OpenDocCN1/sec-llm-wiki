## CMSeek的功能：

*   超过170个CMS的基本CMS检测
    
*   Drupal版本检测
    
*   先进的Wordpress扫描
    

*   检测版本
    
*   用户枚举
    
*   插件枚举
    
*   主题枚举
    
*   检测用户（3种检测方法）
    
*   寻找版本漏洞等等！
    

*   先进的Joomla扫描
    

*   版本检测
    
*   备份文件查找器
    
*   管理员页面查找器
    
*   核心漏洞检测
    
*   目录清单检查
    
*   配置泄漏检测
    
*   其他各种检查
    

*   模块化蛮力系统
    

*   使用预制的bruteforce模块或创建自己的模块并与之集成
    

## 要求和兼容性：

CMSeeK是使用python3构建的，您将需要python3来运行此工具，并且到目前为止可与基于unix的系统兼容。Windows支持将在以后添加。CMSeeK依赖git进行自动更新，因此请确保已安装git。

## 安装和使用：

使用CMSeeK相当容易，只需确保已安装python3和git（仅用于克隆存储库）并使用以下命令：

*   git克隆 `https://github.com/Tuhinshubhra/CMSeeK`
    
*   光盘CMSeeK
    
*   pip / pip3 install -r requirements.txt
    

对于引导式扫描：

*   python3 cmseek.py
    

其他：

*   python3 cmseek.py -u <target\_url> \[...\]
    

程序中的帮助菜单：

```
USAGE:
```

## 检查更新：

您可以从主菜单`python3 cmseek.py --update`检查更新，也可以用于检查更新和应用自动更新。

PS：请确保已`git`安装，CMSeeK使用git来应用自动更新。

## 检测方法：

CMSeek通过以下方式检测CMS：

*   HTTP头
    
*   生成器元标记
    
*   页面源代码
    
*   robots.txt
    

## 支持的CMS：

CMSeeK当前可以检测170多个 CMS。检查以下列表：目录中存在的cmss.py文件`cmseekdb`。所有cmss均以以下方式存储：

```
 cmsID = {
```

## Bruteforce模块：

CMSeek具有模块化的bruteforce系统，这意味着您可以添加自定义的bruteforce模块以与cmseek一起使用。不久将创建一个用于创建模块的适当文档，但是如果您已经弄清楚了如何做（一旦分析了预制模块，这将非常容易），那么您需要做的就是：

1.  完全像这样添加评论`# <Name Of The CMS> Bruteforce module`。这将帮助CMSeeK使用正则表达式了解CMS的名称
    
2.  添加另一个注释`### cmseekbruteforcemodule`，这将帮助CMSeeK知道它是一个模块
    
3.  将模块复制并粘贴到`brutecms`CMSeeK目录下的目录中
    
4.  使用`R`第一个菜单中的输入打开CMSeeK和Rebuild Cache 。
    
5.  如果一切正确，您将看到类似这样的内容（请参阅下面的屏幕截图），并且下次打开CMSeeK时，模块将列在bruteforce菜单中。
