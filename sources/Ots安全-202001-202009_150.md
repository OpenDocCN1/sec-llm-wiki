# Autoenum-自动服务枚举脚本

AutoRecon是一种多线程网络侦察工具，可以执行服务的自动枚举。它旨在用作节省时间的工具，用于CTF和其他渗透测试环境（例如OSCP）。在现实世界中参与也可能很有用。

该工具通过首先执行端口扫描/服务检测扫描来工作。根据这些最初的结果，该工具将使用许多不同的工具对这些服务启动进一步的枚举扫描。例如，如果找到HTTP，则将启动nikto（以及许多其他命令）。

该工具中的所有内容都是高度可配置的。默认配置不执行任何自动利用，以使工具与OSCP考试规则保持一致。如果您希望向配置中添加自动利用工具，则后果自负。对于因滥用该工具而导致的负面行为，作者概不负责。

## 起源

：AutoRecon是由三个工具，其在OSCP实验室使用的作者灵感侦察，ReconScan和BSCAN。尽管这三个工具都很有用，但三个工具都没有一个具有所需的功能。AutoRecon结合了上述工具的最佳功能，同时还实现了许多新功能，以帮助测试人员枚举多个目标。

## 特征

*   支持IP地址，IP范围（CIDR表示法）和可解析主机名形式的多个目标。
    
*   可以同时扫描目标，并利用多个处理器（如果可用）。
    
*   可自定义的端口扫描配置文件，可以灵活地进行初始扫描。
    
*   可自定义的服务枚举命令和建议的手动后续命令。
    
*   用于结果收集的直观目录结构。
    
*   完整记录已运行的命令，如果失败则显示错误。
    
*   全局和每次扫描模式匹配，因此您可以突出显示/提取噪音中的重要信息。
    

## 用法

AutoRecon使用Python 3的特定功能，但不支持Python 2。

```
usage: autorecon    [-h] [-t TARGET_FILE] [-ct <number>] [-cs <number>]
```

### 例子

扫描单个目标：

```
$ autorecon 127.0.0.1
```

默认端口扫描配置文件首先执行完整的TCP端口扫描，前20个UDP端口扫描和前1000个TCP端口扫描。您可能会问为什么AutoRecon与完整的TCP端口扫描（也扫描那些端口）同时扫描前1000个TCP端口。原因很简单：大多数开放端口通常在前1000个端口中，我们希望快速枚举服务，而不是等待Nmap扫描每个端口。如您所见，所有服务枚举扫描实际上都在完成完整的TCP端口扫描之前完成。尽管工作量稍有重复，但它可以通过将实际的枚举结果更快地返回给测试人员来获得回报。

请注意，如果您的终端支持，则实际的命令行输出将显示为彩色。

扫描多个目标

```
$ autorecon 192.168.1.100 192.168.1.1/30 localhost
```

AutoRecon每次扫描支持多个目标，并将扩展CIDR表示法提供的IP范围。默认情况下，一次仅扫描5个目标，每个目标10次扫描。

使用高级选项扫描多个目标

```
$ autorecon -ct 2 -cs 2 -vv -o outputdir 192.168.1.100 192.168.1.1/30 localhost
```

在此示例中，-ct选项将并发目标的数量限制为2，-cs选项将每个目标的并发扫描数量限制为2。-vv选项使输出非常冗长，显示了每次扫描的输出跑。\-o选项设置用于保存扫描结果的自定义输出目录。
