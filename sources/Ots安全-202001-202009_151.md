t14m4t是自动的暴力破解攻击工具，是THC-Hydra和Nmap Security Scanner的包装。

t14m4t正在扫描用户定义的目标（或包含目标的文档）以查找t14m4t支持的服务的开放端口，然后使用最常用的弱凭据列表对运行在发现的端口上的服务发起暴力攻击。

# 安装：

安装包括克隆存储库和使t14m4t可执行。要运行t14m4t，需要THC-Hydra和Nmap Security Scanner。

```
# git clone https://github.com/MS-WEB-BN/t14m4t/
```

# 用法：

t14m4t唯一需要的参数是目标标识（显然）。目标参数也可以是一个文件，其中每个目标都由return分隔。线程数（如果为可选参数，范围为1到64）。如果未定义，则t14m4t使用16个（默认）线程运行攻击。

```

# ./t14m4t <target> <number of threads>
```

例：

```
# ./t14m4t 192.168.0.1 32
```
