# 黑客已利用Cisco ASA和FTD中的CVE-2020-3452漏洞

安全公司发现黑客已经在利用CVE-2020-3452自适应安全设备（ASA）和Firepower威胁防御（FTD）漏洞

思科网络安全软件，自适应安全设备和Firepower威胁防御中发现的一个高度严重的漏洞可能会将敏感数据（例如WebVPN配置和Web Cookie）泄漏给潜在的黑客。

  

该漏洞已被授予唯一标识符CVE-2020-3452，该漏洞存在于Cisco Firepower威胁防御（FTD）软件的Web服务接口中，该软件是其网络安全和流量管理产品套件的一部分；以及Adaptive Security Appliance（ASA）软件，这是ASA公司网络安全设备系列的操作系统。

  

思科在星期三的一份咨询报告中说：“攻击者可以通过向受影响的设备发送包含目录遍历字符序列的精心设计的HTTP请求来利用此漏洞  。” “成功利用漏洞可以使攻击者查看目标设备上Web服务文件系统内的任意文件。”

  

尽管思科已经修补了该漏洞，但安全研究公司Rapid7表示：“自补丁发布以来，仅约10％的Cisco ASA / FTD设备已重新启动。” Rapid7表示，这表明使用易受攻击的思科产品的398家《财富》 500强公司中只有27家已得到修补。
