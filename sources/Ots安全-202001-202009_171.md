# 思科网络安全缺陷泄漏敏感数据

该缺陷存在于思科的网络安全Firepower威胁防御（FTD）软件及其自适应安全设备（ASA）软件中。

  

思科网络安全软件中的一个高度严重的漏洞可能会将敏感数据（如WebVPN配置和Web Cookie）暴露给未经身份验证的远程攻击者。

  

该漏洞存在于思科Firepower威胁防御（FTD）软件的Web服务接口中，该软件是其网络安全和流量管理产品套件的一部分；以及Adaptive Security Appliance（ASA）软件，这是ASA公司网络安全设备系列的操作系统。

  

思科公司在星期三的一份咨询报告中说：“攻击者可以通过向受影响的设备发送包含目录遍历字符序列的精心设计的HTTP请求来利用此漏洞。” “成功利用漏洞可以使攻击者查看目标设备上Web服务文件系统内的任意文件。”

  

该漏洞（CVE-2020-3452）在CVSS等级中的7.5中排名10（7.5），这是由于缺乏对受影响设备处理的HTTP请求中URL的正确输入验证所致。具体来说，该漏洞使攻击者可以进行目录遍历攻击，这是一种HTTP攻击，使恶意行为者可以访问受限制的目录并在Web服务器的根目录之外执行命令。

  

“该漏洞……非常危险，” Positive Technologies的Mikhail Klyuchnikov说，他在向Threatpost提供的一份声明中独立报告了该漏洞（以及RedForce的Ahmed Aboul-Ela）。“原因是未能充分验证输入。攻击者可以发送特制的HTTP请求来访问文件系统（RamFS），该文件系统将数据存储在RAM中。”

  

潜在的攻击者只能查看Web服务文件系统中的文件。已为特定的WebVPN和AnyConnect功能启用了Web服务文件系统（在思科咨询中概述）。攻击者可以查看的Web服务文件可能包含WebVPN配置，书签，Web Cookie，部分Web内容和HTTP URL之类的信息。

  

思科表示，如果产品运行带有漏洞的AnyConnect或WebVPN配置的易受攻击的Cisco ASA软件或Cisco FTD软件版本，则该漏洞会影响产品：“当受影响的设备配置了WebVPN或AnyConnect功能时，将启用Web服务文件系统”，根据其咨询。但是，“此漏洞不能用于获取对ASA或FTD系统文件或基础操作系统（OS）文件的访问。”

  

为了消除该漏洞，Klyuchnikov敦促思科用户将思科ASA更新到最新版本。思科表示尚不知道该漏洞的任何恶意利用-但是，它知道安全研究员Ahmed Aboul-Ela 周三发布的概念验证（POC）利用代码。
