TCP/UDP端口 + SMB爆破工具

一个简单而功能强大的TCP和UDP端口扫描程序：

  • 检测打开，关闭和过滤的端口（TCP和UDP）

  • 能够扫描单个主机，网络范围或文件中的主机列表

  • 可调超时值，可进行有效而可靠的端口扫描

尽管具有简约的设计，但两个端口扫描程序都使用在当前工作目录中创建的简单状态文件（scanresults.txt）来跟踪所有内容。如果扫描仪被打断，则可以轻松恢复它们，或者跳过已扫描的主机/端口。


有关详细说明，请参见主要文章：

https://www.infosecmatter.com/minimalistic-tcp-and-udp-port-scanner/


用法和示例

Import-Module .\port-scan-tcp.ps1
Import-Module .\port-scan-udp.ps1

# Usage:
port-scan-tcp <host(s)> <port(s)>
port-scan-udp <host(s)> <port(s)>

单个主机的端口tcp / 80（HTTP）的端口检查

port-scan-tcp 192.168.205.15 80

在单个主机上扫描常见的TCP端口

port-scan-tcp 10.10.0.1 (21,22,23,25,80,443,445,3389)

扫描文件中的主机列表中的端口tcp / 22（SSH）

port-scan-tcp (gc .\computers.txt) 22

扫描网络范围/ 24的端口tcp / 445（SMB）

0..255 | foreach { port-scan-tcp 192.168.204.$_ 445 }

在单个主机上扫描常见的UDP服务

test-port-udp 192.168.205.15 (53,161,623)

扫描网络范围/ 24的端口udp / 161（SNMP）

0..255 | foreach { test-port-udp 10.10.0.$_ 161 }

注意：port-scan-tcp-compat.ps1版本适用于未安装.NET 4.5的旧系统。

简约的SMB登录蛮力（smblogin.ps1）

一个简单的SMB登录攻击和密码喷涂工具。

它以目标和凭据（用户名和密码）的列表作为参数，并尝试使用提供的凭据针对每个目标进行身份验证。

尽管设计简约，但该工具通过将每个结果写入文本文件来跟踪所有内容。如果该工具被中断或跳过已经受到威胁的目标，则可以轻松恢复该工具。

有关详细说明，请参见主要文章：https : //www.infosecmatter.com/minimalistic-smb-login-bruteforcer/

用法和示例

Import-Module .\smblogin.ps1

# Usage:
smblogin <hosts.txt> <username> <password>

# Examples:
smblogin hosts.txt .\Administrator P@ssw0rd
smblogin hosts.txt CORP\bkpadmin P@ssw0rd

注意：额外的迷你版本缺少端口tcp / 445的检查，否则功能相同。
