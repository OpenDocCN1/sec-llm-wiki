# 蓝牙重新连接漏洞使10亿个BLE设备被攻击

蓝牙重新连接漏洞使10亿个BLE设备和16,000个BLE应用程序遭受BLE欺骗攻击（BLESA）

一组研究人员发现了蓝牙无线通信协议中的一个新漏洞，该漏洞暴露了近10亿个蓝牙低功耗（BLE）设备和16,000个BLE应用程序。低功耗蓝牙（BLE）是移动设备和IoT设备之间相互通信的最常见蓝牙协议。研究人员发现，潜在的黑客可以利用BLE协议中的重新连接漏洞来发起BLESA或BLE欺骗攻击。

  

该研究团队由Nan Yuhong，Vireshwar Kumar，Dave（Jing）Tian，Antonio Bianchi，Mathias Payer和Xu Dongyan组成，并对BLE进行了分析，以揭示BLE的两个关键设计弱点：

*   对于某些BLE设备，设备重新连接期间的身份验证是可选的，而不是强制性的。
    
*   对于其他BLE设备，如果用户的设备无法强制IoT设备对通信的数据进行身份验证，则可能会绕过身份验证。
    

  

BLE设备通常使用非常独特的配对过程相互连接。但是，一旦完成了初始配对，重新连接就会自动进行，并且无需用户的知情或同意即可进行。蓝牙设备通常会移出范围，然后稍后又移回范围，并与先前配对的蓝牙设备重新建立自动连接，而无需任何用户交互。普渡大学的研究人员在先前配对的BLE设备的重新连接过程中发现了一个漏洞。

  

在发现BLE无需身份验证如何重新连接的固有缺陷之后，研究人员分析了主流BLE堆栈实现，包括Linux，Android，iOS和Windows上的BLE协议堆栈。经过分析，普渡大学的研究人员得出结论，可能有超过10亿个BLE设备和16,000个BLE应用程序容易受到BLESA的攻击。
