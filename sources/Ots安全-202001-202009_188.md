# 伊朗黑客组织手滑泄漏了自己内部培训视频

伊朗威胁行动者的一次OPSEC错误通过提供对“幕后调查其方法”的罕见见解，暴露了黑客组织的内部运作。

  

IBM的X-Force事件响应情报服务（IRIS）获得了由国家资助的组织ITG18（也称为Charming Kitten，Phosphorous或APT35）用于培训其操作员的近五个小时的视频录像。

  

黑客从受害者帐户（包括美国和希腊军事人员）窃取的40 GB数据中，发现了泄漏的视频。数据中的其他线索表明，这些黑客针对的是美国国务院工作人员和一名未透露姓名的伊朗裔美国慈善家。

  

IBM研究人员说，他们在虚拟私有云服务器上发现了这些视频，这些视频由于安全设置的错误配置而暴露在外。该服务器在今年早些时候还被发现可以托管多个ITG18域，可容纳40 GB以上的数据。

![](../Images/292d1efa14503da4a444abdd8c4812a1.png)

发现的视频文件表明，ITG18可以访问通过鱼叉式网络钓鱼获得的目标电子邮件和社交媒体凭据，使用该信息登录帐户，删除可疑登录的通知，以便不向受害者发出警报并泄露联系人，照片和来自Google云端硬盘的文档。

  

除此之外，使用Bandicam的屏幕录制工具捕获的视频还显示，行动背后的参与者将受害者的凭证插入了Zimbra的电子邮件协作软件，该软件旨在监视和管理受感染的电子邮件帐户。

![](../Images/cb67018884e983b2143b8be1151e9937.png)

其他剪辑显示ITG18组利用虚拟Yahoo! 帐户，其中包括带有伊朗国家代码（+98）的电话号码，使用这些帐户发送网络钓鱼电子邮件，其中一些邮件被弹回，表明这些电子邮件未到达受害者的收件箱。

研究人员说：“在视频中，操作员正在验证受害者的凭据，如果操作员针对通过多因素身份验证（MFA）设置的站点成功进行了身份验证，他们将暂停并转到另一组凭据，而没有获得访问权限。” 。

ITG18长期以来一直以美国和中东的军事，外交和政府人员为目标，以收集情报和从事间谍活动，以服务于伊朗的地缘政治利益。
