# F5发布有关BIG-IP TMUI RCE漏洞CVE-2020-5902的安全公告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247486760&idx=1&sn=55a55aae2d348895092c17c4f6df8a6c&chksm=9bae4463acd9cd75a841b21574d4bb7eccd783aa724851110b6909ac2c3c4545fc815d2ed1e3&scene=126&sessionid=1681670178#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247486760&idx=1&sn=55a55aae2d348895092c17c4f6df8a6c&chksm=9bae4463acd9cd75a841b21574d4bb7eccd783aa724851110b6909ac2c3c4545fc815d2ed1e3&scene=126&sessionid=1681670178#rd)

F5发布了一个安全公告，以解决BIG-IP流量管理用户界面（TMUI）中的远程代码执行（RCE）漏洞CVE-2020-5902。攻击者可能利用此漏洞来控制受影响的系统。

  

根据威胁情报监控，Positive Technologies的专家发现，到2020年6月，全球互联网上有8,000多个易受攻击的设备可供使用，其中40％位于美国，16％在中国，3％在台湾，在加拿大和印度尼西亚为2.5％。在俄罗斯，不到1％的易受攻击设备被检测到。

  

漏洞CVE-2020-5902的CVSS评分为10，表示危险度最高。要利用此漏洞，攻击者需要向托管用于BIG-IP配置的流量管理用户界面（TMUI）实用程序的服务器发送特制的HTTP请求。

  

研究员Mikhail Klyuchnikov说：“通过利用此漏洞，具有BIG-IP配置实用程序访问权限的远程攻击者可以在未经授权的情况下执行远程代码执行（RCE 1）。攻击者可以创建或删除文件，禁用服务，拦截信息，运行任意系统命令和Java代码，完全破坏系统，以及追求其他目标，例如内部网络。在这种情况下，RCE是由多个组件中的安全漏洞导致的，例如允许目录遍历的组件。对于在Shodan等搜索引擎上列出了F5 BIG-IP Web界面的公司而言，这尤其危险。幸运的是，大多数使用该产品的公司都无法通过互联网访问该界面。”

  

建议受影响的公司进行更新。应将BIG-IP的脆弱版本（11.6.x，12.1.x，13.1.x，14.1.x，15.0.x，15.1.x）替换为相应的更新版本（11.6.5.2、12.1.5.2、13.1）。3.4、14.1.2.6、15.1.0.4）。AWS，Azure，GCP和阿里巴巴等公共云市场的用户应切换到BIG-IP虚拟版（VE）版本11.6.5.2、12.1.5.2、13.1.3.4、14.1.2.6、15.0.1.4或15.1。0.4（如果有）。其他建议在F5 BIG-IP公告中给出。为了阻止这种和其他潜在的攻击，公司可以部署Web应用程序防火墙，例如PT Application Firewall。

  

F5还修复了Mikhail Klyuchnikov在BIG-IP配置界面中发现的第二个漏洞。XSS漏洞CVE-2020-5903（得分：7.5）允许以登录用户的身份运行恶意JavaScript代码。如果用户具有管理员特权并有权访问Advanced Shell（bash），则成功利用该漏洞可能会导致通过RCE完全破坏BIG-IP。F5在安全公告中提供了详细信息和建议。

  

为了阻止利用诸如CVE-2020-5902和CVE-2020-5903之类的漏洞的攻击，公司可以部署Web应用程序防火墙，例如PT Application Firewall。
