0x01。环境搭建

1.1主机机创建

在VMware Workstation中创建Ubuntu 20.04虚拟机，并为虚拟机的CPU开启虚拟化引擎相关选项，使之支持嵌入式虚拟化，对QEMU进行调试分析。

安装好Ubuntu之后，可以先将源设置为国内的开源初始化网站，然后执行如下命令更新系统组件：

$ sudo apt-get update$ sudo apt-get upgrade


编译QEMU需要Python 2，因为Ubuntu 20.04中只有Python 3，所以需要自行安装Python 2：

$ sudo apt-get install python2$ sudo ln -s /usr/bin/python2 /usr/bin/python
