“首先，合法的Little Snitch安装程序将经过精美且专业的包装，并带有经过适当代码签名的精心制作的自定义安装程序，” Malwarebytes的Mac和移动设备主管Thomas Reed说。“但是，此安装程序是一个带有通用图标的简单Apple安装程序包。更糟糕的是，该安装程序包毫无意义地分布在磁盘映像文件中。”


Microsoft发布紧急安全更新以修复Windows编解码器

Microsoft通过Windows Store应用程序静默发布了两个带外安全更新，以解决Windows Codecs库中的两个漏洞。


这两个问题是跟踪为CVE-2020-1425  和  CVE-2020-1457的远程执行代码漏洞，这些漏洞影响Windows 10和Windows Server 2019操作系统。


“ Microsoft Windows Codecs库处理内存中对象的方式中存在一个远程执行代码漏洞。成功利用此漏洞的攻击者可以获得信息，以进一步危害用户的系统。

Reed对Little Snitch安装程序的恶意版本进行了分析，他说：“它具有精美且专业的包装，并带有经过正确代码签名的精心制作的自定义安装程序。”


安装过程中，图标看起来像合法的Little Snitch安装程序和卸载程序应用程序，一旦安装完成，它也会运行shell脚本。


恶意软件的安装过程并不复杂，因此勒索软件的成功率低于其水平。


一旦恶意软件感染过程开始，它就会开始在硬盘驱动器中自行传播，并建立持久性。
