**CVE-2020-0796**  

**NVD的描述**

Microsoft服务器消息块3.1.1（SMBv3）协议处理某些请求的方式中存在一个远程执行代码漏洞，也称为“ Windows SMBv3客户端/服务器远程执行代码漏洞”。

  

**Forti的描述**

**MS SMB服务器压缩转换标头内存损坏**

这表明存在尝试利用Microsoft SMB服务器中的缓冲区溢出漏洞的攻击。此漏洞是由于易受攻击的软件处理恶意制作的压缩数据包时出错。远程未经身份验证的攻击者可以利用此漏洞在应用程序的上下文中执行任意代码。

  

**受影响的产品**

Windows 10版本1903（用于32位系统）

Windows 10版本1903（用于基于x64的系统）

Windows 10版本1903（用于基于ARM64的系统）

Windows Server版本1903（服务器核心安装）

Windows 10版本1909（用于32位系统）

Windows 10版本1909对于基于x64的系统

Windows 10版本1909对于基于ARM64的系统

Windows Server版本1909（服务器核心安装）

  

**影响力**

系统危害：远程攻击者可以控制易受攻击的系统。

  

**建议措施**

应用供应商提供的最新升级或补丁。

https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2020-0796

  

**参考资料**

https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2020-0796

**CVE-2020-13401**

**NVD的描述**

在19.03.11之前的Docker Engine中发现了一个问题。具有CAP\_NET\_RAW功能的容器中的攻击者可以制作IPv6路由器通告，从而欺骗外部IPv6主机，获取敏感信息或导致拒绝服务。

  

  

**CVE-2020-13777**

**NVD的描述**

3.6.14之前的GnuTLS 3.6.x使用不正确的加密技术来加密会话票证（TLS 1.2中机密性的丢失和TLS 1.3中的身份验证的绕过）。最早受影响的版本是3.6.4（2018-09-24），因为2018-09-18提交中存在错误。在第一次密钥轮换之前，TLS服务器始终使用错误的数据来代替从应用程序派生的加密密钥。

  

  

**CVE-2020-3956**

**NVD的描述**

10.0.0.2之前的VMware Cloud Director 10.0.x，9.7.0.5之前的9.7.0.x，9.5.0.6之前的9.5.0.x和9.1.0.4之前的9.1.0.x无法正确处理导致代码的输入注入漏洞。经过身份验证的参与者可能能够将恶意流量发送到VMware Cloud Director，这可能导致任意远程代码执行。可以通过基于HTML5和Flex的UI，API Explorer界面和API访问来利用此漏洞。

  

  

**CVE-2020-8618**

**NVD描述**

允许通过区域传输将区域数据发送到服务器的攻击者可以利用此漏洞通过特制的区域有意触发断言失败，从而拒绝为客户端提供服务。

  

**CVE-2020-8619**

**NVD描述**

除非名称服务器为一个或多个区域提供权威服务，并且至少一个区域包含一个带星号（\*）的空非终端条目，否则不会遇到此缺陷。理论上，准许更改区域内容的潜在攻击者可以引入这样的记录，以便利用此条件导致拒绝服务，尽管我们认为使用此向量的可能性不大，因为任何此类攻击都需要很高的特权级别，并且易于追踪。

**NVD描述**

适用于：iPhone 6s和更高版本，iPad Air 2和更高版本，iPad mini 4和更高版本以及iPod touch第7代

影响：应用程序可能能够以内核特权执行任意代码
