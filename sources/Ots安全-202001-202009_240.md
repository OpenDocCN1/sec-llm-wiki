# **Vuln ID**：CVE-2020-15306

**发布时间：**2020年6月26日01：15：10Z

****漏洞详情**：**在v2.5.2之前的OpenEXR中发现了一个问题。无效的chunkCount属性可能会导致IlmImf / ImfMisc.cpp中的getChunkOffsetTableSize（）中的堆缓冲区溢出。

  

# **Vuln ID**：CVE-2020-15305

**发布时间**：2020年6月26日01：15：10Z

**漏洞详情**：在2.5.2之前的OpenEXR中发现一个问题。无效的输入可能会导致IlmImf / ImfDeepScanLineInputFile.cpp中的DeepScanLineInputFile :: DeepScanLineInputFile（）中的释放后使用。

#   

# **Vuln ID**：CVE-2020-15304

**发布时间**：2020年6月26日01：15：10Z

**漏洞详情**：在2.5.2之前的OpenEXR中发现一个问题。无效的切片输入文件可能会导致IlmImf / ImfTiledInputFile.cpp中的TiledInputFile :: TiledInputFile（）中的无效内存访问，如NULL指针取消引用所示。
