# Ripple20配置错误导致数百万设备出现安全问题

安全研究人员发现了一些改变游戏规则的漏洞，这些漏洞给数十个相连的设备供应商及其客户带来麻烦。本周二，安全公司JSOF在一个低级网络软件库中发布了19个CVE，其中四个是关键的远程代码执行漏洞，使数百万个设备容易受到攻击。

  

研究人员称该发现为Ripple20标签，该漏洞使攻击者能够控制面向Internet的设备，然后潜伏数年未见踪影。他们的脆弱性分析说，其他风险包括使用被入侵设备作为立足点的网络内部大规模感染。黑客无需使用用户干预即可使用这些漏洞来接管您的网络。

  

与供应商保持联系一直是JSOF的优先事项。JSOF表示，截至昨天为止，已有15家企业受到影响，其中包括Cisco，HP和Schneider Electric。另外57个仍在调查对其产品的影响，包括EMC，GE，Broadcom和NVIDIA。未受影响的是AMD，飞利浦和德州仪器（至少根据他们自己的报告）。

  

开发人员Treck，Inc是这些错误的来源（并已修复）。该公司在20年前编写了一个低级TCP / IP库，已将其许可给其他供应商。这些错误使数以亿计的设备面临风险。据JSOF称，即使使用该代码追踪制造商和产品也是一个重大挑战。现在，他们必须将更新的软件投放到他们的产品中，并在可能的情况下更新旧的软件。

  

防止新的bug造成危害已经足够糟糕了，但是当一个已有多年历史的代码渗透到无数产品中，并带来严重的缺陷时，这是一个更为严重的问题。那时，您最大的问题是将要设法创建的任何代码修复程序带入现场。

  

这些错误的基本详细信息现在才可用，但是研究人员将在今年的BlackHat USA之后发布另外两份白皮书，说明他们如何设法利用其中的一些错误来关闭Schneider Electric UPS。

  

在此之前，该公司已为设备供应商和网络运营商列出了一些建议，向他们展示了如何保护他们无法立即更新的设备。
