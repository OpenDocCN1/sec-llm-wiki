# 揭秘外挂产业链，月入千万，还能轻松毁掉一款游戏

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247485729&idx=3&sn=e368a109b28c62bc42dd41266299579e&chksm=9bae406aacd9c97cae253cfd42cedbc6733b149b337073c21d110c035547fe172c739cff2f37&scene=126&sessionid=1681670198#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247485729&idx=3&sn=e368a109b28c62bc42dd41266299579e&chksm=9bae406aacd9c97cae253cfd42cedbc6733b149b337073c21d110c035547fe172c739cff2f37&scene=126&sessionid=1681670198#rd)

外挂一直以来都存在于各类游戏之中，不论是Moba类游戏中的走位脚本，还是FPS游戏中的透视追踪，乃至回合制网游中的修改数据，外挂自游戏出现以来就从未停止过更新的脚步。虽然在最开始游戏制作者认为外挂并没有那么恐怖，但在之后外挂的发展迅速出乎所有人意料，也成为游戏的最大敌人之一。

![](../Images/fc138133893b9f633ad568d94641c093.png)

外挂带来的不仅有更爽快的游戏体验，还有高到恐怖的高额利润。无数人选择在大逃杀游戏中有外挂大杀特杀，而中国更是外挂玩家的重灾区。近日大火的《APEX》英雄这款大逃杀游戏中，有数十万人被系统封禁，其中90%的IP来自中国。而在中国有着非常完善的外挂产业，制作、销售、推广乃至售后，就算是世界上最大的公司也对外挂有些难以招架。

![](../Images/1f14ea0bb422578ae939c57dca649ee7.png)

在利润方面，仅从某宝上就能看出外挂的高利润。开发外挂的称得上是无本万利，仅仅是一款外挂就能为一个淘宝店带来上万元收入。PBUG、APEX等大逃杀游戏更是外挂的重灾区，虽然官方尽全力去封锁外挂，但开挂玩家依然是源源不断的涌入游戏当中。在2018年腾讯曾经配合警方破获过数起外挂制造案件，有350人次被捕，而涉案金额达到恐怖的1.51亿元。

![](../Images/92f9b575dc8df8b9272df3b86c33b849.png)

外挂工作室不但会只做外挂，还能不断更新、不断创新，以此来吸引玩家的青睐。甚至有外挂工作室开始与官方合作，通过外挂方式来刷取营业额，有公司上市也是凭借外挂才得以成功。APEX国外制作者也曾透露过外挂的利润，一月的收入就有上千万人民币，已然超过现在绝大部分产业。在绝地求生中曾有过“速跑挂”，一名玩家用远超汽车的速度向另一名玩家“推销”自己的外挂，既魔幻又恐怖。

  

被外挂毁掉的游戏同样不在少数，守望先锋、全境封锁等高利润游戏中也不乏外挂存在。绝地求生更是被外挂彻底摧毁，从巅峰的百万人数在线到如今的不足四十万，外挂已然成为游戏界最大的病毒。
