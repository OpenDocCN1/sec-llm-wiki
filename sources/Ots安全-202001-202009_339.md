# PHP-FPM远程命令执行（CVE-2019-11043）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247485644&idx=1&sn=4f0699af942c44967d5c577a810c15d1&chksm=9bae4187acd9c891236f062bf06312f30f6f3d65d73808a552944e0fecab8b6e959ad324b74e&scene=126&sessionid=1681670203#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247485644&idx=1&sn=4f0699af942c44967d5c577a810c15d1&chksm=9bae4187acd9c891236f062bf06312f30f6f3d65d73808a552944e0fecab8b6e959ad324b74e&scene=126&sessionid=1681670203#rd)

在长亭科技举办的 Real World CTF 中，国外安全研究员 Andrew Danau 在解决一道 CTF 题目时发现，向目标服务器 URL 发送 %0a 符号时，服务返回异常，疑似存在漏洞。

  

在使用一些有错误的Nginx配置的情况下，通过恶意构造的数据包，即可让PHP-FPM执行任意代码。


**漏洞环境**

执行如下命令启动有漏洞的Nginx和PHP：

docker-compose up -d

环境启动后，访问http://your-ip:8080/index.php即可查看到一个默认页面。
