# 近期冠状病毒出现新的冠状恶意软件

*   在过去的几周中，安全研究人员发现了各种以冠状病毒名义传播的，具有新功能的新恶意软件。
    
*   其中一些恶意软件利用了当前情况的敏感性，比正常情况下造成了更大的破坏。
    

  

除了与冠状病毒相关的骗局激增外，利用恶意软件的名称和对这种疾病的恐惧来感染用户的恶意软件攻击也有所增加。在过去的几周中，安全研究人员发现了各种以冠状病毒传播的具有新功能的新恶意软件。其中一些恶意软件利用了当前情况的敏感性，比正常情况下造成了更大的破坏。

  

**新发现的恶意软件**

以下是利用该流行病迄今已发现的新恶意软件的列表。

  

*   CoronaLocker
    

这种新的screenlocker ，它通过假的WiFi程序分发所谓的“wifihacker.exe，”试图锁定用户从Windows中通过使恼人的声音，并显示一个警告消息。要求受害者通过屏幕上显示的电子邮件地址与攻击者联系以解锁屏幕。安装后，该恶意软件会创建各种注册表设置，从而阻止任务管理器和运行命令运行，隐藏桌面图标，禁用“开始”菜单等。     

  

*   PoetRAT
    

对手已经使用了这种基于Python的远程访问木马（RAT）来瞄准阿塞拜疆政府和能源部门。该恶意软件是通过以Word COVID-19为主题的网络钓鱼电子邮件到达的Microsoft Word文档进行部署的。   

  

*   ProjectSpy campaign
    

该活动旨在通过两个名为AndroidOS\_ProjectSpy.HRX和IOS\_ProjectSpy.A的间谍软件感染Android和iOS用户。这些间谍软件伪装成一个名为“冠状病毒更新”的应用程序，该应用程序在巴基斯坦，印度，阿富汗，孟加拉国，伊朗，沙特阿拉伯，奥地利，罗马尼亚，格林纳达和俄罗斯都有大量下载。  

  

*   BlueTea Action trojan
    

发现此新木马通过网络钓鱼电子邮件进行传播，该电子邮件的主题行为“ COVID-19的真相”。网络钓鱼电子邮件中包含一个RTF附件，其中带有针对CVE-2017-8570漏洞的利用。    

  

*   Coronavirus wiper malware
    

这种新的Windows恶意软件不少于NotPetya，它会通过覆盖主启动记录（MBR）来使磁盘无法使用。恶意软件的受害者显示为灰色屏幕，并且光标闪烁并带有一条简单消息，上面写着“您的计算机已被丢弃”。        

  

*   SpyMax
    

属于监视软件家族，SpyMax 被发现针对利比亚个人。它伪装成“ Corona live 1.1”，可以窃取照片，媒体，文件，设备位置，以及允许拍照和录制个人视频的权限。  

  

*   CoronaVirus ransomware
    

由MalwareHunterTeam 发现，此新勒索软件是通过假冒网站进行分发的，该网站假装从WiseCleaner推广系统优化软件实用程序。感染系统后，它会加密具有特定扩展名的文件，随后需要大约50美元的比特币来解密文件。   

  

*   BlackWater backdoor
    

这种新的后门恶意软件利用冠状病毒的爆发滥用Cloudflare Workers作为与C2服务器的接口。该恶意软件通过名为“ COVID-19”的可疑RAR文件传播，该文件提供了有关疾病的信息。
