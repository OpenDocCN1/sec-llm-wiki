# 分析：Excel 4.0宏表上的可疑“非常隐藏”公式

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247485467&idx=1&sn=abd476f59abe390cbc581028a9517ee9&chksm=9bae4150acd9c846c692955630fe8d59718fe25e82bf4c4376d86bd49d2cd9189b63fb5b504b&scene=126&sessionid=1681670208#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247485467&idx=1&sn=abd476f59abe390cbc581028a9517ee9&chksm=9bae4150acd9c846c692955630fe8d59718fe25e82bf4c4376d86bd49d2cd9189b63fb5b504b&scene=126&sessionid=1681670208#rd)

客户提交了带有设置为“非常隐藏”的可疑公式的恶意Microsoft Excel 4.0宏表，并由趋势科技研究人员进行了进一步分析。由于Microsoft网站中记录的功能允许用户隐藏工作表，因此无法通过Microsoft Excel用户界面（UI）轻松访问工作表。受感染的文件通常用作垃圾邮件的附件。

  

打开文件后，它将显示一条消息，要求用户单击“启用编辑”按钮，然后单击“启用内容”按钮。单击这些的用户不经意间启用了宏。

![](../Images/2b9c35f2023b71960b4b98a80acd38bb.png)

图1.提示启用编辑和启用内容

  

研究人员通过打开Visual Basic编辑器检查宏的存在。启动后，发现不存在宏。

  

我们使用内部工具来分析OLE2文件，进一步检查了文件结构。通过此操作，我们发现了一个名为“ G5U1D5zEis”的宏表，该宏表被设置为“非常隐藏”。文档设置意味着无法通过Excel UI以任何方式方便地访问工作表，因为它在用户工作表列表中不可见，并且除非使用其他工具，否则无法将其隐藏。

![](../Images/12b7469e81329cf086b0c69b740208e5.png)

图2.显示“非常隐藏”状态

我们修改了文件以取消隐藏工作表。这揭示了文件的内容。

![](../Images/822d82f4a5723c005e9d995a3a1e7837.png)

图3.模糊的宏工作表内容

内容通过去模糊处理显示，表明宏表具有在打开文档时将运行的公式。它还称为URL hxxps：// grpxmqnrb \[。\] pw / ehrj4g9g。

![](../Images/0cabfc62669a80e99827cffdab2f2a83.png)

图4.模糊化的宏工作表内容

URL hxxps：// grpxmqnrb \[。\] pw / ehrj4g9g将重定向到hxxps：// github \[。\] com / arntsonl / calc\_security\_poc / raw / master / dll / calc.dll。要下载的文件仅执行Windows计算器calc.exe。因此，似乎收到了诱饵有效载荷。但是，即使URL现在无法解析并重定向到任何地址，它仍然有可能使用不同的重定向和有效负载再次启动。

**防御恶意文件**

威胁参与者继续隐藏在看似无害的文件中的恶意代码，同时定期利用新文件类型。这些文件通常使用社交工程技术通过垃圾邮件进行传播，例如引用诸如冠状病毒（COVID-19）爆发等时事事件，以引起收件人的注意并促使他们下载附件。有些甚至伪装成合法的，备受瞩目的组织，以赢得接收者的信任。

  

为避免妥协，用户切勿下载附件或单击来自不受信任来源的电子邮件中的链接。对于看似由官方组织发送的电子邮件，使用者应向该小组的官方网站查询有关该电子邮件咨询的新闻稿，或通过网站上列出的联系方式与他们联系以验证他们是否发送了电子邮件。用户还应该检查电子邮件正文中的语法错误和拼写错误，这通常是电子邮件为垃圾邮件的致命礼物。利用安全解决方案还可以检测并阻止恶意软件通过电子邮件进入。
