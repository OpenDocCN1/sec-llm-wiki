*   CVE-2011-2856
    

在14.0.835.163之前的Google Chrome中使用的Google V8允许远程攻击者通过未指定的媒介绕过Same Origin Policy。

  

*   CVE-2011-3243
    

WebKit中的跨站点脚本（XSS）漏洞（在5之前的Apple iOS和5.1.1之前的Safari中使用）允许远程攻击者通过涉及非活动DOM窗口的向量注入任意Web脚本或HTML。

  

*   CVE-2013-2618
    

0.97b之前的Network Weathermap中editor.php中的跨站点脚本（XSS）漏洞允许远程攻击者通过map\_title参数注入任意Web脚本或HTML。

  

*   CVE-2013-6632
    

31.0.1650.57之前的Google Chrome浏览器中的整数溢出使远程攻击者可以通过未指定的向量执行任意代码或导致服务拒绝（内存损坏），如在PacSec 2013的Mobile Pwn2Own竞赛中所展示的。

  

*   CVE-2014-1701
    

在33.0.1750.149之前的Google Chrome中使用的Blink的bindings / scripts / code\_generator\_v8.pm中的GenerateFunction函数并未对EventTarget :: dispatchEventEvent函数实施某种跨域限制，从而允许远程攻击者进行通用XSS（ UXSS）通过涉及事件的媒介进行攻击。

  

*   CVE-2014-1705
    

在OS X和Linux上的33.0.1750.152之前和Windows上的33.0.1750.154之前的Google Chrome中使用的Google V8，允许远程攻击者造成拒绝服务（内存损坏）或可能通过未知媒介造成其他不确定的影响。

  

*   CVE-2014-1747
    

35.0.1916.114之前的Google Chrome中使用的Blink的core / loader / DocumentLoader.cpp中的DocumentLoader :: maybeCreateArchive函数中的跨站点脚本（XSS）漏洞在35.0.1916.114之前的Google Chrome中使用，允许远程攻击者通过精心制作的MHTML内容注入任意Web脚本或HTML ，也称为“通用XSS（UXSS）”。

  

*   CVE-2014-3176
    

37.0.2062.94之前的Google Chrome浏览器无法正确处理扩展程序，IPC，同步API和Google V8的交互，从而使远程攻击者可以通过未指定的向量执行任意代码，此漏洞与CVE-2014-3177不同。

  

*   CVE-2014-6332
    

Microsoft Windows Server 2003 SP2，Windows Vista SP2，Windows Server 2008 SP2和R2 SP1，Windows 7 SP1，Windows 8，Windows 8.1，Windows Server 2012 Gold和R2以及Windows RT Gold和8.1中的OLE中的OleAut32.dll通过精心设计的网站执行任意代码，如数组重新尝试触发的那样，该尝试触发对SafeArrayDimen函数（也称为“ Windows OLE自动化数组远程代码执行漏洞”）中的大小值进行不正确的处理。

  

*   CVE-2014-7927
    

在40.0.2214.91之前的Google Chrome中使用的Google V8编译器/simplified-lowering.cc中的SimplifiedLowering :: DoLoadBuffer函数未正确选择整数数据类型，这使远程攻击者可以导致拒绝服务（内存损坏） ），或者可能通过精心制作的JavaScript代码产生未指定的其他影响。

  

*   CVE-2014-7928
    

Google V8中的hydrogen.cc（在40.0.2214.91之前使用过Google Chrome）无法正确处理带有孔的阵列，这使远程攻击者可以通过触发的精心制作的JavaScript代码导致拒绝服务（内存损坏）或可能产生未指定的其他影响数组副本。

  

*   CVE-2015-0072
    

Microsoft Internet Explorer 9至11中的跨站点脚本（XSS）漏洞使远程攻击者可以绕过Same Origin策略，并通过涉及触发重定向的IFRAME元素（不触发第二个IFRAME元素）的向量注入任意Web脚本或HTML。重定向以及WindowProxy对象（也称为“通用XSS（UXSS）”）的评估。

  

*   CVE-2015-0235
    

glibc 2.2中的\_\_nss\_hostname\_digits\_dots函数以及2.18之前的其他2.x版本中基于堆的缓冲区溢出，允许上下文相关的攻击者通过与（1）gethostbyname或（2）gethostbyname2函数（也称为“ GHOST”）相关的向量执行任意代码。”。

  

*   CVE-2015-0240
    

在Samba 3.5.x和3.6.x之前，3.6.25之前的Netlogon服务器实现，4.0.0.25之前的4.0.x，4.1.17之前的4.1.x和4.2.0rc5之前的4.2.x的Netlogon服务器实现未初始化的堆栈指针，使远程攻击者可以通过使用ServerPasswordSet RPC API的精心制作的Netlogon数据包执行任意代码，如到达rpc\_server / netlogon / srv\_netlog\_nt.c中的\_netr\_ServerPasswordSet函数的数据包所示。

  

*   CVE-2015-1233
    

41.0.2272.118之前的Google Chrome无法正确处理IPC，Gamepad API和Google V8的交互，这使得远程攻击者可以通过未指定的向量执行任意代码。

  

*   CVE-2015-1242
    

在42.0.2311.90之前的Google Chrome中使用的4.2.77.8之前的Google V8中hydrogen-check-elimination.cc中的ReduceTransitionElementsKind函数允许远程攻击者通过精心设计的JavaScript代码利用这些杠杆，导致拒绝服务或可能造成未指定的其他影响消除检查优化中的“类型混乱”。

  

*   CVE-2015-1268
    

在43.0.2357.130之前的Google Chrome中使用的Blink中的bindings / scripts / v8\_types.py未正确选择返回值的DOM包装器的创建上下文，这使远程攻击者可以通过精心制作的JavaScript代码绕过Same Origin Policy。通过使用数据进行演示：URL。

  

*   CVE-2015-1635
    

Microsoft Windows 7 SP1，Windows Server 2008 R2 SP1，Windows 8，Windows 8.1和Windows Server 2012 Gold和R2中的HTTP.sys允许远程攻击者通过精心设计的HTTP请求（即“ HTTP.sys远程执行代码漏洞”）执行任意代码。”

  

*   CVE-2015-1830
    

Windows 5.11.2之前的Apache ActiveMQ 5.x中blob消息的文件服务器上载/下载功能中的目录遍历漏洞允许远程攻击者通过未指定的向量在任意目录中创建JSP文件。

  

*   CVE-2015-2177
    

西门子SIMATIC S7-300 CPU设备允许远程攻击者通过（1）TCP端口102或（2）Profibus上的精心设计的数据包导致拒绝服务（缺陷模式转换）。

  

*   CVE-2015-3306
    

ProFTPD 1.3.5中的mod\_copy模块允许远程攻击者通过site cpfr和site cpto命令读取和写入任意文件。

  

*   CVE-2015-5119
    

Windows和OS X上的Adobe Flash Player 13.x至13.0.0.296和14.x至18.0.0.194中的ActionScript 3（AS3）实现中的ByteArray类中的After-After-Use-after-free使用漏洞，在Windows和OS X以及11.x至11.2.202.468上Linux上的Linux允许远程攻击者执行覆盖了valueOf函数的精心制作的Flash内容，从而执行任意代码或导致拒绝服务（内存损坏）（如2015年7月的野蛮利用）。

  

*   CVE-2015-5254
    

5.13.0之前的Apache ActiveMQ 5.x并不限制可以在代理中序列化的类，这允许远程攻击者通过精心设计的序列化Java消息服务（JMS）ObjectMessage对象执行任意代码。

  

*   CVE-2015-5531
    

1.6.1之前的Elasticsearch中的目录遍历漏洞允许远程攻击者通过与快照API调用相关的未指定向量读取任意文件。

  

*   CVE-2015-6086
    

Microsoft Internet Explorer 9至11允许远程攻击者通过精心制作的网站（也称为“ Internet Explorer信息泄露漏洞”）从进程内存中获取敏感信息。

  

*   CVE-2015-6755
    

在46.0.2490.71之前的Google Chrome中使用的Blink的core / dom / ContainerNode.cpp中的ContainerNode :: parserInsertBefore函数在某些情况下会进行DOM树插入，其中父节点不再包含子节点，从而允许远程攻击者通过精心设计的JavaScript代码绕过“同源策略”。

  

*   CVE-2015-6764
    

在47.0.2526.73之前的Google Chrome中使用的Google V8 JSON字符串化器中json-stringifier.h中json-stringifier.h中的BasicJsonStringifier :: SerializeJSArray函数不适当地加载了数组元素，这使远程攻击者可以导致拒绝服务（限制内存访问）或可能通过精心设计的JavaScript代码产生未指定的其他影响。

  

*   CVE-2015-6769
    

在47.0.2526.73之前的Google Chrome浏览器中，WebKit / Source / bindings / core / v8 / WindowProxy.cpp中的临时加载落实实现允许远程攻击者利用窗口代理清除的延迟来绕过同源策略。

  

*   CVE-2015-6770
    

47.0.2526.73之前的Google Chrome浏览器中的DOM实现允许远程攻击者通过未指定的向量绕过Same Origin Policy，这是与CVE-2015-6768不同的漏洞。

  

*   CVE-2015-6771
    

在47.0.2526.73之前的Google Chrome中使用的Google V8中的js / array.js不正确地为数组实现了某些映射和过滤操作，这使远程攻击者可能导致拒绝服务（越界内存访问）或可能通过精心设计的JavaScript代码具有未指定的其他影响。

  

*   CVE-2015-7450
    

某些IBM分析，业务解决方案，认知，IT基础架构以及移动和社交产品中的序列化对象接口允许远程攻击者通过与Apache Commons Collections库中的InvokerTransformer类相关的精心制作的序列化Java对象执行任意命令。

红帽JBoss A-MQ 6.x; BPM Suite（BPMS）6.x；BRMS 6.x和5.x; 数据网格（JDG）6.x; 数据虚拟化（JDV）6.x和5.x; 企业应用平台6.x，5.x和4.3.x; 保险丝6.x; 保险丝维修厂（FSW）6.x; 运营网络（JBoss ON）3.x；门户网站6.x; SOA平台（SOA-P）5.x；Web服务器（JWS）3.x; 红帽OpenShift / xPAAS 3.x; 和Red Hat Subscription Asset Manager 1.3允许远程攻击者通过与Apache Commons Collections（ACC）库相关的精心设计的序列化Java对象执行任意命令。

  

*   CVE-2015-7545
    

（1）git-remote-ext和（2）Git在2.3.10之前的其他未指定的其他远程帮助程序，2.4.10之前的2.4.x，2.5.4之前的2.5.x和2.6.1之前的2.6.x没有适当地限制允许的协议，这可能允许远程攻击者通过（a）.gitmodules文件或（b）子模块中未知的其他源中的URL执行任意代码。

JSON，OOB。

*   CVE-2016-0450

*   CVE-2016-0451
    

Oracle GoldenGate 11.2和12.1.2中Oracle GoldenGate组件中的未指定漏洞使远程攻击者可以通过未知媒介影响机密性，完整性和可用性，这是与CVE-2016-0452不同的漏洞。

*   CVE-2016-0792
    

在1.650之前的Jenkins和1.642.2之前的LTS中，多个未指定的API端点允许远程身份验证的用户通过XML文件中与XStream和groovy.util.Expando相关的序列化数据来执行任意代码。

  

*   CVE-2016-0856
