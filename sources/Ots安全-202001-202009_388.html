CVE-2019-3016

Ubuntu安全公告4301-1-发现Linux内核中的KVM实现，在来宾中启用了准虚拟TLB刷新后，虚拟机管理程序在某些情况下可能会错过延迟的TLB刷新或以其他方式处理不当。来宾VM中的攻击者可以使用此方法公开敏感信息。Paulo Bonzini发现，在某些情况下，Linux内核中的KVM虚拟机管理程序实现可能会使嵌套的来宾不正确地访问父来宾的资源。攻击者可以使用此方法公开敏感信息。还解决了其他各种问题。

CVE-2019-12526

Gentoo Linux安全通报202003-34-在Squid中发现了多个漏洞，其中最严重的漏洞可能导致任意代码执行。小于4.10的版本会受到影响。

CVE-2020-0796

Microsoft Windows SMB version 3.1.1 版存在代码执行漏洞。

CVE-2019-0205

Red Hat Security Advisory 2020-0811-01-此版本的Red Hat JBoss企业应用平台7.2.7替代了Red Hat JBoss企业应用平台7.2.6，并包含一些错误修复和增强功能。解决的问题包括越界阅读。
