# CVE-2019-15126：Kr00k漏洞影响大量设备

有一个新的重大漏洞影响广泛的产品。该漏洞被称为Kr00k（CVE-2019-15126），可以利用此漏洞来拦截和解密依赖WPA2连接的WiFi网络流量。

  

ESET研究人员在旧金山举行的RSA 2020安全会议上披露了CVE-2019-15126漏洞。

  

**CVE-2019-15126：****说明了Kr00k漏洞**

研究人员表示，Kr00k或CVE-2019-15126会影响所有使用Broadcom和Cypress Wi-Fi芯片或两个最受欢迎和使用最广泛的此类芯片组的支持Wi-Fi的设备。这些芯片几乎用于任何设备，例如智能手机，笔记本电脑，IoT设备等。

  

根据ESET的说法，Kr00k漏洞会影响来自Amazon（Echo Kindle），Apple（iPhone，iPad，MacBook），Google（Nexus），Samsung（Galaxy），Raspberry（Pi 3）和Xiaomi（Redmi）的设备，以及访问点从华硕和华为。似乎有超过十亿个设备容易出现此漏洞，而这个数字是“ 保守估计 ”。

  

**是什么使Kr00k与类似漏洞不同？**

从技术上讲，该缺陷与每天披露的其他缺陷没有太大区别。但是，使这种加密方式变得更加复杂，独特和危险的原因在于，它会影响加密，从而保护通过WiFi连接发送的数据包的安全。

  

在典型情况下，这些数据包通过与用户的WiFi密码关联的唯一密钥进行加密。但是，看来在Broadcom和Cypress Wi-Fi芯片组中，此密钥在称为取消关联的特定过程中被重置为全零值。

  

解除关联是Wi-Fi连接中的“自然过程”，因为它源于信号低可能导致的断开。无线设备一天可以多次处于断开状态，并且它们可以自动重新连接到以前的网络。

  

Kr00k漏洞的问题在于，威胁行动者可以迫使设备进入长时间的未关联状态，以接收特定的WiFi数据包，然后部署该漏洞以通过归零密钥解密流量。

  

值得注意的是，研究人员在“ KRACKing Amazon Echo ”时发现了Kr00k 。KRACK漏洞是在2017年发现的，当时研究人员设计了一种名为Krack Attack的危险利用程序，使恶意用户有可能窃听计算机与路由器和接入点等其他网络设备之间的Wi-Fi流量。

  

漏洞被披露后甚至两年，许多支持Wi-Fi的设备仍然很脆弱，包括多个Amazon设备，例如被广泛采用的Amazon Echo和Amazon Kindle。这些设备的庞大用户群构成了巨大的安全威胁。

  

ESET随后发现：“ 尽管第二代Amazon Echo不受原始KRACK攻击的影响，但它很容易受到KRACK变体之一的攻击，特别是：当STA使用Temporal PTK构造，随机Anonce时，PTK以4次握手方式重新安装。”

  

研究人员还向亚马逊报告了这一缺陷，并发现不当行为是第二代Echo设备中使用的赛普拉斯WLAN芯片。赛普拉斯的WLAN芯片容易受到该漏洞的攻击，该漏洞后来被研究人员称为Kr00k。

  

他们还认为，KRACK测试脚本通过触发解除关联来揭示它。专家说：“ 应该注意，使用全零TK进行加密可能有多种原因-Kr00k只是其中一种，尽管非常重要，原因是易受攻击的Broadcom和Cypress芯片的广泛分布。”他们的报告。

  

**思科目前正在调查Kr00k在其产品中的影响**

关于此漏洞的最新消息之一是，思科当前正在检查其产品中该漏洞的影响。原因是该公司在其产品组合中使用了Broadcom芯片。看来该公司的许多设备都受到了影响–大量的网格和以太网供电（PoE）路由器，防火墙产品，IP电话和接入点系统。

  

思科还正在检查运行在Android固件上的Cisco DX70，DX80和DX650 IP电话以及Cisco IP Phone 8861的状态。补丁尚未开发。
