# 化妆品公司雅诗兰黛的数据泄露暴露了4.4亿人的记录

作为用户，通常认为信息安全事件仅影响技术公司。这是一个错误的概念，因为各种各样的公司都不断报告数据安全事件。这恰恰是化妆品公司EstéeLauder所发生的情况，该公司遭受了一次数据泄露，泄露了近4.4亿条记录。

  

研究发现的负责人耶利米·福勒（Jeremiah Fowler）说，这起事件是由于数据库未受保护而造成的。该公开的数据库包含客户和员工的未加密电子邮件地址记录，市场营销报告，内部文档，以及有关IP地址和数据存储路径的信息。Fowler补充说，他已通知EstéeLauder负责信息安全的区域，该区域立即禁止访问数据库。

  

接到报告后不久，雅诗兰黛（EstéeLauder）证实了这一事件，并提到该数据库暴露了在在线平台上注册的有限数量的电子邮件地址（非客户成员）。该化妆品公司的信息安全团队还声称，到目前为止，尚未记录对数据库的不当访问。

  

但是，该公司的问题尚未解决，因为它仍需要进行调查以确定没有威胁者可以访问受到破坏的信息。此外，该版本还向客户提出了更多问题，因为有时数据泄露可被用作公司内部网络的访问点，从而损害了更大的内部和客户详细信息。

  

“这样的事件使用户暴露于各种恶意活动中。黑客可以发送网络钓鱼电子邮件，使用其支付卡数据在其他站点上进行购买，甚至进行网络钓鱼攻击。”信息安全专家罗伯特·卡普斯（Robert Capps）说。 

![](../Images/fd30c23beebb0ffe7e2e9739be0380e2.png)

随着公司调查的进行，国际网络安全研究所（IICS）指出，由于暴露了欧盟公民的数据，因此可以根据欧盟通用数据保护条例（GDPR）对事件进行调查。应当记住，不遵守该法律的罚款最高可达公司年利润的4％，因此，该事件可能会对这家总部位于纽约的公司造成灾难性的财务后果。
