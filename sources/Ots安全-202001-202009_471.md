# TELERIK UI FOR ASP.NET中的任意代码执行漏洞

Telerik UI for ASP.NET的开发人员（动态网站Web开发的开源应用程序框架）的开发人员收到了一份漏洞报告，该漏洞一旦被利用，将允许攻击者执行任意代码。该漏洞是由一家信息安全公司报告的，该公司的名称尚未披露。  

  

如前一段所述，该漏洞允许任意代码在高特权进程的上下文中运行。根据与应用程序相关的特权，威胁行动者可能会部署恶意活动，例如安装程序，访问和修改数据，甚至创建完全特权的用户帐户。应该注意的是，如果为应用程序配置了减少的特权，则此漏洞的实际影响可能会大大降低。

  

在该报告中，匿名信息安全公司提到该漏洞是由于使用RadAsyncUpload的.NET JavaScriptSerializer的反序列化问题而存在的，该问题可被利用来导致服务器上任意代码的执行，所有这些都在w3wp的情况下进行。.exe进程。

  

该漏洞会影响适用于v2020.1.114之前的ASP.NET AJAX版本的所有Progress Telerik UI系统。风险主要存在于大型公司和政府组织的环境中。在中小型公司以及家庭环境中，剥削的可能性降低了。

  

开发人员在收到信息安全公司的报告后即确认并解决了该漏洞。根据国际网络安全研究所（IICS）的建议，防止利用风险的主要建议包括：

*   分析易受攻击的系统并立即安装Telerik发布的安全补丁
    
*   验证使用Telerik用户界面的其他Web应用程序也已更新为最新版本
    
*   以非特权用户身份运行所有软件（无管理权限），以减小潜在成功攻击的范围
    
*   在使用中的所有系统和服务上启用最低特权原则
    

  

还提醒Telerik部署管理员，没有针对此漏洞的解决方法，因此建议安装正式补丁。
