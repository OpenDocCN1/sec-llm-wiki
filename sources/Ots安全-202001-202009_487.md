# Winnti Hackers Group通过供应链攻击启动新的恶意软件，以在Windows中注入后门程序

研究人员从Winnti威胁小组发现了一个新的恶意软件活动，该活动利用供应链攻击和一组新的工件将新的后门注入Windows计算机。

  

自2013年以来，对Winnti 集团的活动进行了监控，从那时起，它就一直针对居住在亚洲的各个私营部门，包括航空，游戏，制药，软件开发，电信和技术。

  

ESET的研究人员发现了一个VMProtected打包程序，该打包程序用于使用密码和密钥生成技术来传送称为PortReuse的后门程序，并且还传送了另一个称为Shadowpad的恶意软件。

  

在这项研究中发现了各种工件，并发现它使用相同的技术，事件关系和各种针对性攻击的代码。

![](../Images/e304273c73396f962cfa28606c1596e1.png)

Winnti小组被认为是近来具有不同威胁参与者的别名，包括Winnti伞，Axiom，72组，APT41，Blackfly和Suckfly。

  

此外，它还负责最近发现的一项名为ShadowHammer的操作，该操作针对的是华硕计算机软件更新工具以注入后门。 

  

这项新的研究揭露了Winnti Group的工具库和方法，后者可以在目标组织网络中部署的Windows计算机上提供PortReuse后门。

  

**PortReuse后门活动**

研究人员更深入地研究了上一份报告中未发现的自定义打包程序，该程序发现了更多可执行文件，并被认为可用于使用受损软件的供应链攻击。

  

但是实际上，他们发现了一个新的侦听模式模块化PortReuse后门，该后门将注入到已经在TCP端口上进行侦听的正在运行的进程中。

  

攻击者在首次启动时使用了以下格式，并且仅将一个文件写入磁盘以启动PortReuse：

1.  嵌入到.NET应用程序中，启动初始Winnti Packer Shellcode 
    
2.   在反序列化并调用启动外壳代码的.NET对象的VB脚本中 
    
3.  在直接在入口点具有shellcode的可执行文件中 
    

  

![](../Images/924b5f1de8640ff31312a68e75b39ced.png)

**模块化体系结构积分：****ESET**

后来，自定义打包程序解密并启动了第一个组件InnerLoader（InnerLoader.dll），研究人员也能够提取打包程序元数据。“来自打包程序的元数据，包括打包时的绝对文件路径”。

  

根据ESET 报告，“对于.NET注入器，InnerLoader的目标进程是GameServer\_NewPoker.exe，对于VBS注入器，它会寻找侦听端口53（DNS）的进程。同样，这些有效负载使用相同的打包程序打包，根据打包程序配置分别称为NetAgent和SK3。”

  

PortReuse后门针对不同的常用端口，包括53（TCP上的DNS），80、443、3389（RDP）和5985（Windows远程管理）。

  

为了对目标受害者进行网络挂接，后门最初需要注入正在运行的进程中。

  

ESET研究人员能够解密使用此自定义VMProtected打包程序打包的多个有效负载，他们认为有效负载是PortReuse后门程序或ShadowPad恶意软件。
