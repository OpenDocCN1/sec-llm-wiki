# 勒索软件给澳大利亚航运业造成巨大损失

为应对勒索软件攻击，澳大利亚运输和物流巨头Toll Group被迫关闭部分在线服务，客户对该公司处理此事件的方式不满意。

  

Toll由Japan Post拥有，拥有40,000多名员工，并声称拥有遍布50多个国家/地区的1,200个地点的全球物流网络。

  

该公司表示，它于1月31日星期五在其系统上发现了一个勒索软件，并急于禁用某些系统以遏制此事件。Toll网站上发布了一条通知，告知客户有关该事件的通知，承诺会定期进行更新，但许多人对第一次更新仅在几天后就感到不满意。

![](../Images/9da7053bf6eee05bdae06a3c08cf47b8.png)

一些客户在社交媒体上抱怨他们无法再跟踪包裹，并声称该公司的员工也无法访问跟踪数据库。

  

澳大利亚商业内幕人士报道说，该事件影响了澳大利亚，印度和菲律宾的业务。

  

目前尚不清楚攻击中使用了哪种勒索软件，Toll将其描述为“目标”，但它似乎具有在受害者网络内传播的能力。

  

一位匿名用户在Twitter上声称该勒索软件已感染了全球1000多台Toll服务器。SecurityWeek已联系Toll进行确认，如果公司做出回应，它将更新本文。

![](../Images/64a9df1dcf51fbd478af9dae39e9b281.png)

Toll表示，正在努力恢复受影响的系统，与此同时，它已采取手动流程继续提供服务。当前，只有几个面向客户的应用程序处于离线状态，因此只能通过电话进行订购。

  

该公司表示：“对于我们的包裹客户，我们的所有加工中心都将继续运营，包括取货，加工和发货，尽管有时速度会降低。” “大多数其他收费业务仍在根据我们的业务连续性计划在手动系统上运行。”

  

该公司已通知有关部门，但声称尚未找到任何证据表明个人数据已被泄露。
