大赏金侦察

BigBountyRecon 工具利用 58 种不同的技术，使用各种 Google dorks 和开源工具来加快对目标组织的初步侦察过程。侦察是任何渗透测试或错误搜寻过程中最重要的步骤。它为攻击者提供了一些关于目标组织的初步知识。此外，深入了解实施了哪些控制措施以及对目标组织的安全成熟度级别进行一些粗略估计将很有用。


除了您通常的错误搜寻方法之外，还可以使用此工具。这个想法是快速检查和收集有关您的目标组织的信息，而无需花费时间和记住这些语法。此外，它还可以帮助您定义一种在目标上快速获胜的方法。

技巧

  1. 目录列表：在目标组织中使用 Google Dork 查找开放目录有助于了解网络服务器上的目录结构。它可能会泄露敏感信息，也可能导致信息泄露。

  2. 配置文件：配置文件通常包含敏感信息，例如硬编码密码、敏感驱动器位置或 API 令牌，可帮助您获得对内部资源的特权访问。

  3. 数据库文件：数据库文件是数据文件，用于将数据库的内容以结构化格式存储到单独的表和字段中的文件中。根据 Web 应用程序的性质，这些文件可以提供对敏感信息的访问。

  4. WordPress：WordPress 是一个用 PHP 编写的开源 CMS。WordPress 拥有数以千计的插件来构建、定制和增强网站。这些插件中有许多漏洞。寻找 WordPress 相关

  5. 日志文件：日志文件有时会提供用户在特定应用程序中活动的详细信息。这些文件很适合查看会话 cookie 或其他类型的令牌。

  6. 备份和旧文件：备份文件是关键系统的原始副本。这些提供对 PII 或敏感记录的访问。

  7. 登录页面：识别目标组织的登录页面以执行暴力尝试或尝试默认凭据以进一步访问组织资源非常重要。

  8. SQL 错误：SQL 错误会泄露有关后端系统的敏感信息。这可以帮助人们对数据库类型执行枚举，并查看应用程序是否容易受到与输入验证相关的攻击，例如 SQL 注入。

  9. Apache 配置文件：Apache HTTP Server 是通过在纯文本配置文件中放置指令来配置的。主要的配置文件通常称为 httpd.conf。此外，可以使用 Include 指令添加其他配置文件，并且可以使用通配符来包含许多配置文件。任何指令都可以放在任何这些配置文件中。根据这些配置文件中的条目，它可能会显示数据库连接字符串、用户名和密码、内部工作、使用和引用的库以及应用程序的业务逻辑。

  10. Robots.txt 文件：Robots.txt 文件指示网络机器人如何抓取其网站上的页面。根据文件的内容，攻击者可能会发现隐藏的目录和文件。

  11. DomainEye：DomainEye 是一个域/主机调查工具，拥有最大的域数据库。他们提供诸如反向 Whois、反向 IP 查找以及反向 NS 和 MX 等服务。

  12. 公开公开的文件：此类文件可用于提取元数据信息。

  13. phpinfo()：单独暴露 phpinfo() 不一定有风险，但与其他漏洞结合使用可能会导致您的站点遭到入侵。此外，当使用新发现的漏洞攻击应用程序时，模块版本可以使攻击者的生活更轻松。

  14. 寻找后门：这可以帮助人们识别网站篡改或服务器劫持相关问题。通过利用受信任的 Web 应用程序上的开放重定向漏洞，攻击者可以将受害者重定向到网络钓鱼页面。

  15. 安装/设置文件：此类文件允许攻击者对目标组织进行枚举。使用这些文件收集的信息可以帮助发现版本详细信息，然后可以使用这些详细信息执行有针对性的漏洞利用。

  16. 开放重定向：通过这些，我们可以查看各种已知的容易受到开放重定向相关问题影响的参数。

  17. Apache Struts RCE：成功利用 RCE 漏洞可能允许攻击者运行任意程序。在这里，我们正在寻找扩展名为“.action”或“.do”的文件。

  18. 第 3 方曝光：在这里，我们正在寻找在 Codebeautify、Codeshare 和 Codepen 等第三方网站上的信息曝光。

  19. 检查安全标头：快速确定目标站点是否在服务器响应中使用安全相关标头。

  20. GitLab：在 GitLab 上快速查找敏感信息。

  21. 查找 Pastebin 条目：显示与 Pastebin 站点上的目标组织相关的结果。这可能是密码或与目标组织相关的任何其他敏感信息。

  22. LINKEDIN 上的员工：识别 LinkedIn 上的员工姓名可以帮助您在涉及密码喷射攻击时建立用户名列表。

  23. .HTACCESS / 敏感文件：查找敏感文件暴露。这可能表示服务器配置错误。

  24. 查找子域：子域可帮助您扩展目标组织的攻击面。有许多工具可用于自动执行子域枚举过程。

  25. 查找子子域：使用 Google Dork 识别目标组织的子子域，

  26. 查找 WordPress 相关曝光：WordPress 相关曝光可帮助您访问敏感文件和文件夹。

  27. BitBucket 和 Atlassian：源代码泄漏、硬编码凭据和对云基础设施的访问。

  28. PassiveTotal：PassiveTotal 是执行威胁调查的绝佳工具。使用 BigBountyRecon，我们将使用 PassiveTotal 来识别目标信息上的子域。

  29. Stackoverflow：源代码公开或 Stackoverflow 上提到的任何特定于技术的问题。

  30. 使用 Wayback Machine 查找与 WordPress 相关的曝光：使用 WaybackMachine 查找归档的 WordPress 文件。

  31. GitHub：在 GitHub 上快速查找敏感信息。

  32. OpenBugBounty：在 OpenBugBounty 网站上查找公开暴露的安全问题。

  33. Reddit：关于 Reddit 平台上特定组织的信息。

  34. Crossdomain.xml：在目标组织中查找配置错误的 crossdomain.xml 文件。

  35. ThreatCrowd：威胁搜索引擎，但是，我们将使用它来识别其他子域。

  36. .git 文件夹：源代码曝光。如果可以访问，可以下载整个存储库内容。

  37. YouTube：在 Youtube 上查找任何最近的新闻。

  38. Digitalocean Spaces：Spaces 是一种与 S3 兼容的对象存储服务，可让您存储和提供大量数据。我们将寻找任何数据暴露。

  39. .SWF 文件 (Google)：Flash 已死。我们将使用 Google Dorks 查找包含漏洞的旧版 flash .swf。

  40. .SWF 文件 (Yandex)：Flash 已死。我们将使用 Yandex 查找包含漏洞的旧版 flash .swf。

  41. .SWF 文件（Wayback Machine）：Flash 已死。我们将使用 WaybackMachine 查找包含漏洞的旧版 flash .swf。

  42. Wayback Machine：查找存档文件以访问旧文件。

  43. 反向 IP 查找：反向 IP 查找可让您发现托管在任何给定 IP 地址上的所有域名。这将帮助您探索目标组织的攻击面。

  44. Traefik：寻找一个开源的边缘路由器，用于暴露内部服务的未经身份验证的接口。

  45. 云存储和存储桶：用于各种云存储的 Google CSE – aws、digitalocean、backblaze、wasabi、rackspace、dropbox、ibm、azure、dreamhost、linode、gcp、box、mailru

  46. s3 存储桶：打开 s3 存储桶。

  47. PublicWWW：源代码搜索引擎为超过 2 亿个网站的内容编制索引，并提供查询界面，让调用者可以在网页“HTML”、“JavaScript”和“CSS”样式表代码中查找任何字母数字片段、签名或关键字.

  48. Censys（IPv4、域和证书）：用于查找互联网设备的搜索引擎。我们将使用它来使用 Censys 上的各种端点查找其他子域。

  49. Shodan：用于联网设备的搜索引擎

  50. SharePoint RCE：查找 CVE-2020-0646 SharePoint RCE 相关端点。

  51. API 端点：查找 WSDL 文件。

  52. 要点搜索：快速查找有关要点粘贴的敏感信息。

  53. CT 日志：证书透明度 (CT) 是一种互联网安全标准和开源框架，用于监控和审核数字证书。我们将用于寻找目标组织的其他子域。

  54. 密码泄漏：查找在各种泄漏中暴露的内部员工的明文密码。

  55. What CMS：确定目标组织用于目标枚举和漏洞利用研究的 CMS 版本和类型。
