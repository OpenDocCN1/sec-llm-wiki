CVE-2021-34527 或 PrintNightmare 是 Windows Print Spooler 中的一个漏洞，允许低权限用户在本地机器或远程服务器上升级为管理员。这尤其糟糕，因为域控制器具有暴露的打印后台处理程序的情况并不少见，因此，此漏洞可以将攻击者从低权限用户带到域管理员。那里有一些概念漏洞证明，我想给他们一个旧的 HackTheBox 机器。我还将研究禁用 Print Spooler 以及它如何破解漏洞，并讨论 7 月 6 日的补丁。

  

**背景**

**历史**

这个错误的历史有点有趣。微软于2021 年 6 月 8 日发布了针对Windows Print Spooler 远程代码执行漏洞的补丁，称为 CVE-2021-1675。看到这个补丁，中国的研究人员正在为打印假脱机程序中一个非常相似的错误进行概念验证，并在看到这个补丁后，在 GitHub 上发布了他们的漏洞利用。只是它们不是同一个错误。研究人员后来取消了他们的漏洞利用，但是一旦有什么东西进入了互联网，损害就已经造成了。

  

微软后来在 7 月 2 日更新了 CVE-2021-1675 的补丁（并将该类从特权升级更新为远程代码执行）。

  

7 月 6 日，微软发布了一个带外更新（不是在补丁星期二），但根据 Twitter 上的讨论尚不清楚此补丁是否完全修复了该问题。在撰写本文时，他们确定漏洞利用是否有效的最佳流程图来自以下推文：

https://twitter.com/wdormann/status/1412906574998392840

![](../Images/cc6d44315bc696481d4cea1839445ff3.png)

这个故事每天都在变化……7 月 6 日发布了一个补丁，我将在帖子末尾的缓解部分讨论这个问题。因为我将在 HackTheBox 实验室中使用未打补丁的机器，所以我展示的各种 POC 都可以正常工作。需要注意的是，Cube0x0 Impact 漏洞利用针对与 Cube0x0 SharpNightmare 版本不同的漏洞利用路径，这意味着修复的补丁可能会或可能不会修复另一个，因此值得一一展示。

  

**漏洞**

该漏洞本身与低权限认证用户如何能够添加打印机，并专门为该打印机提供驱动程序有关。该过程检查用户是否已通过身份验证，然后授予他们系统级别的访问权限以安装打印机驱动程序。

  

这意味着使用 Windows 机器上的低 priv shell 或远程有效凭据，攻击者可以获得主机上的 SYSTEM 权限。

**减轻**

**禁用后台处理程序**

直到几天前，唯一的缓解措施是禁用打印后台处理程序服务。

  

在管理 shell（如 0xdf）中，我可以使用以下命令执行此操作：

*   
*   

```
*Evil-WinRM* PS C:\Users\0xdf\Documents> stop-service -name spooler -force*Evil-WinRM* PS C:\Users\0xdf\Documents> set-service -name spooler -startuptype disabled
```

第一个当前禁用该服务，第二个将使其在重新启动时不启动。第二个在 HTB 机器上并不重要，因为它将恢复到启用并运行服务的快照，但我在这里运行它只是为了展示最佳实践。

  

完成此操作后，rpcdump.py @10.10.10.149 | grep MS-RPRN不再显示服务，并且漏洞利用不再有效。

**7 月 6 日补丁**

据我所知，7 月 6 日的 CVE-2021-34527 补丁修复了部分漏洞。现在需要管理员访问权限才能安装任何未签名的打印机驱动程序。虽然有很多签名恶意软件的案例，但这仍然是向前迈出的坚实一步。此外，还有一个新的注册表项 ，RestrictDriverInstallationToAdministrators它将阻止非管理员用户安装所有驱动程序，这似乎是一件好事，因为它完全阻止了本地权限提升。

  

仍然有一个解决方法，涉及“Point&Print”服务。从它更新的安全公告：

  

2021 年 7 月 7 日更新：Windows Server 2012、Windows Server 2016 和 Windows 10 版本 1607 的安全更新已发布。请参阅安全更新表，了解适用于您系统的更新。我们建议您立即安装这些更新。如果您无法安装这些更新，请参阅此 CVE 中的常见问题解答和解决方法部分，以获取有关如何帮助保护您的系统免受此漏洞影响的信息。

  

为了保护您的系统，您必须确认以下注册表设置设置为 0（零）或未定义（注意：这些注册表项默认不存在，因此已处于安全设置中。）：

*   HKEY\_LOCAL\_MACHINE\\SOFTWARE\\Policies\\Microsoft\\Windows NT\\Printers\\PointAndPrint
    
*   NoWarningNoElevationOnInstall = 0 (DWORD) 或未定义（默认设置）
    
*   NoWarningNoElevationOnUpdate = 0 (DWORD) 或未定义（默认设置）
    
*   原文链接：https://0xdf.gitlab.io/2021/07/08/playing-with-printnightmare.html
