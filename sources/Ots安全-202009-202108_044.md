用 Python 编写的模块化暴力破解工具，用于非常快速的密码喷射 SSH，以及不久的将来其他网络服务。

  

即将推出：FTP、SMB、HTTP(s) POST、HTTP(s) GET、HTTP BASIC AUTH 感谢@0dayctf、Rondons、Enigma 和 001 的测试和贡献
