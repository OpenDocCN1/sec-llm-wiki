然后终于拿到了RCE！！！^_^深圳一家安全公司的研究人员意外发布了一个危险的未修补漏洞的概念验证，该漏洞可用于接管 Active Directory 域控制器。


有问题的漏洞是CVE-2021-1675，它最初被微软描述为影响几乎所有受支持的 Windows 版本的特权提升问题。该漏洞的存在是由于应用程序没有在Windows Print Spooler中正确施加安全限制，导致绕过安全限制和提权。


CVE-2021-1675 - https://www.cybersecurity-help.cz/vdb/SB2021060813


微软在 6 月 8 日修复了 CVE-2021-1675，作为其 6 月补丁星期二的一部分，然而，在 6 月 21 日，科技巨头突然且没有解释地将分类更改为更严重的远程代码执行漏洞。


事情变得有点混乱。显然，中国网络安全公司深信服科技的研究人员正准备在 2021 年 8 月的 Black Hat 网络安全会议上发表有关 Windows Print Spooler 漏洞的深入技术论文，考虑到该漏洞现已修复，他们决定发布他们的概念验证演示之前的代码。


然而，其他研究人员尝试了这个漏洞，发现它仍然有效。看来深信服研究人员发现的漏洞实际上与微软修复的漏洞并不相同。


研究人员在意识到他们的错误后不久就从 GitHub 上删除了该出版物，但此时漏洞利用代码已被复制并发布到其他地方。


几位独立安全研究人员在 Twitter 上发布了 屏幕截图，显示该漏洞的漏洞利用程序名为“PrintNightmare”，可在完全修补的 Windows 系统上运行。看来微软的 CVE-2021-1675 补丁只修补了权限提升攻击向量，而不是 RCE 攻击向量，因此建议系统管理员禁用 Print Spooler 服务，尤其是在作为域控制器运行的 Windows 服务器上。
