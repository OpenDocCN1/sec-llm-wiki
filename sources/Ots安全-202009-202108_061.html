我又回来了，写了一篇有趣的文章！这是我最古老的文章之一。

这完全是关于我如何能够升级 XSS 漏洞以读取内部文件。


由于程序的机密性，我不会共享网站详细信息。


所以就像这是一个普通的 Web 应用程序，它的功能是生成动态页面。


大多数情况下，如果我们发现反射的 xss 漏洞，我们都旨在使其存储 xss 以产生严重影响。


这是一个 Web 应用程序，可让用户生成动态页面并创建和维护网站。在分析了该网站后，我试图破解它。


由于这是一个 Web 应用程序生成器页面，它有许多存储在服务器上的输入字段。在分析应用程序后，我观察到可能有可能读取内部文件。

我尝试在文本字段之一上使用 XSS 有效负载，发现脚本标签被阻止。

所以我试图绕过 xss 过滤器，在这种情况下很容易附加空字节字符（%00）。我发现它是基于 DOM 的 XSS 漏洞。

有效载荷：

 <script%00> x=new XMLHttpRequest; x.onload=function(){document.write(this.responseText)}; x.open("GET","file:///etc/passwd");x.send(); </script%00>

最后这个有效载荷起作用了，我也能够读取弹出窗口和网页上的内部文件。


网页坏了，我能够读取etc/passwd文件的内容，该文件有影响并且发现严重性很高。

由于报告了这个高严重性漏洞，我获得了赏金
