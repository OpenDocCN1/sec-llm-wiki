**拒绝服务 (DoS) 攻击的类型**

我们主要关注应用层拒绝服务 (DoS) 攻击，您可以在漏洞赏金计划中找到这种攻击，但我们还将讨论最常见的拒绝服务类型：

1.  基于卷的 DoS/DDoS 攻击：ICMP Floods、Ping-of-Death (PoD) 等
    
2.  基于协议的 DoS/DDoS 攻击：SYN Floods、Fragmented Packets Floods、Smurf DoS/DDoS 攻击等
    
3.  基于应用程序的 Dos/DDoS 攻击：Web 应用程序 DoS/DDoS、Slowloris 攻击、GET/POST Floods。
    

  

**如何测试应用程序中的拒绝服务**

有一些常见的方法可以测试和发现漏洞赏金计划甚至渗透测试中的拒绝服务漏洞：

1.  测试允许输入大尺寸的字段和表单，最终导致拒绝服务。这可以在 URL 参数（反映的拒绝服务）中找到，也可以在应用程序的输入字段中找到，稍后将在其中存储输入。
    
2.  用于在后端检索信息的测试 API 端点。尝试将通配符解析到搜索中，例如“\*”，以便应用程序在后端启动最后一次搜索，从而导致拒绝服务。
    
3.  测试不限速的应用程序，通过它可以在短时间内发送多个GET/POST请求，导致应用程序对用户无响应。
