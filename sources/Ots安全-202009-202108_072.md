# 修补 Tor 浏览器错误以防止跟踪您的在线活动

开源 Tor 浏览器已更新至 10.0.18 版，修复了多个问题，包括一个破坏隐私的错误，该错误可用于根据计算机上安装的应用程序对不同浏览器的用户进行唯一指纹识别。

  

除了将Tor更新到 0.4.5.9 之外，浏览器的 Android 版本还升级到 Firefox 到 89.1.1 版，同时整合了 Mozilla 针对Firefox 89 中解决的几个安全漏洞推出的补丁。

  

纠正的问题中最主要的是上个月曝光的一种新的指纹识别攻击。该漏洞被称为方案泛滥，即使用户切换浏览器、使用隐身模式或 VPN，恶意网站也能利用有关系统上已安装应用程序的信息为用户分配永久唯一标识符。

  

换句话说，该漏洞利用应用程序中的自定义 URL 方案作为攻击媒介，允许不法分子在不同浏览器（包括 Chrome、Firefox、Microsoft Edge、Safari 甚至 Tor）之间跟踪设备用户，从而有效规避跨浏览器Windows、Linux 和 macOS 上的匿名保护。

![](../Images/1431d3dc0f62e530febe197464f62d86.png "pexels-pixabay-267045.jpg")

FingerprintJS 研究员 Konstantin Darutkin 说：“利用方案泛滥漏洞的网站可以创建一个稳定且唯一的标识符，将这些浏览身份链接在一起。”

  

目前，攻击检查了 24 个已安装的应用程序列表，其中包括 Adobe、Battle.net、Discord、Epic Games、ExpressVPN、Facebook Messenger、Figma、Hotspot Shield、iTunes、Microsoft Word、NordVPN、Notion、Postman、Sketch、Skype、 Slack、Spotify、Steam、TeamViewer、Telegram、Visual Studio Code、WhatsApp、Xcode 和 Zoom。

  

该问题对隐私具有严重影响，因为攻击者可能会利用它来通过在 Tor 用户切换到非匿名浏览器（例如 Google Chrome）时关联他们的浏览活动来揭露他们。为了对抗攻击，Tor 现在将“network.protocol-handler.external”设置为 false 以阻止浏览器探测已安装的应用程序。

  

在其他三个浏览器中，虽然 Google Chrome 具有防止方案泛滥的内置保护措施——它阻止启动任何应用程序，除非它是由用户手势触发的，比如鼠标点击——但浏览器的PDF 查看器被发现绕过了这种缓解措施。

  

Darutkin 说：“在修复此漏洞之前，获得与您的主要设备无关的私人浏览会话的唯一方法是完全使用另一台设备。” 建议 Tor 浏览器用户迅速采取行动应用更新，以确保他们受到保护。

  

在加密消息服务 Wire解决了其 iOS 和 Web 应用程序中的两个可能导致拒绝服务 ( CVE-2021-32666 ) 并允许攻击者控制用户帐户的关键漏洞后，开发工作才到来。( CVE-2021-32683 )。
