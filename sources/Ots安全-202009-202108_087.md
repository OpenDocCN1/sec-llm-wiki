Traitor 打包了一堆方法来利用本地错误配置和漏洞（包括大多数GTFOBins）以弹出 root shell。

![](../Images/e935f6776500d62cad0508b35c042c3f.png)

它将利用 GTFOBins 中列出的大多数 sudo 权限来弹出 root shell，并利用可写docker.sock. 随着时间的推移，还会添加更多到 root 的路由。

  

**用法**

不带参数运行以查找可能允许特权升级的潜在漏洞/错误配置。-p如果已知当前用户密码，则添加该标志。如果需要分析 sudo 权限等，将要求输入密码。
