欢迎参加这个为期 3 小时的关于 XML 外部实体 (XXE) 开发的研讨会！

在本次研讨会中，将介绍最新的 XML 外部实体 (XXE) 和 XML 相关攻击向量。XXE 是一个漏洞，它会影响任何评估外部实体的 XML 解析器。随着OWASP Top10 2017 (A4) 的推出，它的知名度越来越高。您或许能够检测到经典模式，但您能否将漏洞转化为目录文件列表、二进制文件渗漏、文件写入或远程代码执行？

本次研讨会的重点将展示适用于 PHP 和 Java 应用程序的各种技术和开发技巧。您可以使用四份申请来测试您的技能。对于每个练习，将提供示例有效负载，以便与会者节省一些时间。

议程：

*   基本 XXE 模式
    
*   越界 DTD
    
*   过滤器编码 (PHP)
    
*   本地DTD
    
*   Jar 协议和 XSLT RCE (Java)
