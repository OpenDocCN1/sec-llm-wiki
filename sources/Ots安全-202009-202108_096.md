# 黑客入侵游戏巨头电子艺界，窃取游戏源代码

游戏巨头电子艺界 (EA) 遭到黑客攻击，威胁行为者声称窃取了大约 750 GB 的数据，包括游戏源代码和调试工具。

EA 在发给 BleepingComputer 的一份声明中证实了数据泄露，称这“不是勒索软件攻击，数量有限的代码和相关工具被盗，我们预计不会对我们的游戏或业务产生任何影响。”

BleepingComputer 与出售 EA 数据的威胁行为者进行了交谈，该行为者声称窃取了完整的 FIFA 源、EA 游戏客户端和用作游戏货币的积分。

众所周知，网络犯罪分子将游戏内积分用于洗钱目的。

当被问及他们如何获得 EA 网络的访问权限时，他们不会提供更多细节。

**被盗 EA 数据价值 2800 万美元**

攻击者声称可以访问 EA 的所有服务，并告诉愿意为被盗数据支付 2800 万美元的客户，他们还将获得“利用所有 EA 服务的全部能力”，正如Motherboard首次报道的那样。

总之，黑客声称从 EA 的网络中窃取了大量数据，包括：

*   FrostBite 游戏引擎源码和调试工具
    
*   FIFA 21配对服务器代码
    
*   FIFA 22 API 密钥和 SDK 和调试工具
    
*   调试工具、SDK 和 API 密钥
    
*   专有EA游戏框架
    
*   XBOX 和 SONY 私有 SDK 和 API 密钥
    
*   XB PS 和 EA pfx 和 crt 带密钥
    
*   他们还分享了目录列表和源代码的屏幕截图，以证明被盗信息是合法的。
    

BleepingComputer 发现攻击者使用 Kela 的 Dark Beast 情报服务在各种市场和黑客论坛上宣传被盗数据的帖子。

EA 数据待售 (BleepingComputer)

**预计不会对游戏或业务产生影响**

“我们正在调查最近一起入侵我们网络的事件，其中有限数量的游戏源代码和相关工具被盗，”一位 EA 发言人告诉 BleepingComputer。

  

“没有访问过玩家数据，我们没有理由相信玩家隐私存在任何风险。

  

“事件发生后，我们已经进行了安全改进，预计不会对我们的游戏或业务产生任何影响。

  

“作为正在进行的刑事调查的一部分，我们正在与执法官员和其他专家积极合作。”

  

EA 是多个知名品牌的游戏开发商和发行商，例如 Madden NFL、EA SPORTS FIFA、Battlefield、The Sims 和 Need for Speed。

  

EA 在全球拥有超过 4.5 亿注册玩家，2020 财年的 GAAP 净收入为 55 亿美元。
