Windows中类似于蠕虫漏洞影响WinRM服务器



在Windows系统驱动程序HTTP.sys中找到有关CVE-2021-31166漏洞的新信息。回想一下，漏洞可以使未经身份验证的攻击者发送利用漏洞的特制数据包。 


根据对研究员吉姆（DeVries），危险的漏洞不仅影响Windows 10中，Windows服务器2004和Windows Server 20H2，同时也经营运行Windows远程管理（系统的WinRM）服务。


问题在于，该组件还使用易受攻击的HTTP.sys驱动程序进行工作。WinRM是Microsoft上协议WS-Management的实现。该协议允许来自不同制造商的硬件和操作系统相互通信。 


此外，应该记住，默认情况下，Windows Server 2004（20H2）上激活了WinRM服务。因此，正如德弗里斯（Devries）解释的那样，违规行为威胁着公司环境。 


特殊的搜索引擎Shodan（用于检测易受攻击的设备的能力得到了增强）能够找到运行WinRM服务的超过160万个Windows系统。正是这些操作系统可能遭受CVE-2021-31166的利用，因此需要紧急更新。 


5月，Microsoft发布了一组补丁程序，解决了55个漏洞，其中包括CVE-2021-31166。这就是为什么您不应该延迟安装May更新的原因。 


上周，网络安全专家Axel Suchet在GitHub上发布了CVE-2021-31166的演示利用代码。
