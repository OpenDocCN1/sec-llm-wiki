Vulscan-使用Nmap NSE进行高级漏洞扫描









介绍



Vulscan是一个模块，可以增强对漏洞扫描程序的nmap。nmap选项-sV启用每个服务的版本检测，该服务用于根据识别出的产品确定潜在的缺陷。在脱机版本的VulDB中查找数据。

安装

请将文件安装到Nmap安装的以下文件夹中：

Nmap\scripts\vulscan\*

像这样克隆GitHub存储库：

git clone https://github.com/scipag/vulscan scipag_vulscanln -s `pwd`/scipag_vulscan /usr/share/nmap/scripts/vulscan

用法

您必须运行以下最小命令来启动简单的漏洞扫描：

nmap -sV --script=vulscan/vulscan.nse www.example.com

漏洞数据库

目前有以下预装的数据库可用：

  • scipvuldb.csv- https: //vuldb.com 

  • cve.csv- https: //cve.mitre.org 

  • securityfocus.csv-  https://www.securityfocus.com/bid/

  • xforce.csv- https: //exchange.xforce.ibmcloud.com/ 

  • expliotdb.csv- https: //www.exploit-db.com 

  • openvas.csv-  http://www.openvas.org

  • securitytracker.csv-  https://www.securitytracker.com  （报废）

  • osvdb.csv-  http://www.osvdb.org  （报废）

单数据库模式

您可以使用以下参数执行vulscan以使用单个数据库：

--script-args vulscandb=your_own_database

也可以创建和引用您自己的数据库。这需要创建一个数据库文件，该文件具有以下结构：

<id>;<title>

只需像引用预先提供的数据库之一那样执行vulscan。随时与我共享您自己的数据库和漏洞连接，并将其添加到官方存储库中。

/vulscan/

版本检测

如果版本检测能够识别软件版本，并且漏洞数据库提供了此类详细信息，则此数据也将匹配。

禁用此功能可能会引入假阳性，但也可能会消除假阴性并稍微提高性能。如果要禁用其他版本匹配，请使用以下参数：

--script-args vulscanversiondetection=0

vulscan的版本检测仅与Nmap版本检测和漏洞数据库条目一样好。某些数据库没有提供确定的版本信息，这可能导致很多错误肯定的结果（对于Apache服务器可以看到）。

比赛优先级

该脚本仅尝试识别最佳匹配。如果找不到正匹配，则显示可能的最佳匹配（可能为假阳性）。

如果要显示所有匹配项，这可能会引入很多假阳性，但可能对进一步调查很有用，请使用以下参数：

--script-args vulscanshowall=1

互动模式

交互式模式可帮助您覆盖每个端口的版本检测结果。使用以下参数启用交互模式：

--script-args vulscaninteractive=1

正在汇报

所有匹配结果均一行打印。默认布局是：

[{id}] {title}\n

可以使用带有以下参数的另一个预定义的报告结构：

--script-args vulscanoutput=details--script-args vulscanoutput=listid--script-args vulscanoutput=listlink--script-args vulscanoutput=listtitle

您可以通过使用以下参数（某些示例）来实施自己的报告结构：

--script-args vulscanoutput='{link}\n{title}\n\n'--script-args vulscanoutput='ID: {id} - Title: {title} ({matches})\n'--script-args vulscanoutput='{id} | {product} | {version}\n'

支持动态报表模板的以下元素：

  • {id}-漏洞的ID

  • {title}-漏洞的标题

  • {matches}-比赛数

  • {product}-匹配的产品字符串

  • {version}-匹配的版本字符串

  • {link}-链接到漏洞数据库条目

  • \ n-换行符

  • \ t-制表符

每个默认数据库都带有一个URL和一个链接，这些URL和链接在扫描期间使用，并且可以在自定义报告模板中以{link}的形式访问。要使用自定义数据库链接，请使用以下参数：

--script-args "vulscandblink=http://example.org/{id}"

免责声明

请记住，这种派生漏洞扫描在很大程度上依赖于nmap版本检测的可信度，记录的漏洞数量以及模式匹配的准确性。潜在的缺陷的存在没有通过额外的扫描或利用技术来验证。
