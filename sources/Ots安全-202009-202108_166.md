# Forrester将Microsoft评为2021年企业电子邮件安全浪潮的领导者

如今，组织面临着不断变化的威胁形势和呈指数级增长的攻击面。电子邮件是网络犯罪的主要攻击媒介，安全团队正在寻求有效且具有成本效益的方法，以最大程度地降低这些威胁的风险以及对组织生产力和创新的影响。

  

今天我们很自豪地宣布，微软在Forrester Wave™：企业电子邮件安全，2021年第二季度¹中处于领先地位，在战略类别中得分最高。Forrester Wave报告评估了企业电子邮件安全解决方案，并提供了有关这些供应商当前产品，策略和市场地位的详细概述。根据该报告，“ Forrester在2021年对电子邮件安全市场的评估显示，随着客户转向云电子邮件基础设施提供商的本机安全功能，安全电子邮件网关（SEG）逐渐成为恐龙。” Microsoft Defender用于Office 365 在事件响应，威胁情报，端点和端点检测与响应（EDR）解决方案集成标准以及产品策略，客户成功以及性能和运营标准方面，均获得了最高分。

对于我们微软公司而言，被公认为领导者证明了我们在该领域不断创新和改进的持续承诺。在过去的几年中，我们一直在努力构建客户所钟爱的解决方案，而今天的新闻只是对我们所做工作的最新验证，以及我们一直以来热爱我们解决方案的客户的反馈。

  

Microsoft提供了同类最佳的电子邮件和协作安全功能，这些功能在我们行业领先的扩展检测和响应（XDR）解决方案中起着至关重要的作用， Microsoft 365后卫。Microsoft Defender共同为Office 365 和 Microsoft 365Defender通过交易不同的点解决方案来获得全面的覆盖范围，从而帮助客户减少覆盖范围上的差距。随着客户面临越来越多地跨越多个域的攻击，Microsoft 365 Defender遍历这些域以了解整个事件链，识别受影响的资产（例如用户，端点，邮箱和应用程序），并将它们自动恢复到安全状态。

  

我们将建立最先进，最适合您的解决方案，为我们的客户提供最佳的保护，体验和价值，我们将继续在这一领域进行创新。
