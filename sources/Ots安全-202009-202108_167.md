# Adobe Illustrator中发现多个零日漏洞

**FortiGuard实验室 威胁研究报告**

  

受影响的平台：Windows

受影响的各方：Adobe Illustrator 2021版本25.2和更早版本的用户

影响：导致任意代码执行的多个漏洞

严重级别：严重

  

今年早些时候，即2021年2月，我在Adobe Illustrator中发现了多个严重的零日漏洞并将其报告给Adobe，Inc。在2021年5月11日星期二，Adobe发布了一些  修复了这些漏洞的安全补丁。它们被标识为CVE-2021-21103，CVE-2021-21104和CVE-2021-21105。所有这些漏洞都有与各种Illustrator插件相关的不同根本原因。由于这些漏洞的严重等级，我们建议用户尽快应用Adobe补丁。 

  

以下是有关这些漏洞的一些详细信息。通过单击下面的CVE链接，可以在相关的Fortinet零日咨询页面上找到更多信息：-

  

**CVE-2021-21103：**

这是在Adobe Illustrator中对计算机图形图元文件“ CGM”文件进行解码时存在的内存损坏漏洞。具体来说，此漏洞是由格式不正确的CGM文件引起的，该文件由于不正确的边界检查而导致越界读取内存访问。该特定漏洞存在于'Reader\_for\_CGM'插件中。 

  

攻击者可以通过对意外的读取，写入或释放进行越界访问来利用此漏洞，从而可能导致代码损坏，控制流劫持或信息泄漏攻击。

  

远程攻击者也可能能够通过精心制作的CGM文件利用此漏洞在应用程序的上下文中执行任意代码。

  

Fortinet先前针对此特定漏洞发布了IPS签名 Adobe.Illustrator.CVE-2021-21103.Memory.Corruption ，以主动保护我们的客户。

  

**CVE-2021-21104：**

这是在Adobe Illustrator中对Adobe Illustrator'AI'文件进行解码时存在的内存损坏漏洞。具体来说，该漏洞是由格式不正确的AI文件引起的，该AI文件由于不正确的边界检查而导致越界写入内存访问。 

  

攻击者可以通过对意外的读取，写入或释放进行越界访问来利用此漏洞，从而可能导致代码损坏，控制流劫持或信息泄漏攻击。

  

远程攻击者也可能能够通过精心制作的AI文件利用此漏洞在应用程序的上下文中执行任意代码。

  

Fortinet先前针对此特定漏洞发布了IPS签名 Adobe.Illustrator.CVE-2021-21104.Memory.Corruption ，以主动保护我们的客户。

  

**CVE-2021-21105：**

这是Adobe Illustrator中对Postscript“ PS”文件进行解码时存在的内存损坏漏洞。具体来说，此漏洞是由格式不正确的PS文件引起的，该PS文件由于不正确的边界检查而导致越界写入内存访问。此特定漏洞存在于“ MPS”插件中。 

  

攻击者可以通过对意外的读取，写入或释放进行越界访问来利用此漏洞，从而可能导致代码损坏，控制流劫持或信息泄漏攻击。

  

远程攻击者还可能能够通过精心制作的PS文件利用此漏洞在应用程序的上下文中执行任意代码。
