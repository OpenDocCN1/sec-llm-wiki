# Google Chrome V8 允许远程执行代码

Google的Chrome浏览器具有多个安全漏洞，这些漏洞可能为多种攻击铺平了道路，其中包括一个V8错误，该错误可能允许用户浏览器中的远程代码执行（RCE）。

  

高严重性V8问题的跟踪记录为CVE-2021-21227，由Singular Security Lab的Gengming Liu报告。Google将该错误描述为“ V8中的数据验证不足”，但其他细节仍在保留之中。但是，刘告诉《安全周刊》，该漏洞在一定程度上得到了缓解，因为它不允许攻击者逃脱Chrome运行的沙箱，这意味着攻击者无法访问计算机上的任何其他程序，数据和应用程序。因此，CVE-2021-21227将需要与另一个漏洞链接在一起，以便成功地对目标计算机造成严重破坏，使其超出浏览器本身。

  

研究人员还指出，他的发现与先前已修补的V8漏洞（CVE-2020-16040和CVE-2020-15965）有关。第一种允许远程攻击者在用户访问或重定向到特制网页时利用堆破坏。后者是一种类型混淆错误，它使远程攻击者可以潜在地执行超出范围的内存访问，也可以通过特制的HTML页面加以利用。

  

同时，根据另一份报告，使用bug进行攻击的含义取决于与应用程序关联的特权：在最坏的情况下，攻击者可以查看，更改或删除数据。

  

而且，如果有人关闭了沙箱，那么所有的赌注都会关闭。

  

Google最近在Chrome中修补了一个零日漏洞（研究人员为此在Twitter上放置了代码）。这是另一个V8问题，允许在浏览器应用程序内使用RCE（但不能进行沙箱转义）。

  

**Chrome 补丁将推出**

以下是所有九种Google Chrome漏洞的详细信息。它们会影响Chrome和其他使用Chromium框架的浏览器，例如Microsoft Edge：

*   CVE-2021-21227：V8组件中存在数据验证不足漏洞。
    
*   CVE-2021-21228：扩展中存在策略执行漏洞不足。
    
*   CVE-2021-21229：下载中存在不正确的UI漏洞。
    
*   CVE-2021-21230：V8组件中存在类型混淆漏洞。
    
*   CVE-2021-21231：V8组件中存在数据验证不足漏洞。
    
*   CVE-2021-21232：开发工具组件中存在的免费使用漏洞。
    
*   CVE-2021-21233：ANGLE组件中存在堆缓冲区溢出漏洞。
