# “ Windows TCP / IP拒绝服务漏洞利用”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247490874&idx=3&sn=f038016a31a22ffe4ee92ce713b9ecb7&chksm=9bae5471acd9dd67b639d6df6369fc321b1c09e4224624ea152c61392c0a8b1a22cd6cc9a109&scene=126&sessionid=1681670071#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247490874&idx=3&sn=f038016a31a22ffe4ee92ce713b9ecb7&chksm=9bae5471acd9dd67b639d6df6369fc321b1c09e4224624ea152c61392c0a8b1a22cd6cc9a109&scene=126&sessionid=1681670071#rd)

这是CVE-2021-24086（“ Windows TCP / IP拒绝服务漏洞”）的概念证明，这是tcpip.sysMicrosoft在2021年2月修补的NULL取消引用。根据此推文，该漏洞已由@piazzt发现。通过IPv6发送恶意UDP数据包可远程触发。

![](../Images/09f04ac5b4f2c36a4b47231d9fe35dbf.png)  

您可以在此处阅读Microsoft的博客：影响TCP / IP的多个安全更新：CVE-2021-24074，CVE-2021-24094和CVE-2021-24086。它简要讨论了影响和解决方法/缓解措施。

  

在doar-e.github.io上可以找到关于根本原因的更深入讨论：tcpip.sys的逆向工程：死亡数据包的机制（CVE-2021-24086）。
