介绍：

-------------

FusionAuth为任何应用程序提供身份验证，授权和用户管理。 

FusionAuth SAML库使用JAXB在Java中实现SAML v2.0绑定，并在 

FusionAuth IDP。Compass Security [3]确定了一个漏洞，该漏洞使远程攻击者能够

使用xml外部实体伪造SAML消息并读取文件系统上的文件或向其他系统发送网络请求。


做作的：

---------

易受伤害的：

fusionauth-samlv2 <0.5.4 


不易受攻击：

fusionauth-samlv2> = 0.5.4

 

技术说明

---------------------

未经身份验证的用户可以将带有xml外部实体的伪造SAML消息发送到FusionAuth。 

FusionAuth将解析xml外部实体并将结果反映在错误页面上。 

与外部实体的伪造SAML消息可能会在AuthnRequest或 

LogoutRequest，因为这些请求均不需要签名。任何公开的FusionAuth部署

SAML端点或利用fusionauth-samlv2库的应用程序很容易受到攻击。


在parseFromBytes函数[4]中可以找到负责解析XML的代码。 

该函数初始化javax.xml.parsers.DocumentBuilderFactory而不显式禁用 

文档类型定义。

``` private Document parseFromBytes(byte[] bytes) throws SAMLException {    DocumentBuilderFactory documentBuilderFactory = DocumentBuilderFactory.newInstance();    documentBuilderFactory.setNamespaceAware(true);    try {      DocumentBuilder builder = documentBuilderFactory.newDocumentBuilder();      return builder.parse(new ByteArrayInputStream(bytes));    } catch (ParserConfigurationException | SAXException | IOException e) {      throw new SAMLException("Unable to parse SAML v2.0 authentication response", e);    }  }```

解决方法/修复：

-----------------

升级到fusionauth-samlv2 0.5.4或更高版本，其中文档类型定义已禁用。
