思科Talos研究人员最近在Microsoft的Azure Sphere中发现了多个漏洞，Azure Sphere是一个云连接和自定义SoC平台，专门针对IoT应用程序安全性而设计。在内部，SoC由一组具有不同角色（例如，运行不同类型的应用程序，实施安全性和管理加密）的多个ARM内核组成，并且在外部，Microsoft的Azure Sphere云支持Azure Sphere平台，该Azure Sphere云可以处理安全更新，应用程序部署，并定期验证设备完整性，以确定是否应允许对其进行云访问。


Talos在Azure Sphere中发现了四个漏洞，这些漏洞可能导致未签名的代码执行和内核特权升级。这些漏洞的发现继续了我们对Azure Sphere的研究，并遵循了我们在2020年披露的多个漏洞。Microsoft在3月和4月的Patch Tuesday版本中修复了这些漏洞。有关4月份更新中披露的其余问题的更多信息，请在此处查看我们的帖子。


根据我们的协调披露政策，Cisco Talos与Microsoft共同确保解决了这些问题，并为受影响的客户提供了更新。


漏洞详情

  • Microsoft Azure Sphere挂接名称空间未签名代码执行漏洞（TALOS-2021-1247 / CVE-2021-27047）

Microsoft Azure Sphere 21.01的安装命名空间功能中存在一个未签名的代码执行漏洞。特制的shellcode可能允许对手在tmpfs挂载中执行任意二进制文件，从而导致未签名的代码执行。攻击者可以切换到新的装载名称空间来触发此漏洞。


参考：https://talosintelligence.com/vulnerability_reports/TALOS-2021-1247


  • Microsoft Azure Sphere Linux名称空间ptrace未签名代码执行漏洞（TALOS-2021-1249 / CVE-2021-27047）

Microsoft Azure Sphere 21.01的Linux名称空间ptrace功能中存在一个未签名的代码执行漏洞。特制的shellcode可以使对手执行未签名的代码。攻击者可以更改名称空间，并使用ptrace修改正在运行的进程的代码以触发此漏洞。


参考：https://www.talosintelligence.com/vulnerability_reports/TALOS-2021-1249


  • Microsoft Azure Sphere mqueue inode初始化内核代码执行漏洞（TALOS-2021-1250 / CVE-2021-27080）

Microsoft Azure Sphere 21.01的队列索引节点初始化功能中存在一个代码执行漏洞。一组特制的syscall可能导致未初始化的内核读取，进而导致内核中的代码执行。要触发此漏洞，攻击者可以在根IPC命名空间中创建并打开队列，也可以仅创建并销毁IPC命名空间。


参考：https://www.talosintelligence.com/vulnerability_reports/TALOS-2021-1250


  • Microsoft Azure球形内核pwm_ioctl_apply_state kfree（）代码执行漏洞（TALOS-2021-1262 / CVE-2021-28460）

Microsoft Azure Sphere 21.01的内核pwm_ioctl_apply_state功能中存在一个代码执行漏洞。特制的ioctl可能导致任意kfree。攻击者可以发出ioctl来触发此漏洞。

参考：https://www.talosintelligence.com/vulnerability_reports/TALOS-2021-1262


测试版本

Talos已测试并确认这些漏洞会影响Microsoft Azure Sphere 21.01版。
