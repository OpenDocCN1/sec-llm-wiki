CVE 2015-4852

此Python脚本执行检查WebLogic服务器是否容易受到CVE-2015-4852的攻击。

在保存python脚本的同一目录中创建文件“ targets.txt”，并将WebLogic服务器IP放入文件中。运行脚本并检查结果     例子：-

python weblogic-CVE-2015-4852.py

  • 项目地址：https://github.com/incredibleindishell/weblogic-exploits/tree/master/CVE%202015-4852


CVE 2018-2628

此python脚本执行基本测试，测试WebLogic Server是否容易受到CVE 2018-2628的攻击。用法：下载代码。将WebLogic Server IP放置在第79行（用服务器IP替换127.0.0.1），将端口放置在第88行（用运行WebLogic服务器的端口替换9013）。保存代码并运行python脚本。例子：-

python weblogic_poc.cve-2018-2628.py

  • 项目地址：https://github.com/incredibleindishell/weblogic-exploits/tree/master/CVE%202018-2628
