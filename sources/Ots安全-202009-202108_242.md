# Microsoft 4月安全更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247490608&idx=1&sn=a1f263ebb0a160e2e606d5494f0bafa6&chksm=9bae557bacd9dc6de259dc9287621349b65c10f5a3c12003a5daa714de1cbd8f97fca69f080a&scene=126&sessionid=1681670076#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247490608&idx=1&sn=a1f263ebb0a160e2e606d5494f0bafa6&chksm=9bae557bacd9dc6de259dc9287621349b65c10f5a3c12003a5daa714de1cbd8f97fca69f080a&scene=126&sessionid=1681670076#rd)

微软今天发布了更新程序，以在其Windows操作系统和其他产品中填补至少110个安全漏洞。这些补丁包括针对Microsoft Exchange Server的四个安全修复程序-过去一个月，该系统遭到了电子邮件软件中四个单独的（和0day）错误的攻击所困扰。雷德蒙德还修补了Windows漏洞，该漏洞在野外被积极利用。

本月修复的漏洞中有19个获得了Microsoft的“最严重”标签，这意味着恶意软件或恶意软件可能会利用这些漏洞在没有用户任何帮助的情况下抢占对易受攻击的Windows系统的远程控制。

  

Microsoft发布了更新，以修复Exchange Server版本2013-2019（CVE-2021-28480，CVE-2021-28481，CVE-2021-28482，CVE-2021-28483）中的另外四个漏洞。有趣的是，这四个漏洞都是由美国国家安全局报告的，尽管微软表示它也在内部发现了两个漏洞。随今天的修补程序一起发布的Microsoft博客文章敦促Exchange Server用户将修补系统列为重中之重。

  

Tenable的研究工程师Satnam Narang表示，利用Microsoft的Exploitability Index，这些漏洞被评为“更可能利用”。

  

“四个漏洞中的两个（CVE-2021-28480，CVE-2021-28481）是预先身份验证的，这意味着攻击者无需向易受攻击的Exchange服务器进行身份验证即可利用此漏洞，” Narang说。“自从上个月以来对Exchange Server的强烈兴趣，至关重要的是，组织必须立即应用这些Exchange Server修补程序。”

  

今天还修复了Windows中的漏洞（CVE-2021-28310），该漏洞已经在主动攻击中加以利用。该缺陷使攻击者可以在目标系统上提升其特权。

  

“这是否意味着他们要么需要登录到系统或诱骗合法用户进入运行代表他们的代码，说：”达斯汀童车的趋势科技。“考虑到列出了发现此错误的人员，它可能已在恶意软件中使用。这种性质的错误通常会与其他错误（例如PDF漏洞的浏览器错误）合并，以接管系统。”

  

卡巴斯基实验室的 研究人员在关于发现和报告对CVE-2021-28310的攻击之后所观察到的内容的技术文章中指出，他们看到的漏洞可能与其他浏览器漏洞一起使用，以逃避对浏览器的“沙盒”保护。

  

卡巴斯基的研究人员写道：“不幸的是，我们无法捕获完整的链，因此我们不知道该漏洞利用是否与另一个浏览器零日使用，或与已知的已修补漏洞一起使用，”。

  

Recorded Future的高级安全架构师Allan Laska指出，本月发布的Microsoft Office产品中也存在一些远程代码执行漏洞。CVE-2021-28454和CVE-2021-28451涉及Excel，而CVE-2021-28453在Microsoft Word中，而CVE-2021-28449在Microsoft Office中。Microsoft将这四个漏洞标记为“重要”（不如“严重”严重）。这些漏洞影响其各自产品的所有版本，包括Office 365。

**相关信息**

*   Windows 10 更新是累积更新。除了非安全更新之外，每月安全发布还包括针对影响 Windows 10 的漏洞的所有安全修补程序。可通过 Microsoft 更新目录获取更新。有关 Windows 10 操作系统生命周期和支持日起的信息，请参阅 Windows 生命周期说明书。
    
*   Microsoft 正在改进 Windows 发行说明。如需了解更多详情，请参阅 Windows 发行说明下一版本。
    
*   ADV990001 中包含每个操作系统的最新服务堆栈更新列表。每当有新服务堆栈更新发布时，此列表就会进行更新。请务必安装最新服务堆栈更新。
    
*   除了针对这些漏洞的安全更改之外，这些更新还包括纵深防御更新，可帮助改进与安全相关的功能。
    
*   运行 Windows 7、Windows Server 2008 R2 或 Windows Server 2008 的客户需要购买扩展的安全更新，以继续接收安全更新。有关更多信息，请参阅 4522133。
