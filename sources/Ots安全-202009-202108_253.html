SecLists是安全测试人员的伴侣。它是在安全评估期间使用的各种类型列表的集合，这些列表集中在一个地方。列表类型包括用户名，密码，URL，敏感数据模式，模糊有效值，Web Shell等。目的是使安全测试人员可以将存储库拉到新的测试箱中，并可以访问可能需要的另一个类型的列表。


该项目由Daniel Miessler，Jason Haddix和g0tmi1k维护。


项目地址：https://github.com/danielmiessler/SecLists


安装

压缩

wget -c https://github.com/danielmiessler/SecLists/archive/master.zip -O SecList.zip \  && unzip SecList.zip \  && rm -f SecList.zip

Git（小）

git clone --depth 1 https://github.com/danielmiessler/SecLists.git

Git（完整）

git clone https://github.com/danielmiessler/SecLists.git

Kali Linux（工具页）

apt -y install seclists
