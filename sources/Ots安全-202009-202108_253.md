# SecLists的密码字典+Web Shell

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247490521&idx=3&sn=baad02df05a63d17a37a551e386f3245&chksm=9bae5292acd9db84a62bb50edcdd31c4e9448c316295b67d80d528d4346bd70e8033cd30b836&scene=126&sessionid=1681670082#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247490521&idx=3&sn=baad02df05a63d17a37a551e386f3245&chksm=9bae5292acd9db84a62bb50edcdd31c4e9448c316295b67d80d528d4346bd70e8033cd30b836&scene=126&sessionid=1681670082#rd)

SecLists是安全测试人员的伴侣。它是在安全评估期间使用的各种类型列表的集合，这些列表集中在一个地方。列表类型包括用户名，密码，URL，敏感数据模式，模糊有效值，Web Shell等。目的是使安全测试人员可以将存储库拉到新的测试箱中，并可以访问可能需要的另一个类型的列表。

  

该项目由Daniel Miessler，Jason Haddix和g0tmi1k维护。

  

项目地址：https://github.com/danielmiessler/SecLists
