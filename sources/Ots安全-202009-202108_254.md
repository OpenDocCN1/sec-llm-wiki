一段时间以来，我们一直在寻找一个进行志愿者安全审核的项目。最近，我们为我们找到了一个完美的选择-由Rails提供支持的开源加密货币交易所Peatio。

我们花了8个小时来寻找一种方法，以解决比特币交易所可以做的最坏的事情-窃取热钱包。该任务已部分完成，我们发现了一系列有趣的关键漏洞。

## **步骤1.劫持帐户**

![](../Images/95351cc5ea6cc68b89f1b7999725b64f.png)

  

Peatio内置了“连接微博帐户”功能。根据OAuth安全备忘单，OAuth的实施不当是一种接管帐户的可靠方法。

##### 将攻击者的微博帐户连接到受害者的Peatio帐户

omniauth-weibo-oauth2 gem容易受到状态修复的攻击。我们可以将state设置为任意值（例如123），然后改用state = 123来应用攻击者的代码，这将导致将攻击者的微博分配给受害者的对等帐户。完全相同的问题是在omniauth-facebook gem和其他基于omniauth的库中复制了相同的易受攻击的代码。有趣的是，上面的评论说“支持omniauth-oauth2的自动csrf保护”，但相反，将其关闭。

##### 如果用户已经连接了微博怎么办？

该系统不会连接另一个微博帐户，但我们希望该漏洞利用程序能够对每个可能的受害者无缝运行。因此，我们入侵了微博的OAuth。

首先，我们发现微博没有`redirect_uri`像Github一样不在白名单中。可以切换`redirect_uri`到受害者域上的另一个页面以泄漏`code`Referrer标头中的内容，然后使用它登录受害者的帐户。

但是，在Peatio上没有这样的页面来使其泄漏。没有外部图像，链接或其他任何内容。攻击面很小。但后来我们在`DocumentsController`：

*   
*   
*   
*   

```
if not @doc  redirect_to(request.referer || root_path)  returnend
```

跟随重定向链通过首先将代码放入`#`片段中来泄漏代码。

1.  `attacker_page` 重定向到 `weibo.com/authorize?...redirect_uri=https://app/documents/not_existing_doc%23...`
    
2.  微博无法正确解析`redirect_uri`，并将受害者重定向到`https://app/documents/not_existing_doc#?code=VALID_CODE`
    
3.  Peatio无法找到`not_existing_doc`并发送等于请求头的Location标头。referer仍然是Attacker\_page （浏览器在重定向时保留了此标头）
    
4.  浏览器保留`#?code=VALID_CODE`片段并加载`attacker_page#?code=VALID_CODE`。现在，可以通过JS使用JS泄漏代码`location.hash`。该代码可用于`https://app/auth/weibo/callback`登录受害者的帐户。
    

因此，使用上述两个错误，我们可以劫持任何对等账户，并且只有最后一个需要JS。

##### 此外，SMS 2FA还有两个问题

*   
*   
*   
*   

```
def gen_code  self.otp_secret = OTP_LENGTH.times.map{ Random.rand(9) + 1 }.join  self.refreshed_at = Time.nowend
```

  

第一个问题是`Random.rand`基于PRNG（Mersenne Twister）的，一旦有了足够的后续生成的数字，就可以很容易地预测到它。

第二个问题是`rand(9)`只能生成0到8之间的数字，因此组合总数将为9 ^ 6 = 531441，几乎比1,000,000少两倍，并且比App 2FA暴力破解更容易两倍。

通过上面概述的技巧，我们可以为任何用户跳过2FA。在最坏的情况下，它需要不到3天的时间。如果受害者只有Google Authenticator，则只需不到5秒钟即可设置新的SMS身份验证器。

## **步骤3：攻击管理员**

好了，我们可以劫持该帐户并为任何用户绕过2FA，因此我们可以从访问我们页面的任何人那里窃取比特币。仍然，我们仍然需要大量用户来诱骗点击我们的虚假链接。让我们只关注其中之一-管理员。

使管理员访问我们链接的最简单方法是创建一个支持票，其内容为“我的帐户有什么问题，请检查吗？https://i.will.hack.you/now”。然后，我们破解2FA进入`/admin`面板：
