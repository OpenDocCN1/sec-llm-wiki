什么是Sub 404

Sub 404是用python编写的工具，用于检查子域接管漏洞的可能性，并且它是异步的，因此速度很快。


为什么

在侦查过程中，您可能会得到很多子域（例如，超过10k）。由于速度非常慢，因此无法手动或使用传统的请求或urllib方法进行测试。使用Sub 404，您可以以更快的方式自动执行此任务。Sub 404使用aiohttp / asyncio，这使该工具异步且速度更快。


怎么运行的

Sub 404使用文本文件中的子域列表，并检查404 Not Found状态代码的url，此外，它还会获取CNAME（规范名称）并删除那些在CNAME中具有目标域名的URL。如果您没有目标子域，则它还会合并subfinder和sublist3r（子域枚举工具）的结果，因为两个子域要好于一个。但是，为此必须在系统中安装sublist3r和subfinder工具。Sub 404能够在不到5分钟的时间内检查7K子域。


如何使用：

注意：仅适用于Python3.7 +

  • git clone https://github.com/r3curs1v3-pr0xy/sub404.git

  • 安装依赖项：pip install -r requirements.txt

  • 安装Subfinder（可选）

  • 安装Sublist3r（可选）

  • python3 sub404.py -h


使用泊坞窗

作为替代方案，也可以构建Docker映像，因此不需要任何先决条件。

$ docker build -t sub404 .$ docker run --rm sub404 -h

用法示例：

注意：如果安装了subfinder和sublist3r。

这结合了sublist3r和subfinder工具的结果，并检查了接管的可能性。

$ python3 sub404.py -d anydomain.com

-如果未安装subfinder和sublist3r，请在文本文件中提供子域

$ python3 sub404.py -f subdomain.txt

笔记：

该工具主要在Linux上进行了测试，但也应该在其他OS上也可以使用。
