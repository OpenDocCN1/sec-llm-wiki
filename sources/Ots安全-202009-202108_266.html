VMware vRealize Operations 存在SSRF和文件写入漏洞

原文：http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247490349&idx=1&sn=e0f13522b53f05f4adedaccf16a842af&chksm=9bae5266acd9db70d9d85ce36a824e670891343ad677f458b655c6a239ede7fb9f37e5d23f17&scene=126&sessionid=1681670082#rd

严重的漏洞CVE-2021-21975是vROPs Manager API中的服务器端请求伪造（SSRF）漏洞。未经身份验证的远程攻击者可以通过将特制请求发送到易受攻击的vROPs Manager API端点来利用此漏洞。成功的利用将导致攻击者获得管理凭据。    


“ VMware还修补了CVE-2021-21983，这是VROPs Manager API中的任意文件写入漏洞，可用于将文件写入底层操作系统。此漏洞是身份验证后的，这意味着攻击者需要使用管理凭据进行身份验证才能利用此漏洞。   “尽管这些漏洞单独出现，但似乎不像CVE-2021-21972严重 ，该漏洞是2月份修补的VMware vCenter Server中的远程代码执行漏洞。但是，如果攻击者将CVE-2021-21975和CVE-2021-21983链接在一起，他们还可以获得远程代码执行特权。


VMware为vROPs Manager 7.5.0到8.3.0的两个漏洞提供了补丁。他们还提供了一种临时解决方法，以防止攻击者利用这些缺陷。在组织能够计划应用补丁程序之前，该解决方法应仅用作临时的权宜之计。” —  Tenable员工研究工程师Satnam Narang


vRealize Operations Manager API中的服务器端请求伪造（CVE-2021-21975）

描述

vRealize Operations Manager API包含服务器端请求伪造。VMware已将此问题评估为“重要”严重性，最高CVSSv3基本得分为8.6。

已知攻击向量


可以通过网络访问vRealize Operations Manager API的恶意攻击者可以执行服务器端请求伪造攻击，以窃取管理凭据。


vRealize Operations Manager API中的任意文件写入漏洞（CVE-2021-21983）

描述

经过身份验证的攻击者可以通过网络访问vRealize Operations Manager API，成功利用漏洞可以将文件写入任意位置。
