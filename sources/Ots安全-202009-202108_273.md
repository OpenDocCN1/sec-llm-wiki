# 勒索软件周-2021年3月26日-攻击数量增加

针对企业的勒索软件攻击以Accellion数据泄漏，全面的勒索软件攻击以及更多针对Microsoft Exchange的勒索软件帮派的形式继续存在。

  

在本周初，发现威胁者正在Microsoft Exchange服务器上部署Black Kingdom Ransomware。到本周末，微软估计该组攻击的目标是大约1,500台交换服务器。

  

**2021年3月21日**

新的Pay2Decrypt变体

S！Ri 发现了一个新的Pay2Decrypt变体，该变体附加了.aes扩展名。

  

**2021年3月22日**

*   Black Kingdom勒索软件现在锁定了Microsoft Exchange服务器
    

另一个被称为“黑王国”的勒索软件操作正在利用Microsoft Exchange Server ProxyLogon漏洞对服务器进行加密。

  

*   能源巨头壳牌在Accellion遭到黑客攻击后披露数据泄露
    

攻击者入侵了由Accellion的File Transfer Appliance（FTA）驱动的公司安全文件共享系统后，能源巨头壳牌公司披露了数据泄露事件。

  

*   新的Dharma勒索软件变体
    

Jakub Kroustek 发现了一个新的Dharma勒索软件变体，该变体附加了 .bqd2扩展名。

  

**2021年3月23日**

*   勒索软件攻击关闭了Sierra Wireless IoT制造商
    

全球领先的物联网（IoT）解决方案提供商Sierra Wireless今天披露了勒索软件攻击，迫使其停止了所有生产基地的生产。

  

*   高可用性服务器制造商Stratus受勒索软件打击
    

Stratus Technologies遭受了勒索软件攻击，该勒索软件攻击要求使系统脱机以防止攻击蔓延。

  

*   勒索软件团伙泄露了从迈阿密大学科罗拉多州窃取的数据
    

Clop勒索软件小组已在网上发布了科罗拉多大学和迈阿密大学患者数据的学生的成绩和社会保险号。

  

*   CNA保险公司遭受网络攻击，运营受到影响
    

美国领先的保险公司CNA Financial遭受了网络攻击，影响了其业务运营并关闭了其网站。

**2021年3月24日**

*   新的Makop变体
    

dnwls0719 发现了一个新的Makop勒索软件变体，该变体附加了 .pecunia扩展名并删除了名为readme-warning.txt的勒索字条。

  

**2021年3月25日**

*   保险巨头CNA被新的Phoenix CryptoLocker勒索软件打击
    

保险业巨头CNA使用名为Phoenix CryptoLocker的新变体遭受了勒索软件攻击，该变体可能与Evil Corp黑客组织有关。

  

*   Evil Corp转向Hades勒索软件以逃避制裁
    

Hades勒索软件已与Evil Corp网络犯罪团伙联系在一起，该团伙利用该勒索逃避了财政部外国资产控制办公室（OFAC）施加的制裁。

  

勒索软件团伙从美国军事承包商PDI集团泄漏数据

向美国空军和全球军方提供军事装备的主要供应商似乎已成为勒索软件攻击的受害者。

  

*   新的Stop Ransomware变体
    

Amigo-A 发现了一个新的STOP勒索软件变体，该变体附加了.ekvf扩展名。

  

**2021年3月26日**

*   FBI揭露Mamba勒索软件DiskCryptor的弱点
    

美国联邦调查局关于Mamba勒索软件的警报显示，加密过程中存在薄弱环节，可以帮助目标组织从攻击中恢复而无需支付勒索。

  

*   勒索软件团伙敦促受害者的客户为他们的隐私而战
    

勒索软件操作“ Clop”通过向客户发送电子邮件并要求他们要求勒索赎金来保护受害者的隐私，从而对受害者施加最大的压力。

  

*   微软：Black Kingdom勒索软件入侵了1.5K Exchange服务器
    

微软已经发现，Black Kingdom运营商在易受ProxyLogon攻击的大约1,500台Exchange服务器上部署了Web Shell。

  

*   零售商FatFace向Conti网络罪犯支付了200万美元的赎金
    

据《计算机周刊》了解，在2021年1月对其系统进行了成功的网络攻击之后，时尚零售商FatFace向Conti勒索软件团伙支付了200万美元的赎金。

  

*   新的HiddenTear变体
    

dnwls0719发现了一个新的HiddenTear变体，该变体附加了.HANTA扩展名并删除了一个名为how\_to\_recover.txt的赎金票据。
