Cicada 3301被描述为“互联网上最令人困惑和神秘的谜团”，并被《华盛顿邮报》列为“互联网上最不可思议的5大未解之谜”之一。Cicada 3301在互联网和深色网上发布了三本引人入胜的谜题，其中三本声称要“招募聪明的人”。


关于Cicada 3301的猜测和理论很多，包括它们是NSA，MI6，Illuminati，邪教组织或黑客组织的招聘工具。许多人最初认为Cicada 3301是一种替代现实游戏，但仍然很少有人知道这个兔子洞会导致什么。那些确实从互联网上消失了的人。

MIDI文件是一种音乐密码形式。分析MIDI文件显示它具有两个音轨（提供两个不同的消息）。每个消息的音高和音调长度组合少于26个，这暗示音高和音调长度的每种组合都可以代表一个字母。


这可以通过不同的方式解决。这是一个简短的Python程序，可将MIDI文件中的音轨转换为文本密码。它使用开源的MIDI解析器mido，您需要在运行该程序之前进行安装。

import mido

def getNotes(filename, track):
    result = ''
    for msg in mido.MidiFile(filename).tracks[track]:
        if msg.type == 'note_off':
            result += f'{msg.note} {msg.time}\r\n'
    return result

def notesToSingleLetters(msg):
    result = ''
    letters = list('abcdefghijklmnopqrstuvwxyz')
    dict = {}
    for line in msg.splitlines():
        if line in dict:
            result += dict[line]
        else:
            letter = letters.pop(0)
            result += letter
            dict[line] = letter
    return result

print(notesToSingleLetters(getNotes('cicada-3301-2012-midi-song.midi', 1)))
