# CVE-2021-26855远程执行代码漏洞利用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247490147&idx=1&sn=e95489cb757a94b09fde5600edbbbec1&chksm=9bae5328acd9da3ef661ddf3113a52c41e0518451f42afabac62efcf5f5b9a49b63d2a6be4e1&scene=126&sessionid=1681670087#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247490147&idx=1&sn=e95489cb757a94b09fde5600edbbbec1&chksm=9bae5328acd9da3ef661ddf3113a52c41e0518451f42afabac62efcf5f5b9a49b63d2a6be4e1&scene=126&sessionid=1681670087#rd)

Microsoft Exchange Server远程执行代码漏洞此CVE ID在CVE-2021-26412，CVE-2021-26854，CVE-2021-26857，CVE-2021-26858，CVE-2021-27065，CVE-2021-27078中是唯一的。

  

ProxyLogon是CVE-2021-26855的正式通用名称，CVE-2021-26855是Microsoft Exchange Server上的一个漏洞，它使攻击者可以绕过身份验证并冒充管理员。我们还将此错误与另一个post-auth任意文件写入漏洞CVE-2021-27065链接在一起，以执行代码。默认情况下，所有受影响的组件都容易受到攻击！

  

结果是，通过未经身份验证的攻击者可以通过仅打开的443端口在Microsoft Exchange Server上执行任意命令！

**哪些版本的Exchange Server受到影响？**

由于该错误是由于Exchange Server 2013上的客户端访问服务体系结构发生了重大变化而导致的，而较早版本的Exchange Server 2010于2020年10月终止了支持。所有主流支持的Exchange Server都容易受到攻击！

  

**确切的易受攻击的版本表：**

*   Exchange Server 2019 <15.02.0792.010
    
*   Exchange Server 2019 <15.02.0721.013
    
*   Exchange Server 2016 <15.01.2106.013
    
*   Exchange Server 2013 <15.00.1497.012

**CVE-2021-26855 - 缓解措施**

该攻击是此攻击链的一部分。初始攻击需要与Exchange Server扩展443建立不受信任的连接。我们可以通过限制不受信任的连接或设置VPN来将Exchange Server与外部访问隔离，从而防止这种情况如果攻击者已经拥有了访问权限，或者能够说服管理员运行恶意文件，则可以触发该攻击链的其他部分。

  

我们建议优先在面向外部的Exchange Server上安装更新。
