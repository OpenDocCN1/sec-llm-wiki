**一，概述**

2020年5月20日（当地时间），Apache软件基金会发布了有关Apache Tomcat中漏洞（CVE-2020-9484）的信息。该漏洞是由于对反序列化数据的验证不正确造成的。利用此漏洞的远程攻击者如果能够控制服务器上文件的内容和名称，则可以通过发送精心设计的请求，在其控制下对文件进行反序列化，从而执行任意代码。

  

有关此漏洞的更多信息，请参考Apache Software Foundation提供的信息。通过会话持久性执行的

  

**Apache Software Foundation**

**CVE-2020-9484 Apache Tomcat远程代码执行**

https://lists.apache.org/thread.html/r77eae567ed829da9012cadb29af17f2df8fa23bf66faf88229857bb1%40%3Cannounce.tomcat.apache.org%3E

  

**更新：2021年3月2日更新**

2020年3月1日（当地时间），Apache软件基金会发布了有关Apache Tomcat中漏洞（CVE-2021-25329）的信息。该漏洞的发布是由于CVE-2020-9484的修复不完整，在不太可能的配置边缘情况下，Tomcat实例仍然容易受到CVE-2020-9484的攻击。有关详细信息，请参考Apache Software Foundation提供的信息。

  

**Apache Software Foundation**

**CVE-2021-25329对CVE-2020-9484的不完整修复（通过会话持久性进行RCE）**

https://lists.apache.org/thread.html/rfe62fbf9d4c314f166fe8c668e50e5d9dd882a99447f26f0367474bf%40%3Cannounce.tomcat.apache.org%3E

  

**二。受影响的产品**

**以下版本受此漏洞影响：**

**\-Apache**

Tomcat 10.0.0-M1至10.0.0-M4

\-Apache Tomcat 9.0.0.M1至9.0.34

\-Apache Tomcat 8.5.0至8.5.54

\-Apache Tomcat 7.0。0到7.0.103

  

如果服务器配置为将PersistentManager与FileStore一起使用，并且PersistentManager配置为具有sessionAttributeValueClassNameFilter =“ null”或足够宽松的过滤器以允许攻击者提供的对象反序列化，则上述版本容易受到攻击。

  

**更新：2021年3月2日更新**

**以下版本受此漏洞（CVE-2021-25329）的影响：**

**\-Apache**

Tomcat 10.0.0-M1至10.0.0

\-Apache Tomcat 9.0.0.M1至9.0.41

\-Apache Tomcat 8.5.0至8.5.61

\-Apache Tomcat 7.0.0至7.0.107

  

**三，解决方案**

Apache Software Foundation已发布了解决此漏洞的Apache Tomcat版本。请参考Apache提供的信息更新到这些版本。 

\-Apache

Tomcat 10.0.0-M5

\-Apache Tomcat 9.0.35

\-Apache Tomcat 8.5.55

\-Apache Tomcat 7.0.104
