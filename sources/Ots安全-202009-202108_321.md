# 微软投资通用汽车的Cruise，实现无人驾驶的未来

软件巨头确认这是通用汽车的Cruise自动驾驶部门20亿美元投资的一部分，该部门将利用Azure向前发展

通用汽车是自动驾驶专家Cruise的母公司，它在周二证实微软已经以一笔巨额投资加入了合资企业。

根据新闻稿，微软将与本田，通用汽车和机构投资者一道，对Cruise进行总计超过20亿美元的新股权投资。

这项投资突显了科技行业的知名人士如何将自动驾驶汽车市场视为未来几年的增长市场。

![](../Images/49a801dc95423cfb593fb99c9052a16a.png)

汽车伙伴关系  

微软与通用汽车之间的“长期战略关系”旨在帮助加速自动驾驶汽车的商业化。

已经证实，两家公司“将把他们在软件和硬件工程方面的卓越表现，云计算能力，制造专有技术和合作伙伴生态系统整合在一起，以改变运输方式，为每个人创造一个更安全，更清洁，更便捷的世界。”

为此，通用汽车将与微软合作，作为其首选的公共云提供商，以加速其数字化计划，包括协作，存储，人工智能和机器学习功能。

克鲁兹还将利用Azure将其自动驾驶汽车解决方案大规模商业化。

通用汽车显然还将与微软一起探索“简化数字供应链中的运营，提高生产率并更快地为客户提供新的移动服务”的机会。

Cruise首席执行官丹·安曼（Dan Ammann）表示：“我们为所有人提供更安全，更好，更实惠的交通的使命不仅是一场技术竞赛，而且是一场信任竞赛。” “作为可信赖的技术民主化的金标准，微软将成为我们的动力倍增器，因为我们将无人驾驶，全电动，共享车辆的车队商业化。”

微软首席执行官萨蒂亚·纳德拉（Satya Nadella）说：“数字技术的进步正在重新定义我们工作和生活的方方面面，包括我们如何移动人员和货物。” “作为Cruise和GM的首选云，我们将利用Azure的力量来帮助他们扩展规模并使其成为自动交通的主流。”

通用汽车公司负责人玛丽·巴拉（Mary Barra）说，微软的介入将“帮助我们加快Cruise的全电动自动驾驶汽车的商业化。”

巴拉说，通用汽车计划到2025年在全球推出30款新电动汽车。
