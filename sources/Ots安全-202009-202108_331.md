# 法国与俄罗斯沙虫组织3年黑客攻击运动

来自法国政府的计算机应急准备小组CERT-FR的警报

法国网络安全部门警告说，被广泛使用的开源IT监控软件Centreon似乎已成为俄罗斯黑客的攻击目标。但是与SolarWinds供应链攻击不同，在此活动中，攻击者似乎已经入侵了该软件的过时，未修补版本。

  

Centreon开源IT网络监视工具由位于巴黎的同名公司开发。

  

法国国家网络安全局（ANSSI）表示，该活动已导致至少数家法国组织受到侵犯，长达三年之久。

  

ANSSI的CERT-FR（周一是法国政府的计算机应急准备小组）周一发布了安全警报，其中说：“该活动主要影响了IT服务提供商，尤其是网络托管提供商。” 该警报包括所有组织可以用来帮助检测和阻止类似攻击的危害指标。

  

Centreon还出售该工具的商业版本，这不是警报的重点。

  

Centreon的一位发言人告诉信息安全媒体集团，攻击者针对的开源版本似乎于2014年或2015年发布。“因此，这很令人震惊-用户尚未更新其版本。”

  

发言人说，该软件的黑客版本还向设备中添加了“非Centreon设计的文件”，并补充说，受害者似乎也已配置了运行监视软件的系统以进行远程访问，而没有适当的保护措施。“这违反了行业和Centreon本身的建议；我们建议仅使用VPN。”

  

Centreon发言人说，没有任何商业客户受到此恶意软件或漏洞的攻击。“我们还建议用户始终遵守这些建议：更新他们的版本；如果您不使用商业版本，则除了使用开源软件之外，还使用安全软件；并且不要在启用该系统的Internet访问的情况下进行监视。”

  

德国网络间谍专家蒂莫·史蒂芬斯（Timo Steffens）同样表示，根据ANSSI的警报，针对Centreon的攻击活动似乎针对未打补丁的系统，而不是将恶意软件潜入该组织的软件开发渠道。后者的策略与去年的SolarWinds供应链攻击有关，在这次攻击中，可疑的俄罗斯间谍黑客显然将他们的“ Sunburst”后门代码潜入了公司的软件开发管道，此后由多达18,000个用户安装并实施了更新。

  

超过三年来，Sandworm一直在使用Webshell和Linux版本的后门Exaramel来打击未被发现的法国实体。

**黑客放下Webshell**

一个40页的报告在法国，周一公布的Anssi，虽然陈旧1月27日，进一步介绍了进攻战役和对策。

  

当局表示，针对Centreon的攻击活动的第一个已知受害者在2017年底受到了攻击，该攻击活动一直持续到去年才被发现。CERT-FR表示，以前曾在受影响的组织内部的系统上发现过恶意软件，包括安全公司ESET称之为Exaramel的恶意Linux代码。

  

CERT-FR说：“在受感染的系统上，ANSSI发现以webshell的形式存在后门，该后门落在暴露于Internet的几台Centreon服务器上。” “该后门被标识为PAS Webshell，版本号3.1.4。在同一服务器上，ANSSI发现了另一个与ESET描述的后门相同的后门，名为Exaramel。”

  

该警报还补充说：“此活动与先前归因于名为Sandworm的入侵集的活动有几处相似之处。”

  

查找先前已被攻击者使用的恶意软件不足以将对该恶意软件的任何进一步使用归因于同一组攻击者。但是ANSSI对Sandworm的命名表明它怀疑该组织确实参与其中。

  

**持久的远程访问**

ESET和其他安全公司表示，例如，所谓的俄罗斯攻击者以前曾使用过PAS Webshell，这是使用BlackEnergy和其他恶意软件的Grizzly Steppe APT活动的一部分。

  

安全公司Trustwave的SpiderLabs研究小组表示：“ PAS Web shell属于功能齐全的PHP Web shell，攻击者在进行初始利用后将其使用，以维持对受感染Web门户的持久访问。”

**俄罗斯的worm蠕虫**

沙虫（Sandworm）是俄罗斯政府的一个骇客小组，具有破坏性攻击的嗜好，是GRU军事情报机构的一部分。众所周知，GRU 74455单位也称为TeleBots，Voodoo Bear和Iron Viking。

![](../Images/c92a13c54d904a2bbd2eaff9e1b453ae.png)

所谓的俄罗斯GRU（又名“沙虫”）特工于2020年10月被起诉（从左到右，第一排）：Yuriy Andrienko，Sergey Detistov，Pavel Frolov，Anatoliy Kovalev，Artem Ochichenko和Petr Pliskin（来源：美国司法部）

在2020年10月发布的联邦起诉书中，美国当局指责74455部队成员直接参与了众多攻击，包括2017年NotPetya假勒索软件攻击，试图破坏2018年冬季奥运会和2020年夏季奥运会以及对组织的攻击调查俄罗斯在2018年的Novichok对英国土壤的袭击。

  

俄罗斯当局驳斥了这些指控，企图抹黑莫斯科。
