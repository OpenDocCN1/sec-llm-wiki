# 注意：立即更新Google Chrome

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247489876&idx=4&sn=efdd90fba7ed94a761bcc13f19cd8c92&chksm=9bae501facd9d909230fd6d01456e1ea44ac69acc70b872af89fe9c05fe08ad68fb68e476e6c&scene=126&sessionid=1681670097#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247489876&idx=4&sn=efdd90fba7ed94a761bcc13f19cd8c92&chksm=9bae501facd9d909230fd6d01456e1ea44ac69acc70b872af89fe9c05fe08ad68fb68e476e6c&scene=126&sessionid=1681670097#rd)

黑客正在积极利用Google Chrome浏览器中的危险漏洞。使用Chrome 88.0.4324.150；Google纠正了该缺陷。

![](../Images/301719dca4a1d68f42277fb95fe2aa9e.png)

研究人员在Google Chrome中发现了一个严重漏洞CVE-2021-21148。我们建议尽快解决此问题，因为网络犯罪分子已经在利用它。主要台式机操作系统（Windows，MacOS和Linux）的浏览器版本容易受到攻击。查看正在发生的事情以及如何更新浏览器。

  

CVE-2021-21148的危险

该漏洞使网络罪犯可以执行堆溢出攻击-这种操作可能导致在受害者的设备上远程执行代码。利用此漏洞就像创建一个恶意网站并吸引受害者一样简单，但结果可能是毁灭性的：他们可以完全控制受影响的系统。

  

在这种情况下，易受攻击的组件是浏览器中内置的JavaScript V8引擎。Google于1月24日从安全研究人员Mattias Buelens处收到了有关此漏洞的信息，该公司于2月4日发布了包含此修复程序的补丁程序。Google认可了有关身份不明的黑客积极探索CVE-2021-21148的报道。

  

根据ZDnet的一篇文章，该漏洞可能与网络安全社区中朝鲜黑客最近的攻击有关。至少，攻击方式与CVE-2021-21148的使用有着惊人的相似之处。此外，该漏洞的发现日期与发布针对专家的攻击的日期非常接近。但是，我们仍然没有直接证实这一理论。

  

像往常一样，谷歌一直等到大多数活跃的Chrome用户更新其浏览器以披露更多技术细节。这是可以理解的。不负责任地披露漏洞可能导致攻击迅速增加。

  

**如何保持安全**

*   立即在您的计算机上更新Google Chrome。为此，请单击浏览器窗口右上角带有三个点的按钮，然后单击设置→关于Chrome。打开此页面后，将更新您的浏览器。
    
*   如果提示您更改生效，请重新启动浏览器。立即执行此操作，不必担心丢失打开的选项卡；当前版本的Chrome会在重新启动后自动恢复标签页，或者在意外关闭的情况下提供恢复标签页的功能。
    
*   如果“关于Chrome”页面指示您已经在使用88.0.4324.150版本，则说明您的浏览器是最新的，并且您不再需要担心CVE-2021-21148。
