# \[CVE-2021-22880\] Active Record PostgreSQL适配器中可能存在的DoS漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247489876&idx=1&sn=8d036b0c25fe6fdd4a9940b52383fc4d&chksm=9bae501facd9d9099a602ec6e9dd3bc78f6361ae5dae62415b036e0a6750761d3c0da6c0f79c&scene=126&sessionid=1681670097#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247489876&idx=1&sn=8d036b0c25fe6fdd4a9940b52383fc4d&chksm=9bae501facd9d9099a602ec6e9dd3bc78f6361ae5dae62415b036e0a6750761d3c0da6c0f79c&scene=126&sessionid=1681670097#rd)

## 影响

精心设计的输入可能会导致Active Record中PostgreSQL适配器的“金钱”类型的输入验证在正则表达式上花费过多时间，从而可能导致DoS攻击。

这只会影响使用PostgreSQL的Rails应用程序以及接受用户输入的资金类型列。

## 发布

固定版本可在正常位置使用。

```
module ActiveRecord  module ConnectionAdapters    module PostgreSQL      module OID # :nodoc:        class Money < Type::Decimal # :nodoc:          def cast_value(value)            return value unless ::String === value
            value = value.sub(/^\((.+)\)$/, '-\1') # (4)            case value            when /^-?\D*+[\d,]+\.\d{2}$/  # (1)              value.gsub!(/[^-\d.]/, "")            when /^-?\D*+[\d.]+,\d{2}$/  # (2)              value.gsub!(/[^-\d,]/, "").sub!(/,/, ".")            end
            super(value)          end        end      end    end  endend
```
