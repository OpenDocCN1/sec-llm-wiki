# CVE-2021-24074 Windows TCP / IP远程执行代码漏洞

Microsoft 发布 了有关Windows TCP / IP远程执行代码漏洞的风险通知。漏洞编号为CVE-2021-24074。漏洞CVSS：3.0的得分是9.8 / 8.5。Windows TCP / IP协议中存在一个远程执行代码漏洞。攻击者可以通过精心构建的IP数据包直接在远程目标主机上执行任意代码。

#### 漏洞详情

> *本月的发行版中有两个TCP / IP错误，但我选择在CVE-2021-24094上强调此漏洞，  因为此错误影响IPv4，而另一个影响IPv6。这两个错误都可能允许在受影响的系统上远程执行未经身份验证的代码。对于CVE-2021-24074，该漏洞位于IPv4源路由中，默认情况下应禁用此功能。您还可以在防火墙或其他外围设备处阻止源路由。IPv6错误涉及数据包分段，其中大量分段可能导致代码执行。*

#### 受影响的版本

*   Microsoft Windows 7/8/10 / Server 2008 / Server 2012 / Server 2016 / Server 2019 /服务器20H2
    

#### 修复建议

我们建议用户及时将Windows升级到最新版本。

解决方法的影响

IPv4源路由被认为是不安全的，并且在Windows中默认为阻止状态；但是，系统将处理该请求并返回拒绝该请求的ICMP消息。解决方法将导致系统完全丢弃这些请求，而不进行任何处理。
