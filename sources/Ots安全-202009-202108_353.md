# 微软发布通报0Day和55个Windows错误的补丁

微软周二发布了针对56个漏洞的修复程序，其中包括一个众所周知的可以在野外积极利用的严重漏洞。  

总共列出11个为“严重”，列出43个为“严重”，列出两个为“严重”，其中有6个以前披露的漏洞。

更新包括.NET Framework，Azure IoT，Microsoft Dynamics，Microsoft Edge for Android，Microsoft Exchange Server，Microsoft Office，Microsoft Windows Codecs库，Skype for Business，Visual Studio，Windows Defender以及其他核心组件，例如内核，TCP / IP，后台打印程序和远程过程调用（RPC）。

### Windows Win32k特权升级漏洞

最严重的漏洞是Windows Win32k特权升级漏洞（CVE-2021-1732，CVSS评分7.8），该漏洞使有权访问目标系统的攻击者能够以更高的权限运行恶意代码。微软对DBAPPSecurity的JinQuan，MaDongZe，TuXiaoYi和LiHao的发现和报告表示感谢。

在另一篇技术文章中，研究人员表示，利用名为该漏洞的零日漏洞利用程序，是由名为Bitter APT的威胁行为者对位于中国的受害者进行的“非常有限的攻击”中检测到的。攻击于2020年12月被发现。

DBAPPSecurity研究人员说： “此零日漏洞是由win32k回调引起的一个新漏洞，它可以用来逃避最新版本Windows 10版本上的Microsoft \[Internet Explorer\]浏览器或Adobe Reader的沙箱，” 。“漏洞是高质量的，漏洞利用是复杂的。”

值得注意的是，作为2月份补丁的一部分，Adobe解决了Windows和macOS的Adobe Acrobat和Reader（CVE-2021-21017）中的严重缓冲区溢出漏洞，该漏洞可能导致在当前环境下任意执行代码用户。

该公司还警告说，针对Windows上针对Adobe Reader用户的有限攻击中的野外错误，请积极尝试利用，以反映DBAPPSecurity的上述发现。

尽管Microsoft和Adobe都未提供其他详细信息，但同时修补这两个漏洞增加了将漏洞链接在一起以进行野外攻击的可能性。

### Netlogon强制执行模式生效  

Microsoft的补丁程序星期二更新还解决了Windows DNS服务器（CVE-2021-24078）、. NET Core和Visual Studio（CVE-2021-26701），Microsoft Windows编解码器库（CVE- 2021-24081）和传真服务（CVE-2021-1722和CVE-2021-24077）。

Windows DNS服务器组件中的RCE的严重等级为9.8，使其成为一个严重漏洞，如果不进行修补，可能会允许未经授权的对手执行任意代码，并可能将合法流量重定向到恶意服务器。

微软还计划在本月推动针对Zerologon漏洞（CVE-2020-1472）的第二轮修复，该漏洞最初于2020年8月得到解决，随后于2020年9月发布了针对未打补丁系统的主动利用漏洞的报告。

从2月9日开始，默认情况下将启用域控制器“强制模式” ，从而阻止“来自不兼容设备的易受攻击的\[Netlogon\]连接”。

此外，星期二补丁更新纠正了Android Edge浏览器（CVE-2021-24100）中的一个错误，该错误可能会泄露用户的个人身份信息和付款信息。

### Windows TCP / IP堆栈中的RCE缺陷

最后，这家Windows制造商发布了一系列影响其TCP / IP实施的修复程序，其中包括两个RCE缺陷（CVE-2021-24074和CVE-2021-24094）和一个拒绝服务漏洞（CVE-2021-24086）。它说可以被DoS攻击利用。

微软在一份通报中说： “针对这些CVE的DoS攻击将使远程攻击者能够引起停止错误。” “在任何以最小的网络流量直接暴露给互联网的Windows系统上，客户都可能会收到蓝屏。因此，我们建议客户在本月内迅速采取行动以应用Windows安全更新。”

但是，这家技术巨头指出，两个TCP / IP RCE漏洞的复杂性将使其难以开发功能性攻击。但它希望攻击者更轻松地创建DoS攻击，将安全漏洞变成野外利用的理想人选。

要安装最新的安全更新，Windows用户可以转到“开始”>“设置”>“更新和安全性”>“ Windows Update”，或选择“检查Windows更新”。
