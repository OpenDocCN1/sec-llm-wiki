# 安全通报2021-02-02-2-RsaPad\_PSS中的wolfSSL堆缓冲区溢出（CVE-2020-36177）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247489829&idx=2&sn=b1f239cb12858fb28293c7cfaddff150&chksm=9bae506eacd9d9781620af38abaf89f06df07e99cdb6da62604b1c29db79603162c8b037e9e4&scene=126&sessionid=1681670097#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247489829&idx=2&sn=b1f239cb12858fb28293c7cfaddff150&chksm=9bae506eacd9d9781620af38abaf89f06df07e99cdb6da62604b1c29db79603162c8b037e9e4&scene=126&sessionid=1681670097#rd)

*它仍在进行中，关于它的信息还很少（甚至wolfSSL本身是空白的），但是根据9.8的很高的CVSS分数（最严重的10分），很可能该问题具有RCE潜力。*

在4.6.0之前的wolfSSL版本中，存在严重的安全问题。自2020年8月27日起，此wolfSSL库作为`libwolfssl24`软件包在OpenWrt中提供，并默认在快照中提供 1个。它不是默认情况下，最新的稳定版本的OpenWrt 19.07发货。

完整的建议可以在专用的Wiki页面上找到 3。

### 软件包升级到固定`libwolfssl24`版本4.6.0

1.  您需要`libwolfssl24`使用以下命令更新正在使用的受影响的软件包。
    
    `opkg update; opkg upgrade libwolfssl24`
    
2.  然后确认您正在运行固定版本。
    
    `opkg list-installed libwolfssl24`
    
    上面的命令应该输出以下内容，以实现稳定的OpenWrt 19.07版本和快照构建：
    
    `libwolfssl24 - 4.6.0-stable-1`
