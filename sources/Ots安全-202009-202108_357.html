比特币跌破30,000美元触发了altcoins的抛售，而逢低买入的交易者可能没有足够的动力来引发救济性反弹。


在过去的一年中，上市公司已经购买了大约85,000个比特币（BTC），机构投资者已经向Grayscale Investments注入资金，这表明机构采用率的提高是最近比特币上涨的主要原因之一。


但是，目前看来机构投资者不太可能将价格追涨。如果新的资金流入停滞不前或急剧减少，则可能导致比特币价格回落。如果发生这种情况，短期交易者和动量参与者可能会预定利润并触发更深的修正。 

每日加密货币市场表现。资料来源：Coin360

进行修正将是一个健康的信号，因为它将震撼投机者，并且只有长期HODLers会留在市场上。随着价格下跌，更多的机构投资者可能会开始以较低水平进行购买。从长期来看，将比特币的所有权从投机者转移到长期投资者将是积极的。


如果短期内比特币进入更深层次的修正，那么多种山寨币可能会效仿。

让我们研究十大加密货币的图表，以确定买家可能介入的支持水平。


BTC /美元

1月25日，比特币突破了20天的指数移动平均线（33,254美元），但交易员利用这一涨幅进行卖出，从而将价格推低至1月26日的30,450美元支撑位。多头买入了这一跌势，但未能推动价格高于20天均线。

BTC / USDT日线图。资料来源：TradingView

BTC / USD货币对今天恢复了修正，这表明多头无法吸收供应。下滑的20天EMA和负区域的相对强度指数（RSI）表明空头处于控制之中。


如果空头能够下跌并将价格维持在50天的简单移动平均线（29,407美元）以下，则该货币对将完成看跌的下降三角形形态。这可能导致斐波那契回撤水平跌至50％（25,897.42美元），然后回落至61.8％回撤水平（22,106.73美元）。


如果价格从当前水平反弹并突破下降趋势线，这种看跌观点将失效。如果发生这种情况，货币对可能反弹至40,000美元，然后升至41,959.63美元。


ETH /美元

1月25日，以太坊（ETH）无法维持在1,400美元上方，这表明空头们正在以更高的水平获得利润。多头于1月26日再次尝试重组，但山寨币今天下跌，这表明交易商可能正在关闭其多头头寸。

ETH / USDT每日图表。资料来源：TradingView

RSI的负背离表明势头已经减弱。如果空头可以将价格拉低至20天均线（1,211美元）以下，则可能会重新测试上升趋势线。这是要提防的重要支撑，因为跌破该水平将表明可能的趋势变化。下行的下一个支撑位是50日均线（928美元）。


另一方面，如果多头能够维持当前的反弹，则表明多头正在逢低买入。如果多头可以将以太坊价格推高至1,400美元以上至1,473.096美元的阻力位，则上升趋势可能会继续，下一个目标目标为1,675美元。


DOT/美元

Polkadot（DOT）从1月25日的上方阻力位下跌至今天的14.7259美元支撑位。多头可能会积极捍卫这一支持。

14.7259美元的强劲反弹将表明交易商正在逢低吸纳。这可能会使DOT / USD货币对继续维持几天在14.7259美元和19.40美元之间波动。逐渐上升的20天EMA和RSI在积极区域内表明多头具有较小优势。

相反，如果空头使价格跌破14.7259美元，则跌幅可能扩大至50％斐波纳契回撤位（13.2821美元），然后扩大至61.8％回撤位（11.8383美元）。更深的修正将表明上升趋势已经失去动力，这可能导致几天的盘整，然后下一个趋势开始。

XRP / USD

在过去几天捍卫20天EMA（0.28美元）之后，空头目前正试图将XRP降至0.245美元支撑之下。下降的移动均线和负值区域的RSI表明阻力最小的路径是下行。

跌破0.245美元将增加下跌至下一个关键支撑位0.17351美元的可能性。如果此支撑也破裂，则XRP / USD对可能会继续下降趋势，下一个可能的止损位于0.10美元。

相反，如果该货币对从当前水平反弹，则多头将再次试图将价格推高至下降趋势线以上。如果他们能够做到这一点，那么该货币对可能会在几天内维持在0.245美元至0.3855美元之间的区间波动。

ADA /美元

卡尔达诺（ADA）在1月22日的强劲反弹在1月24日收于0.3685714美元，这表明交易员利用0.34美元上方的涨势来平仓其多头头寸。


多头目前正在捍卫上升通道的支撑线。如果从该水平强劲反弹，则表明多头正在逢低买入。多头随后将试图将价格推高至下降趋势线上方，这将是回调可能结束的第一个迹象。

如果价格维持在下降趋势线上方，则可能会重新测试0.3971995美元。相反，如果空头将价格跌至支撑线以下，则表明可能出现趋势变化，从而可能跌至50日均线（0.23美元）。

LINK /美元

Chainlink（LINK）目前正处于上升趋势中。下行的第一个关键支撑是20日均线（20.15美元），接近突破水平20.1111美元。

该支撑位强劲反弹，表明多头正在积极地在较低水平上积累。然后，他们将尝试通过将价格推高至近期历史高点25.7824美元来恢复上升趋势。

与此假设相反，如果空头将价格推低至20天均线下方，则LINK / USD对可能跌至17.7777美元。跌破该支撑位将表明趋势发生变化，并可能将价格拉低至50天均线（15.58美元）。

LTC / USD

莱特币（LTC）从1月25日的20天均线（139美元）下跌，这表明空头在救济集会上卖出。多头在1月26日将价格跌至50日均线（128美元），但未能将价格推高至20日均线上方。

新的卖盘将LTC / USD拖至今天的50日均线下方，空头现在将试图突破120美元的支撑位。如果他们能够做到这一点，则该货币对将完成看跌的头肩形态，可能会跌至100美元，然后跌至70美元。

向下倾斜的20天EMA和RSI在负区域表明，阻力最小的路径是下行。如果该货币对从120美元的支撑位反弹并升至148美元以上，这种负面看法将被否定。

BCH / USD

1月25日，比特币现金（BCH）未能维持在20天均线（443美元）以上，这可能吸引了空头卖空，这些空头今天将价格推低至50天均线（389美元）以下。

下滑的20天EMA和RSI在负区域表明，阻力最小的路径是下行。跌破370美元支撑位可能会将价格拉低至353美元，如果该水平也能突破，下一止损可能是275美元。

如果BCH / USD货币对从当前水平或353美元支撑位反弹并升至450美元以上，这种看跌观点将无效。

BNB /美元

Binance Coin（BNB）未能在1月25日维持在43.0992美元上方，表明缺乏较高水平的买家。山寨币在1月25日至26日形成了十字星烛台图案，表明多头和空头之间的犹豫不决。

卖方试图通过将价格下沉到上升的扩大楔形图案的支撑线以下来获得优势。如果它们成功，那么BNB / USD可能跌至35.69美元，然后跌至30美元。

与这个假设相反，如果多头能够捍卫支撑线，它将表明需求处于较低水平。多头将再次试图将价格推高至43.0992美元上方。如果他们能够做到这一点，则该货币对可能升至47.2187美元。

平淡的20天EMA（40.99美元）和RSI接近中点并没有给多头或空头带来明显的优势。

XLM / USD

多头的失败未能将Stellar Lumens（XLM）推高至0.282美元上方，这可能已吸引了短期交易员的获利，这些交易员在1月22日购买了该下跌幅度。altcoin下跌并跌破20天均线（0.261美元） 1月25日。

当价格未能在20天均线上方建立动能时，表明情绪发生了变化。当前的下跌表明交易者利用最近的救济集会减轻了头寸。

XLM / USD货币对现在可以跌至50日均线（0.214美元），这可能会吸引一些逢低买入。但是，如果该货币对未能以强劲的力量从支撑位反弹，则修正可能会加深，并可能跌至0.19美元然后跌至0.15美元。
