# NSA发布过时加密工具指南

在国家安全局已经发布了关于如何指导国防部，其他联邦机构和支持他们应该替换过时的加密协议，可以使网络入侵的承包商。

  

美国国家安全局（NSA）建议五角大楼的系统管理员，负责国家安全事务的美国政府其他机构以及向机构提供技术的私人公司和第三方，以取代过时的传输层安全和安全套接字层协议加密服务器之间传输的网络流量。国家安全局建议其他组织也遵守该准则。

该机构指出，所有联邦机构都应优先考虑替换过时的TLS协议，因为它们可以使未经授权的网络访问民族国家行为者和其他对手，然后他们可以修改流量以执行中间人攻击。

该指南建议组织仅使用协议的TLS 1.2或TLS 1.3版本。该机构还表示，组织应避免使用过时的Secure Sockets Layer 2.0，SSL 3.0，TLS 1.0和TLS 1.1版本。

该机构指出：“该指南提供了检测策略，可以帮助网络安全分析人员确定是否继续使用过时的TLS协议版本，密码套件和密钥交换。” “这种补救对于减少计算机系统和网络攻击面以及防止未经授权的私人数据访问至关重要。”

### NSA建议

NSA在GitHub上发布了免费的检测工具，用于识别其系统中过时的TLS版本。

国家安全局说，联邦机构应将旧协议更新为最新版本，并确保其配置符合国家安全系统政府间委员会组织以及美国国家标准与技术研究所规定的加密标准。

美国国家安全局（NSA）指出，对TLS使用弱，已损坏或已吊销的证书可能会导致中间人攻击。该机构补充说，联邦机构必须确保TLS证书是由合法的证书颁发机构颁发的，能够准确代表服务器并在其到期之前被替换。

NSA还表示，运行TLS工具过期版本的组织应禁用这些工具，直到将它们重新配置为最新版本为止。

### TLS相关攻击

近年来，威胁行动者已经开发出变通办法，以绕过TLS加密或使协议武器化。

2015年，微软透露，黑客正在出售伪造的TLS证书，以诱骗Windows用户运行恶意软件（请参阅：*Microsoft黑名单伪造证书https://www.bankinfosecurity.com/microsoft-blacklists-fake-certificate-a-8021*）。

2020年，独立安全研究人员发现攻击者可以使用伪造的TLS证书来欺骗合法网站。研究人员接着继续欺骗了Microsoft拥有的GitHub网页（请参阅：*Windows漏洞：研究人员展示漏洞https://www.databreachtoday.com/windows-vulnerability-researchers-demonstrate-exploits-a-13614*）。

5月，美国网络安全和基础设施安全局警告说，北朝鲜高级持续威胁小组正在使用伪造的TLS协议来认证和加密其活动，以使其免受安全工具的影响（请参阅：*立即使用新恶意软件进行WannaCry背后的小组https://www.databreachtoday.com/group-behind-wannacry-now-using-new-malware-a-14279*）。
