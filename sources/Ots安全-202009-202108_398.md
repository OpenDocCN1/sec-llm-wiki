# Google Docs Bug让黑客劫持Screenshots

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247489530&idx=3&sn=8411204b4074ab5afc8406495dc78bf8&chksm=9bae5eb1acd9d7a7a34b8f17e1a5ded2aa3de9e66c84c869f2509ceeac1bbac104390ad47d82&scene=126&sessionid=1681670107#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247489530&idx=3&sn=8411204b4074ab5afc8406495dc78bf8&chksm=9bae5eb1acd9d7a7a34b8f17e1a5ded2aa3de9e66c84c869f2509ceeac1bbac104390ad47d82&scene=126&sessionid=1681670107#rd)

Google提到其反馈工具中最近发生了一个漏洞，并且Google确认存在一个严重漏洞，该漏洞不断破坏用户的所有敏感文件。

  

Google反馈工具是各种服务的一部分，威胁行为者可能会利用它来将所有敏感的Google Docs文档的屏幕快照插入到处置不当的网站中，从而捕获它们的屏幕快照。

  

除此之外，Google在所有产品中都有一个名为“发送反馈”的功能。此工具功能可帮助Google在遇到任何问题时从每个用户那里获取反馈。此外，此功能还提供了添加屏幕快照以及用户所面临问题的简短摘要的选择。

  

  

此反馈功能位于Google的主域（“ www.google.com”）中，并通过添加iframe元素（通过PostMessage从“ feedback.googleusercontent.com”填充弹出窗口的内容）将其组合到其他域中。

## 寻找XSS

用户熟悉此功能后，便会在沙盒域feedback.googleusercontent.com中找到XSS。但是，用户可以使用XSS并劫持像素的RGB值。之后，他们可以渲染图像并捕获屏幕截图。

名为Sreeram的用户之一试图在其中找到XSS，因为它是一个沙箱域，但他未能找到XSS。一周后，他在Twitter提要中注意到了“ filedescriptor”的视频。
