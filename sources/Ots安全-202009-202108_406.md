# 在美国之后，越南政府遭受供应链攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247489467&idx=2&sn=34111436e9f5a9725880c6bfcdeb0c15&chksm=9bae5ef0acd9d7e6e89e0a46281eb7c4ed0a69d64b552a9c8944efdebc07d3d7c5252b8ed882&scene=126&sessionid=1681670107#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247489467&idx=2&sn=34111436e9f5a9725880c6bfcdeb0c15&chksm=9bae5ef0acd9d7e6e89e0a46281eb7c4ed0a69d64b552a9c8944efdebc07d3d7c5252b8ed882&scene=126&sessionid=1681670107#rd)

ESET研究人员通过利用数字签名工具包，发现了针对越南政府证书颁发机构（VGCA）的供应链攻击。

![](../Images/79797aa43b6ada32f16967292b552b99.png)

安全研究人员确定了针对越南政府证书颁发机构（VGCA）的供应链攻击，该攻击破坏了该机构的数字签名工具包。根据安全公司ESET的调查，网络犯罪分子利用VGCA网站*“ ca.gov.vn”*上托管的软件安装程序注入了称为PhantomNet或Smanager的间谍软件。

越南政府已授权使用数字签名和数字签名的文档。VGCA是授权的证书提供者。它还开发和分发数字签名工具包，并提供用于签名文档的加密证书。

### **“ SignSight”攻击**

研究人员将网络操作命名为SignSight攻击，该攻击发生在2020年7月23日至8月16日**。ESET**研究人员表示，网络犯罪分子修改了两个软件安装程序，即“ **gca01-client-v2-x32-8.3.msi** ”和“ **gca01-client- v2-x64-8.3.msi** ”（适用于32位和64位Windows系统），可以在代理商的网站上下载。攻击者操纵了该软件，并添加了后门以损害合法应用程序的用户。

ESET研究人员说：“我们能够确认这些安装程序是通过HTTPS协议从ca.gov.vn下载的，因此我们认为这不太可能是中间人攻击。”

*将用户重定向到恶意安装程序的URL包括：*

**https://ca.gov \[。\] vn / documents / 20182/6768590 / gca01-client-v2-x64-8.3.msi**

**https://ca.gov \[。\] vn / documents / 20182/6768590 / gca01-client-v2-x32-8.3.msi**

### **PhantomNet供应链攻击**

如果下载并安装在目标系统上的官方网站上托管的受感染软件，则用户可能会受到PhantomNet间谍软件的影响。安装完成后，更改后的软件将隐藏其恶意软件并运行PhantomNet后门，该后门将用户欺骗为名为“ eToken.exe”的常规文件。

### **攻击流程  **

![](../Images/1a1de8a1c77733794dd88efd711b3fc5.png)

“我们认为，截至2020年8月，该网站尚未提供受感染的软件安装程序，并且ESET遥测数据并不表明受感染的安装程序已分发到其他任何地方。ESET研究人员补充说，越南政府证书颁发机构确认，在我们通知之前，他们已经意识到了这次攻击，并通知了下载木马软件的用户。
