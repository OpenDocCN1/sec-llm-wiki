# 报告：黑客破坏了美国核安全系统

消息人士告诉波利蒂科，负责维持核储存的两个机构，能源部和国家核安全局的官员说，黑客通过大规模的间谍活动访问了他们的网络。  

  

美国能源部和国家核安全局官员说，可能有多达六个联邦机构受到损害。

  

该报告援引直接熟悉此事的官员的话说，在美国能源部发言人洛基·坎皮奥内（Rocky Campione）通报情况后，有关官员正在努力就此违规行为作出适当的通知。

  

消息人士说，“联邦能源监管委员会（FERC），新墨西哥州和华盛顿州桑迪亚和洛斯阿拉莫斯国家实验室，美国国家安全局（NNSA）的安全运输办公室以及能源部里奇兰地区办公室的网络中存在可疑活动。”

  

报告称，尽管没有公布细节，但在FERC，存在“高度恶意活动”。

  

网络安全和基础设施安全局（Cybersecurity and Infrastructure Security Agency）的董事克里斯·克雷布斯（Chris Krebs）最近因声称2020年选举是有史以来最安全而被特朗普总统解雇，“本周向FERC表示CISA不堪重负，可能无法分配必要的资源回应。”报告说。

  

调查人员的首要任务是确定是否有任何信息被盗。

  

“对DOE的攻击是迄今为止最明显的迹象，表明黑客能够访问属于美国国家安全企业核心部分的网络。据信，黑客通过损害软件公司的权限来访问联邦机构的网络。SolarWinds向数百名政府和私营部门客户出售IT管理产品。”

  

CISA，联邦调查局和国家情报局局长办公室在一份联合声明中说：“这是一个发展中的局面，尽管我们继续努力了解这项运动的全部内容，但我们知道这种妥协影响了内部的网络。联邦政府。”

  

DailyMail.com报道，美国估计有5800枚核弹头，其中包括导弹和炸弹，可以从潜艇，飞机和陆基导弹上发射。

  

但是，实际的数字和状态不是公开的。

  

洛斯阿拉莫斯国家实验室的工作是制造新武器。

  

DailMail.com报道称，瓦尔迪米尔·普京（Valdimir Putin）的俄罗斯政府否认幕后黑手“，但是其他专家对此轻描淡写，他们说，黑客的规模和精确度直接指向克里姆林宫。”

  

报告说，美国国家安全顾问罗伯特·奥布赖恩（Robert O'Brien）缩短了一周的中东和欧洲之行，以应对这一后果。
