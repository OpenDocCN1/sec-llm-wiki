# 苹果制造商富士康遭到勒索软件攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247489309&idx=3&sn=b4de5248407548edf0d20684880869ca&chksm=9bae5e56acd9d7406d6f3b6d2e1d69f16954a5d85258dcff15ade0dcdc0ff0496ea730e5fb17&scene=126&sessionid=1681670117#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247489309&idx=3&sn=b4de5248407548edf0d20684880869ca&chksm=9bae5e56acd9d7406d6f3b6d2e1d69f16954a5d85258dcff15ade0dcdc0ff0496ea730e5fb17&scene=126&sessionid=1681670117#rd)

富士康科技集团周二证实，11月的网络攻击使其在美国的部分业务脱机。据报道，此事件是由一个网络犯罪分子发起的勒索软件攻击，试图从全球制造大国勒索3400万美元。

  

富士康周二在一份声明中说：“我们可以确定，支持我们在美洲某些业务的美国信息系统是11月29日网络安全攻击的重点。”

  

该公司在一份新闻声明中说：“受此事件影响的系统正在接受彻底检查，并将逐步投入使用。” 根据BleepingComputer的报告，该攻击被认为是由DoppelPaymer网络犯罪分子进行的。命中的是富士康在墨西哥奇瓦瓦州的制造工厂。据报道，犯罪分子对1,200台服务器进行了加密，下载了100GB的数据，并删除了20至30TB的备份。

  

攻击者似乎已公开发布了富士康的机密商业文件，试图验证数据系统是否受到破坏。富士康没有通过Threatpost确认BleepingComputer公开并报告的文件的合法性。

  

Nozomi Networks的联合创始人安德里亚·卡卡诺（Andrea Carcano）在一份准备好的声明中指出，DopplePaymer犯罪集团的勒索软件具有相同的名字，该组织去年成为头条新闻，攻击了许多大型组织。

  

Carcano还指出，勒索软件犯罪分子现在普遍将加密，删除和窃取数据作为犯罪活动的一部分。希望是迫使受害者支付赎金，以防止公众暴露数据并避免业务系统崩溃。

  

富士康表示，富士康在墨西哥奇瓦瓦州的制造工厂被用来将电子产品组装并运送到美洲。在撰写本文时，富士康墨西哥工厂网站（https：// fii-na \[。\] com.mx/）似乎已关闭。

  

Gurucul的首席执行官Saryu Nayyar在一份准备好的声明中强调，这些攻击的“新标准模型”是“闯入，窃取数据以勒索和部署勒索软件”。

  

美国网络紧急响应小组长期以来一直警告勒索软件受害者不要付款。“支付赎金并不能保证加密文件将被释放；它仅保证恶意行为者获得受害者的钱，在某些情况下还获得他们的银行信息。” 它在过去的公告中写道：“此外，解密文件并不意味着恶意软件感染本身已被删除。”
