# Nitro大规模数据泄露影响了Microsoft，Google和Apple

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247488968&idx=1&sn=38425c0cb708d9a6add3eb9f9216455d&chksm=9bae5c83acd9d5954fdc6ebca240f930c2c824fc6c5d0fa6171c843371328d23245607d54286&scene=126&sessionid=1681670127#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247488968&idx=1&sn=38425c0cb708d9a6add3eb9f9216455d&chksm=9bae5c83acd9d5954fdc6ebca240f930c2c824fc6c5d0fa6171c843371328d23245607d54286&scene=126&sessionid=1681670127#rd)

Nitro PDF服务遭受了大数据泄露。数据丢失已影响到许多大型技术组织，包括Google，Apple，Microsoft，Chase和Citibank。

![](../Images/4352f51eec208d265312ba66655e8fbd.png)

Nitro是一项可用于创建，编辑和签名PDF和数字文档的应用程序，据说可以被超过1万名商业客户和180万许可用户使用。2020年10月21日， Nitro Software向澳大利亚证券交易所发布了一份咨询报告，指出它们受到“低影响安全事件”的影响，但没有影响任何客户数据。

  

网络安全情报公司Cyble透露，威胁者正在出售他们声称从Nitro Software的云服务中窃取的用户和文档数据库以及1TB文档。Cyble指出，“ user\_credential”数据库表包含7,000万条用户记录，其中包含电子邮件地址，全名，bcrypt哈希密码，标题，公司名称，IP地址以及其他与系统相关的数据。Cyble已将数据添加到其AmIBreached.com服务中。

  

关于事件，Nitro向Digital Journal发送了一条消息，其中指出：“ Nitro继续调查孤立的安全事件，涉及未经授权的第三方有限地访问Nitro数据库。该数据库不包含用户或客户文档，托管在单独的数据库中。

  

当前没有确定的证据表明与客户有关的任何敏感或财务数据已受到破坏。对Nitro Pro或Nitro Analytics没有影响。”

  

使用Nitro流行的免费文档转换服务不需要用户创建和记帐或成为Nitro客户。要求用户提供电子邮件地址，并且经常输入常见的电子邮件域。

  

为了获得真知灼见，Digital Journal赶上了CloudSphere产品副总裁Pravin Rasiah。

根据Rasiah的说法，该事件还应归咎于企业世界：“受委托提供客户信息的公司有责任确保其数据保持安全并不受网络犯罪分子的控制，后者可以利用这些公开的信息发起有针对性的攻击，并获得对其他用户帐户和资源的访问权限。”

  

专家进一步解释说：“在没有意识或未采取积极行动来维护云安全策略的情况下，恶意行为者更有可能将目标锁定并利用该系统来破坏敏感信息。对云环境的完全可见性以及适当的云治理对于防止数据至关重要违反和保护客户数据。”

  

关于要做的事情，分析师补充说：“企业应该投资一套全面的安全工具，这些工具可以实时监视和控制安全状态，最大程度地减少潜在的攻击面，并在云环境中提供全面的可观察性。”
