概要

Google Chrome 83.0.4103.116（稳定）（64位）和86.0.4198.0（开发人员内部版本）（64位）的WebGL功能中存在一个信息泄露漏洞。特制的JavaScript可能会导致越界读取。受害者必须访问特制的恶意网页才能触发此漏洞。


测试版本

  • 谷歌浏览器83.0.4103.116（稳定）（64位）

  • 谷歌浏览器86.0.4198.0（开发者内部版本）（64位）


产品网址

https://www.google.com/chrome/

CWE-125-越界读取


细节

谷歌浏览器是最受欢迎和功能最丰富的Web浏览器之一，并支持最新的技术和扩展，其中之一就是WebGL。


此漏洞位于ANGLE中，它是Chrome浏览器和其他项目在Windows上使用的OpenGL和Direct3D之间的兼容层。


执行提供的PoC时，Chromium浏览器从IndexDataManager的ConvertIndexArray内部崩溃。此功能的代码片段如下：

  void ConvertIndexArray(const void *input,                         gl::DrawElementsType sourceType,                         void *output,                         gl::DrawElementsType destinationType,                         GLsizei count,                         bool usePrimitiveRestartFixedIndex)  {      const InputT *in = static_cast<const InputT *>(input);      DestT *out       = static_cast<DestT *>(output);      if (usePrimitiveRestartFixedIndex)      {          InputT srcRestartIndex = static_cast<InputT>(gl::GetPrimitiveRestartIndex(sourceType));          DestT destRestartIndex = static_cast<DestT>(gl::GetPrimitiveRestartIndex(destinationType));          for (GLsizei i = 0; i < count; i++)          {              out[i] = (in[i] == srcRestartIndex ? destRestartIndex : static_cast<DestT>(in[i]));          }      }      else      {          for (GLsizei i = 0; i < count; i++)          {              out[i] = static_cast<DestT>(in[i]);          }      }  }

由于错误的内存地址，函数在第17行崩溃，因为为变量提供的值in直接来自function void ext.drawElementsInstancedANGLE(mode, count, type, offset, primcount);。此时，可以直接从JavaScript中完全控制两个值。第in8行的值offset在JavaScript中count，第15行的值与countJavaScript中的变量相对应。


提供了一种用于值offset在JS变量是在下述范围00000000到7fffffff。


这些值的未经检查的边界可能导致超出范围的读取，并且如果可以自由返回JavaScript值，则此漏洞可能变成信息泄漏，被滥用来绕过缓解措施。
