hydra

官网：http://www.thc.org/thc-hydra，

Hydra是并行的登录破解程序，它支持多种协议进行攻击。它非常快速且灵活，并且易于添加新模块。该工具使研究人员和安全顾问可以显示获得未经授权的远程访问系统的容易程度。

支持：Cisco AAA，Cisco auth，Cisco enable，CVS，FTP，HTTP（S）-FORM-GET，HTTP（S）-FORM-POST，HTTP（S）-GET，HTTP（S）-HEAD，HTTP-代理，ICQ，IMAP，IRC，LDAP，MS-SQL，MySQL，NNTP，Oracle Listener，Oracle SID，PC-Anywhere，PC-NFS，POP3，PostgreSQL，RDP，Rexec，Rlogin，Rsh，SIP，SMB（NT） ，SMTP，SMTP枚举，SNMP v1 + v2 + v3，SOCKS5，SSH（v1和v2），SSHKEY，Subversion，Teamspeak（TS2），Telnet，VMware-Auth，VNC,XMPP等多种服务。

参数：

选项：
  -R恢复先前的中止/崩溃的会话
  -S执行SSL连接
  -s PORT服务在不同的默认端口上，在此处定义
  -l LOGIN或-L FILE登录名，或从FILE加载多个登录名
  -p PASS或-P FILE尝试输入密码PASS，或从FILE
  -x MIN加载多个密码：MAX：CHARSET密码蛮力生成，键入“ -x -h”以获取帮助
  -e nsr尝试使用“ n”空密码，“ s”作为通过登录名和/或“ r”反向登录
  -u在用户周围循环，而不是密码（有效！用-x表示）
  -C FILE冒号分隔“ login：pass”格式，而不是-L / -P选项
  -M FILE被并行攻击的服务器列表，每行一个条目
  -o FILE将找到的登录名/密码对写入FILE而不是stdout
  -f / -F在登录/找到通过对（-M：-f每个主机，-F全局）
  -t TASKS运行TASKS并行连接数（每个主机，默认值：16）
  -w / -W TIME等待响应时间（32s）/连接之间每个线程
  -4 / -6首选IPv4（默认）或IPv6地址
  -v / -V / -d详细模式/每次尝试显示登录名+密码/调试模式
  -U服务模块用法详细信息
  服务器目标服务器（使用此选项或-M选项）
  将服务破解（请参见下文）支持的协议）
  OPT一些服务模块支持附加输入（-U，以获取模块帮助）

下载成功后直接使用CMD打开 - hyare.exe

hydra爆破rdp：（前提是目标的远程连接可以访问）

hydra -l Administrator -P password.txt rdp://192.168.1.111   

hydra爆破mysql:（前提是目标的mysql可远程访问）

hydra -l root -P password.txt 192.168.1.111 mysql

hydra爆破http：( http-get or http-form-post.)

hydra -l admin -P password.txt http-get://192.168.1.111/login.php

注意事项：

1、字典路径为全英文且不能空格；

2、做测试的时候要确保目标可访问；
