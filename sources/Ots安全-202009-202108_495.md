## 0x02 任意文件上传？

这个站打开是个登录框

![](../Images/5af5e8c43a1f3141b3e4a2fb67d942e9.png)

抓包，发现验证码无效，爆破一顿以后没爆出来。注意到

![](../Images/1f7e32ba8c3b7253f31d65882c9483b2.png)

这个框架叫某admin框架，谷歌查了一下这个框架有什么洞，发现一篇帖子。

![](../Images/f2cc4dfaf2d60c25dc5e697e8d33d71c.png)

说存在此文件plugins/uploadify/uploadFile.jsp 且此文件存在任意文件上传

```


































































<%@ page language="java" contentType="text/html; charset=UTF-8" pageEncoding="UTF-8"%>
```

尝试访问此文件，提示未登录302跳转

![](../Images/c9ae720d71e428aedd8607502d0ec5e9.png)

想到这个站用了shiro虽然反序列化命令执行修了，shiro权限绕过可能没修。具体可以看这篇文章：[https://mp.weixin.qq.com/s/yb6Tb7zSTKKmBlcNVz0MBA](https://mp.weixin.qq.com/s?__biz=MzAwNzk0NTkxNw==&mid=2247484197&idx=1&sn=4b1cc68795e8b5120de6db4fb827e8a4&scene=21#wechat_redirect)

我们使用

```
/;a/plugins/uploadify/uploadFile.jsp
```

来绕过shiro的权限控制，可以注意到状态码为200

![](../Images/6639f702073b09fe3f946be8af35a84b.png)

结合之前给出的代码需要两个参数构造上传包

![](../Images/2dec6ea409787d06e73a26f8bafb6da2.png)

发现上传成功，但是居然找不到文件。

![](../Images/87085234c57a4371596add59f30256cf.png)

仔细看了一下才知道request.getParameter("uploadPath");解析不了multipart里的参数，再次构造上传包

```









POST /;a/plugins/uploadify/uploadFile.jsp?uploadPath=/plugins/uploadify/ HTTP/1.1
```

成功shell![](../Images/de1735f80d4cefb98d7b0a63821bcfa9.png)
