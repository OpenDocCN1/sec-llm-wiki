# 用于检测 Acropalypse 的 Web 工具 (CVE-2023-21036)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247497227&idx=3&sn=6529abd686b94db2a4445499f1a9ed6b&chksm=9badbf40acda36563f85e3918e3dfcc8d2a6d6746cf1581450d29929970c21e67bb951119b16&scene=126&sessionid=1681669907#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247497227&idx=3&sn=6529abd686b94db2a4445499f1a9ed6b&chksm=9badbf40acda36563f85e3918e3dfcc8d2a6d6746cf1581450d29929970c21e67bb951119b16&scene=126&sessionid=1681669907#rd)

用于扫描频道或整个服务器以查找可能是像素屏幕截图的图像附件或 URL 的机器人，下载它们并检查它们是否存在 CVE-2023-21036。如果它认为是，它会尝试删除附件/消息。最后它会给出一个小的统计数据，其中包含指向它认为受到影响但无法删除的消息的链接（例如由于权限）

为了检测，这使用 retr0id https://gist.github.com/DavidBuchanan314/93de9d07f7fab494bcdf17c2bd6cef02的脚本，并由https://github.com/infobyte/CVE-2023-21036稍作修改

代码大多是可怕的，如果你在大型服务器上运行它可能会做可怕的事情，因为“速率限制”非常糟糕。如果您将您的帐户/机器人扔到 shadowrealm 中，我不承担任何责任

这需要`message_content`意图和`DISCORD_TOKEN`环境变量
