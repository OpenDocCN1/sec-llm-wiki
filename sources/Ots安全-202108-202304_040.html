openRedScan 是一个基于 python 的工具，可以测试每个 URL 并检查开放重定向漏洞。


主要特点

  • 基于标头的重定向

  • 基于 Javascript 的重定向

  • 基于元标记的重定向


安装

git clone https://github.com/thenurhabib/openredscan.gitcd openredscanbash setup.shpython3 openredscan.py -h
