CVE-2023-23752

joomla CVE-2023-23752 扫描器的简单程序，这是一个简单的 Ruby 脚本，用于检查目标列表是否容易受到 CVE-2023-23752 的攻击，CVE-2023-23752 是 Web 应用程序中的一个严重安全漏洞。该脚本向指定端点发送 HTTP GET 请求，并从响应中提取信息以确定目标是否易受攻击。
