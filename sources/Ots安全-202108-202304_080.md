Joomla (CVE-2023-23752) - 请求参数突破 Rest API

## 受影响的版本

Joomla大致有3个路由入口，分别是

1.  根目录下的index.php（用户访问文章）
    
2.  根目录下的administrator/index.php（管理员管理）
    
3.  根目录下的api/index.php（开发者的Rest API）
    

非授权接口正是第三个入口点。因此，只有Joomla4.0.0 Joomla4.2.7受到影响（Rest API 4.x是官方开发的）
