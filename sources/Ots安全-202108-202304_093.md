Dompdf 是一个 HTML 到 PDF 的转换器。`<image>`通过传递带有大写字母的标签，可以在 SVG 解析时绕过 dompdf 2.0.1 上的 URI 验证。`phar`这可能会导致通过URL 包装器在 PHP < 8 上反序列化任意对象。如果攻击者可以向 dompdf 提供 SVG 文件，则攻击者可以利用该漏洞使用任意协议调用任意 URL。在 8.0.0 之前的 PHP 版本中，它会导致任意反序列化，这至少会导致任意文件删除甚至远程代码执行，具体取决于可用的类。  

### 概括
