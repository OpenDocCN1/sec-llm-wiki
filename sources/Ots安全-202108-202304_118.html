JSON Web 令牌 (JWT) 支持 Burp 拦截代理。JWT4B 将允许您即时操作 JWT，自动执行针对 JWT 的常见攻击，并在代理历史记录中为您解码。JWT4B 自动检测“授权承载”标头形式的 JWT 以及可自定义的帖子正文参数和正文内容。

构建您自己的版本（使用 Eclipse）

  1. 克隆存储库并创建新的 Eclipse Java 项目

  2. 右键单击 -> 配置 -> 转换为 Maven 项目（下载所有需要的库）

  3. 打开Burp -> Extender -> APIs -> 保存接口文件 -> 将所有文件复制到JWT4B\src\burp

  4. 导出可运行的 fat JAR，包括库

  5. 通过 Extender Tab -> Extensions -> Add 在 Burp 中加载 JAR（提示：CTRL+单击扩展以重新加载它）
