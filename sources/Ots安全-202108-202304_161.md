```
/Java调用的主函数function burpJsEncrypter(rawPayload){
  var encryptedPayload;
  //===============加密开始=================
  encryptedPayload = hex_md5(rawPayload);
  //===============加密结束=================
  return encryptedPayload;}
```

如上面的代码中的hex\_md5函数是加载到里面的其他js文件中的函数。实战中只需要把页面中所有摸及加密的js文件下载到这个目录即可。
