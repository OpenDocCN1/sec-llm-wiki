# 恶意 HTML 文件 (QBot) 分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247495858&idx=2&sn=f7a1fd2f4d25ab1cc5351ad7b0905ddf&chksm=9badb9f9acda30ef365a0987274ec650386d49d76f0976a80bb0104a9ef2ef57e70a3b052d44&scene=126&sessionid=1681669960#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247495858&idx=2&sn=f7a1fd2f4d25ab1cc5351ad7b0905ddf&chksm=9badb9f9acda30ef365a0987274ec650386d49d76f0976a80bb0104a9ef2ef57e70a3b052d44&scene=126&sessionid=1681669960#rd)

读者 Eric 提交了一个恶意 HTML 页面，其中包含带有恶意软件的 BASE64 图像。

  

让我们来看看。使用我的工具base64dump.py我在 HTML 代码中搜索长 BASE64 字符串：

![](../Images/f33da755c44cd8ae4c6a574ddfaf805c.png)

看起来确实有2张图片。一个 GIF 和一个 SVG 文件。

让我们仔细看看：

![](../Images/26d72cd41bdb8bb014a4a8c9c59f40d0.png)![](../Images/4b204788141454b7adb0d00bdb2ae5c9.png)

GIF 文件具有非常高的熵，并且没有长字符串。而 SVG 文件包含 BASE64 数字的字节序列，长度为 596938 字节。

所以很可能在 SVG 文件中隐藏了一些东西。

让我们尝试第二级 base64 解码：

![](../Images/f366223681bf83b3a9380f6f7a97b38d.png)

PK：那可能是一个 ZIP 文件。让我们试试zipdump.py：

![](../Images/f32fe21308df8fba5e1817f58403f49e.png)

它确实是一个 ZIP 文件，但它受密码保护。让我们 grep 获取 HTML 文件中的密码：

![](../Images/a12c3cbd392516ee986af9394b7fecbf.png)

![](../Images/0021bb1b967f492553f2e143bc9a8cc3.png)看起来 abc333 是密码。我们试试看：

![](../Images/cc7335e630ecdc8a1f48f2285fb4c1f5.png)

ZIP 文件包含一个 ISO 文件。

让我们看一下isodump.py：

![](../Images/b009c6a7b124a79543b10621cd10cdbb.png)![](../Images/64f0666b72bdc0f2e8aeab0201baccfd.png)

isodump.py 只看到一个文本文件。恶意文档（现在很明显这是恶意的）仅包含一个文本文件，这是非常不可能的。发生了什么，是有一个二级卷描述符，但 isodump 使用的 pathlab 模块无法识别二级卷。

  

由于我现在希望该 ISO 文件中有一个 Windows 可执行文件，因此我使用pecheck.py来创建 PE 文件：

![](../Images/dbb3927de1ba960ff1677a1d938c22f5.png)

事实上，我们有一个 32 位的 DLL，原来是QBot。

QBot沙箱检测报告：https://www.virustotal.com/gui/file/8bf00c146ff533fa193c448d5ccdeb0ba5f56764d290b3de0f55f1b40acf810a

  

7-zip 实用程序可以帮助我们查看 ISO 文件，但它不接受 ISO 文件作为通过标准输入的输入。

  

所以我首先必须将文件写入磁盘，然后让 7-zip 对其进行分析：

![](../Images/06ce99cfb74b98064badfc7e605f2181.png)![](../Images/d5aae5489a28a7da722f4a2a4275c6e7.png)
