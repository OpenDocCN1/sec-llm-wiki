1、没有teamserver文件问题

  

需要检查是否有dos2unix，dos2unix是将Windows格式文件转换为Unix、Linux格式的实用命令；输入下方命令，转换teamserver文件内容的格式dos2unix teamserver，一般kali会带有dos2unix直接转换  

*   
*   
*   

```
┌──(root㉿kali)-[~/Desktop/Cobalt 4.5]└─# dos2unix teamserverdos2unix: 正在转换文件 teamserver 为Unix格式...
```

  

2、权限问题  

*   
*   
*   

```
┌──(root㉿kali)-[~/Desktop//Cobalt Strike 4.5]└─# ./teamserver 192.168.135.129 vamvamzsh: 权限不够: ./teamserver
```

解决  

*   
*   

```
┌──(root㉿kali)-[~/Desktop/Cobalt 4.5]└─# chmod +x teamserver
```
