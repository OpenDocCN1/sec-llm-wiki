CVE-2022-26134 - OGNL 注入漏洞。

利用影响 Atlassian Confluence 7.18 及更低版本产品的远程代码执行漏洞的脚本概念验证。OGNL 注入漏洞允许未经身份验证的用户在 Confluence 服务器或数据中心实例上执行任意代码。

所有受支持的 Confluence Server 和 Data Center 版本都会受到影响。

Confluence Server 和 Data Center 1.3.0 之后的版本和 7.18.1 以下的版本会受到影响。

国家计算机病毒应急处理中心和360公司分别发布专题研究报告，同日披露美国国家安全局（NSA）下属的又一款网络攻击武器“FOXACID”漏洞攻击武器平台（以下简称“酸狐狸”平台）。


FoxAcid系统

根据斯诺登提供的各种绝密文件，FoxAcid 是 NSA 所称的“漏洞利用编排器”的 NSA 代号，这是一个能够以各种不同方式攻击目标计算机的互联网系统。它是一台配置了自定义软件和一系列 Perl 脚本的 Windows 2003 计算机。这些服务器由 NSA 的定制访问操作或 TAO 组运行。TAO 是系统情报局的另一个小组。

服务器位于公共 Internet 上。它们的域名看起来很正常，可以在任何地方被任何浏览器访问；这些域名的所有权无法追溯到 NSA。


但是，如果浏览器尝试使用称为 FoxAcid 标记的特殊 URL 访问 FoxAcid 服务器，则服务器会尝试感染该浏览器，然后感染计算机，以控制它。NSA 可以使用多种方法诱骗浏览器使用该 URL，包括上面提到的竞争条件攻击和帧注入攻击。


FoxAcid 标签的设计看起来无害，因此任何看到它们的人都不会怀疑。http://baseball2.2ndhalfplays.com/nested/attribs/bins/1/define/forms9952_z1zzz.html 就是这样一个标签的一个例子，在斯诺登提供的另一个绝密培训演示中给出。


目前没有该名称的注册域名；这只是 NSA 内部培训目的的一个示例。


培训材料指出，仅仅尝试访问真实 FoxAcid 服务器的主页不会导致任何攻击，并且需要专门的 URL。此 URL 将由 TAO 为特定的 NSA 操作创建，并且对于该操作和目标是唯一的。这允许 FoxAcid 服务器在他的计算机与其联系时准确地知道目标是谁。


根据斯诺登的说法，FoxAcid 是一个通用的 CNE 系统，用于除此处描述的 Tor 攻击之外的许多类型的攻击。它被设计成模块化的，具有灵活性，允许TAO在发现漏洞时交换和替换漏洞，并且只针对某些类型的目标运行某些漏洞。


为最重要的目标保存最有价值的漏洞利用。低价值漏洞针对技术复杂的目标运行，检测机会很高。TAO 维护着一个漏洞库，每个漏洞都基于系统中的不同漏洞。根据目标的价值、目标的技术复杂性、漏洞利用的价值和其他考虑因素，不同的漏洞利用被授权针对不同的目标。


根据斯诺登提供的绝密操作管理程序手册，一旦目标被成功利用，它就会被几个有效载荷之一感染。手册中提到的两个基本有效载荷旨在从目标计算机收集配置和位置信息，以便分析人员可以确定如何进一步感染计算机。


这些决定部分取决于目标的技术复杂性和安装在目标计算机上的安全软件，在手册中称为个人安全产品或 PSP。


FoxAcid 有效载荷由 TAO 定期更新。例如，手册中引用了其中之一的 8.2.1.1 版本。


FoxAcid 服务器还具有复杂的功能，可以避免检测并确保成功感染其目标。操作手册指出，代号为 DireScallop 的 FoxAcid 有效负载可以规避商业产品，这些产品可防止恶意软件对在重启过程中幸存的系统进行更改。


NSA 还使用网络钓鱼攻击诱使用户点击 FoxAcid 标签。


TAO 还使用 FoxAcid 来利用回调——这是被某种自动方式感染的计算机的总称——回调 NSA 以获取更多指令，并可能从目标计算机上传数据。


根据绝密操作管理程序手册，配置为接收回调的 FoxAcid 服务器代号为 FrugalShot。回调后，FoxAcid 服务器可能会运行更多漏洞以确保目标计算机长期处于受感染状态，并安装旨在窃取数据的“植入物”。


根据该工具，在方程式恶意软件中还带有一个FOXACID 程序一起泄露的，2015年3月中旬俄罗斯卡巴斯基的的一篇文章中，卡巴斯基实验室发布了一份详尽的报告，称该组织至少从 2001 年甚至可能早在 1996 年就开始进行网络间谍活动。该报告详细介绍了该组织的攻击技术和恶意软件工具。

3.1 (TS//SI) FOXACID 服务器背景

Foxacid 服务器是一个 Microsoft Windows 2003 服务器，具有 FA 服务器软件，安装了 FA 插件和有效负载。一系列过滤器，modrewrite，前置过滤器和后置过滤器（在那个order) 用于向服务器提供逻辑。此逻辑确定是否有标签进来可能会更改，目标可能会获得什么有效负载，或者如果它是被阻止的 IP，则为 404 或 200。


3.2. (TS//SI) FOXACID 服务器与 CDR 和数据流的交互CDR 是 Foxacid 服务器使用的数据传输方法。数据偏低的是以加密格式传输到接收计算机。然后将数据传输到高边，解密，并放置在其适当的文件位置。这包括数据填充 Foxsearch 和我们的心跳文件。有时 CDR 出现故障和/或备份有过多的数据。Foxacid 之外还有许多项目使用 CDR，并且这些项目中的任何一个都存在错误会影响 CDR。根据 CDR 出现问题的时间长短，将影响如何当前的数据是。积压的数据越多，所需的时间就越长一切都可以恢复到最新状态。
