点击上方蓝字“Ots安全”一起玩耍

我正在寻找一个负责任的计划。该程序的功能非常少。我的意思是没有可以测试错误的注册或登录功能或类似的输入字段。像您这样可以下载该公司的软件并阅读手册、隐私政策等的网页很少。现在呢？

我启动了 Burpsuite (Burpi ❤) 并爬取了整个网站。然后突然我看到没有更多的安全标头。特别是 XSS 保护标头。如您所知，目标没有测试输入验证的功能。有一个语言/电子邮件参数（例如 target.com/?lang=en&email=x）。我知道你现在在想什么。我尝试了一个简单的 XSS 有效载荷，它奏效了！！呜呼……😍

我开始了错误链接。我做了 HTML 注入。我输入了简单的 HTML 代码（例如<h1>HelloWorldHTMLInjectionHere</h1>）并执行了它。我们还能做什么？另一个错误链是 通过 HTML 注入打开重定向 。是的，你没有看错。有效载荷如下所示：

<script>document.location.href="https://example.com"</script>

它将重定向到 example.com。我很快做了 POC 并写了一份很好的报告并将其发送到他们的安全邮件。几天后，我收到了我有资格获得赏金的邮件。我得到了500美元。就是这样，伙计们。继续打猎，继续分享。


我在测试时犯的错误。与目标公司相关的域名超过 6 个。同样的错误也在那里。但是我只报告了一个主要域的错误，他们修复了也受相同错误影响的其余域。


课程：如果您发现错误，请检查范围内域上的相同参数。


提示：如果 Self XSS 超出范围，那么您可以尝试 HTML Injection、Open Redirection、CSRF、Self XSS to Stored XSS。
