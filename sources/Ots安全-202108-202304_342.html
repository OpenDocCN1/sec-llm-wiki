Bug-type：off-domain XSS

最初，让我们假设目标域为 target.com。


我正在搜索一些参数和端点，我观察到目标网站具有聊天机器人功能因此，开始使用一些 HTML 和 XSS 有效负载来处理输入字段，但没有运气。

我观察到它有一个上传选项，所以我尝试了文件上传漏洞 Boom !! 它没有文件上传限制。


让我们开始寻找 XSS，

PROCEDURE：


在目标网站中打开聊天机器人功能。

上传包含 XSS 载荷的恶意文件，这里可以观察到我已经绕过文件限制使用双扩展名上传恶意文件。

XSS 有效负载保存为 HTML 文件：

<?xml version=”1.0" standalone=”no”?><!DOCTYPE svg PUBLIC “-//W3C//DTD SVG 1.1//EN” “http://www.w3.org/Graphics/SVG/1.1/DTD/svg11.dtd"><svg version=”1.1" baseProfile=”full” xmlns=”http://www.w3.org/2000/svg"> <polygon id=”triangle” points=”0,0 0,50 50,0" fill=”#009900" stroke=”#004400"/> <script type=”text/javascript”> alert(document.cookie);</script></svg>

有效载荷保存为 xss.svg.html


文件上传绕过技术：

黑名单绕过：

通过上传不受欢迎的php扩展可以绕过黑名单。

如：pht, phpt, phtml, php3,php4,php5,php6。


白名单绕过：

白名单可以通过上传文件来绕过一些技巧，比如添加一个空字节注入（shell.php%00.gif 或 shell.PHP.gif%00）。或者对上传的文件使用双重扩展名，例如 (shell.jpg.php)


成功上传后，将鼠标悬停在文件上并在新选项卡中打开图像 BOOM !! 我们可以看到 XSS 被触发了

影响：

该漏洞影响很大，因为它有可能在服务器上下文和客户端执行任意代码。可以利用上传的文件将应用程序的其他敏感部分暴露给客户端攻击，例如 XSS 或跨站点内容劫持。
