一个安全问题会影响 Ubuntu 及其衍生产品的这些版本：

- Ubuntu 21.10 

- Ubuntu 21.04 

- Ubuntu 20.04 LTS 


摘要：Linux 内核中修复了几个安全问题。

软件说明：

- linux：Linux 内核

- linux-aws：Amazon Web Services (AWS) 系统的 Linux 内核 

- linux-azure：Microsoft Azure Cloud 系统的 Linux 内核 

- linux-gcp：Google 云平台 (GCP) 系统的 Linux 内核

- linux-kvm：用于云环境的 Linux 内核 

- linux-oracle：用于 Oracle 云系统的 Linux 内核 

- linux-raspi：用于 Raspberry Pi 系统的 Linux 内核 

- linux-aws-5.11：用于 Amazon Web Services (AWS) 系统的 Linux 内核 

- linux-azure-5.11：用于 Microsoft Azure 云系统的 Linux 内核 

- linux-gcp-5.11：用于 Google Cloud Platform (GCP) 系统的 Linux 内核 

- linux-hwe-5.11：Linux 硬件支持 (HWE) 内核 

- linux-oracle-5 . 11：Oracle Cloud 系统的Linux 内核 


详细信息：Nadav Amit 发现Linux 内核中的hugetlb 实现在某些情况下不会执行TLB 刷新。本地攻击者可以使用它来泄漏或更改来自使用大页面的其他进程的数据。


(CVE-2021-4002) 发现在 Linux 内核的覆盖文件系统实现中存在竞争条件。本地攻击者可以使用它来导致拒绝服务（系统崩溃）。


(CVE-2021-20321) 发现 Linux 内核中的 NFC 子系统在其 NFC 控制器接口 (NCI) 实现中包含一个释放后使用漏洞。本地攻击者可能会使用它来导致拒绝服务（系统崩溃）或执行任意代码。


(CVE-2021-3760) 发现在为堆栈映射预分配对象时，Linux 内核中的 eBPF 实现可能会触发整数溢出。有特权的本地攻击者可以使用它来导致拒绝服务或可能执行任意代码。(CVE-2021-41864) 发现 Linux 内核中的 POWER8 处理器的 KVM 实现无法正确跟踪唤醒事件是否可以由来宾解决。来宾 VM 中的攻击者可能会使用它来导致拒绝服务（主机操作系统崩溃）。


(CVE-2021-43056) 发现 Linux 内核中的 TIPC 协议实现在某些情况下没有正确验证 MSG_CRYPTO 消息。攻击者可以使用它来导致拒绝服务（系统崩溃）或可能执行任意代码。(CVE-2021-43267) 发现 Linux 内核中的 ISDN CAPI 实现在某些情况下包含可能触发数组越界错误的竞争条件。享有特权的本地攻击者可能会使用它来导致拒绝服务或执行任意代码。(CVE-2021-43389)
