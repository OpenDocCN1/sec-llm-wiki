什么是DNSlog？作用是什么？  

**原理：**

首先需要有一个可以配置的域名，例如：ceye.io ，然后通过代理设置域名ceye.io为其服务器A的nameserver ，然后在DNS Server上配置服务器A ，所以既然都是ceye。io和 subdomain 会向服务器A查询，可以实时监控域名查询请求的情况，如下图所示。

![](../Images/0cba8d99a775eadcb80f5bd08bf95fec.png)

  

**好，回到正题。**  

Log4j 日志输出允许包含变量，这些变量使 Java 日志记录在本地环境中更加健壮和详细。这是为了“方便”而添加的，正如原始拉取请求在 2013 年添加此漏洞时所表明的那样。 

  

然而，这也使攻击者能够通过打开执行 shell 丢弃的机会来调用外部 Java 库，而无需付出太多额外的努力。此外，威胁参与者可以利用在实际环境中执行命令来部署 RCE 攻击和投放 shell，目前很多人尝试反弹不了shell
