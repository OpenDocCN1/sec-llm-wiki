NFT 已经席卷了艺术和游戏世界。无论您认为它们是投机时尚还是艺术家的新可能性，当它们以数百万美元的价格出售时，它们都会继续成为头条新闻。

  

NFT 的寿命仍在争论中，但它们仍然像热蛋糕一样在网上销售。许多人相信 NFT 将继续存在，随着Facebook 元宇宙的兴起，现在似乎是了解所有数字事物的最佳时机，因此请继续阅读以了解了解难以捉摸的 NFT 所需的一切。

  

NFT 代表不可替代的代币，这意味着隐藏在那些古怪的艺术品中，有一个完全独特且不可互换的数据单元存储在使用区块链技术建立所有权证明的数字分类账上。NFT 是具有收藏价值的数字资产，就像实物艺术品如何保值一样，NFT 也是如此。 

  

NFT 很像比特币和以太坊等加密货币。然而，NFT 是完全独特的，它不能被交换，这是不可替代的开始有意义的地方。该文件存储了额外的信息，将其提升到纯货币之上，并将其带入任何领域，真的。 

  

任何类型的易于复制的数字文件都可以存储为 NFT 以识别原始副本，例如摄影、艺术、音乐、视频、推文，甚至模因。你可以用几乎任何可以数字存储并保持价值的独特事物来制作 NFT。它们就像任何其他收藏家的物品，如一幅画或一个老式的可动人偶，但您购买的不是实物，而是支付文件和证明您拥有原始副本的费用。 

  
**NFT 包含哪些类型？**

![](../Images/3dfb77232703059b0130b1975fa7dc52.png)

NFT 是以太坊区块链的一部分 （图片来源：以太坊）

NFT 的唯一身份和所有权可通过区块链分类账进行验证。它们最初是在以太坊区块链上推出的，但包括 FLOW 和比特币现金在内的其他区块链现在也支持它们。无论原始文件是JPG、MP3、GIF还是其他任何文件，标识其所有权的 NFT 都可以像任何其他类型的艺术品一样进行买卖——而且，与实物艺术品一样，价格在很大程度上取决于市场需求。

  

如果你走进一家艺术画廊的礼品店，你会发现许多著名杰作的复制品，还有一些 NFT 以同样的方式运作。区块链的某些部分是完全有效的，但它们的价值与原始价值不同。 

  

NFT 很可能会附带对其指向的数字资产的许可，但这并不会自动授予版权所有权。版权所有者可以复制作品，NFT 所有者不收取版税。
