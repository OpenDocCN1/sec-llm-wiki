本节中的主题面向 IT 专业人员，介绍 Windows 中的安全审核功能以及您的组织如何从使用这些技术中受益，以增强网络的安全性和可管理性。

  

安全审计是您可以用来维护系统完整性的最强大的工具之一。作为整体安全策略的一部分，您应该确定适合您环境的审核级别。审计应识别对您的网络构成威胁的攻击（成功与否），以及对您在风险评估中确定为有价值的资源的攻击。

  

**在这个部分**

话题与描述

*   基本安全审计策略：在实施审计之前，您必须决定审计策略。基本审计策略指定要审计的安全相关事件的类别。首次安装此版本的 Windows 时，将禁用所有审核类别。通过启用各种审核事件类别，您可以实施适合您组织安全需求的审核策略。
    
*   高级安全审计策略：高级安全审核策略设置位于安全设置\\高级审核策略配置\\系统审核策略中，似乎与基本安全审核策略重叠，但它们的记录和应用方式不同。

**相关内容**

*   基本安全审核策略 (Windows 10) - Windows 安全
    

了解基本安全审核策略，这些策略指定您要审核以满足组织需求的安全相关事件的类别。

  

*   为事件类别创建基本审核策略 (Windows 10) - Windows 安全
    

通过为特定事件类别定义审核设置，您可以创建适合组织安全需求的审核策略。

  

*   高级安全审核策略设置 (Windows 10) - Windows 安全
    

此 IT 专业人员参考提供了有关 Windows 中可用的高级审核策略设置及其生成的审核事件的信息。

  

*   审核进程跟踪 (Windows 10) - Windows 安全
    

确定是否审计程序激活、进程退出、句柄重复和间接对象访问等事件的详细跟踪信息。

  

*   审核帐户登录事件 (Windows 10) - Windows 安全
    

确定是否审核用户登录或从另一台设备注销的每个实例，该设备用于验证帐户。

  

*   审计 SAM (Windows 10) - Windows 安全
    

高级安全审核策略设置审核 SAM 使您能够审核通过尝试访问安全帐户管理器 (SAM) 对象而生成的事件。

  

*   计划和部署高级安全审核策略 (Windows 10) - Windows 安全
    

学习在包含高级安全审计策略的网络中部署有效的安全审计策略。

  

*   审核策略 (Windows 10) - Windows 安全
    

提供有关 Windows 中可用的基本审核策略的信息以及指向有关每个设置的信息的链接。
