什么是入侵检测系统 (IDS)？

一个入侵检测系统（IDS不寻常或可疑的活动）监控网络传输，发送警报给管理员。检测异常活动并将其报告给网络管理员是主要功能；但是，某些 IDS 软件可以在检测到恶意活动时根据规则采取行动，例如阻止某些传入流量。

入侵检测系统的类型

入侵检测系统有两种主要类型（本指南后面将对这两种系统进行更详细的说明）：

  • 基于主机的入侵检测系统 (HIDS) – 该系统将检查网络上计算机上的事件，而不是通过系统的流量。

  • 基于网络的入侵检测系统 (NIDS) – 该系统将检查您网络上的流量。

网络入侵检测软件和系统现在对于网络安全至关重要。幸运的是，这些系统非常易于使用，而且市场上大多数最好的 IDS 都可以免费使用。在这篇评论中，您将了解现在可以安装以开始保护您的网络免受攻击的十种最佳入侵检测系统软件。我们涵盖了适用于 Windows、Linux 和 Mac 的工具。


基于主机的入侵检测系统 (HIDS)

基于主机的入侵检测系统，也称为主机入侵检测系统或基于主机的 IDS，它检查网络上计算机上的事件，而不是通过系统的流量。这种类型的入侵检测系统缩写为HIDS，它主要通过查看它所保护的计算机上的管理文件中的数据来运行。这些文件包括日志文件和配置文件。


HIDS 将备份您的配置文件，以便您可以在恶意病毒通过更改计算机设置而削弱系统安全性时恢复设置。您要防范的另一个关键因素是类 Unix 平台上的 root 访问权限或 Windows 系统上的注册表更改。HIDS 将无法阻止这些更改，但它应该能够在发生任何此类访问时提醒您。


HIDS 监控的每个主机上都必须安装一些软件。您可以让您的 HIDS 监控一台计算机。但是，更常见的是在网络上的每台设备上安装 HIDS。这是因为您不想忽视任何设备上的配置更改。自然地，如果您的网络上有多个 HIDS 主机，您不希望必须登录每个主机才能获得反馈。因此，分布式 HIDS 系统需要包含一个集中控制模块。寻找对主机代理和中央监视器之间的通信进行加密的系统。


基于网络的入侵检测系统 (NIDS)

基于网络的入侵检测，也称为网络入侵检测系统或网络 IDS，可检查网络上的流量。因此，典型的NIDS必须包含一个数据包嗅探器来收集网络流量以进行分析。


NIDS 的分析引擎通常是基于规则的，可以通过添加您自己的规则进行修改。对于许多 NIDS，系统提供者或用户社区将为您提供规则，您只需将这些规则导入到您的实现中即可。一旦您熟悉了所选 NIDS 的规则语法，您将能够创建自己的规则。


回到流量收集，您不想将所有流量转储到文件中或通过仪表板运行所有流量，因为您无法分析所有这些数据。因此，在 NIDS 中驱动分析的规则也创建了选择性数据捕获。例如，如果您有针对某种类型的令人担忧的 HTTP 流量的规则，则您的 NIDS 应该只选取和存储显示这些特征的 HTTP 数据包。


通常，NIDS 安装在专用硬件上。高端付费企业解决方案作为一个网络套件提供，其中预装了软件。但是，您不必为专业硬件支付大笔费用。NIDS 确实需要一个传感器模块来获取流量，因此您可以将其加载到 LAN 分析器上，或者您可以选择分配一台计算机来运行该任务。但是，请确保您为该任务选择的设备具有足够的时钟速度，不会减慢您的网络速度。

简短的回答是两者兼而有之。与 HIDS 相比，NIDS 将为您提供更多的监控能力。您可以拦截 NIDS 发生的攻击。相比之下，HIDS 只会在设备上的文件或设置已经更改后才注意到任何错误。然而，仅仅因为 HIDS 没有 NIDS 那么多的活动并不意味着它们不那么重要。


NIDS 通常安装在独立设备上的事实意味着它不会拖累服务器的处理器。然而，HIDS 的活动不像 NIDS 那样具有侵略性。HIDS 功能可以由计算机上的轻量级守护程序来完成，不应消耗过多 CPU。两个系统都不会产生额外的网络流量。


检测方法：基于签名或基于异常的 IDS

无论您是在寻找主机入侵检测系统还是网络入侵检测系统，所有 IDS 都使用两种操作模式——有些可能只使用一种或另一种，但大多数同时使用两种模式。

  • 基于签名的 IDS

  • 基于异常的 IDS


基于签名的 IDS

基于签名的方法查看校验和和消息身份验证。NIDS 和 HIDS 都可以应用基于特征的检测方法。HIDS 将查看日志和配置文件是否有任何意外的重写，而 NIDS 将查看捕获的数据包中的校验和以及 SHA1 等系统的消息身份验证完整性。


NIDS 可能包括一个签名数据库，已知为恶意活动来源的数据包携带该签名数据库。幸运的是，黑客不会坐在他们的电脑前像愤怒一样打字来破解密码或访问 root 用户。相反，他们使用由知名黑客工具提供的自动化程序。这些工具每次都倾向于生成相同的流量签名，因为计算机程序一遍又一遍地重复相同的指令，而不是引入随机变化。


基于异常的 IDS

基于异常的检测寻找意外或异常的活动模式。这个类别也可以通过主机和基于网络的入侵检测系统来实现。在 HIDS 的情况下，异常可能是重复失败的登录尝试 或设备端口上表示端口扫描的异常活动。


在 NIDS 的情况下，异常方法需要建立一个行为基线，以创建一个标准情况，可以与正在进行的流量模式进行比较。一系列流量模式被认为是可以接受的，当当前实时流量超出该范围时，就会引发异常警报。


选择 IDS 方法

复杂的 NIDS 可以建立标准行为记录并随着其使用寿命的进展调整其界限。总体而言，与使用 NIDS 相比，使用 HIDS 软件进行签名和异常分析的操作和设置要简单得多。


基于签名的方法比基于异常的检测快得多。一个完全全面的异常引擎涉及人工智能的方法，可能需要大量资金来开发。然而，基于签名的方法归结为值的比较。事实上，在 HIDS 的情况下，与文件版本的模式匹配可以是一项非常简单的任务，任何人都可以使用带有正则表达式的命令行实用程序来执行自己的任务。因此，它们的开发成本并不高，而且更有可能在免费的入侵检测系统中实现。


一个全面的入侵检测系统需要基于签名的方法和基于异常的程序。


使用 IPS 保护网络

现在我们需要考虑入侵防御系统 (IPS)。IPS 软件和 IDS 是同一技术的分支，因为没有检测就无法进行预防。表达这两个入侵工具分支之间差异的另一种方式是将它们称为被动或主动。一个简单的入侵监控和警报系统有时被称为“被动”IDS。不仅可以发现入侵，而且可以采取行动修复任何损坏并阻止来自检测到的源的进一步入侵尝试的系统，也称为“反应式”IDS。


反应式 IDS 或IPS 通常不直接实施解决方案。相反，它们通过调整设置与防火墙和软件应用程序交互。反应式 HIDS 可以与许多网络助手交互以恢复设备上的设置，例如SNMP或已安装的配置管理器。对 root 用户或 Windows 中的管理员用户的攻击通常不会自动处理，因为阻止管理员用户或更改系统密码会导致系统管理员无法访问网络和服务器。


许多 IDS 用户在首次安装防御系统时报告了大量误报，就像 IPS 在检测到警报条件时自动实施防御策略一样。不正确校准的 IPS 会造成严重破坏，并使您的合法网络活动陷入停顿。


为了最大限度地减少误报可能导致的网络中断，您应该分阶段引入您的入侵检测和防御系统。触发器可以定制，您可以组合警告条件来创建自定义警报。在检测潜在威胁时需要执行的操作声明称为策略。入侵检测和防御程序与防火墙的交互应该特别微调，以防止您企业的真正用户被过于严格的策略锁定。

1. SolarWinds 安全事件管理器（免费试用）

SolarWinds 安全事件管理器( SEM )在Windows Server上运行，但它可以记录由Unix、 Linux和Mac OS计算机以及Windows PC生成的消息。


作为日志管理器，这是一个基于主机的入侵检测系统，因为它涉及管理系统上的文件。但是，它还管理 Snort 收集的数据，这使其成为基于网络的入侵检测系统的一部分。

主要特点：

  • 分析日志文件

  • 可以处理实时数据

  • 与 Snort 兼容

  • 自动修复


Snort 是 Cisco Systems 创建的一种广泛使用的数据包嗅探器（见下文）。它具有特定的数据格式，其他 IDS 工具生产商将其集成到他们的产品中。SolarWinds 安全事件管理器就是这种情况。网络入侵检测系统会检查在网络上流通的流量数据。要部署安全事件管理器的 NIDS 功能，您需要使用 Snort 作为数据包捕获工具并将捕获的数据汇集到安全事件管理器进行分析。虽然 LEM 在处理日志文件创建和完整性时充当 HIDS 工具，但它能够通过 Snort 接收实时网络数据，这是一项 NIDS 活动。


SolarWinds 产品也可以作为入侵防御系统，因为它可以触发检测入侵的动作。该软件包附带 700 多个事件关联规则，使其能够发现可疑活动并自动实施补救活动。这些操作称为主动响应。


这些主动响应包括：

  • 通过 SNMP、屏幕消息或电子邮件发出事件警报

  • USB设备隔离

  • 用户账户暂停或用户驱逐

  • IP地址阻塞

  • 进程杀死

  • 系统关机或重启

  • 服务关闭

  • 服务触发

安全事件管理器的 Snort 消息处理能力使其成为一个非常全面的网络安全监控器。由于该工具能够将 Snort 数据与系统上的其他事件相结合，恶意活动几乎可以立即关闭。由于微调的事件关联规则，通过检测误报而中断服务的风险大大降低。


2. CrowdStrike Falcon （免费试用）

该CrowdStrike猎鹰系统是端点保护平台（EPP） 。这是一个 HIDS，因为它监视单个端点上的活动而不是网络活动。但是，与典型的 HIDS 不同，该系统不关注受监控设备上的日志文件，而是查看每台计算机上运行的进程，这通常是 NIDS 策略。


主要特点：

  • 端点保护平台

  • 检查日志文件

  • 在云端处理数据

  • 基于云的控制台


Falcon 平台是一组模块。HIDS 功能由Falcon Insight单元提供。这是一个端点检测和响应 (EDR)系统。EPP的核心模块叫做Falcon Prevent，是下一代AV系统。这也使用HIDS 方法来检测恶意行为。这两个模块的方法之间的差异很小，因为这两种方法都监视异常行为。但是，Falcon Prevent 的识别特征是它正在搜索恶意软件，而 Falcon Insight 则专门寻找入侵。


Falcon Insight 在受保护的计算机上记录事件，这些事件需要存储在日志文件中，因此一旦写入这些事件，该工具的研究和检测元素就会使用纯HIDS 策略。EPP 的事件收集元素是一个代理，它必须安装在受保护的设备上。代理与驻留在云中的 EPP 的中央处理系统进行通信。受保护端点的人工管理员通过任何标准浏览器访问 Falcon 仪表板。


CrowdStrike Falcon 软件的本地/云混合架构的优势在于该系统在您的设备上非常轻巧。CrowdStrike 服务器上的分析软件提供了威胁分析的所有处理能力。这意味着安装此安全服务不会减慢计算机的速度，让它们可以自由地执行为其提供的任务。但是，该代理还充当威胁修复实施者，因此即使 Internet 连接不可用，它也会继续工作。


3. ManageEngine EventLog Analyzer （免费试用）

ManageEngine是 IT 网络基础设施监控和管理解决方案的领先制造商。EventLog Analyzer是公司安全产品的一部分。这是一个HIDS，专注于管理和分析由标准应用程序和操作系统生成的日志文件。该工具安装在Windows Server或Linux 上。它从这些操作系统以及Mac OS、IBM AIX、HP UX和Solaris系统收集数据。来自 Windows 系统的日志包括来自 Windows Server Windows Vista 及更高版本和 Windows DHCP 服务器的源。


主要特点：

  • 管理和分析日志文件

  • 审计数据保护标准合规性

除了操作系统之外，该服务还收集和整合来自Microsoft SQL Server和Oracle数据库的日志。它还能够传输来自许多防病毒系统的警报，包括Microsoft Anti-malware、ESET、Sophos、Norton、Kaspersky、FireEye、Malwarebytes、McAfee和Symantec。它将从 Web 服务器、防火墙、管理程序、路由器、交换机和网络漏洞扫描程序收集日志。


EventLog Analyzer 收集日志消息并作为日志文件服务器运行，按消息源和日期将消息组织到文件和目录中。紧急警告还会转发到 EventLog Analyzer 仪表板，并可以作为票证传送到帮助台系统，以引起技术人员的立即关注。关于哪些事件构成潜在安全漏洞的决定是由包中内置的威胁情报模块驱动的。


该服务包括自动日志搜索和事件关联，以编制定期安全报告。这些报告包括特权用户监控和审计 (PUMA) 格式，以及证明符合PCI DSS、FISMA、ISO 27001、GLBA、HIPAA、SOX和GDPR所需的各种格式。


4. Snort

Snort 是NIDS 的行业领导者，但它仍然可以免费使用。这是少数可以安装在 Windows 上的 IDS 之一。它是由思科创建的。该系统可以运行在三种不同的模式下，可以实施防御策略，因此它既是一个入侵防御系统，也是一个入侵检测系统。


Snort 的三种模式是：

  • 嗅探模式

  • 数据包记录器

  • 入侵检测

您可以将 snort 用作数据包嗅探器，而无需打开其入侵检测功能。在这种模式下，您可以实时读取通过网络的数据包。在数据包记录模式下，这些数据包详细信息被写入文件。


主要特点：

  • 行业领先的 NIDS

  • 由思科系统支持

当您访问 Snort 的入侵检测功能时，您会调用一个分析模块，该模块将一组规则应用于经过的流量。这些规则称为“基本策略”，如果您不知道需要哪些规则，可以从 Snort 网站下载它们。但是，一旦您对 Snort 的方法论充满信心，就可以编写自己的方法。这个 IDS 有一个庞大的社区基础，他们在 Snort 网站的社区页面上非常活跃。您可以从其他用户那里获得提示和帮助，还可以下载有经验的 Snort 用户开发的规则。


这些规则将检测诸如隐形端口扫描、缓冲区溢出攻击、CGI 攻击、SMB 探测和操作系统指纹等事件。检测方法取决于所使用的特定规则，它们包括基于签名的方法和基于异常的系统。


Snort 的名声吸引了软件开发商行业的追随者。其他软件公司创建的几个应用程序可以对 Snort 收集的数据进行更深入的分析。其中包括Snorby、BASE、Squil和Anaval。这些配套应用程序可以帮助您弥补 Snort 的界面不是很人性化的事实。


5. OSSEC

OSSEC 代表开源 HIDS 安全。它是可用的领先 HIDS，并且完全免费使用。作为基于主机的入侵检测系统，该程序侧重于安装它的计算机上的日志文件。它监视所有日志文件的校验和签名以检测可能的干扰。在 Windows 上，它将密切关注对注册表的任何更改。在类 Unix 系统上，它将监视任何试图访问 root 帐户的尝试。虽然 OSSEC 是一个开源项目，但它实际上归著名的安全软件生产商趋势科技所有。


主要特点：

  • 日志文件分析器

  • 免费政策

  • 警报系统

主监控应用程序可以覆盖一台计算机或多台主机，将数据整合到一个控制台中。虽然有 Windows 代理可以监控 Windows 计算机，但主应用程序只能安装在类 Unix 系统上，即 Unix、Linux 或 Mac OS。主程序有 OSSEC 接口，但这是单独安装的，不再受支持。OSSEC 的普通用户发现了其他可以很好地作为数据收集工具前端的应用程序：包括 Splunk、Kibana 和 Graylog。


OSSEC 涵盖的日志文件包括 FTP、邮件和 Web 服务器数据。它还监视操作系统事件日志、防火墙和防病毒日志和表格以及流量日志。OSSEC 的行为由您在其上安装的策略控制。这些可以作为附加组件从活跃于此产品的大型用户社区中获取。策略定义警报条件。这些警报可以显示在控制台上，也可以作为通知通过电子邮件发送。


6. Suricata

Suricata 可能是 Snort 的主要替代品。与 Snort 相比，Suricata 有一个至关重要的优势，那就是它在应用层收集数据。这克服了 Snort 必须将签名拆分为多个 TCP 数据包的盲目性。Suricata 会等待，直到数据包中的所有数据都已组装完毕，然后才会将信息转移到分析中。


主要特点：

  • 应用层操作

  • 对实时数据进行操作

虽然系统工作在应用层，但它可以监控较低级别的协议活动，例如 IP、TLS、ICMP、TCP 和 UDP。它检查不同网络应用程序的实时流量，包括 FTP、HTTP 和 SMB。监视器不仅仅查看数据包结构。它可以检查 TLS 证书并专注于 HTTP 请求和 DNS 调用。文件提取工具可让您检查和隔离具有病毒感染特征的可疑文件。


Suricata 与 Snort 兼容，您可以使用为该 NIDS 领导者编写的相同 VRT 规则。那些与 Snort 集成的第三方工具，例如Snorby、BASE、Squil和Anaval也可以连接到 Suricata。因此，访问 Snort 社区以获取提示和免费规则对 Suricata 用户来说是一个很大的好处。内置脚本模块允许您组合规则并获得比 Snort 更精确的检测配置文件。Suricata 使用签名和异常检测方法。


Suricata 拥有一个巧妙的处理架构，它通过使用许多不同的处理器同时进行多线程活动来实现硬件加速。它甚至可以部分运行在您的显卡上。任务的这种分配可以防止负载只压在一台主机上。这很好，因为这个 NIDS 的一个问题是它的处理非常繁重。


Suricata 有一个非常漂亮的仪表板，它结合了图形，使分析和问题识别变得更加容易。尽管前端看起来很昂贵，但Suricata 是免费的。


7.Zeek

Zeek（原 Bro）是一款免费的 NIDS，它超越了入侵检测，还可以为您提供其他网络监控功能。Zeek 的用户社区包括许多学术和科研机构。


Zeek 入侵检测功能分两个阶段完成：流量记录和分析。与 Suricata 一样，Zeek 与 Snort 相比的主要优势在于它的分析在应用程序层运行。这使您可以查看数据包，从而对网络协议活动进行更广泛的分析。


主要特点：

  • 签名检测

  • 异常分析

Zeek 的分析模块有两个元素，分别用于签名检测和异常分析。这些分析工具中的第一个是Zeek 事件引擎。这会跟踪触发事件，例如新的 TCP 连接或 HTTP 请求。每个事件都被记录下来，所以系统的这一部分是策略中立的——它只提供一个事件列表，在这些事件中，分析可能会揭示由同一用户帐户生成的重复动作或可疑的不同活动。


该事件数据的挖掘由策略脚本执行。警报条件将引发操作，因此Zeek 是一个入侵防御系统以及一个网络流量分析器。策略脚本可以自定义，但它们通常按照标准框架运行，包括签名匹配、异常检测和连接分析。


您可以使用 Zeek 跟踪 HTTP、DNS 和 FTP 活动，还可以监控 SNMP 流量，使您能够检查设备配置更改和 SNMP 陷阱条件。每个策略都是一组规则，您不限于可以检查的活动策略或协议堆栈附加层的数量。在较低级别，您可以注意 DDoS 同步泛洪攻击并检测端口扫描。


8. Sagan

Sagan 是一个基于主机的入侵检测系统，因此它是 OSSEC 的替代品，并且可以免费使用。尽管是 HIDS，但该程序与 Snort 收集的数据兼容，后者是 NIDS 系统。这种兼容性还扩展到可与 Snort 结合使用的其他工具，例如Snorby、BASE、Squil和Anaval。Zeek 和 Suricata 的数据源也可以输入 Sagan。该工具可以安装在 Unix、Linux 和 Mac OS 上。尽管您无法在 Windows 上运行 Sagan，但您可以将 Windows 事件日志输入其中。


主要特点：

  • 日志分析

  • 网络流量分析

严格来说，Sagan 是一个日志分析工具。使其成为独立 NIDS 所缺少的元素是数据包嗅探器模块。然而，从好的方面来说，这意味着 Sagan 不需要专用硬件，并且可以灵活地分析主机日志和网络流量数据。该工具必须与其他数据收集系统配合使用才能创建完整的入侵检测系统。


Sagan 的一些不错的功能包括 IP 定位器，它使您能够查看被检测为具有可疑活动的 IP 地址的地理位置。这将使您能够聚合似乎协同工作以形成攻击的 IP 地址的操作。Sagan 可以将其处理分布在多个设备上，从而减轻关键服务器 CPU 的负载。


该系统包括脚本执行，这意味着它将生成警报并在检测入侵场景时执行操作。它可以与防火墙表交互以在来自特定来源的可疑活动的情况下实施 IP 禁令。所以，这是一个入侵防御系统。分析模块适用于签名和异常检测方法。


9.安全洋葱

对于 IDS 解决方案的混合，您可以尝试免费的 Security Onion 系统。此列表中的大多数 IDS 工具都是开源项目。这意味着任何人都可以下载源代码并进行更改。


这正是 Security Onion 的开发者所做的。他从Snort、Suricata、OSSEC和Zeek的源代码中获取元素，并将它们拼接在一起，制成这个基于 Linux 的免费 NIDS/HIDS 混合体。Security Onion 是为在 Ubuntu 上运行而编写的，它还集成了来自前端系统和分析工具的元素，包括Snorby、Sguil、Squet、Kibana、ELSA、Xplico和NetworkMiner。


主要特点：

  • HIDS/NIDS 混合

  • 日志文件篡改警报

虽然 Security Onion 被归类为 NIDS，但它也包含 HIDS 功能。它将监视您的日志和配置文件是否存在可疑活动，并检查这些文件的校验和是否有任何意外更改。Security Onion 的网络基础设施监控综合方法的一个缺点是其复杂性。它有几种不同的操作结构，并且没有足够的在线或捆绑学习材料来帮助网络管理员掌握该工具的全部功能。


网络分析由数据包嗅探器进行，它可以在屏幕上显示传递的数据，也可以写入文件。Security Onion 的分析引擎使事情变得复杂，因为有许多不同的工具具有不同的操作程序，您很可能最终会忽略其中的大部分。Kibana 的界面为 Security Onion 提供了仪表板，它确实包含一些不错的图形和图表来简化状态识别。


10. 助手

《高级入侵检测环境》要写很多，所以这个IDS软件的开发者决定把它的名字缩写为AIDE。这是一个免费的 HIDS，专注于 Unix 和类 Unix 操作系统的 rootkit 检测和文件签名比较，因此它也适用于 Mac OS 和 Linux。


主要特点：

  • 创建配置基线

  • 回滚未经授权的更改

如果您考虑过 Tripwire，那么您最好还是看看 AIDE，因为这是该方便工具的免费替代品。Tripwire 有一个免费版本，但是大多数人需要从 IDS 获得的许多关键功能只能通过付费的 Tripwire 获得，因此您可以通过 AIDE 免费获得更多功能。


系统在首次安装时从配置文件编译管理数据数据库。这会创建一个基线，然后只要检测到系统设置的更改，就可以回滚对配置的任何更改。该工具包括签名和异常监控方法。系统检查是按需发出的，不会连续运行，这对于 HIDS 来说有点不足。但是，由于这是一个命令行函数，因此您可以安排它使用某种操作方法（例如 cron）定期运行。如果您想要接近实时的数据，您可以安排它非常频繁地运行。


11. 打开 WIPS-NG

如果您听说过 Aircrack-NG，那么您可能会对这个基于网络的 IDS有点谨慎，因为它是由同一位企业家开发的。Aircrack-NG 是一款无线网络数据包嗅探器和密码破解器，已成为每个 wifi 网络黑客工具包的一部分。


在 WIPS-NG 中，我们看到了一个偷猎者变成游戏管理员的案例。这个免费软件旨在保护无线网络。尽管 Aircrack-NG 可以在一系列操作系统上运行，但 Open WIPS-NG 只能在 Linux 上运行。“WIPS”这个名字代表“无线入侵防御系统”，所以这个NIDS既能检测入侵又能阻止入侵。

该系统包括三个要素：

  • 传感器模块

  • 服务器

  • 界面


有计划允许 WIPS-NG 安装监控多个传感器。但是，目前，每个安装只能包含一个传感器。这应该不是什么大问题，因为您只需一个传感器即可完成多项任务。传感器是一个数据包嗅探器，它也有能力在流中操纵无线传输。因此，传感器充当系统的收发器。


传感器收集的信息被转发到服务器，这就是魔法发生的地方。服务器程序套件包含将检测入侵模式的分析引擎。阻止检测到的入侵的干预策略也在服务器上产生。保护网络所需的操作作为指令发送到传感器。


12. Samhain

Samhain由德国Samhain Design Labs出品，是一款免费使用的基于主机的入侵检测系统软件。它可以在一台计算机或多台主机上运行，提供对每台机器上运行的代理检测到的事件的集中数据收集。


每个代理执行的任务包括文件完整性检查、日志文件监控和端口监控。这些进程会查找 rootkit 病毒、流氓 SUID（用户访问权限）和隐藏进程。该系统将加密应用于代理和多主机实施中的中央控制器之间的通信。用于交付日志文件数据的连接包括身份验证要求，可防止入侵者劫持或更换监控过程。


Samhain 收集的数据可以分析网络上的活动，并将突出显示入侵的警告信号。但是，它不会阻止入侵或清除流氓进程。您需要保留配置文件和用户身份的备份，以解决 Samhain 监视器显示的问题。


黑客和病毒入侵的一个问题是入侵者会采取措施隐藏。这包括终止监视进程。Samhain 部署了一种隐形技术来隐藏其进程，从而防止入侵者操纵或杀死 IDS。这种隐形方法被称为“隐写术”。


中央日志文件和配置备份使用 PGP 密钥进行签名，以防止被入侵者篡改。Samhain 是一个开源的网络入侵检测系统，可以免费下载。它是按照 POSIX 准则设计的，以使其与 Unix、Linux 和 Mac OS 兼容。中央监视器将汇总来自不同操作系统的数据。


13.Fail2Ban

Fail2Ban 是一个免费的基于主机的入侵检测系统，专注于检测日志文件中记录的令人担忧的事件，例如过多的失败登录尝试。系统会阻止显示可疑行为的 IP 地址。这些禁令通常只持续几分钟，但这足以破坏标准的自动暴力破解密码方案。此安全策略也可以有效抵御 DoS 攻击。管理员可以调整IP地址禁令的实际长度。


Fail2Ban 实际上是一个入侵防御系统，因为它可以在检测到可疑活动时采取行动，而不仅仅是记录和突出显示可能的可疑入侵。


因此，系统管理员在设置软件时必须小心访问策略，因为过于严格的预防策略很容易锁定真正的用户。Fail2Ban 的一个问题是它专注于来自一个地址的重复操作。这并没有赋予它应对分布式密码破解活动或 DDoS 攻击的能力。


Fail2Ban 是用 Python 编写的，它能够写入系统表以阻止可疑地址。这些自动锁定发生在 Netfilter、iptables、PF 防火墙规则和 TCP Wrapper 的 hosts.deny 表中。


系统的攻击监控范围由一系列过滤器定义，这些过滤器指示 IPS 监控哪些服务。其中包括 Postfix、Apache、Courier Mail Server、Lighttpd、sshd、vsftpd 和 qmail。每个过滤器都与检测到警报条件时要执行的操作相结合。过滤器和动作的组合称为“监狱”。该系统是按照 POSIX 标准编写的，因此可以安装在 Unix、Linux 和 Mac OS 操作系统上。


如何为您的网络选择 IDS 软件

基于网络的 IDS 解决方案的硬件要求可能会让您望而却步，并将您推向基于主机的系统，它更容易启动和运行。但是，不要忽视这样一个事实，即您不需要这些系统的专用硬件，只需要一个专用主机。


事实上，您应该考虑为您的网络同时获得 HIDS 和 NIDS。这是因为您需要注意计算机上的配置更改和 root 访问，以及查看网络流量中的异常活动。


好消息是我们列表中的所有系统都是免费或免费试用的，因此您可以试用其中的一些。如果您已经有一位有经验的同事，这些系统的用户社区方面可能会特别吸引您。从其他网络管理员那里获得提示的能力是这些系统的一个明确的吸引力。它使它们比具有专业帮助台支持的付费解决方案更具吸引力。


如果您的公司处于需要标准安全合规性的领域，例如 PCI，那么您确实需要适当的 IDS 解决方案。此外，如果您持有公众成员的个人信息，您的数据保护程序需要完善，以防止您的公司因数据泄露而被起诉。


尽管可能需要花费您整个工作日的时间来管理您的网络管理员托盘，但不要推迟安装入侵检测系统的决定。希望本指南已让您朝着正确的方向前进。如果您对自己喜欢的 IDS 有任何建议，并且您对本指南中提到的任何软件有使用经验，请在下面的评论部分留言，并与社区分享您的想法。


入侵检测系统常见问题

什么是 IDS 和 IPS？

IDS是入侵检测系统，IPS是入侵防御系统。IDS 可以检测对网络和主机资源的未授权访问，而 IPS 则可以完成所有这些工作，此外还实施自动响应以将入侵者拒之门外并保护系统免遭劫持或数据被盗。IPS 是一种 IDS，具有由检测到的入侵事件触发的内置工作流。


解释 Snort 与 OSSEC

Snort 和 OSSEC 都是开源 IDS。Snort 是基于网络的入侵检测系统 (NIDS)，而 OSSEC 是基于主机的入侵检测系统 (HIDS)。Snort 和 OSSEC 方法之间的主要区别在于，Snort 的 NIDS 方法在数据通过网络时对数据进行处理。OSSEC 的 HIDS 系统检查网络周围计算机上的日志文件以查找意外事件。Snort 和 OSSEC 都是领先的 IDS。


基于主机的入侵检测系统如何工作？

基于主机的入侵检测系统( HIDS ) 检查日志文件以识别未经授权的访问或对系统资源和数据的不当使用。基于主机的入侵检测系统的主要来源是 Syslog 和 Windows Events 生成的日志。虽然一些基于主机的入侵检测系统希望日志文件由单独的日志服务器收集和管理，但其他系统内置了自己的日志文件整合器，并收集其他信息，例如网络流量数据包捕获。


什么是主动和被动 IDS？

入侵检测系统( IDS ) 只需识别对网络或数据的未授权访问即可获得该称号。被动 IDS 将记录入侵事件并生成警报以引起操作员的注意。被动 IDS 还可以存储有关每个检测到的入侵和支持分析的信息。主动 IDS 也称为入侵防御系统( IPS ) 或入侵检测和防御系统( IDPS )，因为除了发现入侵外，它还实施自动化操作来阻止入侵者并保护资源。


IDS 是如何定义正常使用的？

IDS 可以使用两种方法来定义正常使用——一些 IDS 工具同时使用这两种方法。一种是将事件与攻击策略数据库进行比较，因此正常使用的定义是任何不会触发识别攻击的活动。另一种方法是使用基于人工智能的机器学习来记录定期活动。AI 方法可能需要一段时间来建立其正常使用的定义。 


什么是最好的入侵检测和预防系统？

我们的研究将最好的入侵检测和防御系统列为最佳入侵检测和防御系统，因为SolarWinds 安全事件管理器、 Snort、OSSEC 和 ManageEngine EventLog Analyzer 是本文中概述的领先系统。
