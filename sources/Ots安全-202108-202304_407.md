Thefatrat 一个海量的漏洞利用工具：生成后门的简单工具和发布浏览器攻击等漏洞利用攻击的简单工具。该工具使用流行的有效载荷编译恶意软件，然后编译的恶意软件可以在 windows、android、mac 上执行。使用此工具创建的恶意软件还能够绕过大多数 AV 软件...

  

TheFatRat是一种利用著名的payload 编译恶意软件的漏洞利用工具，编译后的maware 可以在Linux、Windows、Mac 和Android 上执行。TheFatRat提供了一种简单的方法来创建可以绕过大多数防病毒软件的后门和有效负载。

  

**信息**

此工具仅用于教育目的，未经双方事先同意，使用 TheFatRat 攻击目标是非法的。开发人员不承担任何责任，也不对本程序造成的任何误用或损坏负责。

  

**特征 ！**

*   全自动 MSFvenom 和 Metasploit。
    
*   本地或远程侦听器生成。
    
*   按类别操作系统轻松制作后门。
    
*   生成各种格式的有效载荷。
    
*   绕过防病毒后门。
    
*   可用于增加文件大小的文件泵。
    
*   检测外部 IP 和接口地址的能力。
    
*   自动创建用于 USB / CDROM 开发的 AutoRun 文件


**TheFatRat 故障排除**

chk\_tools 脚本在 fatrat 的 setup.sh 出现问题时使用该脚本将检查一切是否在正确的版本中运行 fatrat，并且还将为您提供问题的解决方案

*   
*   
*   

```
cd TheFatRatchmod +x chk_tools ./chk_tools
```
