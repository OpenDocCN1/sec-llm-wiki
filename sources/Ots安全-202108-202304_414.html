什么是原型污染？

JavaScript 是基于原型的：当创建新对象时，它们会继承原型“对象”的属性和方法，原型“对象”包含基本功能，例如toString、构造函数和hasOwnProperty。

基于对象的继承为 JavaScript 提供了 Web 程序员喜爱的灵活性和效率——但它也使其容易被篡改。

恶意行为者可以通过修改对象对所有对象进行应用程序范围的更改，因此名称原型污染。

有趣的是，攻击者甚至不需要直接修改对象——他们可以通过任何 JavaScript 对象的“ __proto__ ”属性访问它。一旦您对对象进行更改，它就会应用于正在运行的应用程序中的所有 JavaScript 对象，包括那些在篡改后创建的对象。

寻找预期的解决方案

我们先来看看lib/compiler.js中Hogan.compile()定义的：

在 [1] 处，options实例化一个 new Object，它继承了受污染的原型链。

在 [2] 中，它尝试在Hogan.cache. 由于Hogan.cache是Object继承的Object.prototype，我们可以使用可通过 访问的任意键/值来污染原型链Hogan.cache[key]。在[3]中，我们可以返回使用原型污染插入的攻击者控制的字符串。

转到 [4]，模板在 [5] 处生成并返回。

  • 我们执行原型污染来设置属性：Object.prototype.asString = '1'。

  • 循环时codeObj.partials，它找到一个键：codeObj.partials.asString，它是一个String。
