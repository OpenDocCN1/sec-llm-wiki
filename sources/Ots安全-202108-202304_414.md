**什么是原型污染？**

JavaScript 是基于原型的：当创建新对象时，它们会继承原型“对象”的属性和方法，原型“对象”包含基本功能，例如toString、构造函数和hasOwnProperty。

基于对象的继承为 JavaScript 提供了 Web 程序员喜爱的灵活性和效率——但它也使其容易被篡改。

恶意行为者可以通过修改对象对所有对象进行应用程序范围的更改，因此名称原型污染。

有趣的是，攻击者甚至不需要直接修改对象——他们可以通过任何 JavaScript 对象的“ \_\_proto\_\_ ”属性访问它。一旦您对对象进行更改，它就会应用于正在运行的应用程序中的所有 JavaScript 对象，包括那些在篡改后创建的对象。

**意外的解决方案**
