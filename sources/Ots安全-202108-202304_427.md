随着攻击面的扩大和威胁的日益复杂，仅对事件做出反应是不够的。日益复杂的环境为攻击者提供了多种机会。每个行业和每个组织都有自己独特的数据来保护，并使用自己的应用程序、技术等。所有这些都为执行攻击的可能方法引入了大量变量，并且每天都有新方法出现。

  

在过去几年中，我们观察到威胁类型和威胁行为者类型之间的界限越来越模糊。以前对少数组织构成威胁的方法和工具已传播到更广泛的市场。这方面的一个例子是 Shadow Brokers 组织倾销代码，该组织将高级漏洞利用给犯罪集团处置，否则这些犯罪集团就无法访问这种复杂的代码。另一个例子是高级持续威胁 (APT) 活动的出现，其重点不是网络间谍活动，而是盗窃——窃取资金以资助 APT 组织参与的其他活动。不胜枚举。

  

**需要一种新的方法**

随着企业越来越多地成为高级和有针对性的攻击的受害者，很明显，成功的防御需要新的方法。为了保护自己，企业需要采取积极主动的方法，不断调整其安全控制以适应不断变化的威胁环境。跟上这些变化的唯一方法是建立一个有效的威胁情报程序。

  

威胁情报已经成为各行各业和地域不同规模的公司建立的安全运营的关键组成部分。威胁情报以人类可读和机器可读的格式提供，可以在整个事件管理周期中为安全团队提供有意义的信息，并为战略决策提供信息。

  

然而，对外部威胁情报不断增长的需求催生了大量威胁情报供应商，每个供应商都提供大量不同的服务。一个具有无数复杂选项的广泛而竞争激烈的市场可能会使为您的组织选择正确的解决方案变得非常混乱和极其令人沮丧。

![](../Images/795d71d70944879ad0682422d4807397.png)

威胁情报驱动的安全操作

不适合您业务的具体情况的威胁情报可能会加剧问题。在当今的许多公司中，安全分析师花费了一半以上的时间来整理误报，而不是主动进行威胁搜寻和响应，从而导致检测时间显着增加。将不相关或不准确的情报提供给您的安全运营将导致错误警报的数量更高，并对您的响应能力和公司的整体安全产生严重的负面影响。

  

**最好的情报在哪里……**

那么，您如何评估众多威胁情报来源，确定与您的组织最相关的威胁情报来源，并有效地实施它们？在几乎每个供应商都声称其智能是最好的情况下，您如何应对大量毫无意义的营销？

  

这些问题虽然有效，但绝对不是您应该首先问的问题。许多组织被华而不实的消息和崇高的承诺所吸引，认为外部供应商可以为他们提供某种超能力的 X 射线视觉，完全忽略了最有价值的情报存在于您自己的公司网络范围内这一事实。

  

来自入侵检测和防御系统、防火墙、应用程序日志和其他安全控制日志的数据可以揭示很多关于公司网络内部发生的事情。它可以识别特定于组织的恶意活动模式。它可以区分普通用户和网络行为，帮助维护数据访问活动的踪迹，识别需要堵塞的潜在数据漏洞，等等。拥有这种可见性使公司能够实施外部威胁情报，将其与内部观察到的内容联系起来。否则，利用外部资源可能会很困难。事实上，一些供应商可能对网络威胁有更广泛的了解，因为他们的全球存在以及收集、处理和关联来自世界不同地区的数据的能力，

实施外部威胁情报

**像攻击者一样思考**

为了建立有效的威胁情报计划，公司，包括那些已建立安全运营中心的公司，必须像攻击者一样思考，识别和保护最有可能的目标。从威胁情报计划中获得真正的价值需要非常清楚地了解关键资产是什么，以及哪些数据集和业务流程对于实现组织的目标至关重要。识别这些“皇冠上的宝石”使公司能够在其周围建立数据收集点，以进一步将收集到的数据与外部可用的威胁信息进行映射。考虑到信息安全部门通常拥有的资源有限，分析整个组织是一项艰巨的任务。解决方案是采取基于风险的方法，首先关注最易受影响的目标。

  

一旦内部威胁情报源被定义和操作，公司就可以开始考虑将外部信息添加到其现有工作流程中。

  

**这是一个信任问题**

外部威胁情报来源的信任级别各不相同：

*   开源是免费的，但它们通常缺乏上下文并返回大量误报。
    
*   作为一个好的开始，请访问特定于行业的情报共享社区，例如金融服务信息共享和分析中心 (FS-ISAC)。这些社区提供了极其有价值的信息，尽管它们通常是封闭的，需要正式会员才能访问。
    
*   商业威胁情报来源要可靠得多，尽管购买它们的访问权限可能很昂贵。
    

选择外部威胁情报源的指导原则应该是质量而不是数量。一些组织可能认为，他们可以集成的威胁情报源越多，他们获得的可见性就越好。在某些情况下可能是这样——例如，当涉及高度可信的来源时，包括商业来源，提供针对组织的特定威胁概况量身定制的威胁情报。否则，它会带来很大的风险，用不相关的信息淹没您的安全操作。

  

专业威胁情报供应商提供的信息重叠可能非常小。由于他们的情报来源和收集方法各不相同，他们提供的见解在某些方面是独一无二的。例如，在特定地区占有重要地位的供应商将提供有关来自该地区的威胁的更多详细信息，而另一个供应商将提供有关特定威胁类型的更多详细信息。获得两种来源的访问权限可能是有益的；一起使用，它们可能有助于揭示更大的图景并指导更有效的威胁追踪和事件响应任务。但请记住，这些类型的可信来源也需要事先仔细评估，以确保它们提供的情报适合您组织的特定需求和用例，例如安全运营、事件响应、

  

评估商业威胁情报产品时要考虑的问题

仍然没有用于评估各种商业威胁情报产品的通用标准，但在执行此操作时需要牢记以下几点：

  

*   寻找具有全球影响力的情报。攻击没有国界——针对拉丁美洲公司的攻击可以从欧洲发起，反之亦然。供应商是否在全球范围内获取信息并将看似无关的活动整理成有凝聚力的活动？这种情报将帮助您采取适当的行动。
    
*   如果您正在寻找更具战略意义的内容来为您的长期安全规划提供信息，请寻求：
    

1.  攻击趋势的高级视图，
    
2.  攻击者使用的技术和方法，
    
3.  动机，
    
4.  权力等，
    
5.  然后寻找在持续发现和调查您所在地区或行业中的复杂威胁方面具有良好记录的威胁情报提供商。供应商根据贵公司的具体情况定制其研究能力的能力也很重要。
    

  

*   上下文从数据中产生智能。没有上下文的威胁指标没有价值——您应该寻找可以帮助您回答重要“为什么这很重要？”的供应商。问题。关系上下文（例如，与检测到的 IP 地址或从中下载特定文件的 URL 相关联的域）提供附加价值，通过发现网络中新获取的相关妥协指标，促进事件调查并支持更好的事件“范围界定”。
    
*   假设您的公司已经制定了一些安全控制措施，并定义了相关的流程，并且将威胁情报与您已经使用和了解的工具结合使用对您来说很重要。因此，寻找支持将威胁情报顺利集成到现有安全运营中的交付方法、集成机制和格式。
