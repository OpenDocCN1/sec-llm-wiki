Fuxploider 是一种开源渗透测试工具，可自动检测和利用文件上传表单缺陷的过程。该工具能够检测允许上传的文件类型，并能够检测哪种技术最适合在所需的 Web 服务器上上传 web shell 或任何恶意文件。

安装

您至少需要 Python 3.6。

git clone https://github.com/almandin/fuxploider.gitcd fuxploiderpip3 install -r requirements.txt

如果您在使用 pip 时遇到问题（如果您显然使用 Windows）：

python3 -m pip install -r requirements.txt

用于 Docker 安装

# Build the docker imagedocker build -t almandin/fuxploider .

用法

要获取基本选项和开关的列表，请使用：

python3 fuxploider.py -h

基本示例：

python3 fuxploider.py --url https://awesomeFileUploadService.com --not-regex "wrong file type"
