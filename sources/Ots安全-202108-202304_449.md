**什么是Pardus？**

Pardus 是 在土耳其政府的支持下开发 的 Linux 发行版。Pardus 的主要重点是与办公室相关的工作，包括在土耳其 政府机构中的使用。尽管如此，Pardus 以多种语言提供服务。它的易用性和免费可用性已经在世界各地催生了众多社区。\[1\]

  

在开发自己独特的身份之前，它作为一个基于 Gentoo 的项目开始了它的生命。自 2012 年底以来，该发行版基于 Debian GNU/Linux。

  

它是基于 Debian 的发行版。那么，目标在哪里？

2009 年，我曾经是 Pardus 的志愿者之一。在那个年代，这是一个非常出色且充满希望的项目。但是 Pardus 选择将他们的 Linux 基础转移到 Debian。据我所知，从 2012 年开始，他们主要围绕新内核开发包。

  

出于这个原因，我决定不加考虑地专注于包管理器的 GUI。

**开发**

1 – 执行 ARP 中毒攻击以成为中间人。

2 – 当 Pardus 用户打开 Pardus 软件中心应用程序时

3 – 应用程序将生成以下 HTTP 请求（http://store.pardus.org.tr/files/appicons.tar.gz）

4 – 截取 tar.gz 文件并将其替换为您自己的 tar.gz 文件，其中包含 ../../.ssh/authorized\_keys 以及您自己的 ssh 文件的公钥。

5-extractAll() 方法将使用我们自己的 tar.gz 文件执行。

6 – 不安全的 tar 提取完成后，您的公共 ssh 密钥将存储在用户的主文件夹下。这将使我们有机会通过 ssh 连接到目标！

7 – SSH 到您的公钥的盒子。

**额外发现：隐私问题：HTTP 上的 Mac 地址泄漏**

在研究过程中，我发现 Pardus 软件中心正在发送一个 HTTP POST 请求（到 store.pardus.org.tr ），其中包含用户单击应用程序图标时计算机的 MAC 地址。
