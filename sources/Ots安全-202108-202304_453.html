强调 ：-

以下是该框架的全部内容：

  • 一个完整的多功能框架，涵盖从侦察到漏洞分析的所有内容。

  • 有5个主要阶段，细分为14个子阶段，共108个模块。

  • 侦察阶段有自己的50个模块（包括主动和被动侦察，信息披露模块）。

  • Scanning & Enumeration Phase 有16个模块（包括端口扫描、WAF分析等）

  • 漏洞分析阶段有 37 个模块（包括最常见的漏洞在行动）。

  • 漏洞利用 Castle 只有 1 个漏洞利用。(purely developmental)

  • 最后，Auxiliaries 有 4 个模块。more under development

  • 所有四个阶段都有一个Auto-Awesome模块，可以为您自动化每个模块。

  • 通过多处理巨大的性能提升

  • 通过 Tor 进行管道攻击（尚未在所有地方实施）

  • 您只需要域名，一切都交给这个工具。

  • TIDoS 有完整的详细支持，所以你会知道发生了什么。

  • 现在使用新的 GUI 更容易攻击


主要新功能

  • 编程语言：TIDoS 完全移植到 Python3

  • 界面：TIDoS 提供了一个新的、类似 Metasploit 的控制台界面

  • 并行化：TIDoS 使用多处理来加速攻击

  • 一种替代 CLI 界面，用于与一个特定模块进行更快的交互

  • 匿名：可以通过 Tor 进行攻击（完成 95%）

  • 模块完成：一些模块已经进行了功能扩展（例如更多的逃避，支持超过 1 个查询参数）

  • 一些新模块：arpscan

  • 图形用户界面，可更轻松地与工具包进行交互

  • 支持非默认 http(s) 端口


即将到来

  • 模块的结果将存储在数据库中

  • 新模块：nikto&photon


安装 ：-

安装脚本（全局）：

要在 /opt 中全局安装框架，请core/install.py以 root 身份运行提供的脚本。之后，您只需tidos在命令行上键入即可启动 TIDoS 。


手动安装（本地）：

在本地克隆存储库并导航到那里：

git clone https://github.com/0xinfection/tidos-framework.gitcd tidos-framework

TIDoS 需要一些库才能运行，可以通过aptitude或dnf包管理器安装。

sudo apt-get install libncurses5 libxml2 nmap tcpdump libexiv2-dev build-essential python3-pip libmariadbclient18 libmysqlclient-dev tor konsole

现在这些依赖项安装完成后，我们需要安装剩余的 Python 包依赖项，因此运行：

pip3 install -r requirements.txt

TIDoS 使用 Vailyn 在一个新的、改进的路径遍历模块中扫描路径遍历。如果您想使用该模块，请前往https://github.com/VainlyStrain/Vailyn并按照那里的安装说明进行操作。


就是这样。您现在有 TIDoS 为您服务。使用以下命令启动它：

python3 tidv2               #Qt5 interfacesudo python3 tidconsole.py  #console interface

码头工人形象：

您可以从 Dockerfile 构建它：

git clone https://github.com/0xinfection/tidos-framework.gitcd tidos-framework/core/dockerdocker build -t tidos .

运行 TIDoS ：

docker run --interactive --tty --rm tidos bashtidos

更新：TIDoS 现在可在 Docker Hub 上使用。像这样安装和运行容器：

docker run -it vainlystrain/tidos-framework

更新 TIDoS ：

要获取当前版本的 TIDoS，请进入安装文件夹并执行(sudo) git pull #sudo if installed by install.py. 或者，您可以fetch在 tidconsole 中运行该命令。


入门 ：-

首先，您需要API KEYS为各种 OSINT & Scanning 和 Enumeration 目的设置自己的。要做到这一点，打开API_KEYS.py下files/目录，并设置自己的钥匙和访问令牌SHODAN，CENSYS，FULL CONTACT，GOOGLE和WHATCMS。
