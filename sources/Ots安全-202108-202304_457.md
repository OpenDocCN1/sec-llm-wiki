# 【漏洞预警】CVE-2021-22902 Action Dispatch 中可能存在拒绝服务漏洞

Action Dispatch 的 Mime 类型解析器中可能存在拒绝服务漏洞。该漏洞的 CVE 标识符为 CVE-2021-22902。

  

受影响的版本：>= 6.0.0 不受影响：< 6.0.0 固定版本：6.0.3.7、6.1.0.2

  

**影响**

Action Dispatch 中可能存在拒绝服务漏洞。精心设计的 Accept 标头可能会导致 Action Dispatch 中的 mime 类型解析器在正则表达式引擎中进行灾难性的回溯。

  

**发布**

固定版本可在正常位置获得。

  

**解决方法**

放置在初始化程序中的以下猴子补丁可用于解决此问题：

*   
*   
*   
*   
*   

```
module Mimeclass Type    MIME_REGEXP = /\A(?:\*\/\*|#{MIME_NAME}\/(?:\*|#{MIME_NAME})(?>\s*#{MIME_PARAMETER}\s*)*)\z/endend
```

**补丁**

为了帮助无法立即升级的用户，我们为两个受支持的版本系列提供了补丁。它们采用 git-am 格式，由单个变更集组成。

*   6-0-Prevent-catastrophic-backtracking-during-mime-parsin.patch - 6.0 系列补丁
    
*   6-1-Prevent-catastrophic-backtracking-during-mime-parsin.patch - 6.1 系列补丁
    

  

请注意，目前仅支持 6.1.Z、6.0.Z 和 5.2.Z 系列。建议早期不受支持版本的用户尽快升级，因为我们无法保证不受支持版本的安全修复程序的持续可用性。
