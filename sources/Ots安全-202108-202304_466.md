# 【漏洞利用】flatcore CMS XSS

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjYyMzkwOA==&mid=2247492960&idx=2&sn=b8e27aee5e087c3c0a2324bf33a7cdb1&chksm=9badac2bacda253dc78a9c95207fa37c27de6551df2dd633d1ccbe5a7b691bbb5bc806ce5c2f&scene=126&sessionid=1681670031#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjYyMzkwOA==&mid=2247492960&idx=2&sn=b8e27aee5e087c3c0a2324bf33a7cdb1&chksm=9badac2bacda253dc78a9c95207fa37c27de6551df2dd633d1ccbe5a7b691bbb5bc806ce5c2f&scene=126&sessionid=1681670031#rd)

  

点击上方蓝字“Ots安全”一起玩耍

通过上传图片功能描述跨站脚本（XSS）的漏洞

  

**重现**

重现行为的步骤：

1.  登录 flatcore CMS
    
2.  点击“上传文件”
    
3.  删除 svg 文件包含 XSS 负载，示例文件名：xss.svg
    
4.  和 url 中的 XSS：http://domain/content/images/payload1.svg
