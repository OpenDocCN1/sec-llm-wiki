**简介**

这是一个非常简单的 Linux 机器，它涉及通过 SSH 暴力破解用户凭据以获得初始访问权限，并利用启用了 Sudo 权限的 Tar 二进制文件将权限提升为 root。

  

**枚举**

首先要做的是对 1000 个最常见的端口运行 TCP Nmap 扫描，并使用以下标志：

*   \-sC 运行默认脚本
    
*   \-sV 枚举应用程序版本
    

![](../Images/8dfc3d9bb3e5b1361179ec1935138f9e.png)

扫描确定了三个开放端口：端口 21 (FTP)、端口 22 (SSH) 和端口 80 (HTTP)。下一步将开始枚举 FTP 和 HTTP。

  

**枚举FTP**

FTP 服务器启用了匿名身份验证，连接到服务器后，它会显示两个文本文件，下载它们：

![](../Images/b71015133edb4de8ce2a537f81ca10f9.png)

locks.txt 文件似乎包含一个单词列表，可能是一个密码列表：

![](../Images/627937f4f6e62decc63adf40886cddac.png)

由于第一个文本文件由“lin”签名，因此这可能是机器上的有效用户。使用 hydra 暴力破解密码，使用以下标志：

*   \-f 找到有效密码时停止攻击
    
*   \-l 指定暴力攻击的用户名
    
*   \-P 指定用于暴力攻击的词表
    
*   蛮力的服务和目标
    

![](../Images/29be06e8fe19fa5e9a6d909ec7f41f54.png)

Hydra 已成功识别“lin”用户的有效密码。通过 SSH 以 lin 身份进行身份验证：

![](../Images/765fbae056a8a199d1a47ac76741a246.png)

**权限提升**

执行 sudo -l 时，似乎 lin 用户可以以 root 身份执行 Tar：

![](../Images/eb6b28c631bb250a6495ac927abda81c.png)

在咨询 GTFOBins 后，似乎可以在以 sudo 身份运行时利用 tar。Tar 有一个名为 –checkpoint 的参数，它允许在每次存档 X 个文件时显示“进度”消息。这可以与 –checkpoint-action 标志连接使用，该标志允许在到达检查点时以二进制或脚本的形式执行操作。

![](../Images/332e2d82ffa6c9b7f94ae68a894051cd.png)

使用所需的标志执行 Tar，指示它在到达检查点后运行 /bin/sh：

![](../Images/ce2d42af681157d13515d7c37cc52538.png)

执行该命令后，将获得一个root权限 shell。

![](../Images/50da8a913339098254f9fb49e92c971c.png)
