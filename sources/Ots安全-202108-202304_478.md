Valve 修复了在其 Steam 平台中发现的 API 漏洞，该漏洞滥用 Smart2Pay 系统向玩家数字钱包添加无限资金。  

  

一名安全研究人员帮助游戏平台 Steam 的制造商 Valve 堵塞了一个易于利用的漏洞，允许用户向他们的数字钱包添加无限资金。只需更改帐户的电子邮件地址，该漏洞就可以让任何人人为地将他们的数字钱包增加到他们想要的任何东西。

  

Steam 钱包资金专用于 Steam 平台，用于购买游戏内商品、订阅和 Steam 相关内容。Valve 限制 Steam 点数（或金钱）被转移到其网络之外进行购买或交易。但是，有几种未经批准的方法可以将钱包资金转换为实际美元。

为 HackerOne 漏洞赏金计划工作的安全研究员 DrBrix于上周一报告了该漏洞。到周三，Valve 堵住了这个漏洞，并向 DrBrix 支付了 7,500 美元以识别错误。

  

**黑客：将 1 美元变成 100 美元或 100 万美元**

该漏洞已被修补，该漏洞是通过滥用 Valve 自己的应用程序编程接口 (API) 来利用的，该 API 用于与 Nuvei 拥有的第三方网络支付公司 Smart2Pay 进行通信。

  

根据 DrBrix 的说法，黑客允许攻击者拦截从 Valve 发送到 Smart2Pay 的 POST 请求。这是通过修改 Smart2Pay 在通过 Valve API 时使用的 Steam 用户电子邮件地址来完成的。

  

“首先，您必须将您的 Steam 帐户电子邮件更改为类似（我将在接下来的步骤中解释为什么金额 100 是重要部分）：brixamount100abc@█████，”研究人员写道。

  

这允许攻击者操纵 Valve 和 Smart2Pay 之间的通信，绕过用于保护交易数据的加密哈希。

  

“我们无法更改参数，因为有带有签名的哈希字段，但是签名是像哈希（ALL\_FIELDS\_NAMES\_VALUES\_CONTACTED）一样生成的，”DrBrix 写道。“因此，通过我们的特殊电子邮件，我们可以通过改变数量的方式来移动参数。”

  

**Valve 参数可能在哪里，**

“hash(MerchantID1102MerchantTransactionID█████Amount2000.....)”攻击者只需更改电子邮件请求的格式即可将1美元变成100美元。

  

“因此，通过我们的特殊电子邮件，我们可以通过改变数量的方式移动参数。例如，我们可以把原来的Amount=2000改为Amount2=000，联系后还是Amount2000。然后我们可以将电子邮件从 CustomerEmail=brixamount100abc%40████ 更改为 CustomerEmail=brix&amount=100&ab=c%40█████████，这样我们就可以用我们的值添加新的字段金额，”DrBrix 写道。

  

Valve首先将这个漏洞评为中等重要性。然而，在调查之后，它将该漏洞升级为本质上的严重漏洞，将其评分为“9-10”，最高评分为 10。

  

Valve 没有回复 Threatpost 媒体的置评请求。

  

“我们已将严重性评估更改为严重，反映了业务的潜在成本，并相应地应用了赏金，”Valve 在 HackerOne 线程中写道，感谢 DrBrix 的提示。
