function waf($input){
  if(is_array($input)){
      foreach($input as $key=>$output){
          $input[$key] = waf($output);
      }
  }else{
      $input = check($input);
  }
}

    case 'pwd':

    case 'upload':

阅读代码，发现生成一个文件夹，当action参数为pwd时候，打印该路径。当action为upload，且存在data参数，对data参数进行过滤后写入生成文件夹下的index.php文件。

首先是过滤部分，过滤了较多参数，包括空格，分号，php等，无法直接写入php一句话或者其他木马。
本人较菜，尝试了好多都是失败。最终想到了<?=code?> 形式。
接下来就是考虑如何绕过check函数的检查内容了。

查看check函数过滤的内容，基本常见展示文件内容的指令都被过滤了。
关于显示文件内容可以使用的指令

因为参数可以是数据，因此可以通过将关键字拆分的形式，绕过单个参数的过滤
具体payload可以为data[0]=<?=ca&data[1]=t?>绕过check部分关键字的过滤。

其他的未在过滤部分的指令 举例如 more等
