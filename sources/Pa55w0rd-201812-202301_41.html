0x00 前言

上周一台web服务器部署单机版OpenRASP之后感觉还不错，想在公司内部推广一下，准备在一些后台系统的服务器上安装agent，单机版部署报警日志查看不是很方便，遂部署管理后台方便管理

官方文档：https://rasp.baidu.com/doc/
单机版部署：https://www.pa55w0rd.online/openrasp/

0x01 准备

OpenRASP使用了 ElasticSearch 和 MongoDB 两种数据库。前者用来存储报警和统计信息，后者用来存储应用、账号密码等信息。

自己机器上有mongodb 3.2 和 elk套件7.1.1，这里对数据库版本有要求

  • MongoDB 版本大于等于 3.6

  • ElasticSearch 版本大于等于 5.6，小于 7.0

好吧，都不符合，重新安装找台服务器安装MongoDB 和 ElasticSearch吧

MongoDB 安装

官方手册：https://docs.mongodb.com/manual/tutorial/install-mongodb-on-red-hat/

安装mongodb社区版，目前最新版为4.2

  1. 创建仓库

vi /etc/yum.repos.d/mongodb-org-4.2.repo

  1. 复制

[mongodb-org-4.2]
name=MongoDB Repository
baseurl=https://repo.mongodb.org/yum/redhat/$releasever/mongodb-org/4.2/x86_64/
gpgcheck=1
enabled=1
gpgkey=https://www.mongodb.org/static/pgp/server-4.2.asc

  1. yum命令安装mongodb

yum install -y mongodb-org

  1. 启动服务

systemctl start mongod

  1. 使用

mongo

  1. 卸载

yum erase $(rpm -qa | grep mongodb-org)
删除数据目录
rm -r /var/log/mongodb
rm -r /var/lib/mongo

  1. 启用认证

vi /etc/mongod.conf
security:
  authorization: enabled

0x02 管理后台安装

  1. 编辑 conf/app.conf 文件，修正 ElasticSearch 和 MongoDB 两个服务器的地址

[prod]

EsUser =
EsPwd =
MongoDBAddr = 127.0.0.1:27017
MongoDBUser =
MongoDBPwd =

  1. 启动后台服务器:

./rasp-cloud -d
