## Centos7 安装PHP 7

通过yum安装报错，只能通过源码编译安装，速度比较慢

## 安装compoeser

```
1.  `下载安装脚本 － composer-setup.php － 到当前目录。`
    
2.  `# php -r "copy('https://install.phpcomposer.com/installer', 'composer-setup.php');"`
    
3.  
    
4.  `执行安装过程`
    
5.  `# php composer-setup.php`
    
6.  
    
7.  `删除安装脚本`
    
8.  `# php -r "unlink('composer-setup.php');"`
    
9.  
    
10.  `全局安装`
     
11.  `# mv composer.phar /usr/local/bin/composer`
     
12.  
     
13.  `切换为国内镜像`
     
14.  `# composer config -g repo.packagist composer https://packagist.phpcomposer.com`
     
15.  
     
16.  `更新 composer`
     
17.  `# composer selfupdate`
     
18.  
     
19.  `安装依赖`
     
20.  `# composer install`
     
```

更多请参考Composer 安装与使用https://www.runoob.com/w3cnote/composer-install-and-usage.html
