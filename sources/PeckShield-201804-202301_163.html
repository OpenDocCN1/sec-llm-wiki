据Ethereum Bounty Program 8月2日消息：凭借三个独立的漏洞报告，区块链安全公司PeckShield获得了由以太坊基金会颁发的12000USD奖金，并跻身赏金猎人排行榜TOP 5。


  • Geth DoS via discovery protocol (2000 points)

  • LES Server DoS via malicious query (5000 points)

  • LES Server DoS via AnnouceMsg (5000 points)


（ Bounty Hunters 排行榜）


获奖漏洞简介：


漏洞①：CVE-2018-11673：Geth DoS via discovery protocol

简介：这是一个以太坊Geth discovery协议实现缺陷漏洞，黑客可向存在该漏洞的节点发动攻击，使受影响节点耗尽内存而卡死。

漏洞②：CVE-2018-12018：LES Server DoS via malicious query

简介：这是一个Geth LES协议实现缺陷漏洞，黑客可以向存在该漏洞的节点发送恶意构造的“ GetBlockHeadersMsg”报文，导致受影响节点发生内存越界访问而迅速崩溃。

漏洞③：CVE-2018-12567:   LES Server DoS via AnnouceMsg

简介：这是一个Geth LES协议实现缺陷漏洞，黑客可以向存在该漏洞的节点发出恶意构造的“AnnounceMsg”报文，致使受影响节点耗尽内存而卡死。

备注：（此次以太坊基金会发出的奖励公告，只是我们发现的以太坊系列漏洞中已被修复公开的三个。②已于6月28日在硅谷Blockchain Connect Conference大会现场演示披露，①和③以及其它漏洞详情，我们将在9月初的ISC 2018大会上或其它时间择机进行披露，敬请关注。）

PeckShield的漏洞发现能力和安全服务

整个区块链行业目前遵循着底层公链——解决方案——行业应用的发展逻辑，底层公链是生态基础，解决方案是为了拓展底层公链性能，行业应用是基于公链的垂直场景落地实现。

以太坊ETH代表着区块链迎来了2.0时代，通过智能合约的方式，可实现广大分布式DApp行业应用的拓展，是当前区块链技术应用的最重要的底层公链。其系统底层架构和协议的实现安全与否，关乎着整个区块链生态的“命脉”，一旦出现漏洞被恶意利用会造成难以估量的经济损失。以太坊历史上著名的“Spurious Dragon”、“Tangerine Whistle”等硬分叉事件均是为了弥补安全漏洞或底层公链设计缺陷而采取的防范措施。这也让整个区块链从业人员开始意识到底层公链安全的重要性。

事实上，底层公链的安全问题是一个容易被忽略的攻击重灾区，一方面是因为公链项目目前处于持续迭代发展的阶段，安全漏洞的出现难以避免；另一方面，底层公链更容易受到来自黑客7*24小时的攻击，很难做到完全抵御；最为关键的是，针对底层公链架构的安全分析是一项系统性的宏大工程，其漏洞发掘耗时耗力，对安全研究人员的综合能力要求较高，目前针对公链进行研究的安全团队也相对较少。

凭借过往在移动端Android系统安全领域的深厚积累，PeckShield安全研究人员具有对复杂系统的深入研究能力，且在区块链安全事件进入大众视野之前就提前做了钻研和布控，因此在区块链底层公链的漏洞发现上具有先发竞争优势。围绕底层公链，我们的纵向安全服务覆盖基础设施、数据层、网络层、共识层、激励层、合约层、业务层等。目前来看，75%的攻击都来自合约层和业务层，但来自共识层和协议层的漏洞威胁也不容忽视，比如：此次曝出的以太坊“致命报文”漏洞，攻击者通过发送一个恶意报文，向存在该漏洞的geth节点发动攻击，可导致以太坊三分之二的节点瞬间停摆。值得一提的是，除了以太坊公链上的一系列漏洞发现之外，围绕EOS生态，PeckShield先后在EOS主网映射率，高危账号EOSRescuer公共查询服务等社区生态安全层面都展开了积极的探索。

另外，PeckShield的安全服务范围已经横向覆盖到交易所、矿池、钱包、合约、DApp等区块链生态的各个环节。今年上半年因连续发现并命名了BEC、SMT、EDU等智能合约的重大安全漏洞，而广受业内关注。PeckShield通过对链上的数据进行整理分析，发现一些安全问题的存在，并做针对性的应急解决方案，避免可能造成的安全隐患和资产损失。


关于PeckShield：


PeckShield（派盾）是面向全球的业内顶尖区块链安全团队，由前360首席科学家、美国北卡州立大学终身教授蒋旭宪博士创办，团队核心成员为海归博士及清华博士，过去在移动安全方面有深厚的积累，先是2012年，率先进行了全球第一个智能手机上的恶意软件基因组研究，目前该研究成果已被全球超过500所的科研机构和知名跨国公司采用。此后又于2014年首次发现了特斯拉汽车的应用程序安全漏洞。成立PeckShield以来，今年上半年因连续发现并命名了BEC、SMT、EDU等智能合约的重大安全漏洞，而广受业内关注。
