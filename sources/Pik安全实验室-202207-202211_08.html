四、继承

如果我们遇到了这样的情况，我们需要去写小学生、初中生、高中生这些类，他们都有共享的方法以及各自的方法，如果每个都去这么写，未免感觉重复、啰嗦、繁琐，这个时候就需要用到继承。

1. 通过this继承

我们看这样的一个例子：

<!DOCTYPE HTML>
<html>
    <head>
        <title>
            test
        </title>
        <meta charset="UTF-8">
    </head>
    <body>
        <script text="text/javascript">
            //定义一个父类
            function Student(name,age){
                this.name = name;
                this.age = age;
                this.show_name_and_age = function(){
                    alert(this.name + "，年龄" + this.age)
                }
            }
            function MidStu(name,age){
                this.student = Student;
                this.student(name,age);
                this.pay = function(pocket_money){
                    alert("中学生的零用钱有" + pocket_money + "元。")
                }
            }
            function Pupil(name,age){
                this.student = Student;
                this.student(name,age);
                this.run = function(){
                    alert("小学生喜欢跑步。")
                }
            }

            //实例化类
            var midstu_1 = new MidStu("中学生1",14);
            var pup_1 = new Pupil("小学生1",10);

            //子类调用父类的方法
            midstu_1.show_name_and_age();
        </script>
    </body>
</html>

得到：

发现继承成功，子类成功调用了父类的show_name_and_age的方法。

2. 通过call继承

我们只需要把上述代码中的这两行：

this.student = Student;
this.student(name,age);

替换为下面这个即可。

Student.call(this,name,age);

效果是完全一样的。

原理就是通过call来修改Student构造函数的this指针的指向，让Student构造函数指向了call所在函数的本身。

3. 通过apply进行继承

把上述代码中的Student.call(this,name,age);替换为Student.apply(this,[name,age]);即可，效果是一样的。

七、多态

所谓多态，用人话说，就是对象或者变量在不同情况下的多种状态。由于javascript本身无态，所以它本身支持多态。

举一个简单的例子来说明多态的含义：

定义三个大类：人类、动物类、食物类；以及人类的一个动作类。人通过动作来将食物投递给动物，这个就是多态。

<!DOCTYPE HTML>
<html>
    <head>
        <title>
            test
        </title>
        <meta charset="UTF-8">
    </head>
    <body>
