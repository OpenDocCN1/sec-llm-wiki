0x01 工具介绍

Pwer是一款多线程目录探测工具，能够快速收集目录，多种匹配响应码的颜色，经前期测试稳定，后续将根据用户体验做更新，欢迎师傅反馈bug，项目内带有大字典，可根据自己收集的字典做更新。

0x02 使用方法

1、首先在将需要字典放在dict.txt文件中，或将用的字典改为名为dict.txt

2、结果会在output.txt文件中


3、到Pwer目录下，安装库 pip install -r requirements.txt

-u --url 输入url http://ip:port
-t --thread 线程
-mc --match 匹配响应码
