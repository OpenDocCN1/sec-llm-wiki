➤【信息安全漏洞周报】


    根据国家信息安全漏洞库（CNNVD）统计，本周（2021 年 3 月 15 日至2021 年 3 月 21 日）安全漏洞情况如下：


    ➤ 公开漏洞情况 

   本周 CNNVD 采集安全漏洞 239 个，与上周（356 个）相比减少了 32.87%。 

    ➤ 接报漏洞情况 

    本周 CNNVD 接报漏洞 3430 个，其中信息技术产品漏洞（通用型 漏洞）15 个，网络信息系统漏洞（事件型漏洞）3415 个。


    ➤ 公开漏洞情况 

    根据国家信息安全漏洞库（CNNVD）统计，本周新增安全漏洞 239 个，漏洞新增数量有所下降。从厂商分布来看 WordPress 基金会新增 漏洞最多，有 27 个；从漏洞类型来看，跨站脚本类的安全漏洞占比 最大，达到 15.06%。新增漏洞中，超危漏洞 23 个，高危漏洞 60 个， 中危漏洞 150 个，低危漏洞 6 个。相应修复率分别为 86.96%、88.33%、 78.00%和 100.00%。

    根据补丁信息统计，合计 196 个漏洞已有修复补丁发布，整体修复率为 82.01%。

1. VMware vCenter Server 安全漏洞（CNNVD-202103-927）

    VMware vCenter Server 是美国威睿（VMware）公司的一套服务 器和虚拟化管理软件。该软件提供了一个用于管理 VMware vSphere 环境的集中式平台，可自动实施和交付虚拟基础架构。

    vCenter Server 存在安全漏洞，攻击者可利用该漏洞导致远程代码执行。    

    目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

    https://security.netapp.com/advisory/ntap-20210315-0001/


2. Linux kernel 安全漏洞（CNNVD-202103-961）

    Linux kernel 是美国 Linux 基金会的开源操作系统 Linux 所使用的内核。

    Linux kernel through 5.11.6 存在安全漏洞，该漏洞源于 fastrpc.c 不阻止用户应用程序发送内核 RPC 消息。

    目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

    https://git.kernel.org/pub/scm/linux/kernel/git/torvald s/linux.git/commit/?id=20c40794eb85ea29852d7bc37c55713802a5 43d6


3. Adobe Acrobat 和 Adobe Acrobat Reader 安全漏洞（CNNVD-202103-1146）

    Adobe Acrobat和Adobe Acrobat Reader都是美国奥多比（Adobe） 公司的产品。

    Adobe Acrobat 是一套 PDF 文件编辑和转换工具。Adobe Acrobat Reader 是一款 PDF 查看器。该软件用于打印，签名和注释 PDF。

    Adobe Acrobat 和 Adobe Acrobat Reader 存在安全漏洞，该漏洞允许 CoolType 任意堆栈操作。

    目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

    https://helpx.adobe.com/security/products/acrobat/apsb21-09.html
