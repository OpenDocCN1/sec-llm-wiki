### 前言

Crobat利用的是Rapid7 Sonar开源的DNS数据集

详情：https://opendata.rapid7.com

### 安装&使用

先安装Golang

安装crobat-client：

```
go get -u github.com/cgboal/sonarsearch/crobat-client
```

使用`--init`参数设置`Crobat`服务器：

这里使用0x00sec搭建的公共Crobat服务器

https://sonar.omnisint.io

> sonar.omnisint.io443

```
crobat-client --init
Host : sonar.omnisint.io
Port: 443
```

查询子域：

```
crobat-client -s polaris-lab.com
```

指定格式显示，json：

```
crobat-client -s polaris-lab.com -f json
```

结合aquatone探测端口及截图：

https://github.com/michenriksen/aquatone 不做过多介绍，也是一款很好用的信息收集工具

```
crobat-client -s polaris-lab.com | aquatone -ports 80,443,8080,8081,8000,8443,8001,9000 -scan-timeout 20000 -debug
```
