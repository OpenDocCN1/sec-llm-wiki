CrowdStrike Falcon的默认安装程序在C:\ProgramData\Package Cache\目录下，找不到的可以通过WindowsSensor关键字搜索：

如图，可以看到WindowsSensor.exe提供了一些命令行选项，包括安装、卸载、修复、暂停。

先试试使用/quiet选项暂停Sensor服务：

如上图，测试发现暂停Sensor服务之后，在没有启用Sensor的情况下CrowdStrike Falcon会重新安装，所以暂停功能并没有什么卵用。

我们只能选用卸载Sensor的方式，如下图命令：

这样成功卸载掉了CrowdStrike Falcon Sensor。

写一段PowerShell来实现以上操作：

$AppsToRemove = @(

‘CrowdStrike Sensor Platform’

‘CrowdStrike Falcon Sensor’

‘CrowdStrike Windows Sensor’)

$RegKeys = @(‘HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\’

‘HKLM:\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\’)



$Apps = $RegKeys|Get-ChildItem|Get-ItemProperty|Where-Object { $AppsToRemove -contains $_.DisplayName -and $_.UninstallString }



foreach( $App in $Apps ){$UninstallString = if( $App.Uninstallstring -match ‘^msiexec’ )

{ “$( $App.UninstallString -replace ‘/I’, ‘/X’ ) /quiet /qn /norestart”} else {$App.UninstallString}

Start-Process -FilePath cmd -ArgumentList ‘/c’, $UninstallString -NoNewWindow -Wait -ErrorAction SilentlyContinue }

最后一个问题，在一顿操作之后如何将Sensor安装回去：

在 https://www.crowdstrike.com/request-information 注册使用获取CID，然后使用如下命令重新安装：

WindowsSensor.exe /install /quiet /norestart CID=<ID>
