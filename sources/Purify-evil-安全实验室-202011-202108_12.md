#实现使用break作用循环#作用：跳出循环，只要执行break，循环不再执行#特点：循环中，break后面的代码不在执行#注意：break只能作用于当前一层while循环# 定义变量计数a = 1 #自然计数法#while 后面加判断while a <= 10:    print("吃了 %d 个" % a)#吃到第三个苹果时退出循环    if a == 3:        break        # 返回结果:        # 吃了 1 个        # 吃了 2 个        # 吃了 3 个        # 程序结束
#修改循环计数    a += 1print("程序结束")
print("-"*10,"分割线","-"*10)
# continue作用于循环：# 作用：continue不会终止循环，会跳过本次循环，进行下一次循环# 注意:修改循环变量，放在continue之后容易出现死循环（建议放置在循环变量前）# continue只能作用于当前一层whlie循环#定义变量计数a = 1 #自然计数法#while 后面加判断while a <= 5:    # 修改循环计数,放在continue后会变成死循环    a += 1#吃到第三个苹果时退出本次循环，进入下一次    if a == 3:        continue #跳过本次循环，进行下一次循环    print("吃了 %d 个" % a)    # 返回结果：    # 吃了 2 个    # 吃了 4 个    # 吃了 5 个    # 吃了 6 个    # 程序结束
print("程序结束")
