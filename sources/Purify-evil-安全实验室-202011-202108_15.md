# 目标：输出❤5次的三种方法# 1.直接打印输出# print("❤")# print("❤")# print("❤")# print("❤")# print("❤") # 2.乘于输出# print("❤" * 5) # 3. whlie循环输出# 占位符：%d（数字） %s（字符串） %f（浮点数/小数/默认保留六位，可以使用%.xf指定x保留几位） %%（两个百分号表示一个百分号）# 基本语法格式:# 定义一个变量为计数器# while 条件(判断 计数器 是否达到目标次数)#     条件满足时，做的事情1#     条件满足时，做的事情2#     条件满足时，做的事情3#     条件满足时，做的事情4#     ......(省略).....#     处理条件(计数器+1) # 1.定义一个变量记录循环次数count = 1# 2.whlie 后面添加条件判断"while count <= 5:    print("❤ count = %s" % count)  #3.条件满足时执行缩进部分代码    # 4.修改循环变量，相当于下一次循环    count += 1  #相当于count = count+1  #这一步注释掉就会变成死循环print("循环结束") # 死循环# 概念:死循环是一种现象# 原理:在while循环内部没有 修改循环变量，导致while后面条件判断一 致成立 ,一直执行缩进部分代码,无法退出循环的现象# 注意:如果没有特殊的需求,要避免死循环，带有打印死循环非常耗费计算机的性能，死循环也有妙用,比如windows窗体界面的显示
