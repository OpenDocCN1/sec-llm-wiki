10.字符串的查找与替换：

1.字符串的查找：

1.string.startswith(str)

判断：变量名.startswith(字符串) 检查字符串是否以xxx开头，是则返回True,否则返回False/可以查询多个字符串

  1. my_str = "hello,python,python"
  2. #单个字符串
  3. print(my_str.startswith("h")) #返回True，是以h开头的
  4. print(my_str.startswith("e")) #返回False，不是以e开头的
  5. #多个字符串
  6. print(my_str.startswith("hello")) #返回True，是以h开头的
  7. print(my_str.startswith("ello")) #返回False，不是以e开头的

2.string.endswith(str)

判断：变量名.endswith(字符串) 检查字符串是否以xxx结束，是则返回True,否则返回False/可以查询多个字符串

  1. my_str = "hello,python,python"
  2. #单个字符串
  3. print(my_str.endswith("n")) #返回True，是以n结尾的
  4. print(my_str.endswith("o")) #返回False，不是以o结尾的
  5. #多个字符串
  6. print(my_str.endswith("python")) #返回True，是以n结尾的
  7. print(my_str.endswith("pytho")) #返回False，不是以o结尾的

3.string.find(str, start=0,end=len(string))

判断：变量名.find(字符串) 在指定范围内查找字符串的索引值，找到则返回索引值，未找到则，返回-1，往下的代码依旧执行

  1. my_str = "hello,python,python"
  2. print(my_str.find("h")) #已查到到，返回索引值0
  3. print(my_str.find("j")) #未查找到，返回-1
  4. print(my_str.find("python")) #返回最左边第一个字符串的索引值6

变量名.find("查找内容", 从第几个索引值开始查找，len（查找范围））/PS：通过数据获取索引的index函数报错后后面的代码无法正常执行，而find函数可以正常执行

  1. my_str = "hello,python,python"
  2. print(my_str.find("python", 7)) #指定查找范围，从8索引值往后查找最左边第一个字符串的索引值
  3. print(my_str.find("python", 7, len(my_str))) #指定范围内查找
  4. print(my_str.find("java", 1, len(my_str))) #指定范围内字符串查找不到返回 -1
  5. print("上行代码报错是否会继续执行？") #这行代码依旧执行

11.字符串的拆分与拼接

1.拆分：

string.split(str="",num) 以str为分隔符拆分string

格式：字符串.split("分隔符",分隔次数)

str默认包含'\r' '\t' '\n' 和空格，返回列表

  1. info_str = "hello,python,java"
  2. print(info_str.split(",")) #返回列表['hello', 'python', 'java']
  3. print(info_str.split(",",1)) #指定切分次数,返回列表['hello', 'python,java']
  5. #切分字符串不适用，切分字符一般安装逗号来切,如果以字符串来切就会破坏原来的数据结构
  6. print(info_str.split("python")) #返回列表['hello,', ',java']，可以看到返回直接切没了原来的数据

 2.转义字符切分：具有特殊功能的字符串：

\r 回车符
\t Tab键
\n 换行符 linux/unix操作系统换行符
'  ' 空格
\r\n windows系统换行符

string.split(str="",num) 以str为分隔符拆分string

格式:字符串.split("指定转义字符在字符串内")


如果split没有定义切分，会以转义字符切分,通过指定分隔符对字符串进行切片

  1. info_str = "hell\ro,py\tthon,ja va"
  2. print(info_str.split()) #返回列表 ['hell', 'o,py', 'thon,ja', 'va']

splitlines()按照行('\r', '\r\n', \n')分隔字符串，返回一个包含各行作为元素的列表

  1. info_str = "hell\ro,p\r\nython,ja\nva" #返回列表 ['hell', 'o,p', 'ython,ja', 'va']

12. 字符串切片

作用：从大字符串中切出小字符串
切片的范围，包含开始位置索引，不包含结束位置索引，只能获取到结束位置索引值的前一个字符，获取数据需要调整步长，步长1可以省略

 

定义一个字符串

  1. 索引：012345.....11 
  2. info_str = "hello,python"

1.切出字符串hello

格式：字符串名[开始位置索引值：结束位置索引值：步长]

  1. 索引：012345.....11 
  2. info_str = "hello,python"
  1. print(info_str[0:5:1])
  2. print(info_str[0:5:]) #步长为正1时可以省略
  3. print(info_str[0:5]) #步长为正1时冒号可以省略
  4. print(info_str[:5]) #开始位置索引值是字符串的边界，开始位置索引值可以省略

2.切出字符串python

  1. 索引：012345.....11 
  2. info_str = "hello,python"
  1. print(info_str[6:12:1])
  2. print(info_str[6:12]) #步长为正1时冒号可以省略
  3. print(info_str[6:])  #结束位置索引值是字符串的边界，结束位置索引值可以省略

3.切出字符串 开始索引值为6，切到字符串结束位置，步长为2

  1. 索引：012345.....11 
  2. info_str = "hello,python"
  1. print(info_str[6::1]) #返回python，步长为1
  2. print(info_str[6::2])#返回pto，步长为2，从开始索引隔一个字符串取

4.倒叙切片 步长是负数

  1. 索引：012345.....11 
  2. info_str = "hello,python"
  1. print(info_str[-1:-7:-1]) #开始位置索引值是字符串的边界，开始位置索引值可以省略
  2. print(info_str[:-7:-1])
  3. print(info_str[11:5:-1])  #结束位置索引值是字符串的边界，结束位置索引值可以省略
  4. print(info_str[:5:-1])

5.面试题 - 字符串的逆序

  1. info_str = "hello,python"
  2. print(info_str[:-13:-1]) #开始位置索引值是字符串的边界，开始位置索引值可以省略
  3. print(info_str[::-1]) #结束位置索引值是字符串的边界，结束位置索引值可以省略
  5. print(info_str[11::-1]) #开始位置索引值是字符串的边界，开始位置索引值可以省略
  6. print(info_str[::-1]) #结束位置索引值是字符串的边界，结束位置索引值可以省略

 

  1. 切片中开始索引或结束索引涉及到字符串的边界，则开始索引或结束索引可以省略

  2. 正序切片，从左往右，如果字符串结束索引是字符串的末尾，则字符串索引可以省略。

  3. 步长为1，步长可以省略，步长前面的冒号也可以省略

  4. 像问卷调查表 => 字典：主要用来存储一个人物或事物的详细信息的

18:字典中的注意事项

1.字典中的键key是唯一的

字典中有相同的键key对应不同的值，后面的键值对会替换前面的键值对

  1. my_dict = {"name":"常威","age":30,"high":180.5,"age":40,"age":50}
  2. print(my_dict) #返回{'name': '常威', 'age': 50, 'high': 180.5}后面的键值对会替换前面的键值对

2.字典中的key键的数据类型，可以是除了列表和字典以外的所有数据类型

          字典名{key:value}

  1. info_dict = {"name":"来福",100:"一百",12.3:"小数",True:"是真的",(10,20,30):"元组"}
  2. # info_dict = {"name":"来福",100:"一百",12.3:"小数",True:"是真的",[10,20,30]:"列表"} TypeError: unhashable type: 'list'
  3. # 注意：列表不能作为字典的键
  4. # info_dict = {"name":"来福",100:"一百",12.3:"小数",True:"是真的",{"one":1,"two":2}:"字典"}  #TypeError: unhashable type: 'dict'
  5. # 注意：字典本身也不能做字典的键
  6. print(info_dict) #返回字典 {'name': '来福', 100: '一百', 12.3: '小数', True: '是真的', (10, 20, 30): '元组'}
  7. print(type(info_dict)) #返回字典类型 <class 'dict'>

3.字典是无序的数据容器

判断字典数据是否相同:

  1. my_dict_1 = {"name":"常威","age":30,"high":180.5}
  2. my_dict_2 = {"high":180.5,"name":"常威","age":30}
  3. print(my_dict_1 == my_dict_2) #返回True，只需要字典里的键值成对匹配即可,因为字典是无序的数据容器
  6. my_dict_1 = {"name":"常威","age":30,"high":180.5}
  7. my_dict_2 = {"high":180.5,"name":"常威","age":30,"gender":"男"}
  8. print(my_dict_1 == my_dict_2) #返回False，字典内的成对键值不匹配
