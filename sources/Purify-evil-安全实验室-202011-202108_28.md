# 字典的定义：# 字典用来存储的数据数据的高级容器(字典中的数据是无序)# 字典 主要用来存储一个人或事物的详细信息的# 不能通过索引的方式访问# 像问卷调查表 => 字典：主要用来存储一个人物或事物的详细信息的# 姓名：         王权富贵# 年龄：         22# 性别：         男# 身高：         178.8# 键key：        值(value)# 字典中以键值成对的方式来存储数据的# 格式： {key1:value1, key2:value2, key3:value3 ...}# 空字典： 字典名 = {} 或 字典名 = dict{}my_dict = {"name":"王权富贵", "age":22, "gender":"男", "stature":178.8}print(my_dict)print(type(my_dict))print("-"*50)  # 访问字典：不能通过索引访问，字典是无序数据容器# print(my_dict[0]) KeyError: 0 # 注意：字典通过 键(key) 来访问的，键和值之间使用：冒号隔开， 键值成对的以，逗号隔开# 字典名[key]my_dict = {"name":"王权富贵", "age":22, "gender":"男", "stature":178.8}print(my_dict["name"])print(my_dict["age"], my_dict["gender"], my_dict["stature"])# print(my_dict["passwod"]) KeyError: 'passwod' 键值不存在就会报错
