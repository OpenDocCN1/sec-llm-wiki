# 列表的作用:# 1.单个数据存放再变量中# 2.多个变量组成大量数据就可以存放再列表当中# 3.列表可以用于存放多个数据 #定义列表：#列表是原来存放多个数据的有序容器 #列表名 = list()  list()等价于[]空列表my_list_01 =list()my_list_02 =[] #格式 [格式1,格式2,格式10]my_list = [100,12.3,True,"hello",120.6]print(my_list)  #列表：[100, 12.3, True, 'hello', 120.6]print(type(my_list)) #类型：<class 'list'>  #列表中的数据可以通过索引（下标）的方式来访问#列表名[索引值] my_list = [100,12.3,True,"hello",120.6]print(my_list[0])  #通过索引值访问数据print(my_list[1])print(my_list[2])print(my_list[3])print(my_list[4])#注意：# print(my_list[5]) #Error索引越界错误，访问超过列表容纳以外的索引
