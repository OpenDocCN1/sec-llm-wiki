2.注释：

 1.被注释的内容不会打印到终端，利用Tab键缩进提高代码可读性

 2.井号#单行注释，可以使用快捷键 CTRL+/ 进行快捷注释(再按一次就是取消注释)，可以选中多行用快捷键进行多行注释

 3. 多行注释：'''成对的单引号'''/"""成对的双引号"""  多行注释其中添加单行注释也不会报错


3.变量的定义及其命名规范：

定义：

1.变量是临时存储的数据

2.变量定义语法：变量名 = 变量值

规范：

1.不能以数字开头

2.不能使用python关键字，对其进行赋值

关键字：                   ['False','None','True','and','as','assert','break','class','continue','def','del','elif','else','except','finally','for','from','global','if','import','in','is','lambda','nonlocal','not','or','pass','raise','return','try','while','With','yield']

3.变量名区分大小写，由数字/字母/下划线组成

4.使用命名习惯：

大驼峰：单词首字母大写 Named After

小驼峰：单词首字母小写 named AFTER

下划线：单词之间有下划线分隔开 Named_After

5. python解释器会从上往下，从右往左运行代码，将运行结果赋值到右边的变量中


4.print() 函数

1.用于打印输出，最常见的一个函数。

2.print()函数自带换行

3.print()函数可以一次性打印多个函数

4.使用格式：print（"字符串信息 占位符" % 变量或数据）

  占位符：%d（数字） %s（字符串） %f（浮点数/小数/默认保留六位，可以使用%.xf，指定x保留几位） %%（两个百分号表示一个百分号）

print("姓名：%s，年龄：%d，性别：%s，身高：%.1f" % (name,age,gender,high))

 任何数据都可以转化为字符串，占位符都可以替换为%s

print("姓名：%s，年龄：%s，性别：%s，身高：%s" % (name,age,gender,high))

5.运算符

1.运算符优先级：算术运算符 => 比较运算符 => 赋值运算符 => 逻辑运算符

       2.使用小括号（）调整运算符优先级


1.算术运算符: +,-,*,/,//,%.**

a=10b=20print(a+b) # + 加 - 对象相加print(a-b) # - 减 - 负数或是一个数减去另一个数print(a*b) # * 乘 - 数相乘或是返回一个被重复若干次的字符串print(b/a) # / 除  - a除以bprint(a//b)# // 求商 - 取整除 - 向下取接近商的整数print(a%b)# % 求余 - 返回除法的余数print(a**b)# ** 幂 - 返回a的b次幂

2.比较运算符: ==,!=,>,<,>=,<=

注意：False 假0----- True 真1 所有比较运算符返回1表示真，返回0表示假。这分别与特殊的变量True和False等价。注意，这些变量名的大小写

a=10b=20print(a==b) #等于 - 比较对象是否相等print(a!=b) #不等于 - 比较两个对象是否不相等print(a>b) #大于 - 返回a否大于bprint(a<b) #小于 - 返回a否小于bprint(a>=b) #大于或等于 - 返回a是否大于bprint(a<=b) #小于或等于 - 返回a是否小于等于b

3.赋值运算符：=，+=，-=，*=，/=，%=，**=，//=

a = 10a += 10print(a) #相当于a = a+10
a = 10a -= 10print(a)#相当于a = a-10
a = 10a *= 10print(a)#相当于a = a*10
a = 10a /= 10print(a)#相当于a = a/10
a = 10a %= 10print(a)#相当于a = a%10 取余 - 返回除法的余数
a = 10a **= 10print(a)#相当于a = a的10次幂
a = 10a //= 10print(a)#相当于a = a//10 取整除

4.逻辑运算符：and，or，not

a=0 #false（假）b=1 #true （真）
print(a and b)print(b and b) #布尔"与" - 两边都为真，结果为真
print(a or a)print(a or b) #布尔"或" - 两边只要有一个为真，结果就为真
print(not a) #布尔"非" - 取反，取否定
