2.注释：

3.变量的定义及其命名规范：

定义：

1.变量是临时存储的数据

2.变量定义语法：变量名 = 变量值

规范：

1.不能以数字开头

2.不能使用python关键字，对其进行赋值

关键字：                   \['False','None','True','and','as','assert','break','class','continue','def','del','elif','else','except','finally','for','from','global','if','import','in','is','lambda','nonlocal','not','or','pass','raise','return','try','while','With','yield'\]

3.变量名区分大小写，由数字/字母/下划线组成

4.使用命名习惯：

大驼峰：单词首字母大写 Named After

小驼峰：单词首字母小写 named AFTER

下划线：单词之间有下划线分隔开 Named\_After

       2.使用小括号（）调整运算符优先级

*   
*   
*   
*   
*   
*   
*   
*   
*   

```
a=10b=20print(a+b) # + 加 - 对象相加print(a-b) # - 减 - 负数或是一个数减去另一个数print(a*b) # * 乘 - 数相乘或是返回一个被重复若干次的字符串print(b/a) # / 除  - a除以bprint(a//b)# // 求商 - 取整除 - 向下取接近商的整数print(a%b)# % 求余 - 返回除法的余数print(a**b)# ** 幂 - 返回a的b次幂
```

2.比较运算符: ==,!=,>,<,>=,<=

注意：False 假0----- True 真1 所有比较运算符返回1表示真，返回0表示假。这分别与特殊的变量True和False等价。注意，这些变量名的大小写

*   
*   
*   
*   
*   
*   
*   
*   
*   

```
a=10b=20print(a==b) #等于 - 比较对象是否相等print(a!=b) #不等于 - 比较两个对象是否不相等print(a>b) #大于 - 返回a否大于bprint(a<b) #小于 - 返回a否小于bprint(a>=b) #大于或等于 - 返回a是否大于bprint(a<=b) #小于或等于 - 返回a是否小于等于b

```
