靶机环境搭建：

1.创建一个用户（用于爆破）：配置 -> 本地用户和组 -> 用户 -> 右键新用户

 

2.服务管理器 -> 角色 -> web服务器（iis） -> internet 信息服务（iis）管理器 -> 网站 -> 添加ftp站点

 3.站点名字随意 -> 选择一份源码 -> 下一步

4.绑定IP -> ssl无 -> 下一步

5. 勾选匿名 -> 指定用户-> 指定你所创建的用户 -> 勾选读写/写入 -> 完成

6.打开cmd 输入ipconfig -> 复制IP

7.本机访问你所复制的IP到浏览器 -> 访问ftp:// IP 输入你所创建的用户看看是否搭建成功
