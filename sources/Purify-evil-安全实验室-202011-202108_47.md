 Kali安装open-vm-tools实现虚拟机交互，从而代替了之前的vmtools

  

*   
*   
*   
*   

```
1.apt-get update2.apt-get install open-vm-tools-desktop fuse #安装vmtools3.echo LANG="zh_CN.UTF-8" > /etc/default/locale #切换中文（解压版需要)3.reboot
```

*   
*   
*   
*   

```
apt-get update && apt-get upgrade  #同步源的索引，升级软件包apt-get install fcitx  #安装输入法框架apt-get install fcitx-googlepinyin  #安装谷歌输入法reboot  #重启系统
```
