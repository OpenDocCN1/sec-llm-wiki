# 漏洞简介  

2021年 Apache Solr(8.8.2) 被爆存在任意文件删除漏洞，漏洞的根本成因是函数 Files.deleteIfExists()对要删除的文件名并未做校验。同时 Apache Solr Config Api 对外开放，导致任意用户可修改配置，造成危害。
