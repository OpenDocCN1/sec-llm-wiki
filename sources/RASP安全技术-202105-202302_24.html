    Java Agent 代码无法独立启动，必须依赖于JVM才能运行，在开发 Agent 功能时，不方便调试，下面介绍下如何debug Agent 代码。


环境条件

  • jdk1.8

  • maven 3.25

  • IDEA CE 2021.2(社区免费版)

  • MacOS 11.4 


代码下载


下载2份代码：

1.web工程代码

https://gitee.com/sh3llsas/spring-boot-actuator-h2-rce.git

(这里为了演示漏洞检测模块，选择了一个有rce漏洞的服务)


2.jrasp-agent工程代码

https://github.com/jvm-rasp/jrasp-agent.git


需要的源码包已经准备好了!



web工程debug

  • 用 idea 打开web工程并执行编译打包命令 mvn clean package



  • 运行web jar包 

java -Xdebug -Xrunjdwp:server=y,transport=dt_socket,address=5005,suspend=n -jar ./target/gs-spring-boot-docker-0.1.0.jar

  • 新增一个remote debug 客户端



  • 启动 debug



agent工程debug


  • 将需要debug的agent 子maven工程加入到当前web工程中

  • 将 jrap-lanucher 的agent 入口打上断点


  • 将 jrasp-agent 编译打包

将 jrasp-agent-1.0.2-bin.zip 解压后进入到 bin目录下执行命令，attach 到我们已经启动的web进程上：
