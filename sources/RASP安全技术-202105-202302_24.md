    Java Agent 代码无法独立启动，必须依赖于JVM才能运行，在开发 Agent 功能时，不方便调试，下面介绍下如何debug Agent 代码。  

  

**环境条件**

*   jdk1.8
    
*   maven 3.25
    
*   IDEA CE 2021.2(社区免费版)
    
*   MacOS 11.4 
    

  

**代码下载**

  

下载2份代码：

**1.web工程代码**

https://gitee.com/sh3llsas/spring-boot-actuator-h2-rce.git

(这里为了演示漏洞检测模块，选择了一个有rce漏洞的服务)

  

**2.jrasp-agent工程代码**

https://github.com/jvm-rasp/jrasp-agent.git
