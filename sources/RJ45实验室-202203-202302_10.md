# 最新Burpsuite Pro 2202.09 白嫖方法

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MDc2MDcyOQ==&mid=2247483810&idx=1&sn=7702e14cc3dd223ab4d7e002c8b9a233&chksm=cf710354f8068a421380cad1be9fb0174ad52a029c4d15fabe20fba9dd4bd3302d5b4306162a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg4MDc2MDcyOQ==&mid=2247483810&idx=1&sn=7702e14cc3dd223ab4d7e002c8b9a233&chksm=cf710354f8068a421380cad1be9fb0174ad52a029c4d15fabe20fba9dd4bd3302d5b4306162a&scene=27#wechat_redirect)

1.下载Burpsuite 2022.9，可以从该链接直接下载，需要下载的格式为jar，方便直接启动

下载后hash为c3a4d5412d89afe4a3a5ed428098b113

2.下载burp-keygen.jar和加载器burp-loader-x-Ai-new.jar，后面会需要这两个包，一个用于绕过，一个用于注册

3.运行下列命令，启动我们的burpsuite pro

java -noverify -javaagent:burp-loader-x-Ai-new.jar -jar burpsuite\_pro\_v2022.9.jar

4.运行burp-keygen.jar来获取license

5.填入license，burpsuite选择手动激活

6.接下来可以成功使用，可以 体验Burpsuite pro版本了

7.上述需要的jar包已同步到星球，可自行搜索或加入星球免去搜索不必要的时间，后期也会有相关工具发布在星球，减少大家搜索时间
