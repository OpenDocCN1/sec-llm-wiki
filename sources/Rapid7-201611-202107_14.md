# Rapid7收购全球领先的Kubernetes安全供应商Alcide

基于云环境的灵活、易部署、性能优越等优势，全球越来越多的客户开始使用云环境来开展自己的业务。而那些已经使用了云环境的客户也发现，在使用云环境后工作效率确实也有了显著的提升。但是在享有它便捷的同时，我们也需要考虑云环境的安全性。在使用前需要全面的了解云的概念及容器环境，从中发现潜在威胁和配置错误最终达到降低风险的目的。

在Rapid7，我们努力帮助我们的客户建立和实施安全的战略方针，使他们能够快速采用和保护云环境。但是仅仅只关注云基础设施或容器，无法做到全面的发现可能存在的漏洞以及各漏洞会影响的范围。

为了更好的帮助我们的客户更全面地了解他们的云环境，我很高兴地宣布，我们已经收购了Alcide，Alcide是一家位于以色列特拉维夫的Kubernetes安全公司的领导者。Alcide提供的Kubernetes安全性解决方案，可以将其完全集成到DevOps的生命周期和流程中，因此业务应用在快速部署的同时也保护云环境免受恶意攻击。

Alcide的云工作负载保护平台(CWPP)提供广泛、实时的可见性和治理、容器运行时和网络监控，以及检测、审计以及具备调查已知和未知安全威胁的能力。通过将Alcide的CWPP能力与我们现有的态势管理(CSPM)和基础设施授权(CIEM)能力结合在一起，我们将能够为我们的客户提供一个云本地安全平台，使他们能够在整个云环境中管理风险和合规。

这是云安全领域一个激动人心的时刻，因为我们正在见证人们观念的转变。云安全团队不再被视为成本中心或运营障碍，而是作为推动业务发展的关键投资赢得了一席之地。有了Alcide，我们很高兴能为我们的客户进一步增加竞争优势。

我们期待着与Alcide的优秀团队携手合作，为我们的客户提供横跨整个云基础设施和本地云应用的全面、统一的解决方案。

Alcide(*https://www.alcide.io/*)成立于2016年7月，其创始人是**Ranny Nachmias** 和 **Gadi Naor**，曾在2018年获得过“Gartner Cool Vendor for Cloud Security”、“Astors Gold Award Winner”，在2019年获得过“TechCrunch Top Pick Company”、“Infosec Awards Winner”、“CRN: The 10 Hottest Kubernetes Tools and Technologies of 2019”等称号。

**在其创始之初Alcide是以填补 DevOps 和安全团队之间的空白为目标，以便所有利益相关者之间能够有更无缝的流程。DevOps 语言是具有操作的实时可见性和安全的语言，具有深入分析和控制，可管理复杂的 Kubernetes 部署。为了真正保护云原生环境，创建了一种新的解决方案。一个专为复杂的 Kubernetes 环境而设计，一个适用于在这个新时代运营和保护的所有利益相关者。**
