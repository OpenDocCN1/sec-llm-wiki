> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4OTUxMzA1NA==&mid=2247484445&idx=1&sn=fa1a3c409aa56a25a7caabc0e4fe7fda&chksm=ec2f4f2cdb58c63a3076933dba7185b2db7da67932ac389f110c8390e134441499acf89b50d5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4OTUxMzA1NA==&mid=2247484445&idx=1&sn=fa1a3c409aa56a25a7caabc0e4fe7fda&chksm=ec2f4f2cdb58c63a3076933dba7185b2db7da67932ac389f110c8390e134441499acf89b50d5&scene=27#wechat_redirect)

Nexpose是Rapid7的漏洞风险安全管理产品，不止具有出色的漏洞检测能力和资产风险管理能力，与第三方产品的整合功能也很强大，能让用户的安全管理工作效率带来很大的改善与提升。正常的安装方法不管在Windows平台还是Linux平台均要进行一个交互式的安装过程，安装过程中涉及到安装路径，主体名称，默认管理员用户名，密码以及选择安装控制台或者单引擎，特别是产品的默认管理员密码，用户在安装完后就忘记了当时设置的密码，导致还要重置密码。**此次提供一键式安装方式，能完美避免诸多问题，而且一键安装支持升级操作，通过参数控制安装中的选项****。****Linux平台下安装**![](../Images/6def563f5ae7676116294a5d63f4c1c1.png)![](../Images/9d76e2c9fb028db6c342205b591462d2.png)

安装命令如上，其中的-overwrite参数在新安装中不影响，其它参数可根据自己需要进行修改，而不同的参数代表意思如下：

| 参数 || 功能  
 |
| :-: | :-: |
| \-q  
 || 无人值守静默安装模式  
 |
| \-dir  
 || 自定义安装目录  
 |
| \-overwrite  
 || 覆盖安装模式，一般用于升级  
 |
| \-Vfirstname || 用户主体信息名称1  
 |
| \-Vlastname  
 || 用户主体信息名称2  
 |
| \-Vcompany  
 || 用户主体企业名称  
 |
| \-Vusername  
 || 产品默认全局管理员账号  
 |
| \-Vpassword1  
 || 产品默认全局管理员密码  
 |
| \-Vpassword2  
 || 确认产品全局默认管理员密码  
 |
| \-Vsys.component.typical  
 || 是否经典默认安装(控制台)  
 |
| \-Vsys.component.engine  
 || 是否单引擎模式安装  
 |
| \-VinitService  
 || 安装完成是否启动服务 |
