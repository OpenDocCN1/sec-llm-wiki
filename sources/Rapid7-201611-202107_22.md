# 为Nexpose启用双因素认证

Nexpose是Rapid7的漏洞风险安全管理产品，不止具有出色的漏洞检测能力和资产风险管理能力，与第三方产品的整合功能也很强大，能让用户的安全管理工作效率带来很大的改善与提升。

本次说到的双因素认证，可以让Nexpose的Web安全控制台结合基于时间的一次性密码应用程序进行双重身份验证。

![](../Images/6d58809a818b821079a0617f7ec086c0.png)

**要求**

**两个因素身份验证需要以下内容：**

1.  您必须是全局管理员才能在全局管理中启用该功能
    
2.  用户必须具有基于时间的一次密码应用，如 Google身份验证器，或者微软的Authenticator以及Authy等类似工具
    

**操作步骤****使用前必须启用双重身份验证选项：**

1.  在安全控制台的左侧导航大菜单中，单击"管理（ADMINISTRATION）"选项卡
2.  在"全局设置（Global and Console Settings）"和"控制台设置（CONSOLE）"下，单击"管理（Administer）"
3.  在"安全控制台配置"（Security Console Configuration）页上，单击"身份验证（AUTHENTICATION）"选项卡
4.  在"双重身份验证（TWO FACTOR AUTHENTICATION）"下，选中相应的框
5.  将显示一个"警告"窗口。单击启用双因素身份验证
6.  单击"保存"以确认更改
7.  现在，除了账户的密码凭据之外，还需要所对应的用户帐户在登录时提供访问代码

**令牌生成**令牌由单个用户或全局管理员生成**用户生成的令牌****如果您是非管理员用户，需要按照全局管理员的授权完成双重身份验证设置，请按照以下步骤操作：**使用常规凭据登录到安全控制台*提示：如果您的（Global）全局管理员在之前启用了双重身份验证，则无论是否自己完成设置，系统都会提示您输入访问代码，所以请注意正确的设置方法*

1.  将此（Access Code）字段留空以进行首次登录
    
2.  打开屏幕右上角的用户名下拉列表。
    
3.  单击用户首选项（User Preferences）（注意不是管理功能里）
    
4.  在"用户配置（User Configuration）"页面的"常规（GENERAL）"选项卡上，单击"生成新令牌（"Generate New Token）"
    
5.  在身份验证应用中添加新帐户，并使用令牌作为密钥
    
6.  完成后单击"保存"
    
7.  后面的的登录，除了密码凭据之外，还需要提供身份验证应用中显示的访问代码，才能成功访问安全控制台

**管理员生成的令牌和管理****全局管理员可以为单个用户生成令牌供其使用，并监视其双重身份验证状态。要为用户生成令牌，需要：**

1.  在安全控制台的左侧导航菜单中，单击"管理"选项卡
    
2.  在"用户"下，单击"管理用户帐户"
    
3.  将显示"用户"表。如果您已启用该功能，则附加列标记为"启用双重身份验证"，并且根据每个用户的状态显示每个用户的"是"或"否"值
    
4.  单击所需用户帐户旁边的"编辑"列中的铅笔图标
    
5.  在"常规"选项卡上，单击"生成新令牌"
    
6.  向用户提供此令牌，以便他们可以将令牌与身份验证应用配对
    
7.  完成后单击"保存"
    
8.  如果需要，用户可以在使用访问代码登录后更改令牌以完成初始设置
    

**注意：此双重身份验证功能当前与活动目录 （LDAP） 和 Kerberos 身份验证方法不兼容；此启用操作无法对单独用户账户取消**
