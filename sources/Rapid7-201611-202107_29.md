# R7-2019-40:Bloomsky SKY2 Weather Camera Station漏洞披露

Rapid7最新披露的漏洞信息，漏洞问题倒是不严重，不过可以给大家参考一下漏洞披露的流程和时间线。  
另外，这种气象摄像头在农业领域和城市规划上挺有用啊，弄个创业公司。Bloomsky SKY2网络中存在许多信息泄漏漏洞，可通过旨在与Bloomsky SKY2 Weather Camera Station配合使用的JSON查询获得这些漏洞。 这包括单个用户的电子邮件地址，移动操作系统信息和经/纬度地理数据，这构成了“私人信息泄露”漏洞CWE-359，CVSS评分为4.3。 此外，用户只需知道关联的用户ID，即可将图像上传到与其他用户的相机关联的云存储（Amazon S3存储桶），该用户ID可通过上述JSON信息泄漏获得。 这是CWE-345“数据真实性验证不足”的一个实例，CVSS得分也为4.3。**产品描述**供应商网站上介绍的Bloomsky SKY2天气摄像机站是一个家庭式气象站，旨在与超过100,000个注册用户的网络记录和共享天气数据（请注意，任何人都可以免费注册，而无需购买设备或订阅服务）。 该设备还记录并共享（通常）室外图像。![](../Images/56cddf714b64ab1cb82a2936b265c0a6.png)**漏洞披露**这些问题是由独立安全研究人员Andrew MacPherson发现的，并根据以下要求报告给Rapid7进行披露 **Rapid7's vulnerability disclosure policy**。**详情**Bloomsky网络中暴露出两个可利用的问题：“私人信息暴露”（CWE-359，CVSSv3得分为4.3）和“数据验证不充分”（CWE-345，CVSSv3得分为4.3）。 为了利用这些漏洞，攻击者只需要在Bloomsky网络上注册一个免费帐户，然后枚举所有用户ID（根据攻击者自己新获取的用户ID，这些用户ID可以递增且可预测）。有关开发的技术细节，研究人员已发表 detailed blog post 。**影响**通过这些漏洞，攻击者可以枚举所有Bloomsky网络用户的电子邮件地址，而无需考虑其SKY2设备的预期隐私设置。 攻击者还可以上传与任意用户ID关联的图像。![](../Images/202b40a26e673b4b29251cf564bcc636.png)**厂商响应**Rapid7通过其供应商列出的电子邮件地址将这些漏洞通知给供应商后，无法获得供应商的回应 **privacy policy**。![](../Images/d15dce864da52c45a492d2a775919648.png)**漏洞修补**尽管我们尚未收到供应商对这些问题的答复，但是自从我们第一次向供应商披露以来，JSON模式已经更新，不再披露设备所有者的电子邮件地址（尽管其他个人信息，例如用户名和 /剩余的设备长度）。不幸的是，在没有供应商进行更新以实施更合理的访问控制的情况下，用户似乎无法限制恶意用户上传与其帐户关联的任意图像。![](../Images/2d0d4ab2ff395c53de566688ce160704.png)**漏洞披露时间线**

*   ***September 2019:*** Issue discovered by Andrew MacPherson
    
*   ***Monday, Sept. 16, 2019:*** Issue reported to Rapid7 for coordinated vulnerability disclosure
    
*   ***Tuesday, Sept. 17, 2019:*** Issue reported to Bloomsky by Rapid7
    
*   ***Wednesday, Jan. 29, 2020:*** Public disclosure of this issue
