# 如何将Rapid7 InsightVM(Nexpose)和Splunk Enterprise相整合

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4OTUxMzA1NA==&mid=2247484222&idx=1&sn=074ee95f9744c9e92755580ebefd7bc1&chksm=ec2f480fdb58c119f063fb0b3082e448c22f85976cc5354123a4143926077052ead684165c9d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4OTUxMzA1NA==&mid=2247484222&idx=1&sn=074ee95f9744c9e92755580ebefd7bc1&chksm=ec2f480fdb58c119f063fb0b3082e448c22f85976cc5354123a4143926077052ead684165c9d&scene=27#wechat_redirect)

Splunk，众所周知，强大的数据引擎，也有人把它称作日志管理，但用了Rapid7产品的客户如何将它与其相结合呢？因为官方手册也是介绍，并没有详细的操作方法，本文将介绍如何操作。  

  

准备好Splunk Enterprise环境，本文使用6.4.3版本，同时准备好Splunkbase的账号，用于下载所需要用到的两个应用，名称分别为：

**Rapid7 Nexpose Technology Add-On for Splunk；**

**Rapid7 Nexpose Dashboard for Splunk Enterprise**。

  

应用链接如下：  

*   
*   

```
https://splunkbase.splunk.com/app/3457/https://splunkbase.splunk.com/app/3492/
```

Splunk应用可在线安装，也可离线安装，但均需要账号密码，注册一个即可；离线安装需要下载好离线的tgz包，离线上传安装。

  

Rapid7 Nexpose Technology Add-On for Splunk我使用离线安装方式，如下图下载后进行离线安装。

![](../Images/740f70b8b62d967b111fb94cab2561ee.png)

![](../Images/9f505740be115f6d779ffa01e5f77b09.png)

![](../Images/5abff8245ed265294a0c49875f14bdf0.png)

![](../Images/da67ee3d27df80824beef394da97cfca.png)

安装完重新启动Splunk，然后如下图，在应用中对刚才安装的应用进行**设置**。

![](../Images/c5e42d75680b2402754508c22052a1d7.png)

填写Nexpose的用户名，密码，地址和端口，至于是否只导入新任务数据还是漏洞解决方案，类型和数量看您自己选择。

![](../Images/d29b65cc9354d5f5b050d2aabaf22093.png)

![](../Images/4418953c94b865c67534ea5c82a27546.png)

填写完成相关凭证后保存，提示成功更新应用即可，然后安装第二个应用Rapid7 Nexpose Dashboard for Splunk Enterprise，如下图第二个，进行安装，输入账号密码后即开始安装。

![](../Images/8789977053950bebf901b7ae51f4e124.png)

![](../Images/7d1c839e53be2d1ab6b8ae8905ea445a.png)

安装完成后需要新建数据导入操作，不然数据不输入，没有显示的，如下图，在Rapid7 Nexpose这个本地输入一行后面新增。  

![](../Images/67bbc2b2da14513494e47977f945e5d5.png)

根据提示选择和输入相应的参数，最重要的是间隔，决定着从Nexpose拉取数据的时间间隔，格式为Linux crond格式，我这里使用每5分钟拉取一次。![](../Images/36bee28c93e57e70b5d120b848c80061.png)

所以操作完成，等待第一次数据拉取，然后在Splunk首页点击Rapid7 Nexpose Dashboard for Splunk Enterprise应用即可查看数据情况。

![](../Images/8cdc9453270e7d76c76f36d0496d704d.png)

![](../Images/e94239027c16b5fabf48543f2ce8a38d.png)

说在最后，有些用户不满足于Splunk现有应用中拉取的数据格式和类型，希望能额外对Nexpose中其它资产属性，漏洞属性进行拉取，也是可以的，因为Splunk中应用使用的是Nexpose的API接口进行拉取，格式固定为所见的部分数据，有开发能力的用户通过学习NexposeAPI即可发现相关字段，并修改Splunk应用进行拉取，并能过Splunk强大的数据处理能力进行查询和展示。
