自动化深度扫描（无需人工管理扫描密钥）

With CyberArk Application Access Manager™ and Rapid7 InsightVM or Nexpose

在漏洞扫描的过程中，如何保护和管理扫描所使用的特权凭证（主机密码和SSH密钥）是当今许多组织面临的挑战。此外，如何确保特权凭证定期更改以及可审计，可能更加难以实现。执行漏洞扫描时，最佳做法是使用特权帐户审核您的系统，以便更深入地了解主机上存在的漏洞。

Rapid7领先的漏洞管理解决方案InsightVM/Nexpose与CyberArk ApplicationAccess Manager™的整合，允许每次扫描的过程中从CyberArk系统检索到相应的安全凭证进行扫描。这使得管理员无需担心必须在多个位置更新特权帐户凭据，并确保所有扫描过程更加安全。



（1）功能实现过程：

特权帐户凭据使用CyberArk的系统进行管理，并与特定资产或资产组相关联。在InsightVM /Nexpose中创建站点（资产的逻辑分组）以执行漏洞扫描。 在运行扫描之前，Rapid7和CyberArk在InsightVM/Nexpose的管理选项卡中链接在一起。然后，InsightVM/Nexpose将在CyberArk的系统中查询每个资产的凭据，包括1：1凭证（单个资产的单个凭据）和1：多个的凭证（多个资产的全局凭据）。完成后，InsightVM/Nexpose将利用CyberArk的凭据进行身份验证的深度扫描。


（2）安全：

凭据本身不存储在InsightVM/Nexpose的安全控制台中，而是仅在短时间内进行处理，仅用于扫描目的。

CyberArkApplication Access Manager会根据组织的安全策略或按需自动轮换凭据。


（3）整合过程概述

步骤1：在CyberArkPrivileged Access Security Solution中创建特权帐户存储

步骤2：选择资产在Insight VM/Nexpose中创建站点

步骤3：在InsightVM/NexposeUI中连接InsightVM和CyberArk的控制台

步骤4：对您的站点运行InsightVM扫描并自动提取管理员凭据

此项功能，Rapid7也提供本地技术支持服务。

图：使用InsightVM中的CyberArk配置凭据管理

 

步骤5: InsightVM或Nexpose从CyberArk请求凭证，CyberArk返回正确的密钥，然后InsightVM（或Nexpose）可以运行经过身份验证的扫描。


(4)您需要准备什么

  • Rapid7 InsightVM或Rapid7 Nexpose 6

  • CyberArk特权访问安全解决方案版本9.3.0

  • CyberArk Application Access Manager 7.2.13

*与CyberArkApplication Access Manager相关的Rapid7 InsightVM的所有提及也适用于Rapid7 Nexpose。

 

（5）整合的好处

  • 提供Rapid7 InsightVM或Nexpose的深度扫描

  • 特权帐户凭据的管理更加简化和安全

  • 不用考虑扫描凭据的安全性和保管问题，CyberArk的解决方案可以提供充分的支持

  • 满足合规计划的全面审计和跟踪
