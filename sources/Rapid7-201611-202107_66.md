# Rapid7 Threat Feed助您实时确定待修复漏洞的优先级

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4OTUxMzA1NA==&mid=2247483980&idx=1&sn=3f8e4dbd505db5dcad4560ed7c4a66e3&chksm=ec2f497ddb58c06b49783343a90bb0747c1dcaadec68c3dfac5c1851a81cda4c21db465e8201&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4OTUxMzA1NA==&mid=2247483980&idx=1&sn=3f8e4dbd505db5dcad4560ed7c4a66e3&chksm=ec2f497ddb58c06b49783343a90bb0747c1dcaadec68c3dfac5c1851a81cda4c21db465e8201&scene=27#wechat_redirect)

我们经常听说一些安全小组被其环境中不计其数的漏洞所淹没：每天发现的漏洞比修复的漏洞还要多。当用于确定优先级，比如常见漏洞评分系统(CVSS)，不能真正起作用或者把威胁因素考虑在内时，它就没有帮助。如果漏洞管理解决方案显示您有一万多个高危漏洞，那么您怎么知道着重处理哪些漏洞呢？当出现一些众所周知且出现频率高的漏洞时，您是如何迅速了解其影响呢？

 了解哪些是最可能被攻击者利用的漏洞，这对于有效的确定优先级至关重要。这就是为什么在InsightVM和Nexpose的实际风险得分考虑了一个漏洞是否被一个已知的漏洞或恶意软件所攻击。此外, Rapid7关键漏洞类别使安全小组能够自动评估关键威胁所造成的风险, 尤其是那些没有CVSS评分的0-days。

但是鉴于最近发生的事件，显然需要以漏洞为基础的威胁情报，正如我们在博客中所解释的那样。Rapid7已经通过Rapid7 Insight平台、Rapid7 实验室的海森堡云计算、我们的管理检测和响应团队以及Metasploit社区来收集和分析关于攻击者方法和新出现的威胁数据。我们希望把所有这些数据都提供给客户，以便更好地了解所暴露的不断变化的威胁环境，但以一种增加实际价值的方式，而不仅仅是抱怨和议论。

**将****Rapid7 Threat Feed****引入到****InsightVM**

Rapid7Threat Feed是一个实时的、精心策划的、被攻击者公开利用的漏洞概述。应立即修复这些最危险的漏洞。该feed结合了我们海森堡的蜜罐和事件响应活动收集的数据，以及来自受信任的第三方信息:

| 来源 || 描述 |
| --- | --- |
| Heisenberg || Rapid7现代实验室现代蜜罐框架检测的攻击 |
| IR Activity || Rapid7管理检测和响应小组确认的事件 |
| FBI || FBI部门伙伴关系的部分共享信息 |
| Info Sharing || 从信任伙伴共享的信息了解此威胁 |
| Open Source || 公开信息 |

除了积极监控和策划ThreatFeed外，Rapid7威胁情报小组增加了重要内容，例如威胁向量和参与者信息，以便您可看到如何威胁您组织的。

![](../Images/7541b610c2848d48663226c96da95344.png)

**环境中可见的威胁**

然而仅仅掌握信息还不够，还需要结合组织环境的上下文，以便使其具有可操作性。我们添加了一个新“Threat Feed Dashboard”模板使您可轻松查看组织对活动威胁的暴露程度，以及需要关注的地方，以便减少潜在的攻击。该仪表盘包括以下信息：您的环境中可能被新手利用的资产或漏洞的百分比、最常被利用的漏洞，以及常见漏洞利用和恶意软件工具包。

![](../Images/53e1875ba1536db5999c885838ebf232.png)

具体地说，有两个仪表盘卡可利用Rapid7 Threat Feed。"Most Common Actively Targeted Vulnerabilities"卡显示了当前环境中最常见的活动威胁。单击此卡可获取网络中可利用漏洞的完整列表，您通过该漏洞深入了解Rapid7 Threat Feed的详情。"Assets with Actively Targeted Vulnerabilities"卡显示您网络上受活动威胁影响的资产总数以及需要优先修复资产。

![](../Images/233aee32ca2ace2b2b33ead78bf6ae6f.png)

**修复环境中的威胁**

发现环境中的高危漏洞只是修复工作的一半，接下来是实际修复漏洞。单击"Assets with Actively Targeted Vulnerabilities"卡获取受影响资产的完整列表，可将这些资产

添加到Static Remediation Project中以便采取行动。通过修复工作流程，您可自动创建和分配凭证，提供相关的和可执行的信息以及追踪自始至终的流程。
