# 在InsightVM和Nexpose中扫描并修复WannaCry/MS17-010

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4OTUxMzA1NA==&mid=2247483950&idx=1&sn=0272380a0856b7457dd1eeb8ef992f06&chksm=ec2f491fdb58c0096cc7d0a4e125c068f38219bb57b47e45e2af884bef803ed0ee4a55b9643c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4OTUxMzA1NA==&mid=2247483950&idx=1&sn=0272380a0856b7457dd1eeb8ef992f06&chksm=ec2f491fdb58c0096cc7d0a4e125c068f38219bb57b47e45e2af884bef803ed0ee4a55b9643c&scene=27#wechat_redirect)

本周，安全小组正开始工作，争取修复MS17-010，以防止相关的勒索软件攻击。WannaCry，也被称为 Wanna Decryptor、WNCRY、以及 Wanna Decryptor 2.0。

随着WannaCry信息的扩散，我们希望尽快得到解决，首先[查看此链接](http://mp.weixin.qq.com/s?__biz=MzI4OTUxMzA1NA==&mid=2247483931&idx=1&sn=2469ac9669bdd97af298e77cd4f5ad4f&chksm=ec2f492adb58c03c2c4f604b8bc5b3f4b0c750c097decce95a06972e6c9daba4e650acd15a02&scene=21#wechat_redirect)以了解Bob Rudis编写的WannaCry ransomware漏洞的概述，然后根据以下步骤快速扫描您自己的基础网络设施中是否有此漏洞(如果您还不是Rapid7的客户，请尝试使用InsightVM 免费试用版，您可以使用此免费试用版来扫描您环境中的此漏洞)，然后再创建动态资产组以持续监控受影响的资产，以及创建动态修复项目以跟踪WannaCry的修复进度。

以下是InsightVM/Nexpose 的step by step指南，专门针对MS17-010创建扫描模板来扫描此漏洞：

1.在"Administation"选项卡下，转到"Scan Options">"Templates">"Manage Templates"

![](../Images/53dc5bb939153371e10ca11d43f0a9bf.png)

2.复制以下模板："Full Audit enhanced logging without Web Spider"。给此副本取一个名字以及添加一些描述；在这里，我们称之为"WNCRY Scan Template"

![](../Images/cd7915e48145f3c9eb6f4f61ac64263d.png)

![](../Images/59e9a14735a0d3b7fad086ec17c39c37.png)

3.点击"VULNERABILITY CHECKS"，然后点击"By Individual Check"

![](../Images/2ec1d58191028c2d51b6f60635104281.png)

4.添加检查项"MS17-010"，然后单击保存：

![](../Images/518449e16f69df5f631118a268e2bb1d.png)

当搜索MS17-010关键字时，应该会返回相关的192个检查项(如果没有，请及时更新您的Nexpose/InsightVM。相关的CVE是：

    CVE-2017-0143

     CVE-2017-0144

     CVE-2017-0145

     CVE-2017-0146

     CVE-2017-0147

     CVE-2017-0148

5.保存模板并运行扫描以识别所有与MS17-010漏洞相关的资产。

**为MS17-010创建动态资产组**

现在如果您已经扫描了资产，您可能需要创建一个动态资产组来生成报告/标记，当新的资产被发现有这个漏洞时(或它们已被修复时)，资产组将自动更新。要开始使用，请点击InsightVM/Nexpose控制台右上方的过滤器图标，位于搜索按钮下方：

![](../Images/b5e9d74aac5320af026341454a9c4366.png)

现在，使用"CVE ID"过滤器指定下列CVE编号：

![](../Images/fae85de7af81cad7931b095145790bdc.png)

该资产组现在可用于报告和标记，以快速识别暴露的系统。

**创建WannaCry Dashboard**

最近，Ken Mizota发表了一篇关于如何构建自定义仪表板的文章，以跟踪您从Shadow Brokers曝光的漏洞。如果您想要具体针对WannaCry，可以使用此Dashboard过滤器：

asset.vulnerability.title CONTAINS "cve-2017-0143" OR 

asset.vulnerability.title CONTAINS "cve-2017-0144" OR 

asset.vulnerability.title CONTAINS "cve-2017-0145" OR 

asset.vulnerability.title CONTAINS "cve-2017-0146" OR 

asset.vulnerability.title CONTAINS "cve-2017-0147" OR 

asset.vulnerability.title CONTAINS "cve-2017-0148"

**为MS17-010创建修复项目：**

在InsightVM中，您还可以为MS17-010创建修复项目，以便实时跟踪修复进度。 为此，请转到" "选项卡，然后单击“创建项目”：

![](../Images/39976a0fb455daea562c284ba80b6d0a.png)

为新建的修复项目起一个名称，并在资产过滤器类型中键入 vulnerability.vulnKey = "MS17-010"：

![](../Images/5215eaffe85e26516874a4a996f337e1.png)

注意，此项目将是动态的，因此在您修复和/或找到此漏洞的新实例时，它将自动更新。

现在，如果您愿意，还可以给这个项目一个描述，并配置修复责任人，以及访问级别。 如果您有JIRA，您还可以配置InsightVM和JIRA之间的自动工单集成，以自动将工单分配给相关的人员。

使用这些步骤，您将能够快速扫描WannaCry并确保正在修复漏洞。 如有任何疑问，请随时联系我们！
