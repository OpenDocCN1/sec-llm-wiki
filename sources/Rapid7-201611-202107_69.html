什么是"Ransomware"(勒索)?

勒索

    "恶意软件悄悄加密您的文件，并阻止您访问它们,然后要求为恢复功能付款.像网络攻击中使用的大多数战术一样,在点击网络钓鱼链接或者访问受到攻击的网站之后,可能会发生"勒索"攻击"(https://www.rapid7.com/solutions/ransomware/).

然而,WannaCry勒索通过包含能够在本地网络上找到易受攻击的系统的组件以及在这种方式传播,偏离了传统的"勒索"定义,这种类型的恶意软件行为被称为"蠕虫",并且使用这种功能可以追溯到1988年,当时莫里斯蠕虫(https://en.wikipedia.org/wiki/Morris_worm)在互联网上传播(尽管当时时间较短).


由于WannaCry结合了两项极具破坏力的功能,因此与过去18-24个月所见过的Ransomware案例相比破坏性和影响性更大.

什么系统受影响?

WannaCry仅针对Microsoft Windows系统,已知会影响以下版本:

  • Microsoft Windows Vista SP2

  • Windows Server 2008 SP2和R2 SP1

  • Windows 7

  • Windows 8.1

  • Windows RT 8.1

  • Windows Server 2012和R2

  • Windows 10

  • Windows Server 2016

  • Windows XP

但是,所有版本的Windows都可能是易受到攻击的,并且在2017年5月13日(https://blogs.technet.microsoft.com/msrc/2017/05/12/customer-guidance-for-wannacrypt-attacks/),Microsoft发布了一个通知,其中包含所有受影响的Windows操作系统(包括Windows XP)的修补程序链接.

如前所述,Windows XP也受到影响,该版本的Windows仍然占据了7-10%的使用份额(由NetMarketshare调查):

而且这个使用情况并不包括像中国这样的国家的终端数量,他们大量的使用Windows XP和其它windows系统的"Aftermarket"版本,这使得他们无法打补丁.


"蠕虫"组合利用Windows中存在的远程执行代码(RCE)漏洞,可以通过网络(称为"服务器消息块"或者SMB)共享文件.以发布美国国家安全局(NSA)工具(EternalBlue/DoublePulsar)之前,微软公布了一个被称为"影子经纪人"的团体,因此微软在2017年3月14日发布了一个补丁公告MS17-010(https://technet.microsoft.com/en-us/library/security/ms17-010.aspx).Rapid7的威胁情报负责人Rebekah Brown在4月份的一篇博客文章中(https://community.rapid7.com/community/infosec/blog/2017/04/18/the-shadow-brokers-leaked-exploits-faq)写道.


脆弱性检测工具,如Rapid7的Metasploit,具有这个弱点的检测功能已经有一段时间了,最新的Metasploit模块(https://github.com/rapid7/metasploit-framework/blob/master/modules/auxiliary/scanner/smb/smb_ms17_010.rb)在2017年4月40日更新了.


这个ransomworm可以由某人在公共wifi或者受感染公司的"Guest"wifi上传播,然后将传播感染到另一个不完全加密的网络.WannaCry也可能传播,传统的网络钓鱼向量以及这个网络蠕虫矢量.


你能做什么?

  • 确保所有系统已经针对MS17-010漏洞进行了修补.

  • 确定任何未修补的面向互联网的系统并尽快修复.

  • 使用网络和基于主机的防火墙来阻止来自不受信任系统的TCP/445端口的流量.如果可能,block掉所有面向互联网的Windows系统的445端口.

  • 确保关键系统和文件具有最新的备份.备份是由于赎金问题而导致数据丢失的全面缓解的唯一办法.


注意:Rapid7管理检测和响应(MDR)SOC已经制定了此广告系统的泄密检测指标(IOC),但是一旦恶意软件在受损系统上执行,我们会收到警报.但这不是缓解措施.


潜在的更广泛的影响

作为Project Sonar(http://sonar.labs.rapid7.com/)的一部分,我们执行常规SMB扫描,并在2017年5月3日的扫描中检测到超过180万个设备响应了完他smb连接.

这些系统的一部分可能是Linux/Unix服务器模拟SMB协议,但很大一部分是Windows系统.这些迹象表明,系统维护不佳,并且也容易受到攻击.
