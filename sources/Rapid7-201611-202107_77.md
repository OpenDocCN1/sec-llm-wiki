# Metasploit让渗透测试更简单

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4OTUxMzA1NA==&mid=2247483858&idx=1&sn=161e97915fae579f3f8e570eaf08f6e3&chksm=ec2f4ae3db58c3f5efafff479e33a29377a86b1cdb1e89c370721f531e7f3343d91e5bccbd6a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4OTUxMzA1NA==&mid=2247483858&idx=1&sn=161e97915fae579f3f8e570eaf08f6e3&chksm=ec2f4ae3db58c3f5efafff479e33a29377a86b1cdb1e89c370721f531e7f3343d91e5bccbd6a&scene=27#wechat_redirect)

来自世界各地数百万IT人员都想进入安全这一热门领域，而Metasploit就是一个很好的开始。Metasploit框架是免费的，被很多测试人员使用，与其他工具相比，更能够帮助用户从攻击者的角度理解安全。但有一个问题：如果没有存在漏洞的服务，就很难使用Metasploit。

因此，Metasploit团队创建了易受攻击的操作系统映像（Metasploitable2和Metasploitable3），每个都包含几十个漏洞服务，用户可以借此初试牛刀。

然而，这些镜像只是可供用户使用的数千个Metasploit模块的一小部分。您可能要问我们为什么没有为每个模块的测试和练习设计存在漏洞的服务。原因很简单：配置漏洞服务非常耗时且难度较大。首先，你必须获得漏洞软件，安装后对每个服务进行配置。有时较旧的软件根本无法下载，要么是因为版本太旧，要么是因为供应商其安全原因将其删除了。根据不同软件，仅仅设置一个漏洞服务都需要几个小时，甚至是几天。虽然Metasploitable VM能够让您更方便的搭建您的第一个漏洞实验室，但这个过程仍然是不简单。

我们开发了易受攻击服务模拟器来填补这一空白。它是一个框架，使其模拟易受攻击的服务进行渗透测试。现在，它模仿了100多个漏洞服务，包括易被攻击的凭据，从被攻击者处拿到Shell等等。通过对模块的练习，用户可以了解有关安全漏洞的详细信息以及测试方法，并可以继续学习和使用Metasploit的其它功能。它就像一个具有高互动性的特殊功能蜜罐。

该工具的安装和使用都非常简单。只需要在您喜欢的操作系统（Windows、Mac或Linux）中安装并运行Perl即可。

工具安装指南见本项目的Github页面，仅需一分钟。

https://github.com/rapid7/metasploit-vulnerability-emulator

除了学习，模拟器还可以用于对Metasploit模块本身执行系统测试，向社区提供有关如何使模块更有效的反馈。但是，本项目的最终目标是帮助整个社区去学习Metasploit，使其更容易进入渗透测试工作！  

**用法示例**

这里我们模拟一个易受攻击的打印机服务，该服务由Metasploit的moduleexploits/windows/iis/ms01\_023\_printer模块提供。IP地址0.0.0.0意味着我们将绑定到0.0.0.0，并且接受任何网络接口上的连接。要绑定的默认IP是“127.0.0.1”，仅从同一主机连接。当与metasploit实例安装在同一服务器上时，这样更安全。

很简单，是吧？而这个框架更棒的地方在于其开发新的模拟漏洞服务也非常容易。我们知道开发人员在编程语言方面有着不同的偏好，因此本框架不使用特定的语言来实现漏洞服务，而是使用JSON描述漏洞服务互动。它本身不是一种编程语言，但有足够的逻辑支持服务仿真。以下是对易受攻击的打印机服务的描述。

| Simple JSON description on an emulated service |
| --- |
| "exploits/windows/iis/ms01\_023\_printer": {  "desc":"set payload windows/shell\_reverse\_tcp",  "seq":\[   \["regex", "GET http:\\/\\/.\*\\/NULL.printer?"\],    \["HTTP/1.1200 OK\\r\\nContent-Length: 0\\r\\n\\r\\n", \["action",\["connect", ":4444"\]\]\]  \]}, |

在上述JSON代码中，最重要的是“seq”部分，代表着用于漏洞的消息序列。它有偶数个条目（本实例中有两个条目）。奇数条目是条件。消息进入时，匹配第一个奇数条目；如果匹配成功，将会执行相应的偶数条目。 通常情况下，该动作涉及发送响应。但也可能包括诸如新建连接（本例中即连接回metepreter会话）的动作。这样，漏洞服务模拟和触发其建立到攻击者的连接就变得简单了。

  

作为项目的核心，我们实现了一个框架（解释器）来执行基于JSON的服务描述文件。当前通过Perl来实现，但您也可以选择其他编程语言来实现框架。
