# Exiting the Matrix: Metasploit硬件桥接简介

**Follow the white rabbit...**

Metasploit是个很棒的工具。通过服务器，甚至是嵌入式操作系统，您可以使用它来操纵大型网络。能够为您和团队提供单一接口控制服务器和网络，功能非常强大。但是，除了控制虚拟世界之外，有时您可能想要做更多。您可能还想控制物理世界。那么就需要Exit The Matrix。

最近，我们新推出了Metasploit更新帮您达成所愿，这就是：硬件桥接API。硬件桥接API将Metasploit的能力扩展到物理世界的硬件设备。Metasploit框架帮助统一工具并开发网络和软件，同样的，硬件桥接对所有类型的硬件起相同的作用。现在，您可以从Metasploit内部扩展到Metasploit兼容硬件设备，来远程控制以满足渗透测试的需要。 

**效果如何实现？**

使用Metasploit连接物理世界有两种方法：

1、直接在固件中构建支持，使其与Metasploit兼容，或者

2、创建中继服务。  

如果您的设备无法自然连接至以太网，则需要中继服务。许多有用的硬件工具，如软件定义无线电（SDR）设备仅通过USB端口控制。将SDR设备如此接入Metasploit，SDR所连接的机器将运行中继服务。这需要使用REST API，详细信息如下：Metasploit硬件桥接API。

**Why REST？**

这是解决方案的权衡。嵌入式系统通常不支持REST，因为这需要运行某种小型的web服务器。较新的嵌入式系统，尤其是IoT设备可以本地运行网络服务器，但是如果您的硬件没有WiFi或以太网功能，我们会使为设备创建中继服务变得更加容易。我们将在Metasploit工具部分提供几个示例，演示如何利用Metasploit框架处理所有http/web需求，以便聚焦于您所使用的串行、USB或其他通信信道。我们还计划为通用的微型控制器和嵌入式系统提供库的支持，以便您的设备能够快速支持Metasploit。 

**那么硬件桥接到底有什么作用**

就技术上而言，任何事都能做到。API提供一些您“认为”应该支持的核心功能，尽管大多数命令是可选的。这些核心功能主要是查看电源，以及获得版本控制信息和设备功能。设备支持的某些“特殊功能”将在Metasploit端触发其他功能。推出时将包括汽车扩展。

**走出梦想，走进车内**

如果您的设备支持CAN，Metasploit将自动提供多个交互式车辆相关命令。这样，您的硬件桥接（HWBridge）会话将标记为汽车会话，可在会话列表中或通过仅在汽车系统中才可以使用的模块中查看。这样一来，开发人员能够专注于编写汽车工具，而无需担心连接的硬件。同时，它还提供内部Metasploit API，使一般汽车呼叫更加方便，如加速或要求发动机控制会话（ECU）安全访问令牌。

硬件设备能够教会Metasploit更多妙招！您无需等待Metasploit更新或支持某个新设备。硬件设备能够披露其对Metasploit框架的任何功能。这就是它独一无二的地方。它可以像展示LED一样简单，也可以像运行在MIL-STD-1553总线系统上的一系列命令一样复杂。通过API教会Metasploit某些功能时，将会在HWBridge中显示为交互命令。允许特定硬件支持，而无需强制开发人员严格遵循API规则，而这些命令也可以开发成模块后使用。

**如何使用？**

如果您看到这里了，我想您已经准备好实战了。第一步是支持SocketCAN。如果您有Linux系统和支持SocketCAN的CAN总线嗅探器，那么您可以开始了。我们以local\_hwbridge模块为例讲解简单的中继系统。您可以本地或远程运行。

| msf > use auxiliary/server/local\_hwbridge  
msf auxiliary(local\_hwbridge) > run\[\*\] Auxiliary module execution completed\[\*\] Using URL: http://0.0.0.0:8080/6xOv7GqFs3YTeIE\[\*\] Local IP: http://10.1.10.21:8080/6xOv7GqFs3YTeIE\[\*\] Server started.msf auxiliary(local\_hwbridge) > |
| --- |

local\_hwbridge将默认自动检测任何SocketCAN接口，而无需键入任何选项。中继服务无需在Metasploit内运行，而可以独自运行，如果REST API由硬件本身支持，您可以跳过这一步。然后，您需要连接到中继或硬件支持点来建立HWBridge会话。

**我能做什么？**

这是HWBridge的初始版本，我们希望收到来自硬件开发人员和使用者的反馈。如果您希望看到更多的汽车特性，请告知我们。如果您是硬件开发人员且希望Metasploit具有更佳的兼容性，请告知我们如何帮助您。 

Metasploit将许多独立的软件和工具整合在一个框架中，而现在我们希望硬件也能如此。
