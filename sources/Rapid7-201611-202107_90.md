# 德国电信通告称：被网络攻击事件影响客户已达90万

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4OTUxMzA1NA==&mid=2247483759&idx=1&sn=29aba4688adb8e6fd1d3c8ebc6fa33c0&chksm=ec2f4a5edb58c34841cac83ea4b721bab3de0cfe3f6fe6b206d48285932a520ea93c5f839aab&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4OTUxMzA1NA==&mid=2247483759&idx=1&sn=29aba4688adb8e6fd1d3c8ebc6fa33c0&chksm=ec2f4a5edb58c34841cac83ea4b721bab3de0cfe3f6fe6b206d48285932a520ea93c5f839aab&scene=27#wechat_redirect)

上个周末，德国电信着手调查因网络攻击导致的多达90万客户的网络中断问题。

德国电信正在调查是否由黑客攻击造成了网络中断。

![](../Images/476e76d475b96880984aa9fb9f0ad3d2.png)  
断网事故始于当地时间11月27日（周日）17：00左右，持续数个小时。周一上午08：00，再次出现断网问题。除了联网服务外，德国电信用户还用这些路由器来连接电话和电视服务。如果得到证实，这将是德国电信集团第一次遭受的重大网络攻击事故，这样的安全漏洞突显了大公司安全防御的脆弱性。

在一份声明中，德国电信表示：不排除网络故障是由外部攻击所导致的可能性，其结果是造成一些提供电话，互联网和在线电视服务的路由器无法再公网注册。  

发言人表示，只有路由器中的某些软件受到影响，这表明该问题是由黑客造成的，但没有证据表明任何客户数据被盗窃。

该公司称，其2000万固定用户中有90万已经在周日下午出现网络问题。到星期一下午，遭受网络中断的用户数已降至40万。

德国电信表示，一些客户看到“非常明显的质量波动，但也有客户的网络不在服务区”。补充到：该网络以全面投入运行，但还有特定的路由器还会出现问题。

![](../Images/c114ac2d2de0a28dbc810f961274caed.png)  

目前已证实引起此次攻击事件是由11月初公开的Zyxel DSL调制解调器漏洞造成。该调制解调器被重新标记并分发给整个欧洲的许多DSL宽带用户。 大约19天后，这个漏洞被利用在互联网上的广泛攻击，显然与新一轮的未来僵尸网络活动有关。

同时确定了两个问题，两个涉及DSL调制解调器上的TR-064 SOAP服务，在TCP端口7547上运行。第一个是设备解析新的NTP服务器配置方式的命令注入漏洞，其中攻击者可以封装任意shell命令在设置 NewNTPServer1 参数时的反引号(')。第二个是信息泄漏漏洞，攻击者可以访问GetSecurityKeys命令来探测设备的WiFi和密码。

在11月29日，Metasploit开源项目已经开始工作，将Kenzo的原始的，特殊目的的概念验证漏洞转换为一个更通用的Metasploit模块，可用于以更安全和更可控的方式测试漏洞。该工作在github持续进行Pull Request #7626

https://github.com/rapid7/metasploit-framework/pull/7626

![](../Images/9c60fd41bc2fa23da4fe05dbc94e1577.png)  

Rapid7的Heisenberg Cloud开始在11月26日收到对端口7547的恶意SOAP HTTP POST请求。 我们能够自动处理这些请求。 到目前为止，我们已经看到超过63,000个特殊的源IP地址尝试接管DSL路由器，在11月27日的当天超过35,000次尝试的峰值。

![](../Images/e3c7ef18c142873f39308ae4a85074e1.png)  
如果你是DSL的用户，你肯定会担心被攻击。如果从InTelnet访问TCP7547端口访问Internet的，你可以使用Nexpose或AppSpider的端口扫描服务。如果端口超时或其不可到达，那么你是安全的。如果它是可访问的，你应该联系你的ISP，

互联网服务供应商，这是有很大风险的行为，暴露出在Internet上的TR-069或TR-064服务资源；而ISP可能需要访问此端口上的用户设备进行常规的配置维护，它使用防火墙规则来限制访问这些端口仅来自ISP的IP地址以管理网络。  

![](../Images/2b734f787340f9a1ddfa8837d990284e.png)  

客服部门建议用户断开设备，等待30秒，重启路由器。在启动过程中，路由器将从德国电信服务器上下载最新固件。如果这个方法无法让路由器恢复连接，那么建议将路由器从德国电信网络彻底断开。除此之外，德国电信还提供免费移动网络，直至技术问题得到解决。

德国电信最近一次遭受如此规模的网络中断是在今年6月，起因是一个数据库故障导致其数百万计的移动用户失去连接。

电信公司一直是黑客们受欢迎的目标。上个月初，一名17岁的青年坦白了与去年在TalkTalk上的数据泄露相关的七次黑客攻击，此次事件影响了156,000名客户。

9月，雅虎透露，在2014年底，500亿雅虎帐户的详细信息被黑客入侵。
