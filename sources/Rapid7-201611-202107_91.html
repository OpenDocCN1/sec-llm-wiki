2015 年 10 月，Intel Security 宣布停止使用 (EOL) McAfee Vulnerability Manager 

作为McAfee的现有客户, 从现在使用的McAfee MVM产品切换到公认的业内领先的Rapid7 Nexpose解决方案是非常简单的。Nexpose是全球领先的漏洞扫描和风险管理解决方案。

McAfee宣布结束MVM产品的研发和销售，选择Rapid7作为独家合作伙伴，继续为已有客户提供漏洞管理服务。

在过去的一年，Rapid7已经成功的帮助很多组织和客户从MVM产品切换到Nexpose解决方案 ，因此，我们期待着同您的公司展开合作，用我们屡获殊荣的产品和解决方案帮助您进一步提升安全风险管理水平。

Symantec™ Control Compliance Suite(CCS) Vulnerability Manager 针对应用程序、数据库、服务器和网络设备提供了端到端的发现和漏洞评估功能，包括 Supervisory Control And Data Acquisition (SCADA) 系统。网络管理面板提供了威胁情报的单一视图，跨整个网络和虚拟环境，包括受管和未受管设备。先进的风险评分功能能够将潜在的漏洞从真正的威胁中区分开来，这样便能优先解决最关键和可能被利用的漏洞。

值得一提的是CCS 一直是OEM rapid7的产品，renew到明年8月份将停止更新。所以如果您之前使用Symantec的漏洞扫描产品，请不要担心，您可以平滑迁移到nexpose上来，功能、性能、以及使用方法上跟您之前完全一致。

Rapid7漏洞扫描和风险管理解决方案—Nexpose：

*  帮助您实时监测资产变化；

*  扫描漏洞情况；

*  评估安全风险；

*  验证漏洞暴露风险；

*  监测漏洞修补情况；

*  提高合规效率；

* 全面管理企业信息安全风险。

通过Nexpose Adaptive Security（自适应安全）紧随变化

Adaptive Security（自适应安全） 让您可以对最新的攻击漏洞和安全威胁自动产生响应动作。比如说，可以为所有的资产识别和评估设定一个基准线，当变化发生时，自动触发资产的定义和评估。当新的资产加入网络时，自动识别资产的情况，开启扫描任务，发现新的漏洞，您可以在预定扫描任务开始之前就及时识别最新的安全风险！

识别并及时响应高危漏洞

提升IT安全运维团队的价值和信誉。Rapid7漏洞研发团队和 Rapid7 实验室及我们Metasploit开源社区紧密合作，为我们的客户提供全球最快速和准确的漏洞信息及发现技术。当高风险的安全威胁发生时，例如： Heartbleed, Poodle, 或者BashBug 漏洞– Nexpose 帮助您区别优先级，追踪和验证漏洞修补情况。

执行有效的修补计划

全面降低安全风险，避免长篇大论难以操作的修补建议。在一页纸的范围内提供准确的、可操作的修补建议，真正降低安全风险。通过 RealCon-text™自动派发修补表单给特定的资产责任人，同时具有针对性、简洁性、可操作性，清晰的step–by–step的操作建议，让IT运维团队能够快速的降低安全风险。


采用RealRisk™，专注在最高风险的事件

Nexpose 采用独特和先进的漏洞风险评分系统：RealRisk™，为客户提供独特的算法和视角，窥见漏洞的真实风险级别，RealRisk™结合了真实攻击手段、恶意程序传播风险、 CVSS v2、暴露时间风险、,资产重要性等各个方面，生成真实的安全风险分数！

区别优先级,什么才是最关键的！

修补所有的安全风险是不可能完成的任务。通过Nexpose, 藉由全球领先的安全智能服务，同你业务相关性最高的风险将优先被修补。投入最少的精力，专注于最有效的修补措施，让您真正的有效降低安全风险，保证安全运维团队的专注，提升效率！

基于Best Practice部署安全控制解决方案

您是否知道部署那些安全控制手段可以有效降低安全风险？Nexpose 能够准确定位您安全防御系统的缺失并提供针对网络和终端防御系统的调整建议。这些强大的功能让您能够整合已有的解决方案应对最新的各类安全威胁，给IT管理团队足够的时间，经过测试和验证，最终修补漏洞，降低风险！
