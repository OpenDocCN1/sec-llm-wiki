新版漏扫和风险管理平台 Nexpose 6.4.6 现已发布！新的功能以及客户端补丁在下表列出，详细描述请查看rapid7社区博客。

https://community.rapid7.com/community/nexpose/blog/2016/11/08/patch-tuesday-november-2016

新功能:

Nexpose与McAfee的ePO和DXL产品做整合

- Nexpose可以直接从McAfee ePolicy Orchestrator导入资产,确保在ePO中新发现的资产可被Nexpose收集和评估。(见以下截图)


- Nexpose对McAfee恶意文件检测事件进行自动响应，并自动标记可疑资产。

- Nexpose将漏洞风险评分发布到McAfee ePO生成新的Dashboard。并在ePO中更好地确定风险等级。

- Nexpose会将资产上新的漏洞发布到McAfee Data Exchange Layer(DXL )。 客户或合作伙伴可以通过订阅DXL，以了解并自动对您所在环境中的风险威胁进行响应。

数据库导出

您可以配置安全控制台将数据导出到外部数据库，以提高性能报告。使用此功能获取更丰富的数据，以便与您自己的内部报告系统（如业务智能工具）集成。导出现有的报告模板,加载到目标库中。

客户受影响的BUG修复:

References

Details

NEX-47731

Session login fails when the user is already logged in  (e.g. CI login workflow)

IS-6880

Fixed an issue that prevented users with the  ControlsInsight role from being able to log into ControlsInsight properly.

NEX-47051

Reporting data model validate is not threadsafe

IS-6552

Fixed an issue where attempting to save multiple SQL  Query Export reports at the same time via the API would fail during the  validation process.

NEX-49435

Improve tolerance of policy assessment integrator:  Policy check result update

IS-7308

We have addressed an issue where a policy rule result  with duplicate checks could cause scan integration to fail.

NEX-44587

Vulnerability age between CSV and Reporting Data Model  inconsistent

IS-6206

Corrected an issue that would cause the age function in  the reporting data model to calculate age incorrectly across certain date  ranges. This is available in version 2.1.0 of the reporting data model.

NEX-31556

Disabling data warehousing requires the user to enter  the database password

IS-6590

We have corrected an issue where the user could  inappropriately disable the data warehousing option.

NEX-49436

Unable to edit Nexpose report config on touchscreen  devices

IS-7309

Addressed an issue where some users were unable to edit  report configurations on touchscreen devices.

NEX-43327

Discourage and require confirmation to run reindex  database maintenance tasks

IS-7314

We inform the user when choosing to reindex the  database that the operation is expensive and also require confirmation to do  so.

NEX-49520

vSphere discovery connection can fail due to whitespace  in IP address of VM or resource

IS-7353

We have fixed an issue where vSphere discovery  connections would fail altogether if a VM's IP address value contained an  unexpected space.

DCA-6553

WMI client does not register a reference with the WMI  service.

IS-7355

In order to maintain scan accuracy and performance, we  have fixed an issue where the WMI service could shut down in the middle of a  scan, causing a loss of connectivity.

DCA-4048

Windows HotFix used hardcoded WordViewer  file  paths

IS-6786

An issue with MS13-072 that could cause false positives  when Word Viewer is installed has been resolved.
