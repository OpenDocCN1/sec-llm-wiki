ZSH和oh my zsh的安装就省略过了

主题选择powerlevel10k,在9k的基础上提升了流畅性,官方说的是10-100倍,实际使用情况来说- `OK`

安装:

```
1.  `git clone --depth=1 https://github.com/romkatv/powerlevel10k.git $ZSH_CUSTOM/themes/powerlevel10k`
    
```

在 `~/.zshrc`里面设置主题名称

```
1.  `ZSH_THEME="powerlevel10k/powerlevel10k"`
    
```

然后

```
1.  `source ~/.zshrc`
    
```
