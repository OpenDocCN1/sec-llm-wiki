## WMI简介

WMI，是Windows 2K/XP管理系统的核心；对于其他的Win32操作系统，WMI是一个有用的插件。WMI以CIMOM为基础，CIMOM即公共信息模型对象管理器（Common Information Model Object Manager），是一个描述操作系统构成单元的对象数据库，为MMC和脚本程序提供了一个访问操作系统构成单元的公共接口。有了WMI，工具软件和脚本程序访问操作系统的不同部分时不需要使用不同的API；相反，操作系统的不同部分都可以插入WMI，如图所示，工具软件和脚本程序可以方便地读写WMI。

**定义**

```
1.  `WMI（Windows Management Instrumentation,Windows 管理规范）是一项核心的 Windows 管理技术；用户可以使用 WMI 管理本地和远程计算机。`
    
```

## 探索Namespaces

查询所有的命名空间

```
1.  `wmic /namespace:\\root path __namespace`
    
```

![](../Images/bbda6ad4a96e728bef890070bd5b77bc.png)

使用ps

```
1.  `Get-WmiObject -namespace "root" -class "__Namespace" | Select Name`
    
```

![](../Images/91f723e55b23fa77b6f7a8c6205b9534.png)

使用WQL

```
1.  `Get-WmiObject -Query "Select * from __Namespace" -Namespace Root | select Name`
    
```

## 探索Classes

获取相应命名空间的类列表

```
1.  `Get-WmiObject -Namespace root\cimv2 -List`
    
```

![](../Images/130b36226fc61f511cdcd1d2a2e2b564.png)

每个命名空间都包含类 类包含

*   属性-可以查询的信息
    
*   方法-执行的功能
    
*   实例
    
*   事件-生成有关WMI数据和服务更改的通知。

*   Call – 调用方法
    
*   Set
    
*   Create

WQL查询一些别名

```
1.  `wmic alias list brief`
    
```

  

![](../Images/ebdcf7662a8de8d78e89f1cbb2880d60.png)

根据别名查询信息,比如进程

```
1.  `wmic process where name='lsass.exe' list brief`
    
```

![](../Images/958e87d42523a28d7a03a3e911c42426.png)

使用get获得信息

```
1.  `wmic process where name='winword.exe' get name, executablepath`
    
```

![](../Images/736306b509b3316a60441c2136e28ffa.png)

```
1.  `wmic process where name='winword.exe' call GetOwner`
    
```

![](../Images/084a01b1c70a491b4882737ca9e473fc.png)

WMI调用可执行程序

```
1.  `wmic process call create 'calc.exe'`
    
```

终止

```
1.  `wmic process where name='notepad.exe' call Terminate`
    
```

### 使用powershell

```
1.  `Get-WmiObject -Class Win32_Process -Filter 'name="winword.exe"'`
    
```

获得更多属性

```
1.  `Get-CimInstance -Class Win32_Process -Filter "name='winword.exe'" -Property Caption, ProcessID, ExecutablePath`
    
```

使用WQL

```
1.  `Get-WmiObject -Query "Select Caption,ProcessID,ExecutablePath from Win32_Process where name='winword.exe'" -Namespace root\cimv2`
    
```

得到所有方法

```
1.  `(Get-WmiObject -Class Win32_Process -List).Methods`
    
```

调用方法

```
1.  `Invoke-WmiMethod -Class Win32_Process -Name Create -ArgumentList @(calc.exe)`
    
```

![](../Images/7367f3397198656dfbc4d1a4dc6318c3.png)

```
1.  `Invoke-CimMethod -ClassName Win32_Process -Name Create -Arguments @{Commandline = 'calc.exe'}`
    
```

## WMIC横向移动

```
1.  `wmic /NODE:"servername" /USER:"yourdomain\administrator" /PASSWORD:password OS GET Name`
    
```

```
1.  `$cred = Get-Credential domain\user`
    
```

```
1.  `Invoke-WmiMethod -Class Win32_Process -Name Create -ArgumentList @(calc.exe) -ComputerName servername -Credential $cred`
    
```

Linux下

```
1.  `pth-wmic -U domain/adminuser%LM:NT //host "select * from Win32_ComputerSystem"`
    
```
