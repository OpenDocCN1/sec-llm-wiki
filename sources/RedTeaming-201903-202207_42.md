docker搜索Redis镜像

```

docker search redis
```

拉去镜像到本地

```

docker pull redis
```

查看下载好的镜像

```


docker images
```

运行镜像

```

docker run -p 6379:6379 -d redis
```

```



-p 将容器的6379端口映射到主机的6379端口。
```

apt安装apache2，sudo，net-tools  
然后docker commit 保存容器状态。  
然后就一个重要的点，如何自定义配置文件。

```


mkdir /home/docker/redis/{conf,data} -p
```

获取 redis 的默认配置模版

```

wget https://raw.githubusercontent.com/antirez/redis/4.0/redis.conf -O conf/redis.conf
```

```


# bind 127.0.0.1
```

创建环境

```

docker run -it -p 6379:6379 -p 8888:80 -v $PWD/data:/data -v $PWD/conf/redis.conf:/etc/redis/redis.conf wing/resdislab sudo redis-server /etc/redis/redis.conf
```

这里redis-server要用sudo权限，所以前面安装sudo，否则后面save就会失败。
