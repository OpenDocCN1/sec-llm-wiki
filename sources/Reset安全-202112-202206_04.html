1.使用迅捷PDF编辑器新建一个空白页。
2.点击“视图”，显示页面缩略图。
3.点击缩略图部分，右键属性。
4.选择动作“打开页面”，在此插入XSS代码。
try {  app.alert("XSS")} catch (e) {  app.alert(e.message);}

5.保存，使用浏览器打开，即可弹窗。
