1 gopher协议介绍
    Gopher是Internet上一个非常有名的信息查找系统，它将Internet上的文件组织成某种索引，很方便地将用户从Internet的一处带到另一处。
    gopher协议支持发出GET、POST请求：可以先截获get请求包和post请求包，在构成符合gopher协议的请求。
    gopher协议是ssrf利用中最强大的协议。
2 Gopherus脚本介绍
    该工具生成gopher链接，用于利用SSRF并在各种服务器中获得RCE。
    如果您知道某个地方存在SSRF漏洞，那么该工具将帮助您生成Gopher有效负载，以利用SSRF（服务器端请求伪造）并获得RCE（远程代码执行）。
    项目地址：
https://github.com/tarunkant/Gopheru
3 支持payload
  1. MySQL (Port-3306)
  2. PostgreSQL(Port-5432)
  3. FastCGI (Port-9000)
  4. Memcached (Port-11211)
        If stored data is getting De-serialized by:
          * Python
          * Ruby
          * PHP
  5. Redis (Port-6379)
  6. Zabbix (Port-10050)
  7. SMTP (Port-25)
