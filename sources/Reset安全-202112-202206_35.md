# Apache Druid任意文件读取漏洞复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU3Mzg1NzMyNw==&mid=2247484183&idx=1&sn=64277ba4c54598d1faed1cb504510aaa&chksm=fd3a0857ca4d8141498f45a30ed6063c1ad4ab4e1a3f8addf7e0735f7434a5f56c40044bd9fa&scene=126&sessionid=1681654927#rd](http://mp.weixin.qq.com/s?__biz=MzU3Mzg1NzMyNw==&mid=2247484183&idx=1&sn=64277ba4c54598d1faed1cb504510aaa&chksm=fd3a0857ca4d8141498f45a30ed6063c1ad4ab4e1a3f8addf7e0735f7434a5f56c40044bd9fa&scene=126&sessionid=1681654927#rd)

**1 漏洞介绍**    Apache Druid存在任意文件读取漏洞（CVE-2021-36749），攻击者可通过将文件URL传递给HTTP InputSource，因Apache Druid默认情况下缺乏授权认证，即攻击者可构造恶意请求，在未授权情况下利用该漏洞读取任意文件，可导致服务器敏感信息泄漏。![](../Images/6c9079ba888f1e0b83f6172071ef0d76.png)

**3 漏洞复现**  
（1）直接访问Druid页面，无需认证，点击Load data选项。![](../Images/6fc319c8ffc02169922bd9aa399e14f7.png)（2）点击HTTP(s)选项，连接数据。  
![](../Images/9c6973cb0ed95a25fe79244b710bbcbe.png)（3）选择源类型为local，目录为/etc，文件为passwd，点击Apply，成功回显文件内容。  
![](../Images/a19f6a7e4ea2a8dd5ba718862a71cc12.png)（4）若是无法进入Load data选项，可直接构造POST请求包向接口/druid/indexer/v1/sampler发送。
