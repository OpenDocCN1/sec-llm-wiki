**1 漏洞描述**    用友 NC 是一款大型 erp 企业管理系统与电子商务平台。2021年5月27日，CNVD 发布关于用友 NC 远程代码执行漏洞的漏洞信息，编号为 CNVD-2021-30167。![](../Images/773b5312c6868cc15c80ea1b2a3d70f4.png)    由于用友 NC 某处安全校验不严，攻击者可在远程且未经授权的情况下直接访问 BeanShell Test Servlet，从而可通过 BeanShell 执行任意恶意 Java 代码，获取系统权限。
