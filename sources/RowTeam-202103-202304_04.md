相比于 2023-02-04 v1.1.9 版本，该版本有以下几点的变化

### 新增内容

1.通过遍历对应的接口，发送 HTTP/1.0 请求，试图获取到内网IP。目前对于获取到的结果进行简单的判断，判断它是否是已知的内网 IP 段，如果是，则输出第一个获取到的值，否则不进行输出。由于是遍历请求，因此请求时间增加了不少。2.从 SSL 证书中获取一些数据，这个数据可以辅助判断该目标是否是我们想要的。

### 优化内容

1.target 输入框可回车，等同于点击 GOGOGO2.GUI 比原来大了一些3.将线程池更换为任务4.优化 Exchange 版本获取，增加获取精确版本的概率5.为了为反编译者增加学习成本，打包工具从 Fody 更换为 ConfuserEx

### 发现的问题

•由于暂时无法解决在 Windows 7 出现的 SSL/TLS 问题，因此 Windows 7 无法在线拉取版本信息对比，建议使用 Windows 10 。•有些环境在获取机器名称时，发现与 X-FeServer 的结果不一致，这个不是工具问题，是它架构问题。•网络不好的情况下会自动关闭程序。
