0x00 项目介绍

该项目是在 获取 .NET Web 框架权限后，上传特定的 aspx 脚本获取相关数据，然后进行权限维持使用。

0x01 使用说明

config 中的文本框需要填入输入，红框的数据是必须要填写的。

特别说明：如果 Mode 为 45，则两个 Decryption 是必须填入的，并且需要勾选 .NET4.5。
