数据渗出往往需要一个媒介作为通道，本文就初步以 OneDrive 作为通道，进行第一步的介绍 -> Token 的获取。

0x00 注册应用及配置

访问 https://portal.azure.com/#home，进行设置。直接看图即可。











0x01 获取 Token

1.1 获取 Authorization code

访问以下链接。

https://login.microsoftonline.com/common/oauth2/v2.0/authorize?client_id={client_id}&redirect_uri=http://localhost:65001/rowteam&scope=files.readwrite offline_access&response_type=code




在输入账密进行登录之后，将得到code值。

1.2 获取 Access Token 和 Refresh Token

https://login.microsoftonline.com/common/oauth2/v2.0/token
httpbody:code={0}&client_id={1}&redirect_uri=http://localhost:65001/rowteam&grant_type=authorization_code




1.3 通过 Refresh Token 获取 Access Token

https://login.microsoftonline.com/common/oauth2/v2.0/token
httpbody:refresh_token={0}&client_id={1}&grant_type=refresh_token

        HttpWebResponse response = (HttpWebResponse)request.GetResponse();        using (var reader = new StreamReader(response.GetResponseStream()))        {            string jsonText = reader.ReadToEnd();            JObject jo = (JObject)JsonConvert.DeserializeObject(jsonText);            token.Add(jo["access_token"].ToString());            token.Add(jo["refresh_token"].ToString());        }    }    catch (WebException ex)    {        HttpWebResponse responseEx = ex.Response as HttpWebResponse;        using (var reader = new StreamReader(responseEx.GetResponseStream()))        {            string result = reader.ReadToEnd();            Console.WriteLine("Exception: {0}", result);        }    }    return token;}
