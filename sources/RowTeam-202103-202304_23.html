0x00 前言

本文将对 https://github.com/RcoIl/CSharp-Tools/tree/master/SharpVssown 进行一个补全。

SharpVssown 工具是在参考 vssown.vb源码的情况下使用 Csharp 编写的一款 vss 利用工具。

在编写完成之后，存在一些不足，但我也没有对其进行补全，只不过在前段时间对域内工具进行了一个梳理，所以顺便做了修补。

已有功能

•查询 vss 服务的状态•启动 vss 服务•停止 vss 服务

•创建快照•删除快照（待完善）



0x01 补全删除

原有方法[1]是使用了 powershell 进行操作，这样一来就需要引入相应的库，不划算。

当时也是脑子没转过来才导致的写法。因此在完善过程中，直接删除相应的类对象即可。

static void DeleteShadow(string ShadowID){    try    {        ManagementClass shadowCopy = new ManagementClass(scope, new ManagementPath("Win32_ShadowCopy"), null);
        // 现在循环遍历我们为该命名空间类找到的所有对象实例        foreach (ManagementObject WMIChild in shadowCopy.GetInstances())        {            if (WMIChild.Path.Path.Contains(ShadowID))            {                WMIChild.Delete();                Console.WriteLine("[*] Attempting to delete a shadow copy. ShadowID: " + ShadowID);            }            WMIChild.Dispose();            break;        }    }    catch (ManagementException ex)    {        Write.Error($"An error occurred while trying to execute the WMI method: \r\n{ex}");    }    catch (Exception ex)    {        Write.Error(ex.Message);    }}

0x02 补全可远程查询等操作

原有方法是仅对本地进行操作，无法远程操作，这也不符合我们理想操作，所以也需要进行修改

string wmiNameSpace = @"root\cimv2";if(ip != null){    wmiNameSpace = $@"\\{ip}\{wmiNameSpace}";}ConnectionOptions Conn = new ConnectionOptions();if (username != null && password != null){    Conn.Username = username;    Conn.Password = password;}
ManagementScope scope = new ManagementScope(wmiNameSpace, Conn);scope.Connect();

后续也将 ManagementObjectSearcher 和 ManagementClass 等涉及到 wmi查询的使用进行替换即可。

比如

ManagementClass shadowCopy = new ManagementClass(scope, new ManagementPath("Win32_ShadowCopy"), null);
