#   

JavaScript 是 web 开发者必学的三种语言之一：  
  

*   *HTML* 定义网页的内容
*   *CSS* 规定网页的布局
*   *JavaScript* 对网页行为进行编程

  
JavaScript与php、asp等语言不同，js源代码可以轻松被任何人获取到。
