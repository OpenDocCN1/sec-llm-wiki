# 【资讯】程序猿的愤怒？有史以来 GitHub Star 数上涨最快的一个项目诞生

程序员不能忍996了！没有X生活，生病ICU，发起抗议网站，GitHub一小时破千星。而这个项目的作者，是一个昨天刚刚注册的小号，名字就叫996icu。

![](../Images/daeb9f90ba7e68efc08a3723e38257f7.png)

（注：本文部分图片引用自公众号“量子位”）

上图是昨天的数据，截止今日上午11：05。star数已破8万，目前仍在爆发式增长。作者还算出了经济账的工资，可见积怨已久。

![](../Images/2cce503029ec9d278e7b953ac795122a.png)

同时，该问题在知乎也引发了激烈的讨论，一时间怨声载道。

![](../Images/302ef7a556fb0831e052cf0ccb13483d.png)

  

  

![](../Images/7c1cbf3ae4009275515d556725a04445.png)

这里不得不提一下，两家重量级的公司，**有赞和京东**。

996，似乎是很多互联网公司的传统，但今年又被推上风口浪尖，原因还是最近有赞和京东两家公司的996工作制。

  

![](../Images/9ef1cbefbce4578b17ce5622caa75f6b.png)

2019年1月17日，有赞把自家的年会变成了“鸿门宴”，公开宣称实行996工作制：

所谓正常工作时间，已经变成了早上9:30到晚上21:00，每天的工作时长长达十一个半小时。一旦公司出现紧急项目，一周将强制工作6天，项目做不完的话，那还请自行延长。

公开宣布后，有赞还制定了具体的规章制度：如果晚上9点前下班，还需要走年假流程，否则就是旷工。

特立独行的有赞CEO白鸦，成为了国内IT界公然对抗国家法律法规第一人。

![](../Images/9db0c37ff349410b08c17caa0a850920.png)

  

![](../Images/5124753810f887f1c707f7a25738be15.png)

有赞不是第一家，也不是最后一家。  

当北京亦庄的京东程序员欢欢喜喜过完年回来，也没想到自己也成了996事件的主角。

纸包不住火，上个月，陆续有京东员工在社交平台透露，京东开始施行类似的995工作制，并且995的“超长待机”时间外，依旧没有加班费。

这些传言很快被证实。没几天，京东大快消事业群公关总监刘力回应称，不会强制要求员工加班，但鼓励大家全情投入，高效产出，不仅为客户和合作伙伴，也为自己和家人创造出更大的价值。

![](../Images/3c07ddaae2c6eda4dd61f453755f5265.png)

还有飞速发展的字节跳动，今年也制定了一项所谓的大/小周工作政策，每隔一周，大部分员工周天也需要加班。  

和996相比，大小周的政策如同换了汤却没有换药。

![](../Images/7c1cbf3ae4009275515d556725a04445.png)  

![](../Images/a59e3aee29e7f13cba024f1f734dff11.png)

已经有人奋起反抗，这场没有硝烟的对抗资本的战争，又将何去何从呢？我们拭目以待。
