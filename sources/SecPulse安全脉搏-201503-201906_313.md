# 安识科技荣获阿里ASRC2016年度优秀生态合作伙伴

2017年4月1日，好雨时节艳阳斜，诗画西溪聚英杰，阿里安全响应中心主办的ASRC 2017 生态大会于杭州西溪宾馆隆重召开。

  

![](../Images/6f3f8b6b64833545792bf79490a19a54.png)

          

安识科技荣获阿里安全应急响应中心(ASRC)"2016年度优秀生态合作伙伴"公司，携手阿里巴巴，一起守护上亿用户的信息安全，打造最安全、最有保障的电子商务交易平台。

  

![](../Images/7e7c14a6ba8a1b1e7eef1b9a109d4f97.png)

  

此前安识科技凭借领先的核心技术优势和团队协同创新能力[荣获阿里云先知“2016年度最佳合作安全公司”top1](http://mp.weixin.qq.com/s?__biz=MzAxNDM3NTM0NQ==&mid=2657031613&idx=1&sn=7b71ce198f69380fa8392d6ec89f2cf0&chksm=803ff563b7487c752ab8bd10cc90f0b7a2c5d1031d5b6e7d2a523dd4b5ea52b76238ef38419f&scene=21#wechat_redirect)。

  

![](../Images/35ba644260752fedf9a81ed9a93cee94.png)  

  

2017财年（2016.4-2017.3）ASRC的有效提交白帽比去年多了33%，有许多优秀的个人、团队和公司与ASRC展开了合作尝试一起解决阿里生态安全的问题；

生态合作伙伴众测就是专注于发现阿里巴巴集团生态合作伙伴高危风险的专项活动；

而类似安识科技这样的专业第三方安全公司及早地介入生态，对可信众测和SRC都是一个极大的帮助，希望生态圈能有更多更广的拓展，大家一起保护上亿用户信息安全。
