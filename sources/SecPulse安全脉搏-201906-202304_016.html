1. 通告信息



近日，安识科技A-Team团队监测到Apache发布安全公告，修复了Linkis DatasourceManager模块中的一个反序列化漏洞（CVE-2022-44645）和一个文件读取漏洞（CVE-2022-44644）。
对此，安识科技建议广大用户及时升级到安全版本，并做好资产自查以及预防工作，以免遭受黑客攻击。


2. 漏洞概述



CVE：CVE-2022-44645/CVE-2022-44644
漏洞名称：Apache Linkis反序列化漏洞/Apache Linkis文件读取漏洞
简述：Apache Linkis（Incubating）是一个开源的上层应用与底层引擎之间的计算中间件，提供了强大的连接、复用、编排、扩展和处理能力。
CVE-2022-44645：Apache Linkis反序列化漏洞
Apache Linkis版本<=1.3.0与MySQL Connector/J一起使用时，当对数据库具有写入权限并使用MySQL数据源和恶意参数配置新数据源时，存在反序列化漏洞，可能导致远程代码执行。
CVE-2022-44644：Apache Linkis文件读取漏洞
Apache Linkis版本<=1.3.0与MySQL Connector/J一起使用时，通过在jdbc参数中将allowLoadLocalInfile添加为true，经过身份验证的用户可以通过连接恶意MySQL服务器读取任意本地文件。


3. 漏洞危害



该漏洞可以导致远程代码执行以及通过连接恶意MySQL服务器读取任意本地文件。


4. 影响版本



目前受影响的Apache Linkis版本：
Apache Linkis 版本 <= 1.3.0


5. 解决方案



目前这些漏洞已经修复，受影响用户可及时升级到Apache Linkis 1.3.1版本。

https://github.com/apache/linkis/releases
