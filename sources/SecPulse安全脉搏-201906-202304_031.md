### **分析Emotet木马中的cmd命令**

Emotet一款著名的银行木马，首次出现于2014年年中。该木马主要通过垃圾邮件的方式传播感染目标用户，其不断变化传播花样，采用越来越复杂的混淆编码来躲避检测。  
现在我们以Emotet木马为例，我们来试着分析一下经过混淆后的cmd内容

![](../Images/e4c76b6aeef6cf7e7cba3734d1065c2e.png)

先将混淆cmd命令中的转义字符“^”全部去掉，再将除了变量@之外的逗号“,”、分号“;”、多余空格删除。注意保留变量@中的逗号和分号，否则影响输出结果。  

![](../Images/03344ada2b6d4dfd026ae95ec86484bb.png)

  

下图为无意义的四个字符串，cmd会自动忽略。

![](../Images/b3e6e986f511a2f476ed4439e39cca95.png)

可以看出这里利用了cmd的系统环境变量`%comspec%`，即是cmd.exe的执行路径，因此会执行cmd命令，这里才是命令的真正开头。因此程序开头可以进行化简。

![](../Images/79417f31725adb4b4f4365c882cb1441.png)

去除无意义的字符串后可以化简为

*   

```

```

先利用`%comspec% /c`执行第一个for循环，再利用`for`循环的`/f`参数，在命令`assoc .cmd`结果`.cmd=cmdfile`中以字符v、f、=为分隔符，取第二列即是“`cmd`”。

![](../Images/3bf51179520e3b6d4a4a206969cd1370.png)

因此这里用for循环生成的cmd又开启了新一个cmd程序来运行下面的字符串内的程序。

![](../Images/00f4a49d6460a7a19ca72df7461edbf5.png)

这里自定义了一个环境变量`@`，等于一个1460长度的字符串。然后利用for循环的/L参数，遍历变量`@`：`for /L %s in (1459,-4,+3 ) do set \=!\!!@ :~ %s, 1!& if %s equ 3 call %\:~-365%`，这个for循环自定义了环境变量"`\`"，还启用了延迟的环境变量扩展`!`，`!@:~%s,1!`表示循环变量`%s`从1459开始，步长为`-4`，到`3`结束，循环提取变量`@`中的字符，添加到`\`变量中。当`%s`到`3`的时候就会执行`\`中倒数365个字符组成的程序。

![](../Images/523214b98ef7a2970d3af35c18122211.png)

## 1.4 逻辑运算符在绕过中的作用

`|` 在cmd中，可以连接命令，且只会执行后面的命令

*   
*   

```
whoami | ping -n 1 www.baidu.com   //只执行pingping -n 1 www.baidu.com | whoami   //只执行whoami
```

![](../Images/fba5828035b9c4dce63d8b43e7d7877b.png)

`||` 只有在前面命令失败才执行后面

*   
*   

```
ping 127.0.0.1 || whoami //不执行whoamiping xxx. || whoami //执行whoami
```

![](../Images/f49fea9316c02dfa227f01331be0f0af.png)

`&`无论前面的命令是否能执行成功都会执行后面的命令

*   
*   

```
ping 127.0.0.1 & whoami //执行whoamiping xxx. & whoami //执行whoami
```

![](../Images/5c71feb1e9e787a098b34a36a5a696a9.png)

`&&`前面命令为真才会执行后面的命令。

*   
*   

```
ping 127.0.0.1 && whoami //执行whoamiping xxx. && whoami //不执行whoami
```
