# 【漏洞预警】Apache Tomcat信息泄露漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxNDM3NTM0NQ==&mid=2657044823&idx=1&sn=db6cf1308a5e0575c53cbd146f76443c&chksm=803fa989b748209ff55dc29cc3bd66ec16adb130e8973789dda33ba2f438e2a147f95add0e51&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxNDM3NTM0NQ==&mid=2657044823&idx=1&sn=db6cf1308a5e0575c53cbd146f76443c&chksm=803fa989b748209ff55dc29cc3bd66ec16adb130e8973789dda33ba2f438e2a147f95add0e51&scene=27#wechat_redirect)

##   

1. **通告信息**

  
  

## 

近日，安识科技A-Team团队监测到一则 Apache Tomcat中的一个信息泄露漏洞，漏洞编号：CVE-2021-43980，漏洞威胁等级：高危。该漏洞是由于某些Tomcat版本中的阻塞式读写的简化实现导致存在并发错误（极难触发），可能使客户端连接共享一个Http11Processor实例，导致响应或部分响应被错误的客户端接收，造成信息泄露。

对此，安识科技建议广大用户及时升级到安全版本，并做好资产自查以及预防工作，以免遭受黑客攻击。

##   

2. **漏洞概述**

  
  

## 

CVE：CVE-2021-43980

简述：Apache Tomcat是一个流行的开源Web服务器和Java代码的Servlet容器。

该漏洞是由于某些Tomcat版本中的阻塞式读写的简化实现导致存在并发错误（极难触发），可能使客户端连接共享一个Http11Processor实例，导致响应或部分响应被错误的客户端接收，造成信息泄露。

##   

3. **漏洞危害**

  
  

## 

攻击者可利用该漏洞获取敏感信息。

##   

4. **影响版本**

  
  

## 

Apache Tomcat 10.1.0-M1 - 10.1.0-M12

Apache Tomcat 10.0.0-M1 - 10.0.18

Apache Tomcat 9.0.0-M1 - 9.0.60

Apache Tomcat 8.5.0 - 8.5.77

##   

5. **解决方案**

  
  

## 

目前该漏洞已经修复，受影响用户可以升级到以下版本：

Apache Tomcat 版本 >= 10.1.0-M14

Apache Tomcat 版本 >= 10.0.20

Apache Tomcat 版本 >= 9.0.62

Apache Tomcat 版本 >= 8.5.78

注：10.1.0-M13、10.0.19和9.0.61未发布。

下载链接：https://tomcat.apache.org/
