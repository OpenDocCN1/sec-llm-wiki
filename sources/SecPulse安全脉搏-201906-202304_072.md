**0x02 Burpsuite安装**

Burpsuite程序文件为：  

![](../Images/b5f09f1a4eebf28e3209a2879fb53e39.png)

  

注册机程序文件为：由于市面上的注册机名字不一致，这里不做说明

  

1\. 给启动脚本加可执行权限，运行启动脚本并安装

*   
*   

```
chmod +x BurpSuiteLoader.sh./BurpSuiteLoader.sh
```

  

在弹出的安装界面：如下图操作即可

![](../Images/20b91c2f4a0e931c93b75e442e2d83dc.png)

  

和图中一样后，点击 I Accept(我同意)，这时，会弹出一个密钥验证页面

![](../Images/35b687a606577b8ff1a45ee69354c194.png)

  

在我们解压的目录里面有一个注册机

  

2\. 再打开一个终端，切换到我们解压的那个目录，然后启动注册机

*   

```

```

  

3. 激活Burpsuite

![](../Images/4ab46f9e84dc3a67dfe8c36c5bad0485.png)

  

然后点击Next，在弹出的页面中，选择手动激活！

![](../Images/86dc1be4f2f07391ba085d62d89b599b.png)

  

弹出的新页面中，复制激活请求

![](../Images/c03f1b671d9cd103fcdd55ad11243650.png)

  

粘贴后，注册机自动生成对应的激活密钥，然后将生成的密钥复制粘贴到Burpsuite

![](../Images/7e73ba313feecea357655e630c81d3c0.png)

  

然后，点击Next(下一步)

![](../Images/be22a5938653b35eb3bb5bac91bb020f.png)

  

如果过程没做错，就弹出该激活页面！

  

进入Burpsuitepro后，查看激活时长，点击功能栏，Help --- License
