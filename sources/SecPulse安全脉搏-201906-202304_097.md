# 【漏洞预警】Apache ShardingSphere ElasticJob-UI 权限提升 漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxNDM3NTM0NQ==&mid=2657044133&idx=1&sn=92048ac05706ee0aa056d9c04a4cc8de&chksm=803fa67bb7482f6d4ced1523c87e716a53155c7b16c85b2f93c53b25d0023afdc4f6f9fa05be&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxNDM3NTM0NQ==&mid=2657044133&idx=1&sn=92048ac05706ee0aa056d9c04a4cc8de&chksm=803fa67bb7482f6d4ced1523c87e716a53155c7b16c85b2f93c53b25d0023afdc4f6f9fa05be&scene=27#wechat_redirect)

1. **通告信息**

  

近日，安识科技A-Team团队监测到一则Apache ShardingSphere ElasticJob-UI 权限提升漏洞的信息，当前官方已发布受影响的补丁。

对此，安识科技建议广大用户及时升级到安全版本,并做好资产自查以及预防工作，以免遭受黑客攻击。

 

![](../Images/48e8f39a6f808346e4acea7ca95dade9.png)![](../Images/8ac18689a13ec378210125aa6dfae314.png)

2. **漏洞概述**

  

CVE-2022-22733该漏洞是由于返回 token 中包含了管理员密码，攻击者可利用该漏洞在授权的情况下，构造恶意数据执行权限绕过攻击，最终获取服务器最高权限。

  

![](../Images/48e8f39a6f808346e4acea7ca95dade9.png)![](../Images/8ac18689a13ec378210125aa6dfae314.png)

3. **漏洞危害**

  

攻击者可利用该漏洞在授权的情况下，构造恶意数据执行权限绕过攻击，最终获取服务器最高权限。

 

![](../Images/48e8f39a6f808346e4acea7ca95dade9.png)![](../Images/8ac18689a13ec378210125aa6dfae314.png)

4. **影响版本**

  

Apache ShardingSphere ElasticJob-UI <= 3.0.0

 

![](../Images/48e8f39a6f808346e4acea7ca95dade9.png)![](../Images/8ac18689a13ec378210125aa6dfae314.png)

5. **解决方案**

  

当前官方已发布最新版本，建议受影响的用户及时更新升级到最新版本。链接如下：https://shardingsphere.apache.org/document/current/cn/downloads/
