# 【漏洞预警】Apache HTTP Server 多个漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxNDM3NTM0NQ==&mid=2657043977&idx=1&sn=fb39d13a360f412e95ced8edd1e7fdc7&chksm=803fa6d7b7482fc1c2a512584a67bd4daee78a86f881e3dd3380f8818e302902d0eb58ffccc1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxNDM3NTM0NQ==&mid=2657043977&idx=1&sn=fb39d13a360f412e95ced8edd1e7fdc7&chksm=803fa6d7b7482fc1c2a512584a67bd4daee78a86f881e3dd3380f8818e302902d0eb58ffccc1&scene=27#wechat_redirect)

  
  

1. **通告信息**

  

近日，安识科技A-Team团队监测到一则 Apache 官方发布安全补丁的通告，共修复了2个安全漏洞，其中包含1个高危漏洞的信息。

对此，安识科技建议广大用户及时升级到安全版本,并做好资产自查以及预防工作，以免遭受黑客攻击。

 

  

2. **漏洞概述**

  

(1) CVE-2021-44224: Apache HTTP Server SSRF漏洞

(2) CVE-2021-44790: Apache HTTP Server 缓冲区溢出漏洞

简述：该漏洞是由于在 mod\_lua 中解析 multipart 内容时出现边界错误，攻击者可利用该漏洞触发缓冲区溢出并在目标系统上执行任意代码，最终可获取服务器最高权限。

 

  

3. **漏洞危害**

  

攻击者可利用该漏洞触发缓冲区溢出并在目标系统上执行任意代码，最终可获取服务器最高权限。

 

  

4. **影响版本**

  

Apache HTTP Server SSRF 漏洞：2.4.7 <\= Apache HTTP Server<=2.4.51

Apache HTTP Server 缓冲区溢出漏洞：Apache HTTP Server <= 2.4.51

##   

  

5. **解决方案**

  

当前官方已发布最新版本，建议受影响的用户及时更新升级到最新版本。链接如下：https://httpd.apache.org/download.cgi
