1. **通告信息**

![](../Images/1cc763b56252d9206c514193226a7a38.png)

  

近日，安识科技A-Team团队监测到 VMware 官方发布安全补丁的通告，共修复了2个安全漏洞。

对此，安识科技建议广大用户及时升级到安全版本,并做好资产自查以及预防工作，以免遭受黑客攻击。

 

![](../Images/110058f18ed96ba4688dddae450eb743.png)![](../Images/c6adfc4307dbab548e4147f6ee246a8c.png)

2. **漏洞概述**

![](../Images/1cc763b56252d9206c514193226a7a38.png)

  

CVE-2021-21980: VMware vCenter Server 任意文件读取漏洞

CVE-2021-22049: VMware vCenter Server SSRF 漏洞

简述：该漏洞为高危漏洞，是由于 vSphere Web Client (FLEX/Flash) 对用户权限控制不当，攻击者可利用该漏洞在未授权的情况下，读取任意文件，并最终访问敏感信息。
