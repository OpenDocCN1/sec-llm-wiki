# 【漏洞预警】Oracle MySQL JDBC XML外部实体注入漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxNDM3NTM0NQ==&mid=2657043692&idx=1&sn=c4196b445205440aa49b998f21aac1dd&chksm=803fa432b7482d242d999f5166c17b7d4f508e169fc9b19ee7e6b5375d3422d9062e1a5ab490&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxNDM3NTM0NQ==&mid=2657043692&idx=1&sn=c4196b445205440aa49b998f21aac1dd&chksm=803fa432b7482d242d999f5166c17b7d4f508e169fc9b19ee7e6b5375d3422d9062e1a5ab490&scene=27#wechat_redirect)

##   

![](../Images/5e193177763b73cc96e11dbd77a8d872.png)

1. **通告信息**

![](../Images/f79dabdfad8fa6811681b436716e9b1d.png)

  

近日，安识科技A-Team团队监测到一则Oracle MySQL组件在JDBC过程中存在XML外部实体注入漏洞的信息，当前官方已发布受影响的补丁。

对此，安识科技建议广大用户及时升级到安全版本,并做好资产自查以及预防工作，以免遭受黑客攻击。

 

![](../Images/5e193177763b73cc96e11dbd77a8d872.png)

2. **漏洞概述**

![](../Images/f79dabdfad8fa6811681b436716e9b1d.png)

  

CVE-2021-2471: Oracle MySQL JDBC XML外部实体注入漏洞

简述：2021年10月21日，安识科技A-Team团队监测到一则Oracle MySQL组件在JDBC过程中存在XML外部实体注入漏洞的信息，漏洞编号：CVE-2021-2471，漏洞威胁等级：高危。

 

![](../Images/5e193177763b73cc96e11dbd77a8d872.png)

3. **漏洞危害**

![](../Images/f79dabdfad8fa6811681b436716e9b1d.png)

  

攻击者可以利用该漏洞获取服务器敏感信息，最终导致信息泄露。

 

![](../Images/5e193177763b73cc96e11dbd77a8d872.png)

4. **影响版本**

![](../Images/f79dabdfad8fa6811681b436716e9b1d.png)

  

Oracle MySQL < 8.0.27

 

![](../Images/5e193177763b73cc96e11dbd77a8d872.png)

5. **解决方案**

![](../Images/f79dabdfad8fa6811681b436716e9b1d.png)

  

当前官方已发布对应安全补丁，建议受影响用户及时更新。参考链接如下：

https://www.oracle.com/security-alerts/cpuoct2021.html

 

![](../Images/5e193177763b73cc96e11dbd77a8d872.png)
