# 【漏洞预警】Windows NFS ONCRPC XDR Driver远程代码执行漏洞

##   

  
  

1. **通告信息**

  

近日，安识科技A-Team团队监测到一则Windows NFS ONCRPC XDR Driver组件存在远程代码执行漏洞的信息，当前官方已发布受影响的补丁。

对此，安识科技建议广大用户及时升级到安全版本,并做好资产自查以及预防工作，以免遭受黑客攻击。

 

  
  

2. **漏洞概述**

  

CVE-2021-26432: Windows NFS ONCRPC XDR Driver远程代码执行漏洞

简述：该漏洞是由于服务器未能正确处理用户传入的请求，导致产生了缓冲区溢出漏洞。

  

  
  

3. **漏洞危害**

  

攻击者可利用该漏洞在未授权的情况下，构造恶意数据造成远程代码执行攻击，最终获取服务器最高权限。

  

  
  

4. **影响版本**

  

Windows 10 Version 1607/1809/1909/2004/20H2/21H1

Windows Server, version 20H2/2004 (Core installation)

Windows Server 2012 R2/2016/2019

Windows 8.1 for 32/64-bit systems

Windows RT 8.1

 

  
  

5. **解决方案**

  

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁。链接如下：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-26432
