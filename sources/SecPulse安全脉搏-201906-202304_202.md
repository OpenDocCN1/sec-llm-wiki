# 【漏洞通告】Oracle WebLogic T3反序列化0day漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxNDM3NTM0NQ==&mid=2657042023&idx=2&sn=fe4266a58a598e10e599eb25d796c711&chksm=803fdeb9b74857aff4ddc34e8261802704741fc8602ac25fe7281b7fb323b2f9756abad0d38f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxNDM3NTM0NQ==&mid=2657042023&idx=2&sn=fe4266a58a598e10e599eb25d796c711&chksm=803fdeb9b74857aff4ddc34e8261802704741fc8602ac25fe7281b7fb323b2f9756abad0d38f&scene=27#wechat_redirect)

1. **通告信息**

![](../Images/20450e4934cd13fa69a846269442cb0e.png)![](../Images/e2cca867169e1dd0a8393abb35e294c1.png)  
![](../Images/1bfd81186d706dd23bf703c17cfd37d7.png)

  

近日，安识科技A-Team团队监测发现WebLogic T3存在反序列化0day高危漏洞，攻击者可利用T3协议进行反序列化漏洞，实现远程代码执行。

对此，安识科技建议广大用户及时做好软件补丁更新，并做好资产自查以及预防工作，以免遭受黑客攻击。

 

![](../Images/623213acdef5080de2556811765d0229.png)

2. **漏洞概述**

![](../Images/20450e4934cd13fa69a846269442cb0e.png)![](../Images/e2cca867169e1dd0a8393abb35e294c1.png)  
![](../Images/1bfd81186d706dd23bf703c17cfd37d7.png)

  

由于WebLogic默认开启T3协议，在使用JDK 1.7或以下版本时，攻击者可通过发送精心构造的恶意请求，利用T3协议进行反序列化漏洞实现远程代码执行。

 

![](../Images/623213acdef5080de2556811765d0229.png)

3. **漏洞危害**

![](../Images/20450e4934cd13fa69a846269442cb0e.png)![](../Images/e2cca867169e1dd0a8393abb35e294c1.png)  
![](../Images/1bfd81186d706dd23bf703c17cfd37d7.png)

  

攻击者可以利用此漏洞在未授权的情况下执行远程命令，进而获取服务器的权限，存在极大的危害。

 

![](../Images/623213acdef5080de2556811765d0229.png)

4. **影响版本**

![](../Images/20450e4934cd13fa69a846269442cb0e.png)![](../Images/e2cca867169e1dd0a8393abb35e294c1.png)  
![](../Images/1bfd81186d706dd23bf703c17cfd37d7.png)

  

WebLogic 10.3.6 版本。

 

![](../Images/623213acdef5080de2556811765d0229.png)

5. **解决方案**

![](../Images/20450e4934cd13fa69a846269442cb0e.png)![](../Images/e2cca867169e1dd0a8393abb35e294c1.png)  
![](../Images/1bfd81186d706dd23bf703c17cfd37d7.png)

  

1、暂时阻断T3协议或限制访问地址。

2、将JDK升级到最新版。
