# 【漏洞通告】VMware vRealize Operations Manager SSRF与文件写入

1. **通告信息**

![](../Images/20450e4934cd13fa69a846269442cb0e.png)![](../Images/e2cca867169e1dd0a8393abb35e294c1.png)  
![](../Images/1bfd81186d706dd23bf703c17cfd37d7.png)

  

近日，安识科技A-Team团队监测发现VMware 官方发布安全公告，披露了CVE-2021-21975 VMware vRealize Operations Manager API SSRF 和 CVE-2021-21983 VMware vRealize Operations Manager API 任意文件写入漏洞。攻击者可直接构造恶意请求执行任意代码，控制服务器。

对此，安识科技建议广大用户及时做好软件补丁更新，并做好资产自查以及预防工作，以免遭受黑客攻击。

 

![](../Images/623213acdef5080de2556811765d0229.png)

2. **漏洞概述**

![](../Images/20450e4934cd13fa69a846269442cb0e.png)![](../Images/e2cca867169e1dd0a8393abb35e294c1.png)  
![](../Images/1bfd81186d706dd23bf703c17cfd37d7.png)

  

攻击者结合两个漏洞构造恶意请求，可在无需认证的情况下执行任意代码，控制服务器。

5. **解决方案**

![](../Images/20450e4934cd13fa69a846269442cb0e.png)![](../Images/e2cca867169e1dd0a8393abb35e294c1.png)  
![](../Images/1bfd81186d706dd23bf703c17cfd37d7.png)

  

1、根据 vRealize Operations Manager 版本下载并更新合适的补丁。在安装补丁前建议做好相应备份。补丁下载地址请见：

https://www.vmware.com/security/advisories/VMSA-2021-0004.html 

2、利用阿里云安全组功能设置 vRealize Operations Manager 仅对可信地址开放。
