# Apache Druid 远程代码执行漏洞（CVE-2021-25646）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxNDM3NTM0NQ==&mid=2657040656&idx=2&sn=11188773b84889a237f2333647767b0a&chksm=803fd9ceb74850d8143d1fbae85ee78a41a6fd2d1b35ad92a2370d3050acad4b270d4a6610a6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxNDM3NTM0NQ==&mid=2657040656&idx=2&sn=11188773b84889a237f2333647767b0a&chksm=803fd9ceb74850d8143d1fbae85ee78a41a6fd2d1b35ad92a2370d3050acad4b270d4a6610a6&scene=27#wechat_redirect)

  

**1. 通告信息**

![](../Images/fbd1b81db146fddf47c5ef4229ac3163.png)

  

2021年02月01日，安识科技A-Team团队监测到Apache Druid官方发布安全更新，通报了一个远程代码执行漏洞，该漏洞编号为CVE-2021-25646，漏洞等级：高危，由于 Apache Druid 默认情况下缺乏授权认证，攻击者可直接构造恶意请求执行任意代码。

 

**2. 漏洞概述**

![](../Images/fbd1b81db146fddf47c5ef4229ac3163.png)

  

Apache Druid包括执行用户提供的JavaScript的功能嵌入在各种类型请求中的代码。此功能在用于高信任度环境中，默认已被禁用。但是，在Druid 0.20.0及更低版本中，经过身份验证的用户发送恶意请求，利用Apache Druid漏洞可以执行任意代码。

  

**3. 漏洞危害**

![](../Images/fbd1b81db146fddf47c5ef4229ac3163.png)

  

攻击者可直接构造恶意请求执行任意代码，控制服务器。

 

4. **影响版本**

![](../Images/fbd1b81db146fddf47c5ef4229ac3163.png)

  

Apache Druid < 0.20.1

 

**5.** **解决方案**

![](../Images/fbd1b81db146fddf47c5ef4229ac3163.png)

  

安识科技建议广大用户及时更新Apache Druid，下载链接为：https://druid.apache.org/downloads.html

https://github.com/apache/druid/releases/tag/druid-0.20.1
