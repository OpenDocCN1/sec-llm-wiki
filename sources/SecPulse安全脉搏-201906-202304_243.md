# Sudo 堆缓冲区溢出漏洞（CVE-2021-3156）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxNDM3NTM0NQ==&mid=2657040642&idx=2&sn=c6651c48856bfdb082bf3a658eafe036&chksm=803fd9dcb74850ca7cd0d1d9f4b41be8af7cdf6b77d1611bd420d3df61a5cd4651700086aced&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxNDM3NTM0NQ==&mid=2657040642&idx=2&sn=c6651c48856bfdb082bf3a658eafe036&chksm=803fd9dcb74850ca7cd0d1d9f4b41be8af7cdf6b77d1611bd420d3df61a5cd4651700086aced&scene=27#wechat_redirect)

1. **通告信息**

![](../Images/15fb978a36e93cfffa39d121fca5471f.png)

  

2021年01月27日，安识科技A-Team团队监测到RedHat官方发布了sudo 缓冲区/栈溢出漏洞的风险通告，该漏洞编号为CVE-2021-3156，漏洞等级：高危，1.9.5p2之前的版本Sudo具有基于堆的缓冲区溢出，攻击者可以通过“ sudoedit -s”和以单个反斜杠字符结尾的命令行参数将特权提升到root用户。

 

![](../Images/9df2a3f8a55fbf5d7cc25bae857a3a83.png)

2. **漏洞概述**

![](../Images/15fb978a36e93cfffa39d121fca5471f.png)

  

在sudo解析命令行参数的方式中发现了基于堆的缓冲区溢出。任何本地用户（普通用户和系统用户，sudoer和非sudoers）都可以利用此漏洞，从而绕过策略从普通账号权限提升获取到root权限。

 

![](../Images/9df2a3f8a55fbf5d7cc25bae857a3a83.png)

3. **漏洞危害**

![](../Images/15fb978a36e93cfffa39d121fca5471f.png)

  

成功利用此漏洞，任何没有特权的用户都可以在易受攻击的主机上获得root权限。

![](../Images/9df2a3f8a55fbf5d7cc25bae857a3a83.png)

4. **影响版本**

![](../Images/15fb978a36e93cfffa39d121fca5471f.png)

  

sudo:sudo: 1.8.2 - 1.8.31p2

sudo:sudo: 1.9.0 - 1.9.5p1

 

![](../Images/9df2a3f8a55fbf5d7cc25bae857a3a83.png)

5. **解决方案**

![](../Images/15fb978a36e93cfffa39d121fca5471f.png)

  

安识科技建议广大用户及时下载升级sudo软件包，下载链接为：https://www.sudo.ws/dist/
