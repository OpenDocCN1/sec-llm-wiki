# JumpServer 堡垒机远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxNDM3NTM0NQ==&mid=2657040409&idx=2&sn=b9cfa009dd9846fcdf4d4eeeb8c60e9c&chksm=803fd8c7b74851d114eca31dfad06bf62a7c6fc747116e609a8fa9a29cab02e942667ec11c99&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxNDM3NTM0NQ==&mid=2657040409&idx=2&sn=b9cfa009dd9846fcdf4d4eeeb8c60e9c&chksm=803fd8c7b74851d114eca31dfad06bf62a7c6fc747116e609a8fa9a29cab02e942667ec11c99&scene=27#wechat_redirect)

1.通告信息

  
  

  

近日,安识科技A-Team团队监测到JumpServer堡垒机项目发布紧急安全漏洞修复通知。修复了一处未授权远程命令执行严重安全漏洞。由于JumpServer 堡垒机部分接口存在未授权访问，攻击者在未授权的情况下构造恶意数据包读取日志文件获取用户登陆凭证。通过伪造数据包操作相关API，进行远程命令执行，可能造成严重的信息泄露。对此，安识科技建议受影响的用户尽快升级到安全版本。

  

2.漏洞概述

  
  

  

由于JumpServer 堡垒机部分接口存在未授权访问，攻击者在未授权的情况下构造恶意数据包读取日志文件获取用户登陆凭证。通过伪造数据包操作相关API，进行远程命令执行。

  

3.漏洞危害

  
  

  

攻击者通过此漏洞可直接获取服务器控制权限、造成严重的信息。

  

4.影响版本

  
  

  

JumpServer < v2.6.2JumpServer < v2.5.4JumpServer < v2.4.5JumpServer = v1.5.9

  

5.解决方案

  
  

  

JumpServer官方已经发布了解决上述漏洞的安全更新，建议受影响用户尽快升级到安全版本。

https://github.com/jumpserver/jumpserver
