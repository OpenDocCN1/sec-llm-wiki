再来介绍一下**Server酱** 👇

「Server酱就是从服务器推报警和日志到手机的工具。」

开通并使用上它，只需要一分钟：

1.  登入：用GitHub账号登入网站，就能获得一个SCKEY（在「发送消息」页面）
    
2.  绑定：点击「微信推送」，扫码关注同时即可完成绑定
    
3.  发消息：往 http://sc.ftqq.com/SCKEY.send 发GET请求，就可以在微信里收到消息啦
    

******![](../Images/6007ba583e143457b5868a79196ade98.png)******  
大概就是通过Server酱的api接口发送我们的漏洞信息同步到我们绑定的微信号就可以收到通知啦。实现代码：

```
import requestsimport logging
def push_ftqq(self,warning_info,vuln_name):   """同步通知"""    data_raw = {"text":"[朋与厌 VulScan] vuln monitor","desp":"\r\n**漏洞信息**\r\n {} \r\n \r\n<br/>\r\n **漏洞详情** \r\n~~~visual basic\r\n{}~~~\r\n".format(vuln_name,warning_info)}    req = requests.post("https://sc.ftqq.com/{SCKEY}.send",data=data_raw)        if req.json()["errno"] !=0:            logging.warning("消息同步失败")
```
