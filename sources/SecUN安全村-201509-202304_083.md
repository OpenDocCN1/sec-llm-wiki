# 教育联盟首个认证课程--CSAO在成都·世界信息安全大会首次亮相

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyODM5NzQwNQ==&mid=2247485722&idx=1&sn=9d6c297228e51f47df8ed4865032418b&chksm=c2182828f56fa13e25194e433ce1be10b466bbce22c4d3c27cf1e57ffdaff2994fa959f2a785&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkyODM5NzQwNQ==&mid=2247485722&idx=1&sn=9d6c297228e51f47df8ed4865032418b&chksm=c2182828f56fa13e25194e433ce1be10b466bbce22c4d3c27cf1e57ffdaff2994fa959f2a785&scene=27#wechat_redirect)

  

中国网络空间安全人才教育联盟（简称**教育联盟**）在成都·世界信息安全大会**首次****推出CSAO****注册安全意识官认证课程**（简称**CSAO****课程**）。CSAO课程是教育联盟之网安意识培训工作组**（**简称**工作组）**组织开发的国内**首创****面向安全意识教育专业人员**的认证课程，也是教育联盟成立以来推出的**首个****认证课程**。

  

 

![](../Images/f167e5646b8fff440c8281fbee28e519.png)

  

  

**CSAO**是Certified Security Awareness Officer的简称，中文名为**注册安全意识官**，是专职负责安全意识管理工作的岗位，全面负责本单位安全意识教育计划的制定和工作开展。  
**CSAO****课程是****国内首个****面向企事业单位安全管理及教育人员的专业TTT培训课程**，旨在为企事业单位**培养能够自主开展安全意识教育、打造单位安全文化的专业人才**，帮助企事业单位**提升员工安全意识教育水平与企业安全文化建设能力**。CSAO课程对学员没有安全技术要求，可以**零技术基础学习**，适合所有正在从事或希望从事安全意识教育相关工作的人员。

本次**CSAO课程**由工作组副组长**谢超首老师**进行主讲，工作组组长、易念科技CEO**王怀宾老师**客串实验部分。两位资深安全专家携手分享，课程深入浅出，理论联系实际，学员收获满满。

在互联网高速发展的今天，信息泄露事故频频发生，“**人**”才是**安全意识第一大关**，这似乎也得到了越来越多人的认可，以至于本次课程培训现场座无虚席，甚至还有国际友人慕名而来临时报名加座。

课程结束，随即进入紧张的考试环节。CSAO课程采用**手机在线考试形式**，学员需要提前在教育联盟的认证平台报名注册，并按照准考证规定的时间准时参加考试。

  

![](../Images/9622a88f7a9b1e994faa84e070bcfa13.png)

![](../Images/015cd42e9c75d622d5748857957908e2.png)

  

  

CSAO课程属于教育联盟认证课程， 学员参加教育联盟统一考试后，将由教育联盟进行评审和认证，学员的成绩和证书可以在教育联盟的认证平台进行查询和打印。CSAO认证在国内具有一定的权威性和实用性，目前尚属起步阶段，未来将具有广阔的职业发展空间。

  

 

![](../Images/6d6bd7ad2bcf568b0147a3003d55c32e.png)

  

  

本次CSAO课程能够得到众多安全从业者的关注和认可，说明安全意识教育已越来越被重视。**预计2022年，****60% 的大型企业/组织将开展全面的安全意识培训**，但目前国内多数企业在安全意识教育方面缺乏理论指导和实践积累，专业的安全意识教育课程在未来将被更多企事业单位或个人发展需要而选择。
