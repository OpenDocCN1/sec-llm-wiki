# 守望者实验室 威胁情报Feed API内测招募开启！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyODM5NzQwNQ==&mid=2247485508&idx=1&sn=f6fc8f364688f885bd2cc562b6a5fa7b&chksm=c2182976f56fa060487657a8c67ff2532dfde197959a2569f9a6bf5bed8688859fb797f6e8b7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkyODM5NzQwNQ==&mid=2247485508&idx=1&sn=f6fc8f364688f885bd2cc562b6a5fa7b&chksm=c2182976f56fa060487657a8c67ff2532dfde197959a2569f9a6bf5bed8688859fb797f6e8b7&scene=27#wechat_redirect)

经过这段时间的辛苦工作，守望者实验室已经完成了威胁情报Feed API 的开发工作，现正式开启内测。

  

威胁情报Feed API 已集成于天际友盟Alice 威胁情报溯源平台。可通过注册Alice平台账号，进入“获取API”页面，得到守望者实验室威胁情报Feed的下载方式。

  

![](../Images/11d4a2e89bad8c445ece4d10abafe852.png)  

平台地址：https://alice.sec-un.com/

  

注册Alice平台账号时，请填写真实个人信息，以便通过账号审核。账号通过审核后，即可获得守望者实验室威胁情报Feed API调用说明，并可使用Alice平台威胁情报检索功能。

  

目前，Alice平台与守望者实验室威胁情报Feed API，尚处于内测阶段，十分期待您加入参与测试，并分享反馈意见。如有任何问题，请直接联系天际友盟客服（service@sec-un.com）或公众号 “守望者实验室”。
