PortaPack H1 便携式软无线电（SDR）

Jared Boone, ShareBrained Technology

PortaPack H1可将软无线电设备HackRF One变成一个便携的开源无线电研究平台，其中包括了一个LCD屏幕、micro SD卡槽、音频接口和控制按键。可将信号监视、采集和分析在一个设备上完成。

PortaPack H1以HackRF One为主体，为其添加了带触控的LCD屏、音频接口、控制案件、micro SD卡槽和RTC电池。HackRF One的双核ARM Cortex-M处理器能够为该无线电研究平台提供低功耗但性能足够处理能力。由于资源的限制，不能够在该平台上面运行一个完整的操作系统，从而采用了ChibiOS系统，且效果不错。尽管性能有限，但该便携式设备仍然能够对多种类型的窄带无线电信号进行监视、分析和记录。由于该平台是开源的，开发者可以对现有软件进行改进以支持更多类型的信号，或开发出其他的程序。

作者简介：

Jared Boone是一位开源硬件爱好者，痴迷于无线电技术的隐私和安全性问题。他创办了ShareBrained 科技公司，并通过该公司将其部分研究项目转化为产品。

MozDef：Mozilla防御平台

Jeff Bryner

MozDef(The Mozilla Defense Platform)是一个基于ElasticSearch的安全事件管理（SIEM）工具。该工具能够进行实时的告警、调查取证、安全事件响应，并能够自动的以一种现代且可扩展的方式进行防御。

作者简介：

Jeff Bryner因为在会议上展示了其设计的kinectasploit 工具而在DEF CON上出名，该工具能够让你以3D、实时和基于手势的操作方式与Metasploit、nmap、nessus等工具进行交互。MozDef工具与kinectasploit类似，只不过是应用于攻击防御。

补充内容：

MozDef对传统SEIM（即安全信息与事件管理）功能作出扩展，使其具备了协同事件响应、可视化以及易于集成至其它企业级系统的能力。它采用Elasticsearch、Meteor以及MongoDB收集大量不同类型的数据，并能够根据用户需求以任意方式加以保存。“大家可以将MozDef视为一套立足于Elasticsearch之上的SIEM层，能够带来安全事件响应任务流程，”Bryner表示。该项目于2013年在Mozilla公司内部开始进行概念验证。

项目地址：https://github.com/jeffbryner/MozDef

官方文档：http://mozdef.readthedocs.org/en/latest/

参考内容：http://n0where.net/mozilla-defense-platform-mozdef/


SpeedPhishing Framework (SPF)

Adam Compton

SpeedPhishing Framework (SPF) 可帮助渗透测试人员在短时间内快速并自动地完成网络钓鱼的实施。向该工具输入一个最简单的信息（例如一个域名），这个工具就能在执行许多其他高级任务的同时自动地寻找潜在的攻击目标、部署多个钓鱼站点、 生成钓鱼邮件并发送给目标、记录对应的结果、并生成一个简单的报告。

CANtact

Eric Evenchick 自由嵌入式系统开发者

CANtact是一个开源的CAN转USB工具，该工具整合了Linux上的SocketCAN工具。该工具为连接到汽车的车载网络提供了一种低成本方法。该讲座将演示辅助用于车载网络研究的硬件和软件工具。其中的一些工具是专门为CANtact开发的，而其他的是已有的开源工具（例如，Wiresharkh和Kayak）。

作者简介：

Eric Evenchick是一名自由的嵌入式系统开发者。当他在滑铁卢大学学习电子工程时，他就和该校的可替代燃料研究团队一起参加了EcoCAR 高级汽车技术比赛，并设计并制作了一个氢电驱动的汽车。Eric曾在特斯拉公司研究过汽车固件。他当前也是Hackaday.com网站的投稿人。

补充内容：

CANtact属于交叉平台，可以通过USB接入运行Mac、Linux或者Windows的笔记本，然后可以通过OBD-II(车载诊断系统)连接线接入任何启用CAN的汽车。CANtact之前的工具售价高昂，不是很多人买得起。研究人员、黑客或者是感兴趣的人都可以买得起CANtact 这个售价仅为59.95美元的设备，如果买不起也可以自己自己做一个，因为代码是开源的，硬件设计文件可以在GitHub上下载。

HamShield: Arduino宽频VHF/UHF FM 收发器

Casey Halverson

HamShield: Arduino宽频VHF/UHF FM 收发器Casey HalversonHamShield能够将你的Arduino设备变成一个可用于136-170MHz、200-260MHz和 400-520 MHz频段 的VHF/UHF FM语音与数据收发器。不需要担心其中的SDR和处理过程，这些都已经在芯片里面解决好了。HamShield的库提供了方便的语音和数据处理能力，并能够对无线电的方方面面进行控制。使用Ardunio IDE能够在几分钟内将新的无线电技术写入该设备。通过标准的手机耳机插孔，能够将无线电信号送入Ardunio设备。甚至你还能够将该设备连接到你的电脑，并通过Chrome浏览器操作它。

Casey Halverson 是一名业余无线电的玩家，在他14岁的时候就已经获得了他的执照。研究了几年Ardunio硬件后，他设想着能够将Ardunio环境的快速原型设计能力和业余无线电结合起来。Casey 也是一名Chrome开发者，第一个将Arduino IDE带入Chromebook(Chromeduino)。停止研究硬件后，他开始涉猎安全问题，涉及的内容从曝光Nissan LEAF的第三方数据泄露到无线相框都有。

ShadyShield: Ardunio上的软件定义电话扩展

Karl Koscher 研究员

ShadyShield是一个可用于老式的电话线路入侵的Ardunio兼容电话接口。ShadyShield可提供原始的模拟音频信号，具体怎么处理由使用者来决定。作者提供了一个利用AVR上的软件实现的300bps的调制解调器的示例代码。只要你能想到的，ShadyShield就能够做到。想弄一个自动拨号器？没问题！ ShadyShield 也可通过SPI总线提供额外的RAM，并可通过microSD来存储更多的数据。 ShadyShield提供了RCA接头用于NTSC/PAL制式信号的输出。

作者简介：

Karl Koscher是加州大学圣地亚哥分校的一名从事嵌入式系统安全的博士后研究员。2011年，他和他的同事在全球范围内首次演示了如何通过手机、蓝眼和其他的渠道远程地完全控制一辆汽车。 除了研究如何攻击这些系统之外，他还研发了一些工具和技术，使得开发者能够自动地发现并修复他们所设计的嵌入式系统中潜在的安全漏洞。


Deck

Phil (Polstra)博士， 宾夕法尼亚大学教授

Deck是一个适用于BeagleBone及其他类似开发板的Linux系统。用Deck系统进行渗透的设备也可称为Deck。Deck系统中集成了大量的扩展插件，包括了用于USB取证中进行写保护的4Deck、进行无人机攻击的AirDeck、可通过802.15.4网络控制多个设备以及用于HID和大容量设备攻击的USBDeck插件。

Phil的出生年代较早，8岁时，他将自己所有存下来的钱都拿去卖了450美元的T199-4A设备了。两年后，他学会了6502汇编并且开始研究其他电视和家电的安全性问题。Phil 是宾夕法尼亚大学的教授。他过去几年的研究领域着重于微处理器和用于取证和渗透测试的小型嵌入式计算机。Phil已经开发了一个基于Linux的定制系统和相关的硬件，通BeagleBone Black开发板和他研发的其他东西能够制作一个低廉的远程渗透无人机。该项工作的详细内容在Phil写的《Hacking and Penetration Testing With Low Power Devices》 (Syngress, 2015)这本书中有详细的介绍。进入学术圈之前，Phil曾在几个知名的美国公司担任过高管。业余时间，他喜欢和他的家人一起度过，玩玩儿无人机、搞搞电子设备。

SWATtack – 智能手表攻击工具

Michael T. Raggo，MobileIron公司安全研究部主管

尽管可穿戴设备和智能手表已经出现了好几年了，但在Apple Watch出现之前，大家并没有对智能手表上的企业数据安全问题给予足够的重视。我们的相关研究以及开发的SWATtack工具，揭示了这些设备在和公司的移动设备配对时所存在的安全漏洞。SWATtack融入了我们在发现和报告智能手表漏洞的研究成果，并将对这些设备的攻击和盗取数据的过程自动化了。据此，我们希望大家能够对这些设备的安全问题引起足够的重视，以确保我们在各种场合中能以一种安全且有效的方式使用这些设备。

作者简介：

Michael T. Raggo是MobileIron公司安全研究部的主管，具备20多年的提供移动安全解决方案的从业经验。Raggo从事过移动设备安全、渗透测试、无线安全评估、合规性评估、应急响应与取证和安全技术研究等工作，并且曾今还是一名信息安全培训老师。他撰写了《Data Hiding》（Syngress 出版）一书，并和他人合著了《Information Security the Complete Reference 2nd Edition》（McGraw Hill出版），还在杂志和在线网站发表了许多的文章。同时他也是PCI Mobile Task Force的参与者。Raggo在全球各地的多个安全会议上发表了演讲，包括了Black Hat, DEF CON, SANS, Gartner, DoD Cyber Crime, OWASP, InfoSec等，还在演讲中提到了五角大楼和FBI。


SecBee: Zigbee协议的漏洞扫描工具

Tobias Zillner

SecBee是一款Zigbee的安全测试工具，属于Zigbee的漏洞扫描工具。因此开发人员或者安全测试人员可以快速地检测实际产品部署中的特定Zigbee漏洞。该工具目前支持的扫描类型：命令执行，是否开启连接，网络明文嗅探和使用默认密钥加密的明文。一款完备的接收设备正在开发，最终的目标确保每个ZigBee设备中的程序安全并且配置无误。

作者简介：

Tobias 就职于维也纳的Cognosec公司并担任高级信息审计师，他通过信息系统的审计来评估是否符合内部和外部的要求，并为客户的管理者提供有用的建议，并且兼顾IT系统的效率行和有效性。此外，Tobias通过执行Web应用和服务的渗透测试，源代码分析以及网络和基础设施的渗透测试，来确保信息技术的安全性。他拥有计算机和存储介质安全的学士学位，IT安全和信息系统管理硕士学位。 Tobias的专业知识也同样适用于IT治理，风险与合规领域。他还拥有众多证书：CISSP，CISA，QSA，CEH，ITIL和COBIT。

项目地址：https://github.com/zu1na/SecBee
