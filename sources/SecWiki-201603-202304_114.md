> 知道创宇成立于2007年，由数位国际顶尖的安全专家创办，并拥有近百位国内一线安全人才的核心安全研究团队。作为定位于下一代的网络安全企业，知道创宇擅长全新形势下的网络攻防一体技术、产品研发。利用在云计算及大数据处理方面的行业领先能力，为客户提供具备国际一流安全技术标准的可视化解决方案，提升客户网络安全监测、预警及防御能力。

*   工作地点：天府三街腾讯大厦B座
*   简历发至：zhus@knownsec.com（备注SecWiki）

# 岗位1：安全研究员（偏大数据方向）

薪资范围：12-20K

岗位职责:

1.  对业界目前的攻击和防御办法进行研究和跟踪，研究新的攻击和防御方法；
2.  海量日志分析，溯源分析，定向分析等，并撰写分析研究报告；
3.  安全漏洞响应，并更新漏洞检测插件；
4.  新型安全模型，安全能力提炼。

技能要求：

1.  熟悉主流的Web安全漏洞，具备独立分析Web应用漏洞的能力；
2.  熟悉渗透测试流程，有渗透测试经验；
3.  熟悉Linux操作系统，并掌握awk、grep、sed等常见Linux文本处理命令；
4.  有编程思维，能熟练使用 Python、Scala、Java 或其他脚本编程语言至少一种，有独立的开发经验；
5.  热爱网络安全，能掌握行业最新技术动态，并有较强的学习能力及抗压能力。

加分项：

1.  熟悉常见的机器学习算法，并使用过Hadoop、Spark分析数据；
2.  有持续更新个人网站、Github。

# 岗位2：产品经理（网络安全）

薪资范围：15-20K

岗位职责：

1.  对公司安全产品进行包装、统筹，与竞品进行性能和功能的对比分析，基于业务和特性，完成产品方案设计、产品运营资料包装、产品面向销售和客户的销售工具；
2.  牵头主导调研、分析安全产品市场前景、客户群体、客户需求痛点、匹配产品的解决方案（包括安全需求，法律法规监管需求等）；
3.  为客户（内部销售、运营+对外支撑等）完成产品特性及产品方案的宣贯、拓展和展示；
4.  完成部门负责人交予的产品项目跟进工作。

技能要求：

1.  具有3-5年安全行业产品规划、设计经验，且至少独立负责和主导过一款成功的安全产品，熟悉需求分析、原型设计、需求设计、开发推进和产品迭代等各环节；
2.  擅长分析行业趋势与市场动态，具备敏锐的业务触觉和创新意识；
3.  良好的技术方案规划能力，优秀的口头表达与文字表达能力，良好的沟通能力及方案讲演能力；
4.  网络安全、信息安全相关专业，熟悉网络安全行业企业、产品与服务、政策法规；
5.  性格热情开朗乐观，有自我驱动，主人翁意识；6、加分项：具有安全攻防对抗，安全研究等工作实践经历。
