Github 简介


Github是一个代码托管平台，开发者可以创建项目将其代码上传上去。同样Github上也有很多有意义的开源项目可供学习。


Github for bug bounty


对于白帽子来说，Github是一个获取攻击目标信息的好资源，在上面通过搜索公司关键字，可以获取一些关于公司的信息。因为总会有一些开发者的疏忽大意，将公司的源码上传到Github，其中可能含有一些密钥、密码之类的敏感信息。
