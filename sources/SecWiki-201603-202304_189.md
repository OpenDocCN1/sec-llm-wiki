### 子域名托管简介

注册一个不再使用的域名来获取对另一个域名的控制。

![](../Images/aeadc5737dbf802afb4182d89065cc62.png)

1.子域名将自己映射到一个特定的IP地址，第三方服务比如`Azure, AWS, Heroku, Github, Fastly, Shopify`等来提供内容。这些子域名使用一个CNAME^(\[3\])记录对应到另一个域名。\[\_eg. xyz.company.com CNAME xyz.cloudservice.com\_\]

2.由于某些原因，公司决定停止使用这个第三方服务来节省开支，该公司取消了对第三方云服务的订阅。

3.但是，这家公司忘记了从`DNS zone`文件中更新或移除掉这个`CNAME`记录。

4.由于这条`CNAME`记录没有从公司的`DNS zone`移除，任何一个注册了`xyz.cloudservice.com`的人都可以完全托管`xyz.company.com`，直到移除这条`CNAME`记录为止。

### 如何挖掘子域名托管

在这个过程中，按照下面的步骤在大规模的范围内进行扫描。

•收集域名

使用`Google`来搜索有漏洞悬赏的公司。

*   
*   
*   
*   
*   

```
inurl:  /bug bounty  inurl: / security  inurl: security.txt  intext: responsible disclosure  inurl:/security ext:txt "contact"
```

![](../Images/83026be7d702b391d64472b44014d1c9.png)

加载搜索结果，可以参考这篇博客^(\[4\])从页面获取`URLS`，它含有一个提取书签的代码，只是一个`javascript`函数来提取`google`搜索结果中的`URLs`。  

提取出`URL`后，将结果保存在`urls.txt`文档里，使用TomNomNom^(\[5\])的`unfurl`^(\[6\])工具来再次提取其中的域名。

cat alive.txt | unfurl domains >> subs.txt

将提取域名并保存在`subs.txt`文档里。

### 枚举子域名

通过我的学习经验，发现不同的子域名枚举工具各有千秋，你会发现我发现不了的，但我也能发现你没有发现的。所以为了获取更好的结果，我决定使用几个不同的工具来收集子域名信息。

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
#!/bin/shfilename=$1while read line; do        echo "Sublist3r"        python3 sublist3r.py -d $line -o $line.txt
        echo "Assetfinder"        assetfinder --subs-only $line | tee -a $line.txt
        sort -u $line.txt -o $line.txtdone < $filename#./enumSubdomains.sh subs.txt

```

上面的脚本使用了Sublist3r^(\[7\])和assetfinder^(\[8\])来枚举子域名，当然你也可以添加其他的子域名枚举工具。

### 检测是否存在子域名托管

有很多工具可以检测子域名托管漏洞，其工具原理都是类似的。进行指纹探测，比如云服务提供商提供的错误信息，标示为已经过期且容易存在接管的页面。你如果发现了新的特征指纹，也可以添加进来。

两个自动化检测工具。

subjack^(\[9\])

SubOver^(\[10\])

### 子域名托管漏洞利用小技巧

1.`subjack`工具有时会误报

2.更多的漏洞利用信息，可以参考 0xpatrick^(\[13\]) 和 m7mdharoun^(\[14\])的博客

3.一定要保存`POC`，然后提交报告。我遇到一个项目，在漏洞提交时立即解决了托管的问题，并标记内部已知悉。

4.Heroku和Azure需要添加信用卡才能添加自定义域名。

5.`Pantheon`需要你购买`50$`的基本任务才可以添加域名。

6.我遇到了很多误报的页面，不能成功的进行子域名托管。经过d0xing^(\[15\])的提醒，大部分不存在这个漏洞，因为他们已经声明了自己的根域名，如果你快速设置子域名并释放它，也是可以利用的。

7.我们使用了`DigitalOcean VPS`来进行测试，它提供了良好的速度和宽带。你可以使用我推荐的连接^(\[16\])获取60天的$100优惠券。
