> 知道创宇成立于2007年，由数位资深的安全专家创办，并拥有近百位国内一线安全人才的核心安全研究团队。知道创宇是国内较早提出云监测与云防御理念的网络安全公司之一，经过多年的积累，利用在云计算及大数据处理方面的行业先进能力，可为客户提供具备国际先进安全技术标准的可视化解决方案，提升客户网络安全监测、预警及防御能力。凭借在行业中先进的技术实力及影响力，知道创宇创始人及CEO赵伟入选2012年《福布斯》30位30岁以下创业者之一，公司还被CIO杂志评选2009年度国内除阿里巴巴之外唯一一家入选亚洲最具价值企业1/20名单。

### 联系方式

简历投递邮箱：zhus@knownsec.com (请主题备注 SecWiki)

工作地点：成都天府三街腾讯大厦B座11F

### 安全数据后端工程师（15k ~ 20k）

•**工作职责**：

1.负责安全数据产品相关开发和维护工作；2.负责系统功能、数据库等总体模块设计；3.负责系统性能优化、疑难技术问题解决；

•**任职要求**：

1.熟练掌握 Python 以及常见 Web 框架；2.熟悉至少一种常用数据库：MongoDB / PostgreSQL / Elasticsearch / Redis；3.有海量数据处理/分析经验；4.熟悉网络协议；5.熟悉 Linux；6.良好的编程习惯及编码风格；7.熟悉掌握 TDD、设计模式；8.自驱力强，有良好的团队协作能力。

•**加分项**：

1.有网络安全相关经验；2.有以下编程语言经验：C / C++ / Go / Rust / Scala。

### 安全大数据工程师（15k ~ 20k）

•**岗位职责**：

1.负责安全数据产品相关开发；2.负责分析模型的构建和调优；3.参与数据平台的建设；

•**任职要求**：

1.熟练掌握 Python 以及常见 Web 框架；2.熟悉 Spark 以及相关组件；3.熟悉至少一种常用数据库：HBase / Cassandra / Clickhouse / Elasticsearch；4.了解常用机器学习算法；5.熟悉 Linux；6.自驱力强，有良好的团队协作能力。

•**加分项**：

1.有网络安全相关经验。

### 产品解决方案经理（15k ~ 20k）

•**岗位职责**：

1.网络信息安全产品解决方案的撰写；

2.完成解决方案的设计及优化，为客户进行方案的宣贯、拓展和产品演示；

3.项目生命周期相关管理工作；

4.深入了解重点行业客户安全体系，优化解决方案，提升产品竞争力；

5.熟悉政府行业相关法律条例的知识体系。

•**任职要求**：

1.计算机、通信、网络安全相关专业本科以上学历，5年以上IT经验，1年以上信息安全领域从业经历；

2.具备网络、安全或业务系统产品管理经验，掌握解决方案的架构与思路，有良好的文案能力；

3.有较强的团队协调能力、人际沟通协调能力、资源整合能力、计划与执行力；

4.具备技术交流、方案设计、标书制作能力，较强的方案整合能力。

•**加分项**：

1.有网络安全背景知识，持有CISP、CISSP、CIAW等证书，具有大型安全公司解决方案经验;

2.具有标准制订从业经历、发表过信息安全领域学术论文或研究报告。
