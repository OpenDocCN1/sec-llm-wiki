Google编程之夏（Google Summer of Code[1]），是由Google公司所主办的年度开源程序设计项目，第一届从2005年开始。本文从2020的Google夏日编程中选择一些安全组织的项目进行简单的介绍，来了解一下安全开源项目的未来发展。如果想了解详细信息，可访问对应组织的计划列表。

1、The Honeynet Project

The Honeynet Project[2]

蜜网项目：蜜网/蜜罐和安全研究的研发。Honeynet Project 是成立于 1999 年的国际性非盈利研究组织，致力于提高因特网的安全性，在蜜罐技术与互联网安全威胁研究领域具有较大的影响力。Honeynet Project组织开发了很多非常成功的开源项目，其中很多已经成为各自领域的行业标准开源工具。

Honeynet Project GSoC 2020项目构想概述[3]

•Hack on Mitmproxy! 改善代理工具。•Unikraft VMI 通过使用Unikraft构建系统将其构建为Unikernel来强化VM自省应用程序•SNARE/TANNER SNARE / TANNER：使我们的Web应用程序蜜罐吸引新的恶意软件•HosTaGe: a mobile honeypot HosTaGe是一个Android设备的低交互性移动蜜罐。•Intel Owl improvements 是一个旨在简化、扩展和加快网络威胁情报数据生成的项目。•Analytical Malware Classification 通过搜索和开发恶意软件分类功能，帮助用户更轻松地理解分析结果•tenjint: Implement Plugins for the Automated Analysis or Detection of Malicious Code tenjint是用于x86和ARM的基于VMI的系统分析框架，使用Python编写，我们计划维护插件存储库。•tenjint: Behavioral Profile•tenjint: Orchestration Framework•QUICk: a go library for analysing QUIC traffic•Heralding: Protocol refinements•PAL Support for AMD/LibVMI•Stealthy Kernel Debugging using Boxy/LibVMI•Expanding Clang-Tidy to include AUTOSAR compliance•Infection Monkey

2、OWASP

OWASP[4]

OWASP，是大家很熟悉的：开放式Web应用程序安全性项目。

OWASP GSoC 2020项目构想概述[5]

•OWASP Python Honeypot[6]

OWASP Honeypot 是用Python开发的开源软件，旨在以简单且安全的方式创建蜜罐和蜜网。期待出现0bug，开发新的模块，更新API以及WebUI等。

•Zed Attack Proxy (ZAP)

Idea one ZAP当前无法检测到GraphQL漏洞：例如注入、身份认证和信息泄露。构想是实现ZAP功能来检测FraphQL端点。

Idea Two SSRF检测/处理 目的是创建有一个替代方案来集成到了ZAP，以便快速检测到SSRF。

Idea Three 重放机制 添加核心或扩展功能，以方便重新测试各种结果/警报。

•OWASP Juice Shop

OWASP Juice Shop 是一个继承最现代化、负责的wWeb漏洞环境，用于安全培训、漏洞演示、CTF等。

•OWASP Security Knowledge Framework

OWASP-SCF 是一个开源的代码安全知识库，其中含有多种编程语言的安全编码规范，展示如何防止黑客的攻击。

•OWASP SAMM

OWASP Software Assurance Maturity Model (SAMM) OWASP软件保障成熟度模型。提供有效且可衡量的方式来分析和改善软件安全状况。

•OWASP Honeypot Project

OWASP Honeypot的目的是快速发现web应用程序的新兴攻击并将其报告给社区，促进针对此类漏洞的保护。这个项目的挑战是将HoneypotTokens嵌入到常用的Web应用CMS中，如Wordpress，Joomla和Drupal，来促进HoeneyPoot的部署。

•OWASP SecureTea

OWASP SecureTea项目为各种设备（个人计算机/服务器/ IoT设备）提供一站式安全解决方案。

•OWASP Risk Assessment Framework

OWASP风险评估框架包括静态应用程序安全性测试和风险评估工具。OWASP Risk Assessment Framework可以集成在DevSecOps工具链中，以帮助开发人员编写和生成安全代码。

•OWASP Nettacker

OWASP Nettacker是Python语言的开放源代码软件，可让您进行自动渗透测试和自动信息收集。

•OWASP Intelligent Intrusion Detection System

OWASP IIDS是一个开源软件，利用人工智能的优势来检测入侵并警告给运维人员。

•OWASP OWTF

攻击性Web测试框架（OWTF）是一个致力于渗透测试效率和安全测试与安全标准（例如OWASP测试指南（v3和v4），OWASP Top 10，PTES和NIST）的一致性的项目。

•灵活的语法变体•在MOpt增变器上扩展•perf-fuzz Linux内核模块•基于QEMU 4的仪器•WASM仪表•机器学习•将afl-fuzz重新设计为线程安全的可嵌入库

4、Metasploit

Metasploit[9]

使用最广泛的渗透测试框架。

Metasploit GSoC 2020项目构想概述[10]

•增强Metasploit框架•改进POST API的利用更加一致，可以跨会话类型且稳定性•改善Web 漏洞API•会话式交互模块•增强Sql注入检测•有选择公开配置•数据可视化•Elasticsearch数据存储

AboutCode.org

AboutCode[11] 检测代码的软件包、版本、许可证，代码中的组件是否安全、可维护等。

AboutCode GSoC 2020项目构想概述 [12]

•ScanCode Toolkit 是一个流行的命令行工具，用于扫描许可证，版权和软件包的代码•Scancode Workbench 一个基于Javascript的Electron的桌面应用程序，用于记录来源和许可结论。•VulnerableCode：用于收集和跟踪已知的程序包漏洞。
