SecWiki安全招聘（第10期）发布广州大学网络空间先进技术研究院、二向箔安全的安全招聘职位，详细的招聘信息如下：

广州大学网络空间先进技术研究院

http://www.gzhu.edu.cn/fujian/wlkj_intro.pdf

广州大学网络空间先进技术研究院于2017年由方滨兴院士作为学术带头人组建，成员从中国科学院、清华大学、国防科技大学、哈尔滨工业大学、北京邮电大学等知名科研院所引进，是广州大学重点打造的一支高水平创新型科研团队！

教师工作地点：广州市大学城外环西路230号

学生实习地点：广州/北京两地，提供优质住宿

简历投递方式：sushen@gzhu.edu.cn，请在邮件标题注明：应聘岗位-所在学校-姓名，邮件附件名：应聘岗位-所在学校-姓名，请严格遵守格式要求。


岗位1：助理研究员/博士后

薪资待遇：博士后年薪24万，助理研究员年薪26/28/30万

招聘人数：5名

岗位职责：

1. 从事网安教育、网络攻防、网络靶场、人工智能安全等方向的研究。

岗位要求：

1. 博士学历，计算机相关专业；

2. 对网络安全、攻防对抗有浓厚兴趣，有志于长期深入研究；

3. 熟悉信息安全技术；

4. 具有高度的责任感和良好的团队协作能力。


岗位2：工程师

薪资待遇：24/26/28/30/34/38万

招聘人数：5名

岗位职责：

1. 从事网络安全前沿技术研究、参与国家网络安全方向科研项目。

岗位要求：

1. 硕士及以上学历，计算机相关专业;

2. 对网络安全、攻防对抗有浓厚兴趣，有志于长期深入研究;

3. 基础知识扎实，熟悉1种以上操作系统和1种以上编程语言;

4. 熟悉漏洞挖掘、逆向工程、网络渗透、CTF者优先;

5. 具有高度的责任感和良好的团队协作能力。


岗位3：网安实习生

招聘人数：10名

岗位职责：

从事网络安全前沿技术研究和参与国家网络安全方向科研项目。

岗位要求：

品学兼优，有志于在网络安全领域作长期深入研究的学生。


二向箔安全

https://twosecurity.io/

Twosecurity隶属四川风物长宜信息技术有限公司，主要专注于Web 安全领域，团队曾为 Google、Apple、微软、W3C、腾讯、阿里等输出过安全能力。


岗位1：安全研究员

工作地点：成都

薪酬待遇：6k-8k

投递邮箱：hr@twosecurity.io (请主题备注 SecWiki)

岗位职责：

1. 前沿 Web 安全研究，如 Http2 安全、serviceworker等；

2. 负责公司业务的渗透测试、培训咨询等工作。

岗位要求：

1. 至少熟悉一种 Web 语言，JavaScript/Python/PHP/Java；

2. 熟悉 Web 常见漏洞；

3. 有漏洞挖掘或安全工具开发经验优先。
