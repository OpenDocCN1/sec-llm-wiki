Google Summer of Code (GSoC，Google编程之夏)从2005年开始，每年举办一次，该活动旨在带动开源爱好者参与开源社区的各种优秀项目，GSoC每年开设的项目种类中包含了社交网络、Web应用、图形图像、虚拟现实等，当然也少不了安全方面的项目，其中诞生了不少安全行业的优秀工具，例如Cuckoo Sandbox、Honeypot等等。本文旨在通过GSoC博客的相关文章盘点下2018年这个活动的火爆程度。

  

2018年GSoC主办方总共接收到了来自62个国家的1,264名学生的申请，共组织参与了206个开源项目，其中的一些统计数字如下：

*   88.2% 学生是首次参与GSoC项目；
    
*   74.4% 学生是第一次申请该项目；
    
*   76.18% 学生都是本科生，17.5% 为研究生, 6.3% 为博士生；
    
*   73% 专业为计算机科学， 4.2% 专业为数学, 17% 专业为工程专业(电子、机械、航天等)；
    
*   206 家主办方参与了本次活动，其中41 家机构是第一次参加；
    
*   613 所世界大学参与；

其中，安全方面的项目有如下几个：

![](../Images/77477af9dc0b8bdf59343d8b68d54ead.png)

*   ***Metasploit***: Open Source framework for exploit development and penetration testing
    
*   ***OWASP Foundation***: OWASP is the Open Web Application Security Project. Our goal is to be the global community that drives visibility and evolution in the safety and security of the world’s software
    
*   ***rad******are***: Radare2 - portable reverse engineering framework and toolset supporting various platforms, architectures and file formats.
    
*   ***Rspamd***: Rspamd is an advanced spam filtering system oriented on high performance and spam detection quality.
    
*   ***The Honeynet Project***: The Honeynet Project is a non-profit research organization dedicated to improving the security of the Internet at no cost to the public. Focus is on honeypots and threat analysis.
    
*   ***The Libreswan Project***: Encrypting the internet using IKE and IPsec
    
*   ***The syslog-ng project***: With syslog-ng, you can collect logs from any source, process them in near real-time and deliver them to a wide variety of destinations.
