# **0x01 工具简介**  

FACT 全称 Firmware Analysis and Comparison Tool 是一个拥有WEB端的自动化固件测试平台。旨在自动执行固件安全分析（路由器，物联网，UEFI，网络摄像头，无人驾驶飞机等）。该工具基于Python-flask框架，采用模块化开发并支持插件接入，因此对于二次开发和优化非常便捷。FACT可以自动化完成固件解包任务并对其进行固件分析包括：

*   软件识别
    

*   使用哪个操作系统？
    
*   哪些节目存在？
    
*   使用哪些版本？
    
*   哪些服务在启动时启动？
    
*   这些漏洞有哪些？
    

*   查找用户凭据
    
*   加密材料检测
    

*   私人钥匙
    
*   证书
    

*   CPU架构（需要进行仿真和反汇编）
    
*   ...
    

FACT 同样也自动化的实现了固件的类比，可以很方便的对比出来旧版本与新版本固件之间的变动。以找出开发商对新固件在哪里进行了更新，同样也可以识别是否为开发商原始固件。比如：识别已更改/相同的文件、识别更改的软件版本。

## **0x02 主要功能分析**

FACT的业务代码主要有三块：Unpacking - 固件解包；Analysis - 固件系统分析；Comparison - 固件类比。每一块业务代码又由一下两部分组成：Scheduler - 任务调度器，Multiple plugins - 插件集。

*FACT的总流程图如下：*

![](../Images/cbb922adcf806a9184db20478f69e63e.png)

  

*固件解包工作流程图*如下：**

![](../Images/8f71a14d84db4c5efabf48007e14c624.png)

其中，FACT在识别文件类型的时候会调用"file"命令，并使用自带的一个mime库来标记文件类型。在确定文件类型后调度器会选择正确的插件进行解包任务。

*固件系统分析工作流程图如下：*

![](../Images/bc1361d56792d763b443c5e8324b1f2e.png)

调度器一次只会调用一个插件，当上一个插件任务结束后才会继续调用下一个插件；插件工作时可以拥有多个线程一起进行；插件可以调用以及查看前面插件执行后的二进制结果。

*固件系统类比工作流程图*

![](../Images/a03a409bdcf0c59fe6faa37c88501a1e.png)

固件系统类比任务是与固件分析任务分开的，需要进行类比的固件要先进行固件分析。需要手工填入需要进行类比的固件UIDS。类比工作是单线程工作，相对节省系统资源。

## **0x06 后记**

该平台运行需要一定的硬件配置，资源需求比较大；代码结构严谨，逻辑清晰，核心功能工作流程设计非常nice，调度器与插件集的实用为二次开发提供了很大的便利；Web安全性低，不建议作为公开服务运营；添加了一个自动化提取固件内部web路径并审计的插件，官方还没有回信；应该是还没有集成firmadyne，没有找到固件仿真的相关代码。
