# dll劫持

## 1.dll劫持产生条件

*   
*   
*   
*   

```
1.dll能否被劫持：    不在'HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Session Manager\KnownDLLs'注册表中2.其dll是EXE程序首先加载的DLL，而不是依赖其他DLL加载的。3.DLL确实被加载进内存中
```

## 2.判断dll是否可以劫持。
