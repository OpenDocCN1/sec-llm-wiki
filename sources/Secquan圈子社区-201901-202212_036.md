# Chrome插件推荐

Google Chrome 浏览器最重要的资源就是数不尽的 Chrome 拓展插件，这里对个人觉得好用的插件进行收集。

插件安装分为在线和本地，本地的话最好将插件包移动到chrome插件目录，可用chrome://version/查看。
