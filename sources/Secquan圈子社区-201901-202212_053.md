# **    现在，我们讨论如何生成动态靶机。**

## **   利用大佬开发的CTFd-Whale：**

####     在机器上安装好 Docker 和 Docker-Compose，并且启用 Docker Swarm。

####     **Docker Swarm 参考：**

####     https://www.jianshu.com/p/77c4c62d9afe

##### **注意需要用以下命令来标记节点：**

![](../Images/768cf39afcdd32ffda73e5effee9a03d.png)docker node ls #检查节点 IDdocker node update --label-add name=linux-1 <节点ID>

##### **参考链接：**

https://docs.docker.com/install/linux/docker-ce/ubuntu/https://docs.docker.com/compose/install/

#### **在机器上下载代码。**

![](../Images/768cf39afcdd32ffda73e5effee9a03d.png)git clone -b single https://github.com/glzjin/CTFd.git

  

**进入目录，编辑 frp 两端配置文件，使 token 随机，再使用 docker-compose 启动相关组件。**

  

![](../Images/768cf39afcdd32ffda73e5effee9a03d.png) cd CTFd vi frp/frps.ini # token 一定要随机 vi frp/frpc.ini # token 一定要随机 git submodule update --init docker-compose up -d

  

**启动完毕，打开****http://ip:8000**** 安装 CTFd。进入系统后台设置，打开插件设置页面，按照如下指导进行设置。**![](../Images/d70ef7173302b50d9a6791f176c03e83.png)![](../Images/09c416376682633bf0d6d2ceb9e581ab.png)

##### **Frp Config Template，记得修改 token:**

![](../Images/768cf39afcdd32ffda73e5effee9a03d.png)\[common\]token = randommeserver\_addr = 172.1.0.4server\_port = 6490pool\_count = 200tls\_enable = trueadmin\_addr = 172.1.0.3admin\_port = 7400
