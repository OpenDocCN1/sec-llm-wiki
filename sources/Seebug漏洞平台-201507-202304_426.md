### ABSTRACT

在未设置任何安全措施的情况下，Aria2 RPC Server 可以接受任何未知来源的请求指令，并予以下载。即使存在诸如`--rpc-secret`、`--rpc-user`、`--rpc-passwd`之类的安全措施，也可以通过社会工程学手段进行攻击。通过 Aria2 RPC Server，可以进行 SSRF、Arbitrary File Write 等 Web 攻击手法，获取服务器权限。

### 1\. INTERDUCTION

Aria2 是一个命令行下运行、多协议、多来源下载工具（HTTP/HTTPS、FTP、BitTorrent、Metalink），内建 XML-RPC 用户界面。\[1\] Aria 提供 RPC Server，通过`--enable-rpc`参数启动。Aria2 的 RPC Server 可以方便的添加、删除下载项目。

### 3\. MITIGATION TECHNIQUES

> 

#### 3.1 CLI OPTIONS

*   `--rpc-listen-all`：最好关闭此项功能
    
*   `--allow-overwrite`：应当关闭此项功能
    
*   `--auto-file-renaming`：应当开启此项功能
