Black Hat，世界顶级黑客大会，云集了来自世界各地的计算机安全研究人员，是每一个安全人憧憬向往的盛大会议。此次，Black Hat 2016在新加坡拉开帷幕，3月31日，知道创宇404安全研究团队携知道创宇漏洞社区——Seebug、Pocsuite、 ZoomEye、KCon登上了这个国际舞台，并现场接受了来自全球顶级黑客的测试。

  

![](../Images/2008e4f2d4dbbaadc32bab34ed96bd28.png)

  

那么，我们在Black Hat Asia 2016上集中展示的三款工具究竟有何用途？就让小S来为大家介绍一下：

  
Seebug：Seebug 是一个开放的漏洞平台，这是一个基于漏洞与PoC/Exp共享的漏洞社区，目前Seebug已经收录了5w多的漏洞以及4w多的PoC/Exp。你可以在Seebug平台上提交新漏洞（允许是已经公开的），也可以提交PoC/Exp，或者是某个已经收录的漏洞，但是它缺少详情、概要、PoC/Exp、解决方案、或者是CVE-ID等一些基本的字段，你都可以进行补充。以上所有的一切，我们都将奖励给你KB，KB可以用于购买其他人提交的内容，也可以直接兑换成RMB，1个KB相当于人民币5元。不仅如此，在Seebug上你还可以进行漏洞的学习，同时，我们将开放Seebug的论坛、Paper等版块，你可以提交你的技术文章，提交您的漏洞思路，可以与大家一起沟通漏洞思路。  
基于Seebug，我们会经常对最新爆发的漏洞进行应急，对一些重点漏洞，我们会上线在线检测功能，如果你是一个甲方厂商、运维人员，没有自己的漏洞检测能力，那么可以使用我们提供的功能进行自检。同时，我们也会公开一些受漏洞影响厂商的名单（已经打码），以此来进行预警。  
 Pocsuite：Pocsuite是由知道创宇安全研究团队打造的一款远程漏洞验证框架。你可以直接使用Pocsuite进行漏洞的验证与利用；你也可以基于Pocsuite进行PoC/Exp的开发；同时，你还可以在你的漏洞测试工具里直接集成Pocsuite；Pocsuite还集成了Seebug与ZoomEye API，通过该功能，你可以通过ZoomEye API 批量获取指定条件的测试目标（通过ZoomEye的 Dork 进行搜索），同时通过Seebug API 读取指定组件或者类型的漏洞的PoC或者本地PoC，进行自动化的批量测试。 ZoomEye：ZoomEye 第一个版本发布的时间是2013年。相比世界第一个网络设备搜索引擎Shodan，我们有自己的擅长之处，我们不仅仅抓取了全球网络设备指纹，同时也爬取了web 应用组件指纹。并同时支持两者搜索。想在网络空间探测方面深入下去，为此我们开发了两套爬虫引擎，分别针对的是网络设备指纹探测 和 web 应用组件探测。并且在全球各个国家部署了我们的爬虫引擎，7X24小时实时更新索引。在 V4 版本上线之后，我们为开发者提供了 restful API，通过 API，开发者能够更好的获取 ZoomEye 的资源。构建自己的应用，在zoomeye 的生态圈玩的更好。
