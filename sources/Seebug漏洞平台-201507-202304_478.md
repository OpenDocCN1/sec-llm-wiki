# Sebug 新版上线，让我们一起赋予漏洞灵魂

点击上方“Sebug 漏洞平台”即可快速关注![](../Images/2f554169aefd37527c0775bdc1dd68a5.png)历经一月有余的设计与开发，Sebug 新版，即 v3.0版本，正式上线，一起来发现、探索！全新的 VI新版中，针对 Sebug 进行了全新的 VI 设计，包括 Sebug 的 Logo，可能不少眼溜的在我们一些宣传材料中已经看到过新版的 Logo 了。![](../Images/a835ff76b451479e6d865ade16bc1072.png)集精致、清爽、简洁于一身，除了 Logo，大家可以发现整站也不再是黑色调，而是采用了由黑、白、土豪金三种色调为主的明亮色调。这一次的 VI 还针对新的 Logo 和风格设计了一系列的周边，包含贴纸、笔记本、证书等，这一系列周边我们也将在 Sebug 兑换商城上线，提供给大家进行兑换。  
在这些周边的设计中，其实本次最重要的是进行了证书的设计，希望让证书更有感觉，更有纪念价值，绝非“淘宝爆款”，12月度前三的同学，我们将采用新版证书，希望大家同样喜欢。周边之月度荣誉证书![](../Images/a3463c4191e0b9fd16d6173789ef45c1.png)![](../Images/d0c211d788811bbe46f1df39a592ce6f.png)周边之海盗主题贴纸功能及布局调整Sebug为了改善整站的用户体验，我们针对原有的一些工作做了比较大的改动和调整。   **首页**![](../Images/85f1d4dcedab01c41aa74a9659c89cda.png)首页整体布局进行了大调整，除了展示交易动态和热门漏洞外，同时将展示 Sebug 的统计数据（如上图），还有悬赏的 PoC 与详情，同时增加了当月排行榜的显示，另外也将热门漏洞的时间由月统计修改为周统计。  
本次首页的以上三点调整除了让大家在进入 Sebug 官网能第一眼看到其他人的漏洞关注动态，也可方便大家进行相关的提交，另外，我们还希望让进入首页的其他访问者第一眼就能看到当月活跃贡献的白帽子，我们希望让大家收获的不止有利，还有名。   **用户中心**原有的用户中心相对比较杂乱，个人设置以及一些消息提醒等，都聚集在一起，难以找到有用的消息，用户体验上也不是很友好。新版用户中心将消息提醒进行分离，并且针对不同类型的消息提醒进行归类，同时针对贡献列表、个人设置等都进行了调整，以此提高用户体验，**更多细节，欢迎大家前往 sebug.net 体验，也可在此后台反馈。**   **其他**除了首页和用户中心，包含排行榜，也做了相关调整，还有漏洞列表、组件列表、漏洞分类等，增加了相关的排序选项以及相关的筛选项，**以上所说几点以及照妖镜，也都增加了搜索功能。**本次调整也修改了用户主页的粉丝和关注列表等，更多细节的地方，还需要靠大家体验后进一步发现。**新增功能**   **漏洞生命线**新版我们增加了荣誉的强调，在漏洞生命线部分我们对每个生命线的节点加上了贡献者的展示，以及在排行榜，包括还有未开放的功能，我们都加了相关的体现，我们希望体现荣誉，**体现对白帽子劳动成果的尊重**，希望除了通过补贴的方式让大家能收获金钱的同时，也能让大家获益更多。   **更多可提交内容**除了已有的 PoC、详情与几个字段的提交外，新版重新上线了新漏洞提交，大家再也不用找管理员添加漏洞；另外，针对每个漏洞，大家也可以提交ZoomEye 的 Dork，以及完善解决方案。  
面向一些指定的漏洞，我们还将提高奖励，针对性的进行2-10倍的奖励悬赏。   **漏洞关注列表**![](../Images/bc9467ced13cb8b650186892d067c47f.png)另外，针对用户功能，增加了漏洞关注列表，在登录后通过导航右侧的星号图标点击进入可以查看。   **绵羊墙**新版还上线了大家关注已久的绵羊墙，通过访问绵羊墙可以看到那些**受漏洞影响的厂商列表。**  
**当然，此举我们是希望能更好的进行漏洞预警，相信对于厂商或者运维来说，通过绵羊墙的预警，加之配合照妖镜的检测，能更容易在攻击者之前找到漏洞并修复它。**   **更多功能**当然，本次新版开发的功能远不止于此，我们将在后续的小版本迭代中开放更多的功能，大家敬请期待！
