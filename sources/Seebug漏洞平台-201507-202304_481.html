龙哥你是如何使用 Unserialize 的 UAF 漏洞实现内存修改的？我们只实现了内存信息泄漏
龙哥：这个我在 PPT 中讲过，你先伪造一个字符串 ZVAL 结构，让他 ZVAL 结构中的字符串指针指向类似 PHP 缓存块结构的内存地址，ZVAL 结构大小要跟内存地址存在的类似 PHP 缓存块结构大小相符合，释放掉这个伪造的字符串 ZVAL 结构，这时候这个内存地址就会被放到 PHP 缓存块空闲链表中，然后再次伪造一个类似大小字符串 ZVAL 结构，这时 PHP 就会把刚才 PHP 缓存块空闲链表中刚放入的内存块分配给我们，用来实现伪字符串 ZVAL 结构，且由我们定义字符串内容，字符串内容就写到了内存地址的后面，实现内存修改。
