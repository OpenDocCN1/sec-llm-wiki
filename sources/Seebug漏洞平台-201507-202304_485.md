# 知道创宇“走进校园人才培养计划”第二站成功举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxNDY2MTQ2OQ==&mid=401098168&idx=1&sn=9b36bde44eb8df8b8009827acae51ae3&chksm=0993078a3ee48e9c151215a4642849fe2c9073efd22f3b3ffda11c4f3b5caca08fa6e070991b&scene=126&sessionid=1681272267#rd](http://mp.weixin.qq.com/s?__biz=MzAxNDY2MTQ2OQ==&mid=401098168&idx=1&sn=9b36bde44eb8df8b8009827acae51ae3&chksm=0993078a3ee48e9c151215a4642849fe2c9073efd22f3b3ffda11c4f3b5caca08fa6e070991b&scene=126&sessionid=1681272267#rd)

点击上方“Sebug 漏洞平台”即可快速关注2015年12月2日，知道创宇“走进校园人才培养计划——漏洞社区校园帮帮帮”活动在腾讯安全应急响应中心 TSRC 与信息安全在线教育平台i春秋以及北信科七星网络安全社的支持下，第二站来到北京信息科技大学，Sebug 漏洞社区负责人、安全研究员张祖优为学生们带来了《大数据时代下的漏洞研究》主题演讲，同时就学生们关心的话题进行了互动交流。作为社区自身功能的重要体现，网络空间安全人才培养一直是知道创宇漏洞社区最为重视的一部分，Sebug 漏洞社区走进校园，近距离的分享一线安全实践，自然受到了学生们的欢迎。![](../Images/ca9bedf4599492bf31496ce37f7c7e82.png)张祖优在话题演讲中表示，以前我们都习惯于单点对漏洞进行研究，而在大数据时代，我们其实可以借助大数据的力量，实现对漏洞的批量化的研究和利用，同时他以知道创宇404安全实验室最近应急处理的 Redis、Java 反序列等漏洞研究为例，以实践讲解的形式为同学们介绍了如何在大数据时代下挖掘这些隐藏在数据中的漏洞价值，以及实现批量的探测与漏洞测试。![](../Images/a9c74a920f322b518941be3423b8ead0.png)张祖优在与学生们交流环节时建议同学们要不断完成自我提升，光靠学校的课程是难以在职场立足的，同时同学们要抓住一切机会去接触实践，这样我们的未来才会愈加宽广。同时他强调国家目前正在加大力度投入到网络安全建设当中去，也欢迎同学们投身于网络安全行业，当这样一份梦想与报效国家完美结合时，那份成就感也会让你不断奋发，成就更好的自己。![](../Images/a580d11a7a93ff6eb04694f742ec0b24.png)知道创宇“走进校园人才培养计划——漏洞社区校园帮帮帮”活动礼品受到到腾讯安全应急响应中心（Tencent Security Response Center）的大力度支持，提供现场交流提问环节礼品。在主题演讲结束后，同学们踊跃的就Sebug漏洞社区、网络安全行业动态、漏洞利用、网络攻防、大学生就业等疑惑做出提问，得到了张祖优长达半个小时的详细解答。![](../Images/6eb0111edc78b885caff93fea7246af9.png)其中同学们还是更为关注如何才能参于到 Sebug 漏洞社区当中，一方面提升了自己的网络安全实践能力，同时还能得到社区的现金补助。在这一问题上张祖优表示，Sebug 漏洞社区之所以发起“走进校园人才培养计划——漏洞社区校园帮帮帮”的这个活动，目的也是与同学们想的一样，所以非常欢迎同学们能参于到 Sebug 漏洞社区当中来，一方面得到了实践性的学习锻炼，另一方面还能赚到学费，就像已有同学在 Sebug 上一个月就拿到了近万元的奖励，而作为一名学生，只要敢想和敢做，就一定能参于进来，并得到自己想要的结果。“‘走进校园人才培养计划——漏洞社区校园帮帮帮’里的三个帮，分别代表着帮学生赚钱，帮学生找工作，帮学生提升能力。Sebug 拿出100万，可以在 Sebug 上提交 PoC、详情、基本字段等等可以获得 KB，而这些内容往往在互联网上可以搜索到，稍加整理即可；当然，如果提交的是原创的内容，将获得更高的 KB，而 KB 可以兑换成现金，Sebug 目前已经发放出去20多万的人民币；而 Sebug 上也有很多只需要0KB可以购买的详细的漏洞分析，初学者完全可以通过学习别人的分析、思路、PoC 来提高自己的能力。目前 Sebug 上有5万多漏洞，4万多 PoC；同时，对于在 Sebug 上贡献的同学，我们将提供相关的证书、上线名人榜等，帮助大家给自己镀金，更好的找到工作。” 张祖优补充说。别撒手
