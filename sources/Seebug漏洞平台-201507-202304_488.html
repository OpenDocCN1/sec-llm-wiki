上周回顾
上周六知道创宇漏洞社区校园帮帮帮行动正式于北航启动，在这里感谢北航师生与众位的支持。知道创宇走进校园人才培养计划之漏洞社区校园帮帮帮致力于帮助学生赚钱，帮助学生找工作，帮助学生提升能力。
可能主讲人 Fooying 个人魅力独特，可能大家对于知识的态度，也有可能是大家钟爱 TSRC 的公仔，总之，现场被被持续提问半小时之久，宣讲后，也有不少人来私下交流。

本周将继续此主题演讲--《大数据时代下的漏洞研究》，如何将漏洞的利用价值更大化，又会有什么新思路呢？敬请期待。

大数据时代下的漏洞研究
2
内容简介
在以前，我们都习惯于单点对漏洞进行研究，而在大数据时代，我们其实可以借助大数据的力量，实现对漏洞的批量化的研究和利用。我们将会给大家介绍知道创宇漏洞社区计划，同时通过知道创宇社区的两大主角，ZoomEye 以及 Sebug，通过案例一一给大家介绍如何在大数据时代下挖掘这些隐藏在数据中的漏洞价值，以及实现批量的探测与漏洞测试。其实网络空间中隐藏着巨大的宝藏，一直等待的我们去挖掘，而漏洞，它的利用价值其实可以更大化！
3
主讲人
张祖优--Fooying
知道创宇漏洞社区负责人，安全研究员，擅长 Web 安全与安全工具研发。 主要负责知道创宇漏洞社区运营，以及进行 Web 安全、安卓安全研究工作。参与相关 Web 扫描器安全工具研发，长期进行Web漏洞的挖掘，给国内外各大甲方安全公司解决过多个严重安全问题，获得微软、阿里巴巴、腾讯感谢等。在 KCon、WOT2014、ISF 等会议上做过安全相关演讲，受邀参加过北京广播电台等访谈，接受过《人物》等杂志采访，在《计算机文摘》等杂志报刊发表过文章。
