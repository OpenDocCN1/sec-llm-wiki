**0x04 总结想法**

  

这里暂且先不讨论实战的应用性、隐秘性强不强，单论检测方法来说，就可以发现其实隐秘性不强，从第三点的检测方法可以看到，排查的方法很简单，所以单是这一点，我觉得以这种方法做持久化权限维持，就已经不现实了。 接着我们继续考虑一点，相信你们也发现了，上面的利用姿势是需要与目标Windows桌面进行交互的，也就是说我们要远程登录到目标主机上才可以进行RID劫持，那么要远程登录，最关键的是获取目标主机的明文密码，然而Windows Server 2012版本及其以上的只能读到Hash，只有Windows Server 2012版本以下的可以获得明文密码，所以对于无法远程登录的目标主机，就无法使用RID劫持了。 在实战中，通常我们都是先拿到webshell，然后再想办法提权。假设此时是利用webshell版的烂土豆提权成功（大多实际情况也如此），得到的也只是webshell版的最高权限shell，这是无法与Windows桌面进行交互的，只能cmd执行命令。又因为远程登录目标主机存在一定局限性，所以我觉得RID劫持的权限维持方法，效果一般吧。
