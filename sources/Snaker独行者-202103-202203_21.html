0x01 漏洞描述

2021年01月26日，sudo被披露存在一个基于堆的缓冲区溢出漏洞（CVE-2021-3156，该漏洞被命名为"Baron Samedit"），可导致本地权限提升。该漏洞发生的原因是当sudo通过 -s 或 -i 命令行选项在shell模式下运行命令时，它将在命令参数中使用反斜杠转义特殊字符。但使用 -s 或 -i 标志运行 sudoedit 时，实际上并未进行转义，从而可能导致缓冲区溢出。只要存在sudoers文件（通常是 /etc/sudoers），攻击者就可以使用本地普通用户利用sudo获得系统root权限。

Sudo 1.8.2 ‐ 1.8.31p2Sudo 1.9.0 ‐ 1.9.5p1


0x03 漏洞验证

无论什么操作系统环境，都可以用以下命令进行验证：
sudoedit ‐s /
Tips：如果出现 "sudoedit: /: not a regular file" 等相关的以 "sudoedit:" 开头的错误提示，则说明可能存在安全风险。
如果出现 "usage: " 开头的错误提示，则说明无影响

0x05 漏洞修复


## Debian 环境


## 修复方法如下：针对Debian 8[root@localhost]# wget https://github.com/sudo-project/sudo/releases/download/SUDO_1_9_6p1/sudo_1.9.6-2_deb8_amd64.deb[root@localhost]# dpkg -i sudo_1.9.6-2_deb8_amd64.deb
针对Debian 9[root@localhost]# wget https://github.com/sudo-project/sudo/releases/download/SUDO_1_9_6p1/sudo_1.9.6-2_deb9_amd64.deb[root@localhost]# dpkg -i sudo_1.9.6-2_deb9_amd64.deb
针对Debian 10[root@localhost]# wget https://github.com/sudo-project/sudo/releases/download/SUDO_1_9_6p1/sudo_1.9.6-2_deb10_amd64.deb[root@localhost]# dpkg -i sudo_1.9.6-2_deb10_amd64.deb

针对ubuntu 18.04[root@localhost]# wget https://github.com/sudo-project/sudo/releases/download/SUDO_1_9_6p1/sudo_1.9.6-2_ubu1804_amd64.deb[root@localhost]# dpkg -i sudo_1.9.6-2_ubu1804_amd64.deb

## CentOS 环境


## 修复方法如下：针对CentOS 6[root@localhost]# rpm -Uvh sudo-1.9.5-3.el7.x86_64.rpm
针对CentOS 7[root@localhost]# yum update sudo或使用这种方式[root@localhost]# rpm -Uvh sudo-1.9.5-3.el7.x86_64.rpm
针对CentOS 8[root@localhost]# yum update sudo


Tips：

CentOS 6：升级到 sudo-1.9.5p2 或更高版本（因为官方已经停止了CentOS 6的支持，所以不能再使用yum进行软件安装和升级了，需要前往官网下载升级软件包）

官方下载地址：https://www.sudo.ws/download.html

CentOS 7：升级到 sudo-1.8.23-10.el7_9.1 或更高版本

CentOS 8：升级到 sudo-1.8.29-6.el8_3.1 或更高版本
