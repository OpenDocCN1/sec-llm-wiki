# 1. **漏洞描述**

GitLab 是一个用于仓库管理系统的开源项目，使用Git作为代码管理工具，并在此基础上搭建起来的web服务。GitLab是由GitLabInc.开发，使用MIT许可证的基于网络的Git仓库管理工具，且具有wiki和issue跟踪功能。

 

在Gitlab 8.5-12.9版本中，存在一处任意文件读取漏洞，攻击者可以利用该漏洞，在不需要特权的状态下，读取任意文件，造成严重信息泄露，从而导致进一步被攻击的风险。

 

# 2. **影响范围**

GitLab GitLab EE >=8.5，<=12.9GitLab GitLab CE >=8.5，<=12.9

## 3.1. **Centos7.6安装GitLab**

操作系统版本：CentOS Linux release 7.6.1810 (Core)

  

新建 /etc/yum.repos.d/gitlab-ce.repo，内容为

 

*   
*   
*   
*   
*   

```
[gitlab-ce]name=Gitlab CE Repositorybaseurl=https://mirrors.tuna.tsinghua.edu.cn/gitlab-ce/yum/el$releasever/gpgcheck=0enabled=1
```

 

再执行

*   
*   

```
yum makecacheyum -y install gitlab-ce-12.8.7-ce.0.el7
```

 

在执行完成后，修改/etc/gitlab/gitlab.rb文件：

 

![](../Images/ff6c177777cf44b3c1b896afe236aecc.png)

  

 

然后gitlab-ctl reconfigure 重新载入配置文件。
