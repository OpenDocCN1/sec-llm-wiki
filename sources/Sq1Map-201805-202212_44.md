# 漏洞说明  

降维安全实验室（johnwick.io）监控到AMR合约代码存在高危安全风险的交易。

通过对代码分析，发现其中存在重要安全溢出漏洞，目前已经被人恶意利用并且进行大量增发。

## 漏洞分析

合约地址  
https://etherscan.io/address/0x96c833e43488c986676e9f6b3b8781812629bbb5#code

出现漏洞的合约代码:

```
 function multiTransfer(address[] destinations, 
```

> multiTransfer函数是为了实现同时给多个地址转账。该函数有两个参数:  
> destinations: 接收地址数组  
> uint\[\] tokens： **转账的金额(256位)**

  

变量totalTokensToTransfer代表转账的总金额。

* * *

注意看这一行代码:

> **totalTokensToTransfer += tokens\[i\];**

**这里统计转账总金额直接使用了+=，而不是使用SafeMath库函数add。**

当转账的金额tokens非常大时，**uint totalTokensToTransfer将会溢出为0**。也就是说**balances\[msg.sender\] > totalTokensToTransfer**这个是肯定满足的。

**转账的人可以使用0个或者少量的币给指定的地址转超大值的币。**
