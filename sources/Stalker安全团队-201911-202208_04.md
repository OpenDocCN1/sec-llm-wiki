**0x00   JavaScript继承机制**

  

  

在JavaScript中，几乎所有的事物都是对象。

创造对象的方法：

  

  

var o = {a:1,b:2};         //直接定义一个对象o 且该对象具有a和b两个属性

o = new Object();          //new一个对象（滑稽

fuction o(a,b,c,d){

this.a = a;

this.b = b;

this.c = c;

this.d = d;

}

var o1 = new o(1,2,3,4);     //使用类构造器

  

  

但是如果是通过类构造器生成的对象，其对象不能直接添加新属性，只能通过在构造器中添加。

  

![](../Images/555af002d2b5d2f15243bc72c27e344f.png)

  

可以看到我定义了一个person类，然后实例化了该类并对其属性赋值，对student对象进行输出后，可以看到输出了该对象的内容，并且有一个自带的属性

  

  

\_\_proto\_\_:Object                          //这个属性可以用来访问person类的原型

  

  

可以再看下面我直接对person类新增加了一个属性 phone ，但我直接输出student.phone的时候却显示了undefined，说明不能直接对类来新增属性。

  

所以就有 prototype 继承这一概念，所有的JavaScript对象都会从一个prototype（原型对象）中继承属性和方法，所有JavaScript中的对象都是位于原型链顶端的Object的实例。

  

我们可以通过

  

  

person.prototype.phone = 123;     

  

  

来为person类新增一个phone属性，其值为123，再访问student.phone看看。

  

![](../Images/250c8ea42ac531a3888bf8cb015aaeb7.png)

  

也可以通过

  

  

student.\_\_proto\_\_.phone = 123;

  

  

来新增phone属性。

  

  

  

  

  

接下来看一个小Demo：

  

![](../Images/f00727bb3d49e744725f34d3de645472.png)

  

当我们对foo的原型对象的属性进行修改后，所有继承该原型对象的对象都会有该属性的值。

  

但为什么foo的属性还是不变呢？

  

因为对于对象foo，在调用foo.bar的时候，实际上JavaScript引擎会进行如下操作：

  

  

1、在对象foo中寻找bar

2、如果找不到，则在foo.\_\_prot\_\_中寻找bar

3、如果仍然找不到，则在foo.\_\_proto\_\_.\_\_proto\_\_中寻找bar

4、依次寻找，找到找到null结束。

  

  

所以调用foo.bar的时候直接找到了，就返回1。

以上的内容可以得到几个结论：

  

  

1、每个类构造器都有一个原型对象prototype

2、对象的\_\_proto\_\_指向类的原型对象prototype

3、JavaScript使用prototype链实现继承机制

**0x01   JavaScript原型链污染**

  

  

先看代码

  

  

function merge(target, source) {

    for (let key in source) {

        if (key in source && key in target) {

            merge(target\[key\], source\[key\])

        } else {

            target\[key\] = source\[key\]

        }

    }

}

let o1 = {}

let o2 = {a: 1, "\_\_proto\_\_": {b: 2}}

merge(o1, o2)

console.log(o1.a, o1.b)

  

o3 = {}

console.log(o3.b)

  

  

merge函数用于合并对象的属性，上面的输出为

  

  

1 2

undefined

  

  

为什么o3.b会是undefined呢？按理说设置了 o2的原型对象的属性b为2，o3继承后应该也有b属性。

但这里却没有继承到。

  

其实是因为原型对象  此时并没有作为键值key，而是作为了o2本身，相当于给o2添加了一个属性b=2，而不是给Object添加了属性。

  

所以要怎么才能达到污染原型链的操作，来让o3.b输出2呢？

只要将代码修改如下：

  

  

let o1 = {}

let o2 = JSON.parse('{a: 1,"\_\_proto\_\_":{b:2}}')

merge(o1,o2)

console.log(o1.a,o1.b)

  

let o3 = {}

console.log(o3.b)

  

  

这样就能解析为键值，给原型对象添加属性b=2了。
