oxo1 前言

现实中很多APP都是直接给网站套个APP壳，功能都是网站的。反编译APP后，可能就会发现 JS 中就有 AJAX 请求接口之类的，下面案例就是通过反编译APP，搜索到接口，通过接口获取到 token ，利用 token 可以在不登录的情况下 直接获取到敏感的信息。


oxo2 测试

打开APP，查看值班的信息，下方是请求包

当再次请求的时候提示：签名参数已过期

这个时候我发现请求头存在 sign ，当时的想法是反编译 classes.dex 查看 java 代码，搜索 sign 参数，但是没搜到生成的方法（PS：是我看不懂 java）

通过 apktool 反编译 APP 之后，在APP目录搜索URL的路径，发现了 AJAX 请求

打开 JS 文件，发现生成 token 的函数

跟进函数发现 token 的加密方法

1、利用JS获取当前时间

2、nonce的值：返回当前时间的毫秒数

3、token的值：当前时间的毫秒数(nonce) 拼接他自定义的字符串(xxxxx)，再进行 MD5 加密

直接把他的代码复制下来，添加一个md5加密的js。就可以获取到他的 nonce 和 token 的值

利用获取到的 nonce 和 token 的值就可以得到敏感信息了


SSRF

之后又发现一处注释，根据提示这是下载文件的接口 path 参数需要一个 url

一开始的想法是直接下载他的 /etc/passwd ，但是试了没反应。

就尝试把 dnslog 的地址填进去，发现是服务端请求了 dnslog 地址，但是回显都是统一错误的，是bool型SSRF

再根据他的注释留下的内网IP地址，扫一扫存活IP和端口
