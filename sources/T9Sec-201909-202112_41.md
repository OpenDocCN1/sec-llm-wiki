> 我的思路是先输入内容看拦截那些参数、再根据拦截的参数来FUZZ。

##### 1、判断注入  

利用符号来绕过（还有很多的符号这里就不一一尝试了）

```
mysql> select '1'\*0;
+-------+
| '1'\*0 |
+-------+
|     0 |
+-------+
1 row in set (0.00 sec)

mysql> select '1'\*1;
+-------+
| '1'\*1 |
+-------+
|     1 |
+-------+
1 row in set (0.00 sec)
```

页面返回正常
