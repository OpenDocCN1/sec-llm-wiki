前言

本次内网渗透所用到的靶机为红日安全的ATT&CK第五个攻防靶场，网址：http://vulnstack.qiyuanxuetang.net/vuln/detail/7/

环境说明

根据官方描述为两个虚拟机，一个外网一个内网，并且给出相应的虚拟机密码。

本次实践的拓补图如下：

按照官方提供的红队思路，我进行了练习，并且记录整个过程，文章写的顺序跟下图差不多。

一、环境搭建

打开虚拟网络编辑器并添加两个虚拟网卡

VMnet5为仅主机子网配置为 10.0.0.0/24

VMnet7为桥接模式192.168.1.0/24


记得把方框中的选择去掉，因为仅主机模式默认是和本机建立专属网络通道的，也就是本机访问到仅主机模式的虚拟机，因此这里去掉让其访问不到，模拟真实的局域网环境。

然后打开靶机，开始配置网络。

win7：


win2008：

能相互ping通过就说明搭建成功了，然后以WIN7\leo的账户登入，打开phpstudy即可。

接下来就是开始了我的渗透之旅啦。

二、信息收集

访问靶机，发现是ThinkPHPV5，猜测应该是thinkphprce漏洞。

话不多说，直接丢goby扫描

发现两个漏洞，一个是远程代码执行，一个是MS17-010，为了达到练习效果，这里我直接用ThinkPHP的漏洞进行下一步渗透。

点开查看详情，复制一下payload，丢浏览器测试一下。

成功执行，下一步我就利用cs上线，方便进行下一步的渗透。

四、横向移动

收集信息

shell ipconfig发现双网卡，两个网段，192.168.1.0/24和10.0.0.0/24。

portscan 扫描一下存活的主机。

发现有一台10.0.0.128的主机。

查看下本机登入域，工作站域等信息

shell net config workstation

可以看到工作站域是sun.com，但现在的登录域是win7，所以要进行下一步渗透我们需要有一个域用户的进程。


抓取一波密码

发现在本机上有一个域用户leo，接下来就利用域用户leo登入收集一下域信息。

身份伪造

先利用heart账户查看一下域用户，发现拒绝访问，接下来就使用leo的凭据生成一个beacon。

使用spawnas命令生成具有其他用户凭据的beacon

选择leo账户的Token


spawnas之后弹回了一个leo的域用户的shell，下一步就利用leo进行下一步的域信息收集。

查看内网主机

查看域管理员

查看域控制器

查看下域控的C盘共享文件，是显示失败的，因为此时为普通域成员，没权限查看。

查看用户SID，为下一步域提权做准备。

接下来使用MS14-068尝试一下域提权

MS14-068 参数解释

MS14-068.exe -u<userName>@<domainName> -p <clearPassword> -s<userSid> -d <domainControlerAddr>

结合以上收集到的信息，输入如下命令：

shell MS14-068.exe -uleo@sun.com -p 123.com -sS-1-5-21-3388020223-1982701712-4030140183-1110 -d 10.0.0.128

此时会生成TGT_leo@sun.com.ccache的伪造缓存文件。


mimikatz kerberos::purge 清空当前机器中所有凭证

mimikatz kerberos::list查看当前机器凭证

mimikatz kerberos::ptcTGT_leo@sun.com.ccache 将票据注入到内存中

ls\\DC\C$，查看域控C盘共享文件，域提权成功，下一步利用psexec登入到域控。


横向到域控

查看当前target，选择域控机

选择psexec

因为我们已经有权限访问DC了，所以直接勾选Usesession's current access token

登入成功
