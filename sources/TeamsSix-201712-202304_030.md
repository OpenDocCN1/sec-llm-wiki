# 0x00 前言  

CVSS 评分：7.8影响范围：5.8 <= Linux 内核版本 < 5.16.11 / 5.15.25 / 5.10.102RT 通过 CVE-2022-0847 可覆盖重写任意可读文件中的数据，可将普通权限的用户提升到特权 root这个漏洞作者将其命名为了 Dirty Pipe，一看到这名字讲道理就让人想到了 Dirty Cow，这是因为该漏洞的原理比较类似于 Dirty Cow，但这个漏洞更容易被利用。

# 0x01 漏洞检测

检测的方法很简单，直接 uname -r ，如果  5.8 <= Linux 内核版本 < 5.16.11 / 5.15.25 / 5.10.102 说明可能受到该漏洞的影响。![](../Images/c88a13a0dc075beb505c35fe4f8dfd25.png)

# 0x04 漏洞修复

更新升级 Linux 内核到以下安全版本：

*   Linux 内核 >= 5.16.11
*   Linux 内核 >= 5.15.25
*   Linux 内核 >= 5.10.102
