# 漏洞笔记 | 测试目录

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5Mzk5NTIwMg==&mid=2247485229&idx=2&sn=4f470ae1577fef737a4b61bc4865f9d0&chksm=ec68d080db1f5996112dc234c3ef43d220df3606dd4bdb581238a924e05d8de2cb5708f6f706&scene=126&sessionid=1681656181#rd](http://mp.weixin.qq.com/s?__biz=MzI5Mzk5NTIwMg==&mid=2247485229&idx=2&sn=4f470ae1577fef737a4b61bc4865f9d0&chksm=ec68d080db1f5996112dc234c3ef43d220df3606dd4bdb581238a924e05d8de2cb5708f6f706&scene=126&sessionid=1681656181#rd)

# 0x00 概述

漏洞名称：测试目录

风险等级：低

问题类型：信息泄露

# 0x01 漏洞描述

Web应用程序在开发过程中，程序员为了测试代码功能，在Web目录下新建测试目录，存放测试代码，可能包含敏感信息。

# 0x02 漏洞危害

攻击者读取测试目录信息，以便进一步攻击目标站点。

# 0x03 修复建议

删除或者限制访问测试目录。

> 原文地址：https://www.teamssix.com/year/191125-195302.html
