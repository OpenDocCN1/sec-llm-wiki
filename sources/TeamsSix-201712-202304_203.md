# 0x00 前言

昨天晚上11点多的突然想在B站看电影了，但是又不知道那个电影值得看，于是首先想到的是去各大影评UP主的频道里面看看，转了几圈后发现他们讲解的电影B站很多都没有，这个时候又想到了一种方法，就是在B站搜索：“在B站值得看的电影”，没想到以前还真有UP主统计过。  

![](../Images/0380e4eae9bb8745e421e37828deb2a3.png)点进去之后发现UP主居然手动统计了160多部电影，最后他做成了一个表格，看完了之后立刻给了三连，因为在我看来每一位付出了努力与汗水的UP主都值得被尊重（疯狂暗示），事后就想到能不能用我这三脚猫的Python水平统计一下B站最值得看的电影呢？  
有了想法，立刻从床上爬了起来，在夜黑风高的晚上开始垒起了代码，终于经历了一个通宵的时间之后完成了这个想法。

0x02 运行结果  

  

通过刚才的运行结果，可以看到，播放数量最高的是《你的名字》，足足有一千八百多万的播放量

![](../Images/75223d9ac538f65932cf0aa9ae28a739.png)  
弹幕数量最高的还是《你的名字》，有高达98万条弹幕![](../Images/2d68d7f844f3984754c205167539cb75.png)

硬币数量最多的依然是《你的名字》，硬币数量达到了39万个![](../Images/a3a536900bc8f93786eb47b336a4b7e9.png)

追剧人数最高的《命运之夜—天之杯：恶兆之花》![](../Images/7994539a2e1b914e121d7ed52c8b3276.png)  
B站评分最高的不详，因为评分最高9.9的视频比较多，所以B站评分没有统计到视频最后的汇总里![](../Images/426b45cc49bdb5c653c6d0a11b572108.png)  
在B站的电影中豆瓣评分最高的是《武林外传》，高达9.5分![](../Images/3c621f9e198442604a13063a163c5964.png)  
B站评分与豆瓣评分差最大的是《深夜食堂》，两个平台差了7分，这部电影我也看过，表示还阔以，不明白为什么豆瓣评分那么低![](../Images/413cb7ee74fb909a6e236d929b607d49.png)  
OK，最后我们再来总结一下，B站的电影中播放数量、弹幕数量、硬币数量最高的均为《你的名字》，可以说是B站电影区当之无愧的C位，其余《刀剑神域：序列之争》《声之形》《白蛇：缘起》也都经常出现在前三之中。
