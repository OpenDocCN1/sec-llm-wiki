# 0x00 为root用户设置密码

```




dora@ubuntu:~$ sudo passwd root
```

# 0x01 修改50-ubuntu.conf配置文件

```
sudo gedit /usr/share/lightdm/lightdm.conf.d/50-ubuntu.conf
```

在文件中添加如下内容

```

autologin-user=root
```

![](../Images/ccb551f4eee6c239bbad63ab7abaca47.png)

# 0x02 修改.profile文件

```
sudo gedit /root/.profile
```

在原文件的的最后一行的最前面加上tty -s && ，就像这样

```






# ~/.profile: executed by Bourne-compatible login shells.
```

![](../Images/076291ea18bc087ded02d806e9ea8c60.png)

# 0x03 重启系统

重启之后，便是默认root用户了

![](../Images/981cfe384e4bc9988192e37af33d0a81.png)
