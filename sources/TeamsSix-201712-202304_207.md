# 一、修改默认python版本

# 1、查看有哪些python版本

```
ls /usr/bin/python*
```

![](../Images/e9251b62202901de9b3ffbc8e9d7a953.png)

# 2、修改.bashrc文件

```
gedit ~/.bashrc
```

在文件中添加下面一行内容，/usr/bin/python3.5就是你要修改的python版本路径

```
alias python='/usr/bin/python3.5'
```

![](../Images/1d46d4a4a9ad1bee9a1035ea1463d8d5.png)

重新登录或者重启即可生效

# 二、修改默认pip版本

```
gedit /usr/local/bin/pip
```

将第一行#!/usr/bin/python3修改成自己想要更改的版本就行
