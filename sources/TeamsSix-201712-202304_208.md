# 0x00 新建扫描

首页右上角新建扫描

![](../Images/f0970f0188d1b93a5886ef82ba0e721b.png)  
选择高级扫描

![](../Images/936a3b732262580f7ddcb35ecdf136da.png)  
在setting栏中填写扫描任务名称（随便写）以及目标主机IP地址，其他的可以自行选择配置

![](../Images/646b345236486bf34e45ee510b071a5e.png)  
在Credentials栏中可以填写一些自己已经知道的目标主机信息，比如对方密码等，但这里因为是黑盒测试，所以直接来到Plugins栏进行设置

![](../Images/9803bfd954cf17b4bc9b512226ddfdcd.png)  
在左边栏中选择自己需要扫描的模块后，单击即可添加右边栏，右边栏中便是接下来需要扫描的模块，点击保存。

# 0x01 开始扫描

回到主界面，点击launch，开始扫描，等待一段时间，便可以看到扫描出来的漏洞。

![](../Images/02aab5c3438fabca5e7281e87de56a38.png)

# 0x02 漏洞利用

在漏洞扫描中发现目标主机存在VNC服务密码是password的弱密码漏洞，接下来对其尝试连接。

![](../Images/670df8ef6a8671954557cf43fb3cdb4e.png)

可以发现已经成功连接，并且是以root用户登陆。

![](../Images/a9594e0aee603cfc8aaf62e36306b57b.png)
