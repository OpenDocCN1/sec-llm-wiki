对于linux建议开始使用有线连接，在无线驱动安装上的基础之上可以使用无线连接。

  

1、检查支持无线连接的接口并开启接口

**~# iwconfig（查看支持无线的接口）**

![](../Images/321bbe256a08239bbf54ebc6bcc4a093.png)

  

通常情况下，无线接口一般为wlan0.

  

**～# ip link set wlan0 up（开启无线网卡接口）**

![](../Images/68d70ea6fdcf84a4a25a265fca2bea0b.png)

  

2、扫描本地网络

**～# iw dev wlan0 scan**

![](../Images/9273836915a5d6247d317cec6c172163.png)

  

由于一般扫描结果很多，所以我们可以来筛选一下

  

![](../Images/a3f65c01c9f1da059e4be414fd60eb58.png)

  

这里使用grep -E 'SSID|signal|WPA'指只显示包含SSID（无线网名）或者signal（信号强度）或者WPA（加密方式）字符串的行，当然也可以设置其他筛选的字符串。

  

可以看出，图片中显示了4个无线网，其中第三个是公开wifi.

  

要注意的一点是当无线网络名称为中文时会以16进制显示。

  

3、连接无线网

**不需要密码的情况：**

**~# iw dev wlan0 connect SSID**

![](../Images/ba730615cfdf9388c430767597594479.png)

  

**需要密码的情况：**

首先在/etc/wpa\_supplicant下修改wpa\_supplicant.conf文件，如果没有可以自行添加一个

  

将里面内容改为如下格式，写入自己的SSID以及Password  

  

**network=**

**{**

**    ssid="\[SSID\]"**

**    psk="\[Password\]"**

**    priority=1**

**}**

![](../Images/bceccad04331d8754e7a30d4b77375b9.png)

  

开始连接

  

**~# wpa\_supplicant -i wlan0 -c wpa\_supplicant.conf**

  

  

![](../Images/2c865d3812b9c7b8177f5f23bf49127d.png)

  

\-i 指定网卡接口，-c指定配置文件

  

配置IP、网关等信息

一般情况下直接使用DHCP即可。

  

**～# dhcpcd wlan0**

  

此时可以再使用iwconfig查看无线连接状态
