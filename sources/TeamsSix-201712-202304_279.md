今天在U盘里装了kali，但是在更新时候提示GPG错误，无法安全的使用该源进行更新……

因为在实体机上运行的kali，所以不方便截图，就直接手机拍了，可以会有点不清晰。

![](../Images/4a81729c85f2ecfc0b3dabc2a351f099.png)

看到这里，发现，哎，什么情况，第一反应——换源！

官方的、科大的、阿里的、清华的，都不行！

接着baidu、google一通还是不行！

于是问群里的大佬们，还是不行![](../Images/66cfae8d3a37fe1ee018a29bb5b282cb.png)

  

在尝试了各种方法后，几经辗转放弃后，终于流暗花明又一村，码了这篇文章。

**1、查看自己的keyring.gpg有没有过期的。**  

        在shell里输入apt-list key进行查看。

![](../Images/b8d14afd5084fefe8e9aff13c26fa0ab.png)

我的有个keyring.gpg在2月2号就过期了，虽然不知道这个文件是干啥的，但是它过期了，系统就更新不了了。

**2、下载文件进行覆盖更新。**

1.  在shell里输入
    
2.  wget https://http.kali.org/kali/pool/main/k/kali-archive-keyring/kali-archive-keyring\_2018.1\_all.deb
    
3.  来下载deb安装包。
    

![](../Images/9d996c23bb9653084328b1912b4456dd.png)

**3、安装新的keyring.gpg包。**

1.  在shell中输入
    
2.  apt install ./kali-archive-keyring\_2018.1\_all.deb
    
3.  进行安装。
    

![](../Images/05e9020fa5bf15188995077c49c3a010.png)

        不放心的还可以再打开看看自己的keyring.gpg.

![](../Images/5340b89147994e620b90fafcc2c2ae25.png)

1.  可以看到已经更新至2021年了。
    

**4、update系统。**

    接下来输入apt-get update或者apt-get update && apt-get upgrade就可以正常更新系统了，看着一行行的命令划过，心中真是舒畅无比![](../Images/d6f0f32199f9131affa08586bbd287ea.png)

![](../Images/ef2535b86a14da7698a9da8a589ab14b.png)
