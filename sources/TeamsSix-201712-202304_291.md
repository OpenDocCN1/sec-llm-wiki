# 每天One Linux 命令 | ex：在Ex模式下启动vim文本编辑器

今日命令ex  【文档编辑】  

  

1说明

  

ex执行效果如同vi -E，使用语法及参数可参照vi指令，如要从Ex模式回到普通模式，则在vim中输入":vi"或":visual"指令即可。

  

2**语法格式**

  

ex \[选项\]\[参数\]

  

3**参数说明**

  

+数字：从文件指定的数字行开始显示

\-b：使用二进制模式编辑文件

\-c 指令：编辑完第一个文件后执行指定的指令

\-d ：编辑多个文件时，显示差异部分

\-m ：不允许修改文件

\-n ：不使用缓存

\-oN：其中 N 为数字

\-r ：列出缓存，并显示恢复信息

\-R ：以只读的方式打开文件

\-s ：不显示任何错误信息

\-V ：显示指令的详细执行过程

\--help ：显示帮助信息

\--version ：显示版本信息

  

4实例

  

**实例：**  

在ex 指令后输入文件名按回车键后，即可进入ex 编辑模式。

~# ex test.txt

![](../Images/74b7472f8ab9c4527e375de6fab2dc06.png)

![](../Images/85ca900bed03cf212a482bcd90f36547.png)

5L表示5 行，25C 表示25个字节。  

  

进入ex 模式，输入"visual"回到正常模式，它的操作与vim 中是一样的，此时如果在":"后输入"visual"后按回车键，将进入到vi 指令全屏界面；如果输入"q"，则退出编辑器。
