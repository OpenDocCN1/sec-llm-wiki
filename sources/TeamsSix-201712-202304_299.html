有时看看MAC的字体，再又看看自己Windows的字体……

这差距简直不能忍


但是好气呀，我又能怎么办，接下来就来教教你如何使自己的Windows界面字体更加美观。


温馨提示：如果看下面感觉很麻烦看不下去了，请看到最后，有简便方法


1、选好想修改成的字体

Win10默认微软雅黑，MAC默认苹方字体，苹方字体的Windows下安装文件可以后台回复“苹方”获取下载链接



打开.ttf文件就可以安装，可以根据自己喜好选择安装



在控制面板里找到字体，打开属性，复制下来文字名称（后面能用到）



2、打开注册表

按下Win+R键，输入regedit，打开注册表



什么，你问我Win键是什么？就是下面那个☟


3、找到路径

打开注册表后，找到HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Fonts

4、修改文件

找到这两项：Microsoft JhengHei & Microsoft JhengHei UI (TrueType)和Microsoft JhengHei Bold & Microsoft JhengHei UI Bold (TrueType)


右击修改，编辑字符串，在数值数据里复制上想要修改的名字，确定


对第二项做相同的修改


5、重启电脑


6、更多优化

打开电脑如果感觉没什么变化的话，还可以在控制面板里，找到调整ClearType，使你的电脑文本更易于阅读



然后再按下Win+Pause Break键找到高级系统设置——性能——设置，可以根据自己电脑性能选择，这里我选择的最佳外观


看到这里是不是感觉很麻烦的样子，所有这里介绍一种一键修改的方法



在自己电脑上面，新建文本，复制粘贴进下面代码

Windows Registry Editor Version 5.00
[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Fonts]
"Microsoft YaHei & Microsoft YaHei UI (TrueType)"="simsun.ttc"
[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\FontSubstitutes]
"Microsoft YaHei"="SimSun"
"Microsoft YaHei UI"="SimSun"

把上面代码里的SimSun替换为想要修改字体的名字，这里的Simsun是宋体的意思。


然后把文档重命名为.reg文件，双击执行即可，怎么，是不是简单很多



这里点继续即可



不知道是不是有的人还是会感觉很麻烦，得，那就直接安装第三方软件。

MacType可以很好得优化字体显示，达到类似于MAC上的字体显示效果，大家可以自行下载，尝试。



如果发现字体修改后，界面显示不全的情况，就直接在注册表中修改会原来的字体就好，例如我就遇到过下面这种情况

然后又默默的改回了原来的字体
