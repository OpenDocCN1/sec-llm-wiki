# 教程 | windows下更改字体的方法

有时看看MAC的字体，再又看看自己Windows的字体……

![](../Images/37513162f8aa256addbcd09e4d62b7a4.png)

这差距简直不能忍![](../Images/9e26cc80cd6b165b7c22d30ccb269966.png)  

  

但是好气呀，我又能怎么办，接下来就来教教你如何使自己的Windows界面字体更加美观。

  

温馨提示：如果看下面感觉很麻烦看不下去了，请看到最后，有简便方法![](../Images/2c6c3bc2a57553cd2dfa86b07b01c81c.png)

  

**1、选好想修改成的字体**

Win10默认微软雅黑，MAC默认苹方字体，苹方字体的Windows下安装文件可以后台回复“**苹方**”获取下载链接

  

![](../Images/f6c7ee82d1ea2ed97550ed6a538063c4.png)

  

打开.ttf文件就可以安装，可以根据自己喜好选择安装

  

![](../Images/6f349bf3e6ea5b226d896fe8c021f49a.png)

  

在控制面板里找到字体，打开属性，复制下来文字名称（后面能用到）

  

![](../Images/d3a41379454a3d81bfbf726757fd005f.png)

  

**2、打开注册表**

按下Win+R键，输入regedit，打开注册表

  

![](../Images/8b8e6500a4978d581be724b8be0c2973.png)

  

什么![](../Images/fa9398c4734a595a447229d70778b5f4.png)，你问我Win键是什么？就是下面那个☟

  

![](../Images/b12d9e92e80bc652b18b89c28bbf4c0b.png)

**3、找到路径**  

打开注册表后，找到HKEY\_LOCAL\_MACHINE\\SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\Fonts

![](../Images/c2e639a981c5e99ff2bcb67166c20550.png)

**4、修改文件**

找到这两项：Microsoft JhengHei & Microsoft JhengHei UI (TrueType)和Microsoft JhengHei Bold & Microsoft JhengHei UI Bold (TrueType)

![](../Images/22fe33ee931ab23765f77ded9d995937.png)

  

右击修改，编辑字符串，在数值数据里复制上想要修改的名字，确定

![](../Images/ef9da83f04d1b8ea262da763b075f4a3.png)

**对第二项做相同的修改**  

  

**5、重启电脑**

  

**6、更多优化**

打开电脑如果感觉没什么变化的话，还可以在控制面板里，找到调整ClearType，使你的电脑文本更易于阅读

  

![](../Images/0da91adc0946c288ae6f0a4059e1d68d.png)

  

然后再按下Win+Pause Break键找到高级系统设置——性能——设置，可以根据自己电脑性能选择，这里我选择的最佳外观

  

![](../Images/de6ede0b1ab5997d5ec043b1fcd1959b.png)

看到这里是不是感觉很麻烦的样子，所有这里介绍一种一键修改的方法![](../Images/13e3d947a73c8b23fdf863adb588898a.png)

  

* * *

  

在自己电脑上面，新建文本，复制粘贴进下面代码

Windows Registry Editor Version 5.00  
\[HKEY\_LOCAL\_MACHINE\\SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\Fonts\]  
"Microsoft YaHei & Microsoft YaHei UI (TrueType)"="simsun.ttc"  
\[HKEY\_LOCAL\_MACHINE\\SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\FontSubstitutes\]  
"Microsoft YaHei"="SimSun"  
"Microsoft YaHei UI"="SimSun"

把上面代码里的SimSun替换为想要修改字体的名字，这里的Simsun是宋体的意思。

  

然后把文档重命名为.reg文件，双击执行即可，怎么，是不是简单很多

  

![](../Images/e404ee1311d79d4a4d4399d2ef021e04.png)

  

这里点继续即可

  

* * *

  

不知道是不是有的人还是会感觉很麻烦，得，那就直接安装第三方软件。

**MacType**可以很好得优化字体显示，达到类似于MAC上的字体显示效果，大家可以自行下载，尝试。

![](../Images/7af96c697433cb17df349be053bcfc8a.png)

  

* * *

  

如果发现字体修改后，界面显示不全的情况，就直接在注册表中修改会原来的字体就好，例如我就遇到过下面这种情况

![](../Images/da681a99176238830126127c287ac03f.png)

然后又默默的改回了原来的字体![](../Images/b14ce9464d2c7742bdb65121e4202564.png)
