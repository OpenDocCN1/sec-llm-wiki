Kali中默认是没有中文输入法的，因此就需要我们自行安装，之前一直尝试安装搜狗输入法，但是各种依赖文件总是安装失败，因此选择了Google拼音。


1

# apt-get update（更新索引文件）

如果更新源是官方源的速度会很慢，这里建议替换成阿里的更新源，更新方法可以查看往期文章👉传送门👈

2

#apt-get install fcitx（可按Tab键补全，下同）

3

#apt-get install fcitx-googlepinyin（安装谷歌拼音软件包）

4

# reboot（重启）

5

Ctrl+空格（切换输入法）
