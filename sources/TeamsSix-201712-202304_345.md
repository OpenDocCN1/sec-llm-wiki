一开始，尝试了各种办法在KALI下安装SS，但都是以失败告终，按照网上提供的各种方式还是不行，直到看到了漫流沙公众号里的一篇文章。

  

至于KALI是什么，SS又是什么，就不用多说了吧，在Windows上，Mac上SS都很好安装，但是在Linux下却是经常冒出各种问题，接下来就来介绍一下我碰到问题的解决办法。

  

1**首先查看一下自己的系统版本**

![](../Images/ba4cd3a8672f6b2f3edd0a44d5e850d0.png)

我使用的是基于Debian 6.4.0-9的4.13.0-kali1-amd64的系统，上次更新在2017年11月8号。

  

2开始安装SS

1

pip install shadowsocks

![](../Images/e08d73a868c3a5c9a5ff598ddba3ca11.png)

2

新建一个配置文件，这里我新建了一个shadowsocks.json文件，在文件中写入以下内容。

{

"server":"你的服务IP",

"server\_port":你的服务端口,

"local\_port":你的本地端口,

"password":"你的账号密码",

"method":"加密方式"

}

![](../Images/41c8a0a8e4cbee385dc9cd57813624a0.png)

3

sslocal -c shadowsocks.json -d start

![](../Images/91fbc83ff826ec832e2fed99a041c1eb.png)

但是到这一步发现出现了问题，随着系统版本的更新，一些函数被删除了，因此需要进一步修改。

4

1、用vim打开/usr/local/lib/python2.7/dist-packages/shadowsocks/crypto/openssl.py

2、“：54”,跳转到54行，找到libcrypto.EVP\_CIPHER\_CTX\_cleanup.argtypes = (c\_void\_p,) 

![](../Images/4607ed8f15052c62b1fceb59f737894b.png)

将其改为改为libcrypto.EVP\_CIPHER\_CTX\_reset.argtypes = (c\_void\_p,)

![](../Images/691c4310a8505c62409c18c76108b31b.png)

3、接下来“：111”跳转到111行，找到libcrypto.EVP\_CIPHER\_CTX\_cleanup(self.\_ctx) 

![](../Images/6e657961e687f3d337cf3f1a27eb06aa.png)

将其改为libcrypto.EVP\_CIPHER\_CTX\_reset(self.\_ctx)

![](../Images/0d9e832ec2edd1053f4d6e31a6faa7de.png)

最后“：wq”保存退出

4、再次启动SS，发现已经成功启动

![](../Images/fc92d41520bf5329fee5b5eae02c949b.png)
