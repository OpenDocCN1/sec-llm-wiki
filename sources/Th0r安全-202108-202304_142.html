不少网民发现，打开 stack.chaitin.com 网站就能下载 EmailAll 这款工具，这款工具不仅能做数据收集，还可做数据存储。

“CT Stack”

01

工具介绍

做数据搜集：

利用搜索引擎发现指定域名相关邮箱，目前支持8个模块：Bing、Google、QWant、So、Sougo、GithubApi、Ask、Baidu

利用邮箱数据集收集邮箱，目前支持5个模块：

Snov、PhoneBook、Veryvp、Skymem、Email-Format


数据存储，根据模块采集数据结果进行分别json文件和汇总json文件保存

支持邮箱账号前缀格式数据分析 - 数据来源Email-Format


02

安装&使用

$ git clone https://github.com/Taonn/EmailAll.git$ cd EmailAll$ pip3 install -r requirements.txtEmailAll is a powerful Email Collect tool
Example:    python3 emailall.py check    python3 emailall.py --domain example.com run    python3 emailall.py --domains ./domains.txt run

python3 emailall.py --domain example.com run

python3 emailall.py --domains ./domains.txt run

最终结果保存至 result 目录，分为不同模块json数据文件和汇总{domain}_All.json文件

1

proxy={'http': '127.0.0.1:2333', 'https': '127.0.0.1:2333'}
2

API配置在 api.py文件

# http://www.veryvp.com/veryvp_username = ''veryvp_password = ''# https://www.github.comgithub_token = ''# https://app.snov.io/snov_username = ''snov_password = ''# https://phonebook.cz/pb_key = ''

4

5
