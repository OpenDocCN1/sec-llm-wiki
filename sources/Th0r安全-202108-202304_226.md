# 【大数据证据之实践与思考】

当前，诉讼案例中已经出现了利用海量数据材料说明、证明案件事实的情况，“大数据证据”走入诉讼渠道、登上司法舞台初见端倪。由于大数据证据技术门槛较高，司法实践中办案干警对其普遍抱有畏难态度而不愿触碰。【大数据证据应用现状】2012年以来刑事诉讼案件裁决文书中涉及到的所谓“大数据证据”基本可以分成如下三类：一种即为简单的数据统计结果（通常为计数求和），只不过量化得到的结果相对于一般认知标准显得“大”，如恶意网页的浏览数量过万，淫秽视频文件的下载数量以千计等，其实质是对数量的一种直观感受；再一种是针对巨量甚至是海量数据进行运算挖掘得到的分析结果，常见处理操作包括去噪、去重、分类、汇总、过滤、筛选、比对、碰撞等，个别复杂需求甚至需要专门编制程序实现。针对犯罪集团的层级、成员数量以及涉案金额的统计即是其典型应用；第三种则是直接从所谓“大数据平台”、“大情报系统”获取得到的数据或结论，如对端手机号码的实际使用人、犯罪嫌疑人行为轨迹与案情在时空上高度吻合等。就第一类证据材料而言，仅是简单的数量统计，只不过依托了互联网络的应用背景，并非真正意义上的“大数据证据”。第二类材料运用了更为复杂的挖掘分析方法，处理对象达到巨量甚至海量数据集的标准，但这种材料早在大数据时代到来之前就已经出现。二十一世纪初期，面对日益泛滥的网络赌博犯罪，侦查取证人员即已针对存储于犯罪嫌疑人使用的电脑硬盘上的数以万计的残留赌博网页碎片，基于HTML重构统计赌博网站会员账号在特定时间段内的下注金额。现在的网络非法集资案件侦办中的会员层级梳理、投资金额统计与当时的网络赌博取证在数据数量、处理方式上并无本质差异，并且同样是以鉴定书、检验报告形式出具。第二类材料具备了一定的“大数据证据”特征，但在司法应用中并无太大障碍，并非争论与争议的焦点。第三类材料宣称直接获取于系统或平台，实践中多转化为书证、物证或破案经过材料等形式出具，但对结论或数据的生成原理完全没有提及，法庭上难以开展举证质证，无法适应庭审实质化改革的发展需求。可见当前法庭上出具的所谓“大数据证据”或是数据处理应用背景的时代更新，或是面对质疑的语焉不详、避重就轻，最为重要的是未能量化说明海量数据中所蕴含的规律，形成大数据分析报告以真正体现大数据的价值。尽管理论界与实务界已经针对“大数据证据”开展热议与研究，并在真实性方面明确提出了以“大”真实性为主，兼顾“小”真实性的规则，但其证据规则依然有相当大的拓展细化空间，需要从证据能力、证据证明力、证据运用等多个角度思考大数据证据的实践运用。【大数据证据的证据能力】在法庭上作为诉讼证据呈现的大数据资料首先需要接受是否具有证据能力的审查。大数据中的数据信息其本质为电子数据，因此有关电子数据的审查判断经验对于大数据具有极强的借鉴意义。 **1.是否属于非法证据**我国关于非法证据排除细则方面的法律文件主要包括2010年7月施行的《关于办理刑事案件排除非法证据若干问题的规定》与2017年6月施行的《关于办理刑事案件严格排除非法证据若干问题的规定》。这两份规范性文件明确了非法言词证据的排除规则，但对于非法实物证据的排除却缺乏具体的细化规定。2016年10月施行的《关于办理刑事案件收集提取和审查判断电子数据若干问题的规定》第二十八条确立了电子数据非法证据排除规则，着重强调客观真实性在证据能力审查方面的重要意义。然而，基于云的多点离散存储造就了大数据与传统电子数据的巨大差异，既无法扣押存储介质，又不便提取电子数据（数据量大，提取时间长，容易造成数据被篡改或灭失），常规的“以扣押原始存储介质为主，以提取电子数据为辅，以拍照、打印、录像等方式为例外”的收集提取原则并不适用，势必需要寻求其他解决途径。“冻结”是特别针对采用云平台方式存储的大数据提出的新型证据固定方法，一般是公安机关提出申请，由云服务提供商执行，通过计算完整性校验值、锁定网络应用账号、采取写保护措施等系列操作杜绝遗失性收集的可能，从而确保处于诉讼期的电子数据不被增加、删除或修改。“冻结”方式很大程度上解决了大数据整体真实性的证明问题，经合法流程冻结后的大数据材料的证据能力理应得到认可。如果对冻结操作这一时间节点前的数据信息真实性存疑，可以通过云系统中管理节点与数据节点各层日志信息综合分析判断。对于不可采取“冻结”方法的大数据信息，如境外云系统的云盘账号，不仅其数据真实性难以保证，而且系统中的各级管理维护日志也无法获得，必须在其他证据（如犯罪嫌疑人使用的电脑主机中记录的云平台访问行为）的支撑下才可以被纳入证据范畴。如果分析结论基于大数据整体认识获得，个别数据记录是否准确并不会影响大数据的整体性价值，也不应影响其证据能力，因此不必过分纠结于特定记录的真实性；如果检验意见来自于大数据中含有的特定数据信息，可以通过保证整体真实进而确保个体的真实；如果无法保证整体的真实，也不可轻易否定局部个体的真实性，而要结合具体案情以及数据信息的生成机理具体问题具体分析。**2.是否具备指向功能**大数据材料与具体案情是否存在关联，是证据能力审查的另一个重要方面，此时依然可以借鉴传统的关联性判断标准。通常分为指向标准与功能标准两类，证据能力主要考察指向标准。传统网络犯罪侧重于从网络技术、信息交流等要素综合分析指向性。以大数据中的特定记录反映案情时，其指向标准的判断与传统网络犯罪相同；在以大数据整体价值反映案情时，则需重点考察数据采集来源、应用领域、平台构建背景等要素。比如交通、住宿等数据才可用于犯罪嫌疑人的行为轨迹梳理，而DNA平台则无法完成此项分析需求。指向判断相较功能判断更加直观明显，加之现代犯罪往往会与各类信息保有千丝万缕的联系，可以预见指向标准不会像真实性那样引起针对证据能力的巨大争议，故在此不多赘述。【大数据证据的证明力】大数据材料主要证明的是行为人的网络空间行为，特别是总结整体规律性认识的分析报告，侧重于关系推理而非因果推理，并需要将机器运算结果转化为人所能理解的内容，证明力提升难度明显加大，但主旨依然是证明线上行为与线下行为的关联强度。当大数据资料能够直接证明犯罪行为时，着重考察其与实际案情的功能性关联程度；当大数据资料对犯罪行为起间接证明作用时，要能够与其他证据交叉印证，实现证明力提升。**1.与案情的功能性关联**所谓功能性关联，是指证据是否能依靠事物间的逻辑或经验关系使实质问题更为真实或更为不真实。就大数据材料而言，充分利用好数据分析挖掘方法是增强其功能关联性的关键，尽量使定位或推导出的数据结果与实际案件更加贴合。例如，对于非法破坏计算机信息系统案件，基于恶意软件自身配备的日志解析出的工具操作时间，其与案情的关联性自然明显高于基于操作系统日志解析出的系统登录时间（虽然系统登录时间一定程度上也能够佐证恶意软件操作时间）。既要全面深入地了解分析案情进而确定关联度高的证据节点，也要正确使用分析分析技术，在不遗漏关键性证据的前提下实现准确深入解析。增强大数据整体性规律性认识的证明力，重视指向性关联是基础，提升规律认识的准确性则是关键。大数据分析报告其实质为分析挖掘结果的阐述，不仅是对事物的定性描述，更要量化说明，通常会以概率形式给出意见，具备科学报告的性质。在不更换数据集的情况下，不同挖掘算法得到的运算结果也会有所不同，因此需要阐述应用算法的原因，说明算法的运行机理，解释算法的运算结果。其所涉及的艰涩高深的数学知识，即便详细讲解，公众也普遍难以理解，此时可以辅助出示已经获得的知识产权成果或是前期的成功应用证明，间接说明算法有效性。比如对于DDOS攻击源的分析，就可通过所获专利、发表论文、期刊档次、应用证明等材料提升分析报告的证明力。另外，大数据平台或大情报系统导出的数据结果具有官方背景，其证明力理应大于其他渠道获取的数据。如通过12306系统得到的火车乘坐信息必然比利用互联网络查得的结果准确得多。**2.与其他证据的相互印证**与其他证据交叉印证是目前广泛采用的提升证明力方法。就大数据证据而言，其涉及到与电子数据的印证及与传统证据印证两个层面的问题。作为电子数据的特殊形式，大数据与电子数据具有天然的亲合性。开展大数据取证的同时也要积极同步开展常规电子数据取证。比如云平台日志表明嫌疑人账号多次登录并对云盘里的大量淫秽视频进行维护，嫌疑人个人主机中记录的系统使用时间与云盘使用时间重叠交叉，同时在微信内容中发现淫秽视频买卖的交易记录，多个证据组合会比单独使用大数据材料更加令人信服。司法实践中一般不单纯以电子数据定案，大数据材料也必须结合传统证据才能证明案件事实。特别是对于抽象性较强的分析报告，如果配合传统证据会可以使分析结论更加具象化，并会降低理解难度。例如，大数据分析得出的资金异动现象与银行柜台交易记录及监控录像、犯罪集团交易合同等相互印证，形成合力影响法官的裁断。【大数据证据的证据运用】**1.结合示例说明分析结果**数据挖掘算法的理解门槛高，大数据分析报告中如果结合示例加以阐述，能够更充分地发挥分析结果价值，更有利于庭审质证。示例不仅可以包括正面例子，反面例子有时可能更说明问题。比如，通过分析得出XXX恶意软件符合某次分布式攻击事件行为特征的90%，如果能够同时判断出其他恶意软件所满足的攻击特征不超过40%，就能更好地凸显分析结果的价值，使侦查焦点更加明确。传统证明案件事实多采取“印证”方式，使用的是“全样本”；海量数据使用全样本印证并不现实，可使用“局部样本”进行“验证”，并可通过不同的证明方法测试结论或意见的有效性。云盘中的海量淫秽视频鉴定即多使用抽样检测方法。**2.丰富创新证据展示方式**大数据分析尚未被列为独立的鉴定项目。即便列出，由于其电子数据的本质，也必然归属于电子数据检验大类之下。可以说，目前通行的以检验报告形式说明大数据分析结果的做法，是现实法律框架下有效且经济的选择，很值得推广沿用。书证是另一种常见的大数据证据形式，多用于说明直接由大数据平台或大情报系统导出的信息记录，可以更为直观明确的表达意见观点。除了检验报告和书证，是否还有其他证据形式适合于说明大数据证据呢？在此着重针对“侦查实验”进行说明。侦查实验是法定的证据形式之一，属于笔录的一种，是指侦查机关在侦查办案过程中，采用模拟和重演的方法，证实在某种条件下案件实施能否发生和怎样发生，以及发生何种结果。侦查实验相较其他笔录实施的技术难度过高，因此实践中很少使用。但不可否认的是，侦查实验非常适合于示例化说明大数据分析结果，从而弥补检验报告及书证的局限，增强分析结果的可信度。未来司法实践中有必要加大侦查实验的使用力度，更好地服务于大数据证据。【大数据证据的注意事项】传统证据在具体数量上产生争议时，往往能够通过确定或认定的数据结果予以裁量解决。大数据分析报告却以概率形式给出意见，但又无法像DNA或声纹鉴定那样出示高质量（近似于定性）的分析结果。鉴于大数据分析报告的自身局限，不宜过分夸大其证据价值，也不应过多使用分析报告中的概率形式结果。另外，大数据分析时需要海量数据源，深奥的数据挖掘算法，高速度大容量的运算器及存储器，并且分析意见多需要鉴定人出庭予以解读，必要时还会聘请具有专门知识的人就相关技术问题进行操作说明，势必大幅度增加证据成本。特别是那些规律性认识性质的分析报告，艰涩难懂，证据偏在问题也更为明显，相较其他证据更容易引发争议，建议在法庭上慎用精用，以免陷入法庭质证困境。
