前言

在安全圈，掌握第一手漏洞信息一般是比较重要的，漏洞刚爆出来的时候，有人就会在近几天将POC或者EXP发布在GitHub上，基于这种前提，这里通过Python脚本做一个监控，随时将GitHub最新漏洞信息推送到自己手机上。脚本是在大佬bonelee和大佬唯米洛熊的基础上修改的。

监控思路讲解

其实就是搜索GitHub和CVE相关的项目，这里直接用GitHub的API来索引，地址为https://api.github.com/search/repositories?q=CVE-2021&sort=updated，查找的是2021年的CVE项目，因为为了方便讲解，所以2021这里用了硬编码，在脚本中可以使用时间函数来替换。现在开始分析，先访问链接，观察页面，结果如下图：

观察页面，我们发现为json格式，这个可以让我们很方便的提取我们需要的数据，这里需要关注的是total_count这个key，这里记录的是数量，我们可以通过这个值是否变化来设计是否推送的标志。推送标志分析完了，现在点击items下的0，来看看里面的键值，然后提取咱们需要的数据。结果如下图：

通过观察，我们需要的数据为name和url,将我们需要的数据提取出来，用下面代码就可以，

req = requests.get(api, headers=github_headers, timeout=10).json()
#提取total_count
total_count = req['total_count']
#提取url
url = req['items'][0]['html_url']

提取出需要的数据，接下来就来设计推送标志，上面简单的提了一下，现在详细说说，我们可以写一个函数命名为getNews，这个函数的目的就是向GitHub的API发送请求，拿到total_count这个值，然后将这个值存到一个变量里，当我们再次请求时，我们与这个变量进行比对，如果相同说明没有更新，如果不同说明更新了，然后进入条件里，更新变量，然后向手机推送。getNews的代码如下：

def getNews():
    try:
        # 获取页面的total的值
        year = datetime.datetime.now().year
        api = "https://api.github.com/search/repositories?q=CVE-{}&sort=updated".format(year)
        json_str = requests.get(api, headers=github_headers, timeout=10).json()
        cve_total_count = json_str['total_count']
        return cve_total_count
    except Exception as e:
        print(e, "github链接不通")
        return '', '', ''

接下来要解决的问题是如何将消息推送到手机上？

这里的解决方案是用企业微信，注册企业微信，登陆后台，然后自建应用（避免占用篇幅，如何自建应用这里不详细阐述）。到了这里，我们会用到两个值，一个是 注册的企业 corpid，一个是自定义应用的 Secret，有了这两个值，我们就可以向微信推送消息了。我们再定义一个函数命名为wechat_qiye，功能就是向企业微信的API发送求情。代码如下：

def wechat_qiye(data):

    global access_token
    # 自定义应用的 Secret
    Secret = "pyUtd3RY**************Y5YYHjAWKjUEpNiQ"
    # 注册的企业 corpid
    corpid = 'wwbfd************1708'
    url = 'https://qyapi.weixin.qq.com/cgi-bin/gettoken?corpid={}&corpsecret={}'

    '''
        先提供Secret以及corpid获取access_token。
    '''
    if access_token == '':

        getr = requests.get(url=url.format(corpid, Secret))
        access_token = getr.json().get('access_token')

    print(access_token)

    r = requests.post(url="https://qyapi.weixin.qq.com/cgi-bin/message/send?access_token={}".format(access_token),
                          data=json.dumps(data))
    print(r.text)
    if str(json.loads(r.text)['errmsg']) != 'ok':
        #获取新的access_token
        getr = requests.get(url=url.format(corpid, Secret))
        access_token = getr.json().get('access_token')
        #恢复之前因token过期异常失去的请求
        r = requests.post(url="https://qyapi.weixin.qq.com/cgi-bin/message/send?access_token={}".format(access_token),
                          data=json.dumps(data))
        print(r.text)

现在大体上已经可以使用了，但是还有一个问题，大家在GitHub上传对应CVE的POC或者EXP时，一般是没有这个CVE的漏洞描述的。那么如何获取CVE描述呢？所以这里参考了bonelee 大佬的思路，把大佬的代码拿过来用。我们可以通过在GitHub获取到的CVE编号然后去请求CVE网站(https://cve.mitre.org)，从这个网站获取描述。代码如下：

cve_name = req['items'][0]['name']
# 根据cve 名字，获取描述
def get_cve_des_zh(cve_name):
    query_cve_url = "https://cve.mitre.org/cgi-bin/cvename.cgi?name=" + cve_name
    response = requests.get(query_cve_url, headers=github_headers, timeout=10)
    html = etree.HTML(response.text)
    des = html.xpath('//*[@id="GeneratedTable"]/table//tr[4]/td/text()')[0].strip()
    print(des)
    translate(des)

现在描述拿到了，但是是英文的，所以还需要翻译一下，我们再写一个翻译函数，将我们获取到的描述翻译成中文。

代码如下：

# 创建md5对象
def nmd5(str):
    m = hashlib.md5()
    b = str.encode(encoding='utf-8')
    m.update(b)
    str_md5 = m.hexdigest()
    return str_md5

# 有道翻译
def translate(word):
    headerstr = 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.114 Safari/537.36'
    bv = nmd5(headerstr)
    lts = str(round(time.time() * 1000))
    salt = lts + '90'

    # 如果翻译失败，{'errorCode': 50}  请查看 fanyi.min.js: https://shared.ydstatic.com/fanyi/newweb/v1.1.7/scripts/newweb/fanyi.min.js
    # 搜索 fanyideskweb   sign: n.md5("fanyideskweb" + e + i + "Y2FYu%TNSbMCxc3t2u^XT")  ，Y2FYu%TNSbMCxc3t2u^XT是否改变，替换即可
    strexample = 'fanyideskweb' + word + salt + 'Y2FYu%TNSbMCxc3t2u^XT'
    sign = nmd5(strexample)

    data = {
        'i': word,

        'to': 'AUTO',

到现在为止，所有模块都写完了，现在开始写主函数，代码如下：

def main():
    try:
        while True:
            print("cve监控中 ...")
            # 抓取本年的cve
            year = datetime.datetime.now().year
            api = "https://api.github.com/search/repositories?q=CVE-{}&sort=updated".format(year)
            # 请求API
            req = requests.get(api, headers=github_headers, timeout=10).json()
            total_count = req['total_count']
            print(total_count)

            print(req['items'][0]['name'])
            global last_total_count

            if total_count != last_total_count:
                # 推送正文内容
                # 推送标题
                last_total_count = total_count
                text = '新的CVE信息'
                # 获取 cve 名字 ，根据cve 名字，获取描述，并翻译
                cve_name = req['items'][0]['name']
                print(cve_name)
                #print(cve_name)
                cve_zh = get_cve_des_zh(cve_name)
                msg = "CVE编号：" + cve_name + "\r\n" + "CVE描述：" + cve_zh
                url = req['items'][0]['html_url']
                print(url)
                # 推送微信
                data = wechat_data(text, msg, url)
                wechat_qiye(data)
            time.sleep(60 * 15)  # 设置定时，每15分钟查看一次
    except KeyboardInterrupt:
        print('程序已停止')

if __name__ == "__main__":
    last_total_count = getNews()
    main()
