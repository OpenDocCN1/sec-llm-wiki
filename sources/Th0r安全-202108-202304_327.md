#### 前言

在安全圈，掌握第一手漏洞信息一般是比较重要的，漏洞刚爆出来的时候，有人就会在近几天将POC或者EXP发布在GitHub上，基于这种前提，这里通过Python脚本做一个监控，随时将GitHub最新漏洞信息推送到自己手机上。脚本是在大佬bonelee和大佬唯米洛熊的基础上修改的。

#### 监控思路讲解

其实就是搜索GitHub和CVE相关的项目，这里直接用GitHub的API来索引，地址为https://api.github.com/search/repositories?q=CVE-2021&sort=updated，查找的是2021年的CVE项目，因为为了方便讲解，所以2021这里用了硬编码，在脚本中可以使用时间函数来替换。现在开始分析，先访问链接，观察页面，结果如下图：

![](../Images/a0e3394f2680dbcc3c5e036ef72d3c67.png)

观察页面，我们发现为json格式，这个可以让我们很方便的提取我们需要的数据，这里需要关注的是**total\_count这个key**，这里记录的是数量，**我们可以通过这个值是否变化来设计是否推送的标志。**推送标志分析完了，现在点击items下的0，来看看里面的键值，然后提取咱们需要的数据。结果如下图：

![](../Images/c1a76dfd1a5494aaf688660a83aa21cd.png)

通过观察，我们需要的数据为name和url,将我们需要的数据提取出来，用下面代码就可以，

```
req = requests.get(api, headers\=github\_headers, timeout\=10).json()
#提取total\_count
total\_count = req\['total\_count'\]
#提取url
url = req\['items'\]\[0\]\['html\_url'\]
```

提取出需要的数据，接下来就来设计推送标志，上面简单的提了一下，现在详细说说，我们可以写一个函数命名为getNews，这个函数的目的就是向GitHub的API发送请求，**拿到total\_count这个值，然后将这个值存到一个变量里，当我们再次请求时，我们与这个变量进行比对，如果相同说明没有更新，如果不同说明更新了，然后进入条件里，更新变量，然后向手机推送。**getNews的代码如下：

```
def getNews():
    try:
        \# 获取页面的total的值
        year = datetime.datetime.now().year
        api = "https://api.github.com/search/repositories?q=CVE-{}&sort=updated".format(year)
        json\_str = requests.get(api, headers\=github\_headers, timeout\=10).json()
        cve\_total\_count = json\_str\['total\_count'\]
        return cve\_total\_count
    except Exception as e:
        print(e, "github链接不通")
        return '', '', ''
```

接下来要解决的问题是如何将消息推送到手机上？

这里的解决方案是用企业微信，注册企业微信，登陆后台，然后自建应用（避免占用篇幅，如何自建应用这里不详细阐述）。到了这里，我们会用到两个值，**一个是 注册的企业 corpid，一个是自定义应用的 Secret**，有了这两个值，我们就可以向微信推送消息了。我们再定义一个函数命名为wechat\_qiye，功能就是向企业微信的API发送求情。代码如下：

```
def wechat\_qiye(data):
    global access\_token
    \# 自定义应用的 Secret
    Secret = "pyUtd3RY\*\*\*\*\*\*\*\*\*\*\*\*\*\*Y5YYHjAWKjUEpNiQ"
    \# 注册的企业 corpid
    corpid = 'wwbfd\*\*\*\*\*\*\*\*\*\*\*\*1708'
    url = 'https://qyapi.weixin.qq.com/cgi-bin/gettoken?corpid={}&corpsecret={}'
    '''
        先提供Secret以及corpid获取access\_token。
    '''
    if access\_token == '':
        getr = requests.get(url\=url.format(corpid, Secret))
        access\_token = getr.json().get('access\_token')
    print(access\_token)
    r = requests.post(url\="https://qyapi.weixin.qq.com/cgi-bin/message/send?access\_token={}".format(access\_token),
                          data\=json.dumps(data))
    print(r.text)
    if str(json.loads(r.text)\['errmsg'\]) !\= 'ok':
        #获取新的access\_token
        getr = requests.get(url\=url.format(corpid, Secret))
        access\_token = getr.json().get('access\_token')
        #恢复之前因token过期异常失去的请求
        r = requests.post(url\="https://qyapi.weixin.qq.com/cgi-bin/message/send?access\_token={}".format(access\_token),
                          data\=json.dumps(data))
        print(r.text)
```

现在大体上已经可以使用了，但是还有一个问题，大家在GitHub上传对应CVE的POC或者EXP时，一般是没有这个CVE的漏洞描述的。那么如何获取CVE描述呢？所以这里参考了bonelee 大佬的思路，把大佬的代码拿过来用。我们可以通过在GitHub获取到的CVE编号然后去请求CVE网站(https://cve.mitre.org)，从这个网站获取描述。代码如下：

```
cve\_name = req\['items'\]\[0\]\['name'\]
\# 根据cve 名字，获取描述
def get\_cve\_des\_zh(cve\_name):
    query\_cve\_url = "https://cve.mitre.org/cgi-bin/cvename.cgi?name=" + cve\_name
    response = requests.get(query\_cve\_url, headers\=github\_headers, timeout\=10)
    html = etree.HTML(response.text)
    des = html.xpath('//\*\[@id="GeneratedTable"\]/table//tr\[4\]/td/text()')\[0\].strip()
    print(des)
    translate(des)
```

现在描述拿到了，但是是英文的，所以还需要翻译一下，我们再写一个翻译函数，将我们获取到的描述翻译成中文。

到现在为止，所有模块都写完了，现在开始写主函数，代码如下：

```
def main():
    try:
        while True:
            print("cve监控中 ...")
            \# 抓取本年的cve
            year = datetime.datetime.now().year
            api = "https://api.github.com/search/repositories?q=CVE-{}&sort=updated".format(year)
            \# 请求API
            req = requests.get(api, headers\=github\_headers, timeout\=10).json()
            total\_count = req\['total\_count'\]
            print(total\_count)
            print(req\['items'\]\[0\]\['name'\])
            global last\_total\_count
            if total\_count !\= last\_total\_count:
                \# 推送正文内容
                \# 推送标题
                last\_total\_count = total\_count
                text = '新的CVE信息'
                \# 获取 cve 名字 ，根据cve 名字，获取描述，并翻译
                cve\_name = req\['items'\]\[0\]\['name'\]
                print(cve\_name)
                #print(cve\_name)
                cve\_zh = get\_cve\_des\_zh(cve\_name)
                msg = "CVE编号：" + cve\_name + "\\r\\n" + "CVE描述：" + cve\_zh
                url = req\['items'\]\[0\]\['html\_url'\]
                print(url)
                \# 推送微信
                data = wechat\_data(text, msg, url)
                wechat\_qiye(data)
            time.sleep(60 \* 15)  \# 设置定时，每15分钟查看一次
    except KeyboardInterrupt:
        print('程序已停止')
if \_\_name\_\_ == "\_\_main\_\_":
    last\_total\_count = getNews()
    main()
```
