靶场官方介绍

Much like DC-1, DC-2 is another purposely built vulnerable lab for the purpose of gaining experience in the world of penetration testing.

As with the original DC-1, it's designed with beginners in mind.

Linux skills and familiarity with the Linux command line are a must, as is some experience with basic penetration testing tools.

Just like with DC-1, there are five flags including the final flag.

And again, just like with DC-1, the flags are important for beginners, but not so important for those who have experience.

In short, the only flag that really counts, is the final flag.

For beginners, Google is your friend. Well, apart from all the privacy concerns etc etc.

I haven't explored all the ways to achieve root, as I scrapped the previous version I had been working on, and started completely fresh apart from the base OS install.

我们先将靶场镜像导入。导入之后DC-2默认是桥接模式，我们需要改为NAT模式，改为NAT模式之后在启动环境

这就是已经启动好了

因为我们不知道靶机的IP所以我们需要扫描一下我们使用 arp-scan 命令扫描注意：arp-scan需要在root下才能使用得到IP地址 192.168.179.133

我们在页面访问这个IP

我们在 /etc/hosts 里面增加 IP 和 dc-2 使用wq命令保存退出

再次刷新页面，成功进入

我们可以看到标签处有Flag字样，点击一下发现了flag1注意：DC靶场每个靶场都有5个flag需要全部找出大体意思就是：需要使用cewl工具来爆破密码。越多越好，但有时你不可能全都赢，用个人身份登录查看下一个flag，如果找不到，请用另一个身份登录

这里提示我们使用cewl来爆破密码。，得到了许多

我们使用-w来保存在1.txt中

使用wpscan，来找到用户名密码wpscan --url http://dc-2 -P 1.txt这样我们就得到了两个用户名和密码

这样我们已经得到了用户名和密码但是需要找到WordPress的登录窗口我们去百度一下WordPress后台登录地址会有好多。我们访问 wp-login.php进入到登录页面

使用我们爆破出来的两个用户名和密码，尝试登录

点进去查看flag2如果没有捷径的话，那就走捷径吧。如果你不能利用wordpress并走捷径，还有另一种方法，希望你能找到另一个入口。

我们使用ssh连接注意：这里jerry不能进行ssh连接，tom可以，连接成功后命令行回显tom@DC-2:~$

我们使用ls查看当前目录下的文件，发现flag3.txt

我们使用cat查看文件内容，cat并不能使用，被加限制了，我们可以绕过限制

我们使用vi来查看大体意思是，让我们使用jerry登录。

我们绕过限制就是吧shell切换到/bin/sh

BASH_CMDS[a]=/bin/sh;a # 切换shell export PATH=$PATH:/bin # 添加$PATH,cat和su都在/bin下 export PATH=$PATH:/usr/bin # sudo在/usr/bin下

这样cat也能使用

我们使用su jerry切换用户

切换到jerry下，ls查看发现flag4，cat查看flag4意思大体是：很高兴看到你已经走了这么远，但你还没回家。你仍然需要得到最后的标志（唯一真正重要的标志！！！）。这里没有提示-你现在只能靠自己了。) 去吧-离开这里！！！！

我们在上图看到了关键字git，应该可以使用git提权可以使用 sudo git help config 或者 sudo git -p help ，在输入./bin/bash即可提权成功

我们查看根目录下是否有flag，因为大部分flag都会放在根目录下。完美结束！！！
