**前言:**

**以下内容均只用于分享学习，不得将其中内容用到违法法律的事情上。本期分享内容是笔者在备考cisp-pte遇到的靶场思路。**

  

  

因为此次靶场是搭建在公网云服务器上，所以匿掉ip,所分享内容均是在靶场上完成，不涉及任何对他人计算机的操作。

  

  

拿到靶场第一步，寻找注入点，多点击看一下页面，可以看到这里很熟悉

![](../Images/58f3214ea606a801fecadc8419eb3d9d.png)

  

接下来我们可以试试看看有没有注入，可以看到我们试探性访问发现有js代码，报非法访问然后跳转到首页，所以感觉是没有，这里我们可以用目录扫描去扫描敏感目录来收集信息，寻找页面注入点

![](../Images/c789781abaf7138e324a8985ad3be77e.png)

这里我们再试试搜索框，试探一下，发现有报错回显，所以这里可能是有注入的

![](../Images/d38e8a8011d5830a703d84a5265872e7.png)

这里我们用控制台可以看见是post提交方式

![](../Images/c558bd2d92c0db9990e7573615203fe0.png)

接下来我们来判断闭合符号，我们用双引号1%“ #发现是报错的，用单引号1%‘ #发现是出数据的。由此可以判断是单引号闭合，在这里%%的意思是模糊匹配

![](../Images/0d846cfffb90e976de7d1bcf4eedb007.png)

接下来我们逻辑判断用1%’ and 1=1页面回显正常，用1%‘ and1=2页面回显不正常，符合我们的预期

![](../Images/dcc2b0a950d4cd8797a840a5151c7cb9.png)

![](../Images/1114238e3ef46fbcad2c84873f786bda.png)

接下来我们用order by 来判断字段数，用二分法，先看5，报错没有  

  

![](../Images/7a041a568e6f70757f4cb3522a0716be.png)

  

再看4，也没有

![](../Images/5db0b00df92e32f1920400b79c37ee91.png)

  

再看看3，可以看见有的，所以可以判断字段数为3

![](../Images/bcc2fe8f6107ed73546e3ca0b4d7abc5.png)

  

再用union select 判断回显点，由下图可以看见。

![](../Images/ba105941b5f21f29f5666303ed65f2b3.png)

  

再判断，数据库名，通过union select 2,3,database()可以看见我们的数据库名sqlgunnews

![](../Images/d930194cb25e26aa43563c52e54b8600.png)

  

再用union select 2,3,group\_concat(schema\_name) frominformation\_schema.schemata #爆出了4个库，很显然这里面sqlgunnews是我们需要的库

![](../Images/eb6611e74fb516f06729e169326f8226.png)

  

再用union select 2,3,group\_concat(table\_name) frominformation\_schema.tables wheretable\_schema='sqlgunnews'查询sqlgunnews里面的数据表名，可以看到admin,class,news,system

  

![](../Images/e24354eacf5a0746fb232d930efad602.png)

这里我们判断一下是哪个表，每个都试试吧，用union select2,3,group\_concat(column\_name) frominformation\_schema.columns where table\_name='admin',查询到id,admin,password字段

  

![](../Images/3499fa90639d627eaf4e7d31ed4ad4c8.png)

这里我们查询字段值，key=1%' union select2,3,group\_concat(admin) from admin #查询字段值，admin，21232f297a57a5a743894a0e4a801fc3

![](../Images/069bdd5b88ce09b8361ba6aa7fb3cf85.png)

![](../Images/ffc6c305b9f91eeceb891fcc966bf924.png)

接下来我们猜目录或者扫目录，看看有没有啥后台登陆文件，这里我们用御剑或者dirsearch，这里字典垃圾了没有扫到，咋们就直接访问sqlgunadmin.php

![](../Images/41735e696cca43a92aeb6ee03edff548.png)

  

访问到后直接用刚刚注入出来的密码账户登陆。上面的密码是md5加密了，解密后密码也是admin

![](../Images/83714f2679291e2f66ed69ae4bddc3c9.png)

  

来到后台后我们可以开始找上传点，数据交互点，来寻找漏洞。发现有任意下载，可能还有xss反弹

  

![](../Images/a1d1befd5c9262c997562fe89d782f8f.png)

![](../Images/c45ca7d2b55cad3a1ac3207a0bcf8418.png)

这里没有看到上传点，这里就得想其他办法，用注入看看能不能上传马子。这里用load\_file和into outfile绝对路径来读文件来写文件。用key=-1%' union select 1,load\_file("/etc/passwd"),3 #发现文件可读。

![](../Images/56ddda9cad4488ae62f481ae81d81a61.png)

  

再用key=-1%' union select 1,'',3 into outfile"/var/www/html/2.php" #发现文件可写

![](../Images/bdacfa53c437d4fb2715ca5dd8a048e1.png)

  

然后再用key=-1%' union select 1,'',3 into outfile"/var/www/html/3.php" #，上传马子，可以看见上传成功

![](../Images/59badb140dfc6d867579981b7be765ff.png)

  

用蚁剑连，成功完成靶场训练！

![](../Images/5e3b8f9d40c656a4cd4310df6ee5a409.png)
