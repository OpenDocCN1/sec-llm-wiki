ChainedTransformer.transform()            

    ->ConstantTransformer.transform()            

      ->InvokerTransformer.transform()              

         ->Method.invoke()                

        ->Class.getMethod()            

       ->InvokerTransformer.transform()

lazyMap:

可以发现是通过这里与上半部分进行连接

public Object get(Object key) {  
   if (map.containsKey(key) == false) {  
       Object value = factory.transform(key);  
       map.put(key, value);  
       return value;  
   }  
   return map.get(key);  
}

那么是如何调用这个get的呢，这里我们看到AnnotationInvocationHandler的invoke方法，这里有一个default执行get方法，这里只需要将memberValues赋值为LazyMap就行了

因为使用的是动态代理，所以不管调用了啥方法，都会进入到这个invoke方法中，memberValues可控。
