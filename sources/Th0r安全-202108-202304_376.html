今天学的链子跟BCEL编码解码有关，这里先讲一下BCEL。


Apache Commons BCEL是一个用于分析、创建和操纵Java类文件的工具库。

BCEL攻击原理:

com.sun.org.apache.bcel.internal.util.ClassLoader#loadClass加载一个类名有$$BCEL$$的类时会截取出后面的字符串,之后使用com.sun.org.apache.bcel.internal.classfile.Utility#decode将剩下的字符串解析成类字节码，最后被defineClass注册，当该类被加载就会触发类中的evilcode.

代码如下:


int    index    = className.indexOf("$$BCEL$$");

String realName = className.substring(index + 8);

byte[] bytes = com.sun.org.apache.bcel.internal.classfile.Utility.decode(realName,true);


BCEL编码代码:


private static final byte[] CLASS_BYTES = new byte[]{字节码数组}];

String className="$$BCEL$$"+com.sun.org.apache.bcel.internal.classfile.Utility.encode(CLASS_BYTES,true);

正常情况下，JSON.parse()会识别调用目标类的setter方法以及某些满足特定条件的getter方法，但是getConnection()方法并不符合特定条件，因此这里是通过调用toString()方法，提取类中所有的Field,执行相应的getter,setter等方法。


这里看一下调用条件:


if (object.getClass() == JSONObject.class) {

key = (key == null) ? "null" : key.toString();

}


这里看到当key是JSONObject对象时会触发toString()方法，这里就完成了getConnection的调用，因此poc中将{"@type":..........}外面再套了一层{},将其变成了一个JSONObject对象，完成了链子。
