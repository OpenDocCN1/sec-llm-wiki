# CVE-2022-42889复现+Xray POC

* * *

## 漏洞简述

2022年10月13日 GMT+8 20:09:48

Apache发布安全公告，修复了Apache Commons Text中的一个远程代码执行漏洞（CVE-2022-42889）

Apache Commons Text版本1.5到1.9中，由于不安全的插值默认值，当输入的参数不受信任时，可能导致远程代码执行。

### 影响范围

1.5 <= Apache Commons Text 版本<= 1.9

### 加固建议

目前该漏洞已经修复，受影响用户可以升级到Apache Commons Text 1.10.0。 下载链接： https://commons.apache.org/proper/commons-text/download\_text.cgi

### 参考链接

https://www.mail-archive.com/announce@apache.org/msg07643.html https://nvd.nist.gov/vuln/detail/CVE-2022-42889
