## 实现

参考了来自“360Quake空间测绘” 的一篇文章

`https://mp.weixin.qq.com/s/cmfc_whg9AZMuWsb0uqy-Q`

使用pocsuite实现，核心代码逻辑与其相似

![](../Images/3cddc69206128dd058d4715c9fbb4209.png)成功实现效果图：

![](../Images/c3b739dbc1af3b929035dcc2b0579a03.png)

原文中，使用quake引擎搜索 service:"socks"，保存到本地进行socks验证。如下图：

![](../Images/6254a59178e0d2d746f6237f47e3e452.png)

在这里笔者提供另一种方法，使用pocsuite自带的Modules。Quake：

（不建议把线程开那么高，20足以）

```
pocsuite -r Wsocks5.py --dork-quake "service:"socks" AND country:\"United States of America\""
 --max-page 10 --threads 20
```

效果图如下：

![](../Images/641e72847287db52e629936c90f9873a.png)

Fofa：

（不建议把线程开那么高，20足以）

```
pocsuite -r Wsocks5.py --dork-fofa "protocol="socks5" && country="US""
 --max-page 100 --threads 20
```

效果图如下：

![](../Images/3a65eee6a5246661bc73250245dbfb97.png)
