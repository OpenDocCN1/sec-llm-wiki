Read-only file system

Read-only file system报错的原因是：所在的分区只有读权限，没有写权限

要想解决很简单

2.3.1 查看分区

df -T

2.3.2 修改分区权限

由于咱们这次测试的目录是

/usr/local/www/

在/usr下，所以使用命令

mount -o remount -rw /usr

增加写权限
