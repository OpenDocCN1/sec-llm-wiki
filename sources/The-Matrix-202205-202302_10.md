### 2.3 写文件

这次抱着试一试的心态，写个文件进

```
/usr/local
/www/
```

参照2.1的方法，写文件

不出意外的话，意外很快就再次发生了

```

Read-only file system
```

![](../Images/26d8ee440b4b98ad7849ed8a5558dd54.png)Read-only file system报错的原因是：所在的分区只有读权限，没有写权限

要想解决很简单

#### 2.3.1 查看分区

```

df -T
```

![](../Images/da508acb75a722528e1c50839e60aa5c.png)

#### 2.3.2 修改分区权限

由于咱们这次测试的目录是

```
/usr/local
/www/
```

在/usr下，所以使用命令

```

mount -o remount -rw /usr
```

增加写权限

![](../Images/c640ca06bed8e5a33946e9ce7b888e3f.png)

#### 2.3.3 再次写文件

然后再执行写文件的命令，就ok了

![](../Images/47c1d963da48ae216064de35494c9e37.png)用cat命令瞅一眼

![](../Images/ab0eb0f56b7eaf3671bfcdc4487e4ce2.png)成功！

#### 2.3.4 成功访问

直接访问根目录，可以看到可以访问咱们的文件了！![](../Images/b29ccdedbc5eb2c75568849e4419bf52.png)
