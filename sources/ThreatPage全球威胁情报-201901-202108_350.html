1、TA505组织使用LOLBins和ServHelper后门来攻击全球金融公司。ServHelper恶意软件收集了信息，并在受感染的系统中进行了探测，执行rundll32.exe（Windows操作系统进程）后，将执行PowerShell脚本enu.ps1。此脚本使用Base64编码，以避免被防病毒产品检测到。ServHelper后门依赖于四个LOLBins和一些本机Windows操作系统进程来进一步推进其恶意活动。ServHelper还获得了Sectigo RSA Code Signing CA的签名和验证证书，以逃避检测。推荐阅读原文文档。

【推荐阅读】1、NSA泄露工具打造工具包，思路不错。两个泄露的NSA漏洞利用工具包已被用于创建名为SMBdoor的恶意软件。恶意软件的特征类似于DoublePulsar和DarkPulsar。恶意软件非常隐蔽，因为它不会绑定到任何本地套接字，打开端口或hook到现有功能，并且这样做可以避免触发某些防病毒系统的警报。恶意软件设计为Windows内核驱动程序，如果安装，可能会滥用srvnet.sys进程中的未记录的API。之后，恶意软件会将自己注册为SMB（服务器消息块）连接的有效处理程序。
