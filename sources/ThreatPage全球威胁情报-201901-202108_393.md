# 梳理疑似来自APT27对国际民航组织的攻击

> 2019年2月27日，加拿大媒体称国际民航组织ICAO在2016年受到来自APT27（Emissary Panda）的网络攻击。
> 
> 2019年2月27日，网络安全公司secureworks发布报告分析BRONZE UNION（Emissary Panda）木马关联分析。
> 
> 2019年3月1日，网络安全公司ESET跟风发布报告【4】，没有任何营养价值。
> 
> 至本文止，外媒多引用加拿大媒体以及ESET和secureworks结论并大肆宣扬，要求来自中国的APT组织（APT27）对入侵事件负责。

  

![](../Images/337ab60cad7612e9f23e35f52a9da16c.png)

**加媒报道**  

    通过2019年2月27日加拿大媒体【2】的报道，我们知道在2016年11月加拿大国际民航组织ICAO收到攻击，同月洛克希德·马丁公司的安全分析师发现水坑攻击网站，并发布告警；国际民航组织ICAO内部自查，联合国分析师辅助，但是由于“限时”问题，只发现了存在Systems Infrastructure Associate用户，并且该账户疑似被恶意利用。后ICAO解雇其4名网络安全人员。

    转到2017年1月，欧洲民航组织员工发现自己账号被冒用。同一时间，ICAO要求SecureWorks介入调查企业安全。据称，国际民航组织的反病毒软件已经识别出网络攻击中使用的恶意程序，但是并未清理恶意软件。2016年12月21日解除职责的ICT团队的四名成员于2017年2月6日恢复了职位。

    加拿大媒体并未说明攻击事件是APT27所为，文中以“probablement”法语可能、大概的意思表述。

    通过在分析2019年2月27日SecureWorks【3】发布的BRONZE UNION（Emissary Panda）工具分析，文中主要描述Emissary Panda组织在2018年使用的工具变种。包括zxshell\\Ghost RAT以及TTP中的“P”。同样没说明APT27攻击ICAO。

**关于APT27，网络安全公司认知角度。**  

    APT27战略和战术情报【5】  

##    **战略威胁情报**

1.  APT27瞄准涉及全球航空航天，学术，媒体，技术，政府和公用事业组织的国际行业组织。
    
2.  关注对涉及美国军事能力具有战略利益的国家的个人或团体感兴趣的信息。
    
3.  使用历史上被认为是中国运营的威胁组织利用的网络基础。
    
4.  该组织运营基础设施的一部分与基于PRC的互联网服务公司之间的联系。  
    
5.  研究人员发观察到的在该组织入侵期间，能够迅速收集了帐户凭据，升级的权限，并部署了多个Web shell。
    

  

**    战术威胁情报**

1.  OwaAuth - 部署到Microsoft Exchange服务器的Web shell和凭据窃取程序作为ISAPI筛选器安装。捕获的凭据使用密码“12345678”进行DES加密。  
    
2.  China Chopper web shell - 这个基于Web的可执行脚本与功能齐全的用户界面进行通信，允许攻击者传输和创建文件，打开命令终端以及与数据库服务器交互。  
    
3.  Rcmd - 此横向移动工具有助于在目标环境中的系统上执行命令。  
    
4.  Wrapikatz - 此工具将Mimikatz代码包装在自定义加载程序中以逃避防病毒检测，并更改命令行使用以避开过程遥测检测并使该工具更易于使用。此工具不是APT27独有的。  
    
5.  Netview - 此公开可用的主机枚举工具提供有关IP地址，网络共享，远程会话和登录用户的详细信息。  
    
6.  Kekeo - 这个公开可用的工具集操纵Kerberos身份验证协议。分析人员通过名为ms.exe的文件识别了BRONZE UNION演员，该文件可能是Kekeo工具集中的凭据滥用的工具。
    

  

**APT27\_TTP**

**1、访问向量和命令与控制**

安全厂商2016年分析的感染链:

![](../Images/090ff0baf809694e3dfb976a7b0414c3.png)

国外分析团队发现该组织多个创建webshell失败的案例。（上传或者包含等方法植入webshell失败，被日志捕获或者上传失败文件未删除）命令和控制（C2）和运营基础设施中使用自注册IP地址和商业VPN服务的组合。

2、横向拓展、主机枚举

使用ipconfig，net use，net user和net view命令进行内部侦察，包括域枚举和网络状态。netview主机枚举工具。

Rcmd横向移动工具相关。遗留的VBS脚本：read.vbs  

3、控制与逃避检测

PowerShell应用广泛。

![](../Images/0617c168e5e88f6d8048bd38cb484009.png)

dll劫持，劫持合法程序dll。

禁用日志进程和删除日志。使用appcmd命令行工具来解锁和禁用服务器上的默认日志记录组件（systsm.webServer/httplogging）

![](../Images/61ab4ff14f8026d0de13650d5b5007c9.png)

#### 4、凭证和权限

使用Wrapikatz工具（w.exe）和一个用法语句从内存中检索各种密码和Windows凭据。  
c:\\programdata\\w.exe -w -l -c >> c:\\programdata\\w.txt

Web shell部署提供的访问来获取帐户凭据。  
使用漏洞提权，比如CVE-2014-6324.

5、数据窃取

运行quser.exe以识别设备上的现有RDP会话，利行命令以编译指定文件类型的RAR存档，并使用密码加密存档：

![](../Images/9c8bab5d7b4386cea989570c350b3407.png)

使用move\\copy等命令，重命名打包加密的文件。多命名为tmp后缀文件。

利用webshell删除打包的tmp文件。  

6、尝试回归

当该组织被检测并且删除了特马后，会尝试连接OWA或者webshell后门。或者是其他备份过的后门等。
