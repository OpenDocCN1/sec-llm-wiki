# Cobalt组织针对金融机构的攻击故事

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUxMDk3ODEwOA==&mid=2247483807&idx=1&sn=5fdaecae1b130c6bd694c7e237a9f76d&chksm=f97bf0ccce0c79daaf5fbcc88cc0b572681602112f32897dc1784f6bd0dea9d2f15e2a440557&scene=126&sessionid=1681272469#rd](http://mp.weixin.qq.com/s?__biz=MzUxMDk3ODEwOA==&mid=2247483807&idx=1&sn=5fdaecae1b130c6bd694c7e237a9f76d&chksm=f97bf0ccce0c79daaf5fbcc88cc0b572681602112f32897dc1784f6bd0dea9d2f15e2a440557&scene=126&sessionid=1681272469#rd)

    ***网络金融犯罪组织“Cobalt”以其渗透工具“Cobalt Strike”命名。  
    该网络犯罪组织攻击过亚美尼亚，保加利亚，白俄罗斯，爱沙尼亚，格鲁吉亚，吉尔吉斯斯坦摩尔多瓦，荷兰，波兰，罗马尼亚，俄罗斯，西班牙，英国，马来西亚等国家的几家银行和金融机******构。***

  

![](../Images/9eb6c5f0c32705b476134e3d5846fd55.png)

    Cobalt组织于2016年首次被发现。网络犯罪组织的名字来源于他们使用的渗透测试工具'Cobalt Strike'，从银行网络中的受感染计算机转移到控制ATM机的专用服务器上。该组织于2018年3月在西班牙被捕，攻击了40个国家的近100家银行，并窃取了超过10亿欧元。Cobalt组织使用的恶意软件和工具包括Cobalt\_Strike，CobInt，SpicyOmlette，Threadkit漏洞利用工具包和more\_eggs。

  

**Cobalt group对ATM机的攻击**

  
    2016年11月，网络犯罪分子使用“Jackpotting”技术突袭了整个欧洲的ATM服务器，该技术迫使受感染的ATM机通过在机器的计算机上安装恶意软件来分发现金。这次袭击影响了世界上最大的两家ATM制造商Diebold Nixdorf和NCR Corp。【见参考链接1】

    这次袭击影响了近14个国家，包括亚美尼亚，保加利亚，白俄罗斯，爱沙尼亚，格鲁吉亚，吉尔吉斯斯坦，摩尔多瓦，荷兰，波兰，罗马尼亚，俄罗斯，西班牙，英国和马来西亚。研究人员指出，这次袭击是由一个名为Cobalt的威胁攻击组织发起的。

  

**Cobalt通过网络钓鱼活动定位银行**  
  
    2017年11月，Cobalt组织通过鱼叉式网络钓鱼活动攻击银行。发送到目标银行的网络钓鱼电子邮件包含带有CVE-2017-8759漏洞利用的RTF附件。一旦受害者打开并下载附件，恶意代码就会下载并执行Cobalt Strike工具。然后该工具连接到由Cobalt组织运营的控制服务器。【见参考链接2】  
    在同一个月的RCE漏洞（CVE-2017-8759）之后，Cobalt组织开始针对包含RTF附件的网络钓鱼电子邮件向银行和金融机构发起攻击，并利用CVE-2017-11882漏洞。【见参考链接3】

  

**Cobalt公布其目标**

      

    在针对银行的网络钓鱼电子邮件活动中，Cobalt使用的钓鱼邮件在电子邮件的“收件人：”字段中包含了目标的电子邮件地址。这种失误让该组织的研究人员和其他受害者了解该活动的目标。【见参考链接4】

  

**Cobalt组织被捕，但恢复了对Cobint恶意软件的攻击**

  

    Cobalt威胁组织成员于2018年3月在西班牙被捕，涉嫌攻击40个国家的100家银行，盗窃超过10亿欧元。然而，Cobalt团伙继续攻击银行。这次攻击发生在2018年5月，并使用“CobInt”恶意软件通过网络钓鱼电子邮件攻击俄罗斯和独立国家联合体的银行员工。【见参考链接5】

    这些网络钓鱼邮件据称来自一家“leading antivirus company”，并声称该银行的系统违反了法律规定。电子邮件敦促收件人下载附件并阅读文档。打开附件后，“CobInt”恶意软件感染了银行的计算机系统。

  

**2018年5月至7月的三次网络钓鱼活动**

在第一个攻击活动中，据称来自欧洲银行联合会的网络钓鱼电子邮件包含恶意PDF文件。这个恶意文件要求受害者下载包含三个漏洞的武器化的RTF文件。攻击者释放了一个名为More\_eggs的JScript后门，允许攻击者获得对目标系统的远程控制。  
    第二个攻击活动于6月19日开始，其中电子邮件中包含恶意网站链接。点击后，恶意URL会将受害者重定向到恶意Word文档，从而触发感染链。此活动系列中的目标组织是主要的ATM和支付系统制造商。  
    第三个攻击活动于7月10日开始，攻击者针对各种企业发送网络钓鱼电子邮件以及一个包含触发感染链漏洞的恶意RTF文件。

  

**Cobalt gang分发了SpicyOmelette恶意软件**

    2018年9月，Cobalt威胁组织使用一种名为SpicyOmelette的新远程访问木马（RAT）来攻击全球银行。此恶意软件是一种JavaScript RAT，具有多种检测功能。SpicyOmelette还能够窃取系统信息，检查防病毒工具以及在系统中安装其他恶意软件。【参考链接6】  
    Cobalt Group的新恶意软件“SpicyOmlette”被用作攻击初始入侵阶段的一部分。恶意软件是通过包含恶意PDF文档的网络钓鱼电子邮件发送的。单击PDF文档后，恶意链接会将受害者重定向到由Cobalt组控制的Amazon Web Service（AWS）URL。此链接将SpicyOmelette恶意软件安装并执行到受害者的系统上。

  

**使用Threadkit漏洞利用工具包的更新版本发现了Cobalt**  
  
    2018年10月，研究人员发现Cobalt组织正在利用新版本的Threadkit恶意软件，这是一种宏观交付框架，此前曾用于2017年的攻击。  
    Threadkit恶意软件是通过包含RFT Microsoft Office附件的网络钓鱼电子邮件分发的，该附件包含漏洞构建工具包的改进版本。研究人员指出，CobInt是Threadkit的有效载荷，现在有一个额外的混淆层，使用XOR例程解码初始有效载荷，使其检测起来很复杂。
