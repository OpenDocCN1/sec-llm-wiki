# 探讨Fallout Exploit Kit的各种恶意软件攻击活动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUxMDk3ODEwOA==&mid=2247483710&idx=1&sn=19395389303483518feaf16e76a44c33&chksm=f97bf06dce0c797b9c58b2a71cba512aca07cb7d91daecc98cb12b270fe57aeedcc262f4d042&scene=126&sessionid=1681272479#rd](http://mp.weixin.qq.com/s?__biz=MzUxMDk3ODEwOA==&mid=2247483710&idx=1&sn=19395389303483518feaf16e76a44c33&chksm=f97bf06dce0c797b9c58b2a71cba512aca07cb7d91daecc98cb12b270fe57aeedcc262f4d042&scene=126&sessionid=1681272479#rd)

> *    Fallout漏洞利用工具包首次出现在攻击日本，韩国，中东，南欧等国家的恶意广告活动中。*
> 
> *    漏洞利用工具包被发现分发GandCrab勒索软件，SAVEfiles勒索软件，KrakenCryptor勒索软件，DanaBot木马，Nocturnal恶意软件，GlobeImposter勒索软件，AZORult变种，Vidar恶意软件等*

**GandCrab勒索软件**

    FireEye的研究人员给出发GandCrab Ransomware的 Fallout漏洞利用工具包分析。漏洞利用工具包用户指纹浏览器配置文件，并在用户配置文件与感兴趣的目标匹配时传送恶意内容。然后，用户将从合法广告页面重定向到漏洞利用工具包登录页面URL。

     恶意软件要么提供Fallout漏洞利用工具包，要么尝试将用户重定向到基于浏览器和操作系统的其他社交工程活动，从而欺骗用户下载恶意软件。

    研究人员指出，此活动已引发政府，电信和医疗保健行业客户的警报。研究人员还观察到Fallout在分发GandCrab勒索软件的恶意广告活动中利用漏洞CVE-2018-4878和CVE-2018-8174。

**SAVEfiles勒索软件**

    2018年9月，在攻击日本、法国等用户的恶意广告活动中发现了Fallout漏洞利用工具包中的SAVEfiles勒索软件。在登陆托管Fallout漏洞利用工具包的网站上之前，该广告会多次重定向用户。然后，漏洞利用工具包将自动下载并将SAVEfiles勒索软件安装到受害者的PC上。然后使用.SAVEfiles扩展名对受害者的文件进行加密。在加密时，勒索软件在每个文件夹中留下赎金票据!!! !!! SAVE\_\_FILES\_\_INFO !!!.txt'。赎金票据要求受害者通过BM-2cXonzj9ovn5qdX2MrwMK4j3qCquXBKo4h @bitmessage \[。\] ch或savefiles @ india \[。\] com与攻击者联系以获取付款说明。  

**Kraken Cryptor勒索软件**

    在2018年10月，Fallout开始推出Kraken Cryptor勒索软件版本1.5和1.6。像往常一样，用户在登陆托管Fallout漏洞利用工具包的网站之前被重定向了好几次。然后，漏洞利用工具包利用Windows VBScript漏洞CVE-2018-8174安装Kraken Cryptor勒索软件。

    安装勒索软件后，受害者文件将被加密并重命名为具有随机扩展名的随机名称。在加密时，勒索软件会留下一个名为“如何解密文件 - \[扩展名\] .html”的赎金。这张赎金说明包含如何支付赎金的说明，并联系我们在onionhelp @memeware \[。\] net或BM-2cWdhn4f5UyMvruDBGs5bK77NsCFALMJkR @ bitmessage \[。\] ch的联盟会员。

**DanaBot，Nocturnal和GlobeImposter**

    在2018年11月，发现了Fallout漏洞利用工具包利用Windows中的已知漏洞来分发各种恶意软件变种，例如DanaBot银行木马，Nocturnal信息窃取器恶意软件和GlobeImposter勒索软件。

    通过执行恶意JavaScript，重定向大量诱饵网站给用户。如果重定向的用户正在运行Internet Explorer，则漏洞利用工具包将尝试利用Windows CVE-2018-8174 VBScript漏洞来安装恶意软件负载。

**AZORult恶意软件变种**

    2018年10月20日，研究人员发现使用Fallout Exploit Kit 将Azorult变体用作“FindMyName”活动中的主要有效载荷。Fallout使用多个HTML标记（例如span，h3和p）来隐藏具有高度混淆的标记内容的真实漏洞利用代码。解密后，真正的VBScript代码利用了IE VBScript漏洞CVE-2018-8174。一旦被利用，Fallout Exploit Kit会下载一个'.tmp'文件，这是AZORult的变体。

**Vidar Infostealer恶意软件**

    在2019年1月，研究人员观察到攻击者使用Vidar恶意软件和GandCrab Ransomware的组合来攻击受害者。来自Malwarebytes的安全研究人员对该活动进行了调查，发现使用Fallout和GrandSoft等几个漏洞利用工具包初步安装了Vidar恶意软件，然后使用了包含GandCrab勒索软件的辅助有效攻击载荷。但是，Vidar Infostealer恶意软件主要通过Fallout漏洞利用工具包进行分发。
