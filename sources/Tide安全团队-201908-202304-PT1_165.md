# 描述

有多种获得root 的方法，但是，已经在系统包含了一些为初学者提供线索的flag。总共有五个flag，最终目标是在 root 的主目录中找到并读取flag。您甚至不需要成为 root 即可执行此操作，但是最终目标是获得 root 权限。根据您的技能水平，您可能可以跳过查找大多数这些标志并直接获取根。

# 信息收集

## 获取IP

在物理机虚拟机中，靶机与攻击机处于同一网段，使用arp-scan对网段进行二层主机探测，获取到靶机ip如下图中所示，ip192.168.183.132为靶机地址。

*   

```
`arp-scan -l`
```

  
![](../Images/bfce2f75ac2165146a6853b910bf0284.png)

## 获取服务

使用nmap扫描靶机开放的端口服务，发现系统开放了22、80、111端口。  
![](../Images/97ac895da4ea74a5b13f90b89d625427.png)  
通过ip访问目标的80端口web服务，发现系统使用了Drupal的cms,通过wappalyzer插件检测Drupal的版本为7.0，在nmap中探测出的信息中80端口使用的也是Drupal 7。  
![](../Images/d21515f5651dd18a279712256ec783cc.png)  
查看一下robots.txt发现很多页面，访问发现没有权限，在robots中的信息中没有发现太多有用信息。  
![](../Images/4ed88ea7c8efdfdd7266b7b5e1d66f5d.png)
