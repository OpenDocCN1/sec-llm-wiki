注释  

*   
*   
*   

```
1、--+空格  2、#  3、/*!数字 xxxxx*/ 第一位是主版本号，第二位是0，剩余是次版本号，大于这个数字没回显
```

  
字段表示  

*   
*   
*   

```
1、column=xxx[正常表示]	
2、`任意符号`.``.column=xxx
```
