一、漏洞描述
CouchDB是一个开源的面向文档的数据库管理系统。可通过RESTful JavaScript Object Notation (JSON) API访问，CouchDB可安装在大部分POSIX系统上，包括Linux和Mac OS X。
CouchDB数据库配置不当时存在未授权访问漏洞，攻击者利用该漏洞可导致数据信息泄露，甚至可执行任意系统命令。
二、影响产品
Apache Software Foundation CouchDB
三、危害级别
危害等级：高危
四、漏洞POC及检测
通达对Couchdb数据库的研究及复现相关漏洞，发现当Couchdb存在未授权访问漏洞时访问：http://your-ip:port/_session，其返回值中包含"authenticated": "default"的json数据。如图所示：
根据其特征编写了检测该漏洞的poc脚本，为用户提供一键式漏洞检测服务。用户可访问潮声漏洞检测平台：http://poc.tidesec.com/ 进行漏洞检测。
五、整改方案
1、指定CouchDB绑定的IP（需要重启CouchDB才能生效）在 /etc/couchdb/local.ini文件中找到“bind_address = 0.0.0.0”，把0.0.0.0修改为127.0.0.1，然后保存。注：修改后只有本机才能访问CouchDB。2、设置访问密码（需要重启CouchDB才能生效）在 /etc/couchdb/local.ini中找到“[admins]”字段配置密码。
