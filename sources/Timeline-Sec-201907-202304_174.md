**0x01 简介**  
  
  

Django是一个由python编写的开源Web应用框架。采用了MTV的框架模式，即模板M、视图V和模板T。Django也是遵循 MVC  设计模式的框架。MVC是Model、View、Controller三个单词的简写，分别代表模型、视图、控制器。  

  

**0x02 漏洞概述**  
  
  
**编号：CVE-2020-7471**  
2020年2月3日，Django官方发布安全通告公布了一个通过StringAgg（分隔符）实现利用的潜在SQL注入漏洞。攻击者可通过构造分隔符传递给聚合函数contrib.postgres.aggregates.StringAgg，从而绕过转义符号（\\）并注入恶意SQL语句。  
  
**0x03 影响版本**  
  
  

#### **受影响版本**

Django 1.11.x < 1.11.28

Django 2.2.x < 2.2.10

Django 3.0.x < 3.0.3

Django 主开发分支

  

#### **不受影响产品版本**

Django 1.11.28

Django 2.2.10

Django 3.0.3
