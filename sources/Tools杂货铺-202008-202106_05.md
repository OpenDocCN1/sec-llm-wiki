        在渗透测试中，经常碰到安全狗，于是就下载一个最新版的研究研究。以此提高效率~官方提供最新的版本为5.0版本

![](../Images/28ec8cba8606349c71d82515dc35b9f3.png)

测试win的服务器，安装以后，把相关安全服务开起来，避免测试不完全。

![](../Images/d9fd9ab7f47db90cf217726f561386d6.png)![](../Images/ba030dfdb067accf4d67f0a0ad514e65.png)![](../Images/fb2cc1fcf33ea7a8a18e087eb922cb72.png)

该开的服务已经开了，安全系数应该还蛮高的了。下一步在msf获取最高的system权限先

![](../Images/6ec5c5e030d4f2dc2fdad362b46e33d1.png)

获取到以后尝试添加用户，看看会不会拦截

![](../Images/fe457e9718b9d152e46efd522a78d911.png)

添加用户没有拦截，但是添加到管理组就被拦截下来，在系统中看到安全狗拦截的日志

![](../Images/68d5abf3a30d49543d06114d9a41bb67.png)

显示拦截成功，那就是拦截呗，尝试杀死安全狗的进程方法，先查看安全狗的进程

![](../Images/7b6a32b94e529bc5a9febe14bbc4c46c.png)

使用taskkill /f /pid pid号强制杀死进程~

![](../Images/b84506c310164bd49182000e50477bdb.png)

发现此操作被阻止了，查资料发现SafeDogGuardCenter.exe 为安全狗守护进程，是无法在taskkill 关闭。因此无法用该方法关闭安全狗。

尝试删除安全狗服务sc query,安全狗服务为SafeDogGuardCenter

![](../Images/a185772c8724de99765dc386f98bd26e.png)

*   
*   

```
sc delete SafeDogGuardCenter    //删除安全狗这个服务安全狗shutdown -r 重启服务器，安全狗没有拦截
```

![](../Images/e1a0f0a01076c37494b095574a1c7b13.png)

成功将服务器重启！安全狗仍然在运行，但在服务器发现安全防护被自动关闭了  

![](../Images/29512ed8746071f9b30542a790b8912f.png)

![](../Images/780bf415edc2fdef79b6822ca95cd2cf.png)

sc config SafeDogGuardCenter start= disabledshutdown -r  //重启服务器
