前期准备：邮箱、github账号

  

![](../Images/4880bf53d9490f818aee25d1ed87a8ec.png)

  

一、领取福利

首先登陆ibm官网注册一个账号，官网地址：https://cloud.ibm.com

![](../Images/e361c40cf1ce4c770c552350ea7776bc.png)

按提示输入信息，登录邮箱填写验证码，完成注册即可

![](../Images/e177591c7a706fe8fe642eba5a10ddfc.png)

点击创建账户，会跳转到另外一个页面，默认继续即可

![](../Images/c654fc58c78292a25aba60bb8054ccc2.png)

登录成功之后，在左上角选择菜单-Cloud Foundry-公共

![](../Images/2e607bfb6d93622155ac3d3a312d8b57.png)

跳转页面后，直接点击创建

![](../Images/d55483997b2883172b61d8489682e359.png)

跳转页面后，选择区域达拉斯，套餐选择，256M

![](../Images/cc14614efea104e89da91af7279a2ab2.png)

填写应用名称，主机名会自动匹配应用名称。其他地方保持默认即可。此处需要记住应用程序名称、域的信息后面需要用到。

![](../Images/b6fefc19b990b2db985f60a5edd4798b.png)

创建成功后会自动启动。在右上角打开IBM cloud shell，就可以进入终端页面了

![](../Images/f959b824c37770930971c8385ad76a5b.png)

进入shell页面

![](../Images/439c9fa3dd30519576c1429a5e1818a8.png)

这样就可以正常使用了。当作自己的小服务器来使用啦。

  

二、合理配置

因为该服务器，在10天没有任何操作会进入休眠，那么我们需要进行设置来到达在一定的时间内实现让它不进入休眠状态。第二点是通过GitHub来实现让避免进入休眠状态，经常登录使用的表哥可以略过

  

现在登录github账号-搜索“IBMYes”-点击右上角的Fork到自己的库中

![](../Images/53b9819f4c3f11f3891d5f1d3d240034.png)

在自己的储存库中找到杠Fork下载的资料-点击Settings

![](../Images/ef3e7c25e40902cfcc752d90e093b89b.png)

然后点击Secrets

![](../Images/10d644eb3f2456d395a67a48b2a00121.png)

然后New Secrets

![](../Images/b539feeeb52097d05cfbbce3271ad3c8.png)

```
然后新建第一个name：IBM\_ACCOUNT   Valu：登录ibm邮箱和密码
```

![](../Images/cf806c60d0c7a80da1d29aae8401e79e.png)

```
创建第二个name：IBM_APP_NAME Value：应用的名称，前面让记住的名称
```

```
![](../Images/821295add163b59193acbe3663bab618.png)
```

```
创建第三个name：REGION_NUM value：区域编码，这个是前面让记住的域信息转换过来的，默认应该是7。或者自己在ibm查看信息，看是哪个区域然后对应的值是多少。

```

`![](../Images/7bde693e33d08b3fbb50688c9f9244eb.png)   `

![](../Images/1fa8141c887e9d4af9df4da0dbda1beb.png)

然后创建好之后，点击Actions

![](../Images/69f8fcdb13361bfed4223c7e269e1e44.png)

点击这个原谅色的按钮

![](../Images/eebb2f568b9fe2c2599ef7f8d6c8c6db.png)

然后点击Code-点击第一项.github/**workflows**/\-点击ibm.yml\-在右上角编辑这个文件

![](../Images/5a231c607d93815548e8efc7b97f84da.png)

![](../Images/ab77aaee4d5a405a0f940390195f11fe.png)

然后在把37行的./IBM\_Cloud\_CLI/ibmcloud cf install修改成./IBM\_Cloud\_CLI/ibmcloud cf install -v 6.51.0。然后再点击Start commit-Commit changes

![](../Images/35c1aec09c5828848bd6051713081b5c.png)

然后点击Actions，等update变成原谅色的勾勾就可以了。这样就完成了，这样就不会出现进入休眠状态。

![](../Images/42fd23c876088a902148f5dff695f7ed.png)

如果嫌麻烦，也可以手动登录IBM，然后在左边找到公共，找到自己创建的，在右边手动启动即可

![](../Images/d1af035f38f04b9da88a7281024d015f.png)

最后因为这个是属于轻量级的服务器，内存小。可能连接速度等不能满足各位大佬，但是要求不是很高的表哥可以考虑，领取使用。
