# 十大最严重漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MDQ1MzQ0NA==&mid=2247484351&idx=4&sn=27b4efdf341dbda733a22ec3477c1ca4&chksm=ebb90b94dcce8282651d26053bd08aa1cbae22dce7976d484ae12121dfb0e8c69be6c050773b&scene=126&sessionid=1681311138#rd](http://mp.weixin.qq.com/s?__biz=MzI4MDQ1MzQ0NA==&mid=2247484351&idx=4&sn=27b4efdf341dbda733a22ec3477c1ca4&chksm=ebb90b94dcce8282651d26053bd08aa1cbae22dce7976d484ae12121dfb0e8c69be6c050773b&scene=126&sessionid=1681311138#rd)

事实证明，漏洞是2019年的主要安全趋势之一。尽管围绕漏洞管理进行了所有测试，警告和建议，但企业在查找和修补漏洞方面面临的挑战似乎不会很快消失。

行业研究表明，未修补的漏洞数量继续增加，指出由于人员配置问题，修补通常延迟12天，而ServiceNow调查的72％的安全专业人员表示，难以确定需要修补的优先级。

考虑到这一点，并强调未固定漏洞利用的风险，Infosecurity汇总了近年来全球企业面临的10个最臭名昭著，最麻烦和最具破坏性的漏洞的列表。

**1-MS17-010（永恒之蓝）**  
WannaCry和NotPetya是迄今为止有史以来最昂贵的攻击的一部分，它们均使用了永恒之蓝风格的攻击作为其有效载荷的一部分。  
资料来源：微软

**2-MS14-068**  
这可能使攻击者利用Microsoft Kerberos中的漏洞并提升非特权域用户帐户特权。  
资料来源：Rapid7

**3-CVE-2019-0708（BlueKeep）**  
尽管有多个警告，但直到2019年11月，才发现Bluekeep的第一个漏洞。据预测，广泛的利用可能是严重的。  
资料来源：Fortinet

**4-MS08-067（Conficker）**  
此Windows SMB漏洞已存在10年以上，并且在带有旧版设备的较旧网络中仍然可以看到。  
资料来源：SANS研究所

**5-MS01-023（Nimda）**  
Nimda是Microsoft IIS漏洞利用程序的软件包，在9/11攻击发生一周后发布。  
资料来源：微软

**6-Spectre / Meltdown**  
这些推测性执行错误是出乎意料的，并推动了硬件安全性的新领域，证明CPU安全性仍然很重要。  
来源：崩溃攻击

**7-CVE-2014-0160（Heartbleed）**  
Heartbleed是OpenSSL代码中的一个漏洞，用于处理TLS / DTLS的Heartbeat扩展。  
资料来源：Synopsys

**8-CVE-2008-1447（Kaminsky错误）**  
此DNS漏洞使攻击者能够将用户发送到恶意网站并冒充任何合法网站并窃取数据。  
资料来源：Duo Security

**9-CVE-2014-6271（Shellshock）**  
远程执行代码漏洞影响了Bash，并且如果成功利用此漏洞，攻击者可能会获得对目标计算机的控制。  
资料来源：赛门铁克

**10-MS02-039（SQL Slammer）**  
MS02-039在2003年1月25日至26日的周末遭到攻击，导致某些Internet主机上的服务被拒绝，并极大地降低了常规Internet流量。  
资料来源：ESET We Live Security
