### **2.kali下安装N卡驱动**

  

**0.2.0 首先更新kali**

apt-get update&& apt-get upgrade -y && apt-get dist-upgrade -y

 

**0.2.1 安装 Linux headers**

 

Install Linux headers as those will be requiredto build NVIDIADriver modules.

 

aptitude -rinstall linux-headers-$(uname -r)

 

**0.2.2 安装 NVIDIA kerel**

 

apt-get installnvidia-kernel-$(uname -r)

 

**0.2.3 安装NVIDIA Driver K ernel DKMS**

 

aptitude installnvidia-kernel-dkms

此时显示出两个弹出的窗口，第一个关于你安装完N卡驱动 nvidia-kernel-dkms 后重启时禁用kali原装的N卡驱动程序nouveau, 第二个关于 /etc/x11/ 文件夹中的xorg.conf的文件

 

**0.2.4 安装 xconfig NVIDIA driverapplication**

 

你需要创建一个新的xorg server 配置文件 xorg.conf或者修改已存在的 xorg.conf 以加载NVIDIADriver module  nvidia-xconfig 使它安装更快捷些

 

aptitude installnvidia-xconfig

 

**0.2.5 安装Generate Xorg server configuration file**

 

我们已经安装了nvidia-xconfig 执行以下命令 generatexorg serverconfiguration filie

 

nvidia-xconfig

 

将会重命名所有存在的 xorg.conf 并创建一个新的文件

 

**0.2.6 安装完成重启**

 

reboot

 

**0.2.7 确认你是否安装完成** 

 

首先检测系统是否使用了glx module

 

glxinfo | grep-I direct rendering

 

首先安装 mesa-utils 然后重新输入以上命令检查输出结果如下为安装完成。

![](../Images/54a9ee16907d601bb443d8a29518b977.png)

aptitude installmesa-utils

 

**0.2.7.0 检查NVIDIA Driver Module**

**检查NVIDIA module 是否加载**

 

lsmod | grepnvidia

 

**0.2.7.1 检查 open source nvidiadriver nouveaumodule**

**确定 open source nvidia driver nouveaumodule 没有被加载驶入以下命令**

 

lsmod | grepnouveau

 

如图所示不出先任何字符即为成功如果出现字符则表明安装出现问题。

![](../Images/977c3e1f73adea31765924d27360b433.png)

以上是本人安装的过程未出现问题不过一开始的时候出现了某个命令不存在的问题如果您也出现的话那就百度那个问题即可很好解决的就此kali下安装N卡驱动完成。

1.  3. 给kali安装金山WPS 办公工具
    

 

0.5.0下载金山WPS Linux版

http://community.wps.cn/download/

 

0.5.1把下载的安装包放到root文件夹下

 

0.5.2在安装之前，先准备libpng12-0。因为在安装的时候会提示libpng12-0的依赖关系。去https://packages.debian.org/zh-cn/wheezy/amd64/libpng12-0/download

去下载找到所在地区，例如：亚洲然后在下载依赖包下载完毕哦，依然复制到home文件夹

 

0.5.3安装libpng12-0。在home文件夹下，单击鼠右键，点击在此处打开终端，然后输入 

 

`**sudo apt install ./libpng12-0_1.2.49-1+deb7u2_amd64.deb**`

 

0.5.4此时再安装WPS。同样在home文件夹下，单击鼠右键，点击在此处打开终端，然后输入 

`**dpkg -i wps-office_10.1.0.5672~a21_i386.deb**`

其中，dpkg -i后面的，是你安装包的版本号，即安装包的名字，你可以点击重命名，然后整个复制安装包的名字，添加在dpkg -i后面，然后回车，就可以安装完毕。

 

安装完毕后，打开wps时，会提示缺少字体，访问我的百度网盘（ 链接：https://pan.baidu.com/s/1J4GgJmUZX8AHpx8888IPFw密码：yvqm），下载–解压，将解压出的wps-office文件夹复制到/usr/share/fonts/ 即可，运行wps发现提示没有了，可以正常使用了。
