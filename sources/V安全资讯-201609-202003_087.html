数据类型


数据类型     大小    用途             格式

INT           4      整数

FLOAT         4     单精度浮点数

DOUBLE        8     双精度浮点数

ENUM                单选:例如性别     ENUM('a','b','c')

SET                 多选              SET('1','2','3')

DATA          3     日期              YYYY-MM-DD

TIME          3     时间点或持续时间  HH:MM:SS

YEAR          1     年分值            YYYY

CHAR         0~255  定长字符串

VARCHAR      0~255  变长字符串

TEXT         0~65535 长文本数据


整数除了 INT 外，还有 TINYINT、SMALLINT、MEDIUMINT、BIGINT


CHAR 和 VARCHAR 的区别: CHAR 的长度是固定的，而 VARCHAR 的长度是可以变化的，

比如，存储字符串 “abc"，对于 CHAR(10)，表示存储的字符将占 10 个字节(包括 7 个空字符)，

而同样的 VARCHAR(12) 则只占用4个字节的长度，增加一个额外字节来存储字符串本身的长度，

12 只是最大值，当你存储的字符小于 12 时，按实际长度存储。


ENUM和SET的区别: ENUM 类型的数据的值，必须是定义时枚举的值的其中之一，即单选，而 SET 类型的值则可以多选。

默认值约束

默认值约束规定,当有DeFAULT约束的列，插入数据为空时,将使用默认值


唯一约束

唯一约束规定一张表中指定的一列的值必须不能有重复值,即这一列每个值都是唯一的


外键约束

外键既能确保数据完整性,也能表现表之类的关系

一个表可以有多个外键,每个外键必须参考另一个表的主键,被外键约束的列,取值必须在它参考的列中有对应值

非空约束 (NOT NULL),听名字就能理解，被非空约束的列，在插入值时必须非空

SELECT语句详解

基本的SELECT语句


SELECT语句的基本格式

SELECT 要查询的列名 FROM 表名字 WHERE 限制条件

如果需要查看表的所有内容则

SELECT * FROM 表名字 WHERE 限制条件


数字符号条件

例如:

SELECT name,age FROM employee WHERE age>25

或者

SELECT name,age,phone FROM employee WHERE name='Mary'


AND与OR


例如:

SELECT name,age FROM employee WHERE age<25 OR age>30

SELECT name,age FROM employee WHERE age<25 AND age>30



IN和NOT IN

在和不在的意思


例如:

SELECT name,age,phone,in_dpt FROM employee WHERE in_dpt IN ('dpt3,dpt4')


SELECT name,age,phone,in_dpt FROM employee WHERE in_dpt NOT IN ('dpt1','dpt3')

子查询


有时必须处理多个表才能获得所需的信息。例如：想要知道名为 "Tom" 的员工所在部门做了几个工程。员工信息储存在 employee 表中，但工程信息储存在project 表中。

对于这样的情况，我们可以用子查询：

SELECT of_dpt,COUNT(proj_name) AS count_project FROM project

WHERE of _dpt IN

(SELECT in_dpt FROM employee WHERE name='TOM');


连接查询 


在处理多个表时,子查询只有结果来自一个表才能适用.但是如果需要显示两个或多个表的数据就需要连接查询join操作

JOIN操作


SELECT id,name,peolpe_num

FROM employee,department

WHERE employee.in_dpt = department.dpt_name

ORDER BY id;  //这条语句查询出的是，各员工所在部门的人数，其中员工的 id 和 name 来自 employee 表，people_num 来自 department 表


另一种方式


JOIN ON操作


SELECT id,name,people_num

FROM employee JOIN deparment

ON employee.in_dpt = deparment.dpt_name

ORDER BY id;

其他基本操作


索引(类似于书的目录)

对一张表中的某个列建立索引

ALTER TABLE 表名字 ADD INDEX 索引名(列名);

或者

CREATE INDEX 索引名 ON 表名字 (列名);


例如

alter table employee add index idx_id (id);  #在employee表的id列建立名为idx_id的索引

create index idx_name on employee (name); #在employee表的name列建立名为idx_name的索引




运用SHOW INDEX查看索引


SHOW INDEX FROM 表名字 #查看表名字的新建索引


视图

创建视图的语句格式为:

CREATE VIEW 视图名(列a,列b,列c) AS SELECT 列1,列2,列3 FROM 表名字;


例如:

create view v_emp(v_name,v_age,v_phone) as select name,age,phone from employee;

select * from v_emp;
