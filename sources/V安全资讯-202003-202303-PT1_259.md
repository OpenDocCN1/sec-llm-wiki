# 铸网安利剑 护网络安全 助陇原发展 甘肃省第二届“陇警杯”网络安全技能大赛圆满收官

为坚决贯彻落实习近平总书记关于网络强国的重要论述，进一步深化“2021警电战略合作”，由甘肃省公安厅主办、国网甘肃省电力公司承办的第二届“陇警杯”网络安全技能大赛于5月15日在兰州圆满收官。此次大赛以“铸网安利剑、护网络安全、助陇原发展”为主题，是近年来甘肃省举办的最高水平、最大规模的网络安全赛事，旨在通过以赛代练、以战促训的方式，检验全省网络安全从业人员的发现预警能力和应急处置水平，选拔培养一批技能突出、攻防兼备的网络安全人才。

![](../Images/f51ca4a0cf62600d2eb24d0ec122d9b0.png)

![](../Images/843c3dc97a7595dbab95522799d842cc.png)

此次大赛是甘肃省公安厅与国网甘肃省电力公司强化警企合作、共建平安甘肃的又一务实举措，也是全省行业部门强化网络安全主体责任、共筑网络安全防线的一次有益尝试，来自全省党政机关、企事业单位、科研机构、高等院校和互联网企业的100支队伍300名选手参加了比赛，按照互联网企业专业组和党政机关学校等非专业进行分组竞技，在各自的AWD PLUS赛场中展开激烈角逐。经过一天的淋漓酣战，最终，党政机关及企事业单位组中，来自国网甘肃省电力公司电力科学研究院战队获得一等奖，来自甘肃省公安厅网安总队战队、兰州理工大学战队获得二等奖，来自甘肃电力科学研究院技术中心有限公司战队、兰州市公安局网安支队战队、国网甘肃信通公司（数据中心）战队获得三等奖。互联网企业组中，山石网科兰州分公司战队获得一等奖，甘肃瑞讯电子科技有限公司战队获得二等奖，甘肃天诚利信息技术工程有限公司战队获得三等奖。

![](../Images/9c4ca60f29446633caaf810c73e543fe.png)

![](../Images/9a3d56e35e4cd13241cdb912c5a2089b.png)

甘肃省副省长、省公安厅党委书记、厅长余建出席开幕仪式并宣布大赛开幕，中国工程院院士沈昌祥，公安部网络安全保卫局一级巡视员、副局长郭启全，分别围绕筑牢网络安全防线和应对网络安全威胁挑战作了专业、精彩的主题演讲。大赛还邀请了国家电网有限公司互联网部副主任樊涛，北京理工大学教授洪延青，全球能源互联网研究院副院长高昆仑，阿里云安全总监王昱等全国网络安全专家学者就态势感知、数据安全、人工智能等前沿技术进行了交流研讨。

![](../Images/7ebaec170523207de405885a6535b83c.png)

![](../Images/a7b9ef5306c6089c689b22b4a981c152.png)

没有网络安全就没有国家安全。此次大赛的成功举办，为全省网络安全人才提供了展示能力、竞技比拼和交流互动的舞台，进一步增强了行业部门、从业人员的网络安全意识和网络安全技能，必将极大地提升全省防范化解网络安全风险隐患能力水平，助力我省经济社会又好又快发展。
