# 涉案金额上亿！52人被抓！内江警方侦破一起特大网络赌博案

**2021年4月19日**

**随着52名嫌疑人陆续到案**

**一起涉案资金高达上亿元的**

**网络赌博案件宣布告破**

![](../Images/b6bb13e1c3d80047b4ef17fd83f362e9.png)

  

![](../Images/205fe225a560148263f34dcc4ec16ff5.png)

近日，在内江市公安局的统一领导指挥下，资中县公安局抽调160名精干警力成立专案组，集中攻克“3.25”特大网络赌博案。一个多月里，办案民警紧扣线索、缜密侦查，通过一遍又一遍的梳理案情，该犯罪团伙的组织架构和犯罪证据越来越清晰明确，收网时机也愈发成熟。

  

![](../Images/12f1aa8905b66979bced7a9230c19179.png)

  

4月17日，随着专案组负责人一声令下，办案民警分赴江苏、云南、重庆、四川成都等多个省市，累计跨越数万公里，经过彻夜摸排蹲守，办案民警将嫌疑人一网打尽。

  

![](../Images/0a65d64263d47e155f542d13c132e401.png)

  

此次收网行动，**共计抓捕犯罪嫌疑人52名，冻结涉案银行卡200余张，扣押电脑数十台，扣押车辆十余辆，暂扣赃款2000余万元。**至此，“3.25”特大网络赌博案宣布成功告破，一伙数十人的犯罪团伙被连根拔起。

  

![](../Images/c528cdec14c5ee50bd7dea7ac4134973.png)![](../Images/433b21583d634593ead9165cf727f852.png)

  

收网之后，办案民警开展了突击审讯，嫌疑人如实供述了犯罪事实。经查，**该犯罪团伙打着棋牌游戏的幌子，****实则通过一款名为“旋友圈”的APP平台聚众赌博，**赌博方式为“扯旋儿”，是一种常见于川渝地区的扑克牌游戏。

  

![](../Images/95629dc62625bc279dc3e3632feb6844.png)

  

平台招揽玩家注册加入APP平台，玩家在游戏过程中向平台付款上分，然后使用积分进行游戏；平台则会为玩家开设牌局，游戏结束后，系统会自动按比例抽成。

  

![](../Images/ffd6d32d5a804330d522d11eee8f52df.png)

  

这是一起典型的网络赌博犯罪，嫌疑人非法获利巨大，严重危害社会秩序，破坏安定团结，社会危害性极大。**目前，该案仍在进一步侦办中。**
