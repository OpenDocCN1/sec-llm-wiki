# Adobe解决了Adobe Creative Cloud App中的一个严重漏洞，该漏洞允许删除文件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MDQ1MzQ0NA==&mid=2247484844&idx=6&sn=6e6356cca5fbd83347dbc963d097eefa&chksm=ebb90d87dcce849139619228e3c0387933face8f725537f7bcfc268ec59a52f16f847962287f&scene=126&sessionid=1681311126#rd](http://mp.weixin.qq.com/s?__biz=MzI4MDQ1MzQ0NA==&mid=2247484844&idx=6&sn=6e6356cca5fbd83347dbc963d097eefa&chksm=ebb90d87dcce849139619228e3c0387933face8f725537f7bcfc268ec59a52f16f847962287f&scene=126&sessionid=1681311126#rd)

Adobe已修复其Creative Cloud桌面应用程序中的一个严重漏洞，攻击者可以利用该漏洞删除任意文件。

CreativeCloud汇集了20多种用于摄影，设计，视频，Web，UX等的桌面和移动应用程序和服务，现在您可以在iPad上使用Photoshop将创意带到新的地方，使用Fresco进行绘画和绘画，并为3D设计和AR。

  

“ Adobe已针对Windows发布了Adobe Creative Cloud Desktop应用程序的安全更新。此更新解决了一个严重漏洞。成功利用漏洞可能导致当前用户上下文中的任意文件删除。”

  

跟踪为CVE-2020-3808的严重漏洞是由华南理工大学的陆家栋和奇虎360核心安全部门的彭志向（@edwardzpeng）报告的一种使用时间（TOCTOU）竞赛情况。。

  

分配给该漏洞的优先级得分是2，这意味着该漏洞不容易利用，并且Adobe不会很快就观察到利用该问题的任何攻击。

  

该漏洞影响Windows版本的Creative Cloud桌面应用程序，Adobe Creative Cloud桌面应用程序5.1版解决了该漏洞。

  

Adobe并未透露有关该漏洞的技术细节，可喜的是该公司尚未意识到利用该漏洞的野外攻击。

  

上周，Adobe发布了一组带外软件更新，以解决其六个产品中的总共41个漏洞。

  

该漏洞影响以下产品：

  

*   *Genuine Integrity Service*
    
*   *Acrobat and Reader*
    
*   *Photoshop*
    
*   *Experience Manager*
    
*   *ColdFusion*
    
*   *Bridge*
    

  

在41个漏洞中，有29个漏洞的严重性被评为严重，其余11个漏洞的严重性被评为“严重”。
