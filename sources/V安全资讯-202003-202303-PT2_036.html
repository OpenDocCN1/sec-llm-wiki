Firefox 将要求输入 Windows 密码来与密码管理功能交互

原文：http://mp.weixin.qq.com/s?__biz=MzI4MDQ1MzQ0NA==&mid=2247484815&idx=3&sn=7a743c72e189882fb18e147a2c0d76b9&chksm=ebb90da4dcce84b2e00c24b20c4ed49ed18cebb74fdad5c77a3b32dce2dcdc3b0c215947fa8a&scene=126&sessionid=1681311126#rd

Mozilla 计划对 Windows 版 Firefox 上的密码管理系统进行改进，以更好地提升数据安全性。

Firefox 的密码管理功能用于保存用户的账户和密码，这些数据可从同一设备的其他浏览器导入，也可从不同设备上的 Firefox 浏览器中同步。

在更改后的新版本中，Firefox 密码管理器将要求用户输入 Windows 账户密码来执行进一步操作，例如查看密码或是删除密码记录等等。不过，仅当用户未在浏览器中设置主密码时，才会需要这样做。

用户也可选择设置 Firefox 主密码，通过主密码来执行密码管理的操作。从 Firefox 76 开始，Firefox 将通过与 Windows 账号交互来保护没有主密码的帐户密码。

Chrome 等浏览器一直在使用类似系统。与 Firefox 不同的是，Chrome 不支持设置主密码。

目前该功能已在 Firefox 76 Nightly 版本中可用。Firefox 会弹出一个要求输入 Windows 密码或 PIN 码的对话框，诸如显示密码、复制密码或编辑密码之类的请求都会产生提示。

根据 ghacks 的报道，现阶段每进行一次操作都会产生一次输入 Windows 密码要求。还不清楚 Firefox 是否会在后续改进，每个会话仅请求一次密码，或是在一定的时间限制内只请求一次密码，以省去用户来回输入密码的麻烦。
