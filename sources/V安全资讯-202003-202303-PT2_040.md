# 谷歌突然宣布彻底取消 I/O 开发者大会：安卓 11 正式版发布时间延迟！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MDQ1MzQ0NA==&mid=2247484798&idx=3&sn=751bdef2181c9ca993dd3571ee6bbdfb&chksm=ebb90d55dcce844323a661d31e9e9079587a65fb18f71f3824773260dab37290e5d52f27ae41&scene=126&sessionid=1681311130#rd](http://mp.weixin.qq.com/s?__biz=MzI4MDQ1MzQ0NA==&mid=2247484798&idx=3&sn=751bdef2181c9ca993dd3571ee6bbdfb&chksm=ebb90d55dcce844323a661d31e9e9079587a65fb18f71f3824773260dab37290e5d52f27ae41&scene=126&sessionid=1681311130#rd)

谷歌周五宣布彻底取消一年一度的 I/O 开发者大会，此前该公司在 3 月 3 日宣布，由于受到新冠病毒疫情的影响，将把 I/O 大会改为仅在线上举行，但现在线上大会也被取消了。

Facebook、微软和苹果公司也都已将各自的开发者大会转移到仅在线上举行，但谷歌是第一家彻底取消大会的公司。

谷歌发布 Twitter 消息称：" 出于对开发者、员工和当地社区健康和安全的考虑——以及旧金山湾区当地政府的‘就地避难’（shelter in place）要求——我们很遗憾地决定今年不会以任何形式举办 I/O 大会。目前，我们大家能做的最重要的事情是，集中注意力去帮助人们应对所有人都正面临的新挑战。我们将继续竭尽所能地帮助社区保持安全，继续发出通报并保持联系。我们将继续致力于通过开发者博客和社区论坛与你们分享 Android 更新。"  

![](../Images/d8c7adbc171aaa1a0610a190f0e56b7d.png)

谷歌通常会在 I/O 大会上推出软件更新，有时还会发布新的硬件产品。在去年的大会上，谷歌推出了 Android 和谷歌搜索（Google Search）软件更新，并发布了 Nest Hub Max 智能显示器以及 Google Pixel 3a 和 Pixel 3a XL 手机。今年的 I/O 大会原本预计将有数千人参加。

这场开发者大会最吸引人的地方是，谷歌会公布 Android 11，届时新系统的更多功能将跟大家见面，而在这之前他们已经送出了 Android 11 的预览版，发布会当天谷歌也会第一时间让更多的第三方机型升级更新至新系统。

Android 11 带来的新特性有：提供了针对挖孔和瀑布屏的 API，新增了悬浮聊天气泡功能，还添加了一次性的位置、麦克风和摄像头权限许可，而屏幕录像也重新出现在系统中，同时还有全新的 Motion Sense 手势，可以暂停音乐。

**Women in Cybersecurity**  -3月12日至3月14日，奥罗拉（科罗拉多州）-当前状态：已取消。**ICS West (trade show)** -拉斯维加斯3月17日至3月20日-当前状态：推迟到7月，新日期待定。 **Pwn2Own CanSecWest (hacking contest)**\-温哥华3月18日至3月20日-当前状态：可以选择远程参与。参加Pwn2Own黑客大赛的黑客可以参加，他们也可以要求组织者代表他们执行攻击。。**InsomniHack**\- 3月19日至3月20日，日内瓦-当前状态：推迟到6月4日至6月5日。**Black Hat Asia** -新加坡3月31日至4月3日-当前状态：推迟至9月29日-10月2日。**BSidesCharm**\- 4月4日至4月5日，巴尔的摩-当前状态：执行调整后的规则。远程发言人可以选择使用视频会议，而不必到现场参加会议。**Kaspersky's Security Analyst Summit** -4月6日至4月9日，巴塞罗那-当前状态：推迟至9月，确切日期待公布。**DEF CON China**\-北京 4月17日至4月19日-当前状态：已推迟，新日期尚未公布。Area41 -6月11日至6月12日，苏黎世-当前状态：推迟到明年2021年6月。另外已经被取消的知名科技会议包括移动网络大会、Facebook的F8开发者大会、IBM的Think 2020、Zoho的Zoholics和SXSW。选择虚拟化的会议包括Microsoft的WSL会议，NVIDIA的GTC，Adobe峰会，Atlassia峰会和Google Cloud Next。
