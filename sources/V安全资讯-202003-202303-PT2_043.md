# Google解决了Chrome中的多个严重漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MDQ1MzQ0NA==&mid=2247484798&idx=4&sn=1654b1053956ba291671b578161fe073&chksm=ebb90d55dcce84437670f636c48d0b44b0a7b57b7ea6c9bac9efb47429b5af3ce2a3e77c7cbb&scene=126&sessionid=1681311130#rd](http://mp.weixin.qq.com/s?__biz=MzI4MDQ1MzQ0NA==&mid=2247484798&idx=4&sn=1654b1053956ba291671b578161fe073&chksm=ebb90d55dcce84437670f636c48d0b44b0a7b57b7ea6c9bac9efb47429b5af3ce2a3e77c7cbb&scene=126&sessionid=1681311130#rd)

谷歌发布了安全更新，以解决Chrome中的多个高严重性漏洞。这家科技巨头还宣布暂停流行浏览器的即将发布。

  

Google宣布由于当前的COVID-19爆发而暂停了即将发布的Chrome和Chrome操作系统。

  

“由于目前工作时间已调整，我们正在暂停即将推出的Chrome和Chrome OS版本。”

  

“我们的主要目标是确保它们继续稳定，安全以及对依赖它们的任何人可靠地工作。我们将继续优先考虑与安全相关的所有更新，这些更新将包含在Chrome 80中。”

  

Google解决了13个安全漏洞，其中最严重的漏洞被追踪为CVE-2020-6422，是一个影响WebGL的免费使用后问题。该漏洞是由David Manouchehri发现的，该漏洞作为公司的漏洞赏金计划的一部分，获得了8,500美元的收入。

  

![](../Images/00049395f7bc5875d1dee75314cffd43.png)

  

Google还解决了另外两个漏洞，分别被称为CVE-2020-6424和CVE-2020-6425。这些缺陷是媒体组件中的“事后使用”，并且扩展中的策略执行问题不足，这两个问题均由Google Project Zero的Sergei Glazunov报告。

  

Google还修复了音频组件中的四个After-after-free问题，跟踪为CVE-2020-6427，CVE-2020-6428，CVE-2020-6429和CVE-2020-6449。

  

该漏洞由Semmle安全研究团队的Man Yue Mo报告。

  

该IT公司还解决了usersctplib中的越界读取错误，该错误已跟踪为CVE-2019-20503。该漏洞由Google Project Zero的Natalie Silvanovich报告。

  

该更新还解决了V8中的一个不适当的实现，SeraphicAlgorithms的Avihay Cohen报告了CVE-2020-6426这个问题。
