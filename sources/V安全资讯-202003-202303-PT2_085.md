# BlackWater，一种使用Cloudflare Workers进行C2通信的恶意软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MDQ1MzQ0NA==&mid=2247484658&idx=4&sn=df00f8a67d6dfa8d9084151a6ee95bc6&chksm=ebb90cd9dcce85cfda6d445761429b7710fb98f3d138d38856d9a3067048d250628ab3e0a6f6&scene=126&sessionid=1681311130#rd](http://mp.weixin.qq.com/s?__biz=MzI4MDQ1MzQ0NA==&mid=2247484658&idx=4&sn=df00f8a67d6dfa8d9084151a6ee95bc6&chksm=ebb90cd9dcce85cfda6d445761429b7710fb98f3d138d38856d9a3067048d250628ab3e0a6f6&scene=126&sessionid=1681311130#rd)

专家发现一种名为BlackWater的新型后门恶意软件，假装在提供有关COVID-19爆发的信息的同时滥用Cloudflare Workers作为与C2服务器的接口。

  

Cloudflare Workers提供了无服务器执行环境，该环境允许用户创建全新的应用程序或扩展现有应用程序，而无需配置或维护基础架构。

  

Cloudflare Workers允许用户在Cloudflare的数据中心中运行JavaScript。用户可以使用Worker修改您网站的HTTP请求和响应，进行并行请求或从边缘生成响应。

  

MalwareHunterTeam的研究人员发现了一个名为“ COVID-19-”的可疑RAR文件，该文件可能是通过网络钓鱼电子邮件进行在线分发的。

  

![](../Images/2e1449a3782b1f38763cc8cfaf04f8b0.png)

RAR存档包含一个名为“重要– COVID-19”的文件，该文件显示一个Word图标。一旦打开，恶意代码会将Word文档提取到％UserProfile％\\ downloads文件夹中，该文件夹称为“重要– COVID-19.docx.docx”，并使用Microsoft Word打开它。

  

![](../Images/22ec39242094abca6766d09c292b3e3f.png)

  

Word doc是带有武器的文档，其中包含有关COVID-19病毒爆发的信息，它充当最终有效负载的投递器并执行该文件。

  

执行后，BlackWater恶意软件将连接到充当命令和控制服务器的Cloudflare Worker。

  

“在这里，事情变得有点有趣，因为该恶意软件随后使用命令行启动，该命令行导致BlackWater恶意软件连接到Cloudflare Worker，后者充当命令和控制服务器或至少是到服务器的传递。” 

  

恶意软件用来联系C2的命令。

  

sqltuner\[.\]exe lively-dream-c871.m7.workers.dev  

  

受欢迎的恶意软件研究人员Vitali Kremez说，被恶意软件联系的工作人员是ReactJS Stapi App的前端，该程序用作命令和控制服务器。

  

该恶意软件连接了工作程序，该工作程序反过来以可能包含命令的JSON编码字符串进行响应。

  

据专家称，该恶意软件正在积极开发中。

  

Cloudflare Worker的使用代表了威胁领域的新颖性，这是一种设计选择，可以使BlackWater避免进行检测。将Cloud Workers用作命令和控制的另一个优点是可以轻松扩展恶意软件攻击。

  

“我认为这就是为什么他们使用它返回合法的Cloudflare代理IP的原因，该代理IP充当将流量传递到C2的反向代理。考虑到它是Cloudflare（除非禁止整个Cloudflare工作者空间）基础架构，而隐藏了实际的C2，这使得阻止IP流量成为不可能。
