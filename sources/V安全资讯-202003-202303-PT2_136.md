# 美国官员指控两名中国男子为朝鲜洗钱

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MDQ1MzQ0NA==&mid=2247484453&idx=5&sn=4513e892fbd7d5ba7c3e57fc88ef947a&chksm=ebb90c0edcce8518eba114fe85cc7a3a3f367328c5debe792f83ff0a851a1b79f04f7572335f&scene=126&sessionid=1681311134#rd](http://mp.weixin.qq.com/s?__biz=MzI4MDQ1MzQ0NA==&mid=2247484453&idx=5&sn=4513e892fbd7d5ba7c3e57fc88ef947a&chksm=ebb90c0edcce8518eba114fe85cc7a3a3f367328c5debe792f83ff0a851a1b79f04f7572335f&scene=126&sessionid=1681311134#rd)

美国司法部已指控两名中国公民为与朝鲜有关的APT团体洗钱。

  

美国财政部和司法部已实施制裁，并指控两名中国国民田寅寅和李家东为帮助与朝鲜有联系的黑客洗钱加密货币。

  

加密货币已被两个加密货币交易所的APT组盗用。

  

寅寅和李家栋帮助与朝鲜有联系的颇受欢迎的拉撒路APT小组洗劫了被盗资金。

  

“两名中国公民被控从黑客入侵加密货币交易所中洗出价值超过1亿美元的加密货币。资金在2018年被朝鲜演员偷走，正如今天也揭露的民事没收指控中所述。”

  

“在今天在哥伦比亚特区展开的两罪起诉中，田寅寅又名田寅音和李家东被控洗钱阴谋并经营无牌汇款业务。”

  

该组织被认为应对大规模的WannaCry勒索软件攻击，2016年的一系列SWIFTattacks以及Sony Pictures黑客事件负责。

卡巴斯基的研究人员分析了与朝鲜有联系的Lazarus APT小组在过去18个月中进行的攻击，并证实了他们对银行和加密货币交易所的兴趣。

![](../Images/7064400802762f6682bae880dc933142.png)

在2018年中期，以APT为目标的加密货币交易所和加密货币公司，卡巴斯基实验室的专家追踪了一项名为AppleJeus行动的活动，旨在传播受污染的加密货币交易应用程序。

  

根据美国财政部和美国司法部的说法，与朝鲜有联系的黑客专注于加密货币交易，以筹集资金并绕开国际制裁。美国官员指出，由国家资助的黑客所进行的行动严重威胁着全球金融体系的安全与完整性。

  

借助加密货币计划以及中国银行和钱骡子网络的参与，从朝鲜获得了网络抢劫案中被盗的资金。

  

田和李在该计划中起着至关重要的作用，他们被指控洗劫了朝鲜收到的加密货币，并将其转换为中国法定货币（元）或可用于兑现这些钱的苹果礼品卡。

![](../Images/a874d430922c5e545d2578d504da9ad6.png)

根据美国财政部和司法部的说法，田和李至少在两起案件中从朝鲜控制的账户获得了资金。

  

被告从朝鲜控制的账户中收到了9,100万美元，这可以追溯到2018年的加密货币交易所黑客事件，另外还有950万美元来自另一家交易所。

  

“诉状进一步称，在2017年12月至2019年4月之间，银阴和嘉东洗钱了价值超过1亿美元的虚拟货币，这些货币主要来自虚拟货币兑换黑客。”继续新闻稿。“被告通过独立帐户和关联帐户进行操作，并提供虚拟货币传输服务，需要向客户收费。被告在美国经营业务，但从未在金融犯罪执法网络（FinCEN）中注册。“

  

根据检察官的说法，这对中国人帮助将他们收到的9100万美元中的3400万美元转换回人民币，然后将这笔钱存入了中国的银行帐户。

美国官员表示，这两人还将价值140万美元的比特币转换为苹果礼品卡，他们没有透露被黑客入侵的交易所的名称。

  

“由于采取了今天的行动，这些个人在美国或由美国拥有或控制的所有财产和财产权益必须被封锁并报告给OFAC。OFAC的法规通常禁止由美国人员或在美国境内进行的所有涉及被禁或指定人员财产或财产权益的交易（包括在美国境内进行的交易）。”

  

对中资银行没有限制。
