大概过了一下`main_Encode`可以发现两个很明显的字符串

```
 "12Nrst6CDquvG7BefghJKLMEFHPQZabRSTUVmyzno89ApwxWXYcdkij345"
"2LZd5FKvX1CRCX6TvAq7QN6FTwKa" #返回值
```

大佬们看到这里一般都已经可以解题了，没看出来的我们之后讲。

我愣是觉得是个加密算法，于是想着去跟了一下算法，首先是 IDA 中的代码，并不深：

![](../Images/9fd65177c307e09895ea3af9967a4a89.png)

可以看到一个明显的`while(1)`，和`v31 <= 0 break`，也是唯一的循环，那么此地八九不离十是个主要循环。

动态调试大体跟踪一下会发现：

*   每次通过`math_big__Int_DivMod`产生一个数值
    
*   ![](../Images/3562fc4ce41dfbaf263739896d8a17e4.png)
    
*   将数值作为索引，获取`那个密码表`中的字符，此处取了`0x37`位置![](../Images/5cebef61662c32d4e856405b336f26c4.png)
    
*   循环28次，获得0x1C(28)长度的加密字符串。
    

而`math_big__Int_DivMod`从名字可以看出来应该是个大数取模类似的，大数取模多半外部是通过字符串传入的。而`String`结构，多半第二个第三个指针指向字符串本身(第一个可能是回环指针，第二个可能是长度啥的)

来到`math_big__Int_DivMod`下断点，栈和内存大概是这样的。![](../Images/9db5d97a2cfd7b8915896a1bf9974cd1.png)

前三个参数的显然是个指针，指向的空间结构十分相同，上面两个指针，下面两个数字，看着好像不是标准字符串结构。但是找到了字符串位于第二个指针即止。

取模总归是两个数，第一第二个相同，所以我觉得应该是第二个第三个是取模的两数

第一第二个指针指向的字符串为：`afdsadsafdfdsafsafds`，是我们后换位的![](../Images/fc5955c9a93949404d16c71924918779.png)

第三个指向的字符串为：`:` ( 0x3A )![](../Images/937c4888450d956d514d4a072a687905.png)

`math_big__Int_DivMod`第一次返回的数值为`0x37`，我们在换位后的字符串上下个硬件访问断点。

应该可以断在这个位置：![](../Images/a100ea4d15ebfe420df88cc562778f16.png)

这里需要标注一些关注点：

*   当前语句为`DIV R9` ，那么应该是`RDX:RAX / R9` -> `AX存商/DX存余`
    
*   `RAX`的值为`0x73646661`是`afds`，头尾都有，但是看代码`R8+RBX*8`，此时`R8`是字符串首，`RBX`为`2`那么这样看的话应该是以8个字符分割，现在用的是最后一段。
    
*   除完以后`RAX`为`0x1FD5136`而`RDX`为0x25
    
    ![](../Images/b1fe9114c7dbf94315fba501884dff1f.png)
    

接下去发现并未结束，程序将商又放了回去，然后再次`DIV R9`![](../Images/2f12fcaeb7a23f01f9bb3e5b341fbd96.png)

但是这次`DIV`并没有那么简单，因为`RDX`储存了上一次除法的到的余数。所以虽然`RAX`是倒数第二段字符串，但是实际上被除数为：`0X257366617364666466`，也就是上一次的商拼接当前数。

因为字符串长度可以被8分为3段，所以这个操作总共进行了3次，最后一次的结果为：![](../Images/2be9df6a1d5301743bc42e66267ca748.png)

很巧，这一次的余数正好是`0x37`也就是第一个返回值。

```
import re  def ExchangeLetters(inputStr:str)->str:     outList = re.findall(r'\w{5}', inputStr)     return outList[-1] + outList[3] + outList[2] + outList[1]  def Flip(inputStr:str)->str:     return inputStr[::-1]  def getAsciiListNumberValueStr(asciiList:list)->list:     retString = []     for index in range(len(asciiList)):         retString.append(hex(ord(asciiList[index])).replace('0x',''))     return retString[::-1]  def DivMod(x:list)->(int,int):     """    使用list计算并    返回divmod()的list(hex())结果    """     divisor = 0x3A     divi = str(x).replace('[','').replace("'",'').replace(',','').replace('0x','').replace(']','').replace(' ','')     res, mod = divmod(int(divi,16), divisor)     res = str(hex(res)).replace('0x','')     # 补零判断     if len(res) % 2 != 0:         res = '0'+res     # 转列表     res = re.findall(r'\w{2}',res)     return res, hex(mod)  def getDivMod(inputStr:str):     """    单轮算法并返回结果    :param inputStr:被除数    :return:计算后数值，返回值    """     # 切分成三个单位     lastOne = getAsciiListNumberValueStr(list(inputStr)[-4:])     midOne = getAsciiListNumberValueStr(list(inputStr)[8:-4])     firstOne = getAsciiListNumberValueStr(list(inputStr)[:8])      while True:         # 对最后一个单位取余         lastOne,mod = DivMod(lastOne)          # 对第二个单位取余         tempList = midOne         tempList.insert(0,mod.replace('0x',''))         midOne,mod = DivMod(tempList)          # 对第一个单位取余         tempList = firstOne         tempList.insert(0,mod.replace('0x',''))         firstOne,mod = DivMod(tempList)         yield int(mod,16)   if __name__ == '__main__':     input = 'asdfasdfasdfasdfasdf'     res = ExchangeLetters(input)     res = Flip(res)     selectList = []     stringList = []     passwdList = "12Nrst6CDquvG7BefghJKLMEFHPQZabRSTUVmyzno89ApwxWXYcdkij345"     for one in getDivMod(res):         selectList.append(one)         stringList.append(passwdList[one])         if len(stringList)==0x1c:             break     print(''.join(stringList[::-1]))     print()
```

看了一下，我的天这大数取余好像有点麻烦啊，百度了一下，于是看到了一个东西叫**`Base58`**![](../Images/8c082586657fe32d7a13daa93b8abb5e.png)

## 别来了求求了

没错，逆了一个正向**Base58**出来。真不错。

而FLAG则当然在底部报假警后的判断中：![](../Images/e56a56468c5ae4389ef3174bd2ae2c3c.png)`2GVdudkYo2CBXoQii7gfpkjTc4gT`

所以实际上原题解法只需要短短几行Python代码即可：

*   
*   
*   
*   
*   
*   

```
 import base58 alphabet = "12Nrst6CDquvG7BefghJKLMEFHPQZabRSTUVmyzno89ApwxWXYcdkij345" oldAb = "123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz" code = "2GVdudkYo2CBXoQii7gfpkjTc4gT" trans = string.maketrans(alphabet,oldAB) print(base58.b58decode(code.translate(trans)))
```
