一、软件介绍

        R3con1z3r是一个被动的侦察工具，内置的功能包括:HTTP报头标志，Traceroute, Whois足迹，DNS信息，同一服务器上的站点，Nmap端口扫描，反向目标和网页上的超链接。在提供了必要的输入之后，该工具会生成HTML格式的输出。


二、下载地址(软件作者)

https://github.com/abdulgaphy/r3con1z3r


三、使用方法

1、直接使用pip安装

pip install r3con1z3r

2、输入目标地址

r3con1z3r -d google.com

3、打开桌面生成的html文件(部分内容)
