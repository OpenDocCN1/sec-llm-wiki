一、软件介绍

Dirsearch是一种命令行工具，可以强制获取web服务器中的目录和文件。


二、下载地址

git clone https://github.com/maurosoria/dirsearch.git


三、使用方法

1、安装所需要的库文件

pip3 install -r requirements.txt

2、输入目标地址

python3 dirsearch.py -u 192.168.1.107

3、查看扫描结果
