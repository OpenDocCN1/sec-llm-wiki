一、软件介绍

主要动能：子域名、屏幕截图、端口扫描、JS文件收集、子域的httpx状态码、目录扫描

  

二、下载地址

https://github.com/0xdekster/ReconNote

  

三、安装docker环境

1、更新APT索引包

sudo apt\-get update

![](../Images/40b3f82589cecd97b699423187fea2f2.png)

2、安装 apt 依赖包，用于通过HTTPS来获取仓库

*   
*   
*   
*   
*   
*   

```
sudo apt-get install \    apt-transport-https \    ca-certificates \    curl \    gnupg-agent \    software-properties-common
```

![](../Images/0b388f4bf997eadb50e60657058ba5c5.png)

3、添加 Docker 的官方 GPG 密钥并通过搜索指纹的后8个字符，验证您现在是否拥有带有指纹的密钥

*   
*   

```
curl -fsSL https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu/gpg | sudo apt-key add -sudo apt-key fingerprint 0EBFCD88
```

  

![](../Images/b17c740d24e2ea8608115b9df9e45105.png)

4、设置稳定版仓库

*   
*   
*   
*   

```
sudo add-apt-repository \   "deb [arch=amd64] https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu/ \  $(lsb_release -cs) \  stable"
```

  

![](../Images/f1218e4da2b035012f98ff2e1efd0b72.png)

5、添加仓库后，更新apt源索引

sudo apt-get update

![](../Images/f927e7ddd4fc66869909c5c169ab6ec9.png)

6、安装最新版本的docker ce和containerd

sudo apt-get install docker-ce docker-ce-cli containerd.io

![](../Images/c5f77a35f805636e6e837d7fbae97c4b.png)

7、验证是否安装成功

docker --version

sudo docker run hello-world

![](../Images/5aadad8a2e4a797ac8422f52ee5ef061.png)
