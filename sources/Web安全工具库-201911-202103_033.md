一、下载 Metasploitable3

下载地址：https://github.com/rapid7/metasploitable3

![](../Images/21b1a83301d9aad951f8b82000f3e6e5.png)

  

二、下载Packer

下载地址：https://www.packer.io/downloads

![](../Images/3f669e81d67f8072cf5e6571942d8a6c.png)

  

三、下载vagrant

下载地址：https://releases.hashicorp.com/vagrant/2.2.14/

![](../Images/831a007e35d770371b6a4501eaab8529.png)

  

四、安装Vagrant Reload插件

vagrant plugin install vagrant-reload

![](../Images/dbafd3c11f00df9065b69b7ccda17271.png)

  

五、修改下载地址为本地

复制这个地址下载，然后将下载好的iso文件放到iso文件

![](../Images/56ce2157531a619190c8e0c21dad40e2.png)

修改后的地址

![](../Images/621a4e9e9d7973293d63b7457123abe3.png)

  

六、执行下面的命令

packer build --only=vmware-iso ./packer/templates/windows\_2008\_r2.json

![](../Images/ee5aa528c15e2799c2918f2f0ba3e759.png)

  

七、该脚本会自动打开VM，自动安装系统

![](../Images/43111d0aaf2b06ab27edfd449028950b.png)

![](../Images/731817141b6a4aaadbc2975835c9cf48.png)

![](../Images/e0681dbee7e23133babd816908629e3c.png)

  

八、相应的文件介绍

resources：此文件夹包含特定漏洞或配置可能需要的任何其他文件。每个漏洞或配置都应拥有自己的文件夹。

scripts/chocolatey\_installs：这里的所有脚本都专门使用Chocolatey执行应用程序的安装。

scripts/configs：任何用于调整基本OS设置配置的脚本都在此处

scripts/installs：任何安装或配置第三方应用程序的脚本都在此处
