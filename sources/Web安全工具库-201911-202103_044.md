一、简介

快速生成免杀exe可执行文件，目前拥有三种免杀的方法

  

二、下载及安装

1、下载到本地

git clone https://github.com/lengjibo/FourEye.git

![](../Images/e07196f7a758f7e5f4f2235b41994f00.png)

2、进入该文件夹

cd   FourEye

![](../Images/41492d1bcf305100f4bcd42def5034d1.png)

3、安装需要的python库

pip install -r requirements.txt

![](../Images/47239f6b74c686c321c540a05697fb13.png)

  

三、使用方法

1、打开该软件

python3 BypassFramework.py

![](../Images/d03f77f1153bf9499e78af300fbd3dbe.png)

2、显示可生成的软件，list

![](../Images/4c7ececefaa26587703d4439cb158558.png)

3、选择shellcode，显示可选择的免杀方式

![](../Images/3e940e7d223648e037e917af379ecc23.png)

4、选择fibers免杀方式，加密方式选择xor，输入shellcode，选择平台的位数，execute运行

![](../Images/c8ecfbddb9eabeda6d5fb1a8a9cc4332.png)

![](../Images/810858f650eae70e8eebd4ec2ad2cbca.png)

apt-get install gcc-mingw-w64-x86-64 g++-mingw-w64-x86-64 wine64
