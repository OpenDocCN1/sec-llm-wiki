一、安装docker

1、sudo apt install docker.io

![](../Images/74468d03ae839594d3975fd0905108cd.png)

2、查看docker版本，如果显示则说明安装成功

docker -v

![](../Images/23e52d356e9bf85b588e150888ebb2a5.png)

二、安装docker-compose

sudo apt install docker-compose

![](../Images/06a72227e70ff01e7ecd1f1b8b737b9e.png)

2、查看版本,确认是否安装成功

docker-compose version

![](../Images/8a6e3bd5466d5861cb3a9397de185366.png)

  

  

三、下载靶场

1、git clone https://github.com/vulhub/vulhub.git

![](../Images/2a9ba050fab38e5607e33a8403d749ad.png)

2、查看都有哪些靶场

![](../Images/a96f8a6f91aee65166d8459cd7527468.png)

  

  

四、部署Jboss未授权访问漏洞环境

1、进入jboss，CVE-2017-7504文件夹

![](../Images/a06614c3a228603498253d8415ef8ad3.png)

  

2、启动该环境，第一次启动可能会慢点

docker-compose up -d

![](../Images/cad759f796060219661e752e9d6ee682.png)

  

3、访问该主机ip:8080进入漏洞环境

![](../Images/dac26a2bccb003c9133044427403f1e6.png)

  

4、后续清理工作

开启下一个靶场之前之前，要先关闭一下

sudo docker-compose down 

清理环境

docker rm $(docker ps -a -p) 

  

  

禁止非法，后果自负
