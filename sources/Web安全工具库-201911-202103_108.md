## 安装  

下载完成后，不出意外会得到一个主程序脚本`acunetix_trial.sh`，和一个破姐所需的程序`patch_awvs*`。

给安装脚本一定的权限

```
chmod 755 ./acunetix_trial.sh
```

以管理员权限运行安装脚本

```
sudo ./acunetix_trial.sh
```

然后会提示你输入主机名、邮箱、密码

1.  主机名：这个我选的默认的
    
2.  邮 箱：这个注意，不一定非要用一个真的邮箱，比如123@123.com都是可以的
    
3.  密 码：密码的规则是`数字、小写字母、大写字母、符号`包含3个或以上。
    

然后会提醒你访问网址：

`Please visit https://g:13443/ to access Acunetix UI`

也就是本机的13443端口，我试试！

`https://g:13443/`

![](../Images/2a3faf206ae190858f4181f837c5ca66.png)

`https://127.0.0.1:13443/`

![](../Images/ec9b91faccc523a1cce7b5e1af257c9f.png)

这两种访问方式都是可以的。

另外就是说，我这是Ubuntu端搭好了，只要是能ping通我这台主机的，也都是可以访问的，不管是Windows还是Linux。

所以可以在云服务器上搭，不过注意带宽！  

这里用虚拟机模拟一下，比如我物理机的IP是`192.168.0.8`，然后我去虚拟机中访问`https://192.168.0.8:13443/`.是可以使用我本机的这个服务的，能懂我意思吧，好兄弟们~

另外就是，这个脚本运行之后，会新建一个名字叫做`acunetix`的普通用户

```

d@g:~$ cat /etc/passwd |grep acunetix
```

明白这一点对接下来的破姐以及卸载可能会有些帮助。

## 破姐

我们这样装完确实是可以用了，但是，好像是只能用10次8次左右。所以...

停掉这个服务先

```
systemctl stop acunetix_trial.service
```

然后把那个破姐程序移动，执行这条命令即可

```
sudo cp patch_awvs /home/acunetix/.acunetix_trial/v_190325161/scanner/
```

执行

```

cd /home/acunetix/.acunetix_trial/v_190325161/scanner/
```

执行成功是这样的

```















d@g:/home/acunetix/.acunetix_trial/v_190325161/scanner$ sudo ./patch_awvs
```

然后再启动服务

```
systemctl start acunetix_trial.service
```

这下就可以了

## 卸载

进入`/home/acunetix/.acunetix_trial/`执行卸载脚本即可

```

cd
```

具体过程是这样的

```















d@g:~$ sudo /home/acunetix/.acunetix_trial/uninstall.sh
```
