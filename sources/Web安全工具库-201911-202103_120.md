\----  网易云热评

一、MSF更新

1、apt-get update

2、apt-get install metasploit-framework

  

二、敏感目录收集

1、查找dir\_scanner模块

search dir\_scanner type:auxiliary

2、选择扫描用到的辅助模块

use 0或者use auxiliary/scanner/http/dir\_scanner

![](../Images/8f1818ee96865b75e0c4906ba6379847.png)

3、查看需要设置的参数

show options

![](../Images/1468f6ce5f836724a8d16b5f81fad5ff.png)

4、设置目标主机

set RHOSTS 192.168.1.

5、设置端口

set RPORT 8003

6、设置线程数

set THREADS 50

7、运行，run

![](../Images/81ec51a508a1cb6fd1453cffb5f14534.png)

8、扫描结果

![](../Images/6b2086448339aa7d49462be16cb6151e.png)

9、字典目录，可以添加自己的字典

![](../Images/ae746cd1555d8c4b21d315837a56f996.png)

  

三、主机发现

1、可以利用的扫描模块

auxiliary/scanner/discovery/arp\_sweep

auxiliary/scanner/discovery/empty\_udp

auxiliary/scanner/discovery/ipv6\_multicast\_ping 

auxiliary/scanner/discovery/ipv6\_neighbor 

auxiliary/scanner/discovery/ipv6\_neighbor\_router\_advertisement

auxiliary/scanner/discovery/udp\_probe

auxiliary/scanner/discovery/udp\_sweep       

2、以arp扫描为例，查看需要设置的选项

show options

![](../Images/260f66957606198347b7d518e5d690f3.png)

3、设置主机范围

set rhosts 192.168.1.0/24

4、设置扫描时候的线程数

set threads 50

5、运行run

![](../Images/bae39324bd2582b1c9f9b61c493b22a0.png)

  

四、端口扫描

1、可以利用的模块

auxiliary/scanner/portscan/ack  

auxiliary/scanner/portscan/ftpbounce   

auxiliary/scanner/portscan/syn 

auxiliary/scanner/portscan/tcp

auxiliary/scanner/portscan/xmas 

2、以syn扫描为例，查看需要设置的参数

![](../Images/f89d0e91f74100e64c5c357c9383b65e.png)

3、设置目标ip

set rhosts 192.168.1.135

4、设置线程数

set threads 50

5、运行，run

![](../Images/758629ea2a4c6bbe245921b277cc9fc3.png)

  

五、获取服务详细信息

nmap -sS -Pn 192.168.1.135 -sV

![](../Images/570c1946bce51d07ad48b5e89527c9d1.png)

  

六、查找具体开放某服务的主机

1、开放telnet服务的主机

选择模块：use auxiliary/scanner/telnet/telnet\_version

设置ip范围：set rhosts 192.168.1.0/24

设置线程：set threads 100

运行：run

![](../Images/71375e836ba05f280d3e8194b7cbd6e9.png)

2、开放SSH服务的主机

选择模块：use auxiliary/scanner/ssh/ssh\_version

设置ip范围：set rhosts 192.168.1.0/24

设置线程：set threads 100

运行：run

![](../Images/c2e4c2809793b908ad6afd77ba43f4ab.png)
