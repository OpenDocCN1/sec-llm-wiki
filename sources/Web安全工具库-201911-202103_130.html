小攻：kali 2020.02 IP地址：

一、下载地址

https://github.com/xiaoheiwo/GGSCAN


二、安装过程

1、复制到本地安装包

git clone https://github.com/xiaoheiwo/GGSCAN.git

 

2、安装依赖

pip3 install -r requirments.txt


三、用法

1、单ip扫描

python3 gg.py -i 192.168.152.188

2、批量扫描

python3 gg.py -i 192.168.152.1/24

python3 gg.py ip.txt 

ip.txt里面  一个ip一行

3、结果会自动保存到/root/GGSCAN/out/
