今天给大家介绍一款探测工具：GGSCAN

小攻：kali 2020.02 IP地址：

小受：metasploit IP地址：

  

一、下载地址

https://github.com/xiaoheiwo/GGSCAN

  

二、安装过程

1、复制到本地安装包

git clone https://github.com/xiaoheiwo/GGSCAN.git

 ![](../Images/e27512d50d7a2381f98ddfa197d41106.png)

2、安装依赖

pip3 install -r requirments.txt

![](../Images/a34676fa419c2709a834a93ec7254e7d.png)

  

三、用法

1、单ip扫描

python3 gg.py -i 192.168.152.188

![](../Images/d7ed03dcc91a4935b49b055d2bcc8c26.png)

2、批量扫描

python3 gg.py -i 192.168.152.1/24

python3 gg.py ip.txt 

ip.txt里面  一个ip一行

3、结果会自动保存到/root/GGSCAN/out/

![](../Images/c02f9d7d497c43f03936415134fc634d.png)
