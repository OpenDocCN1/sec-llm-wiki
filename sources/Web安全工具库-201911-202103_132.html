小攻：win7  IP地址：192.168.1.129

小受：win2003  IP地址：192.168.1.130


一、图形界面登录(mstsc)

1、小受新建添加一个用户，net user aaa bbb /add

2、把新添加的用户再添加到远程桌面组，net localgroup "remote desktop users" aaa /add

3、小攻Win+R打开运行窗口，输入mstsc

4、输入小受的ip地址，然后输入刚创建的用户名和密码

5、成功登录


二、telnet命令登录

1、小受新建添加一个用户，net user bbb ccc /add

2、把新添加的用户再添加到telnetclients组，net localgroup telnetclients bbb /add

3、小攻win+R，打开运行命令窗口，输入services.msc

4、找到Telnet服务并开启

5、打开DOS窗口，输入telnet  192.168.1.130，选择继续

6、输入新添加的bbb用户，密码需要输入，但是看不见

7、成功登录
