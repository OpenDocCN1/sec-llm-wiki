一、AD的基础概念

1、 基于 Windows 的目录服务。Active Directory 存储有关网络上对象（计算机、用户、打印机）的信息，并让用户和网络管理员可以使用这些信息。Active Directory 允许网络用户使用单个登录进程来访问网络中任意位置的许可资源。它为网络管理员提供了直观的网络层次视图和对所有网络对象的单点管理。

2、DC主要工作就是认证用户，控制对象

3、域，域内所有的对象可以共享数据

  

二、域服务的添加参考下面的文章

域服务器ip地址：192.168.1.11

三、添加域成员

1、查看域服务器ip地址：192.168.1.11

![](../Images/9ee2ad3529c32c7d61ac7b36785e56f6.png)

2、将win2003的dns设置为192.168.1.11

在网络连接窗口中右击当前网络,属性===TCP协议，更改IP地址以及DNS服务器地址

![](../Images/b639d577aa7e96cff91cac9e9a1159e0.png)

3、右击计算机===系统保护===计算机名===更改，选择域并添加域名重新启动

![](../Images/a0667956833a6b30e5d7d9cf5e5dd973.png)

![](../Images/9001682a70e93e15b3043b9aff8f4872.png)

![](../Images/cc056beee202ae561e53429d13ab695e.png)

4、重启后，选择要登录的域

![](../Images/6befafcf9050ff9b14dc1a6125d67df2.png)

![](../Images/1c9e4c5911f9343d410813fa998e41c1.png)

5、在域服务器也可看到刚添加的域成员

![](../Images/b1b665ed6b6c36b774b1649184d0bfb4.png)
