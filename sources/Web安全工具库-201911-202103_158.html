<meta charset="utf-8"><?php$dbhost = 'localhost';  // mysql服务器主机地址$dbuser = 'root';            // mysql用户名$dbpass = 'root';          // mysql用户名密码$conn = mysqli_connect($dbhost, $dbuser, $dbpass);if(! $conn ){    die('连接失败' . mysqli_error());}echo '数据库连接成功！';mysqli_close($conn);?>

二、不同页面需要连接不同的数据库，为了避免代码的重复，我们新建一个connect.php,需要连接数据库的时候直接用一句话就可以调用

<meta charset="utf-8"><?php$dbhost = 'localhost';  // mysql服务器主机地址$dbuser = 'root';            // mysql用户名$dbpass = 'root';          // mysql用户名密码$conn = mysql_connect($dbhost, $dbuser, $dbpass);if(! $conn ){    die('连接失败' . mysqli_error());}mysql_select_db('jay',$conn);//选择我们要连接的数据库?>

三、注册页面，直接将注册信息添加到数据库中

<meta charset="utf-8"><?phpif(isset($_POST['submit'])){    $name=$_POST['user'];//获取表单里的用户名    $password=$_POST['pass1'];//获取表单里的密码    include('connect.php');//连接数据库    if(isset($_POST['user']) && isset($_POST['pass1']) && isset($_POST['pass2']))    {        $q="insert into user(name,pass) values ($name,md5($password))";//向数据库中添加数据        $res=mysql_query($q,$conn);//执行sql语句            echo "恭喜".$_POST['user']."注册成功";    }else{        echo "注册信息有误";    }}else{    echo "请通过表单提交";}?>

通过sql命令查看数据，数据已添加到数据中

四、登录页面，只有数据库存在的账户才能登录

<meta charset="utf-8"><?phpinclude("connect.php");//连接数据库$name=$_GET['user'];//获取表单里的用户名$password=md5($_GET['pass']);//获取表单里的密码echo $name,$password;if(isset($_GET['submit'])){    $sql="select * from user where name='$name' and pass='$password'";//检测数据是否存在    $res=mysql_query($sql);//执行sql语句    $row=mysql_num_rows($res);//返回结果中行的数量    if($row)    {        if(setcookie("name",$name)){            echo "登录成功，<a href='dlcg.php'>返回首页</a>";        }else{            echo "cookie设置失败";        }    }else{        echo "用户名或密码错误,<a href='../html/dl.html'>重新登录</a>";    }}else{    echo "请通过表单提交";}?>
