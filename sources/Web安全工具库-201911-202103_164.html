一、判断语句

if..else..<?php$a=10;if($a>10)  {  echo "a>10";}elseif($a=10){  echo "a=10";}else{  echo "a<10";}?>
switch<?php$a=12;switch ($a){case 11:    echo "a>10";  //如果$a=11    break; //跳出switch语句case 10: //如果$a=10    echo "a=10";    break;default: //其他情况    echo "我不知道该说什么";}?>

二、循环语句

while，输出1到9

<?php  //先判断再执行$a=1;while($a<10){    echo $a++."<br>";}?>
<?php  //先执行再判断$a=1;do{    echo $a."<br>";    $a++;}while($a<10)?>

for，输出1到9

<?phpfor($a=1;$a<10;$a++){    echo $a."<br>";}?>

三、跳出循环

break;  跳出本次循环

continue; 跳出当前循环语句，继续下次循环

exit; 跳出脚本

四、函数

加法运算，运行结果：4

<?php  //无返回值function aiyou($a,$b){    $c=$a+$b;    echo $c;}aiyou(1,3);?>
<?php //有返回值function aiyou($a,$b){    $c=$a+$b;    return $c;}echo "1+3=".aiyou(1,3);?>

五、作用域

局部变量：函数内部定义的变量

全局变量：函数外部定义的变量，global

静态变量：函数内部定义，static，仅在函数初次使用时初始化

六、函数参数

func_get_args();获取函数参数的一个数组

func_get_arg();获取参数内容，从下标0开始

func_num_args();获取参数数量

<?phpfunction aiyou(){    echo print_r(func_get_args());     echo "<br>";    for($a=0;$a<func_num_args();$a++){        echo func_get_arg($a)."----";    }}aiyou("Jay","等待下课","说好不哭");?>

运行结果：

Array ( [0] => Jay [1] => 等待下课 [2] => 说好不哭 ) 1Jay----等待下课----说好不哭----
