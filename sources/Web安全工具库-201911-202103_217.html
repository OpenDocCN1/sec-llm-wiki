----  网易云热评


1、列出所有任务及进程号：tasklist


2、查看网络连接状态：netstat -ano


3、利用管道符查找netstat -ano | find ".1"


4、查看本地网络信息：ipconfig

5、清屏：cls

6、打开远程连接mstsc

7、打开服务services.msc

8、注册表regedit

9、控制面板control


10、查看当前用户net user


11、添加用户及密码 net user a a /add

12、删除用户 net user admin /del
