一、基础命令

1、列出目录文件 ls

2、列出目录详细信息 ls -l

3、列出目录素有文件纤细信息 ls -alh

4、更换工作目录 cd

5、显示当前所在目录 pwd

二、创建、复制和删除目录

1、创建新目录  mkdir 目录名字

2、复制文件或者目录 cp -r 目标文件 目标地址

3、删除目录 rm -rf 文件名

新建一个456的文件夹，将1.txt文件复制到456文件夹中，然后再删除1.txt

三、移动与重命名文件

1、移动文件 mv 目标文件 目标地址

2、重命名文件 mv 目标文件 需要修改的名字

将1.txt文件移动到456文件夹，然后将1.txt文件重命名为3.txt

四、查看文件

1、查看文件           cat 文件名

2、查看文件头几行 head 文件名

3、查看文件后几行 tail文件名

4、反向查看            tac 文件名

五、查看与结束进程

1、查看进程 ps -aux | grep root

2、结束进程 kill 进程id

六、vim编辑器

1、vim 文件名   打开文件

2、i 插入模式

3、:wq  保存退出

七、添加或删除用户、组

useradd aaaa 添加用户

passwd aabb 设置密码

userdel -r 用户名 彻底删除用户名，包括家目录

groupadd 组名 添加组名

groupdel  组名  删除组名

cat /etc/group  查看组名

cat /etc/passwd  查看用户名

八、查看密码文件

1、查看用户密码：cat /etc/shadow

2、查看指定用户密码： cat /etc/shadow | grep 用户名

3、修改用户密码：passwd 用户名
