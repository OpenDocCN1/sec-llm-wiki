今天给大家推荐一款信息收集工具：FuzzScanner

一、环境：kali2020.01 python2

二、安装过程：

1、复制FuzzScanner到本地安装包

git clone https://github.com/TideSec/FuzzScanner.git

2、安装依赖包

pip install -r requirements.txt

三、命令

1、python FuzzScanner.py -hc target.com

设置单个目标网站，子域名枚举 && web指纹识别 && 目录枚举 && C段扫描

2、python FuzzScanner.py -Hc vuln_domains.txt

从文件读取单个或多个目标网站，子域名枚举 && web指纹识别 && 目录枚举 && C段扫描

3、python FuzzScanner.py -hca target.com

设置单个目标网站，子域名枚举 && web指纹识别 && 目录枚举 && C段全端口扫描

4、python FuzzScanner.py -Hca vuln_domains.txt

从文件读取单个或多个目标网站，子域名枚举 && web指纹识别 && 目录枚举 && C段全端口扫描

5、python FuzzScanner.py -h target.com

设置单个目标网站，子域名枚举 && web指纹识别 && 目录枚举

6、python FuzzScanner.py -H vuln_domains.txt

从文件读取单个或多个目标网站，子域名枚举 && web指纹识别 && 目录枚举

7、python FuzzScanner.py -c 192.168.1.1

设置单个IP，进行C段地址探测

8、python FuzzScanner.py -cd 192.168.1.1

设置单个IP，进行C段地址探测并对web服务进行目录枚举

9、python FuzzScanner.py -C vuln_ip.txt

从文件读取单个或多个目标IP地址，进行C段地址探测

10、python FuzzScanner.py -Cd vuln_ip.txt

从文件读取单个或多个目标IP地址，进行C段地址探测并对web服务进行目录枚举

11、python FuzzScanner.py -ca 192.168.1.1

设置单个IP，进行C段地址探测和全端口扫描

12、python FuzzScanner.py -Ca vuln_ip.txt

从文件读取单个或多个目标IP地址，进行C段地址探测和全端口扫描
