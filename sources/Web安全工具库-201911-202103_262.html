今天给大家介绍一款字典生成工具：pydictor

一、环境 kali2019.4 python3

二、安装过程：

复制到本地安装包

git clone https://github.com/LandGrey/pydictor.git

三、用法

1、python3 pydictor.py -base L --len 2 3 --encode b64

-base  L  类型为小写字母

--len 2 3    2-3个字母

--encode  b64  加密方式base64

2、字典去重

python3 pydictor.py -tool uniqifer 1.txt --output 2.txt
