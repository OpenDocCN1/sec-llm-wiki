今天给大家介绍一款子域名收集软件theHarvester


一、环境 kali2019.4 python3


二、安装过程：

1、复制到本地安装包

git clone https://github.com/laramies/theHarvester.git


2、安装依赖

pip3 install -r ./ext/requirements.txt

python3 domained.py --install


三、命令

python3 domained.py -d xxxx.com -b baidu

-d 指定目标

-b 指定搜索引擎
