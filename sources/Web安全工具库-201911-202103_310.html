今天给大家介绍一款子域名收集软件Sublist3r


下载地址：https://github.com/aboul3la/Sublist3r


一、环境 Kali2019.4 python3


二、安装过程：

1、下载到本地

git clone

https://github.com/aboul3la/Sublist3r.git



2、安装依赖

pip3 install -r requirements.txt


三、命令

python3 sublist3r.py -d baidu.com
