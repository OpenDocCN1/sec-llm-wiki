今天给大家介绍一款子域名收集软件subcollect

一、环境 kali2019.3 python3

  

二、安装过程：

  

1、复制到本地安装包

https://github.com/smelond/subcollect.git

  

2、安装依赖

pip3 install beautifulsoup4 

pip3 install requests 

pip3 install PyMySQL

  

3.修改配置

cd subcollect 

vim setting.py # 找到socks5修改为你自己的地址，或者将上面的socks5\_switch = True

修改为socks5\_switch = False

 

三、命令

python subcollect.py -u xxx.com 

等待获取结果...

cd output 

vim result\_xxx.com.txt

  

禁止非法，后果自负
