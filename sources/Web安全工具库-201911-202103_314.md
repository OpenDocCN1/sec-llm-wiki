今天给大家介绍一款子域名收集软件DiscoverSubdomain

下载地址：https://github.com/coco413/DiscoverSubdomain

  

一、环境 kali2019.3 python2

  

二、安装过程：

1、复制到本地安装包

https://github.com/coco413/DiscoverSubdomain.git

![](../Images/e68e173370e1c40aeca7f4973fe410e5.png)

  

2、安装依赖

pip install -r requirements.txt 

![](../Images/f0b729ff826490fbaf0de8bd07d18710.png)

 

三、命令

python2 DiscoverSubdomain.py -t 100 -f True -d xxx.com

禁止非法，后果自负
