今天给大家介绍一款子域名收集软件Aquatone

下载地址：https://github.com/michenriksen/aquatone

一、环境 kali2019.3 python3

二、安装过程：

1、复制到本地安装包

git clone https://github.com/michenriksen/aquatone.git



2、安装依赖

gem install aquatone


 

三、命令

子域名扫描：

aquatone-discover --domain xxx.com

端口扫描：

aquatone-scan --domain xxx.com

信息收集：

aquatone-gather --domain xxx.com

禁止非法，后果自负
