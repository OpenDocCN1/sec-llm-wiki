今天给大家介绍一款子域名收集软件Anubis

  

下载地址：https://github.com/jonluca/Anubis

  

一、环境 kali python3

  

二、安装过程：

1、复制到本地安装包

git clone https://github.com/jonluca/Anubis.git

2、进入该目录下

cd Anubis

3、安装以下文件

pip3 install  -r requirements.txt

pip3 install .

三、开始收集子域名

 命令：anubis -t XXX.com -o 123.txt

 -t 指定目标

 -o 把内容输出到123.txt这个文件里
