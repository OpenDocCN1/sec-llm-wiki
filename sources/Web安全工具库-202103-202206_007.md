# BurpSuite如何利用CSRF漏洞获取权限

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MDQ5MjY1Mg==&mid=2247499334&idx=1&sn=ef33c8aaa3ba4fee352bf965f3225df7&chksm=ebb51145dcc298532535a3a9f3783390f0b8b8b84eca296a13a2f4bf434c1f6206e3c6f6bb6e&scene=126&sessionid=1681670007#rd](http://mp.weixin.qq.com/s?__biz=MzI4MDQ5MjY1Mg==&mid=2247499334&idx=1&sn=ef33c8aaa3ba4fee352bf965f3225df7&chksm=ebb51145dcc298532535a3a9f3783390f0b8b8b84eca296a13a2f4bf434c1f6206e3c6f6bb6e&scene=126&sessionid=1681670007#rd)

假如已经拿到了一个网站后台，但是没有管理员的权限，可以利用此方法试一下。

  

一、进入网站后台，填写好要增加管理员的信息

![](../Images/db67f0f077fd97afcc07f7716022cbda.png)

![](../Images/8dab78e922e9eeb22a270cf95bc9050b.png)

二、打开BurpSuite，开启抓包，点击保存，找到我们提交的POST数据包

![](../Images/497c7f6061a598e683378af1007ca60b.png)

  

三、右击该数据包，选择Engagement tools--》Generate CSRF POC

![](../Images/1f4136b9a9575a13ee5ac4e2d4961dd6.png)

  

四、将我们提交的信息，构造成一个html网页，里面的内容可以适当的修改一下，然后点击Copy HTML，复制内容到一个任何人都可以访问的网站。

![](../Images/751995e0bede74ffe010da1b49d2ef7b.png)

  

五、我这里就放在了本地搭建的网站，重命名为aiyou.html，访问http://127.0.0.1/aiyou.html就能自动提交里面的内容，如果是外网就加上外网的ip，最好有自己的域名，让管理员看起来比较像正规的网站，因为，这个漏洞需要管理员去触发。

![](../Images/a50fbcca9762f4da9b8802551a1c19ad.png)

  

六、将BurpSuite抓的包丢弃，并关闭抓包功能，然后通过浏览器访问：127.0.0.1/aiyou.html，会收到这样一个返回信息。

![](../Images/6313cbfb2d124156720fec8bde24160c.png)

  

七、再次刷新管理员后台，发现新的管理员用户已被添加

![](../Images/5fec09860754a16dc156c507e6453712.png)
