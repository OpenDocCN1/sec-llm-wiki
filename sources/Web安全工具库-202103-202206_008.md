前言:没有Root用不了喔  
realme是oppo旗下的，本来只改了个realme的主题商店，但听说oppo也有很多机型能解锁root，又去网上找了个oppo主题商店的包想看一看，结果它的代码几乎和realme一样，说夸张点几乎只是包名的差别  
realme修改的关键地方是：

*   
*   
*   
*   
*   

```
Lcom/oppo/cdo/card/theme/dto/vip/VipUserDto;->getVipStatus()ILcom/oppo/cdo/card/theme/dto/vip/VipUserDto;->getVipDays()ILcom/oppo/cdo/theme/domain/dto/response/PublishProductItemDto;->getIsVipAvailable()I#其中getVipDays 可改可不改 改它就是消除一个今天VIP到期提示#getVipStatus,getIsVipAvailable赋值1，getVipDays就是会员天数嘛，随便赋值个正整数就ok
```

  
  
oppo的类和方法名也和realme一模一样，理论上来说realme有用也是对oppo有用的，但是我没oppo手机也没法测试，hhh（讲道理如果用不了才是真离谱）
