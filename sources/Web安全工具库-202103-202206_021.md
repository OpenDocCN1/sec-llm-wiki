一、工具简介

 一个简单易用的fofa客户端，由 WgpSec狼组安全团队 f1ashine 师傅主要开发。程序使用 JavaFX 编写，便于跨平台使用。本工具基于 FoFa 的 API 进行封装，使用时需要高级会员或者普通会员的 API key，使用注册用户的 API key 会提示账户需要充值F币。

```
1、多标签式查询结果展示2、丰富的右键菜单3、支持查询结果导出为excel文件4、支持手动修改查询最大条数，方便非高级会员使用(修改config.properties中的maxSize即可)5、支持证书转换 将证书序列填写入启动页框内可转换，再使用 cert="计算出来的值" 语法进行查询 具体例子6、支持输入智能提示7、支持fofa的一键排除干扰（蜜罐）功能。（注：需要高级会员，使用时会在tab页标记(*)）8、支持Fid查询（注：需要高级会员，查询时需要勾选）9、支持full查询(查询全部数据)10显示fofa官网的查询语法
```
