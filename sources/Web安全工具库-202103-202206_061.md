# Frida脱壳环境构建：获取root权限

使用Frida-Server脱壳必须要获取root权限，最近学习脱壳专门找了一台退役的手机（红米6，Android 9.0）做了测试，最后成功获取了root 权限。就目前来讲，小米系统的手机应该是最容易root的了，主要包含以下几个步骤：  
  
1\. 申请解BL锁    
  
在MIUI官网申请解锁（\[传送门\](http://www.miui.com/unlock/download.html)），按说明操作即可  

![](../Images/4339e3a7cf7dfa202a9255b814a5a9f0.png)

  
  
完成解锁后,在开发者选项查看设备解锁状态，显示设备已解锁  

![](../Images/55d07b588e3bcc6a7e9886f05be38608.png)

 

![](../Images/3d707ce3612154dbba24fc5a35280178.png)

  
  
2\. 刷入Twrp  
  
完成BL解锁后，下载需要root设备的twrp（\[传送门\](https://twrp.me/Devices/)），小米系统适配的应该是最多的。  

![](../Images/3a18876fce1e7bd0f722de6f605eda1c.png)

  
  
红米6我下载的这个对应的版本。  

![](../Images/45235320a5c4220da8a2c3d30f04228f.png)

  
  
下载Magisk，下载最新版即可（\[传送门\](https://github.com/topjohnwu/Magisk/releases/)）  

![](../Images/adbad10c4a45295b96aef0ce6b500a02.png)

  
  
  
下载完成后，把Magisk apk文件改成zip格式，放到手机存储根目录下，然后关闭手机，同时长按开机键和音量减键，进入fastboot。  

![](../Images/51cbcdb3e1e62049da980f2ea95d172e.png)

  
  
  
把下载的twrp文件放到fastboot工具目录下，我使用的是Android SDK platform-tools里面的fastboot工具。然后用数据线连接电脑，在当前目录命令行执行如下命令：  
  
  
fastboot flash recovery  twrp-3.6.1\_9-0-cereus.img  
  

![](../Images/4c03d87b85add61d5b1b14a63fb88f5c.png)

  
  
3\. 安装Magisk  
  
文件传输完成后，关机后长按音量加键进入twrp recovery，安装Magisk。  

![](../Images/f99ecce8b5acc5f312cdb9a29eb3986c.png)

 

![](../Images/4db6b252c09ea554c76356b409d1ec28.png)

 

![](../Images/dfcaba66d6e1915163a5b4f78cae81ca.png)

 

![](../Images/85e4f78378ca7cccceba029f95735583.png)

  
  
安装完成后重启手机  
  
4\. Root授权  
  
打开Magisk  

![](../Images/de58aee4deb0fccbfdce9849f020d881.png)

  
  
在命令行执行如下命令：  
  
adb shell  
  
su  
  

![](../Images/6904b791e8ee9dc7fd466792e2bd3f5f.png)

  
  
在手机端Magisk同意授权Shell root权限  

![](../Images/48675608d30cada6b7865bfd8748e0a2.png)

  
  
至此，root权限获取成功  

![](../Images/a4b81df699e94209104580ce54e42755.png)

 

![](../Images/4e4484ec1617d3f1fb45f8f894b8aa01.png)
