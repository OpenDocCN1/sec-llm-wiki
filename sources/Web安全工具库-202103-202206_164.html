一、过人 webshell 的生成工具

将 payload 放在 -pf 所指定的路径


二、hide webshell

python hide_webshell.py hide_webshell.py normal.php -pf payload.txt

三、hide webshell pro

python hide_webshell.py normal_pro.php -pf payload.txt --pro
