一、Nessus简介

Nessus号称是世界上最流行的漏洞扫描程序，全世界有超过75000个组织在使用它。该工具提供完整的电脑漏洞扫描服务，并随时更新其漏洞数据库。Nessus不同于传统的漏洞扫描软件，Nessus可同时在本机或远端上遥控，进行系统的漏洞分析扫描。Nessus也是渗透测试重要工具之一

三、更新

不同系统更新类似，这里简单说明Linux：

1、找到你Nessus安装目录下的nessuscli（Linux在目录 /opt/nessus/sbin/；windows默认在C:\Program Files\Tenable\Nessus）

2、停止nessus服务

sudo systemctl stop nessusd

3、更新插件包

sudo /opt/nessus/sbin/nessuscli update ./all-2.0_20220309.tar.gz   //注意更改自己放插件包的路径

4、更新成功会提示：

[info] Copying templates version 202203072104 to /opt/nessus/var/nessus/templates/tmp[info] Finished copying templates.[info] Moved new templates with version 202203072104 from plugins dir.

 * Update successful.  The changes will be automatically processed by Nessus.

5、启动Nessus服务

sudo systemctl start nessusd


注意：

切记更新前先停止服务，如果忘了导致后面404出错可停止服务后再重新导入插件包升级即可
