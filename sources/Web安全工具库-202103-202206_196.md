# 抓包神器 -- Ecapture(无需安装证书抓取https)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MDQ5MjY1Mg==&mid=2247495432&idx=1&sn=1078b79948fd93b59ac9dc26221fed57&chksm=ebb5000bdcc2891d619f628ed71be61ab7c7f695aac0e75a324ab1386f995693d734f8618fa3&scene=126&sessionid=1681670043#rd](http://mp.weixin.qq.com/s?__biz=MzI4MDQ5MjY1Mg==&mid=2247495432&idx=1&sn=1078b79948fd93b59ac9dc26221fed57&chksm=ebb5000bdcc2891d619f628ed71be61ab7c7f695aac0e75a324ab1386f995693d734f8618fa3&scene=126&sessionid=1681670043#rd)

Ecapture是一款无需CA证书，就可以进行HTTPS通讯明文抓包的工具。

一、下载地址

https://github.com/ehids/ecapture

  

二、安装环境

ubuntu 21.04， linux kernel 5.10以上通用。推荐使用UBUNTU 21.04版本的linux测试。

  

三、工具链版本

gcc 10.3.0

clang 12.0.0

cmake 3.18.4

clang backend: llvm 12.0.0

最低要求 (笔者未验证)

gcc 5.1 以上

clang 9

cmake 3.14

  

四、编译

git clone git@github.com:ehids/ecapture.git

cd ecapture

make

bin/ecapture

  

五、使用

https的无证书抓包 ssldump

执行任意https网络请求即可使用。

wget https://www.qq.com
