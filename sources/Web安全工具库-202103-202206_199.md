### 前言

遇到一个站，后端是Node.js写的，对于这种类型的站点，一般比较难getshell，但也实现了最终的目标，拿到后台权限

### 信息搜集

先进行常规的信息搜集，子域名扫描、端口扫描、目录扫描等  

![](../Images/ae884a69cb10de39f0c311c919f72fd8.png)

这个站后端脚本语言是Node.js  

![](../Images/c98d6a30d7445854854142cbf16bf711.png)

目录探测发现404界面也极像Node.js的404页面，后面重点关注js文件  

![](../Images/d24c651697dc4b001659cdec839a5be8.png)

### 突破接口  

在进行目录扫描的时候，发现了一个有用的目录：  

![](../Images/58e50b807eccade7dd9c2f4571ce34de.png)

前面说了，重点关注js文件，查看页面源代码，发现一个有趣的js文件，为什么说这个文件有趣呢？因为这个js的文件名和产品名一致

![](../Images/ba9c9e053bbf83aa066d2a045809033b.png)

进去之后发现了新世界

![](../Images/3f8f62f2c0bbd9760df4117f0d12acd0.png)

  
这个网站的前端界面都是通过在js文件里document.write函数构造

![](../Images/bdec8760a1b873cb40c8202979a4291b.png)

页面动态渲染的数据是通过js函数中ajax请求获取

![](../Images/e20a9ca7f6cc2196d812e2289d234cec.png)

```
$.ajax({
url: host + "/agent/getPlayerInfo",
type: "post",
dataType: 'json',
headers: {"content-type" : "application/json"},
data: JSON.stringify({"uid" : uid})
}).done(function(data){
console.log(data);

```

核心的所有功能接口都是未授权访问的，根据不同的js文件里的ajax请求，使用postman直接构造数据包，即可实现后台相对应的功能

![](../Images/5c6c6fedd077b015a9583a210205094f.png)

### 登陆后台

通过上述接口，可以通过用户的uid获取用户的用户名，将所有的用户名作为字典，放入burp爆破弱口令

![](../Images/f182b24472229f610492d6567cee8c0b.png)

![](../Images/ed179fc5f5a69534b6924d06ceacb6c6.png)

分析后台登陆包，密码被加密了  

![](../Images/ace80c2d21de30ace52325b73c5e5de3.png)

在js中找到加密方式，截取的是16位的md5  

![](../Images/8227f661a53e5a3d7238ba07efb7dab5.png)

根据js代码里的if逻辑可以很清楚的看到：返回包code值为101100是密码错误，200就是登陆成功，  

![](../Images/e6ef2899c163f9657a9080db9374767e.png)

成功爆破出多个用户存在弱口令  

密码错误：  

![](../Images/2e6aec36c2fa411f2298bdfb7e495da4.png)

密码正确：

![](../Images/2303f675eeaa2528060026d74b622f6f.png)

### 进入管理员后台

利用爆破的用户登陆后台，发现不是管理员权限  
![](../Images/687948e022b2975c63e23dbc3e061a98.png)但是继续阅读js代码，发现存在如下的代码：登陆成功后data.code == 200，再根据返回包的agentClass值，可以控制显示的是管理员界面还是客服界面还是一级、二级用户界面。由于是前端判断且通过document.write函数渲染界面，因此可以前端绕过，直接修改返回包中的agentClass值为管理员的值，就可以进入到管理员界面，且后端所有接口也都如上面一样不存在鉴权，因此管理员的后台所有功能都可以使用  
agentClass=1时：  

![](../Images/94db634f98c7e5acfbc46d69a4c79e22.png)

agentClass=2-4时：  
![](../Images/a1253980665575af53761c3920ea5851.png)那么只要修改返回包的agentClass=1即可  

![](../Images/0344f16b6e07d3173098efca4d188af0.png)

  
成功进入管理员后台  
![](../Images/6fedcaa1fad3f2a153ac6625c47de3b1.png)
