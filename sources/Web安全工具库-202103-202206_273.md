# 前言  

萌新，没发过帖子，看了Squirrels，newlifes，4nt*\*\**1130老哥的渗透帖子，也把自己的一次经历写成帖子以供大家参考。

# 过程&&细节

1.FoFa游荡时偶遇一棋牌后台，本着棋牌站人人得而诛之，搞一下。

![](../Images/0d0e345b93368a67220d7c8b332c37d6.png)

2.本能的用弱口令试一下，不出意料，失败~~~  

![](../Images/1926c41ae53ce83e660dd80118867534.png)

3.不死心，用burp测试一下top100，果不其然，再次失败~~~  

![](../Images/11052ad6e84904ceebb68593636ff16f.png)

4.没办法，只能继续分析分析，通常这种状况下，我都会用burpsuit爬虫一下，找找数据交互的地方fuzzing一下，当然，首先后台这种类型站最明显的交互就是登录了，很幸运的简单检测一下发现post请求中username字段是存在注入的，当逻辑为真的时候，回显:用户名或者密码错误,当逻辑为假时回显：账号不存在，经典的报错回显。  

```

真：userName=admin'AND 1=1 AND 't'='t&password=
```

![](../Images/e168fb5744cd8e6fe5abdcefa6840952.png)

![](../Images/f213db2ff971603ffb5f11458ce55aae.png)

  
5.当发现此处的注入，当然马上使用sqlmap来梭哈一下，把post请求包保存为txt，用sqlmap -r sql\_pointer.txt --random-agent先试试水，果然发现一堆注入。  

![](../Images/7d6f098cd62bd2e6991585d759203398.png)

6.再一看，竟然是Microsoft SQL Server 2014,心中有些小激动了，不会直接可以用xp\_cmdshell直接getshell吧？  

![](../Images/9703e97c969073b3c77564bdeddf443d.png)

7.说干就干，直接打开cs，先生成一个one-liner，复制一下链接。  

![](../Images/6f17601b7a40f32fbd2cd722fab28d8b.png)

8.再用sqlmap跑一下，加个参数--os-shell尝试获取一个交互，获取之后再把one-liner链接执行。  

![](../Images/9e2505bdc932d2261e7c2299e7cb1f95.png)

9.在静静等待几秒之后，cs上线成功！  

![](../Images/e40704d4da79b28a64012c0ab7abcb3c.png)

10.但是再看了一下，果不其然，也只是低权限的MSSQLSERVER，尝试了哈希转储和mimikatz，失败，本想查看远程文件，但是太慢了，等了几分钟也没刷出来dirvers，难道是网络太差？  

![](../Images/7de2ff9f4e5b3ffbbcb414557705932d.png)

  

11.使用CS默认的提权，果不其然，失败。

![](../Images/cf3b9ae14aae104dbc95ccdf513d41e0.png)

12.之后又尝试了烂土豆，bypassuac等等统统失败，心想老机子不该呀，而且进程列表也没法什么防护软件呀，终于用ms14-058成功提权，CS又获取到了一个system的session。  

![](../Images/f2390e5d97722870beb08d5c6ab57296.png)

![](../Images/328963f6465eef7b764a13f8a9f5be90.png)  

13.接下来就顺利了，mimikazt赶紧跑起来，成功获取账户和明文密码，这波爽歪歪。  

![](../Images/6dc3338ecb2496a43b890ced607cf9b2.png)

![](../Images/7a85b9a52857fc7810d10ecc7919075f.png)

14.之后再扫描一下端口，发现RDP端口设置在了高位：23389，再直接远程登录一下，果然发现了正在运行的赌博后台程序。

![](../Images/ed89932843a8ca8eef1af214a997b25f.png)

![](../Images/6c0df644e379f887ec0f735e3cff1a1c.png)

15.找一下后台文件夹在哪里，顺便放了一只哥斯拉马，顺利连接上。

![](../Images/592d972cc4ab0d69bbaca63b63ddeaa3.png)

![](../Images/43415ac16874090869b2ad66a417f000.png)

16.继续翻一番配置文件：web.config,果然发现了数据库配置信息和一堆其他的配置信息。

![](../Images/c77e1c1ce5cee7838e3598633ab445ed.png)

17.在哥斯拉中，用数据库账号密码本地链接一下试试，成功了，并找到了后台管理员账号密码，用nmap搜集信息的时候看了开放1433端口，貌似可以远程。

![](../Images/b3ae2a35e8ffa8d07efbdc39c6a4f35c.png)

18.在cmd5查一下明文密码，好像也是弱口令。

![](../Images/cc07c5893749788975f932f1471c6562.png)

19.获取到明文密码后，直接登录一下看看，发现只是个小站又或者测试站，测试信息不少，似乎也没什么人上当。  

![](../Images/a48c9bdccf89e22026cd60f59610f64a.png)

![](../Images/74ad076647dc24e7107a994d7b9acfaa.png)

20.搞完查了一下fofa，发现资产数量不少，应该是个比较流通的棋牌系统了，唉，骗子大行其道，可恶。

![](../Images/4a2bf3cf06348b9137b8338caff753b4.png)

21.清理一下登录信息，结束。  

# 总结

本次渗透比较顺利，都是些简单通用的思路：信息搜集(爬虫，namp，js接口之类)-->sql注入点（突破点）-->cs上线-->提权（权限提升）-->mimikatz（凭证访问）-->信息再搜集利用等等。希望对大家有些许助益，谢谢观看。
