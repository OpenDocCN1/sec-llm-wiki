一、分析apk的java层代码，发现调用了“wtf”这个so文件

*   
*   
*   
*   
*   
*   
*   
*   

```
package com.sichuanol.cbgc.util;public class SignManager {    static {        System.loadLibrary("wtf");    }    public static native String getSign(String arg0, String arg1, String arg2) {    }}
```

  

  

二、找到apk的libwtf.so文件，拖进IDA，出现has been finished，代表该so文件分析完毕

![](../Images/58be4d5c76e24de519bb097c70923da1.png)

  

三、查看导出文件，点击选项卡Exports，会看到一个带有getSign的名字，这是so层的命名规则，双击进入

![](../Images/563e1b9561335cc24fe7d10f1c17bc26.png)

  

四、进去后看到的是流程图，可以按空格键切换成汇编代码

![](../Images/613936a8c7385093ff19ffcc1167df2f.png)

![](../Images/833697bc52c10fd7c6c19825fe1ce55a.png)

  

五、汇编代码也看不懂，按F5可以切换到伪C代码

![](../Images/f6f9b37990978e5d5f4ce5606f78b79b.png)

  

六、右击代码选择Hide casts，可以隐藏那些看着比较乱的指针

![](../Images/b3fbb848fa6c7abec66fa5646d7be91f.png)

隐藏后

![](../Images/fd7dc712f8e29f95415e52738fb6b5e2.png)

  

七、加载jin.h文件帮助我们分析代码，点击File--Load file--Parse C header file

![](../Images/86b722dd3ceed33149b145d0364d39d3.png)

  

八、选择第一个参数，右击，选择Convert to struct \*，选择\_JNIEnv，点击OK

![](../Images/7cd45066b5a9d77e5b5b6544e1e87a46.png)

![](../Images/282348c660eab98af58d7dab9c6a28d7.png)

  

九、重新查看代码就比较清晰了，整个操作就是对字符串进行MD5加密

![](../Images/99f6541d9dd3a00ca899b77372749e87.png)

十、查看SO文件中存在的字符串，点击view--Open subviews--Strings

![](../Images/0a026e88fd478c3ee6d0c9139bde11ca.png)

![](../Images/a5209735b7a89122078d3e77f265033f.png)
