import java.security.MessageDigest;
String bs= "逆向有你a";MessageDigest md=MessageDigest.getInstance("MD5");//我要用md5算法md.update(bs.getBytes());//我要加密的数据byte[] res = md.digest();//给我加密System.out.println("MD5加密（字节）："+Arrays.toString(res));System.out.println("MD5加密（字符串）："+bytes2HexString(res));
MessageDigest mdmd = MessageDigest.getInstance("MD5");mdmd.update("逆向".getBytes(StandardCharsets.UTF_8));mdmd.update("有你".getBytes(StandardCharsets.UTF_8));byte[] mdmdres = mdmd.digest("a".getBytes(StandardCharsets.UTF_8));System.out.println(bytes2HexString(mdmdres));



三、分析要hook的地方

1、hook的类就是导入的包，即“java.security.MessageDigest”

2、update可以使用多次（如果hook这里会无限循环）， digest只能使用一次（这里是hook点）
