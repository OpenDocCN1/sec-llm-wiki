> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MDQ5MjY1Mg==&mid=2247490236&idx=1&sn=a81cc27124313efc5d263e9c5718feba&chksm=ebb6f5bfdcc17ca955f7743765c36270f0ffe6dc3a96372d21edb96ca8a13aa95ff8e30dc90f&scene=126&sessionid=1681670103#rd](http://mp.weixin.qq.com/s?__biz=MzI4MDQ5MjY1Mg==&mid=2247490236&idx=1&sn=a81cc27124313efc5d263e9c5718feba&chksm=ebb6f5bfdcc17ca955f7743765c36270f0ffe6dc3a96372d21edb96ca8a13aa95ff8e30dc90f&scene=126&sessionid=1681670103#rd)

一、下载地址（原作者）：

https://github.com/chroblert/WindowsVulnScan

二、使用方法

1、搜集目标主机上的漏洞，以管理员身份打开cmd，进入到windowsvulnscan目录

2、进入powershell

![](../Images/e7fb98d24ff916959b66f6609fc61a57.png)

3、设置可运行脚本，set-ExecutionPolicy RemoteSigned

4、运行KBCollect.ps1

![](../Images/37347057818241e35eaaa198151edd86.png)

5、生成kb.json文件，里面有我们的漏洞信息

6、安装一下所需要的库文件

pip install -r requirements.txt

![](../Images/dae3d2939b96fc3fbe785cdfc21cf349.png)

7、更新一下漏洞库

python3 cve-check.py -u  更新数据库

python3 cve-check.py -U 更新exp

![](../Images/c2906e82cd362f51be941f7dacef7ef3.png)

8、检测可利用的漏洞

python3 cve-check.py -C -f KB.json

![](../Images/940ca03fb7a9d0ef62799260efd9b0e7.png)
