# 安卓逆向 -- JEB3.7安装使用

JEB一款强大的安卓逆向分析工具，动态调试smali代码非常方便  

一、解压缩下载的原包，将里面的压缩包继续解压

![](../Images/5e4cb4799669f15cd2ddb7e2fe9ed480.png)

二、将jeb-demo../bin/app/文件里的jeb文件，替换一下

![](../Images/2250519bbc85fc5e941652714ab84d8e.png)

三、将Keygen.class文件复制到Keygen\_GUI里面

![](../Images/ec6f3810263715831765eec6faa2a85e.png)

四、打开终端，运行java Keygen，获取密钥

![](../Images/48722d0239630ea338d6f60358f952fb.png)

五、进入jeb\_demo..文件夹，给最高权限（windows系统可以省略这一步）

chmod 777 jeb\_linux.sh

六、运行./jeb\_linux.sh（windows系统，直接双击jeb\_wincon.bat文件即可）

![](../Images/3bc22b31a6eb882a8599f92d3dbc5e00.png)

七、点击Manual Key Generation，将上面的key复制进去，点击确定

![](../Images/9cd10d9f0157c3d108792eabebc81fba.png)

八、点击continue，成功打开破解以后jeb

![](../Images/f6d5f450be16ec6ce63d9c2bfd0ee6ab.png)

![](../Images/ee4967b729d199555cbf785d7a2aa74a.png)

![](../Images/9465a30dc4ef59eb5bd0ee2b142459c5.png)
