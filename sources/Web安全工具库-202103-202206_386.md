二、Fiddler设置

1、点击工具,选择选项

![](../Images/37aa4cf8c8b43b9b11cc2402df264864.png)

2、HTTPS选项及连接选项全打钩，顺便端口改一下，为了避免检测

![](../Images/40753bc4e056cda5eefcde8bb87b5453.png)

![](../Images/77e0dd8670078cf102dc75ff566a245d.png)

3、设置fiddlerScript，可以抓取Websocket包，结果会在日志中显示

*   
*   
*   
*   

```
static function OnWebSocketMessage(oMsg: WebSocketMessage) {    // Log Message to the LOG tab    FiddlerApplication.Log.LogString(oMsg.ToString());}
```

![](../Images/8f5e627c44788604f15c0935724ae9fc.png)

4、全部设置完毕重启Fiddler。

  

  

三、安装证书，抓取https的数据包

1、打开雷电模拟器，点击设置，修改网络，设置成本机ip地址，端口为上面定义的端口号

![](../Images/4602c550d549c17f8b2aa1f9a3de5204.png)

![](../Images/aa82e4d2d6b76df0d4a9a06495857d16.png)

  

2、打开模拟器浏览器，访问192.168.1.105:8877，点击FiddleRoot证书

![](../Images/ef6e9117910f1af871baf6c22e1df7ca.png)

3、点击下载好的证书，随便起个名字，点击确定，然后再设置一个图案

![](../Images/5a5c98a565bb4b945208f4f9305b3e2a.png)

![](../Images/55ac5722865412db5ddcb0b3a033b903.png)

  

3、点击一下捕获，让其不显示，这样就只抓模拟器的包了

  

![](../Images/f8bf26efe052e3894e75bb8bb9617033.png)

  

4、打开登陆页面，成功抓取登录的数据包

![](../Images/4074b66fecbd0012a6f46db46c99a735.png)

  

5、过滤数据，选择仅显示以下主机

![](../Images/5c7f73e81da419b62b4ea84e09d59257.png)
