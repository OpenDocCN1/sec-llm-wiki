‍‍一、安装方法‍‍

1、Kali系统自带Bttercap

2、软件下载地址（原作者）：https://github.com/bettercap/bettercap/releases/

  

  

二、常用命令

1、启动Bttercap

![](../Images/9cd677062b60e8d0f6d0ffc62c6dd141.png)

2、设置嗅探结果保存位置

set net.sniff.output aiyou.pcap

3、设置嗅探内容的关键词

set net.sniff.regexp "192.168.139.129"

4、开启嗅探

net.sniff on

![](../Images/0b744f404fc92d2ff1da2c671bea8d20.png)

5、查看设置的参数

net.sniff stats

![](../Images/dfd9233cb88528673de09f189e919973.png)

6、当其它主机访问包含192.168.139.129内容的网站，我们都可以监控得到

![](../Images/d77bf1305eaa11c325463eea43b45c98.png)

7、wireshark打开我们保存包，可以具体分析

![](../Images/44d114232eb981c8748ff9ce176b88bd.png)
