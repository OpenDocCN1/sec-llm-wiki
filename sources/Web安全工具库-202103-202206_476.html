简介：AWVS是自动化应用程序安全测试工具，主要用于扫描web应用程序上的安全问题，如SQL注入，XSS，目录遍历，命令注入等


一、下载AWVS相关包，请支持正版

二、给脚本文件最高权限

chmod 777 acunetix_13.0.200807155_x64.sh


三、安装步骤

sudo -i  切换root模式./acunetix_13.0.200807155_x64.sh

3、查看说明文件，按enter继续浏览，按q直接退出

4、选择yes

5、设置主机名，aiyou

4、设置登陆账号密码，密码必须有数字字符字母

aiyou@123.comaiyou@123

5、安装成功

6、将wvsc强制替换到

sudo cp wvsc /home/acunetix/.acunetix/v_200217097/scanner/

7、访问Kali主机的IP地址

https://192.168.139.133:3443

8、输入上面设置的账号密码

9、设置目标地址

10、扫描基本设置，默认即可

11、扫描结果
