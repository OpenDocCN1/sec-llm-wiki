----  网易云热评

一、在线查找

1、通过google语法

site:baidu.com

2、通过在线网站

https://phpinfo.me/domain

3、通过证书搜索

https://crt.sh/

4、通过dns搜索

http://dns.bufferover.run/dns?q=baidu.com

二、sublist3r工具搜索

1、下载安装：

git clone https://github.com/aboul3la/Sublist3r.git

2、安装需要的模块

pip3 install -r requirements.txt

3、搜索子域名

python3 sublist3r -d baidu.com -p 80,443 -o 1.txt

禁止非法，后果自负
