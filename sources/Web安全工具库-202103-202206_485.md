三、软件更新

1、安装软件leafpad

sudo apt install leafpad

![](../Images/f7107b65eeea8f5889729ff0e1d4fa38.png)

2、切换root权限

sudo -i

3、配置更新源

leafpad /etc/apt/sources.list

![](../Images/7043721ba48b64d1e5a74e593914fd82.png)

4、获取最新软件包列表信息，并更新，更新后删除安装包

apt-get update&&apt-get upgrade&& apt-get clean

![](../Images/c61c3f138a5bd152a2542a149492334a.png)

  

四、安装搜狗输入法

1、打开官网下载搜狗：https://pinyin.sogou.com/linux/?r=pinyin

2、右击打开终端，安装fcitx

sudo apt-get install fcitx

3、安装sougo

sudo dpkg -i 下载的搜狗安装包的名字

4、如果报错，root模式下制定apt-get --fix-broken install

![](../Images/4a32aae22f88e8f93ea044160578ff5b.png)

5、重复第三步，然后重启

  

五、设置快照

一切设置完毕后，关闭kali系统，选择虚拟机、快照、拍摄快照，这样不管怎么倒腾该系统，最后都可以从这里恢复到目前的状态

![](../Images/ab9d8b79fe9d24d5147f3ccff0a7fa98.png)
