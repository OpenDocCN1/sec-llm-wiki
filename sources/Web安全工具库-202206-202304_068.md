**0x01 工具介绍**

一个既可以满足安服仔日常渗透工作也可以批量刷洞的工具盒子。集合了常见的域名收集、目录扫描、ip扫描、指纹扫描、PoC验证等常用工具，方便安服仔快速展开渗透测试。

**0x02 安装与使用**

1、安装方法

*   
*   
*   
*   
*   

```
git clone https://github.com/givemefivw/SecurityServiceBox.gitcd SecurityServiceBoxpython3 install.pypip install -r requirements.txtpython3 main.py
```

2、基于Win环境下运行cmd /k 即可新开cmd窗口，除collect\_subdomain之外，其余工具均可无需等待当前命令执行结束直接执行下一条命令。且支持TAB键关键字自动补全。

3、命令执行结束后，在results文件夹下可查看输出的报告(Finger扫描的结果在tools/collect/finger/output文件夹内)

![](../Images/95478f5ea8389ef10f2cd06de68922ce.png)
