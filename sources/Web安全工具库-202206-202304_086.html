0x01 工具介绍

Dismap 定位是一个资产发现和识别工具，他可以快速识别 Web/tcp/udp 等协议和指纹信息，定位资产类型，适用于内外网，辅助红队人员快速定位潜在风险资产信息，辅助蓝队人员探测疑似脆弱资产.

0x02 安装与使用

# Scan 192.168.1.1 subnet./dismap -i 192.168.1.1/24# Scan, output to result.txt and json output to result.json./dismap -i 192.168.1.1/24 -o result.txt -j result.json# Scan, Not use ICMP/PING to detect surviving hosts, timeout 10 seconds./dismap -i 192.168.1.1/24 --np --timeout 10# Scan, Number of concurrent threads 1000./dismap -i 192.168.1.1/24 -t 1000
