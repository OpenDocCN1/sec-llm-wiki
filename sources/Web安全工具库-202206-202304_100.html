0x01 工具介绍

SQLi Hunter v2是一个python程序，用于检查URL中的SQL(和Blind)注入漏洞。该程序易于使用，实用，有益。

0x02 安装与使用

1、下载项目到本地

2、安装需求

pip Install -r requirements.txt

3、将执行权限授予SQLi Hunter v2.py文件

chmod +x 'SQLi Hunter v2.py'

4、运行程序!示例:

python 'SQLi Hunter v2.py' -url url .txt——clean -v .txt
