0x01 工具介绍

PVS漏洞扫描是一款适用于企业内网的漏洞快速应急、巡航扫描系统，通过搜索功能可清晰的了解内部网络资产分布情况，并且可指定漏洞插件对搜索结果进行快速漏洞检测并输出结果报表。

0x02 安装与使用

1. Nginx配置

location / {        proxy_pass   http://127.0.0.1:8889/;}

2. 创作镜像

$ docker build -t pvs .

3. 创造容器

$ docker run -d -p 8889:8889 -v /opt/data:/data pvs:latest

把物理机的/opt/data挂载到容器的/data目录下,访问:http://127.0.0.1:8889/正常访问则代表安装成功

4 安装mongodb3.4.0

5 添加mongodb用户

# mongo> use xunfeng> db.createUser({user:'scan',pwd:'your password',roles:[{role:'dbOwner',db:'xunfeng'}]})> exit

这里的scan和your password需要更换为你的mongodb的账号和密码。

6. 导入数据库

输入db文件夹，执行如下命令：

# mongorestore -h 127.0.0.1 --port 27017 -d xunfeng .

7.修改配置

修改系统数据库配置脚本config.ini：

MONGODB = 10.1.2.233MONGODB_PORT = 27017DB_USERNAME = scanDB_PASSWORD = scanlol66DB_NAME = xunfengPORT = 8889   #项目端口
