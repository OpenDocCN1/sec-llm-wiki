**0x02 安装与使用**

1、本地有 JRE/JDK 8+ 环境（如果使用内置JRE的exe版本无需Java环境）

2、使用 java -jar SuperXray.jar 启动（在Windows中双击启动会有权限问题）

3、前往 ctstack 或 xray 下载站 下载最新版 xray

![](../Images/b7e595b0aeef1937ada8fff336af0c1c.png)
