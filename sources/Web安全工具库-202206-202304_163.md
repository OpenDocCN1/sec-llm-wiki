**0x01 工具介绍**

主要有以下功能：

1、信息收集：

主机存活扫描 / 端口扫描 / 端口服务识别 / WebTitle扫描 / Web指纹识别 / findnet

2、口令爆破：

mysql、mssql、redis、psql、oracle、memcached、mongodb、redis、ssh、smb、rdp、ftp、elastic

3、漏洞探测：

docker、kubernetes、rmi、snmp、zookeeper、MS17010、MS-SMB2

**0x02 安装与使用**

  

1、常规用法  

*   
*   
*   
*   

```
Lscan.exe -h 192.168.1.1/24       (信息收集模式扫描)Lscan.exe -h 192.168.1.1/24 -ifms (信息收集模式扫描)Lscan.exe -h 192.168.1.1/24 -satt (扫描探测模式扫描)Lscan.exe -h 192.168.1.1/24 -ffat (火力全开模式扫描)  // 非对外开放功能
```

2、其他用法

*   
*   
*   

```
Lscan.exe -h 192.168.1.1/24 -m ftp      // 模块：ftp 功能：口令爆破Lscan.exe -h 192.168.1.1/24 -m survival // 模块：资产 功能：存活探测Lscan.exe -h 192.168.1.1/24 -m portscan // 模块：资产 功能：端口开放扫描
```
