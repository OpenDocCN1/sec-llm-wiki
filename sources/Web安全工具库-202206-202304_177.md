**0x01 工具介绍**

集成式，批量漏洞扫描器，集成 afrog nuclei vulmap pocbomber xray 五个漏扫。

**0x02 安装与使用**

1、将要扫描的全部url放在target目录下的url.txt里

2、到God.py同级目录下 python God.py 注意需要用到哪个漏扫，那么请加上对应漏扫首字母参数，比如需要xray，那么请这样 python God.py -x 1

3、如果需要线程速度更快 python God.py -x 1 这里的数字越多扫描完目标越快（线程数量）

*   
*   
*   

```
pip install -r requirements.txt
python God.py -x 1 -v 1 -p 1 -n 1 -a 1
```

4、结果回存放在各个漏扫的对应目录下！会在xray目录下以html形式生成。

5、安装chrome xray需要这个浏览器
