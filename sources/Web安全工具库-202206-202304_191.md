**0x01 工具介绍**

包含的字典内容如下：

1、Auth : 认证字典

帐户和密码。

2、网络：网络（计算）

排除的私有 IP 段、本地 IP 段、DNS 服务器列表。

3、端口：端口字典

按照端口渗透的想法,将不同端口承载的服务可爆破点作为字典内容。

4、Regular : 规则词典

各种规则、排列的字典整理。

5、网络：网络词典

web 渗透过程中出现的可爆破点作为字典内容。

  

包含的payload内容：

Burp，CORS，email，Format，HPP，LFI，OOB，SQL-Inj，SSI，XSS，XXE
