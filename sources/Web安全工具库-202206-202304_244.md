## 描述

Canteen Management System v1.0 中的跨站脚本 (XSS) 漏洞允许攻击者通过精心设计的有效负载执行任意 Web 脚本或 HTML。

## 影响

*   允许攻击者劫持用户的会话并接管帐户。
    
*   要利用此漏洞，受害者必须访问存储 XXS 有效负载的页面。
