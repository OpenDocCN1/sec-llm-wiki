动态域名解析

昨天逛B站看到：工信部强制要求运营商为家庭宽带设置公网IPv6，然后看了一下家里宽带，发现能够获取到IPv6，又根据其他知识得知这一分配的公网IP是动态的，于是写了python代码去动态解析域名到家庭公网上，  
  
python dynamic\_modify\_dns.py -domain=xxx.top -sub\_domain=ipv6 -is\_ipv6 -check\_ip\_fmt  
\-is\_ipv6选项可以选择ipv6模式，默认是ipv4模式  
\-domain参数即为你拥有的域名  
\-sub\_domain是指定子域名，默认二级域名为ipv4  
\-check\_ip\_fmt参数可以不加  
  
  
运行前准备工作：  
1.到为你的域名提供解析服务的dnspod控制台获取secret，https://console.dnspod.cn/  
2.安装一下依赖包  
\`pip install -i https://mirrors.tencent.com/pypi/simple/ --upgrade tencentcloud-sdk-python click IPy\`  
3.放到你的服务器上长久运行，推荐使用crontab  
\* \* \* \* \* python 绝对路径更佳dynamic\_modify\_dns.py -domain=xxx.top -sub\_domain=ipv6 -is\_ipv6 -check\_ip\_fmt > /tmp/ddns.log
