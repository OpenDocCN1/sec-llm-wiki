0x01 工具介绍

PoC 用于一种新的睡眠混淆技术（基于Ekko），利用等待计时器来 RC4 加密当前进程并将权限从 RW 更改为 RX 以逃避内存扫描器。

int main() {    int timesToExecute = 1337;    int seconds = 10;
    for (int i = 0; i < timesToExecute; i++) {        CronosSleep(seconds);
        // YOUR CODE HERE!    }}
