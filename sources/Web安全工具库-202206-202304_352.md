**0x01 工具介绍**

Msmap是一个内存马生成器，兼容多种容器、组件、编码器、*WebShell / Proxy / Killer* 和管理客户端。本文中涉及到的所有操作均得到了客户单位的授权，并且在漏洞修复后得以公开。请勿在未授权状态下进行任何形式的渗透测试！！！！
