# 解决渗透测试中参数加密工具 -- JS-Forward

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MDQ5MjY1Mg==&mid=2247502421&idx=2&sn=749d9909d1854e845c7de45f52c9f31c&chksm=ebb52556dcc2ac40b45c32bdffb8669216b496669246a5a8f92ebe4d2632e07df9e3a18d6179&scene=126&sessionid=1681669982#rd](http://mp.weixin.qq.com/s?__biz=MzI4MDQ5MjY1Mg==&mid=2247502421&idx=2&sn=749d9909d1854e845c7de45f52c9f31c&chksm=ebb52556dcc2ac40b45c32bdffb8669216b496669246a5a8f92ebe4d2632e07df9e3a18d6179&scene=126&sessionid=1681669982#rd)

> 项目作者：G-Security-Team项目地址：https://github.com/G-Security-Team/JS-Forward

  

一、工具介绍Js-Forward是为了解决在渗透测试过程中所遇到的WEB参数加密而开发出的脚本工具。  

二、安装与使用

1、输入手机号，点击发送验证码

![](../Images/a1e720ab4f398a519363c82929eb7c08.png)

  
2、Burp正常抓包，发现参数是加密的，并且有summary、data、encelope三个参数

![](../Images/f2462a7a957e31caec831318ffde0766.png)

  
3、通过前端JS的调试，寻找到加密函数点，这里可以发现summary、data、encelope都是由此而来，函数名称setInto

![](../Images/5730440e092697823571b255f1cf023a.png)

  
4、要对burp做一些设置，使得burp可以截断js

![](../Images/10a25d8e72ea1c806147e144595ecc46.png)

  
5、设置后的样子

![](../Images/ed8885daa2302728474e5828f387531f.png)

  
6、此时就可以启动Js-Forward了

![](../Images/344052aba50aa4a756465c08404f5cd8.png)

  
7、清除浏览器缓存，重新加载8、判断一下该应用是否使用的Jquery，例子中是不包含的，所以需要将Jquery手动添加进去，若已经引用了js则这一步可以省略

![](../Images/1bab3b3e8eb6bf1455c810ce3d131faa.png)

  
9、burp慢慢找带有setInto的js，最终找到了

![](../Images/d6170a620503920f6c17fffd1a26c72c.png)

  
10、在Js-Forward中输入要转发出来的参数名称，即data，会生成payload

![](../Images/edeb53ee03333cca76011b5969e7743b.png)

  
11、将payload插入进要替换参数的位置（注意在这里setInto是动态加载的js所以是字符串，要将Js-Forward生成的payload的双引号转义一下" -> \\"，若是正常的js代码则直接复制粘贴payload即可）

![](../Images/c8fa3306713d36923eed976a41dcb067.png)

  
12、将js放行，此时js便会缓存在浏览器中，后续就算不挂代理，burp依旧可以抓取带该数据包,解密成功

![](../Images/5a4d48ef79c55d1aa16bf7a08796d545.png)

  
13、脚本输出请求日志

![](../Images/3245f6da9a10c3e0b6369bfdfc00f429.png)
