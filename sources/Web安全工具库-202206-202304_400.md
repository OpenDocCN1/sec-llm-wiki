一、工具介绍

osakura 定位是一个资产发现和识别工具；其特色功能在于快速识别 Web 指纹信息，定位资产类型。辅助红队快速定位目标资产信息。Yosakura 拥有完善的指纹规则库。借助于 golang 并发优势，即可实现快速资产探测与识别 。后期将持续开发，POC验证、漏洞扫描等功能，励志打造成一款红队渗透框架，Yosakura在手天下我有(我瞎说的)
