一、工具介绍
ProxyAdmin 是强大的代理服务工具 snail007/goproxy 的控制面板，运行了它，一秒让你的服务器变为强大的代理服务器，友好的交互界面，小白也能轻松上手，让你用起来得心应手，心情舒畅。


二、安装与使用

1、使用助手工具安装

管理员打开 goproxy_helper.exe，可以一键安装/卸载/重启服务。
2、命令行安装
管理员账号执行cmd.exe
cd 进入“有proxy-admin的目录”
proxy-admin.exe install
3、访问安装成功后，打开浏览器访问：http://127.0.0.1:32080 , 首次默认账号是root，密码是123，登录后记得第一时间修改。
配置文件路径：
Linux && MacOS 位于 /etc/gpa/app.toml
Windows 位于 C:\gpa\app.toml
可以配置监听的端口和日志记录。
