# 某LOGO在线设计网站漏洞

今天在某度搜LOGO在线制作，看有个网站写着大大的“**免费**”于是开开心心的点了进去 。。。  

![](../Images/05722ee2efe3725f3f913cebe04cca91.png)

  
别说，这网站弄出来的LOGO还蛮漂亮的。。。**在线设计制作过程确实免费**。。。  

![](../Images/5552ca74e04cb08a47d0233114187878.png)

  
  
但**保存的时候就要钱了**，最低也要99。。。  

![](../Images/7646ee7e08b0ece45e6173ddf98098ba.png)

  
于是，右键——检查，发现生成的LOGO都是SVG的，而且那里写着一个大大的watermark  
  

![](../Images/34cae24428c0f5333f2de09d4bf75436.png)

  
删掉那一行，于是得到了一个没水印的LOGO  

![](../Images/31fef13ef6ac7cba2a563c870cd26a69.png)

  
复制SVG节点，右键，复制，复制元素  
  

![](../Images/d49e55ee5596df2f3918e64d509666ed.png)

  
桌面新建个文本，粘贴进去，然后保存为svg，用IE打开查看（**IE打开可以右键另存为png**），得到一个没水印的LOGO  

![](../Images/d3fa1248e366e3913cc8e4ef9b44a019.png)

  
右键保存为png后发现，不是透明的，有白背景  
  

![](../Images/c379ec85a19552e1f2becdfad9f14713.png)

  
回网站上继续看，这里有个background和#fff（白色），应该是这行了，删掉，然后再复制代码保存  

![](../Images/b96f6b83b6d654b48313d28f3039e6a8.png)

  
于是免费得到一个透明的LOGO图片  

![](../Images/38c477e99608331cbba97d2ec1118a86.png)

  
  
网站也可以在线编辑，替换图标，字体，效果之类的，保存都一样，复制SVG出来就行了。。。
