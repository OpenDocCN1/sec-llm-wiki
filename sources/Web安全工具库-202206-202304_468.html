一、工具介绍
一款分布式资产信息收集和漏洞扫描平台，扫描插件中使用了一些优秀的工具，其中部分工具所需license、接口api token等需自行添加。

二、安装与使用
1、将xray-license.lic分别添加到如下位置即可:(xray配置文件需自行配置/如reverse等)
gosint/client/subdomain_scan/xray_subdomain/tools/gosint/client/vuln_scan/rad2xray/tools/
2、客户端配置相关api
gosint/client/config.yaml
3、环境搭建

安装docker / docker-compose, 请自行安装

cd gosint/docker-compose up -d --build

为了避免xray webhook被人恶意塞数据，建议对webhook url path进行修改，直接改如下两处即可：

gosint/apps/dashboard/urls.pygosint/client/docker-entrypoint.sh
