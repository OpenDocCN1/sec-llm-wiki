一、工具介绍

调用ZoomEye的官方api(未来会支持更多资产搜索引擎)，开发的GUI界面的信息搜集工具。支持查询主机搜索、域名/IP、web应用搜索、个人信息，支持读取config.json文件进行登陆，支持账号密码和API-KEY登陆，查询显示结果仅为部分，完整内容保存至指定文件或数据库，支持查询用户个人信息。


二、使用方法
1、配置文件config.json说明
"API-KEY":"","username":"",      # zoomeye用户名(邮箱)"password":"",      # 登陆密码"db_name":"",       # 数据库名(需预先手动创建)"db_host":"",       # 数据库host"db_username":"",   # 数据库用户名"db_password":""    # 数据库密码
2、安装python需要的库文件（python version：3.8+）
pip install -r requirements.txt
