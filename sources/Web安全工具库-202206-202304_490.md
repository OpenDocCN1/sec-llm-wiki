一、工具介绍  

quiet是一款安全人员渗透测试工具，目前支持功能：端口扫描（TCP-Connect 与 TCP-SYN），主机探测（ICMP），本项目为Go语言学习产物，既有独立研究，亦有二次开发。

  

二、安装与使用

1、编译

go build -o quiet

2、普通扫描  

sudo ./quiet ps -i 114.114.114.110-120 -m syn -p 50-55,80 -c 100

![](../Images/12cdfac1a767ddcaf4d71588012cd58d.png)

3、内网端口

内网端口扫描加入参数 --local/-l 则无需指定 ip

sudo ./quiet ps -l -m syn -p 3300-3350 -c 20

![](../Images/8d6c2bc769104d7e60aa8eed8fcb959e.png)

4、内网探测：

sudo ./quiet ping -l 

![](../Images/893409bc9cdb99a0097212ee5e0b8bb6.png)
