一、工具介绍

以 subfinder 为基础，融合 ksubdomain、 Amass 的一些优点进行二次开发的一款子域名收集工具，可以很方便作为 go 库集成进入项目中。并增加了以下功能：

1、域名接管检测功能

2、网络空间扫描引擎被动获取子域时，增加ip、端口开放收集

*   
*   
*   

```
shodan 获取 ip\端口fofa 获取 ip\端口zoomeyeapi 获取 ip
```
