# **    游戏逆向修改、MP锁定之dll文件修改与hook**

**0x02开始正文**  

    游戏开始前，可以看到HEALTH是血量，即常说的HP，而MANA是我们说的MP，因为进入时候没有技能，技能栏为空，而需要获取到技能才可以看到MP的变化。

![](../Images/ac1b66a2bdfafeba97f7feb66b1ba51a.png)

在路口往前后左转，直走后找到相关秘籍，获得第一个技能：“火遁”，火遁需要MP的消耗才能成功放出来，因此，在释放“火遁”的时候，对应的MP也会减少，因此，需要定位到MP的数据修改位置

![](../Images/2f58db40bc48d2d13ad8c55e4bd609e8.png)

![](../Images/163571e97823777c5aba27bb9891a5e6.png)

在“火遁”释放之前，可以确定的是MP数值满为100，释放一个“火遁”后，发现MP在释放后瞬间减少，然后缓慢回升，这时候可以想到，搜索数据100，然后释放以后直接不断搜索改变的数据，对应缓慢回升的数据定位，最后选择锁定后，可以找到MP相关的地址数据。

![](../Images/c622957045641e514b6f5252c7f754c9.png)

1）MP满格时候，搜索100的数据

![](../Images/e494d73d498348b7298d4cc82c9717a6.png)

一共搜索出7827个数据

2）喷射一定量的火遁，不断点击变化数据

![](../Images/334b40d1e729747cfb57722cebb4d039.png)3）找到三个数据，并双击后取下来

![](../Images/ae712d984e56d201e83b2faf7f05db5a.png)

4）通过锁定数值一一查看定位到MP数据是哪一块

![](../Images/e83d182b58963e11715d22434e624c3f.png)

4）经过锁定，得到的MP数据块是

```

```

5）追踪相关数据

![](../Images/741560d90d6e817bdf1473f1b11e2cea.png)

因此，只需要写死eax为满格就好了。

已知相关的位置汇编代码是：

*   
*   
*   
*   
*   

```
7A8E25C3 - 7C E6 - jl GameLogic.RandomFloat+318BB7A8E25C5 - 2B C2  - sub eax,edx7A8E25C7 - 89 86 BC000000  - mov [esi+000000BC],eax <<7A8E25CD - 8B 11  - mov edx,[ecx]7A8E25CF - 50 - push eax
```

在地址7A8E25C7处将数据写在地址esi+000000BC处，然后该值是由eax赋予的，因此，可以hookeax的数据，但是这时候我们可以在动态调试进行写死。

这时候需要直接进入动态调试进行分析

![](../Images/7d73791f3d935c5c84f3302ac132d4c4.png)

下好断点后再次使用“火遁”，发现断点成功，接下来查看eax的数据是60，

![](../Images/16df5a43a12758a4d90c3f0f6313a5cb.png)![](../Images/40f937472f1ccfc9d92fd9b4ed91fd7c.png)

追踪数据，找到相关位置，发现数据是6400 00 00 ，而64正是十进制的100，就是满格MP

![](../Images/7cbb03c6a789a756fdfe2cabd08d191d.png)![](../Images/426d967df54b67b938310555907048b2.png)

![](../Images/46dc83fd2190f7799f7705ee428c4b53.png)

这时候可以知道，eax就是写入到该位置的，所以直接把eax改为固定值即可，这时候直接改为其他数值，然后保存为GameLogic.dll。

![](../Images/33e34a15193bf2552c7825a892c09147.png)

替换游戏根目录下的GameLohic.dll然后重新进入游戏获得“火遁”后，释放一次查看一下MP值已经是被锁定得了。

![](../Images/2d9329994ccd8b490fc055eb284e23d6.png)

6）接下来就是hook了，可以直接写一个简单的修改器，其中设置两个按钮：![](../Images/76418b781943640b2d6f691848000f50.png "1596337002209285.png")

       恢复体力的时候，可以直接调到地址2DBAE30C，将其数值直接改为100，使用WriteProcessMemory指令，可以写出修改器，这样就省下分析的过程了，关键代码如下：

*   
*   
*

```
HWND game_wnd = ::FindWindowA(NULL, "PwnAdventure3 (32-bit, PCD3D_SM5)");    BYTE game_data[1];    LPCVOID pbase = (LPCVOID)0x2DBAE30C;    LPVOID a = (LPVOID)0x2DBAE30C;    RtlZeroMemory(game_data, 1);    if (game_wnd)    {        DWORD game_pid;        ::GetWindowThreadProcessId(game_wnd,   &game_pid);        HANDLE game_handle =   ::OpenProcess(PROCESS_ALL_ACCESS, FALSE, game_pid);        if (NULL != game_handle)        {             DWORD bread;             ReadProcessMemory(game_handle,   pbase, game_data, 1, &bread);             if (game_data[0] !=   100) {                 DWORD ii=100;                 WriteProcessMemory(game_handle,   a, &ii, 1, &bread);             }             CloseHandle(game_handle);        }    }
```
