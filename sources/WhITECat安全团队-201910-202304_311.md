# Python sqlalchemy ORM注入漏洞分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMzc2MDQ3NQ==&mid=2247483753&idx=1&sn=2a9d91c8a857f1feb8cd4d236770847e&chksm=9b37095dac40804b4ee4f450efa34f58727c46dde1bd7f2359318aefe2470bd42e29e80fa7ca&scene=126&sessionid=1681400712#rd](http://mp.weixin.qq.com/s?__biz=MzAwMzc2MDQ3NQ==&mid=2247483753&idx=1&sn=2a9d91c8a857f1feb8cd4d236770847e&chksm=9b37095dac40804b4ee4f450efa34f58727c46dde1bd7f2359318aefe2470bd42e29e80fa7ca&scene=126&sessionid=1681400712#rd)

介绍：

SQLAlchemy是一个Python的SQL工具包以及数据库对象映射框架。

  

影响：  

SQLAlchemy 1.3.3 版本存在ORM注入漏洞，攻击者可利用该漏洞获取数据库敏感信息。

  

安全等级：

**高**

漏洞编号：  

CNVD-2019-17301

  

参考资料：

《HITB16议题解析：Java应用ORM注入开发新方法》

  https://www.freebuf.com/vuls/106605.html

  

分析：

1、对于不合规的SQL语句为进行过滤和拦截。

2、所谓的SAQL注入，就是指在SQLAlchemy中没有对数据进行有效的验证导致恶意数据进入应用程序中造成的。

漏洞分析：

在sqlalchemy.orm.session.sessionmaker之中，这里是数据库连接会话。

![](../Images/0df48cbec906dcdeaa5cbccd3026eef0.png)

漏洞入口定位：sqlalchemy\\orm\\session.py 第608行，这里是数据会连接会话的对象。

![](../Images/e3f414465ba826abbb2a25b57eea82b7.png)

漏洞入口方法定位:sqlalchemy\\orm\\session.py 第1137行，进入到执行SQL语句的方法。

![](../Images/9e1cf2dabfe4e7788debbee519bbe2ea.png)

继续往下来看方法代码，第1267行将SQL语句进行执行。

![](../Images/e131cbbea65e9ae7219abd5170bce685.png)

Execute() 是SQL语句执行的一个接口，允许执行任意的SQL语句，没有对于SQL注入进行有效的过滤。

修复建议：  

1、过滤非预定义中的拼接字符，比如过多的引号、@、冒号、分号等等；

2、使用有效的安全防护设备；

3、开发管理中禁止使用该接口；
