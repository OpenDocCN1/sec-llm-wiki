## 密码规律

密码一般由三部分组成： 

名称（人名、单位名、系统名、开发公司名等，常见的如a、password、Password、P@ssw0rd） 

数字（常见的有123、123456、1、2、01、000，以及座机区号、生日等等）

字符（常见的拼接密码的字符有\['?','@','#','\_','!','$',',','.'\]，常见的位数是1-3位）

  

其中： 

1\. 名称有全称、全称/简称混合、全简称、首字符大小写等区分；

2\. 数字和字符的位置位于第二位和第三位，两者位置可以交换，字符一般是1-3位，不过优质的密码还要使用工作上发现的、常用的特殊字符组合，而非全部特殊字符组合，可以极大的减少密码的数量，提高精确度；

3\. 非复杂类型的密码，特殊字符可以没有，或者数字可以没有；

## 思路二

为简化生成的密码，从特殊字符下手，固定特殊字符的组合，并且按照特殊字符在中间、后面所处的位置不同，差异化出两种特殊字符组合的列表（这需要依据经验总结来生成固定特殊字符组合），此时密码组合的可能性就少了很多，但同时也可能因此而错失少数的正确的密码，毕竟组合概率极大的减少了。不过个人认为大多数情况下，这种损失是可以接受的，毕竟都是为了权衡效率与概率。

# -*- coding:utf-8 -*-import pypinyin
def readfile(txt):    txt_list = []    with open(txt, 'r', encoding="utf-8") as f1:        for line in f1.readlines():            if line.startswith(u"\ufeff"):                line = line.encode("utf8")[3:].decode("utf8")            if '    ' in line or '\n' in line:                line = line[:-1]            txt_list.append(line)    return txt_list
def genname(txt):    name_list = readfile(txt)    with open("gen_name.txt", 'a+') as file:        file.truncate(0)        for name in name_list:            pinyin_list = pypinyin.lazy_pinyin(name)            quanpin = ''.join(pinyin_list)            fixpin = ''.join([pinyin_list[n] if n==0 else pinyin_list[n][0] for n in range(len(pinyin_list))])            simpin = ''.join([pinyin_list[n][0] for n in range(len(pinyin_list))])            Bquanpin = quanpin.capitalize()            Bfixpin = fixpin.capitalize()            Bsimpin = simpin.capitalize()            file.write(quanpin+'\n'+fixpin+'\n'+simpin+'\n'+Bquanpin+'\n'+Bfixpin+'\n'+Bsimpin+'\n')
if __name__ == '__main__':    genname('name.txt')
