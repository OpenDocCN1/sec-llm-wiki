## 流量

如果想在流量上处理加密过程，就需要服务端和客户端同时修改了。比如AES加密后替换一定的字符也达到混淆的目的。

即

*   
*   

```
String data=request.getReader().readLine();data=data.replace("#",k.substring(0,1).toLowerCase()).replace("*","=");
```

从key中取出第一位字符并替换为`#`，以及将`=`替换为`*` 对应客户端也需要修改，在`net.rebeyond.behinder.utils#getData`里

*   
*   
*   

```
String data = Base64.encode(encrypedBincls);data = data.replace(key.substring(0, 1).toLowerCase(), "#").replace("=", "*");return data.getBytes();
```
