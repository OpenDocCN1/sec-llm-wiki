## 找dll基址

  

先列过程：

  

1.  找到TEB
    
2.  找到PEB
    

3.  找到\_PEB\_LDR\_DATA
    
4.  跳两次到kernel32的位置
    

5.  找到kernel的entry
    

  

和x86不同的一点是，TEB存放的位置不在fs寄存器中，而是在gs寄存器中，TEB的地址存放于 gs:\[30h\]处。

  

PEB也变了，PEB在TEB+0x60处。其余过程和x86的区别不大，代码如下图所示。

  

```


	mov rbx, gs:\[30h\]               ;TEB
```

  

## 找函数的绝对地址

  

继续列过程：

  

1.  找到`E_lfanew`的RVA地址（DllBase+0x3c）
    
2.  找到PE文件签名地址（DllBase+1中保存的RVA）
    

3.  找到导出表的RVA(2中得到的地址+0x88)
    
4.  找到导出表的绝对地址（DllBase+3中的RVA）
    

5.  找到导出名称表的RVA(2中地址+0x20)
    
6.  找出导出名称表的绝对地址（DllBase+5中的RVA）
    

7.  找到导出序号表的RVA（2中地址+0x24）
    
8.  找到导出序号表的绝对地址（DllBase+7中的RVA）
    

9.  找到导出地址表的RVA(2中地址+0x1c)
    
10.  找到导出地址表的绝对地址（2中地址+9中RVA）
     

11.  找到导出函数的数量（2中地址+0x14）
     
12.  遍历名称表，找到*WinExec*并记住遍历过的数量。
     

  

代码如下所示：

  

```


	; Find WinExec address
```

  

## 调用函数

  

过程

  

1.  在序号表在对应位置处找到WinExec并得到其序号（序号表的绝对地址+（12中的值\*2））
    
2.  在地址表里找到WinExec的RVA（地址表的绝对地址+（13中得到的序号\*4））
    

3.  找到WinExec的绝对地址（RVA+DllBase）
    
4.  将参数放入寄存器中
    

5.  调用
    

  

```


    ; the counter (eax) now holds the position of WinExec
```
