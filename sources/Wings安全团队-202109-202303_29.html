前言：

关于frp搭建及使用的教程，按照简单易懂的方式整理一哈，好让小可爱们都可以看明白及正确的使用，有错误请各位师傅及时指正。

使用场景例如：

1.靶机服务器无公网IP，但可出网，想进一步实现内网横向测试。

2.甲方要进行漏洞扫描及内网渗透测试，但时间紧急且客户无VPN，团队只能远程操作。

3.远程连接公司电脑进行内网办公。

简介：

frp是一个专注于内网穿透的高性能的反向代理应用，go语言开发，支持TCP、UDP、HTTP、HTTPS等多种协议。可将内网服务以安全、便捷的方式通过具有公网IP节点的中转暴露到公网，并带有功能强大的web管理端。
对比nps优劣势：

  • nps在scks5代理下会长连接导致结果不准确。

  • frp虽需落地配置文件，但扫描结果比较准确。

  • frp具备负载均衡功能，但很容易被管理员发现。

  • nps有流量加密和压缩传输也是减少触犯防火墙规则。

  • frp图形化界面，简单易操作。

  • frp采用 TCP 连接流式复用，可节省连接建立的时间。

脚本主要分为服务端与客户端文件

1.VPS服务器端用到的是frps和frps.ini

2.windows或linux系统客户端用到的是frpc和frpc.ini

3.每个包中都存在frps服务端的文件与frpc客户端的文件，按需所取即可，如作为服务端的文件可删除其中的客户端文件，不影响服务端


服务端部署配置：

1.将frp_0.37.1_linux_386.tar.gz文件传到vps：

mkdir frptar  xzvf frp_0.37.1_linux_386.tar.gzmv  frp_0.37.1_linux_386  frp#新建文件夹并解压文件，将解压文件移动到新建文件夹
2.编辑vim /frps.ini

#服务端配置(注意写注释的话记得单独一行)

[common]# frp监听的端口，默认是7000，可修改为其他bind_addr = 0.0.0.0bind_port = 7000# 授权号，可修改为其他，客户端连接时需要token = 1234567890
# frp管理后台端口，可修改为其他dashboard_port =7500# frp管理后台用户名和密码，可修改为其他dashboard_user =你设置的用户名dashboard_pwd =你设置的密码enable_prometheus =true
# frp日志配置log_file =/var/log/frps.loglog_level = infolog_max_days = 3

3.启动服务端：

./frps -c ./frps.in
反馈如下图及启动成功，同时记得把vps的防火墙策略调整一下，放行你的监听端口及管理端口。


4.测试访问（需输入服务端配置文件里的管理后台用户名及密码）：

http://VPSIP:7500

客户端配置：

针对linux客户端、windows客户端均适用

1.客户端首先上传frpc文件，编辑vim /frpc.ini

# 客户端配置

[common]server_addr = VPS地址server_port = 7000# 需要与服务端端口对应token = 1234567890#授权号需与服务端对应tls_enable = turepool_count = 5
[sock5]type = tcpremote_port = 46075#可修改为其他plugin = socks5plugin_user =你设置的用户名plugin_passwd =你设置的密码#可修改为其他use_encryption =trueuse_compression= true

2.启动客户端:

./frpc -c frpc.ini或frp.exe -c frpc.in

如下图及反馈启动成功。


Proxifier配置:

实现本地与客户端的交互

Proxifier是一款功能非常强大的socks5客户端，可以让不支持通过代理服务器工作的网络程序能通过HTTPS或SOCKS代理或代理链。支持64位系统，支持Xp，Vista，Win7，MAC OS,支持socks4，socks5，http代理协议，支持TCP，UDP协议，可以指定端口，指定IP，指定域名，指定程序等运行模式，兼容性非常好。
