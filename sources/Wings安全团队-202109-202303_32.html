1、内网信息收集概述

渗透测试人员进入内网后，面对的是一片 “黑暗森林”。所以，渗透测试人员首先需要对当前所处的网络环境进行判断。
判断涉及如下三个方面


  • 我是谁？对当前机器角色的判断。

  • 这是哪？对当前机器所处网络环境的拓扑结构进行分析和判断。

  • 我在哪？对当前机器所处区域的判断

2、域环境or工作组

当我们通过 Web 漏洞或者其他的手段获取到了一个命令执行的口子后，我们想要对当前服务器进行深层次的内网渗透，那么必须得知道当前机器所在的环境是工作组还是域 ，因为两种环境的攻击手法不同，所以我们需要根据不同的环境来做不同的处理!

2.1、判断是否在域内


查看当前网卡和ip信息
可以看到该机器主DNS后缀是一个域名，一般来说只有域机器才会有域名显示，而在工作组下显示的是空

2.2、查看系统详细信息

通过输入systeminfo命令查看系统详细信息，如果是域环境则会显示域名，如果是工作组则会显示WORKGROUP


2.3、查看当前登录域及域用户

net config workstation 通过该命令可以看到域环境会直接显示工作站域的名称，工作组只会显示WORKGROUP

2.4、查看域内时间

net time /domain

  • 不存在域

  • 存在域当前用户不是域用户

  • 存在域且为域用户

3、对当前机器进行信息收集

3.1、获取当前机器的网络配置信息

ipconfig /all
通过截图可以看到该机器有一个网卡，网卡配置信息如图所示

3.2、查看端口开放情况

netstat -ano
通过查看本机端口开放情况我们就可以知道当前机器有没有与其他机器进行连接,同时可以查看有没有开放远程桌面 3389、MySQL 服务 3306 ... 等等

3.3、查看安装的软件及版本、路径

wmic product get name,version
通过查看安装了哪些软件可以知道当前机器的使用情况，并且可以利用某些软件的溢出、提权等漏洞

3.4、查询本机服务信息

wmic service list brief

3.5、查询进程列表

tasklist /svc
通过查看进程列表可以查看是否有杀软

3.6、查看当前进程列表对应的用户身份

tasklist /svc
通过执行这条命令我们可以知道每个进程对应的用户，是那个用户启动的这个软件，但是这条命令只能看到和你一 样级别或者比你低权限的用户的进程，在令牌窃取时会用到这里

3.7、查看启动程序信息

wmic startup get command,caption
通过查看启动程序信息我们可以知道当前机器开机的时候会运行哪些软件，这也可以利用自启动劫持。

3.8、查看计划任务

schtasks /query /fo LIST /v
通过查看本机计划任务我们就能知道当前机器上“某个时间”会运行哪些软件，我们就可以利用这一点来做定时任务 劫持。

3.9 查看开机时间

net statistics workstation
通过查看本机的开机时间，我们就能判断这台机器的管理员是不是经常关机，是不是经常在登录这台机器。

3.10、查看用户及当前在线用户

net user
query user || qwinsta
通过查看当前机器有哪些用户，我们就可以知道当前机器有没有其他管理员，同时也可以查看是否被其他人入侵过，是不是留下了一个后⻔。
通过查看当前在线用户我们就可以知道当前机器有没有管理员在登陆，因为有的时候我们可能需要远程登录到目标 服务器上，盲目的登陆到目标服务器上，容易暴露自己。

3.11、查看系统补丁

systeminfo
wmic qfe get Caption,Description,HotFixID,InstalledOn
通过查看目标补丁情况我们就可以知道当前机器上有哪些补丁打了，哪些漏洞补丁是不是没打，没打补丁的话那 么我们就可以对某个漏洞进行利用

3.12、查询路由表及所有可用接口的ARP缓冲表

通过查询路由表及所有可用接口的ARP缓冲表，我们就可以知道当前网络的分布情况，内网有没有其他机器

3.13、查看防火墙配置

通过查看防火墙配置我们就能知道当前机器是否开了防火墙，或者一些防火墙配置信息。

修改防火墙配置常用的命令
win 2003及之前的版本，运行指定程序全部连接:
netsh firewall add allowedprogram c:\nc.exe "allow nc" enable
win 2003之后的版本用这条:
netsh advfirewall firewall add rule name="pass nc" dir=in action=allow program="C:\nc.exe"
允许指定程序连出，命令如下
netsh advfirewall firewall add rule name="Allow nc" dir=out action=allow program="C: \nc.exe"
允许 3389 端口放行，命令如下
netsh advfirewall firewall add rule name="Remote Desktop" protocol=TCP dir=in localport=3389 action=allow
自定义防火墙日志储存位置
netsh advfirewall set currentprofile logging filename "C:\windows\temp\fw.log"
若是想要关闭防火墙就可以使用:
win 2003及之前的版本用这条命令: netsh firewall set opmode disable
win 2003之后的版本用这条命令:
netsh advfirewall set allprofiles state off

3.14、查询并开启远程桌面服务

查看远程桌面服务
tasklist /svc | find "TermService" netstat -ano |findstr 1248


查看远程桌面服务是否开启，在 cmd 下使用注册表查询语句，命令如下，得到连接端口为 0xd3d，转换后为 3389

REG QUERY "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp" /V PortNumber

 一些开启远程桌面服务的命令
# 在 Windows Server 2003 中开启 3389 端口
wmic path win32_terminalservicesetting where (__CLASS !="") call setallowtsconnections 1
# 在 Windows Server 2008 和 Windows Server 2012 中开启 3389 端口
wmic /namespace:\\root\cimv2\terminalservices path win32_terminalservicesetting where (__CLASS !="") call setallowtsconnections 1
wmic /namespace:\\root\cimv2\terminalservices path win32_tsgeneralsetting where (TerminalName='RDP-Tcp') call setuserauthenticationrequired 1
# 在 Windows 7 中开启 3389 端口
reg add "HKLM\SYSTEM\CURRENT\CONTROLSET\CONTROL\TERMINAL SERVER" /v fSingleSessionPerUser /t REG_DWORD /d 0 /f

4、域内信息收集

4.1、获取SID

whoami /all 获取sid后续做票据传递的时候使用

4.2、查询域内用户

net user /domain
通过查询域内用户我们就可以知道这个域内所有用户名，这也是可以知道这个域的大小到底有多大的一个命令

4.3、查看某个域用户的详细信息

net user hacker01 /domain

4.4、查询域列表

net view /domain

4.5、查询管理员列表

net group "domain admins" /domain

4.6、查看域内时间

net time /domain
通过查看域内时间(时间服务器)，我们得知了当前域的时间，我们就可以使用定时任务+IPC来运行一些bat文件。
我们还知道当前域的时间服务器是 server2016.hacker.com我们可以 Ping 一下它的机器名就知道它的 IP 是多少

4.7、查看登陆本机的域管理员

net localgroup administrators /domain

4.8、查看域内所有用户组列表

net group /domain

4.9、查看主域控制器

netdom query pdc

4.10、查看所有域控制器列表

net group "Domain Controllers" /domain

4.11、查看域信任信息

nltest /domain_trusts
通过查询域信任信息我们就可以知道当前有多少个域，域名是多少。

4.12、查询域密码信息

net accounts /domain
