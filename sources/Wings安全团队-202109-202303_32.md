## 1、内网信息收集概述

渗透测试人员进入内网后，面对的是一片 “黑暗森林”。所以，渗透测试人员首先需要对当前所处的网络环境进行判断。  
判断涉及如下三个方面

  

*   我是谁？对当前机器角色的判断。
    
*   这是哪？对当前机器所处网络环境的拓扑结构进行分析和判断。
    

*   我在哪？对当前机器所处区域的判断
    

## 2、域环境or工作组

当我们通过 Web 漏洞或者其他的手段获取到了一个命令执行的口子后，我们想要对当前服务器进行深层次的内网渗透，那么必须得知道当前机器所在的环境是工作组还是域 ，因为两种环境的攻击手法不同，所以我们需要根据不同的环境来做不同的处理!

### 2.1、判断是否在域内

  

查看当前网卡和ip信息  
![](../Images/bd4c5f2ad20e07ab0536d89925274fde.png)可以看到该机器主DNS后缀是一个域名，一般来说只有域机器才会有域名显示，而在工作组下显示的是空  
![](../Images/b9cc526fb7cd99667fe6bd60c7a7ab4c.png)

### 2.2、查看系统详细信息

通过输入systeminfo命令查看系统详细信息，如果是域环境则会显示域名，如果是工作组则会显示WORKGROUP

## 3、对当前机器进行信息收集

### 3.1、获取当前机器的网络配置信息

ipconfig /all  
通过截图可以看到该机器有一个网卡，网卡配置信息如图所示  
![](../Images/e9b75b7c834dab46fa21406b0592e984.png)

### 3.2、查看端口开放情况

netstat -ano  
通过查看本机端口开放情况我们就可以知道当前机器有没有与其他机器进行连接,同时可以查看有没有开放远程桌面 3389、MySQL 服务 3306 ... 等等

![](../Images/ee712120f9674776c59f45deac3d4bed.png)

### 3.3、查看安装的软件及版本、路径

wmic product get name,version  
通过查看安装了哪些软件可以知道当前机器的使用情况，并且可以利用某些软件的溢出、提权等漏洞  
![](../Images/c5cdea207c38b46e7528f40ae2fa3a6e.png)

### 3.4、查询本机服务信息

wmic service list brief

![](../Images/29f8cbc785bedb2782116a2364c1e83f.png)

### 3.5、查询进程列表

tasklist /svc  
通过查看进程列表可以查看是否有杀软

![](../Images/7b158624396a2a991e580101c0071e83.png)

### 3.6、查看当前进程列表对应的用户身份

tasklist /svc  
通过执行这条命令我们可以知道每个进程对应的用户，是那个用户启动的这个软件，但是这条命令只能看到和你一 样级别或者比你低权限的用户的进程，在令牌窃取时会用到这里

![](../Images/3c851e2e5c7027f137d129bc6df81135.png)

### 3.7、查看启动程序信息

wmic startup get command,caption  
通过查看启动程序信息我们可以知道当前机器开机的时候会运行哪些软件，这也可以利用自启动劫持。  
![](../Images/3f64d5447c95ffa56d8d45fed9772a4b.png)

### 3.8、查看计划任务

schtasks /query /fo LIST /v  
通过查看本机计划任务我们就能知道当前机器上“某个时间”会运行哪些软件，我们就可以利用这一点来做定时任务 劫持。  
![](../Images/e6f7ea913822a1d62fe90d730637e485.png)

### 3.9 查看开机时间

net statistics workstation  
通过查看本机的开机时间，我们就能判断这台机器的管理员是不是经常关机，是不是经常在登录这台机器。  
![](../Images/be2e96bbd9120650958eed595f1392bf.png)

### 3.10、查看用户及当前在线用户

net user  
query user || qwinsta  
通过查看当前机器有哪些用户，我们就可以知道当前机器有没有其他管理员，同时也可以查看是否被其他人入侵过，是不是留下了一个后⻔。  
通过查看当前在线用户我们就可以知道当前机器有没有管理员在登陆，因为有的时候我们可能需要远程登录到目标 服务器上，盲目的登陆到目标服务器上，容易暴露自己。

![](../Images/f8bf5c44f10012d562f72c0c477d0ba2.png)![](../Images/f3b5377434cbf83d28806e0cf64b794c.png)

### 3.11、查看系统补丁

systeminfo  
wmic qfe get Caption,Description,HotFixID,InstalledOn  
通过查看目标补丁情况我们就可以知道当前机器上有哪些补丁打了，哪些漏洞补丁是不是没打，没打补丁的话那 么我们就可以对某个漏洞进行利用

![](../Images/bdfad47d03936ff61f9065c3a4c6e716.png)![](../Images/9692f3e37c42562ac664f54ce54b23d2.png)

### 3.12、查询路由表及所有可用接口的ARP缓冲表

通过查询路由表及所有可用接口的ARP缓冲表，我们就可以知道当前网络的分布情况，内网有没有其他机器  
![](../Images/74dd757ed6818bfb8978444cfbb7eabe.png)

![](../Images/60203a6783fec697ac1d413e5036cfff.png)

### 3.14、查询并开启远程桌面服务

查看远程桌面服务  
tasklist /svc | find "TermService" netstat -ano |findstr 1248

![](../Images/0ff8d080bc091e4fc47b643d8523b6b7.png)

  

查看远程桌面服务是否开启，在 cmd 下使用注册表查询语句，命令如下，得到连接端口为 0xd3d，转换后为 3389

```
REG QUERY "HKEY\_LOCAL\_MACHINE\\SYSTEM\\CurrentControlSet\\Control\\Terminal Server\\WinStations\\RDP-Tcp" /V PortNumber
```
