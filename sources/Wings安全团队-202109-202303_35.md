有关secure\_file\_priv的解释说明如下：  

MySQL5.5之前secure\_file\_priv默认是空，这个情况下可以向任意绝对路径写文件。

MySQL5.5之后secure\_file\_privmore是NULL，这个情况下不可以写文件。

| value || 说明 |
| --- | --- |
| NULL || 不允许导入和导出 |
| /tmp || 只允许在/tmp目录导入导出 |
| 空 || 不限制目录，可以随意导入导出 |

**利用sql注入提权、UDF提权**

什么是UDF？

自定义函数，是数据库功能的一种扩展。用户通过自定义函数可以实现在MySQL中无法方便实现的功能，其添加的新函数都可以在sql语句中调用，就像调用本机函数version（）同样方便。

  

UDF提权原理

已知root账号和密码，利用root权限，创建带有调用cmd函数的“udf.dll”。当我们把udf.dll导出指定文件夹引入mysql时候，其中的调用函数拿出来当作mysql函数来使用。

**mof提权**

mof文件是MySQL数据库的扩展文件

存放路径：C:/windows/system32/wbem/mof/

提权条件：

1、windows2003及一下

2、mysql启动身份具有权限去读写C:/windows/system32/wbem/mof/目录

3、secure\-file\-priv\=不为null
