## 1、环境描述

  

server2016 10.211.55.23 域控  
server2012 10.211.55.22 域内主机  
server2019 10.211.55.25 域内主机  
子网掩码 255.255.255.0  
默认网关 10.211.55.1  
DNS 10.211.55.23

## 2、环境配置

### 2.1、更改机器ip

将机器ip设置为固定ip 10.211.55.23，子网掩码 255.255.255.0，默认网关 10.211.55.1，DNS 指向本机ip

### 2.2、更改计算机名

使用本地管理员登录server2016然后将计算机改名为server2016(名字随意)，更改后需要重启服务器

### 2.3、安装域控制器和DNS服务

首先打开服务器管理器  
![](../Images/940ec949c818b4b480389b9300484431.png)点击管理-->添加角色和功能  
![](../Images/94852444cadf38faa8d31cfde6062c00.png)在开始之前界面保持默认即可，直接点击下一步，选择基于角色或基于功能的安装，点击下一步即可  
![](../Images/22d50546b1f22f29affabee4e0151a63.png)进入服务器选择部分，目前在服务器池中只有当前这台机器，保持默认设置，直接点击下一步即可

![](../Images/25f930da9441d7853026d7a4bb7558cd.png)

在服务器角色部分勾选Active Directory服务和DNS服务器，然后点击下一步即可

![](../Images/dd639c0154e5dab205a5734ab48b2c10.png)

在接下来的功能、AD DS、DNS服务器、界面都直接默认下一步即可

![](../Images/839153e8d89d0fb9a27c6c54897b98df.png)

在确认界面勾选如果需要自动重新启动目标服务器，然后点击安装即可

![](../Images/c08dc50d98e55f2e0d4ed5d3ddbc23ea.png)

接下来等待所有功能安装完毕,然后点击关闭即可

![](../Images/0884b810f25e3a6be6b86b410fc46b18.png)

### 2.4、提升此服务器为域控制器

将上述功能都安装完毕后，服务器管理器会出现一个黄色的叹号，点击叹号后，点击将此服务器提升为域控制器

![](../Images/786c612890cad903b7e0128859eefdd4.png)

接下来会进入到域服务配置向导，在配置部署界面选择添加新林，然后输入根域名hacker.com然后点击下一步

![](../Images/46e07e45bf55d0d6bdbeeb80979bfdfe.png)

然后进入到域控制器选项部分，选择新林和根域的功能级别都保持为 windows server 2016默认即可，然后输入还原密码

![](../Images/06ea9f1d715fbf2bc041e8881973c5b9.png)

在DNS选项部分会出现关于DNS的警告，不用管，直接点击下一步

![](../Images/39ee15b1be4d3f4de0198ffaf6c89016.png)

然后进入到其他选项，NetBIOS保持默认即可，点击下一步

![](../Images/8936f934a39139d720b58249c0607ad0.png)

路径和查看选项保持默认即可，点击下一步

![](../Images/ad97a67f02d8a5048e4902825183b27c.png)

![](../Images/31b03580262eaae0073b84d741b98657.png)

然后在先觉条件这里如果显示administraor密码不符合要求，输入一下两行命令即可

![](../Images/2178fac3b668c47224d25c8aab8863ff.png)

```

net user administrator server@2016
```

输入完命令，然后点击重新运行先觉条件检查,检查通过后点击安装即可,等待安装完毕后，会显示此服务器已成功提升为域控制器，点击关闭，服务器会重启

![](../Images/9f37ea2ac3876768f44c2efb453ad400.png)

系统重启完成再次进入系统打开服务器管理器界面中就可以看到AD DS、DNS服务了

![](../Images/0b2ffbdb5a6668f82e1c2bb271dfd77b.png)

### 2.5、添加域用户

打开服务器管理器，然后选择Active Dirctory用户和计算机，点击域名选择 User-->新建-->用户

![](../Images/cd31b728fe99c4b2634639b6c2dedb33.png)![](../Images/0cb430f43e5605d345c5c1755ba90a56.png)

创建一个用户名为hacker01的用户，然后点击下一步输入密码，并且去掉用户下次登录时更改密码，勾选上密码永不过期

![](../Images/cb5cd76ebe3c1cad42d3efa9e3592241.png)

![](../Images/23eff883ff8bfdb03739d77d580d5e78.png)

  

### 2.6、将server2012加入域中

首先设置ip，DNS为server2016的ip截图如下，更改完成后ping hacker.com进行检测

![](../Images/ae74be2b294560f22eddf75b0ee4b1ce.png)

接下来将server2012添加到域中,更改计算机名和域名，点击确定后会让你输入域管理员的账号和密码 校验通过后会提示成功加入域，然后机器会重启，截图如下(server2019加入域中同此操作)

![](../Images/2ce8b78a1d2689c2296ad80a15294e0b.png)

![](../Images/bb542fa8a64152bed5e7c8a904df138e.png)

![](../Images/5e0271233ab97284b0882b83902efdcb.png)

然后我们使用刚才创建的hacker01登录server2012，此时我们再次回到server2016，就可以看到server2012已经成功加入到域中  
![](../Images/e441743d3ad9387607bfd46fdf7d6c30.png)
