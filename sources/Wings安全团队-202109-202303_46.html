原理

在Windows中，句柄是一个系统内部数据结构的引用。例如当你操作一个窗口，或说是一个Delphi窗体时，系统会给你一个该窗口的句柄，系统会通知你：你正在操作142号窗口，就此你的应用程序就能要求系统对142号窗口进行操作——移动窗口、改变窗口大小、把窗口最小化等等。实际上许多Windows API函数把句柄作为它的第一个参数，如GDI（图形设备接口）句柄、菜单句柄、实例句柄、位图句柄等，不仅仅局限于窗口函数。换句话说，句柄是一种内部代码，通过它能引用受系统控制的特殊元素，如窗口、位图、图标、内存块、光标、字体、菜单等。            ———— 引自百度百科

因此，我们可以通过操纵句柄的方式来从控件的UI中获取我们想要的东西，而不需要通过遍历内存来寻找相关的内容。步骤如下

  1. 使用工具来获取teamview中我们想要定位的控件名称。

  2. 遍历所有的窗口句柄，找到teamview的主窗口句柄。

  3. 遍历teamview窗口中的所有控件，找到我们在第二步中获取到的控件名称，获取其控件句柄。

  4. 通过第三步找到的控件句柄获取控件中保存的值。

遍历所有的窗口句柄，获取teamview的主窗口句柄

  1. 我们使用GetDesktopWindow()来获取桌面窗口的句柄，桌面窗口覆盖整个屏幕。桌面窗口是一个要在其上绘制所有的图标和其他窗口的区域。

  2. 再通过GetWindow（HWND hWnd，UNIT nCmd）和GetNextWindow(hWnd, GW_HWNDNEXT)来遍历所有窗口。

    代码如下所示

 HWND hd = GetDesktopWindow();        //得到桌面窗口  hd = GetWindow(hd, GW_CHILD);        //得到屏幕上第一个子窗口  char s[200] = { 0 };  int num = 1;  while (hd != NULL)                    //循环得到所有的子窗口  {    memset(s, 0, 200);    GetWindowTextA(hd, s, 200);    std::string strText = s;    if (!strText.compare("TeamViewer"))    {      EnumChildWindows(hd, EnumChildWindowsView, NULL);    }    hd = GetNextWindow(hd, GW_HWNDNEXT);  }
