1、为什么要隐藏c2服务器

在红蓝对抗中如果我们不设法隐藏自己的c2服务器，就有可能被蓝方溯源甚至被反控，以下内容为如何通过某些手段来隐藏c2。

2、端口特征修改

cs的默认连接端口为50050，这是个很明显的特征，要想去除该特征，我们可以修改teamserver文件，将50050修改为其他任意端口即可。

3、证书特征修改

Keytool是一个java数据证书的管理工具，Keytool将密钥和证书存放在一个称为keystore 的文件中, 即.store后缀的文件中。

Keystore是什么?keystore是java的密钥库，用来进行通信加密，如数字签名。keystore就是用来保存 密钥对的公钥和私钥。Keystore可理解为一个数据库，可以存放很多个组数据。

每组数据主要包含以下两种数据:

  • 密钥实体 --- 密钥(secret key)又或者私钥和配对公钥(采用非对称加密)

  • 可信任的证书实体 --- 只包含公钥

常用命令

查看证书文件:  keytool -list -v -keystore xx.store修改证书密码:  keytool -storepasswd -keystore xx.store 修改keystore的alias别名:  keytool -changealias -keystore xx.store -alias source_name -destalias new_name修改alias(别名)的密码:  keytool -keypasswd -keystore xx.store -alias source_name

查看cs默认的store文件

1、keyool -list -v keystore cobaltstrike.store

可以看出CobaltStrike默认的store文件中的Alias name 、Onwer 和 Issuer 的信息，特征都比较明显。

2、通过直接访问CobaltStrike服务器的端口，也可以看到证书信息。

   curl https://10.211.55.5:50050 -v -k

修改服务端证书CobaltStrike.store

服务器端使用的证书CobaltStrike.store，为了掩盖默认SSL证书存在的特征，需要重新创建一个新的不

一样的证书 。使用以下命令创建证书:

先删除 CobaltStrike 自带的 cobaltstrike.store，然后使用以下命令生成一个新的cobaltstrike.store即可!

  • alias 指定别名

  • storepass pass 和 -keypass pass 指定密钥 -keyalg 指定算法

  • dname 指定所有者信息

keytool -keystore cobaltstrike.store -storepass 密码 -keypass 密码 -genkey - keyalg RSA -alias google.com -dname "CN=(名字与姓氏), OU=(组织单位名称), O=(组织名 称), L=(城市或区域名称), ST=(州或省份名称), C=(单位的两字母国家代码)"

例如:

keytool -keystore cobaltstrike.store -storepass 123456 -keypass 123456 -genkey -keyalg RSA -alias microsoft.com -dname "CN=Microsoft Windows, OU=MOPR, O=Microsoft Corporation, L=Redmond, ST=Washington, C=US"

再次查看cobaltstrike.store，特征已经去除。

4、修改上线的证书

cobaltStrike.store 仅仅是服务器端连接的证书。通过https上线使用的证书，不是cobaltstrike.store， 并且该证书也是默认的!

启动时使用此命令 ./teamserver [external IP] [password] [/path/to/my.profile]

如果想要修改这个证书，需要修改Malleable C2 profile。官方文档:https://www.cobaltstrike.com/help-malleable-c2

github上提供的Malleable-C2-Profiles模版:https://github.com/rsmudge/Malleable-C2-Profiles

Self-signed Certificates with SSL Beacon 和 Valid SSL Certificates with SSL Beacon 这两个都是用来修 改https上线使用的证书的。

  • Self-signed Certificates with SSL Beacon 这里是自己设定的自签名证书。

  • Valid SSL Certificates with SSL Beacon    这里是让我们使用有效的证书。我们可以使用之前修改过 的cobaltstrike.store，也可以使用从其他地方弄过来的证书。

SourcePoint

https://github.com/Tylous/SourcePoint#global-options 此工具是用来帮我们生成C2 profile

必要的参数

  • Outfile 输出文件名

  • Host TeamServer的域名或IP

  • Injector 进程注入使用的函数

命令:

./SourcePoint_1.3_linux_amd64 -Outfile my.c2profile -Host 10.211.55.5 -Injector NtMapViewOfSection

创建完成后，一定要使用cs自带的c2lint校验是否正确

./c2lint ./my.c2profile

代码签名和SSL证书

通常情况下，我们使用的是上节中的c2配置文件即可，但是在高强度的对抗中，代码签名和SSL证书也是需 要用上的。

方法一:使用Let's Encrypt签发https证书

Let’s Encrypt 是 一个叫 ISRG （ Internet Security Research Group ，互联网安全研究小组）的组织推出的免费安全证书计划。参与这个计划的组织和公司可以说是互联网顶顶重要的先驱，除了前文提到的三个牛气哄哄的发起单位外，后来又有思科（全球网络设备制造商执牛耳者）、 Akamai 加入，甚至连 Linux 基金会也加入了合作，这些大牌组织的加入保证了这个项目的可信度和可持续性。

1.安装certbot

sudo apt-get install certbot

2.签发证书

certbot certonly --standalone  -d your-domain.com

这里的your-domain.com必须要有A记录对应

3.打包生成Java Keystore

# 切换到证书生成目录

cd /etc/letsencrypt/live/your-domain.com

# 打包证书

openssl pkcs12 -export -in fullchain.pem -inkey privkey.pem -out your-domain.com.p12 -name your-domain.com -passout pass:123456789

# 生成Java keystone

keytool -importkeystore -deststorepass 123456789 -destkeypass 123456789 -destkeystore your-domain.com.store -srckeystore your-domain.com.p12 -srcstoretype PKCS12 -srcstorepass 123456789 -alias your-domain.com

把生成的your-domain.com.store拷贝到cs目录然后修改刚刚的profile,在profile最底部

启动./teamserver ip password https.profile

5、Beacon Staging特征

在cobalt strike 上线的时候，首先投递一个被称为stager的小巧payload，然后去beacon staging server下载体积较大更复杂的stage,通过访问默认的uri就可以获取到cobalt strike 的shellcode

https://github.com/whickey-r7/grab_beacon_config 检测工具

nmap 10.211.55.5 --script=grab_beacon_config.nse

修改这个特征的方法，目前只看到两种：

1、修改源代码加密的密钥：https://cloud.tencent.com/developer/article/1764340

2、从防火墙上限制访问beacon的端口。

iptables -I INPUT -p tcp --dport 443 -j DROP iptables -I INPUT -s 10.211.55.5 -ptcp --dport 443 -j ACCEPT

只允许c2服务器的这个IP访问443端口

但是在kali上测试的时候通过上面两个命令不生效，然后通过使用iptablse-save生成配置文件

iptables-save > /etc/iptables.rules

配置网卡启动前加载

编辑/etc/network/interfaces文件，添加pre-up iptables-restore < /etc/iptables.rules

再重启网卡systemctl restart networking

再次测试

6、流量特征修改

流量特征修改使用域前置技术，域前置是一种用于隐藏真实C2服务器IP且同时能伪装为与高信誉域名通信的技术，多用于木⻢受控端和控制端之间的隐蔽通信。

1、注册cloudflare账号，然后添加域名,选择最下面免费的


2、在dns处找到NS值，然后填写到购买域名的网站中，具体看截图

3、再次回到couldflare,找到 缓存-->配置-->开发模式 开启开发模式

4、最后在cloudflare添加一个解析A记录到自己的VPS，名称就是域名、内容就是VPS的IP地址

5、检查是否配置成功

   用超级ping检查，并没有显示vps的真实ip

1、创建http/https的监听器

   注意 http port 端口只能设置成以下几个：80,8080,8880,2052,2082,2086,2095
