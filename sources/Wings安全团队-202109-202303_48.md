## 1、为什么要隐藏c2服务器

在红蓝对抗中如果我们不设法隐藏自己的c2服务器，就有可能被蓝方溯源甚至被反控，以下内容为如何通过某些手段来隐藏c2。

## 2、端口特征修改

cs的默认连接端口为50050，这是个很明显的特征，要想去除该特征，我们可以修改teamserver文件，将50050修改为其他任意端口即可。

## 3、证书特征修改

Keytool是一个java数据证书的管理工具，Keytool将密钥和证书存放在一个称为keystore 的文件中, 即.store后缀的文件中。

Keystore是什么?keystore是java的密钥库，用来进行通信加密，如数字签名。keystore就是用来保存 密钥对的公钥和私钥。Keystore可理解为一个数据库，可以存放很多个组数据。

每组数据主要包含以下两种数据:

*   密钥实体 --- 密钥(secret key)又或者私钥和配对公钥(采用非对称加密)
    
*   可信任的证书实体 --- 只包含公钥
    

![](../Images/f5a8971ecc66932b97e25c7535be3c29.png)

## 4、修改上线的证书

cobaltStrike.store 仅仅是服务器端连接的证书。通过https上线使用的证书，不是cobaltstrike.store， 并且该证书也是默认的!

启动时使用此命令 ./teamserver \[external IP\] \[password\] \[/path/to/my.profile\]

如果想要修改这个证书，需要修改Malleable C2 profile。官方文档:https://www.cobaltstrike.com/help-malleable-c2

github上提供的Malleable-C2-Profiles模版:https://github.com/rsmudge/Malleable-C2-Profiles

Self-signed Certificates with SSL Beacon 和 Valid SSL Certificates with SSL Beacon 这两个都是用来修 改https上线使用的证书的。

*   Self-signed Certificates with SSL Beacon 这里是自己设定的自签名证书。
    
*   Valid SSL Certificates with SSL Beacon    这里是让我们使用有效的证书。我们可以使用之前修改过 的cobaltstrike.store，也可以使用从其他地方弄过来的证书。

## 5、Beacon Staging特征

在cobalt strike 上线的时候，首先投递一个被称为stager的小巧payload，然后去beacon staging server下载体积较大更复杂的stage,通过访问默认的uri就可以获取到cobalt strike 的shellcode

https://github.com/whickey-r7/grab\_beacon\_config 检测工具

nmap 10.211.55.5 --script=grab\_beacon\_config.nse

![](../Images/6b817e8a6b0bd15f243a69064c7ea17d.png)

修改这个特征的方法，目前只看到两种：

1、修改源代码加密的密钥：https://cloud.tencent.com/developer/article/1764340

2、从防火墙上限制访问beacon的端口。

*   
*   

```
iptables -I INPUT -p tcp --dport 443 -j DROP iptables -I INPUT -s 10.211.55.5 -ptcp --dport 443 -j ACCEPT
```

只允许c2服务器的这个IP访问443端口

但是在kali上测试的时候通过上面两个命令不生效，然后通过使用iptablse-save生成配置文件

iptables-save > /etc/iptables.rules

配置网卡启动前加载

编辑/etc/network/interfaces文件，添加pre-up iptables-restore < /etc/iptables.rules

再重启网卡systemctl restart networking

再次测试

## 7、上线cs

#### 1、创建http/https的监听器

    注意 http port 端口只能设置成以下几个：80,8080,8880,2052,2082,2086,2095

    如果是 https 的监听端口只能设置成以下几个：443,2053,2083,2087,2096,8443;

    因为这是 Cloudflare 仅支持的端口，所以没办法把监听器设置成其他端口。
