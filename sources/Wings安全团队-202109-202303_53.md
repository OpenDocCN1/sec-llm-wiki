class KeyBlock:    __base = "%^$^GHsgjdsad24dffgjkdhw4"
    __key: bytes = None
    @staticmethod    def new_block(sun_login_code: str = ""):        if len(sun_login_code) > 31:            raise Exception("invalid key")        result = KeyBlock()        temp = sun_login_code + result.__base        size = struct.pack("<I", len(temp))        for i in range(56 - len(temp)):            temp += "\x00"        result.__key = bytes(temp.encode() + size)        return result

class Init(Base):    __key: bytes = None

    def on_create(self):        obj = self._get_handle()        obj.mem_map(self._code_ptr, align(len(init_code)))        obj.mem_write(self._code_ptr, init_code)

class Decrypt(Base):    __save_ptr = 0x100000
    def __init__(self, encoded_data, box):        self.__encoded_data = encoded_data        self.__box = box        super().__init__()

        obj.mem_map(self._data_ptr, 0x2000)        obj.mem_write(self._data_ptr, self.__box)        obj.reg_write(unicorn.x86_const.UC_X86_REG_RDX, self._data_ptr)

## 高版本

特点：运行过程中动态加载配置文件  
利用方式：直接在配置文件中添加连接密码，进行无人值守访问。  
1、设置random\_password=666666

  

![](../Images/b4f07045d0604de7da6067951c09d0a9.png)

重新连接，输入设置的密码信息。

  

![](../Images/57b0bed13bd093d11e3d280530950445.png)

  

连接成功。

  

![](../Images/c7325ffb61d35e00856e103d8ed04e2d.png)

2、设置random\_password  
本地搭建客户端，设置连接密码999999。

  

![](../Images/6be3596a417ebb2dc894fb8d614ecba7.png)

  

查看本地配置文件中加密后的hash为  
connect\_password=5eec351934af7678a852ade9efc74133

  

![](../Images/623c268cd75834605cf65ebf943a0a41.png)

  
修改目标主机的配置文件中的参数连接即可。  
connect\_password为5eec351934af7678a852ade9efc74133

## 低版本

特点：只在开始运行时加载配置文件  
无random\_password只能通过修改connect\_password连接。  
利用方式：结束进程，修改配置文件，重新运行。  
1、结束进程

```

taskkill /pid 84636  -t  -f
```

![](../Images/4ca5556964b43b9e83dab756ecab9dca.png)

  

2、修改配置文件内容  
connect\_password为5eec351934af7678a852ade9efc74133（999999）  
3、重新启动即可用密码连接。

# 坑点

1、uac  
非server服务器运行向日葵需要bypass uac

  

![](../Images/6f104ba7562dc4aa56279c0df929ce52.png)

2、用户不在线的情况，需要密码登录。

  

![](../Images/a2ae484bfd04140a3a88f4c026946f66.png)

  

这个坑点导致利用起来比较鸡肋，适用于隧道流量无法绕过等一些极端情况，可以选择免杀读密码/免杀加用户然后登录。
