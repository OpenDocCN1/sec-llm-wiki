前言

安装Android SDK、模拟器

Android SDK

选择arm架构，然后正常下载安装。ARM system lmage 就是支持M1、M2芯片的安卓镜像。

打开SDK tools 选择 layout inspector image server for api s

安装完所有的依赖包后，点击ok关闭窗口。

模拟器

打开AVD mannger

即可运行，这时我们的Android模拟器已经成功运行了。

Mac 快捷启动

通过Mac的自动操作来实现快捷启动Android模拟器

cd /Users/你的用户名/Library/Android/sdk/emulator

./emulator -list-avds


cd /Users/你的用户名/Library/Android/sdk/emulator

./emulator -avd Pixel_3a_API_33_arm64-v8a

保存后，即可快速启动，替换上自己喜爱的图片（胡桃一生推 ~ ）
