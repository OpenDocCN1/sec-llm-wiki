## 前言

新款MacBook M1 由于芯片是苹果自研，所以很多的工具不兼容，不管是开发者还是安全行业从业者，都会相同的苦恼，此处解决的是Android开发者与安全从业者困扰的问题，在2021年4月的时候，谷歌有一个自己开源的一款模拟器（google/android-emulator-m1-preview）实际使用起来就很，恩~~

## **Android Studio 安装**

官方下载地址：https://developer.android.com/studio/archive

版本选择：

![](../Images/687ecac1757d9b2942176120fd4cb4f4.png)

此处已经告诉了我们，arm、Apple silicon。下载后，正常跟着流程安装即可

## 安装Android SDK、模拟器

#### Android SDK

选择arm架构，然后正常下载安装。ARM system lmage 就是支持M1、M2芯片的安卓镜像。

![](../Images/9f51851c01d31cfa9f9ec569a7ffa050.png)

打开SDK tools 选择 layout inspector image server for api s

![](../Images/6f83a410aba119e0263ef40c8a88d6ed.png)

安装完所有的依赖包后，点击ok关闭窗口。

#### 模拟器

打开AVD mannger

![](../Images/91c14f2b95364ba011171c4e8143adcb.png)

![](../Images/1333b1de374654014d98017db1b082ba.png)

即可运行，这时我们的Android模拟器已经成功运行了。

![](../Images/9b38da578d0f69d67810e4d583f0fe6c.png)

## Mac 快捷启动

通过Mac的自动操作来实现快捷启动Android模拟器

```


cd /Users/你的用户名/Library/Android/sdk/emulator
```

  

```


cd /Users/你的用户名/Library/Android/sdk/emulator
```

![](../Images/adaad14655b50e70c0caf7c5fbd8af22.png)

保存后，即可快速启动，替换上自己喜爱的图片（**胡桃一生推 ~ **）

![](../Images/2a039873a2678816656ae5a2458118e5.png)

## 应用安装

因为目前google的安卓镜像目前好像只支持ARM64-v8a架构的应用包，所以我们需要以下的工具去辅助我们找到程序安装包去下载。

####  APK download

apl download 这是一个Chrome的插件，这个插件可以帮助你搜索Googleplay里面的应用安装包，查找你需要的版本然后直接下载就行。

![](../Images/0ee44248eb5ae0b0a0028d1a3b90fb2c.png)

可自由选择版本去下载：

![](../Images/4f48d8faf4586aea074cf06c4e112363.png)

![](../Images/4894b551d891c0171120f293b91d9a65.png)
