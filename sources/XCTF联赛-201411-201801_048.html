8月24日-8月25日，XCTF联赛新加坡站HITB GSEC CTF在新加坡洲际大酒店举办，大赛由赛宁网安、蓝莲花战队、XCTF联赛与HITB联合举办，360战略支持。经过两天的激烈比拼，最终来自德国的KITCTF战队从500多支参赛队伍中脱颖而出，力挫群雄，获得HITB GSEC CTF大赛的冠军。


赛后第二天，由XCTF联赛组织新加坡站一行去往亚洲高校排名第一的南洋理工大学进行网络安全学术分享，零距离感受世界著名高等学府的魅力。



南洋理工大学

南洋理工大学是一所享誉国际，位列全球大学排名第十一名亚洲排名第一的高等教育学府，是国际商学院联合会AACSB International认证的大学，为全球科技大学联盟成员和创始校。1991年，南洋理工学院进行重组，正式将国立教育学院纳入旗下，更名为南洋理工大学。 校园被誉为世界最美丽的大学校园之一，它为教授提供自由教学和研究的最好环境。它是全世界最出色的工程学府之一，在纳米材料、生物材料、功能性陶瓷和高分子材料等许多领域的研究上享有盛誉。




精彩内容

现场，新加坡南洋理工大学Yang Liu教授讲述了自己近年在网络安全研究方面的进展；美国乔治亚大学Kang Li教授分享了题为《Enhancing Symbolic fuzzing with learning》的主题报告，讲述了通过机器学习改进基于符号化执行的Fuzzing测试方法；美国佐治亚理工学院Chengyu Song教授分享了题为《Discovering Memory Errors with better detection methods》的主题报告，讲述了如何使用更好的检测方式发现内存错误；新加坡国立大学Zhenkai Liang教授分享了题为《Binary Security as Researcher and Service provider》的主题报告，以研究人员和服务提供商视角探讨二进制安全；XCTF联赛创始人清华大学诸葛建伟副研究员分享了自己在带领XCTF联赛在CTF赛事的引进推广方面作出的努力。

几位专家通过分享网络安全技术前沿的新兴话题及前端技术，国内外顶尖学府教授之间进行了深刻的对话交流，现场引来听众们的频频互动，随后，HITB GSEC CTF大赛蓝莲花战队的出题人也都做了赛题思路的分享。
