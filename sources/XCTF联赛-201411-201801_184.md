# 中科院及中兴通讯安全专家团做客南京赛宁云计算中心

内容摘要    10月14号上午，中科院及中兴通讯安全专家团一行10人做客南京赛宁信息**云计算中心**，营销部张晓博、市场部吴鑫菊等陪同，并做详细演示和介绍，双方就网络安全、云安全技术等方面进行了沟通和交流。

 ![](../Images/9cc7f42c4ebcdbcff18bbe18766d344f.png)  

中科院及中兴通讯专家团做客赛宁云计算中心

  

进入赛宁云计算中心，一行人首先被眼前超大屏幕上XCTF实训平台的炫酷画面所吸引。市场部吴鑫菊在作了简短的中心介绍之后，对XCTF平台上的功能和模块作详细介绍和演示。**XCTF实训平台**是在汇集两届XCTF国际联赛竞赛真题的基础上搭建的比武练习和实训操作平台，对于提升网络安全人才攻防对抗的能力有着非常重要的作用。

  

也正是因为拥有XCTF联赛举办的实力，今年6月，赛宁成功举办了华为第三届安全技术大赛，并且以顶尖的赛题输出、高质量的平台支撑、零故障的运维保障，赢得华为的交口称赞。初赛形式为线上解题，决赛为线下攻防对抗模式。题型与国际DEF CON大赛题型接轨，并结合华为实际业务需求，**覆盖的知识体系**涉及了Web安全、JSP代码审计、逆向、加解密、日志分析、android安全等。

  

![](../Images/7b5c96c41ac7b8a437877354cd9a0545.png)

  

**进一步了解南京赛宁** 

  

>     介绍完XCTF实训平台，工作人员还演示了网络靶场和APT攻击防御平台，并一同观看了南京赛宁的宣传片和电视媒体关于XCTF联赛的相关报道。从媒体报道中不难看出，国家对网络安全的重视和关注，为了让更多人拥有网络安全意识，已连续举办了3家国家网络安全宣传周的活动，而2016年武汉安全周的活动上，南京赛宁和中兴通讯都在展会上进行了亮相宣传。

  

![](../Images/fd018e56fe3408557676549de2a8101d.png)  
双方就网络安全方面的知识进行交流沟通  

    而更让彼此拥有更多共同话题的是，中兴通讯拥有着全球云计算中心，并成立云计算与IT经营部，对于云计算市场、云安全领域有着丰富的经验和独到见解。云计算的核心始终是云安全和网络安全，技术方面的发展需要大家共同的探索、沟通和学习。

     没有网络安全就没有国家安全，期待着南京赛宁和中兴通讯今后的进一步战略合作，为持续提升国内一流企业的安全技术能力而共同努力！
