# XMan练习赛，“战争+分享”助力网安人才培养

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NDU3MjExNw==&mid=2247484084&idx=1&sn=c8a8066ec1e9394055ff47c533e001eb&chksm=a684f08e91f37998b9ebb64c84f4942bb545135570b947c5d97266273c16d2e509555ff42297&scene=126&sessionid=1681669608#rd](http://mp.weixin.qq.com/s?__biz=MjM5NDU3MjExNw==&mid=2247484084&idx=1&sn=c8a8066ec1e9394055ff47c533e001eb&chksm=a684f08e91f37998b9ebb64c84f4942bb545135570b947c5d97266273c16d2e509555ff42297&scene=126&sessionid=1681669608#rd)

近日，历时三天的XCTF-XMan练习赛顺利谢幕。最终，江苏高校联合战队SU力挫群雄，夺得冠军。北京航空航天大学Lancet战队和清华大学紫荆花战队分获亚军和季军。

![](../Images/ad8a8d5f5fcc3919758101d2164ee253.png)  
**（练习赛中表现出色的SU战队）**

XCTF-XMan“攻防未来”特训夏令营由XCTF联赛发起与总体承办方南京赛宁公司主办，夏令营旨在提升国内高校安全人才整体水平、缩短与国际一流强队技术实力差距，增加XCTF联赛第一梯队战队阵容，凝聚XCTF两年的经验和最顶级的平台，培养未来网络空间安全的守卫者。永信至诚、浙江大学为此次夏令营提供协办支持。

  

此次特训营练习赛采用“战争＋分享”（Belluminar） CTF赛制，由参赛队伍互相出题，进行挑战，13支参赛队伍每支抽签选择MISC/Crypto、Web、RE、Pwn、Mobile/IOT五大类别中的两个类别，利用夏令营所学，编写完整的解题代码和过程文档，以及考察知识技能点列表，并在赛后进行出题、解题思路分享，最后以解题得分（50%）、出题得分（30%）、分享评分（20%）综合评价每支队伍的排名成绩。

![](../Images/103b335669baa8c815137303d1213267.png)  

**（练习赛比赛现场）**

在首日的比赛中，由来自东南大学、南邮、解放军理工大学等江苏高校组成的联合战队SU率先发力，解出8题，以总分1200分独自领跑，清华大学的紫荆花战队获得1000分紧随其后，来自东华大学的2419战队暂列第三，13支战队全力解题，仍有超过一半的题目未被攻破，这也让第二天的比赛充满悬念。

![](../Images/66e04ca63f935bfd742548e7b14dcc8b.png)  
**（首日积分榜）**

经过第一天的适应以及晚上的紧张准备，第二天的比赛更加精彩激烈，临近比赛结束前的15分钟，仍有九支队伍提交新的flag，比分交替上升，排名几度更迭，让人大呼过瘾。

![](../Images/fb3413f04081e88195cb8313c5ecf448.png)  
**（积分趋势变化图****）**

混战之中，还是首日强势出击的SU战队更胜一筹，以解出21题，总得分2900分的优异成绩夺得桂冠，第二天表现十分出色的北航Lancet战队以19题紧随其后，清华紫荆花战队收获第三，浙大whoami、中国公安大学宫保鸡丁、厦大Ph0en1x战队分列4~6位。  

![](../Images/74b1eacce3f352e35c7f63b6842aa411.png)  
**（练习赛积分榜****）**

“战争”阶段结束，练习赛的第三天进入分享环节，XMan们分享出题和解题思路，交流所得。由13支队伍的2位同学，准备PPT和演示，代表出题人进行出题、解题思路和考察知识技能点的分享，并解答疑问，讲师/实验助教与其他队伍根据技术分享内容进行打分，占竞赛总分的20%。

![](../Images/6cde52a2571e235b4fa3240cea0f95cb.png)

**（蓝莲花队员陈星曼在分享中）**

比赛完美谢幕，结果并不重要，夏令营的精彩还将继续，25~26日，主办方特邀在刚刚结束的美国拉斯维加斯DEFCON CTF中获得世界第二的b1o0p战队中蓝莲花战队成员，进行经验交流与分享。夏令营的最后，还将进行“星球大战”结业汇报赛，这也是XMan们证明自己的最佳舞台~
