# XCTF特训营之CTF比赛选手与企业如何接轨（一）

随着越来越多优秀的网络安全人才在XCTF联赛中涌现而出，构建CTF比赛选手与企业的桥梁成为重中之重，如何将CTF知识与企业实际相结合，让CTF选手在实践中学以致用，而非仅仅为了比赛而比赛，难以积累和沉淀。

  

针对上述情况，XCTF-XMan特训营特邀请多位业界网络安全大咖带来“CTF比赛选手与企业如何接轨”系列讲座，今天为大家介绍的是其中四位：清华大学网络信息安全研究室高级顾问魏克、佐治亚大学计算机科学教授李康、启明星辰助理总裁大菠萝、360Vulcan Team的核心成员古河。

  

**培训内容： 企业渗透测试全面解析**

 

**简介： **介绍一般企业网络的安全架构，管理策略，安全设备等；了解企业的业务网络中心和办公网络的区别和管理方式。讲解外部网络渗透测试，外部应用渗透，内部网络渗透，内部应用渗透及其相关直接的联合作用。介绍不同渗透测试的流程、所需要的一般工具及其基本用法。

 

**目标：**全面了解企业级网络信息安全所需的基本架构；学习多种渗透环境下使用的渗透策略、流程、和工具方法。

 

**讲师介绍： **魏克，清华大学网络信息安全研究室高级顾问，CISSP ；曾在实验室参与2011-2012年CTF预选赛；北京三思网安科技有限公司CEO；主要研究网络信息安全体系架构。

![](../Images/49950753b3946f58f76650a0d368f7dd.png)  

  

**培训内容： CTF实践与经历分享**

  

**Kang Li：**李康，佐治亚大学的计算机科学教授，佐治亚大学网络系统和安全实验室（NSS）的主任，DARPA网络超级挑战赛决赛队伍disket领队。他的研究方向是计算机网络和操作系统安全，特别是关于数据安全和隐私安全。

![](../Images/4047b902d272e31199fd66b21b9af7a7.png)  
**课程简介：**主要分为网络超级挑战赛简介、ROP 利用生成课堂实践、CTF实践经历三部分。

  

第一部分将介绍DARPA网络超级挑战赛的基本情况，包控竞赛平台，赛制，规则，以及参赛队伍情况。第一部分内容还包括Disekt战队在过去3年里在网络超级挑战赛的比赛经历。

  

第二部分内容包括对简单堆栈漏洞的利用实践，学员将通过实践来尝试利用ROP组织攻击。实践的问题会因人而异，由浅入深。

  

第三部分将以座谈形式与学员探讨CTF的经历，以及学术和工业界合作的各种经验和问题。

**课程标题：二进制漏洞研究介绍**

  

**课程简介：**介绍二进制漏洞挖掘的工作内容、方式和方法。通过实际工作中的例子，如团队两年参加和备战Pwn2Own比赛的经历，让同学们对二进制漏洞研究工作有所了解。内容包括漏洞挖掘、利用、对抗操作系统和软件的保护机制等等。

  

**期望：**希望能通过该课程，能让同学们对实际的二进制漏洞研究工作能有一个总体的概念和了解。

  

**讲师介绍：**

姓名：古河  

单位：奇虎360

介绍：古河是360Vulcan Team的核心成员。目前在360核心安全事业部负责一支专注于二进制漏洞研究的团队。他的研究方向包括二进制漏洞挖掘、利用、 Exploit和APT检测。在主流浏览器、Adobe Flash、PDF、 Java等软件中发现过大量高危安全漏洞。也曾在多个国内外会议包括BlackHat EU、SysCan、Syscan360、44Con、Xcon上发表过演讲。
