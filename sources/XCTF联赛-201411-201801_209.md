# XCTF特训营开营第一课——XMan生存挑战赛火热进行

8月7日，由教育部高等学校教学指导委员会指导，XCTF联赛发起与总体承办方南京赛宁主办、永信至诚和浙江大学协办的XCTF-XMan“攻防未来”特训夏令营正式拉开序幕。

     学员们来到了祖国的首都——北京，将展开为期20天的网络安全技能学习与实践生活。![](../Images/085294ce6c71ebca23fb1e998dbfea53.png)  

夏令营开始的前一天晚上，老司机们已经开始开车了~~

![](../Images/634e2b536d16e806172ad316628652f0.png)

教室集结，宣读夏令营章程，XCTF-XMan特训夏令营正式开始！  

![](../Images/8a17bc1908334ceed4fec4fc726c3a11.png)  
活捉萌妹一枚^v^

![](../Images/f46c76adbe6815282fca735c03c3685e.png)  

50余名来自全国各地的高校精英汇聚一堂，大合影来一发~

参加夏令营的小伙伴将打乱原有编制，通过抽取扑克进行宿舍分配，在生存挑战赛中，各位营员将通过活动分为六组，展开比拼。![](../Images/43caf7f5933881ea1a4a48fe0fbb253b.png)  

生存挑战赛正式开始，营员们必须为了获得使用手机、空调、网络、甚至是寝室钥匙的权利而不懈努力。  

![](../Images/012b84db1c0a8e2e8ac9709fb114f33a.png)  
黑客大闯关，发动团队智慧通过所有关卡，解锁wifi“补给”~  
![](../Images/30e1f223c8c97fb725f46180a9979ff9.png)  

清华大学副研究员，XCTF联赛创始人、蓝莲花战队领队诸葛老师亲临现场，与各位营员亲密接触，合影留念~

![](../Images/33afbd029a11ea133036c536d0504ffe.png)  
此次XCTF-XMan夏令营特训内容包括：理论知识分享结合实操训练；XCTF联赛及国际知名CTF赛事历届赛题讲解和分析；如何解读和撰写Writeup；自制题库混战与分享，攻防对抗模拟赛等。安全课程覆盖CTF 五大知识技能体系：Crypto／MISC、Web、RE、Pwn、Mobile／IOT。

凝聚XCTF两年的经验和最顶级的平台，培养未来网络空间安全的守卫者。XCTF-XMan“攻防未来”特训夏令营将提升国内高校安全人才整体水平、缩短与国际一流强队技术实力差距，增加XCTF联赛第一梯队战队阵容。夏令营结束后，课程视频将面向高校战队开放，助力高校网络空间安全学科实践教学。
