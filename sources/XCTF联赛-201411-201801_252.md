# XCTF联赛武汉站WHCTF明日开战！

XCTF联赛武汉站WHCTF即将于明天（5月14日）上午十点打响，共计持续36个小时，本站比赛由华中科技大学计算机学院天喻网络空间安全俱乐部组织，赛宁网安提供技术支持，线上比赛将选拔12支国内网络安全队伍，参加于6月11~12日举办的线下决赛，争夺高达3.5万元的奖金，比赛冠军将获得一张**直通XCTF联赛总决赛**的门票，积累联赛积分同样有机会入围最终决赛。

  

2015~2016年度XCTF联赛仅剩最后两站比赛，机不可失，江汉大地等你来战！
