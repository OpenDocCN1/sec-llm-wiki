# 逐鹿中原，谁与争锋 ——XCTF国际联赛郑州站暨赛客杯ZCTF线上赛完美收官

XCTF联赛郑州站暨赛客杯ZCTF线上初赛已于2016年1月24日21:00点顺利结束。本站比赛共吸引了1493个团队共4500多人共同参与。比赛从2016年1月23日至2016年1月24日历时36个小时。ZCTF线上初赛在前期宣传后，各个报名战队都摩拳擦掌积极准备。ZCTF线上初赛于1月23日早上9点准时开赛，经过最开始的准备期后，比赛迅速进入白热化，排名也数次变换。第一天比赛结束时， Nu1L战队暂列第一，六星战队及NeSE战队紧随其后，XCTF联赛福州站国际赛RCTF线下决赛冠军FlappyPig战队及上海交大0ops战队暂列4、5位。可仅仅一天的比赛不足以确定最终的结果，各个战队也都认真的对一天的比赛进行总结。经过一晚的离线分析，FlappyPig战队战果丰硕，在第二日比赛平台重新开放后，FlappyPig战队迅速提交多道高分值题目Flag,迅速反超至第一位，同时在第二比赛日的绝大部分时间里稳居首位。

![](../Images/090a7035d6bd18c016d9c1fb923ed7b5.png)  

比赛在临近结束20分钟时进入高潮，各个战队分别使出自己的杀手锏，比赛排名也在不断的改变。最终多高校联合的Nu1L战队以出色的表现获得第一名，FlappyPig战队则以微弱差距获得第二名，第三名被浙大AAA战队获得（最终结果将在主办方审核完成后正式公布）。本次郑州站比赛在河南省内乃至全国范围内得到了强烈的反响，吸引了河南省内的十余支高校队伍积极参加，其中FlappyPig战队实力尤为强劲。

![](../Images/06ea73a1f40e81724e5a7ba27258cb42.png)  

本届ZCTF作为河南省首次举办的全国网络安全技术对抗比赛，以及ZCTF联赛的“一带一路”赛程设计中的重要一站，得到了XCTF联赛组委会的强烈支持和指导，同时本次比赛在河南省内也受到了政府单位的广泛支持和社会各界的广泛关注。本次ZCTF“赛客”杯网络安全对抗赛是由河南省工业和信息化委员会、河南省教育厅、河南省公安厅、河南省网信办，中国保密协会指导，河南省信息安全保密协会、云安信息安全产业联盟、河南省软件服务业协会主办，河南赛客信息技术有限公司承办，河南省高等学校计算机教育研究会、河南省电子商务协会、河南省民办教育协会、河南省电子商会协会、郑州市信息化促进会协办。

第二届XCTF国际联赛由网络空间安全人才发展基金主办，国家创新与发展战略研究会联合主办，南京赛宁信息技术有限公司总体承办，规划由国内外八站选拔赛，以及南京总决赛和北京全明星赛等系列赛事组成，整个赛季将从2015年11月份延续到2016年8月份，设置超过百万元的总奖励池。第二届XCTF国际联赛已获得百度云安全的钻石级（顶级）赞助，联赛同时获得威客安全、众人科技、通付盾、启明星辰的金牌级赞助支持。

![](../Images/6ca0a76d0ee9c7383729117cd7df7a05.png)

本次XCTF联赛郑州站比赛(ZCTF)线上赛的成功举办，为河南地区线下赛及未来网络安全技术对抗比赛的举办奠定了良好的基础。同时ZCTF线上赛吸引了各大高校学生、网络安全从业者以及网络安全技术爱好者的参与。本次比赛的举办得到了河南省内教育界各方力量的重视，为河南高校网络空间安全人才的培养提供了强大的推动力。

     第二届XCTF联赛郑州站比赛暨“赛客”杯网络安全对抗赛线上初赛已经结束，共将决出10支强队，线下决赛还会邀请几支国内顶级战队前来参战。“逐鹿中原，谁与争锋”，ZCTF比赛是一场强者之间的比拼，一场智者之间的较量，让我们拭目以待即将举行的线下决赛。
