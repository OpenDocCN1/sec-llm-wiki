# 进入DEFCON CTF全球总决赛前六的三支中国战队揭秘

被誉为黑客领域“世界杯”的DEFCON夺旗赛总决赛再次在拉斯维加斯上演巅峰对决。全球顶级黑客战队在这里炫技，上演精彩的攻防“秀”。DEFCON CTF总决赛的舞台是每一位CTF成员心中的圣地，类似于足球运动员的世界杯，是团队之间的体力与智力的癫狂对决。不同的是“足球”换成了攻击代码，CTF赛中想要得分必须挖掘网络漏洞攻击对手服务来得分，CTF选手也可以通过修补自身服务漏洞来避免丢分。

作为历史最悠久的网络安全技术竞赛， DEFCON CTF每年都会通过线上资格赛选出最优秀的战队，在拉斯维加斯进行线下决赛决出年度最强CTF战队。作为一名黑客，能够获得站上国际舞台与全球顶尖的黑客分享交流的机会，是绝大多数的黑客的梦想。就有这样一群黑客为了梦想，为了竞技，为了分享交流而来。来自中国的XCTF网络安全技术对抗联赛（以下简称：XCTF联赛）总决赛命题组织者百度\-蓝莲花战队第三次入围全球总决赛，XCTF联赛总决赛冠亚军获得者HITCON、0ops刚刚打完XCTF联赛，就马不停蹄走上另一个战场，前往拉斯维加斯参加全球最高级别的CTF夺旗赛—第23届DEFCON CTF总决赛，三个战队凭借比赛中的良好发挥，全部杀入DEFCON CTF总决赛的前六强。

![](../Images/06e24816b5a09c7d798eba13a26b09f3.png)  

 Blue-lotus（百度-蓝莲花）战队成立于2010年，是一群热衷于网络安全技术的爱好者组成的“白帽子黑客”团队。战队领队诸葛建伟，是清华大学信息与网络安全实验室副研究员，队员以学生为主，除了有来自清华大学计算机系、软件学院、信息与网络安全实验室的的学生外，还有全国其他院校的学生以及国内安全公司的技术精英。蓝莲花是华人世界第一支并连续三次打进代表全球最高网络安全技术水平的顶级黑客大赛-DEFCON CTF的战队，是中国网络安全届的骄傲！同时蓝莲花将CTF赛制引入中国，和国内其他兄弟战队一起，支持南京赛宁组织了全国最大规模的CTF比赛-XCTF联赛，为中国网络安全攻防实战的提高做出了重要贡献。

![](../Images/447acfc8b0d51be4ddc4c29b049af011.png)  

 HITCON战队 是来自中国宝岛台湾的队伍，主力为由台湾大学学生组成，参与XCTF联赛中的217战队，在由南京赛宁总体承办的首届XCTF联赛总决赛中荣获冠军，并通过在Boston Key Party大满贯赛的亚军，获得入围DEFCON总决赛资格，HITCON是台湾地区首次入围DEFCON CTF决赛的队伍，在本次总决赛中获得第四名的优秀成绩。。

![](../Images/82165bf68815a97c6f131961085aefd1.png)  

0ops战队成立于2013年9月，成员均来自上海交通大学，因为对安全的共同兴趣而聚在了一起。在由南京赛宁总体承办的首届XCTF联赛中组织了上海站选拔赛0CTF，并在XCTF总决赛中以微弱比分差距，在台湾大学217战队之后屈居亚军。今年0ops战队首次通过资格赛闯入DEFCON CTF全球总决赛，并携手国内老牌CTF强队蓝莲花战队进军“黑客世界杯”。在Defcon CTF总决赛中，0ops战队克服了全球总决赛参赛经验不足等困难，从第一天的排名靠后奋起直追，最终以首次参赛第六名的优秀战绩，在国际赛场上赢得了中国战队的荣耀。
