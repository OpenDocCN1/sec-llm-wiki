Android Root —— 一场没有止境的对抗

王宇 - 某著名国际网络安全公司 研究科学家

议题概要

随着移动互联网的发展，Android 设备的安全性日益受到人们的关注。作为设备权限的制高点，Root 和 Anti-Root 的攻防将成为一场没有止境的战争。本议题将和您探讨诸如 SELinux 机制、PXN 防护、Kernel ROP 等 Android Root 攻防过程中的防御机制与攻击技巧，向您展示这魔高一尺道高一丈攻防对抗的乐趣。

演讲嘉宾介绍

王宇热爱与操作系统内核有关的一切事物，从内核架构实现、驱动程序编写、Rootkit/Anti-Rootkit 到漏洞挖掘与利用、Android Root 等。目前他任职于某知名网络安全公司从事漏洞挖掘与 APT 识别相关的工作。他曾在 SysCan360 2012/2013、Hitcon 2013、BlackHat USA 2014 等会议发表过演讲。


面向触屏终端输入的盲识别攻击

凌振 - 东南大学讲师，博士

议题概要

在这个报告中，我们将介绍在看不到终端屏幕内容的前提下，从拍摄的视频中获取终端用户通过触摸屏输入的内容。在我们之前的工作中，我们在一定拍摄范围内可高效的获取终端用户输入的随机密码。随着距离增加，成功率将降低。但在输入有意义的内容时，如撰写的电子邮件，由于内容中具有文字拼写、语法及上下文内容等信息，我们可利用自然语言处理技术进一步提高成功率。从视频中获取输入内容可建模为噪声信道，我们先为输入的每个单词选取一系列候选单词，然后采用隐性马尔可夫模型对整个输入内容建模，应用三元语言模型获取最终的输入内容。我们通过大量的实验验证了该技术的可行性和有效性。

演讲嘉宾介绍

凌振，东南大学计算机学科与工程学院讲师，于2005年和2014年分别在南京工程学院和东南大学获得学士学位 和博士学位。他的主要研究方向是智能手机，网络安全，隐私保护和网络取证。2008年8月至2009年11月，他在香港城市大 学计算机科学系任副研究员参与网络安全相关研究工作，2011年8月至2013年8月，他以访问博士研究生身份加入加拿大维多利亚大学计算机系从事相关研究工作。 他参与了多项国家和部、省级科研项目并在学术会议和期刊发表了论文,其中包括国际高水平学术会议ACM Conference on Computer and Communications Security (CCS)，IEEE International Conference on Computer Communications (INFOCOM)以及期刊IEEE/ACM Transactions on Networking (ToN), IEEE Transactions on Dependable and Secure Computing (TDSC), IEEE Transactions on Parallel and Distributed Systems (TPDS), IEEE Transactions on Computers (TC)。他的研究成果在BlackHat及中国互联网安全大会 （ISC）上陈述。他 是IEEE、ACM、CCF会员并担任各种会议的程序委员会委员，包括 INFOCOM,ICCCN,HPCC,ChinaCom,WISA,BigSecurity 等。
