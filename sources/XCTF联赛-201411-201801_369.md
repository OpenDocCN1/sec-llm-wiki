# XCTF联赛上海站0CTF决赛圆满落幕，217、Blue-Lotus、FlappyPig战队分获冠亚季军

XCTF联赛上海站0CTF线下决赛今天下午1点正式落下帷幕，经过2天的激烈鏖战，最终来自台湾大学的217战队凭借强大的攻防实力，以及对0CTF赛制和竞赛规则的熟悉，从比赛开始就一路领先，毫无悬念地以大比分领先优势夺冠。清华/浙大/杭电选手联合组队的Blue-Lotus蓝莲花战队、来自多所高校联合组成的FlappyPig战队，进行了激烈争夺后，分获亚军、季军。

 ![](../Images/6efe5b5423c2d0819be5298eda60cc4d.png)  

今天上午8：30分比赛战火重新点燃，各队先后投入战斗之中，由于217战队领先第二名FlappyPig太多（昨天比赛结束时的排名），夺冠只是早晚的事情，已变得毫无悬念。冠军奖品包括无人机、1080p高清投影仪、NAS、Kindle、西普学院VIP课程券、博文视点网络安全畅销书籍等，价值1.3万元。

 

![](../Images/3d416be3f3e8e6e532a65adbfdc5cb12.png)  
冠军217战队领奖

 

今天赛事的看点来自于亚季军的争夺战，blue-lotus（蓝莲花）战队一上来就开始发力，很快解出了droidpwner题拿到2个flag得到600分，其原本与FlappyPig的分差就很接近，这一轮的加分使其升到了第二位。随后，blue-lotus战队率先找到NFTP服务0day漏洞，疯狂刷分，迅速拉开与FlappyPig的差距，以此奠定亚军地位。

  
![](../Images/0bbde35c6d53d0b775e1ada516c695dd.png)  

最终积分排行榜

  

尽管FlappyPig随后奋起直追，droidpwner题也有斩获，无奈剩下的时间已经不多了，难以撼动blue-lotus。亚军和季军均获得价值0.7万元奖品。

比赛结束前1个小时，4~6名的排位赛竞争也十分激烈，最终来自福州大学的ROIS获得第4名，Freed0m、武汉大学Dawn分别获得第5、6名。新竹交通大学Bamboofox、乌克兰在华队伍dcua等队伍则获得鼓励奖。与冠亚季军共同分享了总价值六万元的0CTF决赛奖品。

小编在赛后与各位选手交流，复旦的“\*\*\*\*\*\*”战队由于队长兼主力身体欠佳，未能出席决战使得团队实力降低了不少。该队一名队员还表示，不太适应现场有背景音乐的环境，影响了发挥，战队最终以第10名收场。不过大家都挺享受比赛的过程，表示这次参与线下决赛的收获很大，增进了现场比赛的临场经验。离开赛场时大家都将自己的队旗收起来，作为纪念。

两位老外帅哥由于连续作战比较疲惫，婉拒了现场的视频采访，好遗憾啊。细心地妹子发现没有，他们形象发生了很大的改变。昨天一位还胡子拉扎的，今天全变没了哇，变得更加帅气了。

![](../Images/b98052cba3773bc4f5c7702fca040ece.png)  
  

随后的颁奖典礼上，上海交大信安学院李建华教授在致辞中表示，通过举办信息安全竞赛是人才培养非常重要的环节，参赛选手从竞赛过程中得到灵感和收获，同时成也为信息安全业界挖掘人才的一条重要路径。

![](../Images/cb107d303fdfbe53b83942cb89063d4b.png)  
李建华教授

  

上海市经信委安全处刘山泉副处长在发言中提到，上海非常重视信息安全竞赛，早在2009年起就开始举办ISG信息安全技能竞赛，经过这么多年来得发展，如今已经发展出CTF技术挑战赛、运维管理赛、知识赛、创意赛等四大赛事，打造出多层次的竞赛体系。同时，他希望本次竞赛的选手们将来把创新创业的起点放在上海，将上海打造成信息安全人才的新高地。

![](../Images/6a5a0d958d1aad6628ab2862eb650733.png)  

刘山泉副处长

 

上海信息安全行业协会会谈剑峰在会上热情洋溢地说，作为最早从事信息安全的一批人，深知人才才是最重要的，通过竞赛能够发现和挖掘出安全人才。上海是安全的热土，希望选手有机会到上海来创业。

![](../Images/3ee661543b2ae3b8e5e187c49a264dfc.png)  

谈剑峰会长

 

颁奖典礼结束后，GeekPwn公开课正式开讲。第一个分享嘉宾是KEEN COO 吕一平。他介绍了KEEN 参加 Pwn2Own 的来龙去脉，去年GeekPwn活动中让人大吃一惊的研究成果，以及未来车联网智能生活面临的安全风险。随后KEEN安全专家吕礼胜在GeekPwn公开课现场进行了令人惊叹的互动演示，并分析了漏洞利用的原理。毕业于上海交大的陈良，也在公开课上分享了其在安全研究的成长历程。与KEEN组队参加Pwn2Own并取得PDFReader项目优胜的腾讯高级研究员吴军分享了征战Pwn2Own的历程。

  
![](../Images/ed20c15a3b81383fc120f2019b29760d.png)
