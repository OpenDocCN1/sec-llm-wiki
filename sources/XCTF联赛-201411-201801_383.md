# XCTF联赛成都站落幕 L1ght战队逆转夺冠

12月7日，XCTF全国网络安全技术对抗联赛成都（成信）站选拔赛落下帷幕。经过36小时不间断的线上激烈比赛，多高校联合的L1ght战队从659支战队中脱颖而出，以3205分赢得本次分站赛冠军，并获得直接入围XCTF总决赛的资格。多高校联合的“万达集团”战队和复旦大学的六星战队分别以3060分和2880分，获得本站亚军和季军。

![](../Images/a167435477d2503a2ab87d05b326a16c.png)

XCTF联赛成都（成信）站最终积分榜

据了解，XCTF联赛成都（成信）站选拔赛共有659支战队报名参赛。与杭州（杭电）站采取线上选拔赛和线下决赛不同的是，此次由三叶草安全小组承办组织的成都（成信）站选拔赛采用线上解题形式，题目形式接近于实战，主要考验参赛选手Web安全、渗透测试、漏洞挖掘、逆向分析、取证分析、安全编程等方面的网络安全技术。

![](../Images/fa8d7fe044b668d70fe855e6c3387cd0.png)

XCTF联赛成都（成信）站结束后诸葛建伟博士与组织方三叶草安全小组合影

  

参赛队伍的增多，也让比赛更加激烈。开赛一小时，就有160支战队得分，三小时后，已有228支队伍取得分数。经过下午短暂的沉寂，各支战队进入“解题模式”，连续解开高分题，榜首位置也数次易主。

最后经过36小时不间断的激烈比赛， L1ght战队凭借在比赛后半程的优异表现，以3205分逆转夺得成都（成信）站选拔赛的冠军，以及2万元等值奖品的奖励，成为第二支直接入围XCTF总决赛的战队。L1ght战队在XCTF联赛首站杭州（杭电）站获得亚军，本站夺冠后以168.99分在XCTF联赛积分榜上占据第一的宝座。

 

联赛总体组织方清华蓝莲花战队诸葛建伟博士介绍道，成都（成信）站作为首届XCTF联赛的第二场分站赛，参赛队伍比首站更多，竞争也更激烈，冠军的悬念几乎保持到比赛最后时刻。随着成都（成信）站的结束，首届XCTF联赛2014年度的比赛也将告一段落，下一分站选拔赛北京（清华）站，将在2015年3月14-15日举行。

 

北京（清华）站选拔赛由安全宝-蓝莲花战队承办组织，安全宝-蓝莲花战队刚刚在澳大利亚9447战队举办的9447 Security Society CTF国际赛事中斩获季军，并在与XCTF联赛成都站选拔赛同期举行的日本SECCON CTF国际赛事中与上海交通大学0ops战队携手入围决赛，将于明年2月份共同代表中国大陆出征日本东京，与美国PPP、中国台湾HITCON、日本binjia等国际著名CTF战队同场竞技。安全宝-蓝莲花战队、上海交通大学0ops战队将充分吸收国际CTF赛事举办经验，并着手办好XCTF联赛北京（清华）站与上海（上交）站选拔赛，为国内选手们呈现更高质量更加完善的XCTF联赛赛事。

 

据了解，首届XCTF联赛旨在发现和培养安全新人才，并通过比赛搭建企业和大学之间的桥梁。赛事共由五站选拔赛组成，最终会有12支战队晋级最后的总决赛。其中5支获得选拔赛冠军的战队，能直接入围总决赛，剩余7个决赛名额，将在分站选拔赛全部结束后，从选拔赛积分排名靠前的队伍中选出。

 

晋级XCTF总决赛的12支队伍，将有机会争夺最后的冠军，以及10万元现金大奖。在奖金之外，优秀选手还能进入特训夏令营，中国顶级黑客天团KeenTeam核心技术成员将提供技术指导与培训，并支持优秀选手备战DEFCON CTF全球总决赛。

 

值得注意的是，Keen Team作为XCTF联赛选手的安全导师，刚刚成为Google Project Zero亚洲第一个正式合作伙伴，将与来自全球各地的顶级黑客一同保护网络空间的安全。未来派出核心技术成员参与XCTF联赛特训夏令营，也将为国内年轻一代网络安全技术人才带来最先进的技术指导和安全理念。 

除此以外，由Keen Team设立的GeekPwn联合实验站也在全球陆续开放。12月5日，长沙实验站开幕，将通过定期举办技术沙龙等活动，为安全技术爱好者们提供专业指导和技术交流的机会。
