# 赛事重启！第五届“强网”拟态防御国际精英挑战赛重磅归来！

突如其来的疫情打乱了我们的脚步，因疫情防控原因，大赛组委会将赛事按下暂停键。在此期间，特别感谢所有参赛选手对赛事延期的理解与支持。

  
今天，承载着大家的关注和期望我们迎来了赛事重启！经过组委会多方确认**第五届“强网”拟态防御国际精英挑战赛****将于12月15日-18日以线上赛形式****重磅归来！**  

目前，赛事筹备工作正在有条不紊的推进中，我们相信即使面对重重困难，大家仍然坚守本心，斗志昂扬带着对CTF的热爱，让我们重聚紫金之巅！重启巅峰之战！
