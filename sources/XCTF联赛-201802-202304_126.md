# 第七届XCTF国际联赛开幕赛RCTF圆满落幕,Nu1L战队夺冠!

2021年9月13日09:00，第七届XCTF国际网络攻防联赛开幕赛RCTF 2021 国际赛圆满落幕。本场赛事由XCTF国际联赛主办，福州大学ROIS战队组织，赛宁网安提供平台支持。本次赛事吸引来自全球的**68个国家和地区****，****756支**战队参赛，**1980人次**参与赛事，其中**483支****战队**成功签到，共同参与这场国际盛宴，角逐冠军之位。  
  
RCTF 2021 分站赛是XCTF国际联赛与ROIS战队第六次合作，作为多次合作的老搭档，此次ROIS战队的出题师傅们延续以往高水平的出题品质，为选手们呈现了一场**趣味与质量并重的国际化CTF竞赛**。在持续**48****小时**的激烈厮杀中，来自全球各地的CTF高手们全力以赴，将放出的31道赛题一一破解，但仍有多道高难度赛题仅被个别几支战队成功破解。  
![](../Images/e802eacb7e108b7d40d997d1ca2953ee.png)赛事结果以WP审核通过后为准  
最终**联合高校Nu1L战队**成功解出31道赛题，以18797的积分排名第一,斩获七届XCTF国际联赛总决赛直通券；该战队以前三血战绩解出的赛题达到**22道**，占比全部解出赛题的70%，同时也是全场唯一一支**“完美All Kill”**的战队。  
  
![](../Images/cd7d4d4caa34393c1b19af3a79b59f48.png)  
**上海交通大学0ops战队**成功解出26道赛题，其中2道赛题获得“一血”成就，该战队在Re类赛题方向展现了相当优异的能力，累计得分14398，排名第二；**浙江大学AAA战队**成功解出25道赛题，该战队在距离赛事结束1分钟时成功解出一道赛题并完成提交（这手也太帅了吧![](../Images/febdd8b5cae4139d1ba0e19cfca36ea0.png)），最终得分13648，排名第三。**南京邮电大学X1cT34m战队**在各方面都表现的相对均衡，成功解出22道赛题，累计得分11218，排名第四。作为唯一入围前五的**国际战队Kalmarunionnen**， 成功解出19道赛题，累计得分8494。  
值得一提的是，CTFTIME 排行榜位于前列的的各大国际战队例如：**Super Guesser、zer0pts 、kalmarunionen、justCatTheFish 、P4、dragonsector**等均参与到本次RCTF 国际赛，并取得了相当不错的成绩。

**赛况回顾**

![](../Images/e802eacb7e108b7d40d997d1ca2953ee.png)

  

**比赛一开始****，**竞争就比较激烈，SU 战队及 X1cT34m战队 分别 斩获全场赛事“ WEB 类赛题 Easyphp 及 CandyShop 一血！

  

**随着赛程的推进，截止至9月11日15:00，**联合战队Nu1L一往无前，3小时内成功提交6道赛题flag，强势占据排行榜第一;联合高校SU战队排名第二，北京邮电大学天枢Dubhe战队排名第三；NBL战队及国际战队SuperGuesser分列第四、第五；第五至十名被国内各单一高校战队包揽。

  

**赛程推进至1/4，**Nu1L战队保持排名领先，与排名第三的0RAYS战队一同AK目前放出的MISC类赛题；浙江大学AAA战队突出重围成功跻身排行榜第二之位。截止至21:00，前十榜单由中国战队占据八席，国际战队SuperGuesser、zer0pts排名分列第八及第十；前20榜单中，来自华中科技大学的L3H\_Sec战队在2小时内连续提交5道赛题flag，开启夺分模式。

  

![](../Images/d4ab4e091a854280b20b1f3f728c8bb3.png)

  

**经过24小时的角逐，**Nu1L依靠前期建立的优势稳坐排名榜一之位，浙江大学AAA战队排名第二，上海交通大学0ops战队排名第三，杭州电子科技大学0RAYS战队排名第四；国际战队Kalmarunionen把握赛场时间差，顺利解出12道赛题斩获排行榜第五之位。值得一提的是上海交通大学 Ph0t1n1a战队也实现突围，成功解锁排行榜前十之位。

  

**截止****至****9月11日****18:00****，**赛场排名争夺进入白热化阶段,Nu1L战队自开赛3小时后即开启霸王庄模式，以高积分差稳坐榜一之位；0ops战队与AAA战队一直呈现为胶着状态，两队同时在Web类赛题中表现得相对较弱，这也可能是接下来两队角逐中的局势演变关键点；四-十名的排位争夺则显得尤为激烈，得分相当接近。

  

**赛程推进至3/4，**排行榜前四战队未出现明显变化，复旦大学\*\*\*\*\*\*战队凭借一道高分值赛题跃居排行前五之列；榜单六-十名的争夺中，0RAYS战队迟迟未进入解题状态，依靠前期积累的得分优势保持排行榜前十之列；国际战队Super Guesser连续提交2道赛题flag，杀回排行榜前十。

  

最终，联合高校Nu1L战队斩获本场赛事排名第一，0ops、 AAA战队分列二三。

  

**RCTF 2021 冠军战队介绍**

![](../Images/7727fcfc6c239e0133b44231fed50d2d.png)

Nu1L战队是国内顶尖CTF联合战队，成立于2015年，队名源于英文单词“NULL”，《从0到1：CTFer成长之路》作者团队，目前成员70余人，队员分布于清华大学、上海科技大学、中科院信工所、复旦大学、南京邮电大学、乔治亚理工学院等国内外各大高校，也分布于阿里、腾讯、华为、Google等国内外安全大厂。

 

Nu1L战队的成员都对信息安全以及CTF比赛有着浓厚的兴趣，如取得2019年护网杯冠军、第五届XCTF国际联赛总决赛冠军、2020年全国工业互联网安全技术技能大赛冠军，于2021年闯入DEFCON CTF决赛并获得全球第七名，除了收获国内外各类CTF比赛优异成绩之外，Nu1L还是N1CTF以及空指针挑战赛发起者，同时也是成都“巅峰极客”决赛“广诚市”三年场景设计者。成员有参加Pwn2own、Geekpwn、天府杯的安全研究员，同时也有HITCON、KCON、Blackhat、天府杯等国内外安全会议演讲者。
