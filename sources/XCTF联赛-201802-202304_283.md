# De1CTF2019国际赛圆满落幕，血霸Whitzard战队问鼎冠军

北京时间8月5日上午9点，第五届XCTF国际联赛分站赛——De1CTF2019国际赛宣告圆满落幕。此次赛事由De1ta战队主办，赛宁网安提供技术支持，8月3日上午9点比赛正式打响，共放赛题28道，历时48小时后完美收官。复旦大学Whitzard 战队解答出23道题目得分11226位列第一；上海交大 0ops战队解答出21道题目得分9117排名第二；中国台湾Balsn战队解答出20道题目得分8852排名第三；联合战队NU1L战队解答出18道题目得分7559排名第四；Chamd5的Venom战队解答出17道题目得分7016排名第五；AAA战队解答出16道题目得分6569排名第六；W&M战队解答出17道题目得分6526排名第七；天枢战队解答出17道题目得分6169排名第八；Vidar-Team战队解出题目16道得分5039排名第九；bi0s战队解出题目16道得分4947排名第十；恭喜以上这十只战队！同时也非常感谢华为、天融信、陌陌安全、红帽安全实验室对De1CTF的赞助与支持。

**喜提7个一血稳居榜首的血霸**

赛事第一天，D0g3拿到了赛题【xorz】一血，天枢拿到【Weapon】的一血，C4M31拿到了赛题【Mine Sweeping】、kn0ck拿到了赛题【Re\_Sign】的一血；Whitzard战队虽然没在比赛开始拿到一血，但是并未受到影响，11：06Whitzarb拿到赛题【Babylfsr】一血，Whitzarb持续提交flag排名跃居到榜首第二，此后排名一直在榜首前三的位置上下浮动。

![](../Images/605e604c510ccdcce8398580e1943931.png)

（赛事最终结果将在审核WP之后发布）

  

通过趋势图可以看出Whitzard战队一直在稳定的提交flag，从比赛第一天12点开始，Whitzard战队就一直稳居排行榜榜首，最终拿到了赛题【Easy EOS】、赛题【Babylfsr】、赛题【Race】、赛题【Evil\_boost】、赛题【Signal vm Δ】、赛题【9calc】7个赛题一血，两个赛题二血，六个赛题三血以总分11226高分拿下冠军。Whitzard战队是本届De1CTF当之无愧的血霸。

本次赛事共有来自77个国家和地区的1362个队伍签到，覆盖全国35个省级行政单位。参赛群体较多的还有美国、印度、韩国、俄罗斯、日本、越南、法国、新加坡等地。国内外的重量级明星战队均有到场，例如，来自美国Shellphish战队、日本TokyoWesterns战队、乌克兰Dcua战队等等，这些明星战队的到场也让不少战队感受到了压力。

0ops战队、Balsn战队、NU1L战队、Venom战队、AAA战队、W&M战队、天枢战队、Vidar-Team战队、bi0s战队一直紧随其后，前十名的战队不断更迭，但不管其他战队如何追赶，Whitzard战队依然稳坐在榜首的位置；赛事全过程中，flag提交次数达3841次，其中正确提交达1917次。

XCTF联赛办到第五届，影响力与日俱增！当然能取得如此成绩，得益于来自各方的支持与自身努力，尤其是赞助商华为、陌陌安全、天融信对第五届XCTF国际联赛的大力支持。作为XCTF联赛的技术支持方，赛宁网安在历经百余场赛事的考验与历练之后以其更加成熟，稳定的特质被业内所认可。
