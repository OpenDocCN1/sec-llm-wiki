今天我们采访到的就是由六名第三届XMan学员组成的Can't_RCE战队，来与我们分享他们的大佬进阶之路。

Can't_RCE战队的六位成员

问：先介绍下你们战队的成员吧，你们是怎么认识的呢？

答：我们战队6个队员的相识都是始于XMan，我们都是在18年8月参加了第三届XMan夏令营认识的，有在深圳营学习二进制的（Art3mis、lego），有在南京做WEB深造的（She1don、@Y2pj），也有在天津主攻密码学的（米饭，HWHXY）。

问：你们战队现在主要的日常是打CTF还是挖洞呢？目前取得了什么成绩？


答：虽然在XMan的学习CTF和漏洞挖掘都有涉及，但是我们几个都对漏洞挖掘的课程比较感兴趣，所以我们都在后续的路上走向了SRC赏金猎人的道路，对了，上一届XMan赏金猎人前三名都在我们这里～

所以我们战队目前的日常主要是挖漏洞，偶尔做一下CTF看题选手，学习下最近有什么新的姿势，让自己的思路不会被局限。成绩的话，我们现在已经在各个SRC中都已经榜上有名了，前段时间的阿里大学生网络安全竞赛，我们队伍也是拿下了全国双冠军的好成绩。

问：战队的名字Can't_RCE有什么意义吗？

答：为什么叫Can't_RCE呢？RCE是一种漏洞类型，远程代码执行哦（Remote Code Execute）的缩写，我们因为都是SRC新手，还没有在大厂中遇到过RCE的漏洞，我们队伍的理念就是：一起挖洞，共同进步！

问：当时来XMan是从哪里获得的消息，当时家里人支持或者是了解吗？

答：我们是在之前去了XMan的师兄那里了解到了XMan夏令营，他强烈安利了我们去XMan，后来我和学校里另一个师傅就一起去了深圳营。一开始跟父母讲这件事的时候，父母支持倒是支持，但是他们总有那么一点担心我被什么“无良”机构骗了，我细心的跟他们解释了XMan是来自于XCTF的夏令营，管我们夏令营的老师是诸葛建伟，以前是带清华大学打网络安全比赛的老师，我们很多比赛都是XCTF来做技术支持的，平台可靠，人员可靠，打消了他们的顾虑。

（想起了去年打电话问我们是不是做传销的那个家长，后来也是经过多番讲解，终于放心地把娃托付给我们了）

问：怎么向家里或者是身边的人解释自己现在做的这个事情呢？

答：跟家里人讲的是，现在在搞一个叫CTF的网络安全竞赛，业余帮企业挖漏洞，赚点外快，从事的是正规行业，可以简单把我理解跟那些做杀毒软件的是一个行业，安全行业；给师弟师妹做介绍时一般就是，大家好，我是一名黑客，没错就是黑客，只是我是一名正向的黑客，白帽子黑客；跟同学解释就说在搞网络安全竞赛，业余帮一些公司做安全测试赚外快，不会破解游戏，不会盗QQ，不会修电脑。

问：在XMan夏令营都学习了什么，有没有什么印象深刻的事情？XMan对你们的技能提升有起到什么帮助吗？

答：在XMan学习了很多CTF的解题技巧，以及很多大佬分享的学习、挖洞、研究的经验，这些都是非常有价值的。印象深刻的事情大概就是有一天因为睡得有点早了，被某大佬嘲讽不努力，可能那个时候才意识到，做安全还不只需要兴趣就能做好的吧。XMan对于技能的提升是有实质性的帮助的，自己摸索的不够全面，XMan带给我的更多的是更加全面的看到CTF的各种边边角角和奇思妙想。

问：XMan对你们来说有什么特别的意义吗？

答：XMan对于我们来说的特别的意义大概就是，认识了RCE的成员们，说不定以后发大财就靠他们了。

问：作为一名老XMan，对新一届的XMan学员有什么想说的吗？ 

答：在XMan的日子将会成为你们记忆中非常难忘的一段美好的回忆，在这里你会遇到一群志同道合的朋友，可以一起开心的聊技术，互相分享，甚至可以创建起自己的小团队在今后继续合作下去，希望大家珍惜这段日子，努力学习，成为更好的XMan。

问：你们好像6个人都不在同一个城市，平时怎么联络交流感情呢？

答：平时我们一般都通过QQ群交流,日常以吹水为主,挖洞为辅.然后会交流一下漏洞挖掘的思路。

问：今后战队的道路怎么规划的，会一直坚持打CTF或者是挖漏洞吗？ 

答：今后我们战队还是会以挖洞为主，如果有多余的时间可能会参加一下CTF比赛。也会定期在我们的公众号上分享一些心得，大家可以关注一下，里面有很多的干货哦！
