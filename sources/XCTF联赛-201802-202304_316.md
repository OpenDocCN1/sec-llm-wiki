# 《ROIS战队和W4terdrop战队收获大学生国赛区域赛第一》

6月22日-23日，由赛宁网安提供竞赛平台支持的第十二届全国大学生信息安全竞赛创新实践能力赛——华南赛区（广州）、华东南赛区（苏州）成功举办！

赛事由教育部高等学校网络空间安全专业教学指导委员会主办，华南赛区由广东外语外贸大学网络空间安全学院承办，华东南赛区由复旦大学承办，赛宁网安提供大赛平台支持。

**创新BBF赛制，推动实践型人才培养**

在国内长期推动CTF，做到“以赛促学、以赛代练”的同时，依照高校教学特点以及企业用人需求，进行创新，开创性的提出了BBF（Build、Break、Fix）的开放命题攻防赛制。

首先要求入围队伍在设定场景下对安全应用开发和安全挑战进行设计，也就是Build环节；随后在分区赛中进行攻击破解的Break环节和运维加固的Fix环节。最终进入总决赛的优胜队伍还会设置分享（Share）环节，进行创新安全挑战设计思路的分享交流。

通过BBF赛制，能够更加全面锻炼网络安全学生的创新思维和安全防护能力，避免了过分引导攻击能力而忽视其它评估维度。

 

**华南赛区 广州高手云集**

本届赛事华南赛区包括广东、广西、海南、香港、澳门。线上初赛，华南赛区报名踊跃，205支队伍，859人报名参赛。经过初赛，共产生59支队伍,共314人进入本次的华南分区赛。

广东外语外贸大学党委常委、副校长王廷惠表示，高校网络安全人才培养需要集合各方面力量共同发力，需要更多实战性的高水平赛事来促进人才培养，以赛促培，以赛代练。

广东外语外贸大学党委常委、副校长王廷惠

赛事第一天，在Break环节，参赛队伍需要尝试突破其他赛区队伍和平台方命题的网络安全挑战题目，攻击获取Flag并向平台提交获取得分。题目分为Web安全漏洞利用、Pwn二进制网络服务漏洞利用及Mobile移动服务漏洞利用三种类型。开赛半小时，在09:32:07，广东警官学院的X10sec战队拿到了Pwn题的一血，广州大学的SSSS在10:20:50拿到了Web题的一血。

赛宁网安竞赛平台（CP-AD）对于每个题目环境，通过容器动态生成题目交互环境，保证题目环境的安全隔离和自助式运维，有效提升竞赛的公平性和选手体验。

![](../Images/41f86fbcb5777bcfb00c3f2ea2a17795.png)华南赛区赛场

当天下午Fix环节，各战队开始对各自的题目环境进行漏洞检测和加固，以保证业务功能正常运行前提下避免被攻击为评估标准，通过平台的自动检测获取加固阶段分数，当天来自深圳大学的Aurora(2256分)、中山大学的WaterDrop2(2012分)、中山大学W4terdrop(1941分)位居加固排行榜三甲。

6月23日，大赛仅剩下半天时间冲刺，竞赛更为激烈。现场各个战队紧追不舍。最终在Break环节由中山大学的W4terdrop、广东外语外贸大学的广外女生Ⅲ、广东警官学院X10sec排名三甲。

![](../Images/be6a3c219644eb19415012ae6cd8ac48.png)华南赛区解题排行榜

Fix环节由海南大学c4t3、中山大学的W4terdrop、深圳大学的Aurora排名三甲。

![](../Images/7c644b4c49a4287d38c9c34ff33586c6.png)华南赛区加固排行榜

综合Break和Fix两个环节成绩得分，最终，中山大学的W4terdrop以79分获得现场环节第一名，广外女生Ⅲ以70.66分获得第二名，暨南大学Xp0intJNU以66.9分获得第三名。从成绩上看华南赛区三甲追赶十分激烈，成绩相差不大。  

 

**华东南赛区 上演精彩对决**

本届华东南赛区落地在风景如画的苏州，华东南赛区开始时间为上午10点整，福州大学ROIS战队再次展现超强实力，在10:28:37获得web题目的一血。浙江工商大学 Na!战队在10:29:44获得babypwn一血。

  

![](../Images/9d7293e052e4b2817e2d409db73bd6e1.png)

华东南赛区现场

顺便说一下，来自福州大学的ROIS战队今年上半年势头劲猛，发起的XCTF分站国际赛RCTF备受好评，在第二届强网拟态防御国际精英挑战赛中又力压群雄，获得头筹！在强网杯全国网络安全挑战赛中杀入24强在线下获得三等奖的成绩。

第一天的fix环节结束时，福州大学ROIS战队（2271分）、南昌大学NCU\_0LinkSec战队（1960分）、浙江大学S2战队（1782分）排名前三。

赛事第二天，ROIS战队继续保持进攻优势、不放松防御工事。在两个环节一直保持领先位置。截止到比赛结束，福州大学的ROIS战队以总分数80分排名第一，上海交通大学Phont1a以46.56分排名第二，东华大学r00t-2019以45.73分排名第三。

随着第十二届全国大学生信息安全竞赛华南赛区、华东南赛区的圆满结束，分区赛阶段告一段落。最终排名需经大赛组委会计算八个赛区的Build环节得分才能确定，并据此选拔出入围7月27-28日在电子科技大学举办的全国总决赛的赛队名单。敬请关注！
