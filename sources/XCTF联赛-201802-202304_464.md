# 赛宁网安支持首届“强网”拟态防御国际精英挑战赛南京开赛！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NDU3MjExNw==&mid=2247486278&idx=1&sn=ef70eb37b4d1994308af6772d0bf2eb6&chksm=a684f97c91f3706a689eb3d7301d7eb4f27eaab87c28fc97a33c25881af3967ab43ad105dc23&scene=126&sessionid=1681669506#rd](http://mp.weixin.qq.com/s?__biz=MjM5NDU3MjExNw==&mid=2247486278&idx=1&sn=ef70eb37b4d1994308af6772d0bf2eb6&chksm=a684f97c91f3706a689eb3d7301d7eb4f27eaab87c28fc97a33c25881af3967ab43ad105dc23&scene=126&sessionid=1681669506#rd)

5月10日，由中国工程院、南京市人民政府主办，拟态技术与产业创新联盟、江宁区人民政府、南京江宁经济技术开发区管委会承办，赛宁网安技术支持的首届“强网”拟态防御国际精英挑战赛在南京正式开赛！该项赛事作为贯穿“第二届全球未来网络发展峰会”全程的亮点项目，吸引了网络安全领域及社会各界的广泛关注。

![](../Images/06f14d5f0cb7112111a3ed3636d0f262.png)

比赛现场

截止5月10日17点，大赛首日赛程结束，日本战队TokyoWesterns凭借web服务器上easy-upload的一血以1074分暂时领先，中国战队HAC最后十分钟拿到web题二血直线反超以810分排第二位，今日一直领跑的俄罗斯LC↯BC虽拿到两个一血，但因为DNS服务器许多队伍解出拉低得分以803分排第三。首日比赛共有4道题目被解出，15支队伍获得分数。

![](../Images/f7e627c15f8283816f58c0381f22af68.png)

首届“强网”拟态防御精英赛邀请国内外22支顶尖战队共同参赛，是国内同类赛事队伍实力最强的一次竞赛。其中，国内战队来自刚刚结束的第二届“强网杯”全国网络安全挑战赛前20强及特邀企业精英队伍；国际战队更具代表性，在CTFTIME全球排行榜中，2018年度排名位居首位的乌克兰dcua战队、第二位的波兰P4战队、第三位的日本TokyoWesterns战队，2017年度第六位俄罗斯LC↯BC战队等4支顶尖国际战队前来参赛，堪称全明星阵容。

![](../Images/1bec8e37ff5ef2dc2cc025d475d56a1e.png)

赛宁网安CP-CR靶场竞赛平台为本次赛事提供技术支撑，本场赛事赛宁网安靶场平台实现了四类带有不同安全隐患场景的复现（web应用、DNS、路由、防火墙），每个场景预设了多个漏洞点供选手挑战，通过虚实结合技术实现和第三方系统的联动，场景可以快速构建；现场展示的物理场景仿真，星际战争两套3D态势展示，平稳流畅的运行及酷炫展示获一众好评！此外，攻防过程还可以回放记录正常赛事的攻防流量，赛后靶场平台可以根据数据类型进行大数据分析，实现赛事重现。

![](../Images/b3524b20d047f0f1e7eb4e5ad434b41d.png)

赛宁网安靶场平台展示赛况

基于网络空间拟态防御理论开发的网络设备和系统，是我国中国工程院院士、国家数字交换系统工程技术研究中心主任邬江兴及其科研团队研发的原创性科研成果，此次作为赛事“靶机”，在世界范围内尚属首次。它将在接下来的两天时间里，接受国内外众多顶级白帽黑客战队开展的全方位、高强度的安全检验。本次赛事总奖金高达200万元人民币，其中基础奖金100万元，特别奖金100万元。

![](../Images/cf3fd049800b48fbbb0519a4310732b7.png)

邬江兴院士（右）现场与大家探讨拟态防御及创新赛制

在首日第一阶段比赛中，战队可以通过三个层次四类网络设备的关卡进行攻坚闯关解题，在每类网络设备的关卡中，突破了第一层每一类设备50%及以上关卡，就可以挑战第二层拟态防御设备关卡；只有攻破了第二层所有四个拟态防御设备关卡，才能开启终极挑战关卡（实网应用体系化部署的成套拟态设备），首日比赛结束，第二层三个拟态设备挑战已被开启，其中，两支优先获得挑战权的战队针对拟态web服务器发起攻击尝试2376次，其中被拟态web服务发现并封堵的威胁340次。

  

此次国际精英挑战赛，代表着CTF竞赛从传统的模拟比赛形式跨越到实战领域，这是国内赛事历史上的一次创新，同时，此次赛事也充分体现了南京市作为主办方，以习总书记网络强国战略思想为统领，深入贯彻全国网信工作会议精神，紧紧围绕国家重大战略需求开展相关工作的长远考量。下一步，南京市将以此次赛事为契机，切实加强重大科技平台建设，努力提升网络与安全技术的原创能力和产业化的水平，为南京建设具有全球影响力的创新名城提供支撑。
