# XCTF联赛欧洲站赛事落幕，赛宁网安平台线上线下完美支持！

4月9日-13日，XCTF联赛再度携手**HITBSecConf 2018**精诚合作，首次在欧洲落地XCTF分站赛事！本站赛事在古丝绸之路的终点城市荷兰**阿姆斯特丹**举办，同期举办了线下赛及线上赛两场比赛，两场比赛均由**赛宁网安**提供平台支持！

![](../Images/c5bd2ac1fc288f510742089e959c0932.png)

支持本次欧洲赛事的是赛宁网安自主研发的产品**“CP-AD网络安全攻防实战竞赛****平台”**，该平台集“练、测、赛”一体化设计，提供理论赛、CTF竞赛、A&D竞赛、工具库、漏洞库，是国内各行业信息安全人才考核和选拔的首选产品，XCTF联赛阿姆斯特丹站赛事算是XCTF联赛继去年新加坡站赛事后的又一站海外赛事，也是赛宁网安平台又一次出海支持海外赛事。

经过多年百余场赛事的考验，赛宁网安竞赛平台以其成熟性、稳定性被业内认可，支持赛事摒弃繁琐工序，轻便部署，以流畅酷炫的展示和丰富的经验获得了业界一众的好评，本次欧洲赛事赛宁网安仅派出一位运维工程师去往阿姆斯特丹，单独为两场并行国际赛事提供支持。

![](../Images/ce2c4554e6c563aeb4b4de1a9f0be22e.png)

赛宁网安工程师（左一）在欧洲现场  

**赛宁网安平台远赴欧洲，线下赛KITCTF战队成功卫冕！**

本次大赛的线下赛事，来自8个国家的24支战队齐聚阿姆斯特丹竞技比拼，中国的**Nu1L战队**与荷兰**HITB NL战队**联合出题，经过两天共16小时的比拼，最终来自德国的**KITCTF战队**成功卫冕，中国战队JD-3kaPig位列第六名，赛宁网安受邀为本次线下赛的提供平台支持，赴欧洲展示实力。

线下赛赛宁网安平台动态展示  

**线上赛事全球战队争****锋，日本战队TokyoWesterns夺冠！**

同期举办的**HITB-XCTF GSEC CTF 2018线上赛**也于荷兰当地时间4月11日14点开赛，北京时间4月13日晚21点落下帷幕，持续48小时的比赛，采用解题的形式，特邀第三届XCTF联赛总决赛冠军战队**FlappyPig**担任出题，**京东安全**为线上赛事提供赞助支持。

![](../Images/d1b4b2cf1c5318c7552e3610b167d4a0.png)线上赛最终排行榜

线上赛共吸引了来自142个国家和地区的425战队参与，344支战队得到分数。最终，来自日本的**TokyoWesterns战队**逆袭韩国CyKor战队夺得第一，中国台湾战队**Balsn**后来居上名列第二，长时间领跑的韩国**Cykor**战队最后阶段被超越排名第三，中国大陆的**天枢战队、Eur3ka战队、ROIS战队**排名均入围前十五。根据比赛规则，排名前十五的战队将受邀入围HITB-XCTF GSEC CTF 2018线下赛（8月30-31日于新加坡），最终入围战队信息XCTF联赛将在审核后发布。

![](../Images/cba849ec6998a3882d2a8fc57ec8102b.png)线上赛赛宁网安平台动态展示  

**下一场赛事\*CTF4月21日开启，MMSRC鼎力支持！**

由复旦大学\*\*\*\*\*\*战队主办，赛宁网安提供技术支持，陌陌安全应急响应中心赞助支持的\*CTF国际赛（以下简称\*CTF）将于4月21日早9点正式打响，作为第四届XCTF联赛的分站选拔赛之一，本次比赛将持续48小时，面向全球战队开放。

![](../Images/4895111ff90a6db121567fccbc5286d6.png)
