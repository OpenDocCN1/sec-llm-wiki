ssh转发
linux下的ssh是我们常用的终端管理命令，但是它不光管理终端，还可以转发流量的，使用ssh的好处是不用将工具上传到目标主机。

ssh的参数可以了解一下
-C 压缩传输，增加传输的效率，-f 将SSH传输放在后台执行，不占用当前的SHELL-N 建立静默连接，就是建立了连接，但是看不到具体的会话；还有一种说法是不允许执行命令-g 允许远程主机连接本地用于转发端口-L 本地端口转发-R 远程端口转发-D 动态转发-P 指定SSH的端口


本地转发

端口流量转发，实现访问本地的8080端口，就会将请求转发给本地的22或其他端口
ssh -L 8080:92.168.10.6:22 -fN 192.168.10.6
转发开启后，ssh连接一下
ssh 192.168.10.6 -p 8080


正向转发

连接外网的服务器上执行，将外网服务器端口数据转发到内网服务器端口上
ssh -CfNg -L:<目标内网ip>:<目标端口> <root@外网web服务器，需要输入密码>
ssh -CfNg -L 8080:192.168.10.79:80 192.168.10.6
外网服务器上查看8080端口是否已经连接
netstat -tulnp | grep "8080"
访问外网服务器的8080，就可以转发访问内网80端口
curl 192.168.10.6:8080


反向转发

将内网服务器端口转发到连接外网的服务器上
所有访问外网服务器端口的流量都会通过SSH隧道传输到内网服务器的端口
ssh -CfNg -R:<目标内网ip>:<目标端口> <（root@vps-ip，会要求输入密码）>
ssh -CfNg -R 8880:192.168.10.6:22 root@192.168.10.9
查看连接外网的服务器以监听端口
netstat -tulnp | grep "8880"
所有访问外网服务器8880端口的流量都会通过SSH隧道传输到内网服务器的22端口
