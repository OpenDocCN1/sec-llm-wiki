开机自启动  

* * *

  
在linux系统中，也有开机自启文件/etc/rc.local  
  
当服务器开机时，将执行自启文件当中的命令可以将反弹shell或运行后门命令写入该文件当中![](../Images/c71c231b0a131abfaeb2fa6215ab30fd.png)  
启动服务执行

* * *

  
在/etc/init.d/目录下存放着全部的服务项启动脚本  
![](../Images/7b608a837de76109724e8bca70cf3472.png)当服务重启或者停止时就会运行该脚本中的代码，我们可以修改此目录下的服务项，写入后门程序  
  
比如新建一个服务脚本tomcat

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
vim /etc/init.d/tomcatcase "$1" instart)echo "starting"/home/tomcat/bin/startup.sh &;;stop)echo "stop"/home/tomcat/bin/shutdown.sh;;esac
```

给相应的执行权限，并添加到开机自启中  

*   
*   

```
chmod +x tomcat                       chkconfig --add tomcat
```

 直接执行此服务也可

*   
*   

```
service tomcat startservice tomcat stop
```

环境变量

* * *

  
系统环境变量是随用户登录自动执行的。  
linux有几个环境变量文件，加载方式各不同  
/etc/profile此文件是所以用户的环境变量，当用户第一次登录时，该文件会被执行并从/etc/porfile.d/目录下的配置文件中搜集shell设置![](../Images/c1f835884472b1482179a8e36c817462.png)~/.bash\_profile  
每个用户专属的环境变量，当用户登录时，该文件只执行一次！！![](../Images/e3990718de494986295cc174841ca609.png)~/.bashrc  
每个用户专属的环境变量，当用户登录或打开新的shell时，该文件将被读取![](../Images/64dec2a95011ca24694e830a39832afb.png)~/.bash\_logout  
退出系统执行该文件内的命令![](../Images/6db60bb5d35b56d1931e2f032314c86a.png)
