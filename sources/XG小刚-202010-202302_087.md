# PHP MVC架构doyocms代码审计

## 什么是MVC

首先要知道什么是MVC，MVC是一种软件架构模式 MVC中M表示`model`(模型)，V表示`view`(视图)，C表示`control`(控制器)，把系统划分为这三个部分

MVC的目的是动态的程序设计，使程序的扩展和修改简化以及重复利用代码

**「Model」**：管理业务逻辑和数据库逻辑。模型提供了连接和操作数据库的抽象层

**「Control」**: 负责响应用户请求，准备数据，以及决定如何展示数据

**「View」**：负责渲染数据，通过Html展示给用户

  

![](../Images/0047be7f937a0388c0027775356aeecb.png)

上图展示了MVC的工作流程：  

1.  `controller`截获用户的请求
2.  `controller`调用model完成状态的读写操作
3.  `controller`把数据传递给`viewer`
4.  `viewer`最终渲染把结果呈现给用户

更详细的mvc介绍：`https://www.awaimai.com/128.html`

## 任意文件上传漏洞

后台的文章编辑处有本地文件上传功能，但是限制了文件后缀，使用的是`uploads`控制器

![](../Images/dbe689fbbf158ae459eaceeedc4540ae.png)

主要还是调用`syupload`中的`upload_file`方法，`upload_file`中会用`pathinfo`函数获取后缀，白名单过滤，暂时没有办法绕过，如果是黑名单可以传入`shell.php/.`这种形式

![](../Images/da554f7804e785bce75e5556d7cbac07.png)

查看`uploads.php`里的`index`方法，就会看到第一行接收了参数`allow`，在实例化`syUpload`对象时传入，而`syupload`对象在构造时，直接将传入的`allow`作为允许的后缀字典

![](../Images/b9e095b9bd2f2c4839a806fda2eaed07.png)

所以我们在上传时，只需要加一个`allow`参数，就可以上传任意后缀的文件了
