WMIC


wmic命令行是用来管理WMI系统的， 算是win的插件 ， 用户可以使用 WMI 管理本地和远程计算机。

WMI在渗透测试中不需要下载和安装，是Windows系统自带功能，和cmd一样用 

在整个运行过程都在计算机内存中发生，不会留下任何操作痕迹。


 简单使用 


大部分命令可以正常使用的，但有几个需要提权完成后，才可以有权限进行操作

cmd下输入wmic进入交互页面也可以直接 wmic+命令 运行

查看帮助

wmic /?           #查看全局命令process /?            #进程管理帮助wmic process get /?           #属性获取操作帮助



 常用命令


这里记录几条在测试过程中会用到的命令

#获取系统正在运行的进程、进程文件路径、进程idwmic process get caption,executablepath,processid

#获取系统当前正在运行的服务wmic service where (state="running") get name,processid,pathname,startmode,caption

#查看服务信息wmic service list brief    

#获取杀软详情wmic /Node:localhost /namespace:\\root\securitycenter2 path antivirusproduct GET displayName,productState,pathToSignedProductExe /Format:List

#获取补丁信息，和打补丁时间wmic qfe get Caption,Description,HotFixID,InstalledOn

#判断是否是虚拟机wmic onboarddevice get Description,DeviceType,Enabled,Status /format:list

#安装了些软件wmic product get name,version#获取本地安装程序wmic /NAMESPACE:"\\root\CIMV2" PATH Win32_Product get name /FORMAT:table

#系统环境变量wmic environment get Description,VariableValue

#计算机品牌，型号、名称、名字wmic computersystem get Name,Domain,Manufacturer,Model,Username,Roles /format:list

#获取系统驱动情况wmic sysdriver get Caption,Name,PathName,ServiceType,State,Status /format:list#查看驱动器wmic logicaldisk get caption,description,providername  

#查看当前操作系统wmic OS get Caption,CSDVersion,OSArchitecture,Version

#查看开机自启动wmic startup get caption,command

#查看共享文件wmic share get name,path,status

忽略广告。


 操作用户 


#搜索用户账户wmic useraccount list brief#锁定用户账号wmic useraccount where name='hacker' set disabled=false#用户账号重命名wmic useraccount where name='hacker' rename hacker限制用户修改密码wmic useraccount where name='hacker' set passwordchangeable=false#搜索登录用户wmic logon list brief

#搜索计算机域控制器wmic ntdomain list brief


 操作服务 


#卸载和重装程序wmic product where "name like '%forit%'" get name

#停止运行服务,主要是关闭杀软Wmic process where name="XXX.exe" call terminatewmic process where name="explorer.exe" call terminate



清理系统日志


nteventlog选项可以清除系统的日志记录,一般需要权限。

wmic nteventlog where filename='system' cleareventlog
