 IP代理 


IP代理就是通过指定的ip传出流量，原理相当于连接客户端和远程服务器的“中转站”，所显示的IP地址是修改后的IP地址。

当ip代理用在内网渗透中，就是通过内网的主机将我们的流量转发出去，达到访问内网的效果。



 浏览器 

SwitchyOmega


浏览器可以用代理插件，添加内网代理来使用



win系统

Proxifier


Proxifier是win系统一款功能非常强大的socks5客户端

可以让不支持代理服务器的程序能通过HTTPS或SOCKS代理或代理链,汉化版挺好用的。


首先添加代理服务器

配置文件-->添加代理服务器

添加一个从宿主机穿透出来的SOCKS5代理，有密码的话自行添加。


添加代理规则

配置文件-->代理规则

规定哪些软件的流量经过定义的代理端口，

注意设置动作: 直接连接系统代理、拦截流量和走代理。


(注意：端口复用技术 reGeorg的python的脚本，所以设置python走系统代理比较稳妥）


这样就可以让数据走Socks5进行穿透内网了。



linux系统 

proxychains


proxychains是 Linux 和 Mac下的一款代理神器

源码：https://github.com/rofl0r/proxychains-ng

//安装的话很多教程apt-get install proxychains            //linux基于debian

安装完配置proxychains代理链

修改配置文件/etc/proxychains.conf

设置代理ip和端口

socks5 127.0.0.1 8888

然后在运行命令前面加上 proxychains就行了

proxychains curl 192.168.1.2
