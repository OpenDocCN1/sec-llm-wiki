**介绍  
**  
msfvenom是用来制作msf所支持的木马文件的，在这介绍一下msfvenom的几个使用参数，和如何制作免杀木马。  
主要过程就是使用msfvenom指定特定编码，编码次数等生成c语言代码，再使用VC++ 生成程序文件。  
**参数**

这里列出几个常用参数，其他参数可使用help查看。

| \-p || 指定所使用的payload |
| --- | --- |
| \-e || 指定使用的编码器 |
| --- | --- |
| \-b || 删除无效字符 |
| \-i || 指定编码次数 |
| \-f || 指定生成的文件类型 |
| \-l || 列出可使用的项 |
| \-o || 导出为某文件 |
| \-x || 捆绑文件 |
| \-platform || 指定目标系统 |

**原因  
**编译都成功时，进行组建可能会报错，修改一下VC++配置。  
在菜单栏。组建配置的c/c++下，修改WINDOWS为CONSOLE![](../Images/d3b9b7e32caab317f8794b85bac838ff.png)在连接下修改windows为console，确定就行了![](../Images/015e9b16303fbae8f939fa19f5bf9ab0.png)
