# **中文乱码**  

新版kali最最头疼的就是中文乱码，弄了半天不知怎么处理。  
1，在命令行输入” dpkg -reconfigure locales”。  
进入图形化界面之后，选中zh\_CN.UTF-8，确定，将zh\_CN.UTF-8选为默认。  
![](../Images/5de7b4b512071edd1c3a9bbadcd8ac22.png)  
 （空格是选择，Tab是切换，带\*是选中）  
![](../Images/307f4242876470afc1f40f4eabe71f96.png)  
 2，在终端输入命令来安装中文字体

*   
*   

```
`apt-get install xfonts-intl-chinese ``apt-get install ttf-wqy-microhei `
```

```
` `3，reboot重启系统，在登录界面，右上角语言列表注意是否为zh\_CN.utf8

```

 点开列表，确定选中的为中文-中国。  
![](../Images/146ff7d7027830ef751984ed412908ec.png)  
 4，如果不成功，可以在重新启动一次
