Kali

kali是个好东西啊，玩起来满满的报错。 

有人说：kali玩得好，牢饭吃得饱。可我没接入外网，你拿我咋地

大学这几年接触最多的是kali，也忘记听谁忽悠了，一开始就玩起了kali。毕竟我没什么基础，玩起来有点吃力，但经过长时间的摸爬滚打，终于会开关机了。

kali说白了就是个普普通通的Linux操作系统，只不过是他们集成了大量的工具集在里面，不需要自己太复杂的配置，只要学会玩就行了。玩起来比较爽，满满的新鲜感。


我的kali是装在了VMware虚拟机上，安装挺简单的。。。就先绕过了


来让我们看看安装好了需要干点啥

01.改一下国内源

国外源实在太慢了太慢了，慢的我想nmsl

root@computer:~# vim /etc/apt/sources.list

#这是用apt更新安装时的配置文件
#所有内容前面加#屏蔽，输入国内源，我用的是中科大源
#不会用vim（点i进入输入模式，按Ese，：，wq保存退出

deb http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contribdeb-src http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib

02.进行更新

每次用的时候都可以更新一下，以保持软件最新版本

apt-get update #取回更新的软件包列表信息apt-get upgrade #进行一次升级apt-get clean && apt-get autoclean #删除所有已下载的包文件- 删除已下载的旧包文件

#可以直接apt或apt-get查看帮助，看看有啥能玩的命令

03.安装中文输入法

中文输入法还是有必要的，我用的搜狗。

安装输入法前需要安装一个支持包fcitx，这是干嘛的等我百度了回来补上

apt-get install fcitx


然后去搜狗拼音下载Linux版本输入法，得到一个.deb包，到包所在的目录,右键在终端打开

root@computer:~/下载# root@computer:~/下载# dpkg -i sogoupinyin_2.2.0.0108_amd64.deb

安装完可能会有环境依赖等错误

apt -f install #安装依赖环境

重启后应该就可以使用了ctrl+shift

04.打开ssh服务

编辑ssh配置信息

vim /etc/apt/sshd_config#PasswordAuthentication yes 删除##PermitRootLogin Prohibit_password 删除#，后面改为yes

打开ssh服务

service ssh start

检查ssh服务状态

service ssh start

新版本kali好像用systemctl start ssh来开启服务

06.打开metasploit

在第一次开启metasploit时候需要重置数据库。msf用的是postgresql数据库。
先打开postgresql数据库service postgresql start
重置msf数据库msfdb init
打开metasploitmsfconsole
查看是否连接上数据库db_status显示连接上postgresql就可以使用了。
最好每次使用都重新启动一次service postgresql restart
