# 来让我们看看安装好了需要干点啥  

## 01.改一下国内源

国外源实在太慢了太慢了，慢的我想nmsl

*   

```
`root@computer:~# vim /etc/apt/sources.list`
```

#这是用apt更新安装时的配置文件  
#所有内容前面加#屏蔽，输入国内源，我用的是中科大源  
#不会用vim（点i进入输入模式，按Ese，：，wq保存退出  

*   
*   

```
`deb http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib``deb-src http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib`
```

## 02.进行更新

每次用的时候都可以更新一下，以保持软件最新版本

*   
*   
*   

```
`apt-get update #取回更新的软件包列表信息``apt-get upgrade #进行一次升级``apt-get clean && apt-get autoclean #删除所有已下载的包文件- 删除已下载的旧包文件`
```

#可以直接apt或apt-get查看帮助，看看有啥能玩的命令

## 03.安装中文输入法

中文输入法还是有必要的，我用的搜狗。

安装输入法前需要安装一个支持包fcitx，这是干嘛的等我百度了回来补上

*   

```
`apt-get install fcitx`
```

  

然后去搜狗拼音下载Linux版本输入法，得到一个.deb包，到包所在的目录,右键在终端打开

*   
*   

```
`root@computer:~/下载# ``root@computer:~/下载# dpkg -i sogoupinyin_2.2.0.0108_amd64.deb`
```

安装完可能会有环境依赖等错误

*   

```
`apt -f install #安装依赖环境`
```

重启后应该就可以使用了ctrl+shift

## 04.打开ssh服务

编辑ssh配置信息

*   
*   
*   

```
`vim /etc/apt/sshd_config``#PasswordAuthentication yes 删除#``#PermitRootLogin Prohibit_password 删除#，后面改为yes`
```

打开ssh服务

*   

```
`service ssh start`
```

检查ssh服务状态

*   

```
`service ssh start`
```

新版本kali好像用`systemctl start ssh`来开启服务

## 06.打开metasploit

在第一次开启metasploit时候需要重置数据库。msf用的是postgresql数据库。  
先打开postgresql数据库`service postgresql start`  
重置msf数据库`msfdb init`  
打开metasploit`msfconsole`  
查看是否连接上数据库`db_status`显示连接上postgresql就可以使用了。  
最好每次使用都重新启动一次`service postgresql restart`
