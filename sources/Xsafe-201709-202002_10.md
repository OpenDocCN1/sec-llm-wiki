
emmmm，虽然，好像，看不懂这个代码的具体意思，但是根据我的一些经验来看，应该是xmrig这个程序输出 xmr.crypto-pool.fr这个文件，在网上看到这就是个挖矿的病毒程序，并且采用了一些加密的方式，后面密文估计就是加密的啥玩意（我也不懂，手动滑稽）

![](../Images/3a828ad0c725816dd7c2a24586ff3532.png)

```
1.  `@echo off`
    
2.  `xmrig.exe`
    
3.  `pause`
    
```

看看run.bat中的代码

```
1.  `@echo off`
    
2.  
    
3.  `REG ADD HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run /v BGClient /t REG_SZ /d C:\System32\TTy_start.bat /F`
    
4.  
    
5.  `pause`
    
```

从这个代码来看，是将C:\\System32\\TTy\_start.bat添加到注册表了，到这个对应的注册表看看吧。

![](../Images/fa0c531f589319e2f705652f4ac6c926.png)

果然在注册表中找到了这个批处理文件，并且从注册表中的意思就可以看出来意思是每次开机都会启动这个C:\\System32\\Tty\_start.bat这个批处理文件。
