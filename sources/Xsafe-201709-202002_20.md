今天在网上意外看到一个在线的`poc`生成工具，传送门,界面如下

![](../Images/9614d310d9a5f49fcf10ec4067feba5f.png)0x01 编译项目

> 环境需求：
> 
> Git 传送门
> 
> Node.js 传送门
> 
> Yarn

安装好`Git`后，使用`git`将项目克隆到本地

```
1.  `git clone https://github.com/phith0n/xray-poc-generation`
    
```

![](../Images/6a6d41f2f373484fb42a99ff71f934be.png)

```
1.  `cd xray-poc-generation`
    
2.  
    
3.  `yarn`
    
```

![](../Images/1323ebbed435baf4f3d7597cbb0825a7.png)

原因：没有安装`yarn`使用`nmp install -g yarn`一键安装

![](../Images/f6a6423143acb0f99f63f3eac0620c32.png)

然后在使用`yarn`命令

![](../Images/8e2bb2cfdbbe50961235840638dd8343.png)

yarn build

# 0x02 本地搭建

> 环境需求：
> 
> Windows server 2003
> 
> PHPstudy

将编译好的`build`文件夹中的内容直接复制到`www`根目录

![](../Images/aba6dfd1260b918f4e0f586295e3f629.png)

使用`ipconfig`命令查看`Windows server 2003 ip`地址

![](../Images/54b3f7cc7b2be1db5996ea95c9cafb3a.png)

然后使用 `http://ip地址` 直接访问

> 注：如果直接将build文件夹复制到www目录下，需要修改index.html的文件，将相对路径改成含build的目录。

![](../Images/476ad52d5fcc9d244c9e87b1d10357f6.png)
