# 1\. portainer介绍

>  Portainer是Docker的图形化管理工具，提供状态显示面板、应用模板快速部署、容器镜像网络数据卷的基本操作上传下载镜像，创建容器等操作、事件日志显示、容器控制台操作、Swarm集群和服务等集中管理和操作、登录用户管理和控制等功能。功能十分全面，基本能满足中小型单位对容器管理的全部需求。

  

## 2\. 安装

```
\[root@docker ~\]# docker search portainer                                #查询当前有哪些Portainer镜像
\[root@docker ~\]# docker pull portainer/portainer            #使用最多下载量的portainer镜像(使用不同加速地址名称不同)
```

## ![](../Images/435dff56841efcf4deeb4eaaf9fa22ad.png)![](../Images/979bda111ede79733773665626def025.png)

  

## 3\. 启动

```
\[root@docker ~\]# docker run -d -p 9000:9000 \\   #宿主机的9000关联到容器的9000
    \--restart=always \\                                  #开机自启
    \-v /var/run/docker.sock:/var/run/docker.sock \\          #把本地的docker.sock关联到容器
    \--name prtainer\_web \\    #指定启动后名称
    portainer/portainer         #指定镜像名称
```
