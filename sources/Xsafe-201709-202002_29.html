  • 系统      centos7-1708

  • 软件      Docker version 19.03.1

  • images  vulnerables/web-dvwa

DVWA是一个用来进行安全脆弱性鉴定的PHP/MySQL Web应用，旨在为安全专业人员测试自己的专业技能和工具提供合法的环境，帮助web开发者更好的理解web应用安全防范的过程。


1.安装docker

  • 修改主机名

[root@localhost ~]# hostname dvwa
[root@localhost ~]# echo "dvwa" > /etc/hostname

  • 安装必要软件包

[root@dvwa ~]# yum -y install wget git

  • 安装docker依赖

[root@dvwa ~]# yum install -y yum-utils device-mapper-persistent-data lvm2

  • 使用国内docker安装源

[root@dvwa ~]# wget -O /etc/yum.repos.d/docker-ce.repo https://download.docker.com/linux/centos/docker-ce.repo
[root@dvwa ~]# sed -i 's+download.docker.com+mirrors.tuna.tsinghua.edu.cn/docker-ce+' /etc/yum.repos.d/docker-ce.repo

  • 使用docker加速源

[root@dvwa ~]# curl -sSL https://get.daocloud.io/daotools/set_mirror.sh | sh -s http://f1361db2.m.daocloud.io
[root@dvwa ~]# systemctl restart docker

  • 查找dvwa

[root@dvwa ~]# docker search web-dvwa

  • 下载dvwa images

[root@dvwa ~]# docker pull vulnerables/web-dvwa

  • 运行docker dwva

[root@dvwa ~]# docker run -d --name docker_dvwa -p 8080:80 vulnerables/web-dvwa             //把本机8080端口映射到容器的80端口

  • 查看本机监听的8080端口

[root@dvwa ~]# ss -ntupl | grep 8080

2.访问DWVA

  • 查看本机ip地址

  • 打开浏览器访问

    http://ip地址:端口号


  • 默认用户名密码

    user:admin
    pass:password

  • 设置页面

  • 点击 Create / Reset Database完成安装,完成后会自动跳转登陆页


  • 登陆后DVWA首页

  • 用户名 admin 密码 password

进入该网站平台，就可以进行愉快的测试实践了。
