**web渗透**

信息搜集，拿下webshell

使用命令查找IP，由于存在防火墙所以PING不通

netdiscover -i eth0 -r 192.168.142.0/24

![](../Images/86c4d1fc2c815d497b391a01a455ab28.png)

定位到IP之后，使用nmap进行端口探测，看到开放的80,3306

![](../Images/5da408764f3b24efd55ebca874698956.png)

8端口是一个探针，使用默认的数据库账号密码连接正常

是个弱密码

![](../Images/4ca9ca89bc3d1dd9e7993e660717e51c.png)

然后就猜测可能存在phpmyadmin，直接输入路径，就显示登录框，默认密码登录

![](../Images/d05319da201fc98c020dfb14f13b434a.png)

在变量这里可以看到日志存放路径等信息，可以猜测默认目录就是c:/phpstudy/www。小皮面板

默认是这个路径

![](../Images/b5b1c9e9544d0c19bb1696af9a90559a.png)

接下来就是使用日志写webshell

show global variables like "%genera%";

//查询general\_log配置 set global  

general\_log='on'; //开启general log模式 set global

general\_log\_file='C:/phpstudy/www/xxx.php';

//设置日志文件保存路径 SELECT '

//phpinfo()写入日志文件 set global general\_log='off';

//关闭general\_log模式

![](../Images/aaeda48c8e847aa141f1fad2978d46ef.png)

之后使用蚁剑进行连接，成功获取webshell

![](../Images/a42b8bcaf932f3b2bba51ddd5f1ca6e3.png)

**内网渗透**

进行信息搜集，此机器当前是god域，administrator权限，还存在第二块网卡

![](../Images/3185d9a0131d87d105bc8872875d2b36.png)

查看一下杀软，没有杀软存在，方便使用msf上线

![](../Images/ee4222cf1957def3c916e1967594615e.png)

生成一个后门，然后使用反向获得一个shell

![](../Images/bda6c2b4df1bcbf211a1d7ad7d969946.png)

添加路由

![](../Images/d3e20c6899d807476e259bd0d61c4c3a.png)

使用arp\_scanner模块，进行内网IP存活探测，发现了129这个IP

![](../Images/3c010cda1fe6a9c25e48958039fe37d2.png)

通过添加socks代理和全局代理使用nmap扫描，速度太慢

![](../Images/9eb43f299a1de63af74bc048ddbcfcb2.png)

上线CS进行arp的端口扫描

![](../Images/9598c266b0993ae9eaadfd69725a2e88.png)

看到开放的端口信息

![](../Images/069deabc06b6e4d9ae97da7cf1f53a94.png)

然后使用nmap探测详细的信息

![](../Images/1de6c3300df0acac8609bd8c92925b51.png)

这里ms17-010是可以使用的，但是只能使用命令。

![](../Images/3f180a7cbe06cc7299eb4efbead1e1ee.png)

这里可能存在防火墙，使用命令将防火墙关闭

netsh advfirewall show allprofile state

netsh advfirewall set allprofiles state off

![](../Images/b0947c5fa441a4eeaf68d8d8992d7b7c.png)

![](../Images/ea8fafc6bb09b60bf755b972946de860.png)

![](../Images/5c4c5f3e6651315a905c9beaeedfc4be.png)
