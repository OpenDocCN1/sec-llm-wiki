获取webshell

搭建好环境之后，知道IP绑定hosts文件，根目录就是空白页面

由于目标开启了防护软件，进行端口探测的时候，需要绕过防火墙的拦截，百度有很多nmap绕过防火墙扫描的文章

MAC地址欺骗

nmap -p 1-65535 -sT -Pn -spoof-mac 0 192.168.0.114

使用-A参数查看详细信息

绑定了hosts之后，接着使用编写的工具进行目录扫描，线程放慢就行了

siteserver的路径是500的，访问到之后是网站后台页面

siteserver 3.6.4是存在漏洞的

sql注入漏洞

查看管理员的密码，输入管理员账号，输入答案的位置抓包清空

放包然后就会显示管理员的密码

登录到后台之后，在附件上传配置的位置，可以修改上传图片类型，删除aspx的后缀，方便上传木马文件

接着在站点模板管理的位置，导入站点模板，将shell.aspx打包成zip的格式

文件上传之后会自动解压，文件目录放在了如下目录：

在web页面访问该目录，连接shell

由于是aspx的冰蝎马，使用冰蝎连接后门，拿到webshell

查看当前权限不是很高

或者使用月师傅的过狗刀，重新上传一个aspx木马文件，使用工具连接

查看一些基础信息，查看进程，然后复制到网站，查看存在的杀软

该服务器存在两块网卡

MSF

提权

上传路径在C:\Windows\temp\

有了system权限之后，制作免杀木马，反弹shell至msf

查看网卡，存在第二块网卡，IP地址为10.10.1.132

进入shell命令，切换中文

chcp 65001

查询是否存在域，当前是工作组，64位机器

横向渗透IP探测，使用后渗透模块，查询到一台存活机器130，正和上面的拓扑相对应

MSF

内网渗透

添加路由

添加socks，添加本地代理

使用namap扫描探测，存活80端口

浏览器挂上代理之后，访问80端口。80端口开放的通达OA的服务，通达OA存在很多漏洞

使用通达OA漏洞检测脚本进行探测，存在历史漏洞

后台文件上传，拿到shell

使用蚁键连接，获取webshell，记得添加代理~

内网信息搜集，直接是system权限，而且存在域环境，第二块网卡是10段的地址

查找域控地址，查看时间服务器，并解析域控的IP地址

而且可以直接访问

查看进程，存在360安全卫士

开放端口信息

查看systeminfo也是存在域环境

查看当前防火墙，并关闭所有的防火墙配置

关闭防火墙的配置后，部分端口扫描也开放了

MSF

域渗透

msf正向连接

生成正向的shellcode，然后使用工具进行免杀

msfvenom -p windows/x64/meterpreter/bind_tcp lport=3333 -f c

免杀之后，上传到蚁剑，与msf生成正向的连接

查看ip和权限

再做一个进程迁移

以上通过查看时间服务器，找到了域控制器，还可以使用msf的后渗透模块来定位域控。知道了域控的地址是165

run post/windows/gather/enum_domain

添加路由，进行内网端口扫描

使用常见端口进行扫描，全端口扫描时间太长

proxychains nmap -Pn -sT 10.10.10.165 -p 80,89,8000,9090,1433,1521,3306,5432,445,135,443,873,5984,88,6379,7001,7002,9200 ,9300,11211,27017,27018,50000,50070,50030,21,22,23,2601,3389 --open

查看进程可以看到管理员登录的信息

窃取token

steal_token 4384

破解hash，由于密码是自己设置的，这里就不够买了：!@#QWEasd123..

上面通过NMAP扫描到了3389开放，直接使用远程桌面连接。因为域控做了限制，只能使用 windows的远程桌面进行连接。(记得添加socks代理，我这里本机可以直接访问域控，所以没加)
