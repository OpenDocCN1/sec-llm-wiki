平时在看技术文章或者漏洞复现文章时，经常会碰到很多跟 Windows 原理相关的内容，如果对其中的某一个知识点不够了解的时候，对整体的理解就会比较困难，甚至是直接劝退了，所以提前储备一定的 Windows 原理相关的知识，不仅有助于理解文章中所提到的思路和技术点，也更有可能将这些思路迁移到自己熟悉的其他技术上。


所以在《CobaltStrike逆向学习系列》主线篇结束后，计划开设《Windows原理深入学习系列》文章，当然，整个系列所追求的一定不会是单纯的概念搬运，只为了搬运概念还不如去看 MSDN 了，他们对概念的把控比其他地方都更熟悉了；我想尝试的是在搞懂基本概念的情况下，分析它在实际环境中的应用，以及它在内核里是如何实现的。


目前整个系列的内容还没有敲定，感兴趣的可以公众号后台回复或者加我微信聊一聊
