## 0x05 示例

1.  首先运行powershell脚本KBCollect.ps收集一些信息  
    `.\KBCollect.ps1`
    
2.  将运行后产生的KB.json文件移动到cve-check.py所在的目录
    
3.  安装一些python3模块  
    `python3 -m pip install requirements.txt`
    
4.  运行`cve-check.py -u`创建CVEKB数据库
    
5.  运行`cve-check.py -U`更新CVEKB数据库中的hasPOC字段
