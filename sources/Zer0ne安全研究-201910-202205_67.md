### 0x01 事情起因

因为疫情的原因，最近一直呆在朋友的宿舍里，然鹅每次用电脑上网的时候，总是弹窗输入手机号获取验证码才能正常上网。看到这个问题就想到需要在路由器里进行设置，然而宿舍里的路由器也是公司布置的，并不知道用户名和密码，因而我来尝试下能不能进去修改下路由器的设置。

### 0x02 尝试

**1\. 弹窗如下：**

![](../Images/320a6b992d1e2cb0672c857b46377dc8.png)

  

**2\. 查看IP相关信息:**

得到路由器的地址`192.168.41.1`：

![](../Images/c5c4ed09328e88c57cd81bf64a1df8c2.png)

  

3\. **使用nmap扫描一下开放的端口信息：**

![](../Images/3f218afa7973e2c4d79371e3cec9d160.png)

  

3.1 可以看到路由器使用了一个比较web server：`Boa 0.94.14rc21`：

![](../Images/f6d0488efe6051560a7afb734498b3cf.png)

  

3.2 可以搜索到一个任意访问文件的漏洞并且有相应payload，试一下看看:

```

http://192.168.41.1/cgi-bin/wapopen?B1=OK&NO=CAM_16&REFRESH_TIME=Auto_00&FILECAMERA=../../etc/shadow%00&REFRESH_HTML=auto.htm&ONLOAD_HTML=onload.htm&STREAMING_HTML=streaming.htm&NAME=admin&PWD=admin&PIC_SIZE=0
```

![](../Images/35187bf21902863bc8607b588dda98fd.png)

  

> 并没有什么卵用，，，开始找网页的漏洞吧

**4\. 进入路由器登录界面：**

使用admin/admin作为账号密码进行测试：

![](../Images/c3d6456c1e833ecd5f73c22e714f9c80.png)

  

可以看到提示有输入次数限制，顿时感觉要小心翼翼的，，，网页右键审查元素，查看网络请求包和响应包：

![](../Images/ca629d2df7cf2325e742fd7381ef2abb.png)

  

![](../Images/7773fcdeccc3c772b92d0477932bf6a9.png)

  

这里就是关键的代码，意思就是：

```







输入用户名和密码
```

**5\. Burp抓包改包：**

如果可以将响应值改为一个非“0”值，试试看能不能成功，开启Burp 开干。。。：

![](../Images/d1c8575d0b05f63f74356960b255bdfc.png)

  

将响应包中的0改为1试试看：

![](../Images/1e8dafae9619b949af944cb508c069cb.png)

  

成功进入：

![](../Images/d613bb582c37a2ee3b724c0a9547e304.png)

**7\. 重置密码：**

下面开始尝试重置密码：

可以直接得到用户名为`awifi`:

输入原密码后，直接显示密码错误，查看响应包

![](../Images/01bb68c41b7d44239677576df1dae834.png)

可以看到响应值为`-1`,尝试将`-1`改为0,1进行测试，最终通过将响应值改为`0`可以重置用户的密码

  

### 0x03 总结

这是一个超简单的测试，问题的主要原因是在客户端而不是在服务器进行验证
