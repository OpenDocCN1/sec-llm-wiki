分享一个清除Github上commit的所有记录的方法  
我们每次commit到GitHub的记录中可能会含有一些包含公司代码在内的敏感数据，虽然我们最后一次commit的代码中已经清除了所有的敏感字段，但是以前commit的那些记录依然存在，恶意攻击者可以利用一些特制的工具进行扫描，因而增加被攻击的风险。  
下面记录一下清除commit记录的方法：  
**0\. 将GitHub上的仓库clone下来**

```

git clone https://github.com/chroblert/domainweakpasswdcheck.git
```

> 进入克隆下来的仓库目录，执行下述操作

**1\. 创建一个新分支**

```

git checkout --orphan latest_branch
```

**2\. 添加所有的文件**

```

git add -A
```

**3\. 提交所有的change**

```

git commit -am "随便填"
```

**4\. 删除以前的分支**

```

git branch -D master
```

**5\. 更改当前所使用分支的名字**

```

git branch -m master
```

**6\. 强制更新至仓库**

```

git push -f origin master
```

**7\. 最后一步**

> 打开GitHub，点击之前要删除的仓库，在里面可以看到有两个branch，只保留commit数量较少的一个branch
