本篇文章将会在（一）的基础上增加可视化功能，接下来需要搭建LAMP环境，安装BASE（Basic Analysis and Security Engine，基本分析和安全引擎）。

0x01 搭建LAMP环境

1.1 安装Apache

yum -y install httpd
systemctl start httpd.service
systemctl enable httpd.service

1.2 安装PHP

yum -y install php php-mysql php-mbstring php-mcrypt php-gd php-pear
# 重启httpd
systemctl restart httpd
# 测试站点是否正常
touch /var/www/html/index.php
# 在该文件中填入内容：
<?php
phpinfo();
?>
# 在浏览器中输入http://<ip>/index.php查看是否正常，正常则成功

1.3 配置PHP

# 配置时区
# 修改/etc/php.in配置文件,PRC 代表中华人民共和国
date.timezone = PRC 

0x02 安装BASE

2.1 安装BASE

# 下载BASE
wget https://downloads.sourceforge.net/project/secureideas/BASE/base-1.4.5/base-1.4.5.tar.gz
# 解压
tar -xzvf base-1.4.5.tar.gz
# 移动
cp -r base-1.4.5 /var/www/html/base

2.2 安装ADOdb

# 下载ADOdb
wget https://sourceforge.net/projects/adodb/files/adodb-php5-only/adodb-520-for-php5/adodb-5.20.9.tar.gz
# 解压
tar -xzvf adodb-5.20.9.tar.gz
# 移动
cp -r adodb5 /var/www/adodb5
# 改变owner.不改变权限，后面会报错
chown -R apache:apache /var/www/adodb5 

2.3 配置base

cd /var/www/html/base
# 重命名配置文件
cp base_conf.php.dist base_conf.php
# 修改base_conf.php配置文件
$BASE_urlpath='/base';
$DBlib_path='/var/www/adodb5';
$DBtype='mysql';
# 配置数据库的一些参数
$alert_dbname   = 'snort';
$alert_host     = 'localhost';
$alert_port     = '3306';
$alert_user     = 'root';
$alert_password = 'root';

2.4 web端访问base

# 在浏览器的地址栏中输入http://<ip>/base/base_main.php
# 这一步会加载base_conf脚本。
# 通常会提示"The underlying database snort@localhost appears to be incomplete/invalid"
# 点击提示的"setup page"
# 页面跳转后，点击“Create BASE AG”，之后会提示一系列红色的提示成功的消息。
# 回到http://<ip>/base/base_main.php

0x03 配置Graph

3.1 解决没有绘图的问题

进行完以上操作后，最基本的搜索查看功能是正常使用的。但当点击主页右侧的Graph Alert Data时，会提示Error loading the Graphing library:.

下面需要使用pear（PHP Extension and Application Repository）安装一些图形库：

# 更新插件
pear upgrade pear
pear channel-update pear.php.net
# 安装 Image_Graph-alpha、Image_Canvas-alpha、Image_Color、Numbers_Roman 这 4个包
pear install Image_Graph-alpha
pear install Image_Canvas-alpha
pear install Image_Color
pear install Numbers_Roman
pear install Numbers_Words-beta

重启httpd服务

systemctl restart httpd

3.2 解决图表没有标签、没有文字的问题
