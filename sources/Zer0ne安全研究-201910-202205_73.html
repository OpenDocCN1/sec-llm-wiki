本章将会结合Snort和iptables实现IPS# snort
snort -c /etc/snort/snort.conf -l /etc/snort/log -d -Q --daq nfq --daq-var queue=1
# 在这里经过测试nfq模式实际可用
# iptables
iptables -I INPUT -j NFQUEUE --queue-num 1 --queue-bypass
# --queue-bypass 表示当没有应用程序对iptables转过去的数据包做决策时，则iptables自动默认ACCEPT数据包
# iptables将位于INPUT链和OUTPUT链的数据包全部交由queue-num为1的应用程序去做ACCEPT、DROP的决策。这里queue-num为1的应用程序为snort

nfq模式只对iptables中设置了链的数据包进行判断，做一个决策。意即：如上述，iptables没有对output链进行设置，那么当本地去访问外部的一个web网站时，即使设定了规则文件，也不能对出去的流量做限制。应对input、output和forward链做一个设置

# snort
snort -c /etc/snort/snort.conf -l /etc/snort/log -d -Q --daq nfq --daq-var queue=1
# iptables
iptables -I INPUT -j NFQUEUE --queue-num 1 --queue-bypass
iptables -I OUTPUT -j NFQUEUE --queue-num 1 --queue-bypass
iptables -I FORWARD -j NFQUEUE --queue-num 1 --queue-bypass
