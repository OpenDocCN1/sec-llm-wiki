安装Snort完全版（一）

本篇文章将会成功安装snort，barnyard2，mariadb。snort产生的log会通过barnyard2存储进mariadb数据库

环境：Centos7

0x01 安装依赖组件

1.1 安装基础组件

yum install -y wget svn gcc gcc-c++ flex bison zlib zlib-devel pcre pcre-devel libtool curl man libxml2 make libpcap tcpdump git

1.2 安装libdnet

wget http://pkgs.fedoraproject.org/repo/pkgs/libdnet/libdnet-1.12.tgz/9253ef6de1b5e28e9c9a62b882e44cc9/libdnet-1.12.tgztar -xzvf libdnet-1.12.tgz./configure "CFLAGS=-fPIC" --prefix=/usr --libdir=/usr/lib64makemake install

1.3 安装libpcap

# 下载：wget http://www.tcpdump.org/release/libpcap-1.7.4.tar.gz# 解压：tar zxvf libpcap-1.7.4.tar.gzcd libpcap-1.7.4/# 编译：./configure --prefix=/usr --libdir=/usr/lib64# 安装：make make install

1.4 安装LuaJIT

不安装LuaJIT的话，在后边configure snort的话会显示ERROQ!LuaJIT library not found.

# 安装wget http://luajit.org/download/LuaJIT-2.0.5.tar.gz# 解压tar -xzvf LuaJIT-2.0.5# 安装makemake install

0x02 安装MariaDB

yum -y install mariadb-server mariadb mariadb-devel*# 不装mariadb-devel* 后面编译barnyard2会报错：cannot find mysql headersystemctl start mariadb.servicesystemctl enable mariadb.service# 修改数据库密码set password for 'root'@'localhost' = password('<password>')

0x04 安装与配置Snort

4.1 安装Snort

# 下载wget https://snort.org/downloads/snort/snort-2.9.15.tar.gz# 解压tar xzvf snort-2.9.15.tar.gzcd snort-2.9.15/# 编译./configure --enable-sourcefire# 安装makemake install

检查snort是否安装成功：

snort --v # 显示版本信息

检查daq支持的模式：

snort --daq-list

4.2 配置Snort

mkdir /etc/snort# 将Snort移动至/etc/snort/mv snort-2.9.15/etc/* /etc/snort/

4.3 配置snort.conf配置文件

# 创建存储日志的目录mkdir /etc/snort/log# 在/etc/snort/目录下创建rules目录mkdir /etc/snort/rules# 在新创建的目录下新建一些存储规则的文件touch /etc/snort/rules/local.rulestouch /etc/snort/rules/white_list.rulestouch /etc/snort/rules/balck_list.rules# 注释掉/etc/snort/snort.conf中包含的一些rules 。从548到651行# 修改规则所在目录var RULE_PATH ../rules  --> var RULE_PATH ./rulesvar SO_RULE_PATH ../so_rules --> var SO_RULE_PATH ./so_rulesvar PREPROC_RULE_PATH ../preproc_rules --> var PREPROC_RULE_PATH ./preproc_rulesvar WHITE_LIST_PATH ../rules --> var WHITE_LIST_PATH ./rulesvar BLACK_LIST_PATH ../rules --> var BLACK_LIST_PATH ./rules# 运行snort测试snort.conf是否配置正确：# 如果提示一些文件或目录不存在，则直接创建相应的文件

4.4 运行Snort

# 运行# snort -c <snort配置文件> -l <log目录> -i <接口> -d <接口> -k nonesnort -c /etc/snort/snort.conf -l /etc/snort/log -i ens33 -d -k none -D# 或者snort -c /etc/snort/snort.conf -l /etc/snort/log -i ens37:ens33 -d  -D # 注意：这里有一个坑# 最初按照其他人的blog，运行的命令后面没有加-k none,结果就是对于http_method等一系列rule option无法正常工作。论坛上的一个解释是“发生这个现象的原因是在嗅探的同一张网卡上生成了数据包”# -k none的含义是不对数据包进行任何校验。# 另一种方式是 -i ens37:ens33# ???我这里有一个问题，最初只有一个ens33接口，添加一块ens37接口后。# 使用 -i ens37:ens33可以正常工作，而使用-i ens33:ens37却不行# -D 表示以Daemon在后台运行

0x05 安装与配置barnyard2

Barnyard2的作用是读取Snort产生的二进制事件文件并存储到MySQL中。

Snort的配置文件自身含有插件，它允许将Snort报警记录到MySQL中，但这样一来，系统数据会激增。当IDS系统检测到入侵行为时，它会用INSERT语句向数据库中写入数据，导致更新非常慢。所以如果直接将Snort输出到数据库，在数据量增大时这种方案的效率并不高，故使用外部代理将报警输出到Barnyard2。

5.1 安装Barnyard2

# 下载git clone https://github.com/firnsy/barnyard2.gitcd barnyard2/# 编译autoreconf -fvi -I ./m4./configure --with-mysql --with-mysql-libraries=/usr/lib64/mysql/# 在# 安装makemake install

5.2 Barnyard2运行命令

# barnyard2运行命令一般为barnyard2 -c /etc/snort/barnyard2.conf -d /var/log/snort -f snort.u2 -w /var/log/snort/barnyard2.waldo# -c 指定barnyard2的配置文件# -d 指定snort输出log的目录# -f 指定snort输出的log文件# -w 指定waldo文件

什么是waldo文件？

waldo是一个通过启动barnyard命令生成的文件。一旦使用CTRL + C停止了稗并再次启动命令，它就不会记录以前记录的数据，而是记录新数据。“.waldo”文件类似于“待续”

要正常运行barnyard2，还需要配置Snort.conf文件：

# 修改snort.conf# 在output模块，开启以u2模式输出数据到snort.u2文件。该文件名称可自定义output unified2: filename snort.u2,limit 128

5.3 配置Barnyard2

# 创建一个waldo文件touch /etc/snort/log/barnyard2.waldo# 移动barnyard2的配置文件cp ~/barnyard2/etc/barnyard2.conf /etc/snort/# 创建或复制一个sid-msg.map文件。该文件的内容是规则的id与msg的对应关系touch /etc/snort/sid-msg.map# 修改barnyard2.conf配置文件output database: log, mysql, dbname=snort user=snort password=root host=localhost  # 数据库名为snort，用户名为snort，密码为root# 创建相应数据库mysql -uroot -prootcreate database snort# 创建相应table。barnyard2提供了创建table的语句，但是在执行的时候并不会为我们自动创建。因而我们需要手动创建，否则后面运行会提示：failed to execute query[select ...# 创建表的sql语句在源码的barnyard2/schemas/create_mysql中# 格式：mysql -u<username> -p<password> <dbname> < barnyard2/schemas/create_mysqlmysql -uroot -proot snort < barnyard2/schemas/create_mysql# 修改几个文件的位置：config reference_file:      /etc/snort/reference.configconfig classification_file: /etc/snort/classification.configconfig gen_file:            /etc/snort/gen-msg.mapconfig sid_file:            /etc/snort/sid-msg.map# 设置log目录config logdir: /var/log/barnyard2# 创建/var/log/barnyard2目录mkdir -p /var/log/barnyard2

5.4 运行barnyard2

barnyard2 -c /etc/snort/barnyard2.conf -d /etc/snort/log -f snort.u2 -w /etc/snort/log/barnyard2.waldo -D# 注意：需要先运行snort# -D 表示以Daemon在后台运行# 运行后如果出现“Waiting for new data”，则说明安装成功！
