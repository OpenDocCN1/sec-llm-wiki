### 0x05 安装与配置barnyard2

> Barnyard2的作用是读取Snort产生的二进制事件文件并存储到MySQL中。
> 
> Snort的配置文件自身含有插件，它允许将Snort报警记录到MySQL中，但这样一来，系统数据会激增。当IDS系统检测到入侵行为时，它会用INSERT语句向数据库中写入数据，导致更新非常慢。所以如果直接将Snort输出到数据库，在数据量增大时这种方案的效率并不高，故使用外部代理将报警输出到Barnyard2。

5.1 安装Barnyard2

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
# 下载git clone https://github.com/firnsy/barnyard2.gitcd barnyard2/# 编译autoreconf -fvi -I ./m4./configure --with-mysql --with-mysql-libraries=/usr/lib64/mysql/# 在# 安装makemake install
```

5.2 Barnyard2运行命令

*   
*   
*   
*   
*   
*   

```
# barnyard2运行命令一般为barnyard2 -c /etc/snort/barnyard2.conf -d /var/log/snort -f snort.u2 -w /var/log/snort/barnyard2.waldo# -c 指定barnyard2的配置文件# -d 指定snort输出log的目录# -f 指定snort输出的log文件# -w 指定waldo文件
```

什么是waldo文件？

> waldo是一个通过启动barnyard命令生成的文件。一旦使用CTRL + C停止了稗并再次启动命令，它就不会记录以前记录的数据，而是记录新数据。“.waldo”文件类似于“待续”

要正常运行barnyard2，还需要配置Snort.conf文件：

*   
*   
*   

```
# 修改snort.conf# 在output模块，开启以u2模式输出数据到snort.u2文件。该文件名称可自定义output unified2: filename snort.u2,limit 128
```

5.3 配置Barnyard2

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
# 创建一个waldo文件touch /etc/snort/log/barnyard2.waldo# 移动barnyard2的配置文件cp ~/barnyard2/etc/barnyard2.conf /etc/snort/# 创建或复制一个sid-msg.map文件。该文件的内容是规则的id与msg的对应关系touch /etc/snort/sid-msg.map# 修改barnyard2.conf配置文件output database: log, mysql, dbname=snort user=snort password=root host=localhost  # 数据库名为snort，用户名为snort，密码为root# 创建相应数据库mysql -uroot -prootcreate database snort# 创建相应table。barnyard2提供了创建table的语句，但是在执行的时候并不会为我们自动创建。因而我们需要手动创建，否则后面运行会提示：failed to execute query[select ...# 创建表的sql语句在源码的barnyard2/schemas/create_mysql中# 格式：mysql -u<username> -p<password> <dbname> < barnyard2/schemas/create_mysqlmysql -uroot -proot snort < barnyard2/schemas/create_mysql# 修改几个文件的位置：config reference_file:      /etc/snort/reference.configconfig classification_file: /etc/snort/classification.configconfig gen_file:            /etc/snort/gen-msg.mapconfig sid_file:            /etc/snort/sid-msg.map# 设置log目录config logdir: /var/log/barnyard2# 创建/var/log/barnyard2目录mkdir -p /var/log/barnyard2
```

5.4 运行barnyard2

*   
*   
*   
*   

```
barnyard2 -c /etc/snort/barnyard2.conf -d /etc/snort/log -f snort.u2 -w /etc/snort/log/barnyard2.waldo -D# 注意：需要先运行snort# -D 表示以Daemon在后台运行# 运行后如果出现“Waiting for new data”，则说明安装成功！
```
