这里需要更改一下策略，命令如下：


echo onreg add HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Associations /v ModRiskFileTypes /t REG_SZ /d .exe;.bat /fgpupdate /forcepauseecho off

wsgidav


上面的ruler-webdav是运行在我们攻击机kali上的，如果是windows，也有一些工具支持去创建共享，比如wsgidav，如果目标机是windows，又想在目标机创建共享，则也可以把wsgidav传到目标机去运行。


wsgidav提供了msi格式，如果传到目标机运行，需要图形化，操作不方便，可以先在自己机器上安装好，然后压缩传到目标机，再解压，windows自带的压缩解压命令：


压缩一个文件：makecab c:\wsgidav\ 1.zip 解压一个文件：expand c:\1.zip c:\windows\


wsgidav是一个命令行工具，运行示例如下：


wsgidav -H=0.0.0.0 -p=8080 -r c:\windows\temp\ --auth=anonymous

samba


samba可在linux平台下搭建smb服务，命令如下：


# 安装sambaapt-get install samba# 切换到samba目录下cd /etc/samba# 备份smb的配置文件sudo cp smb.conf smb.conf_bat# 编辑smb配置文件vim smb.conf# 重启服务sudo service smbd restart


smb配置文件，直接在底部添加以下内容即可：


[global]workgroup = WORkGROUPsecurity = usermap to guest = Bad User
[Share]path = /tmppublic = yeswritable = yesavailable = yes

windows-smb


widows本身设置相关文件夹为共享即可，这里测试以下命令操作。


cacls c:\windows\temp /e /g everyone:fnet share share=c:\windows\temp /grant:everyone,full


cacls命令自带，用来对文件夹权限做设置，参数说明：e：编辑acl（访问控制）而不替换。g：赋予指定用户的访问权限，f是full的意思，即完全控制。



net share命令设置共享，share指定共享文件夹目录，grant设置权限：
