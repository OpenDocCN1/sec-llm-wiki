**介绍**

  

CVE-2021-4034：Linux提权漏洞，主要原因在于Polkit包下的Pkexec工具存在内存损害，允许非特权用户利用提升到ROOT。

  

Pkexec默认安装，主要用来做临时的权限提升，和Sudo类似，简单理解如下：

  

*   
*   
*   

```
su：默认切换到root身份，需要提供root密码。sudo：执行的命令临时获取一个root权限，只需要提供当前普通用户的密码即可。pkexec：执行的命令临时获取一个root权限，弹框以图形化的形式输入普通用户的密码。
```

**影响范围**

Pkexec是系统预装的工具，所以主流的都会受到影响，像Ubuntu、Debian、Fedora、Centos等，从2009年起所有的Pkexec都会受到攻击，下面以Ubuntu20.04为例。

**防护**

建议更新到最新版：

  

*   
*   
*   
*   
*   
*   

```
# CentOSyum clean all && yum makecacheyum update polkit -y# Ubuntusudo apt-get updatesudo apt-get install policykit-1
```

![](../Images/c3afaf900a0ea18b2ef2eda9113319a7.png)

如果官方源没有更新的话，可以临时防护一下，从Pkexec中删除Suid，先取消该工具的临时高权限功能：

  

chmod 0755 /usr/bin/pkexec
