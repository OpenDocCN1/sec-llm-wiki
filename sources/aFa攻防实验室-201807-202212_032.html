介绍


越来越多的程序和站点都在使用Go语言进行开发，Go语言提供了相关的调试工具，即包net/http/pprof，可对程序和服务器进行调试分析。

默认情况下，不对pprof做限制，则意味可以直接访问获取相关的敏感信息。


环境


pprof只需要将net/http/pprof包导入，就可以通过地址/debug/pprof访问，如下示例代码：


package main
import (  "fmt"  "log"  "net/http"  _ "net/http/pprof" // pprof包用不到，导入就行，所以直接_忽略)
func main() {   // 访问站点跟目录，就调用第二个参数所指定的函数  http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {     // 打印个Hello    fmt.Fprintf(w, "Hello")  })  // 所有IP监听6060端口  log.Fatal(http.ListenAndServe(":6060", nil))}

参数说明


allocs：记录了其内存分配情况，点击直接查看即可。


block：跟踪堵塞情况，默认不开启，如果开启的话，可以大概知道程序的一些目录结构和文件名。


cmdline：获取程序启动时的命令和参数，一般会暴露其物理路径。


goroutine：查看协程信息，会泄露go包所在位置以及程序的相关信息。


heap：查看堆信息和GC垃圾回收信息。


mutex：互斥锁的堆栈跟踪，默认不开启。


profile：CPU相关信息。


threadcreate：线程堆栈跟踪。


trace：跟踪Go程序运行中的运行时事件。


信息查看


那么如何根据上面的参数来查看相关信息，这里也简单记录下，首先第一种是访问相关URL，带上?debug=1参数，可直接在浏览器查看：



如果不带，则默认是下载相应的文件：



这里也有例外，像profile和trace带上debug=1也会进行文件下载。


第二种就是通过交互式命令行来查看，比如上面说到的profile会下载文件，这里先下载该文件，然后进去命令行进行操作：



默认取的配置时间是30秒，如果想修改，可以通过seconds参数指定，进入命令行后就可以分析配置了，输入help查看命令说明，比如说top10查看消耗排名前10的函数：



第三种方法是图形化，图形化查看很简单，将profile文件下载后，使用go tool pprof命令即可，命令如下：


`go tool pprof -http=:6061 profile`


该命令会把profile配置文件以图形化方式展现出来，并放到指定的6061端口上：



上面提示没有安装graphviz，pprot图形化查看需要用到，这里在官网下载安装即可。



危害


综上所述，主要危害可以看到就是信息泄露，例如程序的相关路径、所在的物理路径、程序相关的函数名、文件路径甚至是部分源代码等等，另外，可能也会包含一些业务上的敏感信息，这些都说不准，需要具体查看。


pprof对外公开访问导致的信息泄露在Acunetix被定级为中危险，我们测试时也可以根据实际情况来进行调整。


查找


pprof官方建议在6060端口上访问，也有很多部署在80、8080、443上，而访问路径就是/debug/pprof，现在字典中基本都有，跑目录会跑出来，字典没有可以手动加下。
