**介绍**

  

Windows打印服务Print Spooler和进程spoolsv.exe，在添加端口监视器Port Monitors时，可以利用来加载恶意的DLL文件，实现权限维持，因为是系统服务运行，所以权限是SYSTEM，也会用来提权。  
添加Port Monitors有两种方法，第一种是通过注册表的方式，第二种是自定义Windows程序，该程序使用AddMonitor函数来加载DLL。因为涉及到注册表的添加和System32文件夹内容写入，所以前提是需要有管理员权限。

**自定义Windows程序**

  

自定义Windows程序即通过官方提供的函数AddMonitor来添加监视器，本质上还是加载dll文件，只不过是通过程序运行加载的，而不是注册表。

  

代码如下：

  

*

```
#include "Windows.h"
int main() {    MONITOR_INFO_2 monitorInfo;    TCHAR env[12] = TEXT("Windows x64");    TCHAR name[12] = TEXT("MonitorTest");    TCHAR dll[12] = TEXT("calctest.dll");    monitorInfo.pName = name;    monitorInfo.pEnvironment = env;    monitorInfo.pDLLName = dll;    AddMonitor(NULL, 2, (LPBYTE)&monitorInfo);    return 0;}
```

  

将上面C代码编译为exe，然后放到目标机system32下，和自己的dll在同一目录，然后手动运行exe来触发dll，我这里可能因为兼容问题导致消息提醒了：

  

![](../Images/82ad1c08bcb1b364e997ff12dd9c6779.png)

  

这种方式如果想自动触发来维持权限，则需要对exe进行处理，例如添加开机运行、定时任务等。

  

**排查**

  

对Monitors的权限维持排查时可使用procmon进行进程查看，查看spoolsv.exe进程下的程序、流程是否有异常的。同时，查看注册表的Monitors子项：

  

![](../Images/3cdf363aac4978d2b1b9b99457247f4a.png)
