**TCP基础**

  

使用go语言进行端口扫描，需要知道三次握手等流程。  
开放端口流程：  
1，客户端向服务器发送syn包。2，服务端返回syn-ack确认包。3，客户端向服务器发送ack包。

  

![](../Images/a4e62540b63fcf0ab2c9626764c95ed6.png)

  

关闭端口流程：

  

1，客户端向服务器发送syn包。

2，服务器返回rst包。

  

![](../Images/cf82f41de0935fa8addea6efa91bcbb1.png)

  

过滤端口流程：

  

1，客户端向服务器发送syn包，被防火墙拦截，请求超时，不会收到响应。

  

![](../Images/3382c74b7fdb4e097a2c4451fe581ce4.png)

  

**端口扫描器**

  

在go中，端口扫描需要用到net网络包下的dial函数。第一个参数指定连接类型，例如tcp、udp、unix sockets等。第二个参数指定连接的主机地址和ip，是一个字符串类型。

  

端口是否开放，可以通过连接是否报错来检查，当返回结果为nil时，则代表没错误端口是开放的状态，示例如下：

  

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
package main
import (  "fmt"  "net")
func main() {  _, err := net.Dial("tcp", "scanme.nmap.org:80")
  if err == nil {    fmt.Println("Connection successful")  }}
```

  

多个端口的扫描，可以通过for循环来实现，示例如下：

```
package main
import (  "fmt"  "net")
func main() {  for i := 1; i <= 1024; i++ {    address := fmt.Sprintf("scanme.nmap.org:%d", i)    conn, err := net.Dial("tcp", address)    if err != nil {      continue    }    conn.Close()    fmt.Printf("%d open\n", i)  }}
```

  

在扫描多个端口时，可以使用goroutine开启多个线程来检测，示例如下：

```
package main
import (  "fmt"  "net"  "sync")
func main() {  var wg sync.WaitGroup  for i := 1; i <= 1024; i++ {    wg.Add(1)    go func(j int) {      defer wg.Done()      address := fmt.Sprintf("scanme.nmap.org:%d", j)      conn, err := net.Dial("tcp", address)      if err != nil {        return      }      conn.Close()      fmt.Printf("%d open\n", j)    }(i)  }  wg.Wait()}
```

```
package main
import (  "fmt"  "net"  "sort"  "time")
func worker(ports, results chan int) {  for p := range ports {    address := fmt.Sprintf("scanme.nmap.org:%d", p)    conn, err := net.Dial("tcp", address)    if err != nil {      results <- 0      continue    }    conn.Close()    results <- p  }}
func main() {  t := time.Now()  ports := make(chan int, 100)  results := make(chan int)  var openports []int
  for i := 0; i < cap(ports); i++ {    go worker(ports, results)  }
  go func() {    for i := 1; i <= 1024; i++ {      ports <- i    }  }()
  for i := 0; i < 1024; i++ {    port := <-results    if port != 0 {      openports = append(openports, port)    }  }
  close(ports)  close(results)  sort.Ints(openports)
  for _, port := range openports {    fmt.Printf("%d open\n", port)  }
  fmt.Println(time.Since(t))}
```

  

线程池的数量越大，检测结果就会越快，一般建议设置一个合适的数值，避免结果不准确。
