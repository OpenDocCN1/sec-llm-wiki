介绍


在项目中，代码都会写在多个文件中，文件都会放在不同的包中。像之前写的测试程序都是放在main包中，该包包含了main函数，作为入口函数。而当功能多了，代码多了，就需要分包写入，而main包只需要导入即可。


包的导入


包使用package定义，导入时使用import导入。


例如有一个calc包，其中包含了Add方法，我们需要在main中进行导入，其中Add方法如下。


package calc
// 方法名首字母大写，代表共有的，共有才可被外部调用// 如果小写就是私有，当自己被导入时，是不允许被调用的func Add(x, y int) int {  return x + y}

包的别名


包可以设置别名，在导入路径前定义别名即可。


import (  "fmt"  // 定义calc包别名为c  c "gotest/main/calc")
func main(){  result := c.Add(1, 2)  fmt.Println(result)}


匿名导入包


如果只是想导入包，而不用到包中的方法，则可以匿名导入，匿名导入即把别名换成下划线即可。如下实例，导入的calc在没有用到时，保存go会自动去除，这时使用匿名导入，再保存，则不会被自动去除。


import (  "fmt"  _ "gotest/main/calc")
func main(){  fmt.Println("test")}


init方法


每个包都可定义init方法，该方法没有参数没有返回值，不需要手工调用，当包被调用时，该方法会自动执行。例如在calc包中添加init方法。


func init(){  fmt.Println("this is calc package")}


这时main包中导入calc，main运行时会自动调用calc的init。
