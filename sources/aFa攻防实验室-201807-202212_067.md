**介绍**

  

go中的指针不像c，go的指针不能进行运行。在go中，指针涉及到的概念有指针地址、指针类型、指针取值等操作。  
当数据加载到内存时，都会有一个内存地址，这个就是指针。

  

**指针地址**

  

在go中，我们通过&来取地址，通过\*可根据地址取值。

  

每个变量都会有一个地址，代表了该变量在内存中的位置。查看一个变量的地址，也就是查看指针地址，可在变量前加&符。

  

*   
*   
*   
*   
*   

```
func main(){  test := "afa gong fang shi yan shi"  testDizhi := &test  fmt.Println(testDizhi) // 0xc00003a1f0}
```

  

上面testDizhi变量保存的值是test变量的地址，testDizhi变量也有自己对应的地址。

  

**根据地址取值**

在得到地址的情况下，也可以进行取值操作，通过\*号取值。

  

*   
*   
*   
*   
*   
*   

```
func main(){  test := "afa gong fang shi yan shi"  testDizhi := &test  testZhi := *testDizhi  fmt.Println(testZhi) // afa gong fang shi yan shi}
```

  

**new和make区别**

1，new和make都可以用来分配内存。

2，make只用用于引用类型，例如slice、map、channel，对它们进行初始化，初始化后返回其本身。

3，new用于值类型，例如int、string、bool等，返回的是指针，且内存会存储对应的默认值。
