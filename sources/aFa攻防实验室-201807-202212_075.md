需要注意的是go中的数组一旦定义，长度就固定了，就不能改变了，且长度不一样的数组，类型是不一样的，如下示例。

```
func main(){  var nums1 [3]int  var nums2 [5]int  fmt.Printf("%T", nums1) // [3]int  fmt.Printf("%T", nums2) // [5]int  // 下面语句报错，nums1和nums2不是一个类型  //if nums1 == nums2 {  //  fmt.Println("true")  //} else {  //  fmt.Println("false")  //}}
```

go在声明数组时，会根据类型赋予默认值，例如int的就是0，也可以手动初始化，初始化值写在大括号中，如下示例。

  

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
package main
import "fmt"
func main(){  var nums1 [3]int  fmt.Println(nums1) // [0 0 0]  var nums2 = [3]int{1, 2}  fmt.Println(nums2) // [1 2 0]}
```

  

我们在写数组时，一般会让go自动识别数组的长度，这样我们就不用手动定义长度了，而让go根据元素数量来定义数组长度，只需要使用三个点就可以了，示例代码。

  

*   
*   
*   
*   
*   
*   
*   
*   

```
package main
import "fmt"
func main(){  var nums = [...]int{1,2,3,4,5}  fmt.Printf("%T", nums) // [5]int}
```

  

同时，数组初始化时支持根据索引号来赋值，如下实例。

  

*   
*   
*   
*   
*   
*   
*   
*   
*   

```
package main
import "fmt"
func main(){  var nums = [...]int{1:6,6:8}  fmt.Printf("%T", nums) // [7]int  fmt.Println(nums) // [0 6 0 0 0 0 8]}
```

  

**数组的遍历**

  

数组遍历有两种方法，一种是通过for循环，一种是通过range。for range可遍历数组、切片、字符串、map和通道，数组、切片、字符串返回索引和值，map返回键和值，通道返回值。

  

*   
*   
*   
*   
*   
*   
*   
*   
*   

```
func main(){  var nums = [...]int{1:6,6:8}  for i := 0; i < len(nums); i++ {    fmt.Print(nums[i]) // 0600008  }  for _, value := range nums {    fmt.Print(value) // 0600008  }}
```

  

**多维数组**

  

当数组的类型为数组时，可以叫多维数组或嵌套数组，需要注意的是，如果让go根据元素数量定义数组长度，则只有第一层数组可以使用三个点。

  

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
func main(){  city := [...][2]string{    {"河北", "石家庄"},    {"河南", "洛阳"},    {"湖北", "武汉"},  }  fmt.Printf("%T \n", city) // [3][2]string
  for index, value := range city {    fmt.Println(index, value) // 0 [河北 石家庄] 1 [河南 洛阳] 2 [湖北 武汉]  }}
```

  

最后还有个需要注意的是，调用另外一个函数，参数为数组，在函数中修改的值是数组的副本，原本数组值不会改变。

  

*   
*   
*   
*   
*   
*   
*   
*   
*   

```
func arrayTest(b [3]int){  b[0] = 8}
func main(){  a := [...]int{6, 6, 6}  arrayTest(a)  fmt.Println(a) // [6 6 6]}
```

  

**数组示例**

  

有一个数组，需要把值相加等于8的元素下标打印出来，例如{1, 3, 5, 7, 8, 0}，打印出03，12，45，示例代码如下。

  

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
func main(){  arr := [...]int{1, 3, 5, 7, 8, 0}
  for i := 0; i < len(arr); i++ {    for j := i; j < len(arr); j++ {      if arr[i] + arr[j] == 8 {        fmt.Println(i, j)      }    }
  }}
```
