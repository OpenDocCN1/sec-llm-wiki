**前言**

  

go语言的优点和特点可以不看，做为安全从业者，我们比较关心的可能是go在安全中可以做什么，我们比较熟悉的就是python，常用来写利用脚本、写攻击工具，同样，go也很出色。  
据去年统计，检测攻击中用的最多的语言是python，其次是go，相差不多，且go也越来越流行。最近用到的一些工具中，也有很多是使用go编写的。

  

**环境安装**

  

官网是golang.org，如果慢或者打不开，可以使用官方的镜像站，地址是golang.google.cn，下载自己系统的安装包安装即可，安装后可在命令行输入go version命令查看。

  

![](../Images/5cb56e6d652403919291fa5f5f107593.png)

  

输入go env命令查看go相关的环境变量，常用的变量有：

GOPATH：为go语言的工作目录，也就是项目目录，一般在相关账号目录下面。

GOROOT：是go的安装路径。

GOPROXY：设置代理，因为墙，go下载一些包会很慢或者失败。

GO111MODULE：开启mod管理包的方式。

  

![](../Images/a5ebff043cf6e47167ccf2ba67ca7b98.png)

  

其中GOPROXY配置推荐使用https://goproxy.cn/或者https://goproxy.io/，例如运行命令go env -w GOPROXY=https://goproxy.cn,direct就可以了。

  

其中GO111MODULE建议配置为on，运行命令go env -w GO111MODULE=on即可。这个变量的作用是开启go的模块管理功能。go在早期的时候，项目只能写在GOPATH下，然后依赖包也会下载到这个目录下，当项目多了，项目大了，包也会很多，管理起来很乱。后来官方就出了一个mod包管理方式，即项目不用必须写在GOPATH下，可以放到任何目录下，只要在项目下写一个go.mod文件，该文件中写入要依赖的包即可。前提是要把GO111MODULE设置为on。

建好的项目下默认会有一个go.mod文件，代表项目时候模块方式来管理包，go.mod中就是项目用到包的依赖等信息，项目编译时会读取这个文件。

  

这时可以建一个main.go文件，随便引入一个包，会发现报错，提示没有找到，因为我们此时用的是mod方式，它不会去GOPATH下找，而是在当前项目下的go.mod中找，我们可以点击sync dependencies来同步依赖进行导入。

  

![](../Images/d7ba676ea78fb53c4325cd23d8cbbaa5.png)

  

点击同步依赖后相当于ide执行了go mod download命令，此命令用来下载相关依赖，这里我们执行此命令做测试。

  

![](../Images/f500bbae636fd27c9003c065665e9c01.png)

  

执行后，会发现相关依赖包就已经下载到了当前项目下，且错误由原来的同步依赖变成了未导入。同时目录下面会多出一个go.sum文件。

**helloword**

  

go程序写好后，可以通过go build命令进行编译，使用mod管理依赖，可以直接在项目下运行该命令，会生成一个以项目同名的exe文件，示例代码和编译如下。

  

*   
*   
*   
*   
*   
*   
*   

```
package main
import "fmt"
func main() {  fmt.Println("hello")}
```

  

![](../Images/320404f9343fbc608998036a8919b754.png)

  

注意：执行的main函数必须在main包下面。

  

fmt包实现了格式化I/O函数，类似于C的printf和scanf，更多包和详细用法可参考https://studygolang.com/pkgdoc

  

go也支持跨平台编译，可以在windows下写代码，编译后在linux或mac上运行。这里以windows下编译linux为例，在以后写工具或脚本过程中，linux的可能会经常用到。

  

命令如下：

  

*   
*   
*   

```
SET CGO_ENABLED=0  // 禁用CGO,CGO做用是让go调用c的库，这里关闭（默认开启），开启无法进行跨平台编译SET GOOS=linux  // 目标平台是linuxSET GOARCH=amd64  // 目标处理器架构是amd64
```

  

设置三个环境即可，这些环境变量的值可以通过go env查看。设置后再次通过go build编译即可，如下图。

  

![](../Images/ae61f4a382a35365d7ec89cfae6fdf39.png)
