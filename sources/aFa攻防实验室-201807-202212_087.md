**介绍**  

  

Neo-reGeorg可以用来搭建http隧道，Neo-reGeorg说是对reGeorg进行了重构，增加了很多特性，例如像内容加密、避免被检测、请求头定制、响应码定制、支持py3等等，更详细可参考官方说明。  
地址：https://github.com/L-codes/Neo-reGeorg

  

**使用**

  

这里以kali为例进行下载，执行下命的命令进行下载，下载后调用neoreg文件，加generate参数生成利用脚本，k指定连接密码。

  

*   
*   

```
git clone https://github.com/L-codes/Neo-reGeorg.gitpython3 neoreg.py generate -k 1x2x3x4x5x6
```
