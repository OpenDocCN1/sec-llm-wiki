准备条件


以kail为例搭建一条到windows上的隧道，常见的使用icmp的就是ping命令。


1，首先在kali中下载icmpsh。


`git clone https://github.com/inquisb/icmpsh.git`


PS：icmpsh下载后的run.sh只能运行在linux上，也就是服务端（攻击机），icmpsh.exe只能运行在windows上，也就是客户端（受害机）。并且icmpsh只能从linux向windows搭建。


2，安装python的impacket包，impacket可以对各种协议进行访问，而icmpsh运行时需要用到impacket。可以直接通过apt-get安装。


`apt-get install python3-impacket`


也可以下载源码安装。


`git clone https://github.com/CoreSecurity/impacket.git

cd impacket/

python3 setup.py install`


3，最后我们需要把kali系统本身的ping命令应答程序关闭，icmpsh需要代替kali进行应答，如果kali本身开启的话，会导致冲突出错。使用sysctl命令来配置参数，将相应值设置为1关闭，0为开启，命令如下。


`sysctl -w net.ipv4.icmp_echo_ignore_all=1`


第三点如果你是直接运行run.sh来操作的，则不用手动关闭icmp应答，run在运行时会自动检测是否关闭ping应答，如果没有，会临时进行关闭，当我们把icmpsh关闭后，会被自动再开启，通过run.sh的代码我们也可以看出来。



而run.sh的主要作用就是检测icmp应答然后调用icmpsh_m.py运行，我这里直接运行run.sh一直有个impacket的错误，索性就手动关闭icmp应答，然后运行icmpsh_m.py文件。
