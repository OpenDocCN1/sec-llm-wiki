# Vmware还原慢问题

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjcxMjkyOA==&mid=2247484530&idx=1&sn=03796cec2f3879f6212daa2f6a9316b1&chksm=9baceafdacdb63ebc968906a77d6eb09c769aea2306082631ec74962bf47114f07f2d241f06b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjcxMjkyOA==&mid=2247484530&idx=1&sn=03796cec2f3879f6212daa2f6a9316b1&chksm=9baceafdacdb63ebc968906a77d6eb09c769aea2306082631ec74962bf47114f07f2d241f06b&scene=27#wechat_redirect)

![](../Images/d60c5151bb856174d06975431beb3add.png)

  

之前vmware挂起虚拟机后，下次还原比较慢，一直也没管，认为不算什么问题，就是多等一会。后来看一个朋友还原用了不到十秒。

  

说是vmware需要加到防火墙白名单中，我试了下，速度确实提上去了，大家可以参考下。我本机用的win10，首先在控制台-系统和安全-windows defender防火墙-允许的应用，把vmware程序添加进去即可。  

  

![](../Images/072b6c7b18da07b5f34fdf5480ae3c5f.png)

  

建议本机添加后重启一下，虚拟机挂起的系统也建议重启下，下次再挂起还原速度会有一定的提升。
