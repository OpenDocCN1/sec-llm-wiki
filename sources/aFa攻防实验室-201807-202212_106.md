介绍

  

DCOM是distributed component object model的缩写，翻译为分布式组件对象模型，简单理解就是一堆组件、一堆接口，对于我们使用来说可以更简单认为是一个工具集，dcom利用包含的接口，可以与网络中其他计算机上的服务和程序通信。它是基于组件对象模型com的，com提供了一套客户端和服务端通信的接口，也可以理解为dcom继承了com。  
总之，dcom可以理解为工具集，它可以远程执行命令，和前面说的at、schtasks、psexec、wmi、smbexec等类似。

  

本地dcom执行命令

  

通过Get-CimInstance Win32\_DCOMApplication命令可以获取dcom程序列表，需要注意的是get-ciminstance在powershell3.0以上版本才存在，也就是windows server2012及以上。

当然，新版对旧版兼容，get-wmiobject在win10等系统上也可以用。

  

下面看一下本地执行的示例，首先第一条命令在本地启动一个powershell，使用的是mmc20类，这个类可以使用脚本来进行相关管理。第二条命令：在mmc20类下有一个executeshellcommand方法，该方法可以用来执行命令。

  

![](../Images/d1499797f630ccd26d4490018fad7845.png)

  

我们可以通过get-member来查看类中都有哪些方法，关于类中方法的具体使用和参数说明等，可以查看微软给出的文档说明。(https://docs.microsoft.com/en-us/openspecs/windows\_protocols/ms-dcom/)

  

![](../Images/e34e4442b29b00d590b7ee804fbab0bb.png)

  

上面运行命令方式适用于powershell3.0以上，非3.0以上则需要使用下面这种。

```
$com = [Type]::GetTypeFromCLSID('9BA05972-F6A8-11CF-A442-00A0C90A8F39',"192.168.1.6")$obj = [System.Activator]::CreateInstance($com)$item = $obj.item()$item.Document.Application.ShellExecute("cmd.exe","/c calc.exe","c:\windows\system32",$null,0)
```
