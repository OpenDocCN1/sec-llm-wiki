**简介**

  

windows本地用户的相关信息保存在sam文件中，sam是被锁定且不允许复制的，lsass进程实现了windows的安全策略（本地安全策略和登录策略），上一篇文章也说到过lsass记录了明文密码和ntlmhash，而我们抓取密码的方式一个就是从内存的lsass进程中获取，第二个就是从sam文件中获取。

  

**PE进入复制sam**

  

这种方法实际渗透中是用不到的，但我们应该知道有这么一回事。科普1：pe也是一个系统，比较小用来应急的，可对原系统进行操作，一般装u盘里，使用也方便。常用的功能就是重新部署、还原系统等。因为可对原系统做操作，所以我们可以在忘记密码的时候进行密码清除和修改，获取密码需要把sam文件复制出来，然后再进行后续的破解。

  

**VSS复制sam**

  

windows2003起引入了一个vss存储技术，全名叫Volume Shadow copy Service,卷映射拷贝服务，简单理解就是可以对磁盘上的文件进行备份。

  

在nishang的gather信息搜集模块中提供了相应的脚本copy-vss，使用方法直接看readme就可以。从github下载后它已经把powershell脚本都按类别分好了，使用时如果要导入所有脚本就用import-module .\\nishang.psm1，单个脚本导入就用点。

  

科普2：psm1是脚本模块，里面存的是一些ps命令，导入时需要用import-module，ps1是ps脚本文件，里面是相关代码，导入时可以使用点也可以直接运行。如果ps脚本文件比较多，就可以通过脚本模块使用命令一次性全部导入。

  

科普3：通过点可引入ps脚本文件，这种方式引入后会保存脚本中的变量和函数，也就意味着你可以通过命令行输入变量名或函数名来进行调用。

  

回到copy-vss，copy-vss会复制三个文件，分别是sam、system、ntds.dit，sam和ntds.dit上篇说过，如果copy-vss在域控主机上运行，那ntds.dit也会被复制，我这里本机所以没有这个文件。system是注册表数据库，存的是注册表的信息。使用示例：

**注册表导出sam**

  

通过reg命令可以导出注册表中的sam、system、security文件到本地，这个方式属于正常操作，有一定的免杀效果，示例（后缀hiv也可以）：

  

![](../Images/5a90734122a94b66500399a8461d1ca7.png)

  

科普4：reg命令是用来操作注册表的，save关键字就是保存，这里注意使用的是save而不是export导出。区别：save保存的是hive格式，也就是配置单元格式，保存了元数据，相当于原封不动的格式保存的，你打开是十六进制的。export导出的是reg格式，可直接文本打开，它只是保存了注册表的路径键值等信息。

科普5：hklm代表的是HKEY\_LOCAL\_MACHINE，后面跟的是导出的文件名。hive文件是配置单元文件，其实就是一个文件，只不过里面包含了相关的配置信息，例如sam的配置单元，它就保存了sam的一些信息，只不过是以注册表形式存在的。

**单机密码抓取防范**

  

如果密码足够复杂，那么hash是不容易破解的。在windows server2012以上版本默认关闭了wdigest（windows下的一个安全协议），关闭后是不能从lsass中获取明文密码的，这时的lsass是不会缓存明文密码的。而2012以下的版本如果打了KB2871997，则lsass也不会存明文密码。通过上面的一些mimikatz结果可以看到wdigest下的password为null。所以防范时一个保证密码复杂度，另一个就是确保wdigest的关闭。

  

当然我们也可以进行打开，操作注册表相关项即可，1为打开0为关闭，打开后当前账号需要注销或者从新登录，这时lsass才会去存明文密码，下面是reg和powershell的命令和示例截图：

  

*   
*   

```
reg add HKLM\SYSTEM\CurrentControlSet\Control\SecurityProviders\WDigest /v UseLogonCredential /t REG_DWORD /d 1 /fpowershell -c "set-itemproperty -path HKLM:\SYSTEM\CurrentControlSet\Control\SecurityProviders\WDigest -Name UseLogonCredential -Type DWORD -Value 1"
```

**总结**

  

windows单机密码可从sam文件和lsass进程中提取。sam文件可以拷贝出来或者是用注册表导出来，然后通过mimikatz离线读取，也可以使用mimikatz直接在线读取。lsass进程可通过右键导出dump文件，或者procdump、sqldumper等工具导出。除此外一些其他工具也支持windows密码获取，例如nishang的get-passhashes脚本、powersploit的Invoke-mimikatz脚本，这些powershell脚本可以传目标机执行，也可以远程加载使用。最后就是lazagne工具，可以获取多方面的密码，其中就包括windowshash。
