## **0x00：介绍**

mimikatz 用来提取 windows 系统的密码，mimikatz 很小巧，除了抓取密码外，还可以抓取 hash，kerberos 等，kerberos 是用来进行身份验证的网络授权协议。因为很小巧功能又强大，msf 便集成了 mimikatz 这个工具，拿到 shell 后不用再上传运行，可以在 msf 中直接使用。

## **0x01：使用**

mimikatz 使用需要有目标的管理员权限，当有了管理员权限后使用 load mimikatz 加载即可。加载成功后，通过 help mimikatz 命令查看命令说明。

![](../Images/2851345d16ac2477602154eb615e795e.png "请输入图片描述")

例如输入 msv 来获取系统的 hash。

![](../Images/6f7d8e3dc03734c8a3800f1e5f59f0dd.png "请输入图片描述")

输入 kerberos 来获取系统的票据。

![](../Images/cdc4aa3e46ff42f9f700ea18bf719d58.png "请输入图片描述")

输入 wdigest 获取系统的账户信息。

![](../Images/3e3056a58943c3eedb655c5277bfe696.png "请输入图片描述")

上面是 mimikatz 的参数说明，除此外 mimitakz 也提供了很多的模块，列举模块需要使用 mimikatz\_command 来运行命令，通过 f 参数来指定模块，模块后跟两个冒号，代表使用此模块，列举此模块的信息。当指定的模块不存在时，mimikatz 会提示当前模块不存在，可使用的模块有哪些，即可以列出所有可用的模块。

![](../Images/7eb5a99ceab1a62955849a6e55f8b0b1.png "请输入图片描述")

例如 samdump 模块，描述翻译过来就是下载 sam 文件，也就是获取密码文件的，查看此模块的参数说明，可执行命令 mimikatz\_command -f samdump::, 可以看到有一个 hashes 参数用来获取 hash 值，使用此参数输入命令 mimikatz\_command -f samdump::hashes 即可。

![](../Images/1ea7a1786aca50e702cd08f99faa5772.png "请输入图片描述")

例如 handle 模块下的 list 参数，用来获取所有的进程。

![](../Images/dfba51f2e0efaf3bde1b47ff0e2d0d9b.png "请输入图片描述")

例如 service 模块下的 list 参数，用来获取所有的服务。

![](../Images/b627bc598baa4ec0c152c796f7bbf607.png "请输入图片描述")

例如 ctypto 模块下的 listProviders 参数，用来获取证书和私钥。

![](../Images/cd8746c1f5865ac1e6c3f83906bf0742.png "请输入图片描述")

## **0x02：总结**

mimitakz 集成到了 msf 中，后期渗透更方便，提供了各种获取目标机敏感信息凭据等操作方法。

直接提取密码可以使用另个命令，一个是 privilege::debug，即 privilege 特权模块下的 debug 参数，用来提取权限。另一个就是 sekurlsa::logonpasswords，即 sekurlsa 下的 logonpasswords 参数，logonpasswords 就是登录的密码，sekurlsa 是用来获取密码的，密码来与 lsass 进程中，lsass 是用来验证用户身份的这个一个进程。
