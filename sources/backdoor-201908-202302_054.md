# centos7搭建H1ve环境

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5MzkwMzU1Nw==&mid=2247484239&idx=1&sn=a475e6f252306faca0132be55ae6177f&chksm=ec6a4ee5db1dc7f36247809e6f695088795bd0653f123b51504a12bebed57c0ff53f393cc639&scene=126&sessionid=1681665102#rd](http://mp.weixin.qq.com/s?__biz=MzI5MzkwMzU1Nw==&mid=2247484239&idx=1&sn=a475e6f252306faca0132be55ae6177f&chksm=ec6a4ee5db1dc7f36247809e6f695088795bd0653f123b51504a12bebed57c0ff53f393cc639&scene=126&sessionid=1681665102#rd)

  

H1ve是一款开源的ctf平台,具备解题和攻防对抗模式,并且还有可视化战况界面.是个很不错的平台,我们今天来搭建一下,顺便解决一下搭建的各种问题.

系统版本:centos7

需要环境:

1.  docker
    
2.  python2 pip
    
3.  docker-compose
    
4.  mariadb
    

开始搭建,先重新安装一个centos7的虚拟机.(mini最小化安装,安装过程不表).

![](../Images/bb01629550438ff6dcff73de76d5eea1.png)

  

1.先安装docker

依赖环境

yum install -y yum-utils device-mapper-persistent-data lvm2 bind-utils

设置docker源

yum-config-manager --add-repo https:*//download.docker.com/linux/centos/docker-ce.repo*

安装docker

yum install docker-ce -y

查看docker版本

docker version

![](../Images/34dc9e117eaf9095affabbf617a1e528.png)

现在还没有开启docker 服务.  

 

2.安装python2 pip

安装pip不能通过yum安装,需要先安装epel-release,然后再去安装pip

yum -y install epel-release

yum -y installpython-pip

升级pip

pip install *\--upgradepip*

![](../Images/164867670fdd29ee89514b7f9ee18cc9.png)

pip安装docker-compose

pip install docker-compose

3.安装docker-compose

Pip install docker-compose

遇到报错

![](../Images/f10c4ec92bd9e1995783dd1d3cdff164.png)

![](../Images/0eaf5d29881753c6535908f9a5447bab.png)

Google后发现是一些依赖没有安装

Yum install python-devel git gcc

这次没有报错,安装成功.

![](../Images/c1f9f15ce77967a65a4c8881d4cfd421.png)

  

看看docker-compose版本

![](../Images/0b2af5c8284bb43e267d2082d28994ea.png)

  

4.安装mariadb,

先检查系统是否安装的mariadb.

Rpm -qa | grep mariadb

![](../Images/6541cd4928f696e55eb80c8f653789a4.png)

  

可以看到,默认是安装了,卸载就是.

Rpm -qa | grep mariadb | xargs rpm -e–nodeps

然后再查看一下

![](../Images/8f44c8d1dc66e985f4212e26cd5900a5.png)

  

然后安装mariadb数据库.这里要安装指定版本.(10.4.12版本)

Vim编辑文件,没有vim.安装一下.

Yum install vim -y

vim /etc/yum.repos.d/MariaDB.repo

![](../Images/c1f9f15ce77967a65a4c8881d4cfd421.png)

  

内容:

\[mariadb\]

 

name = MariaDB

baseurl = http://yum.mariadb.org/10.4.12/centos7-amd64

gpgkey=https://yum.mariadb.org/RPM-GPG-KEY-MariaDB

gpgcheck=1

更新系统索引,更新系统

Yum makecache fast

Yum update -y

安装mariadb数据库(10.4.12版本)

yum -y install MariaDB-serverMariaDB-client

设置开机自启动mariadb并且开启

systemctl enable mariadb

systemctl start mariadb

![](../Images/0b01fc4ecf1b317886eaa7d6fef2893c.png)

  

5.下载H1ve源码

https://github.com/D0g3-Lab/H1ve.git

官方github下载速度有点慢,这里建议自己去gitee复制过来下载.下面给出我的地址.

https://gitee.com/cxaqhq/H1ve.git

git clone https://gitee.com/cxaqhq/H1ve.git

![](../Images/0cd0767c216138301988e92fa0e8d1c3.png)

  

6.启动H1ve

修改配置文件中mariadb版本 10.4改成10.4.12

Vim single.yml

![](../Images/84f61e8498ca1f8b2db092d3779e894d.png)

启动docker

systemctl start docker //启动docker

systemctl status docker //查看服务信息(是否启动运行)

![](../Images/425dc58d9ddc0cf4ea04824c899aa4f0.png)

  

这里需要等待一会,因为要获取docker镜像文件.(不同地区的网速不一样)

然后就开始启动ctfd服务,运行h1ve了.

![](../Images/b3df370545be2b0c84e674a84b453fc5.png)

  

访问地址:http://ip:8000/

![](../Images/aa4d2a7ac001f3532db056e70c91dd5a.png)

  

  

自己按要求设置一下,然后就搭建好了

![](../Images/d83c3f652b9817a0c14cd2423bfaec81.png)
