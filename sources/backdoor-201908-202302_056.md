cobalt strike dns beacon  

  

简单的来说，就是木马上线走dns协议。目的就是掩人耳目。避免被发现！

实战来说，还是有作用的。比如躲避流量检测什么的。我就喜欢用它来做持久控制。

  

咱们就来讲讲如何设置这个 dns beacon

先上官网链接：https://www.cobaltstrike.com/help-dns-beacon

![](../Images/ec0fac312c523e77bbb0f754b26eac96.png)

此处借鉴官方的讲解图，说的就是dns协议。帮助大家理解。

我们来实际操作一下，看看咱们搭建这个。

1，需要一台公网ip的vps。

2，一个域名。

3，如果还有3的话那就是做dns解析的网站。(便宜的域名居然无法更改ns记录，惨)

  

首先vps搭建好cobaltstrike服务。记得防火墙开启53端口，而且协议为udp，别问我为什么，问就是dns不走tcp协议。

  

找的你的域名控制面板，设置一个A类地址。ip指向自己的cobaltstrike服务器，然后设置几个NS解析，域名解析到刚刚设置A类的域名。上图。

![](../Images/93df1c8f6128d094e69ca52eb49dfd69.png)

原谅神打码

例子：

dns.xxxx.com --> 123.456.78.9 A类解析

ns1.xxxx.com --> dns.xxxx.com NS

ns2.xxxx.com --> dns.xxxx.com NS

设置解析好了以后。等着吧。等解析好再说。

什么样叫解析好？查一下

windows: nslookup

linux: dig +trace

上图

![](../Images/f850f5e6a9ee588416aeb5f32611951d.png)

![](../Images/06eb241f7b6cf1c53233ed1c70f4c1fb.png)

查询的值是 0.0.0.0 那就说明你离成功又近了一步  

我们再来看看cobaltstrike dns设置

![](../Images/f67fa244417ea8c1f9cbeaac7429ea78.png)

重要的就两个参数

dns hosts 就是填NS记录值的域名

dns host 就是A记录的域名

简单吧。

然后随便生成个木马。运行一下，很快就上线了，看着挺成功的，这里有个大坑。

![](../Images/4f2d23a535f48463555ee8c438d1f018.png)

因为cobaltstrike4.0 dns beacon 默认是dns\_txt 看着比dns多了一个txt，其实传输速度差很多的

经过自己实际测试，国内默认dns\_txt 模式执行个命令没有一次成功，等待时间半个小时没反应。

解决方法。在第一次主机上线后通过命令更改模式为dns

这是刚上线情况下。

等待时间可能有个几分钟，希望大家有点耐心。

而且4.0和之前版本的dns beacon有区别，有兴趣的话大家可以自行抓包看看
