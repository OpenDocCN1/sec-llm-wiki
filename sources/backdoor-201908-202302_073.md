## 安装metasploitable2

**安装什么的就不用说了，下载完直接是vm虚拟机格式，直接打开即可，设置好网络。**

**打开后，登录用户名密码都是msfadmin ，**

**登录后是一个终端页面，咱们看一下ip地址，其他的就不用关了，什么服务什么的都已经自动开启了。**

![](../Images/d8fa78d9d6cb0b44af9d057cbc834fe2.png)

  

**欧克，靶机ip出来了：192.168.134.134**

**现在就是来配置msf了。**

## 配置metasploit

**安装**

**Apt-get install Metasploit-frameworks -y**

**安装postgresql**

**Apt-get install postgresql -y**

**Msf5****现在已经没有自动攻击模块了，需要自己下载添加msf文件，有人说找不到下载地址？**

**下载地址其实msf有，你们看看，很贴心的。**

  

![](../Images/2b630b66c9bed76dafa08757404bc757.png)

  

**See ****后面那个就是下载地址，我这个是已经添加完了的，要是没有添加的话你加载这个模块不仅有下载地址，还有需要放置的文件夹地址。**

**Load db\_autopwn //****加载模块**

**msf5auxiliary(scanner/portscan/tcp) > load db\_autopwn**

**\[-\]Failed to load plugin from /usr/share/metasploit-framework/plugins/db\_autopwn:cannot load such file -- /usr/share/metasploit-framework/plugins/db\_autopwn.rb**

**msf5auxiliary(scanner/portscan/tcp) >**

**这是我删除模块后加载的情况，它告诉你了模块应该放置的目录。**
