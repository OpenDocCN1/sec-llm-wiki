**用法**  

  

*   启动所有模块
    

```

laZagne.exe all
```

*   仅启动特定模块
    

```

laZagne.exe browsers
```

*   仅启动特定的软件脚本
    

```

laZagne.exe browsers -firefox
```

*   将找到的所有密码写到文件中（普通txt为-oN，Json为-oJ，所有为-oA）。注意：如果您在解析以多行字符串形式编写的JSON结果时遇到问题，请选中this。
    

```
laZagne.exe all -oN
```

*   得到帮助
    

```
laZagne.exe -h
```

*   更改详细模式（2个不同级别）
    

```

laZagne.exe all -vv
```

*   安静模式（标准输出上不会打印任何内容）
    

```

laZagne.exe all -quiet -oA
```

*   要解密域凭据，可以通过指定用户Windows密码来完成。否则，它将尝试将所有已找到的密码作为Windows密码使用。
    

```

laZagne.exe all -password ZapataVive
```

注意：对于wifi密码\\ Windows Secrets，请以管理员权限启动它（UAC身份验证/ sudo）
