0x01 工具介绍

Kunyu测绘工具，主要应用Zoomeye网站提供的信息，可以理解为简化版的Zoomeye。

0x02 安装与使用

1、安装所需要的库文件

pip3 install -r requirements.txt

2、安装Kunyu

sudo python3 setup.py install

3、初始化操作

从下面两个地址获取并设置一下相关keyZoomEye：https://www.zoomeye.org/Seebug：https://www.seebug.org/
kunyu init --apikey 123321 --seebug 123321

4、启动Kunyu

kunyu console

5、搜索url

SearchWeb www.xxx.com

6、搜索子域名

SearchDomain XXX.com

7、搜索ip地址

SearchHost 15X.XX.xx.xx

8、通过关键字，搜索漏洞

Seebug thinkphp
