01


系统更新



>>> apt-get update>>> apt-get upgrade>>> apt-get dist-upgrade

02


谷歌输入法



>>> apt-get install fcitx fcitx-googlepinyin

安装完毕后重启生效，打开Fcitx Configuration 点击加号添加 “googlepinyin”，默认使用ctrl+空格切换输入法。

03

>>> apt-get install flameshot>>> flameshot config   //配置 flameshot>>> flameshot gui        //截图

在系统设置—Keyboard设置中添加快捷键

06

msf连接数据库



对于kali2.0 先启动postgresql数据库：
/etc/init.d/postgresql start；或 service postgresql start；

然后初始化msf_db:
 msfdb init

直接运行：
 msfconsole
