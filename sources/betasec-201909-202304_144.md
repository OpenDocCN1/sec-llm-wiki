NPS是一款好用的内网穿透工具，不过相比于FRP还是稍微比较麻烦一点，原因在于NPS的服务端需要安装。

以下是NPS的使用：

工具下载地址：https://github.com/ehang-io/nps/releases

官方说明文档：https://ehang-io.github.io/nps/#/api

01  
  

### **服务端的安装**

首先查看服务器的架构，下载对应版本的NPS。我的服务器是x86\_64的，所以下载 linux\_amd64\_server.tar.gz

![](../Images/a63ee0db6fe459ab5e070960a6b8f3d3.png)

上传到服务器，解压，安装

*   
*   

```
tar -xvzf linux_amd64_server.tar.gz./nps install
```

![](../Images/891cdcd5124447823b01dc7e5ea8211e.png)

修改/etc/nps/conf/nps.conf 配置文件的 http\_proxy\_port 和 https\_proxy\_port 端口，防止端口冲突。至于 bridg\_port 和 web\_port 保持默认即可。注意，修改web管理端的账号密码！！

![](../Images/22df7b8582a76fb298dff285cdea49c1.png)

**启动**

*   
*   

```
1.   ./nps start2.   ./nps stop
```

![](../Images/6919022d8a0114d8c94597b586cc7f94.png)

**客户端**

*   客户端windows使用windows\_amd64\_client.tar.gz
    
*   客户端linux用linux\_amd64\_client.tar.gz
    

执行以下命令进行无配置文件链接

*   
*   
*   
*   

```
1.   Windows：2.       npc.exe -server=ip:8024 -vkey=P@ssword3.   Linux：4.       ./npc -server=xx.xx.xx.xx:8024 -vkey=P@ssword
```
