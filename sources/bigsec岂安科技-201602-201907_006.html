在接口测试的过程中，很多时候会用到对CSV的读取操作，本文主要说明Python3对CSV的写入和读取。

★


1
  需求


某API，GET方法，token,mobile,email三个参数

  • token为必填项

  • mobile,email 必填其中1项

  • mobile为手机号,email为email格式



2
  方案


针对上面的API，在做接口测试时，需要的测试用例动辄会多达10+, 这个时候采用数据驱动的方式将共性的内容写入配置文件或许会更合适。


这里考虑把API、参数、以及预期结果预行在格式化的CSV里保存，利用csv组件从CSV里读取URL、参数以及预期结果，Requests组件发起请求，将响应结果与预期结果进行比对，最后把比对结果写到结果CSV。

reader_CSV函数代码示例


  1. import csv
  2. import json
  3. import requests
  4. import time
  5. import unittest
  7. def readCSV(self,filename):
  8.  '''
  9.  :param filename: 需要读取的数据文件
  10.  :return: [{data1},{data2}...]
  11.  '''
  12.  datas = []
  13.  try:
  14.  #以DictReader的方式读取数据文件，方便与json互做转换
  15.  with open(filename,'r') as csvfile :
  16.  #从文件里读取到的数据转换成字典列表的格式
  17.  reader = csv.DictReader(csvfile)
  18.  for row in reader:
  19.  data = {}
  20.  data['id'] = row['id']
  21.  data['url'] = row['url']
  22.  data['token'] = str(row['token'])
  23.  data['mobile'] = row['mobile']
  24.  data['email'] = row['email']
  25.  data['expect'] = json.dumps(row['expect']) \
  26.  if isinstance(row['expect'],dict) \
  27.  else row['expect'] #如果expect读取出来的不是json则取其原值，否则转为json格式保存到result里
  28.  datas.append(data)
  29.  return datas
  30.  #如果文件找不到，返回空的datas
  31.  except FileNotFoundError:
  32.  print("文件不存在",filename)
  33.  return datas

request_URL函数示例(包含GET请求和POST请求2个方法)


  1. def get_request(self,url,params):
  2.  '''
  3.  通用的调用GET接口方法
  4.  :param url:string 接口路径
  5.  :param params:{"":"","":""} 需要传入的参数
  6.  :return: response响应体
  7.  '''
  8.  print("调用API...")
  10.  r = requests.get(url,params=params)
  12.  print(r.text)
  13.  return r
  14. def post_request(self,url,params):
  15.  '''
  16.  通用的调用POST接口方法
  17.  :param url: string 接口路径
  18.  :param params: {"":"","":""} 需要传入的参数
  19.  :return:response响应体
  20.  '''
  21.  print("调用API...")
  23.  r = requests.post(url,params=json.dumps(params)) #post的方法必须用json.dumps()转化成json格式
  24.  print(r.text)
  25.  return r

  1. def assertResult(self,except_value,real_value):
  2.  '''
  3.  校验样本字符串中是否包含指定字符串
  4.  :param except_value: string 指定字符串
  5.  :param real_value: string 样本字符串
  6.  :return: Boolean 样本中包含指定字符串返回True,否则返回False
  7.  '''
  8.  ifsuccess = except_value in str(real_value)
  10.  return ifsuccess

6. write_CSV函数示例


  1. def writeCSV(self,filename,results):
  2.  '''
  3.  写入csv文件指定内容
  4.  :param filename: string 需要写入的文件名称
  5.  :param results: [{data1},{data2},...] 写入的内容
  6.  :return: 无
  7.  '''
  8.  print("写文件:",filename)
  10.  #以DictWriter的方式写文件
  11.  with open(filename,'w+') as csvfile:
  12.  headers="id,url,token,mobile,email,expect,real_value,assert_value".split(",")
  14.  writer = csv.DictWriter(csvfile,fieldnames=headers)
  16.  #写表头
  17.  writer.writeheader()
  19.  #写数据
  20.  if results.__len__() > 0 :
  21.  for result in results:
  22.  writer.writerow(result)
  23.  csvfile.close()

test_interface1函数示例


  1. def test_interface1(self):

  3.  #指定读取的数据文件名称
  4.  data_file = "../data/data.csv"

  6.  #指定最终结果生成的数据文件名称
  7.  result_file = "../data/result_{}.csv".format(str(time.time()).split(".")[0])

  9.  #读取指定文件的数据
  10.  datas = self.readCSV(data_file)

  12.  #数据文件有内容则调用接口，否则直接测试结束
  13.  if datas.__len__() > 0:
  14.  results =[]

  16.  #获取数据文件里的每一行
  17.  for testcase in datas :
  18.  result = {}
  19.  result["id"] = testcase["id"]
  20.  result["url"] = testcase["url"]
  21.  result["token"] = testcase["token"]
  22.  result["mobile"] = testcase["mobile"]
  23.  result["email"] = testcase["email"]
  24.  result["expect"] = testcase["expect"]

  26.  #组装参数
  27.  params = {
  28.  "token":result["token"],
  29.  "mobile":result["mobile"],
  30.  "email":result["email"]
  31.  }

  33.  #调用API接口，获取响应结果
  34.  real_value = self.get_request(result["url"],params)

  36.  #调用assert方法，检查预期结果是否在响应结果中存在
  37.  assert_value = self.assertResult(result["expect"],real_value.text)
  39.  result["real_value"] = real_value.text
  40.  result["assert_value"] = assert_value
  42.  #获取每一行里的所有字段以及实际结果和验证结果
  43.  results.append(result)
  45.  #执行完所有记录后，将所有结果写入result.csv
  46.  self.writeCSV(result_file,results) #写入csv文件
  47.  print("测试结束")
