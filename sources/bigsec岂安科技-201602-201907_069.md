# 离2018年还有10天，这些机票为啥还买得不明不白？

捆绑搭售成在线旅游的主要槽点一

  

说起航空机票代理，不少消费者又爱又怨。北京市东城区居民柳珠在某在线旅游网站买了旅行往返机票，“将所有航空公司的票都汇集在一起，消费者不用来回比对，而且往返总价一目了然，特别方便。”但柳珠最后结算时发现，消费总额比机票总价贵了不少。仔细核对后才知，原来网站直接将保险和酒店优惠券作为默认选项“搭售”，如果不仔细看，很容易被动选择，而且取消选项需要费一番周折。  

  

类似的机票捆绑搭售现象并不鲜见，成为消费者投诉在线旅游网站的主要“槽点”。这背后反映了怎样的行业现状？如何让消费者明明白白买机票？

  

  

机票代理利润不够，其他服务来“凑”二

  

长期以来，机票代理销售行业实行**“前返+后返”**的佣金模式，“前返”一般按票面价格的3%提取手续费；“后返”一般提取代理销售总额的2%—5%，业界俗称“3+X”模式。从2014年开始，相关部门提出**“提直降代”**，要求航空公司提高机票直销比例，降低代理费用支出。2015年起，各大航空公司陆续取消机票代理费。传统依靠线下和人脉开展业务的中小机票代理商面临被淘汰的危机，**旅客购票行为逐渐向航空公司直销和大型在线旅行网站汇集。**

  

![](../Images/c419ff684a7d6f3815ed44c0bdd9aa7e.png)

  

“近一两年，机票代理行业正在转型寻求出路，从推销机票转变为基于旅游全链条开展多元化综合服务。”广州民航职业技术学院副教授綦琦说。柳珠告诉记者，网站提供多元服务是一件好事，免去了很多旅行前“做功课”的麻烦。

  

专家认为，捆绑搭售现象反映了机票代理行业生存状况的进一步恶化。据某在线旅游网站市场部工作人员透露，目前每卖出1张国内机票，航空公司补贴的定额代理费用不足10元，而销售成本平均在14—16元。“机票代理的收入难以覆盖成本，因此往往通过最大化其它航旅服务收益来填补，比如将机票服务捆绑搭售各种旅行服务。”綦琦说。

  

![](../Images/10adb7e54801bfffb55e55851bad7bf3.png)

  

今年8月，民航局就此进行了清理整治，**明确规定禁止机票搭售**，不得以默认选项方式出售机票以外产品。民航局运输司副司长于彪表示，按照消费者权益保护法，维护旅客知情权和自主选择权，各销售平台应当通过清晰显著、明白无误的形式，将贵宾休息室、保险等除机票以外的附加服务设置为旅客自主选择项，有效避免旅客误选的情形发生。

  

  

**机票分销服务仍有价值，专家建议透明收取服务费**

  

“应该说，在各航空公司都有直销渠道的今天，机票代理行业提供机票分销服务的价值仍然存在。代理行业可以跨航空公司销售和整合产品，可以为消费者提供更加个性化的信息服务，至少在未来一段时间内，这是任何一家单独的航空公司都难以实现的。”綦琦认为，在越来越火爆的国际机票销售领域，由于其产品是非标准化的，消费者更需要机票代理的经验和服务。

  

如何既能规范机票代理行为，又让其售卖机票有利可赚？一些业内专家认为，**暗箱搭售不可取，明面收取相关费用或可行**。消费者既然享受了机票代理的增值服务、个性化服务，支付一定的服务费并非不合理。比如，部分海外航空公司也会向通过电话或柜台预订机票的旅客收取人工服务费。中国旅游研究院院长戴斌表示，在市场经济条件下，应当允许旅游企业向消费者收取一定金额的服务费，但关键是**收费要透明公开**，让消费者自主选择，明明白白消费。“国内一些在线旅游网站正准备上线‘代订技术费’，并在网页上明示。”綦琦透露。

  

“杜绝机票捆绑搭售等违规行为，维护好消费者权益，要严格监管票务代理行业，加大违法违规行为打击力度，也应该关注票务代理的服务价值，让其可持续发展，更长久地服务消费者。”綦琦说。

  

> 来源：《人民日报》（2017年12月18日 17版）

  

  

佣金不够，爬虫显身手三

  

“提直代降”被各大航空公司大力推行以后，给票代们的佣金越来越少，退票成本越来越高，很多票代开始意识到：再不行动就活不下去了！而票代们的行动，**除了捆绑搭售以外，还有其他五花八门的手段，虚占座位**就是其中之一。

  

他们大量抢占：①长期热门线路的各舱位；②座位数很少的舱位；③特价舱位；④黄金时期（如黄金周）的各舱位。目的就是利用因时间推移造成的舱位价格变化获利、或通过自己的平台自主加价转售。

  

但是航空公司那么多，航班那么多，怎么能找到自己想要的目标呢？这个时候，爬虫就开始进入战场了，热门紧俏的航班在哪儿，爬了就知道了！特价票在哪儿？边爬边选不就知道了！于是，爬虫和航司的战争打响了。

  

![](../Images/03c3ca80d4f9af8b0f8078ad6e055340.png)

  

针对大量的弃程现象，航空公司肯定是要重视的，航司风控技术部门的很快就会捕捉到使用工具的人们，他们的特征是： IP 来源单一，频次过高，发现了这一特点，爬虫即可被识破并且被禁止掉。但是那些灰黑产也不断改进技术，他们充分的利用各种资源，比如利用购买或者租用的云机房、IDC 中的 IP 资源，甚至会改造了路由器，待买家购置家中后，便直接转化成了为他们服务的爬虫种子。

  

**风险黑名单可能是大多风控部门采用的方式**，对这种经过分散稀释过后的IP，单纯的只是从访问频率、Useragent 观测角度肯定是不够的，这就存在一定局限性，**从行为轨迹和用户画像角度出发一定是风控的大趋势。**

  

![](../Images/075cc89b2440bbaf14bc245253a5259b.png)

  

岂安科技的工作人员发现了这一现象，其产品Warden通过对**访问元素丰富度、访问轨迹连贯性、访问静态资源比例等维度**进行分析：

  

✦ 普通用户在打开网页时会有比较丰富的地址访问，而自动爬虫通常只有少数固定的页面访问，比如航司活动专版、舱位价格页面、航线动态等。

  

✦爬虫获取数据时往往只关心具体的文字内容和数据，但不会查看图片以及加载页面上的 CSS 或者 JS 信息，这就为风控平台提供了一个较为显著的判断因素，这一点不用多加解释。

  

✦用户在进行页面访问时，通常是有一个合理的访问轨迹，如从首页跳转到机票搜索，但爬虫在自动获取数据时，往往是对页面地址进行逐个访问，没有连贯的轨迹。比如首次访问就是登录页面，正常应该从搜索或者广告页跳转而来。

  

![](../Images/3addd121c2a10a90da75937fa51bbe48.png)

  

以上只是岂安科技反爬虫原理几个简单的例子，事实上，岂安科技的 warden 产品不仅能准确的识别出哪些是恶意爬虫，还能通过分析有效解决信息泄露、短信轰炸、虚假注册、羊毛党、扫号撞库、密码找回等诸多风险问题。
