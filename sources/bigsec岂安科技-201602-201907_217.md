# 岂安科技荣获2016中国国际大数据大会企业创新奖

**由人民邮电出版社主办的2016中国国际大数据大会于9月27日在京召开。岂安科技作为国内首家专注业务风险控制的服务供应商受邀出席大会，与超过2000位的大数据产业链行业精英、技术专家把脉产业方向，展示创新应用、分享实践成果，共同发掘大数据创新之美与力量，并被授予2016年度中国大数据领域企业创新奖。**

![](../Images/c3d4916684df14edc768013d39ce3d7a.png)

  

  

随着互联网、云计算与物联网技术的不断发展，大数据产业市场规模迅速增长。为更好的落实大数据国家战略，交流探讨国内外大数据技术与产业趋势，加速落地大数据在各领域的创新应用，由人民邮电出版社主办，《大数据》杂志、数创汇承办的2016中国国际大数据大会将于9月27日—28日在北京召开。  

  

![](../Images/c2c8bcf4a16c17ab900a80ba895c36a1.png)  

  

本次大会持续两天，以**“数聚新动能，数创大未来”**为主题，召开大数据助力政府治理与智慧城市发展、技术与安全、运营商大数据、数享家峰会、互联网+大数据峰会、大数据应用、大数据交易与市场营销、金融大数据与征信论坛等十一场论坛。国家信息化专家咨询委员会常务副主任周宏仁演讲《推动数据产业发展》并认为，从趋势来看，**决定未来的是数据化的数据，要具备数据资源最基本的还是要推动信息化的建设**。

  

据了解，大会汇聚来自主管部委、地方政府、行业组织、大数据厂商、IT、互联网企业、应用单位、行业组织、科研院所等大数据产业链各环节共2000多位代表出席，百位发言嘉宾为业界带来关于大数据政策、标准、市场、技术、产品、应用、安全、交易等产业热点话题的精彩演讲，全面深入解读我国大数据产业当前态势与发展。

  

![](../Images/d7970d64704cc83fa8646f611ab087ee.png)

  

另外，大会现场还将对大数据产业内优秀的人物、企业和产品技术应用平台进行表彰。其中，岂安科技在产品技术应用平台表彰中，被授予年度对大数据应用提供最优方案的企业，同时摘下2016年度中国大数据领域企业创新奖。

  

![](../Images/07bba1a2dd49a5f052dd0473082d75b8.png)

  

上海岂安信息科技有限公司（简称“岂安科技”）是国内首家专注业务风险控制的服务供应商，由来自PayPal、支付宝、Cisco、携程、网易的一批反欺诈、安全技术专家创立，并拥有带自主知识产权的一系列核心产品。核心解决方案包括大数据风控预警云平台以及基于复杂信息流的业务风险实时检测系统。2015年，岂安科技获得了来自经纬创投的千万元级别的股权投资，客户包括**航旅酒店、第三方支付、金融、电商、O2O、OTA、社交、游戏、媒体、广告**等行业。

  

岂安科技核心团队基于多年对黑灰产业链的情报收集、深入研究和用户行为分析，结合大数据模型，针对各类风险建立了一整套数据驱动的风控技术体系。这套体系能够从每天百亿级的交易、近百PB的数据中实时识别和处置盗号、活动作弊、恶意行为、禁限售等十几种业务风险，为客户直接带来直接的数字收益，助力用户核心业务的高速发展。
