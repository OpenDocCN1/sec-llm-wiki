第三章：微信小程序项目结构以及配置

  

  

找到创建的 demo 文件夹，把项目导入到你的编辑器，这里使用的是 Sublime Text 编辑器。

  

![](../Images/7e4be9309127a5fb3e8082cffb9bce90.png)  

  

这个时候需要根据自己的项目需求结构进行更改了，项目根目录下面是首页渲染的几个 tabBar 页面，以及 app 的一些配置文件，如名片盒项目的 tabBar 是 3 个切换菜单：

  

![](../Images/9c60343c8b4116a8c74e6c3289cad488.png)  
 

我们先找到 app.json 文件打开配置好这几个菜单，配置好 tabBar，这个直接把配置文件改成你自己设计的即可。

  

![](../Images/58ac52d556b83fb11ba630bce7bad28d.png)  

  

App.json 里面有几个配置项：

  

*   Pages：这个是编写的 js 文件，后缀 .js 这里不需要使用，配置好正确路径即可正常应用到（应用不到在重启微信开发者工具会直接报 page 错误）。
    
*   Window：配置顶部的一些样式，文档介绍比较详细。
    
*   tabBar：底部的几项配置，见名知意。
    
*   networkTimeout：暂时没发现用处，建议看文档。
    
*   根据实际项目需求进行添加与更改。
    
*   iconPath 和 selectedIconPath：底部菜单按钮图片与得到切换点击高亮。
    
*   "text"：可以去掉，全部去掉会发现底部 tabar 高度会减少很多。
    

  

![](../Images/64aa17cf58a06f1ab2485ed37d190a58.png)  

  

Json 文件配置好后，根据项目进行文件创建，

Demo：存放的是假数据，这一期的开发工具支持 require，假数据使用的是 .js 文件形式，

里面的数据结构 json 一致，把 data 暴露出去即可。

  

![](../Images/34382e750e6ef87745cf12df581ebad7.png)

![](../Images/476c3a41e3b298e0452c1cd331a88465.png)

  
然后取数据 require 进来即可，这一点使用很方便；  

  

Images：图片路径；

Page：除 tabar 以外的页面；

Servise：服务交付层（与后台联调真实数据时使用）；

Wxss：一些公共的 css 文件。

  

看到这里大家发现每个页面都被连带好三个不同的后缀。分别**页面，css，js **目前只能依照这样，是微信应用号的一个规范吧。

  

![](../Images/4308c008c5fb08fd23046f5be48acc9a.png)  
 

Wxss 文件是引入你写的样式文件，也可以直接在里面写样式。

  

![](../Images/f7e9e4883a3a2313096bfa1cf4a52542.png)  
 

Js 文件需全部配置到 pages 里面才能生效。

  

![](../Images/c040c360536191ca3b34a8b4a78cdf1e.png)  
 

  

  

  

第四章：微信小程序首页面开发

  

  

  

进行了各种准备与配置后，来到首页开发。首先需要实现首页效果图如下：

  

![](../Images/e6448033bcf4ea26e085aae2afa89309.png)  
 

Template 名片很多，需要用模板。

  

这里需要微信提供的基础组件大致是 input（搜索框）、

action-sheet（右边是个底部下拉菜单，需要下拉菜单）、

Scroll-view (右边 ABC 跳转)、（这个目前实现还有点问题，正在攻克中）。

  

![](../Images/b894aab471d027512cfb37f839f51417.png)

![](../Images/d0b3a3cb2ab1c6912f226a66da4d1e21.png)

  

View 是块元素，整个搜索框的一个样式。

  

 ![](../Images/27ea28fdd46315187d4568cdb88c93cd.png) 

  

*   名片夹：由于该项目主打名片功能，故很多地方使用，所以需要把名片以 template 分离出来。
    
*   Template：定义一个模板，name 模板的名字其实是个作用域。
    
*   Block：循环控制，名片很多，必须用循环出来，和很多操作数据的前端框架循环差不多。
    
*   支持自定义属性 data，这里用作判断线上名片以及线下名片。
    

  

View 里面是一些数据引入，里面是支持三目运算符。

  

![](../Images/cf0cc763f9fbbdebfe75fb0a3d275f1b.png)  

  

引入 template 时非常方便，is 和 name 一样，data 是 nameData 传递过来的数据填充。

  

一切都绑定数据为中心点。

  

![](../Images/16fc6ccd1e641e06b8103ea32b5d1dba.png)  
 

取到数据具体操作根据你数据结构：

  

![](../Images/b9710beab73ddead2af8b6aed625d961.png)  
  

这里的数据结构和 json 数据结构一样，

  

![](../Images/fb79f1b4f7b2ca28b64f9bc7c2bfdd66.png)  
  

这里如要传到页面的话即是

  

this.setData({

nameData:card\_list\_name.data.cards,

timeData:card\_list\_time.data.cards

});

  

因为页面遍历的是 nameData,timeData

  

![](../Images/28d776a4585c97b7d8ef0f4b13b6c474.png)  
 

可以看下打印出来的数据结构，根据你的结构进行解析与传递。

  

![](../Images/7a80aa4c8a330a75a07d651de6a17e10.png)  
 

也可以看下这里对数据的一些操作。（这里须根据定义的 json 数据格式来操作的）

  

![](../Images/427f2dd8413463fb8a87a6d84c449bb3.png)  

  

名片的样式由于很多页面需要使用放在 common.css 里面，这个 common.css 是所有页面都需要用到，一些初始化设置。它是在 pp.wxss 里面引用之后才能被映射到全局 APP。

  

![](../Images/2b76bce79001f7eb6c6408eb1f7241e7.png)

![](../Images/8793d8ef979a059aa17fd3f7f22d4492.png)
