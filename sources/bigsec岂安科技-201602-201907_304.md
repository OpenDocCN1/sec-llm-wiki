# 岂安科技坐客第一财经全访谈记录

访谈岂安创始人现在对于互联网市面上出现的“羊毛党”，“薅羊毛”给许多互联网公司带去了致命的伤害，那么就让我们走进“羊毛党”，让我们一起探寻“薅羊毛”的本质。在此特别采访了上海岂安信息科技有限公司联合创始人刘明和于勇。主：让我们通过五问约客来更清楚的了解岂安是做什么的吧！那么，过年回家你们是如何向家人朋友介绍自己是做什么的呢？刘：和老妈解释了四五分钟，说了一大堆防爬虫，防盗号，防羊毛党的信息，我老妈给出的总结：你们就是让网站更安全呗！其实我觉得老妈说的也是对的。![](../Images/feaaf167e16debba271fc845cde83d92.png)主：这个行业还是很新兴的，你们觉得现在市面上做这这件事情的还有哪些企业？刘：其实做了半年左右，才发现都是一些挺大型的公司，比如像阿里云盾和腾讯他们都在做这种相关的服务，所以说我觉得暂时只有这两家和我们做的事情是相同的。主：你觉得岂安和这些BAT公司的区别在哪里呢？刘：其实我觉得最大的区别是他们的比我们有钱，我们是创业公司，所以肯定有自己的一些市场打法，也就是我们不会做和阿里腾讯相同的事情。对于阿里、腾讯，他们做的可能是通用场景，提供解决方案，而我们在自己的产品方面和他们有一些明显的差异，做的更多的是定制化。主：你们可能更精而小，更灵活，那么第四个问题，谁是你们的用户？刘：我们的用户也是很典型的，首先要是互联网；再次，要有账号、钱、隐私，可能大部分公司没有办法像BAT这样的公司投入几百人、几千人去解决它这些隐私或者是隐私相关的资金安全问题，那我们就可以提供这样的服务。![](../Images/c542b061d5237f0bee533147f476d9d4.png)主：你们现在是处于一个怎样的阶段？你们是等着有人来投资，还是已经赚钱盈利了？于：我们是痛并快乐着，因为我们的业务现在也是刚起步，但是发展的也是非常的迅猛的，这是一件很令人开心的事，我们旁边也有很多行业巨头，也是我们担心的事情，但在这个创业过程中，我们也体会到了创业的热情。主：今社会互联网风控这个概念大家耳熟能详，但是具体的事情大家还是不太清楚。我觉得大致可以分为两类：风险管理，风险控制。不知道是否可以给大家普及一下概念。刘：这两者的区别好比是：一个人的眼睛和手。你要看到问题，你才知道你的问题出现在哪里；那控制好比是把手，伸出去把这个问题挡住，保护自己的利益。像我们所看到的：企业做市场推广活动，他们一期可能投了100万，通过购买大量电影票赠送的方式去获得新客户，可能在很短的时间内发现这些散出去的电影票没了，但是当他想看到是哪些人领取时，发现那些注册的号码根本打不通，或者是一些虚假、不存在的手机号码，那就相当于企业这100万就打水漂了。那从这个问题角度来看，他是两方面都没有做到，第一个是，上一个活动的时候，企业没有做到风险管理，他不知道上这个活动会存在哪些风险或者说对风险没有想的够周全；第二个是，即使有一个监控体系，可以看到有人在刷单，那么我需要用什么样的手段去阻止他们。风险管理是自己体系中可能出现哪些风险以及对这些风险的预知。那风险控制是在你发现这些风险的时候你是用怎样的一个手段来限制它并且可以挽回损失或者是降低损失。![](../Images/204faec58c60faee289d442b6d89594f.png)主：这样案例我在生活中确实看到了不少，比如秒杀、优惠限时等。通过这些活动，就出现了一帮“羊毛党”，那么，很多人还不是很了解“羊毛党”，可以和我们介绍一下“羊毛党”吗？于：羊毛党的起源是“薅羊毛”，宋丹丹说过“薅社会主义羊毛”，那她是用薅来的羊毛织毛衣，那么这样的薅法羊是薅不死的，如果有专业的人过来薅的话，他可能连羊皮都薅下来了，羊肯定就活不下去了。所以商家对薅羊毛的这个行为他是即爱又恨的，他是欢迎真正的消费者，当然他拒绝的是抱着恶意目的想着把羊薅死的哪些人。我们所说的羊毛党，指的大多为后者。我们岂安现在做的事情也就是把后者拒之企业的门外。![](../Images/5b27119e98d8fb8f804003da1a4c0175.png)主：其实我们在节目里也教过大家如何做一个羊毛党。（哈哈）当一个新的优惠措施出来之后，总会有些人想尽一切办法以极小的代价来获得一个成果。再恶意的话无非就是在市场上演化为“黄牛”，他们会将优惠全部拿下来，零成本，再以某个价钱反复销售，对于商家来说，他们是达不到一个拓展新用户的目的的。对于你们来说，商家完全不能容忍的行为是什么？于：每个商家在“羊毛党”和消费者之间，他们会根据自己的业务场景，有不同的划分。打个比方，你是一个真正的用户，你薅了一次羊毛，然后你投资了或者你有潜在的投资行为，那么企业是欢迎的；但是对于“羊毛党”这种行为，他是起不到推广发展新用户的，他的这种实惠被“羊毛党”全拿走了，这种从企业的利益角度来说，是企业憎恨的用户。  
刘：所有风控不能说没有风险，风险是相对的，首先企业要知道我可以承受的风险。比如说：这次活动投了500万，全亏了，我是否能接受，能接受就是我的风险；如果企业说我投了500万，最多只能亏100万，我能达到20%的风控，其实也是达到了他的要求。至于方式上，有些人为了娱乐或者看到帖子上有些优惠政策去尝试一下，这些人可能手机是正常的，ip也是没有问题的。但是那些团伙作案，可能是用代理ip，在某个二三线城市拉了一根网线，然后这种人就可以在短时间里造成非常大的伤害，所以我们是通过这些维度，行为，信息特征来判断这些人是否是坏人。主：岂安的合作模式是怎样的呢？刘：很多互联网企业，可能没有足够的人手和相应的经验去解决这个问题，我们能够提供的是更完善的风控服务，可以提供意见和建议，这是一种延续性的行为。![](../Images/bb57d8ff51ead20c8f3bfc9cbc7367a2.png)主：你们这个摊子如果一铺张开来，需要的人力会多很多，那你们如何解决人力这一问题。刘：刚开始我们是在企业的内部网络部署，其实你会发现他们的业务的模式都差不多，我们从注册，下单这种最基础的业务场景入手，然后设定一些基本模式，如果出现特殊场景后，那么我们的机器也会自主学习，我们也会去培养企业专门的一位员工去做这样的事情。那么，在一定程度上降低了我们的成本。![](../Images/9dfae688c785cbfe3ca067bee5b43f6e.png)主：那就是说如果你是一个互联网企业，也不打算成立互联网风控部门的话，就可以寻求你们这边的帮助，岂安这边可以提供设备、软件以及人员的培训。这个行业虽然处于比较初期阶段，但已经有几家大佬进入了。比如说腾讯，他们有资金、有实力、也有技术人员，可能比你们更加的专业，你觉得你们怎样和他们竞争，包括这种定制化的设计，会表现在哪些方面？刘：对于BAT来说，大都是在他们的生态圈里面玩，比如说：阿里有阿里云，首先你可能是需要在阿里云里，他们这种BAT的服务是接口化的。那些BAT的大公司的工程师是不可能出差帮你解决问题的，他们更倾向于做一些基础的解决方案来解决你的问题，除此之外，不仅帮你解决了基础问题，还能得到你的数据，这些数据对BAT企业会起到一些辅助性的作用，这是他们的一个看法，当然他们也不可能把自己的工程师下发出去跑客户去解决问题。我们是会去本地部署，而且会对人员进行培训，并且保证我们不会收到企业的数据，数据是在自己的环境里面。我们会有专门的人员去支持，去把其他行业的最新策略部署到企业，帮助企业去预防可能会发生的问题。或者总结来讲：我们和BAT这种巨头公司竞争的时候，我们最主要的优势是：我们愿意跑到企业现场去帮助企业解决问题。![](../Images/73f164f26fa9833f2257b00ed3102b91.png)主：岂安是一家：不会去获得你数据的一个互联网风控支持团队。这样说对吗？刘：我们的服务模式是：一个是提供软件，另一个就是提供服务支持。我们是部署在企业内部环境的，这样带来了两个好处，一个是：我的数据是觉得对不会上传，不会造成隐私泄漏，这个就是说我们给企业做风控，但是我们不能给企业带来额外的风险，首先要保证数据安全，这个是重中之重。再一点是：像BAT这种公司提供的服务是需要客户上传到云端的，这样会延时。风控是没办法等的，我们的风控放在本地是考虑到数据的安全性，还有一个就是说风控的时效性。主：总结下来岂安还是一家有良心的企业。那么企业也了解到了，让我们来了解一下两位创业者的朋友圈是怎样的吧！听说刘明是一个已婚，爱插花，爱瑜伽，爱美的东西的一位很细心的人啊！不知道创业与细心和耐心是否有关系呢？刘：我的插花和瑜伽都是老婆让我去的，对于瑜伽我觉得刚开始是为了强身壮体，但是后来也从瑜伽中得到了很多东西可以关系到工作。瑜伽中的阴瑜伽和热瑜伽告诉我们一个人不能一直处于一种亢奋的状态，一段时间的亢奋状态后我们要停下来去修正。这个也可以运用到我们创业过程当中，因为创业是一段5000米的长跑，你不能以100米的冲刺那样跑下去那样你会累垮的。那我们需要工作和生活处于一个平衡的状态，我们的工作状态才会非常的高，才能有不同的idea迸发出来。如果你长期处于一种疲劳的状态，你是没办法处理好事情以及不能做正确的判断。主：刘明是一个很小资的，对生活、工作十分有见解的一位创始人，那么于勇，听说你是个大吃货，对吃非常的有研究，并且给团队带来了吃的乐趣啊！于：在此我也申明，我也是个爱老婆的人哈！（哈哈），我是觉得吃是一种乐趣，我觉得在工作之余如果可以让自己的嘴巴也享享福也是一件非常美好的事情啊，如果再可以把身边的美食分享给小伙伴们，那我会感觉非常开心，因为独乐乐不如众乐乐吗！![](../Images/16f7adeb7b41cc93224d806cd7929473.png)主：听您二位介绍啊！那我想问一下，岂安的氛围有没有什么特殊的情调呢？刘：我觉得一个人对生活负责、对身体负责的人，那么对工作也是很负责的，所以在招人的时候也是非常注意到这点。现在整个公司的氛围也是非常好的，大家在中午吃饭会在大长桌上一起吃饭，一起聊天。下班了会去打球，平时还经常回去team building。我们出来创业本来是一件十分苦的事情，不能让大家苦上加苦，这样做出来的工作也是苦的，如果你能协调员工的生活和工作，那员工的创新能力以及想法都会变得十分的灵活。![](../Images/9c45e70043afa63ef17a4b45520c2a2a.png)主：从岂安目前形势来看，似乎不会出现传统公司的那种氛围，这可能与创始人也有很大的关系，热爱生活，热爱工作。整个氛围也是十分的轻松和活泼的。那么假设明年的同时同地，还是我们四人在这里做一期访谈节目，你们会以一个怎样的身份讲一个怎样的访谈内容。刘：一年之后，我们首先是希望我们的团队人员会变得更多，明年的今天要到达100人这样。我希望公司估值会上一个台阶。于：我希望是我们可以把大多数的互联网公司纳为我们的客户。主：你们说到规模说道估值啊，那你们想要做一个小而美的团体还是要做大而全的公司呢？刘：其实技术圈里流传一句话“小而美，大而烦”，任何东西在小的时候看起来都非常的美好，变大了以后变得十分的臃肿，大，乱，所有的问题都来了，我们肯定是希望自己规模上面变大，但是在企业的特质上面还是保持着这种小而美的状态。主：这种状态真的是比较美好的。那么在一年中你们需要人员的扩张的话，难点您觉得是在哪里？刘：现在的当务之急还是招聘啊！我们整个团队都人走入的招聘狂潮中，我们甚至是说内推，推荐一名一部iPhone，两名两部iPhone,三名四部iPhone。不惜大价来招聘人才。那么现在只要有人推荐，我们都会有这个奖励措施！![](../Images/d0c41aea7b58367c2294dbc23fc9e902.png)主当今互联网公司现状是不可能每个公司都有一个风控部的，那么是需要第三方来做这样一件事情的，哪家好，哪家会更有特色，岂安给出的答案是，我是不拿取顾客数据的，并且是可以提供工作人员进行上门服务的，并且为你的人员提供培训，这些对一些企业来说是一个瓶颈，但是岂安目前是能做到的，这也是他们的职责所在。那么，岂安确实可以称得上为“岂止于安全，岂能不安全。”
