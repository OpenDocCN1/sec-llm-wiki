while循环

python的while循环语法

while条件：

条件为真（true)

举例：

A=input("我的年龄:")
guess=int(A)
while guess!=18:
    A=input("不对,猜错了,继续猜:")
    guess=int(A)
    if guess==18:
        print("猜对了，么么哒")
    else:
         if guess>18:
             print("大了")
         else:
             print("小了")

random模块（用于生成随机数）

random模块中有一个函数叫做randint（），会返回一个随机的整数。


导入模块：import

举例：

import random
B=random.randint(1,10)
A=input("知道我心里在想什么数字吗:")
guess=int(A)
while guess!=B:
    A=input("不对,猜错了继续猜:")
    guess=int(A)
    if guess==B:
        print("猜对了")
    else:
         if guess>B:
             print("大了")
         else:
             print("小了")
