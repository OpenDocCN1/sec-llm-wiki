为喜欢信息安全的小伙伴所准备

不知道昨天的知识点大家学会了吗，今天小编继续讲新的知识点了，小伙伴们，跟着小编的脚步一起学习吧

大家先了解一下css中的选择器，不过，除了了解外，还要熟悉，学会使用哦

css中的选择器：

（1）通配选择器

（2）标签选择器

（3）类选择器（必须以字母开头，可以由字母数字以及下划线组成）

（4）id选择器

（5）群组选择器

（6）后代选择器

（7）子代选择器

（8）属性选择器

（9）相邻兄弟选择器

举例：

通配选择器：

<html>

 <head>

  <meta>

  <title>通配选择器</title>

  <style>

    *{color:red;}      重点是*号，大家要注意哦

  </style>

 </head>

 <body>

  <p>我是段落</p>

  <h1>我是标题</h1>

  <ul>

   <li>我是列表</li>

   <li>我是列表</li>

  </ul>

 </body>

</html>

结果：


标签选择器举例：

<html>

 <head>

  <meta>

  <title>标签选择器</title>

  <style type="text/css">

    h2{width:200px;height:300px;border:1px solid red;text-align:center;}   <!---注意border:1px solid red的写法，意思是边框为1 边框颜色为红色--->

  </style>

 </head>

 <body>

  <p>爸爸</p>

  <h1>妈妈</h1>

  <h2>哥哥</h2>

  <h3>姐姐</h3>

 </body>

</html>

结果为：


类选择器举例：（必须以字母开头，可以由字母数字以及下划线组成）

（1）

<html>

 <head>

  <meta>

  <title>类选择器</title>

  <style type="text/css">

    .tag01{color:red;border:1px solid blue;width:300px;height:100px;}   注意前边的点

  </style>

 </head>

 <body>

  <p class="tag01">好好学习</p>   <!---tag01指的是类名--->

  <ul>

   <li>中国</li>

   <li>山东</li>

  </ul>

 </body>

</html>

结果：
