今天给大家讲HTML5的列表

列表分为两类：有序列表和无序列表

（1）有序列表：用于显示具有同一特征的有效数据。

语法：

<ol  type="列表类型"  start=“起始编号”>

    <li>......</li>

    <li>......</li>

</ol>

属性名称及属性值：

type=“数字”/"字母大写"/"字母小写"/"小写罗马数字"/"大写罗马数字"

start="数字"（任意数字，表示他的起始编号）

举例：

<html>

  <head>

    <meta>

    <title></title>

  </head>

  <body>

      <ol type="a" start="6">

          <li>语文</li>

          <li>数学</li>

          <li>英语</li>

      </ol>

  </body>

</html>

结果是

type为默认时是数字，start默认时是从第一个开始的。




❖星星发亮是为了让每一个人有一天都能找到属于自己的星星。

（2）无序列表：用于显示同一特征的无序列表。

语法：

<ul type="列表类型">

  <li></li>

  <li></li>

</ul>

属性名称及属性值：

type=“disc”（实心圆）/"circle"（空心圆）/"square"（实心矩形）

type=“none”（当type=“none”时，没有上面这三种情况）

type默认时为实心圆。

举例：

<html>

 <head>

  <meta>

  <title></title>

 </head>

 <body>

   <ul type="circle">

      <li>语文</li>

      <li>数学</li>

      <li>英语</li>

   </ul>

 </body>

</html>

结果是：


应该懂得这样一个道理：要努力，努力，再努力；如果开始不成功，还要努力，努力，再努力。

（3）dl标签：（与列表相似）

语法：

<dl>

  <dt>标题</dt>

  <dd>描述</dd>

 </dl>

举例：

<html>

  <head>

    <meta>

    <title></title>

  </head>

  <body>

     <dl>

      <dt>山东大学有</dt>

      <dd>工商管理学院</dd>

      <dd>计算机学院</dd>

    </dl>

 </body>

</html>

结果为：

成功就是当洋溢的生命力突然冲决堤坝而汇入一条合适的渠道。
