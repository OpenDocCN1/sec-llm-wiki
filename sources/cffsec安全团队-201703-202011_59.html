用Windows 7的注意，有哪种状况会失去系统更新资格！

在先前微软（Microsoft）的公开信息中显示，Windows 7 将会续更新到 2020 年 1 月 14 日，Windows 8.1 则会持续更新号 2023 年 1 月 10 日。不过现在微软的新做法，可能会让 Windows 7 与 8.1 用户，提早失去系统更新支援！



《Znet》的报导指出，近期在新计算机装置上运行旧版 Windows 系统的用户，于系统升级时会出现错误讯息，内容提到该装置不支援、用户的计算机将无法获得 Windows 更新。



其中包含 Windows 7 和 Windows 8.1 系统的用户，只要是使用搭载第 7 代 Intel Kaby Lake 处理器、或是 AMD Bristol Ridge 处理器的计算机，就会遭遇这个更新错误。事实上，微软在 2016 年 1 月就曾发出这个讯息，明确指出未来采用 Intel Kaby Lake、Qualcomm MSM8896、AMD Bristol Ridge APU 等处理器的机种，必须要安装 Windows 10 系统，才能获得 Microsoft 支援服务。



Microsoft 对此的解释是，最新的处理器需要搭配最新的系统，才能有效运作。象是 USB Type-C 和 Thunderbolt 3 这类新型态传输埠，都必须依靠 Windows 10 才能支援。



不过微软显然是到了最近才开始落实这项政策，目前使用更老旧版本处理器的计算机（象是 Intel Skylake 处理器），依旧可以获得完整的 Windows 7、8.1 系统更新。但若是想要在新计算机上运行安全的 Windows 系统，恐怕 Windows 10 是唯一的选择。
