一、某赛的brainfuck题目。

> Brainfuck是一种极小化的计算机语言，它是由Urban Müller在1993年创建的。由于fuck在英语中是脏话，这种语言有时被称为brainf\*ck或brainf\*\*k，甚至被简称为BF。

题干：

```






























,>>++ +++++ +++[< +++++ +++++ >-]<+ +[<-> -]<[+ -],>> +++++ +++++
```

直接放到https://www.splitbrain.org/services/ook在线解码网站并未解除。

  

解题步骤：

1、删除掉\\n换行符

        ![](../Images/561a4ed50708ffccf9447b2cff7c086c.png)

得到删除掉换行符的编码如下图：

![](../Images/de51b12cad825d52cff74958486aed0e.png)

2、删除掉代码中的循环语言，并替换为".\\n"

循环语句：

```




[<-> -]<[+ -]
```

  ![](../Images/4b759ca8ad7cb9c0c0de188c836dc4cc.png) 最终得到：

![](../Images/9196a33e26bc9c4cc715647922951b19.png)

 

```







































,>>++++++++++[<++++++++++>-]<++.
```
