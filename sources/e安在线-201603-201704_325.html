防火墙是协助确保信息安全的设备，它依照特定的规则，允许或限制传输数据通过。简单说防火墙的作用就是保护你的网络免受非法用户的入侵。

且听Juniper老司机捷哥的经验谈——

《Juniper SRX Branch防火墙基础配置实战》

本课程从网络管理从业者、运维、网络安全工程师的实际工作出发，针对SRX防火墙的网络配置，路由配置，策略配置，双机热备等工作中的原理与使用进行案例讲解。

课程亮点

1. 实战、理论与案例结合，注重实用性、经验的传递；

2. 捷哥多年网络管理和教学经验，称得上Juniper SRX Branch的老司机，跟捷哥学，事半功倍。

捷哥

北大青鸟APTECH（北京学知堂）高级讲师， 培训过的课程有：Windows server 2008活动目录，Windows server 2008网络服务， 网络技术与应用，构建大型企业网络。获得 证书：CITP、CCNA、RHCE。

专业技术领域：熟练搭建大中型企业网络以及配置各种服务器、精通计算机硬件以及硬件故障与网络故障的排除、擅长Windows系统、Linux系统、SQL、server数据库管理、熟练掌握各种主流网络产品、路由器、交换机的原理及互联技术具有丰富的网络管理和教学经验。
