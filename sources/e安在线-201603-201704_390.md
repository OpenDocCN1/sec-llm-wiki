**第一章 时间控件**

Android的时间控件分为两种：DatePicker与TimePicker。

   1.DatePicker控件

DatePicker是一个选择年月日的日历控件。

在res\\layout\\datepicker.xml中定义一个按钮。  

<Button  
    android:layout\_width="wrap\_content"  
    android:layout\_height="wrap\_content"  
    android:text="0000-00-00"  
    android:id="@+id/btnChooseDate" />  

在DatePrickerActivity中，对按钮进行点击事件后，调用DatePicker控件。

首先在JAVA代码定义一个按钮：

private Button btnChooseDate;  

随后在onCreate方法中引用到按钮的ID：  

btnChooseDate = (Button) findViewById(R.id.btnChooseDate);  

对点击按钮进行监听操作，在监听中实现调用DatePircker控件。

btnChooseDate.setOnClickListener(new View.OnClickListener() {  

         @Override

         public void onClick(View v) {

            new DatePickerDialog(DatePickerActivity.this, new DatePickerDialog.OnDateSetListener() {

                 @Override

                 public void onDateSet(DatePicker view, int year, int monthOfYear, int dayOfMonth) {

                     btnChooseDate.setText(String.format("%d-%d-%d",year,monthOfYear+1,dayOfMonth));  
                }  
            },2016,5,10).show();  
        }  
    });  

这当中重要的方法是DatePickerDialog，通过这个方法，将会实现对控件的调用。而在重载onDateSet方法中，一定要对月份+1操作，由于月份是0开始的。这一点比较重要，否则月份将为所选用份-1。最后通过setText将所选的日期赋值到按钮上。

![](../Images/dc66a5a8d260f0147b3597f40ebcca2e.png)调用时间控件

   2.TimePicker控件

TimePicke也继承自FrameLayout类，时间选择控件向用户显示一天中的时间(可以为24小时，也可以为AM/PM制)，并允许用户进行选择，如果要捕获用户修改时间数据的事件，便需要为TimePicker添加 OnTimeChangedListener监听器。

与DatePicker一致，先在XML中添加一个新的按钮。  

<Button  
    android:layout\_width="wrap\_content"  
    android:layout\_height="wrap\_content"  
    android:text="00:00"  
    android:id\="@+id/btnChooseTime" />  

接下来在DatePickerActivity定义新的按钮。

btnChooseTime = (Button) findViewById(R.id.btnChooseTime);  

紧跟着在onCreate中引用并实现调用TimePicker控件：

btnChooseTime = (Button) findViewById(R.id.btnChooseTime);  

btnChooseTime.setOnClickListener(new View.OnClickListener() {

         @Override

         public void onClick(View v) {

           new TimePickerDialog(DatePickerActivity.this, new TimePickerDialog.OnTimeSetListener() {                 @Override

                 public void onTimeSet(TimePicker view, int hourOfDay, int minute) {  
                    btnChooseTime.setText(String.format("%d:%d",hourOfDay,minute));  
                }  
            },0,0,true).show();  
        }  

实现后，在手机跑下项目，点击DatePicker列，操作此按钮，选好时间，会发现一个问题。如果小时或分钟小于10，显示不美观。这时我们可以用新的方法进行处理一下。

private String timeFormat(int time){

     return time\>10?""+time:"0"+time;

 }  

在重载方法onTimeSet做下小修改：

btnChooseTime.setOnClickListener(new View.OnClickListener() {

         @Override

         public void onClick(View v) {

           new TimePickerDialog(DatePickerActivity.this, new TimePickerDialog.OnTimeSetListener() {                 @Override

                 public void onTimeSet(TimePicker view, int hourOfDay, int minute) {                     

//btnChooseTime.setText(String.format("%d:%d",hourOfDay,minute));  

                btnChooseTime.setText(String.format("%s:%s",timeFormat(hourOfDay),timeFormat(minute)));  
                }  
            },0,0,true).show();  
        }  
    });  

在TimePickerDialog方法中，有一行0,0,true。他们分别表示小时，分钟，以及是否为24小时制。最后随意拖动，点击确定后如下图所示：

**第二章 进度条控件**  

ProgressBar是一个进度条控件，当用户在后台执行一些任务时，在前台展示的信息，用于表示任务正在处理，请用户等待或者给用户展示处理的进度消息等，它在android源代码中是直接继承View类的。

打开res\\layout\\progressbar.xml,将根节点改为LinearLayout,将布局改为垂直。由于系统自带的进度条控件分为无限加载及进度加载，所以我们拖三个控件进来。  

![](../Images/1f86cfda4a431426e121313888252d7b.png)进度条控件.png

最后生成的XML：

<?xml version="1.0" encoding="utf-8"?>

<LinearLayout xmlns:android\="http://schemas.android.com/apk/res/android"

    android:layout\_width\="match\_parent"  
   android:layout\_height\="match\_parent"  
   android:orientation\="vertical">  
  
   <ProgressBar  
       android:layout\_width\="wrap\_content"  
       android:layout\_height\="wrap\_content"  
       android:id\="@+id/lttleBar" />  
  
   <ProgressBar  
       style\="?android:attr/progressBarStyleLarge"  
       android:layout\_width\="wrap\_content"  
       android:layout\_height\="wrap\_content"  
       android:id\="@+id/normalBar" />  
  
   <ProgressBar  
       style\="?android:attr/progressBarStyleHorizontal"  
       android:layout\_width\="match\_parent"  
       android:layout\_height\="match\_parent"  

        android:id\="@+id/loadingBar" />

  

</LinearLayout\>

接下来我们在ProgressBarActivity中对可进度加载的控件进行定义。

private ProgressBar progressBar;  

在onCreat方法中实现进度条方法：

progressBar = (ProgressBar) findViewById(R.id.loadingBar);  
progressBar.setMax(100);  
progressBar.setProgress(50);  

其中setMax是用来控制最大进度是多少，setProgress是用来展示当前进度是多少。

可能大家会有疑问，要如何将进度条动起来呢？

   1.定义两个变量

private Timer timer =null;

privateTimerTask timerTask = null;

Timer是Java中的定时器。详细用法：java定时器的使用（Timer）。官网说明：Timer (Java Platform SE 7 )。TimerTask是定时器任务。可以理解成可执行多线程。具体可参考Java线程(五)：Timer和TimerTask。  
  
   2.接着定义进度条进度private int progress =0;  

  

   3.定义启动方法与停止方法/\*\*  
 \* 进度条启动  
 \*/  

public void startTimer(){

     if (timer == null){

         timer = new Timer();  
        timerTask = new TimerTask() {  

         @Override

         public void run() {

             progress++;  
            progressBar.setProgress(progress);  
        }};  
  
    timer.schedule(timerTask,200,200);  
    }  

 }

  

 /\*\*

  \* 进度条停止  
 \*/  
public void stopTime(){             
    if (timer!=null){  
        timer = null;  
        timerTask = null;  
        timer.cancel();  
        timerTask.cancel();  
    }  
}  
  
   4.启动与停止

先修改onCreate方法，启动startTimer()方法：

@Override  
protected void onCreate(Bundle savedInstanceState)  

 {

     super.onCreate(savedInstanceState);

     setContentView(R.layout.progressbar);  
  

     progressBar = (ProgressBar) findViewById(R.id.loadingBar);

     //progressBar.setMax(100);

     //progressBar.setProgress(50);   
    startTimer();  
}  

在Android中，有个onPause()，我们就在此方法中停止。忘记的请看：[安卓入门学习（七）Android生命周期](http://mp.weixin.qq.com/s?__biz=MzI1OTA1MzQzNA==&mid=2651209781&idx=2&sn=9c54906cd329b8c83dca7de7ec937ea9&scene=21#wechat_redirect)。

@Override  

protected void onPause() {

     super.onPause();

     stopTime();  
}

**第四章 网格视图插件**  

GridView(网格视图)是按照行列的方式来显示内容的，一般用于显示图片等内容，比如实现九宫格图，用GridView是首选，也是最简单的。

   1.布局定义

在res\\layout\\gridview定义一个GridView。同时也定义一行的数据量为4：

<?xml version="1.0" encoding="utf-8"?>

<LinearLayout xmlns:android\="http://schemas.android.com/apk/res/android"

android:layout\_width\="match\_parent"  
android:layout\_height\="match\_parent"  
android:orientation\="vertical">  
  
<GridView  
    android:layout\_width\="match\_parent"  
    android:layout\_height\="wrap\_content"  
    android:id\="@+id/gridView"  

     android:numColumns\="4" />

</LinearLayout\>

   2.Activity实现数据填充

GridView说白了也是一个ListView,只不过是种横纵向都有的ListView。因此也需要通过setAdapter填充数据。首先定义：

privateGridView gridView;

privateArrayAdapter<String\> adapter;

接着在onCreate方法中配置数据：

//配置数据

adapter = new ArrayAdapter<String\>(this,android.R.layout.simple\_list\_item\_1);

gridView = (GridView) findViewById(R.id.gridView);  

gridView.setAdapter(adapter);

//配置数据

adapter = new ArrayAdapter<String\>(this,android.R.layout.simple\_list\_item\_1);

gridView.setAdapter(adapter);
