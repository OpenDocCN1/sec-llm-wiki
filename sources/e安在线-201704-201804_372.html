警方确认对 MEDoc 进行突袭，其所有人或面临刑事指控。

乌克兰网络警察没收为‘Petya’病毒传播源头的MeDoc 软件公司服务器。

——乌克兰网络警察

乌克兰国家网络犯罪局在7月5日称，在检测到“新一轮袭击”后，没收了由一家小型公司持有的服务器，该服务器是导致恶意软件在全球爆发的源头。这进一步说明，黑客们在进行上周的大范围网络袭击后，仍处于蠢蠢欲动的状态。


网络警察对 M.E. Doc 税务软件公司进行了突袭，并勒令其“立即停止执行不受控传播”的恶意软件。网络警察发言人 Yulia Kvitko 多次表明，M.E. Doc 公司已经或正在准备发送一个新的更新，并补充称当局已迅速采取行动，避免了进一步损失。


“我们的专家（对其）进行了及时制止”，她说道。黑客仍能进入 M.E. Doc 服务器的方式和原因尚不明确。


在导致乌克兰数家跨国企业电脑瘫痪，并且自动提款机、加油站和银行支行遭到网络袭击后，该公司被认定为第一感染源，并成为了政府部门和网络安全研究员们瞩目的焦点。公司尚未对美联社做出回复，但在脸书的一些声明中，该公司对因其不良的安全环境而加速了恶意软件传播的指控做出了反驳。


网络警察对 M.E. Doc 税务软件公司进行了突袭，并勒令其“立即停止执行不受控传播”的恶意软件。网络警察发言人 Yulia Kvitko 发言人多次表明，M.E. Doc 公司已经或正在准备发送一个新的更新，并补充称当局已迅速采取行动，避免了进一步损失。

同时，乌克兰官员开始计算此次爆发带来的损失。基建部部长 Volodymyr Omelyan 对美联社称，其部门六台服务器中的两台及数百处工作站遭受袭击，造成了“数百万”的损失。


乌克兰国家网络警察局局长 Col. Serhiy Demydiuk 称位于基辅的 M.E. Doc 员工对关于信息技术基础设施的连番警告充耳不闻。他在办公室采访中对美联社说道，“他们早已知悉，多家杀毒公司已警告过他们很多次了。涉案人员因忽视这个警告而将可能面临承担刑事责任的风险。”


Demydiuk 和其它官员说，上周反常的破坏性网络袭击主要借助于M.E. Doc 同名税务软件程序的恶意更新传播，这种软件的主要用户是乌克兰会计师和企业。


黑客有可能是在乌克兰人和数家其它跨国企业遭受大规模数据扰频软件袭击之前，便将恶意更新植入了 M.E. Doc 更新服务器，然后在国内散播。M.E. Doc 针对其在袭击中起到的作用给出了数种解释。起初，它承认遭受了黑客袭击，但随后删除了声明。之后称，对其引发了传播的指控是个“明显错误”，但之后，又称其在与当局合作。


同时，上周遭受网络袭击的数家公司称其几乎已经恢复常态。DLA Piper 法律事务所称，上周日已经恢复了邮件服务，正在将其它网络业务联网。丹麦的 A.P. Moller-Maersk 船运公司称，周一已经几乎“满血复活”，仅有除一个货物码头外，其余码头全部重新投入使用。


据报道，俄罗斯公司也受到了影响；俄罗斯国有石油巨头 Rosneft 于周一称，在遭受网络袭击的重击后，他们已经花费了六天时间来彻底维修电脑系统。乌克兰当局指责俄罗斯策划了这次爆发。但数名独立专家称，根据公开的信息，确定任何肯定结论为时尚早。


乌克兰曾数次遭受过来自莫斯科的强力网络袭击。截至周一，乌克兰受损害破坏范围尚未明确，但当局已经发布了恶意软件受害人数和损失预估清单。 Demydiuk 称，他仍在整理数据，甚至拒绝做出预估。


但是，经济破坏显然不容小觑。部分银行员工已经数日没有工作。在基辅的 Kiev's Boryspil 机场，高级官员Yevhenii Dykhne 对美联社透露，三分之一的计算机（主要是属于采购部等后勤部门）仍不能联网。
