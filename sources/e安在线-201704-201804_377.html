中央网信办：特别重大网络事件发生后需24小时值班

中央网信办27日印发了《国家网络安全事件应急预案》，其中将网络安全事件分成四级，并提出对应的预警和应急响应。当特别重大网络安全事件发生后，需成立指挥部，履行应急处置工作的统一领导、指挥、协调职责，同时应急办24小时值班。

来源：中国网信网

北约：“网络”属于军事领域

北约秘书长近日明确表示，“网络”属于一类“军事领域”，而针对北约盟国的网络攻击行为将触犯北约《北大西洋公约》中的第5条内容。体现了北约各国的集体防御原则——换句话来说，针对某一盟国的攻击即被视为针对全体北约国家的攻击，其中也包括网络攻击。

北约目前“正在将网络视为一类军事领域，意味着陆地、空中、海上与网络将作为同等级别的军事领域。”

来源：E安全


中央深改组批准设立杭州互联网法院

据新华社报道，中共中央总书记、国家主席、中央军委主席、中央全面深化改革领导小组组长习近平6月26日上午主持召开中央全面深化改革领导小组第三十六次会议并发表重要讲话。会议审议通过了包括《关于设立杭州互联网法院的方案》等在内的一系列方案。

未来杭州互联网法院诉讼平台受理的案件范围主要包括：网络购物合同纠纷、网络购物产品责任纠纷、网络服务合同纠纷、在互联网上签订、履行的金融借款合同纠纷和小额贷款合同纠纷、网络著作纠纷等。

来源：虎嗅网

中国台湾地区正式成立网络部队

中国台湾地区领导人蔡英文6月29日前往新北市新店营区出席参谋本部资通电军指挥部（资通电：信息、通讯、电子，以下简称网络部队）成立典礼。

网络部队的三项任务

首先，要求积极整合军方信息、通讯和电子各个相关单位，执行“机密”保护，以及关键基础设施防护等工作；

第二，加强网络安全人才的培育；

最后，要发挥领头的前导角色。网络部队的成立，要成为推动台湾地区产学发展的引擎。

来源：E安全

太恶劣：新勒索病毒不为钱 就为搞坏你硬盘

被网络安全专家认为是“Petya”勒索病毒的计算机新病毒在全球发动新攻势。外媒统计称，已有60多个国家报告“中招”。

某网络机构将Petya称为一把刷子，会对数据造成不可逆转的损害。Petya不只是锁定特定文件，而是直接对磁盘的MBR下手，篡改MBR导致整个磁盘无法访问。更糟糕的是，即便向黑客交了赎金，也无法恢复文件。

来源：快科技

英最新航母被曝电脑系统早已过时 “不堪一击”

英国海军最新航空母舰“伊丽莎白女王号”(HMS Queen Elizabeth)正式试航。不过，有英国媒体发现，这艘造价高达35亿英镑的航母，其控制室使用的计算机系统，是微软公司一款已经停止支持的软件Windows XP。鉴于今年5月有黑客发动大规模攻击的目标之一，正是Windows XP，外界担心航母的“铜皮铁骨”之下，计算机系统会不堪一击。

来源：中国新闻网

微软正在使用4亿个人电脑制造一种智能杀毒软件

为了防止下一次全球恶意软件危机，微软即将推出的更新将依靠运行Windows 10的超过4亿台计算机的机器学习。

升级版将升级为Windows防御系统的高级威胁保护，新功能包括浏览器聚焦的应用程序保护，云关联设备保护和漏洞保护。大约96%的被检测到的网络攻击是全新的。微软将人工智能视为安全的下一个解决方案，因为攻击变得更加复杂。

来源：TechWeb


安全团队 Project Zero 曝光：微软发布补丁并未完全修复 Windows 漏洞

Google 团队再次披露了 Windows 系统中能够访问内核存储的安全漏洞。该漏洞于今年 3 月份被 Project Zero 团队成员发现，同时存在于包括 Google 在内的其他公司软件产品，微软已经于今年六月的补丁星期二活动中进行了修复。Project Zero 在发现漏洞之后会向软件商报告，并且在 90 天之后完全公布。尽管这次微软在限定时间内对该漏洞进行了修复，但是 Project Zero 团队表示微软并未完全在正确修复。对此，微软承认确实还存在问题。该漏洞允许任何人访问内核存储。在 Windows 系统中 nt!NtNotifyChangeDirectoryFile 子系统中，被报告由于输出机构隐患导致攻击者可以在用户模式下查看和访问未初始化的内存池。

来源：cnBeta.com

“教材涉黄”案水落石出 网址早过期出版社不知情

出现在国家正版教材中的网址被非法篡改后指向一个涉黄网站，背后是一个靠黄色信息吸引流量的陷阱。日前，在腾讯公司守护者计划安全团队的协助下，武汉警方调集网警、刑警等多警种联合出击，一举打掉一个涉嫌非法侵入计算机信息系统和诈骗犯罪的团伙，刑事拘留33名涉案犯罪嫌疑人，让倍受社会关注的“教材涉黄”案水落石出。

专家呼吁更多的行业、企业和公民个人加入联合共治行列，提高网络安全意识与防范犯罪的能力，做反网络犯罪的“行动派”。 

来源：雷锋网

赛门铁克发布新CISO调研报告 ：云成为网络犯罪的下一个着手点

赛门铁克的调查显示，云安全成为中国CISO所面临的棘手问题。绝大数的CISO(92%)都认为，确保云应用符合合规要求是他们所面临的最大的工作压力之一。在行业合规性方面，中国CISO最担心自身企业是否能够充分跟踪已批准的云应用中的活动(29%)，以及公司员工是否使用未被批准的云应用(23%)。

此外，中国CISO针对云安全的担忧还包括：在云应用中广泛分享合规所管控的敏感数据 (21%)，对企业所属移动设备的管理(16%) 以及遵守国家和地区特定的数据保留和管理条例(11%)。

来源：IT168

美国防部IT预算要求增加5% 保密投资占总数的22%

美国国防部审计长（Comptroller）公布的文件显示，国防部要求增加425亿美元（约2900亿元人民币）的预算支持IT项目。其中，93亿美元（约为总预算的22%）用于保密投资，332亿美元用于非保密投资与支出。

国防部提供的其它的关键数据包括：

  • 5.49亿美元用于采购；

  • 28亿美元用于战斗空间网络；

  • 149亿美元用于国防部IT基础设施；

  • 17亿美元用于“健康”。

文件指出，服务IT要求细目如下：

  • 美国陆军：1100万美元；

  • 美国海军：900万美元；

  • 美国空军：700万美元。

来源：E安全

苹果 iOS 11 被爆存在 iCloud Activation Lock 安全漏洞

据悉，在  iOS 11  的前两个测试版中就有一个漏洞：当  iCloud  被锁定时，使用设备的人还是可以激活设备的某些功能和特性。

iPad  或  iPhone  被锁定到特定  iCloud  账户时，在没有正确的账户凭据的情况下，谁都不能够在设备上有任何操作。苹果推出这个 Activation Lock 机制可以远程锁住  iPhone ：即使对方关闭网络连接、关机、iPhone  刷机，也要输入正确的  Apple ID  才能正常使用，否则会一直被锁上，这个机制有效减少了 iPhone 失窃的比例。希望今年秋季正式版推出的时候，希望这个问题已经得到解决，以保护用户的安全。

来源： TechWeb
