5月底，安全加报道过 勒索软件好多都使用恶意LNK链接文件欺骗用户，趋势科技分析新型LNK-PowerShell攻击 。6月13日，又爆出微软在这个方面存在设计层面的问题，Windows LNK远程代码执行漏洞CVE-2017-8464 ，SecurityFocus评价。

  

microsoft windows 容易出现远程代码执行漏洞。此次漏洞，攻击者如果成功利用，将会在目标系统上执行任意代码。失败的攻击将导致DoS拒绝服务条件。

  

漏洞影响Windows 7、Windows 8.1、Windows 10、Windows server 2008、Windows Server 2012、Windows Server 2016等相关版本，详情如下。

**微软尚未给出缓解措施**

在微软对该漏洞的描述中，不认为可以进行DoS利用，到目前为止没有给出任何缓解措施。描述对该漏洞的表述如下：

*   在 microsoft windows 中存在一个远程代码执行漏洞, 如果执行LNK文件，则有可能被攻击者利用，允许远程执行代码。
    
*   成功利用此漏洞的攻击者可以获得与本地用户相同的用户权限。如果用户的帐户被配置为在系统上拥有较少的用户权限, 则会比使用管理用户权限的用户受到的影响更小。
    
*   攻击者可以通过可移动驱动器或远程共享，向受者传播包含恶意 .LNK文件和相关的恶意二进制文件。当用户在 windows 资源管理器中打开此驱动器 (或远程共享)，或任何其他 .LNK相关的应用程序，就会在受害者的系统上, 执行攻击者构造的恶意二进制文件。
    
*   此安全更新通过更正 LNK引用的处理来解决此漏洞。
