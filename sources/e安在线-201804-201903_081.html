一、概述

网络空间成为国家安全新的疆域已经得到广泛认可，在信息化社会中，没有信息安全就没有国家安全，而保障信息安全依靠的核心要素是人。习近平总书记在2016年4月19日召开的网络安全和信息化工作座谈会中明确提出：“网络空间的竞争,归根结底是人才竞争。建设网络强国,没有一支优秀的人才队伍,没有人才创造力迸发、活力涌流,是难以成功的。”

《中华人民共和国网络安全法》实施一年多以来，信息安全人才培养在不同的行业中都得到了高度的重视，行业、企业纷纷通过组织或者参加各类CTF比赛、联合高校定向培养及内部培训等多种方式培养信息安全人才。尽管如此，信息安全人才短缺问题始终是目前各组织机构在信息安全工作中的痛点。在中国信息安全测评中心主办，中国信息产业商会信息安全产业分会承办的“2018年度中国信息安全从业人员现状调查”活动中，“职业教育”已经取代“自我学习”成为信息安全人才能力成长的首选方式。


二、网络空间安全保障需要全方位的人才

传统国家安全领域如海洋防护依靠的是国家整体的军事实力，而一个国家的军事实力，不仅仅是强大的作战部队，还包括支持部队作战的后勤保障，情报分析、军事工业、情报收集及分析能力等。例如保护我国领海安全方面，需要国家明确海洋安全战略，需要强大的军工科技研发力量研发、设计出先进的军事科技，需要可靠的军工企业生产制造出先进的武器系统，需要优秀的作战参谋在面临威胁时做出正确的判断，需要优秀的舰长在战斗时以准确的战术眼光指挥行动、需要合格的士兵在战斗中对舰船、雷达、火炮、导弹等武器系统进行操作以实现对敌人的有效打击等。网络空间作为与海洋、陆地、天空和外太空并列的第五空间，其安全保障也与其他空间安全防护类似，需要的信息安全人才多种多样。不管是“参谋”还是“士兵”、 “武器设计人员”和“后勤保障人员”以及其他各种不同类型的人才，都是网络空间安全保障不可缺少的，只有这些不同的人才相互配合、各司其职，才能有效地保障我国网络空间安全。 由此可见，网络空间安全保障的人才需求也是全方位、全类型的，既需要熟悉全景的宏观人才，也需要在特定领域非常精通的专才。


三、CISP全面性人才培养

CISP作为我国信息安全人员资质认定的主要形式，经过十多年的发展，已经成为我国批量、快速培养高素质信息安全人才的主要方式之一。在网络空间安全人员培养方面，CISP也在不断地发展以适应目前网络空间安全形势下人才培养的需要。

CISE、CISO是首批推出CISP培训证书，知识体系以总结信息安全相关知识，其目标是通过短时间、集中性的培训帮助学员了解信息安全保障的概念，构建信息安全保障所需要的知识框架从而更好地应对信息安全保障工作。培训学员的定位是网络空间安全保障的基层“指挥官”和“作战参谋”，他们在基本安全技能上可以不如专业的技术人员，但必须各方面有所了解，不会因为存在知识的短板而导致决策错误，就如同巡洋舰的舰长和大副，他们在操作雷达上不可能比得上雷达兵，但知识全面性上不能有短板，大致知道雷达盲区位置，被干扰的情况等，从而在进行决策时能有针对性避免相关问题。


为了适应网络空间安全保障对人才的需求，CISE/CISO的知识体系也在不断地更新和发展，2018年10月1日启用的知识体系V4.1版中，在V4.0版本上进行了重新调整，以信息安全保障为核心，按照信息系统生命周期各阶段的工作，划分并重新构建了网络安全监管、安全管理、安全评估、安全工程与运营、业务连续性、信息安全支撑技术、物理与网络通信安全、计算环境安全、软件安全开发九大知识域。基本覆盖了信息安全工作各个环节，通过学习有效地形成信息安全保障工作的体系化思路，较好的避免了信息安全中“木桶效应”的出现。


四、CISP专项领域人才培养

信息技术与不同领域的深度结合，新的信息化技术的出现，使得网络空间安全保障对人才需求也在不断地变化。“云大移物智”等新技术领域对安全的需求，工业控制系统等领域对复合型信息安全人才需求都是CISE/CISO培训的知识体系难以满足的。为了解决专项领域信息安全人才培养的问题，CISP培训体系从2012年开启了专业领域的信息安全人才培训，并推出了相应的培训证书,力图解决专项领域和复合性的信息安全人才培养痛点。2012年，针对软件安全开发领域和信息系统审计领域的安全人才需求推出了CISD和CISP-Audit(现已更名为CISP-A)，随后与国内知名企业联合针对不同的技术领域先后又推出了CISP-PTE、CWASP CSSP、CISP-ICSSE等多个专项培训证书。

CISP-A(Certified Information System Auditor)，中文名称为注册信息系统审计师。针对从事信息安全审计工作领域的从业人员提供的培训和资质认定，其知识体系在信息安全基本知识技能基础上，侧重信息安全风险评估、信息安全检查、信息系统审计等方面的知识和能力。持有信息系统审计师证书体现了证书持有者在信息系统审计，安全与控制等方面的综合实际能力。 

CISP-PTE（Certified Information Security Professional -Penetration Test Engineer），中文名称为注册信息安全专业人员-渗透测试，是针对渗透测试岗位的专项证书。与CISE/CISO定位信息系统安全防护,侧重知识体系的全面性不同，CISP-PTE是“点”的能力要求，侧重的是“攻”，强调对信息系统的渗透能力，对学习和考试的人员没有任何学历和工作经验的要求，只要对自己的渗透测试技术有信心就可以报名。

CWASP CSSP（Certified Secure Software Professional），中文名称注册软件安全专业人员，培训体系基于软件安全开发生命周期（S-SDLC：Secure Software Development Life Cycle）整理出的一套适用于广大软件开发人员的知识体系。

除了以上的专项领域外，目前正在逐步研发和推出的证书还有工业控制系统、云计算、大数据等新保障领域的安全培训证书。

CISP-ICSSE（Certified Information Security Professional-industrial control system Security Engineer），中文名称为注册工业控制系统安全工程师，针对工业控制系统安全的专项领域培训和资质证书。

CISP-CSE（Certified Information Security Professional-Cloud Security Engineer），中文名称注册云安全工程师,针对云计算领域的安全专项培训和资质证书。 

CISP-BDSA（Certified Information Security Professional-Big Data Security Analyst），中文名称注册大数据安全分析师，针对大数据分析领域的安全专项培训及资质证书。


五、 CISP培训发展思路

CISP培训的发展是伴随着信息安全行业的发展，伴随着国家网络空间安全保障对人才的需求而不断进步。在与其他信息安全培养机制进行协同，不断探索更多更优的信息安全人才培养方式的同时，也逐步将人才培养向专精领域发展。通过点面结合全面培养信息人才。传统的“面”的培训仍然是目前主要的培训重点，尽管经过了十六年的发展，总计培训了近五万持证人员，但对于百万级的信息安全人才缺口，还有很大的成长空间。目前正在探索的“点”的培训是为了适应信息技术的发展对人才新的需求。针对不同领域、技术的专项培训也是未来CISP发展的工作重点。由于信息技术的发展使得安全不断延伸发展，CISP在未来会更多地与在特定领域、特定技术方面有积累的组织机构进行合作，更好地形成专项领域信息安全人才培养的模式，使得人才培养更精细化，更有针对性，也更适应实际工作的需要。
