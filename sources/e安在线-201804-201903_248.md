**最高法五年工作规划：拟出台相关司法解释，保护个人信息权**

![](../Images/e809c1e76519e88bdf2709e6e4e5b7c9.png)

关键词：个人信息

随着个人信息泄露事件的增多，人们对个人信息保护的需求也不断高涨。近日，最高人民法院发布《关于在司法解释中全面贯彻社会主义核心价值观的工作规划（2018-2023）》（以下简称《规划》）。《规划》明确规定，要及时出台审理个人信息权纠纷案件适用法律问题的司法解释，保护个人信息权。

“以前民法和行政法律规则不健全，只能依靠刑法规则，但是仅仅依靠刑事法律打击犯罪并不能真正有效地提升企业的数据安全管理水平。现在最高法拟出台审理个人信息权纠纷案件的司法解释，提供民事救济渠道，将进一步完善我国个人信息权利保护框架下公力救济和私力救济机制。”上海社会科学院信息研究所助理研究员张衠表示。（来源：安全内参）

  

**欧盟拟定网络平台监管法规打击恐怖主义**

![](../Images/b8cb67dac780cb7fd0c6b575ecbabab3.png)

关键词：网络平台监管

欧盟委员会主席Jean-Claude Juncker上周表示，拟定的法规将明确规定，如果网站方没有在极端主义内容出现的一小时内持续删除相关内容，则将面临高达年度营业额4%的巨额罚款。欧盟将极端主义内容定义为“准备、煽动或美化恐怖主义行为的宣传”，各成员国将标记出极端主义内容，明确发布清除令。法规还限定，企业必须监控并确保删除的内容不会因人工智能技术等因素再次出现在网络；而且企业需要发布透明度报告记录相关守则行为。以最近实施的GDPR隐私规则为例，该规则适用于所有在欧盟境内提供服务的托管服务提供商(无论规模大小，所在地是否位于欧盟）。

目前官方表示，这项举措带来的影响态势良好：“目前70％的非法在线激进反社会言论在收到通知后被删除，超过80％的案例在24小时内进行评估，其他在线平台同样需要遵守相关要求。”新规则。“该计划也已扩展到其他在线平台。”（来源：黑客视界）

  

**白宫发布《国家网络战略》，以加强美国网络安全和网络防御**

![](../Images/d69719f06977a18a5b5d8554dd1c676a.png)

关键词：国家网络安全

唐纳德·J·特朗普总统正在发布一项国家网络战略，以加强我们对网络威胁的防御。

一、特朗普总统的国家网络战略确定了联邦政府为保护美国免受网络威胁和加强我们在网络空间的能力所采取的大胆新举措。

二、保护美国人民，家庭和我们的生活方式：加强美国网络安全是国家网络战略的核心。三、促进美国的繁荣：特朗普总统的国家网络战略将有助于保护网络空间，将其作为经济增长和创新的引擎。

四、通过力量保持和平：国家网络战略将加强努力，以阻止网络空间破坏稳定的活动。

五、提升美国影响力：国家网络战略将保持互联网的长期开放性，支持并加强美国的利益。

六、承诺确保未来网络的安全：特朗普总统致力于保护我们国家的网络安全，并正在实施有助于实现这一目标的政策。

总统的国家安全战略优先考虑让美国在网络时代保持安全。特朗普政府发布了一系列针对特定机构的战略，强调网络安全的重要性。（来源：军事首条）

  

**新加坡将设立东盟-新加坡网络安全卓越中心**

![](../Images/4e18be0ce80cc16b9fc579c296615ac1.png)

关键词：网络安全中心

新加坡副总理张志贤（Teo Chee Hean）9月18日在第三届新加坡国际网络活动周的开幕上宣布，新加坡将设立东盟-新加坡网络安全卓越中心，以加强东盟成员国的网络战略制定、立法和研究能力。该中心将扩大现有的东盟网络能力计划，并培训东盟地区的国家计算机应急响应小组（CERT），并促进CERT与CERT之间进行信息开源共享。（来源：E安全）

  

**网络安全事件**

**美国国务院电子邮件系统遭遇入侵**

![](../Images/87ff58abebd34f04e4e34eb7957e86a0.png)

关键词：电子邮件入侵

美国国务院发言人透露，其非保密电子邮件系统遭遇入侵，部分员工的个人可识别信息面临泄露风险。这起入侵事件发生在美国国会议员批评其未达到联邦网络安全标准之后不久。美国国务院发言人表示，该机构正在跨部门，以及与私营部门服务提供商合作，以全面评估这起事件。（来源：E安全）

  

**华住：网上叫卖5亿条酒店客户信息的嫌疑人被抓**

![](../Images/9c946555ad125a27975e3287d3748b8a.png)

关键词：华住

北京时间2018年9月17日，华住集团在美国证券市场发布了“关于华住数据疑遭泄露的调查进展说明”。

说明称，2018年8月28日，网上传言华住数据疑似发生泄露。当天，华住集团对公众作出了正式声明，并向公安机关报案。根据公安机关的最新消息，目前案件已告破，在暗网上试图兜售数据的犯罪嫌疑人已经被缉拿归案，其企图之交易未果。

说明还称，犯罪嫌疑人还利用舆论声浪，对华住进行敲诈勒索，未遂。目前，公安机关在进一步的侦办中。根据中国法律和公安机关的要求，案件侦查过程中不得有更多的信息披露；关于犯罪嫌疑人在暗网上的宣称是否真实，是否存在数据泄露等各界关心的问题，需要等待案件侦办完成后才能正式发布。（来源：澎湃新闻）

  

**超1000万条快递信息被非法窃取，各大高校为重灾区**

![](../Images/d96d289e3e13e0546d08568c62141e13.png)

关键词：快递信息

近期，杭州市萧山区公安分局在“净网2018”专项行动中抓获一个非法获取公民信息团伙。该团伙利用自己是菜鸟驿站服务商的身份，将破解后的“菜鸟驿站”APP安装进物流网点手持终端（俗称巴枪）中，同时植入恶意控件。截获菜鸟驿站服务器发送到巴枪的数据，回传到自己的服务器。

初步统计，截止2018年6月，被窃取的菜鸟驿站快递数据超过1000万条，而且绝大部分数据来自各大高校的网点，服务群体主要是大学生。泄露的信息包括单号、姓名、手机号等等。（来源：澎湃新闻 ）

  

**比特币软件被曝 DoS 漏洞：开发者紧急修补**

![](../Images/9493fdf673fb42634503797855fe9fd8.png)

关键词：比特币DoS漏洞

比特币软件被曝存在一个严重漏洞，导致开发者紧急商讨，并发布修复方案。这个漏洞是一个DoS漏洞，修复方案已经通过Bitcoin Core 0.16.3发出。如果这个漏洞被黑客利用，就有可能去掉节点，最糟糕的情况甚至会导致相当一部分网络暂时崩溃。但并非所有人都有能力利用这个漏洞。只有矿机可以通过加倍投入交易并将其注入到区块中才能实现。

这个漏洞出现在Bitcoin Core 0.14.0中，该软件2071年3月首次推出，但直到两天前才被发现。正因如此，开发者才紧急采取行动，并在24小时内推出解决方案。幸运的是，多数比特币持有人目前都不必采取任何措施。开发者强调称，“存储的”比特币没有风险。但却会影响到那些使用Lightning网络的比特币，这是一种正在开发的交易层，目的是加快交易速度、降低交易成本。（来源：新浪科技）

  

**布里斯托尔机场大屏被勒索软件攻占 耗时2天终于恢复**

![](../Images/788775e22617614763c4c89295d87031.png)

关键词：勒索软件

因机场网络内多台电脑受到恶意勒索软件攻击，布里斯托尔机场（Bristol Airport）在经历了长达两天的宕机之后所有航班信息屏终于恢复正常。本次网络袭击事件发生于上周五早晨，显示航班信息的大屏幕上显示需要支付赎金才能解锁。布里斯托尔机场方面并未就此向黑客妥协，拒绝支付赎金，所有受影响的系统全部都被拆除，而且必须由机场的IT管理人员进行手动恢复。

在勒索软件攻击期间，机场的工作人员不得不使用白板以及海报等方式显示到达的航班以及登机信息。布里斯托尔机场官方推文称：“数字屏上的实时航班信息目前已经完成了核心区域的修复，不过目前在我们上仍未完成。航班不受该技术问题影响，对于给您带来的任何不便，我们深表歉意。”（来源：cnBeta）

  

**数据统计**

**2018 年第二季度针对 web 网站的攻击数量有所上升**

![](../Images/4106f2afcf91e1b08e74830dfdc2531e.png)

关键词：web网站

web 网站服务供应商 SiteLock 调查发现，在 2018 年第二季度，web 网站遭遇的攻击数量有所上升。平均每个网站每天遭遇的攻击高达 58 次，也就是说一个网站每隔 25 分钟就会遭遇一次攻击。与一季度相比，攻击体量增加了 16%。数据显示，目前常见的方法是挖矿劫持以及基于 JS 的攻击。与第一季度相比，挖矿劫持增加了一倍，而恶意 JS 文件则增加了 16%。挖矿劫持的脚本大多使用 JS 套件部署并挖掘加密货币，因此二者同步增长。加密劫持和 JS 脚本往往有隐蔽性，不易被受害者发现，因此成为攻击者青睐的攻击手段。（来源： darkreading）

  

**2018年我国网络安全产业规模将达到545.49亿元**

![](../Images/af3ff29738be008df95723bbeebb4d12.png)

关键词：网络安全产业

 9月19日，中国信息通信研究院在2018国家网络安全宣传周“电信日”主题论坛上发布《中国网络安全产业白皮书（2018）》。白皮书显示，近年来，网络安全产业步入发展的崭新阶段。产业规模快速增长， 2017年我国网络安全产业规模达到439.2亿元，较2016年增长27.6%，预计2018年将达到545.49亿元。据不完全统计，2017年我国共有2681家从事网络安全业务的企业，其中北京、广州、上海企业数量最高，分别为957家、337家和279家，呈现高度集聚态势。安全企业发展态势总体良好。10家典型上市网络安全企业2017年平均营收增长率为26.98%，超过了国际同类企业21.99%的平均增长速度。（来源：人民邮电报社）

  

**人才培养**

**2018网络安全人才发展白皮书发布**

![](../Images/bd43c53c9ed76315beef1075b0220174.png)

关键词：网络安全人才发展

在2018国家网络安全宣传周网络安全人才培养分论坛上，中国信息安全测评中心等单位发布《2018网络安全人才发展白皮书》，白皮书显示，我国网络安全从业人员相对年轻，新加入的网络安全从业人员较少；北上广三地对网络安全人才需求最大，大型政企机构对网络安全人才的需求最大；从事战略与法规制定、信息安全执法监管的网络安全从业人员相对短缺。

 

**人员构成：我国网络安全从业人员相对年轻化**

从年龄结构来看，网络安全从业人员的年龄主要集中在25~35岁之间，这一年龄段的从业人员占总数的68.9%，40岁以下的占比高达94.6%，我国网络安全从业人员相对年轻化。

从网络安全从业人员的薪资来看，近两年，网络安全从业者涨薪明显。目前，薪资水平在10万~30万元的是网络安全从业人员的主流，占比高达75.18%。薪资水平在30万元/年以上的占比达到20.6%，与2016年的9.2%相比，占比显著上升。

**行业需求：北上广三地对网络安全人才需求最大**

北京、上海、广东是人才需求量最大的地区。三省（市）对于网络安全人才的需求占全国需求总量的62.3%，其中，仅北京的需求量就占28.40%。

**岗位分布：安全体系设计等岗位缺口较大**

从岗位分布来看，从事安全运维、应急响应、分析设计的从业人员相对较多，从事战略与法规制定、信息安全执法监管的从业人员相对较少。从事安全态势、分析设计、开发集成和组织管理等岗位的人才相对短缺，38.5%受访者认为分析设计岗位需求最高。（来源：人民邮电报社）

  

**漏洞速递**

**西数NAS出现严重安全漏洞，攻击者可获得完整访问权限**

![](../Images/3decf0eeea120667d73a48b069de56bc.png)

关键词：西数设备漏洞

西部数据（Western Digital）广受欢迎的 My Cloud 系列网络附加存储（NAS）设备，近日曝出了一个严重的安全漏洞，导致攻击者可以完全访问设备里的内容。荷兰安全研究员 Remco Vermeulen 刚刚分享了有关该问题的“特权提升攻击报告”，另一位同行亦表示早已披露了其它攻击的详细信息，但西数迄今未给出固件更新。

Remco Vermeulen 指出：身份验证绕过漏洞允许攻击者在登录设备之前获得管理员权限，他们只需创建反向 shell，便可访问驱动器上的用户文件。（来源：cnBeta）
