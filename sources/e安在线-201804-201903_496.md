# 域外动态丨Cloud法美国国内争议

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTA1MzQzNA==&mid=2651213865&idx=2&sn=5dfd48acb3bd0ddb7a4011bf00c6c63c&chksm=f18c323cc6fbbb2a79f4a5a616bb1bd8f3627b2b53d5ca4b55fd8857543212bc43486b468c20&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTA1MzQzNA==&mid=2651213865&idx=2&sn=5dfd48acb3bd0ddb7a4011bf00c6c63c&chksm=f18c323cc6fbbb2a79f4a5a616bb1bd8f3627b2b53d5ca4b55fd8857543212bc43486b468c20&scene=27#wechat_redirect)

**与其相忘于江湖，不如点击蓝字关注**

2018年3月23日，美国总统特朗普正式签署了《合法使用境外数据明确法》（Clarify Lawful Overseas Use of Data Act，又称“Cloud法”）。该法旨在解决美国政府如何合法获取境外数据及外国政府如何合法获取美国境内数据问题。

  

Cloud法从草案到最终通过在美国国内引发的争议不断，主要表现为以执法部门和科技公司为代表的的支持派及以隐私、公民自由人权保护人士为代表的反对派。本期内容针对能代表支持派意见的“科技公司给参议院的一封信”及代表反对派意见的“隐私、公民自由及人权保障组织联名致国会函”两个文件进行了全文翻译。

  

**支持派意见**

2018年2月6日，苹果、谷歌、facebook、微软、Oath 等科技巨头向提议该法案的议员和白宫提交了一封信，表示CLOUD 法案反映了保护网络用户的共识，并为跨境数据获取行为的管制问题提供了一个合理的解决方案。以下为该信函的中文全译文。

  

**科技公司给参议院的一封信**

 

2018年2月6日

亲爱的参议员 Hatch，Coons，Graham以及白宫：

CLOUD 法案反映了保护网络用户的共识，并为跨境数据获取行为的管制问题提供了一个合理的解决方案。引入这项两党立法是加强和保护个人隐私权，减少国际法律冲突，让我们更安全的重要一步。

一旦颁布，CLOUD法案将为美国政府与其他国家签署现代双边协议创造具体途径，以更好地保护用户。更重要的是，该法要求国家间订立协议时，应当以隐私、人权、法律标准为基线。这将确保用户和数据持有者可受到他们本国法律的保护，并且这些法律是有意义的。这项立法将有助于执法部门调查跨境犯罪和打击恐怖主义时避免国际法律冲突。

该法鼓励外交对话，同时也给予了科技部门两种不同法定权利以保护消费者，解决法律冲突。当一个法律要求涉及到外国政府的居民时，该法建立了一个通知外国政府，必要时直接发起法律质疑的机制。

我们这些企业长期以来一直主张采用国际协议以及全球性的解决方案来为全球用户提供保护。我们一直强调，对话和立法—而不是诉讼—是最好的处理方式。

如果颁布，CLOUD法案将是保护消费者权利的显着进展，并可减少法律冲突。我们感谢你领导提议此项有效的立法解决方案，我们支持此折中法案。

  

**反对派意见**

2018年3月12日，隐私、公民自由和人权组织联名致函国会，反对CLOUD 法案，认为CLOUD法案破坏了隐私和其他人权，损害了重要的民主保障。以下为该信函的中文全译文。

  

**隐私、公民自由及人权保障组织联名致国会函**

 

2018年3月12日

亲爱的议员/参议员：

以下签名的隐私、公民自由和人权组织强烈反对S.2383/H.R. 4943 —《合法使用境外数据明确法》(CLOUD 法)。一些科技公司表示，CLOUD法案代表着“保护消费者权益的显着进展”。我们不同意。我们认为CLOUD法案破坏了隐私和其他人权，以及重要的民主保障。该立法旨在明确政府获取存储在其辖区以外的数据应适用的法律标准。根据现行的美国法律，这种对存储信息的获取请求通常由司法协助条约(MLATs）进行规范。MLATs允许美国和外国政府之间交换信息CLOUD法案建议允许美国和外国政府绕开MLAT框架。

**但是，该法案创建的替代框架未能保护美国人和海外个人的权利，并将过多的权力交给行政部门，而防止滥用的机制很少。如下文所详述，除其他外，立法将：**

**● 允许外国政府按照不符合美国法律的标准在美国土地上进行窃听；**

**● 授权行政部门在没有国会批准的情况下签署外国协议；**

**● 可能促使外国政府获得用于实施侵犯人权的信息，如酷刑；**

**● 允许外国政府获得与美国个人相关的信息，但并不符合宪法标准。**

 

*外国政府要求提供数据*

许多以下签名的团体以前写过我们对CLOUD法案的担忧，包括该法案将允许行政部门与外国政府达成双边协议以绕过MLAT流程；这些协议将允许外国政府直接从美国科技公司获得窃听和储存的通信，包括那些可能包含美国人信息的通信，而未经美国司法部审查或美国法官批准。虽然这个框架产生了许多问题，但下面是我们认为最突出的一些问题：

***该法案将剥夺国会权力，并将权力交给行政部门。***与现有的MLAT程序不同，CLOUD法赋予司法部长在国务卿的同意下，在没有国会的建议和同意的情况下与外国政府达成协议的决定权，并且禁止对他们的决定进行司法或行政复审。MLAT协议通常由行政部门协商并经参议院三分之二投票通过。相比之下，CLOUD法案将允许行政部门未经国会批准即与外国政府达成协议。该法案规定，谈判达成的任何协议将在通知国会该认证后90天后生效，除非国会通过联合决议不予批准。但这需要总统的批准或足够的投票来克服总统的否决权。

***该法案将赋予行政部门与不保护人权的国家达成协议的自由裁量权，允许不保护人权的国家获取敏感的用户信息，而无需美国政府机构的进一步审查。***CLOUD法案未要求外国政府接收来自美国公司的数据时需要达到的标准。例如，司法部长必须考虑，但无需确定该国家是否“遵守适用的人权保障义务”，或者“表明对国际人权的尊重”。该法也不要求外国政府在提出数据要求时获得独立决策者的事先批准，也不需要表明合理的理由。与此相反，MLAT程序中，外国政府请求须经司法部与美国法官的审查，须存在合理的理由，且可能会考虑对人权的影响。

***该法案将允许外国政府以美国政府禁止窃听的标准在美国实施实时拦截（窃听）。***这项协议首次允许外国政府获得美国公司的协助，以实时截取用户的通信信息。它不要求外国政府遵守窃听法的标准，包括通知、合理的理由或设置持续时间限制。这不仅会影响可能成为窃听对象的非美国人，还会影响参与此类通信的美国人。

***该法案将无法保护美国公民和其他居住在美国境内的人的宪法权利。***该法案将允许在不符合第四修正案中规定的标准下，在美国境内实施搜查和扣押，将允许外国政府与美国政府机构分享偶然收集的关于美国人的数据，即使是在低于宪法要求的标准下获得的。此外，该法案规定外国政府必须采取措施尽量减少“美国”人的“信息，但这些规定是不够的，因为它们只要求政府的政策“尽可能地”满足《外国情报监视法》所要求的“定义”。此外，该表述也将非美国公民也没有美国绿卡的人排除在保护范围之外。

  

*美国政府要求提供数据*

CLOUD法案还建议允许司法部获取海外存储的数据，而无需通过MLAT流程。 但是在这样做的时候，该法案未能确保这些请求能够充分保护个人权利，我们最担忧的一些问题是：

***该法案没有规定司法部必须获得内容搜查许可证或遵守宪法规定的通知义务。***CLOUD法未规定获取180天以上的通信内容需要许可证的要求。这可能会为美国政府不符合宪法要求的获取这些信息敞开大门。另外，该法案不能确保通知信息关涉的用户，以便他们可以对于不合理的获取要求提出质疑。

***该法案可能会剥夺用户在美国政府的要求不符合法案要求的情况下的干预能力。***CLOUD法案允许企业在数据披露会违反数据所在国的法律并且美国与该国政府达成数据协议的情况下，允许企业撤销披露要求。但没有明确用户有权提出该撤销请求。此外，它通常不要求美国法官对该要求是否引发了法律冲突作出评估。我们敦促您反对CLOUD法案，并努力将其附加于其他立法。
