**每周一喂**

![](../Images/6d6f08769f8bce9c380a01f78e949c42.png)

时间来到三月底，此次“新冠”疫情的影响已经持续了2个月有余，在多数人居家隔离的日子里，互联网成为了我们与外界沟通的主要渠道。而很多企业也是开放了有期限的免费服务，比如教育和娱乐资源，但却被某些无良的黑产盯上，遭到恶意爬虫攻击。

  

首先，我们来看一下目前开放的免费资源有哪些。

上文提到，图片中列出的某些企业资源原本是收费使用，但特殊时期响应号召所以变成了免费，这一举动却让黑产看到了有利益可寻，纷纷出“洞”。

  

**案例**

**机械工业出版社遭遇恶意爬虫攻击**

2020年2月，机械工业出版社宣布免费开放 6000 余种电子书，其中包括很多专业书籍。不久之后，官方接口陷入崩溃状态，搜索引擎出现其他相关入口。这很有可能是遭遇了大量恶意爬虫攻击。

![](../Images/4905c1c662a5122beea5ed5849728669.png)

  

通过追踪，目前找到了两个机械工业出版社的爬虫，两个都是脚本爬虫，一个爬取web端的数据，另一个爬取H5端的数据。

  

**web端 python爬虫**

爬虫主要使用 requests 进行爬取，通过获取所有的图书连接最终到亚马逊的 CDN 上面去下载内容。

![](../Images/1176eecf91b97772218ace31e1079562.png)

获取该分类下的所有图书，下面使用伪代码说明:

最后保存所有的下载链接，项目中并没有给出所有图书批量下载的代码，但是从仓库的描述来看，之前提供了分片下载的代码。从 github 的 commit 历史里面找到了之前的多线程下载代码，本来以为就是一个简单的爬虫，但是到这里却发现并不那么简单。代码的实际用途是从 AWS 下载 PDF，这个地方为了防止 AWS 拦截，还做了一些伪装。

  

**伪装 HTTP header**

模拟浏览器添加了 http header，并且增加了分段下载的支持。

![](../Images/f85cce933d772604a0d432c637f62256.png)

  

**多线程支持**

为了加速下载仓库使用了多线程下载，但是作者为了防止 AWS 封禁，使用信号量控制同时只能运行三个线程。

![](../Images/d254021d204bdd293bab3589baabfe36.png)

  

**H5端 爬虫**

移动端的爬虫稍微比web端复杂一些，经过一番review发现主要是获取书籍的链接更加复杂了，并且移动端不能直接获取PDF，只能获取到HTML，爬虫这里使用的主要手段是通过获取每个章节的HTML，最终通过将HTML转换成PDF完称书籍的爬取。

  

H5端爬取的大致思路:

1.枚举的方式获取所有的图书 ID (作者猜测总共图书不超过 10000)；

2、因为前端有 cookie 的校验，无法获取 token 所以在前端直接发起请求， 并保存内容，后续处理(类似模拟器的方式)；

3、最终通过 HTML 转 PDF 的形式保存图书。

  

整个过程中比较难处理的是 token 的获取方法，因为笔者没有找到破解办法，最终使用类似模拟器的形式获取所有的HTML连接内容。

  

截止到目前，官方的入口还在升级维护中。想来是有些心寒，为众人抱薪者，却冻毙于风雪之中。

![](../Images/af37a3f590f2f1e820dfbf8b33f03d1f.png)

  

**来自爬虫的威胁**

爬虫，是一种自动化抓取网络资源和信息程序或者脚本。爬虫有好有坏，好的爬虫为我们提供便捷的服务，比如搜索引擎。恶意爬虫会盗取企业核心资源信息，比如上文中提到的内容资源，高频访问侵占服务器资源，导致企业服务崩溃，这无疑是在给企业增加运营的成本。

  

除了上文提到的出版社，清华大学出版社文泉学堂免费为用户提供近三万种正版电子书，同样遭到了大量恶意爬虫的攻击，导致网站服务器处于崩溃的边缘，不得不进行系统升级和维护，暂停为广大读者服务。

  

![](../Images/3c36b21b04defa947f1ac11a3cbb4eff.png)

  

2020 年了，内容付费于我们而言不再是陌生的词，大家都乐于为好的内容买单。我们清楚的知道，好的内容和资源对于一家企业而言意味着什么，而在非常时期遭受的恶意爬虫攻击，让这些企业也是很无奈。

  

**e小安说：**

爬虫与反爬虫的对抗历时久远，很多企业也都会尝试保护自己的核心资源内容。如今，简单的反爬技术很容易被破解绕过，简单的反爬虫机制已经无法抵挡住恶意爬虫的攻击。传统的反爬虫技术包括IP黑白名单、UA 检查和频率控制，但是这些早已经不能有效的防住恶意爬虫了，对付恶意爬虫攻击，仍然是一项任重道远的工作。
