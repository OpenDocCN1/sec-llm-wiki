**全国信息安全标准化技术委员会就信息技术安全系列标准规范公开征求意见**

![](../Images/679b0d5977235916ce712fc91dde8c91.png)

关键词：信息技术安全

近日，全国信息安全标准化技术委员会发布了一系列信息安全技术标准规范，并公开征求意见。此次公开征求意见主要包括《信息安全技术 个人信息告知同意指南》《信息安全技术 移动互联网应用（App）收集个人信息基本规范》以及《信息安全技术 互联网信息服务安全通用要求》等18项标准规范。本次公开征求意见截止时间为3月20日。（来源：全国信息安全标准化技术委员会网站）

  

**英国网络安全行业收入近两年增长46％**

![](../Images/46a23043ed9e4c40e8f631d6396224d1.png)

关键词：网络安全行业

1月30日，英国数字、文化、媒体和体育部（DCMS）发布了最新报告《2020年英国网络安全行业分析》，该报告指出英国网络安全行业现在估值约为83亿英镑，该领域总收入比2017年的57亿英镑增长了46％。此外，该报告重点内容有：英国活跃的网络安全公司从2017年的846家增加到2019年底的1200多家，数量增加了44％，相当于在英国每周都有新的网络安全业务开设；自2017年以来，网络安全领域的全职员工数量增长了37％，达到43000名；行业总收入增长46％，达到约83亿英镑。员工的平均收入增长了7％，达到193500英镑。（来源：SC Media）

  

**美国国家安全局发布《缓解云漏洞指南》**

![](../Images/747a6b79ab76bf1f9ab315442ee4e22d.png)

关键词：云漏洞指南

上月，美国国家安全局（NSA）发布了《缓解云漏洞指南》（Guidance on Mitigating Cloud Vulnerabilities），旨在帮助减少云漏洞和保护云环境组件的信息安全。该指南详细介绍了云安全面临的四个具体威胁，即供应链漏洞、共享信息漏洞、访问控制漏洞以及错误配置。此外，美国国家安全局（NSA）表示，云服务提供商(CSP)和云用户在确保公共云中存储服务和敏感数据安全性方面负有重要责任，将鼓励云服务提供商(CSP)和云用户之间在共享威胁检测、事件响应和补丁管理等方面加强协作。（来源：CISA）

  

**新加坡、马来西亚打击网上关于新型冠状病毒的虚假信息**

![](../Images/2f05ae7d1f55b4b05ef65461a07e2e47.png)

关键词：虚假信息

近日，新加坡和马来西亚都已采取行动，制止关于新型冠状病毒的不准确信息在网络上传播。马来西亚通信和多媒体委员会(MCMC)上周三表示，他们与马来西亚皇家警察联合进行了四次突击搜查，逮捕了四名涉嫌在社交媒体上发布和传播疫情虚假信息的人。新加坡卫生部长上周一指示，向防止在线欺诈和操纵法（POFMA）办公室向运营“硬件地带”论坛的SPH杂志发出一般性更正要求，原因是论坛上的一篇帖子错误地宣称新加坡有一名男子死于该病毒。新加坡通信与信息部部长伊斯瓦兰(S. Iswaran)称:“我们必须迅速采取行动，打击这些谣言，否则它们会在我国公民中蔓延并造成恐慌。”（来源：ZDNet）

**黑客正以新冠疫情热门词汇为诱饵发动网络攻击**

![](../Images/5ae097e1a65a67cde6ab5fa1c1dee8f2.png)

关键词：网络攻击

1月29日，奇安信病毒响应中心和奇安信CERT的技术人员发现多起利用新型冠状病毒肺炎疫情相关热词开展的攻击行动。他们监测到一些黑客组织正在制造并大肆传播一系列电脑版病毒，这些病毒均带有“冠状病毒”“疫情”“武汉”等热门字样，可导致电脑声音被窃听，文件被窃取，一些版本的病毒还会删除操作系统核心文件导致无法开机。目前，该系列病毒正通过社交网络悄然蔓延、肆意传播。

通过热点事件、热门词汇制造“诱饵”，并以此发起攻击是黑客组织的惯用伎俩。奇安信CERT的安全团队在监测中发现，社交网络成为该病毒传播的主要渠道，该黑产团伙使用的病毒会伪装成“冠状病毒”“逃离武汉”“双重预防机制”“新型冠状病毒预防通知”等诱饵词汇，利用人们高度关注、渴求获得相关信息的心理，诱导电脑用户下载并将其打开。（来源：中国青年报）

  

**日内瓦和维也纳联合国办事处去年遭黑客攻击，400GB数据被泄露**

![](../Images/84e3285ea9297b4afb61f8d0cc5a400e.png)

关键词：黑客攻击

在2019年7月发起的一项目的明确的网络攻击活动中，黑客组织入侵了联合国在日内瓦和维也纳办事处的IT系统。在事件发生之后联合国并没有立即公开本次攻击事件，甚至没有向员工披露该事件的性质和受影响范围。直到近日，联合国IT部门的高级官员才对外证实遭到了非常复杂的网络攻击，预估已经有400GB的数据被泄露。

援引《新人道主义》报道，联合国日内瓦办事处的IT官员似乎在一个月后意识到了该黑客事件，并于2019年8月向其技术团队发出了警报。

据报道，该攻击使用了一些未知的恶意软件，并利用了Microsoft SharePoint（CVE-2019-0604）中的一个漏洞，该修补程序已经发布了几个月，但尚未部署。

据说，这些泄露的数据包括人事记录和数千份商业合同的信息，因为黑客获得了网络上的管理员访问权限，最终渗透到该组织在维也纳和日内瓦办事处（包括其高级专员办事处）的40台服务器。

联合国发言人史蒂芬·杜哈里克将事件归类为“严重”，并指出，由于无法确定其确切性质和范围，因此未公开披露该违规行为。（来源：cnBeta）

  

**德国波茨坦市遭遇网络攻击，政府服务器离线**

![](../Images/1fa8945b7d218dff104712595ecca21d.png)

关键词：网络攻击

据外媒报道，近日，德国波茨坦市遭受了重大网络攻击。政府服务器已被关闭，但值得庆幸的是其包括消防部门在内的紧急服务均未受到影响。

据了解，截至目前，波茨坦市政府尚未提供有关此次攻击的详细信息，但德国记者HannoBöck报道称，该政府网络上的Citrix ADC服务器可能是受到 CVE-2019-19781漏洞的影响。有专家注意到，攻击者曾试图利用该漏洞从外部未经授权的向该政府服务器中检索数据并安装恶意软件。

该市市长在事发后发表声明表示，出于安全考虑，在发现政府服务器被入侵后，便即刻计划将系统与Internet断开连接，置于离线状态以应对非法的网络攻击，控制感染并防止数据泄露。

 目前，波茨坦市已聘请了外部IT安全公司和IT法证专家来对此次攻击进行调查。州府已对相关嫌疑人提起刑事诉讼，并将事件通知了负责IT安全和数据保护的区域办事处。（来源：E安全）

  

**“杀毒霸主”Avast被曝挖掘4.35亿用户数据卖给谷歌和微软**

![](../Images/862ceaf7cf9260d42829b0660a84dd38.png)

关键词：Avast

据了解，数月前微软曾清理过一次系统清理软件CCleaner，其本身不仅清理功能薄弱，安全也存在问题，而且还内置捆绑了Avast杀毒软件。而CCleaner的母公司正是2017年就被Avast收购的Piriform，此后CCleaner的质量服务和安全性能一直下降，Avast还悄悄地捆绑了自己的软件。

不仅如此，Avast被曝旗下的多款浏览器插件都有严重侵犯用户隐私的嫌疑，比如这些插件会在用户使用时详细记录其操作的踪迹，用户曾打开了哪些网页和在网页上停留了几秒钟等。

近日，根据外媒Vice和PCMag的联合调查发现，让人更为恼怒的是，Avast的Mac和Windows版杀毒软件一直被用于暗中挖掘用户数据，然后再把敏感信息出售给包括谷歌、微软和财务软件开发商Intuit等在内的第三方。

据了解，Avast提供免费和付费的这些杀毒和安全工具，每月大约有超过4.35亿活跃用户在Macs、个人电脑和移动设备上使用Avast的产品，保护他们的数据免受伤害。同时，Avast的软件提供了选择加入的选项，允许公司收集某些类型的用户数据，然后通过附属公司Jumpshot进行销售。（来源：雷锋网）

  

**微软的 0day 漏洞修复破坏了 Windows 功能**

![](../Images/239cebcc95086ad55525509fcd7ff409.png)

关键词：0 day

此前，微软曾警告 Windows 用户注意来自 IE 浏览器中的 0day 攻击。然而现如今，其在修复 0day 漏洞时却发现，在 Windows 中修复 Internet Explorer zero-day ，则可能会导致操作系统中出现其他问题。

微软早已确认了 0day 问题会影响所有受支持的 Windows 版本中的 Internet Explorer，并解释说全面修复仍在进行中。与此同时，该公司为受影响的用户提供了一种变通方法来保护其设备，实质上就是指示他们限制对 JScript.dll 的访问。

但是，这种缓解措施却会破坏 Windows 的打印，并且撤消变通办法几乎是还原操作系统此功能的唯一方法。据转向 reddit 讨论此错误的用户发现，不论制造品牌是什么，所有打印机都受到了影响。（来源：COSCHINA）

  

**世界经济论坛报告：《预防网络犯罪：互联网服务提供商的原则》**

![](../Images/0126064b4ea44e537473fc383a23126b.png)

关键词：预防网络犯罪

1月底，世界经济论坛（WEF）发布了报告《预防网络犯罪：互联网服务提供商的原则》（Cybercrime Prevention: Principles for Internet Service Providers ）。该报告为互联网服务提供商（ISP）增强网络安全性制定了四项关键性原则：①保护消费者免受网络攻击，并与同行业共同行动，识别和应对已知威胁；②采取措施提高对网络威胁的认识，支持消费者保护自己的网络安全；③与硬件、软件和基础设施供应商紧密合作，提高最低安全级别；④采取措施增强路由安全，有效防御网络攻击。此外，该报告指出，互联网服务提供商（ISP）应积极响应《相互同意的路由安全规范》倡议（Mutually Agreed Norms for Routing Security，MANRS），减少最常见的路由威胁，提高互联网服务提供商之间的协作效率和透明度，增强互联网全球路由系统的安全性。（来源：WEF）

**2019加密货币黑客攻击依然高发，损失超过2.83亿美元**

![](../Images/576c802f244790723994fb39e2f97b6f.png)

关键词：加密货币攻击

根据区块链分析公司 Chainalysis 的数据，黑客在 2019 年攻破了 11 家大型加密货币交易平台，并窃取了价值超过 2.83 亿美元的加密货币。过去 10 年，针对加密货币交易门户网站的攻击数量一直较高。然而最严重的，还是 2018 年失窃的 8.755 亿美元、以及 2014 年的 4.83 亿美元损失。

Chainalysis 指出，黑客得逞数量的急剧增加，可以归因于攻击者不断演变为使用更加复杂的方法来渗透加密货币交易所。

另一方面，加密货币交易所也不是干瞪眼。Chainalysis 报告称，许多平台都有在安全功能上加大投入、以及改进交易验证系统。

根据 Chainalysis 专家的分析，2019 年间，其追踪了超过 28 亿美元的比特币。赃款从已知犯罪实体转移到了几个门户交易所的账户，然后迅速被兑现为法定货币。

除了从加密货币交易所窃取的资金，28 亿美元中还包括了其它类型的非法交易，例如勒索软件的赎金、网络钓鱼 / 诈骗活动、以及与某些犯罪组织有关联的资金。

进一步分析表明，有超过 50% 的资金被转移到了 Binance 和 Huobi 交易平台上的帐户中，成为了网络犯罪分子最常光顾的洗钱场所。

Chainalysis 报告称：尽管几乎所有国家 / 地区都要求对客户身份进行验证，但总体而言，仍有 30 多万个 Binance 和 Huobi 个人账户涉嫌比特币犯罪活动。（来源：cnBeta）

  

**漏洞速递**

  

**Microsoft Azure服务中发现漏洞，或将导致黑客接管云服务器**

![](../Images/b2c8a6bc944b8df87f182e3231964a0d.png)

关键词：云服务器

据外媒报道，近日，以色列网络安全公司Check Point的研究人员披露了Microsoft Azure App Service中两个潜在高危漏洞的详细信息，这些漏洞如果被利用，可能会影响在Azure上运行其Web和移动应用程序的多家企业。

据了解，第一个是一个请求欺骗漏洞CVE-2019-1234，影响了Microsoft的混合云计算软件解决方案Azure Stack。若被利用，则可能使黑客能够未经授权地远程访问在Azure架构上运行的所有虚拟机的屏幕截图和敏感信息，无论它们是在共享、专用还是隔离的虚拟机上运行都会受到影响。

第二个漏洞是一个远程代码执行漏洞CVE-2019-1372，影响了Azure Stack上的Azure应用服务，使黑客能够完全控制整个Azure服务器，从而控制整个企业的商业代码。此外，攻击者还可以通过使用Azure Cloud创建免费用户帐户并在其上运行恶意功能，或者将未经身份验证的HTTP请求发送到Azure Stack用户门户来利用这两个漏洞。

目前，发现这两个漏洞的Check Point研究人员Ronen Shustin已将所发现的详细情况报告给了Microsoft，以黑客造成严重破坏和混乱，并获得了Microsoft 4万美元的漏洞奖励。（来源：E安全）

  

**OpenWRT 曝远程代码执行漏洞**

![](../Images/4711643318642d291c66a9fe0e39844d.png)

关键词：远程代码执行漏洞

路由器发行版 OpenWrt 披露了一个远程代码执行漏洞，OpenWrt opkg 包中的一个 bug 会导致包管理器忽略库索引嵌入的 SHA-256 校验和，事实上绕过了下载 .ipk 文件的完整性检查。由于 opkg 包以 root 权限运行，对整个文件系统具有读访问权限，意味着 .ipk 包嵌入的恶意负荷能执行任意代码。开发者已经释出了新版本修复了漏洞。（来源：solidot）
