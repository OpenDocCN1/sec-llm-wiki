微信方面已处罚超过8万个网络欺诈账号


3月12日，微信安全团队发布《微信个人帐号发布违禁品信息及欺诈行为打击公告》，2021年1月至3月，在核实用户投诉证据后，微信团队共计对4362个发布违禁品售卖信息的微信帐号进行了梯度处罚，对1570个发布违禁品售卖信息的微信群进行封禁处罚，对84598个欺诈类恶意帐号进行了阶梯式处罚，除了对确认欺诈帐号进行封禁处理以外，微信安全团队还会继续挖掘作恶团伙。

百度2021 年初正式把项目捐赠 Apache 基金会


为加速隐私安全生态发展，完善 TrustZone 的技术基础设施，百度在 2021 年初正式把项目捐赠给 Apache 基金会，作为 Teaclave 的子项目之一，同时更名为Teaclave TrustZone SDK，Teaclave TrustZone SDK 与 Teaclave SGX SDK 一样，可以为 Teaclave FaaS 隐私安全计算平台提供底层支持，赋能多平台可信执行环境的隐私安全计算生态。

3.

菲律宾国调局证实国家政府网站遭黑客攻击


3月11日，菲律宾国调局(NBI)证实国家政府网站近日遭受网络攻击，但目前还无法确定此次黑客攻击的幕后主谋是谁。菲国调局返网络犯罪部门负责人洛伦索(Victor Lorenzo)表示，黑客近日对www.gov.ph进行了“拒绝服务攻击”(DoS)，这导致普通民众无法正常访问该网站。菲国调局已经请求信息通讯部(DICT)提供必要的信息和细节，以便展开调查。

4.

1400万个Amazon和eBay帐户数据被泄露


近日，有匿名用户在一个著名的黑客网站上披露了来自 Amazon 和 eBay 的 1400 万帐户数据。从数据细节来看，数据似乎是从 2014 年至 2021 年间从 18 个国家/地区窃取的 Amazon 或 eBay 账户信息。黑客将数据标价 800 美元出售，泄露的详细信息包括完整的客户名称、邮递区号、送货地址和店铺名称以及 160 万用户的电话号码。

微软正在调查机密信息泄露事件


《华尔街日报》援引消息人士的话称，微软公司正在调查机密信息泄露事件，这些信息可能被潜在黑客用于对微软交换服务器（Microsoft Exchange Server）发起网络攻击。2月23日，微软通过微软主动保护计划（MAPP）向专门从事网络安全和杀毒软件开发的公司传送了上述机密信息，而在5天后，出现了使用部分已传送数据的黑客攻击。

Google“隐私模式”下追踪用户面临诉讼


据《彭博》消息，加州一名法官裁定，Google 必须面对一项集体诉讼，诉讼称这家搜索引擎巨头秘密收集用户数据，即便用户使用“隐私”模式也是如此。 用户在去年 6 月指控 Google 拥有“无孔不入的数据追踪业务”，即便用户采取措施保护自己的隐私信息，譬如在 Chrome 浏览器中使用隐私模式，或在 Safari 和其他浏览器中使用私密浏览模式，Google 对用户的追踪依然会持续进行。

美司法部对加密电话公司发起诉讼


据外媒报道，美国司法部(DOJ)于当地时间周五宣布对Sky Global CEO和一名同伙提起诉讼，指控他们出售自己的设备以帮助国际毒品走私者逃避执法。这种类型的起诉非常少见，据悉 ，这是美DOJ第二次对加密电话公司提起诉讼。就在几天前，Sky在回应欧洲针对该公司的执法行动时强烈否认自己是犯罪分子的首选。
