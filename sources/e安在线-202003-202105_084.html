Gartner对云计算和边缘基础设施前景的预测

在当今这个“数字优先”的世界中，企业基础设施正在不断发展和变化，因此基础设施和运营（I&O）领导者需要将适应和保护作为他们的首要任务之一。


物联网（IoT）设备数量每五年增加一倍，因此必须缓解它们所带来的安全风险。云计算的使用正在呈爆炸式增长，企业应用纷纷向公有云迁移，企业机构也正在越来越多地采用云原生部署。随着超大型云供应商开发出将云能力分布到更接近边缘的解决方案，边缘计算的普及速度正在加快。


根据下面几项主要预测，物联网领导者必须做好随时随地运营的准备。


//  隔离式或分段式园区网络设备具有更强大的网络攻击抵御能力

Gartner预计到2029年，将有超过150亿台物联网设备连接至企业基础设施。如果I&O领导者无法合理协调何时以及如何连接这些设备，那么企业、访客、受信任和不受信任的设备都会给企业带来风险。


IT企业机构常常在自己的网络上发现不是由自己安装、保护或管理的物联网设备。黑客只需要三分钟就能入侵这些设备，而企业机构则需要半年或更长时间才能发现漏洞。


请召集整个企业机构就共同的设备连接治理结构达成一致。如果不这么做，IT企业机构将可能无法控制网络安全。为所有设备创建一个在任何设备连接至企业网络之前都必须通过认证的设备认证流程。请让跨职能团队也参与并作出贡献，而不仅仅是IT部门。 


通过对设备进行分段或隔离，可以让企业不易受到网络攻击。事实上，从现在起到2023年，采取这一措施的企业将减少25%的成功网络攻击。


//   云端部署正在加速

在“2020年Gartner云计算终端用户购买行为调查”中，几乎所有的受访者都表示，他们所在的企业计划在未来12个月内维持或增加云计算方面的IT支出。 


云基础设施和平台服务（CIPS）的快速创新步伐使得云成为了新型数字服务和当前传统工作负载的实际平台。这就是为什么到2023年，40%或所有企业工作负载都将被部署到CIPS中，而在2020年，这一比例只有20%。


新冠疫情引发了云战略的重新调整。为实现安全的分布式工作队伍，协作、移动和虚拟桌面正在迅速转移至云端。受益于云弹性的灾难恢复和扩展应用现在已成为云迁移的首要考虑因素之一。


Gartner高级研究总监John McArthur表示：

IT领导者需要制定一个具有凝聚力、扩展性和前瞻性的云战略来充分挖掘云的商业价值。请确保该战略能适应云原生平台和分布式云服务领域的最新行业发展趋势。

//  边缘计算解决方案将在未来五年去芜存菁

边缘计算平台是可以在边缘或接近边缘处实现安全零接触分布式应用和数据处理计算架构的软件和硬件。


凭借集中化的云托管管理以及不断增长的通用云和边缘能力组合，超大型云供应商能够满足边缘附近更广泛的计算需求。而到2023年末，仅有20%已安装的边缘计算平台将由超大型云供应商交付和管理（比2020年的不到1%有所增加）。


边缘计算解决了许多日益增长的需求，包括减少延迟、处理边缘上日益增长的数据和支持网络断连后的恢复能力。

McArthur表示：

边缘计算的范围之广足以支持许多子市场，但它将从支持数千种定制模式精简到只支持几十种模式。云供应商将在整个边缘迁移过程中扮演重要角色或补充边缘解决方案。企业必须优先考虑将基于分布式云的解决方案作为默认解决方案，并依靠合作关系和生态系统而不是一家供应商来实现未来的边缘解决方案。
