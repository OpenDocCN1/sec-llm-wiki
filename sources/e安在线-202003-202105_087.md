**今日 · 看点**

  

**1.**

**红杉遭遇黑客攻击**

据报道，硅谷顶尖风险投资公司红杉资本周五对投资者表示，在它的一名雇员遭遇网络钓鱼攻击后，该公司的一些个人信息和财务信息可能已被第三方窃取。红杉对投资者表示，目前还没有迹象表明这些被窃信息在暗网上交易，或者遭到不法分子利用，该公司表示，他们已经上报给执法部门，并且在与外部网络安全专家合作处理此事。

  

参考来源：

https://www.cnbeta.com/articles/tech/1092935.htm

  

**2.**

**Windows Installer权限提升漏洞**

近日，监测发现微软2月安全更新公告中修复了Windows Installer组件存在权限提升漏洞（CVE-2021-1727）。攻击者可利用该漏洞在目标系统上提升SYSTEM权限。该漏洞为CVE-2020-16902的补丁绕过，且漏洞利用代码（EXP）已被公开，漏洞风险较大。目前官方已发布修复补丁，建议广大用户及时下载并安装修复补丁进行防护，做好资产自查以及预防工作，以免遭受黑客攻击。

  

参考来源：

https://www.secrss.com/articles/29378

  

**3.**

**苹果发布新版安全指南**

安全性和隐私防护是苹果近年来产品的一大卖点。据悉，苹果近日发布了新版平台安全指南，内容主要针对用户在安全和隐私方面的创新和改进，包括更新只读、专用、隔离的系统内容卷，使用Apple的加密签名进行签名，以使其更加安全。此外，苹果还设立了一个新的安全认证和合规中心，并提供了更多关于苹果安全研究设备的信息，以调查操作系统的安全性。

  

参考来源：

https://mp.weixin.qq.com/s/y4fpIx5sJnEzKRkph2p4vQ

  

**4.**

**苹果 M1 Mac 新款原生运行恶意软件**

安全公司Red Canary发现了第二个已知的恶意软件 “Silver Sparrow”（银雀），它被编译成原生运行在M1 Mac上。鉴于 “Silver Sparrow”这个名字，据说这个恶意包利用 macOS Installer JavaScript API 执行可疑的命令。不过，在观察该恶意软件一周多之后，Red Canary 及其研究伙伴都没有观察到最终的有效数据，因此该恶意软件所带来的具体威胁仍然是个谜。

  

参考来源：

https://www.163.com/dy/article/G3D1FUIC0511B8LM.html

  

**5.**

**Windows 和 Linux 服务器遭新型僵尸网络**

随着近期密币交易价格的上涨，多数在线系统会遭密币挖掘僵尸网络的攻击，WatchDog 便是最近出现的一个威胁。安全团队Unit42在上周三发布的分析报告中指出，WatchDog至少活跃于2019年1月，该僵尸网络的操纵者利用了33种不同的 exploit攻击Drupal、Apache Hadoop等软件中的32个漏洞。

  

参考来源：

https://mp.weixin.qq.com/s/D0nr98\_9nAt0LI7t-YAOYA

  

**6.**

**2020年报告的漏洞数量创历史新高 **

近日，根据美国国家标准与技术研究所收集的关于常见漏洞(CVE)的数据分析，2020年全球的安全漏洞报告比以往任何一年都多。托管安全服务提供商Redscan的报告显示，2020年报告了18103个漏洞，其中大多数被列为高度严重级别，占比达57.1%。实际上，2020年披露的高严重性和严重漏洞数量超过了2010年披露的漏洞总数。

  

参考来源：

https://mp.weixin.qq.com/s/tmRHLqyYDo0BCKH2icVOZQ

  

**7.**

**Linux Mint用户安全意识落后于其他发行版**

面向初学者而又易于使用的Linux Mint是知名度比较高的Linux发行版本，但在没有用户干预的情况下默认不安装新的安全更新的问题是，对于许多用户来说，他们在安全修复方面落后了。Linux Mint博客发布了一则通知，鼓励用户安装安全更新，而内部统计显示有相当数量的用户没有这样做。通知中同时也警告用户不要运行基于Ubuntu/Debian的发行版的已淘汰（EOL）版本。

https://www.cnbeta.com/articles/tech/1092823.htm
