Apache Tomcat WebSocket拒绝服务漏洞EXP公开，黑客攻击即将到来

2020年7月14日，Apache官方通报了Apache Tomcat 两个拒绝服务漏洞：CVE-2020-13934、CVE-2020-13935，并发布安全更新。11月5日，该漏洞的利用代码（EXP）已在互联网上公开。这意味着，黑客的攻击利用即将到来，建议受影响的用户尽快升级安装到安全版本。

巴西高等司法法院遭遇重大网络攻击事件

据外媒报道，巴西高等司法法院(STJ)遭遇重大网络攻击，将使其业务停顿整整一周。事件是在周二（3日）发现的，当时正有几个审判庭在进行。据STJ称，在法院的网络中发现了一种病毒，作为预防措施，与互联网的链接被切断，促使审判会议被取消。法院的所有系统，包括电子邮件以及电话系统也因此无法使用。此次攻击并没有影响到正在进行的法院诉讼的相关信息。

戴尔Linux电脑实现硬件隐私控制

戴尔最新发布的隐私驱动程序支持其最新的Linux笔记本电脑，提供硬件控制隐私选项，防止任何程序后台访问。戴尔将此新代码写入到Linux内核中，意味着任何程序（包括恶意软件和间谍软件）都无法“悄悄”启动摄像头或麦克风进行监听或监视。

GitHub否认网站源代码泄露

隐私活动人士 Resynth1943 声称 GitHub 的源代码泄露。但 GitHub CEO Nat Friedman 迅速回应否认网站源代码泄露。Friedman 解释说，源代码意外公开的是 GitHub Enterprise Server，并非网站本身，虽然两者共享了一部分代码，但区别也很大。它通常以混淆格式向客户提供 GitHub Enterprise Server 的源代码，但几个月前不小心向客户提供了非混淆的 GitHub Enterprise Server 代码。

黑客组织向卡普空勒索 1100 万美元，声称盗取 1TB 文件

本周，日本电视游戏软件公司卡普空（CAPCOM）发布声明，称该公司系统遭受第三方攻击。随后，Bleeping Computers 报道称，Ragnar Locker 勒索软件团队声称对此负责。据悉，这个名为 Ragnar Locker 的勒索软件团队声称他们已经从卡普空位于美国和加拿大的公司网络中窃取 1TB 文件，包括银行文件、公司合约、知识产权、客户和员工信息等。

美波特兰市通过人脸识别禁令，公职人员违规使用或被解雇

近日，据媒体报道，美国缅因州波特兰市通过了一项投票，禁止警察和其他公职人员使用人脸识别技术。在今年8月，波特兰市议会就通过了禁止执法机构使用人脸识别技术的禁令，但其中没有关于如何执法的细则。最新的条例是八月禁令的“加强版”：禁止政府机构通过人脸识别进行非法取证，并允许公民起诉非法监视行为。

朝鲜黑客利用Torisma间谍软件进行攻击

这是一场针对航空航天和国防部门的网络间谍活动，目的是在受害者的机器上安装数据收集植入程序，以进行监视和数据过滤。攻击目标是澳大利亚、以色列、俄罗斯的互联网服务提供商（ISPs）以及俄罗斯和印度的国防承包商的IP地址。这些攻击涉及一个之前未被发现的间谍软件工具Torisma，它在暗中监视并利用受害者。这些攻击被归因于之前与“Hidden Cobra”有关的基础设施和TTPs。
