# 关注丨2019年全球网络犯罪损失超35亿美元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTA1MzQzNA==&mid=2651218219&idx=2&sn=eeb25133d81b6367c57f74676f66d891&chksm=f18c033ec6fb8a281129b837be6b720981de04a6cbdcfa9309c3bf484a718215f4375c568500&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTA1MzQzNA==&mid=2651218219&idx=2&sn=eeb25133d81b6367c57f74676f66d891&chksm=f18c033ec6fb8a281129b837be6b720981de04a6cbdcfa9309c3bf484a718215f4375c568500&scene=27#wechat_redirect)

伴随着互联网的深入发展与疫情背景下的信息安全问题，2020年顶级网络安全数据统计也比往年来得更早更深入些，今天让e小安带各位一起来看下，2020年迄今排名前列的统计数据。

  

**2019年全球网络犯罪损失超35亿美元**

![](../Images/3fdbe267ba195a7c6c2c240a07469241.png)![](../Images/4542fb69cbb57bc3ed9d611c9157f37b.png)

2019年是全球网络犯罪案件井喷的一年，据FBI IC 3数据统计，2019年全球企业和个人网络安全事件超过46万，带来了超过35亿元的损失，其中EBC/EAC骗局带来的损失最大，超过了17亿美元，所谓EBC骗局，就是商业电子邮件妥协，也可以称为EAC（电子邮件账户妥协），从本质上讲这是骗子手册中最古老的技巧，但因为技术门槛低，造成的损失影响大，成为黑客最“青睐”的诈骗手段。另外，信心/浪漫举报损失排第二，超4.75亿美元，但由于该类损失涉及到的情感因素较为复杂，许多受害人并未进行举报，这意味着实际带来的损失，可能远远超过这个数字。

  

**2020一季度网络钓鱼攻击中，苹果占品牌假冒行为的十分之一**

![](../Images/3fdbe267ba195a7c6c2c240a07469241.png)![](../Images/cd5be7a1de4e63ed4e7ddc06b2087ac9.png)

模仿知名品牌进行诈骗也是网络犯罪分子最常用的品牌，据调研显示，在2020年第一季度中，苹果依然是最常被模仿的品牌，占据了品牌网络钓鱼尝试的百分之十，紧随其后的是Netflix和雅虎。

  

**乐观的现象：3/4调查者定期审查访问权限**

![](../Images/3fdbe267ba195a7c6c2c240a07469241.png)![](../Images/9765bfe4e2d640af01a8d37400338a5e.png)

一个令人欣慰的现象是，在受访者中，73%的受访者表示会定期检查“人身安全对机密信息的访问”，尽管调查人员表示理想的状况是每个人都应该定期检查，但相较去年的数字，可以看出互联网用户的安全意识在大大提高了。

  

**73%的优秀组织将网络安全视为企业成功的重要因素**

![](../Images/3fdbe267ba195a7c6c2c240a07469241.png)![](../Images/572ddc4514f7471e858feac139e9c965.png)

目前，越是发展状况良好的企业和组织，越重视网络安全，AT&T在最新基准报告中指出，将强大的网络安全与业务结合，与组织文化和IT结合的，是新时代背景下的“领先组织”，其中有73%的组织认可网络安全的重要性。
