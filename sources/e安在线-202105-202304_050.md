**案情**

2022年9月15日，杭州富阳网警发现有人在网站上售卖涉未成年人淫秽视频，随即迅速展开分析研判，明确网站架构人员1名、视频上传人员10名。

  

经查，网站架构人员陈某长期混迹于外网。某天他在群组看到一条“招工信息”，对方需要人帮忙搭建网站，想着自己现在也无所事事，在利益驱使下接了这份活儿。

  

他开始帮助上游犯罪嫌疑人购买服务器、链接，帮助维护渠道以及跳转链接，为“传播涉未成年人淫秽视频”提供了一个分享与交易的平台。

  

网站的运营形式类似于“贴吧”。在该网站，人人都能做卖方，大家可以自行上传视频进行出售、分享、讨论。

  

视频上传人员来自江苏、广西、上海、天津等8个省市，年龄跨度非常大。年长的近40岁，小的甚至还在上学，线下从未见过面。

  

这些“上传人员”们将涉未成年人的淫秽视频打包放在网盘里，后将网盘链接晒在该网站上出售。

  

价格依据视频的数量和“质量”而定，几十元至上百元不等，每个网盘里至少含有4到5条视频。

  

这些视频有的是从外网下载的，有的是从别处搬运而来。在他们看来，只是把视频整合后在兴趣圈里分享，顺带赚点钱……

  

![](../Images/c6d254779dc09fefc65753023f03fd49.png)

  

截至警方查处时，该网站已运行7个多月，每日点击率最少上千，高的时候上万。

  

因涉嫌非法利用信息网络罪、传播淫秽物品罪等罪名，2022年底，杭州市、区两级公安联合展开集中收网，在镇江、天津等地成功抓获犯罪嫌疑人，对其中8人依法采取刑事强制措施，扣押手机9部、电脑8台，查获涉未成年人色情视频2T，涉案金额180余万元。

第三百六十四条第一款【传播淫秽物品罪】传播淫秽的书刊、影片、音像、图片或者其他淫秽物品，情节严重的，处二年以下有期徒刑、拘役或者管制。

  

**GitHub遭到攻击 入侵者窃取了代码签名证书**

IT之家 2 月 1 日消息，微软旗下的代码在线托管平台 GitHub 今天表示遭到网络攻击，入侵者访问了部分代码储存库，并窃取了签署 Desktop 和 Atom 两款应用的代码签名证书。  

  

![](../Images/5218129330485d45046f6e07032244c4.png)

  

代码签名证书用于在代码中植入一个加密戳记，以明确这些代码的开发者。入侵者在窃取了 Desktop 和 Atom 两款应用的代码签名证书之后，可以用于签署恶意篡改的非官方版本。GitHub 表示 Desktop 和 Atom 的当前版本不受凭据盗窃的影响。

  

GitHub 在公告中表示：“入侵者窃取了一组加密的代码签名证书，该证书经过了密码保护，目前并未发现证据表明入侵者使用该证书。但作为预防措施，我们将撤销用于 GitHub Desktop 和 Atom 应用程序的公开证书”。
