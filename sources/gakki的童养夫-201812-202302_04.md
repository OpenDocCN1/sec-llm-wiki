# 安卓逆向（二）-apk动态调试

## 前言

跳过一些内容，关于smali语法，静态分析资料很多，不重新写，主要记下之前动态调试的学习过程。

## 环境

android studio或idea，这里我是用的idea。  
Jeb是一款专业实用且为安全专业人士设计的Android应用程序的反编绎工具。  
安装：

```
1.  `https://down.52pojie.cn/Tools/Android_Tools/`
    
```

## 准备工作

要进行app调试，需要以调试模式启动app。  
需要改apk中的manifest设置为可调试，或者修改安卓的ro.debuggable为1。  
执行命令：

```
1.  `adb shell am start -D -n  "com.xxx.xxxx/.MainActivity”   `
    
```

此时手机或者模拟器会出现如下界面，然后才可以在idea或者jeb中去进行调试：  

![](../Images/005b60c016d888e0a04383b3961f5165.png)

### jeb动态调试

先打开jeb，把要调试的apk拖进去。  

![](../Images/e0f2204feb76f6448b6cf12903208375.png)

找到想要观察的地方，通过ctrl+b下断：  

![](../Images/98b31812c1fcb7a9103e4897130f22bf.png)

然后再完成最前面的准备工作，就可以开始调试了。  
找到对应的设备和进程，附加进程就可以了。  

![](../Images/b7ae5017aa112346fd9a62984bd013b8.png)

然后就去触发断点，就会断下来。  

![](../Images/0eeafa14b519e5fcdc8e107bdeb5ce97.png)

然后就可以愉快的调试了。

  

## idea动态调试

要通过idea或者as调试apk，首先要安装一个插件。  

![](../Images/7bef4bac1f6147de72bea7bc461ca0ac.png)

然后先对要调试的app进行解包，用apktool，然后导入idea。  

![](../Images/061016ee2c88439044023278cb65ac91.png)

右键点击smali文件夹，设定Mark Directory as -> Sources Root。  

![](../Images/3f692f8c960db492d5d9044497405180.png)

然后设置断点：  

![](../Images/ed7c3a486002d018ade744b068f0474c.png)

同样调试模式打开app，然后配置idea去连接jdb。  

![](../Images/545ac58054ab1b499b8655b84963cbfc.png)

然后就可以开始run -> Debug了。  

![](../Images/8bb5896a0bc1d31184cc6ee151128063.png)

触发断点，就可以断下来了。  

![](../Images/ed7c3a486002d018ade744b068f0474c.png)

然后就可以愉快的调试了。
