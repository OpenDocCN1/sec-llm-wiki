RDP bitmap Cache


        当用户使用RDP连接到另一台主机时，bitmap缓存可以减少RDP (Remote Desktop Protocol)客户端和服务器端之间的bitmap数据传输，RDP客户端会创建一个未压缩的临时位图缓存文件，其中包含从远程服务器重复发送给客户端的位图。RDP客户端使用图形设备接口(GDI)调用这些缓存的bitmap来将bitmap展示到显示器上。RDP bitmap缓存位置在

C:\Users\<username>\AppData\Local\Microsoft\Terminal Server Client\Cache

RDP Bitmap可以使用bmc-tools进行解析，下载地址如下：

https://github.com/ANSSI-FR/bmc-tools

使用方法：

python bmc-tools.py  -s bcache24.bmc -d /opt/bmc-tools/

通过bitmap可以看到攻击者打开了什么文件，执行了什么命令等等。如上图，可以看到攻击者打开了cmd窗口执行了systeminfo命令。

mstsc.exe


       在应急响应中，往往会看到受害主机上运行了mstsc.exe进程，想要获取当前进程连接了哪台机器，有两个方法，一种是通过命令查看3389端口对应的主机，如下所示。

另一种就是从进程内存中提取，提取进程字符串检索Cookie: mstshash， 可以看到远程登录的用户名，还有远程主机的IP。

之前在某篇博客中看到Windows10的某些版本，可以在进程内存字符串中获取远程主机的连接密码，具体就不细说了。
