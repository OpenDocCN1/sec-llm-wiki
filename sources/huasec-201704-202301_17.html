修复损坏的video


场景：录像过程中未能正常结束，导致生成的文件无法打开

准备工作：recover_mp4.exe和 ffmpeg.exe

开始修复：

(1) 分析视频设置信息

recover_mp4.exe example.mp4 --analyze

会在当前目录生成一个"video.hdr"的配置文件，注意返回内容的尾部，会给出操作提示：

Now run thefollowing command to start recovering:

recover_mp4.exe corrupted_fileresult.h264 --noaudio --lav

Then use ffmpeg tomux the final file:

ffmpeg.exe -r **.000-i result.h264 -c:v copy result.mp4

 

(2)修复视频文件

recover_mp4.exe corrupted_file result.h264 --noaudio --lav //此处将corrupted_file 替换为你的损坏录像文件名

 ffmpeg.exe -r 15.000-i result.h264 -c:v copy result.mp4   //这里的 15.000 是原始帧率，会根据样本文件分析结果而改变

至此，生成的result.mp4即为修复好的录像。

相关工具见：https://github.com/shiyihua/Emergency_Reponse
