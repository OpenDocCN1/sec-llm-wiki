前言


    得到客户授权，为企业内网进行渗透测试时，通常客户会给我们几个B段、或者几十个C段，面临这么大渗透目标，通常我们首先会扫一下弱口令、然后用各种CMS EXP去批量，最后才是针对性的测试。这里我总结一些企业内部常见的存在弱口令应用，欢迎补充。

mysql、vnc、redis、mongodb、ldapd、tomcat、ssh、http 401、mssql、zookeeper、memcached、smb、snmp、ftp、postgresql、rdp、telnet、rsync、phpmyadmin、smtp、pop3

这些应用的默认端口会被修改，例如redis默认端口为6379，但是内网扫6379发现没有一台机器开放，那么你就要注意是不是被修改在其他端口，比如我遇到过的redis开放在10082端口。

工具介绍


根据上一节的描述，扫描弱口令的时候我有两个需求一是批量，也就是同时对多个目标进行扫描，二是自定义端口。以mysql和zookeeper为例，介绍脚本的使用方法。

(1)爆破mysql脚本

参数介绍

-h          查看帮助                                 -t          测试单个目标                                           -p          测试端口                                           -u          用户名字典                                           -P          密码字典                    -a          指定ip文件                      

不指定-p 参数，默认测试端口为3306

单个目标：

python brute_mysql.py -t 127.0.0.1 -p 3306 -u user.txt -P pass.txt

多个目标：

python brute_mysql.py -a ips.txt  -p 3306 -u user.txt -P pass.txt

ips.txt

(2) zookeeper未授权访问

参数介绍

-h         查看帮助-t         测试单个目标-p         指定端口-a         指定ip文件

不指定-p 参数，默认测试端口为2181

单个目标：

python brute_zookeeper.py -t 52.x.x.x

多个目标：

python brute_zookeeper.py -a ips.txt -p 2181

ips.txt

备注：其他脚本的用法与以上用法一致。
