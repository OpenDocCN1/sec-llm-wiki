小姿势  

  

    在渗透测试中，我们常常会暴力破解管理员或者某些用户的账号，在之前渗透中，我总结了一些爆破的一些使用小技巧，在此抛砖引玉，希望能给各位带来一些意想不到的收获。

  

1.管理员账号除了常规的的 admin、root、system等，还有该网站的域名或者域名加常规字符，例如我们测试 www.huasec.com，构造用户名爆破字典的时候，除了常规字典，我们可以在加上huasec、huasec123、Huasec等。

#!/usr/bin/env python# -*- coding: utf-8 -*-# @Date    : 2018-06-16 19:34:44# @Author  : crhua
import reimport sys
"""1.常规弱口令2.域名弱口令  2.1 域名+ 123/123456  2.2 域名双写 + 123/1234563.用户名@域名4.域名的首字母加系统功能  如 bbs.paipai.commysql密码  ppbbsdb ppbbsdb@db"""
def run(url):  ulen = url.split(".")  print(ulen)  if len(ulen) == 2:    u_pattern = r'(.*?)\.(.*?)'    ures = re.findall(u_pattern, url)    m_domain = ures[0][0]  elif len(ulen) == 3:    u_pattern = r'(.*?)\.(.*?)\.(.*?)'    ures = re.findall(u_pattern, url)    m_domain = ures[0][1]  elif len(ulen) == 4:    u_pattern = r'(.*?)\.(.*?)\.(.*?)\.(.*?)'    ures = re.findall(u_pattern, url)    m_domain = ures[0][2]  else:    print("url is long!!!!")    sys.exit(0)  print(m_domain)
  two_m_domain = "{0}{1}".format(m_domain,m_domain)  last_dic = [m_domain,two_m_domain]
  """  字典1格式： baidu111  """  for i in range(10):    tmp = "{0}{1}{2}{3}".format(m_domain,i,i,i)    last_dic.append(tmp)
  """  弱口令字典后缀,可以在这里追加后缀  字典2格式: baidu+后缀  """  week_dic = ['123','123456','888','666','1','1234','12345','12','@123','@163','163','8','2018','999','2019','!@#','2015','2016','2017','@2018','@2019']  for i in week_dic:    tmp = "{0}{1}".format(m_domain,i)    last_dic.append(tmp)
  """  字典3格式:baidubaidu+后缀  """  for i in week_dic:    tmp = "{0}{1}".format(two_m_domain,i)    last_dic.append(tmp)
  """  字典4格式:baidubaidu+111  """  for i in range(10):    tmp = "{0}{1}{2}{3}".format(two_m_domain,i,i,i)    last_dic.append(tmp)
  print(last_dic)  filename = "{0}.txt".format(url)  with open(filename,'a+') as f:    for i in last_dic:      f.write("{0}\n".format(i))  f.close()
if __name__ == "__main__":  if len(sys.argv) < 2:    print("Usage: python main.py www.baidu.com")  else:    url = sys.argv[1]    run(url)
