“今天介绍一款工具FileScan(敏感文件扫描)。 ”


01

—


工具介绍


     某些网站的运维会将网站的源码或者数据库文件打包成压缩文件放在网站的目录下，FileScan可以扫描网站是否存在敏感文件，可以将网站的域名制作成扫描字典，增强扫描的全面性。


02

—


使用方法


1.使用帮助

python FileScan.py -h
usage:  python FileScan.py -u https://www.example.com/  python FileScan.py -f url.txt -d bak.txt
A Website File Leak Scan Tool.
optional arguments:  -h, --help            show this help message and exit  -f URL_FILE, --url-file URL_FILE                        Example: url.txt  -u [URL], --url [URL]                        Example: http://www.example.com/  -d [DICT_FILE], --dict-file [DICT_FILE]                        Example: dict.txt


2.对单个url进行扫描

python FileScan.py -u http://www.huasec.com/

框起来的是根据域名生成的字典。

3.对多个url进行扫描
python FileScan.py -f url.txt

4.加载字典进行扫描
python FileScan.py -u http://www.huasec.com/ -d bak.txt

—


工具扩展


使用者可以对工具进行二次开发，在代码的93行

suffixFormat = ['.rar', '.zip', '.gz', '.sql.gz', '.tar.gz', '.sql', '.tar.tgz', 'swp','bak','tmp','~','.7z','.tar','cab','tgz','gz','bz2','z' ]

可以添加更多的敏感文件的后缀；另外也可以对当前目录下的bak.txt追加自己搜集的字典。
