**前言**

      很多人用过sqlmap和burpsuite这两个神器,但是他俩结合起来使用，会产生更大效果。文章介绍Sqlmapapi与burpsuite结合使用。批量检测注入，方便我们做渗透测试。

**环境**

    burpsuite

    sqlmap

    jypthon  

**流程**

1.  打开kali linux,进入sqlmap的安装目录/usr/share/sqlmap，列出目录下的文件。
    
    ![](../Images/0a0bde4d427ccdeb071c1af29c4fcb17.png)
    
2.  我们要使用的是**sqlmapapi.py**,查看下帮助
    
    ![](../Images/f6d9fe77e32ef5d575b9dd5d21213357.png)
    
3.  使用 **python sqlmap.py -s -H 127.0.0.1 -p 9090** 启动sqlmapapi
    
    ![](../Images/ffc3745168f1c5d89137576e5ea5de82.png)
    
4.  打开burp,进入Extender模块，下载SQLiPy扩展，需要jpython 环境。  
    
    ![](../Images/b3b15150cbd117d797372c28e73fae70.png)
    
5.  进入SQLi扩展，配置ip和port，对应我们使用sqlmapapi 设置的ip和port
    
    ![](../Images/b5697c8b420356969527db3acdc44302.png)
    
6.  设置完成后，点击start API 启动
    
    ![](../Images/6e1133f55b70aeaeeccd9308c4f0e677.png)
    
7.  打开浏览器配置代理，使用burp爬去链接，将你选择的内容发送到SQLiPy 扩展。
    
    ![](../Images/36f8894e0f6da4cd7eb0e6e72d3253ff.png)
    
8.  配置你的选择然后开始扫描
    
      
    
    ![](../Images/16737565436578e3770587771754e020.png)
    
9.  在SQLMAP Logs 里查看扫描结果。
    
    ![](../Images/89dba03d5b1976bc6c0ce01999b70a66.png)
