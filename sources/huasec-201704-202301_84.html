0x00 简介

 Shodan是互联网上最可怕的搜索引擎

                      --摘自《百度百科》

0x01 命令解释

    alert          为你的账户管理网络警报

    convert     将给定的输入数据转码为

    counts       返回搜索结果的条数

    downloads    将搜索结果保存在本地

    honeyscore   检查IP是否为蜜罐

    host            查看IP信息

    info             显示账户的详细信息

    myip            打印本机IP地址

    parse          从压缩的JSON文件提取信息

    scan            扫描IP

    search        搜索shodan数据库

    stats           提供关于搜索的摘要信息

    stream         实时流数据

0x02 命令行下的使用

 #初始化命令行
 shodan  init [API_KEY]

#查询搜索结果的数量
shodan  count  microsoft iis 7

#将搜索结果下载
shodan down search microsoft iis 7.0

#解析下载的json数据
shodan parse --fields ip_str,port,

#查看本机ip
shodan myip

#查看IP信息
shodan  host IP
