**0x00  docker介绍**

Docker 使用 Google 公司推出的 Go 语言 进行开发实现，基于 Linux 内核的 cgroup，namespace，以及 AUFS 类的 Union FS 等技术，对进程进行封装隔离，属于操作系统层面的虚拟化技术。由于隔离的进程独立于宿主和其它的隔离的进程，因此也称其为容器。最初实现是基于 LXC，从 0.7 以后开始去除 LXC，转而使用自行开发的 libcontainer，从 1.11 开始，则进一步演进为使用 runC 和 containerd。

Docker 在容器的基础上，进行了进一步的封装，从文件系统、网络互联到进程隔离等等，极大的简化了容器的创建和维护。使得 Docker 技术比虚拟机技术更为轻便、快捷。

**0x02  安装**

windows10安装采用docker toolbox 安装    

下载地址  https://www.docker.com/products/docker-toolbox

下载结束，双击exe 安装

![](../Images/d5a6d8f0cfb440797848aae521f30a03.png)  

如果电脑上没有virtual box 选中安装

![](../Images/9aeeacc2bc1b91fdb7e58205a619599c.png)

一路点击确认，如果你的电脑装的360 中间会拦截写入注册表，允许操作就行了

安装完成后出现三个图标

![](../Images/e82f6737e98d32f5758684be617fa901.png)

点击Docker Quickstart Terminal 运行

出现这个界面表示成功

![](../Images/0dae59c5a32589125b377af2e169b01c.png)

过程中会遇到一些问题 ，下面我说一下我安装中遇到的问题

1）点击Docker Quickstart Terminal 运行后，显示boot2docker.iso is out-of-date， 需要从git 上下载 然后替换默认的，注意要看路径

2）安装卸载后再安装，出现  

Error with pre-create check: "Hyper-V is installed. VirtualBox won't boot a 64bits VM when Hyper-V is activated.installed but deactivated, you can use --virtualbox-no-vtx-check to try anyways"

解决方法：禁用 hyper -V  

![](../Images/bd341950c7ed967118853a31c6e554a5.png)

然后再安装，就ok了
