这题的核心就是这两个算式

  1. print x * p + FLAG % p
  2. print y * p + FLAG % q

  2. b1 = y1 * p + FLAG % q

  4. b2 = y2 * p + FLAG % q

  1. a1 - a2 = (x1 - x2) * p
