## 0x07 number

### 这题的核心就是这两个算式  

```
1.  `print x * p + FLAG % p`
    
2.  `print y * p + FLAG % q`
    
```

由于 `x` 和 `y` 是随机出来的，因此两次获取的值是不同的。所以我们 `nc`两次可以拿到不同的值。记为

```
1.  `a1 = x1 * p + FLAG % p`
    
2.  `b1 = y1 * p + FLAG % q`
    
3.  `a2 = x2 * p + FLAG % p`
    
4.  `b2 = y2 * p + FLAG % q`
    
```

所以可得

```
1.  `a1 - a2 = (x1 - x2) * p`
    
2.  `b1 - b2 = (y1 - y2) * p`
    
```

也就是说 a1 - a2 和 b1 - b2 有相同的因数 kp (k为某个常数)，那么直接 gcd 就可以求出来（求出来之后别忘了看下结果是否是质数，不是质数记得再 nc 上去拿一组新的值再 gcd）

```
1.  `import gmpy2`
    
2.  `p = gmpy2.gcd(a1 - a2, b1 - b2)`
    
```

由于 `a1 % p = ((x1 * p) % p + FLAG % p) p = FLAG % p`，所以

```
1.  `flag_mod_p = a1 % p`
    
```

知道了 `FLAG % p`，接下来就是求 `FLAG` 了。 （其实这里就结束了，然而我当时并不知道。。。）

由于 `len(hex(flag_mod_p)) == 86`, 而 `len(hex(p) == 514`，考虑到比赛的 `flag`不会很长，所以简单枚举下就可以了。


2.  各种并行计算
    
3.  一般来说，这个语言是从右往左算的，但是遇到『左参数』的时候要注意下
    
4.  你看到 `{}`的时候表示这是一个函数， `⍵` 代表右参数， `⍺` 代表左参数，有左参数的时候必须有右参数。
    

这题里还有一个不常见的写法 `1(8)40` ，意思就是一个 `1 8 40`的list，括号仅表示间隔

说下这题里用到重要的符号

1.  `⎕UCS`， 是根据 `String` 获取一个 `ASCII` 码列表
    
2.  `⍴`，有两个含义，单独用是取 shape， 如 `⍴2 4 6`结果为 `3`，左面也有参数的时候表示 reshape，如 `(2 2)⍴2 4 6 8`结果为 `(2 4)(6 8)`
    
3.  `⊥`与 `⊤`，官方为 encode 与 decode，在本题就是用来在二进制和数字之间来回转换
    
4.  `⊖⌽`，形象描述，做上下左右翻转
