leakPasswd

这是一款用来查询密码泄露的 Python 模块

开源地址：https://github.com/lauixData/leakPasswd

安装

安装方式一

  1. pip install leakPasswd

安装方式二

下载源码，进入源码目录

  1. python setup.py install

使用

测试是否安装成功

  1. import leakPasswd

查看所有泄露厂商的信息

  1. import leakPasswd
  2. leakPasswd.queryBreachs()

查看某个泄露厂商的信息

  1. import leakPasswd
  2. leakPasswd.findBreach('taobao')

查看泄露密码的账号

  1. import leakPasswd
  2. leakPasswd.findAccount('test@qq.com')
