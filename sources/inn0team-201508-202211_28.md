## 破解思路

右键查找 软件所在目录 拖到 桌面

![](../Images/6f3d3825eb1bea473625842d9c755a8b.png)

桌面软件 `mac_demo.app`

右键 -》显示包内容 -》Contents -》MacOS -》mac\_demo

![](../Images/596a35323aa1a945b9b6acd8320ebd96.png)

![](../Images/5766e3ecf1619a2fc1f25417d3583025.png)

![](../Images/0b2d1c4008097627105f97a025a6f3fd.png)

> mov 可以理解 成 是 代码里的 变量赋值 cmp 可以理解 成 是 代码里的 if 判断 je 当等于时跳转到 正确代码区 jne 当不等于时 跳转到 错误代码区

填充 为 nop 保存 即可  

![](../Images/fba4a35f2e9358f40826d0fe710cc349.png)

![](../Images/dadb32581740689a65762471ca952b43.png)

**导出修改后的 文件 保存到桌面**

把桌面生成的文件 替换掉 桌面软件 `mac_demo.app`

右键 -》显示包内容 -》Contents -》MacOS -》mac\_demo 

![](../Images/a646b649f1696e98e2e388176c3ec2df.png)
