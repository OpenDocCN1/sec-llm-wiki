### 项目结构

➜ webKiss tree  
.  
├── db # db数据库目录  
│ └── \_\_init\_\_.py  
├── kiss # 框架主目录 可以放到python 的库目录，这样会支持全局调用。可以不用在项目里调用。  
│ ├── Kiss.py # 框架主文件  
│ └── \_\_init\_\_.py  
├── run.py # 运行主入口  
├── static # 静态文件  
│ ├── css  
│ ├── images  
│ └── js  
├── templates # 网站模板  
│ └── index.html  
└── util # 工具文件夹  
└── \_\_init\_\_.py
