0x01 系统的搭建

0x03 remastersys软件的安装和使用

  

![](../Images/04445e2330afcc9ed4590d6eb5b69e46.png)  

进入www.remastersys.org 而非网络资料中的www.remastersys.com，点击Ubuntu按钮出现下面的网页。

![](../Images/fe1c4aecb6d7261dc330896d2a0082cb.png)  

下载需要的 Ubuntu Remastersys command line（必要），根据系统版本下载相应版本的32位或64位GUI程序（有点不稳定，不推荐使用）。

![](../Images/db48e3900518f44e61453834d8d63165.png)  

先安装 Ubuntu Remastersys command line，点击文件软件中心自动安装，使用了其他linux系统可没有这么好的待遇哦。 

打开终端，输入sudo remastersys 可以发现出现了提示信息

![](../Images/32c2785e2cacc165cbfc713c701059c6.png)  

根据提示，可以使用sudo remastersys backup进行打包，打包ISO文件名字是默认，或者后面加上指定的ISO文件名称。

输入sudo remastersys backup myubuntu.iso

经历不长时间的打包过程，你会在home/remastersys/remastersys路径下找到你需要的光盘镜像

![](../Images/22abd6145a83b9b695a9f9eda4531195.png)  

使用sudo remastersys clean可以进行所有文件的清理

也可以使用GUI进行更加方便的镜像制作

首先安装remastersys-gui程序，点击安装，一切都很简单......

![](../Images/e0efac50055629961081304b384db90d.png)

悲催的是，你还是需要使用终端输入sudo remastersys-gui来开启这个程序

![](../Images/bdda1ed987c2822ee114b1fb8ddc124c.png)  

点击backup进行光盘镜像的制作，在相同的位置找到制作完成的光盘镜像。

![](../Images/c6712e76f689e376462890a876639b18.png)  

找到指定镜像后可以将iso镜像进行导出或者刻录。指定光盘镜像进行安装的时候出现以下画面意味着光盘镜像制作成功，按照提示一步步安装即可。

![](../Images/6175af92d846284d447312e86d70847c.png)
