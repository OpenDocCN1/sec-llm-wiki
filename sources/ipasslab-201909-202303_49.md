报告题目：On the detection of custom memory allocators in C binaries

报告人：张根  

简介：众所周知，C语言中有常见的allocator与deallocator，例如malloc()和free()。本次汇报首先介绍On the detection of custom memory allocators in C binaries这篇文章，该文章利用动态二进制插桩识别二进制程序中的customized allocator（分配）, deallocator（释放）, reallocator（重新分配）函数，成功识别了十几个allocator与deallocator。其次，介绍我近期对内核源代码进行的漏洞挖掘工作中识别内核allocator（分配）, deallocator（释放）函数的工作，主要是使用了静态分析，以及基于特征的方法识别allocator，基于error-code的方法识别deallocator，成功识别了上百个allocator与deallocator。
