No.4 Mirai botnet的演进（星期四）

No.5 Spring WebFlow 远程代码执行漏洞（CVE-2017-4971）（星期五）

推荐指数：★★★

关键词：漏洞场景复现、漏洞原理、利用方法以及修复建议

 Spring Web Flow 是 Spring 的一个子项目，其最主要的目的是解决跨越多个请求的、用户与服务器之间的、有状态交互问题。

     而本次漏洞，Spring Web Flow 远程代码执行漏洞（CVE-2017-4971），允许攻击者从表单可以提交恶意的表达式从而被执行，导致任意代码执行，但这个漏洞利用除了版本的限制之外还有两个前置条件，这两个前置条件中有一个是默认配置，另外一个就是编码规范了，漏洞能不能利用成功主要就取决于后面的条件，具体请参考文档内容

    本次实验环境对CVE-2017-4971漏洞场景进行复现，对漏洞原理、利用方法以及修复建议进行了讲解，同学们快来体验吧！
