**No.1  Apt之盾：一个精密的APT木马检测系统（星期四）**

推荐指数：★★★

关键词：APT，APT防御方法

    APT攻击一直威胁着企业的数据安全，是很多企业的大麻烦。黑客蓄谋已久的“恶意商业间谍威胁“悄悄拉开帷幕，黑客为了盗取企业核心资料，针对客户所发出的网络攻击和侵袭行为，这种行为往往经过长期的经营与策划，并具有很强的隐蔽性，令许多企业头疼不已。

    来自美国西北大学的教授教授Yan Chen，为我们讲解了什么是APT，并带来了基于RAT的APT防御方法，可以实时弹性规避APT攻击。通过这门课的学习，我们可以了解到 APT攻击是怎样实现的，APT最新的防御方法，给我们带来世界领先的技术分享。

**No.3 用机器学习对抗金融诈骗（星期四）**

推荐指数：★★★★★+

关键词：URL分析黑产、机器学习、金融诈骗、安全数据的关联、挖掘黑产

 一个顾客在商店用信用卡结账，收银员却说该卡被拒，可是该卡信用额度良好，并且可以正常使用，对于金融服务行业来说，这些”误判“是一个很大的问题。

**No.4 Mirai botnet的演进（星期四）**

推荐指数：★★★★★

关键词：Mirai历史数据、Mirai传播方式、蜜罐生成、Mirai变种的检测

什么是  Mirai botnet？Mirai botnet是攻击者采用一种或多种传播手段，传播病毒并感染互联网上的大量主机，从而使得攻击者将控制并指挥多台主机，常常威胁到网上冲浪的网友，可想而知的可怕！

     来自360网络安全研究院的数据分析工程师刘亚，逐步从Mirai历史数据，Mirai传播方式以及蜜罐生成，到Mirai变种的检测等三个方面，为我们带来了Mirai botnet的演进历史 。从这门课程中，我们可以综合学习到有关于Mirai的各种知识，包括未来Mirai的变种及其检测。

**No.5 Spring WebFlow 远程代码执行漏洞（CVE-2017-4971）（星期五）**

推荐指数：★★★

关键词：漏洞场景复现、漏洞原理、利用方法以及修复建议

 Spring Web Flow 是 Spring 的一个子项目，其最主要的目的是解决跨越多个请求的、用户与服务器之间的、有状态交互问题。

     而本次漏洞，Spring Web Flow 远程代码执行漏洞（CVE-2017-4971），允许攻击者从表单可以提交恶意的表达式从而被执行，导致任意代码执行，但这个漏洞利用除了版本的限制之外还有两个前置条件，这两个前置条件中有一个是默认配置，另外一个就是编码规范了，漏洞能不能利用成功主要就取决于后面的条件，具体请参考文档内容

    本次实验环境对CVE-2017-4971漏洞场景进行复现，对漏洞原理、利用方法以及修复建议进行了讲解，同学们快来体验吧！
