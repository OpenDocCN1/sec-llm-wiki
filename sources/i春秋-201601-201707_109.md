# 安全攻防桌游大漩涡：你玩得转吗？

大学的时候，有次好基友叫上了三五个妹纸约小i一起去玩桌游。小i那时第一次接触桌游这个名词还并不了解它是什么，心里暗自盘算，桌游？斗地主还是搓麻将？我吊打他们一群啊，这几个臭流氓等着在菇凉面前输的无地自容吧。

![](../Images/23ddbbb98fc4996e1964409ad444f8ff.png)

然而，当小i斗志昂扬的大跨步走进跟基友约好的桌游吧时，不曾想基友们却拿出来了一副狼人杀。。。

之后在长达三个小时的游戏过程中，每局都会被看穿身份的小i整个i都懵逼了。。。那天，小i是被虐的含眼泪儿走的。。。

![](../Images/5dfc5b50241f811d8aa3a2f887d9fd03.png)

回去以后，小i苦读攻略看了大量教程，终于在之后的一次聚会时大杀四方，拾回了曾经碎了一地的面子。。。

大家也都有玩桌游的经历吧，在游戏中伪装成各种角色，还能不被他人看穿是不是相当过瘾呢？

今天小i要介绍一位神奇的黑客，他不但兼职律师，还自己做出了一套名为大漩涡的安全攻防桌游，一起听他讲一讲他的大漩涡桌游玩法吧~

课程推荐

DEF CON 24·安全攻防桌游大漩涡：你玩得转吗？

![](../Images/1c66c991084a11e81afb92ec8f4dbb25.png)![](../Images/bd980006d5476f6366c3780bb50a13e1.png)![](../Images/19be92ff5317f39e5a90e17c9d053e73.png)

本节课程选自2016年在美国拉斯维加斯举办的DEF CON大会。作为世界上最知名的黑客大会，DEF CON每年举办一次，参会者除了来自世界各地的黑客，还有全球许多大公司的代表以及美国国防部、联邦调查局、国家安全局等政府机构的官员。

![](../Images/4fca91b6b6fbf29d2525c381ef5c0723.png)

本节课程的主讲人Shawn神奇地兼顾了律师与黑客两个身份，他将通过一个网络攻击的生命周期游戏给大家带来一场意想不到的旅行，这个过程中涉及到了洛克希德·马丁网络狙杀链原理，该原理揭示了攻击者和防御者在不同的阶段采取不同的攻击手段和防御方法，Shawn由此展开研究并向大家分享依托于研究成果而开发的安全攻防桌游：大漩涡。

![](../Images/5e14d64652d4d83d04e37593e69820e8.png)

Shawn向大家展示了他利用网络攻防中攻击者和防御者在不同阶段的应对方法原理制作出来的桌游，告诉大家防御者可以根据这套桌游来了解到攻击生命周期的概念，从而更好地做好防御部署。

![](../Images/bd980006d5476f6366c3780bb50a13e1.png)

你是不是也跟小i一样为这位Shawn先生自己制作攻防桌游的脑洞大开深深折服呢？桌游玩爽了，网络攻击也不怕啦。一起来看教程跟Shawn先生学习大漩涡安全攻防桌游的的玩法吧~
