# 欢迎途牛、海康威视、萤石、美丽联合SRC入驻i春秋部落大家庭！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNTkyODI0OA==&mid=2247490731&idx=2&sn=bf584b16c8246b174bc3e83307afb8ef&chksm=faff507ccd88d96a4767a9f097ef098ca070aeccfb231eecc72b597ba22aa39de460894ce574&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzNTkyODI0OA==&mid=2247490731&idx=2&sn=bf584b16c8246b174bc3e83307afb8ef&chksm=faff507ccd88d96a4767a9f097ef098ca070aeccfb231eecc72b597ba22aa39de460894ce574&scene=27#wechat_redirect)

![](../Images/de9563025416a96dde3ce2f09bae9b22.png)![](../Images/5de3648a9fabd89b35d1d938ddc48821.png)

近年来各大公司的SRC（Security Response Center，安全应急响应中心）如雨后春笋般纷纷建立起来，代表了企业和厂商们对网络安全的重视和全民安全意识的提高。

![](../Images/71fb44e2f28ea239ec538dd704219143.png)

白帽子们也由此有了提交漏洞的正规渠道，现在白帽可以在i春秋学习，然后到各大SRC挖洞并提交，SRC给予白帽相应的奖励和礼品，形成了良好的合作关系。于企业、厂商和白帽们来说都是互利共赢的局面，一片其乐融融~  

![](../Images/2fbf94416c08b0822a67fd6d94020c19.png)

**i春秋SRC部落**自成立以来几乎汇集了全网最全的SRC，邀请各大SRC入驻，由各大官方SRC自主运营，发布最新活动消息，在这里查找SRC再也不会迷路啦~  

**值此元旦佳节来临之际**

**我们又迎来了四家SRC入驻！**

![](../Images/5de3648a9fabd89b35d1d938ddc48821.png)![](../Images/f47d68fbe66a10bbc8d10c3a98acbaa4.png)

**途牛SRC**

**成立时间**：2016年4月18日  

**入驻时间**：2016年12月21日

途牛安全应急响应中心，接收针对途牛在信息安全方面如隐患、漏洞等反馈与建议，并与广大安全爱好者们一起分享、交流、进步。

![](../Images/5de3648a9fabd89b35d1d938ddc48821.png)![](../Images/3c95b5110c8cc63e17b44f94854f00c0.png)

**海康威视SRC**

**成立时间**：2001年

**入驻时间**：2016年12月27日

海康威视安全应急响应中心（Hikvision Security Response Center，以下简称HSRC）是一个负责接受、处理和公开披露海康威视产品和解决方案相关的安全漏洞的平台。海康威视非常重视自身安全，也一直致力于保障用户安全，我们也希望通过此平台加强与业界的合作和交流。

![](../Images/5de3648a9fabd89b35d1d938ddc48821.png)

  

![](../Images/21d6965963646ef52e5108516ce02709.png)

  

**萤石SRC**

**成立时间**：2016年7月1日

**入驻时间**：2016年12月28日

萤石安全响应中心（Ys7 Security Response Center）是一个负责接受、处理和公开披露萤石产品和解决方案相关的安全漏洞的平台。

![](../Images/5de3648a9fabd89b35d1d938ddc48821.png)![](../Images/f4109728d47c5c078d0dc686e5136659.png)

**美丽联合集团SRC**

**成立时间**：2016年12月21日

**入驻时间**：2016年12月29日

美丽联合集团一直致力于提升自身产品及业务的安全性，美丽联合集团安全应急响应中心（MLSRC）非常欢迎广大白帽子给我们提供美联集团旗下的产品及业务安全漏洞，  
同时我们也希望通过平台加强与业内白帽子及团队的合作，为营造更安全的互联网生态环境出一份力。

**在此欢迎几位小伙伴加入我们SRC部落大家庭**

**希望大家以后共同守护互联网安全！
