# 警惕！苹果系统新型垃圾骚扰：“拒绝不了”的骚扰邀请！

日常生活中我们大多数人都收到过垃圾邮件和垃圾短信，这类骚扰我们通过一些屏蔽接收的方式能够得到一定程度的缓解。可是最近，一种利用苹果系统自带的日历和相册共享功能，进行的新型垃圾骚扰，在短时间内大量出现。用户在拒绝之后，反而骚扰越来越多，这是怎么回事？

**骚扰或导致其他恶性事件发生**

  

经过央视记者调查，发现众多网友都抱怨了同样的遭遇，日历和相册经常会收到一些莫名邀请，打开只有接受和拒绝两个功能。拒绝和删除都无法停止这种垃圾邮件的持续骚扰，一旦轻信，就可能导致苹果账号密码泄露，资金被骗等恶性事件。

![](../Images/b31945e5314f0b2d90806453db842f77.png)

**北京永信至诚科技股份有限公司CTO张凯**表示，此次的骚扰主要是利用了苹果系统云服务的共享推送功能实现的。也就是说，对方知道了你的苹果账号，就可以给你发送垃圾信息，原理跟骚扰电话相同，知道号码就能打，我们只能被动接收。并且就算你点击拒收，对方也会接收到回执，并且由此知道你的邮箱的账户或者ID其实是活跃的，然后就可以对你进行一个有针对性的攻击。

  

在国务院联席办钱盾反诈平台收到的苹果用户反馈中发现，这类骚扰经常让用户收到无关提醒，近一个月内就增长了88%。从内容上看，赌博、色情、代开发票的内容占比超过90%，其中赌博类内容达到63%，严重影响用户的日常生活。

**骚扰如何破解？**

  

那么，这种骚扰能进行屏蔽吗？

![](../Images/f5e50ff26fa718947e12c634a06213f4.png)

**北京永信至诚科技股份有限公司教研总监孙义**给出了解决办法：点击iCloud这里边的共享的设置，这里边包括两部分，第一个是照片，一个是日历。我们把照片，以及日历功能用这样的关闭共享功能进行一次性全部解决。苹果电脑上登陆日历设置里边有个高级选项，在高级选项里边有个邀请设置，原先默认情况下是应用程序内置通知，将它发送到电子邮箱点存储，为邮箱本身有一个屏蔽广告的那种功能。所以说这样的话可以避免到我们常规工作受到影响，也可以阻止到垃圾信息。  

![](../Images/7c4a5b01ea3e850dff8b65a7a9dde775.png)

其实也正是日历、相册的共享功能没有黑名单和过滤机制，所以任何内容都可以创建并发送给任意用户。这也就是说，应对垃圾骚扰，**除了用户要继续提升自己的安全意识，从源头上来说，厂商和开发者在设计产品时也应该有更多安全考虑。**

![](../Images/b59ea1e1e3a262abb7636eda85ae67b2.png)

开发者需要提高安全意识和安全开发的应用能力，而开发者的产品也需要面对公众用户和白帽子们的检验。当然，各大厂商也开始建立自己的SRC（Security Response Center，安全应急响应中心）来保障自家产品的安全性能。

![](../Images/6088b53148d704a82629ecd82a7521e4.png)![](../Images/cc86d6a99d67a644fe4bbeb2630c291b.png)

  

现在国内的SRC如雨后春笋般的建立起来，各大SRC平台也纷纷入驻i春秋部落，白帽子们在i春秋学习网络安全知识，学成之后到各大SRC提交漏洞并且获得奖励，各大SRC也在i春秋SRC部落里相互切磋交流，使自己的产品安全性能得到更大提升，形成一个网络空间安全的良性循环。

  

这些都代表了公众、厂商和开发者对产品安全以及网络安全的重视，相信在大家的共同努力下，我们能用更有力的手段打击信息泄露和网络骚扰行为，共同构造一个洁净安全的网络空间。
