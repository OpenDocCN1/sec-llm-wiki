在kali中安装w3af

在kali中安装w3af是非常简单的：

apt-get update
apt-get install -y w3af
但是这样安装的不一定是最新版本的，要想安装最新版本，可以使用下诉步骤：
cd ~
apt-get update
apt-get install -y python-pip w3af
pip install --upgrade pip
git clone [url]https://github.com/andresriancho/w3af.git[/url]
cd w3af
./w3af_console
. /tmp/w3af_dependency_install.sh
这样最新版本w3af将被安装到~/w3af/w3af_console目录下。

注意：这时候需要到最新版目录下

运行./w3af_console 更新到最新版本。

1、手动更新
手动更新w3af很简单
首先cd到w3af目录下，运行下列命令。

git pull


2、自动更新
w3af有自动更新的功能，这样我们不用再去管更新的事了，我们还可以设置更新的频率。自动更新功能默认启用的，我们可以在~/.w3af/startup.conf文件中进行设置。

Frequency：

更新频率，D是每日，W是每周，M是每月。

auto-update：

true启用自动更新，false关闭自动更新。



w3af基础介绍

在使用w3af之前，我们需要先了解一下w3af是如何工作的，认识一下它的基本框架结构，这样在之后我们识别和利用漏洞的时候会更加轻松。


主要插件：
w3af主要有三种主要类型的插件。
Crawl：抓取插件，主要负责寻找url，其实就是网络爬虫。
Audit：审计插件，主要负责发现抓取插件爬取的url中是否存在安全漏洞。
Attack：攻击插件，主要是去利用审计插件发现的漏洞。

其他插件：
Infrastructure：确定目标的基本信息，如安装的waf、操作系统等。
Grep：分析其他插件发送的HTTP请求和响应，并确定漏洞。
Output：输出插件，可以将数据保存到文本文件、XML文件或HTML文件。
Mangle：用于修改网络请求和响应。
Bruteforce：暴力破解
Evasion：用于逃避简单的入侵检测。

常见的使用案例

一、扫描指定目录

在渗透一个网站时我们常常有意的只扫描一个指定的目录：
1、 设置目标URL，例如http://domain/test/
2、 启用audit插件
3、启用crawl.web_spider插件
这样抓取插件就只会去抓取该目录下的URL，审计插件也只扫描该目录中的网址

二、保存抓取到的URL
爬取URL是一个很耗时的过程，我们可以将其保存起来给其他程序使用，如sqlmap。我们可以使用output.export_requests插件。它可以将url写入到用户配置文件中。加载保存的数据使用import_results插件。

三、复杂的Web应用程序
现在有些web应用程序中使用了浏览器端的技术，如JavaScript、flash、Java applets。这些浏览器可以识别，但是w3af目前还不能。
但是w3af中插件spider_man可以解决这个问题。
进入插件配置，启用spider_man插件。然后扫描目标
w3af>>> plugins
w3af/plugins>>> crawl spider_man
w3af/plugins>>> audit sqli
w3af/plugins>>> back
w3af>>> target
w3af/target>>> set target http://localhost/
w3af/target>>> back
w3af>>> start
spider_man proxy is running on 127.0.0.1:44444 .
Please configure your browser to use these proxy settings and navigate the target site.
To exit spider_man plugin please navigate to [url]http://127.7.7.7/spider_man?terminate[/url] 

这样，我们将自己的浏览器代理设置为127.0.0.1:44444然后去访问要审计的页面。



Web应用漏洞利用

w3af还可以在审计插件发现漏洞后进行利用:

w3af>>> plugins
w3af/plugins>>> audit os_commanding
w3af/plugins>>> back
w3af>>> target
w3af/config:target>>> set target http://localhost/w3af/os_commanding/v.php?command=f0as9
w3af/config:target>>> back
