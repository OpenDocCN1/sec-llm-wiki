21世纪最绝望的不是背叛，
                而是手机没电

—出门在外没有充电宝的你
手机在日常的生活中扮演着越来越重要的角色，出门在外一旦手机没电就仿佛回到了“交通基本靠走、通信基本靠吼”的远古时代，这时路边的手机充电站就成了你的救命稻草、沙漠中的绿洲。
BUT···
今天的i春秋公开课就来给你提个醒，充电也能导致手机被黑，远离“邪恶”充电站，别让绿洲变成夺命的泥淖。

（星期四）

No.2 华为&英特尔强强联手：LTE/3G调制解调器的秘密
（星期五）

推荐指数：★★★
关键词：LTE调制解调器、黑客攻击
本节课程选自2015年在美国拉斯维加斯举办的DEF CON大会。作为世界上最知名的黑客大会，DEF CON每年举办一次，参会者除了来自世界各地黑客，还有全球许多大公司的代表以及美国国防部、联邦调查局、国家安全局等政府机构的官员。
英特尔的信息安全研究员在会上表示，商业笔记本和平板电脑中内置的LTE/3G调制解调器有可能会成为黑客们新一轮的攻击目标。两位信息安全研究员展示了电脑设备上安装的恶意软件能够轻松重写华为一款LTE调制解调器模组的固件，被感染的调制解调器模组能进一步侵蚀主操作系统，这时即便重装系统也无济于事。该漏洞存在于所有独立于计算机主系统的模组，因为主系统内的安全监控软件无法顾及到该类模组。

No.1 SQL注入基础实战  
（星期四）
Asp手工注入
Asp工具注入
Asp中转注入

推荐指数：★★★★
关键词：ASP、SQL注入
SQL注入渗透测试指的是：当我们的Web程序在向后台数据库传递SQL语句进行数据库操作时，在未对用户输入的参数进行严格的过滤处理情况下，攻击者通过构造特殊的SQL语句，直接传输到数据库，使其执行此语句，从而达到获取或修改数据库中的数据的目的。
注入漏洞是企业运营中遇到的最具破坏性的漏洞之一，它也是目前被利用得最多的漏洞。
本节课程使用了Asp和Jsp两种脚本语言来演示，分别介绍了如何使用手工、中转、工具注入。旨在使大家理解SQL注入渗透测试的原理、利用方法及其修复机制。

No.3 11月前沿漏洞复现与分析（星期五）
MySQL / MariaDB / PerconaDB - 提权/条件竞争漏洞

推荐指数：★★★★
关键词：MySQL数据库
Dawid Golunski在 MySQl, MariaDB 和 PerconaDB 数据库中发现条件竞争漏洞，该漏洞允许本地用户使用低权限(CREATE/INSERT/SELECT权限)账号提升权限到数据库系统用户（通常是'mysql'）执行任意代码。基于MYSQL的数据库允许用户新建数据库，并且指定存储目录,攻击者成功利用此漏洞，就能完全访问数据库。
漏洞影响：
MariaDB
< 5.5.52
< 10.1.18
< 10.0.28 
MySQL
<= 5.5.51
<= 5.6.32
<= 5.7.14
本次课程主要对MySQL数据库涉及的漏洞进行复现，对其原理进行讲解并给出修复方案。
