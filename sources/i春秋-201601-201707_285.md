# 【国内首发】让你和脏牛近距离接触！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNTkyODI0OA==&mid=2247490776&idx=1&sn=67f2657106b526b2cfc128fbf0bf3623&chksm=faff500fcd88d9193a9b6d9e4eeb2f43fb26c56d50983dcbd89b6af3e6e387da1bd90cb1287f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzNTkyODI0OA==&mid=2247490776&idx=1&sn=67f2657106b526b2cfc128fbf0bf3623&chksm=faff500fcd88d9193a9b6d9e4eeb2f43fb26c56d50983dcbd89b6af3e6e387da1bd90cb1287f&scene=27#wechat_redirect)

**脏牛(Dirty COW，编号：CVE-2016-5195)**是本月18日被曝出的存在于Linux内核中的一款0day漏洞。因为此漏洞是在Linux内核的内存子系统在处理写时拷贝(Copy-on-Write)时发生的，而又给Linux内核的使用带来烦恼，所以将其命名为“Dirty COW”。![](../Images/f908356139ba53b27d5217ce8b46b981.png)这个漏洞10月18号由**Phil Oester**提交，被Linux的创始人**Linus**亲自修复，并且在当天将Linux内核补丁提交至:https://git.kernel.org/cgit/linux/kernel/git/torvalds/linux.git/10月20号，漏洞的发现者**Phil Oester**将漏洞的部分细节提交到github上，Phil Oester表示，Dirty COW漏洞是一个古老的漏洞，发现于2007年，并一直存在于后续的Linux版本当中。漏洞编号于2016年5月申请，此次获得的版本是用gcc 4.8编译的。利用这一漏洞实施针对服务器的攻击非常便利，而且成功率很高，未来肯定会被大范围的使用。因此提醒每一位用户注意修复这一漏洞，并做好防范措施。![](../Images/393d6e422d5cb06e14a714a0d378c364.png)与此同时，开源系统服务商RedHat 10月25日也针对Dirty COW漏洞发布了一份声明，更加详细的描述道，该漏洞能够让低权限用户利用内存读写机制的缺陷提升自己的系统权限，从而获得写入特权。换而言之，**无权限用户也可以利用该漏洞访问根服务器，这对于互联网来说是一件相当可怕的事。**  
脏牛漏洞出来的当天就几乎在整个朋友圈刷屏，毕竟是几乎通杀全版本linux的本地提权的神洞，这种漏洞还是很少见的。![](../Images/749e7cb5503e3c16723bb20c2f46a3e4.png)![](../Images/20cdf0d479b41befd815e630dd7c8c2c.png)**于是大家关心的问题出现了…**![](../Images/30b0dd2a9afddc76e7724c9022877d1d.png)![](../Images/0cb2158ac5c94cd5b14b03ba52f602b1.png)**我的设备感染脏牛漏洞了吗？**![](../Images/e80617be1f678ed3316384e80967318b.png)如果你的设备Linux内核版本高于2.6.22，那么很可能存在该漏洞。所有安卓系统的手机，不管是三星/Google/ Cyanogen/MIUI或者其他手机厂商的产品，都有安全隐患（三星又在里面…）。而且，这些厂商至今为止都没有发布安全更新……  
做最坏的打算，如果想利用这一漏洞，那攻击者的方式会是什么呢？在受影响的设备上运行代码即可，对，就是那么简单。安卓系统是借由USB或者安装APP，实现Android Debug Bridge (ADB)完成的。![](../Images/0cb2158ac5c94cd5b14b03ba52f602b1.png)**如何保护自己？**![](../Images/e80617be1f678ed3316384e80967318b.png)截止到现在，尚未有任何针对受影响设备的更新。脏牛是本地漏洞，在安卓上运行本机代码无需特殊权限。所以首要建议就是不要安装任何未知来源的软件。还有，用USB连接移动设备和电脑时要千万当心，因为一旦电脑恶意软件能够使用ADB，那么你的手机就有可能别人拿到Root权限！ 最根本的方法就是了解这个漏洞，i春秋实验组针对本次重大漏洞紧急发布了**国内首个DirtyCOW（脏牛）在线实验环境。**
