先来开盒
最上面的是开发板，有我微信的小伙伴应该已经看过我写的上手初体验，板子做工不错，作为硬件狗，最喜欢买各种板子，有国产山寨的，有正宗进口货，也有良心国产，还有实验室2wRMB订做的开发板套件，Ruff的做工确实值这个价（个人想法，不服别打我）

然后下面是自带了蛮多的传感器，还有杜邦线，杜邦线有点硬，但不影响使用，试着拔插了一下，接口非常牢固，但是比较硬，这个就有待后续版本改进了

为了简单易懂呢，我就参考Ruff官网的入门教程来写了（其实是急着去看海豹突击队~我电影看到一半结果被约稿了(╯‵□′)╯︵）
第一步呢，自然是先配置环境，到这里下载SDK
https://ruff.io/zh-cn/docs/download.html
如下配置环境变量，下面命令里面的路径换成你的SDK的路径
Linux或者OS X
export RUFF_HOME= /path/to/ruff-sdk
export PATH="$PATH:$RUFF_HOME/bin"
如果你是Windows
set RUFF_HOME=X:\path\to\ruff-sdk
setx PATH "%PATH%;%RUFF_HOME%\bin"
然后看看效果
rap version
You see see！！！
是不是interesting，接下来就是创建一个小小的Project了
我们创建项目，最好是不要在SDK文件夹里面创建，我这里选择在桌面创建
cd 桌面
mkdir light-button
cd light-button
rap init
? project name: light-button
? version: 0.1.0
? description: just a test
? author: toT0C
然后就会进行初始化了

酷炫还是很酷炫的是吧
到这里项目的初始化已经完成了，咱们来连接一下板子，有必要说明的是，板子是靠WiFi连接的，方便吧（加个保护壳再加个电源放女生寝室仿佛可以干很多坏事了呢~~~）
接上线
等各种灯乱七八糟瞎闪一顿后，可以看到就剩一个小红灯一闪一闪的，这个意思是等待配置WiFi，注意图中右上角那个小红灯

其实右上角一共有三个灯，分别是G(绿)B(蓝)R(红)，开发板的这个位置需要多关注，因为板子很多状态都是在这里通过指示灯的不同显示方式来表示
我们来广播一下WiFi
rap wifi
因为Ubuntu网络的原因所以我切到win10，但是步骤一样的，如下有多个网络，使用箭头选择当前WiFi

回车后输入wifi名字和密码，SSID是WiFi的名字，password是密码

同时板子上的蓝灯就会一闪一闪的，代表正在连接，闪了几下就会变成蓝灯常亮，蓝灯常亮代表已经接上WiFi，如果还是红色一闪一闪的恭喜你，你的板子Hash不好，没有接上WiFi，
Look，我这里是蓝色常亮，代表着我已经配置好了

既然已经配置好了网络，那就来搜一下
rap scan
过几秒就会出现一个item，回车就行，紧接着会让设置一个密码，用于使用开发板的身份验证，以后在使用这个板子的时候就需要输入密码，然后是设备名称，这个看个人的喜欢了，完整的过程如下

到这里已经完成了项目初始化，连接硬件，网络设置的工作，接下来就是写代码啦~~~
Ruff用的是JS，Web狗是不是很激动！！！！！！
找到src文件夹下的index.js，打开
可以看到这是一个简单的测试代码，部署的时候亮红灯，就刚刚说重点注意的那三个灯，退出的时候灭灯

既然人家写了代码那就来部署一下
rap deploy -s

看，红灯亮了，至于为什么蓝灯亮了（它本来就亮的）

如果不想玩了，就
rap stop
到这里是不是觉得这玩意很容易上手~~~
想不想加个按钮来玩一玩，就是按一下按钮可以控制灯亮的那种？
那我们就来玩一玩
先来看看大按钮，果然有点大_(:3 」∠)_
可以看到有三个引脚，一个接电，一个接地，还有一个是输出脉冲的

然后添加一下button，这个button是设备ID，就像开发一样，每一个控件都有着自己的ID，需要输入button型号和选择可用驱动
rap device add button

这样我们就添加好了硬件，然后来连线吧
rap layout --visual
这是使用可视化的方法，超好用，下面的图片自己弹出来的

然后就照着接线吧，最好先拔掉开发板的电源线（严肃脸）

接好线后就可以重新接上电源线，接上电源线后等一会让板子自己载入配置，等一会Ruff板自己会配置好的，等蓝灯亮起来就行啦
现在来写一下代码，当button按下去，红灯亮，释放的时候红灯灭
但是有一个问题，传感器的相关函数怎么调用？
这个自然是去Ruff社区了
https://rap.ruff.io/
比如现在需要使用大按钮，然而不知道怎么使用，搜CK002，也就是包装上的型号
然后可以看到需要的都已经显示出来了
看的差不多就可以开始根据文档写代码

写完后来部署
rap deploy -s 

来看看效果
按下按钮，红灯亮了

释放按钮，红灯灭

最后
rap stop
可能有小伙伴看到这已经发现了没有关于固件的内容，不要着急哇！
在这下载固件，版本根据你的系统选择就行
https://ruff.io/zh-cn/docs/download.html
根据以下格式更新，IP是你板子的IP，scan就可以看到板子的IP，后面跟着的是固件的路径
rap system upgrade --hostname 192.168.1.30 ~/Downloads/ruffos-0.8.0.bin
