鉴于这板子也不便宜，300软妹币，我这种每个月都吃土的穷屌丝都不知道怎么省出来的，所以我先写一篇上手体验，要是您也有兴趣玩的话，那就买啊（此处没有收广告费）  
  
   先来开盒最上面的是开发板，有我微信的小伙伴应该已经看过我写的上手初体验，板子做工不错，作为硬件狗，最喜欢买各种板子，有国产山寨的，有正宗进口货，也有良心国产，还有实验室2wRMB订做的开发板套件，Ruff的做工确实值这个价（个人想法，不服别打我）![](../Images/11df05bea237a5a333aec027ec056c63.png)  
然后下面是自带了蛮多的传感器，还有杜邦线，杜邦线有点硬，但不影响使用，试着拔插了一下，接口非常牢固，但是比较硬，这个就有待后续版本改进了![](../Images/bf89775e9310b70952391d09456af854.png)  
为了简单易懂呢，我就参考Ruff官网的入门教程来写了（其实是急着去看海豹突击队~我电影看到一半结果被约稿了(╯‵□′)╯︵）第一步呢，自然是先配置环境，到这里下载SDK  
https://ruff.io/zh-cn/docs/download.html如下配置环境变量，下面命令里面的路径换成你的SDK的路径Linux或者OS Xexport RUFF\_HOME= /path/to/ruff-sdkexport PATH="$PATH:$RUFF\_HOME/bin"如果你是Windowsset RUFF\_HOME=X:\\path\\to\\ruff-sdksetx PATH "%PATH%;%RUFF\_HOME%\\bin"然后看看效果rap version![](../Images/ca1457de82da4ef5b790ab8e2f14451f.png)![](../Images/618f3233816f1a774b67ee3a990d7500.png)You see see！！！  
是不是interesting，接下来就是创建一个小小的Project了我们创建项目，最好是不要在SDK文件夹里面创建，我这里选择在桌面创建cd 桌面mkdir light-buttoncd light-buttonrap init? project name: light-button? version: 0.1.0? description: just a test? author: toT0C然后就会进行初始化了![](../Images/8784d22ec5816ef377d32ab9d8ba8573.png)  
酷炫还是很酷炫的是吧到这里项目的初始化已经完成了，咱们来连接一下板子，有必要说明的是，板子是靠WiFi连接的，方便吧（加个保护壳再加个电源放女生寝室仿佛可以干很多坏事了呢~~~）![](../Images/3f8497ef9eb6be8a7ef1324da941a123.png)接上线  
等各种灯乱七八糟瞎闪一顿后，可以看到就剩一个小红灯一闪一闪的，这个意思是等待配置WiFi，注意图中右上角那个小红灯![](../Images/0f556fa2df8bbdd2021476fae2ac88ba.png)  
其实右上角一共有三个灯，分别是G(绿)B(蓝)R(红)，开发板的这个位置需要多关注，因为板子很多状态都是在这里通过指示灯的不同显示方式来表示我们来广播一下WiFirap wifi因为Ubuntu网络的原因所以我切到win10，但是步骤一样的，如下有多个网络，使用箭头选择当前WiFi![](../Images/3a9dfe01962d4d039e28dda21b559bcb.png)  
回车后输入wifi名字和密码，SSID是WiFi的名字，password是密码![](../Images/fd24d08c8ad5396a342a2bf6eefbc7fb.png)  
同时板子上的蓝灯就会一闪一闪的，代表正在连接，闪了几下就会变成蓝灯常亮，蓝灯常亮代表已经接上WiFi，如果还是红色一闪一闪的恭喜你，你的板子Hash不好，没有接上WiFi，Look，我这里是蓝色常亮，代表着我已经配置好了![](../Images/fc5afc82c4b6d47fed167595bfd02e19.png)  
既然已经配置好了网络，那就来搜一下rap scan过几秒就会出现一个item，回车就行，紧接着会让设置一个密码，用于使用开发板的身份验证，以后在使用这个板子的时候就需要输入密码，然后是设备名称，这个看个人的喜欢了，完整的过程如下![](../Images/5fd7edfc4197c106fb8a4e9478800183.png)  
到这里已经完成了项目初始化，连接硬件，网络设置的工作，接下来就是写代码啦~~~Ruff用的是JS，Web狗是不是很激动！！！！！！找到src文件夹下的index.js，打开可以看到这是一个简单的测试代码，部署的时候亮红灯，就刚刚说重点注意的那三个灯，退出的时候灭灯![](../Images/853610483e88a059f1d58b5e98d296d7.png)  
既然人家写了代码那就来部署一下rap deploy -s![](../Images/8c5db135be6fe36935b09c23a9e47ee9.png)  
看，红灯亮了，至于为什么蓝灯亮了（它本来就亮的）![](../Images/c6141b6dc610a1defd3938e432ce9fb1.png)  
如果不想玩了，就rap stop到这里是不是觉得这玩意很容易上手~~~想不想加个按钮来玩一玩，就是按一下按钮可以控制灯亮的那种？那我们就来玩一玩先来看看大按钮，果然有点大\_(:3 」∠)\_可以看到有三个引脚，一个接电，一个接地，还有一个是输出脉冲的![](../Images/639fa8b91f4f3aed551c8d584e80a34e.png)  
然后添加一下button，这个button是设备ID，就像开发一样，每一个控件都有着自己的ID，需要输入button型号和选择可用驱动rap device add button![](../Images/c66153c123ad786828a59abe2e4494a7.png)  
这样我们就添加好了硬件，然后来连线吧rap layout --visual这是使用可视化的方法，超好用，下面的图片自己弹出来的![](../Images/2ddeab674cf7c5986303bec816087f6d.png)  
然后就照着接线吧，最好先拔掉开发板的电源线（严肃脸）![](../Images/af472a71215666a06cd5715f854232d9.png)  
接好线后就可以重新接上电源线，接上电源线后等一会让板子自己载入配置，等一会Ruff板自己会配置好的，等蓝灯亮起来就行啦现在来写一下代码，当button按下去，红灯亮，释放的时候红灯灭但是有一个问题，传感器的相关函数怎么调用？这个自然是去Ruff社区了https://rap.ruff.io/比如现在需要使用大按钮，然而不知道怎么使用，搜CK002，也就是包装上的型号![](../Images/0437c2328e7897d197b5c0bf709cde75.png)然后可以看到需要的都已经显示出来了![](../Images/515187862ba9ff0c741fc641432be7f8.png)看的差不多就可以开始根据文档写代码![](../Images/548e09f3d311472b9155a2d47d4bdbe4.png)  
写完后来部署rap deploy -s ![](../Images/d45481c4912eeb1da4e804b9b4c05ae6.png)  
来看看效果按下按钮，红灯亮了![](../Images/fa3c67788e2accf4baf64c1320698aeb.png)  
释放按钮，红灯灭![](../Images/c6d30dbc906efa76329e4081ef02a77c.png)  
最后rap stop可能有小伙伴看到这已经发现了没有关于固件的内容，不要着急哇！在这下载固件，版本根据你的系统选择就行https://ruff.io/zh-cn/docs/download.html根据以下格式更新，IP是你板子的IP，scan就可以看到板子的IP，后面跟着的是固件的路径rap system upgrade --hostname 192.168.1.30 ~/Downloads/ruffos-0.8.0.bin![](../Images/c66b8a47e6ab94713edcad871027a881.png)好啦，整个上手就到这里了，从整个包装，开发板做工和使用体验来看，都是很令人满意的，Ruff板是一个非常好用的板子，如果你看完后觉得还不错或者说很想玩一玩，那么赶快入手一个一起玩吧o(\*≧▽≦)ツ（我没收广告费！！！！！！）
