 一.《Kali Linux/Back Track系统漏洞风险及安全防护 》
【课程介绍】
Kali 一为Linux操作系统，所以又称为Kali Linux ，其前身是 Back Track（基于Ubuntu）；因此相比较而言，Kali比较复杂，backtrack比较简单；backtrack现在没什么用处，只能做些渗透和信息整理，是一个基于 debian 的 Linux 发行版。而Kali Linux预装了许多渗透测试软件包括：Nmap (端口扫描器)；Wire shark (数据包分析器)；John the Ripper (密码破解器)；Air crack-ng (一套用于对无线局域网进行渗透测试的软件)；用户可通过硬盘、live CD或live USB运行Kali Linux。Metasploit的Metasploit Framework支持Kali Linux，Metasploit一套针对远程主机进行开发和执行Exploit代码的工具。因此大家可以先从Linux学起，然后学习backtrack，最后研究kali，难度是逐渐增加的。
上线节：1. 如何实施MAC地址欺骗
               2. 怎么把别人踢出你的局域网
               3. 黑客是如何用hydra进行暴力破解
               4. 关于Nmap工具的基本指导
               5. 怎么安装Kali Linux 2.0

 大菠萝的《渗透技术分析》
 【课程内容】
《渗透技术分析》系列课程由启明星辰积极防御实验室（ADLab）资深元老级安全研究员主讲。从专业角度，结合网络安全中的实际案例，再现了一系列渗透技术的精彩过程。
本课程共有7章，由浅入深介绍和分析了目前网络流行的渗透攻击方法和手段，并结合讲师多年的网络安全实践经验给出了相对应的安全防范措施，并对一些经典案例给出了经验总结和防御技巧。内容主要包括敏感信息泄漏、暴力破解、拒绝服务攻击、本地提权、中间人劫持、溢出攻击、开源软件历史漏洞案例分析。
通过学习本课程，可以让您快速掌握当前渗透的主流技术和防御手段。
 
更新节: DOTNET逆向入门

《量子密码术：公钥密码术的救赎》
【课程内容】
本课程按照密码术发展的客观历程，讲述了公钥密码术和量子密码术两部分内容。
在课程的前半部分，我们充分结合生活经验，巧妙的利用一些假想的生活场景对公钥密码术基于的原理和其中蕴含的丰富思想进行了透彻的阐释；通过最常用的电子邮件加密协议PGP，系统讲解了密码术在现实生活中的综合运用，引出了密码术中数字签名、哈希函数等重要概念；系统讨论了对重要密码算法（如RSA）和重要安全协议（如PGP）的攻击和防御方法。
量子计算机和量子密码术的提出是密码学界的一场深刻的变革，作为这门课程的重要内容，我们在课程的后半部分对量子计算机这一前沿概念和绝对安全的重要加密技术——量子密码术进行了深入讲解，用生活中的简单例子去理解复杂的量子物理原理，让大家能够更好地看到看似“高深”的事物如何“简单”的运作。
