0x00 简介
1.非关系型数据库
a.行的概念更换成文档 一条记录可以表示非常复杂的层级关系.
b.没有模式 文档的键事先不会固定也不会改变.
2.易扩展
3.不牺牲速度
基本概念:
1.文档是数据的基本单元.
2.集合可以被看作没有模式的表.
3.单个MongoDB可以容纳多个独立的数据库 每个都有自己的集合和权限.
4.每一个文档都有一个特殊的键“_id” 它在文档所处集合中唯一.
5.区分类型和大小写.
6.运行mongodb：
(在mongodb目录的bin目录中运行./mongod启动mongodb)
7.启动MongoDB shell：
(新建控制台窗口执行./mongo)
8.shell可运行完整的javascript程序

2.使用修改器
a.通常文档只有一部分需要更新 利用原子的更新修改器可以使这种部分更新极为高效
b.$inc修改器用于增加已有键的值 或者在键不存在时创建一个键 用于需要数值变化的地方
3.假设一个打砖块游戏 小球撞到了砖块会给玩家加分 分数键原来不存在 使用$inc创建了这个键
 > db.game.insert({"game":"pinball","user":"joe"})

 WriteResult({ "nInserted" : 1 })

 > db.game.update({"game":"pinball","user":"joe"},

 ... {"$inc":{"score":50}})

 WriteResult({ "nMatched" : 1, "nUpserted" : 0, "nModified" : 1 })

 > db.game.find()

 { "\_id" : ObjectId("563b22e616e903ae2a924c52"), "game" : "pinball", "user" : "joe", "score" : 50 }

如果小球落入加分区 要加10000分

6.可以通过客户端api生成ObjectId减轻服务器压力
