# 从社工考试答案到发现惊天作弊团伙

**社会工程学（Social Engineering）简称社工，是一种通过人际交流的方式获得信息的非技术渗透手段。世界第一黑客凯文·米特尼克在《欺骗的艺术》中曾提到，人为因素才是安全的软肋，人们可能永远都想象不到，对于黑客们来说，通过一个用户名、一串数字、一串英文代码，加以筛选、整理，就能把你的所有个人情况信息、家庭状况、兴趣爱好、婚姻状况等个人信息全部掌握得一清二楚。**

**小爱在此提醒大家，技术是把双刃剑，把握好尺度才是关键～**  

  

故事发生在五月，至今已过去快两个月了。当时就想分享这个事情，但是迫于学业的紧张，还是搁置了这个想法。现在难得有空余时间，分享这次经验，希望其中一些思路对大家能有所启发。

  

其中的有些细节我也记不大清楚了，很多当时的截图资料已经没有保存，所以我会尽我所能的描写的详细一些，也望大家提出问题， 此事件更是引导我发现了一些不为人知的产业链条，从事互联网犯罪的考试作弊的团伙，揭露了大数据时代下新型作弊手段。也希望政府等部门关心一下，不过我虽然社工了试卷，但是没有进行交易或者有作弊的行为，这也对得起我的良心。我希望大家不要用社工去做坏事。下面开始正文，我会写的生动一点。

  

![](../Images/3a6ba997ab4ff50a9232aaef4236a1f6.png)

  

高中生涯普通的一天，云淡风轻。十点多钟，正在上第三节课，是一节化学课，眼中已有些疲惫。思绪飞向了窗外，想着今天正在进行的NBA的比赛，还在幻想着我最爱的马刺捧起冠军奖杯的场景。忽然一阵电话铃声将我的思绪拉回了化学老师身上。

  

平常一个电话倒也没什么特别，但是这个电话明显不一样。从我观察来看，化学老师从来没有上着课接电话的习惯。他大多数时候通常选择看一眼就挂掉电话。而这次，他先是望向了墙上的挂钟，然后眼睛向上看（这是明显的思考的标志），又望了一眼手机屏幕，然后离开教室，接起了电话。

  

我觉得这个电话应该是很重要的，但也只是有一个这样的想法。这时机（duo）灵（zui）的同桌突然告诉我，会不会是联考的事情？我突然的回想起来我们化学老师是年级主任，主管联考等事项。  

  

同桌成绩一般，路子野，悄咪咪告诉我他能搞到这次联考的答案，我好奇心一下被勾起来，这种级别的考试答案到底是怎么泄露的？

  

下意识的，我开始留意化学老师谈话的内容（化学老师就站在离门口不远处，可能是考虑到我们是菜B班的学生，也没什么好遮遮掩掩的，放心的接听，声音还挺大）。谈话的具体内容我已经记不清楚了，大概如下。  

  

![](../Images/c66ad6b601fdb1af6ceea7efe85eb4bc.png)

“你好，我XX中学的X老师。您是A中学的B老师吧？”

“对没错，没想到你们就好了？”

“好的好的。这样，你发到我的邮箱吧，我下课把我的邮箱用短信发给你。”

“好的好的，辛苦了。”

到此，一个骚年不安分的心被彻底点燃了。

  

他涉及到了邮箱这么关键的东西，我自然有了可查之处。

  

要想查答案泄露的源头，得先摸清他们出题的源头。我想到化学老师是年纪主任，又有独立办公室，他的电脑上应该有存他的邮箱等一些重要信息，所以拿下电脑权限就是重中之重（请大家不要模仿，风险极大）。

  

我开始了一系列的策划工作，购买了一台服务器，从网上下载了一款远程软件。测试好之后，将被控端，放在了准备好的U盘上面。下面就是等待时机。

  

我一下课就去化学老师办公室门前徘徊，几次之后便发现，下课时候办公室总会有人，不是化学老师，就是跑去问问题的学生，没有什么机会下手，这时候，便想到化学老师上课的时候办公室应该没人吧！

  

我开始慢慢等待这样一节特殊的化学课。

  

很快就到了这样一节特殊的化学课，课上，再化学老师讲最为重要的知识点的时候，我突然跑过去，谎称自己肚子疼，要给家里打电话，跟化学老师交谈一番后，我自己去了办公室打电话，化学老师还在班里上课。我迅速准备好事先的U盘插入电脑上，将电脑360等杀毒软件退出且设置开机不再启动，我小心翼翼的打开了远控端，再连接服务器后发现成功上线，由于怕待着时间长了引起怀疑，并没有打电话我就回班里了（并告诉化学老师说家长让先去学校医务室看看）  

  

![](../Images/5ca24d2d390bf566b5bc6a6a1015370e.png)

  

一台服务器，一台是老师电脑。

![](../Images/4422363d5f93d6aee39bee43664b9492.png)

  

等待放学回家后，通过安装键盘记录器，等待老师第二天上班登陆邮箱时候记录密码。很快拿到了老师邮箱的密码。于是我登陆了邮箱！通过查找邮件记录成功的发现了该答案。

  

![](../Images/c485dbc8a538f00e99cd1e48e85f41dd.png)

  

虽然拿到了试卷答案，但是没有进行交易或者有作弊的行为，这也对得起我的良心。本就是一场追寻答案泄露的溯源事件，没有任何目的性而言。本以为这样就结束了。

  

事后通过查看老师邮件的内容，发现这次考试只是几个学校的联合考试命题，全是几个学校的老师，保密性很差，考试的答案再头考试就传到了邮箱，回想了一下更为专业的考试都是月考或者省联考。在邮箱发现了每次大联考之前的考试安排，考试的答案都是再每个科目考完之后发到我们老师的邮箱的。

  

![](../Images/34a8248f101af2f68640f0922f11294e.png)![](../Images/eb482bb7309967b82cc70ebea15dcf25.png)

  

我发现考试命题机构是金太阳，答案都是金太阳教育机构的人发送的，答案发放形式是，考完每一科目，发送每一科目的答案，每次都特别准时。这给了我的社工带来了很大的难度。心里想着如果是这样的制度，他们岂不是只有拿到教育机构的权限，才有可能考试之前拿到答案？

  

为了验证是否可拿到大型考试的答案我继续开始了社工，我将木马端通过压缩包打包，给该教育机构的邮箱发送了一件木马邮件！

![](../Images/2d5f1438f2071224d526440ffc86b721.png)

很可惜苦苦等待了一个月都没有上线，想着要放弃这次社工了。但是喜欢百度的我，就百度了一下这个教育机构，并且尝试能不能获取到答案。

![](../Images/88db5022bd16ca45fd7ccb396f710e3d.png)![](../Images/70356ce8b8c9d914decb2cb0ee3e3770.png)

  

随后发现了这个贴吧，贴吧的广告巧了，声称考试之前可以购买到答案，正和我意，我尝试加了几个群，准备一探究竟。

![](../Images/70524ea5c944d783a6fb82ba155f62c9.png)

  

进群潜伏一段时间后发现，每次大型考试来临之前，他们都会开始售卖答案。以几十一科目的价格出售，另外这样的群通过群搜索还能搜到许多。

![](../Images/e9548744255499821f474ad9f9e80e46.png)

  

为了一探究竟，验证到底是不是真的，我们加上了一个售卖答案的人。

![](../Images/aec6fbff081e98279d05a0645b499e34.png)

  

因为学校23号24号有个省内大联考，我在化学老师的邮件中也找到联考科目安排

我就再三核实之后，购买了答案。

![](../Images/32111fdd027aa7a3fed22c7cfcc4af7d.png)![](../Images/9d590e5adcd962e3c41c9c96bca62939.png)

  

再距离考试前一天，他发来了考试的答案，很明显不是标准答案是手写的答案。再考试结束后，我对比了该答案，发现完全一样。此时我的心开始慌了。图片还打着水印，是他们的官方群，应该是怕同行盗答案，也能招揽学生才这么搞得，

![](../Images/9af0434441ce734a8e147022978fff79.png)![](../Images/06861ec29d96208c64ce3f0ec620fc6c.png)

  

再询问了试卷的来源之后，很快他给出了解释，说这个行业人也多。竞争压力也大。像这样的作弊组织有成千上百个，通过百度贴吧，QQ群，或者校园小广告宣传，每次联考，发现都有卖答案的。

  

此次事件我当了一个记者，发现该问题的严重性，原来源头出自学校的老师，他们为了自身利益，出卖联考试卷，在网上肆意泛滥，只后通过聊天得知，一次联考下来他们能受益上万元，利润之大。令我难以想象，都快比上HC了。

  

社工到此就算结束了，其实很多细节都忘了，隔得时间太长了。大家凑合着看吧！

  

小结一下：  

这对我来说真的是一次艰难但是激动人心的社工，过程在各位看客眼里可能非常的简单，甚至没有什么技术含量，但是其中的艰辛我自己才知道，有些细节问题对我来说是很难把握的。

  

这次社工其中的思路希望各位能够自己领悟，什么都要人点拨，始终是学不到什么东西的。社工这东西，最主要还是脑力游戏，只要你想法够大胆新奇巧妙而又不失现实性，那么你很可能就找到了一条社工的捷径，所以各位，不要总是使用其他人用烂了的思路，试着自己开拓新的方法，这样，就算你失败了，你也会有其他人没有的收获。

  

此次社工也引出了，一个网络作弊利益链条，利益之大，难以想象。也希望教育机构，政府部分，监管部门能治理该现象，想象一个孩子，在学校的考试成绩回回杰出的时候，家长有没有质疑过呢？也难以想象一个孩子为了成绩去购买答案。为的是什么呢？虚伪？还是........
