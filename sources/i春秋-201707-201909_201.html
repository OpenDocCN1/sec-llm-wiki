小爱的爸爸总是酷酷地、话很少

每天早出晚归，

为这个家奔波劳累。

在我眼里他是家电修理工、烹饪达人、万能侠客……

 

小时候

每一次爸爸把鱼头夹进自己的碗里，把鱼肚子那儿最细腻的肉留给我的时候，常常说：“我爱吃鱼头。”


有一次家里突然跳闸，被眼前一片漆黑吓哭了

爸爸总在第一时间修好，然后训斥我做人要坚强一点，不能动不动就哭鼻子。


我们的爸爸，就好像超级英雄一样

永远在危难抵达之前帮我们扛住了一切

所以无论发生什么事情

总是第一时间想到：爸爸会保护我


上了大学后

我和爸爸讲，“暑假在家没什么意思，找个实习锻炼锻炼。”他顿了顿，和我说：“这是好事，女孩子也得磨练磨练。”

但我知道，他为我担心，

但爸爸也会无条件的支持我。

如果有一天，我需要他为我做什么，他一定会全力以赴。


我们的爸爸一直没有太多话语

一直都是默默守候。

更像空气，好像是不存在的又必须依赖着。


▼▼▼

# 1 #

“他的爱，不是用语言，而是行动”

——Byzzh 糯米籽

我在外地上大学，来这边一个多月了，我爸说想我了，自己开三个小时的车偷偷过来了，就为了看看我，在一起不到一个多小时他回去了，来回六个多小时，还没敢和我妈说，因为我妈知道他腰疼肯定不让他来。


# 2 #

“父亲，是女生一生最舍不得的依靠”

——By  Vera

调皮的儿时夜晚偷跑出去，在没有手机的年代，爸爸打车绕过整个小镇寻找，“打开车窗，是我爸爸！”熟悉的脸让眼泪倾泻而下，成年后身在异乡，骑车打伞的归家夜，隔着雨声接通熟悉的关怀：“打个车吧，想家就回来。”让所有委屈和心酸混在雨里，成为继续前行的力量。


# 3 #

“我知道他给我的是他的全部”

——By 来包青柠薯片

我知道他给我们姐弟俩的是他的全部。小时候家里负担大，我爸每天都是打两份工，很辛苦也很拼。我们全家都很爱他，愿他一直都健健康康，永远是我们的大山。


你无法用华丽的辞藻渲染他的爱意

他给到的爱

是让任何言语都黯然失色的力量

今天

就用你的故事

诉说父爱的不凡

好啦，就说这么多吧，

小爱给爸爸选礼物去啦。

最后祝全天下的爸爸，节日快乐！
