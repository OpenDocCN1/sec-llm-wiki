CVE-2018-0171是一个远程代码执行漏洞，其为思科IOS和IOS-XE系统的配置管理类协议Cisco Smart Install Client（Cisco私有协议）代码中存在的一处缓冲区栈溢出漏洞。不法分子可以远程向 TCP 4786 端口发送一个恶意数据包，利用该漏洞，触发目标设备的栈溢出漏洞造成设备拒绝服务（DoS）或造成远程命令执行，这样不法分子就可以远程控制受到漏洞影响的网络设备。

![](../Images/5d0c6e534f91dc9be362958134c913ff.png)

两周前，一个名为“JHT”的黑客组织还利用此漏洞渗透了俄罗斯和伊朗两国的网络基础设施。这正是之前曝光的思科底层设备漏洞CVE-2018-0171被利用代码在互联网上肆虐。黑客利用漏洞渗透了涉及全球200000只路由器交换机，包括伊朗的3500只交换机。

而就在昨天，国内多个机构遭受同样的经历。一旦“中奖”除了设备瘫痪外，屏幕上还显示出美国国旗。在思科发布漏洞预警之时，全球受影响的设备高达850万。

![](../Images/c4373acd015410d1309d7bb66f9fa527.png)

近年来诸如此类的网络安全事件时有发生，我们只有提高自己的网络安全知识技能，才能防范诸如此类的网络威胁。

**No.1 移动端的渗透测试工具入门（星期一）**

推荐指数：★★★★

更新章节：activity组件安全

关键词：安卓软件zANTI模拟渗透流程、中间人利用、密码复杂度审计等

近年来，利用app渗透工具展开利用访问的案例层出不穷，受害者也与日俱增。虽说只要消除安全漏洞就能够杜绝这些利用，但这就需要相关人员掌握正确的安全知识。

0hop，是一名信息安全爱好者，主要方向是移动安全，目前对安卓app渗透以及系统方面进行研究。本课程他将通俗易懂地给大家介绍如何用安卓软件zANTI模拟渗透流程，中间人利用、密码复杂度审计等这些虽然对于Web安全从业人员耳熟能详的渗透技巧，但对大多数人来说却一知半解的术语都将详细的剖析。课程的最后将详细的对这些漏洞实例进行分析，并利用移动app，zANTI等工具为大家做出演示与讲解。

本课程建议学生跟随讲师从头到尾一步步地系统性学习，从理解原理到安装app渗透工具再到实践，由浅入深提高自己的安全水平。

**No.2 ARM 静态分析技术与实战（星期二）**

推荐指数：★★★★

更新章节：各种类型的参数传递

关键词：ARM汇编基础、C/C++与ARM之间的编译规则等

ARM静态分析与调试技术，该技术是Android、iOS、智能设备、等基于ARM芯片设备的逆向分析基础。

陈愉鑫，接触逆向领域四年、Android逆向两年。对Android逆向、保护等领域有强烈兴趣爱好。本课程讲师将从ARM汇编基础开始讲解，再到C/C++与ARM之间的编译规则，最后课程会进行一些算法还原方面的实战分析。

学完课程后，学员应该具有初步逆向分析能力、调试能力、算法还原能力。
