这里需要注意的有一个数据类型就是，uleb128。
uleb128就是一个1~5个字节来回浮动的数据类型，出现的作用就是为了避免内存浪费。
这里用python进行实现。

def get_uleb128(content):        value = 0        for i in xrange(0,5):                tmp = ord(content[i]) & 0x7f                value = tmp << (i * 7) | value //前n个字节组合，如i=1,为前2个字节的组合；当i=4时，共5个字节组合                if (ord(content[i]) & 0x80) != 0x80:                        break        if i == 4 and (tmp & 0xf0) != 0:                print "parse a error uleb128 number"                return -1        return i+1, value
