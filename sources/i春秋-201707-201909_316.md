**1.Concat函数**

concat()是一个函数，用于用于将两个字符串连接起来，形成一个单一的字符串，类似于字符串拼接；

语法:SELECT CONCAT(str1,str2,...)

执行结果：

![](../Images/5c0b9d61cc94aa0eda201de70306009d.png)

  

**2.实战演示**

查看users表下的数据

SELECT \* FROM users

![](../Images/564d8ef350712888425b370659ed5f2c.png)

那么当一条语句为

SELECT username,email FROM users

就只有如下结果（仅包含username,email）：

![](../Images/fd2b834f192300f32b32d8b8e5fd675a.png)

在渗透测试SQL注入时，如果想要password等敏感字段时，我们又该如何查询呐？

这里Concat函数就大显神威了，我们将username字段修改如下SQL语句：

SELECT CONCAT(username,password),email FROM users

![](../Images/c662920233a9fa33dd0dee093562f220.png)

在之前username字段的结果中，就同时得到了username和password的字段信息，为了阅读，清晰我们加上一个十六进制的分隔符~，其十六进制为0x7e，SQL语句改为：

SELECT CONCAT(username,0x7e,password),email FROM users

![](../Images/132b340502bbdfa2e49ad3850a7d7453.png)

这样子就清晰多了！同时也可以查询多个字段了！

SELECT CONCAT(username,0x7e,VERSION()),email FROM users

![](../Images/1afea2199d8a03e99565a963ad3f96bd.png)

  

**3.Concat\_ws()函数**

刚才有讲到分隔符便于我们的查看，concat\_ws()函数就是方便我们的，避免在每一个字段前加上分隔符，SQL语句如下：

SELECT CONCAT\_WS(0x7e,username,password,VERSION()),email FROM users

![](../Images/a7f01f1695679e0fb7394c5d1353d679.png)

  

**4.Group\_concat()函数**

SQL语句：

SELECT GROUP\_CONCAT(username),email FROM users

![](../Images/37aa69c3c151b113b28fe3a5d5fa3dbd.png)

作用是将对应字段的所有结果都查找并组合返回到一条记录中。
