讲师林很在IT行业领域有着十余年工作经验，持有CISSP\CIW\ISO27001\CCNP等专业证书；曾担任知名银行，移动通讯网，国际知名日用品消费公司，互联网金融公司，传统线下金融公司等安全相关重要职责。讲师通过讲解风控基础知识，风控系统知识的风控核心规则三个层次的内容，让学员全方面理解风控概念，帮助学员学习企业风控安全知识，把控企业安全策略。

学习了本课程，如果你是公司的在职从业者，它可以帮助你认识企业风控工作相关知识；如果你是企业中的计算机安全工作者，它能帮助你借此了解风控安全，便于策略公司整体安全工作规划。


No.2 恶意SSH链接导致的任意代码执行(CVE-2017-1000117)（实验/新课）（星期五）

推荐指数：★★★

关键词：复现漏洞场景、漏洞的利用手法

近日，三款主流的源版本控制系统Git、Subversion(svn)、Mercurial,发布了更新补丁，修复了一个客户端代码执行漏洞。这个漏洞的产生可以使恶意的攻击者向受害者发送一条精心构造的ssh://URL链接,如果受害者访问了这个URL，则会导致恶意指令在客户端执行，从而获取主机权限。

漏洞利用条件和方式则是结合社会工程学远程钓鱼利用而来。该漏洞由GitLab的Brian Neel，Recurity Labs的Joan Schneeweiss和GitHub的Jeff King发现和报告。

漏洞影响范围:

Git v2.7.6 至 Git v2.13.5

Apache Subversion clients 1.0.0 through 1.8.18 (inclusive)

Apache Subversion clients 1.9.0 through 1.9.6 (inclusive)

Apache Subversion client 1.10.0-alpha3

本次实验通过复现漏洞场景，希望同学们知晓漏洞的利用手法、了解漏洞的原理，马上点击课程开始实验吧！
