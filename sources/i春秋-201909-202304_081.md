No、No。咱今天就用利用时间来进行信息隐藏。

首先来读取一下这个时间，在python中使用os库就可以直接读取创建、修改、访问时间。

```
import
 os"new.txt"

```

打印之后得到以下内容：

`os.stat_result(st_mode=33206, st_ino=1970324837900684, st_dev=40639268, st_nlink=1, st_uid=0, st_gid=0, st_size=0, st_atime=1652854599, st_mtime=1652854574, st_ctime=1652854574)`

其中st\_atime为访问时间，st\_mtime为修改时间，st\_ctime为创建时间。

都是以unix时间戳(S)表示。

单独提取出创建时间使用`file_attr.st_ctime`可以直接提取。

如果需要转为标准格式`%Y-%m-%d %H:%M:%S`，需要导入time库。

其他修改、访问时间同理使用file\_attr.st\_mtime、file\_attr.st\_atime即可。
