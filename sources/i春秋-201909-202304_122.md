HTB是一个靶机平台，里面包含多种系统类型的靶机，并且很多靶机非常贴近实战情景，是一个学习渗透测试不错的靶场。

  

![](../Images/ada7b61d9cbe52aec609f97ff05ca394.png)

  

**1、靶机介绍**

  

这次的靶机是Brainfuck（Brainfuck是一种极小化的计算机语言，由于fuck在英语中是脏话，所以简称为BF），本期难点主要是在密码学。

  

![](../Images/2c7290a2ec384e2ff423a152060f5199.png)

  

**2、探测靶机**

  

首先使用autorecon进行基础的信息收集。

  

命令：python autorecon.py IP地址

  

![](../Images/8c90744161bbd536e1fa8729c1d918cd.png)

  

跑完以后打开nmap探测的结果，这次并没有开启80端口，而是转到了443端口。

  

同时DNS给的地址分别是www.brainfuck.htb和sup3rs3cr3t.brainfuck.htb

  

![](../Images/bcfe13ec6ef490df36bbb85ae5ca2c12.png)

  

虽然输入IP到浏览器还是会回显，但是页面不同。

  

![](../Images/138ba92c3b65796458b41cf45d3f928b.png)

  

这里要稍微修改下etc/hosts把IP加进去页面正常回显。

  

\[url=mailto:同时观察到页面有一个邮箱信息是\[email\]orestis@brainfuck.htb\[/email\]\]

  

同时观察到页面有一个邮箱信息是\[email\]orestis@brainfuck.htb\[/email\]\[/url\]和右下角有个大大的wordpress，可以确认目标是个wordpress站点。

  

![](../Images/f2ea5ad6475f5e7feb725718ff035db3.png)

  

**3、使用wpscan获取信息**

  

这里直接用wpscan加IP扫结果发现，wpscan并不是合适，https就直接识别不出来了。  

  

![](../Images/68c4879c34e224853fa5682bcd22650b.png)

  

这里只能改进下wpscan的命令，最后扫的一个wp-supportxxxx的插件可以确定是一个比较老的版本，对于老版本而言漏洞存在几率大。

  

命令：wpscan –-url https://brainfuck.htb –disable-tls-checks-eu,ap,t

  

![](../Images/9b29c2dbc63a0e2d1a77e05ddf9c98b5.png)

  

**4、搜索漏洞信息**

  

这里通过删减关键词找到了两个漏洞，一个是SQL注入，一个是提权。  

  

![](../Images/ed3324a92fed4c0e796d35a2f95e91ea.png)

  

SQL是一个后台注入漏洞，然而需要先登录后台。

  

再看另外一个是由于cookie配置不当，导致可以直接升级为admin。

  

![](../Images/134688a153a9c931bacc74edfbe0adff.png)

  

**5、制造对应的payload**

  

这里要注意下面的proof是一个html的文件格式，需要在本地创建好。

  

然后架一个python共享服务器点击发送数据过去，不是直接到action后面的地址，用Burp修改数据。

  

这是最终版payload(username为admin，是wpscan用eu扫出的结果)  

  

![](../Images/d3b2e83d8d28a1b311ed36d51b32d56e.png)

  

然后用python开启服务器模式，根据自己的python版本进行输入，然后在浏览器输入本地IP后，点开构造好的html payload。

  

点击login，命令: python -m SimpleHTTPServer 8081      python -m http.server 8081

  

![](../Images/224b75270db41a76b8d5157fe2018705.png)

  

此时访问会action后面的地址，再刷新wordpress发现多了些内容，变成admin在浏览器后面输入/wp-admin后，可直接进后台。

  

![](../Images/d2c2bd7541ab232366e9f67fe75278ba.png)

  

**6、进入后台收集信息**

  

这里进入后台爬到settings时，发现有个SMTP的密码。打开F12点击查看一波，可以去到110/25端口看一下。

  

![](../Images/e751a6f6774341f7d6252e95a4bc5b32.png)

  

可以使用nc或者是其它工具进行连接邮件端口。

  

因为在一开始已经知道开了25 110邮件端口，所以可以直接连接。

  

用list代替ls，用retr数字号码打开邮件。

  

![](../Images/88ad2c29cf7a3883521bc1a443b43984.png)

  

重点是第二封邮件给了一个账号密码。

  

![](../Images/832ecb9efc2ee39893cd79ddc365a1ca.png)

  

**7、难度最大的密码学解密**

  

这里的账号密码可能是子域名的这个网站

  

![](../Images/7434206f25bde5a7acd21e932b14b272.png)

  

成功登录以后有3个文件

  

![](../Images/3924b78715ec37b77fd6e40826ae6da9.png)

  

打开SSH是一版不知道啥语言，只看懂有个http网址。

  

![](../Images/72e88b4aeb41fb83e0bdb7356b35edf6.png)

  

后来发现是vigenere密码，需要先把词转，但是并不是固定的，这里直接放答案，id\_rsa典型的ssh钥匙。

  

![](../Images/3c619ae2d2f4a2ab20d4e9b39aad2d9e.png)

  

**8、利用john猜解ssh密码**

  

这里赋予权限后，有个密码需要猜解。  

  

![](../Images/a811ba59fd56dcccbc35e680407f60f0.png)

  

先转，然后直接上万能的rockyou.txt很快就跑出来了。

  

![](../Images/ead22aaa2f9b37c66e6972d966619689.png)

  

最后终于见到user的flag了

  

![](../Images/e6ecf5adc71ab6d0d42206aa9438abd6.png)

  

**9、解密拿flag**

  

这里由于Home目录下还有其它文件逐一打开，虽然encrypt.sage有root.txt，但是其它文件还有加密。  

  

![](../Images/dcd43d596d41d703e33980447730ff1d.png)

  

只能一段一段复制进必应，最后找到GitHub上有一个类似的，这是RSA加密。

  

![](../Images/3a4fc6b8f8c934c642d4d225e804586c.png)

  

然后又跟着其它代码找到了一个可解密的脚本，关键词是p,q,e,ct。

  

![](../Images/1e4a7a7f053a3405c21d2c8bd7ef1ceb.png)

  

p,q,e对应的是debug的每一段，然后ct是output.txt里面的，把脚本复制下来后改一改。

  

![](../Images/3ea7385b0c927ab7848547171a4bb1aa.png)

  

当然这个脚本解密后并不是最后的root的flag，还得转hex一波。

  

![](../Images/a633f04cb2e660f36b1ec929cce70b5d.png)

  

最后这才是最终的flag。

![](../Images/958ff8b66b81392deab0058ecb312f1f.png)
