# HTB靶场记录之Fuse

HTB是一个靶机平台，里面包含多种系统类型的靶机，并且很多靶机非常贴近实战情景，是一个学习渗透测试不错的靶场。

  

![](../Images/ada7b61d9cbe52aec609f97ff05ca394.png)

  

**1、靶机介绍**

  

这次的靶机是Fuse，本期用到的工具比较多。

  

![](../Images/86406d49983142bfd392e8d8ba86a625.png)

  

**2、信息收集**

  

还是python autorecon起手收集波端口信息，开的端口比较多，还有个LDAP端口，直接绕过节省时间。

  

![](../Images/8d5b981e4d7e809811c6a88825c87726.png)

  

把IP地址输入到浏览器后发现打不开，URL也变成其它了。

  

![](../Images/079389639557862a06e1dc18a46c74b8.png)

  

这里就需要在/etc/hosts里面添加进去就可，再次F5刷新成功。

  

![](../Images/dba24b3b24fa4cb0144d426f86b061b7.png)

  

这里点进去以后发现一些用户名信息，可以使用cewl爬虫下来，如果后面需要爆破的话可能会用的上。

  

![](../Images/c07b38fb8e9860688e03f3ceb8fefd04.png)

  

**3、88端口**

  

在前面信息收集的时候出现了一个稀有端口，88 kerberos服务。简单理解就是在不爆破LDAP的情况下改碰瓷88端口，从域外对域用户进行用户枚举和口令破解。

  

可以验证有哪些账号是存在的。

  

![](../Images/00eaaee2fe8c25c5bca122415d552f92.png)

  

使用方法也比较简单，下载好kerbrute以后直接用刚才cewl爬虫下来的文件对准10.10.10.193和fabricorp.local发射就可。

  

成功枚举到一些账户信息。

  

![](../Images/26ff280f295ffbe12c232e0f0ed3ab8f.png)

  

**4、其它端口**

  

在信息收集阶段有看到靶机开启SMB服务端口，但是autorecon表示需要登录，既然上面已经爬了一堆账户，那密码有可能还是在dict.txt里面，这里可以改用hydra进行爆破。  

  

![](../Images/39abcf7c8cf6af5f7314f9dbc3970cc3.png)

  

爆破成功以后遇到一个很尴尬的提示session setup failed:xxxxx。

  

后面在网上转了转才发现密码已过期要设一个新的。

  

![](../Images/4064f7dd260df62fe88518feb81a9ff3.png)

  

密码必须要包含大小写和特殊符号，要不然不给通过。

  

![](../Images/e65c7cec9ff880e9cfdbebd8e6c56f7b.png)

  

最后还是能枚举出来信息，不过操作比较麻烦。

  

![](../Images/c4d42e71547124de439a17df605b6d80.png)

  

**5、转用rpcclient继续深入SMB端口获取信息**

  

做到这步其实尬住了，好像只能做到这种效果，后来请教了大佬，大佬给了一个hackingarticle链接：

https://www.hackingarticles.in/active-directory-enumeration-rpcclient/

  

重点是里面的两句话：

*   

```

```

简单理解就是smbclient能做的事rpcclient也能做。使用方法也是跟smbclient比较类似。

  

直接rpcclient -U ‘用户’ IP地址这样，最后输入新的密码成功登录。

  

![](../Images/8e1379be833ae84b125209f13f224d93.png)

  

可以使用enumdomusers来枚举当前用户，保存下来。

  

![](../Images/aac10b7f3714e16db748b550359e9a88.png)

  

除此之外，由于80端口是个打印机页面，直接enumprinters也是可以列举出信息出来。

  

顺便得到一个password。

  

![](../Images/d6f6b95ec99a8db53fc4a1e46259ba1c.png)

  

**6、登录靶机**

  

在前面rpcclient得到一个完整密码以后，这次还得用另外一个工具crackmapexec， 可以参考论坛一位大佬的文章：

 https://bbs.ichunqiu.com/thread-60767-1-1.html

  

简单来讲就是枚举用户登录。本质上来说我们sudo openvpn –config 你的文件名连接成功，也是一波内网攻击靶机的操作。Crackmapexec在kali是自带的，这里可以看到有一个账户密码枚举成功。

  

![](../Images/532bde8a5171887421a1314f4a351ce2.png)

  

接下来就是域内用户登录。这里要用到evil-winrm，kali非自带要下载，评论区有链接(一个windows远程管理shell的终极版本，由于我们有一个域内用户账号密码可直接登录)。登录以后可直接获得User的flag。

  

![](../Images/abf52cfb6eebe8d09d4c9453c0c3c8d4.png)

  

**7、提权**

  

如果说前面只是各种方法转来转去，提权这里差点是把我搞崩溃了。首先先使用whoami/priv查看波权限，发现有个SeLoadDriverPrivilege，可以Load and unload device drivers。

  

网上有个利用方法：

https://www.tarlogic.com/en/blog/abusing-seloaddriverprivilege-for-privilege-escalation

  

概况来讲就是有准备两个东西，一个是Capcom.sys，另一个是得编译好的loaddriver。

  

![](../Images/90c4f75fba985176c486ec35f90ab652.png)

  

Capcom.sys还好找Github一搜就有了：

https://github.com/FuzzySecurity ... r/Driver/Capcom.sys

  

![](../Images/41ba56d16af99c86ca815a089b10ba2a.png)

  

然而好像是需要自己编译的，直接在GitHub上找到一个大佬编译好的点开链接会自动下载：

https://github.com/clubby789/ExploitCapcom/releases/download/1.0/ExploitCapcom.exe

  

![](../Images/2bcb43ed10616978cea54e83392769b0.png)

  

这里可以直接用Upload把这两个文件传上去

  

![](../Images/feef3ac59159ae08f581bf0ad2a64e02.png)

  

使用方法也很简单，直接exe load sys就可后面带需要执行的命令，直接最高权限。

![](../Images/87027526a1ec66811640195954e095f8.png)

  

做到这步其实就可了，为了拿flag还得生成一个反弹文件出来。  

  

![](../Images/fb7231a9021d174c63eaf16d148c24cb.png)

  

![](../Images/4565df863f80be52819cea63a2bb6d04.png)

  

最后成功接收到shell。

  

![](../Images/cd796bbda3c3a1a57f5413e91fc97fc2.png)
