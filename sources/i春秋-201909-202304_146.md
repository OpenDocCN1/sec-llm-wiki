4.这个时候需要手工还原和分析代码了，先格式化一下代码。

  

![](../Images/22dbaa584005d7be33ae81c58ee9ff2a.png)

  

5.先还原一下tipstime这个函数。

  

![](../Images/6f4442fb449b6b5c72996b0646eb2410.png)

  

6.代码中大量的使用了\_\_Ox6f8fd,其中\_\_Ox6f8fd定义的是一个数组。

  

![](../Images/a8ec9c824d368cf0d15febd7935209cc.png)

  

7.把这个数组复制到浏览器的控制台运行一下就行。

![](../Images/0face81529615beb27cdf46a6b819a4f.png)

  

8.\_\_Ox6f8fd\[0x1\]代表.timemsg,\_\_Ox6f8fd\[0x0\]代表text。

![](../Images/f036c6102842e4b592b4c4a179d0227d.png)

9.然后第一行还原结果是如下：  

![](../Images/6d93a29693f0d4a30b2dec740d78aec9.png)

  

10.然后换一种格式，就是这样$(".timemsg").text(\_0x81efx2)；

  

11.第二行的if(\_0x81efx2 == 20)这个不用管，因为\_0x81efx2就是个传参名称而已。

  

12.第三行$(\_\_Ox6f8fd\[0x3\])\[\_\_Ox6f8fd\[0x2\]\]();其中\_\_Ox6f8fd\[0x3\]代表.tips,\_\_Ox6f8fd\[0x2\]代表hide。

  

![](../Images/ac664aa01f8542b6741ce9f5d547ce84.png)

  

13.第三行的还原结果如下：

  

![](../Images/346441a84c5dca1a97a5ef995d488c04.png)

  

14.其实就是$(".tips").hide()；

  

15.第四行

  

 (1)\_\_Ox6f8fd\[0x5\]代表.timeout

  

 (2) \_\_Ox6f8fd\[0x4\]代表show

  

![](../Images/94bd8e61c5563432c96e19fa3879ecb3.png)

  

16.第四行还原结果如下：

  

![](../Images/d58d7f0c0db3234fe556a5671c457243.png)

  

17.其实就是这样$(".timeout").show()

  

18.最后tipstime函数完整的代码就是这样：

  

![](../Images/2723e88f3ec4e34b3fff820a671c1104.png)

  

19.如果觉得\_0x81efx2不美观，那就全部替换成变量名称time。

![](../Images/d04ab6732017efbd070f47e76793863d.png)

  

20.接下来就是NXplayer函数了

  

(1)navigator\[\_\_Ox6f8fd\[0x7\]\]\[\_\_Ox6f8fd\[0x6\]\](/iPad|iPhone|iPod/i)

  

(2)navigator\[\_\_Ox6f8fd\[0x7\]\]\[\_\_Ox6f8fd\[0x6\]\]

(/iPad|iPhone|Android|Linux|iPod/i)

  

21.Navigator 对象是由 JavaScript runtime engine 自动创建的，并不是用户自己创建的。

  

22.\_\_Ox6f8fd\[0x7\]代表userAgent,\_\_Ox6f8fd\[0x6\]代表match。

  

![](../Images/a09daf8aac6d8d9e46e6439f1624b318.png)

  

  

23.所以NXplayer函数第一行和第二行还原结果如下：

  

![](../Images/2041b98be3b72c237747cdd0868e5669.png)

  

24.换一种表达形式

  

(1)navigator.userAgent.match(/iPad|iPhone|iPod/i) != null；

  

(2)navigator.userAgent.match(/iPad|iPhone|Android|Linux|iPod/i) != null；

  

![](../Images/866cb301ecc367fda64b19d6cf5072e5.png)

  

  

25.把上面这些操作自动化，先遍历数组，提取混淆之前的字符串，然后用混淆之前的字符串去替换代码中混淆之后的字符串，这样自动去除混淆脚本基本完成了。

  

26.为什么说基本完成，因为只是替换了字符，很多语法问题还需要细调。

  

![](../Images/7a86be2d985f61071862058afe918829.png)

  

27.这个已经是比较简单的案例了，碰到更复杂的混淆和加密，需要花更多的时间。
