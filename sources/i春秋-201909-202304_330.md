# 密码安全丨你的手机锁屏密码真的安全吗？

你的手机锁屏密码真的安全吗？

  

很多人都这样认为：我的电脑、手机非常安全，因为设置了密码，而且是人脸识别、指纹密码，除了自己其他人都打不开。

  

为什么会这么自信呢？

  

因为密码一般都具有高隐私性，很大程度上只有自己知道。

  

然而，经过大量的实验分析证明，我们的锁屏密码并不安全！

  

不仅如此，超过90%的人为了便捷，习惯在多场景下使用同一组密码，这种操作无疑加重了安全隐患。

![](../Images/924210b154b557c62137bb7d0088207c.png)

据调查显示，超过60%的用户使用的手机锁屏模式还是这样的：  

  

![](../Images/e6e07081208a5797bdb8f8ec7c923a3f.png)

  

Android系统爆出过一个广泛存在的漏洞，通过简单几步操作就能绕过锁屏密码进入主屏。

  

  

具体操作方法是：先点击紧急呼救，进入紧急拨号界面，随机输入一组数字，并重复复制粘贴它，数次之后就自动跳回锁屏界面。

  

这时，再打开摄像机，反复地按快门拍照，重复数次之后就可以进入系统！

  

  

类似可绕过密码的方法由来已久，随手搜索一些关键词，出来的答案能多到让你咋舌。通过一系列的操作达到绕过锁屏密码的方法一直都有，也许以后还会有。

  

而且即使这些漏洞被修复了，一旦别人拿到你的手机，依然有其他办法可以破解锁屏密码。  

  

为什么会这样？  

  

因为你是可预测的，你的密码是可预测的，你的PIN码同样如此，你的手机锁定模式也“在劫难逃”。

  

![](../Images/6e2b2d55b2ac9bab03e9f76610272d7d.png)

  

在本节公开课《研究3400个大众式手机锁屏的背后》中，大量数据分析得出，有高达**389112种**可能的锁屏模式。

**![](../Images/5626b75fb4b1c345731591fa92b561b8.png)**

  

![](../Images/e4d2cc0db008d998198362104f4b0631.png)

  

众多的锁屏模式中又隐藏了哪些秘密？你创建的锁定模式会与别人不同吗？

  

![](../Images/cf1673643bb6ff7a6592cf0b2b308872.png)

  

由此可知，每十个手机的锁屏图案里至少有一个是用字母设置的，那么得到正确锁屏密码的概率可以说很高了。  

  

然而，除了用字母设置外，也会有相对复杂的图案设置，假如多连接几个点，交替连接，这样的话，还有概率可言吗？

  

![](../Images/48c60f4e1eced986d0bf90c83779c676.png)

  

如果你的上锁手势是L形，那么你被破解的概率高达62%，即使使用的是全加密模式的设备也“在劫难逃”。

  

当然了，生活中有10%的人是左撇子，90%的人是右撇子，那么使用习惯、手势都不同的情况下，还能被破解吗？  

  

答案当然是可以的，具体的操作流程，可以识别下方二维码，在公开课中进行观看学习。
