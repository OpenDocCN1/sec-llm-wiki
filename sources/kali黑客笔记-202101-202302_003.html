wget是我们常用的一款网络下载工具。它支持断点下载，同时支持FTP和HTTP下载方式，支持代理服务器。下面我们一起来看看让如何使用吧！

下载单个文件

下载一个文件并保存在当前目录

wget https://bbskali.cn/kali.zip

在下载的过程中会显示进度条，包含（下载完成百分比，已经下载的字节，当前下载速度，剩余下载时间）

下载并以不同的文件名保存

我们可以使用参数-O来指定一个文件名，如下，我们将文件保存为了逍遥子.zip

wget -O 逍遥子.zip https://bbskali.cn/kali.zip

限速下载

我们用wget下载，会占用全部可用的宽带。如果是个较大的文件，可能会影响我们的工作。因此对下载进行限速就很有必要了。

wget --limit-rate=8000k https://bbskali.cn/kali.zip

断点续传

在实际下载中，可能会有突发情况，如停电。这时我们的下载就会中断。为了解决这个我们我们可以通过-c断点续传进行下载。

wget -c https://bbskali.cn/kali.zip

后台下载

对于下载非常大的文件的时候，我们可以使用参数-b进行后台下载。

wget -b https://bbskali.cn/kali.zip

下载多个文件

以上的下载，仅仅是针对单个的文件下载。对于多个文件，我们该怎么办呢？首先我们需要将下载链接保持到同一个txt文件中。然后在执行下面命令就行了。

wget -i filelist.txt

克隆网站

wget可以下载目标站点到本地。达到克隆网站的作用。

wget --mirror -p --convert-links -P ./home https://bbskali.cn

参数说明

  • --miror：开启镜像下载
  • -p：下载所有为了html页面显示正常的文件
  • --convert-links：下载后，转换成本地的链接
  • -P ./home：保存所有文件和目录到本地指定目录

过滤下载

我们可以使用wget --reject过滤指定格式下载,如过滤掉所有的图片文件。

wget --reject=gif https://bbskali.cn

基于FTP下载

wget --ftp-user=USERNAME --ftp-password=PASSWORD kali.zip

总结

wget是一款很强大的工具。是我们学习Linux运维、网络安全必不可少的。在Linux系统中，该工具已经默认安装，直接使用即可！
