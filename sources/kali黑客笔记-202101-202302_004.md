# 前言

对于文件压缩和解压，我们不想向windows那样，可以通过鼠标解压，因为需要记住常用的解压和压缩命令。常用的压缩包后缀有 `.tar`、`.gz`、`.bz`、`.z`、`.zip`、`.rar` 等，分别采用不同压缩方法进行压缩和解压。根据不同类型可以在 Linux 下选择不同的压缩文件。

# gzip、gunzip

`gzip`命令和`gunzip` 命令用于 `.gz`文件的压缩和解压。

**🐼常用参数：**

*   `-l`：列出压缩文件的相关信息（list）
*   `-v`：显示指令执行过程（verbose）
*   `-d`：改为解压指定文件（decompress）
*   `-r`：递归处理目录下的文件及子目录（recursive）

**示例**

压缩`kali`文件夹下的所有文件

```
gzip -r kali

```

![](../Images/853d67e430717382413dfda98b541b54.png)

解压`kali`文件下的所有文件

```
gunzip -r kali

```

# zip、unzip

`zip` 命令和 `unzip` 命令用于 `.zip` 文件的压缩。这两个命令是我们最常用的命令了。

**⚽常用参数**

*   `-r`：递归文件或目录
*   `-d`：从压缩文件内删除指定的文件
*   `-q`：不显示指令执行过程
*   `-f`：更新现有文件
*   `-P` <密码>：加密压缩文件，后接加密密码
*   `-z` 替压缩文件加上注释。
*   `-u` 更换较新的文件到压缩文件内。

**🐶示例**

压缩`kali`文件夹下的所有内容。

```
zip -r kali.zip kali
 
```

![](../Images/0598076f1177cfdcbbd96ddf1338c925.png)解压文件

```
unzip kali.zip

```

# rar、unrar

`rar` 命令和 `unrar` 命令用于 `.rar` 文件的压缩。他的用法和上述zip类型。压缩文件

```
rar a kali.rar kali
  
```

解压文件

```
unrar x kali.rar
 
```

![](../Images/9d5b124d4e704ceebf3cbf5ddf622fad.png)

# tar

`tar`是用来建立，还原备份文件的工具程序，可以加入、解开备份文件内的文件。tar 本身可以处理 `.tar` 格式的压缩和解压。但通过附加参数即可实现 tar 上追加其他属性的压缩和解压。如我们最常用的`.tar.gz`文件格式就是经过了`tar`打包后，再使用`gzip`压缩。

压缩文件

```
tar cvfz kali.tar.gz kali

```

![](../Images/462c96a8aad625ad64999f65f17a55d2.png)解压`.tar.gz`文件（一定要记住，最常用的一条命令。）

```
tar xvfz kali.tar.gz
 
```
