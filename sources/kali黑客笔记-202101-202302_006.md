# 安装

`Yakit`支持`windows` `Linux` `mac`等常见平台。我们只需去官网下载安装包，运行安装就行了。

**项目地址：**

> https://github.com/yaklang/yakit

  

![](../Images/75024a53fbe25212fd37e2a8c16d9088.png)

**🌈windows平台**

我们需要安装Yak环境 用管理员身份打开`cmd`,输入下面命令。

```
powershell (new-object System.Net.WebClient).DownloadFile('https://yaklang.oss-cn-beijing.aliyuncs.com/yak/latest/yak_windows_amd64.exe','yak_windows_amd64.exe'
) && yak_windows_amd64.exe install && del /f yak_windows_amd64.exe
```

![](../Images/891a953ab301b3a17327001de476fae8.png)

检测环境是否安装成功。

```
yak
 -h
```

![](../Images/0dca3d49a8ff631e6e91c826c6612c27.png)

**🎲安装Linux环境**

```
bash <(curl -sS -L http://oss.yaklang.io
/install-latest-yak.sh)
```

![](../Images/83b0e56814361ec01b9ac780ecbe6471.png)

环境安装完成后，运行下载的程序。便可以看到`Yakit`的界面了。对于`Linux`我们只需只需下面命令即可运行

```
sudo ./Yakit-1.0.12-sp7-linux-amd64.AppImage
 --no-sandbox
```

如下便可以看到相应的界面

![](../Images/1cd947b14a5f5fab3b95494548a04c93.png)

然后点击`核心引擎安装与升级`

![](../Images/8285e7ffb6a9e64f3ca927919dad64c0.png)

点击一键更新。等待更新完成后，点击连接引擎进入系统。

![](../Images/069320232a6728936e7e41a191998cec.png)![](../Images/b86c7a756e85d2d9af7df9499f853fbe.png)

这个功能和`burp`一个道理。可以抓包、改包、放包等常规操作。对于https站点，我们需要先下载证书。

```
wget -e use_proxy
=yes -e http_proxy=http://127.0.0.1:8083 http://download-mitm-cert.yaklang.io -O yakit-mitm-cert.pem
```

然后在浏览器中导入证书。
