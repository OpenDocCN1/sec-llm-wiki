# 关于

`Captura`是一款小巧的屏幕录制工具，体积小巧，运行速度快，支持全屏录制、窗口录制、区域选择、游戏录制。输出格式包含常见的`mp4`、`avi`、`gif`等常见的媒体输出方式。

# 工具特性

*   拍摄截屏
*   捕捉特定区域、屏幕或Windows录制
*   捕获屏幕广播（Avi / Gif / Mp4）
*   全屏 DirectX 游戏录制
*   使用/不使用鼠标光标捕获
*   捕获鼠标单击或击键
*   混合从麦克风和扬声器输出录制的音频
*   从网络摄像头捕获。

# 注意事项

该工具需要`FFmpeg`拓展支持，我们需要下载`FFmpeg`。下载完成后，点击设置 选择`ffmpeg`的bin目录即可。同样也可以在设置语言选项。
