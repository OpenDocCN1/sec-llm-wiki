对于网络安全初学者而言，不知道该从什么地方入手。我的回答是从最基本的Linux命令入手。先掌握每个Linux命令以及每个文件的作用。其次掌握Linux的运行机制。本文我们将为初学者献上最详细的Linux入门指南，文章较长建议收藏阅读。

为什么使用Linux

Linux中的一切都是围绕文件。对于文件处理，Linux 只需要一个终端/shell 就可以对文件来创建、命名、移动、压缩、加压等操作。Linux 的另一个巨大优势是占有的系统资源比较低。无需对电脑有太高的要求如单片机、树莓派等均可完美运行Linux。

Linux文件系统结构

Linux文件系统结构简单。一切都位于一个文件夹中（/），其中细分了许多子文件夹。这些子文件夹中的每一个都有特定的用途。

每个文件夹作用

💌目录🇨🇳作用
/顶级目录或根目录，包含了Linux系统中所有的文件。
/bin包含必要的二进制命令文件（如cd ls等系统命令）
/boot引导加载程序、内核可执行文件和引导 Linux 操作系统所需的文件组成。
/etc注意存放系统各类软件的参数，保持系统文件，用户软件配置文件
/home本地系统配置文件和已安装应用程序的配置文件也可能保存在该目录中。
/lib系统启动所需的共享库文件。
/media外部可移动媒体设备（例如 USB 驱动器）
/mnt常规文件系统的临时挂载点。
/opt第三方工具等可选文件可以保存在这里。
/root根用户的主目录。
/sbin该目录包含用于系统管理的可执行文件，即用户安装的命令
/tmp操作系统和许多程序使用此目录来存储临时文件。该目录通常在系统启动时被清除，并且可能会在其他时间被删除而不会发出警告。
/usr包含可执行文件、库、man 文件等。
/var该目录包含可变数据文件，例如日志文件、电子邮件收件箱、与 Web 应用程序相关的文件、cron 文件等。

Linux 命令速查表

🌈01 -h命令

-h命令主要显示每个工具的使用帮助。在初次使用该工具时，如果不知如何下手，可通过-h命令查看相关工具说明 如

whatweb -h

🍀02 pwd

通过pwd命令可以返回当前工作所在的目录。

🍓03 ls

列出当前目录下的文件内容

ls #列出文件内容
ls -a #显示隐藏的文件

🍑04 cd

通过cd命令，可以方便的切换工作目录。

🥳05 tree

tree以树状结构的形式展示文件

🚢06 clear

清除当前终端内容，快捷键ctrl+k

🍔07 文件三大妈

mkdir #创建文件夹
cp #复制文件
mv #移动和重命名

🍀08 cat

通过cat命令可以查看文件内容，通用的工具还有vim

cat 逍遥子大表哥.php

🏠09 whoami

显示当前用户

🐼10 ifconfig

最常用的命令，用于显示当前设备的IP和网络等相关信息。

🚀11 用户管理

passwd #修改用户密码
useradd #添加用户
userdel #删除用户
addgroup #添加用户组
delgroup #删除用户组
