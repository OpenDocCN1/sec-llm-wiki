# 汇编反编译

所需编译工具`010Editor`

**官网下载** https://www.sweetscape.com/010editor

下载 `010Editor` 二进制修改工具，免费试用30天，够用了。![](../Images/132be1c170999cc0966770b5a8820c16.png)

注意先备份！`010Editor` 打开 ``` `` `xshell.exe` `` ```，全局搜索`74 11 6A 00 6A 07 6A 01`，把开头的 `` `74` ``改成 `EB`(注意是大写) 保存即可。同样的方法对于`XFTP`我们只需全局搜索 `75 22 6A 07 6A 04 FF 15`，把开头的 `75` 改成 `74` 保存即可!​![](../Images/44926aa71276d9e6ed3f605a6a193a25.png)
