> 当设备遭到入侵后，我们该如何排查可疑程序和进程呢？本文将为你介绍在`Windows`和`Linux`系统中常用的排查方法。

# Windows系统

对于windows系统。我们优先考虑通过各种杀毒软件进行杀毒扫描。当然如何shell是免杀的话，我们只能进行手动排查！

#### 🥳查看账号

攻击者为了方便登录系统。往往会給自己添加相应的账号，并且有些账号可能是隐藏账号。

**🐼普通账号**

首先`win`+`r`输入下面命令

```
lusrmgr
.msc
```

**🌈隐藏账号**

`win`+`r`输入`regedit`查看`HKEY_LOCAL_MACHINE\SAM\SAM\Domains\Account\Users`

![](../Images/b4c8d08668faeaff423183e60bab77e8.png)

#### 🍓系统日志分析

`win`+`r`输入`eventvwr.msc` -> `windows日志`

![](../Images/d0d9af8503c9f5c2e815473c1173f1c8.png)

#### ✈️排查网络与端口

如何设备遭到入侵，哪么设备和攻击者之间肯定会建立通信。这时我们可以检查可疑的IP和端口。

```
netstat -ano

```

![](../Images/85da4490fecaa4cb1f72630cfe9bc770.png)

#### ⚽排查恶意进程

```
tasklist

```

![](../Images/c942d61f2730bee064a455913a7f3777.png)

#### 🎧检查自启动

`win`+`r`输入`msconfig`，查看自启动服务。

#### 🍺检查计划任务

```
schtasks

```

![](../Images/ee290cf6c6c664a561de0b84068bb2e5.png)

#### 🚀最近打开文件

`win`+`r`输入`%UserProfile%\Recent`

![](../Images/f08c3f6ea84cb65387db6e6f98da7387.png)

# Linux系统

对于Linux系统，排查难度和Windows相比难度略有提升。在使用`安全狗` `D盾` `云锁`等常规WAF无果的情况下。我们可以手动进行排查。

#### 🚸历史执行命令记录

在Linux中，我们可以查看执行各种命令的历史记录。

```
history

```

![](../Images/26b29d4bc1e9ebfd72d991593f9fbc8e.png)

#### 🪤检查定时任务

```
ls /etc
/cron*
```

![](../Images/714277dd97ab7bff9d8f759765f83c17.png)

#### ❄️查看用户

```
cat /etc/passwd

```

#### 🍀查看登录及重启记录

```
last

```

![](../Images/271ce97c7ab893b22778c09e72a9c0b3.png)

#### 🏓网络与端口

```

 -alntp
```

![](../Images/957dfb251badac86f85c0d1f9c0ff907.png)
