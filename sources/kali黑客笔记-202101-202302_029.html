关于laZzzy

laZzzy是一款功能强大的Shellcode加载器，该工具使用了各种不同的开源代码库实现其功能，能够给广大研究人员更好地演示恶意软件所使用的常见的不同代码执行技术。

功能及特性

  • 1、直接系统调用和本地函数（Nt*）调用（支持绝大多数本地函数）；
  • 2、IAT（导入地址表）绕过；
  • 3、Payload加密（AES、异或）：随机生成密钥、自动填充Payload（\x90）、在内存中逐字节解密Payload；
  • 4、字符串异或加密；
  • 5、PPID欺骗；
  • 6、屏蔽非微软签名的DLL；
  • 7、（可选）克隆PE图标和属性；
  • 8、（可选）使用伪造的证书进行 代码签名；

安装

带有Visual Studio和以下组件的Windows机器，可以从Visual Studio Installer>单个组件安装：C++ Clang Compiler for Windows和C++ Clang-cl for build tools

安装ClickOnce Publishing

下载及安装模块：

git clone https://github.com/capt-meelo/laZzzy.git
python3 -m pip install -r requirements.txt

运行执行builder.py即可。
