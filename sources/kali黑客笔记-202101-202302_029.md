# 关于laZzzy

`laZzzy`是一款功能强大的`Shellcode`加载器，该工具使用了各种不同的开源代码库实现其功能，能够给广大研究人员更好地演示恶意软件所使用的常见的不同代码执行技术。

# 功能及特性

*   1、直接系统调用和本地函数（Nt\*）调用（支持绝大多数本地函数）；
*   2、IAT（导入地址表）绕过；
*   3、Payload加密（AES、异或）：随机生成密钥、自动填充Payload（\\x90）、在内存中逐字节解密Payload；
*   4、字符串异或加密；
*   5、PPID欺骗；
*   6、屏蔽非微软签名的DLL；
*   7、（可选）克隆PE图标和属性；
*   8、（可选）使用伪造的证书进行 代码签名；
