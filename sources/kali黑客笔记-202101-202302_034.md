> 我们在利用cs玩耍时，最头疼的莫过于没有公网IP问题。在前面的文章中我们讲过通过内网映射或者端口转发的方式使其上线。哪么有没有更简单的方法呢？

# 实验环境

*   `vps`(轻量服务器)
*   cs4.5
*   远在天边的好友（甲 乙 丙）

# 在vps中安装cs

因为我们的cs依赖于`Java`开发。所以我们需要在`vps`中安装`java`环境。执行下面命令进行安装。

```
yum -y install java-1.8.0-openjdk*

```

安装完成后，我们执行`javac`命令便可以看到相关java的信息。

![](../Images/f7f3375aae436733f729d64b76bbfd7b.png)

接着，我们上传`cs`到vps 并启动服务端。

```
./teamserver vpsip pass66

```

![](../Images/222154b693c245c286056b5eeac33b8e.png)这样我们的cs便在vps服务器中安装好了。接着我们在kali中登陆客户端。

![](../Images/b30e81bc79644a52a9597745d05e2776.png)

![](../Images/c9268ad1477e6828ee901c10952da3f8.png)

这样我们便完成了cs在`vps`中的安装和利用。

# 测试

# 总结

个人觉得这是目前解决公网`IP`最稳定和最经济的方法了。但是也有一定的缺陷。如受到vps带宽的影响、或者vps地域的因素。有时请求响应可能需要的时间比较长。
