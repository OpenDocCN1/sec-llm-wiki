# 安装

这里我们参考了官方的一键安装脚本。手动安装可能会出现各种问题。首先我们先安装`docker`。根据系统类型可以用`apt`或者`yum`命令进行安装。

```
apt-get install docker-compose

```

然后执行下面命令

```
sysctl -w vm.max_map_count=262144
o f8x https://f8x.io/   # wget -O f8x https://f8x.io/
bash
 f8x -viperchmod +x f8x

```

执行命令后，效果如下。我们等待安装完成。需要下载1G的文件，根据自身网络情况而定。![](../Images/7989015f6c67b147efeaed754363ee3c.png)

输入自己的账号和密码后，等待下载镜像文件。

![](../Images/9fdbaff6aa09f8e57ca462723858f213.png)

等待安装完成后，我们访问`ip:60000`输入账号和密码登录系统。如果你有`vps`的话，建议直接在`vps`上面安装。这样可以解决内网访问问题。

![](../Images/ce98133d86b87b74cc676b88bcac8a7e.png)

登录后效果如下，全程友好中文界面。
