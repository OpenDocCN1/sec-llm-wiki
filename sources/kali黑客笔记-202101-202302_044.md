# 什么是Kali Linux？

`Kali Linux` 是一个基于 `Debian` 的安全发行版，最初设计用于渗透测试和网络分析。该操作系统是完全免费的，我们可以通过PC、手机、手表、树莓派等设备进行安装。目前支持 `500` 多个渗透测试和网络安全相关应用程序。它是一个开源操作系统，因此其代码可在线免费获得，这意味着您可以根据需要查看并对其进行调整。它还支持多种语言，并包括许多自定义功能。

# 选择它的理由

其实在当前，还是有很多类似kali这样的安全审计系统。但是大多数由于官方放弃更新，从而让人们对其淡忘。笔者总结了以下几点理由，让我们一起看看吧！

#### 🎃01 对设备的要求比较低

我们在初学时，担心自己的电脑配置比较低。从而有些程序没法运行（如密码破解程序，需要很强的`GPU`性能）但是kali对系统资源要求比较低。我们在虚拟机中分配`20G` `1G/HZ`等比较少的资源。kali就能运行。当然我们还可以将其安装在手机、手表、U盘等设备中，携带也更加方便。

![](../Images/991e1bcb931dc1cebeec1e2cafdd1aff.png)

#### 🎨02 对小白及其友好

许多安全工具它的运行需要依赖很多环境。如`java` `python` ，但这些环境在kali中已经默认安装，开箱即用！同时有些工具我们只需利用`apt`命令一键安装。很多Linux的命令，在kali中也通用。因此作为网络安全爱好者，深入了解 Linux 命令行很重要。

![](../Images/6af661eaacb8561346080bc121ce414f.png)

#### 03 🏀工具多 更新快 长期维护

在我看来，这时`kali`最吸引用户的地方。`kali`官方每个季度会更新一次。每次更新都会带来不一样的体验。当然也包括里面各种安全工具的更新。

![](../Images/940cb764a00ece05f0695a4a803781b6.png)

#### ⛳04 相关教程丰富

在初学者学习kali相关知识时，互联网上存在很多与其相关的文章。如`B站` `博客园` `知乎`都有相关的安全文章。为小白入门提供了不少的帮助。

![](../Images/fe3ca1fe04961c1bf3e1aeffd59a05d7.png)
