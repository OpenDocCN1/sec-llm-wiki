> 在前面的一篇文章中。我们讲到了如何利用`frp`进行内网映射。使得内网的设备可以通过公网登录。但是`frp`相对来说都是通过配置命令参数来实现的。对小白而言还是有点挑战，今天来介绍另外一种简单的方法吧。

# 关于NPS

`nps`是一款轻量级、高性能、功能强大的内网穿透代理服务器。目前支持`tcp`、`udp`流量转发，可支持任何`tcp`、`udp`上层协议（访问内网网站、本地支付接口调试、ssh访问、远程桌面，内网dns解析等等……），此外还支持内网`ttp代理`、`内网socks5`代理，并带有功能强大的`web`管理端。

# 实验环境

*   公网vps (服务端 `centos7`)
*   用户端 （`kali linux` 、`Windows10`）

# 下载nps

首先，根据自己的系统类型到项目地址去下载。服务器端为`linux_arm64_server.tar.gz` 客户端为`windows_amd64_client.tar.gz`

# 安装服务端

根据公网服务器的类型，下载`server`端。![](../Images/fbd5aad20aa874a685cfc49b7ca1e4c7.png)

```
mkdir
 npscd
releases/download/v0.26.10/linux_amd64_server.tar.gz
tar -zxvf linux_amd64_server.tar.gz

```

**🚢配置nps.conf**

```
**vim **conf/nps.conf

```

修改部分

```


#web123
 #web控制台密码设置8080
0.0.0.0

false


```

![](../Images/ccb8de14eedd0c244d4134b18b918cfe.png)

**🎃安装nps**

执行命令

```
**./nps** install
**./nps** start #启动

```

![](../Images/09662b8ad37a4462bdc83deefaa11c5c.png)

# 访问web控制台

浏览器访问 `ip:8080` (安全组和防火墙需开启对应的端口)![](../Images/b46760a961524d1e3a57578e4003ec92.png)输入你配置文件中的账号和密码进行登录。![](../Images/8fde071575ede7cdd7a5c8b341809e07.png)如上，登录后台后，我们只需根据实际需要，在后台添映射的目标即可。

# 添加映射目录

配置完成后，点击提交。然后点击客户端，新增一个客户端。记录密匙！![](../Images/73b1d85b9cf80822f0aa516156ed644c.png)

点击`tcp`——`添加`根据实际情况填写相应的参数。注意客户端ID就是我们上一步中创建的客户端id。

![](../Images/4852d1ca709c1912ef741da300c6d09c.png)

# 配置客户端

这里，我们还是以kali的22端口为例。首先，下载对应的客户端`linux_arm64_client.tar.gz`。

```
mkdir nps
releases/download/v0.26.10/linux_arm64_client.tar.gz
tar -zxvf linux_arm64_client.tar.gz

```

解压后，文件如下![](../Images/2bd4ec0e73f07f57f53fd6c5aefa4f10.png)

# 连接

我们只需下面命令，便可实现连接。

```
**./npc** -server=公网IP:8024 -vkey=你的客户端密匙 -type
=tcp
```

# 总结

`nps`和`frp`这两款端口映射工具可以说各有千秋。前者相对来说配置比较简单，并且有漂亮的web管理平台。（`frp`也有web管理，但都是最基本的功能。）支持的协议也比较多。但是缺点是支持的设备相对frp就比较少。如我们的路由器对frp支持比较广泛。
