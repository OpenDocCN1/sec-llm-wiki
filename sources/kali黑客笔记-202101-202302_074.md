# U盘安装

我们可以将Kali安装到U盘中。真正意义上的做到了随时随地的“肾透”，无需考虑主机是否在身边，只需任意设备，利用U盘启动，便可使用Kali。

*   优点：对设备没有局限、便于携带。
*   缺点：受到U盘性能的影响，在实际使用中比较卡。

##### 安装

我们首先在kali的官网下载下载U盘版的镜像文件。

![](../Images/ddf1750c61985200af49b3de6f557aeb.png)

下载文件完成后，打开镜像写入工具`Etcher`选择下载好的镜像文件，以及U盘后。点击`Flash`即可。

![](../Images/b48ced8fd559d68e7c111ea93da00031.png)制作完成后，通过启动主板的boot快捷菜单（不同的主板，快捷菜单可能不同。）

![](../Images/a2393d5331cb45d19daf6955d5b9b1d4.png)选择我们的U盘设备后，会出现kali的boot引导页面。

![](../Images/8dac1e1b2fb0088bbab3f60b43f8e873.png)![](../Images/18f504e972dc4ff5216e5b4f96c3dc7c.png)

# 在Windows主机安装

这种方法是我们最常用的方法之一。方便Windows和kali系统直接切换。通常我们是通过虚拟机软件进行安装的。常见的虚拟机有`VirtualBox` `VMware`。这里基于的安装方法我就不介绍了，说过很多次了，大家可以参考下面的文章。

*   优点：适合新手，尤其是刚开始学习Linux的同学。同时搞坏后不影响我们正常的windows系统。
*   缺点：因为电脑同时运行windows系统和Linux系统，对电脑的性能要求比较高。

# 树莓派安装

还是一样，我们只需下载树莓派的镜像文件。通过烧录工具将镜像文件烧录即可。

![](../Images/2c12105ad1b07e8d9eff5b88333acae0.png)

详细的安装和配置可以移步之前的文章

*   优点：便捷、小巧、可以随时随地，无时无刻”肾透“
*   缺点：贵！贵！贵！

![](../Images/722c8d19c2691ac76951303b5e886a23.png)

# 手机安装

没错，kali是可以手机安装的，但是由于支持的设备较少。安装的话我们只需下载镜像，然后给手机刷机即可。如常见支持的手机。

*   优点：比树莓派更加便捷，并且可以解决电源、网络等问题。
*   缺点：支持的手机机型比较少。
