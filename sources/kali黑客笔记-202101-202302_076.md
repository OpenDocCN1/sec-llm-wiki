# 环境

*   Python3.8
*   BeautifulSoup 依赖

在kali中以上环境都是默认安装好的。我们无需安装，如果你是其他环境，缺少的依赖可以`pip`命令安装即可。如

```

pip3 install BeautifulSoup
```
