# 配置Kali ssh服务

这里，我们以kali的ssh服务器为映射目标。当然也可以是其他服务器。默认情况下，kali的ssh服务是关闭的。

```
vi /etc/ssh/sshd_config

```

将#`PasswordAuthentication no`的注释去掉，并且将`NO`修改为`YES` ，kali中默认是yes 。将`PermitRootLogin without-password`修改为`PermitRootLogin yes`![](../Images/cd1269f1a9580a01bdaed71075666646.png)

启动`ssh`

```
service ssh start

```

用`xshell`登录kali

![](../Images/8e48de30a371fd70e2c808f46a0b7ec1.png)

# 下载Frp

`Frp`是一款开源的内网映射工具。跨平台类型比较多（如 `Linux` `Windows` 甚至路由器）这也是我选择它的原因之一。访问项目地址：下载适合你的架构类型。https://github.com/fatedier/frp/releases 如何知道 `VPS` 的处理器架构？在 `VPS` 上运行这个命令：

```
arch

```

如果输出`x86_64`则需要下载带`linux_amd64`的那个压缩包；

![](../Images/bd05ddddb7155308601dbe1db3b71b46.png)

# 配置服务端

在我们的云服务器中，解压及给予程序运行权限。

```

#解压文件tar -xzvf frp_0.45.0_linux_amd64

.tar.gzmv frp_0.45.0_linux_amd64

 frpchmod -R 777 frp

```

![](../Images/f6ff6b12a5120c8d759a7ad014f17557.png)

**🍉配置服务端的配置文件 `frps.ini`**

```
[common
]bind_port = 7000
token = 12345678

```

![](../Images/4646e998cb23d287505543a2907e82d6.png)为了简单化，其他乱七八糟的参数我就不配置了。头疼！

**🎃启动frp服务端**

```
./frps -c frps.ini

```

![](../Images/e693ea39c9d161f92b96a1a0f319fd1a.png)

# 配置客户端

这里我们以`kali`的`22`端口为列。用同样的方式，在`kali`中解压文件和给予文件运行权限。

![](../Images/fa6e63f81681639af6c0a7d420b9e01f.png)

**🚸配置客户端文件 **

**frpc.ini**参考如下：

```
[common
]server_addr = 43.143.165.54
 #你的公网IPserver_port = 7000
 #和服务端保存一致token = 12345678

 #和服务端保存一致ssh

]local_ip = 192.168.123.23
 # 要映射的设备IPlocal_port = 22
 #要映射的设备端口remote_port = 6000
 #公网端口
```

![](../Images/7e6d930c764ccc7626f46d323ddca94c.png)即映射效果为：`43.143.165.54:6000 == 192.168.123.23:22`

**🎲启动客户端**

```
./frpc -c frpc.ini

```

# 配置Windows10远程登录

还是一样的原理，我们只需在`frpc.ini`文件中继续添加下面参数即可。

```
[windows

]local_ip = 192.168.123.129
 # 要映射的设备IPlocal_port = 3389
 #要映射的设备端口remote_port = 6001
 #公网端口
```

**💌登录测试**

```
rdesktop 43.143.165.54:6001

```

# 其他

**❄️后台运行**

我们这样仅仅是在终端中挂起了一条命令。当命令关闭后，我们的连接也会中断。因此我们需要让程序后台运行。

```
nohup ./frps -c frps.ini & #服务端
nohup ./frpc -c frpc.ini & #客户端

```

**🐼防火墙**

我们需要在云服务器的安全组里面开启相关的端口。如`6000` `6001`等。如果没有安全的需要，我们可以开启全部的`TCP`。另外我们需要关闭系统的防火墙或者开启相应的端口

```
#关闭系统防火墙
systemctl stop firewalld.service
#或者开启相应的端口
firewall-cmd --zone=public --add-port=6000
/tcp --permanent
```
