LaZagne 是用于获取存储在本地计算机上的大量密码的开源应用程序。LaZagne 使用Python编写，有较好的跨平台性，因此分为Windows 版本、Linux 版本、Mac版本。和我们之前介绍过的miz类似，本文将为你介绍他的具体编译等事项。

实验环境

  • python3.10
  • Kali 2022

安装pyinstaller

PyInstaller 是一个在Windows、GNU/Linux、macOS等平台下，将python程序打包成为exe程序的包。他的安也很简单，执行下面命令即可。

python -m pip install pyinstaller

编译安装

#克隆项目
git clone https://github.com/AlessandroZ/LaZagne 
#安装依赖库
pip install -r requirements.txt

打包

pyinstaller --onefile -w lazagne.spec

效果

基本用法

抓取所有支持软件的密码

laZagne.exe all

抓取特定一类软件的密码：

laZagne.exe browsers

抓取特定一个软件的密码：

laZagne.exe browsers -firefox

把所有的密码写入一个文件：

laZagne.exe all -oN;laZagne.exe all -oA -output C:\Users\test\Desktop

安静模式（标准输出上不会打印任何内容）：

laZagne.exe all -quiet -oA

解密域凭据（要解密域凭据，可以通过指定用户 Windows 密码的方式来完成。）：

laZagne.exe all -password ZapataVive

总结

laZagne在编译过程中，坑比较多。填了一个又一个，当然在实际中的效果也是比较好的。
