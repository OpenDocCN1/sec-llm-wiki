> 在上一篇文章中，我们简单的学习了`Empire`框架的基本使用。本文我们将`Empire`中的命令进行了汇总。希望对你的学习有所帮助。

### 😘一级菜单目录

![](../Images/77c7f7da6495ae2c25dc7dbce46381b6.png)

| 🍀命令 || 🌈说明 |
| --- | --- |
| agents || 显示目前在线或离线的设备 |
| --- | --- |
| connect || 连接到empire |
| credentials || 向数据库中添加凭据 |
| disconnect || 断开当前的连接 |
| interact || 连接当前会话`interact <agent_name>` |
| listeners || 查看目前所有的监听配置 |
| plugins || 列出说要的插件信息 |
| resource || 运行empire的配置文件 类似`msfconfig -r`命令 |
| sponsors || 显示赞助过empire的名单 |
| usecredential || 查看和编辑凭据 |
| uselistener || 设置监听模块（`http` `meterpreter` `http_hop`等） |
| usemodule || 选择模块 |
| usestager || 设置生成shell的方式 （`exe` `dll` `bat`） |
| useplugin || 选择插件 |

### 🚢二级目录

这里我们重点将`plugins`进行单独的讲解。

| 🍉插件名称 || 🥳说明 |
| --- | --- |
| reverseshell\_stager\_server || 使用 msfvenom 反向连接，即与msf联动 |
| --- | --- |
| websockify\_server || 用于 TCP 代理/网桥连接应用程序的 `Websockify` 服务器。 |
| csharpserver || 基于C+的Empire代理 |
| socksproxyserver || 基于socks的服务器代理 |
| chiselserver || 大概时关于Linux和Mac主机的上线 |

另外由于`usemodule`这块内容比较多，我就不一个个说明了。在后面的文章中，我们找几个典型的列子单独讲解。
