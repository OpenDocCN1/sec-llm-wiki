# 疑问解答

1：利用WiFi钓鱼一定能破解WiFi吗？

答：不一定，全靠运气。

2：所有usb网卡都可以吗？

答：不行，需要支持的usb网卡。推荐芯号`3070`的。

3：抓不到`cap`包怎么办？

答：抓不到包是因为当前WiFi可能没有设备接入。建议用网高峰期抓包。

4：连接钓鱼WiFi后，钓鱼页面打不开。

答：一般情况是，都是可以打开的。出现这种问题一般是你的网卡问题。笔者在测试过程中，发现`8187`的网卡，虽然有热点。但是连接后无法打开钓鱼页面。换了`3070`的网卡后，正常访问。

# 填坑指北

**首先还是硬件方面：**

在前面的几篇文章中，我经常提到。对于WiFi钓鱼推荐网卡型号为`3070`。这里我们不再多说。  
![](../Images/cedf475a67a7e701a904c2cae71bd077.png)

**关于Fluxion的安装**

安装相对来说，还是很简单的，我们根据官方给出的安装文档安装即可。

```
**git** clone
 https://www.github.com/FluxionNetwork/fluxion.gitcd fluxion 
./fluxion.sh

```

然而大多数人在这里常常安装失败，问题在于你的源有问题。许多新手在安装kali时，会参考网上的文章修改kali的源。其实自`kali2020`开始后，kali的源无需修改，它会随着用户位置自动选择合适的源进行下载。

**模块检测**

安装完成后，初次会对当前系统进行模块检测。如需手动安装模块，只需要执行`apt-get install xxx`后跟缺失的模块。这里我们以`FLUXION 6.9`作为演示 在终端执行`./fluxion.sh`![](../Images/64a9d5dcb8fd46bd44c9dd16afd4816d.png)选`1`这时会分配你的无线网卡为监听模式，在新版中支持对`5G`WiFi的支持。![](../Images/c7a2ca6865db51aeb8d456a2861ed788.png)扫描周围的WiFi 按`ctrl+c`停止。![](../Images/37ba167e6c8016d35630e57708684b97.png)然而，在新版中最大的问题是在这里![](../Images/a2a8e331cb3da88016e8c4db089d9bd2.png)很多人在这里就不会搞了，在旧版中`fluxion`会自动抓取WiFi的包，而新版中放弃了这个功能，需要我们收到抓。这门这里只需要填写我么抓到包的路劲即可。如`/root/66.cap`其他的就和旧版一样了。

# 总结

钓鱼成功率相对来说还是比较低的。最主要的原因之一就是WiFi信号问题。因为USB无线网卡的发射功率有限。从你笔记本发出的WiFi信号穿墙到邻居家，最多就是两格信号。如果在周围WiFi较多的情况下，我们的AP肯定排在最底了。因为大多数人发现WiFi不能连接时，一般会选择重启路由。因此，这`里我们仅供技术领域的研究和学习，请勿用于非法攻击。`
