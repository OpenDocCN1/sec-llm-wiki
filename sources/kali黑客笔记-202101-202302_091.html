更新日志

🎉SOCKS5 代理服务器支持

此版本实现了一个流行的功能请求——对SOCKS5 的支持。与其完全替换SOCKS4a，在启动 SOCKS 时选择是使用SOCKS4a还是SOCKS5。

🎃Beacon 进入睡眠状态调整

在此版本中，Beacon 已经过重新设计，以添加对您在 BOF 中可以在睡眠中执行的所有操作的支持。您现在不仅可以使用自己的 sleep 函数，还可以调用动态函数 (LIBRARY$function) 和 Beacon API 函数

🏀窃取令牌更新

steal_token函数已更新，使其能够从以前无法访问的进程中窃取令牌。Steal Token对话框已更新，允许您设置访问掩码（并覆盖默认值）。这适用于在打开对话框之前同时选择了单个进程和多个进程的情况。

🎯剪贴板内容获取模块更新

如果剪贴板上有文本，则返回并显示；如果没有，将显示一个错误，通知您剪贴板内容不是基于文本的。如果剪贴板内容超过204800字节，则会返回错误。

⚽用户界面更新

此版本对客户端 UI 的外观和感觉进行了更新。并且加入了黑暗主题。

🔔睡眠时间跟踪

睡眠时间跟踪通过记录每个Beacon 的睡眠时间并将其显示在Beacon表视图的新列中来工作。此信息在团队服务器重新启动之间保留，因此它应该始终可用。

工具栏和菜单更新

我们还更新了客户端工具栏上的图标，并删除了一些不太受欢迎的功能的工具栏按钮。与此更改相关的是，主菜单已重新组织，将菜单扁平化并将一些选项移动到更有用和更直观的位置。

🎻进程列表显示更新

ps命令的输出已得到增强，以解决父/子关系并将进程列表显示为树视图，而不是旧的平面版本。Beacon进程显示为黄色。
