VMware Workstation Pro 是将多个操作系统作为虚拟机 (VM) 在单台 Linux 或 Windows PC 上运行的行业标准。为任何设备、平台或云环境构建、测试或演示软件的 IT 专业人员、开发人员和企业都可以信赖 Workstation Pro

容器和Kubernetes支持

  • 使用vctl CLI 构建/运行/拉/推容器映像
  • 支持在Workstation Pro顶部运行的KIND kubernetes集群

新操作系统支持

  • RHEL 8.2
  • Debian的10.5

沙盒图形
