> 今天给大家介绍一款腾讯的开源项目`GFPGAN`-人脸修复工具。相对部署比较简单，可玩性比较高。一起看看吧！

### 环境

*   Python >= 3.7
*   PyTorch >= 1.7

### 部署项目

下载项目

```
proxychains4 git clone
 https://github.com/TencentARC/GFPGAN.git 
```

为了加快下载速度，我这里开启了代理。

![](../Images/b02cc6e7f1f67e624435043bc1fc344b.png)

### 安装依赖环境

```


pip install basicsr
```

![](../Images/fceec44c718650b8ca1f248d16af2d2d.png)

安装gfpgan

```

python setup.py develop
```

### 下载预训练模型

**GFPGANv1.3.pth**

> https://github.com/TencentARC/GFPGAN/releases/download/v1.3.0/GFPGANv1.3.pth

 具体最新模型链接前往GitHub查看  

下载好的文件放在`\GFPGAN\experiments\pretrained_models`

![](../Images/19fdbd896167acc71706a98beb681c94.png)

### 帮助

```


Usage: python inference_gfpgan.py -i inputs/whole_imgs -o results -v 1.3 -s 2 [options]...help

for background sampler, 0 for

 no tile during testing. Default: 400
```

### 示例

```

python inference_gfpgan.py -i inputs/whole_imgs -o results -v 1.3 -s 2
```

`inputs/whole_imgs` 为原始图片位置 生成文件夹为`results`

![](../Images/2f687aae63736e8d58dbda8c100c9599.png)当然，如果你觉得太麻烦，可以使用在线项目， 项目地址 

> https://app.baseten.co/apps/QPp4nPE/operator\_views/RqgOnqV
