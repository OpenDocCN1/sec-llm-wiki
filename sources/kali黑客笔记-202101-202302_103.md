> 域名信息收集，是我们“肾透”中最重要的一环。好比是进入大门的钥匙，一把锁不只仅有一把钥匙。当我们掌握了其中任意一把，开锁也就很简单了。

本文将为你介绍在kali中常用的子域名信息收集工具。排名不分先后！

### 🚀TheHarvester

`TheHarvester`能够收集电子邮件账号、用户名、主机名和子域名等信息。它通过`Google`、`Bing`、`PGP`、`LinkedIn`、`Baidu`、`Yandex`、`People123`、`Jigsaw`、`Shodan`等公开资源整理收集这些信息。![](../Images/e4a020019ee1040b129c958b0aa412b5.png)

通过百度查找域名`bbskali.cn`的相关信息

```
theHarvester -d bbskali.cn -l 500
 -b baidu
```

![](../Images/1401cf7b0510ea2751c2f64b3e6c9070.png)

### 🌍dnsmap

`dnsmap`利用dns解析记录来获取目标解析过的域名。同类型的工具还有`fierce`，使用方法和他一样，这里我就不说了。

```
dnsmap bbskali.cn

```

![](../Images/8a6b0dea97c8086e6113073b3bbb9f89.png)

### 🧺burpsuite

没错，神器burp也可以获取目标中可能存在的子域名。但是他所用到的原理类似蜘蛛爬虫，将当前浏览网页中的所有url连接全部整理，再看看有没有和子域名一样的就是了。相对来说，效率比较低。

![](../Images/d06df14e0dbc25e0eba3097edfb93fb7.png)

以上几款工具都是kali中默认自带的。比较方便，平时的使用应该足够了。但也有很多缺点，如维护周期短、效率低、不够强大。所以除了这些工具外还有很多优秀工具。下面给大家进行简单的介绍。

*   支持子域爆破
*   支持子域验证
*   支持子域爬取
*   支持子域置换
*   支持子域接管
*   体验良好**安装：**

### 🚖Sublist3r

和上一个工具一样。Sublist3r 是一个基于 `python` 开发的工具，旨在使用 OSINT 枚举网站的子域。它可以帮助渗透测试人员和 挖洞大佬 收集和收集他们所针对的域的子域。

**安装**

```
git clone
 https://github.com/aboul3la/Sublist3r.gitpip3 install -r requirements
.txtpython3 sublist3r.py
 -h
```

![](../Images/665bda89a624ec5ba6a10adee803253c.png)

**使用**

```
python3 sublist3r.py -d bbskali
.cn
```

### ❄Subfinder

`Subfinder`是基于GO语言开发的子域名扫描工具。可以通过使用被动的在线资源来发现网站的有效子域。它具有简单的模块化架构，并针对速度进行了优化。**安装**

```
go install
 -v github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest
```

修改接口api`$HOME/.config/subfinder/provider-config.yaml`添加各个平台的`api key`(改成你自己的)

### 🧯总结

以上便是我们常用的几款子域名收集工具。当然除了这几款工具外，应该还有更优秀的工具。仁者见仁智者见智这里也就不多说了。当然每款工具都有自身的优点和缺点，适合自己的哪一款才是最好的。
