> 在我们的电脑上存放了很多敏感的文件。如浏览器存储的网站登录密码。或是为了防止丢失，将密码存放到了txt文件中。而攻击者如果拿到了这些文件，造成的后果极其严重。

### 🌵实现原理

无论是windows还是Linux系统，攻击者使用系统命令来搜集查找一些当前机器可能存在的敏感文件信息。从而扩大战果！如下，我们利用msfconsole获取到了目标系统的权限。便可以利用windows下的shell命令进行搜索文件。

![](../Images/23b9e8e846e60c711a4de92c9a434051.png)

### 🧻windows环境

**根据文件名搜索**

利用`dir`命令查找当前目录下文件名称中包含（`user`,`pass`,`username`,`password`,`config`.）关键字的文件。

```
dir /b /s user.*,pass.*,username.*,password.*,config
.*
```

![](../Images/fb75ab80eea17fc35a9c7ab28c58bee7.png)

**根据文件内容搜索**

利用`findstr`命令查找当前目录下指定类型（`.txt`）文件内容中包含指定敏感字符(`root`,`username`,`password`,`账号`,`密码`)的文件。

```
findstr /F:"root" /F:"user" /F:"pass" /F:"账号" /F:"密码"
 /si *.txt
```

![](../Images/6b4dcbd6a9381173712c746dae60c060.png)

### 🌈Linux环境

**根据文件名称搜索**

利用`find`命令查找当前目录下文件名称中包含（```user``,pass```,`config`）关键字的文件。

```
find ./ -type f -iname "*config*" -or -name "*pass*" -or -name "*user*"

```

![](../Images/3e5001052a752be70d8c54a01f7af268.png)

**根据文件内容搜索**

利用`find+grep`命令组合查找当前目录下指定类型（.txt）文件内容中包含指定敏感字符(`admin`,`root`,`user`,`pass`)的文件。

```
find -type f -iname '*.txt'|xargs grep -i -E 'admin|root|pass|user'

```

![](../Images/08df5c78abd92ebd04a787a788a19edd.png)

### 🚢总结

以上便是我们常用的获取敏感信息的方法。因而我们在平时工作中，一定要对敏感文件特殊保护。
