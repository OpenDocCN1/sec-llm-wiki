### 📺安装

这里我们以kali为列 从压缩包中解压文件`metasploit-latest-linux-x64-installer.run`（文末提供下载）复制到Kali中。选择文件点击右键`执行`

![](../Images/046dcc38beed8cd276b06811376b3e9f.png)

接受条款 下一步

![](../Images/06088c361fb125befe24fb45022fdf99.png)

选择安装目录(默认`/opt/metasploit`),下一步。

![](../Images/1c6e5e54d5461f21b29580c08d9991a6.png)

`Yes`,下一步

![](../Images/bd0050ca39a55daef661a4ab2e2eba8e.png)

设置SSL端口(默认`3790`),下一步(一般默认就行了)

![](../Images/4cc1bfbc002aa84a1a839e8542405f2a.png)

设置服务名称

![](../Images/71933dd4e220be12df91e15834c31b87.png)

设置完成后，进入安装界面。

![](../Images/646382353e34e0d3dac4264c14b8e6c2.png)

安装完成后，访问`https://localhost:3790`

![](../Images/d4cf3636d84612c136686c1dae972b9d.png)输入你喜欢的用户名密码进行注册,注意,密码需要大小写字母+数字+特殊字符+大于8位. 然后点击右下角的`Create Account`创建用户即可。

![](../Images/a83ad6f45a438889615408b9a0b24455.png)

### 🎯破解metasploit

将压缩包中的文件执行下面命令进行复制。

```
cp 
application.html.erb /opt/metasploit/apps/pro/ui/app/views/layouts/application.html.erbcp 
application_controller.rb /opt/metasploit/apps/pro/ui/app/controllers/application_controller.rbcp
 license.rb /opt/metasploit/apps/pro/ui/app/models/license.rbcp
 tasks.rb /opt/metasploit/apps/pro/engine/app/concerns/metasploit/pro/engine/rpc/tasks.rb
```

重启`metasploit pro`

```
systemctl restart metasploit

```

启动msfpro

```
sudo
 msfpro
```

`Metasploit pro`还有一个`Web UI`,它可以通过`https://localhost:3790`访问
