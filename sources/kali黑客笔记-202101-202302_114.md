### 特性

*   检测速度快。发包速度快; 漏洞检测算法效率高。
*   支持范围广。大至 `OWASP Top 10`通用漏洞检测，小至各种 CMS 框架 POC，均可以支持。
*   代码质量高。编写代码的人员素质高, 通过 `Code Review`、单元测试、集成测试等多层验证来提高代码可靠性。
*   高级可定制。通过配置文件暴露了引擎的各种参数，通过修改配置文件可以客制化功能。
*   安全无威胁。`xray`定位为一款安全辅助评估工具，而不是攻击工具，内置的所有 `payload` 和`poc`均为无害化检查。

![](../Images/b3d57c5f24757427dfc387519dab6f5a.png)

### 下载安装

`xray`跨平台支持，根据我们所需，按系统下载即可。需要注意的是`xray`并不开源。这里我们以kali为例。访问项目地址：https://github.com/chaitin/xray/releases

![](../Images/9f32f493cdaca5839850fab5e2eac38b.png)选择对应的版本 使用 `unzip`命令解压，就可以得到`xray_linux_amd64` 文件了。

然后运行 `./xray_linux_amd64` 即可查看 `xray`的版本号。

![](../Images/18b667623cd3623bb9cefd0bfdaad1f6.png)

### 使用代理模式漏洞扫描

代理模式下的基本架构为，扫描器作为中间人，首先原样转发流量，并返回服务器响应给浏览器等客户端，通讯两端都认为自己直接与对方对话，同时记录该流量，然后修改参数并重新发送请求进行扫描。

#### 生成https证书

对于https网站，我们必须先要配置证书。不然无法代理（和burp类似） 运行`./xray_linux_amd64 genca` 即可生成 ca 证书，保存为 `ca.crt`和 `ca.key`两个文件。

![](../Images/79dcc2d7f1ad793ee87a8bee97cb3744.png)kali中默认的是FireFox 浏览器，我们在FireFox 浏览器中导入证书。

![](../Images/ea2d0bdc86eb02124c96683b8c11f399.png)![](../Images/aaa9a594934210025c1ef47d8d07b4a8.png)

#### 启动代理

在扫描之前，我们还需要做一些必要的设置

第一次启动 xray 之后，当前目录会生成 `config.yml`文件，选择文件编辑器打开，并按照下方说明修改。

mitm 中 `restriction` 中 `hostname_allowed` 增加 你的目标域名。

![](../Images/f3da5dc30712a53edaaaa01d9e6b05b8.png)

#### 配置浏览器的代理

和burp一样，设置代理。端口随意。

![](../Images/dd92b361a7d88255699705c99c212ceb.png)

#### 开始扫描

```

./xray_linux_amd64 webscan --listen 127.0.0.1:7777 --html-output xray-testphp.html
```

执行上诉命令后，我们在浏览器中访问目标域名，这时在`xray`中便可以获取到数据。

![](../Images/93bb02e49a6052d1fbe3be4ed1228a3a.png)

完成后，我们可以查看扫描报告

![](../Images/7cb3fb0de9e91ac24f57b07815b2aa36.png)

### 对目标爬虫

```

./xray_linux_amd64 webscan --basic-crawler https://bbskali.cn/ --html-output xray-crawler-testphp.html
```

![](../Images/c473bbc2341dda3ce83f68d32eceb47d.png)

### 使用 Burp 与 xray 进行联动

首先 xray 建立起 webscan 的监听

![](../Images/f65797536b0f1e72e9ec78144db498b5.png)进入 `Burp`后，打开 `User options` 标签页，然后找到 `Upstream Proxy Servers`设置。

点击`Add`添加上游代理以及作用域，`Destination host`处可以使用`*`匹配多个任意字符串，`?`匹配单一任意字符串，而上游代理的地址则填写`xray` 的监听地址。

![](../Images/a15cfaf5f3a2723e68d2cd2e31790e28.png)

![](../Images/ea199bfe4842814761e3c57520647af1.png)这样两者便可以保持联动了。
