🚧项目介绍

evillimiter用于限制和监视连接到网络的设备的带宽（上传/下载）的工具，无需物理或管理访问权限。采用 ARP 欺骗和流量整形来限制网络上主机的带宽。

🌊实验环境

  • Kali2022
  • Python3

🚀下载与安装

evillimiter的安装很简单，我们直接从github上面克隆项目即可。（今天好像抽风了，访问不了。我用gitee上面的项目，原理是一样的。）

git clone https://github.com/bitbrute/evillimiter.git
cd evillimiter
sudo python3 setup.py install

🌈运行

#执行命令
evillimiter
#或者
python3 bin/evillimiter

🏴‍☠️使用文档

命令说明
-h显示列出所有命令行参数的帮助消息
-i指定网络接口
-g指定网关 IP 地址
-m指定网关 MAC 地址
-n指定网络掩码
scan扫描局域网所有设备
hosts列出所有设备
limit对局域网设备限速
block指定设备禁止上网
free解除限制

⚽牛刀小试

扫描所有设备

scan

如上，我们扫描到了6台设备。显示扫描到的设备

hosts --force

对192.168.123.22 这台设备限速

limit 2 100kbit

这里的2为对应设备的id，100kbit为当前的网速。当然这里是对上行和下行都限制了。也可以单独限制。如下，身为卡迪拉克车主的我，已经不能正常刷短视频了。

🎯总结

这款工具相对来说比较好玩，当我们想限速，但又怕在路由器中设置参数而影响舍友和谐的关系。因此在无需硬件的情况下，我们便能轻而易举的对目标进行限速。但是也有缺陷，它只能针对IPv4设备限速，如果是ipv6则不行。
