### 🚧项目介绍

`evillimiter`用于限制和监视连接到网络的设备的带宽（上传/下载）的工具，无需物理或管理访问权限。采用 ARP 欺骗和流量整形来限制网络上主机的带宽。

### 🌊实验环境

*   Kali2022
*   Python3

### 🚀下载与安装

`evillimiter`的安装很简单，我们直接从github上面克隆项目即可。（今天好像抽风了，访问不了。我用gitee上面的项目，原理是一样的。）

```

```

### 🏴‍☠️使用文档

| 命令 || 说明 |
| --- | :-: |
| \-h || 显示列出所有命令行参数的帮助消息 |
| --- | :-: |
| \-i || 指定网络接口 |
| \-g || 指定网关 IP 地址 |
| \-m || 指定网关 MAC 地址 |
| \-n || 指定网络掩码 |
| scan || 扫描局域网所有设备 |
| hosts || 列出所有设备 |
| limit || 对局域网设备限速 |
| block || 指定设备禁止上网 |
| free || 解除限制 |


![](../Images/ec29a265d90024e739ddf0e2eb39a9ac.png)

对`192.168.123.22` 这台设备限速

```
limit
 2 100kbit
```

这里的`2`为对应设备的id，100kbit为当前的网速。当然这里是对上行和下行都限制了。也可以单独限制。如下，身为卡迪拉克车主的我，已经不能正常刷短视频了。

### 🎯总结

这款工具相对来说比较好玩，当我们想限速，但又怕在路由器中设置参数而影响舍友和谐的关系。因此在无需硬件的情况下，我们便能轻而易举的对目标进行限速。但是也有缺陷，它只能针对`IPv4`设备限速，如果是`ipv6`则不行。
