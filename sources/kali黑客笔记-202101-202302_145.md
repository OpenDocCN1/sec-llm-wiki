> 我们在利用kali工作和学习时，常常由于网络原因导致很多项目回出现失败。这时我们需要给我们的网络进行代理，便可以解决此问题。

### 🍇关于

`Clash` 是由`Dreamacro` 开发的，是一个使用`Go`开发的、无需服务器和虚拟主机并且支持很多种协议。

![](../Images/048f26fff8fe91bf5188337b811d4b81.png)

### 🍓在kali中安装

首先访问项目地址：

> https://github.com/Fndroid/clash\_for\_windows\_pkg/releases

选择合适的版本，我这里以`1.7.1`为例。

![](../Images/0ba1726e7fc0c5dfc47102fa7070cb66.png)执行下面命令直接下载

```

wget -O clash.gz https://github.com/Dreamacro/clash/releases/download/v1.7.1/clash-linux-amd64-v1.7.1.gz
```

**PS**如果下载比较慢，建议使用迅雷下载。下载完成后，执行下面命令

```
#赋予权限
chmod +x clash-linux-amd64
#运行
./clash
-linux-amd64
```

首次运行后会在`/root/.config/clash`目录下生成两个配置文件。在这两个文件中，最重要的是`config.yaml`文件，这里面是你所有的代理信息。然后从服务商处获取订阅链接,获取方法自行百度很简单的，由于某些原因我这里就不提了。修改完成后保存`config.yaml`文件。然后重新运行

```
./clash
-linux-amd64
```

打开浏览器，输入`http://clash.razord.top/#/proxies`进行clash的配置

![](../Images/46bf546e01c60a7b6918373aa77a6e84.png)端口就填`yaml`配置文件中的`external-controller`后的端口

![](../Images/0cfff3043cb2411d7531d7a06295f61b.png)

最后，在`firefox`中设置你的代理

![](../Images/52907a8d85bb857559c4be4e043cbb24.png)

这样便完成了。
