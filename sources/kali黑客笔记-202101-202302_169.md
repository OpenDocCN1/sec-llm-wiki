> 当你为网红小姐姐一掷千金，刷了几个`W`。结果对方是个抠脚大汉，你的心情会是怎样的？事情的起源是这样的，某位粉丝留言说自己在某平台给小姐姐刷礼物，刷了几个`W`，感觉自己被骗了，让我帮帮他，于是便有了这篇文章！

### 🌈思路

我们可以给对方生成一条链接，诱骗打开！当打开链接后，便可以获取对方手机的信息，如摄像头，相册文件，键盘记录等等。而利用Android肾透神器`ShotDroid`便能很方便的解决这个问题！

### 🐼ShotDroid 功能

*   隐藏安卓应用。
*   自定义文件目录。
*   基于`Android`的键盘记录
*   利用`html`模板获取面部网络摄像头。

### 🍔安装

首先安装依赖环境

```
apt install zenity xterm

```

![](../Images/6319c76ff198f6e435513f632862e51a.png)

**安装ngrok**

`ngrok`是一款优秀的内网映射工具，可以方便的让不在同一局域网内的设备进行访问。

```
curl -s https://ngrok-agent.s3.amazonaws.com/ngrok.asc | sudo tee /etc/apt/trusted.gpg.d/ngrok.asc >/dev/null && echo "deb https://ngrok-agent.s3.amazonaws.com buster main"
 | sudo tee /etc/apt/sources.list.d/ngrok.list && sudo apt update && sudo apt install ngrok
```

由于网络原因 安装过程可能有点慢

⚽配置ngrok

登录ngrok的官网进行注册ngrok.com 注册完成后，访问`https://dashboard.ngrok.com/get-started/your-authtoken`获取api

![](../Images/f40283a4b687a571645822383b98d9e3.png)

然后再kali中执行下面命令，添加密匙

```
ngrok config add-authtoken
 2DEuwA***************1eRSym
```

![](../Images/1d83d4915dd2341aa0bb998a0422a1df.png)

### 🛺启动

```

```

![](../Images/6d2e965304f39d79f7582307aacb2e64.png)

**参数说明：**

*   Android Files   获取手机文件
*   Android Keylogger  获取键盘记录
*   Take Face Webcam   获取摄像头

### 💌获取手机文件

由于部分机型对手机权限的问题，有可能会失败。最好是`root`后的手机测试。![](../Images/0b3abdc7874046fac6f181669fe0d053.png)

### ♣️获取摄像头

![](../Images/ac65c19914197dc4d60cfb6e54c2a88c.png)

注意，生成的`ngrok`链接不能复制，访问`http://127.0.0.1:4040`便可以复制了

![](../Images/3aafdfe2bd9e8178b19aa79af43b29c6.png)

访问链接后，效果如下,当然页面你可以自定义！![](../Images/f0222f1bda5a76a740b80fe8aecca783.png)

允许摄像头后，照片会保存！![](../Images/2576dca7003658bed6280083a3fb84df.png)
