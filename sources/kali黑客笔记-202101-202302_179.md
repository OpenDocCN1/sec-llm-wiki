> 对于光猫超级管理员密码的破解，在前面的文章中我也写过。因家中有个`华为HN8145V`的光猫，闲来无事也尝试倒腾下超级管理员密码的破解。

![](../Images/fd3931510280577851a1d52888b50cc5.png)

### 🌈环境

*   光猫型号: 华为 `HN8145V`
*   硬件版本：`1950.A`
*   软件版本：`V5.19.C30S010`
*   电脑一台，网线一根。

### 🐼登录shell

首先下载好破解工具，下载地址：（`阅读原文`开始下载）

首先拔掉光猫电源，再拔下光猫光纤线，再插上电源线等待重启，开机之后通过网线或者WI-FI连接光猫打开我发的合集中的ONT使能2.0工具。![](../Images/9ef75ffa92c8129bf37588a5d706ac02.png)

点击启动后，等待右侧出现成功字样或者等左下角的“当前成功总数”显示为1及以上字样后，点击停止，关闭软件，手动重启光猫。做到这一步，我们就已经补全了shell。

### 🎉检查shell

以防万一，我们检查一下，打开cmd，输入如下命令（telnet请提前开启，如果嫌麻烦，可以利用kali或Linux主机直接搞。）

```
telnet 192.168.1.1

```

输入用户名密码`root`:`adminHW`

登入后继续输

```
su

cd /mnt/jffs2

/
```

显示如下则说明`shell`补全成功![](../Images/3c02a0b38a66626c1cdfbe657615cbbd.png)

### 💯获取超级密码

```
cp /mnt/jffs2
/hw_ctree.xml /mnt/jffs2/mycfg.xml.gzcd /mnt/jffs2
aescrypt2

 1 mycfg.xml.gz temgzmycfg
.xmlrm 
mycfg.xml
```

当然也可以双击运行一键查询超密.bat![](../Images/0f91da857f8f69c34d551c32a4849499.png)

把`password`的`""`里面的代码复制出来放到`huawei.exe`，将复制的内容粘贴进`密文解密`下的文本框，点击`$2解密`，即可看到超级密码。
