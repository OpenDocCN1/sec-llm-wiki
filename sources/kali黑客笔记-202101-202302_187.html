如何拥有公网IP的kali进行肾透呢？

在实际操作中，我们的kali都是安装在虚拟机或者物理机、树莓派中。虽然用起来比较方便，但是网络只有运维商分配的网络IP。在很多情况下我们需要公网IP，一般都是通过frp ngrok内网映射实现的。那么有没有更加简单的方法呢？

🌈安装docker

这里我们需要购买一台VPS,笔者用的是阿里的轻量服务器。也很便宜，用完就扔的哪种！

yum -y install docker

启动docker

systemctl start docker

🐼搜索kali的镜像

docker search kali

拉取kali的镜像

docker pull kalilinux/kali-last-release

运行镜像

docker run -t -i kalilinux/kali-last-release

这样我们便利用docker运行了kali的镜像。需要注意的是docker中的kali几乎没有什么工具，需要什么工具需要自己手动去安装。

🎉总结

docker能较为方便的解决kali没有公网IP的问题。同时在我们执行完肾透后，可以直接销毁镜像。但是也有缺点，docker中的镜像也是阉割版的kali，很多工具集是没有的，需要我们手动去安装。显得略有些麻烦。
