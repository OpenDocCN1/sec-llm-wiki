# 如何拥有公网IP的kali进行肾透呢？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxMzIwNTY1OA==&mid=2247489504&idx=1&sn=f9b1a9ba71d73afff57f1efb247d5e53&chksm=c1006715f677ee039716ccc669d64b954df74198c46a66c45f0fd0d78df55f0409dcef2ae3b2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkxMzIwNTY1OA==&mid=2247489504&idx=1&sn=f9b1a9ba71d73afff57f1efb247d5e53&chksm=c1006715f677ee039716ccc669d64b954df74198c46a66c45f0fd0d78df55f0409dcef2ae3b2&scene=27#wechat_redirect)

> 在实际操作中，我们的kali都是安装在虚拟机或者物理机、树莓派中。虽然用起来比较方便，但是网络只有运维商分配的网络IP。在很多情况下我们需要公网IP，一般都是通过`frp` `ngrok`内网映射实现的。那么有没有更加简单的方法呢？

### 🌈安装docker

这里我们需要购买一台VPS,笔者用的是阿里的轻量服务器。也很便宜，用完就扔的哪种！

```
yum -y install
 docker
```

![](../Images/ba21a146c81038308e2a70859e204915.png)启动docker

```
systemctl
 start docker
```

### 🐼搜索kali的镜像

```
docker
 search kali
```

![](../Images/34dc3e6c85361962acf6522dad4c4497.png)拉取kali的镜像

```
docker pull kalilinux/kali-last-release

```

![](../Images/ecab811e4509f8692c79dedd1e09d67b.png)运行镜像

```
docker run -t -i 
kalilinux/kali-last-release
```

这样我们便利用docker运行了kali的镜像。需要注意的是docker中的kali几乎没有什么工具，需要什么工具需要自己手动去安装。

### 🎉总结

docker能较为方便的解决kali没有公网IP的问题。同时在我们执行完肾透后，可以直接销毁镜像。但是也有缺点，docker中的镜像也是阉割版的kali，很多工具集是没有的，需要我们手动去安装。显得略有些麻烦。
