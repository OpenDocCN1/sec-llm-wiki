### 🌈LaZagne介绍

> `LaZagne` 是用于获取存储在本地计算机上的大量密码的开源应用程序。`LaZagne` 使用`Python`编写，有较好的跨平台性，因此分为`Windows` 版本、`Linux` 版本、`Mac`版本。

### 🎉编译和免杀

#### 01 安装python环境

这个自行百度，相对于java环境，python就很简单了。因为kali中已经默认安装好了python3.8这里我也就跳过了。

#### 02安装pyinstaller

```
python3 -m pip install
 pyinstaller
```

![](../Images/07def39397a883a7b99e8edcbdff4a93.png)

克隆`git`项目到本地

```
git clone
 https://github.com/AlessandroZ/LaZagnecd

pip install -r 
requirements.txt
```

![](../Images/aad0cf3a442cc9a312c569b4328a3fcf.png)进入`Linux`目录后，执行下面命令开始编译

```

```

**实在不行就用编译好的吧，我编译了好几次才成功。各种环境不兼容。**

### 🥳使用

抓取所有支持软件的密码：

```
laZagne.exe all

```

![](../Images/1253251ab3495b18e9fae0fce2b941ca.png)

如上，抓取了所有连接过本机的`WiFi`密码。抓取特定一类软件的密码：

```
laZagne
.exe browsers
```

抓取特定一个软件的密码：

```
laZagne.exe browsers -firefox

```

把所有的密码写入一个文件：

```
laZagne.exe all -oN;laZagne.exe all -oA -output C:\Users\test
\Desktop
```

安静模式（标准输出上不会打印任何内容）：

```
laZagne.exe all -quiet
 -oA
```

解密域凭据（要解密域凭据，可以通过指定用户 Windows 密码的方式来完成。）：

```
laZagne.exe all -password
 ZapataVive
```

当然，以上运行的前提是超级用户或者`root`用户才可以。
