🍀前言

Netdiscover是一种终极扫描工具，用于获取网络中实时主机的内部IP地址和MAC地址。Netdiscover是Kali Linux中预安装的工具，如果您使用的是Kali Linux，那么您不需要安装netdiscover。毫无疑问，nmap是扫描网络的最佳工具，但Netdiscover也是查找内部IP地址和MAC地址的最好工具。

🎉Netdiscover模式

Netdiscover是一个非常有吸引力的工具，用于发现有线或无线网络上的主机。它可以在主动和被动模式下使用。

主动模式：它向主机发送请求以获取信息。被动模式：以静默模式工作，称为被动模式或监听模式。

🥳安装

#unbunt/debian系列
apt-get install netdiscover
#centos
yum install netdiscover

🍔帮助

netdiscover -h

🛀示例

查看局域网内的设备IP

netdiscover -i eth0 -r 192.168.123.0/24

参数说明：

-i:网卡设备（通过ifconfig命令查看本机的IP信息）

-r:局域网网关信息。

🎲后记

netdiscover肯定和神器nmap无法相提并论。但是netdiscover也有它自身独特的优势，比如针对局域网的扫描比较快速准确，并将结果以列表的形式展现出来。而nmap相对来说比较耗时。
