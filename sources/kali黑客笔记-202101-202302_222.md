> 骑士人才系统是一项基于PHP+MYSQL为核心开发的一套免费 + 开源专业人才招聘系统。为个人求职和企业招聘提供信息化解决方案, 骑士人才系统具备执行效率高、模板切换自由、后台管理功能灵活、模块功能强大等特点，自上线以来一直是职场人士、企业HR青睐的求职招聘平台。2020年年底被爆出模板文件存在注入可通过写木马进日志的方法包含日志Getshell。

### 🍄漏洞复现

```
#访问url

#构造POST：
$_GET
[‘id’]”/>
```

![](../Images/f4f0fdb121fd6d7647f02e86fa63fddd.png)

报错了，是正常的，就是通过执行语句出错来将我们的PHP代码插入到报错日志中 日志默认存放在`\data\Runtime\Logs\Home\`下，文件名以当天日期命名![](../Images/6003ec150159523dadbe9dbf597c6321.png)可以看到，当前的post请求已经写到了日志文件中。![](../Images/080c3b58aabb4ffafc2481c68acb1fbc.png)  

接下来继续通过模板文件来包含进日志

```

#POST请求


```

此时在根目录下生成了`shell.php`![](../Images/f62b1b155f875c589a3baf53c95d4819.png)
