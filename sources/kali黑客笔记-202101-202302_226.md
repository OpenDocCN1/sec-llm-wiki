### 🚢什么是KMS

> `Key Management Service`（简称:KMS），这个功能是在Windows Vista之后的产品中的一种新型产品激活机制，目的是为了Microsoft更好的遏制非法软件授权行为(盗版)。本文将介绍如何搭建`KMS`来激活你的Windows。

KMS激活有两种方法，分别为`vlmcsd`和`py-kms`，本文使用vlmcsd进行搭建。

### ⚽为什么要自建KMS激活服务？

虽然现在网络上已经涌现了大批的激活工具如小马激活，暴风激活。但是存在许多不安定因素，例如后门或者病毒等，会造成较大的安全隐患，而自己搭建Kms激活服务则可以避免这类问题~

**注意**只能激活VL版本的Windows VL，就是VOL，Volume Licensing for Organizations的缩写，中文翻译为团体批量许可证

### 🏀环境准备

*   系统：CentOS 7.5

### 🏓激活

首先使用下面命令确认机器的CPU架构

```

cat /proc/cpuinfo
```

![](../Images/cb486dc1e6bd9b0e3f4ce3bccf4be48a.png)

cpu架构

然后从Github下载项目文件

```


yum -y install wget #解压安装包


```

如果你机器的架构为Intel，cd到如下目录，否则的话需要在`binaries`目录内找到对应你机器CPU架构的目录

```
cd
 binaries/Linux/intel/static
```

### 🎲启动服务

```

 ./vlmcsd-x64-musl-static
```

如果你的机器不是`64`位系统，则需要内找到对应系统位数的可执行文件来运行 因为vlmcsd运行后会占用`1688`端口，请在防火墙放行`1688`端口，或者关闭防火墙，所以我们可以输入以下命令查看是否成功启动：

```

netstat -lnp
```

### 💍激活

以管理员身份运行`CMD`

```


slmgr /skms 你服务器的IP或者域名
```

到这你的KMS服务应该可以正常使用了，激活周期为`180`天，到期后如果你的KMS服务器还在运行，Windows将自动进行激活。
