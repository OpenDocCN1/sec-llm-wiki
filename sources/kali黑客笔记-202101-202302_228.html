CHAOS 是一款用golang编写的Windows远控程序，它可以生成payload和远程控制Windows系统。另外，CHAOS得益于go语言，因而自带免杀。当生成客户端被病毒库标记后，也可以使用更换密匙的形式，脱离病毒库的锁定！本文将详细介绍它的安装和使用。

01 安装配置

🌈常规安装启动

# 安装go环境
sudo apt install golang git -y
# 克隆项目
$ git clone https://github.com/tiagorlampert/CHAOS
$ cd CHAOS/
# 运行
$ PORT=8080 DATABASE_NAME=chaos go run cmd/chaos/main.go


需要注意的是，安装go环境需要占用700M左右的空间。安装过程和自身网速有关。当然，如果你觉得安装比较麻烦，可以试试利用docke

🍓docke启动

docker run -it -v ~/chaos-container:/database/ -v ~/chaos-container:/temp/ \
  -e PORT=8080 -p 8080:8080 tiagorlampert/chaos:latest

运行后访问http://localhost:8080并使用默认用户名和密码admin登录。

03 后记

CHAOS最大的优势在于将所有的操作通过WEB端来实现，不需要你记住很多的命令。通过点击鼠标就能完成。并且该项目自带免杀效果，不需要考虑后期的免杀。
