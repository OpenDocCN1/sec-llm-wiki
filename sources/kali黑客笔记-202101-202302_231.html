前面的文章不少小伙伴留言说太深奥了，看不懂没意思 😱。今天给大家来一期比较实用的教程。在朋友圈发九宫格很上档次，除了利用ps等图片处理工具如何将一张图片进行裁剪，变成九宫格的样子呢，本文将通过Python脚本简单实现。

🌈代码如下

import sys
import os 
from PIL import Image
file_root = "/root/22" #要切的图片放的文件
fileList = []
n = 0
#读取文件列表
def read_bmp_file_list(path):
     for root, dirs, files in os.walk(path, topdown=False):
            for file in files:
                fileList.append(os.path.join(root, file))
#开始切图
def qie_tu(file_path):
    global n
    im = Image.open(file_path)
    # 图片的宽度和高度
    img_size = im.size
    print("图片宽度和高度分别是{}".format(img_size))
    #切成512X512
    x = 0
    y = 0
    w = 512
    h = 512
    for j in range(0,3):
        for i in range(0,3):
            #region = im.crop((x, y, x+w*i, y+h*j))
            print(x+w*i, y+h*j,x+w*i+w, y+h*j+h)
            region = im.crop((x+w*i, y+h*j,x+w*i+w, y+h*j+h))
            #文件输出位置
            region.save("/root/22/{name}.jpg".format(name=n))
            n=n+1

if __name__ == '__main__':
    read_bmp_file_list(file_root)
    for f in fileList:
        qie_tu(f)

重要参数说明:

for j in range(0,3):
for i in range(0,3):

这里的3就是3*3九宫格的意思。保存py文件后，我们在kali中执行下面命令即可！

python3 xx.py
