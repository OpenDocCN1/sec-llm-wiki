> `Uniscan`是一款联合性扫描工具，用于远程文件包含，本地文件包含和远程命令执行漏洞扫描程序，同时还可以进行指纹识别，DNS域名解析查询，OS检测等多种功能。是小白学习WEB安全一款很不错的工具。现在让我们开始吧!!!

# 01 安装

新版的kali中是没有安装的，我们执行下面命令安装。

```

apt-get install uniscan
```

![](../Images/7646e2370047a4287113b3ef75145862.png)

# 02 查看帮助

```

uniscan -h
```

![](../Images/841f5ffa88b9ba94d560c240d2454045.png)

# 03 参数说明：

`-h`:帮助信息

`-u`：例如：https://www.example.com/

`-f`：url's列表-批量扫描

`-b`：后台运行Uniscan

`-q`:启用目录检查

`-w`:启用文件检查

`-e`：启用机器人.txt和网站地图.xml检查

`-d`: 启用动态检查

`-s`: 使用静态检查

`-r`: 启用压力测试'

`-i`：必应搜索

`-o`：谷歌搜索

`-g`：网络指纹

`-j`: 服务器指纹

# 04 服务器指纹识别

使用命令，对服务器进行指纹识别。扫描结果将会包含以下内容，结果、 、以及结果。`-j``ping``TRACEROUTE``NSLOOKUP``Nmap`

```

uniscan -u https://bbskali.cn -j
```

*   通过将 数据包发送到目标服务器并建立连接来启动 PING 枚举。`ICMP`
    
*   此外，它将使用  来显示从源到目标的信息包的路径，并列出它经过或失败并被丢弃的所有路由器。`TRACEROUTE`
    
*   `NSLOOKUP`是一个查询互联网域名服务器（DNS）的程序。NSLOOKUP或反向DNS（rDNS）是一种将IP地址解析为域名的方法。
    
*   `NMAP`对目标服务器进行主动扫描，以识别开放端口和协议服务，它还使用 NMAP NSE 脚本枚举目标，以识别正在运行的漏洞服务的漏洞和详细信息。
    

![](../Images/1c637d0e5a0d074e1fb80ba2af92e5f9.png)

# 05 动态扫描

使用\-d命令，对目标服务器进行动态扫描。将加载选定的插件来进行攻击，如 `XSS``SQL注入等`

```

uniscan -u https://bbskali.cn -d
```
