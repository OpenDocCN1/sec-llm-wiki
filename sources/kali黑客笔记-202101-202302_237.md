# 01 前言

> `Crunch`在肾透测试和各种暴力破解中，我们需要各种各样的密码字典。github上面的字典五花八门，但是没有一款适合自己。那么，如何制作自己的字典文件呢？`Crunch`是C语言开发的一种工具，可以创建自定义可修改的单词列表。在本文中，我们将详细讲解Crunch的使用。

# 02 安装

`Crunch`默认安装在Kali Linux上，如果其他系统也可以用`apt`命令安装。

```

apt-get install crunch
```

运行`crunch`生成字典，要求我们输入要生成的单词的`最小`和`最大`值以及`输出文件`，它会自动将小写字母表作为字符集并生成字典。![](../Images/949b05230f8e5baa7c6c788b127c289c.png)

# 03 牛刀小试

生成最短1个长度，最长为3个长度。

```
crunch 1 3
 -o kali.txt
```

![](../Images/e42476b4dbc993103fdde75f4bf31b84.png)

生成最短是1 最长是3位数的密码

![](../Images/1c061445af2c62fa9b6cdba3572ff611.png)

### 🍀3.1自定义字母和数字字符

当然，我们可以做字母和数字两者的结合。如下：

```

crunch 5 7 pass123 -o kali.txt
```

代码说明：以`p` `a` `s` `s` `1` `2` `3`这七个字母和数字进行排列组合，生成最短5位，最长7位的字典。![](../Images/865d316e72d9f16b0061f87268648e82.png)

### 🌈3.2创建带有符号的字典

`@`:将插入小写字符

`，`:将插入大写字符

`%` :将插入数字

`^` :将插入符号

### 🐶3.3固定单词 + 3 个数字

假设我们要将前3个字母固定为`bbs`，并在每个单词`6`个字符,最后3个位置插入随机数字组合，则可以通过指定模式来完成。

```
crunch 6 6
 -t bbs%%% -o num.txt
```

![](../Images/1634a0e259fa7e8c5a12cc2b31c757a2.png)

#### 💋3.4固定单词 + 3 个大写字母

假设我们要将前3个字母固定为`bbs`，并在每个单词6个字符,最后3个位置插入大写字母的随机组合，则可以通过以下方式完成

```
crunch 6 6
 -t bbs,,, -o kali.txt
```

![](../Images/34dba8d3ea4329fc8534605eccd4b799.png)

#### 🎉3.5固定单词 + 3 个小写字母

```
crunch 6 6
 -t bbs@@@ -o kali.txt
```

#### 🍉3.6固定单词 + 3 个符号

```
crunch 6 6
 -t bbs^^^ -o kali.txt
```

#### 🍇3.7小写字母（a，b 或 c）+ 数字 （1，2 或 3） + 符号 （ANY）

在下面的示例中，使用了`abc`和`123`。还使用`+`运算符。我们要创建一个字典，其中`第一个字符小写`，`数字`作为第二个字符，`符号`作为第三个字符，但只有`a`，`b`或`c`作为字符，`1`，`2`或`3`分别作为数字和最后一个位置上的任何随机符号，命令如下：

```
crunch 3 3 abc + 123
 -t @%^ -o kali.txt
```

![](../Images/d4ef1e2f420b8dc56d0d9f387270991e.png)

### 🏀3.8两个数字（1、2 或 3）+ 小写字母 （ANY） + 符号 （ANY）

类似地，要创建一个 2 位数字的每个单词 4 个字符的模式（仅包含 1，2 或 3）+ 小写的字母 + 符号，我们可以这样做：

```
crunch 4 4 + + 123
 + -t %%@^ -o kali.txt
```

这时`+ +`起到了两个占位符

![](../Images/9e67ab889fc8b5d8d6fc38d19c5fa096.png)

# 04 压缩单词列表

通常，单词列表在文本格式中太大，`gzip`可用于将其压缩到60-70%以上。

```
crunch 4 7
 Pass123 -z gzip -o START
```
