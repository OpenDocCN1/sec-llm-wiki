🎃前言

shecodject是由Python3编写的Shellcode自动注入的脚本。可以配合msfconsole直接使用。生成的源文件可以直接使用pyinstaller封装或者您也可使用本工具生成普通的原始档再进行封装。在封装exe时，不再使用wine进行封装。所以不用担心在Linux或Mac系统下不能封装exe的问题。

⛳安装

git clone https://github.com/TaroballzChen/Shecodject.git
cd Shecodject
cd setup
python3 setup.py

需要安装部分依赖，耐心等待。

🥋说明

mpr 生成普通的Shellcode

exe 產生exe文件，保存到output目录

msf 启动msf开始监听

🎣使用

python3 shecodeject.py

首先生成shellcode执行命令

mpr
run

然后生成exe文件

exe
根据前一步的shellcode生成exe
run

🎯后记

这款工具，适合刚开始玩免杀的小伙伴，算是一个入门小脚本吧。需要注意的是，工具抛弃了windows和mac系统的依赖，而引用了Docker。故而下载和部署环境需要占用一定的空间。当然除了这种方法之外，还有很多的免杀小技巧，我们在后面的文章中会提到。希望通过本篇文章，对你学习免杀有所帮助。
