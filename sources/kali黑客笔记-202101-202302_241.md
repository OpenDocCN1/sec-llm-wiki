### 🎃前言

`shecodject`是由`Python3`编写的`Shellcode`自动注入的脚本。可以配合msfconsole直接使用。生成的源文件可以直接使用`pyinstaller`封装或者您也可使用本工具生成普通的原始档再进行封装。在封装exe时，不再使用`wine`进行封装。所以不用担心在Linux或Mac系统下不能封装exe的问题。

### ⛳安装

```
git clone
 https://github.com/TaroballzChen/Shecodject.gitcd
 Shecodjectcd

 setup
```

![](../Images/65b58840ad74bf5c4817d81e1aeda681.png)需要安装部分依赖，耐心等待。

### 🥋说明

`mpr` 生成普通的Shellcode

`exe` 產生exe文件，保存到output目录

`msf` 启动msf开始监听

### 🎣使用  

```

python3 shecodeject.py
```

![](../Images/5da7d265433cc59dc1b441d4f7668b90.png)首先生成`shellcode`执行命令

```


mpr
```

![](../Images/24b962d4757e280361531aa6bc3d131e.png)然后生成exe文件

```


exe
```
