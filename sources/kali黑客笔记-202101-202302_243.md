> 百度云是我们工作和学习中常用的一款软件之一。但是因为下载速度贼慢而受到万人戳骂。再后来随着`PanDown`已死。百度云盘也优于`鸡肋`。但我们有时候的确也离不开它，那么用什么方法能加速它的下载速度呢？

**PS**: 本文只提供思路（你懂得）

### 🌈方式一：IDM

##### 01下载IDM（文末已打包）

注：本文提供的IDM是绿色版本，解压后，执行`绿化.bat`，就可以正常使用了。

##### 02 IDM配置 ：

设置4线程![](../Images/8002944502d79fdbfd64d49d68d51e91.png)

修改`UA`为 `netdisk;7.0.3.2;PC;PC-Windows;10.0.17763`![](../Images/2527f3546399eb4f840e2dd28df531d9.png)

##### 03 解析文件地址

下载`百度网盘简易下载助手`(拖动到浏览器即可安装) 安装之后，打开百度网盘，即会发现多了一个红色按钮`简易下载助手`

![](../Images/ac80fa06b6277c79f910e02653d483d7.png)  

勾选文件，点击【简易下载助手】，弹出文件下载窗口。![](../Images/89077df81e413c6b4bbab94e1f46ea4f.png)复制直链地址：复制后就可以到`IDM`中新建下载任务了

### 🥳方式二  KinhDown+Aria2

利用`KinhDown` (https://baidu.kinh.cc/?Type=LinkParsing)这个项目，在链接框粘贴分享链接与密码即可自动识别并解析，然后在文件列表勾选你想下载的文件 (夹), 点击底部 下载 按钮，即可加入解析列表，然后点击左上角导航栏或者右上角下载按钮即可打开下载页面

##### 02 部署Aria2+AriaNg

服务端aria2部署

```

apt-get install aria2
```

![](../Images/0283362428cb6f3ce61f8558ca8e1a12.png)

启动服务器端

```
aria2c --enable
-rpc --rpc-listen-all --rpc-secret 666666
```

`666666`是你的密码,你可以自定义。![](../Images/3c1eb8518864cfa5fd3fbfb0f739b3b6.png)配置客户端

> github项目:https://github.com/ziahamza/webui-aria2

下载项目文件，放到 `/var/www/html`在 `设置` > `连接设置`中配置好我们的IP地址和密码![](../Images/de19efd702f5cf6ec74c5eaf3197b737.png)现在，我们只需将第一步中解析得到的链接放到ariang中便可以下载了。

### 🎃其他

无论是哪种下载方法，原理都是一样的。将云盘文件，通过解析得到直链地址。然后通过下载平台进行下载就行了。
