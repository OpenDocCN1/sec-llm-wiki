利用Kali卸载MIUI广告

MIUI是小米手机吹炸天的手机系统。但是小米的广告有时候的确很烦人。并且自带了很多不常用的软件，你想要root，还需刷开发包。那么怎样无需root来卸载不常用的软件和屏蔽广告呢？

准备

  • MIUI13 手机、
  • Kali Linux

PS：手机做好备份，以防万一 因为kali已经安装好了adb，所以我们无需安装。如果没有，请执行命令安装。

apt-get install adb

同样，对于Windows我们只需下载程序放到系统目录即可。

打开开发者模式

打开设置-我的设备-全部参数-在 MIUI 版本上连续点击，直到提示 您已处于开发者模式，无需进行此操作.

然后打开设置-更多设置-开发者选项-向下拉勾选 USB 调试-弹出框点击确认

使用 ADB 命令删除系统应用

adb卸载应用的命令为

adb shell pm uninstall --user 0 <包名>

这里列出一些可直接删除的包名，复制命令删除即可:

若在使用以上 adb 命令删除时出现「not installed for 0」错误，则可以尝试下面的命令：

adb pm uninstall -k --user 0 package:<包名>
