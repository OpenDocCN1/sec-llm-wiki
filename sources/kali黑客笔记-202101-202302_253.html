肾透的本质--信息收集

所谓肾透，是指前期我们对目标进行侦察。获取为后期肾透的有利信息。比如网站的开发架构、CMS类型、PHP版本、Mysql版本、操作系统类型、开放的端口、网站后台地址、管理员邮箱、网站备案信息、域名注册信息等等……。这些都是我们肾透所需。之前，对这些信息的手机我们都是通过单一的工具进行测试。如用Nmap扫描完端口后，用其他工具去扫描子域名信息等。本文将为大家介绍一款新的工具，为你提供一条龙服务。

🧲SiteScan简介

专注一站化解决渗透测试的信息收集任务，功能包括域名ip历史解析、nmap常见端口爆破、子域名信息收集、旁站信息收集、whois信息收集、网站架构分析、cms解析、备案信息收集、CDN信息解析、是否存在waf检测、后台寻找以及生成检测结果html报表。

🏀安装

git clone https://github.com/kracer127/SiteScan/issues
pip3 install -r requirements.txt

⏰牛刀小试

python3 main.py -u http://10086.com

🎡后记

优点： 利用Python爬虫，将目标提交到某些站点。然后将结果通过html的方式发聩给我们。

缺点： 该工具依赖于第三方网站的爬虫，如端口扫描没有调用namp扫描，而是借用http://www.ip33.com扫描。一旦该网站无法使用，则工具也就失去了意义。在笔者测试时，遇到了卡在端口扫描的进程中。

总而言之，通过此工具。我们可以顺便研究下 Python在爬虫领域的使用。仁者见仁智者见智，希望对此工具的使用来增加我们对安全领域的学习。
