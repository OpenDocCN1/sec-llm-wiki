最近微博、抖音平台都相互开启了显示对方IP归属地功能。感觉很火。官方现在这样做无非是防止电信诈骗类的事情发生。但老夫夜观天象，看了看微信，也只有公众号显示了IP信息。但是无法显示好友IP信息（这才是关键），那么如何显示好友IP信息呢？这里我简单的介绍两种方法，其原理都是一样的，都是通过分析数据包获取对方IP！

🚴方式一 通过路由器

我们可以利用路由器对数据包进行捕获，然后进行分析数据。通常情况下家庭路由器是没有这个功能的。我们可以刷一些第三方固件如老毛子 梅林 高格等固件。开启SSH服务，在路由器中直接抓包。然后分析数据包即可。这里我以高格固件为列：登录路由器，进入在线主机管理。

选择自己的手机（192.168.5.118），进入详情页。

可以很详细的看到，目前该手机访问的目标IP地址和端口。然后，我们利用手机和对方视频/语音通话（需要接通），然后在该详情中筛选UDP协议，本地端口为33540,便可以看到目标IP。

⛵方式二 利用Wireshark

上面案列中，虽然方便但是有一定的局限性。由于家中路由器的多样化，所有并不是所有的路由器都可以这样做。这时我们可以利用流量分析神器Wireshark来解决了。首先我们在windows下安装Wireshark

安装完成后，选择我们本地的网卡（因为我笔记本连接的WiFi，我选择Wlan）。

然后打开微信电脑端，和目标进行视频/语音通话。根据前面的信息，我们在Wireshark中对数据进行过滤，只显示UDP和31734端口的信息。(注意，这里的31734端口可能不唯一，需要你本地实验下，你自己的端口。)

udp.srcport==31734

这样，我们便获得了对方的IP地址。便可以对其位置进行较为精确的定位。

👾方法三 利用探针

当然，除了以上方法外，我们还可以利用PHP写一个获取对方的GPS或者ip的探针。只需要对方打开我们的链接，就可以获取目标的IP地址。（GPS手机端会弹窗提示授权，pc端无法定位。）

php获取IP示例

<?php
error_reporting (E_ERROR | E_WARNING | E_PARSE);
if($HTTP_SERVER_VARS["HTTP_X_FORWARDED_FOR"]){
$ip = $HTTP_SERVER_VARS["HTTP_X_FORWARDED_FOR"];
}
elseif($HTTP_SERVER_VARS["HTTP_CLIENT_IP"]){
$ip = $HTTP_SERVER_VARS["HTTP_CLIENT_IP"];
}
elseif ($HTTP_SERVER_VARS["REMOTE_ADDR"]){
$ip = $HTTP_SERVER_VARS["REMOTE_ADDR"];
}
elseif (getenv("HTTP_X_FORWARDED_FOR")){
$ip = getenv("HTTP_X_FORWARDED_FOR");
}
elseif (getenv("HTTP_CLIENT_IP")){
$ip = getenv("HTTP_CLIENT_IP");
}
elseif (getenv("REMOTE_ADDR")){
$ip = getenv("REMOTE_ADDR");
}
else{
$ip = "Unknown";
}
echo $ip;
?>

🎭后记

和前面两种方法相比，第三种比较被动。成功与否在于是否点开链接。而前面两种，需要我们主动收集信息，难度较大。希望通过此文，能增加大家的安全意识。
