# 防诈指南之获取微信好友IP

> 最近微博、抖音平台都相互开启了显示对方IP归属地功能。感觉很火。官方现在这样做无非是防止电信诈骗类的事情发生。但老夫夜观天象，看了看微信，也只有公众号显示了IP信息。但是无法显示好友IP信息（这才是关键），那么如何显示好友IP信息呢？这里我简单的介绍两种方法，其原理都是一样的，都是通过分析数据包获取对方IP！

### 🚴方式一 通过路由器

我们可以利用路由器对数据包进行捕获，然后进行分析数据。通常情况下家庭路由器是没有这个功能的。我们可以刷一些第三方固件如`老毛子` `梅林` `高格`等固件。开启`SSH`服务，在路由器中直接抓包。然后分析数据包即可。这里我以高格固件为列：登录路由器，进入在线主机管理。

![](../Images/ad6476ace1946d965fab65b2335cb4fb.png)

选择自己的手机（`192.168.5.118`），进入详情页。

![](../Images/d024a4e2ee7d72644d4585d39708bb36.png)

可以很详细的看到，目前该手机访问的目标IP地址和端口。然后，我们利用手机和对方视频/语音通话（需要接通），然后在该详情中筛选`UDP`协议，本地端口为`33540`,便可以看到目标IP。

![](../Images/7ef156cbf5cec56d3dfdb2360fc0fb88.png)

### ⛵方式二 利用Wireshark

上面案列中，虽然方便但是有一定的局限性。由于家中路由器的多样化，所有并不是所有的路由器都可以这样做。这时我们可以利用流量分析神器`Wireshark`来解决了。首先我们在`windows`下安装`Wireshark`![](../Images/975d189de3aa5a5a8d73bd3ad12e4897.png)

安装完成后，选择我们本地的网卡（因为我笔记本连接的WiFi，我选择`Wlan`）。

![](../Images/20d3156cbd629470e20cf409dafecb9b.png)

然后打开微信电脑端，和目标进行视频/语音通话。根据前面的信息，我们在`Wireshark`中对数据进行过滤，只显示`UDP`和`31734`端口的信息。(注意，这里的`31734`端口可能不唯一，需要你本地实验下，你自己的端口。)

```
udp.srcport==31734

```

![](../Images/826d8119e85d7012b5f49d13354b88e5.png)

这样，我们便获得了对方的IP地址。便可以对其位置进行较为精确的定位。

![](../Images/70fb1de329c2ad05cf1b60e96c82b5b2.png)

### 👾方法三 利用探针

当然，除了以上方法外，我们还可以利用`PHP`写一个获取对方的`GPS`或者`ip`的探针。只需要对方打开我们的链接，就可以获取目标的`IP`地址。（`GPS`手机端会弹窗提示授权，`pc`端无法定位。）


### 🎭后记

和前面两种方法相比，第三种比较被动。成功与否在于是否点开链接。而前面两种，需要我们主动收集信息，难度较大。希望通过此文，能增加大家的安全意识。
