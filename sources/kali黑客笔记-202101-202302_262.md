### 🎭Binwalk介绍

> `Binwalk`是用于搜索给定二进制镜像文件以获取嵌入的文件和代码的工具。可帮助产品安全研究人员提取固件映像的组件。由于Binwalk用于分析，逆向工程和提取固件映像，因此您可以使用此工具反转路由器的固件映像。通过这种方式，您可以了解它的工作原理，并识别嵌入在固件映像中的文件和代码

#### 🚡在Kali Linux上安装Binwalk

`binwalk`预装在Kali Linux操作系统。要安装 Binwalk 及其依赖的任何其他软件包，请使用以下命令：

```
apt-get install binwalk
```
