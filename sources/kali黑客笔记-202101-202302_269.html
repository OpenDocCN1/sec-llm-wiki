you-get是一款由Python编写的下载程序。几乎可以下载全网视频。如我们常用的B站、爱奇艺、快手、抖音等。本文来看看如何在kali中搭建并完成视频的下载。

安装

在kali LInux安装

git clone  https://github.com/soimort/you-get 
python3 setup.py install

在windows10安装

pip3 install you-get

环境

  • Python 3.2 或更高
  • FFmpeg 1.0 或更高
