> you-get是一款由Python编写的下载程序。几乎可以下载全网视频。如我们常用的B站、爱奇艺、快手、抖音等。本文来看看如何在kali中搭建并完成视频的下载。

### 安装

**在kali LInux安装**

```
git clone

  https://github.com/soimort/you-get 
```

![](../Images/4ef42962983d4880008a055f40c9e730.png)

**在windows10安装**

```

pip3 install you-get
```

![](../Images/e4971a3ad7b1a74c28f269475efe4df7.png)

### 环境

*   `Python 3.2` 或更高
*   `FFmpeg 1.0` 或更高

### 使用教程

这里我以下载我B站的视频为列。在`B站`搜索`逍遥子大表哥`

![](../Images/539eb066fab47f0743e53929a8681fa0.png)

比如我们要下载视频`《kali Linux给app添加后门》` 复制视频地址：https://www.bilibili.com/video/BV1Bf4y1M78W?spm_id_from=333.337.search-card.all.click 在终端中执行命令：

```

python3 you-get https://www.bilibili.com/video/BV1Bf4y1M78W?spm_id_from=333.337.search-card.all.click
```

![](../Images/f1ca78582140ab2ccd97f163b1442898.png)
