# OpenWRT挂载剩余硬盘和开启网络共享

> 之前，我们树莓派安装了OpenWRT。手头又有几块500G的机械硬盘。由于之前一直用黑群晖，但是旧电脑噪音太大。晚上太吵。于是出一片文章，给大家说说如何将硬盘挂载到OpenWRT

### 🤞分区

终端登录，输入命令

```

fdisk /dev/sda
```

输入`n`新建分区，会让设置盘符和分区大小，直接`enter`默认设置就行 新建完后输入`w`保存。至此分区创建完成。如果出错输入`d`删除重新分区就可以。格式化分区，输入命令:

  

```
mkfs.ext4 /dev/sda2 #sda2是我的盘符 换成你自己的

```

### 😎挂载

进入`OpenWRT`后台，`系统`->`挂载点`，查看在已挂载的文件系统里面是否自动挂载了分区。

![](../Images/38a643f39105a1e6322613cf94abaa3c.png)

没有的话在下面的挂载点看看是否有分区，有的话直接点启用然后点保存和应用就可以了

![](../Images/3eb48527d73b9424783dc735ce8f17b9.png)

如果挂载点也没有就要自己添加了。

![](../Images/2c6dffe18b96408238272e0426e6a6da.png)

至此挂载分区完成了。

### 🎉网络共享

OpenWRT后台，`服务`->`网络共享`。

启用root用户，在编辑模版里注掉以下代码，在其前面添加`#`就可以了。

```

invalid user = root
```

![](../Images/c1da542d605785cce30255d441c93344.png)

按以上设置就可以了。设置`root`账户密码，SSH后台输入以下命令。

```

smbpasswd -a root
```

依次输入两次密码就可以了。网络共享就设置完成了。之后在电脑的端连接就可以了
