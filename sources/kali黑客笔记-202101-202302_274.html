samba简介

Samba，是种用来让UNIX系列的操作系统与微软Windows操作系统的SMB/CIFS（Server Message Block/Common Internet File System）网络协议做链接的自由软件。第三版不仅可访问及分享SMB的文件夹及打印机，本身还可以集成入Windows Server的网域，扮演为网域控制站（Domain Controller）以及加入Active Directory成员。简而言之，此软件在Windows与UNIX系列操作系统之间搭起一座桥梁，让两者的资源可互通有无。

准备

centos7系统

关闭防火墙

systemctl stop firewalld.service
systemctl disable firewalld.service

临时关闭selinux setenforce 0

修改/etc/selinux/config 只需修改selinux=disabled不然会出现没权限写入

​

安装samba

centos系统下直接使用yum安装

命令

yum install samba -y
​

说明：samba配置文件目录/etc/samba smb.conf为核心配置文件

启动samba

systemctl start smb 

查看状态

systemctl status smb 

重启

service smb restart 

设置开机自启

systemctl enable smb

创建共享文件目录

mkdir

配置共享文件

/etc/samba/smb.conf
​

我们直接在下面添加

说明：

[共享名]
comment=共享描述
path=共享目录路径
writable=yes|no 是否可写
valid users=允许访问的用户|组
public=yes|no 是否允许guest用户访问

[电影]
comment = test samba
path = /home/cunchu
writable = yes
public = yes

全局设置

workgroup #设定加入的组
security=user  share#表示匿名也可以访问，
user#表示需要使

打开电脑输入\地址 输入刚创建的用户名密码点击登录就可以打开我们刚才创建的共享了；
