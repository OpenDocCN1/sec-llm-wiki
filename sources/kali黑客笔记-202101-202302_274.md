# samba简介

**Samba**，是种用来让UNIX系列的操作系统与微软Windows操作系统的SMB/CIFS（Server Message Block/Common Internet File System）网络协议做链接的自由软件。第三版不仅可访问及分享SMB的文件夹及打印机，本身还可以集成入Windows Server的网域，扮演为网域控制站（Domain Controller）以及加入Active Directory成员。简而言之，此软件在Windows与UNIX系列操作系统之间搭起一座桥梁，让两者的资源可互通有无。

# 准备

centos7系统

关闭防火墙

```

systemctl stop firewalld.service
```

  

临时关闭`selinux setenforce 0`

修改`/etc/selinux/config` 只需修改`selinux=disabled`不然会出现没权限写入

# 安装samba

centos系统下直接使用yum安装

命令

```
yum install samba -y
```

![](../Images/eaa1098124ca582b56afb9697437ef04.png)​

说明：samba配置文件目录`/etc/samba smb.conf`为核心配置文件

启动samba

```

systemctl start smb 
```

查看状态

```

systemctl status smb 
```

重启

```

service smb restart 
```

设置开机自启

```
systemctl 
```

创建共享文件目录

```

mkdir
```

配置共享文件

```
/etc/samba/smb.conf
```

![](../Images/9776019ffe73def5112d08ff3bc8ae3c.png)​

说明：
