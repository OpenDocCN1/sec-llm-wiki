### nmap --script

Nmap的脚本位置：`/usr/share/nmap/scripts/`查看脚本的数量

```

ls /usr/share/nmap/scripts/ | wc -l
```

可以看到，目前有`605`个，当然这些插件我们可以自己编写，也可以去下载。总之很方便的。![](../Images/ebacc6376c554d8c8d3ccc66464ed698.png)nmap脚本主要分为以下几类，在扫描时可根据需要设置`-–script=类别`这种方式进行比较笼统的扫描：

| 脚本名 || 说明 |
| --- | --- |
| auth || 绕开鉴权 检测是否存在弱口令 |
| --- | --- |
| broadcast || 局域网内探查更多服务开启状况 |
| brute || 暴力破解方式，针对常见的应用如http/snmp等 |
| default || 使用-sC或-A选项扫描时候默认的脚本 |
| dos || 用于进行拒绝服务攻击 |
| exploit || 利用已知的漏洞 |
| vuln || 负责检查目标机是否有常见的漏洞 |

### 常用示例

#### 检查弱口令

```

nmap --script=auth 192.168.123.1
```

![](../Images/290006b4e6db8117bbec481aa15e5f70.png)

#### 暴力破解

可对mysql http smtp等常见协议进行暴力破解。

```

nmap --script=brute 192.168.123.1
```

如下，我们通过暴力破解，得到了telent的登录密码为`admin`

![](../Images/e079f1860bc70f704abf037c3629c11c.png)尝试登录![](../Images/1548dabfcfeee0ad9dfe21d12a6290b1.png)

#### 默认脚本扫描

默认的脚本扫描，主要是搜集各种应用服务的信息，收集到后，可再针对具体服务进行攻击。

```


nmap --script=default 192.168.123.1
```

#### 检查是否存在常见漏洞

```

nmap --script=vuln  192.168.123.1
```

扫描得到，目标可能存在`CVE:CVE-2007-6750`漏洞![](../Images/7f0aaf537173323c3c8e2dd96cd28214.png)

#### 漏洞利用

在msf中搜索此漏洞，配置相关信息即可！

```


search CVE-2007-6750set

 rhost 192.168.123.1
```

![](../Images/3fb95e7bc041188d6f62ed6e5756631b.png)

#### whois解析

我们对论坛地址`bbskali.cn`进行历史解析查询。

```

nmap --script external bbskali.cn
```

如下我们得到了很多有用的信息：![](../Images/2169b1248b4cbfc573ec3d866cbd7331.png)

#### HTTP认证爆破

```

nmap --script=http-brute 192.168.123.1
```

同样，我们这里以路由器的登录密码为破解对象，破解得到账号和密码为`admin`**注意：**Nmap默认字典位置为：`/usr/share/nmap/nselib/data`![](../Images/fc8c224f74edc95a37cf07c62d7ef8a7.png)

#### 网站目录扫描

类似于御剑那样，nmap也同样可对网站目录进行扫描。

```

nmap --script=http-ls bbskali.cn
```
