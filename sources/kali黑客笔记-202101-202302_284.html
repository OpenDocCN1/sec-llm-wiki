在win10系统下，我们可以利用笔记本的无线网卡来搭建钓鱼WiFi。原理是，利用笔记本的无线网卡发射WiFi热点。并且保证本机可以正常上网。当目标主机连接WiFi后，我们在对目标主机进行数据包抓取和ARP欺骗。已完成钓鱼的目的。


验证您的无线网卡是否支持

当您要创建 WiFi 热点时，您首先需要验证您的笔记本电脑的无线适配器是否具有此功能。

netsh wlan show drivers

如果Hosted netword supporter：YES，那么您可以在笔记本电脑上创建 WiFi 热点，然后您可以继续下一步。

在Windows 10 中创建热点

在 Windows 10 中创建 WiFi 热点非常简单，您只需运行以下命令。但请确保您的命令提示符具有管理员权限

netsh wlan set hostsnetwok mode=allow ssid=wifiname key=password

启动热点

执行下面命令，以启动热点。

netsh wlan start hostednetwork

到目前为止，您已经在 Windows 10 中创建了热点，您可以使用任何无线设备（如 Mobile）查看此热点，并使用您的安全密钥与之连接，但您仍然无法在移动设备上使用Internet 连接，

1.打开控制面板-网络和 Internet-网络和共享中心-更改适配器设置

2.右键单击您正在运行 Internet 连接的网络适配器，然后单击属性

3.单击顶部的共享选项卡

4.勾选允许网络用户通过此计算机的 Internet 连接选项5.选择无线网卡适配器

现在，我们将本地的网络共享到了无线网卡。

关闭热点

netsh wlan stop hostednetwork

更改 WiFi 热点信息

netsh wlan set hostednetwork ssid=New_SSIDnetsh wlan set hsotednetwork key=New_Password

显示当前 WiFi 热点信息

netsh wlan show hostednetwork

数据包截取

当目标连接后WiFi后，我们便可以利用抓包工具对目标的请求信息进行捕捉了。
