> 在平时生活和工作中，只要第一次输入 Wi-Fi 密码后，基本就可以忘记了，因为基本上不会再输入 Wi-Fi 密码。当我们有新的设备要连接WiFi或者有小伙伴来家里玩时，忘记WiFi密码就是一件非常烦恼的事。通常都是进入路由器查看Wi-Fi 密码，但这样太麻烦了，那么如何查找本机连接过的WiFi密码呢？**当然文章末尾给大家提供了一种利用WiFi信息查岗的手段。**

![](../Images/69dea7dd91c91efc8af9a214d88bde88.png)

### Windows 查找 WiFi 密码的办法

1、「任务栏」右击「网络」→点击 「打开网络和 Internet设置」![](../Images/aafaaf0ae40c2fd5cf76628223cafd67.png)

2、点击「更改适配器选项」![](../Images/64937c79afd06d470fe55469c6c6aa67.png)3、右击「 WLAN」→选择 「状态」 4、点击「无线属性」![](../Images/1981850c39a432f66a3c6b666a4cfebb.png)5、切换至「安全」选项卡，点击「显示字符」这样便可以看到连接后的WiFi密码了。![](../Images/9bf084d3a6f8b5095109d92069ea31b7.png)当然，作为一名当代打黑阔，怎么用上面的方法呢，我们要显得黑阔的水平。在`CMD`中执行下面命令

```
netsh wlan show profiles #列出所有连接的WiFi信息
# 显示密码

```

![](../Images/cdd17bc5428f4fdffe7f5a219f12be49.png)

关键内容，便为我们的WiFi密码了。

### Linux系统查看已连WiFi密码

在LInux中，已连接的WiFi信息存放在`/etc/NetworkManager/system-connections `目录下。终端执行下面命令

```
cd
 /etc/NetworkManager/system-connections#列出已连接的WiFi


```

![](../Images/171a7e39e73c8b11317c1574ce65ecbc.png)

### 查看手机连接的WiFi

警告！此方法可能引起家庭和睦，建议别让家中老婆掌握。原因懂得都懂。但也放心，此方法的前提是手机需要`root`利用`adb`连接手机，执行命令

```


adb shell
```

这样将设备已经成功连接的wifi账号和密码显示出来（ssid后面跟的是账号，psk后面跟的是密码）

### 查岗模式（渣男们 颤抖吧！）

列出连接的所有WiFi信息，（无需`root `）

```
adb shell dumpsys wifi #列出所有WiFi
"Wi-Fi name" #筛选WiFi

```

### 核能示例

**在此申明：以下信息，来自朋友的手机。**

想要查看男票是否到某足浴店，执行命令！

```
adb shell dumpsys wifi | grep "在水一方足浴"

```
