**环境**

*   `Windows10`
    
*   `Nessus-8.15.3`
    

  

**官网地址**  
https://www.tenable.com/downloads/nessus

**Nessus配置SSL**

浏览器自动访问  
https://localhost:8834或访问  
https://127.0.0.1:8834:8834

![](../Images/02d17d257b37bc453a3cd0dead9a3871.png)

  

点击Connect via SSL

然后选择`Managed Scanner`再点击`Continue`

![](../Images/6617eec6c37d20178316f6b9bca41889.png)

然后选择`Tenable.sc`再点击`Continue`

![](../Images/b1b95fad5e3971a56d79808d6ebd4387.png)

随便填写用户名密码进行注册
