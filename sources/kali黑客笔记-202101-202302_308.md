> 在渗透测试时，通过了解系统和目标之间的网络环境非常重要。这就是`traceroute`的用武之地。它可以将数据包从您的系统发送到目标机器，并列出其整个旅程的路线。这将显示您的网络数据正在通过多少设备，以及每个设备的 IP 地址。以便我们获取更多的信息。

**Kali Linux**有另一个类似的侦察实用程序称为 `mtr`，它的功能与 `traceroute` 基本相同。在本指南中，我们将了解如何在 Kali 上使用 traceroute 和 mtr 以及它们的各种命令选项。

如果您的系统上尚未安装`traceroute`，请打开命令行终端并键入以下命令进行安装。

```
sudo apt 
```

安装后，尝试运行到其他系统的跟踪路由。它可以是您网络上的设备、Web 服务器，或者您可以连接到的任何东西，无论是本地还是远程。在命令中指定主机名、域名或 IP 地址。请注意，某些 `traceroute` 命令需要 `root` 权限。

### 后记

在本指南中，我们了解了如何在 Kali Linux 上使用 traceroute。我们还看到了如何使用 mtr，两者各有千秋，traceroute 以及 mtr 两者都通过帮助我们了解特定设备的网络路径而派上用场。它们还可用于帮助测试您的互联网连接。使用这些工具查找位于 Kali 和目标系统之间的网络连接。
