# Faraday - 渗透测试IDE和漏洞管理平台

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxMzIwNTY1OA==&mid=2247486089&idx=1&sn=db6b9307cffa6d9470246e1bb3a8632d&chksm=c1007a7cf677f36a0e2fb1ab3cb7c174d4d750516eb99d4381f06e77d70815c933789e8d891c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkxMzIwNTY1OA==&mid=2247486089&idx=1&sn=db6b9307cffa6d9470246e1bb3a8632d&chksm=c1007a7cf677f36a0e2fb1ab3cb7c174d4d750516eb99d4381f06e77d70815c933789e8d891c&scene=27#wechat_redirect)

> Faraday引入了一个新概念——IPE（集成渗透测试环境）一个多用户渗透测试 IDE。设计用于分发、索引和分析安全审计期间生成的数据。也就是说它可以将很多工具的数据信息汇总到一个工具中，如将`namp`的端口扫描信息，和`msfconsole`扫描的漏洞信息同时展现在一个平台。这样是不是很牛逼呢？

### Faraday支持的插件

目前Faraday有超过70 多种支持的插件，也就是说这些工具的数据都可以放到Faraday中。

### 开始开始

在kali2021.4中已经默认安装了Faraday  
我们在终端直接执行`Faraday`命令即可完成初始化。  

![](../Images/b289280d6644a5c5fa4536244efc00c7.png)  
记录好自己的用户名和密码  
当然如果你忘记了你的密码或者想要重置密码，请执行下面的命令

```
faraday-manage 
```

### 启动Faraday

在初始化完成Faraday后，我们再次从终端执行命令`faraday`  
这时会自动打开浏览器，并跳转到http://localhost:5985/#/login登录页面。  

![](../Images/7da2c7da8921775bf1c197f78970db9f.png)  
输入上一步中我们记录的账号和密码。登录`faraday`  
![](../Images/d127aa68edeb5287cd08bfd2750502fb.png)  
点击`NEW`创建工作区  
![](../Images/b0602b6b59b276468b858a0c6f18fc9a.png)

### 启动客户端

执行命令

```

faraday-client
```

输入账号和密码，选择工作组。  

![](../Images/2c3f093eb51902c773dc6c3f52ef9a5a.png)  
选择工作组（此处工作组就是上面我们建立的工作组）  
![](../Images/6240e1e72511bef2438c679fb5f6494b.png)  
这时，faraday会打开一个新的客户端窗口。  
![](../Images/2acff87d134a5801994ca39cd63d00ad.png)  
在这个窗口中，我们执行的相关工具的信息会显示在faraday的UIz中。
