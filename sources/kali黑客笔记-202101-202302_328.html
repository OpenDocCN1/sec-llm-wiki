二：钓鱼页面使用

配置WiFi钓鱼页面

激活钓鱼插件

set  proxy  captiveflask

显示当前插件信息

proxies

可以看到，当前我们插件下启动了loginPage这个页面，如何启动其他页面呢？

set captiveflask.Login_v4 true

这样就启动了其他页面
