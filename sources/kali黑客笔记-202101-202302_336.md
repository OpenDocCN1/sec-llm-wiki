> 家里有一款华硕路由器，今天看到又有新品路由器发布。奈何钱包羞涩，但很是喜欢他的主题，想着能不能移植它的主题，但我用的是官方的固件移植起来比较困难。于是参考网上的教程，修改了路由器的背景！

### 准备

*   华硕路由器
*   U盘一个

### 背景图处理

`title`栏背景图像素为`998×54`，有效像素约`980×54`（即图片两边各留9像素的空白边），圆角半径`10px`，保存为PNG格式备用。主页背景图宽度像素建议为`X+998+X`（X为图中左边红框宽度像素），高度像素与红框一致。保存为PNG格式备用。

举个例子：假设左边红框像素为`400×1000`，那么主页背景图像素应为`（400+998+400）×1000`。

### 启用路由器SSH服务。  

登陆路由器管理界面，找到`系统管理`—>`系统设置`—>`服务`—>启用`SSH`，选择`Lan Only`—>应用本页面设置。

### 拷贝index\_style.css。

把路由器`/www/index_style.css`拷贝到电脑。命令如下：

```
cd

 /www
```

**/tmp/mnt/U** 为`U`盘的路劲。

### 修改index\_style.css。

将第`3-5`行的内容修改为：

```
background-color:#21333e
;background:url(http://图片地址）#283437 no-repeat
;background-size: 1802px 999px
;background-position: center
 0%;margin: 0px
;background:#2834379
;
```

**Tips：**

`backgroud:url`后面的括号要替换成前面经base64编码后的主页背景图代码。

`backgroud-size`修改为主页背景图分辨率。

![](../Images/31a69b504dbcb883db08f80ea57df02e.png)

index\_style.css复制到U盘并覆盖。由于`/www`只有读取权限，需要将`index_style.css` 上传到U盘即可

### 挂载index\_style.css。

ssh登录路由器后，运行下面命令挂载修改后的index\_style.css。

```
mount --bind
 /tmp/mnt/U/index_style.css /www/index_style.css
```

至此，在浏览器登录路由器管理后台即可看到新的背景图。
