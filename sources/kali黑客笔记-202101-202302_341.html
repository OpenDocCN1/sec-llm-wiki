如何在 Kali Linux 上保持匿名

在今天的生活中，隐私泄露，我们也常谈论匿名问题，但我们真的是匿名的吗？所以这里有一个工具可以帮助我们实现匿名性，它被称为WHOAMI。它非常有用，并且有一个非常简单的用户界面。 

特征

  • 中间人攻击

  • 日志截取

  • IP转换

  • 域名服务器更换

  • Mac 欺骗

  • 更改时区

  • 更改主机名

  • 浏览器匿名化

安装

在我们开始在我们的 Linux 上安装这个工具之前，我们必须检查这个工具所必需的几个工具，这些工具是：-tar、git、tor、curl、python3、python3-scapy。

通常，这些已预安装在我们的 Linux 中，但如果您没有，则只需运行以下命令：

apt update && sudo apt install tar tor curl python3 python3-scapy network-manager

克隆项目到本地

git clone https://github.com/omer-dogan/kali-whoami

运行

sudo kali-whoami --help

启动攻击

sudo kali-whoami --start

选择要启用的选项，为此只需按数字即可启用，如果要禁用，请再次按该数字。

检查状态，请使用以下命令

sudo kali-whoami --status 

优缺点分析

优点： 匿名比较全面，涉及到IP地址 mac地址等敏感新的匿名。简单的通过选择相应的数字即可达到目的。无需复杂的手动配置。
缺点： 若需达到完全的匿名，部分功能需要外网才能实现。
