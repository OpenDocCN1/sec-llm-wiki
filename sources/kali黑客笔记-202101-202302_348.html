当您忘记密码并苦苦思索如何破解密码时，fcrack 会帮助您挽救局面，并向您展示如何加密您的文件。在 Linux 中可用的 fcrackzip 的支持下，您可以轻松破解 zip 文件的密码。

安装：

fcrackzip 是一种可用于解密 zip 文件并确定其密码的工具。该工具使用了暴力破解方法。Fcrackzip 可以通过几个基本步骤安装：

步骤1：

apt-get updeteapt-get install fcrackzip

验证安装：

由于我们使用的是Kali Linux，fcrackzip已经安装；我们现在要做的就是打开终端并输入“ fcrackzip –help ”。

fcrackzip –help



创建一个加密的zip文件：

首先，我们必须生成一个受密码保护的文件。

sudo zip --password abc123 bbskali.zip xin.sh

即，将xin.sh文件打包成bbskali.zip 密码为abc123

使用 fcrackzip破解 zip 密码

fcrackzip 是一种强大而简单的方法，可以对任何 zip 文件暴力攻击。为此，我们将使用各种格式来破解 zip 文件的密码。

-b暴力破解

-c字典的字符集

-u在结果中只看到正确的结果

fcrackzip -b -c 'a1' -u bbskali.zip

破解一定长度的密码：

我们使用与构建受密码保护的 zip 文件相同的命令来创建受密码保护的 zip 文件。在这种情况下，我们使用两个不同的参数，例如 (-c 'a')。

fcrackzip -b -v -c 'a' -l 1-5 -u bbskali.zip

1-5即为密码的长度

利用初始密码破解

fcrackzip -b -v -c 'a' -p bbs blog.zip

字典破解密码

fcrackzip可以从我们提供的文件中读取密码；该文件必须每行包含一个密码，并按字母顺序排列，以便 fcrackzip 正常运行。

fcrackzip -u -D -p /usr/share/wordlists/zidian.txt bbs.zip
