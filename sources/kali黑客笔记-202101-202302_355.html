Kali Linux 快捷键大全

怎么让被人看到你是一个很牛逼的黑阔？那就是放弃鼠标！全程都在敲键盘。是不是感觉很厉害（至少电影里面是这样演的），那么本文将教你怎样扔掉 你的鼠标，成为黑阔大佬！

01

系统快捷键

键盘快捷键描述
Ctrl + Alt + T打开一个新的命令行终端。
Alt + F4关闭当前窗口。
Alt + F11最大化当前窗口。
Alt + F3打开应用程序查找器。
PrtSc使用此快捷方式截取屏幕截图。
Super + PrtSc我们使用这个快捷方式打开 Kazam（截图/截屏工具）
Ctrl + N新的窗口
Ctrl + X切换窗口
Ctrl + C复制。
Ctrl + Z撤消。
Ctrl + S式用于保存
Ctrl + Q退出。
F1我们使用此快捷方式获得在线帮助。
F10左键单击菜单或光标
Alt + F1使用这个快捷方式，我们可以打开窗口。
Alt + F2使用这个快捷方式，我们可以打开命令窗口。
Alt + F7使用这个快捷方式，我们可以移动窗口。
Alt + 空格使用这个快捷方式，我们可以激活窗口菜单。
Alt + F10切换最大化状态。
Ctrl + Alt + D使用此快捷方式，我们可以最小化所有窗口。
Alt + F8借助此快捷方式，我们可以调整窗口大小。

02

终端快捷键


以下是终端快捷键列表：

键盘快捷键描述
Ctrl + D使用这个快捷方式，我们可以关闭终端窗口。
Ctrl + +此快捷方式用于放大。
Ctrl +-此快捷方式用于缩小。
Ctrl + L清除终端
Ctrl + C使用这个快捷方式，我们可以取消当前正在运行的命令。
Ctrl + A使用这个快捷方式，我们可以将光标移动到行首。
Ctrl + B使用此快捷方式，我们可以将光标向后移动到一个字符。
Ctrl + E使用这个快捷方式，我们可以将光标移动到行尾。
Ctrl + F使用此快捷方式，我们可以将光标向前移动一个字符。

03

截图快捷键

以下是截图快捷键列表：

键盘快捷键描述
Print Screen使用这个快捷按钮，我们可以截图。
Ctrl + Print Screen截图到剪贴板
Alt + Print Screen使用此快捷方式，我们可以截取窗口的屏幕截图。
Ctrl + Shift + Print Screen借助此快捷方式，我们可以将某个区域的屏幕截图复制到剪贴板。
Ctrl + Alt + Print Screen借助此快捷方式，我们可以将窗口的屏幕截图复制到剪贴板。
Shift + Ctrl + Alt + R使用此快捷方式，我们可以录制截屏视频。

04

工作区快捷键

以下是工作区快捷方式列表：

键盘快捷键描述
Shift + Ctrl + Alt + ↑我们可以将窗口向上移动一个工作区。
Shift + Ctrl + Alt + 向下翻页我们可以将窗口向下移动一个工作区。
Shift + Ctrl + Alt + ←我们可以将窗口向左移动一个工作区。
Shift + Ctrl + Alt + →我们可以将窗口向右移动一个工作区。
