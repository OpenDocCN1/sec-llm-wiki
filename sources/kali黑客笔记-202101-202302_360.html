前言

DDoS 攻击工具通过在网络中查找易受攻击的系统并在这些系统上注入恶意软件来针对服务器或网络。一旦网络内有足够多的设备受到感染，DDoS 攻击工具就会指示每个受感染的系统通过发送大量请求和使服务器或网络过载来攻击服务器，从而导致速度减慢、拒绝服务或完全失败。由于各种原因，本文只做简单的描述，懂否~

Dos与DDos的区别

DoS（拒绝服务）是一种用于拒绝合法用户访问资源（例如访问网站、网络、电子邮件等）的攻击。分布式拒绝服务 (DDoS) 是一种 DoS 攻击，由许多用户针对同一受害者的攻击。

常见工具

01 DDoS 攻击

DDoS攻击是一种可用于执行分布式拒绝服务攻击的工具。此应用程序可以监控来自众多来源的事件日志，以查找和检测 DDoS 活动。

特征：

  • 此应用程序可以检测与控制服务器和命令的通信。

  • 提供实时响应。

  • 可以轻松过滤特定的时间范围、IP 或参数。

  • 该工具可帮助您检测命令和控制服务器之间的恶意活动。

02 PRTG

PRTG网络监控软件以其先进的基础设施管理功能而闻名。该工具使用 SNMP、WMI、嗅探、REST APIS、SQL 等技术监控 IT 基础设施。


特征：

  • PRTG 可以通过 ping 定义的 IP 范围来扫描网段

  • 简单灵活的警报

  • 多个用户界面

  • 当它在您的网络中看到警告或异常指标时向您发出警报。



03 LOIC（低轨道离子炮）

LOIC（低轨道离子炮）是用于 DDoS 攻击的开源软件。这个 ddos 工具是用 C# 编写的。此工具向服务器发送 HTTP、TCP 和 UDP 请求。
特征：

  • LOIC 是免费的 ddos 攻击工具之一，可帮助您测试网络性能。

  • 它使您能够针对他们控制的任何站点在线创建 DDoS 攻击。

  • 该ddos软件可用于识别可能被黑客用来攻击计算机网络的ddos程序。
    传送门：https : //sourceforge.net/projects/loic/

04  HOIC（高轨道离子炮）

High Orbit Ion Cannon 是一种免费的拒绝服务攻击工具。它旨在同时攻击多个 URL。此 ddos 工具可帮助您使用 HTTP（超文本传输协议）发起 DDoS 攻击。


特征：

  • 一次最多可以攻击 256 个 ddos 网站。

  • 可以移植到 Linux 或 Mac OS。

  • 可以使用低、中和高设置来控制攻击。

    传送门：https : //sourceforge.net/projects/highorbitioncannon/

05  (HULK)

HTTP Unbearable Load King (HULK) 是一个 Web 服务器 DDoS 工具。它是一种免费的 ddos 攻击工具，专门用于在网络服务器上生成大量流量。
特征：

  • 可以绕过缓存服务器。

  • 可帮助您生成独特的网络流量。
    传送门：https : //packetstormsecurity.com/files/112856/HULK-Http-Unbearable-Load-King.html

06 OWASP HTTP POST

OWASP（开放式 Web 应用程序安全项目）HTTP Post 软件使您能够测试 Web 应用程序的网络性能。它可以帮助您从单个 DDoS 机器在线进行拒绝服务。

特征：

  • 允许您与他人分发和传输该工具。

  • 能够针对应用层攻击进行测试。
    传送门：https : //owasp.org/projects/

07 Tors Hammer（雷神之锤）
Tor的锤是一个应用层DDoS软件程序。您可以使用此DDOS在线工具，目标Web应用程序和Web服务器。它执行的是被用来加载网页的基于浏览器的网络请求。

特征：

  • 它适用于1000〜30000秒HTTP POST请求和连接。
    传送门：https://sourceforge.net/projects/torshammer/
