介绍

**DNSEnum**是一个命令行工具，可自动识别基本 DNS 记录，例如 MX、邮件交换服务器、NS、域名服务器或 A（域的地址记录）。它还尝试在所有已识别服务器上进行区域传输，并且能够尝试反向解析（即，获取给定 IP 地址的主机名）和暴力破解（查询主机名的存在以获取其 IP 地址）子域和主机名。

  

01

使用示例

```

dnsenum bbskali.cn
```
