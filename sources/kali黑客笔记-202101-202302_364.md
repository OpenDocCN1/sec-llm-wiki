> 无需任何环境，便可获取服务器磁盘、内存、负载、等相关使用情况。

### 使用方法

```
vim bbskali.sh #创建sh文件，将下面的代码复制到里面。
#添加运行权限


```

会在`root`目录下生成`bbskali.html`文件！浏览器打开即可！

### 代码

```
#!/bin/bash
'{print $2}'
`"/"|awk '{print $1}'
`"/"|awk '{print $2}'
`"/"|awk '{print $3}'
`"/"|awk '{print $4}'
`"/"|awk '{print $5}'
`"/"|awk '{print $6}'
`"/"|awk '{print $7}'
`#free-h
"Mem"|awk '{print $1}'
`"Mem"|awk '{print $2}'
`"Mem"|awk '{print $3}'
`"Mem"|awk '{print $4}'
`"Mem"|awk '{print $5}'
`"Mem"|awk '{print $6}'
`"Mem"|awk '{print $7}'
`#fuzai
'sub(/,/,"",$11)'|awk '{print $11}'
`"/"| awk 'sub(/%/,"",$6)'|awk '{print $6}'
`"Mem"|awk '{print $2}'
`"Mem"|awk '{print $3}'
`

"<html>$ip

</td>$nc2/$nc1

;  $fuzai

*100,$cp

,
echo -e "$html"
 >/root/bbskali.html
```
