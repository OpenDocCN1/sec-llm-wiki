### 开启Telnet

为了更好的玩，我替朋友开启了Telnet。环境如下：

*   Python3(必须)
*   路由器和电脑在同一局域网内
*   打开路由器进入路由后台

### 下载利用脚本

```
git clone
 https://github.com/shenmeiqian/OpenWRTInvasion.gitcd

 OpenWRTInvasion
```

![](../Images/ae6d699c9ec6a7bbd067103bd1d7c1a4.png)输入完之后系统会提示你输入路由器的ip 默认是`192.168.31.1`回车之后会让你输入`stok`。这个stok就在上面我说的不让你关闭的小米路由器的管理页面。![](../Images/d65217bef669ad889095696a2cb34430.png)当显示`telnet 192.168.31.1`的时候一般来说就是成功了![](../Images/be251e8fd5d7bbeae51e9457008848da.png)

### 登录Telnet

```

telnet 192.168.31.1
```

提示你输入用户名 此时输入 `root`密码为空直接回车![](../Images/187ec9dd6c8213aac9fa53d28e1a5844.png)当然，开启了Telnet我们可以给路由器刷入其他的固件。但是由于不是自己的，也就打住了！又想刷其他固件的，可以参考网上的其他教程。
