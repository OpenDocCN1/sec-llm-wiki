美化nmap报告模板

### 

> 利用nmap可以生成我们对目标主机的扫描结果。通过生成的报告可以直观的告诉我们，目标主机开启了那些端口和信息，方便我们渗透。但是nmap自带的样式并不是很美观。于是在前人的基础上进行了细化和修改。让生成的报告更加美观。老板看后都直接给我涨了工资！迎娶了白富美，从此踏上了性福的人生。

### 生成报告

```

nmap -T4 -A 192.168.1.1/24 -oX bbskali.xml
```

\*\*注意：\*\*生成的报告格式为xml

### 下载文末的附件

下载完成后放到`/usr/share/nmap`替换原来的`nmap.xsl`

### 格式转换

为了更好的阅读，我们需将`xsl`文件转换为`html`执行命令：

```

xsltproc -o nmap报告.htm  bbskali.xml
```

**注：**`bbskali.xml`就是我们上步生成的报告![](../Images/2c9efcc0448bf7474016b6cb86c7b978.png)![](../Images/bfa9fa4c0a39c080368819a9c6b91f28.png)
