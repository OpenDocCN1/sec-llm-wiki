> XSS是一种发生在Web前端的漏洞，所以其危害的对象也主要是前端用户。XSS漏洞可以用来进行钓鱼攻击、前端js挖矿、盗取用户cookie，甚至对主机进行远程控制。

```

<?php "display_errors"
, 0);$str = $_GET["name"

通过`GET`方法，将`name`的值赋值为变量`$srt`并将其直接输出。即！如果name=`<script>alert()</script>`时，将会把结果直接输出。构造POC

```
http://192.168.123.240/level1.php?name=%3Cscript%3Ealert('bbskali.cn'

### leve2

![](../Images/64788172600bb8c2989679af16d83916.png)**代码解读**

```

<?php "display_errors"
, 0);$str = $_GET["keyword"
];echo "<h2 align=center>没有找到和".htmlspecialchars($str)."相关的结果.</h2>".

'<center>.$str.

'">

;
```

我们对数据进行抓包分析![](../Images/8b969fd26655a90a5be0e09ef805d42e.png)后台过滤了<>符号，对其进行了实体化。但是我们发现了另一个可搞的地方。input标签的value值，正是我们的输入内容，且没有过滤。修改payload：`"><script>alert()</script>`提前将input标签闭合，让`<script>`独立出来。

### leve3

![](../Images/25229b36793c76b1aa772349c854faa4.png)代码分析![](../Images/ce78b68e18e988f44d9aaed0b8494844.png)发现value里的<>也被实体化掉了 以采用“事件”，常用的有两个，`onclick`和`onmouseover`。这里用onmouseover，payload：`' onmouseover='javascript:alert(1)`这个为什么会起作用呢？你把它带进input的value就明白了。带入：源码中就会被修改成：`<input name=keyword value=' ' onmouseover='javascript:alert(1)'>`![](../Images/a3492beed2bb373ef68c64a8f1402845.png)注入成功后，鼠标移动到input输入框，就会触发

![](../Images/31ca983bf82b8693652622ff019c775a.png)

### leve4

![](../Images/53600ece396c7204f8c7ba0b9cb94950.png)和leve3的原理一样，只不过需要将`'`改为`"`payload:`" onmouseover='alert(1)'`![](../Images/0d1fbfe0ae599e24a4f3c6db94b69664.png)

### leve5

![](../Images/b4641d5015f6154d9af0fb495d448db1.png)发现事件也被过滤掉了。不要感到束手无策，前两题我们用事件是因为，<>不能用。但是这关没限制呀。我们只是不能用script，还有好多标签可用，比如`<a>`, `<img>`。所以我们提前闭合`input`给`<a>`即可 payload:`" /> <a href=javascript:alert()>bbskali.cn</a>`![](../Images/2900f8c0f0b517f165da80f6f3b7e6ae.png)

### leve6

同样的套路，但是发现超链接屏蔽了。![](../Images/e392748538c61beaa9305d6b260f7196.png)将`href`进行了屏蔽，那么有么有屏蔽`Href`等大小写组合呢？OK 成功！![](../Images/f14828d7b487e9193504d0564e176392.png)

### leve7

![](../Images/8c798b7999701b63550f92015bfb114e.png)script字符串被整个的过滤掉了，输入的on被过滤掉了，javascript的script也过滤了。payload：`"><scripscriptt>alert()</scrscriptipt>`

### leve8

![](../Images/5dbc216dfa03a2192d82054bf11382af.png)发现输入框的value会被填进超链接的href里面去。所以我们只需构造href就好了。javascript被过滤了。这里你发现调整大小写也没有用。怎么办？我们就可以使用&#116替换javascript中的t，从而绕过过滤。payload：`javascrip&#116:alert()`

### leve9

![](../Images/0d55e40654741f5862becdfb8c34d65a.png)输入中要有http://才能被识别写入。paylaod：`javascrip&#x74:alert()//http://`

### leve10

![](../Images/de2881b997f5f3bf9a4fa4276abb59e3.png)没有输入框，也没有超链接了。![](../Images/4ef48877bb54b80dddee47c98fb225d0.png)通过发现，将输入框隐藏了而已。payload:`t_sort=" type="text" onmouseover=alert() "`![](../Images/70146374dba94693a8e6e1ab504ad5e8.png)
