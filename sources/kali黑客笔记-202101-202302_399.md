# Kali Linux 2020.4 安装详细讲解

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxMzIwNTY1OA==&mid=2247483716&idx=1&sn=8789eb5876f2cb0cd95bc6ad63d5c0f0&chksm=c10071b1f677f8a7212aa84cc3f5867e7f586fac30a828935203cd0b3e8e809110f0d96a3fd8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkxMzIwNTY1OA==&mid=2247483716&idx=1&sn=8789eb5876f2cb0cd95bc6ad63d5c0f0&chksm=c10071b1f677f8a7212aa84cc3f5867e7f586fac30a828935203cd0b3e8e809110f0d96a3fd8&scene=27#wechat_redirect)

![](../Images/d5c9f9c1f5d7cedf43345fde496b4b49.png)

Kali Linux是目前最流行的渗透测试系统。基于Debian开发。里面集成了 WiFi 、SQL、密码破解、web渗透测试等用到的各种工具。是学习网络安全必不可少的工具。本文将讲诉如何在虚拟机中安装Kali Linux。

![](../Images/9ee2ad337ccccb27ed908a7bcf20ab57.png)

  

01

获取映像文件

  

Kali Linux官网：

 【速度较慢】

下载建议使用迅雷下载。

此处选择官网获取，访问官网进入获取模块  
![](../Images/f004e68474088e8ae7b019f9e982636b.png)

  

点击选择获取Kali Linux 2020.4 64-bit版本的映像文件（建议迅雷获取）  
![](../Images/a667776b04b50a55104fa6ada7b65a7c.png)

  

02

虚拟机配置

使用虚拟机工作站VMware Workstation Pro15.5.0（安装过程省略，没有的话可以参考其它网络资源安装）

打开VM，新建虚拟机  
![](../Images/7ec908c926a8d38b4b22ce1bbc4652fd.png)

  

无特殊情况，默认使用典型（推荐）安装

![](../Images/de2a1b8b52271b8bc3c6e80c940aaec9.png)

  

使用获取好的Kali Linux 2020.4 映像文件进行安装

![](../Images/b5d472b3c1c740d2790ad03f489987c8.png)

  

选择客户机操作系统类型

![](../Images/d553b23e6f9908e9dc1e01d6e6ba0807.png)

  

设置虚拟机的名称、虚拟机文件的安装位置

![](../Images/d557ef5394e4e4e5cf7ef7c3e012a50c.png)

  

无特殊情况，硬盘大小使用默认20GB即可

  
![](../Images/a3c50a671039f097ecfb9588574eab91.png)

  

完成安装

![](../Images/6adf049a208a5bfbb807a5aee73b838b.png)

  

开启虚拟机

  
![](../Images/1ad4425ff4042bdee9bbfcd585f823c6.png)

  

选择图形化界面安装方式

![](../Images/7240d03fe12ef185cb54495c8ea4e98c.png)

  

**选择中文**

![](../Images/d9f8452085b0a003e40d8da81cc63cdb.png)  
![](../Images/3746938b46974386f2f4761e3f1d083d.png)  
![](../Images/5f9b6ad6ced37a4494f49b00eb07e52b.png)

  

设置一个主机名（可在网络中展示），这里选择默认：kali

![](../Images/cbca57c32ba7aeeacc9c9e0aae6e4c99.png)

  

设置域名，无特殊情况选择默认为空

![](../Images/00608565c9cf010d590c96c9db22d2fa.png)

  

设置一个喜欢的用户名，创建一个用以取代root执行非管理任务的普通用户账户（这里的用户名之后需要用来登陆系统，我的用户名为boolo）  
![](../Images/161855329d57a0cdb80eb4ec01d99e6d.png)  
![](../Images/ad2823bc6427cfd7bb15ab1944e178f2.png)

设置一个用户账户的密码，注意这里不是设置root账户的密码（这里的密码之后需要用来登陆系统，我的对应为账户boolo的密码）  
![](../Images/ac4ba0e185cf24aaa1898fbc13a5ad0d.png)

  

无特殊情况，选择使用整体磁盘进行分区  
![](../Images/41de538d5d160e58f045aa88743ccaf8.png)

  

选择使要分区的磁盘  
![](../Images/8591369dd53454eadc45f1377705bc09.png)

  

无特殊情况，选择使将所有文件放在同一个分区中  
![](../Images/f2d81d8e5092ee78b115603dc9690ba1.png)

  

结束分区设定并将修改写入磁盘  
![](../Images/1bdfda6afe6422e4531362d7a0dbfa51.png)

  

注意：这里需选择“是”！

![](../Images/6320b9fc8b0eaa0c8b997dbfe49eb018.png)

  

接下来会安装基本系统，需要花费一点时间(建议固态安装)

![](../Images/9af3684c0351bd22880a6a30d90e70aa.png)

  

HTTP代理信息，无特殊情况选择默认为空  
![](../Images/be2bb3942bf29238291366e8631358b3.png)

  

这里需要选择Xfce桌面环境（首选，桌面环境选其中一个就行），否则安装完毕后Kali Linux将无法使用图形化桌面环境，只能使用命令行环境  
无特殊情况，其它软件选择默认勾选项即可，如图所示

注：无“…”表示主菜单，有“…”表示对应的子菜单

![](../Images/6c3eb57bc4387112e688f8db9477be88.png)

  

接下来会获取安装软件，需要花费一点时间  
![](../Images/d34270198e5f2bbd9af72b9f1488416a.png)

  

将GRUB安装到硬盘，选择“是”，注意选择设备为“/dev/sda”  
![](../Images/2eb1ac805f1903629ce4df96f915e62f.png)  
![](../Images/12ad33eeefe5b98cf14bb921a83eb7d7.png)

  

结束安装进程，需要花费一点时间  
![](../Images/38605a21d1bcb36a845cb357febb7b0a.png)

  

完成安装，点击“继续”，虚拟机将自动重启  
![](../Images/a6540996afdd692770b70fa2fc7fac61.png)

  

开机，选择“Kali GNU/Linux”  

![](../Images/d708ec455db4d2c5b46a74a4bfe45ee3.png)

  

使用先前设置的用户账户名和密码进行登录  

  

![](../Images/28f8edbb245a027a8250c490e55b85df.png)

  

恭喜你，安装完成！

![](../Images/593388cf213ce328b7c219b2b7e48909.png)
