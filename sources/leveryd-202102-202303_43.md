# 分析过程

*   最简便的方法找到"kernel.inc"文件位置
    
    strace -f可以跟踪子进程的系统调用
    
    ```
    [root@instance-fj5pftdp Cosmos]# strace -f make 2>/tmp/q.txt
    # cat /tmp/q.txt
    
    "kernel.inc"
    , O_RDONLY) = -1 ENOENT (没有那个文件或目录)"../includekernel.inc"
    , O_RDONLY) = -1 ENOENT (没有那个文件或目录)"../include/bastypeinckernel.inc"
    , O_RDONLY) = -1 ENOENT (没有那个文件或目录)"../include/halinckernel.inc"
    , O_RDONLY) = -1 ENOENT (没有那个文件或目录)"../include/knlinckernel.inc"
    , O_RDONLY) = -1 ENOENT (没有那个文件或目录)"../include/libinckernel.inc"
    , O_RDONLY) = -1 ENOENT (没有那个文件或目录)"../include/drvinckernel.inc"
    , O_RDONLY) = -1 ENOENT (没有那个文件或目录)"../hal/x86/kernel.asm:6: "
    , 25../hal/x86/kernel.asm:6: ) = 25
    ```
    
    可以发现 `../includekernel.inc`等路径少了一个`/`符号
    
    修改后，就编译成功了
