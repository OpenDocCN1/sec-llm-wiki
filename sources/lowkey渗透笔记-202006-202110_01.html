前期准备

  • 系统：centos7 #演示用的centos7.6.1810,以下简称centos7

  • 环境：docker、pip3

  • 靶场：vulhub

搭建步骤

  1. 下载centos7镜像

    1. 下载地址：https://archive.kernel.org/centos-vault/7.6.1810/isos/x86_64/CentOS-7-x86_64-DVD-1810.iso

  1. 下载vulhub安装包

    1. 下载地址：https://github.com/vulhub/vulhub/archive/master.zip

  1. 安装centos7

    1. vmware安装硬盘最好80G+

    2. 直接选择安装centos7

    3. 默认选择英文

    4. 需要配置时间，组件，分区

    5. 时间选择上海，然后done

    6. 组件如图选择

    7. 硬盘选择配置

    8. 如图配置，/home 2G、/boot 2G、swap 2G、剩下全给根目录

    9. 点击done后点这里

    10. 然后开始安装

    11. 配置root密码

    12. 设置简单密码需要点两次done

    13. 安装完成后重启系统

      1. 优化centos7配置

        1. 关闭防火墙 systemctl stop firewalld.service

        2. 关闭开机自启动防火墙 systemctl disable firewalld.service

        3. 安装docker yum install -y docker

        4. 开启docker systemctl start docker

          1.  

        5. 开启开机自启docker systemctl enable docker

          1.  

        6. 安装python3 yum install -y python3

          1.  

        7. 安装python3-pip yum install -y python3-pip

        8. 更新pip包 pip3 install --upgrade pip

        9. 安装docker-compose 1.26.2 pip install docker-compose==1.26.2

          1.  

        10. reboot重启

        11. 下边写成了脚本，直接保存为docker.sh，然后chmod 777 docker.sh可直接执行

          #/bin/bashsystemctl stop firewalld.servicesystemctl disable firewalld.servicedhclient -r && dhclient -vyum install -y dockersystemctl start dockersystemctl enable dockeryum install -y python3yum install -y python3-pippip3 install --upgrade pippip install docker-compose==1.26.2reboot

      1. 搭建vulhub

        1. 将下载好的vulhub zip包用xshell等工具传入到centos7中

        2. unzip vulhub.zip

        3. 然后需要哪个漏洞，进入对应的文件夹就可以了，执行docker-compose up -d  就可以开启靶场

        4. docker-compose up -d 开启靶场

        5. docker-compose down 关闭靶场
