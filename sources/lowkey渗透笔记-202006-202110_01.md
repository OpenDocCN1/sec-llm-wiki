# 前期准备  

*   系统：centos7 #演示用的centos7.6.1810,以下简称centos7
    
*   环境：docker、pip3
    

*   靶场：vulhub

4.  优化centos7配置
    

1.  关闭防火墙 systemctl stop firewalld.service
    

1.  ![](../Images/b22fe0de89666f5f51adc8aa63f7842e.png)

5.  安装docker yum install -y docker
    

1.  ![](../Images/2b4c1a325fa19b56355f7708e1c242f0.png)
    

7.  开启docker systemctl start docker
    

1.   ![](../Images/82fc04f4d124c78680a2a75ef3844201.png)
    

9.  开启开机自启docker systemctl enable docker
    

1.   ![](../Images/cf87e048b7318cdafc6321091a9a8983.png)
    

11.  安装python3 yum install -y python3
     

1.   ![](../Images/2981216a52392e4a7148ac319068fb33.png)

1.  ![](../Images/1156387c4faa838e0ca369426e392ccb.png)

5.  搭建vulhub
    

1.  将下载好的vulhub zip包用xshell等工具传入到centos7中
    

1.  ![](../Images/b0e509e17a28ecd8efc55e23aadc1bf6.png)
    

3.  unzip vulhub.zip
    

1.  ![](../Images/22666865b8bec3802cdd67c8e768a132.png)
    

5.  然后需要哪个漏洞，进入对应的文件夹就可以了，执行docker-compose up -d  就可以开启靶场
    
6.  docker-compose up -d 开启靶场
    
7.  docker-compose down 关闭靶场
