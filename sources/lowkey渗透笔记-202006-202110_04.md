函数  多行处理函数  #别名：分组函数    count  计数    sum    求和    avg    平均值    max    最大值    min    最小值    注：1.所有的分组函数都是对某一组数据进行操作      2.自动忽略null      3.分组函数也能组合起来用        eg:mysql> select count(*),max(age),min(age),avg(age),sum(age) from student;            +----------+----------+----------+----------+----------+            | count(*) | max(age) | min(age) | avg(age) | sum(age) |            +----------+----------+----------+----------+----------+            |        4 |       19 |       10 |  14.7500 |       59 |            +----------+----------+----------+----------+----------+            1 row in set (0.00 sec)
          1、count  计数id    mysql> select count(id) from t_user;      +-----------+      | count(id) |      +-----------+      |         3 |      +-----------+      1 row in set (0.03 sec)    注：count(*)和count(某个字段)区别      count(*)：不是统计某个字段的个数，而是统计总记录的条数      count(某个字段)：字段中不记录null的数据总量          2、sum  求和id    mysql> select sum(id) from t_user;      +---------+      | sum(id) |      +---------+      |       5 |      +---------+      1 row in set (0.05 sec)          3、avg id的平均值     mysql> select avg(id) from t_user;      +---------+      | avg(id) |      +---------+      |  1.6667 |      +---------+      1 row in set (0.04 sec)          4、max  最大id    mysql> select max(id) from t_user;      +---------+      | max(id) |      +---------+      |       2 |      +---------+      1 row in set (0.03 sec)          5、min  最小id    mysql> select min(id) from t_user;      +---------+      | min(id) |      +---------+      |       1 |      +---------+      1 row in set (0.00 sec)      单行处理函数      ifnull()  空处理函数  #ifnull(字段为null时，当做100)      mysql> select ifnull(table_catalog,100) from schema_privileges;        +---------------------------+        | ifnull(table_catalog,100) |        +---------------------------+        | 100                       |        | 100                       |        | 100                       |        | 100                       |        | 100                       |        | 100                       |        | 100                       |        | 100                       |        | 100                       |        | 100                       |        | 100                       |        | 100                       |        +---------------------------+        28 rows in set (0.00 sec)
