sql语句写法：  简单查询语句：    语法格式：      select        字段名1,字段名2,字段名3......       from        表名;    提示：      1、sql语句以";"结尾      2、sql语句不区分大小写      3、字段可以参加数学运算      4、字符串中文用''括起来      5、as关键字可以省略        简单查询：    1、查询语句：      select id,ip from kite_log; #在kite_log表中查询id,ip字段        mysql> select id,ip from kite_log;        ERROR 2006 (HY000): MySQL server has gone away        No connection. Trying to reconnect...        Connection id:    9        Current database: hacker        +----+----------------+        | id | ip             |        +----+----------------+        |  1 | 171.217.162.33 |        |  2 | 183.192.37.142 |        |  3 | 124.204.43.26  |        |  4 | 127.0.0.1      |        |  5 | 127.0.0.1      |        |  6 | 127.0.0.1      |        |  7 | 127.0.0.1      |        |  8 | 127.0.0.1      |        +----+----------------+        8 rows in set (0.00 sec)            2、字段参加运算      mysql> select id * 10,ip from kite_log;  #在kite_log表中查询id*10,ip字段        ERROR 2006 (HY000): MySQL server has gone away        No connection. Trying to reconnect...        Connection id:    10        Current database: hacker        +---------+----------------+        | id * 10 | ip             |        +---------+----------------+        |      10 | 171.217.162.33 |        |      20 | 183.192.37.142 |        |      30 | 124.204.43.26  |        |      40 | 127.0.0.1      |        |      50 | 127.0.0.1      |        |      60 | 127.0.0.1      |        |      70 | 127.0.0.1      |        |      80 | 127.0.0.1      |        +---------+----------------+        8 rows in set (0.00 sec)                  3、字段重命名      mysql> select id * 10 as '测试',ip from kite_log;  在kite_log表中查询id*10重命名为测试,ip字段        +------+----------------+        | 测试 | ip             |        +------+----------------+        |   10 | 171.217.162.33 |        |   20 | 183.192.37.142 |        |   30 | 124.204.43.26  |        |   40 | 127.0.0.1      |        |   50 | 127.0.0.1      |        |   60 | 127.0.0.1      |        |   70 | 127.0.0.1      |        |   80 | 127.0.0.1      |        +------+----------------+        8 rows in set (0.00 sec)      注：as关键字可以省略                条件查询：    语法格式：      select        字段名1、字段名2、字段名3....      from        表名      where        条件;    顺序：先from,然后where,最后select        1、查询kite_log表中ip等于127.0.0.1的ID      mysql> select id from kite_log where ip='127.0.0.1';        +----+        | id |        +----+        |  4 |        |  5 |        |  6 |        |  7 |        |  8 |        +----+        5 rows in set (0.03 sec)        2、查询kite_log表中ip不等于127.0.0.1的ID      mysql> select id from kite_log where ip <> '127.0.0.1';           select id from kite_log where ip != '127.0.0.1';        +----+        | id |        +----+        |  1 |        |  2 |        |  3 |        +----+        3 rows in set (0.00 sec)      注：!= 不等于        <> 不等于            3、查询kite_log表中id大于等于2小于等于6的ip      mysql> select ip from kite_log where id >=2 and id <=6;           select ip from kite_log where id between 2 and 6;        +----------------+        | ip             |        +----------------+        | 183.192.37.142 |        | 124.204.43.26  |        | 127.0.0.1      |        | 127.0.0.1      |        | 127.0.0.1      |        +----------------+        5 rows in set (0.01 sec)      注：between...and...左小右大，是闭区间[2~6]          4、null为空，不为空值      mysql> select ip from kite_log where title is null;        +----------------+        | ip             |        +----------------+        | 171.217.162.33 |        | 183.192.37.142 |        | 124.204.43.26  |        | 127.0.0.1      |        | 127.0.0.1      |        | 127.0.0.1      |        | 127.0.0.1      |        | 127.0.0.1      |        +----------------+        8 rows in set (0.00 sec)    5、or(或者)满足一个条件即可      mysql> select id from kite_log where ip = '127.0.0.1' or title is null;        +----+        | id |        +----+        |  1 |        |  2 |        |  3 |        |  4 |        |  5 |        |  6 |        |  7 |        |  8 |        +----+        8 rows in set (0.00 sec)                6、and(并且)满足两个条件      mysql> select id from kite_log where ip = '127.0.0.1' or title is null;        +----+        | id |        +----+        |  1 |        |  2 |        |  3 |        |  4 |        |  5 |        |  6 |        |  7 |        |  8 |        +----+        8 rows in set (0.00 sec)    7、and和or同时出现时，默认and优先级大于or      mysql> select user from users where user_id > 2 and last_name = 'Me' or last_name = 'Smith';        ERROR 2006 (HY000): MySQL server has gone away        +--------+        | user   |        +--------+        | 1337   |        | smithy |        +--------+        2 rows in set (0.04 sec)              注：当无法确定优先级时，添加()的优先级大            mysql> select user from users where user_id > 2 and (last_name = 'Me' or last_name = 'admin');        +------+        | user |        +------+        | 1337 |        +------+        1 row in set (0.00 sec)            8、in等同于or  #in后边的每一个值都是具体的值，不是区间      mysql> select user from users where first_name in ('admin','Hack');        +-------+        | user  |        +-------+        | admin |        | 1337  |        +-------+        2 rows in set (0.00 sec)    效果同：      mysql> select user from users where first_name = 'admin' or first_name = 'Hack';        +-------+        | user  |        +-------+        | admin |        | 1337  |        +-------+        2 rows in set (0.00 sec)        9、not in 不在这个值内      mysql> select user from users where first_name not in ('admin','Hack');        +---------+        | user    |        +---------+        | gordonb |        | pablo   |        | smithy  |        +---------+        3 rows in set (0.00 sec)    10、like 模糊查询        %代表任意多个字符        _代表任意一个字符        \转义      找出user中带d的      mysql> select user from users where user like '%d%';        +---------+        | user    |        +---------+        | admin   |        | gordonb |        +---------+        2 rows in set (0.00 sec)      找出user中第二个字母是d的      mysql> select user from users where user like '_d%';        +-------+        | user  |        +-------+        | admin |        +-------+        1 row in set (0.00 sec)      找出name中带_的      mysql> select name from t_user where name like '%\_%';        +-----------+        | name      |        +-----------+        | Zhang_San |        +-----------+        1 row in set (0.00 sec)        11、order by  排序      asc    #升序      desc  #降序    按照user_id降序排列    mysql> select user from users order by user_id desc;      +---------+      | user    |      +---------+      | smithy  |      | pablo   |      | 1337    |      | gordonb |      | admin   |      +---------+      5 rows in set (0.00 sec)    按照id降序排列    mysql> select * from t_user order by  id desc;      +------+-----------+      | id   | name      |      +------+-----------+      |    2 | Zhang_San |      |    2 | Li_Si     |      |    1 | admin     |      +------+-----------+      3 rows in set (0.03 sec)    按照id降序排列当id相同时安装姓名升序排列    mysql> select * from t_user order by  id desc,name asc;      +------+-----------+      | id   | name      |      +------+-----------+      |    2 | Li_Si     |      |    2 | Zhang_San |      |    1 | admin     |      +------+-----------+      3 rows in set (0.00 sec)    按照第二列排序    mysql> select * from t_user order by 2;      +------+-----------+      | id   | name      |      +------+-----------+      |    1 | admin     |      |    2 | Li_Si     |      |    2 | Zhang_San |      +------+-----------+      3 rows in set (0.00 sec)    查询id=2的人员并按照姓名排序    mysql> select * from t_user where id = 2 order by name asc;      +------+-----------+      | id   | name      |      +------+-----------+      |    2 | Li_Si     |      |    2 | Zhang_San |      +------+-----------+      2 rows in set (0.04 sec)
