w13scan是一款插件化基于流量分析的扫描器，通过编写插件它会从访问流量中自动扫描，基于Python3。

详细说明参考git主页说明 https://github.com/w-digital-scanner/w13scan/blob/master/README_CN.md

1.mac 下安装

我来重点说一下安装。在mac 如果有安装python3 

直接php install w13scan  就可以了。

2 kali下安装

在kali2020.1版本中 pip 或者pip3 是没有安装的。


2.1首先来安装 pip3 

sudo apt-get install python3-pip


2.2 安装w13scan

pip3 install w13scan


2.3 启动 w13scan


3 w13scan的使用

首先在终端下启动 w13scan 

使用其他参数还是可以查看帮助文档。

3.1 设置浏览器代理

设置本地浏览器代理 127.0.0.1:7778 或者使用代理插件


3.2 测试效果

浏览器访问靶机上的dvwa 随便访问一下带有漏洞的模块 提交参数。

w13scan终端会自动匹配http状态 进行安全检测。
