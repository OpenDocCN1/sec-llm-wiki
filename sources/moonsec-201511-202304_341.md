# kali2020.1/mac 下安装 w13scan 被动扫描器和使用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMjc0NTEzMw==&mid=2653570615&idx=1&sn=89fc750ad1e6aab52f894929426fa495&chksm=811b5075b66cd9631a6ca3dfcce8e00a940b117b3328bcc625d045d0fb045d7e249a659b1131&scene=126&sessionid=1681665156#rd](http://mp.weixin.qq.com/s?__biz=MzAwMjc0NTEzMw==&mid=2653570615&idx=1&sn=89fc750ad1e6aab52f894929426fa495&chksm=811b5075b66cd9631a6ca3dfcce8e00a940b117b3328bcc625d045d0fb045d7e249a659b1131&scene=126&sessionid=1681665156#rd)

w13scan是一款插件化基于流量分析的扫描器，通过编写插件它会从访问流量中自动扫描，基于Python3。

![](../Images/6ec156ec9f3c421b5c9aca4061be01a7.png)

详细说明参考git主页说明 https://github.com/w-digital-scanner/w13scan/blob/master/README\_CN.md

**1.mac 下安装**  

我来重点说一下安装。在mac 如果有安装python3 

直接php install w13scan  就可以了。

![](../Images/0dcf33addcb763100acbfe7257d70755.png)

**2 kali下安装**

在kali2020.1版本中 pip 或者pip3 是没有安装的。

  

2.1首先来安装 pip3    

sudo apt-get install python3-pip

  

2.2 安装w13scan   

pip3 install w13scan

  

2.3 启动 w13scan

![](../Images/f19584baac2d1be380e2ee4c5ff2c26c.png)

  

**3 w13scan的使用  
**

首先在终端下启动 w13scan 

使用其他参数还是可以查看帮助文档。

![](../Images/b178639bfdafae138ac62a13ad12a052.png)

设置本地浏览器代理 127.0.0.1:7778 或者使用代理插件
