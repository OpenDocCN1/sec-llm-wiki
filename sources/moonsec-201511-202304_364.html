延时注入 等于时间差注入

 

延时注入往往用于难于判断页面 是否存在注入漏洞的检测方法。

 

延时注入的原理：在mysql中存在sleep函数，这个函数是主要让数据库查询的结果，等待多少秒返回给客户端，可以使用这个函数构造注入语句加以判断即可。

 

Sleep

select sleep(10)

 

if

select if('x'='y',1,0)

 

select if('x'='x',sleep(5),0)
