# 前言

glider是个很香的东西，支持把各种梯子协议聚合起来变成一个随机代理池。这玩意目前唯一的遗憾是对格式有要求，而机场提供的都是base64编码的，那我来魔改一波。

# 机场订阅解析

这玩意最开始是看@zgao师傅弄的，不过当时他并没有说base64他是怎么转换的。既然如此那就只能靠自己了。

首先，把自己买的订阅，简单的转换一下。

```
curl 
```

在每个协议前加上forward=

![](../Images/f7100ca8e29e593a99687e9b473c8331.png)

随便拿一个出来，可以看到解开就是一串json。这里注意有的只有addr，没有host的。

![](../Images/e314674b082e637b11c8482659bdd9c5.png)

转换之后，直接添加到配置文件即可。

配置文件用官方提供的example魔改就行(config/examples/4.multiple\_forwarders/glider.conf)。
