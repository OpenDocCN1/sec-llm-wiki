我个人常用的扫web一般用AWVS，扫主机一般用Nessus。

今天给大家分享雷石安全实验室打包好的docker镜像。


使用


1、拉取镜像


docker pull leishianquan/awvs-nessus:v1


2、启动镜像


docker run -it -d -p 13443:3443 -p 8834:8834 leishianquan/awvs-nessus:v1


3、单独启动nessus服务

#查看容器idsudo docker ps


进入容器，启动服务

sudo docker exec -it 5057d14f8007 /bin/bash# 启动服务/etc/init.d/nessusd start
