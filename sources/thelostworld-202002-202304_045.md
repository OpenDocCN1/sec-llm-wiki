一、maven安装和配置

1、下载安装

下载地址： https://maven.apache.org/download.cgi

![](../Images/807e72736a789f90de821193b1d25b11.png)

下载解压复制到/usr/local/下

![](../Images/741be0b929480ddec28a8d1800f9956a.png)

  

2、配置环境变量

打开终端，输入命令：

*   

```

```

   

如果没有该文件，就输入命令touch ~/.bash\_profile ，再输入上面的命令。

打开.bash\_profile之后，按下i键，使其进入编辑状态。然后输入下面命令来配置环境变量（下面的M，你可以自己命名）：

*   
*   

```
export M="/usr/local/ApacheMaven" export PATH="$M/bin:$PATH"
```

![](../Images/f16fd3378151c8c3f40274a4dea1ef3a.png)

按下esc，退出编辑状态，输入:wq，退出文件。

在终端执行生效命令：

source ~/.bash\_profile

然后执行命令：

mvn -v

正常显示maven的版本等信息，表示配置成功。如果没有，检查路径是否正确，或者版本号名称等。

![](../Images/529445ef00d4bb9247bdfc485c5879b5.png)
