返回的信息比较多，自己想要获取的是系统探测的IP存活的信息：

抓取扫描回来的信息的IP值：

#!/usr/bin/python3#_*_ encoding=utf-8 _*_
import nmapimport click
#相关参数@click.command()@click.option('-ip', default='127.0.0.1/24', help='Input you ip.', type=str)
def Alive(ip):  nm = nmap.PortScanner()  data = nm.scan(hosts=ip, arguments='-sP')  for ip in data['scan'].keys():    print('ip存活: '+ip)
if __name__ == '__main__':  Alive()
