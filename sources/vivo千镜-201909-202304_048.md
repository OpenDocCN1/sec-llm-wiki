# 游戏连麦，隐私无忧！vivo X Note里暗藏的安全黑科技…

vivo新发布的旗舰机 vivo X Note，兼具办公体验和安全性，是商务人士的不二之选。同时，凭借在视觉、续航、散热等性能上的出色表现，再加上独特的大屏手感，也深受游戏达人青睐。  

但大家在日常玩游戏的时候，应该都有过这样的经历：在家里、宿舍或公司等地方与队友游戏语音聊天时，周围家人、室友或同事谈话交流的声音很容易被队友听见，如果刚好谈论的是敏感或者隐私的话题，不仅让人尴尬“社死”，还存在隐私泄露的风险。

![](../Images/cf6fba7a9be10aa1349904d1786c3f7b.png)

如何能畅快开黑，还能避免隐私泄漏？**X Note暗藏的黑科技功能——****三麦降噪****很好地解决了这一痛点。**

当你用X Note与队友开麦互动玩《王者荣耀》游戏时，三麦降噪就会定向角度收取玩家的声音，并屏蔽旁人的语音和环境的杂音，从而既达到了提升声音品质的作用，又很好地保护了玩家的隐私。在全球范围内，目前除了三星，只有vivo实现了这样的技术。

![](../Images/96847cd6bf074a8880647a69774f0b68.png)

三麦降噪为什么有这么好的语音通话和降噪效果呢？有硬件和软件两大层面的原因。

**在硬件层面**，**与一般的手机只有两个麦克风的结构不同， X Note上为了让用户得到更好的声音品质，增加了一个麦克风**，从而形成了顶部+底部+背后镜头组成的相互协同的立体的麦克风阵列，立体麦克风阵列形成的波束，结合AI模型对语音的精确识别，能够精准辨别声音来源的方向；**在软件层面，vivo独有的AI降噪算法和风噪检测机制，降噪效果出色，可大幅提升通话的声音品质。**

![](../Images/b9b66cef538bc5f240996620322f6cf8.png)

（X Note游戏场景定向收音效果示意图）

在这两大层面因素的作用下，就实现了在游戏场景下定向收取游戏玩家的声音，有效去除或抑制身边人的语音和其他杂音的效果，避免背景音泄漏自己及旁人的个人隐私信息。

同时，经过测试，**vivo手机的3 Quest部分指标（语音通话时手机抑制处理周围噪声的能力指标）在4.5分以上**，这意味着在日常通话时，三麦降噪还能让通话质量更清晰、更顺畅。

![](../Images/29272940bb8b81aa7fe95e30e9af9abc.png)

除了游戏场景，后续vivo还会把这项技术应用到会议通话、社交聊天等场景，为用户提供更好的声音品质的同时，保护好用户的隐私。   

可能读到这里，很多用户会惊讶于为了保护用户的通话隐私，vivo竟然在背后做了这么多工作。其实除了三麦降噪这样的安全黑科技， **X Note还内置了SPU安全处理单元，提供基于千镜安全架构的防护体系，搭载千镜可信引擎、远程锁卡、Jovi输入法Pro和隐匿模式等多项同样创新的安全技术和产品。**因为，vivo从来认为用户隐私无大小，只要是用户的真实安全需求，vivo都会持续关注和投资，用最新最好的科技来守护用户隐私，默默构筑用户隐私的防护长城。
