# vivo X Fold、X Note通过泰尔权威认证，信息安全保护能力达最高级！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0Njg4NzE3MQ==&mid=2247488042&idx=1&sn=7f074d19a2cb70c8f8e9549f8499dafd&chksm=e9b93446decebd504ed65b6923f4b7f814cca344a4facb7b57cb1cf7d504e133955ff3670b27&scene=126&sessionid=1681321964#rd](http://mp.weixin.qq.com/s?__biz=MzI0Njg4NzE3MQ==&mid=2247488042&idx=1&sn=7f074d19a2cb70c8f8e9549f8499dafd&chksm=e9b93446decebd504ed65b6923f4b7f814cca344a4facb7b57cb1cf7d504e133955ff3670b27&scene=126&sessionid=1681321964#rd)

手机已成为人们生活的必备品，承载着越来越多的个人数据和隐私信息，手机的安全性成为用户关注的焦点。  

为回应用户的安全诉求，近日，vivo新上市的vivo X Fold和vivo X Note两款手机发布了多个安全功能和安全能力，在获得用户好评的同时，也得到了权威机构的认可——双双获得中国泰尔实验室“移动智能终端安全能力分级测试”五级证书，标志着X Fold、X Note的安全能力均达到中国泰尔实验室认证的最高水准，在安全和隐私保护上值得用户信赖。

中国泰尔实验室的“移动智能终端安全能力分级测试“共包含84条测评项，从硬件安全能力、操作系统安全能力、应用层安全要求、外围接口安全能力和用户数据保护安全能力要求等5个层面提出了严格的标准，并根据基本的安全保障、实现难度、特殊安全能力等层面将终端安全能力划分为5个等级。**X Fold和X Note最终通过全部测试，并获得最高级安全等级的五级证书。**

**![](../Images/ad207ce808685f861630b85d789156a4.png)**

vivo X Fold和X Note两款机型能够顺利通过测评得益于高通SPU芯片级安全守护。**SPU是高通骁龙8Gen1系列内置的安全处理单元， X Fold和X Note采用了骁龙8 Gen1 SPU定制旗舰芯片，充分释放了骁龙8在安全防护上的能力。**

![](../Images/8d3f020d13b5ffacfe6eb9b8a48947bc.png)

X Fold和Note还内置了千镜安全架构，该架构是vivo的全链路隐私安全解决方案，它如同一张“安全网”，覆盖手机的芯片、框架、系统、应用4个层级，全面守护用户的数据和隐私安全。

作为一家用户导向的公司，**vivo始终将用户的安全与隐私保护放在首位，不断提升自身的安全能力，并融入到产品设计当中。**X Fold和X Note搭载的OriginOS系统也在去年获得了中国泰尔实验室颁发的首张移动智能终端操作系统个人信息保护五星证书。此次获得“移动智能终端安全能力”五级证书，是对vivo隐私安全保护能力的又一次认可。

未来，vivo将继续加大产品安全与合规建设，不断向全球最权威的安全隐私标准对齐，获取更多的安全认证，为亿万终端用户的数字化生活保驾护航。
