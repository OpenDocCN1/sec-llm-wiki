**安装方法：**  

  

1.克隆存储库

git clone http://github.com/mzfr/liffy

  

2.建立虚拟环境

  

python3 -m venv <name-of-virtual-env>

  

  
例如：python3 -m venv liffy

  

3.激活虚拟

  

source liffy/bin/activate

  

4.安装依赖

  

pip3 install -r requirements.txt

  

注意 -Liffy使用msfvenom生成php有效负载，因此您应该安装metasploit

  

  

**使用方法：**  

  

  

```
用法：liffy.py \[-h\] \[-d\] \[-i\] \[-e\] \[-f\] \[-p\] \[-a\]
测试 为 LFI
help显示此帮助消息并退出
请勿使用stager
进行攻击
以进行身份验证
```

  

  

  

#### 检查URL与数据：//

选项：`-d`或`--data`

例如： `python liffy.py http://example.com/?id= -d`

#### 使用输入：//检查URL

选项：`-i`或`--input`

例如： `python liffy.py http://example.com/?id= -i`

#### 检查URL与期望：//

选项：`-e`或`--expect`

例如： `python liffy.py http://example.com/?id= -e`

#### 使用filter：//检查URL

选项：`-f`或`--filter`

例如： `python liffy.py http://example.com/?id= -f`

#### 使用/ proc / self / environ执行代码

选项：`-p`或`--proc`

例如： `python liffy.py http://example.com/?id= -p`

#### 使用Apache access.log中毒

选项：`-a`或`--access`

例如： `python liffy.py http://example.com/?id= -a`

#### 使用SSH auth.log中毒

选项：`-s`或`--ssh`

例如： `python liffy.py http://example.com/?id= -s`

#### 相对遍历目录

选项： `-r`

此选项可以与其他选项一起使用，以便相对遍历目录。

例如：

```
- python liffy.py http://example.com/?id= -s -r
```

#### 指定日志路径

选项：`-l`或`--location`

此选项必须与所有日志技术（如`authlog`，`sshlog`

例如：

```
- python liffy.py http://example.com/?id= -s -l /var/auth.log
```

默认情况下，使用以下位置：

*   对于SSH auth.log- `/var/log/auth.log`
    
*   对于apache2 access.log- `/var/log/apache2/access.log`
