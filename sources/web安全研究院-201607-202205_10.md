介绍：

extplorer 是一个文件管理的CMS。

  

从全网搜索：extplorer  即可

  

PHP code file：~\\include\\authentication\\extplorer.php

![](../Images/5ec4ac4a7d03a4172752f96c4046c3df.png)

  

    

如果$data变量不是NULL，则定义会话（登录状态）。

  

PHP code file： ~\\include\\users.php

  

![](../Images/b7d3d631a919c80caaf6ece7c917488c.png)

  

  

如果密码已经存在，将执行73～76行代码。

当密码为NULL时，返回是一个数组，如果不是NULL，返回为NULL。

因此，没有密码参数的提交后为空。

  

发送数据包：

填写已存在账号，不写密码参数请求过去，那么密码的值肯定就是Null
