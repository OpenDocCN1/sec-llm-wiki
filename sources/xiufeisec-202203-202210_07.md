# fofa信息收集

## 1、目的

最近因为一系列问题，之前很多师傅写的工具没法联动fofa.so，渗透过程带来很大困扰，出于目的，为了方便日后安服仔会快速信息收集，简单用python写个信息收集的小工具

## 2、爬坑记录

### 2.1、导出csv

导出csv没有按列插入循环的数据，最后使用`w.writerows(zip(ipline,server,banner))`的方式以列插入数据（辣鸡大佬轻喷）

### 2.2、中文乱码

导出csv中文乱码情况，python3需要使用`encoding='utf-8-sig'`编码，确保导出中文无错

```
import requestsimport base64import jsonimport csv
email = ''api_key = ''install = input("请输入您要查询的内容:")encode = base64.b64encode(install.encode('utf-8'))qbase64 = str(encode, 'utf-8')url = 'https://fofa.info/api/v1/search/all?email=' + email + '&key=' + api_key + '&qbase64=' + qbase64 + '&size=100&fields=ip,port,title,server,banner'  # urlprint('您的查询接口：'+url)
req = requests.get(url)  # 请求接口json_req = json.loads(req.text)  # 接口数据转化为json格式# print(json_req)
ipline = []                         # 定义一个空列表，后期往里边添加数据server = []banner = []header = ['ip', 'title', 'server', 'banner']
with open('xiufei.csv', 'w', encoding='utf-8-sig',newline='') as f:    w = csv.writer(f)    w.writerow(header)    for i in json_req['results']:       # 循环结果，对内容添加        new_ipline = ipline.append(i[0]+":"+i[1])        new_server = server.append(i[2])        new_banner = banner.append(i[3])        w.writerows(zip(ipline,server,banner))
    f.close()
print('查询结束，请在当前目录查看具体信息')

```
