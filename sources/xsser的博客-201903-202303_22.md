// 生成 URL 实例对象
URI url = new URI("https://www.baidu.com/");
//调用 Desktop 中 browse 方法打开URL

可以看到url是可以随意从客户端传递进去的。

  

这个rce的危害在于，如果url参数可控，可以传递file协议开头的内容进去，即可导致RCE
