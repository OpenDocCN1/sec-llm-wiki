下载下来，然后拖拽对应的组件和页面即可设计一个原型

非常的方便！

二.  Umi 和antdesign pro

这个就是安装麻烦了点，大概就是先

npm i @umijs/preset-react -D

然后


再然后

npm run fetch:blocks #这条是获得一些组件，下载全部的组件

 

$ yarn add@umijs/preset-ui -D #这条我也不知道为啥 反正执行就对了

  

$ UMI_UI=1 umi dev #这条是启动一个web. 打开界面就是umi了

   

 

然后接下来就可以模块化 去设计原型，哦不，这强大之处在于原型设计好的同时，代码也写好了…大概就是产品经理+ui+前端，集成在一起了。一个人干3个人的事情，节约了开发，为资本家剩下了工资……


 

第二个方案大家有空可以去学习下。很快的。一个后端程序员也可以快速当产品经理写好原型 你只要专注于开发后端就完事了。蚂蚁金服在用户体验这快上的确很牛逼。开源了不少东西，搜下官网就知道了。

 

当然我因为是在做SDL。所以作为用户，我尽可能学习蚂蚁金服的 一些原则，简约，简单，方便。把复杂的工作丢给后端机器，让前端交互的人用最简单的知识即可学会操作。这个好像也是传统人机交互理念初期的思想。让人机交互变得简单！
