概述 （Overview）

攻击链 （Kiillchain）

这台靶机的攻击路径比较简单，均是已知的 CVE 漏洞利用。首先通过 Nmap 的扫描，得知服务器上运行的 HTTP 服务信息，查看版本信息找到 RCE 脚本。

进一步收集信息，在 mysql 数据库中到了服务器登录账号的加密密码，通过解密获得明文后 SSH 成功连接，拿到立足点。

最终配合 sudo 配置权限滥用完成权限提升。

立足点（Foothold）

接下来就简单了，通过版本找寻找可以造成 RCE 的漏洞。顺利的从文章[1]中找到 CVE 编号，根据编号找到可以执行未经身份验证的 RCE 脚本。

CVE-2018-7600 RCE - https://github.com/FireFart/CVE-2018-7600

将脚本内的 HOST 变量改为目标服务器地址，执行成功返回命令执行结果：

随后简单写一段 PHP 脚本用于接受参数，进行命令执行，见下图窗口 1。随后使用 Python 起了一个 HTTP 服务，改写先前的脚本，通过执行 wget 命令将自己写的 PHP 脚本传递至目标服务器，成功结果见窗口 2。发送 http 请求访问我们的脚本，在窗口 3 中可以看到有结果返回。

查看 passwd 文件中允许远程登录的用户：

root:x:0:0:root:/root:/bin/bash...snip...brucetherealadmin:x:1000:1000::/home/brucetherealadmin:/bin/bash

$databases = array (  'default' =>  array (    'default' =>    array (      'database' => 'drupal',      'username' => 'drupaluser',      'password' => 'CQHEy@9M*m23gBVj',      'host' => 'localhost',      'port' => '',      'driver' => 'mysql',      'prefix' => '',    ),  ),);
