## 阶段2：利用工具

尝试简单枚举一下网站路径：  
![](../Images/a0ecbcd70acbd5ac7a0e1dc4b392ea5c.png)

`/tree/` 路径看着像是一个新的应用。  
![](../Images/adeb804c2d903fcc1ebae34a6274284f.png)页尾发现版本信息 `SilverStripe Tree Control v1.0`  
![](../Images/69bb249ad2cd4d6c9703eec2a7a10714.png)

根据版本信息没有找到什么收获，跑一边大点的字典：

![](../Images/b454631aa17ab01299534d953ad90d18.png)

对比两个字典的结果，发现存在一个 `system-users.txt` 的文件，内容为一组账号和口令(口令提示为默认口令)。

![](../Images/17565305324a26f8e62ac6bb8f32521b.png)  
随后在页面加载的样式链接里发现 `pfsense_ng` 的字符串，google后找到了该靶机所部署的服务。  
![](../Images/9cedd15429706d6060cf9b150d8174f7.png)

> pfSense是基于FreeBSD的开源防火墙解决方案，该发行版本可以免费安装在任意的设备上。

![](../Images/6b50a878107d740733f889c72fe1636d.png)

根据 `.txt` 文件提示的口令信息，google到了该系统的初始账号。

```


https://docs.netgate.com/pfsense/en/latest/usermanager/defaults.html
```

> 组合起来就是 rohit:pfsense

成功登录系统。

![](../Images/eba957dd0bc8d03e96a350d7dececdd0.png)

根据已知的系统名称及版本信息，找到了利用的 exploit：

![](../Images/7359908e232d826c113fbe033a9d811c.png)

## 阶段3：权限提升

查看该 exploit ，验证下 payload 里的页面是否存在：  
![](../Images/2eb167495f0f14b9b5f5754ef00c2b60.png)

![](../Images/15dea4691514c0aad88ec935ee25521f.png)OK，利用页面是存在的，接下来直接修改脚本将完整的 exploit 打印出来。  
![](../Images/ba6470338a7a2c3887add55e7fab492c.png)![](../Images/6f2767651adc5674c01d6f1bab517edc.png)

printf后的 char 对应的内容为：

```















# command to be converted into octal
```

又GET到一个可以bypass命令执行的技巧，奶思啊

![](../Images/49bada675432375febcf1c7d2691918f.png)

将其粘贴至浏览器访问，发现监听的NC已经成功上线。  
![](../Images/e8c44d16324d003a8b6008e59a435779.png)

## 学习-利用env进行bypass命令注入

做完该题后，查看IPPSEC的视频，发现他在bypass这个命令执行时用了另外一个技巧（继续GET，向大佬学习）。

```




通过 `env` 命令查看定义的环境变量，接着利用变量的值进行字符串截取，利用截取的内容去bypass。
```
