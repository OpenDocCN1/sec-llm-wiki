## 信息收集

老规矩 nmap 起手：

![](../Images/124cc8389e86a9fb3c7482aab11f0900.png)

从开放的端口来看，这题肯定是关于SMB的漏洞利用了，何况系统是 Windows 7。尝试查看下共享目录

![](../Images/c7ed68924f04bbc7577ff60f3850e6f6.png)

用nmap扫一遍关于smb的漏洞验证脚本：`$ nmap --script smb-vuln* -p 445 -oA scans/smb_vuln 10.10.10.40`

![](../Images/8f0b32368123a0c01479c424c716af2b.png)

OK，存在上古漏洞 MS17-010 ，但是通过 searchsploit 搜索到的 exp 无法使用，提示错误。随后在HTB的论坛里找，发现也有出现和我一样的问题，楼下用户推荐他使用GitHub上的项目。

![](../Images/9c80940968f883f5c221e84a06eb8577.png)

因为是新版的 kali，默认的 zsh 对 bash 命令做了一层转义，所以需要先进入 bash 才能成功运行。

![](../Images/f4186e79ceaf86c20731b9cb18b404bf.png)

参照生成两个环境的反链程序，分别反向两个不同的端口。

在回到上一级目录，输入监听的本机IP和对应两环境的端口，将会自动启动 msf 并设置好监听模块。

![](../Images/77d9c9c7626744e3397a0f08d32c32dd.png)

![](../Images/7bbd02f723ed1e3b5d850f2d86356127.png)

解析下脚本的自动实现，就是将命令写入到 config.rc 文件，在利用 -r 参数去加载运行这个文件。

![](../Images/672e0db678085330c70a8c6c5888ad79.png)

而生成 msf shell 也比较有意思，这里他处理生成两个环境的 shell 以外，还额外生成了一个兼容的 shell。

![](../Images/a6fd7775fa3c84d0b7e090f9673f57d2.png)

![](../Images/c56cca9731109a96eb4c8ae1fb09ef58.png)

这样 sc\_all.bin 将兼容 x86 和 x64，牛皮有被秀到。

![](../Images/bc454d5c2dabaf89104bd3e7d2d2e502.png)

运行成功，MSF上线了管理员身份的session。
