## 阶段1：枚举

这里我首先是用的 AutoRecon ，它是一个自动化扫描工具会根据扫描出来的服务进行深度分析。

![](../Images/f4f0d9be39eabce71bd6b87a2d6a54da.png)

可以看到是XP系统，只开放了 139、445 端口。

> Microsoft Windows XP microsoft-ds

扫描结束后提醒存在 ms17-010 漏洞，想起之前的靶机也出现过所以直接尝试攻击。

![](../Images/5c86f1d5987523dc73ce4b8f5d52d58f.png)

这里我怕出现漏洞，用nmapAutomator也扫了一遍，发现多出来一个 ms08-067。

![](../Images/f34fa1c7c08676f3d36cff179560ff04.png)

## 阶段2：利用

先用 msf 来确认下漏洞是否存在。

![](../Images/1424c7e0a1b417d3b5df298c9df2b488.png)

提示存在后，可以直接用 msf 的 payload 拿到shell。考虑到后面靠OSCP是不允许用 msf的，复习一下之前靶机碰到该漏洞的拿shell方式。

GitHub 下载对应项目，首先生成 msf 的客户端。

![](../Images/73bcf1e8a2b5b83af466a2ea67b21fe3.png)

随后在启动服务端并开启端口监听。

![](../Images/e986761a3e26c959085e8fa21e4ed27d.png)

但是这里碰到一个问题，这个项目好像不支持xp的，执行后没有反弹会话。尝试攻击 ms08-067。

![](../Images/40775ce3b760dec71dc75f0940d00409.png)

不知道是我的方法不对，还是啥，按照 40279 exploit 的提示替换了 msfvenom 生成的 shellcode，执行后也不反弹会话。裂开…

换另一个GitHub项目，成功：https://github.com/andyacer/ms08\_067/blob/master/ms08\_067\_2018.py

首先生成shellcode并替换，同时开启服务端监听。

![](../Images/126738712221c95a8eacb210a6dba821.png)

这里根据 nmap 扫描的提示信息，ms08-067 在XP上出现的版本为 XP SP2 and XP SP3，所以类型可能是 5、6、7中的一种。最终当类为6时返回了会话到MSF上。

![](../Images/af65f87dcf1d32a4a783355c811f6501.png)  
  
成功拿到 user flag。

![](../Images/5532abfe9abac24f64e4305f77c10741.png)

> 小技巧：$ meterpreter> search -f user.txt
