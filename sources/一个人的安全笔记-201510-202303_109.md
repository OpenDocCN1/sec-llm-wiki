## 0x02 为什么PHP中使用命名空间？

当两个php文件中定义了同名的类时，便会引起命名冲突的错误。列：

```php
A.php
```

显示错误提示：

> Fatal error: Cannot redeclare class setClass in H:\\yii2\\B.php on line 4
> 
> 致命的错误：不能重新声明类setClass

## 0x03 如何使用命名空间

定义：

```php
A.php
```

这样定义后，运行**Test.php**便不会出现类名冲突的问题了。

> 也可以将**namespace bbb;**改写成**use bbb;** 在实现效果上，两者都是一致的。

我们在使用时只需如下使用即可：

```php
Test.php
```

我们还可以改写成如下形式：

```php
Test.php
```

## 0x04 命名空间的别名使用

当然出现如下代码时，会出现致命错误，说不能使用bbb\\setClass用作实例化steClass，因为该名称已被使用。这时候就需要用到别名了。

```php
Test.php
```

改写成如下格式：

```php
Test.php
```
