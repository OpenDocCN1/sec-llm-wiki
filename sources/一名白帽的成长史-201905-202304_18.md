***Part.1***

**漏洞说明**

  

漏洞说明

 

Oracle在一次更新中，修复了WeblogicWeb Service Test Page中一处任意文件上传漏洞，Web Service Test Page 在“生产模式”下默认不开启，所以该漏洞有一定限制。

![](../Images/3f0c539adcabdfbefc96d30bf1e6f65a.png)

  

利用该漏洞，可以上传任意文件，进而获取服务器权限。  

  

影响版本：

Oracle WebLogic Server，版本10.3.6.0，12.1.3.0，12.2.1.2，12.2.1.3。

  

漏洞页面：

/ws\_utc/begin.do，/ws\_utc/config.do

![](../Images/8ba0288981cba2bacf70c7a83b1a2298.png)

**漏洞复现**

  

漏洞利用

 

首先访问漏洞页面：

http://192.168.3.129:7001/ws\_utc/config.do

![](../Images/7e1e4675437af39b5c739d5231fb068b.png)

首先把工作目录从：

*   

```

```

修改为：

*   

```

```

因为ws\_utc应用的静态文件css目录是无需访问权限的，而默认的工作目录即使上传成功，也无法访问。

![](../Images/1b0fcf23523b92470f04dc141008bd6e.png)

点击安全-添加进行文件上传：

![](../Images/3f0c539adcabdfbefc96d30bf1e6f65a.png)

上传shell.jsp并提交：

![](../Images/fad6584e9c572dfc48bc602076340579.png)

上传完毕后，检查当前页面元素可以发现时间戳：

![](../Images/76c4ff070e639ddd3ee1afe8740770a2.png)

那么该文件的访问路径就是：  
http://192.168.3.129:7001/ws\_utc/css/config/keystore/\[时间戳\]\_\[文件名\]

访问：

http://192.168.3.129:7001/ws\_utc/css/config/keystore/1595399038538\_shell.jsp

![](../Images/b525deab7bc34be3c24167d91fb80d7e.png)

最后通过冰蝎连接webshell：

![](../Images/b710c0c04cc849b9f3692f468ed82de3.png)

//成功~

  

![](../Images/62424894f7aae32ff731404f75b09721.png)

  

修复建议

 

（1）关闭web服务测试页，或者为/ws\_utc/config.do页面添加访问权限控制。

（2）升级至官方最新版本。
