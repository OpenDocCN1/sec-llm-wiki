# Windows 下 python 版本切换

小编最近在学习python相关的知识，电脑中安装的是python3，就发现一些python2脚本无法顺利运行。

  

调查发现，原来Python当前有两个版本，一个是2.x版本，一个是3.x版本，且这两个版本是互不兼容的。

![](../Images/9a56958b2f02b21bd13957c5cbb8eb91.png)

因此，如果我们想在python3上运行2.x版本的代码，就需要对代码进行大量的修改，产生不必要的工作量。![](../Images/679351ddcdd8ca3b252ae8987dfdc845.png)![](../Images/679351ddcdd8ca3b252ae8987dfdc845.png)

  

Windows下允许我们同时安装两个版本的python，那么怎样灵活地切换两个版本的python呢?![](../Images/6bbdce25f66dacd7e5cd7324efea387a.png)

  

请看如下分解:

![](../Images/8d65fb0e2ad6bd5b6f665155bd6e2dcb.png)![](../Images/2099b0a4123e36c16ebc9613e4a4d388.png)

  

**1.查看当前python默认版本**

python --version命令：可以查看当前默认运行版本为2.7.15

![](../Images/30030f470167a868374fd1435fc04e9c.png)

  

**2.修改环境变量**

在cmd中输入python后，打开的python版本取决于环境变量里哪个版本的python路径更靠前。

如下图，可以看到本机仅添加了2.x版本的路径。如果希望默认使用python3，可以在此处添加python3的路径，并上移到python2路径前面即可。

![](../Images/298d24e64c5425bf7eba9cca43fe1de1.png)

**3.调用python参数**

但是如果我们每次切换python版本都需要去修改环境变量，那效率就太低了。因此我们可以使用python自带的参数来进行版本的快速切换。

  

(1)py -2 快速启动python2

![](../Images/a828a64d7eb40a86a0644f5dbee6e239.png)

(2)py -3 快速启动python3

![](../Images/819b1c9b93f5730b7fe7b44493b395db.png)

  

**4.打开python脚本**

Python2和python3存在兼容性问题，使用错版本可能会报错。

（1）py -3 打开python2脚本  

       可能存在语法问题，如下：

![](../Images/294bd09efe010828a200a53441c29dc0.png)

因此脚本需要用对应的python版本打开。

（2）py -2 打开python2脚本

![](../Images/9ee14ee484c0d43016f08e28ce2aef4c.png)

（3）py -3 打开python3脚本

![](../Images/f726c29dcdb57fdb1e1687ccc347bd3c.png)

  

**其他：pycharm版本切换**

在使用pycharm进行python编程时，也需要指定使用的python版本。在创建项目时，直接选择相应的版本即可。

![](../Images/c1ca19e1289aba09f8d0e4cfcdb420df.png)

我们安装了pycharm后，有时候所有.py 的脚本都默认用pycharm打开，如下：  

![](../Images/329305e2777d979d7b8070db12b8a89f.png)

此时想在cmd中打开，只要加上py -2 或者 py-3 即可。

  

![](../Images/2099b0a4123e36c16ebc9613e4a4d388.png)

  

好啦，以上就是windows下python切换的简单方法，大家都明白了吗？
