ELK简单介绍：

ELK是Elasticsearch、Logstash、Kibana三大开源框架首字母大写简称。

  • Elasticsearch是一个基于Lucene、分布式、通过Restful方式进行交互的近实时搜索平台框架。

  • Logstash是ELK的中央数据流引擎，用于从不同目标（文件/数据存储/MQ）收集的不同格式数据，经过过滤后支持输出到不同目的地（文件/MQ/redis/elasticsearch/kafka等）。

  • Kibana则可以让在Elasticsearch中使用图形和图标对数据进行可视化。


准备环境：

Elk安装系统：centos 7.6

mysql数据库：centos 7.6

Elk安装包：

这里用的是tar.gz方式，tar -zxvf解压后cp到新建的elk文件夹下。



1.java安装

  yum -y install java-1.8.0-openjdk   java -version

检查是否安装成功（yum安装都不用配置环境变量）



2.Elasticsearch安装（ 简称es ）

进入config目录下修改配置文件：

  cd /elk/es/config/  vim elasticsearch.yml

此时启动会出现报错，一般为两个原因：

（1）es是不可以在root用户下运行的，需要新建用户，切换用户去启动：

  • 创建elk用户组及用户：

 groupadd  elk  useradd elk

  • 赋予该用户elk文件夹权限：

 chown –R elk:elk /opt/elk/

  • elk用户启动：

 su elk -c "/opt/elk/es/bin/elasticsearch"

（2）进程数太小导致报错

修改进程数：

vim /etc/security/limits.conf * soft nofile 65536 * hard nofile 65536 * soft nproc 65536 * hard nproc 65536
 vim /etc/sysctl.conf vm.max_map_count=655360 fs.file-max=655360

再次启动后，浏览器查看127.0.0.1:9200（出现如下图即启动成功）



3.logstash安装

这里做的是通过连接mysql数据表同步日志

（1）安装logstash-input-jdbc

 cd  /opt/elk/logstash/bin  ./logstash-plugininstall logstash-input-jdbc

（2）在/logstash下创建一个mysql.conf的配置文件

vim mysql.conf
input {jdbc {    jdbc_connection_string =>"jdbc:mysql://ip:3306/new?characterEncoding=UTF-8"    jdbc_user => "用户名"    jdbc_password => "密码"    #jdbc_driver_library => "/opt/elk/logstash/logstash-core/lib/jars/mysql-connector-java-8.0.19.jar"    jdbc_driver_class => "com.mysql.jdbc.Driver"    jdbc_paging_enabled =>"true"    statement => "select  * from 数据表 "    tracking_column_type => "numeric"    schedule => "* * * * *" }}output{ elasticsearch {    hosts => ["ip:9200"]    document_id =>"%{b_id}"    index =>"索引名-%{+YYYY.MM.dd}"}stdout     { codec => rubydebug }    }        


启动mysql.conf配置文件（启动前检查写的配置文件是否有错误）

 cd /opt/elk/logstash ./bin/logstash–f mysql.conf -t #检查是否有误 ./bin/logstash–f mysql.conf    #启动

注：数据库表编码格式必须为UTF-8,否则会出现乱码。



4.kibana安装

修改配置文件

  cd /opt/elk/kibana/config   vim kibana.yml

启动kibana

 cd /opt/elk/kibana ./bin/kibana

启动后浏览器查看：服务器ip：5601访问
