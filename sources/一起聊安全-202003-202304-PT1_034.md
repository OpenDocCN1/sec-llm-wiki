****斯元商业咨询今日正式发布****「Emerging Technology Vendor Index · 网安新兴赛道厂商速查指南」（2022年）第4版。****

  

![](../Images/70a59ec11cf3a06274e86c111a8db2e4.png)

  

**定位****：**网安新兴赛道及厂商速查

**内容：**赛道中英文名称，国内、国际厂商索引，代表性厂商

**受众：**企业安全负责人、渠道合作伙伴、安全营销人群、投资机构、行业咨询分析机构，及其他网络安全行业从业者

  

此前斯元商业咨询面向国内安全厂商启动了「Emerging Technology Vendor Index · 网安新兴赛道厂商速查指南」（2022年）（如下简称“速查指南”）第4版的公开调研工作，得到了国内厂商的积极参与及反馈。**斯元商业咨询梳理优化本次调研数据，并结合网安技术与产品最新的发展动态，正式发布第四版速查指南报告。**

  

本指南属于斯元商业咨询Cyber Security Billboard系列报告之一。

  

**第4版速查指南共收录144个新兴产品赛道，较之第3版新增了17个产品赛道，同时，对厂商收录情况进行了调整优化，共收录国内外厂商1300+家。**

**展示方式保持不变**

采用中英文对照目录索引，每个赛道均独立页面展示，厂商名字以文字形式呈现，便于使用者快速检索定位、分析者按图索骥。

  

****新增17个赛道****

1.IT供应商风险管理  IT Vendor Risk Management

2.身份目录即服务  Directory as a Service

3.基于风险的身份验证  Risk-Based Authentication

4.身份威胁检测和响应  Identity Threat Detection and Response

5.Kubernetes安全配置管理  Kubernetes Security Posture Management

6.数据安全即服务  Data Security as a Service

7.数据安全配置管理  Data Security Posture Management

8.格式保留加密  Format-Preserving Encryption

9.应用防护/加固  Application Shielding

10.安全众测平台  Crowdsourced Software Security Testing Platforms

11.关键业务应用安全  Business-Critical Application Security

12.自带PC办公安全  BYOPC Security

13.主机入侵检测系统  Host-based Intrusion Detection System

14.IP情报  IP Intelligence

15.第三方风险管理  Third-party Risk Management

16.内部（人员）风险管理  Insider Risk Management

17.网络安全测试与保障  Cybersecurity Test & Assurance

  

****优化调整厂商收录****

进一步提升厂商收录的技术要求，结合调研填写情况，对厂商收录情况进行了增删调整。新增收录了近100+国内厂商，大幅度优化删减了300+技术赛道聚焦不足的国内厂商，新增收录200+国际创新技术厂商。
