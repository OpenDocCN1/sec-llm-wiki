# 飞腾重磅发布嵌入式领域全栈解决方案白皮书，全面赋能万物互联

日前，飞腾携手生态合作伙伴发布**《嵌入式领域基于飞腾平台的全栈解决方案白皮书》**，通过为各型嵌入式设备提供算力支撑和技术支持，全面赋能万物互联新时代。  

  

![](../Images/672c4128c44c435541f1c17c258ca47b.png)  
  

  **构建全栈生态，链接万物互联** 

  

随着新技术的升级进化，人类社会正从 “ 移动互联网 ” 时代快速迈向 “ 万物互联 ” 时代，由此也将引发全社会智能变革，工业互联网、车联网、智慧金融、智慧家居等逐渐进入普及应用阶段。万物互联时代对于嵌入式设备的需求非常旺盛，IDC 数据预测，2020 年全球将有超过 500 亿的终端和设备联网，其中大部分都属于嵌入式设备。  

  

嵌入式设备要求满足不同行业用户的特定需求，需要根据不同行业应用场景的要求灵活裁剪软硬件，因此对嵌入式 CPU 的功能、接口、安全性、可靠性、成本、体积和功耗等方面往往有特殊的要求。5G、AI、区块链、边缘计算技术的飞速发展也促进了各型嵌入式设备的技术迭代升级。  
嵌入式产品线一直是飞腾重点发展的方向，飞腾通过 20 多年的技术积累，在嵌入式方向的行业应用也不断拓展，有力支撑着国家信息安全和产业发展。飞腾携手生态合作伙伴发布嵌入式领域解决方案，旨在打通、构建基于飞腾平台的嵌入式产品全栈生态，提供一站式解决方案助力行业客户进行技术路线选型、程序迁移，与广大生态伙伴共赢万物互联时代的红利和新基建红利。  
在广泛调研并深入分析用户需求的基础上，飞腾公司解决方案团队编写了《嵌入式领域基于飞腾平台的全栈解决方案白皮书》（以下简称 “ 白皮书 ”），并于2020年9月23日正式发布。  

![](../Images/ee6af9cac246f9c3a56adf1c2ff7281b.png)

  

白皮书系统介绍了飞腾嵌入式产品、基于飞腾平台的嵌入式全栈架构和生态图谱，全面梳理总结了嵌入式硬件、嵌入式操作系统、板级支持包、嵌入式图形、视频编解码、数学加速库等解决方案，深入解析了飞腾在网安、视讯、轨交、能源、金融等行业和领域的成功案例以及参考设计，并分享了针对最终用户和生态伙伴在方案咨询、板卡设计、认证等方面提供技术支持和生态支持的服务方式。

  

  

**全栈解决方案助力“端-边-云”协同作业 **

  
飞腾嵌入式产品涵盖高、中、低端处理器，飞腾在终端侧主推 FT-2000A/2、FT-2000/4，在边缘计算场景 FT-2000+/64 及腾云 S2500 也有着广泛的应用。下图是飞腾 CPU 产品路线图。

  

![](../Images/4c057ffdc0f4033908e3dae3103a3d63.png)飞腾产品线路图

  

随着云计算和边缘计算的发展，嵌入式设备、边缘计算设备和云计算基础设施形成了一种典型的 “ 端-边-云 ” 协同架构。如下图所示，嵌入式设备更多出现在端和边缘，与云端进行 “ 端-边-云 ” 协同。而云计算适用于非实时、大规模并行业务处理场景，边缘计算与嵌入式终端则可以卸载数据中心负载，实现更快速的、“ 现场 ” 的数据采集、分析和响应。工业互联网、智能交通、智慧能源、智慧社区、智慧医疗等越来越多的行业都需要 “ 端-边-云 ” 的协同作业。例如金融行业的金融机具，电信行业的 BBU、AAU 设备，能源行业的控制终端、智能终端，交通行业的核心列车控制系统，牵引传动控制系统，工业互联网领域的数据采集和边缘计算分析系统等等。  

![](../Images/fdf633a04b43bf43169e7029f137f6b6.png)

端边云协同方案

![](../Images/66679f65c9a65919cc4c009ca5801c20.png)

基于飞腾平台的嵌入式全栈架构

  
飞腾在嵌入式硬件设计方面的定位是帮助行业客户进行嵌入式产品的规划设计，帮助嵌入式板卡厂商基于用户需求进行嵌入式产品开发，期间飞腾可以为生态伙伴提供全流程技术支持。飞腾主要为生态伙伴提供基于飞腾嵌入式处理器的硬件参考板设计，后续会联合生态伙伴推出 “ 飞腾派 ” 开发板，更好服务用户对于基于飞腾嵌入式平台的学习和开发。  
基于飞腾平台的其他嵌入式解决方案包括嵌入式图形解决方案（GPU）、视频编解码、数学库运算等，更多详细介绍请获取 “ 白皮书 ” 查阅（获取方式详见本文文末）。

     **落地多行业多场景应用   ** 

  
基于飞腾平台的嵌入式领域解决方案在网安、视讯会议、轨交、能源、金融、航空等行业均已落地应用，为各型嵌入式设备提供核心算力支撑，助力国家信息安全和产业发展。  
网络安全领域的信息化设备根据具体应用场景不同，形成的设备组合与系统拓扑略有差异，随着信息安全管理的快速发展，目前的网安领域都是采用硬件平台+软件管理的方式去应对各种安全领域需求。根据飞腾 CPU 的性能特点，国内厂商大多将其应用在网络防火墙、安全隔离网闸、入侵检测、运维安全管理、安全审计、反垃圾邮件管理等应用中。  
视频会议及语音通讯在政府、央企办公场景及特殊领域指挥系统中保密性要求很高。基于飞腾的产品有包含视讯会议的终端及 MCU 的整体解决方案。其中云视讯平台基于飞腾 CPU 和麒麟操作系统，率先支持飞腾 CPU、麒麟 OS 和达梦数据库，实现从处理器、操作系统、数据库到业务平台的全面安全保障。  
自助售检设备（AFC 系统）是城市轨道交通为社会提供服务的窗口，是运营收益核算的信息源点。依托飞腾 CPU 的优异性能以及高可靠性、高安全性等特点，自助售检设备有了一个可靠的控制核心，为安全运营提供了有力的技术保障。从实际测试效果看，飞腾 CPU 从性能、可靠性、功耗等方面都具有优势。  
更多行业解决方案案例，请获取 “ 白皮书 ” 查阅。
