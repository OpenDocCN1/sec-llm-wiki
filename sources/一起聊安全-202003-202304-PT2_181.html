为加速中国行业信息化建设的转型升级，飞腾作为国内领先的自主 CPU 芯片提供商，重磅发布 行业解决方案方阵，为行业信息化建设提供 “ 新动能 ”。

本期与大家分享方案方阵中的第四篇：《能源、交通、工业联合解决方案分册》的部分典型案例，该分册的全文您可以在飞腾官方网站或在公众号后台获取。



     前  言     

我们在上一期介绍了飞腾 CPU 在金融、电信、数字城市方面的进展（点击直达），沿着飞腾赋能中国信创并向更广泛行业延伸的脉搏，本期重点介绍飞腾在能源、交通和工业等领域的联合解决方案。相比信创、金融、电信，在能源、交通、工业方面的解决方案则更加复杂和多元，几乎融合了云计算、大数据、边缘计算、5G、AI、物联网、区块链等所有技术方向。


能源行业是国之命脉，在新基建的浪潮下面临着数字化和智能化的转型，各家电力集团都在通过数字化建设优化其生产、供应、服务的全流程，进行更加精细化的运营管理。传统粗放的发电模式也在转变，如在火电方面，基于飞腾平台的分布式控制系统，可以实现 I/O 数据采集、加工、控制计算和指令输出，满足火电行业控制系统要求，实现发电系统精细化管理。基于国产处理器平台，类似的变革在电网继电保护、电网安全和核电仪控等高安全、高可靠系统中也开始得到广泛应用。


交通行业是中国经济发展的助推剂，交通 “ 新基建 ” 并非以钢筋混凝土主导，而是深度根植于中国的科技创新和产业升级。其中，飞腾 CPU 在高铁核心列控、牵引传动、网络传输及数据中心中开始崭露头角，基于飞腾 CPU 的工控机打造的地铁自动售检票系统已成功在天津地铁投入使用，基于飞腾平台的轨交大数据分析平台也已开始规划和应用。未来，飞腾将进一步与交通行业客户和生态伙伴携手，扩展轨交国产化建设的内涵和外延，持续助推交通新基建。


在国家经济的命脉——工业领域，传统的 “ 工业制造 ” 已经向 “ 智能制造 ” 转变。智能制造除了先进的工艺、材料和制造能力之外，还有网络化和数字化改造，主要方式是将工业控制系统涉及的方方面面连接成网络，通过网络采集数据并进行分析，形成可用于提高生产效率的结果，不仅减少资源消耗，更重要的是可实现安全管控。目前，飞腾处理器已在工业安全审计控制平台和工业安全控制云平台方面得到应用。


飞腾联合解决方案《能源、交通、工业联合解决方案分册》收入 13 个案例，包括电力、轨交、工控、显控方案，以及相关行业中的边缘计算、大数据和网络安全等优秀解决方案。飞腾希望在支撑好传统信创领域的基础上，为更广泛的行业提供核心算力和系统级解决方案支撑，从而为加速关键行业信息化转型升级贡献力量。






     精选部分联合解决方案     

中软与飞腾
地铁自动售检票系统
联合解决方案

城市轨道交通建设是应国家重大需求而生，并顺应国家重大战略而不断发展。目前，我国城市交通体系正从传统 “ 交通基础设施建设 ” 向 “ 交通效能提升 ” 进行重大转型，传统业务模式开始融合互联网、大数据与 AI 技术。新技术的引入，导致以往运行在封闭环境中的轨道交通业务系统越来越多的暴露在互联网中，系统的安全受到越来越大的威胁，其网络设施和信息系统一旦遭遇攻击或数据泄密，可能严重危害国家安全、国计民生和公共利益。因此，轨交业务系统迫切的需要基于自主设备进行国产化的安全改造和升级。


在轨道交通中，自动售检票系统（AFC 系统）是最直接与用户进行交互的系统，系统内储存着大量的乘客个人信息及金融信息，其安全性需要重点关注。本方案提出基于飞腾 CPU、麒麟操作系统和达梦数据库，并结合 AI、大数据等新技术对 AFC 系统进行的升级，在保证本质安全的同时，使系统更加高效便捷。该方案已在天津地铁投入运行。



本方案分为两期试点工作。第一期为传统系统安全升级，第二期为系统业务改造。本方案经过充分的验证之后，已经在天津地铁 5 号线北辰道站实现试点应用。


国电南自与飞腾

电力行业DCS

联合解决方案

随着社会对电力资源需求越来越高，火电以往较为粗放的发电形式已经无法满足需求，需要实现精细化发电，以达到资源的最大利用。而这类资源的控制都需要自动化技术得以实现，单纯的人工是达不到这种效果的。作为国家基础建设的重中之重，电力系统可以凭借选用国产控制系统，来提高发电效率和安全性。

采用基于飞腾 CPU 的分散控制系统，可以减少对国外 CPU 的依赖，提高核心控制装备的国产化水平，降低国际形势变化带来的技术风险，同时支持国产自主创新 CPU，促进国产 CPU 相关技术和产品生态环境的健康发展。


本项目所应用的基于飞腾 CPU 的分散控制系统，是在吸收现有火电厂 maxDNA 系统优点的基础上进行重新设计，其核心内容是开发高可靠性嵌入式加固操作系统，采用飞腾国产 CPU 实现分布式控制单元。本项目主要应用内容是新一代基于国产自主创新处理器的分散控制系统，主要包含基于导轨安装和先进测量技术的 I/O 层、过程自动化控制层和监控系统层，并提出基于控制指令加密与授权、SBP 访问数字签名、恶意代码和网络入侵防护、网络审计、主机加固和组态自动备份与恢复的 DCS 系统整体信息安全构架方案。



由于电厂分散控制系统对实时性、可靠性和运算能力要求极高，不仅要求硬件本身的拥有足够的性能和稳定性，对所采用的操作系统和应用软件也具有很高的要求。飞腾 CPU 针对工控行业做了实时性的增强，通过特殊的 memory 来贮存实时性任务， 无需对 DDR 进行调度即可保障稳定的访问时间。 


飞腾 CPU 支持安全态和非安全态两种运行模式，彼此完全隔离，在很多资源上也是完全独立的。该模式不仅将处理器的执行态分开，对内存也区分为安全段内存和非安全段内存，普通的任务包括操作系统只能访问非安全的内存，但安全态的任务可以访问到所有的内存。通过这样的机制，在对上位机安全性要求比较高的控制类应用便可以放在安全态运行，对数据通讯、人机交互的安全性要求不高的应用可放在非安全态运行，有效规避人为误操作对高安全性任务的破坏。


江苏自动化研究所与飞腾

国产化计算模块
联合解决方案

随着特殊领域的电子信息系统对自主创新需求的日益提升，需不断开展国产抗恶劣环境计算整机及模块产品的研制和升级。特殊领域电子信息系统的自主创新，是指依靠自身技术手段和安全机制，实现信息系统从硬件到软件的自主研发设计、生产、升级、维护的全程可控，其中特殊领域抗恶劣环境计算模块产品的自主创新是其中的重要组成部分。


江苏自动化研究所与飞腾国产化计算模块联合解决方案，可为科技工业行业客户提供基于飞腾 CPU 的抗恶劣环境计算装备及模块级产品，提供从加固计算模块到整机、显控台级的硬件平台，提供从国产固件到国产操作系统、中间件、平台支撑软件的全系列自主创新解决方案。

 


某型显控台采用基于飞腾处理器计算模块和外部扩展模块搭建的显控硬件平台，运行国产银河麒麟桌面操作系统或国产 Jari-Works 嵌入式操作系统，操作系统上层运行图形中间件、操控中间件、数据处理中间件等中间层软件，中间件层再往上层运行显示模块、身份认证、系统管理等平台软件，为用户方的各种应用软件提供支撑。



超越申泰与飞腾

边缘云计算

联合解决方案

当前国际形势严峻，关键核心技术要不来、买不来、讨不来，特别是特种信息化装备的发展更需要自力更生，不断突破关键核心技术，走出一条自主创新之路。面对新形势，在积极的政策指引下，特种行业云计算的自主创新进程也在不断加速。作为业界首款针对移动使用场景自主研发的边缘云计算产品，超越云结合了云计算与边缘计算的相关技术特点，通过在近用户端提供计算能力，减少网络操作和服务的交付延时，利用虚拟化技术，将计算、存储、网络、安全等模块深度融合到标准服务器单元中，实现联合业务系统时计算资源的快速部署、快速使用、快速恢复。


本方案采用了软硬双重加固的模式。硬件采用加固方式的超越飞龙 RM5000，处理器为飞腾 FT-2000+/64；边缘云操作系统也通过诸如资源的标签隔离、网络的限速和访问控制等实现安全加固。



本方案采用软硬结合的理念设计。通过软硬一体化解决方案，实现即插即用，快速初始化的目的；同时还针对特定硬件进行软件优化，提升整体性能。多台物理机可以组建集群，同一个物理集群下的主机相互备份，不存在单硬件单点故障；每个主机上均部署了虚拟化层、管理台和业务终端，并且业务终端支持双屏扩展显示。可通过虚拟机的容错机制，实现两个虚机之间的实时高可用，确保两个虚机的实时镜像（包括扩内存），当一虚机宕机时，另一个虚拟机可以快速接管，确保服务的顺畅进行。通过在数据中心统一部署边缘云操作系统，只需在席位上放置专用的云终端，或在现有的 PC 上安装客户端程序，即可以保证用户快速安全地访问到工作环境中。



晋商博创与飞腾

工控安全核心计算云平台
联合解决方案

时空信息云平台是一种采集、处理、存储、管理、分析、输出地理空间信息及其属性信息的信息系统，解决 “ 信息孤岛 ” 等问题，建立城市时空大数据的统一管理、共享、更新机制，是 “ 智慧城市 ” 整体框架中一项重要的、不可缺少的基础内容。


为加快推进国产升级计划、构建安全的信息技术体系，硬件服务器与操作系统必须为国产的自主创新产品。国产工控安全核心计算云平台为满足高性能、高密集要求，采用国产恒为基于飞腾 FT-1500A/16 的高密度服务器和国产银河麒麟操作系统来满足平台业务需求。


该平台分为平台控制节点与计算节点。平台控制节点提供云平台功能操作入口，负责平台管理、网络管理、资源调度编排、权限管理以及高可用策略等；平台计算节点负责提供资源服务，为安全态势感知平台应用提供安全的可运行环境。


基于国产飞腾 CPU 的工控安全核心计算云平台，可保证平台系统所提供的服务具有高可靠性，保证整个信息系统各种数据的一致性、完整性和安全性，同时还可以达到在节约服务器设备的情况下，大幅度提高物理资源利用率，减少机房建设负担。



平台可提供全国工控安全 “ 一网一库三平台 ” 中的 “ 一网 ”（全国在线监测网络）平台系统和企业客户 OA 办公系统（中软安全电子公文系统）运行支持环境。将相关应用系统与平台进行深度适配移植，并提供应用集群快速构建、统一管理、动态扩缩和自动化运维。在稳定性测试中，基于飞腾平台的全国在线监测网络平台系统和企业 OA 办公系统，能长期、稳定的运行在国产工控安全核心计算云平台环境中，真正实现了应用快速部署、高可用、动态伸缩、高效安全等特性。



至此，飞腾解决方案连载发布完毕。感谢飞腾生态伙伴包括软件厂商、OEM、ODM、嵌入式厂商及广大集成商的积极响应和配合，让我们有机会携手一同推动中国行业信息化建设的转型升级。


“ 飞腾行业联合解决方案发布与推广计划 ” 是持续开放的项目，诚邀各生态合作伙伴与飞腾共同协作，对基于飞腾平台的行业联合解决方案进行梳理，形成联合解决方案并持续发布。发布方式包括但不限于：在飞腾生态伙伴大会、飞腾开发者大会、飞腾生态工作组会议、公众号、媒体发布以及其他市场推广活动中介绍和推送生态合作伙伴的行业联合解决方案；在飞腾展厅、展会、适配中心、展示中心、体验中心等向用户推介行业联合解决方案。


20 年风雨兼程，飞腾始终站在国产 CPU 研发的最前沿，通过不断积累，形成了覆盖高端服务器芯片、高效能桌面芯片和高端嵌入式芯片的完善产品线，有力支撑着国家信息安全和产业发展。近年来，飞腾持续蓄力，发展进入快车道，联合千余家国内软硬件厂商，构建起国内最完善、最庞大的信息化建设生态体系。


20 年不忘初心，飞腾始终坚持 “ 核心技术自主创新，产业生态开放联合 ” 的发展理念，以 “ 成为世界一流芯片企业，用中国芯服务社会 ” 为目标愿景，持续打造领先与开放的行业联合解决方案，确保各类应用能够基于飞腾 CPU 实现最优的运行效果，赋能更多行业客户，助力中国行业信息化建设转型升级，助力中国数字经济转型升级。
