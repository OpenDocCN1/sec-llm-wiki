**     前  言     **

在首期飞腾解决方案连载中，我们重点介绍了飞腾与合作伙伴在信创上云方面的成功实践（[点击回顾](http://mp.weixin.qq.com/s?__biz=MzIyMzE0ODc3Ng==&mid=2650484235&idx=1&sn=d739b1d1fb714095f90f641e9f8378d4&chksm=f02d218cc75aa89a01c4832b527c8e9bd78437089f277923d648c9eee912c1473a0fbf6d5e9b&scene=21#wechat_redirect)），由此延伸到另一个问题：在硬件基础设施云化的背景下，该如何进一步实现信创领域政府办公的 “ 数字化转型升级 ”，绘制 “ 数字政府 ” 的蓝图。数字政府的核心，是将日渐海量化、碎片化的结构和非结构化数据予以高效利用，做好数据/大数据的治理与应用，进而实现社会治理的数字化和智能化。因此，需要从数据的存储备份、安全防护、传输交换、分析利用、智能展现等方面进行解决方案的总体规划和生态建设。  
一直以来，飞腾坚持自主研发，不断革新技术，持续提升飞腾处理器单核性能和多核并行协同处理能力。飞腾即将上市的全新服务器芯片将支持 2-8 路互联，更好的满足各行业在处理海量数据时对高性能、低延迟和大规模并行处理的需求；同时，飞腾还为基于飞腾平台的数据存储、备份、传输、显示、安全等硬件设备提供参考设计和技术支持，为相关软件和集成商提供基于飞腾平台的软件移植、适配和优化支持。  
**《信创领域联合解决方案—大数据、视频会议、存储及安全分册》**收入 24 个优秀联合解决方案，包括大数据、视频会议、存储、备份恢复、安全等方面，基本涵盖了数字政府建设的主要解决方案。我们希望与生态伙伴合作，站在全系统集成的角度，为集成商和最终用户梳理已被验证的、有说服力的系统级解决方案和实际案例，加速中国 “ 数字政府 ” 转型升级的历史进程，**破解信创产业快速落地应用的 “ 最后一公里 ” 难题。**

**     精选部分联合解决方案     **

**星环与飞腾**

**政务共享交换平台****联合解决方案**![](../Images/c4c1321c99cb2851f3bf15c46f9e5119.png)

本方案基于以飞腾 CPU 平台构建的电子政务云，以跨部门、跨层级应用为抓手，统筹构建 “ 云数联动 ” 的政务数据共享交换平台。依托统一的国产化平台，实现重要信息的数据共享、交换，从而打通政府各部门信息系统、打破 “ 数据孤岛 ”。

  

方案依托国产基础软硬件设施，建立一个中心——数据资源中心；一个门户——统一数据资源门户；四个平台——大数据支撑平台、数据共享交换平台、数据资源管理平台、算法模型开发平台；一套服务体系——数据归集服务、数仓建设服务、数据治理服务、模型开发服务；形成一套产品体系，即星环大数据云平台 Transwarp Data Cloud。

  

![](../Images/6a35ad41a0f1a011b5c694511f07e903.png)  

政务数据共享交互平台分 5 部分工作：汇、治、融、享、用。“ 汇 ”：是数据汇聚，把各个政府部门的数据、从其他数据资源平台交换过来的数据、以及一些互联网数据统一采集，汇聚到大数据平台，形成数据湖。“ 治 ”：是数据治理，通过对数据湖中原始数据进行清洗、校验、去重、标准化，形成高质量的结果数据，并导入到数据库中。“ 融 ”：是数据融合，将数据库中的高质量数据融合打通，构建主题库、专题库、共享库。“ 享 ”：是数据共享，向上级联上一级共享交换平台完成数据汇聚，向下把清洗融合后的高质量数据反哺到各个业务部门。“ 用 ”：是数据应用，基于两大数据资源库，对上层提供数据服务，支撑跨部门、跨层级的政务应用，如一网通办、城市综合治理等。

  

**宏杉与飞腾**

**电子公文数据存储双活**

**联合解决方案**

![](../Images/822f6def3a59b5080a2823094a150287.png)

电子公文系统是数字政府办公的重要组成部分，在提升政府办公效率的同时，从硬件和系统方面进行规划建设以确保电子文档实现可靠和安全的存储是非常重要的环节。宏杉采用基于飞腾平台的设备搭建存储双活方案，以满足这一要求。  
宏杉科技的对称双活存储（Symmetrical Dual Active Storage，简称 SDAS）是一项专门针对双活存储方案的创新技术。通过宏杉科技对称双活存储技术，可不需要引入三方软硬件，直接通过两台 MS3000GT-FT（基于 FT-1500A/16）系列存储阵列实现双活工作，互为冗余。当其中一台存储发生故障时，可由另一台存储实时接管。  
![](../Images/c7706f325ea0b80f01c7901622988d66.png)

  

宏杉科技的 SDAS 技术，不仅支持近距离的双活存储系统，而且支持上百公里甚至更远距离的双活数据中心。近距离的双活存储可以采用更加高效的光纤交叉直连的方式进行组网部署；远距离的双活数据中心采用交换机连接方式，再配以仲裁者机制进行组网部署。SDAS 系统最大可支持 400 块 HDD/SSD，可满足客户未来 3-5 年的存储空间需求。  
本方案已应用于国内多个省份的政府机关，可部署于电子公文系统、OA 办公系统、党建系统、电子签章和门户网站等场景。

  

**中兴与飞腾**

**会议电视****联合解决方案**

![](../Images/e6fefd3cc3bbc421a7d7cbed39e61667.png)

视频会议系统是政府数字化办公的重要组成部分。在平台端，中兴基于自研创新的理念，研制发布了基于云计算的视频会议服务器 M930，可实现视频会议业务管理和视频会议媒体服务，支持云化部署，目前已经适配飞腾 FT-2000+/64 服务器；在终端接入侧，中兴通讯还发布基于自研视频处理芯片 ZX296719 的智能高清视频终端 ET3 系列，此系列终端实现视音频编码代码 100%、人脸识别智能业务等全自研；中兴通讯研制基于自研视频处理芯片 ZX296719 的智会大屏一体机 TCS 系列，实现全自研人脸识别智能业务；中兴通讯还提供全自研的个人移动视讯软终端 VT100，实现数据共享，多人操作，目前已完成和 FT-1500A/16 的融合。  

  

![](../Images/8c3673199ba2970a31a840f4ea73b27f.png)  

该方案已成功应用在北方某市政府视频会议项目上，在该市政府建设一套市--县--乡镇的行政办公视频会议系统，覆盖全市共 70 个会场，实现与省级会议互联互通。该方案具备如下特点：1、系统多重备份，保障系统稳定；2、信令媒体双重加密，保障会议安全；3、远程音视频监控，统揽会场全局。此方案带来的客户利益：1、统一行动，相互协作，有效提升了省市级会议的效率和体验；2、多种类型终端灵活接入，打破地域的限制，节省时间和行政成本；3、系统安全，运行可靠，会前组织非常方便，维护人力成本低。

  

**捷视飞通与飞腾**

**高清视频会议**

**联合解决方案**

![](../Images/31af85cc2fa64c7bf3f9f002966308b2.png)

目前，国产视频会议系统已在国内各个行业实现应用，尤其在政府、航天等 “ 国之重器 ” 行业存在大量的多级视频会议系统。为应对这些系统的数字化转型升级，捷视飞通凭借近二十年视频通讯的从业经验，提出了以自有核心技术+飞腾 CPU 芯片算力+银河麒麟操作系统相结合，实现视频会议系统全国产化解决方案。本系统遵循标准的 H.323/SIP 通讯协议，保证会议系统的安全性，满足政府、企事业单位等客户的需求。同时具有高效的视音频编解码能力和抗网络损伤技术，为新时代党政用户的视频会议系统提供了自主安全、先进可靠的选择。

  

其组网拓扑如图所示：

  

![](../Images/e8e7deaa4cfc34269cf07dc61380ea14.png)  

捷视飞通基于飞腾平台的全国产高清视频会议解决方案，具备 1080P 级高清视频会议管理、终端设备管理、注册认证、会议控制、内置 GK 服务器、公私网穿越等功能，能够实现国家、省、市、县四级部署，五级会议，满足全网各单位通过远程视频开展会议、会商、培训、指挥调度、点名签等需求，同时支持横向各单位之间开展会议。该方案同时支持飞腾终端电脑接入及视频会议的召开，满足未建立视频会议室单位使用，提高工作效率，享受国产信息化建设带来的安全性及便利性。

  

**深信服与飞腾**

**新一代边界安全****联合解决方案**

![](../Images/dbd82c6703947cc18939c32cbafd649f.png)

数据安全防护是 “ 数字政府 ” 转型升级的安全保证。针对当今网络和数据安全面临的挑战，深信服与飞腾联合发布新一代边界安全解决方案。该方案的核心组件包括下一代防火墙、入侵防御系统和 WEB 应用防火墙，三款产品均采用飞腾 CPU 平台。该方案以保障用户核心资产为目标，以安全可视化为中心，为现有安全建设体系增加 “ 预防 ”、“ 防御 ” 和 “ 检测 ” 的边界安全防护能力，有效抵御来自内部、外部的非法攻击，保障核心业务的可靠和安全。

  

![](../Images/2a13f715a4f8aa88bdc8f98ecc24c0a6.png)  

通过在边界部署深信服下一代入侵防御系统，对进出数据中心网络流量进行深度解析，可及时准确发现各类非法入侵攻击行为，并执行实时精确阻断，主动而高效的保护数据中心的网络安全。深信服下一代入侵防御系统不仅可以有效应对常见的漏洞攻击，还可针对蠕虫病毒、间谍软件、木马后门、溢出攻击、数据库攻击、服务器暴力破解，特别的可以对 APT 攻击、未知威胁攻击等多种深层攻击行为进行全面防御。

  

**鼎甲与飞腾**

**数据灾备联合解决方案**

![](../Images/84380e5e041ec520c43d254d6c766b78.png)

鼎甲科技电子政务云平台数据容灾与备份恢复系统，由鼎甲科技基于飞腾 CPU 完全自主设计研发通过云平台灾备全服务流程和技术架构，满足了政务云平台数据安全和容灾恢复要求，目前已成功为全国多个省、市电子政务云平台提供容灾备份系统解决方案，获得了广泛的行业用户认可，为政务关键数据的信息安全提供了保障。  

  

![](../Images/c05d1e33727c7de7bb274b9186643685.png)

基于飞腾 CPU 的电子政务云平台数据容灾与备份恢复系统，完全兼容 OpenStack、KylinCloud 等国内 12 种 55 个版本的主流云平台架构，支持 MySQL、达梦、GBase、KingBase 等不同业务数据库类型、多个版本的操作系统保护，提供业务单机、集群、分布式和对象存储等多种数据架构的保护能力。该系统面向政务应用灾备恢复的服务化要求，采用 WEB 交换式服务设计，提供多租户灾备资源管理、资源监控与计费、灾备策略配置管理、灾备作业管理、统计和报表管理、综合运维监控与告警等功能模块，为用户提供统一的身份认证、工作流审批管理功能，提供了政务云平台基于两地三中心体系架构的完备的业务系统云灾备功能。
