2.Crypto“多次解码”

下载附件，得到一个txt文本文件，打开发现一串字符串，根据开头的0x得知这串字符串为16进制字符串。

知识点：以0x开始的数据表示16进制

复制除开头0x以外的字符串，百度“base16在线解码”或“十六进制在线转字符串”，打开转换网站，进行转换

知识点：字符串经过base16加密后就是十六进制，因此base16解密和十六进制转换为字符串是一个过程

解密后发现大量&#，因此可以得知这是Unicode编码，搜索Unicode在线解码，进入解码网站进行解码

得到的结果存在大小写字母和数字，盲猜为base64编码，尝试base64解码

得到一排数字，盲猜为ASCII值，编写python脚本进行转换

脚本代码：

s = '''10210897103123561019752521015157995749529953100100102989857564856994948485151525049125'''#定义ASCII值，python中使用三个单引号包裹表示定义多行字符串s = s.split("\n")#对变量s表示的多行字符串进行分割，分割符为\n，即换行符。此处表示将每行的字符串按顺序存到列表中，并重新赋值给变量s#print(s)#此时s为['102', '108', '97', '103', '123', '56', '101', '97', '52', '52', '101', '51', '57', '99', '57', '49', '52', '99', '53', '100', '100', '102', '98', '98', '57', '56', '48', '56', '99', '49', '48', '48', '51', '51', '52', '50', '49', '125']l = ""#定义一个字符型变量l，并将它置为空，为后面存放转换后的ASCII字符做准备for i in s:#使用for循环将列表s中的值循环赋给变量i    l += chr(int(i))#由于列表s中存储的数据为字符型，因此i得到的数据类型也为字符型，先使用int函数将数据强制转换为整型，再使用chr函数将ASCII值转换为ASCII字符，最后将其插入变量l中print(l)#输出转换后的结果，得到flag{8ea44e39c914c5ddfbb9808c10033421}

from hashlib import md5#导入MD5加密所需使用的第三方库
s = 'abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789'#定义英文和数字字符，为后面爆破做准备for a in s:#使用for循环将列表s中的值循环赋给变量a，变量a为未知的三位中的第一位    for b in s:#使用for循环将列表s中的值循环赋给变量b，变量b为未知的三位中的第二位        for c in s:#使用for循环将列表s中的值循环赋给变量c，变量c为未知的三位中的第三位            n = 'flag{e57b9e18b08bff0d05a3c59900b10'+a+b+c+'}'#将变量a、b、c所表示的值插入flag中            n_md5 = md5(n.encode('utf-8')).hexdigest()#对变量n的值使用utf-8编码格式进行编码，之后进行MD5加密，将加密后的值以十六进制表示并赋值给变量n_md5            if n_md5 == '742ea8152ff11b1f6f9314c3c4eff93e':#判断加密后的MD5值与告知的MD5值是否相同                print(n)#如果相同说明变量n为正确的flag，输出变量n的值
