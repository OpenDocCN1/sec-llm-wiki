  1. CreateRemoteThread是最流行的技术之一，它通常带有以下 API 调用序列：
  2. VirtualAllocEx -> 分配内存空间来暂存 shellcode
  3. WriteProcessMemory -> 将解密/解码的shellcode写入内存空间
  4. CreateRemoteThread -> 在进程上新建一个线程，起始地址指向内存空间

  6. 这些已经被分析烂了，详情可以查看参考（抄袭）那篇文章，可以看看怎么分析的

技术优点

  1. 不使用内存分配 API（例如，NtAllocateVirtualMemory、VirtualAllocEx 、NtMapViewOfSection ）

  3. 线程在 DLL 的 .text 部分中执行，这对于在内存页面上具有可执行权限

  5. 新创建线程的起始地址位于MEM_IMAGE内存区域，没有使用传统的线程劫持技术（严密监控！）
