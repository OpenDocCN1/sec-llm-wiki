原理

反射DLL就是内存加载执行DLL，现在需要将DLL转shellcode。

生成sRDI Shellcode

Donut 也可生成shellcode，具体自己体验。

利用了https://github.com/monoxgas/sRDI这个项目实现

Golang实现反射DLL 代码

main.h

#include <windows.h>`

`void Run();`

`BOOL WINAPI DllMain(`
    `HINSTANCE _hinstDLL, // handle to DLL module`
    `DWORD _fdwReason,    // reason for calling function`
    `LPVOID _lpReserved   // reserved`
`);`

main.go

//CGO的玩法

package main

//#include "main.h"
import "C"
import(
"os/exec"
)

var Isruning bool =false

//入口
//export Run
func Run(){
if !Isruning{
Isruning = true
main()
}

}

//export DllInstall
func DllInstall(){main()}

//export DllRegisterServer
func DllRegisterServer() { main() }

//export DllUnregisterServer
func DllUnregisterServer() { main() }

func main(){
_ =exec.Command("calc.exe").Run()
}

保存生成DLL

go build -ldflags="-w -s" -buildmode=c-shared -o Exp.dll .\main.go

调用sRDI 生成shellcode,sRDI可以从师傅的https://github.com/timwhitez/Doge-sRDI 获取。

需要修改这二个地方与我们的DLL名字和入口函数和一致。

运行即可生成。
