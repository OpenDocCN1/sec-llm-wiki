# 微软发布多语言群聊翻译服务microsoft translator

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MTE0NTE3Mw==&mid=2651103950&idx=1&sn=4776cd7aebb269685722652df5ad9136&chksm=f1aed5f4c6d95ce23eba284dfbdb70a86f227a196c3570b36ae0803bab11c84c411c0e3764e3&scene=126&sessionid=1681267677#rd](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651103950&idx=1&sn=4776cd7aebb269685722652df5ad9136&chksm=f1aed5f4c6d95ce23eba284dfbdb70a86f227a196c3570b36ae0803bab11c84c411c0e3764e3&scene=126&sessionid=1681267677#rd)

本月14日，微软在Microsoft AI 会议上发布了一款多语言群聊翻译的服务，可以在 Web 端或移动端 通过Microsoft Translator 发起或加入多语言群聊，在这个群聊里其他人说的其他语言都会通过翻译直接翻译为你的语言。目前支持50多种语言的文字翻译和9种语言的语音翻译。

选择开始交谈，填写姓名和自己的语言，并生成加入代码和二维码，其他人通过填写加入代码或者扫描二维码加入群聊，加入时填写名字并选择他自己的语言，大家就可以用自己的母语无障碍沟通了。
