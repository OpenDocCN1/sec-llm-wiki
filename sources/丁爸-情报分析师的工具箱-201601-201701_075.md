# 使哲学、科学、宗教归于统一的高维度

网上有文章和视频就什么是一维到十维进行了解释，我看前面1至5维大多数人都能理解，后面的估计就有点犯晕了。

  

下面再将我对这些维度的理解给大家分享一下，通过对1-10维的思考，我感觉科学、哲学和宗教其实是相通的，最终都是殊途同归：

  

总得来说高纬度世界都是无数个低纬度世界组成的。

  

1维是点组成的线、2维是线组成的面、3维是面组成立体、4维是不同时间的立体组成的宇宙，这就是我们现在生活的世界，我们出生死亡，宇宙也从大爆炸到现在，时间一直还在流淌，没有尽头。

![](../Images/54940a7e5a0d57c3bc10da40fde29cec.png)  

5维世界是无数个和我们现在所处的宇宙类似的宇宙组成的，我们可以选择自己未来发展方向，你可以是张三或者李四。不同的选择就让你去不同的宇宙。但你不能在5维世界里既是张三的同时又是李四。

5维世界比4维世界多的维度就是：意识（或者灵魂、智慧、信息、弦）

意识决定你的未来是在4维世界的哪个宇宙，所以说路在脚下，你的每一步选择都将影响你的未来，每个不同的意识选择就组成了不同的世界。或许在这个世界张三和李四是朋友，但在另外一个世界张三和李四根本就不认识，或者是仇敌。

  

6维世界里的张三只是一个点、张三能感受到李四的意识，但张三也只能感受到李四的意识是一个点。这个6维世界是无数个和张三一样的意识点组成的直线。这里的每一个点其实就是一个5维世界，这个点就是5维世界的初始状态，同时也是5维世界的终结状态。

  

7维世界是无数个6维世界的线组成的面，在这里意识是由无数个点状意识组成的线，一个意识也能感觉到其它意识的存在，但也只能感受到他们是一条一条的线。  

7维世界的张三到6维世界既可以是张三还可以是李四或者王五，他可以是6维世界里的任意一个意识主体，因为他就是这些意识主体的集合。

  

8维世界是无数个7维世界这种面组成的立体，意识在这里就是一个立体的镜像，他能感受到这个世界还有许多和他一样的意识，他们都和他一样是立体的，方的、圆的、六角的等等各种各样，千奇百怪，但大家都是静止的，不变化的。8维世界里意识张三只能感受到另外一个意识李四的一种状态，不能看到他的成长变化。

  

9维世界里的意识张三能感受到另外一个意识李四从一个点产生、到成长为各种形状又逐渐衰退至一个点并消失，同样意识李四也能感受到同一个世界中其它意识的成长与衰退。但这些意识之间是没有交流和沟通的，他们能相互感受成长状态，但相互之间不能交流、融合、沟通、感应。

  

10维世界里的意识则是可以交流、融合和沟通的，每个意识都能感受其它意识的存在，并能保持和他一样。无论张三在哪里，李四都能同时和他保持相同的状态。

10维的世界里的维度关键词：交流、融合、沟通、感应、一致。

在这里意识张三和意识李四就像两个量子，他们随时保持相同的状态，同生共灭。他们的状态也是不固定的，因为组成他们的意识是随时在变化的。他们既是世界的基本构成又是世界的全部。

  

到这里我们就可以发现其实科学、哲学和宗教其实是相通的，量子的不确定性即代表了哲学的意识、也代表了宗教的灵魂，同时也是构成世界的根本所在。一切的一切原本就是统一的，因分离到不同的维度，产生出万千世界。宇宙发展的进程中，我中有你，你中有我，有时大家又合为一体，原本大家都是从虚无而来最终又要归于虚无。
