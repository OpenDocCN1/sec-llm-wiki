# DNA技术协助侦破贵州遵义杀人案

2016年10月20日报道，11年前，贵州遵义汇川区三阁公园发生一起命案，一名年轻男子浑身赤裸惨死山上。11年后，8名凶手被捉拿归案，而其中一人已是网络公司的老板。谁能想到，当年他们行凶的动机竟然是“杀人练胆”。2016年10月18日，汇川区公安分局民警押解8名嫌疑人来到案发现场进行指认。

![](../Images/bdca201ac6d337000e756f439c550819.png)  
    2005年11月25日，贵阳遵义，距离体育馆不远的三阁公园，发生一起命案。一名赤身裸体的年轻男子被人在公园内杀害。最早发现死者的是一名晨练市民。据他说，当时自己经过公园的一条小道，突然发现台阶上一摊血迹，一个赤身裸体的男子斜躺在地上，浑身是血。

![](../Images/e6891262e0d0014ec62f687b5e769f4c.png)  

按照以往的侦查方向，专案组民警围绕死者生前社会关系展开调查，可是因为无法明确死者身份，使得案件一直无法取得突破。时间一晃到了2016年。汇川区警方启动对往年未破命案再次深挖线索的工作。案件终于在今年9月取得了突破。在对当年的卷宗档案以及物证重新整理时，那曾经遗留在现场的烟头再次被提取。警方借助先进的技术，锁定了其中一名嫌疑人的身份。而此人曾经因涉嫌10年前的一宗发生在网吧的故意伤害致人死亡案件，受到公安机关的打击处理。

警方当即将这名嫌疑人抓获，从其口中警方了解到，该案共有8名涉案人员，其中绝大多数都还在遵义。9月下旬，汇川区警方展开收网行动，兵分数路，将涉案人员悉数抓获。令人震惊的是，当年这8人大多数为在校中学生，而作案动机只为了练胆！

这次侦破案件的物证为杀人者留在现场的烟头，据此法医进行了唾液斑检查，提取了其中的DNA。DNA中有个体识别和家系识别所需要的人体信息，不仅可以得知男性嫌犯的姓氏家系，而且可以确定具体个体。以往的的DNA鉴定都是在法庭上使用，作为指认罪犯的证据。随着技术的发展，DNA技术不断升级换代，用于办案的事件越来越多。以现场的烟头和唾液斑作为检测对象，已经破获多起案件，有的案件情节十分离奇。

    如2006年3月，河南某村发生一强奸杀人案，是以唾液斑为线索侦破的。死者牛某（女，30岁）在家遇害。提取死者乳房擦拭物，经Y-DNA检测，检出一男性与死者混合DNA分型，遂在案发地周围7个村内27个家族中进行排查。结果周姓家族20个分支和1个冯姓分支家族仅与乳房擦拭物在1个Y-DNA分型存在差异，此为Y-DNA在家系遗传中的变异现象。通过家谱调查，对冯姓家族溯源，查找到冯姓家族是由房氏族人过继而来。继而对房氏家族进行Y-STR检测，结果发现乳房唾液斑分型与房氏家族相同。通过Y-DNA检测，认定房氏族人房某为此案犯罪嫌疑人。
