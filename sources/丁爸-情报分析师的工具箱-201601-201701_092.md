# 那些未来的科技，其实都用到军事里面去了！

在军事竞赛上，各大国也是你追我赶，对于各种军事研发也是毫不吝啬，看多了消费级的科技，来看看军事级别的高科技吧。

  

1、主动拒止系统

  

![](../Images/7c6d5d1862a6b87b1d3a00612e620219.png)

  
  

这个系统又称热射线，是美军研制的一种非致命性定向能量武器，常用来驱散敌军或人群。ADS 的工作原理是发射毫米波电磁针对人们的皮肤加热，会使人们感觉到身上着火了一样。

  

![](../Images/d33bc4b60888a8bd9bcee8f0fd3fb396.png)

  
  

虽然在能在安全的温度下击退人群，但是这种射线会对人的身体造成潜在的影响，如果过度暴露会引发癌症。

  

2、电磁轨炮

  

![](../Images/9a0f3ebf7d5f0dfcb61e7d4ef37fd3c5.png)

  
  

磁轨炮是利用磁场动能推进弹丸的杀伤武器，与传统的大炮将火药燃气压力作用于弹丸不同，电磁炮是利用电磁系统中电磁场的作用力，其作用的时间要长得多，可大大提高弹丸的速度和射程

  

![](../Images/ae6590d00e4c70e0f218c61d878d1e16.png)

  
  

磁轨炮的速度能达到 2-3 公里/每秒，NASA 也提出了用磁轨炮来推送小型火箭升空。

  

3、线圈枪

  

![](../Images/9be4910a86195caa837d535d1beafc04.png)

  
  

高斯枪又称为线圈炮，为磁轨炮的前身，子弹通线圈感应产生电流，磁场与感应电流相互作用，推动炮弹前进过线圈当炮弹到达第二个线圈时，向第二个线圈供电，又推动炮弹前进，然后经常第三个、第四个线圈……直至最后一个线圈，逐级把炮弹加速到很高的速度。

  

![](../Images/085c05da8656bf6090040b3e0247c768.png)

  
  

这种武器也是经常在游戏里面出现，例如《星际争霸》、《半条命》。正因原理简单，网络上很多爱好者都自制当玩具。

  

4、激光武器

  

![](../Images/fae6d698ec03113621e944d3f9cee731.png)

  
  

这套系统也是各种影视作品的常客，而在现实中也被美海军采用，依靠高密度的红外光束，拦截无人飞机或者高空引爆炸弹。

  

5、金属风暴

  

![](../Images/bcb4c10953d17d6645b98289a7899263.png)

  

![](../Images/f8b7142b106c84707a11c7177e14326b.png)

  
  

该武器技术由澳大利亚人 Mike ODwyer 发明的，利用电子化学气点火的技术，通过过电子控制处理器控制设置在枪管中的电子脉冲点火节点，可靠地点燃最前面一发弹的发射药，发射药燃烧后产生的火药燃气压力推动弹丸沿枪管加速运动飞出枪口。

  

![](../Images/15ecc876442ee27cb486156b9aeeab2c.png)

  
  

据说在一秒之内发射一万六千发特制的子弹。

  

6、墙角枪

  

正所谓，明枪易挡，暗箭难防。

  

![](../Images/ef1e2f940de1a04346c7427efc3e62b0.png)

  
  

墙角枪由两部分组成，前半部分装有手枪，高清摄像头，红外激光，提供士兵监察敌情；后半部分装有屏幕和扳机，以便瞄准。

  

![](../Images/2fc27295d3aada4eee72ea2bff77f06a.png)

  
  

顾名思义，此枪躲起来就能开火，中枪了也不知道谁下的手。

  

7、Mahem

  

![](../Images/972259b7ba1ea601f2adea23f76e58f5.png)

  
  

美国国防高等研究计划署（DARPA）正在研发的一种磁流体动力爆炸弹药。它能够利用一种炸药产生多头射流和破片,形成定向的、高速的火力打击目标。
