# 中国电信网络重构的初步探索：5GSDN网关VoWiFi亮点突出

2016年7月12日中国电信发布《中国电信CTNet2025网络架构白皮书》，全面启动网络智能化重构。在本次“2016年中国国际信息通信展览会”上，中国电信展出了对“网络重构”的初步探索产品：5G原型机、SDN智能网关以及高清语音VoWiFi。

  

![](../Images/49598ebaba09d9f6c4a0c4d9f796f7fe.png)

  

  

**高速率的5G原型机和提升网络容量的大规模天线技术**

在全球大规模部署4G的同时，5G悄悄来了。如今全球运营商和设备制造商都已陆续着手5G技术的验证和讨论，2020年或是5G商用元年。中国电信作为世界领先运营商，在满足现在的用户宽带和语音业务的同时，也立足现在展望未来，为5G网络的规划和验证承担相应责任，做出了很多成绩。

在“2016年北京国际信息通信展览会”现场，中国电信展示了与诺基亚公司合作的5G原型机，这套5G原型机系统相当于一个5G模拟设备，通过宽载波(4个100M)，高阶MIMO(8\*8)和高阶调制(64QAM)等新技术，实现了上行下行各5Gbps的高速率。

因为现在5G标准还未确定，一旦确定中国电信将要求统一安排适时开展5G试验。另外，在现场中国电信还展示了大规模天线技术(Massive MIMO)就是中国电信的一项阶段性成果。

大规模天线是5G的标志性技术，中国电信在这方面也走在前面。日前中国电信技术创新中心就在业界首次完成模块化大规模天线概念样机并进行了测试，测试结果显示模块化大规模天线可以实现与大规模天线面阵相似性能增益，同时在安装和部署上更为敏捷，灵动，可实现大规模天线根据用户分布，覆盖场景按需部署，为该项技术的落地和提升网络容量提供了更为广阔的空间。

**自主研发SDN网关 实现开放网络能力**

在这次展会上看，中国电信还展出了对“网络重构”的初步探索产品：SDN宽带网关。

据了解，这是由中国电信研究开发的网关软件与控制器平台软件，用户通过PC或者手机APP登录自服务门户，可以像逛网上商城一样购买自己喜欢的网络服务与产品、定向加速、智能家居即插即用、信息安全锁等多种增值服务，选中订购后传递到SDN控制器，再实时下发配置和流表到SDN宽带网关;网关自动建立隧道连接到指定的服务平台，进而可以快速部署增值服务，实现开放安全的网络能力。

以往传统的文件在下载过程中，用户根本无法灵活调节下载速度。而使用了中国电信的SDN网关后，用户可以登录自服务门户订购相应的加速业务，实现下载加速，真正实现定制服务，按照自己的需求进行网络分流。

如今很多家庭开始广泛接入智能家居，拿摄像头为例，型号众多的摄像头都接入网关，传统的网关需要手动对摄像头一一进行配置才能保证正常使用。但中国电信SDN网关可以无需配置直接插入不同型号的摄像头，这样用户在自服务平台上点击“智能家居”应用服务，通过手机就可以直接调取拍摄视频，真正实现了即插即用。

当然，安全性也是不可忽视的问题，据中国电信工作人员介绍，SDN网关还针对安全问题提供了相应信息安全锁服务。以上面提到的摄像头为例，传统的摄像头视频内容存在泄露的风险。中国电信的SDN网关推出家庭网络安全锁服务，当用户发送收看视频请求后，SDN网关会在绑定的移动端给予告警信息，告诉用户现在有特定的用户(包括IP地址、手机号码、用户名称等)需要访问家庭摄像头视频，只有当用户确认授权后，视频才能正常播放，如果用户点击拒绝，将有效拦截对视频内容的非法调用。

另外，SDN网关还具有绿色上网功能、为软件开发者提供第三方平台一级一级用户通过自服务门户或者APP可以灵活控制业务的功能。

**网络重构在应用侧的重要实现：VoWiFi-VoLTE双向无缝切换**

随着中国电信“快马加鞭”推进VoLTE的商用，尤其在居民区VoLTE室内覆盖面临着弱覆盖的问题，如果部署微基站或者安装信号放大器都会增加投入成本。

其实，WiFi已经发展很成熟，并且在人口密集区已经成为标配。因此，可以利用WiFi热点推出VoWiFi实现通过同一个核心网与VoLTE进行双向无缝切换。

何谓VoLTE-VoWiFi双向无缝切换?是指用户在通话状态下，可根据4G网络和WiFi网络的信号强弱情况，自动选择切入信号更佳的网络，切换前后通话不会中断。

中国电信VoWiFi解决方案就做到了这点，据介绍，它是基于3GPP标准规范化网络解决方案，实现了通过同一个核心网与VoLTE的双向无缝切换，保证用户语音感知顺畅;同时也可以支持短信、视频等交互业务。目前VoWiFi国际标准完善，产业链成熟，用户体验优良。

其实早在2016年8月30日，中国电信上海公司就在现网环境下，打通了VoWiFi网络下的First Call(第一通电话)，实现了与现网用户语音电话/视频电话/短信业务的互通，同日也实现了在这些业务下的VoWiFi和VoLTE双向无缝切换。

而且这是基于NFV架构的虚拟化网络设备实现的VoWiFi通话，是中国电信网络重构在应用侧的重要实现。“中国电信采用虚拟化ePDG设备开展VoWiFi现场试验，其虚拟化工作是NFV架构在中国电信移动网络部署的切入点，本次现场试验也将作为中国电信CTNet2025网络架构重构重点工作的先导性试点项目之一。”中国电信工作人员介绍说。

在这次展会现场，中国电信演示了在WiFi信号强弱变化下VoWiFi到VoLTE的双向无缝切换。【责任编辑/闫红玉】
