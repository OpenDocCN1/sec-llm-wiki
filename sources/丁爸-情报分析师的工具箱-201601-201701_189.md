# 南宁我又来了

多年前去过南宁两次，都是开车去的。

  

第一次去南宁是和丁妈、丁哥开车自驾游。当年轮到春节值班，节后补休一周，就决定自驾游。中午出发时并没有明确的目的地，我们先去五通吃了有名的鸡血旺，然后又到自贡看了恐龙博物馆，大约4点出发前往重庆。

  

本打算到重庆去骚扰一下老同学，但到了重庆就发现堵车很严重，于是就转往贵阳。到贵阳已是接近0点，刚好贵阳的环城高速和进城的路都在修建，路况非常不好。我们又临时决定不进城了，干脆往广西去，路上随便找个城市睡一觉就行了。可是出了贵阳没多久，又遇到在修贵州到广西的高速路。我们就在正在修建的高速路上一路颠簸而行，一路都是大雾，路况不熟，加上那时还没有智能手机，gps导航的更新又不及时，于是就不敢胡乱找路了。就这样沿着在修的高速路，跑到天亮时，到达广西地界。路况也好了，铺了柏油的二级公路。我找了个加油站，在车上打了一个小时的盹，又继续上路了。

  

中午时分，路过南宁，在南宁高速公路服务区吃了午饭，记得那里的鸡肉还做得不错。午饭后，我们原计划去北海，但想想海南就在对岸，不如直接去海南，那里还有朋友。就这样，我们漫无目的的就在傍晚6点在广东湛江的海安上了汽车轮渡，晚上8点到达海南的海口。这次只能算是路过南宁，对南宁没有什么印象。

  

第二次去南宁，是第二年和同事出差去广西柳州，我们也是驾车前往，一路还是我开车，早上从重庆出发，晚上到的南宁。在南宁住了两晚，期间去北海逛了一下午。对南宁的印象就是酸菜米粉的味道很怪，我无法适应。

  

这次时隔多年，再次和同事出差前往南宁。改乘飞机，提前在神州租车预订了车辆，这样到了南宁办事也方便，希望能圆满里程。
