# 手机摄影，如何提升照片通透感？

很久没有写与摄影相关的文章了，这段时间极少出去就疏于研究。前段时间在门诊遇到一位病人，喜欢摄影，一聊才发现他已经是国家中级摄影师了，作品一对比，我的就相形见绌了。

  

不过至少也让我知道了还有哪些不足，应该怎么继续学习。写的文章更多像学习笔记，这次则是讨论下**照片的通透感。**

  

![](../Images/8b8ab6579638f41ebf1681fca3eb45a8.png)  

### **一、什么是通透感**

出去拍照时，经常会遇到不好的天气，雾霾、下雨，或者在车上隔着窗户拍时，常常会觉得拍出来的照片上有一层灰蒙蒙的感觉。画面不够清澈、干净，看上去让人觉得不舒服。

  

这就是通透，在摄影中通透具体有三方面：**1、画面色彩丰富，2、空间层次分明，3、物体轮廓清晰。**

  

![](../Images/c36b7e2b457da31a11d20d618a14469e.png)  

  

大致是左图与右图的区别，让画面色彩更丰富，表达更清楚，毕竟清晰的图片给人感觉始终是享受的。

  

### **二、影响通透的因素**

分析原因，影响通透的因素主要有两方面：拍摄因素和环境因素。

在拍摄中又有人为因素和器材因素等，人为因素主要由技术问题导致，比如：曝光不足、白平衡不准、ISO过高等。器材则是由镜头、滤镜等影响。

  

环境因素有雾霾、玻璃、透明塑料袋等介质拍摄产生，导致光线混合干扰，最后影响通透。

  

好像说得复杂了些，大致明白就可以了，有些因素是无法避免的，但我们依旧可以通过后期来进行修复。

  

### **三、提高通透的方法**

其实不仅仅只是手机修图可以用，其他也是一样的原理，通透只是最基础的准则。提高通透一般有两种方法：基本调整和高级调整。

  

基本调整主要从以下几个方面处理：

  

> *   **提高清晰度**
>     
> *   **提高饱和度**
>     
> *   **提高对比度**
>     
> *   **纠正偏色**
>     
> *   **丰富细节**
>     

好像越说越复杂了，但后期其实没有完全的标准，找到自己喜欢的感觉才是最重要的。

  

手机里提高通透的方法也很简单，只需要调节锐化、饱和度、阴影、曝光等，具体调节参数依旧自己感觉而定。

  

比如这样：

  

![](../Images/4275e8df9b4abe1098d578e5b51fb47d.png)  
![](../Images/449167711baa87b93a0d9c11d2fe3c1f.png)  

  

也许改变是很细微的，但通透依旧是不可忽视的一步。

手机里推荐使用APP：Pixlr，可以调节程度比较大。

  

![](../Images/df39ade51e36954c15e4c5517976702b.png)  

  

或者使用泼辣修图的去雾功能。

  

![](../Images/3729917616812164d77da1ba562f5692.png)  

  

但调节这些参数其实并不是解决通透的核心方法，因为影响通透最核心原因是光色的互相干扰。  

  

比较复杂的概念，但这是摄影基础知识，如果你想系统学习的话，这很重要。

  

色彩中不能再分解的颜色称为原色，原色可以合成其他颜色。原色一般分两种：光学三原色和印刷三原色。

  

红绿蓝（RGB）和青品红（CMY，K），这是两种原色模式。

  

![](../Images/8010de0725daada7727b0e4bfc2c9349.png)  

在RGB中，三原色的组合可以形成各种颜色。  
红色+绿色=黄色  
红色+蓝色=紫色  
绿色+蓝色=青色  
...

所以颜色之间存在支持与互补的关系。以红色为例（观察RGB表）,黄色和紫色是红色的支持色，而青色则是红色的互补色。

  

具体运用场景，比如我们想拍一个漂亮的晚霞场景时，觉得天空不够红，除了增加饱和度外，我们还可以给画面增加黄色或者紫色来调节，减少青色也可以。

  

比如，可以在泼辣修图修图中适当调节红色来使天空更加通透。

  

![](../Images/8b49ed1c03541fa116235d6a19a0ffe7.png)  

  

曲线调节其实算是比较高级的调色技巧，手机上需要用支持曲线调节的APP才行，推荐使用泼辣修图。

  

其实这一部分用电脑更方便，直接利用Photoshop中的可选颜色功能。

  

比如这个，如果想要增加天空的蓝色，就需要在蓝色通道里增加红和青，同时减少黄色。

  

![](../Images/b15a028b9abef398ba113beff3e732ed.png)  

  

其他地方也是一样的道理，拍树木的时候觉得绿色不够，可以在绿色通道里，增加黄色和青色，同时减少品红。

  

**这才是解决通透的核心方法。**

  

还有一个例子是，平时经常会隔着窗户拍一些东西，如果觉得拍的不够通透，可以通过减少画面中的黄色或者直接用泼辣修图的去雾。

  

![](../Images/07bbc07fdfc909324bdf568370754979.png)  

  

泼辣修图的去雾很好用，手机和电脑都有客户端。

  

![](../Images/2cfe5f0f59c4cb65fd24bdbdb32e4cb7.png)
