企业微信今日正式上架 消息可云端同步

4月18日，企业微信上架APP Store，使用者可在电脑上访问注册页面，注册企业使用。

微信方面介绍，企业微信是专为企业打造的沟通、协同工具，在多平台同步推出。消息可以云端同步。


“企业微信的推出跟微信的发展有着紧密的关系。实际上，随着微信的应用越来越广泛，很多人除了生活，社交外，也会把部分日常工作的交流延伸到微信上。特别是非工作时间，免不了因为同事们都在群里讨论工作，而参与进去。”

不久前，很多人还在期待企业微信的发布能够让自己的微信回归正常生活，而就在今天，腾讯终于正式发布了企业微信 1.0 版，兼容 iOS、Android、Windows、Mac 四个主流平台（嗯，没有 WP 版）。


   


企业微信与阿里钉钉类似，都是完全针对企业工作需求而打造的办公沟通工具，除了标配的聊天功能以外，还提供了公费电话、邮件（需要绑定腾讯企业邮箱）、公告、考勤、请假、报销、待办提醒等功能。

传说中的“回执消息”、“休息一下”功能也没有落下。“休息”功能可以让员工在休息的时候不受打扰，而微信团队设计这个功能的初衷也非常简单：

生命的1/3都在工作，所以为什么不能让体验更好一点，工作更愉悦一点？！


   


针对“回执”功能，微信的解释是：

“和微信一样，出于对消息接收者的保护，企业微信也默认不带消息的已读未读状态，但在工作场景下，又确实有些紧急和重要的事项，那就可以通过 “回执” 功能，让发送者知道消息是否触达接收方。这样既保护了接收者，又用 “回执” 满足了发送者，是一个有节制的功能。”

目前企业微信的注册和使用完全免费，有意使用的企业可以通过腾讯企业邮箱或微信企业号创建。


   


根据微信的推送，总结了一些常见的企业微信问答：

1. 企业微信适用于多大规模的企业？

无论你是几十人的创业团队、中小型企业，还是多大上万人的大公司，企业微信都能够顺畅地提供服务。

2. 企业微信是免费产品，服务质量有保证吗？

免费的互联网产品太多了，以腾讯的体量和盈利能力，也不需要在产品的发育期就通过向企业微信用户收费来保证正常运行。企业微信团队是这样回答的：

正如 Pony（马化腾）说的，“在国内，企业市场其实是一件慢工出细活的事。”既然我们希望“让每个企业都有自己的微信”，这一定是一个长期投入的过程，我们有十年磨一剑的耐心。

3. 企业微信如何保证企业机密信息的安全？

企业微信团队：企业微信设计之初，就考虑了企业用户在信息安全上的要求，除了继承微信多年的经验，对信息传输加密，数据存储加密等。 企业微信还针对企业应用的特点，强化所有企业数据操作等的安全审计能力，我们把企业的数据安全，防止数据泄漏等作为重中之重。

4. 企业微信未来怎么搞？

企业业务千变万化，对于沟通应用的需求也是非常复杂的，想要有未来，企业微信就必须走上开放平台的道路。企业微信团队也的确强调了这点，下一阶段他们将会着重 API 接口的开放，延展企业微信的开放能力。
