今天给大家推荐office2016专业加强版的下载地址和注册激活方法

一、下载地址：http://www.itellyou.cn/

![](../Images/b190043b810af8bc628a9a5bcd11eb50.png)  
该网站有许多系统资源可以下载，包括office2002到2016的所有版本

1、在应用程序中找到office2016，点击详细信息，可看见下载链接

![](../Images/667a8a903bbd30d55e06fdc7d96f2726.png)  
2、将下载链接复制到迅雷中新建下载任务

![](../Images/a292b2ee87423c660b365165152cb2d5.png)  
3、该文件是光盘映像文件，点击虚拟光盘依次安装。

![](../Images/2947142452a9d819be6eb8d6ab68a573.png)  
二、第二种下载office2016光盘映像文件方法：

百度云上的下载地址：http://pan.baidu.com/s/1qXgvzy8

  

三、安装完后不要运行软件，先到百度云下载office2016注册软件

1、注册软件下载地址：http://pan.baidu.com/s/1c1ifB24  

2、下载后解压kmspico v10.1.6 install

![](../Images/d8ccd8a96eb2098d651a4da5f27f2ff8.png)  

3、先运行卸载服务，再运行kmspico-setup

![](../Images/9469c944400ed6847a91a4dac1dbb6e2.png)
