# 【汇总】美国执法情报分析师职业培训机构

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MTE0NTE3Mw==&mid=2651107619&idx=1&sn=a4dc7486dd1ec387d828fc77bdf2e322&chksm=f1aec619c6d94f0faf7a8b6c22ca223cb1225be251be9b870da9dd1d2deb0df1b197719badb1&scene=126&sessionid=1681267487#rd](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651107619&idx=1&sn=a4dc7486dd1ec387d828fc77bdf2e322&chksm=f1aec619c6d94f0faf7a8b6c22ca223cb1225be251be9b870da9dd1d2deb0df1b197719badb1&scene=126&sessionid=1681267487#rd)

美国执法情报分析职业培训课程项目开发和提供主体有私营机构、专业协会、政府机构、高等院校与研究机构等四大类。

一、私营机构

在美国，大多数的执法情报分析师主要通过私营供应商接受培训。阿纳卡帕科学有限公司(AnacapaSciences，Inc．)、阿尔法集团中心(AlphaGroupCenter)、情报分析培训股份有限公司(Intelli-genceAnalysisTrainingLtd．)等私营企业在美国情报分析培训领域具有较大的影响力。

1、阿纳卡帕科学有限公司1971年便开始提供情报分析策略与技术方面的培训，来自执法、情报、金融、保险、军事等领域的数以千计的分析师参加了该公司的培训课程。

阿纳卡帕公司官网网址：http://www.anacapasciences.com/

![](../Images/5411c52edd2038a3899905f029f0e20f.png)

2、阿尔法集团为刑事司法、公共安全以及受害者服务等领域的组织提供专业知识与实践经验，在犯罪、调查(心理画像)、情报分析、财务报表分析、项目工作量分析、基金申请以及其他执法领域的培训方面具有优势。

阿尔法公司官网网址：http://www.alphagroupcenter.com/

![](../Images/f036b6236c2f52a7b1ebac0bf772920e.png)

3、情报分析培训股份有限公司开发了犯罪与情报分析领域初级、中级和高级培训课程项目，部分课程已经美国国际执法情报分析师协会(IALEIA)专业认证委员会认可。

情报分析培训股份有限公司官网网址：https://intelligenceanalysistraining.com/

![](../Images/597e08e4809dd08fc8dd7621a551525a.png)

二、专业协会

美国国际执法情报分析师协会(IALEIA)、国际犯罪分析师协会(IACA)、执法情报单位协会(LEIU)三大协会组织在美国执法情报领域具有举足轻重的地位。

1、国际执法情报分析师协会(IA-LEIA)创建的“情报分析基础培训项目”(FIAT)影响最为广泛。

美国国际执法情报分析师协会官网地址：https://www.ialeia.org/

![](../Images/9736a30fa97cb6dce4fee35d35425fce.png)

2、国际犯罪分析师协会(IACA)是成立于1990年的非盈利组织，旨为全球的犯罪与情报分析人员提供培训、交流与职业发展机会，改进执法机构的犯罪分析能力，提供的培训课程主要涉及犯罪制图与分析、EXCEL分析技术、计算机在犯罪分析中的应用、犯罪分析基本技能、GIS在犯罪分析中的应用、CrimeStat系统、战术与问题分析、话单分析、犯罪分析工具等内容。

  

IACA提供的CLEA执法分析师认证计划具有权威性，其出版的《犯罪分析探究》一书总结了IACA会员认定的高效进行犯罪分析必不可少的20种技能，在犯罪分析培训领域影响深远。

国际犯罪分析师协会官网地址：http://www.iaca.int/

![](../Images/f8d0619d1fe4861e0dadac5b27cdcbcc.png)

  

  

3、执法情报单位协会(LEIU)是一个以领导和推动刑事情报机构保护公共安全和宪法权利为使命的专业组织。LEIU成立于1956年，有240个地方,州和联邦机构成员单位，建有刑事情报交流中心,促进了机密信息的及时交换，并提供情报专家认证培训。

执法情报单位协会官网地址：http://www.leiu.org/

![](../Images/f1b11ea8ca6251b5824592ead78d4ecd.png)

三、执法机构

美国国土安全部、联邦调查局、美国缉毒署、联邦执法培训中心以及部分州和地区执法机构的情报分析培训项目成效颇为显著。

1、联邦调查局情报培训中心创建于2002年，其前身为FBI分析研究学院(CAS)，为FBI特工、情报分析师以及州、地区和部族执法机构的分析师提供初级与高级情报搜集、分析与谍报技术培训。

FBI培训学院官网地址：https://www.fbi.gov/services/training-academy

![](../Images/4715874a5d8d42184964b75d53f9bc0f.png)

2、美国缉毒署(DEA)是缉毒情报领域的领头羊，提供“初级情报研究专家培训项目”(BIRS)和“联邦执法分析师培训项目”(FLEAT)。

  

BIＲS是为期9周的分析技能强化培训项目，旨在为新聘任的进入禁毒领域的情报研究专家提供入门级的分析培训。

  

FLEAT是为期4周的培训项目，旨在与其他联邦、州、地区、部族和国际执法机构分享DEA毒品情报专业知识、最佳分析工具和实践，强化批判性分析能力，该项目还设有为期2周的移动FLEAT课程。

美国缉毒署官网地址：https://www.dea.gov/

![](../Images/804101acc7692e90ee56e306bc628a7a.png)

美国缉毒署培训网页地址https://www.dea.gov/ops/Training/Training.shtml

![](../Images/b5c695db29880a493fb1af8ea4b77986.png)

3、联邦执法培训中心(FLETC)是为91个联邦机构提供执法培训的跨部门组织，该机构也为州、地区、部族和国际执法机构服务，提供的情报培训项目主要有执法官员情报意识培训项目(IALEETP)、情报分析师培训项目(IATP)、反恐情报认知培训项目(ATIATP)等。

联邦执法培训中心官网地址：https://www.fletc.gov/

![](../Images/6d2a7885fd7e89bfcc659cea927bdacd.png)

4、佛罗里达州执法部门(FDLE)于2003年建立了佛罗里达州执法分析师学院(FLEAA)，这是美国第一所此类学院，先后开发了佛罗里达分析人员初级培训课程(FBAT)、计算机应用与分析技术课程(CAAT)，2009年将上述两类课程调整为佛罗里达执法分析师培训(FLEATⅠ－Ⅱ)。

佛罗里达州执法部门官网地址：http://www.fdle.state.fl.us

![](../Images/ebdcb30166cd98232859b09f5907de89.png)

  

此外，国家白领犯罪中心、移民与海关执法局国土安全调查情报办公室、新泽西州警察局地方情报研究所、高强度毒品交易区域(HID-TA)以及州和地方反恐培训机构(SLATT)等执法机构提供各类具有特色的情报分析培训课程，在各自领域具有一定的影响。

  

四、高等院校

在美国，高等院校是执法情报学历教育和在职培训的重要力量，提供情报分析本科学位、硕士学位课程和在职认证培训课程。

1、密歇根州立大学(MSU)提供执法情报与情报分析硕士学位课程，该情报学位课程是美国最古老的刑事司法学位项目。

密歇根州立大学官网地址：https://msu.edu/

![](../Images/8c95fdd07d01d841f4b0637ffdd19473.png)

2、梅西赫斯特大学提供研究/情报分析师本科教育项目(ＲIAP)，该项目始于1992年，是第一个情报领域的非政府教育项目，“9．11”事件后ＲIAP项目名声大振，2004年开始提供硕士学历教育项目，2004年2月成立情报学院(IIS－MU)，提供情报学文学学士项目(BachelorofArtsinIntelligenceStudies)、应用情报理学硕士项目(MasterofScienceinAppliedIntelli-gence)、应用情报在线研究生证书项目以及网络空间威胁分析非学历在线学习课程项目等。

梅西赫斯特大学官网地址：https://www.mercyhurst.edu/

![](../Images/18dcd77c30a1895e3cd554acacc5d923.png)

此外，美国国防情报学院、中央情报局大学、美国海军研究生院、美国国土安全部国土防卫与安全中心、马里兰大学公共政策学院、圣母学院、亨利普特南大学等院校研究所提供情报分析学历教育或职业认证培训项目。

  

还有部分高校与执法机构合作开发情报分析培训课程，例如加利福尼亚大学河滨分校与加州司法部门合作的“犯罪和情报分析认证项目”在业内颇具名气。

  

五、受美国司法部与国土安全部资助的培训课程

随着对分析师培训价值的认识的增长以及分析师数量的增多，美国各类情报培训项目不断产生。在各级各类情报分析培训课程项目中，尤其值得关注的是执法机构与国土安全机构资助的情报培训课程，这些课程在情报分析培训中具有重要的地位。

  

一是美国司法部情报培训协调工作组(ITCWG)和反恐培训协调工作组(CTTCWG)提出的培训计划项目，得到了司法部、司法项目办公室、司法援助局的资助，国家犯罪情报资源中心将满足《犯罪情报最低培训标准》的情报培训项目制作成日程表，为各级执法机构提供统一的查询入口。

美国司法部官网地址：https://www.justice.gov/

![](../Images/47d62513ed4f5ddac79cdcdc09dcf663.png)

二是符合美国《州、地区和部族情报分析师通用能力》标准，满足融合中心分析师的培训需求，并经美国联邦紧急事务管理署(FEMA)的批准，纳入国家培训与教育部门培训课程目录。或州/联邦资助培训课程目录，列入国土安全拨款计划的培训项目。

  

这些项目主要有:初级情报与威胁评估课程(BITAC)、脆弱性/威胁和风险评估(VTＲA)、批判性思维与分析方法(CTAM)、情报整编基本原则(PI-WB)、写作效用最大化(WFMU)、情报分析基础培训(FIAT)、中级融合中心分析师培训(分析与恐怖主义预防、战略分析和口头报告)、执法分析师项目、国家情报办公室－分析101、融合中心分析师风险分析入门等。
