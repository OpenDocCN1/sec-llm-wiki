# 【工具】让你随时都可以办公的小程序-----最近文档随身

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MTE0NTE3Mw==&mid=2651107366&idx=1&sn=b321d7a4b388ca1275b31251945bb294&chksm=f1aec71cc6d94e0a079579a0142c0afdec220b696eb855532e36229373ede8fdb9c9b5f65e7e&scene=126&sessionid=1681267502#rd](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651107366&idx=1&sn=b321d7a4b388ca1275b31251945bb294&chksm=f1aec71cc6d94e0a079579a0142c0afdec220b696eb855532e36229373ede8fdb9c9b5f65e7e&scene=126&sessionid=1681267502#rd)

经常都会遇到电脑上需要处理的文档、表格、ppt等等还没有弄完，因为有事又不得不离开，又不方便带电脑出门。路途中又有许多时间，这时着急想完成的事情能在手机上处理就好了。

  

平时遇到类似情况我们可以用office的云端共享功能，这个在昨天的文章里我提到过。

  

今天丁爸再给大家推荐一个腾讯的小程序-----“最近文档随身”，它也可以让你很方便的处理电脑上没有处理完的相关文档。

  

具体使用方法：

1、在电脑上安装腾讯电脑管家。

官网下载地址：https://guanjia.qq.com/?ADTAG=media.buy.baidu.TXDNGJSEM

![](../Images/361d8627362fdce646bf3b52a7a441fa.png)

2、打开腾讯电脑管家，进入右下角的工具箱，选择左侧的文档菜单栏，点击启用“最近文档”插件。

![](../Images/dee050b9ef335f883a91562edb477ddf.png)

3、打开手机微信，在发现栏目进入小程序，在顶部搜索栏搜索“最近文档随身”，即可找到该小程序，选择使用该小程序。

![](../Images/7fff4f5b09aaf7b6a1ae8c727fef3763.png)

4、打开电脑屏幕，右上角会出现的最近文档框，点击左下角人形图标，会出现绑定“最近文档随身”小程序的二维码。用小程序扫描并绑定电脑。

![](../Images/984e200532c871007276e9b106b5d592.png)

![](../Images/1d4b6a476248946f3e197ab7881e401f.png)

5、这时在手机上就可以看见电脑上最近打开和处理过的各类文档了。这时只要你带着手机就可以很方便的在手机上处理你着急的事情了。

![](../Images/575219af63842412f767b937e4a3910a.png)

![](../Images/c988f0900c2fe25af16e8e4187ab7805.png)
