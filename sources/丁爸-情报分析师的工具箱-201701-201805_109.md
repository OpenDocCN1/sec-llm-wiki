# 【资讯】可以感知人脑信号的外骨骼即将上市民用

每个人都有骨骼构成支撑身体的骨架。骨骼功能是运动、支持和保护身体;制造红血球和白血球;储藏矿物质。骨骼由各种不同的形状组成，有复杂的内在和外在结构，使骨骼在减轻重量的同时能够保持坚硬。骨骼受损或者病变就将影响人的正常活动能力。电影《钢铁侠》里的主角托尼.史塔克就有一件钢铁的外衣让他能够拥有超人的力量。

![](../Images/02176e9b33059fc9a5c34348eed477c1.png)

目前，日本机器人技术公司 Cyberdyne 已经正式获得美国食品及药物管理局（FDA）批准：其医疗版下身外骨骼，即混合辅助肢体（Hybrid Assisted Limb 或 HAL）可在美国上市。

![](../Images/c12601f4e33e35095227706f8f6f93d3.png)

目前，这种外骨骼仅能通过正规医疗机构获得。其可通过传感器检测大脑发送到肌肉的生物电信号，并与用户的运动（或意向运动）相匹配，从而增加肌体的强度和稳定性。

 

![](../Images/61e2fcc981de5ddc48233d7828302293.png)

已获批的 HAL 版本为医疗版，主要针对下肢残疾人士。它可以帮助用户恢复肌体的机动性和独立性。

![](../Images/e4945afa61c21b446d76f6b2fd6916a9.png)

外部人工系统, 增加支持和保护, 被称为外部骨架或外骨骼。这外骨骼增强系统, 可用于军队、医疗、建筑等领域。 在日本塞柏制作的哈尔套装问世后, 小说就成了现实。 Hybrid Assisted Limb 或 HAL也许是市场上可用最先进的外骨骼。这款机器人套装的商业版价格介于1.4万和1.9万美元之间。 作为身体结构的延伸, HAL5 被用来支持运动和举重。该系统可以辅助残疾病人从椅子上上升, 走路或举起各种重量。在建筑中可以用在搬运或捡重物的时候。 Exoskeleto 公司的混合辅助肢体 为福岛地震后出现的放射性残留物的清除提供了很大帮助。这仅仅说明了它的通用性和实用性, 可以从使用这种机器人骨骼系统中获益的应用程序列表实际上是无穷无尽的。 HAL 是一种用于支持和扩展人体能力的机器人型机械手。自1992年启动项目以来, 塞柏发布了几个版本, 从 hal 1、hal 3 到hal 5 。每个版本都带来了移动性、低权重和更大自主权的改善。 作为身体的延伸, 系统必须知道身体的意图。可以直接从大脑读取, 然后到达人体肌肉, 那么这些意图的信息可能更合适。

  

生物 Cybernic通过阅读控制肌肉的生物信号来设置身体运动意图。并非每种类型的信号都被考虑到, 首先是导致肌肉纤维收缩的所有信号都被读取, 这个信号叫做肌电信号。在看过肌肉可见运动之前发生的这些肌电信号后, 就可以很容易地将系统与人体同步。

  

随着越来越复杂的机器人和系统的发展, 医学和技术之间的联系变得越来越强大。像哈尔这样的外骨骼套装具有巨大的潜力, 可以用来支持有临时或永久性残疾的人, 或在需要提高提升能力的各个领域工作的人。
