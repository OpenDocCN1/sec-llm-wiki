# 【资讯】地上有共享单车天上将有共享无人机了，国产载人无人机亿航184发布测试视频

亿航184是全球第一款可载客的无人驾驶飞机，由总部位于中国广州的亿航智能技术有限公司独立自主研发制造，是一款安全、环保、智能的自动驾驶低空飞行器，将为人类提供中短途日常交通运输解决方案。

![](../Images/e084dce19ebcfb57d4348e0cc035801a.png)

“亿航184”的寓意是这种无人机能运载1位乘客，它有8个螺旋桨和4支向四外伸出的机臂。

![](../Images/c748422b7664e88c4ec70c1ffc6d37cc.png)

亿航184已经获得迪拜交通局的首肯，在2017年7月正式开始试运营“无人机的士”服务。

![](../Images/3b3a5e077c949fb4331094d864321833.png)

2018年2月6日，广州亿航智能技术有限公司向全球发布亿航184”自动驾驶飞行器载人飞行测试视频。

金羊网讯 记者罗仕报道：

  

2月6日，广州亿航智能技术有限公司向全球发布了“亿航184”自动驾驶飞行器载人飞行测试视频，在媒体记者的见证下，“亿航184”在广州飞行基地进行了飞行演示。亿航创始人兼CEO胡华智表示，未来空中巴士将成为现实，载人飞行器将像私家车一样普及，今年“亿航184”计划实现小批量交付，未来会在广州等城市率先试点。

  

“现在我偶尔也乘坐‘亿航184’，从家短距离飞到飞行基地上班。”胡华智介绍，“亿航184”能解决城市短途交通的问题，实现城市内及城市间的点对点飞行，明显提高交通效率。该飞行器飞行均速约100km/小时，高速巡航测试可达到130km/小时，飞行直线距离理论上可达到50km，一般飞行预留距离为40km，“别小看40km，城市空中直线距离远远大于地面交通的距离，从广州城区出发40公里直线距离，可到达东莞、佛山。”

  

羊城晚报：“亿航184”怎么保证飞行安全？

胡华智：安全是飞行的前提。作为全球首款全电力低空自动驾驶载人飞行器，这几年，我们一直在研究、调试，目前技术已经很成熟。

  

“亿航184”将实现“永远不坏”，这个“不坏”不是说真的不坏，而是指它的所有系统都有备份，如一个系统出问题，备份系统会及时跟上，将乘客安全送达地面。

  

羊城晚报：未来 “打飞的”真的会成为可能吗？

胡华智：未来不到5年的时间内，城市内将会设立起降点，载人飞行器将得到普及，成为市民的交通工具。我相信载人飞行器未来将像私家车一样普及，大家在天上交通来往，频率跟地面交通是不相上下的。现在城市寸土寸金，留给地面交通的都是线状的道路，城市交通需要一维到三维空间的变化才能解决。

  

羊城晚报：普通市民能买得起“亿航184”吗？

胡华智：现在“亿航184”产量比较小，成本还比较高。但未来2-3年，随着量产及推广运营，成本会逐渐降下来，我们将会让大家都买得起。“亿航184”的运营成本很低，起降点将设立充电系统，用220v的充电器，一个小时左右就可以充满，由于使用的是电能，非常环保。
