第一个工具是前几天介绍过的fakeApp

往期推文：不可描述，技术进步


fakeApp让用户在电脑上选择一段视频，从一个公共可用的资料库中下载与某个人脸相关的神经网络。然后，只需一个按钮，就能将视频中的人脸更换成资料库中的人脸。

通过机器学习，任何使用者都可以使用该应用将名人的脸“p”在其他视频人物的脸上，创建新的视频片段，包括盖尔加朵等多位名人的被编辑后的视频片段已被发布在网络上。该应用下载、使用简便，效果逼真。

第二个工具是：Project VOCO


Project VOCO是一款由Adobe公司推出的一款音频编辑软件，此音频编辑软件可以在音频文件里加入不存在的词语和语音内容。从此以后你也能PS音频了。


Project VOCO和 Photoshop 很相似，Project VoCo 项目的设计目标，就是要打造一款先进的音频编辑应用程序，除了标准的音频编辑和噪音消除功能之外，Project VoCo 还可以利用一个播放器来记录声音，生成新词。简单的说，这款软件可以理解、分析某个人的声音，然后再复制出一个完全相同的声音，所有这一切，Project VoCo 只需要一段大约 20 分钟的语音记录就能搞定。在对外发布的一段 demo 里，开发人员展示了 Project VoCo 在一个句子中加入一个新词，音效完全听不出来有任何差异，几乎接近于完美模仿原发音者。


这款工具甚至有可能颠覆音频工程师的声音处理工作，包括声音编辑、润色、清理记录等等。 使用 Project VoCo 技术，我们就有能力伪造出某个人的声音，让他/她表达一整段句子。

编辑时，只需将相应的文字复制、剪切、粘贴就可以完成对相应音频的编辑。

第三个工具是Project Cloak


Project Cloak是Adobe公司在Adobe Max2017大会上发布的新功能。

根据工程师的演示可以看到，新功能可以让视频画面中的一些物体消失掉。


在示范视频1里有一条碍眼的灯柱，演示工程师进入影片其中一格，选出灯柱「执走」，其余影片的灯柱即时消失。初次示范效果未见完美，之後配合 After Effects 便能在影片内追踪灯柱出现的位置，估算所遮盖的背景，做到完美执走。示范视频2是把人物衣服上的图案执走，示范视频3是把视频中的人物都可以完美无瑕疵地执走。
