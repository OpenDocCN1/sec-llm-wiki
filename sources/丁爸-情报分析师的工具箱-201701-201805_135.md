# 【工具】可以把手机变成遥控器的输入法---袋鼠输入法

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MTE0NTE3Mw==&mid=2651106968&idx=1&sn=c3757b0be00a492605446466eace2bd9&chksm=f1aed9a2c6d950b47ddca4d9376db790de725ebf58340925537b7a89f400b2b9a93945c5bb1a&scene=126&sessionid=1681267518#rd](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651106968&idx=1&sn=c3757b0be00a492605446466eace2bd9&chksm=f1aed9a2c6d950b47ddca4d9376db790de725ebf58340925537b7a89f400b2b9a93945c5bb1a&scene=126&sessionid=1681267518#rd)

今天给大家介绍一款可以将手机变成遥控器的输入法-----袋鼠输入法

官网下载地址：http://daishu.baidu.com/

![](../Images/5e897a1ed8289a8736a21553e8cd22ad.png)

在电脑和手机都安装该输入法后，手机就可遥控播放电脑上的视频，还可语音输入文字到电脑上，也可以遥控ppt播放，在手机上操作电脑鼠标等等。

![](../Images/9093f06c3e961b472c8354ca7b15e230.png)

使用方法：

1、官网下载软件到电脑、平板和手机并安装。  

![](../Images/7243af27467177aac79be34bd795d7bf.png)

2、打开电脑上的袋鼠输入法，会出现二维码，提示用手机袋鼠输入法扫描连接电脑。

![](../Images/a730fa8dc349b537353ead1ed9550a44.png)

  

3、连接成功后，进入遥控----视频遥控界面，点击左下角的鼠标图标，进入控制电脑鼠标界面。

![](../Images/281192f564ecb1e7e4445067f1c71718.png)

4、在手机上即可操作电脑鼠标，可操作鼠标移动，模拟操作鼠标左右键。

![](../Images/0a287fc4fa552585e895df0b4a241fe6.png)

5、进入输入界面，可语音输入文字到电脑输入窗口。

![](../Images/e89a472439f8204b80dbf0b0354fe02e.png)

![](../Images/dd2cd847c930875c873e8eb661b6ade8.png)

6、语音输入时，可以选择使用普通话、四川话、粤语和英语。

![](../Images/ecbbdbe52418b8618b7ea21cc6fbf884.png)

  

7、手机操作电脑视频，首先要使播放的视频处于全屏状态，然后就可以用手机上模拟的遥控功能键操作视频播放的声音大小，快进或者快退，跳转下一个视频等等。

![](../Images/6020ed7e95cd4b0a06facfea2bcac92f.png)

8、用手机操作PPT，上下滑动即可翻页或者返回，还可模拟激光笔投射到屏幕上。

![](../Images/68d40e0891d9b48e07caa3c542cf47ae.png)

![](../Images/b56d0148256e02c410c5212a6fd30af7.png)

  

9、还可用手机操作电脑关机、重启、注销、休眠。

![](../Images/b5322e513c0e06202f62e9b59683ff48.png)
