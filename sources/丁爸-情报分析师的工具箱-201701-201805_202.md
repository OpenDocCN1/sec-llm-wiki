# 【资讯】战火在四川警察学院点燃

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MTE0NTE3Mw==&mid=2651106575&idx=1&sn=aa31d2aa0647632695bd9335a1319f1c&chksm=f1aeda35c6d95323edf484d38e10c1408a699fdf6c3cb09b18015be1e576b2490ef59cf210d4&scene=126&sessionid=1681267543#rd](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651106575&idx=1&sn=aa31d2aa0647632695bd9335a1319f1c&chksm=f1aeda35c6d95323edf484d38e10c1408a699fdf6c3cb09b18015be1e576b2490ef59cf210d4&scene=126&sessionid=1681267543#rd)

2017年11月27日，四川省公安机关第四届教官教学技能大比武大赛的战火在四川警察学院点燃。

![](../Images/3975d6eaeea4a56eb84fe6adcdc69a21.png)

![](../Images/6da502fd4920724aa1dc4047c101a940.png)

来自全省21个市（州）公安局，厅属有关部门和四川警察学院的110余名教师、教官，同场竞技、激烈角逐，向团体和个人冠军发起冲刺。

![](../Images/d03a2731e41a880936079c0a88a3fcad.png)

  

比武分为“警务技能训练”和“公安理论教学”两大部分。通过比赛将选出全省“十佳警务技能训练教官”和“十佳公安理论教学教官”。

  

  

![](../Images/6bed9334e6d37bee1a14dcb81afc1e6a.png)

参赛教官们都非常认真，赛前都精心准备和训练了数月，到了赛场，比赛前也都还在连夜训练。

![](../Images/564f2ec8d722bbcd36ec3b0fb70764e8.png)

  

![](../Images/e9bd13e64846d941d2e391f0aabcfbd6.png)

警务技能比赛教学，有枪械使用、棍盾应用、暴恐处置、现场抓捕、拦截盘查等各种内容。

![](../Images/10fbe68aed19eba0ca266ae0fecfb550.png)

  

![](../Images/ba822b1850d88c83ef963397ff91169c.png)

  

  

![](../Images/6bca9e914e156eb3124bcec36e2504b6.png)

![](../Images/7a0bbd0cf2a25ee8ce89284da24bf274.png)

理论教官48人分别以《理想信念与警察精神培育》、《保密教育级公民信息保护》、《警务实战安全理念》、《刑事执法中常见问题及解决思路》、《涉警舆情与媒体应对》、《突发事件处置中的群众工作》、《行政执法中的常见问题解析》、《常见警情处置与现场执法规范》、《公安信息化技战法》等课题为内容进行讲授。  

![](../Images/a384a99ff2c3a389ab6ff3bd42b0f530.png)

![](../Images/23de80a827cde909f121683008a27a28.png)

![](../Images/5dbdc1e6b1854c29f09fcb7df7621abf.png)

四川省公安机关通过定期的教学比武选拔教学人才，补充到“战训合一”常态化教学训练中，不断加强教学队伍，提升教学训练的效果，为提升全省民警执勤执法素质奠定了坚实的基础。
