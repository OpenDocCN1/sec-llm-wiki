# 【工具】一个可以将人脸平面图像转换成3D图像的网站

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MTE0NTE3Mw==&mid=2651106021&idx=1&sn=258f8cf7fabd3b343833d2195d6c3b15&chksm=f1aedddfc6d954c9060595ba910c91148d657ea7c55b1665782a7df49f753ca36a86b2b797b5&scene=126&sessionid=1681267563#rd](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651106021&idx=1&sn=258f8cf7fabd3b343833d2195d6c3b15&chksm=f1aedddfc6d954c9060595ba910c91148d657ea7c55b1665782a7df49f753ca36a86b2b797b5&scene=126&sessionid=1681267563#rd)

     一群来自诺丁汉大学和金斯顿大学的人工智能专家使用机器学习创建了一个可以将平面人脸图像转换为3 d图像的方法。

　　

![](../Images/47b6d03860bf85a6e68eeb9437b1dcd1.png)

　　研究人员通过输入大量的人脸数据来训练卷积神经网络学习重建被遮挡的那部分脸的模样。

![](../Images/965a75e656205557dfc888e7b757453a.png)

     这个3D计算机视觉项目由Aaron S. Jackson，Adrian Bulat，Vasileios Argyriou和Georgios Tzimiropoulos组成的团队成员研发， 他们将于下个月在威尼斯国际计算机视觉大会上展示研究成果。

  

  他们还创建了一个网站供人们来试用他们是新技术。

网站网址：http://www.cs.nott.ac.uk/~psxasj/3dme/index.php

![](../Images/9086bfd2fee3ffefc6f6862beb56cd00.png)

  

  

在该网站上传人像图片后，即可获得相关图片的3d图片
