# 【工具】不用告诉他人电话号码也能让他联系上你

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MTE0NTE3Mw==&mid=2651105725&idx=1&sn=dd7a2d08fb1584e33836e5e1bcc9af3d&chksm=f1aede87c6d957911463471aaa552621714add965272d68132f9c56ae592c2755ecb8f51fc86&scene=126&sessionid=1681267578#rd](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651105725&idx=1&sn=dd7a2d08fb1584e33836e5e1bcc9af3d&chksm=f1aede87c6d957911463471aaa552621714add965272d68132f9c56ae592c2755ecb8f51fc86&scene=126&sessionid=1681267578#rd)

现代社会中，我们经常需要和陌生人联系，但又不想让他们知道自己的电话号码，该怎么办呢？  

  

比如，我的汽车因为临时需要停车，可能会影响其他车子的移动。平时我们就是放一张有自己的电话号码的卡片或者纸张在车窗前，方便其他车主联系自己。但这确实也会暴露自己的电话号码，可能被别有用心的坏人利用。

  

有需求，就有市场。这不，微信小程序里就有了一款专门方便上述移车时使用的小程序------移车通知。

![](../Images/89c3810f49055656f37ccb83a2b570d7.png)

使用该小程序生成一个移车二维码，打印出来贴在可能需要移车的车窗上，其他车主需要请车主移车时，只需要扫描二维码就可以联系上车主。双方的电话不会因联系而泄露。

  

使用方法比较简单：

一、进入小程序

在微信底部菜单栏的发现，进入小程序，在顶部搜索菜单栏搜索“移车通知”，就可找到该小程序。

  

二、生成移车码                                                                                         

![](../Images/f09afdb9bdc112c08eb67cbfd78755d0.png)

三、分享保存移车二维码，并打印后贴在车窗上

![](../Images/df89ddd8e3571f0f633ec6a4092202ad.png)

四、需要移车的人扫描，拍照，证明车子确实需要移动，车主收到通知来移车。

  

![](../Images/9fb252e6a8571182264a9ce06e1c726b.png)

当然这个工具不仅仅是可以用来移车了，其他需要隐藏自己电话号码，但用需要联系的情况都可以借鉴使用。
