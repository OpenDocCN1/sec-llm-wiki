# 【资讯】又有三家中国背景公司获得美国加州自动驾驶路测牌照

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MTE0NTE3Mw==&mid=2651105565&idx=1&sn=4223acc4853a86338937fd4d2bf446e8&chksm=f1aede27c6d957313697d793cd8e51667fa46d303559658f277689952122756910889d5da1f1&scene=126&sessionid=1681267583#rd](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651105565&idx=1&sn=4223acc4853a86338937fd4d2bf446e8&chksm=f1aede27c6d957313697d793cd8e51667fa46d303559658f277689952122756910889d5da1f1&scene=126&sessionid=1681267583#rd)

受到国内政策法规的限制，很多自动驾驶技术公司会选择让测试车在国外先跑起来，以便验证完善自动驾驶软件算法。近日，美国加州车辆管理局通过了三家具有中国背景的技术公司的自动驾驶汽车路测牌照申请，这三家公司分别是景驰、图森和小马智行。意味着这三家公司获得了在加州真实道路环境路测的入场券。

![](../Images/7c1ea9ae5a1f59906aab4444a8254d4d.png)

  

**拿证条件：先交500万美元押金**  

加州车管局的自动驾驶许可对在美国的自动驾驶公司来说，是一个“硬指标”，主流车厂与入局自动驾驶的大型科技公司都拿到了许可。这一许可意味着，其自动驾驶车辆可以合法上路测试，同时这也是技术实力的体现。  
加州对自动驾驶测试公司的考核不包括技术实力，只关注技术资质和安全保障能力，申请公司在测试前需要缴纳500万美金的保证金。这笔钱用来证明测试中发生事故伤亡时，测试公司是有能力进行责任赔偿的。

一、**景驰**

http://jingchi.ai/

![](../Images/b8a02959c8b727eb7cf3e5f44bb09ede.png)

**景驰:使用激光雷达 目标L4级自动驾驶**

景驰由前百度高级副总裁、自动驾驶事业部总经理王劲创办，目前从纰漏的信息看景驰的创始团队实力不容小视，除CEO的王劲，CTO韩旭此前担任百度自动驾驶事业部首席科学家、CFO此前担任知名激光雷达制造商Velodyne公司CFO。  
在自动驾驶技术路线上，景驰倾向于延续王劲和韩旭身在百度时的L4级别--景驰流传出来的自动驾驶测试车顶着Velodyne家64线的激光雷达，而非单纯依靠摄像头方案实现低级别的自动驾驶。  
今年4月，景驰就已经获得了来自洪泰基金、联创投资、启明创投等千万美金以上的融资，随着加州自动驾驶路测牌照的获批，景驰的自动驾驶研发之路将开始加速。虽然公司注册地选在了美国，但景驰官网上明确指出：“我们致力于自动驾驶技术在中国的落地。”

二、**图森**

http://www.tusimple.com/

![](../Images/3eac93dc12a4e27198b90be2d8245939.png)

**图森未来:无人驾驶唯一业务是卡车 乘用车只用于测试**

北京图森未来科技有限公司(以下简称图森)由来自加州理工学院、香港科技大学、卡耐基梅隆大学、南洋理工大学及清华、北大、上交、复旦的学术派团队和来自丰田、通用等公司的研究人员创办的自动驾驶技术公司。CEO陈默是一位连续创业者；CTO侯晓迪是加州理工博士，负责计算机视觉算法的研发；首席科学家王乃岩是香港科技大学博士，负责深度学习算法的研发业务。

在加州图森将会使用小型乘用车进行路测，但只限于感知、定位、决策规划等方面，图森希望能通过测试结果对算法方案进行优化，最终应用到卡车的自动驾驶解决方案上。  
图森的自动驾驶硬件解决方案采用了毫米波雷达、摄像头及来自英伟达的Drive PX2自动驾驶芯。这种路线现阶段与大多数车企采用的技术路线基本一致。  
在图森的商业逻辑里，他们只提供驾驶行为的运营服务，不做硬件，只提供算法。其服务对象为第三方承运人、自有车辆运输商、工商企业自营运输车队。图森向服务对象按所减少的  
按照陈默的说法随着加州路测牌照的获批，2018年将会进行自动驾驶汽车测试，而正式商业化的时间定在了2019年。驾驶员成本百分比收取服务费。  
有意思的是这家公司曾明确表示卡车将是自己在无人驾驶方案上的唯一业务，乘用车将只被用于测试，不会考虑将其商业化。

三、**小马智行**

https://www.pony.ai/

![](../Images/883e9f97e0f3de7e463a3082d5344a64.png)

小马智行的CEO楼天城此前在王劲的招揽下加入百度自动驾驶研发团队，成为百度最年轻的T10工程师。很快他便与王劲招来的另一位传奇技术人才James Peng从百度离职创业。加上另外三位百度系技术人才，五个人的创业公司成立伊始便拿到了来自红杉、IDG等近亿美元的融资。

  

**硅谷华人无人车创业潮正兴起**

事实上，华人正在撑起硅谷自动驾驶创业的半壁江山，获准在加州展开无人车路测的公司已经达到33家，具备中国背景的公司包括百度、上汽等已经达到10家。而这份名单上的国外大玩家还包括：大众、奔驰、Waymo(谷歌)、特斯拉、博世、通用、宝马、福特、英伟达以及前不久刚获得许可的苹果。这里或许反应出一个趋势，在自动驾驶领域的发展势头上中国已经开始奋起直追了。
