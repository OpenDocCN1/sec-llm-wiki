# 【工具】你想知道谁还没有看你发的微信群通知吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MTE0NTE3Mw==&mid=2651105291&idx=1&sn=3465e02657df113292aafa43bc35e7ff&chksm=f1aedf31c6d95627f79236a835b1254fe8b44a56596866a970e7a550c995657617f52d4daaa5&scene=126&sessionid=1681267609#rd](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651105291&idx=1&sn=3465e02657df113292aafa43bc35e7ff&chksm=f1aedf31c6d95627f79236a835b1254fe8b44a56596866a970e7a550c995657617f52d4daaa5&scene=126&sessionid=1681267609#rd)

现在大家的微信里都有各种各样的微信群：工作群、兴趣群、运动群、亲友群、同学群、战友群-----------

  

经常也会通过微信群发布各种活动通知，可是我们并无法确定哪些群友收到了通知，哪些群友还没有查看通知。

  

或者有些群友明明看见了通知，他却说没有看见，让群主很是为难。想要惩罚他，让他给大家发个红包都没有依据。

  

不过，今天丁爸有好消息要告诉大家了，我发现两个微信小程序可以让你看看微信群友里哪些人查看了你在群里发的通知，这也是不是可以让你的通知无遗漏的传达到每一名群友啊？

  

一、智公告

在微信发现栏的小程序搜索框输入“智公告”可搜到该小程序

也可长按下图使用该小程序

![](../Images/ed2b74540f570ca8cfa207a35096d72f.png)

  

进入小程序后点击底部“+”号可添加新的群通知，并可要求手工确认已阅读！！！

![](../Images/9a12cf5a9cbd3b265ec156282ede4278.png)

![](../Images/21d285cf0b27d807ea8d692f4752c384.png)

发布后分享到相关的群里，大家就可以看见相关通知了：

![](../Images/5a3c8d55b74986c9602ba0d7f9ca014b.png)

发布者可查看谁阅读了该通知：

![](../Images/90522ce269ad43305735f62367ab2798.png)

二、群里有事

在微信发现栏的小程序搜索栏输入“群里有事”可找到该小程序。

进入后点击底部右下角的“+”号，可选择发布通知或者发布活动

![](../Images/516129e593f1acd0995eba1e9413fcf7.png)

  

  

![](../Images/cc41b4239bdd43484c342b520296a65f.png)

![](../Images/1a0389cf6a7f4522d3827a80220015a9.png)

  

生成的通知或者活动可分享到相关的微信群：  

![](../Images/280e0c78d07561c8722429ef49c71509.png)

![](../Images/4d2db3c9eae7993fa701614f2be4f59d.png)

微信服务通知会提醒哪些人浏览了通知，进入相关通知还可看见具体哪些群友阅读了通知或者报名参加了活动。
