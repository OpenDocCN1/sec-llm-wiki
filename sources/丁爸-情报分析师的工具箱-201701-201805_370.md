# 【工具】一个查看手机位置的方法和工具

今天给大家推荐一个利用即时通讯软件“陌陌”查看手机位置的方法和工具。

  

具体步骤

一、查看手机号码是否注册陌陌

1、将该号码存到手机通讯录，如果不是你认识的，随便存一个名字都可以，用完删除。

2、打开陌陌，进入底部菜单栏最右边的“更多”菜单

  

![](../Images/56e605f0bfcbd5aa0c3850f6fc8c2180.png)

  

3、进入后可看见“好友”菜单，点击底部“查看通讯录好友”菜单

  

![](../Images/482d4b5b183148bb275b14229806844c.png)

4、如果你要查看的号码开通了陌陌，在此可以看见其陌陌名称以及和你的大概距离。

![](../Images/bf75d10a9486eea3b50ecfdea0997394.png)

5、点击你要查看的陌陌用户，可看见其陌陌详细资料，包括陌陌号、注册日期、家乡、星座、职业、学校、个人签名等等。

这里我们需要复制其“陌陌号”

![](../Images/159160165b92d848f34ffdd8a24a00c7.png)

二、利用一个手机app定位该号码的位置

1、打开该app，将需要定位的陌陌号码粘贴到搜索栏，选择“开始定位”

![](../Images/4e8c7314fd83916ff29b0656d84b469d.png)

2、地图上就可看见相关号码的位置

![](../Images/a420f18d5f3e2e55fdf19b670360db7b.png)

![](../Images/21eab753a14d79a40555d0c43cac28da.png)

3、该软件分为静态定位和动态定位，静态反应的是该号码最后一次发布动态的位置，动态定位就相对要及时一些。  

  

想要获取软件名称和下载地址，可警网通联系：101865

  

![](../Images/4f2957bce4ccbf3ac3ec1c68cd866929.png)
