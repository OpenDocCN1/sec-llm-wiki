银行卡归属查询分为『单个查询』和『批量查询』，点击查询框上方切换。单个查询时，当输入前6位银行卡号码时就会自动快捷判断银行卡归属，输全银行卡号码后会计算判断卡号是否正确，帮助避免输入错误。

  

在『批量查询』中，每行输入一个银行卡号进行查询，系统会自动忽略空格、标点符号等非数字元素，所以基本上将大块的银行卡号直接粘贴进去就能查询。同时，『批量查询』还支持对结果进行导出，导出的结果可以直接在 Excel 里打开分析，值得一提的是，导出的计算全部在客户端进行，不会和服务器通信，所以导出是即时的。

  

![](../Images/c3ed87adee8df19b7f1a90e2bdd7f087.png)

  

警戒区的IP数据来源于 「IPIP.net」和「纯真 」。

  

除了 IP 归属地信息，在警戒区 IP 查询工具中还提供了 IP 类型数据。在侦查工作中判断 IP 类型是 IP 分析的一项重要内容。目前主要的 IP 类型有：

  

*   **数据中心**，此类 IP 为互联网数据中心机房所用；
    
*   **专用出口**，此类 IP 是中大型机构使用的固定IP互联网接入专线，部分时候可能为移动网络专用出口；
    
*   **普通宽带** ，此类 IP 是普通家庭或企业、单位使用的宽带 IP；
    
*   **移动宽带**，此类 IP 地址是移动上网 2G/3G/4G 使用的IP；
    
*   **骨干节点**，此类 IP 地址属于运营商路由器节点IP。
    

  

IP 类型由计算机识别判断，作为辅助参考。实际使用中，如果一个 IP 被判断为普通宽带，且归属地信息可以精确到县级区域，基本可以确认为普通宽带 IP 。
