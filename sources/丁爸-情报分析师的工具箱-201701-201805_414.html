2017年4月7日凌晨，由位于波斯湾的“乔治·H·W·布什”号航空母舰的舰长管理的，隶属美国第6舰队的阿利·伯克级导弹驱逐舰“波特”号与“罗斯”号在地中海，发射出的59枚导弹（本来有60枚，其中一枚出现故障），空袭叙利亚霍姆斯省的谢拉特（Shayrat）空军基地。

发射一小时后，导弹几乎同时击中目标，摧毁了叙利亚空军基地的油库以及约20架停放在飞机库里和跑道上的飞机。

美国总统特朗普表示，这次对叙利亚的打击是“出于国家利益的考虑……”

不知美国在叙利亚有什么重要的国家利益

美国国防部声明称，叙政府军此前从沙伊拉特军用机场发动一起化武袭击，美军对其实施打击是为了阻止叙政府再次使用化学武器。


本月4日，叙利亚伊德利卜省遭到了飞机空袭，随后有毒气在受袭击区域蔓延开来，已导致数十人死亡。伊德利卜省的大部分地区被叙利亚反对派控制，事件发生后，叙利亚政府军否认了曾使用化学武器，而俄罗斯方面则表示没有发动空袭。

从叙利亚战场态势来看，形势比较有利于受俄罗斯支持的阿萨德政府军。因此从理论上来看，政府军不具有使用化武的动机。

当然，美国也从来就是特别会找理由修理人的。

前天美国驻联合国代表拿出一张照片，表示这次针对平民的化学攻击是由叙利亚政府发动的。所以美国才会发起对叙利亚的正义打击。结果，玻利维亚驻联合国代表突然暴起发难，在会上展示了一张照片，指出在2003年，前美国国务卿鲍威尔手持一管疑似洗衣粉的粉末，就在演讲中确定伊拉克拥有化学武器。而最后美国并没有在伊拉克找到任何化学武器。


下面我们再来刨刨这次发射战斧巡航导弹的两艘驱逐舰。

美国的这两艘战舰都是阿利·伯克级导弹驱逐舰，一艘“波特”号（编号：USS Porter，DDG-78）一艘“罗斯”号（编号：USS Ross，DDG-71）


百度词条可知：

阿利·伯克级驱逐舰（英语：Arleigh Burke Class Destroyer，一般简称为伯克级驱逐舰，英语：Burke Class Destroyer）是美国海军隶下唯一一型现役驱逐舰，为美国海军主力。


分为Flight Ⅰ/ⅠA（21艘）Flight Ⅱ（7艘）Flight ⅡA（34艘）等多种构型，现役共计62艘，仍在建造，使得伯克级至今仍为世界上最新锐，最先进，战斗力最为全面的驱逐舰，也是世界上建造数量最多的现役驱逐舰。



FlightⅠA巴里号DDG-52

伯克级首舰伯克号为Flight 1，伯克号的建造工作于1985预算年度执行，二号舰巴里号（USS Barry DDG-52）1987预算年度开始执行，并进行了简单修改，称为Flight 1A，编号从USS Barry DDG-52至USS Barry DDG-71。


“罗斯”号（编号：USS Ross，DDG-71）是最后建造的一艘Flight 1A，1997年6月28日入役。

“罗斯”号上装有MK-41垂直导弹八联装发射器十二组，舰身前部安装四组，后方安装八组，载弹量为90枚；

其中前、后各有一组八联装发射器中相邻三管的空间被用来安装一具再装填用起重机。但是MK-41的海上再装填起重机只能装填标准SM-2导弹，不能填装更重的战斧导弹。也就是说，“罗斯”号上的战斧导弹只能在出海前就填装好，战舰自身的起重机是无法装填的。


“波特”号（编号：USS Porter，DDG-78）是Flight Ⅱ型中的最后一艘(共7艘)。与I型舰相比，该舰除大幅度改进了电子系统外。除了装备MK-41垂直导弹八联装发射器十二组外，还装备了新型的“标准”sM 2ER型舰对空导弹。

但是“波特”号依旧无法依靠自身的起重机填装战斧巡航导弹。



战斧对陆型巡航导弹是美国舰载对陆作战的主要进攻武器，而“波特”号和“罗斯”号阿利·伯克级驱逐舰在“乔治·H·W·布什”号航母战斗群主要是一防空为主，因此正常情况下需要携带48枚“标准”防空导弹，因此90个导弹发射筒还剩42个，除了留给ESSM“海麻雀”的20个发射筒以外，还需要携带至少6枚“阿斯洛克”反潜导弹，即使不考虑携带“鱼叉”型反舰导弹，能留给“战斧”式巡航导弹的垂直发射筒也只不过剩下了14个。


而且"波特”号和“罗斯”号都不能依靠自身的起重机填装战斧巡航导弹，这些导弹必须在从母港出发前就装载好。


而"波特”号和“罗斯”号驱逐舰离开港口已经好几个月了，可见在离开港口前，已经将战斧巡航导弹填装好了。这对于侧重于航母战斗群防空护航的护卫舰来说是很不正常的事。反过来说，这两艘战舰早就领受了将对地面目标进行攻击的战斗计划。


所以美国打击叙利亚的军事基地是早有预谋，化武只是一个理由，或许这个理由还是他故意制造的。

而美国选择两国元首会晤期间动武，就是早有预谋了。今天，美军航母又在向朝鲜开去，不知美军又要搞什么名堂了。

美国第三舰队8日发布声明说，该舰队下属的“卡尔·文森”航母战斗群当天离开新加坡，改变原定驶往澳大利亚的任务计划，转而北上，前往西太平洋朝鲜半岛附近水域展开行动。
