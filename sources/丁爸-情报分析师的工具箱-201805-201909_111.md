# 英国国家犯罪情报局概况

为了实现信息资源共享, 加强地区之间以及中央与地方之间的情报沟通, 协调彼此之间的行动, 有效地打击犯罪, 上世纪九十年代初, 英国在内政部专门设立了国家犯罪情报局。2004 年, 该局并入新组建的“国家打击有组织犯罪局”。   

![](../Images/b7098cd968b6157de6987c74a9fe396c.png)

国家犯罪情报局官网：https://nationalcrimeagency.gov.uk/

  

作为情报主管部门,该局在英格兰、 威尔士、 苏格兰、 北爱尔兰地区都设有办事机构, 经费直接由中央政府拨款, 其任务是负责犯罪情报的收集、 分析和评估工作, 研究犯罪的发展趋势, 对各地警察局起指导作用,在各地警察部和合作单位之间实现资源共享, 确保国家犯罪情报服务的高效率与高品质, 保证中央与地方、 各地警察局对犯罪特别是有组织犯罪的协同作战。 

![](../Images/4a561d68757fa663d4c347551d9a0c03.png)

他们的情报信息主要来源于: 锁定 目标进行窃听 ; 发展线人收集情报 ; 从各地警察部门收集情报 ; 从非警察部门, 如海关、 移民、金融等部门收集情信息等。 

  

同时, 他们还从国外执法部门收集情报。足球流氓的个人情况也被他们收人信息库,遇有重 大赛事可采取限制性措施, 由警察部门收缴护照, 防止其进人赛事所在国家滋事。 

  

情报信息收集之后, 他们大体将情报分为战略情报和战术情报两类。

  

国家犯罪情报局通过采取多种手段广泛收集信息, 并将信息分门别类, 进行汇总, 建立信息库, 实现信息共享, 建立 中央与地方之间、 各地警察部门之间畅通、 灵敏的情报共享系统。 

  

如对有组织犯罪活动的情报信息进行汇总、 分析得出结论, 判断被调查的有组织犯罪究竟是属于跨国犯罪、 跨地区犯罪还是本地犯罪, 然后统筹协调, 确定管辖机构, 由其负责查处或者协调查处。通过引人这种模式, 警察行动更有方向性、 目的性, 大大降低了成本,避免了资源浪费。

  

![](../Images/973eb425137c61eca596d8275c09a9d3.png)

英国警察官网：https://www.police.uk/

英国各地警察局也积极响应犯罪情报模式的要求。 在打击各类犯罪中广泛运用犯罪情报模式, 利用情报信息更好、 更准确地预防和打击犯罪。 现在基本上每个警察局都设有专门的情报机构, 人员编制大约占警察局人数的3一5 %。
