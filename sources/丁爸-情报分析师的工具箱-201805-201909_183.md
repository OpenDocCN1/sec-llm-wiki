# 【情报机构】英国情报机构简介

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MTE0NTE3Mw==&mid=2651111862&idx=1&sn=02bb3f636577405bb87993a9670de98e&chksm=f1aeb68cc6d93f9a4c17a3704942babc72bdea56cd79e4f2bc569bc40e71b6dfc7581f9dc967&scene=126&sessionid=1681267335#rd](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651111862&idx=1&sn=02bb3f636577405bb87993a9670de98e&chksm=f1aeb68cc6d93f9a4c17a3704942babc72bdea56cd79e4f2bc569bc40e71b6dfc7581f9dc967&scene=126&sessionid=1681267335#rd)

英国政府拥有着若干不同的对内和对外情报机构。这些机构负责收集和制作外国和国内情报，提供军事情报，从事间谍活动和反间谍活动。他们的情报评估有助于促进英国的对外关系，维护英国的国家安全，辅助军事行动和执法行动。

其三个主要机构是秘密情报局（MI6），安全局（MI5）和政府通讯总部（GCHQ）。

1、安全局（MI5）由联合情报委员会（JIC）领导，负责英国境内的反恐和反间谍情报工作，旨在保护英国议会、民主和经济利益。

**比如：**1971年,MI5成功破获英国境内一个120名苏联情报人员的间谍网，英国因此驱逐了105名苏联外交官员。

安全局官网地址：https://www.mi5.gov.uk/

![](../Images/29b5058b08a80cc904e4d31e01aadc60.png)

  

英国伦敦米尔班克的泰晤士大厦设有MI5总部，这里还有联合恐怖主义分析中心等其下属组织。

![](../Images/c48fbf7774d035aecf4dceec5d637bca.png)

2、秘密情报局（SIS），俗称MI6，是英国政府对外情报局，专门从事外国情报收集工作，主要任务是通过隐秘的人力情报（HUMINT）进行海外情报收集和分析以支持英国的国家安全。

SIS的优先任务是反恐，反扩散，提供网络安全的情报支持，支持海外稳定以破坏恐怖主义和其他犯罪活动。

SIS的官网地址：https://www.sis.gov.uk/

![](../Images/7945a3c3964ef92fd2468eedc2f0777e.png)

SIS的总部位于伦敦南西部威斯敏斯特大桥路靠近滑铁卢车站的SIS大楼。

![](../Images/886f646d7b3b062225332c0a15d7ec7c.png)

3、政府通信总部（GCHQ）是负责为英国政府与军队提供情报和安全信号（SIGINT）以及信息安全保障的机构。

GCHQ有两个主要组成部分，即负责收集信息的综合信号组织（CSO）和国家网络安全中心（NCSC）。

GCHQ官网地址：https://www.gchq.gov.uk/

![](../Images/8826f0739d930296412f4513e70983ff.png)

  

4、国防情报 （DI）是英国情报界的一个组织，专注于收集和分析军事情报。它不是一个独立的组织，而是国防部（MoD）不可分割的一部分。该组织雇用了民事和军事人员，其经费在英国国防预算范围内开支。

国防情报局局长（CDI）接受国防部长（CDS）和常任副局长（PUS）关于MOD的情报需求的指示，并从内阁办公室联合情报委员会（JIC）获得国家指导。

英国政府官网关于国防情报的网页：  

https://www.gov.uk/government/groups/defence-intelligence

 

![](../Images/3b7167f9551e0beb398a604ce19c978a.png)

国防情报位于剑桥郡皇家空军威尔顿探路者大厦

![](../Images/08bc20b6d4117f3fdba272db1a201ac4.png)  

5、安全和反恐办公室（OSCT）创建于2007年，负责与警方和安全部门密切合作领导英国的反恐工作。该办公室向内政大臣和安全与反恐国务大臣报告。现任总干事是Tom Hurd，他是负责打击恐怖主义和有组织犯罪战略的高级政府官员。  

英国政府官网关于安全和反恐办公室的网页：

https://www.gov.uk/crime-justice-and-law/counter-terrorism

![](../Images/24986190b135c56b64ff168db70cebec.png)

  

6、国家犯罪局（NCA）是英国国家执法机构。它是英国打击有组织犯罪的牵头机构; 同时可以负责调查人口，武器和毒品贩运; 网络犯罪; 跨越区域和国际边界的经济犯罪等任何犯罪。NCA在分析整个英国的情况，分析犯罪分子的运作方式以及他们如何被打击的战略中扮演着重要角色。为此，它与区域有组织犯罪单位（ROCU），严重欺诈办公室以及各个警察部队密切合作。

NCA官网：http://www.nationalcrimeagency.gov.uk/

![](../Images/cf192ad41a58a86676b6549127e119e1.png)

 7、国家极端主义和骚乱情报部门（NDEDIU）是伦敦大都会警察局专家行动小组内的一个警察单位。该部门于2004年在威尔士和英格兰的首席警察协会下成立。其目的是直接打击国内极端主义，包括极端主义驱动的恐怖主义行为。  

 

8、国家弹道情报局（NBIS），是英国专门管理，并提供与枪支有关犯罪的详细信息的情报部门。该机构旨在利用其数据库存储有关涉及枪支的警方案件的弹道信息，并因此将其保存以供将来使用和参考。该服务设有四个设施，用于测试和分析枪支证据，以帮助将其与其他案件联系起来。其在伯明翰，伦敦和曼彻斯特等地设有办事处。

NBIS官网：http://www.nabis.police.uk/

![](../Images/5c0cb2bc2fa4e61b0dd72f1405f81fad.png)

9、国家欺诈情报局（NFIB）是英国负责有关欺诈和财务动机的网络犯罪情报收集和分析的警察部门。

https://www.cityoflondon.police.uk/advice-and-support/fraud-and-economic-crime/nfib/Pages/default.aspx

![](../Images/2b8efd7f411572ccc915afc6b2106210.png)

10、联合情报组织（JIO）是英国负责情报评估英国情报界的分析和发展能力的情报机构。主要职能是评估当前关注的情况和问题，警告对英国利益的威胁以及确定和监测面临不稳定风险的国家。

JIO评估人员由来自各个部门和学科的情报分析员组成，他们利用一系列情报，主要来自英国情报机构，还有外交报道和开源材料。

JIO的负责人也是情报分析的专业负责人，并就分析师培训和招聘分析师，职业结构和交流机会方面的差距提出建议，以提高英国情报界的分析能力。

情报分析专业主管还为所有英国情报界、情报分析员开展分析方法和培训。

英国政府官网关于联合情报组织的网页：

https://www.gov.uk/government/groups/joint-intelligence-organisation

这些机构的历史最早可以追溯到19世纪。1917年对齐默尔曼电报的解密被描述为第一次世界大战期间英国最重要的情报胜利，也是信号情报影响世界事件的最早时期之一。

 

1873年负责管理英国陆军的战争办公室于成立了情报处，成为军事情报局。1882年成立了对外情报委员会，1887年其演变成海军情报署（NID），1902年成立帝国防务委员会，负责军事战略问题的研究和一些协调。

 

1909年，为控制英国和海外的秘密情报行动，特别是德国的活动，在海军部和战争办公室的联合倡议下成立特勤局。该局分为海军和军队部门，随着时间的推移，他们分别专门从事外国间谍活动和内部反间谍活动。1916年，在第一次世界大战期间，这两个部分进行了行政改变，成为军事情报部门第5部分（MI5）和军事情报部门第6部分（MI6），分别演变成现在安全局和秘密情报局。

 

1919年，内阁的特勤局委员会建议建立一个和平时期的破译机构。工作人员从陆军信号情报机构NID25和海军的信息情报机构MI1b合并成立GC＆CS，1946年6月更名为“政府通讯总部”（GCHQ）。

 

作为帝国防务委员会的一个小组委员会，联合情报委员会成立于1936年。在第二次世界大战期间，它成为英国政府的高级情报评估机构。

 

联合情报委员会于1957年移交内阁办公室，其评估人员为委员会准备情报评估进行审议。

 

1946年，联合情报局（JIB）成立。JIB分为一系列部门：采购（JIB 1），地理（JIB 2和JIB3），防御，港口和海滩（JIB 4），机场（JIB 5），关键点（JIB 6） ，石油（JIB 7）和电信（JIB 8）。

 

1964年成立国防部时，联合情报局，海军情报局，军事情报局和空中情报局合并组成了国防情报人员（DIS）。DIS主要关注冷战问题。

 

1989年《安全服务法》和1994年《情报服务法案》颁布后，安全局（MI5）、GCHQ和秘密情报局（MI6）获得法定地位。

 

2009年，国防情报人员（DIS）更名为国防情报局（DI）。

 

2013年成立国家犯罪局（NCA），对严重有组织犯罪的情报进行收集和分析。其前身是严重有组织犯罪局（2006-2013），国家刑事情报局（1992-2006）和国家毒品情报股（1970年代至1992年）。

 

内政部管辖有四个国内情报单位：

1、国内极端主义和骚乱情报机构（NDEDIU），其历史可追溯到2004年，并自2011年以来被伦敦警察厅托管；

2、国家安全和反恐办公室（OSCT），创建于2007年，负责领导反恐工作并与警察和安全部门密切合作; 

3、国家弹道情报局（NBIS），于2008年创建的; 

4、国家欺诈情报局（NFIB），由伦敦市警察局于2010年成立。

 

在第二次世界大战期间和之后，许多观察家认为无线信息收集和密码破解对第二次世界大战的同盟国具有极大的价值。在战后时期，英国和美国之间的情报合作构建了两国的“特殊关系 ”并成为西方情报收集的基石。
