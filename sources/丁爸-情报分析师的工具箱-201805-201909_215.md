# SC-FEGAN：使用用户的草图和颜色进行面部编辑生成对抗网络

2019年2月18日，韩国学者Youngjoo Jo和Jongyoul Park在康奈尔大学的学术刊物arxiv.org上发表了利用草图和颜色进行面部编辑的人工智能图像编辑合成方法。

![](../Images/8cd7e1e5ae37869c283e58beb11322a9.png)

Jongyoul Park目前在韩国视觉智能研究组，电子和电信研究所工作。Jongyoul从事视觉智能，计算机，人机交互和计算机安全方面的研究。他们目前的项目是“DeepView”。

  

他们提出了一种新颖的图像编辑系统，可以在用户提供自由形式的蒙版，草图和颜色作为输入时生成图像。他们的系统包括端到端可训练的卷积网络。与现有方法相反，他们的系统完全利用具有颜色和形状的自由形式用户输入。这允许系统响应用户的草图和颜色输入，使用它作为生成图像的指南。他们训练网络具有额外的风格损失，尽管在图像的大部分被移除的情况下依然可以生成逼真的结果。 他们提出的网络架构SC-FEGAN非常适合使用直观的用户输入生成高质量的合成图像。
