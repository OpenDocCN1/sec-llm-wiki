Eclipse Foundation创建于2004年1月，是一家独立的非营利性公司，是Eclipse社区的管家。创建独立的非营利性公司是为了在Eclipse周围建立供应商中立，开放和透明的社区。

  

Eclipse Foundation为个人和组织提供成熟的，可扩展且业务友好的，用于开源软件协作和创新的全球社区环境。该基金会是Eclipse IDE，Jakarta EE和350多个开源项目、工具和框架的所在地，广泛适用于技术领域，如物联网，汽车，地理空间，系统工程等等。

  

## 其中**Eclipse BIRT**是一种开源解决方案，用于在基于Java和Java EE的Web应用程序中创建和嵌入报表和数据可视化。

![](../Images/bb9f7a2959199fbc44ac7f231887695e.png)

Eclipse BIRT是一个基于Eclipse的开源报告系统，它与您的Java / Java EE应用程序集成，以生成引人注目的报告。

  

该项目是Eclipse IDE 2018-12，Eclipse Photon，Eclipse Oxygen，Neon，Mars，Luna，Kepler，Juno，Indigo，Helios，Galileo，Ganymede，Europa和Callisto的一部分。

  

Eclipse BIRT下载地址：

https://download.eclipse.org/birt/downloads/

![](../Images/d3f3cd747ad1f0b497ce17e09e959a33.png)

  

BIRT可以创建一系列报告，从文本文档到交叉标签到标准饼图和条形图。除了这些BI基础知识，BIRT还可以处理稍微更高级的任务，“例如对总和进行分组，总计百分比等等。”

BIRT还可以嵌入到一系列其他应用程序中，因此它可以与您已经使用的商业软件集成。BIRT报告引擎和图表引擎可以轻松地与使用Java的应用程序和程序集成。

但请注意，您需要知道代码的人才能真正使用该程序。如果您对诸如“条件格式化”或“脚本数据集”等术语感到头疼，那么您可能会陷入困境。
