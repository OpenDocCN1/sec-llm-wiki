# 【会议】全国首届治理新型网络犯罪技术大会即将召开！快点击报名！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MTE0NTE3Mw==&mid=2651110386&idx=1&sn=858eeeb50023186daa51ebd8dc240fe4&chksm=f1aeccc8c6d945deea448e843f31dc0d6f77a8bd6ab746a44bc81d0aa55f484ac9cb2dc60271&scene=126&sessionid=1681267391#rd](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651110386&idx=1&sn=858eeeb50023186daa51ebd8dc240fe4&chksm=f1aeccc8c6d945deea448e843f31dc0d6f77a8bd6ab746a44bc81d0aa55f484ac9cb2dc60271&scene=126&sessionid=1681267391#rd)

原创： 点击阅读原文报名 终结诈骗 3天前

  

众所周知，以电信网络诈骗、网络传销、黑灰产业为代表的新型网络犯罪，严重损害人民群众的利益。这类犯罪具有明显的技术特征，已形成一条条完善的黑灰产业链，无数人或被骗倾家荡产，或陷入传销妻离子散，或在不知不觉中资金受到损失，衍生了不少社会问题，已成为各地治理的难题。

  

为真正破解这一难题，让战斗在一线的公安民警能第一时间了解犯罪技术最新发展趋势以及新型犯罪的侦查思路，**广州市警察协会**与**深圳安巽科技有限公司**特联合举办**全国首届治理新型网络犯罪技术大会**，诚邀全国公安民警参与。  

![](../Images/0e1f2e38f9c170bb382ae0bb84755567.png)

  

**终结诈骗（微信ID：antifraud2）**公众号作为此次大会的特别支持媒体，受权发布此次大会基本信息与报名注意事项。

  

  

一、基本情况

  

大会秉承“技术分享、实战分析”的原则，邀请公安部、部分省市公安机关及全国知名网络公司、安全公司从事一线实战的专家和技术大拿，讲解新型网络犯罪的治理理念、反制技术、 打击思路、 防范举措。不但聚焦侦查破案，还聚焦技术原理的讲解，聚焦宣传防范的开展，以及综合治理的理念与实践。  

大会的口号是：紧贴实战，只讲干货，拒绝忽悠，不做广告。争取让每一个参会的民警不负此行。

![](../Images/80e9c6be59f2028b671e058e1624e9d5.png)
