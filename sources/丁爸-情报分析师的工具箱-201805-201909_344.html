Exif可交换图像文件格式（Exchangeable image file format），是专门为数码相机的照片设定的，可以记录数码照片的属性信息和拍摄数据。


Exif可以附加于JPEG、TIFF、RIFF等文件之中，为其增加有关数码相机拍摄信息的内容和索引图或图像处理软件的版本信息。


Windows 7操作系统具备对Exif的原生支持，通过鼠标右键点击图片打开菜单，点击属性并切换到详细信息标签下即可直接查看Exif信息。

我们也可以利用Exif信息查看软件和Exif查看网站来查看图片的Exif信息。


不同设备拍摄的照片其包含的Exif信息类型有所不同，另外照片在传输过程中往往会被压缩，有可能会丢失部分或者全部Exif信息。比如通过微信传递图片，若不是传原图，就会丢失全部Exif信息。


不过还是有很多途径我们可以获取原图或者包含部分Exif信息的图片，因此在情报分析中也可以利用Exif信息开展相应的分析研判。
