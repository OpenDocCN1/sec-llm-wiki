图形数据库，是一个数据库，使用图形结构进行语义查询，其中包含节点，边和属性来表示和存储数据。通过设计，可以通过图形数据库简单快速的检索复杂的、难以建模的关系层次结构。


以分析社交网络里好友的动态为例，如果用传统的数据库设计，就会有用户表、用户好友动态表、用户好友点赞表等一系列的表，然后把这些表关联起来进行查询，效率极低。


而如果用图数据库来存储，就可以把刚才所有的表纳入到一张图里面，通过图来解决所有的问题。从形式上来说图数据库更接近于人类思维方式和现实世界万事万物的关联性。


1、百度安全开源大规模图数据库HugeGraph

HugeGraph已经在GitHub上实现开源，并包含数据导入、可视化的IDE、命令行、RESTFul API、Client等一系列工具集。


HugeGraph体系下包含了十多个关联子项目，具体包括HugeGraph 、HugeGraph-Client、HugeGraph-Loader、HugeGraph-Studio等。

HugeGraph在github项目地址：https://github.com/hugegraph/hugegraph




HugeGraph是一个快速，高度可扩展的图形数据库。由于其出色的OLTP能力，可以轻松地将数十亿个顶点和边缘存储到HugeGraph中并进行查询。由于符合Apache TinkerPop 3框架，可以通过Gremlin（一种功能强大的图形遍历语言）完成各种复杂的图形查询。


Apache TinkerPop：https://tinkerpop.apache.org/




Gremlin：https://tinkerpop.apache.org/gremlin.html

据悉，百度安全大规模开源的图数据库HugeGraph，已经助力业务协助公安机关破获多起电信诈骗、伪基站、流量劫持、用户隐私窃取等重大黑产案件，HugeGraph为公安机关提供了打击溯源的核心能力，全方位实现从警务数据整合到分析挖掘。


2、janusgraph分布式图数据库

JanusGraph是一个可扩展的图形数据库，专门用于存储和查询包含分布在多机群集中的数千亿个顶点和边缘的图形。JanusGraph是一个事务数据库，可以支持数千个并发用户实时执行复杂的图遍历。

janusgraph官网：http://janusgraph.org/

github项目地址：https://github.com/JanusGraph/janusgraph/

3、orientdb

通过利用多个数据模型并集成多个系统，OrientDB优化了图形数据。该平台结合了空间感知和图形数据，使应用程序能够利用图形数据库速度和许多现代用例的事务数据。

官网地址：https://orientdb.com/


图形数据库下载：https://orientdb.com/orientdb-enterprise/

4、neo4j

neo4j图形平台：https://neo4j.com/product/

Neo4j的图形平台经过专门优化，可以映射，分析，存储和遍历连接数据网络，以揭示隐形上下文和隐藏关系。通过直观地映射数据点和它们之间的连接，Neo4j为智能的实时应用程序提供支持，解决当今最棘手的挑战，

包括：

人工智能（AI）和机器学习

物联网（IoT）

实时建议和个性化

主数据管理（MDM）

欺诈识别

网络和IT运营

身份和访问管理


5、Amazon Neptune 

中文地址：https://aws.amazon.com/cn/neptune/

Amazon Neptune 是一项快速、可靠且完全托管的图形数据库服务，可帮助您轻松构建和运行适用于高度互连数据集的应用程序。Amazon Neptune 的核心是专门构建的高性能图形数据库引擎，它进行了优化以存储数十亿个关系并将图形查询延迟降低到毫秒级。Amazon Neptune 支持常见的图形模型 Property Graph 和 W3C RDF 及其关联的查询语言 Apache TinkerPop Gremlin 和 SPARQL，从而使您能够轻松构建查询以有效地导航高度互连数据集。Neptune 支持图形使用案例，如建议引擎、欺诈检测、知识图谱、药物开发和网络安全。
