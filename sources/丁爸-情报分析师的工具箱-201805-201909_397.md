# 【通知】关于举办警务人员网络信息安全工程师研修班（3期）的通知

各有关单位：

为贯彻落实党的十九大精神和习近平总书记在网络安全和信息化工作座谈会上重要讲话的要求，执行中央政法委关于推进建设智慧警务的指示，根据《中华人民共和国网络安全法》，结合警务信息化建设实战需求，我校信息与软件工程学院特举行警务人员网络信息安全工程师研修班。现将有关事项通知如下：

一、   主办单位

工信部教育与考试中心NSACE项目组

电子科技大学信息与软件工程学院

二、   承办单位

电子科技大学信息与软件工程学院

成都数之星科技有限公司

三、   培训对象

全国政法系统各专业警务领域的技术骨干、业务骨干、管理人员等。

四、   培训内容

本次研修班将按照理论、技术、案例和应用的递进层次，对网络信息安全专业知识和业务实践进行讲解，具体课题如下：

| 课程阶段 || 初级班 || 中级班 |
| --- | --- | --- |
| 基础理论 || 信息安全基础 |
| 网络空间安全技术体系 |
| 技术讲解 || 网络轨迹侦查 |
| 网络情报获取与侦测 |
| 案例分析 || 警务大数据应用 |
| 人工智能在公共安全行业的应用和发展 |
| 实践应用 ||   
 || 网络安全测试在业务中的思路与应用 |
| 网络安全测试实战案例 |
| 网络空间电子取证 |
| 考核 || 网络信息安全员职业技术考核 || 网络信息安全工程师职业技术考核 |

研修班另为每位中级班学员提供：情报收集与分析、网络安全测试等专业工具优盘。

五、   资格认定

所有完训的学员，授予《电子科技大学结业证书》；初级班考核合格者，授予工信部《网络信息安全员》职业技术证书；中级班考核合格者，授予工信部《网络信息安全工程师》职业技术证书。（证书样式见附件）

六、   培训时间及地点

暂定2018年9月下旬到10月中旬期间，适应大部分学员工作日程，择日开班，培训为期一周以内。具体日期将后续通知。

| 培训班类型 || 初级班 || 中级班 |
| --- | --- | --- |
| 报到时间 || 开班前夕周日下午 |
| 培训时间 || 周一至周四上午（含考核） || 周一至周五（含考核） |
| 培训地点 || 成都·电子科技大学沙河校区 |

       七、   培训费用

| 培训班类型 || 初级班 || 中级班 |
| --- | --- | --- |
| 培训费用（元/人） || 5200 || 6700 |
| 工信部证书 || 网络信息安全员 || 网络信息安全工程师 |

培训费用包含午餐和材料费等。

培训期间住宿由学员自行安排，费用自理。研修班可协助联系酒店。

八、   报名和缴费流程

1、预报名：学员填写报名表（见附件）并回复至微信工作号kyoukdash，确认报名资格（请选择初级班或中级班）；

2、报名成功后，研修班向学员出具正式邀请函。

3、培训费用于学员报到时现场缴纳（刷卡或转账）。

九、   自带材料

1、中级班学员，请携带互联网笔记本电脑（用于网络安全测试环境部署）

2、本人有效警官证和身份证（与报名信息一致）

3、邀请函

4、证书照片：1寸蓝底免冠警服照四张，以及相应的电子照片（387.5px×312.5px，72像素，JPEG格式）

十、   研修纪律

学员在研修期间，须遵守部委和各单位管理规定及电子科大校园管理规定，妥善保管培训资料及相关软件，遵守相关保密规定。如违反管理规定或遗失保密材料，责任自负。
