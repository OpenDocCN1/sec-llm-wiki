# 【案例】 亮亮视野智能警务眼镜再立新功

CCTV-13《新闻直播间》报道四川警方

佩戴高科技AR眼镜捕获逃犯

亮亮视野智能警务眼镜助力安防事业。

![](../Images/aa895759587d2f0ad32167dc7334b16e.png)

5月22日晚8点半，一辆面包车驶入雅安市荥经县查缉点。

  

“请摇下车窗。”在临近夜晚的昏暗时分，佩戴AR智能眼镜的缉毒警察望向车内，对乘客进行逐一排查。当缉毒警察看向后排的一名乘客时，鼻梁上的AR智能眼镜发出报警提示：此人系在逃人员，曾参与盗窃抢劫，比中率达98.04%。

  

在民警详细的盘查后发现，这名在逃人员在沿海一带犯案并冒用其弟弟的身份证，在逃回老家凉山途中被四川缉毒民警抓获。 “他（在逃人员）和他兄弟的身份证几乎一模一样，加上天色昏暗，凭借肉眼极难分辨，多亏了高科技的帮助！”民警感叹。

  

这是“5·14” 堵源截流毒品查缉行动现场的一幕。本次行动5月17日至23日在雅安市荥经县开展，9支查缉队伍近百人参加。在这次缉毒行动中，缉毒民警鼻梁上架起的这部AR智能眼镜，便是由亮亮视野研发的智能眼镜。在此之前，亮亮视野智能警务眼镜就已经配合公安战警破获诸多案件，这次在四川雅安又为公安战警再立新功。

 

亮亮视野智能警务眼镜

![](../Images/aa895759587d2f0ad32167dc7334b16e.png)

**AR智能眼镜亮相毒品缉查行动**

在“5·14”四川雅安堵源截流毒品查缉行动中，缉毒民警佩戴的就是亮亮视野智能警务眼镜。在行动过程中，缉毒干警通过智能警务眼镜的人像对比功能，实时识别出犯罪分子的身份信息，后方连接到警务数据库，实现实时信息回传。亮亮视野智能眼镜搭载了自主研发的能够适配主流训练框架的神经网络推理框架，在已有英特尔AI芯片的极限计算速度上又提升了2.25倍，人脸识别率达到99.5%。

  

“车内乘客的信息第一时间就能显示出来，是不是有前科人员、是不是在逃人员，提高了我们的查缉效率。“缉查干警表示道。

  

![](../Images/508dee5dbb67684d8a2fa6d0f02eed56.png)![](../Images/aa895759587d2f0ad32167dc7334b16e.png)

**AR智能眼镜-安在第一视角 防于第一时间**

![](../Images/2404eda4ca118e5bc269cfd8df447419.png)

  

为提高公安部门的快速反应能力，亮亮视野基于第一视角交互，推出了一整套移动警务解决方案。民警在执勤时配戴亮亮视野警务智能眼镜，可以实现移动智能识别、移动监控巡查和远程调度指挥等工作。

 

**移动智能识别**  警用智能眼镜可实时人脸识别、车牌识别、人证比对，实时得出结果。

 

**移动监控巡查**  通过警用智能眼镜，现场民警可对接公安部门的数字视频管控平台，实现常规巡查实时记录，归档调阅。在遭遇突发情况时还可进行第一视角直播。

 

**远程指挥调度**  指挥人员还可远程调度一线民警。现场民警可通过智能眼镜实现前后方信息共享，彼此配合。
