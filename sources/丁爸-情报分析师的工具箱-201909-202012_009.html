今天给大家推荐一些境外API、SDK、开放源码、被黑的数据库等工具网站。

1、国外网络API接口

官网地址：https://www.programmableweb.com/category/all/apis

有超过23818个各类API接口，比如google、facebook、telegram、YouTube、维基百科、Bing Maps、Amazon Web Services、LinkedIn、Instagram、OpenStreetMap、Yahoo Map Image 等等。



2、SDK目录

官网地址：https://www.programmableweb.com/category/all/sdk?order=created&sort=desc

包含近两万个SDK，比如：Python Wikitools、PHP LinkedIn SDK、Bing Maps Java SDK等等。

3、源代码目录

官网地址：https://www.programmableweb.com/category/all/sample-source-code?order=created&sort=desc

比如：地图制作工具、NOAA地图、适用于Microsoft Excel的MapMaker、Flickr Api资源管理器、Google Maps hack和书签、Amazon Web Services代码示例、PHP5中的Yahoo术语提取、Phoogle地图、基于Lypp VoIP API的VoIP Ruby on Rails插件、如何使用Java和JSP页面编写YouTube代码的示例、Twitter的壳、使用Perl编写Twitter脚本、Twitter API的HTML包装器、Google Chart API的ASP.NET实现等等


4、DeHashed

数据挖掘和被黑的数据库搜索引擎（提供免费和付费选项）。

官网地址：https://dehashed.com/

5、谷歌黑客数据库

可通过关键词搜索相关黑客数据

官网地址：https://www.exploit-db.com/google-hacking-database
