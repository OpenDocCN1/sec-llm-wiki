【摘要】

自互联网和社交媒体出现以来，新的情报分支如网络情报(CyberIntelligence)、开源情报(Open Source Intelligence)和社交媒体情报(Social Media Intelligence)蓬勃发展，目的是利用虚拟世界的不同维度。这些与情报有关的学科可以查询自愿在网站或社交平台上张贴的个人信息、声明和谈话，以便对人进行介绍，确定社交网络和组织结构，并发现可能危及个人或组织安全的漏洞和威胁/风险。在这方面，因特网作为环境可以从技术和社会方面提供宝贵的信息。这就是为什么因特网现在是并将继续是搜索可被处理成情报的数据和信息的重要场所，也是人们为什么在敏感领域（如：情报部门应了解他们的脆弱性以及这一环境构成的风险和威胁。

关键词:网络情报, 开源情报, 社交媒体，社会工程


1. 导言

正如历史所显示的，随着社会趋势和技术的发展，情报收集不断演变和适应。社会和技术这两个因素关系密切，我们可以提到社交媒体的情况，个人或专业存在/活动可能成为个人社会行为的一部分。


随着WEB 2. 0、社交媒体和情报技术的出现，塑造现代情报的最重要因素无疑是技术。


Web 2. 0带来了一种新的信息传播方式，因为社交媒体允许Web从数据和应用迁移到用户交互和经验，这意味着现代万维网不限制互联网用户只阅读数据或信息，还允许他们在不同的平台上分享他们的想法，意见、个人资料等等。


随着信息收集和分析的新机会的出现，所有这些数据共享自由都伴随着个人和组织安全的巨大风险。


得益于Web2. 0开发的主要情报或竞争情报相关分支是网络情报、开源情报和社会工程，后者是从情报收集角度分析的，不被视为网络空间的犯罪活动。


2. 社交媒体中的网络情报——情报采集的技术手段

网络情报是一门获取、处理、分析和传播信息的学科，这些信息识别、跟踪和预测网络领域的威胁、风险和机会随着网络维度成为公共空间，从技术和社会角度看作为各种活动的扩展或现实复制品，网络情报可能与信号情报、人力情报传统情报收集学科重叠。


通常网络操作有三种主要形式：计算机网络防御、计算机网络攻击和计算机网络开发，我们将计算机视为任何可以连接到其他设备或云和网络的设备——Intemet。


从这一技术角度看，个人和社交平台设备最常见的脆弱性由软件或硬件设计中的漏洞表示。对于任何设备，在生命周期的某个时刻，随着技术的发展，可能出现安全漏洞。


设备可以发送信息或可以被扫描以获得可用于情报处理的数据。促进数据收集的最重要因素是连通性和安全性差。这些可能揭示出每个设备都有的传感器处理的数据，正如我们在图1中看到的情报手机示例。

此外，互联网和社交平台的使用可能揭示关于用户的个人数据。通过生活在一个媒体饱和的社会世界中，我们留下了我们媒体使用的足迹，在我们的设备和平台上。这创建了两个信息收集活动可以关注的易受攻击的点：单个设备或提供服务的平台。


个人设备通常以最小的安全设置来设置(以便其用户舒适地访问)，这可能表示个人数据暴露以及外域实体进一步利用的风险。


对于社交平台，它们都在多个服务器上云中存储数据。用户提供的所有社交媒体数据和存储在服务器上的与使用有关的数据----私营公司的财产----都暴露在驻地国家规则之下，只要公司可以交换用户的数据以谋取利益，这些规则就可能用于财政收益。


大量容易在网上获得的数据及其成倍增长的数据量对开源情报处理是一个挑战，它

试图从旧的、过时的信息中分离有价值的数据，并忽视假新闻或其他不相关的内容。


在这方面，在互联网环境中收集情报（以及外部实体处理个人数据的相关风险）的最重要的机会可能是大数据分析。大数据分析以及对较小数据集的分析可以揭示关于实体、现象或过程的描述性、预测性和/或规定性见解，这种类型的分析可以使用由个人自愿共享的数据或由特定技术数据收集装置收集的数据，并且涉及具有范围广泛的数据类型(图像、视频、文本或活动模式)的大量数据。


现代系统处理能力的不断发展促进了大数据分析；相比之下，由于要处理的信息量大，几乎不可能由人类分析大数据。


开源情报收藏的一个重要机会在于能够揭示一个群体的社会情绪。这一点非常重要，因为与社会情绪有关的情报产品可能在战略层面为决策者提供优势(图2)；与此同时，目标组织或社区处于弱势地位。

3. WEB 2. 0中的开源情报

随着 Web 2. 0 的出现，我们可以注意到万维网上可用数据的指数式增长，以及公开（或者，在最佳情况下，以推断的保护方式）共享情报组织可能感兴趣的数据的社会趋势。


用数据暴露的另一个情报收集机会由制图平台表示。这种平台为用户提供了在地图上上传照片或评论的可能性，使得对目标区域的增强评估成为可能。


在Web2. 0的出现中，一种关于映射的特殊方法谈到了社会映射作为任何空间局部化信息的建模、可视化和图形表示的方法，目的是获得关于所代表的现象的知识，显然，如果将收集的数据添加到地图中，则对于分析人员来说更有价值。这样，作为信息处理的结果，标记在地图上的社会或安全相关方面提供了更高的理解环境和支持远景分析。意识到社交平台为大数据分析提供的机会，我们可以期望以影响个人感知、动机或行为为目标的操纵行为。


最重要的是。因此，通过利用人为错误，社会工程可以用于从组织/私有网络收集私有数据。


网络安全领域的研究人员警告说，除了关注技术发展之外，在打击网络威胁时，还应该考虑人的因素，我们的生活与技术密切相关，在使用计算机系统的组织中，安全链中最薄弱的环节往往是人。


从社会角度看，社会工程中使用的技术是说服，基于以下原则：互惠、一致、喜爱、社会证明、稀缺、权威。


社会工程师可能假装自己是重要的人，比如总部的大老板、政府机构的检查员、组织的顶尖顾客，或者可能攻击普通员工内心恐惧的人，通过这种技巧，他们使用了权威原则，试图通过恐吓人们来获得信息。


社会证明是一种心理现象，当人们无法确定适当的行为方式时，社会证明就会出现在社会情况中，这样，社会工程师就可以使用劝说技巧来创造一种受害者将以预期方式做某事的情况的适当形象。


社会工程师利用互惠、一致性、喜好或稀缺，从对这些自然原则敏感、拥有低水平安全文化的人们那里获得信息。所有这些原则反映了人们对于与某人接触的感觉，可以用非常复杂的方式说服某人遵循规定的行为。


社会工程攻击很可能发生在没有适当和明确的程序，或有监管漏洞的组织身上。如果对每种可能的情况都有精确的程序，而且组织的成员训练有素，遵守安全规则和尊重程序，那么试图利用人为错误的社会工程攻击就不大可能发生。


从技术角度看，我们可以根据环境(真实世界的模仿、网络环境中的钓鱼或视觉、诱饵、尾随等)和用来收集数据或信息的工具(用于链接分析、取证、欺骗、GPS跟踪等)来划分社会工程。


钓鱼是一种社会工程，它隐含着社会工程师在网络环境中作为一个值得信任的实体的身份。通过利用人们的贪婪或好奇心来点击获胜的横幅、打开链接或检查“丢失”内存USB的内容来进行保释。


尾随或背负代表社会工程师进入未经授权的区域的情况，该未经授权的区域与正在准许访问的授权人经过。从技术角度看，欺骗一般代表身份的伪装。黑客或社会工程师广泛使用欺骗来掩饰他们的身份或看起来是别人。

4. 社会工程

社会工程有技术和心理两个方面，后者是社会工程可以通过使用这些平台提供的通信手段与社交媒体中的情报数据收集重叠到一定点；这种方法开启了关于人力情报（HUMINT）在网络或网络-HUMINT操作中的进一步讨论，这些操作可以使用社会工程原则。


在社交媒体上互动时，从个人保护的角度看，要留存的是首先检查对方的真实身份，只需通过经过验证的通信手段(例如：（电话）或与你应该认识的人建立视频联系。高级方法（比如IP检查）可以进一步在这方面提供相关的见解。


5. 结论

Web 2. 0的开发为从多学科角度收集情报提供了新的机会，同时伴随着个人或组织数据暴露所带来的风险和脆弱性。由于Web 2. 0（也称为参与式或社交网络）的主要功能是在刚刚登录的平台上添加媒体，人们在网络环境中的作用越来越重要。


人们可以选择在社交媒体上分享什么，他们需要关注新的在线社会化，以避免敏感的数据披露。即使他们使用用户名和密码来限制对其数据的一般访问，社交媒体用户也应该假设平台上发布的每个数据都可以由感兴趣的实体访问。


现代互联网的社会方面使得网络空间的开发成为可能，不仅从技术角度出发，而且从社会角度出发；这为反智力和HUMINT等学科创造了发展机遇。


在社交媒体上反对收集情报的最重要方面是教育。如果人们知道网络环境中的安全问题，那么情报收集就会受到严重限制。


明确的组织过程是另一个可以反对情报收集活动的特征，特别是针对公司或政府机构的社会工程攻击。这意味着，一个组织的每个成员都知道该怎么办，他的责任是什么，并且不太可能犯错误，从而披露有价值或敏感的数据。


由于先进的技术收集和社会联系分析，人们应该明确区分个人和职业生活。如果打算用于工作的设备用于个人目的，或者反之亦然，那么重要数据可能不情愿地泄露。


另一方面，随着社交媒体和Intemet的不断发展，情报部门(以及经济竞争者，或轻型网络罪犯)往往总是寻找收集机会，寻找增强的方法和工具，从而带来新的风险和脆弱性，防止个人和组织的数据保护。
