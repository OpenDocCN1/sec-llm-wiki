# 【大数据分析】开源数据分析各省及全国暴力犯罪态势

今天利用裁判文书网（http://wenshu.court.gov.cn/）

和国家大数据网（https://data.stats.gov.cn/）

查询了2000年至今的刑事立案数量和2014年至今的刑事一审判决数据，分析暴力案件发案变化趋势，同时也可以分析一下各省市的暴力犯罪态势。

  

**一、基于国家统计数据分析近20年来暴力犯罪变化趋势（2000年至2018年）**

数据来源于国家大数据网（国家统计局数据），最新数据为2018年统计数据。

详细数据已上传小编的知识星球，可文末有二维码，可扫码识别前往下载。  

  

从杀人案件、抢劫案、伤害案在各年度案件立案总数中的占比来看，暴力案件呈现明显的下降趋势。命案和抢劫案在总发案数中的占比都非常低。故意伤害案件立案数量占比变化不大，但总体还是呈现下降趋势。  

  

盗窃案件在总立案数量中的占比一直变化不大，但近几年有较明显下降趋势。  

  

诈骗案件则呈现明显的上升趋势，在总立案数中的占比不断创新高。

**二、基于一审刑事判决文书数量分析各省市暴力犯罪指数**  

数据来源于中国裁判文书网，统计了2014年至2020年的数据。

因并非所有判决书都即时上传到中国裁判文书网，故本分析的结论也并不一定准确。

  

本分析通过裁判文书网的高级检索，分别检索了一审刑事判决涉及故意杀人故意伤害、寻衅滋事、聚众斗殴四类案件的判决书数量。并分析了各省相应判决书在总数中的占比，最后将四类案件占比相加后得出各省总的暴力犯罪指数。  

  

没想到裁判文书网上云南的故意杀人案件居然是最多的，其次就是四川，完全出乎意料。
