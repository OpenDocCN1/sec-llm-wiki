# 【资料】社交媒体情报改善人们生活的潜力

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MTE0NTE3Mw==&mid=2651117996&idx=1&sn=91ce18190ffb27f6142e18c4f29a5ad9&chksm=f1aeae96c6d92780f2dcb04f39821e252908c38c5d1c354e4525fc5ac959239711802a736074&scene=126&sessionid=1681267091#rd](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651117996&idx=1&sn=91ce18190ffb27f6142e18c4f29a5ad9&chksm=f1aeae96c6d92780f2dcb04f39821e252908c38c5d1c354e4525fc5ac959239711802a736074&scene=126&sessionid=1681267091#rd)

二十一世纪在许多方面都将是具有挑战性的。从气候变化造成的历史性灾难性自然灾害到不平等，再到难民和恐怖主义危机，显然我们不仅需要新的解决方案，而且需要新的洞察力和解决方案的方法。数据，以及通过数据科学的进步从数据中获得的情报，越来越多地被视为答案的一部分。这份报告探讨了这样一个前提，即数据-特别是社交媒体公司拥有的海量数据存储和独特的分析专业知识-可能确实提供了一种新型的情报，可以帮助开发应对当今挑战的解决方案。

  

这是一份与facebook公司支持下写的报告。数据是每天在Facebook上为人们提供价值的产品的核心。Facebook的数据、覆盖范围和研究工具还可以帮助企业、组织和政府做出更好的决策，改善生活。这份报告不仅捕捉到了数据和技术让世界变得更美好所取得的成功，还强调了数据和技术界必须解决的一些挑战，才能产生更大的影响。

  

这份报告重点介绍了一种从社交媒体数据中提取公共价值的方法：**数据协作**。

数据协作是公司伙伴关系的一种新兴形式，来自不同部门的行为者交换信息以创造新的公共价值。这种合作安排，例如社交媒体公司和人道主义组织或民间社会行为者之间的合作安排，可以被视为利用私人持有的数据实现公共目标的可能模板。

  

**数据协作的前景**  
现有的关于数据协作的研究很少，但最近的一些例子表明，社交媒体数据可以被用于公益。其中包括Facebook在自然灾害发生后与人道主义组织分享人口地图；通过社交媒体数据分析预测西班牙的药物不良反应；波士顿市政府使用Waze的众包数据来改善交通规划。报告全文讨论了这些例子和另外9个案例。通过评估这些示例，确定了将社交媒体数据用于公共目标背后的五个关键价值：

  

**1.态势感知与应对。**  
社交媒体公司持有的数据可以帮助非政府组织、人道主义组织和其他人更好地了解人口趋势、公众情绪和各种现象的地理分布。在这样做的过程中，数据有助于改进态势感知和响应。  
**案例研究：**  
*Facebook灾难地图。  
追踪东欧社交媒体网络中的反疫苗情绪。  
Facebook人口密度地图。*

**2.知识创造和转移**  
广泛分散的数据集可以组合和分析，以创造新的知识，在这个过程中，确保那些负责解决问题的人手头有最有用的信息。**案例研究：***  
Yelp数据集挑战。  
麻省理工学院社会机器电子组项目实验室。  
领英的经济图表研究计划。*

**3.公共服务设计和交付数据。**  
协作可以增加对以前无法访问的数据集的访问，从而实现对公共服务设计的更准确建模，并帮助以有针对性的、基于证据的方式指导服务交付。  
**案例研究：**  
*Facebook未来商业调查。  
利用WAZE交通数据缓解城市拥堵。  
Facebook对影响寨卡病毒的洞察。*

**4.预测和预报**  
通过访问社交媒体数据集实现的新预测能力可以帮助机构变得更加主动，建立基于可靠证据的机制，在问题发生之前缓解或避免危机。  
**案例研究：**  
*使用推文追踪流感。  
使用社交媒体元标签预测洪水。  
挖掘健康社交媒体流和论坛预测药物不良事件。*

**5.影响评估和评价。**  
访问社交媒体数据集可以帮助机构监控和评估政策的现实影响。这有助于设计更好的产品或服务，并实现迭代和持续改进的过程。  
**案例研究：**  
*体育英格兰的#ThisGirlCan。  
利用推特数据分析萨尔瓦多燃料补贴政策改革的民意。  
使用推特衡量全球对气候变化的参与度。
