# 【转载】贝鲁特港爆炸毁伤分析

2020年当地时间8月4日下午6时左右，黎巴嫩首都贝鲁特发生大规模爆炸，爆炸点位于贝鲁特港口12号库房，坐标为东经35˚31ˊ08˝，北纬33˚54ˊ05˝，据说为焊接火花引燃炸药，进而引起硝酸铵爆炸所致。这些硝酸铵是六年前黎巴嫩海关查获，并卸载在此，共2750吨。第一次爆炸为白色烟雾，**第二次爆炸产生形态完整的红色蘑菇云，高达600米，爆炸造成地面140米直径的大坑，毁伤半径约1000米，爆点附近6座大型建筑和12座大型库房被夷为平地，岸边大型集装箱发生严重位移。**贝鲁特总人口数量约为180万，目前至少137人死亡、约5000人受伤，30万人无家可归，经济损失高达100亿至150亿美元。 

![](../Images/194a1ff4511a651e9a5e146fe64cb0b3.png)爆炸毁伤半径

**一、基本情况**

贝鲁特为黎巴嫩首都，是地中海东岸最大的海港城市，有中东的巴黎之称，作为中东商业、交通、金融和文化中心，也是东西方的连结点和出入中东的大门。贝鲁特港是黎巴嫩重要的门户和货物集散地，10万吨级货轮可直接靠岸装卸货物。现有集装箱及集散货码头14个。2014年吞吐量为828万吨，承担着黎巴嫩70%的进出口货物运输量。港区面积120万平方米，水域面积100万平方米，拥有大小码头总长5655米，其中1654米是普通货物码头，水深8～10.5米；1334米是集装箱码头，水深10.5～13米，另有新完成扩建的16号集装箱码头，总长1100米，其中水深15.5米的码头600米，水深16.5米的码头500米。 

![](../Images/4415e7de7a38979b9180b490eaf1f815.png)贝鲁特港全貌

贝鲁特港区拥有12座仓库，总面积77444平方米，用于普通货物、汽车、重型机械和危险化学品专用等。此次爆炸的硝酸铵存放于12号库房，为长方形建筑，长136米，宽42米。 

![](../Images/f1cd5f76fccd61504e940239e4600067.png)贝鲁特港仓库分布图

从影像图可以看到，爆心形成“斗”形大坑，直径达140米，坑深在60米以上，散发着烟雾，海水倒灌覆盖地基。爆炸点北部紧靠岸边停靠的船只，被推离港口。爆点附近6座大型建筑和12座大型库房被夷为平地，岸边大型集装箱发生严重位移，车场车辆在冲击波作用下产生漂移、堆积。

**二、毁伤分析**

硝酸铵在常温下并不会自行燃烧，在耐撞击方面，硝酸铵也极其钝感。实验数据显示，50公斤的铁锤从50厘米的高度落在固体硝酸铵上，它的爆炸几率为0。而对比炸药硝酸甘油，200克的铁锤从20厘米的高度落下，就能100%被引爆。但当硝酸铵温度达到165℃左右，或者与明火接触，固体硝酸铵若在密闭空间内迅速分解，会引发爆炸。

此次爆炸的硝酸铵体量高达2750吨，其威力、毁伤的程度与核爆还是具有一定可比性的。经计算，2750吨硝酸铵能产生相当于1000吨TNT当量的威力，相当于美在广岛投掷的首枚原子弹“小男孩”当量的十五分之一；相当于2006年10月9日朝鲜核试验（相当于800吨TNT当量，造成3.6级的人工地震）的1.25倍；还相当于2015年我国天津港爆炸威力的3倍。从公开视频可以看到，此次事件第一次爆炸，产生大量白色烟雾，随后进一步引爆了2750吨的硝酸铵，形成了殉爆，产生红色蘑菇云，高度在600米左右，。此次爆炸和日本广岛核爆所产生的蘑菇云对比图如下。

![](../Images/bd55d9b11c87c799153b304bff30c5f3.png)贝鲁特港爆炸和广岛核爆蘑菇云对比图

**从爆炸机理与爆轰产物来讲，硝酸铵和核爆都产生冲击波超压、震动和飞散物，对周围的建筑和人员造成伤害。不同的是，相比于核爆，硝酸铵爆炸不产生放射性元素，不会对人体造成持续性的严重伤害。**硝酸铵爆炸主要生成氮气、水、氨气及氮氧化物等，氨气具有腥臭味，当浓度过高时，会对皮肤、眼睛及呼吸道产生刺激；氮氧化物也会对空气造成污染，影响人的神经系统。氮气和水是无毒无味，局部氮气过多会降低空气中氧气比例，也会对人的神经系统造成伤害。
