# 【技巧】28种推特（twitter)语法搜索技巧

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MTE0NTE3Mw==&mid=2651116503&idx=1&sn=49358a2661f84563cdd37c2febd5a218&chksm=f1aea4edc6d92dfbd40f4c7fac31f42b7a52a5ea61ce24d56fa71580de720645b86f6edcb75d&scene=126&sessionid=1681267142#rd](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651116503&idx=1&sn=49358a2661f84563cdd37c2febd5a218&chksm=f1aea4edc6d92dfbd40f4c7fac31f42b7a52a5ea61ce24d56fa71580de720645b86f6edcb75d&scene=126&sessionid=1681267142#rd)

推特是全球覆盖量巨大的社交媒体，很多人都在用，特朗普甚至使用推特来治理国家。因此大家经常会到推特上搜索一些需要的信息，今天小编给大家推荐28种提高搜索精准度利用语法搜索推特推文的方法。  

  

| 搜索栏输入内容  
 || 搜索运算 |
| --- | --- |
| 美国 新冠 肺炎  
 || 搜索结果同时包含“美国” “新冠” “肺炎”  
 |
| “特朗普病毒”  
 || 精确搜索包含短语“特朗普病毒”的推文 |
| 特朗普OR病毒 || 搜索结果包含其中一个或者两个词  
 |
| 特朗普-病毒  
 || 搜索结果包含”特朗普“但不包含”病毒“  
 |
| #病毒  
 || 搜索结果包含主题标签“病毒” |
| from:CIA  
 || 搜索从CIA发出的推文  
 |
| list:NASA/astronauts-in-space-now || 搜索从NASA/名单-in-space-now发出的推文 |
| to:NASA || 回复Twitter帐户“ NASA”的推文。 |
| @NASA || 提到Twitter帐户“ NASA”。 |

  

| 政治 filter:safe || 包含带有标记为“政治”的潜在敏感推文。 |
| --- | --- |
| 特朗普 filter:media || 包含“特朗普”的图片或视频。 |
| 特朗普 -filter:retweets || 包含“特朗普”，过滤掉转发 |
| 特朗普 -filter:retweets || 包含“特朗普”，过滤掉转发 |
| 特朗普 filter:native\_video || 包含“特朗普”和上传各类视频。 |
| 特朗普 filter:periscope || 包含“ 特朗普”和一个Periscope视频URL。 |
| 特朗普 filter:vine || 包含“特朗普”和vine。 |
| 特朗普 filter:images || 包含“特朗普”和标识为照片的链接，包括第三方（如Instagram）。 |
| 特朗普 filter:twimg || 包含“特朗普”和一个代表一张或多张照片的pic.twitter.com链接。 |
| 特朗普 filter:links || 包含“特朗普”并链接到URL。 |
| 特朗普 url:amazon || 包含“ 特朗普”和一个在其中任何位置带有单词“ amazon”的URL。 |

| 特朗普 since:2015-12-21 || 包含“特朗普”，自日期“ 2015-12-21”（年-月-日）发送。 |
| --- | --- |
| 特朗普 until:2015-12-21 || 包含“特朗普”并在日期“ 2015-12-21”之前发送。 |
| movie -scary :) || 包含“电影”，但不包含“scary”，并且态度积极。 |
| flight :( || 包含“flight”并持消极态度。 |
| traffic ? || 包含“traffic”并提出问题。 |

| "特朗普病毒" near:"san francisco" || 包含确切的短语“特朗普病毒”，并在“旧金山”附近发送 |
| --- | --- |
| near:NYC within:15mi || 在“ NYC”的15英里范围内发送 |
| news source:twitterfeed || 包含“news”并通过TwitterFeed输入 |
