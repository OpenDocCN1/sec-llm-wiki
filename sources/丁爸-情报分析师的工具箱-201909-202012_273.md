# 【情报实战】发论文说新型冠状病毒并非来自实验室的教授和美国马里兰州的生物研究基地有什么关系？

2020年3月17日，自然医学杂志上发表了一篇论文，认为2019新型冠状病毒

（HCoV-19，也称为SARS-COV-2 ）不是实验室构建物也不是有意操纵的病毒。论文的作者有五位：Kristian G. Andersen, Andrew Rambaut, W. Ian Lipkin, Edward C. Holmes， Robert F. Garry 。其中**克里斯蒂安·安德森（Kristian G.Andersen）**是本文第一作者。

  

![](../Images/068b9e88c5c8bcf88e4720cdf9e4b3b3.png)

![](../Images/5ef6cee4a86a1ff11473f3b20abfd520.png)

  

小编从第一作者**克里斯蒂安·安德森**的简历中发现其和因泄露而被关闭的美国马里兰州德特里克堡（Fort Detrick）有着紧密的联系。并且其在3月份晋升为教授并任命为西非新发传染病研究中心首席研究员。

# 而美国国家过敏和传染病研究所（NIH  NIAID）、国家先进转化科学中心（NIH NCATS）和国家普通医学科学研究所（NIH  NIGMS）都是美国国家卫生研究院（NIH）的下属机构。美国国家卫生研究院位于美国马里兰州贝塞斯达，是美国卫生与公众服务部（HHS）下属医学研究机构。

# 美国卫生与公众服务部（HHS）组织机构图

美国国家卫生研究院（NIH ）支持美国和国外的生物医学研究，其下属有27个研究机构。（相关机构名单及地址和联系电话在小编的知识星球里）

# 美国卫生与公众服务部（HHS）官网介绍到：国家过敏和传染病研究所（ NIAID）综合研究设施是国家跨机构生物防御园区（IRF）的一部分，该园区是一组位于马里兰州德特里克堡（Fort Detrick）的联邦生物医学研究设施。IRF由6个核心实验室组成：（1）临床核心，（2）解剖病理学，（3）细胞培养，（4）成像物理学，（5）比较医学和（6）航空生物学。IRF的科学家致力于开发与人类疾病直接相关的预防和治疗方案，无论这些方案是自然出现还是有意引入的。安全实验室内部的先进成像技术和其他最先进的功能使研究人员可以跟踪疾病过程。运营和活动包括实验室，废水处理厂以及储水，处理和分配。IRF大楼约为144,000平方英尺。
