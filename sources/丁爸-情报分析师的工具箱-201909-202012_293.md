# 开源情报（OSINT）的演变

本文介绍了两位欧洲实践者对开源情报的看法。

作者：Florian Schaurer和JanStörger

![](../Images/61b0da2f8b1707ba0c2acdd5648210c9.png)

**引言**

OSINT一词的定义是收集，处理，分析，生产，分类和传播源信息的信息，并应公众对国家官方安全要求的公开和合法获取和使用。本文讨论了OSINT作为情报学科的起源，认为OSINT应该被称为工匠，以及它对情报企业内部集成的所有源知识管理过程的贡献。

  

**OSINT的历史**

利用开放信息的历史可以追溯到情报的兴起，情报是支持政府决策和行动的工具。但是，这并不是有条不紊的推进，直到美国率先建立独立的监视外国媒体的能力的制度化和专业化，并建立了国外广播监视服务（FBMS），该服务源于普林斯顿大学的一项研究计划。在日本袭击珍珠港之后，FBMS迅速发展起来。1947年，它更名为外国广播情报服务（FBIS），并归入新成立的中央情报局。2005年，随着9/11袭击事件以及《情报改革和防止恐怖主义法》的通过，FBIS和其他研究要素一起被转变为国家情报局开源中心（OSC）的职责。自成立以来，OSINT一直致力于过滤，转录，翻译（从而解释）和存档来自所有类型的外国媒体来源的新闻项目和信息。

  

1939年，英国政府要求英国广播公司（BBC）推出民用的，后来的商业服务，其《外国广播摘要》（其摘要为《世界广播摘要》（SWB）和现在称为BBC监控。正如英国广播公司（BBC）于1940年出版的手册所言，其目的是建立“现代的通天塔，在那里，他们集中地倾听朋友和敌人的声音。” 到1943年中，BBC每天监控125万个广播单词。1947/48年，英国广播公司（BBC）与美国同行建立了正式的伙伴关系，并就全部交换产出达成协议。同样在1948年，美国国会图书馆的研究机构从航空研究部门中成立，以利用图书馆的大量藏品提供定制的研究和分析服务，现在称为联邦研究部（FRD）。

  

在冷战期间，铁幕两侧的国家都建立了开源收集能力，这些能力通常嵌入其秘密情报服务中。中情局分析师史蒂芬·梅卡多（Stephen Mercado）表示，开放源不仅“构成了所有情报的主要部分”，而且最终成为了有关对手的军事能力和政治意图的信息的“主要来源”，包括预警和威胁预测。例如，东德国家安全部（MfS，称为“ Stasi”）每月分析1000份西方杂志和100本书，同时每天还汇总100多家报纸和12个小时的西德广播和电视广播。

  

正如约瑟夫·奈（Joseph Nye）所说，在冷战期间，开源已经是一种行之有效的信息资源，通常是针对其他收集工作或“拼图的外围部分”的首选手段。互联网技术已公开可用信息对现代政治，社会和经济生活的各个方面都产生了巨大影响。但是，需要意识到，互联网本身不是来源（元数据除外），而是一种传输信息和虚拟位置的方法。

  

大多数情报机构对互联网的价值了解缓慢，其原因有两个：

（1）情报机构通过秘密处理秘密来寻求信息优势。依赖公开信息及其各自的版权限制与该想法背道而驰。

 （2）在大多数情况下，使用秘密方法来获取秘密资源更加困难，风险和昂贵，因此给人的印象是，这些秘密资源必须比开放资源具有更高的价值，从而使该方法与产品混淆或导致滥用知识保密性。

  

苏联解体后，西方情报机构将行动重心转移到新的地理和主题优先事项，例如非洲和亚洲，非国家行为者，远征环境中的低度冲突，政治和宗教恐怖主义，大规模武器扩散破坏（WMD）和计算机网络的漏洞，这导致对开源情报的更多重视。

  

美国军方在1980年代后期首次创造了OSINT一词，认为必须进行情报改革以应对信息需求的动态性质，尤其是在战场上的战术层面。1992年，《情报重组法》将信息收集的目标定义为“根据美国情报共同体（公共和非公共）可利用的所有来源，提供及时，客观的，没有偏见的情报。” 1994年，在CIA内部建立了社区开源计划办公室（COSPO）。1996年，美国情报共同体的角色和能力委员会（通常称为阿斯平·布朗委员会）得出结论：“还应该做出更大的努力，以利用现在可从开放源获得的大量信息。”北约为建立使用OSINT的框架而作出的平行努力导致出版了几本质量各异的手册，入门和实用手册。借助欧洲媒体监控器（EMM）和OSINT套件以及其他工具和项目，欧盟（EU）委员会的联合研究中心（JRC）正在开发自己的工具来应对日益增长的信息泛滥的挑战姿势。

  

9/11被证明是OSINT的分水岭，2004年美国遭受恐怖袭击国家委员会（9/11委员会）建议建立一个开源机构，而无需进一步评论或详细说明。这个概念是在2005年被采纳的，同时美国情报部门关于大规模毁灭性武器的情报能力委员会（WMD委员会）也提出了相应的建议，当时国家情报总监（DNI）成立了OSC，吸收了CIA的FBIS在国家技术信息服务（NTIS）的监督下与世界新闻连接（WNC）联系。OSC表示自己是“美国政府提供外国开源情报的主要提供者，并且通过不断扩大的开源领域，提供了超越普通媒体的有关外国政治，军事，经济和技术问题的信息。”同时，任命了开源情报国家情报（ADDNI / OS）的助理副局长，这提高了开源情报企业的知名度。随着专注于国土安全和执法问题的区域融合中心的发展，OSINT是将相关情报合并和整合为可操作产品的主要来源。

  

**OSINT和私营企业**

从经济角度讲，国家安全作为公共物品只能由政府或在国家监督下有效地提供。尽管OSINT具有很大的价值，但它不需要任何特殊权限。由于非国家承包商在交付OSINT的能力和资源方面可能更胜一筹，因此它们可以为更好地提供国家安全做出贡献。来自情报或公开使用但非法的手段的情报不应被视为OSINT，例如属于机密信息的机密信息或专有信息的泄漏。中央情报局（CIA）的风险投资公司In-Q-Tel对网络监控的预测分析工具Recorded Future的投资证明了中央情报局前局长迈克尔·海登（Michael Hayden）的说法：“秘密信息并不总是我们职业上的黄铜戒指。”

  

OSINT政府与私营部门建立伙伴关系的关键点是需要制定保密法规来保护国家安全。有时，必须对仅基于公开可用信息的情报产品进行分类，以保护政府的利益不被泄露。情报机构必须整合和控制外宣活动和承包商的工作，以防止危害运营和国家安全。与学术界的伙伴关系避免了国家与以利益为导向的参与者之间的潜在冲突。大学是获取公共领域内专业知识的沃土，可以成为情报机构的理想合作伙伴。

  

开源通常会提供大部分情报来源，这一事实使OSINT成为所有情报工作中必不可少的一部分。每个情报专业人员都应该了解OSINT的来源和方法，尤其是随着分析和收集越来越相互融合。但是，外展活动和开放源代码开发必须由专门的元素来支持，以确保分析师跟上新兴技术和市场的发展。专门的OSINT专家最有资格确定潜在的能力差距并评估承包商可在何处使用。例如，目前正在美国引入的OSINT认证计划是将私营部门的知识和技能整合到情报界的一个好方法。

  

**OSINT面临的挑战**

由于OSINT具有开放性，因此可以促进共享。但是，对于OSINT以及更具限制性的情报类别，需要改进共享手段。这种需求不仅存在于国家安全界，而且存在于负责国内安全和法律执行的人们。因此，必须建立纵向和横向一致的共享和保障体系。

  

公开对于政府的公信力以及向公众和国际盟友证明其决定的合理性很重要。但是，如果对手使用开源破坏国家的国家安全，就会存在一个固有的漏洞。OSINT可用于评估本国的脆弱性。

  

敌对国家还将出于欺骗目的操纵开源信息。但是，在当今世界上，随着大量信息的公开获取，这种欺骗性的计划变得更加困难。

  

尽管快速发展的信息技术是一个重要的挑战，但人为因素不应被低估。归根结底，总是依靠人类的专业知识才能在情报行业中发挥作用。因此，收集人员和分析人员都需要法律和实践培训，适当的素养和一流的技术能力（例如数据挖掘，网络分析和翻译解决方案），以将不同的原始OSINT数据放入上下文中并加以理解。随着新的基于Internet的媒体的出现，信息的种类，数量和速度成倍增加。今天的挑战不再是“连接点”，而是组织信息流，区分信号和噪声以及通过及时验证来源以支持政府决策者和战斗人员。
