在实际开源情报工作中，往往会因为目标的既得信息不足而无法进行深度挖掘。此时我们的既得信息一般有：“xxxxx@gmail.com”、“twitter账号@xxxxx”、“facebook账号@xxxxx”其中之一，常用做法是将“xxxxx”作为新的关键词进行搜索。相较于早期使用的userrecon工具，NExfil自动检查的网站超过350个，是Userrecon的四倍之多，且NExfil的安装和操作简单，适合新手开源情报爱好者。下面介绍该工具的安装和使用：**一、在windows系统下安装Ubuntu**

![](../Images/f3a97b996fde9d019ff8cdb98850ba64.png)

打开Microsoft Store，搜索“Ubuntu”，选择下载最新版本（目前为Ubuntu 20.04 LTS），然后安装即可。  
**二、在Ubuntu 20.04 LTS中安装NExfil**

```
git clone https://github.com/thewhiteh4t/nexfil.git
```

```
cd nexfil
```

```
pip3 install -r requirements.txt
```

**三、使用NExfil全网检查用户名**  
1.help命令：

```
python3 nexfil.py -h
```

2.指定单个用户名查找  

```
python3 nexfil.py -u 用户名
```

3.指定多个用户名查找

```
python3 nexfil.py -l " 用户名1, 用户名2 "
```

![](../Images/4f1664c743ad0098be04fbcf9274e253.png)

**四、一些小建议**  

1.  将每个工具命名为：“名字+功能”，方便以后使用。Ubuntu修改文件（夹）名称语法如下：
    
    **修改文件名：sudo mv  原名字  新名字**
    
    **修改文件夹名：sudo mv  原名字/  新名字/**
    
2.  在cd到工具内部之后，新建文件（夹），以使用的代码作为文件（夹）的名字，如“使用python3 nexfil.py -u”，并在该文件（夹）内部写入该工具help文件的详细内容，相关命令语句如下：
    
    **新建文件：touch 文件名**
    
    **新建文件夹：mkdir 文件夹名**
    
    **编辑文件：vi  文件名**
    
    **保存并退出编辑：“:wq” **
