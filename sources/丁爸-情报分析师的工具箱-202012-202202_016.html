网络计量分析师（Webometric Analyst ）是一个基于 Windows 的免费程序，用于 altmetrics、引文分析、社交网络分析和网络计量，包括链接分析。它通过 API 或直接下载从 Web 下载数据，并包括广泛的处理选项。该网站包含最流行功能的简要使用说明。

官网地址：http://lexiurl.wlv.ac.uk/


社交网络分析

  • 社交网络数据源：YouTube 、 Twitter 、Goodreads和Flickr。

  • 下载和计算推特图像或Tumblr 图像。下载谷歌图片搜索图片。


引文分析

教学大纲提及搜索、专利引用搜索、演示引用搜索、灰色文献搜索、网络引用和来自一般网络的 URL 引用搜索。


链接分析和网络计量

  • 一组单词、短语或文档中的每一个在网上被提及的次数的网络影响报告

  • 链接引用一个或多个网站或页面的网页和网站数量的影响报告 

  • 网站集合之间（引用）链接的网络图或Twitter 对话，或YouTube 评论者。

  • Web 环境单个网站的网络 

  • 谷歌自定义搜索注册。


Webometric Analyst 允许通过“YouTube API”从 YouTube 收集数据。它可以自动下载：

  • 与关键字、频道或标签搜索匹配的视频列表

  • 有关视频列表的信息

  • 用户列表频道统计

  • 对视频的评论

  • 视频评论回复的网络图

  • 它还可以将下载的评论导出到Mozdeh以进行关键字和时间序列分析。

要使用 YouTube 功能，(a)下载 Webometric Analyst， (b)注册 YouTube 项目并获取您的开发人员密钥（此密钥授予您 YouTube 运行自动搜索的权限）

单击屏幕左上角附近的 YouTube API 选项卡以显示主要的 YouTube 处理选项

该工具还可以用于必应、谷歌自定义搜索结果分析。

可以使用Webometric Analyst f或指定的用户列表从 Twitter 中提取关注/关注者列表。这些通常应该是您主题的关键角色。如果他们有超过 1000 个追随者/追随者，则该过程很慢，因为 Twitter 速率限制。无论如何，只能识别前 5000 个关注者/关注者。

方法

  1. 使用 Windows 记事本，创建一个包含用户名列表的纯文本文件，每行一个。

  2. 启动 Webometric Analyst 并单击 Twitter 选项卡。

  3. 单击列出 Twitter 关注/关注者按钮并选择 Twitter 用户名的纯文本文件并按照说明进行操作。您将被要求登录 Twitter 以获得许可。

  4. 等待程序完成。如果您的列表有很多用户，或者他们有很多朋友或关注者，那么这可能需要很长时间。

  5. 程序完成后，使用第二个Webometric Analyst按钮将列表转换为网络，从跟随/跟随连接文件创建网络。
