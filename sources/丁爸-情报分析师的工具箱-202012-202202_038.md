# 【情报官培训】竞争情报-摩托罗拉公司案例研究

在16世纪的30年里，富有的德国富格尔家族出版了一份简报，其中包含了他们在欧洲、非洲、亚洲和美洲的代理人提供的第一手信息，这些信息可能会影响到家族遥远的业务，包括商品价格、竞争对手活动、政治事件、街头犯罪和战争。这标志着竞争对手和市场情报在商业企业中用于支持决策的最早记录之一。

  

历史上充斥着工业间谍的故事，但竞争情报作为美国企业决策的公认学科和工具，要追溯到上世纪70年代初。美国石油、摄影、自行车、一次性纸尿裤、婴儿食品、电子产品等行业的巨头们收集、分析并采取行动，获取竞争对手的信息，以在瞬息变化的行业中获得市场优势。1980年，迈克尔·波特(Michael Porter)在一份被广泛视为现代竞争情报基础的出版物中引入了五因素分析，作为了解竞争对手和选择适当的竞争战略反应的一种手段。80年代中期，许多美国大公司——埃克森美孚、宝洁、阿博特、强生和摩托罗拉——都设立了正式的竞争情报机构，不仅为战术营销和产品开发决策提供支持，也为指导高级战略提供帮助。

  

竞争情报这一术语的广义定义是定义、收集、分析和分发有关产品、客户、竞争对手和环境因素的情报，这些情报是支持企业管理人员进行决策所必需的。对这一定义的进一步完善，可以在可追溯到上世纪80年代初的关于竞争情报技术的大量出版物中找到。特别是，已经发表了一些关于非法企业间谍活动和竞争情报之间区别的研究报告，并就如何合法和合乎道德地收集、分析和处理竞争对手的信息提出了广泛的指导方针。

  

正如摩托罗拉的案例研究所证明的那样，企业竞争情报组织的活力直接关系到它通过市场变化、组织结构和领导变化以及战略重新定向提供关键决策支持的能力。

  

**摩托罗拉竞争情报的26年演变**

摩托罗拉企业竞争情报 (CI) 小组于1983年由当时的首席执行官兼董事长鲍勃•加尔文创立，作为高级决策的重要组成部分，该小组在26年的时间里蓬勃发展，直到2009年底，摩托罗拉开始准备将其拆分为两家独立的公司，才被解散。纵观其传奇的历史，摩托罗拉企业竞争情报 (CI) 小组提供了一系列可靠的情报分析，包括竞争对手的行动、行业和市场发展以及技术趋势，并回应了数以千计的询问，这些都对影响这家数十亿美元的全球公司的发展和方向的决策提供了支持。

  

上世纪80年代，作为总统的外国情报顾问委员会(PFIAB)成员，鲍勃·加尔文观察到情报界在支持国家重大决策方面发挥的关键作用。他认识到情报人员是收集情报的专家。他们感觉到指标。他们准备估算并进行净估算，以及替代估算和评估。他立即看到了将这种能力导入摩托罗拉的价值。

  

在设计该组织时，高尔文坚持由一名前美国政府情报官员领导。他认为，即使是企业情报，最好也留给情报专业人士。他联系了在CIA工作了20年的前国家科技情报官员扬·赫林(Jan Herring)来领导这个组织。继1月之后，6名前CIA专业人员相继离职，这使摩托罗拉竞争情报 (CI) 小组有别于其他拥有企业情报职能的公司。这种与众不同的设计元素也给该小组在摩托罗拉内部带来了独特的光环，并立即提高了其在高度分散的公司文化中关键业务负责人的接受程度，他们对公司的举措持健康的怀疑态度。

  

情报组位于公司的高层，向公司战略主管报告，后者是首席执行官高级领导团队的一部分。在这个高级级别，该小组了解高级决策者不断变化的情报需求，确保其重点和报告永远不会与企业领导人的关键需求脱节。它也保证了集团是错综复杂的参与和积极贡献的战略规划周期的公司。纵观其历史，摩托罗拉的情报组一直处于这一高级职位，情报组的负责人是公司最高级战略规划团队的成员，为继任的CEO和众多的战略主管提供直接支持。

  

鲍勃·加尔文(Bob Galvin)还与摩托罗拉(Motorola)的高管公开支持该小组，让其成员“足够令人讨厌”地提出可靠的、经过调整的分析，尤其是在报告与主流观点相反的情况下。

  

**任务及表现评估**

新公司情报组的使命是提供相关的、可操作的和及时的战略情报。它的重点是“超越车头灯”，收集、分析并为摩托罗拉高管提供有关竞争对手的预期行动、技术发展、市场和行业趋势的见解。虽然情报组在其历史上一直保持小规模，在其鼎盛时期增长到10名成员，但它的预算每年根据5个关键绩效指标进行评估，这些指标在整个集团的历史中都保持不变:

•对业务决策影响的证据

•对竞争对手的行动进行早期预警

•识别、分析和建议新的增长机会

•对战略规划的影响和影响——短期和长期的

•全球市场的反情报和安全意识

  

此外，摩托罗拉的大部分业务都保留了自己的情报团队，专门为业务的特定产品、技术、销售和战略需求服务。企业情报机构将这些分散的小组编织在一起，提供援助和支持，有时在内部情报机构发现难以在问题上获得关注时提供外部确认。这个虚拟情报组织的成员共享线索，并在彼此的情报分析中充当独立的意见领袖。

  

**提供价值**

情报小组的价值不仅在于它能够收集并产生大量的信息,而且在其成员采取的技巧多源输入,寻求替代的观点,分析趋势和模式,并产生独立的分析,认为影响摩托罗拉和为行动提供了选项。如下图所示，团队将大量的时间和资源集中在这些高价值的活动上。情报出版物总是对读者提出“那又怎样”的问题，并提出行动方案，始终有意识地保持客观性。这种对关键决策者产品价值的认真关注，可能是情报组长寿的最重要因素。

![](../Images/f7401a088cf4ec56496d9486c88d0598.png)

  

为了实现对高价值活动的关注，团队成员成为紧跟公司战略转变的专家。他们学会了如何“及时”生成情报报告，以支持关键决策。他们非常熟悉公司的日程表，以及需要讨论的议程项目，特别是在战略规划会议上。他们主动地寻求对他们所提供的情报的坦诚反馈，并将这种反馈作为新的需求的基础。

  

相反，当情报小组的成员未能在关系层面上与决策者联系时，他们很快就发现自己与这些高管接收和处理情报信息的方式不一致。结果，他们错过了充分利用情报的机会。

  

在不断的预算限制下，团队学会了集中精力，并剔除那些“很好拥有”的信息请求。通过问关键问题，“你想要解决什么问题?”情报小组经常将请求者重新定向到现成的信息来源。其他时候，它可以让CI组找出真正的问题，从而确保他们的回答更准确。作为可能的智能项目引入的主题必须通过团队其他成员在生动的生产会议上进行的“so what”测试。通过这个不断调整优先顺序的过程，CI集团成功地将其出版物打上了分销名单上所有高管“现在必须阅读”的标签。

  

数据和线索从该集团不断增长的网络中源源不断地流入。对团队成员的评估包括情报的数量和质量，以及他们识别新网络成员的能力，这些新成员不仅能够提供领导和见解，而且能够提供公正和深思熟虑的反馈。这个网络由摩托罗拉的工程师组成，他们与行业协会和标准机构有着密切的联系;市场研究人员;贸易显示与会者;企业的销售主管和竞争情报专家;以及外部行业分析师、学术界和国际协会的技术专家。

  

情报小组与摩托罗拉的法律部门合作，建立了一套严格的道德准则，与竞争情报专业人员协会(SCIP)所拥护的道德准则密切一致这一准则反映了摩托罗拉强烈的道德文化。情报小组领导了整个公司以及整个SCIP社区的强制性道德培训。2000年，该集团还完成了为期一年的过程，为摩托罗拉创建并制度化了一个情报职业生涯管理系统。这个项目定义了情报专业人员的素质和功能特征，以便在职业阶梯上得到提升。这与大SCIP和美国政府情报机构共享。

  

**应对挑战**

情报小组仔细审视了自己在公司任何糟糕决策中的作用。在某些情况下，没有足够的、可靠的情报来抵消人们对某一特定决定的普遍情绪。在其他情况下，情报是充足的，但是情报集团的成员认为情报是已知的，并没有采取主动确保这些情报落入正确的人手中。有时，团队会选择“足够好”的答案，以确保被广泛接受。但在大多数被归因于情报失误的情况下，情报团队的成员只是缺乏信心或资历，无法挑战普遍的情绪，即使情报来源充足。

  

纵观其历史，摩托罗拉的企业情报小组遇到了许多政府情报机构面临的相同挑战:领导层的变化，战略方向的转变;从分散到集中再到集中的重组;以及恒定的预算压力。

  

随着需求的变化，团队的组成在这几年中发生了变化。随着摩托罗拉在全球的发展，团队成员加入了亚洲、拉丁美洲和欧洲。一个土生土长的韩国人有很强的分析能力提供大大大洞察新兴竞争对手三星和lg电器。为了了解90年代末电信行业金融市场和并购活动的影响，该团队招募了几名具有解释财务报表经验的成员。

**每位新上任的摩托罗拉高管都看到了摩托罗拉情报小组的不同潜力**

在20世纪90年代，该小组从最初关注“毫无意外”转向更广泛的技术和行业趋势分析。2000-02年，重点转移到了解相关行业的疯狂并购活动对摩托罗拉的影响。作为摩托罗拉核心战略团队的重要组成部分，情报小组提供市场和竞争对手分析，以支持时任首席执行官克里斯•加尔文(Chris Galvin)倡导的增长计划。从2006年开始，该集团反映了公司的分权趋势。与过去集中收集、分析和分发情报的角色相比，摩托罗拉的重心更多地转向在其分布广泛的商业情报机构中设计和分发情报项目。直到2009年，情报小组一直是公司内部分散情报团队的“粘合剂”。

  

**结论**

或许鲍勃·加尔文在1996年SCIP关于竞争情报的圆桌会议上最清楚地抓住了摩托罗拉企业情报的精髓:“一个情报部门可以被看作是一个专业的实体，它支持或激励人们，或者偶尔打出全垒打，或者大多数时候打出一些相当不错的短打，以帮助推进该机构更基本的文化和特征。”26年来，无论是打出几次漂亮的短打，还是偶尔打出一记本垒打，情报小组都为摩托罗拉作为一家全球性公司的成长做出了不可或缺的贡献。
