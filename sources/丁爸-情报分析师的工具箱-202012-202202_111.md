# 【资料】美国国土安全部（DHS）的实验室

**今天给大家介绍隶属于美国国土安全部的6个实验室：**

**1、国家生物防御分析与对策中心（NBACC）**

**National Biodefense Analysis and Countermeasures Center**

**地点：****马里兰州德特里克堡**

![](../Images/bacf0dbdc47fc8d981b9dd2f399cf025.png)

国家生物防御分析与对策中心（NBACC）是美国应对生物威胁，保护公众免受恐怖主义行为侵害的国家级机构。其工作支持情报评估、准备计划、响应、新兴威胁特征描述和生物取证分析。它是美国国土安全部（DHS）于2004年创建的第一个国家实验室，与联邦调查局（FBI）合作运营，位于马里兰州德特里克堡（Fort Detrick）的国家机构间生物防御园区。是美国13个运行和计划的BSL-4实验室之一。

  

国家生物防御分析与对策中心（NBACC）的组成部分包括国家生物法医分析中心 (NBFAC) 和国家生物威胁鉴定中心 (NBTCC)。

  

**国家生物法医分析中心（NBFAC）**在联邦调查局（FBI）实验室司的指导下运作，为敏感的联邦执法调查进行24/7技术分析。专家通过同时分析鉴定证据样品中的生物制剂，同时分析包括基于制剂的测定以及细菌和病毒培养、聚合酶链反应和免疫测定。国家生物法医分析中心（NBFAC）提供基于方法的能力，包括全基因组测序和生物信息学分析、电子显微镜和质谱。

  

**国家生物威胁鉴定中心（NBTCC）**在国土安全部（DHS）科技局的指导下运作，并开展实验，以便更好地了解生物的脆弱性和危害。这项工作为国土安全部、卫生部和人类服务部、国防部和情报界进行有效准备和反应规划所需的生物剂危害建模提供了信息。

  

国家生物防御分析与对策中心（NBACC）由联邦资助的研究与开发中心 (FFRDC) ** Battelle 国家生物防御研究所** (BNBI) 管理。Battelle 国家生物防御研究所是一家非营利性、专注于 DHS FFRDC 合同的公司。BNBI 是巴特尔纪念研究所的全资子公司。DHS 和 BNBI领导层都对 NBACC/BNBI 进行监督。

  

![](../Images/f830f84ce0b15b538fb426754f33f7e8.png)

国家生物防御分析与对策中心（NBACC）的**生物安全委员会 (IBC) **负责审查、批准和监督所有涉及使用重组核酸（即 DNA 和 RNA）的研究，包括合成核酸分子和转基因生物。NBACC 涉及重组或合成核酸分子和/或重组生物体实验室操作的所有研究项目必须得到 IBC 的批准，并且必须符合 IBC 程序和原则，这些程序和原则在*NIH 涉及重组或合成的研究指南*中概述*核酸分子*（2013 年 11 月*NIH 指南*）。

  

国家生物防御分析与对策中心（NBACC）的**动物护理和使用委员会 (IACUC)** 负责监督和评估机构的动物护理和使用计划（AAALAC）。AAALAC通过自愿认证和评估计划促进科学中动物的人道待遇。50 个国家/地区的 1040 多家公司、大学、医院、政府机构和其他研究机构获得了 AAALAC 认证，表明他们致力于负责任的动物护理和使用。除了遵守监管动物研究的地方、州和联邦法律外，这些机构还自愿参与 AAALAC 的计划。一些获得 AAALAC 认证的机构包括斯隆凯特琳癌症中心、圣裘德儿童研究医院、美国红十字会和美国国立卫生研究院。

  

**2、梅岛动物疾病中心（PIADC）**

**Plum Island Animal Disease Center**

**地点：纽约东方点**

![](../Images/661ddb7cec21dcdcdfd5cb8d959f8cfd.png)

自 1954 年以来，国家实验室梅岛动物疾病中心(PIADC)的国土安全部科技办公室一直是国家防止意外或故意引入包括口蹄疫和非洲猪瘟在内的跨界动物疾病的首要防御措施。梅岛动物疾病中心(PIADC)是美国唯一可以研究活口蹄疫病毒的实验室。该实验室及其近 400 名员工提供了大量具有影响力的、不可或缺的准备和响应能力，包括疫苗研发、诊断、培训和生物法医学等。

  

国土安全部负责实验室的运作，国土安全部跨界动物疫病对策处与美国农业部 (USDA)农业研究局(ARS) 和美国农业部动植物卫生检验局(APHIS) 合作，在梅岛研究和开发新疫苗和诊断测试，以应对并控制跨界动物疾病的爆发。

  

由美国农业部动植物卫生检验局（APHIS）运营的外来动物疾病诊断实验室(FADDL) 是国际公认的致力于诊断外来动物疾病的机构。外来动物疾病诊断实验室在梅岛动物疾病中心维护着北美口蹄疫疫苗库（疫苗库的工作人员负责对新抗原批次的口蹄疫疫苗进行安全性和效力测试，并定期测试存储抗原的质量）。外来动物疾病诊断实验室 还通过学校向州、联邦和外国官员提供外国动物疾病临床和实验室诊断方面的培训。  

  

**3、国家生物和农业防御设施（NBAF）**

**National Bio and Agro-Defense Facility**

**地点：堪萨斯州曼哈顿**

![](../Images/676cd912fc635eb0ebac4ef08c2b860e.png)

国家生物和农业防御设施（NBAF）是最先进的研究动物农业产业化和公众健康威胁疾病的国家生物控制实验室。

  

美国目前没有 (BSL-4)实验室设施来研究影响后果严重的大型牲畜人畜共患病。NBAF 将成为美国第一个提供能够饲养牛和其他大型牲畜的 BSL-4 实验室设施。NBAF 还将设有一个疫苗开发模块。

  

国土安全部科技局领导国家生物和农业防御设施（NBAF）的建设活动，目前仍在进行中。梅岛动物疾病中心(PIADC)目前的运营将继续，直到任务过渡到 国家生物和农业防御设施（NBAF）。

  

联邦政府将执行一项计划，将农业防御任务从 PIADC 无缝过渡到 NBAF，其中包括操作重叠，以确保关键科学任务和操作能力不会中断。

  

2020 年 1 月，美国农业部和国土安全部科技局签署了一份谅解备忘录 (MOU)，概述了他们在国家生物和农业防御设施（NBAF）以国家安全为重点的持续战略跨部门合作伙伴关系。谅解备忘录为科学合作建立了初步框架，并确定了当前的合作机会领域，其中包括：

  

威胁风险评估和研究优先排序：确定哪些跨界、新出现的动物疾病和人畜共患病病原体对动物健康、人类健康和国家安全构成最大风险。这项工作的成果将为 国家生物和农业防御设施（NBAF）的研究优先排序过程提供信息。

研究与合作：  支持相关的美国农业部和国土安全部科技食品和农业任务，包括威胁特征描述和机密研究；涉及疫苗、生物治疗和诊断的生物对策；主题专家协作和信息共享和伙伴关系。

  

国土安全部科学和技术局正在按照标准建造该设施一旦建设和调试活动完成，美国农业部将拥有、管理和运营 NBAF。美国农业部的农业研究局 (ARS) 和动植物卫生检验局 (APHIS) 将在该设施中进行外国动物疾病研究、培训和诊断。

  

**4、化学品安全分析中心(CSAC)**

**Chemical Security Analysis Center**

**CSAC化学品安全分析中心地点：马里兰州阿伯丁试验场**

![](../Images/111072e0c57d65b868a901595d6ed141.png)

2006 年，国土安全部 (DHS) 成立了化学安全分析中心(CSAC)，以识别和评估美国的化学威胁和脆弱性，并针对潜在的化学危害制定最佳应对措施。在国土安全部科学技术局 (S&T) 的监督下，化学安全分析中心(CSAC) 通过提供重要的化学威胁信息知识库、实验室和现场测试的设计和执行以及基于科学的威胁和风险分析能力来支持国土安全社区，其中包括其他服务。化学安全分析中心(CSAC)位于马里兰州美国陆军阿伯丁试验场的埃奇伍德地区，可以与陆军科学家和工程师密切合作。化学安全分析中心(CSAC) 技术援助通常每年响应 70 到 80 个请求。主要客户包括卫生与公共服务部、环境保护署、联邦调查局以及许多其他机构和行业利益相关者。

  

**5、国家城市安全技术实验室（NUSTL）**

**National Urban Security Technology Laboratory**

**地点：纽约曼哈顿**

![](../Images/c1a8ec80379651e5903e2af8d99dda94.png)

国家城市安全技术实验室（NUSTL）每天都在开发新技术以提高响应者的性能和安全性，但它们耐用吗？他们会在压力下表现吗？这就是国家城市安全技术实验室(NUSTL) 的目标。

  

国家城市安全技术实验室（NUSTL）是美国国土安全部科学与技术局管理的联邦实验室，将国土安全企业的利益和倡议与第一响应者社区结合起来。实验室在测试和评估 以及研发方面的任务活动帮助急救人员准备、保护和应对国土安全威胁。

  

**6、交通安全实验室（TSL）**

**Transportation Security Laboratory**

**地点：新泽西州大西洋城**

![](../Images/3585ddcef1772769e31fda6048025a4f.png)

交通安全实验室（TSL）位于新泽西州大西洋城国际机场威廉·J·休斯技术中心，是国土安全部科学与技术局联邦实验室之一。核心任务是通过研究、开发和验证解决方案来检测和减轻简易爆炸装置的威胁，从而增强国土安全。

  

交通安全实验室（TSL ）帮助保护民用航空运输系统。凭借其经验丰富的专家、尖端设施和合作伙伴关系，交通安全实验室（TSL ）为国土安全社区和交通安全合作伙伴提供了通过应用研究、测试和评估、评估、认证和资格测试推进检测技术从概念到部署的能力。交通安全实验室（TSL ）的 100 多名员工包括物理学家、化学家、工程师和数学家，他们在爆炸物检测和缓解方面处于领先地位。
