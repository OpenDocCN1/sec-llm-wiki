### **一、Map Puzzle** 

http://www.mappuzzle.se

如果您想从 Google Maps、Bing Maps 或任何其他地图服务下载一些地图位置，MapPuzzle 正是您所需要的！ 它将允许您将地图位置保存为高分辨率图像（jpg、gif、png、bmp、tiff），您唯一需要做的就是通过地理编码输入 GPS 坐标或地址，点击“下载”即可！无需安装且免费。

![](../Images/ba7c92f56087b9b002c11c4fc1477b61.png)

### **二、Open Street Map** 

http://www.openstreetmap.org

OpenStreetMap 是一个由地图制作爱好者组成的社区。这些爱好者提供并维护世界各地关于道路、小道、咖啡馆、铁路车站等各种各样的数据。OpenStreetMap 强调使用本地知识。贡献者们使用航空图像、GPS设备与传统的地区地图来确保 OSM 的精确性和时效性。OpenStreetMap 是开源数据:只要您表明使用了 OpenStreetMap 并承认其贡献者的工作，您就可以使用 OpenStreetMap。主机由伦敦大学学院、快速的、Bytemark主机，以及其他合作伙伴所支持。

![](../Images/e4793cff6c8b11e2872ee47bc46f2e58.png)

### **三、ALOS**

http://www.eorc.jaxa.jp/ALOS/en/aw3d30

该数据集是全球数字表面模型 (DSM)，水平分辨率约为 30 米（基本为 1 弧秒），由用于立体测绘的全色遥感仪器 (PRISM) 提供，该仪器是高级陆地观测卫星上的光学传感器“阿洛斯”。

### **四、Copernicus Open Access Hub** 

https://scihub.copernicus.eu

卫星地图Copernicus Open Access Hub（以前称为 Sentinels Scientific Data Hub）提供对Sentinel-1、Sentinel-2、Sentinel-3和Sentinel-5P用户产品的完整、免费和开放的访问，从在轨调试审查 (IOCR) 开始）。Sentinel Data 也可通过 Copernicus Data and Information Access Services (DIAS) 多个平台获得。

**![](../Images/a0b9dfc8c77e4766e30a4c224428eb63.png)**

### **五、Digital Globe Open Data Program**

https://www.digitalglobe.com/ecosystem/open-data

MAXAR 是一家领先的空间技术和情报公司。Maxar 通过在灾难发生时提供最准确的数据和分析来支持更大的地理空间社区。在前线工作的组织通过访问这些数据来提高其影响力和有效性。Maxar 与创新企业和 50 多个政府合作，通过空间基础设施和地球情报能力监测全球变化、提供宽带通信和推进空间运营。

![](../Images/1be4cbca8d85ac3c74679e62a3a08760.png)

### **六、Earth Data** 

https://search.earthdata.nasa.gov/search

强大的地球数据集搜索，可搜索关键词，不同平台，不同数据源，不同组织，不同项目，不同级别，不同数据格式，不同分辨率的各种卫星图像数据。

![](../Images/beb107639bdce02f821542ce03e51f40.png)

### **七、ESA Earth Online** 

https://earth.esa.int/eogateway/

欧洲航天局地球在线搜索引擎，支持各种卫星地图搜索功能，包括：专题搜索、仪器搜索、卫星搜索、数据搜索、消息搜索、活动搜索、文件搜索等等。

![](../Images/ce733d23e4c0e513e6316f5be1a8465c.png)

### **八、Copernicus Open Access Hub** 

https://scihub.copernicus.eu/dhus/#/home

Copernicus Open Access Hub 是一个基于 Web 的系统，旨在为 EO 数据用户提供Sentinels 产品的分布式镜像存档和批量传播功能。

![](../Images/259e9b0ddb1da3e0c23254e32b81f9e5.png)
