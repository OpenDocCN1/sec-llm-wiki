# 【资讯】美国打造AUKUS(澳哭死）的同时又要推进USMCA（用死墨加）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MTE0NTE3Mw==&mid=2651124324&idx=1&sn=e56297f4996907be217fea6ecc5ba338&chksm=f1ae855ec6d90c4805d4674abb29b97197838329f4b245e3d2863cf476c76c268a9174b4070f&scene=126&sessionid=1681266899#rd](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651124324&idx=1&sn=e56297f4996907be217fea6ecc5ba338&chksm=f1ae855ec6d90c4805d4674abb29b97197838329f4b245e3d2863cf476c76c268a9174b4070f&scene=126&sessionid=1681266899#rd)

最近，美国宣布在澳大利亚、英国和美国之间为印度洋太平洋建立新的三边安全伙伴关系（AUKUS）。澳大利亚、英国和美国的安全集团将侧重于推进印度-太平洋地区的战略利益。

这一安排的主要亮点是澳大利亚将在英国和美国的帮助下获得核动力潜艇。这一步骤意义重大，因为美国以前仅在1958年开始与英国共享核潜艇技术。核潜艇为澳大利亚提供战略和作战利益。他们走得更远、更快，在海上停留的时间比常规潜艇长。

o 尽管美国已明确否认该组织针对中国，但其在印度洋-太平洋方向结成实际联盟，将阻扰中国在南海采取果断行动。

o AUKUS还将涉及三国之间的新的会议和接触架构，以及跨新兴技术（应用人工智能、量子技术和海底能力）的合作。

  

**但这一合作带给澳大利亚的可能并非仅是益处：**

1、这一计划带给澳大利亚的经济影响是现实的。新的潜艇计划，必然导致澳大利亚国防开支需求大幅增加，这包括对法国的补偿。

2、澳大利亚最昂贵、最强大的国防资产的能力发挥将永远受制于美国，澳大利亚将不能单独操作它们，将进一步削弱澳大利亚的主权。

3、该计划将不可避免地导致AUKUS更深入一体化，澳大利亚将被深深捆绑在美国的战车上。

4、该计划将进一步加深北京的认识：澳大利亚是抵制中国发展的急先锋。

5、澳大利亚未来容易受到中国经济冲击或铁矿石等额外商品进口限制的影响。

  

因此，**AUKUS**最终结果可能是：**“澳哭死”**。

![](../Images/180c8be98f94d832d5484328e29bc36d.png)

  

在打造**“澳哭死”**的同时，美国-墨西哥-加拿大协议 (USMCA) 在美国国会获得两党的压倒性支持。它以北美自由贸易协定 (NAFTA) 为基础，在很大程度上保留了北美自由贸易协定降低贸易壁垒的承诺。USMCA 为美国、墨西哥和加拿大这三个国家提供了“重建得更好”并利用该地区的集体人才、资本和专业知识来发展更具竞争力、可持续和包容性的北美经济的机会。

  

 USMCA 可能产生最大影响的五个优先领域：

1.  建立更具竞争力的北美经济，包括增加贸易和投资；
    
2.  确保有弹性的供应链；
    
3.  扩大数字贸易；
    
4.  支持改善工资和工作条件；
    
5.  应对气候变化。
