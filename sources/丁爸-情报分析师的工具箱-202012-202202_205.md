# 【资料】美国情报总监：不明空中现象初步评估

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MTE0NTE3Mw==&mid=2651124018&idx=1&sn=93d022fe1e50ea57c073f483e1a302c5&chksm=f1ae8608c6d90f1e71e1047128f405299c7e7344e82c390ebecc7f7167fb927a6205c4b2ab5d&scene=126&sessionid=1681266904#rd](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651124018&idx=1&sn=93d022fe1e50ea57c073f483e1a302c5&chksm=f1ae8608c6d90f1e71e1047128f405299c7e7344e82c390ebecc7f7167fb927a6205c4b2ab5d&scene=126&sessionid=1681266904#rd)

2021年6月25日，美国情报总监发布《不明空中现象初步评估》。  

![](../Images/be9cf4763276d1c67fa4d5403b5a155a.png)

该报告收集和分析的数据主要限于美国政府对2004年11月至2021年3月期间发生的事件的报告。

国家情报局局长办公室为国会情报和武装服务委员会编写了本报告。来自美国（I&S）、国防情报局、FBI、NRO、NGA、NSA、空军、陆军、海军/ONI、国防高级研究计划局、联邦航空管理局（FAA）、NOAA、NGA、ODNI/DISM人员组成的不明空中现象特别工作组（UAPTF）和国家情报总监办公室（ODNI）航空事务国家情报经理起草了本报告。

•       所报道的大多数不明空中现象(UAP)可能确实代表物理物体，因为大多数不明空中现象是在多个传感器上登记的，包括雷达、红外、光电、武器搜索和视觉观察。

**•144****份报告来自美国政府的消息来源。其中80份报告涉及多传感器观测。**

**在有限的事件中，不明空中现象似乎表现出不寻常的飞行特征。这些观察可能是传感器错误、欺骗或观察者误解的结果，需要额外的严格分析。**

**可能有多种类型的不明空中现象需要根据现有报道中描述的外观和行为的范围进行不同的解释。我们对数据的分析支持了这样一种观点，即如果个别不明空中现象事件得到解决，它们将属于五个可能的解释类别之一：空中杂物、自然大气现象、美国政府或美国工业发展计划、外国敌对系统和一个笼统的“其他”类型。**

空中杂物：这些物体包括鸟类、气球、娱乐性无人机（UAV）或像塑料袋这样的空中残骸，这些残骸扰乱了场景，影响了真实目标的能力，如敌机。

自然大气现象：自然大气现象包括冰晶、湿气和热波动，它们可能出现在一些红外和雷达系统中。

美国政府或产业发展项目：一些不明空中现象的观察可归因于美国实体的发展和分类项目。然而，我们无法证实这些系统导致了我们收集的任何不明空中现象报告。

外国不利系统：一些不明空中现象可能是由中国、俄罗斯、其他国家或非政府实体部署的技术。

其他：虽然数据集中描述的大部分不明空中现象可能由于有限的数据或收集处理或分析的挑战而仍未被识别，但我们可能需要额外的科学知识来成功收集、分析和表征其中的一些现象。我们将这类物体归入这一类，等待科学进步，使我们能够更好地理解它们。不明飞行物现象工作队（UAPTF）打算重点对少数不明飞行物现象似乎表现出不同寻常的飞行特点或特征管理的案例进行额外分析。
