# 【病毒溯源】2019年德特里克堡千疮万孔，污水横流，基地居民怨声载道

**背景：**  

在20世纪40年代早期，美国国防部/美国陆军收购了马里兰州弗雷德里克市北部的农田，用于生物和化学武器研究和生产设施的发展。这些设施的所在的园区被命名为德特里克堡，德特里克堡一直是美国陆军主要的化学和生物武器研究和生产中心。1972年根据国际协议，生物和化学武器的开发被禁止。德特里克堡改作化学和生物对策的研究和生产中心、传染病研究中心、癌症研究中心。

  

  

从20世纪40年代至今，整个德特里克堡的研究和生产活动都产生了生物和化学废物。生物废弃物经焚化或直接埋在园区内一个被称为B区的区域，化学废物放置在55加仑钢桶后也埋在B区。德特里克堡的东北部分，即A区，是研究实验室和生产设施的所在地。

  

  

然而，由于德特里克堡附近的物业中人类癌症发病率很高，社区开始从“公共健康和安全”的角度质疑德特里克堡的运营完整性。

  

  

环境承包商一直在对德特里克堡A、B两个地区进行综合评估，发现了广泛的地下水污染，这些污染已经转移到邻近的住宅物业及其饮用水井和现场以外的罗宾逊池塘和卡罗尔溪。已确定A区污染源是实验室发生故障和泄漏污染物的结果。B区污染的来源是埋在地下的55加仑桶的结果，这些桶已经生锈，并将其内容物释放到B区地下水中。

**住在德特里克堡的士兵说，他们已经习惯了从管道中流出的褐色水。**

**他们不喝自来水，他们买瓶装水。**

**一位德特里克堡居民说，当水浑浊时，他们不会给孩子洗澡。**

  

![](../Images/7b3dba45ce9a33e93609550a5dc4d909.png)

![](../Images/0bd356acbaa9a28e2f243bf8cac537c3.png)

**更多的居民报告了棕色水问题；**

**这个问题可能比最初报告的39户家庭更广泛。**

**褐色水对于德特里克堡来说并不陌生，前驻军指挥官斯科特·哈尔特上校说主要是由于其老化的基础设施，其中的一些管道，建于1950年代……**

  

**来自德特里克堡和合作伙伴社区的领导人与居民会面，讨论改善陆军住房的努力和未来的道路。美国陆军医学研究与发展司令部和德特里克堡指挥官迈克尔·塔利准将(Brig.Gen.Michael Tley)在基地政务大厅会见了基地住户，表达了他对纠正手头问题的努力和期望。塔利说：“作为领导者，我们需要撸起袖子加油干。现在是看到结果的时候了，是停止空谈和做出承诺的时候了。“最近公布的陆军住房调查结果显示，居民看到的表现有所下降。**

  

**政务厅讨论的另一个话题是“褐色水”问题。到目前为止，已经有39个家庭报告了这个问题。整个军队老化的基础设施是一个令人担忧的问题，德特里克堡有70年历史的供水线路只是影响基地的一个例子。**

  

**解决棕色水问题的长期解决方案也在进行中，资金申请是在美国陆军设施管理司令部(U.S.Army Installation Management Command)一级提出的。驻军指挥官德克斯特·努纳利上校说：“我们有两个项目提交，每个项目价值990万美元。第一个项目是更换下水道，第二个项目将更换供水系统的基础设施。“这两个项目最终解决都取决于陆军可用的资金。**
