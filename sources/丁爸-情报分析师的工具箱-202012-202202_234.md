知名的开源调查团队Bellingcat希望来自各种背景的数字研究人员拥有可以进行开源调查的方法和工具，在github上设立了专栏：

https://github.com/bellingcat/

  

**发布了几款开源工具供大家免费使用：**

**1、Instagram位置搜索**

https://github.com/bellingcat/instagram-location-search

Instagram 在现代社交媒体网站中有些独特，因为公开分享和地理标记。但是，照片无法通过特定坐标进行搜索——而是与 Instagram“地点”相关联。Instagram 不提供通过纬度和经度坐标搜索或发现这些地方的方法，只能通过城市和位置名称。例如，虽然从阿姆斯特丹中央车站找到 Instagram 帖子很简单，但要找到在附近其他地点拍摄的照片并不容易，除非您确切知道要查找的内容（以及相关的 Instagram 地名）。

但是，Instagram 应用程序访问私有 API 或应用程序编程接口，它会查找特定 Instagram 位置附近的位置，并在为新照片选择位置时使用。通过使用这个 API，Bellingcat 开发了一个用于查找 Instagram 地点的工具。

![](../Images/074dcdc00b11e1e44048476ba57cd2ac.png)

**具体用法可去上述github项目地址查看。**  

**2、电报电话号码检查器**

https://github.com/bellingcat/telegram-phone-number-checker

如果研究人员想查明特定电话号码或号码列表是否已用于在 Telegram 上创建帐户，则 Telegram 电话号码检查器非常有用。

该工具使用 Telegram API 并需要“API\_ID”和“API\_HASH”。如果电话号码与 Telegram 用户名相关联，则该工具会提供连接的用户名。由于 Telegram 不需要用户名，因此它还可以简单地检测是否已使用特定电话号码创建了 Telegram 帐户。

**3、自动存档**

https://github.com/bellingcat/auto-archiver

这是一个将youtube-dl与 Google Sheets相结合的工具，用于创建一个用于从社交媒体归档视频的协作界面。这是一个 Python 脚本，定期运行时（与 cron 一样）将：  

*   从 Google Sheet 中的 URL 下载已识别的视频。
    
*   将这些视频上传到与 Amazon Web Service 的 S3 协议兼容的云存储位置，例如 S3 本身或 Digital Ocean Spaces。 
    
*   使用可能对组织和检索有用的元数据更新工作表。
    

该工具由 Bellingcat 开发，用于处理 2021 年美国总统就职典礼的社交媒体图像。

虽然大部分元数据是由 youtube-dl 直接提供的，但该脚本还可以使用ffmpeg（一种用于视频处理的开源工具）转换视频格式并提取元数据。这用于生成缩略图，该缩略图可以作为图像直接插入到 Google 表格中。它还可以为视频“联系表”生成定期缩略图，使视频内容更容易一目了然。

**5、无云区域卫星图像**

https://github.com/bellingcat/cloud-free-subregion

![](../Images/adf5d9f53bab54d3f67e0933e239f6d8.png)

这是一个 Google Earth Engine 应用程序，它尝试查找特定区域中无云的Sentinel-2卫星图像。Sentinel-2 是由欧洲航天局运营的地球观测卫星，每周大约两次捕获地球表面大多数位置的中等分辨率（每像素 10 米）可见光和红外图像。该图像对开源调查人员非常有用，并且在最近的 Bellingcat 文章中，已被用于了解伊拉克的环境污染和分析埃塞俄比亚提格雷的无人机战争索赔。

该工具在赤道地区特别有用，在这些地区，Sentinel-2 在测量整个图像时会定期详细说明重要的云层覆盖，正如 Google Earth Engine 和 Sentinel Hub 中默认提供的那样。然而，其中一些图像可能在特定的小范围内有晴朗的天空。此应用程序有助于找到这些图像。

此外，它会过滤图像集合，使其每月仅包含一张图像，这简化了对可能包含许多图像的大时间范围进行排序的过程。它还提供对比度调整和近红外假色选项，有助于可视化植被。
