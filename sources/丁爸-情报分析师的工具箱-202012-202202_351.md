# 【资讯】开源地理空间信息分析案例一等奖评出来了！

4月23日，第一届“瞰天杯”开源地理空间信息分析案例有奖征集活动进入评审环节。十余位业内专家齐聚现场，对来自高校学生、相关领域从业者及兴趣爱好者的来稿，从选题、内容、创新、展现形式、分析思路、观点结论等方面进行了深入探讨和严格的评审，最终评选出：

一等奖：

《蓝天下的秘密》

  

二等奖：

《藏在大山里的台湾P4病毒实验室》

《“萨德”反导系统入韩事件影像分析》  

  

三等奖：

《宝妈在哪里》

《阿塞拜疆和亚美尼亚的恩怨——2020年纳卡冲突》

《阿萨德基地遇袭情况》

  

优秀奖：

《新竹空军基地》

《缅甸政变报告》

《结合人员社交媒体图片分析轨迹并推断所乘坐船舶船、IMO、MMSI等信息》

《从遥感图像浅论克里米亚半岛俄罗斯军队军事分布》

《基于谷歌影像分析以色列水治理和水资源循环》

《越南地空导弹部队情况研究》

《基于NLP和GIS技术的新冠疫情舆情分析》

比如一等奖《蓝天下的秘密》，采用短视频方式展现了对社交媒体上发布的一张民众在开放日参观军事基地的照片开展图像挖掘，找到照片具体拍摄地点的过程。作者研判思路清晰，逻辑严密，方法巧妙，从照片中的人的肤色、脸型及飞机徽标等判断出照片是在美军亚太军事基地拍摄，再结合开源信息判断美军各个军事基地是否有开放日活动逐渐缩小排查范围，再结合照片中飞机和人员的阴影判断出机场跑道的方向，再通过卫星地图逐一排查美军亚太军事基地，最终确定拍摄地点在日本普天间军事基地。最后，作者根据飞机编号、照片中建筑特点，进一步精确锁定了拍摄地点。
