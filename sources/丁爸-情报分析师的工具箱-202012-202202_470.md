主要发现：  
*1·警务*预测*是应用分析技术来确定警察干预的有希望的目标，目的是降低犯罪风险或解决过去的犯罪。  
2·*警务*预测**技术可以用来识别犯罪风险最高的地点和时间，有可能成为罪犯或受害者的人，以及最有可能过去犯罪的人。  
3·为了有效，*警务*预测**必须包括基于分析结果的干预措施。成功的干预措施通常有顶层支持、充足的资源、提供所需信息的自动化系统，并指派有自由解决犯罪问题和负责解决犯罪问题的人员。  
4·许多机构可能会发现简单的启发式算法足以满足他们的*警务*预测**需求，尽管收集大量数据的较大机构可能会从更复杂的模型中受益。*

**一、警务**预测****

应用分析技术，特别是定量技术，以确定警察干预的有希望的目标，防止或解决犯罪-可以为执法机构提供几个优势。更聪明、更有效、更主动的警务显然比简单地对犯罪行为做出反应更可取。预测方法还可以让警方更好地利用有限的资源。  
为了增加对如何使用警务预测方法的理解，兰德研究人员在国家司法研究所的赞助下，审查了关于警务预测工具的文献，汇编了使用了看似有前途的技术的部门的案例研究，并开发了警务预测方法的分类法。

  
**二、警务**预测**分类**研究人员发现了四大类警务预测方法，方法在涉及的数据量和复杂性上有所不同：***1·犯罪预测方法：**这些方法用于预测犯罪风险增加的地点和时间。**  
2·预测罪犯的方法：**这些方法识别未来有犯罪风险的个人。**  
3·预测肇事者身份的方法：**这些技术被用来创建档案，准确地将可能的犯罪者与特定的过去罪行进行匹配。**  
4·预测犯罪受害者的方法：**与那些侧重于犯罪者、犯罪地点和高风险时间的方法类似，这些方法被用来识别可能成为犯罪受害者的群体，或者在某些情况下，识别个人。***  
后面的表格总结了每个类别，并显示了执法机构用来预测犯罪、犯罪者、肇事者身份和受害者的各种方法。研究人员发现，传统的犯罪分析和调查方法以及较新的“预测分析”方法之间几乎一一对应，这些方法在数学上扩展或自动化了早期的方法。**

| **问题** || **常规犯罪分析** || **预测分析** |
| --- | --- | --- |
| ***犯罪预测*** |
| 确定风险增加的领域 |
| 使用历史犯罪数据 || 犯罪制图（热点识别） || 先进的热点识别模型，风险地形分析 |
| 使用一系列附加数据(例如，911呼叫记录、经济学) || 在电子表格程序中创建的基本回归模型 || 回归、分类和聚类模型 |
| 对最近犯罪风险增加的核算 || 假设近期犯罪周围地区风险增加 || 近重复建模 |
| 确定哪些地区最有犯罪风险 || 按时间/日期(或具体事件)绘制/绘制特定地区犯罪的频率 || 时空分析方法 |
| 确定增加犯罪风险的地理特征 || 找出犯罪事件频度最高的地点并作出推断 || 风险地形分析 |
| ***对罪犯的预测*** |
| 发现犯罪集团之间暴力爆发的高风险 || 对收到的帮派/刑事情报报告的手工审查 || 最近群体间暴力的近重复模型 |
| 查明可能成为罪犯的个人 || 总结各类罪犯已知危险因素的临床仪器 || 基于风险因素的回归与分类模型 |
| ***预测犯罪者身份*** |
| 使用受害者的犯罪历史或其他部分数据来识别嫌疑人 || 手工审查刑事情报报告并得出结论 || 计算机辅助查询和分析情报和其他数据库 |
| 确定哪些罪行属于一系列罪行(很可能由同一犯罪人实施) || 将犯罪联系起来(使用表格来比较已知一系列犯罪的属性与其他犯罪) || 进行犯罪联系的统计建模 |
| 寻找犯罪者最有可能的锚点 || 一系列犯罪附近和犯罪之间的区域定位 || 地理分析工具用于统计推断最有可能的锚点 |
| 在犯罪现场周围使用传感器信息（GPS跟踪、牌照阅读器）查找嫌疑人 || 手动请求和审查传感器数据 || 计算机辅助查询和分析传感器数据库 |
| ***预测犯罪受害者*** |
| 查明可能成为各类犯罪受害者的群体(弱势群体) || 犯罪绘图(查明不同类型犯罪的热点) || 高级热点识别模型；风险地形分析 |
| 查明直接受风险地点影响的人 || 手工绘制或绘制最常见的犯罪地点地图，并查明最有可能在这些地点的人 || 先进的犯罪绘图工具，用于生成犯罪地点并识别频繁使用这些地点的工人、居民和其他人 |
| 查明有受害风险的人(例如，从事高风险犯罪行为的人) || 审查已知从事重复犯罪活动的个人的刑事记录 || 多数据库查询以识别风险人群；回归和分类模型以评估个人风险 |
| 查明有家庭暴力风险的人 || 手工审查国内骚乱事件，以查明风险最大的人 || 计算机辅助查询多个数据库，以查明涉及当地居民的国内和其他干扰 |

**三、警务预测流程**  
做出“预测”只是预测主导的警力的一半。另一半是根据预测进行干预，以减少犯罪活动或解决犯罪。

![](../Images/f2c69407ee546fe436b156a8165a5adc.png)

该过程的核心是一个由四个步骤组成的循环，如图所示。前两个步骤涉及收集和分析有关犯罪、事件和罪犯的数据，以产生预测。第三步是在预测的基础上进行警察行动进行干预。如图底部所示，此类干预措施可能是一般性的(即增加资源)、针对特定犯罪或针对特定问题。理想情况下，这些干预措施将减少犯罪活动或引导警方破案，这是第四步。执法机构应该评估干预的直接效果，以确保不会立即出现明显的问题。机构还应通过检查收集的数据、执行附加分析和根据需要修改操作来跟踪较长期的变化。

  
**四、警务**预测**误区和陷阱**  
虽然预见性警务有很大的前景，也受到了很多关注，但在采用这些方法时，有一些神话需要意识到，也有一些陷阱需要避免。许多神话源于不切实际的期望：警务预测被炒作得太夸张了，以至于现实无法与夸张相提并论。当谈到警务预测时，有**四种常见的误区**：  
*1·计算机实际上知道未来。尽管许多新闻报道宣扬警务*预测*是一个“水晶球”的模因，但由此产生的算法预测的是未来事件的风险，而不是实际事件。计算机可以极大地简化对模式的搜索，但它们的预测将取决于制作它们所用的数据。  
2·电脑会为你做一切事情。相反，即使拥有最完整的软件套件，人类也必须找到相关数据，处理这些数据以进行分析，针对不断变化的犯罪特征设计和进行分析，审查和解释分析结果(并排除错误的发现)，推荐干预措施，并采取行动利用这些发现并评估干预措施的影响。  
3·你需要一款高性能(且昂贵)的机型。事实上，大多数部门不需要最复杂的软件包或计算机来启动预见性警务计划。在几个案例研究中，简单的启发式方法在执行一些*警务*预测**任务方面几乎与分析软件一样好。虽然复杂的模型可以提供更强的预测能力，但回报可能会递减。  
4·预测会自动导致重大犯罪率下降。预测就是这样。犯罪率的实际下降需要根据预测采取行动。*警务*预测**是端到端流程的一部分。*

  
**为了确保警务**预测**实现其潜力，执法机构需要避免一些常见的陷阱：**  
·注重准确性，而不是实用性。将整个城市描述为犯罪热点可能是准确的，但当涉及到利用有限的资源规划警察干预时，如此大的面积是不可能的。  

  

为了识别那些小到足以让警方采取实际行动的热点，分析人士必须接受以数据捕获的总体犯罪比例衡量的准确性方面的一些限制。  
*1·依赖劣质数据。数据质量的三个典型缺陷是数据审查，或遗漏关于特定地点或特定时间感兴趣的事件的数据；系统偏差，这可能是数据收集方式造成的；以及不相关的数据，即对正在解决的具体问题没有用处的数据。  
2·误解了这一预测背后的因素。在应用回归或数据挖掘等技术时，分析师应该使用常识来选择要分析的因素，以避免作用于虚假的关系。  
3·不强调评估和评价。在与从业人员的访谈中，兰德研究人员发现，很少有受访者评估他们部门预测的有效性。衡量有效性是确定需要改进的领域和有效分配资源的关键。  
4·忽视了公民权利和隐私权。将某些地区或个人指定为值得采取执法行动会引起对公民和隐私权的担忧。美国最高法院裁定，在“高犯罪率地区”放宽了合理怀疑的标准，但什么构成这一地区，以及可能采取什么措施，都是悬而未决的问题。  
*  
**五、结论**  
对于正在考虑采用警务预测工具的执法机构来说，关键价值在于态势感知。犯罪相对较少且犯罪模式合理可理解的小型机构可能只需要相对简单的功能，例如由基本电子表格或统计程序提供的功能。对数据要求更高的大型机构可能需要更复杂的系统，这些系统可以与现有系统和其他司法管辖区的系统互操作。

  
对于开发商来说，研究人员建议供应商将他们的系统描述为识别犯罪风险，而不是预测犯罪风险。开发人员还必须意识到执法机构在采购和维护新系统时面临的财务限制。供应商应该考虑让小型机构更容易负担得起预测系统的商业模式，例如地区成本分担。

  
对于打击犯罪的人来说，研究人员强调，预见性警务必须与阻止犯罪的行动相辅相成。成功的干预措施通常有顶层支持、充足的资源、提供所需信息的自动化系统，并指派有自由解决犯罪问题和负责解决犯罪问题的人员。设计具有这些属性的干预计划，结合可靠的预测性分析，可以在很大程度上确保预测的犯罪风险不会变成真正的犯罪。
