# 【情报实战】挖掘美国公司与政治的联系

这篇文章是关于如何调查公司与政治之间的联系的，重点是个人披露和说客报告。美国不少网站公开记录了公司与政治之间的许多活动，但由于很少有人知道该去哪里找，所以在浩瀚的互联网海洋里它仍然是隐蔽的。

  

![](../Images/c564d4245717e404e24e6936108eff24.png)

  

**本文将**通过**研究如何浏览一位美国会议员的案例来**介绍**这些链接。**

  

这种调查的重点是查找隐藏在各种“深层网络”数据库中的信息。回想一下，深层网络数据库中的信息对Google和其他搜索引擎而言是隐藏的（可以将“开放式网络”或“表面式网络”视为可以在Google搜索中找到的任何内容）。

  

**因此，您实际上必须去数据库的网站才能找到其中的信息。**

  

这就像是将信息埋在地下，所以没人能看到。将常规互联网视为表面，您可以在搜索国会议员并查看有关其新立法建议的新闻报道。但是，当您挖掘隐藏的信息（例如在深层网络数据库中注册的他们的个人业务）并将其带到地面时，您可以在下文中看到它。在这种情况下，这意味着您可以看到国会议员正在提出有利于其个人业务的立法。

  

  

**研究机会**

在大多数人认为的利益冲突与政治上的法律冲突之间，存在很大的差距。这两个定义之间的鸿沟是研究公司与政治家之间联系的好地方。

  

对于美国会议员来说，众议院道德委员会设定官方标准来确定国会议员是否存在利益冲突。“但要证明一名成员为个人利益而滥用其影响力的举证责任太重了，”Roll Call的一篇文章说。

  

在威廉姆斯议员案中，道德委员会实际上认为他的行为不符合利益冲突的标准。

  

**案例分析**

本文以德克萨斯州一名国会议员约翰·卡特（以下简称“国会议员”）在2018年的案例研究为基础，展示了可用于任何政治企业调查的研究方法。（这主要针对2018年的数据，因为一些相关数据尚未提供2020年的数据。）

  

![](../Images/c6b86a798327a036f6982a86d3e0cdec.png)

  

因此，如果您决定调查这位议员，那么从哪里开始呢？

  

**1、政治捐款**

在开始对议员进行标准Google搜索之后，下一步就是查看谁为他的竞选活动提供资金。

  

![](../Images/5310762e27804403ff633d01bd317e52.png)

他们与谁有联系？

  

当政客收到任何至少200美元的政治捐款时，就会在联邦选举委员会（FEC）数据库中列出，**网址为：****https://www.fec.gov/data/**

  

也可以使用搜索FEC数据库的其他站点来搜索政治捐赠。我特别推荐**责任项目：****publicaccountability.org**和在OpenSecrets.org的捐助查找工具：www.opensecrets.org/donor-lookup，更方便用户使用。根据捐赠者是个人还是公司/组织，此工具将识别捐赠者的姓名，地址，职业，所捐赠的金额以及接受者。

  

这是追踪线索的绝佳工具。但是就国会议员而言，他的捐助者并没有什么非同寻常。

  

**2、公开披露**

  

公开披露通常是大量的重要信息。政客们必须公开其财务状况的信息，这些信息记录在各种公共数据库中。您可能在想“如果政客公开披露此信息，它怎么会有任何秘密？”

  

事实证明，定期公开披露是丑闻的来源。

  

![](../Images/0081567de5d14d360f2f2389d48ced51.png)

  

*附带说明一下，这是源于“秘密”公开披露的丑闻的一个示例：*

  

*“在里诺市议会从市中心驱逐脱衣舞俱乐部的运动的高峰期，里诺市检察官卡尔·霍尔（Karl Hall）努力出售了一座办公大楼，距离野生兰花绅士俱乐部不到一个街区，但并未透露可能的利益冲突。根据《里诺公报》的调查。” *

  

多年来，政客经常在这些数据库中披露利益冲突，而没有人注意到。原因是双重的：首先，从披露本身来看，没有明显的利益冲突，您必须做很多工作。因此，政客们经常且正确地认为，不可能有任何人会特别关注他。其次，如果确实发现了利益冲突，则政治家在法律上是安全的，因为他们遵守了披露的法律要求。

https://disclosures-clerk.house.gov/PublicDisclosure/FinancialDisclosure

我搜索了2018年的议员，并得到了一个结果。查看他的资产清单，我们看到他的支票帐户，养恤金，储蓄帐户中有一些现金，然后有大量的埃克森美孚股票中的钱。

**3、具体贡献者的捐款**

这仍然可能什么证据都没有，所以让我们继续讨论一下，看看还能找到什么。让我们看看埃克森美孚是否向国会议员捐款。如果我们回到FEC数据库并仔细查看国会议员的捐助者，就会发现其中列出了埃克森美孚公司。但这重要吗？

  

要找到答案，请检查两件事。我们查看了国会议员对其竞选活动的其他捐款以及所提供的金额。与国会议员的其他捐助者相比，埃克森美孚公司的实际捐助数额并不大。根据OpenSecrets，该公司在当年国会议员的最大捐助者名单中仅排名第44位。

  

另外，在数据库中快速搜索埃克森美孚（Exxon Mobil）即可发现，该捐赠是向大多数国会议员捐赠的，而且捐赠给我们这位国会议员的数额也差不多。这证实了公司向国会议员的捐赠没有什么不寻常的。

  

让我们离开国会议员片刻，集中讨论埃克森美孚的游说工作。

  

**4、游说工作**

当一家公司游说任何立法时，可以说是承认它认为该立法可以使公司受益或受到伤害。当然，帮助/伤害像埃克森美孚这样的公司的立法也会同样影响其股票和国会议员的个人财务状况。

  

在一些数据库中，公司记录了他们游说政府的努力。

  

首先，我们进入**众议院：****lobbyingdisclosure.house.gov**和**参议院：****lda.senate.gov/system/public**的游说数据库。当我们搜索埃克森美孚时，我们会发现类似这样的文档。

  

![](../Images/e07e4323b5646446a217677a77afe3e0.png)

  

方框内显示，游说花费了超过300万美元。请记住，这只是一份文件，尽管可以肯定的是，该价格高于埃克森美孚公司大多数游说的价格标签。

  

*游说表格上列出的价格不是很准确。为了理解原因，在Propublica的指南中提供了以下解释：*

  

*“弄清楚一个组织在特定的游说活动上花费了多少，这很棘手。该法律仅要求游说者报告他们每个季度为联邦游说所支付的金额，四舍五入至最接近的10,000美元-如果给定季度的收入少于3,000美元（对于内部游说者的组织，则少于13,000美元），他们不会完全不必披露。另外，一些组织包括不属于该报告的支出，例如，花钱游说州政府或其他法律工作。”*

**7、旋转门**

政治和游说中有一个概念，称为“旋转门”，通常被定义为“一方面是立法者和监管者角色之间的人员流动，另一方面是受立法和法规影响的行业成员之间的人员流动。”

  

您可以研究从事特定合同的任何游说者与被游说者之间是否存在过往关系。因此，在我们的示例中，我们可以查看上述立法的合同，埃克森美孚（Exxon Mobil）正在游说国会议员所在的拨款委员会。

  

**这该怎么做**

  

**首先**，要找到相关合同，我们重复以上过程，在该过程中我们找到了埃克森美孚公司内部游说委员会的具体记录。我们使用Propublica游说工具：https://projects.propublica.org/represent/lobbying，搜索我们的公司并获得结果：https://projects.propublica.org/represent/lobbying/search?utf8=%E2%9C%93&search=exxon+mobil&commit=Search，我们选择查看公司内部游说记录的详细信息（但您可以选择任何一个），然后在此处获取此详细页面：

https://projects.propublica.org/represent/lobbying/r/300985502。我们再次向下滚动到2018年第四季度记录。

  

**其次**，请注意右上角的“原始文件”，旁边是一个xml文件链接。这是合同的记录，请单击此处，以便我们深入了解哪些游说者致力于解决哪些问题。

  

![](../Images/4b6303c8a7e90e4aaa3e9b95197a1098.png)

  

**第三**，您将看到一个或多个标题为“游说活动”的部分，在第16号下看到了什么问题被游说，在第17号下看到了政府的哪个部分（例如众议院或特定部门）被游说了。这些问题。最后，我们在第18号下看到从事这些工作的注册说客。

  

因此，例如，我们在下面的部分中看到，一个叫Dan Dan Easley的说客是游说的说客之一。接下来，我们将调查以下列出的任何游说者是否具有相关的“旋转门”历史，在这些历史中，他们曾为游说过的政府部门服务。

  

![](../Images/66526ef0c4a78b2a29cb43b53bf21c67.png)

  

**第四步**，转到“公开秘密”页面以获取有关联邦游说的数据：https://www.opensecrets.org/federal-lobbying。搜索相关公司的名称，然后进入其“大厅资料”：https://www.opensecrets.org/federal-lobbying/clients/lobbyists?cycle=2018&id=d000000129&t0-Revolving+Door+Profiles=All，在右侧的下拉菜单中选择相关年份，然后单击“大厅”选项卡。您将看到一个结果列表，其中显示了该公司在这一年中雇用的所有游说者。如果需要，您可以选择过滤并仅显示曾经是国会议员的说客，或过滤具有“旋转门轮廓”的说客。

  

![](../Images/32e2af8cf6efb2befa8327b80d52d7a5.png)

  

为了我们的目的，我们将仅搜索合同中指定的说客。如上所示，如果它们的名称右边有两个圆形箭头，则表示它们具有“旋转门轮廓”。

  

在下图中，我们在右方看到埃克森美孚游说记录，其中列出了几位游说者，他们就各种科学问题游说过国会和其他政府实体（“科学问题”显然不是很具体，但我想尽量保持简短）可能），其中列出的一位说客是Daniel Easley。在左侧，您可以看到埃克森美孚（Exxon Mobil）游说者领导下的“公开秘密（Open Secrets）”中的相关数据。因为Easley在右边的记录中，所以我们知道可以在Open Secrets页面中找到他。

  

![](../Images/fe6e813017cf9ac9f8c59e6292f5b77d.png)

  

当我们看到Easley列在“公开的秘密”中时，我们还观察到他的名字右侧的圆形箭头中有一个“旋转门轮廓”。我们单击箭头，然后打开他的“旋转门轮廓”。个人资料显示了Easley的工作经历，这表明他之前曾在众议院科学委员会工作。这就是为什么他具有“旋转门”身份的部分原因。作为众议院科学委员会的前雇员，他现在正在游说科学问题和立法，他可能会游说他的前同事。

  

![](../Images/6a5ec14d13c415d51b13e60f8c80970a.png)

  

在我们的示例中，在专门针对拨款委员会的记录中，我们没有发现从事这些问题的任何旋转门游说者。埃克森美孚公司游说委员会的其他记录可能还包括旋转门游说者，但我们将重点放在一个记录上，因为我们不想开始挑选数据。

  

**8、进一步了解更多数据**

好吧，现在让我们把事情放到上下文中，然后问“这是典型的吗？”。我们将查看两个数据池以获取上下文。首先，我们可以从总体上看一下埃克森美孚公司的捐款，看看是否有任何模式。您可以从“ Open Secrets”中获取此数据，并使用Python进行显示。这里的目标是找到尝试利用埃克森美孚公司的捐款来反映公司感兴趣的领域。换句话说，如果他们在一个主题上花费更多，也许他们会更在意。

  

![](../Images/9f76d6f1548ac8fb63112e8007fad73f.png)

  

如果您熟悉使用Python，以埃克森美孚公司为例的演练，它产生了上面的图。图表中的数据来自Open Secrets，显示了公司向每个委员会成员捐赠了多少钱。该图显示，埃克森美孚花了最多的钱向拨款委员会成员捐款。

  

在查看政治捐款数据之前，我认为公司似乎只是向所有人捐款，但现在我们看到了一种模式，表明公司可能将更多资源用于拨款委员会。

  

现在，我们要寻找对拨款委员会成员，或者只是对国会来说，普遍投资于埃克森美孚公司是否普遍。

  

为了找出答案，我们再次返回“Open Secrets”，该名单提供了国会议员的名单，按其在埃克森美孚公司的投资额排名。

https://www.opensecrets.org/orgs/exxon-mobil/members-invested?id=D000000129

  

我们的国会议员是排第一。

  

![](../Images/ad13f767d8257fa910e7443f60bbd79a.png)

  

**9、总结**

  

我们调查的国会议员压倒性地投资了一家公司，比国会中的任何其他人都多。他坐在一个委员会中，而公司似乎向该委员会中的大多数人捐款。但最重要的是，他是一个委员会的成员，该委员会与我们公司正在游说并为此支付大量费用的立法一起工作。

  

困惑？

  

该图试图解释这种情况。

  

![](../Images/213d9ff7e5f2908659a32fe9729f68df.png)

  

**第一**：国会议员是一个参与某些立法的委员会。

  

![](../Images/ea1aaceda32939d1f2ca98174f50d7fa.png)

  

**第二**：该公司正在游说该立法，因为从理论上讲，它认为可以从中受益。

  

![](../Images/1cecc37f5e8082ef84d062572f51da2b.png)

  

第三：公司的成功与股票有关，而股票与议员的个人财务状况有关。

  

![](../Images/dc1b38b3b77eee732f3ec4ae37a4b3f1.png)

  

现在，可以说，我们看到了国会议员的职位与其个人理财之间的联系。

这些研究方法可以应用于研究任何政客或公司。
