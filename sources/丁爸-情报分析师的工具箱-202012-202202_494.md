# 【资料】与美国情报融合中心合作的企业

融合中心的概念是美国9月11日报告的结果，美国国土安全部试图在州，地方和地区执法部门与包括联邦调查局、国土安全部等在内的联邦执法实体之间建立更好的沟通与合作。

《国家信息共享和保护战略》和《国家信息共享战略》是影响融合中心工作的两份文件，它们为建立更加主动的信息共享网络定义了广泛的战略。融合中心协会（NFCA）与其他几个联邦和地方执法协会共同制定了“州和主要融合中心的基础能力”以及“国家融合中心国家网络的国家战略”，这些文件明确定义了融合的作用和他们应该实现的目标。

**通过了解与美国情报融合中心合作的企业也可以窥探美国情报融合中心的相关业务开展情况。**

**1、Kaseware**

https://www.kaseware.com/

Kaseware是首要的调查平台。它可轻松管理您的调查，案件，记录，证据等，同时提供便捷的功能，如分析，驾驶执照扫描和自动填写，因此您无需再次填写重复的表格。

Kaseware十年前由在华盛顿特区的联邦调查局（FBI）总部前FBI的特工创立，他们具有数十年的公共安全以及企业软件开发经验。

4、ACISS

ACISS Systems，Inc.提供了完全集成的信息管理和分析解决方案，用于组织和传播执法机构和其他调查组织收集和利用的大量信息。

自1984年以来，ACISS Systems一直致力于成为开发可扩展解决方案以满足执法部门独特需求的行业领导者。目前，其解决方案已在美国各地的各种机构中使用，部署范围从麻醉品部门到多机构，多辖区，全州和区域情报共享计划。

https://www.aciss.com/

**6、clearview ai**

Clearview AI是执法机构用来识别犯罪者和受害者的新研究工具。Clearview AI的技术已帮助执法部门追踪了数百名一般的罪犯，包括恋童癖者，恐怖分子和性贩子。它还可用于帮助无辜者免除罪责，并确定包括儿童性虐待和财务欺诈在内的犯罪行为的受害者。借助Clearview AI，执法人员可以抓捕最危险的罪犯。

https://www.clearview.ai/

cobwebs的系统为国家安全，执法和私人部门提供服务，确定网络关系，犯罪活动和网络恐怖分子威胁。协助客户调查和分析目标数据。产品范围涵盖从支持目标Web数据搜索的支持起点到提取重要的智能见解，以及一直监控和实时提供相关事件警报的所有内容。旨在收集和分析网络中无穷无尽的社交媒体，开放，深度和黑暗的网络数据层。
