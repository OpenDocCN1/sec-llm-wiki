前几天小编给大家推送了[【突发信息】五角大楼机密文件泄露：包含乌克兰进攻计划信息](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651135698&idx=1&sn=725c722e71dfa9d6bb18b36e9c47fb62&chksm=f1af69e8c6d8e0fef130c742eed298be7a425a6a0ea8d6beec5d98122b048cc9ca6494956116&scene=21#wechat_redirect)，这几天又陆续泄露出一堆五角大楼的机密文件，这些机密文件的密级如何区分呢？今天小编就给大家推送美国情报界关于机密资料的分类管理规则文件《情报界授权的机密和控制标记登记簿和手册》  

![](../Images/aa8043626b8b66630e24a671df8aed99.png)

该手册中将美国政府的文件分为九类：  

1\. US Classification Markings （美国机密标识）2\. Non-US Protective Markings （非美国防护标识）3\. Joint Classification Markings （联合机密标识）4\. Sensitive Compartmented Information Control System Markings （敏感分区信息管理系统标识）5\. Special Access Program Markings （特别访问程序标识）6\. Atomic Energy Act Information Markings（原子能法案信息标识）7\. Foreign Government Information Markings （外国政府信息标识）8\. Dissemination Control Markings （传播控制标识）9\. Non-Intelligence Community Dissemination Control Markings（非情报界传播控制标识）  
Required on classified documents and unclassified documents with dissemination controls - Items 1-3 are mutually exclusive within a banner and portion mark其中：带有传播控制的机密文件和非机密文件要求：1-3项在横幅和部分标记中相互排斥。

  

在这次泄露的文件中都有相关文件机密等级的标识：  

比如下面这张图片的右上角标注的：SECRET//NOFORN

表示：该文件泄露会严重危害国家安全（SECRET），不得对外国发布，外国人不可看见（NOFORN）

文件上谈到：

*   耶路撒冷采用土耳其援助乌克兰的方式：以色列在美国的压力下采用土耳其的模式，出售或通过第三方实体提供致命的防御系统;它公开主张和平结束冲突，并愿意主持调解工作。安卡拉成功地与莫斯科保持了友好关系，同时为向基辅运送武器提供了便利:耶路撒冷可能认为，它同样可以平衡两国关系。
    
*   俄罗斯扩大战略，扩张对伊朗的援助：俄罗斯向伊朗转让苏-35侧卫或sa -21等战略系统，或扩大对伊朗导弹、核或太空计划的援助，促使以色列提供致命援助。以色列国防军担心俄罗斯将提供先进的系统或技术，例如用于导弹和太空计划的钢合金或其他材料，以换取伊朗的武器。
    
*   以色列扩大与美国的接触，进行反伊朗行动：以色列常规武器通过叙利亚，促使俄罗斯继续允许伊朗进步反穿越行动来换取致命的援助，美国请求以色列扩大对乌克兰的支持。以色列国防领导人正在倡导加强对抗伊朗的行动，包括提出以色列和美国的双边行动:以色列经常要求ATG飞越以支持对叙利亚的打击。
    
*   扩大对空防御在叙利亚的存在和使用：俄罗斯在以色列的袭击中造成人员伤亡，并开始用地对空导弹直接瞄准以色列飞机:携带先进的地对空导弹，如IR-SA-2或ANU PRESENCEIR-SA-3发射到叙利亚，改变了以色列对致命援助的考量。以色列在2022年定期打击叙利亚和特兰尼安在叙利亚的防空。俄罗斯发射了一架sa -21，可能是为了传递信息——在以色列飞机在空袭离开叙利亚领空之后。  
    

  

部分标识和缩略语含义：

\- SI = Special Intelligence （特殊情报-来自截获通信的情报）

\- G = GAMMA（敏感通信截获）

\- NOFORN = No Foreign Nationals（不得对外国发布 )

\- ORCON = Originator Controlled（原创者访问控制 )

\- HCS = HUMINT Control System（秘密人力情报来源 )

\- HCS-O = HCS Operations（人力情报情报行动）

\- HCS-P = HCS Product（人力情报情报产品）

\- TK = TALENT-KEYHOLE（来自卫星收集的情报）

\- TS = Top Secret（泄露会造成特别严重的损害国家安全）

\- SAP =  SPECIAL ACCESS PROGRAM （特殊访问计划）

\- NF = NOFORN（不得对外国发布）

\- OC = ORCON（发起者控制）

\- FRD = FORMERLY RESTRICTED DATA（以前受限制的数据）

\- NATO = 可向北约伙伴发布

\- S = SECRET（泄露会严重危害国家安全）

\- C = Confidential（泄露会危害国家安全）
