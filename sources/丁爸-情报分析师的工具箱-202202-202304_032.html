1、什么是操作系统：

Palantir Technologies 是一家软件公司，为公司和政府提供独特的技术产品。公司产品的核心是通过使用数字孪生和本体来模拟现实，从而能够预测、预防和模拟事件，并创造最佳结果。

此外，与其他软件产品相比，Palantir 与众不同，Palantir 不提供单一的一次性工具或独立产品，而是旨在为软件和数据提供操作系统。

与微软的情况类似——微软操作系统充当个人、团队和国家的基础层，在其上构建他们的产品，是一系列其他技术、工具和应用程序的支柱。与 Palantir 的情况类似——通过 Palantir 操作系统——该软件可以互操作并充当一系列定制或标准化工具的基础层。例如，该产品可以与先前的组织软件工具和解决方案进行互操作，将它们集成到 Palantir 操作系统中，同时容纳 Snowflake 和 Azure 等软件产品——所有这些都结合在一起。

Palantir 作为基础层，不仅可以容纳这些工具，还可以进行互操作和结合使用，从而从中获取价值。

Palantir 还提供了一系列内置工具，可以与第三方软件集成结合使用，也可以单独使用。

而Snowflake 和 Data Brick 等公司仅提供独立的一次性产品，例如 Data Lakehouse，因此无法提供任何真正的 alpha。


中央操作平台的想法可以更流畅地进一步分解为 4 个主要领域：

1) 首先，通过 Palantir 软件，可以将某些工具、功能和合作应用程序“拖放”到项目中。 这可以流畅地完成，这意味着工具、功能和应用程序可以相互通信和协同工作。除了 Palantir 在其平台内拥有固有工具（数据可视化、人工智能、机器学习、本体论）之外，人们还可以利用这些固有工具，并将它们与合作伙伴的功能和工具结合使用，以获得最大价值。PLTR 与亚马逊 AWS 的合作示例：“使用 Foundry 的数据连接、提取、转换、加载和数据分支功能快速准备数据，然后将 AWS 工具拖放到项目中以分析数据和开发模型。”

2) 协调和绑定 IT 环境。 这意味着，通过 Palantir，组织可以将他们自己定制的数据系统和工具与更现代的工具和应用程序结合起来，而不是在组织内部替换旧的数据系统和工具——并在整体上使用它们相互通信。

3） 网络效应是指Palantir OS的低代码、无代码环境。 这使组织中的任何人和每个人都可以使用该平台，创建新的应用程序和功能，无论技术能力如何。可以在整个组织内共享更改，揭示产品如何随着更多人的使用而变得更有用。

4）串联数据。 数据被转化为人、地点和事物——这让数据变得生动起来。

2、什么是本体

本体层是 Palantir 操作系统最重要的方面。这种本体——在哲学上指的是“存在的本质”——指的是一个操作层，在这个层中允许数据连接到现实世界的行动，从而使这些数据活跃起来。

从根本上说，本体层的核心是为 Palantir 创建一个数字化孪生，从而通过模拟、理论——但准确的——实验来模拟现实，从而选择导致成功的最佳结果。

本体层中的对象代表构成业务的现实世界实体、关系和事件。关系表示现实世界实体、事件和过程之间的联系。动作捕捉对象之间的动力学，并通过企业系统协调现实世界的变化。Ontology Scenarios 允许企业以完全保真的方式安全地模拟改变个人行为或整个行动过程的后果。

此外，随着越来越多的人使用该平台，这个本体层也在不断改进。通过使用回写功能，这可以捕获操作、流程和相关数据的影响，以确保本体层——以及驱动的操作——可以随着时间的推移稳步改进。

这一点是有必要理解的，并且会波及整个 Palantir OS。通过增加平台的采用和使用——不仅是本体，还有平台的其他重要领域——这导致平台的实用性得到提高。随着越来越多的人使用它，该平台变得越来越有用。这就是网络效应的概念，也许在 Facebook 的案例中最为明显。随着越来越多的人使用 Facebook 平台，该平台的实用性也越来越高。如果不使用 Facebook 生态系统，一个人就会被视为局外人，并且会感觉到很大程度的脱节。

因此，与仅表示为复杂图表、表格和不清楚的术语的数据相比，本体层可以创建对现实的模仿——数字孪生——从而将这些无用的数据转化为人物、地点、动作、事件和真实的企业内的活动数据。
