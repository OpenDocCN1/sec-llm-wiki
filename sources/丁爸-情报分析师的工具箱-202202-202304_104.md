# 【情报案例】印度孟买恐怖袭击

**【案例简介】**

2008年11月26日21时30分左右，一伙端着冲锋枪、拎着手榴弹的恐怖分子闯入孟买最知名的五星级饭店——泰姬玛哈饭店，他们见人就扫射，随处投掷手榴弹。几乎与此同时，奥贝罗伊酒店、犹太人聚居的纳里曼大楼、一个大市场以及交通最繁忙的CST火车站和百年老店利奥波德餐厅等9个地方也遭到恐怖分子的袭击。

印度媒体援引孟买灾难管理机构的统计数字报道说，11月26日21点30分至29日10点长达近60个小时的恐怖袭击造成195人死亡，另有295人受伤，死者主要是印度人，但也包括至少22名外国旅客。

2008年11月29日的新闻发布会上，印度内政部长帕蒂尔称恐怖分子在行动前的目标是杀死5000人。帕蒂尔介绍说，初步调查显示，共有10名恐怖分子参与了袭击，其中9人在交火中被击毙，1人被活捉。

孟买著名的泰姬玛哈和奥贝罗伊两家五星级酒店是当天袭击的主要目标。枪手还袭击了孟买世界文化遗产贾特拉帕蒂·希瓦吉火车站。因小说《尚塔拉姆》而为西方游客青睐的孟买知名餐厅利奥波德餐厅第一个遭袭。

泰姬陵饭店拥有105年历史，有浓郁印度风格，被誉为印度自由精神的象征。曾在此下榻的客人包括美国前总统比尔·克林顿、法国前总统雅克·希拉克、英国王储查尔斯王子、“猫王”埃尔维斯·普雷斯利、英国“甲壳虫”乐队、“滚石”乐队主唱米克·贾格等。

此次袭击，英美游客成为首要袭击目标，恐怖分子专门寻找持有美国和英国护照的人士下手。一名在欧博龙目岛度假酒店用餐的英国游客说，枪手们首先挑选出英国人和美国人。他说，一名二十二三岁的年轻枪手，将三四十人从餐馆中驱入楼梯，命令所有人举起手。他们从中挑选出英国人和美国人。一名意大利人回忆说：“他们先问你是哪国人，我回答说来自意大利，他们说‘很好’，并准许我离开。我很害怕，因为‘很好’的意思通常就是不问为什么，直接被射杀。但是感谢上帝，他们没有杀我”。

有媒体报道称，恐怖分子手持武器冲进一家餐厅后，立刻勒令正在吃饭的外国游客起立排队报出国籍，凡是自称英美游客的一律就地枪决。据现场逃生的游客透露说，英美游客还成为恐怖分子绑架的对象。在泰姬玛哈酒店里，共有包括7名外国人在内的15人被带往酒店顶层作为人质。

根据孟买袭击事件中唯一落网者阿杰马勒·阿米尔·盖塞卜的口供，印方指控拉赫维和“虔诚军”行动总负责人优素福·穆扎米尔联手策划了孟买袭击。现年21岁的盖塞卜供认，他在加入“虔诚军”后，在18个月内辗转多处“虔诚军”营地，接受体能、射击、爆破、航海等训练，其中一个训练营地便在穆扎法拉巴德附近。

印度警方还发现，今年2月被捕的印度籍恐怖嫌疑人法希姆·安萨里也在“虔诚军”设在穆扎法拉巴德附近的训练营受过训。安萨里被认为在孟买为袭击“踩点”。

**【蓄谋已久的袭击】**  

“虔诚军”（Lashkar-e-Taiba）于20世纪80年代创建于巴基斯坦和阿富汗，其总部位于巴基斯坦的拉合尔，训练营地则位于莫迪克地区。该组织带有浓烈的伊斯兰原教旨主义色彩，其目标是解放克什米尔，肢解印度，在南亚和中亚地区建立一个伊斯兰政权。它宣布美国、以色列和印度为伊斯兰教的生存敌人。

已知的第一个“虔诚军”行动是 1990 年对一小群印度空军人员的伏击。

“虔诚军”创建之时，本·拉登曾伸出援手，提供过经济援助。同“基地”组织一样，“虔诚军”也从西亚的阿拉伯国家尤其是沙特取得经济援助。自创建以来，它一直得到巴基斯坦三军情报局(ISI)的资助和支持，巴基斯坦希望通过这种不对称战争削弱印度对克什米尔地区的控制。

“虔诚军”组织策划过一系列发生在印度、死亡人数超过150人的恐怖行动，如2000年3月在克什米尔地区对锡克教徒的屠杀、2005年发生在新德里的爆炸事件、2006年7月11日的孟买列车爆炸。此外，它还积极介入了阿富汗战争，在伊拉克战争中，人们也可以看到它的身影。在许多方面，它都与“基地”组织类似，成为一个全球性的国际恐怖主义组织。

“9·11”事件后，在美国的压力下，巴基斯坦政府取缔了“虔城军”，随后美国和英国将其列入恐怖组织名单。于是，“虔诚军”策划发动一次轰动性的打击，借此恢复该组织的凝聚力。其计划制造一次同时可能打击到印度人、美国人、英国人和犹太人的恐怖袭击，目标便是印度繁荣的中心—孟买。

为实施此计划，“虔诚军”招募了24人在该组织的训练营中接受了为期一年的训练。训练由退役军人负责实施，分成三个阶段：先是为期三个月的体能训练，参加者每天都要长跑10到15千米；接下来的三个月中，他们进行水上训练，演习游泳和航海术；最后三个月才是正规的兵器训练。训练结束后，教官从他们中选出10名“敢死队”成员。带往印度孟买进行“短时间实习”，以便熟悉当地的环境。他们拍摄了大量相片和录像资料进行分析，也曾利用谷歌地球数字地图来了解孟买街道、建筑的布局环境，掌握了各袭击目标的卫星相片，拥有建筑位置和布局的详细地图。

与此同时，“虔诚军”也在紧锣密鼓地进行技术方面的筹备。

30岁的计算机专家扎拉尔·沙阿（Zarar Shah)是“虔诚军”的技术负责人，负责通信和筹措装备。沙阿是一个精通数字技术的老手，他胡须浓密，走路一瘸一拐，强烈憎恨印度。

2008年9月中旬，沙阿开始检索VoIP系统、网络安全与通信掩盖方式。沙阿首先与新泽西州一家公司取得联系，假冒印度电话服务转售商，化名为卡拉克·辛格，宣称自己住在孟买，就VoIP网络电务进行砍价。起初，沙阿觉得对方要价过高，便用蹩脚的英文致信新泽西州公司的管理人员：“我不是第一次购买Voip服务，我用这项服务已经两年了。”最终，沙阿通过新泽西州那家公司搭建起VOIP服务，他与恐怖分子通话时可以显示出201的区号，从而掩盖真实的电话来源。

2008年11月，该公司的老板致信这位冒牌的印度转售商“辛格”，抱怨这个数字电话网络没有产生任何流量，沙阿回复称：尊敬的先生，这个月底我会送去流量的。

在制定计划的过程中，沙阿在笔记本电脑上检索欧洲通讯安全薄弱点，并在一个旨在隐藏浏览历史的网站逗留过，还在谷歌新闻上检索“印美海军演习”、“孙子兵法”、“泰姬玛哈酒店”、“印度此前发生的恐怖袭击”等内容，他还访问印度地图网站，查看孟买市内及周边情况。

此外，“虔诚军”还专门安排人员到印度踩点，负责踩点的是一个名为戴维·黑德利的巴基斯坦裔美国人。此人在袭击发生前，曾多次到印度旅行，帮助恐怖分子寻找袭击目标，收集录像资料和 GPS信息，并乘船巡游孟买附近海面，为袭击者寻找泊港和登陆港口。

为了此次袭击，恐怖分子可谓训练周密，谋划精心。

**【第一次警告】**  

事实上，关于孟买袭击的蛛丝马迹，早在三年前就已经显露出来。

2005年8月的一天，美国联邦调查局接到一个神秘的举报电话，电话是一名美国妇女通过该局的反恐热线打进来的。她举报她的丈夫---巴基斯坦裔美国人戴维·科尔曼·黑德利---是巴基斯坦“虔诚军”的一名活跃的武装分子，曾在位于巴基斯坦的武装分子营地接受训练，与多名极端恐怖分子联系密切。接报后，工作人员迅速将信息传给了联邦调查局的反恐联合工作组。

黑德利的父亲是一位巴基斯坦外交官，黑德利本人出生于美国。一岁的时候，他父母带他回到了巴基斯坦，在伊斯兰堡郊外一所最古老的的寄宿制学院汉森·阿卜达尔军事学院上学。他中学没有毕业，父母就离了婚，他跟父亲去了美国费城，帮助他的美国继母经营一个一个酒吧，后来他自己开了几间音像出租屋。也就在这个时候，他卷入了毒品走私。1988年和1997年，他因走私毒品被指控，但他利用自己在美国和巴基斯坦的关系摆平了这一麻烦，并成为美国毒品管制局的线人。他提供的情报极有价值，因此美国毒品管制局让他穿梭于巴基斯坦和美国之间。

或许为了掩盖黑德利的美国毒品管制局线人身份，美国有关当局没有继续调查下去。如果他们继续调查下去，就会发现黑德利不仅是毒品管制局的线人，同时也是巴基斯坦三军情报局的线人。三军情报局的情报网招募他充当间谍，以监视印度军队的调动情况。2006年初，三军情报局一位名叫伊克巴尔的少校军官交给黑德利25000美元，作为他在孟买设立办事处、建立掩护机构的资金。

联邦调查局认为，它所掌握的证据不能确认黑德利与“虔诚军”之间的联系，因此没有对黑德利采取任何限制措施。2006年的出入境记录显示，黑德利曾自由地在巴基斯坦、印度、迪拜以及欧洲旅行。

无独有偶，2007年12月，黑德利的另一任妻子---一位名叫奥塔哈的摩洛哥妇女---走进了美国驻巴基斯坦大使馆，称黑德利正在策划一场恐怖袭击。27岁的奥塔哈告诉美国大使馆官员，她的丈夫有许多“虔诚军”朋友，具有强烈的反印情结，经常前往印度经营，但其商业活动总不见起色。奥塔哈还说，黑德利不断转换身份：当他在巴基斯坦时，他是一个名叫达乌德的虔诚穆斯林；当他在印度时，他又变成了名叫戴维的美国花花公子。

奥塔哈甚至向大使馆的官员出示了她与黑德利在2007年4月和5月两次在泰姬玛哈饭店门口的留影。饭店的旅游记录显示，他们确实到过饭店。但是，接待她的大使馆地区安全事务助理认为，奥塔哈的指控只能说明她的丈夫正与一些坏人来往，而这些坏人正在策划“圣战“。但是，哪些人卷入了这一阴谋，他们的阴谋是什么，她并没有给出详细的细节。结果，此次举报同样不了了之！

第一次告警就这样归于平静。

**【袭击警报不断拉响】**

印度是一个恐怖活动频发的国家，而作为印度的商业和娱乐中心，孟买更是恐怖活动肆虐的中心。从20世纪80年代起，这个沿海城市曾多次遭受重大恐怖袭击。1992年底，印度教极端分子捣毁巴布里清真寺（Babri Masjid),引发孟买历史上最大规模的连环恐怖袭击案。l993年3月12日，孟买证券交易所、火车站等13个地区发生炸弹爆炸事件，造成253人死亡，713人受伤。2002年12月6日，恐怖分子将炸弹放在火车站附近一家麦当劳快餐店的空调管内，造成25人受伤。

2003年1月27日，一枚放置在自行车上的炸弹在维拉-帕拉火车站外发生爆炸，炸弹弹出的钢针至少造成30人死亡。时隔一个月后，穆兰德火车站在高峰时段再次发生炸弹爆炸，造成11人死亡，超过65人受伤。2006年7月11日，孟买列车连环爆炸案夺走209条生命。

按理说，经历过如此频繁的恐怖袭击，印度应该对恐怖袭击的迹象和线索极为敏感。那么，袭击发生之前，印度安全和情报部门是不是没有掌握任何消息呢？

显然不是。

印度是美国的反恐伙伴，美国情报机构向印度情报机构提供了恐怖袭击的信息。2008年10月中旬，两名常驻印度的美国中情局高级情报官曾向美国和印度发出两次恐怖袭击的预警，说恐怖分子可能瞄准孟买的酒店。这份预警情报甚至点明，老巢在巴基斯坦的“虔诚军”行动小组成员，可能“秘密侦察”了孟买的酒店。11月18日，他俩第二次发出警告，称巴基斯坦境内的恐怖组织正准备对孟买发动恐怖袭击，并且可能从“海上进入”。这份情报还说，这些恐怖分子将不同于以前的普通恐怖分子，他们特别训练有素。接到警告后，孟买安全部门提高了酒店的安全保卫措施，但随后又松懈了下来。

印度警方也获得过有价值的信息。2008年2月10日，一个名叫安萨里的印度人在印度北部城市兰普尔因涉嫌参与袭击一个警察营地而被捕，警察从他身上搜出了手绘的孟买酒店、火车站及其他重点目标的草图。安萨里承认，他在阿拉伯联合首长国迪拜市为一家平面媒体工作期与“虔诚军”取得联系。之后，他经海路抵达巴基斯坦，再转陆路到达穆扎法拉巴德的“虔诚军”驻地接受训练。“虔诚军”为他提供了伪造的巴基斯坦护照和身份证明。“虔诚军”有意袭击孟买市内8到9个具体目标，其潜在目标还包括美国领事馆、孟买证券交易所等。从2007年秋天起，他就开始侦察孟买的各种情况，并负责为武装人员安排临时窝点。

印度情报部门也从自己的渠道获得了恐怖袭击的信息。印度的研究分析局(Research and Analysis Wing,R&AW)是印度的主要对外情报机构，负责搜集外国情报，从事反恐事务，执行隐蔽行动，其情报搜集手段包括人力搜集、信号情报等。在恐怖袭击发生前数月，它曾多次截获信号，暗示以巴基斯坦为基地的恐怖组织即将对孟买发动恐怖袭击。

2008年9月18日，印度研究分析局截获了一个卫星电话，对话的一方是“虔诚军”成员，另一位则不知其名。“虔诚军”神秘人物说：“对孟买印度门附近饭店的攻击已经在计划之中，将会通过海路实施。”6天后，该机构又截获了另一次卫星电话，电话中提及了正在考虑攻击的印度饭店的名字，它们是泰姬玛哈饭店、海礁石酒店和孟买万豪酒店。这些饭店都能轻易从海上进入。2008年11月18日，研究分析局又截获一个莫名其妙的卫星电话。对话中一个声音说：“我们将在晚上9点至11点之间到达孟买。”经确认，这次通话的准确地点在孟买近海，即孟买西部40千米处的乔尔。消息立刻传到新德里的总部，并被送往印度国家安全委员会、国家安全顾问、联合情报委员会。联合情报委员会把信息传递给陆军、空军、海军和海岸警卫队，以及印度情报局，后者再通过其在孟买的分部向下传递给马哈拉施特拉邦警察局、孟买警监、马哈拉施特拉邦反恐特别行动队。不过，情报传递过程中，不同机构对信息的严重程度以及真实性存在不同解读，部分机构以此类情报太多为由并未加以重视。甚至在恐怖袭击发生前数小时，一位研究分析局的技术人员监听到恐怖分子与其控制者之间通过卫星电话的谈话，当时这些恐怖分子正在驶向孟买。技术人员认为通话内容非常可疑，向上级做了报告。研究分析局认为这一迹象确实可疑，向国家安全顾问办公室发出了警告。

11月26日，研究分析局在印孟边境地带截获了一条要求把10个手机SIM卡激活的信息。这些手机卡均在孟加拉国购买，研究分析局一直监视着这些手机，但手机一直处于停机状态。而到11月26日，它们突然全部激活了。然而，研究分析局没有破译这一信息的含义，没有把它与恐怖袭击联系起来。谁也没想到，梦魇，就在下一刻开始…

**【恐怖杀戮】**

2008年11月26日夜，星期三，印度最大的海港和金融中心城市孟买华灯初上，光影如织，大街上车水马龙。川流不息的车流，熙熙攮攮；夺目的广告灯闪烁的陆离光彩，映照着来去匆匆的人流。餐厅里，三五成群的知己好友正在把酒谈心；商店里，来来往往的顾客有的购物，有的观赏，到处呈现出一片欢乐祥和的景象。殊不知，一场噩梦即将降临…

就在孟买海岸边，刚刚乘船抵达的10名恐怖分子上岸后即分成四个“战斗小组”，其中四人前往泰姬玛哈饭店，两人的目标是三叉戟饭店，两人负责那拉曼旅社，两人被派到火车站。分组完成后，几乎没做任何停留，他们就迅速朝着目标方向出发，不一会儿就消失在黑暗中…

这10名恐怖分子正是巴基斯坦恐怖组织“虔诚军”的成员。2008年11月21日，他们乘坐一艘较大船只从卡拉奇出发；出发前，每个人分发到手6、7本杂志、一把AK-47式自动步枪、一把左轮手枪、50发子弹、8枚手榴弹以及若干水果。他们穿过了阿拉伯海，遇到一艘名为“库柏”(Kuber)的印度拖船，杀死4名船员，逼迫船长引航。抵达孟买附近海域后，又杀死船长，由一名海上经验丰富的袭击者借助全球卫星定位系统驶向孟买海岸。当船只距离海岸还有约7千米时，他们又分组改乘3艘劫得的快艇在孟买海岸登陆。

11月26日晚21时30分，袭击首先从外国游客云集的利奥波德餐厅开始。三名枪手冲进餐厅四处扫射，墙壁上满是弹孔，而地上则布满了血迹。

大约22时，位于马哈拉施特拉邦议院后的三叉戟酒店内也响起了枪声。据称，当时共有约1000名游客被困酒店。据一名目击者称，一伙武装分子冲入大堂围拢游客，并四处寻找持有美国或英国护照的人。最后，他们劫持了大约15名游客为人质。

22时15分至22时30分，恐怖分子在一千米外的泰姬玛哈酒店外与警方交火。当时，共有20多名游客被困在该酒店的大堂中。同样，恐怖分子主要的攻击目标是英国人和美国人。

22时33分，两名男孩模样的人若无其事地进了希瓦吉火车站(CST),在候车大厅内突然亮出AK-47自动步枪并向人群扫射，随后穿越数个月台，向人群投掷手榴弹。有目击者称，在这座也被称为维多利亚火车站的站外还发生了两起爆炸。紧接着，在离希瓦吉火车站仅一千米远的Mtro电影院也响起了枪声。恐怖分子攻击了两名警察，并劫持了他们的警车。

此外，恐怖分子还冲进Cama医院，劫持了几名病人为人质；在孟买的两处居民区造成了数起爆炸；占据了犹太人会所，并在里面展开杀戮。

27日凌晨0时20分，恐怖分子向泰姬玛哈饭店投掷手榴弹，奥贝罗伊饭店外发生爆炸。0时37分，两名袭击者开着一辆警车逃脱。

0时41分，马哈拉施特拉邦议会大楼外响起枪声。0时48分，泰姬玛哈饭店一个圆顶内发生爆炸，冒出滚滚浓烟，稍后可见火苗蹿出。150名在饭店内开会的一家公司的职员被困。0时57分，袭击者占据泰姬玛哈饭店360号和361号房间。1时5分，泰姬玛哈饭店和奥贝罗伊饭店分别发生爆炸。1时15分，拉马达饭店发生交火，至少4名警察身亡。1时35分，号称孟买警方遭遇战专家的维贾伊·萨拉什卡在交火中丧生。孟买警方反恐部门负责人赫曼特·卡尔卡尔也因枪伤身亡。警方高级官员阿肖克·坎普特也死于枪战。1时55分，泰姬玛哈饭店内发生枪战。5时59分，泰姬玛哈饭店和奥贝罗伊饭店发生劫持人质事件。至少上百人被困泰姬玛哈，饭店顶层着火，几乎被烧得干干净净。

面对恐怖分子的疯狂，无助的游客和市民只能把生的希望寄托在等待救援上。

**【反恐行动】**

马哈拉施特邦首席部长德希姆克迟至晚23时才认识到事态的严重性，向印内政部长要求派遣被称为“黑猫”的国家安全卫队来对付恐怖分子。

200人的精锐队员整装待发。但是，空军的伊尔-76型运输机却用了近3个小时才从昌迪加尔空军基地赶到国家安全卫队所在的德里，之后又用了近3个小时才把这支反恐部队运抵孟买机场。当巴士用40分钟将队员们运送到集结地点时已经是第二天早上6点钟了。此后，国家安全卫队又与警方、军方花了一个小时进行情况分析，制定行动计划和人员部署。

27日晨，解救人质的战斗在三叉戟酒店展开。100名印度特种部队队员攻入饭店的19层，成功解救出5名外籍人质。与此同时，印度警方也开始对泰姬玛哈酒店展开进攻。数分钟后，警察护卫着数十人，其中多为西方人，走出酒店。

攻坚战首先从被称为“加巴德大屋”的犹太人会所开始。凭借抢占的重要战术位置、强大的火力和良好的训练，恐怖分子与反恐部队僵持了三十几个小时。直到28日下午，突击队员才利用直升机空降的方式进会所，但除了两名被击毙的恐怖分子，还有5名犹太人被打死。对泰姬玛哈酒店和三叉戟酒店残余恐怖分子的围剿一直持续到29日。

至29日晚，经过60多小时的激战，最终平息恐怖事件。

这次惨案至少造成175人死亡，300余人受伤。这是继“9·11”后最大规模的恐怖袭击，被称为印度的“9·11事件”。美国中央情报局前南亚事务分析专家布鲁斯·里德尔表示：“此次恐怖袭击在全球性圣战上是一个新的、令人恐惧的里程碑。”
