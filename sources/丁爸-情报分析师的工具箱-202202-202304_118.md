# 【技巧】如何利用开源情报工具核查目标人物的位置

今天推送一篇读者来稿，因部分内容不适合公开推送，小编将来稿内容做了一些修改后推送给大家。  

这篇文章的总体思路是通过查询手机、邮箱关联的社交账号或者注册的应用软件，然后通过查看这些社交账号或者应用发帖和使用的位置，进而锁定目标人物的大致位置，再使用社交软件查看附近的人的功能，利用三角定位逐步缩小目标所在的位置。  

**一、查看目标人物注册和使用的社交软件或者其他应用软件**

1、国内手机和邮箱可以使用reg007查询（https://www.reg007.com/)，小编之前的文章也给大家介绍过一些类似工具：[【工具】查手机注册过哪些网站工具测评](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651110412&idx=1&sn=cd10656357ed1e0e1c4360986cf5c05e&chksm=f1aecb36c6d94220246abf5828d2956cdd96d97ac308259de9c4bc25e4d1b3f13f125cd71812&scene=21#wechat_redirect)

2、境外邮箱可使用epieos查询（https://epieos.com/）看看目标邮箱注册了哪些应用。
