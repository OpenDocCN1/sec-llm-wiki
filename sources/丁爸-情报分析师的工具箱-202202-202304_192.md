# 【转载】第聂伯河上的桥

2022年7月19日，乌克兰使用海马斯火箭炮对第聂伯河上的安东尼夫卡公路桥进行了攻击，使该桥造成严重破损。这是一个重要的信号和标志，表明双方军事斗争的着力点不再局限于军事目标。根据目前的战局情况分析，俄乌双方都在逐步加强对民生设施的争夺与控制，桥梁作为重要的民生设施，也会成为双方争控的焦点。

针对此，我们搜集整理了第聂伯河上的有关桥梁情况，供关注时局的人研究使用。![](../Images/2248c8d19e4502e9f99536b1c8eca00d.png)

被海马斯火箭炮袭击的大桥桥面

  

第聂伯河发源于俄罗斯首都莫斯科以西的瓦尔代南部沼泽地区，流经白俄罗斯和乌克兰，出海口为黑海。河面上有各种桥梁75座（公路桥48座，铁路桥14座，公铁两用桥5座，连接水坝两岸桥6座，人行桥1座，浮桥1座），其中俄罗斯境内22座（公路桥17座，铁路桥4座，浮桥1座），白俄罗斯境内20座（公路桥15座，铁路桥5座），乌克兰境内33座（公路桥16座，铁路桥5座，公铁两用桥5座，连接水坝两岸桥6座，人行桥1座）。

![](../Images/3a4b9ceb58ff39d2ccfa837e61472102.png)

第聂伯河上的桥梁

为便于理解和描述，按照从上游到下游的顺序依次对桥梁进行了编号。本文重点是介绍在乌境内的桥梁。

  

![](../Images/ecbbcb167ce72be052b8de9ce251e24b.png)乌克兰境内第聂伯河上的桥梁

  

1.桥43：该桥名为内丹奇奇铁路桥，为白俄罗斯和乌克兰之间的过境铁路桥，钢架结构。由乌克兰的斯拉维季奇通往白俄罗斯境内。长781米，宽5米。

![](../Images/67d1d31c65743e8ece3c7c0a401e1f27.png)

桥43

2.桥44：该桥位于区域道路0P56/R35上，钢筋混凝土材质公路桥，由乌克兰的斯拉维季奇通往白俄罗斯境内。长880米，宽16米。公开报道称该桥被乌克兰在撤退的时候炸毁了位于乌克兰境内的桥梁。

![](../Images/f2867e764fef0bf5f297a4010ec445c7.png)

桥44

3.桥45：该桥位于区域道路P69号公路上，是首都基辅的公路桥，钢筋混凝土结构，双向4车道，长300米，宽13米。

![](../Images/fd3cd96af44b5f2757fd7106f262e370.png)

桥45

4.桥46：该桥名为皮夫尼奇尼桥，乌克兰首都基辅市内的斯捷潘纳班德里大道上，2018年2月，这座桥才被命名为莫斯科夫斯基桥或莫斯科桥。该桥为公路斜拉桥，双向8车道。长816米，宽31.4米，高119米，最大跨度300米。

![](../Images/532b448c5a220e041aea791e22c5cd6f.png)

桥46

5.桥47：该桥名为彼得里夫卡铁路桥，位于乌克兰首都基辅市内，为钢架结构铁路桥。长1457米，宽8.4米。

![](../Images/08d6a926baf88caf80832dbe4844f3e7.png)

桥47

6.桥48：该桥名为波多利斯基桥，是乌克兰第聂伯河上正在建设中的公路铁路组合桥，它是基辅地铁Podilsko-Vyhurivska线建设的重点。设计为双向6车道，将中央Podil社区连接到左岸城市的部分地区。桥的顶层将承载公路交通，而底层将承载铁路交通。长4432米，宽32米。

![](../Images/0ecf6b9d1f44566b26be381671630838.png)

桥48

7.桥49：该桥名为海港大桥，横跨位于Podil和Obolon社区之间的基辅港入口，提供了通往Rybalskyi半岛的更快通道，并连接了两个城市的堤岸街道，拉伸了第聂伯河右岸的轮廓。为公路桥，钢筋混凝土结构，双向6车道，长380米，宽35米。

![](../Images/5f1169e6a1ae98842748fd587cdf70de.png)

桥49

8.桥50：该桥名为帕科维人行天桥，将右岸的基辅市中心与特鲁哈尼夫岛的休闲区和海滩连接起来。该桥为悬索桥，专为行人设计建造，不允许车辆通行。长429米，宽7米。

![](../Images/8cc83d8c5fac3f57bc26d7b6f6ac4eb9.png)

桥50

9.桥51：该桥名为基辅地铁桥,位于H07号公路上，将基辅右岸与Rusanivka、Levoberezhnaya阵列、Voskresenka、Lesnoi Massiv和著名的基辅休闲区-Hidropark（水上乐园）连接起来。为汽车地铁两用桥，钢筋混凝土材质，双向4车道。长700米，宽30米。

![](../Images/acf5e7ed91e15f7d46a70d5b91a6b53c.png)

桥51

![](../Images/69a659e8d6a4d26db78776f6bcdc28e8.png)
