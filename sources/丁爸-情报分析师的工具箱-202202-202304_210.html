今天给大家介绍一个社交媒体地理位置信息聚合器-Creepy

Creepy是一个地理定位OSINT工具。可以从Twitter在线来源收集地理位置相关信息，并允许在地图上显示，基于确切位置和/或日期的搜索过滤，导出为csv格式或kml，以便在谷歌地图中进一步分析。

Creepy 允许用户从 Twitter、 Flickr、Instagram、google plus等社交网络平台和图像托管服务中收集已经发布和公开的地理位置信息。Creepy 检索到的地理位置信息以可导航嵌入式地图上的点的形式以及位置列表（地理纬度和经度以及日期和时间）呈现给用户。每个位置来源信息相关联，例如用户在该特定位置发布的推文，或者他或她上传的照片。

Creepy 是用 python 编写的，它的源代码在 Github 上可用，它也作为基于 debian 的 Linux 发行版（Debian、Ubuntu、Backtrack）和 MS Windows（XP 和更高版本）的打包二进制文件提供。官网提供了适合于多种操作系统的多种版本下载链接。

官网地址：http://www.geocreepy.com/

github地址：https://github.com/ilektrojohn/creepy

使用该工具需要进行配置，让工具可以通过你的 Twitter、 Flickr、Instagram、google plus等社交网络账号访问 twitter等 API接口。因此需要进行相应的设置。

对于twitter，可以通过用户名、全名和电子邮件进行搜索。对于Flickr，可以通过选择相应的搜索按钮来搜索全名或用户名。搜索结果包括用户名、全名、用户的头像和一些附加信息，如声明的位置。
