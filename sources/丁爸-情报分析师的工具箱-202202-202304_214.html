【资讯】全球开源情报 (OSINT) 市场预测及主要开源情报企业

2021年全球开源情报市场规模为54.4923亿美元，预计到 2030 年，全球开源情报 (OSINT) 市场规模将达到 362.4124 亿美元，复合年增长率为 28.33%。


开源情报 (OSINT) 市场的主要参与者是：

1.Alfresco Software, Inc.

Alfresco Software是由Alfresco Software Inc.使用Java技术开发的Microsoft Windows和类 Unix操作系统的信息管理软件产品集合。该软件被称为数字业务平台，主要是专有和商业许可的开源平台，支持开放标准，并提供企业规模。

https://www.alfresco.com/


2.Siemens AG

西门子股份有限公司为一家德国的跨国企业，其电子与电机产品是全球业界先驱，并活跃于能源、医疗、工业、基础建设及城市业务等领域。西门子于1847年由维尔纳·冯·西门子建立，总部位于德国慕尼黑和柏林，于法兰克福证券交易所和纽约证券交易所挂牌上市。此外，西门子也是美国《财富》杂志2017年500大企业第66名，目前在全球拥有385000名员工，公司业务遍布190个国家。

https://www.siemens.com/

3.Maltego Technologies

Maltego是用于开源情报和取证的软件，由来自南非比勒陀利亚的 Paterva 开发。Maltego 专注于提供一个转换库，用于发现来自开源的数据，并以图形格式可视化该信息，适用于链接分析和数据挖掘。截至 2019 年，总部位于德国慕尼黑的 Maltego Technologies 团队负责所有面向全球客户的运营。

Maltego 允许创建自定义实体，允许它表示除了作为软件一部分的基本实体类型之外的任何类型的信息。该应用程序的基本重点是分析人、组、网页、域、网络、互联网基础设施和社交媒体从属关系之间的现实世界关系（社交网络、OSINT API、自托管私有数据和计算机网络节点）。Maltego 通过各种数据合作伙伴的集成来扩展其数据范围。其数据源包括DNS 记录、whois记录、搜索引擎、社交网络服务、各种API和各种元数据。

https://www.maltego.com/

4.Expert System S.p.A.

Expert System SpA 提供语义技术的开发和营销，以理解和管理非结构化信息。它服务于银行、保险、石油和天然气、媒体、出版、政府、电信、生命科学和制药行业。

https://www.expert.ai/

5.Google LLC

Google是总部位于美国加州芒廷维尤的跨国科技公司，为Alphabet的子公司，业务范围涵盖互联网广告、互联网搜索、云计算等领域，开发并提供大量基于互联网的产品与服务，其主要利润来自Ads等广告服务。

https://www.google.com/

6.IPS S.p.A.

IPS是一家网络情报解决方案的全球供应商，在高科技市场拥有超过30年的经验。4大洲30多个国家的国土安全部门、情报部门和执法机构都将IPS作为可信赖的长期合作伙伴。IPS网络情报解决方案有助于打击非法活动，这得益于通过人工智能算法收集、监控和分析来自各种信息、来源和网络的广泛数据通信的可能性。

https://www.ips-intelligence.com/


7.Digital Clues

Digital Clues掌握了数字情报，并提供开创性的全渠道情报工具和数字侦探服务。其产品被情报机构的情报分析师和调查人员使用，使用户能够启动任何有意义的线索的调查，分析他们，并将他们转化为真正的嫌疑人。Cellebrite（纳斯达克股票代码：CLBT）的使命是帮助其客户保护和拯救生命，加速正义，维护世界各地社区的隐私。Cellebrite 是公共和私营部门数字情报解决方案的全球领导者，通过简化情报流程，使组织能够掌握法律认可的数字调查的复杂性。Cellebrite 的数字情报平台和解决方案受到 140 多个国家/地区的数千家机构和公司的信任，改变了客户在法律认可的调查中收集、审查、分析和管理数据的方式。

https://cellebrite.com/


8.NetSentries Technologies FZCO

Netsentries Technologies 是一家私营公司。该公司目前专注于信息技术和服务领域。其总部位于美国华盛顿州贝尔维尤。业务涉及：渗透测试、防火墙管理、日志管理服务、内容安全、IPS/IDS 实施、漏洞评估、托管安全服务、托管 SOC、合规咨询、PCI DSS、ISO 27001、安全评估、托管安全服务、SIEM、SOC 咨询、IOT安全等。

https://www.nstcyber.ai/


9.Recorded Future, Inc.

Recorded Future是一家成立于2009年的私有网络安全公司，总部位于马萨诸塞州萨默维尔。该公司专门从事威胁情报的收集，处理，分析和传播。Recorded Future使用获得专利的机器学习和自然语言处理方法，不断收集和组织来自开放网络，暗网和技术来源的数据。

https://www.recordedfuture.com/

10.Palantir Technologies

Palantir Technologies专门从事大数据分析，总部位于科罗拉多州丹佛市，由Peter Thiel、Nathan Gettings、Joe Lonsdale、Stephen Cohen和Alex Karp于 2003 年创立。公司名称源自魔戒中神奇的palantíri，被描述为坚不可摧的水晶球，用于交流和观察世界其他地区的事件。

该公司以三个项目而闻名：Palantir Gotham、Palantir Apollo 和 Palantir Foundry。Palantir Gotham 被美国情报界(USIC) 和美国国防部办公室的反恐分析师使用。过去，Gotham 曾被美国前联邦机构Recovery Accountability and Transparency Board的欺诈调查员使用。Gotham 还被加拿大公私机构Information Warfare Monitor的网络分析师使用。Palantir Apollo 是用于在所有环境中持续交付和部署的操作系统。他们的 SaaS 是美国国防部为关键任务国家安全系统 (IL5) 授权的五种产品之一。Palantir Foundry 被摩根士丹利、默克集团、空中客车、 Wejo、 Lilium和菲亚特克莱斯勒汽车等企业客户使用。

Palantir 的原始客户是美国情报界(USIC) 的联邦机构。此后，它扩大了客户群，为州和地方政府以及金融和医疗保健行业的私营公司提供服务。

https://www.palantir.com/


11.Thales Group

Thales Group是法国的一家专注于航空航天、国防、地面交通运输、安全和制造电气系统的电子集团。其总部位于巴黎的拉德芳斯。其股票在巴黎泛欧证券交易所上市，截止2019年4月2日，在56个国家和地区有业务，并有80000名员工。

https://www.thalesgroup.com/
