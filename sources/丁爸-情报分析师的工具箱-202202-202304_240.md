# 【资料】 联合全域作战（JADO）与联合全域指挥与控制(JADC2)

昨天给大家介绍了[【资料】美军的多域作战(MDO)](http://mp.weixin.qq.com/s?__biz=MzI2MTE0NTE3Mw==&mid=2651131978&idx=1&sn=45cfaaac11a83d1d393477f89b08327e&chksm=f1af6770c6d8ee66c9c8ab96d4d19b9ae8c2a28f0e8b9a004da971bbcd2e5759d0337b7b4c05&scene=21#wechat_redirect)，今天给大家介绍多域作战的升级版：

**联合全域作战（JADO）:**是Joint All Domain Operations的首字母缩略词，这是美国国防部 (DoD) 的一种战略方法，它将所有防御领域（海、陆、空、太空和网络空间）的能力和资源整合到计划、分析和执行任务。 

![](../Images/2f3432fd9f184b9b1ce3390e1b5ce46e.png)

这种方法是各种军种跨域学说的跨部门变体，为战场交战注入了速度和规模效应的融合，可以压倒敌人，包括近乎对等的对手，并确保任务成功。然而，要实现 JADO 的成功，需要在来自国防部各部门的行动中使用的所有资源之间进行广泛的协调与合作，包括陆军、海军、海军陆战队、空军和太空部队的专家。

采用 JADO 作为学说。有效实施 JADO 还需要每个军事部门重新考虑如何在整个冲突过程中执行行动，以及如何最好地访问所有领域的组合以最大程度地受益于任务成果。这代表了关于防御战术如何运作以及需要执行的任务的军事学说的变化。虽然所有的改变都可能很困难，但这种学说的改变与美国的空中力量理论相一致，该理论允许美军快速适应新形势，同时抑制敌人这样做的能力。重新思考的一个重要部分是考虑并针对各个分支机构传统上使用的技术和运营元素的差异，以及这种可互操作的“网络中的网络”方法都需要它们做出哪些改变*并*首次提供给他们。

实现 JADO 所需的许多技术促成网络和系统融合，以加速 C4ISR 态势感知和决策，同时使所有域的部队更容易安全地通信和交换数据。其他技术允许身份验证、提高弹药准确性、使移动系统具有现场适应性等等。其中一些包括：

*   自适应情报、监视和侦察 (ISR) 传感器
    
*   网络弹性系统和协议
    
*   分布式边缘计算
    
*   全球定位系统 (GPS) 和 GPS 测绘
    
*   高速数据处理器和 ISR 分析
    
*   联合直接攻击弹药 (JDAM) 制导套件
    
*   远程反舰导弹（LRASSM）系统
    
*   多功能信息分发系统 (MIDS) 终端
    
*   战术数据链路和软件无线电 (SDR) 通信
    

此外，要使这些先进技术对 JADO 最有效，它们还必须与经验丰富、富有洞察力且不断发展的JADC2（全域联合指挥与控制）结构相结合。上面提到的 C4ISR 技术的结合是 JADC2 结构的基础，但它的成功还取决于组织、预算和条令的接受程度。

实现有效 JADO 任务的挑战始于解决几十年来一直是美国军方一部分的传统能力孤岛，每个分支都开发自己的内部跨域解决方案。突破这些孤岛以建立跨部门的战术合作和信任具有心理、技术、地理、预算和指挥方面的挑战，整个国防部和情报界都必须克服这些挑战，以确保 JADO 的持久成功。

考虑到采用和实施 JADO 和 JADC2 以及每个军种的跨域解决方案需要克服的许多结构、预算、培训和政治挑战，大多数美国军事部门和情报机构选择国防社区合作伙伴公司来帮助他们开发所需的先进技术。拥有能够产生快速技术创新的结构和人员的合作伙伴在满足此类计划成功的需求方面具有明显的优势。

**![](../Images/b64d0436c592bd068800ca112c67dcb1.png)**

**联合全域指挥与控制(JADC2)：**是美国国防部(DOD)提出的概念，将来自所有军种(空军、陆军、海军陆战队、海军和太空部队)的传感器连接到一个单一的网络中。传统上，陆军、海军、空军、海军陆战队和太空部队每个军种都开发自己的战术网络，与其他军种的战术网络不兼容(即陆军网络无法与海军或空军网络连接) - 最终将盟国伙伴整合为一个集成的“网络网络”。国防部官员认为，未来的冲突可能需要在几小时、几分钟、甚至几秒钟内做出决定，而目前需要多天的时间来分析作战环境和发布命令。

目的是通过提高态势感知并加速决策和指挥的信息优势，提高指挥与控制 (C2) 能力，以在所有领域的所有战争级别和阶段感知、理解和采取行动分散以促进高速运行。

考虑到当今世界范围内快节奏、时间敏感的威胁情况，包括潜在的近对等对手，这种能力尤为重要。作为国防部联合全域作战 (JADO)框架的 C2 组成部分，JADC2 实现对每个域——海、陆、空、太空和网络空间——的富有成效的联合指挥和控制的能力依赖于每个军种的协调合作。一个有效的 JADC2 架构将帮助指挥人员：

*   快速、彻底、直接地了解战场
    
*   比对手更快地指挥美国和盟军
    
*   在引发动态战斗之前遏制网络/数字威胁
    
*   快速协调所有领域的战斗努力
    

速度对 JADC2 成功的重要性始于快速从来源收集更多数据，但它也需要实时正确*解释这些数据。*对速度*和*信息准确性的需求是 JADC2 将人工智能 (AI) 和机器学习 (ML) 应用于海量情报、监视和侦察 (ISR) 数据的原因。人工智能和机器学习可以提供更快速的数据处理、验证、分发、分析和共享，以加速潜在或活跃冲突的每个阶段的运营准备——包括订单的发布和执行。

克服 JADC2 的挑战。尽管需要克服一系列技术、预算和政治障碍，但 JADC2 的支持者认为，它是为作战人员提供及时选择以应对美国近邻中已经在进行的“全域战”的核心必要性潜在的对手。事实上，JADC2 的一个关键目标是继续发展指挥和控制快速反应结构，以更积极地满足当前美国国防战略 (NDS) 的要求，从而为日益专制的侵略者做好准备。过去，每个军种传统上都开发、运营和指挥自己的战术网络，但这导致了特定领域的技术通常无法相互通信。JADC2 和JADO（联合全域作战）框架旨在打破这些孤岛——和孤立的思维——在所有域中加速和提高对非战场侵略的响应，以免它们成为战场冲突。

国防部如何实施 JADC2。与美国国防部这样规模和广度的任何组织一样，JADC2 等项目的实施需要时间和协调，但正在取得进展。国防部首席信息官 (CIO) 办公室和负责采办与保障的国防部副部长正在领导一个跨职能联合小组从概念上探索 JADC2，联合参谋部、空军、陆军和海军。

*   联合参谋部将 JADC2 添加到五角大楼的联合作战概念中，并指定空军作为 JADC2 的技术开发执行机构。
    
*   空军正在开发 5G 数字网络，旨在连接所有这些传感器、射击器和其他通信设备，以使 JADC2 发挥作用。它被称为高级战斗管理系统（ABMS）。
    
*   陆军未来司令部是开发 JADC2 的服务代表，包括将其作为其项目融合的一部分，以统一某些通信和目标途径。
    
*   海军的超配计划（Project Overmatch） 将成为 JADC2 的一部分，包括一个使用人工智能和有人/无人团队进行分布式海上作战的新架构。它还将删除专有网络标准，以实现与其他服务的互操作性。
    

  

控制网络的网络。作为 JADO 集成框架的指挥和控制组件，JADC2 使用通过先进战斗管理系统 (ABMS) 数字基础设施联网的众多 C4ISR 技术。它收集、处理和分析传感器数据以加快决策制定，同时还使所有领域的部队更容易安全地通信和交换数据。其中一些 C4ISR 技术包括：

*   用于多信号情报 (SIGINT) 平台的高级自适应传感器
    
*   ISR 传感器数据收集，以及高速处理、分析和分散
    
*   网络弹性系统和协议
    
*   安全的企业通信
    
*   空间系统，包括抗辐射组件、SBC、RF/IR 传感器等
    
*   安全、实时的通信、导航和识别系统
    

采用和实施 JADC2 以及 JADO 框架需要克服相当大的结构、预算、培训和政治挑战，因此大多数美国军事部门和情报机构选择国防社区合作伙伴公司进行先进技术开发。具有经验、结构和人员适应快速技术创新的合作伙伴在满足此类项目的必要需求方面具有显着优势。
