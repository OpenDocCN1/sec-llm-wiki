为支持执法部门领导继续聘用和培训分析师，制定了《分析师专业发展路线图》。该路线图的目的是为在州、地方、部落和领土组织中工作的分析师创建一个可持续的、专业的职业道路。这条路径侧重于开发和增强分析相关的知识、技能和能力，涉及三个分析师级别(初级、中级和高级)，以及为达到每个级别而推荐的培训。

在本文中，“分析员”一词通常指担任情报分析员职务的个人；然而，鼓励其他分析人员，包括犯罪分析人员适当地使用本指南。

  1. 确定初级、中级和高级分析师的共同知识、技能和能力；

  2. 为每个级别提供推荐的训练基线；

  3. 为分析师阐明一条共同的职业道路；

  4. 为分析师创造一种专业的文化；

初级:这一入门级分析员是执法或国土安全分析领域的新手，应该对犯罪分析和情报分析标准和概念有基本的了解，包括执法、国土安全、犯罪信息和情报的处理和使用。一个在基础层面的分析师应该了解犯罪和情报分析的基础，这对分析周期的每一步都是必要的。基本层次分析的基本概念包括：理解客户需求；信息来源；隐私、公民权利和公民自由问题；分析技术和协作；开发评估；产品的传播。


中级:中级分析师应该专注于保持和提高他们的能力，执行专业分析，产生战略评估，并向不同的受众呈现分析结果。此外，分析师应该开始发展特定主题领域的专业知识。中级分析员应该更深入地了解分析员在执法或国土安全环境中的角色、功能和批判性思维技巧。中级分析师还应该开始培养领导技能，可以作为新分析师的导师，应该为其他分析师提供在职培训，应该帮助制定专业发展计划。


高级:高级分析师应该有增强和扩展的分析能力。具体来说，高级分析师应该是至少一个执法或国土安全重点领域的主题专家，或监督机构的分析过程。


分析专业知识水平

路线图由三个总体的专业水平指导，旨在根据三个分析进展水平清晰地阐述分析师的知识、技能和能力。


对能力的熟悉程度：被定义为对分析通用能力有较高的认识，包括理解能力的目的和如何实现能力的能力在操作环境中的辅助角色。


要求熟练掌握的：定义为对分析通用能力的深入理解，以及对这些能力在执法或国土安全行动和产品中的应用。中级分析师应该对这些能力有更深刻的认识，并展示与能力相关的分析技能和行为指标。在操作环境中，中级分析师应该在项目开发角色中实现能力。


掌握水平：被定义为在某一学科或成就中拥有全面的知识或技能。不仅仅是分析师了解(熟悉)一个能力，并知道如何使用或实现(熟练)这个能力，分析师应该知道并理解一个能力的复杂性，包括如何培训或指导其他人使用这个能力。

初级

基层分析职位应熟悉分析共同能力。

熟悉性包括了解执法环境中的能力及其与分析人员的相关性。共同能力包括：

•     关于分析过程的法律问题

•      分析周期中的批判性思考

•      分享信息和合作

•     在执法环境中融合分析性工艺

•     向决策者传达分析意见和判断，生成分析产品

•     将概念和原则转化为行动

美国执法分析标准和执法及其他刑事司法机构最低刑事情报培训标准确定了基层培训标准。(附录A)

基层分析员应具备下列技能和能力：

•      理解分析过程

•     了解制定收集和分析计划的过程

•     了解并使用多种信息来源作为分析过程的一部分

•     使用计算机化可视化和分析工具

•     在分析过程中识别和应用各种分析技术

•     在分析过程和分析产品中适用隐私、公民权利和公民自由保护，例如适用第28CFR第23部分条例和处理个人识别信息(Pll)

•     与同行、其他机构代表和专业组织联络

•     确定社区、国家和国家面临的威胁

•     评估来源和信息的可靠性和有效性

•      提出建议和结论

•     查明信息和建议方面的差距

•     撰写对消费者相关和有用的报告和产品

教育：基层分析员至少应具备三级教育和经验中的一级：

•     获得认可高等教育机构四年学位；或

•     两年以上研究、分析和情报方面的经验；或

•     至少五年的研究、分析和面向情报的经验

培训：基础分析级别的培训课程旨在发展、维护和加强基础级别的分析能力和能力。课程包括：

•     情报分析训练基础（IALEIA、LEIU和NW3C）

•     基本情报与威胁分析课程

•      批判性思维与分析方法

•      情报写作与简报

•      情报分析员培训方案*

•      分析101(ODNI)

•     防止恐怖主义的高级刑事情报分析(NW3C)*

•      开源执业者课程*

•      风险分析介绍

此外，作为基础分析课程的前身，应完成以下工作：

•      IS-100:事件指挥系统介绍，ICS-100

•      IS-700:国家事故管理系统(NIMS)简介

•      28 CFR Part 23 培训，https://www.ncirc.gov/28CFR/ default.aspx

•      私隐线官训练，http://www.ncirc.gov/ privacylineofficer/lineofficer.swf

•      第一修正案-保护事件培训，https://www. ncirc.gov/onlinetraining/modules/first_amendment_ rollcall/index.html

•      全国可疑活动报告(SAR)线官培训，http://nsi.ncirc.gov/training_online.aspx

•      信息共享环境(ISE)核心意识训练，http://ise.gov/ise-core-awareness-training

*这些课程未被联邦应急管理局(FEMA)批准列入批准的课程目录，并符合国土安全赠款方案(HSGP)的要求（(http:// www.dhs.gov/fema-approved-intelligence-analyst-trainingcourses)。

中级

中级分析职位应精通分析共同能力，包括深入了解能力以及如何在执法或国土安全业务和产品中应用这些能力。

•      关于分析过程的法律问题

•      分析周期中的批判性思考

•      分享信息和合作

•      在执法环境中融合分析性工艺

•      交流分析观察和判断，生成分析产品

•      将概念和原则转化为行动

在业务环境中，中间层分析人员应发挥项目开发作用的能力。

中级分析培训课程最低标准确定了中级培训标准。(附录B)

中级的分析师应该

具备下列技能和能力：

•      在分析过程和产品中应用隐私、公民权利和公民自由的保护

•      审查关于潜在隐私、公民权利和公民自由相关问题的产品

•      识别个人可识别信息(Pll)以及如何在分析过程中使用Pll

•      独立分析结论

•      生成并测试假设和结论

•      将替代分析纳入分析产品

•      确定和评价信息来源

•      识别和应用结构化分析方法、技术和工具来生产分析产品

•      在分析同行和外部合作伙伴之间共享信息

•      与内部机构伙伴和外部伙伴合作

•      适当标示(带有警告和限制)产品和分析信息以供传播

•      应用技术交流和协作产品和信息

•      进行威胁、脆弱性和/或后果评估

•      开发和审查满足客户需求的分析产品

•      向指挥人员和机构伙伴通报分析产品和调查结果

•      在至少一个执法或国土安全领域展示知识a

•      管理分析项目，包括产品的开发、审查和交付

•      指导分析过程和机构政策和程序的新分析员

教育：中级分析员至少应有三级教育之一：

•      获得认可高等教育院校四年学位的至少两年研究、分析或面向情报的经验；或

•      至少五年研究、分析或具有两年学历的情报型经验；或

•      至少10年的研究、分析和情报方面的经验

培训：对中间层次的分析师的培训应侧重于提高分析过程的理解和适用性。中级培训课程可包括：

•      中级融合中心分析员培训

•      中级风险分析

•      分析201(ODNI)

•      中级情报与威胁分析课程

分析员还应参加侧重于执法和国土安全重点领域的专门培训。

高级

高级分析职位应有掌握-共同分析能力，其中包括能力的专门知识，以及如何在执法或国土安全行动和产品中监督和应用这些能力。

•    关于分析过程的法律问题

•    分析循环中的思维批判

•    分享信息和合作

•    在执法环境中融合分析性工艺

•    交流分析观察和判断，生成分析产品

•     将概念和原则转化为行动

在业务环境中，高级分析员应发挥项目监督作用的能力，或在至少一个重点领域担任分析专家。

高级培训标准在高级分析训练课程最低标准。(附录C)

高级的分析师应该掌握中级分析级的技能和能力。此外，高级分析员应至少在以下领域具备专门知识。

A.     领导/管理/监督

•     明确机构及其合作伙伴在信息共享环境中的作用和任务，以及客户群

•     评估机构分析进程的机遇和挑战

•       促进隐私权的落实权利与公民自由问题和政策

•     分析机构运作和程序如何支持区域和国家举措

•     提供领导和项目管理

•    监督分析过程的完成

•     促进信息的制作和传播

B.    专题专家

•     在至少一个执法或国土安全领域担任专题专家a

•     能够审查和加强收集和生产计划

•     能够通过使用正式的风险评估分析程序评估威胁信息的管辖权影响

•     提高分析产品的一致性、质量和防御性

•     了解分析如何告知刑事情报和警务做法(情报主导的警务等)

•     能够指导分析人员的分析过程

教育：高级分析员至少应拥有三级教育之一：

•    获认可高等教育院校颁发学士后学位及至少5年研究、分析和以情报为导向的经验；或

•    四年制学位和至少10年的研究、分析和情报方面的经验；或

•     2年研究、分析和情报方面的经验；或

•     至少15年的研究、分析和面向情报的经验

培训：高级分析员的培训应侧重于提高分析员充分实施分析过程的能力，以及参加指导员技术培训，至少参加项目管理培训。

•    海军研究生院的融合中心领导者计划

•     管理协作分析

•     网络分析课程

分析员还应当接受有关领导/管理/监督或学科的专门培训物质专门知识。
