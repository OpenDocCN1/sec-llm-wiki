PatentsView 是一个屡获殊荣的可视化、数据传播和分析平台，专注于知识产权数据。PatentsView 为学生、教育工作者、研究人员、政策制定者、小企业主和公众提供服务。它提供了一个独特且有价值的开放数据平台，提供免费的数据传播和增值分析，以促进对知识产权制度的更好了解，并推动对发明和创新的新见解。 

官网地址：https://patentsview.org/


PatentsView项目于2012年开始。测试版于2015年12月向公众发布，完整网站于2017年1月推出。2019年，该平台平均每天吸引超过77000 次应用程序接口 (API) 查询，每天访问可视化和搜索界面 167 次，以及大量直接数据集下载。 


自成立以来，合作者已经开发和部署了几个基于 Web 的工具和数据库。这些产品包括： 

专利可视化

一组图表和图形，以可访问的格式访问和探索专利数据。可视化工具允许用户搜索关键字、按位置过滤、按属性进行比较，以及查看显示大图的专利网络。 

社区合作

一个提供协作空间的管理社区，例如讨论论坛和 Data in Action Spotlight。Data in Action Spotlight 是使用通过 PatentsView 网站提供的数据和工具完成的研究的集合。 

API 工具

API 工具允许软件开发人员和研究人员在其本地环境中使用我们的数据。文档可用于 API 工具以及用于搜索和过滤数据的查询字符串格式列表。 

数据查询生成器

用户友好的查询构建器界面，允许用户根据特定的搜索条件创建自己的数据集。查询生成器不同于 API 工具。通过提供发送到用户电子邮件地址的链接，可以使用任何自定义查询的最终数据集。   

批量数据下载

提供用于创建网站及其可视化的数据的页面。它被拆分为包含原始数据、已消除歧义或已处理数据的各种表。该页面还提供 Python 和 R 程序，旨在帮助在下载数据后读取数据。
