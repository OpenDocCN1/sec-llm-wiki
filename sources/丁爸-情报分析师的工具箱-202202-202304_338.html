“web3”是一个总称，指的是“互联网的未来”，相信会去中心化并基于区块链。支持者倾向于吹捧数据将如何不受“大科技”的控制，以及它将如何不受审查和平等。

被描述为 web3 的往往包含以下一些内容：

  • 各种加密货币

  • 去中心化自治组织（DAO）

  • 去中心化金融（DeFi）

  • 不可替代代币（NFT）

  • 智能合约


违法犯罪使用去中心化的加密货币与通讯越来越普遍，如何追踪和利用这些新技术也是情报分析师需要关注的内容。


今天丁爸就给大家推送一些web3相关的资源、工具网站。


  1. 以太坊侦探

https://ethtective.com/

可视化显示交易的时间、数量和地址并支持扩展挖掘追踪。

2、加密货币标志

https://cryptologos.cc/

Crypto Logos 是经过精心策划的专业准备的高质量加密货币徽标文件的集合，这些文件易于访问和免费下载。

3.Breadcrumbs

https://www.breadcrumbs.app/

Breadcrumbs 是一个所有人都可以访问的区块链分析平台。它提供了一系列用于调查、监控、跟踪和共享区块链交易相关信息的工具。

4.Esteroids

http://www.esteroids.xyz/

Esteroids 是 Web3 社区发现去中心化网络的工具。

5.Web3 Is Going Great

https://web3isgoinggreat.com/

Web3 Is Going Great 是一个跟踪区块链/加密/web3 技术领域中的事件的网站。包括跟踪加密货币和基于区块链的技术中的事件，可追溯到 2021 年初。

6.龙卷风（Tornado）

https://www.tornadoweb.org/

Tornado是一个 Python Web 框架和异步网络库，最初在FriendFeed开发。通过使用非阻塞网络 I/O，Tornado 可以扩展到数万个打开的连接，使其成为  long polling、 WebSocket和其他需要与每个用户长期连接的应用程序的理想选择。



7.GraphQL

https://graphql.org/

GraphQL 是一种 API 查询语言，也是一种使用现有数据完成这些查询的运行时。GraphQL 为您的 API 中的数据提供了完整且易于理解的描述，使客户能够准确地询问他们需要什么，仅此而已，使 API 更容易随着时间的推移而发展，并支持强大的开发人员工具。

8.infura

https://infura.io/

强大的区块链开发套件。
