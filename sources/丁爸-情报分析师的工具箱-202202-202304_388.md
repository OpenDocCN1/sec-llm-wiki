# 【资讯】四家提供位置监控的美国公司

**一、X-Mode**

X-Mode Social 成立于 2013 年，是一家位于弗吉尼亚州雷斯顿的美国公司。X-Mode 专门收集智能手机位置数据集。2021 年 8 月，该公司被 Digital Envoy 收购。

X-Mode使用XDK 收集信息，包括

1.  精确的位置数据：
    

*   设备的地理位置，通常通过我们的 XDK 的 GPS 功能、WiFi 数据、蜂窝塔三角测量等技术获得的经纬度坐标表示。
    
*   兴趣点附近的停留时间（或您的设备在一个地方停留的时间）。
    

*   相对位置数据：
    

*   蓝牙低功耗 (BLE) 传感器或信标，
    
*   来自物联网 (IoT) 设备的信号。
    
*   近场通信 (NFC)
    
*   我们 XDK 的 GPS 功能允许它接收来自这些技术的信号，这些信号显示设备何时靠近。例如，许多零售店都有信标，可以检测蓝牙设备何时经过或进入商店。购物中心、体育场、餐馆、博物馆和其他类似的兴趣点也可以使用信标。
    

*   广告 ID 或用于广告的唯一设备标识符（Android ID 或 iOS IDFA）
    
*   时间和日期信息
    
*   关于您的设备的事件信息，包含：
    

*   任何崩溃
    
*   系统活动
    
*   硬件设置
    

*   使用数据是自动收集的，无法识别个人用户，包含：
    

*   设备类型（即 iPhone 7）
    
*   操作系统版本和类型（即 iOS 13.2）
    
*   设备设置（例如您是否启用了定位服务）
    
*   设备时区
    
*   设备载体
    
*   当前 IP 地址
    

官网地址：https://xmode.io/

**二、venntel**

 venntel位于美国弗吉尼亚州赫恩登，从事数据处理、托管和相关服务。是从个人那里收集信息的公司，包括他们的移动设备的位置信息。

| **信息类别** || **收集信息的描述** |
| --- | --- |
| 身份标识 || IP 地址，以及以下信息（如果您选择提供给我们）：姓名、电子邮件地址、电话号码；工作和公司信息，以及状态 |
| 设备信息 || 您的浏览器类型和操作系统、时区设置和位置、浏览器插件类型和版本。 |
| 互联网或网络活动 || 您查看的网页、您点击的链接、您访问我们网站的时间长度以及引导您访问我们网站的网页。 |
| 通讯偏好 || 您在接收我们的营销信息方面的偏好以及您的沟通偏好。 |
| 专业或就业信息 || 如果您申请工作，当前或过去的工作经历或绩效评估。 |

  

| **信息类别** || **收集信息的描述** |
| --- | --- |
| 位置数据 || 精确的地理位置数据，包括通过向移动设备操作系统发出请求从移动应用程序获得的经纬度坐标，移动设备操作系统利用各种机制来获取位置数据，包括 GPS 工具、蜂窝塔三角测量、WiFi 数据或其他技术。我们不会实时收集您的精确地理位置。Venntel 及其第三方数据合作伙伴都无法确定位置数据是否来自 GPS 信号、蜂窝塔三角测量、WiFi 数据或其他技术。设备操作系统确定设备最容易获得哪个信号，并将位置数据返回给相应的移动应用程序提供商。 |
| 身份标识 || IP地址; 移动广告商 ID（“MAID”）；哈希电子邮件 |
| 互联网或网络活动 || 时间戳，从其接收位置信号的移动应用程序列表。 |
| 设备用户代理数据 || 设备类型; 浏览器系列；浏览器版本；操作系统; 操作系统版本；设备型号，运营商数据。 |
| 人口统计数据 || 年龄、性别、世代后缀、婚姻状况、父母状况、子女数量、教育程度、年收入。 |
| 出价流数据 || Venntel 不会收集移动广告竞价流数据来支持我们的数据服务。我们同样要求我们的第三方合作伙伴不要提供来自移动广告竞价流的数据。 |

 

| **信息类别** || **收集信息的描述** |
| --- | --- |
| 用户数据 || 您或您的公司提供的姓名和电子邮件地址，以便 Venntel 可以让您创建一个帐户来访问门户。 |
| 使用数据 || 这是 Venntel 在您访问和/或使用门户网站时收集的关于您的信息，包括：会话信息（登录时间、使用时间、注销时间、搜索次数、搜索性质） |

官网地址：https://www.venntel.com/  

  

**三、**Anomaly Six****

Anomaly Six是美国媒体情报公司。它向美国政府和私营部门销售全球位置数据产品。该公司已将其软件嵌入到500多种移动应用程序中，使其能够跟踪数以亿计的手机。在一次演示中，该公司声称可以实时跟踪30亿个电话。该公司由两名前军事情报官员于2018年创立。它位于弗吉尼亚的亚历山大。
