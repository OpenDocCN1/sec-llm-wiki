今天给大家介绍一个开源且免费的情报分析工具---Gephi

官网地址：https://gephi.org/

官网介绍：

Gephi是数据分析师和热衷于探索和理解图表的科学家的工具。与Photoshop™类似，但用于将数据进行图形展示，可与用户进行交互，操作结构、形状和颜色，以揭示数据隐含的信息。其目标是帮助数据分析师在数据来源过程中做出假设，直观地发现特殊模式，突出显示结构重点或错误。它是传统统计的补充工具，因为带有交互界面的视觉思维，因而被认为有助于推理。这是一个探索性数据分析的软件，一个出现在视觉分析研究领域的范例。

从最快的图形可视化引擎中获益，以加快对大型图形的理解和模式发现。Gephi 在其 ad-hoc OpenGL 引擎的支持下，正在推动网络探索的交互性和高效性。

  • 网络多达 100,000 个节点和 1,000,000 条边

  • 使用动态过滤遍历可视化

  • 用于有意义的图形操作的丰富工具

布局算法赋予图形形状。Gephi 提供最先进的算法布局算法，无论是效率还是质量。布局调色板允许用户在运行时更改布局设置，从而显著增加用户反馈和体验。

  • 基于力的算法

  • 优化图形可读性

统计和指标框架为社交网络分析 (SNA) 和无标度网络提供了最常见的指标。

  • 中心性、紧密度、直径、聚类系数、网页排名

  • 群检测（模块化）

  • 随机发生器

  • 最短的路径

随着时间的推移网络

Gephi 是动态图分析的创新前沿。用户可以通过操纵嵌入的时间线来可视化网络如何随时间演变。

  • 使用 GEXF 文件格式导入时态图

  • 随着时间的推移运行指标（聚类系数）

  • 图形流准备就绪

创建制图

使用排名或分区数据使网络表示有意义。自定义颜色、大小或标签，为网络表示带来意义。矢量预览模块可让您在使用 SVG 或 PDF 进行探索之前进行最后的润色并关注美学。

  • 可定制的 PDF、SVG 和 PNG 导出

  • 保存预设

动态过滤

根据网络结构或数据过滤网络以选择节点和/或边。使用交互式用户界面实时过滤网络。

  • 无需脚本即可创建复杂的过滤器查询

  • 从过滤结果构建新网络

  • 保存您最喜欢的查询

数据表和版本

Gephi 拥有自己的数据实验室，具有类似 Excel 的界面来操作数据列、搜索和转换数据。

  • 强大的搜索/替换

  • 操作列

  • 批量编辑、自定义列合并等

支持导入输出

Gephi 可以读取大多数图形文件格式，但也支持 CSV 和关系数据库导入。

  • 电子表格导入向导

  • 数据库导入

  • 保存/加载项目文件

可扩展

内置插件中心自动从 Gephi 插件门户获取可用插件列表，并负责所有软件更新。有几十个社区构建的插件扩展了 Gephi 的功能。
