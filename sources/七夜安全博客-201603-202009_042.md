## 恶意软件集合

### 匿名代理

*对于分析人员的 Web 流量匿名方案*

*   Anonymouse.org - 一个免费、基于 Web 的匿名代理
    
*   OpenVPN - VPN 软件和托管解决方案
    
*   Privoxy - 一个带有隐私保护功能的开源代理服务器
    
*   Tor - 洋葱路由器，为了在浏览网页时不留下客户端 IP 地址
    

### 蜜罐

*捕获和收集你自己的样本*

*   Conpot - ICS/SCADA 蜜罐
    
*   Cowrie - 基于 Kippo 的 SSH 蜜罐
    
*   DemoHunter - 低交互分布式蜜罐
    
*   Dionaea - 用来捕获恶意软件的蜜罐
    
*   Glastopf - Web 应用蜜罐
    
*   Honeyd - 创建一个虚拟蜜罐
    
*   HoneyDrive - 蜜罐包的 Linux 发行版
    
*   Mnemosyne - 受 Dinoaea 支持的蜜罐数据标准化
    
*   Thug - 用来调查恶意网站的低交互蜜罐
