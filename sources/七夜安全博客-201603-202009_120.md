**3.3**

最后分析**password**的加密方式:搜索password,发现敏感内容。 

　　http://passport.bdimg.com/passApi/js/login\_tangram\_a829ef5.js

  
![](../Images/cfb7b8d2e622af7ccd144619cdd81057.png)  
![](../Images/a21af5df76da89f74c778490e4af9abd.png)  

通过下断点，动态调试可以知道password，是**通过公钥pubkey对密码进行加密，最后输出进行base64编码**，

上图的xn()就是在进行base64编码。

 

如果大家对javascript的RSA加密不熟悉，可以推荐　　　　          　　　　   https://github.com/travist/jsencrypt/blob/master/src/jsencrypt.js。

等你看完了这个开源项目，你会发现，百度使用的RSA加密函数和上面的连命名几乎一样，这也就是为什么能这么快分析出RSA加密的原因。

**3.4** 

如何使用**python进行RSA加密**呢 

采用的是RSA加密方式：

from Crypto.PublicKey import RSA

from Crypto.Cipher import PKCS1\_v1\_5

password = 'xxxxxxxx'

with open('pub.pem') as f:

    pubkey = f.read()

    rsakey = RSA.importKey(pubkey)

    cipher = PKCS1\_v1\_5.new(rsakey)

    cipher\_text = base64.b64encode(cipher.encrypt(password))

    print cipher\_text
