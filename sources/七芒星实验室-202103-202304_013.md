# UWA\_2.3.11\_后台新建模板getshell

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MTU4NTc2Nw==&mid=2247489148&idx=1&sn=ebad38f44aca85a834951c027827ac3b&chksm=64cc8764c98ccee21e17fc3fa7f05bc4776fff581dfdd51e9b0228524a8f94558ae128471e54&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg4MTU4NTc2Nw==&mid=2247489148&idx=1&sn=ebad38f44aca85a834951c027827ac3b&chksm=64cc8764c98ccee21e17fc3fa7f05bc4776fff581dfdd51e9b0228524a8f94558ae128471e54&scene=27#wechat_redirect)

#### 影响范围

UWA 2.3.11

#### 漏洞类型

新建模板getshell

#### 利用条件

登陆管理后台

#### 漏洞概述

UWA 2.X是如斯(AsThis)基于 PHP 和 MySQL 开发的通用建站系统，程序简洁、灵活而具备强大的扩展性，是轻松建站的首选利器。  
UWA 2.3.11后台允许自定义php模板文件，且在保存时未对PHP文件中的内容做合法性校验，导致攻击者在登陆后台的情况下可以写入一句话木马进去，之后getshell。
