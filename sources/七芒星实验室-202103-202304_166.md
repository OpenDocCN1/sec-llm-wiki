#### 文章前言

IIS Raid是本机的一个IIS模块，通过滥用IIS的可扩展性可以实现一个Web服务器后门并执行攻击者定义的自定义操作，本篇文章主要介绍IIS-Raid的构建和使用过程

#### 测试环境

目标主机：Windows Server 2012 64位 Standard

目标版本：IIS 8.5
