# CVE-2022-0847:DirtyPipe本地提权

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MTU4NTc2Nw==&mid=2247486318&idx=1&sn=dcfb04404bab779524e68a732cafd620&chksm=cf62f066f81579703aca5ecf6f82afe1c53096fbbbd833b45e85cbbac7d1460204e351dbb933&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg4MTU4NTc2Nw==&mid=2247486318&idx=1&sn=dcfb04404bab779524e68a732cafd620&chksm=cf62f066f81579703aca5ecf6f82afe1c53096fbbbd833b45e85cbbac7d1460204e351dbb933&scene=27#wechat_redirect)

#### 影响范围

Linux kernel 5.8 later

#### 漏洞类型

本地权限提升

#### 利用条件

影响范围应用

#### 漏洞概述

2022年3月7日，国外安全研究人员马克斯·凯勒曼在其博客中披露了一处存在于Linux内核中的本地提权漏洞，该漏洞允许非特权用户通过注入和覆盖任意只读文件中的数据(例如:/etc/passwd等)，攻击者可以利用该特性从而实现权限提升，漏洞编号为CVE-2022-0847，该漏洞CVSS评分:7.8，危害等级:高危
