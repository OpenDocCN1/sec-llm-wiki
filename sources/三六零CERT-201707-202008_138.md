## 0x00 漏洞背景

2020年02月16日， 360CERT对微软 2 月份安全更新中的CVE-2020-0618SQL Server 远程命令执行漏洞进行资产测绘时发现，SQL Server 在国内使用量大，存在危害面。

**！！相关分析与PoC已在互联网公开**

Microsoft SQL Server(微软结构化查询语言服务器)是由微软公司所推出的关系型数据库解决方案。

该漏洞需要经过身份验证后，攻击者向 SQL Server 的报告服务(Reporting Services) 发送特制请求进行触发。攻击成功可获得SQL Server服务的对应控制权限。

## 0x01 风险等级

360CERT对该漏洞进行评定

| 评定方式 || 等级 |
| --- | --- |
| 威胁等级 || 高危 |
| --- | --- |
| 影响面 || 广泛 |

360CERT建议广大用户及时更新 SQL Server 软件版本。做好资产 自查/自检/预防 工作，以免遭受攻击。
