# 【2018 ISC】360首届数学黑客挑战赛即将启动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5MjEzOTM3NA==&mid=2247485637&idx=1&sn=a92537ff2f56b33519ef8a6df6aee996&chksm=fe250dc4c95284d2f819ca381fbbb18dff3d38c5aa76727609adab781d468f01dbc17ca74b9a&scene=126&sessionid=1681374272#rd](http://mp.weixin.qq.com/s?__biz=MzU5MjEzOTM3NA==&mid=2247485637&idx=1&sn=a92537ff2f56b33519ef8a6df6aee996&chksm=fe250dc4c95284d2f819ca381fbbb18dff3d38c5aa76727609adab781d468f01dbc17ca74b9a&scene=126&sessionid=1681374272#rd)

2018年9月4日，360首届数学黑客挑战赛将会在2018 ISC互联网安全大会上正式启动，大赛采用线下挑战的方式进行。

  

各位挑战者需要去ISC现场（**北京国家会议中心** / **2018 ISC **/ **360-CERT展台现场（A27）**）领取挑战赛的题目进行作答，题目一共三道，正确完成第一题，才有资格领取第二题，同理第三题。只要正确作答每一道题目都会有神秘奖品发放，也可以在360CERT展台背景板留言签名。

  

最后成功挑战三道题目的将有机会赢得**Apple iPhoneX手机**或者直接成为**360CERT正式员工**。
