# 360CERT安全专家redrain受邀参加Syscan360 2018

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5MjEzOTM3NA==&mid=2247485243&idx=2&sn=7671a23c431df57b44179bf6f7015515&chksm=fe25023ac9528b2c8f442ba72442a64a0b244343c52a1e0bc57b0375c49ead0346e997b3d0a6&scene=126&sessionid=1681374292#rd](http://mp.weixin.qq.com/s?__biz=MzU5MjEzOTM3NA==&mid=2247485243&idx=2&sn=7671a23c431df57b44179bf6f7015515&chksm=fe25023ac9528b2c8f442ba72442a64a0b244343c52a1e0bc57b0375c49ead0346e997b3d0a6&scene=126&sessionid=1681374292#rd)

3月23日，360CERT安全专家redrain受邀赴新加坡参加Syscan360前瞻信息安全技术年会，并在Expert Panel专家圆桌会议讨论分享网络安全应急响应趋势和相关研究成果。

![](../Images/a362bdb4724a4d3fd625b6f4bedc3503.png)

redrain在会议中介绍道360CERT团队：我们专注于网络安全事件的应急响应，例如加密劫持、恶意软件分析，僵尸网络追踪，威胁捕捉等。虽然目前还是一个年轻的团队，但已经取得了不小的成绩。

去年我们及时处理了影子经纪人黑客组织的网络武器泄露事件，WannaCry勒索病毒事件，ccleanner、xshellghost供应链攻击等一系列安全事件在国内的影响。可以说我们的团队富有社会责任感和安全使命感。

![](../Images/736ac97bce88db4d1fd9a9c85b7e3327.png)

同时在技术方面，redrain也与业内专家进行了深度对话：

我们一直都保持着较高的研究水准，其中包括应用二进制系统。并且曾经在HITB, Bluehat, Ruxcon, Syscan360等安全会议分享研究成果。

计算机安全应急需要各方面团结协作，所以我们就如同庞大安全体系中的一个枢纽，获取有价值的数据和技术来对事件进行分析和协调。
