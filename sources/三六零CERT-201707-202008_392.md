# 苹果系统App Store 偏好设置菜单任意密码解锁

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5MjEzOTM3NA==&mid=2247484784&idx=1&sn=29144cf53192186f7b718471bdaef87b&chksm=fe250071c952896753b3f676fdf255713bc8f1597583c852b9012b5059e675ccc2ba1befd95b&scene=126&sessionid=1681374307#rd](http://mp.weixin.qq.com/s?__biz=MzU5MjEzOTM3NA==&mid=2247484784&idx=1&sn=29144cf53192186f7b718471bdaef87b&chksm=fe250071c952896753b3f676fdf255713bc8f1597583c852b9012b5059e675ccc2ba1befd95b&scene=126&sessionid=1681374307#rd)

Open Radar 网站本周发布的一份漏洞报告曝光了当前 macOS High Sierra 系统版本的一个安全漏洞。360 信息安全部分析，该漏洞导致 App Store 在偏好设置中的菜单可以使用任意密码解锁，进而控制部分系统配置项。

  

该漏洞存在于 macOS Sierra 10.2.6 以上的版本中，**建议用户要养成要养成离开电脑时，及时锁屏的习惯。**
