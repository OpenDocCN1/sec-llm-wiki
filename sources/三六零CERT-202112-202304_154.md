 漏洞简述  
  
  

2022年11月30日，360CERT监测发现`Apache`发布了`Apache Fineract`的风险通告，漏洞编号为`CVE-2022-44635`，漏洞等级：`高危`，漏洞评分：`7.5`。

Apache Fineract是用于金融服务的开源软件，旨在实现核心银行系统平台化建设。

对此，360CERT建议广大用户及时将`Apache Fineract`升级到最新版本。与此同时，请做好资产自查以及预防工作，以免遭受黑客攻击。

3  
 漏洞详情  
  
  

### CVE-2022-44635: Apache Fineract 文件上传漏洞

CVE: CVE-2022-44635

组件: Fineract

漏洞类型: 文件上传

影响: 代码执行

简述: 该漏洞存在于 Apache Fineract 的文件上传组件中，该组件由于对上传路径处理不当存在目录穿越问题，经过身份验证的攻击者可以利用该漏洞在远程服务器上上传恶意文件并执行任意代码。
