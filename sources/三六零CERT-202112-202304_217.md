 漏洞简述  
  
  

2022年09月22日，360CERT监测发现`Microsoft官方`发布了`Microsoft Endpoint Configuration Manager（MECM）`的风险通告，漏洞编号为`CVE-2022-37972`，漏洞等级：`高危`，漏洞评分：`7.5`。

Microsoft Endpoint Configuration Manager（MECM）是一种本地管理解决方案，用于管理网络上或基于 Internet 的台式机、服务器和笔记本电脑。用户可以通过云启用它以与 Intune、Azure Active Directory (AD)、Microsoft Defender for Endpoint 和其他云服务集成。

对此，360CERT建议广大用户及时将`MECM`升级到最新版本。与此同时，请做好资产自查以及预防工作，以免遭受黑客攻击。

 漏洞详情  
  
  

### CVE-2022-37972: Microsoft MECM信息泄露漏洞

CVE: CVE-2022-37972

组件: MECM

漏洞类型: 信息泄露

影响: 敏感数据泄漏

简述: 该漏洞存在于Microsoft Endpoint Configuration Manager 版本 2103-2207中，攻击者可以利用此漏洞获取敏感信息。

| :-: | :-: | :-: |
| Microsoft Endpoint Configuration Manager || 2103-2207 || 应用 KB15498768 补丁 |

  
5  
 修复建议  
  
  

### 临时修补建议

目前微软官方已经发布此漏洞的安全更新，（KB15498768：当禁用“允许连接回退到 NTLM”选项时，该更新可防止对客户端推送安装进行 NTLM 身份验证的任何尝试 ）。对于运行 Microsoft 端点配置管理器 2103 -2207 版本的客户，将在配置管理器控制台的更新和服务节点中列出该更新。

补丁链接：*https://learn.microsoft.com/zh-cn/mem/configmgr/hotfix/2207/15498768*

使用 2103 之前的 Configuration Manager 当前分支版本的环境更新到受支持的更高版本。管理员还可以禁用自动和手动客户端推送安装方法。
