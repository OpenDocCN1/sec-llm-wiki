1  
 简述  
  
  

目前360CERT了解到，组织机构在排查`Spring`漏洞时，仅以jar包的文件名，或路径中包含特定字符串为检测和排查标准。该方式存在一定的误报，360CERT根据实战攻防经验，特别为业界的安全人员研发了一款在磁盘中扫描存在漏洞的 class 文件扫描工具，希望能够帮助安全人员减轻负担，提升调查响应效率！

该工具可以自动递归扫描`zip、jar、war、ear、fatJar`此类常见 zip 衍生格式。

```


http://pub-shbt.s3.360.cn/cert-public-file/jarhash-check-darwin-amd64
```

```


0d07930cedede1c3495db1dd4486c211  jarhash-check-darwin-amd64
```

  
2  
 使用指南  
  
  

以 linux x64 为例：

```


./jarhash-check
```

以搜索 war包为例：

```


jarhash-check -d ./spring-demo.war
```

list 显示指定 jar 包的所有 class sha256hash：

```


./jarhash-check -d ./spring-beans-5.3.17.jar -l
```

  
3  
 扫描原理  
  
  

360CERT 经过分析定位到存在问题的2个重点class文件：

```


org/springframework/validation/DataBinder.class
```
