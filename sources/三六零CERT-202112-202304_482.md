### CVE-2021-45046: Log4j 2 远程代码执行漏洞通告

标签: \["影响面 大" "组件类型 日志"\]

链接: https://cert.360.cn/warning/detail?id=fc08131e1735eb44a99798f464f51579

2021年12月17日，360CERT监测发现Apache Log4j发布了远程代码执行的风险通告，漏洞编号为CVE-2021-45046，漏洞等级：严重，漏洞评分：9.0。

该漏洞为 CVE-2021-44228 修复的绕过，在某些特殊配置的情况下可能造成远程代码执行，虽然 log4j 2.15.0 默认情况下的修复将 JNDI LDAP Lookup 限制为 localhost ，但存在绕过。

### CVE-2021-42550: Logback 远程代码执行

标签: \["影响面 一般" "组件类型 日志"\]

链接: https://jira.qos.ch/browse/LOGBACK-1591

该漏洞被认为比 log4shell 构成的威胁要小，因为它需要攻击者访问 logback 的配置文件。

### 国家资助的黑客滥用SlackAPI窃取航空公司数据

标签: \[State-sponsored hackers Slack API steal data airline muddywater \]

链接: https://www.bleepingcomputer.com/news/security/state-sponsored-hackers-abuse-slack-api-to-steal-airline-data/

一个被怀疑是伊朗政府支持的攻击者正在部署一个新发现的名为“aclip”的后门，它滥用Slack API进行秘密通信。

该攻击者的活动始于2019年，并以一家不知名的亚洲航空公司为目标，窃取航班预订数据。

根据IBM security x-force的一份报告，攻击者可能是itg17，又名“muddywater”，这是一个非常活跃的黑客组织，在全球范围内维护着一个目标组织。

### Phorpiex僵尸网络以新的技巧回归，使其更难被破坏

标签: \[phorpix botnet \]

链接: https://www.bleepingcomputer.com/news/security/phorpiex-botnet-returns-with-new-tricks-making-it-harder-to-disrupt/

以前关闭的phorpix僵尸网络重新出现了新的点对点命令和控制基础设施，使恶意软件更难以破坏。

phorpiex于2016年首次上线，多年来迅速积累了超过100万台设备的庞大军队。

该恶意软件通过交换复制到Windows剪贴板上的加密货币地址(地址在他们的控制之下)，或者通过发送性勒索邮件来恐吓人们支付勒索要求，为其开发者创造收入。

### 为了更快的攻击，Emotet再次开始投掷Cobalt Strike

标签: \[emotet cobalt strike \]

链接: https://www.bleepingcomputer.com/news/security/emotet-starts-dropping-cobalt-strike-again-for-faster-attacks/

正值假期，臭名昭著的emotet恶意软件再次直接安装cobalt strike进行攻击，以进行快速网络攻击。

对于那些不熟悉emotet的人来说，它被认为是最广泛的恶意软件感染之一，通过包含恶意附件的钓鱼邮件传播。

从历史上看，一旦一个设备被感染，emotet会窃取受害者的电子邮件，以便在未来的活动中使用，然后丢弃恶意软件的有效负载，如trickbot和qbot。

### 伊朗和中国国家黑客利用Log4j漏洞

标签: \[China Cyber Attack Iran Log4j Mandiant security Vulnerability \]

链接: https://www.hackread.com/irani-chinese-hackers-exploit-log4j-vulnerability/

根据John hultquist，情报分析，mandiant公司的副总裁，伊朗国家黑客特别攻击log4j漏洞。

网络安全公司mandiant和crowdstrike已经证实，伊朗和中国的国家攻击者者正在利用最近发现的log4j或log4shell漏洞，许多其他行动者正计划利用它。

一些报告显示，朝鲜和土耳其的黑客也在利用log4j漏洞进行恶意攻击。

### 美国CISA命令联邦机构在12月24日前修复Log4Shell

标签: \[log4shell vulnerability CISA \]

链接: https://securityaffairs.co/wordpress/125623/security/cisa-log4shell-actions.html

美国cisa命令联邦机构在2021年12月24日之前解决log4j库中关键的log4shell漏洞。

该命令旨在防止攻击者利用该漏洞攻击政府系统。

### 新的无文件恶意软件使用Windows注册表作为存储，以逃避检测

标签: \[javascript pact darkwatchman \]

链接: https://thehackernews.com/2021/12/new-fileless-malware-uses-windows.html

一种新的基于javascript的远程访问木马(rat)通过社会工程传播，被观察到使用的“无文件”技术作为其逃避检测方法的一部分。

该恶意软件被反间谍联盟(pact)的研究人员命名为“darkwatchman”，它使用一种弹性域生成算法(dga)来识别其指挥与控制(c2)基础设施，并利用Windows注册表进行所有存储操作，从而使它能够绕过反软件引擎。

### APT-C-53（Gamaredon）内网后渗透攻击技战术分析

标签: \[APT APT-C-53\]

链接: https://mp.weixin.qq.com/s/OfDTcrTVAgjACeh0Z5wi7w

共享内容污染(Taint Shared Content)是指通过向共享内容添加恶意内容的方式感染其他阅读该共享内容用户计算机的手段，属于横向移动中的重要技巧之一，Gamaredon组织向受害用户Word文档添加模板或VBA宏的手段就属于其中之一。长期以来，国内外安全研究员频繁捕获含有Gamaredon组织恶意模板链接的Word文档，针对这些文档，360高级威胁研究院借助安全大脑的数据进行了溯源调查，发现了Gamaredon的文档感染模块。

### Aggah针对乌克兰、立陶宛和意大利的信息窃取行动

标签: \[APT Aggah\]

链接: https://yoroi.company/research/serverless-infostealer-delivered-in-est-european-countries/

自2019年以来，Yoroi一直在跟踪Aggah组织，其恶意攻击活动的持久性随着时间的推移揭示了结构化的信息窃取攻击框架。Yoroi发现了该组织针对全球多个受害者的信息窃取和侦察行动，包括乌克兰、立陶宛和意大利。整个活动影响了数百名受害者，持续了两个月。
