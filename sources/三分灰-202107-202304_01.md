# 十几块钱的随身WIFI，被网友魔改成了服务器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzODgxMDYyNA==&mid=2247484313&idx=1&sn=425af0000cbc39337793dc7140fe497c&chksm=e932e0f6de4569e0abe650324456ed92c311c79e0fb59af4a867fade7c7261cdafc5ddf00b3b&scene=126&sessionid=1681657023#rd](http://mp.weixin.qq.com/s?__biz=MzIzODgxMDYyNA==&mid=2247484313&idx=1&sn=425af0000cbc39337793dc7140fe497c&chksm=e932e0f6de4569e0abe650324456ed92c311c79e0fb59af4a867fade7c7261cdafc5ddf00b3b&scene=126&sessionid=1681657023#rd)

随身 WIFI 想必大家都不陌生，就是下面这种像 U 盘一样的玩意儿。

![](../Images/b3d8b7b42570800b643885bf26a5d57d.png)

随插随用，插到电脑或者充电宝上就能使用。

插上后会开启一个热点，用于手机电脑等设备连接 WIFI，并且插到电脑上时可以直接当宽带使用，电脑不需要再连接 WIFI。

由于使用方便和便于携带，受到大众的喜爱。

本来按常理来说，这玩意儿就一个提供热点的功能。

但是偶然看到 B 站上的 up 主们，给它刷系统，装风扇，魔改成了下面这个样子。

![](../Images/80c8c5b93a3ea943d9a41c6824cb266b.png)

当时真是惊呆我了！这是啥操作啊？

仔细看了看 up 主们的视频，大概了解了来龙去脉。

up 主们大都是用的某贝的随身 WIFI，该款随身 WIFI 搭载的是高通 410 系列的处理器。

网上有个 OpenStick 项目，是某大佬针对该系列处理器进行的 Linux 移植。文档地址：https://www.kancloud.cn/handsomehacker/openstick/2636506

![](../Images/c56a3b166b2817715d6a00222c7baee9.png)

感兴趣的可以自己去看看。

有了这个项目，随身 WIFI 也就能刷入 Linux 了。

而且是完整的 Linux。

我们都知道，服务器上跑的就是 Linux 系统。

刷入 Linux 之后，它可以跑 Docker、搭网站、挂 QQ 机器人、青龙面板等等。服务器能干的事它都能干，妥妥的就是一台 mini 服务器。

功耗还低，不过性能也有点低。

但是嘛，十几块的东西，都这么便宜了还要什么自行车。

有老哥直接给它接上了硬盘 + 网线，秒变 NAS。

还有上面加装风扇的骚操作！也不知道是要拿来跑什么。

我在小黄鱼上整了一个别人刷好的，大概 800 多 M 内存，15 G 容量的样子。

![](../Images/4f27238bb0584ac9dfb11a0633beb600.png)

装了个 Docker ，用来跑 Alist 挂网盘。如上图，一共占了 200 M 内存左右。

![](../Images/b03b592a27c918d5d32e79e28c34652b.png)

也没加装风扇，倒是没怎么发热，可能是只跑了一个服务的原因。终端上输命令也还挺流畅，不会卡顿。

这玩意儿，其实厂家的本意，是想卖它里面的物联网卡套餐。

虽然它才十几块一个，但是你还得买他们的套餐才能用，不然你连上热点也上不了网。

他们赚的就是这个套餐的钱。

没曾想，被网友们给薅了羊毛。

不过我也真的佩服这些动手能力强，爱折腾的人。

一个小小的随身 WIFI ，也被他们玩出花来。

果然，**生命的意义在于折腾。**
