0x01

今天闲着无事，用 FOFA 扫网站，然后扫到一个塑料膜公司的网站，网站看着挺旧的，猜想应该存在漏洞，然后就想着友情检测一波，网站首页长这样

是个 ASP 的站


0x02

直接拿扫描器扫一波网站目录

猜测 /manage/login.asp 应该就是后台地址了，浏览器打开，果不其然，熟悉的后台登录界面

并且我还发现扫到了名为 database 的目录，猜想应该是存放数据库文件的目录，不过扫描器显示 403，用浏览器访问，确实显示 403，并且得到了网站绝对路径为 C:\inetpub\wwwroot\，不过暂时好像没啥用

不管了，先尝试弱口令登录后台吧，一番操作之后......果然登录失败！

这时突然想起首页的产品，数据应该是动态的，点击一个进入详情，果然发现参数放在了地址上，第一时间就想到 sql 注入，直接加个单引号测试，结果被拦截，弹出如下提示

然后又尝试了 and，union，order by 等，要么就提示参数有非法字符，要么就直接参数错误，猜测这里应该的 id 参数应该只允许为数字，没办法，只能另寻它路了


0x03

想起首页还有个搜索框，搜索框总不能只允许数字了吧？首先搜索 炫彩膜，只返回一条数据，这是搜索，所以直接使用搜索常用的 payload

炫彩膜%' or 1=1 and '%'='

发送请求，发现返回了全部数据，所以搜索框这里确实存在 sql 注入，但是没找到利用方法，用 sqlmap 尝试了，也显示存在 sql 注入漏洞

但是 sqlmap 爆不出它的表，因为这是 Access 数据库，无法猜解表名，只能用字典爆破，很遗憾我的字典里并没有它里面的表名，所以无法爆出


0x04

sql 注入似乎行不通，看到首页还有个留言，我又想到了 xss，打算碰碰运气

姓名输入框似乎有长度限制，直接 F12 改代码

原本限制 20，我直接给他改成 200，正常输入，但是提交又出问题了

估计数据库也限制了字段长度，算了，姓名就不 xss 了，随便填一个，然后提交，发现电话也有长度限制，我淦，最后只在邮箱和留言内容插了代码

显示等待管理员审核，于是我赶紧又插了一段窃取 cookie 的 xss 代码，懒得用 beef 加内网穿透，就随便网上找了一个 xss 平台，复制它的 xss 代码

只要网站存在 xss，并且管理员进入到留言审核界面，那么我就可以窃取他的 cookie，从而登录后台。

可惜的是，我等了好几天，也没一点反应


0x05

xss 似乎也行不通，难道就这样放弃吗，不，我不甘心，我冷静思考，它的网站既然有后台，有动态数据，那肯定也会有编辑器。

编辑器上传漏洞？我第一时间想到这个，很多编辑器为了方便测试，大多都有默认的上传页，且没有访问限制，只要能找到这些页面，就可以实现任意文件上传，说干就干，重新打开我的扫描器，不停的换字典，最终居然真的被我扫到了！

FckEditor！Nice！

先看一下编辑器的版本

可以看到版本是 2.5，这是个存在漏洞的版本，随便打开一个上传页

首先打算上传一个 asp 小马，直接上传 1.asp ，提示非法，应该是不能直接上传 asp 文件

按照网上的说法，fck 编辑器在上了文件名类似 m.asp;.jpg 的文件后，会自动将文件名改为m_asp;.jpg，然后继续上传 m.asp;.jpg，文件名会变为  m.asp;(1).jpg  ，但是经过尝试发现并不会，每次传上去的文件 . 都会变成 _ ，无论传多少次都是这样

最后在 csdn 上找到一个可行的方案，上传 m.asp.asp.jpg，然后使用 burp 拦截请求，把 m.asp.asp.jpg 改为 m.asp%00asp%00jpg，然后选中 m.asp%00asp%00jpg，右键解码，如下图

然后会变成 m.aspaspjpg，右键，发送到 Repeater，发送两次请求，返回 /uploadfiles/file/m(1).asp，用菜刀连接这个地址，成功连接

打算用菜刀上传一个大马的，但是不知道为什么无法上传文件，只好再用 FckEditor 的漏洞上传了

成功访问大马！

接下来应该做的就是提权、建用户、开远程桌面了，但是我没有再继续了，点到为止，把木马删了，痕迹都清理了。

就这样，完结！
