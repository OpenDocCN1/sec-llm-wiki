为什么? 

因为runInContext这句话把你的程序限制在了一个隔离的上下文之中.一开始我并没有提供源代码, 但你可以通过随便打些什么出发报错来查看调用栈 - 也可以得到大概的沙盒信息.

this 

一般来说, 在这个Context下运行的代码应该只属于该隔离环境. 然而, this是一个特别的. 

this指向runInContext(line, context)这一句里的context变量. 它属于沙盒外.实际上, 它是一个{}:

```

所以, 你就可以拿到它原型链末尾的Function对象:

```
