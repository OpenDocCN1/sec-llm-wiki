应用简述

 metabase是一款开源的数据分析平台,使用简单，可减少开发周期，节约成本，简单易上手等优点，同时该平台也拥有针对企业用户的付费版。

  

![](../Images/686bdba9d41503ea2e090e07221fc06f.png)

02

漏洞相关

在受影响的版本中，自定义 GeoJSON 地图（admin->settings->maps->custom maps->add a map）操作缺少权限验证，攻击者可通过该漏洞获得敏感信息。该漏洞 CVSS3 评分高达 9.9，危险性较高。  

  

CVE编号：CVE-2021-41277

  

影响版本：

metabase version < 0.40.5  

metabase version >= 1.0.0, < 1.40.5

  

![](../Images/686bdba9d41503ea2e090e07221fc06f.png)

FOFA：app="metabase"
