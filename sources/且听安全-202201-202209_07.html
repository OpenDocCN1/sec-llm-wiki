漏洞信息


近日监测到 Apache Spark 官方通报了一个命令注入漏洞 CVE-2022-33891：



Apache Spark 支持启动 ACL 来为 Web UI 访问提供身份验证，当 ACL 启动时可以通过构造特殊请求用户名导致 RCE ，漏洞影响版本：


  •  versions 3.0.3 and earlier

  •  versions 3.1.1 to 3.1.2

  •  and versions 3.2.0 to 3.2.1
