**详情看点**

  

**01**

  

  

**日本公平贸易委员会结束**

**对App Store的调查**

  
  

  

从明年初开始，Apple 将允许全球各地“阅读器”类 App 的开发者提供访问外部网站的链接，让用户设置或管理帐户。

本文来源：FreeBuf.COM

**02**

  

  

**WhatsApp图片过滤功能中**

**存在高危漏洞，可致程序崩溃**

  
  

  

9月3日消息，WhatApp的图片过滤功能中存在一个高危漏洞，可能被攻击者滥用来发送恶意图像，并读取该应用程序中存储的敏感信息。目前，该漏洞已被修复。

本文作者：yannichen

本文来源：FreeBuf.COM

**03**

  

  

**微软Exchange新漏洞ProxyToken**

**可以让攻击者重新配置邮箱**

  
  

  

邮箱网讯 9月2日消息 有关影响 Microsoft Exchange Server 的现已修补的安全漏洞的详细信息已经出现，未经身份验证的攻击者可以利用该漏洞修改服务器配置，从而导致个人身份信息 (PII) 的泄露。

本文来源：邮箱网
