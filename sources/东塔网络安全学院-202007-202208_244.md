# 行业资讯 | 黑客袭击！摩根士丹利(MS.US)客户数据造遭泄露

当地时间7月8日（周四），**摩根士丹利(MS.US)(Morgan Stanley)披露，黑客入侵了一家第三方供应商的 Accellion FTA 服务器，导致其部分企业客户的个人数据，包括客户姓名、地址、出生日期和公司名称在今年1月遭到盗窃。**

尽管摩根士丹利表明，尚未发现被盗信息在网上流传，**但为保护客户不被威胁，该司已将这些股票账户处于休眠状态，并表态“保护客户数据至关重要**，我们对此非常重视。鉴此，我们正在与 Guidehouse 保持密切联系，采取措施减轻客户的潜在风险。”

作为为摩根士丹利StockPlan Connect业务提供账户维护服务的第三方供应商，Guidehouse在2021年5月，通知该投资银行公司，称攻击者入侵了其服务器，窃取了属于摩根士丹利股票计划参与者的信息。**虽然漏洞已在发现的五天后修补完毕，但目前仍未清楚具体的损失。**

**消息发布后，该司股票收跌2.62%，报87.64美元/股，为连续第三天收跌。**而今年以来，摩根士丹利的股价上涨了34%，分析师预测随着该行已通过美联储（Fed）压力测试，预计其普通股股息将进一步提高。

作为一家领先的全球金融服务公司，摩根士丹利在全球范围内提供投资银行、证券、财富和投资管理服务。其2020年全年净收入高达482亿美元，同比增长16%，且是在受疫情打击最为严重的时期。

福布斯经济学家预测，随着财富和投资管理业务继续推动公司的增长，摩根士丹利2021财年的收入将触及546亿美元，每股收益（EPS）可能为6.89美元，再加上略低于13倍的市盈率，估值将达到89美元。
