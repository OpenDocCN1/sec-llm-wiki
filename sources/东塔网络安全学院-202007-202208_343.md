**英国牛津大学实验室遭黑客攻击，**

**未影响新冠疫苗研究**

  
  

  

![](../Images/f6599f823bcea964443192f55a1f62ca.png)

图：丘吉尔路路牌（新华社发，蒂姆·爱尔兰摄）

  

新华社北京2月26日电（记者 杜鹃）英国牛津大学25日证实，校方正在调查一间研究新冠病毒的生物实验室遭电脑“黑客”攻击事件，与新冠疫苗相关的研究没有受影响。

  

美国霍尔德网络安全公司创始人亚历克斯·霍尔登先前披露，他发现黑客2月中旬对牛津大学一间研究新冠病毒的生物实验室发动网络攻击。霍尔德网络安全公司说，正在追踪那些据信身处南美洲的黑客，后者目的可能是索要钱财。  

  

路透社报道，霍尔登所说实验室没有与英国阿斯利康制药公司共同研发新冠疫苗。

  

牛津大学25日在一份声明中证实黑客攻击，没有说明哪间实验室受影响。“我们发现并控制了问题，正在进一步调查。没有任何临床研究受影响。（新冠疫苗研究）不在（黑客攻击）影响区域内（开展）。”

  

校方说，正在与英国情报机构政府通信总部下属国家网络安全中心一道调查。

来源：新华社

# **CDPR遭黑客破坏比想象中严重？**

**据传员工数周无法远程工作**

  

知名企业的工控设备存在高危漏洞，

  

![](../Images/81da3b5573cbcd81d3535cb532bf9e78.png)

图：cyberpunk

  

CD Projekt Red 宣布，决定推迟 1.2 补丁的发布时间，原因为近期遭受的网络攻击以及 1.2 版本的重要性，团队需要更多时间进行开发。

  

不过公告并没有详细说明网络攻击对更新延期造成了多大的影响。在公告发出后，彭博社根据自己的情报渠道，撰文透露了更多详情：这次不曾预期的黑客攻击直接导致绝大多数员工连续两周都没法进行修复工作。

  

报道称，员工无法登陆公司的专属网络，因此无法进入系统和使用相应的软件工具。考虑到黑客可能获取了 CD Projekt Red 员工的私人数据，公司要求员工冻结个人账户，并向有关方面报告安全漏洞。一些员工需要将电脑寄往 IT 部门来扫描，以查找是否存在恶意软件或被入侵。

因为以上这些防护措施，《赛博朋克2077》新补丁的制作进度被严重拖慢，导致了延期。

目前该补丁预计会在三月后半个月内推出。

来源：彭博社

# **黑客用假邮箱骗走9.8万美元**

# **警方及时出击帮企业挽回损失**

  

知名企业的工控设备存在高危漏洞，

  

![](../Images/679272cf84fadce5a81a1a27e941cf72.png)

图：网络  

  

中国邮箱网讯 2月25日消息 “没想到货款还能追回来，谢谢你们帮企业挽回了损失。”近日，嵊州市黄泽镇某公司外贸部负责人董经理向黄泽派出所表示感谢。

  

1月26日，董经理匆匆报案，称黑客入侵加拿大客户的公司邮箱，骗取货款98000美元（约合人民币60万元）。

  

董经理告诉民警，公司与加拿大客户有长期业务往来，平时双方通过邮箱进行贸易谈判和货款给付确认。几天前，他向加拿大客户催收货款，对方却表示，货款早已打到公司账户上。董经理便向客户要求核实汇款信息，这才发现，客户收到的邮件内容被人篡改了。

  

原来，加拿大公司因新上任的财务人员不熟悉业务，将货款打到公司停用已久的账户上，钱原封不动退回客户的账户里，但这条重要的信息却被黑客监视了。黑客马上注册了一个相似的邮箱，冒充黄泽镇某公司同加拿大客户进行接触，要求客户将货款汇至另一账户。几天后，加拿大客户将共计98000美元的货款分两次打到黑客指定的账户。发现被骗，董经理和加拿大客户分别向当地警方报警。

  

黄泽派出所立即开展案件侦查。经调查，约60万元人民币的货款最终被转到了安徽马鞍山某公司的账户上。在安徽警方的高效配合下，民警联系上了该公司的负责人芮女士。而芮女士对此事并不知情，并表示会积极配合警方工作。

  

原来，芮女士经营的公司具有自营和代理进出口货物的资质，黑客将货款打到其公司账户上，再迅速转到境外的账户，达到洗钱的目的。芮女士核查发现，公司账户上收到的两笔货款确实存在问题。

  

经过民警的一番努力，最终43000美元成功返回加拿大公司的账户中。加拿大警方正根据相关线索，对余下未追回的55000美元货款进行深入调查。2月19日，黄泽某公司也已收到加拿大客户先行偿付的55000美元的货款，至此，公司的两笔货款已全部追回。

来源：中国邮箱网
