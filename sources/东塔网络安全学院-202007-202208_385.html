1、CVE-2020-3956-VMware Cloud Director 代码注入漏洞


VMware Cloud Director (也叫做vCloud Director)是一款领先的云计算服务交付平台，一些全球最受欢迎的云服务提供商利用它成功地运维和管理云计算服务业务。云服务提供商使用 Cloud Director 向全球数以千计的企业和 IT 团队安全、高效地交付弹性云计算资源。


漏洞概述

攻击者利用该漏洞可以获取敏感数据的访问权限，并接管和控制整个基础设施的私有云。攻击者还可以修改整个基础设施的登陆层来获取其他账户的用户名和口令。经过认证的攻击者可以使用基于web的接口或API调用来发送恶意流量到VMware Cloud Director。


漏洞通告

poc：

https://github.com/aaronsvk/CVE-2020-3956/blob/master/exploit.py


影响范围

漏洞影响Cloud Director

10.0.0.2之前的10.0.x版本、

9.7.0.5之前的9.7.0.x版本、

9.5.0.6之前的9.5.0.x版本、

9.1.0.4之前的9.1.0.x版本。


修复建议

目前VMvare已经发布了相关的漏洞补丁，请升级到安全版本。

 

2、CVE-2020-3980 VMware Fusion 权限提升漏洞


漏洞概述

VMware Fusion是美国威睿（VMware）公司的一套专用于在苹果机（Mac）上运行Windows应用程序的的虚拟机软件。VMware Fusion 11.x版本中存在一个权限提升漏洞，该漏洞允许攻击者配置系统路径。


具有正常用户权限的攻击者可能会利用此问题诱使管理员用户在安装 Fusion 的计算机上执行恶意代码。


影响范围

VMware Fusion Pro / Fusion (Fusion) 12.x

VMware Fusion Pro / Fusion (Fusion) 11.x
