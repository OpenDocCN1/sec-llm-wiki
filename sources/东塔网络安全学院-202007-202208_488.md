# 在制定云安全计划时，企业应考虑两种核心原则方法，即主动或被动。

l 主动方法是一种尝试通过在威胁发生之前解决问题来防止网络威胁发生的方法。l 被动的网络安全方法包括在网络威胁发生后做出反应。 企业之间存在一种有缺陷的心态，即，被动的网络安全措施最好实现场所中的在线数据保护。他们认为，预见到的威胁将过于昂贵，而且这是不必要的。嗯，遭受攻击的财务和声誉率每年都在不断增长。这意味着补救的成本可能会比最初用于实施适当的安全标准和控制的成本更高。   
**二．正文****1.****威胁发生后采取行动为时已晚**您不必走太远就可以确定由于使用网络安全响应式方法而遭受网络攻击的企业的真实示例。在2017年，WannaCry勒索软件攻击给NHS和世界各地的企业捆绑带来了巨大的问题-大约23万台PC受到此攻击的影响。经过调查，我们发现企业未能采取主动的网络安全措施来维护修补已知漏洞的核心计算机。 **2.****互联网黑客正在变得更具创新性**企业面临的主要云计算安全挑战之一是黑客的复杂程度不断提高。随着黑客实用工具的可用性越来越强，黑客策略和方法的增长使黑客有可能打破传统的防御性安全产品，例如防病毒应用程序和防火墙。相应的情况导致出现更严重的问题，其中威胁变得更难发现。 如今，暴露于组织甚至没有经历的情况变得越来越普遍。根据Ponemon Institute的说法，它平均需要191天左右的时间才能让公司确定其已受到攻击。为了解决这些问题，必须获得对周围和端点发生的操作的深刻了解。这有助于在恶意活动传播之前及早解决它。假设企业将处于某个阶段，并在其确切位置具有足够数量的监视程序和控制措施，以减轻风险。 **3.****通过GDPR 实现网络安全主动解决方案**众所周知，欧盟通用数据保护法规标准于2018年5月25日生效。这迫使数家企业对其数据保护和控制策略进行了修改，并更新了现有的云数据安全程序。但是，遵守标准不仅仅是对政策的一次性更改。企业的主要负担在于采取适当的技术和业务措施来保护个人信息以及处理，调查和报告数据泄露。未能在云计算安全风险领域展示出积极的网络安全方法的公司可能必须支付罚款。请注意，根据GDPR的规定，面临个人记录泄漏的企业还应向其客户提供最新信息，以防其自由和权利面临很高的风险。 **4.****如何在企业中实施主动网络安全？**到现在为止，我们假定您已经了解事实，即与被动方法相比，主动方法更合适。但是，现在出现了一个问题，即“ 实施这些措施的实际措施是什么？首先，良好的习惯是不断投资于安全评估服务，例如漏洞扫描和渗透测试。这有助于在黑客利用数据之前揭露业务网络，PC和应用程序上的弱点。应实施主动的网络和端点监视系统，以搜寻并应对每天发生的小威胁。对个人进行网络安全培训是提高云数据安全意识和知识的优秀实践之一。主动采取措施并不一定是一项代价高昂的措施，它意味着要花时间和资源来准备您的房屋，以在很早的阶段就预防和应对攻击。与其花费额外的时间，金钱和精力来应对网络威胁，不如尽早做好准备。在本文的结尾，我们只想说：“ 不要等待互联网威胁的发生；在此之前适当地采取积极的网络安全措施，以防止事后遭受网络攻击的灾难性后果。”![](../Images/f1e646358e27a11771884b77f4c9c787.png)
