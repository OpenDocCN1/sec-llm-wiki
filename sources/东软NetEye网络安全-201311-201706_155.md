# 东软网络安全人才实训基地获ISG管理运维赛二等奖

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=2649207981&idx=1&sn=30ab75c33a0842c9db2c8889e2ec7140&chksm=beedde77899a57619a9d919e6b654e3d21ce9562a3e35a9d07bd440cb8edf28f018a3403648c&scene=126&sessionid=1681369887#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=2649207981&idx=1&sn=30ab75c33a0842c9db2c8889e2ec7140&chksm=beedde77899a57619a9d919e6b654e3d21ce9562a3e35a9d07bd440cb8edf28f018a3403648c&scene=126&sessionid=1681369887#rd)

ISG管理运维赛隶属于中国**信息安全**技能竞赛中的行业知识赛，ISG是英文 Information Security Game的缩写，旨在普及行业信息安全意识。在刚刚落幕的2016 ISG管理运维赛中，东软网络安全人才实训基地的学员获得了二等奖。

  

![](../Images/e543c3ccde3a6da34cff8abee36533f1.png)  

![](../Images/a8142afb4e16a42228495eb313fdcaae.png)  

本届ISG管理运维赛由上海市经济和信息化委员会指导，ISG竞赛组委会主办，绿盟科技冠名并提供主要技术支持。比赛内容主要针对信息系统管理人员、运维人员，从战略与治理、运维与管理、技术与攻防、事件与应急、互联网+安全五个维度展开，考查参赛团队的管理体系、知识体系、运维技能、表达阐述与团队协作等多方面能力。

 

今年该赛事在初赛阶段就吸引了来自银行、证券、保险、通信、国企、高校、交通、综合等行业的140支队伍参赛，参赛队伍创造了历史新高。经过层层考验，此次比赛高校组最终决出一等奖一名，二等奖两名，三等奖三名。**东软网络安全人才实训基地参赛学员以高校组的身份，最终夺得了整个比赛的二等奖。获得高校组一等奖的是国防科技大学。**  
  

![](../Images/a9d467df7f4233c16c1c8f9a6aefbdde.png)  

2015年10月东软NetEye与成都东软信息学院在成都成立了**成都东软学院&东软网络安全人才实训基地****，**旨在通过教育理论与行业实践的有机结合，加强网络安全人才的培养和选拔，为网络安全行业提供更多理论与实践技能兼备的优秀专业人才。

 

东软网络安全人才实训基地的参赛学员表示，对这次比赛的成绩并不是很满意，希望下次能够努力冲击一等奖。此次获奖并不是东软安全学员在大型安全比赛中的最好成绩，今年7月分，东软网络安全人才实训基地的学员曾获得2016年“启明星辰杯”四川省大学生信息安全技术大赛一等奖。
