# 东软NetEye参展阿里云栖大会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=208781460&idx=2&sn=367c1c2657df40c45db568461d96d114&chksm=2f7baa4e180c2358fe51e08d7791ba677681e94893cc45b94bc47a07f85a29c2bb07794fac98&scene=126&sessionid=1681369958#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=208781460&idx=2&sn=367c1c2657df40c45db568461d96d114&chksm=2f7baa4e180c2358fe51e08d7791ba677681e94893cc45b94bc47a07f85a29c2bb07794fac98&scene=126&sessionid=1681369958#rd)

7月22日，首届阿里云分享日×云栖大会在北京富力万丽酒店隆重召开,吸引了海内外2000余名开发者、创业者及生态伙伴参与。作为阿里重要合作伙伴，东软网络安全携旗下优秀的NetEye系列产品以及解决方案参展。

本次阿里云分享日x云栖大会围绕DT世界的生态、六大元素、企业级互联网架构、生态安全、未来技术等主题，联合40家全球合作生态伙伴和行业大咖，通过主论坛和行业分论坛的形式，展现了一副DT时代的“清明上河图”。

  

在本次展会上东软安全重点展示了虚拟安全网关产品（NISG-VA）。一经展出，便吸引了在场观众高度的关注和浓厚的兴趣。该产品集防火墙、VPN、DoS/DDoS攻击防御、入侵防御、防病毒、反垃圾邮件、URL过滤、应用协议识别与控制等多项尖端安全技术于一身，通过模块化设计，让企业迁移到云端的同时兼顾安全。

历经六年的时间，从无到有，阿里云如今已成长为全球领先的云计算服务平台。同样，东软NetEye品牌从1996年创立至今，经历了十几年的风雨，以技术、人及对行业的深厚经验积累为基础的核心竞争力也愈加突出，一直致力于为客户提供更为完备、更科学的网络安全产品和解决方案。通过不断地沟通与协作，东软NetEye将与合作伙伴共同成长，合力保障行业客户的网络信息安全。
