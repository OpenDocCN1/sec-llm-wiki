# Mac OSX及FreeBSD系统下的ftp命令被发现存在漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=202088250&idx=2&sn=98bb6de7b28d1f14e714c38c57f2efa7&chksm=2f01f5e018767cf67ac860408d3bd05d15be49d5ce26bbb6806cf45ad19377fad346decb9a20&scene=126&sessionid=1681369983#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=202088250&idx=2&sn=98bb6de7b28d1f14e714c38c57f2efa7&chksm=2f01f5e018767cf67ac860408d3bd05d15be49d5ce26bbb6806cf45ad19377fad346decb9a20&scene=126&sessionid=1681369983#rd)

近日，最新版本的Mac OSX及FreeBSD系统下的ftp命令被发现存在漏洞。当使用ftp通过http协议去下载一个文件时，会导致任意命令执行。基于Mac OS X系统越来越广泛的被大众使用，提醒大家注意在漏洞修复前不要使用ftp命令下载不可信的文件。

  

**漏洞等级：**

严重

  

**漏洞系统：**

Mac OS X

FreeBSD

  

**漏洞原理：**

当用户请求一个文件时，攻击者返回HTTP 301重定位，迫使ftp命令去下载另外一个文件。新下载的文件名首个字符为“|”。下载结束后，ftp命令会将“|”当作管道符，于是将新文件名就会被当作系统命令执行。
