# 软交会分论坛，看网络安全产业如何融入教育

6月15日-6月18日，第十五届中国国际软件和信息服务交易会在大连盛大开幕，本次软交会中设有多场高端论坛，在6月16日，**“产业融入教育”**东软睿道产教融合、校企合作高峰论坛召开，国家示范性软件学院联盟理事长北京交通大学软件学院院长芦苇、东软集团董事长兼CEO刘积仁博士、东软集团网络安全事业部副总经理张泉等参与此次会议并发表演讲。  

  

![](../Images/23f7ebd5ea9e207abf67b0ae0cd0363a.png)

软集团董事长兼CEO刘积仁博士  

  

高校领导致辞后，软集团董事长兼CEO刘积仁博士重磅开场，发表了《数字社会推动教育变革》主题演讲。他指出，数字产业与教育的融合，应以学习者为中心，跨界发展，推动与服务数字社会的前行。我们要不断迭代教育自身，以社会需求推动教学、培养模式、教室队伍的变革。同时，应构建开放的联盟，整合社会资源和需求以达成与产业的深度融合，最终形成高度渗透的创新与创业文化。

  

![](../Images/813dacc737656b22066730a22ca3e16e.png)

分论坛现场  

  

**那么网络安全产业如何切实的融入教育呢？东软集团网络安全事业部副总经理张泉以《网络安全为教育带来的新机遇》为主题，为我们解答了这一问题。**

  

![](../Images/4c32afe05fdba78abd976819c15f9a7d.png)

东软集团网络安全事业部副总经理张泉

  

张泉指出，我国只有**126**所高校设立了143个网络安全相关专业，仅占1200所理工院校的**10%**，近3年，全国网络安全相关专业年均招生数仅在1万人左右，而网络安全人才总需求量则超过**70万**人，缺口高达**95%**。7.1亿中国网民的网络安全问题，已成为行业乃至国家亟待解决的问题。但与此相对，2016年中国互联网新增危害信息安全的事件数量超过一万个，比2015年增长约**36%**。预计中国重要行业信息系统和信息基础设施需要各类网络信息安全人才还将以每年1.5万人的速度递增，到2020年相关人才需求将增长到**140万**。

  

2016年6月，国家中网办、发改委、工信部、教育部、科技部、人社部等政府机构在《关于加强网络安全学科建设和人才培养的意见》中提出了加快网络安全学科专业和院系建设、创新网络安全人才培养机制、加强网络安全教材建设、强化网络安全师资队伍建设、推动高等院校与行业企业合作育人、协同创新、加强网络安全从业人员在职培训、加强全民网络安全意识与技能培养、完善网络安全人才培养配套措施等各方面意见。今年6月施行的《国家网络安全法》内也明确提出支持企业和高等学校、职业学校等教育培训机构开展网络安全相关教育与培训，采取多种方式培养网络安全人才，促进网络安全人才交流。

  

张泉指出，切实加强网络安全人才培训落地到微观工作中，需要引进先进理念和系统的网络安全教育体系，可借助E-learning（在线学习）等更灵活的形式加强网络安全教育培训。另外，网络安全学科的教育培训可以更加低龄化，也就是我们常说的“从娃娃抓起”，尽早培养孩子的网络安全意识，挖掘学生的兴趣。同时还有很重要的一点则是需要加强教师队伍的网络安全水平，完善网络安全教育职业培训。

  

![](../Images/bfe1f05aae3cf8357280962f12069419.png)

成都东软学院&东软网络安全人才实训基地

  

无论是从网络安全服务保障，还是网络安全人才培养上，东软NetEye一直都在付出努力，中国科学院、北京理工大学、东北大学、北京航空航天大学等科学教育机构都在其安全服务客户名单之内。东软NetEye定期在全国各地组织不同规模的教育行业信息安全发展研讨会，从行业案例和技术培训上帮助教育领域提升网络安全防御能力。2015年10月东软NetEye与成都东软信息学院在成都成立了**成都东软学院&东软网络安全人才实训基地****，**旨在通过教育理论与行业实践的有机结合，加强网络安全人才的培养和选拔，为网络安全行业提供更多理论与实践技能兼备的优秀专业人才。该学院的学生曾获得2016年四川省大学生信息安全技术大赛一等奖；2016年中国信息安全技能竞赛二等奖等荣誉。

  

**行是知之始，知是行之成**。东软NetEye 21年的网络安全经验积累使其在网络安全行业与教育的融合推动中具备强大的实力，而对中国网络安全未来的责任感与使命感为这项事业提供了动力。东软NetEye将持续助力网络安全行业与教育的融合发展，为我国网络安全的未来添砖加瓦。
