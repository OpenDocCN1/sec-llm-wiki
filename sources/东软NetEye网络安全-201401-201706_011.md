# 顺势而起，乘势而发：东软NetEye渠道大会陕西站现场直击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=2649208644&idx=1&sn=9616f7cbe13624f94bb237ff89525485&chksm=beeddd9e899a54882cddec8984d691cfd16c642bfeb6e702f7a9bf1b66cc69132190b14d9156&scene=126&sessionid=1681369812#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=2649208644&idx=1&sn=9616f7cbe13624f94bb237ff89525485&chksm=beeddd9e899a54882cddec8984d691cfd16c642bfeb6e702f7a9bf1b66cc69132190b14d9156&scene=126&sessionid=1681369812#rd)

西安是中华文明和中华民族重要发祥地之一，丝绸之路的东方起点，“红尘白日长安路，马走车轮不暂闲”说的正是西安自古的繁华。如今，西安正是东软NetEye西北大区渠道版图的核心，在这个历史文化名城，东软网络安全渠道蓬勃发展，6月2日，东软NetEye渠道合作伙伴大会陕西站隆重举行。

  

![](../Images/09d79cfb87a5a9f24fc1e61f7479667b.png)

会议现场  

  

此次合作大会的主题为“顺势而起，乘势而发”，吸引了一百多家陕西地区代理商参与大会，多位领导莅临指导。国家计算机网络应急技术处理协调中心陕西分中心处长田瑛、陕西省网络与安全测评中心主任安克万、东软集团副总裁兼网络安全事业部总经理杨纪文、东软集团网络安全事业部副总经理张泉、东软集团网络安全事业部副总经理路娜、东软集团网络安全事业部全国渠道总监戴志刚等参与会议。

  

6月1日国家网络安全法正式施行，且公安部在今年初期已经开始规划将会对党政机关、重要行业、国有企事业单位、互联网企业等进行基于法律的安全检查，安全市场需求将会呈现井喷之势。[（了解详细分析可点击《史上最全：网络安全法解析、公安部安全检查应对指南》）](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=2649208616&idx=1&sn=972c7518c8229da5e0685413c5573e37&chksm=beedddf2899a54e4c4e01bdf9e63f550db8c70ce15d48644956e4e4daae7df4d934f74196172&scene=21#wechat_redirect)在网络安全法的大势之下，东软NetEye抓住时机，及时与渠道合作伙伴进行对网络安全法的解读与交流，提出了更多针对应对法律实施和公安部检查的各种安全解决方案。

  

  

![](../Images/1a1ae94d467f2a207332adba0620d1f2.png)

国家计算机网络应急技术处理协调中心陕西分中心处长田瑛  

  

大会伊始，国家计算机网络应急技术处理协调中心陕西分中心田瑛处长发表致辞，她说，网络安全绝对不是一家的网络安全，真正的安全是指大家的安全，群众的安全、社会的安全。今天我们聚集到这里也是为了要把几个单位的安全发展到整个社会的安全。她本人表示非常肯定东软安全在国家应急响应方面的支撑，全国仅有9家的国家级应急支撑单位，东软安全位列其中，足以见得在安全应急方面的出色能力。

  

![](../Images/e92e6925c2f1c6f61008035ebc17b4fc.png)

陕西省网络与安全测评中心主任安克万  

  

陕西省网络与安全测评中心主任安克万也在大会中给予了指导与鼓励，他指出与东软NetEye在陕西省风险评估测评以及国家标准制定方面合作非常出色和顺利，并祝愿此次合作伙伴大会圆满成功。

  

![](../Images/81192ecb2bfb1a68f5239a74230d0f98.png)  

东软集团副总裁兼网络安全事业部总经理杨纪文  

  

东软集团副总裁兼网络安全事业部总经理杨纪文发表致辞，他对到场的领导以及代理商们表示了热烈的欢迎，东软NetEye将持续在国家安全标准建设、应急服务支撑等方面不断努力，接下来也会更加大力发展渠道，给各位渠道代理商带去更多优惠政策。

  

此次合作伙伴大会设立了充分的展示区，将能够解决网络安全法所要求的安全产品和服务展出，向渠道代理商进行展示试用。安全网关类、数据审计类和运维管理类产品颇受合作伙伴的青睐。

![](../Images/bffb01881436b61778d6f29c360fcc7e.png)

![](../Images/b682fa5e249d1634d14f4c0827a9c35b.png)

  

此次渠道会议的技术交流环节以**把握宏观趋势——解读网络安全法——东软安全输出能力**三个层次逻辑进行。

  

![](../Images/f88ee5099d0864ae4eeedaed296f4bac.png)

东软集团网络安全事业部副总经理张泉

  

首先，东软集团网络安全事业部副总经理张泉为我们分析了目前国内以及国外的网络环境现状以及发展预测。值得一提的是，张泉还为我们详细讲解了东软近日发布的2017年医疗行业信息安全报告。该报告面向100家医疗执业单位、907家三甲医院网站、4663个医疗互联网资产样本进行调查，张泉根据调查结果明确得指出以医疗行业为例，目前最重要的安全需求是什么、最需要的安全产品是那些、安全服务是哪些。

  

![](../Images/7f7ae8de8fd81f4bd12a98e08c919ae2.png)

东软NetEye高级咨询专家王华铎

  

其次，东软NetEye高级咨询专家王华铎详细解析了网络安全法。从法律颁布后将对国内安全市场带来的改变的预测、到法律条文所强制的安全部署、至东软NetEye如何帮助用户应对相应法律要求等内容，详略得当，有理有据地与合作伙伴进行了交流。

  

![](../Images/8649de08af16db1e0ad6521fecaa136e.png)

  

在此次与代理商的交流中，许多代理商表示在详细了解东软的安全产品品质前，他们首先关注的是东软NetEye西北大区的渠道销售团队——知行合一团队。知行合一团队的成员让合作伙伴充分得感受到了热血与激情，努力与勤奋，专业与好学。在此次交流会中，知行合一团队的九零后负责人杨帅与我们分享了更多陕西地区的渠道政策，团队成员梁华、王耀也在实践角度分享了渠道伙伴非常感兴趣的网络安全产品。  

  

![](../Images/4a465b0581cc72cf39e36b8ef8611615.png)

东软安全团队

  

顺势而起，乘势而发。在网络安全空间里，东软NetEye开拓着一次又一次的技术革命，抓住了一次又一次的政策指引。正如田瑛处长所说，我们所追求的是大众的安全，社会的安全，中国的安全乃至世界的安全。若想使安全事业开枝散叶，渠道合作伙伴的力量不容忽视，在合作共赢的道路上我们拥有共同的安全责任与梦想。东软NetEye渠道Club欢迎更多志同道合朋友的加入！
