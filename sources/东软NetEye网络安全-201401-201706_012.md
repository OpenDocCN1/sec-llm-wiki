# 东软NetEye21款产品入围中央政府采购名录

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=2649208644&idx=2&sn=78f23704cb5f3af87d4113b896fa8532&chksm=beeddd9e899a5488059a20c2ea159a15268fd45b72aa7686bb34268ec5b7658455d78029da7c&scene=126&sessionid=1681369812#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=2649208644&idx=2&sn=78f23704cb5f3af87d4113b896fa8532&chksm=beeddd9e899a5488059a20c2ea159a15268fd45b72aa7686bb34268ec5b7658455d78029da7c&scene=126&sessionid=1681369812#rd)

近日，由中央国家机关政府采购中心主办的“中央国家机关2017-2018信息类产品协议供货采购项目”完美落幕，在中央政府采购网上公示的中标公告中，东软NetEye的21款产品顺利通过竞标和专家论证，成为中央政府指定采购产品。

相比往年，本次中标公告的名录中，新增了漏洞扫描产品、上网行为管理系统、WEB应用防火墙、负载均衡等产品，东软网络安全在防火墙以外的产品领域有创新突破。东软NetEye作为中国网络安全行业的领导厂商，连续20年保持快速增长，凭借丰厚的经验与技术基础，持续创新发展，满足网络安全产品市场需求，引导市场健康发展。
