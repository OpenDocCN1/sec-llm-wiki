# 智慧城市之梦—东软NetEye，梦的守护者

2017年5月11日中国网络安全产业联盟下属标准工作组（原智慧城市标准工作组）在北京召开第六次工作会议。会上，联盟秘书长陈兴跃对标准工作组的先进单位及个人进行了表彰。东软NetEye凭借在工作组各项工作中提供的强有力技术支撑、对网络安全标准的灵活应用等优异表现**获得联盟积极参与单位的表彰**。**东软****网络安全研究院资深顾问石金获得个人突出贡献表彰。**

智慧之城—安全何在？![](../Images/e0bb8b875052511581e8113e628609f1.png)

  

当前，我国正处于城镇化加速发展的时期，很多地区“城市病”问题日益严重，为解决城市发展难题，保证城市的和谐可持续发展，实现城市的智慧式管理和安全运行已经成为当今各国城市发展的潮流。建设智慧城市即利用先进的信息技术整合城市运行系统的关键信息，从而对民生、公共安全、城市服务、工商业活动在内的各种需求做出智能响应。从传统的城市发展模式到新型智慧城市，开展信息化建设的同时也面临着更多更加严峻的安全挑战，但更加缺乏的是保障智慧城市安全性的总体框架和依据。为此，中国网络安全产业联盟作为业内极具代表性的组织，成立了标准工作组编写《智慧城市安全体系框架》。

该工作组汇集行业内多家安全厂商，东软NetEye作为中国网络安全行业的领导厂商，凭借对网络安全行业各项安全标准的深刻理解成为《智慧城市安全体系框架》的主要编写单位之一。

  

智慧之城—NetEye安全守护![](../Images/e0bb8b875052511581e8113e628609f1.png)

  

在工作组成立一年多的时间里，东软NetEye始终保持着高参与度，出席每一次的工作组会议；深入研究《智慧城市安全体系框架》的相关内容，与相关专家讨论交换工作意见；不断完善《智慧城市安全体系框架》。东软NetEye认为：智慧城市的安全技术保障要从安全防护、安全检测、事件的及时响应和系统恢复4个要素出发，分别对物联感知层、网络通信层、计算与存储层、数据与服务融合层提出不同层级的功能安全要求。充分展示了东软NetEye “因需而变，因御而安”的发展理念，同时融合多年的技术积累与业务经验，不断创新，来满足不同市场条件下的网络安全防护需求。让智慧城市的发展因御而安。

![](../Images/b87374a67a43ee1653bd0a5b5ec6d4af.png)

未来，在建设智慧城市标准体系的过程中，东软NetEye会始终与各专家单位保持协同高效的工作方式，以既有的技术产品实力更好的构建智慧城市安全体系框架，有效推进智慧城市信息化总体建设，为智慧城市的网络安全保驾护航。
