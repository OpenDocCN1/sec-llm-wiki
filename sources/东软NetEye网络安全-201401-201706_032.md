# ONION、WNCRY“永恒之蓝”勒索病毒攻击解决方案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=2649208502&idx=1&sn=d3731168c4505c641aafedc28af8f3f5&chksm=beeddc6c899a557aad6e1dcec4c67f0194d8c4e1b4e48a101acb216ba47e99109201f9237771&scene=126&sessionid=1681369822#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=2649208502&idx=1&sn=d3731168c4505c641aafedc28af8f3f5&chksm=beeddc6c899a557aad6e1dcec4c67f0194d8c4e1b4e48a101acb216ba47e99109201f9237771&scene=126&sessionid=1681369822#rd)

**安全通告**

2017年5月12日起，在国内外网络中发现爆发基于Windows网络共享协议进行攻击传播的蠕虫恶意代码，这是不法分子通过改造之前泄露的NSA黑客武器库中“永恒之蓝”攻击程序发起的网络攻击事件。

  

目前发现的蠕虫会扫描开放445文件共享端口的Windows机器，无需用户任何操作，只要开机上网，不法分子就能在电脑和服务器中植入执行勒索程序、远程控制木马、虚拟货币挖矿机等恶意程序。

  

此蠕虫目前在没有对445端口进行严格访问控制的教育网内大量传播，受感染系统被勒索巨额金钱。该由NSA泄露工具所引发的蠕虫攻击事件已经造成非常严重的现实危害，与教育网类似的大规模的企业内网也已经面临此类威胁。

  

东软安全监测与响应中心也将持续关注该事件的进展，并第一时间为您更新该事件信息。

  

前情提要：北京时间2017年4月14日晚，一大批新的NSA相关网络攻击工具及文档被Shadow Brokers组织公布，其中包含了涉及多个Windows系统服务（SMB、RDP、IIS）的远程命令执行工具。

  

![](../Images/23e36bc21f4162e9164f2e57f950de9a.png)

**漏洞信息**

**漏洞描述**

近期国内多处高校网络出现ONION/Wncry勒索软件感染情况，磁盘文件会被病毒加密为.onion后缀，只有支付高额赎金才能解密恢复文件，对重要数据造成严重损失。

  

根据网络安全机构通报，这是不法分子利用NSA黑客武器库泄漏的“永恒之蓝”发起的蠕虫病毒攻击事件。恶意代码会扫描开放445文件共享端口的Windows机器，无需用户任何操作，只要开机上网，不法分子就能在电脑和服务器中植入勒索软件、远程控制木马、虚拟货币挖矿机等恶意程序。

  

由于以前国内多次爆发利用445端口传播的蠕虫，部分运营商在主干网络上封禁了445端口，但是教育网并没有此限制，仍然存在大量暴露445端口且存在漏洞的电脑，导致目前蠕虫的泛滥。

  

针对NSA黑客武器利用的Windows系统漏洞，微软在今年3月已发布补丁修复。但由于Windows XP/Vista/2003等已经停止更新，因此微软没有发布相应的补丁程序，您可以使用系统防火墙或第三方工具关闭漏洞利用的端口，防止电脑被NSA黑客武器植入勒索病毒等恶意程序。如果您的电脑是 Windows 7 /8/8.1 ，请到「控制面板」>「Windows Update」>「查看更新历史记录」，检查是否已经有以下更新：

  

三月份安全性更新编号：

Windows 7 : KB4012215

Windows 8.1:KB4012216

  

四月份安全性更新编号：

Windows 7 : KB4015549

Windows 8.1:KB4015550

  

五月份安全性更新编号：

Windows 7: KB4019264

Windows 8.1:KB4019215

  

**风险等级**

对此事件的风险评级为：危急。

**解决方案**

**确认影响范围**

政府、企业、IDC、教育、医疗网络等所有开放445 SMB服务端口且没有及时安装安全补丁的客户端和服务器系统都将面临此威胁。

  

**应急处置手段**

目前利用漏洞进行攻击传播的蠕虫开始泛滥，东软强烈建议网络管理员在网络边界的防火墙上阻断445端口的访问，如果边界上有东软NetEye入侵防御系统IPS和东软NetEye防火墙FW之类的设备，请升级设备的检测规则到最新版本，直到确认网内的电脑已经安装了MS17-010补丁或关闭了Server服务。

  

**Step1攻击应对**

可在东软NetEye防火墙添加阻止相关端口的策略，防范来自外网及安全域之间的攻击和感染，具体操作如下：

  

1、登录防火墙,选择「防火墙」,点击「访问策略」

  

![](../Images/e1cffa0cfa28b33b235a967dc36361bd.png)

2、点击页面内的「服务」窗体中的「使用下表」，选择「添加」，弹出窗口添加自定义TCP 445、137、138、139目的端口，完成后点击「确认」

  

![](../Images/8a36013dca5f5352b7a42ece7e3bc444.png)

3、点击页面内的「动作」下拉菜单中选择「拒绝」，完成后点击「确认」

  

![](../Images/82ee176d82a0d4089004dca295fe71cb.png)

4、返回访问控制菜单中查看是否生成策略并生效。

  

![](../Images/2f19e01bb172e70b9eb0d45f4c36c18a.png)

Step2修复漏洞

目前微软已发布补丁MS17-010修复了“永恒之蓝”攻击的系统漏洞，请立即电脑安装此补丁。对于Win7以下版本的操作系统，微软已经不提供安全补丁支持，请尽快按 快速应急处置建议 中的描述处理。

  

1、升级针对MS17-010的微软的漏洞补丁，可以采用自动更新或下载更新补丁的方法，补丁更新地址如下：

补丁传送门：https://technet.microsoft.com/zh-cn/library/security/MS17-010

  

2、对于 Windows XP、 2003 等微软已不再提供安全更新的机器，推荐使用 360

“ NSA 武器库免疫工具”检测系统是否存在漏洞，并关闭受到漏洞影响的端口，  
可以避免遭到勒索软件等病毒的侵害。

免疫工具下载地址：http://dl.360safe.com/nsa/nsatool.exe

  

3、备份系统中的重要文件，XYclouds用户可使用云灾备服务进行备份。
