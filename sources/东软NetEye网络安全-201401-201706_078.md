# 东软NetEye助力教育行业信息安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=2649208318&idx=1&sn=06e1da601edf35424ce1ad7cfefb182a&chksm=beeddf24899a5632d6ead4ad884532516f5fc3fa45cf1bc0a9332d5c68ea3897afe059b5c6e5&scene=126&sessionid=1681369837#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=2649208318&idx=1&sn=06e1da601edf35424ce1ad7cfefb182a&chksm=beeddf24899a5632d6ead4ad884532516f5fc3fa45cf1bc0a9332d5c68ea3897afe059b5c6e5&scene=126&sessionid=1681369837#rd)

       2017年3月11日，由东软集团华南大区主办，网络安全事业部协办的茂名教育行业信息化发展研讨会成功召开。本次会议是东软NetEye在广东茂名地区首次亮相，邀请到茂名市教育局专家、茂名移动政企主管领导、茂名市经信局以及教育行业的各级负责人、教师参会。东软集团华南大区副总经理叶军出席会议并发表致辞。东软NetEye被邀请参与其中，为与会人员分享了东软安全在教育行业中的应用及成功案例。

![](../Images/8ea4715f608cbab05e34ceaffc3b0f63.png)

       东软集团网络安全事业部高级项目经理朱劲锋以内蒙19万考生信息泄露为举例，并列举了2016年11月7日全国人大审议通过的《中华人民共和国网络安全法》以及2017年2月20日《关于印发教育部网络安全和信息化小组第二次会议会议纪要的通知》等重要举措，其中均涉及到教育行业信息安全问题，说明教育行业的信息安全得到了国家的高度重视。

       东软NetEye工程师从物理环境、网络环境、主机环境、应用环境、数据环境几个方面进行分析，重点说明运维管理、安全制度管理、人员安全管理三个方面是国内高校面临的典型网络安全问题。同时，从技术角度为大家分享了针对高校IT系统安全的研究与解决方案，并对教育行业的等级保护建设进行概述，引起了与会人员的热烈讨论。朱劲峰最后介绍了东软NetEye的品牌理念、产品技术、广泛的服务对象与丰富的经验，希望能与更多的教育行业合作，服务更多高校。

       通过此次会议，可以让用户全面了解东软网络安全产品，能够与教育行业紧密合作，把东软网络安全产品输送给更多的教育行业客户。东软NetEye始终为各行业客户提供成熟、先进的网络安全产品及高效、完善的安全解决方案与服务。通过对技术发展的把握与对行业需求的全面深度融合，致力于成为全球领先的网络安全产品及服务供应商。
