# 东软NetEye助力医疗信息安全—FY2017东软医疗IT事业部全国销售大会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=2649208298&idx=1&sn=02a6f2e686d6b8ac4556cc3089ac792d&chksm=beeddf30899a56264b18d9455204af5d238b4bc27a6714e1ccecea1594573264d1cb68eb7a99&scene=126&sessionid=1681369842#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=2649208298&idx=1&sn=02a6f2e686d6b8ac4556cc3089ac792d&chksm=beeddf30899a56264b18d9455204af5d238b4bc27a6714e1ccecea1594573264d1cb68eb7a99&scene=126&sessionid=1681369842#rd)

        2017年3月9日-10日，东软医疗IT事业部全国销售大会在延安盛大召开，东软集团高级副总裁卢朝霞教授以及东软医疗IT事业部、集团各大区的相关负责人、营销体系人员共计280余人参与此次会议。东软集团副总裁、网络安全事业部副总经理杨纪文受邀出席。

       保护患者信息是东软NetEye一直不断关注的医疗信息安全问题，患者的隐私应当被保护起来，近期，由于网络安全问题造成医疗事件比比皆是，网络安全在医疗行业中的重要性必须被重视起来。

![](../Images/a82ae163d2065919eabcec0e73a8ea6c.png)

东软集团副总裁网络安全事业部总经理杨纪文

       杨纪文提出，东软NetEye医疗行业网络安全解决方案是按照医院信息系统的重要性和网络使用的逻辑特性划分安全域，综合多种安全技术手段保障并提升核心业务系统的安全防护水平，满足等级保护在物理安全、网络安全、主机安全、应用安全、数据安全、安全管理制度、安全管理机构、人员安全管理、系统运维管理多方面的技术和管理要求，从整体上为业务系统构建一套完备、多层次的安全防护体系。

       杨纪文在会议中还列举了东软NetEye近年来服务的医疗行业客户，包括湖北省卫计委等级保护改造项目、北京医院信息安全等级保护项目、上海五院重要信息系统三级等级保护安全加固项目、宁波云医院等级保护信息安全集团项目等，在以上项目中，东软NetEye受到了许多好评，多次获得了客户的感谢信。

       本次医疗IT销售大会分别从市场策略、合作伙伴、渠道策略及医疗产品发展策略等几个方便进行了全面介绍，东软NetEye将贯彻集团发展方针，积极推进网络安全在医疗行业的发展，继续为我国医疗行业提供顶尖的安全技术、产品及服务。
