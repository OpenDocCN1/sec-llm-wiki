# 创新发展 合作共赢—FY2017东软政府本部全国销售大会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=2649208276&idx=1&sn=8f156efd36ac4943f31bbe8f21574b64&chksm=beeddf0e899a56189a2da0434f14182f045fa6c302d63eee378aa9e7de8db08f2c753dbbe658&scene=126&sessionid=1681369842#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=2649208276&idx=1&sn=8f156efd36ac4943f31bbe8f21574b64&chksm=beeddf0e899a56189a2da0434f14182f045fa6c302d63eee378aa9e7de8db08f2c753dbbe658&scene=126&sessionid=1681369842#rd)

   2017东软政府本部全国销售大会于3月3日-6日在桂林召开，本次会议邀请到政府本部及第一二三五事业部、东软集团各大区负责人与销售团队出席。本次会议围绕政府行业整体解决方案、创新产品、合作策略以及相关各事业部销售政策展开。东软集团副总裁兼网络安全事业部总经理杨纪文应邀在本次会议中发表了讲话。

![](../Images/be4ddaa88509b69503f764b3842d0e2d.png)

东软集团副总裁网络安全事业部总经理杨纪文

![](../Images/0e053601065a9c1da190366b86fd00a0.png)

    杨纪文在会议中为与会者分享了网安事业部2016年的重点项目，东软NetEye产品线在国家测评机构及媒体中不断获得肯定，在国家重点行业重点项目顺利中标等，可以看出2016年是东软NetEye不断创新、不断积淀、厚积薄发的一年。同时杨纪文也明确了2017年市场及营销策略，提出要建立完整的认知体系，坚持构建与完善渠道体系建设，建设以市场为导向的研发体系，打造行业专家形象。

    作为全球领先的网络安全产品和解决方案供应商，2017年东软NetEye将继续秉承“合作发展，共赢未来“的理念，不断创新、开拓视野，提高产品成熟度，与更多政府行业的合作伙伴一起，携手共前，共创辉煌！
