# 双十一爽购的背后，智慧城市与大数据起什么作用？

随着“智慧城市”的发展，我们渐渐在生活中体会到了智能与大数据带来的便利。双十一购物如何做到安全可靠和井然有序？阿里是如何在短时间内快速计算销售额，并以此作为依据向顾客无形推销更多产品？这都是智慧城市和大数据的体现。11月11日，在“双十一”这个本身就是以智能和数据为依托的购物节之际，**2016智慧城市和大数据发展（沈阳）博览会**（以下简称博览会）在辽宁工业展览馆拉开帷幕。

 

![](../Images/27813cd8a45152ab1b2a1d575aa5759d.png)  
2016智慧城市和大数据发展（沈阳）博览会

  

![](../Images/78e50bc353c91ab9d482ef493e8bba82.png)**“振兴、协同、共赢”意味着什么？**

“振兴、协同、共赢”是此次博览会的主题，沈阳作为东北老工业基地的核心之一，在智慧城市的发展蓝图中，如何将过去的经济结构与智能、数据进行结合做到振兴，是一个需要攻克的题目。而各行业相互协同合作，传统工业与新兴科技相结合是沈阳智慧城市发展的重要途径。共赢则是我们所追求的目标，不仅要达到行业与行业之间的共赢，更重要的是让市民赢得更便利、更安全的生活。以双十一为例，从销售额来看这无疑是一次前所未有的经济“振兴”，销售行业、制造行业、电子互联网行业等相互协同产生了网购的便利，各行业得到利润，顾客得到折扣，也是共赢的典型成果。

 

 

**![](../Images/78e50bc353c91ab9d482ef493e8bba82.png)智慧生活的基础是什么？**

我们大多数人看到的都是飞速更新换代的生活方式，手机银行、网上购物、网上约车……大家很少有机会去看一看是哪种技术、哪个公司帮我们提供的这些功能，我们都很想知道以后我们的生活会往哪个方向发展？谁来保证我们的信息安全？此次博览会就是来解决大家的问题。

 

此次博览会众多企业带着自己与智慧城市和大数据相关的技术成果来此展示，东软展台位于中央大厅的第一位置。除东软之外，微软、华为、百度、腾讯、中兴和以机器智能为主要业务的新松等公司都参与了此次博览会。东软向大家展示了数字医疗、汽车电子、遍在应用、网络安全等与智慧城市和大数据息息相关的技术成果，网络安全方面的展示让人尤为关注。

![](../Images/78e50bc353c91ab9d482ef493e8bba82.png)**智慧城市与大数据益处多，安全吗？**

信息安全、财产安全、网络安全等，都是在这个时代我们更加关注的。现如今出门在外可以不带钱包，可以不带银行卡，只要带好手机就可以随时支付，快速叫车，火车票飞机票预订酒店都不在话下，对于我们来说，唯一有所顾虑的就是安全。东软NetEye作为国内20年网络安全行业领导品牌，所做的工作，就是努力最大程度的保护信息安全。

 

![](../Images/78e50bc353c91ab9d482ef493e8bba82.png)**信息安全大品牌东软NetEye？为什么我不知道？**

东软NetEye所面对的都是政府、企业等大型客户，虽然为全国乃至世界数亿用户提供网络安全保障，但是您可能并不察觉。举个例子，**东软NetEye为中国农业银行保障网络安全，也就是说您在农业银行所留下的个人信息、存款、密码都受东软NetEye安全产品的保护。东软NetEye为中国东方航空、上海航空等航空公司提供安全服务，在您坐飞机的时候，享受的安全服务便是由她提供。东软NetEye客户遍布政府、金融、军队、电信、教育、电力、医疗、航空、交通、烟草和企业，深入到生活的每一个方面，有安全的保障，智慧城市与大数据才可以放心应用。**

**![](../Images/78e50bc353c91ab9d482ef493e8bba82.png)东软NetEye在此次博览会中展示了什么与我们相关的科技？**

东软NetEye此次博览会重点展示了**车联网安全解决方案S-car和安全运维平台SOC。**

 ![](../Images/811a3c54b9a4324518cc79d69ade4612.png)

东软NetEye车联网安全解决方案S-car

  

今年9月，车载信息安全产业联盟正式成立，东软NetEye作为秘书长单位，当天对外发布了国内第一款车载信息安全产品及解决方案S-car。该解决方案可以在车载智能系统联网的情况下，为汽车智能系统进行安全攻击防御。如果说传统网络安全攻击直接威胁的是信息安全，那么车载安全攻击直接威胁的就是生命安全了。**汽车的智能是智慧城市的典型体现，黑客可以通过攻击你的汽车联网系统，控制温度、门锁、车速甚至刹车，东软NetEye车联网安全解决方案，帮助你抵御黑客攻击。所以在购买带有智能系统的汽车时，千万不要被花哨的功能冲昏了头脑，要看一看有没有相应的车联网安全防护措施。**

 

![](../Images/0aa90084012e14d53289afe5652cf7a3.png)  
东软NetEye安全运维平台（SOC）演示

  

东软NetEye安全运维平台（SOC）则是针对政府、企业等推出的安全管理平台。网络攻击的种类有很多，同一系统所受的攻击是分散的，维护人员、应急小组、事件处理、技术监控等环节相对割裂，SOC将安全流程和问题进行统一运维和管控，可以使用户随时随地掌控核心业务系统的运行状况。**你可以在SOC中看到自己系统各部分的安全状态，有多少网络攻击是来自同一个攻击来源，甚至可以通过对方攻击手段数据的整理，推测对方的目的。智能地帮助你整理这些数据，完成安全运维管理。**
