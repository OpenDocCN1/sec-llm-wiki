# 东软 NetEye DBA中标河北省某市第一医院项目

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=2649207745&idx=1&sn=4508ccc624b782937736f9dc104a29a7&chksm=beedd91b899a500defa16625d8a30a73bd02bd8fd3eef31e34397aa58bb8c28a9aed7211336e&scene=126&sessionid=1681369897#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=2649207745&idx=1&sn=4508ccc624b782937736f9dc104a29a7&chksm=beedd91b899a500defa16625d8a30a73bd02bd8fd3eef31e34397aa58bb8c28a9aed7211336e&scene=126&sessionid=1681369897#rd)

本次东软NetEye中标的河北省某市第一医院，是一所集医疗、教学、科研、预防、保健和康复为一体的大型现代化综合性三级甲等医院，其等级保护整改主旨在于构建一个集安全技术体系、安全管理体系和安全运维服务体系于一体的信息安全保障系统。凭借缜密的方案设计以及良好的产品品质，东软DBA产品以及堡垒机等NetEye安全家族在数据安全、应用安全、网络安全、系统安全和管理安全各个层面上提供了可信赖的解决方案。![](../Images/0f5adbb97b36a90bc5e74e457fe2a463.png)NetEye DBA数据库审计系统具有显著技术优势：是一个完备的数据安全平台，而非单一产品；通过License即可灵活扩展各项功能，如DBFW、DB扫描、DB透明加密等；处理性能高于竞品整整一个档次；可通过策略配置准确检测发现非法统方、倒库等行为；详细记录HIS、LIS、PACS等核心业务数据库系统所承受的各项SQL访问行为。为了解决数据库信息安全领域的深层次应用及业务逻辑层面的安全问题及审计需求，东软在多年数据库安全的理论和实践经验积累的基础上，面向政府、企业的数据库审计系统——DBA应运而生，该产品重点实现细粒度审计、精准化行为回溯、全方位风险控制，为广大用户的核心数据库提供全方位、细粒度的保护功能。2016年，东软NetEye DBA数据审计系统将继续为您的数据库保驾护航，与您一起在数据安全的路上越走越远。
