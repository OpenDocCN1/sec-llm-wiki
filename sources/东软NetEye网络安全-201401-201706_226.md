# 一场只有安全圈精英才能看到的特训……

在4.19网络安全和信息化工作座谈会中，习大大说过**“聚天下英才而用之，为网信事业发展提供有力人才支撑。”**所谓“**梦想不是躺在床上就能实现的”（摘自《东软集团副总裁兼网络安全事业部总经理杨纪文经典语录》），为响应习大大的号召，为国家网信事业输送更多人才，同时为提高国内网络安全渠道技术水平，普及网络安全相关知识，东软网络安全于2016年7月4日至7月8日，于东软集团总部开展了“东软NetEye Club渠道技术精英FY16暑期特训营”。**

接下来学员们一同移步到了课程培训教室，开始了正式的课程培训。课程培训包括“东软NetEye全国渠道发展策略”、“网络安全行业新技术介绍”、“面向安全领域的大数据分析应用平台构建与发展”、“东软各产品功能介绍、产品选型、竞争优势”、“安全新技术探索”、“网络安全产业未来趋势分析”、“等级保护知识”和东软各行业解决方案、具体产品的基本配置实践及案例讲解等。五天的课程在此不一一例举。等待着学员们的是一场安全技术的饕餮盛宴。

**为期五天的培训目前过去了两天，学员们非常认可这种集中培训的方式，也纷纷认为在此次培训中收获很多。“这次是我第二次来东软，每次来都有不一样的感觉。东软的底蕴和朝气非常吸引我，我非常认可东软的企业实力，也非常珍惜此次培训机会，希望日后我们能有更多的学习和合作机会！”参加此次培训的学员如是说。**

  

在后面的三天培训当中，学员们还会接触具体**产品的介绍、基本配置、故障判断及维护等理论和实践培训**。本次培训的反响与效果，东软NetEye会持续为大家报道，请您继续关注！
