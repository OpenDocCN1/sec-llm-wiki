# 东软NetEye亮相 “面向信息化发展的数据安全思考与对策专题研讨会——嘉兴站”

7月1日，由嘉兴电子信息工程协会主办，东软集团股份有限公司、杭州智廷信息技术有限公司联合承办的“**面向信息化发展的数据安全思考与对策**专题研讨会”在嘉兴市市召开，本次会议围绕“信息数据安全、可控网络技术、领先解决方案”和“数据中心微模块的发展”等技术细节展开，邀请了来自东软网络安全的技术专家以及来自智廷的的技术专家向与会嘉宾做主题演讲，通过详实的成功案例介绍相关新成果，共同探讨信息化安全及IT应用创新之道。

![](../Images/8c2334eca542dd1cebd9ae1cc57ab9a1.png)  
会议现场

东软网络安全资深技术顾问俞黎斌分享的 “面向信息化发展的数据安全思考与对策”主题演讲，得到了与会代表的一直共鸣，尤其实针对云计算问做出的详细解读全面深入。余黎斌提到，要保障云安全问题首先需要了解四个重要的信息点：技术构成、安全问题、解决方案以及等级保护。

云计算的技术构成主要分为两个相关的模型，而云计算存在的安全威胁和需求分析主要来自两个方面，一是传统的安全威胁，二是新引入的威胁。从外部看，网络环境、提供的服务和应用没有变化，所以，传统的威胁仍然存在；从内部来看，由于结构发生了变化，云计算平台是在传统 IT 技术的基础上,增加了一个虚拟化层,引入了新的安全威胁。如虚拟化技术本身的安全。多租户共享的隔离性问题等等。**最后，余黎斌着重介绍了东软的云计算安全解决方案，东软网络安全作为中国最大的IT解决方案和服务提供商之一，长期对云计算安全的探索和研究,借鉴行业最佳实践,再结合近期云计算安全建设经验,提出了一套整体的云计算安全保障框架和方法。东软网络安全长期以来以自主产品和用户需求为中心，为高端用户提供整体安全解决方案为服务目标，不断改善并提供优质服务。**

![](../Images/14ea424f2207f8fec84d5a3efd2b2256.png)  
余黎斌演讲

在当前的网络环境的影响下，大数据、云计算、移动互联网、物联网等新技术，在整个智慧城市构建中已不知不觉产生深远影响，在政府的构建中发挥巨大作用，随着网络的发展，安全问题逐渐被提上日程。东软网络安全始终致力于打造全方位的安全服务体系，为各领域提供优质的安全产品以及解决方案，在信息安全服务领域具有绝对的优势。
