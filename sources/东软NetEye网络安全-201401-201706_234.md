# “从需求定义网络安全新市场”——东软NetEye陕西渠道大会

东软NetEye从2014年底全面展开渠道合作的模式，正在向产品化转型的东软本着合作共赢的良性发展态度，为渠道输出行业解决方案和技术支撑体系。6月22日，东软携手西安网迅科工贸有限公司在西安曲江国际会议中心举办了“颠覆·聚赢——从需求定义网络安全新市场“主题渠道大会，与近150家合作伙伴们见证了东软NetEye的网络安全观和市场新格局。  

东软网络安全渠道总监戴志刚、陕西省等级保护专家、东软网络安全陕西省钻石代理商西安网迅科工贸有限公司总经理刘铮等参加了此次渠道大会。

  

![](../Images/efcd7debcc8a75293239b304a0122177.png)  

会议现场

  

东软网络安全渠道总监戴志刚从美国“棱镜门”事件和“爱因斯坦计划”为切入点，阐明了网络安全的必要性，并结合东软NetEye解决方案，揭示了“互联网+”时代下网络安全的诸多需求场景。**东软NetEye是最懂用户业务的安全厂家，拥有完善的直通用户业务的培训体系，合作伙伴与东软的紧密合作把安全与业务系统深度融合服务于用户，提升公司整体业务的高度！**

  

  

![](../Images/603def89ad74611dcba83717ce1253e7.png)  
东软网络安全渠道总监戴志刚演讲

  

  

陕西省等级保护专家讲解了等保的核心内容，各级等保的建设要求，结合东软NetEye网络安全产品实际应用。

东软网络安全渠道经理杨帅在会上与合作伙伴们进行了深度交流。他提到网络安全不仅仅是产品更重要的是一套安全体系。通过跟合作伙伴的合作建立用户端完善的安全体系技术支撑和服务能力。杨帅介绍了东软NetEye全线的网络安全产品，从防御，审理，管理到云安全完整的安全解决方案，同时对陕西网络安全市场现状进行了详细分析。希望与合作伙伴携手推进陕西市场网络安全建设。

  

  

![](../Images/d8780153d377103da94fdfd0c9ff0ece.png)  

东软网络安全渠道经理杨帅演讲

  

  

西安网迅科工贸有限公司安全产品经理刘启萍对公司渠道政策进行了详细的宣讲，会场上现金形式奖励了数名代理商销售。作为东软NetEye钻石代理商，西安网迅不仅提供全线安全产品，售前咨询服务，样机测试服务，还提供《信息系统业务安全服务资质》的办理服务，是西北独家咨询办理单位。

  

  

![](../Images/ab50085ddf2cf42c71f2ccef00f525d9.png)  
西安网迅刘启萍演讲

  

  

此次渠道会是东软在陕西地区的重要发声，2016以来，东软NetEye本着合作、共赢的态度在全国范围内构建了更加完整的渠道生态体系，给全国的渠道商带来网络安全产品和服务。因需而变，因御而安！
