# 东软网络安全受邀参加邢台医院协会信息管理专业委员会成立大会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=2649207428&idx=2&sn=88ba368566e5db52564dcf25974bfbdb&chksm=beedd85e899a514822f09677e55d8d8a49f04664b8c9d524adef83e3e3b11f4d3049b6c3a48e&scene=126&sessionid=1681369918#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=2649207428&idx=2&sn=88ba368566e5db52564dcf25974bfbdb&chksm=beedd85e899a514822f09677e55d8d8a49f04664b8c9d524adef83e3e3b11f4d3049b6c3a48e&scene=126&sessionid=1681369918#rd)

5月14日，由河北省邢台市医院协会主办的“邢台市医院协会信息管理专业委员会成立暨医院信息建设学术交流会”在邢台盛大召开，邢台市卫计委、邢台市医院协会主要领导，邢台市区医院、邢台各区县人民医院及中医院信息中心主任及分管院长出席了此次会议。信息安全界领军企业东软NetEye受邀与钻级代理商河北贝恩电子科技有限公司参加了此次会议，并做为唯一安全厂商讲解了“东软医疗行业安全解决方案”，着重强调了网络安全在医院信息化建设中的重要性。![](../Images/8e6caa9edbe92f4eecc1ea986dd6215f.png)参会嘉宾合影留念东软网络安全高级技术顾问赵彦皓在现场，针对“东软医疗行业安全解决方案”做出了技术分享。赵彦皓提到，伴随医疗数据价值的提高，也带来了更高的风险隐患， 针对医疗行业特点，东软NetEye推出的医疗行业的解决方案，充分满足行业需求，技术上专注风险预警、大数据分析的安全动态感知系统，达到360度的全面保障。赵彦皓从技术、产品、安全服务、制度管理几方面介绍了医疗行业解决方案。 ![](../Images/305df9ca04fb2b6f1f8f5c27439afd38.png)现场主题演讲东软NetEye产品线以边界防护、虚拟专用网、入侵防护、安全管理、流量管理、安全审计、安全风险评估为主。不论是小型企业，还是大型互联网数据中心，东软NetEye均能根据不同客户的需求提供高品质的网络安全产品、专业化的安全服务以及面向客户应用的网络安全整体解决方案。秉承多年的专业技术经验积累，东软持续为用户提供成熟、先进的网络安全产品以及高效、完善的安全解决方案与服务，努力将东软NetEye打造成为全球领先的网络安全产品及服务供应商！
