# 东软NetEye携下一代防火墙出席英特尔信息技术峰会（IDF）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=2649207309&idx=1&sn=5eb907e89dd1dbc56240803e17947c80&chksm=beedd8d7899a51c149c4ac78cd97086cadeea4456073dd6d59b5f8d4df8879a9d3c0c62b2f39&scene=126&sessionid=1681369928#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=2649207309&idx=1&sn=5eb907e89dd1dbc56240803e17947c80&chksm=beedd8d7899a51c149c4ac78cd97086cadeea4456073dd6d59b5f8d4df8879a9d3c0c62b2f39&scene=126&sessionid=1681369928#rd)

由英特尔主办的全球行业技术峰会——2016年英特尔信息技术峰会（Intel Developer Forum, IDF）于北京时间4月13日在深圳大中华喜来登酒店正式拉开帷幕，本次信息技术峰会以“精彩源于您的创新”为主题，为期两天。英特尔信息技术峰会（IDF）是由英特尔主办的全球最负盛名的技术论坛，是集发布、交流、展示计算机软硬件和网络、无线、通讯等领域最新技术及产品的年度盛会，吸引了众多参展商前来参展。东软网络安全事业部与英特尔合作多年，尤其在高端产品领域一直合作密切，作为重要的战略合作伙伴，今年再次受邀参加盛会，共同见证精彩一刻。

  

![](../Images/d8a6156b15d18683ed7dcba0ce632b53.png)  

东软集团网络安全事业部华南大区经理柯利平等代表网络安全事业部出席了此次展会。展会上，东软NetEye全面展示了信息安全产品设备和解决方案。尤其针对**集成安全网关NISG5000、NISG6000**和**下一代防火墙**进行进行现场产品演示活动，并有高级技术顾问为每一位前来咨询的参会人员讲解东软NetEye产品的性能以及优势。此次展会，东软产品展台前吸引了众多参观人员前来咨询、体验，了解我们的前沿产品及创新。

 

**东软网络安全下一代防火墙是****国内第一批通过公安部下一代防火墙标准，并且第一批拿到下一代防火墙销售许可证的品牌产品**。该产品除了具备传统防火墙功能以外，更关注应用层的安全防护，如集成庞大的应用特征库、入侵防护特征库、病毒库、漏洞库（漏扫）等；支持对应用层协议的QoS限速，彻底改变了传统防火墙的检测机制，通过各模块协同处理与优化，构建更为高效的协同并行处理架构；支持IPv6环境下的协议识别、入侵防御、URL过滤、垃圾邮件防御、病毒防护等几乎全部UTM功能。

  

![](../Images/80ee8413af3fd202a9cba0d43f36a763.png)

东软网安产品在政府、金融、医疗、电力、电信等重点行业中的大型IT系统建设中具有丰富的经验，2016年东软NetEye始终秉承着将信息安全产品和解决方案与行业应用深度结合的理念，东软旗下的网安产品，包括针对数据中心的高性能防火墙、解决分支机构安全防护问题的桌面级集成安全网关以及针对数据中心与分支机构的安全互联、云计算安全、基于权限管控及安全运维的态势感知平台等和整体安全解决方案，都将持续服务于广大行业客户。

  

![](../Images/384a2cace4b550e42c0e9a47da0347d8.png)

本届英特尔信息技术峰会的成功召开，意在与大家一同分享英特尔与中国共成长的战略规划。方便了解到英特尔与众多合作伙伴的最新进展，领略前沿炫酷的技术体验，共同探讨未来计算的创新趋势。东软NetEye也将持续创新，为广大行业客户提供更丰富、更成熟的信息安全产品和解决方案。
