# 2016年东软NetEye核心渠道合作伙伴沟通会在沈阳成功举办

新的一年刚刚开始，“爱折腾”的东软网络安全就开始了首场核心渠道合作伙伴沟通会。（请忽视以下市场部的表情……）

  

![](../Images/62cb8a946a1df26cc430f91c2800b5ec.png)  

  

  

2016年1月10日，东软NetEye核心渠道合作伙伴高层沟通会议在沈阳东软软件园成功举办，近30家核心渠道合作伙伴参加了此次会议。东软集团副总裁兼网络安全事业部总经理杨纪文做会议发言，强调2016年东软网络安全事业部将以“为渠道合作伙伴创造更大的利润和价值”为核心，致力于建立更务实、有序、透明、健康的渠道发展体系。

![](../Images/318242f0988e85ab51cbc8f0054c4aa7.png)  

**“好卖”才是硬道理**

从可满足数据中心高性能需求的高端防火墙，到面向中小企业和分支机构的桌面级集成安全网关，东软NetEye网络安全产品以高性能、高稳定性和与客户应用高度结合为核心特点，服务于政府、金融、能源、医疗、通信、教育等大型行业客户和中小型企业。2015年，东软NetEye推出了160G高性能下一代防火墙、桌面级集成安全网关等一系列创新产品，发布了业界首款国家级认证的自主可控千兆防火墙产品，以及云安全、虚拟化安全整体解决方案，满足行业客户及渠道合作伙伴不断变化的信息安全防护需求。

![](../Images/05402c72a36b49579f3863a9dd255f8b.png)

**授人以鱼，更要授人以渔**

  

**除了“好卖”的产品以外，东软NetEye认为提升渠道合作伙伴在技术服务和市场拓展方面的软实力同样重要。**

  

2015年东软网络安全举办了7场大型渠道招募活动和覆盖全国8个大区的多场渠道培训，开启了东软NetEye有史以来最大规模的渠道开拓模式。而这个记录将在2016年被再次刷新。2016年，东软NetEye将继续加强与渠道合作伙伴的紧密互动，计划在各区域增设更多的渠道专属支撑力量，通过制定标准化的培训认证体系，达到每周有交流，每月有培训，每季度有技术认证考试的渠道培训常态化。

东软NetEye致力于为客户构建覆盖总部、分支机构、云端&虚拟化、移动办公等全方位、立体化的网络安全防御体系。2016年，东软NetEye将继续为各行业客户及合作伙伴提供先进、高效、稳定的信息安全产品、解决方案与服务，与各地合作伙伴合力共建高效、健康、可持续发展的渠道发展体系。
