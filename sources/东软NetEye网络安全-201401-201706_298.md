# 东软NetEye渠道合作伙伴大会在郑州完美收官（这次真的是今年最后一站啦）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=400471630&idx=1&sn=b12d274bc78b10494fce9f256a7bc0f8&chksm=34d4dc9403a35582e1831c0981252a39822fd74fa911192337c2c4dc2edd6e247c684117bd1b&scene=126&sessionid=1681369943#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=400471630&idx=1&sn=b12d274bc78b10494fce9f256a7bc0f8&chksm=34d4dc9403a35582e1831c0981252a39822fd74fa911192337c2c4dc2edd6e247c684117bd1b&scene=126&sessionid=1681369943#rd)

2015年11月27日，以“合作发展，共赢未来”为主题的东软NetEye渠道合作伙伴大会在郑州喜来登大酒店隆重召开,华北区域80多家渠道合作伙伴公司代表参加了本次会议。

  

![](../Images/9d9515d48a8c51df9d76a5a6f3ed14bd.png)  
  

东软集团华北大区副总经理盖龙佳作会议致辞，表示郑州作为2015年东软NetEye渠道合作伙伴大会的收官之站，东软安全将与华北区域各合作伙伴携手并肩，共享产业发展的盛况、共赢美好的未来。

  

东软网络安全渠道总监戴志刚以“构建共赢的渠道体系”为题介绍了2016年东软网安渠道发展策略。东软网络安全技术团队则为到场的合作伙伴详细介绍了东软NetEye网络安全产品的亮点和技术优势。东软NetEye将继续秉承自主、创新的原则，持续为行业客户及合作伙伴提供高性价比、高稳定性、满足各行业用户安全防护需求的网络安全产品与服务。

  

![](../Images/a67d1c585059922479b99fe839dad577.png)

![](../Images/785c73d4456ae0ba5de40b986c10ca38.png)

  

此次渠道合作伙伴大会是东软NetEye2015年渠道巡展的最后一站，2015年东软NetEye加大渠道拓展的力度，在多地举办了渠道合作伙伴沟通活动和技术培训会议，加强了与合作伙伴们的互动，加深了彼此的了解，加强了双方合作的信心，为2016年继续开展互利共赢的友好合作奠定了坚实的基础。
