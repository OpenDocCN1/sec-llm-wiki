# 东软解决方案论坛2015在贵阳盛大启幕

10月30日，东软解决方案论坛2015（贵阳）在有着“中国数谷”之称的贵阳揭幕。在本次论坛上，东软发布了其在互联时代的新解决方案战略，并公布了以知识资产为核心，以行业解决方案、智能互联、平台、云与数据服务为四个核心板块的新业务架构。东软的新解决方案战略预示着东软将从传统解决方案提供商转型为互联时代下的新解决方案提供商，东软以创新推动发展将开启新的征程。

![](../Images/8fa6938c3e581e8f6a29f0a8b71af9c0.png)  

据介绍，新解决方案是东软基于技术形态，商业环境的变化，在互联时代做出的战略选择，融合了东软历次创新和转型发展的智慧，是东软推动持续发展的新特征和新表达。东软认为，新解决方案主要表现为三大特征：即扩展，新解决方案不单单满足客户对IT技术和功能的需要，更要服务于客户的客户，创造客户的商业与业务发展的成功，并且与客户利益和社会发展方向保持高度一致。其次是变革，新解决方案不仅仅是技术的展现，更重视和支持客户业务模式的变革，与客户一起通过新解决方案架构与新服务模式的创造推动东软与客户业务发展模式的变革和价值的创造。第三是精准，新解决方案要通过大数据挖掘、人工智能创造卓越运行与精准经营的时代。商业模式变革、互联与社区、大数据与商业智能、技术的卓越、价值创造成为新解决方案的五大核心要素。

  

一直以来，东软始终站在社会发展和客户需求的角度，不断思考IT解决方案的价值，探索符合消费者习惯和需求的新解决方案建设模式，致力于推动社会基础行业和重点民生领域信息化建设水平的不断提升。2011年，东软以多年行业信息化建设实践和积累为基础，依托移动互联网、云计算、大数据、物联网新技术，积极推动面向互联网的业务、战略和商业模式转型与创新。2015年，东软基于过去5年来的转型与创新实践，系统性、战略性提出行业信息化建设新解决方案，以期为政府、企业把握新时代的发展机遇，实现商业模式的创新和转型提供有价值的实践。

  

东软指出，解决方案是创造客户的价值与社会发展动力的充分融合，在新解决方案战略下，东软将秉持新技术、新服务、新模式、新价值，发展解决方案，通过创新的信息技术和商业模式推动社会的发展与变革，为个人和社会创造价值和新的生活方式。基于新解决方案框架和新业务架构，东软将越来越注重平台的价值，利用SaCa和UniEAP等平台帮助客户在互联网时代下实现创新和转型；此外，东软将致力于构建新型客户伙伴关系和新型商业模式，实现业务的专业化、IP化和互联网化转型，推动公司商业模式由传统的B2B向B2B2C、B2C、X2B2C拓展；同时，东软将利用大数据技术驱动更精准的客户洞察和运营优化，实现客户智能、物联网智能和运营智能，真正实现与客户协同创新。东软也将通过IoT策略，不断推进物联网与新解决方案的融合。通过与资本市场的结合，以技术和商业模式差异化发展，驱动组织整合与优化。

  

东软集团董事长兼CEO刘积仁博士在论坛上发表题为《新生态下的新解决方案》主题演讲时表示，互联正在改变着我们的工作、生活生态，融合、分享、技术与新商业模式的创新在重构解决方案的内涵。在每个社会发展的历史阶段，商业都会呈现出不同的形态，也都会必然产生相应的生态。我们过去谈互联网思维，更强调互联，社交，商业模式，而今天的互联网的发展需要更多的计算，智能，分享与融合，是与更多的行业变革的深度整合。互联网已经从电子商务，中介，社交等领域的成功向更深入的行业解决方案领域发展，垂直行业之间的整合，数据的分享，人与物的互联，将创新出更多的新的商业形态和业务模式，而软件行业将在变革中成为更重要的角色。

  

![](../Images/9c4bc11b0cb466877aea045c4d0ef6ee.png)  

  

随后，刘积仁博士从互联与普及的价值、社区的力量、APPS经济、协同与分享、数字空间的商业模式、数据是财富、计算的威力、透明的商业、平台创业的时代、商业的娱乐、超越组织的学习等十一个维度，详尽地阐述了互联网时代下的思维和商业价值。他表示，在互联网时代，企业要有一个开放的心态，要学会拥抱互联网，而不是墨守成规。今天的互联网所产生的消费概念，已经彻底改变了我们对传统软件的定义，对软件结构的定义、对硬件结构的定义、对组织和商业文化的定义，传统的解决方案已经无法满足社会发展和客户需求的快速变化。

  

刘积仁表示，面向未来，东软将通过持续的创新，不断完善新解决方案，为客户创造互联时代的新价值。首先，在市场领先的社会保险、商业保险风险控制及商业模式变革等业务领域，提供新型解决方案与大数据战略；其次，面向智慧城市的医疗、教育、交通、就业等重点民生领域，致力于打造新型的解决方案；第三，在重要行业和企业领域，东软将持续基于现有的解决方案进行创新和转型，不断向最终端客户扩展和延伸；第四，在汽车电子、医疗健康等领域，不断将物联网技术融入解决方案，帮助客户真正实现互联互通；第五，东软将通过超越解决方案的整合，打造更加开放、完整的新商业模式，为客户、为社会创造更大价值；第六，加快公司自身的组织的变革，提升运营管理能力和核心竞争力，推动公司快速实现转型。

  

本届东软解决方案论坛的主题为“新解决方案的商业与创新”。围绕这一主题，论坛还举办了大健康、互联网+、智慧政府、信息安全等平行论坛，来自政府、合作伙伴与客户、研究机构、大学等近千名嘉宾出席。富士通、华为、IBM、英特尔、联想、Oracle、Redhat等IT厂商参与了本次论坛。
