# 成都东软学子摘得全国信息安全技术大赛桂冠

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=209026454&idx=1&sn=3700b8824fcd56112e6c157eddf6337c&chksm=2f7f174c18089e5a8980eaa1c7c7784d7aedabdf4c2355cb1a7156ad9b7a26243569950c8b4b&scene=126&sessionid=1681369958#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=209026454&idx=1&sn=3700b8824fcd56112e6c157eddf6337c&chksm=2f7f174c18089e5a8980eaa1c7c7784d7aedabdf4c2355cb1a7156ad9b7a26243569950c8b4b&scene=126&sessionid=1681369958#rd)

8月2日，由中国互联网协会、四川省教育厅共同组织主办，成都信息工程大学、四川省信息安全测评中心承办的“全国暨四川省大学生信息安全技术大赛”在成都信息工程大学航空港校区成功落下帷幕，来自成都信息工程大学、四川大学、中国矿业大学、福州大学、西南石油大学、西安工业大学等31所省内外高校共68支队伍参加比赛。

  

![](../Images/65b1adf2912e5de2b748cb6fae2a1e11.png)  

  

成都东软学院计科系信息安全技术专业13级的温世民、余晓东、邓力组成了成都东软学院1队、14级信息安全技术专业陈睿、刘康、孙珏娥组成了成都东软学员2队参加了比赛。最终，成都东软学院1队以全国总分第一名的成绩荣获特等奖，成都东软2队荣获一等奖。

随着信息技术的快速发展和互联网应用的普及，网络安全的重要性愈加凸显，对网络安全领域专业人才的需求也急剧上升。东软不仅拥有高性能、高稳定性的网络安全产品和成熟的行业安全解决方案，在网络安全人才储备方面也早有准备和部署，而网络安全专业人才储备也是东软NetEye的核心竞争力之一。近年来，东软NetEye一直为国家层面提供重大事件期间网络安全保障和应急响应工作，协助各行业客户处理了包括大规模病毒爆发、网络入侵、拒绝服务攻击等上百起重大紧急安全事件。帮助客户快速恢复系统的保密性、完整性和可用性，保障业务的连续性和整体系统的安全稳定运行，是东软NetEye的能力所及，也是职责所在。同时，配合全国八个大区、40多个城市的本地化服务，东软NetEye随时随地响应客户的各类网络安全防护和服务需求。
