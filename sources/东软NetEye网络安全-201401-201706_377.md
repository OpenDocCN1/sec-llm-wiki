# “永哥和你聊安全”系列之——密码安全

最近，永哥入手了一个新版Xbox，爱不释手，于是赶紧申请了个账户，准备开玩儿。可家人抱怨说密码太复杂，对于使用手柄的Xbox来说，输入密码十分费力。永哥只能无奈一笑，想想作为网络安全从业人员的家属，安全意识都这么低，说明大众这方面的意识普及得还十分不到位。所以，今天永哥想和大家聊聊密码安全。

 

在如此依赖互联网的今天，信息和网络安全谁来保证？完全依托于技术显然已经不现实，那问题来了，不依托于技术难道靠我们自己？作为普通网民何来专业技能应付这么复杂的安全问题？

 

永哥认为，只要是技术，就有存在问题的可能；既然存在问题，就会给攻击者可乘之机。那么这就是个成本问题了。如果是一些普通的无关紧要的论坛账户丢失，顶多就是被冒发几个帖子，然后道歉了事，从此隐匿论坛。但如果银行账户存在风险，谁又为你的损失买单呢？血淋淋的教训比比皆是。2014年最火爆的安全事件莫过于“好莱坞艳照”事件，媒体已经从各种角度进行了解读：“据美国科技新闻网站Venturebeat等网站报道，大量影星的密码帐号被盗取，仍然和苹果iCloud平台的安全机制不健全脱不开干系。据称，早在半年前，一位名叫巴里科（IbrahimBalic）的英国软件工程师对新闻界爆料称，他曾经发现了苹果iCloud的一个漏洞，可以绕过防火墙，采用暴力破解的方式，获取用户密码。巴里科表示，他曾经和苹果公司相关部门多次通过邮件沟通，向苹果告知了iCloud存在的这一漏洞。”（http://tech.qq.com/a/20140925/071140.htm）

 

**生于忧患，死于安乐**

 

想必大家会问，既然是icloud漏洞我们如何防范？作为技术人员，虽然这个问题归咎于apple的安全漏洞，但这中间，被攻击成功的手机用户也有不可推卸的责任。

我们还是说一下前面提过的问题 “成本”；如果将攻击者的攻击成本增加到只存在于理论攻击的可能，那么我们就认为这是相对安全的。**按照现有的设备计算速度，用时下最快的普通计算机，暴力破解一个含有数字、字母、大小写和特殊字符的八位密码需要一年以上。**接下来可以考虑这样一个问题，你是否值得攻击者花一年时间去破解密码？

 

即便真的花一年时间去破解你的密码，如果你**几个月更改一次密码，那么攻击者也将无计可施。**至少可以保证，在服务出现漏洞的前提下，采用复杂的密码和频繁更换密码就可以规避大部分的风险。

 

**永哥建议**

 

技术对抗时刻存在，谁也保证不了防护技术不会被攻破，那么就只能提高我们自己的安全意识，**加大密码强度，频繁更改密码**。凡是负责任的网站都会有相关的提醒，当我们涉及安全问题的时候，要仔细参看网络提示，采取相应的手段，来保护我们的个人隐私。顺便提一下，再安全的网站也有被攻破的可能，为了防止撞库（即：用你的一个网站密码，去尝试在另一个网站系统登陆），最好的解决办法，就是**尽量在不同的网站系统，采用不同的密码**，最大程度地保护个人信息的保密和安全。
