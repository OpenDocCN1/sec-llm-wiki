# 从被动跟随到主动突破 ——访东软集团副总裁兼网络安全事业部总经理杨纪文

网络信息安全事关国民经济、国家安全和人民生活等各方面，在互联网高速发展的今天，信息安全与国家、企业、个人都密切相关，因泄密而带来损失的案例屡见不鲜，信息安全实力影响着国家的政治、经济、军事、国防实力。那么，国内信息安全产业处于一个什么样的状况，在技术和产品方面国产信息安全设备以及软件是否做好承担起信息安全防护盾的准备，《中国投资》杂志采访了较早进入信息安全领域的东软集团副总裁兼网络安全事业部总经理杨纪文。

  

**《中国投资》：**今年初国家成立了信息安全领导小组，随着信息安全事件的频发，国家层面对信息安全重视程度也是日益提升，在重大的基础设施领域，可能有特别强烈的信息安全的需求。请您介绍一下，目前的国内这种信息安全产业的发展状况。  

  

**杨纪文**：现在发展的状况，国内已经是群雄逐鹿的态势。东软网络安全业务起源1996年，中国网络刚刚兴起之时。东软成立了东软网络安全实验室，几个年轻人开始中国信息安全梦的追求之路。1999年东软防火墙产品开始了批量化生产。算起来东软网络安全业务很早就跟着集团上市了。现在在全国的范围内，能够参与竞争，或者是有规模、有技术积淀、能做大、做强的网络安全的企业，可能仅仅有十家左右，但是已经达到群雄逐鹿的局面，而且还有很多地方性的网络安全产品公司在不断的成长。

  

我们面临的最大的问题是怎样使中国的网络安全行业真正地和世界接轨。国内的信息安全产业，不论是从技术上，还是从产品来说，虽然各有优势，但是都带点有特色的模仿，这是我个人的定义。绝大部分的中国安全企业都面临着如何能尽快地在某一个领域或者某一个技术层面，进入世界的先进行列的问题。

  

**《中国投资》**：您判断整个IT领域里的信息安全产业会朝哪些方向发展？  

**杨纪文**：主要是三大方向。

一个是高端持续威胁，就是APT攻击防范。因为会涉及到很多高层面及国家安全领域，一定会是国内主流安全企业的发展方面，国家和很多高水平的研究机构都会在这方面投入。

  

第二个是在移动终端安全。目前为止大家的通讯数据，个人隐私、位置跟踪、金融交易等等，都会越来越多的在移动终端上实现。因此这块安全市场也会是很大的方向。

  

第三个方向是虚拟化存储。一般人基本的安全意识都比较薄弱，其实所有虚拟的存储，黑客都能够通过技术手段监控到。没有价值的他不管，万一有了他感兴趣的数据，比如你是一个名人，有一些比较隐私的东西，黑客都可以窃取到为之所用。云应用，包括云盘，很多人用着感觉非常方便，但如果不能处理好云安全，随时都会给你带来信息泄露的风险。

  

**《中国投资》**：请您判断一下信息安全产业下一步发展是什么样的，发展趋势会怎样？

**杨纪文**：现在大家都会说在IT领域，信息安全是最有希望，也是最具有创新机会的市场。

  

先谈谈市场份额巨大的事。我们做初步的测算，每100块钱的IT投资，应该带来10块钱的信息安全的市场。可以想象，中国这么多年的IT投入有多大，或者全球IT投入有多大，仅仅从商业计算角度考虑，这个市场就是巨大的。说到数据的积累，还有一个沃尔玛在十年前的大数据分析的故事。沃尔玛通过大数据分析，发现在美国市场，纸尿裤和啤酒的销售量相关性极强。后来发现，美国男人买啤酒的时候顺便把纸尿裤买了，因此后来把纸尿裤和啤酒放在一起，销量提高了10%，说明了数据分析带来的价值，现在的关联性分析更是如此。医疗数据、健康数据等等，这些积累带来的就是信息安全市场的市场积累。我觉得这一定是IT领域最有前途或者是希望最大的一块市场。

  

再谈中国安全企业的梦想和创新机会。中国信息安全企业很多都是想做事的企业，东软也是其中之一。我与国内一些芯片厂商负责人探讨的时候，看到大家都开始走到这个层面了，各自技术积累也都很厉害，让我很敬佩。大家考虑的是同样的问题。除了为股东和员工提供企业持续的盈利能力之外，所有的企业都希望把自己做成产业的领军者而不是跟随者。从我们国内的安全厂商来看，东软具备得天独厚的条件，一来东软安全在信息安全技术上有着18年的技术积累，二来东软集团在各个行业领域里有着20多年的深厚行业应用技术解决方案的沉淀。既然我们迎来了这个机会，又积累到了这个层面，我们更不应该丧失这个机会，东软血液里就有一种愿意迎接挑战的企业精神。 

  

随着中国信息安全市场的逐渐成熟，竞争机制逐渐完善，投机盈利的机会逐渐减少，产业恶性竞争泛滥的时代逐渐规范。要想盈利企业发展的唯一途径就是创新。从被动跟随到主动领导，我坚信中国信息安全企业都会有这样一个梦想。我也坚信中国未来会出现不需要模仿、而是被模仿的创新型安全企业。我们要走的路还很长，很有挑战，但是这并不妨碍中国信息安全企业在国家的支持下坚定地走下去。
