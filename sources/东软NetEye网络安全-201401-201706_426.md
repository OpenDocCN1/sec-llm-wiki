# 东软统一身份管控系统首次亮相，一举斩获今年软博会金奖

2014年5月底，第十八届中国国际软件博览会（软博会）的隆重召开一如既往的吸引了众多参观者。东软NetEye统一身份管控系统（堡垒机）首次亮相便一举斩获了软博会最高奖项金奖，引起业界的普遍关注。

  

东软NetEye统一身份管控系统的设计初衷旨在为高端行业用户解决IT运维管理和IT内控外审问题。它将众多管理员账号和设备的账号进行统一管理，建立统一的权限影射关系，呈现一个统一的运维管理门户。东软NetEye统一身份管控系统采用物理旁路，逻辑网关模式部署，在不影响业务稳定性的前提下，极大地提高了运维管理的效率和安全性。

  

其主要产品功能和应用价值体现在以下几方面：

  

**支持多种协议、设备，单点登录提高运维效率**

全面支持主流的字符、图形运维协议，兼容目前几乎全部网络设备及操作系统、Web应用系统、中间件等。在进行全部设备托管后即可通过单点登录进行密码代填，大大提高运维效率。

  

**精细的访问控制，有效降低操作风险**

东软NetEye统一身份管控系统可以根据时间、IP、命令黑白名单、用户组、服务器组、角色等对运维管理员进行精细的实时访问控制，同时支持双人复核运维流程，特别适用于运维外包的大型企业。

  

**准确的操作还原****，便捷的事后取证**

东软NetEye统一身份管控系统采用操作还原技术，能够自动展现操作流程，监控每一次行为，并判定该行为是否对企业内部网络安全造成危害。操作还原功能有效降低了恶意操作的可能性。

  

同时，设备具备单点登录、多因素认证、双人复核管理流程等更多实用功能，为用户系统运维安全保驾护航。
