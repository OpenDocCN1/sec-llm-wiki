# 阿里云与东软强强联合 携手共拓云服务市场

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=200042217&idx=2&sn=f93c687662312b0ebc6243eca46fd10a&chksm=28e60c331f918525f38c9dfe2b61d1992512a756ddedb05a39519d38441ac2e1a52f49fd1a1d&scene=126&sessionid=1681369988#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=200042217&idx=2&sn=f93c687662312b0ebc6243eca46fd10a&chksm=28e60c331f918525f38c9dfe2b61d1992512a756ddedb05a39519d38441ac2e1a52f49fd1a1d&scene=126&sessionid=1681369988#rd)

2014年2月24日，中国·北京】近日，东软集团股份有限公司（以下简称“东软”）与阿里云计算有限公司（以下简称“阿里云”）宣布，双方正式签署战略合作协议，将在全球范围内就政府与公共事业、企业、IT运营等领域展开产品与技术、解决方案与服务、市场联合营销与拓展等全方位的交流与合作。

  

根据协议，双方将共同推进相关领域云服务业务的发展：东软旗下SaCa、UniEAP系列家族产品将支持基于阿里云平台的部署与运维，成为阿里云重点推荐的云应用支撑服务；同时，阿里云将成为东软面向云业务领域的重点合作伙伴，为客户提供更加灵活、自主可控的信息化系统。

  

协议签署后，东软与阿里云将共同推进与合作领域相关的产品认证培训、生态系统建设、市场联合营销与拓展等工作。双方通过优势互补，互利共赢，共同推进相关领域云服务业务的发展，以创新型技术和解决方案服务于国内外客户。

  

阿里集团首席技术官王坚博士表示，阿里云始终致力于打造公共、开放的云计算服务平台，通过创新的技术和服务为合作伙伴、客户和开发者创造价值。东软是中国最大的IT解决方案与服务提供商，在政府与公共事业、企业等领域拥有卓越的技术和资源优势。此后，阿里云将为东软提供强有力的云计算技术支持，相信双方的密切合作将有助于各自优势的充分发挥和市场渠道的有效拓展，从而为行业客户提供更加便捷、高效、安全的解决方案与服务，推动云服务业务的快速发展。

  

东软集团高级副总裁兼首席技术官、首席知识官张霞博士表示，东软在行业解决方案与服务领域深耕二十余年，在深入理解行业与技术市场发展趋势的基础上，始终重视客户价值的提升和解决方案/产品与服务的创新与高效交付。SaCa、UniEAP作为东软重要的云应用平台和企业应用基础架构平台，对于提升客户体验和解决方案开发与交付效率起到了重要的支撑作用。阿里云提供了公共、开放的云计算服务平台，与阿里云展开合作后，双方将加强在技术、资源、市场等方面的交流和互动，提升客户价值，实现与客户、合作伙伴的共同成长。
