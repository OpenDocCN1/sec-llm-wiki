# 2014中国IT市场年会在京举办，东软继续领跑防火墙市场

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=200042217&idx=3&sn=672be1fcdebbe962991d55713cdbc372&chksm=28e60c331f9185253a9d97d19e0911c3f557c26da773cd82624493b320401cfeddc4c9fc9ec5&scene=126&sessionid=1681369988#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=200042217&idx=3&sn=672be1fcdebbe962991d55713cdbc372&chksm=28e60c331f9185253a9d97d19e0911c3f557c26da773cd82624493b320401cfeddc4c9fc9ec5&scene=126&sessionid=1681369988#rd)

2月20日，由赛迪顾问股份有限公司主办的2014中国IT市场年会在北京香格里拉饭店隆重举行。本届年会以“信息助力消费，数据提升价值”为主题，吸引了700余名政府领导、知名学者、企业领袖、行业用户和媒体代表到现场交流，气氛热烈，场面壮观。

  

来自工业和信息化部、中国社会科学院、中国电子信息产业发展研究院、赛迪顾问以及知名企业的代表分别在大会上做精彩发言，对未来经济形势、信息消费趋势、大数据创新应用及信息技术变革等问题进行了深度的分析与探讨。在分享前沿经验和畅想未来趋势的同时，主办方经多方调研评选出了一批年度市场成功企业和创新产品，东软NetEye荣获2013-2014中国防火墙产品市场年度成功企业称号，引起业界专家、行业用户和广大媒体的关注，东软NetEye防火墙产品在市场中的良好表现再次获得业界肯定，继续领跑防火墙市场。  

  

一年一度的IT市场年会为行业用户和IT厂商搭建了交流和沟通的平台，为地方政府发展IT产业提供了指导性意见，对推动中国IT产业及应用市场的发展起到了重要的作用。本届年会深入分析了中国IT产业现状及未来趋势，结合新时期、新形势下产业发展趋势，共同探讨了推动市场发展的原动力。“信息助力消费，数据提升价值”，2014年面对新的发展方向和新的机遇，东软安全将全力以赴。
