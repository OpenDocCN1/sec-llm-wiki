# 东软NetEye合作伙伴培训获奖学员感言

2014年东软NetEye全国合作伙伴售后工程师认证培训获奖学员感言节选：

![](../Images/05386e35ff7c1c125b6f05f74b61c805.png)

        淮安天鑫达科技服务有限公司**刘百千**    

**获奖感言：**“衷心感谢东软精心安排的培训,大家一起听课、一起交流、一起研讨方案。谢谢老师们用心良苦,细心的讲解，真心地感动！祝东软的事业红遍九州，东软的员工与合作伙伴遍布世界各地。”

![](../Images/c4bac5bbb99a8dd8b1138a8c858eeb87.png)

          **杭州通厚科技有限公司****段志辉**

**获奖感言：“**在培训之前，接触过部分安全产品，由于实施过程都是厂家直接安装调试，只是大概的了解产品的部署方式及部分功能的配置，对于如何完整的部署一台设备没有一个概念。通过本次的培训，系统地学习了各类安全产品的整个配置流程，对于各类产品的部署配置有了较清晰的思路。尤其是培训讲师对于本次培训产品各类应用案例的介绍及实施步骤的梳理，感觉非常的受用，对于今后项目实施方案的制定及项目实施会有很大的帮助。最后，非常感谢东软组织的这次培训！”

![](../Images/d1e330f6200a2d30ee211288c7a72f3f.png)

        合肥东联信息技术有限公司 **蒋明浩**  

**获奖感言：“**通过这次培训，使我对东软全系列产品有了更加深入的了解，对以后的安装与调试有非常大的帮助。”
