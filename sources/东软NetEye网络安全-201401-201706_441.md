# 2014东软NetEye全国合作伙伴售后工程师培训在沈阳成功举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=10015074&idx=3&sn=ee3a81036874e42fba98e64085957561&chksm=2392bbb814e532ae94eeb852216c02afade49357aad00011ad5d5920cc03d9aeb4cc5b7a85a0&scene=126&sessionid=1681369988#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=10015074&idx=3&sn=ee3a81036874e42fba98e64085957561&chksm=2392bbb814e532ae94eeb852216c02afade49357aad00011ad5d5920cc03d9aeb4cc5b7a85a0&scene=126&sessionid=1681369988#rd)

2014年1月6日，东软NetEye全国合作伙伴售后工程师培训在沈阳东软软件园拉开帷幕，来自全国的近20家合作伙伴工程师参加了培训。

  

在为期五天的培训期间，通过产品理论讲解和现场演示，参加培训的工程师们将全面了解东软NetEye信息安全产品的技术特点和操作要领，为项目实施过程中更好地应用并最大限度的发挥东软NetEye产品的功能、性能优势做好技术理论培训和实际操作准备，同时增强与东软NetEye的协同合作。另外，本次培训设有现场考核环节，通过考试的学员将被正式授予东软网络安全产品工程师资格证书。

  

2014年，东软NetEye将继续加大对渠道合作伙伴们的支持力度，提供更多、更全面成熟易用、高性价比的产品线，以及更为完善、有保障的渠道管理政策。东软NetEye希望能与广大合作伙伴，尤其是关键行业、重点区域内的合作伙伴，一起努力拓宽、加深合作关系，共同开启崭新的一年。
