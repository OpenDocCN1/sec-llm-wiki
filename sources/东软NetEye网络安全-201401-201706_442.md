# IT人的五个不良生活习惯，你中招了没？

奋斗在IT前线的童鞋们，在繁忙的工作和打游戏之余，请格外关注个人健康，提醒自己养成良好的生活习惯。因为你们是改变世界的一群人，也希望能不时停下脚步，欣赏一会这个因你们而变得越来越智能、高效、美好的世界。

  

**不良习惯一：熬夜**

半夜一点以后睡觉，人体的代谢作用会改由内分泌燃烧，产生更多毒素。通常熬夜的人得慢性病的机率比吸烟喝酒的人都高。

**改善建议**：每天尽量十二点之前入睡！

  

**不良习惯二：吃宵夜**

凡是晚八点以后进食的就称作宵夜。吃宵夜会造成次日感觉疲惫，起不来床，肝部受损等。因为睡觉时，人体各器官活动能力降低，处于休息状态，食物残留会增加机体负担并产生毒素。

**改善建议**：不吃宵夜！

  

**不良习惯三：不吃早餐**

很多上班族因早上起不来经常省掉了早餐，其实是错过了一天中最重要的一顿饭。早餐一定要吃好，吃得丰富，才能为一天的辛苦工作提供足够的能量。

**改善建议**：早餐要吃好！

  

**不良习惯四：运动不足**

现代人生活节奏快，加之便利的交通工具，整天坐在办公室的上班族，运动量大大减少，十分不利毒素排出体外，导致体质的酸性化，加大患病的机会。

**改善建议**：即使没时间运动，每天步行上班一段路程也好！

  

**不良习惯五：压力过大**

IT人士往往处于高度紧张、压力过大的工作环境中。有研究发现，当一个人发脾气或压力得不到释放的时候，体内会分泌十分不利健康的物质，沉积下来势必产生不良影响。

**改善建议**：休息，什么都不想，放空自己。
