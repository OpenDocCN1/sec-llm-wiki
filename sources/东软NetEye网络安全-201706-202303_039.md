# 东软NetEye出席第36次全国计算机安全学术交流会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=2649212125&idx=2&sn=4c55cb41829e92e5a5e3089bfed328c1&chksm=beedae07899a27110b2463584153e3e2ae533649d9ddc8b0a25796d5feb9876f2b5e80d2826b&scene=126&sessionid=1681369609#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=2649212125&idx=2&sn=4c55cb41829e92e5a5e3089bfed328c1&chksm=beedae07899a27110b2463584153e3e2ae533649d9ddc8b0a25796d5feb9876f2b5e80d2826b&scene=126&sessionid=1681369609#rd)

近日，由公安部网络安全保卫局指导，中国计算机学会（CCF）主办，CCF计算机安全专业委员会承办的第36次全国计算机安全学术交流会在成都举办，会议邀请党、政、军有关部门领导，国内知名信息安全专家，大学、科研机构及企业的信息安全科技工作者参会，并就当前我国计算机与网络安全的热点进行交流研讨。东软NetEye作为委员单位受邀参与此次会议。本次大会集结了多位院士、主管单位领导、行业资深专家，为国家网络安全建设献计献策，其中公安部网络安全保卫局副局长、一级巡视员郭启全，中国计算机学会专委会主任、公安部第一研究所副所长于锐，四川省公安厅网安总队总队长冯艳伟出席大会并现场致辞。会上，《数据安全法》、《个人信息保护法》、《关键信息基础设施安全保护条例》等新规议题依然是大家关注的热门话题。东软NetEye1996年成立作为中国网络安全行业资深厂商，与中国网络安全产业共生共成长，创立伊始，即承担国家“九五”攻关重点科研项目，率先研发具有信息分析功能的防火墙，并在防火墙领域最早实现状态检测技术，经过25年的不断发展与技术创新，东软NetEye承担一系列国家技术创新计划、国家级产业化项目，东软NetEye网络安全产品与解决方案已服务于全国千余家企事业单位。近年来，东软NetEye通过深入分析各个行业的业务特征，将业务与安全紧密融合，抽象出一套业务安全通用框架Business Security Frame并推出以业务驱动安全理念为核心的一系列适用于保障业务系统安全稳定运行的网络安全产品与解决方案，以构架安全和业务安全为基础，以安全态势为中心，构建自适应安全框架体系，以体系化防护化的理念，建立预测、防御、响应、检测的联动机制，形成可视、可控、可调度的体系化防护。![](../Images/e98d8f5a7c34f29b1e6c78657e57041c.png)

  

未来，东软NetEye将持续全面支持中国计算机学会（CCF）以及CCF计算机安全专业委员会各项工作的开展。通过本次会议研究网络安全有关法律法规的贯彻落实，从网络安全的保卫、保护和保障的角度，东软NetEye将同产业指导单位、客户与合作伙伴共同努力构建国家网络安全综合防御体系，形成合力，做到真正有能力应对来自网络空间对国家安全的威胁和挑战，致力于建设网络空间强国，保障国家网络空间安全。
