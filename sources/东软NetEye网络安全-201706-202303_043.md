# 东软杨纪文受邀世界互联网大会为构筑网络空间命运共同体贡献网安力量

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=2649212090&idx=1&sn=049a999d70f6eb2908890bb37d4dac1e&chksm=beedae60899a27765e2c3ffd4b76d28e4471a9d4aa277ce73d1fce32e19c7fde8b443bd78b9f&scene=126&sessionid=1681369615#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=2649212090&idx=1&sn=049a999d70f6eb2908890bb37d4dac1e&chksm=beedae60899a27765e2c3ffd4b76d28e4471a9d4aa277ce73d1fce32e19c7fde8b443bd78b9f&scene=126&sessionid=1681369615#rd)

“携手构建网络空间命运共同体”是世界互联网大会一以贯之的主题。2015年，中国国家主席习近平出席第二届世界互联网大会开幕式并发表主旨演讲时强调：“网络空间是人类共同的活动空间，网络空间前途命运应由世界各国共同掌握。”东软集团副总裁兼网络安全事业部总经理杨纪文受邀参与本届世界互联网大会，同到场专家、学者、行业合作伙伴等嘉宾共同探讨安全企业参与构建网络空间命运共同体的新模式、新动能等问题。![](../Images/e68a9b051db9ceaf3f283976002f6f6a.png)东软网络安全1996年成立，与中国网络安全产业共生共成长，东软NetEye创立伊始，即承担国家“九五”攻关重点科研项目，率先研发具有信息分析功能的防火墙，并在防火墙领域最早实现状态检测技术，经过25年的不断发展与技术创新，东软NetEye承担一系列国家技术创新计划、国家级产业化项目，东软NetEye网络安全产品与解决方案已服务于全国千余家企事业单位。![](../Images/b5c8852f864fd97c1ae6d2edd669ba9d.png)经过二十余年的技术积淀与百余行业8000多家客户信息系统网络安全建设经验积累，东软NetEye通过深入分析各个行业的业务特征，将业务与安全紧密融合，抽象出一套业务安全通用框架Business Security Frame并推出以业务驱动安全理念为核心的一系列适用于保障业务系统安全稳定运行的网络安全产品与解决方案，以构架安全和业务安全为基础，以安全态势为中心，构建自适应安全框架体系，以体系化防护化的理念，建立预测、防御、响应、检测的联动机制，形成可视、可控、可调度的体系化防护。![](../Images/4e41faacb8c1859a2b43d3130bf91688.png)

  

以业务驱动安全理念为指导，东软NetEye在智能网联汽车信息安全领域形成了业务与安全相结合的最佳实践，提出针对端-管-云多角度、一体化的安全解决方案，为客户提供一站式的服务，实现事前风险分析，事中主动安全防御措施，事后应急响应。解决终端安全、传输安全、OTA远程升级、车内安全隔离车载防火墙与CAN IDPS、云端安全管理平台、安全虚拟车钥匙、安全芯片等，目前已在国内外多家知名车厂实现量产交付，保障数百万智能网联汽车网络信息安全。![](../Images/2e70e48733d4c1f18b33144a41b5730c.png)

  

不断提高自主创新能力，是建设网络强国的核心，东软在信息技术应用创新方面拥有25年国产自主基础软件研发能力，25年国产网络安全产品研制能力，13年国家涉密甲级集成服务能力， 10年国产化联合攻关与技术能力，8个区域总部，10个软件研发基地，16个软件开发与技术支持中心，66个骨干城市服务网络，东软信创联合攻关开发测试区3000平米，拥有联合攻关实验室、信创验证实验室及信创产品生产中心。承建并参与了涉密、非密领域两个国家级适配中心建设。同时整合教育与培训、测试与验证、研发与集成、生态与产业等方面资源，构建了一个平台五个中心的综合保障体系。通过服务资源统筹协调、问题与知识集中管理、集成服务全程管控等方式构建了以客户为中心的全过程支撑与服务体系。未来，东软网络安全将始终不忘初心，将维护我国网络安全，保障企事业单位信息系统安全为己任，同产业指导单位、合作伙伴共同致力于维护我国网络空间安全，为构筑网络空间命运共同体贡献网络安全产业力量。
