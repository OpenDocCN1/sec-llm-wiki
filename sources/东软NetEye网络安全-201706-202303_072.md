# 融心聚力 共享未来——2021东软NetEye业务发展论坛圆满召开

近日，由东软NetEye主办的“融心聚力 共享未来”2021东软NetEye业务发展论坛在长沙圆满召开，此次会议邀请到东软集团高级副总裁兼首席营销官盖龙佳、东软集团网络安全事业部数十家优秀渠道合作伙伴参会，共同探讨国内网络安全行业发展新态势、新机遇，共建网络安全新生态。会议伊始，东软集团高级副总裁兼首席营销官盖龙佳发表致辞：网络空间安全已成为陆海空天外的第五大主权领域空间，东软作为资深国产品牌网络安全厂商，是铸就我国网络安全空间安全钢铁长城的重要参与者之一。![](../Images/928a9ba0559691f726b8e35b31282119.png)

东软集团高级副总裁兼首席营销官盖龙佳

  

东软集团副总裁兼网络安全事业部总经理杨纪文首先对所有到场的嘉宾表示热烈欢迎，并对一直以来支持东软网络安全的渠道合作伙伴致以深深的感谢。合作伙伴一直以来是东软网络安全事业长期稳定发展的重要助力，东软将不断创新，推出更优秀的网络安全产品，更完善的网络安全解决方案，同所有合作伙伴融心聚力，共赢网络安全新未来。 ![](../Images/0ae8d0d770c2280e828c753008e915d7.png)

东软集团副总裁兼网络安全事业部总经理杨纪文

  

东软集团网络安全事业部副总经理路娜发表以《NetEye之旅——因为坚持 所以看见》主题演讲，路娜全面介绍了东软NetEye品牌25年发展历程，从作为国家计算机软件工程中心承接“九五”攻关项目—“具有信息分析功能的防火墙开始，步步坚实，不断创新商业及运营服务发展模式，提升客户价值，以开放式创新技术与产品的发展策略，推动渠道合作伙伴优势力量与东软网络安全业务相融合。

![](../Images/38c1c47b140ba97d576158a5f0aa10a8.png)

东软集团网络安全事业部副总经理路娜

  

东软集团网络安全事业部副总经理张泉向到场嘉宾介绍东软NetEye业务驱动安全理念下，在行业安全的实践和思考。![](../Images/f717c7222a9e84b149cf0d307e1809f6.png)

东软集团网络安全事业部副总经理张泉

  

会上，东软NetEye发布体系化网络安全防护系统，该系统作为东软NetEye业务驱动安全理念的重要技术延伸，将为企事业单位提供全方位、一体化的网络安全防御。东软集团网络安全事业部副总经理陈静相现场对东软NetEye体系化网络安全防护系统进行了全面解读。![](../Images/df8620e24f3f564beecae50d690bc47b.png)

东软集团网络安全事业部副总经理陈静相

  

2020年新冠疫情的袭来与疫情常态化防控的背景下，医疗行业信息化建设再一次进入了快速轨道，快速发展带来更多机遇的同时，必定会带来更多的安全风险，为此，东软集团网络安全事业部咨询方案部部长王华铎发表《安全赋能业务——东软NetEye医疗行业安全机会与解决方案分享》主题报告。  

![](../Images/a9f46bbc344dcac05de3a85527fd750f.png)
