# 安全旅途，智慧车载——东软NetEye车载安全系统亮相智博会

![](../Images/a1395ea3989b177b47e3cfaae89bc488.png)今日，2019中国国际智能产业博览会在重庆国际博览中心召开，博览会由重庆市人民政府、科技部、工业和信息化部、中国科学院、中国工程院、中国科协共同主办。东软NetEye车载安全系统亮相东软展台。  

![](../Images/0a9a953e182421b03afe576bc4f16fc0.png)

  

本次智博会主题是：“智能化：为经济赋能，为生活添彩”，为期4天的展会，将突出国际化、专业性、体验感，向广大企业和观众展示新技术、新动能、新前景。博览会集中展示全球大数据智能产业的新产品、新技术、新业态和新模式。

  

东软网络安全在车载信息安全领域持续创新开拓。2015年东软睿驰与东软网络安全共同成立车联网安全研发中心（NTSC），以应对智能网联汽车领域日益增长的安全威胁。2016年东软联合国内汽车厂商、全球顶级半导体公司及多个国家级评测认证中心成立车载信息安全产业联盟。2017年NTSC作为唯一中国民企对国外车联网信息安全标准的跟踪，东软网络安全车联网安全中心主任参与ISO/WP29等国际车联网安全标准制定工作，并且积极参加国内信安标委车联网信息安全标准的制定，在行业内起到主导作用。  

![](../Images/2bcf68dc7fd0063cbc4b384167c699c8.png)

东软智能网联车载信息安全平台系统，从整车信息安全防御的角度，基于车辆下一代电子电器网络架构，进行车内网络安全防护。车载信息安全平台支持车内动力域、舒适域、娱乐域、智能驾驶（ADAS）域的安全隔离与防护，包括车载网络（车内域控制器和域控制器之间的以太网、域控制器与ECU之间的CAN总线）的访问控制、会话控制、攻击防御、数据过滤、流量监控等功能；车内域控制器、关键ECU的安全FOTA功能；车内网数据通信安全，包括车内网络中（车载以太网、CAN总线）域控制器和域控制器之间、域控制器与ECU之间的数据机密性与数据完整性防护。  
在当前汽车与IT技术和移动互联网不断融合的时代，东软车载信息安全通过对网络安全技术的不断革新，与云计算和大数据深度结合，在车载安全领域，积极推动车联网安全技术发展，为全球客户的智慧生活提供更好的产品与价值。![](../Images/a4c1a389c06453007e06c1dff14dbdb7.png)
