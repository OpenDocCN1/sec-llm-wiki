# 东软业务驱动安全落地，赋能车载信息安全产业

随着信息技术不断发展，网络技术及设施已经成为现代化社会的基础，摩尔定律与贝尔定律更是为新一次的科技革命带来了可能。从工作站到个人电脑，从个人电脑再到智能手机，很显然，科技的进步和新技术的出现正在改变着人们的生产和生活方式，而这场以信息技术为主要标志的工业变革仍在继续。  

  

狄更斯的《双城记》中说过，这是最美好的时代，这是最糟糕的时代；在科技革命来临之时，数字化、网络化、智能化的现代通信技术，让人们对互联网的依赖越来越强。但事物都是辩证统一的，随之而来的数据泄漏、网络攻击等网络安全问题却越发严重。

  

跨入数字时代，云计算、大数据、物联网、移动互联网、智慧城市等新一代信息技术的出现，更是让网络安全的范畴无限延伸至各行各业，也使得新型安全挑战不断出现，网络安全市场正逐年升温。当今的网络安全问题，关乎社会生活的稳定，面对新技术、新市场需求的不断变化，网络安全产业也需要求新求变。

  

**新业务 新需求 新机遇**

“东软集团作为全行业的解决方案和产品工程解决方案提供商，在网络安全领域的更是有着深厚资源和技术积累，东软安全也适时提出了业务驱动安全的概念，希望真正找到行业痛点，根据不同客户的需求，提供所需的信息安全产品。” 东软集团网络安全事业部产品总监、车联网安全研发中心主任陈静相表示。

  

构建一个完整的业务体系理念只是空架子，真正的着手实践才是硬道理。2015年，东软集团的汽车电子事业部在为客户提供的过程中，客户提出了车辆数据传输信息安全层面的需求，东软集团结合汽车和网络安全事业部的相关业务经验，开始跟进车上相关信息安全的功能开发。

  

在当时来看，这一全新的领域国内标准还不完善，车企的需求也不明确，而智能网联时代的到来，汽车的智能化、网联化已经成为趋势，智能网联汽车极有可能成为及智能手机之后的又一新兴产业。

  

如何保障它的信息安全性成了汽车行业的必修课。恰巧的是，克莱斯勒被入侵事件也在当年爆发，也成为了车辆信息安全的历史元年，让人们第一次注意到了汽车智能化后的网络安全问题。

  

**技术创新+产业联盟的双轮驱动**

对于东软而言，大汽车概念是一块百亿级的大蛋糕市场，确实也让人眼馋。其中的东软车载安全已被公认为业界的领头企业，但是该领域涉及零件、芯片、车厂等多类产业，同时又分为智能化、网联化两个概念，与纷繁复杂的产业脉络相比，东软安全的体量相对来说不大，那么如何在该领域内确保自己的发展之路能得到正确且快速的发展呢？

  

与其闭门造车，不如集众人智慧采众家之长。东软安全开始将自己设定为一个产业技术桥梁的角色，从信息安全领域到与车相关的领域，以车厂为主体，链接与车辆信息安全相关的上下游产业优质企业和科研机构，于2016年联合发起了车载信息安全产业联盟，致力于智能网联汽车信息安全和服务为客户交付更高的价值。此外，联盟的成立，还将有助于推动政府制定有利于产业发展的重大政策，切实促进车载信息安全产业的健康发展。

  

成立伊始，东软安全基于两方面推动联盟的发展。第一类是技术方面，创建联盟的第一个主旨是不谈商务、不谈商业，只针对汽车信息安全谈核心技术。第二类是行业标准，联盟将纯理论的标准提前适配落地，通过车厂的小规模实际测试，完善标准推动标准的实际落地。

  

当然，东软安全作为桥梁自身优势也十分明显，一方面拥有千人团队实施汽车的相关开发。另一方面，在车内网络的安全管控，传统防火墙、云安全、业务安全网关等方面也处于领先地位。东软安全根据汽车智能化、网联化的不同层级，在整车和零部件上部署相关软件产品，保护汽车的信息化系统和整车的架构。

  

不过从2018年起，诸多知名安全厂商正式进入智能网联汽车领域。应该说，东软安全又选择了最佳的时间点，这时智能网联汽车的发展进入了快车道，由于对于产业和技术的不了解，成熟的智能网联汽车信息安全解决方案确实不多。

  

东软安全抓住机会，今年加大逐步投入，完善智能网联汽车信息安全解决方案，并将其设定为企业的核心战略地位目前，东软安全已经与长安汽车进行的整车网络通讯安全相关合作，同时在整车网络通讯、车内防火墙等方面都有所尝试，并牵头完成了新能源汽车相关标准法规的落地，希望能将之前的优势慢慢形成壁垒，更深入的为行业服务。

  

毋庸置疑，联盟的想法是好的，但真正实践起来确实存在一定的难度。目前，联盟内所有相关技术或者落地方案可以互相参考，但是车厂的相关数据无法达到共享。希望车厂之间能打破技术壁垒实现更深入的分享，达到吸引更多的车企和供应商的效果，更好的进行全产业链的构建。

  

**人才——东软安全技术创新之源**

智能网联汽车信息安全产业蓬勃发展，车载信息安全产业联盟也逐渐成熟，智能网联汽车开始被人们接纳，未来让人充满期待。然而人才缺乏问题却始终是难以回避的问题。

  

几十年来，与其说东软是一家企业，毋宁说他是一个熔炉，不断将人才培养成功，为东软所用。东软安全未雨绸缪依托于自己的信息学院，通过定向的东软网络安全班，去培养人才。据悉，今年东软还将启动轮岗计划，会定期的把相关技术人员送到东软硅谷研发中心去轮岗，希望能和硅谷的信息安全技术产业做更多、更丰富的交流。

  

知识经济时代，人才培养的对产业的发展意义重大。未来东软集团将凭借自身强大的研发能力和号召力，着力发展网络安全产业，通过更多优势资源的投入，为用户提供多角度、一体化的安全解决方案，为各产业的发展保驾护航。
