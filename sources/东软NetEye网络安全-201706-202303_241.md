# 东软NetEye受邀出席ISO国际标准化组织汽车信息安全工作组第八次会议

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTAyODkxNw==&mid=2649210163&idx=1&sn=98eb486cdf5d295afbb8029e22a37f6e&chksm=beedd7e9899a5eff6d720da078be3e0957df50c6b3010a0f06c2ad59b622af786aed3ba8868b&scene=126&sessionid=1681369700#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTAyODkxNw==&mid=2649210163&idx=1&sn=98eb486cdf5d295afbb8029e22a37f6e&chksm=beedd7e9899a5eff6d720da078be3e0957df50c6b3010a0f06c2ad59b622af786aed3ba8868b&scene=126&sessionid=1681369700#rd)

2018年12月，ISO/TC22/SC32/WG11（ISO/SAE JWG）汽车信息安全联合工作组第八次会议在印度召开。来自中国、英国、美国、法国、德国、日本、比利时等10余个国家代表团相关成员出席会议。东软NetEye作为国内网络安全行业领导厂商，同中国汽车技术研究中心组成中国代表团共同参加了本次会议。

  

![](../Images/e5272e42eafc5280318a9d9990c44998.png)

  

本次会议主要对正在制定的国际标准ISO／SAE 21434 “Roadvehicles - Cybersecurity Engineering”（道路车辆-信息安全）在进入CD（CommitteeDraft, 委员会草案）阶段后收到的建议进行讨论和决议。相关建议涉及到汽车信息安全关键词语解释、汽车信息安全风险评估中具体方法、部分章节的结构顺序、裁剪和复用的修订以及增加汽车报废阶段的要求等问题。

  

另外，在此次会议期间，东软NetEye与德国代表团德国汽车工业联合会（VDA）进行了深度的交流。此次交流涵盖TAF（Target Attack Feasibility）、漏洞评级系统、汽车信息安全管理系统、汽车信息共享组织、德国在汽车信息安全方面型式认证的计划、中国汽车信息安全标准等内容。

  

![](../Images/ae98d8990438e64c5b2cfd3e25e4580b.png)

东软NetEye作为中国代表团成员通过出席此次国际会议，进一步深入参与到汽车信息安全国际标准的制定之中，不断为国际标准化活动贡献力量。

  

**东软汽车信息安全之路**

**2015年**，成立“东软车联网安全研发中心”,专注于智能网联汽车安全产品的研发。

  

**2016年**，东软联合国内汽车厂商及国家级评测认证中心成立国内首个”车载信息安全产业联盟”，对外发布《车载信息安全技术要求白皮书》以及国内首款车载信息安全产品——东软S-Car整体解决方案。

  

近年来，通过与一汽集团、华晨宝马等车厂的深度合作，东软车载安全产品已经在多个车型上逐步实现量产。

  

**2017年**，东软开始作为中国代表团成员为联合国WP.29提案,建设汽车信息安全标准。并作为中国代表团创始企业代表，出席ISO国际标准化组织会议并提案。（UN/WP.29全称为：联合国世界车辆法规协调论坛,主要开展整个国际范围内汽车技术法规和汽车产品认证的协调和统一工作）

  

**2018年**，东软安全作为主要编写单位在国家信安标委2018年第一次工作组会议周正式发布《汽车电子网络安全标准化白皮书》；“东软智能网联车载信息安全平台系统”在中国网络安全产业联盟主办的“2018年优秀网络安全解决方案和网络安全创新产品”评选中，荣获年度创新产品第一名。
