# 揭秘美国情报分析方法，探寻信息藏宝图

安全问题无处不在，任何网络都存在安全隐患。在威胁存在的情况下，建立一个具备可以追踪目标、追溯威胁源头、查找安全隐患、布置防御制高点、控制隐患发生、利用信息获取利益等特点的Treasure Map（藏宝图系统）是至关重要的。这样的网络系统不仅能够将所有网络终端联系在一起，能够查找网络漏洞、威胁隐患以防御敌手攻击，还能进行信息搜索。Treasure Map是建立在全球互联网基础上，利用各个网络结点信息，集中网络逻辑层，汇聚数据源，监测物理路由器及用户服务器，旨在寻找和防范安全隐患结点及对象，并能够获取利益的网络应用系统。

  

在如今全球网络互联通讯的形势下，数据来源可以是专门学术研究者的学术研究、利于商业用途的数据信息以及通讯信息和信息保障等。可以从拥有很多用户群体的多样网络中获得信息，如联合全球情报通信系统(Joint Worldwide Intelligence Communications System)。大数据量的更新以每天30GB的速度进行，新的操作功能也会不断更新。而Treasure Map应用系统是具备收罗大量信息数据、处理海量数据及发现有效资源以实施应对措施的有利工具。Treasure Map具有大量的因特网网络映射，开发以及分析引擎，还具备包装化的宝物，即全球分发的路由追踪发动器，这些都为搜集准确、及时、有效的信息数据提供良好的保障。

  

  

1

**Treasure Map介绍**

2014年9月，网易科技引用《明镜周刊》指出Treasure Map是能够进行实时交互的全球网络系统，能够在任何时间和地点连接整个因特网的全球网络。在这样的定义之下，我们能够完成诸多意义重大的任务，包括我们自身和敌手的网络局势分析，构建常见操作图，进行计算机攻击和网络侦测及有效措施的实效性判断。这种网络的缺点在于其可利用性及有效性数据是有限的，从而增大了数据利用的难度。

  

![](../Images/d8d75eadb3127008dd021175057f5dfd.png)

图1 全球网络图

  

如图1所示全球网络图，我们所能操作的网络层为个人层和网络个人层，而我们的任务层是物理网络层和地理层。而连接网络个人层和物理网络层的是逻辑层， Treasure Map主要存在于红色的网络逻辑层，我们通过建立和部署Treasure Map来操纵和控制物理网络层和地理层，Treasure Map恰可以使得我们完成任务成为可能。

  

Treasure Map网络系统实施的操作对象是数据源，而数据源的得来是靠公开资源情报计划（简称OSINT，是美国中央情报局（CIA）的一种情报搜集手段，从各种公开的信息资源中寻找和获取有价值的情报），这里包含商业应用数据也包含专门学者的学术研究，这些数据源可满足商业需求、信息保障，有些还是通讯情报。公开资源情报计划的数据来源还包括用户注册表、DNS（Domain Name System，域名系统）和操作系统指痕（网络装置的软件和操作系统特性）。

  

使用这个系统的用户包括美国国家安全局、美国国防部、“五眼”情报联盟（简称FVEY，由美国、英国、澳大利亚、加拿大和新西兰的情报机构组成。这五个国家组成的情报间谍联盟内部实现互联互通情报信息，窃取来的商业数据在这些国家的政府部门和公司企业之间共享）、联合全球情报通信系统用户，该网络系统可谓包含面之广。该系统是不断更新的，官方指出每90天提交新的功能，此外从数据量上讲当前的状态的强大之处在于每天有30GB的数据添加和替换进去。

**Treasure Map框架简介**

如图2所示网络知识图谱，图中我们可以看到各个网络节点之间的关系，黄色的链接表示数据类型间的直接关联，从中我们可以获得数据间的追踪信息。Border Gateway Protocol (BGP)是一种标准的建立在自治系统Autonomous Systems（AS）之间，进行交换路由和可达性信息的外部网关协议。IP Geolocation是一种存储地理IP的IP库，由IP Geolocation可以定位一个IP地址的国家位置。OS Fingerprints表示操作系统的特征，例如Window XP、Windows NT等。Trace routes是一种网络工具，测试网络达到的状况。Router configurations Files是路由器配置文件。IP Prefix为IP地址前缀。Mac Address（Media Access control Address ）为连接通讯的物理网段分配给网路接口的一种唯一标识符。Domain Names表示辨识网络的唯一标识符。AS Owner表示自治系统的拥有者。SIGAD/CASN指信号情报活动指示器，标识信号情报和情报相关集合，可以认为是情报基地。简单的数据关系为一个路由与一个IP地址关联，而IP地址可以通过ARP协议找到对应的Mac Address，一个IP地址属于一个网段，通过DNS协议和域名对应，通过IP Geolocation可以定位IP的国家位置，而AS是IP路由前缀的集合，由此可以判断路由从属于哪个AS系统。

**总结**

  

美国国家安全局和中央安全服务威胁操作中心技术发展报告指出，安全问题无处不在，安全隐患也无处不在。Treasure Map应用系统是具备收罗大量信息数据、处理海量数据及发现有效资源以实施应对措施的有利工具。我们可以通过藏宝图(Treasure Map)计划实现诸多安全防范、达到性能保障目的、满足获取利益需求。
