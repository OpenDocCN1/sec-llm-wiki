安装流程

安装还是比较简单的，这里是中文的官方文档，可以根据自己的发行版来查看。

以Centos为例。
安装步骤如下：

sudo yum update mssql-server
export MSSQL_COLLATION='Chinese_PRC_CI_AS'
export MSSQL_LCID='2052'
/opt/mssql/bin/mssql-conf setup
// 然后选择版本(免费的推荐选择Developer)接下来设置密码即可。

这里的两句export增加的环境变量，是为了添加MSSQL的中文支持，否则安装好后再去添加会十分困难。

然后在建议安装mssql-tools，安装过程，请参考官方文档，不要去百度了。很简单的。

坑1：This program requires a machine with at least 2000 megabytes of memory.

这个是说要求你的机器要有2G以上的可用空间。对于很多学生党来说，1核2G的云服务器刚好不够，但是还是想装MSSQL，这时就要对sqlservr该可执行程序做一点小小的修改来绕过限制了。
这个网上可以搜到大片的教程，然而！然而！如果是最新版2017的话，全部不可用。
大部分的教程都是这么写的

cd /opt/mssql/bin/ # 进入目录
mv sqlservr sqlservr.old # 保存备份文件
python # 使用python修改内存限制代码
>>> oldfile = open("sqlservr.bak", "rb").read()
>>> newfile = oldfile.replace("\x00\x94\x35\x77", "\x00\x80\x84\x1e")
>>> open("sqlservr", "wb").write(newfile)
>>>exit()

即把sqlservr中16进制数据00943577（小端存储，实际上是16进制77359400，10进制2000000000）即2GB更改为16进制0080841e 512MB。



但是，新版的sqlservr你是找不到00943577这个数据的。新版的数据为FF933577(10进制1999999999)。
所以你需要把上面的脚本中

\x00\x94\x35\x77

修改为

\xff\x93\x35\x77

是不是很坑，应该就是官方故意的 hhhhh。让小内存就不要用了。github上有我修改好的程序和源码

坑2 中文编码问题

如果你在安装之前，没有设置两个MSSQL_COLLATION和MSSQL_LCID的环境变量。默认的就支持英语啦。中文会显示成一堆问号。
若你已经安装完毕了，要想设置排序规则和区域设置为中文，我强烈建议卸载重装的方法。

当前数据库的区域设置是否为中文，的查询命令如下：

1> SELECT CONVERT(NVARCHAR(50),SERVERPROPERTY('Collation'));
2> GO

SQL_Latin1_General_CP1_CI_AS 为英文默认。
Chinese_PRC_CI_AS 为中文。

卸载重装法

注意，这里的卸载重装，是会连同数据文件一同删除的，否则是没法更改的。
更多卸载帮助，参考官方文档
Centos为例：

sudo systemctl stop mssql-server.service
sudo yum remove mssql-server
sudo rm -rf /var/opt/mssql/

然后再安装我之前的安装方法，配置环境变量后，进行安装。查看环境变量是否设置成功，可以使用
echo $MSSQL_COLLATION
