# **关于APP侵害用户权益整治“回头看”发现问题的通报（2022年第6批，总第26批）**

  

工业和信息化部高度重视用户权益保护工作，持续开展APP侵害用户权益专项整治行动。为巩固治理成效，营造共同维护消费者权益的良好环境，近期我部开展APP侵害用户权益整治“回头看”，组织第三方检测机构对违规推送弹窗信息、APP过度索取权限等问题进行重点抽测，共发现38款APP（详见附件）存在问题，现予以通报。上述APP应在10月20日前完成整改，逾期不整改或整改不到位的，我部将依法依规处置。工业和信息化部信息通信管理局2022年10月13日附件：工业和信息化部通报存在问题的APP名单.docx![](../Images/e398484992b284e0d5b3f4293bcbfdd0.png)
