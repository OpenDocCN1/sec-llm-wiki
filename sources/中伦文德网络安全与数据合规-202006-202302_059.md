# 【新闻速递】欧盟批准全面数字监管新规 《数字服务法》（DSA）和《数字市场法》（DMA）

      当地时间5日，欧洲议会分别以539票赞成，54票反对，30票弃权和588票赞成，11票反对，31票弃权通过了《数字服务法》和《数字市场法》。这两项法案为科技企业如何在欧盟提供服务树立了清晰的标准，明确了企业如何在符合欧盟基本权利和价值观的前提下运营。

      两项法案直指谷歌、facebook等科技巨头，规定了数字服务提供者、大型在线平台的打击非法内容、禁止诱导行为等义务，并对个性化推荐广告、优先推荐自身服务、限制用户卸载预加载应用等行为也作出了规制。

    《数字服务法》(DSA)规定了社交媒体或市场等数字服务提供商的应对非法内容的传播、在线虚假信息和其他社会风险的义务，这些要求与平台的规模和对社会构成的风险成比例。

    《数字市场法》(DMA)规定了大型在线平台在数字市场上充当“守门人”（这些平台占据市场支配地位使得消费者难以避免）的义务，以确保消费者能够享受更公平的商业环境和更多的服务。

       根据新法规，违反《数字市场法》的企业将最高被处以年度全球营收10%的罚款，违反《数字服务法》的企业将最高被处以年度全球营收6%的罚款。对于屡次不合规者，罚款金额可达到企业年度全球营收的20%。
