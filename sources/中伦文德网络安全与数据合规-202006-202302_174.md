# 【法评】数据安全审查跑步入场，数据合规布局迫在眉睫——《网络安全审查办法（修订草案征求意见稿）》简析

![](../Images/6b380eb5cfa808dfeb3cd3e20e773f9b.png)2021年7月10日，国家互联网信息办公室（以下简称“**网信办**”）发布了《关于<网络安全审查办法（修订草案征求意见稿）>公开征求意见的通知》（以下简称“**《征求意见稿》**”）。征求意见稿回应了目前市场关注度较高的中概股国外上市数据合规的问题，并将《网络安全审查办法》（以下简称“**《办法》**”）\[i\]的审查标的由“供应链安全”审查扩大到了“供应链安全”审查和“数据安全”审查，并落实了最新出台但尚未生效的《中华人民共和国数据安全法》（以下简称“**《数据安全法》**”）\[ii\]中的相关制度。

鉴于《征求意见稿》并未改变《办法》中关于“供应链安全”审查的相关制度，本文主要分析《征求意见稿》中新增的数据安全审查相关制度和待澄清的问题，供相关方参考。如相关方希望了解“供应链安全”审查相关制度，可以阅读我们针对《办法》的解读文章[《<网络安全审查办法>简析及实务合规提示》](http://mp.weixin.qq.com/s?__biz=MzU2ODU3MTA5Ng==&mid=2247484052&idx=1&sn=9ae3fbc496559f9c4d0797dfb26fdbbe&chksm=fc8aa723cbfd2e3518bb1d307d248b604fdfdf14902e5988655ae3e2490f066cd54aa13b278e&scene=21#wechat_redirect)（以下简称“**《办法》解读文章**”）。

本文是在前述《办法》解读文章的基础上做出，因此相关术语与《办法》解读文章一致，结合《办法》解读文章阅读更容易理解。

  

  

**一、数据安全审查制度体系**

  

  

《征求意见稿》从上位法依据及监管体系、审查标的及考虑因素、审查程序、罚则等角度规定了数据安全审查制度的基本体系，具体如下：

1**.****上位法依据和监管体系****① ****上位法依据**《办法》依据《国家安全法》和《网络安全法》制定，《征求意见稿》增加了《数据安全法》作为上位法依据\[iii\]，为将数据安全审查的相关内容纳入《征求意见稿》提供了上位法依据。《数据安全法》虽然规定了数据安全审查制度，要求对影响或者可能影响国家安全的数据处理活动进行国家安全审查\[iv\]，但是并未规定此项制度的具体内容，我们理解此项规定的作用仅是为未来立法提供法律依据。但《征求意见稿》的本次修订则意味着《数据安全法》项下的数据安全审查制度正在迅速进入立法框架内，未来可能在《数据安全法》正式施行之日（2021年9月1日）同步生效或在其后较短的时间内生效。当然，《数据安全法》中的数据安全审查制度可能覆盖的范围更为广泛。**② ****监管机构**《办法》项下的监管体系为中央网络安全和信息化委员会领导下的、以国家互联网信息办公室为核心的12部委联席审查工作机制。《征求意见稿》将“中国证券监督管理委员会”（以下简称“**证监会**”）增加进了监管机构，《办法》项下的12部委联席审查工作机制因此变更为13部委联席审查工作机制（《征求意见稿》第4条）。根据《征求意见稿》，网络安全审查工作机制成员单位认为影响或可能影响国家安全的网络产品和服务、数据处理活动以及国外上市行为，由网络安全审查办公室按程序报中央网络安全和信息化委员会批准后，依照本办法的规定进行审查（《征求意见稿》第16条）。此项规定赋予了证监会在认为某项网络产品和服务、数据处理活动以及国外上市行为影响或可能影响国家安全时，按照程序依职权启动网络安全审查的权限。我们理解将证监会纳入联席审查工作机制的主要目的是为了更好的解决中概股国外上市（所涉数据合规）监管问题。**③ ****监管对象**《办法》项下的监管对象仅为CIIO，《征求意见稿》将监管对象扩大为CIIO和数据处理者（二者均简称为“**运营者**”）。根据《办法》，CIIO采购网络产品和服务，影响或可能影响国家安全的，需要进行网络安全审查。《征求意见稿》进一步规定，数据处理者开展数据处理活动，影响或可能影响国家安全的，也应当进行网络安全审查（《征求意见稿》第2条）。根据《数据安全法》，数据指任何以电子或者其他方式对信息的记录，数据处理则包括数据的收集、存储、使用、加工、传输、提供、公开等。根据该定义，通常理解，只要相关企业从事了数据处理任何一个环节的业务，即可能被认定为“数据处理者开展数据处理活动”。因此，“数据处理者开展数据处理活动”的范围是非常广泛的，此项规定大幅扩张了《办法》的监管对象和适用范围。**2.  ****审查标的及考虑因素**《办法》中的网络安全审查标的为“供应链安全”审查，《征求意见稿》中增加了“数据安全”审查。《征求意见稿》规定，网络安全审查重点评估采购活动、数据处理活动以及国外上市可能带来的国家安全风险（“供应链安全”审查的考虑因素没有变化，如需了解，可参阅《办法》解读文章）。“数据安全”审查的考虑因素则区分为如下两种情形：**① ****主要从定量角度考虑的因素**《征求意见稿》明确规定，掌握超过100万用户个人信息的运营者赴国外上市，必须向网络安全审查办公室申报网络安全审查（《征求意见稿》第6条）。本条规定虽然存在若干待进一步澄清的问题（具体参见本文“二、待澄清的问题”），但是从实操的角度，因为是定量标准，具有较大的确定性。**② ****主要从定性角度考虑的因素**《征求意见稿》进一步规定，“数据安全”审查的主要评估因素为：（略）；（五）核心数据、重要数据或大量个人信息被窃取、泄露、毁损以及非法利用或出境的风险；（六）国外上市后关键信息基础设施，核心数据、重要数据或大量个人信息被国外政府影响、控制、恶意利用的风险；（七）其他可能危害关键信息基础设施安全和国家数据安全的因素（《征求意见稿》第10条）。本条规定进一步和《数据安全法》衔接，例如“核心数据”我们理解指《数据安全法》项下的国家核心数据\[v\]。**3.  ****审查程序****① ****审查启动**《办法》虽然维持了原有CIIO预判及主动申报和网络安全审查工作机制成员单位依职权启动相结合的双层审查启动机制。但在此基础上，增加了为数据安全之目的的启动程序：**a)  针对赴国外上市的强制申报程序**如上，掌握超过100万用户个人信息的运营者赴国外上市，必须向网络安全审查办公室申报网络安全审查。**b)  针对网络安全审查工作机制成员单位依职权启动程序**网络安全审查工作机制成员单位认为影响或可能影响国家安全的数据处理活动以及国外上市行为，由网络安全审查办公室按程序报中央网络安全和信息化委员会批准后，依照本《办法》的规定进行审查。**② ****提交材料**提交材料基本上没有变化，仅增加了“拟提交的IPO材料”。需提交的材料未有重大变化的原因在于即便增加了“数据安全”审查，所需提交的材料在种类上也基本相同，仅有国外上市需要单独列举所需材料。**③ ****审查时限**《办法》项下的审查程序包括初步审查和特别审查两个阶段。《征求意见稿》维持了上述规定，但大幅延长了特别审查阶段的法定时限。根据《征求意见稿》，初步审查阶段的法定时限仍约为70个工作日，但是特别审查阶段的法定时限延长为3个月，情况复杂的还可以延长。在实务中，申报前准备材料的时间必须提前预留，申报程序中还可能发生提交补充材料的情况（不计入法定时限），因此如果企业判断需要申报网络安全审查，则至少应预留6个月以上的时间，情况复杂时还应做好审查时限延长的准备。《征求意见稿》的网络安全审查流程见下图。**![](../Images/45acc04065a393513c59282ac2286e34.png)****4.  ****罚则**根据《办法》规定，CIIO违反《办法》规定的，应依照《网络安全法》处理。《征求意见稿》扩大了处罚的法律依据，运营者违反《征求意见稿》的，不仅依照《网络安全法》，还应依照《数据安全法》的相关规定进行处理。  
  

**二、待澄清的问题**  

  
  
主要待澄清问题集中在《征求意见稿》第6条，即“掌握超过100万用户个人信息的运营者赴国外上市，必须向网络安全审查办公室申报网络安全审查”。我们理解，“掌握”、“100万用户个人信息”、“国外”、“上市”等均需要进一步澄清其含义。**1.  ****关于“掌握”**“掌握”并非法律用语，其内涵和外延均需要界定。《中华人民共和国民法典》\[vi\]、《个人信息保护法》（草案二次审议稿）\[vii\]采用的术语均为“处理”，个人信息的处理“包括个人信息的收集、存储、使用、加工、传输、提供、公开等”。《个人信息保护法》（草案二次审议稿）进一步规定了个人信息的委托处理制度\[viii\]。《数据安全法》的概念与前述定义一致。推荐性国家标准《信息安全技术个人信息安全规范》（GB/T 35273—2020）（以下简称“**《个人信息安全规范》**”）则定义个人信息处理活动为收集、存储、使用、共享、转让、公开披露、删除\[ix\]等，但从其内容上看，也应包括委托处理\[x\]。此外，《个人信息安全规范》还定义了“个人信息控制者”，指“有能力决定个人信息处理目的、方式等的组织或个人”\[xi\]。“掌握”用户个人信息与“处理”用户个人信息的内涵与外延是否一致，例如被共享或转让方或者受托处理方是否在安全审查的范围内，如不一致应如何衔接？“掌握”个人信息的运营者与“个人信息控制者”的内涵与外延是否一致？等等均为涉及到网络安全审查的对象范围如何界定的重大问题，需监管机关进一步澄清。**2.  ****关于“100万用户个人信息”**“100万用户个人信息”的表述存在歧义，可以理解为100万名用户的个人信息，也可以理解为100万条用户个人信息。鉴于在当前形势下，100万条个人信息的门槛相对较低，我们理解指100万名用户的个人信息的可能性更大，但仍然需监管机关进一步澄清。**3.  ****关于“国外”**《征求意见稿》使用了“国外”一词，但并未明确该词的具体内涵，如是否将“赴港上市”排除在外。《中华人民共和国出境入境管理法》\[xii\]、《中华人民共和国证券法》、《网络安全法》及其配套法规中常用的为“境内”和“境外”概念，“境外”通常包含港澳台地区。而“国外”通常指除我国国境（包含港澳台地区）以外的国家和地区。据此，我们理解，赴港上市可能不需要申报网络安全审查。但以上仅为我们的推测，最终解释需监管机关进一步明确。**4.  ****关于“上市”** 根据《征求意见稿》的规定，运营者在申报网络安全审查时应提交的材料涉及上市的仅为“拟提交的IPO材料”，即仅规定了采用IPO（首次公开募集股份并上市）方式时的材料要求。但国外“上市”的方式并非仅有“IPO”，从《征求意见稿》的立法意图看，不论采用何种上市方式，只要构成国外上市，理论上均可能需要按照《征求意见稿》的规定申报网络安全审查，但最终解释亦须待监管机关进一步明确。  
  
  

**三、小结**

  

  

  

  

  

  
结合近期平台企业反垄断执法、中概股国外上市网络安全审查等情况以及《征求意见稿》的快速发布，我们理解整个互联网行业的监管逻辑在发生变化，监管尺度正在收紧，企业的合规运营正在被提升到更加重要的、甚至可以称为生命线的地位。我们建议相关企业尽快就此做好准备，立即按照《网络安全法》、《数据安全法》、《个人信息保护法》（草案二次审议稿）的要求对自身的数据资产进行梳理，在此基础上建立起完善的网络安全、数据（包括个人信息）安全管理体系。涉及到赴国外上市的，可能需要考虑暂缓，并在与相关主管机关沟通后再做进一步的安排。
