02**根源——格式化函数**

    

格式化字符串  

     当用户可以向格式化函数提供字符串时，“偷懒”的行为常常会引入漏洞。错误用法：

int func (char \*user) {

     printf (user);

}

      正确用法：

int func (char \*user) {

     printf ("%s", user);

}

  

格式化函数

  printf系列有printf、fprintf、sprintf、snprintf、vfprintf、vprintf、vsprintf、svnprintf；近似的有setproctitle、syslog。

     其作用是将简单的C数据类型转换为字符串输出，并允许指定输出格式。工作原理主要是控制了函数的行为（访问哪些地址、什么形式），指定了参数的类型和参数入栈。

  

03**漏洞的形式**

  

 触发崩溃  

      格式化字符串漏洞最易于达成的目的就是造成进程崩溃（触发非法内存访问）。虽然无法获得控制权限，但是在很多场景下是很粗暴实用的。例如在网络环境下，使服务器崩溃，无法响应。

      通过下面简单格式化字符串，就能达到这一目的。

printf ("%s%s%s%s%s%s%s%s%s%s%s%s");

     “%s”以字符串的形式展示地址内存的内容，而栈地址是存在栈上的，我们虽然未提供地址，但是格式化字符串会依照参数入栈的规则“自发”地把对应位置的参数作为地址参数。很容易造成非法内存的访问，很大概率崩溃。  

  

查看进程的内存

      查看栈内容：

printf ("%08x.%08x.%08x.%08x.%08x\\n");

   这样一条语句，会让printf输出栈上的五个参数（8位填充的十六进制）；当然你改换参数，会有不同的效果；例如下面的语句会输出栈的前五个参数的地址。

printf ("%p.%p.%p.%p.%p\\n");

      查看任意地址的内容：  

     其实很简单，如果足够幸运我们的格式化字符串就在栈上，我们只需要将想要查看的地址输入进字符串（放到栈上）就OK了，当然需要注意内存对齐。例如  
 address = 0x08480160

// address (encoded as 32 bit le string): "\\x60\\x01\\x48\\x08"

printf ("\\x60\\x01\\x48\\x08\_%08x.%08x.%08x.%08x.%08x|%s|");

      只要调整好参数的位置，就可以输出地址0x08480160处的内容。我们简单的看一下如何调整参数：

      实例代码

*   
*   
*   
*   
*

*

```
#include <stdio.h>#include <stdlib.h>int main(){  char buf[20]={0};  read(0,buf,20);  printf(buf);  return 0;}
```

  

       我们想确定buf的第一个参数在栈上的位置，只需要从1到n逐个的尝试即可。幸运的是，有一个符号可以帮到我们——

”$“操作符可以指定参数的位置。

      在如下过程中，在7个时，我们发现”%x”输出的就是第一个参数’aaaa’的十六进制形式，这就是offset了！

![](../Images/fe9f4dc07cf194577a0eaf7b505d3d65.png)

       这样一来，一个格式化漏洞，其实可以帮我们拿到整个目标进程的内存（dump下来），还原程序代码结构，俗称“盲打”。

  

任意地址写

      这里又要用到另一个特殊的格式化操作符”%n”，可以将目前为止输出的字符个数写入到指定的地址。与”$”配合，我们就可以指定写入内存。

     示例程序

*   
*   
*   
*   
*   
*   
*   
*   

```
#include <stdio.h> int main(void){int c = 0;printf("the use of %n", &c);printf("%d\n", c);return 0;}
```

  

        在”%n”前有11个字符，我们看看结果；c现在已经成了11。

![](../Images/d1e49a68dd4db37bc239ef71ef537a14.png)

     那么，如果我们想要c=100呢，写100个字符吗？想想，格式符的另一个特性——定义输出的宽度。如下

*   
*   
*   
*   
*   
*   
*   
*   

```
#include <stdio.h>int main(void){int c = 0;printf("%.100d%n",c, &c);printf("c= %d\n", c);return 0;}
```

  

       可以看到c被修改为了100.
