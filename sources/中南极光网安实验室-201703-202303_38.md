## 隐写

    那么在一张图片中，任意地修改图片中的颜色bit的最低位，对图片是几乎没有任何影响的，那么假如我想在这张图片中隐写一个 `A`，我们先获得 `A`的二进制形式 `01100001`，然后再按顺序将其放入颜色bits的最低位中。

![](../Images/0abd60cdca01c127ee994a9f93ae9e69.png)

    原理写到这里，下面就是代码的实现，这里使用的是python，首先贴一下完整的代码：

```
1.  `# -*- coding: utf-8 -*-`
    
2.  `from PIL import Image`
    
3.  `#改变十进制变成二进制后的最后一位`
    
4.  `def turnlast(s,i):`
    
5.  `    s=list(bin(s))`
    
6.  `    s[9]=i`
    
7.  `    s=''.join(s)`
    
8.  `    return int(s,2)`
    
9.  `#将字符串转换为8位的二进制字符串，例如A变成'01000001'`
    
10.  `def encode(s):`
     
11.  `    return ''.join([bin(ord(c)).replace('0b', '').zfill(8) for c in s])`
     
12.  `#读取图片`
     
13.  `im=Image.open('1.png')            #使用Image读取图片`
     
14.  `width,heigh=im.size                #获取图片的宽和高`
     
15.  `#隐写的内容`
     
16.  `s='LSB so Fun!'`
     
17.  `s=encode(s)`
     
18.  `#补齐隐写的长度，否则会越界`
     
19.  `for i in range(1,4):`
     
20.  `    if((len(s)+i)%3==0):`
     
21.  `        s=s.ljust(len(s)+i,'0')`
     
22.  `leng=len(s)`
     
23.  `num=0`
     
24.  `for h in range(heigh):`
     
25.  `    for w in range(width):`
     
26.  `        if(num>=leng):`
     
27.  `            break`
     
28.  `        pixel=im.getpixel((w,h))    #读取坐标是(w,h)的像素点`
     
29.  `        R=turnlast(pixel[0],s[num])`
     
30.  `        num += 1`
     
31.  `        G=turnlast(pixel[1],s[num])`
     
32.  `        num += 1`
     
33.  `        B = turnlast(pixel[2], s[num])`
     
34.  `        num += 1`
     
35.  `        im.putpixel((w,h),(R,G,B))`
     
36.  `        im.putpixel((w,h),(R,G,B))  #将坐标是(w,h)的像素点修改为(R,G,B)`
     
37.  `im.save('111.png')                    #保存修改后的图片`
     
38.  `im.close()                            #关闭图片`
     
```

![](../Images/8b2262dad80c2ebd6184080922cbbedb.png)

    实现过程非常简单，简要概括即是，读取图片，将要隐写的内容转换成二进制，然后按顺序读取图片的像素点，修改像素点的最低位，最后将修改后的图片保存即可。

![](../Images/5158cc2e4d615cd491057744cd1cb5f1.png)

    这里用到的是python自带的库PIL，通过这个库，我们可以对图片进行非常多的操作，这里用到这库里的函数都有了相应的注释了，也就不再复述了。

    而图中的字符串转数字的一列系操作是因为python下转为二进制带有0x，所以要通过replace去掉，并且python里的字符转十六进制的长度是不一致的，所以要通过zfill函数来进行补零。

![](../Images/6743d9a404bbf127f4d437096fa282a7.png)

## 读取

    上面实现了隐写功能，而直到LSB的隐写原理后，读取则更是简单了。将整个过程反序即可，读取每一个像素点bits的最后一位，将其以8（7）个为一组，转换成字符。

![](../Images/c7077dd75600a6b4a6f5f8f8c15cf3fb.png)

    说的简单，代码更是简单：

```
1.  `from PIL import Image`
    
2.  `#将二进制串按8个一组转成字符输出`
    
3.  `def decodelsb(s):`
    
4.  `    l=int(len(s)/8)`
    
5.  `    m=''`
    
6.  `    for i in range(l):`
    
7.  `        c = chr(int(s[i*8:(i+1)*8], 2))`
    
8.  `        print(c,end="")`
    
9.  `        m=m+c`
    
10.  `    return m`
     
11.  `im=Image.open('merged.png','r')        #使用Image读取图片`
     
12.  `width,heigh=im.size                    #获取图片的宽和高`
     
13.  `x=width*heigh                        #隐写内容的长度，稍多一点`
     
14.  `num=0`
     
15.  `s=''`
     
16.  `for h in range(heigh):`
     
17.  `    for w in range(width):`
     
18.  `        if(num>x):`
     
19.  `            break`
     
20.  `        pixel = im.getpixel((w, h))        #读取坐标是(w,h)的像素点`
     
21.  `        for pi in pixel:`
     
22.  `            s+=str(mod(pi,2))            #模2相当于取最低位`
     
23.  `        num+=3`
     
24.  `decodelsb(s)        #调用函数，输出解密后的内容`
     
25.  `im.close()            #关闭图片`
     
```

## 颜色通道

    这里提到了**stegsolve.jar**（这篇推送的封面就是将windows xp的默认桌面将颜色翻转后的结果），该工具有一个查看颜色通道的功能，在这里就介绍一下这个功能有何作用。

    除去几个特殊的，可以发现stegsolve里面一共有红绿蓝各8个共24个颜色通道。但这些通道又有什么作用呢？

![](../Images/97d1ea7ac8db2284c92db0f8bb34a234.png)

    相信敏感的读者看见8这个数字就有了想法，没错这些颜色通道实际上就是每个颜色的8个bits，本来一张图片显示是需要3个颜色的各8个bits混合，而这些颜色通道则是只截取了一个颜色的bit，并且通道8-1，代表着一共有几个bits被显示。并且颜色也变成了黑-白。

    例如：Red plane 7 ，则显示的是每一个像素点的红色里的8个bits；而Green plane 3，则显示的是每一个像素点的绿色里的4个bits。
