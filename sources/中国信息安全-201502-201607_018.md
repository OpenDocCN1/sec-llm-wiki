# 原创｜发展与安全并进： 用新思维应对大数据安全挑战

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=2664107526&idx=1&sn=963d3ecf4f2c5a95305c70388c8fa9de&chksm=8b5e0cffbc2985e98b211b5082336e8741d9f21d43fb93ecde64252b99d5a7eb7cfbdb8b9073&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664107526&idx=1&sn=963d3ecf4f2c5a95305c70388c8fa9de&chksm=8b5e0cffbc2985e98b211b5082336e8741d9f21d43fb93ecde64252b99d5a7eb7cfbdb8b9073&scene=27#wechat_redirect)

![](../Images/98e2ba8b9c81480b6ec2fbc3ec0c7143.png)点击上方“中国信息安全” 可以订阅◎ 黄殿中在中国大数据产业峰会上，李克强总理强调，“大数据等新一代互联网技术深刻改变了世界，也让各国站在科技革命的同一起跑线上”。纵观历史，人类的每一次在科学和技术上取得的重大突破，不仅深刻的改变了生产和生活模式，而且改变了一个国家、一个民族的命运。在与几次科技革命失之交臂后，中国这一次借助新一轮科技革命的关键机遇，与世界强国站在了同一起跑线上，大数据已经成为我们国家的战略选择。发令枪已响，如何让我们国家的大数据跑的又快又好，大数据安全与大数据发展同步建设是必然选择，作好大数据“钻石矿”和“智慧树”的守护神，也应是信息安全从业人员义不容辞的职责。在此，我谈几点对大数据安全的思考和认识。**大数据安全带来新挑战，我们应顺势而为、积极应对**

大数据的总的发展态势是数据的资源化和战略化，资源化指在整个信息产业的价值创造过程中，日趋围绕、依靠数据开展。数据的战略化，指数据的重要性和影响力正日趋超出信息产业的范畴，而渗透进入涉及国家安全的各个领域，成为网络时代国家间竞争的焦点、核心以及关键。大数据的价值不仅仅在于其本身是“未来的新石油”，更在于其推动思维方式的改变。在经济、社会、安全等领域中，将日益基于数据进行分析决策，而非基于经验和直觉。这些特性使得大数据成为媒介，将传统安全与非传统安全深度融合，固有的安全风险和新型的威胁挑战因为数据时代的来临而复杂交织，以信息为基础的现代社会由此步入到一个风险多样、挑战多变的新阶段。

从国际层面看，大数据与国家主权安全紧密结合，威胁挑战日渐增多。大数据时代数据跨境流动的频繁性，对于信息主权产生了颠覆性的变革，数据开放性与数据主权之间的刚性矛盾关系逐步凸显放大。信息资源与数据资产所有权和治理权分离，加大了国家数据主权的捍卫难度；数据资源“自东向西”的国际流向格局，制约了信息技术相对落后国家的话语权，使东西方信息博弈的不对称性更加突出；网络强国对数据治理规则的强权操控，威胁了他国的网络主权，更增加了在网络空间国际博弈中的代价。难度的增大、力度的增强、程度的增多,使得大数据时代国家安全发展的外部环境变得日趋严峻、日益复杂。

从内部环境看，大数据与国家治理体系深度交织，风险冲击日趋复杂。大数据加剧了个人信息保护的难度，数据泄露事件频发，信息资源失控风险骤升。新技术对大数据的高度依赖，增添了新的风险敞口。大数据本身容易成为网络攻击的显著目标。新的威胁挑战加快了向各领域的传导渗透，致使国家安全的防护目标急速增加、社会稳定的威胁行为体多元复杂。同时，大数据时代政府、企业、社会组织、个人等在网络安全防护方面参差不齐的水平和能力，信息安全技术体系还没同步跟上，也进一步加深了大数据安全的脆弱性、加大了数据信息的泄露风险。原本相对单一的安全风险，在大数据条件下，全新排列组合、重重叠加复合，对网络的治理、社会的进步、国家安全构成严峻威胁。未来，大数据安全挑战带给我们的未知仍然大于已知。

从技术和管理看，大数据对传统的网络安全技术提出严峻挑战，新的管理思维呼之欲出。大数据技术带来的网络虚拟化、边界模糊化的特点，多租户共享资源的应用模式，分布式的数据存储模式等，使得统一的安全弱点和安全威胁管理变得不可能，传统的防护技术不能适应新形势下的新挑战。在管理边界方面，由于海量数据实时跨境、跨机构的流动、开发和利用，国家、政府、企业、个人的数据权属关系进一步模糊，传统的基于组织和疆域边界的信息安全管理模式被打破。

**大数据安全呈现新特点，我们需因势而谋、准确把握**

习近平总书记在今年网信工作座谈会上，深刻分析了新形势下网络安全的主要特点。结合开展大数据工作的特性，进一步认识和把握这些特点，对我们推动大数据安全发展，具有重要意义。

**首先，大数据安全是整体的而不是割裂的。**在大数据、“互联网+”时代，大数据安全对网络安全和国家安全起的是“牵一发而动全身”的作用，同许多其他方面的安全都有着密切联系。一旦发生问题，就有可能对其他方面的安全甚至全局造成结构性的威胁、冲击和破坏。

**其次，大数据安全是动态的而不是静态的。**信息技术发展日新月异、网络安全威胁千变万化，每个国家的政府、企业、社会组织、个人都可能在不同时期、不同程度遭遇来自数据安全领域的风险。面对数据时代的安全治理问题，我们不可能有“一劳永逸”的防护措施，更不会有“一蹴而就”的捷径办法。

**再次，大数据安全是相对的而不是绝对的。**数据时代的安全问题纷繁复杂、变化多端，我们既不必要也不可能不计成本地追求本不存在的绝对安全，一味提高安全的标准和要求，很可能出现包袱过大、负担过重、顾此失彼的情况。

**此外，大数据安全是共同的而不是孤立的。**大数据安全是全球共同的挑战，是政府、企业、用户共同的问题，世界上的任何政府、企业、组织、个人都难以置身事外、独善其身。维护大数据安全是全社会共同责任，是各个国家共同的利益，携手共同构筑数据安全防线，筑牢网络空间命运共同体的战略基石是我们的必然选择。

**大数据治理需要新思维，我们应乘势而上、主动作为**

大数据时代的信息安全是一个复杂的系统工程，比以往任何时代都更加依靠多方力量的共同作用和相互配合，包括国家顶层设计、政府监管、企业研发和个体使用等，包含了大数据产生和使用过程中政府、企业、个人等多个方面。除了要凝聚各方力量，至关重要的一点是需要理念思维和方式方法发生重大变革。

中国有句至理名言“他山之石，可以攻玉”。西方发达国家尤其是美国，在大数据安全的治理问题上比我们走得早，经验和教训比我们要多。战略设计、政策法规、科研创新、人才培养等方面的做法为我们当前的治理工作提供了一定的参考和借鉴。我们要去粗存精、为我所用，要紧密结合维护我国大数据安全的实际，加强探索创新，拿出真抓实干的干劲、坚忍不拔的韧劲和开拓创新的闯劲,革新旧观念、树立新信念、培养新思维。

**一要在战略谋划中发现问题、在战略实践中解决问题。**“问渠哪得清如许，为有源头活水来”。好的战略就如同好的源头，有了好的源头，发展路径才能清晰明朗。党的十八届五中全会，国家“十三五”规划纲要都对实施网络强国战略、“互联网+”行动计划、大数据战略等做了部署，国家大数据顶层设计日渐清晰，也为大数据安全发展指明了方向和路径。现阶段我们要做的就是贯彻战略规划中的各项要求、解决战略实践中的问题难题、推动战略部署的落地实施，建立立体协同的整体防控体系，共同建立信息安全的生态环境，发挥我国大数据优势，在大数据安全国际治理体系中把握“话语权”，最终实现建设网络强国的战略目标。

**二要在技术科研上突破难题、在技术应用中化解难题。**习近平总书记指出，“我们要掌握我国互联网发展的主动权，保障互联网安全、国家安全，就必须突破核心技术这个难题”。大数据安全领域的核心技术是国家之重器，大数据安全工作做得成功与否，核心技术的攻坚克难成为关键。我们只有把好核心技术这个最大的“命门”，充分发挥工匠精神，化解关键技术受制于人的安全“隐患”，建立自主、可控、专业、开放的大数据安全力量和产业，形成对大数据安全的有力支撑，才能在大数据时代大有可为、大有作为。

**三要在激励机制上吸引人才、在发展创新中用好人才**。“得人者兴，失人者崩。”大数据的竞争，归根结底是人才竞争，念好了人才经，才能事半功倍。要研究制定吸引人才、培养人才、留住人才的办法，为人才发挥聪明才智创造良好条件，营造宽松环境，提供广阔平台。对待大数据安全领域的特殊人才，要有特殊政策，不拘一格“选”人才，不拘一格“用”人才。要建立灵活的人才激励机制，让作出贡献的人有成就感、获得感，打造一批人才高地，只有建立了思想解放、机制创新，能聚天下英才而用之的人才凝聚体系，才能为大数据安全发展提供不竭动力。

大数据安全是确保国家健康、有序、繁荣发展的重要战略与关键基石。在大数据安全问题上，我们要想万家灯火、念百姓忧乐；要为国家尽责、为人民造福；要以“滴水穿石、锲而不舍”的精神来“谋发展”，以“知之愈明、行之愈笃”的行动来“保安全”，形成强大的数据安全防御能力和威慑能力，更好地维护网络安全、维护国家安全，为实现全面建成小康社会、实现中华民族伟大复兴的中国梦做出更大贡献！（本文刊登于《中国信息安全》2016年第6期）
