# 看点｜网康上网行为管理再登国家级活动舞台——为贵阳数博会保驾护航

点击上方“中国信息安全”可以订阅![](../Images/903eedc810df7ea73d400b53edb5f951.png)随着大数据发展上升为国家战略，2016贵阳数博会已升格为“国家级”盛会。超过20000参展观众，将海量图片、视频、新闻上传到互联网上，小编这几天朋友圈也被贵阳数据博览会刷屏了。![](../Images/81f33a9048ca255a49e65943312fbec1.png)开幕式，总理致辞  
![](../Images/0594f083f2341776f68b6f6642af4ce1.png)业内大佬云集![](../Images/ff157ce9b02466463534078e7975828c.png)数博会现场分论坛为此，WIFI管理成为了最重要的一环，尤其是如何保障WIFI网络通畅，防止出现网络拥堵导致的迟、卡、慢现象，提高参会者的上网体验显得尤为重要。网康上网行为管理（ICG）带宽管理优势功能恰好契合了本次大会展览馆的需求。ICG为数博会展馆提供了全方位的带宽保障机制，控制占用带宽的应用使用，确保网络流量合理分布。贵阳数博会这样国家级盛会，媒体争抢时效性对网络速度有着很高的要求，网康上网行为管理通过七级虚拟通道分配物理带宽资源，对P2P下载、P2P影音、OA系统进行合理的流量分配，保障关键业务的正常运行。经过精确的流量控制，博览会网络体验得到质的提升，上网流畅无阻。这也是小伙伴们即使没去现场也能通过网络上的这些视频图片全面了解数博会情况，第一时间了解到各种信息，而网康上网行为管理就是背后幕后英雄，为网络通畅保驾护航。![](../Images/144278c22135781086c4eb03bc0c32b7.png)数博会现场网康上网行为管理设备2016数博会展馆选择网康上网行为管理不仅是因为上网行为管理的产品功能与需求的高度契合，也源于网康在其他国家级活动舞台上的精彩表现。继在冬季运动会精彩表现之后，网康上网行为管理再次登上国家级活动舞台，为第二届中国大数据产业峰会顺利召开提供坚实的网络流控保障。长按二维码关注《中国信息安全》公众号：chinainfosec![](../Images/7b553d9c890bdcdc915a11fb642be5ce.png)
