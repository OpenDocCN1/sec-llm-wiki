# 回顾｜2015数博会精彩回顾

2015贵阳数博会以“‘互联网+’时代的数据安全与发展”为主题，集展览展示、峰会论坛、创新大赛于一体，聚集了微软、谷歌、英特尔、惠普、思科、甲骨文、戴尔、阿里巴巴、富士康、华为、联想等近400家全球大数据领域顶尖企业参展。博览会吸引了4万余人参加展览会、峰会论坛及相关活动。会议期间还发布了《大数据贵阳宣言》，展示了国内首个大数据交易所，举行了一系列重要签约活动，促成了众多大数据项目合作。

贵阳数博会得到了国家领导的高度重视，并得到了行业组织和新闻媒体的大力支持。李克强总理为2015数博会发来贺信，贺信指出：“当今世界，新一轮科技和产业革命正在蓬勃兴起，数据是基础性资源，也是重要生产力。”马凯副总理出席峰会并讲话指出，基于互联网的大数据与云计算、物联网一样都是新一代信息技术的重要标志，深刻影响着经济社会各个领域，是新时代最重要的战略资源之一，带来了巨大的商业机会和创业空间。2015数博会期间，众多专业协会参与数博会和论坛的组织工作，国内外众多官方和专业媒体参与报道，产生了广泛的影响。
