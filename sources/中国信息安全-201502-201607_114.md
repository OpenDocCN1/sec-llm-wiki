# 原创｜工业控制系统被谁“反控”

可以订阅哦！2010年的夏天，当伊朗布什尔核电站的工人将IR-1离心机一台台搬往门外时，他们不禁迷惑，为什么这段时间离心机的故障多得出奇？同时在遥远的一个监控房间，“攻击者”通过卫星图像，满意地看到事态正在朝着预先设计的轨道发展——“震网”病毒，仅仅是一个病毒，就破坏了伊朗数以千计的离心机，将伊朗的核计划大大延迟。“震网”病毒震惊了全世界，它将工业控制系统的安全问题，直接而又粗暴地展现在人们面前，让毫无防备的人们惊慌不已。原来，曾经以为是网络孤岛的工业控制系统，曾经以为是固若金汤的防线，面对万物互联的大潮，已然脆弱不堪。工业控制系统被“反控”，下一个伊朗核电站会是谁呢？工控安全近年来步步逼近相对互联网上无时无刻都在发生的黑客攻击，付诸于媒体报道的工控安全事件可谓寥寥可数，但工业控制系统遭受破坏的影响力却是不可同日而语的，工业控制系统广泛应用于电力、水利、轨道交通、石油化工、航空航天、核工业等领域，相比互联网攻击带来的财产损失、信息泄露，其安全涉及国家经济安全、公共社会安全、国防安全，它带来的风险实实在在地影响到人们的生活、人身安全，乃至社会的稳定。就像一部电影里所展现的，通过网络，攻击者控制了交通、电厂、水坝甚至国防系统，人们失去了基础设施和生活秩序，面对的是一个混乱失控、处处危机的末日景象。这并不是导演的空穴来风，事实上它的某个环节已在现实中重现。2015年12月23日，乌克兰电力系统遭受网络攻击，导致大面积停电，数万民众在严冬时节陷入无电可用的困境。2016年1月25日，以色列宣布电力系统受到重大网络攻击，电力设施中大量计算机设备被迫终止运行了两天。突然频繁起来的工控安全事件，又重新引发社会的高度关注。由于工业控制系统近年来大量采用通用软硬件和网络设施，网络通用协议逐渐在工控系统中应用；在管理需求下，工业控制系统不可避免地与OA、ERP等企业管理信息系统集成，很多工业控制系统已与传统信息网络有着隐蔽的联系。在这种情况下，传统信息网络所面临的病毒、木马、入侵攻击、拒绝服务等安全威胁，也同样在向工业控制系统扩散。遗憾的是，工业控制系统在设计时主要考虑的是系统的可用性，对工控安全问题的考虑普遍不足，人员的安全意识相对淡薄。随着“震网”事件的发生，到近来的电力系统被攻击，人们发现再戒备森严的物理防御，也难以挡住互联网时代精心准备的定点、定制化的网络攻击。工控安全随工业4.0快速升级互联网推动着现实世界与虚拟世界的结合，也推动着制造业进入一个新的时代。我国目前正在大力推行两化融合和“工业4.0”。两化融合是指信息化和工业化的高层次的深度结合，其核心就是信息化支撑，将电子信息技术广泛应用到工业生产的各个环节，信息化成为工业企业经营管理的常规手段。所谓“工业4.0”，通俗地说就是“互联网+制造”。2011年德国汉诺威工业博览会上首次提出“工业4.0”概念，即利用基于信息物理融合系统的智能化来促进产业变革的时代，意味着未来互联网企业与工业企业的边界逐渐被打破。我国据此消化吸收，提出适合我国国情的“中国制造2025”，即“中国版工业4.0规划”。国务院李克强总理在去年的政府工作报告中谈及产业结构转型时强调：“要实施‘中国制造2025’，加快从制造大国转向制造强国”，同时要“促进工业化和信息化深度融合”。工信部和中国工程院把中国版的工业4.0的核心目标定义为智能制造，而物联网、工业互联网、智慧城市等领域的核心也是网络互联。可以看出，随着国家战略的推进、工业化与信息化的深度融合，未来的工业控制系统将向着更加智能、更为网络化的方向发展，而作为工业生产的中枢，工业控制系统的安全是实现两化融合和工业4.0的前提保障，来自信息网络的安全威胁将逐步成为工业控制系统所面临的最大安全威胁。我国近年来非常重视工业控制系统安全工作， 2011年9月，工业和信息化部专门发文《关于加强工业控制系统信息安全管理的通知》，要求各地区、各有关部门、有关国有大型企业充分认识工业控制系统信息安全的重要性和紧迫性，切实加强工业控制系统信息安全管理，以保障工业生产运行安全、国家经济安全和人民生命财产安全。2015年，工业和信息化部发布的《关于贯彻落实〈国务院关于积极推进“互联网+”行动的指导意见〉的行动计划（2015~2018年）》也明确指出，要加强工业信息系统安全保障体系建设，探索建立工业信息系统和产品安全审查制度，完善工业信息系统信息安全标准体系，提升工业企业信息安全管理能力。但就目前现实情况来看，我国工业控制系统的安全防护远滞后于工业智能化的飞速发展，防护能力亟需加强。根据工业和信息化部电子科学技术情报研究所的监测，我国的工业控制系统网络存在大量安全风险漏洞，涉及的行业包括能源、市政供水、供气和供热等，根据分析，有87%的漏洞是可以被黑客远程利用，而这些攻击很多仅需初级水平就可以做到。此外，我国重要工业制造业领域大量使用国外工控设备。据调查，2015年仅在我国工业PLC 市场，西门子、三菱、欧姆龙、罗克韦尔、施耐德等5家国外厂商就占有了超过80%的市场份额。很明显对工业控制系统的核心技术，我们还没有自主权，这无疑是极大的风险和隐患。重要基础设施的工控系统一旦出现问题，影响力和破坏力巨大，未来更有可能成为国家之间网络对抗的新手段，“震网”和乌克兰电力事件都表明了这种可能性。为此，应及早将工控系统的安全建设提升到国家战略层面，做好顶层设计，制定行业发展规划，掌握核心技术，建立完备的工控安全体系。在对新的重大工业项目建设时，要同步考虑工控安全问题，做好规划和验收。同时建立相应的审查和测评机制，对国外的工控产品做好检查，促使其与国内安全厂商合作，把控好引进产品和技术的安全命脉。抓住转型带来的机遇工业化转型为工控安全提供了难得的发展机遇。在工控安全领域国外并不具有特别的先发优势，反观我国的体制特点，倒是大有可为。据悉在国家电网领域这种情况就颇具典型，据国家能源局有关人员介绍，电力系统已基本实现全国产化，类似乌克兰电网的情况几乎不可能出现。此外，在政策、标准、科研、产品层面，我们也正在积极发展：已经涌现出一批具有活力的工控安全企业，相关的实验室建设如火如荼，工控安全的标准也已推出。对这样一个新的安全领域，我们应防患于未然，积极研究和应对，真正做到“以安全保发展，以发展促安全”。
