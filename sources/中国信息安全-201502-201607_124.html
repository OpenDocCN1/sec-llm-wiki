记者：您作为可信计算技术方面的从业专家，能否简要介绍下可信计算技术的发展历史、背景及国内发展现状？
郑驰：可信计算概念最早可以追溯到1983年美国国防部的TCSEC准则及之后出现的彩虹系列信息系统安全文件。1999年IBM、HP、Intel和微软等牵头组织的TCPA(2003年3月TCPA改组为TCG组织)， 
致力于形成可信计算的工业标准，截至目前已有100多家国际著名IT公司加入。TCG组织制定了TPM、TSS、TNC等一系列技术标准，2014年，TCG发布TPM 2.0标准，支持中国密码算法体系,2015年,TPM 2.0成为国际标准ISO/IEC11889-2015。国际信息安全类标准应用中国密码算法体系,是我国密码算法技术和标准的又一次重要突破，这也加速了我国可信计算相关产业的发展。同期，微软与Intel宣布全面应用TPM 2.0，欧洲电信运营商开始批量应用可信网络设备。
我国可信计算于1992年正式立项并开始应用研究与测试。2000年前后，我国已有企业开始与武汉大学合作开发安全计算机。2003年，我国第一块可信计算平台模块“嵌入式安全模块（ESM，J2810）”正式面世。同期，第一款可信计算平台“SQY-14嵌入密码型安全计算机”正式推出。2006年国家密码管理局主持制定了《可信计算平台密码技术方案》和《可信计算密码支撑平台功能与接口规范》两个规范。2007年在全国信息安全标委会的主持下，我国开始制定了一系列的可信计算标准，包括芯片、主板、软件、网络连接、测评等标准。2012年以来，我国的可信计算进入高潮：国民技术推出世界上第一颗支持中国密码算法的TPM 2.0芯片，中国可信云计算社区成立。2013年，华为、浪潮、大唐高鸿开始研制中国自己的可信服务器。2014年，中关村可信计算产业联盟成立，推动主动免疫的双体系创新结构，中标软件研制出中标麒麟安全操作系统。华为开发出可信路由器，大唐高鸿发布了中国第一款市场化的采用自主免疫结构融入TCM/TPM 2.0国产安全模块的可信服务器。
总体来看，我国的可信计算，起步不晚，水平不低，成果可喜，处于国际可信计算领域前列。
记者：您认为可信计算技术最核心工作的是什么？可信计算技术与信息安全、网络安全是什么关系？可信计算一定能保证安全么？
郑驰：之前高校、科研机构和产业界做了大量的工作，现阶段可信计算技术最核心工作包括：关键技术的自主可控，包括可信基础软件、动态度量技术及可信链构建、可信网络连接方案、虚拟可信平台、安全I/O等；可信计算应用的开拓及测评体系的完善。
《国家中长期科学技术发展(2006-2020年)》明确提出“以发展高可信网络为重点，开发网络安全技术及相关产品，建立网络安全技术保障体系”。可信计算及相关产业在促进信息系统国产化方面可以提供基础性的保障，对于构建网络安全保障体系、满足云计算等新型网络安全技术等，具有非常重要的作用。基于可信计算构建网络安全防御体系，是推进我国网络安全体系建设的重要举措之一。
需要强调的是，信息安全是一门综合性学科，一种技术对付某种特定领域攻击可能更有效，但任何一种技术都不能确保系统安全，可信计算也不例外。可信计算需要和其他技术配合，各自承担自己的角色和发挥自己的作用，共同保障系统安全。可信计算技术有它完整的应用场景，但绝不等同于绝对安全，但可以肯定的是，可信计算将大大增强网络安全，将是我国信息安全战略的重要组成部分。
记者：大唐高鸿从事可信计算应用方面研发的背景及目标是？
郑驰：大唐电信集团是国务院国资委管理的一家从事电子信息系统装备开发、生产和销售的大型高科技央企，在无线移动通信、集成电路设计与制造、信息安全与军工电子、战略性新兴产业、产业金融等领域具备雄厚实力。大唐高鸿是大唐电信集团整合多年累积的数据通信技术、产品和资源组建的高新技术上市公司，起点高，发展快，目前已形成了具有较强竞争力的面向企业信息化的物联网和融合通信、面向独立消费群体的移动互联网和互联网支撑服务两大产业板块。
顺应国家网络空间安全发展大势，承担央企责任，支撑国家信息安全发展战略，助力网络空间安全顺理成章的成为大唐电信集团和大唐高鸿“十三五”战略重点。2015年底大唐电信集团发布了《建设安全可信的网络空间》的5G（第五代移动通信技术）网络安全白皮书，提出了实现网络安全所必须的三个核心要素:身份可信、网络可信和实体可信。大唐高鸿以可信计算事业部及大唐高鸿信安(浙江)信息科技有限公司为载体，充分承接大唐电信集团可信计算产业，秉承开放合作的精神，与产业链充分合作，建成了完整的基于可信计算技术的产品规划、研发和销售体系，与业界共同创建安全可信的网络空间。
记者：对比目前国内外可信计算技术应用方面的发展趋势，大唐高鸿可信云、服务器的研发进展如何？
郑驰：从国际上来看，可信计算技术的研究及其相关产业正在成为一个热门的研究领域。Intel推出的可信执行技术(Trusted Execute Technology，TXT)，已经应用到各个平台。据悉，目前Intel正在推动将可信计算技术运用到软件定义基础设施(SDI)、物联网、大数据分析平台等。微软也早在2002年就已展开了可信计算战略的布局，微软的目标是构造基于硬件的新一代安全计算平台——从10年前的Vista到最新的Windows10都已经开始支持可信计算硬件安全功能。IBM旗下的IDC与云服务提供商SoftLayer，很早就开始提供基于可信计算技术的云服务，帮助用户提升安全性和合规性。Google推出的OnHub Wi-Fi路由器，包含了可信计算模块；Linux Kernel4.0开始支持TPM 2.0芯片。
在我国，《国家中长期科学技术发展(2006-2020年)》规划和“十二五”规划有关工程项目都把可信计算列为发展重点，可信计算标准系列已逐步制定，参与标准研究制定单位多达40家，标准的创新点都已作了相关技术验证，过程中完成专利申报超40项。诸多单位和部门已在标准体系下研制出了芯片、整机、软件和网络连接等可信部件和设备，并在国家电网调度、中央电视台等重要系统中得到有效应用。例如，中标软件基于安全操作系统和可信计算技术，推出了安全操作系统V5及可信操作系统V6；国民技术TPM 2.0密码安全芯片已应用到中国型号的微软Surface Pro3/4,Surface Book中。
目前，大唐高鸿基于可信计算技术研发的国内首款可商用可信服务器已完成多轮次场景应用验证。2015年11月，大唐高鸿在天津成功发布自主设计研发的国内创新的第一代X86可信服务器-CTRUST SERVER RT650V3，该服务器采用主动免疫的结构，应用Intel E5V3平台，融入TCM/ TPM 2.0国产安全模块，支持中国商用密码算法。可信管理套件可实现服务器从启动到运行全过程的安全性管理，保障关键应用的执行安全，基于等保要求的基线管理，实现可信数据中心的合规管理。可信云管理平台通过可信资源池技术、云完整性技术以及可信虚拟化技术，帮助用户提升IT治理能力，加强云基础设施的感知能力、多元分权管理能力，强化软硬件变更管理能力、支持地理资产标签的法规性遵从能力，同时兼容Openstack最新版本，符合国家网信办《关于加强党政部门云计算服务网络安全管理的意见》和公安部等级保护要求。新一代X86可信服务器CTRUST SERVER RTV4平台及多种机型，应用Intel 最新发布的E5V4平台，完全实现可信功能，并大幅提高系统性能。
同时，大唐高鸿还将陆续推出可信云存储及可信云桌面解决方案，行业应用可信解决方案已在测试阶段锋芒初露。
记者：大唐高鸿可信计算产品的应用领域有哪些？目前市场的现状如何？公司的发展规划是怎样的？
郑驰：大唐高鸿可信计算产品应用覆盖了可信服务器、可信终端、可信虚拟化管理、端到端可信云管理平台、可信软件定义基础设施(SDI)、行业可信应用解决方案。同时我们通过开放的可信中间件服务，与可信计算产业链的众多合作伙伴联合推出了可信计算应用系列产品与解决方案，包括中联润通的易云汇智云计算一体机和易云汇仓大数据一体机、云巅科技的可信云桌面解决方案、海云捷迅的AWcloud可信超融合云一体机、星辰天合(XSKY)的可信SDS解决方案、艾奈信息（XNET）的可信SDN网络交换机等，共同推动云计算安全领域走向了一个全新的舞台。
就国内可信产业的整体发展而言，现阶段仍处于市场概念导入、市场可信认知、市场初期培育环节。在网络空间安全已上升为国家战略，云计算、物联网、工业互联网浪潮涌动下，信息安全正在得到更为广泛的关注。可信计算作为一种革命性的解决方案，势将得到充分应用。据数据显示，2015年我国X86服务器出货量约为200万台，其中政府应用约38万台，电信与金融等安全等级要求较高的行业约34万台；可见市场容量巨大。从我国政府推动的“信息化自主品牌、可信可控和完全自主可控”的发展路径来看，保守估算，3年内可信计算服务器市场容量将达10万台，五年后将达到60万台，相配套的设备市场和服务市场规模则将轻松突破千亿。
大唐高鸿规划，在服务器方面，涵盖单路，双路，四路，八路平台，结合可信操作系统和可信管理平台，充分满足客户不同应用场景的需求；在云计算方面，充分考虑私有云/公有云/混合云的应用场景，工作负载从计算虚拟化延伸到云存储、SDN、容器技术；在新兴应用方向上，和合作伙伴紧密合作，将产品、方案和行业应用紧密结合；将可信计算探索应用到嵌入式设备、物联网、工业互联网方面，为网络空间安全保驾护航。
