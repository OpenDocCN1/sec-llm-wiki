# 专题｜数据“安全港”事件折射出的国家跨境数据管理博弈（连载二）

![](../Images/c83da40adcf0bef1b33d33c7539eb541.png)点击上方“中国信息安全” 可以订阅■ 严峰 潘斐斐 宋谨谨  张静引言 “安全港”的崩塌 存在了十五年之久的欧盟和美国的数据“安全港”协议在2015年10月被欧盟高等法院宣判无效。这起看似源于一名奥地利公民对自己数据隐私权利的申诉而引起的偶然事件，实则是欧盟与美国之间就公民数据隐私权利保护制度的不信任感的必然结果。十五年间，欧盟与美国在2000年签署“安全港”协议时的基础已经发生了翻天覆地的变化，制度已然跟不上时代，如何规避“安全港”协议自身存的很多不完善之处，防止“斯诺登事件”曝光的监控项目包括一些跨国企业对欧盟的数据和隐私侵害，探求全球各国对数据保护的途径，促发更多的国家或组织重新审视国民数据安全问题，包括欧盟和美国也仍在商讨如何继续新的数据跨境流动已是大势所趋。本篇将围绕“安全港”事件对数据跨境流动新动向进行研究和探讨。（接上期）三、数据跨境流动的商业价值和多利益相关体属性加剧了博弈的复杂性在数据世界中，大量利润是通过使用人工生成的信息得到的。人们的浏览习惯、聊天记录、移动轨迹以及地点定位——所有这些东西都被商业化了。这些都是极为私人化的数据，尽管通常情况下人们并不这样认为。若将私人数据与化石燃料进行一种行之有效的比较：原油是从死去很久的微生物身体中压缩得来的，而私人数据则是通过对人们私人生活碎片的压榨而产生的。这些数据实际是人类经验的一类浓缩。**1.跨境数据流动涉及多个利益相关主体**数据的价值让企业和国家都看到了获取的意义及保护的重要性。但是，数据价值和现代技术的发展却又让数据的跨境流动变成趋势。互联网时代的许多服务和产品就是数据形式，如一个软件、一部电影等；大数据和云计算时代的数据又包含了太多的价值，如商业价值、情报价值，甚至是军事价值等。所以，数据跨境流动是一个综合性议题，包括贸易规则、国家安全、知识产权以及网络开放等。数据跨境流动议题具有复杂性和多样性，与数据的属性和来源有密切的关系。大数据时代数据的属性超越了传统单一性的特点，传播路径和节点变得复杂。通过下图可以看出：（1）从不同的维度，能够看到不同类型的数据有可能在这张图上流动；![](../Images/79a121f859883c45a86657d738e02c9b.png)（2）从数据的类型，可以看到有特别敏感的健康数据在流动；（3）从数据使用要求，可以看到有要求知识产权许可的数据在流动；（4）从数据控制标准，可看到要求进行严格安全控制的金融数据在流动。**2.跨境数据流动问题牵涉多议题**从以上数据跨境流动路径和牵涉利益相关主体的复杂性可以看出，跨境数据流动问题会牵涉到多个议题。数据跨境流动问题是全球贸易问题，也是知识产权问题，也涉及国家安全问题，同时也是互联网开放问题。以全球贸易问题为例，数据流动会对全球现行贸易规则的挑战，促进新贸易秩序的建立。互联网产品和服务的数字化让数据具有了商品属性。数据商品的全球跨境涉及到贸易规则的改变，虽然当前各方对新的贸易规则的建立或修改仍存在争议，但是新的数据交易模式的形成将倒逼现行制度和规则必须做出改变。**3.利益相关方的矛盾与诉求**利益相关方在数据流动中存在的冲突主要来自于国家与国家之间、国家和企业之间。基于各自的利益考虑，需要各方权衡利弊，集中达成诉求平衡。（1）国家与国家的利益冲突数据控制弱势国家的敏感性、双边数据流动与保护力度不对等、WTO多边框架下的贸易自由流通与各国不同安全诉求的冲突等。（2）国家与企业的利益冲突企业认为跨境数据制度建立带来的监管和市场准入障碍会影响云计算对经济的促进作用、不希望将国家安全与企业数据流动混为一谈、繁琐的跨境数据流动制度会增加企业的成本和风险，影响企业在全球竞争中的地位。（3）利益相关方的冲突和诉求原则不同国家层面是要解决跨境数据流动带来的主权与治权的分离问题，考虑国家安全问题；企业层面则更希望信息自由流动，或者形成全球一致的技术标准、制度框架原则；个人层面就聚焦于应用体验好，也关注隐私保护。四、跨境数据流动管理政策差异，揭示各国尚未找到管理共同点政策是一国对数据能力的体现，反映出政府的态度。对于跨境数据流动的管理，全球主要国家并没有形成统一的认知。基于各自对数据保护和利用的差异性需求，每个国家都能够产出符合自己利益的政策或规则或指南。虽然各自的细节不尽相同，但是可以从整体思维导向对比各国政策的共性与差异。**1.美国内松外紧的管理政策**美国对数据的管理包括隐私政策通常被认为是自律或自由。但是事实可能如同美国总统行政办公室发布的《美国白宫“大数据”白皮书》中的一句话，“大数据正在改变世界。但是它并没有改变美国人对于保护个人隐私、确保公平或是防止歧视的坚定信仰。”美国表面宽泛自由的数据政策背后是一套严谨的审查逻辑体系，对事关国家安全的数据存储和流动有着极为严格的要求。美国表面宽泛自由的数据政策背后是一套严谨的审查逻辑体系，对事关国家安全的数据存储和流动有着极为严格的要求。（1）在美国，关于数据管理条例包括HIPAA、HITECH、GLBA、SOX和FISMA等，但不具体管理存储数据的物理位置。（2）组织法规中对安全性的标准可能会限制位置移动。（3）出于法律差异性带来的风险考虑，组织通常会将远程存储的敏感信息或知识产权保留在美国本土。**2.欧盟制定有严格的数据保护法律**欧盟以立法严格保护其公民个人数据权益而著称。欧盟将数据保护看作是一项基本人权，是隐私保护的重要内容。基本人权对诸如经济选择和机会等基本权益具有优先价值。欧盟数据保护的监管出发点是严格控制本人数据流动，信息处理原则上应获得数据主体同意。（1）对内：欧盟新通过了数据保护政策为成员国确定了数据保护的统一标准，禁止成员国借数据保护的名义限制个人信息在欧盟境内的自由流动。（2）对外：以数据接受国是否达到数据保护的充分性要求，向欧盟境外转移数据将受到限制。同时，在新的法规中也对数据的跨境流出和使用进行了详细严格的规定。**3.俄罗斯新规限制公民数据存储位置**俄罗斯新的《个人数据保护法》要求俄罗斯公民的个人信息数据只能存于俄境内的服务器中，以实现数据本地化。法律规定，任何收集俄罗斯公民个人信息的本国或者外国公司在处理与个人信息相关的数据，包括采集、积累和存储时，必须使用俄罗斯境内的服务器。法律中所指的个人信息，不止包括姓名、住址、出生日期等，而是与公民身份相关的任何信息。法律对签证办理、机票购买、媒体行为和法院行为等进行了例外规定。个人信息数据的跨境传输是允许的，但是必须存储在俄罗斯境内。数据的副本可暂时存放在国外，但仅限于需要使用的期间内。例如，俄罗斯公民的个人数据可以被传输到境外的宾馆或者医院，但是在公民结束休息或者结束治疗后，宾馆和诊所中的俄公民个人数据应当被删除。**4.跨境数据流动问题上各国尚未完全找到共同点**从以上的政策差异可见，各国的决策者还没有完全在国际条约或协定设计上找到共同点，来明确如何协调数据的跨境流动。主要体现在两个方面：**第一**，各国/各地的政策权重不同。以欧盟和美国为例：欧盟对于数字版权要求更高，高度监管着互联网服务提供商要符合数据保护规则，而对于言论自由的保护程度低于美国。**第二**，各国/各地的部门职能分工不同。在美国,州有贸易政策制定权，但法律制定权在国家。而欧盟则是，国家安全政策的一些政策制定上仅仅在国家层面上，数据保护和人权等政策制定存在于国家和欧盟层面，但贸易政策在欧盟层面。五、推动多边对话的解决机制，以战略高度解决数据流动与安全问题全球数据流动贸易发展的趋势和各国政府对数据政策的差异使得矛盾点产生，趋势和安全都必须兼顾。所以，解决数据流动带来的新矛盾就必须要推动建立多边对话的机制，以针对性解决问题。**1.各利益相关方冲突，始于解决机制不同**主权国家会根据自身的安全诉求，限定跨境数据流动政策限制，实施跨境许可管控。需要进行双边数据流动保护谈判。企业倡导以领先的云服务商来在实践中积累技术标准、法律标准和运营保障的解决方案。政府、企业和用户摸索共识，来促成这些障碍的解决。需要推动数据自由流动被纳入到全球贸易规则中。地区性、政府间、综合性的国际组织具有充分的讨论合作机制，以欧盟为例，建立数据保护充分性审核机制，以欧盟为主体签订双边数据保护协议。**2. WTO：传统多边贸易组织协调范围延伸争论**由于全球的贸易都离不开WTO，所以作为一个特殊的存在，WTO在全球数据跨境流动方面的态度对未来数据跨境流动能否顺利进一步发展具有重要价值。当前，对WTO能否协调全球数据跨境流动贸易的声音有两种。一种是支持派，即WTO作为国际多边贸易的重要组织，数据交易绕不开WTO；WTO管辖范围包括所有货物贸易和服务，包括通过互联网的国际贸易。因此在此基础上对原有贸易类别进行适度扩展，能够使原有贸易原则适用于在线服务。另一种则是反对派，认为数据流动不仅仅是贸易问题，还涉及隐私和人权。WTO原有政策框在设计时“没有做好准备在隐私和人权问题上设计弹性的语言”。**3.以战略高度解决数据流动和安全问题**互联网发展到当前，已经升级为网络空间的概念。这不仅是一个概念的转换，更是一种新的理念、环境的变革。所以，在这样的背景下去解决数据跨境流动和贸易问题，需要更大的智慧和更高的战略高度。互联网的发展是为了确保技术的互操作性,协作开发和透明度更加明晰。但孤立的政策使互操作性,跨边界合作和透明度更难实现。政策制定者必须更加战略性地考虑如何最好地促进跨境信息的自由流动和贸易协定。以战略高度解决数据自由流动和安全问题是未来谈判中的焦点。数据的自由流动比贸易、金融、物流、人流还要广泛，因为人流、物流、资金流等都是数据流。没有数据流作为基础，一切都是空谈。在坚持数据保护和贸易流动方面，欧盟和美国已经做出了有益的探索。虽然基于这个探索形成的协议在2015年出现了波折，但是由此形成的机制值得参考，这种模式思路的探索不应该成为历史，而需要继续往前一步。（本文刊登于《中国信息安全》2016年第3期，连载完）长按二维码关注《中国信息安全》公众号：chinainfosec![](../Images/e8f4659e34dd66f8d9ac295681ab56df.png)
