# 3·15｜恶意扣费程序、智能设备隐患…晚会曝光的网络安全问题及对策

![](../Images/b6ec7493485475ddffa74b9e01edefab.png)点击上方“中国信息安全” 可以订阅消费在民，一年一度的3·15晚会越来越受到老百姓的关注。还记得去年3·15曝光的信息安全问题吗？信安君带您回顾一下：电话诈骗、银行漏洞、实名制虚设、免费wifi陷阱等。随着互联网应用深入大家的生活，在获得更多便利的同时，安全问题也越来越多。信安君整理了今年曝光的网络安全问题，以及相应问题的对策。一、APP存在恶意程序插件，手机莫名被扣费![](../Images/1947444cc91c3ec36a8d0db76d6bab55.png)  
会上，“道有道”和“话语”两家广告营销公司被曝光。他们将恶意程序嵌入APP应用中，有意模糊或伪装扣费按键，诱使用户点击，并屏蔽甚至自动发送扣费二次确认短信，导致用户手机不明不白就被扣费。信安君建议使用手机时尽量从正规的应用市场下载APP，操作APP时先看清楚再按键。二、APP和Wifi漏洞泄漏隐私![](../Images/09548d9d2a9b7735fea3e179c53eef6e.png)  
晚会主持人邀请现场观众做了这样一个实验：首先，大家的手机都连上现场的公共wifi。然后，主持人问了几位观众，之前都打开过手机上的哪些APP。果不其然，几位观众手机里这些APP上的信息都被窃取，并显示在了现场大屏幕上。一些上门美甲、订餐、购买电影票等软件，会泄露用户地址、联系方式，甚至连叫了什么餐，什么时间在哪个电影院买了几张几排几座的电影票都一目了然。主持人还介绍，不仅有安全漏洞的wifi会泄露信息，一些自身存在安全漏洞的APP也会。如果不法分子获取这些信息，对个人将是极大的安全隐患。信安君建议在安全可靠的应用市场下载APP，同时账户尽量设置复杂程度较高的密码。购买正规安全可靠的路由器，不随意连接来历不明的公共wifi。三、智能终端设备存安全隐患![](../Images/7d99ee57c373750d88a27226f38123f4.png)  
晚会现场播放的视频录像显示，人们生活中使用的一些智能设备，如智能洗衣机、智能插座、智能摄像头等，都有可能被黑客利用安全漏洞入侵，进行监控甚至远程操控。还曝光了不安全POS机终端，若被不法分子利用，可造成个人银行卡信息及密码的泄露，对个人财产安全是极大威胁。信安君建议不随意连接不明wifi的同时要提高自家wifi的安全，选择靠谱的路由器，设置高强度的wifi密码，不要使用“wifi万能钥匙”以及同类蹭网软件，并关闭路由器的wps功能。（不会关闭的小伙伴请自行百度~）在此，信安君也呼吁广大智能家居设备厂商重视产品的网络安全问题。四、扫二维码泄露个人信息![](../Images/16cd6878940d56d7085652c3c8e3369f.png)  
晚会曝光了一些无良商家利用街边摊、促销优惠送礼等手段，吸引消费者扫二维码，以此获取用户个人信息隐私，安装恶意程序等，对消费者财物及人身安全造成威胁。信安君建议街边小摊的刷卡机和二维码，千万不要刷！！![](../Images/7d41451bcbb916cfdeab8c076a847063.png)科技越来越发达，生活越来越便利，但安全问题不容忽视。从自身做起，提高网络安全防范意识，不给犯罪分子可乘之机。![](../Images/2d1e052d7a3381a9b6bc14f616b77595.png)
