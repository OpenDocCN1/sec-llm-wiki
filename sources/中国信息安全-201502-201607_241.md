# 连载二｜安全极客是怎样炼成的？——万涛的新安全人才观

点击上方“**中国信息安全**”可以订阅哦培养信息安全人才需树立新安全人才观万涛![](../Images/88d87208537ccb3097e4cda5d7f0195b.png)网名老鹰，2015 GeekPwn嘉年华评委，益云创新中心&IDF实验室联合创始人，中国计算机取证专委会成员。1992年进入信息安全领域，经历和见证了中国互联网安全产业的发展和演变历程。曾先后服务于普华永道、公安部冠群金辰和IBM等企业。关注威胁情报、无线安全、智能硬件、家庭光伏电站、数字无线电等方面的研究与实践。您如何看待当前的信息安全人才培养体系？**万涛**：从以往相当长的一段时间看，在信息安全人才培养上，教学和实践不能同步发展，过去常见的现象是高学历并不能代表高能力。曾经业界有这样一种调侃的说法：一类高校毕业生从事信息安全工作，躲在政府机构或银行总部等甲方，年薪10万左右；二类高校学生，多在安全企业，年薪20万；偏科自学型学生，业有专长，在互联网公司，年薪30万；没接受高等教育的，从事黑产，年收入50万。当然，最近几年我们欣喜地看到如清华、上海交大等高校出现了产学研结合注重攻防竞技的学历与能力并进的优秀人才，但与市场以及企业需求以及行业发展来看，我们还不能盲目乐观。您认为产生这种现象的主要原因是什么？**万涛**：主要是由于信息安全高等教育的硬伤造成。首先，学科内容配置存在一定的滞后或者不足。课程内容和教学方式方法不能激发或者吸引学生的兴趣与学习热情，而信息安全是个需要浓厚兴趣以及相当的沉淀和实践才能做精做深的跨界专业，没兴趣无专注就无法深入和展开。而且，当前学校的课程很多已经脱节，学生学到的是落后于产业界最新实践的过时内容。从师资队伍角度来看，很多教师也是半路出家，缺少安全实践和业务经验，接触不到产业最新的技术和成果，不了解安全市场和安全业务需求。其次，教学手段传统保守，缺乏开展攻防对抗实战的必要条件和风险防范能力。信息安全和物理化学一样，是对动手能力要求很高的专业，不经历安全实战，只会纸上谈兵，无法真正承担对业务视野、实践能力要求极强的信息安全工作，更谈不上在此领域有所建树。信息安全人才培养要让学生在实践中了解和体验安全行业和安全威胁，熟悉现有技术手段和管理实践，充分认知安全治理所涉及的人性、社会性、法律、政治、业务环境，真正具备快速进入信息安全领域的从业能力。您认为在人才培养过程中，最重要的因素是什么？请您结合自己的经历，谈一下信息安全人才成长中的关键要素。**万涛**：安全人才培养过程中，最重要的因素是安全文化观或者是职业使命的认知。过去常说网络安全技术是双刃剑，说通俗点就是对安全技术和管理的平衡性把握的认识和控制能力，这不是简单用“武德”可以概述的。安全文化观必须能回答为什么安全、什么是安全、安全的底限和上限是什么等问题。我个人认为，信息安全人才成长中的关键要素应包括：**环境激励。**不是个体而是群体性的安全人才的成长，外部的激励环境非常重要。重文轻武的大宋帝国无法培育对抗蒙元的将军。信息安全是集实用性和前瞻性非常强的跨界学科，而其社会价值与彰显可能不如影视娱乐和公众领域来的直接和易见。所以一个国家、社会乐于支持，媒体主动传播，法律与时俱进，资本敢于投入的安全产业氛围和公众高度关注的安全文化意识是非常关键的要素。**资源支持。**信息安全的实践和学习都对基础设施和应用场景需要一定的条件，跨界学习与实践的挑战很大，且具备一定的风险性。对于信息安全人才培养来说，在今天没有必要每个人都从零开始，而是可以根据兴趣和专长专注信息安全的某个技术应用领域，也可以从行业认知出发，专注关键业务的风险管理。而这些都需要现实或者模拟现实的资源支持。所以在教学环境资源上，需要更好的如开放式的攻防实验室、甲方业务模拟环境等资源支持与分享。**对抗竞技。**信息安全人才培养和国防军事训练有类似的地方，在不同维度和层次对信息安全人才有不同的需求和要求。所以基于实战的对抗竞技是必不可缺的环节，创造和支持丰富的不同层次的对抗和演练形式与鼓励，既有利于信息安全人才的选拔，也带来更好的传播普及效应，也是发现教学方式方法问题和改进人才培养的重要途径和评价手段。**风险教育。**安全技术是双刃剑，善于运用和合理运用需要与之匹配的法律监督与监管的防范。对于未来走向信息安全管理和技术岗位的信息安全人才来说，这也是减少偏离以及误入歧途的有效防范。您如何看待当前院校、企业、独立的信息安全研究者？他们有什么主要区别？**万涛**：当前院校受到教育体制与格局以及师资、生源等环境与条件的限制，除了少数院校和老师，有相当一批院校的信息安全人才培养模式正面临严峻的挑战，但依然是未来信息安全人才最重要的来源，也是企业与独立安全研究者潜在的重要合作伙伴，是信息安全独立和趋势研究最重要的潜在资源。企业信息安全研究者受企业价值观、格局、视野以及业务重心、规模、资金和管理的影响，特别是互联网企业的安全部门与传统安全企业的关注点依然存在一定差异或者分歧。独立的信息安全研究者拥有最大的兴趣自由度和灵活度，但受到信息安全行业巨大变化和挑战的影响，在资源和深度上面临一定的挑战，承担的风险和压力也相对院校和企业为大，但从安全产业和视野的格局来说，独立信息安全研究者的方向往往可以更快速地反映安全行业的潜在新方向和机遇机会。院校、企业和独立的信息安全研究者，和国家安全监管、执法部门等，既要加强协作，又鼓励支持开放竞争，才能共同构筑发展有鲜明中国标签的安全产业生态与环境。您如何看待比赛对信息安全人才培养的作用？**万涛**：安全是在对抗中逐步加强、改进和演进的, 如同笔试不能绝对代表英语的学习水平一样，CTF等安全比赛的模式可以在非威胁刺激环境下给信息安全人才一个接受挑战和检验水平以及彰显自我和能力的机会，和军演、游戏竞技有类似的地方，也有利于吸引更多有才华的年轻人投身信息安全事业。当然，这类比赛只是一种比较有可观赏性和吸引企业和公众参与的模式之一，除了技能性的比赛，我们还要积极开展基于行业核心业务的安全对抗（如运营商的安全大比武）、应急演练、渗透测试等其他形式的安全训练活动，丰富比赛的模式与内容，提升信息安全人才对职业的深度认知，避免浮躁和流于形式。您曾经提出新安全人才观，该如何理解？**万涛**：现在的信息网络安全与过去相比发生了巨大的变化，或者说正在呈现泛化的趋势，从维度来说包括但不限于有业务思维的基础安全、有态度的信息安全、有效益的社会安全、注重艺术和美的传播安全、无边界有权责的数据安全以及风险导向的金融安全等等。新的安全观对新安全人才提出了新的挑战，所谓新安全人才观，是指新型安全人才应具有广阔的视野、平衡观，既能跨界，也兼有艺术之美。作为安全行业人才，要有一颗极客的心，自由平等分享和互助的精神，辅以新安全人才观和宽广的视野。有更多的人才参与进来，才能打造出未来美好的安全整体生态。您认为将来信息安全人才的发展呈现一个什么样的态势？**万涛**：“互联网+”时代，信息产业迅猛发展，未来社会对安全的需求必然迎来一个强劲的增长，我们要看到对未来安全人才的潜在需求和需求变化。目前，社会各界对信息安全虽然日益关注，但还是对此缺乏理解、参与和体验以及足够的尊重，这也影响了全社会对于信息安全人才的需求和认识，也使我国未来的信息安全产业和相关“互联网+”产业对于安全人才的投入和储备存在总量不足和需求偏差的隐忧。就目前来看，熟悉硬件和软件，特别是有业务思维的“跨界”安全人才还属于稀缺资源，我们要立足当下，放眼未来，大力加强对信息安全人才的培养。（本文为《中国信息安全》杂志记者原创）
