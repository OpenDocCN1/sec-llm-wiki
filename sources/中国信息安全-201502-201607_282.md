# 拥抱“互联网+”，江南天安助力阿里云保障云端安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=404951721&idx=5&sn=4d95b3e16ace8c6851d63bb60ded2e75&chksm=0db610503ac199464e97739e30cbb45c1090f973619213a4d76cea21275761e576428c85d1f3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=404951721&idx=5&sn=4d95b3e16ace8c6851d63bb60ded2e75&chksm=0db610503ac199464e97739e30cbb45c1090f973619213a4d76cea21275761e576428c85d1f3&scene=27#wechat_redirect)

12月10日上午，在2015年全国商用密码展览会上，阿里云联合江南天安推出加密服务，可以解决用户云端数据隐私问题，有望满足云端金融、政务、电商等行业对数据安全的强烈需求。

![](../Images/62d0620a53800449b23011515b977e01.png)  
*现场发布仪式*

据悉，这是国内首款云数据加密服务，简单的说可以实现让数据明文进去，密文出来。北京市密码管理局局长许博春表示，商用密码的安全性、规范性越来越受到国家重视，而基于加密服务构建的云端应用，无疑将让云上数据更安全。此次阿里云与江南天安联合推出的加密服务，是云服务厂商与国产商用密码厂商在业内的一次创新。

阿里云资深安全总监肖力表示，随着云计算的发展，原来的安全和云计算的安全有很大的不同。传统的数据安全市场需求不是很强烈，但是到了云计算环境，在这种公共平台上，用户对数据安全就非常重视。这给整个数据安全行业带来很大的变化，数据安全会随着云计算的发展会成为下一个迸发的领域。

而作为传统的安全厂商代表，江南天安此次携手阿里云，不仅是重要的商业合作，也是自身积极布局“互联网+”的重要步骤。江南天安总经理邓小四表示，云计算的发展实际上是一个业务生态，作为厂商，从安全的角度来说，一定是要跟业务生态配合，共同发展。和阿里云的合作，充分体现了“互联网+”的精神，安全的春天已经到来，但还有各种各样的挑战，但我们对未来的发展充满信心。![](../Images/226f1974eaf0b1de36378e0210093e2b.png)

*邓小四和肖力答记者问*

本次发布的云数据加密服务有两大亮点，其一能够实现在线使用、按需付费，并符合国家安全合规的相关规定。肖力介绍，“当数据加密从采购硬件迈向采购服务的时代，配置周期也将从一个月缩短为一天。同时，按需付费更是极大地节省了企业的成本”。其二，加密服务最大的创新是将密钥交给客户控制，让客户获得最高等级的数据安全性。使用该服务的云计算用户会收到一张独享的云端身份令牌。通过该令牌，用户可轻松与云端加密服务交互，完成密钥的初始化，部署，授权，备份等操作。业务系统将通过加密服务的API接口，对业务数据实现密文转换和解读。![](../Images/838718c30e014321846363f2b02250a0.png)  
*江南天安展位*

加密服务先期引入了江南天安生产的硬件密码机(HSM) 设备。该设备已通过国家商用密码主管部门认证，完全满足金融、政企等用户在数据安全方面对加密和监管合规的强需求。这也是国内首款唯一获得国家密码管理局认证资质的云数据加密服务。

当前，各种新技术新应用层出不穷，传统安全边界已经模糊，依靠传统的方式和措施手段，企业已难以有效应对目前的安全防御挑战，必须联合第三方安全厂商相互合作，共建互联网安全产业链生态。肖力表示，与江南天安发布云计算加密服务只是开始，建设云安全生态、形成立体防御体系是阿里云发展的重要方向，希望有更多的安全厂商加入阿里的安全云生态，用自己的产品技术服务于云上的用户。邓小四也强调，未来将与阿里云共同携手把云端安全做得更好、更扎实，江南天安会在云计算领域持续加大投入，保持技术领先，同时与云服务商合作，推出更多的云加密服务，共同打造云安全立体防御体系。
