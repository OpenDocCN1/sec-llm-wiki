# 第二届XCTF国际网络安全技术对抗联赛启动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=400774217&idx=2&sn=2f41f7e09262c60e9248e5a988c78167&chksm=027656b03501dfa6bb6e3a9e7fe2ae44dc846b6bcc84557571e0cba82c6c6ba2feb7e0deb29a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=400774217&idx=2&sn=2f41f7e09262c60e9248e5a988c78167&chksm=027656b03501dfa6bb6e3a9e7fe2ae44dc846b6bcc84557571e0cba82c6c6ba2feb7e0deb29a&scene=27#wechat_redirect)

第二届XCTF国际网络安全技术对抗联赛（简称“XCTF国际联赛”）启动会于11月2日在北京举行。XCTF联赛组织委员会、监督委员会成员和首届联赛赞助商代表齐聚怀柔雁栖湖国际会展中心，共同商议联赛相关事务，XCTF联赛2015—2016赛季正式启动。  

![](../Images/f07d9a4bea2cf7ff11e19de46e53a992.png)  

2015—2016赛季关键词：国际第二届XCTF联赛进一步从全国联赛升级成为国际联赛。在“一带一路”国际战略背景下，以及首届XCTF全国联赛成功举办的基础上，第二届XCTF联赛将集结中国网络安全攻防圈的集体力量，打造“一带一路”国际联赛。![](../Images/eb3425e8591e780384618a7ce00ae353.png)  
首站揭幕赛选择于11月14日在“21世纪海上丝绸之路”的起点——福州正式开启，除中国大陆和台湾地区海峡两岸网络安全竞技队伍之外，还将接受与邀请东南亚、南亚、西亚、东非、北非、南欧等“一路”沿线国家队伍参赛；第二场国际赛则选择“新丝绸之路经济带”的起点西安，特邀中亚、西亚、东欧和西欧等“一带”沿线国家队伍参赛；并将北京站、上海站设立成为国际赛场，分别由中国大陆两支国际级强队－蓝莲花和0ops命题组织，并设置丰厚的奖金吸引全球强队来华PK；将XCTF总决赛的舞台致力打造成为顶级国际赛场，预计将有八支国内顶级强队和八支“一带一路”国际著名队伍决战巅峰。

据了解，在第二届XCTF联赛总决赛同时将召开中国白帽黑客WhiteHat大会，大会将产业高峰论坛&技术论坛、厂商展览、会场解谜寻宝 、著名团队培训与动手实训、现场解题竞赛以及多种娱乐体验项目相结合，为安全从业者和爱好者们提供多样化交流平台。

第二届XCTF国际联赛，期待您的参与！关于XCTF  
XCTF国际联赛是由高校、科研院所、安全企业、社会团体等共同组织，面向高校及科研院所学生、企业技术人员、网络安全技术爱好者群体，旨在于通过竞赛公开选拔奖励具有全面且深入网络安全技术对抗实践能力的参赛团队，并引导高校及科研院所学生、企业技术人员和网络安全技术爱好者在竞赛过程中锻炼实际网络安全对抗技能与团队协作能力，提升我国网络安全技术人才水平，进而增强我国网络空间安全防御能力。**主办单位**网络空间安全人才发展基金国家创新与发展战略研究会**承办及协办方**• 总体承办方：南京赛宁• 选拔赛组织方：清华/上海交通大学/杭电/成信/福大/河南省信息安全保密协会/四叶草 + Blue-Lotus/0ops/HDUSec/Syclover/ROIS/FlappyPig/CloverSec• 总决赛承办方：南京赛宁/Blue-Lotus/0ops首届XCTF回顾

![](../Images/19b581ce375ae201a76c2cb8cf3519dc.png)  
首届XCTF全国联赛采用国际前沿的CTF（CaptureThe Flag）解题与攻防竞赛形式，历经10个月，踏遍中国整片疆土，吸引了89个国家、3847支队次，超过1万人次参与。在杭州(杭电)站选拔赛（HCTF）、成都(成信)站选拔赛(SCTF)、上海(上交)站选拔赛(0CTF)、北京(清华)站选拔赛(BCTF)、杭州(浙大)站选拔赛(ACTF)五场七场选拔赛中脱颖而出的十二支强队，于今年7月在南京江宁决战“紫金江宁之巅”。最终，台湾大学217战队夺冠，上海交通大学0ops和福州大学ROIS分获亚军和季军。随后XCTF联赛三支战队HITCON、0ops与Blue-lotus战队一起并肩进入DEFCON CTF全球总决赛（相当于网络安全领域中的“世界杯”）世界前六位，以良好战绩为中国在网络安全领域争得了荣耀。至此，首届XCTF全国联赛在“江南佳丽地，金陵帝王州”的古都南京画上圆满的句号。
