# “西湖论剑—中国网络安全创新分享大会”热点探析

11月1日，“西湖论剑——中国网络安全创新分享大会（CCIS2015）”在杭州白马湖畔召开。这是信息安全界的第三次“西湖论剑”，大会今年的主题是“分享、创新、安全”，在主办方没有高调宣传的情况下，共有近600位来自各个行业的信息安全人士参加了会议，就最新政策解读、数据安全、云安全、网络空间安全、IOT安全、互联网+、信息安全人才培养等热门议题进行了深入的探讨和交流。

用创新的理念，全球化的思维做好网络安全工作

![](../Images/fce505a2d1b840577a4e4c3fb9416863.png)  

*中央网信办网络安全协调局局长赵泽良做主题发言*

针对国家近期的网络安全政策，中央网信办网络安全协调局局长赵泽良重点围绕着大会的创新、分享主题谈了他的思考。

他指出，首先要树立创新的理念，让创新成为网络安全工作的基石。网络安全工作本身就是一个新生事物，我们要应对的就是不断出现的新问题、新挑战、新风险，对这一工作并没有千篇一律的模式和现成的经验可以照搬，只有不断地去探索，不断地去学习，这就要求我们必须要创新。在实践中已经确立的一些网络安全制度和要求要坚持，但互联网和信息技术的发展，使得传统的网络边界越来越模糊，系统越来越难以分清，这种情况下就要求我们用网络空间的思维来应对网络空间的问题和挑战。网络空间思维就是要以整体的思维，全局的思维来应对问题、解决问题，而不是各自为战，分而治之。新时期对外开放的全球化环境下，网络安全工作一定要用全球化的思维，用创新和分享的思路和理念来应对。网络安全工作者的责任，是既要用好先进技术，发挥IT技术的潜力，发挥互联网的优势，又能保证国家安全、企业安全、老百姓的安全，而不是将国外先进的东西拒之门外。我们不能因为安全政策、规定，来妨碍先进技术的使用，最终影响国家的经济繁荣发展。我们要坚持开放的理念，立足于全球化的环境，做好网络安全工作。网络安全是世界性的问题，网络安全挑战当然是世界性的挑战，应对这种挑战，我们不能关起门来解决，也不可能关起门来解决。只有开放才能带来先进，封闭必然导致落后。最后，赵泽良强调，全球化的思维是一个双向的过程，不仅包括让国外先进的产品、技术、服务进入中国，我们还要更多的参与国际性的竞争，特别是要在国际的制度安排、规则、标准上更多的发出中国的声音、注入中国的元素、体现中国的利益、拓展中国的空间，这是我们立足全球化环境下做好网络安全工作的重要内容。“互联网+”时代的数据安全

![](../Images/c67c31bb7fbfefcca6ec25e857f60056.png)  
*阿里巴巴技术副总裁杜跃进做主题发言*

针对很多人对大数据又爱又恨的心理，以及对BAT掌握大数据的担忧，阿里巴巴技术副总裁杜跃进博士表示，数据安全问题不仅仅是大公司的问题，所有人都将遇到和我们今天一样的问题。人人都爱大数据，人人都想大数据，但是都忽略数据安全。数据技术是未来的必然趋势，是中国技术超车的希望，不能因为安全问题就因噎废食。

杜跃进认为，现在网络安全涉及到很多方面，融合趋势不可避免。从个人电脑时代到网络空间时代，数据从纸质到电子化，到数据库、企业数据，到数据仓库、大数据，概念已经不同，而数据防护也在随之演变。他以阿里巴巴的数据管理为例，介绍了当前大数据管理和安全所面临的挑战和变革，以及用户数据和隐私保护的思路和方法。杜跃进表示，面对当前形形色色的安全研究，数据安全可以说显得有些“土”，但数据安全是“互联网+”时代的基础性课题，关于数据安全的现状，可以说“我们还在路上”。安恒发布“先知”工程

![](../Images/089fb30b6a5ff0a2778e44d2f3091809.png)  
*安恒总裁范渊讲解云上合规*

安恒总裁范渊发表了“安全让数据腾飞”的主题演讲，他表示，当前安全态势严峻，未来的网络空间对抗已悄然到来；同时，智慧城市等重要新兴技术的推进，也需要安全来保驾护航。在上午的大会环节，安恒信息联合公安部信息安全等级保护评估中心同共发布了“云上合规”解决方案。范渊表示，“安全是信息系统的基础，安全也是信息系统的助推器，最终，我们还要让安全为业务产生更多价值。”

同时，安恒还在会上发布了威胁情报与态势感知研究计划——“先知”工程。据安恒信息智慧城市安全风暴中心副总经理杨勃介绍，有别于传统的网络安全防护，“先知”工程是基于整体的态势感知能力来进行整体的网络安全防护，目标是做到“未卜先知”。“先知”通过部署在全国的分布式监测节点全天候监测整个网络空间，实时探测刷新网络空间的设备、端口、资产、应用等重要信息，并对空间中的各类设备进行安全监测以及终端日志分析，形成对网络空间的安全态势感知。杨勃透露，“先知”工程已于今年内在浙江省公安厅、宁波市公安局、丽水市电子政务外网、世界互联网安保等工作中成功应用。会上，浙江经信委总工厉敏、中国信息安全测评中心主任朱胜涛、四川大学教授陈兴蜀、梆梆安全总裁阚志刚也做了相关发言。会议主办方还安排了参观杭州青山湖科技城“云安小镇”，了解了青山湖科技城管委会将“云安小镇”建设成为中国网络信息安全第一镇的愿景。大会设置了云安全创新技术分论坛暨云安全联盟（CSA）沙龙、IOT安全技术、人才与信息安全产业发展圆桌会议三个分论坛，与会人员在分论坛中展开了更进一步的深入研讨和交流。
