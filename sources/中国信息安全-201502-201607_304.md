# 打点万物互联智能设备安全

人类从移动互联网时代向万物互联时代前进的道路上，将面临诸多新型的安全威胁。在不久的将来，传统设备会大规模智能化，以传感器、芯片为主体的智能设备将渗透到人们日常生活的点点滴滴，通过智能设备，人们可以随时将自己生活、工作的内容数据化，然后通过网络传输到云端整合起来，由此可见，智能设备、互联网和云技术的应用，实现了信息的聚合，传统行业将实现巨大变革。在万物互联的时代，智能设备作为终端节点发挥着举足轻重的作用，正在全球范围呈现出大爆发的增长趋势，并在工业、航空、交通、医疗、家居、办公等各个领域全面开花，发挥至关重要的作用。智能设备广泛应用，与人们的日常生活息息相关，一旦遇到安全威胁就会导致经济损失、隐私损失、甚至危及人身安全，不仅有别于过去的安全，还有许多潜在的未知风险渐次降临。

智能设备概念热：三大特征2007年，iPhone智能手机的出现，一度引爆了智能设备市场，一发而不可收拾，首次为人类诠释了智能设备这个科技概念。智能设备通过软硬件结合的方式，对传统设备加以改造，让其拥有智能化的功能，也就是以一种全新的方式将现实生活中的机器、设备、人、网络通过传感器、控制器与应用软件联系起来，并将实时数据传送到云端存储分析，形成了“云-网-端”的架构，而智能设备就是“端”的主要表现形式。在移动互联网环境下，现在的智能设备都具备了网络连接的能力，让用户能够随时随地感知、控制设备的状态。智能设备与传统的电子设备不同主要表现在以下几个方面：一是智能化。相比普通的电器设备，智能设备增加了传感、控制等功能，可在设定程序后，实现自动控制、提醒的效果，能够代替人工完成各项任务，比如，在下班回家的路上，智能汽车自动导航前行，而此时家里的智能电饭煲会自动煮好米饭，到家后智能门锁感应开门，智能电灯和智能电视自动开启，生活因此变得愈加便利，这就是智能时代变革的力量。二是网络化。智能设备通常借助蓝牙、WiFi等进行数据传输，用户可通过网络实时查看设备的运行状态，还可以远程发送指令控制设备运行。三是多样性。智能设备应用的领域非常广泛，如家居生活、城市建设、医疗、工业、航空等，几乎所有的传统电子设备都能够借助传感、控制等器件实现智能化、网络化。智能时代变革潮：五大分类1974年出现的Pulsar计算器手表可以被看作是智能化设备的雏形。30多年后iPhone手机随着移动互联网发展，对传统互联网运作模式产生颠覆作用，拉开了智能化设备接入网络的大幕，物物相联的智能设备逐渐登上时代大舞台。2012年，SmartWatch的出现刺激了智能硬件市场的发展，引发了传统互联网设备模式向智能网络模式变革的热潮，智能时代也从探索期走向了市场启动期，并将快速进入稳定发展期，形形色色的智能设备开始活跃在各个领域。在国内，随着小米、腾讯、百度、360等知名企业的加入，智能设备市场呈现井喷式增长趋势。目前，可穿戴设备、智能电视、智能冰箱、智能汽车、智能玩具、智能医疗、智能工厂、机器人等联网智能设备陆续走向大众消费市场，今后门锁、电灯、茶杯、桌椅都有可能智能联网。通过联网和控制，智能设备可以为人类提供便利的生活和办公环境。分析机构IDC预测，到2020年将有2000亿台智能设备连接至互联网，而现在约有50亿台设备。根据移动应用统计分析公司Flurry的报告，中国已经超过美国成为全球最大的智能设备市场。目前，广泛应用的智能设备只要有以下几种：一，可穿戴智能设备。当下流行的可穿戴智能设备主要有智能手环、智能手表、智能眼镜等，这些设备可帮助用户记录日常生活中的锻炼、睡眠、饮食等实时数据，然后通过特定网络将数据同步到手机、平板上，便于用户查看检测数据，指导用户健康生活。二，智能医疗类。智能医疗设备目前主要有智能血压计、智能轮椅、智能心脏起搏器等，目的是通过智能设备检测患者的生命体征信息，结合数据分析和特定算法，发现患者身体健康问题，通过智能设备采集的数据还可推送到云端，实现远程监测、诊断、治疗和咨询，智能医疗设备使患者就诊变得更加简单便利，使跨国跨省会诊更加轻松。三，智能家居类。主要包括智能电视、智能冰箱、智能窗帘等，为日常生活注入了科技元素，通过自动控制、互联网、大数据等技术，构建家庭日常事务管理系统，保证居住环境的便利性、舒适性。四，智能安防类。家庭安防类产品在今年的CES上备受关注，如智能摄像头、智能门锁等，通过这些智能设备，用户即使不在家，也能够通过手机应用进行远程指挥控制，实时了解家里的安防情况，对婴儿监护、独居老人关注提供便利。五，其他关键行业。智能设备还广泛应用于工业、交通、城市建设等方面，随着科技的发展必定还会应用到更多领域，开启智能时代的新纪元。智能设备安全事：触目惊心近两年，智能设备呈现井喷式增长趋势，随之而来的安全问题自当引起充分重视。智能时代与PC时代不同，智能设备都具备一定的自动控制功能，一旦出现信息安全问题，不仅仅是软件系统遭到破坏，更有可能导致大规模的隐私泄露、经济损失，甚至造成人身伤害。截至目前，由于智能设备漏洞引发的安全事件已屡见不鲜，国内外一些组织和个人也陆续开始关注智能设备安全。2013年，著名白帽黑客巴纳比•杰克宣布将在黑客大会上展示心脏起搏器远程攻击，从9米之外入侵植入式心脏起搏器并发出指令，让设备释放出高达830伏的电压，形成让人瞬间致命的电流，该事件在当时引起轩然大波，也将硬件设备安全问题推向风口浪尖。2014年，在美国召开的黑帽大会上，智能设备成了黑客攻击的新目标，谷歌旗下智能家居品牌Nest的智能恒温器、汽车的智能仪表盘等被一举攻下。同年10月，在北京举办的“极棒”GeekPwn是全球首个关注智能生活的安全极客嘉年华，在智能设备破解挑战赛上，参赛者对NEST家居控制器、特斯拉汽车、智能WiFi插座、路由器、智能机顶盒、智能摄像头等一系列智能设备进行了现场破解并取得圆满成功，比如，黑客仅仅通过捕获空气中的蓝牙信号即可以破解某智能门锁的密码，进而直接开门进屋。技术的不断革新让人类体验到不一样的智能生活，同时也必然面对更多的新型安全威胁。惠普曾对市面上最热门的10款消费级智能家居产品研究，竟发现250种安全漏洞，产品涉及电视、网络摄像头、家用恒温器、远程电源插座等。韩国高丽大学的安全人员Seungji n Lee曾遥控三星智能电视发布“白宫遭到攻击”的假新闻，并证明了可以通过智能电视监视用户，除此之外，飞利浦、惠普等多个知名品牌智能电视均被曝光存在严重安全漏洞。美国西雅图一家科技公司发现了入侵智能插座的办法，并可控制被入侵者的家电，甚至包括开启加热装置和电熨斗。美国trustwave安全公司成功破解了日本Lixil智能马桶所使用的蓝牙通信链路，能通过蓝牙发起连接而任意操纵马桶盖的开启和关闭，自动喷水。计算机安全研究公司Proofpoint发现了一种新型的僵尸网络，可感染联网的家电设备（路由网关、电视、多媒体中心等），并对外发送数十万条恶意数据。随着智能汽车的盛行，越来越多的汽车制造商开始将车辆操控和网络相连，而汽车安全事件也频繁引发风波。除了特斯拉安全攻击事件，宝马公司 ConnectedDrive 、美国通用汽车公司 OnStar都存在安全漏洞，致使汽车处于潜在危险之中。随着联网的智能设备日益增多，安全威胁更加多样化，在真正的智能时代到来之前，有必要对智能设备信息安全予以足够的重视。智能设备安全解：盲点软肋智能设备广泛应用于日常生活和关键基础设施中，一旦被攻破或是失控，会给用户带来巨大的损失，必须引起密切关注，智能设备安全事件频繁发生，为安全研究人员敲响了警钟。随着国家对信息安全层面关注程度的提高，智能设备的安全问题也逐渐进入专家、学者以及大众的视野。但是，从目前来看，智能设备安全形势仍不容乐观，主要表现在以下几个方面。**一、硬件开发厂商不重视信息安全，设备安全令人担忧**智能设备开发属于创新型工作，参与研发的企业主要分为三类：第一类是传统的电器生产企业，如海信电器，第二类是智能控制类企业，如东软载波，第三类是互联网电商，如小米。这些企业的专注领域各有不同，技术水平良莠不齐，由于智能设备大多是快速消费品，各生产厂商对设备产品的研究大多聚焦在设备功能方面，而对于设备的安全性研究存在关注少、投入少等问题，其产品采用的硬件和软件都相对简单以缩短开发周期，导致产品的安全机制不完善，有些产品甚至完全没有考虑安全性问题。因此，目前市面上的智能硬件都存在很大的安全隐患，比如固件代码使用不安全的函数、开启不必要的网络端口、固件中内置管理员账户密码等。**二、用户安全意识薄弱，黑客入侵轻而易举**智能设备产品所面对的用户都是普通消费者，用户群体非常广泛，且大多数完全不具备信息安全知识，他们不会料到黑客可能早已攻击了家里的智能电视、智能摄像头、智能冰箱、智能手环等设备，并通过这些智能设备详细掌握了自己的家庭环境、财务现状、健康状况等重要敏感信息，用户安全意识薄弱给黑客提供了更多入侵的机会。**三、安全管理制度松散，缺乏统一标准**目前，传统安全产品的准入管制相当严格，而对于智能设备产品的准入的管理非常宽松，由于智能设备发展迅速快、平台差异性大、应用范围广，因此管理起来有较大难度，在智能设备等新领域的安全准入标准制定方面尚待研究。不同的智能设备，其硬件、固件等方面存在较大差异，设备的多样化为形成标准化的智能设备安全测评、漏洞发现、漏洞修补机制带来了较大困难。**四、网络扁平化发展，接入安全问题突出**随着智能化、网络化普及，智能设备纷纷接入互联网，网络扁平化导致接入点无处不在，网络边界变得不再清晰，那么黑客攻击面呈倍数增长，曾经在终端防护中一贯使用的隔离、切断等安全管控措施会面临巨大挑战，任一联网智能设备受到攻击并感染，其传播速度将呈指数增长，影响范围不得而知。**五、数据大多存放云端，传输和存储安全面临挑战**为了使用的便利性，智能设备的设计者通常会选择将数据传送到云端存储，据悉，有相当数量的智能设备数据使用明文传输，黑客可通过劫持网络流量控制设备，再加上现在云存储市场处于发展阶段，大多公有云安全性防护能力差，且大多数智能设备依赖于移动应用传输控制信号，意味着网络服务、云应用出现安全问题，都可能会导致大规模用户数据信息泄露，黑客利用云计算、大数据等技术分析用户行为和日常生活轨迹的案例早已屡见不鲜，保护好智能设备的数据安全是保障用户隐私安全的重要部分。**六、硬件信息安全产业化滞后，缺乏有效的防御技术**在产业化方面，国家力促进可信嵌入式软件在高端装备领域的发展和使用，并向工业控制、智能装备以及物联网等领域辐射和转化成果，但是，目前产业化效果并不明显。在国外，Itus Networks已推出iGuardian产品用于检测智能家居信息安全，用于保障智能设备安全，而目前国内尚未出现专门针对智能设备的信息安全防护和攻击检测产品。因此，在智能设备大批量生产并投入市场的过程中，必然会导致由于安全防护技术不到位而引发的不可控制的局面。智能设备安全路：三大方向随着智能生活的到来，智能设备将无处不在，将面临巨大的信息安全挑战。为了确保人民的日常生活免受侵害，必须采取措施对新型智能设备引发的安全问题加以防护。综合各方面的原因，结合目前国内智能设备应用的实际情况，我国应持续推进在智能设备安全方面的政策、标准、安全技术研发和应用等工作，在安全管控和防护方面加大力度，引导和促进设备厂商对安全问题的关注和投入，同时推广智能设备安全概念，提高用户群体的安全意识，保障我国信息安全工作的顺利进行。 第一，在用户层面普及智能设备安全观念。用户是智能设备的主要使用群体，是保障嵌入式设备安全最为关键的一环。厂商和科研机构、教育部门、宣传单位应该推广正确的信息安全观念，提升用户的安全意识；推广安全的设备使用方法，在企事业用户中普及安全的管理理念，降低人为安全隐患的风险。第二，在行业层面构建智能设备安全的规范措施和标准。产品制造商是保证设备安全的基础。法律和政策应该引导和促进设备厂商对智能设备安全问题的关注，促进智能设备行业安全标准的制定；建设和完善统一的智能设备漏洞库；推动厂商建立和完善设备漏洞快速响应机制；促进厂商建立健全的智能设备安全测评和风险评估机制，划分产品安全等级，尽可能降低智能设备因为安全问题带来的风险。第三，在技术层面加快智能设备安全技术研究。安全性研究是保证智能设备安全的关键技术手段，由于智能设备的固有特征，对其进行安全隐患和漏洞的挖掘和测试具备难度，且难以形成统一的技术标准。科研机构、设备厂商应该高度关注硬件、固件方面的安全技术，加大研发投入，针对设备硬件和固件开发出有效的安全隐患发现和方法和高效的测试手段，构建智能设备安全防护技术体系。国家应出台专门政策，引导科研力量关注智能设备安全基础理论、关键技术等重大课题，吸引社会资源研发智能设备硬件和固件安全防护手段和产品，从宏观和微观上共同为我国信息技术的发展保驾护航。（本文刊登于《中国信息安全》第9期）
