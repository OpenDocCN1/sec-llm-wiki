# 史上最全的2015两会信息安全提案与建议

十二届全国人大三次会议和全国政协十二届三次会议分别于2015年３月5日和3日在北京召开，“信息安全”也成为代表委员关注的话题。张德江委员长在今年人大常委会工作报告中明确表示，今年要加强重点领域的立法，包括制定网络安全法。李克强总理在今年的《政府工作报告》中更是提到要“依法保护企业和个人信息安全”。代表的建议和提案涉及立法制度建设、隐私保护、数据保护、电信管理、产业发展等方面。

1怀进鹏全国人大代表、工信部副部长

怀进鹏代表表示，要严防隐私泄露，保信息安全。例如当大数据应用于医疗领域，对于特种疑难病等，属病人隐私，需要保护。应该对个人、公务信息进行分类管理，“比如哪些信息需要有立法，哪些方面要开发，形成一个有效利用信息、保护信息、尊重信息的大环境。”

2李世杰全国政协委员、民建中央组织部长

李世杰委员递交提案建议加强对骚扰电话及信息的管理。骚扰电话问题不如杀人放火之类的刑事案件社会影响大，但却给人遍地是骗子的感觉，不可小视。手机是个人的通信工具，骚扰电话和信息是对个人权益的侵害，必须要加以制止。建议公安、工商、工信部等主管部门，应切实负起责任，用经济、行政和法律等手段，加强对骚扰电话的综合治理，还广大消费者一个安宁。建议加强对用户信息的保密工作，对泄漏和倒卖信息的个人和单位，要严加惩处。电信企业在注重经济效益的同时，也要讲社会责任，应采取技术手段对骚扰电话进行监控，必要时进行停机处理。

3陈建国全国政协委员、农工党中央常委

陈建国委员建议，应当鼓励民营企业参与国家信息安全领域建设。从国际经验来看，最好的技术实践往往来自有良好激励机制和研发应用环境的私营企业，而政府会主动建立常态机制，从国家层面给予支持。我们要发展信息安全，也需要支持自主可控创新技术领域的民营机构，积极参与到国家信息安全体系建设中。云计算、大数据等新兴技术在我国正在快速发展，为弯道超车，摆脱对国外技术和产品依赖，真正实现自主可控提供了极大的可能性。建议以“十三五”规划为契机，着眼未来长远，选取云计算、大数据、物联网、生物识别等下一代信息产业关键领域，提前制订规划，予以重点扶持，支持技术领先企业不断做大做强，早日达到国际领先乃至一流水平；鼓励产学研结合，建立国家信息安全领域引导扶持基金，对民营机构与科研机构、高校合作的技术创新项目，以非营利目的参与支持。

4严望佳政协委员、启明星辰首席执行官

严望佳委员此次向大会提交了三份涉及信息安全提案。一是《关于在关键基础设施、敏感部门、政府机构等推行首席信息安全官制度》的提案，第二个是《关于在电子政务云建设过程中做好安全保障工作》的提案, 第三个是《关于在关键基础设施、敏感部门、政府机构中落实透明供应链登记工作》的提案。

5廖仁斌人大代表、电信湖南公司总经理

廖仁斌代表呼吁重视信息安全这个战略问题，提出了《关于加快建设大数据时代个人信息安全保护体系》的建议，加快国家对大数据时代个人信息安全的统一立法工作。大力构建大数据政府监管和行业自律体系，推动大数据信息安全产业繁荣发展，提升公民信息安全防范技术水平和安全保护意识。第二个提案是关于加快推进产业互联网发展的建议。以顶层设计推动产业互联网快速发展，加大基础设施建设，建设更加优质高效的信息高速公路。鼓励创新、打造产业价值链，丰富信息资源、业务应用和商务模式，不断壮大产业互联网生态圈。构筑覆盖基础设施层面、信息应用层面、风险管控层面、个人诚信层面的安全防范体系，确保产业互联网的健康发展。第三个是关于加强电子商务交易与信息安全管理的建议。建设国家级电子商务交易者认证平台，让所有参与电子商务交易的双方得到权威的认证。利用消费者反馈和大数据监控电子商务交易的真实性和交易商品。建立电子商务平台信息安全管理体系和评估机制。

6钟天华人大代表、中国移动广东公司总经理

钟天华代表提交了《关于加快制定〈网络信息安全法〉的议案》，呼吁国家加快立法，保护网络信息安全。提案共分六章58条，从监管主体、设施安全、运行安全、信息安全、法律责任等方面进行全面规范，主要内容包括明确网络与信息安全管理机构的地位和职责；明确网络安全等级保护制度；完善网络基础设施保护规定，加强关键基础设施保护；强化公民信息安全权利保护，加强个人信息保护和垃圾信息治理；完善电子交易保密制度，确保网络交易安全；明确危害网络及计算机系统安全等违法行为；加强对利用网络危害国家安全、公共安全行为的打击；明确网络虚拟财产规定，为打击网络违法活动提供制度保障。

7左世忠人大代表、山西高级人民法院院长

左世忠代表提出尽快制定网络安全法的建议。一是要尽快制定一部统一的网络安全基本法。二是明确网络从业者和社会组织的行为规范、责任、权利和义务，明确网络监管者的主体、权利、职责、监管程序、行为规范等。三是重点防范危害国家安全、网络犯罪、侵犯公民权利等违法犯罪行为。四是保障网络核心技术发展，改变我国网络安全核心技术薄弱的现状。五是建立对各种网络事件的应对机制。六是对现行与网络相关的法律法规进行梳理并进行修订和补充。七是拓宽视野，放眼全球，借鉴其他国家先进的网络立法经验。八是结合我国国情，制定具有中国特色的网络安全法。

8谢子龙人大代表、老百姓大药房董事长

谢子龙代表呼吁加强网络个人信息安全管理。建议推动《个人信息安全保护法》的尽快立法，按照“谁经营、谁负责”的原则，对于政府部门、金融、电信、交通、教育、医疗、中介等单位的个人信息保护作出严格规定，全面保护网络个人信息安全。制定行业规范，针对网络个人信息的管理者（如政府单位、企业或个人），一旦收集了信息，就要建立一套“谁收集谁保护谁泄露谁负责”的信息保护制度。规范对个人信息的收集、储存及使用行为，明确相关的个人信息在使用完毕后应该及时删除；对于泄露个人信息的行为，采取严厉的行业惩罚措施。

9李彦宏政协委员、百度董事长兼CEO

李彦宏委员表示，希望设立国家层面的“中国大脑”计划，推动中国人工智能的跨越发展。“互联网+”计划，我的理解是互联网和其他传统产业的一种结合的模式。这几年随着中国互联网网民人数的增加，现在渗透率已经接近50%。尤其是移动互联网的兴起，使得互联网在其他的产业当中能够产生越来越大的影响力。每一个行业和互联网一旦结合，尤其中国现在传统产业。市场经济只有几十年的时间，并不是很成熟，并不是特别的高效率，用互联网的方法再做一遍，我们可以看到有太多太多的机会。

10马化腾人大代表 腾讯董事会主席兼CEO

马化腾代表对推动我国互联网与其他产业融合发展提出了三点建议。一是加快制定“互联网+”全面发展的国家战略及具体指导意见，鼓励和促进互联网与各产业的融合创新，推动“互联网+交通”、“互联网+医疗”等新业态以及“互联网+政务民生”的快速发展。二是研究制定我国公共数据开放战略，将政府公共信息与数据向全社会开放，打破行业信息孤岛，确保社会公众能及时获取与使用公共信息。同时，逐步建立数据安全保护体系和数据开发利用的标准，确保数据的有效使用和相关方权益。三是重视互联网快速发展中出现的违法犯罪问题，依法规范网络行为，打击网络犯罪，同时保护正当合法的网络行为，促进互联网快速、健康、有序发展，让互联网更好地服务经济、社会的各个领域。

11赖小民人大代表、华融资产管理董事长

赖小民代表表示，应对互联网征信数据的采集范围、使用原则和信息安全等问题做出明确的法律规范，防止个人隐私被侵犯甚至泄露。我国《征信业管理条例》规定，征信机构不得采集个人收入、存款、有价证券、不动产信息等，明确告知主体提供该信息可能产生的不利后果并取得其书面同意的除外。然而在互联网时代，怎么向用户进行有效提示，微信朋友圈文章、支付宝转账记录、在线填写信息等到底算不算个人隐私？一旦隐私泄露，应该怎么维权？对此，他建议，一方面需要明确大数据背景下数据采集、整理、加工、分析和使用的规则，特别是对哪些网上信息可以采集、如何使用、如何维权等做出确切规定，要从立法层面完善征信信息安全和数据管理的相关法律法规。另一方面在技术上，要研究并采用最先进的网络信息安全技术，从信息的存储、传递、使用、销毁等全流程进行信息保护，防止信息外泄。积极培育市场化的征信机构非常必要，但必须在有效监管、完善制度和维护信息安全的前提下开放市场。

12牛弩韬人大代表、安徽省经信委主任

牛弩韬代表建议尽快制定一部国家层面信息化基本法律，填补相关法律空白，在我国建立健全形成信息化和网络安全的相关法律法规体系。我国现有与信息化相关的法规数量较少、规定笼统。一些现有的规范，内容较为简单,执行难度较大；一些互联网新领域法规欠缺，与信息化发展存在一定程度脱节。如互联网金融、电子政务、电子商务等方面法律，都比较欠缺。

13冯俊政协委员、浦东干部学院常务副院长

冯俊委员谈到，个人信息安全立法迫在眉睫。当前大数据概念十分火热，大数据需要采集大量的个人信息，其中就会涉及许多个人隐私。如果对这些收集数据的行为与数据的使用不加以规范，一旦与互联网传播相结合，会导致严重的侵害个人权利的行为。大量个人信息泄露事件的出现，表明保护个人信息安全迫在眉睫。在个人信息的法律保护方面，美国采取分行业保护的分散立法模式，保护个人信息的法律规定散见于各部门法。欧盟模式则是一种政府主导下的个人数据资料的保护模式。以制定统一的个人信息保护法为特征，两种立法模式各有利弊。他建议，国内可借鉴上述两种模式各自的成功经验，尽快形成个人信息保护的中国立法路径。大数据时代，保护个人信息安全是一项非常复杂的系统性工程。它需要从法制建设、技术创新、监督管理、行业自律等多层面进行配套制约，建立起长效机制。基于当前我国大数据的发展趋势和个人隐私保护存在的问题，为把全面推进依法治国落到实处。

14谢渡扬政协委员、中国建设银行原监事长

谢渡扬委员认为，银行业在大数据分析应用方面已具备相当的系统、机构和人才基础，可以利用数据挖掘和分析探索大数据防范电信诈骗汇款。出于加强风险把控、业务创新、改进客户服务的要求，银行业对发展大数据应用有相当的紧迫感。建议可考虑将银行业作为开展大数据应用的重点试点行业，率先启动，加大工作力度，以此带动和推动大数据应用在我国的发展。

15王明雯全国人大代表、西昌学院法学教授

王明雯代表认为，当前网络安全问题已成为公共安全的重要组成部分，网络信息安全及网民的网络隐私权保护面临着严峻的挑战，因此建议制定《中华人民共和国网络隐私保护法》。据调查，有49.0%的网民表示互联网不太安全或非常不安全。遭遇信息泄露、消费欺诈等问题，严重影响到网民的网络安全。当前网络安全问题已成为公共安全的重要组成部分。对于个人来说，个人隐私的保护与他的生活安宁休戚相关。过度地曝光，变得透明，将失去安全保障。因此，立法保护网络隐私是保护个人隐私和生活安宁，保障公民和法人的合法权益的需要。对于网络行业和相关企业来说，加强行业自律已经成为共识，但是因为缺乏法律制度的规制，这种自律是靠不住的，因此也需要立法跟进，规范网络活动。对于国家来说，如何推动互联网的健康发展，充分利用大数据的运用作为发展经济的抓手，是当务之急。

16孙丕恕人大代表、浪潮集团董事长兼CEO

孙丕恕代表提出了“推动政府数据开放工作”的建议。认为，信息技术和互联网的发展带来了数据的爆发式增长，数据正在成为驱动经济增长和社会进步的重要基础和战略资源。我国必须加快政府开放数据的步伐，要统筹规划，出台指导意见和行动规划，大力推动政府开放数据标准的制定工作，并鼓励社会化力量广泛参与政府数据开放。我国的社会信息资源80%掌握在政府手中，大部分都是高价值数据，一旦将这些数据开放，将为中国经济的转型增长释放巨大的红利。我国必须加快政府开放数据的步伐，要统筹规划，出台指导意见和行动规划，大力推动政府开放数据标准的制定工作，并鼓励社会化力量广泛参与政府数据开放。

17陈伟才全国人大代表、格力电器副总裁

陈伟才代表建议，建立电信诈骗冻结资金“原路返还”机制，让这些钱原路返还给受骗者。电话用户与运营商签订了服务协议，用户交付来电显示费用，运营商就应按照电信条例的要求提供准确的来电号码。因为改号来电被骗，运营商应负民事赔偿责任。还要将买、卖银行卡入刑。刑法规定买、卖伪造的银行卡属于妨害信用卡管理罪，但这只能处理伪造而不能处理真实银行卡的买卖行为。
