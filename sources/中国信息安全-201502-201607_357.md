# 封面人物｜唐荣喜：保护重要数字资产安全刻不容缓

作者简介唐荣喜，南京工学院毕业，民建上海闸北区委会员。上海俊悦光纤网络科技有限公司董事长，高级工程师，第六届上海市慈善之星，第12、13届上海市闸北区政协委员。

网络强国战略带来新机遇

习近平总书记在中央网络安全和信息化领导小组第一次会议上提出“网络安全和信息化是事关国家安全和国家发展、事关广大人民群众工作生活的重大战略问题”，“没有网络安全就没有国家安全，没有信息化就没有现代化“，把网络安全摆到了前所未有的高度。信息化战略要求我们从各个层面提高对信息安全重要意义、重要价值和重要功能的认知，从原本单一局限的信息安全技术，拓展至信息安全意识和人才队伍建设、网络安全技能、数据技术素养、安全防范手段的全方位和综合性的安全保障体系，形成全天候和动态型的信息安全综合系统，以提升国家和企业的保障水平和竞争力。这既给信息安全产业界提供了发展机遇，也给产业界提出了新要求，赋予了新任务。自从中央网络安全和信息化领导小组成立以来，从顶层设计上统筹网络强国的发展战略，显示出在保障信息安全、维护国家利益、推动信息化发展决心，从关键基础设施保护出发，对重要技术产品提出安全管理的高要求。政府已经从产业高度来关注信息系统国产化，IT系统国产化正在成为保护国家信息安全乃至国家安全的重要手段。由于历史的原因，在大型机、操作系统、大型数据库等方面我国并不占优势，但在新兴的虚拟化、智能终端、嵌入式物联网设备，高性能存储等方面的产品与技术面临着产业的重新洗牌，大家在同一起跑线上有更多的发展机遇，另外，在军队信息安全防护体系中，政府正越来越鼓励更多的社会资源参与其中的建设。国家层面的重视，为IT系统国产化的实施提供了可靠的政策保障，并能为整个信息安全行业带来巨大的商业价值。

数据安全建设进入高峰期

在移动互联网、云计算的快速发展环境下，网络正在成为继水电煤电话等之后的重要生活必需品，数据成为用户信息的核心资产，随着“棱镜门”事件继续发酵，个人隐私意识和企业数据安全意识正在双重提升，预计金融、运营商和央企即将迈入数据安全建设的高峰期，而政府行业用户由于便民服务需求的紧迫性将紧随其后、快速启动。可以说，在云计算、大数据等新技术背景下，作为计算资源以及存储资源的重要载体，网络数据如果不能从基础结构上得到有效保障，信息安全就会成为建筑在沙滩上的大厦。对于信息安全产业界来说，需要密切关注并结合大数据、云计算、物联网、移动互联网、智慧城市、可穿戴设备、工业4.0等领域的技术发展，在这些新的发展领域采用新的商业模式，推动并保障新的生活方式，让信息安全技术与产品融入到政务、军队、金融、电信、交通、能源等重要领域以及涉及民生的智慧城市、智慧社区等民用领域，使之摆脱原先曲高和寡或者可有可无的尴尬境地，真正地为民所用，为民所喜。随着政府对信息安全的高度重视，国产化步伐加快，必将促使我国信息安全产业取得跨越式发展，而这些工作，都留待我们信息安全领域的科研院所以及厂商来共同努力完成，目前，国家尚未形成统一的网络安全防御体系，在抵御重要网络威胁、应急重要网络事件时，速度远远落后于其他国家，我国在网络空间上的重要资产数量远低于其他国家，在漏洞修复趋势和危机应急反应能力方面，与我国的网络大国地位极不相称。复杂的国际国内形势下，我们对信息安全的物理基础环境不得不加以足够的重视，对重点数据中心的设计必须采取平战结合的原则，居安思危。遵循平战结合原则，由政府有关部门牵头管理指导，联合有关监管部门、有关技术提供单位及建设单位，利用现有人防工事来建设高等级的，符合战争、防灾难标准的数据运行及备份中心，以达到在现代化战争和各种自然、人为灾难来临的时候，保证重要数字资产的安全保障，从容应对，已经是一项刻不容缓的紧迫任务。近年来，党和政府机关，军工企业，金融保险证券，医疗院校和上市企业增加了少量数据，据不完全统计，我国现有IDC装机在50万只标准机柜左右，其中只有5万只机柜或多或少涉及到国家馆或企事业商业秘密，但相应的机房防灾能力却极为薄弱，国家有关部门尚未制定灾难数据备份中心的运维标准，日常的雷击、火灾、地震等灾害防范能力不足，更谈不上防止战争攻击。根据中央及相关部委有关文件精神，我国各省市及部委建造了大量的屏蔽机房和数据中心，但仍达不到防止灾难和战争的要求。因此，应立即着手制定标准，按标准要求设计、施工高等级安全数据中心，以确保国家秘密信息和商业秘密信息的安全。

探索平战结合高强度数据中心模式

在信息安全领域，我们长期注重于信息防泄漏产品技术的研发与部署，涉及党、政、军、警、航空、航天、造船、军工等重要企业的涉密计算机信息网络系统，为国家政务网，公务网，党务网信息化建设提供有力保障。这些领域的用户其基本点是对信息安全有着比较清晰的认识，并对相关技术与产品有着严格的要求，在技术点上，对于自有技术以及国产化设备比较关注，要求产品必须通过相关技术测评与认证，注重统筹设计、自主可控、渐进替代，等级保护等方面，对于信息安全强调集中统管，构建全面的信息安全体系，因此，他们特别需要能提供全面综合的整体安全解决方案以及国产化产品的信息安全厂商。在上海市机关事物管理局与人防办监管下，由解放军南京工程兵工程学院以及国家保密局防电磁泄漏专家指导设计，建造的“上海佘山防战争容灾云数据中心”，具备抗常规武器、核武器以及电磁脉冲武器攻击的能力，并能抗震，抗雷击，内部采用国产化的云计算平台，兼容各类应用平台，实现了计算，存储，网络资源的独立与智能化统一管理，除了常规防火墙之外，更引入了主动安全理念，可以为用户提供抢先式安全性和健壮性测试方案以及态势感知，在客户产品和服务发布或部署之前减少已知和未知的安全威胁，实时监控并排除网络故障；并且建立了应用与数据持续保护平台，可以对用户托管的服务器进行定时快照，服务器系统由于软硬件原因崩溃时可以得到无缝热备切换，使用户托管的信息系统得到最好的安全保障。数据中心由原人防工程改建而成，通过探索军转民改革之路，将纯军事专用性设施转向军民结合，为国民经济的发展服务，站在国家安全和发展的全局高度提供军民相互兼容的技术平台和设备，形成军民相互支撑、相互促进、协调发展的格局，充分挖掘国防科技服务国民经济发展的潜力，并为应对未来信息化战争威胁提供切实有力的运维经验与基础设施。可以说，该数据中心已经成为国内最安全的容灾云数据仓库之一，为电子政务、电子商务、网络金融证券、网络交易、虚拟云服务、网络社区等应用提供强有力的安全保障，发挥巨大的社会效益与经济效益。

数字资产保护大有可为

信息技术和应用的发展还带来了大量管理“漏洞”，如一些网络运营商将收集的信息进行大数据分析并销售给他人，给用户带来巨大安全隐患，针对行业中企业侵害个人隐私、开展恶意竞争等受到广泛关注的问题，需要加强行业管理规范和行业自律准则的制定和实施，规范信息安全企业的行为，以确保重要数字资产的安全。当前的形势对信息安全产业界来说，是一个极为难得发展机遇期。尤其是云计算、大数据、物联网等新兴技术的兴起更为信息安全行业提供了广阔的用武之地。广大信息安全从业者应当抓住机遇，顺势而为，把技术做好做深，把产业做大做强。目前我国信息安全市场参与者数量不少，但主流信息安全厂商所占市场份额不到50%，集中度较低，国内安全厂商企业规模普遍偏小，市场集中度分散，企业优势仅仅局限于某一个或几个细分领域。随着各领域优势企业资金和技术实力的增强，信息安全亟需形成整合式竞争优势以满足企业整体IT建设的需求。以自主技术为基础，以统一整合为主导，构建完整的信息化解决方案，才能适用目前快速发展的信息化需求，提升中国信息安全自主可控能力。政府应该发挥信息安全企业各自的优势地，在自有核心技术产品研发基础上，联合产业上下游其他企业，带动从基础产品到应用产品和服务的具有完全自主知识产权的产业发展，以资本为纽带推动资源整合，充分发挥行业协会、产业联盟和政府机构的作用，提升自主企业应对国际竞争的能力。（文章刊登于《中国信息安全》2015年第4期）
