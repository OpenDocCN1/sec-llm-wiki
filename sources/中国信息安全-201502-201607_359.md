# 【网界论衡】大数据安全解析（BDSA）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=207427364&idx=2&sn=bb8cddbfd683b17963db6f77e52d3b21&chksm=19c815dd2ebf9ccb5e0b2f2d285bff1c95e5cafe84911da7063da9e8007abc7a268504bcf37a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=207427364&idx=2&sn=bb8cddbfd683b17963db6f77e52d3b21&chksm=19c815dd2ebf9ccb5e0b2f2d285bff1c95e5cafe84911da7063da9e8007abc7a268504bcf37a&scene=27#wechat_redirect)

大数据安全解析（BDSA，Big Data Security Analytics）近几年来成为了信息安全领域的一个热点，引起信息安全专家和相关企业的广泛关注。其原因一方面缘于大数据技术的兴起，另一方面也缘于传统的信息安全技术难以应对网络空间威胁不断发展和变化的挑战。BDSA严格意义上并不是全新的技术或方法论，基于数据的安全解析在传统安全信息和事件管理（SIEM，security information and event management）得到了普遍的应用，但大数据和大数据技术确实为信息安全领域带来了全新的思路和不同的视角。例如在信息安全管理上，将以往的人、过程和技术（PPT）对象延展到了人、过程、技术和数据（PPTD）；在威胁管控上，除了行政安全控制、物理安全控制和技术控制外，增加了数据安全控制，即通过数据手段来进行威胁管控，如基于数据解析的异常行为管控等。

BDSA的根本是“解析（Analytics）”，即从数据中发现有意义的模式或咨情（Intelligence）并能提供可视化。概念上，解析完全不同于分析（Analysis），前者涉及多种学科的应用，如统计学、机器学习、计算机科学或软件工具等，因此解析意味着系统的方法论和技术支撑；而后者往往是指对事物的具体解读过程，例如结构化的分析是设法将较复杂的问题分解为若干个较简单的问题来进行解读。对安全的解析则是通过科学技术手段从数据中揭示能够解决安全问题的模式或咨情。在BDSA语境中，安全是指网络空间安全或信息安全，典型的场景是企业信息安全。“企业（Enterprise）”的含义包括一般意义上的企业，也包括组织和政府机构等。就企业信息安全而言，安全解析目的是从数据中及时提取出能够明确引导企业信息安全威胁管理的具体信息。强调“及时提取”、“明确引导”和“具体信息”意味着解析的结果应可以用来决定行动的咨情（Actionable Intelligence），而不仅仅是帮助理解企业安全态势的知识。“解析”一词本身其实已蕴含着数据，故“数据解析”多少有些同义反复，不过冠之与“大数据”的确增添了不少新的语义和新的挑战。具体到企业信息安全管理，大数据的“大”更多意味着“全”，即需要全面、完整地获得所有相关数据，才可能进行有意义的安全解析，才可能不会忽略企业网络环境中恶意行为的蛛丝马迹。这种数据“全”的要求，必然带来数据的“大”，也同时带来数据解析的复杂性。典型的BDSA的数据源包括了日志数据、网络流数据、元数据、配置数据、资产数据、上下文场景数据等方面。从大数据3V特征（Volume、Velocity、Variety）来看，数据“全”的要求显然扩大了安全信息数据源，而网络流数据的要求则显著地影响到数据的量和数据的速度。业界有人提出：为了保证安全解析的有效性，企业要获取所有数据、存储所有数据、运用所有数据。这确实有一定的道理，无疑是一个极大的挑战。如此种种，可能将未来的安全成为典型的大数据应用之一。在信息技术领域中，大数据常常是大数据技术的同义词，BDSA中的大数据(BG)也同样更多地意味着大数据技术。BDSA之所以能够成为新一代的信息安全技术，也正是由于大数据技术的不断的发展而逐渐能够支撑起复杂的安全解析任务所致。例如信息安全解析有效性的一个重要的指标是及时性，这反映到技术上即是在大数据的实时或近乎实时的处理要求。过去的几年，大数据技术生态中在这个方面有着长足的发展，其中包括流数据的摄取、实时消息总线、实时索引与搜索、数据节点分布式实时计算等诸多方面。尽管其中有些技术尚不成熟，但这些技术进步之快，出乎所料。尤其值得赞赏的是，大数据技术生态中是开源的基础上发展起来的，其中包括大数据实时处理技术。BDSA的兴起引发了业界许多讨论，例如BDSA平台与SIEM的关系，是替代现有的SIEM系统，还是SIEM系统将演变为BDSA平台等。当然，BDSA发展的尚不成熟，究竟在企业信息安全中能起到怎样的作用还需拭目以待。此外，BDSA也面临着数据科学家稀缺、与领域专家如何结合这类问题的困扰。但无论怎样可以肯定是，BDSA将会对信息安全的发展带来深刻的影响。
