# 中国信息产业商会信息安全产业分会秘书长李斌：做好“四方平台”助力信息安全产业发展

编者按  

作为我国信息安全产业的行业组织，中国信息产业商会信息安全产业分会在我国信息安全产业发展过程中起到了重要的作用。商会如何看待我国信息安全产业发展的这20年？它在产业发展中的自我定位和主要作用什么？在新形势下如何开展工作？带着这些问题，我们采访了中国信息产业商会信息安全产业分会的秘书长李斌。

![](../Images/2180a2f7d0d7a872a3106278ffe65430.png)  

记者：在信息安全蓬勃兴起的过程中，协会组织扮演了特殊的角色。中国信息产业商会信息安全产业分会作为安全产业界的社会团体，聚拢了产业界的诸多厂商。您能否谈谈这一产业分会组建的背景和其初衷？

李斌：中国信息产业商会信息安全产业分会是2002年成立。回顾2002年信息安全产业的形势，我国的信息安全产业刚刚兴起，市场本身还有些无序，规模较小，产品种类相对单一。现在的启明星辰、天融信、卫士通那时都才是几十个人的规模，跟国外赛门铁克、RSA等大型的集团相比差距很大。

虽然政府部门已经开始重视信息安全，但是很多政策缺乏一个比较合适的渠道去宣贯，同时企业也很难了解到一些政策性的信息，把自己的声音跟政府部门进行有效的沟通、对接。此外，还有很多大型行业用户与安全企业之间也没有建立起一个比较通畅的沟通渠道，对国产产品、国内的产业也不太了解。在这样的背景下，我们成立了信息安全产业分会。

信息安全产业分会成立的初衷，也就是目前商会的定位和宗旨，即成为政府、用户和企业之间的三方交流平台。现在还增加了国际交流方面的工作，也称为“四方平台”。

记者：您觉得协会自成立以来所发挥的作用主要有哪些？

李斌：目前我们提出了三个目标来评价商会的工作。一是促进我国信息安全产业的发展，二是维护安全企业的利益，三是规范产业环境。

这些年，商会一直在做的一项工作就是协助政府对企业展开调研，包括很多政策制定之前的一些调研。我们会组织会员企业和一些主管部门，如公安部、保密局、工信部，还有原国信办等部门，以座谈会或者交流会的形式，来充分反映企业的声音和诉求。同时也通过一些政策宣贯会，第一时间把主管部门的政策解读传达到会员企业。这是政府相关主管部门和企业都很欢迎和重视的工作。

作为用户平台，商会也经常组织金融、电力、交通运输等大的行业用户和会员企业以座谈会的形式进行交流，让用户能够了解国内的产业和企业发展现状、未来的发展规划等，同时把这些行业用户对信息安全的诉求及时有效地传达给会员企业。

对于企业之间，商会的会员企业大都有各自的拳头产品或者优势技术，我们通过组织企业之间的交流，形成一个完善的产业链，利于整个产业的良性发展。多年来，会员企业对于商会这个平台的权威性、公正性也十分认可，包括企业不同的产品和技术的组合，企业之间的技术沟通和交流，重组并购、上市等重大决策，都会选择商会这个“娘家”来发布。在必要的时候商会还作为“检委会”、“居委会大妈”等角色来协调会员企业之间的一些矛盾和分歧。

另外，从2012年开始，商会也陆续开展了国际交流，帮助我们的会员企业走向国际市场，包括到新加坡、美国参展，到美国与国际信息技术联盟（ITI）进行交流，不仅包括技术方面的交流，也包括一些中美两国关于安全的市场环境和政策环境的交流。这两年商会的国际对外交流越来越多，不少企业也开拓起了国际市场，比如东软、绿盟等。

记者：如您所说，代表产业界与政府行业等进行沟通交流是近年来分会一直在做的主要工作，有哪些重大成果可以分享？

李斌：除了以上所说的代表产业界与政府行业等进行沟通交流以外，商会还承担了国家信息主管部门跟产业相关的有关政策、产业环境的课题的研究。例如2009年承担的工信部“关于信息安全产业的投融资环境的政策研究”，这项研究成果有力地促进了我国面向信息安全产业的投融资政策的改善。目前业内很多企业都上市了，而近两年上市的会员企业就有十家左右，这项政策研究可以说是发挥了一定的作用。另外，国家关于信息安全的十二五规划，甚至十三五规划里，商会也协助主管部门对产业的现状和面临的问题以及诉求，进行了充分的调研，形成了一些成果，供相关部门在制定行业相关政策时参考。

记者：作为信息安全的行业组织该如何适应新的形势，继续开展各项工作？

李斌：目前的信息安全形势，需要各方高度重视。网络空间的发展对传统的安全企业造成了很大冲击，另外大型的国有企业也开始进军安全产业，这是产业的发展形势。从国家层面来看，目前国家对网络空间安全，或者叫网络安全更加重视。这些变化导致传统的信息安全其外延发生了一些改变，不再局限于传统的信息安全基础上，而是在网络空间安全和总体安全观这个大的背景下来看待我国的信息安全，这对我国信息安全产业的发展有一定的促进和冲击。产业形势、国家政策形势发生的变化，给商会带来一些新的挑战和机遇。

目前，商会一个新的工作方向就是要组织和帮助会员企业来应对互联网产业对传统信息安全产业的冲击。传统信息安全企业的经营模式是“一对一”，面向个人或企业用户，而互联网企业走的是P2P模式。互联网带来的一些新的思维，新的观念，甚至包括一些新的营销模式和技术发展方向，都和传统的信息安全企业不太一样，这些都对传统信息安全企业的话语权有很大的冲击。对于企业自身来说，不能固守它原有的模式，要去适应，甚至是驾驭互联网对传统信息安全产业方方面面的冲击。

另外，企业要发挥各自的技术优势、资金优势、市场优势，加强横向合作，打造新产业群。这样的话，企业不仅能找准各自定位，既有分工又有协作，还能扩大市场号召力和规模效应，发挥专业信息安全企业的技术优势和创新能力，把产业真正做大做强。

在政策方面，现在国家赋予网络空间安全的内涵更深，外延更大，所以我们的信息安全企业也应该紧随发展，从维护我们国家安全、维护网络空间主权这个层面和角度来看待安全市场，在新的政策环境里重新定位我们的产业力量。以前我们呼吁用户给国产企业和国产技术产品多一些机会，现在新的机会已经出现，我们当务之急是能不能满足用户的需要，能不能把这个工作做好。所以商会的工作重点也从原来为企业去呼吁市场机会、政策机会，转变为组织会员企业抓住机会，把企业的创新能力迅速提升，最终把目前的这种机遇变成常态化，确实能够迎来一种长远的、可持续的发展，这是商会现在面临的一个新挑战。

记者：从您个人角度，您怎么看待安全产业界的合作与竞争？产业界最需要加强哪些方面？

李斌：从我个人角度来看，现在国内的信息安全产业存在一个比较突出的问题，就是同质性竞争矛盾比较突出。有些产品重复率太高，比如说防火墙、各种扫描软件等传统产品，几乎主流的厂家都有，又比较分散，但是这些企业之间的竞争远大于合作。同质性竞争导致了价格战，有限的市场规模容量同时也导致大家的利润都很低，也不利于技术的创新和积累。

我们希望会员企业能通过抓住目前产业发生的一些变化带来的机会，与进驻产业的大型国有企业或者其他行业的综合性企业、央企等来合作，通过打造产业群或者说是航母式发展的方式，各自寻找定位，发挥出各自的优势。其他的行业就有这样的例子，例如一个汽车企业，整装厂可能就一家，但是由它来带动几千家甚至上万家的配套企业。这些配套企业专做其中的某些零部件，甚至是某种材料，最后由这种大的汽车厂或者整装厂来完成组装。未来我们也建议或鼓励在信息安全产业采取这种模式。但这种模式一定是在比较好的市场环境或者是政策推动下慢慢形成，不能完全指望利用行政手段来做到。

商会现在的会员企业已经开始出现这种分化，一部分是大的上市企业，甚至包括央企都进来了。还有一部分是规模比较小的创新企业，他们的最大优势就是在做一些创新的技术或产品，是老的传统厂商不愿意做的新方向和细分领域，这些小的企业现在已经开始和大型企业就参股、投资、控股、战略伙伴等进行合作，加入到大企业的产业群里，这种模式的合作是我们鼓励和支持的。另外现在很多别的行业，比如像房地产，都开始投入到信息安全产业，表明产业前景一片大好。

我认为产业的竞争不怕，但是要有序。我们鼓励大家在技术层面良性竞争，鼓励创新，鼓励技术升级，鼓励为用户提供更好的服务，但是我们反对无序的竞争，甚至包括价格战，这对整个产业都是冲击，最后产业就两败俱伤，这个大家都不愿意看到的。我们希望产业有多种方式合作，技术合作、战略合作，甚至包括资本合作都可以尝试。

新的政策形势给了产业一个新的机遇，但是也是一个新的挑战，由原来要做大市场变成了要满足市场的需要，实现这个转变，就是目前产业界最需要最急迫的问题，所以我们迫切希望产业在核心技术方面能够有所突破。现在国内的产品可能在填补空白或者解决有无问题层面做的还不错，但跟国外的高端技术和产品之间的差距依然很大，是整个产业未来五到十年的最主要的挑战。

产业要做到解决有无问题，那么首先必须先解决一个好坏的问题，要有更好更实用的产品和更高端的技术。其次要解决产业界这种小而全的传统经营理念。最后要适应新的互联网思维模式或者经营模式，这也是一个挑战。例如，互联网企业对安全理念的阐释影响广泛，它们开始并不关注产品如何去盈利，而是先从观念和理念上去影响和教育市场，等市场接受这个观念后，再开始推广相关的技术和产品，再开始扩大市场。但是传统的信息安全企业依然保持从前那种低调做市场、做销售的经营模式，致使传统安全企业日益丧失话语权，有的企业已经感受到了这种危机，这还需要企业的经营理念尽快做出改变。
