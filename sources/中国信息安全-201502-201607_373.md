# 博鳌聚焦|嘉宾热议大数据安全

3月28日上午，在2015博鳌亚洲论坛“大数据的局限、误区与真相”电视辩论中，嘉宾就大数据的隐私问题展开热议。

**百度总裁张亚勤：**

第一个问题是数据是不是可靠。我把我的数据存在你的云端里面，我的东西会不会丢掉。这个问题可以通过技术来解决，相对比较容易解决。

第二个是隐私的问题。因为这里面有技术的问题，有法规的问题，有政府的政策问题，也有用户的使用习惯问题。最近iCloud的苹果艳照，eBay有多少帐户丢了，很多事情是他的密码，有些是很简单的可以猜得出的密码，所以隐私的问题是很重要的，但是很重要的一点就是企业需要负更多的责任。

第三个问题是安全问题。互联网现在走向物理化，过去更多的是虚拟空间，数据，现在真正到了物理化之后，你的汽车，你的家电，你的支付交易，都到了云端，这个时候，安全、黑客的攻击就变得十分重要了，因为不仅仅是过去数据信息本身，而且它也包括了银行支付的信息，交易的数据，而且也包括了你的医疗信息，我们讲的移动医疗，电脑有四个轮子，信息全在云端，这个时候如果有黑客攻击，他把你的车开走怎么办，所以牵涉到人身的安全。

**格力董事长董明珠：**

大数据可能有安全问题，但是我们不能因为有小偷就不上街了，在这个时代，我们必须往前走，要怎么走得更好，这是大家都关注的问题。小偷的问题必须要解决，但是不能因为有小偷，我们不往前走。

**韩国京畿道知事南景弼：**

我觉得权力会带来腐败，尤其是对于一些没有得到控制的权力会带来腐败，所以应该能更好地监管个人的权力。我们需要大数据吗？是的，需要。我们现在大数据的这种体系是非常有效的吗？不是。它有是危险性的吗？是的。为什么？因为大数据有可能会变得非常具有挑战性，我也有点担心谷歌，它有大量的数据，但谁知道他们现在用这些数据在？数据是非常强大的，尤其是对于没有得到控制的权力也是非常危险的，所以说我们需要监管，而且需要有很好的管理，但是，我们知道大数据包括核电也是比较危险的，但是我们需要它们，我们也要建核电站，所以在这方面我们需要有更好的治理，能够来管理权力。

**爱立信董事长雷夫·约翰森：**

大数据不是非黑即白。我们现在有能量采集海量的数据，现在我们已经在做海量数据的采集了，但是真正的问题是，是好还是坏？这要取决于数据的分析，也就是运用这些数据在社会的哪些领域，而要取决于社会、政府，还要取决于不同的企业，以企业为导向的应用，总体来讲，还是一件积极的事情。
