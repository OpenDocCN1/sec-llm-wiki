【观点】左晓栋：自主创新、安全可控不是搞闭关锁国

近日，就外媒热炒的中国发布网络安全新规、要求提交源代码等问题，中国信息安全专家左晓栋接受了媒体采访，对外媒长期关心的问题做了正面回应，努力还原技术的本来面目，批驳了西方一些人的对华偏见和敌视。根据当事人的回忆，现将这次采访内容摘要刊登如下。


反对带着有色眼镜看待中国成立网络安全和信息化领导小组

外媒：去年以来，中国成立中央网络安全和信息化领导小组，力度空前，我们感觉中国政府似乎对网络安全更担心、更害怕了，请问这是为什么？

左晓栋：当前，信息技术应用越来越广泛，已经成为经济和社会发展的重要推动力，我们的经济和社会发展都要依赖于网络和信息系统的平稳运行。但是，目前网络安全问题十分突出，影响到了国家安全、经济发展、公众利益和公民权益。因此，中国政府提出了建设网络强国的战略部署，将网络安全提高到了前所未有的重视程度，这是国家安全和长远发展的需要，是全民福祉之所在。

近年来，世界各国特别是发达国家十分重视网络安全，纷纷将其上升为国家战略，这已经成为各国的共同举措。你把各国的共同举措解读为中国政府怕什么，这个角度很奇怪。

自主创新、安全可控不是搞闭关锁国

外媒：很多美国企业都反映，他们在中国的生存环境越来越差，中国的自主创新战略是不是意味着美国企业今后要被排除出中国？

左晓栋：众所周知，中国的信息化发展取得了令人瞩目的成就，这是个双赢的局面。一方面，国外企业为我们带来了先进的技术和产品，促进了信息技术在中国的广泛应用，我们的经济发展受益良多；另一方面，国外企业特别是美国企业在中国获得了巨大的商业利益。我想，这种双赢局面今后还会继续。显然，美国的技术领先于我们，为什么要排除先进的技术呢？而且也要看到，在经济全球化条件下，没有哪个国家有能力把自己封闭起来。美国的信息技术那么发达，然而他也声称自己IT产品的供应链是全球化的。

但是，这并不意味着企业可以自由卖产品而不需承担对消费者的责任。不能一见到政府有要求就提意见，就认为是要赶你走，这不是负责任和成熟企业的做派。

特别是，由于我们的技术基础薄弱，目前在绝大多数重要系统和重要场合，美国企业的产品都占据垄断地位。这造成了我们受制于人的局面。例如，微软公司的Windows XP操作系统停止升级服务后，我们很多政府和行业用户的系统暴露在风险环境中。这意味着一个国家、一个行业可能要看一个国外企业的脸色。难道我们不需要有自己的东西吗？但发展自己的东西，并不是要赶走国外企业，而是要加大自己产品的研发和应用，没有应用怎么能够带动产品的成熟？况且，这中间还离不开更多的国际合作。

受制于人所带来的后果恐怕不仅仅是任人摆布。现在的系统绝大多数在线运行，即使物理隔离的系统也要与外界交互。信息技术的基本原理告诉我们，掌握产品或系统设计细节的企业或机构有能力远程窃取用户的信息，或远程控制、破坏用户的系统。用户是不是有足够的理由去警惕这种事情发生？企业是不是有责任消除用户的疑虑？这应该就是安全可控的实质所在。安全可控的指标可能会有多个方面，但绝不是简单的国产化。我没有听谁说过国外产品就一定不可用，但国外产品在重要系统中使用时，应当做到安全可控，应当对用户是透明的，企业有责任为用户建立信心。国外企业试图规避这些义务、只收钱而不尽责任的时代过去了。

恶意炒作源代码公开是选择性眼盲

外媒：银行业最近发布了两个文件，《关于应用安全可控信息技术加强银行业网络安全和信息化建设的指导意见》和《银行业应用安全可控信息技术推进指南（2014—2015年）》，我们看到文件里要求企业提交源代码，这是否太过分了？

左晓栋：你说的第一个文件我看到过，因为是网上公开的；第二个我没有看到，不知道你是怎么获得文件的。但我可以告诉你关于源代码的国际惯例是什么。《共同准则》（CC）是全球最权威的IT产品安全评估标准，世界主要国家都在使用这个标准。CC的评估结果分为7个级别，即EAL1到EAL7，由低到高。其中，从第4到第7级需要满足一个称为“实现表示（Implementation representation）”的要求，即厂商要把能够代表产品实现细节的证据提交给评估机构，以便于做安全性分析，低级别（第1到第3级）的产品就不用提交了。CC要求，“实现表示”要能够反映产品安全功能的内部工作情况。那么，哪些算是“实现表示”呢？CC指出：这包含软件源代码、固件源代码、硬件图样和IC硬件设计语言代码或布图数据（This may be software source code, firmware source code, hardwarediagrams and/or IC hardware design language code or layout data.）。

这意味着，要求提交高安全级产品的源代码以便于分析其安全性，这是国际标准十几年来的一贯要求，在技术上也很合理，国外也一直是在这样实践，但为什么西方媒体很喜欢针对中国发难呢？我每次把这些基本事实告诉西方媒体和商业代表团后，大家毫无例外都故意遗忘了。也许很多人的兴趣不在于搞清事实，而在于利用公众对知识产权的敏感度炒作话题。

我还想起一件事，有一次某个外企的专家实在抵赖不掉了，就跟我摊牌说：虽然国际标准是有这个要求，但我可以把我的源代码交给美国或我们的盟国，交给中国我们就是不放心。这就是另外性质的问题了。他在政治上有这么强烈的意识形态抵触情绪和冷战思维，我认为也可以敞开谈，但请他不要拿源代码来说事。

恶意炒作政府对网民监控是无中生有

外媒：我们看到，银行的文件要求厂商在设备上安装监控接口，中国政府的反恐法草案也要求厂商在设备上安装监控接口，这是政府要继续实施大规模监控吗？

左晓栋：你拿到了银行的那个文件，而我没有，所以我没看到这个要求。但我肯定的是，这个文件肯定不是关于监控的，更不是监控网民，为什么溺水三千只取一瓢饮？

我不认为银行的文件与你问的问题有直接关系。但针对你关心的监控接口的问题，我也可以从技术角度谈一谈。建议你去看一看欧洲电信标准化协会（ETSI）的合法拦截（LI）系列标准，这些标准指出了厂商在设计通信设备时如何为执法部门留出合法拦截接口，还明确了需要拦截或监听哪些数据，以及拦截或监听到的数据如何传输给执法部门。这在业界也是常识问题。我记得中国通信企业的设备卖到了欧洲后，被欧洲人要求安装上合法拦截接口，这又曾引起西方媒体的极大兴趣，纷纷炒作中国的设备到欧洲去搞监控了，西方媒体总是乐此不疲。

反而是在中国，目前没有这样的标准，我认为应该尽快与国际惯例相靠拢，抓紧明确通信设备厂商对执法部门的责任义务。

现在回到银行的那个文件，虽然我没有看到，但我认为它至少要涉及对金融信息系统运行状态和安全事件的监测设备，这是任何一个信息系统安全防护体系的必然组成部分，但绝非你所理解的对网民进行监控。

外媒：你刚才说的是欧洲的情况，美国有这个监控的要求吗？

左晓栋：建议你去翻一下美国的《通信协助法》（CALEA），其他的请去问斯诺登，你懂的。

外媒：银监会的文件发布后，是使中国网民更加害怕了呢，还是更有利于金融安全？

左晓栋：心中有魔鬼，你就只能看到魔鬼。

西方媒体应该在网络安全中扮演积极意义的角色

外媒：你刚才提到，在线监测是信息系统安全防线的一部分，这个观点是否可以刊登？

左晓栋：我所有谈到的都可以登出来。我希望能够保持真实、客观、全面，这是底线。不能为了迎合一些集团或者势力的口味，丧失掉这个底线。这固然可以一时博得眼球，但却难以长久。

建议西方媒体在网络安全中更多扮演积极意义的角色。我举个例子，美国有那么多信息安全院校，通过政府奖学金大力支持信息安全人才效力于政府，还举办了那么多黑客竞赛，但为什么我们某个学校成立一个信息安全学院，就引起了西方媒体的莫名惊诧呢？难道只允许西方国家成立网络战部队搞攻击，不允许我们培养信息安全人才做防护，天下岂有这样的道理！
