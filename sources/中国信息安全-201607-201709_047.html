十年创宇

有用更要有趣，这是KCon 六年来一直不变的宗旨。8月26日，KCon 黑客大会2017在北京中关村时尚产业创新园召开，本届KCon 主题为“洞见未来”。从一个咖啡馆起步，大会已经发展成一个业内知名的技术大会，孜孜追求高质量的议题和有趣的环节。

作为一个业界知名“老黑客”，知道创宇CEO赵伟在开场致辞中表示， KCon 连年举办，在技术圈里打造了自己的知名口碑，主要就是两点：一个是干货，议题质量一定要好，另外一个就是有趣，要打造属于自己的而又能让参会者喜欢的风格。

本届KCon恰逢知道创宇成立十周年，赵伟明显感慨颇深。他表示，自从踏上了这条网络安全的道路，从原来只是为了企业的生存，到后来思考对个人、公司、国家的责任，这十年的路走的非常不易。创宇十周年，对他来说印象最深的一是成立了产业界的安全联盟，定义了相关标准，推动数据共享，为产业和网民做了实实在在的安全服务；第二是促进了白帽子社区的发展，打造了ZoomEye网络空间搜索引擎，Seebug 漏洞平台，以及今天的KCon黑客大会，为白帽子的成长做出了看得到摸得着的贡献；三是成功推出了SaaS模式的安全服务，如创宇盾、加速乐、抗D保三位一体的安全服务，捍卫着国内众多中小网站的安全。

赵伟表示，未来知道创宇会继续坚持创新、务实的态度，面向实战市场，解决刚性需求，在反欺诈、云防御、态势感知等产品层面继续发力，打造产业生态，共同把网络安全事业做大做强。

干货议题概要

作为广受技术爱好者们的纯技术会议，今年KCon共汇聚了18个前沿且有趣的议题，各路大咖轮番登场，展现了白帽们的智慧和极客精神。

《争夺保护内存之战——使用高级纯数据利用技术攻击只读内存》

迈克菲 IPS 安全研究团队的孙冰和徐崇首先登场，给观众带来《争夺保护内存之战》议题。该议题作为高级纯数据攻击的尾篇，其中前两部分分别在 Black hat 2017亚洲黑帽大会、Hack in the Box 2017荷兰站当中做过分享，而尾篇则带到了 KCon 2017。

微软在Windows 10和8.1 Update 3上默认启用了一个新的漏洞利用缓解——CFG（控制流保护），经过持续的修补后，过往常见CFG绕过方法变得非常困难，孙冰发现，将现有纯数据攻击和其它技术如竞争条件、异常注入想结合，可继续绕过CFG防护，称之为高级纯数据攻击。现场演示中，孙冰和徐崇通过抢占同步锁解锁 ntdll.dll 的只读区段和使用异常注入技术解锁 ntdll.dll 和 eShims.dll 的只读区段两种方式，并修改其中的某些关键数据来实现绕过 CFG ，并给出了防御针对保护内存的攻击的实用建议。

《攻击欺骗的虚实之道》

锦行科技的胡鹏带来了今年国际上非常流行的攻击欺骗议题。攻击欺骗是一整套能够诱骗攻击者触碰、进入、并利用的系统，是以攻击者视角构建的陷阱。目前国内攻击欺骗的主流是隔离，把攻击者从真实的业务环境隔离到欺骗环境中。而在胡鹏看来，隔离是为了更加的安全，而“开放”是为了更好的诱骗，欺骗系统与真实系统的虚实融合，将攻击者诱骗于无形之中。

虚实运用要符合真实业务场景，关键在于环境的可利用性、数据的真实性以及行为监控隐蔽性。每一个步骤、环节都可以是一个小小的诱骗元素，而正是利用这些小元素却能够组合出千变万化的诱骗网络，攻击者一旦踏入就很难抗拒种种诱惑，一步一步深入我们精心为其准备的陷阱中。

《从三星支付底层实现看移动支付安全体系设计》

移动支付的迅猛发展正在给各行各业带来全新的机遇与挑战，如何让用户在享受移动支付便捷性的同时，确保其财产安全不受损害，成为了亟需解决的问题。腾讯玄武实验室安全研究员——Hyperchem（马卓）带来关于移动支付安全体系设计的研究成果分享。他以三星支付为例，剖析目前手机厂商在底层安全技术的实践及应用，并阐明其在应用层、内核态、 trustzone 等各个层次对其支付系统的安全防御手段。在展示手机移动支付的完整技术图景的同时，马卓还对目前移动支付所采用的安全技术进行系统介绍，详细揭示了移动支付开发商在支付各个环节进行的安全防护手段。

《unix 世界中的另一面》

安洵信息黑洞实验室的安全研究员吉芸辉分享了关于 Rootkit技术剖析的议题。Rootkit 作为攻击过程中权限维持最重要的一个工具，对系统安全防护的重要意义不言而喻。Unix-Like 种类众多，而 Rootkit 随着系统的不断迭代升级也在不断进化。针对 Rootkit 的不同种类，吉芸辉通过一些实际工具和代码与参会者探讨其实现方案和技术特征。随着开放的 unix 世界不断升级，功能愈加丰富多变，攻击方式也会不断升级变多。针对 Rootkit 原理和特性的研究，能更好了解攻与防。

《智能门锁的“天灾人祸”》

启明星辰 ADlab 安全研究员（ID：蝴蝶）给大家带来了《智能门锁的“天灾人祸”》议题。蝴蝶在议题分享中归纳了蓝牙智能锁存在的攻击面，如 APP 存在的攻击面、蓝牙协议攻击面，当然还有固件的安全性问题。最后蝴蝶分享了三同智能门锁的黑入分析，最后还给出了安全建议。其实所谓“天灾人祸”，人的部分仍然占具更多成分，也希望设备厂商能在今后的硬件生产中多考虑安全性问题。

《重现速8僵尸车队》

微步在线资深安全研究员——杨晋的演讲题目为《重现速8僵尸车队》，主要探讨蓝牙4.0 BLE 协议的进攻研究。议题围绕对使用BLE协议的设备的定位，多种嗅探方法，协议分析和攻击等方面来展开。最后在现场还给出了攻击BLE智能小车的案例，模拟出电影速度与激情8里面那个僵尸车队的情景。

《Android 驱动漏洞挖掘之旅》

360安全研究员杨文林带来了Android 驱动漏洞挖掘的研究成果，杨文林表示，Android 驱动漏洞在2014年还仅占整体的4%，到了2016年驱动漏洞已经上升到了44%，内核驱动漏洞已成为移动安全致命伤。杨文林为大家总结了内核驱动的各类交互流程，并且分享了大量的驱动漏洞挖掘实例，以助于高效地去发现驱动漏洞。

《 Web 日志大数据安全分析实战》

前百度安全应急响应中心负责人，墨攻安全团队成员高渐离带来《 Web 日志大数据安全分析实战》议题。该议题分享全程注重“实战”，面向的全部是来自于现实当中我们所处的困境。高渐离在演讲中指出，在现有的安全建设情况下，数据分析需要根据现有的实际情况来进行分析。包括结合现有的安全系统，进行定制化的数据采集。在海量攻击的情况下，通过后移关注角度，从 Pre-breach / Breach 的视角转向 Breach / Post-breach 的视角，并针对具体的攻击方式设计检测方案，可以大大提高检测有效性。

《玩转无人机攻防》

独立安全分析师Kevin2600 分享了数个无人机攻击案例，配有直观视频展现，并对攻击方法进行了简要概述。在更为详细的无人机攻防实战部分，Kevin 给出了适宜逆向入门的 CX-10 的包含干扰、逆向、刷固等多种攻进实战讲解。Kevin 在议题分享最后总结到，100%安全的系统并不存在，无人机安全研究与其他嵌入式无线产品大同小异，无人设备与人工智能相结合是未来趋势。

《授人以鱼不如授人以渔 教你如何写一个自己的私有越狱》

阿里巴巴安全专家蒸米介绍了如何打破 iOS 系统的缓解机制并实现一个私有的 iOS 越狱。在这个私有越狱中利用了不同类型的漏洞，绕过了 iOS 几乎所有的安全机制：通过 NSXPC 实现沙盒逃脱，通过 neagent 和 mach port 绕过 Team ID 和 Entitlement 检测，通过 IOHIDFamily 攻击内核，并最终破解内核堆的缓解机制以及 KPP。蒸米希望能够对感兴趣的人有所帮助，并早日写出自己的 iOS 私有越狱。

《探索虚拟化技术在漏洞检测中的应用》

漏洞安全研究员仙果介绍了建立在硬件虚拟化技术上，并使用这种攻防对抗的技术来检测漏洞的方法。具体有以下几点：1.使用 VT 对抗反虚拟机技术；2.EPT 技术打开了一个新的大门，在传统的系统中，内存要想执行，就必须具备可执行+可读的权限，EPT 的出现，可以把执行属性和可读属性区分开来。指令跟踪技术通过 MTF，EPT 等各种手法可以做到指令跟踪（包括内核指令）。从程序执行指令流来检测漏洞；3. 还可以用来跟踪 shellcode 执行流；4. 模拟器具备更灵活的检测思路，例如利用模拟器来 FUZZ，可以检测内核信息泄漏之类的漏洞。

《暗云Ⅲ——史上最复杂木马的探索之旅》

腾讯安全反病毒实验室耿深介绍，“暗云”是史上最复杂的木马之一，感染了数以百万的计算机。“暗云”木马并没有具体的文件形态，它潜伏于用户电脑的磁盘引导区内，通过云端数据下载病毒代码向电脑发起攻击，并可破坏杀毒软件功能，即便用户格式化硬盘也难以清除。耿深对“暗云Ⅲ”做了全面的技术分析，让听众一探究竟。

此外，会议还分享了伪基站升级、浏览器漏洞挖掘、反无人机系统、bootloader安全、Powershell 攻击等干货，两天的技术盛宴，让与会者大呼不虚此行。
