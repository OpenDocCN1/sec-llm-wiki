# 关注 | CSS2017：聚焦新秩序下的安全之道

■ 本刊记者 方言

 8月15日，第三届中国互联网安全领袖峰会（Cyber Security Summit 2017，简称“CSS2017”）在北京国家会议中心正式举行。本次峰会由腾讯公司、中国电子技术标准化研究院等企事业单位共同举办，得到了国家网信办、工信部、公安部等国家部门大力支持和指导。

![](../Images/308a5d015e7feb5c5a5298dff2121b60.png)

**▲大会现场**

作为CSS安全峰会的主办方，腾讯携手500多家企业以及“世界头号传奇黑客”Kevin Mitnick、卡巴斯基实验室安全专家Vladimir Dashchenko、腾讯安全玄武实验室负责人“TK教主”于旸等众多全球顶尖安全专家，围绕“安全新秩序，连接新机遇”主题，共同探讨全球网络安全最新发展趋势，分享时下前沿安全技术与研究成果，为中国互联网安全产业格局和发展机遇进行全面解读把脉，为产业的“数字经济”转型献策。产业协同合力成为共识

当天上午的大会由财讯传媒集团首席战略官段永朝主持。中央网信办网络安全协调局副局长高林、腾讯首席运营官任宇昕、中国电子技术标准化研究院院长赵波、中国互联网协会秘书长卢卫、Visa公司副董事长兼首席风险官Ellen Richey做了主题发言。

![](../Images/65c22359ff35a1cb67e0c73813f7825e.png)

**▲中央网信办网络安全协调局副局长高林**

中央网信办网络安全协调局副局长高林在发言中表示，网络安全已经成为影响经济社会发展、国家长治久安和人民群众利益福祉的重大战略问题。维护好网络安全，才能夯实数字经济的基石。贯彻实施网络安全法是当今和今后网络安全工作的重要任务，也是推动数字经济发展的重要手段。为此他提出三点意见，一是要深入开展网络安全宣传教育活动，增强全民网络安全意识；二要充分发挥各方面作用，形成宣贯落实网络安全法的强大合力；三要积极参与网络安全相关工作，切实将网络安全法落实到位。

腾讯首席运营官任宇昕认为，信息安全已经成为数字经济发展的神经系统。新形势下，信息安全已发生结构性改变，其责任主体从单纯的政府及专业安全公司转变为所有参与数字经济的企业；信息安全公司也将由独立的第三方产业转为深度融入数字经济领域，成为数字经济的神经系统；行业合作机制也面临改变，技术共享、全球协同将成为新时期信息安全保障机制的重要基础，人才、技术、体系都将不再孤立存在。

![](../Images/35fc6933535fb8152b17f8a59d681155.png)

▲**腾讯首席运营官任宇昕**

任宇昕指出，应该从社会安全意识、应急响应机制、基础建设投入、法治保障体系四个层面入手，构建保障数字经济发展的四条“中枢神经”：第一，社会安全意识需要转变，安全问题前置、安全已成为业务流程重要组成；第二，建立协同应急响应机制，人才、技术、数据全面共享，释放安全“势能”；第三，加大安全基础建设投入；第四，提升安全法治保障体系。

任宇昕表示，腾讯非常重视信息安全建设，将持续加大在人才、技术、数据方面的能力建设和开放，积极倡导安全新生态。信息安全发展需要全产业联动，开放、共享、合作，已经成为数字经济时代信息安全产业共识。作为数字经济的重要参与单位，腾讯呼吁有能力、有担当的企业积极承担责任，积极参与信息安全这一“神经系统”的构建。腾讯将在开放合作、技术创新和产业融合三方面将不断发力，为推动建立全产业联动的安全生态新体系做出切实努力。

![](../Images/dfc44b1a6bbcee09132775cd8b694082.png)

▲**Visa公司副董事长兼首席风险官Ellen Richey**

作为金融领域的安全专家，Visa公司副董事长兼首席风险官Ellen Richey总结了金融体系欺诈防护的四点经验，她认为，第一，不会有一个放之四海而皆准的方法，需要多管齐下。在整个系统生态当中，需要各方协同合作，这样才能够避免网络袭击。第二，在这样的生态系统当中，不可能万无一失，因为系统有太多的薄弱点、太多的漏洞，犯罪分子总是能够找到一个薄弱点。所以我们要做的就是减少对他们有价值的这些数据，例如对数据进行脱敏、令牌化等。第三，我们的数据可能会受到攻击和盗窃，但是数据也是我们的解决方案，要利用数据为我们服务。第四，在整个生态体系中，我们是一个互联的世界，人和设备都是互联的，大家都要彼此协作，这是保护我们的关键。

新秩序下的安全之道

数字经济时代，如何在实现自身发展的同时维护好网络安全，成为传统行业和互联网行业面临的共同挑战。在上午的圆桌论坛环节，腾讯副总裁丁珂、Visa副董事长兼首席风险官 Ellen Richey、中国联通信息化部总经理孙世臻、国家电网公司信息通信部主任王继业、中国信息安全测评中心总工程师王军五位嘉宾聚焦新环境下互联网安全面临的挑战与机遇，深入探讨了传统行业与互联网行业在新秩序下的安全之道。

![](../Images/ba3877941553c28a4de64f37679df8b9.png)

**▲圆桌论坛环节**

6月1日《网络安全法》的落地实施，意味着数字经济将步入有法可依的新秩序阶段，企业需要更好贯彻《网络安全法》。与会嘉宾一致认为，新秩序下的互联网企业面临巨大挑战，同时也迎来了前所未有的机遇。

丁珂指出，新秩序下，网络安全、信息安全领域主要面临三个方面的挑战和威胁。第一，用户的隐私保护正式提上议程，打击个人信息泄露犯罪有法可依；第二，企业责任更加明确，每个企业都有明确的责任来保护用户的财产和隐私安全；第三，在有法可依和制度保障上，《网络安全法》会为行业合作提供指导性意义，随着全行业对网络安全的重视程度提高，对网络安全的投入力度加大，将催生更大空间的网络安全市场和更多合作可能。

![](../Images/e944f0f824eda9929e1f686ba31b2cad.png)

**▲腾讯副总裁丁珂**

面对新秩序下的新挑战，丁珂表示对腾讯而言，安全不仅是腾讯公司的核心战略，更是践行社会责任的重要体现，腾讯在人才培养、整体安全防护体系构建和大数据、核心技术开放共享三个层面持续发力。在安全人才培养方面，腾讯安全发起并举办了腾讯信息安全争霸赛(TCTF)，由腾讯安全联合实验室7大掌门人和国内数十位资深网络安全老师组成的明星导师团，为通过比赛选拔的学生进行指导，并将优秀选手输送到国际赛场，以赛代练，促进实战人才的培养，建立了信息安全专业人才培养的闭环。

在安全防护体系构建方面，腾讯安全打造了腾讯安全联合实验室、腾讯安全云库、腾讯手机管家、腾讯电脑管家、腾讯WiFi管家、腾讯守护者计划在内的强大安全矩阵，对电信网络诈骗、木马病毒攻击等安全威胁实现了全方位、多场景防御和遏制。2016年7月，腾讯成立了腾讯安全联合实验室，并推出鹰眼、麒麟系统，腾讯联合公安、银行、运营商等各方推出共同打造的“守护者计划”。

随着技术的演进，这两年针对电信基础运营商的网络攻击正在变化和升级，尤其在黑色产业链利益的驱使下，利用网络漏洞或信息泄漏的攻击数量在不断上升。中国联通信息化部总经理孙世臻表示，联通在应对这些攻击时除了做好跟踪预警、完善防护手段、建立比较完善的应急处理机制和体系之外，也积极与腾讯等互联网安全企业紧密合作，借助业内最新的安全成果，不断的丰富和完善自身的防护手段和防护能力。

作为关系到国计民生的国家电网，如何保障自身的体系安全，国家电网公司信息通信部主任王继业对此表示，和互联网安全最大的不同，电力监控系统如果发生网络安全问题，有可能引发大面积的停电事故，对于现代社会来讲这是不可忍受的。虽然电力系统实行了物理隔离，但也不是万能的。所以我们在网络安全防护中，第一注重体系的防护，即从技术体系上、架构上进行防范；第二强化管理，因为任何物理系统都是由人来控制的；第三是技术防护，从技术上建立一整套完整的防御体系，包括技术监测体系、及时的感知系统，出现问题及时隔离、及时消除故障。

![](../Images/ca7d93950baa48c6f92771d30de54a38.png)

**▲中国信息安全测评中心总工程师王军**

中国信息安全测评中心总工程师王军强调了保护好关键信息基础设施的重要性。他认为，除了过去的一些能源、电力、通讯、电信、金融等传统行业，现在包括一些大型互联网企业都已经进入了关键信息基础设施的范畴。而所面临的威胁，随着新技术新应用的发展，又在不断更新变化，压力也在增大。例如当前快速发展的物联网里包含的很重要的一个领域就是工控系统，但工控安全问题存在已久，现在还没有得到解决，又有了云计算、大数据这些技术领域带来的新的安全问题。所以目前我们还是在一个边发展、边解决的状态。

在圆桌论坛结束之际，主持人、财经传媒集团首席战略官段永朝总结称，在当前的安全形势下，普通消费者要时刻保持警惕性，提高安全意识，同时还要有提升公共安全和他人安全的精神；对企业而言，要把客户数据的安全当成资产一样来保护；此外，监管机构、政府机构需要扮演一个先导作用，搭建更好的平台促进网络安全新生态的构建。

据了解，除了8月15日上午的圆桌论坛之外，CSS2017还将围绕金融安全、大数据及云安全、人工智能与安全伦理、安全法治治理、基础设施安全、智能硬件与物联网安全、网络空间威胁态势感知、网络安全标准化等多维度议题组织专题论坛，与业界共同探讨全新环境和形势下网络安全的新秩序构建、安全连接数字经济的新发展机遇。
