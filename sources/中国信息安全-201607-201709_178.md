# 数博会｜中国信息安全测评中心总工王军:用大数据来保障数据安全

万物互联时代，大数据规模空前，数据流动更加频繁，安全问题日益凸显，如何防范大数据安全成为当下面临的重要问题。“要处理好安全和发展的关系，设法能够安全地使用大数据，应该从大数据本身的安全、用大数据来解决安全问题两方面来探讨。”中国信息安全测评中心总工程师王军说。

2017数博会召开之际，人民网记者就大数据安全及网络安全问题采访了中国信息安全测评中心总工程师王军。王军介绍，一般而言，病毒入侵的系统并不太区分到底是终端还是某个特定的设备，主要是看它有没有感染的条件。所以任何使用移动互联网的用户都应该具有相应的安全意识，比如自己个人的信息安全，要充分使用或者利用法律给予我们的隐私保护权利。对于当前勒索病毒的威胁，这也是对网络安全的一个警示——数据安全防控的形式依旧迫于眉睫。

“在从事网络安全相应工作的人士来看，通常没有靠单一的技术来解决网络安全面临的问题，通常来讲要是要一个系统性的解决方案。”王军表示，当大量数据聚集在一起的时候，我们通常把它的敏感属性或者敏感成份淡化甚至去掉的过程，造成数据有一些统计性的规律或者统计性的信息可以用，但是有一定的缺点就是没办法对其进行恢复，这就是所谓脱敏。

王军有着多年的云计算安全、大数据安全等研究的经验，他认为，技术性的问题往往是此消彼涨的过程，现有的技术手段不一定能能够管用，或者未来有一些新的技术出现，使你感觉现在比较保险的保护方法也许不够保险、不太安全。但目前没有百分之百可以解决这个问题的技术，但是可以不断去完善、不断去发展。

目前而言，多数人所关心是解决大数据在应用过程当中出现的公民的个人信息、个人隐私、相关机构的商业机密等问题；而大数据的一些工作平台、处理的平台自身也有很多的安全性问题，有些和传统的安全问题是一致的，有些是在大数据的情况下所新产生的。在当前经济新常态下，大数据的发展为经济的发展带来了动力，同时要保证数据安全不能只依靠数据本身的防范，还将依赖于大数据技术手段。
