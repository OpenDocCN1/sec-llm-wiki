# 产业观察｜从新华三安全策略看安全转型发展

*   本刊记者 崔光耀
    

在安全与发展密切关联、安全与网络日益融合的大背景下，新华三集团和亚信（包括互联网巨头）在安全领域的接连发力，印证着行业变迁的一个显著趋势。云化、场景化、虚拟化、可视化、智能化，大数据爆炸，应用环境的复杂和开放的供应链等，都对传统安全的边界防护理念和基于路径防护的传统方式提出重大挑战，正在深入地影响和撬动网络安全的发展格局。

人们曾经预测，安全市场达到一定成熟度的时候，会向两到三家专业安全厂商集中，出现整合市场的旗舰企业品牌，但这一假想一直没有出现。安全之意不在安全之中而在安全之外,倒是互联网安全和IT安全逐步渗透加量。纵观阿里安全、腾讯安全、百度安全，以及360、新华三集团和亚信安全的高调动作，这种感觉就会更为强烈。未来哪种模式会成为安全的主流，谁来主导行业的走向，是各方面都在关切和思考的现实问题。

**新华三安全超出预期**

去年五月，新华三集团正式成立，并在不久之后宣布组建大安全、云计算、大数据三大产品线。这引起业内外的高度关注，大家张目以望，揣摸预估其安全市场策略选择及效果如何。

在新华三集团以“新IT新经济”为主题的NAVIGATE 2017领航者峰会举办前夕，新华三集团副总裁、安全产品线总裁张力给出了一份分量不轻的周年成绩单。

![](../Images/50d6d22a3327c77414c6c46476fbccf8.png)

从业绩看，新华三大安全业务在2016年取得大幅提升，特别是在云计算和网络两大主业的带领下云安全增速尤为明显；其二是高端防火墙的运营商集采当中也是位居一二，强势入围；其三是在完成了国有身份转变之后，新华三大安全已经并将继续进入更多的领域。

从体系结构看，集团聚焦四大战略方向，即“三大一云”——云计算、大数据、大互联和大安全，目标是成为新IT时代的基础架构领导者。为此谋划在成都、郑州、合肥成立三个全资子公司，对应着集团的云计算、大数据和信息安全三大业务。其中合肥信息安全公司主要从事云计算、大数据、工业、网络等核心领域的安全技术研发与产品销售，以打造新华三集团大安全产品及解决方案的全球研发及销售中心，将组建上千人的研究团队，成立4个联合实验室，此外新华三还先后成立了信息安全学院、信息安全研究院，立体布局。

从产品形态看，在安全方面新华三产品涉及网络安全、云安全、移动IT安全以及大数据安全、工业控制信息安全等产品方案与服务，还将向可信计算、物联安全等方面延伸。今年2月，新华三成为国内唯一一家获得公安部信息安全等级保护安全建设服务机构能力评估合格证书的综合类网络安全厂商。被称为业界绝对领先的云安全解决方案2.0版本已经发布，在刚刚举行的领航者峰会上，又发布了华三天机3.0版本，其企业级安全产品和解决方案已占据领先优势。

从投入和预期上看，新华三对整个安全研发的投入大幅度增长，对于安全市场寄予很高的期望，提出公司的信息安全战略要匹配国家信息安全战略，做践行国家网络安全战略的先行者和表率者。

张力表示，紫光集团一个重大战略叫“从芯到云”，芯片部分由紫光展锐集团实现，云计算部分包括云应用的整个解决方案，则落在了新华三。云计算本来就是公司最核心的部分，新华三能够在激烈的竞争中保持高速增长，其中很大一个原因是因为云计算方案一直保持领先位置，也给安全留出了巨大空间。政务云将成为新华三下一阶段的龙头。新华三所进行的服务链、安全资源池化等技术创新与突破，都是为了应对云计算环境的特殊需求。目前新华三已承接了18个省级政务云。

**新环境变化重构安全生态**

时值今日，安全生态环境已经发生重大变化，顺应这种变化才能立于不败之地。

张力指出，互联网应用的普及致使网络流量呈指数增长，对带宽的要求越来越高，面对大流量转发技术，传统安全设备厂家越来越力不从心，而新华三软硬件结合的优势则将进一步彰显。新华三提出“三大一云”的概念（大互联、大安全、大数据和云计算），这个大，首先表现在涵盖领域的大和全，在国内厂商里面至少是第一梯队的，因为跟着网络一起走，几乎涉及国内四百多个行业。所谓的大安全，也是指能够跟云计算、网络、大数据等最各类应用场景相匹配，能够做到一体化融合，并能保持功能覆盖、高性能等技术的领先性。在网络安全方面，新华三最具竞争力的优势在于，拥有十多年的网络技术积累，对网络结构、IT流程和用户需求都有明晰深入的了解与把握，在网设备达数千万台（安全设备也超过数百万台），可以轻松实现云、网、安三个领域的无缝衔接，这对于安全信息收集和威胁分析有着极大帮助。新华三的安全产品与方案不仅仅能够跟本公司的云网融合，更重要的是理解客户在这种环境下对安全的不同需求，而这正是新华三未来在这个市场上会有越来越具竞争优势的一个重要原因。

可以看到，过去集成商、代理商跟传统安全厂家合作比较多，云计算、大数据兴起以后，一些走在前沿的集成商开始重新梳理在安全方面的合作伙伴，更愿意跟新华三进行合作。因为传统的安全厂商自己不做云计算，也不做大数据，意味着对新兴市场需求理解不透，或者至少对其安全需求的理解不深刻。其安全和方案无法跟用户的云平台和管理系统有效结合，对网络层很多的隧道协议也存在不支持或支持的性能低的问题。另一方面,从态势感知和处置响应角度看，它要求搜集到尽可能多的信息来源，分析才会更准确，即所谓“大数据是要养的，人工智能是要拿数据去喂它”。新华三自已拥有海量的网络设备，再加上跟亚信这样的合作伙伴联合，搜集信息的丰富度就要远远胜出业内其它厂家。安全边界的改变，导致安全能力本身也正在变成一种虚拟化的能力或虚拟化的服务，使得安全资源能够自动进行迁移和配制，融合到整个平台里面，这也正是考验公司整体实力的最佳舞台。

张力说，新华三会更多地跟一些主流厂家进行合作，包括纯粹做安全的厂家，因为毕竟各自侧重面不一样。新华三意在构建一个全局的大安全生态圈，未来会有很多超出传统意义上的安全产品，这需要新华三练好自己的内功，不断提升整体能力，以适应数字化时代的更高要求。

**产业融合转型适者生存**

霍布斯鲍恩在《革命的时代》中写道，“产业革命是既无开头也无结尾的乐章，它仍在奏响”。今天技术进步的摩尔定律不断地被打破，产业革命的变化也如影形随变化越来越快。近年来云计算、大数据、人工智能、物联网等颠覆性技术的快速发展和应用，对安全产业的生态产生了重要影响，一些过去的模式和思路自然面临着调整和改变。

其实安全产业的这些变化一直在进行，只是近来节奏更快加了。大概十年前，几乎所有主流的传统安全企业为了抢占市场纷纷扩充产品线，推出完整的安全解决方案。产品线全了，产品的功能也需要整合，UTM又开始兴起。这样还不够，接着又出现一些企业的整合，比如从卫士通与东方龙马缔结联盟到启明星辰对网御星云的收购等等。这些都做完了，市场规模还是没上去，那就再到资本市场去闯一闯。卫士通、启明星辰等先后上市了，飞天诚信还一度冲到了A股的榜首，仅去年一年就有十六家安全公司在新三版上市，而悲情如最早投身其中的天融信公司最后也还是壮志未酬，终被南洋股份兼并。这些年安全产业分分合合，不可谓不拼，劲没有少使，办法不可谓不多，爱恨交织，无以复加！但是，安全市场依然波澜不惊，突破不大。不仅国内企业，一些在华的安全外企也在进行着各种尝试，思科就不用说了，那个美国网络公司Juniper在2004曾经也花费40多亿美元巨资收购了高端市场领先的防火墙厂商NetScreen，添加了系列网络安全产品，甚至可以说在SSL VPN市场取得了全球领导地位，但这些年传闻他们意在出售NetScreen业务。加上安全产业特殊的政策限制，早先前来赶场的众多外企已经大势不再。

这个时候，变化悄然而至，在很多人尚未敏感地细察秋毫之际，互联网模式杀了进来，其代表是360公司开启的杀毒市场免费模式，这对众杀毒企业几乎是一刀毙命。接着发生的3Q大战，客观上还倒逼着互联网巨头们在安全上真正发力。

**网络安全的不死鸟和领头羊**

和新华三有着密切合作的亚信安全，按田溯宁的说法也曾走过一条特殊的道路，十多年前他们涉足联想网御也未能达到预期的目的，而去年对趋势中国的收购与紫光持股51%新华三集团股权，结果却迥然而异。收购以后两家公司安全市场的增幅均达到了百分之五六十，预计今年增幅会更大。两家公司共同的地方很多，都曾在IT领域有着厚积之力，软硬件和网络建设也都深有所长，各自主办的领航者峰会和C3安全峰会不论规模和影响也都势大力沉，非同凡响。赶上国家网络强国建设这一波利好大潮，优势将充分发挥，因而被称为安全领域的两大黑马。时过境迁，情势改变，结果当然不一样。包括东软刘积仁早在二十年前就投资东软网络安全等，不可谓没有战略前瞻和技术洞察力，但这种前瞻和洞察还是需要和外部条件相匹配才能发挥效用，近年来东软潜心云安全，着力车联网，与公司技术积淀和行业应用趋于一致，效果也已显现。

客观地说，许多传统安全厂商的创业者和团队，这么些年来持之以恒地以一种特殊的情怀坚守网络和信息安全的前沿阵地，克服各种困难，在保卫国家安全，发展安全技术，做大安全市场，培育安全人才等方面做了大量开创性的工作，值得尊重和称道。这些安全厂商有着深厚的技术积累和专业特长，新的形势下如何发挥这种优势，调整公司战略，还是有着巨大的发展空间：或者提供专业的安全服务，或者提供专业的安全设备，或者进行针对性的创新开发和定制服务，或者选择与网络巨头合作，以适应形势需要。去年总书记亲临安全公司考察，即是对这些专业安全厂商的极大褒奖和鼓励，并把安天这样的民营企业纳入国家队大盘之中考量，意义尤其深远。

如今人们普遍看好国家网络安全的大势和市场，各方面的市场预期也都很高。过去IDC预测网络安全市场常常存在偏差盖因火候未到，今天安全市场的发展已不只是一种期待而是一种现实。对于未来，不论是传统安全厂商也好，新兴安全厂商也好，互联网和IT厂商也罢，应当明白这样一个市场道理，你要是不变，人家就会来变你；你要是不革命，就有人来革你的命。

那么，谁会成为不死鸟，谁会成为领头羊，形势会逐渐清晰起来。
