# 资讯｜第十六次计算机和移动终端病毒疫情调查活动在京启动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=2664108410&idx=2&sn=8197fab21389f4e0087d0d5b76eadbd7&chksm=8b5e1383bc299a9569eff21f40e5c72371465599bdc99051935f1f6298fedfbf7b7c7678ac29&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664108410&idx=2&sn=8197fab21389f4e0087d0d5b76eadbd7&chksm=8b5e1383bc299a9569eff21f40e5c72371465599bdc99051935f1f6298fedfbf7b7c7678ac29&scene=27#wechat_redirect)

为进一步宣传、普及信息网络安全知识，提高广大用户网络安全防范意识，同时给国家有关部门制定网络安全及计算机病毒防治策略提供准确参考，在公安部网络安全保卫局的指导下，3月17日，第十六次计算机和移动终端病毒疫情调查活动在北京正式启动，公安部网络安全保卫局郭启全总工程师在启动会上做出重要指示，国家计算机病毒应急处理中心张建成主任进行了工作部署，部分省市公安网安部门和以亚信安全为代表的国内外52家防病毒企业的负责人参会。

![](../Images/5984c1c4ab5d0eecb2ea7addc020045f.png)

▲第十六次计算机和移动终端病毒疫情调查活动在北京正式启动

 

在启动会上，张建成主任表示：“本届计算机和移动终端病毒疫情调查活动，旨在全面掌握我国信息网络安全总体状况，系统分析、查找我国信息网络安全存在的突出问题，研究制定切实可行的打防管控措施，为国家制定网络安全法律法规及计算机病毒防治策略提供准确参考。同时更好地收集网民关心的安全问题，受影响情况，继而制定出符合安全上网需要的、切实可行的打防管控措施，健全和完善网络安全事件预警机制，切实推进平安网络建设。”

![](../Images/4dc16158246c111f68e475c3c69a1a32.png)

▲国家计算机病毒应急处理中心张建成主任

  

作为本次调查活动的协办单位，亚信安全将从网络安全厂商角度为调查提供专业能力支撑，亚信安全副总裁刘东红在致辞时表示：“网络安全已经不再是平面的概念，而是涵盖整个网络空间的安全保障，因此此次调查将会增强对安全情势的全方位感知。为了应对越来越‘聪明’的病毒威胁，亚信安全已将AI技术引入到反病毒工作中，结合大数据、智能算法和专业的风险分析平台对威胁情势进行判断，积极履行企业责任。”

![](../Images/2c09df0a141bcba4a409810d59b68ec1.png)

▲亚信安全副总裁刘东红  

  

最后，郭启全总工程师作出工作指示：“习总书记对网络安全提出重要要求，2017年国家举办的五大活动同样要求我们加大对网安保卫的重视。面对复杂多变的互联网安全环境，要通过全民参与共同构筑网络安全防线，提高网网络安全态势的感知能力和网络安全事件的处置能力，增强网络安全防御能力和威慑能力，营造风清气正的网络空间这四个方面来全面开展，以维护网络安全、规范网络秩序、净化网络环境。”

![](../Images/589e8b3ece3938bdb9e0d3ba99d3bcf8.png)

▲公安部网络安全保卫局郭启全总工程师

  

“第十六次计算机和移动终端病毒疫情调查活动”由国家计算机病毒应急处理中心主办，亚信安全协办，多家信息安全企业共同参与活动并提供支持，于2017年3月17日至2017年4月17日在全国范围内开展。此次调查活动分为正式启动、广泛开展及权威发布三个阶段，采用了线上线下同步发布的方式，不仅在权威媒体、门户网站、各支持单位网站上开展网络调研，通过摸排、走访的方式对关键基础设施和重要信息系统的安全状况进行调查。

同时选取具有代表性的城市，与合作高校、网络安全企业配合进行线下调研，对重点地区、重点行业、重点领域的安全问题进行实地走访。还会与亚信安全2017上半年度市场活动进行联动，针对参会的政企专业用户、安全市场渠道厂商代表进行深入调查。调查范围为全国企业及个人用户在使用联网设备过程中的网络安全状况，包括计算机设备、智能设备、移动设备以及网络支付等联网应用安全情况。

本次调查活动将在问卷网开设调查专题（https://vip.wenjuan.com/s/RjuMbq）。调查结束后，国家计算机病毒应急处理中心将适时面向社会公布调查结果，并会在今年7月在成都举办的C3安全峰会2017 暨中国云安全峰会、国际反病毒大会和行业知名度较高的专业会议及论坛上进行重要发布。欢迎广大互联网用户参加调查，详情请登录国家计算机病毒应急处理中心（www.cverc.org.cn）网站查看。
