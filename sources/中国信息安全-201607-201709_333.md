# 铁三赛｜信息安全人才培养：电子科技大学与亚信安全联合出击

信息安全铁人三项赛是由中国信息产业商会信息安全产业分会主办，教育部高等学校信息安全专业教学指导委员会协办，中国信息产业商会信息安全产业分会人才建设专业委员会和北京西普阳光教育科技股份有限公司承办的面向大学生以典型实际应用环境为背景的公益性实战技能大赛。大赛分“数据分析赛”、“企业环境赛”“个人环境赛”三项赛事，并由参赛校企组成联合战队参赛，通过信息安全铁人三项赛训练营，实现校企的深度融合。

信息安全铁人三项赛训练营是结队校企建立深度合作关系的桥梁，通过开展铁三训练营活动，对于高校而言，在将企业的优势技能转化为课程资源的同时，还丰富了课程体系，提高了学生的实用技能。对企业来说，通过本次训练营既能深入接触并了解学生，还能建立人才选拔的直接途径。因此，铁三训练营可以被定位为信息安全人才培养与就业指导基地。

11月14日，电子科技大学与亚信安全强强联合成立“信息安全铁人三项赛训练营”，迅速组成一支“哈桑战队”，参加西南赛区的比赛。本次训练营启动仪式由电子科技大学负责人王瑞锦博士主持，他代表CCF电子科技大学学生分会及参加培训的学生对本次培训课程的亚信安全老师们表示热烈欢迎，然后对本次大赛的竞赛精神、赛事规则、以及需要掌握的技术方向做了详细介绍。本次训练营计划开展5天的网络安全知识培训课程。

![](../Images/7cfb579e9aacb8bc23c575ff84ccd36f.png)  
**▲训练营课堂**  

 本次训练营的企业导师为亚信安全资深咨询顾问赵天永与资深研发经理喻存林。亚信安全赵天永老师首先给学员们介绍了近年来的一些信息安全问题事件，讲解了其中的安全问题及攻防的相关知识，然后详细说明了黑客们常用的攻击手段与攻击的几个阶段。赵老师在通过实例分析讲解了相关的攻防知识后，又带领大家回顾了一些年度信息安全威胁让同学们切身体会到了网络安全对国家安全、社会安全的重要性。赵老师引人入胜的讲解让在场的每位学员受益匪浅,让大家对网络安全及攻防知识有了新的认知。

亚信安全资深研发经理喻存林老师详细讲解了网络安全及攻防知识，主要内容有Cybercrime Operations, APT Introduction, Attack Methodologies三部分。课堂上，为提高学员们学习的积极性，也为了更好的让学员们掌握APT攻击技术，喻老师精心为大家准备了实验环节。实验过程中，他对每名学员耐心指导，让同学们通过实际操作消化所学的理论知识。

![](../Images/a5df3c403664fc498beb5bcfb256328d.png)  
相信在培训中的实际操练和对抗，能让学员们通过实战检验所学，查缺补漏，加速自我能力的提升。期待亚信-科大联合战队的同学们在“信息安全铁人三项赛”中的精彩表现。

关于**亚信安全**

 

亚信安全是中国领先的云与大数据的安全技术领导者。随着国家网络安全战略的提出，信息安全日益成为瞩目焦点。2015年9月，亚信科技收购了全球最大的独立安全软件提供商-趋势科技中国区业务并组建了新公司“亚信安全”，实现了推动实施自主可控战略，为国家提供网络和云与大数据产业的安全保障，为用户提供国际领先的产业互联网安全技术和解决方案的全覆盖。
