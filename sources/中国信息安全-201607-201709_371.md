# 关注｜以标准制定为抓手 扎实推进物联网产业发展

*   无锡市经济和信息化委员会主任/高亚光

近年来，美、德、欧盟等国家和地区均将物联网作为战略性产业推进。物联网国际竞争日趋激烈，物联网标准和顶层架构建设成为物联网国际竞争的制高点。2015年，美国政府宣布投入1.6亿美元推动“智慧城市”计划，将物联网应用试验平台建设作为首要任务。同年，欧盟成立物联网创新联盟，确立物联网发展的标准化、项目设置、价值链重塑和政策导向四大横向基础支撑。德国政府投资2亿欧元支持“工业4.0”，投入800万欧元用于物联网信息安全标准研发。此外，全球多家科技巨头也积极部署物联网标准化建设。2016年2月，包括微软、英特尔、三星、思科、通用电气在内的多家科技巨头联合发起成立物联网标准组织“Open Connectivity Foundation”，通过创建一套开放的规范和协议标准，以推进物联网产业的发展。

我国物联网标准制定具有先发优势。2010年11月，国家物联网基础标准工作组正式成立，下设六个行业应用标准组，形成了组织协调、技术协调、标准研制三级协同的物联网标准工作机制。随着物联网应用范围的扩大，制约标准制定的深层次难题逐步显现。现阶段国内物联网标准工作仍然面临体系不成熟、标准研制与应用发展不同步、标准化人才匮乏等难题。

自国家传感网创新示范区设立以来，无锡市精准研判全球物联网产业发展新趋势，不断创新工作方式，坚持制定纲要明确标准工作方向、搭建平台集聚标准工作资源、坚持应用导向驱动标准制定“三面发力”，突破物联网标准工作的天花板。

一、制定纲要明确标准工作方向

从国内物联网标准制定现状看，统一的规划和部署仍然不足，造成物联网标准化组织一拥而上，难以充分发挥各个标准组织的优势，同时也制约了物联网标准制定进程。2012年以来，无锡市深入实施《无锡国家传感网创新示范区发展规划纲要（2012—2020年）》，明确“充分发挥示范区在物联网标准领域的先发优势和在国内外标准化组织中的主导地位，加快推动核心知识产权纳入国际、国家标准”。通过制定规划纲要，无锡市明确了全市物联网标准化工作的重点方向是加快推动核心知识产权纳入国际、国家标准。通过纳入国际标准体系，深度参与全球物联网产业的核心技术活动，从而保证无锡先行者地位。在此前提下，一批具有重要影响力的标准陆续发布。

二、搭建平台集聚标准工作资源

如何集聚资源形成发展合力，成为各地推动物联网标准制定需要思考的问题。作为物联网发展的先行城市，无锡给出的回答是借助国内唯一的“国家传感网创新示范区”这一名片，搭建各类公共服务平台，充分发挥各类资源的最大优势。建立标准联盟。为推进物联网标准制定与本地产业结合，孵化更多的无锡市企业标准，解决标准缺失难题，无锡市依托感知中国物联网联盟，先后成立了环保物联网产业标准联盟和物联网系统测试认证标准联盟，开展联盟标准研制工作，并向国家标准和行业标准转化。其中，物联网系统测试认证标准联盟成为2016年江苏省首批团体标准化试点建设组织机构。搭建各类研发机构，集聚物联网人才。近年来，无锡加强引进国内外知名企业、大学和科研机构。目前，国家医疗物联网研究院、英特尔中国首个联合创新中心、微软中国第二个战略服务基地、中国农业大学农业物联网研究中心相继落户无锡，物联网重点研发机构已达40家，新引入物联网高端人才2500多名，其中国家“千人计划”人才66名。搭建公共服务平台，集聚各类有效资源。为服务全市物联网技术创新和产业发展，无锡市建成53个物联网公共服务重点平台，建立包括检验检测服务平台、技术中介服务平台、标准及知识产权服务平台、应用推广平台等相对完备的物联网公共服务体系，同时形成了在锡各类教育培训机构每年培养2000多名物联网本科以上学历人才的培训规模。

三、坚持应用导向驱动标准制定

物联网属于大产业链，应用种类繁多，需求差异较大，同时，标准制定流程复杂缓慢、推广力度不足造成标准研制与应用发展不同步。对此，无锡做法是强化创新驱动，以重大应用示范工程为抓手，推动物联网标准研制工作。目前，无锡市有关物联网企事业单位已承建工信部、国家发改委、科技部、公安部、民政部、环保部、水利部、商务部、国家卫生计生委、税务总局、质检总局、全国供销总社、中国气象局等部门支持推广的重大应用示范工程17个，全市累计建设物联网应用示范项目200多个。2009年至今，无锡国家传感网创新示范区牵头和参与制定物联网国际标准9项、国家标准20项、行业标准25项。无锡物联网产业研究院连任ISO/IEC物联网体系架构国际标准项目组主编辑单位，代表中国牢牢掌握国际标准话语权。医疗物联网无锡研究院包揽2015年全部11个国家医疗健康物联网行业标准牵头起草工作。无锡物联网产业研究院牵头和参与了《物联网感知对象信息融合模型》等7个国家标准的制定，江苏物联网研究发展中心承担了9个智慧城市国家标准中的4个，公安部交通管理科学研究所主导制订了《汽车电子标识密钥管理系统》等8项国家标准，无锡特检院参与了国家标准《特种设备物联网系统数据交换技术规范》的制订工作。

“十三五”是我国充分发挥物联网产业先发优势的关键窗口期。作为先行城市，无锡将继续用好标准制定这一重要抓手，扎实推进全市物联网产业发展。

进一步推进企业主导与政府服务的协同化创新。借鉴美国企业联盟的做法，充分发挥企业主导作用，加快构建标准储备池，让更多的物联网企业参与标准制定，以推动发展企业联盟标准。精准把握国际、国内标准研制趋势，创新与物联网企业、行业协会的合作方式。同时，建立标准工作信息库，作为标准研制的开放平台，方便标准工作者查询相关标准信息，进一步规范标准认证、审批等流程。

进一步完善物联网标准供给结构。物联网标准制定既要考虑产业链“纵向”上下游之间的标准关系，同时还要关注“横向”产业与产业之间的标准关系。无锡将加快形成“共性平台标准+应用子集标准”双轮驱动的物联网标准供给结构，加强共性类标准以及面向应用子集的标准研制工作；充分发挥市场主体作用，推动物联网团体标准试点，鼓励物联网龙头企业、标准化组织以及技术标准联盟共同制定满足应用需求的标准。

引进、培养、培训三管齐下集成人才资源。未来，无锡将通过引进、培养和培训三个途径培育物联网标准化专职、专业人才。首先，结合全市物联网产业发展规划，将物联网标准化人才纳入全市人才引进体系，以此快速打开局面，带动全市物联网标准研发工作；其次，立足本地科研资源，开设相关专业，鼓励物联网企业与高校以订单式培养、研究生工作站等方式开展合作；其三，物联网企业应加强标准化人员培训，联合高校院所建立培训基地，整合社会资源强化相关人员标准化知识培训。

加强物联网标准研制的资金扶持力度。当前，物联网标准从立项到发布周期太长，加上政府资金扶持一般都是在标准发布之后，导致企业从事标准制定负担过重。针对这一情况，无锡将加大物联网标准研制的资金扶持力度，加强对物联网标准的单独立项，将标准研发作为技术成果转化的一部分，纳入全市科技成果奖励体系。同时，根据物联网研发机构和企业的实际需要前移扶持资金，从物联网标准立项之时就给予一定比例的奖励，打造标准研制全链条资金扶持体系。（本文刊登于《中国信息安全》2016年第10期）
