# 聚焦｜黑客圈的洪荒之力，Kcon大会成功召开

近日，“白帽”圈颇不平静。发生的种种管控事件，似乎表明“白帽”和“黑客”们所游走的灰色地带正在收窄，在这个时刻召开的第六届Kcon黑客大会，无疑受到了更多的关注。

作为业内标杆黑客盛会，从最初的咖啡馆到近两年的凯宾斯基，KCon迄今已经是第六届，知名度和影响力也越来越高。8月26日-28日，闭门培训、技术演讲，满满三天的技术干货让千余名黑客不虚此行。本届大会的口号是“汇聚黑客的智慧”，主题是“探索一切、攻破一切”，演讲环节带来总计18大顶级黑客议题，借此警示行业健全安全，共御风险。

![](../Images/eab77d74cc1d3d0466178e1e4888c4c3.png)

对于近期“白帽”们生存环境的变化，很多从业人员都在思考，是否继续坚守白帽情怀？能否继续发扬黑客精神？知道创宇CEO赵伟在大会致辞中对此作了肯定的回答，他表示，爱因斯坦有句名言：“这个世界是一个危险的地方，不是因为那些邪恶的人，而是无动于衷的我们！”赵伟呼吁黑客们要站出来，团结起来，一起对抗网络地下黑产，利用自身所学来保护网络及数据安全，保护民众安全。![](../Images/80f7e2a69b130d60b31ef94eab0bf3bb.png)

▲知道创宇CEO赵伟

 大会越来越走向国际开放，令人眼前一亮的是，本届大会邀请了Black Hat（黑帽）与 DEF CON安全大会创始人Jeff Moss，以及他的执行团队来到了现场。Jeff Moss表示，黑客的使命就是寻找安全问题，并找出解决方案。然而理想很丰满，现实很残酷，当前的教育、行业等都没有充分发挥其作用和影响力。他认为，即使网络安全问题不可能被全部解决，但大家还是要努力，去建设一个安全的网络空间。

![](../Images/e3ee9de98dc926ce9d727f1598de8d2b.png)  
▲Black Hat（黑帽）与 DEF CON安全大会创始人Jeff Moss

 大会今年的亮点不仅是国外重量级嘉宾，18大各类“黑”议题，还有兵器谱的亮相，核心白帽子颁奖，KCon-RockNight 摇滚之夜……议题精华

大会准备的议题类型覆盖广泛，包含了云 Hack、企业 Hack、安卓/iOS Hack、无线 Hack、物联网 Hack、汽车 Hack、网络设备 Hack、伪基站 Hack、工控 Hack、网络空间 Hack、僵尸网络 Hack、逆向 Hack等等，由来自政府相关安全机构、国内知名安全公司，民间的新生代安全力量进行分享。

 第一天的演讲环节，阿里云的李可弈指出了云服务存在的种种不安全，演示了一些实际入侵的场景。曾经攻破过智能保险箱的姚威带来了关于威胁情报在APT攻击中的运用心得。Only\_guest题为《给谁的愚蠢买单？！》的演讲，针对信息泄露问题做了深入的探讨。公安部网络安全专家童瀛则从从执法者的角度分析了黑客热点事件，介绍了打击网络犯罪的案例。

 下午，刘凯仁介绍了新的逆向工具，何潇潇演示了虚拟化的保护技术，unLimit安全小组针对Android 第三方库的漏洞攻击和 Fuzz 方法展开讨论，行之分享了安卓系统的漏洞和系统服务漏洞的常见利用方法，最后，知道创宇的黑哥演示了一个iOS的设计缺陷，从而导致众多APP受到0day攻击的安全漏洞。

![](../Images/ad614e6d47dcd312298b09d3f6f77218.png)  
▲知名黑客“黑哥”在演讲

第二天的演讲更关注物联网和无线安全。上午，朱利军介绍了如何利用漏洞攻破各类智能网络，KEVIN2600演示了攻破wifi和蓝牙、NFC等无线通讯的场景，Seeker介绍了伪基站的攻击原理和模拟攻击，还是高中生的汪正扬介绍了Mifare Classic的常见漏洞和攻防手法。下午，李均分享了智能汽车内网的入侵检测，timo分析了Cisco在内的网络设备的漏洞特点和研究方法，闫兆腾演示了网络空间中的IoT安全，灯塔实验室的Kimon介绍了将威胁情报应用到工控系统安全，b1t讲述了与僵尸网络攻防对抗的经验和技术分享。

![](../Images/ac8ae1aaa0a5bb99efa2ce6348f79ee1.png)  
▲最小的演讲者汪正扬

核心白帽子与兵器谱大会第一天结束时，颁布了Seebug2015-1016年度 top 10核心白帽子奖项，奖励他们为Seebug所做出的贡献和技术能力。

![](../Images/62efcf68233e08cbe890d46b15332c6d.png)▲Top 10核心白帽子颁奖

今年大会还推出了“兵器谱”环节，知道创宇筛选出十二件“安全神兵”，向所有与会者开放，并在Sebug漏洞社区对安全技术爱好者提供免费下载试用。据“兵器谱”的负责人张祖优介绍，此次展示的黑客工具拒绝任何商业推介，目的在于鼓励国内安全自动化工具的发展，不管公司大小，甚至是个人开发的工具，只要在某一领域有独到的地方都有可能入选到“兵器谱”之中。![](../Images/6b5225c8da4d89690c34cb5624870530.png)  
大会最后一天结束时，作为压轴环节，由黑哥向入选今年“兵器谱”的各式强力黑客工具进行颁奖。据了解，这是对 Black Hat（黑帽）大会致敬的一种特别方式，也是国内首次在安全会议上集中展示黑客工具。

![](../Images/1eb2ef1ce8d0ced573e4791cb98a7286.png)  
▲兵器谱颁奖摇滚之夜知道创宇这两年将黑客和摇滚紧密捆绑，意图用真正的摇滚，为黑客精神正名。知道创宇认为，黑客与摇滚，看似天差地别的两个群体，却有着心意想通的内在。虽然被世人质疑，但其实都拥有着超群创造力、无限正能量的极致灵魂。![](../Images/afb82dc8ad3da6c9df7e97c1d27b0ed0.png)  
大会演讲首日，当晚原创音乐组织走唱运动五位歌手现场轮流献唱，让现场的黑客们释放激情，飞扬梦想，为大会增添了浓厚的欢乐氛围。 记者参会后，深切感到在网络世界没有谁是安全的，之所以安然无事，那只是你还没有被盯上。能力有多大，责任就有多大，Kcon一直在宣传真正的黑客精神。正如今年的主题“探索一切、攻破一切”，自由、开放、探索、创造是黑客的终极目的。黑客是网络世界的先行者和守护者，不越界，不做恶，将技术和知识用到正确的安全之道上，这正是我们这个时代所需要的。
