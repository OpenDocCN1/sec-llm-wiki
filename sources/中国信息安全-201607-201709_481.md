# C3峰会系列｜赵泽良：网络安全关系你我 多方携手共建网络强国

![](../Images/088c0181e3034e648a0ff1f3ea3b2dab.png)点击上方“中国信息安全” 可以订阅8月5日—6日，主题为“安全可控•御未来”的2016年首届C3安全峰会暨中国云安全峰会在成都召开。此次安全峰会引起社会各界的广泛关注，吸引了近2000名业内人士参与。信安君将整理部分政府及相关部门代表、业界专家等的讲话内容，并结合相关采访，在今后几天为大家呈现首届C3安全峰会系列报道，敬请关注。

在8月5日上午，以“控全局、御未来”为主题的主论坛上，政府及相关部门代表、专家就信息和网络安全问题发表了讲话。中央网信办网络安全协调局局长赵泽良在论坛上表示，**今天的网络安全问题已经不仅仅是国家安全问题，做好网络安全工作也不仅仅是中央网信办和其他国家相关部门的责任，而是越来越成为各级政府、广大企业、广大网民的共同责任。**

![](../Images/f896b881fc2e5485423eeeaeb83ea192.png)  
网络安全关系国家安全，没有国家安全，老百姓的个人安全也无从谈起。赵泽良表示，网络安全问题并非遥不可及，一旦出现问题，首先受到影响的就是老百姓，而最关心、最担心、第一个作出响应的就是国家。他指出，今天的网络安全问题要放到非常重要的位置上，强调各级政府、特别是地方的网络安全和信息化的领导小组要统一领导、统一协调本地区的网络安全工作。赵泽良引用习近平总书记在网络安全和信息化工作座谈会上的重要讲话，再次强调网络安全从业人员要深入研究，要采取有效措施，做好安全防护，并建立关键信息基础措施的保障。

习总书记强调网络安全为人民，网络安全靠人民，总书记要求我们的网络安全工作要为广大人民群众带来更多的获得感。那么如何做到网络安全为人民、靠人民，怎么样让人民有获得感，赵泽良认为要从网络安全的教育，提高人民的网络安全意识做起。他表示，从今年9月19日起，中央网信办将在每年9月的第三周举办国家网络安全周活动，以通俗易懂的形式，把网络安全的知识传播到千家万户，让全社会的网络安全意识提升到一个新的层面。

随着近日《国家信息化发展战略纲要》的印发，以及《中国银行业信息科技“十三五”发展规划监管指导意见》等国家关键行业信息安全法案陆续出台，网络安全已经上升到国家战略高度，网络安全是全天候、全方位、全民性、全局性的事业，只有加强网络安全建设，通过加强能力建设来突破核心技术，提高人民群众的网络安全意识，才能促进中国网络市场的繁荣稳定，才能把控信息化发展的未来，才能保障国家安全，才能加快建设网络强国的步伐。（本文由“中国信息安全”公众号整理）
