中国信息安全测评中心 /杨诗雨  郝永乐

习近平总书记曾指出，要推动网信事业发展，建立政府和企业网络安全信息共享机制，建立统一高效的网络安全风险报告机制、情报共享机制、研判处置机制，增强我国的网络安全防御能力和威慑能力。这对于强化我国漏洞管控机制有着极其重要的指导意义。为深化细化网络强国建设，需联合社会力量，建立国家信息安全漏洞库统一消控体系。

一
漏洞库建设背景

随着网络威胁逐步加剧，各国均加强了对信息安全的重视程度。作为信息安全问题产生的根源之一，安全漏洞逐渐成为网络空间安全战略的重要内容，是国家信息安全保障体系中不可或缺的基石。

欧美发达国家采取了多种措施加强国土安全和信息安全保障工作，在漏洞管控方面制定了详细的策略和路线，并建立了完善的漏洞管理体系。以美国为例，通过国土安全部（DHS）和军方主导关于漏洞分析方面的研究和探索工作，充分利用美国的技术优势，整合各方资源，以美国国家漏洞库（NVD）为核心，联合非营利机构（如CERT）、商业公司（如Microsoft）、科研院校（如MIT）等民间力量，掌握全球最全面的漏洞信息，控制有关国防安全的关键信息。

近年来，随着国家宏观管理和支持力度的加强，我国信息安全管理方面也得到了长足的发展。《网络安全法》立法工作逐步推进，《国家安全法》、《刑法》、《反恐法》等法案涉网条款不断完善，十八届五中全会将“网络强国战略”纳入“十三五”规划的战略体系，强调以网络安全和信息化护航强国战略，我国网络安全产业迎来爆发式增长机遇。然而，与西方发达国家相比，我国信息化起步较晚，网络安全领域缺乏核心技术，国内厂商对国外产品的漏洞、后门等安全缺陷缺乏有效应对办法，党政机关、工控、金融、通信、交通运输、卫生医疗等关键领域安全事件频发。

二
全球漏洞平台概况

漏洞库是以漏洞收集和发布为主的研究机构，作为网络安全隐患分析的核心，对网络安全保障和国家安全维护有着重要的指导意义。目前漏洞管理机构主要分为国家级、行业和民间级和软件厂商。

（一）国外漏洞平台

西方国家信息化、网络化发展较为迅速，在信息安全领域也处于领先地位。

美国于2005年建立了美国国家漏洞库（NVD），由国土安全部（DHS）研究部署并提供建设资金，由美国国家标准与技术研究院（NIST）负责技术开发和运维管理。NVD整合各方资源，拥有当前全球最全面的漏洞信息，与安全公司、企业和安全机构保持秘密合作和雇佣关系，建立了政府、企业以及学术机构联合共进的模式，从上而下形成了严密的漏洞信息管控模式，其漏洞管理机制非常完善。在政府的主导和指挥下，美国各类机构在漏洞管控方面做了大量工作，如US-CERT（美国国土安全部）和MITRE（麻省理工学院的科研机构）；各大企业也纷纷建立了漏洞平台，包括X-Force（IBM ISS公司）、ZDI（HP TippingPoint公司）、BugTraq（Symantec Security Focus公司）、Exploit Database（Offebnsive Security团队）等，此外还有Microsoft、Apple等软件厂商定期以安全公告的形式发布本公司产品中的漏洞信息。

2008年，欧盟启动了以“安全漏洞库服务（Security Vulnerability Repository Service，SVRS）”为核心的欧盟盾牌计划（SHIELDS计划），收集来自欧洲各国政府、安全研究人员和相关企业的漏洞，并通过该漏洞库和相关工作的部署，在软件开发过程中直接整合漏洞检测和消除过程，避免因已知漏洞和同类漏洞的反复出现而引发大量安全事件。

此外，国家级漏洞平台还包括了日本计算机网络应急技术处理协调中心（JPCERT/CC）和日本信息技术促进局（IPA）共同建立的JVN（Japan Vulnerability Notes）以及印度计算机应急响应小组（IndianComputerEmergencyResponse Team）建立的CIVN（Cert-In Vulnerability Note）等；行业级和民间级漏洞平台还有丹麦Secunia公司创建的Secunia漏洞平台、法国Vupen Security公司的VUPEN漏洞平台、俄罗斯Positive、Technologies公司建立的SecurityLab、瑞士scip公司的scipVulDB，以及开源非盈利的全球性安全组织OWASP定期发布的安全公告等。

（二）国内漏洞平台

我国信息安全领域起步较晚，但近年来发展极为迅速。2009年，我国的国家信息安全漏洞库（China National Vulnerability Database of Information Security，CNNVD）正式上线运营，由中国信息安全测评中心负责建设运维，作为我国信息安全保障体系建设的重要举措，与国内安全厂商、科研单位、安全人员等广泛开展技术合作与交流，提高我国信息系统安全防护水平。

国内相关的组织机构和企业也纷纷建立漏洞平台，积极开展与漏洞处置相关的工作。国家计算机网络应急技术处理协调中心（CNCERT/CC）建立了国家信息安全漏洞共享平台（China National Vulnerability Database，CNVD），国家计算机网络入侵防范中心（NCNIPC）建立了NCNIPC安全漏洞数据库，清华大学网络中心与信息安全实验室所属的SCAP中文社区，国内绿盟科技公司、启明星辰公司分别建立了绿盟科技安全漏洞库和天镜漏洞信息资源库，腾讯、华为、阿里巴巴、百度、网易、联想等数十家国内知名企业对自身产品的安全性愈发重视，纷纷成立了安全应急响应部门，以便第一时间收录和处置旗下相关产品及业务的安全漏洞和威胁信息，消除安全隐患。

此外，随着安全问题逐渐得到人们的重视，中小型企业对于通过渗透测试等方式解决漏洞隐患的安全保障需求日益强烈，新兴众测模式的商业公司也开始逐步兴起，并建立了如乌云漏洞平台、补天漏洞平台（原“360库带计划”）、FreeBuf漏洞盒子、Seebug漏洞平台、Sobug众测平台、威客安全众测平台等第三方漏洞平台。这些第三方漏洞平台主要收集安全研究人员和厂商提交的漏洞信息，并提供了一定的奖励机制。其中乌云平台成立时间较早，为软件厂商和安全研究者提供技术上的各种参考和漏洞的修复方案。不同的平台拥有不同的漏洞收集、验证、处置和披露机制，但目前还未形成统一规范。

三
国家信息安全漏洞库（CNNVD）

国家信息安全漏洞库是测评中心为切实履行漏洞分析和风险评估职能，自2007年起负责建设运维的国家级信息安全漏洞数据管理平台，旨在为我国信息安全保障提供基础服务。CNNVD与国内外安全厂商、科研单位、安全人员等广泛开展技术合作，以提高信息系统安全防护水平，降低网络安全威胁。经过几年的建设与应用，在信息安全漏洞搜集、重大漏洞信息通报、高危漏洞安全消控、信息安全标准化建设等方面发挥了重大作用。

（一）CNNVD介绍

CNNVD作为国家级公益服务平台，采用统一的规范对漏洞进行收集、发布、命名、分类和分级，建立了规范、全面的漏洞管理机制。CNNVD对收集来自CVE、NVD、Bugtrag、ZDI、绿盟科技、启明星辰等10余个漏洞数据源的漏洞数据，并对Microsoft、Cisco、Oracle等安全厂商的安全公告页面中产品漏洞数据进行采集，对漏洞数据资源信息进行规范描述，包含了漏洞名称、漏洞编号、发布时间、更新时间、严重级别、漏洞类型、发现时间、修复状态、CVSS基础评分、利用性评分、可利用距离、攻击复杂度、身份鉴别强度、影响度评分、保密性影响、完整性影响、可用性影响、临时解决措施、漏洞简介、漏洞公告、参考网址、受影响软件、与其他漏洞的对应关系（如CVE编号、BID编号、Secunia编号、ZDI编号等）等30余项属性信息。CNNVD兼容《通用漏洞与披露》（Common Vulnerabilities and Exposures，CVE）的命名标准，使用CNNVD ID作为漏洞的唯一标识，并遵照《通用漏洞评价体系》（Common Vulnerability Scoring System，CVSS）进行漏洞评级。CNNVD具有漏洞数据资源统计、查询等功能，对外提供漏洞信息查询、统计查询、漏洞信息通报以及漏洞数据资源的兼容性服务，用户可以通过漏洞编号、漏洞名称、受影响产品信息、厂商信息等多个维度查询漏洞数据资源信息及统计数据。此外，CNNVD收录了可靠的漏洞官方补丁信息，用户可以根据需求通过CNNVD下载补丁。

CNNVD目前已经收录了信息产品漏洞（通用型漏洞）8万多条，信息系统漏洞（事件型漏洞）4万多条，漏洞补丁及修复措施5万余条，发布漏洞权威通报300余份，涉及国内外各大厂商达300多家，涵盖政府、金融、工控、社保、卫生医疗、交通运输等多个行业。

（二）CNNVD重要职能
漏洞数据和通报

CNNVD数据覆盖国内外主流漏洞平台，为政府、央企和社会公众提供权威的漏洞数据查询和统计；定期发布信息安全漏洞通报，对漏洞的数量、类型、威胁要素、发展趋势等方面进行宏观和微观方面的分析；每年发布年度态势报告，结合漏洞数据情况，剖析国内外最新的安全形势；并针对网上出现的安全漏洞和事件进行及时的预警和消控。

随着网络威胁逐步攀升，针对安全漏洞的应急响应和安全事件的处置消控成为国家漏洞库工作的重中之重。CNNVD以漏洞数据为核心，及时发现重大漏洞和后门隐患，发布信息安全漏洞通报，把漏洞防御点前移，实现网络信息安全的“预防性保护”，同时为指导未来的安全策略提供重要的依据。

CNNVD自运营以来在漏洞库的建设中积累了丰富的经验，推出了技术支撑单位合作计划、特聘专家计划和战略合作伙伴计划，已初步建立了与重要企业、信息安全厂商、软件厂商、安全组织及安全研究人员的合作体系，形成合作密切、各有优势、互为补充的良好局面，完善了CNNVD漏洞收集、验证、消控、发布和修复流程，并能做到针对出现的重大漏洞和安全事件如“OpenSSL心脏出血漏洞”、“Struts2远程命令执行漏洞”等都进行及时的预警和消控。

技术支撑单位计划

CNNVD技术支撑单位计划主要面向信息安全厂商，以平等自愿的原则，通过签约合作的方式与信息安全厂商开展合作，将信息安全厂商作为CNNVD的技术支撑单位。通过整合业内信息安全厂商在漏洞发现、分析、收集、处置等方面的力量优势，扩展CNNVD的漏洞收集渠道，提高CNNVD的漏洞发布预警和处置能力，同时将CNNVD的漏洞信息与信息安全厂商共享，进一步助力信息安全厂商开展信息安全漏洞研究，从而在行业内形成漏洞信息研究、分析、收集、发布的良性机制，从而提高整个国家的信息安全漏洞整体研究水平和预警能力。该计划的目标在于依托CNNVD，根据测评中心和信息安全厂商的业务需求，围绕漏洞发现和漏洞信息共享，双方开展广泛的合作并达成长期的战略共识。

目前，CNNVD技术支撑单位已经有40家，第一批技术支撑单位以信息安全厂商为主，包括奇虎360、绿盟科技、启明星辰、天融信等；第二批技术支撑单位以软件和系统厂商为主，包括腾讯、华为、金山、国舜等；第三批技术支撑单位以第三方漏洞平台为主，包括乌云平台、FreeBuf漏洞盒子、威客安全、Sobug等。

学术交流

CNNVD邀请国内知名的信息安全研究人员作为特聘专家，提供咨询和指导，并在CNNVD定期举办的技术交流、学术会议和安全培训等活动上分享最新的技术成果。

此外，CNNVD定期举办学术会议、技术交流和安全培训，针对重大安全漏洞和事件进行研讨，需最新的技术应用和进展进行分享和学习，开展安全培训，提升员工的安全素养和安全应对能力，切实提升企业的安全防范能力。

兼容性认证服务

如今基于漏洞发现和攻击防护类的产品如IDS、IPS、防火墙等种类和数量即多且杂，这些产品所使用的漏洞信息主要是依据CVE的标准，用英文进行命名和描述，且仍有大量的国内产品的漏洞没有统一的规范命名和标准化描述。为此，CNNVD推出了兼容性认证服务。

CNNVD兼容性服务是指国家信息安全漏洞库面向我国信息安全厂商，对其信息安全产品或系统等涉及到的漏洞信息进行数据规范性评估与认证的服务。通过CNNVD兼容性服务，我国信息安全厂商对漏洞可逐步形成统一的认识，积极共享以漏洞为核心的各类数据资源，极大解决了国内信息安全行业漏洞信息标准不规范统一、漏洞统计分析结果不可比对的现状，为漏洞挖掘、应用、验证与规避等技术研究提供基础支持，为开发更安全的信息产品或软件系统提供理论和技术支撑，进一步满足国家重要信息产业安全保障的需求。目前，通过CNNVD兼容性服务认证的共有13家公司（其中包括北京启明星辰信息安全技术有限公司、北京神州绿盟科技有限公司、杭州安恒信息技术有限公司、腾讯科技有限（深圳）公司等）的漏洞扫描、入侵检测、网站监测等6类19款信息安全产品。

（三）未来展望

金融、能源、电力、通信、交通等领域的关键信息基础设施是经济社会运行的神经中枢，是网络安全的重中之重，也是可能遭到重点攻击的目标。而国家关键信息基础设施的安全防护离不开对漏洞的合理管控。CNNVD通过多种渠道收集数据信息资源，整合社会各界信息安全力量，建立多种合作模式，打造CNNVD安全服务体系，搭建信息安全服务链，建立以CNNVD为核心的统一消控体系，及时发现关键信息基础设施的安全漏洞，并做到及时预警和消控，切实提高我国信息安全漏洞整体防范能力。（本文刊登于《中国信息安全》2016年第7期）
