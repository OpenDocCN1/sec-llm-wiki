# 论坛｜北京邮电大学教授马严：把握发展机遇 掌握核心技术 建设网络强国

**一、把握发展机遇**

    

中共中央办公厅和国务院办公厅于2017年11月印发了《推进互联网协议第六版（IPv6）规模部署行动计划》。该计划从重要意义、总体要求、重点任务、实施步骤和保障措施共五个方面，对今后我国用五到十年时间建成全球最大规模的IPv6商业应用网络，构建下一代互联网自主技术体系和产业生态，实现下一代互联网在经济社会各领域深度融合应用，利用下一代互联网技术建设网络强国，成为全球下一代互联网发展的重要主导力量，做出了具体的行动计划。

文件明确指出“互联网是关系国民经济和社会发展的重要基础设施，深刻影响着全球经济格局、利益格局和安全格局”。我国是世界上较早开展下一代互联网核心协议IPv6试验和应用的国家，在技术研发、标准制定、网络建设、应用创新方面取得了重要阶段性成果，已具备大规模部署的基础和条件。把握住全球网络信息技术加速创新变革、信息基础设施快速演进升级的历史机遇，加强统筹谋划，加快推进IPv6网络和应用的规模部署，将对我国今后社会和经济的良好发展带来不可估量的影响。我们要构建高速率、广普及、全覆盖、智能化的下一代互联网，这是加快网络强国建设、加速国家信息化进程、助力经济社会发展、赢得未来国际竞争新优势的紧迫要求。

当前以IPv6为核心协议的下一代互联网技术在全球得到了快速的发展。无论是路由器、交换机等网络设备、还是各类操作系统和网络应用，从标准到产品都已经得到普及使用。不仅工业发达国家，不少发展中国家近几年来都在加大部署力度。根据亚太地区互联网信息中心APNIC今年12月的最新统计，按照IPv6用户数量的比例排名，比利时、印度、德国和美国都已超过了38%，其中印度接近一半的互联网用户在使用IPv6。而中国只有不到0.5%的用户利用IPv6接入互联网。

改革开放近三十年来，中国社会发生了翻天覆地的变化。在国家政策引导推进下，我们建设了一个自信、开放的社会。在我国教育和科研、软硬件设备制造商、网络服务提供商、IP地址和域名管理和运营机构、内容和应用服务提供商、政府管理部门等各行各业的努力之下，中国互联网的发展取得了举世瞩目的成就。我们取得了网络用户数量全球第一并超过全球平均普及率，网络与安全设备国产化，电子商务总量全球第一，电子支付总额全球第一、信息化服务程度显著提高等一系列瞩目成就。下一代互联网和信息技术的进步也为我们跨越和赶超发展提供了难得的历史机遇，我们将在基础设施建设、综合创新能力、数字经济发展、互联网应用、网络安全和网络管理等等方面进一步努力工作。

正如习近平主席在乌镇互联网大会上所指出：“互联网发展是无国界、无边界的，利用好、发展好、治理好互联网必须深化网络空间国际合作，携手构建网络空间命运共同体。”全球通达的互联网真正让世界变成了地球村，信息化环境下的国际社会越来越成为你中有我、我中有你的命运共同体。改革开放的中国离不开国际社会，世界也离不开对人类做出积极贡献的中国。互联网与社会各个方面的深入融合和快速发展已经对国家的主权、安全、发展利益提出了新的挑战，迫切需要国际社会认真应对、谋求共治、实现共赢。我们需要加强与国际标准化组织的合作，积极参与下一代互联网相关标准的制定，在政府和民间多层次多方位的合作与交流中发挥我们的正能量，争取发挥引领的作用。

  

    

**二、掌握核心技术**

    

在全球互联网加速向IPv6过渡的浪潮中，我们应该具备远见卓识并加以付诸实际行动。我们不能习惯于跟随，今后更需要有足够积累后的创新。随着互联网规模的不断扩大，网络和信息系统面临的问题和挑战越来越大，掌握核心技术的重要性越来越突出。我们要在网络和云服务系统的复杂性、网络基础设施和业务系统安全防护、网络和业务系统服务质量、网络和应用系统性能、个人隐私防护、绿色节能、法律法规建设等方面着手，不应仅仅专注于传统技术和设施，还是应该投资于面向未来的人才、技术和设施。

我国互联网发展主动权掌握在我们手中。保障国家安全，互联网安全就必须研究和掌握网络与信息处理的核心技术，用创新性的思维和行动，在下一代互联网与传统产业的结合上实行“弯道超车”，各行各业协同推进《行动计划》的落地实施，构建有序产业生态环境，推动网络强国的建设。我们一定要抓住下一代互联网发展的良好历史机遇，打造‘自主可控’的网络安全生态链。自主研发的软硬件和系统需要经得住检验，否则其存在的漏洞会被利用。引进经过检验检测的软硬件和系统在可控的环境中也能发挥作用。

下一代互联网新型网络体系结构与关键技术的研究需要在理论和技术上实现创新。我们要在基于IPv6的网络路由、IPv4向IPv6的网络过渡、智能化故障排查与网络管理、网络与云资源调度、网络功能虚拟化、网络安全和隐私保护等核心技术的研发上加大力度。我们要在下一代互联网的网络和信息安全方面做好各种类型的人才培养、研究制定并实施相关国内标准与国际标准、研发支持下一代互联网的自主可控的网络和安全等核心设备与系统，实现核心技术与应用技术的突破及其产业化。

为落实《行动计划》，我们要在今后的几年里实现政府网站与应用系统和各类商用网站对IPv6的全面支持、研发适应物联网和车联网等新兴领域的网络和应用、域名注册和运营机构全面支持IPv6、网间互连与接入网的工程部署、云服务提供商和内容分发网络、IPv4向IPv6平滑过渡系统、地址管理和网络运维系统、网络安全防护与审计系统、认证计费管理与统计分析系统、网络测量仪器仪表，以及各类政策与法规等各方面加大对下一代互联网发展的支持力度，以创新的思维做出实际的行动，实现《行动计划》要求在2025年时IPv6网络规模、用户规模、流量规模位居世界第一位的目标，形成全球领先的下一代互联网技术产业体系。

  

    

**三、建设网络强国**

    

当今时代信息化社会的发展将不断得到加速，下一代互联网的推进已是全球的发展趋势。我们一定要像习近平主席所说那样，建设网络强国，与实现“两个一百年”奋斗目标同步推进，向着网络基础设施基本普及、自主创新能力显著增强、信息经济全面发展、网络安全保障有力的目标努力前行。

网络安全和信息化是事关国家安全和经济与社会发展、事关我们广大人民群众工作生活的重大战略问题。要从国际国内大势出发，总体布局，统筹各方，培养人才，发展产业，国际合作，全面创新，才能把我国建设成为网络强国。

国家关键信息基础设施的规模、能力和安全防护从1994年互联网接入我国起已得到极大的提升，取得了网络用户数居全球最多等一系列成就，但我们仍不是网络强国，与工业发达国家人均资源占有相比还有很大差距。我们的基础设施从规模、能力到安全仍然有很大的发展空间。从网络和信息安全角度看也仍面临较大风险和隐患，存在着“‘物理隔离’的内网防线可被跨网入侵，电力调配指令可被恶意篡改，金融交易信息可被窃取，高水平网络与信息安全人才缺乏，隐私防护薄弱易被攻破，监测和对抗手段单薄”等问题。

我们有自信把网络与信息技术的自主创新，特别是“核心技术自主创新这个‘牛鼻子”与消化吸收国际先进经验很好地结合，加强实现自主创新的政策保障条件，加大对自主创新能力建设的投入，实现网络强国这个目标的关键技术、设备和工程能力的产业化。我们的技术研发和产业今后面向的不仅是国内的市场，也一定要面向全球的市场，并努力在信息社会和互联网治理领域引领全球化发展的正确方向。

没有网络安全就没有国家安全，没有信息化就没有现代化。全国人民代表大会常务委员会执法检查组于2017年12月24日发布了关于检查《中华人民共和国网络安全法》和《全国人民代表大会常务委员会关于加强网络信息保护的决定》实施情况的报告，正是在建设网络强国的征途上的一个重要举措。我们要认真贯彻关于“建设网络强国”的战略部署，把网络安全纳入经济社会发展的全局高度做好统筹谋划部署，大力推进网络安全和网络信息保护工作。

网络安全保障是通过攻防对抗来实现的，“网络安全的本质在对抗，对抗的本质在攻防两端能力较量”。面向下一代互联网的网络安全保障需要通过网络与信息系统的规划、工程部署、信息采集、攻击检测、系统防御、数据分析、身份认证、访问授权、威胁溯源、情报分析、态势感知和预测等大量工作才能实现。而这一切说到底要依靠包括高素质人才、技术、设备和体系化的组织管理等一整套相互关联、相互协作的系统才能实现。当然，还必须把网络和信息安全工作列入重要工作议程而不只是口头上重视，“说起来重要，干起来次要，忙起来不要”。

我们相信在党和政府的正确领导下，在各行各业的努力之下，我们一定能够把握住发展机遇，掌握住核心技术，发展下一代互联网，建设好网络强国。

（本文刊登于《中国信息安全》2018年第1期）
