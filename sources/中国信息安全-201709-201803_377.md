# 十九大精神学习体会 | 大力开展网络安全人才培养与产业创新 坚决保卫国家网络安全

■ 北京易华录网络安全与发展研究所所长 薛晓东

近期比较关注网络安全人才与创新方面的工作，结合工作谈谈个人体会。习近平总书记在十九大报告中指出，国家安全是安邦定国的重要基石，维护国家安全是全国各族人民根本利益所在。对于我们网络安全研究人员来讲，深刻学习领会和贯彻十九大精神，就是要增强忧患意识，做到居安思危，坚决保卫国家网络安全，以实际行动积极投身于新时代中国特色社会主义的伟大实践。特别是要大力开展网络安全人才培养和产业创新，服务于国家网络安全保障。可以从四个方面来看：党、政、军、国际。

**一是要坚决保卫国家政治安全。**互联网已经成为舆论斗争的主战场。未来一个时期，网络意识形态斗争形势将依然严峻。网络安全人才培养与产业创新工作要服务于网络意识形态斗争，有力维护国家政治安全。要大力开展新媒体传播、网上舆情监测、网上舆论引导、违法信息监测处置等领域人才培养，以及大数据、人工智能在文本、音视频检测领域应用等相关产业创新工作，为网络意识形态斗争提供人才和技术支撑。

**二是要坚决保卫经济社会网络安全，包括关键基础设施网络安全、企业运营网络安全、个人隐私安全，以及打击网络恐怖主义、打击网络犯罪等。**网络安全已经融入经济社会的各个方面，网络安全人才培养和产业、技术创新要与各行各业深度融合。在开展专业和职业培训的同时，还要大力开展意识和素养培训，与各行业管理部门、相关院校管理学院、商学院、继续教育学院、职校等合作，开设网络安全通识类课程，提升各行业网络安全素养和基本技能，培养懂管理、懂法规、懂技术的综合性人才。

**三是要坚决保卫国家军事网络安全。**作为企业，要积极参与网信军民融合工作，我们在各地提供的城市数据湖解决方案，也会努力服务于军队网络安全人才培养和产业、技术创新；数据湖产业园将落实中央关于网信军民融合发展战略部署，在其中设立网信军民融合产业示范园区，培养网络安全预备役力量。

**四是要坚决维护网络空间国际安全。**网络空间是大国战略博弈的重要空间。贯彻落实十九大精神，推动构建网络空间人类命运共同体，需要我们“贡献中国智慧和中国方案”。一是要通过举办国际网络安全论坛，逐步提高国际话语权和影响力。去年以来，360举办的中国互联网安全大会观潮论坛受到国内外广泛关注，论坛由国家创新与发展战略研究会副会长郝叶力将军任主席，360齐向东董事长任理事长，易华录是首批理事单位，我们将继续积极参与，把观潮论坛办得更好；二是与美国、以色列、欧洲等国际知名网络安全及互联网创新企业加强产业交流合作；三是围绕一带一路战略推进，开展网络安全国际培训，不断扩大网络安全朋友圈；四是开展国际互联网治理相关人才培养、研讨交流。
