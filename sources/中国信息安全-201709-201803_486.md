# 聚焦 | 信息安全铁人三项赛“聚信安铁人 铸强国重器”论坛成功举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=2664109346&idx=1&sn=2fc0b7c274cddc28b35691ce07b24b2e&chksm=8b5e17dbbc299ecde73a1a4687f46788640f68db97524fecfec45ea73502805e2f6ac77d6d70&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664109346&idx=1&sn=2fc0b7c274cddc28b35691ce07b24b2e&chksm=8b5e17dbbc299ecde73a1a4687f46788640f68db97524fecfec45ea73502805e2f6ac77d6d70&scene=27#wechat_redirect)

![](../Images/09d22215a3c42bf45b4e96ff28339d6a.png)点击上方“中国信息安全” 可订阅

9月24日, 由中国信息安全测评中心、武汉市互联网信息办公室、武汉临空港经开区管委会联合主办，中国信息产业商会信息安全产业分会人才建设专业委员会、北京西普阳光教育科技股份有限公司承办的“聚信安铁人 铸强国重器论坛” 在湖北武汉顺利举行。来自全国各地的上百所院校、企业和单位的400多位嘉宾出席了本次论坛。

![](../Images/8ba2dddd147ce94b026692948f723f26.png)

本次论坛针对当前的安全形势出发，旨在总结信息安全铁人三项赛举办经验，共同探讨信息安全人才新未来，分享网络安全人才培养的新技术和新模式。中国工程院院士沈昌祥、中国信息安全测评中心副主任李守鹏、中国科学院信息工程研究所副所长邹维、武汉市网信办副主任王烁、中国信息产业商会信息安全产业分会秘书长位华、西安电子科技大学网络与信息安全学院院长李晖、武汉大学计算机学院副院长赵波、东莞理工学院计算机与网络安全学院院长袁华强、中国信息产业商会信息安全产业分会人才建设专业委员会秘书长王建、信息安全铁人三项赛技术委员会主任潘柱廷等嘉宾出席了本次论坛。

![](../Images/8c5108d677a289acaaa5652bdacf4417.png)

中国工程院沈昌祥院士在本次大会的主题演讲中指出：加强网络学科建设和人才培养，需要改革创新，从国家安全战略急需的角度出发，特事特办，加强组织领导，统筹指导全国网络空间安全学科专业建设创新驱动，深化改革人才培养模式和机制，采取有力措施，加快学科专业和院系和教师队伍的建设，提高教学质量和科技知识水平，加强教材和建设开放实训平台，进一步推动高校与企事业单位的合作育人。

当前，互联网技术的应用已经深入到各行各业，针对企业和个人的网络安全事件频发，在这样的严峻形势下，如何更好更快的培养高素质安全人才，成为社会各界广泛关注的问题。西安电子科技大学网络与信息安全学院院长李晖认为：“培养一流人才，攻克核心技术，为国家安全和经济社会发展保驾护航，学院重任在肩，刻不容缓。” 东莞理工学院计算机与网络安全学院院长袁华强指出，“在当前的网络安全形势下，院校需要以学生的实际操作能力和安全产业入手，深入以学习为核心的教学改革，实现政-企-学合作、协同育人，培养创新型的实用人才。”

![](../Images/b939b27bd70b83b166f1a91aed34bfe3.png)

信息安全铁人三项赛，正是为解决这些问题的一种尝试。在将赛事与产教融合相结合后，通过比赛以及赛前西普教育技术支持的铁三赛训练营，将学校和企业对接起来，让学校里面的同学能够得到专业技能的提升，是赛事的初衷。第一届信息安全铁人三项赛深入到13个城市、70余所院校，40余家安全企业参与结对，进行了上百场线下培训，组建了近百个训练营基地，学生进行总计数十万分钟线上训练。下一赛季的信息安全铁人三项赛将采取分区赛和全国总决赛两级赛制，参赛院校的规模也将会进一步扩大到300所以上，总决赛参赛规模预计会达到60至70所学校。 

在本次论坛上，中国信息安全测评中心副主任李守鹏、中国科学院信息工程研究所副所长邹维、武汉市网信办副主任王烁、中国信息产业商会信息安全产业分会秘书长位华、中国信息产业商会信息安全产业分会人才建设专业委员会秘书长王建、信息安全铁人三项赛技术委员会主任潘柱廷出席了2017-2018赛季信息安全铁人三项赛启动仪式。

![](../Images/784aabab479e4ca49bc16b20818b61b4.png)

信息安全铁人三项赛总决赛暨高峰论坛的成功举办，不仅打通了校企人才对接的最后一公里，也为安全人才的实战培养和产教融合协同育人的新模式进行了有益的探索。
