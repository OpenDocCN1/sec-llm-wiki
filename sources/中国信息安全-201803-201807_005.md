# 国际 | 美国银行申请最新区块链网络安全保障工具专利

根据最新公布的文件显示，美国银行(Bank of America)获得了一项专利，旨在控制对区块链网络方面的访问许可权。

![](../Images/edc57caa49a9ce2a20fa64ef1c31ed36.png)

**（美国银行申请最新区块链网络安全保障工具专利）**

该专利名为“安全管理和资源子组件访问系统”(system for managing security and access to resource sub-components),解释了证券型token中将被允许用户访问特定区块中包含的信息。该系统将是自动化的，将由网络本身授予权限或进行访问。

根据美国专利商标局的数据，美国银行与5月22日获得了该项专利，而近年来该银行已经提交了许多与区块链有关的申请。

考虑到美国银行对通过网络传输信息的敏感性，其对安全和数据隐私的关注或许就并不令人感到意外了，同时该行也提到了当今加密货币领域中的普遍安全问题，也就是人们都需要保护自己的私人密钥不被窃。

在该专利文件中，美国银行指出，“随着分布式/多中心化区块链网络的出现....需要开发现行系统...能够控制资源区块。”

该行解释称：“为指定的实体或用户提供识别特定区块的功能是必要的，一旦确定了区块，安全功能就可以确保访问制定区块的实体或用户是被授权的。”

此外，该专利中还提到了其自动化功能将会控制指定实体或用户对区块链访问权限的时间，来降低受攻击风险。
