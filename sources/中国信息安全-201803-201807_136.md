# 警惕 | AcFun近千万条用户数据外泄 暗网已开始售卖网站shell和内网权限

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=2664112180&idx=3&sn=6c2be8df6a3438745e628b79d1e4340c&chksm=8b5e22cdbc29abdbb45c56a9df0a44f89ae8e1e1fcce8a095ab5ed5d0698a3b58cb55e846700&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664112180&idx=3&sn=6c2be8df6a3438745e628b79d1e4340c&chksm=8b5e22cdbc29abdbb45c56a9df0a44f89ae8e1e1fcce8a095ab5ed5d0698a3b58cb55e846700&scene=27#wechat_redirect)

![](../Images/4931dc779bb0cc3535c10e7556d7f357.png)点击上方“中国信息安全” 可订阅

6月13日，AcFun发布公告称网站遭遇黑客攻击，近千万条用户数据外泄。AcFun表示泄露的数据包括用户ID、昵称以及加密存储的密码。同时公告也提示用户，所有的密码都是经过加密的没有明文密码。2017年7月7日之后登录过AcFun的用户密码自动升级为更强的加密策略，密码是安全的。但如果密码过于简单，也应尽快修改。

![](../Images/785d1f80e33a3b02773ab08731be4573.png)

  

**暗网已在出售用户数据**

据悉，早在今年 3 月份，暗网论坛中就有人公开出售 AcFun 的一手用户数据，数量高达 800 万条，平均 1 元能买到 800 条。

![](../Images/8d8e2aee1cc6ad7dbbe8cdcec1a38c02.png)

而在 AcFun 发布此次数据泄露公告之前，暗网中也早有人兜售其 Shell 和内网权限，主要卖点就是数据量大以及日流量高。

![](../Images/373273cc93f237a97c259e774677dd5a.png)

  

**小编建议：**

1.  尽快将密码修改成较复杂的形式，比如大小写英文字母+数字；
    
2.  定期修改密码，至少2-3个月修改一次；
    
3.  不要将所有帐户名和密码设置相同，这样如果黑客获取一个账户和密码，你的其它账户信息也将可能沦陷；
    
4.  添加尽量多的安全保障，例如设置短信验证登录、安全提示问题等。
    

  

**希望大家能重视自身个人信息和财产在网络空间的安全问题，学会保障个人信息和财产不受侵害。**
