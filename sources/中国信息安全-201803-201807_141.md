# 调查 | 国家网信办启动《“十三五”国家信息化规划》实施情况中期评估调查问卷

日前，国家网信办启动了**《“十三五”国家信息化规划》实施情况中期评估调查问卷**工作，问卷从**个人信息、信息化发展总体情况、信息技术产业发展情况、信息基础设施发展情况、大数据应用和发展情况、数字经济发展情况、电子政务发展情况、信息惠民发展情况、网信军民融合发展情况、数字经济国际合作情况、网络空间治理情况、政策建议**等12个方面向大众征集意见与建议。调查结果将集中反映《“十三五”国家信息化规划》实施以来，人们对现期工作的看法与评价，将对今后工作的实施与改进提供重要的参考价值。问卷中，涉及网络安全等方面的内容集中在第十一、十二条等部分，见下图：

![](../Images/fad68db2f8d97c01667766c02c1edc86.png)

![](../Images/4c32a0e2f9f04ef81bc743e93c7f56ea.png)

  

**调查全文如下：**

2018年是贯彻党的十九大精神的开局之年，是改革开放40周年，是决胜全面建成小康社会、实施“十三五”规划承上启下的关键一年。按照党中央、国务院的部署和要求，国家互联网信息办公室正在组织开展《“十三五”国家信息化规划》（以下简称《规划》）实施情况中期评估工作。我们设计此问卷，目的是了解《规划》实施以来信息化给人们生产生活带来的变化和感受，以及大家对信息化发展更好造福人民的愿望和期待。我们将根据调查结果对下一步工作进行改进或强化，使《规划》实施更加及时、准确地反映公众诉求，让人民群众在信息化发展中有更多获得感。网络调查问卷截止时间2018年6月30日。

您的意见对我们非常重要，本次答题大约用时5分钟，真诚感谢您的积极参与！

  

国家互联网信息办公室

2018年5月31日
