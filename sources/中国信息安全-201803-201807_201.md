# 地方 | 违规信息“零容忍” 河北查处违规网站17家

河北省委网信办持续加大对属地网络游戏领域违法违规信息内容的整治力度，取得显著成效，近两个月来共查处违规网站17家。

秉持对违规信息“零容忍”的态度，河北省委网信办集中力量加强网上巡查和网站督查，动员网民加大举报力度，规范处置流程，从严查处违规内容。

加强网上巡查。河北各市组织力量对属地内网站、移动客户端等平台进行巡查，督促属地内网站开展全面自查整改，其中沧州对全市28家涉网络游戏互联网企业进行了全面筛查；保定市督促全市6家具有网络游戏经营资质的网络公司开展自查。

拓展举报渠道。开展专项举报工作，利用技术手段在河北省委网信办举报平台开设举报专区，在省内网站上公布举报平台链接、举报电话、邮箱等，动员广大网民进行监督举报。整个专项整治工作期间，共受理涉网络游戏举报217件，其中有效举报线索39件。

规范处置线索。严格落实“一法两规”，建立研判处置制度，召开3次涉违规内容网游研判会，对收到的举报线索逐一进行审核查证，认定了17家涉嫌违规网站，确保处置得当、证据确凿、执法规范。

从严查处违规内容。依法依规对17家网站进行了处置，其中“大奖娱乐”“阿里彩票”等12家游戏网站传播非法博彩信息，“调教初体验”“乐虎国际”等2家游戏网站传播淫秽色情内容，“传奇（游戏）”涉嫌网络游戏诈骗，“f486.com”涉嫌传播邪典游戏，上述网站严重违反《中华人民共和国网络安全法》《互联网信息服务管理办法》等有关法律法规，已协调通管部门依法依规给予列入黑名单、注销备案、限制接入等处置。此外，“益玩游戏交易平台”因涉案金额较大，已移交公安网监部门协助调查；沧州市网信办联合有关部门，对属地内河北盛世千月网络科技有限公司网站违规问题下达责令整改通知书，督促全面整改。
