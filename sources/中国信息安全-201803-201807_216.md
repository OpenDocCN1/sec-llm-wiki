# 行业 | 李洋荣任网安会千人计划专家 平安助力国家网安事业发展

东半球规模最大的网络安全峰会——第六届中国互联网安全大会（China Internet Security Conference ,以下简称ISC）是由国家网信办、工信部、公安部、国家密码管理局指导，中国互联网协会、中国网络空间安全协会等组织共同主办的国际性互联网安全会议。

  

自2013年始办起，已成功举办五届，累计13.6万人次参与，超过700个演讲议题，覆盖20个国家的演讲嘉宾，现已成为亚太地区规格最高、规模最大、影响力最深远的安全峰会。美国第一任网络司令部司令基斯·亚历山大、美国911后第一任安全部部长汤姆·里奇、“计算机病毒之父”美国专家弗雷德•科恩、迈克菲杀毒软件公司创始人约翰•迈克菲、世界顶级黑客本杰明等重量级专家人物都曾登上ISC峰会舞台。

 

近年来，网络安全形势越来越严峻，影响到各行各业和国家社会的健康发展。为了推动并领导各行业网络安全的顶层设计、行业规划、体制机制创新，以及安全责任、安全体系、安全能力的完善与落地，尽快解决各行业面临的紧迫安全问题，全面提高各行业以及国家网络安全能力水平，**2017年第五届ISC大会启动了“行业网****络安全专家千人计划”**。此项计划旨在凝聚行业网络安全精英，共筑国家网络安全中坚力量，计划将聚集在国家关键基础设施相关行业承当信息与网络安全管理职能的领军人物，以及在信息与网络安全领域具有前瞻思维、创新精神和重要影响力的专家学者和政企精英。

 

![](../Images/205ec8a86e3948eeb8ec1e304ff9a494.png)

  

平安科技首席安全官、平安金融安全研究院执行副院长李洋博士深耕网络安全与信息化事业十余载的丰厚经验，为互联网、金融、制造、通信等行业输出众多成果，是推动行业安全发展的杰出先锋，其聚焦金融，立足创新，主导创办平安金融安全研究院，提出“金融安全3.0”的前瞻性理论，引领平安集团在安全领域的超前探索，致力构建安全生态，对行业安全发展具有重要影响。**经中国互联网安全大会（ISC）创新协同智库中国互联网安全大会专委会举荐，李洋博士将受邀担任“2018中国互联网安全大会”——行业网络安全专家千人计划行业专家委员会专家。**

![](../Images/da00ede04c34b2c0c21f0c3413c274d1.png)

平安科技首席安全官、平安金融安全研究院执行副院长李洋博士

  

行业网络安全专家千人计划行业专家委员会肩负担当行业网络安全，保障行业持续发展稳定的使命。未来，李洋博士将与专委会团队共同探索并落实国家及地方相关法律法规实施细则，依托ISC中国行，与各行业、省部级安全实验室等平台进行深度交流、开展研究合作，致力于完善行业安全管理和技术创新，引领核心技术应用创新，树立行业安全领域的防御体系标杆，并大力推进网络安全人才培养的发展，为专委会和国家网信事业吸纳精英专家人才，持续有效护航网络信息安全。**届时，李洋博士也将出席2018第六届中国互联网安全大会（将于2018年9月4日至6日在北京召开），并与业界同仁分享及探讨金融安全的最佳实践。**

**![](../Images/714e4b0f41318bce2f82fd843f592225.png)**

**关于平安金融安全研究院**

 

由平安科技成立的业界首家综合性的金融安全研究及创新机构，以“聚焦金融、着力创新、引领行业、打造品牌”为指导方针，着力整合“政、产、学、研、金、介、用”的业界优秀资源，与国家、行业、高校、研究院所等强强联合，“一手抓创新，一手抓落地”，在金融信息基础设施安全、金融科技3.0安全、金融业务安全风控三方持续创新实践，并致力于构建“金融安全3.0”时代的安全生态圈，为平安集团、行业、国家提供强有力的金融安全技术支撑，为金融机构在互联网、人工智能时代下的信息安全建设、业务安全风控、金融科技安全保障和国家金融安全作出科技贡献，形成可持续发展的独特学术研究优势、产品和服务，推动和引领我国在金融安全方面上的科学技术进步，打造金融安全品牌。

 

目前研究院下分6个研究领域：网络安全、数据及内容安全、系统安全、金融业务安全、金融安全标准和政策、医疗信息及应用安全。各个研究领域的骨干精英均来自知名院校、科学家团队、BAT、知名咨询公司、金融机构、国内顶尖安全公司等。
