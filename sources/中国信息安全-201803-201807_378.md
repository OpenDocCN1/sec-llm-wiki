# 地方 | 国家网安基地展示中心将成武汉地标

“土建部分主体结构已于二月全部完工，二次结构、专业施工正全面展开。”14日，国家网络安全人才与创新基地(后简称“网安基地”)展示中心项目现场，吊车正吊起一巨型“网壳”。项目施工方，武汉建工集团项目施工主管樊荣丰正指挥钢结构屋面网架落地工作。

展示中心作为网安基地首批集中开工重点项目之一，在去年8月底破土动工。其采用高空间大跨度曲面异形钢结构，是全国罕见高难度建造工艺，建成后通透环保，人们甚至看不到一根承重柱。

由于施工难度大，为和时间赛跑赶工期，临空港经开区主要负责人、相关部门工作人员及施工方技术人员放弃双休，每天驻守在项目工地确保施工进展，“晴天一身灰，雨天一身泥”成为常态。

记者3月探访时，项目钢结构“框架”才初现端倪，一个月过去，钢结构屋面网架就已落地。按目前进度，展示中心预计将在今年7月底完工，建成后将成为网安基地地标性建筑物之一。

华中地区规模最大的国际5A级互联网数据中心(IDC)位于临空港经开区径河街的临时厂房正在进行施工改造，而距离其签约，还不足3个月。

为配合企业时间表，春节假期一过完，工人就已进场施工改造。企业董事长孙志鹏表示，IDC项目一期投资30亿元，在现有厂房基础上建成2500个机柜和约35000个服务器。二期还将投资100亿元，建设一个更大的数据中心。

现代服务产业建设管理办公室有关负责人介绍，临空港经开区以“临空港速度”全力推进网安基地产业项目开工建设，目前已开工项目15个，占地5600亩，在建项目总投资达1500亿元。

其中，去年11月正式签约的中金数据武汉数谷项目已完成场地平整、大型机房试桩;京东方项目政府配套道路管网基础设施已全部完成，4月9日全面开工后已进场施工人员2000人，进场施工设备300台套，预计在2018年11月完成142万平方米厂房。

此外，投资8.6亿元的网安基地一期外环路、内环路等8公里道路将于6月完工，投资14亿元6座变电站同时开建，保证企业用电需求。
