# 关注 | 9月份全国网络违法和不良信息有效举报751.8万件

9月份，全国各级网络举报部门受理有效举报751.8万件，环比、同比分别增长4.3%和81.2%。其中，中央网信办（国家互联网信息办公室）违法和不良信息举报中心受理9.4万件，环比、同比分别下降7.8%和1.9%；各地网信办举报部门受理159.3万件，环比增长14.3%，同比下降8.6%；全国主要网站受理583.1万件，环比、同比分别增长2.1%和1.5倍。

  

![](../Images/d59208eecb5fe839448de970d58f10e7.png)

在全国主要网站受理的有效举报中，新浪（新浪微博、新浪网）、腾讯（微信、QQ、腾讯安全服务平台、腾讯网、腾讯微博）、百度、阿里巴巴等主要商业网站受理量占86.4%，为503.7万件。

![](../Images/1dde6b8b1ae28b1a1b419601e101ab2b.png)

网络连着你我他，空间清朗靠大家。欢迎广大网民通过举报中心网站、12377举报电话、“网络举报”客户端等渠道，或拨打31个省（区、市）网信办举报部门以及2000余家网站举报电话（可通过举报中心网站右下角入口查询），或通过人民网、新华网、央视网等19家中央新闻网站，千龙网、新浪网、天涯网等900余家地方新闻网站和商业网站开设的“网上有害信息举报专区”，积极举报网上有害信息，踊跃参与网络综合治理，推动网络空间共建共治共享。
