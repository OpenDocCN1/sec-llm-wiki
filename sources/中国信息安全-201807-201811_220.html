■ 永信至诚高级副总裁、首席战略官  潘柱廷

“网络安全为人民，网络安全靠人民”。 

人民，是一个整体的概念；人民，也是一个散点所组成之集合的概念。你、我、他都是人民的一部分。“靠人民”，是指靠人民的什么呢？ 

换一个视角说这个话题。站到每一个“我”的视角来看，“我自己的网络安全到底是我自己的事儿？还是谁的事儿？” 是自己要安全还是要冒险，都是我自己的事儿，不关其他人的事儿，真的是这样吗？ 


一、{ if 事儿 = 责任 }

2014年11月24日至30日，在北京举办了第一届“国家网络安全宣传周”。这是第一个国家级的网络安全宣传活动，面向广大的普通百姓。 

2016年9月，在武汉举办了第三届国家网络安全宣传周。这是宣传周第一次走出了北京，从那之后的各届宣传周都继续在不同的城市轮巡。 

大家都听过“网络效应”这个词。换一个更专业一点的说法叫“网络外部性”或“网络正外部性”，也就是指我们获得的效果，不仅来自于直接面对的对象，而且还大大依赖于这个对象后面的网络的规模和形态。 

举一个典型的例子就是传真机。如果世界上只有我一个人用传真机，那么这部机器一点也没有用途（也许只能当打印机用）；只有更多的人用传真机（特别是与我关系密切的人用），这台传真机才有价值。我们使用传真机，不仅仅是使用这台机器，还包括这台机器背后的网络。这就是网络正外部性，或简称为网络效应。电话、电子邮件、社交网络都具有这个效应。

 网络安全是一门对抗的技术。网络安全所面临和对抗的威胁，其中一部分是具有“负网络效应”（或称为网络负外部性）的事物。或者形象地称为“盘丝效应”。 一根一根的网线、电源线，如果一两根纠缠在一起，很容易就择清楚；但是如果参与纠缠的线越来越多，就会越来越难理清楚。这就是“盘丝效应”。 

病毒及其传播就具有很强的“负网络效应”——盘丝效应。感染设备的数量、感染变种的多样性等等，积累到一定程度就会形成爆发。 

那么，网络安全到底是自己的事儿，还是谁的事儿？ 

如果，事儿代表的是“对某某的责任”的话，网络安全绝对不仅仅是要对自己负责的责任，还要对我们身边的其他人、其他机构担负一定责任。对于普通百姓来说，这个责任就是要保护好自己。 

如果我们没能够保护好自己，那么我们就会成为盘丝效应的一段乱线。 

在北京举办的第一届国家网络安全宣传周，最令人印象深刻的是大力提倡在普通民众中推动网络安全意识教育、传播正确的网络安全观念。通过宣传周，让更多的普通百姓能够意识到网络安全问题的存在，能够用基本正确的观念来理解和应对。从那之后，网络安全意识宣传、网络安全观念教育都成为历届安全周的必然组成部分。 

“网络安全靠人民”，“靠民觉”，靠的是人民的网络安全意识的大范围觉醒和重视。


二、{ if 事儿 =使命 x 能力 }

那么，网络安全到底是谁的事儿？ 

如果，事儿代表的是“做网络安全事情的能力”的话，网络安全绝对不仅仅需要各种专业人士能够具有能力，还要让自己具备应有的能力。一个人要保护好自己，不仅仅要有自我意识、威胁意识、风险观念等等；还要具有实在性的安全知识和技能。 

对于不同人群的网络安全知识和技能要求是分层的。至少可以分成： 普通百姓（宣传周中的电信日、青少年日等对应的人群）； 高IT依赖行业从业者（宣传周中的金融日、政务日对应的人群）； IT从业者 ；网络安全专业相关从业者。

如果想择清楚一堆网线，或者捋顺一团糟的毛线，总要找到线头，总要把一些容易的线（能力强的）先择出来。当择到一定程度的时候，就会感觉到一种“反盘丝效应”。我们每个人都应当让自己称为那种“容易的线”。 

第三届宣传周之后，令人印象深刻的是以人才培养为使命的一系列举措得以落地。国家网络空间安全学院落户武汉，武汉大学和华中科技大学称为学院的支柱。继而，国家网络空间安全人才基地落户武汉市临空港经济区（东西湖区），国测、启明星辰、永信至诚、安恒信息等机构和公司相继签约入驻。2017年9月国内首届RHG机器人攻防大赛、首届信息安全铁人三项赛总决赛先后在人才基地举办。武汉大学也成为首批网络空间安全一流学院示范工程获选学校之一。 

能力教育不仅仅需要高校等教育机构，还需要广泛的民间力量。先进的互联网教育平台成为网络安全知识和技能教育的不可或缺的重要支柱。致使i春秋等一系列教育平台蓬勃发展。 

“网络安全靠人民”，要“靠民力”，靠的是人民的网络安全能力。所谓“兵民者，得天下”，所谓“藏兵于民，蓄力于民”。 


三、{ if 事儿 =行动 + 结果 }

2018年9月17日至23日，在成都将举办第五届国家网络安全宣传周。 

我们在看《动物世界》纪录片的时候，看到成千上万的火烈鸟聚集在一起起飞时，最令人惊奇的是每个火烈鸟不会撞在一起，因为每一只鸟都有趋避的能力。例如奔跑的野牛群等等，自身群体的秩序度同样让人敬佩不已。 

盘丝效应是一部分种类安全威胁的内在效应。就像心理学中的破窗效应一样，要解决盘破窗问题，最好不是等到整条街都破败不堪了再整治；而应当在初始比较整洁的情况下，通过各家各户的自我保护和自我修补达成整体的反“破窗效应”。 

而反“盘丝效应”也是要让整个IT及其相关系统的各个部分具有自保护自修复的能力。套用“治未病”这句话就叫“治未盘丝”，就是要持续保持一种稳定状态。 

系统除了要保持稳态之外，还要有进行跃变的能力。这种跃变，有时候是主动的，比如系统提升和改进；有时候是被动的，是系统突发事故和灾害而需要修复和全面恢复。

上述反“盘丝效应”的能力，都需要大系统的各个部件都具有较强的安全力。对应到人，就是要求安全专业服务人员（以及安全供应链上下游人员）、系统运维人员（以及系统供应链上下游人员）、普通用户都具有较强的安全能力和安全执行力，能够达成一定的安全效果。就像我们撑起一把雨伞的时候，各个伞骨的用力一样（撑伞效应）。 

再来看，网络安全到底是自己的事儿，还是谁的事儿？ 

如果，事儿代表的是“网络安全的行动”的话，网络安全绝对不仅仅是自己的行动，也不仅仅是别人的行动，而是所有人的行动且达成应有效果。 

“会做”与“做”还是有不小差距的。有意识、有能力，并不意味着就能做得出来、做得好。我们要让所有人（专业人士和普通百姓）都实际地做。要有安全实践教育、安全实操训练。 

“与其临渊羡鱼，不如退而结网”。一张好网，每根线、每个结都是有力的。 

在今年成都网络安全周期间，将举办“巅峰极客”网络安全挑战赛总决赛。此项赛事参赛人数破万，国内首个城市网络空间仿真靶场将重磅亮相，在环境规模宏大到现实城市数倍的虚拟城市“广诚市”中，模拟仿真出城市中成百上千个网络节点，多方角色将联合参与一场浓墨重彩的演习。

让错发生在靶场，让汗流在赛场，战场少出错，少流血。 

“网络安全靠人民”，要“靠民行”，靠的是人民的网络安全行为实践。


四、结语

“网络安全为人民”“靠人民”，是靠民觉、民力、民行。

有意识有观念、有知识有能力、有实践有实操的你我他组成的集合（人民），必将是建设网络强国的必要力量。 

（本文刊登于《中国信息安全》杂志2018年第9期）
