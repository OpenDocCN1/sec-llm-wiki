# 大会 | 2018第三届SSC安全峰会成功举办

2018年9月18日,第三届SSC安全峰会在中国•西安君悦酒店成功召开。本届峰会由中国信息安全测评中心、陕西省互联网信息办公室、陕西省公安厅指导，西安高新技术产业开发区管理委员会主办，西安四叶草信息技术有限公司、西安软件园发展中心承办，中国信息产业商会信息安全产业分会、陕西省科技厅信息中心、西安高新空间安全产业联盟协办。同时，本次峰会也得到了百度安全、蚂蚁金服安全响应中心、WiFi万能钥匙安全应急响应中心、平安安全应急响应中心、小米、腾讯安全应急响应中心、唯品会安全应急响应中心、小米安全中心、汉领、安信与诚、极验等企业的大力支持。

![](../Images/c253809a6788bd0f45cda47d01f88cb5.png)

中国信息产业商会信息安全产业分会常务副理事长温哲、陕西省委网信办副主任鲁世宗、陕西省公安厅副厅长张安新、西安市人民政府副市长董劲威、西安市人民政府副秘书长肖争光、中国信息产业商会信息安全产业分会秘书长位华、高新区党工委委员、管委会副主任杨华等领导出席本次峰会。

![](../Images/23ed43c614b2ea1fba0cf49b53a18e3d.png)

中国信息安全测评中心与四叶草安全成立“网络安全人才培养联合实验室”，致力于发展不同地域、领域的网络安全从业人才，不断提升从业人员素质和技能，为国家网络安全发展作出更重要的贡献。四叶草安全作为蚂蚁金服在检测领域的唯一合作伙伴，已经为蚂蚁商检平台数十万商户提供数十亿次的安全检测，在互联网金融领域四叶草安全与蚂蚁金服天穹实验室成立联合实验室，探索安全领域未来的发展方向和技术创新。

![](../Images/dc2887ed3bdb36608cd39f22baa6676b.png)

高峰论坛环节，以“智御安全•洞鉴未来”为话题，由IDF（极安客）实验室联合创始人老鹰主持,百度安全事业部总经理马杰、蚂蚁金服安全产品技术资深总监、安全产品技术负责人大师、绿色兵团创始人，WiFi万能钥匙CSOgoodwell、安全焦点的创始人，中国的第一代黑客xundi、中国第一代黑客之一，顾问级网络安全专家PP、X-Scan 和「冰河」木马作者冰河参与围绕“网络安全攻防不对等的现状”、“企业安全防御方面如何变被动式为主动防御”、“网络安全的新形势及未来新格局，新方向”等热点话题进行了精彩的分享。

![](../Images/c47056c412a40c3d34c29429a60136fe.png)

本次峰会共两天（9月18日-19日），第一天高峰论坛分为主论坛和分论坛，主论坛以引领安全新方向，探究安全新理念，共创安全新未来为主题，三大分论坛有百度安全出品的白帽子技术论坛、平安安全出品的安全技术创新论坛、唯品会安全应急响应中心出品的企业安全建设论坛分享技术干货，交流前沿技术，共享研究成果为主要内容；第二天为闭门会议，以创新人才培养模式，打造网络安全领域的专业型人才、复合型人才、领军型人才，培养网络强国路上的生力军。

![](../Images/6db61b114bcbf06f076969e04c320c58.png)

SSC安全峰会作为2018陕西省第五届国家网络安全宣传周系列活动的重要活动之一，旨在提高全民网络安全意识，营造网络安全人人有责、人人参与的良好氛围，同时，作为中西部最具盛名，影响力最大，知名度最高的网络安全峰会，旨在通过搭建“开放、共享、创新”的网络安全协同互促平台，推动国家网络安全事业整体发展，助力网络强国建设。
