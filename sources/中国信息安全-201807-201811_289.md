# 发布 | 中国信通院发布《区块链白皮书（2018年）》（附解读）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=2664113628&idx=2&sn=8d20da9d538d18f8b2820dc7bd433e2e&chksm=8b5e2725bc29ae3309b33cc333bf1e805b2c2923d653bcf712eb508da02b1e32116940f67a7c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664113628&idx=2&sn=8d20da9d538d18f8b2820dc7bd433e2e&chksm=8b5e2725bc29ae3309b33cc333bf1e805b2c2923d653bcf712eb508da02b1e32116940f67a7c&scene=27#wechat_redirect)

为推动区块链技术与实体经济深度融合，形成发展共识，中国信息通信研究院和可信区块链推进计划共同组织编写了《区块链白皮书》（2018年），并于2018年9月5日下午在中国信息通信研究院组织召开了《区块链白皮书（2018年）》发布会，同期举办了可信区块链媒体特设组成立大会。

在9月5日下午的发布会上，中国信通院和可信区块链推进计划共同发布了《区块链白皮书》（2018年）。这是中国信息通信研究院首次发布区块链白皮书，内容涵盖区块链概念特征、技术框架与趋势、发展现状、面临挑战、措施建议等多个方面。

中国信通院云计算与大数据研究所大数据部主任魏凯在白皮书发布现场为大家带来深度解读。
