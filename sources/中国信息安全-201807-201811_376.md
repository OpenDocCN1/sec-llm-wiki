# 预告 | 2018网络安全生态峰会即将举行 《中国信息安全》杂志主办软件供应链安全分论坛

8月21日至22日，由中国互联网协会联合阿里巴巴集团、蚂蚁金服和阿里云等共同主办的**“2018网络安全生态峰会”**将在北京国家会议中心举行。本次峰会将以**“共建安全防线 共治安全环境 共享安全生态”**为主题进行研讨，呼吁社会各界关注网络安全。**《中国信息安全》杂志****与阿里巴巴集团安全部共同主办的“软件供应链安全高端论坛”将于8月22日下午举行。**

![](../Images/b4375ceb3c4a10d434eb5f26af65ea65.png)

作为国内安全领域的顶级会议，8月21日峰会主论坛精心设置了六大亮点议题，包括**“前沿安全趋势”、“全球化视角看数据保护”、“AI与内容治理”、“金融安全与黑灰产治理”、“互联网+知识产权保护”和“云安全助力数字经济”等。**

峰会亮点还包括国内外参会嘉宾阵容，“政产学研”领域均有代表出席。除中央网信办、工信部和公安部三大主管机构的相关负责人，大会主办方还特别邀请了中国工程院沈昌祥院士等参会。会上，量子密码先驱Hoi-Kwong Lo教授也将做前沿安全领域的主题演讲，向现场观众分享自己多年来对未来安全的思考。

另外，来自国家信息技术安全研究中心、中国电子技术标准化研究院信息安全研究中心、中国网络空间研究院、香港警务处等机构，微软、阿里巴巴集团、蚂蚁金服、阿里云、科大讯飞等企业代表，也将分享各自在安全领域的研究和实践成果。

8月22日峰会第二天，主办方还准备了14个分论坛，将聚焦**通讯网络诈骗治理、软件供应链安全、知识产权保护、区块链安全、白帽与SRC、安全分析、数据安全、黑灰产技术对抗、应用安全、企业数字化转型安全、IoT安全、黑灰产打击治理、互联网安全标准以及创新安全等领域。**

8月22日下午，由《中国信息安全》杂志社与阿里巴巴集团安全部共同主办的“软件供应链安全高端论坛暨软件供应链大赛决赛阶段启动仪式”将在一层多功能厅A举行。论坛邀请到产业界领军人物和代表机构人员深度参与，他们将在会上发表精彩演讲、分享经验，为行业安全贡献自己的智慧。

近些年，从棱镜门事件到XcodeGhost，再从惠普驱动键盘记录后门事件，到Xshell后门、python pip源欺骗性污染、VSCODE插件钓鱼。软件供应链安全事件频发，且具有威胁对象种类多、极端隐蔽、涉及纬度广、攻击成本低回报高、检测困难等特性。举办此次论坛旨在汇聚行业智慧，促进软件供应链安全技术的发展，引起业界重视，呼吁社会高度关注软件供应链安全问题。

作为信息安全领域的权威媒体机构，《中国信息安全》长期关注网络信息安全领域政策、产业、技术、治理等话题，是国家网信领域重要媒体智库，此次主办“软件供应链安全高端论坛”，将行业问题更全面、更权威、更有深度的呈现给广大关注中国网信事业，尤其是关注网络信息安全的读者朋友！
