# 行业 | Dice：网络安全行业薪资调查

网络安全的重要性已经不言而喻，随着GDPR的施行，全球企业对用户数据保护的需求也空前高涨，而网络安全人才短缺的问题也日益严峻，但是对于准备投身，或者期望在职场升值的安全行业人士来说，如何在不断细分和专业化的安全职业岗位中选择一条能够“高薪之路”呢？哪些岗位的“薪情”看涨呢？

近日，职业招聘网站Dice在硅谷、波士顿、纽约、圣迭戈、巴尔的摩、西雅图、洛杉矶等科技公司密集的城市进行了一次美国信息安全行业薪酬调查，受访者范围限定为拥有5年以上工作经验的安全行业从业人员。结果显示，不同信息安全岗位的薪酬存在较大差异，其中网络安全工程师的薪酬最为坚挺，CISSP是最具含金量的安全认证。

Dice重点调查了网络安全从业人员（Cyber Security）、网络安全工程师（Cyber Security Engineer）和网络安全分析师（Cyber Security Analyst）三个安全岗位，下图是三个安全岗位在不同城市的薪酬区间：

![](../Images/cb922d42e8f13b8e2e048c81b1f92787.png)

![](../Images/124c677e851903f6d576b3ae872d5fe9.png)

![](../Images/a4098226049db11c94de943fe449322a.png)

从上图可以看出，如果你想要在安全行业获取不错的薪水，网络安全工程师是最具含金量的岗位，而网络安全分析师这个岗位的薪情则不会太好。

此外，调查还显示，在名目繁多的安全认证中，CISSP的含金量最高，对全行业岗位的薪酬都有提升作用，无论你是安全分析师还是安全工程师都可以从CISSP证书中获益（薪资10-15%的提升）。

最后，从下面这张图我们还可以看出，美国网络安全从业人员整体薪酬待遇不低，在刨去生活成本后，纽约、华盛顿特区、圣迭戈和波士顿是最接近硅谷信息安全人员的薪酬水平。
