# 独家盘点 | 网络安全：我眼中的2018（三）

送别2018，网络安全又迎来了新的一年。在这辞旧迎新之际，我刊特邀请业界企业管理者、技术专家、行业知名专家，发表对2018年网络安全领域的观感，讲述印象最深刻的事件，描绘2019年的发展蓝图。

  

**2018年网络安全领域出现了那些新热点？**

**预测2019年会出现哪些新的动向？**

**2018年的新热点有人工智能、隐私保护、关键信息基础设施保护等。**

**预测2019年网络安全领域的立法、安全生态、5G安全等将成为新的热点。**

  

**中国信通院互联网法律研究中心副主任 方禹**

一是网络安全顶层设计持续更新。多个国家颁布网络安全相关法案。二是个人信息保护成为重要领域。三是在线内容管理要求显著提高。四是对新型业态监管逐步形成思路，如人工智能、区块链等领域，有关政策、战略和法规均在陆续研究、制定之中。

  

**启明星辰总裁 严立**

2018年的新热点有三个：数据安全、独立运营、安全大脑。2019年，随着等保2.0和关键基础设施保护条例的发布，安全产业会有新一轮的爆发。

  

**中国网络安全审查技术与认证中心党委书记 王连印**

2018年，各国对网络安全重要性的认识提升到了新的高度，纷纷发布新的国家网络安全战略。供应链风险不断加大，单靠单一方面的力量难以实现有效的网络安全保障。因此，需要加快构建以关键信息基础设施保障为核心的，国家、行业、企业各方密切合作的集体防御体系，形成总体的国家防御能力。

  

**腾讯副总裁 丁珂**

2018年对于网络安全可以说是一个分水岭。随着移动互联网下半场向产业互联网发展，网络安全的问题由原来聚焦个人的安全到聚焦企业安全。区块链技术的兴起及理性回归、AI和大数据在安全场景的应用和价值凸显、在车联网及IoT 等新技术商业领域安全问题的暴露，给网络安全行业带来的新的挑战和思考。2019年，云和智慧产业安全挑战将成为一个全新的关注焦点。

  

**360集团董事长兼CEO 周鸿祎**

随着万物互联时代、大安全时代的到来，未来的网络安全领域会逐渐形成一种“安全生态”。城市联网后，其消防安全、交通安全、基础设施安全都需要不同领域、不同区域几十家甚至更多企业共同解决。360会用安全大数据、安全大脑对生态伙伴赋能，形成生态舰队去作战。

  

**国家能源局信息中心副主任 胡红升**

新热点：关键信息基础设施保护条例、网络安全等级保护条例的制定得到广泛关注和积极参与；工业互联网安全、个人信息保护、大数据安全等日益得到关注和重视；全国各地积极组织开展各类网络安全攻防演练。新进展：国家层面积极开展相关项目，布局工业互联网，提升工业互联网安全保障能力。2019新动向：期盼密码法、关键信息基础设施安全保护条例、网络安全等级保护条例等法规标准尽快出台，加快工业互联网安全能力建设，保护国家关键信息基础设施安全。

  

**华北电力大学能源电力大数据研究院院长 李建彬**

数据安全和工控安全是2018年网络安全领域最抢眼的两个热点。网络安全审查工作在2018年有了新的进展，落实了技术支撑机构，组建了审查队伍，开展了审查试点。2019年合规性的要求力度会进一步加大，网络安全审查工作会进一步落地，同时产业也将出现更多的独角兽企业。数据安全、工控安全和物联网安全等将出现重大技术突破。

  

**北京师范大学刑事法律科学研究院暨法学院副教授 吴沈括**

2018年数据安全已经成为网络安全领域的核心问题之一，人工智能热度空前高涨。2019年人工智能将充分运用于数据的处理，使得数据更易管理。人工智能将成为安全解决方案的核心。

  

**360企业安全集团总裁 吴云坤**

能力导向的安全体系规划和建设已经被越来越多的政企机构所接受，也将成为未来网络安全体系建设的方向，尤其是在新一代信息化系统中。利用大数据和AI技术在网络安全产品和服务中的应用加速，打造以大数据和人工智能为核心的新安全体系将成为趋势和方向。

  

**永信至诚董事长 蔡晶晶**

2018年热点可归为两类：第一 “实战”，演习和竞赛成为“非战”时态最接近实战的模拟，这方面的举措（比如“护网行动”）在2019年将继续成为引领性标杆。第二类“实力”，只有实力占优，才能实战得胜。基于大数据的人工智能技术、区块链为代表的攻击容韧技术、靶场和蜜罐为代表的第三范式仿真技术、融合大测绘大情报能力和人才梯队能力的高处置态势感知技术等四大新技术群落，2019年将在云计算、5G+物联网、工控+产业互联网、智慧城市、新金融等这五大超级应用场景下，考验业界的实力。

  

**东软集团网络安全事业部总经理 杨纪文**

等保2.0、安全可靠都是2018年的新热点，说明在网络安全上国家从顶层设计开始往下传递。2019年国家对个人信息安全保护会加强，安全可靠会更加明确和突出，国家可能会发布安全可靠的名录。

  

**绿盟科技副总裁 李晨**

政策法规是2018年最受到关注的新热点。在2019年，网络安全相关的政策法规将会逐步落地，网络安全工作将越来越有法可依。此外随着5G时代的到来，各国针对网络主导权的博弈日趋焦灼，预见在2019年国家网络安全也将成为网络安全的重中之重。

  

**阿里巴巴集团安全部资深技术专家 铁花**

网络安全领域的新热点是数据安全、区块链安全和IPv6网络安全。未来用户隐私保护和数据安全会是重点，区块链安全主要是一些传统的安全问题在新技术领域继续产生影响，针对IPv6服务的一些新型网络攻击行为开始出现。

  

**知道创宇CEO 赵伟**

2019年，预测国内的网络犯罪现象会更加猖獗，国际上网络空间的冲突会越来越激烈，大国间围绕网络安全的博弈会成为热点。

  

**美创科技总经理 柳遵梁**

2019年预测勒索和挖矿病毒攻击会成为网络安全的最大威胁，新一代端点安全将提上日程。流动数据的安全将成为优先级很高的考虑。

  

**青藤云安全创始人兼CEO 张福**

明年主机安全或成为关注的一个重点。同时人工智能可能会成为一个大趋势。

  

**清华大学软件学院教授 叶晓俊**

2018年全国信安标委大数据工作组重视的热点包括人工智能安全、智能安全（数据驱动安全）、工业互联网安全、运作安全（OpSec）等。2019年物联网安全、智能安全、业务安全等数据安全相关领域应该是一个研究方向。

  

**全国人大代表、中华全国律师协会理事会理事 方燕**

2019年，数据安全、个人信息保护以及未成年人健康成长依旧是各界重点关注的话题。大数据应用的便捷与个人隐私信息泄漏的冲突，网络直播带来的大众自我表达自由与监管缺位导致的不良网红文化渗透侵蚀的矛盾等，仍然值得社会各界去关注和深思。

  

**新华三集团安全产品线总工 涂尧**

2018年新热点：态势感知、勒索软件攻击、人工智能、机器学习、培养网络空间安全人才。2019年新动向：混合云安全、数据安全、智慧城市安全、工业互联网安全。

  

**NETSCOUT Arbor大中华区总经理 金大刚**

预测2019年数据泄密以及面向勒索的定向攻击情况会更加严重，攻击者更加务实。随着5G的逐步落地，基于互联网的IoT设备的攻击会更加频繁，造成的伤害也会更大。

  

**指掌易COO 许铭**

2018年数据安全成为核心问题；云、物联网与数字化推动身份认证等技术变革；人工智能在行为分析等领域被广泛应用。2019年可能的新动向：网络空间安全人才培养急需加强；个人数据、隐私保护将通过法律等技术手段向前推进；政企客户将进一步认识到安全服务的作用。

  

**Palo Alto Networks大中华区总裁 陈文俊**

2019年我们预测商务邮件攻击将呈增长趋势，供应链安全成为最薄弱环节，云安全持续引起业界重视，关键基础设施安全越来越至关重要，同时亚太区数据保护立法将取得进展。
