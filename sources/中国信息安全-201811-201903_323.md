# 报告 | 《2018年摄像头安全报告》：摄像头安全问题已成全球共同挑战

12月27日，北京华顺信安科技有限公司与白帽汇安全研究院联合发布《网络空间测绘系列 ——2018年摄像头安全报告》。报告显示，摄像头对公网开放的安全问题已是全世界共同面临的重要挑战。

![](../Images/98513507cd547e95fce8214e6525817c.png)

北京华顺信安科技有限公司CEO赵武表示，摄像头危害较大的原因，一方面是源于设备数量众多，安全性被使用者忽视。大量出现的廉价摄像头、监视器等物联网应用产品往往没有任何安全措施，容易被黑客控制；另一方面，物联网设备的硬件难以更新。未来，僵尸网络的规模会越来越大，攻击能力越来越强。

![](../Images/b52f7d8a4f851714cc9b0d098de01e1f.png)

  

**摄像头漏洞数量呈现爆发式增长**

在摄像头数量快速增长的同时，漏洞也快速升级，摄像头被曝光漏洞事件频发。这次发布的摄像头安全报告显示，自2017年起，摄像头漏洞呈现爆发式增长。截至2018年11月，摄像头漏洞有221条，较2017全年的186条相比，增长19%。以2018年为例，6月，Axis摄像头被ADOO安全公司发现其设备的7个安全漏洞，攻击者可以利用这些漏洞以root权限执行任意命令。8 月，Swann摄像头被发现存在访问控制缺陷，该漏洞可以将一个摄像头的视频流切换到另一个摄像头上，攻击者可以利用该漏洞访问任意摄像头。

![](../Images/25299738fdcbaf3caae2cfd3ab948bff.png)

摄像头设备存在的漏洞类型包括权限绕过、拒绝服务、信息泄漏、跨站、命令执行、缓冲区溢出、SQL注入、弱口令、设计缺陷等。其中，权限绕过、信息泄漏、代码执行等类型漏洞数量占比最高，分别占所有漏洞类型总数的23%、15%和10%。

华顺信安安全总监吴明指出，代码执行漏洞的危害与影响最大，恶意攻击者可以通过该漏洞执行植入僵尸程序，达到完整控制该程序的目的。值得关注的是,硬编码、默认密码、隐藏后门等占比 6%，此类漏洞可能是厂商或厂商被攻击者入侵而在设备中制造的后门。

  

**摄像头泄露隐私导致监管成难题**

高盛等市场研究公司发布的数据显示，截至 2017 年，全球摄像头总数约为14万亿个；到2022年，全球摄像头总量将增至44万亿个。假设全球每人都使用两台手机，全球的手机数量也不过150亿台左右。吴明认为，这一数量等级的差距决定，摄像头的监管很难做到面面俱到，也不可能像手机一样做到一对一监管。

![](../Images/25299738fdcbaf3caae2cfd3ab948bff.png)

赵武建议，摄像头设备应用的特点决定，摄像头安全问题需要国家、企业和个人共同努力，应从标准制定、资产排查、风险监测、漏洞修复等多方面提高摄像头使用的安全性。未来，网络空间测绘将成为推动摄像头安全发展的技术突破口。赵武表示，华顺信安希望通过网络空间测绘技术，从暴露情况、漏洞、隐患等多方面对摄像头应用现存的安全威胁和相关黑色产业攻击行为进行深度剖析，并利用网络空间测绘技术对摄像头进行安全排查，搭建安全防护体系，从根源上优化摄像头使用生态。
