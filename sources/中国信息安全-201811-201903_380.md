# 供应链安全 | 赛迪智库网络空间研究所刘权：加强软件供应链安全保障的对策建议

■ 赛迪智库网络空间研究所  刘权 王超

近年来，我国软件供应链不断延伸，因软件供应链遭破坏引发的网络安全事件数量也逐年上升。美国等西方国家通过限制我关键软件进口、暗埋软件后门等方式，攻击、破坏我国软件供应链，阻挠我国技术创新和产业发展。与此同时，针对软件供应链的网络攻击具有低成本、高回报、难检测等特点，也吸引着不法分子逐步将网络攻击火力向软件供应链调转，我国软件供应链面临的安全风险不断攀升。有必要深入分析我国软件供应链的安全薄弱环节，研究提出加强软件供应链安全保障的对策建议。

  

**一、我国软件供应链面临严峻的安全挑战**

**（一）西方国家限制我国关键软件进口，破坏我国软件供应链完整性**

一方面，美国等西方国家对我国实行严密的技术封锁。美国颁布了《出口管理法》《出口管理条例》等，建立了完善的出口管制法律制度体系，将软件、硬件和技术列入出口管制清单。美、澳、英、德、法、日等30多个国家共同签订了《瓦森纳协定》，对电信与信息安全、电子器件等软硬件产品实施出口管制。另一方面，美国借口国家安全，利用IT技术产业优势，多次对我国软硬件断供，肆意打压我国产业发展。2018年4月，美国政府以中兴违反美国限制向伊朗出售美国技术的制裁条款为由，禁止美国公司未来7年向中兴通讯销售零部件、商品、软件和技术。8月，又以国家安全和外交利益为由，将航天科工二院、中国电科13所等44家中国电子、航空研究机构列入出口管制“实体清单”，加大了中国企业进口相关产品的难度。

**（二）美国借助技术优势暗埋软件后门，极大推高软件供应链安全风险**

依托在IT领域的绝对技术和市场优势，美国政府多次和科技巨头合作，在相关软硬件产品内预置后门，以获取全球各国敏感数据，更好维护其在全球的霸权地位。2013年6月，“棱镜门”事件曝光，思科、微软、谷歌、Facebook等美国科技巨头在其研发、销售的产品中设置“后门”，协助美国政府对世界各国实施大规模信息监控，随时获取各国最新动态。其中，思科多款主流路由器产品被曝在VPN隧道通讯和加密模块预置“后门”，以获取密钥等核心敏感数据。12月，加密技术公司RSA被曝与美国国家安全局（NSA）达成1000万美元协议，将存在明显漏洞的“双椭圆曲线”（Dual Elliptic Curve）算法替换为RSA开发的安全软件BSafe的优先或默认随机数生成算法，方便NSA通过后门程序轻易破解各种加密数据。

**（三）软件供应链攻击成本小、回报高、影响深、危害广，已成为不法分子网络攻击的新趋势**

近年来，针对软件供应链的网络攻击日渐增多，攻击的深度和广度不断延伸，已遍布软件开发、交付、使用等上中下游环节，影响用户量级从十万到百万甚至上千万不等。在软件开发环节，针对源代码、开发工具的网络攻击具有极强的渗透性，识别、检测难度大，影响范围广泛。2017年8月，NetSarang的远程终端Xshell被植入后门代码，官方版本也受到影响，导致我国近十万用户中招；2015年9月，苹果集成开发工具Xcode被注入病毒Xcode Ghost，导致超过 4000个不同版本的苹果应用被感染，影响了中国近一亿苹果手机用户。在软件交付环节，针对网络下载、厂商预装、只读存储器（ROM）内置等重要渠道实施攻击，具有低投入、高回报等特点。国内众多未授权的第三方下载站点、云服务、共享资源、破解盗版软件等灰色软件供应链，极易被植入恶意代码，成为网络攻击的发起点和扩散源。应用商店等正规渠道审核不严，也往往成为恶意软件肆意传播的“帮凶”。在软件使用环节，攻击者经常通过劫持软件更新渠道，实施针对性攻击。2017年5月，攻击者利用petya病毒感染了M.E.Doc（乌克兰公司使用的热门会计软件）更新服务器，并向客户推送这个恶意软件更新，导致petya病毒迅速在乌克兰、俄罗斯、英国等欧洲多个国家蔓延，机场、银行ATM机及大型企业和公共设施大量沦陷。

  

**二、我国软件供应链安全薄弱环节分析**

**（一）关键软件和设计工具依赖进口，难以从源头掌控软件供应链**

当前，国际巨头牢牢控制着网信领域核心技术生态圈，我国诸多关键软件和设计工具等依赖进口。调查显示，安卓系统和IOS操作系统占据移动智能终端市场的垄断地位，市场占有率达到85%以上。思爱普（SAP）、IBM、西门子、甲骨文等国外跨国公司占据了设计软件、试验验证软件、生产流程信息化管理系统等关键核心工业软件的市场主导权，我国80%以上的核心工业软件依赖进口，国防军工业领域制造装备用操作系统95%以上购自国外，电子、航空、机械领域的研发设计软件对外依赖率分别高达90%、85%及70%。国外电子设计自动化（EDA）领域三大巨头公司铿腾电子（Cadence）、新思科技（Synopsys）及明导国际（Mentor Graphics）占据行业70% 的份额，我国89%的EDA软件由这些公司提供。

**（二）开源代码潜藏安全缺陷，极易引入新的供应链安全风险**

开源软件具有开放、共享、自由等特性，在软件开发中扮演着重要角色，已经成为软件开发的核心基础设施，软件供应链的重要组成部分。据Gartner调查显示，99%的组织在其IT系统中使用开源组件。美国弗雷斯特研究公司Forrester Research2017年的研究表明，应用软件80%-90%的代码来自于开源组件。受限于软件原始创新能力，以及便捷开发的需要，我国操作系统、数据库等基础软件，以及大量应用软件都使用了开源代码。一方面，我国对包括开源Linux内核等在内的开源代码消化掌握不足，既难以发现其中可能潜藏的漏洞和“后门”，也无法自主掌握演进方向。另一方面，开源代码的安全缺陷密度较高。据美国国家信息安全漏洞库（NVD）统计，截至2017年2月，全球开源软件相关的已知安全漏洞已超过28000个。Synopsys公司发布的《2018年开源代码安全和风险分析》报告显示，78%的开源代码库至少包含一个漏洞，平均每个代码库有64个漏洞。考虑到开源代码使用的广度和深度，一旦其安全缺陷被不法分子恶意易用，势必将对我国产生广泛、严重的安全影响。

**（三）软件供应链管控体系尚不完善，检测支撑能力有待提升**

一是软件产品网络安全审查亟需加强。尽管我国已于2017年6月发布实施《网络产品和服务安全审查办法（试行）》，将软件产品研发、测试、交付、技术支持过程中的供应链安全风险作为重点审查内容，并推动开展了云计算服务网络安全审查。但是，金融、电信等重点领域的网络安全审查仍处于起步阶段，并且较少涉及软件产品，审查、评估等配套标准仍需完善。二是对开源代码安全性的重视程度不够。早在2006年美国国土安全部就资助Coverity公司开展“开源软件代码测试计划”，对大量开源软件进行安全隐患的筛查和加固。我国缺乏国家层面的统筹谋划，对开源代码的安全检测未成体系，仅有360公司等少数企业支持开源代码安全检测。此外，我国恶意代码检测、漏洞分析、协议分析等技术能力严重不足，难以及时有效发现软件中的安全缺陷。

**（四）企业安全管理存在漏洞，加剧软件供应链安全风险**

一是企业供应链管理制度尚不完备，缺乏针对软件交付、更新等重要环节的管控措施。二是企业软件供应链透明度不高，软件供应链安全评估缺失，难以依据安全风险划分供应商安全等级，进行针对性的管理。三是部分企业开源代码管理机制尚不健全，在软件开发过程中，随意使用开源组件的现象屡见不鲜，管理者甚至程序员都无法列出完整的开源组件使用列表，给软件供应链管控带来极大挑战。

  

**三、应对之策**

**（一）开展软件产品安全审查，研判管控软件供应链安全风险**

一是及时跟踪研究美、日、欧等国家和地区相关政策对我国软件供应链安全的影响，系统分析产业链各环节、重点企业、核心技术等方面的供应商情况，针对我国软件供应链的安全状况和短板，制定系统化策略，加紧补齐。及早研判5G、人工智能、量子计算等新技术带来的软件供应链安全风险，提前谋划，制定策略性和前瞻性的应对之策。二是国家网信部门统筹协调金融、电信、交通等行业主管部门尽快启动针对软件产品的网络安全审查工作，对进入我国重要行业、领域的软件产品进行网络安全审查，重点审查软件产品研发、测试、交付、技术支持过程中的供应链安全风险，强制性提高我国软件供应链透明度。三是推动研究机构、安全企业开展开源代码安全检测服务，鼓励企业采用通过安全检测的开源代码，整体提升行业软件安全性。

**（二）突破关键软件和设计工具核心技术，消减国外软件和技术断供风险**

核心技术是国之重器。要下定决心、保持恒心、找准重心，加速推动网信领域核心技术突破。充分利用核高基重大专项、电子信息产业发展基金、技术改造专项等中央财政资金，持续加大对关键软件核心技术和设计工具等的研发和应用投入，聚焦软件核心技术创新发展方向，重点突破内核、编译器、应用程序接口（API）等操作系统关键技术，自主研发设计软件、试验验证软件、生产流程信息化管理系统等关键核心工业软件，打破国外厂商垄断，缓解国外软件和技术断供风险。着力提升恶意代码检测、漏洞分析、协议分析等技术水平，不断提高软件产品安全缺陷的发现能力。

**（三）引导企业加强安全管理，补齐软件供应链管理短板**

一是推动企业按照ICT供应链安全风险管理等国家标准要求，建立完善供应链安全管理制度，规范企业在软件研发、交付、使用等重点环节的供应链安全要求。二是引导企业建立供应商审核制度，从技术能力、产品质量、生产环境、网络安全保障、社会责任等多角度对供应商进行安全评估，量化供应商的安全级别，采取针对性的管理措施，确保软件供应链安全。三是督促企业制定开源管理策略，明确使用开源软件的基本原则，制定开源软件管理方法，采用工具核查等方式，检测并清晰记录软件开发过程中使用的开源代码，及时规避开源代码的许可证合规风险和安全漏洞风险等。

**（四）加强国际合作，营造IT产业发展良好国际环境**

我国IT产业发展壮大受益于开放创新和全球合作，应继续坚持并不断深化对外开放，一方面，针对当前中美贸易摩擦不断的困境，应冷静分析、客观应对，引导中美IT产业合作向积极方向发展，使美方不继续扩大对我软硬件核心技术的出口管制限制，为我国技术产业发展壮大争取时间。另一方面，继续贯彻“一带一路”等国际合作战略，加快“走出去”和“引进来”步伐，在关键软件、设计工具等的合作研发、采购等方面，加强与欧盟、俄罗斯、日本等国家和地区的合作，增强我国软件供应链的安全、稳定性和完整性。
