# 赛事 | 百场网络安全竞赛 永信至诚2018重大赛事盘点

2018年，在网络强国战略的号召下，为培养、选拔、激励、发现网络安全人才，网络安全竞赛在全国呈现如火如荼、百花齐放的态势。

随着网络安全竞赛的创新发展，比赛的意义现在不仅仅局限于人才的培养和选拔。一方面，网络安全竞赛在全国范围内，逐渐向金融、能源、教育等各行业延伸，提升了各行各业对网络安全的重视、对网络安全主体责任的践行。另一方面，随着网络安全竞赛演化到以“网络靶场”为基础的3.0时代，竞赛还对探索新知、方案测试、实战演练等大有裨益。

作为网络安全大赛技术支持的代表企业，永信至诚i春秋、e春秋，今年共为全国34个省级行政区、10余行业、18万人次呈现了近百场高质量网络安全竞赛。其中不乏众多“第一”和创新之处：史上最大规模的网络安全竞赛诞生，国内首个城市级网络靶场现身，三大主管机构接连赋能网络安全竞赛，人与人工智能在网络安全疆域战火不断，DEF CON首次出海...2018年的网络安竞赛如火如荼的可喜态势，为2019年后继比赛的开展奠定了良好的基础。

在新赛季即将开始之际，以永信至诚为例，让我们共同回顾2018网络安全竞赛的重要节点。

 

**序幕：第二届“强网杯”全国网络安全挑战赛**

**指导单位：中央网信办网络安全协调局**

**主办单位：解放军战略支援部队信息工程大学、郑州高新区管委会**

**协办单位：教育部高等学校信息安全专业教学指导委员会**

**技术支撑：永信至诚**

第二届强网杯全国网络安全挑战赛在2018年3月拉开帷幕，大赛是第一次真正意义上的大规模、军民融合网络安全大赛。大赛采用激烈的网络竞赛对抗模式，面向全国网信办、高校和企事业单位开启报名通道，社会各界高度关注，短短14天内，全国共2622支战队、13000余人报名参赛，其影响覆盖1000000+人。

大赛设置了共计500万的奖金，对从大赛中脱颖而出的人才给予鼓励。主办方特别邀请业内专家担任解说嘉宾，对赛场内的赛况进行直播，有效的吸引了大众对网络安全竞赛、网络安全知识的理解，让更多网络安全爱好者加入行业中来。另一方面，强网杯论坛和展会的举办，为专家、行业领袖、从业者、学生搭建了一个探索、交流的桥梁。强网论坛上，中国工程院院士邬江兴通过大数据分析，多维度的诠释了强网杯参赛规模、竞赛的激烈程度、参赛战队的水平。他指出本次大赛形成了新的网络安全竞赛标准和规范，将网络安全赛事推向了崭新的高峰。

**规模最大：“网鼎杯”网络安全大赛**

**支持单位：国家网络与信息安全信息通报中心、国家密码管理局商用密码管理办公室**

**主办单位：永信至诚**

**联合协办：360公司、阿里、百度、腾讯、中科院信工所、清华大学**

2018年8月，史上最大规模的网络安全大赛—“网鼎杯”网络安全大赛正式打响。大赛自启动报名以来就受到了社会各界的广泛关注，至报名截止，在短短的17天内，来自32个省级行政区的重要行业部门、科研机构、高等院校、职业院校、互联网企业、信息安全企业和社会力量的7000+支战队、20000+人踊跃报名参赛。在公安部的主导下，“网鼎杯”网络安全大赛全面覆盖了电子政务、金融、能源、教育、通信、交通、政法、科技、国防工业、互联网企业等关系国计民生的不同行业领域，参与人员之多，覆盖范围之广，战队阵容之豪华，堪称史上最大规模的网络安全大赛。

“网鼎杯”网络安全大赛是一次覆盖全国的技术能力大比武。通过大赛的选拔，公安部将吸纳一线的技术好手进入“网络安全千人”计划。鼓励各行业培养、选拔和善用该领域的优秀人才，最终实现网络安全能力的整体跃升。

![](../Images/ccd34ae0a36e8978fac502e7e1adfccb.png)

  

**实战演练：“广诚市”“巅峰极客”网络安全技能挑战赛**

**指导单位：四川省网信办**

**主办单位：成都市人民政府**

**承办单位：成都市网信办、成都高新区管委会、网信军民融合发展联盟自主可控信息技术专门委员会**

**技术支撑：永信至诚**

2018年9月15日-16日，2018年国家网络安全宣传周官方赛事——“巅峰极客”网络安全技能挑战赛成功举办。“巅峰极客”网络安全技能挑战赛是网络安全竞赛史上的颠覆式创新，首开国内城市网络空间攻防演练先河。如果说CTF解题模式是网络安全竞赛的1.0时代，AWD攻防模式是网络安全竞赛的2.0时代，“巅峰极客”大赛便开启了以攻防演练模式为核心的3.0时代。此次，成都联手永信至诚，以e春秋网络靶场平台为基础，打造国内首个城市网络空间仿真靶场，在虚拟城市“广诚市”的沙盘上，上演一场高度仿真城市级互联网场景、 32 小时不间断、规模宏大的竞赛演习。

大赛引入八组不同身份的参赛团队分别扮演攻击、防御、IT 系统厂商、安全厂商等角色，以丰富的关键基础设施、IoT、企业服务等 IT 系统厂商的真实产品为内容，向社会各界立体化展示城市网络遭受攻击之后诱发的连锁反应。城市靶场堪称“中国版锁盾，网络安全的朱日和”。

![](../Images/e110616dd80f066848b47362e52493f4.png)

  

**对抗人工智能：“黄鹤杯”RHG机器人网络安全大赛**

**主办单位：湖北省互联网信息办公室、武汉市互联网信息办公室、武汉临空港竞技技术开发区管委会**

**承办单位：武汉市互联网行业联合会、武汉市软件行业联合会、武汉市网络安全协会协办单位：永信至诚、百度安全**

随着人工智能的发展，网络安全也进入了人工智能时代。近年来，RHG机器人网络安全大赛开始逐渐风行。大赛不仅促进了我国人工智能技术在发掘系统未知漏洞、检索偏僻的安全隐患、推演未知风险，安全自动化方面的应用，还取得了显著的技术推广和引领生态发展的社会效益，并使我国的人工智能技术和网络安全技术获得国际社会的关注和认可。

2017年9月，首届国际机器人网络安全大赛在武汉成功举办，大赛依托永信至诚自主研发的国内首个人工智能网络安全攻防平台 — 人与机器网络攻防竞赛（简称RHG）平台，率先开启了我国网络安全人工智能攻防竞赛的序幕。2018年5月，DEFCON China百度国际网络安全技术对抗赛举办，国内外顶尖黑客战队在全新升级的RHG平台上，展开巅峰对决。2018年8月，中国网络安全技术对抗赛人工智能安全夺旗赛（AI CTF）举办，人工智能战队在历史上，首次以大比分战胜人类战队。2018年9月，“黄鹤杯”RHG机器人网络安全大赛在武汉举办，人工智能再次展现出惊人的速度，拿下全场一血，人工智能仅耗时5秒，30秒内，人工智能连续提交flag，冠军战队拿下全场4个一血，只用了19分钟，速度令人类望尘莫及。

![](../Images/76866bbadfb3e583d87e5043abd1615d.png)

  

**等保演练：全国网络安全等级保护测评能力验证与攻防比赛**

**指导单位：公安部网络安全保卫局、中国合格评定国家认可委员会**

**主办单位：中国电子科技集团公司第十五研究所**

**技术专家指导：公安部信息安全等级保护评估中心**

**技术支撑：永信至诚**

10月21日，CNAS Z0220网络安全等级保护测评能力验证与攻防比赛在北京举办，本次比赛是全国各省市自治区网络安全等级保护测评机构参与的，每年一届的大比武活动。作为国内规模最大、参与人数最多的网络安全等级保护测评能力验证赛事，大赛共吸引了全国166家网络安全等级保护测评机构,540名选手参与。本次大赛是一次规模宏大、覆盖全国的等级保护测评人员综合能力大比武，为网络运营者面对未来网络安全挑战，等保测评人员顺畅开展等保工作，打下了坚实的基础。

![](../Images/7894b126beab9d53a8d3a04564c5bb79.png)

  

**国际交流：DEF CON CHINA百度国际网络安全技术对抗赛**

**主办：DEF CON、百度安全**

**承办：永信至诚**

今年，全球网络安全领域最顶级的会议DEF CON进入中国，百度安全携手永信至诚，为国内外黑客战队、参会嘉宾和观众，打造了一场兼具挑战性、观赏性、创新性的网络安全大赛。起源于DEF CON的CTF竞赛一直是DEF CON大会的重要组成，本届大赛延续了往届DEF CON大会的传统，并融合了高度创新，将赛制分为AI程序漏洞攻防挑战赛、靶场渗透及CTF攻防对抗赛两项，十二支人类战队、四支黑客战队同场竞技，决战紫禁之巅。顶尖黑客战队同场较量、多种竞赛模式的融合，给参赛选手带来极大的心理压力和实力考验。

![](../Images/084cf8a41afe8aab74bf829903ce3336.png)

  

作为专业的赛事平台研发及网络安全赛事运营服务商，永信至诚赛事团队所支撑的大型赛事还包括2016-2018全国大学生信息安全竞赛、2016-2017WCTF国际黑客大师挑战赛、企业内网安全实战靶场对抗赛、 “企业安全众测”靶场挑战赛、全网TOP白帽挖洞大赛等。以及为各行业的大赛奉献自己的技术力量，如福建金融系统网络安全技能竞赛、中石化网络安全专业技术比武、军工网络安全攻防演练、民航网络安全职业技能竞赛等。

在2019新赛季即将开启之际，相信未来将会有越来越多的行业和企事业单位参与到网络安全赛事的运动中来，共同为培养发现人才，磨炼安全技能，提升安全水平做出努力。期待行业中永信至诚这样的赛事支撑平台，开发出更前沿、更丰富、更创新、更接地气的实战训练场，助力我国网络安全事业蓬勃发展。
