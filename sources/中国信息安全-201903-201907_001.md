# 赛事 | 2019 WCTF世界黑客大师赛落幕 中国战队再度夺冠

7月7日，历经“夺旗厮杀”和“复盘分享”两轮鏖战，为期3天的2019 WCTF世界黑客大师赛在360总部决出胜负。

![](../Images/958434dc722acb2c595d5ce32c7f35e8.png)

**冠军团队中国台湾217战队**

中国台湾217战队以2133分的“碾压性”战绩捧得冠军奖杯，获取5万美元奖励，波兰的Dragon Sector战队夺得亚军，中国战队r3kapig则击败上届三强，获得第三名的佳绩。这是继2016年的首冠，中国台湾217战队又一次获得WCTF总冠军的殊荣。来自中国的战队成绩傲然，不仅包揽了冠、季军，去年刚拿下2018 WCTF新锐赛冠军，闯进WCTF大师赛的中国新秀Nu1L战队，今年成功斩获六道赛题，挺进六强，扛起了中国网安“青年军团”的大旗。

![](../Images/6327e0bf3b14e1710018bfca839ef097.png)

**中国新秀Nu1L战队**

  

**顶端战队赛场实战切磋**

2019 WCTF世界黑客大师赛是由360公司赞助，世界知名安全团队360Vulcan主办的国际级CTF挑战赛，自2016年创办以来，一直秉持着定向邀请全球TOP10黑客大师来华参赛的操作模式。2019 WCTF主办方邀请到了波兰Google安全团队Dragon Sector、法国瑞士联合战队0daysober、日本战队TokyoWesterns、美国战队Shellphish、德国战队Eat,Sleep,Pwn,Repeat、俄罗斯战队LC↯BC、韩国战队Cykor，以及NU1L、r3kapig和217三支来自中国网安领域的顶尖战队。

![](../Images/77e04f42b09a2c76f177b212c8d642d7.png)

2019 WCTF在赛题设置上，重点关注实战切磋，主要方向有破解安全硬件和浏览器漏洞、虚拟机逃逸等。网络世界如今充斥着形形色色的安全硬件产品，比赛真实还原网络战情景，模拟攻防实战，号召全球黑客超级战队，向硬件安全发起“进攻”，探索硬件的安全边界。同时，浏览器漏洞已成为攻击者的常用武器，比赛力求破解浏览器漏洞的攻防密技，定点突击破局漏洞威胁。

除高端的大师级黑客实战攻防外，WCTF还延续了2018 WCTF赛场上增设的“高校新锐赛”演兵场，定向邀请清华、复旦、北航、西安电子、成信大、中国科学院等十所顶尖高校的青年网安战队，与大师战队同台试炼，“以赛代练”在实兵攻防中提升中国网安青年战队的技术与实力，并致力于中国网安新生力量的培养与输出，构建应对未来网络战的后备军。

  

**优化赛制打造国际视野**

360集团助理总裁郑文彬在采访中表示，WCTF旨在为全球顶尖黑客打造一个切磋的交流平台，创立四年来一直立足新视野、新技术，致力于构建最贴近实战标准、实战环境的网安战场，在实战攻防中为网安建设带来新的灵感与思路，挖掘网安人才助力技术提升。

![](../Images/544fcd0cd4344b831e79c32c2d02443c.png)

反映到2019 WCTF上，就是赛制和比赛场景的进一步优化。郑文彬介绍，今年线上赛共计有600多支队伍参与，保证比赛高水平的同时，也吸引了更多国际战队的目光。针对去年新锐赛题目较难的情况，今年对新锐赛做了更适合的出题优化，让新锐战队可以更好地参与其中。同时去年新锐赛的冠军NU1L，今年也已经晋级到大师赛中，取得了不错的成绩，显示出新锐赛对人才选拔的推动作用。

郑文彬强调，本次2019 WCTF比往届更加接近真实的攻防，比赛模拟了很多真实的网络攻击，在实际比赛中也出现了日常安全防护中遇到的极端情况，让战队不仅是在展示攻击和防守技术，也要考虑实战中可能遇到的冷门场景。

本次比赛在赛制上还增加了对最佳赛题的评比，让战队彼此出题时不再单纯强调难度而是综合质量，大力奖励出题质量高的战队。在分享问答环节，评委会根据innovative、reasonable、stable、flawless四个维度，对赛题给予评分，让安全从业者近距离学习世界顶级黑客的技术思路，思维模式和安全智慧。美国战队Shellphish凭借上述四个维度的优势，成功拿下349.46分，荣膺2019 WCTF全新设立的“最佳赛题奖”（Best Challenge）。

![](../Images/1b15ca7416137d25bb6554303c11cc36.png)

**美国Shellphish战队获得“最佳赛题奖”**

WCTF世界黑客大师赛主办方360Vulcan团队作为360互联网安全创新中心旗下的二进制漏洞安全团队，多名成员入选微软全球Top100贡献榜，且多次获得微软Bluehat、Edge浏览器赏金项目奖励，一直通过实际行动致力于网安生态的构建。创办WCTF世界黑客大师赛，就是以打造全球性网安交流平台为发展目标，创建网安“实战”空间，加速强化中国网安力量，致力于培养中国自己的网安“尖兵”。
