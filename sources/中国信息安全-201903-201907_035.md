# 招募 | CSS 2019 Future Power 50安全新锐启动新成员招募

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=2664118904&idx=3&sn=77f1044768992971f7d257faf0aa4e5d&chksm=8b5e3881bc29b197119a6d9a36dac6eb708f793bdd029f01e64799d7cca9c6809461423fdc3c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664118904&idx=3&sn=77f1044768992971f7d257faf0aa4e5d&chksm=8b5e3881bc29b197119a6d9a36dac6eb708f793bdd029f01e64799d7cca9c6809461423fdc3c&scene=27#wechat_redirect)

在2018年的互联网安全领袖峰会（CSS）上，知道创宇与腾讯安全联合举办FP50分论坛，通过汇集重要行业权威专家的意见，发掘推选出30家代表安全行业未来发展的新锐企业，并共同成立了FP50安全新锐力量俱乐部。

![](../Images/c05baa1817830a224ee188384f8d1fb0.png)

FP50的出世，旨在聚集安全行业未来担当，搭建交流平台，展示企业潜力，为带动行业新一轮快速发展注入“Future Power”。

伴随产业互联网时代的开启，安全行业将迎来全新的机遇与挑战，今年CSS 2019的FP50分论坛，将以“行业新担当，聚力赢未来”为主题，聚合更多优秀的安全行业新锐力量企业，打造业内新型生态平台，并共享标杆案例经验，启迪安全行业创新成长。

![](../Images/07ceb2a01e2fe66a25254057ff2208c9.png)

在本月上旬举办的FP50俱乐部沙龙中，FP50安全新锐力量分论坛希望通过安全新锐俱乐部，为更多的新兴企业提供一个平台，吸引更多的企业加入进来，推动行业发展，为行业不断造血。

在此，FP50俱乐部正式启动新成员招募，真诚向业界安全企业发出邀请，如果您拥有首屈一指的技术创新力、耳目一新的商业模式、未来广阔的蓝海市场、抑或是业界典范的用户实例，期待您的加入，为FP50注入鲜活血液和未来力量，共同推动安全行业的下一轮发展。

**企业报名条件：**

1、公司业务范围为网络安全相关；

2、公司注册地在中国境内；

3、公司法人是中国国籍公民；

4、公司规模不低于50人；

5、公司成立时间在一年以上。

**企业参与流程：**

1、即日起至2019年7月7日，发送“企业名称+联系人+联系电话”至会务组邮箱fp50@mail.thecss.cn进行报名；

2、报名邮件发出后，会务组（fp50@mail.thecss.cn）将在两日内发回《Future Power 50新锐安全力量评选调查表》；

3、请企业于2019年7月9日前反馈《Future Power 50新锐安全力量评选调查表》；

4、2019年7月22日- 30日参与结果反馈及后续工作对接；

5、活动时间：2019年7月31日。

本次俱乐部成员纳新将继续由资深行业专家、权威媒体、创投机构等组成招募评审团队，并新增安全牛主编、谷安天下副总裁李少鹏，北京赛博英杰公司创始人谭晓生，《信息网络安全》杂志主编关非三名专家评委，将继续秉承开放、公开的原则，根据资本、人员、技术、市场四大板块，从企业融资情况及估值、创始人团队及组织架构、技术创新性及优势、市场规模、未来市场空间、客户验证等多维细分领域进行综合考察，审慎推选出能够代表安全行业未来的新兴力量。最终评审结果将在7月31日举行的CSS 2019的FP50分论坛上揭晓，入围企业也将正式加入FP50安全新锐力量俱乐部。

产业互联网时代的大门开启，安全行业的发展和变化风起云涌，FP50俱乐部希望促进行业的良性交流，为大家争取更多合作空间，同时通过FP50的品牌号召力，彰显大家的创新与实力。你，就是未来的力量，FP50在这敞开大门！
