# 聚焦 | 院士专家纵论互联网基础资源与网信新技术大势

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=2664118904&idx=2&sn=9a4c047c736559ab831bc7c1c9eccfbc&chksm=8b5e3881bc29b197c31d5a9933de43b7f50f6986fe7dc12755bdea130d4ba97df46a72846974&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664118904&idx=2&sn=9a4c047c736559ab831bc7c1c9eccfbc&chksm=8b5e3881bc29b197c31d5a9933de43b7f50f6986fe7dc12755bdea130d4ba97df46a72846974&scene=27#wechat_redirect)

6月30日，由国家互联网信息办公室指导，中国互联网络信息中心（CNNIC）主办的“中国互联网基础资源大会 2019”（China Internet Infrastructure Resources Conference，CNIRC 2019）在京举行。国家互联网信息办公室副主任杨小伟出席大会并致开幕辞，中国工程院院士、中国科学院原副院长胡启恒出席大会，多位院士和知名专家作主旨报告和技术报告。

![](../Images/d0f6ddd9219f4737c4a9ef6eb2bc7ce7.png)

国家信息化专家咨询委员会常务副主任周宏仁指出，物联网的发展进入了一个新时期，即“全联网（全球物联网）”时期，全联网带来全球信息化发展的新的重大拐点。全联网所带来的海量的“人、机、物”数据的不同组合，将极大地推动云计算产业、大数据产业、人工智能、网络服务业的创新发展。全联网发展的前提和关键是在“物”上。“智能产品”为全社会、全产业提供广阔的创新和创业空间，提供了一个真正的“八仙过海，各显神通”的平台。

![](../Images/0e293ecfb9a1a81ad86feae739825a57.png)

中国工程院院士邬贺铨指出，从通信基础设施物理层的资源来看，我国城市人口密集，宽带移动通信频谱不足的矛盾十分突出。5G的发展需要更多的频谱资源，除了向更高频段扩展外，原用于2G/3G的频段可以通过频率重耕转为5G频谱。从通信基础设施网络层资源来看，中国获得IPv6的全球地址数是全球第一的，但是路由通告率相对较少，我们要大力加快IPv6的使用。

![](../Images/4dadf8eac03337e4f73fc37476222c52.png)

中国工程院院士倪光南指出，网络安全的核心是技术安全,不但像传统安全一样要求有“安全性”,而且还要求有网络安全特有的“可控性”。我国网信领域尤其是关键核心技术要加强自主可控，应当将自主可控作为达到技术安全和网络安全的必要条件。

![](../Images/478c16836bc9f9899b4ab09d00cae6a2.png)

中国工程院院士刘韵洁认为，工业互联网、全息通信、8K/VR等业务的发展，对网络提出了一系列新的要求与挑战，未来网络/B5G/6G将有十分巨大的前景。陆海空天一体化网络、网络虚拟化/切片、确定性网络、光+IP、边缘计算、网络人工智能、开放开源等创新技术趋势正在深入影响和变革网络产业形态，亟需加强网络2030技术布局与攻关。

![](../Images/0c0c51a305536e3e2d589511f9427203.png)

中国工业互联网研究院院长徐晓兰指出，工业互联网是人工智能、物联网、云计算、边缘计算、5G等新一代信息技术与工业技术深度融合应用的主战场，将极大地影响新一轮工业经济格局调整，深刻影响未来全球经济发展格局。工业互联网实现的全面数字化网络化智能化，有利于企业大幅度提质增效降本减存，促进制造业优质升级发展。同时，对优化工业存量，壮大现代制造业增量，促进一二三产业、大中小企业融通发展意义重大，从而推动产业价值链向高端延伸，促进经济高质量发展。

![](../Images/71f37a45fb828fba14f07a685f29f3b6.png)

中国科学院计算机网络信息中心主任廖方宇指出，数据与智能计算是新型互联网基础资源的核心支撑手段。要构建基于大数据与AI驱动的新型可演进网络体系架构，实现云网融合、边云协同。他表示，建立传输、计算、存储一体化的新型网络体系构架将有可能满足今后互联网基础设施不断发展的需求。

![](../Images/e3395e56a75b880da5465448b26c35ec.png)

世界区块链组织首席科学家白硕指出，区块链在跨境支付、国际汇兑、开放金融方面成为传统技术实现方式的有力竞争者，要积极应对，抢抓机遇。要充分发挥我国在移动支付方面的先发优势，充分挖掘在区块链技术实现与业务落地方面的巨大潜力。

![](../Images/1301c453183483ca904bbbf7dc8ffcf3.png)

中国互联网络信息中心（CNNIC）主任曾宇在会上作了题为《以新型域名解析架构保障我国数字经济发展》的技术报告，他指出，域名系统是我国数字经济发展的重要基石，基于共治链的共治根解析架构可实现域名解析的无中心化、各方参与、平等开放、用户透明、兼容可演进、高效可扩展、可监管，该架构符合全球互联网治理多利益相关方的共治理念并兼容当下域名解析体系，是保障国家网络空间主权的可行路径之一。

![](../Images/76ad5864c27db8867c576bc32a2e2f28.png)

据悉，本次大会会期一天，共举办6个分论坛：互联网基础资源技术发布会、域名行业合作与发展高峰论坛、IPv6技术创新与应用推广论坛、互联网基础安全论坛、前沿技术与自主创新论坛、中国互联网25周年暨国家顶级域名开通25周年座谈会。国家互联网应急中心、中国信息安全测评中心、电子一所、电子四院等相关机构，清华大学、北京大学、北京邮电大学等高等院校学者，复旦大学、哈尔滨工业大学、中国人民公安大学等网络空间国际治理研究基地专家，中国电信、中国联通、中国移动等电信运营商，华为、中兴、阿里巴巴、腾讯、百度、小米、360等互联网企业界代表，国家域名注册机构代表，IPv6联盟会员等近千人参加大会，并在分论坛上发表精彩观点。
