# 预告 | CSS大会产业与安全标准化分论坛将于7月31日在京举办 鹅门标局专属票务通道开启

互联网安全领袖峰会（Cyber Security Summit，CSS）由腾讯与企事业单位联合主办，自2015年首届举办以来，已吸引超过数万名行业精英参会，超过500家国内外顶尖企业与会，百位国内外大咖莅临分享前瞻观点。CSS已经成为全球规模最大、最有影响力的互联网安全合作交流平台，是安全行业和企业不容错过的世界级安全盛会。

CSS 2019峰会期间，腾讯安全和腾讯标准将于2019年7月31日下午在北京国际饭店联合举办“产业与安全标准化分论坛”，并发布腾讯标准化团队打造的《腾讯产业与安全标准化白皮书》。届时，还将邀请各行各业专家，围绕这一主题展开深入研讨。

CSS 2019以“产业升级 安全升维”为主题，围绕金融安全、云安全、大数据安全、大交通安全、产业与安全标准化等议题展开，同时，邀请来自国内外的重磅嘉宾，包括亚马逊、IDC、三一重工等不同领域的企业负责人，国内知名工程院院士，共同探讨产业安全的未来与机遇。

鹅门标局为粉丝开启专属的限时免费票务通道，扫码关注“鹅门标局”公众号，在对话框发送“CSS”，获取CSS大会及分论坛通关密码。
