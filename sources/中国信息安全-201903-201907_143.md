# 法治 | 篡改存单骗贷款，50元变50万元——警方破获贷款诈骗案

最近，有不法分子瞄准了**银行的贷款业务**。

  

通常，银行的各类存款数据个人是不能随意修改的，但是近日，上海警方就破获了一起贷款诈骗案，犯罪嫌疑人通过篡改存款金额骗取了巨额贷款。

  

而其中一名叫马某的犯罪嫌疑人，在短短半年间，从负债累累摇身一变，成了住别墅、开豪车的有钱人......

  

**篡改存单骗贷款 50元变50万元**

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_846781809642848260](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_846781809642848260)

  

![](../Images/3ce233ad686367579aaa24a3819fa030.png)

  

**上海市公安局松江分局刑侦支队反电诈队队长 陈琦**：我们接到银行报警，有张银行卡有虚开存款单、套取银行贷款的情况，从他们统计的这一张银行卡，涉案金额一共是300多万。

  

据银行工作人员介绍，只要有这家银行没有到期的定期存单，就能在线申请不超过存单金额的90%的贷款。

  

可是，到了2018年9月底，该银行上海松江支行工作人员却发现，**有人利用银行安全漏洞，篡改了账户内的存款数额，进而骗取大额贷款，50元存单就骗取了近50万元贷款**。

  

![](../Images/0c58ee7673e7d008d7c7671faa808721.png)

  

**上海市公安局松江分局刑侦支队反电诈队探长 陈捷**：他把50块钱存款修改成了50万元，变成50万元之后，银行贷款服务器上面就审批通过了他的贷款申请，他就把这近50万元给贷出来了。

  

接到报警后，上海松江警方立即成立专案组展开调查。经过统计，民警发现共有五个账户涉嫌用同一手法来骗取贷款。**总涉及贷款金额约3000万元**。

  

![](../Images/0a052c5c04bfbb551cf720659d57c303.png)

  

经过进一步调查，警方发现，有人冒用身份获取了这些银行账户，通过银行流水单，警方锁定了一名嫌疑人。这名年轻男子多次驾车前往银行存款，但每次都只存了200元。

  

通过大量的视频追踪工作，民警发现了嫌疑人的行动规律。

  

**上海市公安局松江分局刑侦支队反电诈队探长 陈捷**：我们发现这辆车，基本上每天晚上半夜之后呢，会停到一个酒店的停车场去，然后这个司机会下车去上夜班。掌握了这条线索之后，我们才顺藤摸瓜，把这个司机的身份给掌握了。

  

![](../Images/f944ce996db9ed47fed6ff279a993fbe.png)

  

掌握这名嫌疑人的身份后，专案组民警针对其名下的房产、车辆及其银行卡资金进行进一步的梳理，发现了另外三名嫌疑人，随即将四人同时抓捕。

**诈骗贷款百余次 金额近3000万元**

  

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_846781399205036034](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_846781399205036034)

  

通过对四名嫌疑人的讯问，警方发现，其中一名叫马某的男子，一直在暗中指挥着其他人，而马某则在短短半年间，从负债累累摇身一变成了有钱人。

  

**上海市公安局松江分局刑侦支队反电诈队探长 陈捷**：他平时没有正当工作，但是住的是大别墅，开的都是豪车，我们在他的别墅门口发现停了三四辆名贵跑车，那我就问他，你这个钱哪里来的？当时他就有点接不上话。

  

面对民警提出的问题，犯罪嫌疑人马某最终如实交代了他利用银行漏洞进行贷款诈骗的行为。

  

![](../Images/d11af65637846460eb885520067d1d4a.png)

  

**犯罪嫌疑人 马某**：我无意当中发现这个漏洞，对计算机方面比较了解，想一想或许能存在漏洞，就去试了一下。

  

通过技术，马某把自己50元的定期存单篡改成了50万元，在网银上发起了定期存单质押的贷款申请。

  

令他没有想到的是**这次修改竟然通过了银行的系统审核**。自此，马某开始了他的犯罪之路。到被捕前，**马某共诈骗贷款100多次，金额近3000万元**。

  

![](../Images/afd9b90fc7653c79899df2fae45f486f.png)

  

目前，犯罪嫌疑人马某因贷款诈骗罪已被上海市松江区人民检察院批准逮捕。案件还在进一步审理中。
