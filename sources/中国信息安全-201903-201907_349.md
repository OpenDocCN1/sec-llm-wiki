# 聚焦 | 网络安全同担，网络生活共享——第六届“4.29首都网络安全日”系列活动在京举行

4月29日，第六届首都网络安全日在北京展览馆开幕，本届活动继续以“网络安全同担 网络生活共享”为宗旨，以“一个核心、两大定位、三个重点、四大领域”为框架，即以“网络强国战略思想”为核心，突出“首善”“安全”两大定位，明确“法治主题”“定制化特色”“全媒体覆盖”的工作重点，围绕“全民普及教育、产业引领发展、人才培养推树、文化价值传播”四大领域统筹设计。

“4.29首都网络安全日”自2014年正式举办至今，逐步成为北京乃至全国网络安全领域的重要活动之一，在普及网络安全知识、培育网络安全人才、传播网络正能量等方面发挥了不可替代的作用。随着互联网技术的飞速发展，各类网络违法犯罪问题日益增多，网络乱象亟待整治。如何运用法治思维打击整治网络违法犯罪问题，有效净化网络环境，进一步提升网络综合治理法治化水平，值得深入探讨和交流。

本届“首都网络安全日”系列活动活动自28日至30日共计3天。除“网络空间法治化治理”等主题论坛外，还包括“净网2019”专项行动主题宣传活动、“净网2019——全民网络安全教育展”、 网络安全技术大赛、网络安全文化作品征集活动颁奖仪式、网络安全系列高峰论坛等特色活动，为广大市民呈现丰盛的网络安全盛宴。

  

**各大论坛精彩纷呈**

作为本届系列活动的“重头戏”，由北京市委网信办、北京市公安局联合北京市互联网法院共同举办的“网络空间法治化治理”主题论坛活动，于4月29日上午在北京展览馆如期举行。

论坛首先举行了《网络空间法治化治理白皮书》发布仪式，该《白皮书》由北京市公安局网络安全保卫总队与北京互联网法院联合编写，内容涵盖严厉打击涉网违法犯罪、依法保护公民人身财产安全、努力营造风清气正网络空间、创新发展互联网版“枫桥经验”、积极参与社会综合治理等方面，梳理分析了互联网违法犯罪案件规律特点，回顾总结近年来涉网犯罪打击成效，致力于完善首都网络空间法治化治理体系，探索互联网背景下司法协作新路径，凝聚社会各界力量，打造网络空间生态。

随后，论坛以“网络空间法治化治理”为主题，邀请中国政法大学刑事司法学院院长曲新久教授、最高人民法院喻海松副处长、公安部网安局翟晓飞副处长和部分企业代表进行主题演讲，从关键信息基础设施防护、移动互联网应用安全治理、区块链技术与应用、等级保护、政务数据安全等角度，共同探讨“互联网+”时代背景下网络安全领域的新思路、新技术、新手段，破局当下网络安全方面存在的威胁与挑战，全方位分析网络安全发展现状及未来趋势。

活动期间，同期共举办了10场网络安全主题高峰论坛，围绕网络安全、关键信息基础设施保护、人工智能、物联网安全、身份认证、金融安全、智慧城市建设等内容进行深入交流探讨。

  

**“净网2019” 维护清朗网络空间**

北京市公安局在“4.29首都网络安全日”活动期间，在北京展览馆举办“净网2019”主题宣传活动，介绍了“净网”专项行动开展以来取得的战果，并倡导警、企、民携手，重拳打击、强化清理、做实监管、乘势宣传，共同深入推进“净网”专项行动，维护清朗网络空间。北京网安总队还发起了重拳打击涉网违法犯罪，深入推进“净网2019”专项行动的倡议。

同时，北京市公安局还主办了“净网2019——全民网络安全教育展”，旨在集中展示公安机关“净网2019”专项行动阶段性成效，进一步震慑网络不法人员，系统宣传普及网络安全基础知识，进一步提升全民网络安全意识，持续凝聚社会共识，进一步筑牢坚实有力网络安全屏障。

![](../Images/2aa40956bc2b1c0468dd9434ba89711e.png)

“净网2019——全民网络安全教育展”分为“净网”专项行动成果篇、全民网络安全教育篇、感知体验篇三个部分，集图文说明、实物展示和技术体验于一体，汇聚北京市公安局、北京市互联网法院、相关知名互联网企业于一堂，既是公安机关会同各行各业主动作为的成绩单，也是为人民群众精心制作的科普书，更是同筑网络安全防线的邀请函。

  

**“虎鲸杯”大赛聚焦电子数据取证**

为培养高素质网络安全和信息化人才，在第六届“首都网络安全日”期间，由公安部网安局指导，北京市公安局与中国人民公安大学于4月29日在北京展览馆联合举办了“虎鲸杯”全国大学生电子数据取证比赛。   

此次大赛以人才培养推树为着力点，聚焦电子数据取证这一网络安全范畴内的专业领域，其目的是进一步加强电子数据取证后备人才培养，探索网络安全学科建设的新模式，加强校际网络安全学科专业沟通交流，促进网络安全教学单位与实战部门合作共建。

![](../Images/c1d31631d2911ce099ced5a69957a142.png)

比赛共有来自全国56所著名院校的100支代表队报名参赛。与以往不同的是，竞赛队伍不再是专业机构的职业队伍，而是一次面向全国大学生的技术交流盛会。参赛院校也不局限于公安司法类院校，只要开设有网络安全相关专业，对电子数据取证抱有研究热情的院校均可组队参赛。

经过紧张的角逐，来自南京森林警察学院的森林狼一队获得大赛的团队一等奖，来自重庆警察学院、浙江警察学院、铁道警察学院的三支战队获得二等奖，浙江警察学院、山东警察学院、湖北警官学院、中国人民公安大学、天津理工大学、重庆邮电大学等院校的六支战队获得三等奖。

  

**“清朗杯”网络安全文化作品征选充满新意**

4月29日，在北京展览馆还举办了首届“清朗杯”网络安全文化作品征集活动颁奖典礼，这也是第六届“4.29首都网络安全日”系列活动的新亮点。

本届“清朗杯”以“共筑健康清朗网络，同谱文化自信新篇”为主题，旨在提升社会各界对网络安全的关注度，培育健康向上的网络文化，倡导全民学习了解网络安全相关知识，打造清朗网络空间。活动面向全社会，历时一个半月，得到了社会各界的积极响应，共收到来自企业和个人投递的作品百余部。

![](../Images/098be8a27ea3f836fcca92e5b0199df5.png)

经过前期评委会集中评选，10部作品脱颖而出，其中《绿色网络与你同行》摘得美术类最佳作品奖，《太阳花开》摘得文学类最佳作品奖，《绿色网络是精彩》摘得音乐类最佳作品奖，《网络安，国家安》和《5G来啦！》获得美术类优秀作品奖，《无名英雄》和《不遗余力，筑牢网络安全》获得文学类优秀作品奖，《爱在清朗》和《擦亮你的眼睛》获得音乐类优秀作品奖，中长篇小说《“零日”追踪》获得评委会特别奖。央视网、千龙网、新浪网、搜狐网、百度、360、新浪微博、今日头条、滴滴出行、优酷网、爱奇艺、乐视网等12家网站荣获优秀组织奖。

“4.29首都网络安全日”系列活动吸引了国内外上万名网络从业者、政府信息安全相关人员、信息安全相关企业人员、科研院校专家学者、行业用户、网民群众、媒体等参与，共同为推进新时代网络安全提供智慧、贡献力量，携手为建立网络综合治理体系，营造清朗的网络空间而不懈奋斗。
