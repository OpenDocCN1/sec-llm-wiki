# 行业 | 2019华为网络安全中国行 “平凡到不凡，没有捷径”

2019年，华为网络安全中国行还是从北京首站始发，计划历经济南、郑州、深圳、广州、杭州、南京和上海，共8个城市。促进中国区华为安全品牌认知度、促进销售额提升的2018年首届华为网络安全中国行，在北京、上海、广州、南京、济南等地打造了SDSec（软件定义安全）品牌。2019华为网络安全中国行将从思想、技术、生态等方面，构建华为网络安全在中国区的领导者形象，全新打造HiSec安全品牌，表明“平凡到不凡，没有捷径”的价值观。

![](../Images/8166af0a658a9c133b5c796919e43e00.png)

**华为安全产品领域总裁宋端智**

  

**网络安全产业发展不能追寻捷径**

华为安全产品领域总裁宋端智介绍，华为网络安全中国行会促进网络安全生态建设。在活动过程中，华为推广生态、推广伙伴，只要有更多的客户选择，伙伴也会跟着被选择，这就是网络生态的价值。宋端智说：“大家看到，我们生态的理念和方式，对未来和睦相处有很大的帮助”。

近些年，中国很多企业在追逐所谓的风口，希望能够寻找一夜暴富的捷径。过去几年，包括共享经济、O2O、区块链、人工智能等，各种风口此起彼伏。宋端智认为，在这个过程中，有些人一夜暴富，但是，大部分接盘者苦不堪言，甚至最终是一地鸡毛。例如，在共享经济领域，如果所有共享单车创业者都能够踏踏实实地一点点扩张，不断提升单车本身的质量、水平，包括运营效率、合适的收入和利润，不断往前演进，共享单车不会是今天这个状况。

宋端智分析，追求捷径在网络安全领域也是存在的。网络安全是一个长周期的风口，在未来二十年、三十年，都是一个不断持续增长的产业，因为网络安全问题始终没有被解决。在这种情况下，网络安全产业面临的挑战非常大，面临的空间不断增长。在最大的风口下，还有更多小的风口，大数据、人工智能、区块链、自适应、拟态安全等新概念层出不穷，很多人追逐这个风口，希望通过一个理念赚更多的钱，达到一夜暴富的目的。很多人说，安全老三样已经过时了，防火墙、IPS、杀毒软件，提这个，很难获得投资者信任，很难跟客户交流。实际上，据华为统计，客户80%的问题还是通过老三样解决的。

宋端智介绍，不管是新技术、新概念还是老三样，每个技术、每种产品只要认认真真去做，都可能做成一个绝世武功。如果都浅尝辄止，可能得到短期利益，然而，长期来看，可能会收效甚微。网络安全产业如果想做好，一定不是靠追寻捷径的方式。如果想从当前的平凡走向不凡，一定不是寻找捷径，而是脚踏实地向前迈进。

![](../Images/73b9a0885deb4a98726ba5ed2a3cc418.png)

  

**网络安全领域扎实投入20年**

实际上，华为已经在网络安全领域“扎扎实实投入了20年”。在这20年，华为在网络安全技术研究、安全产品技术开发上都有长足的投入，在软件、硬件、算法等方面都有持续的积累。截至2018年年底，华为网络安全相关的发明专利超过2900项，其中，超过80%是国际专利。此外，华为在全球有8个安全研发团队，其中，包括北美和欧洲的团队。

宋端智介绍，截至目前，华为在网络安全上投入2500名研发人员。2018年，华为在网络安全领域的投资超过48亿元人民币，其中，包括芯片、人工智能等方面。华为在安全芯片上做了很多的工作，一是芯片加持，二是发挥芯片能力自研引擎。例如，华为手机麒麟芯片，在2018年实现了GPU的突破，能够大幅度提升用户玩游戏时的性能，这是要软件和芯片结合的能力才能做到。

除了芯片、AI等先进技术，华为也在传统技术上持续投入。例如，在病毒检测引擎方面，华为研发了自己的病毒检测引擎CDE（Content-Based Detection Engine）。目前，CDE已获得了十多个专利，扎扎实实将恶意软件检测能力做到了国际领先。CDE引擎被应用于华为防火墙、沙箱等产品，结合AI引擎，华为安全产品不断提升恶意软件的检测能力。

  

**有效协同华为产品和生态伙伴的产品**

宋端智表示，“华为安全要把自己能做的做好，同时，希望安全产业生态合作伙伴能够把他们擅长的、聚焦的产品做好，大家形成合力为客户提供更加完善而高效的安全防护。”

2018年3月，华为成立华为安全商业联盟，就是希望通过统一的解决方案架构，基于软件定义安全的解决方案架构和标准接口，将华为的产品和生态伙伴的产品有效协同起来，形成一整套安全方案，给客户提供完整的保护。这个联盟的目的不是“抱团取暖”，而是希望“有效联动，给客户提供更好的保护效率”。例如，在华为的客户界面销售推广方案，能够有更多收入和利润，进一步投资做好这样的产品，进一步形成良性循环，让方案更加完善。在这种情况下，可以做到与客户和生态合作伙伴，多方共赢。

在华为价值观中，从来没有终点，宋端智说：“我们上一刻的技术突破、产品突破，都是下一刻故事的开始，我们希望能够一步接着一步，在不断进步中更好地服务客户。”

宋端智认为，网络安全产业从平凡到不凡，没有捷径，希望能够通过脚踏实地、一步一个脚印的态度和践行，走向不凡，同时，希望通过华为安全商业联盟的生态吸引更多的伙伴加入，促进中国安全产业健康发展，“在不走捷径的路上，共同给我们的客户、我们的国家在网络安全上更多的信心。”
