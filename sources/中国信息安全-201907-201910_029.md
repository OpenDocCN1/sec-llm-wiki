# 观点 | 强化网络基础管理，筑牢数字经济发展基础

习近平总书记指出，“新常态要有新动力，数字经济在这方面可以大有作为”。数字经济已成为推动我国经济高质量发展的新动力。数字经济依托互联网高速生成、传送、处理信息功能而进行，载体是电信网的数据服务。电信主管部门承担网络建设、网站准入、信息交互、网络安全等网络基础管理，目标是营造通畅、有序、安全运行的网络。强化网络基础管理，是构建良好网络运行环境、筑牢数字经济发展的网络基础的需要。  

  

**一、电信网是数字经济发展的网络基础**

**（一）电信设施是发展数字经济的物质基础**  

互联网深刻改变和影响了人们的生产生活。人们接受互联网服务，业者提供互联网服务，均要接受和使用电信运营商提供的数据服务。数据服务表现为“流量”，是与话音、短信息并列的基础电信业务。互联网服务可以覆盖到何种地域，可以普及到哪种人群，取决于电信设施的分布范围和密度。通俗讲，若无基站等电信设施有效分布，手机没有信号，人们将不能使用无人驾驶、互联网医疗、互联网导航、在线支付、视频聊天等服务。

  

**（二）信息生成、传送和处理是数字经济活动的载体**

互联网依托电信网的数据服务，将线下金融、交易、娱乐、社交、新闻、医疗等服务搬至线上，实现了电信与垂直行业的融合和创新发展，涌现出数字经济蓬勃发展的新业态，极大丰富和改变了生产生活。互联网的基本功能是生成、传送和处理信息。基于互联网生成、传送和处理信息功能，实现了金融、医疗、文化、交通、电子商务等诸多数字经济活动。如互联网音乐服务，服务提供者向用户提供在线音乐赏析，实质上是提供信息，运用一定方式转化为音乐。

  

**（三）电信网是数字经济发展的网络基础**

数字经济是网络经济，以网络联结生产要素，联结服务提供者与用户，促进传统行业提质增效。我国以“电信网”为纽带，联结了诸多计算机信息系统与用户，形成了全国的“一张网”。电信网是联结不同信息处理系统的纽带，是国家“一张网”的基础。《网络安全法》中的“网络”，包括两个方面：一是具有发送、传送、接收信息功能，起到联结作用的网络，这是一般认识上的网络，即电信网；二是接入电信网、对外提供网络服务的计算机信息系统。前者是面，是真正意义上的网络；后者是点，不过是网络的使用者，不属于一般认识上的网络。广电网是收转、传送广播电视节目的载体，具有发送、传送、接收信息功能，可以起到网络联结作用。如果广电网向社会提供网络联结服务，需要取得电信业务经营许可证，成为电信网的组成部分。因此，电信网等于网络。电信网联结你我他，融合千业百态，是数字经济的物质基础。

  

**二、网络基础管理为数字经济提供“信任”供给**

**（一）网站是数字经济活动的入口**  

人们生活在现实社会，现实性是其生产生活的基础；互联网极大丰富和改造了人们的生产生活，但线上空间的“虚拟性”与生产生活的现实性需求是一对永恒的矛盾。网站是网络虚拟空间和现实社会的主要联结点，是解决虚拟与现实之间矛盾的主要切入点。无论通过互联网从事何种线上活动，提供何种数字经济服务，均需依托网站。网站是线下主体在线上从事数字经济活动的入口。

  

**（二）网站管理为数字经济活动提供“信任”供给**

人无信不立。无论是现实社会，还是网络空间，人与人要社交、交易，需要以“信任”为基础。为了解决信任问题，确保社交、交易安全，需要国家公权力介入，对社交、交易主体身份进行确认并公示。在现实社会，对个人而言是居民身份证，对法人或者非法人团体而言是工商登记、社会团体登记、事业单位登记。在网络空间，因网络具有虚拟性，社交、交易双方不见面，具有远程性特点，更加需要解决信任问题，解决方式为电信主管部门通过备案或者经营许可对网站进行准入管理。

  

**（三）网络基础管理是数字经济发展的基础**

互联网活动存在于网络空间，推进网络建设、提高网络覆盖和提升网络能力，属于电信主管部门的基本职责。互联网活动依托于网站，设立网站的基础条件是办理互联网接入和具有相应的IP地址和域名，互联网接入业务和域名解析属于典型的电信业务，IP地址资源也由电信主管部门负责管理。同时，断开互联网接入或者停止域名解析即可以关闭或者限制网站服务。无论从网络层面，还是业务层面，抑或管理层面，由电信主管部门对网站进行统一管理，是确保登记信息准确，为互联网活动提供“信任”供给和有效管理的必然要求。

  

**三、强化网络基础管理，筑牢数字经济发展的网络基础**

数字经济涉及多个主管部门。在数字经济管理体系或者网络管理体系中，网络基础管理是横切面，负责网络运行监管，目标是营造通畅、有序、安全运行的网络；金融、卫生、交通、新闻、文化等主管部门负责网络上某个具体服务或者经济活动领域的监管，是竖切面，遵照的是“线下线上一致原则”。  

  

**（一）合理划分监管职责，明确监管责任**

一是区分网站与依托网站提供的服务。通过互联网提供线上服务，需要依托网站。网站之于互联网服务，犹如厂房或者办公场所之于线下服务。网站与依托网站提供的服务，分别由相应主管部门管理，即网站设立由电信主管部门负责管理，依托网站提供的互联网服务由相应的业务主管部门负责管理。

  

二是区分信息交互与具体的服务活动。用户接受互联网服务，业者提供互联网服务，均需要接入网络，建立用户与网站之间的网络联结，进行信息的生成、传送、处理活动，表现为检索、访问、浏览、下载、安装等信息交互活动。互联网环境下自主、自愿进行信息交互，需要信息生成、传送、处理活动可正常和安全进行，不受非法干扰和破坏。网站与用户之间信息交互正常进行，核心关涉是信息流动的自主、自愿和安全，不关涉任何具体服务。通过信息交互进行的具体互联网服务，如新闻、医疗、交通等，应由相应的主管部门负责监管。

  

**（二）强化网络基础管理**

**一是营造通畅的网络。**包括：加大电信网分布范围和覆盖密度，深入推进电信普遍服务，让数字经济惠及更多地区和人群。二是加强电信网络更新换代，全面提升网络功能，支撑数字经济蓬勃发展对网络传输数据能力的需求。当前，5G商用大门已经开启，5G发挥着引领经济社会数字化转型的作用。电信设施仍面临规划难、建设难、进小区难、进机场和地铁难、保护难等问题。若不能从根本上解决电信设施建设和保护中的问题，将严重制约5G建设、普及和通信质量，影响5G对经济社会转型发展支撑作用的发挥。

  

**二是营造有序的网络。**包括：加强网站设立管理，确保网站主体身份真实，奠定数字经济活动有序进行、确保交易可靠的基础；做好信息交互活动的市场秩序和用户权益保护管理，确保数字经济活动中信息生成、传送、处理的有序进行，保障用户与网站之间的检索、访问、浏览、下载、安装等信息交互活动的自主自愿进行。

  

**三是营造安全的网络。**包括：确保电信网运行安全，督促电信运营商提升电信网络运行安全水平，是确保数字经济活动安全的基础；确保网站安全，网站是数字经济活动的窗口，是业者与用户之间的联结界面，网站安全是数字经济活动安全进行的保障；确保信息交互安全，避免信息交互被干扰、攻击和破坏，是数字经济活动得以进行的直接要求。

  

综上，网络基础管理的对象是网络，包括物理设施、网络能力、网络环境，涵盖网络本身、利用网络提供服务所设立的网站、网站与用户之间的信息交互。利用网络提供服务所设立的网站，是服务提供者与用户之间交互界面，区别于提供具体服务所需的信息系统，前者属于网络基础管理范畴，后者属于相应主管部门对具体服务活动管理的对象。
