# 2019年国家网络安全宣传周——展会亮点抢先看！

**全球网络人的年度狂欢****互联网行业大佬的津城聚首****2019年国家网络安全宣传周****网络安全博览会****将于明日（9月14日），如约启幕****逛展会、品设计、做游戏、巧答题……****思维碰撞、大咖论道**

  

![](../Images/ca1b626579e96914c7b2df7e78d7a367.png)

  

**同往届相比今年博览会有哪些亮眼特色？****场馆布展情况如何？****让我们一起去看看吧~**

![](../Images/c9181958fecacd3bfd6678b0b4d03daa.png)

  

**本次网络安全博览会将在天津梅江会展中心举办，展馆面积约2.3万平米，为历届之最，设置天津展区、关键信息基础设施网络安全解决方案展区、网络安全核心技术展区、智能生活网络安全展区、互动体验专区、网络安全大讲堂等6大展区。**

**博览会以“网络安全为人民，网络安全靠人民”主题，重点展示新中国成立70周年特别是党的十八大以来国家网络安全领域取得的重大成就，展示国内外最新产品和技术成果，广泛普及网络安全知识技能，提升全民网络安全意识，营造关注网络安全、重视网络安全的社会氛围。**  

  

**进入梅江会展中心****工人们正如火如荼的搭建展位****安装展品、布置展区****一点一滴****打造着“精致”的博览会展馆**

  

![](../Images/aa887fe0ad91123224cec12166cb4a36.png)

  

**名企“黑科技”等你解锁**

![](../Images/942482ebf67bab524dc7c6fc49b04f3d.png)

![](../Images/bb8b6ae08e66af50ac710cae9fc1b9e9.png)

本届网络安全博览会吸引了阿里巴巴、腾讯、360、卡巴斯基、奇安信等重点企业及电信运营商、金融单位等100余家机构参展，大数据、云计算、人工智能、5G、区块链、车联网……将在各展位悉数亮相、各显所长，场馆内更提供了全覆盖的智能语音导览服务，引导观众通过沉浸式互动体验，切身感受加强网络安全防护的重要性。

![](../Images/e67c99ce3c7897e5c1a80a3823dde031.png)

![](../Images/faa087bcf4534a799f2f7511f2429d1f.png)

在这里，市民可以了解到最新技术的发展现状，看到一体化新能源综合服务云平台“国网芯”，接触到“安全芯片及相关安全产品”、“电力监控系统网络安全装置与工具”等产品。另外，众多金融类企业还展示了智慧银行、智慧柜员机、智慧货架、感知地图等创新安全技术。

  

**“网红天津”之美等你发现**

![](../Images/54586ae52295c3f55fdd1ea829285f0e.png)

![](../Images/aa3953e6d3319eea35b9df0a55aa659a.png)

作为网安周的独立城市展区，天津展区将城市形象、网络安全成就和网民互动有机融合，全面展示天津市在建设现代化国际港口之城、交通枢纽之城、开放包容之城、高端产业集聚之城、科教资源雄厚之城、历史文化名城、生态宜居之城所取得的突出成就，系统呈现近年来天津在网络安全顶层设计、产学研工作、应用示范开展、产业生态建设等方面的发展成就，将天津的历史文化底蕴与网络安全前沿科技相融合，全面呈现城市发展的科技感和艺术美。

![](../Images/db88e34e2026c6b7d4f6605988a1ca95.png)

![](../Images/dd1397dd25491b30822441c7a98be63d.png)

在天津展区，观众可以与“津产黑科技”来个“零距离”接触，现场参观“计算小能手”“天河三号”服务器，个人计算机的国产“大脑”飞腾芯片，和飞腾芯片的好朋友“银河麒麟操作系统”。这里还有“能上天”“能下海”的一对“好兄弟”深之蓝水下智能装备，一飞智控无人机管控系统；“深之蓝”工业级产品最大下潜深度达7076米；一飞智控系统操作无人机，能让几百架无人机在天上“乖乖听话”。有体力吗，骑上“数字单车”漫游五大道、海河沿线吧，骑累了，戴上VR眼镜在中新生态城散散步……

  

**好看的、好玩的等你打卡**

![](../Images/9398ae6a4d541fd1eeaf8a8214fd9738.png)

本次博览会采用“全展区集中互动+各展位特色互动”的新型模式，专门打造3000平米网络安全互动体验专区。互动体验专区内部设置了三条主题线路，聚焦个人信息保护、网络安全法治、防止电信诈骗等人民群众普遍关心的问题，借助人工智能、VR、AR、模拟场景体验等技术，引导观众参与现场互动学习相关领域的网络安全知识并进行线上传播。

![](../Images/b49555cca5135a84cf16d2645b18118e.png)

![](../Images/6ee2b1d7fbb5171efd46692ffb716c49.png)

互动展区搭建模拟现实应用场景，将“链接公共WiFi安全风险”“预防电信网络诈骗”“保护虚拟‘钱袋子’的安全”“智能门锁的网络安全保护”等网络安全知识点，以活泼生动的互动方式呈现给观众，引导观众学习自我防护知识。在展区，观众还可以参与“大家来找茬”游戏，辨别真假网站、邮件及短信，提升防骗技能；在实体“愤怒的小鸟”游戏区，观众可以操纵“弹弓”击中带有“个人信息保护”“网络安全法治”等主题名称字样的翻板，回答相应主题的题目完成通关。“网络安全点球战”则让观众过把球星瘾，将球踢入球门后即可获得网络安全知识答题机会，体验新技术带来的新奇感受。网安周期间，虚拟主持人“津小卫”将开设《“津小卫”课堂》，为前来参观的市民讲解网络安全小知识。

![](../Images/753013266fd56287fa31d4224a19ec31.png)
