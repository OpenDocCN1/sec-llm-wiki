# 行业 | 深信服安全创新的“三驾马车”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=2664120143&idx=4&sn=d3e5c34f7eaddea42e0148c5bb49a1cc&chksm=8b5e3db6bc29b4a0671138e191810afe552a0139d4f654d68b23e0740d8038265d0cff583498&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664120143&idx=4&sn=d3e5c34f7eaddea42e0148c5bb49a1cc&chksm=8b5e3db6bc29b4a0671138e191810afe552a0139d4f654d68b23e0740d8038265d0cff583498&scene=27#wechat_redirect)

今年4月，深信服发布了上市以来的首份财报，这是一份成绩斐然的答卷：2018年实现营业收入32.24亿元，同比增长30.41%。其中信息安全业务收入为18.9亿元，同比增长24.55%；云计算业务收入为8.67亿元，同比增长59.17%；以企业级无线为主的基础网络业务收入为3.94亿元，同比增长18.32%。

不难看出，深信服加快了云计算领域的步伐，云计算业务整体增幅最快，安全业务整体收入比重则略微下降，从2017年的61.43%下降至58.66%，但安全业务仍是深信服的营收主力，短时间内难有变化。

![](../Images/f2d0dc3031a249b70fb4972bcfa51eff.png)

再来看另外一个数字，2018年深信服的研发人员比2017年增加473人；研发投入比2017年增加2.89亿元，同比增长58.78%，达到7.79亿元。这个比重已经远远超出营收的增长率，可见深信服对研发创新的重视。但业界都知道，深信服的研发有一个特点，就是不跟风，接地气，根据客户需求来决定自己的产品方向。那么增长巨大的研发投入，持续不断的创新，在深信服的主营业务信息安全上，具体体现在哪些方面？对此，深信服CEO何朝曦在近日举办的2019深信服创新大会上表示，未来的安全建设将长期受到合规、安全事件、业务建设的驱动，未来的安全将是动态、多维、多场景、全局并重视体验的，用户可选择的安全产品不再是过去的“老三样”，安全交付的形态也愈加丰富。“未来的安全必须做到自我更新、高度集成、可编排、按需部署、融入业务、自动化。”何朝曦的这句话，即是深信服在信息安全上的发展方向。

![](../Images/cc87e12258b0dd3dccff59d2b7a4c851.png)

为此，深信服发展出了新的安全架构、理念、做法，来指引其全线安全产品和服务的发展。

  

**新的安全架构：****APDRO**

在2019深信服创新大会上，深信服提出了APDRO风险管理模型，这是深信服智安全架构的重要组成部分。它引入人工智能技术，打造集防御、检测、响应于一体的闭环安全，旨在应对自动化水平不断提高的威胁，让用户更简单有效地处理不断变化的网络风险。　　APDRO，即智能、防御、检测、响应、运营，由风险控制措施、能力交付矩阵、风险管理能力等级框架、风险管理流程这五个部分组成。深信服安全业务总经理马程认为，APDRO是对PDR模型的一种改进，更能适应最新的网络安全形势。过去业界注重P（防御），但D和R，即检测和响应是未来网络安全中非常重要的两个环节。同时，作为深信服“让IT更简单”的理念体现，马程表示“安全也应该更简单”，现实中安全运维人员常常被海量的报警和日志所淹没，这时就必须加入A和O，即智能和运营。智能可以帮助人来做日志的分析和检索，找出真正有威胁的事件，还可以通过训练和模型，推测可能存在的安全风险。智能的引入最终使得安全运营更简单，更加容易交付，形成安全闭环能力。“所以，P（防御）是基础，DR（检测和响应）是对安全能力的整体延伸，AO（智能和运营）让我们安全的交付更加简单有效。”马程总结道。要让安全架构真正发挥作用，离不开有效威胁情报的支持。对此马程表示，深信服近20年的发展，已经有了10万多家用户，几十万台设备，在经用户许可后，积累了大量的企业安全情报数据。同时深信服还和业界领先的威胁情报单位、组织联盟做情报互换，以及购买最新的情报，加大情报的广度。这些措施有力地保证了深信服威胁情报的准确性和实时性，让APDRO安全架构做到既智能又可靠。

  

**新的安全理念：****从零信任到精益信任（aTrust）**

精益信任，这是深信服在2019创新大会上推出的又一个安全架构。据介绍，精益信任安全架构由全面身份化、多源信任评估、动态访问控制、统一安全、可成长等五点组成，基于信任和风险的闭环，整合终端、边界、外网的已有安全设备，进行统一联动，形成自主调优、快速处置的统一安全架构，最终实现内外网“精确而足够”的信任。精益信任发源于零信任，自从谷歌通过Beyond Corp将零信任安全架构在自身内网成功落地，业界看到了在全新网络架构下的安全新思路，纷纷跟进并推出相应解决方案。“零信任只是实现精益信任的一个初始阶段。”深信服精益安全产品专家訾然表示，Gartner在2017年提出了“精益信任”的概念，零信任只是安全建设的第一步，企业在初始是采取零信任的态度，什么都不相信，但是随着业务的发展，不可避免的对信任会存在扩展和变化的需求，不能再采取永不信任、总是验证的思路，而且应该基于当前对风险的观测，对后继的信任和风险进行精益控制。零信任解决了当前边界模糊的问题，但是安全从来不是任意一个安全产品可以独自解决的，一定需要联动和协作。訾然认为，精益信任aTrust安全架构是在零信任的基础上做了增强，更加接近安全的实质。相对零信任对访问授权的非黑即白，精益信任的最大特点是实时动态调整，在新的控制平台上将内网、终端以及边界重构，所有的安全设备不仅仅聚焦身份，还结合场景和应用环境，以及访问者的行为特征进行判断，进行权限的实时调整。

![](../Images/26e229f34656458f08f051bc3eb5a07a.png)

“相对于零信任，精益信任更易于落地。”深信服安全业务CTO郝轶表示，类似谷歌的零信任架构需要对现有的IT架构进行大量改造，也伴随着大量的迁移工作，人力物力投入巨大。但深信服的理念是让IT更简单，更有价值，所以精益信任在落地时就尽可能的利用用户现有的工具、资源、设备，延续用户之前的使用习惯，尽可能的不去做严重改变用户习惯的调整，让用户享受到新技术所带来的效果。“更多的为用户解决问题，更少地为用户带来问题。”

  

**新的安全服务：****“人机共智”的安全运营**

2018年，深信服在成都的创新论坛上正式发布了面向未来基于“人机共智”的深信服安全托管服务。经过一年的发展，深信服安全服务CTO李焕波认为，安全托管是国外MSS（Managed Security Services）的直译，已经不能准确反映深信服的安全服务范畴，应该称作“人机共智”的安全运营。国内很多企业在信息安全建设初期，安全工作的主要内容是购买安全设备和部署安全管控系统并进行日常维护。从网络层、系统层、应用层、数据层、终端层部署了一系列安全设备或软件并确保其稳定运行，但发现安全状况并没有得到有效改善，安全问题频发。“根本原因是企业一直在进行被动防护，没有进行有效的安全运营。”李焕波强调。但企业在安全运营上，往往缺乏高端安全人才，缺乏持续监测手段，缺少研判经验和响应流程，达不到应有的效果。李焕波表示，深信服认为安全运营是以安全效果为目标，以资产、脆弱性、威胁以及事件的四要素为安全效果提升的核心抓手，遵循PDCA的闭环原则，以“人机共智”的创新模式持续开展网络安全保障工作。“人机共智”的安全运营平台，“人”指的是深信服高阶的安全专家，深信服采用专家资源共享的方式让每个用户都能享受到专家级的优质服务，同时也提供科学家、数学家对平台的AI检测引擎进行场景训练，确保AI检测引擎持续进化。“机”指的是深信服自研的AI安全运营平台、基于威胁情报打造的脆弱性管理平台、标准化服务监控平台。李焕波介绍，通过高阶安全专家+AI自动化引擎，将用户内部信息和外部信息通过AI引擎自动化分析后，形成针对客户特有的威胁消息，这些威胁消息就可以去推动安全管理体系中的人员、流程去跟进处置。“由此，从安全组件、云端研判、云端专家就形成一套7\*24小时的持续、闭环、主动、动态的安全运营体系，可以帮助用户提前预警，快速研判，精准响应。”李焕波透露，目前深信服的安全运营服务发展迅猛，已有超过500个客户。“让畅想成为现实，靠的是不断的创新。”正如何朝曦所说，用户的驱动，事件的驱动，业务建设的驱动，都在促使深信服不断地创新。安全仍是深信服营收的主力军，相信深信服安全业务的新架构、新理念、新服务，将助力深信服明年交出一张更闪亮的“成绩单”。
