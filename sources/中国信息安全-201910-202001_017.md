# 行业 | Win7停服，网络安全问题需认真应对

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=2664123670&idx=3&sn=0730a7fb9460727a6ba31d231f0698da&chksm=8b5e4fefbc29c6f98b338745a81af80c9371f67f3986e41158dd80f5ada2f2333f1813bccbaf&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664123670&idx=3&sn=0730a7fb9460727a6ba31d231f0698da&chksm=8b5e4fefbc29c6f98b338745a81af80c9371f67f3986e41158dd80f5ada2f2333f1813bccbaf&scene=27#wechat_redirect)

2020年1月14日微软官方正式停止支持Win 7系统服务，除付费政企用户外，不再提供安全补丁或者更新服务。Win 7的安全风险随之大增，这对现如今仍在使用Win 7的用户无疑是个坏消息，业界纷纷出招，帮助国内用户应对Win 7停服后的防御。

尽管有过WindowsXP停服后的经验教训，安全业界已有技术上的准备，但Win 7庞大的用户量，和新型安全风险的不断出现，使得Win 7停服事件仍需高度重视。360近日举办了“面对win7停服，我们如何应对”研讨会，针对大型行业用户，给出应对win7停服的安全方案。在研讨会上，360集团首席安全技术官郑文彬表示，停更意味着微软不再针对Win7进行漏洞修复和纵深防御策略，以及不再提供安全防御机制。由此带来的后果就是，国内六成用户面临着零日漏洞威胁和在野（ITW）0day的威胁，停更后这些用户无法获知漏洞情报，甚至微软也将很快失去这部分漏洞情报，因此更不能有全面的漏洞评估和分析以及有效的防护、修复和对抗方案。可以说Win 7用户进入了“裸奔”时代。可怕的是，APT组织和黑产从业者们却还关注着这一系统，获取这部分漏洞情报。这并非危言耸听，郑文彬介绍，“双星”0day漏洞攻击就是这样一个例子。360安全大脑在Win 7停服前夕捕获到全球首例同时复合利用IE浏览器和火狐浏览器两个0day漏洞的攻击，攻击者使用组合两个0day漏洞的恶意网页进行攻击，无论IE浏览器还是火狐浏览器打开都会中招。用户在毫无防备的情况下，可被植入勒索病毒，甚至被黑客监听监控，执行窃取敏感信息等任意操作。360将其命名为“双星”0day漏洞攻击。只要Win 7系统还被使用，新的漏洞和新的攻击方法还会出现。郑文彬提出从五个方面来应对Win 7停服，分别是遗留补丁 / Patch Diff、漏洞缓和、操作系统/应用程序加固、威胁情报+微补丁、隔离和虚拟化。其中，后四种解决方案都被内化为四大引擎，集成在360最近推出的Win7盾甲解决方案中。在四大安全引擎的加持下，360安全大脑Win7盾甲企业版安全防御机制，可在安全威胁发生的第一时间，做到从漏洞补丁分析、漏洞缓和、操作系统/应用程序加固、威胁情报+微补丁、隔离和虚拟化等五大维度发力，实现最快速、最及时、最高效的威胁洞察防护响应。

![](../Images/26c4df5f22b330d6112443e284bbb300.png)

Win 7停服之后，用户可以选择升级系统或更换其他操作系统。但从产业界来说，很多工业互联网设备面临的最大问题就是升级困，甚至困难，甚至无法重启赖安装补丁，因此360安全大脑Win 7盾甲的微补丁技术就能很好的解决这类问题。

公安部第一研究所、第三研究所原所长、中国计算机学会（CCF）计算机安全专业委员会原主任严明在发言中提出，Win7停服既是好事也是坏事。严明表示，中国的软硬件系统在外部压力下发展快速，以麒麟为代表的操作系统已经从不可用走到了可用阶段，飞腾、龙芯等核心芯片也得到更多的应用，Win7停服虽然使用户安全面临挑战和风险，但会明显推进我国自主知识产权产品研发和提升的速度。春节将至，我国大量使用Win7系统的政府部门、国企以及关键基础设施单位可能面临巨大的安全风险，春节假期更有可能成为关键的风险敞口期。郑文彬表示，win7盾甲将致力于为用户消除高危安全漏洞带来的安全隐患，并为用户提供长期的漏洞防御及修复服务。
