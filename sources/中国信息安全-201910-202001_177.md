# 行业 | 阿里“可用不可见”数据技术在国际安全计算竞赛夺冠

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=2664122739&idx=3&sn=d140cfe0c96fd511d9de98f1a43dc402&chksm=8b5e4b8abc29c29cb1cc03bb000106a72d9c2f5a09d773d94b72ca33bd7e14dd75d5c305e913&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664122739&idx=3&sn=d140cfe0c96fd511d9de98f1a43dc402&chksm=8b5e4b8abc29c29cb1cc03bb000106a72d9c2f5a09d773d94b72ca33bd7e14dd75d5c305e913&scene=27#wechat_redirect)

![](../Images/a922858ce79e65e2785c482605513bda.png)点击上方“中国信息安全” 可订阅![](../Images/480bacb266cd9c733eb7b0fd8e7c59d7.png)**iDASH 2019 赛事主办方及参赛队伍合照**只需20秒，多个医院就能使用“可用不可见”技术，完成多个患者数据的联合建模，且每个患者的数据均不需要离开各自的医院。近日，阿里安全双子座实验室和蚂蚁金服摩斯团队在由美国国立卫生研究院 (NIH)、加州大学圣地亚哥分校（UCSD）、印第安纳大学等联合主办的 iDASH 安全计算赛事中，获得了“安全多方计算”赛道的并列第一名。这是自 2014 年 iDASH 举办比赛至今，首次由中国大陆代表队夺冠。据悉，iDASH竞赛旨在探索解决云环境下海量基因组分析期间的数据隐私和安全性问题。目前也是国际上在隐私保护和安全计算方面最高规格的竞赛。今年赛事有来自全球各国105 个队伍参加，大赛设置了包括区块链、同态加密、SGX 以及安全多方计算(MPC)等四大赛道。其中，MPC是本次大赛最大亮点，因提交方案最多，竞争也最为激烈。该赛道“机器学习模型的安全协同训练” 要求参赛队伍提供一个方案，基于MPC技术，在多个医院互相不接触对方任何隐私数据的前提下，完成机器学习模型的合作训练——根据多个医院的总共数万维基因数据，预测癌症患者的复发率。 “我们的数据安全技术只需20秒即可训练得到准确率高达70%以上的模型。”阿里巴巴安全部高级安全专家洪澄作为参赛成员之一，他向记者介绍，阿里安全团队的“可用不可见”数据安全技术———安全多方计算框架，是基于TF-Encrypted 研发，其预测结果不仅速度快，而且准确率在所有参赛队伍中也是最高，比其他参赛队伍的方案准确率高出了4%至10%。目前，阿里安全团队此次参赛研发的TF-Encrypted ABY3模块，也已在github开源：https://github.com/tf-encrypted/tf-encrypted/pull/721，这是中国机构对安全多方计算社区的首次贡献。据介绍，阿里安全双子实验室早在2017年开始，就一直在推进“可用不可见”数据安全技术，以便解决数据行业面临的信任难点、数据孤岛等问题。双子实验室还曾与马里兰大学等高校合作，在欧洲密码年会Eurocrypt2019上发表论文：《Covert  Security  with  Public  Verifiability:  Faster,  Leaner,  and  Simpler 》，这也是国内公司在安全多方计算领域的第一篇顶会论文。阿里双子实验室同时还牵头在IEEE成立了安全多方计算工作组（P2842），这也是首个立项的安全多方计算国际标准。有业内人士评价称，iDASH竞赛夺冠、对MPC开源社区的贡献、成功立项MPC国际标准、在国际顶级会议上发表MPC论文等，这一系列成果都充分表明了阿里安全双子座实验室，在安全多方计算的理论和实践两个方面，均已具备国际一流的技术实力。
