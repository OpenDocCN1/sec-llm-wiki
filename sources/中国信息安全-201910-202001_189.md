随着信息技术的飞速发展，工业4.0时代的大幕正在开启。云计算、大数据、人工智能等新兴技术正逐渐影响着工业领域的生产与业务流程，加速了工业IT与OT（Operational Technology）的融合，OT环境正面临着严峻的安全威胁。近年来，针对工控系统的网络攻击事件频频发生，乌克兰电网遭攻击、台积电遭遇勒索病毒、委内瑞拉电力系统瘫痪等，都给当地经济和社会稳定运行带来了严重后果，这让行业乃至国家政府都意识到，做好OT安全防护已刻不容缓。

对此，**Fortinet技术总监张略**表示，“互联网的飞速发展正逐渐打破传统工业IT与OT间的壁垒。以前的工业生产是完全隔离的，生产运行都有专用的硬件和控制协议，现在，随着业务效率与需求的改变，OT与IT 的连接越来越多，这就使得网络攻击和病毒可通过IT环境进入OT，对整个工业生产运行造成严重威胁。尤其在中国这样制造业发达的国家，做好OT安全防护更是当务之急。”近日，Fortinet公布了最新的OT安全架构，以及Fortinet工控安全整体解决方案。该解决方案不仅能够对于已知威胁提供可视化和防御能力，还可以通过防火墙与集中管理解决方案，以及与工业控制网络与安全可见性与控制厂商Nozomi等多种集成方案的联动来发现和阻止异常行为，并制造欺骗“迷宫网络”，为工业企业更加放心地拥抱工业互联网提供了可靠保障。

  

**相对IT，OT安全同样重要**

在人们看来，相对于金融业、医疗行业等已将运营技术应用的较为成熟的行业来说，制造业似乎在IT与OT融合方面较为落后，从而使得很多企业并不太重视OT环境的安全。其实不然，纵观近些年针对工控系统的安全事件可以看出，攻击造成的危害和后果极其严重。

国际权威机构调查结果显示，ICS（工业控制系统）6大类最常见的漏洞为网络边界保护、识别和认证、资源分配、物理访问控制、帐户管理和基础功能，这些问题占总问题的三分之一。其中，企业和ICS网络之间的边界隔离不足，以及无法检测到关键系统非法访问活动是最常见的弱点。而针对这些安全漏洞，网络攻击者正在利用不断进化的恶意软件，对网络上暴露的工控系统发动攻击。

![](../Images/4ee27b16ad6b1c41b3356a5c850acbfc.png)

张略表示，“毫无疑问，目前许多先进制造企业是很容易受到攻击的，相较于一些传统行业，他们的OT安全威胁更加紧迫，一旦发生安全事件，损失惨重。首先，需要企业自身认识到OT安全的重要性，有需求才会有市场。Fortinet有多年与国际大型制造企业的合作经验，帮他们解决了很多实际的问题。目前，Fortinet也在积极布局OT安全领域，致力于为更多的企业解决安全问题，为行业服务。”

  

**一个框架，四点能力**

据张略介绍，目前国内OT的普遍现状如下：

*   构网两极化：网络较为开放，OT/IT网络共用同一网络设备互联；或OT/IT网络物理隔离；
    
*   缺少网络安全设备有效地针对OT/IT网进行安全区域划分和进行安全运行状态的统一监控；
    
*   OT网接入设备以有线/无线方式接入，网络安全设备部署没涉及“最后一公里”的安全体系联动防御；
    
*   缺乏主动阻止外部恶意攻击和发现与阻挡高级可持续性攻击的能力，易造成OT网络瞬间瘫痪；
    
*   OT网设备接入缺乏必要身份或资产识别，定位安全威胁与取证过程低效；
    
*   OT网服务器存在安全和管理风险点：因历史原因，OT网系统、版本等老旧、漏洞多等安全问题；
    
*   终端电脑/工控机：因历史原因，设备系统存在非标准化，造成管理杂乱、漏洞多等安全问题；
    
*   终端电脑/工控机：缺乏定期病毒查杀习惯与机制：感染主机处理不及时，存在安全隐患；
    
*   移动设备接入缺乏管理和制度，容易造成终端病毒感染与传播；
    
*   安全教育意识不足；没形成网络安全规范，指引日常安全操作。
    

基于此，Fortinet发布了其最新的OT安全架构及工控安全整体解决方案。“**基于Fortinet Security Fabric的工控风险管理框架：** 通过将Fortinet的参考架构应用于工业控制Purdue模型，Fortinet能够在仪表总线网络、流程控制局域网、区域总控网络、生产区域、企业环境等不同层面构建安全控制能力与分段安全保护”， 张略指出，“目前，Fortinet Security Fabric安全架构已经实现了与Nozomi Networks解决方案的集成，提供了基于SCADA（数据采集与监视控制系统）安全的主动防御能力。”

![](../Images/89086998baa6876b593f2d832d917744.png)

Fortinet Security Fabric的风险管理框架在不同场景下均能提供高适应性的安全能力，包括以下四点：

**针对已知威胁的可见性和分段保护：**在此类场景中，Fortinet方案提供了FortiGate防火墙、FortiGuard威胁情报服务等组件，实现了从监控网络到流程控制网络的主动防护，以及对于常见的ICS/SCADA协议、基于工业协议的IPS特征的识别和监控，并可以通过集中安全管理报告实现自动化安全防护。

**异常检测和响应：**FortiSIEM安全信息与事件管理解决方案可以在统一可扩展的解决方案中提供可见性、关联性、自动响应和补救措施建议，FortiGate则可以提供从监控网络到控制网络的主动防护，在与Nozomi对网络的被动监控能力融合起来之后，帮助用户对于异常行为进行及时响应。

**OT Security Fabric自动化联动：**通过与Nozomi终端等第三方解决方案商的的联动与集成，增强在检测、发现、响应异常行为，并作出自动阻截攻击的能力。

**攻击欺骗：**FortiDeceptor作为一个轻量级的，专门针对OT网络的蜜罐，可以快速创建一个伪造的“迷宫网络”，以诱使攻击者进行攻击，进而检测到攻击者的活动详细信息，以在攻击真正造成损害之前进行遏制。

  

**拓展合作，布局生态建设**

Fortinet有着丰富的工控安全实施经验，但随着技术环境的快速发展，企业的业务场景与需求也随之丰富，安全挑战也越来越多。四家全球领先的OT技术的方案提供商：Fortinet的长期合作伙伴Nozomi与新加入的三个合作伙伴--RAD，Indegy和SecurityMatters，加入Fortinet合作伙伴体系，通过Fortinet Security Fabric安全架构保护不断增长的数字与物理空间。Fortinet的Security Fabric安全架构通过Fabric API，Fabric Connector和DevOps脚本和工具来创建一个开放的生态系统。 这种高度集成与协同的方式将针对OT细分市场的各种关键安全解决方案无缝整合在一起，以实现全面的安全性，可靠性。Fortinet与四家OT安全解决方案提供商携手，扩大OT客户可用的解决方案范围。RAD，Indegy和SecurityMatters三位新的OT安全专家与长期合作伙伴Nozomi Networks一起提供了OT特定命令和协议的高级可见性，联动Fortinet 安全架构，保护OT网络在新兴的工控网络领域的安全性。 这些合作伙伴通过在Fortinet的OT漏洞扫描和策略执行中添加深度数据包检查和上下文分析功能，增强了OT网络安全防护能力。

  

**OT安全市场未来可期**

目前，OT安全还处于市场发展的初期，许多企业并不重视，收益甚小，但是在张略眼中，“这就是Fortinet的战略投入，我们认为OT市场一定会在近几年的某个时刻爆发，成为行业关注的焦点。现在就进行投入，有利于抢占市场先机，在机会和安全事件来临的时候，我们会有更充分的准备，为企业做好服务、实际解决问题。”Fortinet提供了面向工控安全严苛环境、满足工业标准和合规性的软硬件设计，不仅符合工业环境需求，还能够在封闭网络下进行更新，确保在任何时候都能提供稳定的安全防护能力。张略表示，“Fortinet在SD-WAN、云安全、OT安全等方面都有多年的实践经验，我们愿意积极与其他安全厂商分享经验，打造生态体系，提供更加完善的安全解决方案，为OT工业互联网安全保驾护航将是我们的目标和宗旨。”
