# 行业 | 黑莓继续发力汽车软件安全 兼顾安全和开放性

BlackBerry，已不是我们所熟悉的那个“黑莓”，如今的BlackBerry，已经成为软件和安全领域的一支重要力量。2016年，黑莓因手机业务不断萎缩而选择了关闭。但在CEO程守宗的领导下，黑莓快速转型到软件厂商。因超强的安全性，黑莓手机受到了大量政界和商界人士的青睐，曾占据了美国市场48%的市场。而今这种安全能力开始应用到更多的软件领域，为政府、商业、金融、医疗、制造业提供安全解决方案。QNX（Quantum Software Systems），2010年被黑莓收购，并将其发展成为转型软件公司的重要支柱。QNX系统采用了独特的微内核结构，具备实时、稳定、可靠的优点，运行速度较Linux等系统更快，是业界公认的X86平台上最好的嵌入式实时操作系统之一。经过多年发展，BlackBerry QNX系统的应用已经遍布各行各业，其中在汽车领域的表现最为突出。黑莓于前段时间宣布，目前全球有超过1.5亿辆汽车采用QNX软件，超过45家的汽车制造商在使用QNX软件，在世界前十大汽车整车厂中有九家在使用QNX的软件解决方案。不夸张的说，BlackBerry QNX已经成为汽车操作系统供应商中的王者。2018年12月，工信部发布《车联网（智能网联汽车）产业发展行动计划》，指出到2020年，实现车联网（智能网联汽车）产业跨行业融合取得突破，在关键技术、标准体系、技术设施、应用服务、安全保障等方面取得积极进展。2019年9月，国务院发布《交通强国建设纲要》，提出要加强智能网联汽车（智能汽车、自动驾驶、车路协同）研发。根据国家发改委发布的《智能汽车创新发展战略》预计，到2020年中国智能网联汽车新车占比将达到50%，到2025年，新车基本实现智能网联化。显然，汽车联网、智能化已经是下一步的产业发展目标。但相应的安全问题，如个人信息泄露、黑客入侵、恶意操控、DDoS攻击等，威胁到了用户生命财产安全和公共安全，成为行业必须面对的挑战。近日，黑莓宣布，QNX安全虚拟机2.0已由知名检测认证机构德国莱茵TÜV（TÜV Rheinland）认定为符合ISO 26262 ASIL D标准，成为全球首款通过ASIL D安全认证的商用虚拟机。这意味着QNX安全虚拟机2.0已经满足了在功能安全领域最高要求的安全等级。借助QNX安全虚拟机2.0产品，开发人员可以将安全关键型系统（例如主控制单元）与非安全关键型系统（例如信息娱乐）进行分区和隔离，确保在系统出现故障时隔离关键系统并对其进行安全管理。不断升级的QNX安全虚拟机，显示出黑莓正在解决当前汽车领域的安全可靠和系统扩展需求之间的矛盾。具体来讲，QNX的高安全性可以保证汽车车机系统的安全可靠，但主机厂在开发车载娱乐系统时，处于生态和落地考虑，往往选择安卓、Linux此类开放灵活的开源系统。随着车联网、5G等技术的发展，以及人们的应用需求，更多的娱乐、辅助类的第三方应用软件被增加到汽车系统里。QNX安全虚拟机可以让这些娱乐软件在QNX的系统中运行，满足汽车软件第三方的扩展需求，同时又保证安全性。由于其封闭而独特的技术架构，以及针对汽车行业的一体化基础方案，BlackBerry QNX在汽车软件安全领域中优势明显。据国家互联网应急中心的监测及分析报告显示，截至2019年5月国家互联网应急中心已收录汽车安全漏洞5011个，其中高危漏洞超过1000个，其中典型严重及高危漏洞主要体现在APP越权远程控制、TSP越权访问/注入/爆破等方面。对此，BlackBerry技术解决方案部高级副总裁兼联席主管Kaivan Karimi在近日的媒体沟通会上表示，汽车软件的复杂度越来越高，保障安全至关重要。来自NVD机构的调查显示，BlackBerry QNX每年处于规定限制范围内的漏洞数量均低于5个，远低于行业平均值。这是开源软件所不能做到的。据介绍，BlackBerry QNX为加强互联及自动驾驶汽车抵御网络攻击的能力，建立了七个安全支柱：1、保障供应链安全；2、使用值得信赖的组件；3、采用隔离手法与受信通信；4、现场安全检查；5、构建事件快速响应网络；6、使用生命周期管理系统；7、组织内建立安全文化。Kaivan Karimi表示，QNX是唯一一个能够实时支持防护的OS系统，这是安全的基础，是BlackBerry在市场竞争中的关键支撑。BlackBerry将继续加强汽车软件安全，新的版本软件新增了15项面向安防的软件防护更新体系，开始进入更多的汽车安全管理领域。只有在一个安全的环境，才能给产业更多的发展。与BlackBerry合作的多家厂商都认为，汽车在考虑嵌入式系统时，要求既保守又开放，这是未来的发展趋势。显然，经过安全认证的BlackBerry QNX可以保证汽车核心驾驶系统的功能安全、网络安全和可靠性，同时QNX Hypervisor又带来了兼容性和开放性。

Kaivan Karimi表示，BlackBerry QNX将致力于为智能网联汽车提供专属软件平台和服务，用行业领先的认证操作系统、工具及软件等丰富产品组合全方位保护智能网联汽车免受网络攻击，为信息安全保驾护航。
