# **一、战略背景**

  

美国白宫于2020年3月26日发布《美国5G安全国家战略》（以下简称“战略”），明确表达了特朗普对美国的愿景，即与盟友及亲密合作伙伴一道，在全球范围内领导研发、部署和管理安全可靠的5G通信基础设施。美国国家委员会早在2018年1月就曾向政府提交了一份5G安全报告，指出5G网络安全与否将直接影响国家经济及政治安全，呼吁由政府主导建设统一的5G网络。2019年5月，美国联合32国召开5G安全准则研讨会，发布《布拉格提案》，试图推动其盟国加强对5G供应商的安全风险评估。2020年3月23日，特朗普签署《保障5G及以上安全法案》，拟与相关部门共同制定一项国家级战略，目标保障美国及其盟友在5G及未来几代无线通信系统和基础设施的安全。作为落实《保障5G及以上安全法案》的第一步，美国白宫制定并发布该战略，提出四方面行动路线。

  

# **二、主要内容**

  

该战略主要内容包括：

  

**（一）推动5G国内部署商用**

  

该战略指出，将从优化频谱规划和支持研发测试两方面同时发力，进一步推动以美国私营部门主导的国内5G部署。一方面，将开放更多的频谱资源用于5G商用，同时通过制定《国家频谱战略》，构建起5G（及后5G）全空域无线通信网络的长期频谱管理计划。另一方面，将继续携手私营部门以及志同道合的盟友及伙伴，共同推动5G及未来通信网络新技术、新体系架构的研发、测试和评估。

  

**（二）评估5G基础设施风险并制定核心安全原则**

  

该战略指出，将通过定期评估5G基础设施安全风险，以及制定和遵守一套核心安全原则，来保障其5G系统的安全可靠。一方面，将与各地方政府以及私营部门一道，持续挖掘5G基础设施现存的安全漏洞，全面评估5G安全风险对其经济和国家安全造成的潜在威胁。另一方面，将加强与私营部门的合作，制定并遵守一套涵盖网络安全、供应链安全、公共安全等各方面、可操作性强的核心安全原则，并与其他安全相关原则（如《布拉格提案》）协同配合，确保其国内5G基础设施的安全性。

  

**（三）管理因使用5G基础设施给经济和国家安全带来的风险**

  

该战略指出，将通过分析5G基础设施的风险，管理其供应链风险并采取措施应对5G基础设施“高风险”供应商，避免其经济和国家安全遭受任何损害。一方面，将通过联邦采购安全委员会，制定供应链管理标准及指南，用于评估和降低供应链风险。另一方面，将利用13873号行政令相关规定，联合其外国投资委员会、联邦采购安全委员会等机构，审查存在“中高风险”的5G供应商，并采取相应举措来应对风险。

  

**（四）促进负责任的全球5G开发和部署**

  

该战略指出，将与其志同道合的国家、盟友合作，参与全球5G安全标准制定，推动安全可靠的5G设备及服务的供应。一方面，将通过双边及多边合作机制（例如布拉格5G安全会议等框架），与国际盟友共同制定全球5G安全原则。另一方面，将与私营机构协力巩固其在5G国际标准制定方面的领导地位。此外，还将通过加紧制定5G设备采购相关政策、标准、指南等来丰富供应商的多样性，并通过设计市场激励、问责以及评价等多重机制来激发全球5G市场竞争力，确保全球网络的安全稳定。

  

# **三、结论**

  

该战略在既有法案基础上进一步强化了美国5G安全战略框架：除推动国内5G商用部署、加快发展外，更聚焦于制定5G基础设施安全原则及风险评估指标、供应链和供应商管控、国际5G安全标准等涉及5G安全的国内及全球规则体系，以影响全球5G开发和部署。
