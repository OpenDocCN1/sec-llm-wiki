# RSA 2020 | 创新沙盒“花落”SECURITI.ai，隐私合规智能服务“渐起”

2020年2月24日，RSAC2020大会开场大戏“创新沙盒”比赛尘埃落定，来自硅谷的初创公司SECURITI.ai斩获桂冠，这个成立仅一年的网安新秀何以击败其他“背景雄厚”的企业？其提供的安全解决方案反映出什么样的业界趋势？网络安全又面临着怎样的“拐点”呢？小编观察如下：

  

**一、抓住行业趋势，盯准隐私合规**

回溯SECURITI.ai的发展轨迹不难发现，这个成立于2019年并在短短一年内就筹集到8100万美元的企业完全抓住了近两年全球网络安全发展的契机，即欧盟通用数据保护条例（GDPR）、加州消费者隐私法（CCPA）等强隐私法规的生效，要求企业赋予个人数据掌控权力。SECURITI.ai创始人Rehan Jalil表示，SECURITI.ai提供的解决方案就是为企业生成一个用户数据操作平台，即首先定义目标数据源（目前该公司拥有250个外部数据源链接，然后根据数据源自动获取相关数据并生成一个集中的可视化的结果，供用户查看并在此基础上作出修改或删除。“说到底，SECURITI.ai的宗旨就是赋予个人对于其数据的权利，包括隐私权、删除权、修订权和停止处理权”。目前，该公司为不同类型的隐私规则（如GDPR、CCPA和巴西“通用数据保护法”）设计了不同的安全模板。

![](../Images/92e0a7b371992b52ebc98a250e02eb06.png)

  

**二、引领隐私技术变革，推进数据智能管理**

隐私技术市场一直是投资者和风险资本优先考虑的领域，而人工智能和自动化已经成为隐私合规的发展方向。各类隐私法规往往要求企业清楚掌握自身所拥有的数据，并且必要时及时回应用户删除或修改数据的请求。但是由于数据的广泛传播性以及易复制性，对于数据的管理面临着较高的技术和人力门槛，极大地提高了全球企业的合规成本。SECURITI.ai作为隐私技术的新生者，其产品和服务充分利用人工智能和机器学习等技术来自动执行合规任务，旗下的PrivacyOps平台是一个全栈解决方案，通过机器人自动化和自然语言接口来组织和简化隐私合规。主要工具包括个人数据图生成器、数据主体请求的机器人自动化回应、安全数据请求门户、同意生命周期管理器、第三方隐私评估、第三方隐私评级、隐私评估自动化和违约管理等。创始人Rehan Jalil认为，企业普遍希望超越简单的web表单来保护隐私的方法，人工智能和自动化代表着隐私合规的未来。

![](../Images/71d9ea29b8c548c7687c0385a152c087.png)

  

**三、人工智能将成为网络安全新动力**

从2018年RSA创新沙盒冠军Big ID到今天的SECURITI.ai，如何自动以及智能满足隐私需求已成为行业的普遍需求和发展趋势。当前，人工智能已经成为网络安全的重要因素，根据凯捷咨询(Capgemini)的研究，69%的高管认为，人工智能和机器学习是应对网络攻击的必要手段，高达80%的电信高管更表示缺少人工智能将不能有效应对网络安全问题。对于基于人工智能的安全解决方案的投资也将显著增长。根据Gartner最新的信息安全和风险管理预测，到2020年，全球在信息安全和风险管理系统上的支出将达到1310亿美元，到2022年将增至1740亿美元。而云安全平台和应用程序的销售额预计将从2020年的6.36亿美元增长到2023年的16.3亿美元，实现36.8%的复合年增长率(CAGR)，并领先于所有类别的信息和安全风险管理系统。可以看出，人工智能已经成为网络安全的新动力。
