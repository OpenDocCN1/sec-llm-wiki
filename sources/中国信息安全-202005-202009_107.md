# 行业 | 云安全联盟发布零信任专家认证（CZTP）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=2664130092&idx=4&sn=adf4f00a0857d7f026c723bb726626d3&chksm=8b5e64d5bc29edc36a4e096917842364ea35cafe47a5c0dca5b5b237d57f676c05ed06654980&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664130092&idx=4&sn=adf4f00a0857d7f026c723bb726626d3&chksm=8b5e64d5bc29edc36a4e096917842364ea35cafe47a5c0dca5b5b237d57f676c05ed06654980&scene=27#wechat_redirect)

零信任，是在不可信网络中构建安全系统。作为新一代信息技术安全架构，零信任创新性的安全思维契合数字基建技术特点，能更好地提升企业信息化系统和网络的整体安全性。

国际上，2019年7月美国国防部在2019-2023年《数字现代化战略》中将零信任安全列为优先发展技术。据Gartner预测，2022年将有80%面向生态合作伙伴的新数字业务应用将采用零信任网络访问；2023年将有60%的企业从远程访问VPN向零信任网络架构转型。在我国，2019年9月工信部起草的《关于促进网络安全产业发展的指导意见(征求意见稿)》首次将零信任列入网络安全需要突破的关键技术。零信任已成为国家高度重视的一项前沿性、创新性、先导性重大的网络安全技术。在刚刚举办的北京网络安全大会战略峰会和CSA峰会期间，工信部副部长刘烈宏表示，要加强零信任安全的研究和落地。 作为在国内最早开展零信任相关研究与标准制定，云安全联盟大中华区现推出CZTP（Certified Zero Trust Professional）零信任专家认证。

![](../Images/5f141f18ecc8122bb6a721140f9664f2.png)

CZTP（Certified Zero Trust Professional）零信任专家认证，是面向个人的零信任安全认证。目的是通过对零信任架构、身份管理与访问控制、软件定义边界、微隔离等方面多维度进行系统性学习，并结合场景、案例、规划与部署等角度对零信任应用于实践等方面的学习，帮助网络信息安全从业人员掌握零信任知识，培养零信任安全思维，传播与践行零信任理念，助力新型网络安全人才培养。

随着零信任技术在各行业的深入落地，各个行业对零信任安全人才的需求量也急剧增加。为什么要参加零信任专家认证课程的学习？价值：

1.  全面掌握零信任知识体系并获得业界认可的国际证书，提升安全从业人员的职场竞争力。
    
2.  培养基于零信任的安全建设与防御思维，提升战略思维，拓宽安全从业人员的专业视野。
    
3.  助力组织安全从业人员的前沿安全知识和技术储备，增强组织应对网络安全新挑战的能力。
    
4.  是新一代网络安全及企业需求人才的知识及能力保障。
    

零信任专家认证不仅在网络安全行业受欢迎，在云计算、5G、物联网等里也十分受追捧，因为零信任的核心思想是捍卫企业的数字资产。零信任专家认证课程由中国人民大学、中科院信工所、武汉大学、华为、奇安信、360企业、启明星辰、腾讯、绿盟、阿里云、微软、云深互联、安几科技、竹云科技、易安联、山石网科、缔安科技、蔷薇灵动、联软科技、完美世界、云安全联盟大中华区等机构近40多位专家参与开发及评审，包括CSA大中华区主席李雨航、奇安信副总裁左英男、IDF实验创始人万涛、中国人民大学教授石文昌等。云安全联盟大中华区将于8月26-31日组织线上零信任专家认证CZTP公开课。
