# 发布 | 共建未成年人“清朗”网络空间倡议书

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=2664129284&idx=3&sn=a388b4a26761004d0082939e452d0a01&chksm=8b5e61fdbc29e8eb133718a3350d64de93cdb1303524fc8b65eabac04eccf328b2b452745ab3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664129284&idx=3&sn=a388b4a26761004d0082939e452d0a01&chksm=8b5e61fdbc29e8eb133718a3350d64de93cdb1303524fc8b65eabac04eccf328b2b452745ab3&scene=27#wechat_redirect)

习近平总书记指出，“为广大网民特别是青少年营造一个风清气正的网络空间”。7月9日，国家网信办启动了为期2个月的“清朗”未成年人暑期网络环境专项整治行动。为响应专项整治行动，中国网络社会组织联合会联合中央电化教育馆、共青团中央权益部向互联网信息服务平台共同发出以下倡议。

**一、倡导价值引领，弘扬网络新风尚。**

全面贯彻党的十九大精神，坚持正确政治方向，树牢“四个意识”，坚定“四个自信”，坚决做到“两个维护”，持续践行社会主义核心价值观，以唱响主旋律，弘扬真善美，引领文明风尚，传播网络正能量为己任，凝聚社会共识，净化网络环境，营造清朗网络空间，为广大网民尤其是未成年人提供一个绿色、健康、文明、和谐的网络环境。

**二、强化自律意识，坚持守正创新。**

发挥企业自律功能，积极履行社会责任，坚守道德底线，努力守正创新。不断加强运营管理，提高对互联网规律的把握能力和新技术新应用管理能力，进一步创新和改进网络内容生产、传播与管理方式，面向未成年人建立有针对性的内容审核机制，促进网络内容建设健康繁荣有序发展。

**三、加强文化建设，守护网络清朗。**

以培育积极健康、向上向善的网络文化为目标，制作发布优质网络文化内容，坚决打击色情、低俗、暴力、恐怖、诈骗和谣言等严重危害未成年人身心健康、影响未成年人健康成长的网络违法和不良信息，让网络空间成为传播正能量的思想文化阵地，切实维护网络生态秩序。

**四、坚持依法办网，维护网络秩序。**

积极践行法治精神，严格遵守国家法律法规，牢记法律红线、规范网络平台的建设和管理，严禁网络违法行为，努力构建良好网络空间秩序，保护未成年人上网安全。

**五、畅通举报渠道，自觉接受监督。**

畅通网民举报渠道，完善举报受理机制，积极接受网民监督，及时处理网民反映的网络违法行为和不良信息，有效保护未成年人网络权益。

  
  
  

请全社会携起手来，努力提高对未成年人网络保护工作的重视，共同“E路护航”，守护广大未成年人“E路平安”。
