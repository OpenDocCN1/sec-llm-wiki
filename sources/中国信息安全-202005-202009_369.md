# 警惕｜线上消费套路多 这份网购“防骗”攻略请收好！

据中国互联网络信息中心（CNNIC）发布的第45次《中国互联网络发展状况统计报告》显示，截至今年3月，我国网民规模为9.04亿，互联网普及率达64.5%，网络购物用户规模达7.1亿，网络消费成为数字经济的重要组成部分。

受新冠肺炎疫情影响，多数消费者会选择通过网络购买日用品、生鲜食品和防疫产品，各家电商的打折促销活动也层出不穷。“网信中国”为您整理安全网购小贴士，希望各位网友避开网购风险和陷阱，安全快乐买买买。![](../Images/1537b4d8bfe8a933575d9c4b3031fb0d.png)**陌生链接你别碰**  
  

网购时，有些陌生链接会通过某些渠道跳出来，其中有些链接隐藏着木马病毒，如缺乏警觉打开查看，手机就可能会被植入病毒，你的个人隐私、金融财产等信息将面临被泄露和盗取的巨大风险。

![](../Images/3378c4dc716ae3684b2ac8e765dd6c36.png)

案例：

北京消费者赵小姐用手机在淘宝下单商品，支付完成后，手机突然收到一个陌生电话号码的来电。电话里的“客服”告诉赵小姐，因为支付宝交易异常，她刚才的购物没成功，要重新操作下单购买。随后，赵小姐收到一条附有网站链接的短信，一直和她保持通话的“客服”让她按页面提示操作。赵小姐在网页里输入了自己的身份证号、信用卡号、密码、银行卡预留手机号等个人信息。操作刚刚结束，赵小姐的手机就一下子进来三四条短信。她打开手机发现短信提示，她的信用卡分4次被扣款1.5万多元，随后赵小姐意识到被骗并且报警。

**小贴士：**

1.不要相信陌生链接、电话，尤其是要输入银行卡号、身份证号的链接，宁愿不买东西也绝不点击、回复。

2.遇到不明来源的中奖、购物退款类链接不要打开。  
  
**虚假宣传要辨识**  
  

网上购物经常会遇到品质描述与实物不符、材质标注有误等虚假宣传问题。不少消费者拿到商品也会有疑问，明明电脑上的图片看起来很漂亮，实物却相差甚远。

![](../Images/d4b4976e810cc4f363fe4078880da8b4.png)

图片来源于凤凰网案例：

消费者何某在张某经营的网络店铺中购买了一款增高产品，共花费2376元。何某收货后发现，自己买的产品是既没有经销商或联系方式，也没有质量合格证明的“三无产品”，就连进口报关单也属伪造。随后，何某将张某告上法庭。诉讼中，张某未能提供证据证实产品来源和合格证明。法院判决认为，张某向何某销售涉案产品的行为构成欺诈，张某退还货款2376元并支付三倍赔偿金7128元。

**小贴士：**

1.网购时选择访问量较高、口碑好的网店购物。

2.尽量购买售后服务较完善的商品。

3.选评级较高的网店，对于要购买的商品一定要看看其他已经购买过的消费者的评价。  

  
  
**社交购物需警惕**  
  

一些不法分子通过手机短信、社交平台发布二手车、二手电脑、海关没收的物品等低价转让信息，一旦事主与其联系，即以“缴纳定金”“交易税手续费”等方式骗取钱财。

![](../Images/91670c9d1bcb378813549bd7bf7bebdb.png)

案例：

李小姐爱好收藏珠宝，有朋友介绍的、有主动添加她的，不知不觉微信里有了很多卖珠宝首饰的好友，李小姐会偶尔刷刷朋友圈，看看有没有心仪的物件。一天，她看到一位不知什么时候加上的微信好友在朋友圈发了几件玉石成品，她一眼就看上了，便主动跟这位好友询价。经过一番讨价还价，双方约定以2万多元的价格成交，但是需要李小姐全额付款后对方才能发货。开始李小姐有点担心，但价格比较优惠，再加上对方一再保证自家店铺都是这样的，从来没出问题，李小姐实在喜欢，便给对方付了款。可自从付款后，这位卖家却没有按照约定放货，而是以商品有质量问题等借口迟迟不给发货，后来干脆拉黑了李小姐消失不见。

**小贴士：**

1.不轻易相信那些所谓的“免费”物品以及“超低价”商品。

2.网络购物要选择正规平台，不要与卖方私下交易。3.一旦对方要求重复付款就要提高警惕，不要盲目转账。4.对于在社交媒体、微信、QQ上发布的购物信息，特别要留意其提供的网址链接，谨防木马植入或钓鱼网站。  
  
**假冒客服莫上当**  
  

有些不法分子会冒充客服，假借“所购商品出现了卡单、调单或交易失败等情况，若逾期处理，账户资金将被冻结”等理由，要求到银行ATM机前操作退款，诱骗网友将钱汇到骗子的账户中。

![](../Images/7240f5db9041101c52827b52ba7d683c.png)

案例：

小陈某天接到一个陌生电话。对方自称是某购物平台的“客服”，说因为工作失误导致小陈被列为了“客户代理商”，每个月将扣除一笔费用。然后热情地提出可以帮小陈解除这一业务，但需小陈提供银行卡号以便处理。接着小陈又接到一个176开头的电话，对方自称是“银行客服”，要求小陈必须要“验证资金”，将自己的资金转到指定账号，以便取消“客户代理商”。并且告诉小陈如果拖得太久，一旦扣除了钱就不能退回来了。

随后小陈按照“银行客服”的要求从银行卡取出20000元，并选择“现金存款”，并输入一串所谓的“代码”（实际是收款账号）后点击“确认”。随后，“银行客服”称银行查账小陈的资金有问题，让小陈再取19000元，这时小陈才意识到被骗了。**小贴士：**

1.“卡单”“调单”“激活订单”等多为诈骗术语，网友们见到此类词语基本可断定是骗局。

2.如果实在不放心，一定要通过电商平台官方热线或客服咨询，多方核实后再行处理，切勿轻信不明短信或电话。
