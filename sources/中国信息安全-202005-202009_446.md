# 专题 | 一线网安从业者谈人才培养（一）

网络安全人才培养是一个全社会共同参与的过程，在满足行业对专业性人才的需求以及人才自身能力的认定和提升上，人才认证认可体系的作用至关重要。本刊邀约了多位参加过CISP认证的一线网安人才，听取他们对人才认证作用、意义的观点，以及对网络安全人才培养的建议。

  

**CISP人才培养对企业网络安全保障体系建设的积极作用****大庆油田信息技术公司北京分公司 郭强**自2011年取得CISP认证至今已有近九年的时间，笔者在企业中一直从事着网络安全的相关工作，亲身经历了永恒之蓝勒索病毒事件，“网络安全法”的试行到实施、演习活动这些里程碑事件，从一个参与者角度见证了企业网络安全保障体系从单薄到饱满，直至趋近完善的过程。专业的安全人员在其中发挥了巨大的正向作用，是网络安全体系建设和发展的重要组成部分。结合这些经历，笔者谈谈CISP人才培养对企业网络安全工作的积极作用。**一、企业网络安全工作及从业人员情况**CISP体系一直倡导的“三分技术、七分管理”是企业网络安全工作的真实写照，其管理体系一般采取垂直管理机制，以行政主体为单位，每层级设有网络安全的管理人员和技术人员；制度体系一般也依附在管理体系中，逐层逐级继承细化；技术方面一般按照业务方向不同进行划分，如网络、终端、服务器等。总结下来就是“以人为本”，网络安全工作效果的好坏，基本取决于企业各层级网络安全从业人员专业知识储备情况和技能水平的高低。按照职能划分，企业网络安全工作者可分为方向型管理人员、技术型管理人员、技术操作人员、技术服务人员。受学校专业因素影响，以前很多管理人员到技术人员基本没有网络安全专业学历，而是依靠工作经验和查阅资料完成网络安全能力的积累，这种片面的学习过程造成了很多企业网络安全工作者能力的局限性，影响到工作中的方方面面：如制度与机制的设置执行是否到位、安全措施的选择和配置是否完善等，甚至存在技术人员不懂安全措施的作用和原理、裸跑在网络中的情况。随着“网络安全法”、网络安全等级保护制度的深入落实和企业安全体系的不断完善，这种现象已经逐渐消失，但曾经对企业的网络安全的影响是一直客观存在的。**二、企业网安从业者能力匮乏的原因**作为企业中的一员，可以深刻体会到内部从业者在网络安全学习积累上的无力感，总结下来，主要有三方面原因：一是知识碎片化，缺乏系统性。网络安全作为后兴起的专业领域，与传统信息化发展相比存在滞后性，早期学校也没有相关专业或知识的传输，即便目前国内部分高校已经开通了相关专业，但短时间很难发展到如传统文理课程的标准化。虽然互联网的兴起加快了知识的传递和分享，但内部从业者很难从网络中汲取到系统性的知识体系，知识碎片化则意味着内容的时效性低、准确性低，学习者无法知悉自己欠缺什么，甚至应该学习什么。二是培训机制僵化，学习机会匮乏。培训在企业内部是一项常态化开展的经营活动，受企业内部管理机制所制约，无论是“内对内”还是“外对内”的培训课程，都按照数年前的标准执行。但网络安全的培训体系是创新型的，其知识体系对授课者的能力要求颇高，像CISP的讲师全国仅有100余名，基本为行业中出类拔萃且适合传授知识的中坚力量，培训成本相对较高，因此企业往往在考虑合规和成本的前提下，采取低成本的培训模式，照本宣科的开展安全培训，千篇一律的内容让内部从业者疲于应对，甚至起到反向效果。三是工作界面狭窄，缺少实训场景。行业对于网络安全都是讲体系，但在企业实际工作过程中，从业人员受到行政、业务、人员分配、编制等多方面原因的制约，往往从事一个细分领域的工作，在网络安全工作中兼职居多，比如负责网络管理的兼职网络安全管理，但管理终端的另有其人。这种现象大大降低了内部从业者对跨工作范围安全知识和技能学习的兴趣，即使掌握了跨工作范围的技能和知识也很难在实际工作中得到应用和验证。**三、CISP人才认证对企业安全保障的积极作用**CISP认证资质发展到今天，其知识体系覆盖管理、技术、风险评估、物理环境等方向，已具备系统化、多元化等特性，在结合企业实际需求的基础上，可以为企业培养复合型的网络安全人才，符合企业“以人为本”的网络安全工作思路,对各项工作的落地和高质量推进有着积极的促进作用。具体有以下几点：1.为企业培养全面的中层管理型人才。通过CISP知识体系，使得管理层对网络安全整体工作内容、性质和方向有详尽的了解，在具体的企业管理工作中可对具体方向有很好的延伸，落实企业网络安全战略规划时可以更高质量地完成工作任务，以及更合理的协调分配资源。2.为企业培养全面的基层技术型人才。通过CISP知识体系，使得网络运维管理人员对安全威胁的识别有了深刻的认知，对网络、终端、物理环境等方面的网络安全知识及技能有全面的了解，在具体工作中可以结合实际环境就某一方向进行深入研究和操作，可适用于企业基层的多种技术应用场景，为企业网络安全工作的落地推进提供了基础的保障，是对企业网络安全工作的重要支撑。3.为企业培养专业的检查评估与渗透服务人才。通过CISP-PTE等知识体系可为企业培养对内服务的红客人才，摆脱依赖外部服务可能存在的数据泄漏、敏感泄密等安全风险，同时也为企业储备可以在网络安全方向担负安全对抗的人才队伍，保障企业在复杂形势及环境下的安全稳定。**四、结语**在企业网络安全保障体系中，无论是管理体系、技术体系还是运维体系、监督体系，都是依靠人去运转和操作落实，企业安全体系建设与发展的优劣维系在企业内部网络安全从业者的身上。CISP是国家目前含金量最高的专业认证培训体系，能很好地解决企业在人员网络安全专业能力缺失和不足上的问题，从而帮助企业进一步加快网络安全保障体系的建设和完善。作为年头较长的CISP持证者，笔者建议在体系课程中加强实操实训环节，让接受培训的一方能更清晰、更深刻掌握网络安全知识与技能，更好地为企业网络安全工作作出贡献，同时也希望CISP认证资质蓬勃发展，为我国的网络强国道路提供强而有力的支撑。

  

**人才资质认定引领和规范安全人才的培养****中国联通河北省分公司高级工程师  孔令飞**人才资质认定对安全人才的培养具有明显的引领作用和规范作用，特别是在帮助执业人员树立全面、复合的专业知识体系框架方面，具有显著的推动作用。网络安全专业仍然处在快速发展阶段，凝聚了众人智慧和先驱经验的最佳实践，是每个从业人员都不应忽视的知识来源。CISP认证的主要内容恰恰就是总结了本行业最佳实践的知识框架。我参与了CISP认证，以此来检验自身专业知识的积累并找到拓展专业知识的方向。在此过程中，我印象最深的就是CISP知识体系的通用性和实用性，以及培训课程的生动和精彩。我认为CISP是目前国内对信息安全从业人员的专业素质和专业能力进行客观评价的事实上的标准，具有广泛的公信力和良好的接受度。建议那些正在准备CISP认证的人们不要把取得认证当成专业学习的全部，学以致用并坚持学习才是取得CISP认证的最有益的收获。当前的CISP培养体系正在向进一步便捷化和实用化的方向发展，希望在此过程中能够妥善处理好速度与质量的关系、数量和质量的关系以及效率与质量的关系；还希望CISP认证的发展，可以坚持自主可控、公正可信，向下兼容国外相关认证并体现出新时代的中国特色。

  

**从学员到讲师，对网安人才培养的观感****中国石油信息内容审计平台项目组 高级工程师  桑圣洁**网络安全人才的培养是基于知识的传达、技能的实践基础上，作为国内权威的网络安全职业认证资质，CISP 认证已成为网络安全行业从业的基础准入条件，能够避免人才技能与网络安全信息安全岗位需求不匹配，成为国家培养网络信息安全人才的重要措施之一。作为学了7年通信专业的人，本人拜服于香农大师的信息论，最早对信息安全的认知从“密码学”课程开始，十几年前的校园里还未有网络信息安全相关的基础或专业课程设置，社会上也远没有如今专业规范的职业培训，偶然跟随做计算机安全方面的导师，毕业设计的题目是“基于PKI的CA安全架构的研究”，在一片懵懂里踏入了安全领域。2009年硕士毕业时赶上物联网概念及应用的兴起，我参与了油气生产物联网项目建设，并重点对其中的生产网络隔离及安全、终端采集数据安全等问题展开研究，开始接触工业级防火墙、隔离网闸这些安全防护手段。那时对网络安全的认识还不成体系，知识比较零散，大多时候都是通过“百度”来拼凑起对信息安全、等级保护这些概念的认知。一边是工作需要的推动，一边是自我学习的摸索，这种“业余”的状态在2012年的秋天结束：我参与了单位组织的首次CISP认证培训，接受了10天专业的、系统化的信息安全知识学习。那些略显枯燥的安全管理方法论，那些层次多样的安全技术，让信息安全在我的脑海里有了更清晰的框架，串接起了我在工作中积攒的对网络安全点滴的认知。学习让人能够挖掘潜力，工作让人获得方向。有了信息安全专业资格认证的背书，自己更加有信心承担更多网络安全相关的工作。有了体系化的基础理论的支撑，加之日渐丰富的工作经验，作为甲方承担内部项目运维及升级建设工作时，与乙方沟通更为顺畅、效率更高；作为乙方为甲方提供安全咨询服务时，对乙方安全需求理解也更为透彻，建议及方案的提出也更为专业，令人信服。学习者看到的是点，传达者手握的是面。在获得了CISE认证6年后，我有机会尝试成为一名CISP讲师，开始从一名学员到一名讲师的转变。从吸收到传达，需要的不仅仅是知识的掌握和理解，还需要对知识的融会贯通，理论和实践的衔接。凭借几年来在能源行业对物联网安全、工控安全方面的实操经验和在数据安全领域的探索，我将CISP 的知识点和自己的工作经验充分融合。这是个两相促进的过程，既再次总结了自己过往的网络安全方面的工作，也重新梳理了CISP的知识体系，对照新的版本、新的技术应用热点，填补了自己的知识盲点，强化了理论基础。泛泛吸纳让人有知识的宽度，有选择的深耕让人有知识的深度。无论是国内的CISP，还是国际化的CISSP，两者都是大而全的知识体系，是“一英里宽一英寸深”的知识体系。通过规范的学习，能够帮助我们把零碎的、分散的、相对独立的知识、观点和概念进行整合，把接触到的点状知识转化为树状，并最终成为一个密密麻麻交织错落的“大网”。要在网络安全这个大网上，把每个结点都做到专家级是不现实的，应结合自己的应用场景选择某一领域深耕挖掘，在某一结点上延伸拓展。由于我近年的主要工作方向为企业数据泄露防护，而网络安全的核心是数据安全的理念越发深入人心，加之曾经为某企业做过数据安全课题研究的咨询，数据安全成为我的主攻领域，近期又参加了CISP-DSG的培训，再次帮助我将工作中关于数据安全治理、数据保密管理、数据泄露防护方面积累的点滴知识理清脉络、聚沙成塔。不间断的学习能够帮助我们维持能力，但在实际工作中，良好的沟通技巧也必不可少，以我为某央企做安全规划咨询为例，CISP中安全管理的内容提供了很好的方法论基础，有较强的指导意义，但从实际的工作来看，还是缺乏了一种顶层设计的思维和一些“安全政治”实操的技巧。理论是完美，但现实也让人困惑，如何能将科学的模型、健全的流程适用于企业的实际现状，满足企业的安全需求，打动说服高层管理者接受设计方案，让执行层心悦诚服地去实施方案，是网络安全服务提供方的工作重点和难点。网络安全领域学无止境，跟随着IT快速更新的技术，层出不穷的新网络安全风险，都让从业者以奔跑的姿态在这条道路上前进。路一直向前，但道可以选择，从业者应根据工作需要或者个人兴趣，选择合适的培训和资质认证，形成自己学习及职业生涯的价值序列，力争在有限的时间内获得最大收益。例如出国工作或者在外企，CISSP会是一个好的选择，但如果在政府、国企及重要行业工作，那CISP则是更强有力的敲门砖。在国家关注信息安全人才培养，齐抓“学历教育、职业培训和专才培养”，发展“政企学研联合创新培养综合能力人才”良好氛围下，无论是半路出家对网络安全事业锲而不舍的从业人员，还是略带迷茫但又对网络安全心怀憧憬的在校大学生，都希望能够消除浮躁，凝神静气，勤练内功，夯实基础，钻坚研微，真正在网安领域有所作为，为企业、社会、国家的信息安全、网络安全、网络空间安全贡献自己的力量！
