# 聚焦 | 智慧风暴席卷“塞上江南” 业内大咖齐聚“美丽银川”——2020银川国际智慧城市博览会日前开幕

共享智慧财富，共鉴城市文明。以“创新智慧城市、赋能社会治理、推动高质量发展”为主题的2020银川国际智慧城市博览会在11月2日隆重开幕，为银川开启了一场智慧头脑风暴。

当天上午10点，宁夏回族自治区和银川市各级领导以及知名院士专家、企业高管、城市代表等参会嘉宾共同参加了2020银川国际智慧城市博览会开幕式。北京、天津、重庆、河北、山西、辽宁、吉林、黑龙江、江苏、浙江、福建等23个省、自治区、直辖市的350余位城市嘉宾代表也出席了本届博览会。

![](../Images/63f7bc98ae2ded8a091061fa2a129014.png)

**银川市委副书记、市长杨玉经同志致辞**

![](../Images/24d569bcad6a613d631a8ee30e520c11.png)

**中国工程院院士、国家信息化专家咨询委员会委员沈昌祥院士致辞**开幕式上，全球智慧城市咨询委员会CEO克里斯·库克、中国工程院院士倪光南，以及英国皇家科学院院士迈克·巴蒂先生，阿里集团副总裁、阿里研究院院长高红冰，新东方创始人俞敏洪，联想集团高级副总裁贺志强，华为公司董事、高级副总裁彭中阳，小米集团联合创始人、副董事长林斌等企业大咖，纷纷发表致辞，为开幕式送来了线上祝福。

![](../Images/b8b8fd6e346560441ef386d20c53ba19.png)

**全球智慧城市咨询委员会CEO 克里斯·库克先生线上致辞**

![](../Images/86ba918497c80b9e7062998b5e575f6b.png)

**中国工程院院士、中国科学院计算技术研究所研究员倪光南院士线上致辞**开幕式后，17位专家学者、企业高管等嘉宾分别围绕大数据赋能城市治理、人工智能技术发展及在教育行业中的应用、新型智慧城市策略与实践、5G云计算、新型智慧产业社区创建与发展等主题进行了主旨演讲。主题发言期间，企业高管与专家学者们还举行了圆桌对话，创新思维在这里激情碰撞，博览会的盛况通过国内外众多媒体实时直播发布，智慧银川在线上同步开启了另一场热烈关注。

![](../Images/a4bde47c07d9be6b9d32f0ddac3814d6.png)

**圆桌对话**开幕式当天，宁夏回族自治区、银川有关领导和参加本次博览会的部分院士专家、企业高管、城市代表，共同参观了智慧城市建设成果展览。银川智慧城市建设成果展区（银川馆）以及国家电网、中国电子、中电科、中国电信、中国移动、中国联通、海信集团等展馆负责人分别向嘉宾们全景呈现了各自在智慧城市领域的创新成果。政府信息化、城市智慧化、工业自动化、生活智能化中的经典案例、科技创新以最饱满的姿态呈现在嘉宾面前。

![](../Images/7b2db3f646397822158c506c61909728.png)

**智慧城市建设成果展览**海信、海尔、万达信息、华为、百度、联想、苍穹数码科技、凯信特、希望信息等参展企业，也向参会嘉宾介绍了各自在数字经济、信息产业中的尖端科技。

![](../Images/33be0151d268129427e191c0f8031ebc.png)

**智慧城市建设成果展览**

![](../Images/631351510978296e4e22c37fec1d07de.png)

**智慧城市建设成果展览**另外，银川市政府还为百度网讯、沧州云图科技、海梁科技、嬴彻科技4家企业的7辆自动驾驶车辆，颁发了道路测试和示范应用牌照。这意味着，自动驾驶正式走进银川，自动驾驶背后的道路交通安全探索、产业规划布局在银川全面掀起。

![](../Images/6e442a32fa3e46e77a889374a2150d75.png)

**颁发首批智能网联车测试牌照**开幕式当天下午，本届博览会的推介会及签约仪式同期召开，150余家大数据、数字经济企业代表参加了此次会议，签约项目共有31个。推介会上，银川市人民政府副市长张全智向与会嘉宾介绍了近年来银川市智慧城市建设情况，表示银川市将继续打造优良的营商环境，以开放包容的姿态，迎接四方友人驻足银川、品味银川、投资银川、共建银川，同时真诚邀请更多企业家来银考察，寻求合作，共谋发展。与会企业家对银川市近年来在智慧银川及数字经济方面取得的成绩表示了肯定，对银川市优良的营商环境进行了高度赞誉，认为银川凭借高度文明与高度智慧的城市底蕴，近年来已然成为投资兴业的热土。

![](../Images/17bdc0dc06da865135be5789c19e6407.png)

**签约仪式**据了解，银川是全国第二批智慧城市试点城市，于2013年获批。多年来，银川市坚持政府主导、需求导向、市场运作等原则，紧抓新一代信息技术发展机遇，在智慧城市建设方面取得了一定的成绩。“互联网+医疗健康”、“互联网+教育”、“互联网+政务服务”等方面走在全国前列，并多次获国务院通报表扬。银川国际智慧城市峰会自2015年起已经连续举办五届，此次升级为博览会，无论从展览规模还是展览时长上都远超往届。百余家企业云集智慧城市建设成果展览，自展览开馆以来，平均每天有9000多市民前来领略智慧城市建设的成果，体验前沿科技。参会嘉宾对智慧银川所取得的有目共睹的成绩赞叹不已，对银川在智慧城市建设中的创新精神和担当作为不住点赞。
