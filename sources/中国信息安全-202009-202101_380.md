# 行业 | 构建安全驱动型SD-WAN Fortinet进入2020 Gartner广域网边缘基础设施领导者象限

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=2664132995&idx=5&sn=564b781745f039b134967301673a2706&chksm=8b5e737abc29fa6c644ff008f7e2e1c7d255ffbf013b023a3b9d2813c2f5b16f769a3126e834&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664132995&idx=5&sn=564b781745f039b134967301673a2706&chksm=8b5e737abc29fa6c644ff008f7e2e1c7d255ffbf013b023a3b9d2813c2f5b16f769a3126e834&scene=27#wechat_redirect)

近日，Gartner发布了2020年度广域网基础设施魔力象限（Magic Quadrant for WAN Edge Infrastructure）报告。在此报告中，Fortinet被Gartner列为领导者象限中的第二位。与此同时，在Gartner针对全球企业网络设备的市场调研中，Fortinet以10%的市场份额位列全球第三位。Gartner评价：Fortinet在全球范围拥有超过30000家广域网边缘设备用户，以及超过8000家SD-WAN用户，遍及所有规模的众多行业用户，包括零售、生命健康、制造、金融和教育等。其中，Fortinet是本次研究中安全解决方案能力最强的供应商之一， 结合SD-WAN能力后，提供了最完善的解决方案。

![](../Images/39bf900e47eda414df1cec84efad68e3.png)

Fortinet 在去年入选Gartner网络防火墙领导者象限后， 能够继续在SD-WAN领域中再次脱颖而出成为领导者，背后都源于Fortinet的核心战略——为用户构建安全驱动型网络。

随着数字化转型进程不断加深，以及网络加速技术在云计算的广泛应用，让广域网边缘基础设施进入了革命性升级的巨大浪潮中。SD-WAN因此成为了近几年市场增长最快速的网络技术。但是采用SD-WAN技术的组织所面临的最关键挑战之一是大多数广域网边缘设备安全能力不足，需要客户部署一个独立的安全解决方案，这无疑增加了管理的复杂性和开销，削弱了SD-WAN本应提供的节省部署时间和总成本的效果。而且，由于安全和网络没有完全融汇，并且不能通过单个管理控制台进行管理，因此会在可见性和控制方面产生断层。Fortinet在解决上述问题方面无疑拥有得天独厚的优势。首先，Fortinet在企业级路由方面有着深厚的基础，并且在为全球分布式企业提供高级网络部署方面有着悠久的历史。其次，Fortinet FortiGate拥有业界出色的安全效能和性价比，在结合SD-WAN功能后，能够让用户在兼顾安全性，网络性能的同时最大化降低整体投入成本。在管理方面，Fortinet在原有管理平台（Fabric Manage Center）基础上增加了SD-WAN Orchestrator编排平台，进一步提升针对大规模复杂场景SD-WAN网络的部署和管理能力，降低运维成本和复杂度。此外，针对基于SD-WAN延展出的场景——SD-Branch，Gartner在本次报告中也有判断：分支机构广域网边缘设备的功能在发生快速变化，从专业单独的路由，安全和广域网优化设备演进到多功能的SD-WAN设备。SD-WAN正在通过其应用感知的多链路智能选路功能、集中编排、原生安全、以及应用性能优化等功能替换传统分支路由器。这正是Fortinet擅长之所在。Fortinet作为倡导“安全SD-WAN”和“安全SD-Branch”的行业领导厂商，所推出的解决方案能够适合所有场景部署，包括：

*   分支机构通过互联网和专线/MPLS访问总部/数据中心；
    
*   远程办公人员通过互联网和VPN访问总部/数据中心/公有云（IaaS和SaaS）；
    
*   总部/数据中心访问公有云（IaaS和SaaS）；
    

  
能够为用户实现：

*   提升业务应用性能。通过6000+应用特征以及互联网服务数据库精准识别应用，基于混合广域网连接进行基于链路质量的智能分流，保障关键业务应用性能和用户体验。
    
*   提升企业组网效率。通过SD-WAN Orchestrator，加速零接触部署的效率，为用户提供统一视图和管理平台，简化针对SD-WAN设备和网络的管理复杂度，并对全网有更清晰的链路质量和应用体验感知。
    
*   提升上云体验。通过与公有云平台原生服务进行集成，FortiGate能够让用户更方便的与公有云网络连接，并通过与运营商合作伙伴构建的骨干网PoP节点实现快速的云直连，优化到公有云IaaS和SaaS的连接性能与稳定性。
    
*   提升多云互联的敏捷性。通过在多云上部署FortiGate，能够为用户构建一张跨多云的SD-WAN网络，让用户管理多云的连接以及安全像管理分支机构一样简单方便。
