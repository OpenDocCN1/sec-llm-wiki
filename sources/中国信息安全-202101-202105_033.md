# RSAC技术观察丨Rohit Ghai口中的弹性之旅

RSAC 2021的主题是“Resilience”， RSA的CEO Rohit Ghai发表了题为《A Resilient Journey》（弹性之旅）的主题演讲，他提出当前网络安全的重点在保持系统的“弹性”。而思科董事长Chuck Robbins在他的主题演讲中也提到“每个行业的每个组织都致力于保持业务弹性。我们的目的就是希望能够为所有人打造一个更具包容性的未来，而安全必须是一切的中心”。”弹性”已然是目前行业最热的关键词。对于”弹性”的概念，NIST早在2019年就发布了《开发网络弹性系统》（NIST SP800-160 Vol. 2），其中弹性的目的是预防、防御、恢复、适应那些施加于网络系统的攻击和压力。就如同 Ghai 演讲中举的例子，网络攻击就像我们起床时会摔倒，保持“弹性”意味着要求“我们必须减少摔倒的次数，更好地承受住摔倒，并且每次都要很快站起来”。这个比喻非常巧妙，在构建具有“弹性”的网络时，网络安全行业的共同目标就是尽量避免攻击、减少攻击损失、快速恢复，具体到实战中，安全系统需要实现攻击预警以规避攻击、实现风险管控以降低损失、实现及时的响应联动以快速恢复。下面我们展开来看：

  

**一、攻击预警：混沌和弹性的交织**

如同 Ghai 在演讲中提到的，“chaos”（混沌）是当前网络安全格局最好的描述。而企业需要做的是在混沌中不信任任何人和区域，不断评估不同类型的风险和攻击，对风险作出提前预警。如果没有检测和预警措施，企业就不知道需要自己保护什么，一旦有了可靠的预警，企业就可以通过这些信息来针对性的处理。这一点来看，目前国内的态势感知系统正是这一理念的最好落地，新华三认为态势感知系统是以安全大数据为基础，对能够引起网络态势发生变化的要素进行获取、理解、评估、呈现以及对未来发展趋势预测的一个过程；是从全局视角提升对安全威胁的发现识别、理解分析、响应处置的一种能力；是通过智能分析和联动响应，结合机器学习和人工智能，实现“安全大脑”的闭环决策，实现安全能力的落地实践。

![](../Images/4ad861a1ce7714db0b006531ad879043.png)

  

**二、降低损失：零信任与风险评估**

零信任的概念对于实现弹性也至关重要。零信任可以“基于风险确定优先级并保护最重要的事物，确保当我们跌倒时，我们能够承受损失”。最重要的是将信任限制在绝对需要的范围内，决不要基于不可靠的因素提升信任。零信任既是一种理念也是一种架构，其最重要的三个原则——永不信任、持续验证、最小授权，能够最大程度减小组织被攻陷的可能性，更重要的是，零信任能够将攻击的损失降低到最小。构建零信任安全访问系统是实现弹性理念的重要手段。在零信任理念下，企业需要最先完成网络安全风险的评估工作，以确定优先级，这需要企业能够构建正确合适的风险评估体系框架。需要注意的是，在评估风险时，漏洞最多的资产不等于风险最大的资产。目前业界提出零信任理念的不少，但各有各的思路，用户在实际建设中往往找不到发力点。新华三的视角下，希望真正搭建一个可实现能落地的技术框架，通过用户风险、终端风险、UEBA等信息，利用动态防火墙技术快速建立安全防御策略、准入策略，从而动态地调整安全访问策略。同时需要能够支持应用、功能、身份、接口等，最小化原则进行访问控制授权，即使获取了某台服务器的权限，也无法对其他服务器进行横向渗透。这个架构中需要具备多因素认证能力，创建账户体系，也可以同步现有的身份管理系统，能对员工、供应商、合作伙伴、客户等对象进行管理，保障用户身份和设备的合法性。提供整体的用户登录入口，实现统一登录，并构建统一的工作入口，实现跨设备的统一管理，保障数据与应用安全，大幅提升用户体验。与此同时，默认关闭所有端口，攻击方端口嗅探和漏洞扫描等信息探测搜集手段不会得到任何响应，可屏蔽所有系统平台的漏洞暴露。

![](../Images/52d0ec2c9956a4d5d26a0138cd6d4b31.png)

  

**三、快速恢复：技术与人**

快速恢复是弹性理念区别于其他理念的特点之一。实现快速恢复的要点，一方面需要将出现问题的资产快速突显，另一方面就是需要快速响应和处理。从技术的角度，我们可以通过网络隔离和网络分段技术——无论是东西向还是南北向分段，将受到攻击的部分隔离开，在保护正常网络资源的同时，为精准处理提供条件。从人的角度，网络安全社区需要更多的包容性和多样性，通过“招募比对手更好的人”来应对，提升网络攻击防护的能力和安全事件处理的效率。同样举一个实际应用案例的话，新华三在态势感知全网协同联动方面的SOAR（安全编排、自动化与响应）技术正与之契合，它可以使组织能够收集来自不同来源安全威胁数据和警报，利用人工和机器组合能力执行事件分析与分类，从而定义、确定优先级，并根据标准工作流驱动标准化的事件响应活动，企业可使用 SOAR 工具在数字工作流格式中定义事件分析与响应过程。利用SOAR技术，实现网络结构的快速恢复。
