# 行业 | 中国版权保护中心与阿里华为共建DCI实验室 入选国家新闻出版署重点实验室

用持续创新的技术和机制，去保护知识产权创新，在数字经济飞速发展的当下尤为重要。近日，国家新闻出版署发布了出版业科技与标准重点实验室名单，由中国版权保护中心牵头，联合阿里巴巴、华为共建的DCI技术研究与应用联合重点实验室（下称“DCI实验室”） 成功入选成为全国42家出版业（含版权）科技与标准重点实验室之一。据悉，这是DCI实验室继2016年被原国家新闻出版广电总局批准成为首批出版业科技与标准重点实验室以来，再次被评定为该行业领域的部级重点实验室。

![](../Images/3db48019dd27f7c8238e3460c0e295be.png)

**DCI实验室成功入选成为全国42家出版业（含版权）科技与标准重点实验室之一**DCI（即Digital Copyright Identifier，数字版权唯一标识符）体系是数字版权公共服务领域的一项重大创新成果，其核心是标识和描述互联网环境下权利人与作品权属的一一对应关系，建立内容创作、使用、传播行为与其行为主体之间的权、责、利关系认证体系。通过“嵌入式”版权服务，为互联网平台的数字作品版权分配DCI码、DCI标，可使数字网络环境下的每一个数字作品都具有唯一的身份标识，进而实现数字作品版权确权、版权费结算认证、监测取证快速维权等功能。“换言之，将来我们平台的商家以及用户发布最新商品时，只要上传自己的商品图、设计图、展示图等都可以快速获得数字版权标识，真正实现‘创作即确权’，缩短原创保护的路径，”阿里巴巴平台治理部原创保护平台负责人王华丹表示，通过对区块链、人工智能、大数据等先进技术系统集成，可以保证DCI码的不可伪造、不可篡改等优势，从而解决著作权人作品被侵权盗版的困扰，促成数字作品的合理利益分配，“使用者需付费才能使用版权作品，创作者还可以自己定价。”王华丹指出，DCI体系的理念与阿里在原创保护领域探索的实践经验可谓异曲同工。2018年8月，阿里巴巴原创保护平台上线，让在淘宝天猫首发创意手稿的商品图，经过原创性审核后就能获得阿里巴巴联合权威公证机构颁发的唯一“出生证”，破解原创商家创作难、抄袭易、确权维权成本高的难题。尤其基于时间戳的电子存证以及基于深度学习的商品理解与视觉检索等原创AI识别技术，为商家进行“一键备案确权”。保护原创就是保护创新，截至目前，阿里原创保护平台已保护超4亿张图片、超200万条短视频、超10万张设计手稿，首发创意商家店铺年均GMV已接近2000万，新商家年均GMV是普通新商家的10倍。“依托DCI实验室，我们将继续共同推动以DCI体系为核心的版权资源编码与管理、版权数据管理与运营、区块链与人工智能等技术集成应用、互联网版权保护机制创新，未来DCI体系也将与我们的原创保护平台打通，让商家和用户享受到更优质的版权保护服务。”王华丹表示。中国版权保护中心相关负责人表示，DCI实验室是由中国版权保护中心与阿里、华为强强联合组建的集“政、产、学、研、用”于一体的跨领域综合性实验室，将继续系统集成阿里巴巴知识产权保护团队、阿里巴巴感知与认知智能团队等国内领先、国际一流的人才、技术和资源优势，为创新机制加快建设我国自主创新的DCI体系，大力推进互联网版权基础设施建设应用，有效助力国家层面以版权服务为进路探索实践互联网内容治理新机制，升级打造“共生、共治、共享”的互联网版权产业新生态等方面提供更加有力的科技支撑。

（阿里巴巴供稿）
