# 全国政协委员周鸿祎：用好大数据，要运营安全两手抓

2月24日晚，央视新闻联播报道，在政协第十三届全国委员会第四十九次主席会议上，全国政协委员、360集团创始人周鸿祎作了题为“做好数据资源的开发利用保护”的汇报。

![](../Images/9a95613ae7f9799a3b490a40739f3a93.png)

“数据运营是长期持续的，不存在交钥匙工程”，周鸿祎认为，衡量一个城市、一个企业的大数据能力，重点不在于数据的数量、种类、新鲜度，而是看有没有数据持续运营的能力，很多城市大数据业务模式失败的原因就是因为没有建立持续运营的模式。

除了做好运营外，安全也是大数据开发利用的“必答题”。周鸿祎认为，当前，大数据面临网络攻击、勒索攻击、数据污染攻击、数据内部泄露等一系列威胁。此外，大数据的流动共享开放，放大了网络攻击风险，高级别网络攻击也“虎视眈眈”。为应对这些安全挑战，周鸿祎也开出了“药方”。“传统的碎片化防护无法适应网络威胁的新挑战，需要建立体系化的协同联防体系” ，周鸿祎指出，要在国家、城市及各行各业建立体系化的防御能力，形成协同联防，整体提升大数据安全水平。

（360供稿）
