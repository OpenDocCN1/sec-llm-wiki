# 大咖谈 | 回顾2020，展望2021（拥抱数字未来和新安全）

2020是跌宕起伏、刻骨铭心的一年，抗击疫情、国际环境复杂多变、“十四五”开篇⋯⋯我国网络安全产业也迎来了不平凡的一年。在各类因素的交织下，我国的网络安全产业即迎来了发展机遇，也面临着数字经济所带来的新型挑战。我刊邀请了政府、行业、企业的权威专家，请他们共同回顾对2020年产业的观感，对2021年的期许。

  

  

**以系统观念加固数字化时代底板**奇安信集团董事长  齐向东回顾这一年，我印象最深的关键词是数字化、系统化、新阶段。 网络安全成了数字化时代的底板。新冠疫情推动全球加速进入数字化时代，网络安全的重要性进一步提升。没有网络安全，就如同木桶没有底板，数字技术的作用会大打折扣，甚至威胁到人们的生命安全。今年9月，德国一家医院遭勒索攻击，导致系统瘫痪，患者因治疗延误不幸身亡，这是网络攻击首次危及人类生命的事件。因此，我们必须不断加固网络安全底板，才能更好地化解未知风险。网络安全系统化建设成为必然趋势。“十四五”规划建议指出，要“坚持系统观念。加强前瞻性思考、全局性谋划、战略性布局、整体性推进。”这既是我国经济社会发展必须遵循的原则，也是网络安全建设的必然趋势。只有进行系统化的安全建设，才能真正实现关口前移，防患于未然。因此，奇安信创新提出内生安全框架，用系统工程的方法，将安全能力统一规划、分步实施，内置到信息化环境中，帮助各个行业建立无处不在的安全“免疫力”。 网络安全产业迈入新发展阶段。党中央提出，我国进入了新发展阶段。网络安全作为国家支柱性产业之一，迎来了发展新高潮。随着新基建的加速推进，数字技术的深入应用，网络安全需求将出现井喷式增长。多家机构预测，未来我国的网络安全市场平均增速在25%以上。按这个增速发展15年，2035年网络安全市场规模将超过2万亿。百年征途谋新篇，雄心壮志启新程。奇安信将充分把握新发展阶段的机遇，为实现第二个百年奋斗目标不断拼搏奋斗。

  

**网络安全产业呈现“四化”趋势**天融信科技集团董事长兼CEO  李雪莹2020年新冠肺炎疫情在全球肆虐，促进了远程办公、在线教育等技术的快速普及应用，人们的工作生活方式发生了结构性的变化，社会运行对网络与信息基础设施的依赖大幅度提升，与之对应，网络空间安全将面临更大的潜在威胁与挑战。当前网络安全产业呈现出四大发展趋势：国产化——未来网络安全产品和技术的发展将基于国产化的核心技术，包括基础软硬件、核心部件的国产化；行业化——网络安全已经渗透到信息化的各个方面，网络安全与行业业务深度融合，场景化安全解决方案服务于各细分行业创新发展；服务化——网络安全的本质是人与人的对抗，网络安全产品正逐步工具化，整体安全能力的交付向服务化转型；智能化——人工智能进入到蓬勃发展阶段，智能化在信息化中逐渐发挥重要作用，人和机器结合的智能化，使安全效率得到显著提升。未来几年，随着国家新基建工作的大力推进，网络安全作为保障新基建安全的重要基石，也将迎来产业蓬勃发展的新机遇，即便有疫情的影响，我国网络安全产业有望保持持续增长的良好态势。

  

**推进网络安全从产品向平台和服务的转型升级**新华三集团副总裁 安全产品线总裁  孙松儿在新兴技术深度参与行业数字化转型的新趋势下，网络安全与垂直行业深度融合发展态势已经初步形成，并成为各行业数字化基础设施不可或缺的组成部分。新趋势下，要求网络安全要与所有最新信息科技及业务深度融合；要求安全产品能够弹性、敏捷、智能和协同以适配业务和场景的变化；要求安全人才具有复合背景，能够跟进最新信息科技，洞悉行业个性化安全特点和需求。 网络安全将实现从粗放式安全管理到精细化安全控制的转变，从外挂式防护到内生式安全的转变、从被动响应向主动安全的转变。为此，安全厂家需要致力于推进安全由产品向平台和服务的转型升级，构建安全大数据分析平台、安全云服务平台、安全攻防试验平台和安全技术创新及人才培养平台。2021年，产业仍需持续增加对安全领域软硬件的研发投入，如芯片、操作系统、数据库、中间件的安全防护领域。其次，需要尽快建立网络安全前沿技术协同创新平台，提早谋划，预先布局，推动网络安全技术协同创新，并在平台上进行技术验证、原型研制和标准制定，实现技术上的赶超。再次，构建网络安全生态产业发展平台，网络安全领域涉及多个产业细分领域，通过集合产业上下游企业，构建“终端+网络+云平台+服务+培训”的产业生态环境，形成聚集效应。最后，加强产学研合作，培养大量网络安全领域人才。

  

**以全流量应对全新网络安全挑战**科来公司副总经理  高彦刚回顾2020年的网安局面，与往年最大的不同是疫情带来的颠覆性变革，一方面提升了大家对网络安全的重视，另一方面新应用、新场景不断涌现，网安问题泛在化和内生化特性显现，安全市场从合规驱动走向业务驱动和竞争力驱动等。同时，安全能力成为企业的核心竞争力，贯穿于企业研发、生产、流通、服务等全过程。2021年网安行业势必掀起更猛的风浪。首先，网络安全市场将进一步规范化、标准化。多部相关法律的陆续出台，将进一步加快构建用户、企业、政府等多层级协作的个人信息保护体系，促进各方从产品形态、数据应用机制、技术安全措施等多维度落实合规要求。其次，新基建、新技术应用、新业务场景密集爆发，安全新赛道层出不穷，市场机遇巨大。此趋势下，安全厂商的生态理念也将改变。一方面用户越来越重视安全实战效果，另一方面用户更希望由原来网络威胁单点叠加式的防护手段转变为多层次、全方位的立体防护体系。此外，用户的网安体系建设将更要求贴合业务，并融入前沿科技应用。2021年，科来将一如既往借助全流量分析技术，聚焦行业领域，打造动态安全模型，为企业用户提供模块式、可迭代的安全产品和服务，帮助用户实现强有力的网络空间管理闭环，做到更加主动的安全防护。

  

**2020年电磁安全重要性凸显**安方高科研究院院长  许耀伟在新技术所带来的的信息化浪潮中，网络安全始终是安全运维的关键与前提，电磁安全作为网络安全的基础屏障和支撑，重要性愈加突显。电磁安全通常包含“防电磁干扰”“防电磁破坏”“防电磁窃密”三个方面。其中“防电磁窃密”是主战场，“电磁窃密”结合APT攻击得手成功的案例更是比比皆是，这也是科研机构长期关注的主要研究方向和从业企业的研发生产重点。随着我国5G移动商用化推进不断加速，“防电磁干扰”需求也日益强烈。同时，随着世界格局的动荡，斗争形势的严峻，西方军事强国对电磁打击手段愈发重视，电磁脉冲武器（EMP）日渐丰富和实用，未来“防电磁破坏”“抗电磁攻击”的军事需求也将会剧增。总之，随着5G移动网络的大规模普及和不断渗透到社会生活的各个角落，电磁安全领域所面临的威胁和挑战也迅速增加，相关主管部门必须及时做出准确的预判和恰当的决策，相关科研机构和从业企业也要顺势而上，不断开发电磁安全防护新技术、新材料、新工艺，筑高筑牢我国信息网络安全的电磁屏障。

  

**网络安全更加强调有效性**北京永信至诚科技股份有限公司董事长  蔡晶晶2020对于所有人来说都是极其特殊的一年，高速发展的数字经济下，网络安全作为新基建中的“基建”，一方面在系统规划设计之初，就将安全作为前提，将安全论证前置，以规避快速发展的新技术可能存在的风险问题，在谋求发展的同时实现网络安全能力的持续增长，助力新基建平稳落地；另一方面，安全防御工作更强调有效性。过去网络安全工作更多的是以合规为导向，很多时候是为了应对安全检查等才去采购设备、做网络攻防演习，今年一个明显的变化是，各政企单位更加主动理解网络安全的意义和任务，履行网络安全防护和主体责任，积极通过攻防演练、风险验证、主动防御等有效手段来应对这种未知威胁。与此同时，网络安全各类创新技术也不断涌现，围绕业务变化不断进化，以有效解决更广范围的安全防御问题。网络安全产品自身的安全性问题也引起了广泛关注。2020年，“人是安全的核心”这一理念价值更加明显，全社会力量共同参与，为实战人才的培养、选拔、评价，提供更好的土壤，以适应数字产业的快速发展。通过网络靶场演习、众测和竞赛选拔等模式进行实战型人才培养与训练，为国家及各行业选拔、推荐、储备人才，以此形成连带效应，促进全国各行业网络安全建设，守护网络空间安全，让人民群众拥有更多的幸福感和安全感。

  

**安全防护应重点防范未知威胁**六方云董事长  任增强2020年的国际局势，让我们真正认识到对抗会成为未来的一条主线，其中网络安全成为对抗中的重要一环。从2021年开始，关键信息基础设施的网安建设，不仅是要满足合规，更重要的是满足未来有组织攻击下的安全。有组织的攻击大多通过未知威胁进行攻击，因此，防护要求应从防已知威胁到重点防未知威胁。物联网安全产业在2020年热度最高，无论是车联网安全、工业物联网安全、还是智慧城市中的物联网安全都得到了社会广泛的关注，未来几年必定是发展最快的领域。谁掌握技术制高点，谁就拥有未来。2020年，六方云在工业物联网安全相关技术、人工智能检测未知威胁、云安全微隔离技术产品均处于业界领先水平，将以保卫国家关键信息基础设施安全方面发挥更加重要的作用。

  

**工控安全是工业互联网安全的基石**杭州木链物联网科技有限公司副总裁  赵宇新一代的工业变革正在如火如荼地进行，工控安全作为工业互联网安全的基石，在工业互联网的建设中必不可少，但实际上大部分工业企业信息化水平较低，还处在刚进入OT层联网的阶段，首先要做的就是工控安全。当前，工控安全普遍面临着三个痛点问题，一是“听不懂”：工业行业种类繁多，各种工控通讯协议冗杂，首先要做的就是对协议进行深度解析。二是“算不清”：工业现场每时每刻都在产生大量的数据，随着时间的累积，日益庞大的数据库需要一个更高效的数据处理方式。三是”用不好”：每个工业场景有其独特的特点，无法用一个通用的场景去解决每一个细分场景的问题，需要做到快速适配工业场景。因此，木链科技提出“三位一体安全体系”：安全技术为基础，安全管理体系为支撑，安全服务体系为保障；以全面安全防护、统一安全管理和持续安全服务为手段，提升工控系统安全防护能力，打好工业互联网发展的基石。

  

**零信任是未来安全趋势**芯盾时代创始人兼CEO  郭晓鹏当前，移动成为设备、业务和人员的基本属性，原访问控制模式已不再适用，基于零信任模式的需求在逐步深化。疫情促进了各行业的数字化发展，加速了远程办公的发展和落地，但网络边界消失、网络环境和不安全设备也让企业的数据泄露风险陡增，企业的安全需求随之增长，网络安全防护能力也成为企业数字化发展中的重要能力之一。新形势下，企业机构亟需新的网络安全模型为数字业务提供有效业务防护，零信任安全是安全思维和安全架构进化的必然结果。零信任理念“不以边界作为信任条件”更符合企业当下的安全需求，尤其对降低可能的巨额业务损失有着重要价值，是企业业务安全防护的基础理念。在数字时代的发展浪潮中，“人”是网络核心价值点，从设备、身份和行为等维度入手，持续验证“人”是否可信，以此抵御新型业务风险。业务依托安全，安全助推业务，这正是芯盾时代“以人为核心、以业务安全为基础的业务智能”的发展理念。
