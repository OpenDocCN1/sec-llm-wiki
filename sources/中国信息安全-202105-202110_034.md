# 行业 | 知道创宇圆满完成第十四届全运会网络安全保障工作

近日，第十四届全运会在西安圆满落幕，本届全运会是在中国共产党成立100周年、我国开启全面建设社会主义现代化国家新征程的重要节点举办的综合性体育盛会，也是我国提出到2035年建成体育强国、健康中国后举办的一次重要综合性运动会。

  

![](../Images/603b70d48118e3e8aea19fd4ad5ffff1.png)

**第十四届全运会闭幕式**

  

为确保西安市重要网站、系统、数据和关键信息基础设施“十四运”期间安全、可靠、稳定运行，在中共西安市委网信办、西安市公安局领导下，知道创宇专门成立国家“十四运”重大活动网络安全保障作战指挥部，从公司各部门抽调顶尖安全专家组建重保工作小组，使用**统一云监测 ScanV MAX、统一云防御、态势感知平台**等核心产品，圆满完成党政机关网站和重要信息系统的网络安全保障工作，无一例被黑事件发生。

  

自今年7月份起，知道创宇云防御提前定制部署**统一云监测/云防御平台、网络安全态势感知平台**，对西安全市的网络安全态势全面洞悉，**“未雨绸缪”**事前设防监测业务系统威胁，**“滴水不漏“**动态防御矩阵拦截各类网络攻击，**“运筹帷幄“**态势感知大图安全趋势一目了然。

  

重保工作小组安排业务支撑团队、平台保障团队、产品研发团队以及404积极防御团队在北京、成都、西安（统一云防御本地驻场）三地联动7\*24小时持续高强度保障，全方位保障十四运期间陕西网站集群业务系统安全稳定进行。

**重保小组7\*24持续高强度保障/成都**

  

![](../Images/6518e50d2df5c293fd2114dd9b5afec7.png)

**重保小组7\*24持续高强度保障/北京**

  

**“未雨绸缪”**

**统一云监测提前部署全面监测**

  

为确保全面掌握业务系统威胁态势变化，知道创宇云防御提前布局西安市统一云监测平台**ScanV MAX**，对接入平台的关键业务系统进行周期性扫描，提供包括可用性、安全事件、漏洞扫描等多维度全方位监测服务，发现中高危漏洞2.7万余个，并第一时间通过短信、邮件、微信以及站内信等多种方式快速告警并提供专业处置建议，帮助运营者及时感知并快速处置。

  

![](../Images/43032d706a723c700e850238163af7b6.png)

**统一云监测平台**

  

**“滴水不漏”**

**统一云防御全面保障业务系统稳定运行**

  

面对高度分散且数量众多的业务系统，知道创宇云防御部署的**西安市重保云统一管理平台**出色完成本次网络安全保障任务，通过对所接入的网站业务系统进行统一管理、监测和防护，在重保期间共计拦截 1.13亿次Web应用类攻击，1.7亿次DDoS类攻击，基于创宇安全智脑的700余次数据分析，完成策略调整、协同防御更新等17000余次。在统一云防御平台动态防御矩阵的支撑下，网站运行安全稳定，各类攻击均未对网站业务造成影响。

  

![](../Images/b1a4e35e942a72a9715eaeb14950af7f.png)

**西安市重保云统一管理平台**

  

**“运筹帷幄”**

**统一态势感知让安全威胁“看得见、看得清”**

  

除了在事前设防监测业务系统的各种威胁，在事中动态调整拦截各类网络攻击，知道创宇云防御还部署了**网络安全态势感知平台**，将接入系统的关键业务系统的威胁数据（漏洞、安全事件等），攻击数据（Web应用类攻击、DDoS攻击等）通过大屏可视化呈现，多角度展示，基于创宇安全智脑的大数据分析，推送常态数据态势报告十余期，做到“看得见、看得清”，真正实现知己知彼，百战不殆。

  

![](../Images/f6d3e6655c6e410bbed807e243d5ae82.png)

**西安市互联网重要信息系统安全监测防护平台**

  

不忘初心 为国为民

  

在本次十四运重保期间，知道创宇云防御在事前采取了完善的应急预案和响应流程，西安驻场安全专家在前场明确实施方案、流程，应急信息收集，北京和成都安全专家远程实现方案部署，落实相关安全防护策略并同步办公画面，实时协作完成支撑，圆满完成第十四届全运会网络安全保障工作，赢得了安保网络主管单位的高度认可。

  

历年来，知道创宇多次参与到国家级重大会议与活动的网络安全保障工作中，为各级关键信息基础设施系统提供坚实防护，凭借专业技能和长期积淀，以及“客户至上，用心服务”的服务理念，收获数次致谢肯定，也充分证明了知道创宇安全服务与防御能力的扎实可靠。
