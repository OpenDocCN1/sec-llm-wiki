# “CISP持证人员能力提升计划”重磅推出 全面赋能国家信息安全专业人才培养

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzE5MDAzOA==&mid=2664156005&idx=2&sn=bcb153582d561f940a80d738a0dba404&chksm=8b5ec99cbc29408a9b7a6ba068e79c94f0c76547c268ae253b2706104e91e151cd0b56d8d33b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664156005&idx=2&sn=bcb153582d561f940a80d738a0dba404&chksm=8b5ec99cbc29408a9b7a6ba068e79c94f0c76547c268ae253b2706104e91e151cd0b56d8d33b&scene=27#wechat_redirect)

2021年底，在中国信息安全测评中心的支持下，《中国信息安全》杂志社联合国内CISP授权培训机构推出“CISP持证人员能力提升计划”。该计划的推出，将进一步强化对我国信息安全专业人才的网络安全政策引导和长期专业能力的培养，达到构建业内信息沟通有效桥梁、为企业培训业务持续赋能等目的。CISP是注册信息安全专业人员（Certified Information Security Professional）的简称，是中国信息安全测评中心（以下简称国家测评中心）为满足社会各界对于专业安全人员的迫切需求，建立和发展出来的一套信息安全保障人才体系，是国家实施的一项对信息安全人员执业资质及资质能力的国家级认证。自推出CISP资质认证和培训体系20年以来，经国家测评中心授权的CISP运营及培训机构数十个，已获证CISP专业人员超过14万人，为我国构建了坚实的信息安全人才培养和支撑体系。当前，信息安全重要性日益凸显，意识形态领域斗争日益严峻，持续性地抓好信息安全专业人才的政策宣传、舆论引导、技术提升、拓展视野至关重要，将直接影响到我国网络安全的总体保障能力建设。《中国信息安全》杂志社作为我国网络安全权威期刊，以全面推进我国信息安全政策宣贯、信息安全管理和技术创新，推动信息安全人才培养和行业发展为己任，在国家测评中心的支持下，联合国内CISP授权培训机构及时推出“CISP持证人员能力提升计划”。该计划主要通过杂志、微信公号、以及行业研讨会等多种方式，进一步强化对已获证CISP持证人员的政策宣传、舆论引导、国内外信息安全热点事件分享、前沿技术研讨、优秀研究成果和风采展示等，达到推动信息安全专业人员政策素养，强化舆论导向、提高长期专业技术能力，为企业培训业务持续赋能等目的。该计划的推出，对于新时期推进我国信息安全保障工作具有重要意义。“CISP持证人员能力提升计划”自2021年底推出以来，立即引起了国内信息安全企业和信息安全专业培训机构的关注。作为首批参与该计划的企业之一，国内信息安全行业领军企业——启明星辰集团等第一时间加入“CISP持证人员能力提升计划”，并通过为全部CISP学员长期订阅《中国信息安全》杂志，参加行业高端交流、专题研讨等提升计划的初步实施，在助力学员长期专业能力积累、提升企业培训业务服务品质等方面取得良好成效。下一步，“CISP持证人员能力提升计划”还将在全国CISP授权培训机构中进一步展开，全面赋能国家信息安全专业人才培养，成为持续强化我国信息安全专业人员能力建设和推进新时期我国信息安全工作的重要抓手。启明星辰集团旗下的“知白学院”是国内最早的专注于网络安全人才培养的培训机构之一，也是第一批CISP授权培训机构，CISD（注册信息安全开发人员）授权运营中心。经过二十年来培训与教学实践，“知白学院”积累了丰富的CISP/CISD培训经验，在网络安全培训教育的技术先进性、广度与深度，及人才培养服务体系的质量和规模等方面富有良好口碑，受到行业推崇和学员欢迎。此外，“知白学院”长期致力于打造“产学研用”一体化人才培养和运营平台，已累计为政府及各大行业组织提供安全培训千余次,参与组织重大安全竞赛 170余次,培训行业安全竞赛获奖人员近700余名，培养安全技术及安全管理人才50000余名，为推进我国良好网络安全生态体系构建发挥了积极作用。
