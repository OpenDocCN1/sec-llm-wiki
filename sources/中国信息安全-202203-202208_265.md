# 闪亮RSA | 绿盟云安全服务再升级，提供一站式应用及网站防护

RSA2022大会于旧金山时间6月6-9日在美国举办。作为全球网络安全风向标，云安全在本次大会受到了极大的关注，这也意味着随着数字化经济的发展，在全球为用户提供弹性、敏捷的安全闭环保障能力已成为一种趋势。绿盟科技在本届大会上，面向国际市场推出了全新升级的绿盟国际云安全服务（NSFOCUS Cloud Security Services），吸引了众多参会者的目光。

![](../Images/1fe507b9787233f675f39d0cc2bc701b.png)

![](../Images/50619cefcd85a030e795f0853c68854c.png)

据了解，本次升级为客户带来了云Web应用和API防护服务（Cloud Web Application and API Protection Service）、网站安全监测服务（WebSafe Service）两项新服务，这两项新服务将同原有国际云清洗服务（Cloud DDoS Protection Service ）一起，为拉美、西欧、亚太及中东非洲区域的运营商、服务提供商、银行、企业、政府等客户提供更完善的一站式应用及网络防护。

随着数字化技术的广泛应用，企业面临的安全风险越来越严峻，在寻找全面的网络安全解决方案时，企业可能面临设备投资繁重、安全专业人员缺乏、多云架构复杂和带宽资源不足的痛点。据介绍，绿盟科技整合应用安全、漏洞管理、威胁情报、Anti-DDoS等方面的技术积累，依托分布在全球多个国家的绿盟科技安全运营中心（Security Operation Center）团队，为企业提供一体化且易于管理的云安全服务，实现敏感数据防护，确保其业务连续性，有效保护企业品牌和商业声誉。升级后的绿盟国际云安全服务有哪些亮点？**● 网站安全监测服务——迅速发现Web应用漏洞**作为一项云服务，本次新推出的网站安全监测服务可提供针对企业Web应用的7\*24小时全天候监控服务，确保企业不会因Web安全风险而遭受声誉损害。具体服务包括恶意代码注入监控和Web漏洞扫描，可保护Web应用程序免受网页篡改和漏洞利用；IP资产核查可以扫描并发现网络中所有暴露在互联网上的IP资产，让企业随时掌握自身资产暴露面；网络钓鱼攻击已成为网络犯罪分子最常见的攻击之一，网站安全监测服务可提供对钓鱼网站的全天候监控，并及时发出警告。**● 云Web应用和API防护——确保Web应用程序安全**绿盟科技的Web应用安全解决方案一直备受市场认可，多次入选Gartner、Forrester、IDC等全球知名市场报告。本次绿盟科技面向国际市场新推出的云Web应用和API防护，将Web安全防护升级为SaaS化的云服务。云Web应用和API防护可以快速部署、灵活升级，通过机器学习、智能补丁和自定义规则等技术，确保Web应用程序和API免受OWASP Top 10 和WASC漏洞的影响。**● 国际云清洗服务——确保业务连续性**基于深受国际市场青睐的抗DDoS解决方案，搭配绿盟科技自研的全球威胁情报，打造了绿盟科技国际云清洗服务。目前绿盟科技在全球拥有八个超级清洗中心，覆盖亚太、北美、拉美、欧洲等业务热点地区。通过Anycast技术，绿盟科技国际云清洗服务可实现全球节点联合近源清洗，拥有T级别清洗容量，可为客户提供无上限防护服务；同时通过绿盟科技全球骨干网络，为客户实现就近回源，优化网络时延和稳定性表现；还可提供多语种7\*24小时服务，可为对业务安全性有较高要求的客户提供管理服务和攻击事件应急响应服务。绿盟科技结合客户需求，提出了以“云运营再造新安全”为目标的云化战略——T-ONE CLOUD，以云的思路重构安全运营体系，围绕绿盟云安全服务平台为用户提供弹性敏捷的安全闭环保障能力。T-ONE CLOUD的绿盟云安全服务平台采用云化交付的安全服务体系，由云端安全专家为客户提供全天候、全方位、可信任的安全运营服务，通过融合、开放、协作的安全交付，保障安全能力动态提升，实现可观、可管、可控的安全价值。
