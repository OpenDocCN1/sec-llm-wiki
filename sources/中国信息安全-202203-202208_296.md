# 共同筑牢网络数据安全屏障

“没有网络安全就没有国家安全，就没有经济社会稳定运行，广大人民群众利益也难以得到保障。”

党的十八大以来，以习近平同志为核心的党中央高度重视网络安全工作，作出一系列重大决策、实施一系列重大举措，走出一条中国特色的治网之道。随着数字经济发展，数据的重要性愈加凸显，已然是国家安全的重要组成部分，加强网络安全管理，进一步筑牢网络数据安全屏障，成为摆在我们面前的重大课题。

![](../Images/71f366656368c34ebb6027037ab3729d.png)

**没有网络安全就没有国家安全，守卫国家数据主权刻不容缓。**当前，数据作为国家新型生产要素和基础战略资源，掌握多寡已成为国家软实力和竞争力的重要标志。面对部分数字经济强国和垄断资本千方百计收集人类生产生活信息数据，意图参与甚至干预全球经济、传播、社会等活动，守卫国家数据主权，迫在眉睫，刻不容缓，为此，中国密集出台《国家安全法》《数据安全法》《网络安全审查办法》等法律法规，不断加强立法和强化执法，以强有力手段提高数据安全保障能力，维护国家安全。

![](../Images/a4dc5bd7154c8754ea109187511b6620.png)

**没有网络安全就没有社会稳定，保障社会数据安全至关重要。**政府治理、基础设施运行、人们日常生活逐步架构在网络平台，一旦遭受攻击，将影响社会稳定运行，如：2010年，伊朗核电站被震网病毒入侵，离心机因转速失控而损坏；2017年美国征信巨头EquiFax发生1.43亿用户数据泄露，面临赔偿金额高达700亿美元……一次小小的网络攻击，就可能造成一个城市的混乱，因此必须时刻筑牢网络安全防线，持续紧绷数据安全这根弦。

![](../Images/58607cd14b276876c8f51661406302ca.png)

**没有网络安全就没有人民幸福，保护人民数据隐私不可或缺。**互联网通达亿万群众，截至2021年底，我国网民规模达10.32亿。互联网全面融入人们日常生产生活中，以电子等方式记录的个人信息大量产生，人们在享受服务的同时，也面临着个人信息泄露带来的困扰与风险，轻则骚扰推销电话源源不断，重则个人隐私公之于众，甚至账户钱款不翼而飞。因此，每个人都需要切实增强信息安全意识，尊重他人隐私，共同守护我们的数据安全。

随着数据安全监管越发严格，行业越趋自律，个人越加重视，定能创造更加安全、开放、可靠的网络空间，为推进网络强国建设、促进经济社会稳定发展、满足人民群众共同期盼提供坚实保障。

（来源：苏州新闻网）
