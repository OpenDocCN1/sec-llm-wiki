随着元宇宙概念持续走热，一些与其相关的概念或技术，如区块链、人工智能、虚拟现实等，也得到极大普及与关注。其中，一些概念在过去几年经历了诞生、发展、鼎盛的快速成长阶段，并成为元宇宙发展的“关键因素”与“标志风向”。非同质化代币（Non-Fungible Token，NFT）是其中的典型代表。因为 NFT 投资价值属性凸显且与其相关的事件频发，其获得的热度更甚于元宇宙，在一系列概念发酵与炒作中发挥了“头雁效应”。持续的热度与显性“机遇”背后，NFT 自身的发展难点与安全挑战，同样值得关注。

  

**一、NFT 的基本概念与历史演进**

NFT 是区块链技术的一个条目，是用于表示数字资产（包括图片和视频剪辑形式）的唯一加密货币令牌，其本质上是一种去中心化的数字账本技术。简单而言，NFT 就是将文档、图片、视频、音乐数字艺术品等产品进行数字确权，并使其以加密货币的形式流通、交易。

**（一）NFT 的四个显著特征**

如果将 NFT 和与其名字高度相似、普及度更高的同质化代币（如比特币、以太坊等加密货币）做比较，那么 NFT 则表现出四个显著特征。

**一是独一无二。**传统艺术作品的数字文件可以被随意复制，NFT 则以区块链确权的方式让这些艺术品获得具有独特标识的“数字身份证”。其创作者可以自行决定某一作品的发行数量并进行编号，流通、交易的每一个环节都通过区块链被完整记录，因而每份 NFT 自身都是独特的。区别于比特币等同质化代币具有相同的形态、价值特征，每一个 NFT都可以被看作互不相同的个体，其所具有的交易价值由交易者裁定且各不相同。

**二是不可分割。**每一个 NFT 的最小单位都是以一个整体存在，无法像比特币等其他加密货币一样以“1”以下的计量单位流通。

**三是延续收益。**按照不同平台的交易协议规定，NFT 商品的每一次交易都可以使其之前的历任所有者获得一定比例的分成。

**四是强调社交。**NFT 具有很强的文化属性和互动属性，参与者购买后就获得了其不可更改的所有权与使用权，而这种购买行为背后具有较强的社交意义，购买者可以借以彰显其在数字领域独一无二的购买能力、意趣品味甚至社交地位。因而，在技术层面的区块链确权问题基础上，NFT 的价值与所有权的承认需要丰富的社交活动与一定数量参与者的共识共同支持。

**（二）NFT 的三个发展阶段**

NFT 以各种娱乐性产品或社交活动为载体不断发展，其历程可分为模糊酝酿、建设发展、集中爆发三个阶段。

**1993 年至 2017 年，**业界对 NFT 的认识停留在概念的模糊酝酿阶段。NFT 的概念设计可追溯至1993 年比特币先驱哈尔·芬尼（Hal Finney）提出的加密交易卡（Crypto Trading Cards）。哈尔·芬尼在介绍加密交易卡时称，“想到了一个展示购买和销售的数字现金的方法——加密交易卡。密码学爱好者会喜欢这些迷人的密码艺术的例子。请注意，它完美的组合呈现形式是——单向函数和数字签名的混合，以及随机盲法。这是一件多么值得珍藏和展示给你的朋友和家人的完美作品。”哈尔·芬尼的这段话提出依托加密学和数学呈现形式随机排列组成一个系列的套卡，而这种卡可以兼具艺术品与数字货币的双重属性。2012 年出现的彩色币（ColoredCoin）实现了现实资产上链，而 2014 年创建的合约币（Counterparty）实现了点对点开放式交易平台的搭建。可以说，构建 NFT 的基本概念与底层技术在这一阶段逐渐成形。

**2017 年至 2020 年，**NFT 正式出现并借加密货币与电子游戏的“东风”茁壮成长。2017 年，同质化代币交易额与参与人数屡创新高，世界上第一个NFT 项目加密朋克（CryptoPunks）也作为一款像素角色生成器出现。其产生的像素头像被开发者通过区块链传播，以当时还不具备足够针对性的 ERC20通证标准作为基础协议，以以太坊进行结算，并以其独特性被虚拟货币从业者关注。ERC20 通证标准是在通过以太坊创建通证时建立的一种规范，可以为编写一个智能合约以创建“可互换通证”并实现与众多交易所、钱包的交互提供依据，现在已被行业普遍接受。此后，Dapper Labs 团队受加密朋克启发推出了专门面向构建非同质化通证的 ERC721通证标准（专门用于非同质化代币的标准接口），并基于此推出了一款名为加密猫（CryptoKitties）的产品。其推出的每一只数字猫都独一无二且不可复制，这种“以稀缺谋求价值最大化”的思路让加密猫迅速成为市场主流。NFT 开始以文娱特别是游戏产业为主赛道蓬勃发展。在此期间， OpenSea、SuperRare 等交易平台逐步成型，蒸汽（Steam）平台等游戏平台不断提出新的玩家需求。因此，NFT也得以进一步规范交易、扩张用户、丰富产品、捂热市场。

**2020 年以来，**NFT 借助此前积累下的用户群体与资本实现集中爆发，市场热度与社会影响力双线走高。新冠肺炎疫情暴发以来，英美等国政府借助发放货币刺激经济。传统的投资方案失去吸引力，更多人的风险投资行为变得大胆，进而将目光投向 NFT 等蓝海领域。据 NFT 数据网站 CryptoSlam统计，借助“疫情经济”的东风，幻想生物（AxieInfinity）等现象级产品累计交易量破 10 亿美元，游戏金融（Gamefi）性质产品层出不穷且获利颇丰。除了资本积累外，NFT 的社会影响力与知名度也不断提升。据谷歌官方搜索趋势数据显示，NFT 相关关键词的搜索量自 2021 年初起呈爆炸式增长，而斯诺登、特斯拉总裁马斯克、NBA 球星史蒂芬·库里等人的积极参与，也带来了名人效应。2021 年11 月 24 日，《柯林斯词典》将 NFT 评为 2021 年度词汇；12 月 20 日，《柯林斯词典》又评出了2021 年 12 大科技热词，NFT 以第一名入围。

  

**二、NFT 主要应用的“一体两面”**

根据美国区块链市场调查机构 Chainalysis 于2021 年 12 月发布的报告，当前全球 NFT 市场规模达到 269 亿美元，其在文化、虚拟资产、身份认证、元宇宙概念等方面已有广泛落地应用。但是，在NFT 市场应用逐步泛化的同时，其安全问题亦值得注意。

**首先，NFT 可有效解决打通虚拟资产交易壁垒，但交易过程难被监管。**NFT 可以实现原本较难以商品化的虚拟资产的可靠认证与流通，以统一的技术协议与“货币标准”进行流通、转让、确权。电子游戏资产是最为典型的代表。电子游戏近年来成为酝酿元宇宙世界观的重要领域，传统的游戏平台难以实现可靠、兼容的打通，单个游戏只能基于自身固化较小的用户群体，无法实现真正意义上的社交活动与商业交易。而 NFT 在游戏领域有得天独厚的适配性，可以让不同游戏商品在同一公开市场流通。玩家参与游戏需要消耗代币，但同时也可以通过交易获得代币甚至变现，虚拟经济与现实世界被打通。在交易繁荣的同时，NFT 作为一种加密货币具有较强的私密性，流通时产生的商品内容、议价权、参与者等要素仅由交易双方掌握决定。NFT 本身高度去中心化的特点令而现在的各类平台更多充当搭台者而非监管者，因而难以引入第三方干预监管。监管的空白将为违法违禁商品流通、变相资金输送、腐败及洗钱等违法犯罪行为提供空间。

**其次，NFT 被视为可能带来新的“文艺复兴”，但对文化繁荣的实际作用有待检验。**数字艺术的NFT 市场未来可能赶上甚至超过传统艺术品市场。一方面，NFT 去中心化的特点激发了大众的创造力，区块链认证的本质双向保障了创作者的版权与买方的权益。另一方面，NFT 文化产品市场基本实现了从无到有、从有到优的演进，传统文化产业也实现了从线下到线上的迁移，并以其新颖性吸引了更年轻、广泛的参与者。以文艺藏品拍卖行业为例，根据佳士得、苏富比先后发布的 2021 年年度报告，NFT 成交额均在 1 亿美元以上，且参与 NFT 竞拍买家的七成以上为首次参与拍卖，平均年龄均在 40岁左右。这说明加密艺术品吸引了大量用户进入文化艺术领域，特别是对新一代年轻用户有较强吸引力。但是，当前 NFT 市场存在较为严重的良莠不齐现象，“万物皆可 NFT”极大拉低了文化作品的门槛与标准，在促进文化繁荣、多元的同时也产生了诸多滥竽充数者。同时，许多亮眼数据一定程度只是资本狂欢与头部效应的片面体现，在真正的推广与应用上仍然面临用户基数不足、群聚效应明显、正确导向迷失、操作门槛较高等多重问题。这种有待检验的“文化繁荣”必然对文化的多样性、延续性等安全维度造成影响。

**最后，NFT 与元宇宙双向融合已是大势所趋，但两个概念风险叠加也是“一加一大于二”。**元宇宙与 NFT“入场玩家”高度重合，构建逻辑高度相似，发展路径相互补充。二者均以去中心化、强社交性、虚实结合为重要特征，NFT 被视作元宇宙的重要底层技术，在元宇宙构建的身份标识、资产确权等关键环节提供支持，也保障了 NFT 的市场活力与社会关注。近年来，改名为元的脸书等科技公司纷纷布局元宇宙，NFT 等新兴概念市场，以求获得标准制定的主导权。面对环境恶化、资源短缺、贫富分化、阶层固化等问题，人们希望元宇宙能推动社会关系形态演进并建立真正的“地球村”，也希望 NFT 可以为普通民众提供分享数字创意红利的新机遇。但是，在发生风险时也可能同频共振甚至一损俱损。NFT 本质仍是虚拟货币，作为元宇宙的重要组成概念，其与元宇宙的经济体系高度挂钩。一旦 NFT 发展失序，将直接对元宇宙这个“下一代互联网”的构建造成冲击。同时，元宇宙概念也对 NFT 市场的安全稳定有极大影响。例如，借助元宇宙热度，NFT 市场涌现了大量的“虚拟地块”，而“虚拟房市”一度繁荣。当元宇宙概念波动，NFT 地产价格亦呈现指数式增长与断崖式下跌，为虚拟经济的有序发展增加了诸多不可控因素，甚至引发较为严重的社会影响。

  

**三、NFT 带来新的国家安全挑战**

总体而言，当前 NFT 的市场热度较高，配套“降温”与管控机制较少，并发风险与问题同样存在。从国家安全角度看，这种发展与安全间的错位可能带来政治、经济、社会等多个层面的挑战。

**（一）政治层面内外差异大带来博弈新战场**

**一是发展路径内外有别。**我国对 NFT 相关产业的发展思路是统筹“安全”与“发展”，注重“规”与“制”，基于联盟链发展，且更注重与实体经济结合，避免了过度的脱实向虚，在虚拟支付上的考虑更佳求稳致远。国外的 NFT 发展则以公链为底层网络，市场自由度较高，产品种类发展过于超前多元，市场规模增速过快，投机情况也更加严重。这种截然不同道路之争届时将呈现不同的发展效果，也可能引发新一轮政治论战。**二是意识形态色彩突出**。NFT 具有较强的文化属性与意识形态色彩，可能成为美国等西方国家所谓“民主国家”对我国展开反宣行动特别是颜色革命的新疆域、新战场。**三是霸权威胁长期复杂。**NFT 兼具数据、经济、文化等多重属性，也必然会在全球竞争格局中带来多重的霸权威胁。一些国家的现有技术水平、国内市场、用户群体、数字生态、产业链和创新环境较为适宜NFT 的发展，而另一些国家可能由于主观因素或客观限制，NFT 的发展相对滞后。届时，掌握 NFT 核心市场、主要用户、头部企业以及更多数据的国家或地区，将在规则标准的制定与管辖管制上有更大的发言权，而其他国家将面临歧视性门槛与发展瓶颈。

**（二）经济层面底层建设弱制约长期发展**

**一是规则标准尚在摸索建立阶段。**作为数字交易类产品，NFT 在各国的政策尚处在空白或起步阶段。特别是在美国等西方国家，NFT 与“币圈”的价值表达高度相似，底层逻辑吸引了大量的入场玩家与资本，市场波动幅度极大。规则与标准的模糊使其真实价值与市场表现易表现出脱节倾向，而炒作、资金盘、洗钱等问题均可能使正在成形的市场遭受冲击甚至破坏。**二是头部效应明显，远未达到全产业的蓬勃发展。**美国职业篮球联盟官方电子藏品发售平台 NBATopShot、加密朋克等项目占据了绝大部分的 NFT 交易量，而 OpenSea 和 NiftyGateway 在各自市场领域处于绝对领先。这种情况在数字艺术作品 NFT中更为明显，头部艺术品和艺术家占据了绝大部分的成交额，更多的作品 NFT 则是低价售卖甚至无人问津。在其产业还未成熟的阶段，实际上已经产生了垄断性企业，并对规则与标准的制定有极大的裁决权与导向作用，而这种几家独大的发展现状与其“去中心化”的核心特征背道而驰，也不利于产业的创新与发展。**三是缺少实体经济的坚实支持易使其沦为无根之木。**虚拟资产本质上依托于它所在的虚拟平台和经济基础而存在，如果未来其所依托的平台、产业因为某种原因而遭受打击或消失，其价值也就不复存在。当前，主要的 NFT 产品还停留在就虚拟谈虚拟的阶段，与实体经济的融合极其有限，根基薄弱使其还不具有长期稳定性。

**（三）社会层面蝴蝶效应强带来管控新议题**

**一是带来就业替代、产业升级，进而深刻影响社会结构。**NFT 将催生新的数字创意岗位，尤其是推动数字创意者成为自由职业者，促进数字经济小微企业特别是文创个体从业者的发展，并酝酿各种非传统社会潮流。与现实世界的阶级分化一样，NFT 也会带来新的阶级分化与身份认同，并可能在元宇宙等新兴产业中有集中明显表现。**二是将对社会治理提出各种新问题。**NFT 的强传播力与链式加密传播渠道可能对社会带来消极影响与挑战，色情、暴力、恐怖主义等违法内容易被不法分子制造带有成瘾性的“数字毒品”，对大众特别是对该领域有较高热情的青少年群体造成危害，而传统的管制很难对这一领域产生有效规制。**三是持续弱化人们对现实世界特别是传统实体文化的兴趣。**NFT 在赋予实体文化新活力的同时，也容易让人们在沉浸虚拟文化的同时弱化对现实世界的感知能力与兴趣。NFT 具有较强的载体属性，正如纸的出现冲击了雕塑、铸造文明，移动端的流行冲击了书本文化，一些具有极大保护价值的传统文化可能因为无法“NFT 化”而经历价值的“此消彼长”并走向绝迹，进而对人类文明的延续产生消极影响。

上述这些挑战与风险使 NFT 发展的规则建立及监管体系至关重要。**一方面，**需要辩证看待其在元宇宙这样的新兴领域中发挥的虚拟经济助推作用，既要对其在数字经济领域的风险挑战保持足够警惕，也要重视其在重组重要资源、重塑经济结构、改变竞争格局中可发挥的独特作用。**另一方面，**政府需要以总体的视野强化其与元宇宙等新兴领域的统筹规制与监管，以系统思维做好其技术规则、法律规制、行业标准的制定与设计。企业也需要以负责任的姿态，在充分保障安全、充分保护文明、审慎发展市场的基础上推动 NFT 的发展。由于 NFT“内外有别”的发展路径与市场定位，国际社会应对其开展探索性、建设性、有限度的合作与沟通，引导其健康有序发展。
