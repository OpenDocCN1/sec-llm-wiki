# 行业 | 永信至诚成功登陆科创板

10月19日，永信至诚正式登陆科创板，股票代码688244。这代表着永信至诚在网络靶场和人才建设领域将迎来新起点，迈向新征途。  

![](../Images/8fd090e96cb83d401a134b53d5e2ad61.png)

永信至诚董事长蔡晶晶在致辞中表示，数字化浪潮打开了生产和生活方式全新的想象空间，也为网络安全事业带来了全新的发展机遇。此次发行上市，是永信至诚的新起点，我们会持续保持创新动力，脚踏实地，致力于成为中国网络空间与数字时代安全基础设施关键建设者，不辱时代赋予的使命。

![](../Images/82505e1c8868cc37c01cb120f3cc88bc.png)

面对当前数字时代网络安全和数据安全的严峻态势，作为数字化建设过程中安全性测试的重要基础设施和重大网络安全风险推演研判的重要科学装置，永信至诚自主研发的网络靶场是保障数字经济发展的有力举措。作为网络靶场领域的龙头企业，永信至诚在技术创新、场景应用、市场表现等方面均占据至高点，为数字经济持续打造安全基础设施。

**在技术创新方面，**永信至诚网络靶场平台，依托自主可控的下一代高性能“春秋云”专有云平台和平行仿真技术体系构建而成，经多位院士、专家评审，具有大规模、多层次、高仿真、高柔性和全场景的特点，被认定为“国内领先”，获评北京市科学技术奖一等奖（牵头单位）。**在场景应用方面，**经过7年多持续迭代和运营，春秋云境网络靶场已经实现了“7+1”应用场景落地，持续为产业数字化转型构建网络安全“数字风洞”，支撑了国家多个部委主办的数十场网络安全演练活动及多个行业的靶场建设工程，同时支撑了中央网信办、公安部、工信部、教育部、科技部、卫健委、国税总局等官方网络安全赛事超过400场。**在市场表现方面，**根据IDC《中国网络安全实训演练测试平台市场份额，2021：高歌猛进，快速发展》研究报告显示，永信至诚凭借春秋云境网络靶场产品，以20.4%的市场份额位居第一名。数世咨询发布的《数字靶场能力点阵图2022》显示，永信至诚春秋云境网络靶场在应用创新力和市场执行力维度均位列行业第一。当前，巨大的网络安全人才缺口是网络安全产业面临的主要问题之一，人才建设成为产业发展的生命线。据专业机构测算，到2027年，我国网络安全人员缺口将达327万，而高校人才培养规模仅为3万/年。永信至诚在网络安全人才建设领域深耕多年，开创了拥有89万多注册用户的全国知名网络安全专业学习社区，打造了完整的社区、岛链式产品线和人才培养、选拔、评价及实践机制；助力国家各大部委举办高质量赛事遴选人才，为6000余家单位、逾55万人次提供训练环境，源源不断为社会和企业输送实战型安全人才，为守护数字世界的安全输出有生力量。

未来，永信至诚将不断夯实网络靶场和人才建设领军者地位，推动核心技术在人工智能安全、数据安全、工业互联网安全、车联网安全等更广阔的场景中拓展延伸应用。同时将积极打造产业生态，引领行业协同发展，为产业数字化转型提供安全保障及人才建设支撑，为我国数字经济安全稳健发展保驾护航，实现“带给世界安全感”的愿景。
