# 聚焦2022网安周 | “网络资产测绘及风险分析系统（信创版）”亮相国家网络安全宣传周

9月5日下午，在国家网络安全宣传周博览会现场，由国家工业信息安全发展研究中心（以下简称“中心”）、北京华顺信安科技有限公司（以下简称“华顺信安”）联合举办的“网络资产测绘及风险分析系统（信创版）”产品发布会正式召开。本次发布会以“赋能信创安全”为主题，以“保障信创·赋能信息化高质量发展”为主旨，会上由双方携手打造的“网络资产测绘及风险分析系统（信创版）”正式亮相。该产品是基于网络空间测绘技术，以信创软硬件资产为主要标的，专项研发的网络资产安全运营管理系统。

![](../Images/69a492b799947310883ad6f0d938c01c.png)

国家工业信息安全发展研究中心副主任郝志强在致辞中强调，网络安全特别是信创安全工作，是维护国家网络空间安全、建设制造强国和网络强国的基础保障。下一步，中心将在信创安全技术研究、产学研用资深度合作和推动信创安全产业融合发展三个方面开展工作。

![](../Images/487bad3cf66ddf040fc794bed8e2156a.png)

华顺信安创始人、CEO赵武表示，信创产业的平稳长期发展对我国当下数字经济建设而言意义重大，很荣幸有机会用实际行动为守护我国信创产业发展做出贡献。

![](../Images/b1c417da1601fa6e4c2e689a35c38c99.png)

发布会现场，中心副主任郝志强、中心检查评估所副所长于盟、华顺信安CEO赵武、华顺信安高级副总裁马男共同启动了“网络资产测绘及风险分析系统（信创版）”产品发布仪式。

国家工信安全中心检查评估所信创安全部负责人赵冉指出，当前我国部分信创系统与产品开发、应用的时间尚短，还需要大量的安全验证与维护工作。所以，要积极开展信创软硬件产品及系统安全测试工作，充分调动产业链上下游的力量，构建信创的安全防护体系。华顺信安的解决方案部总监刘洋表示，国内信创建设单位通常是以信创与非信创混搭进行起步，再逐步进行替换推进，在这一过程中，对信息资产的安全管理是一个极大的挑战。作为国内首个定向针对信创资产打造的网络空间测绘产品，“网络资产测绘及风险分析系统（信创版）”基于海量数据样本，结合自研的指纹采集、协议识别技术，在混搭环境中“摸清家底”，区分出信创与传统资产，并进行资产画像建模，为信创建设单位提供数据支撑，有效帮助信创建设单位提升安全防护能力与资产安全管理效率，成为护航信创产业安全长期发展的重要力量，赋能信创产业高质量发展，助力打造更加安全、健康、稳定的信创产业生态环境。
