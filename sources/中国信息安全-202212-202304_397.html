文│中国工程院院士 倪光南
党的二十大报告提出，必须坚持科技是第一生产力、人才是第一资源、创新是第一动力，深入实施科教兴国战略、人才强国战略、创新驱动发展战略，开辟发展新领域新赛道，不断塑造发展新动能、新优势。教育、科技、人才是全面建设社会主义现代化国家的基础性、战略性支撑。报告强调，人才是第一资源，这是因为“千秋大业、人才为先”，人才是实现科技强国、民族振兴，赢得国际竞争主动的重要支撑。习近平总书记在党的二十大报告中还指出，要顺势而为，构建具有全球竞争力的人才制度体系；要培养造就一大批具有国际水平的战略科技人才，科技领军人才、青年科技人才和高水平创新人才团队；要更加重视青年人才培养。
近年来，“开源”（开放源代码）作为一种发展模式、创新模式，已经成为推动当代世界信息技术、软件技术发展的强大动力。国际上开源技术生态体系已经形成，并发展成为软件业主流，以致有人说“开源正在吞噬软件”。
2020 年，Synopsys 公司审计了 1252 个应用程序，其中 99% 包含开源软件，总体来说有 70% 的代码是由开源代码组成的。2022 年的数据显示，全球 80% 的新软件由开源组建， 98% 以上企业使用开源软件。实践表明，开源社区通过大众协同、开放共享，不断持续更新迭代，展现出惊人的开源创新能力。此外，开源不仅打破了软件业被专有软件垄断的格局，还正在从软件领域向硬件领域扩展。为此，我们应该高度重视开源人才培养，用好开源模式，汇天下英才激活中国创新动能。
开源创新在当代信息技术领域取得的巨大成效是与其规模化、生态化、平民化、全球化的特性分不开的。
第一，开源创新规模化是指开源促进全球开发者协同创新，使开发项目达到空前的规模。我们以 Linux 开源社区为例，该社区已拥有 700 万个产品家族，200000 万+开发者，这是其他任何采用常规模式的单个企业、机构、学校……所不可能达到的。相关数据显示，全球开源项目数量呈指数增长，截至 2019 年，在 GitHub 托管的代码仓库已有 1.4 亿个，新增仓库 4400 万个，创建第一个项目的用户比 2018 年增长了 44%。
SourceClear 调查报告预测，到 2026 年，全球开源项目数量将超过 3 亿。规模化不仅关系到单一项目或产品本身的规模，还关系到众多项目或产品的融合渗透。实际上，在一个开源社区中或者在任何开源社区之间的任何项目或产品都可以相互碰撞激励、交叉融合，其结果不仅提升了自身，还可以催生出全新的项目或产品。
第二，开源创新生态化是指开源既能融合合作伙伴又能融合应用伙伴，既能突破关键核心技术又能延展上下游产业链，从而营造出庞大的技术和产业生态。开源生态依托开源社区形成软硬件开源项目，发展为相应的产品或服务，进入市场良性循环。开源生态涉及开源的参与者、贡献者、使用者、运营者、服务者、支持者等等多种角色，无论企业和个人均可参与。例如，Linux 操作系统核心技术已经孕育出了包括固件、虚拟化、程序语言、编译工具链、基础库、开发环境、运行环境等在内的完整的 Linux 技术和产业体系，形成了一个由产业链各环节商业伙伴及其用户群构成的巨大生态系统。
目前各行各业为了提高竞争力，不但注重技术和产品，还越来越重视生态建设，开源创新的生态化特性可以在这方面发挥重要作用。
第三，开源创新平民化是指开源大大降低了创新门槛，基本消除了从事创新必须逾越的知识产权壁垒、资金壁垒、市场壁垒等，使发展中国家、低收入低资历人群都能平等地参与创新，作出贡献，并提升自身，这对中国具有特别重要的意义。中国拥抱开源，注重开源人才培养，可以使中国的广大高校毕业生以最低成本参与开源社区当中，社区为大学生提供培养、锻炼和施展才能的平台，这不仅可以充分发挥中国每年近千万大学生人数优势，汇天下英雄提供用武之地。当然，这里说的人才优势已经不再是上世纪时的那种“人口红利”，而是在新一轮科技革命和产业变革中具有重大意义的“人才红利”，或对信息领域而言的“工程师（或开源工作者）红利”。
第四，开源创新全球化是指开源可以实现跨地域、跨国界的开放创新、协同创新。目前我国在国际开源界还处在跟跑阶段。GitHub开源平台发布的年度报告显示，美国有 1355 万+开发者，中国有 755 万+开发者，印度有 721 万+开发者。从开发者数量上，中国位居全球第二，称得上是开源大国，但还不是开源强国。例如，目前还缺少中国人主导的开源社区和开源项目，大多中国开发者是参与别人主导的社区和项目，进行学习，予以应用，做些贡献等。今后我们要注重开源人才培养，发挥开源人才优势，加大对开源的投入、贡献和话语权，增加中国带头创建的开源社区。通过这些举措，使中国从开源界的跟跑者向并跑、领跑者的方向发展，早日成为开源强国。面对当前错综复杂的国际形势，开源创新还能充分体现“你中有我，我中有你”，有助于防止或缓解可能发生的遏制、禁运、停服、断供、脱钩之类制裁。
中国是全世界大学生毕业人数最多的国家，据统计， 2021 年中国高等院校毕业生数量已达到 909 万人。中国科技研发的人才结构为金字塔结构，以庞大的技术本科、硕士、博士毕业生为基础，具有国内外高学历教育背景和成熟的专业经验的研发人员为塔尖。中国正在成为全球高科技研发体系中的重要部分，这一庞大的技术队伍如果能与开源模式相结合，就能使中国人才数量优势能得到充分的发挥。据了解，中国目前已经有很多高校已经开展了一些开源课程培训，但还没有形成规模，形成制度。为此，建议在高校系统地推进开源教育，要从全球视野谋划人才培养方式，激活国家创新动力，要统筹规划建立完善的产学研一体化开源人才培养体系，要针对国家科学技术发展的产业需求，进行针对性开源人才培养，以支撑产业发展需求和国家发展的战略方向。
建议国内有关部门要用好中国人才基数优势，注重开源人才培养，打造围绕国家战略、产业需求，探索建设大学生“学习+实践+孵化+金融”为一体的开源社区，培养更多的大学生开发者参与到开源社区建设当中，将习近平总书记在二十大报告中提出的“科教兴国战略、人才强国战略、创新驱动发展战略”落到实处。总之，推进开源创新有助于实现科技、人才、教育的融合，探索建设社会主义现代化国家的基础性、战略性支撑新路径，并进而探索构建人类命运共同体的新方式。
