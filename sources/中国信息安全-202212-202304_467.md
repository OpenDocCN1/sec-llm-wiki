# 行业 | 华云安完成B轮融资，专注ASM与BAS全球数字安全创新方向

近日，北京华云安信息技术有限公司（以下简称华云安）完成数千万人民币的B轮融资，此轮融资由执一资本领投，领沨资本、老股东微智数科、国君景泰跟投，密码资本再次担任独家财务顾问。本轮融资将用于加速攻击面管理（ASM）+入侵和攻击模拟（BAS）产品体系建设,进一步打造数字时代ASM和BAS产品创新力。据介绍，华云安是国内攻击面管理领域领先的创新企业，致力于对主动防御、情报协同、溯源反制能力进行融合创新，以攻防视角构建新一代网络安全对抗防御产品解决方案。经过三年的发展，华云安已拥有业界领先的“基于云原生架构的攻击面管理整体产品体系”，以CAASM（网络资产攻击面管理）+EASM（外部攻击面管理）+BAS（入侵和攻击模拟）三大产品引领ASM+BAS市场发展。

  

**以原子化安全能力打造ASM+BAS产品创新力**

2021年7月，Gartner首次提出来CAASM、EASM攻击面管理相关技术。2021年9月，华云安正式发布攻击面管理产品体系，构建以攻击者视角的资产安全性管理解决方案。2022年，在Gartner发布《Hype Cycle for Security in China, 2022》中，ASM和BAS均是处于快速上升期的新兴技术。华云安是唯一一家获得Gartner报告ASM+BAS双领域代表厂商。在国内，ASM和BAS亦是受到行业肯定的未来产业链重要技术创新方向，国内多家权威机构相继将ASM和BAS列为2022网络安全新兴赛道之一。可见在全球范围内，ASM和BAS已被视为推动网络安全运营技术创新的关键技术。

 作为国内首家聚焦攻击面管理的网络安全公司，华云安历时三年，完成攻击面管理从单点产品到体系的演进：从最初的灵洞·网络资产攻击面管理系统（Ai·Vul），到灵刃·智能渗透与攻击模拟系统（Ai·Bot），再到灵知·互联网情报监测预警中心（Ai·Radar），华云安潜心打造极致的产品力，推出基于云原生模块化架构的攻击面管理整体产品体系，通过网络资产攻击面管理（CAASM）、外部攻击面管理（EASM）、入侵和攻击模拟（BAS）等典型场景，贯穿攻击面的检测发现、分析研判、情报预警、响应处置四大环节帮助企业应对数字安全风险。![](../Images/d345853e146f416b673f107988c38877.png)当下，云计算全面进入云原生时代。云原生技术生态将成为企业的新一代底层基础设施、创新平台。创立以来，华云安持续打造基于云原生的原子化安全能力平台（VUL.AI PLATFORM），以微服务的方式提供不断迭代的安全能力，充分考虑了弹性、冗余和高性能，安全能力敏捷且易用。平台化架构让华云安的多个产品既可以独立提供各自的安全能力，也可以将原子化的安全能力编排成攻击面管理的整体解决方案。以云原生的方式构建下一代的数字安全防御体系，是华云安可持续发展的长期技术目标，也是未来重点发力方向。![](../Images/5e2de0c121dc3357affaefa34701146e.png)华云安是国内攻击面管理领域理论与实践的先行者，亦是相关技术创新的深耕者。2022年，华云安在ASM及BAS两个领域的创新实践能力，相继得到Gartner、赛迪顾问、数世咨询、数说安全等国际国内权威机构认可。据悉，在市场拓展方面，华云安ASM与BAS相关产品已覆盖政府、央企、能源、金融、教育、医疗等关键信息基础设施行业，保障广大客户数字化转型稳步推进。今年，华云安在电力行业、金融行业、央企领域实现重大突破：在电力行业实现国家电网资产与漏洞管理系统统一部署实施、某省网公司超千万级攻击模拟对抗防御产品解决方案部署；在金融行业，公司中标具有标志性的金融行业资产攻击面管理系统；在央企领域，中标多个央企的资产攻击面管理整体解决方案。华云安创始人兼CEO沈传宝表示，2022年华云安在业绩上实现了相较上年度100%的增长。尽管受疫情等因素，今年客户的预算执行都受到一定的影响，但华云安的客户聚焦在国家关键信息基础设施行业，对安全的需求愈发刚性，这也是公司业绩翻番的主要原因。

在谈及此轮融资与未来发展，沈传宝表示，“此轮融资将有助于我们进一步加强人才体系建设，完善基于云原生架构的攻击面管理产品体系，强化ASM+BAS在数字化场景中的应用，以面向未来的下一代网络安全对抗防御体系为企业数字化转型带来全新体验，以持续的技术创新为企业数字化转型提供安全保障与业务护航。”
