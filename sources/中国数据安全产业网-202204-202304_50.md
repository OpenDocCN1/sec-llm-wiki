# “8+8+8数据安全人才培养体系”发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2OTczNjMwNQ==&mid=2247485430&idx=1&sn=098c8c103977ceea33574a96b42969ed&chksm=ce99cde8f9ee44fe918ce8e3d9c265c8c8b3b78481d0dfb5393ae0e1005542a361133b0cc0eb&scene=126&sessionid=1681270967#rd](http://mp.weixin.qq.com/s?__biz=Mzg2OTczNjMwNQ==&mid=2247485430&idx=1&sn=098c8c103977ceea33574a96b42969ed&chksm=ce99cde8f9ee44fe918ce8e3d9c265c8c8b3b78481d0dfb5393ae0e1005542a361133b0cc0eb&scene=126&sessionid=1681270967#rd)

2022年11月30日，在工业和信息化部网络安全管理局指导下，以**“8+8+8数据安全人才培养体系”发布**为主题的数据安全产业人才培养沙龙活动成功举办。

本期沙龙由中国电子信息产业发展研究院、中国信息通信研究院、中国软件评测中心联合主办，中国计算机行业协会数据安全专业委员会、上海珪梵科技有限公司、江西财经大学、江西省法学会数据法学研究会、江西省国防科技工业文化联合会、江西凌科安时律师事务所、江西中科伟青云虚拟应用技术有限公司、江西国鼎科技有限公司承办。

![](../Images/87409d785d5de2f6cd52a340353860f4.png)![](../Images/87409d785d5de2f6cd52a340353860f4.png)![](../Images/87409d785d5de2f6cd52a340353860f4.png)

本期主题沙龙坚持人才引领发展的战略，聚焦“数据安全产业人才培养”主题，正式发布全面覆盖校园、社会和全民通识类的“8+8+8数据安全人才培养体系”，涵盖了数据安全产业中8个面向社会的岗位、8个面向校园的专业方向和8个行业领域的意识宣贯等三大体系下的24门课程。并结合《数据出境安全评估办法》的施行，探讨了工业和信息化领域数据出境安全评估服务内容，切实推动数据安全产业高质量发展。主题沙龙采取线上线下相结合的方式，线下参会嘉宾20余位，线上参会嘉宾160余位（具体参会名单附后）。

本次数据安全产业沙龙邀请到中国电子信息产业发展研究院网络安全研究所副所长、中国计算机行业协会数据安全专业委员会秘书长、中国软件评测中心主任助理唐刚，江西财经大学校长、法学教授、博士生导师、国家社科基金重大项目“数字社会的法律治理体系与立法变革研究”课题组带头人邓辉，江西财经大学数据法律研究院教授、院长、江西省法学会数据法学研究会会长饶传平，中国计算机行业协会数据安全产业专家委员会委员、中国软件评测中心网安中心关基部主任李杺恬，中国计算机行业协会数据安全产业专家委员会委员、上海珪梵科技有限公司创始人&CTO栾浩，江西凌科安时律师事务所执行合伙人余斐蓉作主题分享，共同探讨了数据安全产业人才培养体系建设的新思路、新路径、新举措，发布了适用于校园、社会以及全民通识的多范围、多维度的数据安全人才培养体系。

**唐刚副所长**着眼于数据安全对于国家安全的重要性，指出数据安全人才培育是数据安全产业健康发展的重要组成部分。在工业和信息化部网络安全管理局指导下，中国软件评测中心牵头开展支撑数据安全产业系列研究工作。本期沙龙希望通过汇聚“产学研”各界专家，促进数据安全产业工作的前瞻性思考、全局性谋划和战略性布局，并建立完备的培训体系，培养高质量的数据安全产业人才，全面提升数据安全人才专业技术能力，促进数据安全产业落地见效。

![](../Images/a5143d28479b83adfe4d94635c405b78.png)

  

**邓辉校长**讲述了数据安全相关专业具有广阔的研究前景和产业前景，数字经济发展离不开人才支撑，希望能够提升数据安全产业人才培养水平，将数据安全系列课程与讲座植入到本科人才培养体系之中，进一步在数据安全人才培养、法律法规与监管合规要求、数据安全科研等领域开展深入的合作，培养数据安全人才并发挥人才的价值。

![](../Images/66636638a0800a79fdf20e0a274e916e.png)

  

**饶传平会长**就身处数字时代，数据科技所驱动的自动化、智能化、智慧化发表观点，并指出随着各项法律的出台，需要从个人、社会和国家三个层面防范数据安全风险，探索数据安全产业发展与经济发展的道路。目前数据安全人才短缺，对政府执法、企业合规提出很高的要求，本次沙龙所发布的三大数据安全人才培养体系既能满足社会人才需求，又能解决校园毕业生就业问题，同时还为重点行业输送数据安全方向的专业人才。

![](../Images/255382a43125f3f38167bfcd43bf1306.png)

  

**李杺恬主任**从人才培养赋能数据安全产业高质量发展着手，介绍了数据安全产业系列工作正在全面开展，需要大量专业人才来落实和支撑，数据安全人才培养意义重大。在工业和信息化部网络安全管理局的指导下，中国计算机行业协会数据安全专业委员会组织成立了人才培养工作的载体——数据安全专业委员会人才培养工作组，紧密围绕数据安全产业发展战略，建立了完备的人才培养体系，培养具备专业技术能力的数据安全人才，为数据安全产业人才招聘、评价提供有效参考，赋能数据安全产业高质量发展。

![](../Images/2efd08b83ff1778ba5f65bf793caf70f.png)

  

**栾浩委员**发布了数据安全人才培养“8+8+8”课程体系：从校园、社会和全员意识宣贯三个角度发布了“三套数据安全人才培养体系，二十四门专业化课程”。涵盖了数据安全水平考试(Data Security Test Program，DSTP)校园体系，包括数据安全审计师方向、数据安全评估师方向、数据安全工程师方向、数据安全架构师方向、数据安全合规师方向、数据安全研发方向、数据安全运维方向和数据安全咨询方向等八大方向。数据安全意识宣贯(Data Security Awareness Training，DSAT)体系，包括全民数据安全意识宣贯、金融行业数据安全意识宣贯、国防军工行业数据安全意识宣贯、政府行业数据安全意识宣贯、企业数据安全意识宣贯、通信行业数据安全意识宣贯、科研教育行业数据安全意识宣贯和医疗行业数据安全意识宣贯等八大行业领域。数据安全人才培养社会体系，包括注册数据安全审计师(CDSA)、数据安全评估师、数据安全工程师、数据安全咨询师、数据安全架构师、数据安全研发人员、数据安全运维人员和数据安全合规师等八大认证。以满足现阶段国家对于数据安全人才的较大需求缺口。

![](../Images/f211faccfdfddae5d8ac440869dae4f9.png)

  

**余斐蓉律师**介绍了工业和信息化领域的数据出境安全评估服务。通过分析“滴滴出行”这一现实案例，阐述了数据出境安全的现状。余律师依据国家法律法规监管合规要求，进一步剖析了在数据出境应用场景中的高频问题，并且分享了数据安全出境的评估方法与申报流程，强调了重点评估事项与技术保障需求，为理解数据出境、做好数据出境合规工作提供了有益参考。

![](../Images/37c1ef7b2c54e1e9ae62debbf1267639.png)

  

下一步，中国电子信息产业发展研究院将持续举办主题沙龙活动，积极搭建产业交流平台，联合科研院所、高校、企业等各相关方，凝聚产业共识，共同推进数据安全人才培养工作，为培养和壮大综合性数据安全人才队伍贡献力量，助力提升我国数据安全产业高质量发展。
