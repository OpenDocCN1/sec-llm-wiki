# 关于数据安全大赛赛道二、赛道三延期的通知

**各参赛单位及社会团体：  
**

根据疫情发展及防控情况，为保障比赛顺利有序开展，经大赛组委会研究决定，原定于2022年10月25日至2022年11月11日举办的赛道二（数据安全产品能力评比）及赛道三（数据安全治理方案）比赛，将延期举行。具体比赛时间及地点将通过大赛官网（https://bm.ichunqiu.com/ds-contest）及官方公众号“中国数据安全产业网”另行通知。同时，赛道二及赛道三报名截止日期顺延。  
  

**赛道一（数据安全大闯关）将如期通过线上举行，比赛时间为10月25日-10月26日。**

  

特此公告。

 数据安全大赛组委会

2022年10月20日
