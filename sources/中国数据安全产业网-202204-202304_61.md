# 中国评测被授予“工业和信息化线上培养工程”培训基地

为深入贯彻中央人才工作会议精神，认真落实工业和信息化部有关部署，工业和信息化部教育与考试中心（以下简称教育考试中心）依托“工业和信息化技术技能人才网上学习平台”开展“工业和信息化线上培养工程”（以下简称线上培养工程），中国软件评测中心（工业和信息化部软件与集成电路促进中心）（以下简称中国评测）经遴选被确定为线上培养工程培训基地。

![](../Images/ef69933739d5fc3477cb41de8a5fb5b1.png)

作为线上培养工程合作单位，中国评测在工业和信息化部网络安全管理局（以下简称部网安局）的指导下，与中国计算机行业协会数据安全专业委员会（以下简称数据安全专委会）、教育与考试中心联合推出了数据安全职业能力培训。数据安全职业能力培训设置了数据安全评估师、数据安全工程师、数据安全咨询师、数据安全架构师、数据安全开发人员、数据安全运维人员、数据安全合规师、数据安全审计师八个培训方向，以全方位满足数据安全人才市场需求。学员参与培训并经考试合格后将获得教育考试中心颁发的**“工业和信息化职业能力证书”**和数据安全专委会颁发的**“数据安全职业能力证书”**，学员信息纳入** “工业和信息化技术技能人才数据库”**，可在**工业和信息化部教育与考试中心官网、工业和信息化技术技能人才网上学习平台、数据安全产业公共服务平台**查询。（课程介绍和开班通知请关注公众号**“中国数据安全产业网”**）

2021年10月开始，中国评测在部网安局的组织和指导下，牵头开展支撑数据安全产业系列研究工作：组织建立长效稳定的产业交流合作机制，合力打造便捷高效的产业交流合作平台，策划举办内容丰富的产业交流合作活动。目前，由中国评测研究起草的《促进数据安全产业发展指导意见》已进入征求意见阶段，牵头开展的数据安全产业研究、标准制定、关键技术、人才培养、能力评价、成果评定等产业工作也在部网安局的指导下紧张有序推进中。
