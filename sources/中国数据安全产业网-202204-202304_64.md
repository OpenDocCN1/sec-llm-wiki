# 首届全国数据安全大赛火热报名中欢迎大家积极报名参与

**积极参与**

![](../Images/f232c9d9dd1529bc233494f78f9f34af.png)

首届全国数据安全大赛自9月1日起始报名至今，旬月之间，中国电子信息产业发展研究院、中国信息通信研究院、国家工业信息安全发展研究中心联合发文动员各地通信管理局、工信主管部门及移动、电信、联通集团积极报名参赛，并在FreeBuf、春秋伽玛、今日头条等媒体公众号进行了广泛宣传。数据安全大赛得到了政务、电信、互联网、金融、医疗、工业等行业单位、数据安全企业及具备数据安全能力的企业、数据安全爱好者的热烈响应。从当前的报名数据来看，大赛已经吸引了全国31个省(自治区、直辖市)的企业及个人报名参加。“数据安全大闯关”报名队伍数已超过千支，数据安全产品能力评比、数据安全治理方案也吸引了多家数据安全龙头企业参与。

  

以赛代练、以赛促改、以赛树标，助力国家关键行业数据安全基线建设，选拔数据安全人才，提升安全人员能力，普及数据安全法规标准，形成以赛事为核心的数据安全人才选拔、培养、认证体系，推动国家数据安全法律、行业标准规范、数据安全知识的推广。

  

金秋十月，硕果满枝，首届全国数据安全大赛即将拉开帷幕，预祝参赛者在三大赛道中大显身手，取得优异成绩，为数据安全产业发展注入新动力。届时，将在工业和信息化部主办的中国数据安全高峰论坛为比赛获奖者颁奖。

  

目前大赛报名还在进行中，欢迎大家积极报名参与！
