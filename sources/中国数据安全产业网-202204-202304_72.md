为持续性跟踪产业动态，引导产业全面健康发展，现面向社会各类数据安全产业主体，长期征集数据安全产业发展相关稿件，优质内容将发布至**“数据安全产业公共服务平台”**、**“中国数据安全产业网”公众号**等平台，文章底部展示作者及所属单位简介。欢迎踊跃投稿。

| 

**征稿范围**

  


 || 

促进数据安全产业发展相关内容，包括但不限于：

 |
| --- | --- |
| 

**解读类：**新出台的产业相关法律法规、政策文件解读，标准规范解读等；

 |
| 

**观点类：**热点安全事件分析、产业发展现状分析、产业发展趋势分析、产业发展建设思路等；

 |
| 

**实践类：**典型应用案例分享、行业实践经验分享等；

 |
| \_ || 

**科普类：**国内外最新技术研究进展、数据安全及个人信息保护措施等。

 |

|

 ||

 |
| 

征稿暂不涉及费用。

 |
