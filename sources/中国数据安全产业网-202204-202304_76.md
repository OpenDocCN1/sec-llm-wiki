# 垂直领域下一代“数据安全管控平台”未来发展研讨会在京召开

为深入贯彻落实《数据安全法》《个人信息保护法》等法律法规，全面深化数据安全保障体系和能力建设，实现数据生命周期全流程管控，2022年8月25日，由中国互联网协会数据安全与治理工作委员会主办，中国信息通信研究院与中国电子信息产业发展研究院承办，天融信科技集团股份有限公司协办的垂直领域下一代“数据安全管控平台”未来发展研讨会在京召开。

  

![](../Images/db0c01569a986021fc09075bed01d2d7.png)

  

中国互联网协会数据安全与治理工作委员会秘书长何桂立、中国信息通信研究院安全研究所总工程师田慧蓉、中国电子信息产业发展研究院网络安全研究所副所长兼中国软件评测中心主任助理唐刚及中国移动集团、中国铁塔集团的相关领导出席会议。

  

何桂立指出，数据安全作为数字经济的重要保障，受到国家和社会各方面的高度关注。目前我国数据安全产品类型持续增加，产品体系逐步完善，数据安全管控平台正在成为市场需求旺盛的代表性数据安全产品。中国互联网协会数据安全与治理工作委员会将开展一系列主题研讨活动，为更好地支撑政府相关部门，引导会员单位提升认识，加强交流合作，为推动技术创新和产业发展贡献力量。

田慧蓉表示，国家在第十四个五年规划和2035年远景目标纲要中明确提出打造数字经济新优势、加快数字社会建设步伐、提高数字政府建设水平、营造良好数字生态的目标。随着数据安全监管要求的逐步落地，社会范围内对于数据安全产品和服务的需求不断释放，数据安全产业作为国家数据安全实力的重要组成部分，基础性地位逐渐凸显，迎来了新的发展机遇。

唐刚表示，随着《数据安全法》《个人信息保护法》等数据安全相关法律法规的出台施行，各个行业都在加速数字化转型。为更好地加强数据治理，为数字经济持续健康发展筑牢安全屏障，赛迪研究院与中国信息通信研究院将继续在工业和信息化部网络安全管理局的指导下，积极开展数据安全产业的系列研究工作。

  

会上，天融信科技集团有限公司助理总裁李建彬，启明星辰信息技术集团股份有限公司数据安全产品线总监周瑞群，杭州安恒信息技术股份有限公司副总裁林明峰，奇安信科技集团股份有限公司数据安全规划总监、战略规划设计院规划总监王超，绿盟科技集团股份有限公司CIO首席创新官刘文懋等企业代表分别作了主题发言。

  

**金融领域数据安全管控平台国内外技术现状与发展趋势**

李建彬发表了题为“金融领域数据安全管控平台国内外技术现状与发展趋势”的主题演讲。他表示，金融机构作为重要的个人信息数据处理者，行业数据呈现多源异构、风险多样性等特点，结合数据可管、可控、可用的发展趋势，单一的数据安全防护已无法有效解决金融业务的安全风险。数据安全管控需求集中体现在数据安全设备的统一管控、设备与平台的智能联动、数据安全态势可视化、数据安全合规监管等，多维度建立数据安全运营管控能力已成为主流发展趋势。

  

**工业互联网领域数据安全管控平台国内外技术现状与发展趋势**

周瑞群发表了题为“工业互联网领域数据安全管控平台国内外技术现状与发展趋势”的主题发言，分享了工业领域数据安全实践、工业数据分类分级实践、工业制造数据流转实践案例，并针对工业互联网领域数据安全提出了细化行业标准、深化行业特点、推动安全运营、试点数据流通的建议。

  

**电信领域数据安全管控平台国内外技术现状与发展趋势**

林明峰发表了题为“电信领域数据安全管控平台国内外技术现状与发展趋势”的主题发言，从电信领域数据安全管控平台发展背景、安恒数据安全管控平台解决方案和成功案例三方面展开介绍。他表示，国家出台政策法规、监管要求驱动了数据安全管控平台能力建设，通过促进数据依法有效利用，充分发挥数据的作用，促进数字经济更好服务社会发展。

  

**政务领域数据安全管控平台国内外技术现状与发展趋势**

王超发表了题为“政务领域数据安全管控平台国内外技术现状与发展趋势”的主题发言。他表示，政务数据是政府部门进行社会治理的重要记录与呈现，蕴藏着难以估量的政治、经济、科学、文化和社会价值，在国民经济建设和国家安全体系中的地位日益凸显。

  

**车联网领域数据安全管控平台国内外技术现状与发展趋势**

刘文懋作了题为“车联网领域数据安全管控平台国内外技术现状与发展趋势”的主题发言。他建议尽快推动编制车联行业数据统一的分类分级标准规范，进一步完善汽车数据权责制度及行业标准体系；智能网联汽车行业需协同攻克汽车数据安全分析、处理、防护、运营等维度技术难题，推动车联网数据安全监管、运营平台技术更新迭代；企业需加强内部数据安全管理体系、技术体系、运营体系能力建设，在合规基础上，充分发挥数据价值。

  

在闭门讨论环节，中国互联网协会数据安全与治理工作委员会、中国信息通信研究院安全研究所、中国电子信息产业发展研究院的相关领导与现场参会企业代表围绕垂直领域下一代“数据安全管控平台”未来发展的相关议题进行了分析和交流。
