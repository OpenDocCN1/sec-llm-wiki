# 美国NIST公布第一批后量子密码标准算法

**2022年7月5日，美国商务部的美国国家标准与技术研究院（NIST）公布了第一批后量子密码标准算法。**经过严格的评选后，最终四种算法胜出，包括用于通用加密的**CRYSTALS-Kyber**和用于数字加密的**CRYSTALS-Dilithium、Falcon、SPHINCS+**。这是自2016年启动后量子密码标准化项目以来，NIST首次发布入围标准的抗量子算法，这四种选定的加密算法将成为NIST后量子密码标准的一部分。

  

对于访问安全网站时使用的一般加密，NIST选择了CRYSTALS-Kyber算法。其优点包括相对较小的加密密钥，双方可以轻松地交换，以及其运行速度；对于数字签名，NIST选择了三种算法CRYSTALS-Dilithium、Falcon和SPHINCS+，前两者具有高效率，NIST推荐CRYSTALS-Dilithium作为主要算法，Falcon用于需要比Dilithium提供的更小的签名的应用程序。第三个SPHINCS+密钥生成与验证速度远快于签名速度，其公钥很短但签名很长，最短的签名长度约8KiB，远大于Dilithium与Falcon。

![](../Images/0e695cefccbb1fa13c101e858017c744.png)

与此同时，出于多样性考虑NIST公布了进入第四轮的候选KEM算法，分别是**BIKE 、Classic McEliece、HQC和SIKE**，它们将进入第四轮进一步研究，NIST同时呼吁提交更多较短签名长度与较快验证速度的后量子数字签名算法，补足多样性，截止时间为2023年6月1日。
