# **前言**

在内网渗透中，当获取到一个账号密码后，经常会使用impacket套件中的psexec.py进行远程连接并执行命令，但是因为用的人多了，杀软也对psexec.py特征进行了拦截，也就导致了如果使用默认的psexec.py进行执行命令时会失败。

# **原理分析**

psexec.py的原理是通过smb上传一个服务程序到c:\\windows（ADMIN$）目录，服务程序通过管道进行后续的命令执行的输入输出。

服务程序来自于remcomsvc.py：

![](../Images/340d8b7a44f1ed04dfe2baeb03002965.png)

服务安装通过serviceinstall.py进行：

![](../Images/483f8824664d498aa2cec66d5c379dde.png)

服务和服务文件的名字默认是随机的：

![](../Images/5d451abb8011a40cda4e1f360bdf39d2.png)

直接psexec.py不带任何参数，上传过去的服务文件名就长这样：

![](../Images/aae0870491039bbb37fa4be5ac5519a0.png)

因此为了防止奇奇怪怪的名字很容易被机器负责人发现，psexec.py也是提供了相应的参数用来自定义：

![](../Images/1dc40b967b7bc0ad73e2cf5ff365ab2c.png)

这里要提一嘴的是，因为UAC的缘故，如果RID不是500，就算账号是管理员也是没权限上传文件到ADMIN$目录，程序报错如下：

![](../Images/ee36506bd5bedcb38c8729b81c6b4a38.png)

# **改造**

默认情况下，使用psexec.py会被拦截：

![](../Images/ee36506bd5bedcb38c8729b81c6b4a38.png)

![](../Images/abb2009ccf4017785c46396a31663ca1.png)

  

![](../Images/847dce39652300c67121fc760db2e08e.png)

根据上面的杀软截图能看到是服务程序被拦截，因此我们需要对服务程序进行修改来尝试绕过杀软，源码在这：

https://github.com/kavika13/RemCom

这里可以尝试修改print的输出：

![](../Images/6640ce1182dc6b451b542ec47a3b3279.png)

或者修改管道名称：

![](../Images/f0f04a8aff31034ab7b23beeeb46cd68.png)

然后重新生成RemComSvc，然后转成hex：

```

import binascii
```

最终可以规避杀软进行命令执行，55.3、55.5分别为上述装有360和腾讯电脑管家的机器：

![](../Images/f06e7d96c116711cb986505c4c18b2e5.png)

# **总结**

本文介绍了通过修改服务程序来绕过杀软，让psexec.py再次大放异彩。
