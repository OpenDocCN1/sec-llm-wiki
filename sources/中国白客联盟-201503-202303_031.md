### 数字型

漏洞语句：

SELECT \* FROM Table WHERE id = 1;

 

AND 1  True

AND 0  False

AND true   True

AND false  False

1-false    如果有漏洞则返回1

1-true如果有漏洞则返回0

1\*56   如果有漏洞则返回56

1\*56        如果没漏洞则返回1

 

例子：

SELECT \* FROM UsersWHERE id = 3**\-2**;

 

笔记:

 

true 等同于 1.

false等同于 0.
