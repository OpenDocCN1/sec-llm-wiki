# 绕过简单搜索APP进行无广告搜索

**前言**

  

百度为了推广app真是费尽心思，首先一开始修改百度系密码需要下载百度app，现在又推出了个简单搜索app，下载app以后再搜索任何东西都不会出现广告。

  

![](../Images/c1f48e10b8be1fcb0c99d9f12bbc8fec.png)

  

**正文**

  

我们可以知道，一般性类似这种下载某个app来达到某个特性要求的时候，一般都是有特殊的如cookie、ua、url等。百度的简单搜索app也不例外。

  

首先我们下载简单搜索app，˙进行随意搜索并抓包，抓包以下类似请求

![](../Images/e9748258ab987b2a7744e87b9608745e.png)

  

我们首先看下url，发现是m子站，我们利用m子站进行搜索经常会出现广告的关键词，如医院

![](../Images/126d3e489d4eeed1eaf4a7e5a7fb4b38.png)

看到还是或或多或少的出现一些广告。

  

那我们再看下ua，修改ua发现搜索任意东西再无广告。

  

![](../Images/df6cfaa47918d8a1fb006d743ad88637.png)

  

最后，附上ua头

> Mozilla/5.0 (iPhone; CPU iPhone OS 11\_3 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Mobile/15E302 SearchCraft/2.6.1 (Baidu; P2 11.3.1)

  

**后续**

  

当然，去除广告的方法有很多，包括不限于各种插件。

所见即所得。
