# NSA发布基于LINUX的开源信息安全工具

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4NjQxMDcxNA==&mid=370940448&idx=1&sn=e317d8ff2777830461d7edf1ae720e1b&chksm=0c21ae953b562783ecfa308a417a313c68fb04cb28b2ddf27c404435b7d587c96e681aef6b58&scene=126&sessionid=1681402878#rd](http://mp.weixin.qq.com/s?__biz=MzA4NjQxMDcxNA==&mid=370940448&idx=1&sn=e317d8ff2777830461d7edf1ae720e1b&chksm=0c21ae953b562783ecfa308a417a313c68fb04cb28b2ddf27c404435b7d587c96e681aef6b58&scene=126&sessionid=1681402878#rd)

为避免政府机构重复的工作。美国国家安全机构已经提供了网络安全工具，为政府部门和私营部门自由使用，以帮助他们加强自身安全和对抗威胁的能力。

上周末，该系统诚信管理平台 - SIMP - 已放到GitHub代码库。

美国国家安全机构说，SIMP有助于保持网络系统符合安全标准，形成一个层次，是“defence-in-depth”信息安全的一部分。

美国国家安全机构表示，发布这个工具，以避免美国政府部门和其他团体试图复制此产品，以满足美国国防和情报机构设置的法规和要求。

美国国家安全机构在一份声明中说，“通过开放SIMP，该机构旨在减少重复工作，促进社区内加强合作：wheel就不必进行彻底改造，为每一个组织，”。

目前，红帽企业Linux版本6.6，7.1和CentOS6.6版本和7.1-1503-01是唯一支持的操作系统对于SIMP。

美国国家安全机构近几年引起了大量的关注，由于其对大众进行监视和批量数据收集活动，由Edward 斯诺登暴露，且分享其技术在最近几个月。

该公司最近推出了“技术转让”项目，其目的是为了进一步发展政府和私营部门的新功能和新技术。

这个计划允许美国国家安全局提供内部开发的技术，为工业和研究人员。到目前为止，它开辟了跨越网络、 光学、 加工处理、 安全和微电子等等，其中的八个类别中的产品范围。

该计划的主任， Linda Burger，说:"联邦实验室的技术转移到市场上是非常有效的"开放源代码方法。

她在一份声明中说，“开源社区可以利用国家安全机构已经有的成果，政府可以从社会的专业知识和观点中受益。这是一个双赢的对于每一个人和国家。“

尽管它的情报收集工作是保密的，美国国家安全机构拥有生产和发布安全相关工作的历史先例，每年举行比赛，设法找到最好的网络安全论文。

为增强Linux安全 L间谍机构信任研究工作组还编写了强制访问控制结构的系统名 ，已经找到了几个版本，以及谷歌的 Android 移动操作系统，FreeBSD 和 Oracle 的 Solaris。
