```
加密密文：afZ_r9VYfScOeO_UL^RWUc格式：flag{ }
```

凯撒密码，其实就是一个简单的移位操作，变异凯撒就是会每个数字换一下这样子。

我们先对比一下ASCII码值（http://c.biancheng.net/c/ascii/）

![](../Images/058c012b402180446448d29b8b1a6758.png)

a的值是97，f的值是102，中间相差5。  

![](../Images/3bc589445f0960880aa7b4f4c2bf3428.png)

下一个字符是f，f的值是102，和l的值108，相差6。

以此类推，后面也是如此，所以我们编写代码，如下：

*   
*   
*   
*   
*   

```
str="afZ_r9VYfScOeO_UL^RWUc"k=5for i in str:    print(chr(ord(i)+k),end='')    k+=1
```

![](../Images/0c595314208b2d368a9e0c3b45140bd2.png)

得到flag为flag{Caesar\_variation}
