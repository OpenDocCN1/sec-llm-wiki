前言

即便是这些年，以谷歌Chrome为首的浏览器为了安全，进一步限制了用户执行JS代码的情况下，XSS依然是OWASP中的TOP10漏洞，危害依然很大，并且容易出现。

那么对于每一个刚入门Web的同学，简单掌握其原理，也是必不可少的了。

什么是XSS

人们经常将跨站脚本攻击（Cross Site Scripting）缩写为CSS，但这会与层叠样式表（Cascading Style Sheets，CSS）的缩写混淆。因此，有人将跨站脚本攻击缩写为XSS。

XSS攻击通常指的是通过利用网页开发时留下的漏洞，通过巧妙的方法注入恶意指令代码到网页，使用户加载并执行攻击者恶意制造的网页程序。这些恶意网页程序通常是JavaScript，但实际上也可以包括Java、 VBScript、ActiveX、 Flash 或者甚至是普通的HTML。

---来自百度百科

在我们摘录的内容中，可以看到其中提到了Java、 VBScript、ActiveX、 Flash 等，但是实际上，随着时代的发展，想VBS,ActiveX控件，以及Flash（尤其是在国外），已经比较少件。所以在CTF中，我们只需要学习和JavaScript有关的XSS即可，这也要求大家熟悉JavaScript这门语言啦。

XSS类型

反射型

我们先来看一张图，其实这就提现了为什么叫反射型XSS，其整个过程很像一个反射弧。

我们将恶意代码通过各种形式，提交给后端，后端在直接将我们的代码提交反射到页面上，显示出来，这样就是被我们攻击过，并且带有恶意代码的页面。

当这个页面被受害者点击，我们提交的恶意代码就会被执行，导致受害者被攻击

 1<?php//DVWA 反射型XSS low等级
 2
 3header ("X-XSS-Protection: 0");
 4
 5// Is there any input?
 6if( array_key_exists( "name", $_GET ) && $_GET[ 'name' ] != NULL ) {
 7    // Feedback for end user
 8    echo '<pre>Hello ' . $_GET[ 'name' ] . '</pre>';
 9}
10
11?>

可以看到，这是最简单的反射型XSS逻辑，我们通过GET方法，获取一个name参数，然后通过后端代码再将我们获得的name返回。

我们在这输入任意字符，比如hello，提交，网页会回显Hello hello。


那如果这个时候，我们提交的代码是如下的JavaScript代码呢？

简单说一下<script>标签是浏览器在HTML执行JS脚本的一个标志，里面的函数和内容会自动被浏览器解析为JavaScript并执行，其中的alert函数便是弹窗警告，显示其中的内容。

1<script>alert("hacker!")</script>

网页回显了我们我们输入的Alert，警告弹窗的内容。

这就是反射型XSS的基础过程，也是最基本的反射过程。

右键查看网页源代码，也可以看到我们的JavaScript语句成功插入，这也是为什么会弹窗的原因。

存储型

接下来，我们来讲讲存储型，和上文一样，我们先看一张图。

而存储型，是先将恶意代码提交给了数据库，再下一次访问特定连接时，将之前提交的恶意代码从数据库中取出，然后提交给了页面罢了，实际上只是多了一个中转过程罢了。

不过在实际中，如果是钓鱼的情况下，显然存储型是要比反射型隐蔽一点的，因为反射型很多情况需要你提前将参数写好，并带在URL中,而存储型则不用。

DOM型

可以说，以上的两种类型实际上没有什么差别，同样需要经过后端，但DOM型就不一样了，差距在哪儿呢？

就直接说了吧，DOM型不需要通过后端代码！

这并不是一件好事，这意味着很难在后端代码处进行过滤，像我们刚才的代码，我们可以在get或者post输入的时候，对字符串进行各种过滤，以防XSS，但是这下根本不经过后端，我们怎么办呢？这样的XSS又是怎么样形成的呢？

我们可以先看看DOM是什么。

HTML DOM（文档对象模型）

当网页被加载时，浏览器会创建页面的文档对象模型（Document Object Model）。

HTML DOM 模型被结构化为对象树：


通过这个对象模型，JavaScript 获得创建动态 HTML 的所有力量：

  • JavaScript 能改变页面中的所有 HTML 元素

  • JavaScript 能改变页面中的所有 HTML 属性

  • JavaScript 能改变页面中的所有 CSS 样式

  • JavaScript 能删除已有的 HTML 元素和属性

  • JavaScript 能添加新的 HTML 元素和属性

  • JavaScript 能对页面中所有已有的 HTML 事件作出反应

  • JavaScript 能在页面中创建新的 HTML 事件

    摘自https://www.w3school.com.cn/js/js_htmldom.asp

也就是说，就算是一个纯HTML页面，我们的JavaScript也可以干很多事情。

XSS可以干什么

讲完了三种类型的XSS，我们当然得说一下XSS可以干什么了，总不能就弹弹窗吧。

当然不是，如果我们将其中的alert函数替换成其他我们可以利用的恶意函数，我们就可以干很多其他的事情。

以下行为都非法的，请勿在未经授权的情况下尝试。

作为网安的学习者，我们要尽力使相关现象不再出现。

获取Cookie，实现无密码登陆

这是大家最熟知的，我们一般登陆网页，网页如何判断我们是否登陆，我们账户又对应的哪一个呢，其实就是使用的Cookie，或者Cookie的发展，Session，在这种情况下，如果目标网站没有做防护，通过XSS的方式，构造可以获取Cookie的JavaScript脚本，让受害者点击相关连接，获取其的Cookie，我们就可以冒充其直接登陆网站。

钓鱼

如果像BAT这种大厂的网站出现了相关漏洞，就会有这种情况，比如构造类似于www.baidu.com开头的连接，使用恶意JavaScript脚本跳转到伪装好的钓鱼页面，这就会让人放松警惕，从而泄露信息。
