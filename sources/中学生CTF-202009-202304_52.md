# Json Web Token浅析

  

## 什么是JWT

Json Web Token(JWT)是目前最流行的跨域认证解决方案。这个方案可以使用户在服务器之间传递安全可靠的信息。

举例来说，A网站和B网站是同一家公司的关联服务。现在一用户只用在A、B其中一个网站登录，在访问另一个网站就会自动登录。

## JWT原理组成

JWT的原理是，服务器认证后，会生成一个JSON对象，发会用户端，主要有header(头部)、payload(载荷)、signature(签名)三部分组成

例下图也有不同的颜色区分开来

  

![](../Images/90f28a3d23483aa3e1d873990590b48c.png)

简单的讲就是header是告诉你签名的算法，默认是HMAC SHA256（HS256），而payload是用来存放实际要传输的数据，signature最终是要对前面两部分进行数字签名。

## JWT的特点

一、缺点  
1.容易遇到跨域问题。不同域名下是无法通过session直接来做到认证和鉴权的。  
2.分布式部署的系统，需要使用共享session机制  
3.容易出现csrf问题。

二、优点  
1.方便灵活，服务器端直接创建一个sessionid，下发给客户端，客户端请求携带sessionid即可。  
2.session存储在服务端，更加安全。  
3.便于服务端清除session，让用户重新授权一次。

4.JWT 不仅可以用于认证，也可以用于交换信息。有效使用 JWT，可以降低服务器查询数据库的次数。
