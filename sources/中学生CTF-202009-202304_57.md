也就是说，只要我们可以操控`undefsafe`函数的第二个与第三个参数，我们就可以污染object的任意属性。

这道题调也用了`child_process`，大家看了上道题应该就理解了，这个是我们实现命令执行的关键，此时我们的`exec`关键字就可以直接调用系统指令命令执行。

那么现在思路其实很明确了，找到`undefsafe`和`exec`两个关键字的所在位置，就是我们的重中之重。

调用`undefsafe`的一共有两个函数，get\_note()、edit\_note()。

```

get_note(id) {
```

第一个函数，显然可以控制的参数不够，那么第二个函数，就是我们可以操控的重点了，他可以传入三个变量，**id**、**author**和**raw**，刚好满足我们刚才说的，第二个、第三个参数。

那我们接着找`exec`所在的地方，也就是我们的**status**路由，也就是当你访问****status****这个网页路径下，会执行的操作。

```
app.route(
```

这里使用了`exec`进行命令执行，然后调用的是**bash**解释器，执行的命令既是我们**commands**的所有属性。那么我们的目标很明确了，就是污染**commands**。
