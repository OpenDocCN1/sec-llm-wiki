原型链污染原理

今天的专题，主要讲的是原型链的污染问题。

原型链污染，如果是对JavaScript了解不深的人，初次看到这个名词的时候大概会一头雾水。

很显然，这个词有两部分组成，一部分是原型链，另一部分是污染。

那我们就按顺序，一个一个讲。

1

其他面向对象语言中的类、对象、继承

首先，再讲原型链之前，我们必须得提到几个概念，虽然这些是面向对象语言的基础，但以免有同学不知道，我们在这里直觉的简单的描述一下，可能不准确，希望各位大佬谅解。

1.类    2.对象    3.继承

1.1类

类是什么呢？简单来说，类就是对事物的一种抽象。比如说，汽车，这个词其实就代表了一个类。因为汽车这个词含括了一些有相同特征的事物：人乘坐的、烧油的、在路上跑的、交通工具。

那么汽车就是一个类，我们可以给这个类赋予一些属性，比如，汽车归属，可以坐几个人，出厂日期，品牌，剩余燃料量，甚至可以给他一些方法（函数），比如计算当前的燃料可以让汽车再跑多远等等。

这样的一个抽象的集合就是一个类。举个例子：

1.2对象

对象是什么呢？对象就是对应的一个类的实例化，对象就是一个一个实在的个体，比如说你的车，老王的车。举个例子：

1.3继承

继承又是什么呢，继承主要是在类上的继承。就和你可以继承你爸爸的外貌类似，继承指的就是获得原先已经有的东西。

还是之前的汽车类，有了汽车类，我是不是可以搞一个电动汽车类出来。但是如果直接单独写一个电动汽车类，会很麻烦，那么有人就想到了，是不是可以利用之前的汽车类，在汽车类上加一点，改变一点东西，就直接有了电动汽车类呢？这就是继承，这个时候，电动汽车类就继承了汽车类直接拥有了汽车类的属性和方法（函数）。

我也可以根据自己的需求对这些属性和方法进行修改。

比如说我可以把剩余公里数计算，改成剩余电量计算。

简单来说就是这样。

2

原型链

那么问题来了，原型链和这些有什么关系呢？

这就不得不回到JavaScript这个语言本身了，JavaScript语言本身是面向对象的，上期我们也提到过，甚至大部分人会对JavaScript有这样一个描述：”万物皆对象“。

那么看了前文，有人就会想，那么JavaScript一定有类吧。

但很不幸的是，它没有，或者说它有但不完全有，虽然他有Class类这个关键字，但那只是一个语法糖（本质上还是用其他东西实现的类，而不是本身有类）。

那么聪明的同学可能就想到了，没有类，又是面向对象的语言，那么怎么样才能创建对象，又怎么样去实现继承功能呢？

简单来说，这两个问题都很好回答，用对象去创建对象，用对象去继承对象不就好了？

但实际上是怎么实现的，就不是那么简单了，这就回到了我们这期的主题之一，原型链。

再讲原型链之前，我们必须还得知道两个属性 __proto__ 和prototype。

2.1proto

请注意，这个属性两边是双下划线。__proto__ 属性是对象拥有的属性，所以可以说JavaScript大部分东西都有这个属性。这个属性的作用是什么呢？当我们访问对象的某个属性的时候，如果这个对象内不存在这个属性，那么JS就会去找这个对象的 __proto__ 所指向的对象，在那个对象的属性里找，如果还没有找到，就会继续向上找，直到某一个属性的 __proto__ 指向了Null，证明找到头了，这就是终点。

是不是觉得很熟悉，明明这个对象里没有的属性，为什么还要向上找？

很显然，这就是为了实现JavaScript中的继承， __proto__ 属性所指向的对象，就相当于父对象，甚至可以说类一样，只要 __proto__ 能找到，那么就可以说这个属性是在这个对象里的。

而这样一个向上查找，在Null停止的链，就是我们的原型链。

好了，那么大家知道原型链是什么了？那和另外一个prototype属性有什么关系呢？答案就要在下面揭晓。

2.2prototype

我们之前说到， __proto__ 属性是对象所拥有的属性。而我们现在讲的prototype是方法（函数）所拥有的的属性。但这并不意味着方法没有 __proto__属性 ，因为方法本身也是对象。

也就是说，方法有 __proto__ 和prototype，但是对象只有__proto__。

那么prototype的作用到底是什么呢？我们刚才提到了，__proto__属性会指向父对象，但是指的是父对象本身吗？并不是，指向的是父对象的prototype，为什么要指向这个属性呢？因为这个属性挂载了我们所需要继承的方法和属性。

3

污染

污染，这个词的意思就是在一些很纯净的东西里加入了一些脏东西。

相信聪明的同学可能已经想到了这个污染到底是怎么一回事了吧，一个对象，它本身如果我们不能改变，是不是可以通过改变它原型链上的东西，从而去改变它本身呢？

这其实就是原型链污染的一个过程，我们举个最简单的例子。

var test ={t:false};//创建一个test**对象**，其中包含一个t属性，初始值为假
console.log(test.t);//打印值，返回当然也是假
test.__proto__.t=true;//改变test**对象**proto属性指向的**对象**（也就是上图的Object.prototype)的t属性值为true
console.log(test.t);//虽然原型的**对象**值改变了，但因为JS会先搜索当前**对象**是否有该属性值，所以返回值任然是false
var test2={};//创建一个test2新的空**对象**
console.log(test2.t)//理论上test2是没有t这个属性的，但是由于它的proto指向与test相同，也就是在一条**原型链**上，导致test2.2在**原型链**上找到了t这个属性，返回值为true
//返回了一个本来不应该存在的属性值，这就是污染

这样的污染就可能让Web服务执行它本来不应该执行的东西，造成各种漏洞。

从这个例子我们也知道，如何利用造成这样的污染呢？就是对已有对象的 __proto__属性进行修改，也就是我们可以操作到某个对象的属性名，让其等于 __proto__，并且可以修改属性的值为我们想要的恶意代码。

最常见的两个可利用方法，就是Merge合并、Clone克隆两个方法，因为这两个方法都会用到对象的属性，或者说key。

https://github.com/HoLyVieR/prototype-pollution-nsec18这个项目里有其他易受攻击的函数API，可自行查看。

我们在这再举一个最基础的例子。

//这是一个简单的合并函数
function merge(target, source) {
    for (let key in source) {
        if (key in source && key in target) {
            merge(target[key], source[key])
        } else {
            target[key] = source[key]
        }
    }
}
let o1 = {}
let o2 = {a: 1, "__proto__": {b: 2}}
merge(o1, o2)
console.log(o1.a, o1.b)

o3 = {}
console.log(o3.b)

最后的结果并不是想象的那样，原型链并没有污染，可以看到o3中并没有b这个属性。

像是o2.__proto__被看作是一个对象，插入到了整个原型链中，也就是现在的o2.__proto__被看作是一个对象，而不是我们所需要属性，或者说Key。

那么我们该怎么办呢？这就不得不提到JavaScript的好朋友，JSON。至于JSON具体是什么，大家只用了解它是JavaScript的一个特殊数据格式就好。

那么我们该如何利用JSON达成我们的目标呢？我们这里使用JSON.parse()，它的作用是将JSON转化为对象，也就是说'{"a": 1, "__proto__": {"b": 2}}'这个内容其实是JSON数据，通过parse()转化为了我们的o2对象。这个时候__proto__就会被解析成我们所需要的，在原型链上的__proto__，不信我们可以试试。

let o1 = {}
let o2 = JSON.parse('{"a": 1, "__proto__": {"b": 2}}')
merge(o1, o2)
console.log(o1.a, o1.b)

o3 = {}
console.log(o3.b)

可以看到，这下我们的污染就已经成功了。
