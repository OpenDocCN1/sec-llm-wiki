JavaScript审计初探





    CTF比赛中，Web方向，主要考察的一个方向就是代码审计，常见的需要审计的代码有PHP、Python、Java，还有我们今天的主角JavaScript。


    很多同学在接触Web的时候，尤其是刚入门，可能只会接触PHP，而对其他语言接触的较少。但随着时代的发展，网页的后端使用PHP外编程语言的占比逐渐增高，对于比赛的出题者来说，就会增加其他语言题目的权重。那么这就让我们需要有更多的技术知识，而不是只仅限于在XSS的时候，会一点JS。


什么是JS





    JavaScript是一种具有函数优先的轻量级，解释型或即时编译型的编程语言。虽然它是作为开发Web页面的脚本语言而出名，但是它也被用到了很多非浏览器环境中，JavaScript 基于原型编程、多范式的动态脚本语言，并且支持面向对象、命令式、声明式、函数式编程范式。——摘自百度百科


    作为一款被设计用来进行Web开发，那么它自然会和PHP有许多的共同点，比如说解释型语言，弱类型等等方面。所以，在这默认读者都有一定的编程基础，就不讲解基础的语法了


    至于环境，你只需要配置一下node.js，有一个VSCODE之类的编辑器，即可编写相关代码。

    那么接下来我们就进行JS审计的一个基础学习。

在这之前，这里有几个小点首先需要大家了解。


变量声明





var

    函数作用域，或者可以说全局作用域，假如在第十行声明的代码。在第一行也可以用，后两者不行。

    可重新赋值。


let

    块作用域，只能在定义后的代码块使用。

    可以重新赋值。


const

    块作用域，和let一样，只能在定义后的代码块使用。

    不能重新赋值。


弱比较






    JS，和PHP一样，是有弱比较存在的。


var a=123;
var b='123';
if(a==b)//弱比较
{
    console.log('true');//console.log，调用console对象的log方法，在控制台输出，可理解为printf
}
if(a===b)//强比较
{
    console.log('true');
}
//只返回一个true，和php很像，但基本不会有这样的题目。


函数声明





    函数声明有两种方式


function a()
{
    var b=1;
    console.log(b);
}
var a = function(){
    var b=1;
    console.log(b);
}//这两种方式基本上是一样的


对象




    俗话说，JS万物皆对象，虽然实际上这么说不准确，但也可以先这么理解。

我们所声明的变量也好，function也好，到最后他们的原型proto都是对象object。

    说到原型，就不得不提到原型链，JS并没有真正意义上类的存在，所谓的Class关键字也就是语法糖，所以继承的实质可以说是对象对象之间，或者说对象和原型之间的继承。

    原型链就概括了整个继承的一个过程，如图。

    这样直接说会有点抽象，大家先有一个印象就好，在后面的例题，以及之后的原型链污染讲解中，相信大家可以完全理解。

function test(arr) {
    var random_value =                                                 "ac1a39300ce7ee8b6cff8021fd7b0b5caf5bc1c316697bd8f22e00f9fab710d6b8dba23ca80f6d80ca697e7aa26fd5f6";
    var check = "20150303";

    if((arr === null || arr === undefined)) {
        console.log("arr is null or undefined.");
        return;
    }

    if(!arr.hasOwnProperty('length')) {

    }

    if(Object.getPrototypeOf(arr) !== Array.prototype) {
        console.log("Oh.... can you give me an array?");
        return;
    }

    var length = check.length;
    for(var i=0;i<length;i++) {
        arr[i] = random_value[Math.floor(Math.random() * random_value.length)];

    题目的目标是输入一个arr参数后，使函数成功打印出flag。

仔细看题目，总共需要过五关，每一个if后都是一关。


1.首先要求arr变量不为空或未定义

    这个很好说，只需要声明一个arr变量即可。


var arr=1;



2.hasOwnProperty方法要求arr拥有length属性

    那我们可以定义一个数组，自带arr属性。


var arr=[]；



3.要求length小于0

    很显然数组的长度不能为0，那么我们可以自己搞一个带length的对象。


var arr={length:-1}



4.getPrototypeOf(arr)!== Array.prototype

    要求arr的原型要和数组原型一样。

    这就有一点难度了，首先arr现在的原型为对象object{}

    而Array的原型为数组[]

    而之前要求的长度为-1，数组的长度不能为-1，那么该怎么办呢？


function a()
{
    this.length=-1;
}
var a;
a.prototype=Array.prototype;
var arr=new a;



    这样就行，为什么呢？

    因为在new的过程中，会将新对象的prototype指向所指对象的prototype，也就是a.prototype，那在这之前我们用a.prototype=Array.prototype;赋值过了。

    那么这样就可以绕过了。

    还有人问，那为什么要一个一个赋值，而不是整体赋值呢？

    因为在整体赋值的时候，arr的类型会认为是数组类型，length值会变化，所以不能整体赋值。

function test(arr) {
    var random_value = "ac1a39300ce7ee8b6cff8021fd7b0b5caf5bc1c316697bd8f22e00f9fab710d6b8dba23ca80f6d80ca697e7aa26fd5f6";
    var check = "20150303";

    if((arr === null || arr === undefined)) {
        console.log("arr is null or undefined.");
        return;
    }//arr不能为空或者未定义

    if(!arr.hasOwnProperty('length')) {
        console.log("length property is null or undefined.");
        return;
    }//hasOwnProperty方法，查找当前对象是否有这个属性，但不会查找原型链

    if(arr.length >= 0) {
        console.log("i think you're not geek. From now on, a GEEK Only!");
        return;
    }//length属性的值不能大于等于0

    if(Object.getPrototypeOf(arr) !== Array.prototype) {
        console.log("Oh.... can you give me an array?");
        return;
    }//获取当前对象的原型The Object.getPrototypeOf() method returns the prototype
    /*
    var proto = {};
    var obj = Object.create(proto);将proto当做原型，创建对象
    Object.getPrototypeOf(obj) === proto; // true
    new方法的过程中
    会将新对象的prototype指向所指对象的prototype
    而create是指向对象的原型的prototype
    */

    var length = check.length;
    for(var i=0;i<length;i++) {
        arr[i] = random_value[Math.floor(Math.random() * random_value.length)];
    }

    for(i=0;i<length;i++) {
        if(arr[i] !== check[i]) {
            console.log("Umm... i think 2015/03/03 is so special day.\nso you must set random value to 20150303 :)");
            return;
        }
    }
    console.log("flag");
}
