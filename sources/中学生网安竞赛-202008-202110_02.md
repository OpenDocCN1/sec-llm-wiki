**welcome2forum**

**考点**

•    Python格式化字符串漏洞

根据首页F12，注释可知访问 /source.html 可以下载源代码。

![](../Images/f829f800d20b095b75a48901f023543b.png)

进行简单的代码审计，在 error.html 这个路由下，可以发现可能存在的格式化字符串漏洞

![](../Images/e4d35f045116ba2b694acd4491a9f459.png)

跟一下调用的 a\_\_error() 函数，可以发现，这里有一个 info 字典，里面存着 flag ，所以思路很清晰了，通过格式字符串漏洞去读全局变量，拿到flag

![](../Images/f60c41c5603b4ab369fd619451dbdbcf.png)

**考点**

•    过滤单双引号，如何bypass

•    利用 rlike 或者 regexp 进行模糊匹配，来SQL盲注

SQL注入语句在F12中给出

![](../Images/3dc6e3d4031a58861deeb9d21bfb867b.png)

通过 username=admin\\&password=||1=1# 可以成功登陆

![](../Images/c8be82c0f3866a6043464466a843dec7.png)

这里 0 || 1 = 1 ，0 || 0 = 0 ，且当username输入 admin\\ 时，username恒为0，所以可以通过控制 password 的输入运算返回值来进行盲注
