这道题主要是查看OFB模式到底是个什么东西 这儿⊕表示按字节异或。

而我们看题目handle部分，其中给出了四个选项

•    加密Blackbird发送给Noah的信息。

•    发送给他明文，接着加密后发送给你。

•    退出

•    拿到Blackbird发送给Noah的消息发送给他然后让他check通过就能拿到flag了。

在这道题目当中，发现了一个比较奇怪的点，IV和KEY都没有变过！只用了一次！而他对明文操作过程中的下一轮的IV其实就是这一轮IV加密后的结果，于是我们就能发现！他其实并没有改变过异或的值，让你加密的时候与拿到他的密文的时候。

那么我们可以先拿到密文，同样！我们还能拿到密文的长度，去构造一个根据密文长度拿到这个加密后的所有密文与你给出的明文异或后拿出的就是东西。

那么，我们只需要接着将拿到加密后的东西去后与他异或就能够拿到明文了。而明文Padding过，我们发现这个Pad就是%16之后的值，那么我们Unpad就只需要m[:-m[-1]]，就能拿到完全的明文是啥了！

Block_of_Hash

这道题其实主要是出题人在看区块链内容去改编了这道题。

一开始的proof_of_work，它的sha值拿出来是 FirstBlockHash，有个transaction = b"0x114514 transfer 1 bitcoin to 0x1919810" 新的一块BlockHash是由transaction_hash_generator将hash和transcation连起来，接着给出了一个随机的limited在0到1024之间，还有一个Pr0of_oF_w00k是根据每一块BlockHash和限制还有transaction一起，一共三次，让数据进行新的工作量证明。

而我们需要最后一块BlockHash给出前8位 如果猜对了就能拿到flag。

其实这道题，我们发现 20 s 有的时候可能会拿不到。而预期解其实就是按照题意来进行爆破，预测一下就可以了。

而如果超时了我们就可以断开之后重连，大概平均5-10s能出来！

题目跟前面的原来的大致一样，就是改变了Hash部分，使用了AES的CBC模式加密后取最后一块。以及这次需要在180ｓ内猜对5次才能够拿到flag，AES——CBC的Key和IV我们都已知都是HashKey，我们发现他在对BlockHash哈希的过程中三次limited都没有改变大小。并且给出了BlockHash的前29字节需要预测对5次BlockHash的值才能拿到flag

def MyHash(self, m):        aes = AES.new(HashKey , AES.MODE_CBC , iv = HashKey)        return aes.encrypt(m)[-16:]

该题如果用上题思路去进行爆破会发现3次Nonce需要爆破3个2的11次方的内容大概是8e10左右的爆破空间，C语言至少需要运算十几分钟

但是该题后面给出了最后一轮的BlockHash的前29字节，并且该题Hash函数使用AES的CBC实现可逆。并不是真正的哈希。可以使用中间相遇的方法 前面只爆破两次Hash函数的结果，将其记录在一张哈希表中（字典），然后爆破BlockHash最后三字节再一次逆向Hash函数，查表找到碰撞。爆破量为2的23次，空间约为4mb

预处理：

我们发现MyHash当中使用AES-CBC模式。最后一块加密使用的IV固定并且可以预先得到。IV = Enc(pad(transaction+hex(nonce)[2:].encode()))

这一块的内容里面nonce是在limited限制当中的，于是我们可以提前先来预测下一段的IV，将这前面的这块内容加密后拿到密文的最后16位，写进一个IV表。

主要解密思路是：

def transaction_hash_generator(hashes):    block = pad(transaction) + hashes    return MyHash(block)

def getdic(limited):    for nonce in range(limited):        m = pad(transaction[32:] + hex(nonce)[2:].encode())        m = XOR(m , iv)        c = aes.encrypt(m)        dic[nonce] = c
def getnoncedic(limited , BlockHash):    noncedic = {}    for nonce1 in range(limited):        m1 = XOR(BlockHash , dic[nonce1])        c1 = aes.encrypt(m1)        for nonce2 in range(limited):            m2 = XOR(c1 , dic[nonce2])            c2 = aes.encrypt(m2)            noncedic[c2] = nonce1    return noncedic
def passed1(noncedic, hint , limited):    for last in range(4096):        c = unhexlify(hint + hex(last)[2:].rjust(3 , '0').encode())        m3 = aes.decrypt(c)        for nonce3 in range(limited):            m2 = XOR(dic[nonce3] , m3)            if m2 in noncedic:                return hexlify(c)    return None
