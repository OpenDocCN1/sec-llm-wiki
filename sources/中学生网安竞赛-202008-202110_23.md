# 电子数据取证比赛参赛流程

**组队相关：**

组队最好的是每个人有每个人的分工，比如队员一负责服务器取证、队员二负责windows取证、队员三负责答题协调并负责一些手机取证、日志流量分析等小项目。但是三个人都必须会Windows取证和内存取证，资格赛会有要求。

**赛前准备：**

比赛之前要准备好相应的工具集，比如：取证大师、手机大师、火眼取证、火眼仿真、恢复大师、WinHex、X-ways、Volatility Workbench、RAID Reconstructor、phpStudy、DiskGenius、FTK、TrueCrypt、VeraCrypt等软件

赛前组队和工具准备好之后需要对往年案例进行模拟演练，最好提前一个月开始进行，每周至少一次，分时分题进行。

到达比赛场地签到后会发放加密的镜像容器文件，一般会提前告知是使用TrueCrypt还是VeraCrypt解密镜像容器。一般一个组只发放一个硬盘，所以比赛前的晚上要进行镜像拷贝工作，并校验哈希值防止复制过程出错。

**比赛进行时：**

比赛分为资格赛和团体赛。

资格赛在上午进行，时间为两个小时，赛题数量为50-60题，时间要抓紧，做不出来要直接战略性放弃。首先按要求接入主办方专用网络，一般采用RJ45有线连接，然后登录自己的账号，如果无法登录咨询主办方工作人员。登录成功后在比赛开始之后会以公告的形式发放加密容器密码，输入密码后就可获取到比赛镜像（详情搜索 TrueCrypt和VeraCrypt的用法）。答题的时候不确定可以先选着然后标记一下，注意只可提交一次，中途没做完不要点提交，时间到了也会自动提交。

团体赛在下午，中午吃饭在自己团体赛座位上，可以交流一下上午的个人赛，一般个人赛和团体赛会有一定的联系。团体赛100道题目左右，时间为5小时，三个人均可答题，但是最后只能由一个人点提交。按照分工提前分好相应的模块，做题过程要交流，每一部分都是有联系的，不会的先空着，后面说不定可以在其他队友的模块里面找到答案。

**比赛结果：**

比赛当天结束就会出结果，可以询问指导老师。第二天会要求一等奖队伍答辩，如果获得了一等奖要好好做答辩PPT。答辩完就开始资格赛和团体赛的颁奖，获奖个人务必参加，获奖队伍派一名代表参加即可。
