解题思路  

  

→题目将flag切分成了四部分,对每部分进行加密,给出对应的module和ciphertext.

  

→运用math.gcd()方法两两求公因数

→完成RSA解密并拼接flag

  

**→RSA e==n 情况：**

定理简单证明

考察 e==n 这一特殊情况下的RSA加密

对任意两个不同素数p,q和整数n=p\*q,对任意整数m,0 < m < p且m < q,若 c = m^n mod n, 则 c^(q') mod q = m,其中q'满足q'\*p mod (q-1) = 1.

予以证明如下:

c^(q') mod q = m^(n\*q') mod q = m^(q\*p\*q') mod q = m^(((q-1)+1)\*(k\*(q-1)+1)) mod q = m^(k'\*(q-1)+1) mod q

根据费马小定理: m^(q-1) mod q = 1,所以 m^(k'\*(q-1)+1) mod q = m.同理c^q' mod p = m.

该题以此为原理,进行了扩展,将素数数量由2个扩大到了4个,并将m的范围扩大到0 < m < n.
