签到题，IDA打开，定位到main函数，F5看伪代码逻辑。

 

Fgets读取输入保存到v5，sub_4016A0验证输入。

程序先将v5这个字符串代入sub_401500进行变换，然后将结果与我们的输入带入sub_4016D0进行编码，最后与字符串”tVmRt1f2Dr...进行比较，这里有一个地方比较坑，就是IDA伪代码显示的"HUyYytQOElCcVpva3...是从v5的第二位开始的（仔细看strcpy的第一个参数！！）所以v5的第一个字符应该是unk_404080。

 

看一下加密函数sub_4016D0的逻辑，有经验的这时候就知道是base64编码了，但有人说，我是小白，不知道这是什么加密怎么办。没有关系，你还有CTF中最强大的工具——搜索引擎。在逆向中，经常会遇到一些没见过的算法，一可以搜代码，比如（这句代码就是从IDA F5的结果里抠的）

还有的时候，Github也是强大的利器。

在函数sub_4016D0下断，可以拿到变换后v5的值。

“lu2c+P8IBqZokw6xUs9SLr34DtKTaWHJ/Rb0eXVNAyEzCf5phmjnFMO1iYdg7GQv”刚好64位且没有重复字符出现，所以我们断定这是一个码表，题目加密算法是换表base64。（关于换表base64，百度上有很多解密的脚本了，觉得看出来不可靠的兄弟，可以看下图）

贴脚本。

import base64

import string

 

enc_flag = "tVmRt1f2DrwPw0sJKrwJr8RP4OFhLMUfDnufT3G64FkhscP5sMGwsrsATFsG"

string1 = "lu2c+P8IBqZokw6xUs9SLr34DtKTaWHJ/Rb0eXVNAyEzCf5phmjnFMO1iYdg7GQv"

string2 = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/"

print(base64.b64decode(enc_flag.translate(string.maketrans(string1,string2))))
