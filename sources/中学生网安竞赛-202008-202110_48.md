程序先将v5这个字符串代入sub\_401500进行变换，然后将结果与我们的输入带入sub\_4016D0进行编码，最后与字符串”tVmRt1f2Dr...进行比较，这里有一个地方比较坑，就是IDA伪代码显示的"HUyYytQOElCcVpva3...是从v5的第二位开始的（仔细看strcpy的第一个参数！！）所以v5的第一个字符应该是unk\_404080。

![](../Images/d9ba31eff80329ee0299db198f4c7ffd.png)

在函数sub\_4016D0下断，可以拿到变换后v5的值。

“lu2c+P8IBqZokw6xUs9SLr34DtKTaWHJ/Rb0eXVNAyEzCf5phmjnFMO1iYdg7GQv”刚好64位且没有重复字符出现，所以我们断定这是一个码表，题目加密算法是换表base64。（关于换表base64，百度上有很多解密的脚本了，觉得看出来不可靠的兄弟，可以看下图）

贴脚本。

import base64

import string

 

enc\_flag = "tVmRt1f2DrwPw0sJKrwJr8RP4OFhLMUfDnufT3G64FkhscP5sMGwsrsATFsG"

string1 = "lu2c+P8IBqZokw6xUs9SLr34DtKTaWHJ/Rb0eXVNAyEzCf5phmjnFMO1iYdg7GQv"

string2 = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/"

print(base64.b64decode(enc\_flag.translate(string.maketrans(string1,string2))))
