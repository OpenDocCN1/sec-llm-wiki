近年来，针对 Active Directory 的网络攻击呈上升趋势，AD作为目前企业应用最广泛的内网身份解决方案，一旦被渗透，将会带来巨大的损失，解决AD安全防护问题，企业需要未雨绸缪。为帮助企业IT运维及安全从业人员更好地了解和防范涉及 AD 的攻击类型和攻击事件，中安网星整理、分析了近期针对AD架构引入或传播恶意软件的网络攻击事件。

2021年HIP全球会议将AD防护列为六大要点之一

Hybrid Identity Protection（混合身份保护）是负责保护混合云环境的以身份为中心的网络安全从业人员的教育论坛。12 月 1 日至 2 日举行的在线会议吸引了来自世界各地的身份和访问管理 （IAM） 专业人员、IT 运维从业人员和安全领导者。

会议上就如今 Active Directory 频繁出现安全漏洞的挑战为与会者提供了一些建设性的指导，其中包括保护Active Directory 的技巧。微软首席混合云倡导者Orin Thomas 指出了常见的AD错误配置，其他专家学者也对AD帐户安全性进行了深入研究，探讨了话题如“顶级遗留AD基础架构漏洞以及攻击者如何看待它们”、“勒索软件攻击后复活Active Directory ”等。








ProxyShell 导致全域勒索软件攻击

ProxyShell是 7 月份披露的三个 Microsoft Exchange Server 漏洞的名称，它们共同点为能够进行权限提升和远程代码执行。

根据 DBIR 报告，未打补丁的 Exchange Server 客户遭受了勒索软件攻击，该攻击利用了未打补丁的漏洞并最终导致全域范围的攻击。报告称，此次攻击不涉及任何勒索软件即服务工具，并且“几乎没有使用恶意软件”。









俄亥俄州医院是一系列勒索软件攻击中最新的医疗保健领域受害者

俄亥俄州南部医疗中心遭到勒索软件攻击，中断了患者护理并破坏了患者数据。最新的通报显示，卫生系统仍在努力安全地恢复系统和运营，并警告省居民，受保护的健康信息似乎在攻击中被盗。

根据 SOMC（social Ohio medical center俄亥俄州社会医疗中心）发布的社交帖子，持续的停电迫使官员们转移救护车并取消了一些患者的预约。

官员解释说：“在似乎是有针对性的网络攻击中，未经授权的第三方获得了对 SOMC 计算机服务器的访问权限。”









Hive 勒索软件声称对约翰逊纪念健康中心进行了攻击

约翰逊纪念健康中心（ Johnson Memorial Health）是美国一家大型医疗机构，自10月1日遭受攻击后，仍在努力从勒索软件集团Hive的袭击中恢复过来。Hive软件使用远程管理软件渗透系统并建立持久性，然后部署 ADRecon 等工具来映射 Active Directory 环境。









Hillrom心脏病学设备的零日漏洞可能允许攻击者完全控制

当设备配置为使用单点登录（SSO）时，Hillrom（一家医疗器械公司）制造的某些产品中的身份验证存在绕过缺陷。几种心脏医疗保健设备中存在高严重性漏洞，可能允许攻击者在没有密码的情况下访问特权帐户并控制设备。

它允许手动输入应用程序中预置的所有活动目录（AD）帐户，这意味着无需提供关联密码即可授予访问权限。该漏洞为CVE-2021-43935，Hillrom计划在下一个版本中解决这个问题，因此该漏洞目前仍未修补。

为了降低风险，Hillrom建议在相应的Modality Manager配置设置中禁用SSO功能。




总

结


从本文相关新闻案例中，AD防护在全球网络安全中的地位水涨船高，其中很大原因是近年攻击者针对AD的攻击手段愈发多样，而作为企业身份认证的连接点，AD被攻击导致的后果也如上述新闻所示，可能致使正常的业务瘫痪。

因此，在未来的企业安全建设过程中，建议将AD安全防护的加固纳入思考，从而防患于未然；若存在已知威胁，也可通过及时修改配置将风险最小化。AD的安全防护建设对内网安全能力的提升将起到至关重要的作用。
