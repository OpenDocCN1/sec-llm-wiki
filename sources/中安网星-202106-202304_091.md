近年来，针对 Active Directory 的网络攻击呈上升趋势，AD作为目前企业应用最广泛的内网身份解决方案，一旦被渗透，将会带来巨大的损失，解决AD安全防护问题，企业需要未雨绸缪。为帮助企业IT运维及安全从业人员更好地了解和防范涉及 AD 的攻击类型和攻击事件，中安网星整理、分析了近期针对AD架构引入或传播恶意软件的网络攻击事件。

**APT29组织以Active Directory联合身份验证服务为目标发动攻击**

安全研究人员标记了一个与俄罗斯政府有联系的网络间谍组织，该组织部署了一个新的后门，旨在利用Active Directory联合服务（AD FS）并窃取配置数据库和安全令牌证书。微软将恶意软件程序FoggyWeb归咎于NOBELIUM（也称为 APT29 或 Cozy Bear）组织——被认为是 SUNBURST后门的幕后黑手。微软表示已通知所有受影响客户，并建议用户：

*   审核本地和云基础架构，包括配置、每个用户和每个应用程序的设置、转发规则以及参与者可能为维持访问而进行的其他更改；
    
*   删除用户和应用程序访问权限，审查每个用户/应用程序的配置，并按照记录在案的行业最佳实践重新颁发新的、强大的凭据；
    
*   使用硬件安全模块（HSM）以防止FoggyWeb泄露机密数据；
    

  
  
  
  
  
  
  
  

# **新的 Microsoft 紧急更新修复了 Windows Server 身份验证问题**  

Microsoft 于11月份发布带外（Out of Band）更新，以解决与影响域控制器 (DC) 运行受支持版本的 Windows Server 的 Kerberos 委派方案相关的身份验证失败。

在受影响的系统上，最终用户无法在本地 Active Directory 或混合 Azure Active Directory 环境中使用单一登录 (SSO) 登录服务或应用程序 。

这些问题会影响运行 Windows Server 2019 及更低版本的系统，包括 Windows Server 2016、Windows Server 2012 R2、Windows Server 2012、Windows Server 2008 R2 SP1 和 Windows Server 2008 SP2。

紧急更新解决了“一个已知问题，该问题可能导致与您从 Service for User to Self (S4U2self) 获得的 Kerberos 票证相关的身份验证失败，”微软在周日的公告中解释道。“在运行 Windows Server 的域控制器 (DC) 上安装 2021 年 11 月 9 日的安全更新后，会出现此问题。”

  

  
  
  
  
  
  
  
  
**Microsoft AD 中几个常见的错误配置**

大多数 Active Directory 环境中存在三种非常常见的错误配置。首先是易受“Kerberoast”攻击的高特权用户。通过结合特定的 kerberos 配置、弱密码和高权限，攻击者能够在几乎每个 Active Directory 域中利用这种错误配置。

其次，是具有任何一种特殊特权的全包安全主体。例如常见的“域用户”组在一个或多个系统上被授予本地管理员权限。这种配置有效地为攻击者提供了一个“beach head”机会，可以启动一条攻击路径且该路径可能会一直受到域管理员用户的攻击。

第三，将普通用户或权限较低的服务账户视为域控制器计算机账户的对象所有者也是很常见的错误配置之一。这种错误配置可以弥补环境的其余部分与域控制器之间的差距，因为这些普通用户或较低权限的服务账户没有得到与更敏感的域管理员用户账户相同的保护和照顾。

  
  
  
  
  
  

  

**Microsoft AD 被 Gartner MQ for IAM 评为领导者**

在2021年 Gartner 访问管理魔力象限中，Microsoft 因其 Microsoft Active Directory 及其Azure AD相关能力被评为该领域中的“**领导者**”。

微软在魔力象限中，愿景轴的完整性排名最靠前，执行能力排名第三。![](../Images/897467e97520c69e43f807ad60c6f93b.png)

  

据 Gartner 称，到 2025 年，超过 70% 的新部署将更喜欢融合身份和访问管理 (IAM)，到 2024 年，低代码和无代码编排工具将成为 IAM 产品的关键。
