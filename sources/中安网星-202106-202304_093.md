## 

  

近年来，针对 Active Directory 的网络攻击呈上升趋势，AD作为目前企业应用最广泛的内网身份解决方案，一旦被渗透，将会带来巨大的损失，解决AD安全防护问题，企业需要未雨绸缪。为帮助企业IT运维及安全从业人员更好地了解和防范涉及 AD 的攻击类型和攻击事件，中安网星整理、分析了近期针对AD架构引入或传播恶意软件的网络攻击事件。

**辛克莱电视台内网AD域被袭击，本地广告投放中断**

在美国拥有87个市场，经营了 193 家美国电视台的辛克莱广播集团是美国第二大电视台运营商，其业务覆盖了约40%的美国家庭。在10月16日，辛克莱检测到安全事件，并于17日确定其内网环境中的部分服务和工作站已被勒索软件加密。这次攻击深入到辛克莱的电视广播系统，并导致业务中断，其中核心业务包括本地广告投放等。由于调查仍处早期阶段，因此暂无法衡量该事件导致的影响范围。据报道，本次事件中，攻击者利用了该公司的企业 Active Directory 域和一个数据库，还有内网中专门用于管理用户和网络设备的服务。

**REvil 活动受国际执法机构限制，基本关停**  

10月份，包括美国执法机构在内的国际政府实体已经关闭了 REvil 的网站和网络基础设施，REvil 是一个臭名昭著的勒索软件组织，又名Sodinokibi，曾入侵并发布了MacBook 的原理图，被称为最具统治力和破坏性的勒索软件之一。今年的5月30日，REvil对肉类加工巨头JBS发动攻击；7月2日，对远程管理软件公司Kaseya 再次发动攻击，而后遭到美国政府的及国际执法机构的毁灭性打击，自7月13日起托管至暗网。在近期的新闻中，暗网及博客也已停止运营，多名团队成员已落网。

![](../Images/181b7c55ea06649b5cba4cbf196122e9.png)

REvil团伙对特定目标进行长期渗透，通过AD域获取内网权限并控制关键生产设施（例如域控主机），然后通过特定方式（例如域策略、PsExec远程连接执行等）在内网中传播加密病毒主体程序；或通过域控下发组策略的方式，将勒索病毒样本拷贝到终端并执行。勒索病毒本体具有有效数字签名，并采用了“白加黑”的方式，以躲避杀毒软件查杀。

**Microsoft Exchange Server 的自动发现功能泄露用户凭据**

国外Guardicore 研究人员发现，Microsoft Exchange 中自动发现功能的错误实施导致至少 100,000 个 Windows 域的登录名和密码被泄露给第三方不受信任的域。据研究人员称，当用户输入电子邮件地址和密码组合时，客户端会尝试在 Active Directory 域服务 (AD DS) 的服务连接点 (SCP) 中查找配置 URL。如果客户端无权访问 AD DS，邮件客户端将尝试对各种自动生成的 Microsoft Exchange 自动发现 URL 进行身份验证。邮件客户端尝试从用户的电子邮件地址构建自动发现 URL。因此，攻击者可以设置顶级自动发现身份验证域来收集用户泄露的凭据。
