公司介绍


    北京中安网星科技有限责任公司成立于2020年8月，是一家聚焦于以智能安全运营方案为企业解决AD域安全问题的软件及服务供应商，由来自于360、知道创宇、默安科技等知名安全企业的行业精英共同创立。

    凭借着在信息安全领域多年的技术积累自主研发了与传统信息安全产品相比具有差异化和核心竞争力的优势产品，以安全运营目标为导向，以人、流程、技术与数据的融合为基础，形成一套标准化、可预测的Windows AD域安全解决方案，致力于使用AI与自动化编排技术为国内企业解决AD域安全问题。

职位介绍



渗透测试工程师

地点 : 北京 / 深圳 8K-15K

工作职责：

1、针对大中型企业外网及内网进行渗透测试，评估企业网络安全等级；

2、研究业界最新的内外网渗透测试技术及方法，完成Beta测试及实际应用；

3、针对现有渗透测试工具提出改进意见，为工具开发人员提供理论支持。


任职要求：

1、熟悉常见的外网渗透测试的漏洞原理及利用方法(参考OWASP TOP 10)；

2、熟悉常见的内网渗透测试的思路及方法；

3、熟练使用常见的外网渗透测试基础工具(如Burpsuite,nmap,sqlmap)；

4、熟练使用常见的内网渗透测试基础工具(如MSF,empire)；


 加分项：

1、熟悉C,C++,Golang等一种或多种编译型语言，熟悉Python，Ruby等一种或多种解释型语言；

2、拥有大型企业内外网完整渗透测试经验，对APT有深入研究或有实践经验；


安全攻防专家

地点 : 北京 30K-50K

职位描述：

1、参与公司产品、内部系统的渗透测试；

2、研究前沿安全技术，分析最新漏洞披露；

3、支撑公司安全应急响应、分析溯源；


岗位要求：

1、对安全相关技术有极大的热情与兴趣，洁身自好，不参与网络黑产、黑客攻击事件；

2、熟悉常见的各类漏洞原理、成因、利用/测试手段、修复/限制方案；

3、至少熟悉一种编程语言，并能进行安全辅助工具的开发。


加分项：

1、精通某一安全细分领域，如：内网渗透、移动安全、通信安全、协议fuzz、代码审计、CTF、应急响应、恶意软件分析等；

2、持有cisp/cissp/ceh/oscp/cisp-pte等安全类证书，有个人CVE/CNNVD漏洞；

3、攻防比赛中获得较好名次，各类安全会议中有演讲经历，英语口语流利；

4、有乙方安全公司工作经验，或甲方大厂安全岗位工作经验。


安全服务技术经理/总监

地点 : 北京 20K-40K

岗位职责：

1. 负责提升安服团队个人技术能力及团队凝聚力，包括但不限于技术指导、技术分享、问题解答、技术考核及团建等；

2. 负责团队内部辅助平台、安全工具及知识库的开发搭建；

3. 负责安服团队交付流程、质量和效率的优化及提升；

4. 负责前沿攻防技术研究，安全领域行业动态追踪。

5. 参与安全服务体系的优化及创新工作；

6. 参与大型或重点客户安全服务项目实施，重点技术问题的攻关。


任职要求：

1. 本科及以上学历，计算机或网络安全相关专业；

2. 具有5年以上乙方安全服务实施经验，3年以上安服团队技术管理经验；

3. 可独立完成大中型企业内外网及移动APP渗透测试，或针对物联网、车联网、工业互联网中一个或多个场景的设备进行渗透测试，且有良好成绩；

4. 熟悉各类安全服务业务（包括但不限于渗透测试、风险评估、合规审计、代码审计、应急响应、安全运维、安全重保等）服务内容及流程；

5. 熟悉渗透测试流程，掌握常见漏洞（不限于OWASP Top10）原理、挖掘技巧及利用手段等；

6. 熟练掌握一门常见编程语言，有编程经验；

7. 自驱性强，逻辑分析能力强，具有良好的沟通、协调、组织能力和文档编写能力。


加分项：

1. 熟悉移动APP、物联网方向渗透测试技术；

2. 在国内外SRC及众测平台提交过高质量漏洞者；

3. 具有CTF比赛经验并且取得较好成绩者；

4. 持有CISP/CISSP/PMP/CISA等安全证书者；


信息技术总监

地点 : 北京 20K-40K

岗位职责：

1、带领区域技术团队负责公司央企/交通行业大客户的售前技术支持工作；

2、负责区域技术团队组建、人员培训、管理考核等日常管理工作；

3、能够把握信息安全行业发展方向，负责区域重点客户、行业客户的技术拓展；

4、通过对区域重点大客户业务需求的理解，深入挖掘大客户的潜在需求，快速设计和构造解决方案；

5、负责区域重点项目管理、跟进，对项目进行统筹、人员分工与协调、质量及风险把控、客户沟通工作；

6、负责大型交流、会议、活动的技术宣讲工作


任职要求：

1、信息安全相关工作经验三年以上，团队管理经验1年以上；

2、擅长编写可研报告、技术方案、项目建议书等各类技术文档；

3、熟悉业界主流安全厂商的产品及核心技术；

4、具备较强的综合分析、组织协调、沟通交流的能力，擅长组织协调跨部门的协同工作，对突发事件有紧急应对能力；

5、有云安全、大数据、态势感知、物联网建设项目经验的工作者优先；

6、具有项目运作、交流策划、技术方案规划等能力；

7、了解等级保护、ISO27001等信息安全标准体系；

8、有公安、网信办、政府、教育等行业信息安全项目售前工作经验者优先；

9、具备大型项目管理经验、CISA、CISP、CISSP、PMP等专业资质证书者优先。
