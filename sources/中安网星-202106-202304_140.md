2021年6月29日，中安网星智域安全产品研究中心监测到安全研究人员在GitHub上公开了Windows Print Spooler权限提升漏洞（CVE-2021-1675）远程代码执行漏洞POC。  

  

01

**漏洞概述**

Print Spooler是打印后台处理程序服务，在Windows系统中用于后台执行打印作业并处理与打印机的交互。该服务对应的进程spoolsv.exe以SYSTEM权限执行，由于其设计中存在的一个严重缺陷，用户可以要求该服务执行任意指定的代码，从而获得权限提升。

  

2021年6月8日，Windows官方发布安全更新，修复了Windows Print Spooler权限提升漏洞（CVE-2021-1675）。

  

2021年6月29日，GitHub上公开了Windows Print Spooler远程代码执行POC。若攻击者所控制的用户在域中，则攻击者可以连接到DC中的Spooler服务，并利用该漏洞在DC中安装恶意的驱动程序，完整的控制整个域环境。

  

中安网星智域安全产品已于2021年6月29日发布漏洞检测规则与修复措施，中安网星提醒使用 Windows AD域用户尽快采取安全措施阻止漏洞攻击。

**修复建议**

1、在DC服务器的服务中暂时禁用 Print Spooler服务。智域产品支持一键检测域控Print Spooler服务是否关闭。

![](../Images/02b668232d4d9eb7647938339d3cab43.png)

  

2、智域产品已经支持该漏洞检测。

![](../Images/f2f68e55a0caa7ccd85b36aa1d61cfb5.png)

  

3、请联系智域安全人员获取最新的完整修复方案。
