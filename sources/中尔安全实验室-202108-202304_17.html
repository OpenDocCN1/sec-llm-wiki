· 1、信息收集简介 ·


1.1

什么是信息收集

信息收集就是指通过各种方式获取所需要的信息，便于在后续更好的开展渗透测试工作。所谓，知己知彼，百战不殆。信息收集的越全面，攻击的面就越广，成功的概率也就越大。

1.2

信息收集的分类

        信息收集主要分为两大类，主动信息收集与被动信息收集。

      主动信息收集：与目标直接进行交互 ，从而获取目标信息，这种方式通常会暴露自身流量信息。

      被动信息收集：不直接与目标主机进行交互，通过搜索引擎或者社会工程的方式间接的去获取目标信息，这种方式收集到的信息通常不全面，但比较隐蔽。


1.3

信息收集需要收集哪些内容

通常拿到一个目标后，新手往往不知道如何开展信息收集，只知道看见登录框就爆破、xss、sql注入一顿乱怼，这种攻击的效率往往很低。在信息收集中主要收集的内容有：

whois
子域名
DNS
真实IP
端口信息
网站架构
企业信息


· 2、信息收集方法 ·



2.1

whois

Whois是一种协议， 简单来说，就是一个用来查询域名是否已经被注册，以及注册域名的详细信息的数据库（如域名所有人、域名注册商、域名注册日期和过期日期等)

常用的收集网站:

http://whois.chinaz.com/

https://www.virustotal.com/gui/home/url

https://who.is/


2.2

子域名挖掘

子域名也就是二级目录，是顶级域名下的域名，当目标网络的规模比较大时，或目标站点无法渗透的情况，可以对目标子域进行渗透最后迂回到真正目标。

举个例子：www.baidu.com

.为根域

baidu为一级域名

www为二级域名


2.2.1子域名收集方法


2.2.1.1子域名收集工具

常用的子域名收集工具有layer、oneforall、DNSenum等等。

layer

layer是一款子域名挖掘工具，支持服务接口，爆破、通服挖掘三种模式，操作方式也简洁方便。

oneforall
oneforall 是一款功能十分强大的子域名收集工具，项目地址https://github.com/shmilylty/OneForAll。支持子域爆破，子域验证，子域爬取，子域爬取，子域置换等。
基本命令格式:python3 oneforall.py --target example.com run
python3 oneforall.py --target baidu.com run 
注：收集结果会保存到软件根目录下的results文件夹下

DNSenum

DNSenmu能够通过谷歌或字典文件猜测可能存在的域名，并对一个网段进行反查询

基本用法：dnsenum -enum baidu.com

2.2.1.2在线网站
在线网站提供集合了很多DNS数据的查询接口，只要在搜索框中输入域名就可以检测到相关的域名信息

https://phpinfo.me/domain

http://dnsdumpster.com

2.2.1.3证书透明度
证书透明度是证书授权机构CA的一个项目，证书授权机构会将每个SSL/TLS证书发布到公共日志中，查找某个域名所属证书的最简单方法就是搜集一些公开的证书透明度日志。

一般使用的查询网站https://crt.sh，直接在搜索处输入域名即可


2.3

DNS

DNS是一种将域名和IP做相互映射的系统，获取域名或者IP地址，并进行反向查找可以快速显示同一服务器承载的所有其他域。

2.3.1 DNS服务器的类型


DNS服务器的类型分为：主服务器、备份服务器、缓冲服务器

2.3.2 DNS的记录类型

A:IP记录地址，将域名解析为IP，正向记录
CNAME:别名记录
MX：邮件服务器查询
PTR:反向记录，将IP解析为域名
TXT：记录域名的相关文本信息

常用的查询网址：

https://viewdns.info/

https://myssl.com/dns_check.html

2.3.3 域传送

域传送（DNSZone Transfer）备份服务器向主服务器拷贝数据并更新自己的数据库，这个操作即为域传送，但是，当DNS配置不当时，导致匿名用户利用DNS域传送获取某个域的所有的记录。其危害有：攻击者获取某个域的所有记录即可得到网络拓扑结构，造成信息泄露。

检测方法：

nslookup//进入交互式shell中
server某个域名
ls域名
exit

2.4真实IP

2.4

真实IP

    在渗透过程中，目标服务器可能只有一个域名，那么如何通过这个域名来确定目标服务器的真实IP对渗透测试来说很重要， 在探测IP的过程中，分为存在CDN和不存在CDN的情况，这里不得不介绍下CDN的概念。

2.4.1 CDN简介

CDN即内容分发网络，主要解决因传输距离和不同的运营商节点造成的网络速度性能低下的问题。简单来说，就是一组在不 同运营商之间的对接节点上的高速缓存服务器，把用户经常访问的静态资源直接缓存到节点服务器上，当用户再次请求时， 会直接分发到在离用户最近的节点服务器上响应给用户。这样可以大大提高网站的响应速度以及用户体验

2.4.2如何判断CDN是否存在


一般我们通过多地ping的方式来验证目标是否存在CDN，在线网址：https://ping.chinaz.com/

如果多个节点ping响应的IP相同则目标可能不存在CDN

如果多个节点ping响应的IP不同则目标存在CDN


2.4.3  不存在CDN探测真实IP


如果目标不能再CDN可以直接通过在线查询的网址去查询:

https://wepcc.com
http://ping.chinaz.om
https://asm.ca.com/en/ping.php

2.4.4 存在CDN探测真实IP


2.4.4.1内部邮箱源
一般的邮件系统在内部，没有经过CDN的解析，通过目标网站用户注册或者RSS订阅功能，查看邮件、寻找邮 件头中的邮件服务器域名IP，ping这个邮件服务器的域名，就可以获取目标的真实IP
2.4.4.2扫描网站测试文件
如phpinfo、test等，从而找到目标的真实IP，平时在做渗透测试的时候，经常会遇到phpinfo这个网页，提供了大量的信息。
System：                    操作系统版本等信息（基础信息）
DOCUMENT_ROOT：网站的绝对路径（对于写shell时很可能有很大的帮助）
SERVER_ADDR：        真实ip，通过这个参数可以得到网站服务器的真实ip无视cdn
allow_url_include：    该项如果开启，则支持远程文件包含，如果有存在文件包含的文件可直接getshell，或可以使用php伪协议
disable_functions        用来查看禁用函数目录
Server API：                 php的应用程序接口

2.4.4.3分站域名
很多网站只有主站挂CDN，但分站可能没挂CDN可以通过ping二级域名获取分站IP，可能主站的IP和分站在同一C段下。
2.4.4.4查询域名解析记录
也许目标很久以前并没有使用过CDN，所以可以通过网站NETCRAFThttps://www.netcraft.com/来 观察域名的IP历史记录，也可以大致分析出目标的真实IP。
2.4.4.5绕过CloudFlare
现在很多网站都使用CloudFlare提供的CDN服务，在确定了目标网站使用了CDN后，可 以先尝试通过在线网站http://www.crimeflare.us/cfs.html#box对CloudFlare客户网站进行真实IP查询。

2.5

端口信息

获取到IP后我们就可以探测端口信息了，收集端口信息可以快速收集目标资产，找到系统的其他功能站点。

2.5.1 Nmap

使用Nmap收集端口信息是最常用的方式。

基本命令格式：nmap 参数 IP/IP段/主机名
nmap -sS -Pn -O 192.168.10.248
-sSSYN扫描
-Pn 无ping扫描
-O显示OS信息


2.5.2 在线探测端口


在线端口扫描工具的好处是可以隐藏自身流量，减少本地资源的使用。

https://www.t1shopper.com/tools/port-scan/


2.6

Google Hacking

借助于Google强大的搜索引擎去进行信息收集、目标探测、踩点等工作，可以极大提高渗透测试工作的效率。

2.6.1 基本语法


intext：查询网页正文中包含关键词的网站
intitle：返回网站标题中含有关键词的网站
cache：搜索 google 里关于某些内容的缓存
define：查询某些词语的定义
filetype：搜索指定类型的文件  doc pdf bak zip mdb inc config.inc
info：查找指定站点的信息
inurl：在 URL中寻找我们指定的关键信息 inurl:admin.php login.php
link：返回所有和目标做了链接的URL
site：返回和目标有关（子域名）的所有URL
+扩大搜索范围
-忽略某些关键词
~同义词
.单一的通配符   admi..php
*多个字符的通配符    admin*php
“”精准匹配

2.6.2 一些技巧


查找后台地址：site:域名 inurl:login|admin|manage|member|admin_login|login_admin|system|login|user|main|cms

查找文本内容: site:域名intext:管理|后台|登陆|用户名|密码|验证码|系统|账号|admin|login|sys|managetem|password|username

查找可注入点：site:域名  inurl:aspx|jsp|php|asp

查找上传漏洞:site:域名 inurl:ewebeditor|editor|uploadfile|eweb|edit

查找存在的备份文件:site:域名 filetype:bak|zip|rar

查看脚本类型:site:域名 filetype:asp|aspx|php|jsp

2.8

网站架构信息

在渗透过程中需要探测目标站点网站架构包括以下信息：操作系统，中间件，脚本语言，数据库，服务器，web容器等 等，可以使用以下方法查询。

2.8.1 Wappalyzer


一款浏览器插件，主流的浏览器应用都支持该插件，可以分析目标网站的平台架构、网站环境、服务器配置环境、编程语言等等


2.8.2  潮汐指纹识别


由Tide安全团队开发，用于快速了解网站架构

http://finger.tidesec.net/


2.8.3 企业信息


一些网站如天眼查、企查查、企信通(微信小程序)等，可以提供企业关系挖掘、工商信息、商标专利、企业年报，历史沿革，股东及出资信息，网站门户等信息。

在线网站：

https://www.tianyancha.com

https://www.qcc.com/


· 3、总结  ·



本文的内容来源于平时的一些笔记总结，信息收集的方式不仅仅局限于本文提供的一些方法，没有任何一种方法可以做到收集的信息很全面，更重要的是得有自己的一套信息收集思路和对信息的敏感度。对于收集到的庞杂信息，要善于去找出其中的关联性，才能更好的开展渗透测试。
