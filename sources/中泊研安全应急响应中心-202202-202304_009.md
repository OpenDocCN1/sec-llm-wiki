# CouchDB垂直越权漏洞复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NDc0MjUxMw==&mid=2247484903&idx=1&sn=da7781dea0285b80cdc22655f9257237&chksm=ce65f8f9f91271ef596146edf57cd070923f6dd872746d48e288b82ea98a493993ad5372ba06&scene=126&sessionid=1681381620#rd](http://mp.weixin.qq.com/s?__biz=Mzg2NDc0MjUxMw==&mid=2247484903&idx=1&sn=da7781dea0285b80cdc22655f9257237&chksm=ce65f8f9f91271ef596146edf57cd070923f6dd872746d48e288b82ea98a493993ad5372ba06&scene=126&sessionid=1681381620#rd)

1 漏洞介绍

Apache CouchDB是一个开源数据库，专注于易用性和成为“完全拥抱web的数据库”，是一个使用JSON作为存储格式，JavaScript作为查询语言，MapReduce和HTTP作为API的NoSQL数据库。

![](../Images/cde71c83b971ef9ac1693aae970af33c.png)

导致漏洞的原因是Erlang和JavaScript，对JSON解析方式的不同，对于重复的键Erlang会存储两个值，而JavaScript只存储第二个值。

2 影响版本  

Apache CouchDB< 1.7.0 和 Apache CouchDB< 2.1.1

3 漏洞复现  

(1)环境启动后，查看环境端口号

![](../Images/ebdf7db7f6cc1e630accd4ab65ebca58.png)

（2）通过端口号进入环境中，得到环境版本号

![](../Images/e2fe07a5d1a2e645a11b1392041c8d24.png)

（3）Couchdb成功启动，但无账号密码  

![](../Images/92ed42dd888d9faeb4f44bf3b01efe7d.png)

（4）通过burp抓包，发送包含两个roles的数据包，绕过限制

![](../Images/637001450b9acefd5b40801ae0910c2b.png)

（5）绕过限制后得到账号密码，登录成功

![](../Images/800a741e4a15f25d3e311e5d4147e608.png)

漏洞修复建议

（1）建议Apache CouchDB升级到最新版本（2）建议加强密码强度，密码使用特殊字符、大小写字母和数字，防止被暴力破解。
