# Windows域提权漏洞分析与复现

漏洞描述

Active Directory 域权限提升漏洞 允许低权限用户在安装了 Active Directory 证书服务 (AD CS) 服务器角色的默认 Active Directory 环境中将权限提升到域管理员。

漏洞影响范围

Windows 8.1,11

Windows 10 Version 1607, 1809,1909, 2004, 20H2, 21H1, 21H

Windows Server 2008，2012，2016，2019，2022

漏洞复现  

（1）修改host文件，搭建域控和域控证书服务

![](../Images/eabb79e9a8601a7f4e80127bf2a4260e.png)

（2）使用工具：Certipy ,下载地址：https://github.com/ly4k/Certipy

验证证书是否有效，获取哈希值  

![](../Images/2649a3e27ec89def96e612756ada1e77.png)

（3）创建机器账户

![](../Images/a2a3d0cefad8aa7640b1c60385ac8c5e.png)

（4）机器账户获得证书

![](../Images/80cfc5bcf384abaa4e75b03c0963209e.png)

（5）通过证书获得hash

![](../Images/4b925b5cd95f763f252aceba2c8c22bc.png)

（6）利用主机的hash来dump全部的hash

![](../Images/7a4f324f82a2e5a4a18be2ec514d2a54.png)

（7）成功获取Administrator的hash后，利用wmiexec利用此hash成功提权

![](../Images/6f6df4bd2ba85918db95258e5cc8be8d.png)

漏洞修复  

（1）补丁地址：https://msrc.microsoft.com/update-guide/vulnerability/CVE-2022-26923

（2）关闭ADCS服务

（3）设置权限，只允许你有“验证写入DNS主机名“权限。

（4）确保证书模板受到限制，只在需要时才允许机器和用户自动注册。
