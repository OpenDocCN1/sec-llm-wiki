# DDos攻击导致意大利政府网站瘫痪

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NDc0MjUxMw==&mid=2247484540&idx=1&sn=81c421d2c023f374684a1c00896cbf8e&chksm=ce65f962f9127074666c237ca69814cb380361d3e48c0f7f5655ba8527263322a415246ed8f2&scene=126&sessionid=1681381688#rd](http://mp.weixin.qq.com/s?__biz=Mzg2NDc0MjUxMw==&mid=2247484540&idx=1&sn=81c421d2c023f374684a1c00896cbf8e&chksm=ce65f962f9127074666c237ca69814cb380361d3e48c0f7f5655ba8527263322a415246ed8f2&scene=126&sessionid=1681381688#rd)

据意大利报社称，意大利多个网站遭受黑客的DDos攻击，导致网站瘫痪，其中就有意大利参议院、上议院、卫生院和国防部等。![](../Images/0774e9d142fae909f98d70a4f63064c8.png)分布式拒绝服务攻击(DDoS)是指处于不同位置的多个攻击者同时向一个或数个目标发动攻击，或者一个攻击者控制了位于不同位置的多台机器并利用这些机器对受害者同时实施攻击,旨在耗尽服务器的可用资源，使其无法响应合法用户请求并使其托管的站点无法正常访问。![](../Images/6ae42b6c1e8b2a96af0667a8fe9d9c55.png)亲俄黑客团伙 Killnet 声称对本次攻击负责。此前，他们还曾先后对罗马尼亚门户网站、美国布拉德利国际机场发动过类似攻击。  
意大利计算机安全事件响应小组称，此次攻击利用了 " 慢速 HTTP" 技术。![](../Images/00fee458db7acc7cf3b77618fd0ccde3.png)" 对于自 5 月 11 日起发现的这几次针对国内及国际目标的 DDoS 攻击，我们发现其不同于常规的 1 类容量耗尽攻击。由于实际占用的带宽较为有限，因此无法利用市面上常用的保护系统加以抵御。" —— CSIRTHTTP-FLOOD 攻击是一种专门针对于 Web 的应用层 FLOOD 攻击，攻击者操纵网络上的肉鸡，对目标 Web 服务器进行海量 http request 攻击，直到服务器带宽被打满，造成了拒绝服务。![](../Images/5f5205fed3ecbc348f4d6419a546364f.png)慢速 HTTP 拒绝服务攻击则是 HTTP-FLOOD 攻击的其中一种，利用 HTTP 现有合法机制，在建立了与 HTTP 服务器的连接后，尽量长时间保持该连接，不释放，那么服务器上可用的连接将一点一点被占满，从而导致拒绝服务。![](../Images/8a0e26c5769b41004e0883e944b6cf02.png)随着科技的不断发展，大量IOT设备和IDC服务因系统漏洞、配置错误或人为误操作等原因沦为肉鸡，导致DDos攻击越来越多。  
每年在重要会议或者重要节日时，各种网络攻击层出不穷。如：疫情期间，全国各地的健康码都遭受过DDos攻击，导致健康码打不开。![](../Images/c11a3cdb06d8cf305ea2af1a5664e42f.png)
