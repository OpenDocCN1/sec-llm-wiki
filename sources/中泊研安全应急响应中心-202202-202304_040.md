# mysql身份认证绕过漏洞复现

**漏洞介绍**

当连接 MariaDB/MySQL 时，输入的密码会与期望的正确密码比较，由于不正确的处理，会导致即便是 memcmp () 返回一个非零值，也会使 MySQL 认为两个密码是相同的。也就是说只要知道用户名，不断尝试就能够直接登入 SQL 数据库。

**漏洞影响版本**  

MariaDB   版本5.1.62, 5.2.12, 5.3.6, 5.5.23

MySQL     版本5.1.63, 5.5.24, 5.6.6
