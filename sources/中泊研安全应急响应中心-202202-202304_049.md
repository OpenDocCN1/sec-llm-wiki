# 整数溢出(CVE-2017-7529)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NDc0MjUxMw==&mid=2247484446&idx=1&sn=ce8bd5a824bdeaefc923bbfae90086ef&chksm=ce65f900f9127016ff7635d374c1eff5fa329d80f018ad042d71dd98d9ba90b3ef8c9ab9b36c&scene=126&sessionid=1681381693#rd](http://mp.weixin.qq.com/s?__biz=Mzg2NDc0MjUxMw==&mid=2247484446&idx=1&sn=ce8bd5a824bdeaefc923bbfae90086ef&chksm=ce65f900f9127016ff7635d374c1eff5fa329d80f018ad042d71dd98d9ba90b3ef8c9ab9b36c&scene=126&sessionid=1681381693#rd)

漏洞介绍  

在Nginx的range filter中存在整数溢出漏洞，可以通过带有特殊构造的range的HTTP头的恶意请求引发这个整数溢出漏洞，并导致信息泄露。

漏洞影响版本

```
Nginx 0.5.6 – 1.13.2
```

漏洞修复  

建议升级到 1.13.3 和 1.12.1 版本；如果不能升级，可以在 Nginx 配置文件中添加 max\_ranges 1，从而禁用 multipart range。
