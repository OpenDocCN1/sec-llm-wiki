# 任天堂Switch曝光

任天堂Switch，简称NS，是任天堂公司于2017年3月发布的主机，采用家用机、掌机一体化设计。Switch主机销量突破1亿354万台，游戏软件销量突破7亿6641万份。为任天堂销量最高的游戏主机。

![](../Images/0ea0505ee30dbfacced618c4d2dd848f.png)

南美黑客组织号称入侵了NVIDIA服务器长达一周，获取了大约1TB的机密数据，并公开叫卖RTX 30系列显卡的挖矿限制破解算法，还要求NVIDIA全面解除限制。NVIDIA一直未回应，南美黑客组织便公开了一个18.8GB RAR压缩包，解压后多达75GB，包含超过40多万个文件。内容大多数都是被视为高度机密的源代码。

![](../Images/c23bf6f0522c0658c0160dfaa2eacc51.png)

文件中还有一个NVN2的目录（注：NVN就是NV专门为任天堂Switch编写的API）。其中显示，新款Switch游戏主机使用NVIDIA的Ampere GPU，支持光线追踪和 DLSS 2.2。T234 SOC被认为具有2048安培GPU CUDA核心和12x ARM Cortex-A78AE（Hercules）64位核心。  

![](../Images/dc5407f1d5514d3cee9ab8dea7056569.png)

此外，任天堂官方推迟《塞尔达：荒野之息2》发售日时，放出的新预告片，相比之前看起来更加清晰，画质也更出色，显然这是现在Switch不能做到的。这意味着新一代Switch已经离我们不远了。
