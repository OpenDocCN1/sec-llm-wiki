# 中睿天下入选安全牛网络安全行业全景图9项能力图谱！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNjc0MDA1NA==&mid=2650138416&idx=1&sn=0098031ebda13357f5649b5736c23493&chksm=83098609b47e0f1fa2745365796201cd4f7c9b83d4952c3bbc61438027c4f35d342f854e71fc&scene=126&sessionid=1681376493#rd](http://mp.weixin.qq.com/s?__biz=MzAwNjc0MDA1NA==&mid=2650138416&idx=1&sn=0098031ebda13357f5649b5736c23493&chksm=83098609b47e0f1fa2745365796201cd4f7c9b83d4952c3bbc61438027c4f35d342f854e71fc&scene=126&sessionid=1681376493#rd)

2023年4月7日上午，网安行业内专业咨询机构安全牛发布了**《网络安全行业全景图》**（2023年4月第十版），受到了行业的广泛关注与一致认可。

  

中睿天下凭借强大的技术实力与创新能力、突出的行业优势及出色的市场表现，成功入选**流量监测与分析、主机安全、邮件安全、态势感知（运营类）、XDR、安全咨询与规划、安全运维与托管服务、渗透测试、攻防演练**等9项能力图谱，再次彰显了联软强大的综合发展实力！

此次发布的全景图共分为15个一级安全分类，107个二级细分领域，共涉及456家国内网络安全企业和相关行业机构，全面展现中国网络安全行业的应用发展与变革创新。

  

安全牛研究团队主要从以下两个维度对企业申报申请进行考量：一是产品需企业自主拥有，可实际交付，并具备一定应用特点和技术优势，二是产品需经过实际应用的验证，有较成熟的市场应用。安全牛方面表示，安全牛全景图报告收录时不涉及细分领域中各企业的排名或比较，企业展现位置与实际产品能力无直接关联性。

  

中睿天下连续多年上榜安全牛网络安全榜单，此次入选安全牛全景图9项能力图谱，是行业以及市场对中睿天下强大实力的再度认可，展现了中睿天下在多个安全细分领域的强大实力及优势。

  

中睿天下成立于2014年，是以“**实战对抗**”为特点的能力价值型网络安全厂商，先后入选北京 **“专精特新” 中小企业、小巨人企业，福布斯中国“中国企业科技50强”、企业服务最具投资价值TOP30**等荣誉。

  

区别于传统防护理念，创新性提出网络“**攻击溯源**”理念。基于此技术理念研发的睿眼、睿云等系列产品及解决方案，深度契合网络安全运营中的强需求，有效解决网络安全运营中的实战对抗问题，得到客户的广泛应用及认可。截至目前，中睿天下已服务数百家行业客户，覆盖**政府、能源、金融、国防、电信、交通、教育、医疗、互联网**等重点行业。
