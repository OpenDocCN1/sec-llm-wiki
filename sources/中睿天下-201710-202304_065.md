# 您的意见很重要 让我们听到您的声音——2022网民网络安全感满意度调查活动全国火热进行

为客观、全面了解网民对我国网络安全状况的感受与看法，向国家有关部门开展互联网监管和治理提供民意支撑，**2022网民网络安全感满意度调查活动于8月3日至8月12日24时，正式面向广大网民采集意见**。活动**由全国135家网络安全行业协会与相关社会组织共同发起**，已成功举办四届，是国内目前**调查范围最广、参与人数最多的全国性大型公益网络社会调查活动，中睿天下作为****攻击溯源领域的领导者和网络安全领域的创新者，也将积极参与到此次活动中来。**活动自2018年开展以来，坚守公益初心，面向广大网民和网络从业人员，一步一个脚印，一年一个台阶，四年**累积收集472万份答卷和44.6万余条建议意见，形成487份专业调查报告**，反映全国网民网络满意度指数逐年上升。今年调查问卷设置**13个专题**，重点在**网络安全惩治犯罪、法治建设、诚信建设、权益保护、数字服务**等领域开展调研，强化对**网络诈骗、网络黑灰产治理、打击水军、维护公平、网络暴力防控**等问题的调查，紧跟时代脉搏，聚焦民生热点，为调查数据采集和分析研究打下良好基础。问卷类型分“**公众网民版**”和“**网络从业人员版**”，为了让数据更真实有效，请您选择适合自己的问卷类型参与调查（鼓励网络从业人员填写两套卷子）。点击以下链接入口或扫描、长按识别二维码即可填写：**公众网民版链接**：https://www.wjx.cn/vm/OI6W9IA.aspx?udsid=329792**从业人员版链接**：https://www.wjx.cn/vm/eSlHa5o.aspx?udsid=267138
