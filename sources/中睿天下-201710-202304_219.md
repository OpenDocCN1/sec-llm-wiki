# 中睿天下入选《CCSIP 2020中国网络安全产业全景图》15大领域

近日，Freebuf咨询正式发布《CCSIP（China Cyber Security Industry Panorama）2020中国网络安全产业全景图》，共计涵盖19个一级分类，79个二级分类。中睿天下入选其中**9个一级分类，15个二级分类，包括****计算环境安全（邮件安全）、应用防护（web应用扫描与监控）、内容安全（恶意内容检测、钓鱼监测）、威胁检测与捕获（IDPS、APT高级威胁检测/恶意软件检测沙箱）、漏洞检测与管理（漏洞管理、漏洞检测）、安全情报（威胁情报）、事件管理&响应（SOC、SIEM、UEBA）、调查取证、安全服务（安全咨询与培训教育、攻防演练）等****。**![](../Images/1f6b1d0870ae6cdd5b2dcafe9af92c8f.png)全景图厂商logo排名不分先后出品方：FreeBuf咨询  
![](../Images/d678b79e92de35fde409716598724836.png)![](../Images/98f65e74c410bcddb67917ee2ebdc6e3.png)![](../Images/183d99b5c3e533b5e8f71c43ee713624.png)CCSIP全景图以PDR网络安全模型为基础，并参考IPDRR安全框架和P2DR2模型，在基础的Protection(防护)、Detection（检测）、Response（响应）三层逻辑上优化出第4层，即“持续改进”，形成“防护——检测——响应——持续改进”的安全闭环。在核心模型之外，增加了网络基础安全与行业场景2个大类，构建完整的企业网络安全建设链，以此作为CCSIP全景图的顶层设计逻辑，并将市面上主流的网络安全厂商以主要产品类型为依据进行归类。CCSIP全景图，旨在为企业安全建设产品选型提供参考。  
**研究方法**

*   问卷调查：通过问卷调查的形式获取多家企业的安全产品以及相应的自评信息，作为基础参考信息。
    
*   权威参考：参考国内外网络安全领域的各类奖项、Gartner魔力象限以及专业机构发布的权威报告等，积累国内安全厂商和安全产品相关信息的数据库。
    
*   专家分析：由FreeBuf咨询团队、市场分析师、安全专家组成专业的评审团队，对安全厂商进行归类与评审。
