# 中睿天下入围“漏洞挖掘最具影响力奖”

12月8日，“2018年度中国网络安全十大影响力品牌：真观奖”（TVA, True Views Award）评选活动，在北京落下帷幕。本次评选活动有四大特性：

*   公益：组织者不从中赚取任何经济利益。
    
*   专业：安全企业市场、安全专家、安全媒体人等参与投票。
    
*   真实：每家企业仅一人具备投票权，没有水军，没有刷票。
    
*   公平：投票前候选企业名单未知，投票后现场出投票结果。
    

中睿天下副总经理谢辉受邀参与了本次评选活动，同时现场首次公开“漏洞挖掘最具影响力奖”十大候选名单，中睿天下入选。

据安全牛主编李少鹏介绍，“漏洞挖掘最具影响力奖”入围标准为企业的技术实力，漏洞提交的数量和重要程度。
