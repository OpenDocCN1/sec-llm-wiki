# 携智慧能源安全解决方案，中睿天下亮相中国能源企业信息化大会

**让能源更智慧**

10月19日，以“思极，让能源更智慧”为主题，国网信通产业集团与中国信息协会联合主办的第八届中国能源企业信息化大会在北京召开。

来自**政府主管部门，电力、石油、煤炭、新能源等能源企业**，行业机构、科研院校和信息技术企业共计600余人参加了会议。

工信部软件司司长谢少锋、国家能源局信息中心主任梁建勇、国家电网有限公司信息通信部副主任王磊等出席了会议。作为信息安全领域的创新企业，中睿天下也受邀出席了本次会议。

![](../Images/4b9efc6789058e26ea35ba24051ac355.png)

**聚焦能源安全**

随着互联网与能源生产、传输、存储、消费及能源市场深度融合，“互联网+”智慧能源已成为未来能源发展的方向。

作为国家重要战略资源，能源行业关系国家安全和国民经济命脉，是网络安全的重中之重，也是可能遭到重点攻击的目标。而BlackEnergy攻击乌克兰电力系统等事件更是给能源行业网络安全敲响了警钟。

**如何提升能源互联网网络和信息安全事件监测、预警和应急处置能力，确保能源互联网安全可靠运行？**中睿天下用“攻击溯源一体化安全解决方案”给出了创新的答案。

![](../Images/2a64f7ed3ed2d862465ee6a5363b5718.png)

**攻击溯源 精准防护**

**智慧能源安全解决方案是使用「攻击溯源」技术构建的新一代威胁监测体系。**

“没有意识到风险是最大的风险。”**基于攻击者视角，智慧能源安全解决方案通过网络访问关系及主机操作行为，融合技术与业务逻辑关系，帮助能源企业实现已知/未知威胁发现及攻击追溯，同时解决黑客“从哪来”、“做了什么”、“去了哪里”等问题**。

当前，攻击溯源一体化安全解决方案，已成功**覆盖国家电网总部、27个网省公司和国网直属单位，并纳入国家电网常态化监控体系**。
