# 中睿天下加入PCSA行业云安全能力者联盟

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNjc0MDA1NA==&mid=2650128721&idx=1&sn=0dbbcb1d91fff0d15c572667325d2a0b&chksm=8309a068b47e297e9c1f014e95aaa94fa1519c6f02e0c6abf15a4d98aa4ef3d3882aed083cbe&scene=126&sessionid=1681376714#rd](http://mp.weixin.qq.com/s?__biz=MzAwNjc0MDA1NA==&mid=2650128721&idx=1&sn=0dbbcb1d91fff0d15c572667325d2a0b&chksm=8309a068b47e297e9c1f014e95aaa94fa1519c6f02e0c6abf15a4d98aa4ef3d3882aed083cbe&scene=126&sessionid=1681376714#rd)

近日，中睿天下正式加入**PCSA行业云安全能力者联盟。**

![](../Images/38562041d44f4b6fd8512ec1a990f630.png)

当前，私有云、政务云、行业云、公有云、混合云等逐渐替代传统网络架构，云化成为主流。行业云安全能力者联盟（PCSA）应势而生，承载着等级保护2.0标准研究与实验室验证，配合行业云平台做等级保护2.0落地验证和云安全关键技术研究、应用、推广的责任，为国家关键基础设施、重要公共服务等行业的云安全建设，提供有效、可用的云安全落地**。**

自成立以来，联盟一直致力于**云安全关键技术、产品、解决方案及标准的研究**、应用和落地推广，为行业云建设提供安全咨询和解决方案。PCSA联盟成员均是目前**国内云安全的集大成者**，涵盖了信息安全领域的专业研究机构、测评机构、IT（安全）服务商、云安全产品及服务商、云平台产品及服务商和专业媒体。

![](../Images/bd62495f75560f2e0aeb9484e003913a.png)

当前，PCSA联盟凝聚联盟成员力量形成**《行业云安全共性解决方案》**，包含1个安全PaaS平台（“银河”云安全PaaS平台）、2个安全体系（租户+平台）、3道安全防线（边界+通道+计算）和4种安全能力**（检测+响应+预防+预测）**。其中：

*   “银河”云安全PaaS平台，历经多版本迭代测试，目前已完成与**国信政务云、北京市政务云等五朵云**的对接和联调，并进入试运行阶段。
    
*   网络安全**态势感知**预警通报平台，汇聚了多家联盟成员的关键安全能力，实现了网络安全态势的实时感知与呈现，适用于城市级、行业级、企业级等不同规模的网络安全态势感知平台建设项目。
    

2017年PCSA联盟累计合作金额超过**1亿元**，项目涵盖了**公安、电力、运营商、交通、党政**等领域。

![](../Images/0c10d928326d12acd8b243a52f51a795.png)

历来，PCSA联盟对成员单位的审核非常严格。每一个成员单位需要经过深入的沟通、严格的审核以及安全能力的确认才得以加入。

  

此次中睿天下凭借自主研发的“睿眼”攻击溯源系统，以优异的**威胁发现与溯源分析能力**，顺利通过审核，正式加入PCSA联盟。

  

作为全球率先把“攻击溯源”技术应用于网络安全防护的公司，中睿天下自主创新研发出以**“攻击溯源”**为核心的解决方案，凭借超强的**威胁发现能力、**智能研判能力**和还原溯源能力**，解决了传统安全产品存在的**“检测率低、误报率高、效率低”**等问题，帮助用户基于攻击溯源，知己知彼，实现**精准防护**。

   

而早在2016年，中睿天下就受中国信息通信研究院邀请，参与关于**云安全标准的制定**。

  

汇聚行业力量，未来中睿天下希望为更多的国家重要信息基础设施安全赋能。
