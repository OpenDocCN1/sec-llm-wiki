# 培训丨中睿受邀参加国家电网安全培训，主讲「威胁追踪」

**国家电网 攻防培训**

![](../Images/da0fcc25329b5f43866d398dab9e4d69.png)![](../Images/7e9f8bb873e931f90059f8a5f1ddfe2f.png)![](../Images/e77facad0671d1d186b0ba82d2862ba9.png)

2017年11月底，由国家电网信通公司举办的「**网络与信息安全攻防技能提升培训班**」在北京召开，培训旨在提升国家电网公司整体攻防技术水平。

  

本次培训主要针对信息安全领域常见的攻防手段，如**漏洞利用、攻击溯源**等，展开理论和实操教学。国家电网公司下属的十余家网省分公司网络安全团队骨干从全国各地赶赴北京，参加培训学习。

![](../Images/21a6550830db579cd76f37a0f5e9aaa4.png)

▲  攻防培训课程安排  

  

因为中睿天下长年专注于「**威胁追踪**」，全球首创把「威胁追踪」技术应用于网络安全整体解决方案，所以这次中睿天下主讲内容围绕**“攻击溯源”、“电子取证”、“后门分析”、“威胁研判”**等展开。

 

中睿天下资深安全专家白应东、李微著等，根据近十年一线攻防的实战经验，结合近期最新的网络安全事件，分别为中、高级培训班学员带来如何识别恶意代码，研判和分析攻击行为，并对攻击者进行溯源与取证等技术的深度解读。

![](../Images/dc7235275faddda0f4ecef5580909c9b.png)

▲攻防培训现场

  

电网作为国家关键基础设施，承载整个国家电力能源的传输配送，其安全运营关乎国计民生。在2016年4月19日网络安全和信息化工作座谈会上，习近平主席特别强调“金融、能源、**电力**、通信、交通等领域的关键信息基础设施是经济社会运行的神经中枢，**是网络安全的重中之重**，也是**可能遭到重点攻击的目标**。”

  

而国家电网在**世界500强**中**排名第二**（数据来源于美国《财富》杂志发布最新一期世界500强排行榜），其信息化和信息安全建设在中国央企中保持着领先水平。

![](../Images/048ba1eae601b574556590843dad66f4.png)

▲ 世界500强排名  图片来自美国财富杂志

  

早在2015年初，中睿天下便开始与国家电网合作，为其提供网络安全保障。中睿天下「睿眼」系列产品凭借**强大的威胁检测**及**攻击追踪溯源**等功能，在各类重大活动保障和对抗中为国家电网公司屡立战功。

 

11月底的北京已是风疾气冷，寒意逼人，但国家电网的会议室里，攻防培训正热火朝天。
