0x01 原由

    关于为啥小CV重复造轮子，写了FOFA的客户端。主要是小CV最近下定决心要学Go，然后买了一本Go黑帽子。于是，开启了Go开发学习的辛酸之旅，昨天正好看到了第三章用Go的http库去连接shodan，获取shodan的API库，看完第三章，小CV忍不住手痒，于是写了一个FOFA的客户端，写完确实也有很多收获，明天来解析一下小CV写的代码，今天还是说一下FOFAu工具的使用。

0x02 使用说明——初始化

    使用命令行打开，在FOFA官网登录账号查看邮箱和API KEY

    在本工具初始化界面进行输入，最后初始化完成    

0x03 使用说明——语法

 -h

参数h: 查看帮助信息

 -f string        

        参数f：获取指定队列名，默认ip,host,port (default "ip,host,port")  

-p string

       参数p：结果保存位置以及文件名，默认本文件夹，如：./xxxx (default "_年_月_日_时_分_秒")  

-q string

       参数q：搜索内容，默认为空（必填项）  

-s string

       参数s：获取搜索的数量，默认为100条，最大为10000条 (default "100")  

-sv string

       参数sv：搜索结果保存，默认开启 (default "up")
