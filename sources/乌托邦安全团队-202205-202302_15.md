**0x01 原由  
**

**0x03 使用说明——语法**

  \-h

 参数h: 查看帮助信息

  \-f string        

        参数f：获取指定队列名，默认ip,host,port (default "ip,host,port")  

\-p string

        参数p：结果保存位置以及文件名，默认本文件夹，如：./xxxx (default "\_年\_月\_日\_时\_分\_秒")  

\-q string

        参数q：搜索内容，默认为空（必填项）  

\-s string

        参数s：获取搜索的数量，默认为100条，最大为10000条 (default "100")  

\-sv string

        参数sv：搜索结果保存，默认开启 (default "up")
