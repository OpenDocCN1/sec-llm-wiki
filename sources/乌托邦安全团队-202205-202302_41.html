0x02 字段分析

  • Magic：此字段描述了文件的状态，有以下值：

通过观察二进制文件的值为0x010B可知该文件是一个32位可执行文件。

  • MajorLinkerVersion：链接器的主要版本号，大小为1个字节，该文件的主要版本号为0x05。

  • MinorLinkerVersion：链接器的次要版本号，大小为1个字节，该文件的主要版本号为0x0C。

  • SizeOfCode：代码段的大小（以字节为单位），如果有多个代码段，则为所有此类段的总和。

该文件代码段的大小为0x00000400字节，转换为十进制是1024byte。

  • SizeOfInitializedData：初始化数据节的大小（以字节为单位），如果有多个初始化数据节，则为所有此类节的总和，该文件的初始化数据节的大小为0x00000A00字节，转换为十进制为2,560字节。

  • SizeOfUninitializedData：未初始化数据节的大小（字节），如果有多个未初始化数据节，则为所有此类节的总和，为0。

  • AddressOfEntryPoint：指向入口点函数的指针，即EP指针的相对地址，相对于映像基址。对于可执行文件，这是起始地址。对于设备驱动程序，这是初始化函数的地址。入口点功能对于DLL是可选的。当不存在入口点时，此成员为零，该文件的的EP指针偏移地址为0x1000。

  • BaseOfCode：指向代码段开头的指针，该文件代码段的偏移地址为0x1000。

  • BaseOfData：指向数据段开头的指针，该文件数据段的偏移地址为0x2000。

  • ImageBase：文件加载到内存中时的第一个字节的首选地址，即文件的基地址。该值是64K字节的倍数。DLL的默认值为0x10000000。应用程序的默认值为0x00400000，但Windows CE上的默认值为0x00010000。该文件的基地址为0x00400000。

  • SectionAlignment：加载到内存中的节的对齐方式，以字节为单位，即段在内存中的最小单位。此值必须大于或等于FileAlignment成员，默认值是系统的页面大小。该文件的值为0x100字节。

  • FileAlignment：文件中各节原始数据的对齐方式，以字节为单位，即段在磁盘文件中的最小单位。该值应为512和64K（包括512和64K）之间的2的幂。默认值为512。如果SectionAlignment成员小于系统页面大小，则该成员必须与SectionAlignment相同。该文件的值为0x200字节，转换为十进制为512字节。

  • MajorOperatingSystemVersion：所需操作系统的主要版本号。

  • MinorOperatingSystemVersion：所需操作系统的次要版本号，分析上图该文件的主要版本号为0x04，次要版本号为0x00。

  • MajorImageVersion：文件的主要版本号。

  • MinorImageVersion：文件的次要版本号，该文件的主要版本为0x00，次要版本号为0x00。

  • MajorSubsystemVersion：子系统的主要版本号。

  • MinorSubsystemVersion：子系统的次要版本号，该文件子系统主要版本号为0x04，次要版本号为0x00。

  • Win32VersionValue：此成员是保留成员，必须为0，该文件中此数值为0。

  • SizeOfImage：文件的大小，以字节为单位，包括所有标头，必须是SectionAlignment的倍数。该文件的大小为0x500字节，即1,280字节=1KB。

  • SizeOfHeaders：这个PE头的大小，包含了DOS头的e_lfanew成员、4字节签名、PE文件头大小、可选头大小以及所有节的头部大小，该文件的头大小为0x4000。

  • CheckSum：文件校验和。加载时验证以下文件：所有驱动程序、启动时加载的任何DLL以及加载到关键系统进程中的任何DLL。该文件的校验和为0x0000B499。

  • Subsystem：运行此文件所需的子系统。定义了以下值。

该文件的值为0x0002，即该文件是一个Windows图像化界面（GUI）。

  • DllCharacteristics：文件的DLL特征。定义了以下值。

同样适用转换为二进制的方法一一对应查看所具备的特征，该文件的DLL特征值为0x0000，即该文件不存在任何DLL特征。

  • SizeOfStackReserve：要为栈保留的字节数。加载时仅提交SizeOfStackCommit成员指定的内存；在达到此保留大小之前，其余部分将一次提供一页。该文件的栈保留大小为0x10000字节。

  • SizeOfStackCommit：要提交栈的字节数，该文件要提交的栈字节数为0x100字节。

  • SizeOfHeapReserve：为本地堆保留的字节数。加载时仅提交SizeOfHeapCommit成员指定的内存；在达到此保留大小之前，其余部分将一次提供一页。该文件需要为本地堆保留的字节数为0x10000字节。

  • SizeOfHeapCommit：要提交本地堆的字节数，该文件要提交的堆字节数为0x100字节。

  • LoaderFlags：这是一个被废弃的字段，可以不用考虑。

  • NumberOfRvaAndSizes：可选头其余部分中的目录条目数。每个条目描述一个位置和大小。该文件的目录条目数为0x01。

  • DataDirectory：指向数据目录中第一个IMAGE_DATA_DIRECTORY 结构的指针，DataDirectory是一个IMAGE_DATA_DIRECTORY 结构体，字段如下：

typedef struct _IMAGE_DATA_DIRECTORY {
  DWORD VirtualAddress;
  DWORD Size;
} IMAGE_DATA_DIRECTORY, *PIMAGE_DATA_DIRECTORY;

包含了两个字段，一个是虚拟地址，一个是大小。
