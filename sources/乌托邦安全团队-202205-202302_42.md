# 0x00 前言

 在上篇中，已对DOS头进行了详细的分析，并对NT头进行了粗略的分析，在此篇中将对NT头中的PE签名和PE文件头进行详细分析。

# 0x01 PE签名

 PE签名字段。

```
DWORD                   Signature;
```

![](../Images/461d4197d7a35d90672b3a586b232c81.png)

字段Signature占4个字节，通常为50 45 00 00，转换为字符就是PE\\0\\0

# 0x02 PE文件头

 字段信息如下，共占20个字节，WinHex的地址从0x000000C4至0x000000D7。

```
typedef struct \_IMAGE\_FILE\_HEADER {
  WORD  Machine;
  WORD  NumberOfSections;
  DWORD TimeDateStamp;
  DWORD PointerToSymbolTable;
  DWORD NumberOfSymbols;
  WORD  SizeOfOptionalHeader;
  WORD  Characteristics;
} IMAGE\_FILE\_HEADER, \*PIMAGE\_FILE\_HEADER;
```

![](../Images/aff0bef33b07989edd77a8a60b1e31b1.png)

*   Macheine：标记了PE文件的架构，常见的值有0x014C(x86架构)和0x8664(x64架构)，还有0x0200是Intel Itanium，该文件的Macheine字段为0x014c，说明该文件是x86架构。
    
*   NumberOfSections：表示分区表的大小(请注意，Windows loader将节数限制为96)，改文件的节数为4。
    
*   TimeDateStamp：是文件创建的时间戳，该文件的时间戳为0x291E38D1，转换为十进制是941,435,166，即日起为1970-1-1 8:0:0。
    
*   PointerToSymbolTable：符号表的偏移量，以字节为单位，如果不存在COFF符号表，则为零，该文件不存在符号表。
    
*   NumberOfSymbols：符号表中的符号数，该文件的符号数为0。
    
*   SizeOfOptionalHeader：PE可选头的大小，以字节为单位，该文件的PE可选头的大小为0x000E个字节。
    
*   Characteristics：文件的特征值，转换为二进制数，可以快速对照数值表进行判断，对应位数为1时，则表示具有该属性，为0时，则不具有该属性，该文件特征值为0x010F，转换为二进制之后0001 0000 1111，对照下表（括号内的内容为对应二进制的特征值）。
    

| Value || Meaning |
| --- | --- |
| **IMAGE\_FILE\_RELOCS\_STRIPPED** 0x0001(1) || Relocation information was stripped from the file. The file must be loaded at its preferred base address.         If the base address is not available, the loader reports an error. |
| --- | --- |
| **IMAGE\_FILE\_EXECUTABLE\_IMAGE** 0x0002(10) || The file is executable (there are no unresolved external references). |
| **IMAGE\_FILE\_LINE\_NUMS\_STRIPPED** 0x0004(100) || COFF line numbers were stripped from the file. |
| **IMAGE\_FILE\_LOCAL\_SYMS\_STRIPPED** 0x0008(1000) || COFF symbol table entries were stripped from file. |
| **IMAGE\_FILE\_AGGRESIVE\_WS\_TRIM** 0x0010(10000) || Aggressively trim the working set. This value is obsolete. |
| **IMAGE\_FILE\_LARGE\_ADDRESS\_AWARE** 0x0020(100000) || The application can handle addresses larger than 2 GB. |
| **IMAGE\_FILE\_BYTES\_REVERSED\_LO** 0x0080(10000000) || The bytes of the word are reversed. This flag is obsolete. |
| **IMAGE\_FILE\_32BIT\_MACHINE** 0x0100(100000000) || The computer supports 32-bit words. |
| **IMAGE\_FILE\_DEBUG\_STRIPPED** 0x0200(10 0000 0000) || Debugging information was removed and stored separately in another file. |
| **IMAGE\_FILE\_REMOVABLE\_RUN\_FROM\_SWAP** 0x0400(100 0000 0000) || If the image is on removable media, copy it to and run it from the swap file. |
| **IMAGE\_FILE\_NET\_RUN\_FROM\_SWAP** 0x0800(1000 0000 0000) || If the image is on the network, copy it to and run it from the swap file. |
| **IMAGE\_FILE\_SYSTEM** 0x1000(1 0000 0000 0000) || The image is a system file. |
| **IMAGE\_FILE\_DLL** 0x2000(10 0000 0000 0000) || The image is a DLL file. While it is an executable file, it cannot be run directly. |
| **IMAGE\_FILE\_UP\_SYSTEM\_ONLY** 0x4000(100 0000 0000 0000) || The file should be run only on a uniprocessor computer. |
| **IMAGE\_FILE\_BYTES\_REVERSED\_HI** 0x8000(1000 0000 0000 0000) || The bytes of the word are reversed. This flag is obsolete. |

 通过判断，该文件具有的特征属性有：IMAGE\_FILE\_RELOCS\_STRIPPED、IMAGE\_FILE\_EXECUTABLE\_IMAGE、IMAGE\_FILE\_LINE\_NUMS\_STRIPPED、IMAGE\_FILE\_LOCAL\_SYMS\_STRIPPED、IMAGE\_FILE\_DEBUG\_STRIPPED。
