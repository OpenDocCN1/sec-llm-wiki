##### 4.1 限制上传文件长度时导出凭据的方法

如果实际的测试环境对上传文件的长度做了限制，这里给出的解决方法：上传.cs文件，借助测试环境默认安装的.Net环境，使用csc.exe进行编译

```
C
:\\Windows\\Microsoft.NET\\Framework64\\v3.5>csc.exe 1.cs /unsafe
```
