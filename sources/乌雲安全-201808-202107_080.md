# **0x00前言**

最近是大事没有,小事不断,被调遣到客户单位做HW蓝方,没啥意思，整天盯着防护设备等待告警，正好一王者大佬最近在挖EduSrc，让帮着搞一搞，在50星荣耀王者的诱惑下，我准备开启我的EduSrc之旅。

# 0x01 年轻人不讲武德

通过对某个大学的C段扫描，扫到了一个学生管理系统

![](../Images/c31278a508826b33d2b25f53a0258677.png)

简单测试了一下，发现抓包验证码不刷新，而且会提示“用户名不存在”，这里就可以进行账号密码的爆破。

![](../Images/2c41e9c8986941ed46131544fb639afb.png)

很显然，我的百万大字典不配爆破，这网站不讲武德，放弃爆破。

![](../Images/e1a8fad9319731866f4d866703d10eba.png)

# 0x02 偷袭

通过目录扫描，扫描到未授权页面

http://mabaoguo /admin/manage.asp

![](../Images/4260f8c9721697233a00cb4a3fba852e.png)

![](../Images/2c41e9c8986941ed46131544fb639afb.png)

此未授权页面包含所有的用户ID值，怪不得我的字典没爆破出来，原来账号全是中文汉字，好家伙，以为我不会爆破了吗，反手就是一个偷袭爆破

![](../Images/2bd4ec0908297a2eed0638f2d27cd271.png)

爬取所有id值进行爆破，爆破到大量弱口令，密码均为123456，但是用户都为普通用户。

利用爆破的账户进行登录

![](../Images/1cbedfd3ac6b303455cdca2fa5e8683b.png)

发现网站存在两处上传点

![](../Images/e0b82d6d8b2cd6e0ed657ad4b4c51fdd.png)

此处上传为资源分享，因为账号权限问题，此账号不可以上传。

另一处上传点为导入数据的功能，只能上传execel文件

![](../Images/bd15fd4e1754be74ba86c68ae8b9949d.png)

# 0x03 接化发 这次我没大意 成功拿下

![](../Images/0c0da393598757375bcbd1b66a7a1606.png)

抓包测试上传

![](../Images/5d238c9916142344a0c6b7e7272e2fab.png)

上传的文件没有路径回显，此时测试一下是否进行了重命名，再次上传相同文件名文件

![](../Images/2b556ca4c97db91fdad295e045ed8027.png)

发现文件名变了，说明上传的文件没有进行重命名，下一步测试上传文件的路径，经过fuzz了多个目录，都没有找到文件位置。

![](../Images/2df12f81e48af5cd820b30f5fa3c452c.png)

再回到上传包，尝试能否跳目录进行上传

![](../Images/80ba56fdd4c8b2b524de563c118159e9.png)

文件名前面加../上传，发现上传成功的文件名又变为了6666.xls

说明上传的文件跳目录了

最后测试发现../../就到网站根目录了

![](../Images/c639c2b9d00a580b7d12a5c92940e73e.png)

![](../Images/470c86ed3239c2a960e6c6c36f820956.png)

找到文件位置后，开始测试上传后缀

![](../Images/29f64e39ff1e64b2d68386ef1f4dbad2.png)

![](../Images/a6bf3a6877790235c4495f9b00b79f50.png)

经过多次测试发现为上传白名单，尝试多种方法，最后利用00截断成功getshell

![](../Images/4748c073f2a84664167699f46421beb3.png)

![](../Images/c3822639e8f21fcfaff8a8045781cf08.png)
