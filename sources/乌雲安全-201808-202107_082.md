# **0x00前言**

闲来无事，网上一朋友发来一个BC的站，在别的端口发现IT运维系统的弱口令，类似于那种网络设备的管控系统，里面存在着几十台路由器，交换机，还有两台服务器，看看能不能getshell。

## 0x01尝试远程连接

选择了一台服务器，进入管理系统，点击远程桌面，难道就这么简单的连接上了吗？

![](../Images/0ac31627babece1941cf1783fa39eb54.png)

那肯定不会的，要是直接连接我也不会来水这篇文章了，连接远程桌面，弹了个空白页面，以为浏览器问题，换了个浏览器也是无果

![](../Images/6604e25f0ead320286f2513e0f34a553.png)

telent也是无果

![](../Images/a30ebb75a20b5771608315b3d60a43a4.png)

# 0x02执行脚本文件

运维系统一般都会有计划任务的功能，执行一些定时重启那些操作，这里发现有直接执行命令的功能，试一下

![](../Images/de71f37f1d5a07fc148c18d68dd66c1f.png)

还是一样，无果，这条路还是不行

![](../Images/d4162d66c4b34b3e60121815149114ec.png)

然后就到下班的点了，本来打算收拾电脑回家搞，结果小伙伴有请客请饭（自助餐），那必须得去，

![](../Images/3c93dfb410736bf186816167d58d5df4.png)

吃完饭后回家电脑直接没碰，因为连续熬了几个夜，实在太困了

# 0x03 思路大开，一键梭哈

经过一晚上的休息以及沉淀，第二天上班再次打开此系统，又对一个功能产生了奇特的想法，看到还有一个功能是加载进程的

能不能直接让他执行powershell呢？

看了一下本机的powershell目录

![](../Images/55ae932077c3aae5ad5012df248f9756.png)

![](../Images/e55d1e5222c75f4ceae10c20cccd9fd5.png)

加载一个显示进程的模块，看看到底执行了没有

![](../Images/7d874f92121d31078bdd0070b2f25950.png)

执行成功，查看进程，确实powershell开启了

![](../Images/30a66a2121c2308e7102ced9921206e6.png)

# 0x04成功getshell

直接执行powershell命令

![](../Images/43480d35e13cf28812d0c0237f7d06e9.png)

进程启动成功，打开CS，成功收到会话

![](../Images/116f5035c2bf900551a051da42f22b4f.png)

![](../Images/06261b57fe16530a57645637753c8ad4.png)

# 0x05总结

本文没有什么技术水平，其实主要还是一个思路问题，本身这种IT运维系统就属于管控设备的，上线之后也发现了，直接SYSTEM权限，但是在碰到好多运维系统都不能直接远程桌面的时候，一些小的功能点也是可以利用的，在日常的渗透工作中也是如此，开阔的思路肯定会让你的渗透之路顺畅很多
