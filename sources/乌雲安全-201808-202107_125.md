# **原理**

Use MSBuild To Do More  
可以简单的理解为，windows下的msbuild命令可以执行内容为特定格式的文件。在.NET Framework 4.0中支持了一项新功能”Inline Tasks”，被包含在元素UsingTask中，可用来在xml文件中执行c#代码。

  

# **用途**

因为这种方式不限制文件的后缀名，只要内容格式符合要求即可。所以可以几乎所有绕过白名单检测来执行shellcode,可在一定程度上达到免杀效果。
