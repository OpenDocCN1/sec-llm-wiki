**还能薅吗？****能！****但需同时满足3个条件**  

  

*   有 Github 账号
    
*   GitHub 账号粉丝在 2019 年 2 月之前超过 15 名
    
*   在2019 年 2 月之前添加了ssh key（我用新添加的key不成功，用旧的成功了）
    

  

满足以上条件，继续往下看，第三个条件是我自己测试的，你也可以用新key试试。  

  

活动地址，可能需要外网访问

https://www.namebase.io/airdrop

  

教程

1.  下载项目
    
    git clone https://github.com/handshake-org/hs-airdrop.git
    
      
    
2.  安装，需要nodejs >= 8.0.0
    

cd hs-airdrop && npm install

  

  

  

7.  进入活动地址，注册登录后生成钱包地址    ![](../Images/c752de2202d777c07426ea7e33fcd4b0.png)
    

  

9.  执行命令
    
    ./bin/hs-airdrop <path to key> <address> <fee>  
    

第1个参数是ssh key的路径，mac下默认是~/.ssh/id\_rsa  

第2个参数是钱包地址  

第3个参数是手续费，写0.010

  

验证完毕之后，会得到一堆东西，我们需要Base64下面那一串
