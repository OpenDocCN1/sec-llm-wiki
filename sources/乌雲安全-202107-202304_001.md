**关于 Github 中红队向工具 / 资源的手册**

旨在通过应用场景 / 标签对开源项目进行分类收集 降低红队技术门槛

带 🌟 项目为个人在实战中体验较好 或在原项目基础上进行重构优化的改版项目

**本项目倾向：**

*   能实际解决攻防项目中场景化问题的项目
    
*   使用新型的、非传统语言（例如 Golang）编写的项目
    
*   近一年还在持续更新维护的项目
    

**后续计划：**

*   对实战场景进行进一步细分（但是不代表某个项目只能用于该场景）
    
*   收录依据实战场景诞生的 1+1>2 的组合拳项目
    
*   汇总对应项目相关的使用指南或实战案例文章
