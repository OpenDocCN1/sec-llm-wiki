# **OutLook**

这是一款burp插件，用于Outlook用户信息收集，在已登录Outlook账号后，可以使用该

插件自动爬取所有联系人的信息

**安装**

在burp扩展面板加载jar即可

**功能介绍**

**All Users**

加载插件后，进入Outlook联系人面板，点击All Users

![](../Images/d4f832b266a08c75a28954e2d6e240d6.png)

在burp中 Proxy -> HTTP history 筛选api接口


![](../Images/f5feaa11296ef0b81bcb8f905dc7a225.png)

选中该请求，右键菜单 Extensions -> OutLook information collection -> Do OoutLook Email scan -> FindPeople scan

![](../Images/ee3f6482cff363ee65b1b6beff3e3c07.png)

会在 Extender -> Extensions -> OutLook information collection -> Output 中显示扫描进度

![](../Images/538400d4e55c553c8a3b152722e20ed5.png)

插件会自动爬取所有数据包并生成目录树，可以查看每一个请求响应包

![](../Images/0665a39e8447b7d1b8e203e6e4fea79c.png)

右击该请求会弹出右键菜单，选择获取所有用户邮箱，即可获得所有的邮箱

![](../Images/2d807ebec536fce39e16d10a4171c9da.png)

![](../Images/45821f755e83ea46d07bc2fd15913ad7.png)
