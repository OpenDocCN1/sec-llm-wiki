使用Chrome 浏览器有一个好处，就是插件极其丰富，只有你想不到的，没有你找不到的，今天就为大家推荐几款必备的Chrome插件工具。


Fehelper—前端人员神器


国人开发的一款功能强大的插件，它相当于一个工具箱，这个插件包含了各种前端程序员所需的功能。

包含多个独立小应用，比如：Json工具、代码美化、代码压缩、二维码、Postman、markdown、网页油猴、便签笔记、信息加密与解密、随机密码生成、Crontab等等。


SimilarSites—发现相关网站


我们经常浏览一个很棒的站点的时候, 或许你会想到, 和它"差不多"的站点有哪些, 尤其是一些资源站点, 这个站点没有, 它同类的站点可能就会有!

这时候这个插件就尤为重要，SimilarSites的最大的作用只有一个：可以通过搜索互联网发现同类站点！



Simple Allow Copy—万能复制


相信很多人都遇到过在网上查阅资料想复制一些内容的时候结果发现需要充VIP才能允许你复制，用快捷键也不行。这种情况不要花钱只需一个插件就能做到。


Simple Allow Copy插件可以解除限制并且可以右键复制，安装好插件之后点击浏览器右上角插件图标，图标从浅灰色变成深色便可解除限制。




自选基金助手


很多朋友平常都喜欢炒股，但股市有风险，投资需谨慎。自选基金助手是一款可以帮助你实时查看你关注的基金涨跌的开源的监控插件。

在不用跳转页面的情况下，随时快速获取你自选基金的实时估值情况并及时根据需求自由地增减自选基金。

你可以在任意网站上，用这款插件来查看你的自选基金的实时估值情况，包括基金总收益，而且这个插件带有特别关注功能的角标提醒，让你不错过任何消息。


listen 1


listen 1汇集了网易云、虾米、QQ音乐、酷狗、酷我、咪咕音乐、哔哩哔哩七大平台的歌曲！欧美、华语、日韩、古风、轻音乐等，各种风格类型的音乐都包含其中。



播放器里所有的歌曲都是免费的。比如周杰伦的歌，在其它平台上基本上都是收费的，在listen 1音乐播放器上畅所欲听！


网页截图——FireShot


网页内部的截屏一直是截图软件解决不了的难题，因为截图软件只能截取当前屏幕的内容。

这时候就需要FireShot插件上场表演了！选择你需要的捕捉方式，就可以直接拖动截图了！在跳出的页面选择保存格式就可以保存了。

GitMind


GitMind是一款全新的云端思维导图、流程图制作软件，简单好用免费的在线作图工具，这是一个全端通用的工具，无论是安卓、苹果、电脑、网页、甚至ipad都可以使用它。

GitMind有丰富的图形模板，除了能绘制常规的思维导图，还有制作组织结构图、泳道图、ER图、拓扑图等。还有项目管理、学习、知识梳理等各种模板，最重要的是能免费使用。


PDF派


PDF派为我们提供了20个好用的pdf在线转换工具，关键是完全免费，包括PDF转换，PDF合并拆分，加密解密PDF,压缩PDF等。所有功能简单易用。

只需上传文件，稍等片刻即可下载，无需下载软件，有非常好的使用体验。


Visual Studio Code


Visual Studio Code是一个运行于 Mac OS X、Windows和 Linux 之上的，针对于编写现代 Web 和云应用的跨平台源代码编辑器。

包含所有主流的开发语言的语法高亮、智能代码补全、自定义热键、括号匹配、代码片段、代码对比Diff、Git等特性。

支持插件扩展，可通过安装插件来支持C++、C#、Python、PHP等其他语言。同时针对网页开发和云端应用开发也做了优化。
