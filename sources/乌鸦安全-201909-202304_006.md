# 2\. 微信解密工具编译

首先在作者地址上将工具下载下来：

```

https://github.com/AdminTest0/SharpWxDump
```

在这个项目里面主要是`Program.cs`里面的程序，在这里使用`visual studio`来编译，其实在这里还可以使用`Windows`自带的程序来编译，但是因为我电脑是`64`位的，编译之后的工具没法使用，在这里先说一下`64`位是如何编译的。

### 2.1 64 位编译（微信暂时无法使用）

将`Program.cs`文件放到`C:\Windows\Microsoft.NET\Framework\v4.0.30319`目录下，然后使用管理员权限启动`cmd`，来编译下文件：

![](../Images/de7ff2c9a8102a8da41f77025033b431.png)

  

然后就会得到一个`Program.exe`文件，但是目前这个文件没法用：

![](../Images/6bd5dfc3d9d2247ae61b5dd23b8d3850.png)

  

执行微信的文件也需要管理员权限来执行：

![](../Images/8273aeb0b6fcbdb0e01a3fbd95e7160d.png)

  

### 2.2 32 位编译（微信可以正常使用）

在`visual studio`中新建一个`c#`的文件，首先新建一个项目：

![](../Images/50f23936f270058d7f2eb3e839c26251.png)

  

在这里选择一个`C#`的控制台应用程序：

![](../Images/ab4af42978f34210e5cb4d713e739cbb.png)

  

然后将`Program.cs`里面的程序复制过来，选择`release`的`x86`位的：

![](../Images/992dd8fe5c072f2debdd0b37d62817a8.png)

  

再选择生成解决方案：

![](../Images/cf8e15ed3b346e2e4a0e29692b6d192d.png)

  

这个程序就是生成的文件：

![](../Images/20ac86eb5952a45ff510d8ad5a988e88.png)

  

在这里使用`管理员模式`的命令行来执行下看看，在这里获取微信`key`的值，要求微信在正在打开使用的的状态下进行：

![](../Images/48915b22b8f8f331a90f97a0240dde7e.png)

  

此时获取的值就是`key`

# 3\. 解密微信聊天记录

微信聊天记录默认是放在`文档`-->`Wechat Files`下：

![](../Images/690a91d6d1b8872cf8329cbc8fe1ef15.png)

开头是`wxid_xxxxxxx`，在这里代表的是一个账号的聊天记录文件，点进去之后，找到`wxid_xxxxx\Msg\Multi\`下的`MSGx.db`文件，`MSG.db`超出`240MB`会自动生成`MSG1.db`。

聊天记录为：

```


wxid_xxxxxxxx\Msg\Multi\MSG0.db > 聊天记录
```

将这里面的文件复制出来，用解密脚本来进行解密操作：
