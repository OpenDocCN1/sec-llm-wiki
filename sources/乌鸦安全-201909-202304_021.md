![](../Images/62c8e787a2a9efc03cf8c02d59f65feb.png "null")

  

看来渗透测试必不可少了。

# 2\. getshell

经过抓包分析，该`app`的后台地址为：`http://www.xxx.com/`，对该站点进行分析发现，该站为`thinkphp`搭建，那还说什么，直接一把梭：

![](../Images/b9585d5582700f34e07b85ac004018bb.png "null")

  

直接就拿到了`shell`，在连接的时候，发现连接报错：

![](../Images/3300d4727ab614603ead81ed8500bc20.png "null")

  

那在浏览器里直接连接看看：

![](../Images/6d5956ecf87abcb83b4b668d00595468.png "null")

应该是出了问题，还是手工测试吧：

```


http://www.xxxx.com/?s=index
```

![](../Images/e87b560d521b64049803b9fdc2e2edfd.png "null")

  

此时发现禁用了非常多的函数：

```
passthru,exec,system,chroot,chgrp,chown,shell_exec,popen,pcntl_exec,ini_alter,ini_restore,dl,openlog,syslog,readlink,symlink,popepassthru,pcntl_alarm,pcntl_fork,pcntl_waitpid,pcntl_wait,pcntl_wifexited,pcntl_wifstopped,pcntl_wifsignaled,pcntl_wifcontinued,pcntl_wexitstatus,pcntl_wtermsig,pcntl_wstopsig,pcntl_signal,pcntl_signal_dispatch,pcntl_get_last_error,pcntl_strerror,pcntl_sigprocmask,pcntl_sigwaitinfo,pcntl_sigtimedwait,pcntl_exec,pcntl_getpriority,pcntl_setpriority,imap_open,apache_setenv
```

试试`session`包含的写`shell`，教程：

```
https://xz.aliyun.com/t/10397
```

先通过`session`包含写入一句话木马

```

http://www.xxxx.com/?s=captcha
```

然后利用文件包含去包含`session`文件，`tp5`的`session`文件一般都是在`/tmp`下面，文件名为`sess_sessionid`：

![](../Images/815e46b2b310b5feaf0c4a43c7202e49.png "null")

  

然后接下来的`payload`为

```

http://www.xxxx.com/?s=captcha
```

![](../Images/86c041324f4cc1761cc5b2bac737f21e.png "null")

  

看到这个就算是成功了，蚁剑连接记得加上body：

![](../Images/0144d85ca0aaad5203a780abe0641e55.png "null")

  

![](../Images/13f04701b0ec64dd8bf74a4441a49c8b.png "null")

  

此时`shell`连接成功：

![](../Images/f8eecc5b457ae30d681e52d1869243fd.png "null")

  

![](../Images/f2c569b6e7e668523d0a665b3b26ed52.png "null")

  

连接成功，发现是www权限，但是提权的时候失败。。那就到此为止吧！
