# 1\. WMI介绍

WMI的全名为"`Windows Management Instrumentation`"。

从`win98`开始，`Windows`操作系统都支持`WMI`，`WMI`可以在本地或者远程管理计算机系统。比如：重启，关机，关闭进程，创建进程等。

```
具体可以参考：https://docs.microsoft.com/zh-cn/windows/win32/wmisdk/using-wmi
```
