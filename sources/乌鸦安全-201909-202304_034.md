# 1\. ip查看

前段时间看到有大佬发了一篇文章：[什么！我用代理你还可以找到真实ip?](https://mp.weixin.qq.com/s?__biz=Mzg5OTQzNTI4Nw==&mid=2247487502&idx=1&sn=a57a6e718673bc6712345b0f96aa2326&scene=21#wechat_redirect)

感觉很有意思，总结下来就是在使用隧道技术的情况下，哪怕是全局，依旧能够访问到你的真实ip。

在这里面大佬分析了用到的技术主要是`WEBRTC`，具体的原理还是直接看大佬的文章吧，以下是分析截图：

![](../Images/577599c89c9051e9e98953ebc739b8fa.png)

### 1.1 无隧道的情况

当前从`138`和请求`ipinof.io`上可以查到目前我的ip地址为真实的ip：

![](../Images/d8c4f629249422ee6a314667fdb7dc42.png "null")![](../Images/5efd5e4408c720da5f188e3b13f0d3ad.png "null")

访问下面这个地址之后，显示的也是准确的：

```
https://www.hackjie.com/tracking
```

![](../Images/0c46a3bf82a8ea74e5efb7eb22b14e6a.png "null")

当前显示的是我的真实ip地址。

### 1.2 有隧道的情况下

当前使用隧道技术，并且全局，命令行配置之后，请求下当前的ip地址：

![](../Images/89d273765d82189045824709d3a33039.png "null")

当前地址已经发生变化，此时去访问`ip138`看下：

![](../Images/daad8989ee8c77b177ae6b2367159a17.png "null")

貌似都是隧道之后的地址，但是当去大佬提供的地址访问之后：

![](../Images/e5edb5d4a22bb431a11218115300eee6.png "null")

此时发现自己的真实ip泄露，后来我经过测试，无论是使用`Proxifier`还是`proxychains`，真实地址依旧会发生泄漏。。。

# 2\. 屏蔽方法

经过另一位大佬指点，目前有浏览器插件能够防止这种情况，以下推荐两个插件（插件不唯一）

### 2.1 Firefox浏览器

插件名称：`Disable WebRTC`，允许该插件在隐私模式下使用：

![](../Images/e6d63996d1993436ae943db56fd2e684.png "null")

点击一下即可开启：

![](../Images/5fa16df09556e1de35543ee6feea8e06.png "null")

此时在使用隧道技术的情况下，再去访问黑客街的链接：

![](../Images/65753ebb9a59aac05f417c418e840d1c.png "null")

### 2.2 Chrome浏览器

Chrome浏览器插件：`WebRTC Leak Prevent`

![](../Images/1e11826e749cb86f3b3ee767cd180559.png "null")

在隐私模式下，并且启动强力模式即可。

在这里注意，有些人在下图的位置会显示失败

![](../Images/70ab67590af18dc8f420f46775314165.png "null")

但是这个并不影响其正常的拦截功能。
