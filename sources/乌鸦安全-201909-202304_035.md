# 1\. Volatility介绍

`Volatility`是一款开源的内存取证分析工具，支持`Windows`，`Linux`，`MaC`，`Android`等多类型操作系统系统的内存取证方式。该工具是由`python`开发的，目前支持`python2`、`python3`环境。接下来小编将带领大家学习`Volatility`工具的安装及使用。

```
参考：http://www.hackdig.com/09/hack-484669.htm
```

`volatility`(挖楼推了推) 是一个开源的框架，能够对导出的内存镜像进行分析，能够通过获取内核的数据结构，使用插件获取内存的详细情况和运行状态，同时可以直接`dump`系统文件，屏幕截图，查看进程。

```
参考：[https://www.cnblogs.com/Junglezt/p/16027761.html](https://www.cnblogs.com/Junglezt/p/16027761.html)  
```

可以使用 -h 参数获取使用方法和插件介绍，列举几个常用到的命令
```

# 3\. volatility使用

在这里以分析`vm`虚拟机的镜像文件为例，在这复制下`winserver2003`的`vm`暂停文件：

## 3.1 获取内存镜像版本信息

使用方法是：`volatility -f 文件名 imageinfo`  
直接使用命令分析：

```
./volatility -f 2003.vmem imageinfo
```

![](../Images/76c30e029889032d4c86cdb51c6ef062.png "null")

当前可以分析出来结果：

```
$ ./volatility -f 2003.

## 3.2 pslist 列出内存中的进程

可以列出内存中运行的进程的`pid`，`ppid`等信息：

```
volatility -f 镜像名 --profile=第一步获取的版本信息 pslist`
```

在第一步获取的是`Win2003SP0x86`，所以命令组合以下就是：

```
./volatility -f 2003.vmem --profile=Win2003SP0x86 pslist
```

但是命令执行之后，并未获取到有效的进程信息：

![](../Images/c94c4bdeb80865b8da11fef39cfa013f.png "null")

在这里将镜像版本信息更换一下再试试：

```
./volatility -f 2003.vmem --profile=Win2003SP1x86 pslist
```

![](../Images/c07a2e18b028500de07c7f47974bde58.png "null")

## 3.3 导出指定进程 memdump

在我们`pslist`后，会给出进程的`PID`，只需要指定`PID`就可以将进程导出：

![](../Images/89a8d9532aa7fdce36e9bd2192e1e5c5.png "null")

当前`svchost`的进程为`1256`，运行命令为：

```
./volatility -f 2003.vmem --profile=Win2003SP1x86 memdump -p 1256 -D ./result
```

![](../Images/72baf390cd97aebad2ef6fc6332c91ee.png "null")![](../Images/844a045337c1b9f730bc4fc02ded8604.png "null")

> 导出的文件名进程的PID，后缀名为dmp  
> 可以使用strings -e l 2616.dmp | grep flag，筛选其中的flag  
> \-e为选择字符的大小，l为32bit为一个字符
>

## 3.6 扫描内存中的文件 filescan

```
./volatility -f win7.vmem --profile=Win7SP1x64 filescan
```

列出的文件会非常的多：

![](../Images/9e4d240799295d6d82ea82faaa98e87d.png "null")

可以使用`grep`命令来查找自己需要的，需要加上`-E`参数

```
./volatility -f win7.vmem --profile=Win7SP1x64 filescan | grep -E "txt\|jpg\|png" # 在linux|mac情况下使用

"txt\|jpg\|png"  # 在Windows下使用
```

![](../Images/81ddd4c088a4b86609e40079d4bb0da5.png)

  

## 3.7 导出内存中的文件 dumpfiles

在这里需要`3.6`中找到的文件的内存地址来导出：

![](../Images/5f703ec2dc7b798ca9da4cac6e01cb09.png "null")

```
./volatility -f win7.vmem --profile=Win7SP1x64 dumpfiles -Q  0x000000007ce78f20

  -D ./ -u 
```

在这里导出的时候，发现`win7`无法成功，导出的文件均为`0kb`

![](../Images/5001d53a8a20d1fa5861295b3e652a4a.png "null")

在这里使用`winserver2003`成功：

```
./volatility -f 2003.vmem --profile=Win2003SP1x86 dumpfiles -Q  0x0000000002e58150 -D ./ -u
```

![](../Images/34cd4347e4d6c30ca83972563df3e10a.png "null")![](../Images/d2188a5c366aa48e0148971850437871.png "null")
