# 3\. 简单复现

复现环境：

*   • 安装了搜狗浏览器的`Windows7`系统（最新版搜狗浏览器）
    
*   • 攻防中获取的`FormData3.dat`文件
    

按照提示，将文件进行替换：

```
C:\Users\crow\AppData\Roaming\SogouExplorer
```

![](../Images/062d1d89381607102261d0567dd660b3.png "null")

替换之后，打开搜狗浏览器：

![](../Images/4e99d25f76063227ffb515ebf9fe6f0d.png "null")

点击账号助手：

![](../Images/902cade7476fb6ac5ca37da336488df6.png "null")

image.png

点击该选项，第一次勾选的话，需要输入主机的账号和密码：

![](../Images/e133be132c8ce9a58dadef46ff524cc8.png "null")

在这里点击眼睛的选项，输入当前机器的用户密码，就可以获取到用户保存的账号密码信息：

![](../Images/49bbb0b806c515566c3792e58d2a3a1d.png "null")
