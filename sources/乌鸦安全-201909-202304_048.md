# 1\. 原理

利用连按5下`Shift`漏洞破解`win7`开机密码。将`c:windows/system32/sethc.exe`替换为`cmd.exe`文件，达到新增用户、修改账号密码的的目的。  
为了防止被发现，在这里不去修改原来的用户，通过`mimikatz`方式`dump`下来所有的`NTLM`值，并对其进行解密。当然，除了这个程序之外，还有以下多个程序的快捷方式：

```




屏幕键盘：C:\Windows\System32\osk.exe
```

# 2\. 环境准备

实验主机：`Windows7`旗舰版 （无任何杀软）

# 3\. shift后门复现

### 3.1测试是否存在粘滞键

在正常登录的`Windows7`用户桌面连续摁5次`shift`键，看是否有粘滞键提示弹出：

![](../Images/543c0c5b49f095043cbbc2a89bba380a.png "null")

此时有弹出，证明其存在漏洞，然后将机器强制关机。

### 3.2 启动启动修复

在这里摁住`option`键，然后关机键就会变成断电键。

![](../Images/a5cfe1586c618c6e3da2e19bf8a33c72.png "null")

关机之后，再正常启动机器：

![](../Images/db35097b75bb9ee0f269446fc6eaf57c.png "null")

启动之后，再选择重新启动，就可以进入到启动启动修复模式：

![](../Images/d9d7fed767c0ba372c734deaee961bd5.png "null")

### 3.3 替换sethc.exe为cmd

然后到这个界面，等待：

![](../Images/7fd1660f65493b0beaa360d636075048.png "null")

在这里选择查看问题详细信息：

![](../Images/fa9e3ca9f9282be68b8975292881e150.png "null")

在这里选择文件——打开：

![](../Images/53cf984aee1dcedb124d6c8a31921667.png "null")

找到路径：`c盘`\->`Windows`\->`system32`\->`sethc.exe`文件

![](../Images/a98a4c2d4b6673e91582a095f68c3e5e.png "null")

将该文件重新命名：

![](../Images/53d495d7208b210fae7d4df39da1c732.png "null")

再找到该目录下的`cmd.exe`，将该文件复制后修改为`sethc.exe`

![](../Images/5d1b5f1499a3a42f899b132465770e25.png "null")

重启机器：

![](../Images/7a7b96bd34f275c8baf88d7c8e62d68b.png "null")

### 3.4 添加新用户

重启之后，使用5次`shift`键打开`cmd`窗口：

![](../Images/a2223a3bba774d98db53563c736879f9.png "null")

在这里如果直接修改`test`用户的密码，后面无法知道当前的密码，因此在这里添加一个新的用户进去，并将该用户添加到管理员组：

![](../Images/a1a26a2a7aff2c08edaf67f3cc441391.png "null")

重启机器登录：

![](../Images/e62347b9b9a0927e20ba9e35894b0ef0.png "null")

### 3.5 获取原用户密码

登录`test2`后之后，使用工具`mimikatz`工具将所有用户的密码`dump`下来：

![](../Images/5f69e46bd221ee5695f7f278f3789a16.png "null")

```

privilege::debug   提取权限
```

![](../Images/8281984722ae29738440fc2373ccb58d.png "null")

当前使用，只能抓到`test2`的用户密码，在这里我们需要`test`用户的账号和密码信息 在这里使用命令`lsadump::lsa /inject`能够导出所有用户的`hash`值：

![](../Images/88a7b5c4920e962cfaa2a2f10a41675f.png "null")

`209c6174da490caeb422f3fa5a7ae634` 通过解密可知当前密码为：`admin`

![](../Images/a1f7c24315d1c2b90cf9d7988e1cdcfc.png "null")

### 3.6 删除新增用户

此时将机器重启，利用`test admin`进行登录，再将当前的`test2`用户删除：

进入环境之后，发现是无法找到`cmd`程序的，因此在这里需要找到已经修改过的`sethc.exe`，将其复制为`cmd.exe`：

![](../Images/7589f3d6e257c3632c71766fb90ace77.png "null")

此时即可通过`cmd`进行运行：

![](../Images/cbae5be8be00eba7ba5ac44e3d8882e8.png "null")

此时删除多余的用户即可：

![](../Images/3fd890aecaa737e3452421344e39d0e1.png "null")

# 4\. 总结

本漏洞存在于`Windows 2003`、`xp`、`win7`等。
