# 1\. 背景介绍

`cmd`命令混淆的意义主要是`bypass`，混淆也不能影响原来的命令执行结果。

# 2\. 混淆方法

### 2.1 双引号法""

使用双引号包裹字符，相当于将字符进行连接。 `who""a""mi`

![](../Images/ed1bcf0e069a211a2d21fb84bdedd6f9.png "null")

在这个也可以这样：

![](../Images/01b54b0a4513417c193dd23aa7590431.png "null")

最好是成对使用：

![](../Images/5d49bbf348c02a22af5b08d18e359df4.png "null")

### 2.2 转义符^

字符` ^` 是`CMD`命令中最常见的转义字符，该字符不影响命令的执行。 `who^am^i`

![](../Images/da5041320de2b8b4c8ae11bda2775fc5.png "null")

在这里不能两个^^放在一起使用，不然会报错：

![](../Images/ceac92ffa8ec21f2b86cbb17ff7d3d0e.png "null")

### 2.3 大小写混合

`WHoAmI`

![](../Images/d2d2d1a40fe618537620a1cc231cef75.png "null")

### 2.4 空格替换 ,;

逗号 `,` 和分号 `;`可以互换，可以取代命令中的合法空格，多个空格也不影响命令执行。

```

;, net user
```

![](../Images/713469af461bf3745f68d3aa487e39ec.png "null")

但是不能在一个连续命令中间使用：

![](../Images/d64ed981f4ca27bc106521bf8804cbc0.png "null")

### 2.5 括号()

成对的圆括号`()`也会出现在命令参数中，也不影响命令的执行。圆括号表示嵌入子命令组，同样被`cmd.exe`参数处理器进行解释 这个句子注意当前使用的时候，只能够使用完整的一个命令使用当前的符号，不能分开：

![](../Images/e16c5a7f45c96b30e08fee3e5ab62819.png "null")

多层同样不影响使用：

![](../Images/3dffd4c825886a5b296553a826b02f2e.png "null")
