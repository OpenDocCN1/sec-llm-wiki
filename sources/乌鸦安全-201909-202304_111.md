## 复现环境：

## windows10 + 1.8.0\_172 + idea2018社区版

  

*   `idea2018社区版`直接去下面的链接下载就行了，非常方便。

    
*   java的环境要求有些许苛刻，`1.8`的高版本也是无法复现的。
    
      
    

win10 ip地址：`10.211.55.3`

  

![](../Images/fa919bf79bf4def2934b53a3ae5a9efa.png)

  

首先需要下载`Log4j-exp`

  

*   
*   
*   

```
https://github.com/feihong-cs/JNDIExploit或者去https://pan.baidu.com/s/1lxXt-27-i7I_dOUACphVtQ 提取码: nkc5
```

参考视频中Up主推荐下载第二个，下载下来之后，解压，并使用idea打开：

  

![](../Images/3c4357d3f00851de312ddcf4a5191218.png)

  

现在去刚下载的文件里面找到`JNDIExploit-1.2-SNAPSHOT.jar`所在的文件夹，并使用`cmd`打开，执行以下命令：

  

![](../Images/622ab7a56d66795b186bd8fbc046c7b1.png)

  

*   
*   

```
java -jar JNDIExploit-1.2-SNAPSHOT.jar -i 10.211.55.3-i  后面接的是本地的ip地址(或者你的VPS地址)
```

  

![](../Images/37a876025467e7fc023678cb79c05b91.png)

  

  

回到你刚打开的idea中，找到`log4jRCE`文件，将该文件中箭头位置的ip地址进行替换。

  

![](../Images/655a75fec0e4ea8eb1a4a477f6a58c3a.png)

  

替换成功之后，按照如下进行build：

  

![](../Images/391437d3837e37097dead2742068e4f4.png)

  

继续`build`

![](../Images/f04967b42058a993a2c54b674fe47748.png)

然后在刚才的目录下会生成一个`out`的文件夹：

![](../Images/50ccca6479e45b51ff32520b8bedd1b7.png)

点进去会找到一个`Log4j-rce.jar`文件。

  

![](../Images/1f1a01712c5c050f92e93d3c5d9d5c1c.png)

  

直接双击即可运行，弹出计算器：

  

![](../Images/dda81a259819cd5b7e1c0b81bbee63a1.png)
