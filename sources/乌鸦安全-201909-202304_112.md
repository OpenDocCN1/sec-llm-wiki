# **1\. 环境配置**

## **1.1 环境准备**

闲着没事来复现一个2011年的工控CVE漏洞，其实还是偏向于web.

再来熟悉一下HMI和SCADA吧

靶机：win xp (192.168.183.160)

攻击机器：kali(192.168.183.139)

工业软件及版本：InduSoft Web Studio v7.1  

 漏洞exp：https://www.exploit-db.com/exploits/21837

  

## **1.2 工业软件安装**

  

安装地址：https://indusoft-web-studio.software.informer.com/7.1/

![](../Images/376ac9d0f80a286280caa6122219ac93.png)

  

然后过程可参考：http://www.opdown.com/soft/92899.html  

![](../Images/427ee2eac23c407c85b79c3355468df2.png)

  

在靶机中安装InduSoft Web Studio v7.1工业软件，安装好后点击remote agent，然后点start

![](../Images/3d93aeca62d1502ce53df4446348abe7.png)

  

然后就来到了主页面![](../Images/67894b82df4bd2452aab0d0a7173d7b3.png)

  

此人机界面继承了许多存在的工业场景，比如是由燃气采集

![](../Images/0b5641a75b9f8f9cea78f3e73f5915f0.png)

  

然后还有自动化机械臂  

![](../Images/9edbd6619451a9f91fb45124cdcd541a.png)

  

还有风能监测，并且还登记了操作系统和用户，作为十年前的软件做的确实可以  

![](../Images/a8be56e0c254a6b8e41eef22eafb76ec.png)

然后我们此时查看端口占用情况

![](../Images/331db29f60c41ad079dcb570e5e12c00.png)同时可以看到4322端口已开启  

## **1.3 子弹上膛**

  

在kali攻击中，如下目录放入下载的exp模块  

![](../Images/6e7b96ce1eb48c92a04ce420b3b9fc44.png)

  

然后下载此攻击exp  

![](../Images/aab3753ce179b609e256a2e25de351a5.png)

  

此脚本在更新后的msf上是存在的，没有的安装一下

![](../Images/d8d4a8d6263fb03c616fd6c6924cad1d.png)

  

通过https://www.exploit-db.com/exploits/21837，获取漏洞exp，发现漏洞测试版本为InduSoft Web Studio v6.1 SP6，由于v6.1版本已经很难找到，本文尝试使用InduSoft Web Studio v7.1版本代替，亲测v7.1版本也是ok的

![](../Images/fa7d750416f5ffd60491f34a3b310a66.png)

  

通过exp发现漏洞利用需要通过4322端口，故InduSoft Web Studio v7.1需要开启相应服务。  

![](../Images/a19ec13ed2d1d7d5658b5eecd64dc7e2.png)
