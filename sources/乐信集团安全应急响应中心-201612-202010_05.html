企业如何更好地应对勒索软件横行

       2016年即将过去，但对于信息安全从业人员来说，是不平静的一年。特别是勒索软件（TeslaCrypt、CTB-Locker、Cryptowall等）让大家记忆尤新。

       当前勒索软件从原来漫天撒网改变为攻击企业高价值目标的方式。特别是医疗数据、金融数据、教育数据、政府数据等，数据可用性要求比较高的企业。

        常见的黑客会先探测企业连接互联网的系统或设备的弱点（漏洞或脆弱性），当攻进一个企业之后，会立即建立支点和安放后门；随后会进一步扩大战果，比如嗅探内网结构、用户名和密码嗅探等；同时寻找高价值目标（薪资系统、交易系统、财务系统、文件存储系统、数据库等等）；获取企业域控管理员权限或软件分发系统权限，将勒索软件打包成可批量推送和分发的软件扩散传播，最后寻找备份系统，删除备份数据或使其失效。当这一切准备就绪，黑客就坐等收钱了。

       其他攻击方式是需要用户交互方式，比如采用社交钓鱼、发送恶意链接、USB介质等传播。

       然而，做为一个企业安全家专如何应对勒索软件对企业的危害呢？

       可以从以下5个方面部署措施防护：

一、源头控制，减少病从口入机率。

 1. 在对外出口部署访问策略阻断内网访问勒索软件下载服务器（以下为不完全统计）。


    2. 清理内部上网人员和疏理上网访问权限，减少许可访问外网人员，严格限制外网许可，缩少外网访问范围。

   3. 定期扫描对外开放端口和更新系统、中间件、框架和设备补丁。

二、通道限制，限制或延缓攻击。

  1. 内部网络限制网络广播阀值和关闭非业务需要的Vlan间访问通道。

  2. 按业务需要清理一遍，关闭访问上述已知网站地址和端口，监控直接暴露在外网的服务器端口和连接。

  3. 采用防火墙（TCP 445，139端口）或域策略阻断网络映射磁盘功能。

  4. 疏清业务应用场景和访问需求，划分相对较少的Vlan，延缓黑客扩大战果。

  5. 疏清USB权限许可清单，关闭不必要的USB接口权限，减少USB介质使用。

  6. 与病毒软件商、安全设备厂商紧密合作，发现可疑样本，送给他们更新设备防御机制。

三、终端防护，确保个体安全。

  1. 在邮件服务器上部署策略扫描所有邮件附件档和防钓鱼邮件。

  2. 更新病毒服务器病毒库样本，加入已知勒索病毒，并部署病毒防护策略，所有下载文件，可执行文件均强制扫描；外接存储设备接入主机强制扫描。

  3. 在网关部署策略，所有访问勒索服务器地址的终端主机，将其隔离，临时禁止所有外部资源（使其无法上传解密密钥）。

  4. 制定域策略，确认终端许可运行软件的白名单。

  5. 拥有重要数据客户端须制定备份策略。

四、用户宣导

  1. 制作勒索病毒识别宣传物，群发给内部所有员工，多渠道让员工接收到危险情报。

  2. 教育员工点击邮件URL链接或执行附件文档（多为Office和PDF文件嵌入恶意脚本）时，需认真辨识。

  3. 客户端主机发现异常时（如反应极慢，点击无反应等），立即拔掉主机电源线缆，寻求IT人员帮助。

  4. 企业部署重要数据备份系统，宣导用户养成重要数据备份习惯。

五、其他

   1. 搭建企业备份系统，依系统数据重要等级，制定备份策略，采用在线和离线系统双重保护重要数据。

   2. 企业应制定针对勒索大规模攻击事件的应急响应流程。

   3. 购买相应的网络保险，并确定相关条款含有“网络敲诈勒索”造成的损失进行赔偿内容。

      未来勒索软件的发展趋势可能会在逃逸和传播手段上大力发展。如借鉴蠕虫传播特点、沙箱逃逸技术、自我复制变种等。愿大家一起携手共享威胁情报，共同抵御威胁。
