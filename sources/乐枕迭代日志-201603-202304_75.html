快捷安装

$ sudo pip install NetEase-MusicBox

$ brew install mpg123

Ubuntu/Debian

$ sudo pip2 install NetEase-MusicBox

$ sudo apt-get install mpg123基

$ pacaur -S netease-musicbox-git
