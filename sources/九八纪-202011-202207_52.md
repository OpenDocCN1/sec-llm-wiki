**三、Burp Suite 2020.11.3 安装破解。**  

![](../Images/f2883f3d9179a7f7718d7cb822d08c46.png)

1.  启动 burp-keygen-scz.jar，用来破解license。(java11 -jar"burp-keygen-scz.jar")
    
2.  加载 burp-loader-x-Ai.jar 启动 burpsuite\_pro\_v2020.11.3.jar。(java11-noverify -javaagent:"burp-loader-x-Ai.jar" -Xmx2048m -jar"burpsuite\_pro\_v2020.11.3.jar")
    
3.  BurpSuite界面取消协助，同意协议。
    
4.  随意修改 burp-keygen-scz 的 License Text，把 License 复制到 BurpSuite，点击 Manual activation，点击 Copy request。
    
5.  把 Request 复制到 burp-keygen-scz 的 Activation Request，把自动生成的 Activation Response 复制回 BurpSuite，完成，开始使用。
    
6.  持久启动必须加载 burp-loader-x-Ai.jar，不然依旧要license key。
    
7.  启动脚本。java11 -noverify-javaagent:"burp-loader-x-Ai.jar" -Xmx2048m -jar"burpsuite\_pro\_v2020.11.3.jar，另存为bat脚本，双击即可启动。
    

启动成功界面。
