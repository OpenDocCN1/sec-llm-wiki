![](../Images/604b9493935906cd263c47280de85de3.png)![](../Images/688da9fa40faf09a0b063dcff6a3cde7.png)背景介绍

DNS（域名系统），通过主机名，最终得到该主机名对应的 IP 地址的过程叫做域名解析（或主机名解析）。DNS 协议运行在 UDP 协议之上，使用端口号 53。

![](../Images/688da9fa40faf09a0b063dcff6a3cde7.png)DNS 漏洞利用1DNS 域传送信息泄露

Dns 是整个互联网公司业务的基础，目前越来越多的互联网公司开始自己搭建 DNS 服务器做解析服务。同时由于 DNS 服务是基础性服务非常重要，因此很多公司会对 DNS 服务器进行主备配置而 DNS 主备之间的数据同步就会用到dns 域传送，但如果配置不当，就会导致任何匿名用户都可以获得 DNS 服务器某一域的所有记录，将整个企业的基础业务以及网络架构对外暴露仅而造成严重的信息泄露，甚至导致企业网络被渗透。DNS服务器的主备数据同步，使用的是域传送功能，域传送关键配置项为：

```
allow-transfer {ipaddress;}; 通过ip限制可进行域传送的服务器
```

```
allow-transfer { key transfer; }; 通过key限制可进行域传送的服务器
```

设置方式为两种：一种设置在options配置域；一种设置在zone配置域。优先级为如果zone没有进行配置，则遵守options的设置。如果zone进行了配置，则遵守zone的设置。

攻击方式及危害

4基于DNS的DRDOS攻击浅析

早几天的时候 VPS 突然锁住了, 联系服务商之后说存在被攻击的迹象, 影响到了其他用户的使用。稀里糊涂说了一番好话解封之后，把用不到的服务该关的都关了之后一直没查到原因, 某天去看时突然发现 DNS 日志大小有 5G 左右。DNS 是基于 UDP 的协议, 没有握手过程, 攻击者可以轻易的伪造来源 IP 并发起请求。DNS 可以轻松设置多条不同类型的解析, 让响应包尽可能放大。  

DNS 服务器的类型主要有权威 DNS 和递归 DNS 两种, 它们带宽一般都相对较大。DRDOS(Distributed Reflection Denial of Service)，顾名思义这种攻击方式有别于普通的 DDOS。最大的不同在于 Relection，这种攻击不是让 botnet 直接请求受害者, 而是发送请求给一个第三方, 通过第三方中转再由第三方将请求发送给受害者：

往往通过中转之后，请求流量将扩大几十倍甚至更多。

扩大的攻击成果的同时还降低了攻击者的成本和风险，同时可以借此发起更大的攻击。

对 botnet 的要求较小。

此时发起攻击的可以视为是进行中转的第三方, 而这里所谓的第三方很多都是我们 VPS 上不安全使用的 DNS 递归服务器，仅某种角度讲这些 DNS 服务器是受害者也是攻击者。

![](../Images/688da9fa40faf09a0b063dcff6a3cde7.png)修复方案

解决域传送问题非常简单，只需要在相应的 zone、options 中添加 allow-transfer 限 制可以迕行同步的服务器就可以了，可以有两种行式：限制 IP、使用 key 认证。关亍 DNS 劫持的修复的一些建议：

1、关注广告联盟中劫持流量情况

2、不安全厂商、浏览器厂商及运营商操作

3、关键操作使用全站 https 加密

4、对网站会员关于此类攻击的安全提示
