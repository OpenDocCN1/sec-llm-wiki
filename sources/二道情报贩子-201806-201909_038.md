# 英国伦敦警察局账号连发十几条消息大骂警察XX

![](../Images/600b8b9570ef8d884514ddcd42d6094a.png)

据《每日邮报》报道，当地时间19日晚间11点之后，大都会警察局的电子邮件系统发出一连串奇怪并带有辱骂字样的信息。其中一条推文称，要求释放说唱歌手Digga D；还有带“F”开头单词的辱骂言论。

  

![](../Images/859dea33bbc2c1baef16d58612ef1e8f.png)

  

不仅推特被黑客攻击，RT说，几乎在同时，大都会警察局的官方网站上也发出了同样内容的信息，这次被发布在警察局官网的“媒体新闻稿”一栏里。

伦敦警察厅承认，他们失去了对新闻办公室电子邮件以及推特账号的控制，并建议公众忽略任何该账号所发布的信息，直到问题得以解决。  

  

  

![](../Images/95541ad282164a0673f7ea4e9a112149.png)

  

这一小插曲在社交平台上引发热议。不乏有网友调侃警方的安全措施存在漏洞：“你们的密码是1234吗？”

  

![](../Images/5fe621dcfece8a4b329b88ea13057c91.png)

也有网友认为，“如果他们（警方）不能保障系统安全，我们就没有机会解决网络犯罪的问题。”  

RT称，截至目前，黑客已经发布了十几条消息，消息后附加的不明标签“##CHUCKLINGHELLA”似乎与某个电子游戏有关。

报道称，当地警方发言人随后告诉媒体，“我们已经注意到@metpoliceuk账号一直受到未授权的访问，我们的媒体团队目前正在努力删除这些信息，并确保该账户的安全。在我们确认该账号重新处于官方控制下之前，请忽略所有的推文。”
