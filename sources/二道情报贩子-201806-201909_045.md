# Facebook被罚50亿美金后，股价上涨反赚40亿

据外媒报道，Facebook与美国联邦贸易委员会（FTC）达成和解协议。委员会同意Facebook支付50亿美元罚款和一些附加限制条款来换取结束对它的调查。这一罚单也成为有史以来该机构对违反隐私承诺的科技公司开出的最大罚单。

据悉，FTC以3-2的投票批准这项和解协议，结束调查。报道称，多数共和党人支持通过这一决定，而民主党人大多投下了反对票。这份和解协议的通过，可能意味着结束其针对Facebook不当处理用户个人信息的广泛调查。

  

![](../Images/f7f8bc87faa69c6d842ccdc682aa5197.png)

  

消息传出后，Facebook的股价当日上涨1.81%，以其约5000亿美元的市值估算，市值增长约90亿美元。  

  

![](../Images/7800ed421fdab678b12d2565e991f0db.png)

  

起初，Facebook 被曝超过8700万用户资料在未获得用户授权的情况下遭第三方数据分析“剑桥分析”CambridgeAnalytica公司非法收集用于大数据分析，从而精准对用户推送广告甚至假新闻，成为Facebook史上最大规模的一次数据泄密事件。  

FTC随后调查这一过失是否违反2012年Facebook 与该机构签署的涉及用户私隐的同意令。

  

但FTC的调查很快扩大超出了剑桥分析公司滥用数据事件，开始覆盖大量Facebook其他侵犯隐私和安全的行为，包括在未通知用户或未获得用户许可的情况下，允许流行网站、智能手机和其他设备制造商获得用户的社交数据。  

  

随后Facebook市值在2018年3月19日、20日两日直接蒸发掉500亿美元。2018年7月，Facebook的二季度财报公布后，Facebook市值更是一夜蒸发掉千亿美元，创下美股史上单日市值缩水规模最大纪录。

  

直至昨天，FTC与Facebook达成和解协议，同意以罚款50亿美元和其他附加限制条款结束对Facebook的长期隐私调查。

此前，FTC对科技公司的最高罚款是2012年谷歌因其隐私惯例而支付的2250万美元的罚款。

  

和解消息出来之后，周五美股收盘，Facebook涨1.18%，报204.87美元，市值增加103亿美元至5848亿美元。

吃了50亿美元的罚单还大涨？原因或许是靴子落地，投资者对着罚单早有预期。

今年4月24日，Facebook曾表示，它可能面临FTC高达50亿美元的罚款。投资人似乎对Facebook这50亿的罚款提前做好准备给予“奖励”。

而这一罚款虽然创纪录，但仅占Facebook2018年营收不到9%，净利20%左右。
