# 只要28300美元，便携式汽车安全测试平台带回家

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5NTA3MTk5Ng==&mid=2247484348&idx=1&sn=4cd591700841d0dfa36654556c0370cb&chksm=fe76c52fc9014c3993191b009a18513f1bd6b50532a9051208d5d4fa868118d8dfd6c34ae852&scene=126&sessionid=1681273962#rd](http://mp.weixin.qq.com/s?__biz=MzU5NTA3MTk5Ng==&mid=2247484348&idx=1&sn=4cd591700841d0dfa36654556c0370cb&chksm=fe76c52fc9014c3993191b009a18513f1bd6b50532a9051208d5d4fa868118d8dfd6c34ae852&scene=126&sessionid=1681273962#rd)

7月2日，丰田正式开始为研究人员和新兴的汽车黑客专家提供其新的便携式汽车安全测试平台（Portable Automotive Security Testbed，PASTA）的商业版本。PASTA硬件和软件工具产品售价为28300美元。  

  

![](../Images/c4b0aecc7439b90d4755c90bc23a0a97.png)

  

PASTA硬件和软件工具产品售价28,300美元，包括钢制公文包，因此商业版不一定适合新手爱好者。丰田今年早些时候在GitHub上提供了PASTA的开源规范，包括平台本身，CAN（控制器区域网络）ID映射，ECU（引擎控制单元）程序代码和车辆测试的ECU电路图。

  

![](../Images/8d763a0b7224d25925350adcc04dc771.png)

  

  

丰田开发商还设想PASTA用于真实车辆的研发目的：例如，汽车制造商可以测试第三方功能对车辆安全性的影响。
