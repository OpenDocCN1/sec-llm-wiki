# SD 协会剔除华为，新机或无法使用 micro SD 卡

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5NTA3MTk5Ng==&mid=2247484094&idx=1&sn=23af64f21469808e8a6f2a2d3f86be97&chksm=fe76c42dc9014d3bc5a6ad0b9ea4e8d5c4f9be20904265381421be9a681cdcb273b4bdb8b2c0&scene=126&sessionid=1681273982#rd](http://mp.weixin.qq.com/s?__biz=MzU5NTA3MTk5Ng==&mid=2247484094&idx=1&sn=23af64f21469808e8a6f2a2d3f86be97&chksm=fe76c42dc9014d3bc5a6ad0b9ea4e8d5c4f9be20904265381421be9a681cdcb273b4bdb8b2c0&scene=126&sessionid=1681273982#rd)

![](../Images/600b8b9570ef8d884514ddcd42d6094a.png)

5 月 24 日消息，国际固态技术协会（JEDEC）及 SD 记忆卡协会都将华为公司从合作名单中剔除，这将影响华为智能手机的储存方面问题。

国际固态技术协会（JEDEC）表示，已经遵从美国商务部对华为公司发出的禁令，将会对华为及其子公司停止他们参与 JEDEC 的所有活动，直到美国政府停止华为的禁令。对华为最大的打击最新的内存标准，例如标准 DDR5 与 LPDDR5，减少华为产品的更新速度。

![](../Images/c434739dd32d759ea7ba1bcca953f44d.png)

同时，制定 SD 记忆卡标准的 SD 协会，也将华为公司从会员名单中剔除，代表未来的新手机中，华为有可能不能使用 micro SD 记忆卡，虽然华为在 Mate 20 Pro 系列及更新产品中，已经改用全新的 NM 记忆卡，不过因为是新技术，及普及率不高，售价比一般 microSD 记忆卡高，尚未成为主流。
