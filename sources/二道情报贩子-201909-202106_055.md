# 模拟真人的聊天机器人专利，可以离世亲友的语言方式展开交流

微软已经申请了一种智能系统新专利，可基于真人产生的历史或当前数据来构建聊天机器人。

![](../Images/d4ac9cd9a8e4ff5f44bb240a2c660b7a.png)

这款 AI 驱动的聊天机器人能够分析语音、电子消息、社交媒体帖子、图像、以及来自其他人的综合信息。

![](../Images/43a76e161be8b66b1635172682dc7d5c.png)

微软希望是打造一套支持通过文本消息 / 语音命令、促进人与人之间的模拟对话的聊天机器人系统。

  

通过分析人物形象，这套系统还能够创建特定人物的 2D / 3D 画像，此外用户能够对模型展开训练。

  

**因此，在亲友离世前，训练出模型，那么在亲友离世后，可以继续以熟悉的方式与机器人展开交流，该系统或可用于保留相关的回忆。**

![](../Images/8f445aa20ba22aca4cd78a384b225bca.png)

聊天机器人还可应用于过去或现在的具体个人，比如亲朋好友、名人、历史人物、虚构角色、或者随机的一个人，此外用户也可对应创建 / 训练聊天机器人。
