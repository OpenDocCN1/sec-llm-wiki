# 找黑客定位前女友手机结果被骗30多万元

今天（12月5日），扬州警方表示，扬州市仪征小伙王强在网上发帖，寻找“黑客”帮忙定位查人。

王强要找的人是前女友。今年一月，他与女友分手，之后才想起，两人曾有过一笔共同债务，可怎么也联系不上对方。情急之下，他上网发帖，希望有“高人”出手相助。很快，一位名叫孙超的“黑客”就回复了，可以帮忙搞定，但要先交一万多元的保证金。王强照此支付了，几天后，他收到了孙超发来的定位信息，“我只告诉他号码、名字、身份证号码，他就说帮我定位到了，说她在老家淮安。”

王强随即赶赴淮安试图堵截前女友，可扑了空。过了半个月，孙超发来一份公安的公文，说王强被公安盯上了。一听这消息，王强慌了神，这时孙超安抚他，说自己有办法摆平。王强介绍：“他说，我可以帮你弄，但是你要花点钱，因为这个事儿我也头一次 。”

之后，王强陆续向孙超转账十多万，可孙超却称，知道此事的人越来越多，需要继续打点。在支付了三十多万元后，王强感觉不对劲了，拒绝继续转账。这时孙超翻了脸，接连发来了威胁信息。最终，在家人的陪同下，王强向公安部门报警求助。

警方接警后，看了王强提供的公安公文，一下发现了疑点。扬州市月塘派出所副所长洪加祥介绍：“每个派出所它有个代码，分局它前面有分局的代码，但这份‘公文’都不对。”

对方显然是个骗子！通过王强提供的社交账号、转账记录，办案人员很快锁定目标，嫌疑人姓陈，一直以假名“孙超”与王强联系，并用朋友的银行卡进行交易。正当民警准备赶赴南京抓捕时，他们发现，嫌疑人正往仪征方向而来。

  

![](../Images/1988bf120714b7759f9de640fa9ee1d2.png)

  

民警在王强暂住地守株待兔，将嫌疑人陈某一举抓获。经审查，陈某是90后，淮安人，现暂住南京。因沉迷网络赌博，负债累累，便萌生了诈骗的念头。

目前，陈某因涉嫌伪造公安机关法律文书敲诈勒索、诈骗已被警方刑事拘留，案件还在进一步侦办中。（来自潇湘晨报）
