# 从未绑定任何应用、通讯记录仅有三个人，这个手机号如何引起警方注意…

**来源：北方法制报**  
因琐事纠纷，男子拿扎枪杀人。直到被抓前，手机号码不绑定微信、支付宝等日常手机应用，25年活动范围集中在一处固定区域……  
25年来，没有身份证，他一直靠打零工生活。每天担惊受怕，一听到警笛的声音，他都是跑的远远的。在自己最寂寞的时候，只是偷偷地给儿子打个电话，时间不敢太长……  
36岁离家，61岁那年，他终于和四平警方踏上了回乡之路……  
![](../Images/d25cb1563432e92515f13efad31bdf10.png)  
1995年9月25日，四平市铁东区山门镇大洼村一组王某某怀疑嫌疑人齐某在半夜去敲其儿媳妇家门意图不轨。一大早，王某某便拿着一把镰刀来到嫌疑人齐某家质问，由于言语过激，两人顿时撕打在一起。嫌疑人齐某随手捡起地上一块板砖，将王某某拍到，然后又取出自己家干活用的扎枪，扎了王某某几下，仓皇逃跑。  
当时办案民警和法医赶到现场时，被害人王某某已经死亡，而附近邻居也说嫌疑人齐某没有回家，具体去了哪里无人知晓。在办案民警对嫌疑人齐某妻子取笔录时，也没有得到有价值的线索。从此，嫌疑人齐某像人间蒸发了一样，消失得无影无踪。  
2020年5月初，四平市公安局铁东分局按照省厅“云剑-2020”专项行动和四平市公安局相关工作部署，积极开展命案积案攻坚行动，刑警大队抽调精干警力开展研判，多种手段同步上轨，对历年未破刑事案件特别是命案进行认真梳理。  
这起尘封25年的命案进入民警视线。

  

  
**确定嫌疑人身份**  
在发现该起命案积案线索后，四平市铁东区副区长、公安局长李炳辰对刑警大队提出明确要求，循线追踪，决不轻易放弃，务必将嫌疑人缉拿到案。  
2020年5月10日，刑警大队针对嫌疑人齐某杀人案成立专案组，对案件进行反复研究，细致分析。经研判，专案组决定以确定嫌疑人身份信息为首要任务。  
于是，办案民警到山门派出所查询嫌疑人齐某身份信息，但查无此人。通过走访，办案民警找到了当年大洼村的老村长，根据老村长描述，嫌疑人齐某是外来户，在案发前几年，他在山门镇大洼村结婚，育有一子，后来夫妻二人离婚，妻子带着孩子回到山门镇龙王村居住。  
![](../Images/312287dd43461edcefce6cbefb05fb67.png)  
根据这一重要线索，办案民警对山门镇龙王村所有适龄女子逐一查询户籍底册，查询到一名叫杜某丽的女子时，发现其配偶一栏填写的正是嫌疑人齐某。为确保嫌疑人身份信息准确无误，办案民警进一步对其关系人进行研判分析。  
“另外，我们在梳理案件卷宗时发现，当年的侦查员给嫌疑人齐某媳妇取的笔录上面写道，嫌疑人齐某有个妹妹在双辽市，名字叫做齐某秋。”四平市公安局铁东分局刑警大队副大队长冯烁说。  
办案民警立即前往双辽市，决定与当地村委会工作人员一起以疫情信息排查为由，接近齐某秋了解情况。为避免打草惊蛇，办案人员先对齐某秋周边邻居进行走访，打消其戒心之后，再对齐某秋进行入户调查。  
民警在要求齐某秋将家庭成员一一列举，并详细说明现实住址，当问到嫌疑人齐某时，齐某秋称嫌疑人齐某在山门镇大洼村居住，已杳无音信多年，没有联系。  
刑警大队副大队长冯烁说：“调查中民警发现嫌疑人齐某妹妹齐谋秋的户口里有个叫齐某的人，户在人不在，调取户口档案后，发现户口上也没有齐某的照片，当时对齐谋秋询问时，她也闪烁其词。”  
随后民警在双辽市双山镇派出所户籍室查询到嫌疑人齐某的户籍底册，获取其身份证号码，成功确定了命案嫌疑人身份信息。  
嫌疑人齐某的户口和妹妹在一起，可是其妹妹齐某秋却对这个哥哥百般遮掩，这引起了办案民警的怀疑，齐某秋是否知道其哥哥的下落，她到底在隐瞒什么?  
**手机尾号1933**  
**办案民警通过大数据平台获取了嫌疑人齐某妹妹齐某秋、前妻杜某丽、儿子齐某汉、儿媳孙某某等嫌疑人近亲属的手机号、微信号等通讯工具信息，通过民警对上述人员通讯信息认真分析研判，其中一个尾号为1933的手机号引起办案民警的高度警觉，该手机号与齐某汉、孙某某和齐某秋均有通话记录，但次数非常少。**  
**经对该号码进一步分析发现，该号码未绑定微信、支付宝等日常手机应用，活动范围集中在辽宁省大连市一处固定区域，并且除上述几人之外，该号码不与其他人联系。这些细节更加坚定了办案民警侦破此案的信心和决心。在四平市公安局技侦支队的大力帮助下，成功锁定嫌疑人齐某位置位于辽宁省大连市甘井子区。**

  

  
**组织实施抓捕**  
经过近一个月的细心准备，分局刑警大队于2020年5月31日前往大连市对命案嫌疑人齐某实施抓捕。专案组成员在四平市局技术侦查部门全力协助下，组成10人抓捕小组，前往辽宁省大连市甘井子区。  
到达该地区后，办案民警侦查发现嫌疑人在一处农民工公寓内，该公寓共2层，20多个房间，给抓捕工作带来很大困难。办案民警立即联系当地警方，将公寓包围，封锁出口。专案组成员进入公寓逐间逐人排查，在一楼最里面的一个房间内，将潜逃25年的命案嫌疑人齐某成功抓获。  
2020年6月1日晚间，嫌疑人齐某被押解回四平市，经民警讯问，犯罪嫌疑人齐某如实供述了25年前使用扎枪将被害人王某某杀害的犯罪事实。至此，一起长达25年的命案积案成功告破。  
**尾声**  
“当时我没想杀他，他拿着镰刀跑我家去了，还放言要把我小儿子整死。”嫌疑人齐某回忆当年的情形时说：“他把我脑袋砍了，把我手也砍出血了，我就来气了，就用砖头把他脑袋打了，然后取出扎枪扎了他几下。”  
嫌疑人齐某自述，这25年来，没有身份证，他一直靠打零工生活，每天担惊受怕，一听到警笛的声音，他都是跑的远远的。在自己最寂寞的时候，只是偷偷地给儿子打个电话，时间不敢太长，他说这样的生活他也过够了。  
36岁离家，61岁那年，他终于和四平警方踏上了回乡之路……
