# 暗网泄漏的两千万多台湾省公民数据库

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5NTA3MTk5Ng==&mid=2247486731&idx=1&sn=cb940cf2183e3119be0ffddfc8f3879e&chksm=fe76cb98c901428e9bc8bda93a186555420fd28fae53f6155bcd4892dae57102d29167b6a299&scene=126&sessionid=1681273816#rd](http://mp.weixin.qq.com/s?__biz=MzU5NTA3MTk5Ng==&mid=2247486731&idx=1&sn=cb940cf2183e3119be0ffddfc8f3879e&chksm=fe76cb98c901428e9bc8bda93a186555420fd28fae53f6155bcd4892dae57102d29167b6a299&scene=126&sessionid=1681273816#rd)

![](../Images/600b8b9570ef8d884514ddcd42d6094a.png)

  

根据美国网站《CYBLE》指出，专家在暗网（dark web）发现一个数据库，其中包含超过2000万笔台湾户政的详细资讯，包括姓名、地址、身分证字号等等个资恐遭外泄。

![](../Images/e075a4d9688c62be87581655f91b8534.png)

对此，台"行政院"发言人丁怡铭30日表示，可以辨认的资料年份均非最新资料。因此，目前网安与警政单位还在设法辨识真伪，同时也着手进一步了解资料来源是从政府机关或民间机构流出。

  

 

![](../Images/79409048cdbffebf70accc2347417cf0.png)

  

  

《CYBLE》是美国网安情报公司，29日刊出一则关于台湾省超过2000万群众个人资料外泄的文章，内容则指出几周前他们的研究人员在暗网上发现一个泄露的数据库，由一名昵称「Toogod」的人在2019年流出，这个「台湾全国房屋登记数据库」（Taiwan Whole Country Home Registry DB）里面有超过2000万笔纪录，

  

 

数据库大小为3.5 GB，包括以下字段：

全名

完整地址

ID

性别

出生日期

电话号码

  

据这位售卖者称，泄漏发生在2019年。初步分析指出，上一次DOB记录是2008年。但是，应该指出的是，某些记录具有“ NULL /空” DoB记录，因此很难确认最近的记录是什么时间泄露。

  

  

对此，丁怡铭指出，网安单位初步检视后发现内容是很旧的资料，不是户政资料，也不是政府机关流出的资料，依据内容格式，应系综整各类资料来源而成。

  

 

  

此外，丁怡铭指出，而网路流存的版本有2种，一种是整合为一个档案，另一种是依县市分成多个档案。资安单位将持续调查中，有相关资讯会再进一步做说明。
