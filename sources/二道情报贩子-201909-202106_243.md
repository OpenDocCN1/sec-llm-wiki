# 港媒：解放军航母参加军演意图不在东沙岛

日本共同社大约两周前曾报道说，今年8月，解放军将在海南岛附近的南海海域举行一场演习，而演习的目的可能是要夺取目前由台湾方面实际控制的东沙岛。

  

日本共同社的相关消息报道之后，台湾方面立刻召开国防部记者会。 

  

台湾"国防部"发言人史顺文在会上强调，"对周边共军演训与军事动态，"国军"运用联合情监侦作为，对周遭情况都能充分掌握、及时应处"。

  

不过，香港《南华早报》在上周日（5月24日）发表的一篇文章中引述军事观察人士的话说，解放军的航空母舰将参加今夏在南海举行的军演，但是意图不在夺取台湾实际控制的东沙岛和太平岛在内的南海岛屿。

  

一名掌握解放军军方内部消息的人士向《南华早报》透露说，**届时将有一艘航母舰队经过东沙岛，最终抵达位在台湾东南部的菲律宾海的军演地点。**不过目前尚不知道，参加军演的将是辽宁号还是山东号航母。

  

这名消息人士还表示，东沙岛上驻扎的台湾海巡署人员只有200多人，"**解放军动用航母战斗群占领如此小的岛没有意义**"。他还说，登陆训练是解放军的常规训练项目。

  

《南华早报》还引述了台湾前海军新江舰长吕礼诗的分析认为，**中国在南海已经开发了8个人工岛，东沙岛和太平岛都失去了地缘战略的重要性。**

  

《南华早报》引述香港军事专家宋忠平的看法表示，解放军将于8月在南海举行的军演是对5月中旬在渤海湾开始的为期两个半月的军演的延伸。他认为， **"这两场军演是为了警告蔡英文和美国，解放军在涉及台湾和南海议题上已做好充分准备"。

今年5月11日，中国海事局发布通告，唐山港附近渤海海域于14日起举行实弹射击，为期两个半月。通告指出，5月14日零时至7月31日24时，请所有无关船舶和人员停止在此时间段、此管制区域内的一切活动。
