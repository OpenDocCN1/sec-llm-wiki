# "区块链+垃圾分类" 模式成功落地应用

# 近期，银川市西夏区三个小区试行了“区块链+垃圾分类”模式，相比于传统的只有投放资源垃圾才可以获得积分的模式，通过区块链技术建立社区消费链积分鼓励机制，让积分当钱使，可以更有效解决居民参与垃圾分类动力不足的问题。

  

![](../Images/1aa6bba3325733d7ae7feac393655f9c.png)

#   

# 垃圾分类在银川市推广以来，实行了通过资源垃圾称重兑换积分，按要求投放积累积分等模式，但存在积分价值较低、积累速度较慢、只能在社区超市兑换商品等现象，导致群众参与热情不够。西夏区西翠芳庭、丽子家园、建工家园三个小区试行了“区块链+垃圾分类”模式，业主只要获取了绿色业主的资格，不仅可以通过正确投放垃圾获取积分，还可以在社区周围各个商家消费源源不断地获取积分，绿色积分不仅可以继续当钱花，还可以用于交纳物业费、停车费、水电费等，大大激发了社区业主主动参与垃圾分类的积极性、主动性。  
  
通过这种模式，不仅驱动了业主主动分类投放垃圾，争当“绿色业主”，还解决了物业公司收取物业费难、停车费难的问题，同时还刺激了社区商业的活力，可谓“惠民又扶商”。相对于以往宣传难、驱动难、监督难，只有少部分老年人参与的情况，该模式年轻人参与度更高、更活跃、自驱性更强。  
  
目前来看，这恐怕是首个正式在中国落地到民生的区块链技术。  

  

# 在此之前，国际上一些企业就已经有将区块链技术用于垃圾分类上的尝试，加拿大初创公司Plastic Bank试图利用分布式分类账本技术（DLT）解决塑料垃圾污染问题。据悉，该公司与美国科技巨头IBM合作开发了一个区块链应用程序，用数字通证奖励人们收集塑料瓶并允许通证兑换商品或现金。这种被称为社会塑料的废物，随后会被出售给全世界的公司。  
  
而之前，在国内也有记者在雄安发现中心附近正在兴建的配套设施停车场中摆放了数十台智慧垃圾收集器样机。新"垃圾箱"是采用了LED屏和二维码以及区块链技术应用的箱体。去年，杭州市发展规划研究院也透露其正与杭州区块链技术与应用联合会合作，探索将区块链技术应用到垃圾分类项目治理当中。  
  
那么区块链技术到底是怎么参与到垃圾分类中来的呢？它能对垃圾分类产生怎样的影响？  
  
**在垃圾分类中有这样一条生产链：社区→减量中心→资源回收利用公司→处理，在这些主体，包括环境集团以及政府之间构建一个区块链生态圈，在链条各主体当中，以信息传递为基础，进而产生价值传递和信任传递，并发行一种Token（代币），用于支付与奖励。**  
  
基于区块链技术在互联网+垃圾分类智能回收的解决方案，通过在社区放置智能垃圾分类回收箱，配备每个市民可方便登录的软件平台。居民使用手机扫描回收箱登录，将垃圾投入到箱体中，根据投放量多少，获得远高于市场价值的积分激励，积分可在社区线下实体店或线上网店中，兑换生活用品。  
  
区块链技术直接参与垃圾分类回收的各社区物业、环境集团、政府监管部门等，共识存储垃圾处理全量数据，这样就能清楚知道垃圾的总量、流向等；与此同时，用户和政府职能机构按角色进入公有链，公有链作为“核心业务数据”的持久层，存储公民信用积分和Token交易流通的数据信息。  
  
通过这个区块链技术解决方案，可以清楚明白垃圾是怎么处理的，处理垃圾花了多少钱，而老百姓因为有Token奖励也会更加积极参与垃圾分类。
