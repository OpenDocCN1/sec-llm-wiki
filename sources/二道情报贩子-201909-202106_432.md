# 英国工党系统遭受大规模DDOS网络攻击袭击

工党（Labour Party），英国议会第二大党 。英国两大主要执政党之一。英国左翼政党。

![](../Images/c90101416e9694ef82b9df5a8805e888.png)  

  

工党受到了它所谓的“复杂而大规模的网络攻击”的打击。

  

工党发言人告诉新闻媒体，网络攻击影响了党的网站以及在线竞选工具和平台，这些工具和平台昨天离线，而IT和数字团队正在努力使事情恢复正常运行。

  

网络事件的性质尚未完全揭露，但我对该党表示“采取迅速行动”，并且由于该党的“强大安全性”而使攻击失败。

  

![](../Images/79f82e8a91d7b4aed494e3fe72688a39.png)

  

工党说：“我们所有平台的完整性得到了维护，我们有信心不会发生数据泄露。”

  

声明补充说：“我们的安全程序放慢了我们的某些竞选活动，但是今天早上恢复了，我们已经恢复了全速。”  

  

据报道，该方受到分布式拒绝服务（DDoS）攻击的攻击，该攻击使用受感染计算机网络“僵尸网络”向服务器发送请求，并使服务器不堪重负。

  

 此类攻击的复杂程度可能有所不同，但通常很容易缓解。网络记录显示，工党是Cloudflare的客户，该公司为Web的很大一部分提供了DDoS保护服务。  

  

该公司通过提供所需的额外容量，过滤流量以仅处理合法请求并将网站的“缓存”版本存储在自己的服务器上，从而保护客户免受DDoS攻击。   

  

即使DDoS攻击成功，它们也不会造成强制停机时间的影响，因为目标会等待攻击结束，或者确保额外的带宽来处理新流量。最简单的说，DDoS攻击很难与合法的流量高峰区分开来，就像电影网站在放映新电影时崩溃一样。   

  

DDoS攻击便宜的很。多个犯罪分子提供“ DDoS即服务”，并在其僵尸网络上出售服务。2017年的一份报告发现300秒攻击，总带宽125Gbps，5欧元; 一次较长的攻击（旨在使网站离线一个小时）可以花费90欧元购买。其他甚至更便宜，可提供三个小时的停机时间（60美元）。布莱恩·希金斯，在安全专家Comparitech.com说，袭击“不正常代表数据或信息的任何威胁，可以被抵御来自很容易，如果受害人在地方强大的网络安全政策恢复。鉴于英国当前的政治形势，工党成为袭击目标毫不奇怪。”不知道这个专家说什么鬼

  

该事件已报告给英国国家网络安全中心。

  

**这次袭击是在大选运动的初期进行的，英国定于12月12日进行民意调查**
