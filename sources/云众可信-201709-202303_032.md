6月15日-6月17日

  
  
2022 IBG技术节“云上派对”成功举办  
活动历时三天【攻防日·产品日·安服日】每天一个主题数位安全专家大咖线上齐聚十三大多维度技术干货分享启明星辰IBG为安全人奉上一场高水准的技术狂欢盛筵  
  
  
  
  
  
  
  
  
  

  

  
  
  

“为了促进团队成员间的技术经验交流，展现IBG的创新技术力与产品力，传递‘创新共享’的活动精神，增进与用户及生态合作伙伴的互动连接，特此举办本届2022 IBG技术节，打造一场云上派对，合力共建安全技术新生态。”启明星辰IBG负责人马里奥在开幕致辞中表示。

  

![](../Images/37400dadf3ae9582df5eba767512ef5a.png "IMG_9863 2.JPG")

  

启明星辰IBG技术节自2021年举办以来，受到了企业级用户、安全实验室、安全团队、安全合作伙伴、安全技术从业者等多方关注，与会嘉宾、议题质量不断提高。此次“云上派对”为了更好的进行技术干货分享，聚焦当日主题，充分展开多维交流，为技术节注入了新鲜活力。

  

![](../Images/dbf5d93d2394f1cc228811d2fa142a45.png "IMG_9858 2.JPG")

  
  
  
  
  
  
  
  
  

  

  
  
  
  
  
  
  
****  
**攻防日：****安全实验室大咖****倾囊相授******

  

  

SecIN安全技术社区联合启明星辰猎豹安全实验室、启明星辰太白安全实验室，以“攻防技术”为主题，对常态化安全运营模式下的边界思考、Vcenter后渗透利用、Meterpreter source code 方向进行探讨，分享最新的技术成果与实践。

  

![](../Images/a459e0d280679a25adb80de21119c160.png "攻防日.png")

  

在直播的交流与碰撞中，讲师们营造了良好的技术分享氛围，同时将“保持热爱、不断探索”的hacker精神向年轻人传递。

  

![](../Images/dfc5d842568aed07e5bd057d648be9c0.png "IMG_9862.JPG")

**产品日：创新产品****技术成果深度交流****

  

  
  
  
  
  

![](../Images/63c0674314f991a7eb5a9a299850addd.png "IMG_3339.JPG")

  

来自启明星辰IBG云众可信、云子可信的主要产品负责人在会上发表了议题演讲。议题方向从网络安全靶场、攻防对抗发展趋势到企业容勒索数据安全服务探索，从实战攻防产品技术创新到敏捷实践经验分享，覆盖IBG全线产品，深度结合应用实践场景，分享最新研发成果。

  

![](../Images/85deaeff47a26f24d23cba93ebf12451.png "IMG_3318.JPG")

  

  
  
  
  
  
  
  
  
  

  

  
  
  
  
  
  
  
****  
**安服日：安全服务****实战经验干货共享******

  

  
  
  
  
  

安全服务作为安全业务中重要的一环，压轴登场。在安服日中，多位安全专家针对安全服务前景与未来、安全服务实战经验、安全服务体系建设等方面进行了详细的解读与分享，保持着与“黑客”交个朋友的初心，为安全从业者带来新的思考，帮助安全从业者打开新的视角。

  

![](../Images/295a030e12d1b24cdf02d682b01e7132.png "IMG_3369.JPG")

  
  
  
  
  
  
  
  
  

  

  
  
  
  
  
  
  
****奖品SHOW TIME****

  

  
  
  
  
  

启明星辰IBG创新事业部一直以“创新”为内在驱动力，本次“云上派对”设置了趣味互动环节。启明星辰IBG云众可信文化周边的造物工坊“云众造物”线上展厅，首次重装亮相。参会者可以线上沉浸式自由观看由“云众造物”出品的所有创意新颖、好玩有趣，设计精美的文化周边，同时，还可以倾听线上讲解，了解周边的创作背景及设计理念。
