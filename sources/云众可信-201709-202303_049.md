# “网络安全靶场”获评“金智奖”优秀解决方案，戳中用户痛点

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NDU3Mzc5OA==&mid=2247487461&idx=1&sn=96df81838c6347586aade5fdd19759a7&chksm=ce660fecf91186faf2619f5f5dfd1dc4e745929fe21478b3926ccb2ac365de272ba9b5b4c9fe&scene=126&sessionid=1681309462#rd](http://mp.weixin.qq.com/s?__biz=Mzg2NDU3Mzc5OA==&mid=2247487461&idx=1&sn=96df81838c6347586aade5fdd19759a7&chksm=ce660fecf91186faf2619f5f5dfd1dc4e745929fe21478b3926ccb2ac365de272ba9b5b4c9fe&scene=126&sessionid=1681309462#rd)

  

辛丑年末启明星辰**网络安全靶场解决方案**荣获**中国网络安全与信息产业金智奖**为即将到来的新春佳节再添一分喜气

  

![](../Images/5e5cdc98649308849b28b7563d70b94c.png)

  

本届“金智奖”共有近百家参选企业，120余位专家评委、50余位媒体评委以及1000余位专业评委共同参与评选。最终，启明星辰网络安全靶场解决方案凭借**灵活的模块化设计、大量的综合资源和用户的认可**，获得“优秀解决方案奖”。

  

  

![](../Images/dcdf9647a36a74176b42bc5cce73f823.png)

  

**三大系统支撑 满足实战诉求**

  

启明星辰网络安全靶场解决方案（以下简称“方案”）由靶标仿真平台及培训教育、攻防/应急演练、测试验证三个系统组成，模块化设计灵活组合，可为用户提供“**平台+场景+可视化**”的试验和训练支撑。通过虚拟化、虚实结合仿真、安全编排、测试评估、知识图谱等技术，为用户构建可信、可控、可操作、高度逼真的仿真环境，提供近似实战的网络安全培训教育、实训竞赛、攻防演习、应急演练、工具测试评估等各类应用场景，以满足其人才培养、提升测试验证效果效率及在仿真环境开展大规模实战化演练的诉求。

  

  

![](../Images/dcdf9647a36a74176b42bc5cce73f823.png)

  

**快速集成交付 有效提升效率**

  

方案能够助力用户快速搭建高度逼真的仿真环境，同时满足培训、演练及测试验证需求，采用模块化设计，快速集成交付。靶标仿真平台具备主机仿真、网络设备仿真、安全设备仿真、网络仿真等能力，对特定的行业设备可支持实物接入与组网。平台采用画板技术，简单拖拽即可完成环境构建，支持单场景下万级节点复杂异构网络快速生成及分钟级的资源回收、重新配置，有效提升试验效率。

  

  

![](../Images/dcdf9647a36a74176b42bc5cce73f823.png)

  

**全面平衡攻守双方 助力优化应急响应**

  

在实战化攻防演练的场景下，方案可以实现对攻防双视角全方位的管理与感知。攻方视角，侧重于攻击行为的监控与对违规行为的阻断，多维度态势展示，保障演习全程可视可审，特色复盘功能，有效支持演练整改及能力提升。守方视角，侧重于精细化的应急处置流程管理，为用户优化应急响应流程、考核、复盘总结提供有力支撑。

  

  

![](../Images/dcdf9647a36a74176b42bc5cce73f823.png)

  

**丰富资源支撑自由环境 实践案例印证客户认可**

  

方案具备大量综合资源，包含漏洞库、攻防工具库、测试工具库、攻防策略库等，能为使用人员带来极大的攻防选择面，而靶标库、场景库、代码库等则能让使用者更自由地搭建不同类型的靶场环境。当前该解决方案已具备大量实践案例，含中国电子技术标准化研究院、国家工业信息安全发展研究中心等政企单位。

  

![](../Images/21b1025a211d4f0b62ed76074bbbbf69.png)

  

荣誉既是认可也是激励，启明星辰将继续秉持“领航信息安全，护航数字中国”的使命愿景，充分发挥技术优势，坚持自主创新，让网络安全和信息化行业在“星辰”的光辉下不断前行，为数字中国的建设添砖加瓦。

  

**关于云众可信**
