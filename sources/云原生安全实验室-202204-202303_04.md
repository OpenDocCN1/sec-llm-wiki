# 云原生安全实验室 | 成员单位风采之梯度科技

在企业数字化转型的浪潮下，云原生作为基础底座推动了云数智深层次融合发展，成为企业数字化转型的新动力，但技术架构的重塑和应用模式的变革引入了新的安全风险。据中国信息通信研究院发布《中国云原生用户调查报告（2022年）》数据显示，安全性是企业云原生化转型的最大顾虑，**云原生安全建设成为企业云原生化转型的必需项。**

  

在此背景下，由中国信息通信研究院云计算与大数据研究所、清华大学和腾讯云鼎实验室牵头发起的**云原生安全实验室（Cloud Native Security Laboratory，简称CNSL）**于2022年6月15日在2022云原生产业大会上正式成立, 以期推动云原生安全技术创新、标准建设、供需对接与产业交流，从解决企业上云实际问题出发，进一步推动云原生产业健康有序发展。

**成员单位风采之梯度科技**

广西梯度科技股份有限公司（以下简称“梯度科技”）是国内最早研发云平台产品的云原生服务提供商之一，面向客户提供云数平台产品和服务。

  

梯度智能云平台是自主研发，以容器编排、服务网关、服务器无感知等云原生生态技术为基础的新一代云平台，帮助客户屏蔽基础设施差异，池化管理资源，搭建微服务架构，实现各类应用无缝迁移上云，提升应用迭代效率。平台主要特点如下：

  

**云原生能力：**

基于Kubenertes技术生态，实现容器编排调度、集群资源池化、多租户体系、服务网关等云原生体系核心能力。提供物理机、虚拟机、私有云、公有云统一接入能力，屏蔽应用对基础设施层的依赖，满足开发测试运行环境统一，服务快速部署等需求。

  

**微服务治理：**

搭建新一代微服务架构，实现应用微服务化管理，结合分布式运行时概念，将分布式能力服务化，解决传统单体应用升级难、管理难等痛点，满足应用迭代需求。

  

**DevOps自动化流水线：**

以标准化流程方式灵活的组合代码检查、测试、编译等步骤，实现持续集成、持续验证、持续部署，同时与在线IDE开发环境融合，提供开发阶段的持续集成能力，支持代码自动化测试，实现研发、测试、运维一体化。

  

**容器化轻量虚拟机：**

基于容器技术封装传统虚拟化能力，实现轻量化的容器虚拟机，在复用同一套基础设施环境的基础之上，既能满足传统应用上云需求，又能享受容器化实例弹性伸缩等灵活性优势。

  

**函数计算：**

将函数服务能力抽象化、服务化、解耦化，提供计算资源管理、计算资源利用、标准化函数模板管理等能。能够屏蔽基础设施层的依赖，实现底层基础设施管理，提高用户开发、部署、运维效率。

  

**轻量级边缘计算：**

平台基于云原生体系实现轻量级边缘计算，支持纳管海量异构边缘设备，高效接入多种物联网协议数据，提供轻量级边缘容器计算能力，助力用户实现边缘智能。

  

**分布式计算框架：**

提供基于进程级的分布式计算能力，具备高性能、易使用、分布式、弹性等特点，支持快速地实现任务调度和数据传输，支持训练和推理大规模的深度学习模型和强化学习模型，支持科学计算、模拟和渲染等计算密集型任务。

  

梯度智能云平台通过云原生技术助力企业应用上云、降本增效，业务领域涵盖政务、科研、金融等诸多场景。为翼支付、国防科技大学、广西壮族自治区商务厅等客户降低60%以上IT使用成本，提升50%以上的运维效率，推动客户数字化转型。
