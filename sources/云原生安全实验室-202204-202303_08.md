# 云原生安全实验室 | 成员单位风采之中移信息

在全球数字经济快速发展，企业数字化转型的浪潮下，云原生作为新一代云计算关键技术带动了技术架构、应用效能与云化效益的全方位提升，作为基础底座推动了云数智深层次融合发展，成为企业数字化转型的新动力。但技术架构的重塑和应用模式的变革引入了新的安全风险。据中国信息通信研究院发布《中国云原生用户调查报告（2022年）》数据显示，安全性是企业云原生化转型的最大顾虑，**云原生安全建设成为企业云原生化转型的必需项。**

  

在此背景下，由中国信息通信研究院云计算与大数据研究所、清华大学和腾讯云鼎实验室牵头发起的**云原生安全实验室（Cloud Native Security Laboratory，简称CNSL）**于2022年6月15日在2022云原生产业大会上正式成立, 以期推动云原生安全技术创新、标准建设、供需对接与产业交流，从解决企业上云实际问题出发，进一步推动云原生产业健康有序发展。

**成员单位风采之中移信息**

中移动信息技术有限公司承担着中国移动IT领域的全网31省的统一指挥、系统统筹规划、资源统筹配置和能力统筹运营，负责集中化IT系统、智慧中台、大数据的规划、建设和运营支撑等工作，是中国移动IT领域的专业机构。截止目前，建设的业务和管理支撑系统承载全网用户近10亿；梧桐大数据平台日处理15PB，累计价值数据超230PB，规模全球领先；自主研发云原生、AI、区块链、IPA等核心技术能力已迈入行业前列。

  

中国移动磐基PaaS平台作为基础技术平台向应用提供服务化的支撑能力，以服务化的形式提供弹性可扩展的基础技术平台，适配底层各类基础设施IaaS环境，应用基于容器编排、微服务治理和DevSecOps研发交付一体化流程，实现平台级服务的资源共享，将集中化支撑系统打造为一个完全适配敏捷开发和智能化运营的平台架构。针对海量的镜像规模，海量的工作负载数目，极大的业务复杂度，与众多繁杂的微服务，如何保证集群的安全运营，持续提高安全水位线，是其面临的极大安全挑战。磐基PaaS平台的容器云安全构建从以下几方面实现：

  

1

**安全内生化**

集中化支撑系统基于中国移动磐基PaaS平台开发部署。磐基PaaS平台不仅仅提供基础运行环境，还内置各类安全能力与安全工具，从可用性、可持续性、快速响应能力、私密性等层面建立无处不在的网络安全，从而降低网络攻击风险，真正保证业务安全。

2

**安全服务化**

构建以PaaS平台方式交付的安全服务，降低集中化支撑系统在安全服务上的投资成本，提高安全服务效率和质量，集中化支撑系统以及其他业务系统可以按需获取所需安全能力，包括持续的服务更新、更高的安全专业知识、更快用户配置、较少的管理开销等。

3

**能力开放化**

磐基PaaS容器安全防护平台提供集中化支撑系统业务安全监测的基础服务能力和行业服务增值能力，客户可自定义选取安全服务和获取自身安全风险数据。

4

**监测智能化**

基于动态学习业务系统进程与网络流量的方法，采用机器学习技术，构建安全基线模型，实现风险识别和风险态势感知。配合传统基于规则的分析识别技术，加上机器学习技术较全面发现安全漏洞和风险。

5

**流程敏捷化**

基于安全左移的思路，实现DevSecOps，在整个生命周期中支持多个卡点，将风险尽早暴露，降低安全运维的成本。安全卡点包括“代码安全检查”、“编排文件扫描”、“镜像安全扫描”等。安全左移能够尽早发现问题，有助于降低修复成本。

  

中国移动磐基PaaS平台提供基础运行环境，内置各类安全能力域安全工具，已完整覆盖容器生命周期中三大关键阶段，即容器构建时的镜像安全、容器部署时的安全配置（基线检查）和容器运行时的入侵检测和防御。从可用性、可持续性、快速响应能力、私密性等层面建立无处不在的网络安全，从而降低网络攻击风险，真正保证业务安全。
