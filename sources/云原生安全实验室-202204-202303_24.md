# 云原生安全实验室欢迎第二批成员加入！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NTkxNDMwMQ==&mid=2247484570&idx=2&sn=4ae6440967ede909cde80757efead7ab&chksm=ce539848f924115e2d5f1d5f522f7692d04e1e2a2a8c8a57fb2f320abc648a50f248eb21cb9d&scene=126&sessionid=1681576034#rd](http://mp.weixin.qq.com/s?__biz=Mzg2NTkxNDMwMQ==&mid=2247484570&idx=2&sn=4ae6440967ede909cde80757efead7ab&chksm=ce539848f924115e2d5f1d5f522f7692d04e1e2a2a8c8a57fb2f320abc648a50f248eb21cb9d&scene=126&sessionid=1681576034#rd)

  

云原生安全实验室（Cloud Native Security Laboratory，简称CNSL）由中国信通院牵头组建，实验室旨在搭建行业沟通与合作促进平台，汇聚产学研用多方力量合力推动云原生安全生态建设，加速技术普惠化，解决企业云原生化转型的安全顾虑，为新形态下的国家信息安全战略保驾护航。

![](../Images/d5dbc0661b065f4275027022286f9230.png)

2023年1月9日，中国信息通信研究院主办的云原生产业联盟年会在北京召开，大会上正式公布了云原生安全实验室新一批成员单位名单。

  

![](../Images/41ae6ec7b6d7d4d64e8bc7f410f7215b.png)

  

**实验室新增成员单位名单如下：**

**副理事长单位**

华为云计算技术有限公司

**成员单位**

中移动信息技术有限公司

联通数字科技有限公司

北京火山引擎科技有限公司

深信服科技股份有限公司

中电云数智科技有限公司

亚信科技（成都）有限公司

北京哈希安全科技有限公司

上海帆一尚行科技有限公司

厦门服云信息科技有限公司

北京宝兰德软件股份有限公司

鼐特（北京）信息技术有限公司

普元信息技术股份有限公司

广西梯度科技股份有限公司

快页信息技术有限公司

上海安般信息科技有限公司

  

云原生安全实验室将继续以开放心态联结产、学、研、用各方力量，共同推进云原生安全生态建设，加速技术普惠化，解决企业云原生转型的安全顾虑，为新技术形态下的国家信息安全战略保驾护航。
