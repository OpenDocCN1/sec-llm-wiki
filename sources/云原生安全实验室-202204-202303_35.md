# “原”动力第8期 | 云原生API安全治理专题沙龙成功举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NTkxNDMwMQ==&mid=2247484560&idx=1&sn=73d32178fd224cf814ff75db60ca79f9&chksm=ce539842f92411549eabd7664506e7534d866a82de28d6c9c4ff3ac6328ba64ac1dfe63ada6e&scene=126&sessionid=1681576038#rd](http://mp.weixin.qq.com/s?__biz=Mzg2NTkxNDMwMQ==&mid=2247484560&idx=1&sn=73d32178fd224cf814ff75db60ca79f9&chksm=ce539842f92411549eabd7664506e7534d866a82de28d6c9c4ff3ac6328ba64ac1dfe63ada6e&scene=126&sessionid=1681576038#rd)

  

随着企业用云上云进程的不断深入，云原生架构下信息流通以及各种程序、应用和系统之间的连接调用关系越来越复杂，API数量激增。Gartner在近日发布的《Hype Cycle for Application Security, 2022》报告中，再次阐明**API作为企业数字化转型的重要基础设施已逐渐成为攻击者的主要攻击目标。**

  

为助力企业挖掘典型云原生API安全风险，探索云原生架构下API安全防护治理的最佳实践路径，洞察云原生API安全发展趋势，由中国信息通信研究院主办，云原生安全实验室承办的**“原”动力第8期—云原生API安全治理沙龙**于11月16日下午成功举行！

  

本次沙龙邀请到了来着腾讯、瑞数信息、绿盟科技、星阑科技等单位的云原生安全领域专家，共同探讨云原生API安全治理的防护思路、研究成果和发展趋势，并分享了信通院在云原生安全领域的最新研究成果和工作计划。

  

![](../Images/201dc816bea04463e257767cd4e17b71.png)     

首先，**中国信通院云大所云计算部主任马飞**为沙龙开场致辞。马主任对参与嘉宾和线上观众表示了欢迎，介绍了在刚刚结束的二十大上，习总书记在报告中指出要加快建设数字中国和网络强国。云计算作为数字中国和网络强国的重要技术底座，正处于业务创新驱动发展的新周期，新安全需求涌现。并从国家政策支撑、产业研究成果、标准体系建设和平台建设等方面介绍了中国信通院在云原生安全领域开展的工作。同时希望通过本次沙龙能够与业界同仁共同推进云原生安全技术体系的持续完善。

![](../Images/13ac85a3e0889403548a3b4a4af98635.png)

  

     

其次，**中国信通院云大所云计算部高级业务主管杜岚**介绍了在云原生安全领域的相关工作并对云原生API安全治理标准进行了解读。在政策支撑和产业研究方面，信通院全面支撑国家、部委的相关政策文件的制定；在平台和生态建设方面，2020年成立了云原生安全工作组，今年6月联合清华大学、腾讯云发起成立云原生安全实验室；在云原生安全标准制定和测试评估体系建设方面，团队从2019年开始启动容器安全的标准制定，至今已经建立了相对完善的云原生安全标准评估体系。在标准解读环节，杜岚老师从API资产管理能力、API风险评估能力、API权限控制能力和API安全监测能力等方面对API安全治理标准进行了详细介绍。

![](../Images/4b096e1bd26f0d219d4194ffbffba26e.png)

  

     

再次，**腾讯安全高级产品经理马子扬**分享了云原生视角下的API安全的最佳实践。随着API 数量呈指数级增长，API 安全的潘多拉魔盒被逐步打开，API 生产力的发展与 API 的安全需求之间形成主要矛盾。马老师对比了传统业务中以边界防护为主API安全和云原生技术架构下API快、多、平的差异，阐述了云原生下API安全治理的五大现状及面临的四大安全挑战，并从安全治理需求、安全运营保障、API安全检测、流量快速纳管、流量共性提取等维度给出了API安全治理的实践方案。

![](../Images/b7e6550c69ed81c16c7a42aafd1a1035.png)     

然后，**瑞数信息技术（上海）有限公司技术总监吴剑刚**进行了从API治理的角度看API安全的主题演讲。与大家分享了为什么需要API治理、如何构建云原生环境下的API安全以实现从环境感知、资产发现、异常监测到安全保护的API安全防护闭环，提出了构建集监测和管控于一体的API安全防护架构的七大关键点，并结合真实用户治理经验给出了解决云原生环境中API管控的安全实践。

![](../Images/80832f01209de11757d39b0de3ff466e.png)     

而后，**绿盟科技集团股份有限公司高级安全研究员浦明**分享了API安全五大类常见风险，包括应用暴露API过多导出的风险、缺乏可见性导致的风险、应用架构变化导致的风险、东西向流量难以防护的风险和其他风险；同时分别对Kubernetes场景和Service Mesh场景给出了API安全防护思考；在安全实践部分，浦明老师从部署方式、性能优化等维度全面介绍了服务网格API安全解决方案和节点API安全解决方案。

![](../Images/7338d467e999609eca7137ca72d50ebe.png)     

最后，**星阑科技产品总监杨旭鹏**进行了云原生API安全解决方案的主题分享。结合目前API安全现状，分别从数据泄露、行业监管、攻防实战等角度对API安全的重要性进行了解读，同时分享了基于API全生命周期安全防护体系的API安全解决方案，阐述了API安全从0到1需要做的三件事，包括理清API资产、检测API风险和管理API数据。

![](../Images/7a99109f8f775e5e521838b58f1876a9.png)     

非常感谢大家对本次沙龙的关注，也非常感谢各位专家的精彩分享，当前我国云原生产业正处于蓬勃发展阶段，行业应用需求明显，技术产品走向多元，标准体系建设加速，希望“原”动力沙龙能够为大家提供一个积极良好的技术交流平台，推动云原生产业发展！
