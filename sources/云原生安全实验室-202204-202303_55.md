# 开放融合•共筑生态繁荣！“云原生安全实验室”筹备会成功举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NTkxNDMwMQ==&mid=2247484537&idx=2&sn=13091d009e3ff9502d8601e7dbc2e25d&chksm=ce5398abf92411bdfdae30867909c59b584a12ab7cf9d479bcce84f74ff5baf549a10dff5553&scene=126&sessionid=1681576046#rd](http://mp.weixin.qq.com/s?__biz=Mzg2NTkxNDMwMQ==&mid=2247484537&idx=2&sn=13091d009e3ff9502d8601e7dbc2e25d&chksm=ce5398abf92411bdfdae30867909c59b584a12ab7cf9d479bcce84f74ff5baf549a10dff5553&scene=126&sessionid=1681576046#rd)

在全球数字经济快速发展，企业数字化转型的浪潮下，云原生作为新一代云计算关键技术带动了技术架构、应用效能与云化效益的全方位提升，作为基础底座推动了云数智深层次融合发展，成为企业数字化转型的新动力。但技术架构的重塑和应用模式的变革引入了新的安全风险，随着云原生应用的不断深入，云原生安全开始受到广泛重视。当前，云原生安全技术创新涌现、建设需求激增、市场规模成倍增长，但产业整体尚处于发展初期，体系化的技术方法、标准化的评估体系、可落地的建设路径都有待完善。

  

在此背景下，**中国信息通信研究院**联合**腾讯云**和**清华大学**拟发起成立**“云原生安全实验室”**（Cloud Native Security Laboratory，简称“CNSL”），旨在搭建行业沟通与合作促进平台，汇聚多方力量合力推动云原生安全生态建设，推广新安全理念、开展新技术研究、探索新应用模式、打造新安全影响力。发起单位于2022年1月25日成功召开了“云原生安全实验室”筹备会，来自知名云服务商、安全企业、高校科研院所和行业用户的50多名专家共同围绕实验室目标愿景、组织架构、工作计划以及参与方式等展开交流。

**一、实验室宗旨**

以开放心态联结产、学、研、用各方力量，共同推进云原生安全生态建设，加速技术普惠化，解决企业云原生转型的安全顾虑，为新技术形态下的国家信息安全战略保驾护航。
