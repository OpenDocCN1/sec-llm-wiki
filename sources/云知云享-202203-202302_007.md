# **战前“踩点”-信息收集**

众所周知，信息收集是渗透测试“核心灵魂”，相当于战斗中的“战前踩点的行为”熟悉了战场，熟悉了敌人的情况，才能更好地赢得战斗的胜利，俗话说：知己知彼，百战百胜，这就更说明了信息收集的重要性。无论是攻防演练，项目中的漏洞挖掘，其实都像是在进行一场没有硝烟的战斗，信息收集就需要我们尽可能更多的获取到情报，扩大攻击面，为后续的漏洞挖掘，深入攻击的开展做准备，下面就来简单分享一下渗透测试中的战前“踩点”--信息收集。

**“踩点”需求--信息收集需要收集什么？****whois查询：**可以得到域名的注册人信息：邮箱，电话等；子域名查询：子域名也就是二级域名，是指顶级域名下的域名。子域名查询可以扩大攻击的范围，一般情况下，顶级域名与其子域名会同属于一个公司或者组织。**指纹识别：**识别出目标的CMS系统，服务器，开发语言，操作系统，CDN，WAF的类别版本等等，找到一些历史通杀的漏洞。**端口探测：**探测其开放的端口，一个IP可能会开放多个端口，搭建不同的网站，有些危险端口（如：445 SMB永恒之蓝，817 Rsync 未授权访问漏洞，1433 MSSQL (暴力破解)，3306 MySQL （暴力破解），3389 远程桌面等等。）可直接进行利用入侵**目录扫描：**扫描网站的目录结构，可能访问到编辑器的目录，废弃的页面，或者robots.txt等。**旁站查询：**查询同IP站点，可能还会存在别的网站，一般属于同一个公司或者同一台服务器，这样如果主站的防御策略很强时，可以尝试对旁站进行渗透攻击。**C段查询：**同一C段下的IP地址可能会同属于一个公司或者同一个组织。

注意：如果说一个网站使用了CDN的话，旁站扫描、C段扫描可能误报对收集信息的结果影响。（CDN，全称内容分发网络（ContentDeliveryNetwork），可以简单地将其理解成一个离你很近的、可以从上面获取到完整的原始数据的服务器，它会定期和拥有原始内容的服务器进行同步，保证用户可以从上面获取到最新的内容。）
