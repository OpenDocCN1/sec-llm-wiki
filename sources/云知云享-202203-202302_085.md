**受 SQL 注入漏洞影响的流行 Django Web 框架。立即升级！**

Django是一个免费且开源的、基于 Python 的 Web 框架，遵循模型-模板-视图 (MTV) 架构模式。Django由独立组织 Django Software Foundation 维护。

  

![](../Images/e7cd2e028f3413af2e6a40f494ffb126.png)  
该框架的最新版本Django 4.0.6 和 3.2.14解决了跟踪为 CVE-2022-34265 的高严重性 SQL 注入漏洞。根据发布说明，该漏洞存在于 Trunc() 和 Extract() 数据库函数中，如果将不受信任的数据用作 kind/lookup\_name 值，则可以利用该漏洞。对这些功能执行输入清理可以降低利用漏洞的风险。“如果将不受信任的数据用作 kind/lookup\_name 值，Trunc() 和 Extract() 数据库函数就会受到 SQL 注入的影响。” 读笔记。“将查找名称和种类选择限制到已知安全列表的应用程序不受影响。”开发团队还在升级到最新版本之前发布安全补丁作为临时解决方案。**来源：securityaffairs**
