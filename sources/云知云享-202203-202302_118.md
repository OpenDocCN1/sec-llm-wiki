# **原意****：**人类为了产肉而驯化饲养饲养的鸡。

# **肉鸡：**肉鸡在网络安全领域是一种很形象的比喻，比喻那些被黑客控制的电脑，肉鸡还称为“傀儡机”“僵尸主机”，黑客可以随意操纵并利用它做任何事情，是僵尸网络的重要组成部分，常被用作DDOS攻击，是中国特有网络黑话。据信“肉鸡”为“肉机”的谐音，意思是人为刀俎我为鱼肉，任人宰割的意思。“肉鸡”可以是被控制的Windows系统、UNIX/LINUX系统等，可以是个人电脑、企业电脑、学校电脑以及企业、学校、政府服务器等。

![](../Images/3db741b8674587cc2f6a555a8cc04063.png)

  

**肉机被控三要素：**IP地址、用户名、密码

![](../Images/0aec6db79d4449fee624bdc6a987e248.png)

# **应对策略**  

**事前检测及预防：**

关闭不必要端口

卸载不必要程序

定期安全检查及加固

**事中防御：**

入侵检测防护设备

下一代防火墙

Web应用防火墙WAF

防恶意代码软件或安全Agent

**事后溯源：**

网络流量恶意代码检测系统

抗DDOS防护设备
