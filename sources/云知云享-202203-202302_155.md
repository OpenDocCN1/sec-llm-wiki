温馨提示  

| **在对于微信中突然有领导干部想添加微信，****特别是借钱或要求发红包、帮忙转账的，****一定通过其他途径进行谨慎甄别核实，****若发现被骗应该选择第一时间报警。** |
| --- |
| **增加个人保护意识，****提高数据安全意识观念！****时刻要注意个人信息和数据安全，  
****智能手机设置锁屏密码，****提高密码安全设置等级，定期修改密码****安装手机安全防护软件，****关注官方平台漏洞发布，及时更新版本。**  
 |
| **不安装来历不明的软件，****不点击来历不明的链接，****不把个人隐私信息泄露给他人，****公共场合不连接不安全的WIFI热点，  
****不在陌生电脑登录微信。** |
| **不贪图小利扫描不安全的二维码，****不向其他用户发送接收到的验证码，****谨慎发布含有个人轨迹的微信动态，****实名认证使用账号，****不出租、转租、出售微信账号，****不帮助他人解封账号，****手机随身携带。** |

**云智信安特别提醒：**

| **疫情严峻，****骗子容易利用疫情等热点进行诈骗，****通过微信进行诈骗，****通过邮件进行钓鱼攻击的事件时有发生，****提高安全防范意识，****注意个人移动设备安全，****防盗、防骗，****营造良好的网络环境，****人人有责！** |
