【漏洞通告】Microsoft Edge远程代码执行漏洞( CNVD-2022-56255)

原文：http://mp.weixin.qq.com/s?__biz=MzkxMDMxNTQ3Mg==&mid=2247483818&idx=1&sn=d8ede2c7729e3cf38095d2001ef4d441&chksm=c12c1b15f65b920311799533f061f53ac5512b00c2de92f55a8f8a2bdf03b9ab6cd8996307d4&scene=27#wechat_redirect


漏洞名称：

Microsoft Edge 远程代码执行漏洞

组件名称：

Microsoft Edge

影响范围：

Microsoft Edge  < 104.0.1293.47

漏洞类型：

远程代码执行

利用条件：

1、用户认证：不需要认证
2、前置条件：默认配置

3、触发方式：远程


漏洞分析
01
组件介绍

Microsoft Edge是美国微软（Microsoft）公司的一款Windows 10之后版本系统附带的Web浏览器。

02
漏洞描述

Microsoft Edge浏览器基于 Chromium 开源项目，该漏洞源于存在远程代码执行。目前没有详细的漏洞细节提供。

修复建议
01
官方修复建议

厂商已发布了漏洞修复程序，请及时关注更新：
https://msrc.microsoft.com/update-guide/vulnerability/CVE-2022-33636


02
临时修复建议


升级Microsoft Edge 到最新版本
