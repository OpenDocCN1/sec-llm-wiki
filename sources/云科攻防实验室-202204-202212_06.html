【漏洞通告】Spring Data MongoDB SpEL表达式注入漏洞 CVE-2022-22980

漏洞名称：

Spring Data MongoDB SpEL 表达式注入漏洞

组件名称：

Spring Data MongoDB

影响范围：

3.3.0 ≤ Spring Data MongoDB ≤ 3.3.4

漏洞类型：

代码执行

利用条件：

1、用户认证：不需要用户认证
2、前置条件：默认配置

3、触发方式：远程


漏洞分析
01
组件介绍

Spring Data MongoDB 为 Spring Data 下的子项目，用于为 MongoDB 提供接口服务，便于接入 Spring 软件生态中使用。

02
漏洞描述

Spring Data MongoDB 应用程序在使用带有 SpEL 表达式的 @Query 或 @Aggregation-annotated 查询方法时容易受到 SpEL 注入的影响，如果输入未过滤，则该表达式包含用于值绑定的查询参数占位符。具体来说，当满足以下所有条件时，应用程序很容易受到攻击：

1、使用 @Query 或 @Aggregation 注释存储库查询方法

2、带注释的查询或聚合值/管道包含 SpEL 部分，使用表达式中的参数占位符语法

3、应用程序未清理用户提供的输入


如果以下任何一项为真，则应用程序不会受到攻击：

1、带注释的存储库查询或聚合方法不包含表达式

2、带注释的存储库查询或聚合方法不使用表达式中的参数占位符语法

3、用户提供的输入由应用程序清理

4、存储库配置为使用限制 SpEL 使用的QueryMethodEvaluationContextProvider

修复建议
01
官方修复建议

官方已发布新版本3.4.1以及 3.3.5，建议升级至安全版本及其以上， https://spring.io/projects/spring-data-mongodb


02
临时修复建议


1、重写查询或聚合声明以在表达式中使用参数引用（“[0]”而不是“?0”）

2、在调用查询方法之前清理参数

3、通过具有受限 QueryMethodEvaluationContextProvider 的 BeanPostProcessor 重新配置存储库工厂 bean
