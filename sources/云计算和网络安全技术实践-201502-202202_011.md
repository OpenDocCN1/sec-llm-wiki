本周发现了一个开源的容器安全神兵利器，尽管年久失修，依然十分震撼，那就是Sysdig Inspect，

项目地址，https://github.com/draios/sysdig-inspect，

最简单的安装方法，直接起现成的docker容器，

docker run -d -v /local/path/to/captures:/captures -p8080:3000 sysdig/sysdig-inspect:latest，

然后就可以访问管理界面了，

![](../Images/f53b367d5c9dfc760036a069c71534b8.png)

都不用上网搜怎么用，管理界面上就直接给出了使用方法，

首先得先安装sysdig，然后监控数据并保存成文件，最后再把文件路径输入给管理界面，

那就先安装sysdig，安装官方的指导来，

https://github.com/draios/sysdig/wiki/How-to-Install-Sysdig-for-Linux，

curl -s https://s3.amazonaws.com/download.draios.com/stable/install-sysdig | sudo bash，

然后就是监控数据并保存成文件，sudo sysdig -w file.scap，

注意这个动作要去sysdig-inspect容器映射到主机的文件夹下做，

也就是cd /local/path/to/captures/，

等sudo sysdig -w file.scap命令执行一段时间，就停掉，

最后再把文件路径输入给管理界面，也就是/captures/file.scap，

Sysdig Inspect界面就开始导入数据，就能得到下面的效果，

![](../Images/4bad451579b6c95e6836daf77a59051c.png)

怎么样，是不是很震撼，满屏的各种数据监控啊，这么好的开源项目也不知道为啥年久失修，感兴趣的可以关注一下。
