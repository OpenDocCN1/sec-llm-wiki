本周开始想好好学学elasticsearch，尤其是API的使用和日志数据的处理，

就还是从安装开始来吧，ubuntu18.04，下载最新版本，

wget https://artifacts.elastic.co/downloads/elasticsearch/elasticsearch-7.15.1-amd64.deb，

安装，sudo dpkg -i elasticsearch-7.15.1-amd64.deb，

启动前要修改配置文件，需要切换到root，

sudo su root，vim /etc/elasticsearch/elasticsearch.yml，

network.host: 0.0.0.0
discovery.seed_hosts: ["ubuntu"]
cluster.initial_master_nodes: ["ubuntu"]
http.cors.enabled: true
http.cors.allow-origin: "*"

前三行属常规操作，后两行是给elasticsearch-head配的，

启动服务，

sudo systemctl daemon-reload，
sudo systemctl enable elasticsearch.service，
sudo systemctl start elasticsearch.service，

接着安装elasticsearch-head，

git clone git://github.com/mobz/elasticsearch-head.git，
cd elasticsearch-head，sudo apt install npm，npm install，

启动elasticsearch-head，npm run start，

elasticsearch-head是对elasticsearch数据索引进行可视化查询的工具，

下面继续实践API的操作，我习惯用Postman，

先创建个索引，用PUT方法，

注意header里要给Content-Type赋值成application/json，

这就能在elasticsearch-head里看到新创建的索引了，

接着给索引创建条数据，用的POST方法，

在elasticsearch-head的数据浏览里能看到索引的数据条目，

最后再做个数据修改，用的PUT方法，

在elasticsearch-head里能看到数据被更新了，

本周就先实践学习到这儿，下周继续。
