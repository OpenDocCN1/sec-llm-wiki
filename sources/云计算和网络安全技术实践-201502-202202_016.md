本周末没时间做技术实践，但是原则上也不能跳票，把之前总结的在k8s下安装部署free5gc的记录发一下吧，我用的是platform9的安装部署模板，

git clone https://github.com/platform9/5gcore.git，

cd 5gcore，先创建free5gc的namespace，kubectl create ns free5gc，

然后分别修改free5gc-amf.yaml，free5gc-smf.yaml，free5gc-configmap.yaml的配置，按要求amf和smf都必须得用静态地址，

先创建数据库，kubectl apply -f free5gc-mongodb.yaml -n free5gc，

然后执行configmap，kubectl apply -f free5gc-configmap.yaml -n free5gc，接着就可以创建各种网元了，

kubectl apply -f free5gc-nrf.yaml -n free5gc，  
kubectl apply -f free5gc-udr.yaml -n free5gc，  
kubectl apply -f free5gc-udm.yaml -n free5gc，  
kubectl apply -f free5gc-ausf.yaml -n free5gc，  
kubectl apply -f free5gc-pcf.yaml -n free5gc，  
kubectl apply -f free5gc-nssf.yaml -n free5gc，  
kubectl apply -f free5gc-smf.yaml -n free5gc，  
kubectl apply -f free5gc-amf.yaml -n free5gc，

都创建成功了，结果是这样，

![](../Images/b6d57931d58b9c92541beec5b479d703.png)

能够看到amf和smf都正确使用了配置的静态地址，

在我司的云铠产品界面上能看到各网元都向nrf进行了注册，

![](../Images/78c6457646acd356bffdf195041e708a.png)

这只是核心网，整体的5G网络还得有upf以及ueransim，这两个可以参考我之前独立安装的记录，麻烦的是需要把upf以及ueransim跟当前用k8s装的5gc做配置连通，这个以后再继续实践。
