以前实践过DVWA，本周有工作需要安装新版DVWA，过程中发现跟以前有不一样的地方，以下是安装记录，

ubuntu18.04.5，安装需要的软件，

sudo apt-get -y install apache2 mariadb-server php php-mysqli php-gd libapache2-mod-php，

下载dvwa项目，wget https://github.com/digininja/DVWA/archive/master.zip，

放到web目录下，sudo mv master.zip /var/www/html，

安装unzip，sudo apt install unzip，解压，sudo unzip master.zip，

改目录名，sudo mv DVWA-master dvwa，

创建配置文件，sudo mv dvwa/config/config.inc.php.dist dvwa/config/config.inc.php，

修改配置，sudo vim dvwa/config/config.inc.php，

$_DVWA[ 'db_password' ] = 'password';

我是按习惯把密码改了，也可以不改，

切到root，sudo su root，mysql，创建数据库，

create database dvwa;

create user dvwa@localhost identified by 'password';

grant all on dvwa.* to dvwa@localhost;

flush privileges;

exit

继续修改配置，sudo vim /etc/php/7.2/apache2/php.ini，

allow_url_include = On

修改上传文件目录权限，sudo chmod -R 777 dvwa/hackable/uploads/，

重启服务，sudo service apache2 restart，

访问页面，http://10.90.11.160/dvwa，

首次登录要Setup DVWA，Create / Reset Database，

就可以再次登录了，用户名密码是admin/password，

进去就先把安全级别调低，

验证一个SQL注入，1' or '1' = '1，成功，

下期用这个环境实践冰蝎。
