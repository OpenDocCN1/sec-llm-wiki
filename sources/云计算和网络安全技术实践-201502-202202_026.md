本周开始研究新东西，HELK，一个现成的基于ELK的威胁狩猎平台，

整个ubuntu虚机，开始安装，

git clone https://github.com/Cyb3rWard0g/HELK.git，

cd HELK/docker，sudo ./helk\_install.sh，

我选择的是最全安装，

KAFKA + KSQL + ELK + NGNIX + SPARK + JUPYTER + ELASTALERT，

安装完成后，可以访问到ELK的界面，

![](../Images/1e2c4f491d13512df48a346688cfb364.png)

还记得之前的Sysmon+Splunk(ThreatHunting)的实践吗，

靶机还是用metasploitable3-win2k8，  

继续用Sysmon，安装过程就不说了，感兴趣的往前面翻，

日志发送这回就得用winlogbeat了，下载地址，

https://www.elastic.co/downloads/beats/winlogbeat，

解压就能用，不用安装，配置文件下载地址，

https://github.com/Cyb3rWard0g/HELK/blob/master/configs/winlogbeat/winlogbeat.yml，

把日志接收的地址改对，然后启动winlogbeat，

等一会儿，数据就上来了，Dashboards里已经内置了模板，

![](../Images/720b9267ca64477734ed5662151a6b08.png)

看一个整体的，

![](../Images/6f2de0e81ef08b6d0e1061fe0813ad80.png)

搞了两个漏洞利用反弹shell攻击，MITRE-ATTACK的Dashboard里也没反应，注意到一个问题，进程监控一直是没数据的，这点得继续研究一下是不是windows那边哪里需要打开什么配置，如果这个地方解开，之前的Sysmon+Splunk(ThreatHunting)估计也可能出来更好的效果，这个下周再继续研究。
