cloud-init两个vdu要分别传，

主墙的cloud-init内容如下，

#cloud-config
chpasswd:
   list:
       hillstone: Hillstone@123
runcmd:
   - rule id 1 from any to any from-zone untrust to-zone untrust service any permit
   - http anti-csrf disable
   - interface ethernet0/0
   - ip mtu 1450
   - manage http
   - exit
   - interface ethernet0/1
   - ip mtu 1450
   - exit
   - interface ethernet0/2
   - ip mtu 1450
   - zone untrust
   - ip address {{ westhavip }}
   - manage ping
   - exit
   - interface ethernet0/3
   - ip mtu 1450
   - zone untrust
   - ip address {{ easthavip }}
   - manage ping
   - exit
   - track track
   - interface ethernet0/2 weight 255
   - interface ethernet0/3 weight 255
   - exit
   - ha group 0
   - priority 50
   - preempt 1
   - monitor track track
   - exit
   - ha link interface ethernet0/1
   - ha link ip {{ activeeth1ip }}
   - ha cluster 1 node 0
   - autosave
   - end
   - reboot confirm
