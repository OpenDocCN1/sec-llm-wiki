cloud-init里面需要传参，west接口用静态地址进行配置，内容如下，

#cloud-config
chpasswd:
   list:
       hillstone: Hillstone@123
runcmd:
   - rule id 1 from any to any from-zone untrust to-zone untrust service any permit
   - http anti-csrf disable
   - interface ethernet0/0
   - manage http
   - exit
   - interface ethernet0/1
   - zone untrust
   - ip address {{ westip }}
   - manage ping
   - exit
   - interface ethernet0/2
   - zone untrust
   - ip address dhcp
   - manage ping
   - exit
   - autosave
   - end

启动NS实例的时候传参如下，

{vld: [ {name: hillstone-mgt, vnfd-connection-point-ref: [ {member-vnf-index-ref: "1", vnfd-connection-point-ref: hillstone-vnf-eth0, ip-address: "10.0.0.11"}, {member-vnf-index-ref: "1", vnfd-connection-point-ref: hillstone-vnf-eth1, ip-address: "10.0.2.11"}, {member-vnf-index-ref: "1", vnfd-connection-point-ref: hillstone-vnf-eth2, ip-address: "10.0.3.11"}]}], additionalParamsForVnf: [{member-vnf-index: '1', additionalParams:{westip: '10.0.2.13/24'}}]}

结果就是一个多接口VNF实例被拉起，对于west接口，

虽然外面dhcp给的地址是10.0.2.11，

但通过传参自动配置成了静态地址10.0.2.13。
