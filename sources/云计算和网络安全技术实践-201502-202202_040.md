五一假期比较懒，就是歇着，啥也没干，为了不跳票，把之前做过的helm的实践总结一下吧，

记得之前做OSM实践的时候用过helm，那时是老版本，新版本有很大不同，

只需下载应用程序就可以了，不用再部署tiller服务，

wget https://get.helm.sh/helm-v3.5.4-linux-amd64.tar.gz，

sudo mv linux-amd64/helm /usr/local/bin/，

添加公共repo，

helm repo add stable http://mirror.azure.cn/kubernetes/charts，

helm repo update，

helm repo list，

删除repo，helm repo remove stable，

搜索chart，helm search repo ldap，

安装chart，helm install openldap stable/openldap，

查看安装好的部署，helm list，

也可以kubectl get pods --all-namespaces，

删除chart，helm uninstall openldap，

部署本地repo，

docker run --rm -d -it \\  
  -p 8080:8080 \\  
  -e DEBUG=1 \\  
  -e STORAGE=local \\  
  -e STORAGE\_LOCAL\_ROOTDIR=/charts \\  
  -v $(pwd)/charts:/charts \\  
  ghcr.io/helm/chartmuseum:v0.13.1

下载chart，sudo chmod 777 charts，cd charts，

可以直接把chart下载到chart目录，helm pull stable/openldap，

添加本地repo，  

helm repo add chartmuseum http://10.90.11.160:8080，

helm repo update，

查看本地repo上的chart，curl http://10.90.11.160:8080/api/charts | jq，  

也可以下载后远程push到本地repo上，

这需要先安装push插件，

helm plugin install https://github.com/chartmuseum/helm-push.git，

helm push openldap-1.2.7.tgz chartmuseum，

然后就可以使用本地repo上的chart安装openldap了，

最后就是怎么创建自己的chart，很简单，

helm create mychart，这是一个模板，按照自己的需要修改即可

再helm package mychart，打包成chart压缩包即可。
