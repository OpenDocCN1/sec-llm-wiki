先安装EK服务器，下载elasticsearch和kibana的最新版本，

sudo vim /etc/elasticsearch/elasticsearch.yml，

discovery.type: single-node
xpack.security.enabled: true
xpack.security.authc.api_key.enabled: true
network.host: 192.168.137.254
discovery.seed_hosts: ["192.168.137.254"]

sudo service elasticsearch start，

初始化密码，

sudo /usr/share/elasticsearch/bin/elasticsearch-setup-passwords interactive，

sudo vim /etc/kibana/kibana.yml，

xpack.security.enabled: true
xpack.fleet.agents.tlsCheckDisabled: true
xpack.encryptedSavedObjects.encryptionKey: "something_at_least_32_characters"
server.host: "192.168.137.254"
elasticsearch.hosts: ["http://192.168.137.254:9200"]
elasticsearch.username: "kibana_system"
elasticsearch.password: "password"

sudo service kibana start，

下载elastic-agent的最新版本，windows和linux的都下，

安装一个win10和一个ubuntu18.04，

访问kibana界面进行配置，添加Elastic Agent，

先改一下日志发送的地址，

再使能Elastic Agent的管理，

添加Agent，拷贝终端上要执行的命令，这里要改一下，

Windows的改成，.\elastic-agent.exe install --insecure -f --kibana-url=http://192.168.137.254:5601 --enrollment-token=ZFQ3dnYzZ0JIRzRFTFVoTWJobEU6bGpfeHVPdTFUNy1MM29TaTdwYklRZw==，

Linux的改成，sudo elastic-agent enroll --insecure -f --kibana-url=http://192.168.137.254:5601 --enrollment-token=ZFQ3dnYzZ0JIRzRFTFVoTWJobEU6bGpfeHVPdTFUNy1MM29TaTdwYklRZw==，

默认策略，目前只有system的插件，先这样，

查看上线的Agent，

很快数据就上来了，

也可以用日志搜索功能查，

再添加Endpoint Security插件，

Elastic Security这边能看到Endpoint上线，

本期就先实践到这里。
