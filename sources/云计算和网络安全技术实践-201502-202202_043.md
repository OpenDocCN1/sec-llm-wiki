先安装EK服务器，下载elasticsearch和kibana的最新版本，

sudo vim /etc/elasticsearch/elasticsearch.yml，

discovery.type: single-node  
xpack.security.enabled: true  
xpack.security.authc.api\_key.enabled: true  
network.host: 192.168.137.254  
discovery.seed\_hosts: \["192.168.137.254"\]

sudo service elasticsearch start，

初始化密码，

sudo /usr/share/elasticsearch/bin/elasticsearch-setup-passwords interactive，

sudo vim /etc/kibana/kibana.yml，

xpack.security.enabled: true  
xpack.fleet.agents.tlsCheckDisabled: true  
xpack.encryptedSavedObjects.encryptionKey: "something\_at\_least\_32\_characters"  
server.host: "192.168.137.254"  
elasticsearch.hosts: \["http://192.168.137.254:9200"\]  
elasticsearch.username: "kibana\_system"  
elasticsearch.password: "password"

sudo service kibana start，

下载elastic-agent的最新版本，windows和linux的都下，
