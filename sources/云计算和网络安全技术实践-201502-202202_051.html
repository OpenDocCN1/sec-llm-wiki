春节假期最后一天，也为Kata Containers的实践系列做个了结，这就是最开始想要达到的目的，实践在k8s下用kata，这个以kubernetes without docker的环境为基础，再把Kata Containers的软件安装上，这两个都需要参考之前的blog，这里只说k8s下用kata作为runtime的配置，有两种方法，

方法一：创建pod使用annotations，需要在/etc/containerd/config.toml里做如下配置，

[plugins."io.containerd.grpc.v1.cri".containerd.untrusted_workload_runtime]
        runtime_type = "io.containerd.kata.v2"

重启containerd服务后，就可以通过模板来创建kata类型的pod了，

sudo vim sshd-kata-pod.yaml，

apiVersion: v1
kind: Pod
metadata:
  name: kata-sshd
  annotations:
    io.kubernetes.cri.untrusted-workload: "true"
spec:
  containers:
  - name: kata-sshd
    image: rastasheep/ubuntu-sshd:14.04
    ports:
    - containerPort: 22

这种方法的缺点是，对deployment无效，通常情况下，k8s下都是不直接创建pod而是创建deployment的，因此才尝试了下面的方法二，

方法二：使用runtimeClassName，需要在/etc/containerd/config.toml里做如下配置，

[plugins."io.containerd.grpc.v1.cri".containerd.runtimes.kata]
          runtime_type = "io.containerd.kata.v2"

重启containerd服务后，需要先创建RuntimeClass，

sudo vim kata-runtime.yaml，

kind: RuntimeClass
apiVersion: node.k8s.io/v1beta1
metadata:
  name: kata-containers
handler: kata

然后就可以创建deployment了，

sudo vim sshd-kata-deployment.yaml，

apiVersion: apps/v1
kind: Deployment
metadata:
  name: sshd-kata
  labels:
    app: sshd-kata
spec:
  selector:
    matchLabels:
      app: sshd-kata
  template:
    metadata:
      labels:
        app: sshd-kata
    spec:
      runtimeClassName: kata-containers
      containers:
      - name: sshd-kata
        image: rastasheep/ubuntu-sshd:14.04
        imagePullPolicy: IfNotPresent
        ports:
        - containerPort: 22
