本来这周想实践k8s用kata，但是有事儿耽搁了，而又想延续这个系列，不如这样吧，咱们继续证明一下Kata Containers对容器安全方案的影响，

就拿falco来做这个实验吧，falco是啥，感兴趣的可以往前翻，有一篇《容器安全实践之falco》，不过那个是在k8s下实践的，这次简单点，顺着上期的环境，就在普通docker环境下实践一下，

安装falco，

curl -s https://s3.amazonaws.com/download.draios.com/DRAIOS-GPG-KEY.public | sudo apt-key add -，

sudo curl -s -o /etc/apt/sources.list.d/draios.list https://s3.amazonaws.com/download.draios.com/stable/deb/draios.list，

sudo apt install falco，

配置falco，本次就简单实践一下，只改个日志输出配置就好了，

sudo vim /etc/falco/falco.yaml，

file_output:
  enabled: true
  keep_alive: false
  filename: /var/log/falco.log

可以检查一下配置文件是否有错误，

falco -c /etc/falco/falco.yaml -L，

启动falco，sudo systemctl start falco，

重启falco，sudo systemctl restart falco，

安装部署就这些，比k8s下简单多了，

接着就可以做实验了，就直接用上期环境里的两个容器，

sshd-runc和sshd-kata，

分别进入两个容器的shell，

docker exec -it sshd-runc /bin/bash，

docker exec -it sshd-kata /bin/bash，

查看/var/log/falco.log，runc的能监控到正确的结果，kata的就乱了，

可以证明了Kata Containers对容器安全方案的影响，
