以前介绍过怎么手动安装kubernetes环境，有人说无法访问外网装不了，就算docker hub能访问也速度也慢的不得了，本周就发一个国内怎么痛快的手动安装kubernetes环境的记录，

用的ubuntu-18.04.5-live-server-amd64，单网卡，能访问互联网，

切换到阿里云的源，

sudo mv /etc/apt/sources.list /etc/apt/sources.list.bak，
sudo vim /etc/apt/sources.list，

deb http://mirrors.aliyun.com/ubuntu/ bionic main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ bionic main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ bionic-security main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ bionic-security main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ bionic-updates main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ bionic-updates main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ bionic-backports main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ bionic-backports main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ bionic-proposed main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ bionic-proposed main restricted universe multiverse

升级，sudo apt update，sudo apt dist-upgrade，重启，sudo reboot，

安装docker，

sudo apt install docker.io，
sudo systemctl enable docker，
sudo gpasswd -a ubuntu docker，
newgrp docker，

安装kube软件，

curl https://mirrors.aliyun.com/kubernetes/apt/doc/apt-key.gpg | apt-key add -，
sudo vim /etc/apt/sources.list.d/kubernetes.list，

deb https://mirrors.aliyun.com/kubernetes/apt/ kubernetes-xenial main
sudo apt update，
sudo apt install kubelet kubeadm kubectl，

sudo swapoff -a，

初始化kubernetes环境，注意指定使用阿里云的registry，

sudo kubeadm init --pod-network-cidr=10.244.0.0/16 --image-repository registry.aliyuncs.com/google_containers，

很快就安装完成，安装提示操作，

mkdir -p $HOME/.kube，
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config，
sudo chown $(id -u):$(id -g) $HOME/.kube/config，

指定master也能当node，
kubectl taint nodes --all node-role.kubernetes.io/master-，

安装CNI，我喜欢calico，

wget https://docs.projectcalico.org/v3.16/manifests/calico.yaml，
sudo vim calico.yaml，
- name: CALICO_IPV4POOL_CIDR
              value: "10.244.0.0/16"

注意镜像都从科技大的仓库下载，

docker.mirrors.ustc.edu.cn/calico/node:v3.16.5 calico/node:v3.16.5，
docker.mirrors.ustc.edu.cn/calico/pod2daemon-flexvol:v3.16.5，
docker.mirrors.ustc.edu.cn/calico/cni:v3.16.5 calico/cni:v3.16.5，

docker.mirrors.ustc.edu.cn/calico/kube-controllers:v3.16.5，

修改calico的网络要求，

sudo vim /etc/sysctl.conf，
net.ipv4.conf.all.rp_filter=1
net.ipv4.ip_forward=1
sudo sysctl -p，

执行，kubectl apply -f calico.yaml，很快搞定，
