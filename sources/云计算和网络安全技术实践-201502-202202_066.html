本周继续在k8s下实践用kubevirt编排虚机，这次是用自己的虚机镜像起虚机，以ubuntu为例，先下载一个ubuntu的qcow2镜像，http://cloud-images.ubuntu.com/releases/xenial/release/ubuntu-16.04-server-cloudimg-amd64-disk1.img，然后用这个虚机镜像build一个docker镜像，

vim Dockerfile
FROM scratch
ADD ubuntu-16.04-server-cloudimg-amd64-disk1.img /disk/

sudo docker build -t ubuntu:16.04 .

能够看到本地新出来的docker镜像，

接着就可以用这个docker镜像起虚机了，

参考之前cirros的模板，vim vm-ubuntu.yaml，

---
apiVersion: kubevirt.io/v1alpha3
kind: VirtualMachine
metadata:
  labels:
    kubevirt.io/vm: vm-ubuntu
  name: vm-ubuntu
spec:
  running: false
  template:
    metadata:
      labels:
        kubevirt.io/vm: vm-ubuntu
    spec:
      domain:
        devices:
          disks:
          - disk:
              bus: virtio
            name: containerdisk
          - disk:
              bus: virtio
            name: cloudinitdisk
        machine:
          type: ""
        resources:
          requests:
            memory: 2048M
      terminationGracePeriodSeconds: 0
      volumes:
      - containerDisk:
          image: ubuntu:16.04
          imagePullPolicy: IfNotPresent
        name: containerdisk
      - cloudInitNoCloud:
          userData: |
            #cloud-config
            ssh_pwauth: True
            chpasswd:
             list: |
               ubuntu:ubuntu
             expire: False
        name: cloudinitdisk

这里我还是改了image和userdata，

userdata这个地方也可以用base64加密，

      - cloudInitNoCloud:
          userDataBase64:
                  I2Nsb3VkLWNvbmZpZwpzc2hfcHdhdXRoOiBUcnVlCmNocGFzc3dkOgogIGxpc3Q6IHwKICAgIHVidW50dTp1YnVudHUKICBleHBpcmU6IEZhbHNl
        name: cloudinitdisk

最好多找几个在线base464加解密的网站，比较一下加密的结果，某些网站的加密结果是错的，多数网站还是对的，

执行kubectl apply -f vm-ubuntu.yaml，

启动虚机，./virtctl start vm-ubuntu，

./virtctl console vm-ubuntu进虚机里看看，

能正常登录，说明userdata正常注入，
