早就听说k8s下可以用kubevirt编排虚机，本周终于任务打败了惰性，开搞，

k8s的安装就不多说了，不会玩儿的往前翻，这里直接从kubevirt说起，

首先要准备kvm条件，sudo apt install qemu-kvm libvirt-bin bridge-utils virtinst libvirt-clients，接着就是安装kubevirt，这安装的是当前最新版本，

wget https://github.com/kubevirt/kubevirt/releases/download/v0.34.0/kubevirt-operator.yaml，

wget https://github.com/kubevirt/kubevirt/releases/download/v0.34.0/kubevirt-cr.yaml，

kubectl apply -f kubevirt-operator.yaml，

kubectl apply -f kubevirt-cr.yaml，

等待一段时间，就出来上面截图的效果了，

接着就可以拉起虚机了，参考官方链接，

https://github.com/kubevirt/kubevirt/blob/master/examples/vm-cirros.yaml，

写个自己的yaml模板，

---
apiVersion: kubevirt.io/v1alpha3
kind: VirtualMachine
metadata:
  labels:
    kubevirt.io/vm: vm-cirros
  name: vm-cirros
spec:
  running: false
  template:
    metadata:
      labels:
        kubevirt.io/vm: vm-cirros
    spec:
      domain:
        devices:
          disks:
          - disk:
              bus: virtio
            name: containerdisk
          - disk:
              bus: virtio
            name: cloudinitdisk
        machine:
          type: ""
        resources:
          requests:
            memory: 64M
      terminationGracePeriodSeconds: 0
      volumes:
      - containerDisk:
          image: kubevirt/cirros-registry-disk-demo
          imagePullPolicy: IfNotPresent
        name: containerdisk
      - cloudInitNoCloud:
          userData: |
            #!/bin/sh
            echo nameserver 8.8.8.8 >> /etc/resolv.conf
        name: cloudinitdisk

这里我改了image和userdata，

执行kubectl apply -f vm-cirros.yaml，

下载工具，

wget https://github.com/kubevirt/kubevirt/releases/download/v0.34.0/virtctl-v0.34.0-linux-amd64，

mv virtctl-v0.34.0-linux-amd64 virtctl，chmod +x virtctl，

启动虚机，./virtctl start vm-cirros，

kubectl get pods就能看到起来的虚机pod了，

docker image list能看到自动下载了kubevirt/cirros-registry-disk-demo镜像，

./virtctl console vm-cirros进虚机里看看，userdata正常注入，

这个虚机在哪儿起的呢，进虚机pod看看就明白了，

kubectl exec -it virt-launcher-vm-cirros-5z8zx bash，virsh list，
