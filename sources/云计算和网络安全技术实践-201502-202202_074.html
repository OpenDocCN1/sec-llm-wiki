以前一直都用DevStack安装All In One的环境，最近有方案验证需要，研究了一下用DevStack安装多节点环境，

官方指南是必须参考的，

https://docs.openstack.org/devstack/latest/guides/multinode-lab.html，

需要先解决国内DevStack默认安装源的各种限制问题，

首先是ubuntu的安装源，这个以前就在用，aliyun的，

sudo mv /etc/apt/sources.list /etc/apt/sources.list.bak，
sudo vim /etc/apt/sources.list，
deb http://mirrors.aliyun.com/ubuntu/ bionic main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ bionic main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ bionic-security main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ bionic-security main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ bionic-updates main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ bionic-updates main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ bionic-backports main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ bionic-backports main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ bionic-proposed main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ bionic-proposed main restricted universe multiverse

然后是pip的安装源，之前没弄过，这次弄明白了，还是aliyun的，

sudo vim /etc/pip.conf，
[global]
index-url = https://mirrors.aliyun.com/pypi/simple
[install]
trusted-host=mirrors.aliyun.com

最后就是DevStack的安装源，国内唯一，trystack的，

这就可以创建各节点的local.conf文件了，

控制节点，

[[local|localrc]]
GIT_BASE=http://git.trystack.cn
NOVNC_REPO=http://git.trystack.cn/kanaka/noVNC.git
HOST_IP=192.168.137.200
SERVICE_HOST=192.168.137.200
PUBLIC_INTERFACE=ens33
SERVICE_PASSWORD=password
ADMIN_PASSWORD=password
DATABASE_PASSWORD=password
RABBIT_PASSWORD=password

计算节点，

[[local|localrc]]
GIT_BASE=http://git.trystack.cn
NOVNC_REPO=http://git.trystack.cn/kanaka/noVNC.git
HOST_IP=192.168.137.201
PUBLIC_INTERFACE=ens33
SERVICE_PASSWORD=password
ADMIN_PASSWORD=password
DATABASE_PASSWORD=password
RABBIT_PASSWORD=password
DATABASE_TYPE=mysql
SERVICE_HOST=192.168.137.200
MYSQL_HOST=$SERVICE_HOST
RABBIT_HOST=$SERVICE_HOST
GLANCE_HOSTPORT=$SERVICE_HOST:9292
ENABLED_SERVICES=n-cpu,q-agt,c-vol,placement-client
NOVA_VNC_ENABLED=True
NOVNCPROXY_URL="http://$SERVICE_HOST:6080/vnc_lite.html"
VNCSERVER_LISTEN=$HOST_IP
VNCSERVER_PROXYCLIENT_ADDRESS=$VNCSERVER_LISTEN

如果遇到网络特别恶劣，有几个地方也需要再特殊处理，

比如说DevStack包的下载，直接下载https://opendev.org/openstack/devstack/archive/master.tar.gz或则https://github.com/openstack/devstack/archive/master.zip就比git clone要靠谱，

再比如安装过程中用的get-pip.py，wget就不如提前用浏览器下载下来放到本地的http下载服务器靠谱，当然要改安装脚本，

vim devstack/tools/install_pip.sh，https://bootstrap.pypa.io/get-pip.py改成http://192.168.137.1/get-pip.py，

再比如etcd-v3.3.12-linux-amd64.tar.gz和cirros-0.5.1-x86_64-disk.img的wget也不如提前用浏览器下载下来传到devstack/files/靠谱，

总之，安装上面的一顿hack，最终跑完控制节点也就不到20分钟，跑完计算节点也就不到10分钟，关键是一次中断都没有，

计算节点跑完，要去控制节点手动执行命令做计算节点发现，

sudo nova-manage cell_v2 discover_hosts --verbose，

还有就是计算节点虽然也指明了PUBLIC_INTERFACE，但没有自动给ovs的br-ex绑上，需要手动绑一下，
