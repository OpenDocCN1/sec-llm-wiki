最近有方案需要Linux使用32位的地址，具体为啥就不明确说了，有缘人自己悟吧，

可以手动给linux配置32位的地址，方法如下，

1、配置地址
sudo ifconfig ens32 192.168.137.250 netmask 255.255.255.255 broadcast 0.0.0.0
2、配置去网关的主机路由
sudo route add -host 192.168.137.1 dev ens32
3、配置默认路由
sudo route add default gw 192.168.137.1


也可以改造dhcp服务，支持给主机下发32位地址，

自己搭建一个dhcp服务器，ubuntu18.04，

安装dhcp服务软件，sudo apt install isc-dhcp-server，

修改网卡配置，我这里加了一个网卡做dhcp服务接口，

sudo vim /etc/netplan/50-cloud-init.yaml，
network:
    ethernets:
        ens32:
            addresses:
            - 192.168.137.200/24
            gateway4: 192.168.137.1
            nameservers:
                addresses:
                - 114.114.114.114
        ens33:
            addresses:
            - 172.16.0.2/24
    version: 2
让网卡配置改动生效，sudo netplan apply，

配置dhcp服务接口，

sudo vim /etc/default/isc-dhcp-server，
INTERFACESv4="ens33"

做明细的dhcp服务配置，给主机分配32地址，

sudo vim /etc/dhcp/dhcpd.conf，
subnet 172.16.0.0 netmask 255.255.255.0 {
    range 172.16.0.2 172.16.0.254;
    option routers 172.16.0.250;
    option subnet-mask 255.255.255.255;
    option broadcast-address 0.0.0.0;
    option domain-name-servers 114.114.114.114;
}

重启dhcp服务，sudo systemctl restart isc-dhcp-server，这就齐活了。
