最近听说有人在用oVirt，开源免费的东西能好用么，端午假期实践了一下，

下载Node的最新版本，https://resources.ovirt.org/pub/ovirt-4.4/iso/ovirt-node-ng-installer/4.4.0-2020052110/el8/ovirt-node-ng-installer-4.4.0-2020052110.el8.iso，

安装十分顺利，试试直接在里面安装Engine虚机，

![](../Images/b2d307c2d33150eb335d309d62efeaaa.png)

填写Engine虚机各项参数，

![](../Images/c90b331c14f3a4dd035cf48416eb068c.png)

然后就没有然后了，

![](../Images/aafb7a31372c01bbebddf1840d92e9cc.png)

那就单独整个CentOS手动安装Engine吧，还是然后就没有然后了，

![](../Images/6dae3a4752c331e2fa0711557f4a1060.png)

经过了各种实验，终于发现次新版本（4.3）的Engine手动安装加上最新版本（4.4）的Node是靠谱的组合，

Engine安装过程，CentOS7，

yum install http://resources.ovirt.org/pub/yum-repo/ovirt-release43.rpm，

yum install ovirt-engine，

engine-setup --generate-answer=/root/answer.txt，

注意给Engine虚机搞个域名，用不着DNS，添加到本地hosts文件里就行，

登录Engine，添加主机，就是用最新版本的iso装出来的Node，

![](../Images/c8f285ab18e646b54f63a93c1ca574c5.png)

然后是添加本地存储，在Node虚机里操作，

mkdir -p /data/images -p，

chown 36:36 /data /data/images，

chmod 0755 /data /data/images，

然后让Node主机进入维护模式，添加本地存储，

![](../Images/23cd2539ebdc1ba9995d114ed88cfa52.png)

接着就可以下载虚机镜像了，系统里内置了可远程下载的各种镜像，

![](../Images/9d0d395c9dd60a1efaca104b94be3d8a.png)

下个最小的cirros试试，

![](../Images/ce09ca9c9f220711d0c80de662761d4f.png)

下载并导入模板成功，

![](../Images/1d8531981029fe6f98f9a0b63fc057fc.png)

另外还可以直接上传镜像，

![](../Images/135609089ae02c97767015f71ec9afaa.png)

首先要把Engine的CA证书导入到浏览器，才允许导入第三方镜像，

![](../Images/c43cf1d534b3451fb70d52a1a66925e0.png)

用第三方镜像创建虚机，模板选择为空，附加第三方镜像即可，

![](../Images/566f312094944029ef866e4a1a9bca56.png)

用cirros和第三方镜像创建出来的虚机，我外面有dhcp，cirros没看到地址，第三方虚机看到地址了，

![](../Images/4e51805a68e1af9938aee1c57268e18e.png)

下载并安装个virt-viewer，进console能看到cirros虚机的地址，

![](../Images/9f654624e5cc3d66cb008de675819666.png)

从外面访问第三方虚机，也没问题，

![](../Images/f35f64e62b78d573a6c0fdca2a747fb2.png)
