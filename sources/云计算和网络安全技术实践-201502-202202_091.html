在Windows Server2019里实践Docker

一直很好奇Windows Server里能不能跑docker，本周查了一些资料，并在Windows Server2019里做了实验，记录如下，

首先安装一个Windows Server2019的虚拟机，这个就不详述了，

用PowerShell开启容器功能，Install-WindowsFeature containers，


然后参考https://docs.microsoft.com/en-us/virtualization/windowscontainers/deploy-containers/deploy-containers-on-server，

安装docker，Install-Module -Name DockerMsftProvider -Repository PSGallery -Force，这个地方虽然没提示重启，但是自己要重启一下，

Install-Package -Name docker -ProviderName DockerMsftProvider，

启动docker服务，

拉镜像试试，

windows的没问题，docker pull mcr.microsoft.com/windows/servercore:ltsc2019，

linux的说不支持，docker pull rastasheep/ubuntu-sshd:14.04，

再继续参考https://success.docker.com/article/how-to-enable-linux-containers-on-windows-server-2019，

在C:\ProgramData\Docker\config目录下创建daemon.json文件，

{
    "experimental":true
}

再重启docker服务，就能拉linux的镜像了，

但是起docker实例的时候报错，

继续按照指南，先开启Hyper-V，

Install-WindowsFeature -Name Hyper-V，

然后安装Linuxkit，

Invoke-WebRequest -UseBasicParsing -OutFile release.zip -uri https://github.com/linuxkit/lcow/releases/download/v4.14.35-v0.3.9/release.zip，

Expand-Archive release.zip -DestinationPath "$Env:ProgramFiles\Linux Containers\." ，
再启动docker实例就OK了，

从外面ssh进去，一切正常，

理解一下docker的网络，是Windows给做的NAT，

因为用了Hyper-V，所以把管理工具装上，看看有没有虚机起来，

还真没有，看来容器这边跟虚机那边还真是两码事儿，
