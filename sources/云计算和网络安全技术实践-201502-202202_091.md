# 在Windows Server2019里实践Docker

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650745681&idx=1&sn=5b5a7e1e55e723932a4100ccb4f3e677&chksm=87148a51b0630347265fecf785b75a40ee51b2ad956a3d3ee40e61dc5ff8ab0da3d62e8a2dd7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650745681&idx=1&sn=5b5a7e1e55e723932a4100ccb4f3e677&chksm=87148a51b0630347265fecf785b75a40ee51b2ad956a3d3ee40e61dc5ff8ab0da3d62e8a2dd7&scene=27#wechat_redirect)

一直很好奇Windows Server里能不能跑docker，本周查了一些资料，并在Windows Server2019里做了实验，记录如下，

首先安装一个Windows Server2019的虚拟机，这个就不详述了，

用PowerShell开启容器功能，Install-WindowsFeature containers，

![](../Images/61e5abdc6cfb21e898154dfb7c7fa63b.png)  
然后参考https://docs.microsoft.com/en-us/virtualization/windowscontainers/deploy-containers/deploy-containers-on-server，  

安装docker，Install-Module -Name DockerMsftProvider -Repository PSGallery -Force，这个地方虽然没提示重启，但是自己要重启一下，

![](../Images/a28a54512aa7ea0d6060d0cc0a6234a1.png)

Install-Package -Name docker -ProviderName DockerMsftProvider，  

![](../Images/3b93631e46cadcbf358fbda4affbdb36.png)

启动docker服务，

![](../Images/00f12f4922ec5e3f397a049482e6253c.png)

拉镜像试试，

windows的没问题，docker pull mcr.microsoft.com/windows/servercore:ltsc2019，

linux的说不支持，docker pull rastasheep/ubuntu-sshd:14.04，

![](../Images/868d2c107ee333b63086424e169ea95a.png)

再继续参考https://success.docker.com/article/how-to-enable-linux-containers-on-windows-server-2019，

在C:\\ProgramData\\Docker\\config目录下创建daemon.json文件，

{  
    "experimental":true  
}

再重启docker服务，就能拉linux的镜像了，

![](../Images/0b4e3193dcc43360a0fdf6d9d500a48e.png)

但是起docker实例的时候报错，

![](../Images/a09f506da77cffb94eadecce31ab36aa.png)

继续按照指南，先开启Hyper-V，

Install-WindowsFeature -Name Hyper-V，

![](../Images/6c3fc2e3e3bed4115b799f1ed5eae567.png)

然后安装Linuxkit，

Invoke-WebRequest -UseBasicParsing -OutFile release.zip -uri https://github.com/linuxkit/lcow/releases/download/v4.14.35-v0.3.9/release.zip，

Expand-Archive release.zip -DestinationPath "$Env:ProgramFiles\\Linux Containers\\." ，  
再启动docker实例就OK了，

![](../Images/cf7cfa6ce11ee9acefcf57b59f1dd5b2.png)

从外面ssh进去，一切正常，

![](../Images/dec37bad0d126ffce0180ffd4230a4a7.png)

理解一下docker的网络，是Windows给做的NAT，

![](../Images/276b4af5f527ad4e1f236a90e046ff1b.png)

因为用了Hyper-V，所以把管理工具装上，看看有没有虚机起来，

![](../Images/ebd7753db86a65905149a16efb9509b9.png)

还真没有，看来容器这边跟虚机那边还真是两码事儿，

![](../Images/98ad7b9724c1e07953c7926de73b6166.png)
