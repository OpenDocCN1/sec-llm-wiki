本周实践的是vulnhub的tr0ll镜像，下载地址，hhttps://download.vulnhub.com/tr0ll/Tr0ll.rar，

第一步当然还是地址扫描，sudo netdiscover -r 192.168.137.0/24，

接着是服务扫描，sudo nmap -sS -sV -A -p- 192.168.137.92，

最明显看到的是ftp能匿名登录，进去看见有个抓包文件，

下载下来打开能看到一些有用的信息，

猜测sup3rs3cr3tdirlol是个url地址，

把这个文件再下载下来查看，

猜测又是一个url地址，

一个目录里貌似有个user list文件，

另一个目录貌似里有password文件，

用这两个文件里的信息尝试破解，竟然不对，

把password文件的名字Pass.txt也添加进password文件再次尝试，竟然猜对了，破解出来一对儿user/password，overflow/Pass.txt，

ssh进去，发现没有sudo权限，

经过验证，tmp目录可写，则下载https://github.com/sleventyeleven/linuxprivchecker/blob/master/linuxprivchecker.py进行提权条件检查，

cd tmp，vim linuxprivchecker.py，chmod +x linuxprivchecker.py，

python linuxprivchecker.py，看到系统是3.13.0版本，

去exploit-db网站搜索提权方法，

从https://www.exploit-db.com/download/37292下载37292.c，

编译出来可执行程序，vim 37292.c，gcc 37292.c -o 37292，执行./37292得到结果，

至此拿root权限成功。
