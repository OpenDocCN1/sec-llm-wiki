# vulnhub之tr0ll的实践

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650745591&idx=1&sn=8bfd8049c68a6fab185f5b95f90679f8&chksm=87148bf7b06302e1ecf4294c383950393db96199ac4318fc1dce4d58cb0bd3be54cbf33ea593&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650745591&idx=1&sn=8bfd8049c68a6fab185f5b95f90679f8&chksm=87148bf7b06302e1ecf4294c383950393db96199ac4318fc1dce4d58cb0bd3be54cbf33ea593&scene=27#wechat_redirect)

本周实践的是vulnhub的tr0ll镜像，下载地址，hhttps://download.vulnhub.com/tr0ll/Tr0ll.rar，

第一步当然还是地址扫描，sudo netdiscover -r 192.168.137.0/24，

![](../Images/7c4f4c044fb97d251e06f00721cb0d17.png)

接着是服务扫描，sudo nmap -sS -sV -A -p- 192.168.137.92，

![](../Images/d278c3314d11bc76867842488f7eb485.png)

最明显看到的是ftp能匿名登录，进去看见有个抓包文件，

![](../Images/c564221bc30a94f8b80b310d43c51549.png)

下载下来打开能看到一些有用的信息，

![](../Images/d76693adcc5fc63a09d337a6c720d16a.png)

猜测sup3rs3cr3tdirlol是个url地址，

![](../Images/2cb0594017ff5970f089fe7dfa93707f.png)

把这个文件再下载下来查看，

![](../Images/c5a015863e136e4c1d997272a8ff7225.png)

猜测又是一个url地址，

![](../Images/2126215932d7f4e8e23ced1e66743956.png)

一个目录里貌似有个user list文件，

![](../Images/82ec8d875fb9a5f7c983e7c3e9d06458.png)

另一个目录貌似里有password文件，

![](../Images/615bdbd55c670bf3965e6e54a6289ace.png)

用这两个文件里的信息尝试破解，竟然不对，

![](../Images/c466d3cfae86c0051f643ff2bfd84352.png)

把password文件的名字Pass.txt也添加进password文件再次尝试，竟然猜对了，破解出来一对儿user/password，overflow/Pass.txt，  

![](../Images/f2c0e079fa65862236b60c3e6174c767.png)

ssh进去，发现没有sudo权限，

![](../Images/e248efb2b189daa632646803f668c7e7.png)

经过验证，tmp目录可写，则下载https://github.com/sleventyeleven/linuxprivchecker/blob/master/linuxprivchecker.py进行提权条件检查，

cd tmp，vim linuxprivchecker.py，chmod +x linuxprivchecker.py，

python linuxprivchecker.py，看到系统是3.13.0版本，

![](../Images/22079e3a25ab26a8f139cf6dfb750229.png)

去exploit-db网站搜索提权方法，

![](../Images/9c462c4a648bfa479f310fd66c3cac7b.png)

从https://www.exploit-db.com/download/37292下载37292.c，

编译出来可执行程序，vim 37292.c，gcc 37292.c -o 37292，执行./37292得到结果，

![](../Images/5e28ab1ccfb2b79754901ac64e3d6da5.png)

至此拿root权限成功。
