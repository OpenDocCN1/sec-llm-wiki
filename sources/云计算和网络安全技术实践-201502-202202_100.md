本周开始研究Suricata+Elasticsearch打造开源入侵检测平台，这个恐怕会是一个很长的系列，

先说说思路，实践环境设计为两台虚机，一台是Elasticsearch+Kibana，等着收日志和可视化展示；另一台是Suricata+Logstash和Filebeat，监控威胁流量产生日志并输送给前者，

Elasticsearch+Kibana的安装比较简单，关键配置记录如下，

Elasticsearch的配置，

sudo vim /etc/elasticsearch/elasticsearch.yml，  
node.name: node-1  
network.host: 0.0.0.0  
cluster.initial\_master\_nodes: \["node-1"\]

Kibana的配置，

sudo vim /etc/kibana/kibana.yml，  
server.host: "0.0.0.0"  
#elasticsearch.hosts: \["http://localhost:9200"\]

Suricata的安装配置稍微麻烦点儿，

首先安装，

sudo add-apt-repository ppa:oisf/suricata-stable，  
sudo apt update，  
sudo apt install suricata，

默认带的规则太少，咱们不用，

cd /etc/suricata，  
sudo mv rules rules-bak，

下载新的规则包并解压，

sudo wget http://rules.emergingthreats.net/open/suricata/emerging.rules.tar.gz，  
sudo tar -zxvf emerging.rules.tar.gz，

修改配置如下，本次实验仅使用扫描规则，

sudo vim /etc/suricata/suricata.yaml，  
HOME\_NET: "any"  
EXTERNAL\_NET: "any"  
af-packet:  
  - interface: ens32  
pcap:  
  - interface: ens32  
default-rule-path: /etc/suricata/rules

rule-files:  
  - emerging-scan.rules

下面分别实验Logstash和Filebeat，

logstash需要安装java jdk，sudo apt install openjdk-8-jdk，

修改配置如下，

sudo vim /etc/logstash/conf.d/logstash.conf，  
input {  
  file {  
    path => \["/var/log/suricata/eve.json"\]  
    codec => json  
  }  
}  
filter {  
  
}  
output {  
  elasticsearch {  
    hosts => "192.168.137.254:9200"  
    index => "suricata-%{+YYYY.MM.dd}"  
  }  
}

为了给Logstash输送的日志做可视化，下载并给Kibana安装一套现成的模板，

https://networkwatcherdocassets.blob.core.windows.net/suricata/Sample\_Suricata\_Alert\_Kibana\_Dashboard.json，  
https://networkwatcherdocassets.blob.core.windows.net/suricata/Sample\_Suricata\_Alert\_Visualizations.json，  
https://networkwatcherdocassets.blob.core.windows.net/suricata/Sample\_Suricata\_Alert\_Saved\_Search.json，

对Suricata虚机简单做个端口扫描，这效果就出来了，

![](../Images/33ee84344316643e3af5ab57d6ce3d7a.png)

Filebeat要更强大，以后就重点研究suricata+filebeat的组合，先修改配置如下，

filebeat.inputs:  
  enabled: true  
  paths:  
    - /var/log/suricata/eve.json  
setup.kibana:  
  host: "192.168.137.254:5601"  
output.elasticsearch:  
  hosts: \["192.168.137.254:9200"\]

查看可用的module，sudo filebeat modules list，

使能suricata，sudo filebeat modules enable suricata，

自动化给Kibana安装可视化模板，sudo filebeat setup -e，

同样再对Suricata虚机简单做个端口扫描，这效果也出来了，

![](../Images/e5423993c2894e44a891870a055573a3.png)
