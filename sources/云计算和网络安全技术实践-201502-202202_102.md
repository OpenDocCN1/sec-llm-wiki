书接上上文，上上文中说到要继续实践一下neo4j向elk同步数据，本周末它就来了，

首先咱们给neo4j装个elasticsearch的插件，由于我的neo4j是3.5.x版本的，所以要下载3.5.x版本的插件包，

wget https://github.com/neo4j-contrib/neo4j-elasticsearch/releases/download/3.5.6/neo4j-elasticsearch-3.5.6.jar，

把插件包放到/var/lib/neo4j/plugins/目录下，

mv neo4j-elasticsearch-3.5.6.jar /var/lib/neo4j/plugins/，

在neo4j的配置文件里添加elasticsearch配置项，指定elasticsearch服务地址和同步的数据索引，

sudo vim /etc/neo4j/neo4j.conf，

elasticsearch.host\_name=http://192.168.137.251:9200  
elasticsearch.index\_spec=people:Person(name)

重启neo4j，service neo4j restart，

elk的安装就还是用sebp/elk容器，

docker run -d -p 5601:5601 -p 9200:9200 -p 5044:5044 --name elk sebp/elk，

这里需要记录的一点是，容器起不来的问题怎么解决，

执行如下命令，sudo sysctl vm.max\_map\_count=262144，  

也可以切换到root把配置写到配置文件里，以便重启后也有效，

echo vm.max\_map\_count=262144 > /etc/sysctl.d/vm\_max\_map\_count.conf，
