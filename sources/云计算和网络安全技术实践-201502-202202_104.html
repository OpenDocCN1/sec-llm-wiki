书接上文，上文书中说到本周要研究一下用python操作neo4j，这个周末就来实践一下，

我用的是Anaconda3，首先需要安装py2neo，pip install py2neo，

连接neo4j，

from py2neo import Graph,Node,Relationship,RelationshipMatcher
graph = Graph('http://10.90.11.160:7474',username='neo4j',password='password')

之前已经在neo4j的UI界面里做了很多数据的操作，所以先把数据清干净，

from py2neo import Graph,Node,Relationship,RelationshipMatcher
graph = Graph('http://10.90.11.160:7474',username='neo4j',password='password')
graph.delete_all()

接下来重新创建数据，

from py2neo import Graph,Node,Relationship,RelationshipMatcher
graph = Graph('http://10.90.11.160:7474',username='neo4j',password='password')
ee = Node('Person',name='Emil')
js = Node('Person',name='Johan')
ir = Node('Person',name='Lan')
rvb = Node('Person',name='Rik')
ally = Node('Person',name='Allison')
r1 = Relationship(ee,'KNOWS',js)
r2 = Relationship(ee,'KNOWS',ir)
r3 = Relationship(js,'KNOWS',ir)
r4 = Relationship(js,'KNOWS',rvb)
r5 = Relationship(ir,'KNOWS',js)
r6 = Relationship(ir,'KNOWS',ally)
r7 = Relationship(rvb,'KNOWS',ally)
s = ee | js | ir | rvb| ally | r1 | r2 | r3 | r4 | r5 | r6 | r7
graph.create(s)

做一个所有关系的查询，

from py2neo import Graph,Node,Relationship,RelationshipMatcher
graph = Graph('http://10.90.11.160:7474',username='neo4j',password='password')
relMatch = RelationshipMatcher(graph)
relList = list(relMatch.match())
for i in relList:
    print(i)

很快能够得到结果如下，

(Johan)-[:KNOWS {}]->(Rik)
(Johan)-[:KNOWS {}]->(Lan)
(Lan)-[:KNOWS {}]->(Johan)
(Lan)-[:KNOWS {}]->(Allison)
(Emil)-[:KNOWS {}]->(Lan)
(Emil)-[:KNOWS {}]->(Johan)
(Rik)-[:KNOWS {}]->(Allison)

再试试明确指定某个关系名的查询，

from py2neo import Graph,Node,Relationship,RelationshipMatcher
graph = Graph('http://10.90.11.160:7474',username='neo4j',password='password')
relMatch = RelationshipMatcher(graph)
relList = list(relMatch.match(r_type="KNOWS"))
for i in relList:
    print(i)

同样能够得到结果如下，但是查询速度要慢一点儿，

(Johan)-[:KNOWS {}]->(Rik)
(Johan)-[:KNOWS {}]->(Lan)
(Lan)-[:KNOWS {}]->(Johan)
(Lan)-[:KNOWS {}]->(Allison)
(Emil)-[:KNOWS {}]->(Lan)
(Emil)-[:KNOWS {}]->(Johan)
(Rik)-[:KNOWS {}]->(Allison)

最后本想试试指定某个Node查询它身上的关系，但是找了半天也没找到合适的编程语句例子，就得直接上CQL语句了，

from py2neo import Graph,Node,Relationship,RelationshipMatcher
graph = Graph('http://10.90.11.160:7474',username='neo4j',password='password')
result = graph.run("MATCH (ee:Person)-[:KNOWS]-(friends) WHERE ee.name = 'Emil' RETURN ee, friends").data()
for i in result:
    print(i)

得到结果如下，

{'ee': (_70:Person {name: 'Emil'}), 'friends': (_1:Person {name: 'Lan'})}
{'ee': (_70:Person {name: 'Emil'}), 'friends': (_0:Person {name: 'Johan'})}

跟直接在neo4j的UI界面里查到的结果的可视化效果还是差很多的，
