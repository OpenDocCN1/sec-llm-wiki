搜了一圈，都说neo4j是目前最成熟的开源图数据库，本周末就先来安装一下，最直接的方法是docker起来一个现成的，但是发现起来后界面一直打不开，换了几个版本都不行，只能暂时放弃，转而尝试手动安装的方法，

手动安装其实也很简单，

curl https://debian.neo4j.org/neotechnology.gpg.key | apt-key add -，

sudo vim /etc/apt/sources.list.d/neo4j.list，

deb http://debian.neo4j.org/repo stable/，

sudo apt update，

sudo apt install neo4j，

启动之前先修改配置文件，

sudo vim /etc/neo4j/neo4j.conf，

dbms.connectors.default\_listen\_address=0.0.0.0，

这就可以启动服务了，service neo4j start，

迫不及待的按简易教程走两步，

录入一些数据，

CREATE (ee:Person { name: "Emil", from: "Sweden", klout: 99 }),  
(js:Person { name: "Johan", from: "Sweden", learn: "surfing" }),  
(ir:Person { name: "Ian", from: "England", title: "author" }),  
(rvb:Person { name: "Rik", from: "Belgium", pet: "Orval" }),  
(ally:Person { name: "Allison", from: "California", hobby: "surfing" }),  
(ee)-\[:KNOWS {since: 2001}\]->(js),(ee)-\[:KNOWS {rating: 5}\]->(ir),  
(js)-\[:KNOWS\]->(ir),(js)-\[:KNOWS\]->(rvb),  
(ir)-\[:KNOWS\]->(js),(ir)-\[:KNOWS\]->(ally),  
(rvb)-\[:KNOWS\]->(ally)

然后查询，

MATCH (ee:Person)-\[:KNOWS\]-(friends)  
WHERE ee.name = "Emil" RETURN ee, friends
