新版本OSM，也就是OSM7.0，支持了容器的编排，本周就来实践一下，

首先是安装一套kubernetes集群，这个以前实践过多次，不再详述，值得记录的一点是，本周发现用阿里的源确实很方便，只需在源配置时做如下操作，

curl https://mirrors.aliyun.com/kubernetes/apt/doc/apt-key.gpg | apt-key add -，

sudo vim /etc/apt/sources.list.d/kubernetes.list，

deb https://mirrors.aliyun.com/kubernetes/apt/ kubernetes-xenial main，

然后是安装一套OSM7.0的环境，从7.0开始，OSM的安装和使用指南升级了，参考https://osm.etsi.org/docs/user-guide/01-quickstart.html即可，太简单，也不再详述，值得记录的一点是，在国内确实可以安装出来，以后也不用再从外面往回到虚机镜像了，

想要实践OSM编排容器，要求kubernetes集群支持helm服务，这个稍详细记录一下，

下载helm2的最新版本，wget https://get.helm.sh/helm-v2.16.1-linux-amd64.tar.gz，

解压后，把可执行程序移动到系统执行目录，sudo mv linux-amd64/helm /usr/local/bin/，

先初始化客户端，helm init -c，

kubectl --namespace kube-system create serviceaccount tiller，

kubectl create clusterrolebinding tiller --clusterrole cluster-admin --serviceaccount=kube-system:tiller，

最后启动服务端，helm init --service-account tiller，

kubernetes这边就齐活儿了，接着去OSM那边，  

参考https://osm.etsi.org/docs/user-guide/05-osm-usage.html#using-kubernetes-based-vnfs-knfs，

第一步添加kubernetes集群，需要把kubernetes集群master节点下.kube/config拷贝出来，重新命名成kubeconfig-cluster.yaml放到OSM的命令行下，这就可以执行命令添加kubernetes集群了，

osm k8scluster-add --creds kubeconfig-cluster.yaml --version '1.17' --vim OpenStack-Site --description "My K8s cluster" --k8s-nets '{"net1": "ext"}' cluster，
