本博主一直混迹于NFV技术领域，自然对各种MANO特别上心，之前长期实践OpenStack的组件Tacker，以及ETSI旗下的开源产品OSM，甚至国内运营商推崇的ONAP也尝试过（尽管没能成功），这几个都是MANO，VNFM是MANO中最重要的部分，而MANO区别于VNFM的关键是有没有NFVO，......，得，啰嗦了，本博主一向习惯是多实践，不解释，书归正传，

本周实践的是一个超强的VNFM产品，terraform，这货强大到什么地步呢，看它支持的云平台列表就知道了，当然已不限于云平台，

https://www.terraform.io/docs/providers/index.html，

这是本博主首次实践terraform，那就挑一个最方便的云平台来，就OpenStack吧，参考https://www.terraform.io/docs/providers/openstack/index.html即可，OpenStack环境用devstack跑就行了，不再详述，

首先下载terraform可执行程序，

https://www.terraform.io/downloads.html，

接着就按指南来，创建几个文件，

sudo vim provider.tf
provider "openstack" {
  user_name = "${var.openstack_user_name}"
  tenant_name = "${var.openstack_tenant_name}"
  password  = "${var.openstack_password}"
  auth_url  = "${var.openstack_auth_url}"
}
sudo vim variables.tf
variable "image" {
  default = "cirros-0.4.0-x86_64-disk"
}
variable "flavor" {
  default = "m1.tiny"
}
variable "availability_zone" {
        default = "nova"
}
variable "security_group" {
        default = "default"
}
variable "network" {
        default  = "admin-service"
}
sudo vim terraform.tfvars
openstack_user_name = "admin"
openstack_tenant_name = "admin"
openstack_password = "password"
openstack_auth_url = "http://10.90.11.250/identity/v3"
sudo vim deploy.tf
resource "openstack_compute_instance_v2" "cirros-vm" {
  count = "1"
  name = "cirros-1"
  image_name = "${var.image}"
  availability_zone = "${var.availability_zone}"
  flavor_name = "${var.flavor}"
  security_groups = ["${var.security_group}"]
  network {
    name = "${var.network}"
  }
}

下面就到执行阶段了，

先初始化，把云平台插件同步下来，./terraform init，


然后./terraform plan和./terraform apply真正执行，

通过./terraform show查看执行结果，

到OpenStack那边看效果，
