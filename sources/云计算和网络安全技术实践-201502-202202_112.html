用EPK监控容器环境内部的流量

我们都熟悉ELK，EPK就是把L换成P，也就是packetbeat，因为packetbeat能够把监控到的流量数据直接吐给elasticsearch，这样logstash也就不需要了，怎么用EPK的组合来监控容器内部的流量呢，

首先在容器外面安装一套elasticsearch+kibana的组合，这个容易，参考官网给的指导就可以了，这里不再详述，

接下来就是制作packetbeat的容器镜像，这个也不难，搞个ubuntu的容器镜像，然后在里面安装packetbeat的好了，也直接参考官方指南即可，

注意修改packetbeat的配置文件，vim /etc/packetbeat/packetbeat.yml，

监控所有宿主机所有接口的流量，packetbeat.interfaces.device: any，

监控数据直接吐给外面的elasticsearch，

output.elasticsearch:
  # Array of hosts to connect to.
  hosts: ["192.168.137.100:9200"]
接下来写一个deamonset模板，sudo vim packetbeat-deamonset.yaml，

apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: packetbeat
  namespace: kube-system
  labels:
    k8s-app: packetbeat
spec:
  selector:
    matchLabels:
      name: packetbeat
  template:
    metadata:
      labels:
        name: packetbeat
    spec:
      hostNetwork: true
      hostPID: true
      containers:
      - name: packetbeat
        image: packetbeat:0.1
        command: ["packetbeat"]
        args: ["-e", "-c", "/etc/packetbeat/packetbeat.yml"]
        imagePullPolicy: IfNotPresent
        securityContext:
          privileged: true
      terminationGracePeriodSeconds: 30
执行，kubectl apply -f packetbeat-daemonset.yaml，

稍等一会儿去kibana上看效果，

容器内部不仅能做流量监控，还能做容器实例的网络通信异常监控，我们下周继续。
