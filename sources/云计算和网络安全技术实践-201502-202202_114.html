以前一直都拿All In One的Kubernetes环境做实验，最近有了多计算节点的需要，这里把Kubernetes计算节点的安装和加入集群的过程记录一下，

先把All In One的Master节点装出来，以前有过记录，这里就不多说了，

还是用ubuntu安装计算节点，

docker在计算节点里必须要装的，

sudo apt install docker.io，

sudo systemctl enable docker，

Kubernetes的组件仅需要安装kubeadm，

curl -s https://packages.cloud.google.com/apt/doc/apt-key.gpg | apt-key add -，

sudo vim /etc/apt/sources.list.d/kubernetes.list，

deb http://apt.kubernetes.io/ kubernetes-xenial main，

sudo apt update，

sudo apt install kubeadm，

同样需要做swapoff，sudo swapoff -a，

同样需要在sysctl.conf里打开net.ipv4.conf.all.rp_filter和net.ipv4.ip_forward，

接下来就是加入Master的集群了，

去Master执行命令，kubeadm token create --print-join-command，

会生成一串命令，sudo kubeadm join 192.168.137.101:6443 --token 6czhfk.3h6ldvh6ldyvtpu6     --discovery-token-ca-cert-hash sha256:68ba131cda7903d66b65f382e588d3bd6ee4584591050c90517abc25deedd277，

拷贝下来回到计算节点上执行，等待执行成功，

再回到Master节点上查看，能看到两个Node了，而且calico-node的pod出现了两个，说明一切正常，

下面来做个实验，验证容器部署会分布在两个Node里，

先在两个Node里都把测试image都pull下来，docker image pull httpd，

然后在Master上编辑一个deployment的yaml文件，

apiVersion: apps/v1
kind: Deployment
metadata:
  name: httpd
  labels:
    app: httpd
spec:
  replicas: 3
  selector:
    matchLabels:
      app: httpd
  template:
    metadata:
      labels:
        app: httpd
    spec:
      containers:
      - name: httpd
        image: httpd
        imagePullPolicy: IfNotPresent
        ports:
        - containerPort: 80

执行kubectl apply -f httpd-deployment.yaml，

再查看pod分布情况，

这个deployment的pod被自动分配到了两个Node上，
