# 容器安全实践之falco

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650745354&idx=1&sn=546e6310767b62048be0e27b0337c761&chksm=87148b0ab063021cf94a6511f7f59bc69cd1da9ec489b38bb23fa7d5ea1a1939a43a5a38a321&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650745354&idx=1&sn=546e6310767b62048be0e27b0337c761&chksm=87148b0ab063021cf94a6511f7f59bc69cd1da9ec489b38bb23fa7d5ea1a1939a43a5a38a321&scene=27#wechat_redirect)

falco是一个进程级别的开源容器安全方案，以daemonset方式起在每个容器node上，对容器的进程级别行为进行监控，下面是详细实践过程，

首先是安装K8S环境，之前有很多实践记录了，这里不再详述，

在K8S环境里安装falco，

下载最新版本的源码，  

git clone https://github.com/falcosecurity/falco/，

进入目录，  

cd falco/integrations/k8s-using-daemonset，

创建账户和服务，  

kubectl apply -f k8s-with-rbac/falco-account.yaml，

kubectl apply -f k8s-with-rbac/falco-service.yaml，

mkdir -p k8s-with-rbac/falco-config，

cp ../../falco.yaml k8s-with-rbac/falco-config/，

cp ../../rules/falco\_rules.\* k8s-with-rbac/falco-config/，

cp ../../rules/k8s\_audit\_rules.yaml k8s-with-rbac/falco-config/，

kubectl create configmap falco-config --from-file=k8s-with-rbac/falco-config，

创建daemonset容器，

kubectl apply -f k8s-with-rbac/falco-daemonset-configmap.yaml，

稍等片刻，安装完成，
