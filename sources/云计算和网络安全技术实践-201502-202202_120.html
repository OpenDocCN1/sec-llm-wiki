VLAN模式的OpenStack可谓是老古董了，最后一次安装这种模式怎么也得3年前了，后来一直都直接拿DevStack自动跑出来OpenStack的实验环境，默认是VXLAN模式，也从没再想过VLAN模式。

最近工作需要又得搭建VLAN模式的OpenStack环境，

由于我是在WorkStation里做的实验，首先得把VLAN TRUNK的环境搞定，

外部网络的网卡得改到VMnet0上，


VMnet0是桥接模式，这种网卡就能做VLAN TRUNK了，

先研究DevStack怎么能自动跑出来，参考https://docs.openstack.org/devstack/latest/guides/neutron.html，各种参数调整，跑了好几遍，就是不能成功，

于是转换思路，先拿DevStack跑VXLAN模式的，然后再想办法手动改配置文件，多亏以前手动安装VLAN模式的配置都有记录，照着以前的配置文件硬改，

sudo vim /etc/neutron/plugins/ml2/ml2_conf.ini
[ml2]
type_drivers = flat,vlan
tenant_network_types = vlan
mechanism_drivers = openvswitch
extension_drivers = port_security
[ml2_type_vlan]
network_vlan_ranges = physnet1:100:200
[ovs]
tenant_network_types = vlan
network_vlan_ranges = physnet1:100:200
integration_bridge = br-int
bridge_mappings = physnet1:br-eth,public:br-ex

当然OVS上也得手动创建br-eth，并把原来绑在br-ex上的外部网卡手动解绑，然后再手动绑到br-eth上，

重启以后，环境就是VLAN模式的了，

创建一个租户网络，

看好VLAN ID，在外面搞一台我司的vFW，配置好子接口，

在网络里创建一台测试虚机，

从虚机里ping网关，

完美搞定。
