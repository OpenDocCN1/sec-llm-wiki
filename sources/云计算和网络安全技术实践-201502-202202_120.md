VLAN模式的OpenStack可谓是老古董了，最后一次安装这种模式怎么也得3年前了，后来一直都直接拿DevStack自动跑出来OpenStack的实验环境，默认是VXLAN模式，也从没再想过VLAN模式。  

最近工作需要又得搭建VLAN模式的OpenStack环境，

由于我是在WorkStation里做的实验，首先得把VLAN TRUNK的环境搞定，

外部网络的网卡得改到VMnet0上，  

![](../Images/bf2b38935ea04f3b049d3016537ec3d6.png)  

VMnet0是桥接模式，这种网卡就能做VLAN TRUNK了，

![](../Images/15a9149bcbff22bc4df41c1d3d3a731e.png)

先研究DevStack怎么能自动跑出来，参考https://docs.openstack.org/devstack/latest/guides/neutron.html，各种参数调整，跑了好几遍，就是不能成功，

于是转换思路，先拿DevStack跑VXLAN模式的，然后再想办法手动改配置文件，多亏以前手动安装VLAN模式的配置都有记录，照着以前的配置文件硬改，

sudo vim /etc/neutron/plugins/ml2/ml2\_conf.ini  
\[ml2\]  
type\_drivers = flat,vlan  
tenant\_network\_types = vlan  
mechanism\_drivers = openvswitch  
extension\_drivers = port\_security  
\[ml2\_type\_vlan\]  
network\_vlan\_ranges = physnet1:100:200  
\[ovs\]  
tenant\_network\_types = vlan  
network\_vlan\_ranges = physnet1:100:200  
integration\_bridge = br-int  
bridge\_mappings = physnet1:br-eth,public:br-ex

当然OVS上也得手动创建br-eth，并把原来绑在br-ex上的外部网卡手动解绑，然后再手动绑到br-eth上，

![](../Images/ae0601ffaedeee4944c01f117f41dfeb.png)

重启以后，环境就是VLAN模式的了，
