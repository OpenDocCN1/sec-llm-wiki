最近会一连串实践开源的基于流量分析的网络安全方案，以前实践过ELK系列的，最近发现这一领域不断的成熟，大有快干过商用产品和方案之势，

本周实践的是moloch，闲话少说，看东西，

这是个一体机的方案，跟我以前实践过的ntopng+EK的方案类似，这个的集成度更高，不用自己费心思安装EK，都包含在moloch的安装里了，而且moloch还有自己独立的UI，体验还是不错的，

既然是一体的，就还是老规矩，搞个最新的ubuntu19.04，

需要先安装两个用到的软件，sudo apt install python，

sudo apt install default-jre，

然后下载moloch主线版本的源码，

git clone https://github.com/aol/moloch，

进入文件夹，cd moloch，  

开始安装，sudo ./easybutton-build.sh --install，

安装过程中会让填各种参数，按实际情况填就好，  

让执行命令也来，比如sudo make config，

最后还要按提示进行服务的初始化，

sudo systemctl start elasticsearch.service，

sudo /data/moloch/db/db.pl http://localhost:9200 init，

sudo /data/moloch/bin/moloch\_add\_user.sh admin "Admin User" password --admin，

sudo systemctl start molochcapture.service，

sudo systemctl start molochviewer.service，

然后就可以直接访问moloch的UI了，我这里是http://10.90.3.2:8005，

首先用上面配置的密码登录，我这里是admin/password，

第一个界面是会话分析，每个会话都很详细，点进去甚至能看到应用层的内容，这点比packetbeat强，
