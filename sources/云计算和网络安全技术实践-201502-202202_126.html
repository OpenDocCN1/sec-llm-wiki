本来这个内容是投topic给今年11月份上海OpenStack峰会的，怎奈人家没识货，就详细写出来保留在这里吧，供有缘人参考。

先嵌套虚拟化出来一个ubuntu19.04，外面配置好向上传递cpu虚拟化，

配置宿主机对大页内存的支持，sudo vim /etc/default/grub，

GRUB_CMDLINE_LINUX="hugepagesz=2M hugepages=8192 iommu=pt intel_iommu=on"，

sudo update-grub，sudo reboot，

重启后检查一下，dmesg | grep -e DMAR -e IOMMU，

cat /proc/cmdline，

开始安装DevStack，

git clone https://opendev.org/openstack/devstack.git，

sudo chown -R ubuntu:ubuntu /home/ubuntu/devstack，

sudo mkdir /opt/stack，

sudo chown -R ubuntu:ubuntu /opt/stack，

sudo vim /home/ubuntu/devstack/local.conf，

[[local|localrc]]
PUBLIC_INTERFACE=ens192
SERVICE_PASSWORD=password
ADMIN_PASSWORD=password
SERVICE_TOKEN=password
DATABASE_PASSWORD=password
RABBIT_PASSWORD=password
enable_plugin networking-sfc https://opendev.org/openstack/networking-sfc
enable_plugin networking-ovs-dpdk https://opendev.org/x/networking-ovs-dpdk
OVS_DPDK_MODE=controller_ovs_dpdk
OVS_DATAPATH_TYPE=netdev
Q_USE_SECGROUP=False
LIBVIRT_FIREWALL_DRIVER=nova.virt.firewall.NoopFirewallDriver
disable_service tempest
[[post-config|/etc/neutron/dhcp_agent.ini]]
[DEFAULT]
enable_isolated_metadata = True

安装之前要手动下载OVS和DPDK版本，

cd /opt/stack，

sudo wget https://github.com/DPDK/dpdk/archive/v18.11.tar.gz，

解压后，sudo mv dpdk-18.11 DPDK-v17.11，

sudo wget https://github.com/openvswitch/ovs/archive/v2.11.0.tar.gz

解压后，sudo mv ovs-2.11.0 ovs，

这就可以开始安装了，

cd /home/ubuntu/devstack，FORCE=yes ./stack.sh，

安装过程中到DPDK的阶段会跳出，这时手动操作一下，

sudo ovs-vsctl --no-wait set Open_vSwitch . other_config:dpdk-socket-mem="1024"，

sudo ovs-vsctl --no-wait set Open_vSwitch . other_config:dpdk-init=true，

sudo /usr/share/openvswitch/scripts/ovs-ctl start，

sudo ovs-vsctl get Open_vSwitch . dpdk_initialized，

grep "Huge" /proc/meminfo，

然后再重新FORCE=yes ./stack.sh，

这就能正常安装成功到最后了，

创建两个大页内存的flavor，

openstack flavor create --id 6 --vcpus 1 --ram 64 --disk 0 --property hw:mem_page_size=large cirros，

openstack flavor create --id 7 --vcpus 2 --ram 2048 --disk 4 --property hw:mem_page_size=large vfw_vnf，

把测试虚机和支持NSH的防火墙虚机都创建出来，

为了后面验证NSH，防火墙虚机的服务接口需要独立创建，

在OVS上能够看到虚拟机接口都是vhost类型，

接下来就可以验证NSH了，

openstack sfc port pair create --ingress p1 --egress p1 --service-function-parameters correlation=nsh pp1，

openstack sfc port pair group create --port-pair pp1 ppg1，

openstack sfc flow classifier create --destination-ip-prefix 10.0.0.108/32 --logical-source-port c4ff007e-70c1-40dd-91d4-c5b779a1faaa fc1，

openstack sfc port chain create --port-pair-group ppg1 --flow-classifier fc1 --chain-parameters correlation=nsh pc1，

可以查看配置成功的openflow规则，
