先嵌套虚拟化出来一个ubuntu19.04，外面配置好向上传递cpu虚拟化，

配置宿主机对大页内存的支持，sudo vim /etc/default/grub，

GRUB\_CMDLINE\_LINUX="hugepagesz=2M hugepages=8192 iommu=pt intel\_iommu=on"，

sudo update-grub，sudo reboot，

重启后检查一下，dmesg | grep -e DMAR -e IOMMU，

cat /proc/cmdline，

开始安装DevStack，

git clone https://opendev.org/openstack/devstack.git，

sudo chown -R ubuntu:ubuntu /home/ubuntu/devstack，

sudo mkdir /opt/stack，

sudo chown -R ubuntu:ubuntu /opt/stack，

sudo vim /home/ubuntu/devstack/local.conf，

\[\[local|localrc\]\]  
PUBLIC\_INTERFACE=ens192  
SERVICE\_PASSWORD=password  
ADMIN\_PASSWORD=password  
SERVICE\_TOKEN=password  
DATABASE\_PASSWORD=password  
RABBIT\_PASSWORD=password  
enable\_plugin networking-sfc https://opendev.org/openstack/networking-sfc  
enable\_plugin networking-ovs-dpdk https://opendev.org/x/networking-ovs-dpdk  
OVS\_DPDK\_MODE=controller\_ovs\_dpdk  
OVS\_DATAPATH\_TYPE=netdev  
Q\_USE\_SECGROUP=False  
LIBVIRT\_FIREWALL\_DRIVER=nova.virt.firewall.NoopFirewallDriver  
disable\_service tempest  
\[\[post-config|/etc/neutron/dhcp\_agent.ini\]\]  
\[DEFAULT\]  
enable\_isolated\_metadata = True  

安装之前要手动下载OVS和DPDK版本，

cd /opt/stack，

sudo wget https://github.com/DPDK/dpdk/archive/v18.11.tar.gz，

解压后，sudo mv dpdk-18.11 DPDK-v17.11，  

sudo wget https://github.com/openvswitch/ovs/archive/v2.11.0.tar.gz  

解压后，sudo mv ovs-2.11.0 ovs，

这就可以开始安装了，

cd /home/ubuntu/devstack，FORCE=yes ./stack.sh，  

安装过程中到DPDK的阶段会跳出，这时手动操作一下，

sudo ovs-vsctl --no-wait set Open\_vSwitch . other\_config:dpdk-socket-mem="1024"，

sudo ovs-vsctl --no-wait set Open\_vSwitch . other\_config:dpdk-init=true，

sudo /usr/share/openvswitch/scripts/ovs-ctl start，

sudo ovs-vsctl get Open\_vSwitch . dpdk\_initialized，

grep "Huge" /proc/meminfo，

然后再重新FORCE=yes ./stack.sh，

这就能正常安装成功到最后了，

创建两个大页内存的flavor，  

openstack flavor create --id 6 --vcpus 1 --ram 64 --disk 0 --property hw:mem\_page\_size=large cirros，

openstack flavor create --id 7 --vcpus 2 --ram 2048 --disk 4 --property hw:mem\_page\_size=large vfw\_vnf，

把测试虚机和支持NSH的防火墙虚机都创建出来，

为了后面验证NSH，防火墙虚机的服务接口需要独立创建，

在OVS上能够看到虚拟机接口都是vhost类型，  

![](../Images/ab7d85eef3c0123bd5925faad6f134db.png)

接下来就可以验证NSH了，  

openstack sfc port pair create --ingress p1 --egress p1 --service-function-parameters correlation=nsh pp1，

openstack sfc port pair group create --port-pair pp1 ppg1，

openstack sfc flow classifier create --destination-ip-prefix 10.0.0.108/32 --logical-source-port c4ff007e-70c1-40dd-91d4-c5b779a1faaa fc1，

openstack sfc port chain create --port-pair-group ppg1 --flow-classifier fc1 --chain-parameters correlation=nsh pc1，
