很久以来，一直想实践一下ONAP，明知山有虎，偏向虎山行，哈哈，

主要这次是K8S的环境准备好了，参考https://docs.onap.org/en/latest/submodules/oom.git/docs/oom_quickstart_guide.html，感觉不算太难，就试试吧，

在上两期calico模式的K8S环境中，

首先安装helm，

wget https://get.helm.sh/helm-v2.14.3-linux-amd64.tar.gz，

sudo mv linux-amd64/helm /usr/sbin/，

helm init -c，

kubectl --namespace kube-system create serviceaccount tiller，

kubectl create clusterrolebinding tiller --clusterrole cluster-admin --serviceaccount=kube-system:tiller，

helm init --service-account tiller，

然后就按照官方指南开始安装ONAP，

git clone -b 4.0.0-ONAP http://gerrit.onap.org/r/oom --recurse-submodules，

cd oom/kubernetes，

sudo cp -R ~/oom/kubernetes/helm/plugins/ ~/.helm，
helm serve &，

helm repo add local http://127.0.0.1:8879，

helm repo list，

sudo apt install make，

make all; make onap，

这个时间挺长，

helm search onap -l，

sudo helm deploy dev local/onap --namespace onap -f onap/resources/overrides/onap-vfw.yaml --timeout 900，
