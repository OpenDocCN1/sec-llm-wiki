上两周一直在研究容器环境下的抓包方法，其实是最后已经实践明白了K8S下不碰host的方案，抓包容器随着K8S系统启动，健壮性很高，而且能把抓包远程写到文件服务器上，暂时本博先不做公开，yi以后zhao

在任何系统环境里做安全，都要首先把这个系统环境的应用方式研究清楚，最近一段时间一直投入在K8S安全的研究之中，本周开始从头梳理K8S的应用方式，

通过模板部署pod，

sudo vim httpd-deployment.yaml，

apiVersion: apps/v1
kind: Deployment
metadata:
  name: httpd
  labels:
    app: httpd
spec:
  replicas: 3
  selector:
    matchLabels:
      app: httpd
  template:
    metadata:
      labels:
        app: httpd
    spec:
      containers:
      - name: httpd
        image: httpd
        imagePullPolicy: IfNotPresent
        ports:
        - containerPort: 80

kubectl apply -f httpd-deployment.yaml，

kubectl get pod -o wide，

通过模板部署service，

sudo vim httpd-service.yaml，

apiVersion: v1
kind: Service
metadata:
  name: httpd-service
spec:
  selector:
    app: httpd
  ports:
  - protocol: TCP
    port: 8080
    targetPort: 80
kubectl apply -f httpd-service.yaml，

kubectl get service，

kubectl describe service httpd-service，

通过host的端口向外暴露service，

sudo vim httpd-service.yaml，

apiVersion: v1
kind: Service
metadata:
  name: httpd-service
spec:
  type: NodePort
  selector:
    app: httpd
  ports:
  - protocol: TCP
    nodePort: 31688
    port: 8080
    targetPort: 80

kubectl apply -f httpd-service.yaml，

kubectl get service，
