# 在Docker环境下抓包

由于Docker环境下的容器通常都跟宿主机共享内核，抓包就很简单了，在宿主机上直接tcpdump即可，要是真这么简单，本博主也就没有实践的必要了，按照本博主一贯坚持的理念，虚拟化的问题要用虚拟化解决，那么容器的问题也要用容器解决，本周末实践的方法是，用容器来抓包，并可远程下载抓包文件，  

首先build抓包容器镜像，

sudo vim Dockerfile，

FROM debian  
RUN apt-get update && apt-get install -y \\  
tcpdump  
RUN mkdir /pcap  
RUN cd /pcap  
WORKDIR /pcap  
CMD tcpdump -i docker0 -G 900 -w '%Y-%m-%d\_%H:%M:%S.pcap' -W 96  

sudo docker build -t private/tcpdump:v1.0 .，

查看创建好的容器镜像，  

sudo docker image list，

创建抓包容器实例，  

sudo docker run -v ~/pcap:/pcap --net=host -d 34bb621b61cf，

再创建远程下载抓包文件的容器实例，

sudo docker run -h tccdumpweb -p 1337:80 -v ~/pcap:/var/www/html/ -d eboraas/apache，

创建两个业务容器实例，

sudo docker run -d astasheep/ubuntu-sshd:14.04，

sudo docker run -d httpd，
