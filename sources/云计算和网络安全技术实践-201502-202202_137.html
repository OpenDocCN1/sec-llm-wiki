书接上回，上回书说到开源容器漏洞扫描器clair没整明白，本博主可不是个轻言放弃之人，本周研究了一下harbor+clair的共同实践，算是间接达到目的了吧，

安装ubuntu-19.04系统，

安装docker，apt install docker.io，

安装docker-compose，apt install docker-compose，

给harbor起个本地域名，vim /etc/hosts，

192.168.137.149 harborclair.com，

给harbor创建个自签名证书，

openssl req -x509 -nodes -newkey rsa:4096 -sha256 -days 999 \
    -keyout /home/ubuntu/harborclair.com.key \
    -out /home/ubuntu/harborclair.com.crt \
    -subj "/C=CN/ST=docker/L=beijing/O=harborclair/OU=New site/CN=harborclair.com/emailAddress=admin@harborclair.com"，

下载harbor当前最新版本在线安装包，

wget https://storage.googleapis.com/harbor-releases/release-1.8.0/harbor-online-installer-v1.8.0.tgz，

解压，tar -zxvf harbor-online-installer-v1.8.0.tgz，

进入目录，修改配置文件，

cd harbor，vim harbor.yml，

hostname: harborclair.com

https:
  port: 443
  certificate: /home/ubuntu/harborclair.com.crt
  private_key: /home/ubuntu/harborclair.com.key

harbor_admin_password: harborclair

开始安装，./install.sh --with-clair，

看到如下结果，那就是安装成功了，

能看到起了很多服务容器，

迫不及待的访问管理界面看看，

下周往仓库里整一个容器镜像试试，

先得把证书放到docker客户端本地，

mkdir -p /etc/docker/certs.d/harborclair.com，

cp /home/ubuntu/harborclair.com.crt /etc/docker/certs.d/harborclair.com，

登录，docker login --username=admin harborclair.com，

报错，Error saving credentials: error storing credentials - err: exit status 1, out: `Cannot autolaunch D-Bus without X11 $DISPLAY`，

解决方法是卸载相应的软件，

apt purge golang-docker-credential-helpers，apt autoremove，

再把docker-compose装回来，pip install -U docker-compose，

docker-compose报错，ImportError: No module named ssl_match_hostname，

解决方法是卸载相应的软件，

pip uninstall backports.ssl-match-hostname，再装回来，

apt install python-backports.ssl-match-hostname，

这就能登录成功了，

先把要传到harbor仓库里的容器镜像从docker-hub上搞下来，

docker pull rastasheep/ubuntu-sshd:14.04，

再往harbor仓库里推，

docker tag rastasheep/ubuntu-sshd:14.04 harborclair.com/library/ubuntu-sshd:14.04，

docker push harborclair.com/library/ubuntu-sshd:14.04，

赶紧去管理界面上查看，确实有了，

点进去，发现可以配置镜像上传时自动漏洞扫描，

这次就手动扫吧，

再点进去，能看到详细漏洞条目，
