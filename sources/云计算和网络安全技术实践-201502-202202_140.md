# 在OpenStack里优雅的使用容器做NAT

以前我写过在OpenStack里优雅的使用虚机做NAT，本周末用同样的方法实践了一下用容器做NAT，

实践环境还是DevStack，为了方便的使用容器，使能了Zun，

以前贴过使能的方法，基本的就不多说了，着重说一下特殊的，

为了让容器能做NAT，就得让容器有路由的能力，而这样是需要在容器启动时给特权的，privileged，

DevStack安装出来的Zun默认是不允许给privileged的，

需要安装前手动进行如下操作，

创建一个policy.json文件，sudo vim /home/ubuntu/policy.json，

里面添加如下内容，

"container:create:privileged": "rule:context\_is\_admin"，

并在DevStack安装脚本local.conf里添加如下内容，

\[\[post-config|/etc/zun/zun.conf\]\]  
\[oslo\_policy\]  
policy\_file = /home/ubuntu/policy.json

这样安装出来的DevStack环境就可以实践用容器做NAT了，

在全局下Pull容器的image，我用的rastasheep/ubuntu-sshd:14.04，

![](../Images/7bddfd112392a459303e3f8c6df0accc.png)

在命令行下创建用来做NAT的容器，

openstack appcontainer run --net network=ext --net network=vfw-service --privileged rastasheep/ubuntu-sshd:14.04，成功后能在Dashboard上看到，

![](../Images/66611f2f3c4c39edf6f6f0cac625bfeb.png)

做NAT业务所需的一切操作，

apt update，apt install vim，

vim /etc/sysctl.conf，net.ipv4.ip\_forward=1，sysctl -p，

apt install iptables，

iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE，

iptables -t nat -A PREROUTING -d 10.90.11.241 -p tcp --dport 222 -j DNAT --to 10.0.0.179:22，

route add -net 10.0.0.0/24 gw 172.16.1.1，
