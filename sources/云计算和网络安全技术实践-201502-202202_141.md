参考cilium的官方指南，https://docs.cilium.io/en/stable/gettingstarted/docker/，先用vagrant的方法，

外层用的ubuntu18.04desktop版本，

安装virtualbox，apt install virtualbox，

安装vagrant，apt install vagrant，

安装其它必要的软件，apt install openssh-server net-tools vim git，

下载cilium的源码，git clone https://github.com/cilium/cilium，

用vagrant安装docker+cilium的虚机，

cd cilium/examples/getting-started，vagrant up，

成功以后就可以直接ssh访问进去了，

我想要的是在docker环境里直接安装cilium，

docker的安装就不说了，以前安装过多次了，

下载cilium程序，

wget -O /usr/local/bin/cilium http://releases.cilium.io/v1.4.1/cilium-x86\_64，

chmod +x /usr/local/bin/cilium，

创建一个docker-compose模板，vim docker-compose.yml，

version: '2'  
services:  
  cilium:  
    container\_name: cilium  
    image: docker.io/cilium/cilium:v1.4.1  
    command: cilium-agent --kvstore consul --kvstore-opt consul.address=127.0.0.1:8500 -t vxlan  
    volumes:  
      - /var/run/docker.sock:/var/run/docker.sock  
      - /var/run/cilium:/var/run/cilium  
      - /sys/fs/bpf:/sys/fs/bpf  
      # To access Docker container netns:  
      - /var/run/docker/netns:/var/run/docker/netns:rshared  
      # To create named netns for cilium-health endpoint:  
      - /var/run/netns:/var/run/netns:rshared  
    network\_mode: "host"  
    cap\_add:  
      - "NET\_ADMIN"  
    privileged: true  
    depends\_on:  
      - consul  
  
  cilium\_docker:  
    container\_name: cilium-docker-plugin  
    image: docker.io/cilium/docker-plugin:v1.4.1  
    command: cilium-docker  
    volumes:  
      - /var/run/cilium:/var/run/cilium  
      - /run/docker/plugins:/run/docker/plugins  
    network\_mode: "host"  
    cap\_add:  
      - "NET\_ADMIN"  
    privileged: true  
    depends\_on:  
      - cilium  
  
  consul:  
    container\_name: cilium-kvstore  
    ports:  
      - "8500:8500"  
    environment:  
      - "CONSUL\_LOCAL\_CONFIG={\\"skip\_leave\_on\_interrupt\\": true, \\"disable\_update\_check\\": true}"  
    image: docker.io/library/consul:0.8.3  
    command: agent -client=0.0.0.0 -server -bootstrap-expect 1

把bpf打开，sudo mount bpffs /sys/fs/bpf -t bpf，

运行docker-compose，docker-compose up -d，
