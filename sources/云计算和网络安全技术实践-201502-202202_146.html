这周末差点忘了更新，本周重新在ubuntu18.04里实践的ansible，

安装很简单，apt install ansible，

编辑环境变量，vim /etc/ansible/hosts，

[linux]
192.168.137.102 ansible_ssh_user='ubuntu' ansible_ssh_pass='ubuntu' ansible_sudo_pass='ubuntu'

执行个最简单的命令，ansible linux -a 'ifconfig'，

报错发现没安装sshpass，就给安装一下，apt install sshpass，再重新执行之前的命令，

没找到python的正确路径，这是因为ubuntu18.04里的python是python3了，需要在变量文件中指示，

[linux]
192.168.137.102 ansible_ssh_user='ubuntu' ansible_ssh_pass='ubuntu' ansible_sudo_pass='ubuntu' ansible_python_interpreter='/usr/bin/python3'

再重新执行之前的命令，

说是向目标做ssh的时候检查key了，本地没有，以前我是手动执行一遍ssh目标机，让key存一下，这次来点儿高级的，在环境变量里指定不检查key，

[linux]
192.168.137.102 ansible_ssh_user='ubuntu' ansible_ssh_pass='ubuntu' ansible_sudo_pass='ubuntu' ansible_python_interpreter='/usr/bin/python3' ansible_ssh_extra_args='-o StrictHostKeyChecking=no'

再次执行之前的命令，就成功了，

同样再实践一下playbook，

编辑剧本，vim playbook.yaml，

- hosts: linux
  gather_facts: no

  tasks:
  - name: install apache2
    become: yes
    command: sudo apt -y install apache2

执行剧本，ansible-playbook playbook.yaml，

执行成功，再看一下效果，

说明剧本确实得到了正确的执行。
