k8s这个玩意儿安装真的太费劲，之前实践过minikube和手动安装，都够麻烦的，本周末尝试了一下microk8s，还算凑合，

在ubuntu18.04下进行实践，默认就支持通过snap安装microk8s，

先看看都能安装哪些版本，snap info microk8s，

![](../Images/07164d051d569a801bd9d315f23bcb5b.png)

直接安装当前最新稳定版本，

sudo snap install microk8s --classic，

成功后，再安装额外功能，都有哪些呢，

![](../Images/647f7546a0f02dfe4b70b4d61393297a.png)

我先安装3个看看效果，

microk8s.enable dns dashboard istio，  
成功后，查看当前都有哪些pod，

microk8s.kubectl get pods --all-namespaces，

![](../Images/91c4c527045c65385da54a39a8431f56.png)

可以看到istio的3个pod没有running，也不知道是啥情况，

想访问dashboard需要使能proxy，

microk8s.kubectl proxy --accept-hosts=.\* --address=0.0.0.0 &，

再访问代理的URL，

http://192.168.137.250:8001/api/v1/namespaces/kube-system/services/https:kubernetes-dashboard:/proxy/，

![](../Images/8bf752f65036d7a972adb689aab51e1f.png)

创建一个业务容器pod，

![](../Images/75749343d08c0213c5356faec4657d93.png)

部署的效果，

![](../Images/cff5b65ef44c2af054905f09779cf3c3.png)

服务的效果，

![](../Images/8633b40bd1695f6c9d829bd6253066e6.png)

从外面无法访问，从里面试试，没问题，

![](../Images/10324ac7da8b6d51d8984bff3beeb1c9.png)

microk8s总体来说还算简单，但是k8s本身就没那么容易了，各种概念不太好理解，业务、部署、容器组，负载均衡互相之间都啥关系，用microk8s安装出来的好多地址都是静态私有的，怎么从外面访问，以后再继续研究。
