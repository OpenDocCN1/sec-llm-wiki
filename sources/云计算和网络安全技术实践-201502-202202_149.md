# Zun+Kata Containers的实践（一）

Docker的安全性一直成为其未来代替虚机的关键顾虑，Kata Containers通过轻量级虚机技术解决了这一问题，让容器和宿主机之间在内核上得到了隔离，同时又兼有容器的秒停秒起的效率。

本周末在Zun下实践了一下Kata Containers，

先搭建DevStack+Zun的环境，不再详述，

然后安装Kata Containers，

sudo sh -c "echo 'deb http://download.opensuse.org/repositories/home:/katacontainers:/releases:/x86\_64:/master/xUbuntu\_$(lsb\_release -rs)/ /' >> /etc/apt/sources.list.d/kata-containers.list"，  
curl -sL  https://download.opensuse.org/repositories/home:/katacontainers:/releases:/x86\_64:/master/xUbuntu\_$(lsb\_release -rs)/Release.key | sudo apt-key add -，  
sudo apt update，  
sudo apt install kata-runtime kata-proxy kata-shim，

编辑/etc/docker/daemon.json，加入如下内容，

{  
  "default-runtime": "kata-runtime",  
  "runtimes": {  
    "kata-runtime": {  
      "path": "/usr/bin/kata-runtime"  
    }  
  }  
}

重启docker服务，

sudo systemctl daemon-reload，  
sudo systemctl restart docker，
