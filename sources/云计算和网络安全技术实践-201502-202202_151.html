以前实践过DevStack+Zun，本次原本想实践一下DPDK下的Zun，没成功，也顺便更新一下实践方法，

首先安装docker，跟之前比有更新，

sudo apt-get install \
    apt-transport-https \
    ca-certificates \
    curl \
    gnupg-agent \
    software-properties-common
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo apt-key add -
sudo apt-key fingerprint 0EBFCD88
sudo add-apt-repository \
   "deb [arch=amd64] https://download.docker.com/linux/ubuntu \
   $(lsb_release -cs) \
   stable"
sudo apt-get update
sudo apt-get install docker-ce docker-ce-cli containerd.io
sudo docker run hello-world

然后devstack的localrc也有更新，

enable_plugin zun ${GIT_BASE}/openstack/zun
enable_plugin devstack-plugin-container ${GIT_BASE}/openstack/devstack-plugin-container
enable_plugin kuryr-libnetwork ${GIT_BASE}/openstack/kuryr-libnetwork
enable_plugin zun-ui ${GIT_BASE}/openstack/zun-ui
LIBS_FROM_GIT="python-zunclient"
KURYR_PROCESS_EXTERNAL_CONNECTIVITY=False
