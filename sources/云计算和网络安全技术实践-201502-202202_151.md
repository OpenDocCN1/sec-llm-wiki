以前实践过DevStack+Zun，本次原本想实践一下DPDK下的Zun，没成功，也顺便更新一下实践方法，

首先安装docker，跟之前比有更新，

sudo apt-get install \\  
    apt-transport-https \\  
    ca-certificates \\  
    curl \\  
    gnupg-agent \\  
    software-properties-common  
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo apt-key add -  
sudo apt-key fingerprint 0EBFCD88  
sudo add-apt-repository \\  
   "deb \[arch=amd64\] https://download.docker.com/linux/ubuntu \\  
   $(lsb\_release -cs) \\  
   stable"  
sudo apt-get update  
sudo apt-get install docker-ce docker-ce-cli containerd.io  
sudo docker run hello-world

然后devstack的localrc也有更新，

enable\_plugin zun ${GIT\_BASE}/openstack/zun  
enable\_plugin devstack-plugin-container ${GIT\_BASE}/openstack/devstack-plugin-container  
enable\_plugin kuryr-libnetwork ${GIT\_BASE}/openstack/kuryr-libnetwork  
enable\_plugin zun-ui ${GIT\_BASE}/openstack/zun-ui  
LIBS\_FROM\_GIT="python-zunclient"  
KURYR\_PROCESS\_EXTERNAL\_CONNECTIVITY=False
