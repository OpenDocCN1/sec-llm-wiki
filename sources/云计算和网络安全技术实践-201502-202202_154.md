一直在尝试DevStack下的networking-ovs-dpdk插件自动化安装DPDK的OpenStack环境，一直都不成功，

本周偶然用当前最新版本尝试竟然安装成功了，

\[\[local|localrc\]\]  
############################################################  
\# Customize the following HOST\_IP based on your installation  
############################################################  
PUBLIC\_INTERFACE=ens192  
SERVICE\_PASSWORD=password  
ADMIN\_PASSWORD=password  
SERVICE\_TOKEN=password  
DATABASE\_PASSWORD=password  
RABBIT\_PASSWORD=password  
GIT\_BASE=${GIT\_BASE:-git://git.openstack.org}  
enable\_plugin networking-ovs-dpdk ${GIT\_BASE}/openstack/networking-ovs-dpdk

但问题是，用sudo ovs-vsctl get Open\_vSwitch . dpdk\_initialized命令查看DPDK状态不支持，看来版本不对，

![](../Images/62afb846004637010354136c16077eea.png)

还是偶然，发现DevStack还有个StarlingX版本，尝试用这个版本安装，

git clone -b stx/stein https://github.com/starlingx-staging/devstack.git，

虽然状态是false，但支持查询状态了，版本对了，  

![](../Images/ed8fe0745e21e6cd5700bb90f787ba57.png)

下面尝试手动开启DPDK，

sudo ovs-vsctl --no-wait set Open\_vSwitch . other\_config:dpdk-init=true，

sudo /usr/share/openvswitch/scripts/ovs-ctl start，

再查询OVS的DPDK状态，true了，  

![](../Images/5efd8be200e9d22b0d0a70953b229ad5.png)

问题是，OVS-Agent不工作了，

![](../Images/f3018b3355d3293946c5f1107a40a395.png)

还得再继续研究。

自动安装的huge pages还真生效了，实在不行可以先不管OVS的DPDK问题，先验证一下huge pages的flavor是否可用，就像之前实践CPU Pinning一样。

看OVS DPDK安装的官方文档，还要求Host OS的grub里添加huge pages和iommu的参数，

sudo vim /etc/default/grub，

GRUB\_CMDLINE\_LINUX="default\_hugepagesz=1G hugepagesz=1G hugepages=16 hugepagesz=2M hugepages=8192 iommu=pt intel\_iommu=on"，

sudo update-grub，  
sudo reboot，

重启后可以验证一下，

dmesg | grep -e DMAR -e IOMMU，

cat /proc/cmdline，
