# OSM-5的安装和使用

最近OSM-5发布了，更加的易用和稳定，本周末就实践了一下，

按照官方指南要求，在Ubuntu16.04里进行的实践，

wget https://osm-download.etsi.org/ftp/osm-5.0-five/install\_osm.sh，

chmod +x install\_osm.sh，

./install\_osm.sh，

剩下的就是等，安装完了就可以拿OpenStack做实验了，

按照官方指南，做一个下面组网的实验，  

![](../Images/e670a01d490038c28489253b501eca55.png)

从这里下载NSD和VNFD模板，https://osm-download.etsi.org/ftp/osm-3.0-three/examples/cirros\_2vnf\_ns/，

提前在OpenStack里注册好镜像，openstack image create --file="./cirros-0.3.4-x86\_64-disk.img" --container-format=bare --disk-format=qcow2 cirros034，

在OSM里注册VIM，  

![](../Images/6f7cfd8e28d1e9f6a7aaa533d8af5758.png)

注册VIM成功，

![](../Images/08884d3bee5b8ef47585e5c68ad35752.png)

在OSM里注册VNFD，

![](../Images/769bdafd14beb7de9a4075748622f027.png)

在OSM里注册NSD，

![](../Images/b340609b3b357311f842ce76a98cc526.png)

创建NS，

![](../Images/b381744f95221577516b96fdbfea8d73.png)

报错，是因为OpenStack的url里用了域名，OSM里解析不到，

![](../Images/e02b3013121793365c11777d7924e30f.png)

解决办法是到OSM的RO组件容器里添加域名的静态解析记录，

先查看RO组件的容器，

![](../Images/95a011ca97926f4101215077db825810.png)

然后进入RO容器，docker exec -it 5bb72d53b12d /bin/bash，

apt install vim，vim /etc/hosts，x.x.x.x    controller，

再重新创建NS就成功了，

![](../Images/48c3aee471fe90a76036a420c05eff54.png)

查看VNF，

![](../Images/bb51b47e967cf3c6778fb6e74c443ead.png)

![](../Images/3ac4133d41a543e8790f80f1e6a08e0b.png)

查看虚机，

![](../Images/9997a7b62ac9473bb1fa7773acdef2e8.png)

![](../Images/6b78d2d337c0cba5a87a173f3d0148b9.png)

非常的易用和稳定，重启都没问题，服务很快都能起来。
