之前做OpenStack FWaaS-V2的实践的时候说FWaaS-V1的Dashboard通过配置就能出来，那是过去了，现在不是了，比如最新的Rocky版本，怎么办呢，本周就实践了一下手动安装过程，

还是要先做配置，参考https://docs.openstack.org/neutron/rocky/admin/fwaas-v1-scenario.html，v2的也是一样的，只是版本不同，

vim /etc/neutron/neutron.conf，

service_plugins = router,firewall

[service_providers]
service_provider = FIREWALL:Iptables:neutron.agent.linux.iptables_firewall.OVSHybridIptablesFirewallDriver:default

vim /etc/neutron/fwaas_driver.ini，

[fwaas]
agent_version = v1（v2只需在这里改一下版本号）
driver = iptables
enabled = True
conntrack_driver = conntrack

vim /etc/neutron/l3_agent.ini，

[agent]
extensions = fwaas

neutron-db-manage --subproject neutron-fwaas upgrade head，

vim /etc/openstack-dashboard/local_settings.py，

OPENSTACK_NEUTRON_NETWORK = {
    # ...
    'enable_firewall' = True,
    # ...
}

service neutron-l3-agent restart，

service neutron-server restart，

以上配置只能保证FWaaS是工作的，但是没有Dashboard，

参考https://docs.openstack.org/neutron-fwaas-dashboard/latest/install/index.html，

git clone https://git.openstack.org/openstack/neutron-fwaas-dashboard，

cd neutron-fwaas-dashboard，

apt install python-pip，

pip install .，

cp neutron_fwaas_dashboard/enabled/_70*_*.py /usr/share/openstack-dashboard/openstack_dashboard/local/enabled，

vim /etc/openstack-dashboard/local_settings.py，

POLICY_FILES = {
     # ...
     'neutron-fwaas': '/home/ubuntu/neutron-fwaas-dashboard/etc/neutron-fwaas-policy.json',
     # ...
}

apt-get install gettext，（这个地方参考原文没提到，很重要）

./manage.py compilemessages，

DJANGO_SETTINGS_MODULE=openstack_dashboard.settings python manage.py collectstatic --noinput，

DJANGO_SETTINGS_MODULE=openstack_dashboard.settings python manage.py compress --force，

service apache2 restart，

再打开Dashboard，你就能看到FWaaS的界面了。
