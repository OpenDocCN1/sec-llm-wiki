# OpenStack FWaaS-V2的实践（一）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650744785&idx=1&sn=9c4c3647595759690dbe0dbed3c39eaa&chksm=871486d1b0630fc7b9eb7239b3e50bd55301df0fc98c3f1add1ad1e7daca38f6ccb5091f8839&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650744785&idx=1&sn=9c4c3647595759690dbe0dbed3c39eaa&chksm=871486d1b0630fc7b9eb7239b3e50bd55301df0fc98c3f1add1ad1e7daca38f6ccb5091f8839&scene=27#wechat_redirect)

OpenStack自带FWaaS-V1的功能和界面，只需要做配置就可以了，这个之前实践过，就不详述了，随着FWaaS-V2的成熟，越来越多的用户开始使用了，本周实践了一下，看跟FWaaS-V1有什么不同。

安装官方的指南，https://docs.openstack.org/neutron/rocky/admin/fwaas-v2-scenario.html，配置倒是不麻烦，但是说不支持dashboard，那就没啥意思了，

于是尝试了一下devstack，指定好neutron-fwaas和neutron-fwaas-dashboard的plugin就可以了，devstack经常实践，也不再详述，

装完一看界面，FWaaS-V2的dashboard还真出来了，

![](../Images/8fe36270c0da4afbb8f35344d2269e85.png)

FWaaS-V1的时候叫防火墙，FWaaS-V2叫防火墙组了，

创建一个防火墙组试试，要求区分入口和出口的策略，  

![](../Images/17a91f132daa84aa45696388ff228db1.png)

没有了要求绑定router的配置项，换成端口了，

![](../Images/967a456315e001576efc35dbf06ec2bb.png)

端口没的选啊，因为没有router呗，创建一个，外网和内网都挂上，

![](../Images/7ee9c127c6a4e99ac29218263934df93.png)

再创建防火墙组，能选端口了，而且只能选内网端口，看来对外网端口无效，

![](../Images/ad7d251075073740f54945687069e46a.png)

FWaaS-V1的时候是一个防火墙只能绑定给一个router，那这FWaaS-V2的防火墙组能不能同时对多个router有效呢，再创建一个router试试，

![](../Images/00f50bb46d0ab095c09cae5d390aaba2.png)

再创建防火墙组，两个router的内网端口都让绑，厉害了，

![](../Images/451b2e6a577553bb1546573dcec90e44.png)

很好奇devstack是怎么配置的，按照官方指南对一下，

![](../Images/02e70eb4ae7630a282d8f6a950237ab4.png)

好几个地方都对不上，再看看FWaaS-V1时候的dashboard配置位置，

![](../Images/0d73e63a8a40cb7790c737feec5e2541.png)

也没有啊，看来这FWaaS-V2也就用devstack搞还容易，自己手动装还真不一定能整明白，运气不错。
