本周没做啥有意思的实践，把之前攒的几个Docker使用技巧总结一下吧，


1、创建多网卡的容器实例


先要创建网络，docker network create network-1，

查看网络，docker network list，

创建容器实例，直接指定连接的网络，docker run -d -P --name sshd-server --network network-1 rastasheep/ubuntu-sshd:14.04，

后给容器实例增加网卡，docker network connect network-2 e008d3dd9758，

查看容器实例，docker inspect sshd-server，


2、在容器实例里不让执行命令怎么办


例如修改网卡的mtu，

先找到容器实例的Pid，docker inspect --format '{{.State.Pid}}' 191fea28ad4c，

在外面执行，nsenter -t 14801 -n ifconfig eth0 mtu 1450，

再进容器查看，docker exec -it 191fea28ad4c /bin/bash，就改过来了，


3、创建容器实例，先不启动，配好多网卡再启动


docker create --name sshd-server -it rastasheep/ubuntu-sshd:14.04，

docker network connect service-network e008d3dd9758，

docker start sshd-server，

还有另一种进容器的方法，docker attach sshd-server，

但是一退出，容器实例就跟着停了，
