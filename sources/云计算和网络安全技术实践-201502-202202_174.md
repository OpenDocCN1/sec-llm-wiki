# 用minikube安装kubernetes

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650744720&idx=1&sn=3bab896f42c845cf7c356c8b0eed80c9&chksm=87148690b0630f8672212300a7a60c60fb67ab5a0891ad57373b4bce9fa458c14a642a44b0cc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650744720&idx=1&sn=3bab896f42c845cf7c356c8b0eed80c9&chksm=87148690b0630f8672212300a7a60c60fb67ab5a0891ad57373b4bce9fa458c14a642a44b0cc&scene=27#wechat_redirect)

在Ubuntu16.04中完成本实践，首先要安装virtualbox-5.2，

为什么不直接apt install virtualbox，因为是5.1版本，有问题，

为了安装virtualbox-5.2需要先做以下工作，

wget -q https://www.virtualbox.org/download/oracle\_vbox\_2016.asc -O- | sudo apt-key add -，

wget -q https://www.virtualbox.org/download/oracle\_vbox.asc -O- | sudo apt-key add -，

vim /etc/apt/sources.list，

deb http://download.virtualbox.org/virtualbox/debian xenial contrib，

apt update，

然后再apt install virtualbox-5.2，

接下来安装kubectl，

curl -LO https://storage.googleapis.com/kubernetes-release/release/$(curl -s https://storage.googleapis.com/kubernetes-release/release/stable.txt)/bin/linux/amd64/kubectl，

chmod +x ./kubectl，

sudo mv ./kubectl /usr/local/bin/kubectl，

再安装minikube，

curl -Lo minikube https://storage.googleapis.com/minikube/releases/latest/minikube-linux-amd64 && chmod +x minikube && sudo mv minikube /usr/local/bin/，

通过minikube完成整个kubernetes环境的安装，

minikube start，需要耐心

等待一段时间，

![](../Images/4b0a3f0d3a5a717b8d5709d808ffdc90.png)

安装完成后用minikube dashboard得到管理界面访问地址，

![](../Images/fd8db9ac9aab6c076c50c58449c4cb60.png)

可以直接在ubuntu里面访问到管理界面，

![](../Images/32ddff523ba53c538447f317f8fffa1f.png)

为了能够在外面直接访问，需要进到ubuntu里做以下工作，

vim /etc/sysctl.conf，

net.ipv4.ip\_forward = 1，

iptables -t nat -A PREROUTING -d 192.168.137.201 -p tcp --dport 30000 -j DNAT --to 192.168.99.100，

iptables -t nat -A POSTROUTING -o vboxnet0 -j MASQUERADE，

![](../Images/c6699ce2aff7a63c2ec8b2537ea50fa7.png)

后面再实践在环境里起容器实例。
