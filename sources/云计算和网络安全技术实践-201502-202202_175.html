大概是从Pike版本开始，OpenStack支持在Dashboard上给路由器配置静态路由，这就让优雅的使用NAT虚机成为了可能，

下面是Rocky版本环境的实践过程，

用普通ubuntu做NAT虚机，从官网下载镜像并上传到OpenStack中，

进行如下组网设计，

这里注意cloud-init的命令注入，

#!/bin/sh
passwd ubuntu<<EOF
ubuntu
ubuntu
EOF
sudo sed -i 's/PasswordAuthentication no/PasswordAuthentication yes/g' /etc/ssh/sshd_config
sudo service ssh restart

可以勾选使用config-drive，比api获取靠谱，

别忘了放开NAT虚机接口的IP检查，

neutron port-update f299963d-ae4d-4830-8a55-d8cd567cd696 --allowed-address-pairs type=dict list=true ip_address=0.0.0.0/0，

NAT虚机里首先要放开路由转发，

vim /etc/sysctl.conf，
net.ipv4.ip_forward=1，
sysctl -p，

然后要配置子网路由和NAT规则，

route add -net 10.0.0.0/24 gw 172.16.1.1，
iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE，
iptables -t nat -A PREROUTING -d 10.90.3.121 -p tcp --dport 222 -j DNAT --to 10.0.0.10:22，

最优雅的地方，在OpenStack Dashboard上给路由器配置静态路由，
