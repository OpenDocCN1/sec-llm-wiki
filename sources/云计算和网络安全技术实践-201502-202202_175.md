# 在OpenStack中优雅的使用NAT虚机

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650744713&idx=1&sn=6cb8984a11e161be20c37ff6bb85eabd&chksm=87148689b0630f9fe6d011a0489a08a6a4a59a95c3c27f3fb850e9f34df9c12ab9887dbd9418&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650744713&idx=1&sn=6cb8984a11e161be20c37ff6bb85eabd&chksm=87148689b0630f9fe6d011a0489a08a6a4a59a95c3c27f3fb850e9f34df9c12ab9887dbd9418&scene=27#wechat_redirect)

大概是从Pike版本开始，OpenStack支持在Dashboard上给路由器配置静态路由，这就让优雅的使用NAT虚机成为了可能，

下面是Rocky版本环境的实践过程，

用普通ubuntu做NAT虚机，从官网下载镜像并上传到OpenStack中，

进行如下组网设计，

![](../Images/782dfc8cf674846fc7e45d856f5598e1.png)

这里注意cloud-init的命令注入，

#!/bin/sh  
passwd ubuntu<<EOF  
ubuntu  
ubuntu  
EOF  
sudo sed -i 's/PasswordAuthentication no/PasswordAuthentication yes/g' /etc/ssh/sshd\_config  
sudo service ssh restart

可以勾选使用config-drive，比api获取靠谱，

![](../Images/8e5c6318f36242a79f5aa4f7993f7d11.png)

别忘了放开NAT虚机接口的IP检查，

neutron port-update f299963d-ae4d-4830-8a55-d8cd567cd696 --allowed-address-pairs type=dict list=true ip\_address=0.0.0.0/0，

NAT虚机里首先要放开路由转发，

vim /etc/sysctl.conf，  
net.ipv4.ip\_forward=1，  
sysctl -p，

然后要配置子网路由和NAT规则，

route add -net 10.0.0.0/24 gw 172.16.1.1，  
iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE，  
iptables -t nat -A PREROUTING -d 10.90.3.121 -p tcp --dport 222 -j DNAT --to 10.0.0.10:22，

最优雅的地方，在OpenStack Dashboard上给路由器配置静态路由，
