以前实践过Pycharm，应该算是Windows下比较好用的python开发工具了，最近想研究一下tensorflow，但是发现Pycharm无法正常安装tensorflow模块，于是就转向了另一款Windows下的python开发工具，Anaconda，也是相当好用，重要的是安装后自带matplotlib，pandas，numpy，scipy等模块，安装tensorflow模块也很方便，

首先从官方网站(https://www.anaconda.com/download/)上下载3.6版本的安装包，2.7版本是不行的，安装tensorflow模块会说找不到，

Jupyper Notebook很多玩儿python的都熟悉，非常方便的python编程界面，

迫不及待的编一个用tensorflow模块的程序吧，

import tensorflow as tf  
hello = tf.constant('Hello, TensorFlow!')  
sess = tf.Session()  
print(sess.run(hello))  
a = tf.constant(10)  
b = tf.constant(32)  
print(sess.run(a+b))

效果如下，报了一个告警，但结果没问题，

当然Jupyper Notebook在图形展示上还是不如Pycharm的，例如之前用Pycharm实践过的用matplotlib.pyplot画图，matplotlib.pyplot.show()在Jupyper Notebook上是展示不出来的，只好matplotlib.pyplot.savefig把画出来的图保存一下再打开。
