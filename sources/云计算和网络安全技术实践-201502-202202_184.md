随着NSH正式成为服务链的技术标准，业内相关项目也开始正式对NSH支持起来，最重要的就是OVS，终于等到发布邮件中宣布支持NSH的版本，

![](../Images/c6646a4182e12de5065fc67f9c499f39.png)

具体到2.9.0版本的新特性，明确对NSH的支持，

![](../Images/409f9ae5baa6bfaa67acb8086b5f91a9.png)

本周就拿DevStack跑了一套OpenStack最新版环境，并按照https://docs.openstack.org/networking-sfc/latest/contributor/ietf\_sfc\_encapsulation.html进行了NSH的实践和验证，

1、不向SF传递header，

openstack sfc port pair create --ingress p1 --egress p1 pp1，  
openstack sfc port pair group create --port-pair pp1 ppg1，  
openstack sfc flow classifier create --protocol icmp --logical-source-port 6c80f5f6-0cf6-4aa4-8504-4e7d580c2c8a fc1，  
openstack sfc port chain create --port-pair-group ppg1 --flow-classifier fc1 pc1  
ovs-ofctl dump-flows br-int，流表如下，  

![](../Images/e0428d30f3aebff8b3ef25ee765d6f58.png)

ovs-ofctl dump-groups br-int -O OpenFlow13，组内容如下，

![](../Images/fdfe58a805a64445592b5d0addd5d897.png)

2、向SF传递MPLS header，

openstack sfc port pair create --ingress p1 --egress p1 --service-function-parameters correlation=mpls pp1，  
openstack sfc port pair group create --port-pair pp1 ppg1，  
openstack sfc flow classifier create --protocol icmp --logical-source-port 6c80f5f6-0cf6-4aa4-8504-4e7d580c2c8a fc1，  
openstack sfc port chain create --port-pair-group ppg1 --flow-classifier fc1 --chain-parameters correlation=mpls pc1，  
ovs-ofctl dump-flows br-int，流表如下，

![](../Images/60dee2b87126e6c33b635f44b9486c1d.png)

ovs-ofctl dump-groups br-int -O OpenFlow13，组内容如下，

![](../Images/f2914ca985c754fbbdf4ca60748067f9.png)

3、向SF传递NSH header，

openstack sfc port pair create --ingress p1 --egress p1 --service-function-parameters correlation=nsh pp1，  
openstack sfc port pair group create --port-pair pp1 ppg1，  
openstack sfc flow classifier create --protocol icmp --logical-source-port 6c80f5f6-0cf6-4aa4-8504-4e7d580c2c8a fc1，  
openstack sfc port chain create --port-pair-group ppg1 --flow-classifier fc1 --chain-parameters correlation=nsh pc1，  
ovs-ofctl dump-flows br-int，流表没出来，  
ovs-ofctl dump-groups br-int -O OpenFlow13，组内容跟之前相同，

说明当前Neutron版本没有跟OVS版本在NSH上配合好，

OVS版本确实是2.9.0，  

![](../Images/d1674aa2d3dafc98142fe2519b809fe5.png)
