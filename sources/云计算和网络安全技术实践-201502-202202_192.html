最近一段时间的周末都会一直实践安全的内容，当然了，也没有太多的技术含量，你可以说我是工具党，术业有专攻，个人更擅长的确实还是找工具和使用工具，本周实践的是SecGen，一个能自定义生成漏洞环境的开源项目，

https://github.com/cliffe/SecGen/，

官方让先安装vagrant_1.9.8_x86_64.deb，但是我之前实践Metasploitable3的环境已经安装了vagrant_1.9.1_x86_64.deb，而且work，就不动了，

其它的环境软件还是按要求照常安装，

sudo apt-get install ruby-dev zlib1g-dev liblzma-dev build-essential patch virtualbox ruby-bundler imagemagick libmagickwand-dev exiftool libpq-dev libcurl4-openssl-dev libxml2-dev，

clone最新的版本，git clone https://github.com/cliffe/SecGen，

开始安装，cd SecGen，bundle install，ruby secgen.rb run，

这是一个随机挑选漏洞的虚机环境，

用root/puppet登录，

给第二块host only的网卡配好IP地址就可以做端口扫描和漏洞扫描了，

开的端口不多，看来rpc，nfc，irc是本次随机挑选的有漏洞的应用，

拿nessus扫一下，没错，这三个应用都有高危漏洞，

下次可以实践通过内置场景针对性的生成漏洞虚机，例如，

ruby secgen.rb --scenario scenarios/examples/remotely_exploitable_user_vulnerability.xml run
