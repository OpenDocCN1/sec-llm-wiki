# SecGen的实践（一）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650744565&idx=1&sn=661302fe15d84093a8288f4aee858072&chksm=871487f5b0630ee31ba2d726151a18c0361ca8ba17351e7ef710da9850c277d9a3da28b3d61e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650744565&idx=1&sn=661302fe15d84093a8288f4aee858072&chksm=871487f5b0630ee31ba2d726151a18c0361ca8ba17351e7ef710da9850c277d9a3da28b3d61e&scene=27#wechat_redirect)

最近一段时间的周末都会一直实践安全的内容，当然了，也没有太多的技术含量，你可以说我是工具党，术业有专攻，个人更擅长的确实还是找工具和使用工具，本周实践的是SecGen，一个能自定义生成漏洞环境的开源项目，

https://github.com/cliffe/SecGen/，

官方让先安装vagrant\_1.9.8\_x86\_64.deb，但是我之前实践Metasploitable3的环境已经安装了vagrant\_1.9.1\_x86\_64.deb，而且work，就不动了，

其它的环境软件还是按要求照常安装，

sudo apt-get install ruby-dev zlib1g-dev liblzma-dev build-essential patch virtualbox ruby-bundler imagemagick libmagickwand-dev exiftool libpq-dev libcurl4-openssl-dev libxml2-dev，

clone最新的版本，git clone https://github.com/cliffe/SecGen，

开始安装，cd SecGen，bundle install，ruby secgen.rb run，

![](../Images/ce940ce2e75fe47e2828b00dab3163fc.png)

这是一个随机挑选漏洞的虚机环境，

![](../Images/138d786862c92dd07d4d95c537abc865.png)

用root/puppet登录，

![](../Images/45c5fc7f23dd918e2b8c086803796af1.png)

给第二块host only的网卡配好IP地址就可以做端口扫描和漏洞扫描了，

![](../Images/d0ac0459623ddc753cf99a8c83feed05.png)

开的端口不多，看来rpc，nfc，irc是本次随机挑选的有漏洞的应用，

![](../Images/b8ad2a9c25abbd20d2cca4c644c35dd4.png)

拿nessus扫一下，没错，这三个应用都有高危漏洞，

![](../Images/710d1e0e94548614c8cc2edcfdf479ca.png)

下次可以实践通过内置场景针对性的生成漏洞虚机，例如，

ruby secgen.rb --scenario scenarios/examples/remotely\_exploitable\_user\_vulnerability.xml run
