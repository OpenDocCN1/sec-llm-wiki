之前实践过用Ansible来做自动化运维，事实上Python也是能干这个事儿的，用paramiko模块，比Ansible还要易用，本周末就进行了简单的实践，

直接在我的Python实践神器PyCharm上搞，首先安装paramiko模块，

![](../Images/df7ab8745417da97b72f76a8a9922042.png)

然后就可以进行实践了，拿远程的ubuntu虚机做实验，

编写一段简单的代码，

```
import 

paramikohostname\='10.90.3.60', port\=22, username\='ubuntu', password\='ubuntu'
)'ifconfig;ls'
)print
(stdout.read().decode())
```

两条命令都能够正确得到输出，

这个是ifconfig的，  

![](../Images/39655e3511ca65556158698719d53a59.png)

这个是ls的，

![](../Images/9ac84bf69df96119e959c63261c4178f.png)

是不是很方便，实践到这儿，可能有人会问，sudo怎么办，你做Ansible实践的时候特意考虑sudo了，没错，这个确实很重要，不然怎么做自动化运维，

paramiko这样处理，自动化的去交互，在上面代码里再增加一个sudo实践，

```
import 

paramikohostname\='10.90.3.60', port\=22, username\='ubuntu', password\='ubuntu'
)'ifconfig;ls;sudo ls /root', get\_pty\=True
)'ubuntu\\n'
)print
(stdout.read().decode())
```

你就能看到sudo命令也能正确得到输出了，

![](../Images/4a013e76e43f30d10d1a19bdfdc9925f.png)
