Tacker是可以独立安装的，如果能封装成Docker镜像，就会更灵活，本周末做了这样的实践，

Docker环境的安装就不说了，以前贴过好多次了，

首先选择母Docker镜像，普通的ubuntu是不合适的，因为不支持systemctl，

需要选择solita/ubuntu-systemd作为母Docker镜像，

docker pull solita/ubuntu-systemd，

对镜像做启动配置，

docker run --rm --privileged -v /:/host solita/ubuntu-systemd setup，

启动实例，

docker run -d --privileged --network host --name systemd --security-opt seccomp=unconfined --tmpfs /run --tmpfs /run/lock -v /sys/fs/cgroup:/sys/fs/cgroup:ro -t solita/ubuntu-systemd，

进入实例，docker exec -i -t 2bedd2da7145 /bin/bash，

更新源，apt-get update && apt-get dist-upgrade，

安装必要的软件，apt-get install net-tools vim git sudo bridge-utils iptables，

创建普通用户，useradd ubuntu，passwd ubuntu，  

usermod -aG sudo ubuntu，mkdir /home/ubuntu，su - ubuntu，

sudo chown -R ubuntu:ubuntu /home/ubuntu，

接下来用devstack进行Tacker的安装，

sudo git clone git://git.openstack.org/openstack-dev/devstack.git，

sudo chown -R ubuntu:ubuntu /home/ubuntu/devstack，

sudo mkdir /opt/stack，sudo chown -R ubuntu:ubuntu /opt/stack，

sudo vim /home/ubuntu/devstack/local.conf，

  

\[\[local|localrc\]\]  
############################################################  
\# Customize the following HOST\_IP based on your installation  
############################################################  
HOST\_IP=127.0.0.1  
SERVICE\_HOST=127.0.0.1  
SERVICE\_PASSWORD=devstack  
ADMIN\_PASSWORD=devstack  
SERVICE\_TOKEN=devstack  
DATABASE\_PASSWORD=root  
RABBIT\_PASSWORD=password  
ENABLE\_HTTPD\_MOD\_WSGI\_SERVICES=True  
KEYSTONE\_USE\_MOD\_WSGI=True  
  
\# Logging  
LOGFILE=$DEST/logs/stack.sh.log  
VERBOSE=True  
ENABLE\_DEBUG\_LOG\_LEVEL=True  
ENABLE\_VERBOSE\_LOG\_LEVEL=True  
GIT\_BASE=${GIT\_BASE:-git://git.openstack.org}  
  
TACKER\_MODE=standalone  
USE\_BARBICAN=True  
enable\_plugin networking-sfc ${GIT\_BASE}/openstack/networking-sfc  
enable\_plugin barbican ${GIT\_BASE}/openstack/barbican  
enable\_plugin mistral ${GIT\_BASE}/openstack/mistral  
enable\_plugin tacker ${GIT\_BASE}/openstack/tacker

  

安装之前最好手动把各组件的源码都下载好，

cd /opt/stack，

sudo git clone git://git.openstack.org/openstack/networking-sfc.git，

sudo git clone git://git.openstack.org/openstack/barbican.git，

sudo git clone git://git.openstack.org/openstack/python-barbicanclient.git，

sudo git clone git://git.openstack.org/openstack/mistral.git，

sudo git clone git://git.openstack.org/openstack/mistral-dashboard.git，

sudo git clone git://git.openstack.org/openstack/tacker.git，

sudo git clone git://git.openstack.org/openstack/tacker-horizon.git，

sudo git clone git://git.openstack.org/openstack/keystone.git，

sudo git clone git://git.openstack.org/openstack/horizon.git，

sudo git clone git://git.openstack.org/openstack/requirements.git，

  

开始安装，cd /home/ubuntu/devstack，./stack.sh，
