为啥从4.3版本开始实践，因为4.3版本开始提供docker镜像，真方便，

首先下载docker镜像，http://repository.cloudifysource.org/cloudify/4.3.0/ga-release/cloudify-docker-manager-4.3ga.tar，

导入到docker环境，docker load -i cloudify-docker-manager-4.3ga.tar，

运行docker实例，docker run --name cfy\_manager -d --restart unless-stopped -v /sys/fs/cgroup:/sys/fs/cgroup:ro --tmpfs /run --tmpfs /run/lock --security-opt seccomp:unconfined --cap-add SYS\_ADMIN --network host docker\_cfy\_manager:latest，

拿OpenStack做VIM来举例，首先下载OpenStack插件，

http://repository.cloudifysource.org/cloudify/wagons/cloudify-openstack-plugin/2.7.2/cloudify\_openstack\_plugin-2.7.2-py27-none-linux\_x86\_64-centos-Core.wgn，

http://www.getcloudify.org/spec/openstack-plugin/2.7.2/plugin.yaml，
