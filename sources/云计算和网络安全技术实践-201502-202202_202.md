参考https://docs.openstack.org/kuryr-kubernetes/latest/installation/devstack/basic.html，

git clone https://github.com/openstack-dev/devstack.git，  
git clone https://github.com/openstack/kuryr-kubernetes.git，  
sudo chown -R ubuntu:ubuntu /home/ubuntu/devstack，  
sudo mkdir /opt/stack，  
sudo chown -R ubuntu:ubuntu /opt/stack，  
sudo cp kuryr-kubernetes/devstack/local.conf.sample devstack/local.conf，  
./devstack/stack.sh，

查看OpenStack服务，

source devstack/openrc admin admin，

openstack service list，
