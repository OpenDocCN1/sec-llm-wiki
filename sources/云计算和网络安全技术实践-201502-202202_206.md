元旦的时候装了个OSM，当时用OpenStack做VIM没搞定，后来才知道是内存没给够的原因，本周末把用OpenStack做VIM的成功实践记录一下。

先把OSM注册到OpenStack上，

osm vim-create --name openstack-site --user admin --password password --auth\_url http://10.90.3.60:35357/v3 --tenant admin --account\_type openstack

成功后的效果，

![](../Images/939ed7e9b6ad76c3de42e82d7bf01a6c.png)

然后参考官网的指导，下载cirros\_vnf.tar.gz和cirros\_2vnf\_ns.tar.gz，

创建VNFD，  

![](../Images/60deb58c13d491620d5fddfaf6edce34.png)
