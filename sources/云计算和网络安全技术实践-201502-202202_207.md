# 用DevStack安装主线版本都有哪些坑

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650744430&idx=1&sn=e4d250f200b3c6c04ca0e31a3f45f454&chksm=8714876eb0630e78181d2872bb55445603c5b77db25fe287429946efa471e835c599fb57800a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650744430&idx=1&sn=e4d250f200b3c6c04ca0e31a3f45f454&chksm=8714876eb0630e78181d2872bb55445603c5b77db25fe287429946efa471e835c599fb57800a&scene=27#wechat_redirect)

用DevStack安装主线版本（一直安装到Ceilometer）有一些坑，看看怎么解，

首先会碰到下面这个问题，  

![](../Images/348fec5822662160800c96384e7307e0.png)

需要去网上搜并手动下载stestr-1.1.0.tar.gz，

![](../Images/e0fdbfc08a24cd12e91692310c4986a5.png)

然后手动安装，

tar -zxvf stestr-1.1.0.tar.gz，

cd stestr-1.1.0，

sudo pip install -r requirements.txt，

sudo python setup.py install，

继续安装，又会碰到这个问题，

![](../Images/4bc14a9937b0ce5a4adc8a75bbc7b158.png)

处理方法一样，去网上搜并下载手动安装，但是对一些软件有依赖，

需要先做如下安装，

sudo pip install pyOpenSSL，

sudo pip install pycrypto，

sudo pip install repoze.who，

sudo pip install paste，

sudo pip install decorator，

sudo python setup.py install，

继续安装，又会碰到这个问题，

![](../Images/3a76eb83269467baef72ebd372182c7d.png)

处理方法一样，去网上搜并下载手动安装，但是对一些软件有依赖，

需要先做如下安装，

sudo pip install pytest-runner，

sudo pip install pkgconfig，

最后就能安装成功了，

![](../Images/33623b736ada535e0e3a47922db8fbda.png)
