利用元旦假期实践了一下OSM的安装，

参考https://osm.etsi.org/wikipub/index.php/OSM_Release_THREE，

首先在ESXi里安装一个Ubuntu16.04，

然后参考https://osm.etsi.org/wikipub/index.php/LXD_configuration_for_OSM_Release_THREE，做LXD configuration，

apt-get update，apt-get install -y lxd，newgrp lxd，lxd init，

然后继续参考https://osm.etsi.org/wikipub/index.php/OSM_Release_THREE，

wget https://osm-download.etsi.org/ftp/osm-3.0-three/install_osm.sh，chmod +x install_osm.sh，

先apt install iptables-persistent，然后再./install_osm.sh，

安装完成后，需要再手动安装osmclient，

参考https://osm.etsi.org/wikipub/index.php/OSM_Release_THREE，

curl http://osm-download.etsi.org/repository/osm/debian/ReleaseTHREE/OSM%20ETSI%20Release%20Key.gpg | sudo apt-key add -，

add-apt-repository -y "deb [arch=amd64] http://osm-download.etsi.org/repository/osm/debian/ReleaseTHREE stable osmclient"，

先apt install apt-transport-https，再apt-get update，

apt-get install -y --allow-unauthenticated python-osmclient，

至此全部安装完成，关机，导出OVA镜像，有10个多G，

重新导入OVA镜像，启动虚机，各服务都能自动启动，但管理地址不可更改，下面看一下效果，

https://10.210.1.100:8443访问登录界面，admin/admin，

NSD和VNFD编排，

NS启动，

OSM Client，

下周拿OpenStack做VIM，继续实践。
