# 开源性能测试软件Trex的实践（一）

本周一直在折腾虚拟化环境内的性能测试，不好搞，本来性能测试的产品就不多，虚拟化环境又要求软件，考虑到成本，还得是开源的，基本上就没啥了，iperf还算是能用的，但是仅能测吞吐，好不容易找到了一个款啥都能测的，Cisco开源的Trex，本周末就研究实践了一下，

官方给了一个封装好的虚拟机版本，可以直接下载，

http://trex-tgn.cisco.com/trex/T\_Rex\_162\_VM\_Fedora\_21.ova，

但是由于是用VirtualBox制作的，无法导入到vSphere环境下用，也不知道给谁做的，

还好官方又给了手动安装的方法，也很容易，就是安装一个兼容的Linux系统，然后把软件下载进去直接就能用，更没必要用VirtualBox做OVA了，

参考https://trex-tgn.cisco.com/trex/doc/trex\_manual.html，

我实践的是Ubuntu 14.04.5，至少给4C4G，不要dist-upgrade，

wget --no-cache http://trex-tgn.cisco.com/trex/release/latest，

tar -xzvf latest，目前的最新版本是v2.32，

给两个空闲网卡用于打流，  

![](../Images/fd6cef01cb0cb67b179b32a4e31b6623.png)

通过./dpdk\_setup\_ports.py -i来交互式设置二层打流还是三层打流，

二层打流设置后的配置文件如下，

![](../Images/2a8cb4de582568ed281aed4882605c26.png)

通过./t-rex-64 -f cap2/dns.yaml -d 10 -l 1000做效果验证，有报错，

![](../Images/132908206396afa98171ba825857ce5c.png)

发现一个很重要的问题，空闲网卡不再可见，

![](../Images/034eac36ab8bebc4550bc4a39b1f5d59.png)

这也就意味着，流量从一个接口扔出去到vSwitch上，无法被转发到另一个接口上，这样的限制对虚拟化环境无法适应，还需要继续研究。
