# 如何在老版DevStack中重启服务

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650744353&idx=1&sn=46496ff3382e63afd6961bf1fee234bb&chksm=87148721b0630e3740d904739a0f60ca5055bcff09c7f4db5de5a07f4c49ce40d6572771cc53&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650744353&idx=1&sn=46496ff3382e63afd6961bf1fee234bb&chksm=87148721b0630e3740d904739a0f60ca5055bcff09c7f4db5de5a07f4c49ce40d6572771cc53&scene=27#wechat_redirect)

上期说到为了实践Tacker NS，又回到了老版DevStack，老版DevStack不支持service "devstack@\*"的操作，给修改配置文件后重启服务带来很大麻烦，本期把老版DevStack中如何重启服务实践一下，

拿之前说到的OpenStack Ocata版本开始由于使用了libvert2.5，导致不支持嵌套虚拟化的问题举例，需要修改/etc/nova/nova.conf，

\[libvirt\]  
virt\_type = qemu

为了让修改生效，就要重启nova-compute服务，

首先在DevStack安装用户下执行screen -x，

![](../Images/9b3fadc18a67293147848f3c8f10a1b8.png)

然后执行Ctrl+a+n让n-cpu排到第一个，

![](../Images/c8ffeb7717bfbde3727d3c8a5e824cc0.png)

再执行Ctrl+c，并向上查找命令，

![](../Images/43b58968aadc27d44904c91154c1cbb1.png)

回车执行，就完成了nova-compute服务的重启，

最后执行Ctrl+a+d，回到Linux Shell，打完收工。
