open_nsfw是yahoo开发的，基于Caffe深度神经网络训练的成人/淫秽图片分类模型。我也是在网上看了人家的一篇blog（http://www.jianshu.com/p/e746454958a3），有兴趣也玩儿一下，

首先安装Docker环境，

apt-get install apt-transport-https ca-certificates curl software-properties-common，

curl -fsSL https://download.docker.com/linux/ubuntu/gpg | apt-key add -，

apt-key fingerprint 0EBFCD88，

add-apt-repository "deb [arch=amd64] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable"，

apt-get update，apt-get install docker-ce，

然后下载open_nsfw，

git clone https://github.com/yahoo/open_nsfw，

再Build caffe docker image (CPU)，

docker build -t caffe:cpu https://raw.githubusercontent.com/BVLC/caffe/master/docker/cpu/Dockerfile，

查看Docker进程和镜像，

接下来就可以进入open_nsfw文件夹对图片进行测试了，

cd open_nsfw，

docker run --volume=$(pwd):/workspace caffe:cpu python ./classify_nsfw.py --model_def nsfw_model/deploy.prototxt --pretrained_model nsfw_model/resnet_50_1by2_nsfw.caffemodel test_image.jpg，

我自己找了几张图进行了测试，
