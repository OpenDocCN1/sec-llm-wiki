# 轻松升级ESXi

kali-linux-2017.2发布了，本周末本来想安装一下写黑客工具RedSnarf的，

但是工作需要，这个升级ESXi的方法比较紧急，下周再写RedSnarf吧，

我实践的是ESXi5.5升级到6.0，没有装vCenter，就没有用Update Manager，

就下面的方法来看，一条命令就能完成升级，还用什么Update Manager呢，

首先安装ESXi5.5，

![](../Images/293644746f575953dbc402a49aa2b886.png)

查看能创建的虚机类型，

![](../Images/636e5631ebe757e5e8ba499432bb5762.png)

下载6.0的离线升级包，上传到存储，

![](../Images/89302a21b7a4830412efbef23a690091.png)

让ESXi5.5进入维护模式，并开启ssh，

![](../Images/6f513f2b8dadfb541b22db9d9cb1d3ef.png)

ssh进入shell，一条命令进行升级，

esxcli software vib install -d /vmfs/volumes/datastore1/ESXi600-201601001.zip，

命令执行完成，

![](../Images/a0abb020202fe81241846687a3fec335.png)

退出维护模式，并重启，

![](../Images/7ece3e9fd3ffc6c1de65ecb374866b0c.png)

查看能创建的虚机类型，

![](../Images/c8cc931468a2d978700bea45961f23e6.png)

完美升级成功。
