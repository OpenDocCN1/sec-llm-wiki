Hack OpenStack Ocata适应嵌套虚拟化环境

原文：http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650744231&idx=1&sn=55ef66f929712c6bdccbdf876ba827d8&chksm=871484a7b0630db1e6658e3353b50dbd6e682bb5dd1b7af973fe2d69e94c74a2910d8e2cbebf&scene=27#wechat_redirect

之前实践OpenStack Ocata时说过，由于libvert版本从1.3升级到2.5，导致不适应嵌套虚拟化环境，虚机无法正常启动，经过了各种hack，终于找到了一种还算方便的办法，就是把计算节点的nova-compute换成Newton版本的，整个过程是这样的，
安装完计算节点的宿主机系统，先不要安装Ocata的安装源，
而是安装Newton的安装源，add-apt-repository cloud-archive:newton，
更新系统的安装源，apt update，
安装nova-compute，apt install nova-compute，能看到libvert版本用的1.3，

配置参考Ocata的安装指南，nova-compute安装完成后，能看到计算节点的nova-compute被正常识别，

接下来先不要着急安装neutron-openvswitch-agent，要改安装源，
进到OpenStack安装源配置目录，cd /etc/apt/sources.list.d，
删除Newton的安装源，rm cloudarchive-newton.list，
重新安装Ocata的安装源，add-apt-repository cloud-archive:ocata，
更新系统的安装源，apt update，
安装neutron-openvswitch-agent，apt install neutron-openvswitch-agent，
配置参考Ocata的安装指南，neutron-openvswitch-agent安装完成后，能看到计算节点的neutron-openvswitch-agent被正常识别，

启动一个虚机验证一下，能够正常启动，
