在公有云上轻松上传自定义镜像

公有云发展的早期，想上传自定义镜像是很困难的，后期有些公有云提供了对象存储业务，算是能够解决这个问题了，一直保密的独门绝技可以公开了，
这个方法类似于大家普遍熟悉的ghost技术，就是在公有云上先创建一个普通Linux虚机，挂上一块云硬盘，把自己的镜像文件上传到云硬盘里，然后把镜像覆盖到系统盘，再重启，这个Linux虚机就变成你的自定义镜像的虚机了，
下面在OpenStack下实践一遍，用Ubuntu替换Centos来举例，
首先创建Centos虚机，

创建一块云硬盘，

把云硬盘挂给Centos虚机，

看一下第二块磁盘的名字，fdisk -l，
在根目录下创建一个磁盘目录，mkdir /datadisk，
格式化第二块磁盘，mkfs -t ext4 /dev/vdb，
关联磁盘目录和第二块磁盘，mount -t ext4 /dev/vdb /datadisk，

把Ubuntu镜像上传到磁盘目录，
先安装qemu-img，yum install qemu-img，
把qcow2转成raw，qemu-img convert -O raw ubuntu-ssh.qcow2 ubuntu-ssh.raw，
把raw镜像文件覆盖到系统盘，dd if=ubuntu-ssh.raw of=/dev/vda bs=1M conv=noerror,sync，


稍微等一会儿，把Centos虚机关掉再开机，就神奇的变成Ubuntu了，

云硬盘完成使命，可以摘掉了，

反过来用Centos替换Ubuntu也是一样，只是Ubuntu下安装qemu-img的命令不同，apt-get install qemu-utils，有一点需要说明，不同的公有云效果不同，有的公有云允许这么干，有的就不允许，有的时候用Ubuntu做母机能成功，有的时候用Centos做母机能成功，看运气吧。
