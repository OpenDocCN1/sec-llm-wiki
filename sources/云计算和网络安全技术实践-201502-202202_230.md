# 在公有云上轻松上传自定义镜像

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650744218&idx=1&sn=1fc53b2a820216b121068476356a42ba&chksm=8714849ab0630d8cabc82047de0b82ac491e6669965767d6709846e72fb589c05bc7e73b23e7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650744218&idx=1&sn=1fc53b2a820216b121068476356a42ba&chksm=8714849ab0630d8cabc82047de0b82ac491e6669965767d6709846e72fb589c05bc7e73b23e7&scene=27#wechat_redirect)

公有云发展的早期，想上传自定义镜像是很困难的，后期有些公有云提供了对象存储业务，算是能够解决这个问题了，一直保密的独门绝技可以公开了，  
这个方法类似于大家普遍熟悉的ghost技术，就是在公有云上先创建一个普通Linux虚机，挂上一块云硬盘，把自己的镜像文件上传到云硬盘里，然后把镜像覆盖到系统盘，再重启，这个Linux虚机就变成你的自定义镜像的虚机了，  
下面在OpenStack下实践一遍，用Ubuntu替换Centos来举例，  
首先创建Centos虚机，

![](../Images/8937c76e24bc074770b3874ace63345b.png)

创建一块云硬盘，

![](../Images/eb8817ad524db7e30d53b09c258f2602.png)

把云硬盘挂给Centos虚机，

![](../Images/ceb022dea83435af5e3a161ad47099d1.png)

看一下第二块磁盘的名字，fdisk -l，  
在根目录下创建一个磁盘目录，mkdir /datadisk，  
格式化第二块磁盘，mkfs -t ext4 /dev/vdb，  
关联磁盘目录和第二块磁盘，mount -t ext4 /dev/vdb /datadisk，

![](../Images/7c6db83d9652c76d87e47be9cc8d24ff.png)

把Ubuntu镜像上传到磁盘目录，  
先安装qemu-img，yum install qemu-img，  
把qcow2转成raw，qemu-img convert -O raw ubuntu-ssh.qcow2 ubuntu-ssh.raw，  
把raw镜像文件覆盖到系统盘，dd if=ubuntu-ssh.raw of=/dev/vda bs=1M conv=noerror,sync，

![](../Images/2c3f53f8f79b1a224709ce2851001c4f.png)  

稍微等一会儿，把Centos虚机关掉再开机，就神奇的变成Ubuntu了，

![](../Images/e0cefbfd895df554f9bba6bb18e81540.png)

云硬盘完成使命，可以摘掉了，

![](../Images/4c2cf7b6255b1aa94253738158352f2c.png)

反过来用Centos替换Ubuntu也是一样，只是Ubuntu下安装qemu-img的命令不同，apt-get install qemu-utils，有一点需要说明，不同的公有云效果不同，有的公有云允许这么干，有的就不允许，有的时候用Ubuntu做母机能成功，有的时候用Centos做母机能成功，看运气吧。
