# 自制去除cloud-init的linux发行版qcow2镜像

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650744217&idx=1&sn=7f456079784f1c420aa43152e3e60506&chksm=87148499b0630d8f5cf5f3a31b68e42eaa4bdda01ee299d6451888c81559ce8b8d5222894304&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650744217&idx=1&sn=7f456079784f1c420aa43152e3e60506&chksm=87148499b0630d8f5cf5f3a31b68e42eaa4bdda01ee299d6451888c81559ce8b8d5222894304&scene=27#wechat_redirect)

我以前经常用Ubuntu和Centos的官方qcow2镜像做实验，由于是内置cloud-init的，每次起虚机实例都得注入账户密码和打开允许ssh登录，很麻烦，这两天研究了一个自制去除cloud-init的linux发行版qcow2镜像的方法，

拿Ubuntu举例，首先还是用官方qcow2镜像起虚机实例，把账户密码和打开允许ssh登录的脚本先注入进去，

![](../Images/70ab6063c24fe2daf93879668a1ed2c5.png)

启动后进行远程登录验证，

![](../Images/72c587c2f08f77d17ac8f4f5aa43703a.png)

用dpkg-reconfigure cloud-init命令把cloud-init检查都关掉，

![](../Images/48c744ab8f9dac53bda9b18cfa037b29.png)

然后关机做快照，

![](../Images/27383c784a51249e78d38d7e97363810.png)

查看做好的快照ID，glance image-list，

把快照下载下来，glance image-download 1ed122d9-bc2c-442d-b68a-e7a8c7b08d5f --file ubuntu-ssh.qcow2，

再把下载下来的image注册成新的镜像，openstack image create "ubuntu-ssh" --file ubuntu-ssh.qcow2 --disk-format qcow2 --container-format bare --public，

![](../Images/acee30f1ec84d4ea8be5e0fdc275b928.png)

再用新镜像起虚机实例，这次不需要再注入账户密码和打开允许ssh登录的脚本了，完美，

![](../Images/6f484ccd60a62049e5d1aea6e4028b30.png)

Centos也是同样的过程，唯一不同的是，Centos下没有dpkg-reconfigure cloud-init命令，只能卸载cloud-init了，yum remove cloud-init，也能达到同样的效果。
