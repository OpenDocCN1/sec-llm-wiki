一直想实践一下ELK的强大插件X-Pack，但是懒得安装，

![](../Images/3ce8510b23c2080797a19e8d690021a2.png)

本周末就用了一次懒人的方法，Docker，

先安装Docker环境，

apt-get install apt-transport-https ca-certificates curl software-properties-common，

curl -fsSL https://download.docker.com/linux/ubuntu/gpg | apt-key add -，

apt-key fingerprint 0EBFCD88，

add-apt-repository "deb \[arch=amd64\] https://download.docker.com/linux/ubuntu $(lsb\_release -cs) stable"，

apt-get update，

apt-get install docker-ce，

docker run hello-world，

再安装elkx，

docker pull sebp/elkx，

这货还是挺大的，家里的100M网络够快了，安装需要很长时间，而且易中断，需要重新安装，反正是安装到第三次才成功，看来我们迫切需要SD-WAN，这个我正在研究，合适的时候再分享，

接下来做一个配置，不然启动会提示vm.max\_map不够，

sysctl -w vm.max\_map\_count=262144，

最后启动elkx，

docker run -p 5601:5601 -p 9200:9200 -p 5044:5044 -it --name elkx sebp/elkx，

访问管理界面，
