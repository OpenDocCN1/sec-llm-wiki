很早就开始在OpenStack里玩儿Cloud-Init，把经验总结一下。

最早给Ubuntu注入用户名密码是这样的：

#!/bin/sh  
passwd ubuntu<<EOF  
ubuntu  
ubuntu  
EOF  
sudo sed -i 's/PasswordAuthentication no/PasswordAuthentication yes/g' /etc/ssh/sshd\_config  
sudo service ssh restart

后来给Centos注入用户名密码是这样的：

#cloud-config  
password: centos  
chpasswd: { expire: False }  
ssh\_pwauth: True

上面两种方法都可以，但是如果Centos要使用第一种方法的话，注意重启ssh服务的命令是sudo systemctl restart sshd，

你以为第二种方法很好是吧，可惜TOSCA语法解析过不去，即使是第一种方法都还有瑕疵，'s/PasswordAuthentication no/PasswordAuthentication yes/g'的单引号需要改成双引号才行，"s/PasswordAuthentication no/PasswordAuthentication yes/g"，不要问我为啥，就是实践出真知，我趟过坑了，你看了我的经验总结，你就省事儿了。

其实本周末真正的成果是用Tacker+Networking-SFC搞了一个NFV一体机方案，大方向上还是很不错的，暂时不方便披露。
