Apache Spot是一个使用机器学习技术分析未知网络威胁的开源项目，

有docker的封装实在是太方面了，直接搞下来欣赏了一把，

docker环境安装就不说了，直接看Apache Spot，

docker run -it -p 8889:8889 apachespot/spot-demo，

运行起来后就是这样，

![](../Images/254858c12ab96a04bbded45a63bb00dc.png)

看一下docker进程，

![](../Images/624f14a9e0b6649141101d96476ee51a.png)

访问Demo URL，

http://192.168.137.250:8889/files/ui/flow/suspicious.html#date=2016-07-08，

第一个例子是Flow分析，

报告有一个地址疑似C&C，

![](../Images/9cade9c28ccd3e281c4a9453a4162136.png)

看详情，这个地址的不同高端口被不同主机地址访问，确实符合C&C地址的特点，

![](../Images/5d53ddc5a7e7d1ac7169b9bde2ef0b14.png)

第二个例子是DNS分析，

报告有一个域名疑似C&C，

![](../Images/6422b54fab893f4672bf878f6bc1c138.png)

看详情，这个域名的子域名有随机字符串，且不断变换地址，确实符合C&C域名的特点，

![](../Images/3a76e0fa684b152eb46940b685dd1715.png)

第三个例子是Proxy分析，

报告有一个网站是恶意的，

![](../Images/a4f6c2a81bee1797af5cec8c96e2eee2.png)

看详情，这个网站存在超长全0数字串的目录名，确实不正常，

![](../Images/e890b19ba32a8df41fb59f4493235d3e.png)
