 这个五一假期没干啥正事儿，总结几个杂活吧，


1、Kali 2017.1发布，安装了一下，

为了能从外面ssh进去，需要放开ssh服务的访问，

vim /etc/ssh/sshd_config，

PermitRootLogin yes，PasswordAuthentication yes，

service ssh restart，

再把升级源配好，vim /etc/apt/sources.list，

deb http://http.kali.org/kali kali-rolling main contrib non-free，

然后进行升级，apt-get update，apt-get dist-upgrade，


2、rhel本地软件安装源制作，

mkdir /root/iso，mkdir /mnt/cdrom，

mv rhel-server-7.1-x86_64-dvd.iso /root/iso，

mount -o loop /root/iso/rhel-server-7.1-x86_64-dvd.iso /mnt/cdrom，

vim /etc/yum.repos.d/rhel-media.repo，

[rhel-media]
name=Red Hat Enterprise Linux 7.1
baseurl=file:///mnt/cdrom
enabled=1
gpgcheck=1
gpgkey=file:///mnt/cdrom/RPM-GPG-KEY-redhat-release

yum clean all，yum makecache，

vim /etc/fstab，

/root/iso/rhel-server-7.1-x86_64-dvd.iso /mnt/cdrom iso9660 defaults,ro,loop 0 0，


3、OpenStack FWaaS配置，

vim /etc/neutron/neutron.conf，service_plugins = router,firewall，

[service_providers]
service_provider = FIREWALL:Iptables:neutron.agent.linux.iptables_firewall.OVSHybridIptablesFirewallDriver:default

vim /etc/neutron/fwaas_driver.ini，

[fwaas]
driver = neutron_fwaas.services.firewall.drivers.linux.iptables_fwaas.IptablesFwaasDriver
enabled = True

vim /etc/openstack-dashboard/local_settings.py，

OPENSTACK_NEUTRON_NETWORK，'enable_firewall': True，

service neutron-server restart，service neutron-l3-agent restart，

service apache2 restart，
