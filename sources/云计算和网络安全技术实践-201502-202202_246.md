# OpenStack Mitaka及以后版本VXLAN环境改平台MTU方法

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650744108&idx=1&sn=489b3d0a83929af76c087b3f8f870e06&chksm=8714842cb0630d3a07603ef2250170d6eae4734e262412da9f5706c38e111ce3575de730a95c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650744108&idx=1&sn=489b3d0a83929af76c087b3f8f870e06&chksm=8714842cb0630d3a07603ef2250170d6eae4734e262412da9f5706c38e111ce3575de730a95c&scene=27#wechat_redirect)

本周遇到一个OpenStack VXLAN环境改平台MTU的需求，各种查资料和实验，终于成功，参考了如下链接，

https://docs.openstack.org/mitaka/networking-guide/config-mtu.html，

OpenStack Mitaka及以后版本的VXLAN环境改平台MTU都可以这么干，

首先要改/etc/neutron/neutron.conf，

global\_physnet\_mtu = 1550，

然后要改/etc/neutron/plugins/ml2/ml2\_conf.ini，

\[ml2\]

path\_mtu = 1550，

为啥全都1550呢，因为我希望虚机的网卡MTU是标准的1500，

如果不改，虚机的网卡MTU就会是1450，

经过了上面的修改，重启neutron-server和openvswitch-agent，

再创建网络就能看到效果了，MTU是网络的属性，

![](../Images/ea60d4ce773b834e6ca89c4808b4b4b5.png)

在网络里起虚机，接口MTU自然也就是1500了，
