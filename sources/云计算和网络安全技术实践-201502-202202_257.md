# ntopng的实践（一）

本周实践的是开源流量分析软件ntopng，先说一下安装过程，

试了一次直接yum install ntopng，发现装的东西太多，而我只想研究ntopng，因此转向源码安装，又试了两次git clone，能正常安装，但有bug，管理界面打不开，最后终于用官方推荐的sourceforge上的stable源码实践成功。

nDPI的下载地址：https://sourceforge.net/projects/ntop/files/nDPI/，

ntopng的下载地址：https://sourceforge.net/projects/ntop/files/ntopng/，

如果你像我一样是用Minimal Centos安装的，那首先需要先把环境准备好，

yum install -y net-tools vim epel-release，

yum install -y wget git autoconf automake libtool libpcap-devel libcurl-devel sqlite-devel GeoIP-devel mariadb-devel glib2-devel libxml2-devel gcc-c++ redis，

然后进到下载到本地的nDPI和ntopng文件夹，都执行一遍，

./autogen.sh，./configure，make，make install，

ntopng要多执行一个make geoip，

启动ntopng之前先启动redis，systemctl start redis，systemctl enable redis，

方便起见，把防火墙直接关掉吧，

systemctl stop firewalld，systemctl disable firewalld，

启动ntopng，/usr/local/bin/ntopng -i ens192 -m "10.0.0.0/24"，
