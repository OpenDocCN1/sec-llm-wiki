上期说到想借opnfv-colorado.3.0实践Tacker，万万没想到是这个样子的，

竟然跟ODL和SFC还有依赖关系，而且装完环境一看，没界面，手动把界面搞出来，NFVO还不Work，这也就没啥意思了，

万万没想到，把opnfv-colorado.3.0环境里的如下Tacker配置搞到之前装的原生Newton版本下，竟然Work了，

project_domain_id = default
project_name = service
user_domain_id = default
password = password
username = tacker
auth_url = http://controller:35357/
auth_plugin = password
identity_uri = http://controller:35357/
auth_uri = http://controller:5000/v2.0/

这就是我想要的，
