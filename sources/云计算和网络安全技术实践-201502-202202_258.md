上期说到想借opnfv-colorado.3.0实践Tacker，万万没想到是这个样子的，

![](../Images/6a644d49582c79808a7543f702962f25.png)

竟然跟ODL和SFC还有依赖关系，而且装完环境一看，没界面，手动把界面搞出来，NFVO还不Work，这也就没啥意思了，

万万没想到，把opnfv-colorado.3.0环境里的如下Tacker配置搞到之前装的原生Newton版本下，竟然Work了，

project\_domain\_id = default  
project\_name = service  
user\_domain\_id = default  
password = password  
username = tacker  
auth\_url = http://controller:35357/  
auth\_plugin = password  
identity\_uri = http://controller:35357/  
auth\_uri = http://controller:5000/v2.0/

这就是我想要的，

![](../Images/a300d7331779b59024e375e76abaedc9.png)

以上就是Tacker方案，当然也是业内逐渐流行的NFV标准方案。
