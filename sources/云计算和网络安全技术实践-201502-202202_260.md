# 恶意代码分析之伪网络服务的快速搭建

继续学习恶意代码分析，进行动态分析时，常常要快速搭建一些伪网络服务来欺骗被分析的恶意代码，而达到行为分析的目的。

比如说，你想劫持恶意代码的域名解析，将本地IP返回给恶意代码，那么就可以用fireeye的免费工具apatedns来实现，下载地址如下，

https://www.fireeye.com/content/dam/fireeye-www/services/freeware/sdl-apatedns.zip，

在win7虚拟机里进行实践，在apatedns里配置所有域名解析都返回本机的IP，然后本机起一个HFS，浏览器访问百度，就直接打开了本机HFS的页面，

![](../Images/5296671eff6454d66b1325fbc23d0839.png)

这个工具相当有用，在很多场景下能够起到事半功倍的效果。

  

另外还有一个linux下的开源工具inetsim，能够快速模拟出很多种服务，可以作为蜜罐让恶意代码来扫描，在ubuntu里安装过程如下，

echo "deb http://www.inetsim.org/debian/ binary/" > /etc/apt/sources.list.d/inetsim.list，

wget -O - http://www.inetsim.org/inetsim-archive-signing-key.asc | apt-key add -，

apt-get update，  
apt-get install inetsim，

启动inetsim，

inetsim --bind-address=192.168.137.250，

能够看到它快速模拟出来了几十个知名端口服务，
