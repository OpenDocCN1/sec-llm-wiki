# 封装OpenVAS虚机镜像

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650743959&idx=1&sn=b3b22a1b4a4c2dabafdcf58dfe7959c9&chksm=87148597b0630c816cd6b76f8f2c6de4f5b5da071992db6cb3cab7d10d961e6f0b1237def9a1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650743959&idx=1&sn=b3b22a1b4a4c2dabafdcf58dfe7959c9&chksm=87148597b0630c816cd6b76f8f2c6de4f5b5da071992db6cb3cab7d10d961e6f0b1237def9a1&scene=27#wechat_redirect)

最近接到需求封装一个开源漏洞扫描虚机的镜像，本来想偷懒直接找一个现成的，正好OpenVAS就有一个，可以去http://www.openvas.org下载，地址是，http://dl.greenbone.net/download/VM/OpenVAS/OpenVAS-8-DEMO-1.0.ova，但是这个东西用起来竟然有问题，能登录界面，但无法正常开启扫描任务，定位了好久也没成功，于是放弃，转而去自己动手用Kali封装，

为了尽量让虚机镜像小一点儿，以light版本的Kali为基础，下载地址是，

http://cdimage.kali.org/kali-2016.2/kali-linux-light-2016.2-amd64.iso，

在VMware Workstation里安装，安装过程就不详述了，考虑到虚机模板的通用性，注意保持dhcp，不要配置静态地址，安装好后，为了方便安装软件，需要从外面远程登录进来，则要临时打开ssh，由于默认是不允许root账户登录的，所以先放开这个限制，vi /etc/ssh/sshd\_config，PermitRootLogin yes，

然后就可以临时启动ssh了，service ssh start，从外面远程登录进来，首先要改一下软件安装源，cp /etc/apt/sources.list /etc/apt/sources.list.bak，

rm /etc/apt/sources.list，vi /etc/apt/sources.list，

deb http://http.kali.org/kali kali-rolling main contrib non-free，

然后更新软件安装源，apt-get update，为了以后编辑配置文件方便，

安装一下vim，apt-get install vim，为了让虚机镜像启动后仅进入命令行，

systemctl set-default multi-user.target，接下来参考Kali官方的安装指南，

https://www.kali.org/penetration-testing/openvas-vulnerability-scanning/，

首先更新一下系统，apt-get dist-upgrade，然后安装OpenVAS，

apt-get install openvas，为了能够远程访问OpenVAS的服务，编辑配置文件，

/lib/systemd/system/greenbone-security-assistant.service，

/lib/systemd/system/openvas-manager.service，

/lib/systemd/system/openvas-scanner.service，

把127.0.0.1都改为0.0.0.0，

然后再去初始化OpenVAS，openvas-setup，

耐心等，直到成功，把生成的随机密码拷贝记下来，后面改，

为了让镜像虚机启动时就把OpenVAS服务拉起来，

vim /etc/rc.local，openvas-start，

不知道什么原因，openvas-manager经常首次启动失败，

只能启动后再执行service openvas-manager start，直到成功为止，

然后就可以远程访问OpenVAS的WebUI管理界面了，

https://192.168.137.203:9392，用admin账户和之前拷贝记下来的密码登录，

先把登录密码改了，试一下开启扫描任务，成功，

下面终于可以开始封装虚机镜像了，

在VMware Workstation里安装一个ESXi5.5，

然后用VMware vCenter Converter把kali-openvas传到ESXi5.5里，

再从ESXi5.5里把kali-openvas导出来OVA，

VMware环境下的虚机镜像就算封装成功了，

KVM环境下的怎么办，把这个OVA传到KVM环境下，

先解压，tar -xvf kali-openvas.ova，

然后把vmdk文件转换成qcow2就可以了，  
qemu-img convert -O qcow2 kali-openvas-disk1.vmdk kali-openvas.qcow2，

打完收功。
