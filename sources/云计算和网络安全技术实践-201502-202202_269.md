# 用CentOS安装OpenStack

以前一直用Ubuntu实践OpenStack，本周末试了一下CentOS，做一些记录，

我实践的是最新的CentOS7.2，安装的过程就不说了，感觉比Ubuntu快，

然后把软件安装源换成阿里云的，

mv /etc/yum.repos.d/CentOS-Base.repo /etc/yum.repos.d/CentOS-Base.repo.backup，

wget -O /etc/yum.repos.d/CentOS-Base.repo http://mirrors.aliyun.com/repo/Centos-7.repo，

yum clean all，yum makecache，

接下来就按照官方指南安装OpenStack，我实践的是Liberty版本，

执行完yum install centos-release-openstack-liberty后，把OpenStack安装源也改成阿里云的，

vim /etc/yum.repos.d/CentOS-OpenStack-liberty.repo，

\[centos-openstack-liberty\]  
name=CentOS-7 - OpenStack liberty  
baseurl=http://mirrors.aliyun.com/centos/7/cloud/$basearch/openstack-liberty/  
gpgcheck=1  
enabled=1  
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-SIG-Cloud

其它安装过程完全参照官方指南，需要注意一点，

/etc/keystone/keystone.conf，/etc/nova/nova.conf，/etc/neutron/neutron.conf里都要加入notification\_driver = noop，否则populate database时报错，

安装完成后就有意思了，Web管理界面的URL是http://controller/dashboard，而Ubuntu下是http://controller/horizon，

访问一下发现打不开，研究发现是CentOS默认有防火墙，

通过命令firewall-cmd --permanent --add-port=80/tcp放开，打开成功，

启动了一个虚机，发现控制台打不开，没错，又是防火墙的问题，

通过命令firewall-cmd --permanent --add-port=6080/tcp放开，打开成功，

可以查看到/etc/firewalld/zones/public.xml的内容，

![](../Images/cfd9dc4fd2365558fa4a8f54109bd6be.png)

我这是All In One的，如果是多节点，还不知道要打开多少端口，还是把防火墙关掉吧，systemctl stop firewalld.service，systemctl disable firewalld.service，

不知道什么原因，我的安装环境，每次重启宿主机，都必须把httpd和neutron-server再重启一下，否则各种错误，于是在/etc/rc.local里加了三句话，

sleep 60，systemctl restart httpd.service，systemctl restart neutron-server.service，为了生效，需要允许可执行，chmod +x /etc/rc.d/rc.local，

对了，CentOS下的Dashboard直接就是OpenStack原生主题，不像Ubuntu，默认是Ubuntu的主题，
