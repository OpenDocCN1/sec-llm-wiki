经高人指点，终于在Newton版本上实践成功了vlan-transparent，不过这个方案跟官方的vlan-transparent不同，而是参考了如下链接，

https://wiki.openstack.org/wiki/Neutron/TrunkPort，

注意参考前文中的配置文件做如下更改，

[securitygroup]
firewall_driver = openvswitch

开始进行配置，

创建trunk网络，openstack network create trunk，

创建trunk网络的子网，openstack subnet create --network trunk --subnet-range 10.0.100.0/24 trunk-net，

在trunk网络里创建一个接口，openstack port create --network trunk trunkport，

创建trunk，把这个接口当作父接口，openstack network trunk create --parent-port trunkport testtrunk，

在业务子网中创建网关接口，openstack port create --network web --fixed-ip subnet=web-net,ip-address=10.0.0.1 subport，

把这个接口当作子接口，绑定给trunk，openstack network trunk set --subport port=subport,segmentation-type=vlan,segmentation-id=143 testtrunk，

在horizon上创建ubuntu虚机，连接到外部网络和父接口（这时候看到horizon上允许创建虚机时选择接口的好处了），


下面验证dnat，

把ubuntu虚机的路由能力放开，vim /etc/sysctl.conf，net.ipv4.ip_forward=1，然后做如下配置，
先让物理口up起来，ifconfig eth1 promisc up，

查询之前创建的业务子网网关的MAC地址，

再起相应的子接口，ip link add link eth1 name eth1.143 address fa:16:3e:8c:da:19 type vlan id 143，

给子接口配置地址，ifconfig eth1.143 10.0.0.1 netmask 255.255.255.0，

配置一条dnat规则，iptables -t nat -A PREROUTING -d 192.168.100.7 -p tcp --dport 2222 -j DNAT --to 10.0.0.5:22，

从外网访问业务虚机，
