OpenStack新版本Newton发布了，本周上手安装了一下，做一些记录，

‍按照官方安装指南，默认是linuxbridge，我需要改成ovs，而且是vlan模式，

安装neutron组件时把neutron-linuxbridge-agent换成neutron-plugin-openvswitch-agent，然后参照如下链接进行配置，

http://docs.openstack.org/newton/networking-guide/deploy-ovs-selfservice.html，

vim /etc/neutron/plugins/ml2/ml2_conf.ini，

[ml2]
type_drivers = flat,vlan
tenant_network_types = vlan
mechanism_drivers = openvswitch
extension_drivers = port_security

[ml2_type_flat]
flat_networks = physnet2

[ml2_type_vlan]
network_vlan_ranges = physnet1:100:200

[securitygroup]
enable_ipset = True

vim /etc/neutron/plugins/ml2/openvswitch_agent.ini，

[ovs]
integration_bridge = br-int
bridge_mappings = physnet1:br-eth,physnet2:br-ex

[securitygroup]
enable_security_group = True
firewall_driver = iptables_hybrid

vim /etc/neutron/l3_agent.ini，

interface_driver = openvswitch

vim /etc/neutron/dhcp_agent.ini，

interface_driver = openvswitch

这里多说一句，默认的linuxbridge方案的vlan模式，linuxbridge_agent.ini下需要增加如下配置，

[vxlan]
enable_vxlan = False

否则Linux bridge agent不能正常工作，
