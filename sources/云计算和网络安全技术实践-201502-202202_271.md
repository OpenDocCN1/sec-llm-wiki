OpenStack新版本Newton发布了，本周上手安装了一下，做一些记录，

‍按照官方安装指南，默认是linuxbridge，我需要改成ovs，而且是vlan模式，

安装neutron组件时把neutron-linuxbridge-agent换成neutron-plugin-openvswitch-agent，然后参照如下链接进行配置，

http://docs.openstack.org/newton/networking-guide/deploy-ovs-selfservice.html，

vim /etc/neutron/plugins/ml2/ml2\_conf.ini，

\[ml2\]  
type\_drivers = flat,vlan  
tenant\_network\_types = vlan  
mechanism\_drivers = openvswitch  
extension\_drivers = port\_security

\[ml2\_type\_flat\]  
flat\_networks = physnet2

\[ml2\_type\_vlan\]  
network\_vlan\_ranges = physnet1:100:200

\[securitygroup\]  
enable\_ipset = True

vim /etc/neutron/plugins/ml2/openvswitch\_agent.ini，

\[ovs\]  
integration\_bridge = br-int  
bridge\_mappings = physnet1:br-eth,physnet2:br-ex

\[securitygroup\]  
enable\_security\_group = True  
firewall\_driver = iptables\_hybrid

vim /etc/neutron/l3\_agent.ini，

interface\_driver = openvswitch

vim /etc/neutron/dhcp\_agent.ini，

interface\_driver = openvswitch

这里多说一句，默认的linuxbridge方案的vlan模式，linuxbridge\_agent.ini下需要增加如下配置，

\[vxlan\]  
enable\_vxlan = False

否则Linux bridge agent不能正常工作，
