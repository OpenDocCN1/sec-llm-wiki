上期《VMware WorkStation做嵌套虚拟化》中提到了MTU的问题，有人咨询在嵌套虚拟化环境中做VXLAN组网时默认MTU值1500不够怎么办，于是就有了今天这期续集。

继续利用上期的环境，想要MTU值超过1500，首先要在WorkStation层面做点儿文章，它默认创建的虚机网卡是e1000的，需要到vmx文件里把它改成vmxnet3，ESXi和OpenStack主机都改了，然后就可以在主机里分别把网卡MTU值改大了，比如1600，

ESXi需要改vSwitch，esxcfg-vswitch --mtu 1600 vSwitch1，

OpenStack则直接改网卡，ifconfig eth1 mtu 1600，还要再改两个配置文件，

vim /etc/neutron/plugins/ml2/ml2_conf.ini，

[agent]
veth_mtu = 1600

vim /etc/nova/nova.conf，

network_device_mtu = 1600

然后在ESXi和OpenStack主机里各自重新创建Guest VM，

ESXi里的win7，把网卡改成vmxnet3类型的，如果识别不出来就安装VMware Tools加驱动，

在Win7里也要把网卡的mtu改大，

netsh interface ipv4 set subinterface "本地连接 2" mtu=1600，

OpenStack里的cirros，直接把网卡的mtu改大，sudo ifconfig eth0 mtu 1600，

测试看效果，


Guest VM的MTU值完美超过了1500，可以放心的玩儿VXLAN了。
