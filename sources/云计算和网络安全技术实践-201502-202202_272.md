# 用VMware WorkStation做嵌套虚拟化（二）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650743930&idx=1&sn=3752ea6110635c769d9a8c1fb47d4824&chksm=8714857ab0630c6c0751d14bf84fc97d5d3c563dc4c69abce7adaca3ebb182ae90e942134c08&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650743930&idx=1&sn=3752ea6110635c769d9a8c1fb47d4824&chksm=8714857ab0630c6c0751d14bf84fc97d5d3c563dc4c69abce7adaca3ebb182ae90e942134c08&scene=27#wechat_redirect)

上期《VMware WorkStation做嵌套虚拟化》中提到了MTU的问题，有人咨询在嵌套虚拟化环境中做VXLAN组网时默认MTU值1500不够怎么办，于是就有了今天这期续集。

继续利用上期的环境，想要MTU值超过1500，首先要在WorkStation层面做点儿文章，它默认创建的虚机网卡是e1000的，需要到vmx文件里把它改成vmxnet3，ESXi和OpenStack主机都改了，然后就可以在主机里分别把网卡MTU值改大了，比如1600，

ESXi需要改vSwitch，esxcfg-vswitch --mtu 1600 vSwitch1，

![](../Images/7eb20a28b1123b0f0f7c2179737c49e0.png)

OpenStack则直接改网卡，ifconfig eth1 mtu 1600，还要再改两个配置文件，

vim /etc/neutron/plugins/ml2/ml2\_conf.ini，

\[agent\]  
veth\_mtu = 1600

vim /etc/nova/nova.conf，

network\_device\_mtu = 1600

然后在ESXi和OpenStack主机里各自重新创建Guest VM，

ESXi里的win7，把网卡改成vmxnet3类型的，如果识别不出来就安装VMware Tools加驱动，

![](../Images/eee222b2d9a37a5f53fd0e6909fbcea5.png)

在Win7里也要把网卡的mtu改大，

netsh interface ipv4 set subinterface "本地连接 2" mtu=1600，

OpenStack里的cirros，直接把网卡的mtu改大，sudo ifconfig eth0 mtu 1600，

![](../Images/d1f3513e6424445c23a8776f5e4dcf6d.png)

测试看效果，

![](../Images/cf6d9bdc104ecc2e4316a846911677b6.png)  
Guest VM的MTU值完美超过了1500，可以放心的玩儿VXLAN了。
