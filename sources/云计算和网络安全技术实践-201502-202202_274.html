目标：使用Heat + Cloud-Init方案实现自动创建ubuntu虚机、使能ssh远程登录、安装apache服务，

按照官方安装指南把Heat装好，参考验证这步，写一个Heat模板，

vim ubuntu-stack.yml，

heat_template_version: 2013-05-23

description: Test Template

parameters:
  ImageID:
    type: string
    description: Image use to boot a server
  NetID:
    type: string
    description: Network ID for the server

resources:
  server1:
    type: OS::Nova::Server
    properties:
      name: "ubuntu"
      image: { get_param: ImageID }
      flavor: "m1.small"
      networks:
      - network: { get_param: NetID }
      user_data_format: RAW
      user_data: |
        #!/bin/sh
        passwd ubuntu<<EOF
        ubuntu
        ubuntu
        EOF
        sed -i 's/PasswordAuthentication no/PasswordAuthentication yes/g' /etc/ssh/sshd_config
        service ssh restart
        sudo apt-get -y install apache2

outputs:
  server1_private_ip:
    description: IP address of the server in the private network
    value: { get_attr: [ server1, first_address ] }

再写一个shell脚本，

vim ubuntu-stack.sh，

NET_ID=$(nova net-list | awk '/ web-net / { print $2 }')

heat stack-create -f ubuntu-stack.yml -P "ImageID=ubuntu-14.04-server;NetID=$NET_ID" ubuntuStack

sleep 10

nova floating-ip-associate ubuntu 192.168.1.3

执行shell脚本之前的准备：

上传ubuntu镜像，

创建网络和路由，


申请弹性IP，

执行shell脚本后：

查看栈，


查看网络，


ssh登录ubuntu，


http访问ubuntu，


在命令行下查看栈，

heat stack-list，

在命令行下删除栈，

heat stack-delete ubuntuStack
