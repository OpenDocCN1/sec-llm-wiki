在网络安全领域，有一个概念叫深度防御，意思就是从2层一直防到7层，其中2层防护往往是比较容易忽略的，而事实上在2层内制造攻击很简单，造成的影响也很大，例如ARP投毒攻击，就能够造成主机无法上网，甚至被中间人监听的可能。虚拟化的数据中心，有很多的大二层环境，一旦一个虚机主动或被动（中毒）的进行2层攻击，后果不堪设想，因此虚拟化环境更加需要加强2层攻击的防范。

下面我们来看一个真实的ARP投毒攻击模拟，

在ESXi中创建三个虚拟机，web、db、ubuntu，放到同一个端口组里，IP地址分别为10.0.0.2，10.0.0.3，10.0.0.4，

给ubuntu安装ARP投毒工具，

apt-get install dsniff，

投毒攻击前，看一下web的ARP表，

在ubuntu上执行arpspoof -i eth0 -t 10.0.0.2 10.0.0.3，对web进行投毒，


再看web的ARP表，


事实上，虚拟机所在的端口组是有默认安全设置的，


但是它管不了ARP投毒攻击。
