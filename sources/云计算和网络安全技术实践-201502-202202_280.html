最近开始研究用Fuel部署OpenStack，摸索中前行，一步一个坎，必需把宝贵经验总结出来，让后来人少走弯路。

因为Fuel是开源的（https://github.com/openstack/fuel-main），是可以自己build这个安装iso的，但是建议不要把时间浪费在这里，直接用人家build好的iso就行了，这里（https://ci.fuel-infra.org/）提供daily build的下载，然并卵，在国内根本没速度，有三个可以正常下载的给各位分享一下（以8.0版本为例），

社区版本，

http://seed.fuel-infra.org/fuelweb-community-release/fuel-community-8.0.iso.torrent，

opnfv版本，

http://artifacts.opnfv.org/fuel/brahmaputra/opnfv-brahmaputra.3.0.iso，

mirantis官方版本，

http://9f2b43d3ab92f886c3f0-e8d43ffad23ec549234584e5c62a6e24.r60.cf1.rackcdn.com/MirantisOpenStack-8.0.iso，

都是今年3月份build的，社区版本没有默认勾选mirantis feature，opnfv版本默认不自动安装，各取所需吧，无所谓，反正后面都得升级（一会儿详细解释），以mirantis官方版本为例，啥也不用管，第一次安装出来的效果就是这样（ubuntu站点在国外，速度太慢，导致build active bootstrap失败），

先不管bootstrap的事，reboot一下，你就会发现很多service都无法正常启动，连UI都无法正常访问，怎么办呢，答案是升级，第一次安装好系统后，首先执行yum -y update，升级fuel系统，由于fuel站点（http://mirror.fuel-infra.org/）在国内没有镜像，这个速度也是及其缓慢的，必需耐心，升级完成后reboot，service最终都能正常启动了，

再来管bootstrap的事，为了能成功制作active bootstrap，编辑配置文件，

vim /etc/fuel-bootstrap-cli/fuel_bootstrap_cli.yaml，

把ubuntu站点改成阿里云，

repos:
    - name: ubuntu
      section: "main universe multiverse"
      uri: "http://mirrors.aliyun.com/ubuntu"
      priority:
      suite: trusty
      type: deb
    - name: ubuntu-updates
      section: "main universe multiverse"
      uri: "http://mirrors.aliyun.com/ubuntu"
      priority:
      suite: trusty-updates
      type: deb
    - name: ubuntu-security
      section: "main universe multiverse"
      uri: "http://mirrors.aliyun.com/ubuntu"
      priority:
      suite: trusty-security
      type: deb

再执行fuel-bootstrap build --activate，制作active bootstrap，完成后把这个active bootstrap打包压缩导出来，以后就不用再费劲联网制作了，

cd /var/www/nailgun/bootstraps/2b54d65e-70b3-4285-a3c1-8fe62b88b571，

tar -zcvf active_bootstrap.tar.gz *，

下次直接导入，本地制作active bootstrap，

fuel-bootstrap import /root/active_bootstrap.tar.gz，

fuel-bootstrap activate 2b54d65e-70b3-4285-a3c1-8fe62b88b571，

在安装OpenStack之前，还有一个最重要的，制作本地安装源，因为ubuntu和fuel的站点都在国外，直接上来就安装，100%会由于中间某处超时导致安装失败，为了能成功制作本地安装源，编辑配置文件，

vim /usr/share/fuel-mirror/ubuntu.yaml，

把ubuntu站点改成阿里云，

ubuntu_baseurl: &ubuntu_baseurl http://mirrors.aliyun.com/ubuntu，

再执行fuel-mirror create -G mos ubuntu -I /usr/share/fuel-mirror/ubuntu.yaml --debug，制作本地安装源，速度也是及其缓慢的，必需耐心，完成后把这个本地安装源打包压缩导出来，以后就不用再费劲联网制作了，

cd /var/www/nailgun/，

tar -zcvf mirrors.tar.gz mirrors，

下次直接导入解压即可，

cd /var/www/nailgun/，tar -zxvf mirrors.tar.gz，

如何指定本地安装源，且听下回分解。
