上周推送了FreeNAS的安装和配置，本周跟着推送OpenStack Cinder后端挂NFS（FreeNAS），

有了NFS（FreeNAS），安装Cinder存储服务节点时，官方推荐的LVM就不用装了，配置也很简单，

vim /etc/cinder/cinder.conf，

volume\_driver=cinder.volume.drivers.nfs.NfsDriver  
nfs\_mount\_point\_base = $state\_path/mnt  
nfs\_shares\_config = /etc/cinder/nfs\_shares

vim /etc/cinder/nfs\_shares，

192.168.137.25:/mnt/freenas

chown root:cinder /etc/cinder/nfs\_shares，  
chmod 0640 /etc/cinder/nfs\_shares，

每个节点都要apt-get install nfs-common，

然后service cinder-volume restart，
