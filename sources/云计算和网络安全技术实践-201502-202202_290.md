# 在VMware WorkStation嵌套虚拟化环境里玩儿VSAN

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650743785&idx=1&sn=e47bc924ef46fba12aaf3e26556ea598&chksm=871482e9b0630bff08d63166328f99f044fadd9fac1455eb807a024d1b2f64313f763f24bae7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650743785&idx=1&sn=e47bc924ef46fba12aaf3e26556ea598&chksm=871482e9b0630bff08d63166328f99f044fadd9fac1455eb807a024d1b2f64313f763f24bae7&scene=27#wechat_redirect)

VSAN是VMware主推的他们自己的存储服务，不管你喜不喜欢它，毕竟它是最容易在vCenter+ESXi环境里构建的存储服务，本周在VMware WorkStation嵌套虚拟化环境里实践了一下。

首先在VMware WorkStation中构建vCenter+ESXi基础环境，5.5和6.0版本我都做了实践，下面贴出来的是6.0的过程，

![](../Images/6713125366e65411c5c81cc50042c41e.png)  
每个ESXi除了给一块装系统的硬盘作为本地存储，再加两块硬盘给VSAN用，

![](../Images/a1d4bba1223d63970d92f144fa52fde2.png)

进入每个ESXi的shell把其中一块给VSAN用的硬盘hack成SSD，

esxcli storage nmp satp rule add --satp VMW\_SATP\_LOCAL --device mpx.vmhba1:C0:T1:L0 --option=enable\_ssd

esxcli storage core claiming reclaim -d mpx.vmhba1:C0:T1:L0

![](../Images/860fcca79627bbe41fff71fdfd8b5ff4.png)

登录vSphere Web Client，进入每个ESXi的网络，

![](../Images/70f9d5fd3e12181257158fc61b46a08e.png)  
对vSwitch0的管理端口组使能vMotion和VSAN，

![](../Images/9badb3d5f08aa05802e1ac0b9fc586f9.png)  

再进入VSAN配置，

![](../Images/d453b5362625aee66ac3270772222968.png)  
选择自动添加磁盘，

![](../Images/d128b60ef3a5b12cb341b4e751cc5543.png)  
自动网络验证，

![](../Images/57df60c66798c9e8829d3f288a76771f.png)  
点击完成，

![](../Images/803e9020d7e72be224825d4b9d7ffa30.png)  
过一会儿就能在ESXi上看到存储服务VSAN了，

![](../Images/c1bc0258cc4f6c2587e7a157c7a760aa.png)

接下来就可以在创建虚拟机时选择VSAN作为存储，虚拟机可迁移。
