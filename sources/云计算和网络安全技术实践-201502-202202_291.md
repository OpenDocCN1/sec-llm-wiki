# Web渗透测试演练系统APP：DVWA的手动安装

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=2650743773&idx=1&sn=9e239d5eb8669f21ef294cc659ab0c61&chksm=871482ddb0630bcb95ecff2ccc155716a7a5d9c3dc35abbd8f0d655710f0a373d10090c8ad2d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=2650743773&idx=1&sn=9e239d5eb8669f21ef294cc659ab0c61&chksm=871482ddb0630bcb95ecff2ccc155716a7a5d9c3dc35abbd8f0d655710f0a373d10090c8ad2d&scene=27#wechat_redirect)

上周介绍了OWASP Mutillidae II的手动安装，本期再介绍一下更有名的Web渗透测试演练系统APP：DVWA的手动安装，还是在ubuntu系统里做的实践。

首先安装数据库，

apt-get install mysql-server，

然后安装应用环境，

apt-get install unzip apache2 php5 php5-mysql php-pear php5-gd，

下载DVWA，当前最新版本下载地址如下，

https://github.com/RandomStorm/DVWA/archive/v1.9.zip，

把下载到的DVWA-1.9.zip上传到/var/www/html目录并解压，

修改目录名，mv DVWA-1.9 dvwa，

编辑配置文件，把数据库密码配上，

vim /var/www/html/dvwa/config/config.inc.php，

$\_DVWA\[ 'db\_password' \] = 'password';

配置apache/php，允许allow\_url\_include，

vim /etc/php5/apache2/php.ini，

allow\_url\_include = On，

允许./hackable/uploads目录可写，

chmod -R 777 /var/www/html/dvwa/hackable/uploads/，

重启apache，

service apache2 restart，

首次访问，需要重置数据库，

看到reCAPTCHA key: Missing和Writable file /var/www/html/dvwa/external/phpids/0.6/lib/IDS/tmp/phpids\_log.txt: No，前者是因为google被墙，懒得搞了，后者是我不想做php ids，

重置数据库后自动跳转，

admin/password登录，
