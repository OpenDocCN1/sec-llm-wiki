本周看到一款Web渗透测试演练系统APP（OWASP Mutillidae II）不错，在ubuntu系统里实践了一下安装过程，

首先安装数据库，

apt-get install mysql-server，

然后安装应用环境，

apt-get install unzip apache2 php5 php5-mysql php-pear，

下载OWASP Mutillidae II，当前最新版本下载地址如下，

http://downloads.sourceforge.net/project/mutillidae/mutillidae-project/LATEST-mutillidae-2.6.37.zip?r=&ts=1463211298&use\_mirror=nchc，

把下载到的LATEST-mutillidae-2.6.37.zip上传到/var/www/html目录并解压，

编辑配置文件，把数据库密码配上，

vim /var/www/html/mutillidae/classes/MySQLHandler.php，

static public $mMySQLDatabasePassword = "password";

首次访问，需要重置数据库，

![](../Images/8955fb79e11e79b85df7c02cd177c0f2.png)  
重置数据库后自动跳转，

![](../Images/ab201e46c7d8701c756f41bffbe9a9e8.png)  
这就可以开始做Web渗透测试演练了。
