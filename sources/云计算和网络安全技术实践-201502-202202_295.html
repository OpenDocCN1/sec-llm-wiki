ELK是一个开源实时日志分析平台，由elasticsearch（负责分布式搜索），logstash（负责日志收集），kibana（负责可视化）组成，通常的方案如下：


我目前实践了前半部分，

安装Java Oracle 8，

add-apt-repository -y ppa:webupd8team/java，

apt-get update，

apt-get install oracle-java8-installer，

下载jdk-8u77-linux-x64.tar.gz非常慢，于是用迅雷下载http://download.oracle.com/otn-pub/java/jdk/8u77-b03/jdk-8u77-linux-x64.tar.gz，放到/var/cache/oracle-jdk8-installer/目录下，提高效率，

下载安装elasticsearch，

目前最新版本https://download.elastic.co/elasticsearch/release/org/elasticsearch/distribution/deb/elasticsearch/2.3.1/elasticsearch-2.3.1.deb，

vim /etc/elasticsearch/elasticsearch.yml，

network.host: localhost，

service elasticsearch restart

下载安装kibana，

目前最新版本https://download.elastic.co/kibana/kibana/kibana_4.5.0_amd64.deb，

vim /opt/kibana/config/kibana.yml，

server.host: "localhost"，

service kibana restart，

安装nginx做反向代理，

apt-get install nginx apache2-utils，

给kibana创建登录账户，

htpasswd -c /etc/nginx/htpasswd.users kadmin

vim /etc/nginx/sites-available/default，

server {
 listen 80;
 server_name localhost;

 auth_basic "Restricted Access";
 auth_basic_user_file /etc/nginx/htpasswd.users;

 location / {
  proxy_pass http://localhost:5601;
  proxy_http_version 1.1;
  proxy_set_header Upgrade $http_upgrade;
  proxy_set_header Connection 'upgrade';
  proxy_set_header Host $host;
  proxy_cache_bypass $http_upgrade;
 }
}

service nginx restart，

下载安装logstash，

目前最新版本https://download.elastic.co/logstash/logstash/packages/debian/logstash_2.3.1-1_all.deb，

vim /etc/logstash/conf.d/syslog.conf，

input {
  tcp {
    port => 5044
    type => "syslog"
  }
}
output {
 elasticsearch { hosts => ["localhost:9200"] }
 stdout { codec => rubydebug }
}

service logstash restart，

访问http://192.168.137.250，用之前创建的kibana账户登录，


修改时间格式，

验证logstash，telnet到localhost的5044端口，输入模拟syslog数据，

kibana的Discover页面出现数据，


监听端口接收syslog日志适用于网络安全设备输出日志的场景，这是本期内容最大的价值所在，也是我当前工作中需要的，后续我要开始慢慢研究syslog日志的格式化以及怎么对日志做搜索进行可视化，用filebeat传日志有空再说。
