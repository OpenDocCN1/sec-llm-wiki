ELK是一个开源实时日志分析平台，由elasticsearch（负责分布式搜索），logstash（负责日志收集），kibana（负责可视化）组成，通常的方案如下：

![](../Images/2096b9a0191fd58f604f5e0f1ed90fbe.png)  
我今天实践了前半部分（有瑕疵，还得慢慢研究），

安装Java Oracle 8，

add-apt-repository -y ppa:webupd8team/java，

apt-get update，

apt-get install oracle-java8-installer，

下载jdk-8u77-linux-x64.tar.gz非常慢，于是用迅雷下载http://download.oracle.com/otn-pub/java/jdk/8u77-b03/jdk-8u77-linux-x64.tar.gz，放到/var/cache/oracle-jdk8-installer/目录下，提高效率，

下载安装elasticsearch，

目前最新版本https://download.elastic.co/elasticsearch/release/org/elasticsearch/distribution/deb/elasticsearch/2.3.1/elasticsearch-2.3.1.deb，

vim /etc/elasticsearch/elasticsearch.yml，

network.host: localhost，

service elasticsearch restart

下载安装kibana，

目前最新版本https://download.elastic.co/kibana/kibana/kibana\_4.5.0\_amd64.deb，

vim /opt/kibana/config/kibana.yml，

server.host: "localhost"，

service kibana restart，

安装nginx做反向代理，

apt-get -y install nginx apache2-utils，

给kibana创建登录账户，

htpasswd -c /etc/nginx/htpasswd.users kadmin

vim /etc/nginx/sites-available/default，

server {  
 listen 80;  
 server\_name localhost;

 auth\_basic "Restricted Access";  
 auth\_basic\_user\_file /etc/nginx/htpasswd.users;

 location / {  
  proxy\_pass http://localhost:5601;  
  proxy\_http\_version 1.1;  
  proxy\_set\_header Upgrade $http\_upgrade;  
  proxy\_set\_header Connection 'upgrade';  
  proxy\_set\_header Host $host;  
  proxy\_cache\_bypass $http\_upgrade;  
 }  
}

service nginx restart，

下载安装logstash，

目前最新版本https://download.elastic.co/logstash/logstash/packages/debian/logstash\_2.3.1-1\_all.deb，

vim /etc/logstash/conf.d/syslog.conf，

input {  
  tcp {  
    port => 5044  
    type => "syslog"  
  }  
}  
filter {  
  if \[type\] == "syslog" {  
    grok {  
      match => { "message" => "%{SYSLOGTIMESTAMP:syslog\_timestamp} %{SYSLOGHOST:syslog\_hostname} %{DATA:syslog\_program}(?:\\\[%{POSINT:syslog\_pid}\\\])?: %{GREEDYDATA:syslog\_message}" }  
      add\_field => \[ "received\_at", "%{@timestamp}" \]  
      add\_field => \[ "received\_from", "%{host}" \]  
    }  
    syslog\_pri { }  
    date {  
      match => \[ "syslog\_timestamp", "MMM  d HH:mm:ss", "MMM dd HH:mm:ss" \]  
    }  
  }  
}  
output {  
 elasticsearch { hosts => \["localhost:9200"\] }  
 stdout { codec => rubydebug }  
}

service logstash restart，
