不知道技术宅们是不是都像我一样有这样的怪癖，自己想实践什么东西一直搞不定，就会想尽办法一直试一直试，直到成功为止。如果你看过我之前写的一期《Docker的实践（三）》，就会知道我当时在OpenStack下实践Docker掉链子了，你以为我忘记了吗，没有，今天终于有机会让我把它做个了结。

虚拟化圈本周最大的事件是什么，当然是OpenStack新版本Mitaka的发布，然而我看了发布特性后第一时间并没有什么兴奋劲儿，因为它还是没有官方宣称支持Docker Hypervisor，直到两天前看了一个老外写的在Mitaka上实践Docker，兴趣来了，这正是我一直想要的，于是有了本期实践内容。

Mitaka的安装就不说了，按照官方安装指南，只不过我没有用官方推荐的Linux bridge，而是用的ovs，怎么改过来的，请参考我之前为Liberty版本发布写的OpenStack相关的实践，这里需要提醒实践者的是，ovs的配置部分在Mitaka版本又变地方了，当然这次的变动还是合理的，等你自己实践的时候就知道了。

本期内容主要看如何实践Docker，我完全按照那个老外的配置步骤做的，仅是有一点自己hack了一下，

1、下载并安装Docker和Nova-Docker，

curl -sSL https://get.docker.com/ | sh，

usermod -aG docker nova，

chmod 666 /var/run/docker.sock，

easy\_install pip，

git clone -b stable/mitaka https://github.com/openstack/nova-docker，

cd nova-docker，

pip install -r requirements.txt，

python setup.py install，

2、给Nova配置Docker Hypervisor，

编辑/etc/nova/nova-compute.conf，（老外的是/etc/nova/nova.conf，无效）

\[DEFAULT\]  
compute\_driver=novadocker.virt.docker.DockerDriver  
\[libvirt\]  
virt\_type=docker

创建/etc/nova/rootwrap.d/docker.filters，  
#nova/virt/docker/driver.py: 'ln', '-sf', '/var/run/netns/.\*'  
ln: CommandFilter, /bin/ln, root

重启nova-compute服务，

3、给Glance配置支持Docker容器格式，

编辑/etc/glance/glance-api.conf，

container\_formats=ami,ari,aki,bare,ovf,ova,docker

重启glance-api服务，

4、下载Docker Image并注册Glance镜像，

docker pull ubuntu，

docker pull rastasheep/ubuntu-sshd，

docker save ubuntu | glance image-create --name "ubuntu" --disk-format raw --container-format docker --visibility public --progress，

docker save rastasheep/ubuntu-sshd | glance image-create --name "rastasheep/ubuntu-sshd" --disk-format raw --container-format docker --visibility public --progress，
