# 在OpenStack下通过Cinder实现虚拟机在线迁移

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=403100258&idx=1&sn=125a0eb8b20f2e23b854ffd2511dfd32&chksm=02ed7362359afa74ab2d70f86db28052732f5753a2574a9a4c3da8c2d827c7eddd7f44971cfc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=403100258&idx=1&sn=125a0eb8b20f2e23b854ffd2511dfd32&chksm=02ed7362359afa74ab2d70f86db28052732f5753a2574a9a4c3da8c2d827c7eddd7f44971cfc&scene=27#wechat_redirect)

玩儿ESXi+vCenter久了，一直在想OpenStack下是否也能轻松实现虚拟机的在线迁移，最直接的思路就是像ESXi+vCenter一样，搞一个NFS存储服务，在网上查了一些资料，发现在OpenStack下通过Cinder就能轻松实现虚拟机的在线迁移，本期跟各位分享我的实践。

怎么安装Cinder就不说了，OpenStack官方安装指南上都有，这里就说一下怎么配置，

编辑/etc/nova/nova.conf，

live\_migration\_flag=VIR\_MIGRATE\_UNDEFINE\_SOURCE,VIR\_MIGRATE\_PEER2PEER,VIR\_MIGRATE\_LIVE，

编辑/etc/libvirt/libvirtd.conf，listen\_tls = 0，listen\_tcp = 1，auth\_tcp = "none"

编辑/etc/init/libvirt-bin.conf，env libvirtd\_opts="-d -l"，

编辑/etc/default/libvirt-bin，libvirtd\_opts=" -d -l"，

然后该重启的重启，service nova-compute restart，service libvirt-bin restart，
