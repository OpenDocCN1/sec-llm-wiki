给上期续一篇。

有人问如何批量处理特征包cap文件，我试了一下bash脚本的方法，分享给你们。

以上期的环境为例，


批量改MAC，

#!/bin/bash
cd /home/ubuntu/cap
for f in *.cap
do
 tcprewrite --enet-dmac=fa:16:3e:2d:37:b2 --enet-smac=fa:16:3e:25:8d:44 -i $f -o /home/ubuntu/changemac/$f-change-mac.pcap
done


批量修改IP，

#!/bin/bash
cd /home/ubuntu/changemac
for f in *.pcap
do
 bittwiste -I $f -O /home/ubuntu/changeip/$f-change-ip.pcap -T ip -s 10.0.0.3 -d 10.0.0.4
done


批量回放，

#!/bin/bash
cd /home/ubuntu/changeip
for f in *.pcap
do
 tcpreplay -i eth0 $f
done
