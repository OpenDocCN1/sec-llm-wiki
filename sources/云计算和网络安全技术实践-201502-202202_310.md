# Rootkit后门ohhara的实践（一）

2016年第一篇，介绍一下我这两天研究的rootkit后门ohhara。

这是研发同事给我提的需求，让研究一下用特征“gkfkqo79”识别的telnet后门ohhara，搭建出攻防环境，给用户演示IPS功能的有效性。

到Google上一搜，原来ohhara是一个韩国的技术牛人，这个rootkit后门是他1999—2000年的作品，可以从http://ohhara.sarang.net/security/ohhara-rootkit.tar.gz下载到安装文件和源码，http://ohhara.sarang.net/security/ohhara-rootkit.txt介绍了使用方法。

使用方法中明确写的仅在x86 redhat linux 6.0中做过测试，我就去找这个古老的操作系统，连redhat自己的archive库里都没有了，无奈只能用http://archive.download.redhat.com/pub/redhat/linux/6.2/en/iso/i386/redhat-6.2-i386.iso了。

先在VMware WorkStation 12.1里装redhat-6.2-i386.iso，发现能安装但不能正常启动，折腾了半天换到ESXi 5.0里终于既能安装也能正常启动了，要注意安装过程中的两处配置，

网卡类型不要选E1000，而是可变，

![](../Images/948eaf238e3bd4719b52c5e4901c6097.png)

硬盘一定要用SCSI的，而且控制器类型要选总线并行，

![](../Images/7cfe0a452009156700d02522ed2b8104.png)

接下来就迫不及待的把ohhara安装包传上去，按使用方法安装一遍看效果，发现几个问题。

安装时提示系统里有两个文件不存在，

![](../Images/94ca77505070265b0f59f8e257fee4c1.png)

修改安装文件install-ohhara-rootkit，把chattr.1和lsattr.1相关的去掉就可以了。

pstree没有隐藏进程，

![](../Images/94953a8f42cc9af32869a3dd8c8af63e.png)  
到安装包的被替换程序目录里看，确实没有pstree，我也没那个时间和能力给补一个，修改安装文件install-ohhara-rootkit，把in.smbd相关的去掉，因为它不仅在pstree下没有隐藏，还开启网卡为混杂模式，会提示管理员，留下in.inetd是因为想留一个除telnet以外的后门，验证一下进程隐藏的效果，而且in.inetd这个名字在pstree下还算不显眼。

顺便修改安装文件install-ohhara-rootkit，把telnetd相关的去掉了，因为用系统默认的in.telnetd已经使telnet后门生效了，而且telnetd还没有被默认隐藏，不免有些鸡肋，这样我还省的按使用方法中的要求，编辑/etc/inetd.conf把in.telnetd改成telnetd了。

最重要的问题，ps命令出错，

![](../Images/d7d56e88913d717899f97bbb94813ae7.png)

明显是系统不兼容造成，好在有源码，在目标系统里重新编译ps程序吧，

注意编辑makefile，把LIBVERSION = 2.0.0改成2.0.6，

![](../Images/bc9095dc30416e8ae37e82bec3a2cf01.png)

然后重新编译出正确的ps程序，

![](../Images/e38bf6e7eb7599668cdc6c36fefb98bb.png)  
问题都解决了，重新装一个干净的redhat-6.2-i386走一遍正规的攻击过程吧，

用nmap扫一下操作系统和服务信息，

![](../Images/7b3522144bbb66d27c087b1f7f0323d5.png)  
搜是否有可被利用的漏洞，

![](../Images/ec1417ce0004cc179e713c8816420adb.png)  
用metasploit做漏洞利用，配置如下，

![](../Images/c5b63fcadf59e68df3f1a56ba3d42504.png)  
利用成功，获取到shell，而且还是root权限，省的提权了，

![](../Images/51bbc6078257f8b887001259dbc63c94.png)在获取到的shell下上传ohhara安装包，安装前把之前改好的install-ohhara-rootkit和重新编译出来的ps程序都替换上去，为了隐藏通信会话，还得修改bin/glibc2.1/var/lock/subsys/...datafile.../...net...，增加两条，

echo "192.168.1.1" >> ...net...，echo "192.168.1.4" >> ...net...，

安装成功，验证一下效果，

telnet后门，用bin/gkfkqo79登录有效，可切换到root下，

![](../Images/be1f3061fb1831d4713881c18490a92f.png)

看一下会话是否被隐藏，

![](../Images/bcc740cd188f3769d1e3c6cac4b6f499.png)

再验证一下in.inetd后门，

![](../Images/9d209d8dcabb43edd86f10be51917057.png)
