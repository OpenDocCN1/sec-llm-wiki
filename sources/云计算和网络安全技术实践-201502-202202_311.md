本期的内容是思科Nexus1000v的安装与配置，算是网络方面的实践，准确的说是虚拟化中的网络，因此我用了云的封面。

以前我在OpenStack里实践过开源的OVS和Linux Bridge，那时还顺着人家叫网络虚拟化（NV），经过了一些实践后，有所领悟，拟化中的网络这个概念就在我的知识体系中抽象独立出来。

不知道你们看没看过特劳特的《定位》系列，没看过的抓紧去看，先有战术，然后把可行的战术上升为战略，我做技术也是按照这个思维方法来的，有人可能会说，网络虚拟化和你总结的虚拟化中的网络，不是一回事吗，非也，主要矛盾不同，这是哲学问题......，好了，扯远了，赶快进入今天的实践内容。

我在VMware的vCenter+ESXi环境里实践的思科Nexus1000v，有人可能会问vCenter+ESXi里不是有VDS吗，思科Nexus1000v有个卵用，从技术上来说是这样，但是技术人不能光看技术，VMware是可以一家提供计算虚拟化加网络的整体解决方案，但也给用户带来被绑架的顾虑，把计算虚拟化和网络拆开，再引入自主可控的第三方网络安全方案，这是有思想的用户干的事，我还见过仅网络就要求SDN和NFV解耦的，一个项目拆给多家做，也是这个意思......，不好意思，又絮叨了，赶快进入今天的实践内容。

先搭建一个vCenter+ESXi的环境，就用我上期实践趋势Deep Security的环境好了，然后去下载一个思科Nexus1000v的软件包，每个版本的软件包都包括VSM虚机模板（我这里的是nexus-1000v.4.2.1.SV2.2.2.ova），VEM驱动包（我这里用的VEM500-201401164100-BG-release.zip），自动化安装APP（Nexus1000V-install\_CNX.jar），

很自然先打开自动化安装APP，发现有3个选项，第一个就是全部安装，

![](../Images/84c28ce90b013d66dcce1a1505f5ab15.png)

如果你认为这么容易就错了，它要求管理网络必须在某个VLAN里，第二个安装VEM驱动包也是如此，

![](../Images/f28b746e6da8511d95219d381adbd860.png)

也就是说，如果你的管理网络不在VLAN里，这个自动化安装APP基本没什么大用了，也就能用第三个连接vCenter，（这也是我这个实践的价值所在，你们在网上找到的相关实践都是要求管理网络在VLAN里的，甚至还有让你选择二层连接模式，Control和Packet都必须有VLAN）

那就先不用安装APP了，手动搞吧，

从vCenter导入VSM虚机nexus-1000v.4.2.1.SV2.2.2.ova，导入过程中配置VSM的登录密码和IP等信息，

![](../Images/7fc61b3be1c9623f7439acf531cb9420.png)

网络都选没有VLAN的VMNetwork，

![](../Images/2dcbff2c12a802cc06fa534aae0f1238.png)

启动VSM虚机，然后再用安装APP把VSM连接到vCenter，当然你也可以手动配置，我就不费那事了，

接下来进行命令行配置，要是能像操作VDS那样在vCenter的网络视图下直接操作就好了，也许能通过在vCenter上装插件解决这个问题，以后再研究了，

远程SSH到VSM虚机，在命令行下配置上行链路和业务端口组，

configure（进入到配置模式）

vlan 2-200（创建业务VLAN）

port-profile type ethernet system-uplink（创建上行链路端口组）

no shutdown

switchport mode trunk

switchport trunk allow vlan all

system vlan 2-200（这个很重要）

vmware port-group

state enabled

show run

port-profile type vethernet vlan10（创建业务端口组）

no shutdown

switchport mode access

switchport access vlan 10

system vlan 10（这个很重要）

vmware port-group

state enabled

show run

然后就能在vCenter的网络视图里看到效果了，

![](../Images/a4d921733382ccc03f3c661b47578271.png)

下面安装VEM驱动包，先把VEM驱动包上传到ESXi主机的存储目录里，

然后在ESXi主机的安全配置中开启SSH服务，

![](../Images/5b9d9c586df77289b29d4ec1091f80fb.png)  
这样就可以远程SSH到ESXi主机上安装VEM驱动包了，

esxcli software vib install -d /vmfs/volumes/datastore1/VEM500-201401164100-BG-release.zip，

最后在switch上添加主机，正确选择上行链路的网卡和上行链路端口组，这就完成了，

![](../Images/c8be0c9ea763dcf2bed6fd977f0cf312.png)  
上行链路端口组效果，

![](../Images/3a4b0cea23a2f0a0494c17cf3fd4d26a.png)  
在两台ESXi主机上各启一个虚机放到vlan10业务端口组里，可以互相ping通，业务端口组效果，
