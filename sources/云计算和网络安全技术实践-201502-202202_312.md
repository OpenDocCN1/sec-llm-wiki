# 趋势Deep Security的实践（一）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjM5MDc2Nw==&mid=401552051&idx=1&sn=2d18e729af03afee296a53ca55b31429&chksm=0d0493b33a731aa596ba51b2c6f850f737438135926cacfc27d043fe70b498540e6c0b9652cd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjM5MDc2Nw==&mid=401552051&idx=1&sn=2d18e729af03afee296a53ca55b31429&chksm=0d0493b33a731aa596ba51b2c6f850f737438135926cacfc27d043fe70b498540e6c0b9652cd&scene=27#wechat_redirect)

本周的内容其实跟虚拟化和网络安全都相关，但主要还是安全，准确的说是虚拟化环境里的安全方案，趋势Deep Security产品，

Deep Security的原理如下，主要是工作在VMware的ESXi+vCenter环境中，通过VMware提供的EPSec接口做无代理杀毒，通过VMware提供的VMsafe接口进行引流做防火墙和入侵防御，

![](../Images/5567cdcb90f47e148d435077da5aff00.png)  
我搭出的实践环境是这样，

![](../Images/8a9db1e29a36d6b536897df45443fd78.png)  

在安装Deep Security之前需要先安装VMware vShield Manager，把ova模板从vCenter导入，启动，命令行中用admin/default登录，enable，setup，重启。

然后登录VMware vShield Manager，

![](../Images/b7ff11c012e0b7d61f1091dcd659b8a6.png)  
先配置连接和注册到vCenter，再给需要被保护的ESXi主机安装Endpoint，Deep Security就是靠这个来做无代理杀毒的，

![](../Images/95360f63100bd14546fc7869d88c0e3f.png)

接下来看如何安装Deep Security，

我用的是趋势中国官方给出的Deep Security版本，

Deep Security Manager（我下的是linux版本），

http://downloadcenter.trendmicro.com/index.php?regs=CH&clk=latest&clkval=4699&lang\_loc=15，

Deep Security Virtual Appliance（ESX Appliance和ESX Filter Driver），

http://downloadcenter.trendmicro.com/index.php?regs=CH&clk=latest&clkval=4700&lang\_loc=15，

先装一个Ubuntu Server，由于Deep Security Manager安装过程中要求图形界面，还得再给Ubuntu Server安装桌面环境，

apt-get install --no-install-recommends ubuntu-desktop，

把Deep Security Manager，ESX Appliance，ESX Filter Driver的安装包都放到同一个目录下，然后进行安装，安装过程中都是图形界面，比较易懂，

![](../Images/0f895643f9bedb347e4aa6366c0938f9.png)

仅说一下激活码怎么办，可以在安装过程中输入，也可以在安装过程中跳过，以后再在管理界面的License管理中输入，激活码怎么获得呢，我是直接给趋势打的电话，提供一些公司的基本信息，说申请一个激活码（30天免费试用），趋势客服的态度非常好，10分钟就把激活码发到公司邮箱里来了，

无论怎么处理，最后License管理中的效果是这样，

![](../Images/1f1aa8913319092c03df1ed5a8224f37.png)

安装完后登录Deep Security Manager，

![](../Images/f8ae6d3fcf8bff99f5d3320f7512da11.png)  
先配置连接到vCenter和vShield Manager，就能从Deep Security Manager上看到vCenter中的ESXi主机和虚机了，

![](../Images/cf4c54fc95d127bbcfe900103b34c918.png)

接下来给需要被保护的ESXi主机安装Filter Driver和Appliance，

Filter Driver装好的效果是这样，

![](../Images/91a463ea499a33352d78cc0de4357ccf.png)  
Appliance装好的效果是这样，

![](../Images/698064f9cd82ced23f0ab1d89c0ac558.png)

一切状态都对，可以进行安全业务测试了，

Deep Security的业务模式是先定义保护策略模板，然后把相应的保护策略模板一一绑定给需要被保护的业务虚机，明显还是主机安全防护的思路，

我这里给需要被保护的虚机（Metasploitable）绑定linux服务器保护策略，可以看到不支持杀毒，但防火墙和入侵防御都是支持的，

![](../Images/23a038d6ba924c100b4cae3bba2d5f13.png)  
比较遗憾的是，都没测试出效果，怀疑是Filter Driver的引流没正常工作，但在管理界面中看所有状态又都对，需要找时间让趋势的人给定位一下。
