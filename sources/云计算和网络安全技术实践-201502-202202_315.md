本期终于回归到网络安全，跟各位介绍一款跟Kali Linux相对的防守系统，SecurityOnion，它集成了主流入侵检测和审计工具，而且基于Ubuntu封装，非常的易用。

首先下载SecurityOnion安装iso，

http://downloads.sourceforge.net/project/security-onion/12.04.5.3/securityonion-12.04.5.3-20150825.iso?r=http

%3A%2F%2Fsourceforge.net%2Fprojects%2Fsecurity-onion%2Ffiles%2F%3Fsource%3Dnavbar&ts=1448466641&use\_mirror=nchc

我在VMware WorkStation里进行的安装，给了足够的硬件资源，

![](../Images/eeee52f5ae7b3e5f67172faa1c2bd9de.png)

第一次启动有点蒙，竟然只能live-boot，

![](../Images/2467da1bded415871c2d7f6447478e02.png)

live-boot完成后，发现可以在系统内选择安装到硬盘，

![](../Images/8dba02a2839cf3b1f82cc3a6db62c542.png)

像安装普通Ubuntu系统一样，完成安装到硬盘，重启再次进入系统，

![](../Images/ccc72bd512c856f6ba53ca26c5e77a92.png)

setup进行SecurityOnion的接口配置，选择管理口，  

![](../Images/b5f72e1805b3084c99786e347c0db244.png)  
选择监听口，

![](../Images/26199c34945b87663d6043cea9bdb6a4.png)  
重启后，再次setup进行SecurityOnion功能配置，咱是专业人士，选择高级，

![](../Images/1d20175d35d76d23437cef95d8a8a9e5.png)

选择单机模式，

![](../Images/121cd49544c49f2bfbe2252519a7a942.png)  
入侵检测选择使用Suricata，其它的一路回车就可以了，

![](../Images/07417d62cdeb07c3e1f91c3cf4b62001.png)  
下面把SecurityOnion改造成安全网关，

编辑配置文件，vim /etc/network/interfaces

auto eth0  
iface eth0 inet static  
address 192.168.1.250  
gateway 192.168.1.1  
netmask 255.255.255.0  
dns-nameservers 114.114.114.114  
auto eth1  
iface eth1 inet static  
address 172.16.1.254  
netmask 255.255.255.0

开启路由能力，vim /etc/sysctl.conf，net.ipv4.ip\_forward=1

添加DNAT规则，

iptables -t nat -A PREROUTING -p tcp -d 192.168.1.250 --dport 1280 -j DNAT --to-destination 172.16.1.204:80

关闭防火墙，ufw disable（否则不能从外面访问管理UI），

然后进行测试，启动Metasploitable2（172.16.1.204），在外面用NetSparker扫http://192.168.1.250:1280/dvwa，

访问https://192.168.1.250:444，进入Snorby的管理UI，

![](../Images/5cbbb2ad696b611c0a0701afe8f9afa4.png)
