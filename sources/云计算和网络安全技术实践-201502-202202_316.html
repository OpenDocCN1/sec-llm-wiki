算了，吐槽没有任何卵用，看我实践的情况吧，安装过程https://wiki.openstack.org/wiki/Docker写的很详细了，我就不在这里贴我的安装过程了，

我直接从下载Docker镜像开始，docker pull busybox，docker pull ubuntu，


然后把Docker镜像注册成Glance镜像，
docker save busybox | glance image-create --name "busybox" --disk-format raw --container-format docker --visibility public --progress，
docker save ubuntu | glance image-create --name "ubuntu" --disk-format raw --container-format docker --visibility public --progress，


起一个容器试试，不支持Neutron，只能用命令行，nova boot --flavor m1.tiny --image busybox busybox，

OpenStack里能看到实例，

Docker命令行下能show出一个启动而又自动关闭的容器，尝试启动，无效，自己新创建一个容器，成功，退出再启动，还是成功，


再起一个ubuntu，nova boot --flavor m1.small --image ubuntu ubuntu，
