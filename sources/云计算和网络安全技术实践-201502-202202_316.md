上期预告了在OpenStack下实践Docker，没想到给自己挖了个坑，一顿纠结，还是决定不跳票了吧，不成功的实践也是实践，享受的是过程。

我参照的是https://wiki.openstack.org/wiki/Docker，

目前Docker在OpenStack下的原理如下，  

![](../Images/5705a4dd2dbbd677a6d0773ebf29c374.png)  
内行一眼就能看出来这玩意儿不兼容Neutron，相当不实用，但既然不想跳票，就硬着头皮继续吧，

参照https://wiki.openstack.org/wiki/Docker，作者也没说支持OpenStack哪个版本，我就从icehouse版本开始试，一直到liberty版本才算能正常安装，这指南明显是去年写的，但是liberty版本才出来呀，不知道作者是怎么成功的。

算了，吐槽没有任何卵用，看我实践的情况吧，安装过程https://wiki.openstack.org/wiki/Docker写的很详细了，我就不在这里贴我的安装过程了，

我直接从下载Docker镜像开始，docker pull busybox，docker pull ubuntu，

![](../Images/de7a51c7ce79f67636cbe795a99a19cc.png)  
然后把Docker镜像注册成Glance镜像，  
docker save busybox | glance image-create --name "busybox" --disk-format raw --container-format docker --visibility public --progress，  
docker save ubuntu | glance image-create --name "ubuntu" --disk-format raw --container-format docker --visibility public --progress，

![](../Images/f8631aaa21b6a5f90f2c9f62efa91cf0.png)  
起一个容器试试，不支持Neutron，只能用命令行，nova boot --flavor m1.tiny --image busybox busybox，

OpenStack里能看到实例，

![](../Images/30c32fc95dd258c9757697943afee638.png)

Docker命令行下能show出一个启动而又自动关闭的容器，尝试启动，无效，自己新创建一个容器，成功，退出再启动，还是成功，

![](../Images/a05c650cedda96cfe1f584aa7bc82e72.png)  

再起一个ubuntu，nova boot --flavor m1.small --image ubuntu ubuntu，

OpenStack里也能看到实例，但是报错，  

![](../Images/dec126a75a66d70d3df013608a316d60.png)  
Docker命令行下发现ubuntu容器都没启动过，

![](../Images/1a9ba460815913a262abacef04fd3361.png)  

就实践到这儿了，在网上查了好多，都没有准确答案，实在弄不下去了，
