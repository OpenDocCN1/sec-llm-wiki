书接上回，本期实践OpenStack新版本推荐的公有云Self Service模式。

Self Service模式架构如下，

上期我说了，新版本中明确了私有云和公有云的Provider和Self Service模式是跟版本无关的，Provider模式我是用Icehouse版本实践的，Self Service模式咱们就换一个，拿Kilo版本试试。

按照Kilo版本的官方安装指南来安装一个Controller和一个Compute节点，在Neutron部分注意不要再安装OVS了，而是改成neutron-plugin-linuxbridge-agent，还有要注意的是，在/etc/nova/nova.conf中修改，

linuxnet_interface_driver = nova.network.linux_net.NeutronLinuxBridgeInterfaceDriver，

在/etc/neutron/l3_agent.ini和/etc/neutron/dhcp_agent.ini中修改，

interface_driver = neutron.agent.linux.interface.BridgeInterfaceDriver，

剩下的就是/etc/neutron/plugins/ml2/ml2_conf.ini里的配置了，

[ml2]
type_drivers = flat,vxlan（Compute节点不需要flat）
tenant_network_types = vxlan
mechanism_drivers = linuxbridge,l2population

[ml2_type_flat]
flat_networks = physnet1（Compute节点不需要）

[ml2_type_vxlan]
vni_ranges = 100:200
vxlan_group = 239.1.1.1

[securitygroup]
enable_security_group = True
enable_ipset = True
firewall_driver = neutron.agent.linux.iptables_firewall.IptablesFirewallDriver

[agent]
tunnel_types = vxlan

[linux_bridge]
physical_interface_mappings = physnet1:eth1（Compute节点不需要）

[vxlan]
enable_vxlan = True
local_ip = 192.168.1.43（Compute节点是192.168.1.44）
l2_population = True

Kilo版本不需要配置linuxbridge_conf.ini，不得不再吐槽OpenStack版本功能配置方法变化太频繁，今天这样，明天那样，后天又改回来。
