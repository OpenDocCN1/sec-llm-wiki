上期我说了，新版本中明确了私有云和公有云的Provider和Self Service模式是跟版本无关的，Provider模式我是用Icehouse版本实践的，Self Service模式咱们就换一个，拿Kilo版本试试。

按照Kilo版本的官方安装指南来安装一个Controller和一个Compute节点，在Neutron部分注意不要再安装OVS了，而是改成neutron-plugin-linuxbridge-agent，还有要注意的是，在/etc/nova/nova.conf中修改，

linuxnet\_interface\_driver = nova.network.linux\_net.NeutronLinuxBridgeInterfaceDriver，

在/etc/neutron/l3\_agent.ini和/etc/neutron/dhcp\_agent.ini中修改，

interface\_driver = neutron.agent.linux.interface.BridgeInterfaceDriver，

剩下的就是/etc/neutron/plugins/ml2/ml2\_conf.ini里的配置了，

\[ml2\]  
type\_drivers = flat,vxlan（Compute节点不需要flat）  
tenant\_network\_types = vxlan  
mechanism\_drivers = linuxbridge,l2population

\[ml2\_type\_flat\]  
flat\_networks = physnet1（Compute节点不需要）

\[ml2\_type\_vxlan\]  
vni\_ranges = 100:200  
vxlan\_group = 239.1.1.1

\[securitygroup\]  
enable\_security\_group = True  
enable\_ipset = True  
firewall\_driver = neutron.agent.linux.iptables\_firewall.IptablesFirewallDriver

\[agent\]  
tunnel\_types = vxlan

\[linux\_bridge\]  
physical\_interface\_mappings = physnet1:eth1（Compute节点不需要）

\[vxlan\]  
enable\_vxlan = True  
local\_ip = 192.168.1.43（Compute节点是192.168.1.44）  
l2\_population = True

Kilo版本不需要配置linuxbridge\_conf.ini，不得不再吐槽OpenStack版本功能配置方法变化太频繁，今天这样，明天那样，后天又改回来。
