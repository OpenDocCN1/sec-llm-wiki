# 用Apache+Modsecurity打造WAF的实践（二）

书接上回，本期给你们展示用NetSparker扫一下，然后用Splunk分析日志的实践，

首先说一下如何升级modsecurity规则库，去OWASP官网下载压缩包，

https://github.com/SpiderLabs/owasp-modsecurity-crs/tarball/master，

把本地的/usr/share/modsecurity-crs替换掉即可，

当然别忘了再从base\_rules把你需要的规则文件拷贝进activated\_rules里，

我本次实践用了常见攻击，以及SQL注入和XSS规则文件，

![](../Images/c1d81666da7652a73a50fd1045971bcb.png)

在外面用NetSparker扫，modsec\_audit.log中的日志条目就多了起来，

下面进入Splunk分析实践，

以前做过Splunk Server的实践，就不再赘述它的安装过程了，

本次实践需要用splunkforwarder把modsec\_audit.log中的日志转发给Splunk Server，所以先要在Splunk Server上配置转发接收，

![](../Images/067f6b6a404b1c1079644cb15f461b36.png)

splunkforwarder的安装过程和用法需要详述一下，

在我们这个手工打造的开源免费WAF系统（Apache+Modsecurity）里安装splunkforwarder，dpkg -i splunkforwarder-6.3.0-aa7d4b1ccb80-linux-2.6-amd64.deb，然后启动，/opt/splunkforwarder/bin/splunk start，

添加forward-server，/opt/splunkforwarder/bin/splunk add forward-server 192.168.1.251:9997，会提示要求输入用户名/密码，我这里是admin/changeme，然后查看一下是否添加成功，/opt/splunkforwarder/bin/splunk list forward-server，

添加被监控的文件或目录，/opt/splunkforwarder/bin/splunk add monitor /var/log/apache2/modsec\_audit.log，

等一会儿就能在Splunk Server上看到进来数据了，

![](../Images/dc923975b06b2a5dc14a5d70693ef3a0.png)

下面看怎么分析，比如我想知道各种攻击数量的排名，

先找到日志中各种攻击名字的位置，然后做字段提取，这里我直接用的正则表达式，msg(?P<modsec\_msg>\[^\\\]\]+)，提取出名字叫modsec\_msg的字段，

![](../Images/adb3817f76dd912aef121ecd6c076036.png)

预览时就能看到当前各种攻击数量的排名了，以后可以直接在搜索里通过sourcetype=modsec\_audit | top modsec\_msg查询，还可以在可视化中直观看柱状图，

![](../Images/fbd7b42e9f6d7bc34f64a161957f092a.png)

点击某一个你关心的攻击的柱子，继续看这种攻击的具体日志信息，

![](../Images/507d052f2c368c5f6b43e277c2bd1e3c.png)

本期实践的内容就是这些，谢谢大家。
