上期实践了一个包装好的开源免费WAF系统，你们见识到了它的强大，是否有人已经意识到了，在互联网+的时代，网络安全必定是一个产品免费，而靠服务赚钱的行业，闲言少叙，本期继续再实践纯手工打造的开源免费WAF系统，Apache+Modsecurity。

环境还是上期的环境，只是把现成的FreeWAF换成了一个干净的Ubuntu Server，网络配置如下，


在Ubuntu Server上安装Apache，apt-get install apache2，

给Apache配置反向代理，vim /etc/apache2/sites-available/000-default.conf，添加如下配置，

ProxyPass / http://192.168.126.204/

ProxyPassReverse / http://192.168.126.204/

重启Apache，service apache2 restart，验证反向代理，


接下来安装modsecurity，apt-get install libapache2-modsecurity，

把模板拷贝成modsecurity配置文件，

cp /etc/modsecurity/modsecurity.conf-recommended /etc/modsecurity/modsecurity.conf，

编辑modsecurity配置文件，vim /etc/modsecurity/modsecurity.conf，

开启阻断模式，SecRuleEngine On，

把需要的规则文件拷贝到激活规则目录，这里我仅实践SQL注入，因此只拷贝一个，

cp /usr/share/modsecurity-crs/base_rules/modsecurity_crs_41_sql_injection_attacks.conf /usr/share/modsecurity-crs/activated_rules，

编辑security2配置文件，vim /etc/apache2/mods-available/security2.conf，添加如下配置，

IncludeOptional /usr/share/modsecurity-crs/*.conf
IncludeOptional /usr/share/modsecurity-crs/activated_rules/*.conf

让Apache加载Modsecurity，service apache2 reload，a2enmod security2，
