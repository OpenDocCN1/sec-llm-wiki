切换到阿里云的14.04的安装源，有人可能会问，你这不是12.04吗，怎么14.04的安装源也行，对，只要你去尝试，任何事情皆有可能，这就是黑客精神，

![](../Images/2879722b3f6be148cf6f9e0415ecc199.png)

  

接下来安装IPSEC VPN软件，apt-get install strongswan，

当然别忘了打开路由功能，修改/etc/sysctl.conf，net.ipv4.ip\_forward = 1，

  

FreeWAF的/etc/ipsec.conf

conn myvpn  
keyexchange=ikev1  
ikelifetime=1440m  
keylife=480m  
ike=aes128-sha1-modp1024!  
esp=aes128-sha1  
left=192.168.1.250  
right=%any  
rightid=%any  
leftsubnet=192.168.126.0/24  
authby=secret  
auto=add

  

FreeWAF的/etc/ipsec.secrets

192.168.1.250 : PSK 123456

  

再搞一个Ubuntu虚拟机做客户端，

  

客户端的/etc/ipsec.conf

conn ipsecvpn  
keyexchange=ikev1  
ikelifetime=1440m  
keylife=480m  
ike=aes128-sha1-modp1024!  
esp=aes128-sha1  
left=192.168.1.25  
right=192.168.1.250  
rightid=%any  
rightsubnet=192.168.126.0/24  
authby=secret  
auto=start

  

客户端的/etc/ipsec.secrets

192.168.1.25 : PSK 123456
