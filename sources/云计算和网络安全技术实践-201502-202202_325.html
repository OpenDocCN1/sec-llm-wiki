本期的内容又回到网络安全，最近对PowerShell比较感兴趣，正好又认识了一个PowerShell渗透测试的新工具，Empire，做了一些实践，分享给大家。

首先在Kali中下载Empire，

git clone https://github.com/PowerShellEmpire/Empire.git，

进入Empire文件夹，cd Empire，进入安装文件夹，cd setup，

执行安装，./install.sh，退回到Empire文件夹，启动Empire，./empire，

就能看到Empire的操作命令行了。

Empire的使用过程一般是这样，先创建一个listener，就是监听端，

然后再创建一个stager，就是反射，想办法让被控制端执行，

连接回listener，控制端就获得了一个交互式shell，

接下来就可以用Empire提供的各种module为所欲为了。

如何让被控制端执行stager，我还是花了些心思的，我不喜欢直接进入被控制端去执行，即使这不是真正的渗透测试过程，我也尽量让它像那么回事。
