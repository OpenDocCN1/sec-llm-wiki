书接上回，本期来看看在Linux Bridge下如何从外面访问Docker容器，以及如何在OVS下使用Docker容器。

创建容器时多加一个-p的参数，就能在宿主机上打开端口转发，

docker run -i -t -d -p 2222:22 91e54dfb1179 /bin/bash，

在宿主机上能够查看到DNAT规则，

![](../Images/def64e291b0ebee5a3f0f5245d51286d.png)  

进入Docker容器，docker exec -i -t cbf3c0111e11 /bin/bash，

更新安装源，apt-get update，

安装ssh服务，apt-get install openssh-server，

安装文本编辑器，apt-get install vim，

编辑ssh服务配置，vim /etc/ssh/ssh\_config，允许root账号远程登录，

PermitRootLogin yes，重启ssh服务，service ssh restart，

在外面ssh宿主机的外网映射端口，便可以远程进入到Docker容器，

![](../Images/2fd424a5ce93decd93e86d781e200cc5.png)  

为了实践在OVS下使用Docker容器，先给宿主机加一个网卡，eth1，

安装OVS，apt-get install openvswitch-switch，

添加外部网络bridge，ovs-vsctl add-br br-ex，

把宿主机的eth1口绑到外部网络bridge上，ovs-vsctl add-port br-ex eth1，

把宿主机的eth1口配置成混杂模式，ifconfig eth1 promisc up，

起一个Docker容器，但不连接到任何网络上，

docker run --net=none --privileged=true -i -t -d 91e54dfb1179 /bin/bash，

查看容器的ID，docker ps，

在宿主机上下载OVS专门给Docker用的脚本，

wget https://github.com/openvswitch/ovs/raw/master/utilities/ovs-docker，

给Docker容器添加一个网卡，并挂在OVS的外部网络bridge上，

./ovs-docker add-port br-ex eth0 b552b74ccb8d，

在宿主机上查看OVS，ovs-vsctl show，

![](../Images/cabbea455fe9bbccc284077003f409d0.png)  

进入Docker容器，docker exec -i -t b552b74ccb8d /bin/bash，

给eth0配置地址（宿主机的eth1已经连接到192.168.137.0/24网络上），

ifconfig eth0 192.168.137.250 netmask 255.255.255.0，

添加默认路由，route add default gw 192.168.137.1，访问外部网络，

![](../Images/428a3effdba53b9ade782dc8d4590ded.png)  

从外部网络访问Docker容器，不需要DNAT，还是这样方便一些，

![](../Images/019b62b328e8829f9180df9d085212c8.png)  

Docker的实践就先做这些，下期换内容。
