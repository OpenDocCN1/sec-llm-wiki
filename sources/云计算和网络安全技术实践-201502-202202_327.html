Docker使用容器的方法来实现类似虚拟机的功能，从而利用更加节省的硬件资源提供给用户更多的计算应用。跟虚拟机的方式不同，容器并不是一套硬件虚拟化方法，而是一个操作系统级虚拟化方法，理解起来可能并不像虚拟机那样直观，算了，你把它理解为APP或进程好了，就像苹果iOS里面的APP，完全使用沙箱机制。

目前Docker仅适用于Linux系统，这也是其不能代替虚拟机方案的原因，但是就看用户需求了，如果Docker刚好满足了你的需求，其相对虚拟机来说，优势是巨大的。

闲话少说，我们来看实践，

装一个ubuntu-15.04-server，更新一下安装源，apt-get update，

安装Docker，apt-get install docker.io，

直接在命令行下执行docker，它支持的子命令就出来了，然后可以再执行docker + 子命令来看各子命令的用法，


下载镜像，docker pull ubuntu，查看镜像，docker images，

启动一个容器，直接就进入命令行，docker run -i -t ubuntu /bin/bash，

如果exit，容器就会被删除，

因此建议后台启动，docker run -i -t -d ubuntu /bin/bash，

查看运行中的容器，docker ps，

进入后台运行容器的bash，docker exec -i -t CONTAINER ID /bin/bash，

停止容器，docker stop CONTAINER ID，

看所有的容器，docker ps -a，

启动未运行的容器，docker start CONTAINER ID，

删除容器（先stop再删除），docker rm CONTAINER ID，

删除镜像（删除容器后再删除），docker rmi IMAGE ID，
