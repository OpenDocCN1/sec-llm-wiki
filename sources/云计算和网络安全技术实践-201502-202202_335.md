本周开始插播SDN/NFV相关内容的技术实践，从OpenStack开始。

OpenStack是一套开源的面向租户的公有云架构，它风靡全球，前景无限。我是从havana版本开始接触OpenStack的，期间经历了icehouse、juno，一直到目前最新的kilo，每出一个新版本我都会安装一遍体验一下，加上工作需要，大大小小的安装也有上百遍了，因此已经成了熟练的安装工人，照着官方安装文档，安装一个两个节点的系统，也就2个小时。这里我要说的是啥呢，想要玩明白OpenStack，必须手动安装，在这个过程中体验它的架构，和各组件之间的关系，然后才是使用它，体验的它设计的精妙和吐槽它跟你期望的差距。

下面是OpenStack的架构，由控制节点、网络节点、计算节点、存储节点组成，然后每个节点上需要安装相应的软件功能模块，一般我做实验就安装一个all in one单节点的（vlan模式），或双节点的（vxlan模式）。

![](../Images/4428a0156ba5457cc3857a50490808b3.png)

vlan或vxlan是指它的业务组网方式，vlan模式一般用于租户数量在1000左右，适用于小型公有云；而vxlan模式则不受租户数量限制，可构建大型公有云。下面是OpenSack的Neutron（网络功能）模块的组网原理，虚拟机都直连在br-int上，vlan模式时用br-eth，vxlan模式时用br-tun，一般通过flat模式的网络从br-ex出公网。

![](../Images/d8119143b93b83253a00dbbf83d45122.png)

目前最新kilo版本的官方安装指南如下：

http://docs.openstack.org/kilo/install-guide/install/apt/content/，

指南中的网络模式用的gre，vlan和vxlan则可以参考如下我的实践，

vlan模式，编辑/etc/neutron/plugins/ml2/ml2\_conf.ini，

\[ml2\]  
type\_drivers = flat,vlan  
tenant\_network\_types = vlan  
mechanism\_drivers = openvswitch  
\[ml2\_type\_flat\]  
flat\_networks = physnet2  
\[ml2\_type\_vlan\]  
network\_vlan\_ranges = physnet1:100:200  
\[securitygroup\]  
enable\_security\_group = True  
enable\_ipset = True  
firewall\_driver = neutron.agent.linux.iptables\_firewall.OVSHybridIptablesFirewallDriver  
\[ovs\]  
tenant\_network\_types = vlan  
network\_vlan\_ranges = physnet1:100:200  
integration\_bridge = br-int  
bridge\_mappings = physnet1:br-eth,physnet2:br-ex

vxlan模式，编辑/etc/neutron/plugins/ml2/ml2\_conf.ini，

\[ml2\]  
type\_drivers = flat,vxlan  
tenant\_network\_types = vxlan  
mechanism\_drivers = openvswitch  
\[ml2\_type\_flat\]  
flat\_networks = physnet2  
\[ml2\_type\_vxlan\]  
vni\_ranges = 100:200  
vxlan\_group = 239.1.1.1  
\[securitygroup\]  
enable\_security\_group = True  
enable\_ipset = True  
firewall\_driver = neutron.agent.linux.iptables\_firewall.OVSHybridIptablesFirewallDriver  
\[ovs\]  
local\_ip = 192.168.70.3  
tunnel\_type = vxlan  
enable\_tunneling = True  
integration\_bridge = br-int  
bridge\_mappings = physnet1:br-tun,physnet2:br-ex  
\[agent\]  
tunnel\_types = vxlan
