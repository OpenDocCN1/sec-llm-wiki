本期开始做strongswan的实践系列。

 

VPN技术能实践的东西可太多了，对于strongswan，咱们就挑相对较难、有技术含量的来，那就是远程接入（数字证书认证）。strongswan的服务端肯定是linux服务器，但接入的终端类型有多种，因此计划分三期介绍，第一期linux终端、第二期windows终端、第三期移动终端（安卓手机）。

 

咱们这就开始第一期的内容。

 

1、准备strongswan服务器

 

既然是VPN服务器，那就得分内外网，我的strongswan服务器的网络配置如下，eth0是外网口，eth1是内网口：

![](../Images/1cb76de30df08b75f9c1f81b8a43c412.png)  

安装strongswan，apt-get install strongswan，

 

linux终端很简单，就不详述了，仅需一个网卡，能跟strongswan服务器的外网口互通，当然也要安装strongswan软件。

 

2、制作数字证书

 

首先制作CA证书，编辑/etc/ssl/openssl.cnf，所有basicConstraints都改成CA:true，

建立CA目录，

mkdir -p ./demoCA/{private,newcerts}

touch ./demoCA/index.txt

echo 01 > ./demoCA/serial

生成CA密钥，openssl genrsa -des3 -out ./demoCA/private/cakey.pem 2048

生成CA证书请求：openssl req -new -days 365 -key ./demoCA/private/cakey.pem -outcareq.pem

生成自签名证书，openssl ca -selfsign -in careq.pem -out cacert.pem

 

再制作用户证书，编辑/etc/ssl/openssl.cnf，之前改的所有basicConstraints再改回来，

生成server密钥，openssl genrsa -des3 -out serverkey.pem

生成server证书请求，openssl req -new -days 365 -key serverkey.pem -out serverreq.pem

生成CA签名证书，openssl ca -in serverreq.pem -out servercert.pem

生成client密钥，openssl genrsa -des3 -out clientkey.pem

生成client证书请求，openssl req -new -days 365 -key clientkey.pem -out clientreq.pem

生成CA签名证书，openssl ca -in clientreq.pem -out clientcert.pem

 

3、安装数字证书

 

server端证书安装：

cacert.pem放入/etc/ipsec.d/cacerts，servercert.pem放入/etc/ipsec.d/certs，serverkey.pem放入/etc/ipsec.d/private

 

client端证书安装：

cacert.pem放入/etc/ipsec.d/cacerts，clientcert.pem放入/etc/ipsec.d/certs，clientkey.pem放入/etc/ipsec.d/private

 

4、配置strongswan

 

server端/etc/ipsec.secrets配置：

: RSA serverkey.pem "123456"

 

server端/etc/ipsec.conf配置：

conn rw

 keyexchange=ikev1

 ike=aes128-sha1-modp1024!

 esp=aes128-sha1

 left=192.168.1.3

 leftsubnet=192.168.226.0/24

 leftcert=servercert.pem

 right=%any

 authby=rsasig

 auto=add

 

client端/etc/ipsec.secrets配置：

: RSA clientkey.pem "123456"

 

client端/etc/ipsec.conf配置：

conn home

 keyexchange=ikev1

 ike=aes128-sha1-modp1024!

 esp=aes128-sha1

 left=192.168.1.33

 leftcert=clientcert.pem

 right=192.168.1.3

 rightsubnet=192.168.226.0/24

 rightid="C=CN, ST=Beijing, O=WLAQJSSJ, OU=WLAQJSSJ, CN=Server"

 authby=rsasig

 auto=start
