1、安装Modern Honey Network

我这里用的是Ubuntu14.04，首先更新一下安装源apt-get update，

安装git，apt-get install git，

下载Modern Honey Network的代码git clone https://github.com/threatstream/mhn.git，

不要使用官方的安装方法（仅执行一个总的安装脚本），因为只要中间哪个地方出一点问题，它就全部重新来过，问题会越来越多，反正我是试了很多次都没有成功，于是看了一下总的安装脚本里的代码，发现可以分部分安装。

第一部分安装hpfeeds，稍微麻烦点，进入mhn中的脚本文件夹cd mhn/scripts，打开hpfeeds安装脚本vim install\_hpfeeds.sh，把wget https://github.com/threatstream/hpfeeds/releases/download/libev-4.15/libev-4.15.tar.gz注释掉，然后自行在网上搜libev-4.15.tar.gz并下载放到/tmp下，然后再执行hpfeeds的安装脚本./install\_hpfeeds.sh，为什么这么做，因为发现install\_hpfeeds.sh自动从github下载不到libev-4.15.tar.gz，导致安装不下去，也是看了install\_hpfeeds.sh的代码，发现可以将这一步注释掉，采用手动下载取而代之。

第二部分安装mnemosyne，./install\_mnemosyne.sh，

第三部分安装honeymap，./install\_honeymap.sh，

最后一部分安装mhnserver，./install\_mhnserver.sh，安装过程中会让做服务器地址、用户名/密码等配置，比较简单，就不详述了。

至此Modern Honey Network安装完成，你可以拿浏览器访问服务器的地址，即可看到登录页面，用刚才配置的用户名/密码登录进去。

 

2、部署honeypot

这是Modern Honey Network最牛逼之处，可以自动化部署honeypot，进入Deploy菜单，在选择脚本下拉菜单下，你会看到它所能提供自动化部署的honeypot类型，我选了一种最简单的wordpot，它就自动给你生成了一个部署脚本，

![](../Images/66c2cf6db6494ddd00ade31bd3e5f795.png)

 

正好新出了Ubuntu15.04，借此机会尝尝鲜，安装好Ubuntu15.04后，在其上执行刚才Modern Honey Network给的wordpot自动化部署脚本，过程很顺利，

![](../Images/7708370ae4184ce59859b0daba193fb6.png)  

在Modern Honey Network的Sensors菜单中可以看到这个honeypot已经加入进来了，

![](../Images/da5e496b99349289df9c650a3f5ed0f9.png)
