# 为你的IP颁发一个免费的SSL证书

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2MzE2Mjk4Mg==&mid=2247483948&idx=1&sn=2fa9b3178cd6a6b5ce2186c15fcdceea&chksm=fc5f3825cb28b13377b3c5f0626bdcf91beb5fc5bfe84eec4f9f6da0349844448ab02eea08ca&scene=126&sessionid=1681656914#rd](http://mp.weixin.qq.com/s?__biz=MzU2MzE2Mjk4Mg==&mid=2247483948&idx=1&sn=2fa9b3178cd6a6b5ce2186c15fcdceea&chksm=fc5f3825cb28b13377b3c5f0626bdcf91beb5fc5bfe84eec4f9f6da0349844448ab02eea08ca&scene=126&sessionid=1681656914#rd)

ZeroSSL提供了一个免费给IP申请SSL证书的服务。

打开https://zerossl.com/注册账户后访问https://app.zerossl.com/certificate/new，在框框中写上你的IP地址。

![](../Images/1baa8830291756f254e0b35a3e728572.png)

这里证书有效期选择90天，当然如果你不差这仨瓜俩枣也可以选择带“PRO”关键字的。 

![](../Images/3ad68073a29ce12e3034d26035041b96.png)

这一步默认，直接下一步就好

![](../Images/a33c3bb91ed4f49baa9ea930b6da538e.png) 

选免费这一栏，下一步。

![](../Images/223116ca15c91038e3de04d713a73949.png)

然后就是验证资产的所有权了，选择“HTTP FILE UPLOAD”启一个http服务，然后下载

验证的文件并重命名，使下图圈红的URL能被访问到就行。

![](../Images/2c99b90ef9a92fae2e509c47832d1cc0.png) 

然后验证通过，等待签发就行，证书签发成功以后下载对应部署的服务证书格式。

![](../Images/1a2293a56d8037afa8fc90eecfa8f5f0.png)
