******Azure B2C – 加密滥用和帐户泄露******

Microsoft 的 Azure Active Directory B2C 服务包含一个加密缺陷，允许攻击者使用任何用户帐户的内容制作 OAuth 刷新令牌。攻击者可以将此刷新令牌兑换为会话令牌，从而获得对受害者帐户的访问权限，就好像攻击者已通过合法登录流程登录一样。
