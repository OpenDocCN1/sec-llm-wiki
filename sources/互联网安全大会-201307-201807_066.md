# 来ISC与行业顶级专家共同把脉关键信息基础设施保护

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODI2MTg3Mw==&mid=2649792635&idx=2&sn=4059615942c9644e9a369a776f80f3e5&chksm=bec9656589beec737a81b19d491eb1691bc73e854690097c6950fdc2a9c15fe75730aafa3e31&scene=126&sessionid=1681309438#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODI2MTg3Mw==&mid=2649792635&idx=2&sn=4059615942c9644e9a369a776f80f3e5&chksm=bec9656589beec737a81b19d491eb1691bc73e854690097c6950fdc2a9c15fe75730aafa3e31&scene=126&sessionid=1681309438#rd)

  

**关键信息基础设施保护**如今已经成为全球网络安全的焦点，世界各国纷纷出台保护关键信息基础设施的政策和战略，联合国安理会2017年2月通过决议，要求各国采取综合措施，减少关键基础设施遭受恐怖袭击的风险。7月11日，我国《关键信息基础设施安全保护条例（征求意见稿）》出台，细化了关键基础设施保护的相关制度和执行细节。

  

![](../Images/7dfda24b26be6e80a2dbadcb2cded682.png)  

  

![](../Images/56d5ef09135e0fbae506c90d0f3c2f3c.png "叶子分割线")

  

9月12日，在**中国互联网安全大会（ISC 2017）**的**关键信息基础设施保护论坛**上，汇集了中国工程院院士沈昌祥、国家工业信息安全发展研究中心所长兼党委副书记尹丽波、国家电网公司信通部主任王继业、同济大学国家创新发展研究院执行副院长李兴华、国家电投集团公司科技管理部总经理范霁红、浙江浙大中控信息技术有限公司首席专家杨永耀、360企业安全集团副总裁韩永刚等业界重量级嘉宾，共话关键信息基础设施保护的思维、体系、技术和方法的创新之道。

  

![](../Images/56d5ef09135e0fbae506c90d0f3c2f3c.png "叶子分割线")

  

  

![](../Images/c661ba878dc312c52704bc2198151f63.png)

  

沈昌祥院士将从可信计算的角度介绍关键信息基础设施的防护，可信计算是一种运算和防护并存的主动免疫的新计算模式，以密码为基因，实施身份识别、状态度量、保密存储等功能，及时识别“自己”和“非己”成份，从而破坏与排斥进入机体的有害物质，相当于为计算机信息系统培育了免疫能力。 

  

![](../Images/56d5ef09135e0fbae506c90d0f3c2f3c.png "叶子分割线")

  

  

![](../Images/c7d5e4f6dcab10da3db5cba73a07c268.png)

  

为保障电网稳定可靠运行，应对关键信息基础设施面临的网络安全风险，国家电网公司信通部主任王继业将介绍国家电网如何构建网络安全智能防御体系，从多个方面开展网络安全智能防御体系建设，有效处置网络安全威胁，为电网安全和国家社会稳定做出积极贡献。

  

![](../Images/56d5ef09135e0fbae506c90d0f3c2f3c.png "叶子分割线")

  

![](../Images/1a72634195eb16a385a4037e407fc4c2.png)

  

交通基础设施供给、交通运输工具、交通运输活动与大数据、网络化、信息化紧密伴随，未来交通系统信息安全也将面临空前的威胁和挑战，交通网络和重要信息系统已成为国家信息安全防护的重要组成部分。同济大学国家创新发展研究院执行副院长李兴华将对交通行业的关键信息基础设施防护进行介绍。

  

![](../Images/56d5ef09135e0fbae506c90d0f3c2f3c.png "叶子分割线")

  

![](../Images/051d5df15227a61fa798055398a98e60.png)

  

国家电投集团公司科技管理部总经理范霁红将从基于FPGA技术提升核电站反应堆保护系统本体安全来介绍如何有效抵御病毒或人为的网络攻击，保护核电系统运行安全。

![](../Images/56d5ef09135e0fbae506c90d0f3c2f3c.png "叶子分割线")

  

![](../Images/fb9a4166e08fff61e1a76e79bc439a11.png)

  

智慧城市建设运维是一项复杂的大型系统工程，物联网、云计算、大数据等新一代技术的应用，使得智慧城市所面临的网络环境更加复杂，因而其系统安全问题比一般互联网的信息安全问题要更加严峻和更具挑战性。浙江浙大中控信息技术有限公司首席专家杨永耀将从整体介绍智慧城市的安全威胁及系统防护。

  

![](../Images/56d5ef09135e0fbae506c90d0f3c2f3c.png "叶子分割线")

  

![](../Images/32d2476d09ec82c1d4473604b625f3da.png)

  

关键信息基础设施单位作为我国新安全态势下的重中之中，其面临的安全问题不再仅是影响到网络与IT层面，更会涉及到国计民生的方方面面。360企业安全集团副总裁韩永刚将介绍如何利用数据与运营驱动的积极防御来构建关键信息基础设施的监测与响应体系。
