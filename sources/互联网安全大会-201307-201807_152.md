# 谁将赢得第五空间争夺战？美俄网军实力大PK

美国俄罗斯VS如今网络空间已经成为陆、海、空、太空之后的第五空间，而随着互联网对现实世界的影响越来越深，网络战也将成为未来战争的决胜力量。而作为传统军事强国，美国和俄罗斯在网络空间的对抗能力也是目前世界最强的。  
![](../Images/adaf57ba9c7b7c552a772c890c2e5ea7.png)目前新一轮网络军备竞赛正拉开序幕，美俄都在积极加强网络军力建设，围绕制网权展开激烈博弈。美国组建世界最强网军不久前，美国中情局前雇员斯诺登向《明镜周刊》披露，美国国家安全局正在为未来积极备战网络战。事实上，这种准备早已贯穿在网络军备建设、网军建设及武器研发等诸多方面，并已经经过了实战的检验。![](../Images/849ec222bde0f1e90c4a9a4f229ab1b0.png)在网军建设方面，多年来美国致力于打造一支攻防能力强的网络部队。2009年美国正式建立世界上首个“网络战司令部”。网络司令部下设3支部队，分别是“国家任务部队”，分管关键电网、发电厂和其他基础设施的计算机系统；“作战任务部队”协助指挥海外项目、执行攻击或其他进攻任务；“网络保护部队”保护国防部自己的网络。  
  
美军网络司令部前司令基思•亚历山大（Keith B. Alexander）在出席参议院军事委员会听证会时，曾特别强调了美军新增40支网络部队，其中13支是专门用于进攻性的，并将进行全球部署，从任一地点对特定目标发动攻击。2014年9月，美国网络司令部现任司令迈克尔•罗杰斯（Michael S. Rogers）表示，美军正在组建一支新的网络防御部队——这支拥有6200名成员的部队应在2016年之前具备完全作战能力，旨在强化应对黑客活动，以及防御他国发起的网络攻击。  
![](../Images/4d24609ef6cef8a910176798371f8436.png)与此同时，美国还加大力度进行网络武器的研发制造。仅病毒武器就达2000多种，且早已进入美军武器序列。在开发新概念、新机理网络战武器方面，美国同样不遗余力。例如，嗜食硅基电子芯片的细菌、用来破坏电子电路的微米/纳米机器人和“网络数字大炮”等，这些新概念和大胆设想一旦在技术上实现突破，成为现实，其有效破坏力堪比原子弹。  
  
实战方面，美国将网络战能力视为其军事实力的重要组成部分。早在1991年的海湾战争中，美军通过激活隐藏的病毒导致伊拉克防空系统瘫痪便是最早的已知案例，拉开了网络战实战的序幕；之后1999年的科索沃战争和2003年的伊拉克战争中，美国和北约同样进一步实践了网络攻击在战争中的运用；之后，美国运用“震网”病毒和“火焰”病毒对伊朗及中东国家发动网络攻击，进一步展示了网络战的强大威力。  
俄罗斯同样不甘示弱2013年2月，俄联邦委员会提交《俄罗斯网络空间安全战略（草案）》，提出建立国家数字化主权，明确了俄罗斯联邦网络安全战略的原则、行动方向和优先事项。![](../Images/60237216f53692868b983cb7040810b6.png)在网络军力筹建方面，以“三驾马车”为主的组织架构已基本成型。这包括：内务部设“K”局，负责调查境内网络犯罪活动，将罪犯绳之以法；安全局设信息安全中心，负责对抗利用虚拟空间危害俄国家和经济安全的外国情报机构、极端组织和犯罪组织；俄国防部的网络司令部则负责遏制其他国家在网络空间对俄国家利益的公然侵犯。内务、安全与军队三大系统下辖的网络力量分工明确，各司其职。可以预见，真正意义上的“网军”在俄军序列中出现指日可待。  
  
尽管起步较晚，但俄网络战斗经验和实战能力却相当引人瞩目。2007年4月，爱沙尼亚因苏联时期纪念铜像搬迁问题与俄罗斯交恶后，该国许多重要机构的网站——包括议会、政府部门、银行、报纸和电视台等——遭到大规模网络袭击。袭击者通过分布式服务拒止攻击（DDOS）使目标网站短时间内承载过量访问而陷入瘫痪。爱沙尼亚政府指责俄罗斯指使或直接发动了这场网络攻击，而许多战略分析人士更是将此次袭击视为第一场国家间的网络战争，俄罗斯由此也被西方视为“第一个发动国家间网络战争的国家”。  
![](../Images/9de7b0681b1c3569bc583793e7e1b17b.png)此后，类似的情景在俄罗斯与格鲁吉亚的冲突中重现。据《纽约时报》去年获取的一份2009年美国国家安全局绝密文件评估中提到，俄罗斯是美国在网络空间里最老辣的对手。可以认为，俄网军通过两次实战，已将网络攻防战由概念设想转变成了实践操作，为其网军建设和发展提供了重要的实战经验。  
  
有消息称，去年刚刚退役的美军网络司令部首任司令基思•亚历山大（Keith B. Alexander）将军，9月29日将出席在北京举行的ISC 2015的中国互联网安全领袖峰会并做主题演讲，从他的演讲中或许可以了解美国网军的战略地位。  
  
据悉ISC由中国互联网协会和360互联网安全中心共同举办的，创办于2013年，是亚洲地区最大规模、最专业的信息安全行业年度会议。历经3年的发展，ISC已成为亚洲地区最大的安全行业会议，成为安全行业和产业沟通、交流合作的主要平台，也被称为亚洲安全行业的风向标。  
![](../Images/cf37536bb20276cbb81bfcf5ad0c7efd.png)中国互联网安全领袖峰会是ISC2015的开幕峰会，以全球视野关注产业前沿和未来，来自全球的顶级安全智库和安全专家将通过主题演讲和高峰对话的方式共同把握产业未来发展方向。  
  
除亚历山大将军、郝叶力和张力等中美顶级智库外，美国中佛罗里达大学教授金意儿，Cyphort联合创始人兼首席架构师弓峰敏、360公司董事长兼CEO周鸿祎、IBM全球首席安全架构师Ron Williams、传奇黑客Samy Kamkar以及邬贺铨、沈昌祥、何德全院士，国家互联网应急中心副主任兼总工程师云晓春等120位顶级智库和安全专家也将出席峰会并分享前沿话题。
