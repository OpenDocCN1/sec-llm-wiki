# 360独家全面截杀“比特币病毒”，给文档图片穿上“铠甲”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODI2MTg3Mw==&mid=205920877&idx=1&sn=2362f56125701e79aced5dfaece9278a&chksm=2f7fdf73180856658f5ae9d33c834a162b41cfc634ff2842465f954a622ceb7252c600cf1a8b&scene=126&sessionid=1681309444#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODI2MTg3Mw==&mid=205920877&idx=1&sn=2362f56125701e79aced5dfaece9278a&chksm=2f7fdf73180856658f5ae9d33c834a162b41cfc634ff2842465f954a622ceb7252c600cf1a8b&scene=126&sessionid=1681309444#rd)

“史上最缺德”比特币病毒CTB-Locker近期传入中国，众多企业办公电脑遭到感染，导致文档、图片等重要资料被病毒加密，如不支付比特币赎金，这些文件将永远无法恢复。对此360安全卫士已独家推出病毒免疫工具，只要开启“文档图片防护”就可全面免疫CTB-Locker等敲诈类比特币病毒，保护用户数据安全。

据央视报道，CTB-Locker最早在国外出现，主要通过英文邮件传播。由于该病毒采用4096位高强度加密算法，解密的私钥掌握在病毒作者手中，目前世界范围内尚无有效的解密办法。如果用暴力破解方式，以普通电脑的计算能力，破解CTB-Locker起码要数十万年！

对付CTB-Locker等比特币病毒重在预防，否则一旦中招就只能向病毒作者支付3个比特币的赎金（约合4000元人民币），就算把病毒杀掉也无法恢复文档等重要资料。更令人担忧的是，该病毒已经从企业邮箱到个人邮箱全面扩散，普通网友也面临威胁。

为了保护用户数据安全，360反病毒团队深入分析了CTB-Locker等比特币病毒的行为特征，并为360安全卫士升级主动防御规则，可以全面拦截此类病毒。同时，最新版360安全卫士还强化了“文档图片防护”功能，即使用户手动运行CTB-Locker等比特币病毒，也无法加密破坏电脑里的文档和图片。

360反病毒专家安扬提醒用户升级360安全卫士，设置开启“文档图片防护”功能。如遇红色弹窗警报，应按提示阻止病毒加密行为，可以查杀病毒并保护电脑里的重要资料。此外建议广大网友提高安全意识，不要轻易打开陌生人发来的可疑文件，并定期备份重要数据。
