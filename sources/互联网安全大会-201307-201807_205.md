# 苹果系统成为漏洞最多操作系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODI2MTg3Mw==&mid=203525279&idx=2&sn=ff362d5f957888a38c6b8dacde653340&chksm=2f184981186fc097caa6f261356c356f4f5d305d7c326fd015df3f52b071d10d9402757fc42b&scene=126&sessionid=1681309446#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODI2MTg3Mw==&mid=203525279&idx=2&sn=ff362d5f957888a38c6b8dacde653340&chksm=2f184981186fc097caa6f261356c356f4f5d305d7c326fd015df3f52b071d10d9402757fc42b&scene=126&sessionid=1681309446#rd)

苹果的操作系统被认为是最安全的操作系统,不论是针对桌面终端的Mac OS X还是针对iPhone等手持设备的iOS。但不管你信不信，苹果系统是2014年一年中最脆弱的操作系统。

**漏洞最多操作系统：**

一直以来人们人为Windows是最不安全的操作系统，它最容易被黑客攻陷，原因是历史上windows爆出过大量的安全漏洞，然后根据国外安全机构2014年的统计结果显示，windows操作系统跌出了存在漏洞最多操作系统前3名的行列，前三名的操作系统分别是：

Apple’s Mac OS X

Apple iOS

Linux kernel

根据数据显示，存在漏洞最多的操作系统，2014年被曝光了如下数量的漏洞：

Apple’s Mac OS X -发布漏洞**147**个，其中高危漏洞**64**

Apple’s iOS -发布漏洞127个，其中高危漏洞**32**

Linux Kernel -发布漏洞**119**个，其中高危漏洞**24**
