# 特斯拉再曝高危漏洞 无需钥匙可启动车辆

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODI2MTg3Mw==&mid=202767528&idx=2&sn=b54de22f4ee868f2363c17164aac1357&chksm=2f2c39b6185bb0a088d68b0473882b2c6e95551bde04b3e049c58ba6be9da05e263eeaaad690&scene=126&sessionid=1681309447#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODI2MTg3Mw==&mid=202767528&idx=2&sn=b54de22f4ee868f2363c17164aac1357&chksm=2f2c39b6185bb0a088d68b0473882b2c6e95551bde04b3e049c58ba6be9da05e263eeaaad690&scene=126&sessionid=1681309447#rd)

1月20日，360网络攻防实验室公布了特斯拉的一个高危漏洞——无需钥匙就能实现车辆开启。截至记者发稿，特斯拉尚未表明是否已经修补了此漏洞。360网络攻防实验室表示，该漏洞细节已于180天以前提交给了特斯拉，但通过验证，发现漏洞目前仍然存在，希望特斯拉车主提高警惕。

据了解，自2014年Syscan360破解特斯拉活动结束后，360网络攻防实验室团队的成员刘健皓向特斯拉提交了名为“Tesla model SKeyless start system Vulnerability Report”的漏洞报告，报告中指出，可以通过使用数字射频处理技术，伪造钥匙发出的原始射频信号，绕过车内无钥匙检测启动系统启动车辆。如果结合360首次报告的可远程控制车辆，实现开锁、鸣笛、闪灯的漏洞，黑客可以轻松实现无钥匙开走特斯拉汽车。

该漏洞提交后，特斯拉（Tesla）漏洞响应团队回复：“我们了解了这个漏洞，我们会尽快修复的。”之后就迟迟没有了消息。

根据360网络攻防实验室的180天公开安全漏洞策略，360网络攻防实验室正式向特斯拉车主发出预警。本次公布的内容，并不包含漏洞细节，所以特斯拉车主不必过于担心漏洞会被黑客利用。

刘健皓建议，特斯拉车主一定要妥善管理好汽车钥匙，在使用时留意周围可疑人员。据悉，黑客只要能录制特斯拉钥匙信号就可以无钥匙启动车辆。

此前业界曾大肆炒作过某机构通过改装实现对特斯拉的远程无人驾驶和操作。据悉，与该机构这种通过改装、乃至拆解才实现汽车破解的方式不同，360网络攻防实验室在数月前就实现了无需钥匙启动特斯拉汽车。

业界专家指出，通过改装、甚至拆解实现汽车破解的现实意义不大，这类破解通常不具有可行性。通过非接触方式，利用汽车本身的功能，获得这辆汽车的控制权，这种方式的现实影响更大，需要引起汽车制造商和车主的高度注意。
