# 当心！黑客盯上航空累积里程

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODI2MTg3Mw==&mid=202679287&idx=3&sn=6585bd04f26109f23b6bdd65df1b096d&chksm=2f2d66e9185aefffbe20aab2af103c55aa18cf847aa28a74c2d486e9edfb44b48ce24a5d7f83&scene=126&sessionid=1681309448#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODI2MTg3Mw==&mid=202679287&idx=3&sn=6585bd04f26109f23b6bdd65df1b096d&chksm=2f2d66e9185aefffbe20aab2af103c55aa18cf847aa28a74c2d486e9edfb44b48ce24a5d7f83&scene=126&sessionid=1681309448#rd)

 如果你登录自己的旅行账户，发现累积里程不知被谁给用掉了。那你也可能成为了黑客的受害者。

 日前，黑客用盗取的用户名与密码，侵入了美航（AA）、美联航（UA）的旅客账号，并用旅客累积里程预订了机票。

 这一事件发生在去年12月，两家公司本周开始通知受影响的旅客。美联社报道，登录信息是通过未知的第三方盗取的。

 美联航发言人称，该公司的累积里程交易仅仅出现在数十个帐号，被黑客窃取的里程将会返还给客户。但美航则有近1万名客户的账户被黑客入侵。

 无独有偶，笔者在360安全播报平台上看到，国内也不时有航空公司被黑客入侵的消息。比如，1月份就出现过厦门航空某系统后台绕过导致用户购票信息泄露、吉祥航空300万会员详细资料泄露、携程泄露春秋航空用户账户及密码等信息。

 盗取旅客的累积里程、游戏金币、游戏装备是黑客转化入侵成果的有效方式。

 360攻防实验室负责人林伟称，国内主要航空公司都存在类似问题。他表示，防范这些自动的钓鱼攻击需要所有相关机构对客户采取双因子认证方式，包括航空公司及其常旅行程序，以及各类第三方合作机构。他建议航空公司安全负责人最好能订阅360安全播报，这样可以及时获得安全警报，将损失降到最低。
