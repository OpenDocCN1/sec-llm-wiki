# 让人着迷的Wi-Fi网络可视化照片

随着移动互联网时代的到来，Wi-Fi（准确讲应该是WLAN，WiFi只是WLAN无线局域网协议iIEEE 802.11的一个产品互通性认证品牌，由Wi-Fi联盟持有。为了迎合大众的误区，以下我们将错就错，以WiFi代指WLAN）正在成为这个星球上最重要的网络技术，WiFi不但是智能家居、智能手机、平板电脑和笔记本电脑的个人网络首选上网方式，同时也正在成为智慧城市乃至移动运营商网络的公共网络的重要网络覆盖和数据传输技术。参考阅读：2013年将是wifi年

但是，虽然如今人们在大街上打开智能手机能搜索到一长串Wi-Fi热点名称，但是除了无线网络工程师外，没有人见过Wi-Fi网络长啥样，也不了解其工作原理。例如很多人担心Wi-Fi路由器的辐射问题，但实际上家用WiFi路由器的辐射强度只有手机的十分之一，而且随着距离的增加会迅速衰减。

最近MyDeals博客作者Nickolay Lamm与一位博士M.Browning Vogel合作测量了华盛顿国家广场的WiFi无线信号数据，并通过叠加的方式绘制了数张绚丽无比的WiFi网络照片（以下所有照片的作者都是Nickolay Lamm）

这些照片很直观地向我们展示了Wi-Fi网络如何同时使用不同频段传输，衰减以及覆盖范围等：

![](../Images/d0621fa6cea5dda81161b296e2e8b64c.png)

WiFi也是一种通过波传播的能量场，有特定的波长、波幅和速度。WiFi的波长比无线电波短，但比微波长。（频率为2.4GHz），在这个频段上WiFi的传输不会被其他无线电信号干扰。上图是理想化的wifi数据传输模型，数据通过多个子频道（以红黄绿等不同颜色代表）传输。（编者按：WLAN共13个子频道，消费者在设置路由器时子频道往往默认为6，这往往导致与邻居的信号产生干扰，可以通过WiFi信号扫描仪选择最少人用的子频道）

![](../Images/695ecf1cc309deaa71c319acd01cec49.png)

这张图可以看出WiFi的信号场呈圆球或椭圆形，普通家用Wi-Fi路由器的有效覆盖半径约20-30米。

![](../Images/7fe26a47b9f6274554fce5f4c64acfc0.png)

在户外，WiFi路由器的信号覆盖范围可达100米，但会被树和建筑遮挡，因此需要多个AP组网覆盖。
