# “全球最严重数据泄露”图表出炉，残酷现实触目惊心

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODI2MTg3Mw==&appmsgid=10000098&itemidx=2&sign=3e2164548dbf72958b2f64b4300e8390&scene=126&sessionid=1681309452#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5ODI2MTg3Mw==&appmsgid=10000098&itemidx=2&sign=3e2164548dbf72958b2f64b4300e8390&scene=126&sessionid=1681309452#wechat_redirect)

  

大规模的数据泄露和攻击往往成为新闻的关注焦点，但数字本身-----6百万次记录或者30万次密码—可能很难有清晰的概念。

网站Information is Beautiful 以交互式、可视化的方式汇总了世界上最大规模的数据泄露事件，并重点介绍了一些最受关注的攻击事件，大家可以点击此处查看具体内容并阅读每一次泄露事故，令人感到新奇。

其中包括近期最受关注的攻击，比如Evernote、LivingSocial、Facebook、LinkedIn、Yahoo 和 Twitter。Information is Beautiful 创办人David McCandless表示：视频游戏网站

从中看出两大趋势：首先大学和金融机构更加安全---或不再是引人的攻击目标。医疗保健机构似乎是最容易发生数据泄露的行业，约占50%的数据泄露比例。 游戏行业则是累计数据泄露数量最大的行业。

 最大规模的数据泄露---支付处理公司Heartland的1.3亿信用卡号码被盗事件在可视化图像中最大；折扣零售商TJ Maxx 泄露9.4千万客户数据，AOL则泄露1.12亿客户账号信息。包括索尼在线（PSN）、Facebook、Linkedin以及eHarmony的数据泄露规模也都名列前矛。

发人深省之处在于，似乎没有哪家企业能从数据泄露风险的魔爪下幸免。更重要的是，数据泄露事件的出现频率近年似乎有所增加。
