# 2013年十大新锐安全企业

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODI2MTg3Mw==&appmsgid=10000068&itemidx=3&sign=eb11f8d117ad473e637dd528caafef4f&scene=126&sessionid=1681309453#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5ODI2MTg3Mw==&appmsgid=10000068&itemidx=3&sign=eb11f8d117ad473e637dd528caafef4f&scene=126&sessionid=1681309453#wechat_redirect)

信息安全新兴企业正努力寻求新途径，旨在检测文件中的可疑活动、从而揪出恶意软件。有些企业希望通过新技术对设备到设备之间的通信内容进行加密，保护关键基础设施安全。移动保护方案则解决了文本信息的安全难题，使其在一段时间内自行销毁或是以安全VoIP通话为基础，最终令窃听者们空手而归。

与网络犯罪分子进行的斗争则更倾向于提高攻击活动成本，从而扼制恶意侵袭行为。新的防御机制以虚拟化技术为武器实现应用程序隔离。技术人员们还不断深入，将基于硬件的安全机制与操作系统进行更紧密的结合，提高整套系统运行流程的直观度。

**1.   ****Silent Circle**

总部位于华盛顿特区的Silent Circle公司专门为移动手机与视频会议服务开发通信加密软件。该公司在RSA 2013大会上位列十大安全企业之一。iOS与Android两大平台上均有其应用产品，Silent Phone为VoIP通话提供点对点加密机制、Silent Text则负责加密用户之间传输的文本信息。

该公司还为台式机与笔记本电脑提供电子邮件加密、语音及视频通话加密等服务，且支持Silent Phone用户与普通用户之间的通话加密功能。Silent Circle公司联合创始人Mike Janke曾是一位海豹突击队员及畅销书作家，另一位创始人Phil Zimmermann则是Pretty Good Privacy邮件加密软件的开发者。官方网站：https://silentcircle.com/

**2**. **GridCOM Technologies**

总部位于圣迭戈的GridCOM Technologies公司利用量子加密手段保护设备对设备间的通信内容安全，其目标在于建立一条安全的互联网与电网自动化设备间的连接通道。随着全球对关键性基础设施保护工作的日益重视，GridCOM等企业也逐渐受到高度关注。公司将激光发生装置产生的光子输入服务器，从而生成随机加密密钥，用于完成工业控制系统组件之间的加密与解密工作。官方网站：http://gridcomtechnologies.com/ 

**3.   ****Light Point Security**

总部位于巴尔的摩的LightPoint Security公司通过在服务器上创建虚拟机保护用户安全，终端用户可通过网络浏览器对整套机制加以操控。这套虚拟机系统能够阻止网站代码在本地计算机上的运行，从而阻断试图通过浏览器对系统进行感染的恶意攻击活动。该公司产品支持Mozilla火狐3.6及更新版本，并计划在未来支持歌 Chrome与微软IE。目前Light Point公司主要开发消费级产品，但已经有计划进军企业业务领域。官方网站：http://lightpointsecurity.com/

**4.   ****Remotium**

总部位于加利福尼亚州圣马特奥的Remotium公司研发出一套技术方案，号称能够让用户通过虚拟客户端访问工作数据，从而一举解决自带设备趋势所引发的安全难题。该公司利用虚拟化技术将移动应用运行于公共或私有云环境当中，并将处理结果数据传输至移动设备端。

电子邮件、日程表、联系人、浏览器、Salesforce、Box、Workday等功能都配备有实时运行状态仪表，根据该公司的说法，这样的机制能保证其数据免于丢失、受到入侵或者遭恶意软件侵害。总而言之，数据永远不会被保存在员工的个人设备当中。官方网站：http://www.remotium.com/

5\. **Security4SOA**

Security4SOA公司致力于保护面向服务的架构环境，并利用底层服务支持大型应用在中间层内的运行。

该公司已经在IBM的WebSphere MQHursley实验室中开发出第一款产品——MQSentry。MQSentry能够为PCI、HIPAA及其它规程提供合规性报告，并能与 WebSphere MQ协同工作。该公司称MQSentry能够识别并修复原先无法捕捉的安全漏洞。它支持状态回滚功能、进行实时活动监控并为SOA环境提供防火墙机制。官方网站：http://security4soa.com/ 

**6.Bromium**

总部位于加利福尼亚州库比蒂诺的Bromium公司于2012年9月推出了其第一款产品——vSentry，并旋即引发安全专业人士的广泛关注。该公司开发出一套基于硬件的强大容器技术，名为“微虚拟化”。这款基于Xen的管理程序能够将每个存在安全漏洞或者不受信的用户任务加以单独隔离，旨在消除攻击活动、检测高级持续性威胁。

该公司的领导团队由多位虚拟化技术专家组成。联合创始人兼CTO Simon Crosby曾创立了XenSource公司并担任CTO一职，后来这家公司被思杰所收购。该公司还拥有多位曾效力于VeriSing及McAfee的知名专家。

官方网站：http://www.bromium.com/ 

**7.Cylance**

总部位于加利福尼亚州尔湾市的Cylance公司将自身描述为一家技术及服务企业。该公司始建于2012年底，由McAfee前任CTO Stuart McClure一手创立。该公司最近宣布刚刚在融资中筹得1500万美元。

公司的服务项目包括渗透测试与事件响应。Cylance公司打造了一套可在后台运行的威胁检测系统，并利用数学方法检测攻击活动。所有威胁情报信息都能与其他用户进行实时共享。该公司表示目前还在开发另一套产品，旨在帮助企业用户进行威胁检测与数据收集。官方网站：http://www.cylance.com/ 

**8\. Secure Access Technologies**

Secure Access Technologies公司帮助企业用户对移动应用进行打包，从而在不涉及设备位置的前提下实现多重因素验证。该公司采用自适应认证技术，能够对设备的当前位置、邻近环境以及行为风险进行评估。它能在用户离开设备时自动登出应用集账户，并在用户返回时使他们直接处理未完成的工作。

公司总部位于加利福尼亚州门洛帕克，且已经与移动设备管理供应商Good Technology建立起合作关系。公司CEO Ben Ayed持有多项专利技术，SSL Taher Elgamal的发明人也是其顾问团成员。官方网站：http://www.secureaccesstechnologies.com/ 

**9.Lastline**

总部位于加利福尼亚州圣巴巴拉的Lastline公司是一家与渠道经销商合作良好的安全企业，专注于以行为为基础提供保护方案。公司CEO Jens Andreassen曾任Fortinet销售主管，丰富的经验使他迅速为这家新兴企业建立起国际化销售体系。公司的Previct设备产品线能够在虚拟化沙箱环境下进行威胁分析与取证，并对每一条执行指令进行检测以捕捉针对性攻击活动。

该公司的创始人分别为大学研究人员Engin Kirda、CHristophere Kruegel以及Giovanni Vigna，已经拥有数万家企业、政府机构以及安全供应商客户群体的云基础恶意软件分析工具Anubis与Wepawet就是他们的杰作。该公司成立于 2011年，但今年六月才刚刚完成第二轮融资，筹得1000万美元资金。官方网站：http://www.lastline.com/ 

**10.****Shape Security**

总部位于加利福尼亚州山景城的Shape Security公司希望解决Web应用程序中的安全漏洞。该公司目前尚处于隐身模式，因此我们对其具体技术细节并不了解。Shape Security表示正计划推出一种新型网络安全技术。

今年一月，Shape Security公司宣布在第二轮融资中筹得2000万美元。该公司高管阵容包括谷歌前点击欺诈技术之王、思科前任应用程序交付部门副总裁以及沃尔玛前任首席信息安全官。
