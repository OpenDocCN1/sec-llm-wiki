Struts2发布高危安全漏洞补丁

7月17日，Apache Struts官方团队再发高危安全漏洞补丁升级(最新版本为：2.3.15.1)，升级修补了多个安全漏洞，其中包括一个远程任意代码的高危安全漏洞，这些漏洞可以影响到Struts 2.0.0 -- Struts 2.3.15的所有版本。

Apache Struts团队6月底发布了Struts 2.3.15版本，由于该版本被发现存在重要的安全漏洞，因此该团队今天发布了Struts 2.3.15.1安全更新版本。

攻击者可以利用该漏洞，执行恶意Java代码，最终导致网站数据被窃取、网页被篡改等严重后果。Struts2框架广泛应用在国内大型网站系统，目前很多网站还没有升级。目前针对该漏洞的攻击代码已出现。

该版本修复的主要安全漏洞如下：

l   使用缩写的导航参数前缀时的远程代码执行漏洞

l   使用缩写的重定向参数前缀时的开放式重定向漏洞

建议开发者将所有Struts 2应用程序升级至最新版本。如果你从其他分支迁移至2.3.x分支，需要注意，该分支最低要求Servlet API 2.4、JSP API 2.0和Java 5。

详细信息：Struts 2.3.15.1 GA

下载地址：http://struts.apache.org/download.cgi#struts23151。

关于Struts：Struts通过采用Java Servlet/JSP技术，实现了基于Java EE Web应用的Model-View-Controller（MVC）设计模式的应用框架，是MVC经典设计模式中的一个经典产品。目前Struts是应用最广泛的Web应用框架之一。
