# 点赞数字安全创新力量，ISC 2022数字安全创新能力百强开启评选

近日，ISC 2022数字安全创新能力百强（以下简称“创新百强”）正式拉开评选阶段序幕。期间，由安全行业专家、行业客户专家、安全分析专家，以及垂直媒体专家组建的评审“天团”将针对200余家参选企业、600余个安全创新产品及解决方案，进行全面、公平、专业的多维评审。同时，本届创新百强也将邀请更加广泛的创新厂商、技术从业者、安全爱好者共同加入评审，旨在真正挖掘引领行业创新发展的未来风向，绘就数字安全创新技术的百强图谱。

![](../Images/425ebc1dcfdfa9ae636f6845ef500ad5.png)

在今年的世界互联网大会乌镇峰会中，“加快构建网络空间命运共同体”被重点提出，这不仅体现了我国的大国担当，也为全球数字化指明了合作互利共赢的新通途。数字安全作为护航数字化发展的基座，同样也需要顺应时代大潮，让每一份力量都能参与其中。

  

因此，为了进一步扩围数字安全的普及度与影响力，本届创新百强在评审阶段，将会把600余个安全创新产品及解决方案在官网进行全面展示。**基于ISC庞大的流量池优势，本次展示的所有安全创新产品及解决方案都将得到千亿级的曝光机会。**

同时，本届创新百强也新增创新产品关注度实时热榜版块，鼓励参选厂商以拉票的形式，将自身的安全创新产品及解决方案进行分享。所有关注创新百强的安全厂商、各领域专家，以及广泛大众群体都可以对自己感兴趣的创新技术点赞，点赞、分享、观看都将会影响创新产品的实时热度**。****最终入围实时热榜的TOP 3创新产品，将获得本届创新百强新增奖项——最佳人气创新产品奖。**

这一裂变式的拉票分享模式，不仅将进一步提升创新产品的曝光度，也可能将对该创新产品感兴趣的创新势力聚集在一起，实现数字安全创新共识的扩张，深度助力构建起护航数字化发展的“数字安全命运共同体”。

  

此外，真实、客观、公正是创新百强自举办以来一直坚守的专业原则。除了大师级评审们的专业意见，不同领域群体的点赞代表着他们对于行业创新发展趋势的洞见与判断，也能够给予评审们充分的启发与思考。因此在多方力量的协同下，本届创新百强的评审结果将会更加精准。

  

![](../Images/1e8db7fd70cc95a73a098b7d17c92e45.png)

时代是数字安全的出卷人，而我们每一个人都是不可或缺的答卷人。不难看出，已经走过三年的创新百强，始终秉持着交流共创的初心。专业评委、安全厂商、权威媒体，抑或是大众群体，都可以在评审中充分发挥力量。每一次点赞，其实都是在重新书写数字安全创新突破的标准。
