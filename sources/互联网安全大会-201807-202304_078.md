# ISC组委会携手光明网即将发布2022数字安全发展趋势关键词

随着数字化转型的深入推进，数字经济已经成为推动全球新一轮科技革命和产业变革的重要引擎，开启了人类数字文明的崭新时代。作为护航数字化发展的“根基底座”，网络安全在政策扶持与市场聚焦的双重红利下，完成了向数字安全的演进。加速推进数字安全发展，已经成为当下各界的普遍共识。

在此背景下，互联网安全大会（简称“ISC”）以“护航数字文明，开创数字安全新时代”为主题，集结全球智慧，为数字安全的高质量发展共同献计献策。在本届大会即启之际，ISC互联网安全大会组委会将重磅携手光明网网络安全频道，特邀9位安全领域权威专家基于数字安全发展的十年变迁，发布数字安全发展趋势关键词，旨在为数字安全未来发展的预判分析给予有效引导。  

![](../Images/89eca1032ad4c093c5a9b95438276bf4.png)

回顾安全产业高速发展的黄金十年，数字安全的征途之上从不缺问题，但更不会缺乏迎难而上的探索者。如今，在顶层建设革新、新兴技术爆发、细分产业涌现的交织作用下，数字安全新一轮的进化与迭代已是呼之欲出。精彩不容错过，敬请期待！
