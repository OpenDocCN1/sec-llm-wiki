# ISC未来数字安全名人堂战绩亮眼，多家入驻创新企业传融资喜讯

随着新一代数字化技术的发展，网络安全产业面临着市场需求、创新能力和人才发展等方面的升级挑战，推动网络安全产业创新发展、扶持网络安全创新企业显得尤为重要。在此背景下，在今年的第九届ISC互联网安全大会中，未来数字安全名人堂应运而生。

  

![](../Images/f11e30e8fc9331f6c81ebd478a1f5f1d.png)

   

作为ISC打造的创新能力孵化平台，未来数字安全名人堂致力于为引领趋势的创新技术发声，挖掘并孵化网络安全的创新结晶。在过去的一年中，基于对旗下“ISC创新独角兽沙盒大赛”与“ISC网络安全创新能力百强”两大年度活动的运营，未来数字安全名人堂有效助力多家入驻创新企业频频取得融资捷报。

 

*   今年11月，北京星阑科技有限公司（以下简称：星阑科技）完成了由苹果资本领投、国君景泰跟投的过亿元人民币Pre-A+轮融资，原有股东晨山资本、海贝资本在本轮融资中持续加码。
    

 

*   今年九月，北京惠而特安全科技有限公司（以下简称：惠而特）成功召开了首轮融资发布会，宣布完成由用友幸福投资独家投资的数千万元首轮融资，并达成与用友股份在工业互联网建设领域的战略合作。
    

 

*   今年八月，深圳开源互联网安全技术有限公司（以下简称：开源网安）完成由深信服旗下专业投资机构琥珀资本领投的亿元级别B轮融资，老股东松禾资本持续跟投，义柏资本担任本轮财务顾问。
    

 

作为在今年成功入驻未来数字安全名人堂的创新后浪，星阑科技、惠而特与开源网安高速成长的背后，离不开未来数字安全名人堂的全面赋能。在今年的ISC互联网安全大会中，未来数字安全名人堂通过深度洞察网络安全初创企业的发展痛点，针对性地为成功入驻的创新势力们提供了投融资对接机会、流量扶持等专属权益，为初创企业们规划出了全生命周期的成长扶持路径。

 

首先，对于初创企业来说，通过加大全渠道的曝光，来快速争夺市场认同度尤为重要。未来数字安全名人堂拥有着ISC平台的天然基因，除了能够基于庞大的流量池优势，助力初创企业快速抢夺市场关注外，同时还能背靠ISC平台强劲的资源整合能力，提供全方位的营销支持，深度助力提升市场对初创企业的认可。

 

其次，多数网络安全初创企业面临着 “不平衡、不协调、不可持续”等重重困难，尤其是以融资难、融资贵为代表的现实问题，成为制约其成长的最大桎梏。因此，在今年的ISC互联网大会中，未来数字安全名人堂特别打造了百亿投融资洽谈会，集聚尚颀资本、国科嘉和、电信方舟、熙诚金睿、盛宇投资等31家行业重量级投融资机构，助力入驻企业获得百亿级的意向投融资扶持机会。

 

显然，未来数字安全名人堂对于网络安全创新势力的孵化布局已经卓见成效。而在今年目前已经开启的ISC 2021网络安全创新能力百强中，ISC平台继续考虑到突出参选厂商的发展需求，特设“创新能力十强”评选奖项。该奖项将依据厂商综合创新力、领域创新领跑能力等多个维度进行评估，累计遴选出十家各个领域中的突出厂商，优先纳入未来数字安全名人堂。伴随未来数字安全名人堂中新锐力量的持续扩围，网络安全行业也将挖掘出未来发展的无限可能。
