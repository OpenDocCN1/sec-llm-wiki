# ISC 2021云峰会主题分享｜掌握安全技术内核，助力业务安全数字化

数字化发展持续深入，如何安全数字化成各行业发展中的重要课题。与此同时，安全技术的重要性在数字化世界中越发凸显。掌握核心安全技术，成引领行业产业高质量发展的根本所在。 **8****月11日，ISC 2021云峰会十大主题分享之“安全技术分析”、“企业安全实践”两大主题分享重磅启幕。**其中，“安全技术分析”主题包含：零信任6A论坛、商用密码应用论坛；“企业安全实践”主题包含：CSA CISO Summit@ISC 2021、企业数字化转型与安全数字化(CSO高峰论坛)。 ![](../Images/2356392890e42c68472c39ef484e5ad5.png)  
**近两年零信任成网络安全圈火热理念之一，与之相应的零信任6A论坛也备受从业者关注。**论坛以“重构6A，再铸信任”为主题，邀请专家学者、行业智囊、企业机构代表等齐聚一堂，为零信任与6A进一步发展进行了交流与研讨。

  

![](../Images/6a0532a502e27ca709b797c59c70cb62.png)零信任6A论坛 **360****政企安全集团首席战略官潘柱廷作为本次论坛主持人讲道，“零信任不是具体的产品或技术，而是一种非常好的思想方法。用6A来标度零信任，用零信任来重构6A，我们将收获一系列看法、一系列理念、一系列解决办法，以及一系列工具、一系列平台、一系列项目工程。“**此外，各位嘉宾也分别从不同视角，分享了零信任的核心观念、应用举措以及解决方案，助力行业构建起零信任“理想国”的大生态，护航企业数字化转型与发展。 ![](../Images/475b6f44ccd23f2fc9dcb66f768ba7c0.png)360政企安全集团首席战略官潘柱廷 **密码作为保障网络和信息安全的核心技术和基础支撑，关系到国家安全、国计民生和社会公共利益。因此在本次“安全技术分析”主题中，商用密码应用论坛也颇具看点。**论坛上，一众专家学者、企业代表围绕“商用密码应用的融合与创新、应用与安全”主题，共研各领域最新标准，共话学术热点研究动态及发展趋势，共议中国商用密码发展之道。 嘉宾们带来的主题演讲，不仅包括：面向通用平台的强认证理论与技术分享，我国商用密码算法及应用，商业密码安全性评估标准等内容，还包括：从工程技术角度谈谈数字经济时代我们的密码技术遇到的需求，面向Web商用密码的发展趋势与应用，以及更为宏观的万物互联一切皆可发证的主题分享。

  

![](../Images/003e58f0a25ace436d1a586550e5c77c.png)商用密码应用论坛 当前，安全成数字化发展根基，首席信息安全官(CISO/CSO)在企业战略发展中，更具有决策意义。在今天的“企业安全实践”主题分享中，CSA CISO Summit@ISC 2021与“数字化转型与安全数字化（CSO高峰论坛）”同样可圈可点。 **其中，CSA CISOSummit@ISC 2021由云安全联盟大中华区主办、ISC互联网安全大会承办。**这也是继CSA CISO Summit在RSAC 2021“大放异彩”后，首次落地中国。**论坛上，****云安全联盟大中华区主席李雨航致欢迎辞表示，“很高兴能把国际上的高峰论坛本地化，并在中国线下举行，此举意义重大。”**同时，他也表示，伴随向数字时代的迈进，安全挑战也非常多，未来云安全联盟在以云计算、云安全为基础研究外，也会对所有的数字新兴技术的安全做深入研究。

  

![](../Images/d33e7d610b99aef439ac99f5dc64fd41.png)云安全联盟大中华区主席李雨航 **数字化转型与安全数字化（CSO高峰论坛）由安在新媒体和ISC互联网安全大会联合主办，****安在新媒体创始人张耀疆作为论坛的联合出品人和主持人也发表了时代观点，他认为CSO代表一家企业的安全高度、方向和主心骨，其作用对企业未来发展至关重要。**所以，联合举办此次论坛也是为了强调一种视角，即从甲方视角来看数字化时代安全数字化工作如何开展。现场，各领域技术专家以及企业信息安全决策者与实践者，也纷纷就企业业务如何安全数字化进行了分享与探讨。  
![](../Images/db5a5b7df0cfbd58fdb90f0be31790fb.png)安在新媒体创始人张耀疆 未来，数字化技术的广泛应用势必会将网络安全的战场无限延伸，安全将是企业数字化转型发展的关键所在，核心技术将成为关系安全与否的关键。所以，掌握创新的安全防护理念和技术，将安全基因植入到不同场景业务系统，增强多级防护和联防联动能力，形成围绕全业务流程全生命周期的风险控制机制，对企业乃至整个行业产业的数字化转型与发展至关重要。 ISC 2021云峰会主题分享持续进行中，它将全面覆盖战略、技术、场景等多个维度和领域的数百议题。**明日，ISC 2021云峰会将继续上线安全技术实践、安全服务与运营两大主题分享，精彩不容错过。**
