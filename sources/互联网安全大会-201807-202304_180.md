# ISC 2021信创安全两大峰会震撼来袭，共谋信创安全发展之路

****2021****年是“十四五”开局之年，作为“十四五”发展目标的重要抓手，信创产业以信息技术产业为根基，通过科技创新，构建国内信息技术产业生态体系。通过信创产业发展推动数字化转型，不仅关乎经济内生动力的培育，更关系到未来我国经济的稳定发展和国际竞争力的持续增强。****

****在7月27日-29日召开的第九届互联网安全大会（ISC 2021）上，将同期举办以****聚力安全·共筑发展为主题的信创安全创新发展峰会和以创新前沿技术·应用牵引未来为主题的信创安全技术与应用峰会****，峰会由国家工业信息安全发展研究中心、中国电子商会自主创新与安全技术委员会和信创安全技术委员会主办，ISC互联网安全大会承办，经开区国家信创园协办，并由《商业伙伴》支持。工信部等政府领导、知名院士专家、信创与网络安全企业精英、信创用户代表等将出席此次峰会，围绕信创安全面临的挑战与应对、基础软硬件安全、应用创新和生态协作等话题，共同探讨信创安全技术与应用的创新发展之路，为我国信创安全保障与产业发展建言献策，凝聚更多产业共识，推动信创产业高质量发展。****

  

![](../Images/02f277ca487fed6ba3ac3337f8055bec.png)

  

**面对科技产业发展百年未有之大变局，信创产业作为科技创新的重要领域，是构建我国安全可控信息技术体系的主要抓手，更是新一轮科技革命和产业变革的关键力量。在此背景下，大力推进信创产业发展，做好信创安全保障是促进信创产业高质量发展，实现我国信创战略目标的重要前提和基础。**

  

**在ISC 2021信创安全创新发展峰会上，中国工程院院士邬贺铨将发表信创主旨演讲,中国电子商会自主创新与安全技术委员会理事长冯燕春将就《信创安全体系建设》进行演讲，国家工业信息安全发展研究中心副主任董大健将带来《软件安全开发体系建设思路与指南》，龙芯中科技术股份有限公司副总裁张戈将发表《龙芯新一代处理器产品，生态及****应用》主题演讲，信创安全技术委员会主任、360集团副总裁兼首席安全官杜跃进将重点讲解《信创安全挑战与应对》。届时，“通明湖杯”2021首届信创关键产品挑战赛启动仪式也会在本次峰会同期举行。**

  

**在ISC 2021信创安全技术与应用峰会上，工业和信息化部电子第五研究所信息安全中心主任、信创安全技术委员会委员、高级工程师程德斌将带来《知止后定，合规行远**·******信创应用系统网络安全实践经验分享》主题分享，统信软件副总经理、统信适配中心总经理张木梁将重点讲解《链动未来：信创安全生态的“共谋与共赢”》，360政企集团浏览器事业部负责人黄亚洲带来《“盒子”外的故事》，华为云首席安全生态官万涛将发表《构建基于云原生的“协同创新融合共赢”信创安全新生态》主题演讲，中国移动研究院主任研究员黄静发表《基于云边协同的自主可控安全防护系统》，中孚信息总裁助理、解决方案中心总经理唐炜则会分享《智启新安加“数”前行》，安华金和数据安全实验室主任朱强分享《信创数据库的漏洞及安全研究和思考》，360大数据智能集团云应用产品部技术总监李方翔阐述《信创环境下的安全协同与开放生态》。**

  

ISC互联网安全大会作为东半球网络安全领域规模大、辐射广、影响力深远的行业盛宴，自2013年至今已成功举办八届，共举办了15场国际峰会，超350场分论坛，60场特色活动。探讨前沿议题超2000个，吸引了来自中国、美国、以色列、韩国、德国等全球30多个国家的500余位网络安全战略决策者深度参与，共话全球网络安全生态。

**值得关注的是，包括信创安全创新发展峰会和信创安全技术与应用峰会在内，ISC 2021将携手行业机构、协会、实验室、研究中心、联盟等权威组织，打造九大联合峰会。致力于通过一场场高权威、高引领属性的峰会活动，为网络安全行业输出前瞻声音。**

**更多演讲嘉宾和演讲主题，请关注7月28日上午信创安全创新发展峰会：聚力安全·共筑发展，以及7月28日下午信创安全技术与应用峰会：创新前沿技术·应用牵引未来，ISC 2021第九届互联网安全大会购票活动正在火热进行中，点击【阅读原文】提前锁定席位，7月27-29日北京与您相约！**
