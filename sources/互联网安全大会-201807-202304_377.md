# 第七届互联网安全大会将举办首届“金墉奖”，奖项评选拉开序幕

网络战正硝烟四起，大安全时代已经来临。网络空间与物理空间的区隔日益模糊，网络安全的辐射范围急速外延。从信息监控、攻击者勒索、蠕虫病毒造成的工业破坏到国家网络战争，网络安全已涵盖国家、城市、基础设施乃至覆盖每一个个体，网络安全行业建设与升维刻不容缓。  

 

为探讨网络安全发展现状，激发行业创造力与投资潜力，推动网络安全行业的创新与发展，协同行业共建网络安全，第七届互联网安全大会（ISC 2019）将举办首届“金墉奖”颁奖典礼，为中国网络安全行业年度优秀企业颁发荣誉。

 

作为网络安全第一奖，“金墉奖”的“墉”字象征着安全的高墙，寓意携手行业力量共建“大安全”。“金墉奖”将评选出最受关注创新企业、最佳行业推动榜样、最佳安全行业杰出企业、最具影响力投资人等重磅奖项。届时，行业优质企业与顶尖人才将齐聚一堂，共同瞩目网络安全行业的新秀与领袖。

 

在奖项设置层面：“最受关注创新企业”将重点聚焦在产品、业务、模式层面有突出创新的安全企业；“最佳行业推动榜样”将在各行各业中选择具备前瞻大安全理念、行动力量，并带来一定推进效果的榜样企业；“最佳安全行业杰出企业”遴选出大安全生态中最有力量的建设者；“最具影响力投资人”关注在安全领域创新创业的优秀投资人。“金墉奖”致力从不同维度，推动大安全生态发展。

 

**目前，“金墉奖”已开启线上提名及投票通道，线上公开投票时间为：****8月1日 - 8月10日。点击「阅读原文」进入投票界面，即可为你认可的企业提名或投出珍贵的一票。ISC组委会将根据提名名单和投票情况，于8月19日第七届互联网安全大会公布最终评选结果。**

 

第七届互联网安全大会（ISC 2019）将于8月19-20日在北京雁栖湖国际会展中心召开。本届大会将以“应对网络战、共建大生态、同筑大安全”的全新主题，深度探讨网络安全现状及未来发展之路。ISC 2019历时2天，包含2场峰会，近20场行业、产业、技术论坛，将邀请来自中国网络安全行业的领军企业和新秀企业，美国、以色列、俄罗斯、新加坡等国家的网络安全专家，国内外知名院校、实验室的学术专家。同时，ISC 2019将举办中国的Sandbox（创新沙盒大赛），评选出Top级安全创业公司。
