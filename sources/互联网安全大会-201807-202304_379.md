# ISC 2019 分论坛前瞻：5G时代网络安全迎来新挑战

5G网络高速率、海量覆盖、极低时延等特性，让万物互联成为可能，也给网络信息与安全带来了全新的机遇和挑战。5G在构建万物互联场景的同时，面临着更多的黑客攻击、恶意代码等风险。近年来，委内瑞拉电网大规模断电、乌克兰氯气站受网络攻击等安全事件，都为相关行业敲响了警钟，把网络安全拉升至国家安全的维度。  

  

正是看到了5G时代的网络与信息安全已成为行业的关注焦点，全球网络安全领域的风向标——第七届互联网安全大会（ISC 2019）将围绕“5G时代下网络与信息安全的机遇与挑战”这一议题，重磅推出5G安全分论坛，邀请业界权威泰斗与知名安全企业共同剖析5G安全当前局势，探索行业发展趋势。

  

ISC 2019“5G安全分论坛”由中国信科承办，中国信科副总经理、专家委主任、无线移动通信国家重点实验室主任陈山枝担任论坛主席，并邀请到了诸多业内顶尖专家学者参会。

  

中国工程院院士沈昌祥将出席，沈昌祥院士在计算机信息系统、密码工程、信息安全体系结构、系统软件安全（安全操作系统、安全数据库等）、网络安全等方面的科研成就颇丰，其成果在信息处理和安全技术上有重大创造性，多项达到世界先进水平，使我国信息安全保密方面取得突破性进展；在网络安全和科技创新、咨询论证和学科专业建设、人才培养等方面，沈昌祥院士均做出过杰出贡献。在本届ISC大会5G安全分论坛上，沈昌祥院士将带来主题为《用可信计算3.0，筑牢网络安全防线》的精彩演讲，分享世界网络安全主流技术和该技术在构建网络强国方面的运用。

  

此外，中国信息通信科技集团有限公司副总经理、专家委主任、无线移动通信国家重点实验室主任陈山枝也将分享5G安全风险及应对的前沿思路；中国移动信息安全中心总经理张滨将带来5G网络安全思考与探索主题演讲；中国信息通信研究院安全所所长魏亮将解读5G安全标准与测试认证；360独角兽安全研究团队负责人黄琳将以“5G安全-让子弹再飞一会”为主题深度剖析5G时代的安全挑战与机遇。中国通服网络安全联盟首席技术官王小鹏将以“5G改变世界，安全守护未来”为主题，从5G应用安全治理体系建设的角度给出相应的建议和意见。

 ![](../Images/9e365de99246850f21f311197bf8a9e3.png)

  

第七届互联网安全大会（ISC 2019）将在北京雁栖湖国际会展中心举行。本届大会将以“应对网络战、共建大生态、同筑大安全”的全新主题，深度探讨网络安全现状及未来发展之路。大会将设置2场国际峰会，20场行业、产业、技术论坛。同时大会还将举办创新独角兽-沙盒大赛，由资深投资人、媒体人、创业家组成评委团，选出TOP级网络安全新物种，打造网络安全初创企业的展示平台和发展跑道。“5G安全分论坛”将于2019年8月20日上午召开，关注5G发展的行业人士不要错过。
