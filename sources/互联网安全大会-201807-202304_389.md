# ISC 2019征集祝福视频，入选人将获赠VIP门票

第七届互联网安全大会（ISC 2019）将于8月19日-20日在北京雁栖湖国际会展中心举行。ISC创立以来，累计接待观众超过18万人次，正是有了这么多专业人士和忠实观众的支持，ISC才能成长为亚太地区规格最高、规模最大、影响力最深远的安全峰会。

![](../Images/9895b4b713e986b3f355898b1f46d0fa.png)

ISC 2019就要来了，无论是参加过ISC的老朋友，还是希望前来参观的新朋友，我们相信大家一定对今年的ISC有很多期待。现在，我们面向全球征集祝福视频，诚挚邀请大家把最想对ISC说的话记录下来，发给ISC 2019组委会，我们将在ISC 2019开幕当天向所有到场观众播放您的祝福，其次，组委会还将选取20位发送祝福视频的朋友，赠送本次大会的VIP门票一张，赠票名单将在大会官方微信、官方微博公布。

**征集主题**

本次征集活动以“应对网络战、共建大生态、同筑大安全”为主题，以富有创意的视频形式祝福大会成功举行。

**征集对象**

关注ISC的所有朋友，包括但不限于安全企业，安全行业专家、机构和学术组织，往届ISC参观观众，合作伙伴等。

**拍摄要求**

横拍（16：9），时长不超过30秒，画面与声音清晰，不限制视频文件格式及大小。

**视频内容要求**

讲话时无配乐，内容需包含对此次大会成功举行的一句祝福话语，其余可自由发挥，如可提及对本次大会的期待，对网络安全的见解等。

示例：我是来自XXX公司（地区、平台等）的XXX，在这里预祝第七届互联网安全大会ISC 2019顺利召开，\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_。

**参与方式**

作品需以“ISC祝福视频+作者”文件名的形式保存（云盘或附件型式均可），邮件标题也要以相同形式撰写。视频需在2019年7月25日前发送至邮箱: topic-isc2019@360.cn

**征集时间**

截止于2019年7月25日
