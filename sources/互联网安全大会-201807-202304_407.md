# ISC 人物｜David Maman：人体“漏洞“或成网络攻击新目标

ISC 2018 --David Maman发表精彩演讲

9月6日，ISC 互联网安全大会技术峰会在北京国家会议中心召开，**Binah.AI公司创始人、董事长兼首席技术官David Maman**在演讲中提到，**源自漏洞发现与利用的网络攻击由虚拟逐渐转向现实，人体也存在可以被破解的“漏洞”**，他还为数千观众现场展示了如何利用视频精准地测算人体心率及相关数据，引起了一阵阵的惊呼。

![](../Images/fbe385a15281ec7ccdac21f732c3cc5c.png)

作为资深创业者，**David Maman **学的是计算机科学专业，18岁大学毕业后，连续创办了多家知名企业，还曾服务于以色列国防军（IDF）精英团队，被《TheMarker》杂志评为以色列Top 40互联网创业家。

  

与虚拟应用系统相比，人体所暴露出的“漏洞”很可能直接对人体造成威胁。譬如在电影《战狼》第一部中，犯罪团伙就是希望从中国人的基因样本中，寻找可能存在的漏洞。这些漏洞或是用于远程监控，或是用于暗网出售，但不论用途如何，都会为个人乃至国家带来严重威胁。

  

David Maman还在演讲中介绍了**Heart Rate Varlability（简称HRV）追踪功能。**利用人工智能算法，通过自拍视频，就可以获取人体信息，只需要采用信号处理，外加VR技术的加持，HRV追踪功能就能准确获取个人心率印记，得到的数据比苹果手表更为精确。

![](../Images/590d64616e4844fe91085be8d98944f8.png)

除了自拍场景，David Maman表示，目前该技术已经支持50多种不同的情景，包括运动、打架等动态场面识别。值得一提的是，面部识别技术在这其中起到了至关重要的作用，依靠人工智能进行远程关注，通过HRV信息便能对人体各项因素了如指掌，实现科幻片中的景象，例如引发癫痫疾病、导致皮肤敏感以及快速降低某人视力等攻击。

  

随后，通过对特朗普演讲的动态捕捉，David Maman再次证明**HRV技术是应用于人体“漏洞“防御的的黄金准则**。在智能摄像头全面普及的科技时代，漏洞无处不在，一旦被扫描到人体数据，就会造成个人隐私数据泄露。****“**未来，我们还将加强基于对人体攻击的深度研究，推动网络安全转向全新的服务领域。**”****David Maman如是说。
