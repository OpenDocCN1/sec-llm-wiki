# 2018 ISC互联网安全大会新闻发布会在京举行

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODI2MTg3Mw==&mid=2649793651&idx=1&sn=c31ffc5a5a8bb8772acc9832ad8869d8&chksm=bec9616d89bee87b0636decad416356029d0d9dd200ff43c4b7ca967fd2468f674a50b772462&scene=126&sessionid=1681309433#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODI2MTg3Mw==&mid=2649793651&idx=1&sn=c31ffc5a5a8bb8772acc9832ad8869d8&chksm=bec9616d89bee87b0636decad416356029d0d9dd200ff43c4b7ca967fd2468f674a50b772462&scene=126&sessionid=1681309433#rd)

  

8月23日上午，2018ISC互联网安全大会（原中国互联网安全大会）新闻发布会在京举行。ISC大会组委会有关领导、部分论坛主席以及数十家业内知名媒体出席了本次发布会。

  

![](../Images/efe975c241884f714f8c16cbb661d546.png)

  

ISC 2018是在中央网信办、工信部、公安部、国家密码管理局的指导下，由中国互联网协会、中国网络空间安全协会、中国密码学会、中国友谊促进会、360互联网安全中心共同主办的世界级网络安全会议，本次会议将于9月4日-6日在北京国家会议中心举行。自2013年首次举办至今已成功举办五届，ISC已经成为亚太地区规格最高、规模最大、影响力最为深远的安全盛会。

  

ISC大会联席主席、360企业安全集团董事长齐向东表示，历经五年发展，ISC互联网安全大会已经成为网络安全行业风向标，“数据驱动安全”、“协同联动，共建安全+命运共同体”、“万物皆变，人是安全的尺度”等大会历年主题无一例外成为当年行业共识，引发全球网络安全产业共鸣。

  

ISC2018的主题是“安全从0开始”，齐向东对这个主题的内涵做了阐释：“0是二进制的一个基本符号，也意味着零信任架构。我们必须从0开始做到安全与项目的规划、建设、运营三同步，这是保障网络安全的基本前提。”

  

![](../Images/8cb76cef658dce031569831975db27fd.png)

  

ISC大会执行主席、360集团技术总裁、首席安全官谭晓生表示，六年来，ISC致力于为所有参会嘉宾提供最优质的内容，从演讲嘉宾、演讲内容、展览展示等方面进行严格筛选。同时，谭晓生希望，未来ISC能够引入更多新的思想和新的理念，成为全球最具代表性的网络安全盛会之一。

  

![](../Images/9c31eef05fd88cac463225c816b681d3.png)

  

ISC大会顾问委员会主任、观潮网络空间论坛主席、国家创新与发展战略研究会副会长郝叶力在致辞中表示，历经五年的发展，ISC开创了亚太之先河，已经成为网络安全产业的风向标。观潮网络空间安全论坛自2016年以来，汇集了来自政府、军队、企业等社会各界的网络安全专家，观网络大潮，顺时代大势，针对焦点问题展开高端对话，打造全球网络空间的“上帝之眼”，对中美网络关系发展起到了非常大的推动作用。对此，中美俄欧等各国嘉宾都给予了高度评价。

  

ISC大会秘书长、360企业安全集团副总裁韩笑向大家介绍了大会的筹备情况。她表示，ISC2018在会议规模、展览展示、会议的国际性等多个方面将比往届全面提升。本届大会聚焦络空间安全战略与国际合作、网络安全产业发展与创新、网络安全技术趋势与方向，特别邀请到全球首个胶囊列车公司CEO了德克-艾尔邦、“MacAuthur天才奖”得主Dawn Song、圣地亚哥前CISO Gary Hayslip、以色列8200部队原开源情报分析主管等来自近20个国家的上百位安全专家；大会设置“战略日”、“产业日”、“技术日”三大主题日和战略峰会、产业峰会、技术峰会三大主题峰会；观潮网络空间论坛、中国网络安全产业发展与担当高峰论坛、中国网络安全产业人才培养体系建设论坛、电子取证技术与发展论坛、移动安全论坛等33个分论坛；蓝帽杯、网鼎杯、安全训练营、安全创客汇、DEFCON GROUP 010等特色活动。

  

![](../Images/2b1c3836d74b1ba506db3b1ae7543c8e.png)

  

一级警监、原公安部网络安全保卫局巡视员顾坚对ISC大会给予了高度评价。他表示，组委会邀请到了最顶尖、最专业的网络安全专家，大会从主题演讲到展览展示均已经达到了业内顶级的水平。

  

广州大学网络空间先进技术研究院院长田志宏、中国友谊促进会副秘书长彭邦富、《中国信息安全》副社长崔光耀、永信至诚高级副总裁潘柱廷、交通运输信息安全中心主任李璐瑶、苹果资本联合创始人胡洪涛、广东中科司法鉴定所所长丁丽萍、中国信息通信研究院泰尔终端实验室移动安全团队负责人杨正军、众享比特创始人兼CEO 严挺、360无线电安全研究院及黑客研究院负责人杨卿分别就分论坛的筹备工作与在座嘉宾做了深入的交流，并对ISC大会给予了高度的评价。

  

据不完全统计，ISC2018将会有超过4万名安全从业者参会，超过400个网络安全战略规划、产业方向、技术趋势、应用创新等相关议题和最新研究成果将会在会议现场发表。
