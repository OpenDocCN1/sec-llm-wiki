# 十大骗术早知道！打击犯罪力度大！

**全力打击**

根据统计，2017年1月到6月，全国电信网络诈骗案件发案数、人民群众财产损失数，同比分别下降12.3％和30.8％，可见打击电信诈骗的决心和成果。

8月12日，全国打击治理电信网络新型违法犯罪集中宣传月活动启动，公布了近期高发的十类电信网络新型违法犯罪手段，包括：**假冒公检法诈骗、冒充熟人诈骗、利用伪基站发送木马链接诈骗、兼职诈骗、考试诈骗、校园贷诈骗、民族资产解冻骗局、投资返利诈骗、保健品购物诈骗、引诱裸聊敲诈勒索**，之前的防诈骗内容中，我们对其中50%以上做过详细分析并提供了防骗贴士。 

本周，先为大家归纳总结top5的骗术，警钟长鸣。

![](../Images/11e0e7a6d51e63f7293d4f3afe924b85.png)

![](../Images/9f8097391131c7ace28ad2d7b8255e9c.png)**骗术一**假冒公检法诈骗

犯罪分子假冒“警官”“检察官”“法官”等角色,谎称受害人涉嫌洗钱、贩毒等严重犯罪,诱导受害人将资金转入实为骗子持有的所谓“安全账户”,此类诈骗造成损失金额最大。

![](../Images/9f7f8d8ddb8e837af2372ec62572bc04.png)

  

  

  

  

**防骗贴士**

警方不会通过电话做笔录,逮捕证由警方在逮捕现场出示,不会通过传真发放,更不会在网上查到。公检法机关从未设立所谓的“安全账户”,更不会通过电话安排当事人转账汇款到“安全账户”。

![](../Images/6b4a64e2c20cedfd3023a7ca3779722a.png)

  

  

![](../Images/34f29eb289347a6f3d4147d937dd3823.png "动物小伙伴拍手祝贺特殊用途动图")

![](../Images/9f8097391131c7ace28ad2d7b8255e9c.png)**骗术二**冒充熟人诈骗

犯罪分子通过非法渠道,获得受害人熟悉的亲友的手机号码、社交账号密码,掌握受害人的社会关系,从而骗取信任,进而编造“发生意外急需用钱”“资金周转”“代缴话费”等理由,诱使受害人转账。

![](../Images/9f7f8d8ddb8e837af2372ec62572bc04.png)

**防骗贴士**

凡是亲友间涉及借款、汇款等问题,一定要通过拨打对方常用号码或者视频聊天等方式,核实对方身份后再做决定。

  

![](../Images/6b4a64e2c20cedfd3023a7ca3779722a.png)

![](../Images/34f29eb289347a6f3d4147d937dd3823.png "动物小伙伴拍手祝贺特殊用途动图")

![](../Images/9f8097391131c7ace28ad2d7b8255e9c.png)骗术三利用伪基站实施诈骗

犯罪分子使用伪基站,冒用银行、运营商等客服电话号码发送短信给受害人,以账户积分兑换奖品等为由诱导受害人点击短信中的木马链接。用户一旦点击,犯罪分子就能在后台获取用户的银行账户信息和密码,进而盗取其账户资金。

![](../Images/9f7f8d8ddb8e837af2372ec62572bc04.png)

**防骗贴士**

当收到“银行卡密码升级”“积分兑换”“中奖”等含有链接的短信时,要通过银行、运营商的官方网站或客服电话进行核实,不要轻易点击短信中的链接。

![](../Images/6b4a64e2c20cedfd3023a7ca3779722a.png)

![](../Images/ebba7d51e9f1f21fa1df34ad761418b7.png)

![](../Images/9f8097391131c7ace28ad2d7b8255e9c.png)骗术四兼职诈骗

犯罪分子许诺在各种网络平台刷得消费记录后,将返还本金并支付佣金。受害人完成前几单任务后都会很快收到回报,而当做更多任务时,骗子就会切断与受害人的联系,就此消失。

![](../Images/9f7f8d8ddb8e837af2372ec62572bc04.png)

**防骗贴士**

求职者不要轻信网络上“高佣金”“先垫付”等兼职工作,不要轻信没有留固定电话和办公地址的招聘广告。

![](../Images/6b4a64e2c20cedfd3023a7ca3779722a.png)

![](../Images/34f29eb289347a6f3d4147d937dd3823.png "动物小伙伴拍手祝贺特殊用途动图")

![](../Images/9f8097391131c7ace28ad2d7b8255e9c.png)骗术五考试诈骗

犯罪分子通过非法手段获得考生信息,有针对性地发送短信或邮件,声称“提供考题”“改分”“办假证”等,引诱考生汇款。

![](../Images/9f7f8d8ddb8e837af2372ec62572bc04.png)

**防骗贴士**

漏题、改分、改档案、伪造资格证等行为本身就是非法的,请坚持用自己的实力说话。

![](../Images/6b4a64e2c20cedfd3023a7ca3779722a.png)
