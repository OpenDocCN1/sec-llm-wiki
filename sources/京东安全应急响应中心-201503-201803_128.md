# 有些支付，看清楚了再付！(附手机支付几大坏习惯)

　“你买东西我付钱。”某支付平台的的“亲密付”功能，让不少人又多了个秀恩爱的方式。只要在该平台内进行设置，将对方关联至自己的亲情账户，你就能通过“亲密付”功能为别人买单了。**“亲密付”便利了人们的付款方式，但也被一些骗子利用。**  

![](../Images/a77ae15568dc5c06bf6ede468364529b.png)

老王创业开了家电脑店，平时维修组装电脑并销售智能手机生意不错。前几天有位自称老客户的人打来电话，想请老王组装一台高性能的电脑。客户很着急称第二天要参加全国的电竞大赛需要一台高端配置电脑，预算有15000元左右。老王二话没说答应了，只是定金需要提前支付。对方说这个好说，希望老王现在就计算价钱然后全款打给老王。老王算好费用后对方却说只有支付宝绑定了银行卡但是今天转账金额用完了能不能下午送现金给老王，老王犯嘀咕毕竟是15000块的买卖没有定金不放心，于是对方提出了一个方案：**某支付平台有个亲密付功能，老王可以加他支付宝好友，然后开通亲密付，设置好15000元的额度就可以了。**老王想：这个之前他没有用过但是目前也只有这个最合适了。于是很快对方加了老王好友，并发来求开通亲密付功能。老王按照要求设置了额度为15000元，还想今天的客户真大方直接支付了全款。可是马上手机收到信息为对方付款15000元。

![](../Images/1216d490da0e4d0b449b18771d46f88c.png)

**亲密付到底是什么？**

按照某支付品台的说法，亲密付是一种为亲人、爱人等亲密关系打造的极简支付服务。为他们开通亲密付后，对方的消费、转账会直接从你支付宝账户扣款，而不需要你的再次确认。

**骗子利用很多人不懂支付宝亲密付功能这个弱点，先以预定价值商品（一般不超过2万，因为亲密付最高额度是2万）但转账额度有有限制为由，诱使受害者同意使用“亲密付”功能，再主动向受害者发出“求开通亲密付”功能的链接，如果受害者不注意看上面风险提示的小字，很容易上了骗子的圈套去设置额度。**其实你设置的并不是商品价钱，而是允许骗子扣款的最高限额。

![](../Images/32db91b6a393ddbdb448b77b99bde399.png)

小周是厦门某公司职员，平时热衷于网购。前端时间，他接到来电，对方自称是某网站客服，并表示小周曾在该网站购买的化妆水会过敏，现可办理退款退货，但必须通过支付宝的“亲密付”才能完成。

小周就将自己的支付宝账号报给“客服”，并应其要求，添加其为“亲密付”成员。但不到2分钟，小周就先后收到扣款1000元、3000元、5000元的短信。意识到有问题的小周立即质问还在保持通话的“客服”，“客服”扔下一句“5分钟后会退回来的”，便匆匆挂断了电话，此后再也联系不上了。

  

不法分子通过非正规渠道获取受害者网购记录及联系方式等信息，一种情况是以网购商品已收货的人员为目标，冒充客服与当事人联系，以商品有质量问题可退款等为由，引导当事人按照要求在手机端开通“亲密付”实施诈骗；另一种情况是谎称兼职刷信誉必须通过“亲密付”刷单支付，诱骗受害人开通该功能。只要受害人给对方开通“亲密付”并设置足够额度，当对方用“亲密付”买单时就无须得到当事人确认，直接通过当事人的支付宝账户或绑定的银行卡自动扣款。

**不要随意与网友或陌生人建立“亲密付”关系，设置支付密码且由自己保管，保障资金安全。**

![](../Images/32db91b6a393ddbdb448b77b99bde399.png)  

手机支付十大坏习惯

⊙**不设手机屏保密****码：**为了图省事不设手机密保。

⊙**跳过软件直接通过手机浏览器购物：**在浏览器中购物易出现钓鱼网站，加上支付过程的极度简化，更容易对财产造成威胁。

⊙**应用程序退出不彻底：**应用仍在后台运行，从后台管理处还能看见。

⊙**不加辨别蹭免费网络：**公共WIFI常被不法分子移植木马及钓鱼网站，不安全隐患多，且分分钟被盗取个人信息。

**⊙蓝牙保持开启状态：**智能手机可以通过蓝牙传播病毒，别人可以通过蓝牙蓝牙间谍软件也可以查看你的电话本、信息、文件，修改你的密码，替你拨号等。

⊙**淘汰手机时不彻底删除个人信息：**旧手机不处理就扔掉或者出售，里面的个人信息会被拿到你手机的人知晓。

⊙**随意点击短信链接：**一些不法分子想向手机发送欺诈短信，诱使用户安装木马或者登录钓鱼网站，从而获得用户账号密码，资金情况等信息。

⊙**见二维码就扫：**二维码中可能会隐藏病毒、木马s手机中的个人信息很轻易就被别人盗取。

⊙**下载山寨软件：**下载应用最好选择大型应用商店下载，出现木马病毒概率低。

⊙**存储敏感信息：**不设手机密保，这些信息别人都可以轻易获取。
