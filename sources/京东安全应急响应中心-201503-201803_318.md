# 2015年JSRC安全乌托邦-北京站活动圆满结束

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTk2MTMxOQ==&mid=203427744&idx=1&sn=566208fde5f6fcaddd5556ab5dfaa558&chksm=2ee7d8281990513efe952a026fd047c6cf2017e52d6f530898553736e1f09aa4eb063cc72674&scene=126&sessionid=1681380365#rd](http://mp.weixin.qq.com/s?__biz=MjM5OTk2MTMxOQ==&mid=203427744&idx=1&sn=566208fde5f6fcaddd5556ab5dfaa558&chksm=2ee7d8281990513efe952a026fd047c6cf2017e52d6f530898553736e1f09aa4eb063cc72674&scene=126&sessionid=1681380365#rd)

2015年3月20日由京东安全管理部发起的京东安全沙龙“2015安全乌托邦\-北京站”在北京市海淀区北京辰茂鸿翔酒店三层如期举行。  

2013年京东正式成立JSRC（京东安全应急响应中心），获得很多白帽子的支持与鼓励，同样今年京东JSRC的《2015安全乌托邦\-北京站》的活动我们依然得到了白帽子以及行业的支持。参与单位及代表们分别来自360、艺龙网、威客众测、金山软件、网易科技、安恒科技、新浪网、百度、去哪儿网、美团网、国家互联网应急中心、小米科技、租车网、安全宝、赶集网、搜狐网络、谷安天下、网信金融集团、联想集团、陌陌科技、中国科学院、江南天安、中国电信、完美时空、绿盟科技、汽车之家、阿里巴巴、中国电信研究院、安信华科等近30余家企业，参与人数80余人。

本次会议给所有的参会人员留下了以下几个印象：内容吸引人、充分尊重白帽子、豪车！

通过本次活动JSRC公众号人数新增了70余人；白帽子增加了20余人。

下午两点，会议正式开始，JSRC负责人李学庆发表了短暂开幕讲话之后并为大家带来了第一个议题《2015JSRC运营回顾》，议题分析了去年JSRC的运营情况，总结去年的问题和2015年的规划总结为挺高漏洞奖励价值、提供给白帽子更大的舞台，设立英雄榜，位白帽子带来更多更好的福利。

第二个议题由江南天安技术总监，攻防实验室负责人俞华晨带来《大数据下的安全隐患与攻击溯源》，讲到如何将大数据技术运用到安全领域。通过大数据技术分析数据了解业务风险、异常行为采集、智能学习、定位风险源头等。

![](../Images/af5f9d08df18271fec5ad847536b502d.png)  

最后压轴的是由登上央视315晚会的360无线安全专家样卿为大家带来议题《无线硬件攻防分享》，其中介绍了地铁、机场的wifi密码破解、无线射频安全等。
