01
安全工程师-应用安全研发方向（T5-T7）

【岗位职责】

1、负责白盒、灰盒、黑盒等安全产品优化与开发

2、技术协助业务方修复安全风险

3、前沿检测、加固技术预研


【岗位要求】

1 、计算机相关专业本科及以上学历

2 、丰富的Java应用开发经验，从事过大型互联网项目设计和开发

3 、对Web 应用漏洞有深入了解，理解原理及本质，且有较好的挖掘和防御思路及经验

4 、出色的问题解决能力，尤其是复杂场景的高可用、性能优化、故障分析方面

5 、有激情和责任心，积极主动，具有良好的团队协作和沟通能力

6 、具有数据分析、安全运营方面的工作经验者优先考虑


02
数据安全-资深研发工程师（T6-T8）

【岗位职责】

 1、负责京东应用安全和数据安全产品的设计，开发和维护工作；

 2、持续对线上系统进行性能优化及稳定性提升；

 3、负责攻克团队遇到的技术难题；

 4、拆解产品需求，提出技术实现方案和步骤。


【任职要求】

1、3年以上互联网开发领域的设计与开发经验，精通一种开发语言（Java，Go）及对应开发领域相关的技术与常用服务框架；

2、良好的开发基础，精通一种编程语言基础，熟练掌握多线程开发技术，熟练掌握常用开发工具和开源技术栈（如Spring框架）

3、熟悉常用数据库软件(MySQL)的原理和使用，熟悉常用ORM和连接池组件,对数据库的优化有一定的理解；

4、具备丰富的大型互联网系统设计经验，熟悉分布式、缓存、消息、负载均衡等机制和实现，具备海量数据研发和处理经验优先；

5、熟悉权限管理，统一认证（SSO），加密算法，数字水印等并且有相关研发和处理经验优先；

6、熟悉软件开发，测试流程；

7、良好的沟通能力，有责任心，有良好的团队合作合作精神。


03

java服务端开发工程师（T6以上）

【岗位描述】
1、负责办公网系统设计和开发工作；
2、技术预研工作，承担核心功能代码编写；

【岗位要求】
1、JAVA 技术知识扎实，熟悉 IO，多线程，异步处理和常用中间件产品，熟悉缓存，消息等机制；
2、对各种 Java 应用框架如 Spring、ibatis 等有深入了解和应用实践
3、熟悉分布式系统原理，熟悉 MySQL 或 Oracle 数据库的基础原理；
4、有大型分布式、高并发、高性能、高可用系统的设计开发经验； 
5、具备良好的系统分析能力，良好的抽象思维和逻辑思维能力，独立分析问题解决问题的能力； 
6、优秀的沟通推动能力，有创新精神，乐于接受挑战，能承受工作压力;

04
ROS系统安全专家/工程师（T5）

 【岗位职责】

1、负责机器人ROS系统安全方案设计与开发，针对不同场景设备提供定制化的云管端安全解决方案。

2、负责机器人、自动驾驶领域前沿安全技术研究，包括：硬件安全、系统安全、固件安全、通信安全、应用安全等。


【岗位要求】

1、5年以上工作经验，至少3年以上IoT物联网、或机器人自动驾驶、或传统安全领域经验；

2、熟悉常见SoC体系架构（x86/arm）、对Android/Linux/RTOS系统原理、安全机制有深入理解；

3、精通至少一种编程语言（如C/C++/Java/python等），有良好的编程习惯和风格；

4、熟悉TEE技术（ARM Trustzone、Intel SGX）并有实践经验者优先；

5、有机器人、ROS系统相关工作经验者优先；熟悉ROS架构、DDS协议者优先；


05
Mac开发工程师（T5）

【岗位描述】

1. 负责Mac平台的产品设计和新技术调研；

2. 协同IOS端完成通用架构设计和基础模块建设；

3. 对产品性能、稳定性方面进行持续性优先和改进；


【岗位要求】

1. 精通Swift和Objective-C语言，3年或以上相关的开发经验；

2. 精通Mac平台，熟练使用AppKit等框架；

3. 熟练使用C/C++，熟悉POSIX API的使用，了解Unix平台开发；

4. 熟练掌握网络编程，对TCP/IP,HTTPS等网络协议有着深入的理解；

5. 熟练掌握面向对象设计和编程，掌握常用设计模式；

6. 熟练掌握常用的算法和数据结构，灵活使用和实践设计模式；
