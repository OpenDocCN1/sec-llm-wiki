背景介绍

Java 序列化是指把 Java 对象转换为字节序列，便于保存在内存、文件、数据库中，而Java 反序列化是指把字节序列恢复为 Java 对象的过程。java的反序列化漏洞波及范围广，危害大，可以执行命令，甚至直接getshell。

课堂大纲

  2. Java序列化/反序列化过程是怎样的？

  3. 反序列化漏洞原理是怎样的？

  4. 黑白盒角度如何挖掘反序列化漏洞？

  5. 反序列化漏洞如何防御？
