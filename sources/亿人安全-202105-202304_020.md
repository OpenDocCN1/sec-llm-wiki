## 0x05 总结

注意：java的Runtime.getRuntime.exec和ProcessBuilder.start，都是直接启动传入参数对应的进程,如果只是命令执行的部分参数可控，想在java中通过;、|、&等实现命令注入是行不通的， 例如这样传入`id && whoami`命令是无法执行的  
存在问题的关键词：

```

Runtime.getRuntime().exec()、new ProcessBuilder().start()、cmd
```
