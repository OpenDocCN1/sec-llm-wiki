最近在我新的虚拟机上，安装了Burp 2021.12版本，顺便重新装一下一些插件，供我在挖掘SRC中可以更加方便，获取更多的信息。

  

**｜****解决光标错位｜**

  

一般我拿到Burp必做的一件事就是把光标错位调整好：

  

User options-Display-HTTP Message Display

  

黑体-24px

**｜****HAE｜**

  

Key师傅的插件着实猛，靠HAE的高亮之前挖到了一个任意文件读取，确实非常的好用。同时最近也是有师傅完善了他的高亮规则，让HAE更加强大。

  

https://github.com/gh0stkey/HaE

  

![](../Images/8fba6ddd8352b2bda1ba25f2ee5ae779.png)

  

此时才把插件导入进来，需要配置你的HAE正则。

  
公共规则：https://gh0st.cn/HaE/

  

![](../Images/48d06c27126e839b2a72b073c6a60e76.png)

此时的HAE就会变得非常强大了：

  

![](../Images/d9faa81f21c3e8b3180bfbd68cdfb1e4.png)

  

你可以自由编辑，扩充你的HAE规则。用法也非常简单，在HTTP History中查看：

  

![](../Images/ec336c46d702f3c78c8496c847c7bb55.png)

  

其实在Comment处就能看出来这个颜色对应的模块是什么。

  

例如我选择后面的一个LinkFinder，就可以看见究竟HAE正则匹配到了什么：

  

![](../Images/60165bd83c2e1142394b32969db25c49.png)

  

如果想要重新看响应包只需要在点击：`RAW`即可

  

![](../Images/902f7f4e4517e36581af2c89ef5dda27.png)

  

**｜****Domain Hunter Pro｜**

  

非常喜欢用的一款插件，他可以更好的帮助我做信息收集的工作。

  

https://github.com/bit4woo/domain\_hunter\_pro

  

第一次使用，你需要点击上方的DomainHunter 并选择New去创建一个属于你即将开始的项目的数据库。创建完成后就会在选项卡上出现Domain：xxx.db  
之后你只需要添加Root Domain（根域名）\[使用Add或者是上方的Import Domain\]，并开始点击你的目标网站。最后，你觉得你点的差不多了，就可以点击上方的search 就可以出来他找到的子域名。

  

![](../Images/0747936deacd288cff5d7a39f0d5b0d8.png)

**｜****HTTPHeadModifer｜**

  

该工具可以快速添加各种头部，实在是懒癌福利。

  

您可以在 右键-`Extensions-HTTP Modifer` 使用它，PS：特别喜欢用他这个add all-ip-Headers。
