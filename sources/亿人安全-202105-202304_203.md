# 写在前面

下文的所有漏洞都是需要有学校统一门户的账号和密码的情况下才能挖掘出来的，不过我也有挖到个别特殊的学校个例，可以直接未授权访问那些目录页面造成危害。挖掘的案例均已提交至漏洞平台并已经修复。

# 过程

首先登陆统一门户，登录账号密码，找到学工系统页面：![](../Images/f3ce4ef839fc0806cca9583efde0fec3.png)

![](../Images/cb139003aea10ebe3c35d90bab3296e9.png)

1.越权漏洞：访问以下的路径：`http://x.x.x.x/xgxt/xsxx_xsgl.do?method=showStudentsAjax&isAll=true`然后便可查看所有学生列表：![](../Images/07cd7a493f49a3ba31d3b3baa8d900b2.png)

`http://x.x.x.x/xgxt/general_szdw.do?method=szdwRybb&lx=fdy`然后便可查看所有辅导员列表：![](../Images/544f37da0c88232837127b4e00b603ef.png)

`http://x.x.x.x/xgxt/xsxx_xsgl.do?method=getXsjbxxMore&xh=某学号`然后便可以查看该学号的学生的敏感信息：![](../Images/e3101f44c5e72239955645aa9e71ac3d.png)

最后根据该漏洞可以编写个脚本，来批量获取系统内用户的敏感信息，效果如下：![](../Images/77212c7b2cb226657675bae1c5eff579.png)

2.任意密码重置漏洞：访问该路径：`http://x.x.x.x/xgxt/mmzhgl_mmzh.do?method=xgmm&yhm=想要修改的账号`![](../Images/0899d7c6779eef50d765ce6662015628.png)

然后可以将系统内置的超级管理员账号的密码重置，我重置为test0123：![](../Images/317e7d3bd2cd9b458c49ad8d716df5d3.png)

然后再退出到`http://x,x,x,x/xgxt/`的学工系统登录页面，重新登录：![](../Images/47725f8ad4dada5a7c9078ba8d63d96b.png)

登录成功：![](../Images/51e818a50a381e99b03f0f33c28361a8.png)

既然是超级管理员，那么便可查看到许多敏感信息了，这里就不截图和赘述了。
