# token 防爆破？

* * *

## token 基础  

*   token由服务器端下发
    
*   每次客户端发送请求都需携带服务器下发的 token（且每次都不一样）
    
*   服务器，收到请求后进行验证，效验成功，则返回请求数据，效验失败返回错误码
    

**注：**

**由于token值输出在了前端源码中，易被获取，因此也就失去了防暴力破解的意义。一般 Token 在防止CSRF上会有比较好的功效。**
