### 函数搜索

查找main函数，在函数窗口Ctrl+F，搜索main

![](../Images/cd7a62d5b2fbebf66fb9c905d4fd4dff.png)

### 字符串搜索

IDA 中有一个窗口叫做【字符串表】 该表收集了程序中所有字符串。

View => Open SubViews => Strings

![](../Images/00bb743d4e0751643eeea4db52950a4c.png)

![](../Images/024623150846bd1d849975f5ac68e27c.png)

#### 进入保存该字符串的数据区域

双击搜索到的字符串

【1】是内存地址

【2】是IDA 为该地址对应数据取的一个标识符（或者理解成变量名）

【3】则是该内存对应的数据。

![](../Images/7baa78ca333af9ce5313abdaa58a19ef.png)

#### 跳转到引用该字符串的代码

【右键】选择【 Jump to xref 】或 选中 aHiCtferInputYo 后直接按下快捷键【X】

![](../Images/01b681eca9e746a98739a01fbe71261f.png)

会显示汇编窗口，两种形式，

图标视图

![](../Images/0e022c847ef661cee72d10e30cbe1491.png)

文本视图

![](../Images/1e7c37cac27dfbf3218b51ce6e7a28aa.png)

#### 转换汇编代码为伪代码

转换伪代码方法: 在这段代码任意位置按下 Tab 键 或 F5 键

![](../Images/07fdc972711b7c477b99138a1ed0ca88.png)

  

## 代码修复

### 函数名修复

选中函数右键Rename Global item或者快捷键N

![](../Images/66891d4d349d4a29261130f80c448c79.png)

### 返回值

判断函数的返回值是否有意义。查找一下函数的所有交叉引用，确保这个函数每一处调用都用不到返回值

![](../Images/8d9cdb0a105dbbe43ba1257758a78fdc.png)

点击函数名，按下Y 键，将函数的返回值类型修改为void（也可以直接按下V键）

![](../Images/5e39929f207ef01e772f4b31311f5cea.png)

### 变量类型

根据上下文信息判断参数或者变量的类型, 在标识符上按下Y 键，输入对应的类型

![](../Images/ae74808256bd3a2e2952ac9bca9d3242.png)

### 数组实体

![](../Images/f9dc08313a80a51590aef0192585edad.png)

第一个元素地址处，右键，Array => Array element size 表示一个元素的大小，ArraySize 表示数组大小，根据上下文分析，dword\_404040的元素大小为4字节，

数组长度为 32Array element size 可以通过调节第一个元素的大小来调整。在第一个元素地址上按下d 键切换大小。

![](../Images/c32d4c8ee55d4230c2449b36a2cf3d46.png)

![](../Images/0aa2d4784d271a98af6e4f7e5f387cac.png)

修复后，元素数据以4字节整数解析，更加直观。

![](../Images/f4b1541c8e7f11bc22921e4b6915aa2c.png)
