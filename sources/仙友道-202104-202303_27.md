![](../Images/b359ae8bf2470f092def6cf1c8688d53.png)

客户端从 Web 服务器检索网页（仅包含 HTML 和 JavaScript）。因此，任何防御系统只会看到通过网络传递的 HTML 和 JavaScript 的组合。因此，这种技术使基于 MIME 类型的基于边界的恶意内容检测变得毫无用处（没有 .doc 传输！）。当网页在客户端的浏览器中呈现时，恶意文件使用 JavaScript 进行解码，放置在 Blob 中并随后下载。这些最后部分仅发生在受害者的网络浏览器中。
