命令注入是在调用系统命令的web应用程序中拼接系统命令或绕过黑名单的方式去执行恶意命令。在linux和windows下都可以使用的常见的拼接符号：|、||、&和&&。  
  
**实例**  

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
Command A & Command B# 执行A的命令也执行B的命令。Command A && Command B# 在A执行成功的情况下执行B，A执行失败就不会执行B，相当于逻辑中与。Command A | Command B# 将A执行的结果作为B的输入，因此无论A执行结果如何，都会执行B。Command A || Command B# 在A执行失败的情况下执行B，A执行成功则不会执行B，和逻辑或一样。Command A ; Command B# A和B都执行。
```
