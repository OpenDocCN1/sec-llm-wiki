# **0x01漏洞概述**

      在Windows域内通过域控制器下组策略设置所有计算机管理员密码，提高了密码策略的安全性，所有管理员密码都一样，因为Windows在处理本地帐户时非常有用，因为如果两台(或多台)计算机具有相同的本地帐户名称和密码，Windows将像验证本地帐户一样对帐户进行身份验证，这意味着通过在一个系统上获得管理员凭据的数据，攻击者就可以获得所有管理员密码获得所有管理员的权限，以至拿下整个域内环境。

**SYSVOL概述**

      SYSVOL是指存储域公共文件服务器副本的共享文件夹，它们在域中所有的域控制器之间复制，所有经过身份验证的用户都可以对其进行读取访问。Sysvol文件夹是安装AD时创建的，它用来存放GPO、Script等信息。同时，存放在Sysvol文件夹中的信息，会复制到域中所有DC上。SYSVOL包含登录脚本、组策略数据和其他域范围的数据，这些数据需要在有域控制器的任何地方使用(因为SYSVOL自动同步并在所有域控制器之间共享。

所有域组策略都存储在：\\\\<域>\\SYSVOL\\<域>\\策略\\

组策略首选项(GPP)最有用的特性之一是能够在多种场景中存储和使用凭据。这些包括:

二、组策略的利用

      创建新GPP时，在SYSVOL中使用相关的配置数据创建一个相关的xml文件，如果提供了密码，则使用AES-256位加密，除了在2012年之前的某个时候，微软在MSDN上发布了AES加密密钥(共享秘密)。可以用来解密密码。由于经过身份验证的用户(任何域用户或受信任域中的用户)都有对SYSVOL的读取访问权，域中的任何人都可以在SYSVOL共享中搜索包含“cPassword”(包含AES加密密码的值)的XML文件。

      通过访问此XML文件，攻击者可以使用AES私钥解密GPP密码。PowerSploit函数GET-GPPPassword对于利用组策略首选项最有用。这里的屏幕截图显示了一个类似的PowerShell函数，它从SYSVOL中找到的XML文件中加密GPP密码。

# **0x03漏洞修补**

       微软在2014年5月13日发布了一个补丁:“GPP中的MS14-025漏洞可能允许提升特权”(KB2962486)。需要在所有使用远程服务器管理工具(RSAT)管理组策略的系统上安装此补丁。此补丁防止管理员将密码数据放入组策略首选项中。
