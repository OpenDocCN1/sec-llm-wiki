2021 年 6 月的 Adobe 补丁


6 月份，Adobe 发布了 10 个补丁，解决了 Adobe Connect、Acrobat 和Reader、Photoshop 中的 39 个 CVE。Photoshop Elements、Experience Manager、Creative Cloud、RoboHelp、Premiere Elements、Animate 和 After Effects。这些错误中共有九个来自 ZDI 程序。突出的两个补丁是 Reader 和 After Effects 的修复。在Adobe Reader的情况下，如果攻击者可以说服用户使用受影响的 Reader 版本打开特制的 PDF 文件，则严重级 CVE 可能允许执行代码。对于通过我们的程序报告的释放后使用 (UAF) 错误，特定缺陷存在于 AcroForm 字段的处理中。该问题是由于在对对象执行操作之前未验证对象是否存在所致。更新为After Effects修复了大量严重到中等级别的错误。其中最糟糕的情况可能允许在登录用户级别执行代码。

 

Adobe 本月修复的错误在发布时均未列为公开已知或受到主动攻击。


2021 年 6 月的 Microsoft 补丁

 

6 月份，微软发布了针对 MicrosoftWindows、.NET Core 和 VisualStudio、Microsoft Office、MicrosoftEdge（基于 Chromium 和 EdgeHTML）、SharePoint Server、Hyper-V、Visual Studio Code - Kubernetes 工具、WindowsHTML 平台中的 50 个 CVE 的补丁和 Windows 远程桌面。这些错误中共有 8 个来自 ZDI 程序。在这 50 个错误中，5个被评为严重，45 个被评为重要。据微软称，其中六个漏洞目前正在受到积极攻击，而三个漏洞在发布时已为公众所知。

 

让我们仔细看看本月一些更有趣的更新，首先是一些列为主动攻击的错误：

 

-       CVE-2021-33742 - Windows MSHTML 平台远程代码执行漏洞

如果用户查看特制的 Web 内容，此漏洞可能允许攻击者在目标系统上执行代码。由于该漏洞存在于 Trident (MSHTML) 引擎本身，许多不同的应用程序都会受到影响——而不仅仅是 Internet Explorer。目前尚不清楚主动攻击的广泛程度，但考虑到该漏洞影响所有受支持的 Windows 版本，这应该是您的测试和部署列表的顶部。

 

-       CVE-2021-31199 / CVE-2021-31201 - Microsoft Enhanced CryptographicProvider Elevation of Privilege Vulnerability

这两个漏洞与上个月列为主动攻击的 Adobe Reader 漏洞 ( CVE-2021-28550 ) 有关。经常看到提权与代码执行错误相结合，这两个漏洞似乎是这些漏洞的提权部分。在主动攻击的不同部分之间看到补丁可用性之间的延迟有点不寻常，但很高兴看到这些漏洞现在正在关闭。

 

-       CVE-2021-31956 - Windows NTFS 特权提升漏洞

这是本月被列为主动攻击的另一个漏洞。这是由发现 CVE-2021-31955 的同一位研究人员报告的，这是一个信息泄露漏洞，也被列为受到主动攻击。有可能这些错误被结合使用，因为这是一种常见的技术 - 使用内存泄漏来获取提升权限所需的地址。这些错误本身很重要，如果结合起来可能会更糟。绝对优先考虑这些补丁的测试和部署。

 

-       CVE-2021-31962 - Kerberos AppContainer 安全功能绕过漏洞

此漏洞允许攻击者绕过 Kerberos 身份验证并可能对任意服务主体名称 ( SPN ) 进行身份验证。该漏洞获得了 6 月份最高的 CVSS，为 9.4。这可能允许攻击者潜在地绕过身份验证来访问通过 SPN 访问的任何服务。鉴于 SPN 身份验证对于 Kerberos 部署中的安全性至关重要，因此应给予此补丁最高优先级。

Defender 的更新将会很突出。Microsoft会定期更新恶意软件保护引擎，因此如果您的系统连接到 Internet，它应该已经收到更新。


本月有 7 个补丁修复了信息泄露漏洞，Windows内核漏洞被列为主动攻击。在大多数情况下，所有这些错误只会导致由未指定内存内容组成的泄漏。一个例外是SharePoint 中的信息泄漏，这可能导致暴露个人身份信息 (PII)。

 

该版本中有五个补丁修复了拒绝服务 (DoS) 错误。最显着的受影响组件是 Hyper-V 和 Windows Defender。同样，您应该已经收到了 Defender 更新。即使您禁用了 Defender，漏洞扫描器也可能会因为存在受影响的文件而将系统检测为易受攻击的系统。但是，微软表示禁用 Defender 的系统并不处于“脆弱状态”。Windows 远程桌面协议中修复的DoS 错误被列为公开已知的，但尚不清楚哪些公开信息可用。

 

本月的版本中修复了四个安全功能绕过，包括前面提到的 Kerberos 绕过。Windows DCOM 的更新需要特别注意。该补丁不会自动修复漏洞。相反，它为企业提供了启用加固以防止错误的能力。微软计划在 2021 年第四季度发布另一个版本，默认情况下启用保护，同时允许通过注册表禁用强化。在2021 年末或 2022 年初，禁用保护的功能将被移除。Microsoft似乎预计此修复程序可能会出现一些应用程序兼容性问题，因此请务必彻底测试此更新。

 

本月的发布包含三个补丁，以解决 SharePoint Server 中的欺骗错误。与往常一样，服务堆栈咨询 ( ADV990001 ) 已针对 Windows 10 和 Server 2019 版本进行了修订。本月没有发布新的咨询。
