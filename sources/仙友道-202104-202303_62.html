一、工具简介

        NPS是一款轻量级、功能强大的内网穿透代理服务器。支持tcp、udp流量转发，支持内网http代理、内网socks5代理，同时支持snappy压缩、站点保护、加密传输、多路复用、header修改等。支持web图形化管理，集成多用户模式。

二、安装

服务端安装步骤：(推荐使用docker安装)

1、下载docker镜像

docker pull ffdfgdfg/nps

2、从github上拉取conf文件信息(如果太慢可以从gitee上拉取)
https://gitee.com/mirrors/nps.git

修改nps.conf文件中的web_password，改为自己的密码。

3、启动

docker run -d --name nps --net=host -v <本机conf目录>:/confffdfgdfg/nps

如我本地是：

docker run -d --name nps --net=host -v/root/conf:/conf ffdfgdfg/nps

4、访问http://ip:8080/login/index输入自己修改的用户名和密码即可登录。

4、之后在本机下载linux/windows的客户端。

本机下载客户端，windows为例：https://github.com/ehang-io/nps/releases/download/v0.26.9/windows_amd64_client.tar.gz

客户端列表找到客户端命令。

一般使用：npc.exe-server=ip:port -vkey=xxxxx这里的ip是你服务器ip，端口是你nps.conf中#bridge设置的桥接端口，-vkey是你控制面板客户端生成的唯一认证密钥。

如 npc.exe-server=192.168.207.130:8024 -vkey=tivujsfrlz6hpw0d
