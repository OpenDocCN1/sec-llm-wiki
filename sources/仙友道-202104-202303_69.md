## 在Android应用中打开任意URL

  
![](../Images/b359ae8bf2470f092def6cf1c8688d53.png)

作者：@mem3hack  
来源：链接

1.  下载Jadx反编译器m并安装ADB
    
2.  打开AndroidManifest.xml  
    
3.  查找所有浏览器活动（必须包含<category andoid:name="android.intent.category.BROWSABLE"/>）
    
4.  adb shell am start -n app\_package\_name/component\_name -a android.intent.action.VIEW -d google.com对每个活动（或您的任何域）运行“ ”。同时在Burp中跟踪对google.com或您的域的任何请求。
    
5.  如果打开了网址，则意味着您发现了一个漏洞！现在，检查请求中是否包含任何身份验证令牌（如果是，则意味着您已经拥有一个帐户！）。没有？尝试不同的技术以获得任何PII。在最坏的情况下，如果您可以在应用程序中打开任意链接，您将获得XSS之类的奖励。
    

我们可以使用apktool代替jadx反编译器，该工具具有从APK解码AndroidManifest.xml文件的更好功能。

![](../Images/b359ae8bf2470f092def6cf1c8688d53.png)

*   
*   
*   
*   

```
target.com/admin –> HTTP 302 (重定向到登陆页面)target.com/admin%20/ -> HTTP 200 OKtarget.com/%20admin%20/ -> HTTP 200 OKtarget.com/admin%20/page -> HTTP 200 OK
```

作者能够使用此技巧来发现“身份验证和会话管理”损坏的问题，并访问目标Web应用程序中的管理面板。后端Web服务器是Apache HTTP服务器，但是它也可以在其他地方工作。

## 从任何域生成Pass字典

  
![](../Images/b359ae8bf2470f092def6cf1c8688d53.png)

  

作者：@hakluke

## 来源：链接

您是否需要为目标生成一个密码表？这很简单，只需提供目标域名即可：

*   
*   
*   
*   
*   

```
# Mac OSecho "bugcrowd.com" | subfinder -silent | hakrawler -plain -usewayback -scope yolo | sed $'s/[:./?=&#:]/\\\n/g' | anew
# Linuxecho "bugcrowd.com" | subfinder -silent | hakrawler -plain -usewayback -scope yolo | sed $'s/[./?=:&#]/\\\n/g' | anew
```

该命令将详细执行以下操作：

1.  查找目标域名的所有子域
    
2.  从公共来源收集已标识子域的所有URL（以及其他相关链接/ URL）
    
3.  将每个URL /链接分解成多个片段以生成关键字
    
4.  仅输出唯一关键字
    

![](../Images/24a8c5aeb847b5ba0e82f207d481a7ca.png)

Protip：有时您可能希望在sed命令中包含其他字符（例如，破折号，下划线等），以进一步分解URL并产生更好的关键字。  

这是您需要的所有技巧：

*   https://github.com/projectdiscovery/subfinder
    
*   https://github.com/hakluke/hakrawler
    
*   https://github.com/tomnomnom/anew

## 通过重置令牌（Burp）来接管账户

  
![](../Images/b359ae8bf2470f092def6cf1c8688d53.png)

  

作者：@hakluke

## 来源：链接

现在，这是在测试Web应用程序时非常实用的技巧：

1.  在浏览器1中设置Burp
    
2.  在浏览器1中进行密码重置请求
    
3.  在浏览器2中打开密码重置电子邮件（没有Burp）并复制令牌
    
4.  在打Burp历史记录（browser1）中搜索令牌。如果在那里，您将拥有一个不错的简易帐户接管服务！
    

详细说明：如果在browser1会话历史记录中找到令牌，则意味着有时在密码重置操作期间，令牌已发送到browser1。

因此，这意味着您实际上不需要阅读电子邮件即可重置密码！这意味着您可以请求重设任何帐户，并且由于令牌已公开给您，因此您可以重设密码而无需访问受害者的邮箱！
