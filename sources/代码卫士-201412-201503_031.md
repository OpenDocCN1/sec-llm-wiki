# 保险公司因客户支付卡信息泄露被罚17.5万英镑

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247486015&idx=6&sn=b4783da9f2dcb49f0bd64684ea267f40&chksm=ea973b55dde0b243a3c08a74d798fe17a37b27276d1a59a2ad3bd48028426a09109f07c9aa98&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247486015&idx=6&sn=b4783da9f2dcb49f0bd64684ea267f40&chksm=ea973b55dde0b243a3c08a74d798fe17a37b27276d1a59a2ad3bd48028426a09109f07c9aa98&scene=27#wechat_redirect)

提供假期保险业务的一家英国公司Staysure被信息委员会（ICO）罚款17.5万英镑，原因是它没有妥善保护好客户的支付卡信息。

  

骗子设法入侵Staysure.co.uk的计算机基础架构并且获得对超过10万张信用卡记录及客户医疗详情的访问权限。ICO表示，攻击发生之后，5000名客户的支付卡详情遭到欺诈性使用。

  

计算机基础架构中似乎还包括CVV码即支付卡背面的三位或四位数字，尽管这一做法完全违背支付卡行业（PCI）标准。

  

黑客对客户数据库拥有完全访问权限

ICO指出，公司没有审查并更新存储敏感信息设备安全性的程序，这导致可被利用的安全漏洞潜伏期长达5年。这起网络攻击发生在2013年14-28日期间，利用的是该网站的JBoss Application Server漏洞。

  

黑客能够在服务器上植入JspSpy工具，允许在网页界面上传、下载、实现并删除文件。同时还可用于为多个行动启动命令控制台。

  

公司再次未采用安全补丁

JBoss Application Server维护人员在2010年发布了漏洞修复，而另外一次更新本可在2013年修复漏洞，但Staysure.co.uk在这两种情况下均未采用补丁。

  

事件发生时，客户数据库包含大约300万客户的个人信息，包括姓名、出生日期、电子邮件地址、邮寄地址、电话号码、支付卡号、卡有效期、CVV、旅行日期及目的地、以及医疗筛查响应数据等。

  

然而，尽管获得大量个人详情，黑客似乎仅仅关注支付卡信息。
