# ZeroAcess点击诈骗僵尸故伎重演

六个月之后，逐渐减少的P2P僵尸网络又卷土重来，故伎重演。ZeroAcess僵尸网络也称Sirefet又开始行动了。幸运的是，这次它的规模比几年前要小。戴尔安全工程CTU研究人员发现了ZeroAcess又复活了，它实际上是两个对等网络僵尸——32位以及64位的Windows僵尸网络。这两个僵尸网络都会控制所有的主要引擎以及网络浏览器。从历史上看，它会劫持搜索结果、将用户引导至恶意站点或欺诈网站骗取广告点击量。

2013年12月，微软、欧洲国际刑警组织以及FBI曾联合抗击ZeroAcess。那时这个僵尸网络感染了全球近200万台计算机，给在线广告商带来高达每月270万美元的损失。
