# 收不到宝马广告就得保护好安卓手机：看看你中招没？

安卓处理WiFi直接实现的方法中存在一个漏洞，导致设备在连接至其他手机、摄像机、游戏机、电脑或打印机时被重启。

  

WiFi直接实现允许设备在不加入本地网络的情况下直接与通讯设备进行无线连接。

  

**安全公司坚称需要被修复**

这一漏洞（CVE-2014-0997）是由Core Security公司的CoreLabs团队发现的。该漏洞可允许攻击者向设备发送特别编制的802.11探测响应框架，并可能因发生在WiFi监控类上的未处理异常导致设备崩溃。该公司将漏洞报告给谷歌，后者将其严重程度列为低级，且并未提供修复日期。

  

该公司编写了一个PoC来演示研究成果的有效性。从该漏洞的技术细节来看，某些安卓设备可能会处于DOS状态如果它们接收到wpa\_supplicant有缺陷的事件，导致无线驱动及安卓平台框架的界面被获取。

  

**谷歌并不急着处理这个问题**

也许谷歌安卓团队一点也不着急是因为DOS情况持续的时间较短。Core Security公司指出，这个问题并没有在安卓5.0.1及以上版本检测到。其中受影响的设备包括运行移动操作系统4.4.4版本的Nexus 5及Nexus 4、运行安卓4.2.2版本的LG D806及三星SM-T310、以及操作系统为4.1.2的摩托罗拉 RAZR HD。

  

暂时规避这个漏洞的方法是限制使用WiFi Direct（WiFi直接网络连接），或者将其更新至不受影响的安卓版本。
