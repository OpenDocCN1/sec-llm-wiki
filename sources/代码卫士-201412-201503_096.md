# Axa公司提供网络攻击保险业务 寻求在英市场机会

担心受到网络攻击的人们有福了：不久就可以购买保险来清理由黑客造成的损失了。

  

Axa（安盛）是一家提供此类服务的法国公司，并且已经在法国开展业务，它计划在英国市场推广这一服务。Axa高级经理Nicolas Moreau表示，这一保单将会作为房屋保险的附加险出售，目的是为了清理被贴到网上的个人图片而不是隐藏合法公布的信息。Moreau表示，“如果你或孩子的名声遭到破坏，我们有人会帮助你处理这个问题。”他表示，这样做的目的并不是删除新闻而是被公开的个人信息，并用一名少女被男朋友拍照之后上传的例子加以说明。他指出他们的目的不是“为某个独裁者提升名誉”。但Moreau并未说明此类保险将于何时登录英国。

  

Axa雇佣黑客测试网站的在线安全，并向公司出售保险并承担这些公司因网络攻击而遭受的所有负债。
