# 微软：2015年的提前通知服务将只对付费用户开放

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247486043&idx=2&sn=91767f2b7e1c98df1bf693e96e40fadf&chksm=ea973b31dde0b227d9b3fffebf74904e2f52898905e28d6bdc5b87a1817892d9a2d05ca3a411&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247486043&idx=2&sn=91767f2b7e1c98df1bf693e96e40fadf&chksm=ea973b31dde0b227d9b3fffebf74904e2f52898905e28d6bdc5b87a1817892d9a2d05ca3a411&scene=27#wechat_redirect)

微软响应中心高级董事Chris Betz发表文章称，2015年的提前通知服务将不对普通公众开放，仅对付费用户开放。全文如下：

  

我们的提前通知服务（ANS）作为星期二更新服务的一部分，建立于十多年前，提前对每月微软产品及服务的安全更新发布广而告之。在过去的几年中，技术环境及客户需求已经发生了变化，因此我们对现有服务及发布渠道进行了评估。这种改善服务的动力促使我们推出MyBulletins，为客户提供定制报告服务，以Exploitability Index替代Deployment Priority矩阵服务，修改了Exploitability Index以应对更多的威胁情境，简化安全通告内容提高客户理解，并为通告定义创建一个更为集中的术语表。而今天所作出的改变正是基于此。

  

我们正在改变向客户发布ANS的方式。未来，我们将向付费客户以及当前参与我们安全项目的组织机构直接提供ANS，我们将不会通过博客或者网页的形式告知普通大众。

  

ANS一直在为大型组织进行优化。然而，我们收到的客户反馈显示，许多大客户因优化测试及部署方式的存在，使用ANS的方式不同于以往。虽然一些客户依然依赖于ANS，但大多数会等待星期二更新的发布，或者不采取任何行动，让更新自动发布。今天，越来越多的客户在寻求捷径，获得适合自己企业的安全信息。客户不再使用ANS来规划安全更新部署，二十更多依赖于微软更新及安全更新管理工具如Windows Server Update Service（Windows服务器更新服务）来组织并优先部署。客户会转向持续更新的云系统。

  

对于那些仍然希望接受ANS的付费客户，微软将继续通过他们的Technical Account Manager（技术客户经理）支持代表们进行提供。ANS将继续作为我们安全姓名的一部分如Microsoft Active Protections Program为当前组织机构提供。对于没有付费支持合同的客户，我们建议你们使用myBulletins，可根据环境运行的应用程序定制安全公告信息。

  

随着客户需求的改编，我们的安全服务也必须随之变化。我们依然会坚持致力于为保护客户而服务，并继续提供安全云体验服务。
