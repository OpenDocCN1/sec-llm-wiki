# 4Chan网站遭遇Lizard Stresser发动的DDoS攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247486048&idx=1&sn=688346619ba194502bb68cf391c0c4af&chksm=ea973b0adde0b21c757c13433fe6a78c3af1b5e3f43214214d66739701fb1081c194bf6c18b3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247486048&idx=1&sn=688346619ba194502bb68cf391c0c4af&chksm=ea973b0adde0b21c757c13433fe6a78c3af1b5e3f43214214d66739701fb1081c194bf6c18b3&scene=27#wechat_redirect)

Lizard Squad或是引发4Chan网站遭遇DDoS攻击的幕后黑手，这次攻击所使用的工具是Lizard Stresser。Lizard Stresser是一款无需具备黑客知识或DDoS攻击知识便可进行入侵操作的工具。这个工具也是致使PlayStation Network以及Xbox Live一周前被黑的工具。由于这一工具同时进行售卖，因此目前尚不得知使用这一工具的人员是谁。但也有报道称可能是网站正在进行维护而下线。愈5个小时之后网站恢复正常，但未有相关说明是否遭到了DDoS攻击。

  

另据报道称Lizard Squad同时发动针对网络安全内容博客KrebsOnSecurity的攻击。原因是KrebsOnSecurity发布了几篇关于Lizard Squad的文章并称其为“skids”即“script kiddies（脚本小子）”，意指黑客技术不高、只能依赖已准备好的脚本实施入侵。
