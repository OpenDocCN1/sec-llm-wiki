# 英国警方声称逮捕一名Lizard Squad成员

Daily Dot报道称英国警方逮捕了一名与Lizard Squad（“蜥蜴部队”）黑客组织有关联的22岁男子。Lizard Squad声称为在圣诞日入侵Xbox Live及PlayStation Network网络负责。

  

从Dot得到的搜查令来看，这名男子名叫Vinnie Omari，目前居住在英国。警方从Omari的家中搜到了电话、笔记本电脑以及一部Xbox。Dot报道称Omari向媒体公开了搜查令以及关于逮捕的信息，但这些尚未得到当地警方的证实。之前的报道猜测Omari是一个团伙，但据Dot报道，这次记录他被保释的警方文件中使用的是这个名字。

  

从这次逮捕中可看出调查人员对Lizard Squad黑客组织所施加的压力。在上周的一次访谈中，另外一名自称为Ryan的成员表示Lizard Squad将索尼员工的登录凭证交给了GoP（攻击索尼影视并要求撤播影片《刺杀金正恩》的团伙），使得GoP的攻击更加易于实施。Lizard Squad还曾在2014年8月份导致载有一名索尼高管的飞机折返机场。在那次访谈中，Ryan表示这件事做得有点过分。上周三，Lizard Maifa在Twitter上发文称Ryan已被芬兰警方逮捕。在一份声明中，Lizard Squad向《华盛顿邮报》证实称Omari被保释，而Ryan仍然待在芬兰监狱。

  

另据报道称GoP同时威胁称，将对其他媒体集团发动类似于索尼影视攻击的入侵行动。
