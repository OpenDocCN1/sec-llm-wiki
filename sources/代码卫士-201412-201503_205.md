# 索尼PlayStation Network及微软Xbox Live被黑

黑客似乎不过圣诞节。在微软Xbox Live于周三（美国时间）被迫下线几小时之后，索尼PlayStation Network不久也中招。这对于在线游戏玩家来说很不幸，因为他们可能正想着指着这两家公司过圣诞节。

周三早些时候，臭名昭著的黑客组织Lizard Squad（蜥蜴队）声称对这两起攻击事件负责，并表示对它们发动了DoS攻击，这意味着他们利用僵尸流量对索尼及微软的服务器发起冲击。Lizard Squad在推特上炫耀了这两起攻击，并且指出只要点赞数和转发数达到一定数目便会停止攻击。

截止到周四下午，几乎没有什么新事情发生。这是一个死循环：Lizard Squad声称对Xbox Live及PlayStation Network发动了DDoS攻击，并要求对推特信息进行转发及点赞，但这些网站受到的攻击根本不会停止。

索尼的“AskPlayStation”推特账号承认受到攻击，但并未说明是否受到DDOS攻击。索尼之后指出服务已恢复正常，但依然可看到客户投诉。Xbox依然处于离线状态。同时一个名为The Finest Squad的黑客组织在网上披露了几个Lizard Squad身份，同时指出Lizard正在利用DoS攻击大型的游戏网络。

Lizard Squad曾于上周表示将会在圣诞期间拿下PlayStation以及Xbox Live网络。
