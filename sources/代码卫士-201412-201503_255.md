# 谷歌面临来自荷兰的1500万欧元罚款

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247486060&idx=3&sn=602ba56b73b4151c2bedf8f9a64e769e&chksm=ea973b06dde0b2100ce728d6ba98e91e8b5d667820505b0a856f7af1fddd4aae2f1ce3c9689a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247486060&idx=3&sn=602ba56b73b4151c2bedf8f9a64e769e&chksm=ea973b06dde0b2100ce728d6ba98e91e8b5d667820505b0a856f7af1fddd4aae2f1ce3c9689a&scene=27#wechat_redirect)

荷兰信息保护机构给谷歌开出1500万欧元的罚单，理由是谷歌违反了荷兰的信息保护法案。谷歌曾在2012年公布了隐私政策，这一政策现在依然为谷歌带来不少麻烦事。谷歌曾面临来自法国及西班牙的罚款，尽管罚款额度大大低于荷兰开出的罚单。

荷兰信息保护机构指出，谷歌从其多款产品——例如搜索、Gmail以及YouTube——的用户中所收集整理的数据并没有得到用户的同意且收集整理过程并不透明。
