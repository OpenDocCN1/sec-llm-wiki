# 微软召回补丁星期二发布的Exchange安全补丁

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247486062&idx=5&sn=1b70cf6975da21e116eed3926e34bb80&chksm=ea973b04dde0b212eb1af4cb441984403452328dfc0d5e89253c0f876411920a8f6ac82768cf&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247486062&idx=5&sn=1b70cf6975da21e116eed3926e34bb80&chksm=ea973b04dde0b212eb1af4cb441984403452328dfc0d5e89253c0f876411920a8f6ac82768cf&scene=27#wechat_redirect)

 微软于12月11日（当地时间）宣布召回之前针对ExchangeServer 发布的一个安全补丁。据悉，这一补丁本来定于11月份发布，曾在11月份提前通知中发布但随后便杳无音信，但官方并未给出任何解释。

 此外，微软宣布召回Exchange的内容还包括Exchange Server 2010 SP3 Update Rollup 8（被列为重要漏洞并已修复一个特权权限升级漏洞）。此外，为Exchange Server 2007补丁包3、2013补丁包1及2013累计更新6依然可获取。微软在Echange Team博客中指出，所召回的更新已不支持下载，用户应该停止使用这个补丁并等待RU8新版本的发布。已经开始部署RU8的客户应当放弃这一安全更新。微软指出，更新中出现的问题影响Outlook连接Exchange的能力。
