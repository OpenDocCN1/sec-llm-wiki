# 索尼影视发动DOS攻击 试图阻止下载被盗文件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247486063&idx=1&sn=71262200268d26aac663d27a759390da&chksm=ea973b05dde0b213c696e41b19f28ad15855ef4b75f0c1bed2e1361c468f92b2539d38e49718&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247486063&idx=1&sn=71262200268d26aac663d27a759390da&chksm=ea973b05dde0b213c696e41b19f28ad15855ef4b75f0c1bed2e1361c468f92b2539d38e49718&scene=27#wechat_redirect)

索尼影视正在采取技术防范措施阻止人们下载公司最敏感信息。据知情人士透露，索尼目前正在利用位于亚洲的上千台电脑针对那些可获得公司被窃取机密信息的站点发动DOS攻击。据悉，索尼使用Amazon Web Services执行反向攻击。这一策略曾被媒体公司广泛用于打击网络电影及音乐盗版行为。
