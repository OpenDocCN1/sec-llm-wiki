# 使用伪造ID乘坐NASA猎户座宇宙飞船

NASA允许人们通过web应用注册猎户座宇宙飞船登机证，一名德国研究人员发现这个web应用中存在一个内容过滤漏洞，允许在姓与名这两个名字字段中输入任意代码。这个漏洞可能导致乘坐宇宙飞船到达另外一个星球的先后次序被更改，也可能被用于其他恶意目的。
