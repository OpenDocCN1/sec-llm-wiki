# 趋势科技发布最新安卓媒体漏洞分析报告

安卓的又一个漏洞细节被曝光，趋势科技围绕谷歌移动操作系统如何处理媒体文件发布了一份报告。

  

趋势科技安全研究员发出警告称攻击者可能利用安卓媒体服务器漏洞发动包括任意代码执行的攻击。这个安全漏洞(CVE-2015-3842)影响安卓版本2.3至5.1.1，因此成千上万的设备可能处于危险之中。

  

这个潜在的危险来自于设置有陷阱的app，不过到目前为止还没有人主动攻击漏洞。谷歌本月初修复了这个漏洞。

  

因为安卓系统的碎片特性以及缺乏有效的补丁传递机制, 除谷歌自己生产的Nexus设备外，漏洞系统添加补丁需要花费一定的时间。

  

趋势科技注意到最新的漏洞源于其他三个安卓媒体服务器部件中的主要漏洞。CVE-2015-3823漏洞使手机陷入无限次重启，ANDROID- 21296336使手机设备的声音系统失效，CVE-2015-3824 (Stagefright)可以通过多媒体信息安装恶意软件。

  

6月18日安全公司将这个漏洞以及相应的概念验证汇报给了安卓安全团队。谷歌公司将这个漏洞定级为高危漏洞，并于8月1日发布了修复。

趋势科技本周一发布了关于这个漏洞的综合性报告，对漏洞进行了完整的剖析。
