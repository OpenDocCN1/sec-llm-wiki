# ICS-CERT告警：SCADA系统中出现多个0day漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485902&idx=2&sn=593c3507c7466827655e1cc92a04bc07&chksm=ea9738a4dde0b1b2a5e256a6235a997a292346671c3849af0d8728fa9910cbaa69ee726fb923&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485902&idx=2&sn=593c3507c7466827655e1cc92a04bc07&chksm=ea9738a4dde0b1b2a5e256a6235a997a292346671c3849af0d8728fa9910cbaa69ee726fb923&scene=27#wechat_redirect)

美国工控系统应急响应小组（ICS-CERET）最近公布了六个安全公告告警组织机构SCADA系统中出现多个0day漏洞。Elastica安全研究人员Aditya K.Sood在2015 DEF CON安全大会上公布了影响SCADA系统人机界面的漏洞。

  

Sood发现了远程及本地文件入侵漏洞、不安全的验证机制、硬编码凭证、薄弱加密、薄弱密码哈希、跨站点请求伪造以及其他影响人机界面（HMI）模 块等缺陷。这些有缺陷的模块由多家公司共同开发而成，包括Moxa、Prisma、KACO、Rockwell Automation、Schneider Electric以及西门子。

  

ICS-CERT为影响Rockwell Automation 1766-L32BWAA以及1766-L32BXBA和1769-L18ER/A及LOGIX5318ER可编程序逻辑控制器（PLC）网络界面的缺陷 发布了两个不同的安全公告。第一个受到远程可利用远程文件包含缺陷的影响，第二个受到远程可利用跨站点脚本缺陷的影响。

  

ICS-CERT为包括硬编码密码在内的KACO HMI产品发布了一个安全公告。Sood发现访问Prisma网络产品所需的密码并没有得到妥善保护，而且存在跨站点请求伪造漏洞，允许远程未验证攻击者 更新易受攻击设备的配置。Sood还表示，Schneider Electric Modicon M340 PL Station P34 CPU模块也受到硬编码凭证以及本地/远程文件包含漏洞的影响。这些漏洞可被利用实施远程代码执行、目录便利以及拒绝服务攻击。Moxa ioLogik E2210以太网微型RTU控制器受到三个漏洞的影响。这三个漏洞可被利用并获取对HMI模块未经授权的访问权限。

  

在相关企业公布安全更新之前，Sood不会公开漏洞相关情况。

  

ICS-CERT迅速为这些漏洞发布了相关告警信息，受影响产品广泛用于多个行业，而且对这些系统的攻击会产生严重后果。

  

ICS-CERT同时提出了一系列建议以减少SCADA系统被攻击的可能性。例如它建议VPN用户要确保对控制系统远程联网的安全。
