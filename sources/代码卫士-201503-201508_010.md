# 以色列公司卡发明检测无人机的新型雷达

**以色列公司****ARTSYS 360****开发出了一种小型****3D****电子雷达器，能够在小范围内监控到无人机。**

在前段时间举行的黑帽大会上，研究人员展示了一款装备有入侵工具、可攻陷无线目标网络的无人机。随着人们对无人机的使用增长，恶意利用也在增多。恐 怖主义分子可利用无人机开展侦查活动或袭击重要基础设施。而如果在市区使用无人机和四轴飞行器（一种微型飞行器），后果会更严重。

  

以色列公司ARTSYS 360正在研发一种小型3D电子雷达，可监控小范围的任何无人设备。这种新型雷达重量轻、电量消耗少、而且能够在400米的范围内监控某个区域的空中交通。

  

ARTSYS 360表示这个雷达确保了盲区的覆盖：3D-360°而且确保了在高密度环境中的检测及追踪。iHLS报道称，“这个系统执行90度的3D垂直扫描及 360度的平行扫描。该公司声称系统提供了1.5度的平行及垂直准确度。这个新雷达每秒钟都会执行360度扫描。

  

公司称该雷达是保障国土安全的理想选择，可用于加强某个地区一定范围内的物理安全，例如监控边境线的无人机。

  

该公司网站指出其电网微型雷达系统有如下作用：

*   监控飞行环境以检测并追踪无人机
    
*   从转发器上查询识别无人机
    
*   在市区检测微型雷达的电网操作网络
    
*   FAA（联邦航空局）及其它执法部门访问云格以实施追踪、通信、敌友识别、及干扰行动。
