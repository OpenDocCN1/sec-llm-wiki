# 安全研究员教你如何通过短信入侵雪佛兰科尔维特

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485904&idx=5&sn=a1f8391616c67bc2dbd4eb68a97aec56&chksm=ea9738badde0b1ac01a5665fed5ee68eecb274348d4bd5d2dcb71a67c16ad3c9bfd3c9506e32&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485904&idx=5&sn=a1f8391616c67bc2dbd4eb68a97aec56&chksm=ea9738badde0b1ac01a5665fed5ee68eecb274348d4bd5d2dcb71a67c16ad3c9bfd3c9506e32&scene=27#wechat_redirect)

**四名来自美国加州大学的安全研究人员仅通过一条短信就使用移动****TCU****（远程信息处理控制单元，或称跟踪****/****保险电子狗）入侵了一辆雪佛兰科尔维特。**

研究人员在华盛顿举行的USENIX WOOT 2015会议上展示了许多企业如Metromile（汽车保险公司）及Uber所使用的跟踪电子狗如何被轻易逆向工程而且被一条短信所控制。这些设备通过 ODB-II端口与汽车联网，随后就获取了访问控制器局域网络（CAN bus）的权限，而多种车辆功能正是通过CAN bus进行交互。

虽然并非所有的TCU都有无线功能，但多数移动2G或3G调制解调器有此功能，以提供网络功能、将GPS地理位置信息回传给追踪服务器或在必要时发送并接收短信。

  

**Metromile****跟****Uber****在车辆上部署了易受攻击的****TCU**

安全研究人员测试的TCU跟Uber和Metromile的类型一样，他们发现利用TCU能够以两种模式访问雪佛兰科尔维特：一种是以本地设置方式即攻击者能够访问汽车及其TCU设备时，一种是远程设置方式即通过短信界面或互联网连接方式。

  

虽然两种设置方式均可攻陷TCU，但最后攻击者都会跟受害者保持距离，并通过短信控制由TCU暴露的汽车功能。安全研究人员找到从网络渠道获取 TCU详情的不同方式，包括IP地址以及与之相关的电话号码。知道了汽车的电话号码后，研究人员通过特别编制的短信设法连接到了CAN bus，且通过利用汽车固件中的漏洞控制了汽车的雨刮器以及汽车的刹车系统。

  

**理论上可获得整辆车的访问权限**

虽然只测试了以上提及的两种行为，但从理论上来讲，研究人员也能获得访问其它任何车辆的功能，包括方向盘的传动设置、车锁、车速限制、仪表盘数据等等。

  

由于TCU能够在车辆移动的过程中接收到短消息，这就会为司机及乘客的生命安全带来威胁。为了组织此类悲剧的发生，安全研究人员建议进行短信验证、提供更好的密钥及密码管理方式、禁用WAN管理等等。

  

安全研究人员将问题告知Metromile及Uber后，前者提出了具体解决方案即禁用所有设备上的短信功能。此前他们曾设法入侵了一辆特斯拉 Model S。由于此类事件发生频繁，W3C牵头一个工作小组就汽车行业使用的网络技术安全及隐私进行探讨研究。（原文含POC。）
