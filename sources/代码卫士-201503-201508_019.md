# Facebook API存在缺陷 14.4亿名用户身份可被盗

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485905&idx=2&sn=73a82034367bbc5bbb0bfc36200a6b6e&chksm=ea9738bbdde0b1adba6bb4d2cf5fd9f62b7c982c2e1c5488c8f56e537cb9e1f4bf81114d37bc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485905&idx=2&sn=73a82034367bbc5bbb0bfc36200a6b6e&chksm=ea9738bbdde0b1adba6bb4d2cf5fd9f62b7c982c2e1c5488c8f56e537cb9e1f4bf81114d37bc&scene=27#wechat_redirect)

Facebook API中出现了一个安全缺陷，允许黑客解密并扫描用户ID。近14.4亿用户的身份存在被盗风险。

  

发现该 缺陷的安全研究人员Reza Moaiandin指出，黑客可利用这个缺陷与Facebook的GraphQL通信并通过传递被哈希的ID获取尽可能多的详情。通过使用一个脚本，整个 国家（Moaiandin在美国、英国及加拿大进行了测试）可能的号码组合都可通过这些URL运行，而且如果有号码与Facebook账户相关，它就会披 露相关姓名及其它详细情况（图像等）。也就是说黑客能够获取访问用户个人信息的权限，查看用户姓名、地址、照片以及其它个人数据。

  

Moaiandin指出，最让人担心的问题是这个缺陷是无意间发现的。攻击者可能会窃取所有的用户信息并在黑市售卖。他表示在4月22日向Facebook报告了这个问题但工程师无法重现该错误。

  

随后Moaiandin提交了相关数据但至今仍未得到答复且该问题还未解决。

  

2个月过后，Moaiandin在7月28日试图联系Facebook再次说明该问题，但得到回应称该问题不属于安全漏洞，不过已采取监控及缓解措施。

  

Moaiandin认为Facebook的处理方式会让用户数据受到威胁。不过他指出修复这个问题并不难，Facebook只需在预加密数据前限制单一用户的请求数目、检测数据模式即可。
