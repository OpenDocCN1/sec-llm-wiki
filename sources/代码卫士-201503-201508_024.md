# 1/4全球网络带宽被盗版内容消耗

尽管美国唱片协会（RIAA）和美国电影协会（MPAA）等组织一直在努力打击盗版，但盗版依然猖獗。据2015应用程序安全状态报告显示，盗版较2014年增加了22%。

  

Arxan技术公司和iThreat网络组在他们最近的报告中总结道：据记载2012年至2014年约有160万盗版资产，2015年这个数字可达196万。

调查还揭露了一个种子文件怎样仅用33分钟就接触到了100,000多名用户。种子文件在发布的不同阶段快速传播，可从阴暗的场景网站，传播到 FTP顶级网站、私人种子网站、再到公共网站，最后是网络存储。调查显示目前移动盗版在线资源所产生的总流量占网络总带宽的23.76%，大约是所有网络 流量的1/4。

  

**2014****企业因盗版内容共损失****$8370亿**** / €7580****亿**

如果2014年用户为盗版内容付钱的话，公司将收益$8370亿 / €7580亿，惊人的是其中电脑和移动软件收益占到$6520亿 / €5900亿。

  

游戏和电影产业是继软件行业受影响最大的行业，分别损失$740亿/ €670亿 和 $730亿/ €660亿。接着是电视产业损失$180亿/ €160亿，音乐产业损失$120亿/ €110亿，最后是成人行业$60亿/ €5.40亿。

  

研究人员和Tru Optik公司在P2P网络上调查了盗版内容的交易值，并且发现与盗版相关的最严重破坏来自巴西用户。俄罗斯、印度、意大利、美国、波兰、土耳其、罗马尼亚、泰国和塞尔维亚紧随其后。

  

**安卓应用最受盗版软件欢迎**

2012年1月至2015年5月，大多数盗版软件都以安卓app的形式出现（41%），接着是软件密钥生成器（17%）、苹果软件（13%）、Windows软件（9%）、和iOS app(5%)。

  

据Arxan报道，安卓apps之所以占比例最大是因为97%安卓设备都缺乏适当的保护，因此盗版趁虚而入。另外，1/2的企业甚至没有为保障移动apps安全做预算，这使得了他们的软件不仅会成为盗版的目标，也会成为攻击者的目标。
