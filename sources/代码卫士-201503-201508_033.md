# 安卓远程支持工具app出现“证书门”漏洞并被利用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485907&idx=3&sn=44ea8d86122640114aa56c62c9b64909&chksm=ea9738b9dde0b1afdf7df48126582f6cbae650be3ebc6f819e376be81430d7f9b10d4c342060&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485907&idx=3&sn=44ea8d86122640114aa56c62c9b64909&chksm=ea9738b9dde0b1afdf7df48126582f6cbae650be3ebc6f819e376be81430d7f9b10d4c342060&scene=27#wechat_redirect)

远程支持工具从本质上来讲具有危险性。安全公司Check Point曾披露安卓移动远程支持工具（mRT）app中出现了“证书门”安全漏洞。任何感染了mRST许可下的恶意软件的设备都会被控制。如今，该公司称已经出现了“证书门”利用。

  

Check Point移动威胁防范技术负责人Avi Bashan表示，在上周公布“证书门”漏洞时还同时公布了一款名为“证书门扫描器（Certifi-gate Scanner）”的app，它可扫描用户设备以发现是否有app受影响，或者是否已存在针对该漏洞的利用。这款app已经识别出几个“证书门”利用案 例，目前公司正在收集利用的相关数据。

  

Bashan还指出，已将此事知悉谷歌以及所有受影响的厂商，而他们在着手推出相关补丁。然而，由于这个漏洞与证书的使用相关，而这些证书用于全球厂商及程序员所制作的app中，因此补丁修复过程更加复杂。

不过一个名为TeamViewer的公司声称已经推出相关补丁。其它公司表示正在修复。

  

谷歌并不认为应当对此漏洞负责。一名谷歌发言人表示，“我们感谢研究人员识别出并上报这个问题。不过他们所描述的问题属于原始设备制造商（OEM） 为安卓设备所做的定制化问题。Nexus设备并未受到影响，而且我们也未发现试图利用这个漏洞的案例。只有用户被诱骗安装潜在的恶意app才会受到影响， 而我们一直在通过VerfiyApps以及SafetyNet进行监控。我们强烈建议用户从受信任来源如Google Play安装app。”

  

谷歌的声明让装有远程支持软件的用户麻烦不断。因为实际生活中已经出现利用案例，因此“证书门”不能再被认为是危险但存在于理论上的问题。因为通过“证书门”攻击的智能手机或平板电脑已为攻击者敞开大门，因此应该尽快修复该问题。

  

首先可通过运行“证书门扫描器”的方式检验自己是否易受攻击。不过这款软件的作用并不是很大，它能做的只是告知设备是否易受攻击，而不能说明具体哪个app易受攻击。

  

从目前来看，似乎只有两种应对之策。一种是可订阅Check Point的移动威胁防范服务即app分析及静态代码分析。另外一种方法是更新app（TeamViewer案例），并卸载其它易受攻击的远程控制/技术 支持程序。在补丁发布之前建议用户删除所有可能易受攻击的程序。
