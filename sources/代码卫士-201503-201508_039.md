# 2015黑帽大会：黑客盯上了加油站

在2015世界黑帽大会BlackHat上，趋势科技前瞻性威胁研究团队（FTR）成员Kyle Wilhoit 和Stephen Hilt 展示了他们最新的研究成果——GasPot实验。实验的目的是了解联网油箱对黑客的诱惑力。实验模仿Guardian AST油箱监控系统建造虚假油箱，该系统在2015年年初曾遭受到一系列的神秘攻击。

  

**GasPot****：引诱油箱罪犯的蜜罐**

这些伪造的罐子被称为GasPot（油箱蜜罐），它们仅仅是一个被配置用来攻击真实油罐终端的服务器，不过其中包含了用来记录活动的Python脚 本。这些GasPot只在发送油箱数据，同时也在观察试图通过互联网终端发出的命令。GasPot实体被部署在不同的国家，比如美国、俄罗斯、德国、巴 西、英国、阿联酋和约旦。

  

黑客中了实验的圈套，不久就通过地下论坛和Pastebin贴出文本片段互相共享信息。据日志收集到的数据显示，最显著的活动是基本的GET指令，用来查询关于油箱的信息，自动扫描仪通常使用这个指令。

  

**油箱遭受DDOS攻击**

事实上，很多其他指令也进入油箱蜜罐中，有的能够列举出油箱基本细节，还有一些能够更改名字。一些油箱的名字已被修改。但最不可思议的是，位于华盛 顿的一个蜜罐遭受了2Gbps DDOS的攻击，已初步证明攻击源头来自于叙利亚电子军（SEA）。不过研究者称“在之前的攻击中从未见过SEA使用这种技术，很有可能是其他团队或个人 嫁祸于SEA”。

  

**美国加油站遭受攻击最多**

日志显示，攻击分别来自美国、加拿大、中国、伊朗、俄罗斯、罗马尼亚和叙利亚。不过由于多数攻击使用了安全VPN连接，攻击者的真实地址可能被隐藏，因此对此应当持保留态度。

  

遭受攻击最多的国家是美国（44%）、约旦（17%）、巴西、英国和阿联酋（11%）。

  

虽然控制加油站并没有黑进美国国防部邮箱那么严重，但攻击者如果能把抽油泵锁住，就可以以此勒索油箱所有者的钱财。

  

另外，未经保护的加油站也可以武器化，错误的数据会引发像2009年发生在波多黎各巴亚蒙炼油厂火灾的意外事件。
