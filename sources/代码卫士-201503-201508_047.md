# 台湾七友指纹门禁设备易被入侵

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485911&idx=6&sn=809c7ad6e47eb6268a58c09345de8190&chksm=ea9738bddde0b1ab93ce8025487c22d8ef5bb69a664254c6453208d5faf42b2f4732ff692faa&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485911&idx=6&sn=809c7ad6e47eb6268a58c09345de8190&chksm=ea9738bddde0b1ab93ce8025487c22d8ef5bb69a664254c6453208d5faf42b2f4732ff692faa&scene=27#wechat_redirect)

台湾七友科技股份有限公司制造的指纹接入控制器能通过一个内置的HTTP网络服务器进行管理配置。安全研究员Maxim Rupp指出问题在于这个网络服务器出现了一个漏洞，允许联网攻击者查看并修改设备的配置，而无需经过直接访问已知路径的验证（CVE- 2015-2871）。

  

CERT/CC在上周五发布的一份安全公告中表示，访问通信的路径、指纹及其它设置页面根据型号及所提供服务的不同而不同。火锅获取控制器的指纹设 置页面，攻击者能够修改设置如“安全级别”以及“敏感度”来更容易地打开由该设备保护的房门。攻击者还能够修改设备的网络设置并将其从目标组织机构网络中 断网。Rupp还发现一些易受攻击的生物识别设备可通过互联网访问，这样攻击者就可远程利用该缺陷。攻击者一旦获取访问控制器配置页面的权限就能够执行其 它方式，不过Rupp表示还未实施进一步的测试。

  

Rupp在BF-660C、BF-630及BF-630W控制器上验证了该漏洞的存在，但其它设备可能也受到了影响。另外，专家表示其它几家公司也在以不同的品牌销售同样的设备。

  

Rupp已将该问题以及另外一个不太严重的反射性跨站点脚本漏洞（CVE-2015-2870）报告给七友公司但尚未得到任何回应，且目前尚不清楚该缺陷是否已被修复，不过CERT/CC表示“目前尚未看到一个可靠解决方案”。

  

Rupp此前曾在控制系统中发现多个漏洞。如在今年年初他在XZERES风力涡轮机、以及霍尼韦尔Tuexdo Touch家庭自动化控制器中发现了安全漏洞。
