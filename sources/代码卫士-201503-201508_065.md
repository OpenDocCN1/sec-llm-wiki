# 德国监控解密网站遭调查

德国联邦检察官正在调查一家解密德国监控问题的国内网站Netzpolitik.org是否犯有叛国罪。

  

Netzpolitik.org曾在今年早些时候指出，将扩充解密德国对国内网络通信实施监控的报道。网站称收到了来自检察官宣布针对网站的两名记者及未具名来源开展调查的信函。

  

网站对德国实施监控的解密报道分别发表于今年二月份及四月份。网站在二月份的一篇文章中指出，德国的国内情报机构希望获得额外资金增强对网络监控计划的投入。四月份的追踪报道说明了该机构成立了一个特别小组，对社交网络站点实施监控。

  

此前有报道称网站的这两名记者被起诉犯有叛国罪，但实际上他们正在接受调查。

  

德国对叛国罪的刑罚是15年的铁窗生涯，不过法官也可做出更重的判决。
