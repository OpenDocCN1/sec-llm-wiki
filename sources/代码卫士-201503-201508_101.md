# 白帽黑客又一力作：16公里开外远程黑掉你的吉普车

两名著名汽车白帽黑客Charlie Miller跟Chris Valasek此前曾黑掉一辆丰田普锐斯跟福特翼虎，而现在他们又有新作：黑掉吉普·切诺基。

  

不过这次他们并没有直接插入位于仪表盘下方端口的汽车网络以控制车辆系统，而是找到了一种远程控制车辆的方式。两人已从美国国防高级研究计划局获得研究基金，并将在下周举行的2015黑帽大会上具体展示入侵吉普·切诺基的过程。

  

相关报道指出，Miller跟Valasek能够控制吉普车的刹车跟油门以及其它不太重要的部件如收音机、喇叭以及挡风玻璃雨刷，方法是通过一个蜂窝网络利用吉普车的娱乐系统即Uconnect，从而可在16公里之外远程控制车辆。

  

不过，这并非世界首个远程控制汽车的案例，曾在2011年就有人演示了针对未知品牌车辆的远程攻击。Miller跟Valasek表示他们已跟吉普车车厂即菲亚特克莱斯勒汽车共同推出相关补丁（消费者可从该车厂网站中下载补丁）。

  

而且，并非只有吉普车存在这个问题——随着汽车跟货车与蓝牙、无线网络及高科技通信及娱乐系统之间的连接越来越紧密，它们受到黑客攻击的可能性越来越大。在这次大会上，其他安全研究人员将展示如何处理特斯拉S型的六个漏洞问题，不过据悉其中一个漏洞已被修复。

  

时隔多年，汽车行业终于重视起网络威胁的重要性了。上周，汽车制造商联盟宣布成立汽车ISAC（信息共享及分析中心）并将于2015年下半年正式发布。ISAC将“即时共享网络威胁信息及潜在漏洞信息”。目前加入该联盟属于资源性质，不过美国议会对汽车网络安全的兴趣越来越大，一部分是由两人的研究引起的，同时也会促进汽车行业的立法。美国参议院议员Edward Markey计划引入针对所有汽车及火车的强制安全标准，美国议会也密切注意着航空行业的网络安全情况。

  

甚至是像微软及Apple这样的软件公司都会花费数年甚至是数十年的时间为自己的产品推出有效补丁。而现在物联网及工控系统（ICS/SCADA）的网络风险也在不断扩展，或许这次两名安全研究人员的成果会更多提高人们对网络安全的警惕。
