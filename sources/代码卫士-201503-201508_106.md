# 微软发布紧急补丁修复Hacking Team的第三个严重漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485923&idx=3&sn=cecfe0e7f2afa6f2281da0d1e8141537&chksm=ea973889dde0b19f88fb3800f421badcc80a8980b58c7df93a6526bee5f372df188dde2d9c86&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485923&idx=3&sn=cecfe0e7f2afa6f2281da0d1e8141537&chksm=ea973889dde0b19f88fb3800f421badcc80a8980b58c7df93a6526bee5f372df188dde2d9c86&scene=27#wechat_redirect)

微软为所有Windows版本发布了一个安全更新以修复远程代码执行漏洞。这个漏洞是安全专家从Hacking Team被泄文件中发现的，这是继Windows权限升级、IE 11远程代码执行漏洞之后的第三个漏洞。

  

第三个漏洞是一个严重的安全缺陷（MS15-078），出现在Windows Adobe Type Manager Library中，攻击者可利用它劫持计算机并用恶意软件感染等等。一旦受害者打开包含恶意嵌入式OpenType字体文件的文档、甚至是一个网页都会因该缺陷受到攻击。微软在昨天发布了紧急修复补丁，因为微软在内核模式中运行字体驱动程序，也就是说如果其中一个库被填入恶意数据，那么整个操作系统都可能被攻陷。微软在安全公告中这样解释称：

  

“攻击者如果成功利用这个漏洞，既可以完全控制受影响的系统。随后攻击者会安装程序；查看、更改或删除数据；或者以完全的用户权限创建新的账户。攻击者利用这个漏洞的方式有很多种，例如说服用户打开一个精心编制的文档或者说服用户访问不受信任且包含嵌入式OpenType字体的网页。这次更新通过更改Windows Adobe Type Manager Library处理OpenType字体的方式修复了这个漏洞。当安全公告发布时，微软有信息表明这个漏洞已被公开但尚未有证据表明该漏洞已被用来攻击消费者。我们的分析表明漏洞利用代码能够以一种能被攻击者持续利用的方式创建。”

  

订阅了微软机密提前通知服务的系统管理员已在上周末收到警告信息称界外补丁将于7月20日东部时间13:00发布。更新后需要重启。大多数用户都启用了自动更新功能，因此不必采取任何措施，但采用手动更新的用户也需要尽快安装本次更新。

  

本次补丁适用于Windows Vista、 Windows Server 2008、Windows 7、 Windows Server 2008 R2、Windows 8 和 Windows 8.1、Windows Server 2012 和Windows Server 2012 R2、Windows RT 和Windows RT 8.1、以及 Server Core。但更新并未涵盖Server 2003或Windows XP（跟微软有协议的除外）。
