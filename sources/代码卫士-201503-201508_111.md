# 朝鲜红星Linux操作系统追踪用户

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485924&idx=1&sn=ff3902a20b6f3885b7f5727f93a78e64&chksm=ea97388edde0b19868e8db38b276f278c925ea18065541633e0d9fef4bfe77a80f555868e919&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485924&idx=1&sn=ff3902a20b6f3885b7f5727f93a78e64&chksm=ea97388edde0b19868e8db38b276f278c925ea18065541633e0d9fef4bfe77a80f555868e919&scene=27#wechat_redirect)

ERNW安全分析员Florian Grunow指出，朝鲜的红星Linux操作系统通过使用独特的隐藏标签对内容进行标记，目的是追踪用户。

  

红星Linux操作系统开发于2002年，是朝鲜用于代替Windows XP的操作系统，其发布于2013年的版本界面类似于Mac。最新版本发布于2015年1月份。

  

Grunow指出，包括微软Word文档及JPEG图像的文件连接至但并不一定在红星系统中执行，这些文件会在包含一个数字的代码中引入一个标签，而这个数字基于硬件序列号码。

  

“分析操作系统时，首先引起我们注意的是他们搭建了自己的内核模块rtscan。有一个运行的二进制叫opprc，它似乎伪装成某种‘病毒扫描器’并且会跟opprc共享一些代码库。”Grunow指出，“查看二进制时首先映入眼帘的是gpsWatermarkingInformation。如果有人在朝鲜在红星操作系统上创建并使用媒体文件及文档会带来麻烦；别以为这些文件会保持秘密状态且无法被追踪。”

  

Grunow指出，红星操作系统不会对通过开源word进程套件OpenOffice创建的文件打上水印。gpsWatermarkingInformation功能会对操作系统上的文档、图像、甚至是音频打上水印。

  

本次研究是继一月份披露操作系统漏洞以来对红星操作系统的最新检查。自2010年发布以来，红星操作系统就一直搅动着安全行业。

  

基于KDE 3的操作系统有着与OS X类似的界面以及名为Naenara且经过修改的Firefox浏览器。这个浏览器允许用户详细了解朝鲜的“光明网（Kwangmyong）”内网。
