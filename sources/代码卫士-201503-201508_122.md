# VMware出现主机权限升级漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485926&idx=4&sn=1d81b5cb71277f89f13638411970c7e5&chksm=ea97388cdde0b19a8da0656168bd8b276f6ac581d68dcd467643454fc0a7e1cf40f723994d2a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485926&idx=4&sn=1d81b5cb71277f89f13638411970c7e5&chksm=ea97388cdde0b19a8da0656168bd8b276f6ac581d68dcd467643454fc0a7e1cf40f723994d2a&scene=27#wechat_redirect)

VMware Workstation、Player以及Horizon View Client的Windows版本没有对进程设置自主访问控制列表（DACL）。这可能会允许本地攻击者升级它们的权限并执行受影响进程安全上下文中的代码。

  

允许防火墙内部出现这种情况会带来相关安全问题，因此VMware升级了受影响产品以修复问题。升级后的版本为：Workstation 10.x及11.x、Player 7.x及6.x、以及Horizon View Client 5.x。

  

安全公告的代号为VMSA-2015-0005，“0005”表明这是VMware第五次的紧急修复。对于一家拥有良好产品组合的公司来说，这个结果并不糟糕，尽管五次中有三次是针对Workstation的事实可能会让人惊讶。对于VMware的Windows桌面管理程序用户来说，会拥有一个全新的“视野（horizon在英文中有‘视野’之意，此处为双关）”，或者至少足以证明对传统的重新定义。
