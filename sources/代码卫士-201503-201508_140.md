# 安全专家反对政府获得加密“后门”的要求

计算机安全专家周二表示，执法部门无法得到访问加密通信的特殊权限，因为这样会引来恶意攻击。

  

麻省理工学院发布一份研究报告，驳斥了英美国家关于此类权限是对抗犯罪及恐怖主义政策响应的说法。报告是由13名科学家完成的，他们认为这种访问权限“会为犯罪分子及恶意国家黑客敞开大门，让他们攻击执法部门想要保卫的人群。”报告发布于FBI局长James Comey要求就加密通信使用展开公开辩论一天后。Comey指出美国人可能没有意识到激进组织及犯罪分子是如何好利用加密技术的。Comey在博客中表示，伊斯兰国家激进分子正是通过加密技术来躲避检测。

  

安全科学家认为任何想要为执法部门搭建权限的努力都会异常复杂，并且会引发“严重后果”，例如阻碍创新并创造对新科技产品的敌意。随之而来的成本是巨大的，会对创新造成严重后果而且对经济增长的损失也难以预测。而且会给国家的软实力及道德权威带来巨大威胁。

  

安全科学家表示，要求获得特殊权限将会带来无数技术及法律问题，而谁将拥有这些权限并设置标准也不清楚。

  

英国政府正在考虑立法要求服务提供商包括总部位于美国的企业为英国立法部门提供访问权限。报告指出，如果英国开发者部署了一个供别国公民使用的消息应用，那是不是也应该给别国执法部门提供特殊权限？
