# 匿名者黑客黑掉电信运营商BSNL期刊网站并攻陷3000多万记录

匿名者黑客组织印度分支以“匿名行动印度”名号入侵了印度电信运营商期刊网站以抗议印度政府实施的监控行动。这次入侵是在印度总理纳伦德拉·莫迪发起数字化印度的运动时发生的。

  

黑客涂鸦了BSNL电信期刊，并留言网站的网络管理员称应该邀请他们修复漏洞并学习学习网络应用程序安全的基础知识。黑客指出，“你竟然把密码以明文形式存储。太丢人了！这就是你们所谓的#数字化印度？现在我们已经访问了所有的BSNL数据库。不过没动服务器上的数据。赶紧赶在中国黑客动手之前修复吧。这真是一座金矿啊。”

  

匿名者黑客组织印度分支要求印度通信和信息技术部部长Ravi Shankar Prasad “停止向发牌制度迈进，”黑客还在涂鸦页面上公布了一个要求清单。以下是涂鸦页面所写内容。

给印度政府的信息：

  

*   要求政府采取措施制止RS Prasad公开挑战印度公民隐私的行为。
    
*   要求政府采取措施惩罚TRAI的愚蠢行为，停止公布数百份邮件身份识别，帮助垃圾推送者助纣为虐且违反印度IT法律。
    
*   要求政府采取措施阻止Reliance公司通过Jio聊天app向中国发送未加密信息。
    
*   要求政府（RS Prasad）停止走向发牌制度。我们在密切注视着你的网络中立性。
    
*   要求政府停止所有的监控项目如CMS以及RS Prasad对手机通话的拦截。公开所有被窃听以及正在被监控通话记录的详细情况。
    
*   要求政府（DoT）解锁所有的站点并结束互联网审查行为。
    
*   要求政府采取措施，阻止NIC改变历史。维基百科并非倡导谎言及鼓动宣传的媒介。
    

“匿名者行动印度”表示，实际情况更为糟糕。黑客声称已经攻陷了BSNL数据库中的3000万份记录。黑客声称这些记录与“账单汇总、支付详情或账户详情有关。”

  

BSNL的安全人员是否已发现这次入侵活动还不得而知。
