# Level 3收购DDoS缓解企业黑莲花

全球通讯提供商Level 3 通信公司宣布将收购私有企业黑莲花。黑莲花是一家全球DDoS缓解服务提供商。Level 3在最近的一份报告中指出DDoS攻击的频率、规模及复杂度都在不断上升，因此需要大力投入DDoS市场。

  

黑莲花的加入将加强Level 3于今年年初推出的DDoS服务能力。Level 3 DDoS缓解服务增强了基于网络检测及缓解的解决能力，以及网络路由、速率限制以及IP过滤能力。黑莲花将为该组合提供基于代理的DDoS缓解服务，通过高级行为分析技术加强分析应用层攻击的能力。

  

Level 3在7月1日以全现金交易的方式收购了黑莲花的未发行股票。交易条款尚未透露。
