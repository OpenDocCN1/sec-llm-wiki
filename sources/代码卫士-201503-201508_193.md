# 美证券交易委员会调查内部黑客组织FIN4

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485939&idx=3&sn=0fd8f650c7745f7d119712a048f702a3&chksm=ea973899dde0b18f200fcadcad3e341a02fac76c79186f940eae39d00c2040dad46e9ac33bbf&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485939&idx=3&sn=0fd8f650c7745f7d119712a048f702a3&chksm=ea973899dde0b18f200fcadcad3e341a02fac76c79186f940eae39d00c2040dad46e9ac33bbf&scene=27#wechat_redirect)

美国证券交易委员会（SEC）正在调查一个入侵企业邮件账户窃取并购等信息予以售卖的黑客组织。

  

据相关人士表示，SEC至少让8家上市机构提供数据被泄露的详细情况。

  

这是SEC首次针对涉及内部交易的调查，反映了对美国企业及政府机构被黑事件的关注。知情人士表示，SEC的问询及美国特勤局针对网络犯罪及金融诈骗的调查是因火眼公司一份12月份报告中提出的FIN4黑客组织引发的。

  

报告指出，自2013年年中开始，FIN4已尝试入侵100多家企业的邮件账户，寻找关于并购以及其他市场活动的信息。入侵目标包括生物科技及其他医疗相关领域的60多家上市企业，如医疗设备、医院设施及药品等。

SEC拒绝置评。一名特勤局发言人表示不会对正在进行的调查予以评论。

  

FIN4策略

SEC要求企业提供网络入侵数据或尝试入侵的数据，以及FIN4组织诱骗员工放弃邮件密码即“鱼叉式网络钓鱼”信息。但调查范围以及涉及的上市企业不得而知。SEC是否只是调查FIN4组织还是还牵涉其他组织也未知。

  

火眼公司认为FIN4黑客来自美国或欧洲，原因是他们的英语水平无懈可击而且深刻理解资本市场及投资银行如何运作。黑客以医疗公司及药品公司作为攻击目标的原因是这些公司的股票不稳定因此具有更多的潜在收益。例如在一个案例中，黑客获得了关于医疗补助退税以及政府购买决策的信息。黑客利用虚假的微软Outlook登录页面诱骗火眼公司受影响客户的律师、执行官及咨询师交出用户名及密码。而且他们能够将自己注入电子邮件程序并持续搜刮信息。他们非常了解自己的受众。火眼至少在一个案例中发现黑客使用一份包含重要信息的机密文档引诱讨论该信息的人们交出电子邮件凭证。

  

民事案件

随着人们对网络安全的关注越来越多，SEC在2011年公布了上市公司关于披露数据泄露的指导意见。意见并不要求公司披露任何数据泄露事件，除非根据美国联邦证券法律来看属于“重大”性质。

  

这次调查对于SEC来说非同寻常，因为SEC一般在调查内部交易案件时只是查找关于股票及期权的可疑交易活动。SEC只能提起民事诉讼，因此调查中涉及刑事的案件由联邦检察官提起。目前SEC只是提出了关于黑客的少量民事案件。

  

SEC曾在2007年针对一名名为Oleksandr Dorozhko的乌克兰交易商提起民事诉讼，称Oleksandr Dorozhko入侵IMS Health并窃取收入信息以从期权交易获利。2010年，美国联邦法院判处Dorozhko支付58万美元。
