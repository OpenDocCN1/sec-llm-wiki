# 维基解密复活：发布索尼新文件、沙特阿拉伯外交部文件

维基解密复活了。继五月份宣布东山再起之后，维基解密团队在两天之内就发布了两份新文件。一份是27万份新的索尼秘密文件，一份是沙特阿拉伯外交部发布的7万份官方文档。

  

**索尼更多的金融信息被发布**

索尼被黑后已经有大规模的数据库数据被泄露，而这次代号为“索尼文件第二部分”将范围更加扩大。跟第一份由GoP组织于2014年12月份发布的信息相比，这次发布的主要是金融信息。维基解密团队暗示文件中隐藏有贿赂踪迹，不过这27万份文件中并未提供详情。

  

这27万份文件的发布时间正好是朱利安·阿桑奇在驻伦敦的厄瓜多尔大使馆避难的第三年纪念日。

  

**沙特阿拉伯购买媒体的沉默**

发布完索尼文件第二部分的内容后，维基百科同时发布了另外一份文档，虽然只有7000份，但却对世界政治产生了更大的影响。

  

这些文件源于沙特外交部、内政部、及其情报服务总部，不过即便维基百科没有发布官方来源，沙特外交部在上个月已经证实遭受到也门网军的攻击。维基百科解释称，也门网军披露了沙特阿拉伯如何不断地卷入邻国内政并且通过恐吓或贿赂的方式控制这些媒体。

  

此外，维基百科还指出，它掌握有50万份文件，编辑完成之后就会尽快发布更多信息。
