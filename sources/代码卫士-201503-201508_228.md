# 美国联邦网站及服务将于2016年年底实施HTTPS保护措施

自2017年起，美国所有可公开访问的联邦网站及在线服务都必须通过执行HTTPS安全通信协议为访客提供额外的安全。

  

白宫行政管理及预算局（OMB）在周一发布了HTTPS-Only标准令，并且将利用从多个互联网标准机构、网络浏览器及用户接收到的反馈改进最终政策。

  

**公民及政府网络资源之间的安全渠道**

截止到3月29日，在近1200个联邦政府网站中，仅有31%的网站提供对HTTPS连接的支持，而且在某些情况下，在域名证书签名中还存在加密哈希算法（SHA-1）强度的问题。

  

在执行部门机构领导的备忘录中，美国首席信息官Tony Scott分析了HTTPS的安全优势及限制。

  

虽然通过阻止数据窃听、追踪及修改而安全连接到联邦网站的方式缓解了暴露敏感信息的风险，但它并没有保护网络服务器免受网络入侵的风险。

  

加密连接并不能隐藏IP地址、目标域或间接详情如花费在站点上的时间以及请求及交流的信息规模。最为重要的一点是，如果有一方被攻陷，HTTPS将不再是保护数据交换的有效解决方案，而且攻击者会控制连接。

  

**转换至新标准并非易事**

转化至HTTPS并不容易也不便宜，因为政府网站上所有的资源（图片、脚本、字体、内嵌框架）都需要通过安全连接进行加载。

  

“迁移现有网站时，可能会涉及到许多自动化及手动工作来更新、替换或删除不安全资源的引用。对于一些网站来说，这可能是迁移过程中最耗时间的事情，”Scott在谈到所面临挑战时指出。

  

此外，执行安全标准需要能够及时解决潜在的安全问题。

  

证书替换失败、加密算法更新、转移至更新的协议版本是威胁发动者能够利用的最主要风险。从另一方面来讲，通过对所有联邦资源实施HTTPS支持，会创建一种更强大的隐私标准。
