# 攻击酒店及其他行业的PoS恶意软件：MalumPoS

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485948&idx=5&sn=051f7829aeea561db6e8d3f0a888da0d&chksm=ea973896dde0b180e8eb96984da17ae839be09dd857bfdf7d4347616095daf56f349e2bef904&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485948&idx=5&sn=051f7829aeea561db6e8d3f0a888da0d&chksm=ea973896dde0b180e8eb96984da17ae839be09dd857bfdf7d4347616095daf56f349e2bef904&scene=27#wechat_redirect)

趋势科技公司的恶意软件研究人员发现了一系列用来攻击酒店、餐饮及零售行业的malumPoS恶意软件。这款软件进行了重新配置以攻陷基于Oracle@MICROS@平台的PoS系统。趋势科技公司表示，全球已有33万客户安装了这款恶意软件。

  

甲骨文公司表示MICRO用于全球33万个客户网站中，而大批利用该平台的公司集中于美国。如果威胁发动者成功部署该恶意软件，可将几个高级别的美国公司及其客户置于风险之中。

  

趋势科技公司的安全研究人员指出， MalumPoS被设定为可配置状态，它的功能在未来很可能被轻易扩展。威胁发动者可增加更多的进程或配置新的目标。

  

研究人员指出MalumPoS恶意软件的如下特征：

  

*   NVIDIA伪装：一旦被安装到系统中，MalumPoS就会把自己伪装成“NVIDIA Display Driver”或被显示为“NVIDIA Display Driv3r”。尽管一般NVIDIA组件在PoS系统中作用并不大，但它们与普通用户的熟悉程度将会让其看起来并无恶意。
    
*   目标系统：除了Oracle MICROS，MalumPoS同时针对Oracle Forms、Shift4系统及其他可通过IE访问的系统发动攻击。从这些所列平台的用户库中可看出多数来自美国。
    
*   选择性窃取信用卡：MalumPoS使用正则表达式筛选出PoS数据并定位相关信用卡信息。之前在更老的PoS威胁Rdasrv中出现了相同的行为。在MalumPoS的案例中，它选择以下信用卡数据为目标：维萨、万事达、美国运通、发现卡以及大来卡。
