微软在欧洲设立透明中心 允许各国政府查看产品源代码

微软在布鲁塞尔（比利时首都）设立了一个新的透明中心，允许外国政府以安全的名义审查公司产品的源代码。


这个中心向参与微软政府安全计划（Government Security Program）的政府开放，政府机构可审查微软源代码、访问网络安全威胁及漏洞信息并与微软安全专家一起合作。


“世界各地政府保护公民及关键资产免受网络攻击的压力在不断增大，”微软安全副总裁Matt Thomlinson指出，“确保国家基础设施免受网络威胁需要公共及私有部门的高度开放及合作。从历史来看，微软已帮助各国政府搭建并部署了越来越多的安全IT基础架构及服务以保护各国公民及国家经济的安全。”


微软去年在美国华盛顿州雷蒙德设立了首个透明中心。该中心让欧洲、中东及非洲政府可以方便地参与GSP计划。欧盟委员会最近才成为GSP计划的新成员。GSP计划始于2003年。总体来看，全球共有23个政府的42家机构参与了这一计划。


Thomlinson表示，“只有增加对可能刺激经济发展的数字化解决方案的信心，欧洲才能够确保每个公民、企业及政府都感受到从数字革命中获得的好处。我们希望布鲁塞尔的透明中心能够帮助我们更好地实现这个目标。”


微软表示，GSP计划提供了多个产品源代码的访问权限，包括Windows 8.1、Windows 7、Windows Vista、Windows Server 2012 R2、Windows Server 2012、Windows Server 2008 R2以及Windows Server 2008。同时，通过该计划还可访问Office 2013，Office 2010及 Office 2007 ，以及Lync 2013 SharePoint 2010， Windows Embedded CE 6.0、CE 5.0 及CE 4.0产品的源代码。


除了在雷蒙德及布鲁塞尔的中心外，微软还计划在欧洲、美洲、及亚洲设立其他中心，并扩大这些计划中所包含的产品范围。
