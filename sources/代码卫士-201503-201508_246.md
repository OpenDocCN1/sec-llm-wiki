# Project Valut：把整台安全的电脑打包进一张microSD卡

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485950&idx=4&sn=49825c88e37f9348c8758c8aeeccbd1a&chksm=ea973894dde0b182bdeed547593b509652e47c08fd32c7948c8e86d80bfb08ad9849e4bc5bdf&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485950&idx=4&sn=49825c88e37f9348c8758c8aeeccbd1a&chksm=ea973894dde0b182bdeed547593b509652e47c08fd32c7948c8e86d80bfb08ad9849e4bc5bdf&scene=27#wechat_redirect)

谷歌为了保护用户最敏感的信息，制造了史上最小的计算机：Project Vault。这个消息是在上周谷歌年度I/O开发者大会上公布的。

  

Project Vault是谷歌ATAP（高级技术及项目）团队设计的，它将一台安全电脑完全打包进一张可插入任何系统的microSD卡中，无论它是台式电脑还是移动手机系统。

  

实际上Vault是一台跟平常用于计算目的不同的电脑。它是一种无需输入密码便可通信及验证的新型安全方式。今天我们一般都会选择聪明或易于记忆的字符当做密码，但谷歌想让密码变得更加个人化，甚至超出我们的想象。

  

这个细小的芯片可以在一款app或网站询问用户密码之前对用户进行验证。简言之，Vault会让用户的主认证（目前我们用的是密码）退居二线，而用户无需做任何操作。

  

通过Project Vault，谷歌将会把用户设备转换为密码。它可以加密或干扰，用户的app就是聊天信息并且提供了额外的验证层，因此用户设备能够确定用户的身份。

  

在演示阶段，ATAP团队展示了两名用户如何使用装有Vault的智能手机进行安全会话。一旦安装了芯片，聊天应用就会通过读/写I/O打开虚拟化的含有两个文件的系统。

  

Vault会对聊天进行进行加密并将之通过加密信道以加密文本形式发送，而且永远不会通过手机发送，因此没有人能够对用户进行监听。手机会自动对信息进行解密，但永远无法在任何端口查看密钥或算法。

  

谷歌表示也可利用Vault加密视频。

  

Project Vault拥有：

*   一个基于ARM的处理器
    
*   一条天线
    
*   一个与附近设备通信的近场通讯（NFC）
    
*   4g大小的“单独、封装的”内部存储
    
*   专注隐私及数据安全的超安全操作系统
    
*   一套加密服务
    

  

Vault运行着拥有一套加密服务的定制化实时操作系统（RTOS），包括哈希、批量加密、签名、以及硬件随机数生成器，以确保用户与朋友之间的数据及信息是安全的。

  

Vault适用于任何操作系统——包括谷歌的安卓 系统、Windows系统、Linux系统以及Apple的OS X系统，因为从本质上来讲，它只是托管电脑或手机的通用存储器。

  

之所以说这个设备更加智能，是因为所有的工作都是由主机完成的，用户无需处理设备配置，这让它非常用户友好。

  

Project Valut依然“处于试验阶段”，并且正处于向用户推出的阶段，不过系统的源代码已根据开源许可发表在了GitHub上。开发人员可好好研究一番了。
