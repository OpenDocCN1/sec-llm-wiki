# 微软发布最新安全情报报告

微软发布第18期《微软安全情报报告（SIR）》。

  

本期报告主要关注2014年下半年的安全情况，并且包含长期趋势数据。报告包括针对一系列全球及区域网络安全威胁的数据、深度观察以及实践指导，包 括漏洞发现、恶意软件及可疑软件。可疑软件包括最新勒索软件、恶意网站如路过式下载网站，漏洞利用活动包括在针对性攻击中的漏洞利用。同时报告还对100 多个国家/地区的威胁全貌做了深入观察。

  

报告的《情报专题（Featured Intelligence）》部分可见《漏洞利用全程观察》。这部分内容探索了一些攻击者在逆向安全漏洞方面的速度不断加快，说明了供应商公布安全更新后尽快更新系统的重要性。

  

报告还给出了可行性知道，帮助全球数千万系统缓解威胁影响。同时还包括了基于威胁的指导，而微软的IT部门正是通过这些指导检测并缓解了微软企业网络中出现的漏洞。

  

此外，微软全球企业合作伙伴集团企业副总裁Susan Hauser在自己的博客中为企业客户强调了报告中的一些关键发现。
