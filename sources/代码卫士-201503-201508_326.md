# 基于GPU的恶意软件：rootkit及键盘记录器的进化

恶意软件开发人员展示了两个POC恶意软件、一个rootkit以及键盘记录器，利用受感染主机的GPU。

  

恶意软件作者一直都展现出很强的创新性以及提出更有效解决方案的能力。最近恶意软件开发人员公布了两个恶意软件：Jellyfish rootkit以及Demon键盘记录器，它们会在受害者计算机上以不同寻常的方式运行。恶意软件利用图形卡而非CPU偷偷摸摸地运行，并提高计算能力。 由于安全专家发现了在CPU上运行的恶意软件并恶意利用GPU来铸造比特币及其他虚拟货币。

  

这两款恶意软件都可以在不吸引操作系统内核进程的情况下操作，并因此而不会引起任何怀疑。这两名匿名恶意软件开发人员为rootkit提供了如下描述：

  

*Jellyfish**是一个基于**Linux**的**userland gpu rootkit POC**项目，利用来自**Jynx (CPU)**的**LD\_PRELOAD**技巧，以及由**Khronos **机构开发的**OpenCL API**。目前代码支持**AMD**及**NVIDIA**显示卡。然而，**AMDAPPSDK**并不支持**Intel**。*

*Gpu**存储内存的优势包括：*

*   *网络上不存在**gpu**恶意软件分析工具*
    
*   *可通过**DMA**欺骗**cpu**主机内存*
    
*   *GPU**可用于快速数学计算如**xor’ ing**或解析**Stubs*
    
*   *恶意内存在关闭使用请求后依然存在于**gpu**内：*
    
*   *安装**OpenCL drivers/icds*
    
*   *Nvidia**或**AMD**显示卡（**intel**支持**amd**的**sdk**）*
    
*   *将**rootkit/kit.c**的第**103**行代码从**Stay Tuned for more features**你想要监控的**gpu**客户端的服务器**ip*
    
*   *客户端监听器；让缓冲存储在**gpu**直到你从服务器发送神奇的数据包*
    

*免责声明：仅用于教育目的；该项目**/**演示的作者不承担任何用于非法目的而引起的责任。*

开发人员并未提供关于Demon键盘记录器的更多详情，他们将其描述为执行在名为《你可以打字，但不可隐藏：一个隐蔽的GPU键盘记录器》论文中描述的恶意代码。

  

*“我们展示了执行隐蔽键盘记录器的新方法；我们探索了这样一种可能性：将显示卡作为托管键盘记录器运行的可选环境。这个方法背后的主要理念是通过DMA**直接监控系统键盘缓冲区，而且除了页面表格之外，在内核的代码及数据结构中没有任何诱骗或修改。”安全研究人员在这篇2013**年的论文中写道，“对原型执行的评估显示，基于GPU**的键盘记录器可有效记录所有的用户按键、将它们存储在GPU**的内存空间、甚至是分析所记录数据，而运行期的开销可忽略不计。*

专家强调，虽然Jellyfish rootkit能够躲避真正的防御系统，但它要求单独显示卡感染主机。就个人而言，我非常担心此类恶意软件的进化，例如将利用图像处理器整合至受害者CPU的可能性。
