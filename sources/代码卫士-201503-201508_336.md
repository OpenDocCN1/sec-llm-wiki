# Uber用户账户疑遭劫持

许多Uber用户报告有未经授权的乘车通过自己的账户支付，但Uber排除了数据泄露的可能性，建议用户重新修改密码。

  

今年三月，媒体机构曾报道Uber服务遭网络犯罪分子入侵，安全专家发现至少两家供应商在暗网黑市上出售被盗Uber用户登录凭证。

  

如今，一些美国Uber用户发现自己被黑客盯上了。一些用户表示有人访问了自己的账户并进行付款操作。而当收到未经授权的乘车通知时，用户才发现。

  

一名美国用户称，“太疯狂了。我第一次用Uber是在周四晚上。周五早上我的手机就收到一条通知称司机在路上。我并没有叫出租车。我点开通知发现叫车服务已被取消但司机拉的客人是在伦敦。”该用户还在网上贴出相关图片，包括许多被取消的Uber乘车服务，但显然这些请求是从她的账户发出的，而且她确认车费是通过自己的银行账户支付的。不过她也确认Uber已经给她退了三次乘车费。然而，为了避免发生其他问题，她删除了自己的银行卡，以免发生额外的欺诈情况。

  

发生这种事件可以有多种合理解释。比如，有可能黑客入侵了一些其他服务，而Uber与这些服务共享同一个凭证。比如在本例中，这名用户就是这种情况。然而，该用户并非报告Uber问题的第一人。许多其它用户也在Twitter上贴图表示自己的Uber账户被不知名的个人所劫持并用他们的账户支付车费。

  

Uber确认称安全专家并未发现数据泄露的证据：“除之前的声明外，我们无法分享其他额外信息：我们调查后并未发现数据泄露证据，”Uber的一名发言人表示，“试图以欺诈行为访问或出售账户是非法行为，我们已向相关机构汇报。希望大家借此机会使用保密程度高且唯一的用户名及密码，避免在多个站点及服务使用相同的登录凭证。”
