# 恶意电子邮件通过ACH向企业发送银行木马

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485976&idx=4&sn=f812588ec7b6e310b27c6685a417c6b4&chksm=ea973b72dde0b264fac4ed2ee9cd1974b54f029029dc8ea2ac71bec22f60aac189979c2bad12&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485976&idx=4&sn=f812588ec7b6e310b27c6685a417c6b4&chksm=ea973b72dde0b264fac4ed2ee9cd1974b54f029029dc8ea2ac71bec22f60aac189979c2bad12&scene=27#wechat_redirect)

最近，声称来自ACH（自动清算所，美国进行金融交易的网络，被很多企业用来快速在美国境内汇款）的恶意电子邮件发送了一个包含宏脚本的恶意Word文档链接，并附着下载Dyre金融木马的指南。

  

**犯罪分子使用社会工程学激活目标**

这次攻击使用的是社会工程学，网络犯罪分子直接将邮件发送给受害者，称之前的ACH转账并未得到银行批准。这一把戏的目的是引诱收件人打开含有详情的Word文档，而不管转账是否成功。有些人想查看一下是否发生了欺诈行为，而那些确实尝试汇款的人想要了解未被批准的原因。

  

Microsoft Office组件利用宏脚本帮助用户针对经常使用的任务创建自动流程。该功能默认禁用，而且如果启动则会收到安全警告，警示文档中未知来源的脚本可能含有恶意目的。

  

**恶意****Word****文件被存储在****Dropbox****账户中**

安全研究人员发现，恶意电子邮件附件中并不包含被控制的文本，而是提供了一个指向Dropbox云存储的位置。

  

文件一旦被下载并打开，用户会得到一个只有在启动宏的情况下才可查看内容的通知。趋势科技欺诈分析人员Christopher Talampas周一在博客中表示，宏恶意软件名称为Bartalex。包含其中的指令会引发下载名为Dyre（又名Dyreza）的银行恶意软件，它的 目标是金融机构如摩根大通、美国银行、加州信托银行以及德克萨斯资本银行。

  

从趋势科技掌握的数据来看，Bartalex在美国最为流行（35.52%）、其次为加拿大（11.54%）、以及澳大利亚（11.06%）。
