# 美国医院通过交流电处理医疗设备恶意软件

两家大型美国医院将在接下来几个月的时间里，通过监控交流电消耗开始使用能够检测出医疗设备上恶意软件感染的系统。这两家未具名医院是首批测试这个插件监控平台（代号WattsUpDoc）的医院，而平台的目的是为了检测出关键医疗设备上危及生命的恶意软件。

  

开发出这个平台的研究人员使用“传统上不受欢迎的”电流消耗侧信道来检测恶意软件，它能够测出桌面防病毒运行时的准确度，而无需修改系统的硬件或软件。

  

研究人员指出，在不修改代码的情况下确保嵌入式系统的安全对于医疗行业来说至关重要。通过交流电消耗可得知插入端口的计算机或者了解计算机目前的使用状况。在测试中，平台在不同嵌入式设备中测出已知及未知恶意软件的准确度至少为94%及85%，跟基于计算机的防病毒准确率相同。在RSA会议上作出的演示表明，平台能够通过访问不同网站包括雅虎、推特及YouTube等生成唯一的电力频率。而它会引发软件执行路径的更改，并最终反映到电源线中。

  

WattsUpDoc能够通过电力频率签名识别出Alexa前50个网站。通过交流电监控恶意软件的挑战包括现代计算机中不同的电力消耗等。
