# “SSH变态”黑客使用密码字典发动SSH暴力攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485988&idx=1&sn=2e2e11a5d9eeee23b824db811bc12019&chksm=ea973b4edde0b258de60ba64f8d1dda3e87cd18d6fffcf41839352ed541d3b8be7c41be43309&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485988&idx=1&sn=2e2e11a5d9eeee23b824db811bc12019&chksm=ea973b4edde0b258de60ba64f8d1dda3e87cd18d6fffcf41839352ed541d3b8be7c41be43309&scene=27#wechat_redirect)

一个名为“SSH变态”的网络犯罪团伙通过搜索SSH主机制造大量扫描流量，试图通过包含愈30万密码的字典进行暴力攻击并登录。

  

该黑客组织也称为“第93组（Group 93）”，它首次被发现于2014年6月被动收集DNS数据时。攻击者生成的SSH流量有时候会通过互联网上35%的全部SSH流量。

  

恶意软件保护受感染机器免受其它威胁

“SSH变态”团伙的目标是安装隐藏密码将机器奴役于用于DDoS的僵尸网络。该恶意软件曾于2014年9月份在《恶意软件必死》中被提及，而FireEye也于2015年2月份进行了披露。

  

思科Talso团队及Level 3通信安全研究人员监控了攻击活动，发现他们依赖字典为root用户查找到登录密码。找到正确的访问字符串后，就可从美国境外的另外一个IP地址完成身份验证，而被攻陷的系统就会发出一个wget请求下载DDoS隐藏木马。

  

思科研究人员表示，“一旦隐藏木马被安装，从一个C2服务器中通过XOR编码文件就会下载额外的指令。配置文件包括如何基于几个指示来终止运行的进程：CRC校验和、和IP的主动通信。

  

当发现与已有参数匹配的输入时，受感染的机器会马上将输入删除。这个措施可能是为了保护受感染机器不会被其他恶意软件利用。

  

摧毁黑客活动并非易事

基于从监控活动中收集到的数据，Talos与Level 3发起了合作活动，以采取措施停止“SSH变态”的行动。

  

Level 3的一份分析报告指出，只有恶意流量来自或者为103.41.124.0/23而准备。因此，两个安全团队开始将其拿下。

  

然而，网络犯罪团伙采取了一些措施来保证运行的安全，并转移到一个新的/23网络（43.255.190.0/23），同时修改了恶意软件的服务主机。

  

思科表示，“针对这种突然转移，我们立即采取了行动，决定删除103.41.124.0/23的路由功能，但同时添加了新的网块43.255.190.0/23。删除这两个网块为‘SSH变态’带来了新的阻碍，希望能减缓他们的活动，哪怕是一小段时间。”

  

Level 3建议在开放互联网上运行SSH守护进程的Linux机器管理员禁用root登录的可能性。
