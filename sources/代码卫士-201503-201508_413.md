# OS X最新版本修复类似后门的漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485988&idx=3&sn=a2c90c9f133a3886e4e5ca4f1ace15c1&chksm=ea973b4edde0b258a80a777bc4298e16cc33412810b42a7e2ee3452b8e3bea37988127e2537d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485988&idx=3&sn=a2c90c9f133a3886e4e5ca4f1ace15c1&chksm=ea973b4edde0b258a80a777bc4298e16cc33412810b42a7e2ee3452b8e3bea37988127e2537d&scene=27#wechat_redirect)

Apple修复了在OS X中至少已存在四年的漏洞。该漏洞使得不受信任的用户及对目标控制有限的远程黑客在Mac上拥有来去自由的“root”权限。

  

漏洞介绍

该漏洞由安全研究人员Emil Kvarnhammar发现并被命名为“隐藏的后门”，随后将其私下提交给Apple。或者这个漏洞被描述为一个未发布的程序界面更为确切，它允许拥有管理员权限或更低水平标准权限的用户获得root能力。这个权限提升漏洞在周三Apple为10.10即OS X Yosemite发布的大规模安全更新中修复。运行10.9或更低版本的Mac依然易受攻击。

  

Kvarnhammar在周四发表的一篇博文中指出，Apple OS X的管理框架中含有一个存在几年（至少自10.7发布时的2011年起）的root权限隐藏后门API，它很可能是充当“系统偏好”app及系统设置（命令行工具），但不存在权限限制。这意味着系统中的任何用户进程都可以（通过XPC）访问API。

  

如何攻击

要完整利用这个漏洞，攻击者需要物理访问目标Mac。但可结合其他攻击被远程利用。例如，能够攻陷浏览器并破坏安全沙箱的攻击者并不拥有访问操作系统资源的访问权限。漏洞利用对于运行OS X服务器版本的机器来说也很有用。

  

当Kvarnhammar在去年十月份首次发现该漏洞时，他发现自己能够利用漏洞获取root权限，而在正常情况下，只有管理员账户才能获得该权限。

  

随后他发现即使从标准的OS X账户中也能提升权限。并且让Kvarnhammar惊讶的是，他可以通过将“nil（类似0的值，在面向对象C语言编程中代表一个不存在的对象）”发送至执行提升授权的OS X机制。他指出，“它就像授权检查是由触发身份验证对象的回调函数产生的。如果你不熟悉面向对象C语言编程，猜测一下如果你调用null引用的方法或者使用面向对象C语言向nil发送一条信息会发生什么？结果是什么也不会发生。”
