# 你想隐藏元数据？可能没希望了

澳大利亚数据保留法案的讨论引出一个问题，即如何阻止政府插手自己的元数据？

  

一般非科技类记者会给出“使用加密”的答案，然后飞快地列出自己最喜爱的技术，并且过度简化事情的严重性。

  

而让人感到沮丧的真相是，多数人并没有保护自己元数据或内容的能力，而且没有考虑到所有风险就贸然提出相反意见的任何人都是不负责任的。而只需通过加或匿名技术来规避执法部门的说辞是一种危险的简单化。

  

很少有人能比世界上最为悠久的解密网站Cryptome（“地下宗卷”）http://cryptome.org/cryptome-anon.htm说的更清楚了：“Cryptome或者其他披露措施（匿名、泄密站点、粘贴、文件解密、torrent等）是一种欺骗行动的可能性非常高，不管是有意的还是无意的，并且应该避免使用它们，”并且“永远不要信任信息接受者提出的任何方法。”

  

Cryptome自1996年起，便开始处理泄露文件，网站创始人（John Young及Deborah Natsios）现在还在监狱里。因此，至少他们知道自己在说什么。

  

然而，依然有人认为即便是非技术用户也可以采取“一种奇怪的技巧”来阻止澳大利亚政府的数据保留举措。下面会解释相关风险。

  

使用Tor：Tor提供的匿名性是有限的。还击Tor最有效的攻击有一个严格的要求，即攻击者能够访问承载流量的网络基础设施。

  

如果你能从入口及出口两个终端观察到这些流量，那么去匿名化的Tor流量更有效果。

  

虽然认为政府会大规模使用去匿名化的Tor有点偏执，但可以说，如果被犯罪分子盯上，个人可被识别出来，至少在理论上是这样。

  

公共WiFi：有人认为公共WiFi热点不会将你的元数据交给政府，因为法律有此类豁免。

  

这里出现的第一个问题是，只有一个数据层即连接至互联网服务提供商的数据层是安全的。

  

如果你利用这个链接通过一个普通的SMTP账户发送电子邮件的话，真是够不明智的，因为服务器日志依然会保留一些政府想要的数据。

  

如果你从咖啡店接听了一个电话，你的电话号码及地理位置（不管运营商捕获了哪些信息）将会被保留。

  

再说，你对公共热点本身的安全性有多大的信心？

  

比如，你知道这个公共网络所使用的WiFi路由器型号吗？这个热点运行的固件是什么水平的？应该打哪些补丁但是却没有？

  

加密电子邮件：很多记者认为诸如PGP的工具是针对政府数据保留措施的回应，但并非如此：PGP保护的是邮件内容，而非澳大利亚政府想要保留的“非内容数据”。

  

实际上这个简化了的“使用加密”建议可能会为记者及消息来源者增加风险。比如，假如法庭以记者能打开由揭秘者加密文档的事实作为两者勾结的理由，该怎么办？

  

的确，可以采取一些措施来环节这些风险——但将运营安全过度简化成“使用加密、Tor，你便得到了保护”正是我所担忧的地方。

  

通过一个安全的揭秘网站揭秘：这种方法也有问题。

  

给出这个建议的安全咨询再次混淆了内容与非内容数据的区别。安全的揭秘网站旨在保护你的身份及内容在服务器端是安全的，但它并不会从本质上从你这个终端来保护非内容信息——比如你跟互联网的连接、地理位置、你连接了一个跟揭秘网站有关的IP地址等等。保护非内容数据的任务就落到了你自己的身上。

  

至于揭秘站点的安全性：它跟代码库的作用差不多。在一年之内就经历了心脏出血漏洞、Poodle以及FREAK漏洞的世界，信任同一个揭秘网站的安全，毫不夸张地说，是轻率的。

  

那这些会对我产生什么影响？会让你处于一种危险的不安全境地，就像你现在所处的环境一样；或者，可能会比你的处境更不安全。

  

虽然并非“身正不怕影子歪”的信奉者，但这里的讨论前提是你已经被有关机构盯上了。如果没有被盯上，那么所收集的数据可能并不会被使用。

  

“可能”一词正是反对澳大利亚数据保留法案、认为政治讨论不够充分、觉得为普通公民提供的保护糟糕透顶的理由。澳大利亚政府称“出于法律目的”已经对所收集收据进行了保护，但这给人们留下了很多的想象空间。
