# Apple发布Safari 8.0.4 修复WebKit漏洞

周二，Apple为OS X发布了Safari浏览器新版本，修复了两个可能允许恶意编制代码在目标Mac运行的WebKit漏洞。

  

从为OS X 10.10 Yosemite、OS X 10.9 Mavericks、OS X10.8 Mountain Lion分别发布的Safari 8.0.4、Safari 7.1.4以及Safari 6.2.4来看，这些更新会增强app的稳定性及Web浏览器的安全性。

  

第一个修复解决了WebKit中多个内存崩溃的问题。当浏览恶意编造的网站时，它可能会导致意外的app终止或任意代码执行问题。Apple通过改善内存处理修复这个问题。

  

第二个修复解决了Safari中存在的用户界面不一致问题。修复之前存在被改进UI一致性检查在内的问题，攻击者可能会篡改网页的URL以隐藏钓鱼攻击。

  

用户可通过软件更新服务免费下载Safari最新版本8.0.4、7.1.4、以及6.2.4。
