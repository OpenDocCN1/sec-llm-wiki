# 永别了，Google Code

2006年，当我们推出Google Code项目托管服务时，这个世界的项目托管服务还很有限。由于担心稳定性跟滞后性的问题，我们为开源社区提供了另外一种选择。至此以后，涌现了一大批更好的项目托管服务，比如GitHub跟Bitbucket，而许多项目也从Google Code迁移到其他的系统。为了顺应开发人员，我们也将近1000个自己的开源项目从Google Code迁移到了GitHub上。

  

随着开发人员从Google Code离开，其余项目中的垃圾信息或滥用信息在增长。最近，管理负荷几乎都存在滥用管理问题。在对Google Code的非滥用项目进行分析之后，我们清楚地意识到，Google Code已完成自己的使命，不再被需要了。

  

从今天开始，我们已禁用了在Google Code上创建项目的功能。我们会在10个月的时间（从今天开始至2016年1月25日）关闭这个服务。我们给出了迁移工具连接，大家可以将自己的项目从Google Code迁移出去。同时，我们会在未来的三个月为那些需要从Google Code迁移到其他托管服务的项目服务。

  

*   2015年3月12日——项目创建功能关闭。
    
*   2015年8月24日——网站为只读。用户依然能够检验/查看项目来源、发布日期以及维基百科。
    
*   2016年1月25日——项目托管服务关闭。用户可下载项目来源、发布日期及维基百科等压缩包。这些压缩包在该日期之后也可用。
    
      
    

Google将持续为Git及Gerrit托管服务提供某些项目如安卓及Chrome。

同时，我们将会保留一些项目如Eclipse、Kernel.org等。

  

如何将你的数据迁移出Google Code

最简单的方法是使用Google Code to GitHub迁出工具，它可将项目来源、发布日期及维基百科内容自动迁移至一个新的GitHub回购。需要注意的是，GitHub的导入会将所有Subversion或Mercurial Google Code项目在进程中转换为Git。

  

同时我们还提供单独工具将项目迁移至GitHub及Bitbucket，而SourceForge也为Google Code项目提供了一个导入服务。

  

如在使用这些工具过程中遇到问题，请将问题反馈给我们google-code-shutdown@google.com，或直接联系我（cdibona@google.com）。同时，我们将密切关注Hacker News、Reddit及其他流行论坛公开回答相关问题。我们知道，这个决定会为仍然使用Google Code的人们带来某种痛苦，对此深表歉意。我们将持续竭尽所能让迁移过程变得更加方便快捷。

  

GitHub及Bitbucket期望与迁移出Google Code的开发人员携手共进。与他们合作发布这份公告非常愉快，感谢那些持续支持这个社区的网站。2006年之后出现了一些很好的新服务，我们期望能帮助你找到适合你的那一款。
