# 美国CIA窃取Apple用户秘密

Intercept获得一份绝密文件称CIA安全研究人员多年以来一直在致力于破解Apple的产品iPhone以及iPad。

  

这些安全研究人员在一个名为Jamboree的秘密年度盛会上展现了他们的最新技巧及成绩。与会者讨论了利用家用及商用电子产品安全漏洞的策略。会议已持续将近10年的时间，第一届会议的举办时间比首个iPhone的发布早1年。

  

安全研究人员的目标是用来对Apple设备存储数据进行加密的关键安全密钥，为实现这一目的，研究人员试图阻止Apple为全球数百万用户提供移动安全功能。CIA对“物理”及“非入侵性”技巧进行了研究，旨在找出解密并渗透Apple加密固件的方法。这样间谍能够在Apple设备中植入恶意代码并在iPhone及iPad的其他部分寻找潜在漏洞。

  

CIA拒绝对此事置评。

  

此外，研究人员还声称他们元已经创建了Apple专利软件开发工具Xcode的修改版本，可将侦查后门插入任何使用这款工具创建的app或者应用程序。Xcode由Apple向数千名开发人员发布，可用来创建通过Apple App Store售卖的app。

  

安全研究人员表示，修改过的Xcode版本可使间谍窃取被感染设备上的密码并抓取信息。研究人员同时表示它还可“强制所有的iOS应用将内嵌数据发送到监听站。”目前尚不清楚CIA是如何做到让开发人员使用被感染的Xcode的。

  

研究人员同时表示他们已成功修改了OS X更新，即一款用来将更新发送至笔记本电脑及台式机的程序，来安装“键盘记录器”。

  

Apple拒绝对此事置评，只是以库克之前发表的评论以及公司保护隐私记录的立场回应。
