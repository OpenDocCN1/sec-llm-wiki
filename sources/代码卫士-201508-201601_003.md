# Oracle将停用Java浏览器插件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485804&idx=3&sn=1c534ea2755543ca3132160ea7b52919&chksm=ea973806dde0b1106fac589e86aab9b1dfadb8b07b4f309ce3a158b837765f758503292bc13f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485804&idx=3&sn=1c534ea2755543ca3132160ea7b52919&chksm=ea973806dde0b1106fac589e86aab9b1dfadb8b07b4f309ce3a158b837765f758503292bc13f&scene=27#wechat_redirect)

**Oracle****周三宣布了停用****Java****浏览器插件的具体计划并且建议用户转用其它技术。**

过去，高级浏览功能仅出现在一些利用NPAPI插件的浏览器中，最流行的是Java、Sliverlight以及Flash。而现在，浏览器厂商意识到过期的NPAPI架构引发了各种问题，比如崩溃和安全问题等，因此他们决定停止支持NPAPI。谷歌在2015年9月完全将NPAPI支持完全删除，并发布了Chrome 45；Mozilla最近也宣布将在2016年年底删除对多数插件的支持；微软也已经在新的Edge网络浏览器中停止对插件的支持。

由于维护一个不久将在所有主要浏览器中停止运行的产品没有必要，因此Oracle建议Java用户从依赖Java插件的小应用程序转移到其它技术如Java Web Start。JDK9将启用这个浏览器插件并且从JDK和JRE中完全删除。

由于很多组织机构很难决定哪些应用程序是需要被转换的，因此Oracle建议系统管理员使用Java AdvancedManagement Console来识别并列出相关应用程序。

由于过去在Java中发现了大量漏洞，许多安全专家已经建议用户如无特殊需要则禁用这个应用程序。如果需要使用Java，用户至少应该确保运行的是最新版本。

思科在2015年安全报告中指出，Java利用下降了34%，原因是Java安全新能得到改善，而攻击者也开始挖掘新的攻击向量。思科发布的2016报告中也发现Java威胁的数量在稳步减少，尤其是利用工具包使用Java漏洞的情况在减少。
