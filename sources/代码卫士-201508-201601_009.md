# Firefox 44修复Stagefright漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485805&idx=4&sn=722ecdb6d7ea303db88015d14458f292&chksm=ea973807dde0b111b27e9e8aec14b5cef7bcdb904dc8164a0da2e03dfe0ee53c3badf9a41eb5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485805&idx=4&sn=722ecdb6d7ea303db88015d14458f292&chksm=ea973807dde0b111b27e9e8aec14b5cef7bcdb904dc8164a0da2e03dfe0ee53c3badf9a41eb5&scene=27#wechat_redirect)

**最新发布的****Firefox 44****火狐浏览器不仅增添了推送通知还修复了****12****个安全漏洞，其中三个是严重漏洞两个是高危漏洞。**

其中一个严重漏洞是位于libstagefright中的缓冲溢出漏洞，跟早先在安卓中发现的库中的Stagefright漏洞一样，当时这个漏洞影响约10亿台设备。

公司表示，攻击者能够通过诱骗用户访问一个恶意的MP4视频文件方式利用这个漏洞，随后就可在用户浏览器中执行任意代码，攻陷应用程序甚至是操作系统，如果攻击者有足够攻击技巧的话。

公司还在WebGL引擎中删除了一个缓冲溢出问题，这个漏洞能够导致浏览器崩溃并且不过不允许远程代码执行。第三个严重漏洞是一系列内存危害问题，开发人员已在Firefox 44和Firefox ESR38.6中将其修复。

除修复漏洞外，公司还兑现了曾在去年9月份许下的承诺并官方删除了对RC4加密的支持。其他浏览器如IE、Edge和Chrome也将在未来版本中取消支持。此外，火狐还宣布将为Windows版本使用SHA-256签名证书，以满足微软去年提出的签名要求。火狐宣布将从浏览器中撤销两个证书即Equifax安全证书颁发机构颁发的1024位的根证书以及UTN-DATACorp SGC颁发的证书。
