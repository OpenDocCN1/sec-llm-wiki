# CryptoWall 4.0 通过Angler利用工具包传播

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485806&idx=1&sn=a798a985c68a1e29f00f94ad1c0e7ede&chksm=ea973804dde0b1120df9e27842572b7f50e431dc2f0dc420ab20d078200bae57b85ca55a3182&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485806&idx=1&sn=a798a985c68a1e29f00f94ad1c0e7ede&chksm=ea973804dde0b1120df9e27842572b7f50e431dc2f0dc420ab20d078200bae57b85ca55a3182&scene=27#wechat_redirect)

**如今最活跃的勒索软件的最新变体****CryptoWall 4.0 ****最近被添加到****Angler****利用工具包（****EK****）中。**

CryptoWall勒索软件加密被感染设备中的文件，并且要求用户支付赎金以重新获取访问权。它出现于几年前并从此快速发展，并在2015年更新至4.0版本。2015年11月，研究人员表示，恶意软件也开始加密文件名，甚至阻止用户识别自己的文件。

CryptoWall4.0假装测试反病毒方案以保护用户数据，而实际上他们是在加密数据。这款恶意软件还包含一个重新设计过的勒索信息，告知用户“CryptoWall项目”并非恶意项目，但仍然要求用户缴纳赎金解密文件。11月底，也就是新变体出现的前一个月，Nuclear EK作者将CryptoWall 4.0添加到恶意有效负载中。刚开始这个利用工具包开始输出CryptoWall 3.0变体，并在10月份带来了3.25亿美元的利益。不久之后，犯罪分子转向CryptoWall 4.0版本。安全研究人员指出，目前CryptoWall 4.0也由Angler EK传播。

Angler EK首次发现于2013年，但在2014年下半年才变得流行起来，那时它已经具备了独特的混淆能力、反病毒检测能力、加密有效负载以及无文件感染能力，同时还能够传播大量有效负载，包括银行木马、后门、勒索软件以及后门木马。

2015年10月，思科预测称Angler的幕后黑手通过147个代理服务器向约9000个IP地址每天发送利用，且感染成功率约为40%。该恶意软件每月攻陷的系统数约为52.9万台，据悉62%的感染传播勒索软件。

安全研究人员建议网络犯罪分子积极面对当前的市场挑战，而恶意软件即服务业务在复杂度跟规模上也将达到合法业务的水平。安全研究人员指出，利用工具包的基础架构活动在2015年Q3较去年同期增长了75%。
