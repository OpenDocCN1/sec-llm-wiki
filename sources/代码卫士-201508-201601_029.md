# 雅虎修复可轻易攻陷邮件账户的XSS漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485809&idx=1&sn=877512f4e438c2c9fad03863bbfcfcad&chksm=ea97381bdde0b10d634c1b468481d47df401c2e396cf41c274594e6eadeb2e866bc9481abb86&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485809&idx=1&sn=877512f4e438c2c9fad03863bbfcfcad&chksm=ea97381bdde0b10d634c1b468481d47df401c2e396cf41c274594e6eadeb2e866bc9481abb86&scene=27#wechat_redirect)

**雅虎修复了一个跨站点脚本（****XSS****）漏洞。该漏洞可允许攻击者仅通过发送一份恶意电子邮件就可完全攻陷邮件账户。而只要受害者打卡并查看邮件，他们的账户就会被完全控制。**

这个漏洞是一名芬兰信息安全专家Jouko Pynnonen发现的。他指出，攻击者能够编制出可以利用这个XSS漏洞的恶意代码，并且用它来“攻陷受害者的账户、更改账户设置并且在未经用户同意的情况下转发或发送邮件”。

**雅虎可能并没有清洁完所有****HTML****标记**

这个问题的原因跟雅虎邮箱处理内潜在邮件主体结构中的HTML标记有关。这些HTML标记用于规整邮件文本的格式和风格，允许用户添加加粗内容、插入图片、嵌入视频、创建列表等等。Pynnonen想要观察雅虎是符合轮流处理所有HTML标记的，于是他编制了一份带有所有HTML标记的邮件，不过每个标记都包含不同的属性。他将这份邮件发送给自己并且随后进行评估观察雅虎是如何进行过滤的。他发现自己可以将"< TAG\_NAME attribute="value1value2" / >"结构中HTML标记的value2用恶意代码替代。

**用户打开恶意邮件就会丢掉账户**

通过这种方法，他编制了一份PoC邮件并且在自己的账户中测试了结果，发现能够修改账户签名。由于恶意代码位于信息的主体部分，因此每当用户查看邮件时这个代码都会执行。

该漏洞仅出现在雅虎邮箱的网络界面，在移动app中并不存在。

Pynnonen将这个漏洞问题于2015年12月26日通知给雅虎，并获得1万美元的奖励。雅虎表示这个XSS漏洞从未用于现实攻击中。公司开发人员于2016年1月6日将漏洞修复。
