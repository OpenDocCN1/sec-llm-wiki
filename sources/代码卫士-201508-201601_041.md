# 物联网门铃可泄露家庭WiFi密码

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485812&idx=1&sn=bc7935ad52a5c97c3879d54041113bb8&chksm=ea97381edde0b1080cb7d33e9e171ea1c3583b630a73230e657eb6f6dd3192f52a56feec85ea&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485812&idx=1&sn=bc7935ad52a5c97c3879d54041113bb8&chksm=ea97381edde0b1080cb7d33e9e171ea1c3583b630a73230e657eb6f6dd3192f52a56feec85ea&scene=27#wechat_redirect)

**没人想让自家房上的门铃泄露家中的****WiFi****密码，话虽如此，但如果你的房子里如果塞满了物联网设备，那么最好做好迎接这个挑战的准备。**

Ring是一款现代化物联网门铃，它跟户主家的WiFi系统连接并且允许人们在手机互联网上查看按门铃的人。此外，这个门铃还为用户提供了打开房门的选择，不过这也说明门的框架中存在一个定制锁系统。

安全公司Pen Test Partners发现门铃中存在一个可披露家庭WiFi密码的漏洞。安全专家指出，安装在门外的门铃可被拆卸下来。在门铃的背面是一个黄色按钮，当按下这个按钮时，按钮就会把门铃的无线组件设置成访问点（AP）模式。

**按下按钮、访问连接、获得****WiFi****密码——成为黑客就这么简单！**

这个无线模块是由Gainspan制造的，其中包括一个网络服务器。攻击者能够利用手机通过一个指定URL连接到这个服务器。当访问这个URL时，URL会将无线模块的配置文件显示在浏览器中，里面包含家庭WiFi网络SSID及PSK（即密码）。而现在攻击者只需把门铃重新装到门外，然后就大功告成了

用户总是对家庭WiFi网络坚信不疑，而且经常将各种设备连接在这个网络。攻击者如果获得访问权限就可以发动针对受害者工作站或其它物联网设备的攻击。

Pen TestPartner表示，门铃公司的工作人员在两周前发布了一个固件更新以解决这个问题。
