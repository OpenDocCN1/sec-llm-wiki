# 微软将停止支持IE浏览器和Win 8操作系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485814&idx=6&sn=1f8684a925e79a5b30ab454b86206910&chksm=ea97381cdde0b10ada41d70a5b7ca4aebc67793d2f2f1d52358434767c52c96e09de362793f4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485814&idx=6&sn=1f8684a925e79a5b30ab454b86206910&chksm=ea97381cdde0b10ada41d70a5b7ca4aebc67793d2f2f1d52358434767c52c96e09de362793f4&scene=27#wechat_redirect)

**微软将停止对****IE****浏览器和****Win 8****操作系统的支持，这意味着全球数百万的用户以后将不会接收更新和安全补丁。**

一部分韩国用户依然在使用IE或者Win 8，据韩国媒体报道称，很多人依然会选择在微软停止支持后继续使用。也就是说这些用户很容易受到未经修复漏洞的攻击，而这种可能性在未来的几个月内很有可能发生，因为相同的漏洞存在所有的Windows版本中。韩国大概有80%的本地用户都运行Windows版本，而且其中40%依赖老旧的IE版本。

**千万别像抓着****WindowsXP****那样抓着****Win 8****不放！**

韩国互联网安全机构已发布告警信息，指出本地电脑用户应该避免让这个时刻成为另外一个WindowsXP时刻，因为很多人依然运行着于2001年发布的操作系统，虽然这个版本已在2014年4月份就不再受支持。

该机构表示，对WindowsXP的技术支持在2014年年初结束，但仍然有15%的韩国用户仍然在使用Windows XP和Windows Vista系统。他们需要通过更新操作系统的方法处理潜在的安全威胁。

如果用户仍然在使用Win8，那就需要更新到8.1，而依然在运行IE浏览器的用户可以安装IE 11，这个版本是唯一仍然支持更新和安全修复的版本。
