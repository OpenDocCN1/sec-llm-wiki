广告软件偷偷关闭火狐安全浏览功能

两款PUP（潜在有害程序）偷偷关闭了火狐的安全浏览支持，以传播来路不明的广告甚至是恶意软件。

这两款PUP是Shell&Serevice和Mintcast 3.0.1，它们都是火狐、Chrome和IE浏览器的扩展，而且通常都是在未经用户同意的情况下连同其它软件安装。这两个扩展带来了Mintcast广告软件的新变种，它除了能在用户浏览器中注入广告外，还能偷偷关闭火狐浏览器的安全浏览支持功能。该功能是由谷歌创建并管理的服务，它同时也在Safari和火狐中执行。安全浏览支持功能也就是将过去恶意软件感染的网站URL列为黑名单。这个黑名单由谷歌和Mozilla公司的工程师进行实时更新。

由于火狐浏览器允许用户创建user.js文件以代码行的形式存储多种浏览器设置，而Mintcast广告软件滥用的正是这个功能。

如果在"C:\Users\{username}\AppData\Roaming\Mozilla\Firefox\Profiles\{profile}.default"文件夹中没有出现user.js文件，那么广告软件就会创建一个只有三行代码的文件，如下：

CODE

user_pref(“browser.safebrowsing.downloads.enabled”,false);
user_pref(“browser.safebrowsing.enabled”, false);
user_pref(“browser.safebrowsing.malware.enabled”, false);

这些设置会告知火狐浏览器在浏览网页或下载文件时停止检查安全浏览黑名单。如果这个功能被关闭，广告软件就会将用户重定向至恶意页面，而浏览器不会向用户显示任何出错信息或告警信息。

由于当浏览器开启时，user.js正在执行，那么即使用户通过浏览器设置部分重启了这些设置，它们也会保持活跃状态，除非用户从之前提到过的文件夹中删除了user.js文件。有报告指出此前，其它广告软件如Yonto/BrowseFox和Constant Fun也使用了相同的技巧。
