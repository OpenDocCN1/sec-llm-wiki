# Adcon ICS产品漏洞未修复

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485828&idx=3&sn=8678161ae81410ad033d771eb0976fea&chksm=ea9738eedde0b1f85a488ac2b1f79d51c232c92ba0d337a80515523ac1e9fa709935ab3a9106&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485828&idx=3&sn=8678161ae81410ad033d771eb0976fea&chksm=ea9738eedde0b1f85a488ac2b1f79d51c232c92ba0d337a80515523ac1e9fa709935ab3a9106&scene=27#wechat_redirect)

**一名安全研究人员在一款****Adcon****的基站产品中发现了几个高危漏洞。**

ICS-CERT发布一份安全公告详细说明了Aditya K. Sood在Adcon A840中发现的四个安全漏洞。这些产品主要用于欧美商业工厂、水和废水处理、关键制造和其它行业。

Sood发现这款产品中含有一个包含硬编码凭证的文件，攻击者可通过管理员权限登录设备。一旦登录成功，攻击者就可更改设备设置并读/写入文件系统，从而对系统的保密性、完整性和可用性带来负面影响。该问题的CVE编号是CVE-2015-7930，CVSS评分为10。

另外一个问题的CVSS评分是10，跟加密网络通信缺乏SSL支持有关（CVE-2015-7931）。也就是说所有的通信都可别拥有目标网络权限的攻击者轻易读取（CVE-2015-7932）。

Sood还发现设备所使用的Java客户端将存储在服务器日志文件中的完整路径泄露。这个漏洞编号为CVE-2015-7934，CVSS评分是8.6。

安全专家还发现了安全公告中未包含的另外一个与Java客户端下载传感器配置文件相关的漏洞。这份配置文件包含敏感信息，允许攻击者在无需验证的情况下下载文件。

Adcon表示，并不会向A840网关系统提供修复，因为该产品不在支持之列。公司表示会向已知客户提供升级服务，升级至更加安全稳定的版本。

A840基站已无法在Adcon网站上获取，而且被A850 Telemetry Gateway版本取代。新版本支持最多1000 RTU，而且增加了十几个新功能。

Sood将于来年的安全会议上详细介绍自己的研究成果，他表示在11月3日向ICS-CERT公布了这些漏洞，当时A840产品还能从网站上找到。虽然厂商声称已经告知客户相关情况，但Sood发现北美和欧洲的数十台A840设备仍然可以从网站上访问。产品的硬编码凭证可被攻击者利用直接从互联网访问这些设备。Adcon目前尚未有任何回应。

ICS-CERT建议相关机构设置防火墙并将控制系统从商业网络中隔离以将风险最小化，并且在远程访问时使用VPN。
