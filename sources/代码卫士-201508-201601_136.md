# “幻影队”黑客组织威胁在圣诞拿下

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485830&idx=4&sn=07ddd85a783e84be08d2a14f184e073d&chksm=ea9738ecdde0b1fa72fbfd37252a9503a1996a0dbbbff2d307f25c689f8a2342144bc14354dc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485830&idx=4&sn=07ddd85a783e84be08d2a14f184e073d&chksm=ea9738ecdde0b1fa72fbfd37252a9503a1996a0dbbbff2d307f25c689f8a2342144bc14354dc&scene=27#wechat_redirect)

**去年，“蜥蜴队”黑客组织设法在圣诞期间拿下了****Xbox Live****和****PlayStation****网络。而今年圣诞节来临之际，一个名为“幻影队”的黑客组织威胁将发动类似攻击。**

从他们的推特计划来看，“幻影队”已经对Reddit发动了DDoS攻击，即使并没有人注意到他们的行踪。当然全部拿下这个站点也并非易事，但攻击本身足以吸引人们的眼球。

过去几天，“幻影队”都一直声称发动了针对Steam网络和服务器的攻击以拿下星球大战系列的游戏。但他们并未提供任何证据，而且从推特搜索来看，这些服务也并未透露任何严重问题。不过他们可能针对Xbox Live和PSN网络发动了小型的可能是测试性的攻击，结果导致它们在短时间内下线。

“幻影队”声称只有五名成员，而且与“蜥蜴队”无任何瓜葛。从目前的行为来看，他们就像是一个只求获取注意力的可怜山寨品。当然想想“蜥蜴队”此前并未被当做真正威胁的事情，这次或许也不能掉以轻心。
