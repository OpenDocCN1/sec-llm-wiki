# 导致软件产生漏洞的九大编程语言

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485836&idx=2&sn=f45bfd143b5df1a0455b0efa1606c590&chksm=ea9738e6dde0b1f060edf2534383a9a0d1347b2e32517f7486280b672e03000810113aefaa95&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485836&idx=2&sn=f45bfd143b5df1a0455b0efa1606c590&chksm=ea9738e6dde0b1f060edf2534383a9a0d1347b2e32517f7486280b672e03000810113aefaa95&scene=27#wechat_redirect)

**Veracode****安全公司分析了从****2013****年****10****月****1****日到****2015****年****3****月****31****日期间发布的****208,670****款****app****后发现，从总体来讲脚本语言会导致****app****出现更多的安全漏洞。**

该报告使用了“每MB的漏洞密度”的衡量标准，也就是每MB大小的源代码中出现的安全漏洞个数。分析结果如下：

l Classic ASP—1,686个漏洞/MB（1,112个严重漏洞/MB）

l ColdFusion—262个漏洞/MB（227个严重漏洞/MB）

l PHP —184个漏洞/MB（47个严重漏洞/MB）

l Java —51个漏洞/MB（5.2个严重漏洞/MB）

l .NET —32个漏洞/MB（9.7个严重漏洞/MB）

l C++ —26个漏洞/MB（8.8个严重漏洞/MB）

l iOS —23 个漏洞/MB（0.9个严重漏洞/MB）

l Android—11个漏洞/MB（0.4个严重漏洞/MB）

l JavaScript—8个漏洞/MB（0.09个严重漏洞/MB）

由于Classic ASP几近消亡，而ColdFusion是一种高端工具，因此位于第三位的PHP实际上排名第一。

**PHP****成为许多安全漏洞的主要来源之一**

PHP坐拥大量粉丝，应用于无数app和网站中，在命令注入漏洞排名方面靠后，但在SQL注入、跨站点脚本漏洞和加密问题方面位居前列。在所分析的app中，有86%包含XSS问题、73%包含加密问题、67%包含目录遍历漏洞、61%包含代码注入漏洞、58%包含凭证管理问题、56%的包含SQL注入问题、以及50%包含信息泄露问题。

在策略合规方面，只有19%的app通过了OWASP的十大测试。ColdFusion的排名最低为17%，而C/C++的通过率为60%。

报告指出，以真正合规语言如C/C++和Objective C（iOS）编程的app比一般的字节码语言如Java或.NET的OWASP通过率要高，而脚本语言如Classic ASP、ColdFusion和PHP的通过率要低。
