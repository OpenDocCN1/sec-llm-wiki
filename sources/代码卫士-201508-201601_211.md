# Windows BitLocker全盘加密可被绕过（已修复）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485846&idx=4&sn=5ea841eb44db164463b5f9ac0dd0f0ef&chksm=ea9738fcdde0b1eacdccaa9c0ce04b4c1f4cf34040d98a3a2441748bd970d6c3e1a616c41ef2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485846&idx=4&sn=5ea841eb44db164463b5f9ac0dd0f0ef&chksm=ea9738fcdde0b1eacdccaa9c0ce04b4c1f4cf34040d98a3a2441748bd970d6c3e1a616c41ef2&scene=27#wechat_redirect)

**来自****Synopsys****的安全研究员****Ian Haken****表示，微软用来保护运行****Windows****电脑数据安全的****BitLokcer****全盘加密系统可被轻松绕过。**

BitLocker是一种添加至Windows 2007版本的全盘加密系统，与Vista一同发布。它允许家庭用户和企业通过强大的加密方法保护自己的数据，而不必不断输入密码或重启。

根据Hacken的最新研究成果，如果攻击者拥有一台曾是某个域名一部分、且运行着Windows的笔记本电脑或台式机，那么就能够获得访问数据的权限。

**攻击要求设备必须是****Windows****域名的一部分**

在大规模的企业配置中，Windows计算机通过叫做“域名”的虚拟网络连接在一起。这个域名将所有的用户连接到一个共享网络，并且通过域控制器来验证参与者并授予他们访问网络的权限。

验证的操作基于密码和唯一的机器密码，前者被本地存储于缓存中的计算机中，后者是通过每个域名\-客户端的链接产生密码。

由于BitLokcer是专门为在授权域名情况下对加密数据提供权限而设立，因此如果攻击者设法绕过这个域名验证，就会带来很多问题。

**成功的攻击的唯一要求是物理接近设备**

如果攻击者设法窃取了一台笔记本电脑，那么就会将本地密码缓存替代成一种克隆密码。如果他们创建了一个跟笔记本电脑原始域名相同名称的新域名，那么验证机制中的漏洞就会允许攻击者绕过本地设置的用户密码验证步骤。

产生这种情况的原因是“虚假”域控制器的安全策略将会推动用户更改老旧密码。而当攻击者更改了被盗笔记本的域密码后，这个新的通过凭证就会替代存储在被盗笔记本缓存中的原始密码。随后攻击者就能将笔记本跟虚假域名断开连接，即使机器密码是无效的且不会提供访问域名的权限也是如此。

由于机器通常会短暂离开域名一段时间，BitLocker的设计也会允许生成的本地用户密码输入时，访问加密数据。

**通过有毒凭证缓存诱骗****BitLocker****披露数据**

也就是说，通过这种技巧更改本地密码后，攻击者只需断开网络，输入新设置的密码，就能够访问通过BitLocker加密的数据。由于笔记本处于断网或者不在域范围内的状态，这个密码仅通过有毒的域凭证缓存验证，因此BitLocker无从区别。

不过好消息是，微软已在MS15-122安全更新中修复了这个漏洞。Haken将在2015欧洲黑帽大会上具体展示其研究成果。
