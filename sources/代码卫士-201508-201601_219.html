人人都能轻松地在Gmail安卓app伪造邮件地址

原文：http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485847&idx=3&sn=c67ad288768f6c0fa6a21f8f49dfe7e9&chksm=ea9738fddde0b1eb729d5e0e9dcea3b8bd518cca660064e8c9f7f3a3fe1ad78ac61806395055&scene=27#wechat_redirect

一名独立安全研究员在Gmail 安卓app中发现了一个bug，允许任何人伪装成别人的邮件地址发送消息。


当用户修改了自己的显示名称后，这个问题就会展示出来。输入如下文本就能让任何人伪装成别人来发送邮件。


CODE

Name ""username@domain.com"


邮件地址开头的这个多余双引号（”）对于堵塞Gmail的输入验证机制并触发邮件欺骗行为来说已经绰绰有余。随后，用户就能输入任何邮件地址，随后该用户就能以伪装的邮件地址发送信息。这名安全研究员将问题反馈给谷歌，但谷歌还未修复，并将其归类于安全bug。


说来也怪，因为整个DMARC标准的目的就是避免电子邮件欺诈，它是对付钓鱼攻击的主要渠道。谷歌是推动DMARC应用在现代邮件服务中的主要力量。虽然DMARC和其它邮件安全协议能够检测到多种邮件欺诈技术并在垃圾邮件或钓鱼攻击对用户展开入侵时阻止它们，但这名研究人员的测试表明她所发现的这个bug目前并未被检测出来。


目前这个问题仅影响安卓版本的Gmail app。
