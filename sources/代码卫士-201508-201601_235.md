# 迈克菲实验室发布2016威胁预测报告：勒索软件将增多

**对于网络犯罪分子来讲，****2015****年是一个忙碌的年份，不过也不要期待他们会在****2016****年度假远行。至少这是****迈克菲实验室威胁预测报告****得出的结论。**

这份报告汇聚了全球超过33名安全领袖的意见，它指出区域组织来年应该关注的领域。

  

**勒索软件将持续引来麻烦**

主要及每个人都能预测到的威胁是勒索软件。它在2015年“光芒四射”，而一些组织也从中攫取了上亿美元。因此不要寄望于勒索软件会消亡，也不要期待硬件攻击会消失。硬件和固件估计很可能会继续，因为安全研究人员发现目前此类工具的市场正在增长。

  

2015年针对可穿戴设备和智能汽车的攻击也有望继续，黑客在之前所积累知识和攻击场景的基础上创建了一些针对这两类新产品的复杂攻击。当然，迈克菲也不会忽视商务环境。它表示云服务器一旦被攻陷就会成为攻击者的一个潜在进入点。另外，报告告警组织机构，攻击者有可能利用单个员工所采取的不当安全措施来攻陷更大的基础架构。

  

**Adobe Flash****播放器是****2015****年问题最多的应用**

由于应用漏洞和利用工具包的市场是2015年问题的主要来源，迈克菲表示这个趋势不会减弱，主要是执法部门在过去几乎没有在这个方面增加投入。因此Flash播放器在安全漏洞利用方面还是会排在首位。

  

说到2016年的光明面，研究人员表示真正的黑客主义几近消亡。因为多数努力推动他们事业的黑客主义者被逮捕、起诉、或关进监狱。而假冒黑客主义发动攻击的攻击者可能会增多。
