# 埃及黑客创建了基于njRAT的监控工具KillerRat

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485851&idx=5&sn=e156b8be00fe1a7cb7446d11f620362c&chksm=ea9738f1dde0b1e751b7ed3ed82f25d6ecf4901651d3398ddb8a12abe649b8b17e69d82798ae&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485851&idx=5&sn=e156b8be00fe1a7cb7446d11f620362c&chksm=ea9738f1dde0b1e751b7ed3ed82f25d6ecf4901651d3398ddb8a12abe649b8b17e69d82798ae&scene=27#wechat_redirect)

**一名来自埃及的黑客在****njRAT****工具包基础上创建了一个新的****RAT****。这个新工具允许攻击者以匿名身份实施行动，而且监控能力得到增强。**

这个RAT名为KillerRat，它是一款添加了新的入侵功能的njRAT。njRAT的监控功能主要针对安卓设备，而不太注意Windows设备，而KillerRat的目的是让攻击者轻易控制Windows电脑。

**KillerRat****监控功能强大**

RAT允许攻击者：

l 与受害者的本地文件系统交互

l 与受害者的本地进程交互

l 与受害者的本地注册表交互

l 在受害者电脑上执行shell命令

l 从浏览器中提取密码

l 激活键盘记录功能

l 开启受害者的网络摄像机并观看实时视频

l 启动远程桌面会话

l 将受害者当做网络流量的代理

l 从受害者电脑上发动DDoS攻击

l 在用户浏览器中开启网站

l 运行定制化脚本

l 用恶意软件感染用户

l 将收集到的信息发送到命令和控制服务器

 根据安全研究公司AlienVault的分析，目前KillerRat仅能被35家中的一家反病毒厂商检测出。虽然njRAT已出现多年，但KillerRat依然享用它的大部分代码库。

** KillerRat****的作者无意隐藏自己身份**

 另外一方面，虽然所有的黑客都喜欢吹嘘自己的工具并在代码后留下名号，但KillerRat似乎留下了真名字以及在Facebook页面上留下了KillerRat的“关于”部分。这名作者名为Ahmed Ibrahim，参与了多个与入侵相关的活动。从他的时间轴可看出，他在10月30日发布了KillerRat4.0.1版本即目前能检测到的最新版本。除了KillerRat外，这名黑客似乎还在开发一款名“楔形蠕虫（Wedges Worm）”的新工具。
