# Mabouia：首款针对MAC OS X的勒索软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485853&idx=2&sn=3f7347b1691f6b223d64f9ec50a9433a&chksm=ea9738f7dde0b1e17b4f10787db5186b7124d50f7986eaf2484d4f74373977dbf0a47dd07523&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485853&idx=2&sn=3f7347b1691f6b223d64f9ec50a9433a&chksm=ea9738f7dde0b1e17b4f10787db5186b7124d50f7986eaf2484d4f74373977dbf0a47dd07523&scene=27#wechat_redirect)

**巴西研究员****RafaelSalema Marques****公布了首款针对****MAC OS X****的勒索软件****Mabouia****的****POC****。**

设想一下这个场景：你在电脑上收到了一个勒索警告称你的所有个人文件都被锁定了。如果要解密则必须支付500美金。你会怎么做呢？而这通常就是勒索软件的“作案方式”。

  

当前世界上有几个活跃的勒索软件，但此前还未有人设计出专门针对MAC OS X的勒索软件。

  

研究人员指出，自己的目的是警告6600万MAC OS X用户，再也不存在没有针对Apple个人电脑发动攻击的恶意软件了。而恶意软件的作者也提到，Mac用户是勒索软件一个很好的目标，因为通常他们的购买力更高，而且会将其用于特殊场合，比如编辑图片和文字。

  

这款恶意软件的名称Mabouia指的是一种从巴西费尔南多—迪诺罗尼亚岛发现的流行蜥蜴。它的编程语言是C++并且通过加密算法XTEA加密用户文件。此外，它并不需要获取超级用户权限来执行恶意代码。也就是说这款勒索软件只会更改用户的个人文件，因此只要用鼠标点一下就会被感染。
