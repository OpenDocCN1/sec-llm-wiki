# 英国披露互联网监控新法案计划

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485854&idx=1&sn=a634c6d2ae31b1f3afe436f9e1a4cd1f&chksm=ea9738f4dde0b1e283b013feac2d4e4d6ba2bbb62e9006f81f3bb6b5b8a53f850d7e93487dd2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485854&idx=1&sn=a634c6d2ae31b1f3afe436f9e1a4cd1f&chksm=ea9738f4dde0b1e283b013feac2d4e4d6ba2bbb62e9006f81f3bb6b5b8a53f850d7e93487dd2&scene=27#wechat_redirect)

**本周三，英国公布了建立互联网监控法案的提案，包括允许访问受害者的部分历史浏览记录。**

虽然英国内政大臣特丽莎·梅将这个草案称赞为“引领世界的监督制度”，但一家顶级人权组织确认为它是对英国网络安全的“重磅攻击”。

  

梅表示新法案将会在未来为执法部门、安全和情报机构的工作助力，而且新法案将成为这些机构工作的许可证。这些机构将能够访问互联网通信记录，显示嫌疑人何时访问了哪个网络服务。这能显示出信息服务如Facbook或WhatsApp的情况，但并非信息内容或收件人信息。该法案也将允许安全官员查出嫌疑人访问了那些网站，但并不是在这些网站中访问了具体的哪些网页。

  

梅否认了访问人们完整网络浏览历史记录的说法，她表示互联网连接记录记录的是人们使用的通信服务，而不是他们访问的所有网页。这些记录必须由服务提供商保留12个月的时间。不过这些法案不会强迫国外公司如Facebook何谷歌遵守“国内保留义务”保留通信数据。

这个计划也提供了数据拦截的授权新方式。当前这些数据请求由梅发布，但未来必须通过法官的审批。这些法案说明了这些机构如何批量获取数据并“干扰”电子设备如计算机和智能手机从而获取数据。

  

公民自由组织担心这些法案的权力实施会缺乏足够的监督而且可能会被滥用，从而导致出现像斯诺登披露的那种监控行为。而英国官员表示升级监控法案的部分原因是考虑到斯诺登披露的监控行为，而且由于当前法案在1995年制定，而当时互联网还未兴起。
