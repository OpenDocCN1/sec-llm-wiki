# 第三季度金融和移动恶意软件攻击见长

**来自****BleepingComputer****公司的极客指出，勒索软件****CryptoWall 4.0****已发布。**

CryptoWall是一款臭名昭著的勒索软件，具有强大而有效的文件加密系统，子没有解密密钥的情况下几乎不可能将文件解密，唯一的办法只有支付赎金。

  

**CryptoWall 3.0****和****4.0****改变不大**

几天齐纳，最新版本的CryptoWall 4.0被检测到，而且虽然版本号意味着有重大变化，但与之前版本相比改变甚少。唯一的不同之处在于勒索页面的设计有所变化即显示有嘲弄受害者的文字；不过这个版本还能加密文件名称，这样受害者就无法找到被加密前的文件是哪个。

  

研究人员指出，新版本继续使用跟此前版本相同的命令和控制服务器、相同的赎金支付域、为命令和控制服务器提供相同的RC4加密、以及未识别受害者生成唯一MD5哈希而使用的相同算法。也就是说，除了附和当前“再设计”的趋势而进行“整容手术”外，它并没有多少变化。

  

**新版****CryptoWall****有着更多恼人的勒索信息**

勒索软件操作者向受害者展示的文本内容包括：“祝贺！！！你已经成为CryptoWall大家庭的一份子！”以及“找不着你需要的文件？你看到的文件不可读？这很正常，因为这些文件名称以及文件数据已被加密啦。”等等。

  

此前曾指出，CryptoWall 3.0版本已经赚取了3.25亿美元的利润。
