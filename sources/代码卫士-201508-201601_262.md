# vBlulletin.com论坛软件站点遭涂鸦

**论坛程序套件网站****vBulletin.com****的官方站点被黑，成千上万名用户的身份信息被泄露。**

**黑客声称共获取了****48****万份记录，并且涂鸦了站点。此外****Foxit Software****论坛也被黑。这两起攻击很可能利用的是同一个****0day****漏洞。**

**随后****vBullletin.com****因维护站点而在****10****月****31****日万圣节之际下线。不过不久站点回复，看似并没有遭受太大的打击，并指出虽然攻击“很复杂”，但仅仅可能泄露了“客户****ID****和加密密码”。话虽如此，但谨慎起见，公司相关人员建议用户重设密码。**

**网络名为“****Coldzer0****”的用户声称为此事负责。据悉****Coldzer0****利用影响****vBulletin.com****的一个****0day****漏洞发动攻击，而且跟自己之前入侵****Foxit Software****使用的是同一个漏洞。不久前****vBulletion 5.x.x****的远程代码执行****0day****漏洞供出售，貌似来自同一名黑客之手。**

**截至目前，尚不清楚有多少名用户受到影响。**
