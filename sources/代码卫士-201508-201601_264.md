# 俄罗斯银行遭受Tinba银行僵尸网络攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485855&idx=5&sn=40f3fd9cf40f74353e5e7cd12312a567&chksm=ea9738f5dde0b1e327fa471eff4968a1db4a7dd0930c186893ba838ad3520a735dc8d7ad0bc0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485855&idx=5&sn=40f3fd9cf40f74353e5e7cd12312a567&chksm=ea9738f5dde0b1e327fa471eff4968a1db4a7dd0930c186893ba838ad3520a735dc8d7ad0bc0&scene=27#wechat_redirect)

**Dell****安全研究人员发现一个恶意活动，专门针对多家俄罗斯银行和支付服务提供商。这次恶意攻击背后的网络犯罪分子据悉运行着一个巨大的僵尸网络，传播****Tinba 2.0****银行木马，窃取受害者的金融信息。**

Tinba是IT安全界有名的威胁，已经活跃多年。它主要的攻击目标位于日本、欧洲和北美。如今它有两个变体，但由于Tinba 1.9的源代码在2014年遭泄露，因此很多网络犯罪团伙自此已不再使用。随后不久Tinba 2.0出现，而且跟前一个版本类似，它出自一个名为“复活节欧洲（Easter European）”的威胁组织。

  

地下黑市将Tinba 2.0当做僵尸工具包出售，允许任何购买者设置自己的命令和控制服务器，配置多个安全和验证方法以躲避简单的检测，随后把木马的MO予以微调，这样就能针对具体的目标发动攻击。大多数Tinba攻击通常只针对小范围的地理区域发动攻击，比如几家银行或几种用户类型。

  

**黑客出其不意地攻击本地目标**

研究人员发现的这次恶意活动仅针对俄罗斯银行和支付服务提供商。这种行为并不典型，因为很多类似的银行僵尸通常会避开攻击俄罗斯目标。原因是一般位于这些地方的犯罪团伙不会攻击本地目标，如此便不会触怒当地执法机构。

  

不照此行事的黑客组织包括Carberp团伙，它们在2013年针对俄罗斯银行发动攻击，不过当地机关不久之后就逮捕了团伙的头目即一名28岁的俄罗斯人。

  

从2015年10月15日获取的数据来看，Tinba 2.0感染中有34.5%位于俄罗斯。研究人员指出多数受害者是通过垃圾邮件和利用工具包如Angler等受感染。一旦电脑被感染，Tinba就会开始记录金融操作并将数据发回命令和控制服务器，随后借此实施欺诈交易。

  

俄罗斯和乌克兰之间不公开的战争或许能解释这个攻击者的国籍和地理位置谜团。虽然并未得到证实，但不能排除这个可能性。
