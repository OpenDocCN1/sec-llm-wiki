# 百度SDK可在安卓设备上安后门 影响人数达1亿

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485856&idx=4&sn=5655017241d85aae8e898f5ebd1f5f02&chksm=ea9738cadde0b1dc5f520b072ff7f5b2b74f936e826a89d65e42521eb1ab28acc6ab1d7734c7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485856&idx=4&sn=5655017241d85aae8e898f5ebd1f5f02&chksm=ea9738cadde0b1dc5f520b072ff7f5b2b74f936e826a89d65e42521eb1ab28acc6ab1d7734c7&scene=27#wechat_redirect)

**趋势科技研究人员发现，百度搜索引擎提供的****SDK****中包含可被恶意利用从而在用户设备上安装后门的功能。**

根据最新估算，这款名为Moplus的SDK存在于14112款安卓app中，其中有4014款由百度自己开发。加上这些app的下载量，面临威胁的安卓用户超过亿名。

  

**SDK****通过****HTTP****请求接收指令**

趋势科技指出，这款Moplus SDK会自动在用户智能手机上启动一个HTTP服务器，该服务器能够在手机后台在用户不知情的情况下静默运行。

  

这台服务器可被攻击者控制，并向其某个特殊端口发送HTTP请求并告知它执行恶意指令。趋势科技目前发现它使用的端口是6259和40310.

  

以下是这款Moplus SDK能够做的最让人担忧的事：

l 获取电话详情

l 发短信

l 拨打电话

l 添加新联系人

l 下载文件

l 从设备上传文件

l 获取本地app清单

l 静默安装其它app（在设备被root的情况下）

l 推送网页

l 获取手机的地理位置等信息。

  

由于这款SDK会在包含Moplus SDK的app启动时部署网络服务器，攻击者只需要扫描这两个端口就能发现移动网络中可被利用的易受攻击的设备。趋势科技发现这款SDK至少用于一种恶意攻击中(ANDROIDOS\_WORMHOLE.HRXA)。

  

**百度知悉此事后并未删除所有功能**

百度知悉此事后删除了这个SDK的某些功能，但并非全部。在最新的更新中，百度删除了上传或下载、扫描本地app、添加联系人或扫描下载文件的功能。但其它功能并未删除。

  

此前曾发生过类似窃取信息的SDK事件。例如之前优米和淘米客就被曝出窃取短信并上传至位于中国的服务器的情况，而且前者因此而被Apple应用商店下架。
