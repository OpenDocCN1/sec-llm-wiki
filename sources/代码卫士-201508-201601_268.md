# 欧盟2016安全研究计划将关注机场、医院和智能汽车领域

**欧洲网络和信息安全机构（****ENISA****）公布了****2016****年的研究计划，将主要关注机场、医疗行业、智能汽车和公共智能道路的安全。**

每年年底，政府机构都会为来年计划预算并作出打算。ENISA将研究目标锁定物联网行业在情理之中。物联网设备已经出现了一段时间，而且即便它并非首次出现在公众面前，今年也被人们了解了不少相关弱点。今年曾发生过一系列惹人注目的入侵案例，包括汽车、冰箱、婴儿监控器和CCTV摄像机等入侵事件。公众已经意识到，物联网带给他们便利的同时也带来危险。

  

**ENISA****欲让物联网设备的世界更加有序**

ENISA来年的目标是这三个至关重要、关乎生命安全的行业：医疗、机场安全、和公路。该机构希望在明年年底所出具的建议会在2017年写入欧洲大陆法。之所以选取这三个领域，主要原因是它们的联网设备很容易遭到入侵，而且会带来巨大损失。
