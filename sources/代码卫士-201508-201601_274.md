# 臭名昭著的CryptoWall勒索软件非法获利3.25亿美元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485857&idx=5&sn=8edd3f29b99c8769e6194b441e9dd9ca&chksm=ea9738cbdde0b1dd94252614026c45592762799f95bbe752fb676a97ed8879e1e084c16e642b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485857&idx=5&sn=8edd3f29b99c8769e6194b441e9dd9ca&chksm=ea9738cbdde0b1dd94252614026c45592762799f95bbe752fb676a97ed8879e1e084c16e642b&scene=27#wechat_redirect)

**臭名昭著的****CryptoWall****勒索软件仅在去年一年就设法集资了****3.25****亿美元用于开发。最近勒索软件已成为网络用户面临的最大威胁之一。**

**黑客主要利用恶意勒索软件获得访问用户计算机系统的权限，并用一种强加密算法将所有文件都加密，并要求受害者支付****200****至****1****万美元不等的赎金。**

**2014****年，研究人员首次发现了****CryptoWall****勒索软件攻击，而目前其最新版本****CryptoWall 3.0****（****CW3****）是该家族中最凶悍最复杂的勒索软件，而它则得益于非常强大的后端基础架构。**

**有报道称，去年一个专门研究新出现威胁的行业组织发现了：**

l 406,887起CryptoWall感染尝试

l 共有4046个恶意软件样本

l 839个用来发送指令核接收数据的命令和控制服务器URL

l 5个二级IP地址

l 49种不同的CryptoWall分布式攻击

l 在这49种攻击中，一个名为“CRYPT100”的攻击感染了全球1.5万台计算机

l 从几处相似点来看，勒索软件背后的网络犯罪分子可能是同一个组织

l 仅去年，这个黑客组织发动的攻击就比之前的CryptoWall增加了1800万多次。

  

报告指出，这个网络犯罪分子团伙从全球成千上万个CryptoWall 3.0的受害者身上获得了多达3.25亿美元的赎金。CryptoWall 3.0主要通过利用工具包和钓鱼邮件发动攻击。

  

目前，要想破解或解密文件，只能通过CryptoWall解密密钥，因此唯一的应对方法就是接受文件丢失的事实或支付赎金。而最好的防御方法则是要时刻注意备份文件远离攻击者的视线。

  

以下是一些可免遭勒索软件敲诈的方法：

  

l 使用声誉良好公司的反病毒软件和防火墙

l 避免从未知来源打开邮件和附件

l 保持操作系统和软件时刻处于最新更新版本。
