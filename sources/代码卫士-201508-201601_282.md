# 警惕！PayPal钓鱼新手法浮出水面

**PayPal****的巨大成功总是找来无数网络犯罪分子的虎视眈眈。他们总在想方设法地获取用户账户。**

如果黑客无法攻陷PayPal的服务器，在多数情况下说明用户被无数钓鱼活动所包围，而这些钓鱼行为一个比一个复杂。

  

最近出现的钓鱼活动是，黑客将仔细推敲后的文字邮件发送给用户，诱骗他们在邮件附件文件中输入PayPal邮箱和密码。这份邮件声称来自PayPal的支持团队，并且告知用户账户上出现了异常活动，督促他们更新资料以验证身份。

  

这个附件文件是一份HTML文件，编造得跟官方文件很像。用户不但会被诱骗输入PayPal邮件登录和密码，还会输入其它敏感信息如信用卡详情、出生日期、全名、电话号码、母亲未出嫁时的名字等等。

  

这里建议大家收到此类邮件时，不要点击邮件内容，并手动打开浏览器，输入“paypal.com”，并验证自己的账户是否有问题。
