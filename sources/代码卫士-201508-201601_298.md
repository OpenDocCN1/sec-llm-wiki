# 尽快修复思科ASA：当心DNS、DHCPv6、和UDP数据包

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485861&idx=5&sn=b9414b8dc54c7a7da8dded2f818ad530&chksm=ea9738cfdde0b1d944b475bf9a9eef87b4aefcc6d11a5544f902c546cd03e2a1530cd7765b79&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485861&idx=5&sn=b9414b8dc54c7a7da8dded2f818ad530&chksm=ea9738cfdde0b1d944b475bf9a9eef87b4aefcc6d11a5544f902c546cd03e2a1530cd7765b79&scene=27#wechat_redirect)

思科发布了一个固件更新解决在ASA（适应性安全产品）中出现的四个可导致DOS攻击的安全漏洞。

  

如果这些漏洞被利用，ASA家族中的六个模型就会被不断强制重启，导致该硬件无法使用。容易受攻击的产品包括：Cisco ASA 1000V CloudFirewall、Cisco ASA 5500 SeriesAdaptive Security Appliances、Cisco ASA 5500-X SeriesNext-Generation Firewalls、Cisco ASA Services Modulefor Cisco Catalyst 6500 Series Switches and Cisco 7600 Series Routers、Cisco Adaptive Security VirtualAppliance (ASAv)、以及 Cisco Firepower 9300 ASASecurity Module。

  

这四个漏洞的CVE编号如下：

l CVE-2015-6324：在带有DHCPv6继电器功能的设备中存在，允许攻击者通过特别编制的DHCPv6数据包重置设备。

l CVE-2015-6325：也是一个DNS处理错误，导致设备受到恶意DNS数据包的攻击从而被重置。

l CVE-2015-6326：与DNS数据包不正确处理相关的DoS漏洞。

l CVE-2015-6327：存在于ASA内部密钥交换中的漏洞，允许攻击者发送编制的UDP数据包，从而强制目标设备重置。

 思科表示，网络管理员应当尽快查看安全公告并尽快安装这些补丁。
