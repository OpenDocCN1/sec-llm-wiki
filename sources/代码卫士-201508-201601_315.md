# 微软为.NET Core、ASP.NET Beta推出漏洞奖励计划

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485864&idx=4&sn=5d906c564b951353af1a15419fab836c&chksm=ea9738c2dde0b1d46686ce3fd34b9a9c27b43b8d812d7e07112080efada6f55e8d8156d7af60&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485864&idx=4&sn=5d906c564b951353af1a15419fab836c&chksm=ea9738c2dde0b1d46686ce3fd34b9a9c27b43b8d812d7e07112080efada6f55e8d8156d7af60&scene=27#wechat_redirect)

**微软周二公布推出包含****.NET****核心和****ASP .NETBeta****的漏洞奖励计划，并表示二者是****VisualStudio Development Suite****的关键支柱。**

该漏洞奖励计划的公布发生于微软公布ASP .NET 5 Beta 8不久之后。不过，微软指出这个新的漏洞奖励计划将会覆盖所有的试用版并会在2015年10月20日至2016年1月20日之间推出最终版本。

  

在.NET核心运行即“CoreCLR”和ASP .NET 5技术预览中发现漏洞的研究人员均可获得500至15000美元的奖励，数额由所报告问题的质量和复杂度决定。微软表示在一些情况下可能还会提供更高的奖励。

  

可获得奖励的漏洞包括远程代码执行、安全设计缺陷、权限升级、远程拒绝服务、篡改和欺骗、信息泄露、和跨站点脚本和跨站点请求伪造问题。所有的漏洞报告必须附有PoC。

  

微软计划为安全设计缺陷和权限升级问题支付最多1万美元的奖励、拒绝服务和欺骗/篡改漏洞最多奖励5000美元、信息泄露最多奖励2500美元、跨站点请求伪造和跨站点脚本漏洞奖励2000美元。

  

微软安全响应中心团队指出，“这个漏洞奖励计划很有意思，因为包含在.NET中的库和功能能够让开发人员非常安全稳定地写入自己的程序，尤其是在许多操作系统中。这个漏洞奖励计划涵盖在Windows、Linux、和OS X上运行的CoreCLR和ASP .NET 5。不过微软指出Linux和OS X上的网络堆栈在达到稳定性和安全性之后会在随后的版本中推出，目前存在于Windows上。

  

微软已对漏洞奖励计划作出了重大改变。8月份，公司宣布为犯利用技术提供双倍奖励，而且在线服务漏洞奖励计划将会包含微软账户。此外，微软宣布将在一段时间内会为在线服务中的验证漏洞提供最多3万美元的奖励。
