# 道琼斯指控俄罗斯黑客组织偷窃其内部交易消息

道琼斯公司宣称其服务器被黑客入侵，且内幕交易信息被盗。

  

据上周五彭博社报道，FBI和美国金融监管机构美国证券交易委员会(SEC)以及美国特勤处对俄罗斯黑帮进行调查指控，认为其从道琼斯电脑偷窃了未公布的金融数据和新闻消息，从而获得市场优势。

  

彭博社在报道中引用了四个匿名消息来源，其中一个来源表示入侵发生于一年多年前。道琼斯通讯副总裁 ColleenSchwartz表示，“据了解，我们没有收到任何这样事件的官方消息，我们正在调查报道是否属实。”

  

上周道琼斯不得不承认他们的订阅系统确实被不法分子入侵，有3500名用户的个人信息被偷窃。

  

今年8月FBI对一个乌克兰黑客组织展开攻击，并在美国东海岸抓捕了9人。该团队被指控在几年时间里已从美通社和美国商业新闻社的服务器端偷窃了15000条还未公布的消息，目的是保证在股票市场上获得有利优势。
