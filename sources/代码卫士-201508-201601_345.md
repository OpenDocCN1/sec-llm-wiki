# 安卓广告软件再次攻击谷歌应用商店

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485871&idx=2&sn=b660c8237ace4b617feb1b2e1dd414b2&chksm=ea9738c5dde0b1d3cbad83ad113b2db723f33d7d74b647b65b61c579b6d72a4f22f0ac4dde84&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485871&idx=2&sn=b660c8237ace4b617feb1b2e1dd414b2&chksm=ea9738c5dde0b1d3cbad83ad113b2db723f33d7d74b647b65b61c579b6d72a4f22f0ac4dde84&scene=27#wechat_redirect)

**ESET****又发现了一起针对谷歌应用商店的恶意活动，攻击者再次在看似合法的****app****中伪装成广告软件实施攻击。**

这种技术压根没什么好说的，也并不少见，网络犯罪分子似乎并不打算在未来对该技术进行进一步的改造。跟之前许多情况一样，利用其它成功app的app多半包含可疑情况，有三种情况也是如此：Cheats for Pou、Cheats for Subway、和Guide for Subway。这三款app包含一种恶意软件，会在每30或45分钟全屏显示插播式广告。

这些app包含多种保护措施以此绕过谷歌的Bouncer app检查系统，同时组织恶意软件元件在模拟环境中运行。

安全研究人员设法利用简单重启模拟环境的方法绕过了这些保护措施，这样就暴露了恶意软件组件并允许研究人员追踪其行动以便识别出类似感染。这三款app已通知给谷歌工程师，且已从应用商店中下线。
