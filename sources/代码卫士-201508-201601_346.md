# WordPress遭受暴力放大攻击 数千博客受影响

多数情况下，我们所见的是WordPress插件易受攻击的案例，不过这次来自Sucuri公司的研究人员在这个最流行的CMS（内容管理系统）平台上发现了暴力放大攻击。

  

研究人员发现一种可在WordPress内置XML-RPC功能上实施暴力放大攻击攻陷管理员凭证的方法。XML-RPC是计算机在网络上安全地交换数据最为简单的方法之一。它使用system.multicall方法允许应用程序在没有HTTP请求的情况下执行多个命令。许多CMS包括WordPress和Drupal都支持XML-RPC。

  

不过，这种方式也被用来放大暴力攻击，仅在一个HTTP请求内尝试数百个密码，且不必冒着被检测到的风险。

  

**放大的暴力攻击**

也就是说不必通过登录页面尝试数千个用户名和密码组合（通常IP会遭禁止从而轻易被拦截），黑客就能利用XML-RPC协议和system.multicall方法：

  

l 常规的暴力缓解产品无法检测到

l 在为数不多的XML-RPC请求下尝试上万个用户名和密码组合。

安全研究人员表示，“需要3个或4个HTTP请求，攻击者就能够尝试数千个密码，绕过旨在寻找和拦截暴力尝试的安全工具。”Sucuri公司在上月初发现了首个此类攻击，而在本月初此类攻击已骤升至每天6万次。

  

**如何通过****XML-RPC****阻止暴力放大攻击？**

要阻止此类威胁，只需拦截所有对XML-RPC的访问。

  

如果你使用的插件没有使用xmlrpc.php文件，那么只需更名/删除它。不过如果你使用诸如JetPack的插件，那么拦截xmlrpc.php可能会导致一些站点的功能崩溃。

  

 所以，网络管理员能够通过WAF（网络放大防火墙）来拦截XML-RPCsystem.multicall请求，从而免受放大攻击。
