# OPM入侵事件导致560万美国人指纹信息被盗

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485876&idx=4&sn=e20ba015a283a30d73675818bb63d8be&chksm=ea9738dedde0b1c8fb0ea7447fb289a549581eff0e148075aa5ebc5071a55ac59d096411e45f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485876&idx=4&sn=e20ba015a283a30d73675818bb63d8be&chksm=ea9738dedde0b1c8fb0ea7447fb289a549581eff0e148075aa5ebc5071a55ac59d096411e45f&scene=27#wechat_redirect)

**美国人事管理局（****OPM****）安全事件正在发酵成为美国史上最大的入侵事件之一。美国国防部指出，除了****2100****万美国政府官员的信息被泄露外，还有超过****560****万员工的指纹信息被盗取。**

最初报道指出，OPM入侵事件影响了约110玩命人员，随着时间的推移，这个数字增长为400万、1800万，而最近的官方声明中又增长为2100万。

  

OPM内部安全团队和美国国防部的调查显示，黑客入侵的服务器中还包含生物识别数据和指纹等。FBI官员指出，虽然目前来看这些数据并无任何损害， 但可能会被用于未来的恶意互动中，因为指纹识别在未来将替代密码的作用。例如Apple已在iOS 9中使用了Touch ID系统。

  

除了电话和平板电脑外，这一技术还会用于网络银行服务中，为黑客提供了更加安全和快速的验证方式，并减少了许多当前入口点。黑客通常会针对用户的字母数字密码发动攻击。

  

以上是OPM入侵事件的最新进展。后续可能会有更多相关情况报道。
