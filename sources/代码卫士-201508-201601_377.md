# 用App测智商？百万安卓用户掉陷阱

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485878&idx=6&sn=61de9ece40723bbe0c62f0aff6fdb24d&chksm=ea9738dcdde0b1cab0cd1dc98f5397193f1fbca271c00d1ab0cb7011aa1343cb9657c9ef0fe9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485878&idx=6&sn=61de9ece40723bbe0c62f0aff6fdb24d&chksm=ea9738dcdde0b1cab0cd1dc98f5397193f1fbca271c00d1ab0cb7011aa1343cb9657c9ef0fe9&scene=27#wechat_redirect)

**一款名为“大脑测试（****Brain Test****）”的恶意安卓****app****成功避开谷歌应用商店的检测，并设法感染了约一百万用户。**

Check Point安全公司的研究人员表示，这款app起初是在一款Nexus 5设备上发现的。由于机主无法卸载这款恶意app，于是公司决定查看感染来源。研究员对Brain Test app进行逆向工程后发现了一款设计精良的恶意软件，允许攻击者将用户手机重启、甚至达到不断重启的地步，并在手机上安装第三方app。

  

**Brain Test****具有复杂的检测逃避系统**

研究人员经过进一步分析后发现了一个复杂的系统，允许恶意软件逃避谷歌自动app检测系统Bouncer的检测。这款恶意软件包含的代码如果发现自己在某个IP地址范围内运行，或者某些域名中包含”google”、”android”、和”1e100”就会停止执行。

  

设法绕过Bouncer的检测并安装到用户手机后，Brain Test就会在用户首次运行时执行一个定时炸弹函数。这个函数会推迟20秒执行，每两个小时执行一次，而且会缓慢下载并通过一系列链接利用解压获取根许可必要的代码。

  

**恶意软件孪生兄弟**

重启一旦结束，Brain Test就会安装一款名为brother.apk的应用。brother.apk会不断检查Brain Test是否被安装和重启。如果这两款app中有一款被删除，每隔两个小时另外一款就会将其重新安装。

  

两天前，Cheetah Mobile公司的安全研究人员发现了一款类似的且导致设备不断重启的安卓恶意软件Ghost Push，不过它是通过全球多种非官方应用商店进行传输的。

  

安全研究人员并未具体说明这款app的功能，不过鉴于它与命令和控制服务器通信并拥有根权限，攻击者可能用它来执行大规模的攻击，而且这些攻击无需任何形式的用户交互。

  

Check Point于9月10日将这款恶意app告知谷歌，后者在五天后将其下架。不过几天后它又卷土重来。
