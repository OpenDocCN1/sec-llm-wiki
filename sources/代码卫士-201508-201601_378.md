# 安卓恶意软件攻陷在线银行账户并隐藏短信提醒

**Dr. Web****发现一款新的安卓恶意软件，它能够从在线银行账户窃取钱财，并隐藏用来证实金融交易信息的短信提醒。**

这款恶意软件名为Android.SmsBot.459.origin木马，通过垃圾短信感染用户。这条垃圾信息包含一个链接，如被打开就会强制用 户将该木马的APK文件下载到用户设备上。不过真正被感染需要点击并打开这个APK文件，因此如果有网页将一款安卓app下载到你的手机上但并不会询问任 何问题，那么千万不要打开它！

  

**木马伪装成合法****app**

对于那些不幸打开APK文件的人来说，这款木马会将自己伪装成来自知名来源的app，而在本案例中，它伪装成俄罗斯一家广告网站的客户端app。

  

如果用户同意安装，这款app就会立即要求获取管理员权限，声称目的是“获取视频编解码器访问权限”。这条信息非常强硬而且知道用户点击“激活”后 才会消失。一旦成功安装并且获取管理员权限，这款木马就会开始和命令和控制服务器运行。它做的第一件事是发送所有关于用户手机的详细信息，包括IMEI、 型号名称、系统语言、移动号码、OS版本等等。

  

**恶意软件目前针对俄罗斯用户**

命令和控制服务器接收到这些数据后，这款木马就会下令扫描一个银行应用列表。目前来看，这款木马只是扫描与俄罗斯银行相关的app。如果发现银行app，木马就会通过预配置操作获取用户账户余额并查看是否有可用资金。

  

通过特殊的命令和短信信息，木马随后会启动金融交易，窃取受害者钱财并将账户金额转移到由攻击者控制的账户。为了隐藏这些动作，木马会隐藏银行发送给用户的所有短信提醒。

  

**狡猾的木马隐藏短信提醒**

即使谷歌工程师设法不让短信隐藏，木马作者也会通过禁用语音提示、在接收到提醒后将短信上传至命令和控制服务器、并在用户意识到之前将信息删除的方式绕过。

  

由于木马的隐藏性极高，如果用户没有安装移动杀毒软件，就很难发现。这款安卓恶意软件会带来更多的问题，如果它应用到西方国家，或者找到其它更加隐蔽的安装方法。
