# FBI推卸物联网安全责任

美国联邦调查局FBI认为，物联网设备风险太大而不能允许随便进入互联网。

  

不过鉴于物联网由世界上最大的几个技术供应商支撑，FBI认为物联网安全责任应该由技术界的霍默·辛普森（不会做任何事情）承担。9月10日FBI 发布了公共服务公告，几乎将所有的消费者保护责任推给了消费者。FBI指出物联网设备中包含的漏洞包括UPnP漏洞、未经修改的默认密码、拒绝服务攻击、 以及使用控制器引起“物理性的伤害”或者干扰商业交易。从闭路式的电视到无线电视、恒温控制器、车库门、电视、家庭医疗保健等都被认为是不安全的。

  

听取FBI的建议避免意外发生对赞助商来说简直就是诅咒，因为FBI估算物联网中最不需要的就是互联网，如公告中指出的“隔离的物联网设备保护网络”。

  

因此，通用的即插即用设备UPnP应该被禁用，特别是路由器，补丁也应该及时更新。出于某些原因，联邦政府工作人员认为户主将有能力“意识到安装在他们家庭和企业的设备和电器的性能”，不过更改默认密码的建议倒是明智的。

  

FBI也关注医疗设备的安全——尽管它又一次将责任推给了病人，而不是告诉业界要挥别他们一向马虎的做法。
