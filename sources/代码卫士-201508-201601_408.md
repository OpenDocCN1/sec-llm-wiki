# 美能源部2010至2014年间被黑159次

**相关数据表明，美国能源部是遭受网络攻击次数最多的美国政府部门。**

美国能源部管理的信息对攻击者来说具有重要的战略意义，它监督电网、核军火库以及国家实验室的运作。数据表明，能源部在2010年至2014年间被攻击了159次。专家指出在48个月内，能源部就遭受了1131次尝试性攻击，其中159次攻击是成功的。

  

能源部官员并未透露与网络攻击相关的其它信息，尤其是与国家电网或核武器储备被访问或被盗相关的数据类型和数量信息。

  

能源部因管理着国家关键基础设施而被认为是具有战略性的攻击目标。而攻击所用的技术似乎表明攻击者来自由国家支持的APT组织。以下是美国国土安全部ICS-CERT于3月份发布的自2014年9月至2015年2月期间的监控报告。

  

报告指出，ICS-CERT在2014财年收到并响应了245起事件，其中过半是由资产所有者和工业合作伙伴报告的。ICS/SCADA系统同时遭受到其它类型威胁的攻击，包括网络犯罪分子、内部威胁发动者、以及黑客主义者。
