# Apple将密码默认设置改为6位数以增强安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485886&idx=1&sn=781bc79fcadb203824b8158601982989&chksm=ea9738d4dde0b1c29e3714d14bed1297d90912b4c501ee488ef061ee04cc85580d0d61397eaa&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485886&idx=1&sn=781bc79fcadb203824b8158601982989&chksm=ea9738d4dde0b1c29e3714d14bed1297d90912b4c501ee488ef061ee04cc85580d0d61397eaa&scene=27#wechat_redirect)

Apple新发布的iPhone跟iPad移动操作系统改进了一项安全功能：用户密码默认设置为6位数。虽然这一动作似乎并不是什么大事，但它实际上增加了密码破解的难度。密码设置组合从4位数改为6位数，意味着密码组合从1万种可能性上升至100万种。

  

这一举措对于在安全方面已如履薄冰的企业来说无疑是一记重锤。IBM对100万种BYOD及企业发布的设备进行研究后发现，几乎90%的公司仅要求 输入一个简单的数字密码，80%的公司要求输入四位数字密码，而这些密码可在20分钟内遭破解。而六位数的密码组合能让破解速度放缓至数天的时间。而这也 是为何要升级至iOS 9的重要原因之一。据悉iOS 9将于9月16日发布且供免费下载。
