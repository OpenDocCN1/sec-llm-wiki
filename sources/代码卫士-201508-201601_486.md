# 丧钟为谁而鸣：亚马逊也宣布放弃Flash广告

零售巨头亚马逊宣布放弃Flash广告并表示原因是这些广告被越来越多的浏览器拦截。

  

亚马逊的这一决定至少受到其他公司认为Flash广告一直不安全看法的影响，亚马逊宣布从9月1号开始不再使用Flash的广告。

  

亚马逊官方公告指出，“（决定）受到近期谷歌Chrome浏览器的设置更新，以及火狐浏览器、苹果浏览器Safari现有的浏览器设置影响，它们都限制在网页中所显示的Flash内容。”

  

换句话说，由于早前微软决定Flash不能播放或者不会自动播放，因此亚马逊想要避免用户收到浏览器关于插件的恼人信息。

  

Flash臭名昭著的安全漏洞，使得用户、安全专家和浏览器供应商对其好感尽失。Adobe正面临着两难的处境：坚持为这一平台而战，还是放弃。
