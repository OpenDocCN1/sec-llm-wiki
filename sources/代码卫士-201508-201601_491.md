# 双因素认证新玩法：语音面部识别双管齐下

Sensory公司本周四宣布称他们开发出一款结合语音及面部识别技术的生物特征验证方法，名为TrulySecure，可保护智能手机或平板电脑数据不被窃取。目前该产品已由在线快速识别联盟（FIDO）颁发证书。

  

与其它依赖单个生物特征识别检测不同，TrulySecure能够同时实施两种识别。设备摄像头用来验证面部身份而话语（说出之前预设的解锁命令）可解锁app。

  

Sensory表示用户可以选择凭借其中一种生物识别验证方法来解锁app，不过也可以同时使用这两种。Sensory表示所开发的软件非常智能，可辨别出照片跟在摄像头面前真人的区别，这一点之所以重要是因为它可抓拍真人照片作为安全应变措施。

  

所有的验证数据都存放在设备本地，因此无需云组件，用户可以在没有网络连接的情况下方便地访问app。目前Sensory已将这款app发布在Google Play上供用户免费下载使用。
