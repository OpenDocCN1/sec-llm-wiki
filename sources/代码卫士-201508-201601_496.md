# WordPress 4.3版本提高密码安全性

代号为“Billie（为纪念爵士歌手Billie Holiday）”的WordPress 4.3版本目前可下载使用。这个最新版本为网站管理人员及开发人员都推出了新功能，此外还改进了密码安全性。

  

4.3版本做出的改进如下。当管理人员创建了新的用户账户后会自动生成强密码。而且修改密码时会出现密码提示并与用户确认密码强度的选择。生成的密 码默认不会显示给管理员而且密码重置连接会发送至用户邮箱。点击按钮会将密码发送给管理员，允许用户通过即时消息app接受WordPress生成的密 码，且同样适用于非邮件环境。

  

明文密码不再通过邮件发送给用户以保证WordPress账户在邮箱被攻陷的情况下依然安全。此外，密码重置连接默认仅在24小时内有效。开发人员表示虽然这种修改看上去很小，但却极大地增强了默认用户行为的安全性。

  

当密码或电子邮箱地址有变化时，用户会收到一份邮件警告。这样，如果浏览器会话被恶意劫持、邮箱地址或密码被修改，用户也能够快速采取应对措施。WordPress开发人员表示，邮件警告功能可通过设置过滤器来禁用。

  

WordPress一名核心开发人员表示，虽然WordPress无法阻止用户选择糟糕的密码，但4.3版本默认用户会得到安全的密码，而且也会弱密码的使用增加了成本。
