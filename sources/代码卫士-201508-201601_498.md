# 谷歌发布更快更安全更易用的智能路由器OnHub

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485901&idx=1&sn=a003dbeace9f79c965145cb5a651cd4a&chksm=ea9738a7dde0b1b1380b6211ceb4b2623a5594ea4cc3ad528742bd639abbea42f71f784f78e3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485901&idx=1&sn=a003dbeace9f79c965145cb5a651cd4a&chksm=ea9738a7dde0b1b1380b6211ceb4b2623a5594ea4cc3ad528742bd639abbea42f71f784f78e3&scene=27#wechat_redirect)

谷歌发布新硬件产品OnHub，为人们提供更加安全易用的接入点设备。OnHub产品经理指出，许多用户在设置WiFi的过程中把很多的时间浪费在 “插拔电源线上、解读闪烁的灯光上或者打电话给客服上”。为了解决这一问题，谷歌跟硬件合作伙伴TP-LINK携手推出接入WiFi的新型路由器 OnHub，它是一款更快、更安全、更易用的路由器。

  

谷歌通过自动更新的方式确保OnHub的安全性。通常情况下被修复的路由器安全漏洞依然会存在于固件中，原因是厂商从来不会更新过时的设备。而且即 使厂商发布了补丁，毫无头绪的用户及忙碌的网络管理员也不会淘汰老旧但依然能用的设备。这样就产生了安全事件，但不幸的是安全从来就不是任何人首先考虑的 因素。

  

**OnHub****提高无线网络速度**

OnHub只有更新到最新最安全的版本时才会运行，这跟谷歌更新Chromebooks很像。谷歌将其作为消费者设备推出，而且可在安卓或IOS程 序或云端由谷歌管理。也就是说即使用户离WiFi范围有数百英里，也可以管理OnHub。虽然该设备还未定下基准，但它已准备好出发。OnHub拥有12 根天线：6根5GHz和6根2.4GHz。同时它还拥有一个2.4GHz反射器将信号发送给寻求速度的设备及app。此外，设备还配有一根接入个人区域网 络的802.15.4以及蓝牙。

  

OnHub不仅支持802.11无线标准的全部范围、802.11b、以及802.11ac，还支持Nest Weave、802.15.4以及蓝牙。此外，OnHub还会一直扫描802.11的家族2.4Ghz以及5GHz频率。当发现有信道超载时也就是用户设 备性能变差时，他会自动转换至最不拥挤的信道。

  

为OnHub提供支持的是Snapdragon ARM处理器Qualcomm IPQ8064，由1GB的RAM以及4GB的flash存储支持。虽然谷歌未提及其操作系统，但可能是基于Chromium 操作系统。

  

目前OnHub已开售，建议零售价为199.99美元。
