# 谷歌将Pirate Bay标记为恶意软件网址

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485668&idx=3&sn=a24548161be9e4d74ab94f4a2df24577&chksm=ea97398edde0b098bbc9819222e0dd80a875a32f48970a886f1d45b39d8d19929b19393082c6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485668&idx=3&sn=a24548161be9e4d74ab94f4a2df24577&chksm=ea97398edde0b098bbc9819222e0dd80a875a32f48970a886f1d45b39d8d19929b19393082c6&scene=27#wechat_redirect)

**谷歌警告用户远离声名狼藉的未经授权的内容分发网站Pirate Bay，否则将会对PC端有损害。**

  

谷歌公司之前一直回避将该网站标记为恶意网站，虽然它曾多次为广告恶意软件提供服务。

  

“该网站的攻击者会试图诱骗你下载软件或者偷取你的信息，比如密码、短消息、或者信用卡信息。”谷歌在安全浏览检查中发出警告。

  

使用chrome浏览器访问该网站的用户会看到谷歌的恶意软件死亡红屏，需要绕过警告才能访问Pirate Bay。

  

Pirate Bay网站托管着各种各样的广告。其中很多链接是与投资以及感染用户设备相关的诈骗网站。

  

谷歌上个月将该网站标记为恶意网站。

  

但谷歌尚未将Pirate Bay的对手Extra Torrent标记，该网站支持VPN匿名广告。
