# 警方提醒：不要将捡到的U盘随便插入电脑

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485676&idx=3&sn=6d63c44f99fd6e8814c7a0008047b49c&chksm=ea973986dde0b090f65568ad1f5017e61891b38f9eaee024cb38e5a10fc8e0a1345fb94f096e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485676&idx=3&sn=6d63c44f99fd6e8814c7a0008047b49c&chksm=ea973986dde0b090f65568ad1f5017e61891b38f9eaee024cb38e5a10fc8e0a1345fb94f096e&scene=27#wechat_redirect)

**澳大利亚警方在维多利亚警署（澳大利亚国家级警署部门之一）的官方网站发布警报，不要将邮箱中莫名其妙出现的USB拇指驱动器插入电脑。否则会产生严重后果。**

近期位于墨尔本东南56公里，人口仅3万的小镇帕克南（Pakenham）发生了此类事件。攻击者在USB中植入银行木马。

  

据2015年10月的一项研究表明，五个美国城市的17%用户会毫不犹豫将在大街上捡到的USB插入自己的电脑。

  

2016年4月，一名安全研究人员受到美剧《黑客军团》（Mr. Robot）的启发，将300个U盘丢在了伊利诺伊大学厄巴纳 - 香槟分校的校园街头。最后发现有98%的U盘被捡走，48%的用户试图访问设备，点击U盘里的文件。

  

上个月香港一家公司开始出售能够将任何计算机短路的U盘，所以用户在捡到U盘时应当慎重对待。
