# 谷歌修复Nexus 5X中漏洞，攻击者可通过USB黑进手机内存

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485688&idx=2&sn=8a7d2b1e1e6ed088d8084ec2c4225183&chksm=ea973992dde0b08478a69248c8d2921004ad415c9e8e29ee52e869068be0b43867b0e556a625&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485688&idx=2&sn=8a7d2b1e1e6ed088d8084ec2c4225183&chksm=ea973992dde0b08478a69248c8d2921004ad415c9e8e29ee52e869068be0b43867b0e556a625&scene=27#wechat_redirect)

**谷歌已修复Nexus 5X 中一个漏洞，该漏洞会导致攻击者能够通过USB端口黑进手机内存，窃取敏感信息。**

该漏洞由IBM的X-Force团队发现，影响LG Nexus 5X安卓设备的图库。漏洞版本为6.0 MDA39E 到6.0.1 MMB29V。

谷歌在Nexus 5X安卓图库MHC19J版本中修复了该漏洞。

IBM表示，该漏洞很容易开发，但攻击面较小。只可攻击打开了Android Debug Bridge (ADB)功能的Nexus 5X设备。

无需物理访问。攻击者可以通过恶意软件感染Nexus 5X用户的PC或者智能充电器。当用户将手机连接到电脑或者充电器（使用USB线）时，恶意软件能够利用漏洞黑进设备的内存。

恶意软件向ADB终端发送指令，强制系统重新启动。随后恶意软件使用其他工具提取手机内存数据，研究人员发现可以在内存中恢复设备测试过程中设置的密码。

当然也可进行物理访问，但需要手动发送指令，而不是像上面提到的恶意软件使用自动化脚本。

幸好攻击面小，受到影响的设备并不多。该漏洞已于3月份修复，Nexus用户有足够的时间更新设备系统。
