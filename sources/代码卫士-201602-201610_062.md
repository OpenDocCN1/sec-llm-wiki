# 里约奥运会期间DDoS攻击最高峰值达540Gbps

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485689&idx=1&sn=b6ebd00c31c96bfbb246ed593eb50d5a&chksm=ea973993dde0b085e20ab57dbe8e2658513130472befacf8666915e2fb5f245e1aa6dba4e102&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485689&idx=1&sn=b6ebd00c31c96bfbb246ed593eb50d5a&chksm=ea973993dde0b085e20ab57dbe8e2658513130472befacf8666915e2fb5f245e1aa6dba4e102&scene=27#wechat_redirect)

**据Arbor网络的遥感数据显示，里约奥运会期间黑客活跃达到前所未有的程度。**

网络安全运营商表示在奥运会的两周时间，DDoS攻击量达到历史最高平均值，平均每日攻击量超过500Gbps，峰值达到540Gbps。几乎接近Arbor网络6月份检测到的历史最高纪录为579Gbps。

**匿名者促成了如此庞大的DDoS活动**

这样的现象大部分归因于匿名者组织的黑客行动，名为#OpOlympicHacking。此次行动非常受欢迎，黑客甚至还特制了一款Windows应用程序，用户可以在PC端安装程序，并使用自己电脑的资源和带宽参与DDoS攻击。

由于巴西政府举办了2014年的世界杯和2016年的里约奥运会，给民众带来极大不满，从而为此次黑客活动在巴西国内积累了大量支持。

巴西人民不满政府斥巨资举办这两场盛大活动，而忽略了在教育、医疗、或者其他更重要和急需领域的投资。

**DDoS种类齐全**

从技术层面来讲，Arbor透露多数攻击都使用了一款名为LizardStresser的工具。这款工具去年由蜥蜴队开源。

根据记录显示存在反射攻击，这表明还有其他类型的僵尸网络存在。攻击的很大一部分由反射攻击载体如DNS、Chargen、NTP和SSDP组成。

还有使用UDP和TCP SYN包进行的洪水攻击。同时还有针对web和DNS服务器的应用层攻击。

**DDoS攻击使用GRE协议**

这次里约DDoS攻击还看到了通用路由封装（GRE）协议重出江湖。

多数受到攻击的对象是和奥运会相关的机构，并且有些攻击在开幕式之前就开始了。
