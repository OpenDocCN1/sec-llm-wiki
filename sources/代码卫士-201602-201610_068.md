# 攻击者“发明”劫持chrome浏览器的新方法

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485691&idx=3&sn=c7dd65a16a86b71097ac18801f5e44af&chksm=ea973991dde0b087af84b8693c7191d2833563551abe852330e95b07639c9a77368549acfafc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485691&idx=3&sn=c7dd65a16a86b71097ac18801f5e44af&chksm=ea973991dde0b087af84b8693c7191d2833563551abe852330e95b07639c9a77368549acfafc&scene=27#wechat_redirect)

**攻击者已找到一种新的方法来欺骗不知情的用户，即利用特制图片和chrome浏览器的全屏模式。**

他们的新方法依赖于模仿微软官方网站的视觉风格制作新的技术支持页面。

当用户通过chrome访问该网站时，隐藏的JavaScript代码偷偷将用户的浏览器切换到全屏模式——浏览器的UI工具栏包括地址栏被隐藏，攻击者在页面的顶部加载一个JPEG图片，看起来很像chrome的原始UI工具栏。

除非用户使用的是某种自定义的chrome主题，其UI设计与普通的chrome版本不同，或者在页面的顶部移动鼠标。否则用户无法辨别出异常。

**骗子还会利用弹窗欺骗用户**

Malwarebytes团队还发现另外一种欺骗chrome用户的手段。

攻击者模仿chrome警报弹窗，询问用户是否需要“prevent this page from creating additional dialogs.”（防止此页面创建额外的对话框）。

但当用户选择了相应的标记后，又会出现越来越多的警报弹窗。

攻击者希望看到的是，当chrome检测到页面滥用了JavaScript警报，并显示出真的“Prevent this...”弹窗，用户会产生怀疑，不再做选择，或者按“OK”，给他日后显示更多弹窗的机会。

目前这样的虚假网站不止有10或者20个，每个团伙通常都有成百上千个域名。

例如，由MalwareHunterTeam发现的骗子注册了超过200个域名，在过去的四个月里都在使用。

浏览器通常要花10个小时才能检测到威胁并做适当标记。另外，一些网站托管公司也难辞其咎，因为他们往往要花数月才对安全研究人员所提交的报告作答复。
