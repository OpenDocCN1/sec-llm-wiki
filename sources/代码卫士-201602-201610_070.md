# 新的W3C Proximity Sensor API可用于识别用户

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485692&idx=2&sn=e0ad38a682a33182178c6a354d347ae1&chksm=ea973996dde0b08031b6648a0286a0f78ae6bb2e4a315b1745efa61cee197858215379d01d92&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485692&idx=2&sn=e0ad38a682a33182178c6a354d347ae1&chksm=ea973996dde0b08031b6648a0286a0f78ae6bb2e4a315b1745efa61cee197858215379d01d92&scene=27#wechat_redirect)

**目前由万维网联盟（W3C）开发出一种新的API，名为ProximitySensor API，能够让网站和广告商查询您的智能手机或平板电脑附近物体的位置。**

随着移动设备及其技术的发展，当你将手机靠近耳朵拨打电话时屏幕通常会变黑，这是因为设备使用摄像头判断其是否在你耳边。

摄像头、运动传感器、加速度计等诸多高科技传感器可让智能手机、平板电脑或物联网设备知道你在房间的哪个位置、或者其他对象如墙壁、门窗等的位置。

由于这些传感器大多数都提供API接口，W3C开始研究通用的基于JavaScript的API，这将帮助网站查询你的设备的位置，并判断它离周围物体的距离。判断精度达到了厘米级别。

**新的W3C API可用于识别用户**

法国国家信息与自动化研究所（INRIA）安全与隐私技术工程师Lukasz Olejnik和W3C的特邀专家称这个新的API未来可能会对用户的隐私造成威胁。

Olejnik称攻击者可以在网站上嵌入（恶意）代码，得到有关手机用户及其行踪的信息。这些数据可以被用于识别用户，广告商对可能对这项技术非常感兴趣。

攻击者可以利用W3C Proximity Sensor API 收集用户如何与设备进行交互的信息、交互的频率、交互模式等。

**Olejnik：没有必要计算详细的距离**

新的Proximity Sensor API 提供了两种查询模式，一种只显示“近”或者“远”的提示，另一种会详细计算到厘米。

Olejnik表示第二种查询模式没有必要存在。除此之外，INRIA研究人员建议新API应该征得用户的允许。设备必须询问用户是否可以采集数据，用户应该有权查看哪些网站使用了这款API，以及使用的频率。

目前最新版本的W3C Proximity Sensor API已采纳了第二个建议，但第二种查询方式（冗余计算结果）仍然会保留。
