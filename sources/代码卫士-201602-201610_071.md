# 金融机构数据泄露原因调查：1/4源于丢失的手机和笔记本电脑

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485693&idx=1&sn=0fd3fb788fd7923d5c2b348361dd0f5f&chksm=ea973997dde0b081ba86c3824fec8a588a8b047ed9acbd76e83700e4ec3ad7b93a0970998aab&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485693&idx=1&sn=0fd3fb788fd7923d5c2b348361dd0f5f&chksm=ea973997dde0b081ba86c3824fec8a588a8b047ed9acbd76e83700e4ec3ad7b93a0970998aab&scene=27#wechat_redirect)

**据最新的调查显示，近几年美国金融机构的数据泄露有1/4（25.3%）是源于丢失或者被偷的设备。**

云安全公司Bitglass进一步报告说，近10年间的数据泄露有1/5是源于黑客攻击。

有60多家金融部门组织在过去10年间数据遭受过泄露，包括大多数的主要银行。

尽管网络攻击占到数据泄露相当大的比例（1/5）。其他原因也占有相当比例，有意外泄露（14%）、内部威胁（13%）、以及丢失的设备等。

2015年，有87起金融服务机构的数据泄露事件发生，而2014年只有45起。2016年上半年，已有37家银行发生了数据泄露。其中1/7（14%）归因于意外泄露，约13%归因于内部威胁。

美国最大的银行摩根大通银行，自2007年至今已遭受过数次数据泄露。最严重的一次发生在2014年，网络攻击影响了7600万户美国家庭。摩根大通银行的其他数据泄露的原因分别是设备丢失、意外泄露和支付卡欺诈。

Bitglass的报告分析基于2006年至今的金融服务机构的所有数据泄露事件，数据源于公共数据库和政府强制披露。

“金融机构是黑客攻击的首要目标，应当小心网络攻击、设备丢失和内部威胁带来的危害。”Bitglass的CEO Nat Kausik表示，“为了防止数据泄露，金融机构必须加密云端数据、进行控制访问、保护非托管设备上的数据。”
