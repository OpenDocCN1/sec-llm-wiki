# 破解面部识别系统的新方法

**北卡罗莱纳大学的计算机科学家设计出一种方法，可以使用照片、3D建模软件、VR（虚拟现实）设备绕过面部认证系统。**

面部识别是基于生物特征识别方法之一，它使用有关一个人的独特面部形状和特征数据，如眼睛、鼻子、嘴巴的深度以及它们之间的距离。

面部认证系统出现于上世纪90年代，从2000年开始备受追捧，相关的软件和硬件功能都更加强大。

对于面部识别系统的早期版本，科学家证明将一张照片放置在系统的摄像机前或者输入视频中，就可以通过系统认证。

**现代面部识别系统不再被照片欺骗**

为了对付这类攻击，很多企业在面部识别软件中考虑进行多种二次互动，例如要求用户眨眼或者执行其他操作，检测用户头部动作等。

因此，现代的面部识别软件更加强大，不会再被原始用户的一张照片糊弄。

但两周前，召开于美国的Usenix安全专题研讨会上，Yi Xu 等人提出了一种新的攻击现代面部认证系统的方法。

**VR设备可用于绕过面部识别系统**

研究人员开展了一系列实验，实验包括志愿者们和五个为手机或笔记本提供面部认证功能的应用程序。

研究人员要求志愿者在这五个APP上创建账户，使用照相机给他们拍照，并从他们的社交媒体账户上获取个人照片。

他们将照片传输到一个3D建模软件，这个软件使用特殊函数非常精确地创建了志愿者的头部模型。

然后将所得到的3D头部模型传输到VR设备中，研究人员将VR设备的屏幕放置到面部识别软件的前面。

**高分辨率的照片100%通过面部认证系统**

这五款被测试的APP分别是1U App、 BioID、 KeyLemon、 Mobius、 True Key。研究人员称使用照相机拍的志愿者照片成功通过了所有志愿者的账户认证。

而由于社交媒体上的照片分辨率比较低，所以认证通过率相对较低。

研究人员表示，使用高分辨率的个人在线照片，攻击者完全可以根据照片挖掘到充分的信息，并制作出假脸数据。最具鲁棒性的面部认证系统需要用户的配合，即图像不会被轻易印刷或者重构。
