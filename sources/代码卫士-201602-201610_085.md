# 比特币开源客户端或将遭“国家黑客攻击”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485697&idx=2&sn=0240dbdc7102cf7f8b69565887ba83cc&chksm=ea97386bdde0b17dfaf1db6d029635992266e62ee7586ed1da801d63d7a7bbfd89548bfbb126&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485697&idx=2&sn=0240dbdc7102cf7f8b69565887ba83cc&chksm=ea97386bdde0b17dfaf1db6d029635992266e62ee7586ed1da801d63d7a7bbfd89548bfbb126&scene=27#wechat_redirect)

**监督比特币软件开发的组织Bitcoin.org告警用户称国家支持的黑客很可能会针对即将发布的比特币开源客户端Bitcoin Core新版本发动攻击。**

Bitcoin Core用来验证块链和所有交易的有效性。Bitcoin Core 0.12.1版本发布于4月份，开发人员不久将发布新版本0.13.0。在本周三发布的安全事项中，Bitcoin.org表示有理由相信这个新版本的二进制将会受到国家黑客的攻击。该站点已为用户提供了一个加密密钥来帮助验证二进制的合法性。安全公告提醒比特币社区尤其是中国比特币社区从站点下载二进制时尤其要警惕，否则有可能失去所有的比特币。恶意软件可能会导致用户计算机参与到攻击比特币网络的阵营中。安全公告认为鉴于攻击者的来源，中国面临的风险最大。

安全专家指出，Bitcoin.org网站并未使用HTTP HPKP以允许管控证书颁发机构的政府为站点生成自己的证书。攻击者能够劫持站点IP并替换该站点提供的密钥。

比特币的热度和高价值引发了各路攻击者的青睐。几个月来多个比特币交易站点因遭受攻击而被迫关闭。例如，最近的受害者即位于香港的Bitfinex是全球最大的数字货币交易所之一。该公司价值数千万美元的比特币被盗，目前案件仍在调查中。
