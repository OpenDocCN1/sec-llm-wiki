# 一款安卓APP偷取用户的照片和视频

**赛门铁克安全研究人员在谷歌应用商店发现了一款安卓应用，会秘密地扫描和窃取用户设备上的私人照片和视频。谷歌已将这款应用移除。**

这款名为HTML Source Code Viewer的安卓应用程序由开发人员Sunuba Gaming开发。到谷歌移除它为止，安装次数为1000至5000次。

通过这款应用的名字也很容易理解，它能够帮助用户查看网页的源代码。用户只需要输入一个URL，应用就可以追溯到网站的源代码并打印到屏幕。

赛门铁克分析称，它不止可以做这些。应用内还包含可以扫描本地 "/DCIM/Camera" 和 "/DCIM/100LGDSC/"文件夹的代码。这两个文件夹是安卓设备默认存储图片和视频的位置。

随后将所有扫描到的数据更新到一个位于阿塞拜疆的在线服务器上。它的最新版本日期为2015年1月。赛门铁克研究人员已成功访问到服务器文件夹，找到了截止2015年3月的图片和视频。

这些私人媒体信息可以用于勒索、恶意软件攻击、身份盗窃、色情交易以及其他形式的伤害。
