# 微软扩展多因素验证解决方案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485730&idx=3&sn=2ccaef11c3eba2bedae07a59d007d3ac&chksm=ea973848dde0b15e71fe7f202719da46846610fbbaaa1824fb20fa3312490d47abe71c22443b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485730&idx=3&sn=2ccaef11c3eba2bedae07a59d007d3ac&chksm=ea973848dde0b15e71fe7f202719da46846610fbbaaa1824fb20fa3312490d47abe71c22443b&scene=27#wechat_redirect)

**上周，微软宣布改变****Win 10****的安全功能，包括扩展端对端多因素验证解决方案****Windows Hello****。**

Windows Hello与Microsoft Passport这两种技术旨在为人们访问基于活动目录/Azure活动目录的商业网络或多种面向互联网的商业相关服务时，提供一种能够减少密码输入的体验。访问Windows 应用商店、Outlook.com、OneDrive和Office 365时也可使用这两种技术，不过即将在八月初推出的Win 10周年更新项目将为这些技术带来一些变化。

首先，微软已加入FIDO（快速身份在线）联盟来构建一种基于跨平台和异构环境内的行业标准的解决方案。其次，Microsoft Passport将会退出，而其所提供的全部验证功能将会传递给Windows Hello，后者将成为微软的FIDO 2.0一致性端对端多因素验证解决方案。

当首次推出Win 10时，Windows Hello指的是用于验证用户身份和其它辅助性生物特征的因素。而Microsoft Passport是指通过两种及两种以上因素核实之后进行验证的凭证，不过这一功能将在八月初被赋予到Windows Hello中。

微软表示，该变化将为客户带来便利性，因为Windows Hello能够满足客户的所有验证需求。客户不会受到该变化的影响，因为它不会对配置或安全层面进行实质性修改。同时，客户能够获得不少安全方面的好处。微软表示，Win 10周年更新将会带来更加灵活的Windows Hello架构，包括将设备、PIN和生物特征作为验证因素选项，从而更加便于添加对新因素类型的支持。届时，用户能够添加各种设备如可携带设备和电话等远程访问自己的计算机并验证相关资源。

新的Windows Hello Companion Device框架允许外部设备当做验证平台的一种或多种因素。该框架将允许厂商推出两种类型的比较设备用于多种场景。
