# 黑客为五角大楼找出100多个漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485741&idx=3&sn=15d4ca20236141f21d3b5ded6f2f1eb8&chksm=ea973847dde0b1511f6be5298a168471ff4822385cc6b83527d5fdaa55d6f6ac8f28bcbf9ebe&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485741&idx=3&sn=15d4ca20236141f21d3b5ded6f2f1eb8&chksm=ea973847dde0b1511f6be5298a168471ff4822385cc6b83527d5fdaa55d6f6ac8f28bcbf9ebe&scene=27#wechat_redirect)

**白帽黑客已在五角大楼基础设施中找到****100****多个漏洞。大约有****1400****名黑客参加了****“****入侵五角大楼****”****漏洞奖励计划，该计划提供的最高奖金为****1.4****万美元。**

美国国防部长阿什顿·卡特表示，这个漏洞计划节约了漏洞发现的成本，而且这个计划将会加强“数字国防从而增强国家安全”。不过参加此次项目的人员必须首先通过背景调查。五角大楼高度敏感的信息不对外部黑客开放。

美国国防部在三月份设立了国防创新机构旨在与私营企业保持一致步伐。卡特透露称五角大楼将会在军队中提高信息安全团队的地位。

明年1月份之前，即奥巴马任期结束而卡特也有可能不再担任国防部长之际，将有一份名为“未来的力量”提案寻求通过。该提案主要是关于改善军人生活的内容。
