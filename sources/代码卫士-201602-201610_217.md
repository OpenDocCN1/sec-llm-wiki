# 暗网出售每秒可克隆15张非接触式银行卡详情的新设备

**名为****“CC****伙伴（****CC Buddies****）****”****的犯罪组织正在暗网出售一款高科技设备，可在离受害者****8****厘米远的地方复制非接触式的借记卡详情。**

该犯罪组织声称通过这款名为“非接触式注入X5”的设备，每秒能够复制最多15张非接触式银行卡的详情。

**X5****针对****RFID****非接触式借记卡发动攻击**

X5设备旨在从内嵌在现代RFID非接触式银行卡中的无线芯片中复制数据。该数据被存储在X5的内部存储系统中，而小偷可以通过USB连接线将设备连接到电脑上，并且利用该犯罪组织提供的特殊软件进行传输。

X5可以收集的数据包括借记卡卡号以及有效期限。如果借记卡的RFID芯片存储的信息包括持卡人姓名、家庭地址以及一个迷你账单，那么X5也能窃取到。当X5拷贝了信用卡卡号时就会加密数据。该犯罪团伙提供的软件能让犯罪分子将被盗信息解密并下载到Windows（XP及以上版本）电脑中，并开始利用空白的塑料开篇创造假冒借记卡。

**X5****售价约****800****美元赠送塑料卡片**

犯罪分子以1.2比特币（825美元）的价格出售X5，并表示可提供邮寄服务。顾客可收到X5设备、USB连接线以及20张空白卡片。他们做的广告如下：

非接触式注入X5设备是黑客在黑市上出售的首款非接触式银行卡片。该产品由“CC伙伴”设计并开发。在离8厘米的地方就能检测并读取任何银行卡片！而且X5的读卡速度为1024kbps，这款强大的非接触式读卡器每秒就能读取并保存约15张银行卡！

X5内置有一只5伏的电池，可通过随附的USB3.0充电。只需约3小时即可充满而且最多可持续使用10小时之久。此外，他还能够读取多种类型的卡片！任何运行在13.56mhz频率的卡片都可读取。X5能够读取并捕获数据！但由于我们所提供的软件专门为解密银行卡而开发，因此它无法解密其它类型的卡片，不过我们现在正在着手解决这个问题，相信不久就可以办到！
