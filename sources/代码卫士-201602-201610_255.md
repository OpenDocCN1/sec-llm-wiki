# 多数笔记本电脑厂商推送膨胀软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485750&idx=2&sn=a0d96557656e8f6d248ddb25e90cb162&chksm=ea97385cdde0b14a1b6791836590b396d9b9f77fc72a5a841b6ab2c211891502089e178e5549&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485750&idx=2&sn=a0d96557656e8f6d248ddb25e90cb162&chksm=ea97385cdde0b14a1b6791836590b396d9b9f77fc72a5a841b6ab2c211891502089e178e5549&scene=27#wechat_redirect)

**Duo****公司****发表了一份长达36页的报告****，披露了当前笔记本原始设备制造商推送膨胀软件的糟糕情况。**

该公司查看了来自宏碁、华硕、戴尔、惠普和联想的内置驱动更新软件。分析发现，OEM将这些程序组合到一起，存在大量的安全问题，可能导致设备被控制。

研究人员指出，每个笔记本电脑厂商的驱动更新软件中至少存在一个安全漏洞，允许攻击者在用户笔记本上执行代码并且控制设备。更糟糕的是，几乎没有一个厂商正确执行了TLS加密，这也就解释了为何会发生类似“快鱼”和“eDellRoot”的事件。

此外，几乎没有厂商知道如何验证所下载驱动更新的有效性，导致用户可能下载的是恶意驱动。

研究人员分析发现联想解决方案中心的驱动更新工具在测试中的结果很好，说明该工具目前很可能是安全的，但之前却并非如此。几个月前，安全研究人员曾投诉并向联想提交漏洞报告，促使联想为自己的应用程序执行了更好的安全。本月初，联想发布了修复所报告问题的方案。
