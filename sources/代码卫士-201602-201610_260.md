# 匿名者黑客泄露肯尼亚国家石油公司员工数据

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485751&idx=5&sn=41aa216f1da5f7bd5b34a41616827a84&chksm=ea97385ddde0b14b094a26a85bdf2d9dc413b7698eddfbf3ef0b2c01d2a327f228fac265bfb8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485751&idx=5&sn=41aa216f1da5f7bd5b34a41616827a84&chksm=ea97385ddde0b14b094a26a85bdf2d9dc413b7698eddfbf3ef0b2c01d2a327f228fac265bfb8&scene=27#wechat_redirect)

**匿名者黑客的一个小分支****WHT****贴出一个关于肯尼亚国家石油公司员工数据的链接。**

该数据泄露中并不包含员工个人敏感详情，而且似乎是一个运行在该公司官方站点的调查管理CMS数据的一部分。WHT黑客组织同时还提供了被黑后台的截图以证明攻击的真实性。

被泄数据包含两个主要表格，一个是关于该公司员工访问CMS的详情，如用户名、邮件地址及邮件内容，以及用户等级。此外还包括五个管理员。第二个表格似乎包含的信息与第一个一直，不过是关于218名用户的信息。第二个表格中所包含的数据都是关于该公司员工的。

该数据泄露事件是“非洲行动”活动的第二部分。黑客曾表示将攻击肯尼亚组织机构以及其他国家如布隆迪、多哥、布基纳法索、中非共和国、埃塞俄比亚、索马里以及阿尔及利亚。

此前匿名者黑客组织层泄露关于肯尼亚外交部多达1TB的数据。

过去几个月，匿名者黑客组织并没有泄露影响力很大的数据，但接下来几个月我们可能会看到垃圾邮件的增多。“非洲行动”并未结束，而WHT将会尝试兑现曾经许下的诺言，继续泄露来自非洲其它国家的数据。
