# 美国仍然使用软盘存储核军火库信息

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485752&idx=2&sn=f99feb1cc8844a36addeaf1c84b139ee&chksm=ea973852dde0b144439043319f98898d312adb1f4843b5cf8ff2262d8f2f7779bcf26cd70aa5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485752&idx=2&sn=f99feb1cc8844a36addeaf1c84b139ee&chksm=ea973852dde0b144439043319f98898d312adb1f4843b5cf8ff2262d8f2f7779bcf26cd70aa5&scene=27#wechat_redirect)

**5****月****25****日，****美国政府问责局（GAO）发表报告****称用来管理美国核军火库的关键系统仍然在****20****世纪****70****年代生产的电脑上运行，而这些电脑依然使用软盘来存储数据。**

报告披露了美国政府机构所使用的遗留IT系统情况，以及进行升级所需的必要费用。除了对2015年花费在IT系统上的预算支出进行分解外，这份报告还指出了政府机构需要优先解决存在问题的系统。

**老旧软件在美国政府机构中随处可见**

报告给出的第一个老旧系统例子发生在美国国防部，该机构依然在用来运行和管理美国核武器系统中使用8英寸大小的软盘。不过国防部已打算进行升级，同时被升级的还包括用于危机行动规划和战略动员的另外一个系统，该系统使用的技术要更先进一点，但依然运行的是老旧版本（Windows Server 2008、2009 Oracle 11g，编程语言是Java）。

美国退伍军人事务部也打算升级系统，它使用50年代的编程语言COBOL来管理关于员工在职时间和出勤的系统。不过事务部仅有升级COBOL系统的资金，虽然它还使用同样的编程语言运行另外一个关于退伍军人福利、合法性和死亡日期的系统。后一个系统将不会在今年更新。

另外一个使用COBOL的是美国国土安全部。国土安全部用该语言来追踪招聘活动，同时还是用一个2008 IBM z10主机和使用运行Java的一台Windows 2012服务器的Web组件。

**使用****COBOL****以及****50****年代的汇编代码**

此外，美国财政部还使用于50年代开发的低级代码（汇编语言）来管理个人主文件系统。该系统是“个人纳税账户的权威数据来源，负责更新账户、访问纳税信息、并在申税期间生成退税。”

另外也有一些机构因为使用老旧系统而将自身暴露于网络攻击。比如美国交通部用于维护有害物质事件综合信息的一个IT系统将于2018年进行更新。该系统使用的是Classic ASP语言。

除了关键IT系统使用过时技术可能导致机构遭受网络攻击外，美国也面临着巨额的维护费用。维护这些老旧系统所需要的成本、定制化硬件及知道如何进行交互、修订或修复此类系统的人才要比现代技术多。
