# 微软禁止使用易曾被攻陷的简单密码

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485754&idx=3&sn=05c25e6c44b1cf65bb3d88e3f188fe96&chksm=ea973850dde0b1461dfc29f2e70084c41b05c0a43a80b59491cc6e99348408c39d99ed7a6886&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485754&idx=3&sn=05c25e6c44b1cf65bb3d88e3f188fe96&chksm=ea973850dde0b1461dfc29f2e70084c41b05c0a43a80b59491cc6e99348408c39d99ed7a6886&scene=27#wechat_redirect)

**LinkedIn****数据泄露事件被披露后，微软身份保护团队决定禁用一般或者普通的密码，以避免被猜到或者再次被攻陷。**

微软表示已经为普通的微软账户用户激活了该功能，而且正在为微软Azure活跃目录服务进行受限私人预览。

Azure AD身份保护团队的项目经理表示，最重要的是要选择特殊的且难以被猜到的密码。微软通过动态禁止使用常用密码的方式来帮助用户实现这一目的。他还表示，微软的做法跟黑帽黑客的做法类似。当数据泄露的详情被公开时，且事件涉及的数据出现在网上时，微软员工就会将它们找出来并添加到数据库中。随后数据被处理并添加到一个动态更新的被禁密码列表，以阻止用户从已被攻陷的数据库中选择常用密码。

此外，微软还发现了被用于暴力攻击中的常用密码。在本月初，微软表示在微软账户和Azure活跃目录身份系统上每天发现超过1000万次网络攻击。这些攻击为微软提供了大量样本来获取关于用于密码猜测暴力攻击中最常用的密码信息。

微软账户（之前被称为Windows Live ID）是基于用户名和密码的身份系统，为普通的微软用户所部署，包括的服务有Bing、Outlook.com、OneDrive、Windows Phone、Skype、Xbox LIVE、Windows 8.1、Windows 10等。另外Azure活跃目录（ADD）是用于管理企业实体用户登录的识别服务。

被攻陷列表一般都会包含密码信息，有时候会以明文或者以诸如SHA1若算法加密的形式出现。最大的一起数据泄露事件是LinkedIn数据泄露事件。上周，一名黑客表示出售1.67亿被攻陷数据，从而驳斥了LinkedIn最初公布的650万份记录的说法。
