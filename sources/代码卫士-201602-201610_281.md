# 谷歌应用商店中的一款手电筒app传播恶意广告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485756&idx=6&sn=97280eab865fb448a3132ba8f8051060&chksm=ea973856dde0b1404b12675c472aa4a5f546421080ecb0c32d2fac83feadf3845c7a10daeb3b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485756&idx=6&sn=97280eab865fb448a3132ba8f8051060&chksm=ea973856dde0b1404b12675c472aa4a5f546421080ecb0c32d2fac83feadf3845c7a10daeb3b&scene=27#wechat_redirect)

**一款极为流行的安卓手电筒****app****向用户展示恶意广告并试图诱骗用户安装具有潜在危险的****app****。**

趋势科技研究员指出，Super-Bright LED手电筒app可从谷歌官方应用商店中获取，被用户安装后会显示恶意广告。虽然app中出现恶意app并不新鲜，但这款app中的广告软件呈现出恐吓性软件的趋势，它告知用户手机已被感染或者电池中存在病毒。一些有经验的用户或许会卸载这款app，但没有经验的用户则可能会点击广告并被诱骗下载另外一款所谓的病毒删除或杀毒app。

安全专家将这类app称作PUP，原因是这些app中一般都存在恶意软件。趋势科技在年度报告中指出，2015年在所有的应用商店中发现0.15的app都含有恶意代码。

安全研究员表示这款app及其开发人员可能是无辜的，因为广告是通过一个广告网络来恢复并显示的，但他们却对大量的负面用户评论置若罔闻。

目前，这款app仍然可从谷歌应用商店中获取。从数据来看，下载次数已超过1亿次。安全研究人员表示已通知谷歌及其它提供下载的所有应用商店。

由于多数手机并没有内置手电筒功能，这类app的受欢迎程度可见一斑。因此，过去犯罪分子通常通过游戏和手电筒app来传播恶意软件，而多数情况下这些恶意app是通过第三方应用商店传播的，不过有时候它们也会在谷歌应用商店中浑水摸鱼。
