# 赛门铁克杀毒引擎出现严重漏洞 通过邮件可被利用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485759&idx=1&sn=1196d8db110b14f1b4cf184263f0b087&chksm=ea973855dde0b1438197c01d035d3819f76b9f3043a086741ce3a82993e448ee2b200306f4f5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485759&idx=1&sn=1196d8db110b14f1b4cf184263f0b087&chksm=ea973855dde0b1438197c01d035d3819f76b9f3043a086741ce3a82993e448ee2b200306f4f5&scene=27#wechat_redirect)

**谷歌零点项目安全研究员****Tavis Ormandy****在赛门铁克中发现了一个影响杀毒引擎（****SAE****）的严重漏洞。****SAE****是该公司多款安全产品的核心。**

Ormandy表示，当在某些情况下某种类型的数据到达SAE时，SAE会议一种不安全的方式处理这些文件，从而导致缓冲溢出问题。

Ormandy表示，当解析这些由早期压缩工具aspack压缩的可执行文件时，在多数赛门铁克和诺顿的杀毒产品中所使用的核心SAE会出现缓冲溢出问题。当SizeOfRawData大于SizeOfImage时，这个问题就会产生。该问题会导致SAE崩溃，随后授予攻击者根权限以及执行代码的权限。该漏洞编号为CVE-2016-2208，影响所有的操作系统包括Mac、Linux和Windows。

Ormandy表示，这个问题可以一种非常简单的方式被利用。由于该漏洞存在于扫描引擎本身，而扫描引擎会打开并读取任何文件而并非只是用户手动选择要进行扫描的文件。犯罪分子可通过发送邮件或者发送指向一个Web利用链接的方式发出利用数据包。SAE会自动扫描内容并且攻陷用户设备，期间无需任何用户交互。

Ormandy表示，在Windows设备上这个问题更严重，因为扫描引擎直接在Windows内核上运行。利用Windows环境下的漏洞会导致内核的0级环损坏，从而导致出现“内核恐慌”问题，而它有可能会导致BSOD（蓝屏死机）问题。

CVE-2016-2208影响赛门铁克产品如赛门铁克端点引擎、诺顿杀毒、赛门铁克扫描引擎以及扫描邮件安全等。Ormandy声称从理论上来讲，这个漏洞应该还会影响部署了SAE的所有产品。

Ormandy向赛门铁克披露了这个问题，后者随后发布了可供下载和应用的一个补丁。
