# 因潜在的误报问题 苹果下架一款iOS安全app

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485760&idx=6&sn=3e3fd2de1c9a52bc499ae6a6acac393b&chksm=ea97382adde0b13c73a8cad6afd189c936d127803db3dcb9a7235ee9e09cd98f646b3c895344&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485760&idx=6&sn=3e3fd2de1c9a52bc499ae6a6acac393b&chksm=ea97382adde0b13c73a8cad6afd189c936d127803db3dcb9a7235ee9e09cd98f646b3c895344&scene=27#wechat_redirect)

**令人质疑的苹果应用商店目前下架了一款由一名德国安全研究员开发的****iOS****安全****app****，原因是这款****app****提供了“不准确且有误导性的”信息。**

这款于上周末被下架的app名为System and Security Info，它于上周发布，并且列于iOS应用商店中。开发作者Stefan Esser表示，对app稍微进行了更新后遭下架。

Esser发表推文称，这款app经过了三道应用商店的审查程序，然后某个苹果经理认为里面含有一些不需要的内容并导致其下架。这款app是为德国公司SektionEins而开发的，它从安全角度为用户展示了运行进程。开发人员声称这款app能够在iOS9中展示运行进程，如果在用户不知情的情况下发生了越狱事件；而且还能够指出所有可能存在恶意软件感染或隐私泄露的安全异常情况。

Esser在上周发布了这款app后因其所具有的突破性功能马上引发了媒体的大量关注。不过周末过后，Esser发推文称甚至希望苹果在第一轮媒体热潮平息下来之后将app下架，而现在这一切都发生了。而苹果工程师表示这款app可能向用户显示了不准确以及具有误导性的信息，因此需要下架。

苹果向来对刺激iOS内部架构的app不友好，因此对于所有苹果迷来说，这款app被删除只是时间的问题。不过这个决定让开发者Esser在推特上咆哮不止。
