# 丝绸之路3.0再次出现在暗网

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485760&idx=2&sn=72c69749eb06313cfc33f30e80d0f7f2&chksm=ea97382adde0b13c1092ceec3433aead7fe6b933f432bc72768dca34baa3741698e46b6301b7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485760&idx=2&sn=72c69749eb06313cfc33f30e80d0f7f2&chksm=ea97382adde0b13c1092ceec3433aead7fe6b933f432bc72768dca34baa3741698e46b6301b7&scene=27#wechat_redirect)

**丝绸之路市场又现身于暗网。这次的版本为丝绸之路****3.0****，它实际上是丝绸之路网站的第四次“重生”。**

丝绸之路3.0是通过Reddit发布的，它由对手网站“加密市场（Crypto Market）”的负责人运行。这两个网站实际上共享一个托管在暗网上的支持论坛。目前丝绸之路3.0开放注册，而且网站中已经充斥着被盗取的数据、利用、僵尸网络、武器以及其它“见不得阳光”的所有非法商品。

最初的丝绸之路网站发布于2011年2月份、关闭于2013年夏天，原因是FBI的突袭行动抓捕了很多网站用户、版主、甚至是管理员Ross Ulbricht。丝绸之路2.0出现在2013年11月份，不过一个月之后美国政府很快将管理员抓捕。2014年11月，有人试图让丝绸之路东山再起，但2016年1月份，该网站因无法吸引新用户而经营惨淡。

丝绸之路3.0的命运几乎已成定论，因为经过前两次对丝绸之路的高调打击后，犯罪分子几乎没有任何理由会注册新账户。而丝绸之路这次唯一拥有的名声就是由加密市场所有人来运作。加密市场的所有人运行加密市场网站已有一段时间了，而且没有出现任何事件。

目前，暗网最受欢迎的市场包括Alphabay、Dream Market、The Real Deal、Zocalo、Valhalla、Hansa Market、Acropolis、Python Market、Oasis Market、Bloomsfield、German-Plaza、Darknet Heroes League、The Majestic Garden、以及之前提到的“加密市场”。
