# 安卓恶意软件传播可重启设备的app

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485763&idx=4&sn=8a42b9083009061d0ef63cfff778e49f&chksm=ea973829dde0b13fd76d9042c4819234cab93a1a5304a60a5cab403cb33aa9f34dd4f0126b88&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485763&idx=4&sn=8a42b9083009061d0ef63cfff778e49f&chksm=ea973829dde0b13fd76d9042c4819234cab93a1a5304a60a5cab403cb33aa9f34dd4f0126b88&scene=27#wechat_redirect)

**来自****Bitdefender****的安全研究人员发现一款旧的安卓恶意软件改变了攻击策略，试图传播含有利用的****app****重启安卓设备。**

这款恶意软件名为安卓矩阵木马(Android Matrix Trojan)，是在之前的攻击中被发现的。在最近的攻击活动中，犯罪分子将木马跟一个名为VideoCharm的app绑定，并通过第三方应用商店进行传播。

这款app表示能够更快捷地访问成人视频，而安全专家表示它会向用户展示弹出信息并要求安装其它app。这款app并非一个空壳而是含有一种内置功能能够将成人视频从网络服务器中下载，这样用户几乎就能忍受所附带的垃圾了。用户第一次打开这款app后，木马会将四个ZIP文件下载到用户设备中，随后解锁这四个包含多个安卓根利用的ZIP文件。

安全研究人员表示木马使用CVE-2015-3636和CVE-2015-1805这两个漏洞来获取被感染智能手机的管理员权限。另外一个利用仅针对华为设备。该利用对安卓5.0、4.1和4.4版本有影响。

如果利用成功，那么有了这些权限之后，木马就能控制手机。研究人员表示这款app还创建了一个名为“root\_trace”的日志文件，会存储并详细记录重启的结果。

研究人员表示，该木马的最新变种表明恶意软件在不断演进，不论是安卓或者电脑恶意软件皆如此。从第三方应用商店下载app所带来的安全风险可能会攻陷用户的个人数据。
