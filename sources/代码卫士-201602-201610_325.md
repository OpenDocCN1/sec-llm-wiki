# Guccifer声称入侵希拉里私人邮件服务器

Marcel Lehel Lazar即臭名昭著的黑客Guccifer已证实入侵民主党总统候选人及前第一夫人希拉里·克林顿的私人邮件服务器。

此前Guccifer曾确认入侵了多个美国名人及政客的个人邮箱账户，包括小布什和美国第一任黑人国务卿科林·鲍威尔。不过他的目标清单似乎都没有结束的意思，一直在提供关于名人政客的个人信息。

他曾被控写了前总统布什的绘画作品，而这次他又在证明希拉里一直在否认的事情：她确实拥有一个私人邮件服务器。丛另一方面来讲，他访问了鲍威尔的邮箱庄户并且泄露了其私人生活详情。实际上，他披露称自己能够访问希拉里的私人邮箱服务器是因为他访问了希拉里的密友西尼·布鲁门多的账户。

Guccifer在2013年入侵了布鲁门多的账户，之后披露了她的邮件内容。邮件显示希拉里跟布鲁门多通过私人邮件地址沟通。布鲁门多被称为“第5号受害者”，并且身份是“记者和前总统顾问”。Guccifer目前正在弗吉尼亚服刑。他在狱中向福克斯新闻和NBC记者披露了自己入侵希拉里邮件服务器的事情。他甚至还识别出了希拉里的邮件地址hdr22@clintonemail.com。

Guccifer所披露的事情很有深意。因为我们知道希拉里自2015年起就因使用私人邮件服务器进行官方通信、而且存储在该服务器中的数千份邮件都被标记为“机密”且22份邮件被标记为“绝密”而饱受批评。

不过Guccifer并没有提出任何能够有力证明其说法的证据。希拉里的新闻秘书表示，“这名犯罪分子在监狱所做的说法是无稽之谈。他并没有能够支持这一说法的证据，而且他对希拉里服务器的描述也是不准确的。此外，他既然获取了访问邮件的权限但却没有像泄露其他受害者信息那样做是不可理解的。”

目前FBI并没有检测到信息泄露的证据，调查完之后也没有发现相关证据。但Guccifer却坚称自己入侵了希拉里的邮件服务器，甚至还表示入侵“很容易”，因为希拉里的服务器“一点也不安全”。他还表示他首先通过访问布鲁门多收到的邮件追踪到了希拉里的IP地址，随后利用IP扫描器和其它网络程序如Netscan、Angry IP和Netmap等查看该服务器是否还呈“活跃”状态。他还指出在自己入侵希拉里服务器的时候还发现来自世界其它国家的10名用户也在访问该服务器。
