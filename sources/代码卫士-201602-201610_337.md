# 加拿大黄金厂商数据遭泄露

**加拿大黄金公司****Goldcorp****本周证实遭受了未知黑客的攻击，数据遭泄露。**

该公司是加拿大最大的黄金矿业公司之一，其站点遍布美洲：从加拿大到美国、从墨西哥到多米尼加共和国。黑客入侵了黄金公司的服务器并且窃取了大量文件，随后将其上传到网络。目前尚不知晓他们使用了哪种入侵方法、服务器被攻陷日期、以及黑客身份。

被泄露的数据包括包含敏感的雇员信息的文件、以及内部文档如关于该公司活动的邮件及报告。从黑客的声明和文件内容来看，确定被攻陷的信息包括：T4和W2表格、薪资信息、与其它公司的合同、银行账户、无线传输、可销售证券、2012年至2016年的预算文档、以及财务报告。

此外，被泄露的数据还包括员工信息、多种类型的登录/密码信息、员工护照扫描件、员工进展报告、国际商务合同列表、IT流程、VMWare恢复程序、以及该公司的SAP账户。

**公司证实泄露事件**

黄金公司几天后证实了数据泄露事件。2015年夏，另外一家加拿大矿业公司也遭受类似数据泄露事件。一个俄罗斯入侵组织攻陷了Detour Gold公司，该公司随后表示已采取措施保证服务器的安全，不过黑客随后卷土重来再次实施入侵。

黑客在声明中表示，他们计划发布来自Goldcorp服务器中的新文件。另据悉，在泄露数据之间，黑客曾试图敲诈勒索Goldcorp公司。
