# PoS恶意软件通过DNS请求窃取信用卡数据

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485774&idx=2&sn=1143d1f12813fcb71375a11e9705017a&chksm=ea973824dde0b132a8d5a730657a419e6fa4840b21cc99576a3d50923f5a833a19060b699c6d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485774&idx=2&sn=1143d1f12813fcb71375a11e9705017a&chksm=ea973824dde0b132a8d5a730657a419e6fa4840b21cc99576a3d50923f5a833a19060b699c6d&scene=27#wechat_redirect)

**NewPosThings POS****恶意软件新版本正在通过一种狡猾的方式从受感染的****PoS****终端中提取数据，而几乎所有的安全解决方案都无法检测到这种恶意活动。**

NewPosThings恶意软件多年前就已出现，而且长期以来都未曾超越其它PoS恶意软件家族。它主要会感染处理信用卡数据的Windows进程，窃取金融信息并发送至其命令和控制服务器。其最初版本的数据提取进程是通过HTTP和HTTPS实现的，而最近其进程又是通过DNS实现的。

**多数安全软件无法扫描****DNS****请求**

发生这样的变化是因为多数安全解决方案的配置都是为了查看HTTP和HTTPS流量中是否存在可疑活动。为了避免被检测到，最新的恶意软件版本已经改为利用DNS请求。而杀毒解决方案并没有观察这一项且网络管理员也无法关闭该请求。其它恶意软甲你如BernhardPOS和FrameworkPOS也使用了同样的方法。

**最近版本仅针对一个****PoS****平台**

除了基于DNS请求的数据提取外，NewPosThings的新版本即MULTIGRAIN还有一种不同之处在于其操纵者似乎专为一款特殊类型的PoS平台而设置。

MULTIGRAIN只会查找multi.exe Windows进程，针对一种PoS终端厂商然后感染设备。一旦进入这个进程，恶意软件就会等待窃取信用卡数据。随后恶意软件会记录信息，用1024比特的RSA公钥加密，并将其伪装成DNS请求每隔五分钟发送至命令和控制服务器。
