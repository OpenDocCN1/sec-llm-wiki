# 亲ISIS组织三天内涂鸦88个站点

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485775&idx=3&sn=59b0e8deffc406120c3c6db4eb869f92&chksm=ea973825dde0b13333d440917dba1bd4168c7cc1ea3247245785c70987a512aa0aedc54de440&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485775&idx=3&sn=59b0e8deffc406120c3c6db4eb869f92&chksm=ea973825dde0b13333d440917dba1bd4168c7cc1ea3247245785c70987a512aa0aedc54de440&scene=27#wechat_redirect)

**亲****ISIS****黑客组织****Team System Dz****在****4****月****14****至****16****日三天时间内入侵并涂鸦了法国、以色列、美国及英国的多个站点。**

这个黑客组织位于阿尔及利亚，已经存在几年的时间了，它在Facebook主页还声称自己跟匿名者黑客组织有关。在三天的时间里，这个黑客组织在Facebook贴出了被黑站点的网址链接。这个黑客组织总统涂鸦了88个站点，并在网站首页上留下了亲ISIS信息及ISIS标识。不过现在看来这些信息已被删除掉。

最有意思的攻击目标是一些属于美国威斯康星州里奇兰县的政府网站。2015年11月，该黑客组织就曾涂鸦了这些站点，随后又在三月底再次涂鸦。多数站点都运行WordPress，而且有些站点似乎以多站点模式运行，也就是说如果有一个站点被攻陷，那么其余的站点也难逃厄运。

所有的站点在上个月都遭到了第二次攻击，里奇兰县可能需要考虑更换网络管理者里，因为在不到六个月的时间里，它的站点已是第三次受攻击。不过目前来看，攻击者似乎除了涂鸦之外也没有别的攻击手法，而且暗网上也没有关于前两次攻击出现数据泄露的报道。
