# 帮助FBI破解iPhone 5C的公司准备拿下

FBI并未透露帮助其破解恐怖主义分子San Bernardino iPhone手机的公司名称，但人们普遍认为这家公司是以色列公司Cellebrite。

Cellebrite通过一种新方法帮助FBI入侵iPhone 5C，但是这种方法无法破解iPhone 5S和之后型号的手机。

**Cellebrite****正在入侵被锁定的****iPhone 6**

据悉，目前Cellebrite对于入侵安全性更高的iPhone 6很“乐观”。CNN报道称一名意大利工程师上周曾询问该公司能否帮助他访问一台属于他已去世儿子的iPhone 6。因为iPhone 6重启之后，被添加的指纹无法开启而这名父亲不知道解锁密码，因此无法打开iPhone 6来查看儿子生前的照片等资料。

Fabbretti曾在3月21日联系苹果公司解决这个问题，但苹果公司发现手机并未备份到云端，因此爱莫能助。

**免费破解****iPhone 6**

了解到Fabbretti的故事之后，Cellebrite主动提出帮助这名父亲免费破解手机。上周跟公司会面后，这名父亲表示一切进展顺利，公司能够下载到手机中的目录，不过依然还在努力找到访问文件的办法。公司表示有可能会获取访问被锁iPhone6上的文件，包括父子间的照片和会话以及儿子去世三天前所拍摄的视频。

目前Cellebrite和苹果公司都尚未就此事置评。如果Cellebrite能够开发出一种破解iPhone 6的新方法，无疑该公司会将工具出售给FBI，就像当初帮助FBI访问恐怖主义分子被锁定的iPhone 5C手机那样。
