# 谷歌修复Chrome 49严重漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485791&idx=1&sn=da929f0bf81f264889b968927cf1ec2b&chksm=ea973835dde0b1233c572578e6cd1bd445d1d3b01e524f873c5f55a4724262910116d4dd440f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485791&idx=1&sn=da929f0bf81f264889b968927cf1ec2b&chksm=ea973835dde0b1233c572578e6cd1bd445d1d3b01e524f873c5f55a4724262910116d4dd440f&scene=27#wechat_redirect)

**谷歌再次更新****Chrome 49****的****Windows****、****Mac****和****Linux****版本，修复几个漏洞其中包括一些高危漏洞。**

Chrome 49.0.2623.108总共解决了5个漏洞，其中4个是外部研究人员发现的。有两个释放后使用的高危漏洞是“匿名人士”发现的，分别位于导航（CVE-2016-1647）和扩展（CVE-2016-1648）中。谷歌对这两个漏洞的奖励分别是5500美元和5000美元。另外一个高危漏洞是V8 JS引擎（CVE-2016-1646）中的带外读取漏洞。

在Pwn2Own 2016竞赛中，JungHoon Lee曾尝试演示攻击Chrome的远程执行利用但并未成功，但似乎这名研究人员在libANGLE（CVE-2016-1649）中发现了一个高危缓冲溢出。谷歌对研究人员进行了致谢，但奖励金额尚不得知。

此外，谷歌也修复了多个由自己安全团队发现的漏洞。

当谷歌在3月初发布了Chrome 49版时，宣布修复了之前版本中的26个漏洞，大概一周后，谷歌又修复了另外三个高危漏洞。上个月，一个未具名研究人员因报告同源策略和Chrome沙盒逃逸漏洞而获得超过2.5万美元的奖励，谷歌目前正在为研究人员提供更高的奖励。谷歌近期宣布已准备好10万美元来奖励能够攻陷Chromebox或Chromebook的研究人员。此外，Chrome奖励计划还将安全浏览下载保护绕过漏洞囊括在内，提供的奖励是1000美元。
