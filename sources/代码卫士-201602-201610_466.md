# Hacking Team发布专门针对Mac的恶意软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485794&idx=1&sn=fe2ce05566e7bd17e25015b20951a58c&chksm=ea973808dde0b11e883b7ea978c955fb4a3576f07b31aa7825606bab033a838917e10df79d49&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485794&idx=1&sn=fe2ce05566e7bd17e25015b20951a58c&chksm=ea973808dde0b11e883b7ea978c955fb4a3576f07b31aa7825606bab033a838917e10df79d49&scene=27#wechat_redirect)

**安全研究人员发现了一款似乎由臭名昭著的黑客组织****HackingTeam****发布的恶意软件样本且专门针对****Mac OS X****。**

来自Palo Alto的安全研究人员Claud Xiao发现了一系列恶意的Mac二进制非常可疑，经过跟信息安全社区分享之后，研究人员得出了一致结论：这些恶意二进制包含新的（或者是修改过的）恶意软件，它所使用的技巧和运行方式跟之前HackingTeam所使用的恶意软件攻击方式一致。

 

**恶意二进制是简单的恶意软件病毒释放器**

对于恶意软件本身而言，研究人员认为这个新变体只是一个病毒释放器而不是什么复杂的东西。病毒释放器是一种计算机病毒，它们必须能够感染计算机并在计算机中站稳脚跟，然后他们还必须能够跟命令和控制服务器交流，且下载一种特定的恶意软件变体。

安全研究人员发现，在分析期间，谷歌的VirusTotal杀毒引擎并非将其标记为恶意软件。他们还发现，跟HackingTeam制造的其它Mac恶意软件相比，这些新的二进制使用的是Apple的内置OS X加密计划和一个定制化的二进制包装系统。
