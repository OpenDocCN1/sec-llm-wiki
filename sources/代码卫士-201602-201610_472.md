# “沙尘暴行动”攻击日本基础设施

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485796&idx=2&sn=46e2957d4fea7b45b9d78cbf28061411&chksm=ea97380edde0b118f4369a2b7148c4419a86a8ac91e05e484e025177f9bbfdbe0500db57058f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485796&idx=2&sn=46e2957d4fea7b45b9d78cbf28061411&chksm=ea97380edde0b118f4369a2b7148c4419a86a8ac91e05e484e025177f9bbfdbe0500db57058f&scene=27#wechat_redirect)

**来自****Cylance****的安全研究人员发布了一个长达六年之久的大型网络间谍行动，名为“沙尘暴行动”。这次行动最近主要针对日本关键基础设施发动攻击。**

安全研究人员近期指出，多次攻击针对日本私营和公共组织机构，其中包括著名的汽车公司、一家韩国电子设备企业在日分公司以及一家来自石油和天然气行业的公司。Cylance指出，攻击者在攻击日本受害者之前，曾针对来自美国、韩国、中国和多个欧洲国家发动攻击。

**“沙尘暴行动”始于****2010****年**

该黑客组织的首次露面是在2010年，当时他们发动了多起非常容易发现的简单攻击，他们利用Adobe Flash播放器和IE浏览器中的0day漏洞传播恶意软件Misdat。一年之后，攻击者开始利用跟利比亚危机相关的垃圾邮件攻击美国机构和中国维吾尔族少数民族区域。而这次，该黑客组织通过利用IE的0day漏洞（CVE-2012-1889）发动攻击。

**“沙尘暴行动”在****2013****年暂停后变本加厉**

攻击在2012年继续施威，不过在2013年年底时停止，当时Mandiant发布了一份关于APT1的报告。暂停一段时间后，“沙尘暴行动”变本加厉，在2014年利用一个IE 0day漏洞发动简单的水坑式攻击之后，从2月15日开始专门针对日本发动攻击。当时该黑客组织首次使用被称为S-Type的后门，并且对安卓设备实施监控。

安全研究人员指出，“沙尘暴行动”利用为特定目标组织机构定制的恶意软件来发动攻击。攻击使用了鱼叉式钓鱼方式、水坑攻击、特殊后门和特殊0day漏洞来攻陷企业网络和安卓移动设备。
