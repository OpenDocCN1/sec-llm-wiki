# Linux Mint被黑

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485798&idx=3&sn=ef6ad08da6957396b9a26904023a931b&chksm=ea97380cdde0b11a2e7f1e8cebe49396853f133747877797a044bf694b663bbf094bfa078b30&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485798&idx=3&sn=ef6ad08da6957396b9a26904023a931b&chksm=ea97380cdde0b11a2e7f1e8cebe49396853f133747877797a044bf694b663bbf094bfa078b30&scene=27#wechat_redirect)

Linux Mint的创建者Clem Lefebvre表示，黑客创建了一个带有后门的修改版的Linux Mint ISO，并且设法攻陷了官方网站。受感染的ISO在操作系统中安装了IRC（多人在交谈系统）后门“海啸”，使得黑客可以通过IRC服务器访问系统。

这次入侵仅影响在2月20日（美国当地时间）下载Linux Mint 17.3“肉桂(Cinnamon)”版本的用户。Lefebvre表示，站点被攻陷后，“肉桂”版本官方下载链接似乎就会被修改版本的下载链接所替代。目前网站已下线并实施调查。

用户可通过对比MD5签名跟官方版本来检查受感染下载。官方下载服务器中也会显示MD5签名。服务器未被攻陷，Linux Mint库也未受影响。

如果用户的安装程序被感染，建议将电脑断网、卸载操作系统并且更改敏感站点和邮件的密码。

这次事件提醒我们检查重要下载的MD5签名的重要性。同时确保MD5签名来自可信来源，而不是被黑客已修改的来源。对于热门Linux传播来讲，这些签名被公布的次数不止一两次，因此签名如果不一致就有可能是出现问题了。

Lefebvre表示目前尚未得知攻击的动机所在。如果更多项目遭受攻击并带来更多损害，将会联合相关机构和安全企业与之斗争。
