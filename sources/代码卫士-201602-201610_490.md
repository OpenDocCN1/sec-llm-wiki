# VMware再次为vCenter RCE漏洞发布补丁

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485801&idx=2&sn=45e17056d9d427510da4c939ae5b988c&chksm=ea973803dde0b1155d4848b00ce0af1aeee0e0168b7c03b9d62fd12b1a7fe0686b2681354555&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485801&idx=2&sn=45e17056d9d427510da4c939ae5b988c&chksm=ea973803dde0b1155d4848b00ce0af1aeee0e0168b7c03b9d62fd12b1a7fe0686b2681354555&scene=27#wechat_redirect)

**由于去年发布的补丁不完整，****VMware****再次发布补丁修复****vCenter****服务器中的一个严重漏洞问题。**

VMware在去年10月份发布一份公告，告知用户应用软件更新以解决影响vCenter和ESXi的严重安全漏洞。当时公司要解决的问题是CVE-2015-2342。该缺陷允许远程未验证攻击者在受影响的vCenter 服务器安装程序中执行任意代码，并且允许本地攻击者进行权限升级。虽然VMware发布了Windows 5.0 U3e以及5.5U3版本，但仍未解决这个问题，因此现在公司发布了另外一个补丁KB2144428来修复这个问题。

公司发布公告指出，如果Windows防火墙在安装了vCenter Server Windows的系统上处于开启状态，远程利用CVE-2015-2342是不可能的。即使防火墙被启用了，建议用户安装新发布的补丁以删除本地权限升级。

2015年，VMware曾发布了九个安全公告公布了20多个漏洞问题。从2016年伊始截止目前，公司仅发布了几个更新解决一个影响ESXi、Fusion、播放器和工作站的访客权限升级漏洞。

值得注意的是，VMware今年将工作站添加到白帽黑客的竞赛Pwn2Own 2016中。该比赛计划于3月16号至17日举行。设法实现虚拟机逃逸目的的参与者将获得7.5万美元的奖金。
