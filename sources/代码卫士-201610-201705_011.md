# 台湾地区声称将拦截谷歌公共DNS保护网络安全

**台湾地区将拦截谷歌的公共DNS服务以保护网络安全。那么问题来了：这是保护谁的安全？普通民众的还是政府的？而台湾地区正在推广自己的DNS服务，用于监控人们的互联网通信。**

  

消息是通过贴到台湾地区政府互联网服务网络新闻页的一个PDF演讲稿透露的。演讲稿用中文概述了问题所在，多次强调DNS欺骗技术和其它网络安全服务。文档指出，如果能减少对所限制来源的使用，那么通过适当的DNS保护机制就能有效减少DNS欺骗风险。而从大量DNS图表来看，谷歌的公告DNS系统应该被视作来源之一。一个图表显示谷歌DNS服务用于规避防火墙，另外一个图表说明了使用该服务时被释放的数据包。

  

另一方面，文档列出了使用台湾地区自己的DNS服务 (210.69.1.1) 在搜索互联网时获得的好处，而互联网服务提供商中华电信的影子在示例中随处可见。

目前尚不清楚是否会在整个台湾地区还是只是针对政府员工拦截谷歌的DNS服务，以及是否只有政府员工才被强制使用政府提供的DNS服务。不过其中一张PPT很明确地显示，只有经过政府的DNS服务的DNS请求将会被允许，其它均被禁止。

  

目前并未表明何时将推行这种做法。

  

谷歌的DNS服务的主要用途之一是访问那些被政府防火墙拦截或审查的某些服务或网站。通过提供DNS服务，互联网服务提供商能够有效地判断出用户所访问的和访问不到的信息。通过此类服务来实施对公民的大规模监控也是可能发生的。

  

谷歌将DNS服务作为一种选项提供，虽然谷歌对于所获取数据将去往何处讳莫如深。有可能台湾地区政府部门只是通过拦截对公开互联网的访问来改进员工的网络安全以确保他们只访问自己的服务。虽然不常见但它是一种合法方式。

然而，该举措可能也跟今年年初台湾地区网民指出访问Facebook、YouTube、谷歌和Gmail存在问题有关系。只有使用中华电信宽带和移动服务的人受影响。台湾通信委员会 (NCC) 调查表示问题在于“路由器过载”并拒绝做出更多回应；另外NCC指出问题并非是因为很多技术人员指出的入侵导致DNS服务异常。
