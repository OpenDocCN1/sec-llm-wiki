**虽然Kali是白帽黑客的心头好，但它并不能阻止被黑帽黑客使用。**

  

要好好想想密码的事情了。设置个长的复杂密码吧。这倒不是因为又发生数据泄露事件了，而是因为Kali Linux在破解密码方面又有了新发展。Kali是基于Debian的Linux系统，它整合了多种黑客和取证工具。它是白帽黑客和调查人员的好帮手。

  

Kali版本的开发人员本周又改进了功能，为Azure和Amazon Web Services的GPU实例中增加了新的图像优化功能。Kali的支持方认为这种新功能会加强其密码破解能力，且会更好地支持GPU破解，因此任何人都可使用Kali并且无法阻止黑帽黑客将其用于攻击行动中。而且只要他们愿意支付就能在GPU云实例上实施攻击。

  

Kali新版本2017.1还增加了对Realtek RTL8812AU无线芯片集的支持。虽然Linux内核并不支持这个芯片集，但很多主流调制解调器厂商如D-Link、Belkin和TP-Link都支持。因此增加对Kali的支持会让它能够侦察很多无线访问点。

  

另外新版本还支持OpenVAS 9漏洞扫描器。在默认版本中该工具并不包含Kali，不过只要快速通过apt-get update和apt install openvas就能够安装工具的更新版本。
