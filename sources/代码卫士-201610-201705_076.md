# \[CVE-2017-5662\] Apache Batik信息泄露漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485544&idx=3&sn=785bf25db50cac0344472e9724ad813f&chksm=ea973902dde0b0140235d2c5d0d4fb9b7ccb2e301683cdd8f93552db2faec92d24b41bc684f1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485544&idx=3&sn=785bf25db50cac0344472e9724ad813f&chksm=ea973902dde0b0140235d2c5d0d4fb9b7ccb2e301683cdd8f93552db2faec92d24b41bc684f1&scene=27#wechat_redirect)

![](../Images/a450ba5fe1e9e9ff1f73115101c45d1d.png)

  

**来自Adobe公司的研究员Lars Krapf和Salesforce公司的Pierre Ernst都发现了Apache Batik信息泄露漏洞。该漏洞被评级为“中危”，影响版本是Batik 1.0至1.8版本。**

  

位于服务器文件系统中且使用batik的文件可被泄露给发送恶意SVG文件的任意用户。根据可利用应用程序运行的用户上下文可展示文件类型。如果用户拥有根权限，那么就可能完全攻陷系统，获取机密或敏感文件信息。

  

XXE还可通过DoS来攻击服务器的可用性，因为一个XML文档中的引用能够触发放大攻击。

  

用户可更新至Batik 1.9以上版本免遭攻击。
