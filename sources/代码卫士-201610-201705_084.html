最新泄露说明NSA攻击SWIFT银行网络

“暗影掮客”黑客组织又放出更多NSA用来入侵Windows操作系统早期版本的入侵工具和利用代码。同时还发现NSA攻击全球多个银行使用的SWIFT银行系统。


上周，“暗影掮客”组织发布了Unix利用代码加密缓存的密码，包括Solaris OS以及去年夏天被拍卖的TOAST框架的远程根0day利用代码。这些黑客工具都属于NSA旗下的“方程式组织”。现在“暗影掮客”通过博客发布了117.9MB的加密文档，密码是“Reeeeeeeeeeeeeee（16个e）”。


有人已经将所有解锁的工具放在GitHub上了，并列出了该组织泄露出的所有文件，它包括23种新的黑客工具。这些工具被称为OddJob、EasyBee、EternalRomance、FuzzBunch、EducatedScholar、EskimoRoll、EclipsedWing、EsteemAudit、EnglishMansDentist、MofConfig、ErraticGopher、EmphasisMine、EmeraldThread、EternalSynergy、EwokFrenzy、ZippyBeer、ExplodingCan、DoublePusar等。


安全研究员开始分析这些泄露资料来判断声称针对Windows平台的利用代码、植入和有效负载的功能。


这个新发布的资料包括三个文件夹：Windows、Swift和OddJob。


Windows文件夹中包含很多针对Windows操作系统的黑客工具，不过仅针对Windows老旧版本如Windows XP和Server 2003。研究人员Hacker Fantastic在推特表示，ETERNALBLUE是一个0day远程代码执行利用代码，影响最新的和已更新的Windows 2008 R2 SERVER VIA SMB和NBT。


另外一个文件夹OddJob，包含一个基于Windows的植入并包含配置文件和有效负载。虽然关于这个植入的详细情况目前还很少但OddJob在Windows Server 2003企业版到Windows XP专业版都起作用。


一些Windows利用代码甚至无法通过VirusTotal网络文件扫描服务检测到，也就是说这些利用代码是0day漏洞。


SWIFT文件夹中包含中东最大的Swift服务局之一EastNets的PowerPoint演示、证据、凭证和内部架构。SWIFT是一款全球金融信息系统，全球数千家银行和组织机构每天都在通过它转账数十亿美元。这个文件夹中包含用于从甲骨文数据库中查询数据如数据库用户列表和SWIFT信息查询。除此之外，文件夹中还包含Excel文档，内容说明NSA精英网络攻击部门方程式组织已经入侵并获取访问了世界多家银行的权限，多数银行来自中东地区如阿联酋、科威特、卡塔尔、巴勒斯坦和也门。


EastNet在14日公布的官方声明中否认了其SWIFT服务局已遭攻陷，并表示入侵报告“完全错误且毫无根据”。
