# 微软发布补丁修复已被利用的严重漏洞

**除了此前并未披露的一个Word代码执行漏洞外，微软周二还修复了两个攻击者已利用数月之久的0day漏洞。**

  

微软总共修复了9款产品中的45个漏洞，包括三个此前已被利用但未公布的漏洞。第一个已被利用的漏洞CVE-2017-0199是一个远程代码执行漏洞，当受害者打开包含恶意OLE2link对象的Word文档时，攻击者可远程控制完全修复的现代计算机。攻击能够绕过微软开发出的多数利用缓解措施，而且有研究人员指出，在某些情况下利用代码能在启用受保护视图的情况下执行恶意代码。如此前报道，这个漏洞已被Dridex银行木马等恶意软件所利用。

  

微软还为漏洞CVE-2017-0210发布补丁。这个漏洞是存在于IE浏览器中的权限升级漏洞，可导致攻击者诱骗受害者访问受攻陷的网站。攻击者能够利用这个漏洞访问来自一个域名中的敏感信息并将其注入到另外一个域名中。微软表示，“这个漏洞本身并不会导致任意代码执行。然而，攻击者能结合使用这个漏洞和其它漏洞如远程代码执行漏洞利用权限升级运行任意代码”。这个IE漏洞也已被利用。

  

第三个此前未被披露的漏洞CVE-2017-2605存在于Offcie的EPS过滤器中，但微软并未在周二发布更新，而是默认禁用EPS过滤器作为一种防御措施。这个Word漏洞也被利用。微软指出，已经意识到利用这个未修复漏洞的有限的针对性攻击，目前还在着手推出安全更新。

  

微软另外还为Windows Creator Update发布了一个补丁，解决一些远程代码执行漏洞和权限升级问题。周二，微软总共推出了15个安全更新修复产品中的十几个CVE漏洞问题。这些产品包括Windows OS、Exchange Server、Edge和IE浏览器、Office、Office Services和Office Web Apps、Visual Studio for Mac Silverlight以及Adobe Flash。

  

强烈建议用户尽快安装安全更新，以防遭受攻击。
