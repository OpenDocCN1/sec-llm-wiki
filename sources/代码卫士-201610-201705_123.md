# 苹果修复产品线中的数百个漏洞

**本周一，苹果公司为macOS和macOS Server、iOS、watchOS、tvOS、Safari和Pages发布了多个安全补丁解决200多个漏洞问题。**

  

苹果发布了macOS Sierra 10.12.4从而解决了不少于127个安全漏洞。这些受影响组件如apache、Audio、Bluetooth、FontParser、ImageIO、IOFireWireAVC、Kernel、OpenSSH、OpenSSL、QuickTime、Security、tcpdump、tiffutil和WebKit。Tcpdump受影响最大，苹果在这个组件中修复的漏洞就有41个。攻击者能够以权限网络身份通过用户协助执行任意代码。苹果还解决了Kernel中的11个问题和tiffutil中的8个缺陷。

  

macOS Sierra 10.12.4中解决的问题包括内存损坏，不一致的用户界面问题，带外读取、访问和验证问题，缓冲溢出，不受控制的格式字符串，定时侧信道问题，资料卸载问题，使用后释放和竞态条件。很多问题是通过改进输入验证或改进内存处理的方式解决的。

  

思科安全团队在对证书的解析中发现了一个内存损坏漏洞CVE-2017-2485并通过改进输入验证而得以解决。苹果公司表示，在处理恶意编制的x509证书，时，这个问题会引发任意代码执行。研究人员指出这个使用后释放漏洞（也影响iOS）出现的原因是处理X.509v3证书扩展字段的方式不正确。

  

macOS Sierra 10.12.4更新还包括对Safari 10.1安全内容的更新。苹果公司表示在浏览器中修复了38个问题，其中33个问题影响WebKit。这个安全更新解决了内存损坏、原型访问、密钥链处理、信息披露和验证问题。

  

iOS 10.3在周一发布，解决了影响Accounts、Audio、CoreGraphics、CoreText、FontParser、ImageIO、Kernel、libarchive、Profiles、Safari、Security和WebKit等组件中的84个问题。

  

解决的问题包括处理字体文件中的缓冲溢出漏洞、一个无限递归问题、多个内存损坏问题、带外读取问题或以明文形式向iTunes沙箱网络服务发送请求。其中一个缺陷影响Safari处理JavaScript弹出的消息，导致受害者无法使用浏览器并被以iTunes礼品卡的方式进行勒索。

  

苹果公司还发布了tvOS 10.2解决56个问题，而watchOS 3.2解决了其中34个问题。另外，苹果还推出macOS Server 5.3解决了3个漏洞，并为Mac推出Pages 6.1、Numbers 4.1和Keynote 7.1，且为iOS推出Pages 3.1、Numbers 3.1和Keynote 3.1解决Export中的一个问题。
