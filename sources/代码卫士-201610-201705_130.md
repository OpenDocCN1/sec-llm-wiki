# Windows 0day漏洞修复前已被犯罪分子利用

**趋势科技周五表示，微软本月修复的一个漏洞CVE-2017-0022在去年夏天就曾被网络犯罪分子利用。**

  

微软在今年2月补丁星期二修复了很多漏洞，包括三个在修复前就被利用的漏洞。其中一个是上述提到的漏洞CVE-2017-0022，它是一个XML核心服务信息披露漏洞，目标用户可点击特别编制的链接通过IE浏览器被利用。微软在安全公告中表示，“当微软XML核心服务（MSXML）不正确地处理内存中的对象时就会存在一个信息漏洞。如成功利用，攻击者就能测试磁盘中是否存在文件”。

  

趋势科技发现这个漏洞后于去年9月份报告给微软。研究人员表示这个漏洞自2016年7月起就被用于AdGholas恶意广告活动中，并且在2016年9月份被加入Neutrino利用工具包中。安全专家认为它CVE-2017-0022取代了同样被用于AdGholas和另外一个恶意广告行动中的CVE-2016-3298和CVE-2016-3351。安全研究人员几个月前表示后两个漏洞已被网络犯罪分子用来躲避研究人员，很显然CVE-2017-0022也被用于类似目的。

  

趋势科技分析人员表示，攻击者能够利用CVE-2017-0022漏洞访问用户系统中发现的文件信息。另外，攻击者还能检测系统是否使用特定的安全解决方案尤其是那些用来分析恶意软件的解决方案。

  

趋势科技已公开了这个漏洞的技术分析和微软发布的补丁。另外该公司还简要解释了这个漏洞是如何被用于Neutrino利用工具包中的。
