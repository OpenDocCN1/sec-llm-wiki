# 维基解密披露CIA如何入侵iPhone和MacBook

**维基解密刚刚公布了另外一批机密文档，关于CIA用于攻击苹果MacOS和iOS设备的利用代码和入侵技巧。**

  

这批机密文档被命名为“暗物质”，披露了CIA下属EDB机构（即创造了“哭泣天使”攻击的机构，主要专注于入侵Mac和iOS固件）开发的macOS漏洞和攻击向量。

  

**通过无法删除的恶意软件感染苹果设备**

  

这批新公布的文档披露称CIA自从2008年就针对iPhone发动攻击。它创建了专门用于感染苹果古剑的一种恶意软件，即使操作系统已被重启，对MacOS和iOS设备的感染仍会继续。

  

**“音速螺丝刀”入侵工具**

  

其中一份文件的时间标记为2012年11月，披露了“因素螺丝刀 (Sonic Screwdriver”项目的详情。CIA指出，它是一种“当引导Mac笔记本或桌面时，用于在外围设备执行代码的机制”。文档中描述的入侵方法能通过一个插在计算机Thunderbolt端口中的以太网适配器访问一台Mac的固件。因此，黑客能从一台外围设备如USB或外部驱动传播恶意软件，“即使设备的固件密码启用”也无济于事。

  

**“夜空”iPhone植入**

  

文档中还披露了CIA“夜空 (Nightskies) 1.2”，它是针对iPhone的一款“信标/加载器/植入工具”。值得注意的是夜空的第一个版本在2007年就已开始运行，主要是感染供应链“刚出厂”的iPhone。

  

这次“暗物质”泄露文档是维基解密解密的第二波文档。此前的Vault 7文档主要披露了软件和设备中的多个安全漏洞，包括iPhone、安卓手机和三星电视机等。
