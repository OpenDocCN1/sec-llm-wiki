# 黑客喊话苹果：不交钱就远程清除3亿台iPhone的数据

**在使用iCloud同步苹果设备吗？如果是，那么到4月7日，你的私人数据可能会被暴露或删除。**

  

一个自称为“土耳其犯罪家族 (Turkish Crime Family)”黑客团伙声称已获取访问超过3亿个iCloud账户的权限，目前正在威胁苹果公司支付7.5万密币或等值于价值10万美元的iTunes礼品卡，否则他们将远程清除这些设备中的数据。黑客要求以比特币或另外一种流行密币以太坊 (Ethereum)。

  

周二，媒体Motherboard在一名声称代表该黑客集团的黑客分享了跟苹果安全团队的邮件截屏后报道此事。从截屏来看，苹果安全团队要求提供被黑账户的样本列表以确定真伪，不过该黑客组织仅提供了一个YouTube视频证明已获取所声称的一个被黑账户并远程从该设备中清除了所有内容。在推特账户上，该黑客组织声称拥有对2亿个iCloud账户的访问权限，但在其中一份邮件中表示对3亿个苹果邮件账户有访问权限，而在另外一份邮件中，数字又变成5.59亿。

  

目前，即使苹果公司也很难验证该事件的真伪。然而，苹果已告警该黑客组织称不会违反法律姑息犯罪分子并要求他们删除视频。而黑客组织则将最后期限定为4月7日。

  

**如何防止iCloud账户被黑**

  

不管该黑客团伙带来的威胁是真是假，如果他们获取了对你的iCloud账户访问权限，那么他们就能轻松下载所有的图片和其它私人数据。建议苹果用户立即更改iCloud密码并启用双因素验证。

  

2014年，iCloud账户被黑导致出现艳照门事件。数百张女性名人的裸照被曝光，而这些均窃取自他们的iCloud账户。一些人由此认为该黑客组织就是上周发动艳照门2.0的幕后黑手。然而，目前尚未有证据能证实它们之间的关联。
