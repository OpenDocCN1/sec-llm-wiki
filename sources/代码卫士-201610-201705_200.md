# 被安装百万次的WP插件出现严重漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485574&idx=4&sn=fcd3cd4d8aa5bb414990b98e4291f12c&chksm=ea9739ecdde0b0fa200d3721f60ceb53fba3182967171413ebb2367b5c767a8fb4e7c927c124&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485574&idx=4&sn=fcd3cd4d8aa5bb414990b98e4291f12c&chksm=ea9739ecdde0b0fa200d3721f60ceb53fba3182967171413ebb2367b5c767a8fb4e7c927c124&scene=27#wechat_redirect)

**研究人员发现WordPress影像图库插件NextGEN图库的活跃安装量已超百万次，它受到严重的SQL注入漏洞影响。**

  

Sucuri网络安全公司研究人员识别出这个漏洞，发现远程攻击者能够轻易获取目标网站数据库的访问权限，包括敏感数据如密码和密钥。

  

SQL注入漏洞之所以存在是因为插件的开发人员并没有正确清洁用户输入。上周随着版本2.1.79的发布，这个问题也得以解决，但并未在日志更改中提及。研究人员表示这个漏洞非常严重，如果使用的是易受攻击的版本，那么就需要立即更新。

  

研究人员指出存在两种攻击场景：一是目标站点使用了NextGEN Basic TagCloud Gallery，一是用户可提交帖子供审查。在第一种攻击场景下，攻击者可通过修改图库的URL来执行SQL查询。在第二种场景下，经验证的攻击者能够通过短代码执行恶意代码。

  

目前尚未有关于漏洞被利用的报告，但考虑到潜在的易受攻击程序数量巨大，未来将会见到此类攻击。这并非研究人员在NexGEN图库插件中首次发现严重漏洞。去年研究人员发现了一个远程代码执行漏洞。

  

RIPS技术公司去年开展的研究结果显示官方WordPress插件目录中的8800个插件都至少受到一个漏洞的影响。几乎有2800款app存在高危漏洞，41款app存在严重漏洞。

  

WordPress仍然是受到攻击次数最多的目标内容管理系统，攻击者在攻击WordPress网站时可以选择很多漏洞。1月份，WordPress修复了一个导致大量网站可被利用的严重漏洞，可造成涂鸦和远程代码执行，不过开发人员并未立即披露漏洞的存在，目的是让人们有足够的修复时间。
