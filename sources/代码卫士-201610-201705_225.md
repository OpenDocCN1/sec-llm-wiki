# TeamSpy恶意软件将TeamViewer变为监控工具

**TeamSpy恶意软件又回来了，而且将TeamViewer转变为监控工具。**

  

安全企业Heimdal表示，上周末出现了一次新的垃圾邮件攻击活动，TeamSpy恶意软件能让黑客获取访问受攻陷计算机的完全权限。这款恶意软件并非首次出现。早在2013年，它就给无数台计算机造成损失。当时受害者有普通用户，也有在各个行业和研究机构工作的高级别人士，甚至还有外交官。

  

然而，这次TeamViewer并未被攻陷，因此用户密码应该还是安全的（但请不要重复使用了）。攻击者似乎使用了社工技巧并利用人们对使用计算机和互联网时粗心大意的习惯诱骗受害者安装恶意软件。

  

**攻击方式**

  

首先，攻击者会利用邮件诱骗受害者下载一个压缩文件，当受害者打开文件时就会触发其中的.exe文件被激活。TeamSpy代码随后就会被释放到受害者的计算机上作为一个恶意DLL。安全研究人员观察到的邮件主题中包含”eFax message from “1408581\*\*”。

  

跟之前一样，犯罪分子都会将合法的TeamViewer版本安装到受害者的计算机上，然后通过DDL劫持修改行为确保它是隐秘的。TeamSpy恶意软件中包含多种组件如键盘记录器和TeamViewer VPN。

  

这些日志会被复制到一个文件中，其中增加了所有可用的用户名和密码。该文件会持续被发送到一个命令和控制服务器中。

  

需要注意的是，攻击能够规避双因素验证并且能够给网络犯罪分子访问受害者未加密但被犯罪分子加密的内容。

  

目前对恶意软件的检测率很低，只有15/58，也就是说只有15个被测试的杀毒软件能够检测出恶意软件，包括卡巴斯基、ESET、Cyren、迈克菲、微软、Sophos、赛门铁克等。

  

攻击尚处于最开始阶段，用户要特别注意收到的邮件并不要下载看似不受信任的任何文件。
