# 勒索软件淘金：75%来自讲俄语的犯罪分子

**人人都知道俄罗斯黑客异常忙碌，不过自从知道接近75%的勒索软件都来自讲俄语的网络犯罪分子后，还是让人惊讶。**

  

卡巴斯基实验室的恶意软件高级分析师Anton Ivanov指出，在公司研究人员去年发现的62个加密勒索软件家族中，有47个是由俄罗斯人或者讲俄语的人开发的。

  

他指出，这个结论基于对地下黑市、命令和控制基础设施和其它可从网络中找到的产品。要知道为何如此多的勒索软件家族都有俄语根源还难以有定论，但其中一个可靠原因就是俄罗斯及其邻国有很多教育良好且技能熟练的编程人员。

  

卡巴斯基的数据显示，所有的勒索软件家族在2016年攻击了超过140万人。当然，有很多方式可以绕过勒索软件，比如可以通过免费解密工具来解密某些变种或者利用No More Ransom等计划来获取免费协助摆脱监控设备的间谍们。

  

通过对2016年攻击数据的分析，卡巴斯基还注意到普通用户平均每10秒钟就会遭受加密勒索软件的攻击，而组织机构每隔40秒就会被攻击。

  

在过去的几年中，攻击频率急剧增长，而且还能明显觉察出一年中的攻击高峰。勒索软件并非新型恶意软件，它已存在了10多年。不过黑客现在才发现利用这种攻击牟利更多。
