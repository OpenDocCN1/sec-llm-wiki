# NSA前员工创立的数据管理公司Immuta融资800万美元

**由美国国家安全局前技术人员创立的数据管理公司Immuta宣布A轮融资800万美元。**

  

该轮融资由Drive Capital领投，Drive Capital还获得董事席位，另外还有Greycroft Partners和Conversion Capital参与，最终融资金额达到950万美元。

  

Immuta位于美国马里兰州米德堡，距离NSA不过一小段车程。目前Immuta拥有21名员工，位于大学城。2014年10月份，Immuta正式成立，并于2015年夏进入市场。

  

Immuta的首席执行官Matthew Carroll表示公司旨在回答这样一个问题：如何提供一种既能给数据科学家完成任务的自由，又能时刻掌握进度？数据科学家可通过使用Immuta创建受监管并合规的数据沙箱环境，这种环境结合了组织机构内外部不同的数据来源。公司声称“支持每种主要的结构化和非结构化、以及在本地服务器和云上的数据来源，包括Amazon S3、SQL、NoSQL和Hadoop”。

  

不管来源是什么，Immuta的平台都能将数据虚拟化以保证完整性，并作为终端用户和数据来源之间的一个层，这样数据拥有人就能够谨慎披露数据，并能让数据科学家不必担忧访问权限的情况下开展实验。

  

公司创始人都没有对自己在NSA的工作披露太多，不过表示他们现在做的很多事情都是基于斯诺登解密事件后在政府部门磨炼过程中学到的。虽然该公司尚未公布其公共行业的消费者，但表示会包括全球金融机构、电信公司和国家安全组织机构以及案例用户通用电气。

  

Immuta在政府治理方面的风格可从其渊源和早期雇佣首席隐私官和法律工程师Andrew Burt一事中就可看出来。Andrew Burt曾在FBI担任联邦网络部门助理主管的特别政策顾问一职。

  

投资人员表示，Immuta解决的问题是当前最严峻的创新不力问题，而数据访问法规和使用法规都在阻碍创新，之所以投资Immuta是因为它拥有最好的团队和技术。
