# 美国或要求签证申请人提供社交媒体密码

**美国国土安全部部长John Kelly周二表示，美国大使馆可要求签证申请人提供社交媒体账户密码供背景调查。**

  

Kelly指出，此举是通过加强对游客的审查来筛选出可能带来安全威胁的人员。他表示这是对来自7个莫斯林国家游客拟实施的措施之一在，这些国家包括伊朗、伊拉克、利比亚、索马里、苏丹、叙利亚和也门。

  

Kelly表示，要真正审查来自这些国家的人员非常难，但是如果他们来美国的话，美国要求知道他们访问了什么网站并交出密码。这样就能知道他们上网都在干什么。如果他们不合作的话，那么就无法去美国。

  

Kelly强调称最终决策还未做出，但表示未来会实施更加严格的筛选措施，即使这意味着访客的美国签证将会延迟发放。

  

这七个国家是特朗普在1月27日颁发一名和难民禁令的目标国家，不过这项禁令目前来看至少是暂时被法庭驳回了。
