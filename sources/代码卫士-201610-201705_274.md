# 审计：美国国土安全部使用老旧且未修复的系统

**一份来自美国****总监察长办公室（OIG）的报告****指出，美国国土安全部（DHS）在信息安全计划方面已经做出改进，但多个地方仍然存在问题。**

  

2015年美国人事管理局遭受严重的数据泄露事件后，DHS等相关部门已被令要求采取措施改进网络安全基础架构。OIG在2016年财年发布的报告指出，DHS确实已经采取措施增强其信息安全计划。然而，截止2016年8月份，评估人员仍然从机密和非机密系统中识别出多个弱点。虽然相关机构已经在计算机中开始执行安全配置，但仍然有很多系统并未被覆盖。

  

评估人员还发现一个机密服务器运行Windows Server 2003，而后者在2015年7月起就不再接受安全更新。只有74%的Windows Server 2008和65%的Unix服务器进行了适当配置。多个工作站和服务器都在运行未修复的Java版本、杀毒软件、IE、多媒体播放器、微软Office、及Adobe Acrobat和阅读器。调查人员指出其中某些应用程序自2011年3月起就未更新，导致DHS数据存在风险。

  

自美国人事管理局遭受数据泄露事件以来，美国政府就要求DHS为权限访问账户和非权限访问账户通过个人身份验证卡来部署更加强大的验证机制。然而，公民及移民服务局（USCIS）、运输安全管理局（TSA）和海岸警卫队（TSA）等机构在评估时点仍未完全按照要求行事。

  

此外，DHS及其相关机构包括FEMA、特勤部和TSA仍未能确保远程访问已被有效防御。OIG提出一系列建议协助DHS进一步强化其安全计划，并提出一系列措施解决相关问题。
