# Windows 10 周年更新版安全性更高 可抵御未打补丁的漏洞攻击

**微软表示其Windows10周年更新版比以往版本更加安全。**

  

8月份的更新进行了一系列的操作系统安全改进，包括增强Windows Defender和AppContainer的使用，旨在提高利用零日漏洞在系统上运行的难度。

  

微软的安全团队针对提供的漏洞利用减缓技术对两个零日漏洞（CVE-2016-7255, CVE-2016-7256）进行了测试，这两个漏洞被黑客用于特权提升。

他们发现，在进行的压力测试中，漏洞在还未安装补丁的周年更新版机器上的利用被中断。

  

该团队表示：“由于搜索漏洞需要时间，并且找到所有漏洞是不可能的，所以这样的安全增强对于防止基于零日攻击是至关重要的。虽然修复单点漏洞有助于消除特定类型的漏洞，不过微软安全团队仍在继续寻找机会引入越来越多的缓解技术。”

  

在对AppContainer进行改进后，将字体解析代码推送到隔离容器，并且对字体文件解析进行额外验证，这将大大降低使用字体漏洞进行特权升级的能力。

  

Windows 10的周年更新版在核心Windows组件和Microsoft Edge浏览器中引入了许多其他缓解技术，帮助保护客户免受最近甚至未公开的漏洞攻击。

  

之前微软曾宣布将在2018年7月停止EMET（enhanced mitigation toolkit，增强缓解工具包）对Windows 8、7和Vista的支持。

  

但这一举动引起卡内基梅隆大学的专家WillDormann的反对，他表示该工具包明显改进了Windows 10的漏洞利用程序，应该继续维护而不是丢弃。
