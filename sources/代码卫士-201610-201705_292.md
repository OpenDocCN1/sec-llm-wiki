# Adobe偷偷用Chrome扩展收集用户数据

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485599&idx=4&sn=674d7c6fd36e408c5d71972199050698&chksm=ea9739f5dde0b0e3f1df949ae5dc9f94fec9bc28fdfbe672007c05934c83946aa96f10a3efe4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485599&idx=4&sn=674d7c6fd36e408c5d71972199050698&chksm=ea9739f5dde0b0e3f1df949ae5dc9f94fec9bc28fdfbe672007c05934c83946aa96f10a3efe4&scene=27#wechat_redirect)

**Adobe上周二发布软件安全更新，不过除补丁之外，用户还收到了意料之外的东西：一个谷歌Chrome扩展被偷偷安装到了系统中。**

  

SwiftOnSecurity在推特上表示最新的Adobe Reader更新还包括一个Chrome扩展，利用遥测功能收集用户信息。这个扩展是Adobe Acrobat，当用户安装安全更新时会被自动添加到Chrome中，不过打开Chrome浏览器时需要用户手动启用。

  

这个扩展的不同之处在于，它会要求获得多个权限，包括“读取并更改所访问网站的所有用户数据，管理用户下载，并跟合作的原生应用程序通信”。这款应用程序的最初目的是让用户将网站转换为PDF文档然后可在Adobe Reader中打开。这一功能要比整合到Chrome的PDF功能强大。不过要将网站转换为PDF需要使用付费的Acrobat版本，所以如果没有这些功能它就只是一款PDF阅读器。

  

**遥测数据**

  

这款PDF阅读器还会收集用户数据并将其发送到Adobe的服务器。Adobe在一份安全公告中指出只会收集浏览器类型和版本、Adobe产品信息如版本、和Adobe功能使用如目录选项或所选的按钮；而不会收集其他信息。

  

然而，Adobe并未说明会将Chrome扩展捆绑到安全更新中。这个扩展确实会在启动前询问用户，但用户并没有收到提示说明在补丁中进行安装。所以Adobe实际在未告知用户且寄望于用户不会发现的情况下将遥测数据收集扩展安装到了用户系统中。

  

目前Adobe并未做出任何评论。
