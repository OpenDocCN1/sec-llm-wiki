# 谷歌推出Cloud Key Management Service

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485600&idx=1&sn=b0b65ec1ac142d98d9a9b77daa29f99c&chksm=ea9739cadde0b0dc45e202482c42d333ef4c1046dedd838da592f795aa07f386156c49f7cda2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485600&idx=1&sn=b0b65ec1ac142d98d9a9b77daa29f99c&chksm=ea9739cadde0b0dc45e202482c42d333ef4c1046dedd838da592f795aa07f386156c49f7cda2&scene=27#wechat_redirect)

**周三谷歌推出了Cloud Key Management Service测试版，用以帮助Google Cloud Platform（GCP）客户处理加密密钥。**

  

产品经理Maya Kaczorowski在一篇博客中表示：“Cloud KMS为用户提供了基于云的信任根，用户可进行监控和审计。对于难以扩展和维护的定制款密钥管理系统，Cloud KMS使保护密钥安全变得容易很多。”

  

随着2013年前NSA承包商爱德华·斯诺登对在线监控的披露，加密对云服务提供商变得更加重要。

  

谷歌从2015年6月开始提供CSEK（customer-supplied encryption keys）。但它并没有为云端客户提供加密的方法。Amazon Web Services在2014年6月为S3引入了CSEK，并于11月推出AWS Key Management Service。微软Azure在2015年1月通过Key Vault添加了CSEK。

  

GCP客户可以使用Cloud KMS创建、使用、旋转（随意或有计划性的）和破坏AES-256对称加密密钥。Cloud KMS提供了一个REST API，可使用密钥来加密或解密数据。

  

Cloud KMS集成了Cloud Identity Access Management和Cloud Audit Logging，这两个服务与GCP相关。

  

Kaczorowski表示Cloud KMS依赖于Galois/Counter模式下的高级加密标准（AES）。根据Kaczorowski的说法，谷歌会使用Project Wycheproof这样的工具，不断检查BoringSSL库中的实施情况。
