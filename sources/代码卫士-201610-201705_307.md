# APT恶意软件瞄准美国 更大阴谋或尚未显现

**2013年4月份，火眼研究人员发现APT恶意软件MM Core，如今它盯上了中东、中亚、非洲和美国。**

  

当时研究人员就认为MM Core有一些很有趣的特征。它旨在收集关于受感染计算机的信息随后会设置后门供远程访问。它的第一个版本是BaneChant（被标记为2.0-LNK），攻击对象是位于中东和中亚的组织机构。BaneChant在逃避沙箱之前会等待多次鼠标点击。另外，它还会使用URL短网址服务保护命令和控制服务器不会被列入黑名单，而且它还会将恶意代码下载到内存以阻止调查人员从受感染设备的硬盘中进行提取。

  

2013年6月末，来自“情境信息安全”公司的研究人员发现了MM Core的一个新变体，名为StrangeLove（2.1-LNK）。它的功能基本跟最初版本一样，不过是对下载器进行了一些更改，攻击目标是位于中东的组织机构。

  

最近来自Forcepoint的研究人员发现了另外两个新变体：BigBoss (2.2-LNK)和SillyGoose (2.3-LNK)。这两个版本的使用都很活跃，前者自2015年年中就开始被使用，而后者从2016年9月份开始传播给受害者。研究人员指出这两个变体针对的是非洲和美国。具体的攻击目标是新闻和媒体、政府（国防部门）、石油和天然气和通信行业。

  

而且这两个新变体的后门代码跟之前的BaneChant和StrangeLove很类似，不同的就是文件名和互斥器以及下载器利用的漏洞。这两个最新版本利用的是CVE-2015-1641来提取恶意软件而前两个变体利用的是CVE-2012-0158。

  

研究人员发现一些下载器组件是通过签发给一家名为Bor Port的俄罗斯组织机构的有效数字证书签名的。专家认为证书可能是犯罪分子偷盗的，因为用自己公司的证书签名恶意软件是不可能的。为了阻止研究人员追踪基础架构，攻击者开始使用WHOIS隐私保护服务保护新的命令和控制服务器的域名。研究人员还指出，虽然MM Core的样本量低，但他们发现下载器跟另外一款更加活跃的下载器Gratem共享代码、技术和基础架构；另外这两个下载器还共享相同的证书。Gratem最晚出现于2014年。这或许证明MM Core实际上属于尚未被完全查出的规模更大的恶意行动。
