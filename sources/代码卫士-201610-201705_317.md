# 黑客利用WhatsApp窃取银行登录凭证

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485607&idx=2&sn=8394f3883ac0a9d1deca52d5d2bde655&chksm=ea9739cddde0b0db9dd960d6a455d7abd1d758b4476107f64c8aafa216c3467d7cddc4dd46c2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485607&idx=2&sn=8394f3883ac0a9d1deca52d5d2bde655&chksm=ea9739cddde0b0db9dd960d6a455d7abd1d758b4476107f64c8aafa216c3467d7cddc4dd46c2&scene=27#wechat_redirect)

**黑客正利用一种新型的移动病毒针对用户发动攻击，它通过WhatsApp发送看似合法的文档被传播，随后窃取用户的敏感信息如在线银行凭证。**

  

虽然IB Times并未明确说明这款恶意软件所针对的操作系统，不过从以往经验来看，这类恶意软件仅对谷歌的操作系统而不是iPhone操作系统起作用。另外，这些“WhatsApp病毒”仅在印度发现，那里充斥着运行老旧安卓系统的低端安卓智能手机。

  

黑客利用印度的两大组织机构说服用户点击消息附件。这些恶意WhatsApp消息包括印度主要的组织机构名称。通过信息流传的文档通常是Excel格式，不过Word和PFD文件格式也有出现。这些文档能够访问个人手机上的信息如银行凭证和PIN码。

  

印度情报机构已经向国防和安全机构发出通告，据悉这次攻击主要针对印度军人。从事国防行业、准军事部队和警察部队的人可能是被攻击的对象。目前尚不清楚这款病毒在手机或平板上还是否存在其它企图，以及WhatsApp是否采取了相关拦截措施。

  

最新关于安卓病毒最让人毛骨悚然的案例是，俄罗斯情报机构通过一款安卓病毒追踪乌克兰武器以及军队精确位置。而保护数据的最佳方式依然是不要点击可疑链接，无论信息是如何收到的；而且要从官方应用商店下载app。
