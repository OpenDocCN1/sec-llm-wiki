# PHPMailer出现严重漏洞 数百万站点易被远程利用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485611&idx=3&sn=c8a5282e42ee831335cba07d0fa0fdfd&chksm=ea9739c1dde0b0d74af1f3910d30e0afae5ee51e3e80523ff940c18b5d77a16a58c1e17b253b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485611&idx=3&sn=c8a5282e42ee831335cba07d0fa0fdfd&chksm=ea9739c1dde0b0d74af1f3910d30e0afae5ee51e3e80523ff940c18b5d77a16a58c1e17b253b&scene=27#wechat_redirect)

**PHPMailer****是全球最流行的开源****PHP****库之一，超过****900****万名用户都在用它发送邮件。研究人员在****PHPMailer****中发现了一个严重漏洞。**

数百万个PHP站点和流行开源网络应用程序如WordPress、Drupal、1CRM、SugerCRM、Yii和Joomla都通过PHPMailer用各种方式如SMTP为用户发送邮件。

  

波兰安全研究员Dawid Golunski发现了这个漏洞（CVE-2016-10033），它允许攻击者在网络服务器的环境下远程执行任意代码并攻陷目标网络应用程序。他指出，“要利用这漏洞，攻击者能够针对常见的网络组件如通讯录/反馈表单、注册表单、密码邮件重置等，通过PHPMailer类的易受攻击版本来发送邮件”。

  

Golunski将这个漏洞告知开发人员，后者已在新版本PHPMailer 5.2.18中修复了这个漏洞。之前所有的版本均受影响，强烈建议网络管理员和开发人员更新至修复版本。出于安全考虑，Golunski尚未公布更多关于该漏洞的详细技术细节，不过他表示不久之后将会发布PoC利用代码和视频演示。
