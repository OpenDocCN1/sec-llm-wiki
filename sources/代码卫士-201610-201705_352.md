# Skype后门潜伏5年之久 Mac OS X用户应尽快升级

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485619&idx=3&sn=acc8ab8f4f6b7cb1dec44cf97dcc9a7e&chksm=ea9739d9dde0b0cf4704310fc373890aafd9d9c2f7337f84b62d2e226a8ceaf1a8b81a158cb4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485619&idx=3&sn=acc8ab8f4f6b7cb1dec44cf97dcc9a7e&chksm=ea9739d9dde0b0cf4704310fc373890aafd9d9c2f7337f84b62d2e226a8ceaf1a8b81a158cb4&scene=27#wechat_redirect)

**Trustwave****安全实验室的分析师发现了隐藏在苹果****macOS****和****Mac OS X****操作系统上运行的****Skype****中的后门。该后门能在用户不知情的情况下监控用户的通信往来。**

 这个后门实际上存在于Desktop API中，允许第三方的插件和app跟微软的Skype通信。这个后门似乎至少在2010年就存在了，它能够允许任意恶意的第三方app绕过验证程序并且提供Mac OS X上Skype版本的几乎所有权限。

  

**如何完全控制****Skype****？**

如果恶意app能够“将自己识别为代表Skype Dashboard工具程序负责与Desktop API进行交互的程序”，那么恶意app就能绕过验证程序。访问这个后门极其简单。黑客所需要做的很简单，只需将app中的文本字符串更改为”Skype Dashbd Wdgt Plugin”，Desktop API就会提供对Skype敏感功能的访问权限。

  

攻击者或者任何利用了这个隐藏后门的恶意程序都能执行以下行为：

*   读取收件箱（及其内容）的通知
    

*   拦截、读取并修改信息
    

*   登录并记录Skype通话音频
    

*   创建聊天会话
    

*   检索用户联系信息
    

研究人员还提供了PoC代码，能够在不要求用户权限的情况下触发进程跟Skype相连。该后门据称是Skype的一名开发人员在微软收购公司之前创建的，有超过3000万的Mac OS X用户信息被暴露。

  

**立即更新****Skype****版本**

Trustwave于10月份将此漏洞告知微软，后者已在Skype 7.37及以后版本中修复了这个漏洞。微软的一名发言人表示，“我们在产品中不设置后门，但是我们会持续改进产品体验和产品安全，并且鼓励用户总是升级至最新版本。”Trustwave还认为这个后门可能是Skype“在实现dashboard插件的进程中”不小心留下的，原因是Skype dashboard工具并没有利用这个后门。

  

所有macOS和MacOS X上的Skype版本，包括7.35在内均易受攻击。强烈建议用户尽快升级至最新版本。
