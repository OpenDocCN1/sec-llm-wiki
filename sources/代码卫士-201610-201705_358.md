# 互联网世界也应守法

**一位17岁少年因对英国互联网提供商TalkTalk进行了非法攻击，他的iPhone手机被没收12个月。**

  

该青少年在英格兰东部的诺维奇青年法院受到判决，除了手机他的硬盘也被带走。

  

这位青少年曾经使用黑客工具对网站进行SQL注入攻击，进行了未授权访问并在线分享。他表示这样做的目的只是“向我的伙伴炫技”。

  

他并没有从黑客行为中获取任何经济利益，但漏洞被披露后TalkTalk的网站预算增加了14,000倍。

  

2015年10月TalkTalk发生的数据泄露事件影响了其4%的客户，约15,656位订阅者的银行账号和分类代码被盗，而TalkTalk为此事花费了3500万英镑。

  

在今年的前3个月中，有上千名客户弃用了TalkTalk的宽带服务。TalkTalk因允许攻击者“轻易”访问客户数据被ICO罚款£400,000。

  

ICO老板伊丽莎白·德纳姆（Elizabeth Denham）表示TalkTalk未能实施“最基本的网络安全措施”。

  

这位青少年对其七次黑客入侵行为认罪。两次与TalkTalk有关，另外几次还攻击了曼彻斯特大学、剑桥大学以及武术徽章提供商Merit Badges的网站。
