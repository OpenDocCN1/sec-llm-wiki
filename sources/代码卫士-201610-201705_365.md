# 赛门铁克：多数外部PowerShell脚本都是恶意的

**PowerShell是一种脚本语言和shell框架，多数Windows电脑都默认安装。现在它成为恶意软件实施感染的热门工具。赛门铁克发表报告称，超过95%的PowerShell脚本都是恶意性质。**

  

Powershell这种框架的灵活性能被攻击者用来下载恶意有效负载、执行侦察行动或者遍历网络。赛门铁克认为95.4%的PowerShell脚本都是恶意的，说明它对于消费者和企业来说都是一种重大威胁（尤其涉及到外部PowerShell脚本时）。

  

许多新近发现的针对性攻击都在使用PowerShell脚本，因为后者允许无文件感染，银行木马和其它类型威胁的幕后黑手也都开始使用它。

  

最新的一次案例是August利用PowerShell窃取凭证和敏感文件。该组织通过包含宏的恶意Word文档传播恶意软件。一旦Word文档被启用，就会启动一个PowerShell命令来下载并安装最终的有效负载。

  

研究人员表示他们还观察到其它很多利用Office宏和Powershell下载有效负载的实例。实际上目前使用PowerShell 的最流行的恶意软件家族包括W97M.Downloader (9.4%)、Trojan.Kovter (4.5%)、和JS.Downloader (4%)。赛门铁克恶意软件分析沙箱光今年就收到49.127份PowerShell脚本，而且研究人员还手动分析了4,728个独特的样本，它们代表利用PowerShell命令行的111个恶意软件家族。2016年收到的样本数量急剧增长，主要是受到JS.Downloader和Kovter的影响。

  

赛门铁克指出，攻击者多数利用PowerShell脚本后攻陷的方式来下载额外的有效负载，而且它们还利用多种技术来确保脚本被执行，例如使用扩展等。研究人员还表示，在10,797份PowerShell脚本执行中，55%的脚本是通过cmd.exe启动的，而恶意脚本中有95%是通过cmd.exe执行的。不过因为多数宏下载在被执行前就遭到拦截，因此并未到达研究人员这里进行分析。

  

赛门铁克建议通过升级到最新版本的PowerShell并启用扩展的日志功能来加强防御。
