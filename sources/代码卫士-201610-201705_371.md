# 雅虎邮件服务有漏洞 黑客可访问任意邮件

**雅虎目前修复了邮件服务中的一个重要安全漏洞，该漏洞可允许攻击者监控任何用户的收件箱。**

  

来自安全公司Klikki Oy的芬兰安全研究人员Jouko Pynnönen在雅虎邮件服务中发现了一个基于DOM的持续XSS漏洞，攻击者可发送内嵌有恶意代码的邮件。他在博客中演示了攻击者如何将受害人的收件箱发送到一个外部网站，并且创建一种通过将恶意脚本添加到消息签名的方式可附着在所有发出邮件中的病毒。

  

由于这个恶意代码位于消息的主体内容部分，一旦受害者打开被感染的邮件代码就会被执行，而且隐藏的有效负载脚本会偷偷将受害者的收件箱内容提交给被攻击者控制的外部网站。

  

出现这个问题的原因是雅虎邮件服务没有正确地过滤HTML邮件中可能存在的恶意代码。Pynnönen指出他通过暴力将所有已知的HTML标签和属性输入过滤器（雅虎用来过滤恶意HTML的过滤器），但发现某些恶意HTML代码设法通过了过滤，因此他找到了这个漏洞。

  

Pynnönen指出，他给雅虎安全团队发送了一封邮件，如被查阅，那么攻击者就会使用AJAX读取用户的收件箱内容并将其发送到攻击者的服务器。这个PoC是通过雅虎的HackerOne漏洞奖励计划发出的，Pynnönen因此获得1万美元的奖励。

  

Pynnönen曾在今年年初报告了雅虎邮件服务网页版本中存在的一个类似问题，并因此获得1万美元的奖励。他还在2015年12月份发现了雅虎Flicker中存在的一个存储型XSS漏洞，并因此获得500美元的奖励。
