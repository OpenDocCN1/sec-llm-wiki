# 普京批准网络安全新政主张

**俄罗斯总统普京周二批准了一项旨在提升国家对抗外国网络攻击并打击外国所带来的影响。**

  

自上个月美国指责俄罗斯干扰美国大选之后，俄罗斯提出了新的信息安全政策主张。它是对2000年颁布的政策升级，它描述了俄罗斯所担忧的大量威胁，比如外国入侵和国外对俄罗斯的负面报道、“对俄罗斯精神和道德价值观的恶化”。

这项新政策并未提出明确细致的计划，但确实确立了新政的总体目标，包括提升俄罗斯军队的对外宣传力度、并且加强对俄罗斯互联网的控制。

  

乌克兰危机之后，俄罗斯跟西方的关系跌至冷战后的最低水平，二者之间的摩擦不断。俄罗斯已经通过大量国有频道和媒体加强对俄罗斯在全球范围内的宣传。
