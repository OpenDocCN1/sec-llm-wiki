# 英国移动网络运营商因员工密码被盗 发生数据库泄露事件

**英国最大的移动网络供应商之一已确认发生数据泄露事件的消息，由于员工登录凭证被偷导致超过10万客户的资料被窃取。**

  

尽管财务信息没有被访问，但合同和设备信息都被泄露。客户的个人信息也被泄露，包括姓名、地址、出生日期等。公司发布的声明表示，犯罪分子以升级为由欺骗客户，试图拦截和窃取他们的设备。

  

犯罪分子通过使用员工的合法凭证，访问了客户的数据库，这意味着数据库仅受密码保护。

  

2016年DBIR（Verizon Data Breach Report，Verizon数据泄露报告）显示，多数数据泄露都与密码有关。最新的数据显示63%的数据泄露都涉及到弱、默认或被盗的密码。

  

美国最大的健康保险供应商之一Anthem，去年年初发生了非常类似的数据泄露事故。该公司的系统管理员注意到一些并非他所操作的数据库查询操作，从而首次检测到可疑活动。恶意黑客偷窃了五名不同技术类员工的凭证，以合法的身份访问了他们的系统，其中包含8000万客户的个人信息。

  

2014年摩根大通因服务器配置错误且缺乏双因子认证，导致8300万用户受到影响。双因子认证是一种除了密码外，还需要额外的身份验证的安全机制。

  

所有这些数据泄露事件都只因一个密码被盗，而使得系统中数百万用户的个人记录被访问。密码被盗后，可以被任何人在任何地方远程使用，而且只需要一个网络浏览器即可。使用双因子认证使得仅拥有设备的合法用户才能通过身份验证。

  

例如，基于推送的双因子认证，用户使用用户名和密码进行登录。然后，通过手机中的身份验证app，用户会收到一条推送消息，必须在有限的时间内进行验证码认证，才能访问应用程序。

  

这是一种简单、轻松、安全的用户身份认证方式。在访问应用程序之前，不仅需要验证用户的身份，而且需要验证设备的安全性。
