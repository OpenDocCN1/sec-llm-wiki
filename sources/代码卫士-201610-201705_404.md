# 谷歌警告用户小心由政府支持的黑客攻击行为

**据报道，谷歌开始向用户发送新一轮的告警邮件，告知政府支持的攻击者可能会试图窃取用户密码，并提供了一些保护账户安全的方法。**

  

2012年，谷歌首次开始践行通知用户关于政府支持的攻击消息，不过近期这类邮件大幅增长，而很多人认为这跟俄罗斯发动的网络攻击有关。

  

俄罗斯黑客被认为试图入侵谷歌账户的消息虽未得到证实，但谷歌表示仅有约0.1%的用户实际上收到了这些告警信息，但每个人也需要尽可能地保证账户的安全。

  

收到告警邮件的人员是记者或高级别的专业人士如经济学家和《纽约时报》专栏作家Paul Krugman、Jonathan Chait、《纽约》杂志记者以及Politico的Julia Loffe。这些人都在推特上证实收到了告警邮件。

  

如果有用户收到该邮件，最好的办法就是更改密码并启用其它安全功能如双因素验证等。
