安卓木马盯上德国银行app 阻止安全类app启动

Fortinet安全研究人员指出，一款安卓银行木马不仅对反恶意软件app具有弹性，还阻止它们启动。


这款木马是Android/Banker.GT!tr.spy，旨在从德国银行15款不同的移动银行app中窃取用户的银行信息。此外，该木马的作者还从C&C服务器控制了目标app的列表，也就是说能够轻易控制这些目标。


这款木马伪装成一个邮件app，甚至在启动器中会显示一个图标。然而，跟某些移动威胁类似，它也会诱骗用户提供管理员权限。目前，这款木马的图标隐藏在启动器中，但在后台运作。


这款木马会要求获取的权限包括：读取手机状态、读取通讯录、获取任务、写入设置、直接拨打电话、读取/写入/发送/接受短信、访问并更改网络状态等。安装之后，它就会推出三种在后台运行的服务：GPService2、FDService和AdminRightsService。


GPService2旨在监控设备上的所有进程，并通过显示类似合法软件窗口的自定义屏幕来攻击银行app。它针对每个银行app都有不同的自定义登录屏。它还通过禁止杀毒移动app工具启动的方式阻止检测。此外，它还能够跟C&C服务器通信来请求并接受针对每个目标的有效负载。


FDService组件会监控设备上所有的运行进程，不过它是针对具体的app的，除了银行软件外还包括热门社交媒体app。它还会显示一个虚假的谷歌应用商店覆盖图来诱骗用户输入信用卡信息。AdminRightsService旨在要求当该木马首次运行时获取管理员权限，这样木马就很难被删除。


木马被安装后，它就会手机关于设备的信息并将其发送到C&C服务器，随后等待命令执行。这款木马支持的命令包括拦截接收到的短信、发送文本信息、发送USSD请求、将短信发送到所有通讯录、更改C&C服务器地址、添加/删除app、从C&C服务器下载更新后的目标app列表、通过Webview显示基于模板的会话、并将所收集到的信息发送到C&C服务器。


这款木马通过HTTPS来跟C&C服务器通信。除了被盗的银行凭证外，它还发送设备IMEI、ISO国家代码、安卓版本、设备型号和电话号码等。同时它还会收集所安装的app并将其发送到服务器。


要删除这款木马，用户需要首先禁用管理员权限（Settings -> Security -> Device administrators -> Device Admin -> Deactivate），然后通过使用命令“adb uninstall[packagename]”利用ADB来卸载。
