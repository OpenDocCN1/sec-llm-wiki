# 俄安全企业Elcomsoft：iPhone偷偷保留用户通话记录

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485638&idx=1&sn=b0855fb557e513373be082509fd6db54&chksm=ea9739acdde0b0ba82b9be78ef61b37b226ffa9e6e6f65a9d5522228419be805824a9302f976&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485638&idx=1&sn=b0855fb557e513373be082509fd6db54&chksm=ea9739acdde0b0ba82b9be78ef61b37b226ffa9e6e6f65a9d5522228419be805824a9302f976&scene=27#wechat_redirect)

**一家俄罗斯安全企业Elcomsoft发布报告称苹果iCloud保留每部iPhone的整个通话记录，时长达四个月，这让用户很容易沦为执法和监控部门的目标。**

  

Elcomsoft指出，只要用户启用了iCloud，他们的通话记录就会被同步并被保存。日志包括电话号码、日期以及通话时长、甚至还包括漏接电话；此外，它还会记录FaceTime通话日志、来自使用“通话记录”功能的app的呼叫如Facebook何WhatsApp。由于没有针对通话同步的设置，除了禁用整个iCloud功能外别无他法。

  

苹果公司发言人发邮件向The Intercept解释称，“我们提供通话历史同步功能是为了方便用户，他们从任何设备中都能回拨。设备数据是通过用户密码加密的，而且要访问iCloud数据包括备份等需要获取用户的Apple ID和密码。苹果公司建议所有用户都选择强密码并且使用双因素验证。”

  

FBI前特工及计算机取证专家Robert Osgood表示，对于执法部门来说这是一种优势，将通话日志保留四个月是个很长的时间，通常电信提供商会保留30天或60天，因为除了必须要达到要保留的时长外并不想这么做。

  

Elcomsoft的手机破解软件曾被很多黑客在2014年大规模的名人裸照泄露事件中使用过。Elcomsoft的“手机破解（Phone Breaker）”软件据悉能够破解iCloud、微软OneDrive和黑莓的备份文件。
