# 研究人员利用缓冲区溢出漏洞成功黑进公共免费WiFi网络

**随着越来越多的城市提供免费的WiFi网络，一名安全研究人员演示了如何成功黑进他所在城市的WiFi网络。**

  

Equus技术负责人Amihai Neiderman利用了网络负载均衡器（一个反向代理设备）中的缓冲区溢出漏洞，会危及到数以千计的使用城市WiFi服务的用户。

  

Neiderman在召开于罗马尼亚的布加勒斯特的信息安全会议DefCamp7上披露了该漏洞。此次攻击演示了如何轻松利用一台路由器漏洞影响WiFi用户。路由器正越来越多地被用于拒绝服务攻击中，但很多用户并没有意识到公共WiFi的危险。

  

Check Point安全移动区域经理Pavel Berengoltz指出该研究是当前WiFi网络生态系统中存在的许多安全问题之一。从错误配置到漏洞以及未修复的固件，攻击者具有广泛的攻击面来劫持所连接设备的流量。当连接到WiFi网络时，用户应当对不寻常行为“睁大眼睛”。

  

Alert Logic网络安全负责人Paul Fletcher表示，寻找简单版本的设备固件中的逻辑漏洞犹如“大海捞针”，安全专家需要进行“24/7式战斗”，良好的应用程序安全性和DevSecOps实施将最小化这种类型的漏洞。
