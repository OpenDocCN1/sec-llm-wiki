低带宽DDoS攻击能干扰防火墙

原文：http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485641&idx=1&sn=671671615f2934e09d5e175eab63b765&chksm=ea9739a3dde0b0b5bca4a78c467058af26c3cef0025340a9cd287a648c97d07d2d21297a3016&scene=27#wechat_redirect



研究人员告警称某种低带宽的DDoS攻击能够导致一些使用广泛的企业防火墙进入一种临时的DoS状态。


来自丹麦电信运营商TDC的安全专家分析了针对客户的DDoS攻击后发现，一些基于互联网控制消息协议（ICMP）的攻击能够引发严重的干扰，即便在低带宽的情况下也是如此。


ICMP攻击也被称为ping洪水攻击，非常常见但在Type 8 Code 0数据包中很罕见。基于ICMP Type 3 Code 3数据包的攻击引起了TDC的注意。此类攻击被TDC公司命名为BlackNurse，它即使在带宽低到15-18 Mbps的情况下仍然高度有效，而且它们能够在用户网速为1Gbps的情况下干扰防火墙。


专家指出，这种攻击已经存在有20多年了但他们认为组织机构并没有充分意识到它的风险。通过对丹麦IP地址空间的扫描显示有超过170万台设备会响应ICMP ping，说明这些攻击能够产生巨大影响。研究人员目前证实称该攻击可攻陷思科ASA和SonicWall防火墙，不过还可能影响来自Palo Alto及其它厂商的产品。Linux、MikroTik产品以及OpenBSD的Iptables防火墙并未受影响。


虽然在一些情况下由于防火墙漏洞的问题可能会产生攻击，但一些厂商认为是配置的问题。检测规则和PoC代码已公开供用户识别攻击并测试设备。


受影响的厂商包括思科、Palo Alto和SonicWall。SonicWall表示已跟TDC取得联系，测试表示该厂商产品有正常的ICMP洪水攻击保护措施，防火墙不易受攻击。思科在六月份已被告知该问题，不过TDC表示思科并不认为这属于安全漏洞。


TDC建议使用思科ASA防火墙产品的用户否决发送到产品WAN界面的ICMP Type 3信息或者升级到更高端的ASA防火墙。更高端的ASA防火墙有多种CPU内核不易受攻击。可通过专业的反DDoS服务来减缓攻击。
