# VMware工作站中发现代码执行漏洞

**上周日，VMware告知用户称已修复一个严重的带外内存访问漏洞。它影响Workstation和Fusion产品。**

该漏洞编号为CVE-2016-7461，影响拖放功能，能够在运行Fusion或Workstation的主机操作系统上执行任意代码。这个安全漏洞影响Workstation Player和Pro 12.x和Fusion (Pro) 8.x。这个问题已在12.5.2和8.5.2版本中分别修复。ESXi并未受影响。

  

VMware指出，如果同时禁用拖放功能和复制粘贴功能，那么这个漏洞无法在Workstation Pro或Fusion被利用。不过这个权变措施无法在Workstation Player中起作用。

  

这个漏洞是在PwnFest竞赛中被披露的。来自中国奇虎360公司和来自韩国的黑客发现了这个漏洞。

  

VMware上周通知用户称多款产品受到最新披露的名为“脏牛”（CVE-2016-5195）Linux内核漏洞的影响。受影响的产品包括Identity Manager、vRealize Automation和vRealize Operations。VMware已开始发布软件更新解决这个本地权限升级漏洞。Identity Manager、vRealize Automation和vRealize Operation 5.x版本的补丁尚未发布。
