# 五家大型俄罗斯银行遭DDoS攻击

**几个月以来，DDoS攻击大规模上涨，而攻击源多数是来自被黑且不安全的物联网设备。**

  

俄罗斯银行监管局表示，至少有五家俄罗斯银行遭受到大规模的DDoS攻击，持续了两天的时间。卡巴斯基实验室表示，持续时间最长的攻击是12个小时，高峰时每秒从遍布30国家至少2.4万台被黑设备遭受到66万个请求。尽管罪魁祸首看似是被黑的不安全物联网设备如CCTV摄像头或者数字视频记录器，但卡巴斯基认为并非是Mirai僵尸网络所为。

  

被攻击的俄罗斯国有银行Sberbank（俄罗斯联邦储蓄银行）在一份声明中指出银行设法在不干扰网站正常运作的情况下缓和了这次攻击，并表示这次DDoS攻击是该银行有史以来遇到的最强大的攻击。另一家银行Alfabank也证实了此次DDoS攻击，不过认为攻击“相对较弱，并非影响到银行的业务系统”。卡巴斯基表示超过一半的物联网僵尸位于美国、印度、中国台湾和以色列。为了控制设备，黑客利用密码容易被猜到的智能设备作为僵尸。

  

研究人员如今都在说明来自被匆忙推向市场的物联网设备的威胁。这些设备的安全措施很薄弱或者根本没有。由物联网带来的威胁越来越多，因此必须进行防御，其中最基本的就是修改设备默认密码并且使用防火墙增强安全。尽管厂商在保护物联网设备安全方面负有重大责任，但消费者也应该提高自己设备的安全。
