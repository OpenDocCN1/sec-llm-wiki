# 芬兰楼宇供暖系统遭DDoS攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485644&idx=2&sn=7bdaa8f8acde2ebc63006e452a01cff6&chksm=ea9739a6dde0b0b0665eb9fe914e77a50a55e65684431611a1cb27c5a5cdc86f381e74faae62&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485644&idx=2&sn=7bdaa8f8acde2ebc63006e452a01cff6&chksm=ea9739a6dde0b0b0665eb9fe914e77a50a55e65684431611a1cb27c5a5cdc86f381e74faae62&scene=27#wechat_redirect)

**芬兰拉彭兰塔小镇的两栋公寓楼居民这一周多时间以来都冻得瑟瑟发抖，原因是楼宇管理系统遭受DDoS攻击。**

  

报道称攻击拦截了楼宇管理系统的互联网连接，导致远程系统不断重启尝试重新连接，而居民就只能洗冷水澡了。公寓管理公司Valtia的首席执行官表示攻击已在上周四下午结束。

  

该公司在网站上发表简短声明表示，由于“超过90%”的远程系统无法对温度或散热器压力做出预警，系统就会出于安全考虑被关闭。公司表示，“系统必须被积极监控并调整”。

  

厂商Fidelex的一名代表表示，在芬兰的其它地方也出现过类似的攻击。另外有媒体表示Valtia公司快速重置了这些手影向的系统并将供暖系统转变为手动操作。该报道将此次攻击归罪于Mirai僵尸网络。
