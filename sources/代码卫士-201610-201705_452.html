英国：除了Windows，还要修复app

一项调查显示，英国用户在修复个人电脑Windows漏洞方面做得越来越好，不过在更新app方面略逊一筹。


漏洞管理公司Secunia披露称，6.4%的英国用户在2016年第三季度运行未修复的Windows操作系统，比第二季度上涨5.4%，不过比去年同期下降1.5%。12.8%的英国用户在2016年第三季度运行着未修复的非微软程序，比第二季度上涨0.2%，且比去年同期上涨1.5%。


2016年第三季度前三大最糟糕修复的程序是Oracle Java JRE（45%未修复，57个漏洞）、Appple iTunes（44%未修复，50个漏洞）和VLC媒体播放器（45%未修复，7个漏洞）。这也说明非微软软件中的缺陷存在的时间更长，例如Java和Adobe Flash中的漏洞要比微软Windows本身的漏洞风险大得多。


微软决定为Windows 7 SP1、Windows 8.1、Windows Server 2008 R2、Windows Server 2012和Windows Server 2012 R2推出综合更新从而简化修复鼓励更多的用户运行更加安全的系统。


Duo Security验证公司也开展了一项调查，结果显示65%的Windows设备运行的是于2009年发布的Win 7系统。大约有600个安全漏洞曾出现在Win 7系统中。数万台设备运行的是仍然是15年前发布且已被微软废弃的Windows XP系统。运行IE浏览器的设备中由20%运行的是IE 8、9及10版本。而这三个版本生命周期已终止且不再接收补丁，导致这些设备易受攻击。在所有运行微软浏览器的设备中，只有三成设备使用的是最新的Edge浏览器。几近62%运行IE的设备都安装着老旧的Flash版本，使得攻击者能够利用Flash和JS引擎漏洞传播恶意软件。


Secunia Research认为未修复的微软程序之所以如此多是因为不同的数据包具有不同的下载和更新流程，导致用户不知所措。该机构指出，微软正在标准化其整个应用程序组合的补丁和自动化流程。而每个非微软厂商的补丁流程可能都各不相同，这就需要用户了解更多的相关知识。非微软程序约占一台计算机60%的代码。很多用户不会花费足够的时间和精力来为计算机上的应用程序打上最新的安全补丁，对于非Windows的应用程序来说所耗精力就更多了。


Secunia的数据来自其内部的补丁监测工具，时间跨度是7月份至9月底。


有一个网友的看法深得其他网友的赞同：如果用户的体验是，上次修复之后主页被重定向而且还多了另外一个不想要的浏览器工具栏，用户可能就不想经历这种事儿了……
