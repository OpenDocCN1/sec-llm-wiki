# IRCTelnet：一种新型的物联网恶意软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485652&idx=3&sn=bcdfdecbfd46e140ee228dc26d2b6f22&chksm=ea9739bedde0b0a80551f909fcf54882a1ba1983eac60888c252773bae51f3083f9a2e89d1fb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485652&idx=3&sn=bcdfdecbfd46e140ee228dc26d2b6f22&chksm=ea9739bedde0b0a80551f909fcf54882a1ba1983eac60888c252773bae51f3083f9a2e89d1fb&scene=27#wechat_redirect)

**一款新型的恶意软件家族出现，目标是基于Linux的物联网设备，主要目的是将这些设备添加进一个僵尸网络中并实行拒绝服务攻击。**

  

这款恶意软件由安全研究人员MalwareMustDie发现，名为Linux/IRCTelnet，使用C++编写。

  

研究人员表示，这款恶意软件主要感染基于Linux的设备，并且这些设备的Telnet端口都向互联网开放且使用弱密码。

  

**IRCTelnet借鉴其他物联网恶意软件**

  

IRCTelnet暴力破解设备的Telnet端口，感染设备的操作系统，并将其添加进通过IRC（Internet Relay Chat ，互联网中继聊天）控制的僵尸网络中。这意味着每个受感染的设备都连接到IRC频道，并读取贴在主聊天室的命令。

  

很多物联网、Linux、Windows恶意软件都以这样的方式操作。

  

MalwareMustDie表示IRCTelnet从其他物联网恶意软件中获取到很多灵感。使用IRC管理僵尸机器显然是从最成功的恶意软件Kaiten借鉴来的。

  

相似的，Telnet扫描器和暴力破解系统是从GafGyt（也被称为Torlus、 Lizkebab、Bashlite、Bashdoor）借鉴来的。而默认的远程登录凭据列表是从最近的Mirai恶意软件借鉴的。

  

**IRCTelnet支持IPv6泛洪攻击**

  

MalwareMustDie表示这款恶意软件能够感染任何运行有Linux Kernel 2.6.32及以上版本的设备。

  

能够针对IPv4 and IPv6地址实行泛洪攻击，但Telnet扫描器只能找到并针对IPv4实行攻击。

  

**目前仅有3,400个僵尸机器**

  

MalwareMustDie表示该恶意软件的初始扫描IP地址位于土耳其、摩尔多瓦和菲律宾。

  

当他连接到僵尸网络的IRC频道，发现约有3,400台僵尸机器。
