# LDAP服务器可用于扩大DDoS攻击，平均放大系数达46倍

**DDoS保护和缓解机构Corero表示检测到DDoS攻击可利用LDAP服务器扩大平均46倍效果，最高倍数达到55倍。**

  

该公司表示有此类攻击针对它的客户之一。进一步的事件调查显示攻击团伙使用LDAP 协议，利用垃圾流量针对目标进行泛洪攻击。该技术此前没有在其他攻击中出现过。

  

Corero表示CLDAP（Connection-less Lightweight Directory Access Protocol，无连接轻量级目录访问协议）中存在0day漏洞，LDAP协议使用Active Directory实现，Active Directory是微软为Windows域名网络开发的一项服务，包含在所有的Windows Server OS分布中。

  

**LDAP反射和放大DDoS攻击**

  

攻击者使用支持CLDAP的有漏洞的服务器对目标反射垃圾流量，这是在DDoS反射攻击中常用的技术。

  

攻击者向服务器的LDAP服务端口发送请求，但会将发送方的IP地址修改为受害者的IP。服务器处理请求后，向发送方发送回执，即受害者的机器。

  

这是反射DDoS攻击的基本原理。 LDAP 服务器的回执是原请求的很多倍。Corero表示在观察到的攻击中，LDAP回执大小（即DDoS的放大系数）平均为46倍，峰值达到55倍。

  

DDoS反射和放大攻击是常用的技术。通常用于反射和放大的协议为DNS、NTP或者SMTP。

  

去年，安全研究人员还发现了其他可用于反射和放大攻击的协议，如 NetBIOS、RPC、 Sentinel、 DNSSEC和TFTP。这些协议的放大系数都比较低，除了TFPT，放大系数达60。

  

近期的大规模DDoS攻击如OVH、Dyn以及KrebsOnSecurity已引起媒体的广泛关注，这些攻击没有使用反射或者认证技术，仅仅将垃圾流量引导至目标，高峰已达到1.1 Tbps。

  

如果攻击者使用LDAP 进行反射和放大，未来的攻击规模轻易可能超过几十Tbps。
