# Firefox 52将支持TLS 1.3协议

**Mozilla昨日宣布推出TLS 1.3版本，该TLS安全协议仍在开发中，即将在明年应用于Firefox 52中。**

  

Mozilla今年6月中旬曾在Firefox 49中添加了对TLS 1.3开发版的支持。

  

Martin Thomson是Mozilla的首席工程师，同时也是IAB（Internet Architecture Board，互联网架构委员会）成员，该委员会负责监督IETF（Internet Engineering Task Force，互联网工程任务组）标准进程的构建。他表示Firefox 52将会成为第一个用户使用TLS 1.3的浏览器稳定版本。

  

目前，Firefox Developer Edition用户可以通过修改配置页面的一个参数激活浏览器对TLS 1.3的支持。

  

**Mozilla、Chrome、Microsoft、CloudFlare都支持TLS 1.3协议**

  

TLS协议是HTTPS网页工作的基本协议。TLS负责用户浏览器和网页服务器之间建立加密通讯的安全操作。

  

Thomson表示，TLS 1.3移除了旧的、不安全的加密原语，它使用现代的分析技术，比TLS 1.2更快、更安全、并且能够加密更多的数据。TLS 1.3还提供了一种O-RTT模式，消除往返握手的延时。

  

今年9月，CloudFlare宣布在其服务器添加对TLS 1.3的支持。随后浏览器厂商如微软和谷歌宣布在Edge和Chrome Canary版中支持TLS 1.3。

  

**Mozilla发布了Firefox 49.0.2**

  

昨天，Mozilla发布了Firefox 49.0.2版本，增加了名为Asynchronous Plugin Rendering的系统插件。Mozilla表示这款新插件将提高使用Flash插件的性能，减少网站崩溃的概率。

  

Firefox 49.0.2还包括另外一款系统插件，在Firefox硬盘加速时停用Direct3D9。这将提高显卡的呈现效果。

  

Firefox 49.0.2目前可支持Linux、Mac和Windows用户。如果需要可进行安装更新。
