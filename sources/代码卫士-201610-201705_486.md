# 勒索软件Locky：占恶意邮件附件的97%

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485662&idx=2&sn=aebfb03f3b9ce3b6a809fe2f352cd47b&chksm=ea9739b4dde0b0a2a4bc41f17a036c88d800e1ba971bee85633ff2df706c7f0d5a9c2a159d7c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485662&idx=2&sn=aebfb03f3b9ce3b6a809fe2f352cd47b&chksm=ea9739b4dde0b0a2a4bc41f17a036c88d800e1ba971bee85633ff2df706c7f0d5a9c2a159d7c&scene=27#wechat_redirect)

**据Proofpoint 2016年第三季度统计，附件中带有恶意文件的垃圾邮件达到了空前高的数目。**

  

在所有恶意软件家族中数量最多的是Locky勒索软件，占所有恶意软件附件的96.8%。

  

在多数情况下，它是一个带有JavaScript文件在内的压缩文件，但攻击者也会使用带有恶意宏脚本、HTML可执行文件、Windows脚本（WSF）文件的office文档。

  

另外五款数量最为猖獗的恶意软件包括Pony 恶意程序、the Vawtrack 网银木马、Tordal (Hancitor) malware dropper以及Panda Banker网银木马。

  

除了Locky，其他的勒索软件变体也通过垃圾邮件大量传播，包括CryptFile2、MarsJoke、Cerber。

  

Proofpoint的报告还强调了虽然银行木马相较2015年有所下降，但还是一个持续的威胁，因为仍有一系列的反侦查功能添加来抵抗安全软件的检测。

  

不过让人欣慰的是2016年第三季度攻击工具包从第二季度的93%下降到65%。

下降的原因要归功于今年春季 Angler和Nuclear攻击工具包的关闭，以及Neutrino攻击工具包进入所谓的“隐私模式”。尽管如此，RIG攻击工具包可能会迅速发展起来。
