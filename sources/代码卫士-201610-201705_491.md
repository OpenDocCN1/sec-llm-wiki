# 微软修复4个0day漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247485664&idx=1&sn=5d4bfca43d21ce9ada6c1f06aeaacb19&chksm=ea97398adde0b09c0625bcd97d3a2c7fdd25a6f45c3aa0429c2915c9e946a6737e94b194cfe2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247485664&idx=1&sn=5d4bfca43d21ce9ada6c1f06aeaacb19&chksm=ea97398adde0b09c0625bcd97d3a2c7fdd25a6f45c3aa0429c2915c9e946a6737e94b194cfe2&scene=27#wechat_redirect)

**本周二是微软例行的补丁发布日，这次修复了4个0day漏洞，公告中共包括10个补丁，解决超过36个记录在案的安全漏洞。**

  

这4个0day漏洞影响微软产品如IE浏览器（CVE-2016-3298）、Edge的脚本引擎（CVE-2016-7189）、Windows图形组件（CVE-2016-3393）、Office（CVE-2016-7193）。

  

**CVE-2016-3298**

  

CVE-2016-3298是IE浏览器中的一个信息泄露漏洞，由Proofpoint公司发现。

  

Proofpoint公司表示该0day漏洞在名为AdGholas的大规模恶意广告中被使用。

微软表示能够成功利用该漏洞的攻击者能够检测到硬盘中的文件。

  

微软在两个安全补丁中修复了此漏洞，MS16-118和MS16-126。上个月，微软还修复了另一个0day漏洞CVE-2016-3351，也被AdGholas恶意广告使用。

  

**CVE-2016-7189**

  

CVE-2016-7189是微软Edge脚本引擎的一个远程代码执行（RCE）漏洞，允许攻击者“获取能够进一步危及用户系统的信息。”

  

不过需要用户访问一个恶意网站，然后进行点击链接类似的操作。这使得漏洞利用难度相较之前的0day漏洞要难，但也是有可能实现的。

  

用户需要在Edge中安装MS16-119安全补丁。

  

**CVE-2016-3393**

  

另一个危险的0day漏洞CVE-2016-3393也具有RCE能力，它会影响Windows的图形（GDI）组件。

  

微软表示攻击者可以利用该漏洞通过本地系统中的恶意文件或者基于web进行远程攻击。

  

MS16-120安全补丁修复了GDI组件处理内存中特定数据对象的方式，抵挡此类攻击。

  

**CVE-2016-7193**

  

CVE-2016-7193是微软Office中的一个内存损坏漏洞，允许攻击者在目标电脑上运行恶意代码。

  

微软表示漏洞通过恶意的RTF文件被利用，并且发布了补丁MS16-121进行修复。

  

该0day漏洞最为危险，因为用户账户有更多与此相关的权限。这也是为什么Windows用户应当使用最低权限而不是管理员账户进行日常操作。
