# Palo Alto 公司的安全平台上出现紧急高危漏洞

**Palo Alto ****网络公司发布更新，解决了**** PAN-OS ****安全平台上的紧急和高危漏洞。这些漏洞如被利用可导致远程代码执行和命令注入问题。**

  

被Palo Alto 网络公司评为“紧急”的问题实际上是管理界面中出现的多个漏洞组合，远程和未授权攻击者能利用这些漏洞在受影响的防火墙上执行任意代码。  

PAN-OS 6.1.18、7.0.18、7.1.13、8.0.5和更早版本均受影响。补丁已在 PAN-OS 6.1.19、7.0.19、 7.1.14 和 8.0.6中提供，不过用户也可以通过该公司发布的漏洞签名拦截攻击。

这些缺陷的CVE编号统一为 CVE-2017-15944，它是由Philip Pettersson发现的。后者在本周也在博客中说明了相关情况。他表示在7月份告知Palo Alto公司相关漏洞情况。

  

Pettersson的安全公告中包含了完整的技术详情，它说明了三个漏洞：一个部分验证绕过、一个任意目录创建问题以及一个命令注入问题。结合使用这些缺陷能导致未经授权的攻击者通过web接口以root权限执行任意代码。

  

  

Palo Alto公司建议用户不要将设备的web 接口暴露在互联网上，但从Sonar 和Shodan 搜索引擎中发现，允许对web接口进行远程访问的设置在组织机构中并不鲜见。

PAN-OS 更新还解决了web 接口包抓取管理组件中的一个高危缺陷。它是由三星公司的研究人员发现的，CVE编号是CVE-2017-15940，可允许认证攻击者注入任意命令。

Palo Alto公司还说明了由CrowdStrike公司的研究人员在 GlobalProtect 客户端的macOS 版本中发现的一个低危漏洞。该漏洞的编号是CVE-2017-15870，拥有本地系统 root 权限的攻击者能实现某种程度上的持续性。这个安全漏洞影响的是 GlobalProtect 的macOS 4.0.2及更早版本，不过已在版本 4.0.3 中修复。
