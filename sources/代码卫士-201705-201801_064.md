DanderSpritz简介

  

“影子经纪人”已公布据称窃取自 NSA “方程式组织”网络间谍的多款工具和利用。他们在4月份发布的其中一款工具是利用后框架 DanderSpritz，它除了能清理日志外还包含很多其它功能。它能让黑客捕获数据、绕过并禁用安全系统并在受攻陷网络中横向位移。NSA 通常结合利用框架 FuzzBunch 使用。

NSA 运营人员使用 FuzzBunch 在目标计算机上加载并运行利用代码，随后部署 DanderSpritz 找到并提取敏感数据，传播至附近计算机并删除攻陷数据。

正如 Kudelski安全公司的研究人员 Francisco Donoso 所言，“就把它想象成 Metasploit Meterpreter 的国家版本，不过配备有自动反病毒检测和规避功能，以及很多不易检测到的用来泄露密码、收集信息、获取持续性并横向移动的工具。”

DanderSpritz 包含一个有意思的插件 EventLogEdit，后者旨在操纵Windows的事件日志文件帮助攻击者隐藏行踪。研究人员从该框架的日志清洁器中发现了一个缺陷。

虽然尚未听说过的修改事件日志的黑客工具，但跟其它工具相比，EventLogEdit 更加复杂，它能从安全、应用和系统日志中删除单个记录，而且不会留下文件已被编辑过的任何明显线索。

Rendition Infosec 的创始人兼“影子经纪人”泄露研究专家 Jake Williams 指出，“虽然我们知道事件日志可以清空、停止对事件的日志记录，但对事件日志进行手术式的编辑通常被认为是一种非常高级的能力（如果真的有可能做到这一点的话）。知道某些攻击者显然有能力编辑事件日志的事情从根本上改变了调查的情况。”

  

Python 脚本恢复被删事件日志

  

由于“影子经纪人”已将工具公开，因此技术能力不强大的攻击者也有机会隐藏行踪并阻碍取证调查。好在研究人员已开发出一款工具，能判断系统中是否使用了EventLogEdit，甚至能恢复它所删除的事件日志条目。

研究人员解释称，“当使用eventlogedit时，将被删除的日志记录本身是未被编辑或删除的，只不过记录未被引用。它是通过操纵之前记录的记录头来实现的。Eventlogedit将将被删除记录的大小加入之前记录的大小中，因此会合并这两个记录。被删的记录包括记录头在内目前仅被认为是此前记录的多余数据。你可能认为一款日志查看器能显示出这种多余数据或垃圾数据，但事实上并非如此。很显然，所有经测试过的查看器在第一个end-标签之前会解析记录的binXml信息数据并移动到下一个记录。”

![](../Images/ed41025fc499816145dfeb71a43968e4.png)  

  

当Windows日志记录 app 读取篡改过的日志文件时，它会读取清洁版本、查看结束标签并忽略未引用的“坏”事件的所有内容。攻击者以此来隐藏在受攻陷机器中的恶意动作。

专家认为，将日志发送到中央服务器的组织机构应该能看到这些飞速写入的被删记录，不过技术高超的攻击者可能也会劫持服务器隐藏行踪。

Fox-IT 公司已在 GitHub上发布开源 Python 脚本danderspritz-evtx以便识别并导出被删事件日志记录，组织机构可借此查看自己是否遭 NSA 或其它可能使用 EventLogEdit 的威胁者的攻击。如用户不想自己编译代码，也可下载该工具的 Windows 可执行文件版本。
