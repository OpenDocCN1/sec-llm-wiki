# 被泄凭证服务Leakbase关闭 或跟暗网市场Hansa有关？

**上周末，专门出售其它公司在数据泄露事件中泄露的用户名和密码的网站****Leakbase.pw****服务突然中止。访问该域名会被重定向至研究员****Troy Hunt****开设的****https://haveibeenpwned.com/ ****网站，供用户查看某些邮箱地址是否被泄露。**  

12月2日，leakbase.pw服务中断，运营人员称某些用户可能还剩下一些未用完的时间，用户可根据订阅合同中的相关规定要求退款。

该网站并未给出官方解释，说明服务为何终止。网络安全新闻调查记者Brian Krebs指出，一个匿名消息人士表示原因可能是该服务违反了荷兰的一项法律规定。这名消息人士称，Leakbase被指在暗网市场Hansa上出售商品，后者于今年夏天被荷兰警方拿下。

运营人员坚决否认关闭跟执法部门有关。Leakbase回应称关闭只是因为竞争太过激烈，运营已无利可图，随着时间的流逝其吸引力也会丢失。不过表示可能会有兴趣对企业提供泄露监控服务，而这也是该公司在去年推出的一项服务。

另外，运营人员指出服务关闭跟Hansa被拿下之间并无关联。尽管Leakbase否认了人们的这种传言，但值得一提的是，Brian Krebs在报道方面一向极少出错。
