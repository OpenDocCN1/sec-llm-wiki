# 谷歌将发出警告：您使用的app正在收集数据

> **谷歌加快了对安卓无用和有害****app****的打击力度，不久将对未经用户同意收集用户个人数据的****app****发出警告。**  

谷歌安全模式浏览服务将会在几个月后对安卓设备启动警告服务，谷歌表示这是加强执行谷歌无用软件策略(Unwanted Software Policy) 的一部分。这种加强执行还涵盖处理个人用户数据的app，如电话号码或邮件或设备数据。对这些数据的所有处理行为都要求通知用户并“在app中提供他们自己的隐私策略”。

另外，谷歌正在要求收集并传输跟app功能无关的个人数据的app在执行收集和传输操作之前，“明确说明如何使用用户数据并获得用户的积极同意”。

谷歌指出，“这些数据收集要求适用于app的所有功能。例如，在分析和崩溃报告过程中，在未明确披露且未获得积极同意的前提下，或无法从设备传输跟app无关的安装包。”

谷歌将同时在谷歌应用商店和非谷歌应用商店app市场中执行这些新要求。谷歌还发布指南，说明了谷歌应用商店中的app应该如何处理用户数据并提供披露信息。

2018年1月末，这项警告功能可能会通过GooglePlay Protect或在导向这些app的网页上出现在用户设备上。

网络管理员应该在搜索面板上查看警告修复和解决指南，开发人员可参考“无用软件帮助中心”指南，而app构建者可要求获取app评测了解相关内容。
