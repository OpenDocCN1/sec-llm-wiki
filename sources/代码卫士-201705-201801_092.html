就在联想刚刚因在未经用户同意的情况下预装广告软件被罚350万美元后，多份报告指出惠普在未获得用户许可的情况下正在用户电脑上部署一个遥测客户端。



导致用户电脑运行缓慢损害系统



这款软件被称为“HP 触点分析服务 (HP TouchpointAnalytics Service)”，首次被发现于11月15日，它似乎取代的是自我管理的惠普触电管理器解决方案。从惠普官方的生产力说明来看，该软件“具备你所需要的功能，保证管理设备的安全性，并且让您内心更加宁静。”问题在于，该软件在未经用户同意的情况下，自我安装并对用户系统造成损害。

有人在惠普支持站点上抱怨称，“它导致电脑运行得非常慢，我能听到电脑像在转动，而且电脑后面的灯随着这种声音快速闪烁。在任务管理器中，我能看到电脑启动并阻止很多应用。”

目前尚不清楚这个新驱动是如何安装的，可能是跟最新的 Windows 更新一起安装的，或者是通过惠普及其支持辅助进程安装的，不管怎样，用户不开心。一名用户在惠普论坛上表示，“我理解它会收集各种遥测数据——但我不愿意分享太多这种数据，在我不知情的情况下就更不用说了。”



用户应如何处理？



首先，用户应该查看下 Windows 电脑上是否安装了惠普触点管理器。

用户可选择两种方式删除该软件。

选项一：Services。

  1. 通过 Windows-R 调出运行框。

  2.  输入 services.msc 并点击Enter键。

  3. 在 Services 列表中查找 HP Touchpoint Analytics Client。如存在，则表示电脑上安装了 HPTouchpoint Manager。如未找到，跳到下面的选项二。

  4.  双击 Service 打开详情。

  5. 将启动类型设置为“禁用”。

  6.  在当前会话中选择“停止”停用该服务。

选项二：Windows 程序 

  1. 通过 Windows-R 加载运行框.

  2.  输入 appwiz.cpl 加载控制面板上的“程序和功能”。

  3.  定位 HP Touchpoint Manager。

  4.  右击这个程序名称，并选择“卸载”进行删除。

卸载这个程序应该也能将 Service 一起删除。



惠普回应



惠普回应称，“惠普触点分析服务是我们在 2014 年作为惠普支持辅助功能的一部分推出的。它匿名收集硬件性能的诊断信息。未经明确授权访问权限，惠普不同共享任何用户数据。用户可在任何时候选择取消或卸载该服务。惠普触点分析服务最近进行了更新，但其中并未对隐私设置做出任何改变。我们非常重视用户隐私，而且根据严格的隐私策略行事。”
