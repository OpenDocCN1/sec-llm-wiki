# 加拿大通信安全局开源恶意软件分析工具

加拿大通信安全局(CSE) 本周宣布开源一款恶意软件检测和分析工具Assemblyline（中文：流水线）的源代码。

  

**Assemblyline可自动化分析恶意软件**

Assemblyline通过Python编写，是根据CSE网络防御计划创建的。CSE表示这款工具用于保护加拿大计算机系统免受高级网络威胁的攻击。  

Assemblyline能让防御人员自动化分析恶意文件。Assemblyline被比作一条传送带，它在遍历系统时会为文件分配唯一标志符，查找恶意文件存在的迹象并分配给它们一个分数，然后将数据发到另外一个防御系统中，从而解决识别出的威胁。

  

**用户可按需自定义工具**

用户也可以添加自己的分析，包括自定义的内置软件和杀毒软件来增强 Assemblyline 的功能。CSE指出，“Assemblyline能让用户按照需求自定义系统，而且它会根据文件大小自定义自动平衡工作量的方式。该工具减少了安全分析师必须检查的非恶意文件数量，并且能让用户将时间和注意力放在恶意威胁最大的文件中，从而腾出精力研究新型网络防御技术。”

Assemblyline的源代码已发布在BitBucket上。组织机构可以按需修改或将其集成到现有的解决方案中。

**CSE并非首个发布开源工具的监控机构**

CSE是一家安全和情报组织机构，它旨在收集情报支持加拿大政府的需求并保护加拿大最重要的计算机网络的安全。虽然该监控机构被指为“绝密”机构，不过斯诺登曾在几年前暴露过它实施的活动。

文档显示，CSE一直在分析一次跟法国相关的外国监控行动。许多研究人员和网络安全公司随后也开始调查了这起监控行动。

CSE并非发布开源工具的首个监控机构。去年，英国的政府通信总部 (GCHQ) 开源了一款工具CyberChef，供技术人员和非技术人员分析加密、压缩和解压缩以及数据格式。
