前言


卡巴斯基研究员在NetSarang网络和服务器管理软件平台中发现一个非常隐秘的后门Shadowpad，或导致数百台公司遭攻陷。


厂商在卡巴斯基告警该攻击后证实了7月13日的攻陷事件。8月4日后NetSarang软件无法下载。卡巴斯基是在其一名香港金融机构客户的系统发出可疑的域名系统请求后追溯到恶意软件的。


NetSarang软件在全球范围内传播，且用于能源、金融和药品公司。受感染的NetSarang软件包和版本号包是：


  • XmanagerEnterprise 5.0 Build 1232


  • Xmanager5.0 Build 1045


  • Xshell5.0 Build 1322


  • Xftp5.0 Build 1218


  • Xlpd5.0 Build 1220


Shadowpad攻击和激活方法


Shadowpad存在于NetSarang的Xmanager和Xshell软件套件的nssock2.dll中。它每隔8小时就会以被攻陷电脑的身份、网络详情和用户名称ping到一个命令和控制服务器。这个后门的激活方式如下：.DLL基于年月生成一个域名并实施DNS查找。为域名特别编制的一个DNS TXT记录会触发控制服务器打开一个信道，该软件随后下载一个解密密钥，而下一步就是解密。这就能让攻击者运行代码并提取数据。如果你能为某个年月设置一个域名并模拟这个控制服务器，你也能强迫组织机构遭受被攻陷NetSarang工具的感染。


卡巴斯基认为有人设法黑进了NetSarang的服务器并静默插入后门，这样后门代码就能通过合法密码签名的软件更新静默传播到测试和生产环境中。研究人员表示，鉴于Shadowpad收集的数据，它可能会通过其它广泛使用的软件组件不断再次复现。卡巴斯基指出，如果后门被激活，攻击者就能上传文件、创建进程并在受害者注册表包含的虚拟文件系统中存储信息。由代码创建的虚拟文件系统和其它文件被加密并存储在为每个受害者准备的位置。


更新已推出


NetSarang已推出更新杀死Shadowpad，但尚不知晓攻击者是如何访问NetSarang系统从而植入代码的，但卡巴斯基指出，恶意代码通过软件开发人员的合法证书签名。卡巴斯基表示，Shadowpad跟中国黑客所使用的PlugX和Winnti攻击代码之间存在某些相似之处。


今年年初，一起类似供应侧攻击攻陷了乌克兰金融软件公司MeDoc的服务器并注入破坏性恶意软件Petya/NotPetya。
