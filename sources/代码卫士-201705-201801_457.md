# Chrome 59修复30个漏洞

**谷歌在周一发布了Chrome 59版本，做出了多个设计和功能改进，并修复了几十个漏洞。**

  

谷歌表示，Chrome 59版本修复了共30个缺陷，其中很多由外部研究人员报告。为此报告该漏洞的专家赚了超过2.3万美元。

  

最严重的漏洞在五月中旬报告给谷歌。研究人员在V8 JavaScript引擎中发现了一个高危的类型混淆缺陷(CVE-2017-5070)，为此赢得7500美元的奖励。

  

多个高危的使用后释放漏洞是由两名研究人员发现的，他们分别获取了2000美元和1000美元。另外一名研究员也因在CSP报告中披露了一个中危信息泄露问题而获得2000美元的奖励。

  

Chrome 59修复的中危和低危漏洞包括多功能网址列地址欺骗、Skia缓冲溢出、电子信箱处理中的命令注入、Blink用户界面欺骗、扩展验证绕过以及在WebUI页面的不当JavaScript执行。

  

研究人员还在信用卡自动填充功能中发现了一个使用后释放漏洞，并发现信用卡编辑器加固不当。

  

谷歌自从2010年推出漏洞奖励计划后就支付900多万奖励，其中300万美元是在去年发出的。随着漏洞越来越难发现，谷歌最近决定提高了对严重漏洞的奖励。
