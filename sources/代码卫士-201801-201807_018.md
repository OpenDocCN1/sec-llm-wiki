# 时隔两年，ADB 修复宽带网关中的多个严重漏洞

> **近两年前，瑞士****Advanced Digital Broadcast (ADB) ****公司生产的宽带网关被曝存在三个严重漏洞，目前补丁发布。这三个严重漏洞是权限提升漏洞、权限绕过漏洞以及本地越狱漏洞。**

ADB 公司为全球二十多家宽带和通讯公司生产路由器和调制解调器。北美第三大互联网服务提供商 Cox Communication 和 Charter Communications 也是它的客户。Cox 和 Charter 公司均未说明受影响的客户数量。

ADB 公司的大量消费者和小企业宽带设备均受影响。SEC Consult 漏洞实验室的研究人员率先在2016年6月发现了这些漏洞，2017年7月开始推出补丁，2018年7月4日开始公布这些漏洞情况。

本地根越狱漏洞 CVE-2018-13108 因网络文件攻陷缺陷的存在而易被利用。攻击如成功，攻击者能以最高权限完全访问设备。研究人员指出，ADB 宽带设备上的“网络文件共享”功能可通过用于 USB 设备的网络协议 Samba 访问。黑客能滥用 Samba 守护进程（后台进程）并“通过最高访问权限”访问 USB 端口，并“通过根用户权限导出网络共享”。

ADB 设备的某些固件版本中还存在漏洞 CVE-2018-13109，可导致攻击者获得对设备设置的访问权限，而用户被禁止访问该权限。研究人员指出，“也有可能通过操纵设置（例如）远程访问 telnet 服务器，前提是该设置被互联网服务提供商禁用。”攻击者需要通过用户账户登录如“互联网服务提供商提供的默认凭证或打印在设备的凭证”。

ADB 宽带网关同时易受经由 Linux 组操作实现的权限提升漏洞 (CVE-2018-13110) 影响，可导致攻击者访问设备的命令行界面 (CLI)，即使 CLI 此前已被互联网服务提供商禁用。研究人员指出，“从 CLI（互联网服务提供商依赖）的功能集来看，有可能获得对整个配置的访问权限并操纵 web GUI 的设置并将权限提升至最高访问权限。”

这个权限提升漏洞可导致攻击者操作 ADB 设备上“存储用户”的组名称设置，并覆盖本地 Linux 组“remoteaccess”或“localaccess”（位于 /etc/ 组），定义对 Telnet 或 SSH 的访问权限。

SEC Consult 公司指出，ADB 已发布解决这些漏洞的固件更新。受影响的产品是 Epicentro 平台上的所有 ADB 宽带网关/路由器。

易受影响的硬件型号包括 ADB P.RG AV4202N、DV2210、VV2220 和 VV5522 等。从 ADB 公司网站来看，受影响产品可能还包括在 Epicentro 平台上运行的EVDSL/G.Fast/Fiber Gateway Dual-band WirelessAC1600 ST6840 以及 GPON Gateway Dual-band Wireless AC1600 VG4820。
