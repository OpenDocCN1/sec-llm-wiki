# 看研究员如何击溃“牢不可破”的神锁 Tapplock

> **今年年初，一款智能挂锁**** Tapplock ****横空出世，一时好评如潮。然而，****6****月初，优酷网红**** JerryRigEverything ****发布视频展示了如何解锁这款神奇的挂锁。厂商当时表示只是个例，不过随后研究人员在不到****45****分钟的时间里就成功解锁，让厂商如坐针毡并发布了重要补丁。**

**风头无两的神奇挂锁**

![](../Images/d9b488ea29ad678b4dd6da7edf0bd6f8.png)

Topplock 挂锁的售价是100美元，它基于蓝牙技术并可通过指纹激活。第一眼看上去，Tapplock 的一切都是那么闪闪发光：厂商说它“牢不可破”、多家媒体也对它赞赏有加。2016年，厂商还在投入生产前在众筹创意平台 Indiegogo 上集资30多万美元，随后这款神奇的挂锁于2018年3月发布。

不过，这美好的一切都在今年6月初被打破了。

**从“牢不可破”到“满身是洞”**

![](../Images/d9b488ea29ad678b4dd6da7edf0bd6f8.png)

如上所述，6月初，有人在优酷视频上展示了如何通过一把螺丝刀就能让 Topplock 松动并最终打开其钩环。虽然厂商表示只是个例，不过这个视频也引起了安全圈子的兴趣。Pen Test Partners 公司的研究员 Andrew Tierney 也在6月份审查了挂锁的安全性，并在不到45分钟的时间内攻破这款智能挂锁。

Tierney 指出，作为挂锁，Topplock 的安全目标非常严格：能物理访问挂锁的攻击者无法打开钩环，然而它却离这个目标相去甚远。只需一部手机且在2秒之内就能将其打开。而发现这一点只需不到一个小时的时间。

Tierney 指出，设备识别符BLE（蓝牙低功耗） MAC 地址在全网公开播报，因此他所需要做的就是获得 BLE MAC 地址。他还表示，除此之外，出于几个其它因素的考虑，这款锁不可避免地要被攻破。他发现应用经由 HTTP 通信，因此挂锁并不具备传输加密安全，而这种缺陷“在2018年是不可饶恕的”。

Tapplock 蓝牙功能说明指出，挂锁使用的是军队用来保护机密和秘密级别文档所使用的AES 128位加密算法。但研究员表示它忽略了配对、密钥交换、密钥分享等问题，而且最重要的一点是并未提及认证安全。

此外，Tapplock 也并未设置恢复出厂设置，也就是说用户能从账户删除挂锁，而用于解锁它的数据仍然并未改变。

另外一名研究员 Vangelis Stykas 在 Tierney 研究工作的基础上发现，当他登入 Tapplock 账户后，只要他知道他人的 ID，就能认证其他人对挂锁的访问。

这样 Skykas 就能够访问敏感的个人可识别信息，包括通过蓝牙和邮件解锁的用户的地址，并且能够和任何账户共享任何挂锁以及访问任何挂锁的所有信息。Skykas 指出，他能够发动攻击和自己的账户（或任何账户）永久共享任何锁的信息，然后提取上次解锁的位置信息，到达这些位置并通过官方应用将它们解锁。

**物联网安全不容小觑**

![](../Images/d9b488ea29ad678b4dd6da7edf0bd6f8.png)

Tapplock 的案例反映了物联网设备中非常重要的问题，尤其是本应该保护个人物品安全的问题。但除此以外，它也反映了媒体和厂商如何对待物联网设备的问题。

Tierney 指出，“Tapplock 已得到很多大型站点和多名优酷人员的审查，但没有发现有人对挂锁的安全性进行测试。虽然有很多人大肆宣扬这款挂锁的安全性，但这种言论需要探讨：为何审查设备的人员能够传播虚假的安全言论呢？”

Tapplock 就 Tierney 和 Stykas 的言论发布安全通知并督促消费者进行升级。该公司指出，“Tapplock 推出了一个重要的安全补丁。该补丁解决了多个可导致未认证用户非法获取访问权限的蓝牙/通信漏洞。Tapplock 将持续监控最新的安全趋势并不时提供更新。”
