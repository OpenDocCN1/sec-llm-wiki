# Chrome 浏览器被曝严重漏洞 影响所有主流操作系统

> **5****月末，研究员**** Michal Bentkowski ****发现并报告了存在于**** Chrome ****浏览器中的一个高危漏洞，它影响所有主流操作系统上的**** web ****浏览软件。**

Chrome 安全团队为留给多数用户时间修复浏览器，并未披露关于该漏洞的任何技术详情，表示它是对 CSP （内容安全策略）头部的不正确处理 (CVE-2018-6148) 问题。团队还表示，如果该问题存在于第三方库以及类似项目中但尚未得以修复，将继续保留技术详情。

CSP 头部能让网站管理员在既定网页上通过允许控制浏览器的加载资源来增加额外的安全层。

如果 web 浏览器错误处理了 CSP 头部，则可导致攻击者在目标网页上执行跨站点脚本攻击、点击劫持以及其它类型的代码注入攻击。

Chrome 更新的稳定版本 67.0.3396.79 中已发布针对所有主流操作系统的补丁。用户可能已经收到该补丁或者将在几天或几周内收到补丁。

因此，确保自己的系统运行的是 Chrome 浏览器的更新版本。我们将持续关注谷歌发布的更新情况。

火狐也推出了包含修复方案的浏览器新版本 60.0.2。建议火狐浏览器稳定版用户尽快予以更新。
