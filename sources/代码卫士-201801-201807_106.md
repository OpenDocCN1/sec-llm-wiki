# Facebook 被曝和60多家设备厂商签订用户数据共享协议

> **剑桥分析公司丑闻还未散去，****Facebook ****又被曝向****60****多家设备厂商提供访问用户数据的不当权限。这些厂商包括亚马逊、苹果、微软、黑莓和三星。**

《纽约时报》发布一份很长的报告指出，Facebook 和至少60家设备制造商确立数据共享合作伙伴关系，以便这些厂商能够在无需用户单独安装应用的情况下为 Facebook 提供通讯功能、“点赞”按钮、地址簿等。

这些协议据称至少持续了10年，在 Facebook app 尚未大规模地用于智能手机上时就已开始。

报告指出，其中最值得注意的是，这种合作伙伴关系可能违反了美国联邦贸易委员会在2011年颁布的同意判决书。判决书禁止 Facebook 在未经用户明确同意的情况下给予其它公司访问用户 Facebook 好友的数据。

今年3月剑桥分析公司丑闻爆发期间，Facebook 声明称已经在2015年停止允许第三方访问用户数据，但报告指出，其中并不包含“手机、平板电脑和其它硬件厂商”。

剑桥分析公司被指滥用8700万 Facebook 用户的数据帮助特朗普成功竞选2016年的总统选举后，Facebook 就一直处在风口浪尖上。

一名《纽约时报》的记者最近通过自己的 Facebook 账户和约550名好友对一款2013年的黑莓手机进行测试后发现，一款名为 “The Hub” 的黑莓应用仍然能够收集其中556名好友的个人数据，其中包括他们的宗教信仰和政治观点。

不止如此，The Hub 应用还能够获得 294,258 名他 Facebook 好友的好友的个人可识别信息。

Facebook 公司的回应

3月份，Facebook 曾在美国国会听证会上表示，“你在 Facebook 上分享的内容都是你自己的。你对访问内容的人员和分享的方式拥有绝对控制。” 上周日Facebook 发布一篇博客文章反对《纽约时报》的报告。

Facebook 在文中指出，公司为亚马逊、苹果、黑莓、HTC、微软、三星和设备厂商创建 API 是为了让它们在尚未出现应用或应用商店之时在自己的操作系统上提供 Facebook 的功能。

产品合作伙伴关系副总裁 Ime Archibong 在文中指出，和设备厂商签订数据协议是必要的：“在移动时代早期，Facebook 尚无法构建在所有手机或操作系统上运行的产品版本。虽然时间已过去很久，但当时并未出现应用商店。因此 Facebook、谷歌、推特和 YouTube 必须和操作系统和设备厂商直接合作，把产品交到人们的手中。这些工作花了很长的时间，而 Facebook 无法触及所有人。为了缩减这一差距，我们构建了一系列设备集成 API，允许公司为个人设备或操作系统重新创建类似 Facebook 的体验。十年来，共有约60家公司使用了这些 API，包括很多家喻户晓的公司如亚马逊、苹果、黑莓、HTC、微软和三星。”

文章还指出，Facebook 牢牢控制这些 API 而且合作伙伴签订协议禁止将 Facebook 用户的信息用作“重新创建类似 Facebook 体验”之外的目的。另外，文章写道，“合作伙伴无法在未经用户同意的情况下，将用户的 Facebook 功能集成到设备中。而我们的合作伙伴关系和工程团队批准了这些公司构建的 Facebook 体验。”

文章指出，“和《纽约时报》的报道不同，当人们决定和好友分享信息时，好友的信息如照片等仅供在设备上访问。我们并未发现这些公司滥用信息的情况。”

由于 iOS和安卓的流行，很少有人依靠这些 API 创建和 Facebook 类似的体验，这也就是 Facebook 为何在4月开始逐步“收缩”合作伙伴关系，到目前为止已结束和其中22家公司的合作伙伴关系。
