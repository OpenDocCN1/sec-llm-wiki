集成IE 0day 漏洞让 RIG 利用包焕发新生

上周公布的一个 IE 浏览器 0day 漏洞已被集成到 RIG 利用包中。RIG 利用包是一种基于 web 的工具包，可导致网站访客受恶意软件感染。

这个0day 漏洞即 CVE-2018-8174，它影响包含在 IE 浏览器和MS Office 中的 Visual Basic 脚本语言 VBScript。

4月20日，一名中国研究人员表示某个网络监控组织正在利用该漏洞经由 IE 浏览器影响用户，而这被指为朝鲜国家黑客组织开展的一系列攻击活动的一部分。

首先发现这些攻击的奇虎360将问题告知微软，后者在5月8日的补丁星期二中将其修复。

Writeup 和 PoC 招来 RIG 利用包

奇虎360、卡巴斯基以及 Malwarebytes 公司发布的 write-up 披露了这个 0day 的被奇虎研究员称为“双杀”的新利用链详情。

这些 write-up 也是 Morphisec 安全研究员 Michael Gorelik 在 GitHub 上发布 PoC 代码的基础。不久之后，Metasploit 模块也予以发布。

历史已无数次证明，公布这些技术 write-up 和 PoC 除了帮助安全研究员外，还能帮助恶意软件作者。

如今，距离RIG 工具包将其加入武器库中已过去一周多的时间。

用于推送挖矿机

安全研究员 Kaffeine 首先发现且之后得到趋势科技公司证实，RIG 利用包正在利用 CVE-2018-8174 通过恶意软件感染 IE 浏览器用户。

犯罪分子正在劫持合法站点的流量并将 IE 用户重定向至托管 RIG 利用包的网页，而 RIG 通过 Smoke Loader 恶意软件利用 IE 浏览器中 VBScript 引擎中的 CVE-2018-8174 再次试图感染受害者。

Smoke Loader 被指为“恶意软件释放器”，得到更多指令后，它会下载并在用户计算机上安装另外一款恶意软件，安装后这款恶意软件会秘密地挖掘用户计算机上的密币。

0day 漏洞为 RIG 利用包注入新活力

虽然最开始朝鲜黑客利用 CVE-2018-8174 攻击的是对平壤感兴趣的人员，但目前它正在遵循所有 0day 漏洞的模式，即它已进入公共空间以及 RIG 利用包的利用链，针对所有而非某些特定用户发动攻击。

如 Malwarebytes、趋势科技和 Kafeine 指出的那样，CVE-2018-8174 为 RIG 利用包注入新的生命力。RIG 工具包已有一年多的时间并未推出任何更新。

另外，最近有证据表明除了 RIG 利用包外，CVE-2018-8174 也得到专门针对银行和金融机构的黑客组织 Cobalt 的青睐。
