# SpectreNG：谷歌和微软披露新型 Spectre 攻击

> **谷歌和微软公司的安全研究员找到了**** Spectre****（“幽灵”）漏洞的两个新变体，影响**** AMD****、****ARM****、****IBM ****和英特尔生产的处理器。**

本月初，德国一家杂志发表的一篇文章引发网络热议，不过漏洞细节昨天才发布。

AMD、ARM、英特尔、微软和红帽 (Red Hat) 均已发布安全公告，其中包括漏洞的利用方式以及缓解建议。

变体名为 SpectreNG

这两个变体即上周公布的 “SpectreNG”，它和去年发现并在2018年1月公布的 Meltdown（“熔断”）和 Spectre 漏洞之间存在关联。

谷歌和微软公司的研究员分别独立发现这两个变体。它们的运作方式类似于 Metldown 和 Spectre，这也是为何它们被称为 “变体3a”和“变体4”而非被单独命名。

变体1即Spectre v1，是边界检查绕过 (CVE-2017-5753)；变体2是 Spectre v2，即分支目标注入 (CVE-2017-5715)；变体3是Meltdown，即恶意数据缓存加载 (CVE-2017-5754)；变体3a 是恶意系统寄存器读取 (CVE-2018-3640)；变体4是推断性存储绕过 (CVE-2018-3639)。

这两个新出现的变体中更重要的是变体4。这两个漏洞发生的原因均为推断性执行。所有的现代 CPU 中都具有推断性执行这个功能，它通过提前计算操作随后摒弃不必要数据的方法改进性能。

这两个变体的不同之处在于，变体4影响推断性执行进程中的另外部分，即 CPU 缓存中“存储缓冲区”中的数据。红帽公司通过一个 YouTube 视频解释了这个变体是如何影响现代 CPU 的。

红帽公司解释称，该漏洞“依靠权限代码中精确定义的指令序列的存在以及从最近发生的存储器写入发生的地址读取的存储器可能会看到一个较旧的值，随后导致从未实际提交的推断性执行指令中的微处理器数据缓存得到更新。结果，非权限攻击者可通过针对性缓存侧信道攻击利用该漏洞读取权限内存。”

微软在类似的安全公告中指出，“成功利用该漏洞的攻击者可能能够在信任边界读取权限内容”，证实红帽认为缺陷可用于打破沙箱环境的评估。

发现 Meltdown 和 Spectre 漏洞的谷歌研究员 Jann Horn 也已经发布了 PoC 代码。

英特尔和 AMD x86 芯片集以及 POWER 8、POWER 9、System z 和 ARM CPU 已知易受影响。英特尔已在安全公告中公布了易受影响的 CPU 系列清单。

攻击者还可经由浏览器中的 JavaScript 代码远程利用变体4。尽管如此，微软表示并未检测到任何利用尝试。

英特尔发布新补丁

英特尔公司产品保证和安全部门的副总裁兼总经理 Leslie Culbertson 表示，2018年1月发布的 Meltdown 和Spectre 原始补丁应该能够缓解变体4。

话虽如此，英特尔还是发布了新补丁。

Culbertson 表示，“我们已经向 OEM 系统厂商和系统软件供应商发布了测试版的变体4微码更新，我们将在未来几周内为生产 BIOS 和软件更新发布补丁。这种缓解措施默认禁用，客户可自行选择是否启用……在配置中，我们并未观测到性能受到影响。如果启用该缓解措施，我们观测到它造成的性能影响是2%至8%。”

红帽和微软也发布了新补丁。
