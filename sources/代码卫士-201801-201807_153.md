# “赤色黎明”移动 APT 组织监控脱北者

> **复杂而具有针对性的手机间谍活动针对朝鲜脱北者发动攻击。该活动的发动者出现时间较短，名为“太阳队**** (Sun Team)****”。该组织使用谷歌应用商店和**** Facebook ****作为攻击向量；总体而言，它表明随着**** APT ****组织的涌入，移动威胁局势变得越来越紧张。**

移动 APT 成趋势

“赤色黎明 (RedDawn)”攻击在谷歌应用商店中植入三款“未发布的”测试版 app，主要攻击韩语用户。它们伪装成有用的应用，其中一个名为 “食品成分信息 (Food Ingredients Info)”，另外两个声称和安全有关 (Fast AppLock and AppLockFree)。

迈克菲 (McAfee) 公司的首席科学家 Raj Samani 指出，“我们看到传统杀伤链的演进，平台变得真正不可知。移动恶意软件已存在14年之久，而移动威胁转变为移动 APT 恰恰证明关键移动设备对我们日常数字化生活起到重要作用。”

这款食品 app 和 Fast AppLock 秘密窃取敏感信息如通讯录、信息、通话记录和照片，而且他们能够从 C2 服务器中接收命令和额外的可执行文件 (.dex)。从另外一方面讲，AppLockFree 似乎是侦察行动的一部分，为未来的攻击潮奠定基础。

Samani 指出，“我们认为这次攻击活动背后的组织才刚刚开始行动。”他认为，上传至谷歌应用商店中的第一个阶段足以实施监控活动，下载攻击者想要的其它自定义 payload。这种复杂程度跟 PC 端的传统攻击一致，它现在出现在移动设备上表明这是移动恶意软件的时代。

恶意软件安装到安卓设备上后，它通过 Facebook 渗透受害者的好友，具体发送信息请求他们安装应用并通过资料虚假的 Facebook 账户提供反馈。这种形式导致信息呈病毒式扩散；尽管最开始感染的群体只有100人左右，但“太阳队”能够扩大其攻击活动。

研究人员指出，“太阳队”攻击活动最让人担心的地方在于，它们使用上传到社交网络服务中的照片以及韩国人的身份创建虚假账户。有证据表明，某些人的身份被盗。它们还使用文本和呼叫服务生成虚拟电话号码来申请韩国在线服务。

Samani 表示，Bouncer app 审查工具和谷歌应用商店保护机制均未能检测出谷歌应用商店中的这些恶意 app；不过 Google Security 立即响应下架请求。但这并非故事的结尾：“赤色黎明”是“太阳队”黑客组织今年发布的第二次攻击活动。1月份，该组织曾发动类似安卓恶意软件活动，针对朝鲜脱北者和记者发动攻击。

从这款恶意软件用于上传数据并发布命令的 Dropbox 和 Yandex 云存储站点来看，“赤色黎明”显然来自同一伙黑客组织。例如，研究人员从相同的安卓测试设备上找到了显示“太阳队”1月份发动恶意软件活动的信息日志。

上周四，迈克菲发布分析报告表示，“这些日志的格式类似，而且使用的字段缩略语和‘太阳队’日志中所使用的一样。另外，新型恶意软件开发人员的邮件地址和此前和‘太阳队’相关的邮件地址类似。”

幕后黑手或为朝鲜

从目标受害者（朝鲜脱北者）的资料以及攻击活动中的某些特征来看，“太阳队”的幕后黑手是朝鲜。例如，恶意软件控制服务器中的一些词句并不存在于韩国词汇中；而且，一个被暴露 IP 地址也指向朝鲜。即便如此，Dropbox 账户源自韩国名人的名字。

研究人员指出，这些特征有力地表明，攻击者虽然并非韩国人，但他们很熟悉韩国的文化和语言。

Samani 表示，“赤色黎明”APT 组织表明了国家黑客间谍技术的演进过程。除了“太阳队”外，研究人员最近还发现 Lazarus APT 组织还将注意力转向移动平台，使用更加复杂的先进的攻击技术，如使用伪造签名绕过操作系统中的安全验证。另外，上周源自朝鲜的一款监控软件攻击了苹果 iOS 设备。

他解释称，不仅是韩国，伊朗以及其它新兴国家以及生活在美国的移民的移动设备均遭攻击。如果你是流亡者或不断需要转移的人（可能是脱北者或伊朗的抗议者）感兴趣，那么智能手机是访问互联网的最佳方法。
