# 警告！邮件加密工具 PGP 和 S/MIME 中存在多个严重漏洞

> **研究团队警告称，邮件加密工具**** PGP ****和**** S/MIME ****中存在多个严重漏洞。**

研究人员表示，这些漏洞如遭利用，可使得攻击者解密发出或收到的信息。这些漏洞或以明文形式披露加密邮件，包括之前所发出的加密邮件。目前尚不存在可靠的修复方案。

研究人员承诺在本周二即5月15日发布更多详情。同时，他们建议用户暂时停止使用 PGP 和 S/MIME。

电子前线基金会已发布如何禁用 PGP 和相关插件的指导手册，包括Thunderbird with Enigmail、AppleMail with GPGTools 和 Outlook with Gpg4win。

研究人员建议用户禁用邮件加密以避免攻击者在获悉研究论文后恢复之前发送的邮件。电子前线基金会表示，这些措施只是利用的直接风险过去且得到社区更广泛缓解之前的暂时的、保守的权宜之计。

电子前线基金会建议急需使用加密保护通信信道安全的用户使用支持端对端加密的即时通讯客户端。
