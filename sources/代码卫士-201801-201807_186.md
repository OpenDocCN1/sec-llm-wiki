# 重大事件将发生？特斯拉通知云用户警惕恶意软件或更糟糕的风险

> **特斯拉已警告运行自我管理资源的云用户称，“面向互联网的服务器可能易受恶意软件或其它恶意活动的攻击”。**

特斯拉表示，5月4日在服务中发现一个弱点，目前正在告知用户“删除或禁用自我管理服务器上的 TOPS 或 TRIC 账户”。

从特斯拉向用户发出的邮件来看，”TOPS” 或 “TRIC” 账户似乎是某种管理员权限账户。特斯拉在邮件中提到“我们已采取措施访问你的账户并删除了 TOPS 或 TRIC 账户，确保将风险最小化。我们仍然建议你检查账户设置并删除/禁用任何不使用的账户，因为目前我们无法确定我们是否能够成功更新这些账户。”

特斯拉将这份邮件发送给自我管理服务器用户，并通知特斯拉管理服务器的用户表明它是清白的。

据猜测，这听起来就像说 TOPS 和 TRIC 账户具有标准密码，但知晓这些密码的人员范围超过了合理范围。由于此类账户似乎是默认开启的，因此对于具有解锁账户凭证的恶意人员而言真是“天上掉了馅儿饼”的事，而特斯拉云就显得十分重要。

特斯拉的一名发言人表示，“用户的安全是我们的首要关注点。我们发现了一个弱点并快速解决它，并且和用户一起紧密合作确保已采取必要措施确保系统的安全。”这名发言人并未阐述这个完全问题的性质。
