Sierra Wireless 修复无线路由器中的两个严重漏洞

Sierra Wireless 修复了无线网关中的两个严重漏洞，它们可导致企业设备遭受多种远程威胁如 Reaper 物联网僵尸网络等。

300多万台 AirLink 设备或受影响

其中一个较为严重的漏洞（CVSSv3 评分为9.4）是权限提升漏洞 (CVE-2018-10251)，它可导致未认证远程攻击者执行任意代码并完全控制受影响系统，如以 root 权限发布命令等。

第二个问题（CVSSv3 评分为 8.4）也是权限提升漏洞 (CVE-2017-15043)，它可导致远程代码执行和设备接管问题。然而，该漏洞产生的原因是对目标设备的 HTTP 请求中的用户输入的输入验证不充分。攻击者需要拥有路由器登录凭证才能利用这个漏洞；获得凭证后，攻击者可向受影响系统发送一个特别构造的 HTTP 请求实施利用。

这个漏洞导致的潜在攻击面较大：Sierra Wireless 拥有300多万台 AirLink 设备。这两个漏洞均影响运行 4.4.6 或更早固件版本的 AirLink Gateways LS300、GX400、GX/ES440；以及运行 4.9.2 或更早固件版本的 GX/ES450、RV50、RV50X、MP70 以及 MP70E。

远程攻击者利用其中一个漏洞即可将恶意软件下载到设备上，执行网络间谍以及提取企业数据、执行中间人攻击、横向移动到网络的其它部分并收集凭证和其它信息，从而窃取身份、攻陷企业邮件或执行其它欺诈行为。

未修复设备易被 Reaper 僵尸网络收割

Sierra Wireless 警告称，设备还可被纳入 Reaper （或IOTroop）僵尸网络中。去年10月，Reaper 僵尸网络利用物联网设备如 IP 无线摄像头、路由器和 DVR 等的速度甚至超过 Mirai。奇虎360 Netlab 研究人员指出，只在一天的时间，超过200万台受感染设备在 C&C 服务器队列中等待被处理；率先分析 Reaper 僵尸网络的 Check Point 公司表示，它发动的 DDoS 攻击造成的后果甚至让 Dyn 攻击也相形见绌。

Mirai 僵尸网络依靠的是不存在的、默认的或弱密码，而 Reaper 使用的是未修复设备上的利用码控制设备、收割设备凭证并和 C&C 服务器保持联系并接受指令。

Sierra Wireless 在一份技术通告中指出，已发现 Reaper 僵尸网络感染运行老旧固件版本的 Airelink 网关，前提是这些网关连接外网并使用默认的用户或查看者 (viewer) 密码。

Sierra Wireless 公司指出，运行固件 4.4.5 或更早版本的 LS300、GX400、GX/ES440 以及运行 4.9.1或更早版本的 GX/ES450、RV50、RV50X、MP70、MP70E 易被 Reaper 僵尸网络收割。
