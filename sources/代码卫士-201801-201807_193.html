联想修复服务器中的高危安全启动漏洞

联想发布补丁，修复影响某些 System x 服务器上安全启动  (Secure Boot) 功能的一个高危漏洞。

该漏洞如遭利用可导致启用未经验证的代码。该漏洞是联想内部测试团队发现的，编号是 CVE-2017-3775。它影响十几个服务器型号，包括 Flex System x240 M5、x280 X6、x480 X6、x880、x3xxx 系列以及 NeXtScale nx360 M5设备。

联想指出，“联想内部的测试团队发现，当系统管理员启用安全启动模式时，某些 System x 服务器 BIOS/UEFI 版本在启动前并未正确验证已签名代码。因此，如果攻击者对系统具有物理访问权限就能启用未签名代码。”

联想指出，在默认情况下系统的安全启动功能是禁止的，因为签名代码在数据中心环境中相对较新。另外标准操作符配置禁用签名检查。

联想在安全公告中不仅公布了所有的受影响服务器型号，而且还发布了每个型号所对应的正确的 BIOS/UEFI 更新。联想建议使用安全启动功能的管理员在应用更显前控制对系统的物理访问权限。

另外，联想还发布了针对联想系统更新驱动映射实用程序 (Lenovo System Update Drive Mapping Utility) 中缓冲溢出漏洞的补丁。该漏洞的编号是 CVE-2018-9063，它可导致未明确行为的产生如执行任意代码等。

该漏洞由 SaifAllah benMassaoud 发现，严重程度为中危。攻击者能够输入大量用户 ID 或密码导致程序缓冲区溢出，从而利用这个漏洞。攻击者还可能以 MapDrv 的权限执行代码。

联想已在 System Update版本 5.07.0072 或之后的版本修复该漏洞，建议用户将应用更新至最新版本。用户可登录应用点击右上角的绿色问号，然后选择“关于”即可查看当前所安装的版本是否是最新版本。

联想 System Update 执行时自动检查是否存在更新版本，因此用户应该只需要打开应用并接受弹出的更新即可。另外用户也可进行手动更新，从联想官网下载最新版本即可。
