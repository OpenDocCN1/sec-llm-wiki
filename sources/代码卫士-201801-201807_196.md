# 哥本哈根的城市公共自行车系统遭黑客关闭

> **一名未具名黑客攻陷了哥本哈根城市自行车网络**** Bycyklen****，并删除了该组织机构的整个数据库，在上周末禁用了公众对自行车的访问权限。**

Bycyklen 在网站上指出，这起黑客事件发生在当地时间5月4日（周五）晚上至5月5日（周六）之间。Bycyklen 指出这起攻击“非常粗糙”，暗指攻击可能是由“对其 IT 基础设施非常了解的人”实施的。

上周六所有自行车均无法使用

周六早上，Bycyklen 的所有1860辆自行车因遭受黑客攻击而无法使用。

受影响的自行车通过连接至 Bycyklken 数据库的安卓平板电脑运作。数据库记录了记录城市所有自行车的租赁详情。如果没有数据库，那么用户无法解锁自行车。当地用户也可通过邮件创建账户以更快地解锁自行车。

Bycyklen 在Facebook 上表示，修复这个问题需要手动更新所有的自行车。周六，员工追踪自行车并重启安卓平板电脑后恢复了200辆自行车的正常运作。该公司表示让所有自行车恢复至正常运转状态将“耗费一些时间”。

Bycyklen 表示黑客并未窃取用户数据

周一，Bycyklen 发布最新消息称，分析攻击后并未发现黑客盗取数据的迹象。

Bycyklen 公司指出，“攻击的直接目标是公司本身而非用户。我们并未存储支付卡信息。我们保存的唯一信息是用户的邮件地址、电话号码和 Bycyklen 自行车的 PIN 码。”

该公司还指出，“为安全起见，我们鼓励所有用户尽快更改 PIN 码。”Bycyklen 目前正在 Facebook 页面举办“寻宝”活动，请用户报告运转失灵的情况，以便员工能更新并恢复运转。

这次攻击的发生时间非常凑巧，正好赶上哥本哈根市举办世界冰球锦标赛。
