火眼公司的研究员在罗技电子公司的 (Logitech) Harmony Hub 家庭控制系统中发现了多个漏洞。该厂商已发布固件更新修复漏洞。

罗技电子 Harmony Hub 可使用户通过安卓或 iOS 手机或平板电脑控制家庭娱乐和多种其它智能设备。通过蓝牙匹配成功后，Harmony app 就会通过基于 HTTP 的 API 和 Harmony Hub 进行通信。

火眼公司的研究员发现，拥有本地网络访问权限的攻击者能够利用多种类型的漏洞控制连接至 Hub 的设备并攻陷网络上的其它设备。

火眼公司认为，鉴于 Harmony Hub 可用于控制智能锁和恒温器，因此这些缺陷可带来严重风险。

安全专家发现可结合使用四种漏洞，通过 SSH 获取对设备的 root 访问权限。

其中一个安全漏洞和生产固件图像中的调试详情有关。另外一个缺陷和固件更新过程中不正确的 SSL 证书验证相关。固件更新流程本身是不安全的，可导致攻击者向设备发送恶意更新。

由于 Hub 上并未配置 root 密码，因此如果攻击者能设法启用 Dropbear SSH 服务器，那么它们就能经由 SSH 获得 root 访问权限。通过之前提到的弱点上传特别构造的固件很可能能够启用服务器。

补丁已发布

罗技电子在1月末获悉漏洞情况并在4月10日通过发布固件版本 4.15.96 修复漏洞。罗技电子建议客户安装更新，并提供了完整的安装指南。

罗技电子指出，这些缺陷影响其基于 Harmony Hub 的产品，包括 Harmony Elite、Home Hub、Ultimate Hub、Home Control、Pro、Smart Control、Companion、Smart Keyboard、Ultimate、Ultimate Home 以及 Harmony Hub。

研究人员解释称，随着技术渗透到生活的方方面面，我们对多种设备的信任在不知不觉中急剧增长。由于Harmony Hub 和很多物联网设备一样使用常见的处理器架构，恶意工具可被轻易添加到受攻陷的 Harmony Hub 中，从而加剧了目标攻击带来的整体影响。
