> **安全研究员已发现史上首个利用新型无文件代码注入技术****Process Doppelg****ä****nging ****躲避检测的勒索软件。**

Process Doppelgänging 攻击技术利用的是内置 Windows 功能即 “NTFS Transactions”和一个过时的 Windows 进程实现加载器，它在微软的所有 Windows 操作系统版本（包括 Windows 10）上均起作用。

Process Doppelgänging 攻击起作用的方式是使用 NTFS Transactions 功能替换合法进程内存启动恶意进程，诱骗进程监控工具和反病毒软件以为运行的是合法进程。

Process Doppelgänging 攻击详情被公开后，多名恶意人员都在滥用这种技术绕过现代的安全解决方案。

有选择地攻击受害者

卡巴斯基实验室的安全研究员目前发现了史上首款勒索软件，即 SynAck 的一个新变体，利用这种技术躲避检测，受害者遍布美国、科威特、德国和伊朗。

这款 SynAck 勒索软件首次现身于2017年9月，它使用复杂的混淆技术阻止逆向工程，但研究员设法将其解压并在一篇博客文章中分享了分析结果。

有意思的是，这款新型 SynAck 勒索软件并不感染某些国家的用户，包括俄罗斯、白俄罗斯、乌克兰、格鲁吉亚、塔吉克斯坦、哈萨克斯坦以及乌兹别克斯坦。

为了找到某个具体用户所在的国家，SynAck 勒索软件将安装在用户计算机上的键盘布局和恶意软件上存储的硬编码列表进行匹配。如匹配成功，这款勒索软件就会休眠30秒，然后调用 ExitProcess 阻止文件加密。

SynAck 勒索软件还通过检查执行目录阻止沙箱的自动分析。如果 SynAck 发现从“不正确的”目录中启动了恶意可执行文件，那么它就不会进一步行动而是选择终止行动。

和其它勒索软件一样，一旦遭感染后，SynAck 勒索软件会通过 AES-256-ECB 算法加密每个受感染文件的内容，并为受害者提供解密密钥，直至他们联系攻击者并支付勒索金。

SynAck 还能够通过修改注册表中的 LegalNoticeCaption 和LegalNoticeText 密钥在 Windows 登录屏幕上展示勒索信息。SynAck 甚至清除系统所存储的事件日志来避免对受感染机器的取证分析。

尽管研究人员并未表示 SynAck 是如何登录到计算机上的，但多数勒索软件通过钓鱼邮件、网站恶意广告和第三方应用和程序进行传播。

防范建议

因此，在打开邮件并点击其中的文档链接时一定要万分谨慎，除非来源已得到验证确保不受此类勒索软件感染的影响。

尽管在这个案例中，只有某些安全软件和反病毒软件能够抵御或警告这种勒索威胁，但作为良好实践，用户可以在系统上安装有效的反病毒安全套件并保持更新。另外，将重要文件备份至不联网的外部存储设备也能保护重要数据的安全。
