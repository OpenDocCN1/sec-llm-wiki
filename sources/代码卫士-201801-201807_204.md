# ZooPark：专门对安卓用户下手的 APT 组织

> **卡巴斯基实验室的研究员发布了一篇报告，详述了三年来攻击中东地区的网络间谍**** APT****组织**** ZooPark****。**  

ZooPark 组织在2015年开始行动，多年来已慢慢演进得越来越复杂。

卡巴斯基实验室发布报告指出，根据 ZooPark 在攻击活动中所使用的恶意软件，其攻击活动可分为四个阶段。

第1阶段 (2015)

攻击者部署的恶意软件极其简单化，它仅具有两种功能：窃取注册在受害者设备上的账户详情以及从地址簿窃取通讯录。在这个阶段，攻击者试图将 app 伪装成 Telegram 官方应用。

第2阶段 (2016)

ZooPark 组织改进了恶意软件的能力。新增能力表明它将被用作监控软件。

各版本功能如下：

> *   版本1：提取通讯录和账户信息
>     
> *    版本2：新增的提取内容包括通话日志、GPS 地理位置、短信、设备信息
>     
> *   版本3：新增的提取内容包括通话记录（音频）、所安装应用详情、浏览器数据（书签和历史）、内存卡中的照片和图片
>     
> *   版本4：新增的提取内容包括键盘记录、剪贴板数据、任意文件/文件夹、浏览器数据（搜索历史）、捕获的照片/视频/音频/截屏/屏幕记录，后门功能包括 root/非 root 权限下的 shell 命令执行、静默发送短消息以及拨打电话。
>     

第3阶段 (2016)

ZooPark 组织似乎意识到，尽管进了最大努力，但恶意软件似乎仍然不高阶，因此他们 fork 了 Spymaster Pro 商用监控软件应用的某个版本并试图将二者杂糅在一起。

第4阶段 (2017)

ZooPark 组织的恶意软件被大面积修改。第3阶段的更改几乎全部被丢弃，该组织在旧的阶段2代码库的基础上甚至构建了更多的功能。

卡巴斯基安全专家指出，最后一步尤其耐人寻味，它说明恶意软件直接从代码功能飞跃到非常复杂的功能。这表明最后一版源自专门的监控工具供应商。不过这种情况也并不稀奇，因为这些监控工具的市场在不断增长，越来越受到政府机构的青睐，而中东地区已经出现了多个案例。

至于传播渠道，ZooPark 组织依靠的是简单的技术。他们要么创建 Telegram 渠道分享恶意 app 的链接； 要么攻陷合法站点，将访客重定向至可下载受污染 app 的页面。

卡巴斯基指出，这些技术都奏效，ZooPark 组织的攻击受害者遍布多个国家，如摩洛哥、埃及、黎巴嫩、约旦和伊朗。
