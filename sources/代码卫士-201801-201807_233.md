> **一名或多名黑客劫持了基于**** web ****的以太坊钱包****MyEtherWallet.com ****的**** DNS ****服务器。**

![](../Images/f3962bbb3af231b98f6efef9e9750698.png)

访问该站点的用户被重定向至虚假网站，已登录用户的钱包私钥被盗，账户被清空。

MyEtherWallet 管理员检测到这起 DNS 劫持事件并尝试通过推特警告用户相关情况。虚假网站易于被发现，因为攻击者使用了一个自签名 TLS 证书在所有现代浏览器中均触发出错消息。

然而，并非所有的用户都会注意到 HTTPS 出错消息，而是直接登录到自己的账户。据资金被盗的用户报告称，黑客将以太坊收集在如下地址：0x1d50588C0aa11959A5c28831ce3DC5F1D3120d29。

大约两小时后且 MyEtherWallet 开始重新获得访问 DNS 的权限后，黑客将被盗资金转移到了另外一个账户中。这名黑客共盗取 215 个以太坊，相当于交易时的16万美元。

甲骨文互联网情报部门表示，黑客执行 BGP 路由劫持将本来属于亚马逊服务器的互联网流量重定向至受他们控制的系统后劫持了 DNS 条目。其中一些被劫持流量本来属于 MyEtherWallet 团队使用的亚马逊 DNS 服务器。攻击者随后将 MyEtherWallet.com 域名的域名解析指向一个位于俄罗斯的 IP 地址，黑客正是将记录私钥的 MyEtherWallet 网站的虚假版本托管在这个 IP 地址上。

MyEtherWallet 事件并非首次针对和密币相关域名的 DNS 劫持攻击。2018年1月，黑客劫持了 BlackWallet.com 的服务器并设法窃取超过40万美元的 XLM 币。

EtherDelta 在2017年圣诞节前也曾遭受一次类似的 DNS 劫持事件，但截至目前尚不清楚攻击者窃取的资金数目。 Classic Ether Wallet 和 Etherparty ICO 网站也曾遭受 DNS 劫持攻击。
