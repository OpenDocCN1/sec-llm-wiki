# 服不服：曾“折腰”的80%的受害者会选择再次支付勒索金

**曾通过支付勒索金恢复文件的约****80%****的勒索软件受害者表示，如果没有备份文件会再次选择支付勒索金恢复数据。**

这是《Telstra 2018 安全报告》得出的结论之一。该报告调查了来自13个横跨亚洲、澳大利亚和欧洲的国家的1252名用户，探讨了网络安全版图的多个方面，本文仅讨论和勒索软件相关的研究成果。

多数付款的受害者能恢复文件

调查结果显示，相比之前的调查情况，受访者在2017年报告的勒索软件攻击数量有所增加。

在所有受感染的用户中，47%的亚洲人和澳大利亚人以及41%的欧洲人支付了勒索金以便恢复对加密文件的访问权限。

Telstra 公司表示，87%的亚洲人、86%的澳大利亚人和82%的欧洲人在支付勒索金之后能够恢复自己的文件。

多数受害者会再次选择支付勒索金

在支付过勒索金的受害者中，76%的亚洲人、83%的澳大利亚人和80%的欧洲人表示如果没有备份文件，则会再次选择支付勒索金。

这和执法部门给出的流行建议不同，后者的建议是不要支付勒索金。然而，这种理想化的建议有时候不可能应用到现实生活中。因为相比1000到5000美元的勒索请求而言，企业如果丢失对知识产权的访问权限会给日常工作带来更昂贵的代价。

因此，有很大一部分受害者会选择支付勒索金，而且只要处理勒索软件感染的总成本仍然小于对正确安全实践的投资总额，那么受害者就会一直选择支付勒索金。

不过也有其它调查结果显示，受害者支付勒索金之后文件被恢复的概率只有50%。
