# 全球最大的身份平台之一Auth0 上出现严重的认证绕过漏洞

> **全球最大的身份即服务平台之一**** Autho0 ****上被曝存在一个严重的认证绕过漏洞，它可导致恶意攻击者访问任何使用**** Autho0 ****服务进行验证的门户或应用程序。**

Auth0 为很多平台提供基于令牌的验证解决方案，包括将社交媒体验证整合至应用程序中。该平台拥有2000多家企业客户并且每天管理4200万登录以及每月数十亿登录行为，是全球最大的身份平台之一。

安全公司 Cinta Infinita 公司的研究人员在2017年9月渗透一款应用时在 Auth0 平台的 Legacy Lock API 中发现了一个缺陷 (CVE-2018-6873) ，它存在的原因在于 JSON Web Tokens (JWT) audience 参数的验证不正确。

研究人员成功地利用这个问题通过一次针对在 Auth0 平台运行的应用程序的简单跨站点请求伪造 (CSRF/XSRF) 攻击绕过了登录验证。

Auth0 平台上的 CSRF (CVE-2018-6874) 漏洞可导致攻击者复用为单独账户生成的一个有效的签名 JWT 访问目标受害者的账户。

为此，攻击者仅需要拥有受害者的用户 ID 或邮件地址即可，而这些信息仅需简单的社工技巧即可获取。

研究人员指出，同样的攻击可复制到很多组织机构中，只需知道 JWT 的预期字段和值即可。在多数案例中并不需要社工技巧。使用邮件地址或增量整数进行用户识别的应用程序验证可被轻松绕过。

响应快速但修复漏洞过程漫长

研究人员在2017年10月将漏洞问题告知 Auth0 安全团队，后者快速响应并在不到4个小时的时间内解决了这个问题。

然而，由于易受攻击的 Auth0 SDK 和支持的库已部署于客户端，因此 Auth0 花费了近6个月的时间才联系上每个客户并帮助他们修复了这个漏洞，随后将漏洞公布。

Auth0 团队在安全公告中指出，“和 Cinta Infinita 发现的特别案例的修复方案不同，我们只能通过强制客户更新库/SDK 的方式解决这个问题，这是一项很巨大的任务。”

该公司已通过大规模重写受感染库和发布 SDK 新版 (auth0.js 9 和 Lock 11) 的方式缓解了该漏洞。

Cinta Infinita 也等待了6个月的时间才公开这一漏洞，从而留给 Auth0 团队足够的时间来更新所有 Private SaaS Applicances （预置）。

Cinta Infinita 公布了一个 PoC 视频，演示了他们如何通过伪造认证令牌登录 Auth0 管理主板的方式获取受害者的用户 id 并绕过密码认证。
