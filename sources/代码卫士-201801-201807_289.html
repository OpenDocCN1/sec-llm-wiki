彭博社报道称，苹果公司计划摒弃英特尔芯片，将在2020年在 Mac 计算机中使用自己的芯片。该计划被称为 “Kalamata （卡拉马塔，希腊港口城市）”，目的是让所有的苹果设备包括移动和台式设备使用同样的芯片从而实现更强的兼容性。

2006年前，苹果一直在使用 PowerPC CPU 平台，随后才转向英特尔处理器。彭博社报道称，苹果对英特尔 CPU 的使用占英特尔收益的5%左右。苹果使用其它处理器的做法势必会给英特尔的利润带来很大的损失。彭博社的这篇新闻报道发出后，英特尔的股价下跌6%。

彭博社报道称，苹果使用自家芯片的做法将使得所有的苹果设备在同一个平台上运行。这样苹果就能在需要的时候发布新的处理器而不必等待英特尔。另外，这种做法将使得英特尔直接向可让苹果设备自力更生的 CPU 增加新功能。

另外，苹果公司还在着手准备一个名为 “Marzipan（杏仁蛋白糖）” 的新平台，从而让 iOS 应用在 macOS 上运行。通过在所有设备上使用相同的 CPU 架构，它将使这种新平台的开发更为容易，因为它们不必创建在英特尔芯片上运行的仿真程序。

目前苹果尚未就此事发表任何评论。
