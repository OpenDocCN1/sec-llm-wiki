GoScanSSH 恶意软件为何避免感染政府和军用服务器？

安全专家发现了一种新型恶意软件，它针对的是易受攻击的 Linux 系统并竭力避免感染政府和军用网络中的设备。

这款新型恶意软件名为 “GoScanSSH”，它的名称也表达了其主要功能和能力：用 Go 语言编写而成，通过受感染主机扫描新主机，而 SSH 端口是进入点。

GoScanSSH 并非一般的物联网僵尸

GoScanSSH 的感染进程有点复杂，但看似不像是出自物联网僵尸网络制造者之手。它看似是由一个高阶的威胁发动者创建的，它寻求的是在内部网络中立足，而且非常谨慎小心地避免感染政府、军方或执法部门的网络，从而避免招来更多审查以及可能存在的合法调查。

GoScanSSH 的典型感染过程如下，思科 Talos 团队公布了更为深入的详情：

  • 一台已遭感染的设备随机选择一个 IP 地址。

  • 恶意软件查看所选 IP 是否位于两个 IP 黑名单列表中（其中一个列表是专用地址，另外一个列表的 IP 地址范围主要是由多种政府和军方实体所控制）。

  • GoScanSSH 在端口22上扫描 IP，查找开放的 SSH 端口。

  • 如果这个 IP 拥有开放的 SSH 端口，那么恶意软件会运行一个逆向 DNS 查找，查看这个 IP 是否托管着任何网站/域名。

  • 如果这个 IP 托管着网站，GoScanSSH 就会运行已找到的域名查看是否在第二个 IP 黑名单内。

  • 第二次执行的扫描会查看这些域名是否用于如下 TLS：.mil、.gov、.army、.airforce、.navy、.gov.uk、.mil.uk、.govt.uk、.mod.uk、.gov.au、.govt.nz、.mil.nz、.parliament.nz、.gov.il、.muni.il、.idf.il、.gov.za、.mil.za、.gob.es以及 .police.uk。

  • 如果这个 IP 托管着任何政府、军方或执法部门的域名，那么 GoScanSSH 就会转移至一个新的 IP 地址。

  • 如果所扫描的 IP 地址并不包含在这两个黑名单之内，那么 GoScanSSH 就会发动字典暴力攻击，试图猜测 SSH 凭证。

  • GoScanSSH 使用已给包含超过7000多个用户密码组合的列表。

  • 多数组织具体针对的是基于 Linux 的设备，而其中一些组合是最常见的用户密码组织。

  • 当 GoScan SSH 找到远程设备的 SSH 凭证后，它会汇报给位于暗网（通过 Tor2Web 代理进行通信）上的 C&C 服务器。

  • 犯罪分子拼凑出 GoScanSSH 恶意软件二进制的唯一版本。

  • 随后犯罪分子手动登录到新设备并安装新版的 GoScanSSH 恶意软件。

  • 恶意软件运行一系列哈希计算来判断设备的硬件能力并汇报给 C&C 服务器。

  • GoScanSSH 开始扫描其它设备实施感染。

思科 Talos 团队的研究人员表示，目前已发现了70多个唯一的 GoScanSSH 恶意软件感染样本，而其中很多感染的版本号并不相同（1.2.2、1.2.4、1.3.0 等）。这表明恶意软件的作者还在持续开发。

看似是在挖矿但实际可能并非如此

有人可能会认为它在受感染设备上运行哈希计算，可能说明攻击者未来可能会在受感染设备上安装挖矿机。但研究人员至今仍未发现类似情况。

从理论上来讲可能会存在很多种可能性，因为恶意软件在暴力攻击中使用了默认的用户密码组合列表。思科公司的安全专家表示，这些凭证属于物联网设备，但这些设备并不具备处理密币挖矿行为所需的硬件。

例如，在暴力攻击中，GoScanSSH 利用和 OpenELEC 系统、Raspberry Pi 板、OSMC 设备、优博通路由器、PolyCom SIP 电话、华为设备和Asterisk 服务器相关的默认凭证。

GoScanSSH 僵尸网络体积小

目前尚不清楚犯罪分子部署GoScanSSH 的目的是什么，不过将它手动部署在每台受感染的主机上并谨慎小心地避开政府和军方网络的行为说明有人试图入侵更大规模的网络，可能是为了协调规模更大的攻击。

犯罪分子喜欢低调行事的特征也很明显，因为尽管活跃于2017年6月、部署了70多个版本且使用了250多个唯一的 C&C 服务器，但研究人员发现的受感染僵尸数量非常少。

研究人员为和 C&C 服务器存在关联的域名使用了被动 DNS 数据，结果发现了向 C&C 服务器提出的少量请求，表明它是一个体量非常小的僵尸网络。

从思科的被动 DNS 数据来看，拥有 DNS 解析请求数量最多的 C&C 域名出现了 8,579 次，它跟多数物联网僵尸网络相比是非常小的数量。如果在过去10天这种活动未增长10倍的话，研究人员也不会注意到这个新威胁。
