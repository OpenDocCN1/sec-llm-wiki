# Telegram 被判必须将密钥交给俄罗斯联邦安全局

> **本周二，俄罗斯最高法院判决**** Telegram ****通讯**** app ****必须将读取用户通讯数据的密钥交给俄罗斯联邦安全局。**

俄罗斯国家信息监控局 (Roskomnadzor) 在网站上下令 Telegram 在15天内“向俄罗斯联邦安全局提供用于解码接收到的、传输的或被发送的电子消息的必要信息”。

Telegram 早前针对必须分享这类信息的判令提出上诉，但在本周二被驳回。

如果不提供密钥，那么该服务可能会在俄罗斯被封。

Telegram 是一款免费的通讯 app，用户可在由最多5000人组成的群组里交换信息、照片和视频，自从2013年成立以来已经吸引了1亿多名用户。

Telegram 的自我流亡的俄罗斯创始人 Pavel Durov 在2017年9月表示，俄罗斯联邦安全局要求获得后门权限。

Telegram 并未提供加密密钥后，联邦安全局提起正式诉讼。

Durov 去年曾表示，俄罗斯联邦局的要求“从技术上来讲是不可能实施的”，而且违反了俄罗斯宪法中关于公民通信隐私权的规定。

去年6月份，俄罗斯国家通信监管部门威胁称，如果 Telegram 不提供注册文档，则会对它实施禁令。尽管 Telegram 随后进行了注册，但并未同意安全局提出的数据存储要求。注册公司必须向联邦安全局提供关于用户交互的信息。

2016年，俄罗斯通过一项具有争议的反恐立法，要求从2018年开始，这类通讯 app 必须将所有俄罗斯用户的数据存储在俄罗斯境内。该法案遭到互联网公司和反对派的谴责。
