# ACRN：Linux 基金会推出开源的物联网设备管理程序

> **Linux ****基金会推出一个新项目**** ACRN****，为物联网设备创建管理程序提供通用代码。**

管理程序是创建并运行虚拟机的计算机代码。ACRN 项目旨在为专门的物联网管理程序组件提供通用结构。

Linux 基金会表示将把 ACRN 设置为完全自定义化的形式，它由两个主要组件构成：管理程序本身以及和底层硬件交互的设备机型。

为智能汽车和智能工业系统而生

ACRN 会为物联网带来多样性和自动化，尤其对于智能工业设备的开发而言更是如此。

ACRN 团队希望硬件供应商能够将该项目作为在物联网设备上运行固件的基础，从而轻松地在多个运行于管理程序虚拟机上的 guest 操作系统之间切换和更新。

开发人员希望 ACRN 能够紧跟信贷物联网的解决方案如智能汽车，不过该项目是针对物联网整体的通用的全方位解决方案。

支持安卓等Guest 操作系统

ACRN 将运行 Linux 即服务（主机）操作系统，并支持多种 Guest 操作系统如安卓、其它 Linux 发行版本或 RTOS。

ACRN 开发人员表示自己的管理程序要比一般的数据中心管理程序小6倍，使得其成为限制资源使用的设备的理想解决方案。

开发人员还表示， ACRN 启动速度快而且安全性能佳。ACRN 开发人员指出有限安全性高的工作负荷并且和其它进程隔离。

该项目旨在通过免费、现成可用且包含安全最佳实践的基础架构设计的解决方案缩减开发成本，以此避免现代物联网设备的安全漏洞问题。

Linux 基金会表示英特尔是 ACRN 项目早期阶段的主要贡献者，利用自身在管理程序虚拟化技术方面的经验做出了贡献。Adlink、Aptiv、LG 和东软集团也在早期阶段提供了支持。
