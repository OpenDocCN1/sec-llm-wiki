# Palo Alto 将以3亿美金收购 CIA 旗下的 Evident.io 公司

> **周三，网络安全公司**** Palo Alto Networks ****表示已同意以****3****亿美元的现金收购云安全和合规公司**** Evident.io****。**

Palo Alto 公司目前提供多种云环境安全解决方案，包括 VM 系列的可视化下一代防火墙、公共云服务基础设施的 API 安全解决方案和基于主机安全的 Traps 端点解决方案。

Evident.io 公司位于美国加利福尼亚州普莱森顿，它的旗舰产品 Evident 安全平台 (ESP) 旨在帮助客户通过将攻击面最小化并提升整体安全态势的方式降低云安全风险。ESP 能够持续监控 AWS 和微软 Azure 部署、识别评估安全风险、为安全团队提供补救指南，并且通过分析服务配置和安全和合规控制的的账户设置提供安全审计和合规报告。

Evident.io 公司的首席执行官和联合创始人 Tim Prendergast 解释称，“集成 Palo Alto Networks 公司的云安全解决方案后，客户能够使用同一方式开展持续性监控、全面的存储安全和合规验证与报告。”

Evident.io 受贝恩资本风险投资 (Bain Capital Ventures)、真风投 (True Ventures)、温洛克资本 (Venrock)、谷歌风投、以及受美国中情局控制的非营利性风投机构in-Q-Tel 的支持。

这次并购交易将于 Palo Alto Networks 公司的第三财季完成，受惯例成交条件达成的影响。

Evident.io 公司的联合创始人 Tim Prendergast 和 Justin Lundy 将加入 Palo Alto Networks 公司。
