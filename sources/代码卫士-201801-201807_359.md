> **美国国防部向谷歌寻求帮助，分析无人机监控录像。**

具体来讲，谷歌正在和美国国防部合作开展一个试点项目，旨在利用 TensorFlow API 协助对非机密数据进行对象识别。谷歌已证实该消息。

Gizmodo 报道称，这种合作关系是国防部 Maven 项目的一部分。该项目发布于2017年4月，旨在通过机器学习和人工智能分析国防部抓取的大量监控录像。

Gizmodo 报道称，上周一些谷歌员工通过内部邮件列表获知谷歌参与 Maven 项目后感到“愤怒”。

一名谷歌发言人在声明中表示，这个项目标记需要人工审查的图像，“并且仅用于非攻击性用途”。

这名发言人补充道，“军方对机器学习的使用引发担忧也在情理之中。我们已和其他人在内部探讨了这个重要议题，因为我们将继续制定关于机器学习技术开发和使用的政策和保护措施。”

虽然谷歌参与 Maven 项目算是新闻，但谷歌发言人表示，谷歌“一直以来和政府机构合作”。2016年，谷歌前首席执行官 Eric Schmidt（曾担任谷歌母公司 Alphabet 的董事长）被聘为五角大楼创新委员会的领头人，而该委员会的任务就是帮助国防部跟上当前技术发展的节奏。
