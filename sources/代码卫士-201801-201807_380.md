# 苹果公司终于承认在谷歌服务器上存储用户的 iCloud 信息

> **如果你选择苹果生态系统的原因是不信任谷歌，那么很遗憾地告诉你，目前苹果首次承认使用谷歌服务器存储用户的某些**** iCloud ****数据。**

自2011年起，苹果公司就一直使用亚马逊 Web Services 和微软的 Azure 服务托管 iCloud 文档。将某些文件托管在谷歌公司应该也不算新闻了，毕竟这种说法早在2007年就在流传。

苹果和谷歌签订的在线存储交易被暴露的时间是在2016年，该消息随后得到《金融时报》的证实。

但这是苹果公司首次公开承认用户的数据以加密形式存储在谷歌服务中。这是苹果公司在上个月发布的一份秘密安全指导文件中提到的。

指导文件指出，iCloud 使用“第三方存储服务如亚马逊的 S3 存储桶和谷歌的云平台”，但并未明确提及微软的 Azure。

苹果公司表示自己的商业模式无需向谷歌那样收集用户的个人数据，尽管并无证据表明谷歌正在挖掘 iCloud 以获取用户信息。让人尴尬的是，苹果公司的首席执行官 Tim Cook 一直都在抨击谷歌的数据囤积和隐私问题。
