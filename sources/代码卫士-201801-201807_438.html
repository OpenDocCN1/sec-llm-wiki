ManageEngine 的 IT 管理产品中存在多个严重漏洞

Digital Defense 公司的安全研究员在 ManageEngine 的 IT 管理产品中发现多个潜在的严重漏洞，其中一些可导致攻击者完全控制受影响应用。厂商已发布修复这些缺陷的补丁。

ManageEngine 公司归 Zoho 所有，它是一家网络、数据中心、桌面和移动设备以及安全解决方案提供商，客户超过4万名，其中60%的客户是全球财富500强公司。

其中一个漏洞影响 ManageEngine 的 ServiceDesk Plus 技术支持软件。一个未经认证的文件上传漏洞导致攻击者上传 JavaScript web shell 并以系统权限执行任意命令。

安全研究人员还发现了多个SQL 盲注漏洞，可导致未经验证的攻击者完全控制应用甚至控制底层主机。

以上提及的缺陷出现在 OpManager 网络监控产品、网络配置管理器、带宽监控和流量分析产品 NetFlow Analyzer、防火墙配置和日志管理产品 Firewall Analyzer、以及 IP 地址管理 app OpUtils 中。

这些产品还受到一个枚举问题的影响。该问题可被用于访问用户信息如用户名、邮件地址和电话号码。攻击者可通过利用一个未经验证的 XML 外部实体漏洞访问主机上的文件内容。

研究人员指出，ManageEngine 迅速回应漏洞报告并为每款受影响应用发布更新解决安全漏洞问题。

Digital Defense 公司的工程副总裁表示，应用层的漏洞继续成为软件供应商的主要关注领域。该公司近期从 Dell EMC 和 VMware 的数据保护产品中发现饿了认证绕过、任意文件上传以及路径遍历漏洞。
