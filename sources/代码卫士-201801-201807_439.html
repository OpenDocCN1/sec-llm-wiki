Python 脚本能通过 Shodan.io 自动搜索易受攻击设备，随后利用 Metasploit 的利用数据库劫持电脑和工具。

 


该脚本运行后会爬取互联网查找可能易受攻击的机器（通常因漏洞未修复而易受攻击），随后自动接管这些机器。

令人惊讶的是，这种方法竟然现在才出现。

一位名为 Vector 的研究人员在 GitHub 上发布了该软件 AutoSploit。它让大规模入侵变得极其容易。通过 Shodan 搜索引擎收集好目标后，这个 Python 2.7 脚本就试图运行 Metasploit 模块发动攻击。

Metasploit 是一款开源的渗透测试工具：它是一个含有利用软件和其它产品中漏洞从系统中提取数据、或打开远程控制面板发布远程命令的代码片段数据库。Shodan 搜索能让用户搜索面向公开互联网的计算机、服务器、工业设备、网络摄像头和其它设备，暴露它们的开放端口以及潜在可遭利用的服务。

                            

这款托管在GitHub 上的库解释称，“Metasploit 模块有助于实施远程代码执行并获得逆向 TCP Shells 以及/或者 Meterpreter 会话。”

由于这种自动化攻击会带来法律后果，因此这个库也警告称在机器上运行该代码能导致用户轻易遭暴露，“可能从 OPSEC 的角度来看并非是最佳方法”。

总体而言，其它安全行业也不认为这是最佳方法。

脚本小子们的福利？

Tao Security 的创始人 Richard Bejtlich 在推特上表示，并无必要发布这一工具。“和Shodan 的关联就能让它行走在法律的边缘。将大规模利用公共系统的工具发布供脚本小子们使用是不合法的。只是因为你能做某件事并不意味着这样做是明智的。最后会以悲剧收场。”

同时，明确把漏洞扫描和漏洞利用关联在一起可能具有一定的价值，这种做法很清楚地表明自动化默默对安全造成破坏。

Vector 在推特上表示该Python 代码在安全社区中反响良好。Vector 表示看到了对工具的负面评价，但认为这种评价适用于所有应用了自动化的攻击工具。他指出和其它工具一样，AutoSploit也取决于使用者如何使用，自己不会扮演门将的角色，他认为信息应该是自由的，他是开源的粉丝。
