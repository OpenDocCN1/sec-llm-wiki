# 微软发布 Windows 紧急带外更新禁用 Spectre 缓解措施

**上周末，微软发布**** Windows ****紧急带外更新，禁用为**** Spectre ****（幽灵）变体****2****漏洞**** (CVE-2017-5715) ****发布的补丁**** KB4078130****。**

该补丁适用于 Windows 7 (SP1)、Windows 8.1以及所有版本的 Windows 10和所有受支持的 Windows 服务器发行版本。微软在1月3日为 Meltdown（“熔毁”）和 Spectre（“幽灵”）漏洞发布缓解措施。

微软对英特尔声明的回应

微软表示英特尔公开证实称为 Spectre所部署的微码更新引发了“比预期频率高的重启和其它不可预测的系统行为”导致“数据丢失或损坏”问题后，决定你禁用为 Spectre 变体2漏洞推出的缓解措施。

作为响应措施，微软决定在英特尔开发出更稳定的修复方案前禁用 Spectre 变体2 的缓解措施。针对无法删除更新的Windows 桌面和服务器用户，微软提供了通过注册密钥手动禁用缓解措施的指令。

微软并非回滚 Spectre 变体2补丁的唯一公司

微软并未首个回滚 Spectre 变体2补丁的公司。英特尔发布公告后，戴尔建议消费者“回滚到之前的BIOS 版本”，而该版本中并不包含 Spectre 补丁。

惠普也采取了类似步骤。此前惠普推出包含 Meltdown 和 Spectre（变体1和变体2）补丁的可用 BIOS 更新，随后在上周重新发布仅包含 Meltdown 和 Spectre 变体1补丁的 BIOS 更新。

Red Hat 企业版也在上上周末，甚至是在英特尔发布正式公布前撤回了 Spectre 变体2补丁的发布。

英特尔并非在Spectre 变体2 补丁中能遭遇问题的唯一大型CPU 制造商。该漏洞还影响使用 AMD 处理器的设备，为此微软还暂停发布对这类设备的 Windows 更新。AMD和微软更正了所报告的 BSOD 错误之后，微软才重新发布相关更新。
