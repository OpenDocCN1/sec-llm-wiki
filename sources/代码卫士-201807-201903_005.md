# Coinhive 浏览器内挖矿服务将在3月8日关闭

> **一周后，即****2019****年****3****月****8****日，旨在为**** web ****开发人员提供基于**** JavaScript ****门罗币矿机的密币挖掘服务**** Coinhive ****将停止服务。**

对于开发人员而言，Coinhive 是一款在 web app 中加载的 JavaScript 库，它允许网站所有人使用访客计算机上可用的 CPU 资源挖掘门罗币 (XMR)。

正如 Coinhive 在公告中指出的那样：“你们当中有些人可能预料到了这种结局，有些人可能很吃惊。我们已经做出了决定。我们将在2019年3月8日停止服务。18个月以来，这个项目的工作就像急旋风，但说实话，在经济上，它不再具备可行性。”

在关于导致服务关闭的原因中，Coinhive 提到了门罗币的最后一次硬分叉，它导致哈希率降低50%，而门罗币的价值同比贬值。

Coinhive 指出，“门罗币的最后一次硬分叉后，哈希率大幅降低（超过50%）给了我们重击。门罗币的贬值率在一年内超过85%导致密币市场‘崩溃’。这个原因再加上硬分叉以及门罗币网络在3月9日的算法更新，使我们认为，是时候停止 Coinhive 服务了。”

Coinhive 还指出，虽然所有的挖矿操作将在3月8日自动停止，但服务控制板还会继续运营，以便提供密币转移服务。

Coinhive 指出，“因此，在2019年3月8日后，将不再运行挖矿操作。在2019年4月30日前仍可访问控制板，这样，如果你的余额高于最低支付门槛，那么就能开始支付。谢谢大家的一路相伴。”

虽然 Coinhive 的运营人员提到，自服务上线起到关闭公告的期间度过了不错的时光，但并非每个人都这样认为，因为它同时也被大规模地用于密币劫持操作中。

**Coinhive 驱动的密币劫持活动也将停止**

![](../Images/c62b0763bd3e8b7eb5092cf1a8bed626.png)

密币劫持活动劫持的是访问合法的但遭攻陷的网站的访客的 CPU资源，这些网站中被犯罪分子嵌入 Coinhive JavaScript 矿机。

密币劫持技术也广泛应用于恶意活动中，作为多阶段感染活动的一部分，它在受攻陷机器上释放了基于 Coinhive 的矿机。

作为密币劫持问题规模的见证者，研究员 Troy Mursch发现 Coinhive 在某个时点每个月获得的利润约为价值25万美元的门罗币，而且“占据所有使用 JavaScript 密币矿机的网站的62%”。

另外，受 Coinhive 驱动的密币劫持活动还扩展至谷歌应用商店，并攻击脆弱的 MikroTik 路由器，成功地通过多次活动感染超过20万台路由器。

密币劫持活动还导致有人在中国30座城市的数千个网吧中部署了恶意 Coinhive 矿机后遭逮捕，甚至因在他人计算机上运行非法的挖矿活动且仅赚取45美元的情况下被判刑。

好消息是，随着 Coinhive 的关闭，密币劫持活动也将不得不停止。而这种停止将一直持续到恶意人员找到另外一款 JavaScript 浏览器内密闭挖掘库的 Coinhive 替代品之时。
