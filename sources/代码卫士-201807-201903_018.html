Edge 浏览器被曝为 Facebook 暗开白名单自动运行 Flash

微软 Edge 浏览器被曝暗藏白名单文件，旨在允许 Facebook 规避其内置的点击播放安全策略，在无需询问获得用户同意的情况下自动运行 Flash 内容。

谷歌 Project Zero 团队的 Ivan Fratric 在去年11月26日提交的首份漏洞报告中指出，“微软 Windows 文件 C:\Windows\system32\edgehtmlpluginpolicy.bin 中包含默认额域名白名单，它可绕过 Flash click2play，在无需获得 Edge 用户确认的情况下加载 Flash 内容。”

此前为秘密的 Edge 白名单的当前版本仅允许 Facebook 绕过www.facebook.com和apps.facebook.com 域名上的 Flash 点击播放策略，该策略目前适用于未出现在该列表上的所有其它域名。

Fratric 在漏洞报告中还强调了 web 浏览器捆绑 Flash 自动运行白名单的安全影响，尤其是在 Adobe 几乎每个月都在发布 Flash 安全补丁的情况下。

他认为该白名单不安全，原因在于：首先，任何域名中存在的 XSS 漏洞都可导致绕过 click2play 策略；其次，至少某些白名单上的域名已经存在公开已知以及未修复的 XSS 漏洞实例，例如 https://www.openbugbounty.org/reports/582253/、 https://www.openbugbounty.org/reports/444528/ 和https://www.openbugbounty.org/reports/130555/；再次，该白名单不仅限于 HTTPS （白名单上的某些域名并不支持 https）。即使不存在 XSS 漏洞，它也会导致实施中间人攻击的攻击者绕过 click2play 策略。

Fratric 报告的问题部分已在微软本月“补丁星期二”中解决。微软将这份白名单减少至两个 Facebook 域名，并为所有白名单上的条目添加了 HTTPS 支持要求来缓解可能存在的中间人攻击。

然而，当时（去年11月），Fratric 在Windows 10 v1803 上发现了58个域名的 sha256 哈希，使他能够解密并获取56个站点的名称。
