Windows 用户要注意了：WinRAR 软件中被曝危险的远程代码执行漏洞，影响全球数亿用户。

WinRAR 是一款流行的 Windows 文件压缩应用，全球用户达5亿。Check Point 公司的网络安全研究员已发布了该漏洞的技术详情，它影响在过去19年来发布的所有版本。

该漏洞存在于一款老旧的第三方库 UNACEV2.DLL 处理以 ACE 数据压缩文档格式压缩的文件的提取方式中。然而，由于 WinRAR 是通过文件内容而非扩展检测该格式，因此攻击者只需将 .ace 扩展更改为 .rar 扩展就能蒙混过关。

研究人员指出，他们在这个库中发现了一个“绝对路径遍历”bug，可被用于通过使用易受攻击的软件来企图解压恶意构造文件文档的目标系统上执行任意代码。

这个路径遍历漏洞使得攻击者能够将压缩文件提取到受攻击者控制而非用户控制的文件夹中，导致攻击者有机会能够将恶意代码释放到 Windows Startup 文件夹中，从而在下一次重启时自动运行。

研究人员在视频演示中表示，攻击者只需说服用户打开恶意构造的 WinRAR 压缩文档，就能完全控制目标计算机。

由于 WinRAR 团队在2005年就已丢失 UNACEV2.dll 库的源代码，因此当时就决定抛弃 UNACEV2.dll 以修复问题，并发布不支持 ACE 格式的 WINRar 版本5.70 beta 1。

建议 Windows 用户尽快安装最新版本的 WinRAR，并请勿打开源自未知来源的文件。
