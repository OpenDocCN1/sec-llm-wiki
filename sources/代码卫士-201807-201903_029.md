# 打开这个链接，你的 Facebook 账户就被黑了

> **研****究员Samm0uda在**** F****acebook ****端点**** facebook.com/comet/dialog\_DONOTUSE/ ****中发现了一个严重的跨站点请求伪造**** (CSRF) ****漏洞，只需诱骗目标用户点击某链接就可利用该漏洞劫持账户。他因此获得****2.5****万美元的奖励。**

这名白帽黑客指出，可利用该漏洞绕过 CSRF 防护措施并通过诱骗用户访问恶意 URL 的方式以用户的身份执行操作。

Samm0uda 已发布了示例 URL，它们可被用于在用户的时间轴上发布内容、删除用户资料图片、甚至是删除用户账户。他指出，可通过使用更改用户 Facebook 账户中的用户邮件地址或电话号码的请求来控制账户。如果攻击者能将自己的邮件地址或电话号码添加至某账户，他们就能通过密码重置功能设置一个新密码并锁定合法用户。

利用该漏洞劫持账户并不如访问两个单独的 URL 那样直接。在这两个 URL 中，其中一个用于新增新的邮件地址或电话号码，另外一个用于确认动作。

然而，Samm0uda 仍然找到通过以受害者身份授权恶意 app 并获取它们的访问令牌的方式执行利用。这种攻击包含多个步骤，但 Samm0dua 表示这个利用将在“眨眼之间”得到执行。

Samm0uda 表示，他在1月26日将研究成果告知 Facebook，后者于1月31日发布补丁。Facebook 颁发出2.5万美元的奖金。

9月份，Facebook 宣布漏洞奖励计划涵盖涉及暴露访问令牌的漏洞。11月，Facebook 公司表示，如果研究人员如果能找到无需用户交互的账户接管利用，则可获得4万美元的奖励，而如果所发现的利用仅需最少的用户交互，则可获得最多2.5万美元的奖励。这也就解释了 Samm0uda 为何获得2.5万美元的奖励。

12月，Facebook 表示去年共颁发了110万美元的奖励金，而自2011年起共颁发出750万美元的奖励。

Samm0uda 在博客中说明了大量 Facebook 和Instagram 漏洞，包括他在去年发现的很多信息暴露问题等。
