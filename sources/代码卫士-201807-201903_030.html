Offensive Security 发布 Kali Linux 2019.1，堪称在2019年为网络安全专业人员准备的瑞士军刀第一版。

最新的Kali Linux操作系统包括版本 4.19.13 及之前的内核以及针对很多 bug 的补丁，以及很多更新后的软件，如 Metasploit、theHarvester、DBeaver等。

Kali Linux 2019.1 配有最新版本的 Metasploit （版本5.0）渗透测试工具，“包括数据库和自动化 API、新的逃避功能以及整个可用性改进”，使其成为渗透测试人员的更高效平台。

Metasploit 版本5.0 是该软件继2011年发布版本4.0后的首个重要发布。

说到 ARM 图像，Kali Linux 2019.1 目前再次增加了对内核版本4.19 上 Banana Pi和 Banana Pro 的支持。

Kali Linux 项目维护人员在官方发布公告中指出，“Veyron 已迁移至4.19的内核，而 Raspberry Pi图像已得到简化，因此可以更加容易地知道使用哪个。因为现在在所有的 TFT LCD 上都包含了 re4son 的kalipi-tft-config 脚本，因此不再为用户提供单独的 Raspberry Pi图像，因此如果你想要设置 TFT板，运行‘kalipi-tft-config’并按照提示进行即可。”

Offensive Security 虚拟机和 ARM 图像已更新至最新的 2019.1 版本。

用户可直接从官方网站上或 Torrent 网络下载新的 Kali Linux ISO，如果用户已在使用，则可通过运行命令：apt update&&apt-y full-upgrade将其升级至最新版本。
