# 俄罗斯拟通过立法隔离本国互联网

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247489203&idx=3&sn=8f66cde7326cae7330860ff9cae4fbed&chksm=ea9727d9dde0aecfd2458054732b80c12303ba1d754373064d7284135df4ed67025dd78518ef&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247489203&idx=3&sn=8f66cde7326cae7330860ff9cae4fbed&chksm=ea9727d9dde0aecfd2458054732b80c12303ba1d754373064d7284135df4ed67025dd78518ef&scene=27#wechat_redirect)

> **周二，俄罗斯立法机构通过一项法案，旨在将俄罗斯的互联网流量与外国服务器割断。批评人士认为这项举措意在开展网络审查以及建立类似朝鲜的隔离网络。**

该法案在下议院国家杜马引发异常激烈的辩论之后，以334票对47票通过一读，少数党的立法人员批评拟议法律含糊不清且成本太高。

该提案的作者表示，美国总统唐纳德·特朗普去年发布新的美国网络安全战略称俄罗斯发动网络攻击而不受惩罚后，俄罗斯必须确保网络安全。

该法案旨在建立“防御机制，确保俄罗斯互联网络的长期稳定运行”，如果美国在网络空间采取行动造成威胁。

该法案提议建立一个“确保和控制互联网流量路由”的中心，并要求互联网服务提供商 (ISP) 部署“抵御威胁的技术措施”。

同时，该法案要求定期进行演习”，以测试俄罗斯的互联网能够在隔离模式下运行。

互联网自由活动人士表示，该法案是俄罗斯继控制全球社交网络平台和阻止 Telegram 通讯服务之后的又一次网络审查行动。

尽管该法案声称是为了解决外部威胁，但反对互联网监管的组织 Roskomsvoboda 的负责人 Artyom Kozlyuk认为，它可能是又一部“允许在俄罗斯限制互联网权利和自由的”法律。他认为法案中提到的措施每年造成的公共和私人成本可能超过1000亿卢布（15亿美元）。

Kozlyuk 表示，“实际上，它将产生严重的经济影响……一切将变得更慢更贵。”

一些批评人士认为，“朝鲜的经验表明，建立完全自主的互联网是可能的。”

**互联网版的“英国脱欧”**

![](../Images/0ff79fdcd1a55ba2c60ea9bfad9caa9e.png)

该法案的作者无法预估长期成本，无法说明它所抵御的威胁甚至无法解释它如何运作。他们表示将会在二读时在法案中融入专家意见。  

提案的这种含糊不清激起某些少数党派立法人员的愤怒。

左翼正义俄罗斯党成员 Valery Gartung 表示，“在座的各位有多少人是 IT 专家？请举手。一个人？那么我们如何能够为自己不懂的法案进行投票？”

其他人预测将引发功能失调的“互联网英国脱欧”，或想知道俄罗斯将如何建立支持法律规定所需的技术基础设施。

民族主义 LDPR 的参议员 Sergei Ivanov 大声说道，“除了电缆之外，俄罗斯不生产任何 IT 硬件，也许某些人应当自缢。”

该法案的其中一名作者驳斥了这一批评，并提到了华盛顿的威胁。Andrei Lugovoi 是在2006年在伦敦谋杀克里姆林宫评论家 Alexander Litvinenko 的主要嫌疑人之一，他指出，“这不是幼儿园！叙利亚的所有网站都被美国关闭。”他指出，互联网的“根服务器”位于“美国五角大楼、美国国家航空航天局、阿姆斯特丹”，而俄罗斯当局甚至不知道俄罗斯境内的流量是如何路由的。

合著俄罗斯互联网监管历史一书的作者 Andrei Soldatov 表示，法案如获通过，该法案将可能使俄罗斯从全球 web 中隔离，或者在发生动乱或压迫的情况下，在偏远地区触发互联网停电。

他指出，“问题非常严重”，并表示法案似乎得到官方支持，“因此它成为正式法律的几率非常高”。
