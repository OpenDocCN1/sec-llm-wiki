# 为防严重漏洞遭滥用，苹果禁用FaceTime 群聊功能

> **昨天，苹果被曝严重的**** iOS ****漏洞，可导致**** FaceTime ****用户访问被呼叫者的麦克风和前置摄像头，即使被呼叫者并未接听也不例外。**

具体而言，只要拨打 FaceTime 电话，任何人均可在接听人接听或拒绝前将自己添加为额外的 FaceTime 群聊参与者，从而导致接听人打开麦克风，监听拨打人。更糟糕的是，如果接听人按下电源键将收到的 FaceTime 通话请求设为静音，它将启用前置摄像头，导致拨打者看到接听人的情况。

不难想象，这个严重的 bug 可导致很令人担心的后果，比如监听监视等。该漏洞影响 iOS 12.1 及以上系统。

苹果系统状态页面显示，苹果已经在昨晚 (10:16) 禁用了FaceTime 群聊功能。由于该 bug 依靠的是 FaceTime 群聊功能，因此禁用的原因很可能是为了阻止该 bug 遭滥用。

虽然禁用FaceTime 群聊功能可能会让使用 FaceTime 更安全，但苹果并未公开宣布这么做的原因。因此，建议所有的 iOS 和 macOS 用户在苹果推出正式补丁之前禁用 FaceTime。
