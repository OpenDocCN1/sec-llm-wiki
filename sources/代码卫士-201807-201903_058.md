# 思科 RV320/RV325 路由器遭攻击

> **思科小企业路由器**** RV320 ****和**** RV325 ****中被曝漏洞且**** PoC ****已发布，导致攻击者能够扫描易受攻击的设备并完全控制它们。**

上周，思科为路由器型号 RV320 和 RV325 发布更新，修复了一个命令注入漏洞 (CVE-2019-1652) 和一个信息泄漏漏洞 (CVE-2019-1653)，这两个漏洞均位于路由器的 web 管理接口中。

利用第一个漏洞要求获取认证以及管理员权限，导致远程攻击者在系统上执行任意命令。第二个漏洞也可遭远程利用，不过无需认证即可从路由器中窃取敏感信息。

**利用代码已发布**

![](../Images/2b99af2d7c9f21da6782d255fadf6185.png)

黑客利用这两个 bug 能够攻击暴露在网上的  RV320 和 RV325以获取权限账户的哈希访问凭证从而以根权限运行任意命令。  

德国公司 RedTeam Pentesting 在思科 RV320 中发现了这些问题，并私下告知思科。研究人员还发现 RV320 还暴露诊断信息。尽管研究人员的研究工作仅针对思科 RV320，但它表示 RV325 也易受该漏洞的攻击。

当思科发布安全公告和固件更新修复时，RedTeam Pentesting 公司还为信息泄漏、信息泄漏和数据泄漏问题发布 PoC 利用代码。这些利用代码也存在于 GitHub 上，是研究员 David Davidson 在思科 RV320 上测试代码后发布的。

**数千台主机遭暴露且易受攻击**

![](../Images/2b99af2d7c9f21da6782d255fadf6185.png)

Shodan 搜索结果显示互联网上暴露了约2万台思科 RV320/RV325 路由器，尽管如此，但并非所有路由器均易遭攻击。  

Bad Packets 公司的首席研究官 Troy Mursch 表示，其中9500多台路由器易受信息暴露漏洞影响，它们多数位于美国。

![](../Images/b2436757a74fd4d751ba94f4a73b4db4.png)

他发现黑客快速利用这些漏洞并开始寻找这些路由器型号。自上周五开始，美国的一个 IP 地址就已出现这种迹象。
