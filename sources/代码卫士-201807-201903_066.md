> **苹果为核心产品如**** iCloud****、****Safari****、****macOS Mojave****、****High Sierra****、****&Sierra****、****tvOS 12.1.2 ****和**** iOS 12.1.3****发布更新。**

这些安全更新包括为多个代码执行、权限提升和信息泄漏漏洞发布的修复方案。因此，如果你是这些产品的用户，应当尽快更新。

**iOS 12.1.3 修复 FaceTime RCE**

![](../Images/66912a77377d9c5f3c859f89ef7f978c.png)

iOS 12.1.3 修复了多个权限提升、远程代码执行和沙箱逃逸漏洞。除此之外，还有一些值得注意的漏洞。

首先，CVE-2019-6200 是一个蓝牙攻击漏洞，可导致攻击者实施远程代码执行。CVE-2019-6224 是由谷歌 Project Zero 团队的研究员 Natalie Silvanovich 发现的，可导致远程攻击者初始化 FaceTime 通话并引发任意代码执行问题。

CVE-2019-6206 允许密码被手动清除后自动填充。另外，还有其它多个漏洞允许仅通过访问恶意站点的方式就执行远程代码。

**macOS Mojave 10.14.3 修复 Intel 图形 RCE**

![](../Images/66912a77377d9c5f3c859f89ef7f978c.png)

尽管 macOS 中的很多漏洞和 iOS 一样，但 macOS 操作系统也有一些独有的漏洞。

VMware 公司的研究人员发现了一个监管漏洞 (CVE-2018-4467)，可允许攻击者提升权限。而 CVE-2018-4452 允许通过 Intel 图形驱动执行远程代码。

CVE-2019-6220 是存在于图像和动画处理 API QuartzCore 中的漏洞，可允许攻击者读取受限内存。

尽管 iOS 和 macOS 是这次更新的重头戏，但 tvOS、watchOS、Safari和 iCloud 也发布了更新。因此如果你是这些产品的用户，那么要记得检查苹果发布的安全更新完整列表。
