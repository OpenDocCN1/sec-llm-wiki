波兰 CERT （计算机应急响应小组）认为，对当前威胁的分析是任何组织机构在处理网络安全问题时都需要面临的共同挑战。随着犯罪分子实施的攻击活动规模越来越大且技术越来越先进，分析也变得越发艰难。因此，研究人员之间有效地进行信息交流就显得越发重要。

MWDB 系统（“恶意软件数据库”）是存储恶意软件样本和在分析该样本过程中所获信息的库。最简单的一个例子就是和已知恶意软件家族相关的特定样本或它所使用的 C&C 服务器的地址。

MWDB 系统概述

用户登录 MWDB 系统后，可看到以时间倒序排列的恶意软件样本。当然它仅适用于具体人员所能看到的样本（所上传或衍生的对象）。每个对象都拥有波兰 CERT 在分类过程中所使用的类别标签（比如，分配给恶意软件家族、具体钓鱼攻击活动的标签）。

和样本相关的信息

MWDB 系统中含有和样本相关的基本信息，如单独的加密哈希、文件类型和文件大小。

相关样本之间的关系以树的方式进行跟踪，以便检查从释放到最后攻击阶段的路径。

MWDB 系统中存储的关联也适用于静态和动态配置。这里解释的“静态”组件应该是可直接从所给样本中提取的详细信息（如此前提到的 C&C 服务器地址或所使用的加密密钥）。而“动态”组件是未直接包含在样本但是从样本中检索出的所有信息，如连接远程服务器之后检索出的信息。

样本及其配置信息通常受自动化分析系统的支持，其中一种是去年提到的 mtracker。

高级功能

所有可通过图形用户接口执行的操作均可通过使用 API 执行。同时 MWDB 系统也提供了 mwdblib 库支持分析师使用 Python 脚本语言，从而简化了和 MWDB 系统的交互。

如果用户具有访问大量样本的权限，那么 WMDB 系统同时也提供高级搜索功能。用户可以查询类似的文件名称、类似大小的样本以及配置中的具体值。

访问条件

第三方对系统的访问权限取决于如下规则：

  • 用户具有访问自己添加至 MWDB 系统中样本的权限；

  • 用户添加样本后，可获取在自动化分析和手动分析过程中的样本信息（但只有精选出的样本才能获得手动分析）；

  • 外部实体可访问位于 MWDB 中的共享样本。

MWDB 系统是为恶意软件研究人员设计的。能够说明所属单位的人员，如CERT 员工、从事网络安全的公司员工或开展恶意软件学术研究的人员可申请账户。

如感兴趣，请发送邮件至 inifo@cert.pl，波兰 CERT 将保留仅对获批准申请的权利。因此，请认真检查申请的可信性如何（如使用商务邮件，提供姓名和职位等）。

总结

波兰 CERT 认为和其它受信任方进行信息交流是更好地理解当前威胁的互利行为。波兰 CERT 期望能够和从事专业恶意软件分析的人员进行合作并共享 MWDB 系统中的信息。
