当2015年微软启用 Windows 10 时，因强制推送升级遭被多名消费者起诉。如今因未经明确同意强制安装 Windows 10，仍然不得不处理相关的法律问题。

这次，类似的案例发生在芬兰。一名芬兰消费者起诉微软强制其从 Windows 8.1 升级至 Windows 10 且导致电脑崩溃，要求赔偿损失3000欧元。而芬兰消费者纠纷小组认为微软未经授权升级至 Windows 10，要求赔付该消费者1100欧元。

这名消费者表示，计算机在升级过程中显示出错信息以及从微软支持工程师获取支持的信息，但结果并无不同。

芬兰消费者纠纷小组认为微软为在2016年强制安装 Windows 10 造成的损失负责，必须赔偿消费者因此而购买零部件的成本以及差旅费。

Windows 10 升级滑铁卢

2018年10月，微软向用户推出拙劣的 Windows 10 更新后受到了严厉批评。微软承诺将对 Windows 10 问题做到更加透明化，并将在今年晚些时候推出漏洞处理平台。最近，微软开始测试 Windows 10 家庭版和专业版中的一个新功能，可允许用户在7天时间内直接从“设置”页面暂停升级系统。
