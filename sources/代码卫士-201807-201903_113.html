法国初创企业Aleph Networks提供“暗网谷歌”服务

多年来，秘密崛起的犯罪网站已超越传统搜索引擎的范围，不过法国工程师团队找到了导航这种暗网的方式，而他们并不希望这个导航工具落入不法之徒的手中。

AlephNetworks 公司的联合创始人兼首席执行官 Nicolas Hernandez 在位于法国博若莱葡萄酒之乡里昂附近的公司办事处表示，“我们坚持这种说‘不’的能力。”

他表示，Aleph 已经拒绝了30%到40%的“暗网谷歌”许可请求，根据是公司道德委员会的审议和政府客户的意见。

多数 web 用户从未越过可通过普通 web 搜索服务进行查找和访问网站的边界。但寻求匿名的人员和网站能够通过轻易可获得的软件如 Tor 或 I2P 获得。这些网站无法通过搜索找到，相反，用户必须输入通常是由随机字符组成的确切的 URL 字符串。

在专制政权中，抗议运动可在不必担心被发现的情况下，通过这种秘密通道组织活动或和外部世界连接。

但暗网也是毒品和武器销售、人口走私和恐怖分子加密聊天通信的理想之地。Aleph公司的联合创始人 Celine Haeri 用自己的软件搜索奥地利手枪制造商格洛克公司时，发现立即出现了几个提供秘密的枪支销售网站。搜索制造“杀伤力巨大的”核弹的反射型元素“铯-137”时，显示出87个暗网网站，而另外一个网页则解释了如何制造爆炸物或自制火箭筒。

Hernandez 表示，“有些人甚至会利用客户满意度打广告。”

未知之地

五年来，Aleph 公司已经索引了14万个暗网站点上的140亿个连接以及4.5亿份文档。截止到2018年12月份，其软件已发现390万个被盗信用卡号。

Hernandez 表示，“如果没有搜索引擎，你无法全面了解”所有隐秘站点。

他和一名儿时好友一起利用自己的黑客技术为言论自由的倡导者或反虐童人员服务，平时任职 IT 工程师。

Haeri 当时是一名教师，她的同事当时请求他们帮忙合并博客，反对政府改革教育制度。这一事件成为他们收集海量数据和索引软件的基础。三人于2012年创建了 Aleph 公司。

他们最开始筹集了20万欧元（22.8万美元），但在法国军方武器和技术采购机构中找到敏锐的客户之前，已经破产多次。

Hernandez 表示，“他们要求我们在查理周刊遇袭事件发生后两天进行一个演示。”据悉，2015年查理周刊遇袭事件造成12名人员遭屠杀。

Haeri 认为，如果不了解暗网这块领土，就无法掌控它。

道德风险

暗中浏览暗网网站是安全服务的圣杯，它旨在打击非法贩运行为并阻止恐怖袭击。

美国国防部高级研究计划局 (DARPA) 多年来一直致力于设立类似项目 Memex。

Aleph 计划将很快在软件中增加人工智能功能，使得软件能够识别诸如卡拉什尼科夫步枪或虐童受害者的图像，或提醒企业注意潜在的版权侵犯行为。

Aleph 公司2018年的收入预计达到66万欧元，2019年将有望翻番。

随着 Aleph 加大力度在其政府客户名单中增加更多的私营部门买家，越来越多的投资者予以关注。

但随着更多人和企业开始使用 Aleph 的搜索引擎，犯罪组织机构或敌对政府最终也将获得访问权限，而随之带来的风险也会增加。在推出解决棘手的道德问题的明确指南的同时，这种挑战将会增加。

不过 Hernandez 坚称会保持警惕，将自己比作古希腊民主国家“城市保护者”。
