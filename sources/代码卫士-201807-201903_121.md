> **发现并提交微软**** Edge ****浏览器的内存损坏**** bug ****的研究人员已公布利用代码。该代码可被用于在未修复机器上执行远程代码。**

这个漏洞影响 Chakra，即驱动 Edge 浏览器的 JavaScript 引擎，可导致攻击者以登录用户的权限在机器上执行任意代码。

漏洞研究员 Bruno Keith 报告了该漏洞，微软认为在多数受影响的操作系统上都会产生严重影响。唯一产生“中等”严重程度影响的是 Windows 服务器2019和2016 版本。

该利用代码共70行，可导致带外 (OBB) 内存读取泄漏问题；虽然这种影响看似没那么严重，但可导致攻击者通过修改演示利用代码的方式造成更严重的后果。

演示代码中的一行注释指出，“Chakra 未能插入补偿值，因此导致 headSegmentsym 而非 headSegmentLength sym 重新加载，因此我们访问了长度错误的新缓冲区。”

**未修复系统有风险**

![](../Images/ec9d55244a2848be9e6445234bb2fd0c.png)

攻击者让利用代码起作用的场景有很多，因为它可导致攻击者完全控制安装的程序，查看、更改或删除数据，或者以管理员权限创建新的用户账户。  

微软在本月的安全公告中指出，“在基于 web 的攻击场景中，攻击者能够托管一个特别构造的旨在通过 Edge 浏览器利用漏洞的网站，之后说服用户查看该网站。”

攻击者还可使用其它方式感染用户计算机，如在用户可能访问的位置如网站或广告放置利用代码，而这也能造成同样的后果。
