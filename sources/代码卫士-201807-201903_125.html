2019年，我们面临的最大安全挑战会是它吗？

 聚焦源代码安全，网罗国内外最新资讯！

作者：Lindsey O'Donnell


2018年充斥着各种网络安全事件，而现在信息安全圈子已经开始预测2019年的挑战了。从新型网络威胁、APT 新组织的涌现，到更多的数据隐私法规出现，2019年注定是网络安全空间的又一个不平凡年份。我们来看下媒体 Threatpost 发布了哪些2019年最值得关注的网络安全趋势。

更多的 Spectre 类缺陷

两个基于硬件的侧信道缺陷 Spectre 和 Meltdown 就像是为2018年准备的两颗重磅炸弹。这两个缺陷影响过去十年计算机和移动设备使用的大量微处理器，包括运行安卓、Chrome、iOS、Linux、macOS 和 Windows 系统的设备。同时，这两个漏洞的新变体不断涌现。安全专家预测，Spectre 变体将在2019年继续出现。

Enveil 公司的首席执行官 Ellison Anne Williams 通过邮件表示，“2018年出现的芯片缺陷可能是我们迄今为止见过的影响面最广的内存攻击面漏洞案例，但它绝对不是最后一个。”

复杂的物联网攻击

物联网市场将暴增，但很多设备在构建时考虑的安全因素很少，或者是根本没有考虑。自2016年 Mirai 僵尸网络出现之后，研究人员已看到物联网设备被恶意用于多种威胁，包括密币挖掘、勒索软件和移动恶意软件攻击中。而在2019年这种情况将进一步恶化。

正如 Armis 公司的产品副总裁 Joe Lea 所述，“2019年，物联网威胁将继续复杂化，从僵尸网络和勒索软件感染转向 APT 组织监控、数据渗透和在真实世界实施直接操控破坏操作。”

勒索软件将返场

提到网络威胁，信息安全圈子预测密币挖掘将退出，而勒索软件将返场。很多网络犯罪分子发现密币挖掘的利润并没有预期高。事实证明，只有当攻击者影响的设备达到数万或数十万台设备时才能获利。然而，勒索软件仍然充满诱惑。

Recorded Future 公司的自身技术架构师 Allan Liska 指出，“比如，SamSam 通过勒索软件攻击已获利至少600万美元，它将开放的 RDP 服务器当作进入方法。我们已经看到勒索软件变体复制这种模式，预计将看到更多的勒索软件家族继续在这种攻击方法上进行拓展。”

运营技术和 IT 融合

随着工业环境对远程监控的利用不断增长，运营技术 (OT) 和 IT 正在融合，而关键系统越来越容易受网络攻击的影响。

Lea 指出，“随着IT基础设施和运营技术环境的融合，运营技术安全受到的关注将增多。智能联网设备将成为处理数字化和物理操作关系的制造工厂、公用设施和其它具有关键基础实施领域的标准。这会加大远程攻击的可能性，从而破坏或损坏机器人、传感器和其它推动我们日常生活的机器和基础设施的设备。”

漏洞修复速度将加快

漏洞修复一直是2018年的关注点，围绕漏洞披露进程的说法也从披露到打补丁的90天期限开始发生变化。

Semmle 公司的联合创始人兼平台工程副总裁 Pavel Avgustinov 表示，“不管是通过漏洞奖励计划、变体分析还是渗透测试，供应商对漏洞发现不断重视，预计从漏洞发现到修复之后到漏洞披露之间的平均时间，将从90天缩减到30天或更短。”

不安全的生物特征识别

生物特征识别是2018年银行和其它机构使用的认证前沿技术。然而，2019年，我们会看到和生物特征识别系统数据相关的更多安全事件。

卡巴斯基的研究员 Yury Namestnikov和 Dmitry Bestuzhev 指出，“已发生多起严重的生物特征识别数据泄漏事件。”

供应链攻击

Zscaler 公司的 Deepen Desai 在博客文章中指出，2019年“我们将看到网络犯罪分子继续攻击关键的软件供应链基础设施，实施更大规模的攻击。”

攻击者已经开始认识到供应链攻击的威力。一切始于2017年6月发生的 NotPetya 攻击活动。该活动快速从全球数千台计算机中擦除数据。2018年发生的供应链攻击数量大幅增加，波及的公司包括达美航空和百思买。

隐私立法

随着以 Facebook 公司和剑桥分析公司事件丑闻为代表的多起巨头公司数据隐私丑闻在2018年集中爆发，安全研究人员认为2019年在数据隐私将得到更多的立法和法规努力。

Claroty 公司的威胁研究副总裁 Dave Weinstein 表示，“安全和隐私在国会上创造了奇怪的同伴，它将左翼进步者与自由主义保守派联合起来。立法者可能会模拟《通用数据保护条例 (GDPR)》来致敬欧盟。不过，可能是由硅谷而非华盛顿来撰写隐私法规，因为他们期待这一天已经很久了。”

GDPR 的影响

虽然欧盟是在2018年颁布了《通用数据保护条例》，但安全专家认为2019年才会真正开始显现该法规在数据隐私和透明度方面的不可预测的影响。

Looker 公司的首席数据布道者 Daniel Mintz 指出，“2019年，我们将会看到企业会加大人力、工具和培训投入以应对数据问题，因此他们将在合规 GDPR 的前提下利用自己宝贵的数据。”

Apache Struts 缺陷

研究人员在2018年发现了两个严重的 Apache Struts 漏洞后，他们认为将会发生源自这些漏洞的重大数据泄漏事件。Equifax 数据泄漏事件的核心就在于 Apache Struts 软件。

Liska 表示，“Apache Struts 代表了一种独特的挑战，因为它出现在如此之多的面向互联网的其它程序中，也就是说虽然传统的漏洞扫描器可能无法检测出 Apache Struts，但扫描这些漏洞的僵尸网络将会找到它。”
