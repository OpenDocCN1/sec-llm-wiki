# 别等了，Facebook 不管这个点击劫持漏洞了

> **安全研究员在**** Facebook****遭垃圾邮件活动后发现了罪魁祸首并根据**** Facebook ****公司设立的漏洞奖励计划提交了报告。但**** Facebook ****表示因为它并未改变账户的状态，因此拒绝修复。**

研究人员发布 PoC，演示了 app 开发人员可以很容易地在 Facebook 上传播任意链接。

**垃圾邮件活动引注意**

研究员发现自己的很多好友都发布了一个网站链接，而且还附有有趣的图片之后决定分析该垃圾邮件活动。在找到让人发笑的内容之前，用户必须声明自己至少已满16岁。

研究员在博客文章指出，“点击按钮后，你就被重定向到带有有趣图片（以及很多广告的）页面。然而同时你刚点击的这个链接会出现在 Facebook 墙上。”

源代码页中的 iFrame 标记引起了他的怀疑，他发现这个 iFrame 包含多个链接以及一个分享 Facebook 内容的 URL。

垃圾邮件发送人员使用的这种方法针对的是法国的手机用户，而获得分享对话按钮访问权限的发送者能够在未经受害者同意的情况下在受害者的时间轴部分发布链接。

似乎是 Facebook app 中的安卓 web 浏览器忽视了 X-Frame-Options 响应头，这个响应头的作用是告知浏览器是否能够在 iFrame 中加载网页。在桌面浏览器中，这个头按预期做出响应并拒绝加载 iFrame。

这种攻击即点击劫持，涉及将网页加载到诱骗网站不可见 iFrame 中。所有用户看到的是诱骗，但交互是和不可见层上的对象进行的。

**Facebook ****拒绝修复**

这名安全研究员从 Facebook 提供的文档中发现，一个名为“mobile\_iframe”的特殊参数被启用时会打开“网站上iframe 中的分享对话”。该功能仅可在手机版使用。

该研究员指出，Facebook 快速对报告作出回应但表示它并非安全问题，因为它并未影响账户的完整性（即更改设置），因此并未解决该问题。

不管怎样，在未经授权的情况下将链接传播到其它用户的时间轴上这件事是一个严重问题，它可被用于传播恶意软件链接，而不止是垃圾信息。

研究员指出，“想想恶意软件文档或钓鱼网站链接会给拥有数千名粉丝的名人带来多大的危害。”
