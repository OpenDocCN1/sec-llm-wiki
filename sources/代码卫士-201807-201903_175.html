思科修复 Prime 许可证管理器中的 SQL 注入缺陷

思科已经修复了思科 Prime 许可证管理器 web 框架代码中的一个漏洞，它可导致攻击者执行任意 SQL 查询。

这个安全缺陷可遭未经认证的远程利用，是因为缺乏对用户在 SQL 查询中用户输入内容的正确验证导致的。攻击者可向受影响应用程序发送包含恶意 SQL 语句的构造的 HTTP POST 请求。

思科在安全公告中指出，“漏洞遭成功利用后可导致攻击者修改并删除 PLM 数据库中的任意数据，或者以 postgres 用户权限获取 shell 访问权限。”

漏洞是由沙特信息技术公司的研究员 Suhail Alaskar 从 Prime 许可证管理器版本 11.0.1 及后续版本中发现的，影响独立 (standalone) 版本和驻立 (coresident) 版本（即 Prime 许可证管理器作为 Unified 通信管理器和Unity 连接的一部分进行安装）。

思科表示，目前尚不存在任何缓解措施，不过已发布解决该问题的新版本，且已发布补丁ciscocm.CSCvk30822_v1.0.k3.cop.sgn。

公司解释称，“同样的 COP 文件也可和思科 Prime 许可证管理器独立版本使用，以及作为思科 Unified 通信管理器和思科 Unity连接的驻存版本使用，以及和所有受影响版本使用。”

补丁仅可安装在 Prime 许可证管理器、Unified 通信管理器以及 Unity 连接 11.5(1) 上。之前版本需要在安装补丁前更新至 11.5 (1)。可从 Cisco.com 网站的软件中心下载新版本。

思科表示，产品安全事件响应团队 (PSIRT) 并未发现漏洞已遭利用，也未发现“关于利用该漏洞的公开内容”。思科表示，思科 Unified 通信管理器和思科 Unity 连接版本 12.0 及后续版本经证实称并未受影响，原因是这些版本中不再包含 Prime 许可证管理器。
