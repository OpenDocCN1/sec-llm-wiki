# 这些漏洞同时影响戴尔 EMC 和 VMware 产品

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247488605&idx=2&sn=ecb49e84ac4c43e9e731102ebedeb870&chksm=ea972537dde0ac213d9ecf5141788138dc024e0007a6c012377dcf85f92088ab56c92d4809fc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247488605&idx=2&sn=ecb49e84ac4c43e9e731102ebedeb870&chksm=ea972537dde0ac213d9ecf5141788138dc024e0007a6c012377dcf85f92088ab56c92d4809fc&scene=27#wechat_redirect)

> **研究人员在戴尔**** EMC Avamar ****和数据保护集成工具**** (IDPA) ****产品中发现了多个漏洞。****VMware ****公司基于**** Avamar ****的**** vSphere ****数据保护产品也受影响。**

本周，戴尔 EMC 通知用户称 Avamar Server 和 IDPA 产品受远程代码执行漏洞和开放重定向漏洞的影响。

第一个漏洞 CVE-2018-11066 被评为“严重”漏洞，导致未认证攻击者在服务器上远程执行任意命令。第二个漏洞 CVE-2018-11067 被评为“中危”漏洞，可遭未认证攻击者用于将用户重定向至任意 URL，方法是诱骗受害者点击一个特殊构造的链接。另外，戴尔还通知用户称注意一个影响这些产品的高危的信息泄露漏洞 (CVE-2018-11076)。

戴尔公司表示，“Avamar Java 管理控制台的 SSL/TLS 私钥可能在 Avamar Java 管理客户端包中被泄露。该私钥可能会遭位于同一个数据层的未认证用户用于针对管理控制台用户发动中间人攻击。”

Avamar 和 IDPA 也遭可被用于以根权限执行任意命令的漏洞影响 (CVE-2018-11077)。然而，该缺陷的严重程度较低，因为攻击者需获得管理员权限。

所有的这些缺陷都是由澳大利亚网络安全公司 TSS 提交给戴尔 EMC 的。

VMware 公司还发布一份安全公告，其 vSphere 数据保护 (VDP) 产品基于 Avamar 虚拟版本。这些漏洞影响 VDP 6.0.x 和 6.1.x 版本。

VMware 和戴尔 EMC 均已为这些漏洞发布补丁。

这并非 VMware 和戴尔 EMC 首次发布关于相同漏洞的安全公告。1月份，两家公司就都发布关于同样的三个严重漏洞的安全公告。这些漏洞影响 EMC 的 Avamar Server、NetWorker 虚拟版本、IDPA 和 VMware 公司的 VDP 产品。
