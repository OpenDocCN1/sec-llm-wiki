你也在用 AMP 插件吗？快修复这个严重漏洞

一名研究人员在一款非常热门且应用广泛的 WordPress 插件“AMP for WP—加速的移动页面”中发现了一个严重的漏洞，可导致低权限攻击者将恶意代码注入目标网站的 AMP 页面中。

该插件允许网站自动为博客帖子和其它网页生成有效的加速移动页面。AMP 即“加速的移动页面”，它是由谷歌创建的开源技术，可允许网站向移动访客构建并提供更快速的网页。

在数百款能使 WordPress 网站创建 AMP 页面的插件中，”AMP for WP”最热门，其下载次数已超过10万次。因易受攻击，受影响的插件最近已从 WordPress 插件库中删除，但其开发人员或 WordPress 团队均未明确说明插件中存在的确切问题。

网络安全公司 WebARX 的研究员 Luka Sikic 分析了易受攻击的插件版本后在“AMP for WP”中发现了一个代码注入漏洞，该漏洞已在后续版本中修复。它存在于“AMP for WP—加速移动页面”插件处理用户账户和 WordPress AJAX 钩子的权限方式中。

Sikic表示，“AMP 插件漏洞位于 ampforwp_save_steps_data 中，它用于在安装程序中保存设置。它已被注册为 wp_ajax_ampforwp_save_installer ajax 钩子。该插件漏洞对于允许用户注册的网站而言是个严重的漏洞。”

在设置中，该插件为网站管理员提供在 AMP 页面头部或底部增加广告和自定义 HTML/JavaScript 代码的选项。为此，插件在后台使用了 WordPress 的内置 /AJAX 钩子功能。

由于 WordPress 站点上的每个注册用户即使是权限最低也被授权调用 AJAX 钩子，而且由于易受攻击的插件并不会检查调用 AJAX 钩子的账户是否为管理员，因此站点的任何用户都可使用该功能注入自定义代码。

研究人员在视频中展示了低权限用户如何仅通过篡改请求调用 AJAX 钩子就能在网站上提交恶意 JavaScript 代码。该代码已在插件的最新版本 0.9.97.20 中修复。研究人员指出，新版本会检查 wpnonce 的值并查看已登录用户是否可以管理选项。

如果你的 WordPress 网站也使用了受影响插件，那么强烈建议尽快安装最新的安全更新。

上周，WordPress 的另外一款插件 WooCommerce 被曝允许恶意的或受攻陷的权限用户获取的 WordPress 网站的完全控制权限。
