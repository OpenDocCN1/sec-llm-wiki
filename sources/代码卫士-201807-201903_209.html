微软和 Adobe 发布了11月的“补丁星期二”，发给用户一大包需要尽快安装的修复方案。

微软：BitLocker 和 TFTP 问题

11月，微软为62个 CVE 漏洞发布了修复方案，它们和工作站以及 Windows 的多个服务器版本以及 Office、Edge 和 IE 浏览器相关。

其中8个漏洞和 Edge 浏览器中的 Chakra 脚本引擎相关。每个漏洞都是远程代码执行漏洞，如遭恶意网页利用，则可导致攻击者运行恶意软件并以已登录用户的权限在遭渗透的机器上执行动作。所有的漏洞都被列为“严重”级别。

这8个漏洞的编号是 CVE-2018-8541、CVE-2018-8542、CVE-2018-8543、CVE-2018-8551、CVE-2018-8555、CVE-2018-8556、CVE-2018-8557 和CVE-2018-8588。

另外，TFTP（TrivialFile Transfer Protocol，简单文件传输协议）中也存在一个远程代码执行漏洞 (CVE-2018-8476)。安全公司 Qualys 的产品管理主管 Jimmy Graham 表示，远程安装并管理网络中 Windows 产品的管理员需要密切关注该修复方案。他解释称，微软的 WDS (Windows Deployment Services) 使用 TFTP 支持经由 PXE 引导的图像部署。如果你在环境中使用了 WDS，那么就需要优先考虑 CVE-2018-8476 的补丁。

微软修复的其它远程代码漏洞还包括微软图形组件 (CVE-2018-8553)、Dynamics 365 (CVE-2018-8609) 和 Windows VBScript 引擎 (CVE-2018-8584) 中的漏洞。

管理员同时需要确保已修复如下遭公开披露的漏洞：CVE-2018-8584（Windows ALPC 中存在的权限提升缺陷）、CVE-2018-8566（BitLocker 中存在的加密绕过）和CVE-2018-8589（已遭利用的Win32k 权限提升漏洞）。

另外，微软还修复了 Word 中的两个远程代码执行漏洞（CVE-2018-8539 和CVE-2018-8573）、Dynamics 365 中存在的四个跨站点脚本缺陷（CVE-2018-8605、CVE-2018-8606、CVE-2018-8607 和 CVE-2018-8608）、Skype 企业版中的一个拒绝服务漏洞 (CVE-2018-8546) 以及可导致远程代码执行的两个 PowerShell 漏洞（CVE-2018-8256和CVE-2018-8415）。

Adobe 发布三个安全更新

Adobe 为三款最流行的产品发布了修复方案。

Flash Player发布更新，解决带外读取漏洞 CVE-2018-15978，该漏洞可导致攻击者读取敏感数据。

Acrobat andReader 发布更新解决信息泄露漏洞 CVE-2018-15978。该欧东可导致攻击者绕过 NTLM 单点登录密码哈希。该漏洞的 PoC 已发布，不过尚未发现遭利用的迹象。

最后，Photoshop CC 发布更新，解决带外读取漏洞 CVE-2018-15980，它可导致信息遭泄露。
