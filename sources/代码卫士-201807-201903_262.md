# 报告：微软等三巨头成前三大被钓鱼目标

> **邮件安全提供商**** Vade Secure ****追踪了北美地区****25****个最常遭钓鱼的品牌，并发布****2018****年第三季度报告，结果显示，微软、****PayPal ****和**** Netflix ****是前三大目标品牌。**

报告共追踪了86个品牌，它们构成了该公司所检测到的95%的攻击目标。Vade Secure 公司表示，总体而言，第三季度的钓鱼攻击数量增长了20.4%，其中备受钓鱼攻击者青睐的依次是微软、PayPal、Netflix、美洲银行和 Wells Fargo。

基于云的服务和金融企业仍然是遭受攻击最多的两个行业，微软成为“众矢之的”的原因是攻击者尝试获得对 Office 365、One Drive 和 Azure 凭证的访问权限，进而发动更多的攻击。

Office 365 钓鱼邮件一般会指出收件人的账户被暂停使用或禁用，然后督促收件人登录以解决该问题。这些钓鱼形式和合法 Office 365 的格式几乎如出一辙，而且通过营造紧迫感，攻击者希望受害者会失去警惕从而输入凭证。

相比之下，PayPal 钓鱼攻击的目的是骗取受害者钱财，而 Netflix 是为了窃取信用卡信息。

有意思的是，攻击者在某几天内会集中发送钓鱼邮件。报告指出，多数和工作相关的攻击在工作日内发生且周二和周四发送的邮件数量最多。而 Netflix 遭受攻击最多的时间是周日，也就是但人们休息看电视的时候。

**钓鱼攻击的针对性增强**

![](../Images/d8d104293f08a477b8991270a2b8d062.png)

Vade Secure 公司还注意到，攻击者在攻击中减少对某个 URL 的使用次数。他们在每次钓鱼攻击活动中都使用唯一的 URL 一边绕过邮件过滤器。  

报告指出，“安全专业人员应该注意的是，钓鱼攻击变得越来越具有针对性。当我们把钓鱼 URL 的数量和钓鱼邮件的数量关联起来时，发现每个URL 所发送的邮件数量在第三季度下降超过64%。这表明黑客在邮件中对每个 URL 的使用在减少，目的是避开基于声望的安全防御措施。实际上在我们见到的复杂的钓鱼攻击中，每封邮件中都包含唯一的 URL，这么做主要是为了绕过传统的邮件安全工具。”

**如何免遭钓鱼攻击**

![](../Images/d8d104293f08a477b8991270a2b8d062.png)

随着钓鱼攻击变得越来越复杂，它们变得越发难以检测。攻击者现在使用云服务确保钓鱼表单得到著名且受信任公司如微软和 Cloudflare 公司的 SSL 证书的保护，从而导致这些钓鱼表单看起来像真的一样。  

如下钓鱼攻击所示，登录页面看似合法，网站托管在微软所属域名上，而且页面受到安全保护。很多人以为它是一个合法的微软表单。实际上，攻击者将恶意表单托管在微软云服务商，为了就是营造合法感觉。

![](../Images/578b91c8d5e0229bff7ad3109807bd1a.png)

  

因此，在输入任何登录凭证前，非常有必要审查站点。如果 URL 看起来奇怪，比如拼写不正确、语法不正确或者有些东西感觉不对劲，那么就不应当输入任何账户凭证。如果感觉自己的账户有问题，那么应该联系管理员或公司。
