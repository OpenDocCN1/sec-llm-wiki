# LIVE555 流媒体库中被曝严重漏洞 VLC 等媒体播放器受影响

> **安全研究员在**** LIVE555 ****流媒体库中发现了一个严重的代码执行漏洞。该流媒体库被多款流行的媒体播放器所使用，如**** VLC ****和**** MPlayer****，以及很多有能力提供流媒体服务的嵌入式设备。**

由 LiveNetworks 开发并维护的 LIVE555 流媒体是由企业和应用开发人员通过公开的标准协议如 RTP/RTSP 或 SIP 发布多媒体的一系列 C++ 库。LIVE555 流媒体库支持对多种视频格式如 MPEG、H.265、H.264、H.263+、VP8、DV 和 JPEG 视频的流、接收和处理服务以及支持多种音频编码译码器如 MPEG、AAC、AMR、AC-3 和 Vorbis。

该易受攻击的库由很多著名的媒体软件如 VLC 和MPlayer 使用，导致数百万用户易受网络攻击。这个代码执行漏洞 (CVE-2018-4013) 由思科 Talos 情报团队研究员 Lilith Wyatt发现，它存在于 LIVE555 RTSP 的 HTTP 数据包解析功能（解析经由 HTTP 挖掘 RTSP 的 HTTP 头）。思科在安全公告中指出，“特殊构造的数据包可引发栈缓冲溢出问题，从而导致代码执行。攻击者可发送数据包触发该漏洞。”

攻击者利用该漏洞所需要做的是创建并将“包含多个‘Accept:’或‘x-sessioncookie’字符串的数据包”发送给易受攻击的应用程序，从而触发‘lookForHeader’功能中的栈缓冲溢出，导致任意代码执行。

思科 Talos 团队已在 Live Networks LIVE555 媒体服务器版本 0.92 中证实了该漏洞的存在，但该团队认为这个安全问题可能还存在该产品的早期版本中。思科团队已在10月10日将漏洞告知 Live Networks 公司，后者在10月17日发布安全补丁。思科团队在10月18日公开披露了该问题。
