Chrome 等所有主流浏览器计划于2020年禁用 TLS 1.0 和 1.1

昨天，所有主流 web 浏览器，包括谷歌 Chrome、苹果 Safari、微软 Edge、IE和 Mozilla 火狐浏览器均宣布不久之后将停止支持 TLS 1.0（已存在20年之久）和 TLS 1.1（已存在12年之久）通信加密协议。

TLS 最初作为 SSL 协议开发，它是用于在客户端和服务器之间设立安全且加密渠道的更新版密码协议。目前 TLS 协议共有四个版本：TLS 1.0、1.1、1.2 和最新版1.3，但老旧版本 TLS 1.0 和1.1 易受多种严重攻击的影响如 POODLE 和 BEAST。

由于所有主流 web 浏览器和应用程序中的 TLS 实现支持降级的谈判进程，因此攻击者有机会能够在服务器支持最新版本的情况下利用更弱的协议。

将在2020年取消对 TLS 1.0 和 TLS 1.1 的支持

谷歌、微软、苹果和 Mozilla 公司发布新闻稿称，web 浏览器将在2020年前半年默认完全取消对 TLS 1.0 和 1.1 的支持。10年前发布的 TLS 1.2自发布之日起就得到广泛使用，它将在 TLS 1.3 开发完成之前成为 TLS 默认版本。

微软指出，很多网站已经逐渐摒弃 TLS 1.0 迁移到 TLS 新版本。目前94%的网站已经支持 TLS 1.2，而只有不到1%的 Edge 浏览器日常连接使用的是 TLS 1.0 或1.1。

苹果也表示 TLS 1.2 是其平台的标准，代表 Safari 浏览器99.5%的连接，而 TLS 1.0 和 1.1 占比不到0.36%。谷歌表示 Chrome HTTPS 连接使用 TLS 1.0 或1.1 的比例只有0.5%。

所有技术公司都建议不支持 TLS 1.2 或更新版本的网站尽快升级。另外，PCI 数据安全标准合规也要求网站在2018年6月30日禁用 SSL/TLS 1.0 实现。

除了这些技术巨头外，Gitlab 也宣布在2018年年底在网站和 API 基础设施上减少对 TLS 1.0 和 TLS1.1 的支持。

用户可在 Chrome 浏览器中手动禁用老旧 TLS 版本（打开设置——高级设置——打开代理设置——点击“高级”标签在“安全”选项下取消对 TLS 1.0 和1.1 的勾选并保存）。
