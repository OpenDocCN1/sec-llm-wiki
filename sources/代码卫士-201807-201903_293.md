# MuddyWater 组织扩大攻击范围

> **卡巴斯基实验室发布报告称，****MuddyWater ****网络间谍组织被指利用鱼叉式钓鱼邮件攻击位于多个国家的实体。**

MuddyWater 组织首次在2017年被检测到，它的目标主要是位于伊朗和沙特阿拉伯的政府目标。该组织的归属问题似乎较难，而且今年又出现了很多和该组织相关的新攻击。最近，该组织被指攻击约旦、土耳其、阿塞拜疆和巴基斯坦的政府机构、军事实体、电信机构和教育机构。其它受害者也位于马里、奥地利、俄罗斯、伊朗和巴林，而最初在伊朗和沙特阿拉伯发现的攻击活动仍在继续。

这些攻击使用新的鱼叉式钓鱼文档并依靠社工诱骗用户启用恶意宏。恶意文档中使用密码保护以阻止分析，当被启用时它执行经混淆的 VBA 代码。该宏 payload 用 Base64 编码，将三个文件释放到“ProgramData”文件夹中并在当前用户的 RUN 密钥（HKCU）中添加注册表项确保用户下次登录时执行。有时，宏不断释放恶意 payload/进程，而不会等待用户下一次登录。

这些攻击利用微软的合法可执行文件（均已白名单化），以确保 payload 的执行。宏释放 INF、SCT 以及文本文件或 VBS 和文本文件。在第一个场景下，INF 通过 advpack.dll “LaunchINFSection”函数启动以通过 scrobj.dll（微软 Scriptlet 库）注册 SCT 文件（脚本片段文件）。接着，JavaScript 或SCT 中的 VBScript 代码利用 WMI (winmgmt) 消耗文本文件的 PowerShell 单行指令。

在第二个场景下，VBS 文件自解码并调用 mshta.exe。被传递到 mshta 的VBScript 单行指令释放PowerShell 单行指令以耗尽该文本文件。

PowerShell 单行指令读取是放在 ProgramData 中的编码文本文件并将其解码为混淆代码。该代码禁用宏警告信息以及 Office 中的“受保护试图”功能以确保未来的攻击能够在无需用户交互的情况下实施。它还会检查硬编码列表中的运行进程并在发现匹配后重启机器。

为了和 C&C 服务器通信，该代码随机从列表中选择一个 URL。如果通信失败，那么它试图连接至另外一个从该列表中随机选择的 URL，然后睡眠0到30秒后再次循环。

机器一旦被感染，该代码试图获取受害者的公共 IP 并将它连同操作系统版本、内部 IP、机器名称、域名和用户名称发送至 C&C，从而过滤受害者。

从C&C 收到的命令来看，该代码能够截屏、检索通过 Excel、Outlook或 Explorer.exe 执行的 PowerShell 代码的另外一个阶段，从 C&C 下载文件并将其保持至“ProgramData”、毁坏磁盘C、D、E、F然后重启系统或者只是重启或关闭受害者的机器。

MuddyWater 组织的受害者多数位于约旦、土耳其、伊拉克、巴基斯坦、沙特阿拉伯、阿富汗和阿塞拜疆，但俄罗斯、伊朗、巴林、奥地利和马里也受影响。卡巴斯基实验室表示，这些攻击都受地域政治驱动，针对的是敏感人员和组织机构。

卡巴斯基实验室总结称，“MuddyWater 组织已实施大量攻击活动并展示出先进的社工技术，另外还主动扩大攻击、基础设施以及使用新方法和新技术。攻击者正在积极改进其工具包，以便将暴露于安全产品和服务的风险最低化。”
