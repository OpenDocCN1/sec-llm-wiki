Windows 0day 漏洞被用于攻击中东实体

微软在本周补丁星期二中修复了12个严重漏洞，其中一个 0day 漏洞已被某 APT 组织用于攻击中东实体。

这个 0day 的编号是 CVE-2018-8453，是一个权限提升漏洞，和 Windows Win32k 组件处理内存对象的方式相关，经认证的攻击者能够利用该漏洞控制受影响系统。

卡巴斯基实验室指出，CVE-2018-8453 已经被 FruityArmor 组织所利用。某恶意软件安装器执行该利用，获取持久访问目标系统的权限。FruityArmor 被指创建了高质量且可靠的利用，可在很多 Windows 版本上运行，包括 Windows 10 在内。

卡巴斯基实验室表示该漏洞是使用后释放问题，类似于微软在2017年5月修复的漏洞 CVE-2017-0263。后者曾被俄罗斯黑客组织 APT28 所利用。

黑客将 CVE-2018-8453 打包到一个恶意软件安装器，要求获得系统权限部署其 payload。该 payload 被描述为“攻击者用于持久访问受害者机器的复杂植入”。卡巴斯基发现该利用代码被用于攻击位于中东地区的多个目标。

卡巴斯基认为 FruityArmor 可能是这些攻击的幕后黑手，因为攻击中出现了只有该组织使用过的一个 PowerShell 后门。另外，最新攻击活动中使用的某些 C2 域名也出现在 FruityArmor 行动中。

周三早些时候，卡巴斯基发布一篇博客文章说明了该漏洞的技术细节以及如何遭 FruityArmor 利用。

这并非卡巴斯基首次发现遭 FruityArmor 使用的 0day 漏洞。该黑客组织还曾在2016年利用了一个 Windows 0day 漏洞。微软在2016年10月经卡巴斯基提醒后予以修复。当时，受害者是位于伊朗、泰国、阿尔及利亚、也门、沙特阿拉伯和瑞典的研究人员、活动家以及和政府相关的个人。

卡巴斯基表示，尽管 FruityArmor 的活动在最近两年缓慢增长，但针对性非常强的特征让它们隐藏在雷达之下。
