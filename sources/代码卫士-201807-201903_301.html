谷歌宣布称，由于 Google+ 中存在一个 API bug，导致50万用户账户的个人信息遭泄露，因此正在关闭该服务的消费者功能。

虽然并未有证据表明该 bug 遭滥用，但由于真正使用该服务的用户较少（90%的 Google+ 用户会话时长不超过5秒钟），消费者或开发者并未大范围使用 Google+，因此保护和运营这类社交网络属于出力不讨好。Google+ 的消费者功能将在十个月的时间内关闭，同时该产品主要供企业内部使用。

API bug 导致数据泄露

谷歌对 Google+ API 进行代码审计 (Project Strobe) 后，表示发现某个 bug可导致 Google+ 账户的个人信息遭泄露。该 bug 可允许用户所安装的 app 利用该 API 并访问属于该用户好友的非公开信息，包括账户持有人姓名、邮件地址、职业、性别和年龄。这种可访问的非公开信息并不包括发表或连接至 Google+ 或其它服务如 Google+ 帖子、信息、Google 账户数据、电话号码或 G Suite 内容。

谷歌表示在2018年3月发现并修复了这个 bug。公司认为该 bug 是因为API 和之后 Google+ 代码更改交互产生的结果。

由于谷歌仅保留 Google+ 为期两周的 API 日志，因此他们无法判断该 bug 是否遭滥用，只能确定在拥有日志数据的两周内未遭滥用。

在5月知晓但未披露

《华尔街日报》发布报告称，Google+ API 中的这个 bug 存在于2015年至2018年3月期间。谷歌内部委员会的一名成员决定不予披露该漏洞，即使他们并没有百分之百的把握确定该 bug 并未遭滥用。报告指出，查看了由谷歌的法律和政策部门员工准备的演示，其中显示如果披露该 bug，可能招致政府法规部门的严格审查，可能招致人们将其和Facebook 公司将用户数据泄露至剑桥分析公司的案例相提并论。

谷歌的一名发言人表示，公司的隐私和数据保护办公室认为由于并未达到审查门槛，因此认为没有必要披露该数据泄露事件。
