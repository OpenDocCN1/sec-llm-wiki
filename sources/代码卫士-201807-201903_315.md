# 美国参议院委员会通过多项网络安全法案

> **周三，美国国土安全和政府事务参议院委员会通过多项网络安全法案，包括和事件响应、供应链安全、政府网络人力和保护联邦信息系统安全的法案。**

其中由参议员 Maggie Hassan 和 Rob Portman 引入的一项法案是《2018年国土安全部网络事件响应团队法案》，它旨在通过要求国土安全部建立长期的事件响应团队以及被立法机构称作“网络猎手”的团队。

这些团队将有助于阻止针对联邦机构和私营公司的网络攻击，并有助于缓解攻击带来的影响。这项立法是在美国电力设施和其它关键基础设施公司遭到和俄罗斯相关的威胁组织之后提议的。

由国土安全众议院委员会主席共和党人Michael McCaul 推出的一套配套法案最近获得美国众议院的通过。

参议院委员会周三还通过了另外一项法案《2018年联邦网络人力轮岗计划法案》，旨在提议一项名为“联邦网络人力轮岗计划 (FRCWP)”的计划，为机构间临时借调员工提供政策和程序支持。

联合提出该计划的参议员 Hassan 表示，“我们的国家每天都面临着来自俄罗斯、中国、犯罪分子黑客和网络恐怖分子的越来越多的网络威胁，这些两党法案将有助于帮助增强联邦机构的网络防御能力，更好地保护美国人民。虽然我们还有很多工作需要做，但这些两党法案是增强精英网络防御队伍的重要步骤，我督促同僚尽快让这些措施落地。”

参议员 Hassan 支持的另外一项网络安全法案和联邦供应链有关。美国政府因担心遭俄罗斯监控而禁用卡巴斯基产品后，他联合推出了《2018年联邦采购供应链安全法案》。这项法案旨在创建联邦收购安全议会，为评估收购某项技术因供应链带来的国家安全和公众利益风险提供标准和进程。

另外，参议院委员会还通过了《2018年联邦信息安全保护法案》，使得联邦机构能够做出和保护 IT 以及信息系统方面的决策。该法案让机构主管限制或禁止对某个网站的访问权限，并部署或更新网络安全措施。

最后，国土安全和政府事务参议院委员会投票通过《推进网络安全诊断和缓解法案》，在国土安全部设立了一项持续的诊断和缓解计划。
