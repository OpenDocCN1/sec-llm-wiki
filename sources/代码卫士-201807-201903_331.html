微软 JET 数据库 0day 漏洞详情遭曝光

翻译：360代码卫士团队

趋势科技公司安全研究团队 ZDI 成员 Lucas Leong 在微软 Jet 数据库引擎中发现了一个 0day 漏洞，它影响所有受支持的 Windows 操作系统（包括服务器版本），可导致攻击者在任意易受攻击的 Windows 计算机上远程执行恶意代码。由于微软未能在120天的期限内将其修复，因此研究员披露漏洞详情。

微软 JET 数据库引擎，或称为“JET”（联合引擎技术），是整合至多款微软产品（包括微软 Access 和 Visual Basic）中的一种数据库引擎。

ZDI 在一份安全公告中指出，漏洞产生的原因是 Jet 数据库引擎指数的管理中出现问题。漏洞如遭成功利用，则可导致带外内存写入，从而引发远程代码执行问题。

攻击者要利用该漏洞，必须说服目标用户打开一个特殊构造的 JET 数据库格式中的文件，而该数据库格式用于多种应用程序中，攻击者之后就能在当前进程级别下载易受攻击的目标 Windows 计算机上远程执行恶意代码。

ZDI 团队的研究人员表示，这个漏洞存在于所有受支持的 Windows 版本中，包括 Windows 10、Windows 8.1、Windows 7 和 Windows Server Edition 2008 至2016。

ZDI 早在5月8日就将漏洞问题告知微软，后者在5月14日予以确认，但未能在120天的修复期限内将其修复，于是 ZDI 将其公开。另外，ZDI 已经在 GitHub 页面公布了 PoC 利用代码 (https://github.com/thezdi/PoC/tree/master/ZDI-18-1075)。

微软正在推出漏洞补丁，由于补丁并未包含在9月份的“补丁星期二”中，因此可能会在10月份发布。

趋势科技公司建议所有受影响用户“将应用程序的交互限制给受信任文件”，作为补丁推出前的缓解措施。
