# 新蛋网也未能逃脱 MageCart 魔掌 数量庞大的用户信用卡信息或被盗

> **导致英国航空公司和**** Feedify ****公司数据遭泄露的信用卡恶意盗取脚本****MageCart ****再次来袭，这次的目标是全球最大的在线技术零售商之一新蛋**** (Newegg) ****公司。**

RisqIQ 和Volexity 公司分别出具报告详细说明了被注入新蛋网站长达一个多月的时间且静默窃取消费者支付信息的 MageCart 脚本情况。

报告指出，8月13日，攻击者创建了一个域名 neweggstats.com。该域名是一个示范网站，用于收集窃取自新蛋站点的信用卡详情。Veloxity 进一步表示，8月16日，攻击在新蛋站点上启动。

Veloxity 在报告中指出，“Volexity 通过全球传感器网络，三天后即2018年8月16日证实了经由新蛋站点发动的攻击。从 Volexity 从传感器网络获取的数据来看，在15:45至20:20UTC 之间，代码被添加至某处。然而，攻击很可能发生在更早的时段，从Volexity 在这天早些时候审查了新蛋交易的多个网络到目前，并未显示返回 neweggstats.com 的连接。”

由于新蛋是最大的技术组件、计算机和硬件的网络零售商之一，因此受影响的受害者数量可能非常庞大。安全研究员在 RiskIQ 博客文章中指出，“2016年新蛋网的业务量达到26.5亿美元，它是一个极其热门的零售商。Alexa 指数显示新蛋网是美国第161位最热门的站点，而收集网站访问量的公司 Similarweb预计新蛋网每个月的访客量超过5000万人。在长达一个月的窃取活动中，我们可以假设攻击影响了大量受害者。”

**MageCart 如何窃取新蛋用户的信用卡信息**

![](../Images/02c2b56e67016a85d8346714151eb2d1.png)

当消费者在新蛋网购买商品时被要求输入购物信息，然后进入第二个阶段即填入支付信息。在这个第二阶段，新蛋会收集消费者的支付信息，这时，15行代码的 MageCart 脚本就被注入。

![](../Images/42599a07a6ece512d16491ec1be651c0.png)   

当页面加载时，脚本就会将自己绑定至用户输入信用卡详情后点击的那个按钮。按钮被点击后，该脚本就会提取表单内容，将其转换为 JSON 之后上传至网页 https://neweggstats.com/GlobalData/。

然而，这个 neweggstats.com 网站并非新蛋所有，而是由攻击者操纵的。这就导致攻击者能够在网站被黑的一个月内窃取新蛋消费者的信用卡详情。然而，对于用户而言，他们会持续购物，就像什么都没发生过一样。

**保护表单免受 MageCart 攻击**

![](../Images/02c2b56e67016a85d8346714151eb2d1.png)

随着对窃取信用卡详情的 MageCart 等脚本的使用越来越多，RiskIQ 公司的研究员 Yonathan Klijnsma 说明了电商网站运营人员如何能够更好地保护自己免受这类恶意脚本的侵扰。他表示，防护非常难做，主要是因为这些脚本见缝插针，会利用所有可利用的渠道发动攻击。不过他还是提出了一些配置支付表单和提交过程的方法，以期加大攻击难度。他指出，将表单和输入字段 names/ID 随机化。当处理付款流程时，通过服务器的会话信息将这些信息映射回来。

**新蛋告知用户相关攻击情况**

![](../Images/02c2b56e67016a85d8346714151eb2d1.png)

新蛋已开始向消费者发送道歉邮件并解释这次数据泄露事件的情况。从新蛋网首席执行官 Danny Lee 发送的邮件内容来看，公司将在周五在网站上发布相关的 FAQ 页面。目前新蛋网并未说明更多相关信息如有多少名消费者受影响。
