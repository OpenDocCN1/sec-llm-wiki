> **微软发布了关于某个**** DoS ****漏洞情况的安全公告，指出该漏洞可导致多个**** Windows ****版本完全不响应，且目前尚不存在缓解因素。**

该漏洞影响未在2018年9月“补丁星期二”中获得更新的 Windows 7 至Windows 10 （包括 8.1 RT），Server 2008、2012、2016 和 Core Installations 的所有版本。

该 bug 的编号是 CVE-2018-5391，被称为“FragmentSmack”，原因是它响应 IP 分片，即将数据包规模调整为适应接收端的最大传输单元 (MTU) 的过程。IP 分片攻击是一种已知的拒绝服务 (DoS) 形式，受害者计算机接受大小较小的多个 IP 数据包，这些数据包在目的地被重新组成其原始形式。

FragmentSmack 是一种 TCP 分片类型的攻击，也被称为 Teardrop 攻击，阻止在收件人端组成数据包。该漏洞老旧如 Windows 3.1 和 95，它能导致这两个版本的 OS 崩溃，不过也出现在新近的 Windows 7 版本中。

微软在安全公告中指出，“攻击者能发送很多带有随机起始偏移量的 8 字节大小的 IP 片段，但在重组 IP 片段时会保留最后一个片段并利用链接列表的最坏情况下的复杂性。”结果，机器的 CPU 达到最大利用率水平并导致操作系统无响应。一旦数据包的 salvo 停止，CPU 就会恢复到正常的使用状态而系统也恢复。

**Linux 已解决该问题**

![](../Images/50064bfbad1e9093afedadd9831825f4.png)

FragmentSmack 问题首先出现在 Linux 系统上，该系统上还出现了名为  SegmentSmack (CVE-2018-5390) 的漏洞，它影响运行在内核版本 3.9 及以上版本的设备。目前它已在主流发行版本上予以修复。

最先发现 FagmentedSmack 和 SegmentSmack 漏洞的是 Juha-Matti Tilli。Tilli 是诺基亚实验室的一名研究员，同时也是芬兰阿尔托大学通讯和网络系的研究员。
