# 利用这些 UMP 应用 恶意软件仍然能实现持久性

> **挪威的一名研究人员发现一种新方法，能让恶意软件在受感染系统重启后仍然实现持久性。**

在信息安全圈子，术语“持久性”指的是系统重启后恶意软件仍然能够卷土重来。恶意软件作者获得这种启动持久性的方式有很多，比如通过修改启动部分、劫持 Windows COM 系统或者劫持 DLL 和快捷方式文件。

但截至目前，最流行的方法仍然是使用 Windows 注册表增加注册表项，在启动时调用恶意软件的进程。

挪威的博客作者兼 Windows 安全专家 Oddvar Moe 最近发现了滥用 Windows 注册表诱骗 Windows 在系统重启后运行恶意软件进程的一种狡猾方式。

Moe 提出的这种新方法仅适用于 Windows 10，且仅适用于 Universal Windows 平台开发的 app。该平台是微软于2015年发布的新型 Windows 运行时系统。

Moe 表示虽然这种技术应该适用于任何 UWP 应用程序，但只有和在 Windows 10 自动启动后的 UWP 应用程序如 Cortana 和 People app 时才管用。

Moe 表示，“如果攻击者针对其它应用程序，那么用户需要手动运行这款 app 来运行植入的二进制。”

Moe 表示，该技术是指，感染系统后，恶意软件网络能够增加一个修改 UWP app 的启动设置的注册表项。当用户下次重启计算机时，这个新的注册表项将该 UWP app 设置为调试模式并选择运行另外一款 app。这款 app 是一款调试程序，能帮助用户或开发人员发现 UWP app哪些地方出错。但 Moe 表示，恶意软件作者能够将这个调试 app 修改为任意想要的东西，包括恶意软件的进程。

不过 Moe 的方法也存在一些好处。最大的好处是遭劫持的 Cortana 或 People app 并不会出现在 Windows 自动运行的 app 列表中，从而隐藏于可疑的系统管理员的视线之外。另外，这种技术并不要求管理员权限添加它所需要的注册表项。攻击者所需要做的就是感染用户，或者通过社工方式或者通过路过式下载方式实现。

Moe 表示，他将研究结果告知微软，但由于该技术依靠的是已经在系统上占有一席之地的恶意软件，因此他的报告并未被归为安全问题，因此也并未得到立即处理。

根据安全软件的复杂性和功能，一些反病毒系统可能利用这个技术检测恶意软件滥用该技术的情况。但如果反病毒软件并未发现在系统上运行的原始恶意软件或恶意代码并进行 Windows 注册表修改，则该反病毒软件存在问题。

Moe 表示，从 payload 来看，如果它并未被反病毒软件检测到，那么很可能它不会触发。Moe 指出他认为在他发布博客文章之前，这个注册位置并未被其他人所知。
