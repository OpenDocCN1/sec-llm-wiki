# 瑞士数据管理公司 Veeam 泄露4.45亿条客户记录

> **为虚拟、物理和云基础设施提供智能数据管理服务的瑞士公司**** Veeam****被曝数据泄露事件。其拥有超过****200GB ****数据的数据库被暴露在服务器上且易遭任何人公开查询。**

安全研究员 Bob Diachenko 于9月5日在亚马逊基础设施上发现了这批信息，不过数据在4天后消失，说明 Veeam 公司已注意到研究人员的提醒并采取措施加固其 MongoDB 服务器。

虽然数据记录暴露的时间仍不确定，但 Diachenko 表示，服务器的 IP 地址被 Shodan 在8月31日检索。数据库的信息包括客户的个人信息如姓氏和名字、邮件地址和居住国家。Diachenko 表示服务器上还包括其它营销类信息，如客户的类型、组织机构规模（企业、商业机构、中小企业）、IP 地址、引荐来源 URL 或用户代理。他通过查找详情判断出服务器的所有人，并发现所有的条目都是在4年前创建的。

Veeam 的客户约有30.7万人，其中包括挪威游轮公司、盖特威克机场、斯堪尼亚、医疗保健和教育机构（多所大学和学区）。

**配置不当的 MongoDB 本该更新**

![](../Images/42d5e84057e6f4edd7560278349a6b38.png)

MongoDB 最初仅允许本地网络访问。这些限制条件被打破后，管理员们继续依靠尚未准备好在线访问的默认设置。从版本 2.6.0 开始，MongoDB 不再允许网络连接，除非管理员明确这样配置。该配置曾在约五年前被实现在最流行的部署数据包 RPM 和 DEB 中。

自从第一起 MongoDB 配置不当实例被曝光后，网络犯罪分子就开始建立相关恶意业务。他们从网上搜索开放访问权限的服务器、可能导出内容并将其删除，之后留下勒索留言。其中最近发生的类似攻击活动是 Mongo Lock。幕后的攻击者已将恶意操作自动化。然而如报道所述，这些脚本并不可靠，有时候会创建勒索留言但数据是完整的。

Veeam 公司表示被泄信息是市场营销数据库的一部分，在短时间内被暴露给第三方。另外该公司表示非常重视数据隐私和安全，目前正在调查该事件。
