# 德国组建类似美国 DARPA 机构 加强网络安全研发能力

> **周三，德国国防部长和内政部长宣布称将在未来五年投入****2****亿欧元组建新的类似于美国**** DARPA****（国防部高级研究计划局）的网络安全研究机构。**

新建机构的目标是让德国在网络安全技术方面独立于其它国际势力。德国对其它国家如中国或美国的依赖性一直以来都是一个政治问题，因为德国所需的一切几乎都是从外国企业和合作伙伴购买的。

内政部长 Horst Seehofer 表示，“我们不能眼睁睁地看着高度安全的敏感信息技术被第三方国家控制。”Seehofer 和国防部长 Ursula von der Leyen 在周三于柏林举行的新闻发布会上介绍了这个将新成立的机构，“我们必须自己确保并发展这些关键技术的安全性。”

新设机构以旨在为美军创建新技术研发的美国 DARPA 为模型。DARPA 在2019年的预算为29.5亿欧元（折合34.4亿美元），是德国新建机构五年后得到的联邦资助的15倍。

德国新建的这个机构名称为“网络安全创新机构”，将在今年年底开始运行，员工为14名；全面运行时员工将增至100名。

德国国防部网站发表声明称，“因此，必须快速发现、引进并进一步开发最先进的技术。这个跨部门的网络机构是迈向这个方向的重要一步，它的目的是研究并推广明天的 IT 信息安全解决方案，比如基于量子力学的系统。这就提出了这样一个问题：从数字计算机转变到更加强大的量子计算机所面临的机遇和风险是什么，以及它对当前加密方法产生的影响是什么。”

另外，德国政府认为人工智能是有资格获得潜在资金和资源的另外一项技术。

不过德国媒体指出，在德国国内，这个新机构的设立迅速招致左翼党和绿党官员的批评，他们担心新机构开展的研究可能具有攻击性。
