# 注意！新型“转台”技术绕过所有 Windows 内核缓解措施

> **安全研究员发现了一种新型利用技术，可绕过**** Windows ****操作系统中的内核防护措施。**

enSilo 公司的两名安全研究员 Omri Misgav 和 UdiYavo 将这种技术称为“转台 (Turning Tables)”，它利用的是 Windows 的页面表。

页面表是常见于所有操作系统而非只有 Windows 操作系统的一种数据结构，用于存储虚拟内存和物理内存之间的映射。虚拟地址由操作系统进程执行的程序使用，而物理地址由硬件组件使用，更具体说是由 RAM 子系统使用。

由于物理内存 (RAM) 有限，操作系统创建了所谓的“攻陷代码页”，多种进程能存储相同代码并在需要时调用。

研究人员表示，“转台”技术依靠构造的恶意代码以一种负面的方式修改这些“共享代码页”以影响其它进程的执行，其中一些进程的权限更高。如此，“转台”技术能让攻击者将代码的权限提升至更高权限如系统权限。

![](../Images/8dffa8786eb759e5140121adc89fa6f0.png)

这两名研究人员表示，恶意人员还可利用这种“转台”技术修改运行在沙箱中的应用程序。例如，“转台”技术可用于投毒运行在沙箱中的浏览器如 Chrome。

**macOS、Linux 也受影响**

![](../Images/153d45d577e9ef46abeb4985b45114f2.png)

另外，由于苹果和 Linux 项目、macOS 和 Linux也在使用页面表概念，因此从理论上来讲，它们也易受“转台”技术的影响，尽管研究人员尚未验证这种攻击的情况。

研究人员表示，这种“转台”技术的最特别之处在于，它绕过微软在近年来增加至 Windows 操作系统中的所有内核级别的安全保护措施。

研究人员表示已将问题告知微软，但截止本文发布前，微软尚未就此事置评。他们在本月月初举办的 BSides 拉斯维加斯安全会议上发布了研究成果。
