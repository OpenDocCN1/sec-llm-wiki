学术界和私营行业的研究员公布了影响英特尔 CPU 的三个 Spectre级别的新型漏洞，它们利用的是 CPU 的“推断性执行”设计功能。

该功能存在于所有的现代 CPU 中，通过提前计算操作提高性能，之后丢弃不必要的数据。这些缺陷针对的是在推断执行过程中处理的存储在处理器 L1 缓存中的数据。L1 缓存是计算机中最快、最靠近处理器的内存，也由 CPU 内核共享。

L1TF 或 Foreshadow 漏洞

这三个漏洞被一般技术行业称为“L1终端故障（L1TF）”，不过最初被研究人员称为 “Foreshadow” 和 “Foreshadow-NG”。

这些漏洞如下：

  • Foreshadow：旨在提取存在于 L1 缓存中的英特尔 SGX 数据的原始攻击 (CVE-2018-3615)。

  • Foreshadow-NG：原始 Foreshadow 攻击的两个变种，它能从 CPU 的 L1 缓存中提取数据，包括系统管理模式的信息或操作系统内核 (CVE-2018-3620) 或运行在主机操作系统虚拟机器监控上的虚拟机数据 (CVE-2018-3646)。

漏洞的其它名称还包括：

  • L1 终端故障 – SGX，即 CVE-2018-3615，即Foreshadow

  • L1 终端故障 – OS/SMM，即 CVE-2018-3620，即Foreshadow-NG

  • L1 终端故障 – VMM，即 CVE-2018-3646，即 Foreshadow-NG

仅影响英特尔 CPU

L1TFF/Foreshadow缺陷的研究团队表示，只有英特尔 CPU 受影响。今年年初，研究人员曾联系英特尔公司，并和英特尔和操作系统厂商以及云托管服务商准备缓解措施和更新。

英特尔公司的一名发言人表示，“今年年初发布微码更新解决了L1终端故障，并发布关于操作系统和管理软件更新，目前已开始推出。我们已经在网站上提供了更多信息并继续鼓励所有人将系统更新至最新状态，以达到最佳保护状态。我们向imec-DistriNet、KU Leuven、以色列理工学院、密歇根大学、阿德莱德大学和 Data61 以及行业合作伙伴协助我们找到并解决这个问题表示感谢。”

研究团队、英特尔和红帽公司已在 YouTube 发布视频，解释 L1TF/Foreshadow 漏洞遭利用的原理。另外有视频也展示了研究团队使用 Foreshadow 攻击如何从安全的英特尔 SGX 封装中提取数据。

补丁已发布，性能不受影响

英特尔表示，应用英特尔为 CVE-2018-3615、CVE-2018-3620和 CVE-2018-3646 推出的微码更新和操作系统补丁应该能充分缓解 L1TF/Foreshadow 攻击。

英特尔公司还表示，和 Spectre 补丁对英特尔 CPU 性能产生重大影响的情况不同，未观测到L1TF 缓解措施产生重大的性能影响。

英特尔发布博客文章说明了 L1TF/Foreshadow 的情况，并发布 FAQ 页面和安全指南页面。英特尔公司还在官方安全公告中公布了受影响 CPU 列表。

微软、甲骨文和红帽公司也公布了关于 L1TF/Foreshadow 缺陷以及补丁信息的博客文章。Linux 内核的修复方案已发布且微软2018年8月补丁星期二也公布这些方案。三家主要的云计算提供商亚马逊 Web Services、谷歌Cloud 和微软 Azure 也发布了安全指南页面。

研究团队还专门推出网站，解释了 L1TF/Foreshadow 漏洞的影响。
