# CCleaner 被指实施主动监控并收集用户数据

> **系统优化和隐私保护工具**** CCleaner ****最新发布的版本**** 5.45 ****被指通过**** heartbeat****（匿名分析）功能，每隔****12****小时向**** Avast ****发送一次最新的使用数据情况。**

**隐私设置和主动监控问题**

![](../Images/ad4521328a2379976280dc03b8bb1a46.png)

Avast 声称 heartbeat 功能是为了更快地推出漏洞修复和产品改进方案，并表示所收集的数据是非个人且不可识别的。除了这个隐私问题外，最新的免费版本还取消了删除数据收集的隐私设置。

除此之外，CCleaner 默认启用两种监控功能，一种是系统监控功能，一种是主动监控功能。如果通过 CCleaner 节约的磁盘空间大小超过 0.5 GB，那么系统监控就会发出通知消息。主动监控功能是为了检查 CCleaner 的产品更新并在 CCleaner 推出新版本时发出提醒通知消息。这两种功能均可通过 CCleaner＞选项＞监控禁用。

但在 CCleaner 5.45 版本中，主动监控功能无法被禁用。禁用该功能后，它还会重新启用。要彻底禁用，用户要么杀死 CCleaner 进程，要么禁用应用程序启动项目，但后一种方法仅适用于部分用户。

**Avast 回应解决方案**

![](../Images/ad4521328a2379976280dc03b8bb1a46.png)

Avast 回应称已将 heartbeat 和主动监控功能结合在一起，尽管二者属于不同的功能，但都将按照同样的机制运行。Avast 目前正在分离二者并对高级监控功能进行重新命名。

Avast 表示，“收到反馈后，我们已经审查了这个功能是如何实现的，并也认为存在改进空间。我们目前正在 CCleaner 的界面着手分离主动监控和 heartbeat 功能，这样大家就能按照自己的需求分别配置这两个功能。我们也将借此机会对 CCleaner 的高级监控功能重新命名，从而让其功能更加清晰。”

用户如果对版本 5.45 的主动监控功能所烦恼，开发人员建议通过任务管理器关闭所有进程，不过这并非最理想的解决方案。

5月份，CCleaner 5.43 发布，取消免费版本中的数据分享禁用功能。6月份，CCleaner 5.44 发布，增加广告弹出功能。7月份，CCleaner 5.45 强制推出主动监控和 heartbeat 功能。
