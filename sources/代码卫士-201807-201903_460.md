# 大规模恶意广告活动每周实施感染4万次

> **网络安全公司**** Check Point ****发布报告说明了一次大规模的恶意广告活动。**

研究人员认为这次恶意广告活动的操纵人员已纳入广告网络和广告经销商，以确保被劫持的流量接触到首选的恶意人员，这些恶意人员随后将受害者重定向至技术支持骗局或利用工具包，通过勒索软件、银行木马等实施感染。

Check Point 将这次复杂的活动称为 “Master134”，是根据这起广告活动的整个操作计划中的中心和关键服务器的 URL 命名的。

**Master134 网络从被黑 WordPress 站点窃取流量**

![](../Images/4d56bc12cbe3ae50602f7729b2c77509.png)

报告指出，Master134 犯罪团伙首先接管 WordPress 站点。研究人员表示发现犯罪团队攻陷的 WordPress站点超过1万台。

Check Point 公司声称这些被黑的 WordPress 站点运行的是 WordPress CMS 版本 4.7.1，易受远程代码执行漏洞，可导致站点遭接管。

攻击者将代码插入这些站点中并将广告注入，随后劫持并将用户重定向至 Master134 “重定向”主服务。

另外，研究人员表示该犯罪团伙还利用 PUPs 如浏览器主页劫持器将用户重定向至 Master134 重定向门户。

**流量如何到达广告网络和经销商**

![](../Images/4d56bc12cbe3ae50602f7729b2c77509.png)

Master134 服务的作用是在 AdsTerra 广告网络上的“出版商”账户下的广告“广告位”。这个“出版商”账户供网站上有广告位的网站所有人访问。

报告指出，这些广告为随后被其中的四个广告经销商之一购买，如 AdKernel、AdventureFeeds、EvoLeads 和 ExoClick。

在“巧合”情况下，各种恶意软件将购买这些广告经销商出售的所有 Master134 的广告位并捕获将用于传播恶意软件的所有的遭劫持流量。

研究人员观测到，几乎所有的主要网络犯罪组织都是经由 “AdsTerra-经销商”系统从 Master134 购买流量。这些犯罪组织包括利用工具包运营商（RIG、Magnitude、GrandSoft、FakeFlash）、流量分发系统（Fobos、HookAds、Seamless、BowMan、TorchLie、BlackTDS、Slyip）和很多技术支持诈骗操纵人员。

![](../Images/edc30812d63c91c1fe7596fda3874e9b.png)

**几种可能的理论**

![](../Images/4d56bc12cbe3ae50602f7729b2c77509.png)

但 Check Point 公司的研究人员认为，所有的恶意人员都从 Master134 购买劫持流量并非仅仅是个巧合。

安全研究人员表示，“似乎从某种程度上来讲，多个恶意组织正在开展协作，而这种协作经由第三方广告网络（其中最大的是 AdsTerra）得到成功维护。”他们指出，“从研究成果来看，我们认为威胁组织直接向 Master134 付款。Master134 之后向广告网络公司付款以重新路由甚至是伪装流量的来源。”

研究人员指出，“在这种场景下，Master134 在网络犯罪黑市上发挥独特的作用；它通过和 AdsTerra 直接合作获取广告利润，并且成功地确保这种流量到达目标人群——在我们的案例中也可以说是恶意组织。”

Check Point 公司表示该恶意广告活动仍然在持续，每周针对受 Master134 攻陷的用户的感染尝试次数约为4万次。
