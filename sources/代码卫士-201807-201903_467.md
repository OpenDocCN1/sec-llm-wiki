# 泰坦安全密钥：谷歌推出硬件双因素认证保护机制

> **谷歌推出“泰坦安全密钥**** (Titan Security Keys)****”。它是一款微小的**** USB ****设备，类似于**** Yubico ****推出的**** YubiKey****，为用户的在线账户提供基于硬件的双因素认证保护机制，从而以最高级别的保护措施对抗钓鱼攻击。**

相比短信双因素认证保护而言，这些基于硬件的安全密钥能更有效地阻止钓鱼攻击、中间人攻击和其它账户接管攻击，因为即使用户凭证遭攻陷，没有这个密钥，也无法登录账户。

本周早些时候，谷歌披露称，其所有8.5万名员工一直在使用物理安全密钥，而且此后从未遭到钓鱼攻击。

和传统的验证协议（短信信息）相比，旨在简化、加快和加固双因素认证进程的通用第二因素认证 (U2F) 极其难以被攻陷。

物理安全密钥加固了对账户的验证安全，只需将 USB 密钥插入并按下按钮，用户就能快速安全地登录账户。

泰坦安全密钥基于 FIDO（快速网络身份）联盟、U2F（通用第二因素）协议基础之上，包含一个安全因素和由谷歌开发的固件，能在硬件级别验证安全密钥的完整性。

泰坦安全密钥目前向谷歌云消费者开放，不久任何人均可在 Google Store 上购买，它旨在经由 USB 和蓝牙验证登录。

基于蓝牙的无线密钥可连接至用户计算机和移动设备上。和其它 U2F 密钥一样，泰坦密钥也可用于很多在线服务如谷歌、Dropbox、Facebook 和 Github，并受所有主流浏览器的支持，包括 Chrome、火狐和 Opera 浏览器。

目前，谷歌并未对外宣布泰坦安全密钥的价格，不过据说为20美元或30美元左右。
