出于安全考虑，谷歌禁用三款 Linux web 浏览器登录其服务

出于安全考虑，谷歌目前禁止三款流行的 Linux 浏览器 Konqueror、Falkon和 Qutebrowser 登录谷歌服务。
前几天，一名用户发现该禁令并发布在 Reddit 论坛上，但目前尚不清楚谷歌是何时开始禁用这些浏览器的。
BleepingComputer 网站证实称无法通过 Konqueror 或 Falkon 在多台机器上登录谷歌服务：登录时被告知由于这两款浏览器不安全，因此要求尝试使用其它浏览器。完整信息如下：
您无法登录。
该浏览器或 app 可能不安全。了解更多。
尝试使用其它浏览器。如果您正在使用受支持的浏览器，则需要刷新屏幕并再次尝试登录。


信息中的“了解更多”连接会指向谷歌发布的一篇支持文章，说明谷歌可能会出于如下一种原因阻止用户登录：

  • 不支持JavaScript 或关闭 JavaScript。

  • 添加的扩展不安全或不受支持。

  • 使用自动测试框架。

  • 被嵌入另外一款应用程序。

更奇怪的是，某些用户报告称仍然可以通过 Falkon 登录服务。
这导致大家纷纷猜测原因，认为可能是谷歌在做 A/B 测试，可能和用户安装的 QtWebEngine 版本有关，或者只是和启用了 2FA 等账户设置有关。
目前谷歌尚未回应此事。
