My Digital Life 网络技术支持论坛社区发现了一种方法可以绕过微软限制，在所有系统上免费安装本来需要付费的 Windows 7 Extended Security Updates 服务。
微软官方宣布将在2020年1月14日终止对 Windows 7 的支持。Windows 7 Extended SecurityUpdates (ESU) 是微软推出的付费服务，将为仍然运行 Windows 7 系统的企业在2020年1月14日至2023年期间提供安全更新服务，不过售价不菲，大概每个工作站的成本是25美元至200美元之间，具体取决于企业所运行的 Windows 7 版本（企业版还是专业版）以及更新所需时间。
但并非所有人都可享受 ESU服务，只有具有批量许可协议的公司和中小企业才能注册 ESU 许可。

绕过工具

上个月，微软发布了测试版 Windows 7 ESU 更新 (KB4528069) 供管理员验证自己的系统和即将推出的 ESU 进程是否兼容。当用户安装该更新后还需要提供一个 ESU 许可密钥，从而为相应的系统授权未来的 ESU 更新。
和多年来模组制作者绕过 Windows OS 安装密钥检查的方法一样，My Digital Life 的一个社区创建了一款能够规避该 ESU 密钥检查运营并启用测试 ESU 安装的工具。
Deskmdoder 在上周末指出，微软很可能会为新的 BypassESU 工具更改账户检查。然而，还应该注意的是，微软过去从未成功地确保其 Windows 许可密钥系统的安全。坊间一直存在破解 Windows 许可密钥的方法，使得盗版 Windows 版本的安装大行其道。
