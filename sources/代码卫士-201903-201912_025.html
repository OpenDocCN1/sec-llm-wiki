废话不多说，三句足够：

（1）  黑客设法越权访问HackerOne 平台安全分析师账户，获2万美元

11月24日，一名昵称为 haxta40k 的黑客表示自己能访问 HackeOne 一名安全分析师的 HackerOne账户并因此获得2万美元的奖励金。这名分析师在尝试复现某漏洞和提交报告的黑客进行会话的过程中，不慎在发出的回复包含了自己的有效会话 cookie，其中包括可被复现的 HTTP 请求。在事件中，复制自浏览器面板的cURL 命令的一部分被泄露在回复邮件中从而导致和hackerone.com 应用程序相关联的会话 cookie 被泄露，而当会话 cookie 被在另外一个地址使用时该应用程序并不会被拦截，从而导致账户被访问。


（2）  FBI 悬赏500万美元捉拿Dridex 恶意软件主谋

美国司法部披露了开发和传播 Dridex 银行木马（也被称为 “Bugat” 和 “Cridex”）且借此在十年内牟利1亿美元的两名俄罗斯黑客的身份： “Evil Corp” 黑客组织的头目 Maksim Yakubets 及其同谋 Igor Turashev。司法部宣布如有人能够提供能够抓捕 Yakubet 的信息则可获得史上最高赏金500万美元。这两名黑客被指从2009年5月开始就利用 Zeus 银行恶意软件实施欺诈，并通过其它手段从美国及其它国家窃取金钱。


（3）  伊朗国家黑客 APT34 新出针对能源行业的数据清洗恶意软件 ZeroCleare

IBM公司的研究人员表示，伊朗国家黑客 APT 34（又称为 ITG13、Oilrig 和 Hive0081）和新出现的针对中东能源行业的数据清洗恶意软件 ZeroCleare 之间存在关联，而该恶意软件和臭名昭著的 Shamoon （曾在2012年被用于攻击沙特阿拉伯最大的石油制造商的3万台计算机）之间高度相似。ZeroCleare 使用合法的硬盘驱动 RawDisk by EIDos 覆写 MBR 和运行 Windows OS 计算机的硬盘分区，通过加载易受攻击但签名的甲骨文 VirtualBox 驱动设法运行 EIdoS。攻击者首先暴力破解网络账户密码之后安装 ASPX web shell，之后试图安装合法的远程访问软件 TeamViewer 并通过 Mimikatz 混淆版本窃取更多凭证。

详见：

https://securityintelligence.com/posts/new-destructive-wiper-zerocleare-targets-energy-sector-in-the-middle-east/


（4）  基于 Unix OS 的操作系统被曝漏洞，影响VPN连接

一篇学术论文称，Linux、安卓、macOS 和其它基于 Unix 的操作系统的网络堆栈中存在一个漏洞 (CVE-2019-14899)，可导致攻击者嗅探、劫持并篡改 VPN 隧道连接。攻击者能通过该漏洞探测设备并发现用户 VPN 连接状态的多种详情。多家 VPN 服务商表示该漏洞影响重大。

详见：

https://seclists.org/oss-sec/2019/q4/122


（5）  思科开源依赖关系自动化构建工具 Mussels

本周，思科 Talos 团队开源了一款利器 Mussels，让创建具有很长的依赖关系链的复杂应用程序变得更容易。Mussels 是一款跨平台的通用依赖关系构建自动化工具，可使软件开发员能轻松下载、构建并汇编 app 依赖关系。该工具的目的是让开发人员不必编写所有的新的 CMake、Meson、Bazel、XCode 或 Visual Studio 项目文件，而是可以编写并分享利用外部库依赖关系的作者推出的原始构建系统的“秘诀”。

工具地址：

https://github.com/Cisco-Talos/Mussels
