# 六年了，APT 29 像“幽灵”一样悄悄攻击政府组织机构

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247491281&idx=3&sn=a5b12ea5091bdf5388c29cecaa89f575&chksm=ea972fbbdde0a6adaaab4b269cbc77fc7ce28a6e66e127fea3f13993a9397e245be145a2ebd5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247491281&idx=3&sn=a5b12ea5091bdf5388c29cecaa89f575&chksm=ea972fbbdde0a6adaaab4b269cbc77fc7ce28a6e66e127fea3f13993a9397e245be145a2ebd5&scene=27#wechat_redirect)

![](../Images/01bb601c1da5fc72107b997999383920.png) 聚焦源代码安全，网罗国内外最新资讯！**编译：奇安信代码卫士团队****ESET ****公司安全研究员表示，俄罗斯国家黑客组织****APT 29 ****在过去三年来一直在悄悄地攻陷多个政府目标且成功规避检测。**APT 29 也被称为 Dukes、CozyDuke 和 Cozy Bear，它至少已活跃超过10年的时间，且被指曾在2016年攻击美国民主党的前管理机构民主国民委员会 (DNC)。他们也曾在2018年11月被指试图渗透 DNC 计算机，使用了曾被 CrowdStrike 和火眼认为属于 APT 29 的鱼叉式钓鱼信息。早在2016年美国总统大选之前，关于该组织的报告就数不胜数，而在2017年初期，它突然销声匿迹。ESET 表示，实际上 APT 29 还在继续实施至少始于2013年的一项影响至少三个欧洲国家外交部的行动。ESET 发布报告，详述了一次复杂的攻击活动“幽灵行动 (OperationGhost)”。这些攻击活动至少活跃于2013年，但鉴于通讯技术和工具改进的隐秘性，均未被检测到。黑客使用了新型恶意软件家族PolyglotDuke、FatDuke 和 LiteDuke，以及此前曾被发现的后门 MiniDuke。第一阶段的恶意软件使用了在线类服务如推特、Imgur 和 Reddit 作为命令和控制信道，而通过隐写术等技术使得黑客能够通过命令和控制服务器隐藏通信内容。攻击的受害者至少有三名，全部是欧洲外交部，包括驻某欧盟成员国的华盛顿特区大使馆。和该攻击活动存在关联的最近活动出现在2019年6月。研究人员指出，不仅是攻击目标符合 APT 29 的资料，所使用的技术和工具也吻合：社交网站用于托管 C&C，隐写术用于隐藏通信内容，而 WMI 用于实现持久性，而被攻陷的机器上也存在和该组织相关的其它恶意软件。虽然不能排除伪旗行动的可能性，但安全研究员认为该攻击活动实际上和 APT 29 发动的其它活动同时进行，尤其因为它是在该组织只有一小部分的武器库是已知的情况下发生的。该攻击活动仅使用了少量工具，而该复杂的恶意软件平台分为四个阶段：PolyglotDuke（使用在线服务作为 C&C）、RegDuke（恢复第一个阶段，使用 Dropbox 作为 C&C）、MiniDuke（第二阶段后门）以及 FatDuke（复杂的第三方阶段后门，包含无数函数和一个灵活的配置）。在调查活动中，研究人员还发现了此前未露面其显然是已退役的第三阶段后门。他们还注意到这些黑客避免在不同受害者之间使用同样的 C&C 网络基础设施。研究人员无法识别出这些攻击中的初始攻陷向量，但确实注意到两个受害者的系统在2015年遭到该组织的攻击，表明该组织在整个期间的确在维护访问权限。

**“幽灵行动”恶意软件**

![](../Images/ad578df9e2ff66d86fc1196bd84eee74.png)

感染进程始于PolyglotDuke。它是一款下载器，用于提取 MiniDuke 后门，而且和此前 APT29 攻击活动样本存在多个相似之处。RegDuke 是一款第一阶段植入，它由黑客在失去同样设备上其它植入的控制时使用。该恶意软件旨在尽可能隐藏尽可能长的时间，以确保攻击者永远不会失去对攻陷系统的访问权限。它包含一个加载器和旨在仅存在于内存中的后门 payload。RegDuke 能够提取不同的文件类型，包括 Windows 可执行文件、DLL 和 PowerShell 脚本。研究人员发现它释放 MiniDuke 后门以及合法的 Process Explorer 工具。MiniDuke 是一款第二阶段后门，和更早的版本之间展示出多个相似之处（最近的样本编译于2019年6月），使用纯粹的 x86 汇编写成的，尽管他的大小在混淆之后增长了不少。该后门具有38个不同的函数，而且能够上传或下载文件、创建进程、获取系统信息（hostname、ID、pipename、HTTP 方法）、获取本地驱动及其类型的列表（unk、nrt、rmv、fix、net、cdr、ram 和 und）、在同样的管道中读取和写入并开启且阻止代理功能。FatDuke 是 APT29当前的旗舰后门，它是部署在据称相关利益最高的设备上的第三阶段恶意软件。它主要通过 MiniDuke 传播，可能使用横向移动工具如 PsExec等释放。而持久性可能是通过更早期的后门实现的。黑客例行重新打包该后门以躲避检测，最近的样本是在2019年5月24日编译的。研究人员发现黑客在几天的时间里多次尝试重新获取对某台机器的控制并且注意到他们每次都使用不同的样本。FatDuke 具有硬编码配置，可通过自定义 C&C 协议经由 HTTP 或本地网络上的命名管道进行远程控制，具有高度混淆的二进制。LiteDuke 第三阶段后门用于2014年至2015年之间，它和“幽灵行动”之间并不直接关联，但研究人员在某些遭 MiniDuke 攻陷的设备上发现了它。该恶意软件使用 SQLite 存储信息，使用的释放器和 PolyglotDuke 相同，以及使用了相同的加密算法。研究人员指出，“因为我们未发现其它威胁行动者使用了相同的代码，因此我们坚信 LiteDuke 是 Dukes 武器库的一部分。”只有加载器被写入磁盘，而后门仅存在于内存中。该后门 DLL 导出7个函数：SendBin、LoadFromCC、SaveToCC、GetDBHandle、GetCCFieldSize、GetCCFieldLn和DllEntryPoint。CC 表示“加密容器”，它是存储在和加载器位于同样目录中的磁盘上的 SQLite 数据库。该数据库包含三个不同的表格和加密模块，作为后门的插件。这款恶意软件支持41种不同的命令，使其能够上传或下载文件、通过首先将随机数据（线性同余发生器）写入文件、上传数据库（配置、模块和对象）、创建进程、获取系统信息（CPUID、BIOS 版本、账户名称等）、自我终止等的方式删除文件。研究人员表示，“幽灵行动”表明Dukes 从未停止从事间谍活动。他们已从 2016年攻陷 DNC 事件中缓过劲，并重构了多数工具集。这一攻击活动同时说明 APT 威胁行动者多年消失不见并不代表着他们停止实施间谍行动。完整报告请见：https://www.welivesecurity.com/2019/10/17/operation-ghost-dukes-never-left/
