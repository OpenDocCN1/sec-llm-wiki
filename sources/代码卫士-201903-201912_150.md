# 两名大学生尝试获取特朗普报税资料未果，一人获刑两年被罚20万美元

**美国哈佛福德学院的两名大学生**** Andrew Harris ****和**** Justin Hiemstra ****因尝试越权获取美国总统唐纳德·特朗普的纳税申报资料未果而被判刑。****Harris ****被判两年且被罚****20****万美元。**

从公布的请求备忘录来看，两人尝试获取资料的过程如下：

2016年11月2日，AndrewHarris 和Justin Hiemstra 在所求学的哈佛福德学院 (Haverford College) 计算机实验室企图通过教育部学生援助免费申请 (FAFSA) 网站获取美国总统唐纳德·特朗普的纳税申报资料。Harris 自己刚刚完成申请，因此对网站比较熟悉。

一般而言，在开始申请FAFSA 时，个人需要在联邦学生援助办公室 (FSA Office) 网站上注册。注册后就可获得唯一的标识符“FSA-ID”，等同于用户名。激活 FSA-ID 后，用户即可在 FAFSA 网站上完成第一次 FAFSA 申请以及后续申请。

FAFSA 申请要求用户提供多种信息如金融和税务信息。当用户填到联邦税务信息部分时，会有两种选择：或者在无需国税局 (IRS)的帮助下自己填写联邦税务信息，或者激活 FAFSA 申请中的一个链接电子导入信息。当用户选择第二种方法激活链接时，FAFSA 部分就会暂停被重定向至 IRS FSA-ID 网站。进入该网站后，用户必须提供多种唯一信息如社保号码等，以此来证实所要求纳税申报信息的人就是本人。如果所提供的信息与预留的信息一致，那么 FSA-ID web 应用过就会获得完成 FAFSA 应用的所需税务信息。用户随后激活 FSA-ID 网站上的一个超链接来返回被暂停的 FAFSA 应用会话部分。FAFSA 会话回复后，所检索的税务信息就会被导入 FAFSA 应用表单的正确字段中，而用户也可完成余下的 FAFSA 申请。

备忘录指出，Harris和Hiemstra 在尝试获取特朗普的保税信息时，首先以特朗普家族一名成员的名义打开了虚假的 FAFSA 申请。他们发现有人已经获得了特朗普的 FSA-ID并设置了识别密码。为了重置识别密码，二人必须回答预留的问题。他们通过谷歌搜索获得了问题的答案并重置了密码。之后使用特朗普的个人识别符如社保号码和出生日期，他们尝试将特朗普的联邦报税信息导入虚假的 FAFSA 申请中，但未果。

美国教育部监控并记录了所有的FAFSA 申请活动。国税局监控并记录了所有获取 FSA-ID 系统中报税信息的尝试。这两个系统都将活动和申请所使用的 IP 地址以及尝试获取信息的 IP 地址进行关联。结果两人被发现使用两台电脑，一台用于谷歌搜索预留答案，一台用于 FAFSA 申请。两人通过电话向同学获得了登录这两台计算机的凭证。当时两人均为哈佛福德学院的学生。

最终Harris 被判入狱两年、一年监外看管、20万美元的罚款以及缴纳50美元的特殊评估费。

Harris 的律师 William J. Brennan 认为这两名大学生只是恶作剧而已。

多年来，特朗普一直拒绝公开自己的报税情况，在总统侯选人和当选总统之后都是如此。虽然历届政客都在对外公开自己的财务状况以接受监督，但特朗普的法律团队上周要求一名联邦法官驳回了众议院民主党要求特朗普提交资料的诉讼。
