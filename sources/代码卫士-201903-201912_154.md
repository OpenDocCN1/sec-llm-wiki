# Sophos 将开源隔离工具 Sandboxie

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247490862&idx=3&sn=7985bc2c8fbf7c5642682a125ea04248&chksm=ea972c44dde0a5527d99128f040fec7f3c55a3ef6b7e66e194286d7071c8602612f9573ec497&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247490862&idx=3&sn=7985bc2c8fbf7c5642682a125ea04248&chksm=ea972c44dde0a5527d99128f040fec7f3c55a3ef6b7e66e194286d7071c8602612f9573ec497&scene=27#wechat_redirect)

**上周，英国网络安全公司****Sophos ****公司取消了对**** Sandboxie ****的许可检查和激活要求，免费开放该隔离工具。**

Sandboxie 最初由 Ronen Tzur 开发而成，随后在2013年由终点保护公司 Invincea 收购。2017年2月，Sophos收购Invincea，Sandboxie成为产品组合的一部分。

Sophos 公司的业务主要是保护端点、网络、邮件和移动系统的安全以及提供统一的威胁管理服务，而从未将 Sandboxie 作为业务的重要组成部分来看。实际上，Sophos 公司有段时间一直在探索 Sandboxie 的未来，并表示完全终止 Sandboxie 的使用本来是最容易做出的且成本也最少的决策。“然而，我们因为太爱它的技术而舍不得让它消失。更重要的是，我们太爱 Sandboxie 社区了，舍不得这样草草结束。Sandboxie 的用户代表着安全社区某些最热情的、思想超前的、知识渊博的用户群体，我们不想让你们失望。”该公司解释称。

因此，Sophos公司决定通过开源Sandboxie 的方法将它交还给用户。不过，在开源过程完成之后，Sophos 才会将所有受限功能完全免费。

首个删除以上提及的受限功能的版本是 5.31.4，下载地址为：

https://www.sandboxie.com/

该工具和Windows 7、8.1和10 兼容，但不兼容 Windows XP。32位和64位均已发布。

Sophos 公司将在敲定所有细节后，发布关于 Sandboxie 开源项目的进展情况。
