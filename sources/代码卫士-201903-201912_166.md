# 信不信？一条短信就能窥探数十亿安卓用户的所有邮件

**注意！****一条钓鱼短信可轻易诱骗数十亿安卓用户更改设备的关键网络设置。**

在手机插入 SIM 卡并首次连接到蜂窝网络时，运营商就会自动配置或发送一条包含用于连接数据服务的网络设置信息。你注意过这些信息更专业点说是 OMA CP （开放移动联盟客户端配置）信息中包含的配置是什么吗？我敢打赌，多数用户从来不关心自己的移动互联网服务是否运行正常。

但是时候了解一下这些设置了。研究人员表示，安装不可信的设置可导致数据隐私遭风险，导致远程攻击者监控数据通信。

移动运营商发动包含 APN 设置的 OMACP 信息以及其它设备配置信息，以供手机建立运营商移动网络和公共互联网服务之间网关的连接。对于 APN 设置而言，配置包含配置可路由 web 流量的 HTTP 代理的可选字段，但很多运营商使用甚至不需要设置该字段的透明代理。除了代理设置外，OMA CP 配置信息还包含通过 OTA 方式更改如下设置的配置：

*   MMS 信息服务器
    
*   代理地址
    
*   浏览器主页和书签
    
*   邮件服务器
    
*   同步通讯录和日历的目录服务器等
    

Check Point 公司发布报告指出，包括三星、华为、LG和索尼在内的某些设备制造商实现的弱认证配置信息可导致远程攻击者诱骗用户通过由恶意攻击者控制的代理服务器更新设备设置。而这可导致攻击者轻易地拦截目标设备通过数据运营服务（如 web 浏览器和内置的邮件客户端）进行的某些网络连接。

研究人员指出，“一条短信就能完全控制对用户信息的访问权限。在这些攻击中。远程代理可诱骗用户接受新的手机设置如路由所有的互联网流量，通过由攻击者控制的代理窃取邮件。另外，连接到蜂窝互联网的任何人都可能成为这类钓鱼攻击的目标，也就是说用户不必连接到 WiFi网络，攻击者就能够恶意提取用户的邮件数据。”

然而，就像在设置 WiFi连接代理那样，移动数据网络的代理设置并非由目标设备安装的所有 app 使用。它取决于哪款 app 被设计于接受用户配置的代理。

另外，该代理服务器无法解密HTTPS 连接；因此该技术仅适用于拦截不安全的连接情况。

**最高级的邮件钓鱼攻击**

![](../Images/1aaf7fa458e09cb9e982b4b6876bdf8f.png)

Check Point 公司的一名安全研究员 Slava Makkaveev 指出，“这是全新的邮件钓鱼攻击类型。第一眼比较难以将该漏洞分类，因为这是一个深入的具体问题。它可能是我所见过的最高级的邮件钓鱼攻击。”

回到研究人员在配置信息验证过程中发现的弱点问题。行业标准推荐的让 OTA 配置更安全的规定并不强制运营商使用 USERPIN、NETWPIN或其它方法对 CP 信息进行适当的认证。因此信息接收人（目标用户）无法验证具有新设置的 OMA CP 信息源自网络运营商还是骗子，因此为攻击者提供了利用该弱点的可乘之机。

研究人员解释称，“更危险的是，任何人只要能付得起10美元的 USB 电子狗就能执行大规模的钓鱼攻击。执行这类攻击无需任何特殊设备。CP 钓鱼信息或者可以仅针对有限的目标（如通过自定义文本信息欺骗某个特定的收件人）或者大批量发动攻击（认为某些收件人可能会在对认证无任何疑问的情况下接受 CP 信息）。”

研究人员在2019年3月将研究成果告知受影响的安卓手机厂商。三星和 LG 已经在五月份和六月份的安全维护公告中解决了该问题。华为计划在下一代 Mate 系列或 P 系列手机中修复该问题；而索尼拒绝承认该问题的存在，表示移动手机设备遵循 OMA CP 标准。

研究人员建议称，即使打上补丁，用户也不能盲目地信任来自移动运营商的信息或者互联网上生成帮助用户解决数据运营商服务问题的可用 APN 设置。
