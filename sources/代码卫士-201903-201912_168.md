# 谷歌前脚发补丁通告，研究员后脚爆出未修复的安卓OS 高危提权 0day

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247490789&idx=1&sn=9ea3c9d2d058b72baac81e6367dd5913&chksm=ea972d8fdde0a499451fd6a87cec9ed5efb543c018d6bea803b667dd029dffab991e79fad596&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247490789&idx=1&sn=9ea3c9d2d058b72baac81e6367dd5913&chksm=ea972d8fdde0a499451fd6a87cec9ed5efb543c018d6bea803b667dd029dffab991e79fad596&scene=27#wechat_redirect)

![](../Images/01bb601c1da5fc72107b997999383920.png) 聚焦源代码安全，网罗国内外最新资讯！**编译：奇安信代码卫士团队****本周二，谷歌发布****9****月份的安卓安全通告，修复了存在于媒体框架中的多个严重漏洞以及一大堆高危漏洞。****但本文说的这个****0day ****并不在列表中，尽管研究员在半年前就已将问题告知谷歌。****于是研究员公开了这个尚未有**** CVE ****编号的高危提权****0day ****详情。**这个 0day漏洞存在于安卓 OS  Video for Linux (V4L2) 驱动处理输入数据的方式中。恶意输入可导致攻击者从较低的用户权限提升至根访问权限。好在该提权漏洞无法遭远程利用。攻击者需要获取本地访问权限，也就是说需要提前将恶意代码植入设备。该0day 虽然无法用于攻破用户的手机，但可让攻击效果增强，方法是使攻击者完全控制设备并发动首次感染。ZDI 在安全公告中指出，“这个漏洞可导致本地攻击者提升易受攻击的谷歌安卓程序的权限。攻击者必须首先获得在目标系统上执行低权限代码的能力才能利用该漏洞。它存在于 v4l12驱动中，是由于在对象上执行操作前缺乏对对象存在的验证导致的。攻击者能够在内核上下文中利用该漏洞提升权限。”

**易于利用的 0day**

![](../Images/1aaf7fa458e09cb9e982b4b6876bdf8f.png)

这个0day 的利用场景之一是，恶意软件作者将其捆绑到通过官方应用商店或第三方应用商店分发的恶意应用程序中。当用户安装其中一款恶意应用程序时，这个 0day 就能使恶意应用获得根访问权限，而这款恶意 app 就能为所欲为如窃取用户数据、下载其它 app 等。而这也是所有提权漏洞在正常情况下被用于安卓设备上的情况。某些安全专家可能认为这个提权0day 的严重程度没那么高，但实际上提权漏洞非常容易被用于攻击安卓生态系统，这和其它操作系统是不同的。例如，如今很多恶意安卓 app 绑定了“脏牛”提权利用代码，可导致 app 获取老旧安卓智能手机的根访问权限。

**谷歌已获悉但迟迟不推补丁**

![](../Images/1aaf7fa458e09cb9e982b4b6876bdf8f.png)

然而，尽管恶意 app 可滥用提权漏洞获取根权限的情况由来已久，但安卓开源项目 (AOSP) 的维护人员并未修复该漏洞。实际上趋势科技的两名研究人员 Lance Jiang 和 Moony Li早在今年3月初就已将问题告知 AOSP，谷歌承认该问题存在并承诺将推出补丁，但补丁迟迟未发布。

**缓解措施**

![](../Images/1aaf7fa458e09cb9e982b4b6876bdf8f.png)

目前尚不存在能够阻止恶意应用程序利用该 0day 的简单解决方案。趋势科技 ZDI 计划的负责人Brian Gorenc 表示，要缓解该问题，用户“应该仅从谷歌应用商店中直接加载已知的非恶意 app，避免从第三方侧加载 app。”ZDI 对该0day 的严重性评估为7.8分（满分10分），并认为更高级的攻击者能够利用该 0day 发动复杂的攻击活动。这虽然让多数黑客知难而退，但野心勃勃的攻击者将借此发动持久性攻击并完全控制目标系统。ZDI 表示在公开该漏洞之前并未发现该 0day遭利用的迹象。
