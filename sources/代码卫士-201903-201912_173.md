# 俄罗斯当局窃听设备 SORM 的监控数据竟然遭泄露了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247490747&idx=2&sn=ff1ab332cf77ebee31a1881727e2e124&chksm=ea972dd1dde0a4c73c4295cdbaafe8e9a660b48ef1037d2b69a8f96981aeac41a209009502e1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247490747&idx=2&sn=ff1ab332cf77ebee31a1881727e2e124&chksm=ea972dd1dde0a4c73c4295cdbaafe8e9a660b48ef1037d2b69a8f96981aeac41a209009502e1&scene=27#wechat_redirect)

![](../Images/01bb601c1da5fc72107b997999383920.png) 聚焦源代码安全，网罗国内外最新资讯！**编译：奇安信代码卫士团队****一名俄罗斯安全研究员发现，俄罗斯当局用于拦截互联网流量的硬件设备**** SORM ****一直在泄露数据。**按照俄罗斯当地法律的规定，俄罗斯所有的互联网服务提供商和电信运营商必须在数据中心安装这些硬件窃听设备 SORM。SORM 的全称是“实施调查活动系统 (System for Operative Investigative Activities)”，是支持俄罗斯在20世纪90年代通过的 SORM技术标准的硬件设备，允许俄罗斯执法机构连接到设备、设置防火墙和登录规则，并在后续节点检索登录数据。从该技术标准的最新版本 SROM-3 的规定来看，SORM 设备能够记录的日志详情包括 IP 地址、IMEI 和 IMSI 代码、MAC 地址、ICQ 用户名和 POP3、SMTP 或 IMAP4流量中或者在和多种网络邮件提供商连接中发现的邮件地址。

**30台 SORM 设备泄露监控数据**

![](../Images/fb4adced5f59c6d37ede1b90782225ab.png)

在8月25日举办的混沌建设安全大会上，一名俄罗斯研究员 Leonid Evdokimov 发表演讲称，某些窃听设备正在泄露数据。Evdokimov 表示他从20家俄罗斯互联网服务提供商网络上发现了30台 SORM 设备，它们正在运行未受密码保护的 FTP 服务器。这些 FTP 服务器包含以往执法监控活动中的流量日志。这些 SORM 设备的 FTP 服务器上被遗留的某些数据包括：

*   萨洛夫小镇居民的 GPS 坐标。该小镇目前已关闭，是俄罗斯的核研究中心。
    
*   莫斯科数百款手机的 ICQ 即使通讯用户名、IMEI 号码和手机号码。
    
*   居住在Novosilske 村的人员的路由器 MAC 地址和 GPS 坐标。
    
*   多个地点运行过时固件的智能手机的无数个GPS 坐标。
    

Evodokimov 表示他在2018年4月发现了这些数据并和互联网服务提供商一道在2018年6月加固 SORM窃听设备的安全。尽管如此，直到演讲发布前，30台被曝泄露数据的 SORM 设备中仍然有6台还在泄露数据。不过这些数据在演讲发布1天后得到加固。Evdokimov 表示，某些泄露数据的 SORM 设备是由当地的硬件设备制造商 MFI Soft 制造的。不过某些 SORM 设备似乎是由其它厂商生产的，因此尚未有证据表明，这次泄漏事故是由某些设备中的默认配置错误导致的。
