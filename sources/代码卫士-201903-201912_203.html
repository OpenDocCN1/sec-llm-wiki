微软CTF 协议被曝严重漏洞，影响自 Windows XP 以来的所有OS

虽然少有人知道的但影响所有自 Windows XP 以来的 Windows 操作系统所使用的微软协议 CTF 被指不安全，可遭轻松利用。

谷歌Project Zero 精英安全团队研究员 Tavis Ormandy 发现了这个有漏洞的协议，他指出已经存在于用户计算机中的黑客或恶意软件能够利用该协议控制任意应用、高权限应用程序或整个操作系统。

CTF 是什么？

目前尚不知晓 CTF 协议的具体内容。即使是如Ormandy 这样著名的研究员也无法从所有的微软文档中找到它的含义表述。

Ormandy 找到的结果是，CTF 是 Windows 文本服务框架 (TSF) 的一部分，该系统负责管理在 Windows 和 Windows 应用程序内部显示的文本。

当用户启动一款应用时，Windows也会为该 app 启动一个 CTF 客户端。CTF 客户端从 CTF 服务器接收关于该操作系统语言和键盘输入方法的指令。

如果该操作系统输入方法从一种语言转变为另外一种语言，则 CTF 服务器会通知到所有的 CTF 客户端，之后客户端会相应地实时更改每款 Windows app 中的语言。

通往一切的 CTF

Ormandy 发现，CTF 客户端和 CTF 服务器之间的通信并未适当认证或得到保护。

Ormandy 表示，CTF 中并不存在访问控制。他指出，“任何应用程序、任何用户，即使是沙箱进程都能够连接至任意 CTF 会话。客户按预期应该是报告线程 id、进程 id 和 HWND，但其中并不牵涉认证，因此可以撒谎。用户能够连接到其他用户的活跃会话并接管任意应用程序，或者等待管理员登录并攻陷其会话。”

劫持另外一款 app 的 CTF 会话的攻击者之后能够将命令发送给伪装成服务器的 app，而正常情况下应该发送给 Windows 操作系统。

攻击者能够利用该漏洞从其它 app 窃取数据或者以这些 app 的命令发布命令。

如果 app 以高权限运行，那么这些动作甚至可导致攻击者完全控制受害者计算机。

Ormandy 表示，任何 app 或 Windows 进程都易遭接管。由于 CTF 角色的存在（在任意 app 或服务中展示文本）所有的一切以及 Windows OS 中所有的用户接口元素中都存在 CTF 会话。

为证明这一点，Ormandy演示了如何劫持 Windows登录屏幕的 CTF 会话，说明了由于 CTF 的存在，Windows系统中的一切都是可以被黑的。

CTF 黑客工具已出现

此外，Ormandy还在发布了一篇博客文章，不仅更加深入地说明了 CTF 的安全问题，而且还在 GitHub 上发布了一款工具，帮助其他研究员测试该协议中得其它问题。

该 CTF 漏洞(CVE-2019-1162) 是一个大问题，不仅可能导致黑客攻破计算机，而且还可导致他们获取在受感染 Windows 系统上的管理员权限。

微软在补丁星期二中概述了漏洞情况：“当 Windows 不正确地处理了对高阶本地程序调用 (ALPC) 的调用时，就会发生提权漏洞。成功利用该漏洞的攻击者能够在本地系统的安全上下文中运行任意代码，之后安装程序，查看、更改或删除数据，或者以完整的用户权限创建新账户。要利用该漏洞，攻击者首先必须登录系统，之后运行一个特殊构造的应用程序以利用该漏洞并控制受影响系统。而该更新通过修正 Windows 处理 ALPC 调用的的方式解决了该漏洞问题。”

虽然目前微软已在补丁星期二中发布了修复方案，但由于该漏洞根植于该协议和设计中，因此补丁的效果仍待观察。
