# WPA3 WiFi 标准又被曝两个新漏洞

**今年****4****月份，两名安全研究员在**** WPA3 WiFi ****安全和认证标准中发现了五个被统称为**** Dragonblood ****的漏洞。****如今他们再次从中发现了****2****个新漏洞。**这两名研究人员 MathyVanhoef 和 EyalRonen 在 WPA3WiFi 标准为设备厂商创建的用于缓解最初的 Dragonblood 攻击的安全建议中发现了这两个新漏洞。和4月份发现的Dragonblood 漏洞一样，这两个漏洞可导致攻击者泄露 WPA3 加密操作中的信息并暴力攻击 WiFi 网络密码。

**漏洞概述**

![](../Images/2cffffe36462013ce62defc73c85519a.png)

第一个漏洞是CVE-2019-13377，影响的是使用 Brainpool 曲线时的 WPA3 Dragonfly 握手。Dragonfly 是供用户在 WPA3 路由器或访问点进行认证的密钥交换机制。4月份，Vanhoef和Ronen 发现依靠P-521 椭圆曲线的Dragonfly 密钥交换机制可被降级为使用安全性更弱的 P-256。因此，WiFi 联盟建议厂商使用更强大的Brainpool 曲线作为 Drgonfly 算法的一部分。但是，研究人员指出，“我们发现适应 Brainpool 曲线引入了 WPA3 Dragonfly 握手中的第二层侧信道泄露。我们实际确认了最新的 Hostapd 版本中存在 Brainpool 信息泄露情况，而且能够使用被泄信息暴力攻破密码。”第二个漏洞是CVE-2019-13456，影响 FreeRADIUS 框架中的 EAP-pwd 实现。很多厂商都在使用该框架支持 WiFi 连接。EAP-pwd（可扩展的认证协议）是受 WPA 和 WPA2 WiFi 认证标准支持的认证系统，也适用于 WPA3 的传统目标。和第一个漏洞一样，某些受 FreeRADIUS 支持的设备上的EAP-pwd 认证进程中也存在信息泄露问题，可导致攻击者恢复密码。

**闭源的标准开发过程备受诟病**

![](../Images/2cffffe36462013ce62defc73c85519a.png)

研究人员表示已经将这两个问题告知 WiFi 联盟。Vanhoef 表示，“WiFi 标准目前正在更新，增加了适当的防御措施，有可能集成于 WPA3.1。尽管这次更新并不向后兼容于 WPA3 的当前部署情况，但它确实阻止了我们发现的大部分攻击。”但除了披露这两个新的 Dragonblood 漏洞外，这两名研究员还批评了 WiFi 联盟封闭的标准开发流程，它不允许开源社区做出贡献，从一开始就阻止标准中出现重大漏洞。研究人员指出，“这证明了实现 Dragonfly 和 WPA3 而不受侧信道泄露攻击非常难。同时它再次表明，从最好的角度而言，以私密的方式创建安全建议和标准是不负责任的行为，从最坏的角度来看，这样做是不称职的。”虽然这些建议如出自其他研究人员之口可能会被忽视，但 Vanhoef 的反馈意味着更多的内容。这两名比利时研究员曾发现了攻破 WPA2 WiFi 认证标准的 KRACK 攻击并促使 WiFi 联盟开发 WPA3 标准并在2018年6月发布。请参见Dragonblood 白皮书更新版本，了解这两个新漏洞的详情：https://eprint.iacr.org/2019/383。
