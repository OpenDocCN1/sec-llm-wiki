# Chrome 76 修复43个漏洞

**编译：奇安信代码卫士团队**

**本周，谷歌发布**** Chrome 76 ****稳定版，修复了****43****个漏洞并增强了其它安全和隐私功能。**在这43个漏洞中，其中16个漏洞是由外部研究人员报告的，包括5个高危漏洞、4个中危漏洞和7个低危漏洞。

**5个高危漏洞**

![](../Images/bf3fa69cacb8f29c794909d449c78d53.png)

其中最重要的缺陷是离线页面提取器中的一个释放后使用漏洞 CVE-2019-5850。该问题是由 Brendon Tiszka 发现的，他因此获得1万美元的奖励。紧随其后的是存在于PDFium 中的释放后使用漏洞CVE-2019-5860，发现它的一名匿名研究人员因此获得6000美元的奖励。谷歌向发现另外两个高危漏洞 CVE-2019-5853（正则表达式长度检查中的内存损坏问题）和CVE-2019-5851（离线音频上下文中的投毒后使用问题）的研究人员各颁发了3000美元的赏金。谷歌尚未发布对第五个高危漏洞CVE-2019-5859（URI 可加载备选浏览器）的赏金金额。

**中危和低危漏洞**

![](../Images/bf3fa69cacb8f29c794909d449c78d53.png)

第一个中危漏洞是CVE-2019-5856，它是“文件系统检查不充分：URI 许可”。谷歌为发现此漏洞的腾讯玄武实验室研究员王永科（音译）颁发了5000美元的赏金。另外两个中危漏洞是CVE-2019-5863（Windows系统上 WebUSB 中的释放后使用漏洞）和 CVE-2019-5855（PDFium 中的整数溢出问题），它们并未被授予赏金。第四个中危漏洞 CVE-2019-5865（受攻陷的渲染器中的整数溢出）的赏金数额尚未公布。这次解决的低危问题包括 CVE-2019-5858（Open URL 服务参数的过滤不充分）、CVE-2019-5864（CORS的扩展端口过滤不充分）、CVE-2019-5862（受攻陷渲染器的 AppCache 不健壮）、CVE-2019-5861（对点击位置的检查不正确）、CVE-2019-5857（比较-0和null 产生崩溃）、CVE-2019-5854（PDFium 文本渲染中的整数溢出）以及 CVE-2019-5852（实用程序函数的对象泄漏）。Chrome 7 还解决了可使站点通过查看 FileSystem API 是否禁用（在隐身模式下是默认发生的）而检测以隐身模式浏览的人员的问题。虽然这样做的目的是阻止在设备上留下活动痕迹，但站点滥用该问题为用户带来不同的体验。谷歌表示，“这种变化将影响使用 FileSystem API 拦截隐身模式会话，并要求人们登录或切换到正常的浏览模式，前提是假设这些个人试图规避计量收费墙。”
