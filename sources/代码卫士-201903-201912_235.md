# 超百万台开源的跨平台ProFTPD 服务器易遭 RCE 和信息泄露攻击

**超过一百万台**** ProFTPD ****服务器易受远程代码执行和信息泄露攻击，成功利用一个任意文件复制漏洞之后即可触发这些攻击。**

ProFTPd 是一款开源的跨平台 FTP 服务器，支持多数 UNIX 类系统和 Windows，它是针对基于 UNIX 平台以及 Pure-FTPd 和 sftpd 的流行服务器之一。

ProFTPd 1.3.5b版本及以上版本均受任意文件复制漏洞影响，可使远程攻击者在无需认证的情况下，在成功实施利用后以 ProFTPd 服务的用户权限，导致远程攻击者执行任意代码。

**发布 ProFTPd 1.3.6 修复缺陷**

![](../Images/f0a45b6fa2614b1cdc51712ca339ac31.png)

研究员 TobiasMädel 发现，该安全缺陷 (CVE-2019-12815)（Debian、SUSE、Ubuntu）存在于 mod\_copy 模块中。ProFTPd 安全团队在2018年9月28日收到漏洞通知，在2019年7月17日发布已修复的ProFTPd 1.3.6 版本。

Mädel 在说明这个不正确的访问控制漏洞时指出，“mod\_copy 在默认的 ProFTPd 安装中提供，在多数版本（如 Debian）中默认启用。向 ProFTPd 服务器发布 CPFR、CPTO 命令可导致没有写入权限的用户在 FTP 服务器上复制任意文件。”

ProFTP 的漏洞追踪工具指出，该问题存在的原因是“mod\_copy 模块的自定义 SITE CPFR 和 SITE CPTO 命令不符合预期的要求和配置。”

服务器管理员如无法立即安装 1.3.5 ProFTPd 的修复版本，则可禁用 ProFTPd 配置文件中的 mod\_copy 模块阻止潜在的攻击，以作为一种缓解措施。

德国计算机应急响应团队 CERT-Bund 也发布了一份安全通告，警告 ProFTPD 用户警惕这个潜在的严重漏洞。

1.3.5b 及以前版本 ProFTPD 中的Mod\_copy 模块中的这个任意文件复制漏洞和2015年发现的漏洞 CVE-2015-3306 相关。CVE-2015-3306可使远程攻击者使用“SITECPFR”和“SITECPTO”命令读写任意文件。

**逾百万 ProFTPd 服务器易受攻击**

![](../Images/f0a45b6fa2614b1cdc51712ca339ac31.png)

从Shodan 搜索结果来看，目前未修复的 ProFTPd 服务器超过一百万台，其中仅有4台升级到修复版本1.3.6。

易受攻击的服务器数量如此之多，导致该漏洞可能会吸引大量攻击者，他们未来可能使用这些利用代码通过恶意软件攻陷并感染所有未修复的服务器。

黑客目前正在利用易受攻击的 Jira 和 Exim服务器，并通过新的 Watchbog Linux 木马变体实施感染，利用产生的僵尸网络挖掘门罗币。

Jira CVE-2019-11581 模板注入漏洞于12天前披露，它展示了攻击者开始滥用新的安全缺陷的速度之快。
