因内部配置错误，Twitter 宕机数十小时

推特因服务终端经历了全球范围内的大宕机，全球用户无法访问推特达20多个小时。

UTC 时间6:58分（比 EDT 时间快24小时）推特在状态更新页面显示，“我们目前正在调查访问推特出现时的问题。我们将持续更新。”

用户尝试加载推特页面时，看到错误提示消息称，“出现某些技术原因，我们将修复问题。不久服务将恢复正常。”UTC 时间19:01推特在 API 状态页面表示，团队目前“正在调查推特数据的依赖关系。受影响的 API 范围目前尚未确定。”当时，所有的推特 API 均受影响，此前曾称只有 Volume Streams & PowerTrack 性能受影响。

推特还表示，多数 API 在7月15日开始将受影响，原因是“所有连接至推特 API（以及其它推特域名）将要求使用 TLS 1.2协议。”

推特在2011年5月收购的社交媒体仪表板 web 应用程序 Tweetdeck也宕机，登录时出错消息显示，“抱歉，出错了。请稍后再试。”

Twwetdeck 在7月1日曾遭全球范围内大宕机。一些用户当时报告称，用户会被自动重定向至推特主页或该网站的移动版本。

EDT 时间15:59，推特服务恢复正常。推特表示是由内部配置更改所致，目前正在修复中。推特表示，“某些用户可能无法访问推特，我们正在解决，确保所有人能尽快访问推特。”

Tweetdeck 及其 API 目前也恢复正常。
