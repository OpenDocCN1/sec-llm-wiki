Offensive Security 公司宣布称，Raspberry Pi 4 版本发布后，立即发布相应的 Kali Linux 操作系统。

在道德黑客和渗透测试团队心中，Kali Linux 永远是排名第一的操作系统，而 Raspberry Pi 又在两周前推出了内存为 4GB 的最强大的小型电脑主板。鉴于此前 Kali Linux 在 Raspberry Pi 版本上的受欢迎程度，该公司想立即让 Kali Linux 获得 Pi 4 支持。

Kali Linux 新特征

Offensive Security 公司指出，Raspberry Pi 4 是一款非常迷人的小机器，而Pi 素以低成本和易获得性见长，而 Raspberry Pi 4 版本又增加了良好性能的特征。如今推出的 Kali Linux 新版本包含如下特征：

  • 更强大的 CPU

  • 更多的内存大小选择：1GB、2GB和4GB

  • USB-C 电源

  • USB 2 和 USB3

  • 千兆以太网

  • 2个微型 HDMI端口

此外，RaspberryPi 4 版本还具备“车载无线监控模式和框架注入支持”功能。

Raspberry Pi 4 版本的 Kali Linux 下载地址：https://www.offensive-security.com/kali-linux-arm-images/

目前，RaspberryPi 4 版本的 KaliLinux 仅支持32位系统，不过 Offensive Security 公司表示不久将推出64位系统。另外，安装和 Pi2 没有区别，因此可以参照 Pi2 文档：https://docs.kali.org/kali-on-arm/kali-linux-raspberry-pi2。
