# 安卓7月安全更新修复4个严重的 RCE 缺陷

**谷歌发布****2019****年****7****月安全补丁安卓开源项目**** (AOSP)****，修复了**** Media ****框架中的三个严重的远程代码执行**** (RCE) ****漏洞和安卓系统中的一个**** RCE ****漏洞等。**

谷歌共修复安卓系统、框架、库、Media 框架、量子组件和量子闭源组件中的33个漏洞，均已在2019-07-01和2019-07-05安全补丁级别中解决。安全通告指出，“该通告具有两个安全补丁等级，安卓合作伙伴能够灵活地更快地修复所有安卓设备中类似的漏洞子集。”

**RCE 漏洞已修复**

![](../Images/a1ecef322918797bd0a8d24f939b3903.png)

2019年7月发布的安卓安全通告指出，“最严重的漏洞存在于 Media 框架中，它可导致远程攻击者利用一份特别构造的文件在权限进程上下文中执行任意代码。”

虽然CVE-2019-2106、CVE-2019-2107和 CVE-2019-2109 这些严重的 RCE 缺陷影响所有的安卓 7.0 版本或后续设备，而安卓9.0并不受CVE-2019-2109 漏洞影响，第四个漏洞 CVE-2019-2111仅影响运行安卓 9.0 的系统。

![](../Images/599846e464c25d08497dacf7cc44052e.png)

**披露前未遭利用**

![](../Images/a1ecef322918797bd0a8d24f939b3903.png)

  

2019年7月安卓安全通告指出，未收到“活跃的客户利用报告或者新报告问题遭滥用的情况”。

该通告还解释称，已在公开披露至少1个月前向所有安卓合作伙伴通报了所修复且已在该更新中披露的安全漏洞问题。

另外，“将在未来48小时内在AOSP仓库中发布源代码补丁”，并将尽快修订 AOSP 链接。

**为谷歌 Pixel 设备发布功能性补丁**

![](../Images/a1ecef322918797bd0a8d24f939b3903.png)

谷歌还在2019年7月Pixel 更新通告中增加了多个功能性补丁，解决影响谷歌设备的多种功能问题。
