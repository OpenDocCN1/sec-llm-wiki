# Cloudflare 因软件部署不当，导致全球网络大瘫痪

**Cloudflare 公司昨天经历了一次约30分钟的网络中断，网络性能问题导致全球多个网站和 web 服务无法访问，并触发“502不良网关”错误。**

虽然多种传言认为Cloudflare公司的内容交付网络和 DoS 缓解服务正在遭攻击，但 Cloudflare 公司的首席执行官John Graham-Cummming 表示，访客看到的502错误实际上是因其网络的 CPU 使用达到峰值造成的。

他指出，“CPU 激增是由回滚的不良软件部署造成的。一旦回滚，服务就返回到正常运营状况，所有使用 Cloudflare 的域名也返回正常的流量水平。”他指出这并非某些人猜测的公司遭攻击的原因，并对服务造成的不便表达歉意。

**并未遭攻击**

![](../Images/a1ecef322918797bd0a8d24f939b3903.png)

Cloudflare 公司在博客文章上证实了其首席执行官的说法。

该公司在 HTTP502出错事件报告发布一小时后、在网络性能问题修复30分钟后进行了更新，表示，“重大网络中断问题影响全球所有的 Cloudflare 服务。CPU 使用激增导致主次系统无法运作。我们关闭了引发 CPU 激增的进程。”

7分钟之后，Cloudflare将事件报告中的状态改为已解决并增加了如下信息，“Cloudfare 已修复该问题，服务已恢复正常。”

一周内连续两次发生网络中断事件

这是一周内Cloudflare公司经历的第二次网络中断问题，尽管其在6月24日经历的 BGP 路由泄漏是由Verizon 和Noction 引发的。

Cloudflare 公司的首席执行官表示，BGP 路由泄漏难以修复，因为 Cloudflare 团队无法在中断期间联系 Verizon NOC。

鉴于超过1600万家网站都在使用Cloudflare 公司的 DDoS 缓解措施、性能提升和多种其它服务，因此 Cloudflare 网络中断通常会对整个互联网造成巨大影响。
