# 波音737 Max 系列控制软件又被曝危险漏洞，可导致飞机自动急速降落

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247490326&idx=1&sn=76f6165b9ff64276a257c490251654d7&chksm=ea972a7cdde0a36aa34fc29a24394ce17cc85dccb8f22c8f17cf73100acfa680ee7714e6ff44&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247490326&idx=1&sn=76f6165b9ff64276a257c490251654d7&chksm=ea972a7cdde0a36aa34fc29a24394ce17cc85dccb8f22c8f17cf73100acfa680ee7714e6ff44&scene=27#wechat_redirect)

**波音公司在本周三证实称，在对飞机进行模拟器测试时发现，****737 Max ****系列新型控制软件将锁定微处理器，从而导致飞机自动进入危险的急速降落状态。**

据了解，导致硬件失灵的代码是解决 MCAS 危险缺陷的固件更新的一部分。MCAS 是 737 Max 系列的反失速技术，曾导致数百人丧生。MCAS 更新目前由美国航空监管机构 FAA （美国联邦航空局）负责审核。

波音公司指出，“确保飞机的安全是波音公司的首要任务。”在 FAA 对737 Max 软件更新和最近的模拟器会话审查后增加了一项新要求，要求波音公司通过更改修改耗时八个月开发的软件来实现。

FAA 对737 Max 重返客运服务的审查和流程旨在进行全面评估。波音公司同意了 FAA 的决定和要求，目前正在处理软件问题。解决这一情况将通过考虑非指令稳定器运动的潜在来源减少飞行员的工作量。

波音公司表示，“在我们满足 Max 的所有认证要求之前，将不会对 Max 进行认证并恢复服务。”而这是在 CNN 援引未具名消息称在测试模拟器中本已该修复的 MCAS 软件版本时，飞行员发现防失速系统中的一款微处理器会锁定，从而导致飞机将俯冲数秒钟，而飞行员难以重新控制。据推测，新软件应该是在模拟器中的真正的 MCAS 硬件上运行，触发硬件卡顿问题。

而对于我们而言，这听起来就像是 MCAS 更新中的代码或者强制处理器进入锁定状态如严重的不可破坏和不间断的无限循环或触发无法处理的异常和 CPU 停顿。很可能代码在远程遇到未识别的微处理器设计权限，导致电路卡顿。

3月份，波音737Max 系列飞机在4个月内发生两起悲惨事故，导致346人丧生，之后遭全球停飞。发生灾难的原因是，飞机的防失速系统重复误读飞机的迎角传感器，迫使机头下降。

自此之后，波音公司一直都在和世界各地的航空机构合作，开发并测试修复方案，以便重新安全地恢复服务。
