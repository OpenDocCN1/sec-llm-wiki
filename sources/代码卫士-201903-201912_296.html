本月初，Facebook 举办了首个全球夺旗大赛 (CTF)，目前已在 GitHub 上开源了比赛题目。

超过65个国家的1600多个团队角逐在6月1日至3日举办的这次 CTF 大赛。

比赛的状元、榜眼、探花分别由谷歌安全团队等组成的 G+ 团队、中国台湾地区的 CTF 团队 Balsn 以及卡内基梅隆大学的 PPP 团队获得。它们获得的奖金分别是3,133.7美元、2000美元和1000美元。

Facebook CTF 2019 大赛的源代码和解决方案已发布在 GitHub 上，错过参与机会的人员可进入真正的竞赛活动进行分析。

Facebook 公司的安全工程师 Gulshan Singh 表示，“CTF 大赛的宽度和深度都令人惊叹，各团队使用各种方式解开我们安全团队成员为大赛设置的挑战，非常令人兴奋。我们学到了一些新技术并希望 CTF 参与人员也能够学习一二。”

本周，谷歌也在举办第四届年度 CTF 大赛的资格赛，奖金总计31,337.00 美元。
