# Telegram 通讯服务遭受大规模 DDoS 攻击，影响全球用户

**今天某些地区的**** Telegram ****通讯服务用户无法收发信息，原因是**** Telegram ****服务器遭受来源不明的大规模**** DDoS ****攻击，受影响用户主要位于北美和南美，尽管其它地区也出现了连接问题。**

Telegram 在推特上表示，其服务器今天遭受由受攻陷计算机组成的网络发动的 DDoS 攻击。该僵尸网络向 Telegram 服务器发送了大量无用流量，导致服务器无法处理来自合法用户的请求，进而引发连接不稳定的情况发生。

实时追踪多种数字化服务网络破坏和中断情况的网站 Downdetector 表示，遭受 DDoS 攻击影响最严重的热点地区位于美洲东海岸、英国、荷兰、德国、乌克兰、俄罗斯和中国。然而，其它地区的用户也受影响，因为澳大利亚的用户也表示在加载视频内容方面遇到问题。

虽然有些人在猜测该 DDoS 攻击的幕后黑手，但 Telegram 澄清表示，僵尸网络的主要特点就是它由位于全球任何地方的受攻陷计算机组成。即使它源自某个特定区域，但也并不一定意味着攻击者就来自某地。此外，也有一些 DDoS 服务租赁僵尸网络能力，因此世界上的任何人均可发动针对性攻击。

在以简单易理解的语言解释了 DDoS 攻击的情况及其影响后，Telegram 向用户表示他们的数据仍然安全。截止目前，情况稳定，而用户在使用时应当不会遇到问题。

2018年3月，Telegram 宣称活跃用户达到2亿，随着其它即时通讯服务遭受连接问题后，更多的人选择 Telegram。例如，Telegram 服务创始人 Pavel Durov 在2019年3月宣布称，该平台在24小时内获得300万名新注册用户。该声明发布时恰逢Facebook、WhatsApp和 Instagram 遭遇服务中断问题。
