# 微软将推出无密码版 Windows 10

**微软想要让**** Windows ****平台变为无密码平台，而最新的**** Windows ****版本让它离这个目标更进一步。**

在这个万物互联的世界，密码一直以来被视作一个安全问题，尤其是在很多设备包含默认或容易猜出的凭证的情况下，而整个行业都在推出替代方案。

多因素验证已存在一段时间，很多人认为它是可行的替代方案，尤其是和强大的唯一密码组合时。而微软正在寻找的替代认证方法能够使用户无需密码即可登录 Windows 10。

最新的 Windows 10 版本1903能使用户添加一个无密码电话号码的微软账户并以微软认证 app 登录。另外，登录还具备 Windows Hello 作为 FIDO2 认证，以及在锁屏上出现的 Windows Hello Pin 恢复。

微软当前允许用户在 iOS 或安卓设备上的移动 Offcie 应用（Word、OneNote 或 Outlook）中通过电话号码创建微软账户。微软表示该功能能够在无需密码的情况下解锁所有的微软账户权益。

微软解释称，“它通过 Windows 锁屏上的附加 web 登录能力启用。之后，Windows Hello 用于端对端无密码体验。”

这种web 登录能力可用于任何微软账户，甚至是邮件账户也不例外，只需在登录 Windows 10时将微软账户添加至 Windows，通过微软认证 app 登录并设置 Windows Hello 界面、指纹或 PIN即可。

无密码登录功能已存在于 Mozilla 火狐浏览器版本66及以上版本，而很快将会出现在基于 Chromium 的浏览器中。当登录微软账户和其它支持 FIDO 认证的网站时该功能即可使用。

现在用户能够更加容易地通过出现在 Windows 锁屏上的“我忘记 PIN 码”界面，恢复 Windows Hello PIN码。微软解释称，用户现在能够使用微软 Authenticator app 而非密码重置 PIN 码。
