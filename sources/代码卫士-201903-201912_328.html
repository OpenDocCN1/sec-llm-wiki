俄罗斯军事系统即将投入使用本地开发的 Astra Linux，从而取代 Windows 操作系统。

上个月，俄罗斯联邦技术和出口管制局 (FSTEC) 授予 Astra Linux 的安全许可为“特别重要”，意味着该操作系统目前可用于处理俄罗斯政府最高程度的保密信息。

到目前为止，俄罗斯政府仅使用了经过修改、检查和由俄罗斯联邦安全局（FSB）批准使用的Windows 特殊版本。

Astra Linux 介绍

但从上个月开始，俄罗斯军方可使用 Astra Linux，它是由俄罗斯公司 RusBITech 自2008年就开发的 Debian 衍生版本。RusBITech 起初开发该操作系统是为了在俄罗斯私有市场上使用，但该公司之后扩展至当地政府部分，在军事承包商之间非常流行。

几年前，Astra Linux 获得处理被标记为“机密”和“绝密”级别的俄罗斯政府信息的认证，根据俄罗斯法律规定，这两种数据保密级别属于“特殊重要性”的类别。

自此之后，Astra Linux 开始逐渐进入政府机构，目前用于俄罗斯国防控制中心以及其它多家政府和军事机构。

俄罗斯军方已开始投入使用

2018年1月，俄罗斯国防部宣布军事系统将从 Windows OS 转向 Astra Linux，表示这样做的原因是担心微软的闭源方式可能隐藏 Windows 后门，被美国情报部门用于监控俄罗斯政府行动。

至此之后，RusBITech 公司一直都通过俄罗斯政府的认证进程，为 Astra Linux获得“特别重要”分类，而且最终在4月17日获得该认证。

除了 FSTEC 认证外，Astra Linux 同时从俄罗斯联邦安全局和国防部获得合格证书，从而为俄罗斯最高军事和情报机构全面使用该操作系统打下基础。

当地报道称，该认证颁发给 Astra Linux 特别版 1.6，也被称为 Smolensk 版本，它是付费版本。
