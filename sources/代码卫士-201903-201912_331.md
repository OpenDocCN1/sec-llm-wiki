# 开源的 DuckDuckGo 安卓浏览器易受 URL 欺骗攻击

**开源的**** DuckDuckGo ****浏览器安卓版**** 5.26.0 ****中被曝存在一个地址栏欺骗漏洞，可导致潜在攻击者发动**** URL ****欺骗攻击。该**** app ****的下载量超过****500****万次。**

安全研究员 Dhiraj Mishra 发现了这个漏洞 (CVE-2019-12329)，并通过 HackerOne 告知该应用的安全团队。Mishra 的PoC 通过特殊构造的 JavaScript 页面使用 setInterval 函数每隔10到50毫秒的时间重新加载一个 URL，从而欺骗欺骗 DuckDuckGo 隐私浏览器的地址栏。

虽然真正的 duckduckgo.com 网站每隔50毫秒自动加载一次，但内部 HTML 被修改以显示完全不同的内容。

Mishra 表示，“2018年10月31日将漏洞提交给浏览器的安全团队，当时它被评估为高危漏洞；但2019年5月27日，他们认为问题并不严重，而将其降级为通知性漏洞，不过仍然从 DuckDuckGo 获得赏金。”

潜在攻击者可通过更改显示在易受攻击浏览器地址栏中显示的 URL诱骗受害者认为正在浏览的网站由受信任方控制。然而，该网站实际上是由发动攻击的恶意人员控制的，就像攻击者能够滥用 Mishra 在安卓版 DuckDuckGo 隐私浏览器中发现的地址栏欺骗缺陷那样。

不知情的受害者之后被重定向至伪装成多种高级别网站的域名，实际上会使得攻击者能够通过使用钓鱼登录页或通过恶意广告活动在计算机上释放恶意软件的方式窃取目标的信息。

安全研究员 Arif Khan 表示，URL 地址栏欺骗是最糟糕的一种钓鱼攻击，因为它是唯一一种识别用户所访问站点的方式。
