# 数百万 Instagram 网红名人品牌的私密联系方式被一扫而光

**包含数百万**** Instagram ****网红、名人和品牌账户的庞大数据库遭暴露。**

该数据库托管在亚马逊 Web 服务 (AWS) 中，并无密码保护，任何人均可查看。在本文成稿时，数据库中共包含490万条记录，不过还在一直增加。

粗略查看数据后发现，每条记录中都包含从网红 Instagram 账户中搜刮的公开数据，包括个人资料、照片、粉丝数量、是否得到验证以及所处国家和城市，同时包括私人联系方式如 Instagram 账户所有人的邮件地址和电话号码。

安全研究员 Anurag Sen 发现了这个数据库并向 TechCrunch 媒体发出警报，希望能找到数据库所有人加固该数据库的安全。TechCruch 认为该数据库属于位于孟买的社交媒体营销公司 Chtrbox，它付费请网红进行推广宣传。数据库中的每条记录中包含根据粉丝数量、参与度、触及范围、喜好和分享计算出的每个账户的价格，用于计算这些 Instagram 网红名人的广告费。

TechCruch 在被暴露的数据库中发现了多个有名的网红，包括美食博主、名人以及其它社交媒体网络红人。另外，TechCruch 还随机联系了数据库中的多名人员并提供了他们的手机号。其中两人回复并证实了邮件地址和注册 Instagram 账户的手机号码是正确的。但他们表示和 Chtrbox 公司之间并无来往。

Chtrbox 公司得到通知后将数据下线。该公司创始人兼首席执行官 Pranay Swarup 并未就公司如何获取这些私密邮件地址和手机号码的情况做出说明。

两年前，Instagram 证实称开发者 API 中出现的一个 bug 可导致黑客获取600万Instagram 账户的邮件地址和电话号码。黑客之后以要求支付比特币的方式将数据出售。

几个月之后，现在已坐拥10多亿用户的 Instagram 公司封锁了 API，限制了 app 及开发人员能够提出的请求数量。

Instagram 所属公司 Facebook 表示正在调查此事。Facebook 公司发表声明称，“我们正在调查此事，了解所述数据包括邮件地址和电话号码源自 Instagram 还是其它来源。我们正在询问 Chtrbox 公司查明数据来源以及如何遭暴露的情况。”
