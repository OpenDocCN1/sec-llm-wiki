# 思科修复 PI 软件中的多个严重漏洞

**思科发布多个补丁，修复可导致远程代码执行的思科**** PI****（主要基础设施）软件中的多个严重漏洞以及其它漏洞。**

PI 软件中被曝出现三个漏洞：CVE-2019-1821、CVE-2019-1822和CVE-2019-1823，CVSS 评分均为9.8。

这些漏洞影响思科 PI 和思科 EPN （进化的可编程网络）管理器基于 web 的管理接口，可导致远程攻击者以提升后的权限执行任意代码。

CVE-2019-1821可被拥有网络访问权限的未认证攻击者访问受影响的管理接口。CVE-2019-1822 和 CVE-2019-1823 要求攻击者具有在受影响管理接口的认证凭证。

思科表示，“这些漏洞存在的原因是软件对用户输入的验证不正确。攻击者能够通过向管理 web 接口上传恶意文件的方式利用这些漏洞。成功利用可导致攻击者以根权限执行代码。”

PI 软件3.4.1、3.5和3.6 之前的版本以及 EPN 管理器3.0.1之前的版本均受影响。思科已发布软件更新解决漏洞问题。

思科表示，尚未发现利用这些漏洞的公开报道。

另外，思科发布补丁，修复位于如下产品中的10个高危漏洞：ASR 9000 Series 路由器，Webex Network Recording Player for Windows，Small Business Sx200、Sx300、Sx500、ESW2 Series 和 Sx250、Sx350、Sx550 Series 交换机， PI 和 EPN Manager, FXOS 和NX-OS Software，IOS XR Software，Video Surveillance Manager 和Nexus 9000 Series 交换机。

这些缺陷如被利用可导致拒绝服务、任意代码执行、任意 SQL 查询执行、信息泄漏或权限提升至根用户的后果。

另外，思科还发布补丁，修复了40多个中危漏洞，多数存在于 NX-OS 软件中，包括命令注入漏洞、安全配置绕过、缓冲区溢出、SSH 密钥信息泄漏、补丁遍历和策略绕过问题。

思科还更新了受最近披露的影响安全启动实现的受影响产品列表。高危漏洞CVE-2019-1649可被用于向安全启动的硬件组件中写入遭修改的固件镜像。
