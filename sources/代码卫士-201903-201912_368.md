# 币安被黑客盗走逾7000个比特币，价值超4100万美元

**今天，全球最大的密币交易所之一币安披露称，黑客设法窃取了****7000****多个比特币，价值超过****4100****万美元。**

币安创始人兼首席执行官赵长鹏表示，黑客从存储着约2%的总持股量的一个热钱包中劫走比特币。赵表示其它钱包并未受影响并向客户保证称，用户安全资产基金 (SAFU) 紧急保险资金将补贴这些损失。

这次黑客事件被称为“大规模的安全泄露事件”，被发现于5月7日。据悉黑客获取大量用户 API 密钥和双因素认证代码，并利用钓鱼攻击、恶意软件和其它技术执行此次攻击。

赵表示，“黑客有足够的耐心等待，并在最有机会得逞的时间，通过多个看似独立的账户采取了精心策划的行动。交易通过了我们现有的安全检查机制。很遗憾我们未能在交易执行前拦截提现。交易一旦执行，提现就会触发系统中的多个警报。之后，我们立即停止了所有提现行为。”

币安计划开展一次彻底的安全审查，预计将为期一周左右的时间。币安承诺将随时向客户说明进展，但在此期间将暂停充值和提现。

赵表示，“我们将继续启用交易，以便客户调整仓位。需要注意的是，黑客仍然可能控制着某些用户账户，而且可能使用这些账户影响价格。我们将持续实施密切监控。但我们认为，禁用提现功能后，黑客影响市场的动力不足。”

赵在推特上表示，Coinbase 和其它交易所将拦截黑客用于交易资金的比特币地址的充值。

很多密币交易所曾遭攻击，而且在很多情况下黑客设法窃取了价值数百万甚至数千万美元的比特币。受影响的交易所包括 Coinrail、Zaif、Coincheck、Bithumb、Bter、Bitfinex 和 CAVIRTEX。
