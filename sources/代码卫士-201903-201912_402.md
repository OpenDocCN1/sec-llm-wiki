# 震惊！印度本地化搜索服务巨头 JustDial 正在泄漏1亿用户的个人信息

**印度最大的本地搜索服务**** JustDial ****的一个未受保护的数据库正在实时泄露所有通过网站、移动应用甚至是拨打****“****88888 88888****”****客户关怀电话访问该服务的用户的个人可识别信息。****外媒**** The Hacker News ****已独立验证该事件属实。**

JustDial(JD) 成立于20多年前，是印度最老牌的领先本地搜索引擎，它允许用户快速找到多种产品和服务的相关本地提供商和供应商，同时帮助企业营销产品。

独立安全研究员 Rajshekhar Rajaharia 分享了不受保护的公开可访问的 JustDial 数据库的API 端点如何可被任何人访问以查看和其移动号码相关联的超过1亿用户的资料信息。

被泄露的信息包括 JustDial 用户的名字、邮件、手机号码、住址、性别、出生日期、照片、职业、所在公司名称，基本上是客户向该公司提供的所有资料信息。

尽管该不受保护的 API 至少存在于2015年中期，但目前尚不清楚是否有人滥用它收集 JustDial 用户的个人信息。

**正在泄露所有用户的个人信息**

![](../Images/d8bfe178ec266b1732ddfd826ddcca82.png)

The HackerNews 验证泄露的端点后，想要进一步验证该 API 是直接从生产服务器中提取结果还是从可能并不包含最新注册用户信息的备份数据库中提取结果。

为此，本文作者向 Rajshekhar 提供了一个此前从未在 Justdial 服务器上注册过的一个新号码，且 Rajshekhar 证实当时该数据库中并未列出该号码。

本文作者并未安装并使用 JD 应用或网站，而是拨打了客户关怀电话并和高管分享了一个随机姓名和个人详情来了解作者所在城市的饭店推荐情况。

挂断电话后，Rajshekhar 就将作者提供的个人资料和电话号码提供给了作者，表明这个未受保护的 API 正在抓取用户的个人实时信息。

尽管这个未受保护的 API 连接到 JD 的主数据库，但 Rajshekhar 披露称它是一个老旧的 API 端点，目前该公司已不在使用但将其遗忘在服务器上。

Rajshekhar 表示是在渗透测试正在使用的最新 API 过程中发现了这个未受保护的端点，而最新在用的 API 显然得到保护并使用了认证措施。

除此以外，Rajshekhar 还找到了其它一些老旧的未受保护的 API，其中一个可熬制任何人触发任何注册号码的 OPT 请求，它可能并非严重问题，但可用户向用户发送垃圾信息并给 JD 带来成本。

Rajshekhar 表示试图联系该公司报告所发现的情况，但遗憾的是并未找到任何联系方式并报告该事件的直接方式。
