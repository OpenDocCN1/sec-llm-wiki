# 说有病就有病？！黑客竟能修改癌症 CT 扫描结果

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247489646&idx=2&sn=9c7f96f5febc807247b95f7ac844439d&chksm=ea972904dde0a012f4e698eb57873be96d257e38a7127e84e193dd8acb66ea73a1349b4a27da&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247489646&idx=2&sn=9c7f96f5febc807247b95f7ac844439d&chksm=ea972904dde0a012f4e698eb57873be96d257e38a7127e84e193dd8acb66ea73a1349b4a27da&scene=27#wechat_redirect)

**以色列古里昂大学和比尔谢瓦索如卡大学医学中心的专家指出，黑客能够修改**** 3D ****医疗扫描结果，增加或删除诸如癌症等重症的证据。**

安全专家已开发 PoC 恶意软件，能够使用生成性对抗网络 (GAN) 的机器学习技术快速修改 CT 扫描中生成的 3D 图像。

CT 扫描器通常通过图片归档和通信系统 (PACS) 进行管理。该系统从扫描器接受扫描、存储结果并将其提供给放射科。数据通过标准格式 DICOM进行传输和存储。PACS 产品是由通用医疗、富士胶片、菲利普斯和 RamSoft 等公司提供的。

研究人员表示，其中的一个问题是，PACS 和 DICOM 服务器通常被暴露在互联网上。Shodan 搜索引擎识别出近2700台联网服务器。另外一个问题是，在很多情况下，医疗图像数据是在未加密的情况下在网络进行产博得，从而导致中间人攻击和操纵的情况发生。

恶意人员能够直接针对可从互联网访问的 PACS，或者可以首先获取对目标组织机构网络的访问权限，之后再发动攻击。研究人员在一所医院的放射科开展的另外一个攻击向量涉及物理连接CT 扫描器工作站和 PACS 网络之间的小型中间人攻击设备。在这些本地攻击中，攻击者能够依靠内部人员或假装成技术人员。

![](../Images/46ef7b3775b228e082257070ea3b8d56.png)

  

一旦攻击者从 CT 扫描器中拦截流量，就能使用攻击框架 CT-GAM 通过 GAN 技术在图像到达负责解释结果的放射科之前操纵图像。

安全专家已经通过请放射科诊断被真实的30份 IT 扫描结果和70份被 CT-GAN 修改过的70份结果测试了攻击的效果。CT-GAN 被用于将恶意癌症的证据注入健康患者的扫描结果中，并从实际患病人群的扫描结果中删除癌症。

放射科在没有意识到结果已被操纵的情况下，将99%的被注入扫描结果诊断为癌症，而将94%的癌症结果被删除的扫描结果诊断为健康。获悉扫描结果遭修改后，反射科误诊的比例分别高达60%和87%。研究人员表示，攻击甚至欺骗了所有测试中的一个最新肺癌筛查模型。

**攻击目的**

![](../Images/0b1befd45a4d43aeb05b2b8c55d91fff.png)

但是，为什么会有人想要发动这类攻击呢？研究人员列出了多种可能的动机和目标。他们认为修改某人的扫描结果并导致误诊可能是出于窃取他人的职位、修改选举结果、阻挠或误导研究、通过扣押数据牟利、实施保险欺诈、甚至是实施谋杀或恐怖主义行为。  

研究人员指出，这种方法可用于增加或删除多种疾病的证据，包括动脉瘤、心脏病、血栓、感染、关节炎、软骨问题、韧带撕裂以及脑、心脏或脊柱肿瘤。

例如，如果攻击者在政治候选人的 CT 扫描结果中增加患癌证据，那么就能迫使该候选人退出竞选。同样的技术也可用于使他人放弃工作或领导职务的场景中。在最糟糕的场景黄总，黑客能够删除严重疾病的证据，从而导致他人因未得到正确的治疗而身亡。
