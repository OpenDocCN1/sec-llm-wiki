运行安卓 4.4 或后续版本的智能手机和其它设备中含有一个漏洞，可遭恶意应用用于窃取网站登录令牌并监控用户的浏览历史。

恶意应用如恶意测试应用或游戏可利用这些被盗的认证令牌假冒所有者登录站点窃取信息或干预受害者的网络账户。

PositiveTechnologies 公司的研究员 Sergey Toshin 发现了这个漏洞 (CVE-2019-5765)并将它告知谷歌。该漏洞存在于安卓版本的 Chrome 浏览器中。由于补丁已在二月份发布，Positive Technologies 刚刚公布了漏洞详情。

影响 Chromium 引擎和 WebView

该漏洞存在于安卓 4.4 （发布于2013年）及后续版本中。因此，如果你运行的是安卓版本的 Chrome 版本72.0.3626.81 或运行安卓7或更高版本的 Chrome，那么并不受影响。该更新应当已经自动应用（可查看 Chrome 更新了解）。如果你运行的是之前的安卓版本，那么需要通过谷歌应用商店服务更新安卓的 WebView 组件。

该漏洞存在于 Chromium 浏览器引擎和 WebView （供应用程序渲染 web 内容）中。自安卓7及后续版本起，Chrome 通过 Chromium 引擎实现 WebView，而在7.0版本前，WebView是一个单独组件，因此根据你所使用的安卓操作系统的不同，需要从两个独立补丁路径中进行选择。如果是安卓7及更高版本，则需要更新 Chrome。如果是安卓7以前的版本，则需要更新 WebView。而如果智能手机上没有谷歌应用商店服务的用户，则需要等待设备厂商推出 WebView 更新。

危险系数高

如上所述，应用程序能够调用 WebView 在用户界面上展示网页。但遗憾的是，在易受攻击的设备上，恶意应用能够通过 WebView 组件滥用“遭暴露的调试端点”访问浏览器数据，包括认证令牌和浏览器历史。例如，恶意开发人员可购买合法非恶意的程序，在未修复设备上推出利用该缺陷的更新。

Positive 公司的研究人员指出，“WebView 组件用于多数安卓移动应用中，使得此类攻击极其危险。最常见的攻击场景涉及很少为人熟知的第三方应用。包含恶意有效负载的更新后，此类应用可从 WebView 读取信息。”

三星互联网浏览器 Yandex Browser 和其它使用易受攻击的 Chromium 版本的浏览器也有风险。研究人员指出，攻击者可滥用某 instant app（即无需安装任何代码即可运行的 app）中的 WebView，收集并提取日志文件中的用户数据。

研究人员解释称，“攻击者能够明确日志应当写入的文件路径，甚至覆写现有文件，但攻击者无法完全控制所记录文件的格式，而仅控制部分文本。这是因为，例如，任何第三方应用都能打开 Chrome 中的任意链接而无需获取任何权限，因此恶意应用可能会激活探查器、打开任意链接，某些数据可能已经记录在任意文件中，之后探查器可遭禁用。”

研究人员再次强调称，虽然最近发布的安卓版本会通过更新至 Chrome 最新版本的方式获得修复方案，但运行低于安卓7版本的用户应当单独修复 WebView，或者通过谷歌应用商店进行修复或者通过设备厂商发布的空中下载更新进行修复。
