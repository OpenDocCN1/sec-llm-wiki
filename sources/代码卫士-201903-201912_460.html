多名用户表示，Windows Defender Antivirus、Microsfot Endpoint Protection 和 Microsoft Security Essentials 反恶意软件解决方案随机崩溃，运行 Windows 7、Windows 8.1 和 Windows Server 2003、2008和2012 系统的电脑上出现了 0X800106ba 错误代码。

该错误似乎源自微软在3月18日发布的1.289.1521.0 的定义更新。Reddit、微软 TechNet、推特和 AskWoody 上的用户报告该情况。

微软证实称这是个全球性问题，并在数小时后在下一个更新版本 1.289.1573.0 中修复。

当恶意软件服务崩溃时，日志说明的出错信息描述为“该操作不合法 (The handle is invalid)”，而原因是“过滤驱动异常卸载”。

在漏洞修复前，有人提供的缓解方案是在回滚至上个版本时运行如下命令：

cd \cd C:\programfiles\Microsoft Security Client\ Mpcmdrun-RemoveDefinitions

微软修复该漏洞并表示，问题似乎仅限于 Windows 7 和 WindowsServer 2008。
