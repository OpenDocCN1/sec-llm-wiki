# 黑客逆袭典范：前“死牛崇拜”成员成美国2020年热门总统侯选人

**美国新任总统侯选人**** Beto O****’****Rourke ****表示，他曾是网络历史上最具传奇色彩的黑客组织“死牛崇拜（****Cult of the Dead Cow****）”的一名成员。**

“死牛崇拜”黑客组织位于美国，活跃于20世纪80年代至90年代，该组织的多名成员已证实称， O’Rourke 在德克萨斯州埃尔帕索度过的青春期确实是该组织的成员之一。

正在撰写关于该黑客组织的作者兼记者 Joseph Menn 表示，O’Rourke 和“死牛崇拜”组织之间的关联一直被其他成员保密，担心这段经历会影响民主党的政治抱负。O’Rourke 自2013年到今年1月是德克萨斯州众议院的代表，因未能成功申请 Ted Cruze 在德克萨斯州的参议院席位而下台。

O’Rourke 目前已证实参选2020年的总统大选，但却自投罗网，向 Menn 表示感谢他曝光这段经历。

![](../Images/6ce11595c138b80d0b731ce713bbca3d.png)

O’Rourke 表示，“能够脱离系统并以批判的眼光看待它并在做这件事情时享受乐趣，具有非常重要的价值。我认为‘死牛崇拜’就是一个很好的例子。”

据称，O’Rourke 并未参与该黑客组织开展的恶意活动，如开发控制被劫持 Windows 计算机的工具等。他确实承认曾规避电话账单并下载破解软件，而这种行为在当时的地下 BBS 团伙成员而言是一种很常见的做法。

虽然O’Rourke 和传奇的德克萨斯黑客组织挂钩这件事让人吃惊，但也不能说是不适合的。毕竟，O’Rourke 在左翼圈子中的印象是他曾是德克萨斯州的朋友摇滚音乐家以及他具有强烈的反传统文化的倾向。

Beto 并非首个渴望在华盛顿特区找到工作的第一个“死牛崇拜”成员。该组织最著名的成员之一 Peiter “Mudge” Zatko 曾在2010年初与 DARPA 合作，在军事研究部门监督过多个信息安全项目。

听闻报道后，Mudge 对于这位总统侯选人之间的关系表现得含糊其辞，他表示，“毕竟是在我表态之前他先说的这个话题。”

本文作者打趣道，如果 Beto 在竞选总统职位时不尽如人意而且需要工作，可以考虑将简历投过来啊。
