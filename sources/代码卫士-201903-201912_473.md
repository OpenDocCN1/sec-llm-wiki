# 小心！“反恐精英”1.6被曝多个 0day 漏洞，恶意服务器攻击全球玩家电脑

**如果你是“反恐精英”玩家，那么就要小心了：****39%****的所有现有的网上“反恐精英”****1.6****游戏服务器是恶意的，目的是为了远程黑入玩家的电脑。**

![](../Images/3ccb6e12ce524ae1916facec5a10e9b2.png)

Dr. Web 公司的研究人员披露称，攻击者一直都在通过恶意的游戏服务器静默攻击全球“反恐精英”玩家的电脑，利用的是游戏客户端中存在的多个 0day 漏洞。

研究人员指出，已存在近20年的热门游戏“反恐精英”1.6 的客户端软件中包含未修复的远程代码执行漏洞，可导致攻击者在玩家连接至恶意服务器之后在玩家电脑上执行任意代码，而无需要求玩家的任何互动。

**木马 Belonard**

![](../Images/d0acb00f6157fe0258ed7efce3700340.png)

结果显示，被称为“Belonard”的俄罗斯游戏服务开发者一直在利用这些漏洞推广其业务并通过一款自定义木马创建了由受攻陷玩家系统组成的僵尸网络。  

这款木马被称为“Belonard”，是根据其开发者命名的，旨在获取持久性、替代安装在受感染系统上的易受攻击游戏客户端中的可用游戏服务器列表，并创建代理以进一步传播该木马。

Dr. Web 在报告中指出，“按规则，代理服务器显示一个更低的 ping，这样其它玩家就会在列表顶部看到它们。玩家选择其中一个后就被重定向至恶意服务器，进而电脑遭 Trojan.Belonard 感染。”

除此以外，恶意开发者还通过已遭感染的 Belonard 木马的网站传播已遭修改的或盗版的游戏客户端。

这个木马含有11个组件，其中1个组件作为恶意客户端的保护器，“过滤接收自其它游戏服务器中的请求、文件和命令，并将客户端的更改尝试数据传输至木马开发者的服务器中。”

这款恶意软件还通过 Steam API 注册了所创建的代理游戏服务器并使用加密将数据存储在系统上，并和远程命令和控制服务器进行通信。

研究人员表示，“分析师指出，在官方 Steam 客户端可用的约5000台服务器中，有1951台服务器是由 Belonard 木马创建的，占比39%。这种规模的网络能够让木马开发者推广其它服务器以牟利，将其加入受感染游戏客户端中的可用服务器列表中。”

研究人员已将问题告知“反恐精英”1.6游戏的开发商 Valve 公司。另外，研究人员还将恶意软件开发者使用的恶意域名告知俄罗斯web 注册机构，后者随后停止多个域名以端掉该僵尸网络。

然而，仅端掉几个域名并不能阻止攻击者设立更多的恶意服务器，除非“反恐精英”开发商能够修复其游戏软件中存在的已报告的远程代码执行漏洞。
