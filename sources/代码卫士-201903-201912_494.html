刚刚，微软开源了 Windows 10 计算器技术，任何人均可借此理解它的工作原理或扩展其功能。感兴趣的用户可以从 GitHub 上下载完整代码并尝试编译。

Windows 计算器使用的是 C++，包含超过3.5万行代码。要编译该项目，用户需要运行Windows 10 版本1803 或者更新版本，并安装最新版本的 Visual Studio，其中包括免费的 Visual Studio 社区版本。GitHub 页面上详细说明了所有要求。

由于该软件已按照 MIT 许可发布，因此它允许开发人员创建自己的修改和衍生，传播该软件甚至是出售。微软认为该项目为多种微软技术如 Fluent app 设计、Universal Windows Platform、Azure Pipelines 等等提供了一个良好的指导。微软认为通过审查该计算器的代码还能够学习微软完整的开发声明周期，并通过复用该代码来构建自己的体验。

想要参与该计算机开发的开发人员可提交漏洞报告、帮助修复漏洞并扩展它的功能。然而，微软要求任何从中找到安全漏洞的研究人员都要联系微软安全响应中心 (MSRC, secure@microsoft.com)而非公开这些漏洞。

另外，微软还在去年开源了 Windows 3.0 文件管理器，不过需要更新以便适用于Windows 10。

GitHub 页面：https://github.com/Microsoft/calculator
