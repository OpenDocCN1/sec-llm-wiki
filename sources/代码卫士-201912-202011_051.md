# 全球软件巨头 Software AG 遭勒索攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247495445&idx=3&sn=0ec3c28d15711282934cdff1ac40bccb&chksm=ea94de7fdde35769eaa925719ed8cd2f38237a966db8549fccaf621c688ca492536fa06b5b88&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247495445&idx=3&sn=0ec3c28d15711282934cdff1ac40bccb&chksm=ea94de7fdde35769eaa925719ed8cd2f38237a966db8549fccaf621c688ca492536fa06b5b88&scene=27#wechat_redirect)

![](../Images/724969efd5bfb8c1d8b761f794b6b733.png) 聚焦源代码安全，网罗国内外最新资讯！**编译：奇安信代码卫士团队****全球最大的软件公司之一 Software AG 在上周末遭勒索攻击，目前这家德国技术巨头公司的服务尚未恢复正常。**  
10月3日，名为“Clop”的勒索团伙攻陷了该公司的内部网络、加密文件并要求支付2000多万美元才提供解密密钥。谈判失败后，该团伙在暗网网站上公开了 Software AG 公司的数据。这些截屏展示了员工的护照和身份证扫描件、员工邮件、金融文档和公司内网目录。

![](../Images/2eb51713b9c3595132c665909a7e6ca7.png)

  

本周一，Software AG 公司称，“因恶意软件攻击“，其内网遭到破坏。客户服务，包括基于云的服务不受影响，且并未发现”任何客户信息遭访问“。但两天后，该公司撤回该声明，承认发现数据被盗的证据。目前该公司的官网主页仍然保留着和攻击相关的消息。Software AG 公司并未发布更多详情或对此事置评。安全研究员 MalwareHunterTeam 本周早些时候发现了所使用的勒索软件二进制副本。高达2000多万美元的勒索金是目前为止见到的最高勒索金之一。

![](../Images/4298beb2ec1044d7a561215fad20d3b8.png)

  
研究人员通过勒索留言中提供的 ID 从 Clop 勒索团伙管理的一个 Web门户网站上查看了 Clop 和 Software AG 之间的聊天记录。从目前的情况来看，并非发现Software AG 公司支付勒索金的证据。

![](../Images/d6b1d59df3bdcfa25d32d5c2292dcfd7.png)

  
Software AG 是德国的第二大公司，企业客户超过1万名，遍布70个国家。它的客户包括富士通、Telefonica、沃达丰、DHL 和 Airbus。其产品线包括商业基础设施软件如数据库系统、企业服务总线 (ESB)框架、软件基础架构 (SOA) 和业务流程管理系统 (BPMS)。
