# 瑞士表商 Swatch 关闭 IT 系统，阻止网络攻击

![](../Images/724969efd5bfb8c1d8b761f794b6b733.png) 聚焦源代码安全，网罗国内外最新资讯！**编译：奇安信代码卫士团队****上周末，瑞士表商 ****Swatch ****集团发现了针对其系统的网络攻击活动，随后关闭**** IT ****系统以阻止。**  
Swatch 集团因生产多姿多彩的手表而闻名，截止到2019年，其员工数量超过3.6万名，收入达96亿美元。Swatch 集团发布声明称，在上周末发现网络攻击活动，于是关闭其 IT 系统以阻止攻击的传播，“Swatch 集团证实上周末，某些 IT 系统出现了网络攻击活动。出于安全考虑，集团立即采取措施并关闭一些 IT 系统，可能会影响一些操作活动。Swatch 集团立即评估并分析了攻击活动的性质，采取了适当措施并执行了必要的修复活动。情况将尽快回复正常。当然，集团也会向 X 提起刑事诉讼。”虽然 Swatch 集团并非进一步说明攻击详情，但很可能是一起勒索攻击。此前发生多起针对市值数十亿美元企业的勒索攻击活动，受害者包括 Luxottica、Universal HealthServices、AJG 以及 TylerTechnologies 等等。
