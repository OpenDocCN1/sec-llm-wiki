# 佳能内部文件遭公开

2020年8月5日，佳能被指遭 Maze 勒索团伙攻击。当时有人共享了勒索金部分信息以及佳能内部发布的员工通知信息。8月10日，佳能 IT 部门向员工发送服务恢复内容。

由于佳能在段时间内恢复了很多系统，因此 BleepingComputer 原以为佳能已支付勒索金。但实际上并非如此，因为 Maze 勒索团伙开始发布被盗数据，而这只有在赎金未支付的情况下才会发生。

  

![](../Images/a952033520d298210984bc3a1ef059b2.png)  
发布未加密文件  
  
  

  

Maze 在数据泄露网站上指出，他们正在发布5%的被盗佳能数据。

被发布的文档大小为2.2GB，名为"STRATEGICPLANNINGpart62.zip"，包含市场营销材料和视频以及和佳能网站相关的文件。

从 BleepingComputer 获得的少量样本来看，这些文件似乎确实属于佳能（美国）公司。审计了该文档的消息来源人士表示，文档内似乎并未包含任何经济信息、员工信息或其它敏感信息。

BleepingComputer 表示尚未独立验证该言论。

目前，佳能尚未置评。
