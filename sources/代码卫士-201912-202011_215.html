当前勒索软件似乎出现一种新迹象：勒索人员通过舆论施压、告发违规操作等手段迫使受害者就范。



企业的 MongoDB 库被删

Threatpost 报道称，22.9万个未设置密码保护且被暴露在互联网的 MongoDB 数据库遭黑客勒索。这些库占所有可联网访问MongoDB 数据库的约47%。
黑客使用自动化脚本扫描配置错误的 MongoDB 数据库，擦除数据库内容并勒索0.015个比特币（约140美元）。黑客要求在两天内付款，否则威胁泄露数据并向受害者当地的GDPR执法机构告发他们泄露数据。
黑客最早发出勒索留言（READ_ME_TO_RECOVER_YOUR_DATA）的时间是2020年4月。
GDI 基金会的一名安全研究员 Victor Gevers 表示，最开始的攻击活动并不包含数据擦除步骤。之前攻击者一直和同一个数据库联系并留下勒索留言，几天后再次留言。
但 Gevers 表示攻击者似乎意识到自动化脚本出了问题，因此从昨天开始更正了脚本而现在确实在删库。Gever 指出，“一切都不复存在了。”虽然其中依稀数据库似乎是为了测试实例，但 Gever 指出某些生产系统也遭攻击且数据被删。
Gever 在GDI 基金会的部分工作是向企业报告被暴露服务器的情况，他表示在今天早些时候检查 MongoDB 系统时发现了删库的情况，“今天我只报告一次数据泄露事件，在正常情况下我至少需要报告5到10次。”
最早发生在2016年年末
然而，这些“擦除并勒索MongoDB 库”的攻击并非新事。Gevers 今天发现的事件早在2016年12月就开始，当时黑客意识到能通过删库并勒索牟取暴利。单在2017年1月、2017年9月和2019年2月，就分别有2.8万、2.6万和3000个服务器遭勒索。2017年，MongoDB 公司的高级产品安全主管 Davi Ottenheimer 就指责数据库所有人未能设置数据库密码，导致数据库在没有防火墙的情况下暴露服务器。
几乎三年后，一切似乎都没有改观。从2017年早期的6万个到现在的4.8万个 MongoDB 服务器遭暴露，数量下降有限，而多数是因为没有启用认证造成的。多数时候，这些服务器被暴露在互联网的原因是管理员遵循了不正确的 MongoDB 配置手册，在配置系统时出错或者使用的服务器镜像中含有错误配置的 MongoDB 系统。
目前 MongoDB 数据库的默认设置是安全的，但尽管如此，出于各种原因，每天还是有数万个服务器被暴露在网上。服务器管理员应当到 MongoDB Security 页面获取正确的保护措施指南。
Securityweek 报道称，最近澳大利亚啤酒牛奶的大型供应商 Lion 遭勒索软件攻击。无独有偶，该媒体报道称数十家美国企业遭 WastedLocker 勒索软件攻击。LG 前段时间也被指遭勒索，源代码或被泄露。
而今天，该媒体报道称，美国打印巨头 Xerox 的系统遭入侵，Maze 勒索软件的幕后黑客威胁如收不到赎金则暴露被盗文件。



高校被迫暗网谈判

The Register 报道称，专注于开展公共健康研究领域的美国加州大学旧金山分校 (UCSF)  已向犯罪团伙 Netwalker交了114万美元的赎金，寄望于重新获得对数据的访问权限。
据BBC 报道称，一名“匿名密告”允许其“在暗网的某个实时聊天中跟踪勒索谈判流程”，从而获悉UCSF 的一名谈判代表曾出价78万美元购买解密密钥。UCSF 指出，恶意人员在6月1日“加密了医学院数量有限的服务器”，并指出正和外部专家“完全恢复受影响的服务器”。虽然UCSF正在研究新冠肺炎情况，但表示这项研究并未受影响，另外其附属的旧金山医疗中心医院的病患医疗记录和护理也并未受影响。
Emsisoft 公司的安全研究员 Brett Callow 表示，Netwalker 组织的多名“道德”犯罪分子指出将不会加入暗网并承诺不会攻击对抗新冠肺炎疫情的机构。BBC 表示所报道的内容截取自犯罪分子在谈判过程中的聊天记录。新闻媒体似乎也成为勒索团伙热衷的战术。一些犯罪团伙甚至在明网和暗网上放出被泄数据片段博得头条关注。

美国多地城市遭勒索


Bleeping Computer 报道称，6月份美国田纳西州的第三大城市 Knoxville 遭勒索，导致该城市的计算机网络全部被加密被关闭。而同样是6月份，媒体报道称阿拉巴马州佛罗伦萨市在今年5月份疑似遭受 DoppelPaymer 勒索软件感染，遭价值30万美元的比特币勒索。
如今，出现在媒体报道中的勒索事件层出不穷，但是否应交赎金也是众说纷纭。不少国家的政府表示不应交赎金，黑客的承诺并不可靠。但安全公司 SecureWorld发布《2020年钓鱼攻击现状报告》指出，2019年超过50%的勒索软件感染者决定支付赎金，且有近70%的人在支付赎金后找回了数据。不过也有超过20%的受害者支付了勒索金但却一无所获，之后有10%的勒索者要求再次支付赎金。我们需要认真思考如果支付后无法访问数据、支付后被勒索者标记为“付款者”分别会有哪些后果再谨慎行事。
