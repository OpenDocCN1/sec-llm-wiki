警惕！这个 PowerPoint“弱点”可用于发动鼠标悬停攻击

独立安全研究员 Mandar Satam 警告称，他发现一个新型攻击向量，可导致黑客操纵一份 PowerPoint 文件，仅通过悬停在超级链接上的方式就能下载并开始安装恶意软件。

该技术要求受害者接受一个弹出的会话框运行或安装程序。因此微软认为它并非漏洞，但 Satam 持相反态度。

Satam 表示，“攻击能够绕过 PowerPoint 关于无法向 HyperLink 动作增添远程文件的限制，如果我们尝试使用 GUI 添加则无法绕过。”他指出，包含该文件名的对话框文本可被操纵展示任意内容，包括 “Windows Update.bat”或 “Loading…Please Wait.exe”。

他通过该技术创建了 PoC 攻击，称该“弱点”存在于 PowerPoint 的 Open XML Slide Show 文件即 PPSX 中。这类 PowerPoint 文件仅用于演示回放，无法被编辑。在 PowerPoint 中，可能针对鼠标悬停设置动作。”他在 PoC 攻击“Hover with Power”演示中，绕过了微软在2017年实现的 PowerPoint 限制（旨在阻止PowerPoint 中的恶意链接仅通过悬停在超文本链接上的方式安装本地可执行程序）。这个旧漏洞已被修复，Satam 认为他发现的这个新“弱点”是其扩展，它使用的是 “HyperLink To” 动作而非 “Run Program” 动作，并指向“其它文件”。因此 PoC 攻击能够从远程服务器运行可执行文件，该远程服务器“是受攻击者控制的具有 WebDAV 扩展的 web 服务器。”这种类型的服务器允许执行远程内容编辑和读取。

他表示，“鉴于 SMB 连接在 Windows 10 中的运作方式，即使在支持 WebDAV 扩展的 webserver 由受害者托管的情况下 SMB 端口（445/139）被关闭，也有可能在互联网上连接 SMB。”Windows SMB 协议提供在网络上的文件分享、网络流量、打印服务和进程间通信功能。在 Satam 的 PoC 上下文中，它规避了对嘈杂 HTTPS 请求的依赖，使得终端用户无法获得关于恶意活动的警报。

Satam 在文章中指出，“如果 HTTP/HTTPS URL 是通过 PowerPoint 超链接动作连接的，那么操作系统就会使用系统上的浏览器下载该文件，这时 WindowsDefender/Smartscreen 就会干涉，表明该文件不可信；即使我们点击了运行按钮，该文件也会被隔离。”

由于 PoC 攻击仅触发一个弹出的可遭攻击者控制的对话框，因此 Satam 认为它是一个漏洞问题。然而，微软安全响应中心回复表示，由于攻击要求社工元素，因此并非漏洞。本文作者向微软求证也得到了同样的答复，“要使社工技术成功，用户必须首先采取措施应付该安全警告信息。我们建议客户践行良好的计算机使用习惯，包括电机网页链接时、打开未知文件或接收文件时格外注意。”
