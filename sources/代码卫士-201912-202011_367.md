# 惠普企业：自今年10月起，固件 bug 将导致某些 SSD 不可用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247492594&idx=4&sn=49ffa5e4267708bc73b6414626eecab0&chksm=ea94d298dde35b8eef1d56a344ae946136aaaa18f780d960da989d2ee26820d99cd29f52374b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247492594&idx=4&sn=49ffa5e4267708bc73b6414626eecab0&chksm=ea94d298dde35b8eef1d56a344ae946136aaaa18f780d960da989d2ee26820d99cd29f52374b&scene=27#wechat_redirect)

![](../Images/01bb601c1da5fc72107b997999383920.png) 聚焦源代码安全，网罗国内外最新资讯！**编译：奇安信代码卫士团队****上周，惠普企业**** (HPE) ****发布安全公告警告客户称，某些**** SAS SSDs****的固件中存在一个**** bug****，可导致****SSDs****在达到****4****万小时运营寿命（****4****年又****206****天又****16****小时）后不可用。**HPE 表示，通过对受影响 SSD 制造时间和出售时间的计算来看，首批不可用的 SSD 将出现在今年10月份。HPE 表示已在上周发布固件更新解决该问题。HPE 警告称如企业未能安装该更新，则面临 SSD 及其数据丢失的风险，而丢失后将不可恢复。这个 bug 和该公司在2019年11月披露的另外一个问题非常相似，后者也使 HPE SAS SSDs 永久不可用，不过寿命是32,768小时（3年又270天又8小时）。然而，受当前 bug 影响的 SAS SSD 型号要少得多。和去年一样，HPE 表示是从另外一个使用产品的 SSD 制造商获悉此事的。受影响的 SAS SSD 型号如下。HPE 表示某些型号以独立产品形式出售，而有些融合至其他 HPE 产品中如 HPE ProLiant、Synergy、Apollo 4200、Synergy Storage Modules、D3000 Storage Enclosure、StoreEasy 1000 Storage。

![](../Images/b9633b7aec8f19bd4e09ca232b9aafb4.png)

   
所有运行 HPE 固件版本 HPD7 以前的 HPE SAS SSD 均受影响。建议用户应用最新固件更新修复该问题，以免造成 SSD 不可用和数据丢失后果。
