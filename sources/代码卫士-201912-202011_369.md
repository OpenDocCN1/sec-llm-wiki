# GPU产品源代码被盗？AMD 证实称仅为测试文件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247492594&idx=2&sn=27e526ff731e1f9951a6248f843a87d0&chksm=ea94d298dde35b8e3f4e99d958db54656420feec1396f5842de76d913376f07b8329219964ca&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247492594&idx=2&sn=27e526ff731e1f9951a6248f843a87d0&chksm=ea94d298dde35b8e3f4e99d958db54656420feec1396f5842de76d913376f07b8329219964ca&scene=27#wechat_redirect)

![](../Images/01bb601c1da5fc72107b997999383920.png) 聚焦源代码安全，网罗国内外最新资讯！**编译：奇安信代码卫士团队**

**AMD ****证实称，黑客盗取某些图形产品文件，但表示并不过于担忧泄露带来的影响。**

该黑客使用的网络昵称为 “Palesa”，他声称已获取和多个 AMD 图形处理单元 (GPU) 相关的源代码文件，包括用于某些 Radeon RX 5000系列显卡、即将推出的 Navi 21 和 Arden产品的 Navi 10 架构。Arden 是GPUs的代号，将驱动微软即将推出的 Xbox 系列 X 控制台。

Palesa 表示，这些文件是从 AMD 的一台服务器中得到的，而非从承包商手中获取，他寄望于从 AMD 或其他人获得好处费。Palesa 声称已经得到一些“以比特币交易的不错的提价”，从5万美元到10万美元不等，但他们正在等待“AMD的态度”。

AMD 在网站上表示，这些被盗文件是“和当前及未来图形产品子集相关的测试文件”。该公司表示早在2019年12月就有人联系称掌握这些文件。

Palesa 最近在 GitHub 上发布了某些被盗文件，但GitHub 根据AMD 提出的 DMCA 法规要求将其删除。GitHub 上仍然存在一些被盗文件的截屏，该黑客承诺将向有兴趣的买家发送证据。

![](../Images/468357cfc7eeb11b26e84b3a50493d2b.png)![](../Images/5fcf8d29801d58988336626d3821626b.png)AMD 表示，“我们已经了解到罪犯掌握了一些尚未公开的其它文件，我们认为被盗图形知识产权并未构成我们的核心竞争力或威胁到图形产品的安全。我们未发现罪犯掌握其它 AMD 知识产权的证据。我们正在密切和执法官员和其它专家进行沟通，合力调查这起犯罪事件。”
