受新冠病毒影响，谷歌延迟发布 Chrome 和 Chrome OS 安全更新版本

谷歌表示，受新冠病毒 (COVID-19) 的影响，暂停发布 Chrome 和 Chrome OS 新版本。
谷歌表示，“工作安排调整”是延迟发布的主要原因，因为目前多数工程师是远程工作。
关于 Chrome 新版本的发布宣传视频昨天出现在 YouTube 视频、推特和博客文章中，但实际上 Chrome v81 尚未出现在用户设备上，之后这些宣传视频被删除。
多名谷歌员工表示，由于受新冠病毒的影响，一些负责和新版本错误或其它问题相关工作的工程师无法到位，因此版本发布延迟。
今天，Chrome 给出了官方声明称，

由于当前工作安排调整，我们将暂停发布 Chrome 和 Chrome OS 新版本。我们的主要目标是确保它们是稳定的、安全的以及可靠的。我们将继续优先处理和安全相关的任何更新，且将包含在 Chrome 80 中。请关注我们的博客获取更新消息。

当前，谷歌计划发布所有的 Chrome 81 安全更新，作为 Chrome 80的次要版本发布，并暂停其它重大稳定版本发布，直至情况好转。
这一决定情有可原，毕竟 Chrome 是全球使用范围最广的软件应用之一，即使是微小的错误也可能为数千用户和组织机构带来问题。比如2019年11月就曾因为 Chrome 版本的一个小变化（推出实验性功能 WebContents Occlusion）导致无法想象的灾难（用户和企业遭遇白屏错误）。
谷歌原本计划在昨天（当地时间3月17日）发布 Chrome 81 版本，本打算增加对 WebXR（Chrome 的增强现实功能）支持、弃用 TLS 1.0 和 TLS1.1 加密协议、以及增加对 Web NFC 标准的初始支持。
