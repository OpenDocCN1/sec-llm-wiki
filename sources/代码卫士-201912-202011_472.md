# 世界上哪个大洲觉得自己遭受的国家黑客攻击最多？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247492182&idx=2&sn=e38824fd4820cad6ae3e74e9c55f3657&chksm=ea94d33cdde35a2a7bc235289b4d7c8d2a656c530a1d6fc02d4398439ebb8b73efe48bf232cf&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247492182&idx=2&sn=e38824fd4820cad6ae3e74e9c55f3657&chksm=ea94d33cdde35a2a7bc235289b4d7c8d2a656c530a1d6fc02d4398439ebb8b73efe48bf232cf&scene=27#wechat_redirect)

**编译：奇安信代码卫士团队****Radware ****公司发布最新的《全球应用程序和网络安全状况》报告指出，在全球各行各业的****561****名受访者中，****27%****认为自己所在的公司于****2019****年遭国家黑客攻击，比****2018****年上升****42****%，而2018年仅有****19%****的受访者表示自己遭遇此类攻击。**随着攻击归因的挑战越来越大，加上国家黑客和犯罪黑客之间的界限越来越模糊，这些比例很容易站不住脚。尽管如此，这项调查说明规模不一的组织机构都认为国家黑客攻击的威胁很严重。报告指出，北美洲的组织机构更容易报告称自己遭到了外国政府的攻击，占比36%。Radware 公司的首席市场营销官 Anna Convery-Pelletier 指出，“国家入侵是最难以抵御的攻击类型之一，因为它们通常手握重要资源、通晓潜在的0day 利用，而且有耐心规划并执行操作。”虽然94%的受访企业机构认为自己在2019年遭受了网络攻击，但其中三分之一的受访者表示每天或每周都会遭一次国家黑客攻击。这项调查并未详细说明这些攻击的复杂程度或严重性。教育(45%)、零售(39%)和银行业以及金融服务(37%) 是日常报告遭攻击的行业。再次申明，这些数字可能是不准确的，因为有些人会将简单的端口扫描或非针对性垃圾邮件/钓鱼邮件视作攻击。话虽如此，大约三分之一的称自己遭到攻击的企业表示黑客是为了获取经济利益或破坏服务。然而，五分之一的受访者表示黑客的目的是窃取信息。去年，勒索攻击最常发生，比2018年增长了16%，回到了2017年的水平。北美地区的组织机构表示勒索是攻击者的最佳动力，占比70%。报告指出，和全球平均水平相比 (28%)，EMEA（欧洲、中东和非洲）地区的黑客主义动机更加盛行，占比38%，而APAC（亚太）地区认为愤怒的用户报复动机最强，占比30%，高于全球平均水平20%。报告还指出，恶意软件和僵尸网络在2019年最流行，占所有攻击数量的72%，其次是社工，占比65%。报告指出，48%的受访者经历了拒绝服务攻击，46%的受访者遭遇了 web 应用程序攻击，39%的受访者遭遇了勒索攻击，21%的受访者遭密币挖矿机攻击，而17%的受访者遭到 API 滥用攻击。报告还证实了攻击缺乏可见性的情况：38%的受访者表示并不知晓物联网僵尸网络是否攻击了自己的网络，而46%的受访者无法确定是否遭到 DDoS 攻击。调查显示，仅有26%的受访运营商表示认为做好了部署 5G 网络的准备，而32%表示只在某种程度上做好了一定的准备。报告还指出，30%的企业表示攻击引发的数据窃取是他们最关心的问题（去年该比例是35%），而23%的企业表示服务中断是最为担心的问题。Radware调查的组织机构规模不一且行业各异，包括政府和公众服务业、银行业和金融业、服务提供商/运营商、高科技行业和专业服务行业。受访者来自北美(45%)、亚太(28%)、EMEA(16%)和中美/南美 (11%)。
