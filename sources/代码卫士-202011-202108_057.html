Akamai 公司正在调查一起断网事件，它导致很多大型网站和在线服务如 Steam、PlayStation Network、Newegg、AWS、亚马逊、谷歌和Salesforce 宕机。


虽然Akamai 已证实是 Edge DNS 服务问题，但仍然还在寻找底层原因，“我们发现 Edge DNS 服务正在出现的问题。我们正在积极调查该问题。如果有任何疑问或者因该问题遭受影响，请立即联系 Akamai 技术支持服务“，并表示将及时更新动态。

Akamai 公司表示，Edge DNS 是其基于云的官方 DNS 解决方案，旨在提供全天候 DNS 可用性并改进 DNS 响应性。Akamai 公司证实了该问题并表示将及时更新动态。

目前，该公司已修复该问题，服务有望恢复，并表示本次断网并非网络攻击造成，而是“软件配置更新触发了DNS系统中的一个漏洞，从而使某些客户网站的可用性受影响。这次破坏持续了1个小时，回滚到软件配置更新后，该服务恢复正常”。

上个月，Fastly CDN 的服务器断网，大量网站和在线服务受影响。
