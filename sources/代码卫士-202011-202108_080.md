# 伊朗国家铁路系统遭攻击，最高领导人电话被公布

上周五早上，伊朗国家铁路公司的计算机系统遭网络攻击，火车站公告板显示虚假信息表示列车取消或延误。

  

目前该攻击的性质尚不清楚，但同时影响客运和货运服务。多家本地媒体报道称，用于管理列车日程和购票服务的系统在当地时间上周五早上宕机。公告板显示某些预定发车的列车被取消或延误。某些火车站给出伊朗最高领袖阿亚图拉·赛义德·阿里·哈梅内伊的 电话号码并让旅客拨打以获取更多详情。

最初，伊朗伊斯兰共和国铁路部和公路和城镇发展部的发言人在向本地媒体发布的声明中否认了网络攻击的传闻，但实际上某些车站公告板已被明显涂鸦。官方称该事件是技术问题并表示，截至当地时间晚7点客运和货运火车正常运行，尽管有一些延误情况，但表示这是因为员工手工管理时间安排导致的。

然而，网络出现公路和城镇开发部的被黑计算机截屏后，伊朗官方在当地时间周六证实攻击存在。

2020年5月，黑客（之后据称和以色列政府有关）破坏了伊朗霍尔木兹海峡最大港口阿巴斯港的日常运营。该攻击发生在以色列指责伊朗国家黑客试图干涉其水处理系统后。
