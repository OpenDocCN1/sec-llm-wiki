# 全球约30%的智能手机受高通新漏洞影响，打补丁状况不明

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247504006&idx=2&sn=5e3be0f6a913cde1548583ff6f77c3d2&chksm=ea94e1ecdde368faafea7d5c9e878dd3938c91343788cb8e7241a4c977e403ccdec05f49808e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247504006&idx=2&sn=5e3be0f6a913cde1548583ff6f77c3d2&chksm=ea94e1ecdde368faafea7d5c9e878dd3938c91343788cb8e7241a4c977e403ccdec05f49808e&scene=27#wechat_redirect)

**编译：奇安信代码卫士**

  

高通调制解调器组件中存在一个新漏洞，影响全球三成左右的智能手机。该漏洞可导致攻击者访问设备的通话记录和 SMS 历史，甚至可访问音频会话。

该漏洞的编号是 CVE-2020-112921，存在于高通移动站调制解调器 (MSM) 中。MSM 芯片的作用是允许黑色被连接至移动网络。该芯片首次在20世纪90年代设计，多年来一直更新以支持2G、3G、4G和5G蜂窝通信，并逐渐成为全球最普遍使用的技术，尤其受智能手机供应商的青睐。

当前使用高通 MSM 芯片的设备包括谷歌、三星、LG、小米和一加等制造的高端机型中。

  

![](../Images/cdadf8d4c60c8ecf0cea7b76f85d965d.png)影响 MSM OMI 协议![](../Images/b6d1fefff0dee361ecf9ca8b335d6932.png)  

  

以色列安全公司 Check Point 发布报告指出，在 MSM 接口 (QMI) 中找到了一个漏洞。QMI 是允许芯片和智能手机操作系统进行通信的协议。研究人员指出，MSM 组件通过 QMI 接口接收到的畸形 Type-Length-Value (TLV) 包可触发内存损坏（缓冲区溢出）漏洞，使攻击者运行自己的代码。

研究人员解释称，“在调查过程中，我们在调制解调器中发现了一个漏洞，它可被用于控制该调制解调器并从应用程序处理器动态打补丁。这意味着攻击者可以利用该漏洞将恶意代码从安卓注入调制解调器中，使其访问设备用户的通话历史和 SMS并监听设备用户的会话。黑客还能利用该漏洞解锁设备的 SIM，从而绕过服务提供商设置的限制条件。

研究人员指出，如果将畸形 TLV 包隐藏在运行该操作系统尤其是运行安卓操作系统（MSM 组件受 SELinux 安全策略保护）的第三方应用内，则无法利用该漏洞。然而，研究人员发现 TLV 包可隐藏在发送到设备的射频（蜂窝）通信或多媒体内容中，如解压则可触及易受影响的 QMI 接口中。

  

![](../Images/cdadf8d4c60c8ecf0cea7b76f85d965d.png)补丁状态未知![](../Images/b6d1fefff0dee361ecf9ca8b335d6932.png)  

  

之前开展的市场调查显示，虽然当前约40%的智能手机使用高通 MSM 芯片，但仅有约30%的智能手机具有 QMI 接口并易受该攻击。

研究人员表示，早在去年就将该漏洞告知高通公司，后者向下游手机制造商发布了 MSM固件修复方案。

Check Point 公司的一名发言人表示，“移动供应商自身必须应用该修复方案。高通表示已经通知了所有安卓供应商，但我们并不了解哪些厂商发布了补丁。”高通公司的一名发言人指出在去年12月通知了所有厂商，但同样并不了解应用补丁的厂商有哪些。

这并非安全研究员首次发现高通芯片中的安全问题。2020年8月，Check Point 公司在 Digital Signal Processer芯片集中发现了400多个安全漏洞。2019年8月，腾讯发现了两个漏洞 QualPwn，可导致威胁行动者滥用高通芯片攻陷安卓操作系统内核。2019年4月，研究人员发现一个漏洞可导致攻击者检索存储在高通芯片集 (QSEE) 安全区域中的私密数据和加密密钥。
