印度研究员 Aman Rai 通过 CVE-2018015473 找到一个高质量的 RCE 漏洞并获得赏金，如下是具体步骤：


1、 找到公司的 IP 地址，如该公司是 testing.com。之后从如下地址克隆 CVE-2018-15473：

https://github.com/Rhynorater/CVE-2018-15473-Exploit/blob/master/sshUsernameEnumExploit.py


2、 运行命令：

/sshUsernameEnumExploit.py --username root 0.0.0.0 (ip)


之后发现输出是具有 root 权限的一名合法用户。因此需要找到其它用户。通过公司的 LinkedIn 材料发现有5名员工，其中一名是名为 test 的开发人员。

3、再次运行以上命令，用户名为 test。结果发现 test 是一个合法用户。

4、 如果密码是弱密码或常见密码，则可暴力破解；或者运行查询语句 user:test 从 github 中查找该用户。

5、结果找到一个密码（abc1），不过主机和我们的目标无关。这么看来，开发人员有时候也会在多个域名使用同一个密码。

6、 于是，尝试以 “putty” 登录，用户名为test，密码为 abc1，结果登录到了服务器。

7、 最终找到一个高质量的 RCE。虽然花了几天的时间，但回报丰厚。
