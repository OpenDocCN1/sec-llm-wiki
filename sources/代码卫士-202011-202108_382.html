拥有开源安全背景的开发员当选白宫技术总监

美国当选总统乔·拜登 (Joe Biden) 的交接团队宣布 Openld 和 oAuth 的开发人员之一 David Recordon 被任命为白宫技术总监。Recordon 最近的一份工作是担任非营利性组织 Chan Zuckerberg Initiative 基金会的基础设施和安全副总裁。




在此之前，Recordon 是 Facebook 公司的工程师总监，牵头组织了该公司的一系列开源计划和项目。其中 Phabricator （一款代码审计 Web app 套件）就是其中一个项目，Facebook 以用于自身的开发。他还牵头Apache 开源分布式数据库管理系统 Cassandra、HipHop （从 PHP 到 C++ 源代码的翻译器）以及软件框架 Apache Thrift，用于可扩展的跨语言服务开发工作。简言之，他同时兼具程序员和管理层的身份，并且是开源行业的行家。

Recordon 从公里小学学习了如何编程。交接团队指出，在近20年的生涯中，他的工作一直在和技术、安全、开源软件、公共服务和慈善服务打交道。

Recordon 在谈到新岗位所面临的挑战时指出，“疫情和正在进行的网络安全攻击虽然为整个总统行政办公室带来了新挑战，但这些挑战是团队可以携手一起以安稳且安全的方式解决的。”

实际上这并非 Recordon 首次任职白宫。在奥巴马执政期间，他是首任白宫信息技术总监，当时主要负责 IT 现代化和网络安全问题。同时他还担任交接团队的副首席技术官。

Recordon 将面临巨大挑战。由于现任总统特朗普不重视技术和科学，他将不得不重建技术基础。另外，Recordon 还将需要处理网络中立、Big Tech 业务监管、宽带扩展以及美国政府如何抓住下一代技术如面部识别、人工智能和预测性分析等。

某些人将会因为 Recordon 的 Facebook 工作背景而心生不满，但实际上消息来源人士指出，“David 是好人，他很懂技术而且知道如何调动大家的热情并凝聚人心，他将十分出色。”
