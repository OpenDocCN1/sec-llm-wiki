本文作者提到了网络安全企业对2021年的安全趋势预测，它们预测的共同趋势如下。另外，作者还单列出21家大厂（McAfee 当时尚未发布，因此未包含）的预测。如下是对该文章的节选编译，更多详情可见文末的原文链接。  
  
![](../Images/795cade23d13bb5b1d487fd4cea4c50d.png)01左中括号一致的趋势预测左中括号

  

1、新冠肺炎疫情催生的远程工作态势将产生巨大影响。家庭计算机和网络将遭到更多的攻击，恶意人员甚至通过利用未修复系统和架构弱点将家庭办公室当作犯罪中心。

2、匆忙迁到云将引发很多安全漏洞、挑战、配置不当和宕机事件。

3、安全行业将获得更快增长。新产品和新一年的并购活动将引发多种网络复杂度问题、集成问题，导致网络团队应接不暇。

4、隐私将一团糟，伴随着用户的对抗、新法律的颁发、困惑和自我规范的失败。

5、随着密码最终开始退出，进入拐点，身份和多因素验证 (MFA) 机制将登上中心舞台。

6、高级别的物联网攻击活动将涌现，其中一些将称为头条新闻。

7、勒索软件将变得越发强劲——不断催生新手段、加密前窃取数据、打包其它威胁的恶意软件以及非常特定的企业目标。

8、随着 5G 技术的发展，很多 5G 漏洞将登上新闻头条。

9、APT 组织的攻击活动将增多。暗网使得犯罪分子可以购买敏感企业网络的访问权限。

10、包括手机在内的移动设备将遭到新型攻击，应用商店也如此。

11、密币将扮演新的角色，将为犯罪分子所用。

12、随着数字化改革项目的增多，随着安全挑战的增多，很多规划将不堪重压而崩溃。

1、  **趋势科技**重点强调的安全预测趋势包括：

*   威胁行动者将把家庭办公室变为犯罪活动中心。
    
*   远程工作态势将强制企业面临混合的环境和不可持续的安全架构。
    
*   攻击者将快速将新发现的漏洞标准化，导致用户打补丁的窗口期缩短。
    
*   被暴露的 API 将成为犯罪分子攻陷企业的下一个最爱的攻击向量。
    
*   用于远程工作的企业软件和云应用程序将布满严重级别的bug。

**5、****卡巴斯基实验室**：作者认为卡巴斯基实验室虽然提供了很多关于网络威胁方面的威胁报告、详细的风险分析等等，但针对的受众范围广泛。这样做可能是为营销服务，但也是造成在本文排名靠后的原因所在。不过作者还是归纳了所有这些报告的精髓：  
（1）高阶威胁预测

*   APT 威胁行动者将从网络犯罪分子购买初始的网络访问权限
    
*   越来越多的国家将通过法律起诉书作为网络战略的一部分
    
*   越来越多的硅谷企业将采取措施应对0day 经纪人或组织
    
*   网络设备遭受的针对性攻击越来越多
    
*   5G 漏洞的出现
    
*   “威力”索要钱财
    
*   更多的破坏性攻击
    
*   攻击者将继续利用新冠肺炎疫情
    

(2) ICS-CERT 威胁预测

*   随机感染——“随机感染的情况将减少或小时，因为过去几年来，网络犯罪分子已经在配置连接到工业网络或能够定期访问这些网络的随机感染计算机。网络犯罪分子将或可能已经被转售给更高阶的组织机构，这些机构具有将工业设备攻击变现的具体计划。”
    
*   勒索软件攻击——“勒索软件在技术上更加高阶并成熟。网络犯罪分子将继续利用黑客和 APT 技术，极力探索并探测目标组织机构的网络，定位最具价值/易受攻击的系统、劫持管理员账户并使用标准的管理员工具发动突袭。我们很可能能会看到伪装成勒索软件的攻击但实际上它们的目标迥然不同——是对 ExPetr 技术的重复。”
    
*   网络间谍——“网络犯罪分子将明白（其中一些已明白）在 OT 边界中，机密信息受到的保护力度没有办公网络中大，而且 OT 网络可能更易被攻破，因为它们具有自己的边界和攻击面。”
    
*   APT——“APT 组织的数量将持续增长——我们将看到越来越多的入局者，包括攻击多种工业行业的入局者。除了数据窃取和其它零散操作外，某些组织可能会在2021年参与危害程度更高的活动，可能跟随 Stuxnet、Black Energy、Industroyer 和 Triton 的步伐。
    
*   新冠疫情的后果——“不同于经济形势走低、裹步不前、增长放缓以及对小型企业造成的损害，网络犯罪分子的规模将增长，因为技术高超的人会另寻工作而和国家政府存在关联的组织实力也将增强。城市服务和公用设施的联网以及政府及公共服务不断增长的数字化将使其更易遭攻击，且使得针对相关中央和地方政府功能和系统的跨机构攻击获得更多机会。例如，威胁行动者可利用政府或城市 Web 服务当作入口点，攻陷受害者的内部基础设施并利用通信信道和利用链接各政府、城市甚至是私营组织机构抵达最终目标的供应链（例如关闭交通系统）“
    

（3） 最后是针对金融机构的网络威胁预测

*   加大镇压网络犯罪活动的力度，比如通过经济制裁等形式。
    
*   犯罪分子可能通过密币实施勒索，可能会转向隐私性增强的货币，如门罗币。犯罪分子可能首先会使用这类密币当作交易货币，之后将资金转移到其它所选密币如比特币。
    
*   勒索活动在增多。网络犯罪分子将以某种勒索方式攻击金融资产，若不是勒索攻击的形式，则有可能是 DDoS 攻击的形式或二者兼而有之。
    

  

**6**、**Check Point **主要分三个方面提供了预测：和疫情相关的开发，恶意软件、隐私和网战，以及5G 新技术和IoT平台。

（1）   和疫情相关的开发预测

*   保护“下一个常态”：2021年，新冠疫情将仍然影响我们的生活、企业和社会，但随着时间的发展这些影响将发生变化。因此当我们应对这些变化时要做好准备迎接一系列“下一个常态”。
    
*   和疫情相关的 exploit 无解：随着疫情继续主导头条资讯，与之相关的疫苗进展或新的国家限制将继续被用于钓鱼攻击活动中，和2020年将无差别。
    
*   在家远程学习：来年，攻击将继续破坏远程学习活动
    

（2）   恶意软件、隐私和网战

*   双重勒索将增加勒索软件的风险
    
*   僵尸网络军队将继续增多
    
*   国家之间将爆发网络战争：民族国家发动的网络攻击活动将持续增多，或者是实施间谍活动或者是影响其它国家的活动
    
*   将 deepfake 武器化
    
*   隐私？隐私无处可逃
    

（3）   5G 新技术和 IoT 平台：

*   5G 的好处和挑战：5G 技术带来的全连、高速世界将使犯罪分子和黑客有机会发动攻击并通过针对该连接造成破坏。电子健康设备将收集关于用户健康、联网汽车服务将监控用户的活动轨迹而智慧城市应用程序将收集关于用户如何生活的信息。
    
*   威胁联网：随着5G的退出，联网 IoT 设备的数量将大幅增长，极大地增强了网络易受大规模、多向量网络攻击的可能性。

*   为应对预算减少的情况，首席安全官和首席信息安全官将融合多种解决方案
    
*   医疗行业的安全事件将造成致命影响
    
*   金融机构会意识到面临更多的攻击活动
    
*   疫情迫使组织机构加快数字化转型的脚步
    
*   新技术的采用以及互联网用户的增多意味着世界多数人口都面临巨大的数据暴露风险

*   更多的开发人员将转移到应用安全的前线
    
*   DevOps 团队将通过安全合作伙伴看到威胁建模的价值
    
*   疫情期间的云采用将提速，将深刻改变软件安全的局势
    
*   随着智能网络安全的出现，网络安全将走出黑暗年代

*   无服务计算成为网络犯罪分子的乐园
