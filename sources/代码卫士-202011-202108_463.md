# 亚马逊 AWS 大宕机，大量互联网服务无法使用

亚马逊的互联网基础设施服务 AWS 是很多网站和应用的“主心骨“，目前已处于宕机状态且已达数小时时间，影响大部分互联网。截止到太平洋时间周三下午11:43（北京时间周四下午3:43），服务仍未恢复。从当前亚马逊发布的更新通告来看，事件仅影响北美地区，其它区域不受影响。

  

![](../Images/68597cad6bc5705a9353246b61c7efd7.png)

  

  

当前，亚马逊在 “AWS 服务健康板“ 中更新了对美国东部1区内的 Kinesis Data Streams API 和其它依赖服务的情况，“目前，我们已经完全缓解对负责处理入站请求的 Kinesis 内部的子系统的影响，错误率或延迟率不再上涨。然而，我们尚未获得全部流量加载，正在努力降低对服务的要求限制。在接下来的数小时内，我们将把这些限制因素放宽到先前的水平。我们期待之后客户服务恢复正常。”

CloudWatch 指标在美国东部1地区仍处于延迟状态。将 Kinesis 的限制恢复到之前水平后，我们将恢复 CloudWatch 指标的功能。我们希望在该阶段会看到新入站指标的 CloudWatch 指标恢复，不过指标的挤压可能会增加额外的填充时间。“

亚马逊表示将持续更新最新进展。

当前，受影响的服务包括：ACM、 Amplify Console、 AppStream2、 AppSync、 Athena、 Batch、 CodeArtifact、 CodeGuru Profiler、 CodeGuru Reviewer、 CloudFormation、 CloudMap、 CloudTrail、 Connect、 Comprehend、 DynamoDB、 Elastic Beanstalk、 EventBridge、 IoT Services、 Lambda、 LEX、 Macie、 Managed Blockchain、 Marketplace、 MediaLive、 MediaConvert、 Personalize、 RDS Performance Insights、 Rekognition、 SageMaker 和 Workspaces。

  

![](../Images/3b5e2d6355a4bc7d96055018a9f96ec9.png)多款服务受影响  

  

多款app、服务和网站表示受 AWS 宕机事件影响，包括：1Password、 Acorns、 Adobe Spark、 Anchor、 Autodesk、 Capital Gazette、 Coinbase、 DataCamp、 Getaround、 Glassdoor、 Flickr、 iRobot、 The Philadelphia Inquirer、 Pocket、 RadioLab、 Roku、 RSS Podcasting、 Tampa Bay Times、 Vonage、 The Washington Post、 和WNYC。Downdetector.com 网站上也出现了用户报错报告激增的情况。

AWS 是全球使用最广泛的云计算服务之一，因此任何问题都会对其它 Web 服务和应用造成重大涟漪影响，正如当前很多家企业服务受影响的状况所示。

**最新更新：**  

亚马逊发布最新进展时指出，“我们已经恢复了所有端点的 Kinesis Data Streams，并且已经解决了调用 CloudWatch API 的错误率问题。我们正在持续密切监控 Kinesis，努力全面服务所有服务。我们已找到 Kinesis Data Streams 事件的根因，并已立即采取措施阻止类似事件的再次发生。Kinesis 和 CloudWatch 目前运行正常。
