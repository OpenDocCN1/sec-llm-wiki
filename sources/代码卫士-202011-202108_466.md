# cPanel 被指存在 2FA 绕过漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247497950&idx=2&sn=dc73a8996deda6bcb41f04f353a00afe&chksm=ea94c9b4dde340a247f2d5ce588a9ee61d63b982704bc0b1e1b0a8dddd3d3d70946b0da9e279&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247497950&idx=2&sn=dc73a8996deda6bcb41f04f353a00afe&chksm=ea94c9b4dde340a247f2d5ce588a9ee61d63b982704bc0b1e1b0a8dddd3d3d70946b0da9e279&scene=27#wechat_redirect)

Digital Defense 公司的安全研究员在供Web 托管企业管理客户网站的流行软件套件 cPanel 中发现了一个严重缺陷。它可导致攻击者绕过 cPanel 账户的双因素认证（2FA）机制。![](../Images/4911447d2ad4e7e1abb23956dadce4ba.png)

  

网站所有人使用给这些账户访问并管理网站及底层服务器设置。这些账户的访问权限非常重要，因为一旦被攻陷，就可导致攻击者完全控制受害者站点。

cPanel 网站指出，其软件已用于数百家 Web 托管企业中，管理全球超过7000万个域名。

Digital Defense 公司刚刚发布新闻稿称，老旧 cPanel & WebHost Manager (WHM) 软件上的 2FA 实现易受暴力攻击，可导致恶意人员猜测 URL 参数并绕过 2FA，前提是账户启用了 2FA。虽然通常来讲，暴力攻击需要数小时甚至数天的时间执行，但在这个案例中，实施攻击只需数分钟即可完成。利用该漏洞虽然要求攻击者拥有目标账户的有效凭据，但可通过钓鱼网站所有人获取这些凭据。

虽然某些网站所有人认为该 bug 并不重要，但实际上正好相反，因为2FA解决方案出现之初就是为了保护用户的凭据不受钓鱼攻击，因此任意类似于该 bug 的2FA 绕过均应引起重视。

好在 Digital Defense 已私下报告该漏洞，并已获编号 SEC-575。cPanel 团队已在上周发布补丁。

在 cPanel 登录中使用 2FA 的网站所有人可通过查看平台的版本号，查看自己的 Web 托管提供商是否已发布 cPanel 安装程序的更新。

cPanel 发布安全公告指出，2FA 绕过问题已在 cPanel & WHM 软件 11.92.0.2、11.90.0.17 和11.86.0.32 中修复。

用户不应因该漏洞就禁用 cPanel 账户的 2FA 机制，而是应该要求 Web 托管提供商将 cPanel 的安装程序更新至最新版本。
