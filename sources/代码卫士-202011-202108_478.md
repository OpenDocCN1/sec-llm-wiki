# 50款苹果 app享特权：可绕过macOS Big Sur 防火墙和VPN

上周，苹果介绍了其下一代操作系统 macOS Big Sur，它带来了一系列 Mac 新功能。然而，它同时被指存在一个问题，可导致苹果应用绕过防火墙和VPN。  
知情但未修复![](../Images/2ef403d613179ebbcb326538f16799b5.png)![](../Images/d88b326e8c328b2e5b5a0b13e3c2b049.png)  
该隐私问题首先在上个月的 macOS Big Sur 测试版被发现。然而，苹果并未在公开版本中将其修复。该macOS Big Sur 更新据称应用到某些更老旧的 MacBook Pro 机型中。就其 Gatekeeper 安全功能引发的隐私担忧问题，苹果公司的回应引发了一些舆论。上个月，昵称为 @mxswd 最先在早期的 macOS Big Sur 测试版本中发现了防火墙绕过问题。当使用苹果自家的应用如 Apple Maps 时，该问题可导致系统绕过防火墙和 VPN。他指出，“某些苹果应用绕过一些网络扩展和 VPN App。例如 Maps 就可以直接访问互联网，绕过所运行的任意 NEFilterDataProvider 或 NEAppProxyProviders。”![](../Images/9c19ca6d23e64409cdd417493182896a.png)  
Maxwell 的推文引发大量讨论以及对苹果公司的控诉。苹果一直以来因用户隐私和产品整体安全性而自豪，但在公司的隐私策略和对客户以及合作伙伴的隐私策略方面采取了双标做法。安全研究员 Patrick Wardle 确认了该问题。Wardle 发布推文表示，“之前，可通过网络内核扩展 ( Network Kernel Extension, kext) 来实现全面的 macOS 防火墙。苹果弃用了 kext 并给出 Network Extensions，但显然自家的很多 app/守护进程绕过了该过滤机制。”Wardle 发现，基于macOS Big Sur 的 Mac App Store 绕过防火墙。专注于苹果产品的博客论坛 Apple Term 详细说明了测试版中的这些问题。当时，人们认为苹果公司在发布 Big Sur 更新时会修复该问题。然而，事实并非如此。  
易遭恶意软件滥用![](../Images/2ef403d613179ebbcb326538f16799b5.png)![](../Images/d88b326e8c328b2e5b5a0b13e3c2b049.png)  
苹果的 NEFilterDataProvider 供应用程序防火墙和 VPN 根据每个 app 的不同过滤流量。绕过 NEFilterDataProvider 导致 VPN 难以拦截苹果自家应用。更糟糕的是，研究人员认为绕过可导致系统易遭攻击。Wardle 指出，绕过防火墙和VPN的问题仍然存在于稳定版中，可被恶意软件滥用，影响最新的 macOS 版本用户的安全。Wardle 指出，“在 Big Sur 中，苹果免除自家 app 通过一些框架路由，而现在要求第三方防火墙（LuLu、Little Snitch等）使用这些框架。这样做是否也会被恶意软件滥用，绕过防火墙？”他自问自答道，“答案不言而喻，是的。而且不费吹灰之力！”![](../Images/b85eee20e2ada9d53c887e3da809185d.png)  
他通过一张简单的图表说明了恶意软件如何可将 app 中的数据直接发送到互联网而不使用防火墙或 VPN 首先来判断流量是否合法的方式利用该问题。

双标做法引不满![](../Images/2ef403d613179ebbcb326538f16799b5.png)![](../Images/d88b326e8c328b2e5b5a0b13e3c2b049.png)  
另外，Wardle指出，苹果公司似乎知道允许该功能出现在最终 OS 版本中所带来的危险。苹果支持文档中强调了出于隐私和安全原因考虑，给予OS监控和过滤网络流量的重要性。![](../Images/e5cb2fa9fc987af6790197f823366f2e.png)确实，苹果公司最近指出，其硬件和设备应用的开发人员必须披露数据是如何和任意“第三方合作伙伴”共享的，包括分析工具、广告网络、第三方 SDK 或其他外部供应商。此举是在收到关于过度授权应用收集、使用并共享用户私人信息的投诉后做出的。Momentum Works 公司的开发人员兼高级工程师 Sean Parsons 表示，“对他们自己是一套规则，对其余农民是另一套。”  
50款苹果 app 享特权![](../Images/2ef403d613179ebbcb326538f16799b5.png)![](../Images/d88b326e8c328b2e5b5a0b13e3c2b049.png)  
昵称为 Dok 的开发人员表示，“我们发现大约50个苹果进程的流量无法被 NEFilterDataProvider 看见和控制，这是由苹果未公开的排除清单造成的。这是从 NKEs 的倒退。我们认为这样做存在很多缺点，而且我们已了解到它对终端用户带来负面影响。“苹果公司对 NEFilterDataProvider 的描述是：![](../Images/5c2158623a218e985dda467ba5047fa9.png)网络内容以 NEFilterFlow 对象的形式提交给 Filter Data Provider。每个 NEFilterFlow 对象都和由设备上运行的应用程序打开的网络连接相对应。Filter Data Provider 收到新的流时可选择通过或拦截数据，或者可以要求系统在做出传递或拦截的决策之前在出站或进站方向中看到更多流数据。  
除了传递或拦截网络数据外，Filter Data Provider 还可告知系统，在做出关于某种特定数据流的决策之前需要更多信息。该系统之后要求 Filter Control Provider 更新当前规则并将其放在可从 Filter Data Provider 扩展可读取的磁盘位置。  
苹果尚未就此事置评。  
MacBook Pro 旧版本变砖![](../Images/2ef403d613179ebbcb326538f16799b5.png)![](../Images/d88b326e8c328b2e5b5a0b13e3c2b049.png)  
除了绕过防火墙和VPN的问题外，MacOS Big Sur 似乎还存在一些问题，可导致某些老旧的 MacBook Pro 版本不可用。媒体MacRumors 报告称，使用2013年后期和2014年中期的13英寸大小 MacBook Pro 的多名用户表示最新的 macOS 更新使机器不可用。受影响的用户表示在更新至 macOS Big Sur 期间，机器出现黑屏，进而导致硬件不可用。其中一名用户表示工程师拔掉 I/O 板后启动了受影响的一台 MacBook Pro。该用户指出，“我不确定苹果公司将如何处理该问题，尤其是在受影响 Mac 已过维保期的情况下。我也不确定是否可通过软件更新的方式解决这些问题，因为 Big Sur 引发的问题似乎是硬件问题。“据称，苹果公司已获悉该问题并提给苹果支持团队。然而，目前尚未告知用户该问题是否可通过软件更新的方式解决。因此，使用老旧版本的 MacBook Pro 用户最好推迟安装 macOS Big Sur，以免机器变砖。上周，一些用户表示，macOS Big Sur 的下载流程持续了数小时之久。然而，如此着急地安装软件更新是因为其发布的新功能影响当前的 macOS 用户，因为当前版本的 app 启动有延迟。该问题是由证书问题导致的，macOS Gatekeeper 服务未能检查该 app 的开发者证书。某些研究人员表示，app 运行缓慢的原因在于系统允许 macOS 将用户数据发送给苹果公司的服务器。然而，苹果公司否认该问题，表示从未组合从 Gatekeeper 检查获得的数据和用户或设备信息，“我们并未使用从检查中获得的数据来了解个人用户在设备上启动或运行的内容。“苹果还提到暂停网络请求的设计，并为用户提供取消选项。这些变化的目的是确保用户安全并防止出现上周的问题，不过将在明年正式生效。
