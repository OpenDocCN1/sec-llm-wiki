# 某疑似亚洲 APT 组织受雇攻击全球金融和娱乐公司

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247497247&idx=3&sn=c036d5e8ce97c6476f7c20d666182455&chksm=ea94c775dde34e63fa963bb9fc100b50e28113107388537cdc8ac9623aba4e1ef7e1a7c73eec&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247497247&idx=3&sn=c036d5e8ce97c6476f7c20d666182455&chksm=ea94c775dde34e63fa963bb9fc100b50e28113107388537cdc8ac9623aba4e1ef7e1a7c73eec&scene=27#wechat_redirect)

![](../Images/724969efd5bfb8c1d8b761f794b6b733.png) 聚焦源代码安全，网罗国内外最新资讯！**编译：奇安信代码卫士团队**Blackberry 公司的安全研究员发现某 APT 组织受雇于使用之前未曾现身过的恶意软件攻击南亚金融组织机构和全球娱乐公司。![](../Images/4aad71eb7d47e078484d2aa6b7cd90d3.png)

  

这次攻击活动被称为 “CostaRicto”，攻击者似乎是手握定制化恶意软件工具及和拥有复杂的 VPN 代理和 SSH 隧道能力的雇佣 APT 组织。研究人员指出，虽然CostaRicto 的攻击目标分散在欧洲、美洲、亚洲、澳大利亚和非洲各地，但最大的受害者集中于南亚，尤其是印度、孟加拉国、新加坡和中国，这表明攻击者可能位于亚洲，但其客户具有多样化特点。

攻击模式本身很直接。通过被盗凭据在目标环境中立稳脚跟后，攻击者继续设立 SSH 隧道下载后门以及 payload 加载器 CostaBricks，后者用于实现 C++ 虚拟机机制，解码并将字节代码 payload 注入内存中。

除了通过 DNS 隧道管理 C2 服务器后，以上提及的加载器提供的后门是用 C++ 编译的可执行文件 SombRAT（命名源自一名墨西哥黑客 Sombra，他渗透进热门的多玩家游戏 Overwatch）。该后门拥有50种命令，用于执行具体任务（可被分为 core、taskman、config、storage、debug、network 函数），如在内存重注入恶意 DLL 以枚举存储文件，将捕获的数据提取到受攻击者控制的服务器中。研究人员共发现了六个 SombRAT 版本，第一个版本可追溯到2019年10月，而最新的变体出现在今年8月份，这说明该后门一直在开发。

![](../Images/8a2086016832e2aa3bbc37f6b5d874f1.png)

  

  

![](../Images/4aad71eb7d47e078484d2aa6b7cd90d3.png)和 APT 28 或有关联

  

虽然目前尚不清楚攻击者的身份，但后门域名注册的其中一个 IP 地址和此前被指和俄罗斯黑客组织 APT28 之间存在关联的钓鱼攻击活动一样，这说明钓鱼攻击活动可能被外包给该受雇 APT 组织。

这是 Blackberry 发现的第二起黑客雇佣攻击活动，第一起是由 Bahamut 黑客组织利用 0day 漏洞、恶意软件和虚假信息活动开展的攻击活动，目标是攻击位于中东和南亚地区的目标。

研究人员指出，“随着勒索软件即服务（RaaS）获得的成功，看到网络犯罪市场将业务范围扩大到专门的钓鱼攻击和间谍活动也不稀奇。将攻击或某些攻击链外包给不相关的恶意组织节省了真正的攻击者的时间和资源，也简化了攻击程序，但最重要的是它是对真正攻击者的间接保护。”
