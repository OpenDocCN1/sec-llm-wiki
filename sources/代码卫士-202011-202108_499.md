# 他发现美国防部严重的 IDOR 漏洞，获评月度研究员

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247497120&idx=2&sn=535df4e0366b7755f6057a973672bf87&chksm=ea94c4cadde34ddc3a7e9a762023408b9a246c7f76f8472315c4679868d60839392f9f1c7211&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247497120&idx=2&sn=535df4e0366b7755f6057a973672bf87&chksm=ea94c4cadde34ddc3a7e9a762023408b9a246c7f76f8472315c4679868d60839392f9f1c7211&scene=27#wechat_redirect)

美国国防部 (DOD) 修复了一个影响其内部网络的严重漏洞，本可导致威胁行动者仅通过修改发送至 DOD 服务器的 Web 请求中的一些参数即可劫持 DOD 账户。![](../Images/73e6a7dabdaf1b9c6cd51a465c654032.png)

  

该漏洞有美国安全公司 Silent Breach 的研究员 Jeff Steinburg 发现，并私下报告给 DoD 的漏洞披露计划 (VDP)。该漏洞的评分为“严重 (9~10)”，原因是它要求最少的技术就能利用并劫持攻击者所选择的任意 DOD 账户。Steinburg 由此获得DOD 颁发的十月“月度研究员”的称号，而这也是该研究员提交的首个 DoD VDP 报告。

![](../Images/5d38e66043d5d01cee5e5ab67125d9a5.png)漏洞概述

  

从公布的漏洞概述来看，该漏洞是一个不安全的直接对象引用（IDOR）漏洞，因应用程序缺少安全检测引发，可导致黑客在无需其它身份检查的情况下修改一些参数。

在DOD 案例中，该漏洞本可导致攻击者获取发送至 DoD 网站的合法 Web 请求，修改用户ID和用户名参数，而 DOD 网站将使攻击者修改任意用户的 DOD 账户密码，从而劫持账户并攻陷 DOD 的网络。

Steinburg 在 HackerOne 平台上指出，只需通过如下步骤即可修改用户密码：

1、打开 burp suite

2、切换 “Repeater” 标签

3、将附加请求的内容复制到 repeater

4、用目标受害者用户的 ID 值替换 cookie 中的 “UID2=4820041”，同时在 “username” 输入中写入用户邮件

5、替换受害者用户的密码

  

![](../Images/5d38e66043d5d01cee5e5ab67125d9a5.png)被低估的漏洞

  

得益于自动工具，如今无需耗费太多时间就可轻易找到 IDOR 漏洞。当前多数 IDOR 漏洞可导致攻击者修改不会带来损害的参数并修改重要性不太大的账户设置，不过如果IDOR 存在于敏感的账户字段如密码和账户恢复/支付邮件或者购物车获得价格值中，那么这类漏洞仍然可带来严重后果。Shutterstock 公司的应用安全工程师 John Jackson 表示，IDOR 漏洞属于静默的被低估的漏洞，但它们并不鲜见。

DOD 在账户系统中添加了一个用户会话机制，修复了该漏洞，阻止攻击者在无需认证或者获取已遭攻击DOD用户会话 cookie 的情况下修改参数。

目前该漏洞的具体详情尚未公布。
