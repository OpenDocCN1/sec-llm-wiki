# 以色列政府网站遭史上规模最大的DDoS 攻击

周一，以色列多个政府网站遭分布式拒绝服务 (DDoS) 攻击，导致这些门户网站在短时间内无法访问。  
  
  
  

  

以色列国家网络局 (INCD) 在推特上表示，“几小时前，某电信提供商遭DDoS 攻击。为此，短时间内，包括政府网站在内的多家网站无法访问。截至目前，所有网站已恢复正常。”

DDoS 攻击是指通过利用受陷计算机和物联网设备作为攻击流量来源，通过垃圾互联网流量冲击受害者及其周边基础设施，拦截目标服务器或服务的正常流量。此前，NetBlocks 报道称，以色列电信提供商 Bezeq 和 Cellcom 提供的多个网络上出现“重大中断”。

INCD并未将攻击归因为具体的威胁者，不过耶路撒冷邮报不排除是伊朗黑客组织针对伊朗福尔多燃料浓缩工厂勒索事件的报复行为。

这并非针对政府IT基础设施的首个DDoS 攻击，正在进行的俄乌战争拉开了双方“以牙还牙”的DDoS 攻击活动。

此外，Mitel MiCollab 和 MiVoice Busienss Express 协作系统中存在的一个漏洞被用于执行DDoS 攻击，持续长达14小时之久，放大比例为创纪录的43亿：1。
