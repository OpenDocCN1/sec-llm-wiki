# “异常的”间谍软件窃取工业企业凭据

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247510263&idx=4&sn=0d1f407e4ddd11b9f9e9befd08a1c195&chksm=ea94999ddde3108ba7851dc79efd476964451075eea8119ec508867a010d743ef9877c00248a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247510263&idx=4&sn=0d1f407e4ddd11b9f9e9befd08a1c195&chksm=ea94999ddde3108ba7851dc79efd476964451075eea8119ec508867a010d743ef9877c00248a&scene=27#wechat_redirect)

**编译：代码卫士**

研究人员发现针对工业企业的多起间谍活动，旨在窃取账户凭据并执行金融欺诈活动或将凭据转售给其它攻击者。

  

恶意攻击者使用现成间谍工具，不过将每个变体部署有限的事件以躲避检测。攻击中使用的商业恶意软件包括 AgentTesla/Origin Logger、HawkEye、Noon/Formbook、Messlogger、Snake Keylogger、Azorult 和 Lokibot。

  

**不常见攻击**

卡巴斯基认为这些间谍攻击是“异常的“，因为和这个领域中的常见攻击相比，这类间谍攻击持续时间短暂。

更具体而言，这类间谍攻击的生命周期约为25天左右，而多数间谍活动可持续数月甚至是数年之久。

这些间谍活动攻击的系统数量总是低于100次，其中半数针对的是部署在工业环境中的工控设备。另外一个不同寻常的元素是基于 SMTP 的通信协议，用于将数据提取到恶意人员控制的C2服务器。HTTPS 用于大多数用于C2通信的标准间谍活动中，SMTP 是备受数据盗取组织欢迎的单向信道。SMTP 并非威胁人员的常见选择，因为它午发提取二进制或其它非文本文件，但它胜在简约型和与常规网络流量混合的能力

  

**窃取凭据以进一步渗透**

  

威胁人员使用通过鱼叉式钓鱼攻击获取的员工凭据，进一步渗透并在公司网络横向移动。此外，攻击者将此前被攻击的企业邮箱作为新攻击的C2服务器，使得恶意内部通信的检测和标记非常困难。

卡巴斯基实验室发布报告指出，“令人好奇的是，企业反垃圾邮件技术有助于攻击者在从受感染机器中提取被盗凭据时不被发现，使其在垃圾邮件文件夹的所有垃圾邮件中‘不可见’。“

![](../Images/61b016fa9ce9541674bb1bf06424abb0.png)

  

从数量上来看，分析师发现至少有2000个企业邮件账户被滥用为临时C2服务器，其它7000个邮件账户也被滥用。

  

**在暗网市场出售**

  

这些攻击活动中被盗的很多邮件 RDP、SMTP、SSH、cPanel 和 VPN 账户凭据都发布在暗网市场上并最终被出售给其它威胁行动者。

卡巴斯基的数据分析显示，在这些非法市场上出售的所有RDP账户中，约3.9%的账户属于工业企业。RDP 账户对于网络犯罪分子而言至关重要，因为这些账户可使犯罪分子远程访问受陷机器并直接和设备交互而无需引起任何警报。一般而言，勒索攻击者会利用RDP访问权限部署破坏性恶意软件。
