# 朝鲜国家黑客被指利用定制恶意软件攻击各国政府官员

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247509314&idx=3&sn=34e75a5c46750ebbb5815fcd3881314c&chksm=ea949428dde31d3e03704de12d7e077c77bd3602b6aa61153ee007fa01330b6d919badce1b0c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247509314&idx=3&sn=34e75a5c46750ebbb5815fcd3881314c&chksm=ea949428dde31d3e03704de12d7e077c77bd3602b6aa61153ee007fa01330b6d919badce1b0c&scene=27#wechat_redirect)

朝鲜国家黑客 TA406 被指最近在网络间谍活动中部署定制化信息窃取恶意软件。

TA406 也被称作 “Kimsuky”（Thallium），它自2018年起鲜少现身，重心在于网络间谍、钱财盗取欺诈活动和勒索。然而，在2021年3月和6月，TA406 发动了两起独立的针对外交专家、记者和非政府组织机构成员的恶意软件分发活动。

Proofpoint 公司的安全研究员根据对TA406的追踪以及工具样本的获取，发现了该组织滥用的服务以及使用的钓鱼诱饵。

  

![](../Images/ac0c1d644141a1c9e168d6f439e94036.png)大规模但具有针对性的攻击

  

TA406 组织通过恶意软件分发、钓鱼攻击、情报收集和密币盗取从事大量犯罪活动。

Proofpoint 公司在报告中指出，TA406 的工作时间大概是韩国标准时间一周七天，每天早上9点到下午5点，hacking 即是全职工作。该组织的攻击范围非常宽泛，包括北美、俄罗斯、中国、韩国、日本、德国、法国、英国、南非、印度等不一而足。

TA406 组织发送的钓鱼邮件通常使用的诱饵和核安全、政治以及韩国外交政策相关，而且攻击的是高级别的当选官员。报告指出，“钓鱼邮件的收件人包括多个不同政府机构的最高层当选官员、咨询公司员工、和国防、执法、以及经济金融相关的政府机构以及大型金融机构的董事会和客户关系邮箱。”这些邮件从受陷网站发出，发件人通常会假冒成真实人员而非制造虚假人设，如Global Asia 的编辑、韩国延世大学的教授以及韩国总统文在寅的顾问。

最引人注意的是，TA406 组织在发动钓鱼攻击收割凭证时通常不会创造详尽的登录页来假冒为人熟知的服务器，而是使用基本的HTTP认证展示浏览器对话窗口，要求用户输入凭据。这些诱饵通常是需要收件人以个人或企业凭据登录到托管平台的PDF文件。

  

![](../Images/ac0c1d644141a1c9e168d6f439e94036.png)客户信息窃取恶意软件

  

从2021年1月起，TA406 组织开始通过钓鱼邮件7z文档释放恶意软件payload，这些文档中包含具有双重扩展的显示为.HTML文件的 EXE 文件。文件打开后会创建一个调度任务 “Twitter Alarm”，使黑客每隔15分钟释放其它 payload。执行时，该EXE 文件也会打开 web 浏览器，查看托管在攻击者基础设施上一篇合法的朝鲜新闻文章的PDF 文件，诱骗用户认为自己阅读的是新闻站点的文章。

2021年6月，TA406 组织开始部署自定义恶意软件 “FatBoy”，将其在受害者磁盘上释放为 HTML 附件。每个附件都有一个唯一哈希和看不见的嵌入式框架来和攻击者通信并告诉他们打开该文件的收件人（IP地址）是谁。FatBoy 使一款小型的第一阶段恶意软件，它的目的是每隔20分钟从C2下载CAB 文件。该CAB 文件中包含一个 batch 脚本 (ball.bat)，用以执行旨在执行侦察并通过HTTP POST 请求提取信息的VBS 脚本。该恶意文件抓取的TA 406 恶意软件是 “YoreKey”。YoreKey 是一款定制化 Windows 键盘记录器，它伪装成合法的电子交易平台 MetaTrader 4 Manager，通过创建注册密钥和将其日志以明文形式存储在受感染系统中确保持久性，使攻击者能够窃取由用户输入的登录凭据。

  

![](../Images/ac0c1d644141a1c9e168d6f439e94036.png)窃取密币

  

此外，TA406 组织还窃取密币，而且研究人员发现该组织已经至少收到了3.77个比特币，价值约为22.2万美元。TA406 组织利用多种方式窃取密币，如伪装成非政府组织机构接受捐款、通过 “Deincube” 网站提供很可能是虚假的文件解码/反混淆服务以及性勒索欺诈活动等。

被盗密币的数量很可能更多，因为TA406 组织可能使用研究人员未知的其它钱包接受密币。

  

![](../Images/ac0c1d644141a1c9e168d6f439e94036.png)攻击可能仍会继续

  

研究人员认为，TA406 组织的恶意活动覆盖面广，之后应该会继续代表朝鲜政府执行更多的攻击。他们可能会进一步攻击美国国防承包商以及和核研究机构窃取可为朝鲜政府使用的情报。
