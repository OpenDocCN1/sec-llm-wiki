# 未修复的Zoho ManageEngine产品正遭利用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247515335&idx=1&sn=a2dfe8edd8e9e4e984be05d2f9979792&chksm=ea948daddde304bb67f081b945a15707e0c1c7a16f9ee5e89e3e0c29167583d5f2e62b8d9106&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247515335&idx=1&sn=a2dfe8edd8e9e4e984be05d2f9979792&chksm=ea948daddde304bb67f081b945a15707e0c1c7a16f9ee5e89e3e0c29167583d5f2e62b8d9106&scene=27#wechat_redirect)

**多款Zoho ManageEngine IT 管理产品中存在一个严重漏洞 (CVE-2022-47966)，可导致未认证的远程代码执行后果，目前正遭活跃利用。**  
  

1月10日，ManageEngine 发布更新，称漏洞产生的根因是“过时的第三方依赖 Apache Santuario”。该安全公告指出，如果单点登录是启用状态或已启用状态，则有24款ManageEngine 产品受影响。截至1月13日，Horizon.ai团队的研究人员提供了妥协指标 (IoCs)。目前，GreyNoise 已发现在过去三天时间内，恶意人员正试图利用该RCE。

研究人员指出，“与该标签相关的IP地址正试图利用CVE-2022-47966，即位于多款Zoho ManageEngine产品中的未认证远程命令执行漏洞。”一旦该RCE被用于攻陷系统，则该访问权限可被恶意人员随心所欲地利用。

研究人员提到，“ManageEngine产品属于企业最常用的产品，可协助企业执行业务功能如认证、授权和身份管理。鉴于这些产品的性质，这类漏洞可对组织机构带来严重风险，可导致攻击者获得初始访问权限并通过高权限凭据进行横向移动。”
