# 立即修复！Atlassian Bitbucket 服务器易受严重的 RCE漏洞影响

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247513716&idx=1&sn=17534c8b961a4ef3a27b7ecdf4588568&chksm=ea94871edde30e08de08a258e2ba454e862dc7b989c93439978434f6141872e937b7f16615b0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247513716&idx=1&sn=17534c8b961a4ef3a27b7ecdf4588568&chksm=ea94871edde30e08de08a258e2ba454e862dc7b989c93439978434f6141872e937b7f16615b0&scene=27#wechat_redirect)

**编译：代码卫士**

  

Atlassian 发布安全公告，提醒 Bitbucket Server and Data Center 的用户注意一个严重漏洞，可导致攻击者在易受攻击实例上执行任意代码。

  

Bitbucket 是一款基于Git的代码托管、管理和协作工具，集成了Jira 和 Trello。该漏洞的编号是CVE-2022-36804，是位于Atlassian软件产品的多个API端点中的命令注入漏洞，CVSS编号为9.9（满分10分），用户应立即修复。

Atlassian 安全公告指出，“拥有访问公开库或对私密Bitbucket仓库具有读取权限的攻击者，可发送恶意HTTP请求执行任意代码。”

  

![](../Images/3cfec5d32abf4d1c5118dd4eee24abb6.png)  
**影响版本**

  

该漏洞影响6.10.17之后的Bitbucket Server and Data Center 版本，包括7.0.0至8.3.0版本。

已修复该漏洞的版本是7.6.17、7.17.10、7.21.4、8.0.3、8.1.3、8.2.2 和 8.3.1。遗憾的是，6.x分支的老旧和不受支持的版本将不再收到秀复方案。

建议无法应用安全更新的用户，使用“feature.public.access=false”来关闭公开库作为临时的部分缓解措施。如此，越权用户便无法访问这些实例；然而，授权用户如拥有受陷的有效凭据的威胁行动者仍然可以执行攻击。

Atlassian 注意到，通过bitbucket.org域名访问Bitbucket的用户不受该严重的RCE漏洞影响，因为该厂商托管这些实例。

  

![](../Images/3cfec5d32abf4d1c5118dd4eee24abb6.png)  
**PoC或将现身**

  

2022年7月，安全研究员 Max Garrett 发现并通过该公司在Bugcrowd平台上的漏洞奖励计划报告了该漏洞，获得6000美元的奖励。

这名研究员承诺将在一个月内发布PoC 利用，以使系统管理员能够有足够的的时间应用这些修复方案。

PoC 发布势必会导致黑客活跃利用该严重漏洞，不过好在不会很快发生。

Garrett 表示，对于技术高超的黑客而言，逆向Atlassian的补丁应该不会太困难。

远程代码执行漏洞是所有漏洞类型中功能最强大的，它可使攻击者绕过所有安全措施，造成一系列损坏。因此，建议Bitbucket Server and Data Center 用户尽快应用安全更新或缓解措施。
