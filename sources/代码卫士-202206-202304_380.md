# 丹麦所有711便利店因遭攻击而关门

**丹麦全国所有的711便利店遭攻击，导致支付系统和结账系统遭破坏而被迫关门。**

攻击发生在当地时间8月8日早晨早些时候，711公司在Facebook 发文称可能“遭黑客攻击”。声明指出，在调查这起安全事件期间已关闭丹麦全国的所有门店，“很遗憾，我们怀疑今天即2022年8月8日周一遭到黑客攻击，这意味着我们无法结账以及/或者接受付款。因此在了解更多信息之前门店将一直关闭。我们希望不久将重新开张。”

在现已删除的一篇Reddit 帖子上，一名声称是丹麦711便利店员工的一名用户也证实这起网络攻击，表示结账系统停止运作后，门店被迫关张。这名员工写道，“我在哥本哈根步行街 (Stroget) 的711便利店工作，我们的结账系统不再运作，公司所有的711门店都是在同一个系统运行，因此现在丹麦所有的711门店都关门了。我们自己也关门了，并贴出关门标签。”

目前上不存在关于这起攻击的更多详情，包括是否牵涉勒索软件，因为勒索攻击已成为引发大规模网络事件的最常见原因。

711便利店表示目前无法分享更多信息。我们将持续关注事态进展。
