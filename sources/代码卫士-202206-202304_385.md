# DEF CON 将披露美国应急警报系统中的多个严重漏洞，有些无补丁

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247513431&idx=2&sn=22ef070c5ae6e6ba53ec5d1c7ca087c6&chksm=ea94843ddde30d2b528bf68129bb595d498ca8e035f5af84e7f533947363c9852764fcd0a57c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247513431&idx=2&sn=22ef070c5ae6e6ba53ec5d1c7ca087c6&chksm=ea94843ddde30d2b528bf68129bb595d498ca8e035f5af84e7f533947363c9852764fcd0a57c&scene=27#wechat_redirect)

**美国国土安全部的直属部门美国联邦应急管理署 (FEMA) 发布安全公告，督促组织机构确保修复自己的应急警报系统 (EAS)，但一名研究员表示影响该系统的一些漏洞并不存在补丁。**

美国的EAS 供相关机构通过电视和广播，向公众播报应急警报和告警信息如天气警报和安珀警戒。本周，FEMA 发布一体化公共警报和告警系统 (IPAWS) 公告中指出，影响 EAS 编码器和解码器设备的漏洞可导致黑客通过电视、广播和有线网络发布越权警报。这种情况曾发生过。2020年，黑客利用一台易受攻击的设备发出了关于辐射性事故的错误告警。

  

01**漏洞将在DEF CON 上披露**![](../Images/a2f065e51177d74bc3881ee19fae8ea3.png)

  

FEMA 提到，安全和事件响应公司 Cybir 的一名研究员 Ken Pyle 将在下周拉斯维加斯的 DEF CON 大会上披露这些漏洞。

为此，FEMA 督促组织机构确保自己的系统已安装最新安全更新和安全补丁、设备得到防火墙保护、设备和支持系统得到监控，以及例行审计日志发现攻陷迹象。

虽然FEMA 发布的安全公告中并未提到受影响的产品，但Pyle 表示自己的研究基于对数字化警报系统公司 R189 DASDEC 编码器/解码器。该公司的前身是 Monroe Electronics。研究员从eBay 平台购得该设备。

Pyle 计划在DEF CON 上展示这些设备未加密、执行不良、复用密钥且软件高度不安全，其中的web应用漏洞使其位于风险之中。他表示分析之后还获得了多个EAS网络和提供商的凭据和元数据。

Pyle还警告称，很多站点将受影响设备暴露在互联网上，导致黑客更容易利用这些漏洞。

  

02**不满厂商处理情况**![](../Images/a2f065e51177d74bc3881ee19fae8ea3.png)

  

Pyle 在2019年开始向数字化警报系统公司报告这些漏洞，并在今年告知其它一些漏洞。然而，他对该公司的漏洞披露流程不满，表示某些缺陷已修复但并未分配CVE编号。

FEMA 警报提到，在EAS 编码器上安装最新更新可阻止漏洞遭滥用，但Pyle 表示事实并非如此，因为一些漏洞厂商并未修复或无法修复如和实践、实现和涉及相关的问题。Pyle 指出，虽然厂商在淡化自己研究成果的严重性，但实际上该公司甚至不了解全貌，“由于缺乏合作和交流，我并没有把自己所有的研究成果告诉他们。他们公开表示我的研究成果已过时。但并不是这样。我可以证明并一定会证明这一点。”

至少十年来，网络安全研究员一直从该公司的EAS产品中发现多个漏洞。

数字化警报系统公司尚未置评。我们将持续跟进事态进展。
