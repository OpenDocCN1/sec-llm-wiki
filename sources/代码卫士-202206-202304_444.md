# 研究员发现针对 Windows 用户的 Raspberry Robin 蠕虫

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NTg4OTc5Nw==&mid=2247512822&idx=2&sn=6077f0b60862a14d2d2a7003564e3643&chksm=ea94839cdde30a8ae8f3cba09af05892a4274c297057166860233a10a7ca241533b968418925&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247512822&idx=2&sn=6077f0b60862a14d2d2a7003564e3643&chksm=ea94839cdde30a8ae8f3cba09af05892a4274c297057166860233a10a7ca241533b968418925&scene=27#wechat_redirect)

**网络安全研究员提醒用户注意一个名为 “Raspberry Robin” 的威胁集群，它是具有类似于蠕虫能力的 Windows 恶意软件。**

Cybereason 公司将该威胁称为“永久的”和“扩张的”威胁，并表示已在欧洲发现很多受害者。感染涉及一个蠕虫，它通过包含恶意.LNK文件的可删除 USB 驱动进行传播，利用受陷的QNAP NAS 设备作为命令和控制。它首先由Red Canary公司的研究员在2022年5月发现。

该威胁也被 Sekoia 称为 “QNAP 蠕虫”，它利用名为 “msiexec.exe” 的合法 Windows 安装程序二进制下载并执行来自受陷 QNAP NAS 设备的恶意共享库 (DLL)。

Cybereason 公司的研究员  Loïc Castel 在write-up 中指出，“为了更难以被检测到，Raspberry Robin 利用了三个合法 Windows 系统进程中的进程注入”，并表示，它“通过TOR退出节点和余下的基础设施进行通信”。

攻击者通过Windows Registry 修改在受陷机器上实现可持久性，通过启动阶段的 Windows 二进制 “rundll32.exe” 加载该恶意payload。这起攻击活动可追溯至2021年9月，目前仍是未解之谜，攻击者的来源或最终目标仍未可知。

QNAP 披露称正在调查针对公司设备的新一轮 Checkmate 勒索软件感染活动，它是继 AgeLocker、eCh0raix 和 DeadBolt之后的最新攻击活动。QNAP 在安全公告中指出，“初始调查表明，通过SMB服务实施的 Checkmate 攻击暴露到互联网，并通过字典攻击破解具有弱密码的账户。攻击者成功登录设备后，会在共享文件夹中加密数据并在每个文件夹中留下勒索留言且文件名为‘!CHECKMATE\_DECRYPTION\_README’”。

QNAP 公司指出，为谨慎起见，建议客户不要将SMB服务暴露到互联网中，增强密码强度，例行备份并将QNAP操作系统更新至最新版本。
