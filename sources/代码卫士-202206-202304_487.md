# 英国内政大臣：维基解密创始人朱丽安·阿桑奇可被引渡到美国

英国内政大臣帕特尔批准，将维基解密的创始人朱利安·阿桑奇引渡到美国。  
  

  

  
**14天的上诉期限**

  

英国内政部（负责移民控制、安全和秩序的英国政府部门）指出，阿桑奇有14天的上诉期限。另外，内政部表示引渡不会“侵犯他的人权”，且他将在美国得到“妥善对待”。

美国当局认为阿桑奇在2010年和2011年的泄密违反了法律并危害他人生命。维基解密文档和伊拉克以及阿富汗战争有关。经过一场旷日持久的避免被引渡的官司后，澳大利亚人阿桑奇被关在位于伦敦的贝尔马什监狱。引渡允许一国要求另一国交出嫌疑犯以进行审判。

在回应英国内政部大臣的裁决时，维基解密证实称将提起上诉。

阿桑奇的妻子史黛拉指出，自己的丈夫“并无过错”，“他并未犯罪。他是一名记者兼出版商，但他却因为履行自己的职责而遭受惩罚。”

阿桑奇的兄弟 Gabriel Shipton 在纽约驻英国大使馆外的新闻发布会上表示，如果在英国高等法院上述不成功，将上诉至欧洲人员法院。

维基解密是一家媒体公司，发布由匿名来源提供的机密信息，是一家吹哨平台。

  

  
**英国法院裁决引渡合法**

  

这一裁决是阿桑奇耗时很久的官司过程中最重要的阶段。伦敦的法官已裁决美国的请求是合法的，美国当局将在监狱对其妥善安置。英国内政大臣通过批准美国的请求而在这场复杂的法律进程中发挥她的作用。其团队成员指出，内政大臣是依法形式，因为阿桑奇并未被判处死刑，且案件也未落入其它类别范围使其拒绝批准引渡。在实践中，这意味着除非上诉成功，否则无法阻止美国政府通过直升机带走阿桑奇的行为。如阿桑奇的律师无法得到伦敦法官的回复，则可上诉至欧洲人权法院。十年前英国判决将阿桑奇引渡到美国不违反人权，除非阿桑奇能够给出新的证据。

2019年5月，因违反保释，阿桑奇在英国被判入狱，美国司法部向阿桑奇提起17项诉讼，起诉他违反间谍法，声称维基解密获得的资料危害生命。阿桑奇的法律团队声称，维基机密披露的和伊拉克和阿富汗战争相关的机密文档暴露了美国的不当行为且符合公众利益。这些文档披露了美国军队在阿富汗战争期间未报道的事件中杀害了数百名公民，被泄露的伊拉克战争文件显示伊拉克军队杀害6.6万名平民，折磨服刑人员。

2019年，厄瓜多尔宣布撤销其庇护身份后遭英国警方逮捕，从厄瓜多尔驻伦敦大使馆转移到英国监狱。阿桑奇在2012年向厄瓜多尔大使馆寻求庇护，担心遭美国起诉并在大使馆带了七年的时间。阿桑奇指出自己是人权滥用受害者，如被引渡将面临无期徒刑。

3月份，英国高等法院判决称，美国已向英国保证对待阿桑奇的方式，该案件在这一方面并无任何法律问题。此前，英国法官因担心阿桑奇的心理健康问题而拒绝将其引渡到美国。

  

  
**是否会得到公正判决？**

  

大赦国际组织指出，启动引渡“将把他置于巨大风险之中，并给记者发出冰冷的信号。”该组织的秘书长 Agnes Callamard 表示，“从之前的历史案件来看美国称将不会单独监禁阿桑奇的外交保证不可信。”

英国前政府部长戴维·戴维斯认为，阿桑奇在美国不会得到公正判决。他指出，“这一引渡条约需要重新编制，以给予英美两国公民同等的权力，而不是像现在这样。”

英国内政部的一名发言人指出，根据2003年的引渡法案，大臣“必须签署”引渡法令，如果“不存在阻止该法令的证据”。内政部指出，“英国法庭并未发现引渡阿桑奇先生的流程具有压迫性、不公正或是滥用行为。”
