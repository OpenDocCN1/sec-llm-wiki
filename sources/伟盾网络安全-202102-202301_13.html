01 类初始化的小知识点


在类加载的init阶段，类的类构造器中会收集所有的static块和字段并执行，static块只执行一次，由JVM保证其只执行一次。

这句话怎么理解呢，我们通过一个小的demo代码就能明白了。

package mydemo.oop;
public class TestStatic {
    private static String name;
    static {        name = "123";        System.out.println("静态初始化代码块被调用了。。。");    }
    public static void main(String[] args) {        TestStatic testStatic = new TestStatic();        System.out.println(testStatic.name);        TestStatic testStatic2 = new TestStatic();        System.out.println(testStatic2.name);    }}


执行结果如图


从demo中我们可以看到，我们定义了一个static代码块，然后在main方法中实例化了两次TestStatic类，但是static代码块只执行了一次，这也就是前面说的static块只执行一次，不论你new多少个实例，个人感觉这是一个小的知识点吧，懂得大佬可以略过，不了解的就加深下印象。

package mydemo.serializable;
import java.io.IOException;import java.io.ObjectInputStream;import java.io.ObjectOutputStream;import java.io.Serializable;
/** 当父类和子类都重写了writeObject方法和readObject方法时，* 进行writeObject方法时，会先调用父类的writeObject方法，然后在调用子类的writeObject方法* 进行readObject方法时，会先调用父类的readObject方法，然后再调用子类的readObject方法* */public class SubClass extends SuperClass /*implements Serializable*/ {
    public int subvalue;    public static Person p;
    public SubClass(int supervalue, int subvalue){        super(supervalue);        this.subvalue = subvalue;    }
    public String toString(){        return super.toString() + " sub: " + subvalue;    }
    // 父类未实现序列化接口，子类序列化时，需要序列化（反序列化）父类的域    private void writeObject(ObjectOutputStream oos){        try {            oos.defaultWriteObject();            oos.writeInt(supervalue);  // 序列化父类的域            oos.writeObject(new Person());        } catch (IOException e) {            e.printStackTrace();        }        System.out.println("子类的writeObject方法被调用。。。");    }
    private void readObject(ObjectInputStream ois){        try {            ois.defaultReadObject();            supervalue = ois.readInt(); // 反序列化父类的域            Person p = (Person) ois.readObject();        } catch (IOException e) {            e.printStackTrace();        } catch (ClassNotFoundException e) {            e.printStackTrace();        }        System.out.println("子类的readObject方法被调用。。。");    }}

  1. 序列化/反序列化时，优先执行父类的序列化/反序列化方法，然后再执行子类的序列化/反序列化方法

  2. 如果序列化/反序列化的时候有写入其他对象，那么会进入到该对象的序列化/反序列化方法中，之后再回到最开始的序列化/反序列化方法中
