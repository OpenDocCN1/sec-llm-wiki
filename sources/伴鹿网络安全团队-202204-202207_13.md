**环境信息**  

攻击机：192.168.148.136

靶机：192.168.148.146

靶场环境：本地部署vulfocus

**漏洞编号：**CVE-2020-14882

**漏洞描述：**未经身份验证的远程攻击者可通过构造特殊的 HTTP GET 请求，结合 CVE-2020-14883 漏洞进行利用，利用此漏洞可在未经身份验证的情况下直接接管 WebLogic Server Console ，并执行任意代码。

**影响版本：**Oracle WebLogic Server 10.3.6.0，12.1.3.0，12.2.1.3，12.2.1.4，14.1.1.0
