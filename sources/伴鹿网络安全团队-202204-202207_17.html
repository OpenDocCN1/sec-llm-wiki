环境信息

靶机：192.168.148.146

靶场环境：本地部署vulfocus

漏洞编号：CVE-2022-22947

漏洞描述：Spring Cloud Gateway是Spring中的一个API网关，当攻击者可以访问Actuator API的情况下，将可以利用该漏洞执行任意命令。

影响版本：

Spring Cloud Gateway < 3.1.1 

Spring Cloud Gateway < 3.0.7

漏洞复现：

 进入目标站点

测试是否开放监控api
