# CVE-2022-0847

## 1\. 漏洞概述

2022 年 3 月 7 日，安全研究人员 Max Kellermann 披露了一个 Linux 内核中的本地提权漏洞。该漏洞允许非特权用户通过注入和覆盖任意只读文件中的数据，导致权限提升，攻击者可以利用该特性最终获得 root 权限。

## 2\. 影响范围

Linux Kernel 版本 >= 5.8

Linux Kernel 版本 < 5.16.11 / 5.15.25 / 5.10.102

## 3\. 漏洞评级

漏洞编号：CVE-2022-0847

CVSS 评分：7.8

漏洞危害：高危。

## 4\. 漏洞复现

漏洞测试环境信息如下图所示：

![](../Images/8e0339f568b0ecfc0b261f9c21798f1b.png)

首先备份文件以防止环境不能恢复（攻击真实环境时可不进行此操作，但**攻击真实环境一定要取得对方授权，否则属于犯罪行为**），接着编译 exp 文件并执行。

本地权限提升命令：

```


cp /etc/passwd /tmp/passwd.bak
```

微信公众号后台回复「20220847」获取 exp 文件。

## 5\. 安全建议

由于该漏洞很容易被利用从而获得 root 权限，建议用户尽早更新 Linux 至以下安全版本：

*   Linux 内核 >= 5.16.11
*   Linux 内核 >= 5.15.25
*   Linux 内核 >= 5.10.102
