0x12 Android 工具 Jadx

上一篇文章中我们讲解了「Android 中 Drozer 使用安装总结」，本文则对 Android 中经常使用到的一个反编译工具 Jadx 进行详细的讲解。

1. 前言

在 Android 渗透测试中，适当的使用工具是必不可少的，这里我们介绍一个非常好用的反编译工具 -- Jadx 。Jadx 的功能很牛逼，在 Android 测试中经常使用 Jadx 可以帮我们解决很多问题。

Jadx 优点：

  • 图形化的界面。
  • 拖拽式的操作。
  • 反编译输出 Java 代码。
  • 导出 Gradle 工程。

2. 使用 Jadx

2.1 下载 Jadx

Jadx 是一款开源软件，其项目地址为：https://github.com/skylot/jadx。

在 GitHub 上根据要下载的版本选择性下载，这里我下载的是 jre 版本：https://github.com/skylot/jadx/releases/download/v1.3.3/jadx-1.3.3.zip

微信公众号后台回复「0228」获取 jadx-gui 软件，截止写文章时最新版本为 v1.3.3。

解压后如下图所示，根据自己的系统版本运行对应的执行文件，我这里 mac 运行的「jadx-gui」。

2.2 使用 Jadx

打开 Jadx 后，显示得都很详细，具体都是啥我就不解释了，知道几个关键的就行。

可以看到有证书，这样就可以不用 keytool 再去验证了，然后就是看资源文件里的 AndroidManifest.xml，可以在该文件里 ctrl+f 搜索相关内容。

也可以点这个放大镜进行全局搜索，打上相应的钩即可。
