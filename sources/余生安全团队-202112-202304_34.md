## 2\. 工具介绍

Bandit 是一款用来检测 Python 代码中常见安全问题的工具，在检测的过程中，Bandit 会对每个 Python 代码文件进行处理，从中构建 AST，并针对 AST 节点运行相应的插件。Bandit 在扫描完全部文件后，会生成一份报告用于查看检测情况。

Bandit 最初是在 OpenStack 安全项目中开发的，后来重新归入 PyCQA。

![](../Images/f2b2fa3aa14785a0b911617ed5d566d0.png)

## 3\. 工具安装

Bandit 是在 PyPI 上进行分发，所以安装它的最佳方法是使用 pip。

创建虚拟环境（可选）：

```


virtualenv bandit-env# And activate it:
source
 bandit-env/bin/activate
```

安装 bandit：

```


pip install bandit
```

运行 bandit：

```

bandit -r path/to/your/code
```

Bandit 也可以通过源代码安装。为此，请从 PyPI 下载源码包，然后安装它：

```

python setup.py install
```

## 4\. 工具使用

### 4.1 常规使用

节点树的用法示例：

```

bandit -r ~/your_repos/project
```

![](../Images/ba9aba538ca5d31d43320f37e07e271c.png)

examples/ 目录遍历使用情况示例，显示三行内容，仅报告高严重性的问题：

```

bandit examples/*.py -n 3 –lll
```

Bandit 可以使用配置文件运行，运行下列命令即可使用 ShellInjection 对 examples 目录运行安全扫描：

```

bandit examples/*.py -p ShellInjection
```

Bandit 还支持使用标准输入传递要扫描的代码行，执行下面代码就能使用标准输入运行 Bandit：

```

cat examples/imports.py | bandit -
```

有关更多用法信息可使用 -h 参数：

```

bandit -h
```

### 4.2 基线

Bandit 允许使用者指定基线报告的路径，以便与使用基线参数进行比较：

```

bandit -b BASELINE
```

对于使用者认为是可忽略的已知问题（例如，单元测试中的明文密码），只需运行 Bandit，将输出格式设置为仅接受 JSON 格式的文件作为基线，并指定输出文件路径：

```

bandit -f json -o PATH_TO_OUTPUT_FILE
```

### 4.3 版本控制集成

安装 pre-commit 后将其添加至代码库的 .pre-commit-config.yaml 文件中（请务必更新 rev 以指向真正的 git 标记/修订版！），然后运行 pre-commit 安装，即可开始使用：

```


repos:'' # Update me!


```

## 5\. 工具扩展

Bandit 允许用户为检查和格式化程序编写和注册扩展，Bandit 将从两个入口点加载插件：

*   bandit.formatters
*   bandit.plugins

Formatter 需要接收下列四种输入参数：

*   result\_store：一个 bandit.core.BanditResultStore 实例
*   file\_list：需要扫描检测的文件列表
*   scores：每个文件的扫描评分
*   excluded\_files：列表中不需要扫描的文件

格式化程序需要接受 5 件事：

*   manager：bandit 管理器的实例
*   fileobj：输出文件对象，可以是 sys.stdout
*   sev\_level ：过滤严重性级别
*   conf\_level：筛选置信水平
*   lines=-1：要报告的行数

插件倾向于利用 bandit.checks 装饰器来对特定类型的 AST 节点进行检测扫描：

```
@bandit.checks('Call'

)if 'unsafe_load'

 incontext.call_function_name_qual:return

 bandit.Issue("Unsafe deserializationdetected."


```

使用者有两种选项来注册插件：

1.  如果我们直接使用了安装工具 (setuptools)，需要在 setup 调用中添加下列信息：

```
# Ifyou have an imaginary bson formatter in the bandit_bson module
# anda function called `formatter`.
'bandit.formatters':['bson = bandit_bson:formatter'
]}# Ora check for using mako templates in bandit_mako that
'bandit.plugins':['mako = bandit_mako'
]}
```

2.  如果我们使用的是 pbr，需要在 setup.cfg 文件中添加下列信息：

```


[entry_points]
```
