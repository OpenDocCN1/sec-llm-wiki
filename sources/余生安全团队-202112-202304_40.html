Ubuntu 18.04 搭建 LAMP 环境

1. 基础操作

LAMP 是指一组通常一起使用来运行动态网站或者服务器的自由软件名称首字母缩写：

  • Linux，操作系统
  • Apache，网页服务器
  • MariaDB 或 MySQL，数据库管理系统（或者数据库服务器）
  • PHP、Perl 或 Python，脚本语言

接下来我们讲解下如何在 Ubuntu 系统上安装 LAMP，当然本文是对 LAMP 进行分开安装，后面也会讲解如何一键安装和使用其它集成环境。

首先来看下我们的 Ubuntu 版本，使用 lsb_release -a 命令来查看。

我们还需要更新一下系统，如果提示权限不够需要在前面加上 sudo 命令。

sudo apt-get update
sudo apt-get upgrade

2. 安装 Apache

安装 apache2 使用如下命令：

sudo apt-get install apache2

-v 参数可以查看版本信息。

apache2 -v

3. 安装 MySQL

安装 MySQL 使用如下命令：

sudo apt-get install mysql-server mysql-client

查看是否安装成功可以用 service 命令。

service mysql status

4. 安装 PHP

安装 PHP 使用如下命令：

sudo apt-get install php

查看 PHP 版本信息可以使用 -v 参数。

php -v

5. 安装 phpMyAdmin

安装 phpmyadmin 并使用软链接到 Web 目录下。

sudo apt-get install phpmyadmin
sudo ln -s /usr/share/phpmyadmin/ /var/www/html/phpmyadmin
