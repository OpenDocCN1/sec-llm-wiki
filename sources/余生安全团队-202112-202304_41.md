# 0x01 MetaMask 安装使用指南

## 1\. 前言

MetaMask 是一个开源的以太坊钱包，能帮助用户方便地管理自己的以太坊数字资产。目前 MetaMask 已经推出中文版，官方发布消息称其支持市面上所有的 DAPP 应用程序。

MetaMask 除了是一个简单的钱包，它还可以让使用者轻松跟以太坊的智能合约互动，甚至 MetaMask 还可以用来参加 ICO。

## 2\. 安装步骤

使用 Chrome 浏览器访问 MetaMask 官方网站 (https://metamask.io/) 点击 Download 进行下载 (https://metamask.io/download.html)。

![](../Images/76868d4058036d39b33ff6088e3ff777.png)

根据客户端种类进行下载安装。

![](../Images/98483ce6398bec9211164b02b17bcdb0.png)

点击 Install MetaMask for Chorme 后会跳转到 Chrome 网上应用店，再点击Add to Chorme 即可安装。

![](../Images/80cd1a0ecb93ac7c2dc63b2f4ce2a525.png)

或者直接在 Chrome 网上应用商店 上搜索 MetaMask。

![](../Images/131b53f3bed7ca26045d42e07c8f09b0.png)

添加到 Chrome 后就会到下面的页面，接着点击开始使用。

![](../Images/7e9c8bbf26ecd3882a197ede3a05d1dd.png)

跳转的页面需要我们选择创建钱包还是导入钱包，如果是第一次使用就需要我们创建钱包。

![](../Images/f92a88f37d99f7bdc1da11476c44d2c8.png)

在创建钱包前会有一个温馨提示，提示我们应该怎么做。

![](../Images/c0401a0d5511748235647f1fd0671f92.png)

然后输入密码，点击创建。

![](../Images/a5f0aff9c630b236351154ce4f77bd1e.png)

之后会给出一个账户助记词，该助记词一定要确保备份好，最好是纸质备份。

![](../Images/7efdf48934548afff9acbb7169a7f134.png)

接着验证刚才我们得到的助记词就可以了。

![](../Images/5c1911145019612be2520e9e0e803362.png)

最后钱包创建完成，同时还会给出多个「安全保存技巧」。

![](../Images/f992a402ff505736896f3a83a9813162.png)

点击全部完成进入主页面。

![](../Images/d50b72b2c8ec7b2cd6e823b29e9791b7.png)

## 3\. 界面介绍

### 3.1 网络选择

MetaMask 提供了以太坊 Ethereum 主网络、Ropsten 测试网络、Kovan 测试网络等，用户可以点击右上角的「以太坊主网络」来选择和查看。此外用户还可以自定 RPC 去连接到其他链的网络上。

![](../Images/54f1be4a943cb37e314ba133bd74a226.png)

### 3.2 账户信息

点击右上角的头像可以查看账户信息，包括创建账户、导入账户、连接硬件钱包等，用户可以根据自己的需求进行设置。

![](../Images/c904758caa4cf920378072aa3e301934.png)

### 3.3 添加代币

下方是资产列表，根据我们的需求可以添加相应的代币，点击添加代币按钮进行添加。

![](../Images/cc2fba9b824029eb3630c476ca72e58d.png)

比如这里我们选择添加 USDT，搜索到后选择再点击下一步，最后点击添加代币即可添加完成。

![](../Images/7f81a7b07b9407f3a229a6012d9f5b39.png)

下面是添加完成后的结果。

![](../Images/1eb3730251a30424618088b9cfbf0685.png)

### 3.4 获取资产

如果我们连接的是主网，可以将 ETH 转入钱包，或者可以点击购买。

![](../Images/a82e0544d09379586b9c58410bdf7947.png)

而当我们接入的是 Ropsten 测试网络时，可以获取一些虚拟的测试 ETH 进行使用（仅做测试，没有任何的价值）。

首先切换到 Ropsten 测试网络，点击购买按钮，选择测试水管后的「获取 Ether」。

![](../Images/f4516d9f9706b28e457146f5d6c2f0f3.png)

点击「request 1 ether from faucet」获取测试代币。

![](../Images/22371cd44697cfbde91cfd0c4541f727.png)

### 3.5 转账操作

相应的，如果要进行转账操作，只需要点击发送，然后输入对方的地址即可。

![](../Images/e113b94b09841736c227c079f9798f94.png)
