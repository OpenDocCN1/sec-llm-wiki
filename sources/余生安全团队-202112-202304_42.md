# DVWA 搭建教程

## 1\. DVWA 介绍

### 1.1 什么是 DVWA

DVWA（Damn Vulnerable Web App）是一个基于 PHP/MySQL 搭建的 Web 应用程序，旨在为安全专业人员测试自己的专业技能和工具提供合法的 环境，帮助 Web 开发者更好的理解 Web 应用安全防范的过程。

## 2\. DVWA 下载

进入 DVWA 官网，点击 DOWNLOAD 开始下载源码，下载链接可以在公众号后台回复 DVWA 获取。

![](../Images/2ab2856e9398d5ea4356114c0a7138c2.png)

## 3\. DVWA 安装

### 3.1 Windows 环境

#### 3.1.1 放入 Web 目录

将下载的压缩包解压到 Web 目录，这里我再将 DVWA-master 改名为 DVWA。

![](../Images/6ff8b5820f8706cb20d76d77c14c9b53.png)

#### 3.1.2 修改配置文件

修改 DVWA 中 config 目录下的 config.inc.php.dist 文件，先将其改名为 config.inc.php，然后再修改数据库中的配置信息。

![](../Images/8991e11c2d581202b02168a62d6462d1.png)

将 db\_user 和 db\_password 修改为自己数据库的用户名和密码。

![](../Images/36546d23166fd797a6f4b74c631b1c15.png)

#### 3.1.3 创建环境

然后使用浏览器访问自己服务器中 DVWA 地址 http://192.168.102.128/dvwa/index.php，点击「Create / Reste Database」创建数据库。

![](../Images/7d237147f4efdaae1c41071e0c57411c.png)

当出现下面内容时说明安装成功，点击 login 或者稍等一下就会跳转到登录页面。

![](../Images/84e996f344881b789b332891863d5c2a.png)

使用 admin/password 进行登录。

![](../Images/df50b27b85eef083d95ecce560b91e83.png)

登录成功后就可以看到 DVWA 的首页内容了，可以点击 「DVWA Security」设置 DVWA 靶场的漏洞等级，到这里我们就是用 Windows 成功安装了 DVWA 靶场环境。

![](../Images/de231c32a156f5b354585ef20ab8c979.png)

### 3.2 Linux 环境

#### 3.2.1 放入 Web 目录

将下载的压缩包解压到 Web 目录，这里我再将 DVWA-master 改名为 DVWA。

![](../Images/ac54266bc917270c8a1de61052dd4d0f.png)

#### 3.2.2 修改配置文件

修改 DVWA 中 config 目录下的 config.inc.php.dist 文件，先将其改名为 config.inc.php，然后再修改数据库中的配置信息。

```


cp config.inc.php.dist config.inc.php
```

![](../Images/ab16b80753627e9ec372f19d97352efb.png)

#### 3.2.3 创建环境

然后使用浏览器访问自己服务器中 DVWA 地址 http://192.168.102.145/dvwa/index.php，但是访问后发现出现了错误，这是由于权限存在问题而导致了。

![](../Images/9ff70a5f6d7c1821bdb1891782ba68a3.png)

针对该问题我们可以将提示的目录或文件加上权限即可。

```


chmod 777 /www/admin/localhost_80/wwwroot/dvwa/hackable/uploads/
```

![](../Images/e0d45103d5edb8f4d437275d359ca7b0.png)

之后再重新访问发现已经都 Yes 了，点击「Create / Reste Database」创建数据库。

![](../Images/9d0284d63fbc8fc9f1135ac72a98d110.png)

当出现下面内容时说明安装成功，点击 login 或者稍等一下就会跳转到登录页面。

![](../Images/e4e4841c990c68125522938900517170.png)

使用 admin/password 进行登录。

![](../Images/9e0eeb4b8a6056c155ca1741ad2416cf.png)

登录成功后就可以看到 DVWA 的首页内容了，可以点击 「DVWA Security」设置 DVWA 靶场的漏洞等级，到这里我们就是用 Linux 成功安装了 DVWA 靶场环境。

![](../Images/fad1cae6ec668416d91c1bb988beeea0.png)

### 3.3 Docker 环境

#### 3.3.1 搜索镜像

使用 search 命令去搜寻 dvwa 的相关镜像内容。

```

docker search dvwa
```

![](../Images/21f055f9353c53b027f85fa638839fb5.png)

#### 3.3.2 拉取镜像

使用 pull 命令去拉取我们需要的镜像，这里以 infoslack/dvwa 为例。

```

docker pull infoslack/dvwa
```

#### 3.3.3 创建容器

拉取完镜像后使用 run 命令来创建容器，前一个 80 代表的是本机的端口，后一个是容器的端口，从而达到映射的目的。

```
docker run -d -p 80:80 infoslack/dvwa

```
