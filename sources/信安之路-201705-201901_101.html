前不久我们信安之路成立多个兴趣小组，也发布了一个文章《信安之路兴趣小组组建完成》，随后我们的设计师为我们所有的兴趣小组都设计了专属 logo 做为群头像，下面给大家展示一下设计师的辛苦成果。

信安之路官方群

信安之路学习交流群

本群是从公众号建立之初就创建了，是所有小伙伴聚集的总群，所有在信安之路发布过文章的小伙伴都在这个群里，所有的兴趣小组成员也都来自于这个群，是我们信安之路的总群，一切的一切都从这里开始。

RTIS Security Team

这个群的成员都是在信安之路上文章数量和质量达到我们成员选择标准之后加入的作者，还有一些有多年安全经验的朋友，对我们的作者提供一些技术支持，后续我们对于成为作者团队成员的审核比以前难，除了要完成三篇文章发布公众号的硬性指标外，还要从积极性、文章质量等方面判断是否适合加入作者团队，一切的决定权有所有作者团队成员决定。

信安之路管理群

这个群的成员包括所有兴趣小组的组长，由 myh0st 直接领导并对他们各个小组的管理提供一些帮助，不管是经验上还是金钱上的，也算提供一个管理经验交流平台，目的就是将我们的各个兴趣小组越做越好。

信安之路兴趣小组

信安之路 CTF 小组

这个小组的成立有三个月了，提交周报已经到十二周，有不少小伙伴坚持了下来，这里的学习目的就是关于 CTF 的一切，比如：pwn、web、crypto、misc 等，聚集了一批热爱 CTF 的小伙伴，希望在不久的将来，大家可以在比赛中取得好的成绩。

信安之路 SRC 小组

这个小组的主要目的是交流挖掘企业安全漏洞，为各大 SRC 平台提交漏洞，聚集一批白帽子互相学习挖掘技巧，在 SRC 这条路上可以越走越远，我相信在不久的将来，会在各大 SRC 排行榜中看到他们的身影。

信安之路 web 安全小组

这个小组从名字上看就是专注 web 安全，无论是 web 安全学习路线，还是 web 漏洞的原理和技巧学习，在安全这个世界，web 是所有企业对外的窗口，是所有服务中应用最广泛的，安全问题也是非常多的，但是由于 web 安全存在已久，各方面漏洞以及学习资料都很成熟了，对于 web 安全学习那就是时间的问题了。

信安之路安全建设小组

安全建设是甲方企业必不可少的项目，由于国家的强制要求，每个企业都要做等级保护，为了企业的安全，安全建设必不可少，相信在未来的企业中，安全建设会越来越重要，这方面的人才也会越来越吃香，希望所有对安全建设感兴趣的小伙伴一起成长，成为行业的佼佼者。

信安之路代码审计小组

在安全这个领域，对于 web 漏洞的挖掘，代码审计可以说是最有效的方式了，很多大型企业的招聘都有关于代码审计的招聘需求，代码审计的能力的大小也就决定了你能否踏足大企业的门槛，希望所有对代码审计感兴趣的小伙伴在这个平台一起学习一起分享，共同提升自身的能力，未来不可估量。

信安之路无线安全群小组

在这个互联网时代，在世界的任何角落都会有无线信号的出现，任何企业或者个人家庭都有无线网络，无线安全必不可少，一群志同道合的小伙伴聚到一起一起玩无线，一起玩设备其乐无穷，兴趣是最好的老师，相信你们在无线领域可以大展宏图。

信安之路学生渗透小组

这个群里的小伙伴都是来自各个高校的在校生，对渗透测试有极大的兴趣，也是未来我们安全圈渗透测试的主力，希望大家可以在管理员的带领下奋勇直前，提升渗透测试能力，你们走的越远，我们信安之路越为你们而感到骄傲。

信安之路移动安全小组

在这个移动互联网时代，移动 app 随处可以见，移动安全问题不得不关注，这个小组的主要学习目的就是关于移动 app 的安全问题，比如：安卓逆向、iso 反编译，api 的接口安全问题等，希望大家齐头并进，提升自己，在未来的工作中体现我们的价值。

信安之路应急响应小组

在所有企业中，安全问题是不可忽视的，每每在企业遭受攻击之后，都一定要做应急响应，及时阻断攻击的行为，并取证，寻找问题的根源，找出攻击者并使用法律的武器维护我们的权益，欢迎所有在做应急响应或者对这方面感兴趣的朋友加入。

信安之路职业渗透小组

这个小组的成员都来自各大公司的渗透测试从业人员，人数控制在十人左右，会经常开语音会议分享自己在工作中遇到的有趣的问题，分享自己的渗透经验，在渗透测试这个领域越走越远，兄弟齐心，其利断金，相信你们未来会更好。
