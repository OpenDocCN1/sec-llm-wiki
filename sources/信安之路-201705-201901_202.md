# JBOOS反序列化漏洞复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5MDQ2NjExOQ==&mid=2247485724&idx=1&sn=9e27e1bc6fd5a0dee76abcd395a2506f&chksm=ec1e3934db69b022c083392ffbbeb493a7f220b1d90a2c76ad0e30727e1ea4e33cbacd4ccd15&scene=126&sessionid=1681402745#rd](http://mp.weixin.qq.com/s?__biz=MzI5MDQ2NjExOQ==&mid=2247485724&idx=1&sn=9e27e1bc6fd5a0dee76abcd395a2506f&chksm=ec1e3934db69b022c083392ffbbeb493a7f220b1d90a2c76ad0e30727e1ea4e33cbacd4ccd15&scene=126&sessionid=1681402745#rd)

2017 年 9 月 14 日，国家信息安全漏洞共享平台（ CNVD ）收录了 JBOSS Application Server 反序列化命令执行漏洞（ CNVD-2017-33724，对应 CVE-2017-12149 ），远程攻击者利用漏洞可在未经任何身份验证的服务器主机上执行任意代码。  

漏洞细节和验证代码已公开，近期被不法分子利用出现大规模攻击尝试的可能性较大。

### 0x01. 漏洞复现

**1). 环境准备**

> JBOSS 下载地址：http://download.jboss.org/jbossas/6.1/jboss-as-distribution-6.1.0.Final.zip

> EXP 下载地址：https://github.com/yunxu1/jboss-\_CVE-2017-1214

**2). 环境搭建**

`第一步：下载 JBOSS 环境，并解压`

> wget http://download.jboss.org/jbossas/6.1/jboss-as-distribution-6.1.0.Final.zip 

![](../Images/fe5c5223e5f969b81e763e1cf9a37584.png)

`第二步：修改配置文件，使网络中的主机都能访问 JBOSS`

> vim ~/jboss-6.1.0.Final/server/default/deploy/jbossweb.sar/server.xml

![](../Images/cedd6a66434578a5b8f0dea70786c47a.png)

`第三步：启动JBOSS`

> ./jboss-6.1.0.Final/bin/run.sh

![](../Images/d266d40ba53ca3f3e453491c016a8e6a.png)

`第四步：下载EXP`

> git clone https://github.com/yunxu1/jboss-\_CVE-2017-12149

![](../Images/06a82f42f9fc8853ab28d78ab639d071.png)

**3). 信息收集**

`第一步：利用nmap对目标主机进行常用端口扫描`

> nmap 192.168.1.111 -A 

![](../Images/8e2ea41299c4830a6e5de65c8eb03798.png)

`第二步：访问目标主机的8080端口，看看能否正常访问`

![](../Images/7365f4420c1104296eff8376b1321a7d.png)

**4). 漏洞利用**

利用刚才下载好的 EXP 进行漏洞利用，打开 `jboss 反序列化_CVE-2017-12149.jar`

![](../Images/fe138e0a4ef7f204822d822f4cb8e7a3.png)
