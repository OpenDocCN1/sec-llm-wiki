# 精简版 WIN10 所占磁盘减小了六倍是如何做到的

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5MDQ2NjExOQ==&mid=2247497107&idx=1&sn=352f016e31401f2acf253c4f268fc3eb&chksm=ec1dc5bbdb6a4cad5cabd4ca316c1bd0fd4430e8983964d6b99ad551e10ae48bcf3925f5d51e&scene=126&sessionid=1681402431#rd](http://mp.weixin.qq.com/s?__biz=MzI5MDQ2NjExOQ==&mid=2247497107&idx=1&sn=352f016e31401f2acf253c4f268fc3eb&chksm=ec1dc5bbdb6a4cad5cabd4ca316c1bd0fd4430e8983964d6b99ad551e10ae48bcf3925f5d51e&scene=126&sessionid=1681402431#rd)

今天看到一个精简版的 windows 10 系统，几乎删除了所有不影响系统运行的软件，保留了基本的应用，比如记事本等。下载地址：

> https://mega.nz/file/rkkEnChZ#f92ZU1rHiwdSBlcQWkugnsF0jO6f\_EjhGdvF6YFna78

据说安装完之后，系统盘只占 3.25 G，赶紧下载试用一下

新建个虚拟机，一样的安装流程，根据提示下一步即可

![](../Images/9bd6f0ce0934c4686253ac404d693b56.png)

没过一会儿，安装完成，中间会有一段黑屏时间，因为原来 windows 的默认提示程序也被删除了，接下来看看有多精简

![](../Images/67381e9af735a216b884ef268fc2bc0d.png)

先看看安装完成之后的系统盘占用多大（4.88G）：

![](../Images/9538292dec56db702e7b8373e7dc6a45.png)

进去看看 windows 文件夹有多大（3.05G ）：

![](../Images/fefba9f671b38b1e673b37eb29835eb1.png)

那么未精简版有多大呢？**18.2 G，精简版比未精简版足足小了 15 G：**

![](../Images/68e1ad0435ddcf451c4419de7cdbd554.png)

那么少的这 15 G少在了哪里？看看菜单就知道了：

![](../Images/13703c442494163cf85433cfe36f4f8b.png)

除了 windows 最基本的程序，没有任何多余的应用。

![](../Images/17b2f8d48d9768db5fcf7a0177555f5e.png)

仅有的这两个还是我自己安装的，系统未带任何程序，是不是很清爽，需要啥用啥，没有一点多余东西，不过目前只有 x86 版本，没有 64 位系统。

那么你觉得这种精简版的系统有必要存在吗？
