# 小姐姐的信息安全技术学习经验分享

我向来对生活充满了憧憬，退休后至期颐之年正是我追求享受生活的时间，那便意味着前四分之二是我奋斗不停歇的日子，而前四分之一的时光终于在不需要父母补给我学费和生活费中逝去。

小时候，读过一篇文章——《山的那边》，山的那边依然是山，但翻过了重重高山后，最终一定会看到海！前四分之一的大山，我数了数，5 座！

自认为，我是那个翻过了家乡第一座山的孩子，在山的那边，是县里知名度最高的一所初中，是一群来自区县最优秀的求学子，也是我智力发育、萌发信念感的两年。

初二下学期，学校有 120 个名额，将优异的学生送进市主校区进行初三阶段的学习。所以，我又跨越了第二座大山，在资源富裕，氛围浓厚的市重点初中进修。也就十来岁的我第一次感受到什么是压力，什么是破釜沉舟。

中考那年，我以高分翻越第三座大山，考入市重点高中。这是拼搏又快乐的三年，经过这么多年的义务教育，我也终于感受到，只有快乐学习，成绩才会反馈给你快乐！三年后，我跨越第四座大山，考上还不错的 985 双一流高校，并且就目前的形势来看当时也选了一个不错的专业。

本科是我充分认识自我，感知环境的四年。所成长的不仅是我的心智，还有我为人处事的态度，职业规划的深思，以及自我思考的形成。四年后跨越第五座大山，我考上研究生了呀！

![](../Images/3c457cd9b9fa9a12286b5998e3a21e40.png)

其实生活中还有很多小山小小山，但是目前来说，教育与学历是我四分之一人生中重要的转折点，是机遇，也是挑战！能有现在的认知，前十二年的教育积淀是非常有意义的，而本科四年与研究生三年的自我成长是最功不可没的。

自信是勇于跨出第一步的成就。大学里我勇于社交，担任年级会办公室主任，班级团支书，组织“奔跑吧，程序员”，参与十佳优秀班级答辩等。加入笑林剧组出演小品，担任晚会主持人。任湖南学生社团联合会媒体中心副主席，全权负责“百团大战”，“迎新晚会”等大型活动的宣传策划。

![](../Images/d3e271eaffee325670db71eb10061f6f.png)

担任湖南大学子弟小学校外辅导员，参与暑期三下乡文化调研与支教活动，当学生角色置换为老师的时候，也更加理解了为人师表的付出。在人际交流中，组织管理中，角色互换中获取到自信的成就感，是我保持和善交际源源不断的动力。

![](../Images/1ff430c734cd25a62b72bb8c53b2f0a4.png)

自律是美德，也是人在确定目标并通过思考打开自己后的人生花朵。我认为自己人生有大把前程，尚有很多进步空间，比如知道自己在重大抉择中的成因，和自己的积习何以形成。

人能保持一时的奋进之势，靠企图心可以，靠兴趣可以，靠内卷可以，甚至靠虚荣心都可以。想保持一生奋进之势，则必然需要有理想，也要有强大的自律。

**学业上自律**，在课业成绩上、学术造就中有所积累，连续 3 年荣获国家励志奖学金，二等奖学金，单项奖学金等。硕士研究生连续2两年荣获国家一等奖学金。

![](../Images/91ca09f47152dfeaf65f1f19db648bf3.png)  

**竞赛中自律**，在理论学习中，实践技能上有所成长，参与华为网络技术大赛，华为大数据考试认证，信息安全等级水平考试，奇安信军民融合考试认证等。获得数学建模二等奖，华为杯第十七届数学建模竞赛三等奖，全国大学生英语科研演讲比赛三等奖等。

![](../Images/b42fa5ffc569bcb906f245139d5bae15.png)

**在锻炼中自律**，身体依然是革命的本钱，每周瑜伽锻炼，跑步训练，让体能和脑能相互促进，相辅相成。

![](../Images/c83b02fbac67b4ffc28d659d8e0e3a90.png)

 

自我沉淀是源源不断的自我输入与输出。我自觉自己起点低，境界也低。很多时候越计较自我，便越没有发展前景；相反，越是主动付出，那么也就越快速发展。为什么说自己起点低境界低呢？

真正接触到安全行业是从 2018 年的暑期实习才开始，且在接触后至 2019 年没有领路人。2018 年在湖南合天智汇有限实习进行了 web 常见漏洞的理论学习与实践，并获得优秀实习生。

![](../Images/02878bcf54c72b8a4b3ede8ad6f53b8e.png)

在实习中沉淀是成长的最快的一个方式，有目标有方向，有自己的探索以及导师的指导，更重要的是，实习中更加了解这个行业的动向，对自己的职业规划有重大影响。

考研其实也是自我沉淀的好方式，在长期的备考阶段，我只管全心全意，按部就班。未来是不确定的，但这个过程是稳定的，冷静的，深刻的沉淀。我很喜欢我考研时的状态，那种自如，求知，奋进的状态。之后很长一段时间，我一直在摸索自己的学习方向与学习状态，除了参与研究生阶段的实验室项目，课题学术研究以外，加入了信安之路成长平台。

![](../Images/a87ef8da0b0feaf70b49cdd56115c65d.png)

信安之路成长平台的自我沉淀，不仅把握了成长的方向，而且还伴随着自学能力的进步，还有自我管理能力的提高。

从百名开外到排行榜前 5：

![](../Images/f34f33998142a5d1e294791179f4c3c4.png)

都是我能力的证明。学不能一时兴起，三天打鱼两天晒网，而需要持续输入与输出，态度是极其重要的。在我学习的过程中，我感到很快乐。理论知识的积累，让我在这个领域里能够充分表达我的观点；靶场实践中的锻炼，让我充分发挥头脑风暴式的思考能力；撰写报告的习惯，让我温故而知新。而我的信安之路成长经验，就是对每一个任务都很用心，我所撰写的每一份报告，首先让自己满意。

四分之一很长，但也很短，每一刻都有意义，但无法列举穷尽。我的前四分之一，从山底开始，把自己沉淀再沉淀倒空再倒空归零再归零，登上一座座山顶。我始终相信，山外有山，天外有人，自己还远达不到自己眼中的优秀，但是自己能感受到自己的进步就是一种成就。下一个四分之一，我来啦！
