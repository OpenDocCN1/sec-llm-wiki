今天来分享一下我拿到一个新的电脑之后优先安装的几款软件，也是日后工作所必须的软件，因为本人之前用 Windows 居多，所以以 windows 为例。  

### Emeditor 编辑器

![](../Images/fdecfb8db273fdb20ae29960b38941f1.png)

下载地址：

> https://www.emeditor.com

常用功能：

1、多文件查找和替换

2、自动去重、排序

3、打开巨大文件

### python 运行环境

![](../Images/82778c87545892a92793d1f9ec03c0ba.png)

下载地址：

> https://www.python.org

建议 python2 和 python3 均安装，安装完成之后，将安装目录设置到全局变量中，分别将 python2 的 python.exe 重命名为 python2.exe，python3 的 python3.exe 来进行区分，快速调用。

### burpsuite

![](../Images/f8dd8675766fb1716be661d48947cf05.png)

官网地址：

> https://portswigger.net/burp

这个算是非常火的软件了，版本更新也很快，破解版更新的也快，下载地址不提供了，自行寻找，信安之路之前分享过的一个：

[**原创** *妈妈*再也不用担心Burp过期了](http://mp.weixin.qq.com/s?__biz=MzI5MDQ2NjExOQ==&mid=2247486369&idx=1&sn=9dfad1fcfde8d6dcea77d302e14d7b02&chksm=ec1e3b89db69b29f24ca07edeba2c65f8dbce013fe3613f3ad328b908e41c12665b07f34d1e1&scene=21#wechat_redirect)

安装前提需要 java 运行环境，需要提前安装

### git

![](../Images/1a8c750bf257ef0c104da997b2904d1f.png)

下载 github 上的工具时，需要用到 git，下载地址：

> https://git-scm.com/downloads

使用命令 `git clone` 就能将 github 上的工具克隆下来，其他用法自行挖掘

### cygwin

![](../Images/6b5f265508e1395446276dd07e881bc3.png)

下载地址：

> http://www.cygwin.com

这是一个模拟 unix 系统的软件，可以在 windows 下运行，在 linux 下好用的命令都可以通过这个来运行，比如 sort、uniq 等

### 最后

这是我推荐的几款 windows 下必用的软件，如果你有经常使用的软件，欢迎留言讨论
