个人惨痛的自学背景  
  

  

在上学期间是非计算机专业，起步比较晚，而且自认不怎么聪明^\_^目前在某乙方安全工程师，负责产品方向，在某 src 赚过 2 百多块钱，也就找找信息泄露和业务逻辑之类的漏洞，找的挺辛苦，就是因为基础太弱，所以不能有更多的发现，工作几年自己攻防技术一直停滞不前，培训视频看了很多，相关文章也看了不少，但就是技术提升不上去，总感觉像是没头的苍蝇在乱飞乱撞，后来在机缘巧合下看到了群主发起的小白成长计划，看到了其中的一些学习计划内容后，毅然决定加入学习，因为这正是我几年来最想要的，WEB安全涉及的内容太多，太杂，说实话，没有人指指路，很容易走偏和无从下手。

  

  

  
技术学习还是要多动手  
  

  

  

学习过程中有点其实挺烦的，就是比如 sql 注入反反复复的看网上的视频，其实对这个洞的原理始终没有掌握，归根就地就是眼高手低，缺少了自己动手实践 归纳总结的过程，所以看视频只是看了一遍别人的成果，也就是看了个热闹，花了学习时间，结果还是自欺欺人，自从加入小白成长计划，能将相关知识点通过自己手动实验的方式，归纳总结，明白了其中的原理加深了印象，就能有底气的和别人说自己真正的会了，掌握了 sql 注入，而不是去背一些知识点，导致最终不能灵活运用。

  

  

  
基础积累还得靠自学  
  

  

  

在之前自学的过程中，碰到了问题，一段时间解决不了，就很容易放弃，很容易打击学习的积极性，自从加入了成长计划，有很多人都可能会遇到想同的问题，解决起来真的很快，学习效率也杠杠滴。

  

还有一点自学的过程中，总是有想懒惰的时候，不想学习，这个平台学习氛围很好，看到别人的分数不断上升，就忍不住去学。看着自己写的一篇篇文章，都是自己的收货颇有成就感，不忍就这么放弃了。

  

现在的我没有了当初刚毕业看到公司渗透测试人员做网站测试满脸崇拜的眼神，有的想的更多的是如何加薪，怎样受到领导的重视，怎么利用自己已有的知识储备在客户现场快速的解决问题

  

  
2020年的规划  
  

  

  

（1）在后续学习中，要牢记快就是慢的原则，把知识点吃透，才能不会再费功夫来回返工

  

（2）依据平台的计划不断夯实基础，遇到新的内容，及时归纳总结到相关内容的知识点，形成自己个人的一个知识库，方便后期遇到问题查阅

  

（3） 本着WEB安全>>应急响应>>渗透测试>>内网安全的学习计划，今年看到一个全新的自己

  

（4）将学习到的计划内容吃透，然后总结归纳成自己的，做部门技术分享
