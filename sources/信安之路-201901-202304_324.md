# 在生命面前其他的一切变得黯然失色

2020 年春节，瘟疫横行，人心惶惶，在天灾面前，人类显得如此脆弱，在生命面前，人生的成就、拥有的金钱、都变的没那么重要了。今天篮球巨星科比也出事了，私人飞机失事，结束了自己的一生。天灾和意外哪个先到来，谁也不知道，作为一个平凡人该做些什么？又一次激发我们思考生命的意义，人生的价值。

我们这些安全从业者，出现网络安全事件或者病毒我们可以出一份自己的力量，而面对公共安全问题，生物病毒非我们专业，现阶段，病毒还没有特效药去对抗，在安全领域还算 0day，你再有钱、再有名，感染病毒之后的治疗方案与常人无异，在此期间，人人平等。

现阶段能做的只有尽量不感染，在传播途径上下功夫，蜗居、戴口罩是不错的选择。在此期间寄希望于各位病毒专家们，早日研究出疫苗、找出有效的治疗方案，到时瘟疫自然能够得到解决，只会是时间的问题。

如今武汉的同胞处在水深火热之中，而网络谣言漫天飞，为了流量制造恐慌，全民恐慌对于我们对抗病毒没有任何好处，理性应对，积极配合专家的意见和建议，作为一名安全从业者对于谣言是有一定的识别能力的，在互联网领域有一定的积累，我们自己应该做到不信谣、不传谣，还要识别谣言、澄清谣言、传播正能量。

看到全国人民都在支援武汉，有钱的出钱、有资源的出资源，各大公司也在纷纷利用自身的优势支援武汉，全国人民众志成城，为了打赢这场仗而努力，这是非常值得骄傲的事情。

好人和坏人永远都是相对的，也看到不少投机分子，借机赚取不义之财，回收口罩二次销售、制假售假，试问你们的良心何在？关乎生命，钱真的比生命更重要吗？

还有一个泄漏武汉回乡人员名单的事情，个人隐私数据不是随便泄漏的，为了自己而泄漏他人隐私的行为是可耻的，试想一下，如果是你的隐私被泄漏，你做何感想？

武汉面临医疗资源短缺，医护人员不足、精力有限，加上人人恐慌，稍有不适就去医院，在互联网安全领域这种情况就好像，有一个安全平台，每天收到的告警非常多，误报消耗审核人员的大量精力，可能出现真实有效告警被淹没的情况，所以降低误报率就变得非常重要。

降低误报，就需要有一些可以区分有效和无效告警的特征，先让受害者先用简单的方式验证告警的真实性，然后再推送告警到审核运营人员手中进行处理，可以大大降低审核人员的工作量，同样的，关于病毒感染，如果有一个简单有效的验证方式，让大家自行做一些初步的判定，然后再去医院，既可以减少医疗资源的消耗，还能预防交叉感染，毕竟医院才是病毒的聚集地，也是最危险的地方。

好多人都在骂武汉的领导们，没有及时报告此次事件，导致事情严重化，这也给我们互联网安全从业者提个醒，安全告警处理不能抱有侥幸心理，越早发现、越早处置对于公司的损失越小，处理起来越简单。

病毒的根源发现来自于一个野味市场，由于自身安全意识的缺乏，导致病毒进入人的身体，成为传播源，互联网的病毒传播亦是如此，互联网的安全问题大部分都来自于人的安全意识不足，一个感染，传播一大片。

2020 年与所有安全从业者一起共勉，瞎说一通，还请谅解！
