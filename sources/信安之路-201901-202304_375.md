信安之路的小白成长计划也已经到了第十周了，完成学习目标的小伙伴也越来越少，大多数因为没时间，工作忙等原因，但是总是有同学完成任务，所以任务也在不断更新，目前已经进入了第三阶段关于 web 安全中最常见，危害最大的 sql 注入的学习，所以给大家简单说一下第二阶段都有哪些任务，我们这段时间都在干什么，参与计划的同学都在学什么。

![](../Images/7866b8eb3b70f32dd77cf0bb17764bea.png)

这是第二阶段整个过程中所涉及的任务目标，主要目的是学习数据库基础，为 sql 注入的学习打基础

![](../Images/fb8370d72becac85608198230aeca440.png)

以上这是在发布第六周作业时，对于学习目标的一些解释，正常来说，我们每周日都会来一个不到一小时语音会议，然后会将会议内容进行整理发布到知识星球，内容不限制，可能是针对作业的解释，也可能是一些经验分享等

![](../Images/2b1e96c3497d2c571a688b1e234446ba.png)

这是在看了几份同学完成的作业之后发现都走偏了，可能是对任务的理解有出入，所以在新一周的会议上及时指出并做了调整。

知识星球里还有很多关于信息安全从业人员个人成长的资料和原创心得，有些不适合发布到公众号的就直接在星球分享啦。

目前成长群里完成任务的情况如下：

![](../Images/15fd89b17187e3f16cb0d39b954ac4a9.png)

希望群内的小伙伴，不要掉队，尽快完成之前拉下的任务，后续想要进群的同学需要同时提交到当时进行到的任务目标所有报告才可以，因为群内的小伙伴都是从一开始就在的，如果不断有新人加入，会影响大家的心情和积极性，所以会对于后续加群的小伙伴进行严格的控制。

即使没有加入知识星球也可以跟着这个任务计划去自学，有一些小伙伴把自己的学习过程记录到了 github 或者 自己 blog 上，需要参考的可以自行通过搜索引擎去寻找，我们在圈子里留了一个置顶主题来收集这些分享的途径，方便圈子里的同学学习。
