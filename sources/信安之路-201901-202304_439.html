信安之路推荐书单

《计算机安全：原理与实践（原书第4版）》

信息安全行业也算计算机领域的一个分支，所以学习信息安全技术，计算机相关知识是必备的，所以推荐下面这本书：

本书是计算机安全领域的经典教材，系统介绍了计算机安全的方方面面。

《Web 安全防护指南：基础篇》

对于初学信安技术的同学，除了要学习计算机相关基础外，接下来要学就是 web 安全了，从就业来看，web 安全的需求还是最大的，所以推荐下面这本书：

这本书展现 web 安全体系，揭示 web 安全与防护的核心方法。

《Kali Linux 高级渗透测试（原书第2版）》

工欲善其事必先利其器，对于渗透而言，渗透工具决定了你能做的很多事情，kali 做为安全从业者必学必会的操作系统，其中工具库更是一个安全技术宝库，每一个工具背后都是前辈的技术积累，会用的同时学习其背后的原理是至关重要的，所以推荐下面这本书：

Kali Linux 面向专业的渗透测试和安全审计，集成了大量精心挑选的安全检测工具。本书在 Kali Linux 平台上从一个攻击者的角度来审视网络框架，详细介绍了攻击者“杀链”采取的具体步骤。通过阅读本书读者能快速学习并掌握渗透测试方法和工具。

《C# 灰帽子：设计安全测试工具》

作为安全从业者，会使用工具只是第一步，会写工具，将自己的思路进行自动化，节省我们的测试时间，可以让我们做更多的事情，解放双手势在必行，所以推荐下面这本书：

《Android 应用安全防护和逆向分析》

随着移动互联网时代到来，移动 APP 的地位逐步提升，安全问题也随之而来，越来越多的公司开始重视移动安全方面的问题，所以推荐下面这本书：

360 公司创始人周鸿袆、CSDN 创始人蒋涛、看雪学院创始人段钢等联袂推荐。零基础学习移动安全技术，手把手带你进入逆向分析领域

《企业安全建设入门:基于开源软件打造企业网络安全》

对于从事甲方安全的小伙伴，安全建设是其主要工作，很多新入门的小伙伴进入甲方之后无从下手，下面的这本书可以给大家做为指导，使用一些开源的软件就可以帮助企业提升一定的安全防御能力：

百度安全专家撰写,零基础、低成本搭建企业安全防御系统，多位业界专家联袂推荐。

《企业安全建设指南：金融行业安全架构与技术实践》

行业内，对于安全要求最高的可数金融行业了，在国内各种强监管之下，以及直接涉及金钱交易，黑客有利可图导致金融行业的安全问题备受关注，一旦出事将会是大事，会造成非常大的损失，如果你想要将来从事金融行业的安全建设，那么推荐阅读下面这本书：

金融行业资深信安专家十余年实战经验的结晶，安全领域多位专家联袂推荐。

《云数据安全》

随着云时代的到来，各种公有云、私有云的出现，大大降低了公司在基础设施上的投入，而且加快了互联网企业的发展过程，随之而来的安全问题也在慢慢被人们所关注，云数据的安全问题是非常关键的，可能会决定一个公司的生死，所以推荐大家阅读下面这本书：

本书主要介绍云数据安全的相关背景、几种重要的云数据安全的保护方法和针对具体应用场景的一种集成化云数据安全保护系统。

《网络空间安全防御与态势感知》

随着安全技术的发展，态势感知火了起来，从整体上看企业或者国家的安全问题，将安全相关的所有数据进行可视化，希望可以做到感知攻击、预测攻击，化被动为主动，本人对此研究不深，推荐大家阅读下面这本书：


全面阐述态势感知的基础理论，黄晟、肖新光万字序言深入解读网络安全企业如何研发态势感知技术解决方案

《网络安全态势感知 提取、理解和预测》

在我们了解完态势感知是什么之后，如果做到呢？整个提取、理解和预测的过程是什么，下面这本书可能让你有所了解：

系统介绍网络安全态势感知的原理、技术、实施过程。
