### 原理介绍

先在 win 环境安装 HDSDR，下载好了以后进入 HDSDR 里面，在里面加入一个叫 `Extlo_RTL2832.dll` 的应用程序扩展，在安装 RTL2832 的驱动

![](../Images/1b8909719202c0b584e68fc179153501.png)

首先插上电视棒，在打开 Zadig 选择 Options-List AII Devices 然后安 Replace Driver 安装好的提示  

![](../Images/83b14ba2c63820666365b4b7a14f4a5e.png)

接下来就进入软件  

![](../Images/fd5ae445deeb03b8b21e07a5181e90a0.png)

在 Options 里面选择你的设备 RTL2832，在 HDSDR 里面设置频率，那频率怎么设置？我们常见的无线钥匙有 315MHz，433MHz，868MHz，915MHz 这几个频点上，基本上都采用 ASK 调制方式，可以通过晶振，`FCC ID` 来确定设备的工作频点信息。  

这个是我的 433 模块的图银色的晶振上面就会刻有这个设备工作的频率是多少，还有就是一些无线设备他外面会有 FCC 的编号可以去 FCC 里面查询，而我的钥匙上面什么都没有，只能一个个试。没有想到第一次测试就中了

![](../Images/b7ae04a7d6ee4903329ff5934a832982.png)

我们可以看到在 314.865.000 出现了一个波动，这个就是钥匙工作的频率（是点误差的）。  

![](../Images/91c84c2f8c66a4aa1fcd44a1af57f55c.png)

那就开始分析信号！！  

我们首先下载 Audacity，Audacity 是一款音频软件，而他可以帮助我们对我们录制好的信号进行分析，然后把我们录制好的电动车钥匙导入进去。如图：

![](../Images/71c478accdb2700bbb38115a6694983b.png)

我们把信号放大很多倍就可以看到这完整的一段信号了，但是我还不知道这个是什么型号的信号下面这个表就是常见的一些信号编码格式  

![](../Images/7f4f9b6d764bd177b5ee114360c85811.png)

![](../Images/45e17e7a73d636f641eb5557b965e367.png)

![](../Images/34ea300d58a045efd6228099a4fd5bc2.png)

经过对比我们可以知道我们的电单车钥匙是 PT224X 的格式，我们就开始分解这个信号有多少 1 和 0 码。  

![](../Images/5d81a5450e71249124774579ba000c09.png)

在把他转换成二进制的话，0 码 = 1000，1 码 = 1110 。  

我们就算地址位，第一个就是 0 码，第二个也是 0 码，第三个就是 1 码以此类推。再把计算出来的 1 和 0 在兑换成 1000 或 1110，就完成了二进制的转化。当然你可以使用软件进行转码

![](../Images/37ac39b2efd5fbcf8ad4d3984eb5dc20.png)

这些转码一些老司机就光看一下就可以知道了（我显然不是。。）  当我们分析完毕了我们就可以使用一些工具进行重放实验了。（实验环境具有一定的攻击性）

### 实验过程

#### 第一种方法：HackCUBE-special

HackCUBE-special 是由 360 独角兽团队打造的一款便捷无线电设备。

HackCube-Special 在我们做无线安全研究的工作中，常常在户外环境中对一些设备进行安全检测，需要抱着电脑，连接无线设备，蹲着或者坐在地上，总是吸引不少人的眼球，十分尴尬。于是我们希望打造一款小巧的设备，只需要把它装进口袋，通过手机或者平板电脑，就能特别方便的对这些设备进行安全审计。这就是我们做 HackCube-Special 的初衷。

HackCube-Special 是一款低成本，便携式，可工作在多个无线射频频段的无线电安全审计平台。我们会给HackCube-Special 提供丰富的案例，方便初学者能够更好的了解无线电安全领域。

使用 HackCube-Special 研究固定码遥控的安全风险

![](../Images/70b5208514c666d3319c27b81220af0a.png)

我们今天实验就是使用重放攻击（实验用的的电动车是固定码），作者也是非常有幸的成为第一批用户，使用体验非常不错。首先我们打开 CUBE 的开关，然后在登入他的后台。

![](../Images/1470abdf8ca2a5badbb22a6577036abe.png)

当我们在 CUBE 旁边使用一些未加密的无线电信号时 CUBE 会自动嗅探的到钥匙发射的信号，而我们也是可以把这个信号进行重放  

![](../Images/a21c3b7eca1ab8414048668427bf037a.png)

当我们按下 Replay 的时候，CUBE 就开始把之前嗅探到的信号发射出去了。  

除了 CUBE 这个设备还有很多无线电设备都是可以进行信号录制和重放的。

#### 第二种方法

我们可以使用树莓派加一个 RTL-SDR 在加杜邦线进行信号录制和重放，这样是做的话成本就低很多，而这里我们就需要一个项目，他叫做Rpitx的一个无线电的项目

![](../Images/98cb599cc10aaa60f113a4e4bbbe9329.png)

树莓派全部版本都是支持的，先自己安装号树莓派的系统。  

> sudo apt-get update
> 
> sudo apt-get install git
> 
> git clone https://github.com/F5OEO/rpitx
> 
> cd rpitx
> 
> ./install.sh
> 
> sudo reboot

附上 Github 的项目地址：

> https://github.com/F5OEO/rpitx

然后把 RTL-SDR 插在树莓派上面并且在树莓派的 GPIO 4 脚针上杜邦线当成发射天线。如图：

![](../Images/248c5b27a8d8271eed2db35857c7c3d5.png)

连接树莓派并且进入 rpitx 目录在执行 `./rtlmenu.sh` 在根据提示自己填写一些录制的信息，然后就可以重放了  

![](../Images/99102360c72e602d194b19c4733440fb.png)

但是他也是有缺点的，就是精度不行。。。但是能用就可以了。  

对于目前来说用不起那些专业的无线电设备来说这些入门还是足够了。

对于上面我们分析信号计算出来的二进制数字他可以配合 Arduino 解码并发送 433MHz RF 无线射频信号。360 独角兽团队的毛毛在 i 春秋上面就给我们演示了 Arduino+ 无线模块打开汽车车门。

![](../Images/ec464241d0d88a0f7b665360c0967682.png)

Arduino + 无线模块 + RC Switch 库就可以进行重放了。由于作者没有实验就不展示了。

### 总结：

目前无线电对于新手来说上手难度大而且设备比较昂贵，所以我也是非常感谢 360 独角兽团队能做一个这么好的一款无线电设备，这样让我们这些小白上手难度简单了不少。对于无线来说动手能力非常重要，目前无线安全面临的一些安全问题如：信号嗅探丶重放攻击丶干扰攻击丶遍历/篡改攻击等等。。。我也希望大家能多关注一下无线安全这些领域。
