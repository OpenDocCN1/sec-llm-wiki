隧道搭建

第一层隧道

拿到Debian主机权限

VPS主机启动frps监听：

[common]
bind_addr = 0.0.0.0
bind_port = 7000

Debian启动frpc：

[common]
server_addr = 192.168.53.132  
server_port = 7000          

[http_proxy]
type = tcp
local_ip = 10.10.20.131
remote_port = 8888  
local_port = 8888
plugin = socks5

proxifier配置：

就可以访问10.10.20.0/24网段了。
