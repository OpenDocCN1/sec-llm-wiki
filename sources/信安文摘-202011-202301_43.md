## 隧道搭建

### 第一层隧道

拿到Debian主机权限

**VPS主机启动frps监听**：

```
\[common\]
bind\_addr = 0.0.0.0
bind\_port = 7000
```

**Debian启动frpc**：

```
\[common\]
server\_addr = 192.168.53.132  
server\_port = 7000          
\[http\_proxy\]
type = tcp
local\_ip = 10.10.20.131
remote\_port = 8888  
local\_port = 8888
plugin = socks5
```

**proxifier配置**：

![](../Images/e2a6b261500cd0a3b1cb9b5fee8d47bb.png)

就可以访问10.10.20.0/24网段了。
