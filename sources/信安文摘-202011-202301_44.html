前言

平时在远程调试php项目时，会遇到xdebug版本问题。

每次调试时，如果目标环境是Windows运行的项目，可以直接在官方下载对应php版本的dll：https://xdebug.org/download/historical

但如果目标项目是运行在Linux系统，官方并未提供编译好的so文件，需要我们自行在对应的php版本环境下编译好so文件，并配置到目标服务系统上。

docker配置xdebug环境

本想着对各类系统做一份docker镜像，方便下次遇到直接运行docker编译xdebug。经过调研发现，GitHub上已经存在类似项目。

项目地址：

https://github.com/MilesChou/docker-xdebug

提供了四大类xdebug环境，使用docker进行构建。

PHP 7.2+ with Xdebug latest
PHP 7.1 with Xdebug 2.9.8
PHP 7.0 with Xdebug 2.9.0
PHP 5.x with Xdebug 2.5.5

看一下dockerfile是怎么构建的：

https://github.com/MilesChou/docker-xdebug/blob/master/5.5/apache/Dockerfile

FROM php:5.5-apache

LABEL org.opencontainers.image.source="https://github.com/MilesChou/docker-xdebug" \
    repository="https://github.com/MilesChou/docker-xdebug" \
    maintainer="MilesChou <jangconan@gmail.com>"

# install xdebug
RUN set -xe && \
        docker-php-source extract && \
        pecl install xdebug-2.5.5 && \
        docker-php-ext-enable xdebug && \
        docker-php-source delete && \
        php -v && \
        php -m

COPY docker-xdebug-* /usr/local/bin/

很简单，拉某个版本的php镜像，通过几条指令安装xdebug。

如果我们需要其他版本的xdebug，我们只需要拉取对应的php版本镜像，即可快速编译一个xdebug的扩展文件。
