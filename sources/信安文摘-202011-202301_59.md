
## 得到一个良好的交互式shell

对反弹回来的shell这样处理后，可以补全输入的命令、高亮显示等。

```
1\. 获得一个tty shell（根据上面的命令获取）
python -c 'import pty; pty.spawn("/bin/bash")'
2\. 键入 Ctrl-Z，回到 VPS 的命令行中；第二步，在 VPS 中执行：
$ stty raw -echo
$ fg
3.（这一步可以不做，回到哑shell后直接敲几下回车就可以了） 回到哑 shell 中；第三步，在哑 shell 中键入 Ctrl-l，执行：
$ reset
$ export SHELL=bash
$ export TERM=xterm-256color
$ stty rows 54 columns 104
```
