## 1、日志框架

## 2\. SLF4J 使用

**「1、如何在系统中使用SLF4j  https://www.slf4j.org」**以后开发的时候,日志记录方法的调用,不应该来直接调用日志的实现类,而是调用日志抽象层里面的方法;给系统里面导入slf4j的jar和logback的实现jar。

```
import
 org.slf4j.Logger;import
 org.slf4j.LoggerFactory;public class HelloWorld 
{public static void main(String\[\] args) 

{"Hello World"

);
```

```

<exclusion\>
```
