# 在 Linux 终端上的 10 个有趣的命令

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2MDQzMjY4NQ==&mid=2247489396&idx=1&sn=a6d26f70f134359cdd5396448637aac2&chksm=ce272736f950ae205f03425957cd1161eeca4e43632e3bc5837206991393197c2f6251fb7101&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2MDQzMjY4NQ==&mid=2247489396&idx=1&sn=a6d26f70f134359cdd5396448637aac2&chksm=ce272736f950ae205f03425957cd1161eeca4e43632e3bc5837206991393197c2f6251fb7101&scene=27#wechat_redirect)

  

Linux 的命令行不仅是一个复杂且强大的命令所在地，同时也是一个有趣的乐园。在本文中，我整理了一系列有趣的 Linux 命令，您可以从中获得乐趣。

1.  cmatrix

本列表中的第一个必须是 `cmatrix` 命令。曾经想拥有一个“电影般”终端的感觉来炫耀您的 Linux 技能吗？这个是给你的！

安装：

```

sudo apt install cmatrix
```

执行：

```

cmatrix
```

效果：

![](../Images/c335ef5d18d771324ec490a79c054102.png)

2.  xcowsay

绝对没有理由，看一头牛为你说话。`xcowsay` 命令接受一个文本并显示一头正在说话的奶牛。

安装：

```

sudo apt install xcowsay
```

执行：

```

xcowsay Linux is Fun!
```

效果：

![](../Images/1833013efb8ba534b297750e0403525f.png)

  

3.  sl

想用命令行旅行吗？蒸汽机车命令是正确的选择。观看一辆火车正跨越你的终端！🚂

安装：

```

sudo apt install sl
```

执行：

```

sl
```

效果：

  

![](../Images/4dd2b11e49e510d2be3e0abe56ddc341.png)

  

4.  aafire

将你的终端设置为火焰 🔥 吧 ，看看这个点燃的命令。

安装：

```

sudo apt install libaa-bin
```

执行：

```

aafire
```

效果：

  

![](../Images/e7d977fc1883fd27970a8b73aeb2da6f.png)

  

5.  asciiquarium

好吧，你不喜欢火。在自己的终端中拥有一个水族馆 🌊 怎么样？试试 `asciiquarium` 命令。附言 对于上述步骤，请确保安装了 `snap store`。

安装：

```

snap install asciiquarium
```

执行：

```

asciiquarium
```

效果：

![](../Images/c24be504bbcc0e604c01535163fac503.png)

  

6.  xeyes

运行 `xeyes` 命令来看看，这些眼睛 👀 正盯着你呢。

安装：

```

sudo apt install x11-apps
```

执行：

```

xeyes
```

效果：

![](../Images/09b3c9794b4bf20796e01f55f168a3a9.png)

7.  asciiview

好奇图像在只有 ASCII 的世界中会是什么样子？`asciiview` 将为您生成它们 🤖。

安装：

```

sudo apt install aview
```

执行：

```

asciiview your_image.png
```

效果：

![](../Images/14cb16c590d40eca06ed1a8d916fd2c5.png)

8.  yes（译者感觉这个命令并没啥意思 😄）

此命令会连续打印该行，除非您明确停止它。（提示：试试 Ctrl+C）

安装：

```

sudo apt install yes
```

执行：

```

yes You are Hacked
```

效果：

![](../Images/9ecd859608cee6726f681be89c91d26a.png)

9.  fortune

利用先进的深度学习和人工智能的力量，该命令将告诉你一个你的确切的命运 🔮。（开个玩笑啦，它会生成一个随机的命运文本）

安装：

```

sudo apt install fortune
```

执行：

```

fortune
```

效果：

![](../Images/f5ecbb4ce0c9a63eaef7a8b939f38661.png)

10.  banner + lolcat

谁说终端只会显示简单的字符和黑白的东西？试试这个 hack，并构建令人惊叹的横幅。

安装：

```


sudo apt install lolcat
```

执行：

```

banner Linux is Fun | lolcat
```

效果：

  

![](../Images/90c3d3b368aedac36f90b374cbe019ff.png)
