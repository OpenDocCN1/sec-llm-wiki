# 因上网套餐太辣鸡，老哥花98万自建光纤网络，承包村里70户居民上网

只因运营商提供的网络套餐又慢又贵，一老哥干脆自建了一套**光纤网络**！

而且不只是自己家能用，同镇的70户家庭都可以接入，网速可达**100Mbps**或**1Gbps**。

甚至当地政府都愿意为他提供**1700万**的资金帮助，让他的网络能覆盖到周围镇子。

![](../Images/8dba3c9d2f32c361a4a3255adb613751.png)

而这一切，都是因为五年前，这位老哥在升级宽带网络时，运营商开出了高达**33万元**的费用。

网友看了直呼他是Superman！

> 不穿紧身衣和披风，也能成为超级英雄！

![](../Images/b0a7f4f50e39218fbbb5fca8f2c448e7.png)

## 自掏腰包98万

上面提到的老哥名叫杰瑞德·毛赫（Jared·Mauch），是阿卡迈（Akamai）的一位网络架构工程师，住在美国密歇根州的乡村地区。

![](../Images/f8df1c466d2b7a601aaef242519c20c3.png)

大约5年前，他家的网络由美国知名运营商AT&T提供，但网速只有**1.5Mbps**。

用杰瑞德的话来说，这个速度放在2002年的话非常快，但是在2020年就不值一提了。

就拿我国运营商现在提供的宽带套餐来举例，基本都是在300-600Mbps。

所以，杰瑞德想把自家宽带升级一下，联系到了美国另一家大型运营商康卡斯特。

结果对方开出了一个天价套餐，需要支付**5万美元**（约合人民币33万），才能把网络拉到他们家。

这其中包括了一些网线的架设费用，即便他们的网络其实已经覆盖了周边地区。

面对如此高昂的价格，杰瑞德怎么都觉得不划算，所以干脆一不做二不休，自己来建光纤网络吧！

![](../Images/5f7ae177d6c1eb887055e79e29911da5.png)

为此，他先注册成立了一个专门提供互联网服务的公司Washtenaw Fiber Properties LLC。

自建的网络不光是自己来用，全村的居民都能申请加入。

前后算下来，杰瑞德花费了大约14.5万美元（人民币约98万）。

![](../Images/d113c7b0dbe0d393936a8de67dcb9627.png)

具体来看，杰瑞德自己找承包商铺设了光纤、找到了可接入的互联网供应商，还把自己家变成了一个网络枢纽。

首先是铺设光纤，他花了大约9.5万美元（人民币约64万）。

一般来说，光纤线路的位置在地下1.8米左右的位置。有时为了避开燃气管道和其他障碍物，可能会深达6米。

杰瑞德找到了专业的承包商来搞定这事儿。

![](../Images/0d1781c6cc45e21f703949639fa203a1.png)

此外，他还选择架设两套可以并行的导管，这样就能安装更多的光纤，后续还能出租或出售给别家公司使用。

![](../Images/1537d569d5c62f6438e97b6923182fd8.png)

而把光纤加到导管中，是杰瑞德自己搞定的。

用到的吹缆机，也是他用租来的空气压缩机改造的。

![](../Images/e592d75ad2f4f6eb30e9bdcc4562d7c6.png)

此外，他还花8000美元（人民币约5.4万）买了一台定向钻机，这样就能在马路下面安装电缆和导管，还能避免挖坑。

![](../Images/342f8f5b1ec2b02cc25b14ae6f1e8850.png)

至于网络方面，杰瑞德是从大型网络提供商ACD.net那里购买的。

他从自家拉了大约3公里的光纤出来，连接到最近的ACD.net地下电缆节点，然后杰瑞德家就成为了一个网络枢纽。

同时，他还设置了冗余备份。

甚至如果之后他把这处房子卖了的情况，也考虑到了。杰瑞德表示可以通过搞定地役权的方式，让自己依旧可以访问该房产上某些ISP的相关设备。

现在他的家里有一个用于和ACD.net通信的路由器、一个线路终端、一个用于网络测速的服务器、一个用于备份的Mac mini，还有一个用来当做备用DHCP服务器的树莓派和一个家庭发电机。

而接入的用户家，只需要安装一个光纤转换器（下图左侧设备），然后使用自己的路由器就能上网了。

![](../Images/7b989f143bcb799417cb5a7a9f867720.png)

目前，杰瑞德架设网络的套餐有两种。

一种是每月55美元（人民币约370元）提供100Mbps网络，另一种是每月79美元（人民币约530元）提供1Gbps网络。

安装费通常需要199美元（人民币约1345元）。

同时，杰瑞德还在参加一个“平价链接计划”，该计划可以让符合要求的家庭每月享有30美元的补贴。

现在，他大概为70个家庭用户提供互联网服务。

当地政府已经为其提供260万美元（折合人民币约1700万元）的资助，以进一步扩建网络。

现在，他铺设的光缆长度已经超过22公里，未来还将继续扩建61公里。

范围将从他所居住的小镇，拓展到附近4个镇子上，可覆盖417户家庭的网络。

计划要求杰瑞德在2026年底之前完成扩建，不过他表示大约在**明年年底**就能搞定。

而在网络上，杰瑞德的大胆尝试也受到了很多人的支持和认可。

有人表示，自己把这个故事读给同事听之后，大家都为杰瑞德欢呼。

![](../Images/8c90d0dc31351ff2cb62e1c91b54c58c.png)

还有同是网络架构工程师的网友询问，杰瑞德这么牛的方案，是否是可复制的？这样其他地区的居民也能享受类似的服务了！

![](../Images/88b338e552492bcfb95f209e13e9d942.png)

## One More Thing

杰瑞德的故事其实并不是个例。

对于欧美一些国家的乡村地区，由于人口稀疏、架设成本高，很多运营商都不愿意在此提供互联网服务，或者价格十分高昂。

在美国不少农村地区都自建了无线网络和宽带。

![](../Images/e674d2e0b8f448c4b6f1fabab327a7cd.png)

英国也有农民自建了网速可达900Mbps的光纤网络。

像马斯克的星链，主打业务也是为边远地区提供互联网服务。

据了解，星链提供300 Mbps的网络，月租在100-500美元左右。
