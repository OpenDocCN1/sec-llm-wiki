微软的Windows系统有过很多经典，对当前一代的网民来说，Windows XP系统可能是最难忘的，国内很多人触网都在Windows XP平台，而Windows XP已不再是一款电脑操作系统，它是时代的印记。


#01


Windows XP系统问世将近20周年


微软在2001年2月5日公布了Windows XP系统，当年8月24日发布了Windows XP系统的RTM正式版，它取代了1999年的Windows 2000系统，不过正式上市是当年的10月25日。


相比之前的系统，Windows XP在那个年代有很多创新，其中最主要的就是UI界面，同时还改进了性能，启动速度更快，也更稳定，当然更经典的还有IE6浏览器，这个更让人记忆深刻了。


对国内用户来说，很多人也恰好是Windows XP时代开始接触电脑、上网，国内最出名的当属各种Ghost魔改版XP系统，包括番茄花园、雨林木风等等，后来还惹上了微软的官司，这种魔改系统才逐渐消失，现在只有爱好者制作的非盈利版Windows 系统了。


Windows XP系统在2002年到2008年之间升级了三次SP3服务包，最终在2009年结束了主流支持，不过扩展支持支持到了2014年，在微软的Win系统中相当长寿了。



▷图片来源官方壁纸


时至今日，Windows XP早就不是主流了，但它在全球依然不算灭绝。


统计网站Statcounter 的数据显示它依然有0.59%的份额，比Vista的0.26%依然高出一倍多。


不过话说回来，这个网站是国外的，国内很多Windows XP用户并不知道更不会访问这个网站，所以Windows XP的实际份额更高，国内一些老机器可能还在坚守Windows XP。


某种深度上来说，坚守XP也是一种情怀使然，不过“年久失修”、长期缺乏安全补丁也意味着，上网存在诸多风险，容易沦为“肉鸡”。



#02


份额跌破1% 的Windows XP


黑色的背景，画面中央印有微软经典的Logo标识，下方写着Microsoft Windows XP的字样，再往下则是经典的载入进度条。如此经典的开机动画，我们不知道看过了多少次。


不可否认的是，开机动画是Windows XP的起点，同时也是我们回忆的开始。



▷图片来源官方介绍


Windows XP的图形界面拥有一个很好听的代号，名为Luna（月神），整个界面都经过了重新设计。Luna针对高分辨率的桌面进行了优化，引入了"选择任务"的用户界面，使得任务栏可以访问具体内容。


2002年9月25日，微软面向用户推送了Windows XP SP1补丁包，SP1全称为Service Pack 1，翻译过来就是补丁包的意思，为了防止系统受到攻击，微软会定期推送SP，以此来增强系统的稳定性。



▷图片来源官方介绍


而后随着微软各代操作系统的推出，Windows XP逐渐成为记忆。


根据微软提醒，其对Windows XP停止技术支持是在2014年4月，当时微软在声明中写道：


"在过去12年中，微软为Windows XP提供了支持。但是现在是时候了，我们和硬件、软件合作伙伴一起，把资源投入到支持更新的技术上，这样我们才能继续提供更好的新体验。因此，Windows XP的技术援助不再可用，包括帮助保护您PC的自动更新"。


"如果您继续使用Windows XP，在支持结束后，您的计算机仍将正常工作，但它可能会变得更容易受到安全风险和病毒的侵扰。Internet Explorer 8也不再受支持，因此，如果您的Windows XP PC使用IE8连接互联网，您的PC还会面临更多威胁。此外，随着越来越多的软件和硬件制造商为更新版本的Windows优化，您可能会遇到Windows XP软件和硬件上的不适用问题"。


微软甚至还表示，如果你的PC无法升级运行Windows 10系统，那么是时候买一台新设备了，它们比以往任何时候都更强大、更轻巧、更时尚，而且平均价格也比14年前的普通PC便宜得多。


#03


Windows XP源代码泄露上网


除了关于市占率的记忆外，2020年底，一批号称Windows XP SP1系统的源代码被打包传上网，一度引起热烈讨论。后经安全专家、代码大神等检查模拟确认源代码属实，甚至能编译出一套可运行的操作系统。虽然微软表面上显得淡定，仅仅给出"正在调查"的回应，但私下里，微软也在四处出击。


一个证据就是Mega网盘的源码打包文件已经被撤下，微软似乎还出手干预了部分谷歌的搜索结果页，甚至包括一些心硬如石头的种子网站。




▷图片来源官方论坛


另外搞笑的是，名为shaswata56的用户更是把源码打包上传到了微软自家的GitHub上。历时10天之后，该代码库才因为DMCA版权保护的要求被关闭。


一些观点认为，XP源代码早在2001年就开始面向学术圈共享，以互相检查确保安全性。可时至今日，XP都被认为是漏洞最多的一代操作系统。
