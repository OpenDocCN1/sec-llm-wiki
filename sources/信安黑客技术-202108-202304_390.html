我们经常会遇见朋好去你家做客，第一句就是问你家WiFi 密码，如果密码负责不仅说的麻烦，还有可能暴露自己的密码，毕竟很多人密码都喜欢设置的一样。。。

但是今天这个GitHub 工具WiFi Card完全就能解决这个问题，这个工具就是把 WiFi 名称和密码，快速转化为二维码，把它贴在冰箱上，别人只要扫描照片，就可以连接 上WiFi。关注公众号：程序员开源社区，回复：666领取资料 。

本地运行

在http://localhost:8080上运行官方 Docker 镜像

make run

发展

  1. 确保你已经yarn安装

  2. 在http://localhost:3000上运行实时重载服务器

    make dev

该项目使用Prettier格式。在合并之前，所有拉取请求都必须通过自动 lint 检查。Prettier 格式作为预提交钩子自动运行。

语言贡献指南

我们希望您为不同的语言做出贡献，并帮助使其比现在更好！作为语言贡献者，我们希望您遵循以下步骤：

  1. 添加翻译 ./src/i18n.js

  2. ./src/App.js在格式中添加语言选项latinName - nativeName，例如French - Français

  3. 如果添加的语言需要 RTL 方向，请将语言键添加到 ./src/App.js 中的 RTL_LANGUAGES 常量。

  4. 在 README.md 中的转换表中添加一个条目。
