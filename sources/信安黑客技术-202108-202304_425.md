# 6步傻瓜式点击在树莓派上安好Win11

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2MDQzMjY4NQ==&mid=2247484985&idx=1&sn=86d21f7b2651ff2ff9b3fb6fc43418a9&chksm=ce27367bf950bf6d31e12589a0ac674b3d1feb81eeed30b47ba0bb89cfaa5b9dacf66de55bc1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2MDQzMjY4NQ==&mid=2247484985&idx=1&sn=86d21f7b2651ff2ff9b3fb6fc43418a9&chksm=ce27367bf950bf6d31e12589a0ac674b3d1feb81eeed30b47ba0bb89cfaa5b9dacf66de55bc1&scene=27#wechat_redirect)

**给树莓派安装Windows 11**系统时**麻烦**吗？

先要去官网下载arm版系统，然后进行镜像烧录；烧好后，还要在树莓派上进行一些配置？

现在，有一个脚本可以把以上操作都**自动化**了，还是**图形界面**的——你只需要傻瓜式地点几下就OK！

![](../Images/fa05a3883abab6a5e51670ed928e0c73.png)

并且也不用担心微软许可证的问题，此脚本完全合法！

（也可以用来装Windows 10。）

## 6步傻瓜式安装

首先，去GitHub上找到这个叫做**WoR-flasher**的项目，clone下来。

![](../Images/7caed620ee4a03b8cf187d807dad34f9.png)

注意，现在这个脚本只有**linux版**。

然后在终端启动脚本：

```

~/wor-flasher/install-wor-gui.sh
```

会出来一个图形界面，就可以开始傻瓜式安装了。

第一步，选一下你要安装Win11还Win10，在树莓派几上安；

![](../Images/0955ddaf8199db0ce8e29244dbf4e615.png)

第二步，选择操作系统要用的语言；

![](../Images/7092c4c1ce86029a2cf6bcd805b6f39a.png)

第三步，插入一个可读写至少8GB的内存卡（25GB以上最佳），选上；

![](../Images/a93992eab1917185b71e63da732fe09c.png)

第四步，检查一下默认配置，如果还有别的需要可以自己添加一些；

![](../Images/9da5abce3b1f221900bcb38ce3e26a45.png)

第五步，点击“Flash”，终端开始正式运行install-wor.sh脚本。

![](../Images/1730cb639826d8c308938dbb820a0bed.png)

这步从微软下载安装包、压缩、生成镜像可能需要很多时间。（如果你用别的更快的/非官方的方式搞定ISO文件的话，到时可以跳过镜像生成这个耗时的步骤。）

**作者在这也声明**：此脚本完全合法，不用担心微软只向OEM（原始设备制造商）出售ARM版本Windows许可证这个问题。

有人拿着它去和微软的几位员工交流过了，他们都没有任何异议。

![](../Images/27400dad5eadc3a00d379b1a2bfa4166.png)

因为脚本是直接通过**UUPdump**从Microsoft的更新服务器（Windows Update servers）下载文件再生成的Windows镜像。

![](../Images/88bc445eba7fc4005eefd3de83d6248f.png)

而Microsoft的更新服务器是可以公开访问的，与直接从官网下载x86 Windows ISO一样合法。

再加上微软从来都知道UUPdump的存在，但从未追究过它的责任。

所以不用担心这样安装的许可证问题。

好了，**最后一步**，终端运行完成后、图形界面继续弹出按照提示把烧好的内存卡插上树莓派，脚本会继续**自动帮你安装好Windows系统并重启**——一切就搞定了（安装大概需要30分钟）。

![](../Images/a508a2123963ae091d63e81b80f74b02.png)

以上就是全部操作，是不是全程都没有需要你动脑的地方？

唯一需要的就是**花点时间**耐心地等待。

![](../Images/1ef7ccd59bef8bed29ad0044ccf985ec.png)

此外，还有一个**好消息**不知道大家注意了没，Windows 11引入了一个名为“ARM64EC”的“仿真兼容”接口（ABI），是一种在装有Windows 11系统的ARM设备上构建应用程序的新方法。

![](../Images/746d521da79f5427eebf36b7beb26daa.png)

这样的话，树莓派上就可以运行**64位的exe程序**了。
