**0x03 绕过宝塔防火墙**

尝试将所有的payload Base64编码传输，既然传过去的是编码后的Base64，小马也应该相应做出改变，只需解密一次传递过来的base64即可。

**0x04 改造蚁剑**

  

我们用到的是Base64编码，但是蚁剑其实是自带Base64编码解码器的，尝试直接使用自带的Base64编码器![](../Images/429beb88eaacac4ce6f0847829ea8325.png)

  

  

  

为什么会这样呢？我们尝试从蚁剑的流量分析，设置代理到burp

  

![](../Images/11c67d99a43e4cb611e4d979f13ac754.png)

  

  
拦截流量，我们可以看到明显有两个地方容易被waf识别。![](../Images/5032e81d912767aa2e361d0156084880.png)  

  

1\. User-Agent头的关键字：antSword/v2.1 这相当于直接告诉waf我是谁了， 所以这是第一个要更改的点。

  

2\. 蚁剑的流量其实还是有关键字的，比如cmd参数后的eval、base64\_decode都是，而且我们的小马自带Base64解密，所以用它的默认编码器不仅过不去waf，即使没waf也不能正常连接我们的小马，所以需要自己定义编码器。

  

![](../Images/f1b7cb31ecfb1b4e4637df706321686d.png)  
由于我们只需要将payload Base64编码一次即可，所以直接将data\['\_'\]Base64处理赋值即可，随机参数有没有无所谓的，编码器如下：

```
'use strict';
/** @param  {String} pwd   连接密码* @param  {Array}  data  编码器处理前的 payload 数组* @return {Array}  data  编码器处理后的 payload 数组*/module.exports = (pwd, data, ext={}) => {
  data[pwd] = Buffer.from(data['_']).toString('base64');
  delete data['_'];
  return data;}
```

  
然后修改UA头![](../Images/5e2cb010cfed2649aa7b22d92a1e7a00.png)  
应用我们的编码器，解码器不需要指定，默认即可，建议选择：增加垃圾数据和Multipart发包，再次测试连接![](../Images/d236ebc0b35400c58974c5106a235f22.png)![](../Images/0a354eef58b97f016b0f2d4e21e2c1f7.png)![](../Images/23b5f28ceb11c2b2cea2e98f75e74c5a.png)  

  

然后点击目录发现依然存在问题，不能跨目录，这个问题其实哥斯拉可以解决，上传哥斯拉马

  

这里可能有人会问了，那你直接上传哥斯拉马不就行了吗？实际情况是get传参有长度限制，而且有的符号会导致截断php文件无法上传完整
