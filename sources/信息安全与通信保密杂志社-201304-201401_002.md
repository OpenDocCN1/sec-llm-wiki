# 北斗导航系统已能媲美GPS系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247543965&idx=1&sn=b88477e5e53e7823f028341b76ccd3b5&chksm=c0b4f6ebf7c37ffd231d3c422ddd03f9c9126d9f5587282303977fb026bec6320164ec1f5d51&scene=126&sessionid=1681312474#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247543965&idx=1&sn=b88477e5e53e7823f028341b76ccd3b5&chksm=c0b4f6ebf7c37ffd231d3c422ddd03f9c9126d9f5587282303977fb026bec6320164ec1f5d51&scene=126&sessionid=1681312474#rd)

根据发表在《中国科学：地球科学》的研究报告，国家自然科学基金项目资助的一项研究称，中国的北斗导航系统在亚太地区的导航精度已能媲美GPS系统。

北斗导航系统目前由14颗卫星构成，在亚太地区内，北斗可见卫星数在7颗以上，而GPS系统目前有31颗卫星。

报告称，原始观测值方面，北斗伪距测量精度约为33cm，载波测量精度约为2mm，已与GPS处在同一水平。在导航定位方面，北斗伪距单点定位水平精度优于6m, 高程精度优于10m，北斗单频伪距差分定位精度优于2.5m。

报告认为，若采用北斗/GPS组合载波相位差分动态定位，其精度相对于单一的GPS定位约改善20%以上。
