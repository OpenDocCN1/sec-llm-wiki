# NSA每日盗取上亿短信

据外媒报道，卫报记者James Ball近日刊文曝出美国NSA代号为Dishfire的监控项目。在该项目下，NSA每日可“捕获”近2亿条短信，之后将其储存下来供未来深入研究。英国的GCHQ也采用了相类似的手段。该份信息同样也来自于前NSA通讯员斯诺登之手。

  

另外，该份文件显示，NSA还会从160万个过境者那里收集500万个当事人错过的通知、从电子卡中收集11万个名字以及80多万比的金融交易，而这一切都发生在一天的时间内。
