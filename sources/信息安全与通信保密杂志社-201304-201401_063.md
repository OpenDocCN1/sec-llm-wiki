# 谷歌工程师对NSA监控的回应：对法律失望，只能被动防御

近日，谷歌公司的多位安全工程师对最近曝出的NSA和GCHQ侵入谷歌及雅虎内部云端网络一事做出回应。Mike Hearn称，“我们打造这样的系统是为了阻止犯罪活动的发生。这点毋庸置疑。” 上个月月底，《华盛顿邮报》刊登了雅虎和谷歌两家公司的个人网页数据遭NSA和GCHQ盗窃的文章。

  

在这一消息公布于众之后，谷歌安全工程师Brandon Downey最先在Google+做出了回应。他写道，“在过去的十年时间，我竭尽全力来保证谷歌用户账号的安全，确保他们不受到公司所面对威胁的伤害。”Downey表示，自己已经见识过大量的DOS攻击、恶意软件、间谍软件，但没想到的是，政府居然也用这种手段来获取他们想要的数据。Downey描述道，“这种感觉就好比与索隆的战争，当我们摧毁了至尊魔戒的时候，却发现NSA正站在夏尔国中，指挥半兽人和它们手中的鞭子，趋势善良的霍比特人砍下聚宴之树(Party Tree)。”

另外一位来自英国的谷歌安全工程也对此做出了相类似的回应--“我们之所以设计出这么一个系统就是为了能够阻止犯罪活动的发生，这点是不需要任何的怀疑。通过这个安全系统，我们可以向法官、向诉讼案件提供证据，而这些，都是我们努力多年才获得的宝贵经验。。。很遗憾，我们生活在了一个在大多数情况下法律只为极少数人服务的世界里。GCHQ和NSA不会有一个人愿意站到法官面前，回答就其颠覆了行业规矩作法的相关问题。在这么一个法律约束性缺失的环境下，作为互联网工程师的我们别无选择，我们只能开发出更多的安全软件。”
