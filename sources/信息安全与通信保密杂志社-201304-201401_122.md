# 斯诺登入俄 美议员：俄罗斯在背后捅了我们一刀

日前，美国政府和国会议员对俄罗斯向斯诺登提供庇护表达不满。白宫发言人杰伊·卡尼在记者会上说：“我们多次公开或私下要求俄方驱逐斯诺登。这些要求明确、合法。然而，俄罗斯政府却作出这种决定，我们极度失望。”

  

　　卡尼说，俄方事先没有通知美方斯诺登将获得避难权。他拒绝说明美国可能作出何种回应。

  

　　美国总统贝拉克·奥巴马定于9月出席在俄罗斯圣彼得堡市举行的20国集团领导人会议，其间将与俄罗斯总统弗拉基米尔·普京举行面对面会晤。

  

　　就斯诺登入境俄罗斯是否影响奥巴马访俄计划，卡尼说：“鉴于这件事和其他事，我们正在评估首脑会晤的效用。”

  

　　一名不愿公开姓名的美国官员告诉路透社记者，美俄原定下周举行两国外交部长和国防部长会晤。俄方批准斯诺登避难后，不好说会晤能否照常举行。

  

　　相比美国政府，一些美国议员言辞更尖锐。共和党籍联邦参议员约翰·麦凯恩和林赛·格雷厄姆发表共同声明，称俄方“故意让美国难堪，打了全体美国人一记耳光……现在应该从根本上重新考虑与俄罗斯的关系。”他们敦促政府报复俄罗斯，包括完成全部在欧洲部署反导系统的计划和把俄罗斯邻国格鲁吉亚纳入北约组织。

  

　　奥巴马的盟友、民主党籍联邦参议员查克·舒默说：“俄罗斯在背后捅了我们一刀。斯诺登先生每在大街上闲逛一天，这把刀就在我们身上转一下。”他说，奥巴马应该提议，20国集团峰会改在其他国家举行。

  

　　美国参议院外交关系委员会主席罗伯特·梅嫩德斯说，斯诺登获避难权使美俄关系“倒退”。

  

**斯诺登在俄罗斯貌似会幸福**

  

斯诺登收到避难文件后数小时，俄罗斯最大的社交网站VK的创始人帕维尔·杜罗夫表示，愿在他的“全明星安全团队”中为斯诺登这位计算机专家安排一个职位。

  

　　库切列纳则说，“不排除”斯诺登将效仿遭美国驱逐出境的俄罗斯女特工安娜·查普曼，在俄罗斯主持电视节目。查普曼2010年在俄美交换被捕特工后回国，获得一家银行聘用，同时主持电视节目。她先前经由微博客网站向斯诺登“示爱”。
