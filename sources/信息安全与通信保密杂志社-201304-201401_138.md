# 危机时刻求救：日本儿童手机无惧“校长”

在日本，每年夏季商战，除了我们平时常用的智能手机之外，也总会有儿童机发布。不过对于大多数成年人来说，我们可能不自觉的就将这些儿童新机忽略掉了。那么现在我们难免会想，儿童机一直在发布，那么儿童手机的普及率到底如何呢？儿童真的不会更倾向于使用普通智能手机吗？今天的豆知识就是：**日本有2/3的儿童都在使用专为儿童设计的儿童手机。**  

**儿童手机除了基本的通信功能、防水防尘功能之外，最常见的就是定位、报警这几项功能。家长可以实时了解孩子的所在位置。当孩子遇到危险时，也可以扯动手机上方的拉环启动报警器功能，发出尖锐的声音来引起周围其他人的注意。**

**应该说日本儿童手机值得我们学习，目前国内针对儿童定制的手机少之又少，在怪蜀黍、“叫兽”、“校长”扎堆出现的今天，一款贴心且能够报警的儿童手机显得尤为重要！**

对于家长来说，小学生对和手机的使用或许是他们最关注的问题，前面我们也看到也有7.6%的小学生使拥有智能手机的。当中学生与高校生有了成型的社会观念与是非观之后，家长们对于孩子通过手机下载的应用内容很少会过问。**但对于小学生，有58.3%的日本家长都会时刻检查小学生所下载的应用内容。**
