# 华为导致山姆大叔中年危机

2013年在华为看来本身就是个“玩笑”，为什么呢？因为这家中国企业的存在直接导致美国产生莫名其妙的“中年危机”。

（1）今年2月，美国国家贸易委员会（ITC）宣布对华为发起3G和4G无线设备 “337调查”，以确定这些产品是否侵犯美国公司专利权；

（2）今年3月，奥巴马签署的一项预算拨款法案中规定，联邦机构在采购中国企业生产的IT系统之前必须得到联邦调查局或其他权威机构的批准，矛头直指华为；

（3）今年5月，出于安全考虑，印度情报机构再次对中国电信设备制造商华为开始严密审查；

（4）今年6月，英国国会即将发布的报告中涉及英国政府对华为的指控；

而最为“滑稽”的是：日本软银对美国第三大移动运营商Sprint的投标因为软银在网络中使用了华为设备，遭到美国反对。为确保交易顺利进行，软银最近承诺将淘汰华为的设备。华为华丽躺枪。

那么，对华为目前的“尴尬处境”，大家都持什么观点呢？

  

@跃马冲锋: 死亡、谋杀、国家安全、跨国公司阴谋、政治投机、主流媒体报道、简直是好莱坞电影元素大集合。。。华为躺枪，说多了全是泪。

  

@酸奶君君\_: 有没有安全问题不说，至少华为是中国最实干的企业。老美的封闭也会有后果的。

  

@葱葱: 除却安全问题，华为的存在对于美国在不同具有竞争关系的供应商之间的采购，是有战略意义的

  

@财富中文网：华为躺枪。

  

@ Affirmative：美国佬对华为这是“死了都要爱”的节奏么？

  

@徐龚：华为就当进行了一次全美品牌推广了

  

@智慧的七根柱：想想前苏联、俄罗斯作为反派大佬，已经被好莱坞消费这么多年了，是该推陈出新了

  

细数上面华为遭遇尴尬的案例中，似乎都有美国的影子，所以最为出人意表的是，美国知名科技博客GigaOM突然发表了一篇文章《为什么美国更需要华为，而不是华为更需要美国》。文章罕见地将天平倒向了华为一方，认为，如今有能力建设一个相当好的移动网络的企业已经为数不多，而美国对华为的禁入政策，严重扭曲了本已倾斜的行业平衡。
