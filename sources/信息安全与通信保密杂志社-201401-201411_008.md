# 一场没有硝烟的战争 谁能获胜？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544146&idx=1&sn=edcbeff5b77e7beebbcaa1afca030152&chksm=c0b4f724f7c37e3208d8c8f57ce33c6ee25747def7be06a899f7ce6092e9c0b832cf56df5dd9&scene=126&sessionid=1681312441#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544146&idx=1&sn=edcbeff5b77e7beebbcaa1afca030152&chksm=c0b4f724f7c37e3208d8c8f57ce33c6ee25747def7be06a899f7ce6092e9c0b832cf56df5dd9&scene=126&sessionid=1681312441#rd)

　　据外媒报道，前NSA总法律顾问Stewart Baker在都柏林举办的Web峰会上指出，由于在用户网络数据加密的不同立场，现在，美国各大科技公司已经跟美国政府展开了一场网络战争。Baker认为，谷歌和苹果及其他公司的新加密手段就很好地反映出了它们对政府情报机构私自收集用户数据的强烈不满。

![](../Images/23c79734e1b225e196a49ba177ef196a.png)

　　另外，Baker还在数据加密这个问题上延伸到了黑莓商业模式的陨落。黑莓曾是一家以安全着称的公司，然而随着谷歌和苹果的加入，黑莓在这一领域的市场遭到蚕食，特别当它没能好好地在Blackberry上利用这点。他还指出，加密用户数据会让黑莓在那些需要通信数据监管的国别市场的销售受阻。

　　Baker称，采用了绝对加密机制的产品市场非常小，就算是企业，也鲜少愿意完全丧失访问职工通信数据的权利。“我曾经跟一些企业合作过，（我发现），只要他们获得了来自执法部门的要求，无论他们平时自称是多么多么开放、多么多么开明，只要发现存有令人厌恶的犯罪行为，他们迟早会付出一切代价找到那个犯下罪行的人好让他接受惩罚。”

　　Cloudflare CEO Matthew Prince对科技公司的作法则表示了赞同。他称，企业是依靠用户对其信任而生存的，斯诺登此前披露的的大量机密文件则很好地提醒了谷歌等科技公司。另外，他还指出，包括Heartbleed、Poodle在内的安全漏洞的出现显示了安全问题已成为主流。
