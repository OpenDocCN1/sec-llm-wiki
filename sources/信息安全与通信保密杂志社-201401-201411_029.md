# 倪光南院士呼吁构建国产OS操作生态系统

　　在28日举办的中国操作系统应用推广大会上，中国工程院院士倪光南表示，国产操作系统的竞争力很大程度上取决于其生态系统的建设。只有大力营造国产操作系统的生态环境，国产操作系统才可能取得成功。倪光南表示，操作系统是否好用在很大程度上取决于其生态环境是否完善。构建一个完善的生态环境的难度远超过开发一个优良的操作系统的难度。

　![](../Images/78324f490a418a536dcb49b60d0df880.png)

　　此前，倪光南院士联合中国电子等多个单位成立了中国智能终端操作系统产业联盟。倪院士希望通过产业联盟的形式，参考Android、苹果等的“应用商店”模式，集中优势资源，建立统一的标准，为国产操作系统开发完善的应用。预计通过1－2年的时间，通过发动国内相关软硬件企业及APP开发者，国产操作系统可以拥有较为完善的应用支撑体系。

　　目前各部委已经有计划逐步推进国产操作系统在本领域的普及。据记者解，思普等公司已经与联想、清华同方签订协议，在集采的电脑中部署思普的SPGnux国产操作系统。思普董事长张龙对记者透露，其中清华同方近期向其采购了1.9万套SPGnux系统。思普也将针对这些集采用户，提供更完善的售后技术支持。

　　针对国内操作系统普遍采用国外开源Linux系统的现状，倪光南院士对搜狐IT表示，国产操作系统基于开源Linux技术符合时代发展的潮流。倪院士称，系统是否安全与是否采用开源技术没有必然联系。一般说来，成熟的开源软件漏洞较少，存在“后门”的可能性也很少。如果能真正掌握开源软件而不是简单地采取“拿来主义”，那么，基于开源软件发展国产软件既能提高开发效率，又能减少漏洞和存在“后门”的风险。只有完全开放源码，并容许用户分析、重构，才可能减少“后门”风险。即使是这种情况，如果源码规模很大，分析水平和时间不够，仍然不能保证不存在“后门”。根据上述考虑，基于开源软件自主开发软件，应该是一条现实的途径。
