# 你的个人信息安全吗？？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544137&idx=2&sn=36ab2c6cbec54ad57a73757498a21ce1&chksm=c0b4f73ff7c37e29652a448c3573f2360def215a97e260c4783db8c67ba8f50a73b4d70f7fb6&scene=126&sessionid=1681312443#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544137&idx=2&sn=36ab2c6cbec54ad57a73757498a21ce1&chksm=c0b4f73ff7c37e29652a448c3573f2360def215a97e260c4783db8c67ba8f50a73b4d70f7fb6&scene=126&sessionid=1681312443#rd)

　　数字时代，越来越多的人将个人信息存储在移动设备或计算机设备中，同时面临着越来越严峻的安全考验。根据微软最新的研究调查显示，四成美国人的个人信息每周或每日均面临着威胁，经受不明来历的访问尝试。不过调查显示，由于智能手机用户均采取了积极的防护措施防止个人信息外泄，最大的个人信息外泄来源还是通过PC，占比42%；而通过移动手机外泄的仅占18%，另外的50%来自平板设备和固定电话。

　　2014年的调查显示，有74%的智能手机用户受访者表示他们正采取积极的措施防止信息外泄，同2012年的相同调查相比，有25%的提高。尽管如此，保护真实个人信息在虚拟世界的安全，仍是说得再多也不嫌多的话题，微软给出了四点建议：

　　1.对于自己的敏感私人信息要非常自私，千万不要随意通过电邮，即时消息或短信分享给他人。

　　2.使用大小写字母、数字、符号混合的“强”密码组合保护信息

　　3.合理理财，控制个人信用，确保信用账户安全

　　4.使用合法渠道下载的反病毒软件并保持病毒库更新
