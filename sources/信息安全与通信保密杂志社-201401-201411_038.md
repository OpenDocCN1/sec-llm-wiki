# 小米服软：海外用户云数据不再备份至北京

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544136&idx=3&sn=edb36934ef53982e9eebe1023316964d&chksm=c0b4f73ef7c37e28ca9757aa385cd24db5f751a4b93c406f3f1e1c83475ed464ebcf04053c36&scene=126&sessionid=1681312443#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544136&idx=3&sn=edb36934ef53982e9eebe1023316964d&chksm=c0b4f73ef7c37e28ca9757aa385cd24db5f751a4b93c406f3f1e1c83475ed464ebcf04053c36&scene=126&sessionid=1681312443#rd)

　　22日，负责小米国际业务的副总裁，曾在 Google 担任高管的 Hugo Barra 在 Google+ 上宣布，为了更好地服务用户，提高国际用户连接小米服务的速度，并且保障小米从他们获取的隐私数据安全（不受国内监管部门的影响），小米决定将服务国际用户的多个服务器数据迁移至中国境外。

　　按照 Barra 透露的情况，数据迁移共分为三个步骤：

　　1）电子商务迁移

　　小米今年早些时候已经开始将全球电子商务平台，也即购买小米手机和配套产品服务的功能，从位于北京的数据中心当中迁移到亚马逊位于美国加州和新加坡的 AWS 数据中心当中，并且开始使用 Akamai 提供的全球 CDN 加速服务。电子商务数据的迁移工作将在本月底结束，完成之后，小米在全球开放了本地市场购买服务的国家和地区市场，比如中国台湾、中国香港、新加坡和印度等，将享受到更快的服务

　　2）MIUI 互联网服务迁移

　　小米从最近开始将 MIUI 服务以及相应的数据，包括小米账户、小米推送服务（Cloud Messaging）、小米云服务等位于北京的数据中心当中迁移到亚马逊位于美国加州和新加坡的 AWS 数据中心当中。迁移工作将在今年底前完成，完成之后印度、马来西亚等国家的用户使用 MIUI 服务的延迟将显着降低。

　　3）云计算服务本地化

　　Barra 透露，小米计划在 2015 年开始在比如印度和巴西等 AWS 服务还没有本地化推广和应用的新兴国家市场，和本地数据中心供应商合作，共同建立本地化的云计算数据架构，帮助本地用户提高服务可用性。

![](../Images/40d9cb236dff5c8a51b5e071e5317467.png)

　　此前，包括中国台湾、印度和美国等地区和国家市场都曾有媒体报道，小米会将用户的数据回传到中国的服务器上。考虑到中国大陆的互联网监管情况，国外用户对于自己使用小米手机和小米各项互联网服务的数据安全性存疑。Barra 宣布的消息，属小米首次公开对用户的意见做出回复，目前来看能够让国外用户稍微放心一些。
