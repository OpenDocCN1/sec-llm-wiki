# 奥巴马反对“互联网快车道”：FCC主席“忠诚度”存疑

　　早2008年的竞选中，美国总统奥巴马就表示支持网络中立。但在上周的采访中，他再次谈到了反对FCC最近提议的“支付优先”（paid prioritization）。奥巴马称，他反对建立互联网“快车道”，因为这将使得ISP向涉及内容、数据、以及更快的速度的用户收取更高的价格。

![](../Images/fcd37389dbe80668c717eb76a7b81928.png)

　　“分裂”的互联网，并将之划分成两个“通道”（lanes），这是现任FCC主席Tom Wheeler所提出的部分网络中立规则之一。但作为一名前“有线网络行业”的说客，Tom Wheeler的忠诚度一直被人所质疑。

　　今年8月份的时候，奥巴马曾明确表示，他认为不应该出现一个分裂的互联网：“针对不同的用户而提供差异化的互联网访问，你肯定不希望这样”。

　　自FCC网站宣布征求有关网络中立性的意见以来，该机构已经收到了大约370余万条评论。讽刺的是，Tom Wheeler就是被奥巴马任命为FCC主席的。
