# 美科技公司收到俄罗斯重要“通知”

　　苹果公司和中国电信合作在本地兴建数据中心的事儿表面上看起来好像是国力的证明——完全是外界看法。稍微懂一点政治经济以及科技相关情况的人士会很快意识到未来他们所使用的苹果设备当中储存和互相交换的数据可能不再仅面向苹果内部使用，中国的监管机构也将笼罩在整个数据中心之上。事实上，中国不是唯一一个要求美国科技公司服从「数据本地化」的国家，最近俄罗斯也对它们发出了类似的要求。

　　俄罗斯媒体莫斯科时报（The Moscow Times）近日报道，俄罗斯监管机构近日开始对 Google、Twitter 和 Facebook 三家公司发出通知，要求他们尽快遵守相关的法律法规，在俄罗斯政府下设的分支机构下备案。据该报报道，本通知要求中涉及的法律名称为「信息发布组织者」，将在很大程度上限制俄罗斯国内的言论自由。

![](../Images/96ebdf53f2807be490e540273ba2f318.png)

　　俄罗斯电信监管部门 Roskomnadzor 副部长 Maxim Ksenzov 在本周五对俄罗斯本地媒体表示，国家会考虑采取任何可能的方式达成目的，让这三家公司服从法律。

　　据悉，该法律要求所有监管对象用户当中来自俄罗斯用户的所有数据存储在俄罗斯国内的服务器当中。如果 Google、Twitter 和 Facebook 三家公司不服从法律的话，将会受到行政制裁。

　　尽管俄罗斯已经不是社会主义国家，但由于政治体制和政局的特殊性，仍然对于言论保持相当强大的监管力度。「信息发布组织者」法案当中还有一条对于博客网站博主进行管制的条文，强制要求单日浏览量超过 3000 的博客网站博主向监管机构备案，并将按照对于公众媒体的监管方式来监管这些博客网站。
