# 4G来了！ 17号段火了！

　　9月22日消息，近日中国联通开通4G并使用176子号段，首批4G用户单独开放20万个号码。自此三大运营商的4G号码已全部亮相，均属于17号段。  

　　按照工信部的批复，三大运营商4G新用户均将使用17打头的号段。中国电信在4G放号时已使用177号段放号，并称177号段为中国电信4G专属号段。中国移动则在今年已经使用178号段对4G用户放号。这就意味着三大运营商的4G号段已全面商用。

　　据了解，虚拟运营商此前一直使用的170号段，但并不为用户熟悉，随着三大运营商全面使用17号段，将有利于虚拟运营商的170号段被用户接受。

　　此外，工信部此前针对“170号段无法接收验证码和验证短信”的问题正式下发通知，要求各互联网企业积极配合移动通信转售企业，并限期在9月30日之前解决此问题。此举也将进一步推动运营商17号段的普及。
