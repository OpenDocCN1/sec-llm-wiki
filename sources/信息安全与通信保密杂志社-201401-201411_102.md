# 黑客又搞创意， 打印机上玩射击！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544113&idx=3&sn=fd1b8284918b431796e11d1778df7786&chksm=c0b4f747f7c37e5121ae5c6c9140502f4606e1b4160aa2f329fba326e4a9e491a57f0e1f51f9&scene=126&sessionid=1681312447#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544113&idx=3&sn=fd1b8284918b431796e11d1778df7786&chksm=c0b4f747f7c37e5121ae5c6c9140502f4606e1b4160aa2f329fba326e4a9e491a57f0e1f51f9&scene=126&sessionid=1681312447#rd)

![](../Images/31978f26597425433a46d13079151877.png)

　　黑客们能入侵 ATM 机玩游戏确实是好本事，不过这和 Michael Jordon（不是乔帮主……）一比可就弱爆了，人家在佳能的喷墨打印机上跑了一把《毁灭战士（Doom）》。其实破解打印机的事儿也不是没人做过，只不过前人达成的成就也不过是让它不停打印一些废话，或是在 LCD 屏上留个言而已，Michael Jordon 决定不流俗，他要玩个大的。

![](../Images/da01697adefc09398b1a08a0ae639956.png)

　　这位黑客发现，佳能的喷墨打印机在进行网络固件升级的时候是不需要证书验证的，因此他更改了打印机的 DNS 服务器 IP，欺骗后者下载并安装一个假的固件，然后这款经典游戏就这么在打印机上跑了起来。

![](../Images/cef60cb5b688855129ba6e2ca389ad1d.png)

　　这件事说明了部分打印机产品是十分脆弱的，不法之徒可以很轻松地利用这个漏洞实现非法目的。所幸这位乔老爷只是想移植一下游戏而已，随后他将这个情况反映给了佳能。

　　佳能表示他们对 Jordon 的报告非常重视，很快将推出补丁修复这个漏洞。
