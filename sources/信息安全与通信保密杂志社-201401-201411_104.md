# 阻止网络攻击，你的企业有信心吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544113&idx=1&sn=bee8320328273a35174b2681b0ebfe7b&chksm=c0b4f747f7c37e51d259624d3983817b1b0a3647a196e3231e3523b48441cff4b8382e8da8b3&scene=126&sessionid=1681312447#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544113&idx=1&sn=bee8320328273a35174b2681b0ebfe7b&chksm=c0b4f747f7c37e51d259624d3983817b1b0a3647a196e3231e3523b48441cff4b8382e8da8b3&scene=126&sessionid=1681312447#rd)

![](../Images/31978f26597425433a46d13079151877.png)

　　近几个月用户信息被窃事件频发，但是很多企业依然缺乏信心来阻止网络犯罪或者数据破坏。据风险顾问公司Protiviti最新的问卷调查结果显示大部分公司没有正确的应对网络危机，并且经常没有合理的核心数据策略。

　　Protiviti常务董事Ryan Rubin表示：“我们的调研结果表示很多公司目前的状态和应该所达到的IT安全基本标准之间还有存在很大的空白。在调查中部分公司已经意识到并进行了相关改进，但是依然有很多机构对于IT安全和机制的重要标准视而不见。这些公司应该花费更多的精力来应对安全风险进行评估，以便于更好的保护他们的核心数据。”
