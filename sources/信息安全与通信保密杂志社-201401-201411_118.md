# MSN将重获新生？

　　微软计划重新启用MSN品牌，将必应品牌的多款应用改用MSN品牌，并且推出iOS和Android版。该公司还将发布一个新的MSN主页。

　　新闻、体育、旅行、天气和财经等现有的必应应用很快都将改用MSN的品牌，该公司很快还将针对每一款应用发布iOS和Android版。这是微软“移动为先，云为先”战略的最新举措，希望为用户提供更多跨平台的服务和应用。

　　近几年来，微软已经基本弃用了MSN品牌，转而力推Windows Live和必应，因此重新关注MSN品牌着实令人感到意外。新的MSN.com主页突出显示了微软出品的多款服务，以及Facebook和Twitter等社交网络。必应应用的设置和信息目前都将可以通过MSN.com和微软Cortana数字助理同步。

　　由于被设定为IE浏览器的默认主页，因此MSN.com依然是一个很受欢迎的门户网站。但目前还不清楚，将必应应用更名为MSN应用，对必应意味着什么。微软今后是否会加大MSN的研发力度也尚未可知。
