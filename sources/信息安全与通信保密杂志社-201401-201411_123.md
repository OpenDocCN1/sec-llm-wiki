# 已经退役4个月，WinXP依然完胜Win8！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544106&idx=3&sn=eb3d2d651cf59d42877e8cafcfec872a&chksm=c0b4f75cf7c37e4a1db928a39fb21406c4888acc9fc1c4b96103507ec77a03f23b5bf032e327&scene=126&sessionid=1681312449#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544106&idx=3&sn=eb3d2d651cf59d42877e8cafcfec872a&chksm=c0b4f75cf7c37e4a1db928a39fb21406c4888acc9fc1c4b96103507ec77a03f23b5bf032e327&scene=126&sessionid=1681312449#rd)

![](../Images/51a35d47db194139d110f71f6baee6ec.png)

　　据报道，市场研究机构Net Applications 的数据显示，已经退役的微软Windows XP系统8 月市场份额仍有23.89%，仅比2014 年7月降低了0.93个百分点，按照这样的降幅微软至少需要等待两年的时间，这款经典操作系统才会彻底退出市场。

　　2014 年8 月Windows XP全球市场占有率为23.89%，比2014 年4 月该系统终止技术支持时仅降低了2.4个百分点，最近一个月仅降低了0.93 个百分比。

　　让微软更失望的是Windows 8并没有因为Windows XP退役市场占有率有所成长，Windows 8/8.1 合计市场占有率仅有13.37%，增长幅度缓慢。Windows 7 市场占有率基本与上一个月持平，保持在51.2%。
