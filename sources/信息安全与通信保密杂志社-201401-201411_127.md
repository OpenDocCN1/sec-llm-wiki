# 担心“艳照门”？云服务到底应该怎么用？

　　近年来，移动互联网快速发展，易于同步与分享的云存储服务走进人们的生活，各大互联网服务商和移动设备厂商纷纷推出云存储服务以增强用户粘性，随之而来的是用户信息安全面临新的挑战，重大敏感信息泄露事件时有发生，近日美国多位女星存储于iCloud（苹果云存储服务）的大量“艳照”被曝，再度引发群体焦虑。

　　尽管“艳照”等绝对隐私被窃取的可能性极低，但一旦被窃取并通过网络扩散，后果极严重。建议不要长期保留在移动设备上，更不要上传到脱离自己控制范围的云存储服务器。请记住，小概率事件常常发生，切勿心存侥幸。

　　用户是信息安全体系的短板、最脆弱的“安全漏洞”，作为移动互联网时代的网民，掌握相关的安全常识是很有必要的。以下几点使用云存储服务的安全“攻略”，供大家参考。

　　1、基于信任原则，一般应选择面向全球或全国提供云存储的知名服务商，因为加密传输和强加密存储是其基本的安全技术要求。

　　2、免费云存储服务并无商业级安全承诺和保障，应仅限于个人用途，且尽量不要存储个人的绝对隐私。不要存储重要商业和技术机密文档，特别是各大互联网服务商和移动设备厂商的员工，原则上应避免使用竞争对手的云存储服务传输和存储涉密信息。如果事先自行强加密，可忽略以上约束性建议。

　　3、遵循强密码约束（大小写字母、数字和特殊符号混编，10位以上），避免与重要性和敏感性低的其它服务账号使用相同密码。如果有可用的增强安全措施也应尽量启用，以最大限度地保护账号安全。

　　4、规避木马或钓鱼陷阱。建议少上色情网站、少点击色情元素广告，不打开来源不明的链接。

　　5、重要数据应做好本地备份，以防服务中断或数据丢失等意外事件。

　　6、云存储服务通常都提供文件分享功能，应尽可能选择加密分享（对方凭密码提取），完全公开分享前应先确认是否涉密。

　　7、某些云存储服务的客户端对用户不够尊重，在用户首次登录后默认设置为自动同步。这可能关系到涉密的信息或文件。因此在首次登录客户端后务必检查默认设置，确保知情与可控，同时避免无谓的电量消耗和网络流量浪费（如果可能，尽量选择只限于WiFi网络下自动同步）。不要随意添加文件到已设置为与云存储服务自动同步的文件夹，建议对此类文件夹或其上级文件夹做特殊命名。

　　8、更换或丢弃移动设备前，必须清除设备中的个人文件和信息（部分安全软件可彻底清零存储器以防文件恢复），并删除云存储服务账号登录信息。如不慎遗失移动设备后，必须尽快远程擦除设备数据，并更改云存储服务账号密码及其它重要账号密码。
