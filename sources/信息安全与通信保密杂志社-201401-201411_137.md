# 央视：网民遭各类侵权年损失超千亿元

　　央视早间《朝闻天下》栏目推出了“互联网大会新观察：网民遭各类侵权年损失超千亿元”的专题报道。报道引用中国互联网协会发布的《中国网民权益保护调查报告》称，每年我国网民遭各类侵权损失为1093亿元，8.9%的网民年度经济损失超过1000元。网购、在线旅游是消费者经常遇到经济损失的领域。  

![](../Images/ec7b6e536f4a40a7e724571ac1d4d58a.png)

　　个人信息泄露是网民遭受权益侵害的重要领域。智能手机应用软件是用户信息泄露的重灾区。38.2%的用户表示遭遇过个人信息被泄露的情况。  
　　记者在采访中发现，不仅是一些不法分子收集用户信息，一些正规企业也在收集用户信息。  
　　小米手机在台湾被监管部门发现，自动将手机的手机号码、移动设备辨识码等信息回传到公司的服务器上。  
　　小米收集用户信息的事情不是个案，苹果、谷歌公司都曾被曝出私自收集用户信息的新闻。  
　　业内人士表示，手机或互联网企业手机用户信息主要是为了经营方便，一些企业在不告知用户的情形下收集用户隐私是担心给用户造成不便。  
　　但也有专家指出，这种说法并不成立。企业在任何情况下都不能私自收集用户信息。　  
　　目前，我国在个人信息使用上只有一些原则上的框架，政策还有待完善。专家指出，工信部应当对个人信息的使用政策和使用方式进一步完善。
