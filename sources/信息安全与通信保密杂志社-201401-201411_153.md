# 默多克再次抨击谷歌：侵犯隐私比NSA还糟

　　传媒大亨鲁伯特·默多克（Rupert Murdoch）并不是一个在Twitter上乱发议论的人，但在刚刚过去的周末，默多克抨击谷歌比NSA还要坏。默多克17日在Twitter上发消息说：“NSA侵犯隐私的行为很糟糕，但与谷歌比就是小巫见大巫。  

![](../Images/2f17fd42d1e9433c79e985c388085133.png)

　　默多克曾经多次批评谷歌，包括在“棱镜门”事件上。今年4月份，他也是在Twitter上发消息说：“谷歌对NSA的指责简直太有勇气了。谷歌所拥有的我们的数据和所有用户的数据更多。没有证据表明NSA这样做。这是一家道德高尚的公司吗？”  
　　2013年，默多克批评了谷歌执行董事长埃里克·施密特（Eric Schmidt）。2012年，他同样因为隐私问题大发牢骚。当年1月14日默多克发布了这样一则Twitter消息：“谷歌就是隐私领袖，它免费提供在线电影，然后在旁边兜售广告。难怪它能把数百万美元用在游说上。”  
　　但正如一些社交媒体上指出的，默多克对谷歌的批评略显虚伪。这位传媒大亨旗下拥有新闻集团、21世纪福克斯等媒体，但曾经因为窃听他人电话等行为而关闭了英国的一家报纸。  
　　例如一位名叫大卫·巴达什（David Badash）的用户也在Twitter上发消息说：“默多克曾有一份百年老报因为窃听电话而关闭，所以他批评谷歌和NSA是多么虚伪。”  
　　当然，默多克的批评对象并不只有谷歌，他还曾在Twitter因为“就业机会缺乏”带来的影响、“野蛮的ISIS”带来的危险，以及拥挤的加州监狱发过牢骚。
