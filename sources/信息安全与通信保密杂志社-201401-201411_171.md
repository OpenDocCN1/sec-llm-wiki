# 那些即将被微软放弃的IE浏览器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544090&idx=3&sn=88da0327bf7d07d89c532e45253dff02&chksm=c0b4f76cf7c37e7a2762f5414422e1108225a15627661ba435d330de058de60311be58584750&scene=126&sessionid=1681312453#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544090&idx=3&sn=88da0327bf7d07d89c532e45253dff02&chksm=c0b4f76cf7c37e7a2762f5414422e1108225a15627661ba435d330de058de60311be58584750&scene=126&sessionid=1681312453#rd)

![](../Images/912ab2205569cb4d460c4de0b4af5a1d.png)

　　据国外媒体报道，微软8月7日表示，将从2016年1月12日起停止支持旧版本的Internet Explorer浏览器。从2016年1月12日起，以下操作系统和IE浏览器的组合将会继续获得微软官方支持，而旧版本的浏览器则不再会获得有关技术支持和安全补丁升级：  
　　  
　　·Windows Vista SP2 + Internet Explorer 9  
　　  
　　·Windows Server 2008 SP2 + Internet Explorer 9  
　　  
　　·Windows 7 SP1 + Internet Explorer 11  
　　  
　　·Windows Server 2008 R2 SP1 + Internet Explorer 11  
　　  
　　·Windows 8.1 + Internet Explorer 11  
　　  
　　·Windows Server 2012 + Internet Explorer 10  
　　  
　　·Windows Server 2012 R2 + Internet Explorer 11  
　　  
　　“举例说，用户如果正在Windows 7 SP1操作系统上使用IE 8、IE 9或者IE 10浏览器，那么就应该升级到IE 11，以继续获得安全更新和技术支持。”微软表示。  
　　  
　　纵观以上列表，IE 8将被完全放弃。不过根据外媒ZDNet的调查，IE 8在桌面电脑用户中仍有不可思议的高占有率。显然微软希望通过停止支持，以迫使用户在未来12到16个月里升级到最新版本的浏览器。
