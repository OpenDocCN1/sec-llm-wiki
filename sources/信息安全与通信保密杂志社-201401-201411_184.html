面对俄罗斯的要求，苹果公司还能淡定么？

　　俄罗斯通信和大众传媒部曾建议苹果公司应该开放其源代码供俄罗斯政府检查，以确保iPhone制造商不参与美国情报机构窥探世界上最大的国家。据路透社报道，俄罗斯通讯部长尼古拉尼基弗罗夫在与苹果俄罗斯公司高层Peter Engrob Nielsen、德国公司SAP董事总经理Vyacheslav Orekhov会谈中提出了相同的要求。
　　基弗罗夫在一份声明中说，2013年爱德华·斯诺登事件和美国情报部门2014年加强对俄罗斯的监测，让俄罗斯需要重新审视国外的软件和硬件信任问题。很显然，公布自己程序源代码的公司没有隐瞒任何东西，但那些不打算在这个问题上与俄罗斯的合作的公司，可能在他们的产品当中隐藏了不为人知的能力。
　　微软在2010年同意了类似的建议，授予俄罗斯联邦安全局访问Windows7，Windows Server 2008 R2，微软Office 2010和Microsoft SQL Server源代码。
　　就中国政府指责苹果产品泄露用户位置的指控，苹果表示，苹果坚定地致力于保护所有客户的隐私。从设计的最初阶段，隐私安全就被内置到苹果的产品和服务当中，苹果不懈地努力，以期在世界上带来最安全的硬件和软件。
