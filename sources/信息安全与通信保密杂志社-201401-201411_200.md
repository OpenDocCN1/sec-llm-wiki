# 第九届亚太区信息安全SecureAsia大会在北京顺利召开

　　第九届亚太区信息安全SecureAsia大会23日在北京顺利召开。本届会议以“共筑网络安全、同享互联未来”为主题，邀请了来自美洲、欧洲和亚太区的20多名信息安全行业顶尖专家、政产学界重量级嘉宾，围绕云计算与大数据安全、移动互联网安全、web应用安全、软件安全、隐私保护与数据安全、网络取证以及信息安全人才培养等热点议题发表主题演讲。  

![](../Images/b42119e74a0c48ce26aa6b3a70ca187d.png)

　　信息安全与通信保密杂志社作为支持媒体积极参与了本次会议，与所有参会者共同探讨，分享全球前瞻的信息安全管理策略与前沿信息安全技术与解决方案，并会及时作出相关报道，与大家共同分享会议精髓。
