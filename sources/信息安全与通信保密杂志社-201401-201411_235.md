# Android用户再躺枪！或泄露手机WiFi历史记录！

　　如果你使用了Android手机的时间少于3年，那么它很可能会广播你曾经连接过的每一个Wi-Fi网络的名称。电子前沿基金会（EFF）发布了一份新的调查结果，其追踪了Honeycomb OS引入的PNO功能（Preferred Network Offload）的行为。由于手机会持续搜寻Wi-Fi连接，PNO会定期曝出此前曾经连接过的网络列表（甚至当电话处于睡眠模式的时候）。  
　　如果这些名称暗示了特定的地点，比如“xx总部的网络”或“xx的公寓”，那么通过推算，这张列表就等于泄露了用户的行踪。  
　　当然，如果你对此感到担心，也可以选择在设置里关闭它。只需前往“高级Wi-Fi设置”并禁用“在睡眠期间保持Wi-Fi连接”的选项，即可阻止在睡眠模式下的网络检查。  
　　当然，这么做的坏处是，你手机的数据流量和耗电量会有所增加。  
　　电子前沿基金会已经敦促Google在系统层面修复这一数据泄露bug，但是该公司回应到：“这会影响用户连接到隐藏的接入点，因此我们仍在权衡在未来版本中做出怎样的改动”。  
　　运行iOS 6/7/8的设备并不受此漏洞影响，不过EFF的报道称iOS 5存在同样的隐患。运行OS X或Windows 7的笔记本也可能受到影响，但是因为没有一个类似的睡眠模式协议（Sleep Mode protocol），所以数据泄露会更加有限。
