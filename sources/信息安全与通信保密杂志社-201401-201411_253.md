# 美蒙大拿州医疗服务遭攻击 或致130万人信息外泄

　　美国蒙大拿州本周向130万人发出警告，他们发现其州立医疗部门服务器于去年遭受攻击，个人信息数据可能泄露。预计受害者甚至超过该州总人口数100万人。据官方消息称，该起攻击发生于去年7月，但直到今年5月才被发现，被攻击服务器上的个人信息数据包括姓名，地址，出生日期，社保号码，医疗纪录，以及出生和死亡证明。  
　　该州政府已向这些可能受害者发出信件，其中包括现住居民，前居民，以及可能被泄露信息的相关家属。州政府官员说，他们认为黑客并没有破解这些信息，仍鼓励可能受害者们注册信用监控服务或保险服务。
