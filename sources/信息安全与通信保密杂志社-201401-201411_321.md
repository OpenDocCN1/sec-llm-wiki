# 《信息安全与通信保密》杂志社亮相国防信息化装备与技术展

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544038&idx=1&sn=2ae576741f54c7e9c0f85dbdc567aecc&chksm=c0b4f690f7c37f86d7bef45879bc227f20f9c1a3417915f194eb24e10cd96a7407b4b75dd99e&scene=126&sessionid=1681312463#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544038&idx=1&sn=2ae576741f54c7e9c0f85dbdc567aecc&chksm=c0b4f690f7c37f86d7bef45879bc227f20f9c1a3417915f194eb24e10cd96a7407b4b75dd99e&scene=126&sessionid=1681312463#rd)

2014年5月21日-23日，第三届中国国防信息化装备与技术展览会在北京中国国际展览中心举行，大会上展示了军用计算机硬件、软件及网络设备、装备信息化与卫星导航、大屏幕投影仪显示设备等国际国内领先的设备与技术。《信息安全与通信保密》杂志社做为参展单位亮相大会，并且其主办的《通信技术》杂志与《信息安全与通信保密》杂志受到了与会科研人员与参展商的欢迎。
