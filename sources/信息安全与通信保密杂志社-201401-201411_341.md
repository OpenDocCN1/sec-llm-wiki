# 邬贺铨：4G促移动互联网“快马加鞭”

　　“4G会带动移动互联网更大的发展，将进一步拓展移动互联网的应用场景。”在日前举行的“2014全球移动互联网大会”上，中国工程院院士邬贺铨表示，新一代移动互联网正“在路上”，但未来机遇与挑战同行。  
　　邬贺铨认为，正是3G和4G开启了移动互联网的时代，现在大众已经逐渐进入4G时代，“目前移动数据的峰值速率平均每年翻一倍。2020年我们会进入5G的时代，5G的速率会提高1000倍”。  
　　随着移动互联网的增长，目前的数据流量呈现大增的趋势，“在全世界的范围来讲，2012年、2013年流量年增81%，今后几年还会以61%的增速发展，同时，移动用户的月均流量增长很快”，邬贺铨指出，2014年4G的连接跟非4G的连接相比，其产生的数据流量是对方的14.5倍。
