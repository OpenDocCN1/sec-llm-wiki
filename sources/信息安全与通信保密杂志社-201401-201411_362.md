# 斯诺登将赴德国作证？ 靠谱吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544023&idx=2&sn=c32c336c6d9f8fdb278d503ead44d2f4&chksm=c0b4f6a1f7c37fb7deb2d5b0223a4fb693d2a1e2183aa910121d96bb9825a741cb79b0ba76e6&scene=126&sessionid=1681312465#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544023&idx=2&sn=c32c336c6d9f8fdb278d503ead44d2f4&chksm=c0b4f6a1f7c37fb7deb2d5b0223a4fb693d2a1e2183aa910121d96bb9825a741cb79b0ba76e6&scene=126&sessionid=1681312465#rd)

　　据《南德意志报》报道，为澄清美国国家安全局（NSA）对德国公民和政府总理默克尔监控行动丑闻，德国调查委员会有意邀请前美国情报机构雇员斯诺登在柏林接受询问并作证。斯诺登表示愿意在德国作证，但要求有出入境自由，保证不被引渡给美国。  
　　作为NSA前雇员，斯诺登曾向美英记者提供该机构大量秘密文件，从而曝光了NSA在全球实施包括对盟国领导人及普通公民的大规模电子监控的丑闻。他被认为是澄清NSA对德国公民和政府总理默克尔监控行动丑闻的关键人物。  
　　联邦德国政府日前在一份意见书中明确反对在德国境内询问前美国情报机构雇员斯诺登，理由是，要以国家利益为重，若在德国境内询问斯诺登，将给德国同美国之间的关系带来持久的负面影响。根据美国和德国之间的双边引渡协议，对他发出通缉令的美国有关当局可以向德国要求引渡斯诺登。德国政府还担心，斯诺登有可能利用在德国接受询问的机会提出政治避难申请。  
　　同为联邦议院NSA丑闻调查委员会成员的左翼党议员伦纳宣布，她仍将继续致力于实现邀请斯诺登在德国境内接受询问的计划，并将采取法律步骤。伦纳和绿党议员施特勒贝勒均拒绝接受政府关于通过视频手段让斯诺登在莫斯科接受询问的建议。施特勒贝勒指出，斯诺登本人就表示过，他不会在德国之外的任何地方作证。
