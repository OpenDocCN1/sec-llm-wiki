# 斯诺登想通了？开始考虑返美认罪

　　《纽约时报》报道，泄露NSA大规模监控活动的前合同工Edward Snowden考虑返美认罪交换减刑。他去年聘请了一位着名辩护律师，希望与联邦检察官达成一份认罪减刑协议。但双方预计不会很快达成协议，政府官员说，谈判仍处在早期阶段。Snowden目前在俄罗斯避难。  
　　他去年被指控违反了多项《反间谍法》罪名，面临着最多30年的监禁，而检方很容易就可以增加更多的指控。Snowden说，他想搬到俄罗斯以外的其他地方，但是美国的外交压力不允许他这么做，也让他无法在其他国家避难。
