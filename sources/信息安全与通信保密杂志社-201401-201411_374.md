# 普京：互联网就是一个由CIA控制的项目

　　据外媒报道，日前，俄罗斯总统弗拉基米尔·普京在新闻发布会上称，现在的互联网中就如同一个由CIA运行的项目，并表示政府应当对美国的这一行为作出反应。而俄罗斯议会最近通过的新规定则要求所有在其国内运行的社交媒体平台都必须要把用户数据储存在俄罗斯境内的服务器中，并且数据保留时间必须要超过6个月。

　　普京表示，俄罗斯政府必须要为其在互联网上的利益而抗争，他把现在的互联网描述成一个受CIA控制的版块，不过他并未透露具体的内容。

　　就在俄罗斯的“Facebook”--VK创始人公开表态不会向俄罗斯联邦安全局开放乌克兰抗议者的信息之后一周，这位创始人却将这家公司卖给了俄罗斯的商人Alisher Usmanov。据称，Usmanov跟普京保持着相当亲密的关系。

　　据悉，俄罗斯境内的最大搜索引擎--Yandex的服务器也没有在俄罗斯境内，而是在荷兰。对此，普京曾公开谴责过这家公司。
