# 微软今日为XP发布最后4个补丁更新 两个级别为“最高”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544000&idx=2&sn=43e0baac2014cdeb1958cac01255a612&chksm=c0b4f6b6f7c37fa091ea6fa5bc6ef956735f129ee3728320b5c840e09a724b229af51c7fc491&scene=126&sessionid=1681312468#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544000&idx=2&sn=43e0baac2014cdeb1958cac01255a612&chksm=c0b4f6b6f7c37fa091ea6fa5bc6ef956735f129ee3728320b5c840e09a724b229af51c7fc491&scene=126&sessionid=1681312468#rd)

![](../Images/ad35ce72aabdd7927c0828a3621bd0f9.png)

　　微软今日正式停止对WindowsXP的技术支持。据官方安全公告，微软将发布针对XP的4个安全补丁，其中两个级别为“最高”，另外两个为“重要”。这也是XP系统最后一批的四个补丁。微软今日正式让XP退休的同时，除直接向用户推送Windows8.1 更新外，还将发布4个安全补丁，一个是针对IE6、IE7和IE8推送的远程代码执行漏洞修复补丁，另一个则是其系统自身的补丁，同样是修补远程代码执行漏洞。

![](../Images/9bd3ce7e3be27ac1cec848c9bb679018.png)

　　另外两个补丁级别分别为“严重”和“重要”。

　　有用户表示，微软让XP退休后，最好能够提供像当年提供XP SP2补丁程序一样，为用提供一个完整的XP补丁包，以方便打包下载。
