# 马航客机失联牵动人心 黑客借机传播恶意程序

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247543986&idx=1&sn=09bc35334f858b19b91e8033979e3737&chksm=c0b4f6c4f7c37fd215c10c4fe1563bcccd464f5b31ed88fb180d9727d00b0ca1588cb0bf9c64&scene=126&sessionid=1681312470#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247543986&idx=1&sn=09bc35334f858b19b91e8033979e3737&chksm=c0b4f6c4f7c37fd215c10c4fe1563bcccd464f5b31ed88fb180d9727d00b0ca1588cb0bf9c64&scene=126&sessionid=1681312470#rd)

![](../Images/f8ef3ce3a076d99df384e877976c267f.png)

　　马航MH370客机“神秘”失踪之后引发了全球的关注，在网络和社交媒体上充斥着关于该事件的最新进展和相关报道，除了各种谣传和假新闻之外黑客也加入到 该行列中来，借助用户对该事件的关注程度利用社交媒体大肆传播恶意程序。援引英国连线报道Malwarebytes恶意程序分析专家Chris Boyd表示黑客在社交网络上发布携带恶意视频连接的类似于“马航失踪客机MH370在海上发现--50人生还”的新闻，用户点击之后就会感染。

![](../Images/291698b5d7786e57eae2ca39fc69e84c.png)

　　根据Hoax-Slayer.com官方博文称这些虚假的新闻都以“发现失踪MH370”来吸引用户眼球，博客主Brett M. Christensen表示一旦Facebook用户点击视频之后通常在观看之前会伪装成为Facebook的问卷调查，并且请求许可来调用你的个人信息等等。一旦许可之后就意味着包括手机号码、邮件地址等用户数据就会被黑客窃取，然后一些诈骗分子会根据这些信息进行进一步的诈骗。对此Facebook的发言人向CBS电台报道称公司已经开始对这些散播恶意程序的帐号和博文进行清理。
