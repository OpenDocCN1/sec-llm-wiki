# 全国政协委员贺强：中国迫切需要自己的云安全

　　目前，抢滩全球云计算和移动互联网基础设施布局、获取和控制网络海量数据，正在成为世界各国争夺未来信息社会控制权的重要战略手段。全国政协委员贺强日前在接受采访时表示，中国迫切需要自己的云安全。

　　“智能手机的快速发展，使我们的无线网成为今后发展的重点，在这个基础上，比如余额宝等互联网应用，都可以通过手机来支付，为大家提供方便。”贺强认为，虽然智能手机在人们生活中发挥着越来越重要的作用，但我国现在智能手机所应用的智能系统上仍存在两个明显的问题：一是中国的市场被美国的三大公司几乎完全给控制了，二是网络等行业垄断了我们的市场以后，打压自己的产业发展。

　　他回忆，当年阿里巴巴曾经准备发布一款搭载自主研发系统的手机，遭到谷歌的阻碍，因此失去了发布手机的机会。但更严重的是这些威胁了中国的国家信息安全，因为他们设在美国的云服务器，可以实时的把我们每个人打的每个电话、发的每个短信，网络银行发布的你的卡号等等信息，随时就传回到美国的云服务器，在中国可以获取大量的数据，然后通过信息的不安全技术等等一系列技术进行分析，分析出大量有价值的情报，对我们的信息安全造成很大影响。

　　美国国会曾抛出一份报告，认为华为、中兴这两家中国公司的经营活动对美国国家安全构成威胁。美国对中国企业的信息安全审查是史上最严格的，美国已将国家信息安全提到更高的地位。

　　在世界上，已经有越来越多的国家意识到建立自主手机操作系统和自主云计算的重要性。例如韩国宣布要开发自主移动操作系统的计划，并呼吁三星和LG改变对Android操作系统的依赖。

　　对此，贺强建议，建立开放竞争的市场秩序，加快研发推广自主可控的操作系统和云计算，抓紧培育阿里云这样的云服务龙头企业和产业体系。事实上，我国云计算产业的百花齐放使得云计算技术并非完全落后于美国等发达国家，且拥有了较高的技术和应用实践水平，通过政策与市场的双重努力，在云服务市场上做到数据自主、应用可控，提升在国际市场上的话语权，并非难事。
