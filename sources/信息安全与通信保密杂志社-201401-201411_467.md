# 两会委员关注 木马病毒成手机用户最大担忧

　　3月6日，央视晚间新闻继续聚焦两会，根据360互联网安全中心的数据显示，如今的手机用户最担忧的不是丢手机或是网购被骗，而是来自手机木马的袭击。在新浪微博与互联网安全相关的实时热度榜上，木马病毒、丢手机和购物网站被排在前三名。数据显示，目前针对手机的恶意程序威胁中，占最大份额的就是吸费木马。一旦中毒，这些木马病毒就会暗中定制手机增值服务，或偷偷拨打付费电话，让你在毫无知情中，就产生了高额费用。

　　根据360互联网安全中心公布的数据显示，2013年全年Android平台新增恶意程序样本 7.1 万个，较去年增长了88.3% 。也正如新闻中所言，资费耗损、恶意吸费类恶意程序占比最高，达到了67%。这意味着对于已经感染了恶意程序的手机用户来说，面临直接经济损失的可能性达到了近七成。

　　而这些恶意程序又是通过什么途径进入到民众手机中的呢？来自360互联网安全中心的数据显示，第三方应用市场及论坛仍然是恶意程序传播的主要途径，占比超过60%。其次的传播途径分别是手机预装和恶意网址。这与第三方应用市场的竞争日趋激烈，部分应用市场盲目追求软件和游戏的数量，对安全监管疏于管控造成的。

　　360安全专家建议，下载手机应用，一定要到安全的应用市场去下载，如360手机助手。收到以银行名义发来的短信，要仔细识别网址链接是不是银行官网，电话是不是银行官方客服。有疑问的时候，最好拨打银行官方客服进行询问后在做处理。

　　随着智能手机的普及，手机预装带和ROM带来的木马病毒威胁日趋严重，这一现象在水货手机和山寨手机中尤其常见。自2013年开始，已经有多起手机厂商工作人员因被利益驱使，在手机中植入吸费软件而被警方抓获。近日广受关注的“暗杀黑帮”木马也有极大的可能是由手机预装和ROM感染所致。

　　分析人士指出，本次两会委员关注手机木马病毒问题尚属首次，未来政府很有可能会对此加强监管力度。更多的关注有利于推动相关法律法规的制定与出台，让整个移动互联网安全领域能够有法可依，有章可循。
