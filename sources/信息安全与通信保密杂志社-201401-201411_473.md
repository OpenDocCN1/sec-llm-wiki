# 为敦促用户升级Windows XP 微软再出新招

　　4月8日，微软将正式停止对Windows XP的服务支持。虽然这家公司承诺将继续为用户提供为期一年的Security Essentials更新，但这仍无法保证系统的安全性。最好的办法也许就是从XP升级到更高的系统。对此，微软也开始采取了一些应对措施。

  

　　首先，微软将会在3月8日通过Windows Update向XP用户发出官方通知予以提醒。另外，微软还发布PC Mover Express这款工具来解决因系统升级而产生的文件转移问题。据了解，PC Mover Express将可把原设备中的文件、音乐、视频、邮件、文件夹及设置信息拷贝到新设备中，而且用户还能自行决定拷贝的具体内容。目前，微软已经在WindowsXP.com上发布了多个版本的PC Mover Express，支持的语言包括了英语、法语、德语、意大利语、日语、西班牙语，这个月晚些时候还将加入韩语、汉语、俄罗斯语、巴西葡萄牙语。
