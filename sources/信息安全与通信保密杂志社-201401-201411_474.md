# 工信部官员：要将打击伪基站列入刑法体系

　　央广网财经北京3月4日消息据经济之声《天下财经》报道，去年以来，工信部主导三大电信运营商联合开展一轮力度空前的垃圾短信治理行动，收效明显，但杜绝垃圾短信仍然任重道远。

  

　　一位手机用户花高价买下了一串9位数连号的VIP号码，没想到从此却成了轰炸目标，一年内收到房产、发票等6万条垃圾短信，用户投诉举报100多次，运营商也协助其不断拦截，虽然垃圾短信量有所下降，但问题始终没有解决，客户无奈之下只能换号，提起这个案例中国互联网协会秘书长胡钢认为，当前法律事件中对短信骚扰的区分并不清晰。

  

　　胡钢：判断确实很麻烦，前两天整天的房产信息，对于一个要买房的人也许还真的就去买了，有的人不想买房它可能很烦。

  

　　2012年12月，全国人大常委会在关于加强网络信息保护的决定中要求，未经接收者同意，不得发送商业性电子信息，最近国务院法制办就广告法修正草案征求意见也提出了类似新规，但这些在实践中都缺乏足够的操作性。

  

　　胡钢：我们刚才提到2012年12月28号，关于加强网络信息保护的决定，是把路线图给我们展示了，但是承担什么法律责任它没写，国外比如新加坡，一条可能上千新元，美国70年代就有这方面的法律。

  

　　长期以来，舆论将治理垃圾短信的压力集中在工信部门，但工信部相关负责人指出，垃圾短信分为违法和骚扰两种，前者由公安直接执法，而对于后者工信部也没有执法权。

  

　　工信部：要是工信能罚那就最好了，但是利用短信来推广它是属于广告的范畴，而广告的监管是在工商那一块。

  

　　去年工信部集中治理垃圾短信以来，用户日均投诉量下降50%，运营商端口垃圾短信下降80%，但70%的垃圾担心转向了伪基站传播，伪基站是一种可移动的大功率信号发射源，一小时可发送几万条短信，但法律对此的处罚却很有限，河南洛阳1月破获的一起案件中，涉案人员在半年内用伪基站平均每小时获利近400元，但仅仅被行政拘留10天，不处罚金。工信部电管局市场管理处处长徐强（音）指出，要将打击伪基站列入刑法体系。

  

　　徐强：伪基站其实不经过我们的公用电信网，用户一进入到这个区域之内，我用户就脱离了正常的通信网络，所以这种危害非常非常巨大，我们一直在推动高法，争取能够修订这样的一个司法解释，把这个伪基站这种情况作为一种刑事案件来进行受理。
