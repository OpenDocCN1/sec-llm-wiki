# 预警：情人节恐变“情人劫”

今年的元宵节，幸福地和西方的情人节“撞车”了。为此众多商家纷纷推出“双节促销”、“鲜花速递”等活动。不过，根据百度安全中心数据监测显示，和情人节相关的恶意网页在最近两天猛增，其中超过一半的虚假网站还存在网页被挂马的情况。此外，打着情人节礼品团购旗号的购物欺诈网站、情人节交友的山寨虚假网站也冒了出来。对此，百度安全人士提示，节日网购更要注意风险，要注重自己打造有效的网络安全保障。

  

鲜花是情人节必不可少的元素。根据百度搜索指数显示，随着情人节的到来，最近7天内“鲜花”、“巧克力”等关键字的搜索较此前上升了138%和84%。同时，利用假冒电商、模仿购物网站进行网购诈骗的行为再此呈现增长趋势。

  ![](../Images/bbc1609f8d29c02e2e6ffaabc253b8d9.png)

由于云南接连遭遇大雪天气，导致鲜花大规模减产，使得鲜花价格暴增数倍，网友戏称今年是“史上最贵情人节”。很多不法分子，通过假冒正规购物网站即钓鱼网站，以低价玫瑰、鲜花促销等各种方式来引诱用户进行交易，从而盗取网银账号密码，骗取用户财产。

  

除了鲜花速递，情人节的前后，网络上关于情人节的广告铺天盖地，各种打折促销、团购活动随处可见，巧克力、首饰、化妆品以及服饰等最受女性欢迎的商品，更是以诱人的价格，成为商家重点推销的对象。而在看似平静的网络交易平台之外，背后却是山寨网站、钓鱼网站的大规模涌现。

  

据百度安全实验室数据分析，情人节前夕影响消费者网络购物的安全威胁主要包括三大类：钓鱼网站、网站劫持木马、盗号木马。而消费者一不留心，就会陷入“周郞妙计安天下，赔了夫人又折兵”的悲剧中。

  

此外，情人节当天一些本地交友网站也会推出各种活动吸引单身男女参与，而一些不乏分子正是抓住了这一点，发送以“情人节交友、情人节约会”为噱头的邮件，诱骗用户去点击其中的链接，进而将用户引向骗子运营的山寨网站中，而这些网站往往都与网站木马、隐私收集有着联系，用户极易在不知情的情况下深陷其中。

  

针对以上情人节背后的风险和威胁，专业人士建议，99%的用户都不是电脑高手，无法人工识别并防范木马、恶意网站、山寨网站和钓鱼网站的威胁，因此，最好的办法是能在购物前或打开未知网站时，在电脑中安装一款安全防护工具。

 ![](../Images/0ef1f42f89c5457f0809d21f3bcc2ac9.png)

根据当前虚假网站横行、网购环境恶化的现状，百度杀毒在近期特别推出了“恶意网址识别”功能，该功能可以对用户在网页浏览或网购交易过程中可能遇到的安全问题进行精准防护，其中独有的“URL防护功能”更是可以自动拦截虚假、欺诈、挂马网址，让用户网购零风险，上网浏览更安全。

 

自百度杀毒发布以来，一直秉承“不骚扰，不胁迫，不窃取”的“三不”原则，依托“卡巴芯，百度云”的先进查杀模式，不断完善产品功能，逐步打造全面的安全防护能力。而百度杀毒新增的网购安全防护功能，能更有效地帮用户阻截网址风险，避免网络钓鱼和网络欺诈等危害，为用户的情人节提供安全的网络环境。
