# 【释放“双创”力量 崇州站在大数据风口 】“创业天府菁蓉汇•崇州”大数据创新发展专场活动隆重举行

【本刊讯】 6月5日上午，以**“双创引领升级•数据创造未来”**为主题的**“创业天府 菁蓉汇•崇州”大数据创新发展专场活动**在崇州市隆重举行。崇州站在大数据的风口上，释放了创新与创业的力量，彰显了崇州人的大数据情怀。

![](../Images/bb72c041e1614e2b0e4ba2d775c27ded.png)

**这场专场活动由成都市人民政府主办，中共崇州市委、崇州市人民政府、成都市科技局、成都市经信委共同承办，成都市大数据管理局、成都国信安信息产业基地有限公司、微软（中国）有限公司、信息安全与通信保密杂志社、崇州大数据产业创新联盟协办。成都市市政府副市长苟正礼，四川省经信委副主任王文胜，成都经信委副主任冷知用，中共崇州市委书记赵浩宇、崇州市人民政府市长欧昭，中国工程院院士倪光南、李乐民，中国科学院教授翟起滨，工信部标准研究院信息中心主任吴志刚等专家，中国电子科技网络信息安全有限公司江波常务副总经理、亚信数据董事长何政以及相关省市领导、专家和业界大咖出席了专场活动。**

![](../Images/478a9e8ebcdc36fb1178be3e62979f2f.png)

这场专场活动主要由“三大板块主题活动”构成。包括：**“成都网络空间安全与信息产业研究院”启动仪式（包括R+孵化器开园商业模式介绍）、大数据产业崇州发布、创业大咖经验分享与创业项目路演**。各板块穿插领导、专家学者、企业代表、投资人的“大咖观察”或“专题演讲”，分享国际国内创新创业经验。

专场活动首先播放了5分钟的**“梦想启航”宣传片**。作为地处西南腹地的县域级城市，崇州在整个大数据产业发展中，提出了一系列创新发展路径，大数据产业强势发展：四川第一个“互联网”众创空间；四川第一个大数据创投基金；四川第一个国资大数据公司；四川第一个开工建设的大数据产业园；四川第一个出台大数据产业发展实施意见的城市；四川第一个出台大数据产业发展规划；四川第一个出台大数据产业发展专项政策。四川省政府将崇州市基于大数据的“互联网+”众创空间列为重点推进工作；成都市将崇州纳入五大高端成长型产业布局，明确将着力打造崇州大数据产业创新驱动示范区；《成都“创业天府”行动计划（2015-2025年）》中明确“围绕新兴产业领域，着力建设崇州大数据产业园等一批专业孵化器”。微软、百度、中兴通讯、勤智数码等知名企业，共同入驻崇州IPC（智慧处理中心）核心枢纽。

  
![](../Images/27ad2c661ab10ce7dd6c80798c04b21d.png)  

**专场“主题活动”的第一板块“成都网络空间安全与信息产业研究院”成立仪式9时40分拉开帷幕。**倪光南和李乐民两位院士、苟正礼副市长、王文胜副主任、江波常务副总经理、何政董事长、赵浩宇书记为“成都网络空间安全与信息产业研究院”的成立启幕，随着他们共同触发启动光球，“成都网络空间安全与信息产业研究院”宣布正式成立。根据国家网络安全战略的需要，成都网络空间安全与信息产业研究院将以网络空间安全与信息产业研究需求为导向，推动成都市网络空间安全事业的发展，增强网络空间安全从业人员的交流，充分利用产学研平台，加强产学研合作，为国家网络安全战略做出贡献。

![](../Images/6cd2252a149f736119b3a885789d064d.png)  

启动光球后，倪光南和李乐民两位院士就成都有什么条件可以实现网络信息安全的目标发表了简短的看法，并指出新的发展方向。

倪光南说，首先应该祝贺成都的网络空间安全和信息安全的成就。当前的大形势是，我们要建设世界科技强国，我们的研究可以为中国的网络空间安全和信息产业的发展提供一个信息动能，要增加科技动力。我相信成都信息研究院的成立，在网络空间和信息安全方面能够起到积极的作用，做出重大的贡献。

李乐民说，崇州市提出大数据有关的产业非常好，这是一个热点。成都市在网络安全空间在全国是出名的，所以把大数据与信息安全结合起来，这是一个很好的发展方向。成都市的生活条件也能够吸收全国各地的优秀人才到这里来研究、创业。

  

![](../Images/dfd2fa4bdc1c8943532974e30cb0615e.png)  

随后，R+孵化器联合创始人李万鹏介绍了R+孵化器呈现方式及商业模式，并通过案例分享——VR技术在街子古镇乐园趣味化体验整体解决方案，具体解说了什么样的孵化器能够帮助创业者活下来。R＋孵化器提出了生态模型，品牌营销、产品验证阶段和市场推广阶段、“古镇＋”、V＋孵化器整体的时间规划各个环节的解决方案。

![](../Images/212ec9dc318c43c7d9294833ac88e201.png)  

在密码、大数据安全等领域的著名网络安全专家——中国科学院翟起滨教授在“大咖观察”环节分享了独到的见解。他说他最感兴趣的是崇州这个人杰地灵的地方。他认为，崇州大数据产业具有前瞻性，成都网络空间和信息安全在全国知名，把大数据与信息安全结合起来是很好的发展方向，成都的条件能够吸引更多人才为信息安全服务。我们做出的产品不是嘴头上的数据，而是实实在在的东西，这才是真正的产业基地。

  

![](../Images/e2bd429aebd9128b34767b4e2e0b3b9c.png)  

**主题活动第二板块“大数据产业崇州发布”10时推****出****。**崇州大数据产业新联盟会长廖昕、赛迪研究院互联网产业研究中心主任张爽现场发布了全国大数据产业发展研究成果及崇州县域大数据产业发展指数和成果。廖昕、张爽介绍说，他们半年前借助勤智数码建立了大数据产业综合指数模型，来计算崇州市大数据产业发展的成熟度。从2015年底第一次发布崇州大数据开始，至今半年时间，崇州大数据产业指数由第一期的427上升至523。他们认为崇州在大数据产业方面有一个完备的生态圈，这个生态圈以数据为土壤，顶层规划为阳光，区域政策为雨露，吸引了众多行业大数据企业和创业者们，如微软、中兴智慧、勤源信息科技、云润等，打造了如政务数据共享及交换平台、自由数据创新创业平台、虚拟硅谷、IPCloud以及iCloudunion等平台，基于这些平台，孕育出很多智慧应用树，这些智慧应用将给崇州的社会治理、民生和经济都带来新的活力。

  

![](../Images/d8536ad65892d32c04a3b05e7afd050e.png)  

明珠家具股份有限公司总裁、CEO王建斌分享了“明珠的大数据转型升级之路”。他们的创新之举，在于通过产业互联网链接产业链上下游，通过智能制造的升级提升产线柔性，最终走向大规模定制模式。为了完成这个转型，他们已经开始着手打造“4朵产业云”：家具产业链包括上游的原材料供货商，中间的家具工厂，下游的零售商/电商到最后的消费者。在链条的关键节点，他们发现利用企业积累的行业资源，再借助互联网，云计算等新技术就可以建立起产业电子交易云平台与供应链协作云平台。

上海社会科学院信息研究所惠志斌从国际战略分析的角度，在“大咖观察”环节对“崇州发布”发表见解，他说，从2014年开始围绕大数据网络空间信息化推进，县级城市如此重视大数据战略，在大数据和网络空间中找到适合崇州发展的战略地位，找到自己的坐标，路径和地位，崇州脚踏实地的务实精神值得肯定和推崇。大数据时代有无限可能，大数据时代打破了大城市和中小城市的边界，相信崇州在独特的人文环境和丰富历史积淀下探索的崇州模式，通过科学规划和科学模式总结，能够让崇州模式走出四川，走向全国，甚至走向世界。

**主题活动的第三板块“创业大咖分享与项目路演”10时30分进行。**电子科技大学大数据研究中心主任、成都数之联科技集团CEO周涛、北京物联港科技发展有限公司创始人、北京物联港科技发展有限公司董事长蔡鸿岩以及联汇通宝董事长、中国知名投资人黄雷做了精彩主题分享，共同探讨创业、创新发展面临的机遇与挑战。在“创业新人秀”环节，四川大学学生创业者带来三个项目，分别是CloudGarden、Flysoap、Roaming。在“创业大家帮”环节，崇州大数据产业园入驻企业展示了五个路演项目，分别是：成都勤源信息技术有限公司天使轮项目、成都中知慧科技有限公司的IPCLD智慧云的项目、成都志博科技有限公司的商旅客车帮项目、四川云瑞大数据的虚拟硅谷项目、崇州数联云算科技有限公司的Icloudunion项目。五个项目路演后，与会的各投资人嘉宾提问并做了点评，投资人对青睐项目举牌确定投资意向，填写了投资意向函。

  

![](../Images/797facd9844491ed04714e053b3e1216.png)  

在“大咖观察”环节，中国电子技术标准化研究院（工业和信息化部电子工业标准化研究院）网络与数据管理部主任、高级工程师吴志刚分享了大数据相关标准工作。吴志刚对四川大学三个学生项目作了点评。他说，创新的动力来自于人才，来自于年轻人。人才是创新的源泉，三个产品都找到自己的定位，找到了核心的创意。要打破常规思维，找到自己的应用点，让创新服务于生活。创新不在于非常复杂，而在于有没有想象的空间。我们要将科技与生活相结合，将双创与生活相结合，将人才的带动与产业的发展相融合，这些都是产业发展的种子，未来产业发展的动力。主要研究国家、城市与企业的竞争战略，产业经济与商业模式的独立学者、高级研究员罗天昊对5个路演项目发表点评说，崇州大数据的创业中心能不能成功，涉及到人才和人口的因素。成都高校在校人数大约是72万，排名全国第八，教育指数排名第一，这是未来进行大数据互联网创业中非常重要的决定性因素。每个项目都有人举牌，我相信举牌的人更多，投资人也就多。成都未来会聚集更多的财富，这也是创业的成功条件。未来中国最大的增长城市竞争就是在武汉和成都之间。很凑巧，现在唐市长既是以前武汉的市长，又是现在成都的市长。从财富来说，成都未来能够聚集多少个产业基地，对未来的创业成功也起至关重要的作用。
