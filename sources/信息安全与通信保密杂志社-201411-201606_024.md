# 2016贵阳国际大数据产业博览会圆满闭幕

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544340&idx=3&sn=53ef98afb9006439626213e06012a56a&chksm=c0b4f462f7c37d746eb02f10f379a359235c8fc083b5f7b2dddff2824cf2c40684c86de6358d&scene=126&sessionid=1681312407#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544340&idx=3&sn=53ef98afb9006439626213e06012a56a&chksm=c0b4f462f7c37d746eb02f10f379a359235c8fc083b5f7b2dddff2824cf2c40684c86de6358d&scene=126&sessionid=1681312407#rd)

**2016贵阳国际大数据产业博览会于5月29日在中国贵阳圆满落幕。超过300家大数据企业带来了1000余项全球最新的产品、技术和解决方案。智能硬件、可穿戴设备、机器人、无人机、智能交通、智慧生活等领域的最新前沿设计精品，刮起一股大数据风暴，进一步推动博览会向全球化、高端化、品牌化迈进，用大数据开启未来之门。**

  

  

  

2016数博会由中华人民共和国发展和改革委员会、中华人民共和国工业和信息化部、中华人民共和国商务部、中央网络安全和信息化领导小组办公室、贵州省人民政府主办，中华人民共和国国家发展和改革委员会高技术产业司、贵阳市人民政府、贵州省经济和信息化委员会等8家单位承办。大会以“大数据开启智能时代”为年度主题，聚焦大数据分析与应用、数据中心和配套产品、智能制造及设备、互联网创新应用、电子商务等五大板块，掀起了众人关注大数据的热潮。

  

据了解，围绕“国际水平、行业引领、专业平台”的三大功能定位,组委会邀请了高通、戴尔、富士康、中兴、浪潮、华为、HPE、HTC、腾讯、百度、阿里巴巴、京东、乐视等全球大数据领域顶尖企业前来参展；联合国可持续发展计划行动办事处、英国驻华大使馆、韩国大数据协会联盟、日本横滨、济宁高新区等国内外机构和组织、机构集中展示了大数据城市应用方面的成果。此外,展览还专门设立了5000平方米的国家(贵州)大数据综合试验区展区,集中展示贵州大数据产业发展的历程和成果。

展馆内，大数据应用和产品琳琅满目、一应俱全，华为的全球首款32路开放架构Kunlun小型机新品、乐视自主研发的LeSEE概念车、富士康的自助式渲染云平台等VR、AR、人工智能、大数据综合解决方案、高端服务器、大数据可视化、云平台等多种新品首次亮相。  
开展以来，展览吸引了近9万观众参展，其中专业观众超过1万人，先后有马化腾、郭台铭、刘强东、李彦宏、贾跃亭、王雪红、毛渝南等嘉宾和国家工信部、发改委等有关领导及部分高校专家学者到场观摩。贵州省、贵阳市机关、企事业单位近百家共4000余名干部职工参观。现场观众跃跃欲试,争相感知新科技。在不少展位上，体验VR、语音识别等新技术的观众排起长队，甚至有市民打听新技术产品的购买渠道和方式。  
今年展会同期活动精彩绝伦，看点目不暇接，新颖的“数小博”动漫主持人主持开馆仪式、奇虎360电子政务云新产品发布会、富士康客户签约仪式暨自助式渲染云产品会、小i机器人新品发布、数字冰雹智慧城市大数据可视化平台新品发布、HPE案例分享等71场高端活动吸引全球业界关注，为2016贵阳国际大数据产业博览会注入创新活力，全方位诠释中国大数据时代的到来，引领未来数据风向标，让世界看见贵阳——中国大数据之都。
