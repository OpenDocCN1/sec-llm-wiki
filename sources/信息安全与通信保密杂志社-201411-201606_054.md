# 工信部部长会见库克 鼓励苹果继续扩大在华业务

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544335&idx=1&sn=bcebdd4e9f4c98856747c293c00df18c&chksm=c0b4f479f7c37d6faea570c65c541859c7bac0aa87c436fd0d60a8e927abf0e2f9d9d697809e&scene=126&sessionid=1681312410#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544335&idx=1&sn=bcebdd4e9f4c98856747c293c00df18c&chksm=c0b4f479f7c37d6faea570c65c541859c7bac0aa87c436fd0d60a8e927abf0e2f9d9d697809e&scene=126&sessionid=1681312410#rd)

工信部网站今日通报称，工信部部长苗圩日前会见了苹果公司CEO库克。

  

工信部官网19日公告称，2016年5月17日，工业和信息化部部长苗圩会见美国苹 果公司首席执行官蒂姆·库克。

  

苗圩对苹果公司与中国业界近年来开展的广泛合作予以赞赏，他表示，“十三五”时期，中国政府将深入实施创新驱动发展战略，培育发展新动力，推动新技术、新产业、新业态加速成长。希望苹果公司进一步扩大在华业务，深化研发和产业链合作，为中国消费者提供方便、安全的用户体验。

  

![](../Images/27823479b3c8235b8de9d93f5652b07a.png)  

  

工业和信息化部国际合作司司长屠森林、电子信息司司长刁石京、信息通信管理局副局长刘多、节能与综合利用司副司长杨铁生、国际合作司副司长刘子平等参加会见。  

  

库克就任苹果CEO以来多次访华，此次来华的第一个背景是几日前苹果宣布10亿美元投资滴滴出行，此后库克来华与滴滴出行总裁刘青会面一度成为市场热议话题。

  

另一个背景是，苹果公司第一季度遭遇了2003年以来的首个季度营收下滑，其中多年来一直高速增长的大中华区营收也遭遇严重下滑，库克访华被一些市场观点解读为赴华寻找新增长点。
