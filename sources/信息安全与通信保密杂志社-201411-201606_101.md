# 【保密头条】全面贯彻落实中央决策部署 加快推动保密工作转型升级

面对复杂严峻的保密形势，中央作出的关于保密工作的决策部署，是党中央加强新时期保密工作的一项重大战略举措。习近平总书记发表重要讲话，对贯彻落实好中央决策部署提出了明确要求。**总书记的重要讲话和中央决策部署在保密工作发展史上具有里程碑意义，是信息化条件下推动和实现保密工作转型升级的根本遵循和行动指南，是保密事业发展的重大战略机遇，必将产生重大而深远的影响。**我们要以总书记重要讲话精神为统领，全面贯彻落实中央决策部署的一系列重大举措，加快推动保密工作转型升级。![](../Images/e3459f1b01ca8ed6f0e0d9a27aa478e4.png)**深刻认识中央决策部署的重大意义**  
**保密工作历来是党和国家的一项重要工作，是党和国家事业的重要组成部分。在革命、建设、改革各个历史时期，保密工作始终发挥着不可替代的重要作用。**![](../Images/5c44b998fa4c73483d833909bb728404.png)![](../Images/b57371e96cb8e024e3a19d4f2a74faa6.png)进入信息化网络化的新时期，各国综合国力角逐不断加剧，围绕信息资源的控制与争夺日趋激烈，窃密与反窃密斗争越发尖锐，**保密工作在党和国家工作中的全局性、基础性地位更加突出，服务保障作用更加明显**。  
![](../Images/7892d57c40f7063a69f314ea618f1413.png)进入信息化时代，网络窃密斗争愈发激烈。  
在这一新的历史背景下，为适应形势发展的新变化和保密工作的新要求，中央出台关于保密工作的决策举措，对全面推进保密工作加以系统部署，具有重大现实意义。![](../Images/fafb1e4c6cf2a2699422e0e9023dc32b.png)**中央决策部署指明了发展方向，是贯彻落实总体国家安全观重大战略的重要遵循**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)坚持和发展中国特色社会主义，保障国家安全是头等大事。国家秘密安全是国家安全的重要内容，保密工作是国家安全体系的重要组成部分，是实现和维护各领域国家安全的重要保障。**经济社会发展越快、国家利益拓展越宽，面临的安全保密风险就越大，保密工作的支撑保障作用就愈加重要。**因此，贯彻落实总体国家安全观，就必须按照中央的决策部署，切实做好保密工作。**中央决策部署提出了治理方略，是应对反窃密防泄密斗争严峻形势的必然选择**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)近年来，境外敌对势力和情报机构对我窃密活动空前猖獗。**西方国家加紧谋求信息霸权，加强全球信息资源的控制与争夺，把情报窃密作为对我实施西化、分化、弱化政治图谋的重要手段，实施全方位、立体式的情报窃密和信息监控，窃密目标紧盯我政治、外交、经济、科技、国防军工等重要领域，直指我党政军领导机关、核心要害部门和涉密人员，大国博弈日趋激烈。**只有全面贯彻确保国家秘密安全的治理方略，才能赢得反窃密防泄密斗争的胜利。**中央决策部署体现了对新形势的深刻洞察，是加快信息化条件下保密工作转型升级的客观要求**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)随着改革开放的深入发展和信息化建设的快速推进，保密工作的对象、领域、方式发生深刻变化，**国家秘密形态日益数字化、网络化，管理领域由体制内向社会、市场领域扩展**，保密工作的复杂性日益增强，保密管理的难度持续加大，保密管理手段亟须与现代科技加快融合。为此，**中央强调，保密工作必须实现由传统形态向以信息化为主要特征的现代形态转型升级**，既展示了对信息安全形势的深刻洞察，也体现了对保密事业发展的远见卓识。**中央决策部署反映了共同心声，是筑牢安全保密防线的迫切需要**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)当前，保密工作与信息化条件下维护国家安全和利益的需要存在较大差距，**保密能力整体相对薄弱，保密工作责任制不落实，保密法律和规章制度执行不严；定密不规范，网络失泄密严重，涉密人员管理不到位；自主创新能力不足，保密技术防范手段滞后；保密机构不健全，普遍缺少专职保密干部和专业人才，工作保障不力等问题仍然存在**。保密战线干部职工迫切希望中央加强顶层设计，统筹加以解决。中央决策部署的出台，不仅反映了大家的心声，也是构筑牢固的安全保密防线所必需。![](../Images/e3459f1b01ca8ed6f0e0d9a27aa478e4.png)**准确理解新理念新举措的核心内涵**  
中央高度重视保密工作，党的十八大以来，习近平总书记多次就做好保密工作作出重要指示批示。在国家安全内涵外延、时空领域、内外因素发生新变化的背景下，总书记发表重要讲话，提出确保国家秘密安全的治理方略，既是新形势下做好保密工作的根本遵循，也是保密战线干部职工的行动指南，必须全面领会、准确理解其核心要义和深刻内涵。**始终坚持党管保密，牢牢把握核心根本**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)党管保密是做好保密工作的最大政治优势，也是保密事业沿着正确轨道发展的根本保证。建党九十多年来，革命、建设、改革的实践充分证明，保密工作的发展进步和作用发挥，无一不是在党的保密工作方针政策指引下、决策部署落实中实现的。在新的起点上开创保密工作新局面，就要求**我们必须始终不渝地坚持党的统一领导，加强党委对保密工作的组织领导，发挥好党委保密委员会的作用**。**着力加强依法治密，牢牢把握基本途径**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)依法治密是实现保密工作科学发展、提高保密管理规范化水平的基本途径。经过新中国成立以来六十多年的艰苦努力，我们已经初步形成了以宪法为根据，以保密法及其实施条例为主干的保密法律法规体系。以此为基础，**强化运用法治思维和法治方式管理国家秘密的能力，进一步完善保密法规制度，加强保密行政执法**，才能站在新的时代高度，推进国家治理能力与治理体系现代化，确保国家秘密安全。**不断加大创新力度，牢牢把握强大动力**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)创新已经成为大国竞争的新赛场，谁注重创新，谁就能主导赛场规则。在保密领域实施创新发展战略，是落实创新发展理念的具体体现，目的就是要激发创新活力，调动广大干部职工的积极性、主动性。**面对赶超跨越的难得历史机遇，只有在创新发展上进行新部署、实现新突破，加强保密理念、体制机制和方法手段创新，特别是要充分发挥科技的基础支撑和引领作用，才能跟上发展大势、形成创新自觉、把握工作主动。****切实做好综合防范，牢牢把握方式方法**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)建立人防物防技防“三位一体”的综合防范体系，不断提高发现和消除泄密风险隐患的能力，是新理念新举措所重点强调的。领会把握这一要求，就必须**坚持技术防护和保密管理并重，特别是要综合运用建章立制、教育培训、技术防范、监督检查等手段，实现技术和管理高度契合、有机衔接；同时建立健全保密部门专业化的保密队伍，并在全社会营造共同维护党和国家秘密安全的良好氛围，力保保密“防护网”安全稳固、牢不可破**。![](../Images/e3459f1b01ca8ed6f0e0d9a27aa478e4.png)**全面把握中央决策部署的内容要求**  
各地区各部门要把认真学习、深刻领会习近平总书记的重要讲话精神和中央决策部署紧密结合起来，从五个方面把握其内容要求：**准确把握目标任务**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)目标指引方向。中央决策部署设定了在既定时间完成保密工作转型升级的总目标。**在实际工作中，要把中央确立的长远目标分解细化为目标体系，落实到5年规划和年度工作安排上，落实到具体任务中，确保整体目标的实现。**各地各部门要在中央确立的总目标指导下，实事求是确立清晰具体的保密“十三五”规划和年度工作的阶段性目标，通过短期目标的实现来引导保密系统扎扎实实地朝着长期目标努力。同时，从体制机制、管理体系、技术方式、人才队伍等多个方面，围绕总目标对具体任务进行分解，形成局部目标和单项目标，不断开辟保密事业发展的新境界。**认真抓好重点工作**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)根据当前实际，**定密管理、网络保密管理、涉密人员管理**仍是工作重点，要着力克服工作中的薄弱环节，提升各项管理的有效性和科学化水平。特别要强化精准定密，完善保密事项范围体系，强化定密不当责任追究，并充分考虑不同地区、不同部门的特殊情况，给予定密政策调整空间。加大网络保密治理的统筹协调，在确保涉密网络安全保密基础上，加强对互联网的保密管理和技术支持。完善涉密人员权益保障办法，加强对涉密人员的管理和核心重要涉密单位涉密人员的背景审查。**推进保密依法行政**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)落实“依法治密”的理念要求，按照全面依法治国战略部署，进一步明确保密依法行政的目标、原则和要求，严格履行法定保密职责，进一步规范保密行政审批，不断推进管理职能转变和管理方式创新，真正把保密行政管理纳入法治化轨道。在具体工作中，就是要健全保密法律法规体系，**强化机关、单位保密主体责任，形成适应信息化发展的现代保密管理能力；加强对保密法律法规、重要政策文件出台后的解读释疑，加大立改废工作力度，及时制定保密部门权力清单**。**加强保密科技攻关**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)在信息化条件下，科学技术是保密工作不可或缺的利器。加强保密科技研究和应用，是落实创新驱动发展战略的重中之重。要建立符合保密工作转型升级需要和科研工作规律特点的**保密科技创新体系**，最终打赢信息化条件下的保密战；**继续推进保密技术服务测评与监管机构和基础设施建设，充分发挥好保密监测平台的预警、防范作用，强化保密科技测评体系规范管理**。**推动机构队伍建设**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)要把保密机构队伍建设放在重要位置，规范中央和国家机关各部门、中央管理企业保密工作机构设置和人员配置，规范省级保密行政管理部门机构设置；加强思想政治建设和保密专业力量建设，建设一支忠诚可靠、又红又专的高素质现代保密人才队伍，为推进保密工作转型升级提供人才保障。![](../Images/e3459f1b01ca8ed6f0e0d9a27aa478e4.png)**切实把中央的决策部署贯彻好落实好**  
各地区各部门要以习近平总书记关于加强保密工作的重要讲话精神为统领，把学习贯彻中央关于保密工作的决策部署作为一项重大政治任务抓紧抓好，切实夯实打牢保密工作转型升级的基础。**要吃透中央精神，夯实保密工作转型升级的思想基础**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)中央关于保密工作的决策部署是我们党新时期加强保密管理的大方略。贯彻落实好中央要求，做好新时期的保密工作，必须牢牢把握这个大方略，各项政策措施、各项工作部署都要向这个战略目标聚焦，把中央要求变成我们的行动。**要认真学习中央决策部署的精神实质，深刻认识加强和改进保密工作的特殊重要意义、现阶段保密工作面临的复杂严峻形势和引领保密工作发展的新理念新举措，深刻理解中央提出的目标任务和具体要求。**不能有选择地学，仅盯着某个方面抓落实，必须原原本本、不打折扣，全面领会中央对形势的判断与做出的战略部署，结合当地实际，贯彻落实到各方面的保密工作中去。**要抢抓发展机遇，夯实保密工作转型升级的工作基础**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)中央的决策部署为保密工作发展提供了广阔空间和难得机遇，要充分用好当前保密工作落实的“窗口期”。目前各地区各部门任务很重，信息化发展日新月异，如果抓不紧、抓不实，就会跟不上保密形势的发展需求，错过推动保密工作转型升级的最佳时机。要以只争朝夕的精神，抓紧谋划部署好本地区本部门的保密工作，以敢于“破”、善于“立”的劲头，把决策部署的每一项任务落到实处，以开局之年取得开门红的实际成效夯实保密工作转型升级的工作基础。**要紧密结合实际，夯实保密工作转型升级的实践基础**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)中央的部署要求是立足全国大局提出的，不同地区、部门情况千差万别，会有不同的体现和侧重，面临的困难问题各异，任务也不尽相同。**各地区各部门在抓落实时，要紧密结合本地区本部门工作实际，创造性地开展工作。**要突出问题导向，以问题为线索进行谋划，找准本地区本部门的“短板”，通过科学设计和系统安排，破解制约保密工作发展的瓶颈性问题；要强化目标意识，以目标为旗帜进行谋划，围绕中央关于保密工作的重大决策部署的总体目标，做好本地区本部门的规划设计；要注重创新求变，围绕中央决策部署的发展理念、重点任务和重大措施，更新观念、创新思路、变中突破，努力开创保密工作新局面。**要加强统筹协调，夯实保密工作转型升级的落实基础**![](../Images/f94fcf09acb014f387639d0e3b9d6f04.png)要强化责任担当，面对复杂的形势和艰巨的任务，勇挑重担，敢于碰硬，在责任面前不推诿，在矛盾面前不回避，把心思集中到保密事业上，把力量凝聚到保密工作上，只争朝夕地谋思路、做工作**。要实行分类指导，根据层级、地区和领域不同的实际情况，有重点有步骤地进行精准指导，不断强化服务能力，同时注重总结新鲜经验和创新做法，及时交流、形成示范。**要加强督促检查，以任务为牵引，制定一揽子督查计划，采取先督后查、督导结合等方式，推动学习贯彻工作扎实进行，确保推动保密工作转型升级的目标如期实现。![](../Images/aea94f643312b7cdf0bc459271eb82b7.png)![](../Images/ec4b6ac227c0c820ec633dff3db3acd1.png)
