# 【企业动态】立思辰：数据安全管控专家

4月28日，**2016第三届“4.29首都网络安全日” 网络与****信息安全****博览会**在北京展览馆举行，本届首都网络安全日以**“网络安全同担、****网络生活****共享”**为主题，通过展览、论坛、竞赛等多种形式展示了当前最前沿的网络安全技术和信息安全理念。

![](../Images/c04f5767521d22d2c734333e42b0ff3a.png)  

立思辰信息安全科技集团总裁潘凤岩表示，数据安全、工控安全、自主可控三大领域并不是独立存在的，而是一体性的融合。数据安全就是在数据的全生命周期中保证数据各个阶段的安全；工控安全首先是针对工控系统、物联网、工业大数据安全，从安全的角度来讲包括能源、交通以及众多基础行业，安全态势比较严重；自主可控是个广义的概念，现在更多的是强调在最核心的技术上自主可控，一部分是关键技术自主研发，另一部分是确保引进的技术必须是可控的；国内比较典型的做自主可控的厂商是以服务器作为产品交付的，立思辰的自主可控主要是绑定应用，包括网关、以及数据输出的一系列产品，有硬件的同时，也融合了数据安全理念和工控安全的方案。

**数据安全管控专家**

现在市场上做数据安全的厂商很多，而且很多厂商认为数据安全就是主机上文档的安全，其实不然。数据安全是从一个数据的产生开始，到传输、应用、存储、消亡的过程，在数据的全生命周期中，保证这个数据各个阶段的安全。潘凤岩表示，在这些阶段安全里面有不同的产品不同的方案，并结合一些行业去做数据安全的管控。当然这里面涉及到很多种类的产品，最终闭合成一个全链条的数据安全产品并形成了解决方案。

立思辰信息安全集团副总裁王明华指出，现在数据无处不在，特别是在管理方面，过去主要基于PC端，基于服务器端，但是在云端的数据管理方面，很多公司是处于空白阶段。安全就是一个木桶原理，有一块短板，就还是不安全。

![](../Images/c53b55a8b12d43ae87249e43128b35e5.png)  

立思辰从整个全生命周期的每一个环节来分析数据有哪些风险，基于这些风险，采取相应的技术和产品去做防护，从而形成了立思辰独有的创新性的整体数据安全防护解决方案，并不仅仅是基于文档和传输过程进行加密，而是从整个数据在应用过程中的流程进行数据安全防护。

  

**多重布局助力数据安全保护**

潘凤岩表示，目前立思辰也在做大数据安全，这也是安全领域一个重要范畴，一个是集中，一个是离散，立思辰将来会主要发展移动端部分。现在很多行业都在应用大数据，但是应用的同时，如果不做好大数据安全，会导致灾难性的后果。

我们理解的大数据主要体现在数据量大和数据种类繁多两方面，但是我们关心的不应该仅仅是简单的文件，而是文件的内容。立思辰信息安全科技集团首席技术官傅刚指出，大数据安全对我们来讲首要的就是存储，在存储方面我们有数据安全存储网关，它对上层的应用是完全透明的，后面接着是磁盘阵列，我们可以把数据进行加密然后存进去，输出时就已经解决安全问题了；其次，就是如何让其得到很好地应用，立思辰现在有一个内容管理平台，负责对数据的用户进行认证鉴权处理，这就解决了两方面问题，一是通过加密的方式保护数据的安全，二是使用数据，必须要让它受控使用。围绕受控使用，对应着许多认证技术，包括各种各样配合的移动端、桌面端等各种受控软件的应用。对于用户来讲，安全就是对自身风险的防范。

![](../Images/ca704d16feca3b0dda5b61bcfb8b24e0.png)

潘凤岩称，立思辰除了通过自身实力研发的产品在大数据安全领域来进行应用与防护之外，在集团整个布局层面，还成立了一个信息安全基金。这个基金主要是应用在当前一些新兴的方向，比如大数据安全、云安全云计算，安全教育等。现在一些新技术给系统带来了一些新的安全问题，由于整个社会的应用形态发生了改变，所以当前网络安全防护手段与过去比也发生了很多的改变。 潘凤岩还表示，立思辰通过对相关公司的并购、收购以及在多领域的合作，未来会做出更多的网络安全产业布局。

  

**三个领域展示**

与此同时，来自国内的优秀安全厂商在会上全方位展示了网络安全技术、深入传达网络安全解决方案。作为国内信息安全领域的专业厂商，北京立思辰信息安全科技集团再次携多款安全产品亮相博览会。本次参展主要是围绕数据安全、工控安全、网络安全攻防演练三个领域进行展示。

立思辰一直致力于数据安全、工控安全和自主可控三个领域的技术、产品研发以及行业应用，提供信息安全产品、服务及解决方案。

1）数据安全产品包括移动加密机，综合安全网关，移动安全接入网关，安全存储网关，移动终端管控，终端管控，人脸识别，文档安全防泄密、安全增强型复印机等产品。

2）工控安全包括工控网络安全监控系统、工控内外网隔离设备、工业防火墙、工控运维审计平台、工业漏洞扫描系统、智慧城市照明安全网关、智慧城市照明安全节点、云端数据监控平台、工业控制加密认证装置等产品。

3）网络安全攻防演练的产品包括网络安全攻防实训平台、网络安全演练竞技平台、信息安全实验教学平台等产品。
