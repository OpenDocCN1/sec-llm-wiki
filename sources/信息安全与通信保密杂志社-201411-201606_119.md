# 二维码发展迅速 国产替代迫在眉睫

4月28日，以**“网络安全同担，网络生活共享”**为主题的**第三届4.29“首都网络安全日”**活动在北京展览馆开幕。

![](../Images/4db5bd3cc4ed5666c2a4caa67beb829f.png)  

由北京市经济信息化委、北京市公安局举办的以**“共创政务新安全助力智慧新城市”**为主题的**电子政务安全应用论坛**于28日当天顺利召开，论坛针对**北京市电子政务在云计算、大数据等领域新技术新形势下的电子政务**安全问题进行了探讨，内容涵盖**云计算安全、大数据安全、智慧城市安全以及工控安全**等。本次论坛聚集了众多国内知名信息安全软硬件厂商，吸引了多家电子政务建设单位，共同探讨分析了基础设备和基础软件安全在信息化与电子政务管理领域中的作用，在安全可信的信息技术及产品基础上推进电子政务信息安全体系的建设。

![](../Images/4deb9c978caef0a168287a0b014ba5a7.png)

**北京信息产业协会信息安全专业委员会常务副主任、北京鼎九信息工程研究院于学东院长**

**北京信息产业协会信息安全专业委员会常务副主任、北京鼎九信息工程研究院院长于学东**在论坛上对二维码的的历史沿革及在政务信息安全领域的应用做了详细的解读。

  

相对于一维码，二维码可存储的信息更加丰富，可广泛应用于网络空间和非网络空间，于学东院长表示，二维码是一种信息图形编码技术，不是物品编码技术，与信息内容无关，二维码是物品编码数据的载体。物品信息与“人”（主体）、“财”信息并列为社会经济运行的三大基础信息。与“人”、“财”信息相比，“物”的品种繁杂、属性多样；管理主体众多；运行过程复杂。如何真正建立起“物”的信息资源系统，实现全社会的信息交换、资源共享，一直是各界关注的重点。

  

同时，于学东院长谈到，二维码在2012年之后呈现爆发式增长，其中一个重要原因就是智能手机的出现。同时，简单、便捷的特点在二维码的发展过程中起到了至关重要的作用，二维码的应用领域也越来越广泛。

  

关于二维码的安全问题，于学东院长认为，二维码是一种载体，而它所承载的内容的安全与码有关，也就是说二维码编码知识产权和二维码识读技术知识产权都与安全息息相关。他同时表示，随着二维码在政务系统中的应用，国产替代迫在眉睫。迄今为止，中国国家标准化管理委员会正式颁布实施的二维码国家标准共有6个，分别是QR码、PDF417码、GM码、CM码、汉信码和D9ing矩阵图码。D9ing矩阵图码的生成和识读是基于国家密码算法的专用设备，是国家密码产品自主核心技术之一，是适用于国家行政机要文件、军事、商业领域的信息安全载体，可作为数字信息安全载体适用于各类网络信息安全应用。

  

于学东院长还强调，二维码如今越来越多地被各个领域广泛使用，但目前情况却是，拥有国外知识产权的二维码占据了大多数的份额，给方方面面安全留下了隐患。他建议，在有重要信息安全需求的政务系统中应使用更加自主、安全、可控的国产二维码。
