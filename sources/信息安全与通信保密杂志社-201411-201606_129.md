# 小编眼中：舌尖上的贵阳

在北方长大的小编，对于南方城市的美食风情向来充满好奇。

贵阳与其他西南城市的饮食习惯有相似之处，也有自身特色的不同。比如，贵阳的很多菜品里会有辣椒（当然也有单纯炒青菜），这一点跟四川、湖南的美食比较像，但贵阳的酸汤鱼又有点偏酸中带辣，这一点与别的省份似乎又有区别；炖土鸡，小编在安徽也品尝过类似的；而贵阳的酥李，在安徽、广西、四川也曾遇见......

  

下面就聊聊小编印象深刻的那些贵阳美食——

**1、贵阳美食第一站酸汤鱼：**  

老凯里酸汤鱼是去贵阳必吃的美食，酸度适中、酸中带辣的味道非常开胃，而且颜色红火鲜亮也比较诱人，小编认为能做出那么美的汤色应该是红番茄的功劳。喜欢牛肉的小伙伴还可以尝尝老凯里酸汤牛肉火锅：）

**2、炖土鸡**

贵阳的炖土鸡，也是非常值得一赞滴。

小编认为，清炖土鸡首先完整地保存了营养成分，而且鸡汤鲜而不腻。据悉，鸡肉有温中益气、补虚填精、健脾胃、活血脉、强筋骨的功效。（就因爱喝汤和极度怕冷，小编常被周围的朋友质疑：你肯定不是北方仁儿，也曾被斩钉截铁地归到广西、湖南......）

**3、酥李**

每到一个城市，小编喜欢探访当地的特色水果。

对于贵阳的酥李，小编更是印象深刻。由于气候温暖光照等原因，南方城市的水果比北方的要甜许多，这一点小编早有心理准备。可是没想到的是，即便看起来还十分青涩的酥李竟然也是酥脆清香、酸甜适口，肉厚汁多。青青酥李的外形跟海南的大青枣有点像，小编在安徽、四川、广西也见过。据悉，酥李这种水果富含维生素C、蛋白质、脂肪、无机盐、钙、铁和多种氨基酸，是降血压、增食欲、抗病、抗辐射、美容、抗衰老的绿色食品。

所以，每次出差小编只要遇到酥李，“从不放过”，带上一大袋，拎上飞机、带回北京......

据悉，贵阳的各类小吃也十分丰富，贵阳小吃是贵州省汉族饮食文化的重镇。仅汉族传统的风味小吃就达100多种，着实令人垂涎。无论白天黑夜，贵阳街头巷尾的小吃摊点星罗棋布，一些饭店酒店将有特色的部分小吃列入筵席中，还有专门的小吃筵可供品尝 贵阳最有名的风味小吃有：恋爱豆腐果、雷家豆腐圆子、糕粑稀饭、“丝娃娃”、荷叶糍粑、吴家汤圆 、 花溪王记牛肉粉、 程肠旺肠旺面 、清镇刘姨妈黄粑 、清镇热汤丝娃娃 、小吃广场臭名远扬臭豆腐 、小吃汤系列 、人剧卤味第一家、小吃广场白吃串串碳烧生耗 、河滨公园素春卷 、洋芋粑 、中曹野菜馆野菜系列 、青岩豆腐 、青岩黄家玫瑰糖......
