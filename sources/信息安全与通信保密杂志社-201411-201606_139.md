# 四专家眼中的网信座谈会：传达一个明确的信号

**导 语**  今日上午，习近平总书记主持召开网络安全和信息化工作座谈会并发表重要讲话。传播君第一时间约请专家，为你独家解读。

**左晓栋|中国信息安全研究院副院长**

  

十八大以来，特别是中央网络安全和信息化领导小组成立后，网信事业发展迅速，网络安全保障能力大大提升，探索出了有中国特色的治网经验，但仍有一些问题存在。因此，在这样的一个时间节点上召开网络安全和信息化工作座谈会十分必要和及时。

  

网络安全和信息化事关国家长远发展，党中央的坚强领导是这项事业成功的保证。中央召开这次座谈会，向外界传达了一个明确的信号，表明中央高度重视网络安全和信息化工作。我们网信工作者心潮澎湃、激动万千，相信我们的事业会进入一个新的阶段，从小胜走向大胜。

  

  

![](../Images/5aca6dfd982c37ded903627280905cda.png)

**唐绪军|中国社会科学院新闻与传播研究所所长**

  

习总书记明确向各级党政机关和领导干部发出了“上网令”。他说：“网民来自老百姓，老百姓上了网，民意也就上了网。群众在哪儿，我们的领导干部就要到哪儿去。”很长一段时间，上网似乎只是年轻人的事，很多领导干部不懂网也不会上网，因而对上网存有偏见，对网络舆论也不屑一顾。  

  

如今，我国有七亿网民，领导干部再不上网就会成为群众的尾巴了，既不知民情，也不懂民意，更别谈引导舆论了。过不了互联网这一关，共产党就过不了长期执政这一关。而要过这一关，党的各级领导干部首先必须学会上网。

  

  

![](../Images/f69d6ed18239834f50f7aa760c781d44.png)

**沈逸|复旦大学网络空间治理研究中心副主任**

  

这是中国网信事业发展进程中具有里程碑意义的一次重要会议。  

  

习总书记高屋建瓴，运用辩证唯物主义和历史唯物主义的分析框架，将网络安全和信息化工作置于宏观大背景中，做出了一系列凝聚中国智慧的论断和决策。

  

总书记的讲话，清晰勾勒出了中国网信大战略的轮廓，指出了网信事业承载的历史使命，精准扼要地回答了一系列曾经困扰和影响网信事业发展的核心命题，点出了全球化时代如何正确深刻地认识网信事业的核心要求，内在规律和本质特征，厘清了必须正确认识，把握和处理的关系和问题，为中国建设网络强国指出了一条正确的道路。

  

  

![](../Images/ecc108741859c46545ea56d2af9c9438.png)

**郑磊|复旦大学国际关系与公共事物学院院长助理**

  

“创新、协调、绿色、开放、共享”的发展理念与网信事业发展不仅紧密相关，更是量身定制。

  

在互联网大数据创新，线上线下协调融合，数据共享与开放，共享经济，智能化条件下的资源节约和绿色经济等各个领域，网信事业都大有可为。

  

习总书记要求领导干部经常上网看看，了解群众所思所愿。但并不是让领导干部们在网上凡是看见自己不喜欢的内容和批评意见就进行删除和压制，而是要“多一些包容和耐心，对建设性意见要及时吸纳”，对善意的批评“要认真研究和吸取”。最后，从人民利益出发，通过政民之间的良性互动和合作，建设天朗气清的网络空间。![](../Images/eb8816ddce6a0d075c6a2d2e59841d67.png)
