# 中关村可信计算产业联盟标准化工作启动会在京召开

11月25日，中关村可信计算产业联盟（以下简称联盟）标准化工作启动会在北京新世纪日航酒店召开，沈昌祥院士、信安标委刘贤刚副秘书长出席会议并讲话，浪潮、联想、中标软件、国网智能电网研究院、北京工业大学等30多家会员单位代表出席会议。

会议启动了两项主体标准（《可信平台控制模块》、《可信基础支撑软件》），和四项配套标准（《可信计算规范体系结构》、《可信服务器平台规范》、《可信存储规范》、《可信计算机可信性测评规范》）的研究工作，预计2016年上半年将发布联盟标准，并按信安标委有关要求申报国家标准。
