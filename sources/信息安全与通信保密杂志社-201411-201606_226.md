# 第二届（2015）中国可信计算技术创新与产业化论坛在京召开

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544273&idx=2&sn=61ad7ec2923a6736f15560757ba89669&chksm=c0b4f7a7f7c37eb1ac5a2ad7467b9c9f8106bbdcb3016ad2ce565b12a2a6ced0745467492020&scene=126&sessionid=1681312421#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544273&idx=2&sn=61ad7ec2923a6736f15560757ba89669&chksm=c0b4f7a7f7c37eb1ac5a2ad7467b9c9f8106bbdcb3016ad2ce565b12a2a6ced0745467492020&scene=126&sessionid=1681312421#rd)

11月5日，第二届（2015）中国可信计算技术创新与产业化论坛在北京美泉宫酒店召开。本次论坛由中关村可信计算产业联盟、中国电子信息产业集团联合主办，旨在促进我国可信计算技术创新和产业化发展，为构建国家网络空间安全提供技术和产业支撑。

  

![](../Images/6dbac6c81cb98bbbff378f75d18135eb.png)  

网络空间安全关系国家安全和经济社会发展，习近平总书记指出：“没有网络安全就没有国家安全”。在日趋激烈的国际网络空间博弈中维护国家战略利益，需要构建积极防御的网络安全防御体系，可信计算是构建积极防御的网络安全保障体系的核心技术。本次论坛围绕“用可信计算构建网络空间安全”这一主题，探讨了可信计算在国家网络安全战略中应发挥怎样的作用，以及如何更好的发挥作用等问题。

  

会议分为上午的主论坛和下午的三个分论坛。工业和信息化部怀进鹏副部长、中国工程院陈左宁副院长（院士）、中央网信办网络安全协调局胡啸副局长、工信部信软司陈英副司长、北京市经信委姜广智委员等领导，中国工程院沈昌祥院士、倪光南院士、何新贵院士、吕跃广院士、费爱国院士等专家，中国信息安全测评中心、国家信息技术安全研究中心、解放军信息安全测评认证中心等国家信息安全专业机构及国内可信计算领域企事业单位代表约300人出席了论坛。

  

![](../Images/46548ff36f677bbca465509ce92582a0.png)  

  

工业和信息化部怀进鹏副部长在致辞中指出，如何网络强国，如何通过信息化实现国家的现代化，实现中国梦，是摆在我们面前的课题。未来的发展当中，互联网、云计算已经成为新的应用模式，工业互联网、工业云提出了新的安全的问题，同时也为网络安全技术和产业发展带来了更大的机遇。加强网络安全技术的研究，深入开展可信计算的创新和产业化的发展，对于保障国家安全，保障网络安全，保障企业和公民的信息安全和商业安全都具有及其重要的意义。未来的网络安全，特别是基于可信计算的网络安全有非常光明的前途。一年来，沈昌祥院士倡导的可信计算产业联盟取得了阶段性成果，为中国可信计算的发展做出了贡献。希望联盟能够越办越好，特别为社会、为国家、为用户提供更有效的安全技术和产品，期待中国的网络能够更安全。

  

![](../Images/b0e5a5380ad5cf60e96b068e32f6363b.png)  

  

中国工程院陈左宁副院长在致辞中指出可信计算技术的创新发展，为我国实施国产化替代战略提供了有力的支撑，尽管国产化产品可能存在更多的缺陷和漏洞，但可信保障使得缺陷和漏洞不被轻易的攻击和利用。我国在可信计算方面，整体技术水平与国际同步，部分创新点处于国际领先地位。目前要尽快推动可信计算技术的产品化、产品的市场化和市场的产业化。希望业界集中优势力量，开展可信系统架构的适配和协同，共同打造具有自主知识产权、适应国家战略需求的可信计算生态环境。

  

![](../Images/4658992cc563ee509157df38afa9305d.png)  

沈昌祥院士在题为“基于可信计算构建网络安全防御体系”的报告中，从可信免疫的体系结构、自主创新的可信技术、构筑积极防御的网络安全防御体系三个层面介绍了对网络空间安全的思考。沈院士认为，“可信可用方能安全交互，主动免疫方能有效防护，自主创新方能安全可控”，网络安全问题的根本原因在于计算机体系结构在设计时只追求计算速度，并没有考虑安全因素。沈院士从“为何构建、如何构建和防御效果”三个角度深入分析了可信计算与网络空间安全的关系，提出了“以可信计算为基础、访问控制为核心，构建可信安全管理中心支持下的，积极主动三重防护框架”的实施方案。基于可信计算构建网络安全防御体系，最终将实现信息系统的“可信、可控、可管”。

  

![](../Images/2c4df0dfedf3c743a68e7141a8d06061.png)  

  

倪光南院士做了题为“核心技术不能受制于人”的报告。倪院士认为保障网络安全要立足于自主创新，中国的可信计算基于我国自主创新的密码体系，是保障网络安全的利器。可信计算具有排他性，其提供者拥有对系统的绝对控制权，所以可信计算技术必须是自主可控的，否则就必然受制于人。在谈在Win8和Win10问题时，倪院士指出正是因为Win8采用了国外的可信计算技术，因此我国政府采购未予采纳。Win8和Win10对微软“可信”，但对中国信息安全厂商却是不可控的。出于安全考虑，同时为了给中国PC领域的自主创新争取一个窗口，建议Win10和Win8应予以同等对待。

  

中央电视台副总工程师宋宜纯介绍了央视实施可信化与可信制播环境建设的情况。实施可信制播，打破了原来一味的封堵、查杀的被动防御方式，走向主动防御。可信制播主要强调构建一个安全的执行环境，保护计算及其对象的完整性、真实性、机密性和不可抵赖性，基于可信计算技术，以不变应万变，把播出安全做的更好。可信化不仅能做到防病毒、防黑客，还能保证整个业务流程有据可查、不被破坏，是解决制播环境安全问题的有效途径，在工程实施上可行，引入的成本和开销也是可以接受的，为业务安全和运行安全提供了坚实的保障。

  

TCG大中华区联合主席、国民技术股份有限公司产品总监刘鑫介绍了国际可信计算技术和产业应用的发展情况：可信计算技术进入了又一个快速发展时期，TPM 2.0规范成为国际标准，采纳了中国可信计算的创新思想并支持中国商用密码算法，国际上出现了更多的可信计算应用，也为建设我国可信计算产业展现了新的机会。

  

在主论坛的最后时段，中关村可信计算产业联盟和北京可信华泰信息技术有限责任公司联合发布了“白细胞创业网”。这是我国首个以讨论可信计算技术，推动可信计算技术研究及产业化为目标的技术型开放社区。白细胞创业网包括开放专区，开发者专区，淘软件专区，淘任务专区，双创专区，软件公测专区六大专区，其中作为可信计算产业化成果的可信操作系统、可信计算应用支撑平台将在开放专区展示，为更多创客及企业提供免疫环境以及安全支撑。

  

当天下午，中关村可信计算产业联盟的四个专业委员会（可信计算基础支撑平台专委会、可信终端和整机专委会、可信软件专会和可信云计算专委会）分别承办了三个分论坛，业界16家公司在分论坛上介绍了各自在可信计算方面近期的工作进展，内容涵盖可信计算产业链的各个环节，参人员就工程技术和产业发展等问题进行了务实和富有成效的交流。

  

此外，论坛还集中展示了中关村可信计算产业联盟会员单位的一批原创性可信计算技术和产品成果，涉及可信芯片、可信板卡、可信终端、可信服务器、可信工控等各个领域。相信中国可信计算技术和产业的发展，必将为我国网络空间安全提供有力的保障和支撑。
