# 大数据时代下信息安全产业创新发展机遇

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544230&idx=2&sn=010e797018253c71aee20f86e3354538&chksm=c0b4f7d0f7c37ec61a38a9ddac54992283b0c9290ed91c190fca8689debdd8946f39669dd0cf&scene=126&sessionid=1681312427#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544230&idx=2&sn=010e797018253c71aee20f86e3354538&chksm=c0b4f7d0f7c37ec61a38a9ddac54992283b0c9290ed91c190fca8689debdd8946f39669dd0cf&scene=126&sessionid=1681312427#rd)

　　5月26日下午，信息安全与通信保密杂志社同贵阳市人民政府主办的"聚合 引领 创新--中国大数据时代信息安全产业创新发展高峰论坛"在贵阳国际生态会议中心成功召开。

  

![](../Images/be8efb8b0e460cf9e4ba04b8ce46e495.png)  

  

高峰论坛由中国电子科技网络信息安全有限公司卿昱副总经理主持，贵阳市市长助理董贵山、中国电子科技集团公司副总经理胡爱民、工业和信息化部信息服务处处长李琰分别致辞。贵阳国家经济技术开发区管委会副主任施波、贵阳市经济开发区招商引资局局长叶国强等领导出席高峰论坛。

  

　　作为"2015贵阳国际大数据博览会"中最为专业的大数据安全论坛，凝聚了中国工程院倪光南院士、中国工程院沈昌祥院士、中国人民公安大学程琳校长、公安部网络安全保卫局祝国邦副处长、交通部信息安全中心负责人李璐瑶、银联移动支付顾问专家及联汇通宝黄雷董事长、电力规划设计总院信息中心阎平副主任，中国电子技术标准化研究院网络与数据管理部主任吴志刚，工业和信息化部电子第五研究所信息安全室主任王颖凯以及云络网络科技首席执行官和首席技术官Steve Mushero等众多国内外知名信息安全领域院士、专家、领导，相聚贵阳共论大数据时代信息安全挑战与新发展机遇。

　  

　　5月27日上午的论坛更是群英荟萃，国际国内的知名信息安全企业纷纷在论坛亮点环节--"产业论道"上亮相。来自国际知名企业微软安全技术政策高级经理陈恺先生、RSA大中国区总经理胡军先生、ChinaNetCloud（云络网络科技）创始人顾逸南女士分别上台演讲，带来了国际大数据产业的最新动态与观点，同时也表达了国外企业本土化的瓶颈与难题；而来自国内知名企业的浪潮副总经理蔡一兵先生、启明星辰副总裁周宗和先生、上海三零卫士市场总监汤江灏先生、山石网科副总裁杨庆华先生等嘉宾也纷纷表达了国内产业的现状、瓶颈与未来发展规划等问题。整场论道环节，国际国内企业代表各抒己见，观点鲜明，不但阐述了制约国际国内大数据安全产业发展的问题，也各自表达了相关的解决之道，同时也为整个产业不遗余力的献计献策。
