# 3·15曝光：公共WiFi用户密码遭泄露

刷微信、看视频，流量省着用，不够用。因此，消费者就形成了去哪都要问一句“WiFi密码是多少？”去哪都要“蹭一下网”。今年央视3·15晚会就曝光了免费WiFi的问题，演示了黑客利用免费WiFi网络窃取用户邮箱账号和密码的过程。专家建议免费WiFi使用需谨慎，涉及个人信息输入切换至3G、4G网络比较安全。

  

　　**WiFi网络较“脆弱”安全隐患多**

  

　　无线网络发达时代，随时随地的搜索免费WiFi已经成为人们的习惯。据WiFi联盟的数据显示，我国已经成为WiFi需求量最大的市场。WiFi在我国的渗透率达到21.8%。现在的WiFi覆盖了大型综合商场、宾馆酒店、飞机场以及咖啡厅之类的区域环境。

  

　　然而，WiFi本身存在一些安全隐患：WiFi非常容易被发现，为了能够使用户发现无线网络的存在，网络必须发送有特点参数的信标帧，这样就给攻击者提供了必要的网络信息。入侵者可以轻易的进入WiFi网络。

  

　　免费的WiFi毫无安全防护措施，一旦攻击者进入之后，就可以对网络中传输的数据进行截取。3·15晚会演示的黑客可以通过技术手段截取到用户的邮箱、聊天信息、银行密码以及基本的设备信息。

  

　　另外，即使公共WiFi设置了密码，但由于密码过于简单，黑客可恶意修改路由器的DNS地址，当用户访问正常网站时，被指向一些恶意非法网址或者钓鱼网站。

  

　　还有一些黑客自己用电脑或手机搭建一个“热点”，仿冒免费公共WiFi的名称，用户一旦连接上，各种登陆信息，被抓包软件复制并揭秘，窃取信息。

  

　　**WiFi也分甲乙丙丁 连接需谨慎**

  

　　目前WiFi热点分运营商所建的热点和商家自建WiFi。运营商级WiFi是电信级管理，采用了多种安全措施，并且有24小时监控，安全级别最高。

  

　　商家自建WiFi又可以分为大型单位建设的大规模WiFi覆盖，比如机场；还有一些是商业场所利用有线网络搭建的WiFi热点，比如小餐馆提供的WiFi。这样的WiFi没有专门进行安全设置，安全级别较低，容易受到攻击。

  

　　**教你如何安全使用公共WiFi**

  

　　首先不能贪图小便宜，选择来路不明的WiFi，尤其是免费、不需要密码的WiFi。第二，不要使用公共WiFi进行个人信息登录或者购物。3G、4G蜂窝网络采用SIM认证方式，安全性最高。因此，专家建议涉及个人信息输入切换至3G、4G网络比较安全。

  

　　第三，养成良好的WiFi使用习惯，尽量不要将WiFi设置成自动连接。手机会把使用过的WiFi热点都记录下来，如果WiFi开关处于打开状态，手机就会不断向周边进行搜寻，一旦遇到同名的热点就会自动进行连接，存在被钓鱼风险。

  

　　第四，需要安装安全软件，每天至少进行一次对木马程序的扫描，尤其在使用重要账号密码前。每周定期进行一次病毒查杀，并及时更新安全软件；

  

　　第五，尽量使用有验证机制的WiFi服务。可以找工作人员确认后连接使用。
