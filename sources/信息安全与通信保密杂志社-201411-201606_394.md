# 新锐公司上榜网安百强 折射安全行业新评价观

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544196&idx=4&sn=50fcb29ac698f0aa536a137a147a050d&chksm=c0b4f7f2f7c37ee4dedf48cf24617a5c950aee4d5e15316c14eea975da858c08ded543fa533f&scene=126&sessionid=1681312432#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544196&idx=4&sn=50fcb29ac698f0aa536a137a147a050d&chksm=c0b4f7f2f7c37ee4dedf48cf24617a5c950aee4d5e15316c14eea975da858c08ded543fa533f&scene=126&sessionid=1681312432#rd)

　　日前，美国网络安全市场调查公司Cybersecurity Ventures发布了一份《网络空间安全企业500强》榜单，对全球主要的网络安全厂商进行了排名。

  

　　Cybersecurity Ventures的创始人兼首席执行官斯蒂夫·摩根表示，此榜单是在研究了近年来数百起网络安全事件和新闻后得出的结果，同时参考了CISO和CIO的推荐。依据最新的《网络空间安全市场报告》，网络空间安全市场将从2014年的710亿美元，迅速扩张，到2019年预计将达到1550亿美元。如此快速发展的市场，一定会有大量的新加入者，以及不断影响和改变市场环境的并购、投资和IPO活动。

  

　　名列榜单前十名的全部为美国企业，其中多为新兴网络安全企业，包括创立不久的Moka5（第2）和Norse（第4），而以高级威胁保护为主要业务的美国安全公司FireEye名列第一，而老牌安全厂商赛门铁克、趋势、迈克菲（被英特尔收购后更名为英特尔安全）等均未能进入十强。有三家中国大陆地区厂商进入榜单，其中安天进入百强，名列第94位。

  

　　在Cybersecurity Ventures网站，列出了评选标准，包括网络安全行业（市场类别）、解决的问题、客户基础、首席信息安全官和决策制定者的反馈、IT安全评估与推荐者（注：企业名）的反馈、企业风险评估、法律人员及顾问的反馈、风险投资基金、企业增长性、公开的产品评论、企业市场和品牌等，这与以往的类似评选有截然不同的标准。摩根表示，"评选并不依据收入、员工数或年度增长率排名，因为"对于网络空间的受众和IT安全的决策者、评估人和推荐者来说，他们已经知道各厂商的实力。"

  

　　据网络安全业内人士分析，此榜单体现出来的核心意义在于，对网络安全行业而言，传统意义上以企业规模、产品线和服务完备程度进行企业排名的评判标准正在转化为对网络空间威胁应对能力和潜力的关注。当前新兴的威胁贯穿了整个虚拟世界和实体世界，网络安全解决方案不再只是简单的产品堆砌，而是厂商锐度和反应的比拼，在这样一个新的标准下，传统以营业额、产品数量的排名不足以体现一个厂商在新空间下的能力与潜力。占据空间五百强榜首的FireEye（火眼）公司2013年上市前，只是一个规模不足400人，营业额约1.6亿的中等规模企业，其今天的规模和收入也只是传统巨头安全厂商的零头，却因其敏锐性和纵深能力，成为美国国家安全能力的重要支点之一，说明了网络安全厂商能量和能力的评价标准正在发生变化。

  

　　如对国内上榜厂商的入围原因进行分析，安天上榜的原因应是因其长期扮演反病毒引擎供应商的角色，从而在国际安全产业体系中扮演了比较独特的供应链位置。

  

　　而具有硅谷背景的下一代防火墙厂商山石（Hillstone Networks）排名142，高于其竞争对手瞻博（Juniper ，排名261）,和飞塔（Fortinet， 排名274），也说明新锐厂商可以凭借"空间"加速度，取得比体量更大的传统对手更有利的先导位置。

  

　　国内的另一家指纹认证解决方案厂商也入选500强，其上榜的原因应该亦来自其供应链的独有角色。

  

　　国内厂商在空间本次500强中席位不多，一方面说明更多国内网络安全企业还需要一个被国际产业界了解的过程。而本次入选的的三家国内厂商均有一定的全球视野，或在全球产业链卡位、或在海外客户分布、或在国际测试表现等方面有鲜明特色（山石横跨中国和硅谷，安天的检测能力在去年获得了AV－Test年度奖项，并保持了较好的水平）。而国内厂商如果想要广泛走出去，占领海外市场就要在国际测试、行业视野、企业风格、文化展示有更多投入，另一方面也说明那种产品线贪大求全、以合规集成为主导的经营理念可能不再适合网络空间的安全场景。

  

　　近两年，更广阔的网络空间（Cyberspace）场景下的博弈安全观逐渐被人接受，以情报驱动，直面威胁，数据支撑、比拼团队敏感性、专注度以及对安全的理解和底蕴的新锐厂商群体正在崛起，新的评价方式也在崛起，这意味着国内的产业界、管理部门都必须更关注新的趋势，摆脱过去只以营业额、大而全的产品和服务等最为唯一评判标准的认识，而国内相关企业在产品、能力、服务的深入上也面临着更严苛的挑战。
