# 保障德国制造业的未来--“工业4.0”战略计划实施建议（2）

有60%的德国机械和设备制造商认为，未来五年他们的技术竞争优势将增强，而只有不到40%的企业希望保持现状。12虽然如此，制造技术行业的全球竞争正愈演愈烈。并且，德国制造业的威胁不仅仅来自亚洲的竞争对手——美国也已采取措施，通过推动“先进制造业”发展的计划来应对去工业化。此外，制造业正变得越来越有活力，越来越复杂。例如，激光烧结技术的进展意味着，而今有可能在几个小时之内“打印”出高品质的复杂三维结构。这将催生全新的商业模式和服务模式，在这种模式中，终端客户能够更紧密地参与其中——客户可以自行设计并且通过电子邮件提交给“复制店”，或者可以直接扫描物品并“复制”。

  

  

因此，在产业科学研究联盟的倡导下，“工业4.0”平台背景下的合作伙伴为自己设定了目标，积极实施德国政府提出的“工业4.0”战略计划，确保德国工业的竞争力。

  

“工业4.0”计划拥有巨大潜力：满足单个客户的要求

  

在“工业4.0”时代，能够将独特、客户特定标准融入设计、配置、订购、规划、制造和操作阶段，使在最后一分钟进行更改成为可能。在“工业4.0”时代，能够制造生产量非常小的独一无二产品（1个批次），并保证获利。

  

灵活性

  

基于信息物理系统的自组织网络能够对业务流程的不同方面进行动态配置，比如：质量、时间、风险、稳健性、价格和环保性。这有助于持续调整材料和供应链。还意味着，可以进一步提高工程流程的灵活性，改变制造过程，补救暂时的短缺（如供应问题造成的缺货），并且能在短时间内大幅度地提高产出。

  

决策优化

  

要想在全球市场上取得胜利，在非常短的时间内作出正确的决策已成为一个至关重要的因素。“工业4.0”实现实时的端到端透明化，能够对工程设计决策进行前期验证，并且能够更灵活地应对生产中断和在生产领域对企业所有场所进行全局优化。

  

资源生产率和效率

  

工业制造工艺的总体战略目标仍然适用于“工业4.0”战略计划：利用一定量的资源获得可能最大的产品产量（资源生产率）以及利用尽可能少的资源量获得指定的产量（资源效率）。通过信息物理系统，可以在整个价值网络中根据具体情况对制造工艺进行优化。另外，不必停止生产，在生产过程中就可以不断优化系统的资源和能源消耗或降低排放。

  

通过新型服务创造价值机会

  

“工业4.0”战略计划开辟创造价值的新途径和新的就业形式，比如通过下游服务。智能算法可应用于智能设备记录的大量不同数据（大数据），提供创新型服务。“工业4.0”战略计划为中小企业和新创企业提供非常重要的机会发展B2B（企业对企业）服务。

  

应对职场上的人口结构变化

  

结合工作组织架构和能力培养计划，人与技术系统之间的交互协作为企业提供将人口结构变化变为优势的新途径。面对技术工人短缺和劳动力多元化（就年龄、性别、文化背景而言）的趋势，“工业4.0”战略计划使多样、灵活的职业途径成为可能，年龄较大的工人能够继续工作下去，并更持久地保持其生产力。

  

工作-生活平衡

  

采用信息物理系统的更灵活的工作组织模式意味着企业能够很好地满足员工不断寻求工作与私人生活之间更好的平衡以及个人发展与持续职业发展之间更好的平衡的需要。例如，智能辅助系统提供新的机遇以实现灵活性新标准的方法组织工作，从而满足企业要求和员工的个人要求。由于劳动力规模趋于下降，当企业招聘最佳的员工时，这会使采用信息物理系统的企业处于明显的优势地位。

  

仍具竞争力的高工资经济

  

“工业4.0”双重战略能让德国发展作为领先供应国的地位，并且能够在“工业4.0”解决方案市场中占据主导位置。

  

但是，“工业4.0”战略计划并非只对相关产业带来专门技术或信息技术相关的挑战，日新月异的科技还会对组织结构发生深远的影响，需要改变组织方式提供新商业模式和企业模式，以利于提高员工的参与度。20世纪80年代初，德国将可编程逻辑控制器（PLC）融合到制造技术中，实现了更加灵活的自动化制造，与此同时，采用基于社会伙伴关系的方法管理自动化对员工的冲击，从而成功完成了第三次工业革命（“工业3.0”）。强大的工业基础、成功的软件产业及语义技术15方面的专业技术奠定了德国实施“工业4.0”战略计划的基础。德国理当有能力克服诸如技术接受度问题或劳力市场上技术工人储备有限等当前面临的重重障碍。但是，只有所有利益相关方精诚合作，挖掘物联网与服务互联网为制造业带来的潜力，才能保障德国工业的未来。

  

2006年以来，德国政府在高科技战略指导下不断推行物联网与服务互联网16，还成功推出了多项技术计划。产业科学研究联盟当前正通过“工业4.0”项目跨领域合作推动该计划的进展。合乎逻辑实施步骤是由德国信息技术、电信和新媒体协会（BITKOM）、德国机械设备制造商联合会（VDMA）和德国电气电子行业协会（ZVEI）等专业组织共同组建“工业4.0”合作平台，并设立了秘书。下一任务是制定关键优先课题的研发路线图。

  

保障德国制造业的未来——这是“工业4.0”平台中合作伙伴为自身设立的目标。本平台欢迎所有相关利益方不断探索“工业4.0”战略计划带来的机遇，共同确保变革远景的顺利实现。
