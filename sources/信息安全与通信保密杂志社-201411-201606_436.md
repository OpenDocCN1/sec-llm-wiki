# 鲁炜当选全球互联网治理联盟成员

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544176&idx=1&sn=aa8c96a84f136c572d19348879c032a1&chksm=c0b4f706f7c37e1077e70d5a801931ff9745260e62026df3c8a7e3ee0a6d405016ec87a081e8&scene=126&sessionid=1681312436#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544176&idx=1&sn=aa8c96a84f136c572d19348879c032a1&chksm=c0b4f706f7c37e1077e70d5a801931ff9745260e62026df3c8a7e3ee0a6d405016ec87a081e8&scene=126&sessionid=1681312436#rd)

　　位于美国的全球互联网治理联盟日前通过官网发布，联盟委员会成员选举完成，20名委员中国2人入选。中国国家互联网信息办公室主任鲁炜代表中国政府，当选全球互联网治理联盟委员会成员，也是亚洲和大洋洲地区唯一的政府官员代表。阿里巴巴董事局主席马云作为亚洲和大洋洲地区唯一的私营部门代表，也当选联盟委员会成员。

  

　　全球互联网治理联盟经过投票选举，从来自全球的46位提名人选中选出了20名委员会成员，主要负责议决联盟重大事项，推动ICANN国际化和全球网络空间治理。

  

　　本次入选的成员，涵盖五大区域、四大领域。五大区域为亚太、非洲、欧洲、北美、南美；四大领域为专家学者、技术社区及基金会，民间组织，政府部门，私营部门。其中，政府部门代表5名，除鲁炜外，还包括欧盟副主席安西普、美国商务部部长普里茨克、埃及通讯信息部部长希尔米、阿根廷司法部个人数据保护官阿隆卡。

  

　　全球互联网治理联盟由ICANN、巴西互联网指导委员会和世界经济论坛联合发起。其中，ICANN是负责根服务器、域名、IP地址等全球互联网基础资源分配管理的国际机构，全称为互联网名称与数字地址分配机构。

  

　　根据全球互联网治理联盟公布的时间表，联盟秘书处将于本月组建专门工作组，负责撰写联盟章程。该章程经征集公众评议后，最终提交委员会审议通过。
