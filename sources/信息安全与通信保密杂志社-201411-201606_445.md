# Twitter面临封杀威胁？！土耳其真的怒了！

　　土耳其官员上周威胁称，如果Twitter不封杀一份左翼报纸的帐号，那么将对Twitter进行封杀。该报纸的帐号此前发布的文件显示，土耳其军方去年1月袭击了前往叙利亚的土耳其情报局卡车。土耳其政府于上周四对Twitter提出了这一要求。此前一天，土耳其南部Adana省地方法院发出命令，禁止对相关调查进行报道，并表示由于法律文件的传播，有可能对Twitter进行全面封杀。

  

　　法庭认为，这些信息的公布将不利于国家安全，同时干扰了正在进行的调查。土耳其政府官员明确否认，当时土耳其情报局的卡车为叙利亚境内的极端分子运输武器。他们表示，当时卡车内运输的是提供给叙利亚境内少数民族土库曼人的人道主义物资。

  

　　土耳其媒体报道称，上周三，Twitter、Facebook和Google+等社交媒体已经接受法庭的命令，从相关帐户中删除了这些存在争议的内容，以避免遭到关闭。

  

　　不过，左翼报纸《BirGun》及另一些Twitter用户仍在挑战这一命令，继续发布新的有关信息。Twitter拒绝封杀《BirGun》的帐号，但屏蔽了该帐号发布的某些消息。这些消息中公布了一些泄露的文件。文件显示，军方承认，当时的卡车运输了武器和爆炸物，而这些武器将被提供给“基地”组织。

  

　　Twitter发言人武·韦克斯勒(Wu Wexler)表示：“在该帐号的近6万条Twitter消息中，Twitter禁止一小部分内容在土耳其国内被阅读。这些消息涉及了与法庭命令有关的国家安全问题。我们仍在采取尽职的方式，保护用户的权利，确保土耳其的数百万用户仍可以使用Twitter。”

  

　　去年3月，由于据称有账号泄露了政府在叙利亚的秘密军事行动计划，Twitter和YouTube在土耳其被封杀。Twitter在两周后被解封，而YouTube的解封则等待了两个月时间。
