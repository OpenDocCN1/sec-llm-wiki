# 用虚假杀毒软件诈骗！还有多少人会上当？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544153&idx=3&sn=1d468c8120698a01a6dd7cc4d8fd5a8a&chksm=c0b4f72ff7c37e395aa413223f6658dd7ef2d07ea7e09af52a2460d5ade48f61812826ed91d1&scene=126&sessionid=1681312440#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544153&idx=3&sn=1d468c8120698a01a6dd7cc4d8fd5a8a&chksm=c0b4f72ff7c37e395aa413223f6658dd7ef2d07ea7e09af52a2460d5ade48f61812826ed91d1&scene=126&sessionid=1681312440#rd)

　　你可能多次听说过这样的事情：对科技不太熟悉的老人在家里上网的时候，误点了诈骗链接，向一家所谓的互联网持术支持公司支付了一笔钱，用来删除电脑上根本不存在的病毒。这是最古老的诈骗技巧，但却仍然十分有效。

　　在美国同样如此，美国监管机构联邦贸易委员会（FTC）最近关闭了两个大型的远程诈骗业务，诱导互联网用户购买虚假的杀毒软件和技术支持，据悉受害人（主要是老人）已经累计被诈骗1.2亿美元。

　　这两个诈骗业务至少在2012年就已开始运转，第一个出售的是PC Cleaner软件，另一个以不同的名字运营，包括Boost Software Inc、OMG Tech Help，以及非常具有讽刺效果的OMG Total Protection（中文意即“老天哪，全面防护”）。

　　FTC表示，他们的诈骗业务都始于一位不幸的用户（可能通过网站上的广告）下载了一个虚假软件的免费测试版，这个测试版当然会通过大量的恶意软件和病毒对用户电脑进行全面扫描，然后诱导用户购买29美元或49美元的完全版。然后再诱导用户拨打免费电话来“激活”软件，使得骗子有机会骗取更多的资金。

　　这些诈骗分子所做的，就是要求用户电脑接受远程操控，然后启动大多数用户根本不使用的程序，例如Windows Event Viewer等。他们告诉受害者说，这些程序的存在意味着电脑已经被病毒感染，唯一的杀毒方法就是购买更多的软件和技术支持，价格有时候高达500美元。

　　FTC发现这些所谓的技术支持公司会扫描完全干净的电脑，然后“技术代表”声称这些电脑已被病毒侵袭。搜集到足够的证据之后，FTC搜查了他们在佛罗里达州的办公室，冻结了嫌疑人的所有资产，并对他们提起了诉讼。所以对于美国用户而言，在互联网上点击“如何让你的电脑更快”之类的链接之前，把链接发送给FTC，这样他们可以详细了解情况。
