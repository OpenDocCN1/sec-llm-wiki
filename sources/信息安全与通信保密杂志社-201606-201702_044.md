# 【高端访谈】与北京江南天安科技有限公司总经理邓小四谈商密发展

**邓小四**

北京江南天安科技有限公司总经理。国内较早期从事信息安全领域服务的从业人员之一，扎根信息安全领域二十余年，有着深厚的行业背景与敏锐的业务前瞻眼光，为信息安全行业培养过大量的专业人才。由他组织开发的研究成果多次获得国家级、省部级科技进步奖等相关荣誉，组织并参与编写了多部信息安全专业领域书籍及文件汇编，如《信息安全策略编制指南》、《中国信息安全手册-政策法规标准篇（2016版）》、《中国信息安全手册-国内外组织机构纵横》、以及NIST系列丛书等，将信息安全行业关键技术与政策法规进行了汇总与解读，为信息安全工作者提供了大量的国内外先进技术与管理手段的参考依据。

  

因为彼此的忙碌，约了江南天安公司总经理邓小四的采访很久，终于在元旦佳节来临之际的深冬时节成行。清晨，我们到达江南天安公司时，邓总已早早地等候在办公室，热情地接待了我们，让刚刚受完寒风洗礼的我们瞬间感觉暖意满满。落座下来，一如我们的印象，务实的邓总没有过多的寒暄，开始了我们的交流。  

  

**技术发展的前瞻者**

首先，我们从邓小四的从业经历谈起。在交流中我们获悉，这个毕业于北京邮电学院的老兵，八十年代末涉足计算机网络，九十年代初进入信息安全行业，是我国改革开放后最早一批从事信息安全领域工作的人员之一。九十年代就开始投身创业，正式组建江南天安公司，向国有能源企业、金融行业、电力行业、国家部委、企事业单位等领域推广信息安全服务、商用密码产品与技术服务。

从邓小四的从业经历中我们发现，之所以对信息安全与加密行业情有独钟，源自于他过去的工作经历。他常说，我们做企业，一方面要赚钱，要对得起客户和员工，另一方面，还要有社会责任感。早在九十年代，邓小四就预见，网络信息安全、加密领域，随着信息技术和互联网的应用和迅速发展，信息安全一定会影响到方方面面，一定会成为未来的方向。尤其是近几年，信息安全已经影响到社会生活的各个角落，信息风险无处不在，安全需求无处不在，特别是，党和国家对网络信息安全高度重视，更加坚定了对信息安全与加密行业的信念。

邓小四介绍，自建立江南天安公司以来，甚至在更早之前的工作经历中，自己一直没离开过密码技术的应用服务。以前主要是做服务多一些，而作为自主商用密码产品的研发生产，还是最近四五年的事，起步不算早，但通过招揽一大批国内顶尖的密码专业技术人才，再加上坚持不懈的大量研发投入，不断创新，使得自有商用密码产品和技术服务快速成长，很快得到市场认可，加入到屈指可数的一线厂商行列，在部分领域成为国内领跑者。

邓小四说，我们的密码产品和技术应用，一定要做自主研发、自主可控，并且要保持技术和市场领先。经过五年左右几千万的研发投入，开始实现了预期的目标，形成了国内领先的系列产品线和丰富的密码技术应用方案。可以说，商用密码技术及应用的门槛高、应用更加专业、需求巨大。正是看到这一点，邓小四在这些年将商用密码产品研发与技术服务放在公司发展战略的重要位置，每年不遗余力地投入人力、财力、物力，先后招揽了一批国内顶级密码专家，不断扩充研发队伍、技术服务队伍，建立了研发中心、生产中心，在产品测评、专利申请、项目推广实施的过程中，不断完善自身管理体系、技术体系和人才队伍建设，带领公司稳健发展。

邓小四说，没有绝对的安全，只有相对的安全，当常规以网络安全为主的信息安全手段失效时，加密是最后一道防线。在谈及商用密码的应用时，邓小四表示，商用密码产品与技术的应用，是在我国自主可控的加密算法基础上施行的，与国际通用加密算法相比，既有理论上的一致性，又有实用上的差异。我国为加强对国家安全、关键基础设施安全、涉密信息系统安全的保护，商用密码产品与技术的推广应用势在必行。邓小四介绍，江南天安在商用密码产品和技术应用方面，主要体现在金融数据加密、金融保证、云加密、签名验证、PKI应用、金融IC卡密钥管理、加密卡、国密合规应用等领域，面向的客户主要有金融行业客户、云服务商、能源行业客户、电力行业客户、政府单位、军队、涉密信息系统客户等。邓小四还认为，在密码应用普及的进程中，仍需要国家从政策和合规的角度大力支持，才能更加有效地提升企业对国产密码推广的重视程度。自1999年国务院颁布《商用密码管理条例》以来，主管部门又相继施行了诸多行业标准、技术规范、管理办法等。以上这些从不同角度、不同层面明确了商用密码在科研、生产、销售、使用等方面的具体原则和措施，从而促进了密码技术更好地为信息化和信息安全服务，推动了我国商用密码事业的健康发展。2016年初，国家密码管理局新发布了两项行业标准，其中，江南天安参与了《GM/T 0045-2016 金融数据密码机技术规范》的起草工作。他坦言道，只有深入其中才能更加深刻地体会到建立健全相关法规标准的重要性和迫切性。邓小四还谈到，商用密码行业发展已经迎来历史最好时期。2009年前后，国产密码算法在金融领域的应用获得重大突破，在国家有关部门的领导下，江南天安联合产业链相关企业和用户，把国产密码算法成功应用于传统银行业务，例如国密改造项目、PBOC应用项目，在金融行业的应用上取得了示范效果。从那以后，国密算法和国产商用密码技术在各个领域的应用获得了突飞猛进的发展，按照相关的规划，到2020年以前，十几个重点行业的核心应用系统都要完成国密改造，这对商用密码相关企业是非常难得的历史机遇。2015年，通过与阿里云等云服务商建立战略合作伙伴关系，又将云密码技术应用推上一个新台阶，成为国内首家云加密产品服务商。此外，还和其它众多企业建立了合作伙伴关系，优势互补，为我国的信息安全和自主可控事业做出贡献。

由此可知，唯有前瞻的意识、积极的态度、务实的行动，才能有效地促进技术的长远发展。

  

**企业管理的布道者**

一个优秀团队的建立离不开领导者精益求精的管理。不同的企业有不同的成长背景、发展基础和业务特点，企业经营管理，一方面需要学习借鉴国内外优秀企业的理论方法，另一方面，需因地制宜，不能照搬。如何把企业搞好，让企业发展壮大、让员工幸福、服务好客户、给社会回报，是邓小四在一直思考和探索的问题。他常说，企业经营管理，首先是战略和方向，其次是业务能力，第三是制度管理，最后是人才培养。归根到底，核心还是人。

提及企业战略，邓小四将公司战略定位为打造中国领先的密码技术与信息安全综合服务商，向能源、金融、政府、电信、军队等行业大客户和企业级客户提供信息安全产品、服务和解决方案。这些年来，公司的发展始终围绕这个战略方向搞经营。

而业务能力的培养和积累，一直是邓小四特别重视的另一个方面。江南天安在邓小四的大力主导下，在密码产品软硬件研发和技术服务、安全集成、安全咨询、网络攻防、风险评估、应用安全、安全运维、课题标准研究、安全合规服务、安全培训教育等业务能力建设上投入大量人力物力，保证了向客户提供高质量的产品应用和服务。

为向客户提供更好的服务，邓小四向公司反复强调了解和学习客户业务的重要性。信息安全，不仅仅是一个单纯的技术，只有和用户的业务结合起来，才能为客户提供更好的服务。为此，领导公司员工不断学习能源客户、金融客户等业务，这也是公司之所以受到客户肯定的重要因素。

为保证业务的规范性、质量和业务连续性，邓小四特别注重公司业务体系的建设，先后建立了 ISO9001 质量体系、ISO207001 信息安全管理体系、ISO20000运维服务体系以及各种技术类别的信息安全服务体系，并通过申请业务资质和参加行业协会，不断提升公司业务能力。

做好企业经营管理，离不开公司制度的建设。邓小四强调，制度的好与坏、多与少、适用不适用，能不能激发员工活力，能不能更好推动企业经营发展，是一个永恒的话题。在公司经历了由小变大的过程中，邓小四作为总经理，深切感受到制度的重要性，在激励机制上，鼓励有能力的人、勤奋肯干的人、诚实守信的人。这些年，邓小四带领公司不遗余力的抓制度建设，聘请咨询公司、委派管理人员学习，因地制宜，在完善制度建设上下了很大功夫，也取得了越来越好的效果。

最后，也是最重要的，就是人才队伍建设。邓小四特别重视人才，不拘一格。无论学历、资历、职位高低，只要有能力，公司都会为其创造施展才华的机会和空间。公司既有顶尖的业务带头人，也有一排朝气蓬勃的年轻队伍。邓小四说，招揽人才、培养人才、用好人才，让员工和企业共同成长和发展，为客户创造最大价值，这是公司想要追求的目标。

当然，在壮大自身队伍磨炼团队实力的同时，邓小四也不忘助力行业的发展。近年来由于信息泄露、网络诈骗、黑客攻击事件层出不穷，对公民个人安全、企业安全、政府事业单位安全、军队安全、国家关键基础设施安全，以至于危害到国家安全等，造成越来越多、越来越大的危害。邓小四根据对时局的分析，2014年决策组建了一支具有国家级水平的猎户攻防实验室，从引进人才，到传帮带，到行业交流和友谊比赛，都做了大量工作。迄今，已建立起一支具有几十人高水平的网络攻防技术队伍，专门从事漏洞挖掘、渗透测试、攻防实训，并向国家部门提供网络安全保卫服务，为一些国家部委、商业银行、大型企业、电商等提供了优质服务，检查发现了大量网络风险和攻击事件，为客户发现、处理和避免损失作出了重要贡献，得到了用户的高度赞扬，被媒体评为国内 Top 10 攻防实验室。在国内举办的网络攻防大赛上，猎户攻防实验室多次名列前茅。此外，猎户攻防实验室每年参与国家重大国事保障工作，近年，在继抗战胜利70周年之后，再次全程参与G20峰会的网络安全保卫工作，为国家重大国事安全保障作出了重要贡献，受到了国家部委的表彰。

猎户攻防实验室的组建，除了助力了行业的发展，同时也坚定了大家对这份事业的信念。在与猎户攻防实验室项目组人员交流时，他们也是感触颇深，还特意跟我们分享了攻防实例：在一个金融行业客户服务的项目中，在得到用户授权委托后，攻防实验室的技术专家做了一次模拟攻击（渗透测试），轻易获取了其单位内大批员工的系统账号以及相关的敏感信息，也包括其最高领导的账号密码和数据信息，当攻防人员向其展示结果时，用户领导大为震惊，以前认为很安全的系统和数据信息，原来如此不堪一击，如果万一真有黑客攻击，后果不堪设想。按照攻防人员的建议，修复了漏洞，采取措施加固了系统，安全性大大提升，得到用户的高度赞扬。

他们还感慨道：“攻与防，是一对矛盾体，预防、检查、补救、违规惩戒，都是必不可少的。我们感到，以当前网络安全的形势，大部分用户在安全意识、安全措施、安全制度、安全人才储备上，都或多或少有这样那样的问题，当我们为客户解决了安全隐患，帮助他们的业务更加安全可靠地运行时，特别是在得到用户认可时，我们也有一份成就感，也感到非常光荣。”

一个优秀的企业家就是如此，建立精英团队、培养优质人才、研发尖端技术，不仅肩负企业使命，更心系行业发展以及国家安全。

  

  

行业文化的传承者

采访期间，我们留意到邓小四的书架上摆放着多部信息安全专业领域的书籍及文件汇编，如《信息安全策略编制指南》、《中国信息安全手册-政策法规标准篇（2016版）》、《中国信息安全手册-国内外组织机构纵横》、以及NIST系列丛书等。经邓小四的介绍，我们才知道，这些书籍及文件汇编都是他自己组织并参与编写的。那一刻，一股敬意油然而生。

在谈及编写书籍的初衷时，邓小四谈到，早在2009年就注意到美国有一部专著叫做《Information Security Policies Made Easy》（信息安全策略编制指南），当时是第11版，在国际上影响很大，而这方面的研究，在国内却是一个空白。邓小四深感信息安全不仅仅是一个技术问题，也不单是管理问题，还需要从策略高度上进行策划。国内信息安全行业需要弥补这一空白，无论是理论研究还是实际应用，迫切需要在信息安全目标制定、宏观策略和具体策略上有一个明确的指导。之后，邓小四安排在公司内部做了翻译，作为内部参考资料，并应用到对客户的服务上，取得了良好效果。

邓小四介绍，他在2012年参加美国RSA大会期间，专门会见了《信息安全策略编制指南》作者 CHARLES CRESSON WOOD（查尔斯·克雷森·伍德）， 双方相谈甚欢，得知伍德先生将在当年出版最新第12版时，邓小四表达了想要引进中国正式出版的意愿，双方达成了共识。但因涉及到版权和国内出版发行的政策规定，公司自己没有出版权，所以最终选择了与出版社合作。

邓小四说，国内信息安全行业，包括政府机构、企事业单位、甚至军队等，对信息安全的应用主要还是围绕着技术、管理、人这几条线，但由于技术的发展、产品的更换、管理的变化、人员的更迭，导致信息安全的应用不稳定，重复建设的现象还是比较严重，这主要还是缺乏了信息安全策略所致，普遍还是缺乏策略层面的规划。邓小四认为，《信息安全策略编制指南》这部专著工具书，对我国信息安全行业和用户来讲，一定是非常有用的，也希望这一成果能够被更多的从业者和用户了解、认知和应用。

在谈起编译书籍的感受及经历时，邓小四感触颇深，他介绍到，《信息安全策略编制指南》这部专著，也是一部信息安全策略大全性质的工具书，用于指导使用者（政府部门、企事业单位等）编制自己的信息安全策略的参考文献。翻译工作经历了一年多，近2000条策略、50个应用案例，拿来就能用，是很好的工具书，公司引进版权、翻译审校、出版发行等投入了几十万元费用。由于专业性很强，请行业专家专门进行了反复审校。对于书名Information Security Policies Made Easy 的翻译，到底翻译成什么才准确、恰当，还专门请教了安标委专家、北大权威教授、行业一些专家，最后定名为《信息安全策略编制指南》，最终在2014年1月份正式出版。出版后，推荐给一些研究机构和部分国家部委，非常受欢迎。从反馈的信息看，读过这部书的单位，包括国家部委、研究机构等，反响非常好。这部书几乎涵盖了信息安全策略的各个领域，目前，这部书的第12版仍然是最新版本。而在收益方面，邓小四告诉我们，翻译这部书，公司是赔钱赚吆喝，也是想借此为国家做点贡献。

由此可以看出一个企业家对一份事业的热爱与付出，以及对整个行业文化的坚守与传承。深植产业数十年，邓小四务实低调的作风赢得了产业各界的认可与尊重。
