# 党政部门云计算服务网络安全审查打造更加安全的移动云

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544401&idx=3&sn=a37dddf74ca933e69abe55b0c4e1a21f&chksm=c0b4f427f7c37d31edc5905058a5a383d367eb75c7425cffc2cb8c80f134f82ebc52920feee0&scene=126&sessionid=1681312389#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544401&idx=3&sn=a37dddf74ca933e69abe55b0c4e1a21f&chksm=c0b4f427f7c37d31edc5905058a5a383d367eb75c7425cffc2cb8c80f134f82ebc52920feee0&scene=126&sessionid=1681312389#rd)

当前，我国云计算产业蓬勃发展，已经进入快速发展和应用普及阶段。随着我国经济发展进入新常态，云计算在响应国家“互联网+”战略，落实“稳增长、调结构、惠民生”要求，以信息流带动技术流、资金流和人才流，激发产业创新，调整产业结构，转变经济发展方式等方面发挥了积极的作用。

   

![](../Images/24625cc6ca701b2bb2cf890c442e337a.png)  
  

> 然而，云计算快速发展的同时也面临着前所未有的挑战，其中最为突出的就是网络与信息安全问题，尤其是隐私问题、数据保护和虚拟化安全等已被公认为是决定云计算发展前景的关键因素。开展党政部门云计算服务网络安全审查（以下称“云审查”）正是为了解决云计算安全困境，提出云计算平台应遵循的安全标准，提升云服务商安全能力，从而促进云计算产业快速发展、保障政府安全放心使用云服务。  
> 
>     
> 
> 云审查促进云计算产业规模的快速发展。首先，云审查能够增强采用云计算服务的客户的安全信心，促使更多的客户迁移到云上，通过扩大云计算服务的整体需求来增加整个产业的市场规模。其次，云审查在安全领域带来的“高标准、严要求”会明显提升云服务商的安全能力，这种安全能力可以迅速转变为安全服务向客户提供，增加云计算市场的有效供给。再者，供需两旺的云计算产业市场定会带动云开发商加大投入去研发安全的信息系统和组件，提供更多的安全支撑服务，激发整个产业链上下游的协同发展。最后，云审查引领云计算产业健康可持续的发展方向。云审查助云服务商理清自身存在的安全问题，识别自身及客户尤其是党政部门的安全需求，明确应该达到的安全水平和程度，从而有序的开展安全工作；有助于提示并鼓励云计算服务客户在选择云计算服务时对于安全保障能力的偏向和侧重；使整个产业链拥有“强健体魄”，让产业具备和谐绿色的环境，从而保障云计算产业的可持续发展。
> 
>     
> 
> 云审查优化升级云计算产业格局。标准化的云审查会对所有的云服务商提出统一的要求，实施统一的审查，展现统一尺度的安全水平，因此包括云服务客户和云服务商在内的整个云计算产业链都能够及时了解彼此的安全状态。因此，重视安全的云服务商会逐渐赢得更多客户的青睐，而安全水平较差的云服务商则会不断降低在客户心目中的形象，从而形成以安全审查结果为评价标准的“优胜劣汰”发展趋势，并最终形成“重安全者兴、轻安全者衰”的产业新格局。
> 
>     
> 
> 云审查提升我国云计算产业的国际影响力。一是云审查在标准与执行层面发挥的作用，从安全的角度为我国成为网络强国打下了坚实基础。二是云审查帮助我国云计算服务企业在国际上树立更为安全可靠的正面形象，使国际市场能够更加容易接受和使用我国的云计算服务。三是云审查客观上使我国云计算产业的标准合规性大幅提高，更加容易融入国际标准，从而顺利开展与国际组织或企业的合作。
> 
>     
> 
> 总之，云审查既提供了一整套可遵循的安全标准，又提供了一项保障我国党政部门云计算安全发展的审核机制，既有完善的要求，又有可执行可落地的措施，能够对包括云服务客户、云服务商等在内的整个云计算产业链产生积极的影响，为我国云计算产业发展保驾护航。
> 
>     
> 
> 中国移动积极响应党政部门云计算服务网络安全审查，从2016年1月开始，经过全面、严格、细致的检查、测试、访谈等，移动云在供应链和系统开发、系统与通信保护、访问控制、配置管理、维护、应急响应、风险评估等方面已经加强和实施了多项安全管理和安全技术措施，消除或减低了相关安全风险，对于提升移动云安全保障能力，有极大的推动和促进作用。在接受审查的过程中，对于为党政部门提供云计算服务需要承担的安全责任和义务、应具备的安全服务能力等，中国移动有了更加深刻的认识，也更有信心为党政部门提供更加安全的一站式云计算服务。
