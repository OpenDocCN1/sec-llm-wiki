# 美国联邦政府如何应对网络安全人才短缺问题？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544395&idx=3&sn=761a0b3ccb1b59319144e2c2fd459c4d&chksm=c0b4f43df7c37d2b8496357b0d78522fb1b66154dec60a84c805e14c716910780ed01b8968e4&scene=126&sessionid=1681312391#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544395&idx=3&sn=761a0b3ccb1b59319144e2c2fd459c4d&chksm=c0b4f43df7c37d2b8496357b0d78522fb1b66154dec60a84c805e14c716910780ed01b8968e4&scene=126&sessionid=1681312391#rd)

聘用合适的网络安全人才对于任何一家企业来说都是一件有难度的事情。特别是对于美国联邦政府来说，人才短缺问题正在变得日益严重。  

  

![](../Images/fbfc3f52c6911e250822c53c78092ba9.png)  
  

赛门铁克曾预测2019年全球网络安全行业的专业人才需求将达到600万人，同时还将有150万的人才短缺。Cisco也在近期发布的报告中表示当前全球网络安全行业人才缺口大约为100万。这些空缺的职位有很多都是属于公共部门的，联邦首席信息官(CIO)Tony Scott表示联邦政府当前需要填补的网络安全职位超过1万个。这些统计数据充分反映了联邦政府在网络安全人员方面面临的严峻挑战。而为了解决该问题，联邦官员们正在采取多项措施来应对人才短缺问题。

  

**新网络安全人员招聘战略**

  

时至今日，奥巴马仍希望能尽快任命首任联邦政府首席信息安全官(Federal Chief Information Security Officer)。作为美国国家网络行动计划(Cybersecurity National Action Plan)的一部分，相关管理部门将会投入6200万美元用于应对网络安全人才短缺问题。在人员招聘方面，联邦政府也加大了力度，例如外语、生物学、人类文化学等其他专业的人才也会被纳入考量范围，只要他们同时具有网络安全方面的知识。其他的重要举措还包括奖学金、相关培训及债务减免等。

  

不过缺少训练有素的网络安全人才仅仅是问题的一部分。除了招聘和留住顶级的网络安全人才以外，联邦机构也必须通过使用新的或已有的安全技术来加强网络防御。

  

**自动化技术将缓解人才短缺问题**

  

在对抗黑客的时候，即使是拥有着大量网络安全人员的企业也会面临很大的挑战。联邦政府需要利用智能安全技术(intelligent security)来检测并制止网络威胁，而且应用这些技术将会对缓解人才短缺问题大有裨益。

  

IT安全自动化(IT security automation) 将最终代替手动的方式来进行威胁检测和威胁防御。例如Blue Coat, Cisco Systems, FireEye, Palo Alto Networks, RSA Security and Tenable等网络安全厂商的安全产品和安全服务都应用了机器学习和行为分析功能，以便能加快对安全事件的检测、识别与修复速度。这些自动化功能能使联邦机构快速找到并终止网络攻击，在网络安全人员紧缺的情况下提高运作效率。

  

那些人手不足或者能力不足的部门需要尽可能的利用任何会对他们产生帮助的事物，所以解决方案中的安全情报(security intelligence)功能是非常有意义的。机器学习和行为分析技术不仅会比手动更快，而且更加准确。关键还能把网络安全专家们从大量的安全威胁和警报中解放出来，使他们可以将他们的技术运用在应对更加复杂的安全问题上。

  

毫无疑问自动化将成为网络安全防御中的重要的组成部分。包含自动化功能的端点安全(endpoint security)产品将会有效阻止网络威胁并减少恶意软件的感染几率，各个联邦部门均可以从中受益。
