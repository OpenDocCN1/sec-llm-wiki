# 将改变人类生活的10大新兴技术，你了解几个？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544357&idx=6&sn=55480e6a6adcfebfcf0a881ca4526e4d&chksm=c0b4f453f7c37d459028191bd3f12b7dee35ac65c649b832ab55e58543b6c90a3eda3b4eff83&scene=126&sessionid=1681312404#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544357&idx=6&sn=55480e6a6adcfebfcf0a881ca4526e4d&chksm=c0b4f453f7c37d459028191bd3f12b7dee35ac65c649b832ab55e58543b6c90a3eda3b4eff83&scene=126&sessionid=1681312404#rd)

世界经济论坛(WEF)近日列出了将改变人类生活的10大新兴技术，其中包括能在人体内循环的纳米传感器、能为整个城镇供电的下一代电池，以及能追踪人类健康状况的人工智能(AI)等。

  

![](../Images/5fce968481503bd7b1f9caab1e0104f6.png)  

  

> WEF认为，这些新兴技术并非遥不可及，它们在不远的将来就会对我们的生活产生重要影响。负责编纂这10大新兴技术的WEF官员伯纳德·梅耶逊(Bernard Meyerson)称：“及时观察新兴技术对我们抢先了解科技发展动态至关重要，因为它们将极大地改变我们的世界。提前行动能让我们及时做好准备，迎接这些颠覆性科技的到来，并对它们进行研究和分析。”
> 
>   
> 
> 梅耶逊还称：“全球要团结起来，达成共识，以便充分利用这些新兴技术并从中受益。同时，也能尽量避免新技术所带来的风险。”
> 
>   
> 
> **以下就是WEF列出的2016年全球10大新兴技术：**
> 
>   
> 
> 1、纳米传感器和纳米物联网(IoNT)
> 
>   
> 
> WEF预计，2020年将有300亿台设备接入物联网(IoT)。届时。物联网将成为科技领域最令人兴奋的一个分支。同时，WEF在报告中还称，纳米传感器将被广泛应用到几乎所有事物中，如人体和家具中。
> 
>   
> 
> 2、下一代电池
> 
>   
> 
> WEF认为，通过使用钠、铝和锌为基本原料的电池，再辅以先进的能源存储解决方案，这种电池将能让微型电网(mini-grids)更好地为整个村庄或小城镇提供清洁能源。
> 
>   
> 
> 3、区块链技术(Blockchain)
> 
>   
> 
> 区块链是数字货币比特币的底层技术，它可以追踪任何有价值事物的交易，包括股票、债券或其他金融证券。WEF认为，“它可能从根本上改变市场和政府的工作方式”。仅在去年，这项技术就获得了10亿美元的投资。
> 
>   
> 
> 4、2D材料
> 
>   
> 
> 虽然3D打印已经受到极大关注，但WEF认为，单原子层材料，如石墨烯等，将被广泛应用于空气净化器、水过滤器、可穿戴设备和电池等产品中。
> 
>   
> 
> 5、自动驾驶汽车
> 
>   
> 
> 在谷歌的引领下，自动驾驶汽车吸引了业内的极大兴趣。相信在不远的将来，自动驾驶汽车将为我们带来极大方便。WEF认为，自动驾驶汽车能挽救生命(安全)、遏制污染和改善经济等。
> 
>   
> 
> 6、器官芯片
> 
>   
> 
> WEF指出，研究人员已经研发出“U盘大小”的人体器官模型，这项技术有望给医学研究和药品发现带来革命。这种微型器官能以前所未有的方式来研究生物学行为。
> 
>   
> 
> 7、钙钛矿太阳能电池
> 
>   
> 
> 钙钛矿(Perovskite)材料是具有特殊晶体结构的矿物和陶瓷材料。与传统的硅太阳能电池相比，钙钛矿材料电池具有诸多优势。WEF称，这些材料还很容易生产，发电效率更高。对于想生产可再生清洁能源的企业而言，这些优势极具吸引力。
> 
>   
> 
> 8、人工智能生态系统
> 
>   
> 
> 海量的数据，加上最新的算法，这意味着智能数字助手(smart digital assistants)的发展将帮助用户追踪其财物和健康等信息。
> 
>   
> 
> 9、光遗传学
> 
>   
> 
> 光遗传学是指利用光来控制活组织中的细胞。WEF称，科学家一直在使用光和颜色与大脑神经元进行互动。但随着技术的发现，科学家如今已经能够将这种光深入到活的大脑组织中，这可能为治疗大脑障碍疾病带来革命。
> 
>   
> 
> 10、系统代谢工程
> 
>   
> 
> 随着环境问题的日益突出，以及化石燃料资源有限，科学家们也一直在研究如何通过可再生资源(如植物)打造全新的燃料和化学物质。WEF称，通过使用植物，生产燃料产品将变得很容易，而且成本也更低。
