# 这些App“太流氓”：强制安装捆绑应用 窃取信息偷偷吸费

未经允许自动下载，私自获取通话记录和联系人，被他人远程控制……昨日，广东省公安厅再曝光了10款安全问题突出的App，经检测，这些App存在窃取用户信息、破坏用户数据、影响移动终端运行、恶意推送广告等突出安全问题。此外，在前期曝光的30款问题App中，有2款App仍在平台上。

  

![](../Images/08807be892fa1e9ec103a58b47444496.png)  

  

> 据了解，2016年4月以来，广东省公安机关对外曝光了30款存在传播违法有害信息、破坏用户数据、窃取用户信息等突出安全问题的App，提醒广大网民加强防范。大多数移动应用平台以此为契机，排查整改隐患，清理违法有害App。然而，前期曝光的30款存在安全问题的App中，植物大战僵尸2大全攻略（v3.0，第一应用）、百变美女锁屏十二星座（v2.5.2，好卓市场）2款App仍在平台上。
> 
>   
> 
> 2016年5月份，广东省公安机关继续大力开展移动互联网应用安全检测工作，发现“非主流唯美爱主题壁纸锁屏”、“金秀贤都叫兽锁屏”等10款App，存在窃取用户信息、破坏用户数据、影响移动终端运行、恶意推送广告等突出安全问题。
> 
>   
> 
> 此次曝光的10款App中，锁屏和桌面主题软件占了一半，还有电话软件1款，游戏软件1款，驾考软件1款等。
> 
>   
> 
> 锁屏和桌面主题软件所涉及的问题是弹出广告窗，在开启数据流量情况下，用户点击广告，未弹出询问下载界面，就直接下载对应应用，并且无法暂停或取消下载。此外，还有1款名为“AndroidTrace”的App，会擅自连接网络，拨打电话、发送短信，甚至导致你的手机被远程控制。
> 
>   
> 
> 下一步，广东省公安机关将结合“安网2016”网络安全专项治理行动，大力打击利用App开展的破坏用户数据、窃取用户信息、恶意吸费等违法犯罪活动，进一步净化广东省移动互联网环境。
> 
>   
> 
> **5月安全问题突出的10款App**
> 
>   
> 
> **1.非主流唯美爱主题壁纸锁屏**
> 
>   
> 
> 这款App未经允许推送无法关闭的弹出式广告或者无法取消的系统通知栏广告，未经允许擅自下载其他应用或捆绑安装其他应用。

>

> 
>

> 擅自连接网络、拨打电话、发送信息，可导致智能终端被他人远程控制。

> 
>

> 
>   
> 
> **5.金秀贤都叫兽锁屏**
> 
>   
> 
> **6.Pure Grid calendar widget**
> 
>   
> 
> **7.泡芙小姐主题动态壁纸**
> 
>   
> 
> **8.萌神EXO主题动态壁纸桌面**
> 
> **9.情侣主题桌面锁屏**
