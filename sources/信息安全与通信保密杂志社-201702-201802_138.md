# 漏洞奖励计划帮助五角大楼收集到来自全球2,837个有效漏洞

还记得2016年的入侵五角大楼计划吗?  

 

![](../Images/85cbe59e37a8de5b4d19cb984569c293.png)

  

这个漏洞奖励计划现在看来已经获得了一定的成效，目前来自全球 50 多个国家的 650 名白帽子向美国政府部门提交了2837个有效漏洞。黑客提交漏洞后也从他们的付出中得到了相应的回报，共计获得了超过 300,000美元的奖金。

  

有接近500个漏洞涉及的是国防部40个组件部分，其中100个漏洞都是critical以及high界别的。主要的漏洞问题在于远程代码执行、SQL 注入、验证机制绕过。
