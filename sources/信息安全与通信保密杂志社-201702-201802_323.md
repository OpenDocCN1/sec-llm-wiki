# 工信部要求：国产安卓系统统一信息推送标准

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544527&idx=1&sn=3fb31affba7ac2b8236d0219d6e05848&chksm=c0b4f4b9f7c37daf057ce56311d7532b75a3cd184f8a5653ac97b3671622469bf9937ba99272&scene=126&sessionid=1681312365#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544527&idx=1&sn=3fb31affba7ac2b8236d0219d6e05848&chksm=c0b4f4b9f7c37daf057ce56311d7532b75a3cd184f8a5653ac97b3671622469bf9937ba99272&scene=126&sessionid=1681312365#rd)

安卓系统在国内可谓是野蛮生长，系统内的推送体验也可谓是五花八门，不一而足。现在，这个乱象有望得到终结，就好比如乱糟糟的幼儿园里，终于来了位严格的老师。近日，工信部旗下的泰尔终端实验室发布消息称，目前正联合国内主要手机厂商和第三方推送平台，共同制定安卓统一推送服务技术标准。此举将让用户、手机厂商和软件开发者获利，对于Android阵营来说，也会增强用户体验，和硬件达到更好的使用平衡。

这个标准的参与方几乎涵盖了目前国产手机的巨头，以及第三方的推送服务方。包括华为、OPPO、vivo、小米、三星、魅族、金立、努比亚、谷歌 (微博)、百度、阿里巴巴、腾讯、个推、极光等。

泰尔终端实验室的与企业共同制定统一推送服务称之为UPS（Unified Push Service），目前取得了阶段性成果。具体来说，未来将由终端厂商提供系统级推送服务（类似APNS的唯一推送通道），确保App的推送消息接收，同时相应的不再允许各App在后台保留常连接，降低终端能耗、提升用户体验。

同时，对于滥用推送消息也将进行限制，对于用户点击率很低或用户消息屏蔽较多的App，可能采取包括限制推送条数、拉入黑名单等惩罚性措施。引导开发者注重用户体验，实现净化安卓生态的目标。

统一推送对于开发者的一个福音是，由于推送API的统一，未来各终端厂商将提供系统级API实现推送功能 (即App无需嵌入各通道SDK)。考虑到实际情况，为了兼容已有机型，手机端还是会提供一个简单的SDK，判断手机是否支持统一推送。若支持则可以直接调用ROM API，否则按照当前已有方式进行推送 (为了适配已有机型还需要保留推送SDK)。随着手机的自然更替，未来支持统一推送的终端数目会不断更加，从而逐步实现统一推送的平滑演进。

泰尔实验室称，谷歌专家对于国内厂商的态度感到“兴奋”，认为统一推送对于中国安卓产业的发展将起到积极的推动作用，表示将持续关注相关进展。另外，提供第三方推送服务的厂商也要尽快开始行动起来，以适应新的游戏规则。
