# 【网安智库】城市“智慧” 从安全开始

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544504&idx=1&sn=6a3fb9cb2525d520b03435b45d03fdeb&chksm=c0b4f4cef7c37dd8ba678acc42d5e27f05161e55721c31e1a700486adcc8da53470dc80020e1&scene=126&sessionid=1681312369#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544504&idx=1&sn=6a3fb9cb2525d520b03435b45d03fdeb&chksm=c0b4f4cef7c37dd8ba678acc42d5e27f05161e55721c31e1a700486adcc8da53470dc80020e1&scene=126&sessionid=1681312369#rd)

> 随着物联网、云计算、大数据、新一代移动宽带网络、下一代互联网等新一代信息技术的迅猛发展，城市信息化发展向着更高的智慧化阶段发展，世界主要发达国家已纷纷启动智慧城市战略。近年来，我国智慧城市建设也取得了积极进展，但也暴露出网络安全隐患和风险突出等问题，为了确保智慧城市网络安全长效化，我国正在积极推进智慧城市相关标准和智慧城市安全标准的研究和制定、完善智慧城市安全保障体系、突破智慧城市安全关键技术。十三五期间，我国智慧城市的投资总规模将逾5000 亿元，智慧城市安全产业也将处于快速发展阶段，智慧城市安全厂商正在抓紧布局。

![](../Images/6326cf581d02c339ba97d9e2cdd8247a.png)

  

![](../Images/575513ae1ec6461ccbff01cc34fc0344.png)**智慧城市的发展**![](../Images/575513ae1ec6461ccbff01cc34fc0344.png)

  

1998 年，美国副总统戈尔提出了“数字地球”的概念，引起了美国和全球的关注，“数字城市”概念逐步在理论到实践中被定义为以城市的数字化和网络化为重点的城市信息化过程。智慧城市的概念是在数字城市基础上发展和延伸的，随着物联网、云计算、大数据、新一代移动宽带网络、下一代互联网等新一代信息技术的迅猛发展，城市信息化发展向着更高的智慧化阶段发展，世界主要发达国家已纷纷启动智慧城市战略，在核心城市探索智慧城市建设。

为探索智慧城市建设、运行、管理、服务和发展的科学方式，住房城乡建设部办公厅印发《关于开展国家智慧城市试点工作的通知》（建办科\[2012\]42 号）。作为今后一个时期指导我国全国城镇化健康发展，中共中央、国务院印发了《国家新型城镇化规划（2014—2020 年）》（中发\[2014\]4 号文件），明确我国未来城镇化的发展路径、主要目标和战略任务，并提出推动新型城市建设的重点之一要推进智慧城市建设，要统筹城市发展的物质资源、信息资源和智力资源利用，推动物联网、云计算、大数据等新一代信息技术创新应用，实现与城市经济社会发展深度融合。

为确保智慧城市建设健康有序推进，国家发改委、工信部、科技部、公安部、财政部、国土部、住建部、交通部八部委又印发《关于促进智慧城市健康发展的指导意见》（发改高技\[2014\]1770 号文件），该指导意见指出智慧城市是运用物联网、云计算、大数据、空间地理信息集成等新一代信息技术，促进城市规划、建设、管理和服务智慧化的新理念和新模式，建设智慧城市，对加快工业化、信息化、城镇化、农业现代化融合，提升城市可持续发展能力具有重要意义。截止至2016 年6 月，我国共有约600 个城市提出或在建智慧城市，其中，住房和城乡建设部、科技部等部门在全国推进了约300 个左右智慧城市试点工作，我国智慧城市建设已进入快速增长的阶段。

![](../Images/575513ae1ec6461ccbff01cc34fc0344.png)****智慧城市安全面临的安全风险与威胁****![](../Images/575513ae1ec6461ccbff01cc34fc0344.png)

  

近年来，我国智慧城市建设取得了积极进展，但随着网络和信息技术的迅速发展，庞大用户数量的增加，网络规模的迅速扩大，智慧城市也暴露出网络安全隐患和安全风险：

1）智慧城市感知和延伸层安全风险与威胁

2）智慧城市网络通信层安全风险与威胁

3）智慧城市计算存储和数据服务层安全风险与威胁

4）智慧城市应用层安全风险与威胁

5）智慧城市管理及运营风险和威胁

  

**![](../Images/575513ae1ec6461ccbff01cc34fc0344.png)****我国智慧城市安全行业趋势分析****![](../Images/575513ae1ec6461ccbff01cc34fc0344.png)**

**1）智慧城市标准体系不断完善**

2012 年以来，智慧城市成为国际和国内城市化中的热点，国际电工委员会（IEC）、国际标准化组织（ISO）、国际电信联盟（ITU）、电气和电子工程师协会（IEEE）、欧洲标准化委员会—欧洲电工标准化委员会（CEN-CENELEC）和欧洲电信标准协会（ETSI）多个标准化组织已从不同层次启动了智慧城市标准化工作。2016年国际电工委员（IEC）还发起会议，组织世界领先标准组织联合起来支持智慧城市，解决城市系统的互连互通。

**2）智慧城市安全保障体系逐步建立**

智慧城市安全范围涉及了国家安全、个人敏感信息安全、关键基础设施安全、公共服务安全、社会安全管理以及跨部门、跨组织的信息融合和共享安全等方面。构建智慧城市安全体系的目的是服务于城市经济发展与转型，保证国家、企业、研究机构及个人的信息资产安全、保障城市信息资源安全和城市信息系统与关键信息基础设施的安全运行，使城市的基础网络和要害信息系统安全可控，重要信息资源安全得到切实保障，居民、企业和政府的信息得到有效保护。

**3）智慧城市安全关键技术已有突破**

智慧城市安全保障体系的不断完善和建立对智慧城市物联感知层、网络通信层、计算存储和数据服务层、应用层提出了具体的安全技术要求。在智慧城市的应用中，物联网、大数据、云计算技术与网络信息技术融合在一起成为智慧城市发展的重要组成元素，相应地物联网安全、云安全技术、大数据安全等目前也成为智慧城市安全需解决的关键技术，目前这些技术也正在逐步得到解决和突破。

**4）智慧城市安全厂商正在抓紧布局**

十三五期间，我国智慧城市的投资总规模将逾5000 亿元。为贯彻落实国家推进智慧城市有关规划和指导意见，促进中国智慧城市产业及新型城镇化建设健康有序快速发展，实现智慧城市网络安全的可管、可控、可信，智慧城市安全产业正处于快速发展阶段，智慧城市安全产业链包括了安全相关硬件设备制造、网络通信、软件和信息服务、系统集成、运营服务等方面，涵盖的范围较广，是传统产业链的转型升级与新一代信息技术有机结合的产物，整个智慧城市安全产业链随着智慧城市建设过程不断地进行着产业的结构性调整和产业的淘汰更新。
