# 关于窃听的秘密 维基解密告诉你！

当地时间7日，维基解密网站公布数千页文件，揭露了美国中央情报局利用黑客工具攻击目标对象作为监控项目的一部分。维基解密表示，这些黑客工具已经失控。

  

**维基解密：中情局黑客工具入侵手机、电脑、智能电视等　窃听谈话**  

根据维基解密的声明，这份被称为“起始年”（Year zero） 的文件所包含的8761个文档， 均来自美国中央情报局内部系统，介绍了中情局秘密黑客项目的规模和方向。 

维基解密表示，目前中情局包括木马软件、恶意软件、病毒以及武器化的黑客工具已经失控，一些黑客工具在未授权的情况下在前美国政府黑客和承包商之间中散播，其中一人将这些资料提供给了维基解密。维基解密称，通过这些黑客工具，除了可以对苹果、安卓手机系统、Windows电脑操作系统等进行攻击外，还可以入侵智能电视，将智能电视伪装成关闭状态下对屋内谈话进行窃听，同时将窃听内容通过网络传回中情报局服务器。

该消息公布后，一些美国国会议员表示，国会应对此展开调查，以确定中情局是否对黑客工具失控、哪些人已经拥有了这些黑客工具，以及如何保护美国公民的隐私。

**维基解密：美驻法兰克福领事馆是中情局“黑客中心”**

“维基解密”网站曝光的中情局机密文件称，美国驻法兰克福领事馆是中情局在欧洲、中东和非洲执行黑客任务的“黑客”中心。

维基解密披露的文件显示，美国驻法兰克福领事馆是美国全球最大领事馆，馆内设有信息设施敏感区，只允许中情局和情报部门工作人员出入。美方从法兰克福对欧洲、中东和非洲的计算器发起进攻。另外，美方的一些监视工作也是在法兰克福进行的。

文件表明，领事馆内设有美国中情局一个秘密工作部门，该部门研发制作计算机病毒。中情局的黑客使用外交护照，并受到国务院的保护。此次披露的其中一份文件是为中情局派往法兰克福的黑客准备的行为细则。其中，建议中情局雇员在被问到在领事馆逗留目的时回答说是从事技术咨询。
