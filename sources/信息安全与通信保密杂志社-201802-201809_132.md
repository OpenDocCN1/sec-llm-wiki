# 【网安智库】《2018上半年互联网黑产研究报告》揭秘互联网“黑幕”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544766&idx=1&sn=6298d9e144fb029e993f694b64fd96e3&chksm=c0b4f5c8f7c37cde98bf3b53d565b6c5eca45fc3ac0dba034b308319aa9c6544b3f6328c3ee6&scene=126&sessionid=1681312320#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544766&idx=1&sn=6298d9e144fb029e993f694b64fd96e3&chksm=c0b4f5c8f7c37cde98bf3b53d565b6c5eca45fc3ac0dba034b308319aa9c6544b3f6328c3ee6&scene=126&sessionid=1681312320#rd)

2018年网络攻击不断升级，黑产渗透各个领域，针对日益严峻的网络安全形势，腾讯安全对2018上半年，互联网黑产攻击数据和发展现状进行了整理，发布了《2018上半年互联网黑产研究报告》。

  

报告盘点出黑产“私自扣费、恶意植入广告、虚假手机应用、强制自动刷量、入侵加密数据、肉鸡挖矿、控制服务器”等七宗“罪”，为大家揭开了互联网黑产的面纱。
