# 【产业观察】咨科和信公司：企业级数据管理公司的引领者

2018 年 5 月 25 日，欧盟“一般数据保护规定”(GDPR) 立法生效之后，有关数据安全问题将使企业可能面临高达年收益 4% 的严重惩罚，因而数据管理与保护成为企业发展面临的重要议题。随着全球信息化步伐的日趋加快，数据合规问题所波及的也不仅仅是 GDPR 规范下的欧洲企业，同时也成为全球企业的挑战。Informatica 公司作为全球领先的企业数据平台解决方案提供商，位居Gartner2018 企业集成平台即服务魔力象限领导者地位。在全球积极推进数据安全与隐私保护进程的背景下，梳理 Informatica 的数据管理与保护产品、技术情况，对于推进中国数据安全产业发展具有一定参考价值。

  

****公司概况****

咨科和信（Informatica）成立于 1993 年，由Gaurav Dhillon 和 Diaz Nesamoney 共同创立，总部位于美国加州红木城。Informatica 从成立以来一直专注数据管理领域，并且在数据集成、主数据管理等多个技术领域成为领导者。Informatica于 1999 年 4 月在纳斯达克上市，作为全球领先的独立企业数据集成软件提供商，Informatica 帮助世界各地的组织为其主要业务提供及时、相关和可信的数据管理和保护，从而在当今全球数字经济发展中获得了竞争优势，其核心产品主要包括企业云数据管理和数据集成。

  

Informatica 拥有遍布全球的客户关系网络，其成功案例显示，Informatica 已经帮助了数量众多的企业和政府机构实现其企业级数据的商业价值。Informatica 与全球 400 余家合作伙伴（领先的系统集成商、分销商和独立软件开发商）携手建造了强大的合作伙伴生态系统。Informatica在全球范围内拥有 7,000 余家客户，是企业云数据管理方面值得信赖的领导者。领先的 IT 研究和咨询公司 Gartner 在其企业集成平台即服务魔力象限中，连续五年将 Informatica 评为全球企业级云数据管理领导者。在 2018 年的报告中，Informatica 除了在企业集成平台即服务魔力象限中处于“愿景完整性”坐标的右侧最远位置以及“执行能力”坐标的最高位置，同时还被Gartner 评选为其他四个市场领域（Gartner 四个魔力象限）的领导者。

****优势产品****

  

Informatica 的主要产品包括智能大数据、智能云服务、智能数据集成、智能数据安全、智能主数据管理等，可支持多项复杂的企业级数据集成计划，包括：企业数据集成、大数据、数据质量控制、主数据管理、应用程序信息生命周期管理、复杂事件处理、超级消息和云数据集成等。借助 Informatica 全面、统一、开放且经济的数据集成平台，各类组织机构可以在改进数据质量的同时，访问、发现、清洗、集成并交付数据，以提高运营效率并降低运营成本。Informatica 开放、独立于平台的软件降低了企业IT 的运营成本，加快了产出速度。

 

智能大数据方面，Enterprise Data Catalog 产品借助基于机器学习的数据目录，可以帮助企业通过云端、内部部署和大数据，对数据资产进行分类和管理。它能在整个企业范围内实现数据最大值和再利用。Big Data Streaming 产品具有快速、可靠、无代码流处理的实时分析功能，能将更多流数据转换为可信的实时分析见解。

  

智能云服务方面，Informatica Cloud 提供了面向数据集成云应用，确保企业用户能够跨基于云的应用程序和预置系统及数据库来集成数据。Informatica Cloud 利用底层的 PowerCenter 数据集成引擎，实现在线注册、用户和任务流管理、工作调度和监控、错误处理、压缩、加密和安全代理等功能，以此访问和集成预置数据源和云数据。借助 Informatica Cloud，客户与合作伙伴可以在云中构建、管理和共享定制的数据集成服务。

  

智能数据集成方面，Informatica B2B DataExchange 是一款业界领先的工具，用于多企业的数据集成。它增加了安全通信、管理和监控功能，来处理来自内部和外部的数据。Informatica B2B Data Exchange 为多个企业数据集成、合作伙伴管理以及业务事件监控提供了一个全面的技术基础设施。它能帮助企业有效且经济高效地与其贸易合作伙伴和客户组成外延网络并进行协作，从而帮助企业降低成本，保持和增加收入。

  

智能数据质量方面，Informatica Data Quality通过一个全面、统一的平台，为所有项目和应用程序的相关人员、项目和数据域（无论在内部预置，还是在云中），提供普遍深入的数据质量控制。Informatica Data Quality 结合了强大的数据分析、清洗、匹配、报告、监控能力和易于使用的界面，使业务信息所有者能够在整个企业范围内实施和管理数据质量计划。

  

智能数据安全方面，Informatica DataMasking 是一款全面、灵活且可扩展的软件，用于管理对如信用卡信息、社会保险号、姓名、地址和电话号码等敏感数据的访问。该软件可以防止机密信息被无意中暴露，降低数据外泄的风险。Informatica Data Archive 是一款高度可扩展的高性能软件，可以帮助 IT 部门经济高效地管理众多企业业务应用中的数据增长。该软件使 IT 团队可以轻松、安全地对应用程序数据进行归档，包括主数据、参考数据和事务数据，并可根据需要随时对其进行访问。

  

智能主数据管理方面，Informatica IdentityResolution 是一款功能强大且高度可扩展的身份识别解决方案，让企业和政府机构能够批量且实时地搜索和匹配来自超过 60 种语言的身份数据。Informatica Master Data Management（MDM）通过提供整合且可靠的关键业务数据，帮助企业用户来改善业务运营。它能够以独特方式识别所有关键业务主数据以及它们之间的关系，通过多域主数据管理，使客户能够从小规模起步，并随着需求的增长进行扩展，可在同一平台上支持所有的 MDM 要求——数据集成、探查、质量和主数据管理。

****发展经验****

  

**加快战略理念转型**

  

随着过去十年全球数据爆炸性增长、数据价值不断被发现以及挖掘的信息化发展进程，Informatica 确 立 了 从 ETL 工 具（ 英 文 ExtractTransform-Load 的缩写，用来描述将数据从来源端经过抽取、交互转换、加载至目的端的过程）到上升为云数据管理领导者的发展战略。这一战略成为 Informatica 契合当下 IT 发展趋势的重要决策，使其从单一的 ETL 工具提升为云数据管理解决方案、满足客户创新需求的领先服务供应商。Informatica 在 2017 年 5 月发布公司全新品牌标识，云数据管理领导者这一战略包含产品、解决方案以及支撑产品和解决方案的智能数据平台，这款数据平台也是业界唯一一款面向数据管理和数据驱动式数字化转型的端到端平台。以前大数据能够操作的大部分只是结构化的数据，Informatica 关注点是元数据的下一代产品，以帮助客户看到更广泛的数据。未来，Informatica 要推荐给客户的是解决方案，而不是单个产品。

  

**推动技术产品创新**

  

Informatica 凭借业界下一代解决方案，实现了对集成平台即服务进行了重新定义。它通过诸多创新技术，在客户实施数据驱动的大规模数字化转型中，为其提供创新动力。这些业界领先的创新技术包括：现代化的用户体验、崭新的微服务架构以及全新的集成平台即服务模式。通过 Informatica 创新的、由人工智能驱动的集成平台即服务，用户可以跨越多重云和混合环境对数据进行智能管理，并从这个灵活且基于云端的数据管理解决方案中获益。Informatica为客户提供了先进并具有市场领先地位的集成平台即服务方案，以帮助当今企业化解在重新思考数据战略时所面临的诸多挑战。这个由人工智能驱动的全方位企业数据治理解决方案，将有效推动企业所有业务和 IT 化工作的相互协作，以及数据治理计划的共同实施，从而实现可信数据和受保护数据的可靠交付。Informatica全新的数据治理解决方案能够实现与可信数据和受保护数据的集成，并且在整个企业范围内方便地对这些数据进行访问、探查、编目、理解和使用。

  

**积极拓展中国市场**  

  

高速发展中的中国正在积极推进各项信息整合工程及企业信息化的投资建设，Informatica把中国列为其全球投资的最重要国家之一。Informatica 于 2005 年正式进入中国，凭借全球领先的技术和完善的服务，在包括金融、电信、制造、政府、保险、公众服务等多个领域获得突破，并帮助众多企业构架随时随地呈现正确重要信息的数据整合平台。Informatica 专注于数据管理领域，自进入中国市场，帮助上千家中国企业实现以数据为驱动的数字化变革。在不断拓展自身业务的同时，Informatica 还积极推动中国信息化产业的发展。通过与中国国内企业和合作伙伴分享国际领先的理念、技术和经验，帮助其加强信息化管理，提升信息化水平，并最终共同推进中国的信息化建设，把中国的信息化产业推向国际市场。
