# 【热点聚焦】Google Play商店又更新规则：加密货币挖矿App被禁止

7月27日消息，谷歌会定期更新Google Play应用商店的开发者规则。本周，谷歌再次更新了这一规则，宣布Google Play禁止一些类型的应用，比如加密货币挖矿、推销枪支等应用。  

  

首先，Google Play将不再允许出现加密货币挖矿应用。目前，挖矿应用已经泛滥，其中包括MinerGate、Crypto Miner和NeoNeonMiner。今年早些时候，谷歌的Chrome Web Store已禁止了挖矿的扩展插件。  

  

其次，“推销爆炸物、枪支、弹药或某些枪支配件”的应用也被禁止。这其中包括为用户自己制造枪支弹药提供指南的应用。

  

谷歌还禁止“吸引儿童但包含成人主题”的应用。这可能是对此前YouTube事件的回应。当时，数千条包含家庭和儿童形象的“邪典”视频被上传至YouTube。目前，存在类似情况的应用和游戏也都将被禁止。　　

  

Google Play目前也禁止重复内容。谷歌解释称，“内容和用户体验高度相似的应用”，或“由自动化工具、向导服务，或是基于模板开发的应用”。有开发者投诉称，因为这条新规，他所开发的游戏由于同时提供付费版和免费版两个版本而被删除。  

  

此外，主要目的是发布广告的应用，以及有意误导用户的应用被谷歌新规明令禁止。谷歌对后一类应用的描述为“故意模仿任何个人或组织，或是歪曲或隐瞒其所有权或主要目的的应用或开发者内容”。
