# 【热点聚焦】Facebook推出API限制，公开屏蔽错误

作为继剑桥分析公司丑闻之后继续努力提高用户隐私和安全性的一部分，Facebook周一推出了额外的API变更，对开发人员访问用户数据施加了更多限制。  

  

除了在其应用审核流程中实施更严格的标准外，这家社交网络巨头还要求对某些API提供高级开发人员权限，并完全关闭其他API。目前，Facebook正在弃用Graph API Explorer应用程序，而Profile Expressions Kit将于10月1日弃用。Facebook表示，后者的采用率较低。

  

与此同时，媒体公司用于电视广播竞选投票等媒体解决方案系列的API将限制开发人员访问个人的公共页面内容和帖子。许多媒体API将在8月1日完全关闭，包括主题搜索，主题洞察、主题源和公共图API。

  

在其他地方，页面API将很快要求页面公共内容访问的特征权限，这只能通过应用审核流程获得。Marketing API将要求开发人员在使用前完成应用审核流程。实时视频和潜在客户广告检索API也将具有新的应用审核权限。

  

在另一篇博客文章中，Facebook披露了Messenger和Facebook中存在的一个错误，该错误清除了一些人的屏蔽用户名单。Facebook首席隐私官Erin Egan表示：该漏洞在5月29日至6月5日期间处于活跃状态，当一个未被屏蔽的人无法看到与朋友分享的内容时，他们本可以看到发布给更多人的内容。例如，与朋友的朋友共享的图片。Facebook表示该问题已得到修复，所有人的屏蔽名单都恢复了。
