# 【热点聚焦】Twitter通过要求新用户确认他们的电子邮件或电话号码来打击垃圾邮件

传统上，Twitter的注册要求比最常被引用的竞争对手Facebook要宽松得多。例如，用户不必在Twitter上提供他们的全名。这使得用户更容易保护自己的身份，但也使垃圾邮件帐户更容易接管平台。

 

现在，该公司正在概述其采取的一系列措施来打击垃圾邮件以及所谓的“恶意账户”。同时也试图为所有用户保持平台的健康和安全。

 

Twitter的约埃尔·罗斯和德尔·哈维在一篇博客文章中表示，新用户在注册平台时将确认电子邮件地址或电话号码。以前，用户在注册帐户之前不必验证这些信息。这项改革将于今年晚些时候推出，该公司表示，其成立两年的信托与安全委员会也将与非政府组织合作，以确保在匿名很重要的高风险环境中，这项改革不会伤害到任何人。该公司还将开始审核现有账户是否存在自动注册的迹象。

 

罗斯和哈维还详细介绍了公司创建的新系统的有效性，以便更主动地识别垃圾邮件账户。首先，该公司披露，由Twitter识别和“挑战”的潜在垃圾邮件或自动垃圾邮件账户数量从2017年9月的每周250万个增至目前的每周990万个。该公司将识别垃圾邮件帐户数量的上升归功于其机器学习工具的新发展，但没有透露具体细节。

 

Twitter还表示，垃圾邮件报告的平均数量已从3月的每天2.5万份下降到5月的1.7万份。该公司表示，这种下降意味着更少的人在他们的时间轴，搜索以及整个Twitter产品中遇到更少的垃圾邮件。

 

彭博社指出的那样，Twitter之前由于未能迅速移除该公司在2015年初发现的一些伪造的俄罗斯链接账户而受到批评，因为2016年美国总统选举的竞选活动期间伪造账户开始增加。因此，在2018年美国中期选举和其他选举期间，Twitter还将面临一个关键的考验:当恶意行为者可能更有动机尝试创建大量的垃圾邮件帐户时, 它在清除垃圾邮件账户方面会做得有多好。

 

Twitter“促进健康对话”的另一个目标是减少平台上的恶意对话和欺凌行为。为此，Twitter上周宣布，它正在收购Smyte，该公司开发了一个API来捕捉垃圾邮件和安全问题。Twitter还透露，它正在扩展其自动处理程序，以捕捉恶意行为，例如来自同一帐户的大量推文。
