# 【理事动态】浙江爱信诺助力杭州道路停车进入电子发票时代

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544730&idx=2&sn=8ddcf57212df56dad5ef0668c07d628c&chksm=c0b4f5ecf7c37cfa2e64dda13ef9298c1ee1e7b17355226c7f664c5ceb24d042a335ece7f24f&scene=126&sessionid=1681312327#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544730&idx=2&sn=8ddcf57212df56dad5ef0668c07d628c&chksm=c0b4f5ecf7c37cfa2e64dda13ef9298c1ee1e7b17355226c7f664c5ceb24d042a335ece7f24f&scene=126&sessionid=1681312327#rd)

2018年7月1日起，浙江爱信诺航天信息有限公司智能POS机收费开票一体化方案在杭州正式运行，杭州市主城区范围内的路边停车进入无纸化电子发票时代，今后市民只需扫描收费小票上的二维码，随时随地开具电子发票。

  

![](../Images/7bddbe767f49c127f2801d806f1b2db3.png)

**行业痛点**

  

开票面额小，开票量大；

手撕发票难以管控，成本高；  

跨区补缴开票，财务管理混乱。  

  

智能POS机收费开票一体化方案针对性解决道路停车开票痛点，开具的电子发票与税务机关监制的纸质发票具有相同法律效力，轻松报销，免除丢失烦恼。

  

**解决方案**

  

根据停车时间计算停车费；  

收费完成后，收费智能POS机打印开票二维码小票；

车主扫描小票上的“结算凭证”上的二维码，进入开票信息填写界面；

车主填写相关开票信息后提交申请；

系统收到车主开票请求后，自动开具电子发票发送至车主。

  

![](../Images/294e18cfac50a4021d4d64fe75d6b62f.png)  

**方案优势**  

  

电子发票替代定额手撕票，降低财务风险；  

电子发票实现在线、实时交付，提高客户满意度；  

消费者自主开具电子发票，提升工作效率；  

极速开票+电子发票，提高开票准确率；  

与业务系统对接，智能获取开票信息。
