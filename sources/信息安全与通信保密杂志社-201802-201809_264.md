# 【理事动态】多家理事单位参加第十六届中国国际软交会并喜获奖项

6月12日，第十六届中国国际软件和信息服务交易会在大连开幕。本届软交会以“软件定义智能新时代”为主题，重点关注新IT技术构建的新产业形态，数据经济的共创共享共赢，云+网+端的企业业态跨界整合，以及人工智能时代的生态圈构建，集中呈现出最前沿的能源、金融、交通、医疗、教育、制造、电信等行业解决方案，全面展示云应用、大数据存储分析及管理、网络安全、智能制造、5G等平台项目，是一次聚焦技术前沿、引领产业方向、促进合作共赢的行业盛会。

在同期举行的中国信息安全年会和软件和信息服务业年度发布会上，杭州世平信息科技有限公司和江苏敏捷科技股份有限公司分别喜获奖项。

![](../Images/c592928a01325cf2fb7dc64019eea910.png)

![](../Images/b93cacb4282dffb995c9dbb984165d9d.png)

杭州世平信息科技有限公司斩获“**2017年度自主可靠企业核心软件品牌**”与“**2017-2018中国软件和信息服务业最具创新精神企业奖**”两项殊荣。

  

  

![](../Images/22cfd03db9e6c4524012ad9a812642be.png)

![](../Images/7a707a80523c717f7ed11e499f0a8cad.png)

江苏敏捷科技股份有限公司斩获“**2017-2018中国软件和信息服务业最具竞争力产品奖**”与**“2017-2018中国软件和信息服务业最具创新精神企业奖**”两项殊荣。
