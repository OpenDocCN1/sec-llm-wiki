# 【理事动态】中国国际大数据产业博览会在贵阳召开，金航数码飞机快速响应客户服务平台获百家大数据优秀案例

5月26日，中国国际大数据产业博览会（数博会）在贵阳开幕，习近平主席为数博会发来贺信，希望各位代表和嘉宾围绕“数化万物·智在融合”的博览会主题，深入交流，集思广益，共同推动大数据产业创新发展，共创智慧生活，造福世界各国人民。数博会期间还举办了《大数据优秀产品和应用解决方案案例系列丛书》发布会，金航数码飞机快速响应客户服务平台获百家大数据优秀案例。

![](../Images/b8088f4b20f3ea9a3a241614604df806.png)

  

《大数据优秀产品和应用解决方案案例系列丛书》发布会还为在工业和信息化部组织的2017年大数据优秀产品和应用解决方案征集活动中入围的百家大数据优秀案例企业授牌。

  

![](../Images/a231673fbfbd6111db31d7a9080d8e23.png)

  

![](../Images/bdb12a323bb8c4db7502bcceea1fc054.png)

金航数码“飞机快速响应客户服务平台案例”成功入选百家大数据优秀案例

  

金航数码飞机快速响应客户服务平台，因其面向全球飞机运营需求，为解决企业客户服务相关大数据问题提供一站式的方案而入选。平台可实现飞机客户服务和运行支持过程中异构数据、分散数据的整合，通过对企业内外部数据的融合与分析，为民机市场营销与客户服务业务优化提供有力支撑，在飞机销售管理、工程技术支援、航材备件管理、辅助教育培训、飞机交付管理、机队运营监控等过程中发挥了关键作用。
