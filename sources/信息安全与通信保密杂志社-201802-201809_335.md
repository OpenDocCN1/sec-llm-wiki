# 【热点聚焦】2018RSA大会网络安全热点（成都）分享会召开

5月23日，2018RSA大会网络安全热点（成都）分享会在成都高新区菁蓉国际广场拉开帷幕。

RSA大会作为网络与信息安全界最具影响力的业界盛会之一，被视为全球网络与信息安全领域的风向标，2018年全球信息安全产业大会以“现在很重要”为主题于4月16－20日在美国旧金山举行，吸引了来自全球各地约500家安全企业和4万余名业界人士参会，共同探讨数字经济时代网络安全的发展趋势。

据悉，本次分享会的举办正值《网络安全法》施行一周年之际。为深入贯彻落实习近平总书记在全国网络安全和信息化工作会议讲话精神和网络强国战略思想，结合“大学习、大讨论、大调研”活动，由四川省网信办、成都市网信办、高新区网信办共同指导，成都市安全可靠信息技术联合会、成都市互联网文化协会、成都市高新区互联网文化协会共同主办。本次分享会邀请了部分国内知名机构与安全企业的专家、学者代表，从国家政策、威胁态势、产业发展、企业实践、技术热点、创新创业等多个方面，对网络与信息安全领域最具影响力的盛会RSA大会进行解读，以助力企业把握产业趋势和发展方向。

在2018 RSA大会上，国际信息系统审计协会（ISACA）发布的网络安全报告显示，2018网络世界的安全问题似乎并未减少，安全事件频发，信息泄露问题愈演愈烈。81% 的安全专业人员表示，所在机构在 2018 年遭遇过网络攻击；50% 的受访者表示2018 年所遭遇的网络攻击已超过了 2017 年的总和。“今年的RSA大会显示，网络安全领域不存在一劳永逸解决问题的银弹。最好的应对方式是抓住当下、脚踏实地。”360企业安全集团副总裁、网络安全专家左英男说。

面对日益严重的安全威胁挑战，观潮论坛主席、国家创新与发展战略研究会副会长郝叶力将军强调，国际网络安全产业需加强协同合作。“合作是根本方向，更是网络空间的主旋律。”

出席本次分享会的成都市网信办相关负责人表示，四川省、成都市历来高度重视网络安全产业，已将其列入五大高端成长型产业之一。据介绍，成都坚持以习近平总书记新时代中国特色社会主义思想为指导，深入学习贯彻党的十九大精神和习近平总书记对四川工作重要指示精神，将加快网络安全产业发展，进一步筑牢网络安全屏障，努力打造自主创新“网络强市”和新时代中国的“网络重镇”。

此外，对于网络安全未来的投资与创业方向，相关投资机构认为，面对层出不穷的安全威胁，除了加强产业协作，人工智能与安全自动化应该是应对挑战的重要方向，这将有助于解决安全人才不足的问题。成都信息工程大学网络空间安全学院副院长张仕斌在对话中呼吁推动安全人才培养模式创新，解决安全人才缺口严重的问题。

网络世界与现实社会已经密不可分，互联网技术和社会发展更是高度融合在一起。目前，以物联网、人工智能、新一代通信技术为代表的新经济正在全球迅猛发展，亟需紧跟前沿网信技术的研发、应用，才能保障新经济产业健康、安全发展。
