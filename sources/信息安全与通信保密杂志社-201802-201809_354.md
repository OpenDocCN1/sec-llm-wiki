# 特朗普称要帮中兴迅速恢复业务 美国议员却不同意

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544700&idx=2&sn=23196bd36167d20cd194bec25456ce8b&chksm=c0b4f50af7c37c1c7aea561e52dfd1cc309f452bfe3707d7ef92009102ef586dc340eb3dbf11&scene=126&sessionid=1681312334#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544700&idx=2&sn=23196bd36167d20cd194bec25456ce8b&chksm=c0b4f50af7c37c1c7aea561e52dfd1cc309f452bfe3707d7ef92009102ef586dc340eb3dbf11&scene=126&sessionid=1681312334#rd)

5月16日消息，据国外媒体报道，当地时间周二，美国议员拒绝唐纳德·特朗普减轻对中兴通讯进行解禁的任何计划，声称该公司是一个安全威胁，并誓言不会放弃对该公司施行强烈惩处的立法。

中兴通讯因所谓的藐视美国对伊朗的贸易制裁，遭受美国政府惩处。不过后来事情有了转机。当地时间周日，特朗普发推文承诺帮助中兴通讯恢复业务。周一，特朗普为自己的这一承诺进行了辩护，据称这一让步是中美双方就寻求当前贸易战解决办法谈判内容的一个组成部分。

共和党参议员马尔科·卢比奥(Marco Rubio)表示，“我希望政府不要推进这样的提议，我对此保持关注。”中美这两个全球最大经济体之间的双边谈判，本周在华盛顿继续进行。

鲁比奥在参议院外交关系委员会的亚洲政策听证会上表示， “他们基本上是在全面窃取我们已经开发出来的技术，并以此作为他们发展的基础，这样他们就可以取代我们而成为21世纪最重要科技的领导者。”

中兴通讯遭遇美国惩处制裁后，其主要业务基本处于瘫痪状态，在中国的数万就业岗位受到影响。特朗普周日发表推文承诺帮助中兴通讯，这与他挂在口头的”美国优先”政策相违背。

美国商务部4月份发现中兴通讯违反2017年达成的和解协议，即该公司违反该和解协议向受到美国政府制裁的伊朗和朝鲜出售设备，因此商务部作出7年内禁止美国公司向中兴通讯提供出口的禁令。

据估计，中兴通讯设备中25%至30%的零配件由美国公司提供，这些设备包括智能手机和用于建立电信网络的设备。

特朗普的表态激怒了部分美国国会议员，这些议员一直敦促对中兴通讯采取更多的限制。一些美国议员声称，中兴通讯和其他中国公司制造的设备，可能对网络安全构成威胁。

参议院财政委员会民主党议员罗恩·怀登（Ron Wyden）对媒体表示，“你们一直在努力证明中国窃取了我们的技术，我的观点也是这样的，是谁在双边谈判的前夕作出单边让步？”。参议院财政委员会监管美国贸易政策制定。

32名参议院民主党议员周二签署联名信，指责特朗普将中国的利益置于美国就业和国家安全之上。怀登也参与了这项连署签名。

中兴通讯否认自己存在不法行为。

周二在一次媒体活动上，共和党议员、众议院军事委员会主席麦克·索恩伯里（Mac Thornberry）表示，他预计议员们不会寻求从年度国防政策议案中解除对中兴通讯的禁令。

“我承认我没有完全理解政府此刻的立场，”索恩伯里表示。“但我认为，这不是一个经济问题，它是安全问题。”

不过，另一位共和党参议员约翰·肯尼迪(John Kennedy)替特朗普辩解称，总统的做法是同中国更大背景谈判的一个组成部分。肯尼迪对媒体表示，“我认为这是一个更大问题的一部分，也是更大范围谈判的一部分。”
