# 首部人工智能基础教材在沪发布 全国40所高中将开设AI课

4月28日，全球首部人工智能普教教材——《人工智能基础》（高中版）在沪发布，华东师大二附中、上海交大附中等全国各地40所学校成为首批“人工智能教育实验基地校”。这是国内中等教育体系首次引入AI教材，标志着我国人工智能教育踏入基础教育阶段。

  

![](../Images/3bf39b2bd70d1546eb91ac3f95c84084.png)

  

《人工智能基础》（高中版）教材强调以“手脑结合”为主要学习方式，由华东师范大学出版社和商务印书馆联合推出，融合了产学研领域教研经验。

  

据悉，上海市市西中学已开始基于教材内容进行授课，并建设起首个人工智能教育实验室。未来，教材合作各方将在更多中小学开展人工智能教师培训、中小学人工智能实验室建设、课堂教学辅助管理、包括平安校园在内的智慧校园建设等。

副市长翁铁慧等出席教材发布会。
