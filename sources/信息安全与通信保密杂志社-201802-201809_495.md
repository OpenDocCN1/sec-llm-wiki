# 春运大幕拉开 谨防“抢票神器”陷阱

2017年2月1日正式进入一年一度的春运季，从1月初起春运火车票正式开抢已经一个月了，然而，今年春运跟往年不一样，不仅12月30日以后的火车票预售期从过去的60天调整为30天，而且春运时间来得也比往年早，抢票形势不容乐观。

据交通部门的数据显示，2017年全国春运旅客发送量为2.98亿人次，而2018年的春运旅客人次将进一步上涨，预计会突破30亿人次，其中，铁路预计发送旅客量3.93亿人次，同比增长10%。不少网友已经将回家的希望寄托在一个个抢票神器上。

**非官方抢票软件嵌入病毒，泄露用户隐私**

由于火车票需要实名制购买，通过抢票软件也要提供个人信息，这就会令乘客的个人信息、账号密码等透漏出去。不少网友反映使用抢票软件后，非但没有抢到票，反而接到了很多垃圾短信和骚扰电话，显然个人信息已遭泄露，被抢票软件囤积信息后倒卖掉。而且，还有部分抢票软件打着快捷抢票的幌子，实际上在兜售抢票加速费，如果不买的话，速度并不明显，同时利用网友的账户密码刷票，等刷到票后就加高价出售，从中赚取非法利润，提高网友的购票成本。

因此，网友要擦亮眼睛，仔细辨识“抢票神器”的真伪，不要盲目信从软件商的说辞，以保护个人信息安全为首要考虑，切勿轻易将个人信息泄露出去，以免带来不必要的麻烦。另外，在帮忙加油抢票的同时，也要注意个人信息安全，仔细阅读相关条款，不要随便将个人信息授权给这些软件。

同时，在抢票的时候，还是尽量从正规渠道，通过12306官网或APP购票，乃是最安全的途径。而且，网上放票也有时间规律，网友可以多留意下，多掌握些抢票技巧，以提高抢票成功率。

**代刷票网站谨防钓鱼**

由于抢票难的问题，不少论坛、网站或者QQ群有代刷票的业务，有免费的也有付费的黄牛，却也存在一些恶意钓鱼网站。出于对个人信息的保护，建议也不要参与接触这一类业务，除非是自己接触过的熟人。

**虚假客服诈骗**

跟网购退款诈骗一样，购买火车票也会期间也可能会收到陌生的通知消息，伪装12306客服称还有余票或者付款信息出错需要退款等，这些往往的带有非法链接，引诱用户上当诈骗钱财。购买或者查询火车票务必认准12306官网，这也是很多人不会去主动确认的。

**实际案例**

在北京实习的王同学就是春运大军中的一员，在抢购除夕当天火车票失败后，她就时刻关注着余票情况，希望能“捡漏”。看到网页上“抢票神器”可以迅速购票后，她心动了。下载应用后，她手动填写了“始发站”和“抵达站”，在选中车次后输入了个人乘车信息。而为了能够快速出票，王同学选择了先付款自动出票的方式。结果，5天后她依旧没有收到抢票成功的消息，反而收到了银行卡被多次扣费的短信。

**安全提示**

那么对急切购票的用户来说，应如何避免木马病毒风险呢?小编总结了以下两点建议：其一，用户需在正规的网站购票，不要轻信网页上“抢票神器”的借口;其二，为用户可以通过腾讯手机管家对下载的抢票类软件进行风险识别并查杀风险软件，保障出行安全。

临近春节，购票的形势愈发紧张。大家在购买春节返乡车票和回程车票时，务必提高警惕，切勿因回家心切，误信抢票类的恶意软件，以免落入骗子的圈套，影响春节回家、带来不必要财产损失等。
