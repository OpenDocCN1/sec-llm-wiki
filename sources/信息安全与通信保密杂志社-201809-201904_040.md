# 【网安智库】三方面应对未来人工智能的应用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544964&idx=1&sn=c7dd0e3f20708bdaf59ce135b9e44acd&chksm=c0b4eaf2f7c363e44e9c0790bfcb75978bf768b32d971a306f6adfe2129f8f19aeac51abfb44&scene=126&sessionid=1681312284#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544964&idx=1&sn=c7dd0e3f20708bdaf59ce135b9e44acd&chksm=c0b4eaf2f7c363e44e9c0790bfcb75978bf768b32d971a306f6adfe2129f8f19aeac51abfb44&scene=126&sessionid=1681312284#rd)

本文将从国际管理、发展现状以及最佳实践三个方面分析国际社会人工智能的发展，怎样弥补发展现状和未来目标之间的差距，以及如何更好地应用人工智能。

首先，人工智能的全球管理是十分必要的。本文表述的人工智能的自动技术是指可以自主做出决定和拟定战略的技术，其发展可能会带来三方面的问题。第一是责任问题，谁为人工智能引导问题来负责。比如此前特斯拉无人驾驶车曾发生车祸的事件。第二是权利问题，如果人工智能自主创造出东西，比如人工智能创作了一幅画，如何判定这幅画的拥有者。另外，人工智能创造的产品获得了收益，最终的获利者和所有者归属也是问题。其中一种解决方案是赋予人工智能以某种法律人格。第三是伦理问题，现阶段国际社会面临着多种伦理困境。首先是人工智能如何做出有关伦理的决定，比如自动驾驶车辆在面临撞车的情况下应如何处置，再比如智能服务生应该先接待谁，这都需要做出选择。其次，在面临困境时应不应当由人工智能作决定。比如在自动化武器的使用或者是自动化执法方面，是否应该禁止由机器或者机器人做出决定。

其次，关于人工智能的发展现状。第一方面，人工智能作为一项伟大的技术发明，公众对于人工智能的信任问题值得深思。以转基因食物为例，现阶段并没有充分证据证明转基因食物对人体有害，但是在欧洲所有人都不相信转基因食物，原因在于转基因技术在开发之初，政府或者是相关公司没有成功地使公众相信转基因食物是安全的，但是却有部分组织成功地让公众认为转基因食物是完全不好的。与欧洲国家相反，2017 年美国77% 的玉米是转基因玉米，但是民众能够完全接受，原因在于美国的政府和相关公司使民众相信了转基因食品不存在问题。因此对于人工智能的发展，国际社会也应该做出正确的策略选择。

第二方面，关于跨行业、跨产业的人工智能，狭义和广义的人工智能也并不是完全分离的。广义人工智能的发展与管控紧密相关，在世界不同区域都能够实现技术的应用，因此应当在各个区域进行不同的管控，制定不同的规定，并实现各个行业的高度协调。

第三方面，之所以需要全球的管控，原因在于多国开始进行人工智能的管控。部分国家不接受国际规定或者提出本国的规定，从博弈论的角度来看，如果该部分国家只关注自身，那么它们很有可能会失败。为了获得最后的整体成功，应该督促那些最关注自身利益的国家去遵守国际规定，这样就可以驱动更多的国家遵从国际规则。从经济角度分析，国际社会存在各种各样的跨国经济交易，比如英国与欧盟，英国如果脱欧就会面临失去欧洲市场的风险。虽然根据现有的市场规定单一国家可以融入其他的市场，但是一旦规定无法兼容，可能会导致该国倾向于利用本国的规定来获取利益，从而损害其他国家的利益。

第四方面，在现有的国际关系中，存在各种各样的组织。以美国为例，美国在退出了《巴黎气候协定》之后，仍然在幕后扮演了非常重要的角色。因此，如果一国不是国际规则的制定者，有可能被竞争者甩在背后。现阶段关于人工智能国际社会已经制定了一系列全球倡议，此类倡议虽然具有一定的约束力，但是并未对所有国家有效。未来倡议存在很多共有的趋势，其中之一就是透明度。透明度虽然十分必要，但是在执行和技术上很难实现较高水平的透明，必须越过众多技术上的障碍，以及现实与预期规章制度之间存在的巨大差异。

最后，在人工智能的最佳实践方面，国际社会致力于通过合作的方式，并利用过去不同的成功技术建立一个全球管控机制作为管理人工智能的工具箱。以往国际社会对于国际法律体系存在一种错误的认知，要么具备约束力，要么不具备约束力。但是通过各国不同的法律法规和指令与国际法的对接，就能够使其灵活地融入到本国的法律中。此外，国际社会还存有模型法律，同样能够有效地利用人工智能或应用到人工智能中。还有一个概念是国家间应加强彼此间的交流，建立全球人工智能学院，为全世界相关的人员带来更多的知识。现有的世界海洋学院会议，参与者就包括了南半球和北半球的国家，商讨相应的事宜。管控机制的建立并不仅仅是由大国设立，同时世界上其他国家也应该参与该过程。

总体而言，国际社会面临一个很好的机遇，现阶段各个国家之间人工智能的发展并未呈现特别的不同，仍然存在多种方式和模式促成全球合作，问题在于是否能够抓住机遇和利用现有的工具促进人工智能的发展。
