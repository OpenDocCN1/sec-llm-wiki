# 【热点聚焦】360企业安全集团的360天眼新一代威胁感知系统获得“金智奖”2018年度产品（解决方案）奖

 360天眼新一代威胁感知系统，是集成360安全能力的高级威胁检测、溯源、响应的完整解决方案，是360天眼实验室研发的国内首套基于大数据的高级威胁定位与发现分析系统。该系统基于网络流量和终端EDR日志，运用威胁情报、规则引擎、文件虚拟执行、机器学习等技术，并对本地流量进行全量还原、存储与深度分析，最终实现了对未知威胁与高级攻击的快速发现、精准定位和攻击溯源。天眼基于多维度、覆盖全球的数据收集能力，利用云端大数据技术自动化处理，并配合顶尖安全研究团队的人工运营，为用户提供精确的威胁情报；并且支持与终端EDR系统协同联动，帮助用户快速定位和处置感染主机和恶意软件，大大提升网络攻击的响应和处置能力。

  

“金智奖”评选出的“十大金智产品奖”“十大金智企业奖”“十大金智人物奖”等系列奖项在过去的两年时间里已经成为行业普遍认可的荣誉，参与各奖项角逐的企事业单位和个人也逐年增多。参加本届“金智奖”评审工作的专家评委达到100位，有1000位专业评委参与推选。

**经评委评选**，**360企业安全集团的360天眼新一代威胁感知系统获得**信息安全与通信保密杂志社主办的********中国网络安全与信息产业**“金智奖”2018金智产品（解决方案）奖。**

**关于360企业安全集团**

360企业安全集团是中国企业级网络安全市场的领军者，是专注于为政府和企业提供新一代网络安全产品和服务的综合型集团公司。齐向东360企业安全集团董事长。集团以“让网络更安全，让世界更美好”为企业使命，以“数据驱动安全”为技术思想，创新建立了新一代协同防御体系，全面涵盖大数据安全分析、网关安全、终端安全、网站安全、移动安全、云安全、无线安全、数据安全、代码安全等全领域安全产品及解决方案，已经为包括中央部委和大型央企在内的超百万家企业级客户提供了全面有效的安全保护，并赢得了客户的一致好评。360企业安全集团，以“让网络更安全，让世界更美好”为使命，以“数据驱动安全”为技术思想，以大数据搜集分析为支撑！为企业级用户保驾护航！
