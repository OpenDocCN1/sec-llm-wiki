# 【热点聚焦】成都启明星辰总经理董跃获得“金智奖”2018年度人物奖

董跃是成都启明星辰信息安全技术有限公司总经理。省青年企业家协会理事，省工控安全专委会主任。坚持技术创新和管理创新，提出“第三方独立安全运营”概念，在成都建立了国内最大、最具专业实力的城市级安全运营中心，为智慧城市、城市云、大数据中心及关键信息基础设施提供全方位服务。

  

“金智奖”评选出的“十大金智产品奖”“十大金智企业奖”“十大金智人物奖”等系列奖项在过去的两年时间里已经成为行业普遍认可的荣誉，参与各奖项角逐的企事业单位和个人也逐年增多。参加本届“金智奖”评审工作的专家评委达到100位，有1000位专业评委参与推选。

**经评委评选，******成都启明星辰信息安全技术有限公司总经理董跃获得信息安全与通信保密杂志社主办的中国网络安全与信息产业“金智奖”2018年度人物奖。****

**关于成都启明星辰**

作为启明星辰旗下全资子公司，成都启明星辰信息安全技术有限公司于2015年11月9日落户成都天府新区。目前，成都启明星辰是集团最大、最重要的区域性总部，主要服务于西南省份（西藏、四川、重庆、贵州、云南），员工总人数达四百余人，拥有丰富技术基础以及强大的安全产品、安全服务、安全集成能力，极其丰富的运营商、政府、电力、能源、电子政务等主要行业的安全建设经验及成功案例。成都启明星辰西部研发中心主要开展防火墙/UTM、入侵检测/防御管理、网络审计、安全管理平台、工控安全管理、安全专业服务工具、大数据、安全培训等信息安全软硬件研发。

  

位于成都科学城启明星辰大厦的启明星辰成都安全运营中心是目前国内规模最大、最具专业实力的城市级安全运营中心，立足于智慧城市及信息化热点技术发展,通过构建城市核心安全能力中心,打造专业安全分析团队,提供覆盖全行业全技术的安全能力,解决城市信息化新技术带来的安全挑战。同时，运营中心与东方电气，成立了国内领先的工控安全实验室；与四川电信联合成立网络安全联合实验室，为行业应用安全树立标杆；与四川省计算机信息安全行业协会合作，积极承担推进四川省工业控制网络安全的重任等。为了促进信息安全新兴技术领域的技术创新，还设立大数据安全实验室、深度安全攻防实验室、工控安全实验室等作为专项研究领域，为智慧城市各项应用提供保障；设立培训服务中心，为政府及企事业单位输送专业安全人才。
