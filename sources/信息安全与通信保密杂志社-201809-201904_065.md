# 【热点聚焦】深圳奥联首席科学家程朝辉获得“金智奖”2018年度人物奖

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544959&idx=4&sn=d6a5979843397a3461d25a03a5fdf11b&chksm=c0b4ea09f7c3631f56e4f4b0ccdec9b9c8113aa0bb6de5c6a2233237cd98759b6aac91ac918f&scene=126&sessionid=1681312286#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544959&idx=4&sn=d6a5979843397a3461d25a03a5fdf11b&chksm=c0b4ea09f7c3631f56e4f4b0ccdec9b9c8113aa0bb6de5c6a2233237cd98759b6aac91ac918f&scene=126&sessionid=1681312286#rd)

程朝辉是深圳奥联信息安全技术有限公司首席科学家，英国密德萨斯密码学博士，国密SM9标识密码算法标准的发起人和编制人。发表20余篇有影响力的学术成果，申请29项发明专利和1项PCT专利。现任中国ISO/IEC标准委员会SC27小组成员，他与合作者设计的多个算法被ISO、IEEE、IETF采纳为标准算法；他代表奥联联合中国电信、华为就《电信网络 物联网标识密码安全标准》在ITU成功立项；他在推动国密算法的国际化进程中做出贡献，2018年10月，在国家密码管理局的领导下，SM2/3/9密码算法正式成为ISO国际标准。

  

“金智奖”评选出的“十大金智产品奖”“十大金智企业奖”“十大金智人物奖”等系列奖项在过去的两年时间里已经成为行业普遍认可的荣誉，参与各奖项角逐的企事业单位和个人也逐年增多。参加本届“金智奖”评审工作的专家评委达到100位，有1000位专业评委参与推选。

**经评委评选，******深圳奥联信息安全技术有限公司首席科学家程朝辉荣获信息安全与通信保密杂志社主办的中国网络安全与信息产业“金智奖”2018年度人物奖。****

**关于深圳奥联**

深圳奥联信息安全技术有限公司是国家高新技术企业，拥有完整的密码算法设计能力和密码产品研发能力，已授权获得密码应用发明专利27项、PCT专利1项、软件著作权26项；提供基于SM2/3/4/9国密算法的密码产品及解决方案：安全电子邮件、加密通讯、海外通讯安全、物联网安全、云密码服务、云安全接入、加密云存储、数字防伪、工控安全等，成功应用于多个国家部委、军队、电信运营商、金融机构、海外中资机构、企事业单位。
