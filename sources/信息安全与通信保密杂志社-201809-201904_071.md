# 【热点聚焦】北京数盾信息董事长李元骅获得“金智奖”2018年度人物奖

李元骅是北京数盾信息科技有限公司董事长，毕业于澳门科技大学，中国信息安全建设专家；省部级科技进步奖第一完成人；曾任职于康佳集团。密码信息安全的推动者、商用密码产品应用推动者。中国密码学会理事，发起并组织密码信息安全产品创新和解决方案创新，获得省部级科技进步奖。

  

“金智奖”评选出的“十大金智产品奖”“十大金智企业奖”“十大金智人物奖”等系列奖项在过去的两年时间里已经成为行业普遍认可的荣誉，参与各奖项角逐的企事业单位和个人也逐年增多。参加本届“金智奖”评审工作的专家评委达到100位，有1000位专业评委参与推选。

**经评委评选，****北京数盾信息科技有限公司****董事长李元骅****获得信息安全与通信保密杂志社主办的中国网络安全与信息产业“金智奖”2018年度人物奖。**

**关于北京数盾信息**

  

  北京数盾信息科技有限公司成立于2002年，总部位于北京是国内领先的密码产品、网络安全产品及行业安全整体解决方案综合提供商。产品线目前涵盖密码类、安全类、通用类三大类共计二十余种产品，形成数据加密，国产自主可控，安全平台三大类产品体系，在高速加密技术领域领跑国际水平。其中“高速加密模组”、“卫星链路加密系统”在国内高速加密领域首屈一指；ARM存储服务器为国内首批采用ARM架构研发的分布式存储系统，紧跟国产自主可控发展形势；同时公司还积极开展底层基于国密算法的金融区块链平台开发项目及相关技术研发，引领国产区块链技术应用的发展趋势，可满足用户在不用领域的安全需求。可信计算环境、云计算安全、大数据安全移动互联安全等领域的需求。同时数盾科技与国内信息安全领域的知名科研机构、军地著名高校、国内外专业厂商共同成立10个实验室和研究院，建立了加密技术和信息安全领域产、学、研、用一体化的研发与创新体系模式，已为中石油、国家电网等行业设计实施了密码信息安全完整解决方案。
