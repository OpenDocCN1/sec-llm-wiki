# 【热点聚焦】卫达安全总裁张长河获得“金智奖”2018年度人物奖

张长河是北京卫达信息技术有限公司总裁。专注网络安全领域研究，带领团队全球首创基于“孙子兵法”+“人工智能”的“智能动态防御”技术，实现了网络安全行业垂直性创新，形成了面向边界安全、内网安全、网站安全、云安全、大数据安全、应用安全、工控安全等领域的全方位动态防御体系。

  

“金智奖”评选出的“十大金智产品奖”“十大金智企业奖”“十大金智人物奖”等系列奖项在过去的两年时间里已经成为行业普遍认可的荣誉，参与各奖项角逐的企事业单位和个人也逐年增多。参加本届“金智奖”评审工作的专家评委达到100位，有1000位专业评委参与推选。

**经评委评选，****北京卫达信息技术有限公司总裁张长河获得**信息安全与通信保密杂志社主办**中国网络安全与信息产业“金智奖”2018年度人物奖。**

**关于**卫达安全****

北京卫达信息技术有限公司（简称“卫达安全”）成立于2015年，总部位于北京，下设郑州研发中心，是一家拥有自主知识产权技术的国家高新技术企业、中关村高新技术企业。卫达安全全球首创“智能动态防御”（AI Dynamic Defence）技术，颠覆传统网络安全理念、打破原有网络安全防御被动格局、引领新型网络安全防御技术发展方向，致力于成为全球领先的网络安全技术服务提供商。公司核心团队从事网络安全技术研究近二十年，曾多次参与国家重大科研专项及国防网络安全建设，为奥运、十八大、G20、十九大等关键时期的网络安保工作做出了重要贡献。卫达安全凭借人才优势和技术优势和产品优势，自创立以来一直稳步高速发展，仅用不到三年时间便在业内占据重要地位。
