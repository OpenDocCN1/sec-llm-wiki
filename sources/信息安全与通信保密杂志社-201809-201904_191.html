【网安学术】一种基于DTN与MANET的交叉异构网络架构设计

摘要：针对基于延迟/中断容忍网络DTN（Disruption/ Delay Tolerant Network）与移动无线自组网MANET（Mobile Ad-hoc NETworks）混合异构网络建立问题，提出了一种混合异构网络模型架构，用于将两种已经被广泛应用的网络架构MANET网络和DTN整合到一个能够利用两者优势的统一网络架构中。MANET由于高效、方便等特点被广泛应用，但是由于节点的移动可能会导致节点之间的链路脆弱和长时间断开的可能，导致MANET效率低下甚至无法正常工作。DTN的解决方案是使用“存储-携带-转发”传输模型代替端到端的IP传输模型，即使存在间歇性连接，也能维持数据的传输。基于DTN与MANET的网络协议栈特点，通过将应用层与适配层结合，合理利用两者的优势建立了混合网络模型架构。最后，对该架构模型进行实现，并进行了简单的评估，说明了该架构的潜在优势。

0 引 言

随着人们对信息需求的增加，随时随地的信息交互变得尤为重要。网络部署正迅速扩展到标准TCP/IP协议不能很好支持的移动ad-hoc网络（Mobile Ad-hoc NETworks MANET）。在这些网络中，节点与节点之间形成的链路由于节点的移动变得脆弱。基于TCP/IP协议的移动无线自组网络MANET在没有稳定可靠的端到端链路存在的情况下，表现不佳，甚至无法正常工作。


中断/延迟容忍网络（Disruption/Delay Tolerant Network，DTN）是从ad hoc网络中抽象出来的一种全新的网络模型。与传统的无线移动自组织网络不同，该网络模型应用场景具有高延迟、易中断等特点。高延迟、易中断的网络环境被称为受限网络。DTN作为一个针对受限网络的新兴研究领域，其使用特殊的“存储-携带-转发”模式进行数据传递，以对抗受限网络中延迟和中断带来的影响[1]。DTN的发展将对未来军事战争、航天通信、抢险救灾等诸多场景，提供更为可靠的通信保证。但是，由于其特殊的转发模式，导致数据不得不进入到DTN的bundle层中缓存后再进行转发。此外，为了追求较高的数据包到达率，不得不生成大量洪泛消息，造成了额外网络开销。因此，在链路可靠的网络中，DTN的性能远远不如MANET等其他一些网络架构。


本文希望能将DTN网络与MANET网络集成到一个统一的网络架构中。这种网络架构既拥有MANET在稳定网络中的优异性能，又能拥有DTN应对链路潜在中断的能力。目前，基于DTN与MANET的异构网络主要使用一种平行网络架构，通过在源节点设置适配层，根据网络状态选择合适的网络架构进行转发数据。在这种架构下，DTN与MANET彼此相互独立，两者之间不会相互干扰[2]。这种架构的优势是操作简单、便于实现，但是DTN与MANET切换不够灵活，导致许多设计的基于DTN与MANET的混合路由协议方案不能在这种网络架构下有效实现。


本文提出了一种交叉混合网络架构。首先在传统平行网络架构基础上提出了一种垂直双重路由异构体系架构模型。该架构通过将两种网络架构中的相似部分进行整合，建立双重路由表将两者有效融合，形成了一个灵活、易于设计实现的垂直网络架构。同时，为了能够更有效地提升网络性能，本文将该垂直结构与平行结构相结合，形成了一种全新的交叉混合网络架构模型。


1　DTN以及MANET网络架构分析


MANET经过多年发展，已经形成了一套较为完善的体系结构和配套服务，并且得到了广泛应用。DTN体系结构是IRTF（Internet Research Task Force）在星际网络研究基础上发展而来的，最初作为星际通信服务被提出，后来研究人员希望将它发展为解决受限网络的一种通用解决方法[3]。DTN与MANET由于网络架构的不同，导致其各自有着一套完全不同的传输模式。


1.1　MANET网络架构


MANET网络架构使用包括应用层、传输层、网络层、数据链路层和物理层五层网络架构。路径上的每一跳都使用不同的物理层和数据链路层，但是IP协议在所有节点上运行，TCP（Transmission Control Protocol）协议只在源节点与目标节点上运行[4]，如图1所示。



1.1.1　应用层


应用层是网络应用程序及其应用层协议存留的地方，主要功能是提供面向用户的各种应用服务，包括具有严格时延和丢失率限制的实时应用、基于RTP/RTCP的自适应应用和没有任何服务质量保障的数据报业务等。


1.1.2　传输层


传输层负责为信源和信宿提供应用程序进程间的数据传输服务，向应用层提供可靠的端到端服务，使上层与通信子网相隔离，并根据网络层特性高效利用网络资源。这一层主要定义了两个传输协议——传输控制协议TCP和用户数据报协议UDP（User Datagram Protocol）。但是，在MANET网络中，无线信道的衰落干扰、节点移动等因素会造成报文冲突和丢失，严重影响TCP的性能。因此，研究人员在有线的传输层协议上添加了包括复用、流控、按序交付、重传控制和拥塞等机制，以满足数据传输的需要。


1.1.3　网络层


网络层负责将数据报独立从信源发送到信宿，主要功能包括邻居发现、分组路由、拥塞控制和网络互连等。邻居发现主要用于收集网络拓扑信息。路由协议的作用是发现和维护去往目的节点的路由。


1.1.4　数据链路层


数据链路层负责将IP数据报封装成适合在物理网络上传输的帧格式并传输，或将从物理网络接收到的帧解封，取出IP数据报交给网络层。在MANET网络中，数据链路层中MAC子层规定了不同用户如何共享可用的媒体资源，即移动节点对无线信道的访问。一是信道划分，即如何把频谱划分为不同的信道；二是信道分配，即如何把划分的信道分给不同的用户。逻辑链路控制子层负责向网络提供统一服务，屏蔽底层不同的MAC方法，具体包括数据流复用、数据帧检测、分组的转发/确认、优先级排队、差错控制和流量控制等。


1.1.5　物理层


物理层负责将比特流在结点间传输，即负责物理传输。该层的协议既与链路有关，也与传输介质有关。在MANET中，它的主要功能包括信道的区分和选择、无线信道的监测、调制解调等。传统基于TCP/IP协议的MANET网络架构的平稳运行主要依赖三个主要的底层链路特性：


（1）源节点与目的节点间存在稳定的端到端链路；


（2）任意节点之间的最大往返时间RTT（Round Trip Time）较小；


（3）数据报文在传输过程中丢失概率较小。


然而，在一些特定的通信环境中，如节点移动速度快、移动范围广的网络或受干扰的通信网络等，这些条件难以满足。


1.2　DTN网络架构


DTN在传统的五层协议栈的基础上增添了Bundle层协议栈。该协议层位于传输层之上、应用层之下，满足数据传输和缓存的需要。该层的主要功能包括以下六点[5]：


（1）保管传递：节点具有保存数据和给其他DTN节点传递数据的功能；


（2）接收回复：目的节点收到数据后，给源节点发送确认信息；


（3）保管传递通知：中间节点收到上一跳节点发送过来的数据后，给上一跳节点发送确认通知；


（4）束转发和通知：当需要转发数据时，给下一跳节点发送确认消息；


（5）传递优先级分类：DTN根据数据的紧急程度，提供不同的传递优先级；


（6）认证：验证发送者身份和数据完整性。


源节点在发送数据前，将数据存储到Bundle中，并给该数据包加上一个标记，注明该包的目的节点ID。在该DTN的路由中，设置了相应的路由转发表，标记了通往该目的ID的下一跳节点的IP地址。通过查看数据包的目的ID，找到对应的转发的下一跳节点的IP地址。下一跳节点收到数据包后，首先将数据包送至Bundle中进行缓存，再通过查看数据包的目的ID，寻找下一跳节点的地址，将数据转发至下一跳节点。使用这种逐跳转发的模式，直至将改数据包传送至目的节点[6]，如图2所示。



2　基于MANET与DTN的混合交叉网络架构设计


目前，混合体系架构的网络模型大都使用一种平行的结构。在这种架构下，DTN与MANET彼此之间相互独立。这样的设计能够简化设计流程，源节点只需要在应用层之下添加一个适配层，通过在适配层设计协议区分到达适配层的数据应该使用哪种网络模式转发。但是。这种方法导致DTN与MANET两种架构之间不能灵活切换，一些设计的混合传输协议不能有效付诸实践。


针对这个问题，本文提出了一种DTN与MANET的交叉异构网络模型，如图3所示。



在这个交叉异构网络模型中，本文首先提出了一种垂直双重路由异构体系传输模型，如图3的Link1所示。在这个架构中，DTN与MANET不再相互独立，DTN的Bundle协议建立在MANET协议基础上，DTN的路由表以MANET路由表为基础建立。在DTN路由建立过程中，节点通过检查数据包的目的ID，在其自身的DTN路由表中获得该ID对应的下一跳IP地址。此时，在系统的底层维护着由MANET建立的系统核心路由表。Bundle层检查系统的核心路由表，查看该IP地址是否可达。当通往下一跳IP的链路可用时，使用MANET协议将该数据包送至下一跳节点的Bundle中进行缓存。当无可用链路时，数据被存储至本节点的Bundle中，等待可用链路的建立。中间节点在收到DTN数据包后，MAC层检查数据包的目的MAC地址。如果是自己的，继续往上层传送至Bundle中。Bundle中的DTN协议查询数据包的目的ID，通过目的ID，在其自身路由表中寻找下一跳转发节点的IP，继续往下传送。IP层检查目的IP地址是自己的就往上送，不是自己的则查询MANET建立的核心路由表，有路由则直接进行转发。使用这种垂直结构，DTN的转发路由表建立在MANET的路由表基础上，因此数据包传输使用的网络架构在中间节点上切换的过程不需要增加额外的组件。


由于在这个垂直双重路由异构网络体系传输模型中，所有的数据都需要进入到源节点与目的节点的Bundle中进行缓存，因此在一些连接可靠的网络中，该垂直混合网络的性能比直接使用MANET性能低。受DTN与MANET的平行网络架构思想的启发，为了解决这个弊端，本文在该垂直结构中加入一个与该结构相对独立的MANET架构，作为该垂直架构的补充，如图3中Link2所示。该平行结构与之前提出的垂直结构（图3中Link1）平行且相对独立，两种架构互为补充，提高了网路性能。在该交叉异构网络模型下，节点的网关模型如图4所示。



3　架构的实现与性能分析


为了验证该交叉异构网络架构的可行性，本文实现了这种架构，并且通过实验得出了这种架构的潜在优势。


3.1　硬件设备


实现使用硬件为树莓派3b，操作系统为基于14.2 linux内核的raspbain操作系统，信道使用树莓派自带的WiFi信道。树莓派具有设备廉价、性能强大、方便携带等特点，因此受到嵌入式开发人员的广泛欢迎。


3.2　软件


软件使用DTN2作为DTN网络架构的协议源码。该应用实现了DTN的bundle层协议，数据在DTN节点间以DTN中Bundle协议所定义的格式进行传播，在这里称DTN的数据包为束。DTN2继承了应用层与Bundle的功能，工作在系统的核心协议层之上。因此，束可以传输在IP传输层上或是其他链路层。利用DTN2以及系统的底层协议栈搭建的网络实现了如束的转发和接收等功能。为了验证协议的可行性，本文对DTN2提供的路由算法进行改进，数据包目的节点ID指定的下一跳IP为MANET建立的核心路由表中能够到达的所有IP地址，本文将这种路由算法称为局部洪泛算法。


MANET使用目前较为成熟的OLSRd作为本文的协议源码。该源码为MANET路由协议OLSR的实现。OLSR（Optimized Link State Routing Protocol）协议是LS（Link State Routing Protocol）路由协议的改进，节点之间通过周期性的交互状态信息维护整个网络的拓扑信息，其中OLSR的关键概念是多点转播MPR机制。只有MPR节点才会向全网广播TC控制消息和链路状态信息，而LS路由协议每个节点都会转发它收到的消息的第一份拷贝。因此，与LS相比，OLSR协议优化了网络中洪泛消息的数量，降低了网络开销。同时，OLSR的维护只用了部分链路状态信息来建立最短链路，降低了拓扑维护的成本和协议的开销。


适配层的主要功能是为数据包找到最快到达目的节点的传输方式提供服务。本文设计了一个较为简单的适配层协议，所有节点的适配层在收到应用层发来的数据包后，检查该数据包的目的节点ID，并将该目的节点ID映射为对应的目的节点IP地址。适配层检查底层系统核心路由表是否有通往目的节点的可用链路，如果有，则直接调用MANET网络架构接口，将该数据包传输至目的节点；如果没有，适配层则将数据包存储至DTN的bundle层中进行缓存，DTN将其路由设置为该数据包的下一跳转发节点的IP地址，将其作为目的节点的IP地址。同时，Bundle层的协议代理循环检测系统的核心路由表，一旦有通往目的节点的可用链路，将Bundle中的数据包使用MANET的方式传至目的节点的Bundle层中。使用这种方式，当该节点移动至可与目的节点形成链路的位置时，Bundle中的数据可以通过MANET建立链路传输至目的节点的Bundle中，且可以通过更改DTN路由达到DTN与MANET切换的目的。


3.3　实验流程


为了验证该混合交叉架构的有效性，本文设置了两个简单的验证性实验场景。实验节点为5个，DTN的ID分别为Pi1、Pi2、Pi3、Pi4、Pi5，IP地址分别为192.168.1.1～192.168.1.5。通过设置将使用不同网络架构传输过来的文件放至不同的文件夹中，以确定该文件使用哪种方式传输到目的节点。


场景1。源节点Pi1在传输前与目的节点Pi5可以形成可靠链路，如图5所示。Pi1节点以Pi5节点为目的节点发送数据，在Pi5节点处检查接收结果，并且在所有节点上使用Wireshark抓取数据包查看结果。


场景2。源节点Pi1在传输前与目的节点Pi5没有可用链路，如图6所示。Pi1节点以Pi5节点为目的节点发送数据，之后Pi1节点移动至可以与Pi5节点形成链路处，但与Pi5不在一跳范围之内，如图5所示。在Pi5节点处检查发送结果，并且在所有节点上使用Wireshark抓取数据包查看结果。




3.4　实验结果及结果分析


场景1与场景2均能在Pi5处接收到Pi1发送过来的文件，且可以在Pi5通过查看数据包所存放的位置得到。场景1中，数据通过MANET传输至目的节点Pi5；场景2中，数据通过DTN方式传输至目的节点Pi5。在两次实验中，在所有节点上使用wireshark进行抓包，可以得场景1所有节点使用MANET网络架构将数据从源节点Pi1传递至目的节点Pi5，场景2则使用了垂直双重路由体系架构，Pi1与Pi5作为DTN节点发送和接收数据，Pi2与Pi4以MANET的方式传输DTN的数据包。可见，这验证了本文提出的架构的有效性。DTN2的Bundle层协议建立在OLSRd建立的底层协议基础上，利用这种双重路由协议，DTN与MANET达到了有效的结合和灵活的切换


4　结　语


本文基于MANET与DTN网络架构，综合考虑两种网络的结构特点，且结合实际应用的需要，提出了一种异构交叉网络架构模型。该模型集合了传统的平行架构网络模型，提出了一种全新的垂直架构模型，即利用垂直与平行两种架构将DTN与MANET两种网络有效结合到一起，以此达到两种架构灵活切换的目的。最后，利用现有的资源对该架构进行实现，验证了该架构的有效性。


未来移动无线通信网络的应用会越来越广泛，应用环境也会变得越来越错综复杂。该架构的提出为未来的研究者们提供了一个良好的解决思路，为未来的异构网络设计打下了良好的基础。
