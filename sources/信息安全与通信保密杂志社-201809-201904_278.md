# 【理事动态】紧追华为 勇攀高峰——六家理事单位跻身全球网络安全企业百强

 12月下旬的上海，临近元旦，节日的气氛日渐浓厚，时间正在期待着翻开新的一页。而12月19日在这里举行的2018网络安全产业创新（上海）论坛，却已经迫不及待的为中国的网络安全产业打开了全新的篇章。

![](../Images/cbf2160236049d88ebc06551b905da21.png)

12月19日，由上海赛博网络安全产业创新研究院出品的《2018全球网络安全企业竞争力研究报告》和《2018全球网络安全产业投融资研究报告》在2018网络安全产业创新（上海）论坛上正式发布，两份研究报告试图为我国网络安全产业发展提供启示和借鉴。

在评选出的全球网络安全百强企业中，六家杂志社理事单位脱颖而出跻身百强，分别是启明星辰、卫士通、360企业安全、绿盟科技、蓝盾股份、山石网科，占据了中国入榜企业的三成的席位。

![](../Images/f704067ccd506ba5531c27d285d6ac35.png)

 《企业竞争力报告》提出了“赛博竞争力指数”评估指标体系，对全球31个国家和地区的共500家网络安全企业进行了竞争力评价。在百强榜中微软排名第一，美国企业数量最多，位列前十的企业中有七家企业来自美国，中国企业上榜的共有17家，数量仅次于美国，其中华为位列榜单的第八位。
