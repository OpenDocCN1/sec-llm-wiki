# 【网安智库】平行世界的平行安全 ——基于 CPSS 的生成式对抗安全智慧系统

智能技术到现在已经进入了新的时代，人工智能发展的三个阶段都是从图灵机延伸出来的，是一个假设，AlphaGo 没有任何技术的创新，只是做同样的事情。这个智能趋势有三个“三”，第一个是三个 IT，IT 不再是信息技术了，是旧 IT，现在的 IT 是智能技术，大家不要忘了 200 年前，IT 叫工业技术。说起来都是一样的。第二个“三”是三个世界。上个世纪最伟大的哲学科学家卡尔•波普尔提出三个世界理论，一个是物理世界，第二个世界是心理世界，信息技术就是开发心理世界的技术。我们现在到了开发人工世界的时候，所以人工智能变成一个热点，所以我们需要新IT。第三个“三”是三个轴心，在时间这个轴上我们进入一个新的时代，卡尔•雅斯贝斯在《历史的起源于目标》中提出一个轴心时代的概念。每个世界都应该有自己的轴心，心理世界的轴心是由科学一点点去提，但是发现这个理性也有限，所以需要新的东西来补充。所有这些都是因为全球化中，第一波的全球化物理世界，物理世界考验在哪儿？你有了我就没有了，这本身是一个负荷。自由贸易也走到头了，先打日本，现在“打”中国。人工世界是无中生有的世界，你也可以我也可以。第三波是智能化全球化，是我们进入的第三个，手段上、空间上一直到时间上。

  

为了利用这个时代，我们还有五个“五”。第一是五张网。其实最早的互联网就是交通网，后来又来了能源网、互联网，现在又来了物联网，大家认为区别没有多大，其实区别很大。到了物联网是再联的，我们人类一定要主联，所以有了智联网——指导的连接。安全必须从这五张网考虑，这就是我们的武器，于是一来整个形态就变了，交通从优步开始，一直到 OFO。这就是一个技术，社会形态，于是五张网把三个世界密切连成一个整体，我们处于中间 3.0，通过 2.0 到物理世界拿来能源，通过 4.0 到人工世界拿来支持，所以形成了完全打通、不一样的世界，安全的概念是五度安全的空间，所以是 CPSS，不是 CPS，而是 CPSS（社会物理信息系统），将来的安全一定要以这个新的“S”为主。数据的力量、网络的力量，区块链一定要放到里面，如此才能自然而然走到工业 5.0 时代。

  

5.0 跟德国的 4.0 本质上是一样的，都是叫ICT+CPS。关于 ICT 和 CPS，大家的理解不一样，以前的人理解为信息技术、工业化。下面要靠知识走，那是一个新的十年，是一个“S”，人、社会，人之间的关系合起来就是整个社会，一定不能丢。

  

智能时代需要智能基础设施、CPSS 和 X5.0平行地“合一体”，即人机结合、虚实合一、知行合一。物理世界我们有核威慑，普遍认为矛盾再往下走就是战争了，我觉得战争可能性不大，因为我们有“核威慑”，能够在将来通过区块链建立“信威慑”，将来还有“知威慑”，所以安全不是百分之百的安全，要 300% 的安全，物理世界的安全，心理世界安全，还有人工智能的安全。

  

我们要考虑两种系统——默顿系统和牛顿系统。将来的安全要知道默顿定律，引导大家走向安全，它本质就是大数据的运用，大数据两句话三件事，最后说多了就变成人工社会了。光大数据不行，大数据要变成区块链，在土基或者沙基上是盖不高的。所以区块链给我们送来了建智能大厦的“钢筋混凝土”，这就是我们从 2004 年开始做的。

  

10 多年前在国际上成立数据资产保护协会办学习班，最重要的目的是吃一堑长一智，现在在物理世界吃一堑，在知识世界长一智，我们通过平行的方法反着来，在知识世界吃一堑，在物理世界长一智。不要大家有了损失才知道，所以要平行的安全。在学习班中，黑客、白客、红客一起打，生成大数据、小数据。它的核心一定要上道，而且是真道。真 (TRUE) = 可信(Trustable) + 可靠 (Reliable) + 可用 (Usable) + 高效 (Efficient + Effective)。道 (DAO) = 分布式与去中心化 (Distributed, Decentralized) + 自主性与自动化 (Autonomous, Automated) + 组织化与有序性(Organized, Ordered)。以正确的方式做正确的事，这才上道了，分布式的去中心其实是确立中心。最后的目标像鲁迅说的，“于无声处听惊雷”。我们把平时安全的小数据搞成大数据，最后再提炼成保护大家安全隐私的小智能。
