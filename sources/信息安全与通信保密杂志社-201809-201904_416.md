# 【热点聚焦】物联网时代渐近 边缘计算走向中心

在人工智能时代，计算力也就是数据处理能力，已经成为重要的生产力。随着智能设备的不断普及，提升计算能力已经成为众多科技公司的主要努力方向之一。在10月23日至26日举行的中国国际社会公共安全产品博览会上，记者看到，不少科技公司正发力研究边缘计算这一新型计算方式，为即将到来的物联网时代布局。

  

当前，云计算已成为耳熟能详的计算方式。有报告认为，中国的云计算市场规模已经突破千亿元大关。然而，云计算模式也存在不少技术瓶颈。有专家认为，随着物联网技术的普及，智能设备将大量出现，对计算能力的要求将出现爆发式增长。预计到2020年，将有500亿台设备连接到网络，在此背景下，传统的云计算架构难以满足庞大的计算需求。此外，云计算存在的网络延迟问题，也将难以应对自动驾驶等新兴智能设备运行方式的要求。

  

本届安博会上，著名人工智能创业企业地平线发布了XForce边缘AI计算平台，可实现人脸和人体抓拍识别、人体行为分析等功能，可广泛应用于安防等场景。

  

地平线创始人、CEO余凯认为，随着物联网时代的到来，边缘计算将成为一种趋势，与云计算形成互补。“传统的云计算模式是数据被终端采集后传输汇集到集中式云计算中心，计算后再返回结果，存在网络延迟导致的延时性。如果你进行自动驾驶，需要及时响应，延迟很可能会导致致命错误。”

  

边缘计算的核心理念是将数据的存储、传输、计算和安全交给边缘节点来处理，但是边缘计算并非让终端自己完成所有计算，而是在离终端更近的地方部署边缘平台，大量实时的计算将在边缘节点完成，需要集中式处理的计算则交由云计算中心进行，边缘计算与云计算分工协作，满足物联网时代的计算需求。目前，包括云计算三巨头亚马逊AWS、微软AZURE和阿里云在内的众多科技公司都已在边缘计算上进行布局。

  

“除了响应时间快以外，边缘结算还可以节省大量的带宽，大大降低服务器端的负载。各种智能设备层出不穷，它们都有负责采集数据和互联互通的传感器，要作出响应就需要大量的数据处理，边缘计算将会分摊其中的部分任务。”余凯介绍说，“由于缺乏高性能、低能耗的边缘人工智能处理器，所以边缘计算目前占比较低，但是未来越来越多的计算会出现在前端，我们高度看好这一趋势。”
