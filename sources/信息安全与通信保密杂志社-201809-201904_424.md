# 【产业动态】诚信密码科研，服务共建共享共治新格局

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247544839&idx=3&sn=850c9f31435384135399a4c83ddde82f&chksm=c0b4ea71f7c36367abda9e9b6270d4166c25570c775d7ce9ea1f6b20e4b288ead969be44db36&scene=126&sessionid=1681312307#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247544839&idx=3&sn=850c9f31435384135399a4c83ddde82f&chksm=c0b4ea71f7c36367abda9e9b6270d4166c25570c775d7ce9ea1f6b20e4b288ead969be44db36&scene=126&sessionid=1681312307#rd)

2018年5月30日，中共中央办公厅、国务院办公厅印发了《关于进一步加强科研诚信建设的若干意见》，为加强科研诚信建设、营造诚实守信的良好科研环境提出指导思想、基本原则、主要目标和具体要求。“人无信不立，国无信不兴”，科研诚信是科技创新的基石，密码作为网络安全的核心技术，是保护国家安全和根本利益的战略性资源，建立科学规范、诚实可信的密码科研环境意义重大，关乎国家安全、国计民生和公共利益。

为了全面落实中央精神，培育和践行社会主义核心价值观，弘扬科学精神、倡导创新文化，进一步推动密码科研诚信建设，营造诚实守信的密码科研环境，密码主管部门将组织密码科研诚信体系建设，2018年7月27日至29日，中国密码学会在“2018年密码数学理论年会”上发布了《密码科研诚信倡议书》，以全面落实中央精神，培育和践行社会主义核心价值观，弘扬科学精神、倡导创新文化。**倡议内容如下：**

**一、惟诚惟实，谨遵学术道德**

科学技术研究是崇高而伟大的事业，需要品德高尚、诚信守诺的人来从事。密码科研工作者应始终保持理性真诚，弘扬严谨诚实的科研作风，不自欺、不欺人，尊重科学事实和发现，不受外部因素的诱惑和干扰，不隐瞒自己的真实见解；充分尊重他人学术成果和知识产权，恪守学术规范，严守职业道德；对科研事业存虔敬之心，抱敬畏之情，独立客观公正开展工作，从自身做起努力捍卫学术尊严，并合力打造清朗诚信、实事求是的学术空间。

**二、规行矩步，弘扬科学精神**

密码是一门实践应用科学，来不得半点虚假。密码科研活动需要始终践行科研诚信要求，以科学的态度对待科学，以真理的精神追求真理，老老实实做学问，积极接受社会监督，坚决规避各种学术不端行为。在科研工作中始终以事实为准绳，不伪造、不篡改研究数据；以诚信为底线，不抄袭、剽窃、虚构同行评议专家及评议意见；以贡献求认可，不强制在未作出实质性贡献的科研成果中署名，不虚构成果骗取国家科研经费资助，不擅自标注或虚假标注科技计划；以公正树声名，在作为同行评审他人成果时，不代入个人偏见，不搞暗箱操作和利益交换。

**三、皓首穷经，勇攀科技高峰**

密码科研已经进入一轮新的热潮，量子计算、人工智能等新技术的突破性发展在给传统密码带来严峻挑战的同时，也开辟了科技创新的蓝海空间。广大密码科研工作者要把论文写在祖国的大地上，把科技成果应用在实现现代化强国的伟大事业中，牢牢抓住战略机遇，坚持创新驱动，增强创新自信，以敢为天下先的志向，潜心钻研、无惧试错，不断在攻坚克难中追求卓越，创造引领世界潮流的密码科技成果，在世界密码科技领域发出中国声音，为丰富人类知识宝库贡献中国智慧。

与会专家纷纷对该倡议书的内容发出响应，认为科研诚信是科技创新的基石，广大科技工作者应潜心研究、遵守学术规范，为密码科研工作做出贡献。

科学研究从本质上讲是人类为了探索未知、追求真理而进行的系统的、创造性的活动。不论是从科学研究的“初心”看，还是从开展科研活动必须秉持的科学精神和科学方法来看，科研诚信都是题中应有之义。而科学研究本身也就是一个去伪存真，不断质疑、不断发现、不断探寻真善美的过程，其中本应是容不下任何不端行为的。随着社会的发展和科学的进步，特别是从二十世纪四、五十年代以来，科学研究的深度和广度突飞猛进，需要的资源越来越多，组织化程度也越来越高。另一方面，由于科学研究的成果极大地促进了技术进步，各国政府、企业和社会公众越来越关注科学研究，经费和各种资源的投入也越来越多。这些都有力地推动了现代科学研究的发展，但同时也给科研工作者带来了许多诱惑。

那么青年科技工作者该如何做好科研诚信工作呢？中国密码学会理事长、北京大学教授王杰老师表示，科研诚信无疑与科研人员自身的道德水准密切相关。老一辈科学家淡泊名利、严谨求实的风范是对年轻科研人员最好的科研诚信教育。反之，个别导师本身的不端行为也必然会给其学生带来负面的影响，而其中的一些学生很可能就是未来的科研人员。中国历来有“身教重于言教”的说法。因此，从自身做起是每个科研人员在恪守科研诚信中应该做到、也可以做到的事情，同时也就是对年轻一代的引导。应该尽早地对学生（也就是未来的科研人员）进行学术道德规范方面的教育，让他们很具体地明白在日常的科研活动中，哪些是要坚守的，哪些是不能逾越的底线。除了正面的教育引导，对于不端行为的“零容忍”非常重要。“针尖大的窟窿可以透过斗大的风”，“千里之堤毁于蚁穴”，讲的都是这个道理。对于哪怕是再小的不端行为的容忍，都是对坚持科研诚信的绝大多数科研工作者的惩罚！因此，国家需要从法律和制度层面对于科研诚信予以明确的规定，政府主管部门、科研资助机构、大学和研究机构等都应该建立健全严肃认真的关于科研不端行为的调查处理机制。

“要加强宣传、教育、引导、惩戒，让青年科技工作者真正重视科研诚信的问题，这是一条红线，任何人不论何种理由和借口不得触碰。另外，有关组织和学术团体也可以制定一些基本学术规范的规则条例，这对青年学术很重要，可以避免青年人走弯路。”杭州师范大学陈克非教授补充道，学术不端行为国外也有报道，韩国曾经出现过声称在生命科学领域取得重大突破，但后来发现很多实验数据造假，事情暴露后身败名裂永世不能在学术圈立足。欧美也出现过影响重大的学术不端事件，其结果不但身败名裂，甚至要有法律风险并受到刑事追究。我们国内这种事情越来越多，但很少真正受到追究因此愈演愈烈。除了常见的学术不端弄虚作假之外，很多人喜欢借助媒体以及官员好大喜功的心理，明明还在进行实验性的探索，却偷换概念夸大为工程实践应用上的突破，欺骗无知群众。科研诚信就是一条高压线，信守诚信就是科研学术的根本，违规行为必须付出代价。

由于对科技工作者的评价标准存在不科学的现象，为出现科技不诚信提供了土壤。现在社会上很流行利用一些简单的数量指标衡量科技工作者的水平，例如发表论文的篇数，申报专利的项数，取得科研项目的个数，以及得到科研经费的量数等。因此，广州大学教授、博士生导师裴定一教授建议，年轻人在规划自己的人生时，遵循先辈诸葛亮在“诫子书”中所说的“非淡泊无以明志，非宁静无以致远，学须静也，才须学也，非学无以广才，非静无以成学”，防止受到社会上流行浮躁习气的感染。

“科研工作者从事科研活动，是追求创新和卓越的过程，是革新和发现的过程，是推动科学不断进步的过程。科研工作是神圣的，科研工作者应当求真务实，主动承担责任，同时秉承科研专业精神，自觉遵守科学研究的诚信要求。 ”中国科学院软件研究所吴文玲研究员谈到，科研人员在平时的科研工作中基金申请、发表成果等方面也要恪守一些原则，如基金申请应该针对学科领域的研究现状和存在科学问题，结合自身的研究基础和学术规划，提炼研究内容、研究方案和年度计划，发表论文应该准确标示参考文献。

对于科研工作的组织管理、基金项目的分配、检查、验收原则，吴文玲认为，我国科学资源主要依靠国家财政，政府科技管理部门直接参与资源分配，这使得我国的科研管理以行政为主导，“官本位”的思想凸显。管理部门应减少对学术界的干预和限制。完善科研评估，避免科研评估走形式。科研项目的检查和验收不要片面追求科研数量，“以量衡定”导致科学研究的浮躁和急功近利。另外，学术研究是一项长期工作，建议延长科研项目的考核年限，给科研工作者宽松的科研氛围，鼓励啃硬骨头，做基础性问题。

科学没有国界，但科学家有自己的祖国。一批批密码领域前辈学者以报效祖国为己任，刻苦钻研、学以致用，为党和人民作出了卓越贡献。中国特色社会主义进入新时代，让我们紧密团结在以习近平同志为核心的党中央周围，不忘初心、牢记使命，以诚立身，以信治学，投身建设密码强国的伟大事业，在实现中华民族伟大复兴中国梦的壮丽征程中不断谱写新的华彩篇章！
