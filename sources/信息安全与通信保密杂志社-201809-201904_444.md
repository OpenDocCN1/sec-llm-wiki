# 【网安智库】2019世界发展报告：人工智能致工作性质变革 需加大教育投入

15日，世界银行集团（简称世界银行）在深圳发布《2019世界发展报告：工作性质的变革》。报告指出，面对人工智能时代带来的工作性质变革，当务之急是各国政府加大对人口健康和教育的投资。  

自己的工作是否会被机器取代？我们这个时代的教育体系能否适应人工智能时代？世界银行最新报告显示，数以亿计的人们正在经历这类由于科技快速发展带来的工作和教育焦虑。

报告认为，随着创新进程的不断加快，技术渗透到生活的方方面面，人们正在经历新一轮不确定性的困扰。机器人正在接手成千上万的重复性工作，并将消除发达经济体和发展中国家中的许多低技能工作。“当前的许多小学生在成人后将从事今天根本不存在的工作”。但同时，技术也为创造就业、提高生产力和提供有效的公共服务开辟了路径。而新市场和新工作需要员工具备批判性思维和解决问题的能力，以及沟通和合作等人际交往能力，对人力资本提出了新的要求。

世界银行首席经济学家办公室局长詹思敏说，面对工作性质的变革，发展中国家需要迅速采取行动，怀着强烈的紧迫感投资自己的人民，特别是投资人力资本的基石——健康和教育，从而确保其在未来经济中的竞争力。世界银行集团的分析显示，在当今人力资本投资最低的国家中，未来劳动力的生产力仅为其享有全面健康并接受高质量教育时所能达到的生产力的三分之一至二分之一。

他建议各国政府加大对教育的投入，尤其要重视儿童早期发展。研究显示，对儿童早期的投资，包括对营养、健康、保护与教育的投资为他们在未来习得高阶认知技能和社会行为技能奠定了坚实的基础。从胎儿期到五岁，是大脑从经验中学习能力的巅峰期。在生命早期习得这类技能的个体，在未来的生活中更能适应不确定性。

然而，尽管儿童早期发展投资对培育儿童的重要技能非常有效，社会对儿童早期发展的投资力度仍然不足。报告显示，由于发育迟缓或者极端贫穷问题的困扰，低收入国家和中等收入国家中约有2.5亿左右五岁以下儿童会遭遇不能充分实现自己发展潜力的风险。

詹思敏表示，除了加大对儿童早期发展的投入外，各国政府还要加大对高等教育和终身学习的投入，以促使学校教育转化为学习成果，帮助人们适应重大技能再调整。
