# 【热点聚焦】开创新模式 锻造新安全 ——招商局集团网络信息安全整体保障服务项目 顺利通过阶段性验收

为积极践行“网络强国”国家战略，落实中央企业网络安全责任，9月27日，中国电科旗下的中国电子科技网络信息安全有限公司（简称“中国网安”）与招商局集团有限公司（简称“招商局集团”）在京召开完成招商局网络信息安全整体保障服务项目建设实施阶段验收评审会议。

  

![](../Images/e93cb2a63c1e985f469f5003aeb023cf.png)  

（验收会现场）

国务院国资委综合局信息化处处长陈建刚，中国电科副总经理李立功，招商局集团副总经理王宏，中国网安党委书记、董事长李成刚，招商局集团信息技术总监吴沂等相关领导出席会议。  

  

![](../Images/6c428eded27412f773636dd8e1882b6d.png)

（何德全院士）

会议由中国工程院院士何德全主持，来自中央网信办、公安部、交通运输部、国资委、国家密码管理局和中央企业等10余名专家组成的评审组，一致同意通过项目验收评审。评审组认为，该项目整体保障服务体系合理、架构清晰，采用新的服务运营保障模式实现了招商局集团网络信息安全由单点防御向系统防御、被动防御向主动防御的转变，打造了中央企业网络安全整体保障的典范。

  

招商局网络信息安全整体保障服务项目的建设实施阶段工作历时8个月，以服务化、平台化的方式打造招商局网络安全防御体系，首创中央企业网络安全整体保障服务新模式，更是中央企业之间合作共建的典范，为中央企业网络安全和信息化水平的整体提升打造“样板”，下一步进入7\*24小时的线上线下运维服务和实时、动态的主动防御服务，在实际运行中不断提升招商局集团的网络安全整体防御能力。

  

![](../Images/5ff868629c3051a0935f5230d8d2261d.png)

（李成刚）

李成刚表示，招商局网络安全整体保障项目首创了中央企业网络信息安全保障服务模式，是中国网安充分整合内外部优质资源，为招商局集团构建全方位的安全管控、安全防护、安全服务保障体系，构建起提升其网络安全防护水平和应对位置网络安全威胁的能力，确保“数字招商”战略成功实施。

  

![](../Images/8a6488a3710cf5ee5d648e8c7e041ef9.png)

（吴沂）

吴沂表示，招商局集团与中国网安开展网络安全整体保障合作的新探索，初步打造出了招商局集团全天候、全方位的网络安全防护和监测预警体系，双方共同成长，从而实现保障招商局的生产经营管理活动能够持续运行，数据资产能够持续安全的目标。  

  

![](../Images/b1f91e811db61a35ad2b3f9b7ec95d18.png)

（陈建刚）

陈建刚代表国务院国资委致辞，高度肯定了双方的模式创新，他谈到：招商局立足提升国有资产的抗风险能力，聚焦问题和目标导向，积极行动，打造数字招商局的铜墙铁壁，主动作为；中国电科所属的中国网安依托集成创新，创造网安产品，推动了网安产业进入了一个新的阶段，从产业的一维进阶、进化到二维，甚至三维，未来服务产品的系列化和标准化呼之欲出，令人振奋。  

  

![](../Images/8492d33d8932a0046805dc242e744a7d.png)

（李立功）

李立功表示，感谢在国资委机关的指导下，两家央企聚焦网络信息安全主题，合力打造和践行央企网络安全整体保障服务的新模式；感谢招商局集团把这样一个重要任务交给电科，交给中国网安公司来完成，体现了招商局集团的魄力、高度和胸怀。同时提出三个“直面”，直面创新过程中遇到的问题，持续优化，实现招商局集团整体保障服务的有效运行；直面网络安全痛点需求，切实实现网络信息安全的整体保障；直面国家层面的网络安全需要，通过强强联合，实现央企合作的一个典范，形成长远的品牌效应和影响力。

  

![](../Images/016a72ac0650269a30bfc5de495be844.png)

（王宏）

王宏表示，感谢国资委对招商局集团网络信息安全工作的指导和关怀，感谢中国电科集团对本项目的高度重视和大力支持，将最优秀的网络安全技术和服务融入到招商局集团网络安全保障体系，推动招商局集团网络安全保障水平再上一个新台阶。招商局集团在推动全球化布局过程中，网络安全面临严峻的挑战，在与中国网安合作建设的网络信息安全整体保障服务项目为全面推进信息技术对招商局集团交通、金融、房地产等全体业务赋能奠定了安全基础，同时为招商局集团及其他央企探寻出一套依托“国家队”保障网络安全的新模式。

  

![](../Images/65933210c7845c328184e92f7247ea75.png)

（双方企业代表合影）
