# 基于面向5G网络的边缘计算技术研究

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247545143&idx=1&sn=300e8e9c1fb580640917118375c532f8&chksm=c0b4eb41f7c36257787047ee7468b627ba04f0b37564cf56e239f9797335d87d0d071ccc8d60&scene=126&sessionid=1681312251#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247545143&idx=1&sn=300e8e9c1fb580640917118375c532f8&chksm=c0b4eb41f7c36257787047ee7468b627ba04f0b37564cf56e239f9797335d87d0d071ccc8d60&scene=126&sessionid=1681312251#rd)

**对总体框架提供思考**

随着物联网终端应用的丰富，人们对数据传输时延和数据处理的要求越来越高，而第五 代移动通信技术(Fifth-Generation, 5G )可以很好地缓解数据处理问题。

5G网络技术中引入边缘 计算，通过运用网络传输技术更好地进行计算、存储和应用软件，使输出的过程更加高效和智能， 并能更好地保证隐私服务。首先介绍5G网络和边缘计算技术的关系和边缘计算产业进展，其次全 面阐述面向5G网络的边缘计算技术结构构成和应用，最后结合典型场景分析边缘计算的总体框架， 希望能够提供参考。

随着通信技术的不断发展，智能终端技术已经 在人们的日常生活中发挥着越来越重要的作用。目 前，包括智能电表和共享单车等设备也已经运用于 包括交通、能源和智能的多个行业中。  

如果能够在 之后通过云计算数据部署相关业务应用，就可以通 过运用智能终端技术直接访问移动云计算空间，并在建设过程中给人们带来更大的便利。但是，复杂 多变的计算任务不仅能够带来更大量的数据传输， 更会造成数据传输出现延迟的作用。本文主要探讨 面向5G网络的边缘计算技术，以期提供参考。**研究背景**

5G除了能够在建设过程中提供更加可靠的网 络，更是未来万物互联网发展的基础。5G网络的 传输速度可以实现1 Gb/s,比现在流行的4G快上 很多倍。  

在当前4G环境的延时通信下，汽车行驶 的距离只需要几厘米，这样的延时往往能够为后续 无人驾驶提供更好的条件。与4G相比，5G将会产生更低的延时和更海量的接入能力。未来的5G可以更加广泛地被运用于生活的方方面面。5G的广泛应用可以影响我国各 行各业的发展田。

但是，边缘设备也会直接影响5G 技术的应用，甚至开始承担计算的任务。5G除了 会对各行各业的发展产生影响，甚至也会在之后对 传统计算模式产生影响。本文主要基于面向5G网 络的边缘计算技术进行研究。

**5G网络和边缘计算技术的关系**

4G技术后，移动通信技术促使物联网技术得 到广泛应用。随着物联网规模的快速增长，集中处理的计算机处理模式将会面临更大的瓶颈和压力。这时靠近数据所产生的边缘设备将开始提供一些最 基本的数据处理能力和服务能力。这种网络边缘提 供数据和处理数据的能力称为边缘计算。  

正是因为5G时代的到来，物联网时代进入了 新的发展过程。移动网络内部的业务在不断增加， 此时的业务量几乎是呈现几何式的增长。传统的空间和计算方式已经不能够满足要求。边缘计算是通 过提高传输的效率来满足用户需求而存在的。**边缘计算产业进展**

目前 OICT ( OICT=运营技术(Operational Technology ,OT ) + 信息技术(Information Technology, IT ) + 通信技术(Communication Technology, CT )) 各个领域的巨头都已经开始布置边缘计算产业。  

在互联网云计算领域，各个厂家都直接将平台即服务 (Platform-as-a-Service, PaaS )的能力延伸到边 缘，并为用户提供边缘化的计算套件。目前，在整 个0T领域内，各个厂家都不断地委托用户到现场 采集数据，再将数据有效地积累在一起，从而更好 地控制边缘业务内部的数据入口。在德国成立的电信公司一直都专注地研究边缘 计算的技术和相关产业。而国内的诸多运营商也开 始不断研究边缘计算方案和有关试点。

但是，目前 整个边缘计算产业的技术还属于需要被完善和探索的阶段。相信将来会随着5G和工业互联网的发展 而使得边缘计算机产业变得更加成熟。

**面向5G网络的边缘计算技术**

目前，面向5G网络的边缘计算技术主要是由 如下几个层次的结构构成。  

**4.1基础资源层**边缘计算平台(Edge Computing Platform, ECP ) 架构一直都在基础资源层中占据着非常重要的地 位，甚至直接发挥作用。整个基础资源层由硬件资 源层和虚拟资源层组成。X86通用服务器一直都在ECP硬件资源层中发 挥着重要作用，甚至能够在一些特殊场景下被使用。但是，如果需要处理与视频图像有关的边缘计算应 用业务，则需要运用CPU处理器直接提高其处理能力。另外，业内的专业人士一直都在不断研究边 缘计算机中所使用的服务器吐 但是由于网络边缘 的位置和机房空间的限制，边缘位置对于硬件资源 的需求普遍变得更小。所以，从实际发展的情况来看，ECP硬件设备在使用过程中具有一定的优势。另外，虽然虚拟机在ECP虚拟资源层中一直 都被广泛地应用，而且整体将会表现出较强的隔离性，但是ECP虚拟机本身的隔离安全性显得非常差。因为边缘计算机的应用场景非常复杂，本身的开发工具和编程的语言显得较为多样，所以需要通过运 用各类应用来营造不同编程语言运行环境。因为网络边缘位置资源的利用率相对显得较为敏感，所以 随着时代的不断发展，容器技术已经成为虚拟化平 台中的重要技术。**4.2平台和管理层**ECP的平台和管理层主要由资源管理和应用 管理功能组成。在实际操作过程中，ECP的资源 管理将会严格遵循在工作组定义网络功能虚拟化 (Network Function Virtua lization, ETSINFV )的管理和编排(Management and Network Orchestrator, MANO)管理体系，并有效地支持虚拟机的编排和 容器编排工具更好地运行。从实际运用过程来看， MANO的管理体系已经不能够更好地适应边缘计算的场景。一方面，某些边缘场景内部的资源将会受 到诸多限制，另一方面MANO管理体系的重量过重, 需要替换轻量级的资源管理机制。

另外，已有的互 联网应用生态体系并没有能够更好地遵循MANO体 系，所以在实际操作的过程中，需要通过全面设置 开放的互联网资源管理机制，才能更好地满足计算 机多生态的发展需求。

**实际案例分析**

中国移动推出的5G网络建设案例为边缘计算 在5G网络中运用的实际案例。一般而言，5G网络拥有连接广泛、低时延和可靠性较高的特点。融入 5G的远程医疗解决方案一般有更好的效果，并在之后有效地实现“基层首诊、双向转诊、急诊分诊、 上下联动”的分级诊疗政策，最终实现优质医疗资 源的配置。  

此次将边缘计算技术融入5G远程医疗的项目 中，可以将计算机、信息和医疗技术有效结合在一 起，并通过运用示范软件平台联通医院内部的第三 方平台。使用过程中可以有效连接5G宏基站，并运用CPE技术与室外无线终端内部的5G网络有效 连接，有效实现医院内部工作移动信息化。在实际 操作过程中，可以将“移动查房” “移动护理” “移 动检测”和“会诊功能”更好地结合在一起，并需 要合并以双向远程操控应用信息为基础的远程超声 和远程查房功能。实际使用过程中可以合并以下两个案例。5G移动医疗车可以通过装入5G通信模块，实 现移动化采集和传输患者生命体征数据和信息，并 通过有效搭建医院信息系统实现电子病历的输入、 查询和修改，配合检查报告的阅览工作。这样能够 改善4G网络功能单一和支持并发业务数量少的现 状，并在之后通过解决医院内部跨院协同工作提升 诊疗效果。远程诊疗经常处在总院和分院之间，并需要配 合患者视频、超声影健头操作视频、上级医生视频 和基层医生视频来有效地实现传输，并以5G网络带 宽为基础，促使远端的医疗专家和基层医生讨论病 历，有效地了解基层的医生对患者展开超声检查和 诊断，改善远程视频分辨率低和实时性的差异。本文分析5G网络和边缘计算技术的关系，全 面阐述边缘计算产业的发展进展，通过分析面向 5G网络的边缘计算技术内部的基础资源层、平台 和管理层以及接口和应用层，提供更多的参考性意 见，最后结合实际案例进行分析，以期大家对5G 有更多清晰的认识。
