# 专访｜佰倬徐翀：身经百战网安路，大悲大勇产业情

徐翀丨多数人知道，少数人了解

徐翀先生，现任佰倬信息技术有限公司副总裁、某单位数据安全与应用安全体系专项课题组专家。毕业于清华大学电子工程系与加拿大约克大学舒力克商学院，曾任朗讯科技有限公司与北电网络公司高级技术经理、CIENA 公司中国区负责人、加拿大 M&JC 咨询公司合伙人、神州数码华东区事业部总经理、无锡智发公司董事及神州绿盟信息有限公司资深业务架构师等职。

徐翀先生在二十多年的信息领域工作经验中，对智慧城市、大数据应用以及数据安全治理有着丰富的经验与独到的见解。徐翀先生的工作范围涵盖了数据的使用者、提供者、服务者与安全保障者。这也使得徐翀先生对大数据环境下的数据安全有着更为全面的视角。

  

![](../Images/357a4e970949162e43baec716d49f6e4.png)

  

好多年前，徐翀先生就戏称自己是“国际老盲流”， 写过通讯标准，干过智慧城市建设，再到网络安全架构，从国内到国外，再从国外到国内。且他对于职业， 有着狂热的执着，把通讯公司的所有岗位都干遍后， 由于财务和人事没有干过，便跑去加拿大学习，主攻财务管理和人力资源，把这两部分的知识点补起来之后又回到国内。

在企业各个岗位都做得很出色的他， 对于所谓的“盲流精神”有自己独到的见解，他说：“那是自由行走的态度，是探索新世界新事物的激情， 是用生命去观察世界不同角落的精神……”

八月，适逢世界人工智能大会圆满落幕之际，我们专程赶到无锡，与徐总面对面，一起翻开这个用生命践行理想、追寻梦想的“老盲流”职业旅程的精彩篇章——

骑“神码”打破“信息孤岛”，忧看大数据裸奔

徐总最早是做光通信的，在那个领域做的最牛的事情就是牵头撰写了国内独有的通讯标准——4X2.5Gbs SDH 信号透明复用器技术要求 (T-MUX)。这是在 21 世纪初中国在 ITU-T 成熟标准外构建的第一个光通信设备标准。

几年后，他到国外为国外通信厂商提供咨询服务时，看到老外也在使用自己牵头做的这个标准，还是有些自豪的。

2012 年徐总回到国内，加入 AGT 国际集团， 担任亚太区技术总监。在他的带领下，其团队做了大量的国际交流合作，也引进了国际上最先进的人脸识别、姿态识别、图像压缩搜索、灾难防护应急系统等技术。

在那个时候，智慧城市在中国刚刚开始兴起，徐总与其团队也对智慧城市的整体架构设计推出了不同于当时国内最大国营 IT 公司的方案。在这个方案中，城市管理学、目录学与 IT 技术融合在一起。在中国智慧城市之后的七年历史中，也印证了这一方案指向的正确性。

2015 年的时候，机缘巧合，进入神州数码工作的他，主动要求到无锡来管理苏皖沪事业部，当然，也在此续下了后来佰倬工作的前缘。选择无锡作为主要耕耘的地域，绝非徐总的心血来潮。

无锡的信息化建设起步很早。从 2009 年开始做数据信息化，就开始电子归档，归档到 2014 年的时候，已经有五年的成绩了。

2014 年至 2015 年，神州数码参与无锡智慧城市的设计与建设，他带领团队在 2015 年底就实现了将 39 个局委办信息全部连接入大数据中心。

因此，无锡成为全国政府数据信息化归集最好的城市，在 2015 年底就打破了李克强总理说的“信息孤岛”。

徐翀告诉我们，“与国外相比，我们的大数据治理有很大的差距，国内数据信息化严重缺失，这是形成信息孤岛的最重要原因。信息孤岛的出现在表面上看是各部门垂直利益的体现，其实真正的原因在于各部门各自沉淀的数据严重缺失与不标准化。”

”因此，各个部门都不愿意也做不到将自己的数据共享出来。真正打破信息孤岛的最关键点在于数据的梳理整顿。比如， 你在加拿大要买一块地，你能查到 100 年前这块地刚开垦出来到现在，每年用了多少肥，种了什么东西，亩产多少，只不过他们以前是纸片， 后来把它电子信息化了。”

徐翀继续介绍道，“经过四五年的努力， 无锡在这一点上的确做到了国内最高水平。信息孤岛打通之后，就要融起来，把其中的价值挖掘出来。但是当经过资源目录整理，清洗后入库的数据全方位呈现在我们面前的时候，其全面性和高度敏感性，让我们这些做大数据的人震惊了！2016 年他们完成了库表，库表做好之后，就要准备做设计应用，真正实现大数据的价值。但当看到国内大数据库个人信息严重裸奔之后，他们自己都不敢用了！”

徐总举例说以前在卫建委或者某一个医院，只能看到你的电子病历， 在公安部门只能看到你的个人信息，在综治办只能看到你是否有违法记录，在信用办只能看到你的信用。但把库表做好，库清洗完了以后，随便打一个人的名字，姓名、年龄，你的孩子是谁，孩子在哪上学，你的前夫是谁，你的前妻是谁，他们现在在干什么，他们的配偶是谁， 你的银行资料，你的房产登记，等等立刻呈现出来。

越健全的大数据库，相关信息的关联度越强越准确。而这一切在元数据库中都是明文存在的，也可以这样讲，我们目前所有的大数据库中相关信息都处于严重裸露的程度！

也正因为如此，才激发了徐总不得不去寻找合理高效的方法去建立大数据安全治理体系。逆潮流探索安全之道，实现新技术突破说到技术，徐翀也是滔滔不绝。他说，佰倬有很好的基础，创始人杨恩辉是国际知名的多媒体压缩、信息论和数字通信领域研究专家， 同时兼任加拿大皇家科学院、加拿大工程院两院院士，美国电气和电子工程协会院士。在杨恩辉院士的带领下，佰倬集信息论、安全操作系统、大数据、人工智能等于一体，研发出了系列网络安全核心技术和拥有自主知识产权的数据安全产品。徐翀继续说，“过去在网络安全中大家听到最多的是如何防漏洞，但在现实中我们真正最害怕的是 APT 攻击。挖几个漏洞出来的确可以显示你的技术水平， 但真正的问题在于人家在你的网里潜伏了三年甚至更长时间怎么办？网络攻击成本低，加上内部人员作案， 所以现在这些攻击不是以前那种攻防了，这其中尤其要管理好的是人的问题， 人的分级评定怎么做。””我们需要借鉴国外的做法，这个他们几十年前就有了，但国内非常欠缺。权责要清楚，安全级别要匹配，基于这些认识， 我们现在需要建立的是一个完整的防护体系， 而不仅仅是一项技术。在这个体系中，常规防护主要有三点：纯机器数据的防护、机器和人的交互以及人和法的规定，而在非常规防护，也就是灾难防护方面有两点；数据的追踪和数据安全备份。”佰倬在数据信息安全治理方面，现在还主要在做纯机器和纯设备的防护，接下来我们将发挥技术力量，同时加强跟其他公司的合作， 把我们的东西扩展到人机方面，实现人和机器、人和数据交互。徐翀说，“在我过去的大数据安全体系中关于基于业务的数据安全方面，和杨教授的解决方案有很多一致的思路。第一，必须是在数据的内核层来做加密，应用层加密是不行的， 因为文档类型太多了，必须是在内核层实现， 这就一定要进到操作系统中去。第二是密钥的管理，这也成了一个非常重要的问题。密钥按我们以前的办法，是有一个中央的密钥管理平台，这一点我觉得教授的想法比我超前，完善一个密钥管理体系，主要是第一次认证，还有就是要建立一个密钥群的主要认证，个人的私钥有一部分放在操作系统可信根里，部分密钥的种子始终保存在个人本机上。”徐翀认为，在拥有了这些技术的创新驱动之后，另一个非常重要的问题需要解决，就是国内大数据没有立法。在这方面，他带领团队从 2015 年就开始在无锡推动大数据地方立法的相关工作。新理念安全治理，打造加密三核心面对恶劣的网络环境，自 2014 年起，杨恩辉院士及其技术研发团队，提出了领先于世界水平的数据自保理念，并根据这个先进理念， 不断推出佰倬数安系统产品，放弃网络系统的纠缠，开创数据自保的先河。而徐翀的加入， 更给这项事业的发展增添了虎翼。谈到佰倬数据自保理念，徐翀说，“我们的数据自保的四个设计理念，包括：世界上没有绝对纯净的网络业务；需要带毒生产能力；数据安全需要专注于业务本身；数据最终级的防护在于看不懂，带不走。”数据自保理念体系以数据为核心，利用三大核心技术构架全球最先进的数据全周期安全系统：基于操作系统内核层的透明加密，支持各种专业格式数据与非结构化数据；根据自身专利，开发了基于进程的强制访问技术，建立从用户到框架层、内核层、基于硬件的可信计算区域的完整的可信链，真正实现数据所有人对数据的全面掌控。排忧患安全可控，营造产业大生态谈到什么叫自主可控，徐翀说，“资金可控、技术可控、人员可控，这三个可控才叫可控。”在自主可控的前提下，如何保证数据安全， 最大的忧患就在于生态的建设还不充分，存在很多问题，如数据泄露事件层出不穷，个人信息安全保护形势严峻，数据跨境流动日益频繁， 数据滥用成为重大安全隐患等等，更重要的是， 大数据安全核心技术薄弱。经过了一大圈丰富的职业历程之后，做这样的创新与发展的努力， 是他最想要用余生去完成的事业。徐翀进一步说，“本着这样的认知，从公司整个起步的过程中，佰倬一直崇尚合作，致力于汇聚产业界、学术界顶级智力资源，共同探讨大数据全业态演进规律与趋势，直面大数据技术链、产业链、价值链、安全链等热点。” “数据安全不是一个行业的事情，这是一个生态链营造问题，水能载舟亦能覆舟，为人类带来巨大福祉的同时也带来了个人隐私的保护问题，大数据共享开放与防治滥用无疑存在着艰巨的挑战，需要社会共同努力，需要我们突破组织边界，从行业内跨到行业外，区域内到区域外。完善相关法律法规，使数据生态建设朝着造福人类、推动社会进步方向发展”， 徐翀这样告诉我们。笔者在徐翀写的《大悲与大勇》这篇文章里读到这样的句子：当你深爱着一个人，一群人， 却又眼见他们身陷苦难的时候，只有这一份爱， 一份慈悲，才有可能让你放弃安逸安全的生活， 而满心欢喜地面对死亡，无所畏惧。此为大慈， 亦为大勇。想到我们的安全产业任重道远，不禁对徐翀这份产业情怀充满感慨与感动，祝愿他带领佰倬在无锡的世界级团队，不忘初心，引领网络安全，智慧世界万物。**往期风云人物**
