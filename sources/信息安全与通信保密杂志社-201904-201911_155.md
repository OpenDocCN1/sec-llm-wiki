# 捷报频传！ 指掌易成功签约多地农商银行

近日，浙江、江苏和湖南等多地农村商业银行纷纷签约《信息安全与通信保密》杂志社理事单位指掌易，采用指掌易智能银行移动业务安全整体解决方案，轻松“破局”安全赋能难题，领跑普惠金融新时代。

![](../Images/8162a50bcd0c134f8fde01e8a34279fd.png)随着各地农商银行在业务移动化建设快速发展，大量的移动终端信息来往传输，传输应用的多样化，为公司的终端安全管理，以及整个公司内部信息的安全管控上埋下了隐患，移动终端的安全性，可控性，逐步向可控范围之外蔓延。  

针对农商银行其业务种类，涉及区域的多样性，人员的复杂性等特点，作为移动业务安全专家，**指掌易依托自主研发的虚拟安全域（VSA）技术，为金融行业客户提供一套完整的移动业务安全架构（SAME，Secured Architecture for Mobile Enterprise），**整合涉及移动端的所有节点——“云管端”，配合IT战略，实现从端到整体架构的转变，适用于金融业各种场景、各种移动业务发展需要。 

![](../Images/3f6c496d6a09175b95d40fc2f093fb46.png)

针对农商银行移动业务安全防护的复杂性，指掌易进行深入地调研、整体统筹规划，可行性分析，**以虚拟安全域（VSA）核心技术为基础，构建了融合多种移动业务场景安全防护平台，提供一站式移动应用安全服务中心，**不仅确保现有方案能够无缝对接现有和未来的系统，具备足够的开放能力，提供灵活、丰富的API和集成架构，并且能与农商行现有的业务系统进行无缝对接，满足国家和行业安全监管、合规要求，助力整体移动安全防护体系建设，快速提升移动业务效率和核心竞争力。 

目前，指掌易已经为广东农信、重庆银行、苏州银行、厦门农商银行、浙商证券、安信证券、平安科技、人保健康、恒生前海基金、凡普金科等众多金融机构提供了完整的移动业务安全解决方案及技术支持，其产品与服务获得了客户的高度认可。在未来，指掌易将仍旧保持产品的不断创新，用更多高品质高性能的产品，为用户提供安全、可靠、高效的保障服务。

北京指掌易科技有限公司

成立于2013年，目前产品已实现技术轻量化和方案一体化，能在各种品牌和型号的智能终端上实现强大的安全能力，让小到几百人、多达几百万人的组织都可以实现安全、便捷的移动业务与移动办公。

公司成立至今，已经为中国人保、圆通速递、伊利股份、泸州老窖、友达光电、苏州银行等金融、制造、能源、航空、互联网等行业领域的头部企业客户以及多家重要政府机构提供了完整的移动端业务安全方案，其产品与服务获得了客户的高度认可。

此外，指掌易与终端厂商、移动应用厂商和安全厂商等上下游生态企业建立起牢固的合作伙伴关系，共同为用户打造完整的移动安全生态链。近年来公司产品实力和市场品牌荣获多方机构认可和一致好评，获得“36kr最具影响力企业服务TOP 10奖”、“2018网络安全（中国）论坛移动安全优秀解决方案奖”、“2018盛景全球创新大赛全球20强” 、“Gartner Hype Cycle for ICT in China 推荐厂商”、“Red Herring全球科技100强”、“Cybersecurity Ventures最具创新性的网络安全企业”等重磅荣誉。
