# 重构战略部署，美创打造行业新样板

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247545086&idx=3&sn=1467f7eaaee42c04c1e9950a2884388d&chksm=c0b4ea88f7c3639ea21f9b5d18b2cd6699cc7b4cfc8f1e0befc08409e0c14bc296c16dc84f76&scene=126&sessionid=1681312261#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247545086&idx=3&sn=1467f7eaaee42c04c1e9950a2884388d&chksm=c0b4ea88f7c3639ea21f9b5d18b2cd6699cc7b4cfc8f1e0befc08409e0c14bc296c16dc84f76&scene=126&sessionid=1681312261#rd)

近日，杭州美创科技有限公司（以下简称“美创科技”）与武汉达梦数据库有限公司（以下简称“达梦”）达成战略合作，美创科技总经理柳遵梁、达梦公司总经理皮宇出席签约仪式。双方就网络安全技术和数据库国产化替代领域开展全面战略合作，共同建全行业标准，共筑网络安全生态，为客户带来更便捷、更安全的网络生态安全环境。

![](../Images/2e33afbfb4c54fdb5895b7dd370216cd.png)  

**随着**科学技术、信息技术的不断进步发展，大数据时代帷幕即将拉开。网络与数据安全重要性在持续升温，国产化替代的进程逐步加快，数据库作为数据存储的重要源头，其自身的安全及安全性防护已成为重中之重。而企业单枪匹马做信息安全防御又显力不从心，整合资源、互相协作、抱团取暖、合作共赢，协同共建共赢的生态圈合作机制，已成为发展趋势和新业态。

**此次**合作，美创将进一步发挥数据安全技术能力，与达梦在产品、方案等多方面形成合力，不断创新，推动数据安全在行业的纵深发展，为客户带来完整的方案体验和技术成果输出。不仅如此，双方还将在网络安全系统解决方案、产品技术规范与应用标准共同研发，品牌深度合作等方面形成全方位的合作关系。

**作为**领先的数据安全管理服务提供商，美创科技始终为客户提供数据安全与管理、智能运维、容灾备份等专业化解决方案，同时，也是数据库技术的普及者和传播者，拥有业内顶尖的数据库大师。自美创成立以来，以创始人、数据库专家柳遵梁为代表的技术大师始终以实际经典案例为指导，通过线上线下多种形式的技术传播手段，助力各行业数据库管理员深入了解技术特性，大大方便其快速高效操作。

**围绕**数据领域的深耕化，美创科技总经理柳遵梁表示：“美创科技曾依托数据库运维，完成多次转型，覆盖了运维、灾备、安全、治理全产品线等多个领域。对于国产化替代趋势，美创与国产数据库第一品牌——达梦的合作将帮助用户无缝、平滑、安全的完成替换，同时，也期待双方联袂合作,给彼此未来的发展注入新的发展能量和空间，取得1+1大于N的价值提升，做出行业的样板和典型。”

达梦总经理皮宇也表示，**美创**科技在数据安全领域走在前列，并拥有业界顶尖的数据库大师，此次联合可谓是“天作之合”，未来双方将在数据库协议，关键技术研究、安全防护方面展开深入合作，为用户提供数据库、数据库安全防护等全面的解决方案。

  

杭州美创科技有限公司

敏感数据保护和数据安全领域的拓荒者和领导者，由国内多名数据库资深专家携手于2005年成立，产品及服务覆盖数据安全、数据管理、容灾备份、智能运维等四大领域，广泛应用于医疗、教育、金融、政府、人社、电力能源、物流交通、企业等众多行业。多年来，凭借卓越的技术创新与良好的用户口碑，美创多次入围全国网络安全50强，并参与多项国家及行业标准的编写，引领数据安全领域的规范发展。目前，美创科技已全面推动全国市场化发展战略，相继在北京、广州、武汉、南京、成都、上海等地设立分公司，致力于为更多的客户提供专业的安全解决方案。
