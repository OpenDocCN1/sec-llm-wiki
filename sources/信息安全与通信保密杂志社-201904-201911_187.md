# 理事｜赋能军工制造，指掌易荣获“2019军工信息安全护航先锋”称号

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247545078&idx=5&sn=77fd7823e8d316f2297b367d235319d9&chksm=c0b4ea80f7c36396d60f8cc6dd2ea61421ca135a379dccd25bfdff52ae3ecad22c945fa54590&scene=126&sessionid=1681312261#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247545078&idx=5&sn=77fd7823e8d316f2297b367d235319d9&chksm=c0b4ea80f7c36396d60f8cc6dd2ea61421ca135a379dccd25bfdff52ae3ecad22c945fa54590&scene=126&sessionid=1681312261#rd)

> 为进一步响应科技强军号召，聚焦新时代强国强军目标，加速推动军工系统安全可控与核心技术应用，构建更加安全可控的军工行业网络安全环境，积极引导经济社会领域的多元投资、多方技术、多种力量更好地服务国防军工建设，中国信息协会牵头主办了“2019军工信息安全护航先锋”评选活动。

  

该奖项由行业专家、学者组成权威评审团，经过层层遴选，最终选择出最具代表性、方案高效可靠的优秀厂商。凭借出色的产品功能、广泛的行业应用及良好的用户评价，指掌易掌上制造安全管理平台荣获“2019军工信息安全护航先锋”。![](../Images/fb14e072e2057bc86eb07992c6e3a11c.png)

**突破核心技术，赋能军工制造**

现如今，军工信息化已成为国防投入重中之重，并在相当长的时间内都是我国国防投入的重点，其中移动信息化发展尤其迅速，快速发展带来了很多机遇却也带来诸多挑战，“业务先行”导致很多军工制造企业缺乏足够的资源同步完成安全工作，造成大量泄密风险，“有目的”、“有规划”的泄露事件频发，企业损失惨重。

对于如何解决移动信息化面临的诸如“物理场所拍照泄密”“数字资产损失”“业务数据采集外泄”等问题，经过多年技术积累和客户需求挖掘，指掌易研发了统一移动安全保障平台——掌上制造安全管理平台，该平台依靠指掌易独有的VSA（Virtual Security Area，虚拟安全域）技术，能够在实现多维度安全保护的基础上，帮助工业企业更好地运营业务应用。

**指掌易掌上制造安全管理平台**

基于“云-管-端”的信息服务体系架构，指掌易掌上制造安全管理平台打破了业界移动安全的分散割据和封闭的现状，充分融合面向对象的身份认证，面向设备的安全管控，面向系统的安全检测，面向应用的封装加固，面向数据的隐私防泄漏，面向网络的专属加密以及基于云端大数据行为分析等功能，实现从人，机、系统到应用、数据、网络再到行为态势追踪等多级纵深的安全防护方案。

除此外，指掌易掌上制造安全管理平台还适用于移动支付、活动分享、事故处理、移动巡检/点检、移动办公等多种场景，利用时间、地点双重围栏，实现基础的设备限制，保障更多的移动化场景开展。该平台既能解决设备限制管控，又能实现数字资产保护，可定制化的业务安全需求保障了消费级的用户体验，同时开放多端接口，实现统一的安全管控，无论是统一配发还是BYOD，均能提供面向数据的安全保障。

成立至今，指掌易已经为军工行业及高端制造行业的头部企业客户提供了完整的移动端业务安全方案，其产品与服务获得了客户的高度认可。未来指掌易将继续秉持“客户第一·追求卓越”的价值观，为军工智造移动业务安全高速平稳发展持续赋能。
