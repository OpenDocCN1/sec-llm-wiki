5G预商用部署策略的探讨

摘要：5G无线技术主要标准已确定，设备产品均已成熟，5G商用频谱已划分，5G商用牌照近 日也已正式发布，我国正式进入了 5G商用元年。三大运营商目前正在全国主要大城市开展5G预商用的工程建设。阐述5G预商用过程中网络的网络架构，论述了无线网、承载网和核心网的改造策略和方法，重点就SA/NSA选取、CU/DU部署、频率重耕方案、站间距选择等重大部署策略进行了深入的探讨，为5G工程建设和网络部署提供了理论和实践方针。
2019年为第五代移动通信（5G）工程建设的元年，三家运营商商用频谱已确定，5G工程建设 全国范围内开展得如火如荼。6月6日工业和信息化部向包括中国广电在内的四大运营商发放5G商用牌照，2019年10月即将正式商用，5G进程又提速了，2019年我国将正式进入5G商用元年。

目前三大运营商在全国主要大城市开展5G预 商用工程建设，其中中国联通5G网络部署要在7个城市城区实现连续覆盖，在33个城市实现热点区域覆盖;中国电信17个城市开展5G创新示范试点；中国移动要在17个城市开展5G规模试验和应用示范工程[1]。因此本文重点阐述运营商在5G预商用过程中网络的总体部署策略。

1预商用网络架构

5G商用组网网络总体架构如图1所示，包括无线网平台、承载网平台和核心网平台。无线网仍采用目前LTE的网络架构，可将BBU （ Bandwidth Based Unit基带处理单元）集中放置（C-RAN, Centralized Radio Access Network,集中无线接入网）或放置在天线端；承载网前传釆用光纤直连方式，回传方案采用 SPN （ Slicing Packet Network,切片 分组网）技术组网，接入层传输设备将替换升级为 25G/50G带宽需求的光口，对于汇聚层（A设备、 B设备）、核心层（ER （ Edge Router,边缘路由器）设备），除部分老旧设备需替换升级外，大部分设备近期将保持不动，待后期依据网络的需求来替换升级；核心网网元分控制面和用户面，控制面网元采用虚拟化、大容量、少局所、集中化部署原则，用户面UPF视业务需求按需部署［2］。

2总体部署策略


2.1先SA还是先NSA?

4G迈向5G不再是核心网与无线接入网“整体 式”演进方式，而是把两者“拆开” 了，包括NSA （Non-Standalone Access,非独立接入组网）和 SA （Standalone Access,独立接入组网）两种部署方式［3］。到底先NSA建网，还是SA,成了一个全世界各家运营商焦点问题。

NSA和SA的组网主要区别：NSA是将5G的控制信令锚定在4G基站上，仍使用4G的核心网 资源；SA方案是5G基站直接接入5G核心网，控制信令完全不依赖4G网络。NSA是5G网络的过 渡方案，SA是5G最终目标架构，其优劣势对比如表1所示。

图1 5G商用组网网络总体架构

从表1可知SA和NSA各有优劣势，世界主要运 营商如何选取的呢？韩国三大运营商、美国Verizon、 英国运营商EE、日本NTT DoCoMo, KDDI选择的是NSA,日本乐天移动选择SA［4］。
国内方面中国联通选择NSA,中国电信选择SA,中国移动仍未明 确表示支持哪种，可能两种均支持。
本文建议中国移动可在一二线大城市采用SA组网以建立良好的 5G品牌形象，拥有高质量高ARPU群体，并运用 SA的优势支持企业开展uRLLC、mMTC业务，开拓5G新业务新的利润增长点，不再轮为“流量管道”。
对于三四五线城市，在5G垂直业务未完全 成熟前，采用NSA快速抢占5G市场先机，保护已有4G投资。
因此目前多数运营商选择NSA组网，即利用现有LTE无线接入和核心网络支援行动性管理与覆盖，但最终将走向SA模式。设备厂家提供的5G基站设备都是双模的，既支持NSA也支持SA,未来 基站仅通过软件升级即可实现NSA到SA的演进［5］。
2.2 CU/DU分设还是合设？

5G 时代 RRU （ Remote Radio Unit,远端射频模块）和天线合并成了 AAU （ Active Antenna Unit 有源天线单元），而BBU则拆分成了 CU （ Control Unit,控制单元）和DU （ User Unit,用户单元），每个站都有一套DU,然后多个站点共用同一个CU 进行集中式管理，CU融合了一部分从核心网下沉的功能，如图2所示。

图2网络架构的变化
BBU中的物理底层下沉到AAU中处理，对实时性要求高的物理高层，MAC, RLC层放 在DU中处理，而把对实时性要求不高的PDCP （Packet Data Convergence Protocol,分组数据聚 合协议）和 RRC （ Radio Resource Control,无线资源控制）层放到CU中处理回。
对于 eMBB （ Enhance Mobile Broadband,增强移动宽带）和mMTC时延要求不高的业务可以 把CU和DU分开来在不同的地方部署，而时延要求极低的业务uRLLC, CU和DU必须合设在一起以减少时延。
5G前期投入至eMBB业务中，但考虑与现有4G-BBU物理架构相一致有利于快速开通5G基站，而专门为CU建设新的数据中心, 成本太大且周期过长，因此5G工程建设的前期仍会继续采用CU和DU合设的方式，后续随着5G的发展和新业务的拓展，才会逐步进行CU和DU的物理分离。
2.3频率如何重耕？
▲中国移动获得2515〜2675 MHz和4800〜4900 MHz共计260 MHz带宽，
▲中国电信获得3400 〜3500 MHz共计100 MHz带宽，

▲中国联通获得3500〜3600 MHz共计100 MHz带宽。

电信和联通是空白频段，可以直接利用,且国际范围比较主流, 产业链相对成熟。中国移动虽中频有160 MHz带宽，频段低可以少建基站，但此频段电信和联通各占用了20 MHz带宽，移动自身D频又占用了 60 MHz, 因此必须采取重耕措施，将此频段移频或清频。
电信和联通各占用的20 MHz带宽，中国移动 可通频谱置换获取。中国获得了 FDD牌照后，能够吸收很大部分流量，但D频仍是目前4G吸收的 主力，不可能一步移频到位，其移频方案如图3所示，分步将D1移至D4, D2移至D5。
本文建议待5G市场完全成熟，4G用户数很少，中国移动可开启160 MHz带宽的5GNR,其性能和优势将完全碾 压电信和联通，有利于开拓高端客户群和加快垂直行业的发展。

2.4站间距如何选取？

由于NR采用了波束赋形、提高发射功率、多 MIMO等技术措施，使得相同频率下NR覆盖较LTE 更远。图4为设备厂家测试上行边缘速率2 Mbit/s站 点的覆盖距离〔7],在同速率情况下，NR2.6G64TR产 品上行覆盖能力超过了目前4G覆盖最好的FDD1.8G 4R；NR3.5G64TR产品较FDD1.8G4R覆盖稍差，但比所有TDD产品均强；4.9G 64TR产品覆盖能力较弱，但可与目前LTE-D频相当。

因此建议中国移动前期可与FDD1800共址建设，站间距初步定在400 m左右，但对于部分热点区域可加密部署，对于话务量较少的站点可不部署以节省投资。4.9 GHz频段可用于5G微小站，用于热点补盲或智慧灯杆项目。中国电信和中国联通建议站间距为300m,可大量共址移动基站，实现快速建站，节约投资，但这也给基站电源和天馈改造带来的困难。

结语

5G预商用过程中，SA/NSA选取、CU/DU部署、频率重耕方案、站间距选择等都是5G部署必须慎重考虑的重大问题。三大运营商应依据各自的特点选择合适的可行方案，在合理部署的同时，应兼顾考虑建网成本、建设周期、市场业务开拓等因素。
