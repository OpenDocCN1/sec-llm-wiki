# 理事｜独占鳌头！炼石网络荣膺“ISC创新独角兽-沙盒大赛”王冠

**360集团董事长周鸿祎为炼石CEO白小勇颁奖**  

由中国互联网协会、中国网络空间安全协会、360互联网安全中心以及多家网络安全企业共同主办的第七届互联网安全大会（ISC 2019）于8月19日-20日在北京雁栖湖国际会展中心召开。更加值得期待的是，ISC 2019还首次带来了“中国版RSA沙盒创新赛”——创新独角兽-沙盒大赛，全国超100+优秀项目报名参赛。  

**经过激烈角逐，北京炼石网络技术限公司凭借其超强的实力，摘得桂冠！**

众多评委一致认为自从创立以来，炼石网络始终坚持以创新作为企业发展的动力，打造出拥有完全自主知识产权的“应用系统免改造”的数据加密产品，荣获多项发明专利和软件著作权。

炼石提出一种全新的CASB技术（Critical Application Security Broker，关键应用安全代理），可以在应用不改造的情况下，为企业广泛的应用系统实现数据安全增强。

炼石的数据安全密码防护方案能够应对两大威胁：一是通过面向服务侧的存储加密，防范恶意DBA、外包人员以及外部黑客；二是通过面向用户侧的动态脱敏、数据解密与访问控制相结合，防范内部业务人员越权等内部威胁。

据悉，北京炼石网络技术限公司不仅可以得到10万元真金白银的现金奖励，还将被优先推荐加入周鸿祎等担任导师的大安全实验室，与多位创业导师进行深入学习，更有机会在10亿元大安全基金的投资下“C位出道”，成为安全领域独角兽！

  

炼石网络

是业内领先的基于CASB与密码技术的新一代数据安全厂商，专注于为用户提供融入业务的数据安全产品与解决方案。炼石提供高性能、安全、易用、场景覆盖完整的卓越密码能力，同时将加密与细粒度访问控制、审计追溯等安全技术结合，以适配的方式将数据安全嵌入到业务流程，免开发改造应用系统增强安全防护能力，让企业数字化业务更安全。炼石针对个人信息保护、云数据安全、大数据密码安全等提供专业安全解决方案，适用于服务业、政府、金融、军工、制造业、商业企业等行业。
