# 【理事动态】天融信举办2019中国网络安全年会车联网安全论坛

7月17-18日，在国家互联网信息办公室指导下，由国家互联网应急中心（简称CNCERT/CC）主办的“2019年第十六届中国网络安全年会”在广州举行。作为本届年会联合主办单位之一，天融信科技集团于7月18日下午举办车联网安全论坛。本次车联网安全分论坛以“智能网联 安全同行”为主题，议题涵盖最新的车联网安全产业发展、安全技术、应用创新等。来自全国党政机关、重要信息系统、企业、行业协会、高校和科研院所等单位代表参加会议。

  

国家互联网应急中心实验室副主任李政先生、国家互联网应急中心广东分中心副主任宋苑女士、天融信科技集团董事长于海波博士分别作大会致辞，国家互联网应急中心实验室软件与车联网安全方向技术负责人范乐君先生、天融信科技集团副总裁唐宁先生主持大会。

  

![](../Images/a36b9ef41254e0435d81d3ce9719c1be.png)

  

国家互联网应急中心实验室副主任李政先生发表致辞。李政表示， 智能汽车的网络安全是一项系统工程，在国家主体引导的基础上，需要发动全行业的力量，联合社会主体共同应对，结成智能网联汽车网络安全命运共同体，以“共研、共建、共享”为原则，加大网络安全投入，加强互联互通，扩大交流合作，加快安全体系建设。

  

![](../Images/55b71ab46e00ccd82fbaa21cd1a2030c.png)

  

国家互联网应急中心广东分中心副主任宋苑女士在致辞中表示，发展智能网联汽车是一个涉及价值链、产业链、创新链的深刻变革。智能化、网联化已经成为汽车产业发展的必然趋势，是信息化与工业化深度融合的重要方向，对促进汽车和信息通信产业创新发展，构建汽车和交通服务新模式新业态，推动自动驾驶技术创新和应用，提高交通效率和安全水平具有重要意义。

  

![](../Images/275bdab517b46a0e5fbaa9117032d4d5.png)

天融信科技集团董事长于海波博士表示，我国是世界最大的汽车市场，根据预测，2020年全球车联网V2X市场规模将突破6140亿元人民币，中国市场将达到2000亿元人民币，3亿存量汽车市场需要互联网连接，为智能网联汽车带来广阔的发展前景，车联网技术向着智能化、网联化方向演进。天融信作为中国领先的网络安全、大数据与安全云服务提供商，紧跟技术浪潮，一直致力于车联网安全的研究。天融信从2016年开始布局车联网，发展至今，拥有非常完备的车联网安全产品线，围绕国内外车载网络安全产业发展趋势、行业标准制定、关键技术与架构进行深入研究，在车载安全网关、车载入侵检测、车联网安全认证等领域取得了一定的建设成果，并深入贯彻落实国家相关部门对车联网行业发展的指导思想，促进车联网安全产业有序、稳定、良性发展。

  

![](../Images/9e9ac5ef612dd49f93ded6de8a4620a3.png)

国家市场监管总局缺陷产品管理中心汽车召回管理部主任肖凌云先生在《中国汽车召回最新进展及车辆信息安全监管思考》主题演讲中提出三点建议：1.针对智能网联汽车，网络安全缺陷将成为汽车召回新模式；2.监管部门、技术机构、行业协会、企业要重视车辆网络安全问题，强化合作，提高安全水平，减少车辆网络安全风险；3、OTA技术正成为新的汽车维修方式和召回实施措施，OTA升级的内容、升级方式的安全性、升级方式的有效性将成为召回监管的重点。

  

![](../Images/a77afe97ee8d2cf021f055ca2c8af2d8.png)

国家互联网应急中心专家王晖先生作《车联网安全相关标准工作情况汇报》主题演讲。王晖先生首先介绍了国家车联网安全政策法规标准规划，并详细介绍了CNCERT车联网安全标准工作规划布局、相关标准工作进展以及CNCERT车联网网络安全应急保障标准化体系。

  

![](../Images/8298ec47a776fe8f06f7492717ea2308.png)

# 天融信科技集团车联网安全产品线总架构师范雪俭先生作《车联网安全防护技术实践》主题演讲，围绕“IT网络安全如何赋能车联网安全”的主题，介绍了天融信为应对风险采用的安全防护技术以及在安全防护实践中的思考。范雪俭指出，要做好车联网安全防护，需要借鉴IT网络安全的防护技术，深入汽车内部业务，采用多种防护技术协同联动。通过轻量级认证加密技术，实现车内、车与云端、车与手机端的可信身份认证、加密通信传输，防止指令破解、重放攻击、伪造身份、数据窃取等攻击行为。通过基于白名单的车载入侵检测技术，结合安全事件上报、云端策略下发，实现车内异常流量、异常报文识别、云端攻击检测。通过车载安全网关，对车内安全域进行隔离、CAN报文深度控制、安全审计、攻击防护等，实现车内网络安全边界防护。

  

# 天融信车联网安全防护体系是以车内安全为核心，通过构建纵深一体化协同防护，为车联网客户提供全方位、多手段、深融合的安全保障。车联网安全需要一个更加紧耦合、演进更快速的生态环境，通过开放合作，快速打破行业认知壁垒，形成共享资源的融合创新。

  

![](../Images/fdad41891b41f43ea330631edae5b6f8.png)

演讲环节过后，天融信科技集团副总裁唐宁先生主持大会圆桌对话环节，中国软件测评中心副总工程师杨玚、华中科技大学教授刘政林、上海银基信息安全技术股份有限公司华南区总经理汪媛、东风汽车技术中心智能网联部总工程师盛凯、腾讯科恩实验室汽车信息安全产品及解决方案负责人李光辉以及阿里云政务拓展与生态合作总经理周斌琦围绕“车联网安全，创新与发展”这一主题，共同探讨了车联网安全标准规范的制定，如何体系化地构建车联网安全防护体系，如何从监管单位、车厂、安全公司、互联网厂商等方面构建车联网安全的生态圈等议题。  

  

作为此次中国网络安全年会车联网安全论坛的主办方，天融信十分期待能够通过本届大会的平台，集思广益，搭建桥梁，促进合作，共同推动智能网联汽车的发展。
