# 【理事动态】国民技术与海尔、有方科技签订三方战略合作协议，共同打造工业互联网商用密码安全体系

7月2日，杂志社理事单位国民技术股份有限公司（简称“国民技术”、“公司”）与海尔数字科技有限公司（简称“海尔数字”）、深圳市有方科技股份有限公司（简称“有方科技”）在青岛签署了三方战略合作协议，三方将在工业互联网与物联网等领域开展深度合作，共同打造国内首个工业互联网国密安全体系，为海尔工业互联网平台COSMOPlat提供边缘层硬件国密安全解决方案和国密安全云解决方案。

公司董事长、总经理孙迎彤与海尔家电产业集团副总裁、海尔数字科技有限公司董事长陈录城，深圳市有方科技股份有限公司董事长王慷共同出席签约仪式。  

                                               ![](../Images/e2e9745395a6122dfd680df0ce67d00f.png)

**（国民技术与海尔数字、有方科技达成战略合作）**

  

海尔COSMOPlat是全球引领的世界级工业互联网生态品牌平台，作为此次合作的重要基础，**国民技术将通过领先的低功耗金融级安全芯片与国民安全云为海尔COSMOPlat提供从云到端的全面安全支撑，实现安全连接与数据保护**；有方科技为海尔COSMOPlat平台提供稳定可靠的通信接入。三方在工业互联网平台、物联网硬件安全、无线通信等方面形成优势互补，从云、管、端全方位打造稳定可靠和安全高效的工业互联网应用。三方还将在资源共享，产业生态打造方面进一步深化合作，为客户提供更优质的增值服务，共同推进工业互联网发展。

  

当前，整合产业资源实现模式创新，用平台能力驱动工业互联网和物联生态共建共享，已成为业界关注焦点。此次公司与海尔数字和有方科技签署三方战略合作协议，**是国民技术物联网安全战略的重要举措**。

  

以此次工业互联网安全合作为契机，国民技术将进一步扩大与业界的深层次合作，采用基于**密码技术的高等级安全芯片和安全云平台**，为工业互联网、物联网、车联网、智能家居、智能家电等应用领域提供安全认证、设备管理和加密服务。
