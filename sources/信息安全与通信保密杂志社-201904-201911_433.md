# 【热点聚焦】“智慧应对危机 共建城市安全”——2019年第三届世界智能大会智慧应急发展论坛暨智能化应急技术成果展成功举办

5月17日，2019年第三届世界智能大会智慧应急发展论坛暨智能化应急技术成果展成功举办，论坛以“智慧应对危机 共建城市安全”为主题，旨在深入探讨特大城市应急管理背景下的智能化应急技术、产品及系统建设。

![](../Images/3d56d8609ce0991a8c224852b8293e9c.png)

会议现场

活动由“一会两展”组成，会议部分邀请到中国科学院院士姚建铨、中国工程院院士刘永才、挪威科学院院士容淳铭、日本横滨市危机管理总监荒井 守、河北唐山市委副书记市长丁绣峰、中国石化股份有限公司天津分公司副总经理王百森、3M中国技术中心-个人安全防护产品部技术专家鹿骋等智慧应急领域的多位权威嘉宾参与；“两展”部分包括梅江展区智能化展示、中北展区成果化展示，分别就智慧城市应急管理机制、智慧消防灭火救援指挥体系、智慧危化品安全监测报警体系等智慧应急成果进行集中展示。在人工智能应用的时代背景下，本届论坛链接海内外行业资源，围绕特大型城市应急管理等核心内容开展学术交流与商务洽谈，力促智能应急产业合作项目落地。
