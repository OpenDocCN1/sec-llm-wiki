# 【理事动态】渔翁信息20年造就国产密码品牌

近日，山东广播电视台《品牌山东》栏目组走进杂志社理事单位山东渔翁信息技术股份有限公司，与董事长郭刚共同探讨渔翁信息发展壮大的秘诀以及品牌成长经验。

  

山东渔翁信息技术股份有限公司成立于1998年，是一家专注于国产密码硬件的高新技术企业，是首批获得商用密码产品生产定点单位和销售许可的民营企业，拥有涉密信息系统集成软件开发甲级资质、信息安全服务一级资质。

  

![](../Images/25a488d03b53e09d90b11c835484628e.png)

  

中国的互联网密码产业起步较晚，一开始便面临着来自外部的技术封锁等压力。成立之初，渔翁信息从零开始，20年心无旁骛主攻密码硬件产业，坚持用工匠精神铸造过硬产品品质。2006年推出国内第一款PCI-E密码卡，产品入驻国家密码管理局珍藏馆；2009年，高速VPN荣获国家科技部“科技型中小企业创新基金”；2013年，高性能云服务器密码机荣获“国家密码科技进步奖”；2015年,研发出支持云计算的服务器密码机,荣获国家党政密码科技进步奖。2018年，新一代PCI-E密码卡，加解密速度达到18Gbps，签名达70000次/秒，性能国内领先。

  

![](../Images/d3e45e8461ee21cc88649b745fc2070b.png "72109c9bfa37db311e133170e29f92fd.jpg")

（山东渔翁信息技术股份有限公司董事长 郭刚）

  

20年专注如一，让渔翁信息搭建起完整的密码技术及产品体系，包括基础密码产品、PKI密码支撑系统平台、通用安全产品、工控安全产品、密码应用方案五大类，其中基础核心产品密码卡涵盖PCI、PCI-E、MINI PCI-E等系列，体系优势已成为公司的核心竞争力。
