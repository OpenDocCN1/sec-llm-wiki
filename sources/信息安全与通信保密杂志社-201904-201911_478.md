# 【热点聚焦】提振行业信心，再创发展辉煌 ——可信计算3.0筑牢等级保护防线高峰论坛

4月29日，在第六届“4.29首都网络安全日”期间，可信计算3.0筑牢等级保护防线高峰论坛也在同期成功举办。本次论坛由北京市委网信办、北京市公安局主办，中关村可信计算产业联盟、中国电子国际展览广告有限责任公司承办，全球能源互联网研究院计算及应用研究所、北京奇安信科技有限公司、北京可信华泰信息技术有限公司、立思辰安科技技术有限公司、北京国舜科技股份有限公司协办。邀请政府主管部门领导和专家学者、企业高管、工程技术人员约300人出席。  

  

此次会议由中国计算机学会计算机安全专业委员会主任严明倾情主持！北京市委网信办数据与技术处副处长尹珩，中国电子信息产业集团有限公司副总经理、党组成员陈锡明为本次论坛致辞。

**《可信计算优秀应用案例征集》仪式正式启动**  

  

随着可信计算技术的发展，可信计算在近年来得到了越来越成熟的应用，同时也出现了越来越多的应用案例。为了更深入地推动可信计算的应用的落地和发展，论坛上进行了《可信计算优秀应用案例征集》的启动仪式。中国工程院院士沈昌祥，公安部11局总工程师郭启全，中国电子副总经理、党组成员陈锡明，全球能源互联网研究院计算及应用研究所所长高昆仑共同参与了本次启动仪式。中关村可信计算产业联盟秘书长王振宇对本次可信计算优秀应用案例征集的背景进行了详细介绍，引导相关优秀企业积极参与，至此，本次论坛正式拉开序幕！

  

本次案例征集的评审组成员包括业界知名专家学者、研究机构以及科研院所，其中组长为中国工程院院士沈昌祥，组委包括：公安一所、公安三所、公安部11局、清华大学、北京交通大学、四川大学、北京工业大学和武汉大学。参评企业征集包括了41家联盟会员单位在内的众多企业，同时也期待更多优秀企业的参与，不断充实壮大可信计算生态体系的队伍。

**主题分享**  

  

随着我国网络安全等级保护制度的进一步完善，等保2.0中强化了对可信计算技术的使用，也标志着可信计算技术的进一步实践与落地。

  

公安部11局总工程师郭启全发表“利用可信计算等关键技术支撑国家网络安全等级保护制度深化实施”的主题演讲。中国工程院院士沈昌祥、公安部信息安全等级保护评估中心副主任张宇翔、全球能源互联网研究院计算及应用研究所所长高昆仑先后围绕“重启可信革命夯实网络安全等级保护基础”、“基于等级保护与可信计算构建我国关键信息基础设施保障体系”，以及“电力可信计算计算研究与应用”等方面进行了深入探讨。

等保2.0时代下，可信计算已成为保卫我国网络安全战略的核心技术，可信计算3.0也将成为筑牢我国等级保护的坚固防线。整个论坛中，无论是院士专家，还是企业，都齐心聚力，为可信计算3.0版能在行业的发展出谋划策，打造独一无二的可信计算生态链体系，可见可信计算当前蕴含的新希望和新未来！同时，可信计算核心关键技术的发展升级，有利于助力我国早日实现网络强国之梦！
