# 重磅！杂志社和中国网信联盟联合发布“桔皮书”

2019年4月29日，在第六届“4.29首都网络安全日”新品发布区，借着安全日的“东风”，信息安全与通信保密杂志社联合中国（中关村）网络安全与信息化产业联盟发布了《中国网络安全与信息化产业桔皮书（2018年）》（简称“桔皮书”）。这是联盟自2016年以来发布的第四本桔皮书。本次桔皮书的编撰得到了信息安全与通信保密杂志社的大力支持与协作。杂志社所编撰的内容成为桔皮书重要的一部分，为桔皮书的成功完成，做出了重大贡献！  

  

其他参与编撰的企业和单位还有360企业安全集团、东软集团、海泰方圆、中睿天下、中标软件等。

  

当前，信息化、网络化对经济、政治、文化、社会、军事等各领域的渗透趋势越来越明显，成为推动经济社会转型、提升国家综合竞争力的强大动力。为了更好地分析我国信息化现状，对比、借鉴发达国家信息化建设经验，联盟特组织成员单位研究世界主要国家网力现状。网力是网络力量的简称，指国家网络技术发展、融合、应用与网络空间治理的综合实力。

  

发布会由联盟战略研究中心副主任张继春主持，联盟成员代表、政府机关领导及专家、编撰成员代表50余人参加发布。中国保密协会副会长纪清阳、公安部网络安全保卫局处长盘冠员到会致辞，对桔皮书的成功发布表示祝贺。

  

纪会长在致辞中表示，在网络安全方面，我们依然面临深刻的危机，我们不乏先进理念，不乏科技成果，不乏科学家，但很多宝贵的理论概念很难落地，原因在于我们的产业没有发展强大，导致一些先进的思想和技术只能束之高阁，阻碍了产业进一步的提升和发展。产业强则科技强，产业强则发展强，产业强则国力强，希望大家牢记使命，担当责任，共同为实现国家网络强国战略做出突出贡献，也希望联盟的桔皮书越来越有份量。

  

![](../Images/2d7969414629e26253976051f9c1362c.png)

（中国保密协会副会长纪清阳）

  

致辞中，盘处长表示，产业上不受制于人是一个国家网络安全实力的重要标志，网络安全保障需要产业支撑，没有强大的网络安全产业支撑，就没有可靠的网络安全保障。目前网络安全产业发展正处于历史上最好的时期。中关村网络安全与信息化产业联盟肩负推动网安产业发展的历史使命，在联盟的指导和服务下，在网络安全产业界的共同努力下，我国的网络安全产业一定会发展地更好更快，取得更大的进步！

  

![](../Images/ecbc2c338cd0e6babb99f510be61fbd8.png)

（公安部网络安全保卫局处长盘冠员）

  

网信战略研究中心副主任张继春代表联盟作桔皮书发布的报告，桔皮书以“世界主要国家网力情况及趋势研究”为主题，研究和回答如何科学界定网络力量、认识网络力量、增强网络力量等问题，研究关系党和国家网络技术与应用发展的重大问题，着力推出有份量、有深度、有价值的网络力量基本体系研究成果，为党和国家决策服务。

  

随后，东软集团股份有限公司网络安全副总经理路娜和海泰方圆科技股份有限公司总工程师唐建新分别作为企业代表在这次桔皮书发布会上作了重要发言，表达了对联盟桔皮书发布的庆贺，并分享对安全企业在当下时代大背景下的发展对策及观点。

  

![](../Images/db1b6394da8c66e16c1edc58171180ed.png)

（海泰方圆科技股份有限公司总工程师唐建新）

  

联盟理事长于晴作发布会总结表示，中国（中关村）网络安全与信息化产业联盟将积极为中国网信事业大发展做贡献，相信在指导单位中央网信办信息化发展局、公安部网络安全保卫局的指导下，联盟会充分发挥桥梁与纽带作用，更好地把上下游企业广泛联系在一起，为网信事业贡献新的力量。
