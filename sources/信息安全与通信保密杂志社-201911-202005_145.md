# 新冠肺炎危机过后中国数字经济将迎来新的起点

**摘　要**

 2019年底爆发的新型冠状病毒肺炎疫情席卷全国，病毒的强感染性和广传播性使这场没有硝烟的抗疫战困难重重。面对未知的疫情，我国科技企业积极运用人工智能、云计算、5G 通信技术、大数据等技术手段解决了医疗资源调配、药物研发、社会经济秩序维护、民生保障等领域的诸多问题，在这次疫情抗击中发挥了关键作用。

同时，中国数字经济的发展模式和数字型产品的应用场景被大众逐渐熟知，新兴技术的应用场景进一步被拓宽，信息化发展动力增强，抗疫期间政府对新兴技术重要性的肯定和对中小型科技企业的政策支持，都预示着此次新冠肺炎疫情后中国数字经济发展将迎来新的起点，中国的信息社会建设将会加速。  

  
0　引　言此次新冠肺炎疫情涉及人数众多，该病毒潜伏期长且感染性强，又恰逢春运，病毒携带者跨区域流动造成了此次疫情的广泛性、复杂性、紧迫性都远超2003年的非典疫情。面对严控疫情和维持经济、社会正常运行的双重挑战，传统的防控手段显得捉襟见肘。

科学技术在这次中国应对新冠肺炎疫情的战役中脱颖而出，成为高效且可靠的抗疫手段，人工智能、5G、大数据、云计算等新兴技术为政府防控疫情、维护经济社会稳定发挥重要作用，同时也在抗击疫情的特殊时期显示出中国数字经济的优势与前景。

一方面，在抗击疫情、保障民生和恢复社会运转方面，科技企业提出了更为高效、便捷、安全和富有创造性的解决方案；另一方面， 在抗击疫情过程中，政府、企业、社会对新兴技术的优势与应用将有更多认识，对数字化生活、工作和学习的场景将更为适应，从而加快中国经济数字化转型的步伐。

1　疫情抗击中科技企业发挥关键作用中国科技企业在这次疫情中主动担当，积极探索新兴技术服务于疫情防控的各种场景与解决方案。自疫情爆发以来，腾讯、阿里巴巴、百度、京东、科大讯飞等一批互联网科技企业主动参与到这场战疫中，充分利用大数据、人工智能、5G 通信技术、云计算等新兴技术，发挥在远程诊断、人群筛查、疫情防控和医疗保障等方面的积极作用。具体而言，运用新兴科技的互联网企业结合其平台，重点从以下六个方面对疫情防控和经济社会运行提供了支撑。  
**1.1　5G 与互联网平台提供线上问诊服务**  
在四川省启动重大突发公共卫生事件一级响应后，中兴通讯（ZTE）与四川电信利用最新的 5G 通信技术，帮助四川大学华西医院与成都市公共卫生临床医疗中心建立了5G远程会诊机制，首次实现了两例新型冠状病毒肺炎的远程会诊，并凭借 5G 通信的高带宽、低延时特性， 确保线上问诊更加高效、便捷。

同时，远程会诊服务也使得武汉紧缺的医疗资源得到有效补充，缓解疫情防控部门的压力。此外，“阿里健康”“丁香医生”“平安好医生”“好大夫”“微医”、腾讯微信等平台在疫情爆发后及时提供相关的线上问诊服务，即医患双方通过文字、图片、语音等“非接触”方式，在互联网平台上进行信息交流。通过这种在线问诊的方式， 可以减少线下接触避免交叉感染，同时帮助疑似患者快速简单判断病情。

  
**1.2　人工智能助力关键场所人群筛查**  
随着假期结束和全国复工潮的到来，各大城市的公共场所都将面临疫情防控的重大挑战。其中，在公共场所筛查高温人群的同时保证高效通行和及时预警是地方政府面临的一大难题。  
为此，旷视科技（MEGVII）的研发团队提出了“人体识别 + 人像识别 + 红外 / 可见光双传感” 的创新解决方案，通过人工智能技术辅助前端的红外热感相机识别高温人群，在流动性大的公共场所帮助工作人员快速筛查体温异常者， 实现非接触式的高温人群筛查，保证了公共场所的通行效率。目前，这一创新解决方案已在北京海淀区的多个地铁站投入使用。

同时，百度也为北京地铁提供了一套完善的“AI 多人体温快速检测”解决方案，可以基于电脑及手机客户端进行快速部署，提升公共场所批量初步筛选检测效率。通过人工智能技术提升检测效率，不仅缓和了各大城市公共场所的人工压力，也提高了疫情整体防控的效率，提升疫情期间各种公共场所的可控度。

  
**1.3　云计算助力药物研发**  
2020年2月3日，华为云联合华中科技大学同济医学院基础医学院、华中科技大学同济医学院附属武汉儿童医院、西安交通大学第一附属医院、中科院北京基因组研究所组成的科研团队宣布，已通过云计算的庞大算力从8506种上市或者正在进行临床试验的药物中筛选出五种可能对2019新型冠状病毒有效的抗病毒药物。传统的药物筛选工作所需时间往往以“年”为单位，此次联合科研团队在一周内就拿出了第一阶段成果，从而使后续的测试和评估过程大大提前。

此外，百度研究院免费向有关机构开放线性时间算法 LinearFold 与 RNA 结构预测网站，以提升新型冠状病毒RNA空间结构预测速度。据悉，百度的 LinearFold 算法可将新型冠状病毒的全基因组二级结构预测从55分钟缩短至27秒，节省两个数量级的时间。浙江省疾控中心、阿里达摩院和杰毅生物技术公司共同研发出全基因组检测分析平台，大幅提高疑似病例的确诊速度和准确率，利用阿里达摩院研发的AI算法将原来数小时的疑似病例基因分析缩短至半小时，并能精准检测出病毒的变异情况。

为助力研究机构加速新药筛查和疫苗研发，腾讯和其他互联网公司也免费开放超级计算机算力以支持病毒基因测序、新药研发、蛋白筛选等工作，帮助科研机构缩短抗病毒药物研发周期。例如，中科曙光、腾讯与深圳超算中心共同组建应急工作组，以帮助中山大学的科研团队开展药物筛选作业。腾讯云也向北京生命科学研究所的黄牛教授实验室提供了大量标准的 CPU算力以及对象储存能力，帮助黄牛教授实验室进行基于结构的药物分子设计的离线计算任务。

  
**1.4　智能机器人助力医疗保障和社区防控**  
达闼科技推出多套疫情防控智能机器人方案，包括隔离病房服务机器人、送货服务机器人、医院消毒清扫机器人、移动巡逻温测机器人等，以助力疫情立体防控。上海钛米机器人也向湖北武汉输送10台钛米智能消毒机器人，并已在武汉疫情中心的6家医院投入临床使用。

此外，各种功能的智能机器人还部署在社区疫情防控一线。例如，公安部第一研究所联合优必选科技推出警用巡视机器人“建国”，不仅增加了疫情防控、人脸测温等系列增强功能，还支持在疫情指挥中心远程进行灵活的定制疫情防控自动语音播报功能，对人群进行有效提醒和疏导。

目前，警用巡视机器人“建国”已经在深圳黄鹤检查站上岗，通过全天候全时段自动化巡逻和现场实施监控，分担民警、辅警等一线工作人员的巡逻任务。可见，智能机器人服务在此次疫情中充当了重要角色，既为疫情防控提供了重要保障，也是助力保障公共安全的有效手段。

  
**1.5　“互联网 + 物流”保障医疗和民生物资运输**  
阿里菜鸟协同全球物流合作伙伴开通免费快速运输通道，将阿里巴巴集团公益采购、海内外捐赠的医疗物资及时配送到重点疫情地区。京东物流凭借其强大的全供应链服务与供应链技术等优势，持续将大批口罩、医疗用品等社会捐赠的医疗物资运往湖北地区的同时，也为众多商家对湖北地区的捐赠援助提供了强有力支撑。

另外，京东云推出了“应急资源信息发布平台”，该平台通过与全国40多个地方政府合作建立基地，共建数字经济产业园，涵盖医药、食品、科技等领域的3000多家企业。

此外， 盒马生鲜、每日优鲜等众多生鲜电商能够克服疫情带来的影响，保持高效运转，为全国的用户提供“无接触配送”服务，满足老百姓对民生物资的需求。互联网企业通过智能化的解决方案，为疫情期间的医疗物资运送与民生保障做出了巨大贡献，同时也充分体现出“互联网 +”模式所具有的强大资源配置能力。

  
**1.6　线上平台保障办公和教育需求**  
为全面控制疫情发展，避免蔓延态势回升，在线办公、在线教育成为疫情控制期间满足经济社会生活需求的主要手段。例如，科大讯飞开放了“AI+ 办公”平台，为企业和个人提供远程办公服务，助力疫情防控。在阿里巴巴钉钉上有超过1000万家企业在线开工。

为支持在线办公需求，钉钉在阿里云上紧急扩容1万台云服务器来保障钉钉视频会议、群直播、办公协同等功能，保障用户流畅体验。“作业帮”“网教通”等在线教育平台也提供了在线课程直播服务，帮助广大师生实现在线教育和在线学习。

此外，许多省份也利用智慧政务系统提升了网上办事的效率，避免线下接触。以福建省为例，目前 95% 以上政务服务事项网上可办、50% 以上事项可“一趟不用跑”，“闽政通”APP注册用户突破850万，政府鼓励企业、个人网上申请办理。

自2019年底疫情爆发以来，众多科技企业积极投入到疫情防控的第一线，利用新兴技术解决了当前在缓解医疗资源紧缺、维护公共场所秩序、加快药物研发、助力医疗保障和社区防控、保障社会民生等领域面临的诸多问题。在此过程中，新兴技术所表现出的灵活性、专业性与高效率，以及互联网企业与平台在助力数字化转型过程中的强大动能，充分体现出中国数字经济市场主体的优势与活力。

2　疫情后中国信息社会建设将会加速抗击疫情中各种新兴技术应用需求的凸显，反映了新兴技术和产业在国家治理、社会治理、经济发展方面所能发挥的重要作用。此次疫情中展现出的国家对新兴技术发展支持政策的出台、新技术自身应用场景的拓宽、传统产业信息化转型势头的加强都预示着，疫情过后中国的信息社会建设将会加速发展。  
**2.1　政府对新兴技术的支持将进一步增加**  
新兴技术产业是国家产业发展的重要组成部分，是国家核心竞争力之一，关乎国家实力和经济发展。此次疫情期间，新兴科技企业在凸显其防疫抗疫方面发挥的关键作用之时，其企业运营因疫情经受的影响也不容忽视。疫情期间国家部委、国务院各直属机构、地方政府等都出台了鼓励新兴技术用于抗击疫情的指导文件。

2020年2月9日，工信部印发《关于应对新型冠状病毒肺炎疫情帮助中小企业复工复产共渡难关有关工作的通知》（以下简称《通知》）就进一步加强对中小企业的财政扶持、金融扶持、创新支持和公共服务等方面推出20条措施。《通知》强调将进一步支持企业数字化转型、支持企业提升智能制造水平、促进大中小企业融通创新发展。

2020年1月30日，国家税务总局发布《国家税务总局关于优化纳税缴费服务配合做好新型冠状病毒感染肺炎疫情防控工作的通知》，强调积极拓展“非接触式” 办税缴费服务，力争实现95%以上的企业纳税人、缴费人网上申报。

2020年2月6日，科技部火炬中心印发《关于疫情防控期间进一步为各类科技企业提供便利化服务的通知》，充分肯定了科技企业的重要性，为科技企业提供便利化服务的必要性，通过推进技术合同认定登记“无纸化”、高新技术企业认定工作线上化、科技中小企业评价工作全流程网上办理等相关政策支持受疫情影响较大的科技企业。此外，北京、上海、天津、重庆、江苏、浙江等省市地方政府都相继出台对疫情期间的中小企业给予扶持的政策。

在抗击疫情中，新兴技术发挥着巨大的作用，政府对科技企业的重视、对中小企业的帮扶、对新型技术创新的鼓励必将对疫情过后新兴技术的发展起到持续性的推动作用。中央和地方政府在公共卫生、医疗、教育和社会治理等领域必将进一步加大对新兴技术和产业发展的政策支持和关注。  

  
**2.2　新兴技术应用场景将进一步拓宽**  
此次突如其来的疫情对各行各业都带来了巨大的挑战，科技企业充分发挥创新精神，快速拓展新兴技术的应用场景，满足了政府和社会在紧急状态下在防控疫情、稳定民生、维护经济社会稳定所需的多种需求。面对抗击疫情的特殊场景，这些需求展现了新兴技术应用场景的丰富度。  
疫情期间，多家互联网企业依托中国疾控中心、国家卫生健康委员会、世界卫生组织等权威组织发布的数据，利用大数据、云计算、人工智能等新兴技术创新开发“疫情地图”“发热门诊地图”“在线寻医问诊”等可视化软件平台，实时呈现确诊病例、疑似病例、治愈病例的动态数据和地域分布，帮助抗击疫情的指挥者有效把握疫情发展态势，制定疫情防控方案；帮助广大群众实时了解疫情情况，关注疫情发展，提高防控意识。疫情结束后，这些产品不仅可以继续服务于我国其他传染性疾病的公共卫生安全治理，也可以向国际社会推广我国公共卫生安全治理的经验。  
在生活保障方面，各大电商平台、外卖平台、物流平台相继推出“无接触配送服务”， 减少人们面对面接触，从而降低疫情传播风险。居民通过线上各类平台采购医药、生活用品、蔬菜食品等，保证足不出户的情况下正常生活需求。外卖平台通过与客户协商将外卖放到指定位置，避免送货人员与客户的直接接触。物流平台采用无人机和机器人配送货物，不仅避免了人与人之间的接触，也缩短了配送时间。  
如前文所述，疫情催生出一大批新的业务场景应用需求，这些需求中的大部分并不会随着疫情的消退而消退，这将会推动大量传统行业的数字转型，使得大数据、人工智能、5G、云计算等科技和产业迎来新需求下的新发展。  
**2.3　社会信息化发展动力将进一步增强**  
传统的社会习惯往往是制约传统社会向信息社会转型的阻力之一。疫情这一特殊的状态下，传统的生活和消费习惯被迫向线上迁徙，在此次疫情带来严峻挑战的同时也应该看到企业数字转型的机遇。  
远程办公、在家办公的理念将会进一步被认可和接受。为了控制疫情的大面积传播，各企事业单位都延迟了复工时间，并要求员工自我隔离14天。这使得远程办公成为刚需，对于数字化能力较强的企业，保障办公、业务操作的线上正常运行则可减小疫情对企业的影响；对于数字化能力较弱的企业，如何利用网络实现运行模式和商业模式的数字转型则关乎企业的生死存亡。在数字化转型过程中，传统企业因为数字化转型成本高、传统办公模式受限等原因导致转型动力不足，但此次疫情无疑将促进甚至倒逼这些传统企业进行信息化转型。  
线上教学模式将被更广泛地接受和推广。线上教学、虚拟课堂、远程教育等在我国教育培训机构早已被采用，但因当前疫情的控制，各省暂定开学时间都已推到三月后（较原计划开学时间推迟1个月），目前小学、初中、高中、大学都开始实施线上教学，线上教学在疫情期间起到了不可替代的作用，这种大规模的远程线上教学实践在我国实属首次。

截至2020年2月2日，教育部组织22个在线课程平台免费开放在线课程2.4万余门，覆盖了本科12个学科门类、专科高职18个专业大类。以往从事线下教学的老师也开始启用各种直播软件为学生开启远程线上教学，对于传统的线下教学模式这是一种创新，是一次空前的在线教学模式推广，也是教育行业数字化转型的体现。在线教学正在改变着社会教育资源的分配方式，此次疫情在线教学既体现了其价值，也反映出需要更加系统地规划线上教育资源平台及教学评价机制，从而建立更立体、质量更高的教育体系。

3　结　论此次抗击疫情的过程，是中国数字经济厚积薄发的一战，既显示出我国科技企业在创新和研发能力上的“战斗力”，也展示出数字经济与实体经济融合对社会经济发展所带来的巨大推动力。尽管此次新冠肺炎疫情将对经济发展带来十分巨大的损失，尤其是对零售业、旅游业和制造业来说更是雪上加霜。

但毫无疑问，中国数字经济的发展潜力与应用前景在疫情中已得到充分印证，对社会治理能力、经济发展模式与生活方式等都产生了巨大影响。十七年前，抗击SARS疫情推动了中国电子商务的发展，使京东、淘宝等一批电商平台崛起。可以相信，新冠肺炎疫情不仅对现有的科技企业来说是一次重要的机遇，也在孕育着新的行业和巨头。
