# 保旺达钟丹晔：创新驱动 安全赋能

2020年3月7日，2019年度“中国网络安全与信息产业金智奖”评选活动圆满落幕，**江苏保旺达软件技术有限公司总经理钟丹晔先生**成功荣膺**“年度人物奖”**。![](../Images/443d95998e4cf5691f36d1b0de13fc9a.png)![](../Images/584f5b65c16f018745f012072c999cd6.png)

  

保旺达创立初始，钟丹晔先生便提出要成为“中国计算机信息安全领域领先的体系设计者、服务交付者和产品供应者”的奋斗目标。二十年来，他带领保旺达人秉持“技术为先、服务为保、人才为本”的理念，矢志不移自主创新，砥砺前行不忘初心。

 

信息安全的最终本质是如何找到信息集中控制与自由流通之间的平衡点。钟丹晔先生认为，最佳途径是以人为核心建立完善的信息安全管理体系，并配套相应的技术能力。保旺达公司是国内最早围绕4A安全管理思想实现完整体系架构搭建与技术能力配套的厂家之一。通过推出全自主研发的统一安全管理平台，针对特定人机数据交互场景，帮助用户快速实现管理配置精细化，策略投放精确化，行为控制精准化的安全目标，力求数据交互过程中的干扰感知最低化。该平台已广泛被应用于金融、政府、运营商等行业。

 

信息安全的永恒课题是如何减少由于阻碍数据流通而影响信息价值。钟丹晔先生提出，关键手段是必须要能做到IPA：识别智能化，管理流程化，控制自动化。内外网跨网数据交换是军工涉密单位的一个重要安全管控场景。原有管理手段重度依赖人工干预，既存在管理漏洞，也影响工作效率。公司通过深度挖掘行业用户需求场景，充分结合自身在安全领域的业务和技术能力积累，创新研发了信息交换管理系统，在实现全载体、全类型、全场景的数据交换安全可管可控可审的同时，极大提升数据流通效率，用安全创造效益。该平台已经在某研究所全面应用。

 

信息安全的管理源头集中在用户核心资产侧，钟丹晔先生要求公司必须提供有效的客户资产管理系统，抓住信息安全管理源头，帮助客户实现全流程、全生命周期的信息安全。公司围绕电信领域的“三无七边资产缺乏防护、安全作业缺乏体系、安全事件依赖人海战术”问题，聚焦“常态化、主动化、自动化、集约化、事先化”的五化建设，通过自研技术，提供主动扫描与被动探测两种技术手段，帮助用户建立自动化常态化的安全作业体系，最大化保护电信企业的资产安全。目前已在江苏电信、广西电信、青海电信得到了实际应用。

 

信息安全能力的提升最终要落地在自身的技术实力。钟丹晔先生号召全公司，积极响应国家主动适应物联网、大数据、云计算、区块链为代表的高技术发展需要的号召，努力加强新技术的业务应用能力及场景适配能力。受益于一直以来钟丹晔先生大力推广要求的“尊重技术、鼓励创新”公司文化，云堡垒、大数据管控，UEBA等利用新技术，适配新环境的产品迅速得以推出。公司希望通过把握信息安全发展趋势，更新安全防护理念，持续实现技术与业务能力自驱动更新升级，帮助用户应对网络新时代信息安全风险。

 

技术是核心，人才是基础。在人才培养和管理方面，钟丹晔建立领导培养机制，合理地挖掘、开发公司战略性的后备干部队伍，为公司的可持续发展提供智力资本支持；推行员工持股激励平台，让个人和公司成为紧密合伙人，稳定优秀的员工队伍。

 

钟丹晔先生表示，保旺达将始终以建设中国自主的信息安全体系为目标，以实现国家安全大业为使命,专注于国内领先的信息安全领域，努力推动核心领域技术突破，为客户提供软件研发、系统集成、技术服务全方位的解决方案与服务，助力网络强国建设。

**中国网络安全与信息产业金智奖**

  

 

“中国网络安全与信息产业金智奖”评选活动由信息安全与通信保密杂志社联合中国网络空间安全网共同主办，从全国众多网络安全企业中遴选出几十家候选企业，并由来自行业、主管部门、研究机构及高校的130余名专家，来自产业一线的1000余位专业人员，以及来自官方、门户、行业等30余家权威媒体担任评委，经过数轮投票评审确定各类奖项。活动旨在促进网络与信息安全产业繁荣，搭建产学研融和沟通平台，以深度价值的挖掘与效能发挥为国家网络安全事业贡献力量，是网络安全行业最具权威及影响力的活动之一。
