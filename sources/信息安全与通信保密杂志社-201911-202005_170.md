# 高端访谈 ｜国网网安殷树刚：守护电网安全, 促进能源互联网可持续发展

**殷树刚**

殷树刚，教授级高级工程师，1991 年 7 月参加工作，2005 年 12 月加入中国共产党。现为国网思极网安科技 ( 北京 ) 有限公司执行董事、党支部书记。中国软件和信息服务十大领军人物，中央企业熠星创新创意大赛优秀导师，国网信通产业集团年度劳动模范。荣获国家电网有限公司 2018 年度软科学成果三等奖，全国电力职工技术成果二等奖、国家电网有限公司职工技术创新优秀成果二等奖。荣获国网信通产业集团“牢记使命勇担当”主题党课竞赛“党组织书记组二等奖”。

  

网络安全关系到电网的安全稳定运行，随着能源互联网的发展，电网安全也提升到至关重要的位置。近年来，能源行业网络安全问题频发，网络安全已经成为影响能源行业安全的重要因素。电网作为关系国计民生的关键信息基础设施，一旦遭到破坏、丧失功能或数据泄露，会严重威胁国家安全和公共利益。电力企业能否保障电网安全以及网络中的信息安全，不仅直接影响其自身的发展与效益，更是直接关系电力系统的安全、稳定、经济、优质运行，影响着“数字电力系统”的实现进程以及国家电力信息系统网络安全的实现。为此，信息安全与通信保密杂志社专访了国网思极网安科技 ( 北京 ) 有限公司执行董事、党支部书记殷树刚。

**记者：请您谈谈国网思极网安科技（北京）有限公司成立的初衷。**

  

殷树刚 ：为落实习近平主席“没有网络安全就没有国家安全”讲话精神，提升国家电网有限公司网络安全与信息安全防护水平，国网信息通信产业集团整合优化网络与信息安全资源，在 2017 年组建了专业的网络与信息安全公司——国网思极网安科技（北京） 有限公司（以下简称“国网网安”），承担国家电网的网络安全研究、运行系统保障等重大使命。国网网安立足于电力信息安全发展需求，以自主技术、产品研发和创新能力为基础，以产业优势支撑服务于电力网络安全与信息化安全， 拥有互联网、调度、运检、 营销、安监等专业业务团队，业务涵盖智能电网“发、输、变、配、用、调度”六大环节，涉及物联网、大数据、云计算、移动互联等领域，提供安全产品、安全运营、安全评测、安全咨询与培训等技术服务。  

**记者：国网网安成立后做了哪些创新工作？与业界其他企业相比，国网网安的优势在哪里？**

  
殷树刚 ：我国能源互联网建设目前处于起步阶段，远未走到能源同互联网跨界融合发展的黄金时代，很多东西都“不确定”“看不清”。因此，互联网企业对涉足能源行业缺乏动力， 大部分能源企业对互联网行业更是有“隔行如隔山”的感觉，往往是想迈又不知道该怎么迈出步子，相互融合发展的观念不足、信心不强。基于此现状，国网网安摒除一般网络安全企业 “懂安全，不懂电”的业务缺陷和能源企业“懂电， 不懂安全”的业务短板，打造了集安全运营中心、IT 共享服务中心、安全运维服务、安全咨询服务、安全检测服务为一体的网络安全服务体系， 贴近电网业务做安全，这是我们与其他一般网络安全企业最大的区别。因为电力工控网络安全已经上升到国家安全战略高度，电力企业面临着如何在复杂的网络空间安全环境中，为用户提供全方位的网络安全保障。因此只有不断加强电力行业的防御能力，才能应对电力行业 网络与信息安全的新挑战。  

优势方面，国网网安聚焦业务安全与工控安全，研发了信息安全攻防演练与实训平台、集中防病毒云平台及网络流量安全监测分析系统等多项软件类安全产品，以及厂站边界工控系统安全威胁监测平台、电力监控系统网络安全监测装置、业务系统安全风险监测审计平台等多项硬件类安全产品，构建了贴合电网特点的网络安全运营平台，聚集了一大批业务精湛的党员骨干，打造了业内领先的攻防技术团队。无论是人才的培养还是技术平台的打造，国网网安都打破了传统思维模式和框架约束。同时， 我们特别注重网安人才的建设，多渠道挖掘、吸纳并破格录用专业技术人才；我们经常不定期地进行内外部攻防演练，随时都在战备状态， 守护电网安全。

**记者：请您介绍一下国网网安在产品开发和技术创新方面的情况。**

  

殷树刚 ：国网网安大力开发核心产品，完成自主化设计开发产品共计10余款，其中，电力监控系统厂站安全监测装置，已用于电网变电站的流量监测、协议分析，发现异常并及时上报处置，保障电力系统的稳定安全运行；自主研发“思极慧眼 - 网络安全保障应急指挥平台”，获得了国资委组织的 2018 中央企业熠星创新创意大赛优秀奖，在党的十九大、70周年大庆等活动中发挥了重要保障作用。此外，国网网安负责支撑国家能源局网络安全工作，牵头编制并发布了《电力行业网络安全行动计划（2018—2020）》《关于加强电力行业网络安全工作的指导意见》。

**记者：请您谈谈国网网安未来发展的战略布局。**

  
殷树刚 ：国网网安一直坚定不移地利用“国网芯”做网络安全，通过制定“123 发展战略”，即“一个核心、两个平台、三个板块”，以“国网网安·国泰民安”为核心，构建“思极网安” 运营平台和安全生态平台，打造信息通信安全、工控安全，以及人工智能三个安全板块。“思极网安”运营平台基于 IT 共享安全服务中心业务，主要提供监测分析、威胁情报、风险评估等服务 ，与安全厂商共同合作构建集团安全服务云；安全生态平台主要提供需求共享、合作开发、情报研究等服务，构建“国网安全智库”， 筹备安全 AI 服务，并基于政策红利打造产学研上下游合作机制。

**记者：您对产业发展有哪些建议及展望？**

  

殷树刚 ：我认为现在存在的问题就是，做安全的不懂业务，做业务的不关心安全，每一个业务都像一个壁垒，企业间的协作非常关键。此外，还要培养网络安全的国家队，网络安全企业不能小而散，就像“木桶原理”，一块短板就能影响整体。希望大家齐心协力克服困难、努力解决问题，共同助力网安产业发展。

**记者：我们了解到国网网安在抗击疫情期间成立了“国网网安特战部队”，全力保障国网湖北电力网络安全，请您跟我们具体分享一下。**

  
殷树刚 ：自新型冠状病毒感染的肺炎疫情爆发以来，湖北的疫情牵动着每一名国人的心， 更牵动着国网网安人的心。国网网安于2月3日集结公司最优秀的网络安全专家成立了“国网网安特战部队”，第一时间发布国网网安特战队“三大纪律八项注意”，严明特殊时期下的工作纪律。2月11日，正式向国网湖北电力递送“国网网安致湖北电力公司的驰援信”，誓与湖北电力共守电网安全。2月12日下午 , 湖北电力提出针对9款所使用的的移动办公应用进行安全测试需求以及企业办公安全注意事项的需求。2月13日上午，特战队连夜完成《企业移动办公安全防护注意要点29条》，发布《疫情期间网络安全风险威胁情报第一期》，为疫情期间企业远程办公和抵御网络安全风险威胁提供防护准则，并于当天下午完成首次安全测试，后续将分阶段进行持续远程支援。特战部队成员以共产党员为骨干，由多名高级网络安全专家组成，他们经验丰富、实力过硬，承担过攻防专项演练、国庆阅兵、湖北军运会等重大网络安全保障服务。  
为保障新型冠状病毒感染的肺炎疫情严重地区政令畅通，“国网网安特战部队”发挥专业优势，以“人民电业为人民”为宗旨，以迎难而上的决心和魄力，24小时不间断全方位支撑国网湖北电力网络安全防护工作，截至目前已为国网湖北电力提供安全测试、网络安全态势综合风险分析与常态保障等服务。疫情防控是一场硬仗、一场大考，我们坚信只要上下一心、守望相助、共克时艰、齐心协力，一定能打赢疫情防控这场硬仗。
