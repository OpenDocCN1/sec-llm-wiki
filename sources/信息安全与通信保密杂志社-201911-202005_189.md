# 航天信息：坚守责任与使命 加力技术创新服务

在2019年度“中国网络安全与信息产业金智奖”评选活动上，**“航天信息手机盾”获2019年度“金智产品奖”和“战疫特别贡献奖”。**这是航天信息继2017年度优秀产品奖（“基于国密算法的电子签章系统”）和2018年度优秀产品（解决方案）奖（“航信区块链平台”）后，第三次获奖。

航天信息手机盾产品定位大规模移动数字证书应用场景，使用手机替代USB Key，无需额外硬件介质，为移动应用提供易用和高安全性的数字证书和签名、加密等基础密码接口服务，有效保护移动端敏感数据安全和交易安全，保障传统业务移动化的安全实现。航天信息手机盾使用自主知识产权的协同签名技术，将私钥分片处理，保障用户密钥安全，由移动端+云端协作生成安全合规的数字签名，支持标准SM2算法验签。同时具备高效SM4白盒加密、代码混淆、移动应用加固、国密SSL通信等多重安全机制，从移动认证安全、数据安全、通信安全、应用安全等层面为移动应用提供全方位的安全支撑。航天信息手机盾可广泛应用于移动互联网、移动医疗、移动商务、移动教育、移动金融、移动办公等使用场景。目前已结合移动数字证书及移动电子签章技术，完成了电子病历、电子税务局、移动开票、电子招投标等多种应用场景的解决方案。该产品已获得国家密码管理局的商用密码产品型号认证，通过密码模块安全二级检测。据悉，航天信息手机盾产品已在多个移动应用中落地实施。2018年手机盾在51发票APP中集成并上线，解决移动认证和数据安全问题，累积服务用户量达47万；2019年安徽省基于手机盾的实名办税APP上线，通过人脸识别解决人证合一问题，发放实名证书数量近5万张。步入数字经济时代，航天信息将始终把党的领导、党的建设融入公司治理全过程，继续以强烈的社会责任感和使命感，积极投身国家重点工程建设，充分发挥技术实力、专业队伍、服务网络以及客户资源优势，服务政府治理、助力企业发展、成就美好生活，迈入高质量发展的新纪元！为全力支援打赢疫情防控阻击战，航天信息党委积极履行央企和上市公司的社会责任，向湖北疫情防控一线捐赠现金350万元，用于当地新型冠状病毒疫情防控。此次捐赠将以专项款汇入航天科工账户，通过航天科工转账至国务院国资委专用账户，最终由国务院国资委统一提供湖北疫情防控一线。此外，航天信息所属广州航软、河北航信、内蒙古航信、海南航信、浙江航信、安徽航信、青岛航信等单位也纷纷行动起来，积极捐款捐物，为打赢疫情防控阻击战贡献力量。

**中国网络安全与信息产业金智奖**

  
  
  
  

“中国网络安全与信息产业金智奖”评选活动旨在宣传理事单位和中国网络安全与信息产业有价值的企业、有成就的人物、优秀的产品及应用解决方案，推动行业创新能力和品牌价值的提升。评选活动从全国众多网络安全企业中遴选出几十家候选企业，并由来自行业、主管部门、研究机构及高校的130余名专家，来自产业一线的1000余位专业人员，以及来自官方、门户、行业等30余家权威媒体担任评委，经过数轮投票评审确定各类奖项。为表彰企业为战疫所做出的贡献，本次活动特增加“战疫特别贡献奖”，该奖项该奖评选的材料来自公开媒体，由评委会编辑整理。
