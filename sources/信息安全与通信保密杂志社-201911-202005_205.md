# 安恒信息：品牌赋能 彰显情怀

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247545256&idx=2&sn=d82b8c1bcfb21d75d11e7257f7887de7&chksm=c0b4ebdef7c362c8b02b97dc6b56e9670ff639c47f36dd2ebc093739c0386b8c2f812ca7a8a4&scene=126&sessionid=1681312231#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247545256&idx=2&sn=d82b8c1bcfb21d75d11e7257f7887de7&chksm=c0b4ebdef7c362c8b02b97dc6b56e9670ff639c47f36dd2ebc093739c0386b8c2f812ca7a8a4&scene=126&sessionid=1681312231#rd)

近日，在2019“金智奖”线上评选活动中，安恒信息实力荣获**“年度企业奖”第一名**与**“战疫特别贡献奖” **两项奖项。

  
![](../Images/15501e2ec0a73d3f52e207747855bf72.png)![](../Images/70653d0ea277de12be6333d297f4147a.png)  
“金智奖”评选活动旨在宣传信息安全与通讯保密杂志社理事单位和中国网络安全与信息产业有价值的企业、有成就的人物、优秀的产品及应用解决方案，推动行业创新能力和品牌价值的提升。  
 “金智奖”评选活动，每年从全国众多网络安全企业中遴选出几十家候选企业，由知名网络安全专家、媒体及专业人员担任评委，经过数轮投票评审，最终确定各类奖项。此外，为表彰企业为战疫所做出的贡献，本次活动特增加“战疫特别贡献奖”，该奖项评选的材料来自公开媒体，由评委会编辑整理。  
![](../Images/f09f36586097c35885118f4b293541ac.png)![](../Images/ec07428ee86af85c5cc26f685444ce22.png)  
作为在云安全、应用安全、大数据安全和智慧城市安全等多个前沿领域深耕的网络安全公司，安恒信息拥有国际一线的核心安全专家团队和最具创新力和自主知识产权的网络安全产品线，用户遍布全国，涉及公安、政府、教育、金融、运营商等众多行业。  
截至2019年12月13日，公司拥有已申请发明专利756项（其中已授权发明专利59项），软件著作权登记153项，出版相关领域著作3篇，发表相关权威论文14篇，牵头或参与制定国家/行业/联盟/团体标准17项，引领信息安全规范发展。  
冠状病毒肺炎疫情期间，作为网络安全领域的重要支撑单位，安恒信息积极组织对疫情严重地区的支援行动，第一时间成立了“防控疫情指挥保障小组”，并相继协助湖北省多家医疗机构和重点医院等进行监测、预警、通报，捐献口罩等医疗物资和千台（套）网络安全设备，还组织向武汉疫情重灾区募捐等等， 彰显出企业应有的责任和担当。  
“金智奖”评选活动由信息安全与通信保密杂志社、中国网络空间安全网主办，北京商用密码行业协会、中关村可信计算产业联盟、中关村智能终端操作系统产业联盟协办。“金智奖”举办三届以来，得到了业界的高度关注和认可，有效地提升了企业的影响力、竞争力和品牌价值，并推动了网安产业的发展。  

**公司简介**

![](../Images/0eebd585af9cbb4dd8abb487e290ecf4.png)     

  

杭州安恒信息技术股份有限公司（简称：安恒信息）成立于2007年，科创板股票代码：688023。自成立以来一直专注于网络信息安全领域，公司秉承“助力安全中国、助推数字经济”的企业使命，以“诚信正直、成就客户，责任至上，开放创新，以人为本，共同成长”作为企业的价值观。  

  

公司主营业务为网络信息安全产品的研发、生产及销售，并为客户提供专业的网络信息安全服务。产品与服务涉及应用安全、大数据安全、云安全、物联网安全、工业控制安全及工业互联网安全、SaaS云安全服务、智慧城市安全运营等领域，覆盖网络信息安全生命全周期的产品体系，能够为客户从安全规划、安全设计、安全建设到安全运营的一站式专业安全服务、重大保障服务、可信众测以及产学研用一体化人才培养服务。多次被评为全球网络安全创新500强，参与了众多国家与行业标准的制定，成为“2018年度国家地方联合工程研究中心”依托单位。
