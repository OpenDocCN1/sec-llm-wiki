# 防疫复工两不误，橙讯助力政企一网畅行

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247545244&idx=3&sn=e03388fa389c101e05c49346252709a3&chksm=c0b4ebeaf7c362fc8b75df2c70ffbe8a71c3f863ff29aeeb6f611e9f88d9556babf80a480701&scene=126&sessionid=1681312235#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247545244&idx=3&sn=e03388fa389c101e05c49346252709a3&chksm=c0b4ebeaf7c362fc8b75df2c70ffbe8a71c3f863ff29aeeb6f611e9f88d9556babf80a480701&scene=126&sessionid=1681312235#rd)

![](../Images/2c4d9a6338e0f7e1d7e2d55bbae28736.png)

**近日，中国电子科技集团正式发布的“一网畅行——复工复产通用管理系统”受到众多政府机构及企事业单位的好评，对其便捷性、安全性等多种功能非常认可，为帮助公众更方便快捷地使用该系统，形成有效联动，卫士通橙讯安全即时通讯协作平台快速响应，全力打造“一网畅行——复工复产通用管理系统”统一入口，帮助政企单位迅速搭建安全移动办公与疫情信息管理平台，避免多线申报，减轻管理负担，实现一站式数据上报与疫情监控。**

  

  

与此同时，作为一款以安全即时通讯为核心的移动办公协作平台，橙讯也将在6月30日前向全国政企用户免费开放安全即时通讯应用及其系列安全服务，全力支援一线防疫工作，为工作人员远程安全移动办公提供有力保障！

![](../Images/96e477f7f405576ee54a4289e802e6f7.png)

  

区别于传统即时通讯应用，橙讯针对政企用户移动办公场景中的安全薄弱环节进行了重点设计，将用户工作相关的敏感信息牢牢限定在可管可控可追溯的安全边界之内，并以商用加密算法为保障，从身份认证、数据传输、通信通话、信息存储等多角度为用户提供全方位的安全防护。

![](../Images/96e477f7f405576ee54a4289e802e6f7.png)

  

一面保安全，一面促生产。橙讯安全即时通讯协作平台与复工复产通用管理系统强强联合，将帮助广大政企客户顺利复工，最大限度减少疫情带来的影响，以实际行动支援疫情防控工作，彰显国企责任担当。 

  

护卫安全，卫士通时刻与您同行！

![](../Images/aeed9148add11b8e61747c4e46aecd60.png)

  

4、在页面下部分，部署了密切接触者测量仪“小护士”、社区管理“小管家”、站点检查“小战士”、企业管理“小帮手”、招聘应聘“小达人”五个软件 APP。点击其中一个二维码放大，长按二维码选择“识别图中的二维码”，即可进入相应的APP；
