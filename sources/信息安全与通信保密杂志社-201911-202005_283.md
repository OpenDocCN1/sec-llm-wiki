# 重要预警：境外黑客组织扬言2月13日攻击我国视频监控系统，中国网安提供全域防护解决方案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247545229&idx=3&sn=cbb0aee1f90f7760bd111c3093e8d5c0&chksm=c0b4ebfbf7c362ed2d87a3b26ca23051c09b9f2e8f88544af3715c2f4947546bf8eac3697167&scene=126&sessionid=1681312237#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247545229&idx=3&sn=cbb0aee1f90f7760bd111c3093e8d5c0&chksm=c0b4ebfbf7c362ed2d87a3b26ca23051c09b9f2e8f88544af3715c2f4947546bf8eac3697167&scene=126&sessionid=1681312237#rd)

近日，境外某黑客组织发布推文称其将于2月13日对我国视频监控系统实施网络攻击破坏活动。同时，其声称已掌握中国境内大量摄像头平台的控制权限，并在某平台公布了70余个视频监控网络设备监控平台链接信息。![](../Images/c733ed601ba2659c554c9e33cf233546.png)

目前，全国约78.9万个开放在互联网的相关监控设备，且与其他物联网设备及控制指挥系统存在不同程度的互联互通，黑客可绕过登录界面直接查看监控内容并获得系统控制权限，直接影响监控视频信息安全，更有可能通过监控系统渗入其他互联控制系统，影响国家关键基础设施安全，危害国家安全，安全风险程度较大。

![](../Images/5d12ad58334871bbf95853ed747d88c6.png)

  
回顾历史上针对视频监控系统设备攻击，主要利用以下几种方式：  
1、弱口令及默认密码、内置密码。2、监控设备固件实现逻辑漏洞以及开源公共组件历史漏洞3、控制协议标准化以及明文传输。因摄像头在国内互联网中的分布十分广泛，而相关视频监控系统、网络摄像头曾出现的安全漏洞并未被及时修补是造成当下被攻击的首要原因。而从以往我国部署的视频监控系统情况来看，其设备往往以产品功能为导向而非安全，传输过程均采用明文传输，极易被黑客组织破解及攻击。该境外黑客组织极有可能已经掌握了此类设备存在的安全漏洞，并获得了进一步利用的方法。中国网安建议:(1) 用户定时更换视频监控设备（IPC、DVR以及NVR等）默认访问口令（口令需要符合一定复杂度，如必须大小写字母+数字组成，长度不低于8位）以及及时更新设备固件等;(2) 针对重要敏感场所及时更换具有可信加固、支持高安全级别（如基于数字身份证书）设备身份认证以及视频信源加密传输保护功能的视频监控设备;(3) 做好安全监控系统和业务系统的隔离防护，避免黑客以监控系统作为跳板攻击，影响业务应用安全;(4) 同时做好视频网络风险排查、资产梳理和安全加固工作，加强视频监控网络的安全监控管理工作。

********![](../Images/a1a7473609c5e9608caf9937bfa5d6c3.png)******网安方案：基于三零视盾为用户提供全域防护** 

中国网安已基于“三零视盾”平台为用户提供全域防护解决方案。平台综合运用信息安全与人工智能技术，构建覆盖“物理+网络”的安全防护体系，实现从物理空间到网络空间一体化的安全防护，真正实现构建基于零信任网络的安全可信、同时兼顾智能的零边界体系。  
在网络安全防护层面，该系统以可信3.0的主动防御技术为基础，通过视频安全准入系统以及设备实体身份安全认证等，实现系统的设备可信安全，构建零信任的网络安全架构。同时采用多模态密码技术对视频信息进行保护，通过视频安全传输体系（信源加密、信令加固、可信机制保障）+视频应用防泄密系统（防软件截屏、防手机拍照、防视频非法拷贝、篡改）实现视频信息的全过程网络安全，为视频信息提供从传输、存储到查看的全过程安全保障。

![](../Images/d42a00d9d8db7346a7e466cf6b2f1091.png)

同时，该系统配套提供目前国内最全的密码安全设备（如基于国产密码的各类摄像机、安全接入设备、密钥管理服务器、安全管理服务器、安全流媒体服务器等），设备均采用信源加密及加载CA双重认证功能，基于动态密码为用户提供全域安全防护。

 

![](../Images/f8b79fa5329ccfcf6fac4f1ed2d76e3c.png)

*安全监控系列产品家族*

**实战成效：****已在多个国家重点关键场所进行部署，运行安全稳定**

目前，国内外已发生多起大型因视频监控信息泄露导致重要关键基础设施被破坏、大量文件失泄密的情况，尤其是针对大量用户关注的“可信用户的不可信操作”问题，迫切需要引入基于密码的视频安全传输体系及视频应用防泄密系统助力。中国网安作为国家网信事业的重要战略科技力量，在党和国家有需要的时候，不断攻坚克难，笃定前行。此前，中国网安已基于“三零视盾”平台延伸形成公共应急医疗防控综合解决方案，为四川某市在疫情防控中提供技术支撑，成功利用“超分视频增强”将不清晰的公交车视频进行高清还原，有效解决当地公安因视频不清晰带来的寻人不便问题。目前，中国网安已基于“三零视盾”平台在国内多个重要关键场所对视频监控系统进行改造升级及安全加固，目前均运行稳定安全，尚未出现摄像机漏洞被利用导致信息被获取及失泄密事件的发生。

![](../Images/2609beac0843abdb278c4c840340277a.png)

经过多年的深入研究与积累，“三零视盾”已逐步推出并形成了覆盖前端安全、数据安全、物理安全、智能应用、态势感知于一体的全系列产品，并根据用户需求，不断进行衍生和拓展，形成了可满足不同行业、不同需求的综合性一体化安全智能解决方案，中国网安将持续关注本次事件，为用户网络安全保驾护航。
