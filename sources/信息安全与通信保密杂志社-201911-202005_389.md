# 网络安全应构建生态化防御体系

**网络安全应构建生态化防御体系**

  

国家能源局电力司司长童光毅近期表示，希望在网网络安全应构建生态化防御体系络安全建设过程中，在已有的横向隔离、纵向认证基础上，能够构建一个生态化网络安全防御体系。否则，泛在电力物联网的建设就如同空中楼阁。他是在“泛在电力物联网智能感知技术论坛”上作此番表述的。

  

![](../Images/21900bed84c7cafd3d541d713693c009.png)![](../Images/be15508cc68ee67a105eb8cadc03aecf.png)![](../Images/91a096bc21c90f01f3ba2d421928ddeb.png)

  

童光毅指出，国家电网公司今年提出了三型两网的世界一流能源互联网企业建设的新战略，积极鼓励具备条件的地区因地制宜开展能源互联网试点示范，并安排了多项能源互联网的行动计划，开展了能源互联网标准体系的专题研究，搭建了能源互联网产业技术创新的平台。

  

童光毅强调，泛在电力物联网的建设要同步构建网络安全防护体系。他现场分享了“一个新的观点”：多年来我国电力系统网络安全防护一直走在前面，但用的是横向隔离、纵向认证的体系，“这是一个固化的体系，即假想人都是正常的，或者未受到外界恶意攻击的情况。如果我们看不清楚敌人是谁，这个体系就很难防御网络攻击”。所以，他认为新时代应该有一个新的生态化防御体系，这个体系的重要特征就是在有攻击的时候，防御才会体现出来，迅速应对，同时形成坚强的隔离网络或者反攻网络，确保系统的安全稳定。
