# 以开放的姿态，拥抱全新的未来——飞腾首届生态合作伙伴大会隆重召开！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247545185&idx=3&sn=5c86ba3508737b3380edb62a8bface1d&chksm=c0b4eb17f7c36201799b35f30d4c21d1a0289a33f69bf3b06a35f8c688209ee706c6413cb027&scene=126&sessionid=1681312244#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247545185&idx=3&sn=5c86ba3508737b3380edb62a8bface1d&chksm=c0b4eb17f7c36201799b35f30d4c21d1a0289a33f69bf3b06a35f8c688209ee706c6413cb027&scene=126&sessionid=1681312244#rd)

2019年12月19日，首届飞腾生态伙伴大会在北京成功举办。大会吸引了 500 余家飞腾合作伙伴单位，包括众多两院院士、业内专家、政府主管部门、行业协会、用户单位、软硬件厂商、系统集成商、媒体和金融机构等来自全国各地的代表共计 2000 余人参加。飞腾于大会现场重磅发布飞腾安全平台架构标准 PSPA，以及多款基于飞腾 CPU 的计算机和网络安全产品。

![](../Images/da557c026380f50fdaa92537a91789e6.png)飞腾公司总经理窦强于大会致欢迎辞，并发表题为《山高人为峰，做新时代的攀登者》的主题演讲。![](../Images/fed2281c399fcb8f4ecb684367a02088.png)2019年，是飞腾首款产品诞生 20 周年，也是公司成立 5 周年，这一年飞腾的产品在国内政务办公、金融、电力、轨交等领域实现了国产化应用的新突破。飞腾本着 “ **核心技术自主创新，产业生态开放联合** ” 的发展道路，以 “ **聚焦信息系统核心芯片，支撑国家信息安全和产业发展** ” 为使命，将联合合作伙伴，继续推进飞腾 CPU 的产业化应用。未来是万物互联的时代，飞腾 CPU 在满足桌面、服务器和嵌入式等通用算力的基础上，还将继续加大投入，满足未来 IoT、边缘计算和人工智能等专用算力的需求，以 “ **成为世界一流芯片企业，用中国芯服务社会** ” 为愿景，做新时代的 “ 攀登者 ”，实现国家信息产业的新腾飞。![](../Images/d5562f6b504693045819a8c906b7ebee.png)中国工程院院士沈昌祥于大会发表题为《用可信计算 3.0 筑牢网络安全防线》的主题演讲。他强调，没有网络空间的安全，信息社会的安全更无从保障。我国要尽快在核心技术上实现突破，加快网信安全产品应用，确保国家网络空间实现本质安全。![](../Images/85a205aa2b4ad229a997316e82160009.png)

**匠心铸国器，飞腾 PSPA 安全标准发布**

当下，加强国产信息系统的安全可信水平时不我待。飞腾副总经理郭御风博士于本次大会发布 “**飞腾安全平台架构标准** ”（Phytium Security Platform Architecture，简称 PSPA） 1.0，以及 PSPA 白皮书和相关技术规范。![](../Images/2234c0cfd3193693aa4a4263dcca849f.png)内生安全，从芯出发，PSPA 标准是飞腾自主定义的安全处理器架构标准。郭御风表示，PSPA 统一了飞腾安全可信 CPU 的属性和功能，规范了软硬件厂商的接口，目前 PSPA 已经在飞腾的最新产品 FT-2000/4 中实现应用。PSPA 安全标准的发布，是飞腾坚持核心技术自主创新的又一有力体现。 ![](../Images/7a219217fdef296ce36e6a4e259a8737.png)

**知心绘蓝图，共话飞腾生态产业发展**

中国信息通信研究院发表《新时代、新实践、新生态》的主题演讲，介绍了国内政务领域在数字化转型建设中的实践，以及建设起基于安全可信 CPU 的完善、健全信息系统生态的重要性。  
中国联通网络技术研究院网络安全研究中心总监马铮，以运营商的角度分享了在 5G 时代下，泛在物联网领域的安全策略研究。国电南自总经理，分享了飞腾 CPU 在电力自动化控制系统中的应用。国电南自基于飞腾 CPU，在电力领域实现了安全过程控制站、分散控制系统的国产化应用，并实现了满负荷情况下的稳定运行。 本次大会上，飞腾还与华迪、浪潮、华宇、东软、东华软件、万达信息、中国系统和中国软件 8 家信创领域领军集成商签署战略合作协议，联合推动飞腾 CPU 更广泛的应用。

**同心筑生态，多款新品联合发布**

大会期间，多家企业发布了基于飞腾 CPU 的全新产品，覆盖桌面终端、金融、网络通讯、工业控制以及轨道交通领域。  
飞腾联合联想、浪潮、长城、同方、曙光、紫光恒越、北京计算机技术及应用研究所、山东超越、中国电子第六研究所、武汉攀升发布了多款基于 **FT-2000/4** 的台式机、一体机、笔记本电脑以及工控机产品。![](../Images/6e472873ea75af4619041e80ab4381d7.png)飞腾联合长城金融、浪潮金融、中电金融发布了多款基于 **FT-2000/4** 的金融产品，类型涵盖存取一体机、智慧柜员机和金融工控机等。![](../Images/af24a6c5e5800adfe772762627c22967.png)**关于 FT-2000/4 处理器**

FT-2000/4 是飞腾最新发布的微处理器产品，采用新一代飞腾自主高能效处理器核，全芯片性能相比飞腾上一代产品提升近一倍，功耗降低 33%，同时硬件实现安全增强，支持 PSPA 标准及多种国密算法。

![](../Images/a94c55ceb847eefaacc45123860c5d2c.png)

该产品适用于构建台式机、一体机、笔记本电脑以及瘦客户机等终端产品，同时可以通过“关核”、“降频”等方式，在嵌入式领域实现低功耗应用。

飞腾联合紫光恒越、迈普、迪普、网御星云等9家国内企业，发布了基于飞腾 CPU 的全新网络及安全产品。 ![](../Images/5a7e4abde8aa9cab4e35b0aa280a62eb.png)飞腾联合中软万维和天津轨道交通运营集团，发布了基于飞腾平台的地铁售检票系统应用。该产品为人脸识别闸机，可用于地铁、写字楼、社区等环境，目前该产品已成功应用于地铁。![](../Images/f50ff2d5a275060ca3cbb89782cba2c8.png)

**凝心谋发展，应用成果大放异彩**

飞腾 CPU 具备高性能、低功耗、自主先进、安全可信的特点，也是国内唯一具备从端到云完善自主全栈解决方案的国产 CPU（[点击查看](http://mp.weixin.qq.com/s?__biz=MzIyMzE0ODc3Ng==&mid=2650482920&idx=1&sn=914094278a54165166b18f7186725833&chksm=f02d276fc75aae7982da01e7e079703dff7bffc1364f08a2885fb4564bb5a239d625053caaed&scene=21#wechat_redirect)），在我国党政办公、云计算、金融、电力和轨道交通等领域具备成功的应用案例和成熟的解决方案，有效助力我国关键领域实现国产化的应用和升级。来自中兴、腾讯和紫光恒越的代表，介绍了飞腾 CPU 在通信、5G 核心网、云计算等领域的成功应用。![](../Images/86ac56c255fcbedb997b982ac4504f25.png)![](../Images/6fbe9e91183470328e13781c1068d4c2.png)在 AI、边缘计算和区块链等新兴领域，飞腾也同国内相关单位一道开展布局。百度公司于大会分享了飞腾 CPU+百度昆仑芯片在 AI 计算上的探索，广东汉为、恒为科技分享了飞腾 CPU 在边缘计算侧和国产化信息处理平台的应用，比特大陆分享了基于飞腾平台在区块链领域的研究和实践。![](../Images/c81efd9eee80589d00c0516fe04ea498.png)本次飞腾生态合作伙伴大会还举行了**高新电子**、**政务金融电信**以及**能源交通**三场分论坛，来自国内相关领域的企业和科研单位近千余人与飞腾齐聚一堂，分享应用成果，共谋产业发展。现场展示区，共有 130 多家企业展出各种基于飞腾 CPU 的先进产品和解决方案，展现了飞腾 CPU 活跃的产业生态和广阔的应用前景。![](../Images/014f30dffa2997b7f95c5cb71712c169.png)![](../Images/681c88df1f46bc77b48a9dba189c21ae.png)![](../Images/9801337266945bf49e274ff77715aece.png)
