# 面向CR-NOMA的动态频谱共享模型与分配算法研究

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247545170&idx=3&sn=ca38591b5ba5e0b3d8808515979db884&chksm=c0b4eb24f7c3623218fc45be7bacd44d9cf659802b4a4fb0f258415c415491a6e84f0c47d6b6&scene=126&sessionid=1681312247#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247545170&idx=3&sn=ca38591b5ba5e0b3d8808515979db884&chksm=c0b4eb24f7c3623218fc45be7bacd44d9cf659802b4a4fb0f258415c415491a6e84f0c47d6b6&scene=126&sessionid=1681312247#rd)

认知无线电具备感知频谱环境和伺机灵活接入频谱能力,能够支撑不同无线电系统之间的频谱资源动态共享，提高频谱利用效率和解决制约无线通信可持续发展的频谱资源稀缺问题。

认知无线电与非正交多址接入技术结合的认知非正交多址接入技术，支持认知用户通过正交、非正交方式在域内和域外进行频谱共享，极大地提高了频谱接入和频谱共享的灵活性。

针对认知非正交多址接入技术提供的灵活频谱接入能力及其充分利用频谱资源的需求，提出基于网络化频谱地图数据库的动态频谱管理模型；从需要解决的两个关键性问题（即频谱资源分配和信道间干扰问题）入手，分析关于用户分组、功率分配及联合优化等问题的频谱分配算法，并进行对比仿真分析，展望更加高效的动态频谱共享模型与关键算法。

  

无线通信技术已成为现代信息社会重要的基础设施，并正向泛在化、高速化、宽带化以及异构化快速发展。在现有无线业务用户数量及其带宽需求快速增长的同时，新的无线通信技术和业务不断出现。移动数据流量在近10年内预计增长1 000倍，满足如此巨大的负载增长需求成为无线通信领域面临的重大挑战。

随之带来的用频设备种类日益增多、数量呈几何级数增长、用频需求大幅增多的严峻形势，使频谱成为制约社会经济发展的重要资源。尽管现行的频谱管理手段和系统在一定程度上可实现频谱资源的合理分配和干扰的有效消除，但目前的静态频谱分配方式凸现出频谱效率低下的弊端。

具备感知频谱环境和伺机灵活接入频谱能力的认知无线电（Cognitive Radio，CR）能够支撑通过不同无线电系统频谱资源的动态共享，提高频谱利用效率和解决频谱资源问题。

目前，电视空白频段（TV White Space，TVWS）、AWS-3频段、3.5 GHz频段、5 GHz频段和毫米波频段等多个频段已经开放或计划开放用于非授权设备动态频谱接入。日本NTT DOCOMO公司于2014年提出的非正交多址接入技术（Non-orthogonal Multiple Access technology，NOMA）是提高频谱利用率的另一种新技术，通过功率域或者码域的复用支持。

与相同域频谱资源同时接入与传统正交多址接入技术相比，NOMA在相同的频谱资源上能够支持更多的用户接入，上下行链路分别可以获得20%和30%的系统容量增益，被视为应对无线电通信网络面临的频谱需求问题、提升频谱效率的关键技术。

CR与NOMA相结合的认知非正交多址接入（Cognitive Radio Non-Orthogonal Multiple Access，CR-NOMA）技术，支持认知用户通过正交、非正交方式在域内和域外进行频谱共享，为提高频谱效率提供了更大的灵活性。基于CR-NOMA技术进行动态频谱共享，需要建立新的共享模型并突破其中用户分组、功率分配等关键技术。

本文在分析CR-NOMA技术特点的基础上，研究面向CR-NOMA的动态频谱共享模型，重点探讨其中的动态频谱分配算法，为面向CR-NOMA的动态频谱共享提供支撑。

**1 **动态频谱共享模型****

  

**1.1　基于CR-NOMA的动态频谱接入**

NOMA技术的基本思想是在发送端采用分配用户发射功率的非正交发送，主动引入干扰信息，在接收端通过串行干扰抵消（Sucessive Interference Cancellation，SIC）技术消除接收机干扰和实现正确解调。通过融合3G的SIC和4G的OFDM技术，既克服了3G系统中的远近效应问题，又解决了4G系统中的同频干扰问题。NOMA是真正利用频域、时域、功率域的多用户复用技术，其中解决频域子载波间干扰的技术仍然是各子载波间的正交，解决时域正交频分复用（Orthogonal Frequency Division Multiplexing，OFDM）符号间干扰的技术仍然是严格的子帧同步和添加的保护时隙（Guard Period，GP），解决功率域各用户功率间干扰的技术则是串行干扰消除技术。在发送端，NOMA采用功率复用技术，使同一子信道上的不同用户信号功率按照相关算法分配，使得到达接收端的每个用户的信号功率不一样。在接收端，NOMA采用SIC技术，根据不同用户信号功率大小按照一定顺序进行干扰消除，达到区分不同用户的目的。CR与NOMA相结合的认知非正交多址接入技术最早由英国纽卡斯尔大学的Zhiguo Ding教授在文献\[6-7\]中提出。将NOMA作为CR的特例，在单个下行载波上同时支持次用户（Secondary User，SU）和主用户（Primary User，PU），通过限制SU发射功率保证PU的服务质量（Qualityof Service，QoS）需求。基于CR-NOMA的动态频谱接入场景如图1所示，在PU基站覆盖相同的范围内，一个或多个次级认知基站（Cognitive user Base station，CBS）和SU寻求在保证PU的QoS的前提下共享频谱。![](../Images/3293b55917d8cb8e3d6482fd1c423c07.png)图1　基于CR-NOMA的动态频谱接入场景  
**1.2　面向CR-NOMA的动态频谱共享模型**针对CR-NOMA接入技术提供的灵活频谱接入能力及其充分利用频谱资源的需求，提出基于网络化频谱地图数据库的动态频谱管理模型，如图2所示。动态频谱管理与服务依托部署于CBS的网络化频谱地图数据库，通过频谱知识库、信息库、决策案例库以及管理案例库，实现对CR-NOMA网络的动态频谱管理与服务。在目标区域内，频谱地图数据库提供频谱知识库、信息库，支持CR-NOMA网络进行频谱机会（Spectrum Opportunity，SOP）信息获取；在SOP信息获取的基础上，CR-NOMA网络进行SOP优化利用的决策，并将决策案例提交给频谱地图数据库的决策案例库；区域内频谱管理的案例则记录入频谱管理案例库。SOP信息获取与SOP优化利用通过SOP信息指标耦合，其中包括可用时间、可用概率和信道增益等因素。![](../Images/ab2092f4ea27ae71c4f6b1e967bfed56.png)图2　面向CR-NOMA的动态频谱共享模型其中，CR-NOMA网络可以直接通过频谱感知获得频谱数据。当有频谱地图支撑时，可以通过查询获得频谱信息和频谱知识，降低SOP信息获取的时间开销。在可以获取频谱地图支持的情况下，CR-NOMA网络SOP信息获取架构如图3所示。![](../Images/ef147c7bc152a4960c9fe46fb4563a5f.png)图3　SOP信息获取架构**1.3　需要解决的关键问题****1.3.1　频谱资源分配问题**现有基于CR-NOMA的动态频谱共享算法通常仅考虑吞吐量、能量效率等单个目标，而未考虑到多个目标的联合优化问题，难以适应用户多样化需求，需要降低功率损耗和复杂度，考虑容量最大化问题，以得到最优的解决方案。**1.3.2　信道间干扰问题**以4G/5G动态频谱共享为例，4G为宽带系统，信道配置相对粗放，控制信道、导频等均为全频带映射，而5G也为宽带系统，同样存在各类物理信道。如何既能完美解决两种制式之间的各种物理信道的干扰，又能提升业务信道在共享频谱上的整体频谱利用率，需要有统筹合理的频谱分配算法支撑。

**2 **动态频谱分配算法****

在CR-NOMA动态频谱共享模型下，需要设计高效的频谱分配算法，以支撑频谱资源在不同用户之间的共享使用。由于CR-NOMA在相同资源域内能够支持多个用户接入，需要解决用户分组、功率分配及其联合优化问题。  

**2.1　用户分组**NOMA技术允许多个用户在相同载波上同时通信。用户分组主要解决如何建立用户与载波的分配关系问题。文献\[8\]提出了一种基于信号差异对齐（Signal Difference and Alignment，SDA）的用户分组算法，其依据大尺度衰落对用户进行分类，并通过信号空间对齐（SignalSpace Alignment，SSA）选出匹配用户来最小化多用户干扰。文献\[9\]研究了基于NOMA的下行多用户波束形成系统，提出了功率分配和用户调度方案。它的思路是通过基于半正交的用户分组算法（Semiorthogonal User Selection，SUS），选择信道增益足够强的弱用户来最小化用户间干扰，从而提高系统总容量。文献\[10\]基于相同的系统模型，引入了迫零波束成形（Zero-Forcing Beam-Forming，ZFBF），旨在解决系统总容量问题，增加可支持用户的数量，并提出一种最小集群间及用户间干扰的聚类算法，减少来自其他波束和用户的干扰。**2.2　功率分配**功率分配解决在一个或多个子载波上的多个认知用户功率配置的优化问题。文献\[11\]研究了多用户NOMA的能量效率优化问题，采取切比雪夫法将该非凹多目标优化问题转化为单目标优化问题，并提出实现局部最优的功率控制算法。文献\[12\]将CR-NOMA推广到上下行链路灵活功率分配的场景，给出了优于OMA的门限条件和相应的功率分配方法，提供了系统中吞吐量和用户公平性之间的灵活折中。针对CR-NOMA中SU性能难以充分优化的问题，给出了使NOMA性能优于OMA门限的方案，并提出了相应的功率分配因子计算方法。**2.3　联合优化**联合优化旨在同时优化功率控制、用户分组、时隙分配等问题。文献\[13\]研究了下行NOMA系统中一个基站和多用户场景下多时隙速率控制和功率控制的联合优化问题，采用Lyapunov优化机制将列队稳定转化为单时隙约束，提出了基于动态规划的功率分配算法，以实现近似最优化。文献\[14\]研究了Het-Nets中NOMA频谱分配和功率分配的联合优化问题，其中频谱分配建模为多对一稳定匹配，功率分配建模为非凸模型，采用序列凸优化机制求解近似最优解。文献\[15-16\]研究了认知OFDM-NOMA系统中感知时间、功率分配、载波分配的联合优化问题，提出了一种交替迭代算法来对3个子问题进行联合优化，通过循环优化3个变量获得近似最优解。表1总结了现有典型算法主要解决的问题和各自的优势。表1　现有算法比较与分析![](../Images/cee4ea00f5519a4906d3626fca88f940.png)

**4 **结 语****

本文主要对当前面向CR-NOMA的动态频谱共享算法研究发展现状进行具体阐述和分析，勾画了面向CR-NOMA的动态频谱共享场景。

针对动态频谱共享面临的主要问题及挑战，归纳了几种具体算法进行优缺点比较分析，并通过MATLAB重点对用户分组中的3种算法性能进行仿真评价和分析。

综上所述，当前迫切需要结合最新的频谱接入技术、智能学习算法等研究动态频谱共享模型与关键算法，推动面向CR-NOMA的动态频谱管理的取得突破性发展，为有效解决频谱稀缺问题提供技术支撑。
