# 院士郑建华：密码研究需要面向实际应用

**网络时代，密码安不安全？**

近日，2019年“巅峰极客”网络安全创新发展论坛在成都举行。现场，中国科学院院士郑建华表示，密码是网络安全的核心技术之一，但体量不够，还需要有创新突破。

  

“**密码研究要紧紧围绕国家信息安全需求，面向实际应用。而当前我们的密码理论研究和密码实际应用的结合有待进一步加强。**”在郑建华看来，密码技术是网络安全核心技术之一，但需要思考，如何充分发挥密码技术、如何发挥好密码技术在整个网络安全中的作用。

  

郑建华为信息分析领域专家，长期关注复杂信息系统分析和相关基础理论研究。现场，他分享网络安全新形势下密码研究的关键问题。

  

在他看来，数据在采集、传输、存储、使用中的安全，具有保密性、完整性、可用性、可控性、不可抵赖，“**要注重密码技术在整个网络安全中的作用发挥，密码的安全原理是计算不可能，其他安全技术是增加攻击成本和代价，要尽可能把安全与密码绑定，比如身份认证技术等。**”

  

郑建华指出，网络安全的新形势有三方面特点：

  

***1***

网络攻防水平水涨船高

***2***

攻防从信息的攻防到设备、设施的攻防，随着人工智能的应用，智能驾驶、智能交通、智能家居的应用，可能最后会直接影响到人

***3***

新技术发展，特别是以信息技术为牵引的新技术，像云计算、大数据、人工智能、区块链技术在快速发展，对网络安全提出了一些新问题

  

郑建华尤其提及数据安全，他表示，在数据安全里，具有用户多、数据量大、数据所在地不确定、操作多样等特点，大数据安全比一般信息系统安全更为复杂，需要考虑静态数据安全、数据传输和处理过程安全、结果的真实性及不可抵赖性等。
