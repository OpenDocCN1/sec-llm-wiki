# 一场盛会，三大展台亮相！

11月24日，为期两天的世界互联网大会·互联网发展论坛在浙江乌镇正式落下帷幕。作为峰会的“老朋友”，中国网安再次亮相“互联网之光”博览会中国电科展台。同期，中国网安在中国电科乌镇基地一期展厅，乌镇基地二期展厅一并亮相，携安全服务新模式助力中央企业高质量发展。

![](../Images/c733ed601ba2659c554c9e33cf233546.png)

  

![](../Images/4bca916f83185f513c50cbb7f91ea98e.png)![](../Images/b67b38418a21da4358e61cea6b350eb5.png)

在“互联网之光”博览会上，中国网安展区通过“区块链服务”“IT安全运营服务”“OT安全运营服务”等三大新业务模式，展示了其在网络安全领域的创新安全服务新模式，全面支撑政府、企业数字化转型和国资监管工作。

在乌镇基地一期展厅，重点展示中国网安在工业互联网领域的业务布局；乌镇基地二期展厅展示了中国网安在关键信息基础设施的网络安全防护方面取得的典型案例和系列成果，为工业企业信息安全保驾护航。

  

![](../Images/f5a418385637c193ad176ba02e3b89d9.png)今年的世界互联网大会·互联网发展论坛，是在新冠肺炎疫情全球蔓延、国际格局深刻演变的复杂背景下召开的，论坛期间举行的“互联网之光”博览会聚焦世界互联网最新发展趋势和前沿技术动态，吸引了130多家知名企业和机构参与，集中展示了人工智能、云计算、大数据、区块链、5G等新技术、新产品、新应用、新成果。**三大展台精彩亮相，使中国网安的创新科技、理念、产品和服务被更广泛地传播，助力中国网安加快建设成为世界一流的网络安全企业！**
