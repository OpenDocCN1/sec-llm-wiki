# 2020“巅峰极客”论坛：中国网安董贵山说透智慧城市

10月26日，2020“巅峰极客”网络安全技能挑战赛重要配套活动之一的2020“巅峰极客”新经济网络安全发展论坛在成都高新区如期举办。此次论坛由四川省互联网信息办公室指导，成都市互联网信息办公室、成都高新区管委会、中国网安主办，成都国信安信息产业基地有限公司承办。

论坛以“聚焦数字经济新未来，构筑网络安全新高地”为主题，邀请网络安全行业内知名专家、行业大咖深度分析当前风起云涌，变幻多端的国内外网络安全形势，解读工业互联网安全保护制度等国家政策及2020年我国网络安全产业发展的现状和趋势。与此同时，还邀请骨干型、创新型网络安全企业参加论坛，为成都网络安全产业发展献言献策。中国工程院院士陈鲸、中国电科首席专家、中国网安副总工程师董贵山、无糖信息CEO朱鹏、成都科来总经理林康、亚信安全工控安全产品总经理王建军、永信至诚战略拓展资深专家马志强分别从大数据应用、平台化密码服务、网络犯罪对抗策略、工控网络安全解决方案、工业互联网安全防护、网络安全思维等方面提出了网络安全发展的见解。  
  
![](../Images/7197afb329578ac53617f787e44bbbb4.png)

**董贵山以《万物互联、安全感知的智慧城市密码保障体系——打造护航智慧城市安全发展的平台化密码服务》为题**，分析了智慧城市网络安全发展现状及趋势，阐释了智慧城市安全设计理念，分享了中国网安关于构建智慧城市密码保障体系的相关应用与服务。最后，董贵山根据当下智慧城市发展情况，提出三点建议，一是要致力于强化顶层设计，打造泛在、深入、体系化应用密码，为城市安全生命体赋能；二是持续构建开放的城市密码服务运营平台，塑造城市内生安全基因，保障城市安全生命体健康发展；三是深入建设开放密码服务运营平台，打造智慧城市密码应用新动能。董贵山的讲话将网络安全观融入智慧城市构建，具有很大的建设性意义，在现场引起了热烈讨论。

![](../Images/8250f23ba254f31e1da5817b19410521.png)▲董贵山据悉，“巅峰极客”网络安全技能挑战赛自2018年首届举办以来，已发展成为国家级网络安全知名赛事品牌，跻身网络安全团队和知名战队“最想参加的十大国产比赛”之列，并永久落户成都。今年，大赛从9月7日报名起，吸引了4081支战队、135522人报名参赛，9月26日，线上初赛圆满结束，前12名优秀战队顺利晋级。总决赛即将于10月27日打响，将以今年初突如其来的新冠肺炎疫情为背景，延续2019年城市网络安全演习的思路，和多种角色配合应对的设定，组织各方力量，上演攻防实战演练和态势推演。
