摘　要

基于飞腾 CPU 体系架构的安全可信的存储系统，是面向国内专业机构、机关单位、军队系统的需求打造，提供从硬件架构、软件系统和核心算法的技术体系，提供全方位、体系化的数据保护解决方案。实现了关键数据的保护和加密，适合各种对数据可靠性及性能要求较高的存储应用。目前经过国家级检验功能性能已达到国际水平。

０

  

引　言

在国家科技实力不断发展的今天， 面对国产化替代的发展趋势， 在国家的政策推动下以及各党政军民的市场作用下，各行业客户对自主可控的国产化产品有了迫切的需求。自主可控技术的发展对国家信息安全建设起到了核心支撑作用 。而数据安全是信息安全的核心组成部分， 是信息产业体系安全可控的保障。  

存储作为数据的最终载体，它对于网络安全来说是一道必须守住的“底线”。一方面， 由于存储系统有层层技术壁垒，核心软硬件具有较高的技术门槛；另外一方面，由于历史原因，存储系统的核心软硬件技术是被少数几家国际存储巨头所掌控，而且存储相关的标准制定也深受历史发展策略的影响。为了守住底线， 突破技术壁垒，打通上下游，进行自主研发， 本项目以飞腾 CPU 为基础，自主研发的安全可信的存储系统为核心，实现对关键数据的保护和加密。自主可控存储系统是国产存储发展历史上的一个里程碑，它实现了从硬件架构、软件系统再到核心算法的自主可控，并且能够真正形成产品市场落地与应用。

１

  

总体介绍

存储作为数据安全的重点，本项目通过自主研发（硬件架构、软件系统和核心算法）来解决长期以来困扰我国信息安全基础建立在“沙滩上”（IT 系统设备主要都是依赖国外进口） 的问题， 通过底层系统植入安全可信的模块解决安全“打补丁”的问题，深度解决数据的安全存储的保障问题。目前研发的基于飞腾 CPU 的自主可控存储（如图 1 所示），为数据安全的保障提供了一款高效、安全、可控的技术选项。更为重要的是，研发的自主可控存储系统在国产化的同时，在性能、可靠性及功能上完全不逊色于国际巨头的产品。

![](../Images/0ef4307cec5f2150b76401b29e4f895e.png)

**图 1 基于飞腾 CPU 的自主可控存储硬件实体**

产品系统设计适合各种对数据可靠性及性能要求较高的存储应用，如中小型数据库、中小型医院核心业务系统（HIS、LIS 等）、新媒体制作、视频非线编、高清视频监控、高清制作网、高性能计算、私有云环境下云计算等，并广泛应用于政府、大中型企业、能源、交通物流、医疗、国防、新媒体、广电、影视特效制作等行业。

２

  

系统架构

整个自主可控存储体系设计按照国际通用标准设计，从前端的SAN 和NAS 统一架构，到国际通用的控制器双活模式等全部按照标准中端存储设计。

如图2 所示，硬件架构上采用双控制器架构， 控制器使用飞腾 1500A 16 核处理器，控制器之间采用 PCI-E x8 的链接；控制器和硬盘之间通过 SAS 接口相连，两个控制器可以同时访问同一组硬盘，从而在硬件上支持高可靠。

![](../Images/69659316286f821c2e602b955d43c37c.png)

**图 2 自主可控国产唯一一体化统一存储架构**

在高可用的硬件架构上，本产品从软件上以共享的磁盘访问为基础，使用 PCI-E 的互联机制实现了双控双活的存储系统。同时使用软件将SSD、HDD 和NVME 的缓存统一管理和使用， 通过 FC、iSCSI、NFS、CIFS 等协议为用户提供统一混合存储系统。

３

  

技术创新

**3.1 基于飞腾 CPU 的多核性能优化**

存储系统经过优化，可以直接调用 Linux 内核的驱动，实现了性能最大程度的优化：

（1） 优化 IO 部分的中断、数据处理方法， 采用中断和 CPU 核心绑定的方法，让数据和CPU 核心匹配，减少 CPU 间的数据访问开销；

（2） 修改协议处理、RAID 算法和磁盘 IO 调度的接口，将部分异步队列调用转换成同步函数调用，减少异步队列导致的线程切换延时；

（3） 使用硬件多终端的配置，让不同的 IO分散到对应的 CPU 和起对应的内存，减少 CPU 核心之间的耦合，提高 CPU 使用效率。

最终，提高了系统多线程效率和多核 CPU 的使用率，减少了多核 CPU 之间的耦合，使得系统的存储 IO 处理效率提升 50% 以上。

**3.2 混合统一存储系统功能技术**

存储系统实现了 FC SAN、IP SAN 、NAS 三种架构的支持, 提供了多种协议访问方式（FCP、iSCSI、CIFS 、NFS 、FTP）。SAN+NAS 一体化的阵列是当前系统产品化的关键，在面对两地多中心的用户场景中，该架构设计能够解决高可靠、高可用、防丢失的问题。相应的系统功能（快照功能、全闪＋机械硬盘混合使用、远程镜像）能进一步丰富数据使用场景以及保障用户的数据安全。

**3.3　 三大性能优势**

通过数据的全生命周期管理，实现了三大性能优势：

（1） 全闪＋机械盘混合存储系统，以全闪技术为渲染、建模等业务提供百万几倍的 I/O，能够通过数据过程周期管理技术把生产后的数据迁移到机械磁盘上；

（2） 性能优化的文件系统，为大尺寸对象提供优化，高效并发分享非结构化数据；

（3） 拥有随机写 / 写吞吐能力，每套存储系统都可以提供全闪高性能 I/O 能力以及具备海量机械盘存储能力。

高性能的数据分层一是通过全闪＋机械盘方式降低了使用成本；二是解决了生产存储和归档存储的数据迁移难题，为用户最大程度的节约整体存储系统所拥有的成本。

**3.4　 加密存储功能的融合**

如图 3 所示，本款产品在存储系统的控制管理做到了：

一是通过磁盘等存储介质中只保存加密数据，避免关键数据泄露；

二是加密过程在存储端完成，对与使用端透明， 可以直接保护已有的大量应用软件的数据安全；

三是独立的密钥管理系统保证了密钥的安全性，拥有成熟的、国家认证的、经过验证的密钥管理系统。

成　果

当前自主可控存储的研发已取得突破性的成果：

一是核心要素测试可用。

（1） 功能测试用例执行覆盖率 100%，测试通过率 95%（部分非强制功能没有实现）；

（2） 安全测试用例执行率 100%，通过率100%；UI 测试用例执行率 100%，通过率 100%；

（3） 模拟测试用例执行率 100%，通过率100%；稳定性测试，6 套设备稳定运行 7\*24 小时未出现死机或无响应的问题，测试通过；

（4） 高可用测试用例执行率 100%，通过率 100%；性能测试初步结果，可达到 45 万 IOPS。

二是形成自主知识产权的源码。目前推出了基于飞腾芯片 FT1500A 的自主可控统一存储产品，所有源代码完全基于自主开发。

５

  

结　语

随着近年来网信产业的迅猛发展，数据已然成为用户的核心资产，从个人隐私意识的逐步提高到数据安全意识的提升再到国家对于信息安全、数据安全的重视，信息产业核心基础设施的国产化替代浪潮已经扑面而来。网络安全是新基建的前提，自主可控则是实现网络安全的重要“基石”\[2\]。根据目前国内对自主可控要求的大环境，而且存储相对门槛高，导致相对商业化的自主可控存储系统问世者甚少，基于飞腾 CPU 的自主可控存储在国产化的同时， 在性能、可靠性及功能上完全不逊色于国际巨头的产品，为信息安全、数据安全的维护提供可靠的保障。
