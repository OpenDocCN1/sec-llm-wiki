# 官宣预告|2020（第一届） LINKUP+网络安全峰会重磅来袭！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247545404&idx=3&sn=4eead4e390f0d09332be180240b16530&chksm=c0b4e84af7c3615c695f62a3b1c79d2abe2042764e4761af646f8eb1454309d51beb3bf8738b&scene=126&sessionid=1681312206#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247545404&idx=3&sn=4eead4e390f0d09332be180240b16530&chksm=c0b4e84af7c3615c695f62a3b1c79d2abe2042764e4761af646f8eb1454309d51beb3bf8738b&scene=126&sessionid=1681312206#rd)

在雨花台区人民政府和中国（南京）软件谷的指导下，第一届LINKUP+网络安全峰会将于2020年9月6日在南京举行。届时，众多安全专家、网络安全厂商和安全从业者聚集一起，围绕“零信任的新安全发展”的主题，共同学习分享网络安全新技术、新标杆、新动向及国内外前沿新趋势。

![](../Images/ae6e51083e01bd73090eff4ac1559e48.png)**LINKUP+网络安全峰会**随着技术的发展， 企业遭受的网络威胁愈发频繁且显著， 零信任网络应运而生， 越来越多的企业意识到需要在企业内部和外部生态环境中营造信任，其目的是基于身份和访问控制从零构建企业新的逻辑边界。零信任理念最早由研究机构FORRESTER在2010 年提出并逐渐得到业内认可， 其整个中心思想是“ 绝不信任， 持续校验” ， 企业不应自动信任内部或外部的任何人/ 事/ 物， 且必须在授权前对任何试图接入企业系统的人/ 事/ 物进行验证。Gartner2019发布的Hype Cycle for Cloud Security指出：零信任网络访问距离进入成熟的平台期依旧有5年左右的时间。九层之台，起于垒土。当量变的积累遇上新的时代需求，所有的成就也就变得有迹可循。**下一代互联网访问，零信任已成必然趋势！**本届LINKUP+网络安全峰会将围绕网络安全热点——零信任，聚焦教育、互联网、绿色经济、高端制造、企业服务等几大行业，在网络安全政策、技术发展及创新方向等维度进行分享，共同探讨未来发展模式、产业生态和国内外竞争态势，并汇聚产业资源并推动各界在安全行业的合作与交流，促进网络安全产品和解决方案在更多领域的应用落地。![](../Images/78de80cde055489258883e5f30075f71.png)![](../Images/02e0910462a3d834ee534529527b58f4.png)![](../Images/9f408ade8297d2d518764c5efc92b8e1.png)
