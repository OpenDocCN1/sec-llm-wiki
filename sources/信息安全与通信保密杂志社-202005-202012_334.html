摘　要

当今社会使用的能源趋向于多元化，配置优化的成本昂贵，对于减小成本的呼声越来越迫切，低功耗广域网（LPWAN）的出现彻底改变了电力能源的发展。窄带物联网技术作为高安全性，高质量的低功耗低沉本物联网技术，在能源领域得到了广泛的应用。对窄带物联网的最新研究进展进行了回顾，重点关注窄带物联网技术在低功耗，低成本，宽覆盖和大连接方面的技术优势，以及在能源领域的应用。具体地说，窄带物联网的优势及其在能源领域的应用是研究的重点。

关键词：LPWAN；NB-IoT；低功耗；低成本

引　言

随着社会的进步，人与人之间的联系已接近饱和，无法进一步刺激经济增长。旨在实现万物互联的物联网应运而生，并已成为下一代蜂窝网络革命的关键驱动力。LPWAN是蜂窝物联网发展的主要动力。自2016年以来，LPWAN中的连接数量迅速增加，到2019年已达到14亿个连接，并超过了传统的蜂窝连接。预计到2021年使用LPWAN技术的IoT连接数量将占链接总数的11％。

1


研究现状

1.1　窄带物联网

LPWAN网络的核心特征是电池寿命长，设备成本低，部署成本低，覆盖范围广，支持大量设备以及高质量的服务。当前的LPWAN技术主要分为非3GPP技术和3GPP技术。非3GPP技术包括LoRa，SixFog，Zigbee等，其中以LoRa技术为代表，而3GPP技术包括NB-IoT，LTE-M，EC-GSM等，其中NB-IoT技术为代表。LPWAN技术的分类如下图1所示。

1.2　能源

能源是社会进步的重要动力。由于当今化石燃料的枯竭，风能、水力发电和太阳能等各种可再生能源在能源领域中发挥着越来越重要的作用。但是，随着发电的多样化，配置的优化昂贵，节能和需求响应之间的矛盾越来越突出，这是现有电网较为棘手的问题。随着无线通信技术的发展，设备之间的数据交换变得越来越容易，能源物联网的出现为电网中存在的“最后一英里”问题提供了完美的解决方案。在解决各种可再生能源接入问题的同时，提高了电力服务的质量，并迎合了未来智能电网的发展趋势。

1.3　研究问题

1.3.1最后一英里

智能电网结合了自动化和通信技术。智能电网中的每个设备都可以看作是一个连接的对象。每个设备都会自动将有关网格基础结构的信息报告给网格信息管理平台。现有的通信技术只能将收集到的数据报告给管理系统，而不能处理管理系统发布的指令。现有电网中的某些设备位于地下深处或相对偏远的山区，基站覆盖的信号较差。同时，现有的2G / 3G / 4G基站不支持大量设备，如何将设备连接到网络以解决“最后一英里”问题迫在眉睫。

1.3.2高成本

智能电网对接入网的要求是不同的。某些具有大数据量和高实时性要求的设备具有更严格的带宽要求，例如实时环境监控。但是，某些设备需要发送的数据量很小（仅几百个字节）并且实时性要求较低，每半小时发送一次数据或每天发送一次数据。如果使用WiFi或4G网络上传数据将导致带宽浪费，并且芯片终端和网络部署的成本相对较高。

2


窄宽物联网的优势

2.1　电池寿命长

NB-IoT终端使用AA电池，初步估计电池寿命可以超过十年（具体使用时间与具体应用和流量模型有关），为了减少NB-IoT终端的功耗并扩展电池寿命，NB-IoT的关键芯片采用了一系列低功耗关键技术：

关键技术1：降低芯片复杂度，降低工作电流。

关键技术2：简化空中接口信令，降低单个数据传输的功耗。

关键技术3：提供覆盖级别的控制和访问，减少单个数据传输的时间。

关键技术4：省电模式（PSM）节能模式，终端功耗仅为15uW。

关键技术5：扩展不连续接收（eDRX），延长周期不连续接收时间，降低了终端监听网络的频率。

关键技术6：使用长周期TAR / RAU减少终端发送位置更新的次数。

关键技术7：仅支持小区选择和重选的移动性管理，减少了测量开销。

NB-IoT终端有99％的时间处于PSM状态，仅消耗小于终端运行时1％的功耗。NB-IOT终端设备处理完数据后，RRC连接被释放并进入空闲状态。同时，激活了活动计时器（T3324），计时器时间在0～255秒之间。计时器到期后，进入PSM模式，并启动TAU循环请求计时器T3412。在3GPP协议中，TAU周期请求计时器默认为54分钟，最大值可以达到31小时。

在PSM模式下，NB-IOT终端会关闭信号的收发和AS（接入层）相关功能，相当于部分关机，进而可以减少射频、天线、信令处理等功耗消耗。在PSM期间，NB-IOT终端不接受任何网络寻呼，并且数据，SMS和电话无法接入。对于下行网络侧，此时的NB-IOT终端无法访问。尽管在PSM模式下，NB-IOT终端不再监听寻呼，但在网络中依旧保持注册，因此，当需要传输数据时，无需重新建立连接或建立PDN连接。

当TAU周期请求计时器（T3412）超时或UE有上行数据要处理时，NB-IOT终端将退出PSM模式。图6是PSM模式的原理。

图6PSM模式原理

eDRX是不连续的接收。eDRX是DRX技术的增强，它支持更长周期的寻呼，以实现节能目的。DRX的寻呼周期为1.28 / 2.56 s，eDRX的寻呼周期可以在ATTACH和TAU中自定义。可以设置为20 s，40 s，80 s等，最大值可以设置为40 min。eDRX延长了DRX时间，并降低了DRX频率和NB-IoT终端接收数据的频率。eDRX可以在空闲模式和连接模式下工作。在连接模式下，eDRX将接收间隔延长到10.24 s。在空闲模式下，eDRX将寻呼监视和TAU更新间隔延长到40分钟以上。图7是DRX的示意图，图8是eDRX的示意图

2.2　广覆盖

广覆盖是NB-IoT技术的最大功能之一，可用于满足农村，工厂，地下车库和井盖的需求。某些NB-IoT终端的位置不佳。与智能手机相比，高度差导致信号损失4 dB。如果计算额外的10 dB损耗（如井盖），则与GSM网络相比，您需要将增益提高20 dB。为了使NB-IOT终端的网络覆盖范围增加20 dB，采用了三种关键技术：

关键技术1：上行功率谱密度提高17 dB。

NB-IoT技术使用的载波带宽为3.75 / 15 Khz，而现有的2G / 3G / 4G上行链路使用200 Khz的载波带宽，保护带宽实际上为180 Khz。功率谱密度（PSD）增益约为11 dB。因此，有可能覆盖更远的距离。

PSD增益=10lg（发射功率A/带宽A）/（发射功率B/带宽B）（1）

发射功率A是NB-IoT终端的发射功率，带宽A是NB-IoT技术的带宽，发射功率B是2G / 3G / 4G终端的发射功率，带宽B是 2G / 3G / 4G终端的带宽。此时，发射功率A为200 mv，带宽A为15 khz，发射功率B为200 mv，带宽B为180 khz，PSD增益为10.7 dB。

PSD = 10lg（200 v / 15 khz）/（200 mv / 180 khz）= 10.7 dB（2）

关键技术2：重复传输增强6〜16 dB。

与传统技术相比，NB-IoT技术支持重复传输数据。重复传输数据可以带来重复的收益，但是却以数据传输速率为代价。重复传输次数每增加一倍，数据传输速率将降低一半，但增益为3 dB。3GPP标准定义了NB-IoT上行链路的重复传输次数最多可以达到128次。但是，考虑到传输速率和基站容量，NB-IOT终端的上行链路重复次数通常限制为16倍，对应于12 dB的增益，但实际上比NB-IoT终端低3 dB。理论上是9 dB，图9显示了NB-IoT重复编码示意图。 

图9NB-IoT重复编码示意

关键技术3：NB-IoT技术采用低频部署。

NB-IoT技术理论上可以部署在任何频段，但出于覆盖范围的考虑，通常选择低于1 Ghz的低频段进行部署。因为低频带比高频带具有更低的路径损耗和更强的衍射能力。

2.3　低成本

低成本是物联网设备的另一个重要特征。NB-IoT网络的低成本体现在两个方面。首先，NB-IoT的部署成本相对较低，无需重建新基站。可以使用已有的2G / 3G / 4G基站进行升级部署。其次，通过简化NB-IoT终端的结构来降低成本。NB-IoT终端的当前成本为5美元，并且预计到2020年成本将降至1美元。为了降低NB-IoT终端的成本，使用了五项关键技术。图10是NB-IoT的芯片结构，图11是NB-IoT的协议堆栈结构。

关键技术1：180 kHz窄带系统，基带复杂度低。

关键技术2：采样率低，缓存Flash/RAM要求小（28  kByte）。

关键技术3：单天线，半双工，射频成本低。

关键技术4：低峰均比，功放效率高，23 dBm发射功率可支持单芯片SoC内置功率放大器PA，进一步降低成本。

关键技术5：简化协议栈（500 kByte），减少片上FLASH / RAM。

3


NB-loT在能源中的应用

电力能源工业主要由四个部分组成：发电，输电，配电和用户。NB-IoT的低功耗、低成本、覆盖面广和连接性强的特点完全适合能源行业的需求，为电力和能源行业的“最后一英里”问题提供了完美的解决方案，因此得到了广泛的应用。在电力行业的发电，输电，配电和用户中，它用于监视系统运行，故障安全管理和远程控制。NB-IoT应用的总体框架如图14所示。

图14NB-IoT应用的整体框架结构

NB-IoT整体框架主要有三层架构组成，包括数据采集层，网络传输层和平台应用层。

数据采集层位于NB-IoT整体框架的底层，由采集电流、电压等各式各样的传感器与NB-IoT无线模块组成，传感器负责采集设备实时运行的数据，NB-IoT模块将采集到的实时数据通过NB-IoT网络实时上传。

网络传输层由NB-IoT基站和NB-IoT核心网组成，NB-IoT基站与数据采集层的NB-IoT终端建立连接，接收实时上传的数据并下发数据，同时将接收到的NB-IoT上传的实时数据转发至NB-IoT核心网，NB-IoT核心网将数据转发至NB-IoT应用平台。

平台应用层负责实时接收上传的数据，并对此进行存储和数据处理等，可以实时监控设备的运行状态，并根据需求下发控制命令。

3.1　发电

发电厂是能源，将各种可再生和不可再生能源转化为电能。如今，发电厂的组成已经多样化，具有风力，光伏发电，火电，核电和其他功能。

每个主要发电厂都由一个复杂的结构组成。火力发电厂最关键的四大关键部分包括：锅炉、汽轮机、凝汽器和发电机。水力发电厂的关键部件包括：水轮机和发电机等。核能发电厂的关键部件包括：汽轮机和发电机等。风力发电厂的关键部件包括：大型桨叶、发电机等。不管是火力发电厂、水力发电厂，还是核能发电厂、风力发电厂，都存在着大量应用传感器的场景，用于采集电压、电流和运行状态等不同的参数。

因此，NB-IoT技术在大型发电厂中具有广泛的应用前景，可用于发电监控，紧急广播通信和泄漏监控等不同的场景。马华玲将窄带物联网技术应用于光伏发电的远程监控；冯思维将NB-IoT技术集成到核电站的应急广播系统中；谢志远设计了基于NB的高精度光伏电站泄漏监测系统-IoT技术；李帅设计了结合NB-IoT技术的风力发电机闪电数据采集和监控系统；王建祥将NB-IoT技术集成到工业风力发电机远程监控系统中；陈童开发了基于NB-IoT技术的太阳能发电监控系统。

3.2　输电

电力传输系统（Power Transmission System）是指将电力从发电厂传输到配电系统的系统。它主要由高压电缆，铁塔（或水泥杆，木杆）和多套变压器组成。通过在输电过程中增加电压来减少输电过程中的功率损耗。

NB-IoT技术可用于电力传输系统中不同的场景，例如电力变压器，高压电缆等。NB-IoT技术的使用可以降低电力传输系统的人工维护成本和运行效率。Su Pan设计的电力变压器远程监控系统集成了NB-IoT技术，电力变压器远程监控系统由数据采集模块，数据传输终端，透明传输云平台和数据监控平台组成，即传感层，传输层和应用层。整个系统中的数据采集模块负责收集相关的工作参数以及变压器电压，电流和温度的模数转换。数据由NB-IoT终端封装并发送到监视平台，以进行数据管理，分层历史记录和报告。

3.3　配电

配电是电力系统中的链接，直接连接到用户并向用户分配能量。配电系统由配电变电站，高压配电线路，配电变压器，低压配电线路以及相应的控制和保护设备组成。

智能配电网的接入网和隔离器为NB-IoT技术提供了广泛的应用场景。刘郑建议使用窄带IoT技术为智能配电网络构建无线访问专用网络；田全利将NB-IoT技术应用于工业控制和配电中的信号隔离器；褚红云将窄带物联网技术应用于视频监控运维智能电源单元；NB-IoT模块负责通过NB-IoT基站和NB-IoT核心网将收集到的相关电流和电压转发到平台应用层。平台应用层实现配电网设备质量监控，智能故障分析与处理以及终端在线管理。

3.４　用户

NB-IoT技术被广泛应用于日常生活中。从当前流行的智能家居市场到路边的智能路灯和智能充电桩，都已通过NB-IoT技术连接到物联网。

电动自行车自动充电系统，智能路灯监控系统和智能电能计量系统由四个部分组成。配备NB-IoT模块的智能终端用于收集所需的电源信息，计费信息等，并接收应用程序层发出的控制命令。NB-IoT基站和NB-IoT核心网负责上载智能终端收集的信息并发布平台层控制命令。平台层负责存储，计划和分析上载的数据，并将其推送到应用程序层。应用层负责根据实时设备状况监视和发布控制命令。

尹旭平设计了基于NB-IoT技术的道路照明智能控制系统；祝恩国设计了基于NB-IoT技术的智能电能计量装置；孟宪宇设计了基于NB-IoT技术的充电桩数据监控系统；鲍建科将NB-IoT技术应用于冰箱，电饭锅和洗衣机等设备；盛庆华设计了一种结合NB-IoT技术的电动自行车充电系统；李庆设计了基于NB-IoT的电动汽车智能充电系统。

结　语
