# 数据安全厂商昂楷科技获奇安投资独家投资

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247545373&idx=3&sn=f142b8607f07412057a7dd09eac26098&chksm=c0b4e86bf7c3617d54f280870dc3c5c36384ae8d6c89aa49d3baa22fffcdf75814df01eb7719&scene=126&sessionid=1681312211#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247545373&idx=3&sn=f142b8607f07412057a7dd09eac26098&chksm=c0b4e86bf7c3617d54f280870dc3c5c36384ae8d6c89aa49d3baa22fffcdf75814df01eb7719&scene=126&sessionid=1681312211#rd)

  
专注于数据安全的深圳昂楷科技有限公司（以下简称：昂楷科技）正式宣布获得奇安投资的独家投资。在全球疫情加剧、国内经济放缓、融资环境恶化的大背景下，昂楷获得奇安投资的投资，表明昂楷公司的数据库安全产品及解决方案进一步得到行业的认可，这也是昂楷科技首次引进具有产业背景的机构投资者。昂楷CEO刘永波先生表示，安全的最终目的就是为了保护敏感数据，让人们放心地享受大数据！数据安全治理是一个充满挑战、快速增长的海量市场！此次融资完成后，昂楷将加速公司发展、加速发展数据安全治理解决方案的研发和服务升级，扩大销售渠道建设，为客户及合作伙伴提供更加完善的数据安全治理解决方案。奇安投资执行董事杨超认为，数据安全是网络安全行业中快速增长的赛道，并且核心数据保护在信息化建设中重要性愈加凸显，各IT基础设施和信息化建设单位需要提高在核心数据保护上面的投入。行业同比中昂楷科技产品技术过硬、方案成熟，另外我们更看重昂楷管理团队的能力，他们普遍具备优秀的工作背景，在对客户的服务方面继承了优秀的客户服务和支持体系，值得客户选择的公司也是值得投资人选择的公司。  

随着新兴技术快速普及，云计算应用引入虚拟化安全和云安全，海量数据应用于大数据分析后数据隐私安全备受重视。三者之中，大数据安全与信息安全在重要会议上多次被并列提及，重要性日益凸显。6月28日，数据安全法草案初次提请十三届全国人大常委会第二十次会议审议。这表明国家确立数据安全保护管理各项基本制度的决心，同时也显示数据安全已经上升到国家战略层面。

![](../Images/31cc5cae0af4b52cfca7e8b15e1ece4a.png)

昂楷科技是国内领军的独立数据库安全产品及方案提供商，拥有多项资质，数据库安全产品服务于医疗、公安、工控、政府、教育、云端数据库等多个领域，覆盖核心头部客户，核心业务围绕大数据、云端数据库展开，在医疗及云数据库安全领域位居行业第一。昂楷科技注重建立核心技术团队，核心骨干来自华为、华赛等国内外知名厂商，具有信息安全及电信行业高端产品研发经验，熟练驾驭先进的IPD、LTC公司管理流程。昂楷科技为用户提供以数据库审计为主打产品的数据安全治理产品及解决方案，涵盖数据库防火墙、数据脱敏、数据库漏扫、数据库状态监控、数据库资产梳理系统、敏感信息梳理系统、集中管理平台、数据安全中台等数据安全产品。2020年上半年，疫情并未对昂楷科技造成太大影响，主营业务同比仍保持较大增幅，核心产品拥有较高毛利率。本轮投资人奇安投资是国内信息安全龙头企业奇安信（688561 ）、国兴投资、北京熙诚金睿以及管理团队发起成立的专业化投资机构，一期基金专注于网络信息安全领域创业项目投资，已投项目包括永信至诚、观安信息、威努特、蓝信移动、盛华安、天际友盟等网安行业优秀创业公司。
