# 盘点 | 2021第一季度国内外重大网络攻击事件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247545596&idx=1&sn=5be4a496ae06591718e1d3314208c9b4&chksm=c0b4e88af7c3619c572b4ba26b269d01409c153b6da685c0fdd5f3bf099dd2d756ae2367f6c5&scene=126&sessionid=1681312173#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247545596&idx=1&sn=5be4a496ae06591718e1d3314208c9b4&chksm=c0b4e88af7c3619c572b4ba26b269d01409c153b6da685c0fdd5f3bf099dd2d756ae2367f6c5&scene=126&sessionid=1681312173#rd)

近年来，网络攻击事件频发，根据SonicWall最新发布的《2020年威胁报告》，2020年勒索软件、物联网威胁、新的恶意软件和加密劫持激增了两位数，SonicWall形容其为网络安全军备竞赛的“引爆点”。据调查，疫情期间，零售、医疗保健和政府部门受到的打击尤其严重。

  

根据卡巴斯基调查显示，虽然2020年下半年全球针对工控系统攻击略有下降（因为受疫情影响很多地区的工业组织支付能力下降），但整体格局未变，东南亚、非洲、中亚、东亚和东南亚依然是重灾区。

  

根据《中国互联网络发展状况统计报告》，2020年，国家信息安全漏洞共享平台收集整理信息系统安全漏洞同比增长28.0%。其中高危漏洞同比增长52.2%。由此可以看出，2020年我国互联网安全状况依旧严峻。

  

2021年开局，国际国内已曝光多起网络攻击事件，Solarwinds大型网络攻击事件的影响还在继续扩大和蔓延，Emsisoft的安全专家Callow指出，2021年会有更多的数据泄漏和网络攻击勒索案件。下面，我们盘点了2021年第一季度国内外发生的重大网络攻击事件：

  
  

**国　内**

  
**多个行业感染incaseformat病毒**

**01**

  
1月13日，国内多家安全厂商检测到蠕虫病毒incaseformat在国内大范围爆发，涉及政府、医疗、教育、运营商等多个行业，且感染主机多为财务管理相关应用系统。感染主机表现为所有非系统分区文件均被删除，对用户造成不可挽回的损失。  
**针对农信社和城商行的短信钓鱼攻击**  

**02**

  
自春节起，全国多地市连续发生通过群发短信方式，以手机银行失效或过期等为由，诱骗客户点击钓鱼网站链接而盗取资金的安全事件。天际友盟检测发现大批钓鱼网站在2月9日后被注册并陆续投入使用，钓鱼网站域名为农信社、城商行等金融机构客服电话+字母，或与金融机构网站相似域名的形式，这些域名多为境外域名注册商注册并托管。  
**春节期间DDoS攻击事件激增**  

**03**

  
2月22日，奇安信羲和实验室发布春节期间DDoS攻击报告，报告显示，春节期间奇安信星迹DDoS观测系统累计观测到反射放大DDoS 攻击事件 65912 个，涉及被攻击 IP 57096 个。与春节前一周相比，DDoS 攻击事件数增加约 25%，被攻击 IP 数增加 37%。  

**国　外**

  
**欧盟委员会遭网络攻击**  

**01**

  
时间：2021年3月攻击方式：未公布攻击团伙：未知影响范围：欧盟委员会等多个欧盟机构，欧盟的IT架构也遭受了一定程度上的冲击  
**排放测试公司Applus Technologies遭遇攻击**  

**02**

  
时间：2021年3月攻击方式：恶意软件（很可能是勒索软件）攻击团伙：未知影响：导致包括康涅狄格州、乔治亚州、爱达荷州、伊利诺伊州、马萨诸塞州、犹他州和威斯康星州等八个州的车辆的年检系统瘫痪。  
**能源巨头壳牌公司遭受黑客攻击**  

**03**

  
时间：2021年3月攻击方式：恶意软件，利用了安全厂商Accellion的文件传输程序FTA的零日漏洞。攻击团伙：UNC2582等多个组织影响：已经访问了一些个人数据以及属于壳牌利益相关方和子公司的数据。  
**宏碁电脑遭勒索攻击：赎金5000万美元创下最高纪录**  

**04**

  
时间：2021年3月攻击方式：REvil勒索软件，可能利用了宏碁域内的微软Exchange服务器攻击团伙：REvil影响：包括关于财务电子表格、银行结余以及银行来往信息的文档泄露。勒索团伙开出的赎金高达5000万美元。  
**VMware虚拟机平台遭到攻击**  

**05**

  
时间：2021年2月攻击方式：新型勒索攻击，通过“RansomExx” 勒索病毒（也称“Defray777”），利用 VMWare ESXi 产品中的漏洞（CVE-2019-5544、CVE-2020-3992），对虚拟硬盘的文件进行加密。攻击团伙：Carbon Spider与Sprite Spider影响：造成大量虚拟机关闭，虚拟机处于无法连接状态，用户生产环境停线等严重问题。  
**美国智能安防厂商Verkada被黑**  

**06**

  
时间：2021年3月攻击方式：从互联网上找到了被暴露的一个用户名和密码，通过该“超级管理员”账户获得对Verkada公司的访问权限。攻击团伙：Advanced Persistent Threat 69420影响：攻陷了硅谷创业公司 Verkada 收集的大量安全摄像头数据，获得了医院、企业、警察局、监狱和学校安装的15万个监控摄像头的访问权限。  
**著名网络安全公司Qualys遭遇勒索软件攻击**  

**07**

  
时间：2021年3月攻击方式：勒索软件攻击团伙：Clop影响：Qualys的采购订单、客户设备扫描结果和报价等文件被盗。作为提供漏洞检测和渗透测试等专业服务的网络安全公司，Qualys颜面尽失。  
**超过35家主要公司内部系统遭到破坏**  

**08**

  
时间：2021年2月攻击方式：新型供应链攻击攻击团伙：未知影响：包括Microsoft，Apple，PayPal，Shopify，Netflix，Yelp，Tesla和Uber的内部系统遭到破坏，并实现了远程代码执行。  
**红杉资本遭钓鱼邮件攻击**  

**09**

  
时间：2021年2月攻击方式：BEC（商业电子邮件欺诈）攻击，攻击者仿冒红杉员工向投资者发送电子邮件。攻击团伙：未知影响：可能已经访问了投资者的一些个人和财务信息。  
**质量安全认证巨头UL遭勒索攻击**  

**10**

  
时间：2021年2月攻击方式：勒索软件攻击团伙：未知影响：攻击对其服务器进行了加密，并导致服务器在恢复时关闭了系统。UL决定不支付赎金，而是从备份中恢复。  
**黑客试图在美国城市供水系统中“放毒”**  

**11**

  
时间：2021年2月攻击方式：攻击远程桌面软件（授权用户以远程方式处理系统问题），进入市政水处理系统攻击团伙：未知影响：接管了系统鼠标，并通过一系列操作调整市政水处理软件中的各项控制参数。入侵者在系统内只用了3到5分钟，就将氢氧化钠含量从百万分之100更改为百万分之11100。由于发现及时，操作员立即介入干预、撤销了上述危险操作。奥尔德斯玛市没有受到任何实际威胁。  
**零售巨头牛奶集团Dairy Farm Group遭勒索攻击**  

**12**

  
时间：2021年1月攻击方式：REvil勒索软件攻击团伙：REvil影响：入侵牛奶集团内部网络，掌握了包括对牛奶集团公司电子邮件的完全控制权，他们声明将这些电子邮件用于网络钓鱼攻击，并向该公司索要高达3000万美元赎金。  
**加利福尼亚大学等机构遭勒索软件攻击**  

**13**

  
时间：2021年初攻击方式：勒索软件。通过利用Accellion的文件传输服务中的漏洞来复制和传输校内文件。攻击团伙：未知影响：导致加利福尼亚大学与其他几个政府机构、私人公司和其他几所学校的个人隐私泄露。  
**美国医疗服务商遭勒索攻击**  

**14**

  
时间：2020年12月攻击方式：勒索软件。攻击团伙：未知影响：美国佛蒙特州一家医疗服务提供商遭到网络攻击，导致电子健康记录(EHR)系统延迟推出，并造成数百万美元的收入损失。  
**沃达丰（Vodafone）旗下意大利移动运营商Ho Mobile被黑**  

**15**

  
时间：2020年12月攻击团伙：未知攻击方式：入侵Ho Mobile的服务器影响：窃取了HoMobile客户的详细信息，包括全名、电话号码、社会安全号码、电子邮件地址、出生日期和地点、国籍和家庭住址等。250万用户需更换手机SIM卡  
**SolarWinds供应链攻击事件**  

**16**

  
时间：2020年12月攻击团伙：UNC2452攻击方式：通过更新包中的后门进行攻击

影响：黑客对文件SolarWinds.Orion.Core.BusinessLayer.dll的源码进行篡改添加了后门代码，北美、欧洲、亚洲和中东的一些政府、咨询、技术公司都受到了攻击，超250家机构受影响。SolarWinds 黑客攻击事件是史上影响最广、最复杂的。
