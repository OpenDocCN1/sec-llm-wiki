# 荣膺金智奖！Testin云测助力企业应对数字化转型下的安全挑战

近日，由信息安全与通信保密杂志社、中国网络空间安全网主办，北京商用密码行业协会、中关村智能终端操作系统产业联盟协办的2020年度“中国网络安全与信息产业金智奖”正式揭晓。以人工智能驱动的企业服务平台Testin云测荣获——2021年度最具创新企业奖。同期入选金智奖的还有360、绿盟科技、卫士通等安全领域前沿厂商。  
“金智奖年度评选”由信息安全与通信保密杂志社发起，已成功举办五届，被视为国内网络安全产业发展的风向标，推动了网安产业的发展。此次评选，有120余位专家评委、50余位媒体评委以及1000余位专业评委参与，经过网络投票、媒体和专家终评等系列环节，最终评选出业内顶尖安全企业的名单。

值得一提的是，此前，“Testin云测”就凭技术领域的创新成果入选“人民网2020科技创新前沿企业”。“创新”可谓是Testin云测的注脚之一。企业服务领域起家的Testin云测，从未停止过以技术赋能服务，帮助客户创造更大价值的步伐。  

  
Testin云测从最开始颠覆传统人力外包测试的云测试服务起家，到后续的安全服务、AI数据服务、RPA服务，目前，服务超过百万的企业及开发者，覆盖超过300万款应用。Testin云测始终致力于通过工具、技术、人才、服务四位一体的共享，加速企业智能化、数字化、科技化的进程。  
此次再度蝉联金智奖，则从侧面印证了Testin云测在网安领域的不俗实力与表现。企业服务端深耕9年的Testin云测，拥有超过300W+移动应用、软件、系统等质量保障经验。先后获得ISO9000、ISO27001、ISO20000、ISO17025和CMMI3等资质认证，安全团队拥有众多来自微软、华为、甲骨文等厂商的资深安全技术人员和安全咨询专家，具备网安行业一流的技术与服务实力。  
Testin云测的安全业务建设着眼于覆盖应用/软件/系统的全生命周期，其核心是以安全测试类服务和产品优先保障应用的实施、测试和发布过程，从而大量减少应用漏洞，降低生产环境的运维压力。  
其次，通过安全合规类服务，诸如等保测评服务以及个人信息收集使用合规测评等服务来保障应用满足国家和行业的合规要求，避免给企业带来声誉和经济方面的损害。  
此外，结合信息安全风险评估服务、安全开发和管理体系建设等咨询类服务，Testin云测还可以帮助客户在需求和设计阶段融入安全基因，从而更有效地保障项目成功，降低后期漏洞的修复成本。深入贯彻国际和国内对于DevSecOps、BSI（Build Security In）等理念的实践，同时也融入了软件敏捷开发和质量管理的“早测试、多测试、快速反馈”等诸多概念，满足企业的多场景需求。  
未来，在十四五数字化转型宏观政策下，企业的业务形式变化在安全方面可能衍生潜在的新风险，同时，随着密码法、数据安全法（草案）和正在讨论审议的个人信息保护法等更细化的安全法规的陆续出台，国家对安全的监管也在不断深化，企业安全层面的需求会不断增加。这将给国内如Testin云测、360、绿盟科技等具备可靠安全服务能力与技术创新能力的企业提供更多的挑战和机遇。
