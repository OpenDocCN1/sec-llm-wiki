# 江南天安：实现密码的可管、可控、自主安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247545561&idx=2&sn=0fcfee82cd2ed6dd6a30f116c6eaa04d&chksm=c0b4e8aff7c361b9682ac9f266b21e78c7fc899e01457c6dc7150ad9a5e24d588e7b87f896fe&scene=126&sessionid=1681312178#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247545561&idx=2&sn=0fcfee82cd2ed6dd6a30f116c6eaa04d&chksm=c0b4e8aff7c361b9682ac9f266b21e78c7fc899e01457c6dc7150ad9a5e24d588e7b87f896fe&scene=126&sessionid=1681312178#rd)

2月23日，2020 年度（第五届）“中国网络安全与信息产业金智奖”评选结果公布，北京江南天安科技有限公司（以下简称“江南天安”）旗下基于国产密码的应急广播信息保护解决方案荣获“优秀解决方案奖”。这是继去年“隐私数据加密系统”获得2019中国网络安全与信息产业“金智奖”年度产品奖后，再次获得该行业大奖。

  
“金智奖”由信息安全与通信保密杂志社、中国网络空间安全网主办，北京商用密码行业协会、中关村智能终端操作系统产业联盟协办。本届评选获得了参选企业的大力支持和业界同仁的广泛关注，在120余位专家评委、50余位媒体评委以及1000余位专业评委的参与和见证下，经过网络投票、媒体和专家终评等系列环节，最终产生了所有的奖项。![](../Images/da170a28177eb3732a86d5b70cfa21b1.png)

江南天安的基于国产密码的应急广播信息保护解决方案通过了国家密码局组织的专家评审，实现了应急广播可管、可控、自主安全的效果，达到了国家广播电视总局针对应急广播系统部、省、市、县四级联动的要求，经过近两年的应用试点和市场推广，目前已经成功实现了覆盖国内27个省的近500个县，遍及5万多个行政村，终端数字证书发放超过20万个，在2020年抗疫宣传实践工作中做出了突出贡献。

该方案根据应急广播系统业务特点，研究了国家应急广播行业应用需求、重点研发适用于应急广播各级业务平台应用的密码设备，突破性地实现了基于国产密码的应急广播安全认证、授权技术，推动安全、自主、可控的全国应急广播体系的建立。

本项目建设了部级应急广播认证中心，省级应急广播安全代理系统，市县级应急广播安全管理系统，以及适用于各类应急广播终端的嵌入式密码模块，形成了覆盖整个广播传输网络的信息保护体系，创新设计了应急广播短证书应用，以及轻量化证书授权协议，具体有如下4点创新。

**创新点1**

突破国产密码技术与应急广播应用结合的安全与性能瓶颈，构建以国产密码技术为基础的应急广播安全防护架构体系本项目从建立国家、省、市、县、乡、村多级应急广播技术系统角度出发，结合应急 广播向融媒体、多种通道、城乡结合发展需求，研究应急广播多级别、全流程的信任和安全 模型，制定国家应急广播国产密码应用总体方案，构建国产密码算法在我国应急广播体系中的防护架构体系。

**创新点2**

建立基于国产密码技术的应急广播安全统一认证体系和应用标准体系 在前期科研和技术工作的基础上，配合国家广播电视总局广播科学研究院完成了国产密码在应急广播数据保护、平台接口、多通道封装传输等方面的多项技术标准的编制，满足了应急广播系统和装备互联、互通、互换的需求，具有国际先进性。

**创新点3**

提出适应于我国应急广播技术体系的轻量级安全认证技术 传统的数字证书通常采用 X.509 标准格式，证书的体积较大，不适用于应急广播网络传输，尤其是调频广播、中波广播之类窄带传输。本项目研究适用于应急广播传输方式的轻 量化数字证书模式，以及适用于集成到各类终端设备内部实现信息认证及安全保护的专用密 码模块，在保证安全的条件下简化证书及应用流程，保障应急广播安全。

**创新点 4**

提出适应于我国应急广播复杂应用场景的终端安全鉴别技术 用国产密码保护的终端提升安全认证效率的问题，尤其是如何快速接收、解析、响应通过各类广播传输网络下发的应急广播消息（包括中波、地面数字电视、调频以及基于 4G/5G 等无线 IP 双向网络等），实现覆盖各类广播终端（村村响大喇叭、中波台站、机顶盒、城市 公共提示屏等），提高国产密码算法的终端设备安全认证效率，大幅降低响应时间。

北京江南天安科技有限公司是国内领先的密码技术开发、应用与推广的信息安全综合服务商。公司凭借十余年的密码研发经验对国产商用密码技术领域有着深刻的理解，公司的密码产品主要基于国产商用密码算法，通过加密算法、数字签名、数字认证、密钥管理等相关密码技术来保护用户的数据安全、身份安全和应用安全等，主要面向政府、金融、电信、医疗、互联网、云平台等各类行业用户以及专业技术领域的用户，提供与其应用系统相结合的密码产品、服务和解决方案，能够帮助用户建立起一套用户自主可控的，与其业务相结合的，安全、有效的密码应用保障体系。

由信息安全与通信保密杂志社发起的“金智奖年度评选”至今已成功举办了五届，被中国网络安全产业视为发展的风向标，得到了业界的高度关注和认可，有效地提升了企业的影响力、竞争力和品牌价值，并推动了网安产业的发展。

  
  

信息安全与通信保密杂志社自成立以来，一直勇于开拓、积极创新，做网络强国建设的思想库，安全产业发展的情报站，创新企业腾飞的动力源，搭建跨学科、跨领域的学术交流平台，助力网络空间学术理论的创新，推动网信事业的发展，服务国家战略的需求。
