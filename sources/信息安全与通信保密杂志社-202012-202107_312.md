# 易安联：深耕零信任 赋能行业新发展

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247545560&idx=2&sn=0d3d528c01f1184b2b903494447fd906&chksm=c0b4e8aef7c361b85d30632e399baf113ba0f93292e1ea468d25cb996ad886b3a020ddc18068&scene=126&sessionid=1681312178#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247545560&idx=2&sn=0d3d528c01f1184b2b903494447fd906&chksm=c0b4e8aef7c361b85d30632e399baf113ba0f93292e1ea468d25cb996ad886b3a020ddc18068&scene=126&sessionid=1681312178#rd)

2月23日，2020 年度（第五届）“中国网络安全与信息产业金智奖”评选结果公布，江苏易安联网络技术有限公司（以下简称“易安联”）同时荣获“优秀产品奖”和“创新企业奖”两项行业大奖。

  
“金智奖”由信息安全与通信保密杂志社、中国网络空间安全网主办，北京商用密码行业协会、中关村智能终端操作系统产业联盟协办。本届评选获得了参选企业的大力支持和业界同仁的广泛关注，在120余位专家评委、50余位媒体评委以及1000余位专业评委的参与和见证下，经过网络投票、媒体和专家终评等系列环节，最终产生了所有的奖项。

易安联专注零信任领域多年，以应用访问安全为核心，目前已成功自主研发了EnCASB（零信任访问平台）、EnSDP（零信任防护平台）、EnIAM（零信任身份管理平台）、EnAPI（零信任API微服务网关）、EnBox（零信任安全沙盒）以及EnSight（安全态势感知平台），为运营商、政企、文化、教育、金融等行业客户提供基于零信任架构的网络安全产品和完整的零信任安全解决方案，致力于成为零信任安全领导者，创造安全的网络云世界。

其中易安联主推的EnSDP——零信任防护平台，基于“零信任”网络安全的基本思想，遵循SDP(Software Defined Perimeter)安全架构，通过控制和转发分离，实现软件定义安全访问边界，构建端到端的组织应用安全访问新模式。

EnSDP具备异常行为智能分析、动态信任权限评估、内部应用安全引流、网络隐身、MFA认证、统一策略管理等核心技术，实现细粒度访问权限控制、用户动态评级授权、业务应用安全发布、服务生命周期管理、用户行为全流程可视化追踪审计，通过AI探测网络用户异常行为和精准的安全态势感知，有效保护组织数字资产安全和满足合规需要。

易安联现已为江苏省广播电视总台、中国移动苏州研发中心、中国核工业建设股份有限公司、南京大学、南京航空航天大学等百余家客户提供高效、稳定、安全的云端防护和接入方案并获得一众好评。

过去的2020年，易安联举行了春夏秋冬四场产品发布会，推出不断升级的EnSDP和一系列零信任产品簇，并收获了业绩上的大丰收；同时由易安联承办的2020 LINKUP+网络安全峰会也完美落下帷幕，大会期间邀请到多名行业领导、领域专家、大量优质客户和技术人才等前来参加，共商“零信任的新安全发展”，凝聚共识，推广合作，也为推动南京市网络安全产业繁荣发展而献出一份力。

易安联表示，未来将继续奔跑在零信任赛道，紧跟网络安全新形势，对中国的网络空间安全更多的做一些引领性的思考，更多的站在用户的角度来考虑产品要更多的思考用户的痛点，持续为信息安全保驾护航，全力推动信息安全产业蓬勃发展。

由信息安全与通信保密杂志社发起的“金智奖年度评选”至今已成功举办了五届，被中国网络安全产业视为发展的风向标，得到了业界的高度关注和认可，有效地提升了企业的影响力、竞争力和品牌价值，并推动了网安产业的发展。

  
  

信息安全与通信保密杂志社自成立以来，一直勇于开拓、积极创新，做网络强国建设的思想库，安全产业发展的情报站，创新企业腾飞的动力源，搭建跨学科、跨领域的学术交流平台，助力网络空间学术理论的创新，推动网信事业的发展，服务国家战略的需求。
