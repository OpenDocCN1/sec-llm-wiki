# 卫士通：喜获年度双奖，安全实力与影响力再次彰显！

2月23日，卫士通凭借中央企业网络安全整体保障运营服务斩获了“**金智优秀解决方案**”奖，与此同时还蝉联了金智奖“**年度最具影响力企业**”奖。  

  

“金智奖”由信息安全与通信保密杂志社、中国网络空间安全网主办，北京商用密码行业协会、中关村智能终端操作系统产业联盟协办。本届评选获得了参选企业的大力支持和业界同仁的广泛关注，在120余位专家评委、50余位媒体评委以及1000余位专业评委的参与和见证下，经过网络投票、媒体和专家终评等系列环节，最终产生了所有的奖项。

**NO.1**

  

***新理念 新托举***

  
去年，受新冠肺炎疫情的影响，数字经济对经济发展的动力引擎作用更加凸显，央企数字化转型加速，网络安全服务需求大增。卫士通中央企业网络安全整体保障运营服务，正是以习近平总书记提出的“整体、动态、开放、相对、共同”的网络安全观为指引，以保障中央企业网络安全为宗旨，坚持“管理与技术并重，预防与保护并举”，覆盖“监测、防护、检测、响应”的全过程网络安全服务。它遵循国家法律法规、政策标准规范，围绕“建设1个安全运营中心，打造1支保障队伍，依托1个服务体系，形成1套管理规范”的服务框架展开，通过“安全策略服务、动态防护服务、监测预警服务以及响应处置服务”实现整体服务交付；通过提供整体保障运营服务，使中央企业关键信息基础设施从分散防护向体系防御、从被动应对向主动防御转变，实现 “整体安全、全面保障”总体目标，在服务中央企业数字化转型升级等方面取得了显著成效。

**NO.2**

  

***新一年 新看点***

  
中央企业网络安全整体保障服务是卫士通安全服务业务中的重点板块之一，在激烈的评选竞争中，获得行业专家、权威媒体和专业评委的一致好评，摘得年度桂冠，在过去的一年里它具备哪些市场优势、升级了哪些新看点呢？  
**· “新赋能”：**融合全球顶级的生态链，引入安全情报以及全球顶级网络安全生态赋能，将专业安全服务能力传导至中央企业。**· “新平台”：**依托态势感知安全运营服务平台打造统一数据底座+多态引擎，应用大数据和人工智能分析技术，增强威胁发现能力、数据识别能力、事件闭环管理能力。将威胁监测、智能研判、响应处置、事件追溯、态势呈现等功能融为一体，有机关联，支撑整体保障安全运营服务体系。**· “新模式”：**由服务团队与用户安全团队形成联合运营体，解决安全业务两张皮问题，从单一关注安全变成注重业务安全，提升最后一公里的处置能力。采用全新服务模式，以安全运营中心为主体，以业务连续性、防护质效作为考核指标，从整体角度检验防护效果。  **· “新效能”：**实现分钟级发现、分钟级预警、分钟级响应，以攻促防，实战检验，保障全时、全域、全业务整体防护。最终实现中央企业整体安全实时监测，安全风险态势感知，安全威胁预警与事件通报，安全事件分钟级发现处置，业务系统分级防护，安全事故调查取证追踪溯源，以及重要时期的安全指挥保障。  

**NO.3**

  

***“老字号”话新篇***

  
伴随着金智奖的历年评选，卫士通作为网络安全领域的“老字号”，已经五年蝉联“最具影响力企业”，其中最重要的支撑点便是卫士通立足自身优势，勇于开新局、话新篇。历经20余年的创新发展，卫士通现在不仅构建了覆盖芯片、模块、平台、整机、系统、整体解决方案与安全服务的产品体系，业务已横跨网络安全、主机安全、数据安全、应用安全等多个场景，并且，在移动互联网安全、5G、云安全、物联网安全、安全整体保障等新技术领域进行了大量探索和创新。例如：① 构建了完整的密码体系化能力，是国内从事商密技术研究和市场应用的企业之一；② 打造“连续的、协同的”数据安全防护体系，实现了“数据安全管理”向“数据安全治理”的跨越，为数据安全保驾护航；③ 针对广大政企移动用户移动办公需求，提供了具备“7+” 移动安全能力的系统级商密解决方案；④ 针对城市关键信息基础设施、工业互联网、城市监控等物联网系统、党政机关和企事业单位重要信息系统的全天候全方位的安全监测能力，形成线上线下相结合的安全聚合运营服务模式等。
