# 川内学术圈、科研圈“掌门们”都聚在一起了！卿昱就网络安全提出这些观点

2月5日，省委、省政府在成都召开在川部委属高校和科研单位迎春座谈会。省委书记彭清华出席会议并讲话，代表省委、省政府向在川部委属高校、科研单位全体同志以及广大师生和科研工作者，致以新春祝福和诚挚问候，向大家长期以来的辛勤付出和对四川经济社会发展的大力支持表示衷心感谢。中国网安董事长、党委书记卿昱参加会议并发言。

  
  
  
  
![](../Images/50b5204800bbae47bfd4c604727797d8.png)

**在发言中，卿昱首先从党和国家顶层设计的角度说明了发展网络安全的重要性。**党的十九届五中全会通过了《中共中央关于制定国民经济和社会发展第十四个五年规划和二○三五年远景目标的建议》，明确提出“坚持创新在我国现代化建设全局中的核心地位”“全面加强网络安全保障体系和能力建设”等重大任务。

她结合中国电科及所属中国网安肩负的央企使命任务，对加强网络安全保障体系和能力建设，融入四川国民经济建设发展提出了三点意见和建议：

**● 聚集我省网络安全优势科技力量，搭建重大科技创新平台。**

**● 加强网络安全前沿科学技术攻关和成果转化。**

**● 加大网络安全市场需求挖掘，做大做强网络安全产业，保障数字经济安全快速发展。**
