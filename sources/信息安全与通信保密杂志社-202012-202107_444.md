# 基于云计算的数字证书大批量签发应用的研究与实践

**摘　要**

  

传统的基于口令的安全防护不足以应对现在日益复杂的智能终端设备及应用环境的需求， 因此，采用非对称密码算法的数字证书认证机制很好的解决了这一问题。本文探讨了云计算模型 中的虚拟化技术在数字证书签发过程中的应用模式并提出了框架模型，针对云平台环境下千万数 量级数字证书的发行、管理及使用方面进行测试，并与实际物理环境进行对比，验证了云计算环 境下大批量数字证书签发及使用的可行性和有效性。

**引　言**

随着计算机网络规模的不断扩张，大规模联网、 并行计算、云计算等新兴技术涌现，为全面提升社会治理现代化水平，提升信息化条件下驾驭社会治 安局势的能力，以公共安全视频监控联网应用为建设重点的雪亮工程,为满足城市治安、防控和管理而以建立实时视频监控系统为重点的天网工程以及以建立一个特大型、综合性强的三防管理系统为重点的平安城市囹等国家重点项目相继展开。GB35114《公共安全视频监控联网信息安全技术要求》国家标准也发布实施。由此可见，建立大型的、 综合的、安全的监控视频联网系统对于完善社会治 安防控体系具有重要意义。

与此同时，安全的安防产品是社会治安防控体 系的基础组件和必要元素，GB35114中所规定的安 全的安防产品都以数字证书体系为基础。随着项目 的持续建设，用户量、对证书签发计算能力的需求、 安全需求等均成爆发式增长，传统的基于PKI囹 (Public Key Infrastructure )体系的数字证书发行系 统，仅通过提高硬件设备(服务器、存储、带宽等) 和软件(数据库、中间件等)性能，将远远不能满 足大规模运算需求，且单纯依靠软硬件性能的叠加 往往伴随着资源利用率低、资源分配不合理、运行开销巨大、运维成本超高等诸多问题。

云计算同(Cloud Computing )则实现了资源和架构的全面弹性，是继分布式计算(Distributed Computation )、并行计算(Parallel Computing )和 网格计算(Grid computing )等技术后发展起来的一 种共享基础架构的计算模式。它是一些可以灵活地自我维护和管理的虚拟计算资源。所以，本文作者通过分析数字证书签发流程， 将其中对计算资源要求最为集中的两个模块，核心 证书签发模块和密码服务模块，部署在云计算环境中,分别对数字证书发行、管理、使用进行性能测试, 测试数量级为千万级别，并与实际物理机环境对比，探讨在云计算环境中数字证书签发、管理和使用的可行性、有效性。

１

  

**相关背景及技术**

**1.1　数字证书与公共安防**

数字证书是一个经证书授权中心数字签名的包 含公开密钥拥有者信息以及相应公开密钥的文件。它具有唯一性和可靠性，可由权威的第三方机构签 发，即CA证书授权(Certificate Authority)中心。其基本架构是PKI体系，即利用一对密钥(公钥和私 钥)实施加密和解密，公钥可用于签名验证和加密, 被多个用户共享，但私钥只会保存在设备内部无法 被读出和伪造，使用数字证书可以保证信息的机密性、完整性和不可抵赖性。同时，数字证书具有时 效性，使用数字证书前需要先验证该证书的有效性, 其使用时间必须在证书的起始日期和结束日期之间 才有效。

在雪亮工程、天网工程以及平安城市等项目中， 其建设重点中均涉及大型公共安全视频监控系统， 目标是实现“全域覆盖、全网共享、全时可用、全 程可控”。其中，“全程可控”就在于建成分层安 全体系，实现重要视频图像信息不失控，敏感视频 图像信息不泄露。而采用基于数字证书的设备身份 认证技术，可准确的确定设备身份，保证设备数据 的真实性、完整性和可信性，从而确保敏感及重要 数据的安全。该技术是建设大型公共安全视频监控 系统的关键技术之一。

在该系统中，数字证书的签发具有以下特征：

大规模：目前我国视频监控联网系统中已经建 设的前端监控设备数量在千万量级，随着应用需求 发展,后续投入到系统中的前端设备、用户数量将 成指数增长，需要及时高效地为其进行数字证书签 发处理。

程序性：数字证书签发具有标准的流程和程序, 不同的工作阶段可以进行拆分为独立模块，方便计 算资源的动态调整。

并发性：数字证书签发操作往往比较集中，通 常是一次性对批量设备进行发证处理，所以其对计 算资源的需求具有并发性的特征。

**1.2　云计算与负载均衡**

云计算是一种新兴的计算模式，利用虚拟化技术，将计算资源(包括CPU、内存、存储、网络等) 利用统一的逻辑表示，经过一系列虚拟化过程，使 资源不受物理约束，为用户提供灵活的按需服务， 虚拟化的应用模式有一对多、多对一、多对多。云计算通常为大型服务器集群，可以进行更好的优势 资源整合，实现弹性管理，提高资源利用效率。云 计算具有高可伸缩性、快速扩展、高可靠性、按需 服务的特征。

负载均衡作为高可用基础架构的关键组成技 术，可以为云计算解决工作负载不均、性能下降等问题，为云用户实现云服务器负载均衡施(GSLB, Global Server Load Balance)。利用负载均衡通常可以 将我们的应用服务器部署多台，通过负载均衡将用 户的请求分发到不同的服务器用来提高网站、应用、 数据库或其他服务的性能以及可靠性，进而提高云服务器可用性和安全性，更加高效而稳定地进行云端操作。

**大批量签发系统应用实例**

通过分析数字证书实际签发流程与云计算的工 作原理，发现数字证书签发过程具有程序化、大规 模、并发性的特征，在大型公共安全视频监控系统 建设时经常有千万甚至上亿数量级的设备需要签发 数字证书，每次进行数字证书签发的数量跨度较大, 从几个到几百万均有可能，如果仅使用物理机负责 数字证书签发工作，则必须满足峰值时签发证书的 需求，随着数字证书待签发数量成指数增长，所需 要的物理机的数量也将迅速增长，使各证书签发中 心成本急剧上升。且由于签发证书具有并发性特征, 必将造成计算资源和成本的巨大浪费。

**2.1　框架模型**

结合实际需求，本文提出了一种基于云计算的 数字证书大批量签发的应用框架，其具体的框架模 型如图1所示，该框架为一层次模型。从上至下分 为四层，最底层为对物理设备进行虚拟化以后的虚 拟资源池，对外呈现统一的逻辑形式。其上层为调 度管理层，主要利用开源的高性能服务框架dubb。负责对虚拟资源的分配、回收以及负载均衡等，提 高虚拟资源的利用效率，实现虚拟资源水平扩展， 消除单点故障，使系统具有高可用性。再上面一层 为用户提供计算密集型服务，用户可根据需要将任 务运行过程中对计算资源要求较为集中的模块单独 部署。最上层为实际的业务需求，直接面向用户。

**2.2　系统实例**

本文对此框架进行了实现，经过分析在釆用 非对称算法对设备进行数字证书签发过程中，核心 证书签发计算和密码服务计算所需计算资源弹性较大，与签发数量密切相关，所以在云端平台环境上, 综合考虑当前业务的证书发行体系，将这两部分规 划上云。

核心证书模块

PKI体系，即物理实体环境架构图中核心区的 两台物理机以虚拟化的方式进行服务。对证书服务 器进行1:4的虚拟化配比，每台虚拟的服务器通过 部署核心证书发行组件TASSL+OpenLDAP,最终实 现业务中的证书签发、证书密钥管理、证书申请和 证书发布等所有证书发行相关功能。

密码服务模块

以SJJ1528云服务密码机为硬件平台，虚拟化 实现4个密码机，为每台证书发行虚拟服务器提供 硬件形式密码服务。

对核心证书系统的各类服务进行分布式优化设 计，釆用虚拟化技术，将核心证书系统的各个组件 分别部署到虚拟机中，对应用密码服务也采用虚拟 化密码机产品进行配合；基于云计算的特性对所有 的虚拟化的组件进行性能优化，并做适量冗余，以 支撑其弹性运算需求。

**2.3　测试环境**

在本次测试中，搭建本地私有云平台，分别将 证书发行服务器和密码机所在物理机虚拟化为4台 虚拟机，同时，部署普通物理实体机环境，在普通 服务器上部署常规应用级CA产品（包括KMC、 CA、RA、LDAP等服务）作为测试参照。物体实体 环境与云平台环境拓扑图分别如图2和图3所示。

**实验与分析**

本文分析了数字证书签发过程中所必需的几类 操作，包括证书生成、LADP读写、CRL列表签发、 OCSP查询等，分别对其模拟千万级用户数量进行 并发测试，对比云化部署的数字证书签发系统和普 通物理设备部署的传统数字证书签发系统不同的响 应速度。其测试结果分别如表2和图4所示。

**图4　云平台性能测试曲线图**

通过上述表2和图4呈现出的结果，我们不难看出，不同的测试项下结果不同。在证书生成过 程中，当生成的证书数量较小时虚拟机与实体机相 差不大，而当生成证书数量较大时，云计算平台表 现出相对优异的性能和效率。在CRL列表签发与 OCSP查询性能测试中，当查询数据量较小时两种 环境下测试数据相当，当查询数据量达到上万级别 时，云计算平台性能参数比实体机实测结果略低。

在LDAP写入测试中，当写入数据量较小时云计算 平台与实体机表现相当，当写入数据量达到十万数 据量及以上时，云计算平台表现出相对优异的性能。在LDAP读取测试中，测试结果显示随着数据量的 加大所需时间稍有加大，总体来说实体机表现比虚 拟机略好。

经过本次实验可以得出结论，一般对资源占用 比较单一的测试，小量请求时虚拟机与物理机表现 性能基本相同；当大量并发时，云计算借助于弹性 计算会实现较实体机更好的响应表现，比如在证书 签发测试、写入测试类；而对一些复合的测试，如 CRL签发、0CSP等测试，这个测试过程需要进行 数据查询、签名运算等复合操作，这类功能的测试 云计算表现与实体机相比略有落后，但是差别不大, 其主要原因是云计算的协调负载均衡以及网络传输 的消耗。综上可得出，当虚拟机单台配置与实体机 配置相同(或相似)情况下，虚拟机的性能会略低 于物理实体机的性能，但当大量并发请求出现时， 云计算的弹性就比较明显，总体响应性能会高于普 通实体机。

４

  

**结　语**

本文通过对数字证书签发过程进行分析，发现 在大型公共安全视频监控系统数字证书签发具有大 规模、程序性和并发性的特征。据此，提出了基于 云计算的数字证书大批量签发的应用框架模型并进 行编程实现，验证了基于云计算的数字证书大批量 签发的有效性和可行性。综上，由于云计算具备超 大规模、高可靠性、高可扩展性、按需服务以及成 本低等诸多优点，所以，在大批量数字证书签发工 作中，采用云计算模式更具优势。但当系统较小， 所需数字证书签发数量有限时，采用传统的基于实 体物理设备搭建的数字证书签发系统则更加合适, 且性能更佳。
