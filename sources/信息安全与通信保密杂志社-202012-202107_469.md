# 网安智库｜美国制定网络安全成熟度模型认证框架 欧盟发布《人工智能网络安全挑战》

如今，全球商业、政务等风险正变得更加多元和复杂，企业需要高度关注来自各方面的风险。其中，安全始终是不可忽视的重要环节。杂志将每周推出《全球最新网络安全动态报告》，旨在提供全球范围内关于信息、态势、战略等最新安全报告动态，助企业及网安产业有关人员及时洞幽察微，从容决策。

  

**2020年12月第4周（第11期）**

  

**《人工智能网络安全挑战》**

  
12月15日，欧盟发布《人工智能网络安全挑战》，报告介绍了在人工智能网络安全特设工作组的支持下实现的AI网络安全生态系统及其威胁态势的主动映射。ENISA AI威胁态势不仅为即将到来的网络安全政策计划和技术准则奠定了基础，而且还强调了相关挑战。一个特别重要的领域是与AI相关的供应链领域，因此，重要的是要强调对欧盟生态系统的需求，以确保包括AI供应链的所有要素在内的安全可靠的AI。欧盟安全的AI生态系统应将网络安全和数据保护放在首位，并促进相关的创新，能力建设，意识增强和研究与开发计划。  

**《欧盟数字十年的网络安全战略》**

  
12月16日，欧盟发布《欧盟数字十年的网络安全战略》，报告旨在增强欧洲应对网络威胁的集体韧性，并有助于确保所有公民和企业都能充分受益于值得信赖和可靠的服务和数字工具。该战略包含法规、投资和政策工具方面的相关建议，旨在应对欧盟行动的三个领域：（1）韧性、技术主权和领导力；（2）建立预防、制止和应对的行动能力；（3）推进全球开放的网络空间。欧盟在新的网络安全战略中承诺，在未来七年内对欧盟数字化转型的投资可能达到以前的四倍。  

**《港口的网络风险报告》**

  
12月17日，欧盟网络安全局发布《港口的网络风险报告》，旨在为港口运营商提供网络风险评估的良好实践，使他们可以适应所遵循的任何风险评估方法。为了实现这一目标，本报告引入了针对港口运营商的网络风险管理的四个阶段的方法，该方法遵循共同的风险管理原则，并映射到ISPS规则和相关欧盟中规定的风险评估方法的步骤港口和港口设施安全立法。对于每个阶段，该报告均提供了可操作的指南，以协助港口运营商的努力，列出与相关活动的实施相关的常见挑战。  

**《ICT供应链风险管理工作组第二年报告》**

  
12月17日，美国网络安全与基础设施安全局(CISA)发布《ICT供应链风险管理工作组第二年报告》，介绍了其在推进有意义的合作伙伴关系和分析方面的进展供应链的安全性和弹性。ICT SCRM工作组第二年报告以ICT SCRM工作组第一年完成的先前工作为基础。它展示了工作队中四个工作人员的集体持续努力，以应对信息共享，威胁分析，合格的投标人和合格的制造商清单以及供应商保证方面的挑战。它还反映了一个新的工作组，即第5工作组，该工作组最近发布了一份关于COVID-19大流行对ICT供应链的影响的分析报告。  

**《系统战的联合作战概念》**

  
12月17日，新国家安全中心发布《系统战的联合作战概念》，报告介绍该中心正在研究的一种新联合作战概念—系统战。这是一个面向智能时代，强调算法、网络、人机协作、智能作战、体系破击的全新概念。这个新概念将解释新的人机协作网络如何利用AI算法作战，将在未来的任何系统对抗中为联合部队带来决定性的优势，并具有击败系统破坏攻击的能力。  

**《国防采办：国防部网络安全成熟度模型认证框架》**

  
12月18日，美国美国国会研究局发布《国防采办：国防部网络安全成熟度模型认证框架》。以网络攻击和数据窃取为代表的网络安全威胁对国防部（DOD）和国防工业基地（DIB）产生了重大影响，为应对网络安全威胁，国防部于2019年初开始制定网络安全成熟度模型认证（CMMC）框架。这项由国防部推动的计划旨在为国防采办提供一个“统一的网络安全标准”，旨在利用并建立在现有法律法规的基础上。CMMC框架将建立一个“验证机制”，要求所有寻求与国防部开展业务的主承包商和分包商从经认可的第三方组织获得证明，证明承包商的内部网络安全实践和流程符合一定标准。国防部的CMMC框架旨在保护联邦合同信息或由政府合同提供或根据政府合同生成的不公开发布的信息，并增强合同活动过程中生成的受控非机密信息的安全性。

**编辑整理：信息安全与通信保密杂志社、中国网安科技情报研究团队**

**信息安全与通信保密杂志社**由中国电子科技集团公司第三十研究所全资组建，旗下有《通信技术》和《信息安全与通信保密》两种期刊。《信息安全与通信保密》创刊于1979年，至今已历时近四十载，全程见证了我国网络安全事业的发展进程。《通信技术》创刊于1967年，是国内创办时间长、影响大的计算机领域专业媒体。同时，信息安全与通信技术杂志社目前已打造成比较成熟的新媒体矩阵。现已成为网信领域用户规模较大、用户活跃度较高、影响力和传播度较广的门户级移动互联网平台。

**中国网安科技情报研究团队**深耕网络安全领域三十余年，主要聚焦于信息安全、密码保密、网络通信、网络对抗等专业。围绕军民两域，实时跟踪全球网络安全领域动态，深度解析网络安全领域智库报告，形成了体系性的科技情报成果。
