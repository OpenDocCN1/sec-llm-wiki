**全球６G技术大会召开在即**

据新华网11月2日报道，2021年全球6G技术大会将于11月23日至25日在南京举行，此次大会将采取现场研讨＋全球多地远程互动的方式，齐聚全球各个国家6G技术研究力量，围绕6G应用场景及需求、6G网络架构、6G无线传输技术和天地融合技术与按需服务等议题展开深入讨论。

此次大会由紫金山实验室、未来移动通信论坛主办，将举办1场大会报告、9场专题论坛和2场国际圆桌讨论，来自美国、英国、加拿大、芬兰、瑞典、日本、韩国、新加坡、希腊和沙特阿拉伯等全球多个国家的高校及科研机构、电信运营企业、设备制造商的近百位权威专家将针对6G相关技术话题展开全面交流和深入讨论，并在会议期间以“未来移动通信论坛”的名义发布多份6G技术系列白皮书。

如今，6G仍处于愿景需求研究及概念形成阶段，6G技术方向及方案仍在探索中， 2021全球6G技术大会将继续全面展现6G技术研发的创新思路和最新成果，持续搭建全球科技合作平台与协同创新桥梁，形成推进6G研发的相关建议，致力推动培育全球一致的6G理念，合力营造全球6G发展良好环境，为推动形成全球统一的6G标准和信息通信产业可持续发展作出贡献。

**02**

**工信部开展信息通信服务感知提升行动**  

工信部网站11月9日发布公告，称工信部将于2021年11月至2022年3月开展信息通信服务感知提升行动。同时工信部也对近日印发的《关于开展信息通信服务感知提升行动的通知》进行了详细解读。

此次专项行动要求相关企业（包含了39家主要互联网企业）建立已收集个人信息清单和与第三方共享个人信息清单，并在APP二级菜单中展示，方便用户查询。同时基于此前印发的《关于开展信息通信服务感知提升行动的通知》，工信部明确提出了两项要求：一是相关企业应简洁、清晰地列出APP（包括内嵌第三方软件工具开发包SDK）已收集的用户个人信息基本情况，包括信息种类、使用目的和使用场景等；二是建立与第三方共享个人信息的清单，相关企业应在二级菜单中列出APP与第三方共享的用户个人信息基本情况，包括与第三方共享的个人信息的种类、使用目的、使用场景和共享方式等。

**03**

**安全牛发布《中国网络安全企业100强》**  

中国智库“安全牛”网站于11月9日发布第九版《中国网络安全企业100强》报告，从经营、用户、产业、行业贡献四大维度27个细分项，对网络安全企业进行了综合考评。该报告的主要调研成果如下：

2020年中，我国网络安全企业的整体收入规模约为690亿元，相比2019年度增长约120亿元，整体增长率约为24%。其中收入最高的三个细分领域为基础安全（199亿元）、安全服务与运营（122亿元）和业务与应用安全（107亿元；），收入增长最快的三个细分领域为云安全（增长126%）、新兴安全（增长106%）和安全服务与运营（增长97%）。

2020年中，我国网络安全企业总利润规模约为85亿元，相比2019年度增长16%，2020年度网络安全企业整体利润增长滞后于整体收入增长。

2020年中，我国网络安全企业（含科技类公司网络安全团队）从业人员总数约为106000人，其中技术研发人员占比约48%，安全服务人员占比约21%，营销人员占比约26%，其余为管理保障类。

截止2020年底，我国网络安全企业一级市场累计融资金额超过400亿元，其中2020年度约为85亿元，我国网络安全企业整体市值（估值）超过3500亿元。

在基础安全、业务与应用安全、身份与访问安全、数据安全、移动安全、云安全、工控安全、安全运营与服务、商用密码和新兴安全这十个细分领域中，奇安信的技术创新、用户认可和行业贡献均位列第一，在中国网络安全100强企业榜单上独占鳌头。

# **乌克兰曝光俄罗斯网络行动**

 据Cyberscoop网站11月4日报道，乌克兰安全局（SSU）于当日发布了一份详细报告，指控俄罗斯及“叛徒”近年来对乌克兰发起了名为“末日审判”的网络行动。

该报告包含了35页的书面分析、幻灯片和视频，称从2013年或2014年起，俄罗斯联邦安全局（FSB）辖下的APT组织Gamaredon（亦称Primitive Bear）就对乌克兰发起了网络行动，主要目标是控制关键基础设施、窃取和收集包括保密信息在内的情报、开展信息战和心理战以及瘫痪各类信息系统。改行动大致可分为两个阶段：2017年前，Gamaredon主要使用公开软件；2017年后，Gamaredon开发了名为Pterodo／Pteranodon的自定义恶意软件来增强网络战能力。该报告表示，Gamaredon在行动期间对乌克兰国家机构和关键基础设施发起了5000多次网络攻击，试图“感染”1500多台政府计算机系统。此外该报告还披露了Gamaredon五名成员的真实身份，称这些人员隶属于FSB克里米亚分部，是在2014年的克里米亚入俄事件中“叛投”俄罗斯的原乌克兰安全人员。为证明指控的真实性，SSU还发布了两名Gamaredon成员之间的电话通讯录音，内容涉及到Gamaredon实施的网络攻击。

乌克兰此举显然是为了吓阻俄罗斯的网络行动，不过俄方对该报告未予置评。

# **美国防部发布2.0版《网络安全成熟度模型认证》**

据C4ISRNET网站2021年11月4日报道，美国国防部于当日发布了2.0版《网络安全成熟度模型认证》（CMMC 2.0）流程，该版本对特朗普政府发布的1.0版流程做了一些调整。

CMMC是一种检验国防承包商网络安全水平的评测流程，其流程本身和评测结果分为若干等级，承包商只能参与符合自身评级的国防合同。与CMMC 1.0相比，CMMC 2.0将原先的5个等级简化为3个等级，进一步阐明了监管要求、政策要求和合同要求，并对承担最高优先级国防项目的承包商实行最严苛的网络安全标准和第三方评估要求。美国国防部表示将在出台相应规则后执行CMMC 2.0，为此其已在发布CMMC 2.0的同时暂停了CMMC 1.0的试点工作，要求在出台最终规则前不得将CMMC纳入任何国防合同要求。

此前CMMC 1.0已于2020年9月开始试点，但一些小型企业和非传统承包商认为该流程成本高昂、过程繁琐，这些意见促使美国国防部国防部于2021年初开始审查CMMC，CMMC 2.0由此应运而生。

# **美国众议院为网络安全拨付巨额经费**

据TheRecord网站11月6日报道，美国众议院于5日批准了1.2万亿美元的基础设施法案，其中近20亿美元将用于联邦政府的网络安全工作。

该法案分配了19亿美元的网络安全资金，其中10亿美元将用于制定一项拨款计划，以改善州、地方、部落和领地政府的网络安全。这笔资金将由联邦紧急事务管理局管理，而网络安全与基础设施安全局（CISA）将在拨款决策中充当主题专家。

此次通过的基础设施法案中还包括《网络响应和恢复法案》，后者授权联邦政府在五年内拨款1亿美元以支持网络事件响应，并允许国土安全部长在国家网络总监的配合下宣布重大网络事件，届时CISA将协调事件响应工作，并利用应急资金帮助政府机构和私营公司从网络攻击中恢复过来。

拜登表示，他相信美国国会还将另行通过一揽子网络安全方案。

# 美海军陆战队扩建网络部队

据Dvids网站2021年11月5日报道，美国海军陆战队网络司令部（MARFORCYBER）于11月1日和5日先后新设了“网络活动预备役”单位和一个网络营。

其中“网络活动预备役”单位将负责掌控面向所有海军陆战队预备役单位的“海军陆战队企业网络”（MCEN）（MCEN是海军陆战队的通信骨干网，可为海军陆战队的所有单位和设备提供强大、无缝且安全的端到端通信），并充当全国150处基地的训练中心；新的网络营则负责执行美国海军陆战队及联合部队安排的网络作战和全域信息行动，与以往的网络部队相比，该营能够更好地指挥和控制各网络防御单位，从而使“海军陆战队网络战集群”（MCCYWG）能专注于组建、训练和部署更强大的网络部队。

按照MARFORCYBER司令的说法，这两个单位将改善海军陆战队的网络安全水平和网络行动能力。

# **美首次将网络部队部署至欧洲轰炸机部队**

据U.S. Cyber Command网站11月4日报道，在“欧洲轰炸机特遣队”任务期间，美国网络司令部派出“网络保护小组”（CPT）保护第9远征轰炸中队的B-1B“枪骑兵”轰炸机上的关键数据，这是网络司令部首次向轰炸机特遣队提供此类支援。

此次网络部队动态部署是网络司令部实施的战略轰炸机同步防御的一环，旨在避免战略轰炸机等关键平台遭到网络入侵。派出的CPT由联合部队总部空军网络分部的网络防御专家组成，他们在一定程度上消除了战略轰炸机关键任务系统的网络漏洞，提升了轰炸机部队的网络安全水平，并加强了这些部队抵御恶意网络活动的能力。

美国空军对这一支援表示欢迎，其官员称部署CPT不仅加固了飞机的网络，还从攻防能力的角度增强了美国战略司令部的全球影响力。

# **美政府打击勒索软件组织REvil**

据Nextgov网站2021年11月8日报道，美国司法部起诉了两名据称是勒索软件组织REvil成员的外国人士，并对他们及虚拟货币交易平台Chatex实施制裁。

美国司法部对乌克兰人Yaroslav Vasinskyi和俄罗斯人Yevgeniy Polyanin提起诉讼，指控他们涉嫌今年7月对软件公司Kaseya发动勒索软件攻击，导致该公司在全球范围内的1500家客户受到影响。按照美国司法部门的说法，Vasinskyi至少勒索了10家公司，而Polyanin则实施了3000多次勒索攻击。目前波兰当局已应美国要求在边境处逮捕了Vasinskyi，美国司法部从Polyanin处查获了610万美元的赎金，美国财政部则对涉嫌帮助REvil洗钱的虚拟货币交易平台Chatex实施制裁。除此之外，美国国务院还悬赏1000万美元以查明REvil的幕后主使。

鉴于勒索软件已对关键基础设施构成巨大威胁，美国开始协调各方力量，全力追查今年一系列重大勒索软件攻击事件的幕后黑手，此前欧洲执法当局就于10月末逮捕了两名涉嫌传播REvil勒索软件的黑客。

# **美国将间谍软件开发公司列入黑名单**

据BreakingDefense网站11月3日报道，美国商务部辖下的工业与安全局以损害美国国家安全利益为由，禁止美国人与包括以色列NSO集团在内的四家公司交易。

NSO集团此前因间谍软件“飞马”而备受关注，其它三家公司则是以色列的Candiru、新加坡的Computer Security Initiative Consultancy和俄罗斯的Positive Technologies。工业与安全局称这些公司威胁到了公民、政府和国内外组织的网络安全，因此被列入商务部实体名单（即禁止交易对象的黑名单），任何美国人都不得与这四家公司交易。不过工业与安全局也同时表示不会对这些公司所在的国家或政府采取行动。

对于此项制裁，NSO集团辩称其间谍软件仅供各国政府追捕犯罪份子之用，因此希望美方撤销这一决定。然而只有经美国商务部、国务院、能源部、国防部和财政部代表组成的最终用户审查委员会（ERC）一致同意，才能从实体名单上撤下某一公司，因此上述制裁决定短期内恐难改变。

# **美陆军加紧部署五大网络防御技术**

据AFCEA网站11月5日报道，在11月3日至5日举行的“AFCEA Belvoir行业日”上，美国陆军的网络专家介绍了陆军正在推进的五大网络防御技术：

网络分析和检测（CAD），该技术立足于美国陆军的大数据平台Gabriel Nimbus，而后者可以汇集原始数据并加以分析。CAD的具体功能将包括增加存储大小、添加新的数据源以及整合特殊的应用程序和工具。目前其已应用于陆军的非保密网络和秘密级网络，未来还将用于陆军的绝密网络。

用户活动监控（UAM），利用该技术，分析师能借助各种触发器近乎实时地识别陆军网络中的高风险用户活动，从而化解内部威胁。此外UAM还将充分利用Gabriel Nimbus平台上的所有工具、应用程序和数据流。

威胁仿真，用户可利用该技术在自己的网络上模拟网络攻防，从而在实际攻击之前就发现网络漏洞。目前该技术刚刚完成运行评估，预计将在未来几个月内部署到位。

网络平台与系统（CPS），美国陆军希望在2023财年部署采用该技术的下一代“可部署防御网络作战系统－模块化”（DDS-M），DDS-M是一种可配置的硬件套件，可供国内外的网络保护小组（CPT）使用。

驻军网络防御行动平台（GDP），该技术可以高速汇集数据，目前美国陆军正在使用第3版GDP，计划于明年推出第4版GDP，并于2023年前推出采用云方案的第5版GDP。

美国陆军表示强化网络防御行动的核心在于增加数据，而更多的数据和接触点能帮助陆军更好地感知网络战场。

# **美军火巨头与通信巨头合作开发军用5G技术**

 据Nextgov网站11月2日报道，全球最大的国防承包商洛克希德·马丁公司正在与美国最大的无线通信运营商Verizon合作开发军用5G技术。

两家公司将合作开发一种特殊的通信网关，这种网关可充当不同军用数据链之间的转换器，从而形成能够互操作的完整战术网络。两家公司将考察通过5G相连的战术数据链的扩展性，并在混合云环境下开展试验的组织。两家公司已在洛克希德马丁公司的5G测试场测试了Verizon公司的5G网络，测试结果表明前者的开放战术网关解决方案能够与后者的现场5G网络技术实现互操作。

目前两家公司的合作以研发为主，未来还可能扩大到其它领域，最终目标则是为美军创建能链接所有武器并实现互操作的战术网络。

# **美研发军用车辆网络安全系统**

# 

据TheDefensePost网站11月3日报道，美国德克萨斯州西南研究所（SwRI）开发了一款入侵检测系统（IDS），以保护军用车辆免遭网络攻击。

该系统由SwRI与“美国陆军车辆系统中心”合作开发，其采用广泛用于各类车辆的控制器局域网（CAN）协议来传输数据，并通过多种算法和数字指纹（后者包括最小和最大电压等基本的物理特性）来识别接入车辆网络的未知节点或无效节点，从而找出车载通信系统中的异常情况。为了尽可能改善技术指标，SwRI对该系统进行了测试。在向该系统注入虚假数据后，该系统立即准确识别并标记了来自未授权节点的消息和来自有效节点的虚假消息。SwRI的工程师表示，该系统将有助于建立接入车辆更多、自动化更高的高弹性无线车辆网络。

尽管上述IDS是为军用车辆设计的，但SwRI称该技术亦可集成到乘用车和商用车中。
