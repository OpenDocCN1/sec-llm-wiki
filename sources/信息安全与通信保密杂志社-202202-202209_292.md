# 2022合作伙伴大会｜绿盟科技胡忠华：全面推进，初见成效，聚以致远，乘风远航

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247545966&idx=2&sn=c3bca3cd2c7f2ff48e7cc3c780416480&chksm=c0b4ee18f7c3670ea2c4da5e39839df0162532848e56a7097abf4457a621dd7cec5ea9e18bdb&scene=126&sessionid=1681312117#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247545966&idx=2&sn=c3bca3cd2c7f2ff48e7cc3c780416480&chksm=c0b4ee18f7c3670ea2c4da5e39839df0162532848e56a7097abf4457a621dd7cec5ea9e18bdb&scene=126&sessionid=1681312117#rd)

**5月8日，绿盟科技在线上召开2022年合作伙伴大会，以“聚以致远·乘风远航”为主题，邀请合作伙伴齐聚云端，共同探讨网络安全行业市场新机遇，分享绿盟科技渠道战略转型成果，洞见绿盟科技核心产品竞争力。**

![](../Images/cb0aa76c8807fe2bc2b6edaa66b2bef8.png)

**以开放之心，促进业绩稳健增长**

绿盟科技集团总裁胡忠华在会上表示，经过三年的全面推进，渠道战略转型初见成效，全行业、全客户全面开放合作，内部管理、流程、运作机制基本成型。2021年，公司整体业务渠道占比约65%，非运营商业务渠道占比达80%以上。到目前为止，公司签约渠道4000多家，其中约70%已有实际合作，过千万35家。对于渠道战略转型，公司在思想上更统一、认识上更深刻、政策上更完善、流程上更简单。基于开放多赢的生态体系，以及学习借鉴业界先进实践、结合网安行业特点构建的简单高效两级渠道架构，绿盟科技业绩稳健增长，夯实安全行业优势地位。

**![](../Images/96f5e336b3bf2c9df32559d64d1c6201.png)**

**绿盟科技集团总裁胡忠华**

**以创新之姿，为客户提供更好体验**

为了响应国家网络安全的整体战略，践行绿盟科技成立之初的产业报国理念，近三年，绿盟科技持续加大研发投入，持续创新解决客户安全痛点和需求，为客户提供更好的体验。2022年，绿盟科技重点推出“云运营再造新安全”的云化战略，并发布T-ONE CLOUD 解决方案，将安全资源池NCSS、魔力防火墙NF-SSE、SASE、手机APP等一系列产品进行整合，做到“云地人机”协同解决客户的安全痛点；在数据安全领域，补齐隐私计算、数据库脱敏、数据备份等产品和方案，提供数据安全全生命周期的解决方案；在物联网安全领域，车联网、IoT、工业互联网、工控方向均发布了若干新产品；在终端安全方面，移动手机的安全在持续创新中；在芯片安全领域，启动开发安全芯片，把多年积累的安全能力固化到芯片上，让安全从“芯”开始。在战略生态合作上，与伙伴联合打造解决方案，磨合创新产品，提升客户体验，合作共赢。

**以组织优化，构建渠道合作生态土壤**

组织方面，一线持续以客户为中心，推进铁四角落地，形成合力；推进代表处和行业的横纵结合，上下拉通，真正做到“一个绿盟”，成为作战和综合经营单元。考核方面，销售考核从毛利改为收入，重塑利他思维，通过考核牵引销售跟主流渠道合作，做大增量、做大蛋糕；流程方面，渠道商务系统持续优化改进，全流程自主可见，从报备、授权函、特价申请、下单、激励、返点等都可自主操作。通过三年来组织、考核、流程的优化，匹配渠道战略转型，培育生态土壤，让更多的合作伙伴跟绿盟科技的合作开花结果，让绿盟科技的业务给合作伙伴的生意添砖加瓦。

**以理念升级，携手合作伙伴乘风远航**

面向未来，公司将继续全面推进渠道战略转型，大力发展能力型合作伙伴，今年全面落实优选渠道政策，拉通绿盟科技及各级合作伙伴的优势资源，推进行业市场拓展，探索商业市场拓展。同时加大研发投入，持续创新产品，本着更加开放、更加坦诚、更加简单、更加多赢的合作理念，进一步坚定信心、完善政策、强化考核、简化流程，从产品到安全服务、安全运营，全行业、全客户开放合作。希望和各位合作伙伴一起，聚以致远，乘风远航。
