# 石梁：沉淀创新 笃实力行

**近日，由信息安全与通信保密杂志社主办，中关村智能终端操作系统产业联盟协办的2021年度（第六届）“中国网络安全与信息产业金智奖”（以下简称“金智奖”）评选结果公布，西安信安保密技术研究所所长石梁荣获“新锐人物”奖。**

本届“金智奖”在参选企业的大力支持和业界同仁的广泛关注下，共有近百家企业、120余位专家评委、50余位媒体评委以及1000余位专业评委报名参与评选。最终，以真实数据为基础，遵循公开化、科学化、权威化、透明化的原则，在专家、媒体、企业等组成的评审团见证下，网安领域新锐人物、最具影响力企业、创新企业、优秀产品及优秀解决方案网安领域年度奖项名单悉数出炉。

![](../Images/e9df885afcb5ab16b785dbe43047e11b.png)

西安信安保密技术研究所所长　石梁

在企业管理方面，石梁创立了先进的信安企业文化，从发展原则、发展理念、发展宗旨、发展战略，到全员“价值”思维和核心价值观，加强员工个人修炼，并以退役军官为核心，打造了一支具有“六特”精神的过硬团队。在军工认证方面，创立了“一站式、一体化、一条龙”的服务模式和“植入+融入”的服务方法，提高了咨询辅导质量效率；组织力量编制了五个军工认证咨询辅导服务规范，分别被陕西省和西安市列为地方标准。在商业秘密保护方面，创造性地提出了商业秘密保护体系建设“新木桶”理论，在此基础上编制了我国第一个《商业秘密保护体系建设规范》，并被陕西省作为地方标准立项。在军民融合方面，创造性地提出了军民融合“6+1”创新思维和新时代九大新思维等研究成果，为全国各地军民融合战略落地提供规划、策化和优化服务，并走遍全国为政府和企事业单位进行军民融合战略宣贯100多场。![](../Images/3a131427e27ce482bc0f480bf30a6333.png)![](../Images/a92bf89334a003acc4d3d1737d5abf27.png)![](../Images/6013f1d558544f3787e4abe0b567f004.png)![](../Images/db9a8599b0a86635ef2f1ff71b74413c.png)![](../Images/9bcf43d774fa040d8565ba1592b8b1ac.png)

石梁曾多次被评为优秀共产党员和陕西省、西安市模范军转干部。2012年当选“中国杰出创新人物”。2013年当选“创业中国年度人物”、获得工信部“领军贡献奖”。2014年入选《中国百名优秀企业家奋斗史》一书。2015年获得全国中小企业金牌服务商和服务之星称号。2016年获得全国中小企业杰出企业家奖、《领军影响人物》奖。2017年当选为中国商协先进个人和西安市年度创新创业先进个人。2018年获得西安市“创业明星”“创业带头人”称号。2019年被评为西安市“诚信西商”和“最美退役军人”，2020年荣获“中国经济(行业)十大创新企业家”称号。

近年来，石梁在网信安全、军民融合、退役军人创就业、大学生职业规划、婚姻家庭、个人品牌、企业文化建设等方面授课八百多场，深受大家欢迎。已为近千个单位提供了高质量的信息安全和保密技术服务，并帮助数百家“民参军”企业取得了相关资质。
