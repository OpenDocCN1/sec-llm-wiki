# 重磅奖项揭晓！长亭科技万象（COSMOS）上榜

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247545889&idx=1&sn=e682415d3bff69aee1923f7b05754642&chksm=c0b4ee57f7c36741aaa7bb91d15bd273a34c2de4ec475e33b6dd027b1e02048da3c39f8e78a6&scene=126&sessionid=1681312129#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247545889&idx=1&sn=e682415d3bff69aee1923f7b05754642&chksm=c0b4ee57f7c36741aaa7bb91d15bd273a34c2de4ec475e33b6dd027b1e02048da3c39f8e78a6&scene=126&sessionid=1681312129#rd)

**在2021 年度（第六届）“中国网络安全与信息产业金智奖”（以下简称“金智奖”）评选表彰活动中，北京长亭科技有限公司（以下简称“长亭科技”）旗下“万象（COSMOS）安全分析与管理平台”在众多参选产品中脱颖而出，荣获“优秀产品”奖。**

  

本届“金智奖”由信息安全与通信保密杂志社主办，中关村智能终端操作系统产业联盟协办，获得了参选企业的大力支持和业界同仁的广泛关注，在近百家企业、120余位专家评委、50余位媒体评委以及1000余位专业评委的参与和见证下，经过网络投票、媒体和专家终评等系列环节，最终产生了所有的奖项。 

  

**金智奖**

![](../Images/71854867344c6e9002c6dab1cfaf8f5a.png)![](../Images/794e79d790c557598692d292edbb5f7c.png)

**金智奖**

此次获奖的万象（COSMOS）安全分析与管理平台提供了一个基于环境的、动态、整体地洞悉安全风险能力的视角。它以企业安全数据为基础、以“人+平台”的运营理念为核心，通过关联分析、基线学习、可视交互、安全引擎等技术手段，将攻防经验和业务场景深度融合，深度感知用户网络空间风险发生的时序关系，并给出精准预判及处置动作。  

万象（COSMOS）安全分析与管理平台采用成熟先进的大数据架构，带来实时的流量分析与处理速度，其独特的数据关联分析能力，可以实现对各类数据以攻击IP、被攻击对象、攻击类型等多个多维的聚合降噪。与此同时，万象（COSMOS）安全分析与管理平台可以通过高度灵活的安全编排自动化与响应（SOAR）技术，联动多种安全设备实现安全运营，助力企业实现全局视角的安全威胁发现识别、理解分析、响应处置。

据悉，长亭科技是国际顶尖的网络信息安全公司之一，全球首发基于智能语义分析的下一代 Web 应用防火墙产品。目前，长亭科技已推出以攻（安全评估系统）、防（下一代 Web 应用防火墙）、知（安全分析与管理平台）、查（主机安全管理平台）、抓（伪装欺骗系统）为核心的下一代安全防护体系，并提供优质的安全测试及咨询服务，为企业级客户带来智能的全新安全防护思路。

由信息安全与通信保密杂志社发起的“金智奖”年度评选活动至今已成功举办了六届，被视为中国网络安全产业发展的风向标，得到了业界的高度关注和认可，有效地提升了企业的影响力、竞争力和品牌价值，大大推动了网安产业的发展。
