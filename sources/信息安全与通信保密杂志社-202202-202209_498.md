# 兰德智库报告《网络恶意信息的人机检测》解读

**2020年6月23日，兰德公司官网发布了一份《网络恶意信息的人机检测》报告。这份报告是英国国防部国防科技实验室通过其国防和安全激励部（DASA）委托进行的一项研究的成果。这项研究是DASA征集提案的一部分，旨在帮助英国国防部发展其行为分析能力。这项研究的最终成果包括一个概念验证方法，用于人机检测和分析社交媒体上恶意使用信息的行为。兰德欧洲公司的方法是基于应用公众理论驱动的方法来影响行动和创新性使用语言立场比较技术。这一方法已被用来理解如何在针对不同公众的假情报工作中使用具体策略。该研究旨在开发一种方法，用于检测网络信息的恶意使用，并培养对网络信息的抵御能力。下面我们将对这篇报告的主要内容进行概括总结，并提出几点认识，供领导、专家和相关技术人员参阅。**

**一、**

  

**报告主要内容**

  

《网络恶意信息的人机检测》报告全文总共69页，主要由三个章节的内容构成。针对该项研究的主要任务，报告第1章建立了恶意信息行动的威胁环境（任务一）。第2章总结了几项发现结果，这些发现结果所采用的手段一是在已知的俄罗斯巨魔数据库中应用概念验证机器检测（任务二），二是对针对左翼和右翼公众的恶意信息行动的俄罗斯间谍情报技术进行分析（任务三）。第3章探讨了工具的开发和应用，并提出了一种对针对目标人群的恶意信息进行抵御可能采取的战略框架组成（任务四）。报告最后是附件A，它是为支持报告中提出的主要发现结果，对弱势公众对恶意信息的抵御能力进行了更广泛的讨论。  

下面对报告主要内容进行概括：

**（****一）报告阐述了开展这项研究的背景主要是基于社交媒体正越来越多地被人和自动化用户用来歪曲信息、侵蚀对民主的信任和煽动极端主义观点**

报告认为，如今，约44%的英国成年人使用社交媒体进行新闻消费，这使得社交媒体成为最受欢迎的在线新闻渠道。社交媒体已经彻底改变了政治话语引导方向，让大众以新的方式参与进来，让用户能够直接接触到社会影响者和政治领袖。然而，越来越多的社交媒体的使用，新闻源中缺少人工编辑，以及合成在线活动的增长都可能使行动者更容易操纵社交网络。

近年来，在英国、其他北约成员国和全球范围内，技术发展使得通过社交媒体对信息的操纵越来越多。社交媒体可以被用来在重要的政治、安全和国防相关决策关键时间点上（如选举或全民公决时）制造虚假的支持或反对信息。社交媒体还可能被用来削弱对政府机构和民主进程的信任，并在目标群体中煽动极端主义观点。

虚假信息的影响已经在英国和国际上得到公认。2014年，世界经济论坛将网络虚假信息的传播列为社会十大危险之一。英国已经在几份政府文件和行动中承认了虚假信息的威胁，包括建立快速反应小组——一种旨在鼓励基于事实的公开辩论的社交媒体能力。尽管做出了这些努力，但这个问题的重要性和影响依然在不断增加，这使得个人和组织更难辨别真假信息。

基于网络的恶意信息的传播有几种形式，包括传播垃圾新闻、冒充个人来操纵受众、网络欺凌活动、恐怖主义宣传和招募，以及以提高声誉或抹黑活动为形式的政治“排挤”。这些活动是由合成账户和个人用户实施的，包括网络在线巨魔、政治领袖、极左或极右个人、国家对手和极端主义团体。

根据他们的任务，无论是个人还是人工合成的在线参与者都可以瞄准广泛的受众。恶意在线活动的目标可能有：（1）大批个人，如选民、政治受众或年轻一代。（2）特定群体，如通过社交媒体成为对手目标的军事人员。（3）市场，如旨在窃取金融数据或操纵股市的金融市场。

**（二）报告明确提出了该项研究的目标、任务和整体研究方法**

基于上述背景，兰德欧洲公司被委托对在线检测恶意信息的人机方法进行研究。这项研究是由英国国防部国防科技实验室通过其国防和安全激励部（DASA）承包的。采用公众理论驱动的方法，使用语言立场技术支持以下两个研究目标：（1）加强对特定修辞策略误导公众方式的理解。（2）开发一种方法，用于检测网络信息的恶意使用，并培养对虚假信息的抵御能力。

为此，兰德研究团队顺序开展了以下研究任务，这些任务与上述研究目标相对应：（1）任务一：在英国、欧洲和跨大西洋社区建立恶意信息行动威胁环境．（2）任务二：在已知的俄罗斯巨魔数据库中应用概念验证机器检测，重点关注是与2016年美国总统选举相关的在线讨论。（3）任务三：对俄罗斯针对左翼和右翼公众的恶意信息行动进行间谍情报技术分析。（4）任务四：提出进一步开发该工具的备选方案，并概述建立抵御恶意信息框架的思想。

根据上述任务，研究团队分别采取了以下方法：（1）文献研究与专家访谈。（2）网络分析、姿态与语义分析、算法开发。（3）统计分析与机器学习、公众分析、战略开发。（4）概念模型构建、战略开发。

**（三）报告概括了当前识别社交媒体操纵的主要技术**

报告指出，当前有多项技术可用于对恶意信息使用的分析。这些技术主要是用于：虚假信息的事实检查/识别和内容验证；假账户和机器人的检测；计算放大的检测；虚假信息活动检测；理解分裂技巧的使用和影响（例如仇恨言论）等。这些分析技术大多是基于网络和文本的，主要有：（1）社交网络分析（SNA）：它被广泛用于识别机器人、检测假账户以及理解虚假信息的传播和放大。（2）自然语言处理（NLP）：已被用于检测错误信息和虚假信息，以及识别机器人。然而，网上虚假信息的自动检测仍然是自然语言处理的一个重大挑战。这是因为原始数据的获取和可用性有限，而原始数据可用于进一步开发专门用于抵消网上传播的虚假信息的速度和数量的方法，以及需要更清楚地说明真实和虚假信息之间的语言差异。（3）情感分析（SA）:可以被认为是自然语言处理的一种形式，经常被用于市场营销和客户服务。情感分析是一种数据挖掘形式，它“通过自然语言处理、计算语言学和文本分析来衡量人们对特定想法、人物或产品的看法”。SA是一个有用的工具，可以理解现有群体意见的潜在极性，并“分类和理解用户对感兴趣主题的感受”。因此，在分析人类行为和社交媒体网络之间的关系时，这种方法可能特别有意义，它允许研究人员检测数据的极性和主观性以及情感强度。（4）姿态和情绪分析（SEA）：它是SA的一种扩展。（5）认知心理学概念：它也被应用到社交媒体分析中，以识别欺骗和虚假信息的传播。应用于社交媒体的认知分析主要集中在对“消息的一致性、消息的连贯性、消息来源的可信度和消息的一般可接受性”的分析上。（6）数据挖掘：旨在“从大量数据集中提取信息，并将其转换成合理的结构以供进一步使用”。因此，这种方法侧重于寻找隐藏在“噪音”中的新的可操作数据。它作为社交媒体分析的基准方法，以及减轻大量原始数据的挑战特别有用。几种数据挖掘技术可以用来构造数据，例如回归、聚类、分类和顺序模式挖掘。（7）信息检索：这是一种计算机科学方法，用于寻找“非结构化性质的数据（通常是文本，并且不是为了便于计算机使用而结构化的数据)，以满足大型集合中的信息需求。（8）机器学习和深度学习以构建人工智能：该技术被视为检测和反击网络虚假信息的潜在解决方案。由于社交媒体的特性（即大数据和非结构化数据及其速度），各种形式的自动化数据分析已经被英国及其盟友所采用。例如，北约的联盟开源系统（AOSS）应用人工智能和大数据分析来访问、分析和可视化开源数据。

**（四）报告总结了这项研究的主要成果：是一个基于理论的机器学习模型，该模型可以成功地检测俄罗斯巨魔**

随着利用网上虚假信息操纵公众舆论的现象继续增加，重要的是要识别、描述并最终遏制这些行为背后的恶意行为者所带来的影响。为了支持对恶意行为者的检测和定性，兰德公司研究团队开发了一个机器学习模型，旨在识别真实的政治支持者和参与2016年美国总统选举相关在线辩论的俄罗斯“巨魔”之间的差异。这项研究要考察瞄准这场公开辩论的俄罗斯“巨魔”如何将同样的手段应用于世界范围内其他可能被俄罗斯瞄准的左翼和右翼政治争论，包括英国退出欧盟。

为了开发这个模型，兰德公司研究团队使用了2016年美国总统选举期间活跃在推特上的俄罗斯左翼和右翼“巨魔”账户的公开数据集，利用了2015-2017年的推特数据。该数据集包含来自互联网研究机构（IRA）所运作的2848条处理程序的2973371条推文。然后，研究团队使用了文本挖掘来提取网络巨魔瞄准的公众搜索术语，而后从190万用户账户中获取推文。除此之外，研究团队在推特数据上使用了一个网络分析算法，该算法使用交互频率来推断社区。

最后，研究团队如期确定了两个大型元社区，文本分析显示其中一个代表唐纳德•特朗普的支持者，另一个代表希拉里•克林顿的支持者。这些大型公共机构由较小的子公共机构组成，这些子公共机构是联合的，但又是不同的。研究分析确定了775个伪装成希拉里和特朗普的自由派和保守派支持者的不真实的俄罗斯巨魔账户，以及190万个真实的自由派和保守派支持者。

利用这些数据，研究团队训练了一个机器学习模型，该模型能够成功地区分四个账户类别：俄罗斯左翼巨魔、俄罗斯右翼巨魔、真正的自由派支持者和真正的保守派支持者。

**（五）报告对试验性建模工作的准确度进行分析认为：精确度非常高，可用于理解巨魔用来制造网上异议的间谍情报技巧**

报告认为，研究团队的建模工作具有很高的准确性（平均71%），使用高度可解释的算法，使研究人员能够理解巨魔传播错误信息和加深在线社区之间分歧的方法。这个模型在从真正的支持者中辨别出巨魔的有效性高达87%。

研究分析表明，俄罗斯巨魔模仿了美国自由派和保守派话语中最具分裂性和对抗性的元素：一种“极左”的自由派话语将美国构建为一个从根本上具有压迫性的国家，另一种“极右”的保守主义话语将美国描述为受到外部力量的攻击。研究团队对俄罗斯巨魔使用的特定修辞策略的分析打开了实时识别巨魔的大门，同时也强调了这些操纵策略的目标。

**（六）报告提供了该项研究得到的四个关键发现：这些发现可以为关注国外恶意信息活动的英国政府机构所采纳**

报告基于该项研究分析，为英国政府在这一领域提供了四个关键发现结论：（1）公众理论和网络分析可以帮助描绘出俄罗斯（和其他国家）试图以恶意方式进行影响的修辞战场。为了进行对抗，政府机构应该考虑采用基于公众的分析来识别元社区。（2）俄罗斯巨魔通过使用重复的修辞模式反复强调双方的情感问题来挑起争议双方的不和。为了提高认识和建立对这些策略的应对能力，政府机构应该让目标受众看到这一点。（3）为了开发探测能力，使用功能较弱但可解释的浅层模型是一个重要的初步步骤。可解释能力可以对间谍情报技术进行观察，并且可以为后续设计更强大的深度算法提供信息支撑。（4）姿态特征可以检测各种话题的修辞模式，并且可以极大地增强机器学习分类。这项工作可以由关注打击外国恶意信息活动的英国政府行动机构来执行。

**（七）报告分析了该项研究的未来发展方向，指出本研究中试验的各项技术可以提供更广泛的应用**

报告指出，这项工作的未来进一步发展是建立在当前的发现基础之上，未来需要扩展建模能力以利用其他先进的深度学习和人工智能方法。此外，还需要利用社会语言学和衍生特征作为合作伙伴模型的输入，并且将研究结果扩展和推广到其他数据集和平台。除了检测恶意信息这一具体问题之外，本研究中试验的各项技术还有更广泛的应用：这项研究模型中的社区检测、文本分析、机器学习和可视化组件都可以重新配置，从而创建一个强大的通用社交媒体监控工具；与来自商业领域的监控工具不同，该研究可以提供一个系统来解释像公众这样的聚集性结构的逻辑以及社交媒体谈话的社会文化目的。而当前现有的解决方案对于解决这些问题还有一定的距离，兰德公司的这项研究将对英国防部科学技术试验室用户有所帮助。

**（八）报告最后探讨了测试模型的可移植性问题，表明了下一步工作是在一个新的环境中测试这个模型，比如英国退出欧盟的网上争论**

报告指出，该项研究工作的下一个阶段，是在一个新的环境中测试这个社交媒体上恶意巨魔账户的检测模型，以探索该模型的可移植性，可能会选择关于英国退出欧盟的网上争论。作为这项工作的第一步，研究团队收集了2019年1月1日至2019年3月31日的推特数据，对该数据集进行了初步的网络分析，并确定了三个在线社区：“脱欧派”、“留欧派”和一个参与支持留欧派讨论的国际（即非英语）社区。在这一探索性研究的基础上，下一阶段的目标是通过将这项研究的模型应用于英国退出欧盟的在线研究这个事例来证明这个模型的稳健性和实用性。

**二、**

  

**启示认识**

  

**（一）早期发现恶意和颠覆性信息是一项具有紧迫性的工作**

从兰德公司的近期相关研究我们可以看出，当前美国及其盟友迫切需要更好地预警那些恶意信息（意在伤害）或颠覆性信息（意在破坏）的活动，他们已经充分认识到这些活动对本国的政治及军事等各方面可能产生的严重影响后果，比如会激化社会矛盾、为恐怖分子提供招募、培训和与其追随者、同情者和其他受众沟通的工具、破坏公平和民主进程等等。

对于我国而言，当前国际形势错综复杂，比如，中美贸易纠纷、香港问题、新冠疫情防疫等话题在国内社交媒体上持续升温，不断发酵，其中同样不乏有各种背后敌对势力的恶意操纵。从管理上看，一些国家已经建立了新的政府机构或授权现有组织打击虚假新闻和外国影响行动，根据2018年北约战略司令部关于政府应对恶意使用社交媒体的报告，自2016年以来，已有43个政府提议或实施了社交媒体操纵领域的法律或监管干预。这些措施有针对社交媒体平台的、针对罪犯的、针对政府能力的、针对公民、民间社会和媒体组织等的各种措施。在欧洲，欧盟委员会已采取监管措施，促使脸书、推特、YouTube和微软签署行为准则等等。美国及其盟国相关规划管理者的觉醒，同时提醒我们，网络恶意和颠覆性信息的早期检测与发现也是摆在我们面前亟待解决的一项非常紧迫的任务。

**（二）必须不断摸索检测的重要新方法和手段**

美国及其盟友认为他们在预警网络恶意信息行动方面还存在不小的能力差距，当前的研究方法是在这些活动结束后对其进行检测和分析，这样虽然可以提供有价值的事后分析研判，但是这种迟到的分析结果使决策者无法快速、主动地解决这些问题。为此，美国及其盟友正在研究检测整个活动的一些新方法和手段。

为了满足检测恶意信息的需求，美国等西方国家正在不断摸索检测的重要方法和手段。比如，采用现有的社交媒体分析方法，将网络分析和文本分析相结合，对社交媒体上互动的社区进行映射、可视化和理解。兰德公司建议美国考虑采用这种或类似的社交媒体分析方法，通过检测社交媒体上的行为，可以切实为美国规划管理者提供早期预警。另外，机器学习方法，如基于主题建模的方法，正被用来检测叙事主题和错误信息。其他研究集中在传播方法和策略上。

但是，这些新的方法和手段都要基于一个重要原则就是，需要将恶意信息检测作为整体而非部分开展研究工作。目前所做的研究都是在单个项目上进行的，由此来牵出更大更为整体的部分，而此次研究成果可以将检测的重点聚焦到集合的层次来完成相关工作。也就是说，这些研究方法不关注个人账户，而是关注频繁互动的大群账户（社交媒体社区），不关注个人推文，而是关注按社区分组的大量推文。通过使用网络和文本分析，分析师能够在非人类尺度上可视化和理解社交媒体讨论（以及影响这些争论的恶意行为）。

**（三）重点关注概念验证领域的主要研究方法和技术**

鉴于发现恶意和颠覆性信息工作的紧迫性，以及概念验证这一研究的前景，建议相关部门应考虑深入研究这一方法在实施过程中必要的技术和专业知识。恶意或颠覆性的行动是一种对于时间十分敏感的竞争形式。如果发现得太晚，可能会呈现一种既成事实。建议应对以下研究方法和技术进行重点关注。

（1）整体性分析方法

当前的研究侧重于检测单个对象，而不是总体水平上的整体检测。兰德公司在2020年3月16日官网上发布题为《通过社交媒体检测恶意或颠覆性信息----可扩展的预警分析》的报告中提到并解释了如何将恶意行为作为整体来检测，这可能比试图在个人网络账户或信息层面识别行为更敏感、更有效。兰德公司建议任何美国政府主导的开发信息工作、检测方法和技术的研究都要聚焦解决这一研究差距。

（2）人在回路的分析方法

在可预见的未来，一种纯粹基于机器的方法不太可能像人类一样精确地处理语言数据，从而有力地检测恶意信息。兰德公司相关报告中讲到的一种人在回路的方法，该方法同时结合了计算机的优势（工作迅速、可靠并可扩展到大量数据）和人类的优势（对数据进行有意义的解释并结合上下文），最大限度地提高了当前技术的回报。然而，这种方法需要数据摄取方面的专业知识，并且整个过程是由专家驱动的。兰德公司建议美国政府投资发展专业知识，适当支持恶意信息的早期检测工作。这种专业知识将包括数据科学、社交网络分析、文本分析以及针对特定目标受众的文化/语言专业知识。

**（四）恰当应用社区词汇检测分析（CLA）的测试方法**

为了证明研究方法可行，兰德公司的研究人员对这种在社交媒体上检测恶意或颠覆性活动的新方法进行了测试，测试过程中采用了一种现有的社交媒体分析方法，称为社区词汇检测分析（CLA）。这种方法将网络分析和文本分析结合起来，通过可视化的方式来呈现和理解社交社区和社交媒体之间的关系。CLA大规模工作，分析人员可以在数据集中寻找与信息工作相关的模式，这些模式对于人类的定性分析来说太大了。

CLA是一种数据简化技术，将一个巨大的数据集划分成更小/更密集的数据集，在这些数据集中可能检测到微弱的信号。例如，想象一下，试图发现准备在大型公共活动中传播虚假信息的人——同时监控成千上万的声音是不可能的。但是，如果你能找出最有影响力的人的主要谈话，并一次分析一段谈话，那么在茫茫人海中可能丢失的微弱信号就可能被探测到。
