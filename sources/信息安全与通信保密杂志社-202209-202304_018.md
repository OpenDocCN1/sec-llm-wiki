# 公安部：构筑网络安全等级保护、网络入侵防御等信息安全标准防火墙

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247574480&idx=2&sn=d47264d5aa5fb79b13242ea817ec328d&chksm=c0b579a6f7c2f0b05b9c0b4476e075c7224dca2a1a583930998fb341e2b39fb90f50d0d0acb6&scene=126&sessionid=1681312056#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247574480&idx=2&sn=d47264d5aa5fb79b13242ea817ec328d&chksm=c0b579a6f7c2f0b05b9c0b4476e075c7224dca2a1a583930998fb341e2b39fb90f50d0d0acb6&scene=126&sessionid=1681312056#rd)

4月3日，公安部召开新闻发布会，发布百项公共安全行业标准。公安部科技信息化局局长厉剑在发布会上介绍称，公安标准是平安中国、法治中国制度建设的重要内容，目前已建立标准化技术委员会9个，委员近1400人，发布的现行有效标准2599项，涉及公安业务领域的方方面面。其中，为打击网络犯罪、保护公民个人信息，确保清朗有序的网络空间环境，构筑了网络安全等级保护、网上身份认证、网络入侵防御等信息安全标准防火墙。厉剑表示，针对严打暴恐分裂活动实际需求，组织制定了石油石化、电力、城市供水、城镇燃气、水利、核设施、国家战略储备库等重点目标的防范恐怖袭击系列标准；为打击网络犯罪、保护公民个人信息，确保清朗有序的网络空间环境，构筑了网络安全等级保护、网上身份认证、网络入侵防御等信息安全标准防火墙；为开展扫黑除恶专项斗争、打击拐卖妇女儿童犯罪、严重暴力犯罪提供了现场勘查、法医检验、DNA鉴定、涉爆涉火检验等方面的标准支撑；为打击非法集资犯罪、电信诈骗、证券期货违法犯罪提供了发现线索和固定证据的有力技术支撑；为打击毒品犯罪，支撑清源断流、肃毒净边行动，研制了毒品检验、溯源、成瘾性评估系列标准；围绕道路安全与畅通、执法与教育、技术与管理推出了道路交通秩序管理、交通事故预防处理、车辆驾驶人管理等标准，为服务和改善民生发挥了积极的促进作用。来源：央广网![](../Images/69950fea4d489f329082e9ce23d2a19f.png)
