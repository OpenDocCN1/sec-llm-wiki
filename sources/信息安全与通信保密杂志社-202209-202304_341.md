# 披露要案细节：国家安全就是安邦基石

近日，中宣部联合中央党史和文献研究院、国家广播电视总局、中央军委政治工作部等单位共同摄制的十六集大型电视专题片《领航》在央视隆重推出。其中，第十二集《安邦基石》从多角度阐释了“大安全”理念，披露了三起涉及国家安全类案件的始末细节。

**中国首例**

**为境外刺探、非法提供高铁通信****数据案**

2022年4月，国家安全机关破获了一起为境外刺探、非法提供高铁数据的重要案件。上海某信息科技公司销售总监王某等人在利益驱动下，非法收集、向境外公司提供涉及高铁敏感数据。![](../Images/911b544e818da740cae45fa119937edf.png)经鉴定，为境外公司搜集、提供的数据涉及铁路GSM-R敏感信号。GSM-R是高铁移动通信专网，直接用于高铁列车运行控制和行车调度指挥，是高铁的“千里眼、顺风耳”，承载着高铁运行管理等各种指令。![](../Images/0ddda4fb4479d3e4ab70a4548db75622.png)不法分子如果非法利用这些数据故意干扰或恶意攻击，严重时将会造成高铁通信中断，影响高铁运行秩序，对铁路运营构成重大威胁。同时，大量获取分析相关数据，也存在高铁内部信息被非法泄露甚至被非法利用的可能。这起案件是《中华人民共和国数据安全法》实施以来，首例涉案数据被鉴定为情报的案件，也是我国首例涉及高铁运行安全的危害国家安全类案件。

**携密出逃**

**军工专家被判处有期徒刑十五年**

片中披露了间谍张建革被我国家安全机关工作人员抓捕时的细节。![](../Images/7c510171fef55c28bedbe0a4addc104a.png)张建革是我国尖端科技领域的核心专家，掌握着重要武器装备研发项目的进展情况及关键数据。在一次国外学术交流报告会上，他被一位名叫Jack的外籍男子盯上，并被其用金钱诱惑策反，走上了卖密牟利、背离国家的不归之路。2014年4月，张建革携带大量秘密情报准备出国之际，被侦查人员在机场抓获。侦查人员在他携带的行李中，发现了准备带离出境的涉密科研材料。![](../Images/f391878b5b16a2d405c9064d92f30eb4.png)据国家安全机关人员介绍，“我们国家很多还没有投入现役，没有装备的武器装备，被张建革泄露出去，（他）把我们研制尖端武器的情况，研究的方向，研究的现状，毫无保留地透露给间谍情报机关。”张建革出卖的情报中，有机密级9项，秘密级6项，其因犯间谍罪被判处有期徒刑十五年。

**非法测绘**

**沿海渔民捞起间谍窃密潜航装置**

2021年春天，江苏盐城渔民王锁，在出海打渔时，打捞出一件奇怪的黑色不明装置。装置上部有太阳能板，后面带螺旋桨，整体呈现船的形状，两侧还有翅膀形状的部件。王锁感到这个东西不简单，立即报告了当地国家安全部门。![](../Images/26d445ad0fa3f050142fb3bfd3d253d4.png)经专家鉴定，这款被渔民捞起的装置实际上是一个波浪滑翔机，是一种应用在海洋上的无人潜航器，搭载了多种传感器和GPS定位等装置，可以实时接收、传递信息给投放者。该装置配有三块太阳能电池进行供电，可以支撑长时间的信息采集工作。而且经专家分析，这并不是我国制造的装置，几乎可以确定是境外国家为窥探我国海域而投放的，目的是为了对我海域的温度、湿度、海底地形等敏感数据进行采集，属于严重的窃密行为，这些数据的泄露，对我国国土安全、海洋安全等产生了很大威胁。![](../Images/dc12996c4ca2cca110b993e51b66d028.png)近年来，境外对我国沿海地区实施非法测绘的间谍活动屡见不鲜，这已经不是我国渔民第一次捕捞到这种探秘装置了。近些年，浙江、海南等多地渔民都曾经捕捞到来自国外的监测装置，其型号、种类、功能多到令人咂舌。
