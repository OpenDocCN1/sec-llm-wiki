# 基于强化学习的自动化红队测试计划构建与验证

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMTMyMDQ3Mw==&mid=2247556940&idx=3&sn=b80251775e171ee69cb23d8ec2201871&chksm=c0b4c53af7c34c2cc754c830f442dc212ff6d3903ed40f399498300a100e4f1171cafa5bc0ca&scene=126&sessionid=1681312092#rd](http://mp.weixin.qq.com/s?__biz=MzkwMTMyMDQ3Mw==&mid=2247556940&idx=3&sn=b80251775e171ee69cb23d8ec2201871&chksm=c0b4c53af7c34c2cc754c830f442dc212ff6d3903ed40f399498300a100e4f1171cafa5bc0ca&scene=126&sessionid=1681312092#rd)

**摘要：**

自动化红队测试是当前研究的热点问题，旨在更加高效、低成本和可重复地进行网络安全评估。自动攻击计划生成是自动化红队测试的重要部分，目的是替代安全专家进行攻击计划过程。将强化学习与红队测试问题相结合，将红队测试过程建模为马尔可夫决策模型，利用基于策略(Policy Gradient)和基于价值(Q-Learning、SARSA和Deep Q Network)的强化学习算法，在仿真环境中训练代理完成攻击计划的构建；在实验环境中验证攻击计划的可行性和适应性。仿真和实验结果表明，PG算法只学习到非最优攻击计划，收敛速度慢；Q-Learning、SARSA和DQN算法能学习到最优攻击计划，Q-Learning算法收敛速度最快，SARSA算法次之，DQN算法最慢；利用强化学习算法构建的攻击计划具有较好的可行性和适应性。

渗透测试是在不影响目标系统网络的前提下，利用系统漏洞获得系统控制权的安全测试方法。与通常侧重于漏洞利用的渗透测试不同，红队测试通过模拟黑客真实的攻击行为(包括黑客的技术、程序、工具和目标)来评估网络系统的整个状态。然而，红队测试成本较高，耗时较长，还有专业知识和方案设计等方面的困难。例如，测试人员的知识水平将决定他们能够对网络执行何种攻击和技术；设计红队演习同样具有挑战性，包括应该测试哪些主机，允许使用什么技术和战术，红队的目标是什么，红队应该如何报告等。花费在建立方案设计上的精力增加了执行红队评估的复杂性。

自动化红队测试为解决上述问题提供了方向。人工智能技术的发展为自动化红队测试提供了新的思路，随着DeepMind AlphaGo在围棋领域超越了人类专家，使强化学习与红队测试的结合成为可能，两者都是根据环境状态进行动态决策的过程，本质上是一个计划问题。

自动攻击计划是自动化红队测试的重要部分，Bozic等人确定了自动化计划在安全方面的应用：攻击通常被描述为最终实现目标的一系列步骤，在很多方面与计划相似。Amos-Binks等人使用自动计划来识别攻击路径以及漏洞评估。近年来，强化学习与自动计划问题的结合成为研究热点。Applebaum等人将红队问题形式化为马尔可夫决策过程，提出了基于启发式算法的计划器来解决自动化攻击计划决策问题，然而该算法通用性不强，没有完善的理论支持。Zhou等人提出了一种基于网络信息增益的攻击路径规划算法，该算法将渗透测试形式化为马尔可夫决策过程，利用网络信息获取奖励，引导代理选择最佳响应动作，然而动作空间侧重于信息收集和漏洞利用，无法满足红队测试评估整个网络系统状态的需要。文献\[8\]和文献\[9\]提出更全面的部分可观测马尔可夫决策模型，但是该模型计算求解复杂度较高，只适合小规模网络环境。李腾等人提出了基于Q-learning的最优攻击路径生成方法，但是没有讨论对比其他强化学习算法。Maeda等人提出了一种结合深度强化学习和PowerShell Empire来实现后渗透阶段自动化的方法，缺少了重要的自动化漏洞评估阶段。

当前，针对自动化红队测试攻击计划问题的研究仍处于初步阶段。本文的主要工作是以窃取目标主机敏感数据作为攻击目标的红队场景为讨论范围，将其建模为马尔可夫决策过程；利用基于策略和基于价值的强化学习算法，在仿真环境中训练攻击代理完成攻击计划的构建过程，讨论不同算法的性能差异；在实验环境中验证攻击代理构建的红队攻击计划的可行性和适应性。

**攻击者建模**

在本文模拟中，攻击者(即攻击代理)主要由知识、能力、策略3个部分组成。其中，知识是指攻击者对于给定红队环境状态的了解；能力是指攻击者执行的攻击动作；策略是指攻击者如何选择能力去执行。根据Sharma等人的研究，62%的网络攻击是在攻击者达到目标后被检测到的。这意味着，攻击者和防御者很少实时竞争。因此，本文在没有明确设置防御代理的环境中训练攻击代理。

**2.1　攻击者的知识**

攻击者的知识，定义为攻击者对于给定红队环境状态的了解，与攻击代理在红队测试中所处的状态相对应，可以用谓词来进行描述：

*initialzed(X)*表示攻击者对主机*X*进行信息收集等初始化操作；*exploited(X,E)*表示攻击者尝试利用漏洞E对主机*X*进行漏洞利用；*socialEngineered(X)*表示攻击者尝试利用社会工程学攻击(如鱼叉式网络钓鱼)对主机*X*进行初始访问攻击；*hasFoothold(X)*表示攻击者在主机*X*上拥有的立足点(user用户权限)；*escalated(X)*表示攻击者在主机*X*上拥有提升的立足点(root用户权限)；*hostEnumerated(X)*表示攻击者在主机*X*上执行所有本地文件发现；

*exfiltrated(X)*表示攻击者从主机*X*上成功窃取文件。

**2.2　攻击者的能力**

攻击者的能力(即攻击者使用的攻击动作)模拟了网络攻击生命周期中的各个阶段，每个能力都是根据MITRE ATT&CK模型中的战术和技术进行设计的。每个能力都具有一组前置条件和后置条件，这些前置条件在攻击者能力执行前必须为真，而后置条件将在攻击者能力执行后为真。如下列出每个能力与其在ATT&CK中相对应的战术：

*scan(X)*表示对主机*X*进行端口扫描、目录扫描和漏洞扫描等。此能力与ATT&CK中的Reconnaissance战术对应，这里设定前置条件为在收集信息阶段进行扫描，后期不需要重复扫描，后置条件是获得扫描结果。

*runExploit(X,E)*表示利用漏洞*E*对主机*X*进行漏洞利用。此能力与ATT&CK中的Initial Access战术对应，前置条件是主机*X*容易受到漏洞*E*攻击，后置条件是攻击者将在主机*X*上立足。

*socialEngineering(X)*表示对主机*X*的用户进行社会工程学攻击。此能力与ATT&CK中的Initial Access战术对应，前置条件是主机*X*的用户容易受到引诱，后置条件是攻击者将在主机*X*上立足。

*escalate(X)*表示提升主机*X*上的立足点权限。此能力与ATT&CK中的Privilege Escalation战术对应，前置条件是攻击者必须在主机*X*上拥有低特权立足点，后置条件是攻击者将在主机*X*上拥有可提升的立足点。

*enumerateHost(X)*表示攻击者在主机X上收集信息。此功能与ATT&CK中的Discovery和Collection战术对应，前置条件是攻击者必须在主机*X*上拥有升级的立足点，后置条件是攻击者将获得主机*X*上的有效网络流，并有资格从主机*X*上窃取文件。

*exfiltrate(X)*表示从主机*X*上窃取敏感数据。此能力与ATT&CK中的Exfiltration战术对应，前置条件是攻击者在主机X上拥有立足点，后置条件是主机*X*上的敏感数据将被窃取。

**2.3　基于计划的攻击者策略**

基于计划的策略表示攻击者如何在给定的场景下选择攻击动作，将攻击动作链接在一起并执行，以实现攻击目标。攻击代理在给定的输入条件下(条件包括第2.1节的攻击者知识、第2.2节的攻击者能力以及攻击目标)，基于强化学习算法构建攻击计划，选择最优攻击计划作为输出，然后与红队场景进行交互以达到攻击目标，攻击计划构建模型如图3所示。基于计划的攻击者策略如下文所述。

(1)代理评估当前在红队环境中的状态、攻击动作集合和攻击目标；(2)代理基于强化学习算法构建攻击计划；(3)代理选择当前最优的攻击计划并执行其攻击动作；(4)如果达成攻击目标，则整个策略结束；

(5)否则，移除该最优攻击计划，重新回到步骤(3)。

**图3　攻击计划构建模型**强化学习算法是构建攻击计划的重要部分。本文讨论了两种类型：一种是基于策略的强化学习算法，如策略梯度(Policy Gradient，PG)算法；另一种是基于价值的强化学习算法，如Q-Learning算法、SARSA(State-Action-Reward-State-Action)算法和深度Q网络(Deep Q-Network，DQN)算法。下面对各算法进行简要介绍。

PG算法是一种基于策略、模型无关以及在线策略的强化学习算法。策略![](../Images/a30b559b40071c634763840ea3a60c0b.png)被述为包含参数9的策略函数![](../Images/9a8849c96d3fd1161265e935acd0443f.png)。PG算法通过端到端的方式不断计算当前策略下的代理累

积收益与策略参数的梯度，最终梯度收敛到最优策略。在进行参数优化时，高回报动作路径的概率会逐步增大，低回报动作路径的概率则会逐渐减小。然而PG算法仅仅跟随最快上升方向方式收敛到局部最优解，而不是全局最优解，并且PG算法对测量噪声敏感，可能导致收敛速度较慢。

Q-Learning算法是一种基于价值、模型无关以及离线策略的强化学习算法。Q-Learning算法采用![](../Images/8977fdad5b5456fd22be6a2d284b1e81.png)表格的方式来存储![](../Images/8977fdad5b5456fd22be6a2d284b1e81.png)值。在迭代过程中，代理首先根据![](../Images/c23021a947166b13076015bf834532d3.png)贪心策略在状态![](../Images/77a417cfd5b2d8a120ef0ddaee5955f2.png)选择动作![](../Images/3d46c15aa19cd94eb4f3e8658c97bc44.png)，执行动作![](../Images/3d46c15aa19cd94eb4f3e8658c97bc44.png)后转移到状态![](../Images/8006ae690e3721c8c688f37bd70f7dd3.png)，同时代理获得即时奖励![](../Images/02cedb1ef6aa0ffea46f49f2ce0b1830.png)，在新状态![](../Images/8006ae690e3721c8c688f37bd70f7dd3.png)，代理根据![](../Images/c23021a947166b13076015bf834532d3.png)贪心策略直接选择表格中![](../Images/8977fdad5b5456fd22be6a2d284b1e81.png)值最大的动作![](../Images/98f90ee2d5ba140765627b8243cf078c.png)，但不执行，只是用于更新价值函数![](../Images/c71e4fe6d882890af8f2a3719c4f0214.png)，见式(3)。Q\-Learning算法依据修改后的![](../Images/8977fdad5b5456fd22be6a2d284b1e81.png)值来确定动作并执行。Q-Learning算法利用![](../Images/8977fdad5b5456fd22be6a2d284b1e81.png)值最大的动作来更新价值函数，其算法效率较高，但是容易得到局部最优解。

![](../Images/c5234955121c2a1ee7e37ae8c25cb318.png)

式中：![](../Images/5259ed412b52272de43108e8c56f0ef2.png)为学习率；![](../Images/01b2fd78d51efac6f851b9e93559c972.png)为折扣因子。

SARSA算法是一种基于价值、模型无关以及在线策略的强化学习算法，是改进的Q-Learning算法。SARSA算法与Q-Learning算法的不同之处在于，在新状态![](../Images/8006ae690e3721c8c688f37bd70f7dd3.png)，代理根据![](../Images/c23021a947166b13076015bf834532d3.png)贪心策略选择动作![](../Images/98f90ee2d5ba140765627b8243cf078c.png)并执行，再利用![](../Images/e2926e6cc14dcaf5cfcc32ddf7fbb280.png)值来更新价值函数![](../Images/630ff85a58cce8446aadb4779cae00d2.png)，见式 (4)。SARSA算法在每个学习步数中，代理依据当前![](../Images/8977fdad5b5456fd22be6a2d284b1e81.png)值确定下一个状态的动作并执行，与Q-Learning算法相比，SARSA算法更加“保守”，从而不易遇到局部最优解，但需要更多训练回合才能收敛。

![](../Images/c65130e20cb97f6fdb2384b50ffaecdf.png)

DQN算法是一种基于价值、模型无关以及离线策略的强化学习算法。该算法使用两个完全相同的神经网络生成目标![](../Images/8977fdad5b5456fd22be6a2d284b1e81.png)值和估计![](../Images/8977fdad5b5456fd22be6a2d284b1e81.png)值，利用经验回放机制打破数据之间的相关性，从而提升算法稳定性。DQN算法能够解决状态空间和动作空间维度较大的问题，是Q-Learning算法的扩展。

**3.4　实验结果及分析**

由图5至图8以及表3至表6分析可知：

(1)除PG外，其余代理均能稳定收敛到最优攻击计划(![](../Images/26aa59b0ed11eccd712b7d7537398e73.png)或![](../Images/1a751a1a36bb6a33c29252ddd1a54cbf.png))，这是由于策略梯度算法本身的缺陷，即PG仅仅跟随最快上升方向方式收敛到局部最优解，而不是全局最优解，导致PG代理仅仅学习到局部解，即![](../Images/4c91473d7dce8ea865cde5e25049d180.png)或![](../Images/b1fe051b2d6966f1a082e37809edffd8.png)。

(2)Q-Learning、SARSA和DQN代理能够学习到所有攻击计划，且学习趋势都是先学习到![](../Images/4c91473d7dce8ea865cde5e25049d180.png)或![](../Images/b1fe051b2d6966f1a082e37809edffd8.png)，然后![](../Images/9f2da95456b1534d26aab6f431277907.png)或![](../Images/4a0502eb776fd835a057baac89f5cf05.png)，最后稳定收敛到![](../Images/1a751a1a36bb6a33c29252ddd1a54cbf.png)或![](../Images/26aa59b0ed11eccd712b7d7537398e73.png)。

(3)表4中“收敛回合”指代理开始呈现收敛趋势时的回合，PG代理收敛所用的回合最多，Q-Learning代理则最少，这是由于PG对测量噪声敏感，可能导致收敛速度较慢，而Q\-Learning直接利用![](../Images/49b3f18116aa31f833cfcc561e3cd3b6.png)值最大的动作来更新价值函数，算法效率相比其他算法更高效。

(4)表4中“最优收敛回合”指代理稳定收敛到最优解时的回合，Q-Learning代理收敛到最优解所用的回合最少，SARSA代理次之，DQN代理最多，这是由于Q-Learning利用![](../Images/49b3f18116aa31f833cfcc561e3cd3b6.png)值最大的动作来更新价值函数，算法效率较高，但是容易得到局部最优解。而SARSA在更新价值函数的过程中做了改进，相比Q-Learning更加“保守”，从而不易遇到局部最优解，这也是图7相比于图6中有相对更少的偏离收敛曲线回合数的原因，但这也导致SARSA需要更多的训练回合才能收敛。而DQN采用神经网络来生成和存储![](../Images/49b3f18116aa31f833cfcc561e3cd3b6.png)值，相比于采用![](../Images/49b3f18116aa31f833cfcc561e3cd3b6.png)表格来存储![](../Images/49b3f18116aa31f833cfcc561e3cd3b6.png)值的Q-Learning和SARSA，需要消耗更多的计算资源，因此，Q-Learning算法优于另外3种强化学习算法。

(5)由强化学习算法构建的攻击计划在自动化测试实验中得到了验证，并且达到了实验预期。

**结语**

在自动化攻击性评估中，无论是自动化渗透测试，还是自动化红队测试，其核心都是自动化计划问题。本文着重研究自动化红队过程，将其建模为马尔可夫决策过程，基于不同类型的强化学习算法，在仿真环境中训练攻击代理构建攻击计划，然后在实验环境中验证了攻击 计划的可行性和适应性。仿真和实验结果表明， Q\-Learning 算法优于本文讨论的其他算法。

受限于强化学习与环境的强交互性，当前 应用强化学习的自动化红队测试仍处于模拟验 证阶段， 应用虚拟化技术在仿真网络甚至真实网 络中训练代理是未来的发展方向，同时，文中 所讨论的红队测试过程较为简单，为了能适应 更加复杂的场景，在未来还需要纳入 ATT&CK 模型中更多的战术和技术以及更加合理地设置 奖励函数。
