0x10 windows 系统安全

0x11 更新补丁

  • 目的：使用最新版的系统补丁，防止攻击者利用已知的漏洞攻击系统。

  • 系统开启在线自动更新

控制面板——系统和安全——Windows Update——启用自动更新

  • 系统离线安装更新补丁

  • 建议优先考虑在线自动更新补丁，谨防供应链攻击。

cmd：systeminfo #下图 只有2个补丁


0x20 windows 用户安全

0x21 检查无密码账户

  • 目的：防止攻击者利用无密码账户登录系统

开机/锁定/注销/重启——检查账户是否需要密码登录操作系统，无则创建密码开始——控制面板——用户帐户——创建密码（已存在密码，则显示更改密码）

  • 检查是否勾选了“要使用本机，用户必须输入用户名和密码”

方式1：运行（Win+R）——control userpasswords2——勾选方式2：运行（Win+R）——rundll32 netplwiz.dll,UsersRunDll——勾选


0x22 密码安全策略

  • 目的：设置有效的密码策略，防止攻击者容易暴力破解出密码。

方式1：开始——控制面板——管理工具——本地安全策略（secpol.msc）——账户策略——密码策略方式2：运行（Win+R）——secpol.msc——账户策略——密码策略要求：- 启用密码复杂性要求- 密码长度最小值 ≥8- 密码最短期限 ≥1- 密码最长期限 ≤90- 强制密码历史 ≤5

  • 密码要定期更换

方式1：开始——控制面板——管理工具——计算机管理——本地用户和组——用户——右击用户属性——不勾选“密码永不过期”方式2：运行（Win+R）——control userpasswords——用户——右击用户属性——不勾选“密码永不过期”


0x23 默认账户策略

  • 目的：避免攻击者针对默认账户的攻击。

  • 重命名默认账户

开始——管理工具——本地安全策略（secpol.msc）——本地策略——安全选项——策略——账户：重命名系统管理员账户（要刷新策略或重启）cmd：gpupdate /force

开始——管理工具——计算机管理——系统工具——本地用户和组——用户运行（Win+R）——compmgmt.msc——系统工具——本地用户和组——用户

  • 检查账户唯一性，禁止同一账户密码多服务公用（可咨询管理员）


0x24 多余账户策略

  • 目的：删除或禁用临时、过期及可疑的帐号，防止被非法利用。

开始——管理工具——计算机管理——系统工具——本地用户和组——用户（咨询管理员）cmd：- net user- net user <user>- net user <user> /del #删除用户- net user <user> /active:no #停用用户


0x25 账户锁定策略

  • 目的：遭遇密码暴力破解攻击时，暂时锁定帐号，降低密码被猜解的可能性

方式1：开始——控制面板——管理工具——本地安全策略——账户策略——账户锁定策略方式2：运行（Win+R）——secpol.msc——账户策略——账户锁定策略要求：- 账户锁定时间≥15- 账户锁定阀值≤15- 重置账户锁定计数器≥5


0x26 远程服务安全策略

  • 目的：防止远程管理过程中，密码等敏感信息被窃听

  • 禁用非必要的服务（如：telnet）

开始——控制面板——打开或关闭windows功能——功能——删除功能——不勾选（telnet功能）

  • 启用RDP安全层

运行（Win+R）——gpedit.msc——计算机配置——管理模板——windows组件——远程桌面服务——远程桌面会话主机——安全——远程（RDP）连接要求使用指定的安全层

开始——控制面板——管理工具——远程桌面服务——远程桌面会话主机配置——右击RDP-Tcp属性——常规——安全层


  • 更改RDP默认端口

查询：reg query "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\Wds\rdpwd\Tds\tcp"reg query "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp"修改：reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\Wds\rdpwd\Tds\tcp" /f /v "PortNumber" /t REG_DWORD /d "13389"reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp" /f /v "PortNumber" /t REG_DWORD /d "13389"


0x30 windows 访问控制

0x31 用户权限控制

开始——管理工具——本地安全策略（secpol.msc）——本地策略——用户权限分配——选择策略——右击属性——删除不必要的用户和组

  • 关闭administrators调试程序（阻止mimikatz）

开始——管理工具——本地安全策略——本地策略——用户权限分配——双击调试程序删除administrators


0x32 禁止未登录前关机

  • 目的:禁止系统在未登录前关机，防止非法用户随意关闭系统。

开始——管理工具——本地安全策略——本地策略——安全选项——策略（默认已禁用）


0x33 关闭默认共享

  • 目的：如果没有关闭系统默认共享，攻击者通过 IPC$方式暴力破解帐户的密码，而后利用系统默认共享如：C$、D$等，对系统的硬盘进行访问

  • 检查是否关闭多余的默认共享及其它文件共享

开始——管理工具——共享和存储管理——右击——停止共享cmd：- net share- net share ADMIN$ /del # 删除

  • 注册表关闭默认共享

开始——运行——regeditHKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\services\LanmanServer\Parameters右击Parameters——新建——DWORD（32位）——AutoShareServer、AutoShareWks——值为0


0x34 关闭不必要端口

  • 关闭不必要的端口（135,137,138,139,445等）

netsh advfirewall set currentprofile state on > nulnetsh advfirewall set publicprofile state on > nulnetsh advfirewall set allprofile state on > nulnetsh advfirewall set privateprofile state on > nulnetsh advfirewall firewall add rule name=denyDangerTCPPort dir=in protocol=TCP localport=135,139,445 action=block #关闭 135,139,445netsh advfirewall firewall add rule name=denyDangerUDPPort dir=in protocol=UDP localport=137,138 action=block #关闭 137,138

  • 根据端口追踪进程及文件位置

cmd：- netstat -an #列出所有开放端口- netstat -ano | findstr <port> #定位相关PID- tasklist | findstr <PID> #找到相关程序- 打开任务管理器，找到对应程序，右击打开文件位置

  • 系统关键目录（C盘、软件安装目录、数据文件保存目录等），everyone只读权限或无权限

0x41 开启审核策略

  • 目的：通过系统日志、安全日志、应用日志记录系统故障、安全事故等，以便于故障排查、日志分析入侵追踪等

开始——管理工具——本地安全策略——本地策略——审核策略


0x42 修改安全日志记录属性

开始——管理工具——事件查看器——windows日志——应用、安全、系统——属性可修改日志保存位置、日志最大大小 ≥64M、日志保存 ≥6个月


0x50 windows 剩余信息保护

0x51 不显示最后登录过的用户名

  • 目的：应保证操作系统和数据库管理系统用户的鉴别信息所在的存储空间，被释放或再分配给其他用户前得到完全清除，无论这些信息是存放在硬盘上还是在内存中。

开始——管理工具——本地安全策略——本地策略——安全选项——交互式登录：不显示最后的用户名


0x52 清理内存信息

  • 目的：及时清理系统中的用户鉴别信息，防止信息外泄，被黑客利用

开始——管理工具——本地安全策略——本地策略——安全选项——关机：清除虚拟内存页面文件


0x53 禁用 WDigest

  • 目的：关闭Wdigest，使攻击者无法从内存中获取明文密码。

  • windows server 2008 要打KB2871997补丁，2012及以上默认关闭

reg add HKLM\SYSTEM\CurrentControlSet\Control\SecurityProviders\WDigest /v UseLogonCredential /t REG_DWORD /d 0 /f #添加，0关闭，1开启reg delete HKLM\SYSTEM\CurrentControlSet\Control\SecurityProviders\WDigest /f #删除


0x54 LSA保护

目的：防止不受信任的进程读取内存或代码注入以获取明文密码。

阻止mimikatz获取明文密码reg add HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\LSA /v RunAsPPL /t REG_DWORD /d 1 /f #阻止 reg add HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\LSA /v RunAsPPL /t REG_DWORD /d 0 /f #允许 需重启


0x55 关闭调试信息

  • 目的：系统启动失败时，为了分析启动失败的原因，内存信息会自动转储到硬盘中。其中数据对普通用户无用，及时清理存这些信息或禁止出错转储，防止外泄被黑客利用。

开始——计算机——右击属性——高级系统设置——高级——启动和故障恢复——设置
