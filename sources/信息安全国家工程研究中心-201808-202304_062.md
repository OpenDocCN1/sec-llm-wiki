# 加强数字信息安全建设，赋能数字经济腾飞

数字技术是信息化时代生产力的基本构成要素，是推进经济社会发展的强效引擎。加快数字化发展、建设数字中国，数字信息安全建设是关键。十四五规划《纲要》明确提出，要“构建数字规则体系，营造开放、健康、安全的数字生态”，“统筹数据开发利用、隐私保护和公共安全，加快建立数据资源产权、交易流通、跨境传输和安全保护等基础制度和标准规范”。立足于新时代，加强数字信息安全建设，既是发展高质量数字经济的必然要求，也是保障国家长治久安的重要议题。

**加强数字信息安全建设意义重大**

  

  

  

  

  

信息化技术的迅猛发展带动了新的产业革命，为中国经济的发展带来了新的历史机遇。从一条网速只有64千比特每秒的网线，到一个拥有近10亿手机网民、互联网普及率达到70.4％的互联网大国。从互联网医疗技术保障公众健康，到数字化智能产品推进区域经济协调发展。从大数据助力全面脱贫，到互联网+驱动万众创业创新。数字技术正全方位融入整个社会，极大推动我国的经济社会发展和产业结构调整。

发展数字经济，建设数字强国，数字信息安全建设是关键。**首先，数字信息安全事关知识产权保护与技术创新。**在数字化时代，保障数字知识产权、推进技术创新是极为重要的现实议题。由于数字化技术的无中心、无边界特性，数字侵权的成本较低，复制抄袭他人作品、制作贩售盗版资源、山寨他人软件等现象时有发生。如何制止和杜绝上述行为，保障正规开发商、著作人合法知识产权，进而推进数字技术创新，事关国家数字经济发展的成败利钝。**同时，数字信息安全事关国家安全。**在数字化时代，数据信息已经成为国家战略资源。大数据、云计算等技术已经广泛应用于国计民生、军事国防等众多领域，对国家安全、经济运行、社会治理等方面均产生重要影响，而保障“数字主权”安全已成为当下国际竞争的白热化议题。作为发展中的数字经济大国，我们必须提升自身对数字信息的掌控能力，从国家层面切实保障国家安全。**最后，数字信息安全事关全球治理。**世界秩序正面临前所未有的激烈重构，数字技术的超国界性使得数字信息安全成为每个国家都面临的重大安全隐患。同时，数字技术的隐匿性和去中心化为传统的政治经济格局的转变推波助澜，区块链、比特币等新型数字技术不断带来新的技术鸿沟，不断增加全球治理的难度。能否在网络空间命运共同体理念的指引下，探索出数字信息安全治理的中国方案，是中国能否在信息化时代参与并主导新一轮全球治理的关键性因素。

**我国数字信息安全建设面临的风险与挑战**

  

  

  

  

  

在新时代的背景下，数字技术的不断发展极大地推动了线上管理、移动支付、人脸识别等众多新兴领域的蓬勃发展，为数字经济发展提供了根本性动力。然而数字技术在不断发展的过程中所暴露出的数字信息安全隐患问题日益突出，主要表现在以下几个方面：

**一是数字信息基础设施存在安全隐患。**在数字经济建设的进程中，传统的信息基础设施逐步被智能互联设备所替代，信息以数字转码的形式被贮存于网络服务器之中，与大数据、云存储等关键数字信息相关的基础设施极易成为网络攻击的目标，由此所引发的大数据问题也成为当下数字基础设施治理的关键。

**二是信息传输与存储存在安全隐患。**数字经济的建设涉及海量数据的收集、存储与转化的环节，不法分子可以通过技术手段，以非法截取数字流通、破解程序访问权限、远程网络入侵等多样化方式对数字信息安全构成严重威胁。

**三是公民个人数字信息隐私存在安全隐患。**随着移动互联网的广泛应用，公民个人的图像、位置、出行、指纹、健康、银行账户等私密信息已经成为多个系统终端的重要信息源，如果加密存储能力较弱或无法利用有效的系统级别隔离，极易造成个人数据信息的泄露。例如，2018年全球数据信息泄露案件超过6500起，其中有12起涉及人数超过1亿。

**加强数字信息安全的路径选择**

  

  

  

  

  

**第一，加强数字信息安全顶层设计，制定长远发展战略。**数字信息安全是涉及技术、政策、法律等方面的系统性工程，加强信息安全建设必须要站在数字经济发展的战略全局统筹兼顾。实现以政府为核心，以企业和高校技术平台为保障，构建自上而下的全方位数字信息安全保障体系。可单独建立数字安全管理机构，明确安全等级保护标准和数字信息管理标准，对各级政府部门数字网络平台进行统一协调和部署，定期排查安全隐患。

**第二，加大研发力度，推动数字安全核心技术创新。**掌握核心数字技术是保障数字信息安全的首要前提，必须予以人力、物力、财力的广泛支持，从根本上提高数字信息安全的预警和突发事件的应急处理能力。一方面，要持续在数据密码技术研发、人工智能应用、数据安全防护系统建立等关键领域加强技术攻关，实现重点突破。另一方面，加大数字信息安全专业人才培养力度，从中小学安全宣讲活动抓起，完善高校专业学科建设，开设信息安全课程，补齐高端数字安全技术的人力短板。

**第三，加强数字信息安全制度建设，加快推进数字安全立法工作。**用制度和法律的准绳推进数字安全建设刻不容缓，一方面要建立和落实权责明晰的安全责任机制，落实政府、企业、个人权利与责任，加强网络监管；另一方面要健全数据保护的法律法规，规范数据使用行为，提高数据监管水平和治理能力，优化数字安全的网络环境，完善数字空间的管理体系，保障数字信息安全有法可依。

**第四，推动数字信息安全国际准则落地，构建人类数字共同体。**在全球范围内，推动数字安全保障管理机制，加强对数字世界全方位、多链路的深入挖掘探索，应对全球数字恐怖主义活动，协调全球数字安全技术规范。一方面，要积极推动WTO框架下的数字贸易和数字安全国际准则的确立，完善电子传输数据保护机制；另一方面，妥善解决跨境数据传输分歧，积极建立双边和多边高级别数字安全对话机制，为全球数字安全治理贡献行之有效的中国方案。
