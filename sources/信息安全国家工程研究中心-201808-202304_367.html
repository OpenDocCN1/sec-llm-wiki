美国洁净网络计划

美国洁净网络计划（Clean Network）是特朗普政府采取的一套全面方法，旨在保护美国公民的隐私和美国公司企业最敏感的信息。



今年4月，美国国务卿蓬佩奥宣布实行“干净5G路径”，要求美国外交设施网络禁用“不可信”供应商。8月2日，美国国务院公布所谓“干净5G网络计划”，并炮制出一份弃用华为的“干净国家和运营商”名单。


在8月5日的记者会上，正值川普政府迫使Tiktok将其在北美业务出售之际，美国国务卿蓬佩奥宣布了针对中国互联网公司更进一步的打击计划——“净网行动”（The Clean Network Program）。



蓬佩奥直言，美国和“小伙伴”们要采取各种措施防止中国应用和电信公司“威胁自身网络安全”。为此，美国政府正加紧努力从美国数字网络中下架“不可信”的中国应用。


美国国务院声称：这些计划基于国际公认的一套数字信任标准，并立足于2020年4月29日宣布的5G洁净路径（5G Clean Path）计划，为5G网络上传输的进入到美国海外外交机构和美国境内的数据保驾护航。


（蓬佩奥宣布“净网行动”，来源：路透社）


在声明中，蓬佩奥规定了五项“净网”准则：


1. 净化电信运营商：来自中国的电信运营商将无法接入美国电信网络。蓬佩奥认为这些公司对美国国家安全“构成威胁”。根据该原则，中国移动、联通和电信等手机SIM卡，将无法连接美国网络、即无法获得国际漫游服务。如果真的实现了，不论对于短期旅美华人，还是中国留学生来说，无法使用国内手机号都会很不方便。


2. 净化应用商店：所有来自中国的应用将被下架。声明中认为中国正在“威胁美国人的隐私、传播病毒、宣传虚假信息”。“美国人的个人和商业机密必须被保护起来，以免遭受中国的偷窃。”


3. 净化应用程序（APP）：不允许中国手机制造商提前预装或者通过其他方式得到可下载的应用程序。华为在这一条当中被点名，蓬佩奥要求APP开发商，从华为APP商店中移除他们的产品。


4. 净化网盘：不允许任何美国公民将个人最敏感的信息和企业最有价值的知识产权，包括新冠病毒疫苗研究，上传到阿里巴巴、百度和腾讯等可以访问的网盘上。


5. 净化网络电缆：保障美国与全球网络沟通的海底电缆的通信安全，使其免于“中国情报部门大规模收集数据”。同时美国将与国外合作伙伴一同保障全球的海底电缆不会“遭受类似的破坏”。


长期以来，美国政府一直在游说欧洲各国和其他盟友，一起“围剿”华为，最近以TikTok为首的中国应用也成为被针对目标。


事实上，从华为被列入实体清单开始，到威胁封杀 TikTok，美国政府近年来一直通过各种手段、措施限制中国科技公司的发展。


目前，针对美国“清洁网络”的五大措施，受影响的华为、中国移动、中国电信、百度、阿里巴巴、腾讯等中国科技公司尚未对此做出回应。



/ 外交部回应 /



中国外交部发言人汪文斌，在8月4日召开的外交部例行记者会上表示，美方以“莫须有”的罪名进行设限打压，这完全是政治操弄。美方务必不要打开潘多拉的盒子，否则将自食其果。
