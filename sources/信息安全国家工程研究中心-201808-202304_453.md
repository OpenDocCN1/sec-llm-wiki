# 重大安保时期网络安全工作要点专题

每当重大安保时期，国内外黑客组织经常会向政府、企业等单位机构发动网络攻击，单位机构往往在安全防御技术、运维管理和日常运营等多方面存在安全问题。

1.技术方面：基础能力薄弱、安全策略不当和安全措施不完善等问题普遍存在；  

2.管理方面：制度缺失，职责不明，应急响应机制不完善等问题；

3.运营方面：信息资产梳理不清晰、安全漏洞整改不彻底、安全监测分析与处置能力不足等问题随处可见。

这些不足往往会导致整体防护能力存在短板，对安全事件的监测、预警、分析和处置效率低下。针对上述情况，在重大安保时期到来之前，单位机构应当从哪些方面进行预防与改进呢？

后续工程中心将发布系列文章，讲述重大安保时期单位机构网络安全工作要点。

帮助政府、企事业单位达到**减少单位机构网络被攻击面，发现安全风险薄弱点，解决潜伏安全隐患，了解自身信息安全现状，完善安全监控能力，提高单位机构网络安全防护能力**的目的。
