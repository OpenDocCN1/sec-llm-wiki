# 信息安全共性技术国家工程研究中心 荣获2018年度“国家重大活动网络安全保卫技术支持单位”称号

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5OTQ0NzY3Ng==&mid=2247483855&idx=1&sn=35b4afc286728c1723c6d75ea91d9b90&chksm=feb580dcc9c209ca3fcd13aa1ce76ba9a85d3c62cfab3ec445bb34f168a7159e06fbf5bdf502&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU5OTQ0NzY3Ng==&mid=2247483855&idx=1&sn=35b4afc286728c1723c6d75ea91d9b90&chksm=feb580dcc9c209ca3fcd13aa1ce76ba9a85d3c62cfab3ec445bb34f168a7159e06fbf5bdf502&scene=27#wechat_redirect)

2019年1月10日，“国家网络与信息安全信息通报机制和国家重大活动网络安全保卫技术支持单位2018年度工作总结及表彰会议”在京召开，由公安部网络安全保卫局总工程师郭启全主持本次会议，公安部网络安全保卫局七处处长祝国邦，九处处长盘冠员，十处处长黄小苏等领导参加会议并发表重要讲话，来自全国各地区100多家网络安全企业及科研院所参加了本次大会。

  

![](../Images/4da30749e31eb61100e9390aed57ca7b.png)

本次会议主要对2018年度通报机制技术支持工作及国家重大活动网络安全保卫工作进行总结，并对2019年度网络安全工作及技术支持单位做了重点部署。

会议中，重点表彰了在2018年国家网络与信息安全信息通报机制和国家重大活动网络安全保卫技术支持工作中表现突出的单位，信息安全共性技术国家工程研究中心荣获“国家重大活动网络安全保卫技术支持单位”称号。
