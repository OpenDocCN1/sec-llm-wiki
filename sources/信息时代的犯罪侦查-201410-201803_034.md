# 大检察官谈打击网络犯罪与“中国式方案”（有删节）

**编者按**

**2017年11月**，以最高人民检察院副检察长张雪樵为团长的中国检察机关代表团一行出访匈牙利，与匈牙利最高检察院共同举办首届打击网络犯罪论坛。期间，两国检察机关代表就网络犯罪问题展开为期两天的深入研讨，双方签署了合作协议，商定拟于2018年春天在中国进行相关交流。论坛闭幕式上，张雪樵副检察长发表了主旨演讲。**小编读来，觉立意高远！**

  

  

![](../Images/52e06575ce8d6a5dac12da62edd7cf4f.png)

尊敬的会议主席，各位检察官，女士们、先生们：

大家下午好！

十分荣幸，会议提供给我总结发言的机会，我也知道，这意味着为期两天、匈中两国最高检察院精心准备的知识盛宴也将进入尾声了。两天来，聆听了18位检察官、警察和研究部门的专家、学者、代表精彩的演讲。他们的演讲题材丰富、视角独特、观点新颖、充满智慧，使我受益匪浅。大家对互联网社会、互联网司法这个新的现象既表达了积极的态度、热忱的期待、冷静的理性和多彩的梦想，但我们也听到了对互联网社会的怀疑、忧虑、无奈，甚至是恐惧，乃至把互联网理解为变态、病态的负面现象。

我认为这样的观点不是个别的，但也是很正常的。中国现在有7.5亿的网民，相当于中国总人口的一半，但关于互联网的分歧和争议，从一开始直到现在仍然无法消除。这不仅仅是因为个人的偏执，其实更多的是包含着利益的冲突。在此，我想用两个词（two words）来表达我的体会。

  

![](../Images/384dcfeb389d1c389e099a9897fdfec3.png)

**First word is no defense，不要拒绝**

  

中国在一千多年前发明了火药，十九世纪，聪明的匈牙利人发明了火柴。有了火柴，人们可以方便生火做饭、取暖御寒。不过火柴一半是天使，一也半是魔鬼，因为火柴往往会酿成火灾，烧毁草原、森林，甚至吞没村庄，损害生命和宝贵的财富。但今天又有谁因为火柴会带来火灾，乃至会成为犯罪的手段和工具而拒绝火柴呢？互联网也是一样，难以用一句话或者一个“面”来概括。

这两天，热情的东道主为我们推荐匈牙利的美酒Tokayi（托卡伊）。我们品尝了之后，感到它的美味绝对胜过法国波尔多地区的拉菲，但中国人只知道法国拉菲，知道智利美酒，很少有人知道匈牙利也生产世界顶尖的葡萄酒。假如匈牙利偏远的农村也像中国农村一样建成了电商销售网店，那么，我想到时候不需要远道来到匈牙利，我只要很习惯的拿出我的手机轻轻的一点，我就能成功的购得Tokaji（托卡伊），一天或者两天，最多不过三天，Tokaji（托卡伊）就会进入我的餐厅成为我的美味。同样，佩奇、赛格德等地区的卷毛猪，还有很多优质的匈牙利农产品都会随着互联网，“飞入”中国乃至世界的寻常百姓家。如果是这样的话，我们是否可以说“互联网是给人类带来福音的上帝之子”？

当然，任何事物都是有利有弊的，很难完美，就像我们这两天来讨论的网络安全和网络犯罪。中国有句老话叫：“邪不压正”，正义总是能战胜邪恶的。只要我们认真的、积极的去建设网络的安全工程，通过科学的立法、严格的执法、社会全民的守法，互联网一定会成为法治的净地，所以，我们不要拒绝互联网。

  

**Second word is no wait，不要等待**

  

大家都知道，美国有个科学家富翁叫比尔·盖茨，但大家可能不知道中国的比尔·盖茨，中国的比尔盖茨就是倡导构建了淘宝网的马云。四天前，就是11月11日，他的淘宝网创下了一天达成交易额3000亿人民币的新纪录。他有句名言：“互联网时代，一切都将被重新定义”。也就是说，互联网会让我们的生活方式、生产方式、管理方式，包括我们的司法办案方式，都会发生颠覆性的改变。

据我了解，从2018年1月1日开始，匈牙利检察机关开始运用网络来办案。中国的检察机关走得比较早，现在我们建成目标（有些地区已经开始运用）是运用互联网的大数据和人工智能来办案。

第一，我们已经开始用智能语音来代替书记员的书写输入、记录。因为大数据、人工智能这个条件下，我们的开发的智能语音，已经让我们的检察官在提审犯罪嫌疑人时或者在出席法庭公诉时，检察官的语言会以最快的速度，绝对超过最快的记录员的速度为我们实时记录转变成文稿。

第二，有些简单的案件，包括盗窃罪、故意伤害罪、交通肇事罪，检察官可以从司法部门连线网络得到警察传输过来的信息，网络和系统会自动的帮助检察官自主地完成审查报告初稿。这篇审查报告会清晰的表明犯罪事实，同时也会告诉检察官，根据这些犯罪事实和证据，嫌疑人所触犯的是刑法哪一条、构成什么罪、应该给出几年到几年的量刑建议等。同时网络会帮检察官自动推送10个或20个与本案犯罪情节最相近似的案例，也会自动为检察官提供本案可以适用的相关法律条文，这样检察官就会很轻松的做比较、做分析，也可以做补充、做纠正。这样办案相较以前，那必然使是办得更加公正，也更加轻松。

除此之外，因为网络的发展和完善，检察官可以坐在办公室和监狱的犯罪嫌疑人进行会见、交流，足不出户就能轻松的核审案情，甚至检察官可以坐在检察官的办公室，来通过网络来参加网络远程的庭审。网络把在法院的法官和在检察院的检察官连成一线，把不同的空间变成了一个融合的新的空间。律师、辩护人下次办理布达佩斯检察院刑事案件时，也不需要从佩奇赶到这里，在佩奇检察院就可以取到布达佩斯检察院的案件材料，甚至在佩奇就可以会见羁押在布达佩斯的犯罪嫌疑人。同样，匈牙利最高检察院的检察官可以跟佩奇、赛格德及其他地方的检察官在一起开会、交流、研讨。这不是梦想，在中国已经成了现实。所以以这样的方式来办案，我们是不是还认为法官、检察官的头发越白，他的司法经验就一定越丰富，他办的案件就一定会质量最高呢？我相信，这类问题的答案也会发生颠覆性的改变。

所以互联网时代的到来是不可阻挡的，不要等待，不要观望，它既是机遇也是挑战。在此，我想起了匈牙利的伟大诗人裴多菲的一首诗——《民族之歌》：

起来，匈牙利人，祖国正在召唤！

是时候了，现在就干，还不算太晚！

去做自由的主人，还是奴隶？

自己选择吧，就是这个问题！

我想，伟人的先见之明就在于为我们今天的命题提供了最好的引导和指引，也为我们全世界检察官保护和推动互联网发展提供了最好的勉励词。

![](../Images/29cfaa1665c6fb3761caa1895fb1db31.png)

朋友们，中国有句古话：“天下没有不散的筵席”，精彩的研讨会马上就要结束了。我想这次会议对我们两国检察机关的合作、交流、和发展等带来的意义一定是里程碑式的，也是令我们参加这次会议的每一位代表终身难忘的。明天我们将带着美好的回忆，也是带着对下一次会议的期待，回到中国认真准备匈中两国最高检察院的第二次检察论坛。在此我谨真诚邀请匈牙利检察官去北京，北京欢迎匈牙利，友谊长存，北京再见！

谢谢大家。
