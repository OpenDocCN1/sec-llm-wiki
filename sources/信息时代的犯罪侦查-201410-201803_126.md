# 昂首迈进电子数据取证2.0时代

我们如今的一切，是传统社会的元素，打上了信息时代的烙印，又匆匆坐进了移动互联网的车子。人们既不能摆脱信息时代的印记，又无法贸然跳车逃走。于是，绝大多数人都在时代的裹挟中前行。这构成了当今时代最为鲜明的特征。

  

**电子数据取证1.0版**

  

七年前，笔者所在的团队，充分吸收外部的经验，大胆探索着自己的道路。经过大小几百次的战役，队伍的素质能力得到锻炼，涌现出许多非常优秀的取证能手。有的在全国的比武活动中获得标兵、能手称号，有的当选了省级先进工作者，有的成长为区域甚至全国范围较有名气的专家骨干。其实，他们的工作内容很单纯，在涉案的电脑、手机、网络等介质中，获得有价值的信息，为侦查案件、审查判断证据、司法鉴定提供技术服务。我们行内称之为电子数据取证。因为在一些案件中发挥了积极作用，我们的团队也逐渐被相关业部门认可、肯定和依赖。这与团队的努力分不开，更与时代发展的趋势息息相关。

那时候，每天的工作就是解析硬盘、优盘、手机等涉案检材。对一个个单独的检材而言，其中的数据文件都是人为操作的痕迹，直接或间接记录了行为人的特征、内心和操作行为。对这些数据文件开展分析研究，是典型的精细化操作。在这个时期，“我们的目光在介质与案情之间来回游走”。这段时期持续的时间比较长，大概有五年以上，笔者称之为电子数据取证1.0版。

  

**您体会过文件秒传吗？**

  

百度云盘出现的那一年，笔者还在为涉案硬盘的数据文件太多而烦恼，为筛选出哪些文档交给办案人员而纠结。直到自己亲身使用和体会了云盘服务，才慢慢感悟出一点心得，而这一点心得逐渐投射到工作实践中，正是所谓的格物而致知。举例而言，您体会过云盘的文件秒传吗？一个数百兆甚至更大的文件，从本地客户端上传到云端存储，居然能做到一秒内完成。无论多么大的网络带宽，这也是难以完成的任务。笔者很快明白并证实了其中的原理，云盘服务商使用了我们工作中常用的哈希校验算法。当其检测到目标文件已存在时，就能够在目标位置上做个标记，实际上并未发生真正的文件传输过程。

  

**电子数据取证2.0版**

  

云盘跟电子数据取证又有什么关系呢？我们既定的取证过程仍需要精细化进行。而笔者想说的是，我们能否通过长期的涉案介质数据文件积累，发现文件之间的关联关系，发现文件内容中出现的各类号码、关键信息，在平台中的关联涉案情况，并在前端检验的过程中，向检验者推送相关的消息？根据米尔格兰社交关系间隔论，任何人之间总是可以找到最多不超过五层的关联关系。就电子数据文件而言，是不是也能遵循这个规律呢？这个想法大胆而又有创新性！

  

实现这一目的，至少需要具备四个步骤。（从略）

  

在这个阶段的电子数据取证工作，将不再仅仅着眼于单个的介质，“我们的目光将在介质与云端数据之间来回游走”。未来，一个涉案介质的检验，将通过精细化操作和关联性操作两个角度，给出更为全面的解决方案。这便是笔者所提到的电子数据取证2.0时代。

  

也许，我们并未做好适应2.0的准备，3.0就已经在前方不远处了。
