# 刍议行政执法阶段收集的电子数据 如何与刑事司法相衔接

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxNTA4NDAwOQ==&mid=2650730193&idx=1&sn=148d4938ff16a379b480028339b53c1c&chksm=83833e57b4f4b7410614e48973ce41d4c29af95a99b33bb0a06d819cdd659d1dd89e15c69027&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxNTA4NDAwOQ==&mid=2650730193&idx=1&sn=148d4938ff16a379b480028339b53c1c&chksm=83833e57b4f4b7410614e48973ce41d4c29af95a99b33bb0a06d819cdd659d1dd89e15c69027&scene=27#wechat_redirect)

不得不说，2012年修订刑事诉讼法是一个标志事件。电子数据入法，在完善刑事证据种类、打击各类新型犯罪、适应信息时代发展等方面具有划时代的意义。以至于有很多问题，依然成为我们目前研究的重点。本文结合《刑事诉讼法》第52条第2款之规定（“行政机关在行政执法和查办案件过程中收集的物证、书证、视听资料、电子数据等证据材料，在刑事诉讼中可以作为证据使用。”），谈一谈行政执法阶段收集的电子数据如何在刑事司法阶段进行衔接的问题。

  

甚嚣尘上的“慢插”案件之所以引起公众的高度关注，在小编看来，文化执法委员会在查封扣押涉案服务器的执法过程中，确有商榷之处。源头上出了点问题，导致案件进入刑事诉讼程序后，有一些先天不足，进而造成一定程度的被动。既然法律都规定了——行政执法阶段收集的电子数据，在刑事诉中可以使用，那么应当如何理解和运用好这条规则呢？我想有三个方面的问题，需要引起一定的重视。

  

**第一，要更加强化对行政执法有关电子数据的审查。**

  

行政执法与刑事司法中都涉及证据制度并以此作为各自领域认定事实的依据和适用法律的基础。但由于两类活动的性质不同，各自证据制度的内容及法治化程度也不同。一般来讲，行政执法证据制度的法治化程度比较低。其关键差别在于，行政执法强调的是效率，而刑事司法注重的是公正。正是有了这一渊源性差别，才应当更加慎重的审查行政执法过程中收集到的各类电子数据。对于电子数据的唯一性、所有者、使用者、保管者等，需要重新审查确定； 对于可复现的鉴定意见、检验报告，应当重新进行复现；当然，对于现场勘查笔录等具有当场性意义的资料，因为时间间隔的原因，复现的可能性不大，且可能造成更加脱离事实,重新收集此类证据,既不现实也不可能，则可以延续使用。

  

**第二，充实和完善两法衔接机制（即行刑衔接）。**

  

在小编看来，刑事诉讼法第52条第2款的修订，其实发端于检察机关前几年倡导的行刑衔接机制建设。所谓的行刑衔接，指的是检察机关、监察机关、公安机关、政府主管部门和有关行政执法机关探索实行的旨在防止以罚代刑、有罪不究、渎职违纪等社会管理问题而形成行政执法与司法合力的工作机制。但几年下来，这项制度的落实情况并不太乐观。原因不言自明，谁也不会心甘情愿的主动接受监督。其实，小编一直认为，这项机制的创设者绝对是一位智者。两法衔接作为一个“多边”平台，协商的空间和意义更具价值。在这个框架内解决证据的标准问题、协作问题、移送和衔接问题，似乎更加顺畅。

  

**第三，推动全国人大常委会修改《全国人民代表大会常务委员会关于司法鉴定管理问题的决定》（简称“228”决定）。**

  

允许人民检察院、公安机关等依侦查职能设定的司法鉴定机构，可以接受行政执法机关的委托，开展电子数据取证、检验、鉴定等工作，并视情况收取一定的费用。该措施的出台，将在一段时间内，弥补行政执法人员在取证、检验、鉴定等环节的短板，有利于提高执法的规范化程度。

  

在一个素来行政权独大的国家，对行政活动的监督无疑是难上加难，但我们可以在机制上不断予以弥补和修正，在夹缝中推进法治文明建设，不断把权力关进制度的笼子。
