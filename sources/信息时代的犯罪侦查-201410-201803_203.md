# 两起命案是什么关系呢？真是想不到……

一栋写字楼在偏僻的筒子楼群里。一家小公司在这栋写字楼的六七层，其余楼层都无人使用。

  

写字楼一共十层但没有电梯，而公司的两楼层都没有厕所，员工只能到二楼的一间有些破烂的公共厕所。

  

碰到下雨天，厕所经常飘雨进去，所以地面常常很湿滑。有一天，一个小员工内急去上厕所，很久没有回来，最后被人发现非正常死亡在厕所里，死亡表情惊悚可怖。

  

六楼的员工跟一楼门卫大爷证实，期间没有人下楼上厕所，或者进入写字楼。但其实，这栋写字楼一共发生了两起命案。

  

你知道这是怎么回事吗？

  

  

想一想，再往下翻……

  

  

  

*   这个案子里没有凶手，两起命案只是巧合
    
*   厕所里能飘雨，是因为有窗户
    
*   因为厕所在二楼，楼上有人跳楼，当那个跳楼的人跳下去经过厕所的窗户时被小员工看到了，所以小员工被吓死了
