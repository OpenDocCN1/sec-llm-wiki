各位用户朋友们，大家好，转眼间四月份已经到来，我们的产品EnCase  Forensic也正式进入22.1版本，从界面到功能都实现了较大的优化和提升，让我们一起确认一下其更新性能吧～




新版特性

简单概括


1、很熟悉，但哪哪儿都比旧版好用的新主页；

2、很包容，可以直接读取添加AFF4格式文件至EnCase案例中；

3、很“扫地机器人”，可以收集更多谷歌浏览器证据；

4、很“犯罪克星”，AI媒体分析模块增加实现人物画像；

5、很省心，在后台直接生产报告；

6、很“信号放大器”，提高了通过网络获取Lx01逻辑证据文件的性能；

7、很与时俱进，支持全新版本的谷歌浏览器等；

8、很“翻译机器”，14门语言掌握者；

9、很“一体机”，实现McAfeee策略协调器(ePO)集成；

10、很灵活，支持多款软件云服务，提供安全、可靠的应用环境。



新版特性

详细说明


1、新的主页面

Encase重新设计了软件主页。新的主页保留旧版本功能的同时，提高了可用性，并为未来的界面现代化奠定了基础。

2、支持AFF4-L镜像格式

新版本可以实现读取高级取证镜像格式AFF4文件(.aff4和.therk格式)并直接添加到EnCase案例中功能。支持逻辑镜像（AFF4-L）文件的创建，暂不支持AFF4文件的创建。

3、支持更多谷歌Chrome数据解析

功能使用导航：Internet Records > Internet > Chrome (Windows)

新版Encase可以收集更多的谷歌Chrome浏览器证据，包括：

3.1 表单历史记录（自动填充）-保存的用户表单数据

3.2 媒体历史记录-有在浏览器中播放的媒体的数据

4、AI媒体分析模块增加：

4.1 聊天：聊天对话应用程序识别，如Facebook messenger, Viber, WhatsApp, Skype, Telegram

和其他基于聊天的应用程序。

4.2 人脸：在一个形象中出现的人脸。

4.3 地图：谷歌地图，街道地图，拓扑地图，导航地图和卫星地图。

4.4 二维码：二维码或条码。

4.5 纹身：纹身识别。

4.6 文本：在图像中显示的文本。

4.7 车辆：牌照和车辆，包括轿车、suv、皮卡、货车和卡车、摩托车和公共汽车。

注意：要使用媒体分析模块，OpenText建议至少使用32GB RAM(4GB per core on an 8 core CPU)。

5、后台生成报告

新版本可以实现直接在后台生成报告并处理其他任务。

6、增强网络获取功能

新版本提高了软件通过网络获取Lx01逻辑证据文件的性能。

7、支持新版本浏览器，包括：Google Chrome 96、Microsoft Edge 96 、Mozilla Firefox 95

8、支持更多语种，包括：阿拉伯文、中文（简体）、中文（繁体）、荷兰语、法语、德语、意大利语、日本、韩语、波兰语、葡萄牙语、俄罗斯、西班牙语及土耳其语。

9、集成McAfeee策略协调器(ePO)

McAfeee策略协调器管理员可以使用ePO将环境包代理部署到ePO管理的节点上。支持版本4.5、4.6、5.1和5.3。

10、提供多软件云支持服务，包括：Microsoft Exchange Server 2013 or Later、Microsoft Exchange Server on Office 365、Google Workspace、Amazon S3、Box、Dropbox、Google Workspace、Microsoft Azure Blob、Microsoft SharePoint 2013 or Later、Microsoft SharePoint Office 365、Microsoft SharePoint Office 365 OneDrive、Microsoft Teams、Facebook（现改名为Meta）、Instagram、Twitter。
