**编者按**

近年来，“**人工智能**”甚嚣尘上。小编正好近期工作用的上，索性“**亲历**”验证了一遭。以自然语言处理为例，说一说体验吧。更重要的是，通过这样的验证和测试，我们未来会将这项技术应用于实践中，而这个实践是足以令人感到鼓舞和振奋的。  

  
一个概念的兴起，自然有他的基础。理性地来说，既不要跪舔，也不要嗤之以鼻，甚至也不建议敬而远之。在小编看来，绝知此事要躬行。考虑到近年来，以及今后一段时间，自然语言处理技术会在工作中有一定的刚性需求场景，小编选择当前比较成熟的几个免费资源尝试了一把，以免日后被“忽悠”……  
**一、先用“人话”说一说，什么是自然语言处理？**  
自然语言处理，翻译成英文：natural language processing，简称NLP。说白了，就是使用自动化的方式，从一段话中分析出相关的内容。比如，“**华为是一家伟大的公司**”如果由人来分析，很自然地能够理解，这里面有名词、动词，有表示情感的词，有表示实体的词……。但如果由计算机来进行分析，就需要依靠强大的“算法”来保证可靠、准确。  
**二、百度的免费接口**  
据小编所知，目前有一些厂商（平台）对外提供免费的调用接口（SDK），比如百度、TRS等。但大部分需要在本地计算机上面安装服务程序，显得略有些麻烦。于是，我选择了百度：不需要本地安装服务程序，只需要使用post/get调用即可，相对比较轻型化。之所以选择百度，还有另外一个考虑：海量的用户、强大的中文搜索引擎，给自然语言识别预备了天然的基础。当然，具备先天优势的还有鹅厂。  
**三、使用百度自然语言处理SDK需要准备的基础**  
小编习惯于使用C++环境，重点研究了百度针对C++的NLP-SDK。根据百度的官方文档，需要在开发环境下提前做好以下方面准备工作：  
1、编译并生成libcurl.lib，以便能够支持进行网络数据传输，比如提交一个URL等。2、编译并生成openssl（libcrypto.lib和libssl.lib），以便能够支持安全加密的网络通信，毕竟调用百度的开放接口，通常要使用https协议。3、编译并生成Jsoncpp，验证和测试端与百度服务器的通信，均以json格式的数据作为交换媒介。（注意版本：坑）  
（上面三个资源的源代码、库文件lib和dll经千辛万苦编译生成，如果大家需要，可以留言，免费分享，都是x64的）  
  
**四、需要严重注意的问题！！！**在验证和调试过程中，有一些细节问题搞得非常疲惫。这些问题在公开资料中均有提及，但大多不太靠谱。向大家报告一下，以免踩坑。比如：**Json处理中文的问题**，就是小编认为非常大的一个挑战。小编通过实际调试，给大家分享两个不错的方法函数。  
调用百度SDK时，提交的json和返回的json仅支持UTF8。因此，客户端需要提前对“**待处理文本**”进行处理（Unicode或者Ansi->UTF8）。接收到服务器返回的json后，也需要进行处理（UTF8->Unicode或者Ansi）。  
**1、GBKToUtf8，把“待处理文本”转化为UTF8**

*std::string GbkToUtf8(const char\* src\_str)**{*

*int len = MultiByteToWideChar(CP\_ACP, 0, src\_str, -1, NULL, 0);*

*wchar\_t\* wstr = new wchar\_t\[len + 1\];*

*memset(wstr, 0, len + 1);*

*MultiByteToWideChar(CP\_ACP, 0, src\_str, -1, wstr, len);*

*len = WideCharToMultiByte(CP\_UTF8, 0, wstr, -1, NULL, 0, NULL, NULL);*

*char\* str = new char\[len + 1\];*

*memset(str, 0, len + 1);*

*WideCharToMultiByte(CP\_UTF8, 0, wstr, -1, str, len, NULL, NULL);*

*std::string strTemp = str;*

*if (wstr) delete\[\] wstr;*

*if (str) delete\[\] str;*

*return strTemp;**}*

**2、把返回的json中的汉字转化为Unicode或者Ansi**  

*CString GetUStr(const string& str)**{*

*std::string showname = str;//\\uXXXX形式的中文*

*int len = strlen(showname.c\_str()) + 1;*

*char outch\[MAX\_PATH\];*

*WCHAR\* wChar = new WCHAR\[len\];*

*wmemset(wChar, 0, len);*

*MultiByteToWideChar(CP\_UTF8, 0, showname.c\_str(), len, wChar, len);*

*CString strRet(wChar);*

*delete\[\] wChar;*

*return strRet;**}*
