**数据分析1之流量分析：**用wireshark分析黑客工具“中国菜刀”的流量包，找出FLAG。最简单的方法是在分组字节流里直接搜索”flag”，实战中若是流量包不大也可以这么做；还有一个是Linux下的ngrep命令；另外常用的技巧还有导出流量包中的资源信息，从”文件”->”导出对象”中选择相应的协议(一般是http)，接着单击”Save all”即可导出所有资源文件，如图片、压缩包等等。对此感兴趣的朋友，推荐做一下”抓住一只苍蝇”，实战性也是非常不错。

**数据分析2之传销组织人员分析：**题目描述：案件发现一个传销群体，通过手机取证获取到这些传销人员的QQ好友信息，请找到这些QQ号码的共同好友（仅一人），疑似是上一级代理的QQ号码。数据字段格式：文件名是qq号，文件内容里的qq号是文件名qq号的好友。请找出他们上一级代理的qq号码。

![](../Images/24aadadee547fa1c113ea3ab17dafeb5.png)

解题思路：当时我采用手工的方式，提取好友列表然后用notepad++将这堆数字处理成python的元组格式，接着每两组筛选出共同好友，大约筛选15组就能拿到共同好友。

![](../Images/6781cf7c57ac4f7d49b16fc26ab49393.png)

还可以将所有数据合并到一个表格里，用WPS的筛选功能查看出现次数最多的数字(按次数排序功能收费，低版本免费)。

![](../Images/ee986fb3e643426ce5e71a3c308fc902.png)

**数据分析4之话单分析：**题目描述：目前发现某市有一个电信诈骗团伙，该团伙分工明确，都是使用不同的手机号码实施诈骗，诈骗步骤：第一步有人冒充警察给受害者打电话，第二步有人冒充检察院工作人员继续给受害者施压，第三步有人冒充法院工作人员继续施压，打电话时间一般是白天9点到晚上20点之间，通过协调通讯公司公安机关调取了近一个月某市所有手机通话记录，请从中分析出诈骗人员的电话号码。（答案三个手机号码） 数据字段格式：（主叫电话，被叫电话，通话时间，通话时长(单位：秒)）。  
解题思路：这道题当时没做出来，也困扰了我好几天，主要是量大且没有思路。后来请教了几位体制内的业务能手，他们说这题非常贴近日常工作并提供了几个思路给先森参考。建议无论是日志分析还是话单类的数据分析，量大就导入MySQL里，毕竟Excel和WPS主要面向处理量较小的办公用户。（**会使用其他工具分析话单的请带带先森~**）首先根据提供的话单字段创建数据库，这里比较坑的是对于 Y:M:D H:M:S 这种datetime型数据导入，需要先将相应的字段设置为字符型，等导入完毕后再转成datetime，不然导入结果可能成了”2000/00/00 12:20:34”这种格式。

![](../Images/b98be77dedc917474ca5dde6cc19663b.png)

其次筛选指定时间段的数据。思路在脑子里蛮清晰，但是实操起来就发现问题了——如何按时间段筛选？直接用between and来筛选日期时间型数据根本不可能，通过查询资料得知可以使用MySQL的TIME\_FORMAT(time, '%H%i')来将此类数据转换成指定格式。

![](../Images/01c878b5a8b4b4a2894f49d0816f6136.png)

完整的SQL语句是select \* from huadan\_wz WHERE TIME\_FORMAT(time, '%H%i') BETWEEN "0900" and "2000"。本次查询筛选出大概75W条数据，筛掉了大约30%的数据。

![](../Images/9086f484b69b18364cb7127bb0dac9cb.png)

为了方便查询和统计，将以上结果导出后再重新导入到另一张同类型的空表里。用navicat的导出功能将结果另存为，然后将原表复制并清空，按第一步的思路导入回去。

![](../Images/f2098195a852d2dab5ef9c2dd9542f53.png)

通过浏览发现存在不少通话时长为0的数据，筛掉之。执行DELETE  from huadan\_wz\_copy\_copy1 where length = 0 ，本次删除共11W条无意义数据。

![](../Images/6ec827d419a541b0c0e199bd40344715.png)

确定受害者范围。通过题目描述我们可知，受害者至少应该收到3个电话，也就是说受害者是话单数据中被叫出现次数大于或等于3次的手机号机主；将数据按被叫字段去重并筛选出次数大于或等于3的所有数据。执行SQL语句 select \* from (select count(beijiao) as BC,zhujiao,beijiao,time,length from huadan\_wz\_copy\_copy1 GROUP BY beijiao order by beijiao) as alldata where bc >= 3 筛选出共4300余条数据，然后将潜在的受害者结果复制出来。语句详解：MySQL中会优先对子查询进行运算，所以我们先来分析子查询语句；select count(beijiao) as BC,zhujiao,beijiao,time,length from huadan\_wz\_copy\_copy1 GROUP BY beijiao order by beijiao 表示将话单数据按beijiao字段去重(group by)、统计beijiao出现的次数并给这个结果起一个别名(as)、最终查询结果按beijiao字段排序(order by)；select \* from (子查询语句) as alldata where bc >= 3 表示筛选出子查询结果中被叫次数大于或等于3次的数据，需要注意的是当对子查询的结果进行再次查询时，要给子查询结果起一个别名。

![](../Images/6bb3a79ec77b290390f13a99fc6724b4.png)

  
提取潜在受害者的所有话单数据。使用SQL语句 select \* from huadan\_wz\_copy\_copy1 where beijiao in (受害者列表) 筛选出受害者的全部话单，将结果导入到新的表中，过程不再赘述。

![](../Images/71652e08dbded3e05983f79d07d905a7.png)

确定诈骗分子范围并提取所有潜在的诈骗团伙数据。按确定受害者范围的思路，筛选出主叫次数大于或等于一次的数据，毕竟题目中提到诈骗团伙是对整个市进行诈骗，所以应该不止一个受害者。将存在诈骗分子的所有话单数据导入到新表中。

![](../Images/b9ac101a47a07280234287a1fb04d690.png)

碰撞出诈骗分子的手机号。截止到上一步，表中的数据满足了：1.通话时间在9:00-20:00；2.被叫次数大于或等于3次；3.主叫次数大于1次，且主叫和被叫字段都未去重，包含了潜在的诈骗团伙和潜在的受害者的所有通话记录。最后一步，对潜在的受害者去重、统计去重后的被叫字段中存在共同的主叫，结果按主叫次数排序，最终得到三个手机号。此题实践性非常不错，但是先森认为此题的不严谨之处，没有考虑到诈骗分子会使用网络电话进行改号(**每次实施诈骗就换新号**)。
