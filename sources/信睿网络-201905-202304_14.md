# 物联网设备安全 + 如何开始

物联网（IoT）已经正式到来。经过多年谈论即将到来的物联网爆炸将如何带来类似于互联网出现的变化，我们终于看到了它的发生。虽然物联网的兴起为创新带来了无数机会，但物联网设备的安全性也带来了严峻的挑战。

  

值得注意的是，围绕物联网安全的挑战无论如何都不是不可克服的。尽管如此，他们确实需要迅速解决，以便组织和消费者等获得物联网必须提供的所有好处。

本文将探讨您需要了解的有关 IoT 安全的知识，包括 IoT 设备的巨大机遇、IoT 安全为何如此重要、当今 IoT 安全面临的主要障碍以及确保适当 IoT 设备安全的最佳实践。

  

**机会比比皆是：物联网的积极影响**

首先，让我们弄清楚物联网到底是什么。物联网是一个物理对象网络，可以与其他支持互联网的系统和设备交互以共享信息和执行操作。

在过去的几年里，物联网设备变得如此普遍，以至于其中许多现在看起来很普遍。例如，想想您的智能手表或亚马逊 Alexa 设备。考虑一辆提供预测性维护和事故避免传感器的汽车，或者一种可以更大规模地直接向您的医生发送信息的医疗设备。

从汽车和医疗设备到制造、零售和金融，连接设备为组织和消费者创造更智能、无缝体验的机会确实是无限的。许多物联网设备的预测元素还承诺节省资源，包括时间和金钱，并创造整体更安全的体验。

值得注意的是，尽管今天这些用例相对成熟，但我们仍然开始使用物联网提供的一切。随着物联网生态系统的不断成熟，安全性已成为其持续成功的关键。

  

**为什么物联网安全如此重要**

物联网设备具有巨大的积极的变化潜力——它们连接对象、共享信息和执行操作的能力——也使它们非常脆弱。那是因为存在的每个连接点都有被黑客入侵的风险。

  

**物联网设备安全漏洞示例**

不幸的是，不乏说明物联网设备易受攻击的例子。**近年来一些最著名的例子包括：**

*   一个被黑客入侵的婴儿监视器，让黑客可以看到婴儿并以绑架的威胁与父母交谈。
    
*   受损的医疗设备，包括：
    

1.  获得植入心脏设备 并可能耗尽电池或发出错误起搏的黑客 。
    
2.  获得胰岛素泵，并可能向糖尿病用户提供不正确剂量胰岛素的黑客。
    

*   消费车辆有缺陷的连接允许黑客远程控制并采取诸如切断刹车、关闭发动机甚至将汽车驶离道路等行动。
    

这些只是说明物联网设备安全重要性的众多示例中的一小部分。他们还强调了黑客完成这些活动是多么容易。例如，在 2015 年克莱斯勒黑客事件中，研究人员发现，由于无线连接系统存在缺陷，他们可以通过 Sprint 移动网络轻松访问美国的任何克莱斯勒汽车。  

至关重要的是，随着物联网设备变得更加普遍，特别是在汽车、医疗设备和原始设备制造等行业，与黑客相关的风险大大增加，以至于人们的生命处于危险之中。

  

**物联网安全挑战**

尽管加强物联网设备安全的重要性日益增加，特别是随着新立法的出台，但仍存在许多挑战。物联网面临的主要安全挑战包括：

**01 缺乏标准**

在最高级别，缺乏管理物联网设备安全的标准。虽然这种情况无疑正在发生变化，但在今天的大多数情况下，设备制造商及其安全团队仍然没有明确的目标标准。因此，市场上存在很多模糊性。反过来，这种模糊性又为身份验证实践、持续安全更新和连接设备之间的通信等领域的其他挑战创造了温床。

**02 改造旧设备**

许多制造商已经用智能传感器改造了传统设备，使它们能够联网并在不付出高成本的情况下实现物联网的好处。这种方法证明可以既省时又省钱，但会带来严重的安全风险。

具体来说，不连接到互联网的旧设备通常几乎没有安全性。因此，即使添加的传感器提供某种类型的安全类型，设备本身也会为恶意方渗透传感器和潜在更广泛的网络创造额外机会。

**03 补丁或更新没有规律**

许多设备无法提供高级安全功能，甚至无法随着时间的推移通过更新获得这些功能。制造商无法针对任何发现的风险或安全更新发布补丁以使设备与最新标准保持一致，这带来了许多挑战。它使许多物联网设备在现场存在安全问题。随着物联网生态系统的不断老化和新的安全标准的开发，这一挑战将在未来几年呈指数级增长。

**04 未签名固件**

即使在制造商确实推送更新的情况下，也存在挑战。例如，当开发人员构建新代码并将其投入生产时，需要一种方法来验证其真实性，他们通过使用受信任的公共/私人加密密钥对代码进行签名来做到这一点。然而，许多制造商将物联网设备推向市场的方式与他们为其他解决方案所做的不同。许多人传统上没有验证新代码是否使用可信密钥正确签名。这种缺乏安全检查的情况打开了风险之门，允许任何有权访问系统的人将新代码推送到物联网设备，从而导致任何数量的安全、财务和声誉风险。

![](../Images/83026d6edf951348dcdb4091282ef48e.png)

**05 硬编码密码**

制造商将密码或加密密钥硬编码到物联网设备中以简化部署已变得司空见惯。这种做法是有风险的，但如果开发人员将此信息嵌入纯文本中以便于访问，则风险会更大——这种情况经常发生。那是因为如果有人找到这些信息，他们可以轻松访问设备并以任何方式控制它。

**06 弱认证**

许多物联网设备都使用静态或默认密码进行编程，用户无法轻易更改这些密码。这种弱级别的身份验证使黑客很容易访问设备和部署恶意软件，从而带来了严重的风险。这通常发生在成本较低的物联网设备上，例如安全摄像头。然而，重要的是要注意，即使是这些设备也会获取敏感信息，当这些信息被黑客入侵时，可能会使人们受到伤害并侵犯他们的隐私——从而给制造商带来严重的财务和声誉风险。

**07 共享和不受保护的密钥**

许多物联网设备使用对称加密，其中使用单个密钥来加密和解密数据。数据被加密的事实提供了一个安全的安全层，特别是与使用硬编码或默认密码相比，但共享和存储加密密钥会产生风险。那是因为如果恶意方截获了密钥，它可以使用它来加密和解密数据。这意味着他们可以访问整个系统并共享数据，甚至可以在制造商或最终用户不知情的情况下通过操纵数据来充当“中间人”。由于这种风险，制造商必须采取额外的预防措施来保护加密密钥，这可能会变得昂贵且难以大规模维护。

使用非对称加密，生成唯一的公钥和私钥对。每个都有不同的用途（公钥解密数据并可以公开共享，而私钥加密数据，必须受到保护），有助于解决对称加密的挑战。然而，即使使用非对称加密，私钥也必须得到适当的保护——否则，同样的风险也会存在。不幸的是，许多开发团队在存储这些私钥时未能采取适当的预防措施。

**08 弱加密**

加密提供了几乎无法穿透的安全性，但只有在正确完成的情况下。具体来说，加密强度取决于用于生成公钥/私钥的算法。理想情况下，公钥应该相对容易从私钥计算出来，但反过来应该是不可能的。

目前存在许多标准，例如 RSA 2048 和 Diffie-Hellman，用于管理加密密钥的强度。不幸的是，许多物联网设备使用不符合这些标准的弱算法来生成加密密钥。在这种情况下，恶意方更容易确定私钥，从而使他们能够访问设备以破坏设备。

**09 DDoS攻击**

围绕物联网设备的所有安全挑战使它们特别容易受到分布式拒绝服务 (DDoS) 攻击。当黑客使用多个设备向系统发出大量数据请求以使系统不堪重负以使其完全停止工作时，就会发生这些攻击。

由于此处列出的许多安全挑战，IoT 设备容易受到 DDoS 攻击。因此，黑客可以快速访问这些连接的设备以形成僵尸网络（又称“僵尸军队”），以便所有设备可以同时向单个系统发出请求。DDoS 攻击在物联网设备中特别频繁，因为这些设备相对容易被黑客入侵，因为安全标准普遍松懈，而且 DDoS 工具包往往易于购买和启动。

  

**物联网设备安全最佳实践**

如今，物联网设备安全存在许多挑战，但有可能克服这些挑战。

团队需要在每一步都优先考虑 IoT 设备的安全性。这种优先级包括在安全方面进行更多投资，并尽早将其纳入开发流程。

在此过程中，物联网设备安全必须围绕创建受信任的设备身份、确保数据机密性以及维护每个设备上运行的数据和固件的完整性。实现这些目标需要用于身份验证、加密和代码签名的关键安全元素。制造团队可以采用几种最佳实践来满足这些需求，包括：

**01 为每台设备创建唯一的凭证**

发送受保护的数据是任何物联网设备的基本功能。为了使此功能有效，用户和制造商都需要相信他们收到的数据是真实的并且是为他们准备的。实现这一目标的最佳方式是以数字证书的形式为每个物联网设备颁发唯一凭证。

为每台设备提供唯一的数字证书有助于改进身份验证，并为当今使用默认密码甚至共享密钥进行对称加密的常见做法提供巨大的保护。这是因为密码具有很高的泄露风险，而提供比默认密码更多保护的对称加密密钥不会在设备之间提供任何类型的区分。这种差异化的缺乏使得无法与特定连接的设备共享唯一信息或确定个人数据源自的特定设备。

相比之下，数字证书可以为每个设备创建一种高度安全、唯一的身份验证方法，从而显著提高安全性。例如，这种方法使制造商能够安全地与特定设备共享更新和数据，并有助于更好地验证来自设备本身的传入信息的真实性。

**02 私钥存储注意事项**

为每个物联网设备创建唯一的数字证书需要非对称加密，它会生成一个公钥和私钥对。因此，制造商需要采取额外的预防措施来存储这些私钥。

最好的方法是使用可信平台模块 (TPM) 技术或提供基于硬件的安全性的安全存储硬件。例如，TPM 芯片提供支持硬件的安全加密处理器来保护加密密钥和数字证书。这种类型的投资对于实现最高级别的物联网安全是非常值得的。它提供了强大的保护，防止用于设备身份验证和数据加密的私钥被泄露。

![](../Images/49e1865db613bbac5cdd7a4c616104f6.png)

**03 始终使用代码签名验证固件和软件更新**

一个重大的物联网安全风险是黑客将恶意软件更新推送到连接设备的能力。制造商可以通过要求设备在安装前验证任何新固件或软件的真实性来防范这种风险。这样做需要制造商的开发团队使用数字签名对其代码进行签名，这可以通过公钥/私钥对来实现。

在这种情况下，每个连接的设备都需要一个与制造商开发团队持有的私钥相匹配的公钥。如果开发人员使用私钥“签署他们的代码”，任何使用公钥的设备都可以 (a) 验证更新确实是从制造商（或拥有私钥的任何人）发送的，并且 (b) 确认更新在传输过程中没有被修改。因此，要求代码签名有助于防止连接的设备安装恶意第三方发送的损坏软件。

**04 建立特定于组织的信任根 (RoT)**

信任根 (RoT) 包含加密密钥，并有助于在颁发新密钥或数字证书时进行初始身份验证。建立特定于组织的 RoT 使制造商可以完全控制他们发布加密密钥的任何设备或个人的身份验证。保持 RoT 组织特定允许制造商设置他们的身份验证标准，以创建强大的信任链，而不是使用共享根并信任第三方的信任模型和操作。

**05 映射、监控和维护证书、密钥和 RoT**

也许最重要的是，上述物联网设备安全最佳实践并非一劳永逸。相反，所有这些努力都需要持续的生命周期管理。这是因为任何类型的静态系统本质上都是不安全的。如果没有适当的生命周期管理，使用中的数字证书、密钥对和 RoT 会随着时间的推移而减弱。

**这种生命周期管理应包括：**

*   映射所有正在使用的东西，以准确了解所创建的内容。
    
*   监控所有证书、密钥和 RoT，以识别任何潜在威胁并迅速做出相应调整。
    
*   通过根据需要更新证书、密钥和 RoT 并在相关设备不再使用时撤销任何证书和密钥来维护此安全性的健康。
    

  

**PKI 如何帮助加强物联网安全**

物联网的安全需求和帮助解决这些需求的最佳实践指向了一个明确的解决方案：**公钥基础设施 (PKI)。**

PKI 是一个信任框架，由管理可信数字证书和公钥加密所需的硬件、软件、策略和程序组成。它有助于验证数字身份和安全数据，满足围绕身份验证、加密和代码签名的关键物联网安全需求。重要的是，它还具有可扩展性，可容纳数百万个设备身份，而每台设备上的占用空间极小。

  

**为什么要为物联网安全引入 PKI？**

**PKI 在加强物联网安全方面提供了几个关键优势，包括：**

*   **唯一身份：**  PKI 使物联网设备制造商能够通过数字证书将可加密验证的身份嵌入到每个设备中，以确保随着时间的推移安全访问和软件交付。重要的是，制造商还可以根据需要更新或撤销单个设备上的这些证书。
    
*   **灵活性： ** PKI 是一种高度灵活的方法，允许制造商使用各种选项（包括 REST API、SCEP 和 EST）来进行可信根、撤销以及证书注册和部署。
    
*   **可扩展性：** 制造商可以从一个受信任的证书颁发机构颁发数字证书，这允许物联网设备在没有任何类型的集中式服务器的情况下安全地相互验证。
    
*   **强大的安全性：**假设 PKI 管理良好，数字证书提供的安全性明显高于其他身份验证方法，包括默认密码和对称加密。
    
*   **最小占用空间： **用于 PKI 的非对称密钥占用空间最小，这意味着对于具有低计算能力的连接设备来说，存储必要信息不是负担。
    
*   **经验证的方法：**PKI 长期以来一直用于为数字身份验证和数据通信提供安全方法，并被公认为一种实用且可扩展的解决方案，可防止设备劫持和数据盗窃。
    

  

**物联网安全的 PKI 与企业安全的 PKI**

**PKI 是一种经过验证的安全方法，在企业 IT 领域有着悠久的历史。但是，用于物联网安全的 PKI 与用于企业安全的 PKI 有所不同。显着差异包括：**

*   **可扩展性和可用性：** 物联网 PKI 代表证书颁发机构需要更高的可扩展性和可用性级别。这些受信任的实体向企业 PKI 所需的设备颁发数字证书。这是因为在物联网的情况下，制造商需要更快地交付更多的证书。
    
*   **私钥生成和存储：** 在企业PKI 中，组织通常使用数字证书来保护 Web 服务器，这些服务器位于大多数人无法访问的受保护数据中心。保护物联网设备的安全是完全不同的，因为这些设备可供公众物理访问。因此，理想情况下，制造商应该在安全的硬件组件上生成和存储物联网设备的私钥，这样它们就永远不会存在于设备之外。
    
*   **证书策略：**与企业 PKI 相比，使用 PKI 实现物联网安全的制造商必须更加严格地遵守证书策略，该策略管理信任和保证级别。这种严格的遵守有助于安全审计并在物联网供应链中建立信任。
    
*   **生命周期管理：**物联网设备上的数字证书的生命周期与用于保护企业 PKI 中的 Web 服务器的数字证书有很大不同。在物联网安全的情况下，制造商必须了解身份将如何随着时间的推移为给定设备提供和更新，并针对任何受损的证书或受信任的根制定明确的响应计划。
    

  

**管理物联网安全的 PKI**

重要的是，要实现 PKI 对物联网安全的全部好处，需要完整的生命周期管理，涵盖从设置和维护可信根和代码签名的程序标准到颁发和撤销证书的所有内容。

鉴于物联网所需的 PKI 规模，在不牺牲效率的情况下保持高水平的可用性和安全性的最佳选择之一是依赖提供 PKI 即服务的 SaaS 模型。此外，通过托管服务模型使用 PKI 可以减轻制造商在功能、性能和安全保证级别方面正确维护系统的负担。因此，他们可以专注于继续将创新的物联网设备快速推向市场，所有这些设备都具有必要的安全级别，以与客户建立信任。

  

**物联网安全是必须的，现在是时候开始了**

物联网不再是一个未来概念——它已经正式到来，连接设备的数量呈指数级增长。随着这些智能设备变得越来越普遍和越来越成熟，物联网安全需要迎头赶上。

迄今为止，物联网设备的安全性有所放松。这种情况源于许多制造商推动将创新设备更快地推向市场并且相对不为人知。但随着物联网生态系统的成熟，出现了严重的安全问题，可能对组织和消费者造成严重破坏。充其量，物联网安全漏洞可能会使设备制造商损失数百万美元并失去信任。在最坏的情况下，他们会使生命处于危险之中。作为回应，新的法规正在出现，这将为物联网安全设置更多的护栏。
