# Linux WPS溢出漏洞分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MDA2NjExMA==&mid=2247486744&idx=2&sn=4a0ed28075fad7a64bf82b07b1da0239&chksm=cf7ba649f80c2f5ffc98573e753540c6a344504a9a198d6231349f27c26f72381867a5d3e6ec&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg4MDA2NjExMA==&mid=2247486744&idx=2&sn=4a0ed28075fad7a64bf82b07b1da0239&chksm=cf7ba649f80c2f5ffc98573e753540c6a344504a9a198d6231349f27c26f72381867a5d3e6ec&scene=27#wechat_redirect)

## 0x00.漏洞描述

在Linux的WPS上，当加载的文件大小达到一定程度且缩放在一定范围50%~100%之间时，添加Text Box，输入数据超过坐标范围，造成WPS崩溃.

## 0x01.影响版本

Version:  < Linux 11.1.0.9662版本

## 0x02.漏洞复现

1.选择一个较大的文件

![](../Images/97ba63020fb1a2adba50b8698ffe2c1d.png)

2.使用WPS加载文件这里选择最新版的WPS 11.1.0.9662版本.

![](../Images/6202141744f23d5e09461279ee59c333.png)3.在页数偏后的PPT中添加Text Box就会触发Crash.  

![](../Images/917a8b6106ef9c25093e605347289dfa.png)

## 0x03.GDB调试

1.通过查看WPS PPT的启动方式wpp，可以确定wpp是通过shell脚本进行启动的

![](../Images/30bda7599773763974f0db12f94ff552.png)

2.查找对应的二进制应用.

![](../Images/263f59403ecaf23fb60e1b8dfd218775.png)

3.使用二进制应用启动对应的PPT

```
 wpp ./WPS-Test.pptx
```

![](../Images/250185164f6b38b1a238dc13bd36f233.png)

4.查找对应的进程ID

```
 ps \-ef  | grep wpp
```

  

![](../Images/81805ec35ced0091dfadf1eb8c2bbdb6.png)

5.使用gdb，根据进程ID进行连接

```
 gdb \-p 22311
```

![](../Images/8c6e9cb40cf98b3418fc5bf774dc7764.png)

可以看到已经成功连接

6.使用明令c，对应用进行放行．在同样的位置输入字符串，触发崩溃.

![](../Images/9e531274ae138372c868c2a9bf3ee288.png)

7.可以使用bt进行栈回溯

![](../Images/0f35063db294e8a9fde872ae4244e012.png)

这里可以看到发生崩溃时，整个栈的情况.

## 0x04.总结

目前官方已修复，请更新到最新版。
