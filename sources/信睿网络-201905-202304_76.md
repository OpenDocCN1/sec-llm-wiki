**0x01.介绍**

Solr是一个独立的企业级搜索应用服务器，它对外提供类似于Web-service的API接口。用户可以通过http请求，向搜索引擎服务器提交一定格式的XML文件，生成索引；也可以通过Http Get操作提出查找请求，并得到XML格式的返回结果。大佬 @s00py发布了solr远程命令执行poc

  

**0x02.影响范围**

Solr版本 5.? - 最新版8.2.0  

  

**0x03.漏洞复现**

**1、官网下载Solr**

  

![](../Images/d5e7096a5b1e6b9260865e56d61fcfaf.png)

  

**2.Windows本地安装Solr**

  

将下载的压缩包进行解压，得到整个Solr

  

![](../Images/78d7994b898aeeb3066b39bcdbead514.png)

  

启动文件在bin目录中

  

```
\# 启动
./solr start
\# 停止
./solr stop
```

  

![](../Images/394c1d7f0f968a9ada097f660af9fece.png)

  

成功启动Solr服务器

  

**3.配置Core Admin**

  

先添加Add Core

  

![](../Images/655e1ecc526e7e701c8e3621faf0dcc0.png)![](../Images/8f5ce18db8c69168a1604fc9d9c548e3.png)

  

将server/solr/configsets/\_default下的config复制到solr/new\_core目录下

  

  

**4.Burpsuite发送POST数据**

  

![](../Images/3719e9ddde7afc91483bff4ed071abd9.png)

成功执行
