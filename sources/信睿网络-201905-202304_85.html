No.48

Miscellaneous-300



解压文件发现需要密码，看见压缩文件里面有一个名字为数字的压缩包，输入里面的数字便可以解压，但是还是会有压缩包，说明里面有很多压缩包，解压要花费大量的时间，这时候我们看到题目的提示是（检查这个，73168.zip）,编写脚本


import os, sys, zipfile

original_file = "73168.zip"

while True:
    try:
        original_file = zipfile.ZipFile(original_file)

        for contents in original_file.namelist():
            password = contents[0:contents.find('.')]

            original_file.setpassword(password)
            original_file.extractall()

            original_file = password + '.zip'
    except:
        break


最后得到了一个wave文件，演奏时会听到一些噪音，字符被转换为媒体流,在音频文件中添加一个Spectrogram图层，便看到了flag为BallsRealBolls

misc_pic_again



此题为一道LSB隐写题，附上解题脚本



# coding: utf-8
from PIL import Image

im = Image.open('flag.png')


width = im.size[0]
height = im.size[1]

a = ""
aa = ""

for y in xrange(height):
for x in xrange(width):

        pixel = im.getpixel((x, y))

        for i in xrange(3):
            aa += str(pixel[i]%2)

for i in xrange(len(aa)):
try:
        a += chr(int(aa[i*8:i*8+8],2))
except:
        break

fflag = open("test.zip","w")

fflag.write(a)
fflag.close()
