## 0x01 漏洞简介

2019年5月14日微软官方发布安全补丁，修复了Windows远程桌面服务的远程代码执行漏洞，该漏洞影响了某些旧版本的Windows系统。此漏洞是预身份验证且无需用户交互，这就意味着这个漏洞可以通过网络蠕虫的方式被利用。利用此漏洞的任何恶意软件都可能从被感染的计算机传播到其他易受攻击的计算机，其方式与2017年WannaCry恶意软件的传播方式类似。

## 0x02 影响范围

1.  Windows 7 for 32位系统Service Pack 1Windows 7（用于基于x64的系统）Service Pack 1   
    
2.  Windows Server 2008 for 32位系统Service Pack 2   
    
3.  Windows Server 2008（用于32位系统）Service Pack 2（服务器核心安装）  
    
4.  Windows Server 2008（用于基于Itanium的系统）Service Pack 2  
    
5.  Windows Server 2008（用于基于x64的系统）Service Pack 2  
    
6.  Windows Server 2008（用于基于x64的系统）Service Pack 2（服务器核心安装  
    
7.  Windows Server 2008 R2（用于基于Itanium的系统）Service Pack 1  
    
8.  Windows Server 2008 R2（用于基于x64的系统）Service Pack 1
    
9.  Windows Server 2008 R2（用于基于x64的系统）Service Pack 1（服务器核心安装）  
    
10.  Windows Server 2003  (全版本)
     
11.  Windows XP  (全版本)
     

**Windows 8和Windows 10及之后版本的用户不受此漏洞影响。**

## 0x03 漏洞修复建议

1，对于Windows 7及Windows Server 2008的用户，

及时安装Windows发布的安全更新

2，对于Windows 2003及Windows XP的用户，及时更新系统版本
