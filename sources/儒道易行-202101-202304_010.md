# 举足轻重的信息搜集CTF

**信息搜集**

## **常见的搜集**

**题目描述:**

一共3部分flag

docker-compose.yml

```
version: '3.2'
services:
  web:
    image: registry.cn-hangzhou.aliyuncs.com/n1book/web-information-backk:latest
    ports:
      - 80:80
```

**启动方式**

docker-compose up -d

**题目Flag**

n1book{info\_1s\_v3ry\_imp0rtant\_hack}

**Writeup**

首先浏览网站

![](../Images/c86dc6a68473e494cbac08a3e4a6bdea.png)

根据提示可知flag由三部分组成，进行敏感信息收集

![](../Images/1837643f417ef21b1066199aa05f29b5.png)

得到敏感目录robots.txt,访问http://192.168.10.21/robots.txt

![](../Images/976e9d0c2abab114d90e03530c4d0c34.png)

得到敏感目录/flag1\_is\_her3\_fun.txt，访问http://192.168.10.21/flag1\_is\_her3\_fun.txt

![](../Images/43efb199d244e598f796ccc4ac288b6d.png)

得到flag的第一部分flag1:n1book{info\_1

在Linux下，用gedit编辑器保存后，当前目录下会生成一个后缀为“～”的文件，其文件内容就是刚编辑的内容。主页文件名为index.php，则该文件名为index.php~。通过浏览器访问这个带有“～”的文件，便可以得到源代码。

http://192.168.10.21/index.php~

![](../Images/afd72ef88eac6522afbcc90481b11655.png)

得到flag的第二部分flag2:s\_v3ry\_im

在用vim编辑文件的过程中可能遇到因为网速不够等原因导致的命令行卡死而意外退出的情况，会在当前目录下生成一文件名为.文件名.swp的备份文件

访问http://192.168.10.21/.index.php.swp，下载该文件

![](../Images/80a7892bdaa1a3a45b541b29f3adab17.png)

用“vim -r”命令恢复文件的内容。恢复SWP备份文件的办法是，先在当前目录下创建一个index.php文件，再使用“vim -r index.php”命令，即可得到意外退出时编辑的内容，

```
touch index.php
cat index.php
vim -r index.php
cat index.php
```

见图

![](../Images/6109d8ff86b5681aeb4b0ba0b32d1e0e.png)

得到flag的第三部分flag3:p0rtant\_hack}'

![](../Images/2542b0a1dd8c8422fdb0774ad973632f.png)

将三部分组合起来即可得到完整的flag：n1book{info\_1s\_v3ry\_imp0rtant\_hack}

## **粗心的小李**

**题目描述:**

看看能不能找到信息吧？

docker-compose.yml

```
version: '3.2'
services:
  web:
    image: registry.cn-hangzhou.aliyuncs.com/n1book/web-information-git:latest
    ports:
      - 80:80
```

**启动方式**

docker-compose up -d

**题目Flag**

n1book{git\_looks\_s0\_easyfun}

**Writeup**

首先浏览网站

![](../Images/c9324faa0cf4a4dec1d79f815920fe22.png)

根据提示可以知道本题是考察git信息泄露的

```
cd CTF #使用完一次后要重新下载
git clone https://github.com/denny0223/scrabble.git
cd scrabble
./scrabble http://192.168.10.21/
ls
cat index.html
```

可以将得到的文件打开

![](../Images/bf74be3ada2dec1e9444836e11bd027e.png)

得到flag：n1book{git\_looks\_s0\_easyfun}
