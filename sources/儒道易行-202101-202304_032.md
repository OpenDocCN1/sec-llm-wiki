# 6.bodgeito通关教程

进入网站整体浏览网页

![](../Images/0ae804337ca5bf339cecd57957656cff.png)

点击页面评分进入关卡

![](../Images/c24fe9c7fabb416e18bc54a043c54bbb.png)

一般搭建之后这里都是红色的，黄色是代表接近，绿色代表过关

![](../Images/d43590eca41a121ea6c4d320c2afac53.png)

首先来到搜索处本着见框就插的原则

构造payload输入

```
<script> alert(/xss/)</script>
```

成功弹窗xss，发现反射型xss一枚

![](../Images/f699e23d6c65dba328854fedd8e4f0a8.png)

就需寻找还有没有xss，一般在网站留言板的地方都会存在储存型xss

点击contact us

构造payload输入

```
<script>alert(/xss/)</script>
```

没有弹窗成功，由此说明网站对用户输入的语句进行了过滤

![](../Images/1515a676c6abbe243ee3e7a62fd6d98a.png)

继续尝试fuzz，构造payload：

```
<scri<script>pt> alert(/xss/)</sc</script>ript>
```

成功弹窗，说明网站会把`<script>`语句替换成空，需要进行双写才能绕过

![](../Images/1ea41d9e8591305558cc564ca8a20d3b.png)

以普通用户的身份查找隐藏的内容

直接使用御剑后台扫描工具进行扫描就可以发现管理员的后台地址，/admin.jsp，

![](../Images/4e4e2a9382a78c2a905b9617adb19ac8.png)

直接访问此地址就进入了管理员的页面中

![](../Images/eb2a8a1a673b83008e6c9f3b5b716d96.png)

我们可以来尝试注册一个用户

```
账号：@<script>alert(/xss/)</script>
密码：123456
```

![](../Images/38a6831927333aced72b49d2fc4dc41d.png)

点击注册，会弹出xss

![](../Images/5d919c4d219f8bde3b68cc9bc07f013f.png)

点击如下所示

![](../Images/6d8f2567d7639d6dbcc55c0b0fd5f3ef.png)

同样会弹出xss

![](../Images/33e5f3d60624bb8c37918328b34b549e.png)

此时再次访问管理员界面会进行弹窗

![](../Images/60446617596dd8df18cbe8be88a5b9ca.png)

登录处是可以注入登录的

账号：'or 1='1

密码：'or 1='1

![](../Images/de4849e1141704996428cdd7d37553b0.png)

万能密码登录

![](../Images/8d7f7cfc3c0f5f715dda60d86f0d3652.png)

购物车内存在水平越权

首先使用

账号：user1@thebodgeitstore.com

密码：'or 1='1

进行登录

查看购物车，当b\_id=0的时候，购物车如下

![](../Images/785810a3965412bf4e26f08479f9317f.png)

修改b\_id=2，进行查看，可以看到其他用户的购物车

![](../Images/82b78425ee3b186f7ed1580a056753a3.png)

修改密码处有个csrf

首先注册

账号：test@qq.com

密码：123456

![](../Images/7a7218a7c62f380ebbcece9bde7d17ee.png)

![](../Images/b5d282a3c6b2234cfd30443077f4b5f6.png)

将密码修改为654321，并进行抓包

![](../Images/dfd91d1184bd4b3543c896d6b9608231.png)
