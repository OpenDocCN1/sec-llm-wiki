# 6.bWAPP XSS

## **0x01、XSS - Reflected (GET)**

### **Low**

输入的内容直接输出到页面中:

![](../Images/105ec234099cd167a10b8e364a114f68.png)

后台服务端没有对输入的参数进行过滤, 构造一个注入xss payload即可:

`<script>alert(1)</script>`

成功弹窗

![](../Images/3db3cb38d4e3c10491ee0889a712ed45.png)

### **Medium**

审查源码可以发现服务端进行了过滤, 但只是addslashes()函数而已(防sql注入), 依旧可以xss:

![](../Images/40446ff5ccbe00fa8b7e686f6abf6ae8.png)

构造一个注入xss payload即可:

`<script>alert(1)</script>`

成功弹窗

![](../Images/76e466ee9944fe6ee555fddca06f3d17.png)

### **High**

审查源码可以发现将所有关键字转换为HTML实体, 是安全的:

![](../Images/2d312d47b70fe2ce23d14c18d12f5303.png)

## **0x02、XSS - Reflected (POST)**

和GET型一样, 只是区别在于GET型的注入直接修改URL的请求即可, POST注入则需要要Post data构造传输post请求:

GET型:

`http://localhost:8080/bWAPP/xss_get.php?firstname=<script>alert(1)</script>`

POST型:

![](../Images/5fc746fff269cebc44ea9992f4a5f98c.png)

成功弹窗

![](../Images/4bb7d29af91db27cbf86bb48db458d56.png)

## **0x03、XSS - Reflected (JSON)**

思考

当查找movie：Iron Man成功时, 就会提示找到:

![](../Images/75def87ed8b41a8d9eaa85dda90980ef.png)

当查找movie：Iron 不成功时, 就会将输入的字符串显示在界面上:

![](../Images/acc7634497937e8cd1e788308b534571.png)

这就造成了可控变量的存在

### **Low**

构造一个注入xss payload即可:

`<script>alert(1)</script>`

错误信息直接爆出来了..

![](../Images/3e4d21fba1b902e0eaa8c75b6dc1e04c.png)

可以看出来是Json注入,

尝试注入json数据:

`{"result": "<script>alert(1)</script>"}`

发现不行; 

![](../Images/92c4450707d56b130926af6634a3e23d.png)

再看报错信息, 继续尝试闭合吧:

`"}]}'; <script>alert(1)</script> //`

发现不行, 查看HTML源码, 发现闭合出去之后是处于script之间的:

![](../Images/e54117e3f8943e429e2b38f778849789.png)

知道原因之后就简单了:

`"}]}'; alert(document.cookie) //`

成功进行json注入

![](../Images/f698d7f7706aab759ccf5a23e155fd7a.png)

### **Medium&High**

将所有关键字转换为HTML实体, 安全:

![](../Images/a860c8df50d01034f9fe0d70e07b04b0.png)

## **0x04、XSS - Reflected (AJAX/JSON)**

通过尝试可以发现本页面是xss\_ajax\_2-1.php, 通过Ajax调用xss\_ajax\_2-2.php完成查询:

![](../Images/19fd16bfe93bbed9f88e9a6c547d8bd0.png)

### **Low&Medium**

有两种方法：

第一种方法：在页面内直接输入XSS的Payload即可

```
<img src=x onerror=alert(1)>
```

成功弹窗

![](../Images/8cc43e420ef4fed8d248d93c53c08ad9.png)

在xss\_ajax\_2-2.php?title=页面也可以直接输入Payload

![](../Images/2402a0cd0c3be8a0e4932775044f979c.png)

### **High**

high等级利用了json的解析:

![](../Images/f4c269a840bac81a75d7402a0ddce6bc.png)

在输入框中注入是直接以字符串的形式输出的, 不会作为html元素或者js执行,

![](../Images/bd3fb0efe9c437dc428be06794355e76.png)

原因就在于xss\_ajax\_2-2.php中对输入进行了HTM实体编码:

![](../Images/bedba2c013e9133f382e71a41722d0fc.png)

## **0x05、XSS - Reflected (AJAX/XML)**

和上一题一样, 同样通过Ajax跳转到另一个php解析,

发现是xml解析:

![](../Images/5667e8bcfffb0121747266577712552e.png)

### Low&Medium

payload:

```
<a xmlns:a='http://www.w3.org/1999/xhtml'><a:body onload='alert(1)'/></a>
```

xmlns是XML Namespaces的缩写,

当加载网站的时候执行alert(1)

![](../Images/8d76711f0da63fc665c55eda2392d3f5.png)

### **Medium**

源码中使用了addslashes()函数来进行过滤，因为有转义，所以该函数无效。payload仍可行

### **High**

源码中使用了htmlspecialchars()函数来进行过滤

## **0x06、XSS - Reflected (Back Button)**

点击Go back按钮, 

![](../Images/7a1ecf0ede6d1d2cfabccec65de84fc7.png)

页面会Header到上一个界面:

![](../Images/800d17b260841cb15c3d3c1f6c71f88f.png)

由于刚刚从上一题到这题, 点击按钮之后就返回了上一个页面

### **Low**

分析源码, 看到是利用了Referer来进行相应地跳转:

![](../Images/0a60bc619d390516dccd067a7b1ec233.png)

观察, 发现可以闭合绕出input标签, 然后加xss:

![](../Images/046323effd27cf65c58102af0240c010.png)

构造payload：

```
Referer:'"><script>alert(1)</script>
```

成功弹窗

![](../Images/1ddfd2b76df16f78b399245f5dd7498a.png)

### High

将所有关键字转换为HTML实体, 安全:

![](../Images/b04d5c8f93a074664f39a415935407d8.png)

## **0x09、XSS - Reflected (HREF)**

web流程大致是先输入姓名, 再进行电影投票:

![](../Images/af95e446e5dcd54509af73f53210de00.png)

![](../Images/9f811e7e5e84d7ed85c80ebfd092330f.png)

发现在p标签中:

```
</p> <script>alert(1)</script>
```

![](../Images/97687a4e122f9863edd6014f644e5f2a.png)

再者, 注意到链接处也可以闭合绕出:

![](../Images/92fc4732beb6b4d0a68d2f534edc0a67.png)

构造payload：

```
1>Vote</a> <script>alert(1)</script>
```

成功闭合

![](../Images/7f14ff029e64738a1c2b436db40cbea2.png)

### **Medium&High**

源码中使用了urlencode()函数来进行过滤。

## **0x0A、XSS - Reflected (Login Form)**

### **Low**

开始先xss盲打一下:

![](../Images/257bfc1bc85e55707d9d1608888a55be.png)

不行, 输入单引号, 尝试sql注入:

![](../Images/4772e0fd0f2a84f1cccb2506618e58ef.png)

发现单引号后面的内容(123)被输出到页面上, 并且应该是没做过滤的。

于是在单引号后面xss:

构造payload:

```
bee' 123 <script>alert(1)</script>
```

![](../Images/7469d33b28b4a277ee646215f4f1036f.png)
