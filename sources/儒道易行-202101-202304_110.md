HTML Injection - Reflected (POST)漏洞url：

*   

```
`http://xxx.xxx.xxx/htmli_post.php`
```

操作同HTML Injection - Reflected (GET)一样，只不过是成了post方式。输入payload：First name: <h1>hello</h1>Last name: <h1>test</h1>![](../Images/071d9424241894b4cd7aad1c897f04e6.png)得到这样的结果![](../Images/321d35dfc4f4b94c83b6ee44c4ca7e5c.png)HTML Injection - Reflected (Current URL )漏洞url：

*   

```
`http://xxx.xxx.xxx/htmli_current_url.php`
```

Level: low正常情况下显示如下![](../Images/0a5c9f2c61e50f38230cc52de2dbd2c5.png)由于url中输入自动转义成urlcode，在burp中还原成原始字符即可构造url：

*   

```
`http://xxx.xxx.xxx/htmli_current_url.php?a=<script>alert('xss')</script`
```
