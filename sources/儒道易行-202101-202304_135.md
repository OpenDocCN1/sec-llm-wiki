# 0x01 NPS隐秘隧道搭建  

# 

1）建立连接运行命令“nps start”启动服务端，如图所示。![](../Images/52e20a41c320190bba11121a43f787ba.png)通过8080端口访问服务端的Web界面，如图所示。http://192.168.1.7:8080![](../Images/adc46a1c3bec262bd9f65174a18e9055.png)输入默认用户名、密码admin、123登录，登录后可以看到默认客户端连接端口为8024，登录后的Web界面如图所示。![](../Images/0e23ec20d3f1aae832b0773afdd5e5e6.png)添加客户端，如图所示，配置唯一验证密钥，验证密钥在从客户端连接到服务端时使用，此处配置为“any”，然后开启压缩和加密传输。![](../Images/7ad0855d07ceca3baf6202cefabca784.png)最后在边界主机运行命令“npc.exe -server=192.168.1.7:8024 -vkey=any”来连接服务端，建立连接如图所示。![](../Images/368d32ec6c416135d41a73bf466d1096.png)连接成功后在攻击机的Web界面可看到客户端上线，如图所示。![](../Images/16a94d57078daa0c28a2de2a73074481.png)2）TCP隧道客户端上线后便可以通过Web界面单击上线的客户端、查看选项、配置隧道，例如，若想访问内网主机的3389端口，则可通过TCP隧道将内网主机的3389端口映射到攻击机的1111端口，单击“新增”，配置目标“192.168.52.143:3389”，配置服务端口为“1111”，TCP隧道如图所示。![](../Images/93b56f79a3f5db917b0f17c47df95bb4.png)TCP隧道建立成功后，即可通过连接攻击机的1111端口来连接内网主机的远程桌面，在攻击机运行命令“rdesktop 192.168.1.7:1111”连接本地的1111端口，隧道的使用如图所示。![](../Images/8eade09914c9492b4a42d574eb858ce1.png)3）SOCKS5代理若想搭建HTTP代理或SOCKS代理，只需选择对应模式，填写服务端端口即可，以SOCKS为例，选择模式为“SOCKS代理”，如图所示，服务端端口为“1234”。

![](../Images/509e87b9c52d061e5577a99a71830982.png)
