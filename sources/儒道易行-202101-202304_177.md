漏洞描述：

默认安装配置完的zookeeper允许未授权访问，管理员未配置访问控制列表（ACL）。导致攻击者可以在默认开放的2181端口下通过执行envi命令获得大量敏感信息（系统名称、java环境）导致任意用户可以在网络不受限的情况下进行未授权访问读取数据

漏洞影响:

Apache ZooKeeper

漏洞复现:

Apache ZooKeeper 默认开放 2181端口 ,使用如下命令获取敏感数据

*   

```
`echo envi | nc64.exe x.x.x.x 2181`
```
