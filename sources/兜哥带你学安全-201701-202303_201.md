# 记忆中的武汉美食（第一篇）

前言

作为一个北漂的武汉人，自从把父母接到北京后，好多年没有回家过年里。过年期间就写些非安全领域的话题。这里介绍的武汉美食并非严格意义上武汉人民发明的食品，有些可能是湖北地区流行的，有些也可能是其他地方传过来的，历史专家就不要纠结了。我写的都是我从小记忆就有的武汉美食，像鸭脖子这类太著名了我就不介绍了。

豆皮

![](../Images/761fc54b6116757d7f2ea7eb37b11276.png)

豆皮，也叫武汉豆皮，将泡好的糯米，放在屉上蒸十几二十分钟油热放肉末，葱姜末炒香，放生抽、老抽、高汤，炒熟后盛出，鲜冬笋切丁焯水，豌豆煮一下，与肉末拌在一起面粉用豆浆调成糊状，醒一会，饼铛或平底锅内放油，放些面糊，摊成薄饼，鸡蛋打匀倒在饼上，饼翻面，糯米趁热平铺在饼面上，在均匀地撒上调好的肉末，榨菜末，小香葱，把饼摊成方形，切四半后翻面，稍煎一下即可。最著名的是武汉市中山大道的“老通城豆皮”。

排骨藕汤

![](../Images/fe7e161278909b49cd175d611bf49318.png)

排骨藕汤是由排骨、藕等主要食材做成的一道菜品亦是一道汉族名肴，属于湖北菜。既有藕的清甜又有排骨的香浓，是温润美味汤的佳品。排骨藕汤鲜香味美，营养丰富，开胃益血，有补气补钙的功效，《舌尖上的中国》都介绍过。湖北人几乎一年四季都会喝藕汤，不过还是冬天喝最带劲，因为武汉是没暖气的，喝口藕汤，寒气全无。我最喜欢的是用口感比较粉的藕熬的，有的人喜欢口感脆的藕。正宗的排骨藕汤都是用陶罐或者瓦罐熬的，现在图省事都是高压锅做主流了。

面窝

![](../Images/7d98a1de68a606391e3f1a0b1797f112.png)

面窝也是武汉的小吃之一。通常只在早餐时间(武汉人称为“过早”)提供。因四周厚而中间薄得干脆成了一个小洞，呈凹状，武汉人不习惯叫它“面凹”，而叫它“面窝”，属于典型咸口的早餐食品，和牛肉粉搭配很赞。讲究的会在面窝上面弄点黑芝麻，就更香了。其实用“面”来修饰“窝”并不贴切，因为它的成分中没有面粉，大部分是粳米磨成的米浆，还要加一定比例的黄豆浆，加葱花、细盐。炸时用的铁勺子，直径约5寸，四周下凹，中央凸起，用另一勺将那种合浆舀入面窝勺，在中间一刮，然后下锅，下凹处因面浆多，所以肥厚，炸成后像个圆圈圈，吃在嘴里，酥、脆、软三种感觉混合。技术好的早点师傅可以将面窝炸成“匡匡”—没有中间的焦脆部分，主要供老人食用；或者将中间焦脆部分炸的比例比较大，供喜欢焦脆的人食用。

鱼糕

鱼糕是去刺后的鱼肉，混合适量的五花肉制成的肉泥，然后放到碗或者其他模具里蒸熟即可。说起来挺容易，去骨，剁碎这两块就非常消耗人力，肥肉和鱼肉的比例不同口味差别也很大。湖北盛产鱼类，很多鱼菜。鱼糕即可单吃，也可以放到汤里或者和别的食材一起炖煮，一般建议和肥肉一起，口感会相互补充。
