# 无处不在的欺骗— 浅析安全攻防演练中的社工案例

社会工程学，在安全攻防演练和真实世界的攻击事件中，是攻击者非常钟爱的一种形式。由于其代价小、隐蔽性强、见效快的特点，往往会被用来作为突破安全防线的利器。本文对安全攻防演练中常见的社会工程学攻击案例进行了简要分析。
**一、****概述**社会工程学（以下简称“社工”），维基百科的定义是“通过与他人的合法交流，来使其心理受到影响，做出某些动作或者是透露一些机密信息的方式。这通常被认为是欺诈他人以收集信息、行骗和入侵计算机系统的行为。”社工的最终目标与其他形式的攻击一样，也是获取更多的敏感信息与更高的系统权限。在真实世界中，随着安全攻防技术的不断发展，攻击者利用技术漏洞的难度也不断提升。与此同时，无数安全事件的经验告诉我们，安全体系中最薄弱的环节永远是人。再严密的安全防护系统，也是由人管理的，而突破人本身的防线，往往比利用技术手段攻击容易的多。因此，无论在安全攻防演练还是真实世界中，社会工程学一直是性价比极高的攻击方式，经常会带来出其不意的效果。在今年进行的安全攻防演练中，我司也发现了多起利用社会工程学进行攻击的案例。由于安全攻防演练的周期短、目标范围大，为了尽快取得突破，攻击队往往会采取五花八门的社工手段。本文总结了安全攻防演练中常见的几种社工方式，从攻击条件、攻击路径、防护措施几方面来进行分析。**二、社会工程学攻击分析****（一）物理场所抵近攻击****1、攻击条件**企业的办公物理场地一般都具有比较严密的授权访问措施，大多数都会采用门禁卡、人脸识别等身份认证方式。再加上配备有保安值守，攻击者正面突破的难度高、暴露的可能性也很大。因此，攻击者在进行物理场所抵近攻击时，一般会选择薄弱点进行突破，可能的利用方式有：（1）混入安保措施薄弱的进出口安保措施薄弱的物理场所进出口，比较容易成为攻击者关注的目标，比如停车场电梯、货物进出通道、消防通道等，凡是可以绕过身份验证环节的进出口，攻击者会考虑采取尾随、伪装工作人员的方式进行混入。（2）伪装访客相较于员工比较完善的授权访问措施，访客进入企业办公场地的流程都较为简单，一般登记后会拿到单独的访客卡，然后由员工带入办公场地。由于没有特别的身份认证机制，访客卡的样式通常会设计的比较简单，仅仅从颜色、文字上与员工门禁卡进行区分。一旦访客携带好卡片后，保安一般不会再去仔细盘查，进出公司就会变得轻而易举。“有心”的攻击者会特别留意目标企业的访客卡样式，通过观察、偷拍等方式，然后仿制出一张仿真度较高的访客卡。接下来，攻击者选择一个进出人流量较高的时间段，尾随其他访客混入即可。**2、攻击路径**以下为物理场所抵近攻击的一般流程：![](../Images/6715391d3d552cd259132bd702c97c07.png)图2.1 物理场所抵近攻击流程图**3、防护措施**（1）加强办公场地出入口（尤其是安保薄弱处）管理，进出必须有严格的身份验证机制。（2）加强访客管理，出入办公场地须有公司员工接送，在公司内需要全程陪同，访客卡可使用芯片卡或定期更换特殊样式，防止被仿制。（3）加强办公场地内部安保巡视力度，主要通道、办公室大门保持关闭而不常开。（4）加强办公环境终端准入管理，采用802.1X等准入协议进行认证，严禁非授权接入；（5）提高个人安全意识，离开电脑及时锁屏，不将口令、敏感文件放置于显眼处；**（二）钓鱼攻击****1、攻击条件**钓鱼攻击是社工最常用的一个手段，传统方式以钓鱼邮件为主。随着安全攻防演练的开展，钓鱼的形式花样频出。攻击队不再会采取“漫天撒网式”的钓鱼，而是更有针对性的选择目标去下手。首先攻击队会进行精心的前期准备，锁定目标对象，然后通过电话\\邮件等，伪装成各种身份获取信任，进而开展下一步攻击。从安全攻防演练的经验来看，可能的利用方式有：（1）  伪装为企业内部人员攻击队通过前期准备，可能会伪装为企业内部工作人员（如系统管理员）发送钓鱼邮件、短信等，诱骗员工点击，获得目标对象主机权限。（2）伪装用户咨询业务\\技术问题攻击队通过目标单位公开的联系方式（如电话\\邮箱\\微信公众号等），联系到相关工作人员（客服\\前台\\业务人员\\技术人员等），然后伪装为普通用户进行业务或技术咨询，构造特定的话术，进一步获取目标单位内部人员的联系方式，或者发送带有木马的文件诱骗对方点击。相较于普通人员，技术人员拥有公司内部系统管理权限，本身也多少掌握着一些敏感数据，被突破后造成的杀伤力更大。（3）伪装猎头攻击者通过公开的招聘平台，注册为招聘单位后，寻找目标单位的相关人员（尤其是技术人员），然后通过获取内部人员的联系方式，发送带有木马的文件诱骗对方点击。**2、攻击路径**以下为钓鱼攻击的一般流程：![](../Images/170c1a46a98a5b534b4f3aa65b97762f.png)  图2.2 钓鱼攻击流程图**3****、防护措施**（1）针对特定岗位人员（前台\\客服\\业务人员）进行专项培训，对外部咨询问题设定统一的话术进行答复，严禁透漏企业内部信息，若有可疑现象需记录并交由安全部门处理；（2）做好安全意识培训，对常见的钓鱼场景进行内部演练，对于多次出现安全问题的员工进行惩戒。**（三）针对供应商\\外包人员的社工****1、攻击条件**在安全攻防演练期间，参演单位都会进行多轮的安全意识培训，采用常规的社工手段，可能不会直接收到成效。因此，攻击队会将目标转向关联供应商或外包人员，旁敲侧击，从侧面获取目标单位的相关信息，可能的突破点有：（1）针对供应商的社工  企业有部分系统会采用云服务或者第三方托管的形式。通过前期收集信息，攻击者锁定这类“离岸”系统，通过伪装为企业内部人员，联系系统供应商\\托管方，可以在不侵入目标单位系统的情况下，尝试获取敏感信息，突破托管系统，以便进行下一步攻击。（2）针对外包人员的社工通过招投标网站、第三方公司案例中获取目标单位的供应商信息，搜集在目标单位常驻的外包人员信息，采用如上的各类钓鱼方法，以期获得目标单位系统权限。**2、攻击路径** 以下为针对供应商\\外包人员的攻击流程：![](../Images/f793f0baa824f324d47df223826604ca.png)图2.3 针对供应商\\外包攻击流程图**3、防护措施**（1）对于供应商\\关联单位，签订保密协议和安全承诺书，不得泄露企业相关信息；（2）对于常驻外包人员，必须与内部员工遵守同样的安全规范，并且从技术上做好信息防泄露、终端防护措施；（3）对于托管在第三方的系统，需要和公司内部系统遵循同样的安全规范，完善安全监测和防护措施，避免成为短板而被攻陷；**三、总结**社会工程学的本质是面向人的攻击，归根到底是由于人的安全意识薄弱而为对手提供了可乘之机。没有完美的技术手段可以防止人出现错误，应该通过建立一种长效的企业安全文化，将安全纳入企业价值观中与业绩一起考核，而不是仅贴在墙上作为展示。正如谷歌公司行为准则中有一条“隐私、安全和言论自由”，重视安全文化建设，才能事半功倍，促成企业信息安全管理落地生根。
