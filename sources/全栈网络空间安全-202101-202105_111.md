# 云安全专题---云安全业界进展

2020年新冠疫情加速了“云计算与安全”、“网络与安全”的融合趋势。企业越来越依赖云计算。但是对于大部分的企业来说，业务上云并不意味着安全上云，“靠山山倒”，想要确保云服务的安全，仅仅依靠或信赖云服务提供商是远远不够的。云计算时代下，整体的IT基础架构发生了根本性的变化，信息安全的防护，越来越多的需要用户（云租户）密切参与，整体的安全责任是由云租户和云服务商共同承担。

企业还需要完成传统思维的转变：“云安全始于云原生思维方式，这种思维方式不再面向网络，而更多的面向身份、数据和应用程序。”

*2021年云安全业界进站如何，下面分享一篇绿盟科技关于云安全业界进展的介绍。*
