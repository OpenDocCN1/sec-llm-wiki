# Windows Server 2012如何实现双网卡绑定

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NTUzOTg3NA==&mid=2247489487&idx=2&sn=7f628f90defcddd99116267edb8127c2&chksm=cf3eab02f8492214bd3526d9df214025fae0cf6fcdf09b22bcdb1f10d4fd7534940710dfac8f&scene=126&sessionid=1681313001#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NTUzOTg3NA==&mid=2247489487&idx=2&sn=7f628f90defcddd99116267edb8127c2&chksm=cf3eab02f8492214bd3526d9df214025fae0cf6fcdf09b22bcdb1f10d4fd7534940710dfac8f&scene=126&sessionid=1681313001#rd)

在windows server 2012 之前我们在服务器上如果要实现双网卡绑定则需要向服务器厂家所要相应的软件，但是现在强大的windows server 2012的到来使我们省去了所有的麻烦，因为操作系统本身就具有双网卡绑定的功能，具体这个功能如何实现呢，下面我们就用实验来为大家说明：

双网卡绑定主要有以下两点好处：

1、实现网络容错：主主模式和主被模式

2、带宽绑定

实验准备：

1、两台windows server 2012服务器。

2、其中一个服务器又两块网卡

3、确保两个服务器网络相通

首先我们开始配置server01的网络：

打开server01的网络适配器：

win+R打开运行命令:

![](../Images/bd76adefc499f9a2c2f4d312f901461d.png "p_w_picpath")

输入ncpa.cpl，点击确定：

![](../Images/4fa65d2896bbb564832719a82ec73157.png "p_w_picpath")

鼠标右键我们所框选的Ethernet0，如下图所示：

![](../Images/c4c60675c9059d12d122e101f8b503a0.png "p_w_picpath")

点击属性，如下图：

![](../Images/8dfbf9a1713e83622a2e95990acb3bff.png "p_w_picpath")

OK，在这里可以看到网卡的一些属性，我们取消IPv4的勾选，然后双击IPv4，如下图：

![](../Images/92de93895b9dd8821d4466dc1f45b6bb.png "p_w_picpath")

在这里我们勾选使用下面的IP地址，然后输入我们要使用得当IP地址，在这里我使用192.168.10网段的，如下图：

![](../Images/7fbeff7f9be65a57b3485666e7f818e6.png "p_w_picpath")

点击确定，如下图：

![](../Images/290ee5a747ec3da65219b82664449717.png "p_w_picpath")系统弹出这个错误是因为我们没有指定DNS服务器，在这里我们点击是：

![](../Images/434f5f058df95ef19d547d46e5401955.png "p_w_picpath")

点击确定，我们在server01端的配置就结束了，下面我们开始配置server02

首先要确保server02有两块网卡：

我们同时按下win+R键：

![](../Images/bd76adefc499f9a2c2f4d312f901461d.png "p_w_picpath")

输入ncpa.cpl，点击确定：

![](../Images/49905194459e51fbfa627be0bcb0b64b.png "p_w_picpath")

有上面这张图片可以看到我们的server02已经有两块网卡，在这里要注意：做双网卡绑定的两块网卡要清楚所有的配置。

在两块网卡上分别鼠标右键：

![](../Images/bc3d36fd04339fab6328c860894d969c.png "p_w_picpath")![](../Images/eeba393746eda55072d9bf434a003bfe.png "p_w_picpath")

点击属性：

![](../Images/78e3d28c24037e1c9c59788f0cbc15c6.png "p_w_picpath")![](../Images/fb7a568fbd516a32e7c97a2fb44bae58.png "p_w_picpath")

在这里我们取消IPv6的勾选，然后双击打开IPv4,如下图:

![](../Images/8aa6b24abf3505196419bb6df999c2ec.png "p_w_picpath")![](../Images/239689d078cf4e302c1607823ad57041.png "p_w_picpath")

这里一定要确定选择自动获得IP地址，下面我们打开服务器管理器:

![](../Images/ce9a218c0e907b65c3324e9a19035cbe.png "p_w_picpath")

点击本地服务器:

![](../Images/1473e4fca8faa6127eece724afddabaa.png "p_w_picpath")点击NIC组合，NIC默认是禁用，我们手动来启用它：

![](../Images/e8834d7c56e9cd2c7734bcdf7d3bd0aa.png "p_w_picpath")打开NIC组合之后我们可以看到我们的两块网卡，然后我们点击任务：

![](../Images/f04b9a63abdf98575488600947e0c934.png "p_w_picpath")

点击新建组:

![](../Images/be19bcde84feb1ba652cb5b3611ae7b8.png "p_w_picpath")

在这里我们给组起名，并选中我们的两块网卡，然后点击其他属性:

![](../Images/694ee26dc05f707143d81061121682dc.png "p_w_picpath")

因为我们没有交换机，所以在成组模式这里我们选择静态成组，然后点击确定：

![](../Images/5a437f8e79f128446838bf582d0aa4fa.png "p_w_picpath")

OK，可以看到我们的两块网卡以及组合成一个，下面我们就打开网络链接：

![](../Images/6c8459bcc0438a30d51214870ca3f5a7.png "p_w_picpath")

从上图也可以看出我们的两块网卡已经成功组合成一块网卡，下面我们就配置一下我们组合的网卡tema1的IP :

鼠标右键tema1：

![](../Images/9572b6d8060badf16dd78e987eb8bba3.png "p_w_picpath")

点击属性：

![](../Images/3bc169b2ff28735b89dacd4dbb01515f.png "p_w_picpath")

这里我们勾选IPv6,然后双击IPv4：

![](../Images/428caefed72bff0b922db24f76f14065.png "p_w_picpath")

这里我们要选择使用下面的IP地址：

注意：这里输入的IP地址一定要和server01的IP地址在同一网段，否则网络不会通：

这里我输入192.168.10.20：

![](../Images/dcfdd78b77b28c58e8805a874f4259c0.png "p_w_picpath")

点击确定

OK ，我们的配置就到此结束了，下面我们测试一下我们的双网卡绑定：

在server01上ping 192.168.10.20 -t:

![](../Images/cd245cf79bfc5e7f5b4e1be0d18bd445.png "p_w_picpath")

可以看到是通的。下面我们禁用server02上的一块网卡：

![](../Images/16f35926df03d00bc705191cd5278103.png "p_w_picpath")

在查看我们的PING命令:

![](../Images/c38b47211fa18e2dc8d7bf56ab06c6f3.png "p_w_picpath")

可以看到我们的ping命令依旧通：

下面我们打开我们所禁用的网卡，然后禁用另一块网卡:

![](../Images/d35d1bf597ef780b7a5724f9715fb659.png "p_w_picpath")

然后查看PING命令:

![](../Images/c38b47211fa18e2dc8d7bf56ab06c6f3.png "p_w_picpath")

可以看到我们的网络依旧是通的。

OK !到这里我们的双网卡绑定实验就成功了。。。。嘎嘎嘎嘎！！！！
