LLMNR 投毒


NetBIOS和Link-LocalMulticast NameResolution（LLMNR）是Microsoft针对工作组和域设计的名称解析协议，主要用于局域网中的名称解析。当DNS解析失败时，Windows系统会使用NetBIOS和LLMNR搜索名称。这些协议只为本地连接设计。

它充当Windows系统中的主机发现/识别方法。LLMNR和NBT-NS（NetBios名称注册和解析服务）用作域名系统（DNS）的替代方案，可以用于识别同一本地连接或网络中的其他主机。

Kerberos 攻击


Kerbroasting


如果已获得一个有效的域用户，用户可以要求KDC提供任意服务需要的TGS。

目前SPN属性可以被设置为特定的用户名，并且TGS使用服务账户的密钥（在该情况下为用户的密钥）进行加密。因此我们可以从自己的机器申请TGS凭据，转储凭据并对其进行离线爆破，以获取该用户（服务账户）的纯文本密码。这就是Kerbroasting。

root@kali: GetUserSPNs.py marvel.local/fcastle:Password1 -dc-ip 192.168.219.131 -request


接下来就可以离线破解凭据，找回服务用户的密码了。

05

白银票据


我们将kerberos身份验证分为两个部分。分别是AS-REQ、AS-REP 和 TGS-REQ、TGS-REP。白银票据(Silver Tickets)是伪造Kerberos票证授予服务（TGS）的票据，也称为服务票据。

在Kerberos认证的第三部，Client带着ST和Authenticator3向Server上的某个服务进行请求，Server接收到Client的请求之后,通过自己的Master Key 解密ST,从而获得 Session Key。通过 Session Key 解密 Authenticator3,进而验证对方的身份,验证成功就让 Client 访问server上的指定服务了。
所以我们只需要知道Server用户的Hash就可以伪造出一个ST,且不会经过KDC,但是伪造的门票只对部分服务起作用。

在发动攻击之前，我们需要针对特定的服务爬取其密码和NTLM hash。我们可以通过对任一服务账户发起kerberos攻击来破解密码来实现。接下来我们创建一个白银票据。


首先，打开Mimikatz并运行如下的命令：

kerberos::golden /user:administrator /domain:jnkfo.lab /sid:S-1-5-21-3178339118-3033626349-2532976716 /target:win10.jnkfo.lab /rc4:1ad9c160bd7ab9cb4b7c890c96862305 /service:cifs

  •  user：用户名，可以是任何用户，即使是无效的也可以。

  •  domain：域名；

  •  sid：域sid，可以通过多种方式获取，whoami /user 就是其中一种方法；

  •  target：目标机；

  •  rc4：目标服务的 NTLM 哈希；

  •  Service：服务名称，如cifs 。

现在就获得了一张白银票据，可以访问win10.jnkfo.lab机器上的共享文件。

7.1  缓存凭据存储和检索


由于Microsoft的Kerberos实现使用了单点登录，因此密码哈希值必须存储在某处才能更新TGT请求。在当前版本的Windows中，这些哈希值存储在本地安全机构子系统服务（LSASS）的内存空间中。LSASS进程是操作系统的一部分并以SYSTEM身份运行，我们需要SYSTEM（或本地管理员）权限才能访问存储在目标上的哈希值。


接下来使用 Mimikatz 来提取哈希值。


由于 Fcastle 域用户是本地管理员，可以用提升的权限启动命令提示符。在该命令提示符下，运行mimikatz并输入privilege::debug以启用SeDebugPrivlege权限，该权限允许与另一个帐户拥有的进程交互。最后，运行sekurlsa::logonpasswords，使用Sekurlsa模块转储所有登录用户的凭据。该操作会转储登录到当前工作站或服务器的所有用户的哈希值，包括远程登录，如远程桌面会话。

7.5  特殊情况下的哈希传递


在某些情况下，获得了用户的哈希值却无法破解它或在哈希攻击中使用它。例如：禁用NTLM身份验证等情况。绕过哈希技术的本质是将NTLM哈希转换为Kerberos票据并避免使用NTLM身份验证。首先假在另一台机器（SPIDERMAN）上作为ppraker用户。通过他的NTLM哈希来访问fcastle用户。一个简单的方法是再次使用来自Mimikatz的sekurlsa::pth命令。
