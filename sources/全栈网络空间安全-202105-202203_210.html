你见过端口0吗？

通过 Internet 发送到侦听端口 0 的主机网络流量可能是由网络攻击者生成的，也可能是由错误编程的应用程序意外生成的，主机为响应端口 0 流量而生成的响应消息可帮助攻击者了解这些设备的行为和潜在的网络漏洞。

许多Internet 服务提供商(ISP) 会阻止端口 0 上的流量，包括传入和传出消息，以防止这些攻击。
