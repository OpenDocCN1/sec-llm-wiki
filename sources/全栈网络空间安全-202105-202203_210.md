# 你见过端口0吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NTUzOTg3NA==&mid=2247495702&idx=2&sn=5b6df6a873fb7f56d6b194b577e20c03&chksm=cf3d4cdbf84ac5cdc6ec44802fd39a6320be273c8049365c93ed64211083433f3910b2457960&scene=126&sessionid=1681312920#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NTUzOTg3NA==&mid=2247495702&idx=2&sn=5b6df6a873fb7f56d6b194b577e20c03&chksm=cf3d4cdbf84ac5cdc6ec44802fd39a6320be273c8049365c93ed64211083433f3910b2457960&scene=126&sessionid=1681312920#rd)

通过 Internet 发送到侦听端口 0 的主机网络流量可能是由网络攻击者生成的，也可能是由错误编程的应用程序意外生成的，主机为响应端口 0 流量而生成的响应消息可帮助攻击者了解这些设备的行为和潜在的网络漏洞。

许多Internet 服务提供商(ISP) 会阻止端口 0 上的流量，包括传入和传出消息，以防止这些攻击。
