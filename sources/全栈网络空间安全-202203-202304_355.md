# 用Wireshark查看IPsec加密报文

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NTUzOTg3NA==&mid=2247501880&idx=2&sn=a0398a027d99ac7d426e7dc98c0800e2&chksm=cf3d74f5f84afde3c66747c22ed26e85bfa08f268cdb679f04b1d0c627b9c6dab0fa7a0e7970&scene=126&sessionid=1681312848#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NTUzOTg3NA==&mid=2247501880&idx=2&sn=a0398a027d99ac7d426e7dc98c0800e2&chksm=cf3d74f5f84afde3c66747c22ed26e85bfa08f268cdb679f04b1d0c627b9c6dab0fa7a0e7970&scene=126&sessionid=1681312848#rd)

IPsec 封装安全负载（IPsec ESP）报文，因为是加密封装报文，wireshark打开后无法查看封装内容。  

有时候我们需要查看封装的报文内容，以定位一些问题。wireshark支持对ESP的解析，只是需要做一些相应配置。

## 一、抓取并打开ipsec报文

通过tcpdump或者wireshark等方式抓取到ipsec报文。打开后，过滤4500端口(ESP标准端口)，可以看到如下所示封装后的报文。  
![](../Images/105e1e6324a98b943ed59b2c65d1cbc4.png)  
此时报文会提示是 UDP Encapsulation of IPsec Packets。并告知 ESP SPI: 0xc0a7ebd8 (3232230360)。ipsec是双向加密，且使用了不同的key，所以反向也有ESP SPI: 0x0caa055e (212469086)。

## 二、获取esp配置

有了SPI，我们就可以在系统上查询相关配置了。  
linux系统可以通过ip xfrm state命令获取到esp相应配置。

```
[root@5-326-sh-qq-dcpe yl]#  ip xfrm state

type

 espinudp sport 4500 dport 19765 addr 0.0.0.0type
 espinudp sport 19765 dport 4500 addr 0.0.0.0
```

通过配置可知

## 三、wireshark上配置esp

wireshark界面操作如下：

### 1\. "Encapsulating Security Payload"右键–>“协议首选项”–>“ESP SAs …”

![](../Images/d4b8784120179dd0cd94e31919a1464d.png)

### 2\. ESP SAs界面操作

在ESP SAs界面上点击"+"，创建一个选项如下。  
![](../Images/9065292ab686048d4c7c81ffddd1750a.png)  
这里的SrcIP和DstIP自然是wireshark里显示的 192.168.43.102和 49.235.117.117。

*   **SPI**：0xc0a7ebd8
*   **Encryption加密方式**: AES-CBC\[RFC3602\]
*   **加密key**：0x6580c3bc833a509132b3e2fb32af88fac3cc25984ee2300a32072f7ec0c3a87a
*   **Authentication**：HMAC-SHA-256-128\[RFC4868\]
*   **Authentication Key**：0x795cf1a66058a9b7e3004a89417699b815676c0e28d450b4d322b52a3fcfc85b

同样步骤配置 49.235.117.117–>192.168.43.102 方向的SA。  
配置完毕后如下图：  
![](../Images/f142b3f31fad700a088768c85c0de7bf.png)

### 3\. 解密后的报文

一般来说，这回就可以看到解密后的报文了。  
部分wireshark需要显式打开 "Attempt to detect/decode encrypted ESP payloads"选项。  
![](../Images/d3efc770274f5665bc83ea70c08a8d96.png)  
然后就可以看到解密后的报文内容，进行相应的查看分析了。  
![](../Images/2fba2922beddb42031ef6f13e66fe3f1.png)
