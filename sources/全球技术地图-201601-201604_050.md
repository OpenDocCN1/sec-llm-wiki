# 美国大数据分析公司帕兰提尔（Palantir） 快速崛起对我国的启示

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651526329&idx=3&sn=f323e8671d7a08f03bcc6ed7168dcac4&chksm=f1826749c6f5ee5f08fd18b1a68c355f576fee5bd8dd89b0d43a42b546162356da1474110767&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651526329&idx=3&sn=f323e8671d7a08f03bcc6ed7168dcac4&chksm=f1826749c6f5ee5f08fd18b1a68c355f576fee5bd8dd89b0d43a42b546162356da1474110767&scene=27#wechat_redirect)

网络技术的飞速发展推动全球进入大数据时代。世界上许多国家已经认识到大数据蕴含的战略意义。美欧等西方国家抢先战略部署，重点发展作为大数据技术研发和创新单元的大数据分析公司。2014年底，美国硅谷的帕兰提尔（Palantir）大数据挖掘分析公司以150亿美元成为全球估值最高的科技初创企业之一。随着大数据技术的进一步发展，帕兰提尔公司在美国的国防、安全及金融等领域发挥越来越重要的作用，势必成为行业的标杆。我们应从中借鉴和学习。![](../Images/6ec47325b86d45de51854b58073680db.png)  

  

![](../Images/49d725bf277c9799c1dc9d0b49087ef1.png)一、帕兰提尔公司在美国的战略地位与日俱增

帕兰提尔公司成立于2004年，最初受美国中央情报局（CIA）旗下IN-Q-Tel投资公司的资助，成为美国中情局布局大数据产业的重要棋子。该公司曾为美国“棱镜（PRISM）”系统的运行提供分析平台，其技术还在寻找和定位本拉登的过程中发挥过重要作用。2008年之后，帕兰提尔公司由于表现卓越，其业务范围得到进一步拓展，开始与不同领域的客户展开合作，其中既有中情局、联邦调查局、国家安全局等美国反恐和军事机构，以及美国财政部、卫生部等非军事机构，还包括一些州和地方政府。据悉，仅2014年美国政府就与帕兰提尔公司签订了近１亿美元的合同。除政府部门外，帕兰提尔公司还为美国金融和医疗保健领域的企业提供数据分析服务，如为著名的摩根大通、对冲基金塞克资本等华尔街金融机构提供用以检测欺诈行为或为贷款进行评估的分析软件。帕兰提尔公司在美国的多个领域中正发挥着不可替代且越来越重要的作用。![](../Images/2f69a956ff67a0322d12d5ad2908513a.png)  

二、帕兰提尔公司的优势及特点

**（一）获得美国多家背景雄厚的风投巨头支持**

美国中央情报局旗下的风投公司IN-Q-Tel是最早资助帕兰提尔的投资公司。该公司是一家非盈利性风投机构，核心业务是为美国中情局、国防部情报局、国家地理空间情报局等寻找高科技公司，来确保这些情报机构的最高信息技术水平。数据分析和数据管理是其重点投资领域。目前IN-Q-Tel是20个数据分析公司和16个数据管理公司的股东。

此外，老虎环球对冲基金以及创始人基金也对帕兰提尔公司投资。同时，美国的亿万富豪肯尼斯·朗格尼和斯坦利·德鲁肯米勒等也成为该公司的重要投资方。

  

**（二）产品科技含量高、定位清晰**

当前帕兰提尔公司共有两大主打产品，一个是帕兰提尔哥谭（Palantir Gotham），主要用于国防和安全领域；另一个是帕兰提尔大都会（Palantir Metropolis），主要用于金融领域。两款大数据分析软件都是基于语义的可视化分析工具，同时具有数据集成、知识管理和分析协作等功效。两款软件的核心理念在于创造一种人脑智能和计算机智能“共生”的关系，发挥两者各自的特长，解决实际的数据分析问题。

  

两款产品均具有突出的能力。一是基于语义的非结构化数据（包括图像、声音等信息）与结构化数据（包括数字、符号等信息）的关联分析能力；二是可视化的数据分析能力。其产品设计思想中突出体现人驱动分析的思想，着重突出人在分析过程中与数据的交互能力。

  

**（三）人性化管理保持公司稳定性**

在美国，工程师跳槽的平均间隔是12个月，而帕兰提尔公司几乎没有人员流失，这就保证了公司软件研发和维护的稳定性。分析其原因，一是在帕兰提尔，工程师就是国王；二是沿袭甚至超越谷歌倡导的“对员工无微不至的关怀”；三是公司所有员工对面试的新员工拥有一票否决权，保证现有员工都会欢迎且接受新的员工；四是多元化的薪酬选择，帕兰提尔提供3种薪水和股票的组合供新员工选择。

三、当前我国大数据技术发展的薄弱环节

当前，我国已开始对大数据进行战略和产业布局，但与发达国家相比仍有较大差距。首先，我国在大数据存储和分析能力方面较为薄弱，相关技术和工具的运用不成熟，例如我国在数据库、数据仓库、数据挖掘以及云计算等相关领域的技术普遍落后于国外先进水平；其次，我国在大数据的应用能力方面相对单一，当前我国政府、企业主要集中在对结构化数据的应用上，对非结构化数据的利用几乎空白。而当今非结构化数据的比重和重要性不断上升，已成为决定大数据应用能力的重要组成部分；再次，我国大数据技术人才储备严重不足，大数据专业人才的缺口已达100万，未来还将进一步拉大。许多专业大数据人才由于公司管理、薪资待遇等种种原因频繁辞职或跳槽，影响了大数据企业的稳定性和技术的研发创新。![](../Images/9764ec59990086bc65bb28d7aa7a4bb3.png)  

四、对我国的启示

**（一）国家应制定明晰的大数据发展战略，理清发展脉络。**美国自2012年起就开始制定和实施明确的短期和中长期大数据发展战略，如《网络空间国际战略》、《联邦云计算战略》、《网络空间行动战略》、《大数据研究和发展计划倡议》等，大数据研发和产业链已成规模化。我应尽快制定明确的大数据发展战略，尽快形成系统、完整的大数据研发和产业链条。

  

**（二）国家应加大对大数据公司的扶持力度，重点关注对关键技术的研发。**帕兰提尔公司的研发进展和规模扩张离不开背后美国中情局的大力支持。从以往的经验来看，美国政府对国内的高科技公司（无论国有还是私有）从不吝啬自己的钱包，通过资金扶持加签合同的方式为高科技公司解决后顾之忧，使其能全身心投入大数据技术的研发。我国应重点扶持国内顶尖的大数据技术研发公司，从政策、资金等方面对其进行支持，与其签订大数据关键技术的研发合同，鼓励其攻坚克难，借此推动我国大数据技术的整体提升。

  

**（三）培养打造一批大数据专业人才。**真正的大数据人才应具备包括技术、数学、商业分析和可视化等方面的专业技能，但当前国内鲜有这样全面的大数据技术人员。这在很大程度上与培养方式有关。国内有关大数据分析应用能力的培养，理论与实践相脱节，很多优秀人才得不到实践锻炼。因此，我们要用好丰富的大数据资源，而目前国内产生大数据最多、规模最大的是企业。高校及科研机构应与企业对接合作，使学员得到有针对性的实践训练，培养全面的数据分析应用能力，打造国家需要的大数据人才。

  

**（四）鼓励大数据企业人性化管理，活跃研发和创新氛围，降低人才流失率。**帕兰提尔采用人性化的管理方式使得技术人员能在一个优越、健康的环境中进行研发工作，研发成果也往往令人满意。相比之下，当前国内多数技术公司因缺乏管理经验、一味追求利润，导致员工始终在高压状态下工作，研发成果质量常得不到保障。因此，应鼓励大数据企业学习国外成功的企业管理经验，在管理层中树立以人为本的管理理念，提供舒适、自主的工作环境，并将企业发展与员工贡献挂钩，这样可以避免大面积的人才流失，同时也能激发研发热情，促进整个行业的技术进步。
