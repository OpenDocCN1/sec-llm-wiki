# 新美国安全中心：下一任美国总统应该这样做

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=404000533&idx=1&sn=b6aa9780c8beaeb53d5b831ccfc4c839&chksm=779dfce540ea75f3cf7c85dfafa6e7ac552d00039d4f6256736501cdd3ccf574f717658fa268&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=404000533&idx=1&sn=b6aa9780c8beaeb53d5b831ccfc4c839&chksm=779dfce540ea75f3cf7c85dfafa6e7ac552d00039d4f6256736501cdd3ccf574f717658fa268&scene=27#wechat_redirect)

近代史上几乎没有任何一个阶段能比下一届美国政府将面对的情形更纷繁复杂。下一任总统上台时将面临一系列国际问题，包括：

  

*   危害美国利益、民众和领土的不断演进的**恐怖主义**威胁，以及伊斯兰极端组织产生的联盟，如伊斯兰国（IS）。
    

  

*   在普京的统治下，愤愤不平且更咄咄逼人的**俄罗斯**再现。普京已经证明了他愿意运用俄罗斯军队、一系列不对称的战略以及能源资源来维护他从乌克兰到叙利亚的意志。
    

  

*   更加强大的、更有能力并且更自信的**中国**崛起。中国一心要成为亚洲的主导力量，并愿意单方面改变现状并违反基于规则的国际秩序。
    

  

*   **中东**不断加深的动乱。4个正在进行的内战（叙利亚、利比亚、也门和伊拉克）造成了自二战结束以来最严重的人道主义危机，激活宗教战争和恐怖极端主义，瓦解国家边界并且动摇了周边政权。
    

  

*   从大杀伤武器到复杂的精确制导弹药、网络武器和无人机，对国家和非国家行为者而言，**危险技术**正加速在全球的扩张。
    

  

同样令人不安的是，美国在过去70年所建构的手段和制度在处理这些问题时变得越来越不适用。

  

在这些非常具体的挑战之外，下一届政府必须应付一个更无形的、艰巨的且更严重的问题：**美国全球领导者的地位将何去何从。**无论这个看法公平与否，在许多朋友、竞争者和潜在的敌人眼中都是真实的。下一任总统需要宣布美国在世界的领导地位的清晰愿景，并采取有力措施来证明美国在坚守承诺并维护自己全球范围内的利益、价值观和同盟的意志和能力。这对恢复信誉和自信——美国对关键盟友和伙伴的支持如铁般坚硬——至关重要。

  

同时，美国有效处理这些挑战的能力正被国会中严重的**政治分歧和政治瘫痪**拖垮。综合预算协议的缺失导致预算控制法案和扣押机制的削减力度大幅提高，在此情况下，下一任总统将无法获得足够的预算用于投资防御、外交和开发工具，而这些都是在竞争更激烈的全球安全环境中保护并提高美国的利益所必要的。通过定期拨款法案还是持续决议案为美国政府拨款这种不确定性已经让涉及国家安全的关键机构付出了巨大的代价，包括国防部和各州政府、情报局和美国国际开发署。缺乏充足的和可预测的经费水平，这些部门无法为现在或将来保卫美国国家安全的能力做出规划并投资。国会在普通防御方面的供给无能正给美国带来真正的、累积的风险。

  

无论下一任总统在致力于国内事务和瞩目的经济问题中有多大的决心（而这些问题有可能对他/她的成功选举有关键影响），国家安全的挑战和危机将不可避免地需要新政府出不少的的带宽、时间和精力。下一任总统应该发挥其聪明才智，从前任总统的**经验**中学习，为现实做准备，而非忽视或拒绝现实。

 

1.  上台时对美国国家安全所面临的挑战、机遇、目标和优势进行清晰地评估，并起草《国家安全决策指示》。
    
      
    
2.  选择国家安全团队，不仅基于个体的经验、专业知识以及资格，还要基于这些个体组成团队后工作的有效性。
    
      
    
3.  从一张白纸开始，重新设计国家安全委员会的人员配置和规则程序。
    
      
    
4.  立即且密切关注任何正在进行的或即将来临的军事或情报操作，尤其是那些将美国人民置于危险境地的行动。
    
      
    
5.  考虑到国家安全议程的工作量和复杂性，要腾出时间让其团队按常规的节奏来设定方向、监控执行和产出、调整进程以及学习中去，尤其是在早期。
    
      
    
6.  制定一个行动和计划议程，传达美国国际领导力恢复的信号和政府的战略行动。
    
      
    
7.  使综合的预算协议成为国家安全首要考虑。
    
      
    
8.  确保国家安全团队在协调的军民关系中投资。
    
      
    
9.  投资国家安全团队人才，无论是受任命的政客、公务员、外事官员、情报专家或是军官。
    

 

**结论**

下一任总统将面对的国家安全挑战是不可避免的。但如果历史可资借鉴，他/她可以更好地为就任做好准备，更有效地处理那些挑战并探索机遇。这些建议并不一定是什么灵丹妙药，但能帮助新总统有力地开展工作，在接管的第一年减少国家安全方面的过失，并大幅提高总统推动国际议程发展、最终强化美国国家安全和国际领导力的机会。
