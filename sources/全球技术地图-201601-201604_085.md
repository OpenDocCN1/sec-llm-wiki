# 威胁地平线2016

威胁地平线2016![](../Images/4b81623998a4e3c533c3cde4c50a8d5d.png)在信任的边缘

网络空间正在迅速发展。组织正面临一个日益复杂的、传统安保方式束手无策的威胁形势。组织必须意识到，无法控制的、最紧迫的威胁广泛存在。  
  

远离网络是不可取的，防御所有网络威胁也是不现实的，现在仍有时间建立针对这些威胁的防御能力。重新评估网络空间运作的假设并让防御能力适应这种新范式是必要的，同时，组织需不断增强对现有威胁的防御能力。  
  

2016年的报告涉及以下主题：

•在网络空间中无人可以信任——组织必须做好在政府不再平衡国家安全与民众和企业的最大利益的环境下运营的准备。

•对公认解决方案的信心崩溃——当许多公认的解决方案不再有效，组织需建立抵御网络威胁的能力。

•网络防御能力的承诺未能兑现——除非首席信息安全官提升其能力，确保能预期CEO的需求并交付日益苛刻的数字议程，否则他们将以失败告终。

威胁地平线2016年度报告预测

1.国家支持的间谍活动成为主流

政府的间谍活动由以前的大多隐蔽转为公开，促使所有国家都加入政府间谍活动的游戏中，造成网络空间交易环境更加无序。  
  

2.互联网业务各自为政

各国将实施区域性的互联网治理，试图在互联网上绘制地缘政治边界。  
  

3.国家干预的非预期后果

当政府试图监管“互联网中属于他们的一隅”时，与过错无直接牵连的企业将越来越多地蒙受间接损失。  
  

4.服务提供商成为关键漏洞

当网络犯罪分子的目标是服务提供商而非企业本身时，服务提供商将成为企业供应链中的关键漏洞。  
  

5.大数据\=大问题

盲目信任大数据的组织将依据错误的或不完整的数据集进行战略决策。  
  

6.移动应用程序成为攻击的主要途径

移动计算的发展，其快速的发展周期和安全考虑上的缺失，将使移动应用程序成为网路犯罪分子和黑客活动的主要渠道。  
  

7.加密失效

计算能力的提升与软件后门相结合，将使得加密失去效力。  
  

8.CEO理解之后，CISO需交付

首席执行官可能会要求首席信息安全官交付其无法提供的防御能力。  
  

9.技能差距变成了鸿沟

技能差距将扩大。对于组织而言，寻求合适的人才在竞争中取胜变得无比紧迫。  
  

10.信息安全未能与新一代人相匹配

以前的技术人才保障信息安全的方法与当前的方式截然不同，给首席信息安全官提出挑战。
