# 兰德：美国如何就网络空间问题与中国进行有效谈判

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=403850613&idx=3&sn=2309f0fcebc47ed2f3086a797b6273f5&chksm=779b368540ecbf93a81ea91c132b38d2587a69b37f1386e09d724ea2616f15d20f8816fa5a95&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=403850613&idx=3&sn=2309f0fcebc47ed2f3086a797b6273f5&chksm=779b368540ecbf93a81ea91c132b38d2587a69b37f1386e09d724ea2616f15d20f8816fa5a95&scene=27#wechat_redirect)

2016年3月22日，兰德公司发布一份名为《美国如何就网络空间问题与中国进行有效谈判》的报告（全长121页），主要内容如下：

  

自1949年中华人民共和国成立以来，中美两国关系就以**冲突、争端和战略上互不信任**为主要特征。近年来，两国间的紧张局势日益加剧。不幸的是，现实世界的这种紧张局势在网络空间中同样存在。实际上，网络空间成为造成中美双边关系紧张局势的所有领域中的最重要因素之一。为了缓解网络空间方面的紧张局面，中美曾于2013年开启正式谈判，但2014年谈判突然夭折，由于当时美方控告几位中国军方官员从事网络间谍活动，中方中止了谈判以作回应。

  

本报告探讨了美国在网络空间这一关键政策领域中，通过协议与行为规范的政策选择来处理中美关系。本报告重点关注两个基本问题：中美就网络空间规范和规则的正式谈判取能否取得有意义的结果？如果能，那么两国在网络空间问题的哪些方面最容易达成一致且达成的交换条件是什么？有两个群体应当对本文的分析感兴趣：一种是关心中美关系的群体，另一种是关心构建网络空间规范尤其是能增进网络安全与自由的规范的群体。

  

主要发现

  

一、中美网络安全观鲜有交叉

  

1.  中美双方对于网络空间的看法很不一致。美国强调网络规范与法治的国际化。中国则坚持对国家主权的维护。
    
2.  在双边议程中，美国最关注的是中国能够取消商业间谍活动，并控制其他网络间谍活动。其中针对美国人事管理局的黑客行为是一个特别的痛点。
    
3.  在双边关系中，美方比中方更重视网络空间问题。中国在网络空间中的行为经常是美方双边议程中的头条；而美国在网络空间中的行为很少在中方双边议程中位列前十。
    

  

二、中美避免针对关键基础设施实施间谍活动有望促成双方达成谈判协议

  

1.  中国似乎对建立防止各国攻击其他国家关键基础设施的规范感兴趣。他们也理解，这样的规范必须禁止对关键基础设施实施间谍活动（从植入攻击中区别间谍活动是很难的）。
    
2.  美国认为这个规范可以发现中方的间谍行为，并希望能有某一后续处理流程（用于处理被发现的间谍行为）。 
    
3.  中国相信他们不太可能发现美方的间谍行为，因此害怕任何可能将己方置于相应劣势的协议。
    
4.  任何正式协议都应该具备双方可信任的程序，这一程序可能需要通过一定的方式来增强中国网络空间划域能力的信心。
    

  

建议

  

1.  美国应该通过将网络规范更直接地与中美双边关系的健康化相联系（强调网络规范在双边关系中的重要性），来与中国进行谈判。
    
2.  中美可通过达成双边协议的形式在网络安全谈判中取得进展，协议内容可以包括禁止攻击对方的关键基础设施，禁止可能造成这类攻击的网络间谍行为。
    
3.  如果中国同意建立证据标准和可信承诺，并同意对违反这些准则的行为提起控诉，作为交换，美国可能会考虑帮助中国构建网络空间划域能力。达成这样的协议需要双方相互认可的评判方法，当一方或另一方违反协议时，可以据此判断是哪方的过错以及过错是什么。
    
4.  在探究交换条件在促成双边协议达成中的作用的同时，美国可通过提高中国继续开展商业网络间谍活动的成本，促使中国同意走到并留在谈判桌前。
