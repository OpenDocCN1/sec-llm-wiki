# 美智库评估中国设南海防空识别区面临8大难题

**关于中国会不会在南海建立防空识别区，美国其实已经给出了答案：只要中国在南海的机场够多够大，下面所说的问题自然也就不是问题。目前，中国在南沙群岛、西沙建设中的人工岛面积都很可观，上述人工岛上的机场一旦建成，加上永兴岛的机场扩建，中国在南海将拥有多个大型机场，可容纳包括大型飞机与作战飞机在内的空军装备，足够设立防空识别区用。但是，应该看到，南海与东海局势不同，建立防空识别区不可能一蹴而就。**

隶属于美国国会的美中经济与安全评估委员会（USCC）于当地时间3月2日发布题为《防空识别区最新进展：东海防空识别区落实情况，南海的未来发展与对美国的影响》的报告，USCC在报告中表示，由于中国现在面临着空域广大，中国在南海还有以下一系列问题需要解决。

![](../Images/077d560f4169e2ae9d6d804f87c16bcd.png)

**机场太少**

因为中国大陆和南海的距离很远，中国必须在南海拥有一些机场来维持中国飞机在南海执行防空识别区任务，而中国在东海的防空识别区距离中国大陆并不远，由大陆起飞的飞机就可以轻松完成东海防空识别区的任务，但南海却由于距离太远，大陆起飞的飞机实在无法覆盖整个领空。目前已知中国在西沙和南沙仅有9个岛屿上兴建了机场，而且这些机场的跑道长度足以起降战斗机。

**有限的雷达设施**

在南海上空建立一个足以覆盖整个区域的雷达网对于前在防空识别区的建设以及监视能力至关重要，据2016年2月美国智库“国际战略研究中心”（CSIS）的一份报告称，中国似乎已经在华阳礁上安装了高频雷达系统，这将“提高中国在南海监测海面和空中目标的能力”。而据2015年CSIS的另一份报告称，中国已经在永暑礁上和永兴岛上建立了雷达设施，而且中国将会在渚碧礁和美济礁上安装雷达系统，进一步扩大其在南海的监视功能。中国可能在华阳礁、南薰礁、东门礁和赤瓜礁上继续兴建雷达设施。此外，中国的早期预警机将成为中国在南海陆基雷达系统的补充，而中国在永兴岛和永暑礁上建设的跑道长度足以起降这类预警机。

**恶劣的海洋环境**

海水的腐蚀会让驻扎在南海的战机加速老化，据美国联邦航空局的研究，在海洋环境中，飞机在空气中接触海水和盐，而且比较潮湿，这样的气候和飞机在干燥的气候下相比更难操作。而且，在炎热潮湿比如在南海的气候下，飞机电气系统出现故障的可能性更大。受到海水腐蚀的影响，中国在南海部署的战机替换周期更短，这让中国不得不需要大量的飞机来保持短时间轮换的频率。而不少中国国产飞机如歼-11战机，其维护间隔本来就不长，再加上海水的侵蚀，维修间隔会更短。但是，中国可以通过定期清洗战机并修建机库来减轻海水对战机的影响。

**恶劣的天气**

海岸被侵蚀不断挑战着中国为保护岛礁作出的努力。虽然中国在渚碧礁和美济礁等岛礁都构建了防止被海浪侵袭的防波堤，而且未来很可能在永暑礁上也建造类似防波堤，但台风很可能会周期性地阻碍中国船只和飞机在南海的活动。

**燃料储备和运输不足**

能够让飞机在南海岛礁上扎住根的重要一步就是建造燃料储备设施。在2015年12月的一份报告中，中国政府和中石化合作在永兴岛上建设的燃油储备设施正在施工，这可以保证一些设施以及车辆和飞机能拥有足够的燃料。但是目前对该设施何时完成，并没有定论。而且这份报告并没有表示中国在其他岛礁上已经建设了燃油储备设施，此外，也并不清楚中国是否有能力输送足够数量的燃料来支持飞机的日常任务。但是据中国空军的一个报告显示，中国首次用一艘液体运输船用17 天时间向岛礁区域运送了航空燃料，而这些油船可以解决中国南海岛礁上燃料的运输问题，而且永暑礁有足够深的港口来停泊这些船只。

![](../Images/02d5abc9cf6a7eb5b569f5f20a04561a.png)  
**永暑礁有足够深的港口来停泊运输补给船只 2015年9月3日****（CSIS）******  

  

**对保障飞行的基础设施建设不足**

中国未来需要建造一系列对飞机的后勤支援系统，比如飞机的掩体和维护设施。一些中国南海岛礁的卫星图片显示，并不明确中国已经修建这类设施来保护自己的飞机。不过据CSIS的报告，中国在渚碧礁和美济礁以及永暑礁上正在建造混凝土工事，这些建筑可以促进对保障飞行的基础设施的建设。

![](../Images/6bca1d49182811b148bbca1d981f2a3d.png)  
**中国在渚碧礁上正在建造混凝土工事 2016年1月8日******（CSIS）********

  

**对人员的基础设施建设程度有限**

如果中国在南海某个岛礁上部署一个团的战斗机，那么这则需要大量的物流、维护和地勤人员来进行支持。而中国虽然可以为这些人员提供基础设施建设，但中国如果要保持在这些岛礁上的建设，那么就需要更多的人员，届时中国未必可以支撑。据CNN2015年5月的报道，中国在永暑礁上建设了一座“军营”，而2016年1月CSIS的一份报告则称中国已经在美济礁建造住房设施。而报告中的一个卫星图像还显示一艘货轮载有“临时住房单位”在渚碧礁的礁湖中出现，国际战略研究中心表示，先前在渚碧礁卫星图片上发现的房屋可以部署200人的部队。

![](../Images/3abdee1600ca35329e955a76e843cdf7.png)  
**据CNN2015年5月的报道，中国在永暑礁上建设了一座“军营” 2015年9月3日********（CSIS）**********

  

**不发达的联合指挥结构**

为了集成执行防空识别区内不同任务的系统，中国可能在南海建立一个联合行动指挥中心（JOCC）。这个中心将负责整合雷达数据，从而可以让中国战机为南海 防空识别区内出现的违规行为作出反应。中国媒体报告建议在西沙群岛建设一个联合指挥系统来协调海防、信息共享和海上执法。这个指挥结构可能会成为一个比较大的框架，从而整体管理南海防空识别区。

不过，这个委员会在长达15页的报告中列出的中国在南海遇到的困难只是一面之词，是美国预设中国在南海的行动。然而实际上，中方在南沙群岛部分驻守岛礁上的建设活动完全是中方主权范围内的事情，合法、合理、合情，不影响也不针对任何国家。而且，中国在南海的主权和相关权利主张是在长期的历史过程中形成的，并为历代中国政府所长期坚持，有充分的历史和法理依据，无需通过岛礁建设来强化。三、中方建设活动的规模、速度与在南海承担的海上搜救、防灾减灾、气象观测、生态环境保护、航行安全、渔业生产服务等方面的国际责任与义务相称。中方的岛礁建设活动不仅不会减损各国在南海享有的航行和飞越自由，反而有利于共同应对海上挑战，为航行安全提供更多保障。
