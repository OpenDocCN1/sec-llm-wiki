# 从巨头企业布局看 3D 打印发展趋势

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651527299&idx=3&sn=273e04644a6cbab8a42974a3eae4b60b&chksm=f1826b73c6f5e265aea3e3e439c41b84cc3c004409b598613c2a1eff04a9e35202f631867b8e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651527299&idx=3&sn=273e04644a6cbab8a42974a3eae4b60b&chksm=f1826b73c6f5e265aea3e3e439c41b84cc3c004409b598613c2a1eff04a9e35202f631867b8e&scene=27#wechat_redirect)

3D打印行业格局正发生变化，在过去的一年，Stratasys和3D Systems两大巨头双双陷入经营困境，规模相对较小的欧洲金属3D打印企业则表现出良好的增长态势。IT巨头惠普正式进军3D打印行业，构建起广泛的合作伙伴生态系统，有望重新制定行业规则。工业巨头已经认可3D打印在灵活性和效率提升方面的能力，将3D打印作为战略性工具加大投入。商业模式的持续创新，带动3D打印技术在更大范围的推广普及。当前，医疗领域的应用增长迅速，成为3D打印重要阵地。

![](../Images/14d7700b62e894d29a5b862ac05728bd.png)  

  

**一、传统巨头业绩受挫，金属打印成为焦点**

  

2015年，主要3D打印企业的收入增长情况喜忧参半。来自美国的两大行业巨头Stratasys和3DSystems的业绩表现都不理想。其中，Stratasys全年的收入为6.96亿美元，比上年降低7%，主要原因是子公司Makerbot在桌面级3D打印机市场的销售不佳。而3D Systems的收入是6.66亿美元，比上年微增2%，收入增速远远低于之前的年份，其中，来自设备和材料的收入分别下降9%和5%，材料收入下降意味着设备使用率不高，出现大量闲置的情况。相比之下，欧洲的金属3D打印企业则呈现逆势增长。德国企业SLM Solution收入增长97%，其财报显示，2015年的客户中，有28%是重复购买的回头客，这也反映出SLM的设备利用率较高，产品得到认可。瑞典企业Arcam收入增长70%，营业利润增加131%，订单量增加38%，该公司在医疗和和航空航天领域的金属3D打印方面具有优势，成为GE公司的重要供应商。英国企业Renishaw收入增长13%,大部分收入来自新兴市场,致力于将3D打印技术带入直接制造领域。

  

**二、IT企业跨界布局，构建3D打印生态系统**

  

IT巨头惠普进入3D打印行业，构建合作伙伴生态系统，重新制定行业规则。2016年5月，惠普公司推出两款3D打印机，瞄准工业级市场，解决传统3D打印机速度慢、精度低和成本高的三大难题。在打印材料方面，惠普采用了类似于苹果应用商店的开放平台策略，鼓励合作伙伴开发与惠普系统兼容的粉末材料，合作伙伴包括赢创（Evonik）、巴斯夫（BASF）、阿科玛（Arkema）等化工巨头。基于材料开放平台，相关的开发商可以对材料自主定价，但是所有的第三方材料都要经过惠普审核，以确保材料与硬件兼容。在软件方面，惠普与业界领先的软件企业合作，以将3D打印技术深入集成到制造流程中，从而让设计到打印的流程更加顺畅。惠普的MJF（多射流熔融）3D打印机集成了Autodesk的开源3D打印平台Spark，充分利用Autodesk在软件方面的优势。惠普的产品也获得了西门子3D打印软件的支持。西门子开发的3D打印软件能够最大限度提高惠普打印机的成型精度，细化打印过程中颜色和材料的控制，助推3D打印从原型制作提升到制造水平。此外，惠普还是3D打印联盟3MF的核心成员。该联盟旨在统一3D打印的文件格式，使用全新的3MF文件格式代替传统的STL、OBJ等文件格式，保障3D打印流程从设计到制造的信息无缝传递。3MF联盟有望改写3D打印的行业规则，在3D打印链上游形成统一标准。

  

**三、工业巨头加大投入，释放3D打印应用潜能**

  

美国通用电气（GE）近年来在3D打印领域频繁进行巨额投资，目标是将3D打印作为公司每个事业部的标准工具。GE最初将3D打印技术用于航空发动机的燃油喷嘴制造，通过一体化成型，在重量减轻25%的同时强度增加5倍。在3D打印的收益得到验证后，GE开始进行全球的3D打印工厂建设，先后设立了位于印度的3D打印工厂、匹兹堡的3D打印技术发展中心（CATA）以及意大利的3D打印生产线等，将3D打印技术的应用延伸到GE的所有业务领域。

  

西门子加大对金属3D打印的投资。早在2015年，西门子下属的风投机构SVC对3D打印公司Materials Solutions发起战略投资，以利用这家企业在金属3D打印方面技术积累改进西门子燃气涡轮的设计制造。2016年2月，西门子在瑞典开设了一家金属3D打印工厂，进行大规模的零部件制造。这家工厂主要对西门子工业燃气涡轮机系列部件进行快速修复，将维修时间从几个月缩短到几周，提升对客户需求的快速反应能力。

  

**四、商业模式持续创新，助推3D打印应用普及**

  

传统的3D打印商业模式一般是依靠设备销售来赚取利润，或者通过设备销售带动材料销售来获得持续的收入。这种模式以购买设备为前提，高昂的设备价格限制了一部分潜在客户的应用。因此，以3D打印创新中心和服务工厂为代表的商业模式逐渐兴起。德国企业EOS近期在北美新建3D打印工厂，以适应公司在北美业务的持续扩张。该工厂设立了一个创新实验室，方便工程师与客户直接互动，以进行材料和系统的测试与改善。工程师可以在现场对打印系统进行定制化的修改，以满足本地客户的特殊业务需求。该工厂还为客户提供基本的实际操作培训，帮助客户快速掌握3D打印技术的应用。3D打印材料企业Materialise与微软合作，开创3D打印与云计算融合的业务模式。Materialise专门开发了Magics 3D打印套件来支持在线3D打印平台，基于这一平台，微软的3D Builder用户能够直接打印模型。此项合作有助于Materialise利用微软庞大的用户群更好的推广业务，同时，也强化了以服务为核心的战略定位。

  

**五、医疗领域增长迅速，成为3D打印重要阵地**

  

医疗领域是当前3D打印应用最广泛、发展最迅速的市场之一。Stratasys认为医疗市场具有重要的战略意义，因此，2015年末，Stratasys专门成立了专门的医疗解决方案组。其产品在医疗领域主要的应用包括：外科手术的工具打印、支持康复的辅助物、高精度的打印还原身体组织和器官，以用于医学教学和帮助外科医生更好地准备手术方案。近期，Stratasys宣布将开展3D打印足踝矫正器的研究，3D打印的矫正器在舒适度、制造成本和定制化方面具有明显优势。3D Systems也十分重3D打印医疗应用。2016年3月，3D Systems在美国科罗拉多州成立医疗技术中心，为公司的精密医疗3D打印解决方案提供支持，包括3D打印医疗器械和植入物、虚拟手术规划（VSP）和浸入式手术模拟。该中心的3D打印制造车间中安装了3D Systems公司已有的全套3D打印系统设备，包括直接金属打印（DMP）、光固化（SLA）、选择性激光烧结（SLS），Colorjet打印（CJP）和MultiJet打印（MJP等）。

  

**六、对我国的启示**

  

> *   **加快产品向高端领域升级。**目前，我国3D打印企业众多，但主要是在低端的消费级产品领域依靠价格获得市场，低价竞争导致企业没有充足的利润和资金进行研发，国内企业很少拥有核心技术和自主知识产权，发展后劲不足。从国际巨头3D systems放弃消费级市场来看，未来整个行业的增长点在于工业级、金属3D打印。因此，我国企业应当加大研发力度，在高端市场进行突破，实现整个行业的可持续发展。
>     
>       
>     
> *   **鼓励创新3D打印商业模式。**当前3D打印应用发展缓慢的原因之一，是用户必须购买设备才能使用此项技术，这造成很多用户观望。因此，应当鼓励3D打印服务中心等创新模式，破解用户对一次性投资的顾虑。国内的先临三维提供区域性专业3D打印服务中心，不仅服务于广大工业企业，同时也带动设备的销售，目前已在全国多地开设了3D打印服务中心。
>     
>       
>     
> *   **探索3D打印新的应用领域。**3D打印的突破，必须从应用入手。相关调查显示，当前我国3D打印应用市场份额仅占全球的10%，而美国占据40%，欧洲占30%。而3D打印实际可应用的范围很广，在任何行业都能找到结合点。因此，我国应当加速推进3D打印技术在不同行业里的应用，带动3D打印产业的发展。
>     
>       
>     
> *   **加速构建3D打印生态系统。**3D打印具备定制化设计、按需定制生产等功能，要实现这些功能，必须依靠复杂的生态系统，确保从数据模型创建到最终成品每个环节的成功。因此需要构建开放式的3D打印生态系统，涵盖3D扫描、设计建模、3D打印技术咨询、3D打印设备、后期处理等链条，汇聚设计师、设备厂商、材料厂商、用户等主体，向客户提供一体化综合解决方案。
>
