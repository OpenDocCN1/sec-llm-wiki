# 不管彼得·蒂尔怎么想，硅谷都不是美国的乌托邦

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651527011&idx=1&sn=fe4e7146915e5fe8112fa4c570b3cc46&chksm=f1826493c6f5ed8579bcca21006e122c82588a05168a942e36c318b384e71f4f219c726d0951&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651527011&idx=1&sn=fe4e7146915e5fe8112fa4c570b3cc46&chksm=f1826493c6f5ed8579bcca21006e122c82588a05168a942e36c318b384e71f4f219c726d0951&scene=27#wechat_redirect)

![](../Images/333d1b6fdf691a88c62d972f6140be4b.png)**全球技术地图****创新丨前沿丨科普丨资讯**![](../Images/4c4f7d55cdb3169ab1a9e26d7cab6113.png)![](../Images/5155d45877d879ca641487c7b9aff5ec.png)  
   **让我们打破乌托邦**在共和党大会上，彼得·蒂尔说，美国已经迷失了方向。  
彼得·蒂尔是PayPal的联合创始人，他在共和党全国大会上描述了一个美国景气失落的时代。  

他声援硅谷，认为其是当今少有的商业天堂。

  

> 当我在硅谷工作时，我很难看到整个美国是哪里出错了。
> 
>   
> 
> 我所在行业，在计算机和软件方面取得了巨大进步，当然也赚了很多钱。
> 
>   
> 
> 然而，硅谷是个小地方。
> 
>   
> 
> 如果驱车向东，到萨克拉门托（加州政府所在地），哪怕只是跨过大桥到奥克兰（旧金山相望城市，以高犯罪率出名），你将无法看到相同的繁荣。
> 
>   
> 
> 这时，你会意识到硅谷有多小。
> 
>   
> 
> 就全国来说，工资没什么增长。
> 
>   
> 
> 美国人的收入甚至比十年前更少了。但是医疗保险和大学学费却在节节攀升。与此同时，华尔街银行家们在给泡沫经济制造膨胀，从政府的基金，到希拉里的演讲费。
> 
>   
> 
> 我们的经济被严重损害了。如果你现在在看我演讲，你比任何华盛顿的政客都看得清楚。你明白，这不是你们所追求的梦想。当我父母来美国找美国梦时（Peter 是德国移民），他们第一个落脚点就是在这个地方：克利夫兰（共和党党代会召开地）。
> 
>   
> 
> 当时我只有 1 岁，就在这里，我成为了一个美国人。
> 
>   
> 
> 那个年代，遍地都是机会。
> 
>   
> 
> 当时我父亲在凯斯西储大学学习工程，就在现在我演讲这个会场前面路的尽头。因为在 1968 年时，世界高科技的首都不是只有一个（硅谷），整个美国都是高科技。
> 
>   
> 
> 这很难让人想起来：我们的政府也曾经是高科技的政府。当我搬到克利夫兰时，防御研究奠定了因特网基础。“阿波罗计划”刚刚把人送到月球——那个人，就是尼尔.阿姆斯特朗，就在这里，在俄亥俄州。
> 
>   
> 
> 未来无可限量。
> 
>   
> 
> 但现在，我们的政府出问题了。我们的核基地还在使用软盘。我们最新型的战斗喷气机甚至无法在雨中航行。如果说我们政府的软件不好用，这都是好听的了，因为很多时候政府的软件甚至根本不能用。
> 
>   
> 
> 对整个国家来说，自完成“曼哈顿计划”是个惊人的衰退。在硅谷，我们不能接受这种无能，我们也无法接受这样的政府。

  
美国计算机行业发达，而且硅谷是个很富有的地方。但若在共和党大会上将其作为数百万人的榜样，显然是不合理的。主要有以下原因：  
   **硅谷在以不平等的方式创造财富**在共和党大会上，有很多关于保护雇员的话题，实际上，硅谷的收入差距是巨大的。  
CNN 5月份的数据显示（注意，科技区域坐落于旧金山湾区，包括圣马特奥和圣克拉拉县）：  
在圣马特奥，收入最高的1%的家庭平均收入是其余99%的46倍，收入差距居加利福尼亚州首位，相当于1989年的三倍。差距第二大的是旧金山，收入最高的前1%的人是其余人的43倍。圣克拉拉这一数据是30.8倍，在加州排在第六位。  
总体来说，科技精英们越来越富有，而其他人获得的报酬却很低。  
   **硅谷正大规模采用外包**在共和党大会上获得蒂尔大力支持的唐纳德·特朗普坚称，他会让工作机会回归美国本土。而特朗普自己的服装生产线却是外包的，硅谷则有过之而无不及。  
我所在的行业在电脑和软件方面取得了很大进步，也赚了很多钱。——彼得·蒂尔  
重要的科技公司如Facebook将内容优化工作外包给美国以外的人，只要工作者有足够的能力，这种工作可以在任何地点完成；谷歌把工程师和IT工作外包到印度；苹果在海外生产iPhone——正如上个月MIT科技评论解释的那样，即使特朗普坚称会改变这种状况，但这种状况基本不会变化，采用外包的公司将越来越多。  
   **硅谷开发的技术可能取代你的工作**没有人知道人工智能应用越来越广的时候会发生什么，但是专家们已经就其对就业市场的影响表达了担忧。  
以谷歌无人驾驶汽车为例，当这种技术应用在汽车驾驶上，数百万人类驾驶员可能将被取代。Facebook的Messenger机器人也将成为鲜花订购的1-800花店这类店铺的客服代表。富士康是很多硅谷公司青睐的外国配件制造商，它已经用机器人取代了六万个岗位。  
所有这些改善都会让世界更好、更安全。但是蒂尔所认为的科技一定会创造更多的就业岗位这一观点让人生疑。  
   **硅谷和政府抢人才**蒂尔谈话中隐含的观念是，政府曾经很先进，能完成“曼哈顿计划”（第二次世界大战时，美国研制原子弹的秘密计划的代号）， 但现在政府已经落后于加州科技专家顾问团。这在一些地区可以得到验证，像脸书和苹果这样的公司采用加密技术，不让司法人员进入。  
但是如果简单地认为这是因为联邦雇员的竞争力不足，那就就漏掉了一个复杂得多的现实——硅谷在和政府竞争顶尖人才。比如你是网络安全专家，加州的科技巨头可以轻易地支付给你比山姆大叔更好的薪资、更多的津贴和更高的职位。但是有很多方法可以改变这一现状——至少某种程度上改变——如果选民想改变的话。  
所以，蒂尔竖起了挡箭牌（“我们最新的战斗机甚至无法在雨中飞行！”），就是为了让联邦政府官员显得很傻。  
尽管已经有很多人在Facebook加州门罗帕克总部工作，但Facebook仍在想办法让更多的人集中到总部来。  
当然，这不是说硅谷的科技进步都不值得庆贺（至少有些是值得的）。但是以一种和我们绝大多数人不一样的方式生活的Facebook早期投资者蒂尔，说这个科技避风港是美国其他地区成功的榜样。我认为是不对的。  

“我们不接受硅谷的无能，我们也绝不能接受我们政府的无能，”彼得·蒂尔在共和党大会上对公众说。

  

这是个不错的观点——但也是个空洞的观点。
