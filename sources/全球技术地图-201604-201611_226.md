# 以大数据创新提升政府管理决策能力

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651526983&idx=2&sn=463642941625237ccc1b9c2c32c48774&chksm=f18264b7c6f5eda1f668e9efa177633942abbdbe1a2fc18d6dec03c157248e355910b6fda58e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651526983&idx=2&sn=463642941625237ccc1b9c2c32c48774&chksm=f18264b7c6f5eda1f668e9efa177633942abbdbe1a2fc18d6dec03c157248e355910b6fda58e&scene=27#wechat_redirect)

随着物联网、云计算的快速发展，大数据蕴藏的巨大价值日益显现。用大数据的技术创新成果服务政府管理决策，将会在决策主体、决策方法和决策过程等方面发生革命性的改变，从而大大提高管理者的决策效率。![](../Images/0e13634e0c89ea0fdd56bc3fd991bbcd.png)  
著名咨询公司麦肯锡研究报告证实，政府部门通过大数据的应用可以大幅度提升生产力和工作效能，有效降低管理成本。据美国医疗管理部门测算，美国每年由于大数据的有效利用而获得的潜在价值将超过3000亿美元，节省的医疗卫生开支将超过8%。欧盟政府部门可能减少15%-20%的行政开支，并在未来10年每年创造1500亿欧元到3000亿欧元的新价值。  
大数据及其技术创新专家认为，大数据的“大”是指大型数据集，即数据量一般在10 TB规模左右，多个用户把多个数据集放在一起，形成PB级的数据量。同时，这些数据又来自多种数据源，并以实时、迭代的方式来实现，即“大数据＝海量数据+复杂类型的数据”。大数据具有海量化、多样化、快速化和价值化等四大创新特征。  
大数据前沿技术的研究，最初是在不同领域采用不同的分析算法，包括机器学习、统计学、图形识别、人工智能、数据库系统等，这些技术现在已逐步发展成强大而复杂的大数据专用工具。目前众多大数据关键技术研发都已取得重要进展，尤其体现在Hadoop、Spark、Elasticsearch和Apache Kylin等关键技术的研发上。  
Hadoop作为大数据平台中最基础、最重要的系统，正在朝着多类型存储介质和异构集群的方向迈进。Spark作为开源大数据项目，目前已支持四种以上语言的接口，当今主流的互联网公司都已部署Spark平台并运行相关业务。Elasticsearch作为可伸缩开源全文搜索和分析引擎，已经能够快速存储、搜索和分析海量数据，其应用也日益广泛，并已应用于Github（用Git做版本控制的项目托管平台）、StackOverflow（一个与程序相关的IT技术问答网站）和维基百科等。Apache Kylin是一个开源的分布式分析引擎，可提供Hadoop之上结构化查询语言（SQL）的查询接口及多维分析（OLAP）能力，并能够支持超大规模的数据分析。  
大数据对政府管理决策的创新  
**（1）大数据在某些方面可使管理决策主体由“管理者和专家”转变为“全部数据”**  
  
随着社会化媒体的增多和大数据应用的不断深入，“全部数据”即“大数据”，能够更加准确地反映数据所隐藏的知识，通过数据分析挖掘，可以反映数据的内在规律。因而，“大数据”正在逐步演变成为管理决策主体之一。  
以美国洛杉矶为例，自1984年奥运会起，美国政府就建立了自动交通监测与控制中心（ATSAC），通过以各种方式采集的大量交通数据，发展自适应实时车流控制系统，实现了交通信号的自动控制和自动管理决策。  
**（2）大数据可使管理决策方法由“经验决策”转变为“数据决策”**  
大数据使决策思维方式发生了根本转变：凡事不问原因，只看数据呈现出的结果，通过对大数据的相关分析，就能够直接得出结论，并直接做出判断和决策。  
美国就是通过大数据来管理全球范围内美国空军在天空、太空和虚拟空间内执行的飞行、甚至是战斗任务。美国空军还通过大数据进行管理车队调度、规划预算、节约成本等复杂任务，使其一年仅在空军车辆采购需求一项，就可节约150万美元。  
**（3）大数据可使管理决策过程从“事后诸葛”向“事前预测”转变**  
全球复杂网络专家巴拉巴西通认为，93%的人类行为是可以预测的。当我们将生活数字化、公式化以及模型化的时候，我们会发现其实大家都非常相似。大数据使管理者的决策思维超越出了眼前的事实，并能对未来做出判断。  
微软纽约研究院经济学家David Rothschild在2012年美国总统大选中，通过大数据分析，正确预测了美国51个选区中50个地区的选举结果，准确率超过98%。2009年爆发的甲型H1N1流感病毒，谷歌公司通过观察人们在网上的搜索记录，在流感爆发的几周前，就判断出流感是从哪里传播出来的，这比疾控中心的判断提前了一两周。  
各国政府运用大数据的创新管理经验**（1）美国从国家战略层面部署大数据研发和政府管理应用**  
美国白宫科技政策办公室于2012年3月29日发布了著名的《大数据研究和发展计划》，成立“大数据高级指导小组”。该计划旨在通过对海量和复杂的数字资料进行收集、整理，增强联邦政府收集海量数据、分析萃取信息的能力，提升对社会经济发展的预测能力。美国国家科学基金会、国家卫生研究院、国防部、能源部、美国国防部高级研究计划局、地质勘探局等6个联邦部门和机构宣布将进行2亿美元的投资，扩充从大量数据中发现、访问、收集、组织信息的工具并提高相关技术水平。同时，奥巴马政府还计划使工业界、大学研究界、非营利性机构与管理者一起利用好大数据所创造的机会。  
为了提高政府的数据管理能力和数据开放能力，美国政府推出DATA.GOV（网址http://www.data.gov/），开放其涵盖约50个细分门类的40余万项原始数据和地理数据。2015年1月美国还宣布将在内华达州里诺工业园区建立全球最大的数据中心，据称该数据中心将耗资10亿美元，整个工程将耗时5-10年时间。在城市管理方面，美国拉斯维加斯市政府通过采取智能数据方式，开发出了一套实时公共事业网络模型。这套模型中包含了地上与地下的所有公共设施，目前已经被用于监测城市地下设施的具体位置和运转状况。  
**（2）英国积极推动大数据在政府管理、公共服务和各行业的应用**2012年5月，英国支持建立了世界上首个开放式数据研究所ODI（The Open Data Institute）。ODI把人们感兴趣的所有数据融会贯通在一起，每个行业的各个领域一方面产生各种数据，而另一方面又可以来利用这些数据。英国政府通过挖掘和利用公开数据的商业潜力，为英国公共部门、学术机构等方面的创新发展提供“孵化环境”。  
英国政府还建立了有“英国数据银行”之称的data.gov.uk网站，发布政府的公开政务信息，希望通过完全公布政府数据，进一步促进大数据技术在科技、商业、农业等领域的应用。   
**（3）日本积极打造公共大数据的开放利用环境**2013年6月，日本公布了新IT战略——“创建最尖端IT国家宣言”。宣言阐述了2013-2020年以发展开放公共数据和大数据为核心的日本新IT国家战略，提出要把日本建设成为一个具有“世界最高水准的广泛运用信息产业技术的社会”。例如在城市安全管理方面，日本在大阪车站安装数量可观的高清摄像机，通过记录车站周围的人流“大数据”，分时段分析通信量及拥堵场所，以预防和应对灾害发生时的避难和疏散引导工作。  
**（4）德国重点关注数据保护和完善相关立法**德国早在2009年就对其《联邦数据保护法》进行了修改，约束范围包括互联网等电子通信领域，旨在防止因个人信息泄露导致的侵犯隐私行为。这部法律对个人数据的合法获取、处理和使用情况做出明确规定。在政府内部，德国政府要求设立“联邦数据保护与信息自由专员”，监督政府机构在保护个人数据方面的行为。在联邦层面以外，德国各州也有自己的数据保护专员，以类似的方式监督各州政府机构的行为。  
在政府管理方面，德国凭借自身较高的信息化水平，通过大型基础数据库和地方数据库的建设，实现在政府管理中运用数据资源来服务公众和服务决策。德国的一些州政府建立了覆盖人口发布、地理数据、矿藏信息等领域的“中央数据库”，并提供相应的分析软件。通过数据分析，州政府的各部门能获得很多有价值的信息，促进了德国政府决策的科学化。  
**（5）其他国家也从本国需求出发加强大数据管理创新**韩国积极建设开放大数据中心，挖掘大数据经济价值。例如，韩国观光公社通过与百度合作，利用百度关于旅游交通的移动流量数据来吸引更多的中国游客。澳大利亚政府发布了公共服务大数据战略，提出大数据分析的实践指南，希望通过大数据分析系统提升公共服务质量，保护公民隐私。法国政府推出的公开信息线上共享平台data.gouv.fr，覆盖了法国国家财政支出、空气质量和法国国家图书馆资源等。法国里昂市还利用IBM公司为该市开发的名为“决策支持系统优化器”（Decision Support System Optimizer）系统，实现了基于实时交通报告来监测和预测拥堵。  
对我国运用大数据服务政府管理的启示**（1）借鉴国外先进的大数据管理经验**当前，信息技术发达国家都相继制定了大数据发展战略，内容涵盖了具体的实施政策和行动计划，并已取得初步成效。发达国家在运用大数据技术创新服务政府管理方面，有很多值得我国借鉴的经验。我们应学习国外在开放性、智能性、价值性、应用性和保障性等方面的经验，不断提高我国运用大数据技术创新服务政府管理的能力。  
**（2）运用大数据服务我国政府管理决策**大数据的创新应用，为政府管理提供了一种全新的思路。随着大数据分析和预测性分析对管理决策影响力的逐渐加大，依据数据进行决策并从中获取价值，将成为政府管理的一种新方式。建议我国政府管理部门能够重视运用大数据技术创新成果，挖掘大数据潜在价值，从宏观调控、市场监管、保护环境、社会治理、公共服务等全方位提升政府服务能力。  
**（3）鼓励开发更多的大数据应用新技术**运用大数据技术提高政府的管理决策能力，需要在大数据基础设施、大数据的分析决策技术以及大数据与各行业的融合技术等方面加强研发。尤其是要加强大数据分析决策技术的开发，如基于人工智能、机器学习、模式识别、数据挖掘、统计学和数据库等技术的研发等。我国应持续支持大数据应用新技术的开发，并将创新成果有效应用于政府管理决策。
