# Facebook打造“Area 404”硬件实验室

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651526957&idx=2&sn=edbfc98c120838f7cbc0485746c86121&chksm=f18264ddc6f5edcb551f35ac4db3611fb64352991a724b8aaaa4235d185bba23fe079a1cf3db&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651526957&idx=2&sn=edbfc98c120838f7cbc0485746c86121&chksm=f18264ddc6f5edcb551f35ac4db3611fb64352991a724b8aaaa4235d185bba23fe079a1cf3db&scene=27#wechat_redirect)

Facebook对外展示新硬件实验室**  
8月4日消息，Facebook本周展示了其最先进的硬件实验室“Area 404”。这座实验室位于Facebook总部的门罗帕克办公园区，面积约2044平方米。负责开发Facebook数据中心设备的基础设施团队、虚拟现实设备Oculus的硬件团队、互联网无人机团队以及Building 8硬件研发部和其他技术设施团队，都将在此工作，其中大多数都是电子工程师。能进入“Area 404”的员工都要遵循最高级别保密协议。  
在“Area 404”，Facebook配备了世界一流的制造设备及基础研究器械，设计师和建模师可以使用电脑软件来设计并塑造硬件的3D模型。可以预见， Facebook的核心硬件产品都将会出自“Area 404”。  
除了Area 404，Facebook近年来还打造了多家实验室，如：西雅图Oculus实验室、加州激光通信实验室、英国Aquila无人机研发中心、巴黎人工智能实验室等。通过这些布局可以发现，以社交网络起家的Facebook正在努力转变成为一家软硬件兼备的科技巨头。  
**私营企业在技术研发方面具有优势 已经成为研发主导者**  
美国国家科学与技术理事会国土与国家安全委员会曾多次表示，进入21世纪以来，曾经在冷战中以政府、官方科研机构主导的技术研发体系已经发生了巨大的改变。  
当下，私营企业在科技研发上投入更多，并还在持续增加，其研发环境、管理模式更受到新一代科研人才的青睐。同时，研发成果在私营企业手中能通过市场化的手段得到更广泛的推广。  
此次Facebook的对外展示也体现出了上述优势。在研发环境方面，充足的资金使Facebook可以为实验室配备能轻松切割钢筋、金属等硬物的喷水式切割机、精确度极高的3D模型打印机等一流设备。在管理方面，Facebook的制度也允许硬件工程师们可以自己安排时间表，来做出他们心目中的完美硬件，同时也允许其在私人时间利用实验室设备搞个人发明。  
目前，美国政府正在积极探索相关政策与机制，谋求与私营企业更好地共享人才、设备等资源，以推动多领域技术突破。
