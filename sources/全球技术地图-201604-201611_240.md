# 以色列推动技术发展，增进国防军部门间协调

**以色列国防军建设“一个网络”军队应对未来战争**  
8月2日，《以色列时报》发表文章称，在第二次黎巴嫩战争后的十年间，以色列军队一直在推动技术发展，建设联合网络增进国防军不同部门之间的协调配合，构建军队的“一个网络”（one-network），使空军和地面部队、海军和情报部队在战场上可以根据接收到的实时信息进行合作。  
以色列通信部队（C41）作战指挥部负责人亚里夫·尼尔接受采访时表示：“如今，我军不再增加预算配置更多的部队、飞机或船只了。相反，我们推动技术发展，寄希望于更好地把现有武力联系起来，通过协作配合提高作战效果。”  
**以色列的“网络中心化国防军”计划**  
过去三年里，以色列通信部队（C41）已经开展了名为“网络中心化国防军”（NCIP，The Network Centric IDF Program）的计划。这项计划将会依托一个联合各个部门的交流平台，打造一支“一个网络”的军队。  
以色列军方认为，战场日益以技术为基础，战争日益以网络为技术，呈现出“网络中心化”的特点。在此前提下，“网络中心化国防军”计划就是要通过建设一套全新的电信基础设施（如，开发全新的虚拟和云端技术，增加数据中心），构建起一个单一的通信网络架构，该架构能够连接天空、太空等多层次战场上的战士、智能武器系统、指挥控制系统、自动点射哨兵系统等多种战争要素，使以色列国防军在沟通、协调方面的能力达到新的高度。  
以色列通信部队作战指挥部负责人尼尔评价该计划称：“所有这些都将会让我们成为一支拥有联合平台的联合部队，分享视频、音频和数据的能力将会成为推动军队建设的主要技术推力”。  
目前，构建军队与国防体系内的统一平台网络成为部分发达国家促进军事实力提升的重要手段。今年5月就有消息称，美国目前正在部署“战术云网络”以提升武器作战能力，而近日雷神公司获得DARPA传感器合同的消息也从侧面印证了这一消息。对此，我国应提早部署，积极应对。
