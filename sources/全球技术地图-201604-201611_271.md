# 干货：如何发现未来科技趋势？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651526876&idx=1&sn=f3ff07cd120d36637561f87f3a81b7db&chksm=f182652cc6f5ec3a052cef99390eb9f727c2999ceb15a1d1a6edb19cc0aa0869dfd3b66fd092&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651526876&idx=1&sn=f3ff07cd120d36637561f87f3a81b7db&chksm=f182652cc6f5ec3a052cef99390eb9f727c2999ceb15a1d1a6edb19cc0aa0869dfd3b66fd092&scene=27#wechat_redirect)

导读无论是创业还是投资，你都想知道下一个重要的科技变革出现在哪里。许多科技界的重要的趋势都来自于不起眼的地方，需要很长的时间才会浮出水面。如何在早期就发现这些想法？

一个想法可能在某个车库诞生，在一些小圈子传播（比如众筹平台或者小众的论坛），然后扩散到铁杆粉丝的小圈子（比如Kickstarter 和 Reddit），一段时间之后，突然爆火了起来。许多初创企业都有类似的经历，包括一些新技术也是如此。

  

比特币就是一个例子，比特币的概念最初来自密码学家当中流转了好几年的一篇文章， 2008年开始引起初创公司的注意。现在，它已经成为了加密货币与区块链协议，不再是小众的事物，纽约时报在内的世界各大媒体都对比特币进行了报道，比特币第一次被提及是在美剧傲骨贤妻当中，时间是四年前。

  

无论是创业还是投资，你都想知道下一个重要的科技变革出现在哪里，如果这个新事物来自于斯坦福或者MIT这样的学术中心，很快就会引起主流社会的注意，但是更多的趋势是来自于不起眼的地方，需要更长的时间才会浮出水面。

  

新想法从哪儿来？  

我们可以通过一些方法来发现那些可能成为主流的重大趋势。这种方法本质上和媒体用来发现娱乐圈的未来新星的方法类似，成为猎奇者、趋势发现者，找对地方、经营正确的信息来源、发现不寻常之处后迅速采取行动。  

  

趋势在哪个地方发送是不可预测的，所以网罗一大批有趣的讨论组或者爱好者社区，无论是线上还是线下）非常重要，它们是新想法的孵化器。

  

你需要做的是持续追踪这些小组的动态，可以通过订阅邮件列表、RSS订阅、关注优质的博客、参加相关会议等等。

  

最好的方法是打造一个“社交网关”，与你所在圈子之外的人建立联系，尤其是那些乐于尝试新鲜事物的早期采用者（early adopters），维护这个圈子，这样一旦有什么新事物冒出来，你很早就可以发现。

  

这些人通常思想开放、有科学的思维方式，有足够的时间和精力尝试新鲜事物，所有具备这类人的群体都是新技术产生的温床，这也是为什么大学非常适合寻找新产品、试验新产品。

![](../Images/3bf39ddbe03b566271cfe445097472b4.png)  

最好的早期采用者群体是外向的、有很多社交关系，因为关系越多，新想法在小群体内的传播就越快。这也是趋势潮流往往由城市的年轻人引领的原因，而不是来自于郊区。  

  

联系紧密的群体既可以是线下，人口密集的城市或地区，也可以是线上的活跃社区。不过这种群体数量实在是太庞大了，所以进一步挖掘想法诞生源头更好，这些圈子一般不大，但是却有极大的影响力。

  

地下丝绒乐队的“香蕉专辑” 是一个很好的例子，这张专辑当年只卖出了 3 万张，但是买了专辑的人很多都成立了知名的乐队。所以尽管地下丝绒乐队没那么知名，但这张专辑却影响了无数的音乐人。

  

在技术领域的乐队是程序员和开发者，所以 StackOverflow 和 Hacker News 就是观察趋势的好地方。如果某个工具或者技术在最好的工程师那里特别流行，那些论坛就值得去关注。程序员的观点往往决定了某项技术是否开发，或者初创企业招聘时要不要把它作为条件。如果没有狂热的开发者早年无私地把大量业务时间倾注在开发上面的话，很难想象 Linux 能取得今天的成功。

  

区分趋势与一时的流行一旦你建立了获取群组和信息源的管道，你应该去关注哪些内容呢？

  

如果有数据的话，任何周增长率能维持在5%的想法都值得关注。第二个好办法是比较领先指标和滞后指标，因为这两个指标的差距往往是快速发展的迹象。

  

像品牌认知、声誉、认知度属于滞后指标。而领先指标来自于想法或产品本身，比如用户的关注度、比替代方案好多少、以及评论如何。阿凡达这样的电影就是滞后指标超过领先指标的例子，电影做了大量的市场营销，但是文化影响却相对较小。

  

早期趋势的这两个指标是不匹配的，比如2011年的比特币或Oculus Kickstarter ，圈子内的用户和开发者群体都十分狂热，认为这是重要的突破，但小圈子之外的人却忽视了这些重要的趋势。

  

发现重要趋势新想法诞生之初，往往是没人愿意为之买单的。那么如何评估其经济影响呢？方法之一看看有多少人会为替代品付费，同时再看看此前类似的东西生产成本是多少。不过颠覆性技术的经济变化是很难评估的。仅出于经济利益就忽视或者拥抱趋势是危险的。  

  

最后，尽管快速的指数式增长是一个好的迹象，大多爆火的事物实际上只是昙花一现，所以重要的是能够选真正重要的，比特币的关键在于技术突破，因为此前分布式信任和资源提供的去中心化努力都失败了，但它利用比特币和区块链协议解决了这些问题。

  

在所有发展快速的趋势当中，只有少数几个有可能真正改变世界。计算机科学领域就更少了，尽管可以采取曲线救国的形式。比方说，共享乘车 app 是一个重要的趋势，但直到智能手机普及之后才获得了更广泛的采用。

  

进入主流  

获得小圈子的接受是不够的。如何区分真的趋势和那些短暂的趋势？一个趋势从小圈子扩散到其他地区，需要一条真正的路径。  

  

在互联网出现之前，这条路径是都市中心。在互联网世界，这条路可能是Reddit 这样社交新闻聚合站点。另一种模式是在相似的机构当中传播，Facebook 很容易就能从哈佛传播到其他学校的一群学生那里，因为大学的架构基本上都是类似的。

  

另一条路径是去一个快速发展的社区。1990年代，Sprite在营销上的重大成果来自于在进入主流之前，先在嘻哈亚文化圈内做广告。这种策略在技术领域同样重要，瞄准一个特定的群体是初创企业的常见策略。2007年移动开发者还是一个小众群体，但现在确是一个庞大的开发者群体，而且仍然保持着许多小众群体的品味和技术偏好。发现趋势也可以采用类似的做法，但过程是反过来的，先找到快速发展的社区，了解它们在使用什么。

  

在时尚界，社交媒体营销往往会找追求时尚的互联网达人，他们时常在Instaram发布食物照片或者活动照片等。

  

在技术界备受推崇的牛人也许是通过开源软件知名，也许是著名的博主，他们都具有影响力。同一原则一样可以应用到群体划分上。比方Python 程序员可能会比 Java 程序员更有影响。

  

逆向思维  
只观察开发者、一线城市人群、大学生群体、你就可以发现不少新想法，但在其他地方也有被低估的事物。游戏圈就是过去几年被低估的一个好例子，尽管没什么声望，但这种亚文化的规模和影响力却十分惊人，游戏玩家一直都是直播以及 VR 这样的新鲜事物的早期采用者。  

  

在一个理想的世界里，未来学家预测出下一个大趋势是什么，但现实世界，充满了复杂性与不确定性。这意味着相对于传统的市场调研或者逻辑推理，追寻新奇事物也许可以成为发现潜在巨大变革的一种方式。
