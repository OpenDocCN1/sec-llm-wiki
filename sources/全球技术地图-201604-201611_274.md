# 关注印尼核电发展，中国核企挑战与机遇并存

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651526875&idx=2&sn=c77e5391fbbd1faf5ba89c65c68a11b9&chksm=f182652bc6f5ec3d2fd2145a3edea21aecc4caafe1707b7df85f1fe0b4847f79107fd75650d0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651526875&idx=2&sn=c77e5391fbbd1faf5ba89c65c68a11b9&chksm=f182652bc6f5ec3d2fd2145a3edea21aecc4caafe1707b7df85f1fe0b4847f79107fd75650d0&scene=27#wechat_redirect)

**印尼将制定核能发展路线图**7月18日《印尼国际日报》讯，印尼能源与矿产部能源保护和新能源总司长利达表示，印尼佐科总统已指示相关部门制定核能发展路线图。佐科总统强调，发展核能必须先制定一个路线图，这也是2025年印尼国家能源总体规划的一个组成部分。![](../Images/662fcbe0e9a91009d7bb185ba3fff210.png)  
路线图主要包括：首先要建设反应堆动力研究和反应堆实验室；其次是要推动国际合作，确保核技术始终保持最现代化。  

利达还表示，将推动所有各方来共同制定路线图，以落实佐科总统指示。

  

**中、俄、日与印尼开展核电技术合作情况**2014年8月，日本与印尼签署协议，将在2007年日、印“就高温气冷核反应堆（HTGR）展开技术合作协定”的基础上拓展协议范围，日本与印尼将共建高温气冷堆。  
  
2014年12月，印尼核工业公司总经理表示，印尼计划兴建首座核能发电站，需要投资额约125亿美元。来自俄罗斯的企业、俄罗斯原子能机构和中国企业都有意在印尼兴建核能发电站。  
2015年6月，印尼国家原子能机构（Batan）与俄罗斯原子能机构（Rosatom）签署了一项关于开展核能合作的谅解备忘录，加强两国在核能领域可持续性的基础设施和教育、研究、培训等合作。  

2016年6月，中国核建集团与印尼原子能机构、东盟能源中心签署协议，将共同就高温气冷堆展开技术合作。

  

**印尼是打开东盟市场的重要支点****中国核企应积极备战**印尼是东盟人口最多、经济体量最大的国家，作为东盟的创始国在东盟扮演着重要角色，而且东盟秘书处就设在雅加达。从资料中可以看到，俄、日两国对于印尼的核电发展给予了极大的关注，并且开展了一系列的布局。随着印尼核能发展路线图的逐步制定，印尼核电市场的企业竞争将变得更加激烈。  
  
2016年4月，印尼提出要大力发展以“钍”为原料的核反应堆技术。有权威机构指出，近年来，中国在“钍”基核反应堆技术上取得重大突破，已经处于世界一流水平。另中国与印尼在基础设施建设，油气勘探开发等方面已经开展了多次合作，中印之间有着稳定的合作基础。  
对此中国核电企业应充分抓住现有中印之间的友好合作关系，以及中国在核电领域的技术优势，积极参与印尼核能发展路线图的制定，提早布局保证中国核电企业在国际市场稳步发展。![](../Images/c8c76832abb2866dc6e1dcdf7daa11a3.png)
