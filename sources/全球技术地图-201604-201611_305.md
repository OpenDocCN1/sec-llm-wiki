# 未来不会突然到来：为何我们需要高瞻远瞩？

Rincón****全球技术地图编译**【布拉格，Malostranská地铁站】我急匆匆地去买票，一则售票公告让我留意到那排售票机，由于长时间受到硬币的摩擦，售票机右侧划痕遍布。一般来说，如果第一次投不进去，那么多投几次就可以了。这些售票机已服务多年，大街上也有类似的机器，布拉格的交通系统非常方便，整合了地铁、有轨电车和市郊列车。售票机用起来并不复杂，通常的步骤是投币——听到响声——取回车票和零钱。然后，只需要在车票上盖章标记日期和时间即可搭乘火车。如果检票员检查，出示这张票就可以避免被罚款，不过7年来我只见过一次检票员。  
  
而新的地铁站，比如Nádraží Veleslavín，那里的售票机则更加数字化、现代化。它会发出滴滴声，而非老式售票机的那种哐啷声。我住在智利圣地亚哥，大概是南美最发达的城市之一。最近几十年，智利发展迅猛，从基础设施、连通性和技术等方面均可体现。然而一眼望去，这里任何一个地铁站的工作人员要比Malostranská地铁站售票处的多，他们无聊地看着监控录像，而检票员时不时来抓没买票的乘客，这让我想到了哈雷彗星。圣地亚哥的Manuel Montt地铁站，售票处有4个工作人员，包括检票员和安检人员。在高峰期，排队买票到通过闸机期间都非常拥挤。这里有两个大型售票机，很先进但几乎没有用过。无论发生什么，它们就在那儿，静静地注视着这一切。  
**未来并非马上就来。**由于文化、制度或者经济方面的原因，有时它会迟到，但它从未止步。几十上百年的趋势很明晰，每年的趋势也同样清晰，自动化时代宣告着每天将**有越来越多的劳动力被机器设备替代**。至少他们工作和生活的方式会彻底改变。如今这种改变更快，昨天看来还是幻想，到今天就可能成为现实。软件、机器视觉、自动化和算法将替代数百万工作岗位，可能是完全替代，也可能是与人类劳动力合作。被替代的不光是那些简单的工作。在《机器人崛起》一书中，马丁·福特说，更确切地说，只要是“可预期的”工作都会被替代。我们谈论的是**人工智能**，这是个沉重的话题。![](../Images/3a288ffca89a884715c4438948fc9414.png)  
不用在YouTube上搜索Boston Dynamics机器人或人形机器人Sophia、洛杉矶的全自动餐厅Eatsa、无人送货机、遥控汽车或Chair Force（这个词原本用来形容美国空军飞行员在座位上就可以侦查、巡逻和攻击目标，这里表示一切都自动化之后的一种工作状态）。别想那么远，拿起iPhone，长按home键，Siri会为你服务，虽然她的智能化程度还不高，但她正在努力做你的私人助理（不要骂她，她能感觉得到）。  
Klaus Schwab在《第四次工业革命》中提到，放射科医师、律师、邮递员，甚至是医生这样的职业都可能消失。我对朋友Gabriel说，“关于就业的公开辩论已不再重要，因为那已经没有意义。我们将不再讨论雇佣男女比例问题，而将讨论是雇佣人还是雇佣机器。”Gabriel说，我们将讨论“雇佣人机比”的问题。来自Momentum Machine的Alexandros Vardacostas直言，他设计的机器不是要让雇员更有效率，而是完全替代雇员。这真可怕，但在某种情况下，这些都是可能发生的。劳动者们需要改变、适应和重新定位。那些没能预料到、也没能做好准备的劳动者的处境将非常艰难。问问差点让我滞留机场的法国出租车司机，他们几个月前在巴黎罢工，抗议Uber。智利的出租车司机也在街上抗议Uber，天真地以为他们能阻止这一趋势，打败这些新的商业模式。  
最后做个总结，我不知道各国知识分子、媒体人、商界人士、工会和政界领导人能否高瞻远瞩。**一个有远见的人并不是天才或者预言家**。他们只是知道如何解读他们周围环境中的信号，并做出相应改变。他们具备以塞亚·伯林所说的“政治判断”，这是一种智力上的又特别实用的能力，能够观察并理解周遭复杂环境。有远见的人又是极其负责任的，他或她会把这些问题放进日程表，并据此不断推进，他们会在分析和决策中考虑到这些问题。**当自动化、机器人和物联网深刻影响产业、教育、家庭甚至是国家时，世界会变成什么样？**我们的教育在努力培养现代社会所需要的技能，尤其是能提供创造性、创新性和适应性方面的技能吗？我们要讨论当代的政策和改革，还是固执地坚持过时的逻辑？古语有云：“**凡事预则立，不预则废**”。现在是凌晨四点，我该休息了。我的手机app提醒我，我的睡眠习惯需要改善。
