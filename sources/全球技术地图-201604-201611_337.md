# IBM计划在2018年推出新超级计算机Summit

IBM即将推出世界上最快的超级计算机Summit

6月28日，IBM透露，即将推出Summit超级计算机，其计算性能将让中国太湖之光超级计算机相形见绌。

  

IBM的这款超级计算机被称为Summit，预计将在2018年初提供给美国能源部橡树岭国家实验室，计算性将能达到200petaflops（petaflops：每秒千万亿次浮点运算），比原定指标提升四分之一以上。在最新全球超级计算机500强榜单中，中国“神威·太湖之光”超算夺魁，其性能指标是93petaflops，峰值性能是124.5petaflops。

IBM、NVIDIA合作提升Summit超级计算机性能

美国向来注重超级计算的研发，在过去的几年间，美国国防部高级研究计划局（DARPA）曾多次巨资赞助IBM、Intel、NVIDIA、AMD等芯片厂商，推动下一代高性能计算技术的研发工作。

  

而此次信息中的Summit超级计算机，就是2014年启动的、IBM和NVIDIA携手提升美国超级计算机性能项目的产物。此前，由于越来越多的企业和研究人员使用美国橡树岭国家实验室的超级计算机Summit进行计算和研究，该超级计算机早已不堪重负，亟待升级。

  

新的Summit超级计算机采用IBM Power9微处理器和NVIDIA Volta GPU进行数学协同处理，将有约3400个节点，每个节点将拥有至少500GB相干内存，以及800GB非易失性内存。为了给客户提供很高的I/O吞吐量，节点将使用Mellanox公司的双轨InfiniBand EDR连接以无阻塞胖树架构互联。建成后，Summit将可以解决一些世界上最紧迫的计算挑战。

全球超算竞争日趋激烈

目前，超级计算机的用途已不仅限于尖端科学技术，对医疗、生物、农业、气象等众多领域均有重要意义，是推动技术革新、引发产业革命的关键所在，全球主要国家都在加紧在超算领域的研发与应用。

  

在中国连续多年在超算排行榜中夺冠的情况下，2015年美国宣布对华禁售超算芯片，但这也在实际上推动了中国的自主研发，今年榜首“太湖之光”就是最新成果。而此次IBM透露的信息一旦成真，新Summit超算将超越“太湖之光”。可以预见的是，在未来，超算领域将再次出现“你追我赶”的激烈竞争局面。
