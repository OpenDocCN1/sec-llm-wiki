# 日本政府加强对海底石油天然气的勘探开发

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651526668&idx=3&sn=87eee464b0711f3d0029e56f6acb5480&chksm=f18265fcc6f5ecea5abbd8095b8992b204a5b5135c27979a458a2901af1cfb30053810a2f1c2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651526668&idx=3&sn=87eee464b0711f3d0029e56f6acb5480&chksm=f18265fcc6f5ecea5abbd8095b8992b204a5b5135c27979a458a2901af1cfb30053810a2f1c2&scene=27#wechat_redirect)

据报道：日本经济产业省再次确认方针，将加强对日本周边海域石油、天然气的勘探及开发（以下简称“加强海底方针”）。随着勘探技术的提高，世界各国接二连三发现了新的海底油田，为此日本制定了以2017年1月为目标的“加强海底方针”。具体来说，经产省提出以石油、天然气埋藏可能性较高的北海道海以及岛根、山口海域周边为中心，调查近2万平方公里的新区域。此次经产省“加强海底方针”将通过改良国有勘探船以提高其勘探能力，向企业贷款支援民间开发等方式来具体执行。此外，日本政府还就目前为止勘探收集的约4.3万平方公里的调查资料展开了二次检查，检查采用精确度更高的图像解析系统，以判别其中是否存在石油、天然气。

对于此次日本政府加强对海底石油天然气的勘探开发，中国重点关注以下几点内容：  

  

首先，关注韩国、俄罗斯对日本政府此次“加强海底油气方针”的态度**。**韩国方面，日韩两国就位于岛根县隐岐列岛西北157公里处的日本海域一直存在争议，两国曾多次交涉但并取得实际结果。此次日本“加强海底油气方针”明确提出了要加强在岛根海域的海底油气勘探，韩国的态度将直接影响日本“加强海底油气方针”是否能顺利执行，对此中国应高度关注。俄罗斯方面，在早期的日报中曾对“俄罗斯将将强与日本在远东地区的油气合作”进行过研究，此次日本“加强海底油气方针”中提到了要加强在北海道海域（与俄萨哈林州（属远东地区）地理位置上靠近）的油气勘探，俄罗斯或将借此机会开展与日本在海底油气资源勘探的合作，对此中国应高度关注。

  

![](../Images/524887e6b5542a14b2b98c8fd343baf6.png)  

  

其次，日本提升海上油气资源勘探开发技术的核心目的是提高石油天然气的自给率。日本超过90%的石油天然气需求通过进口来满足，为了降低其能源对外依存度，日本瞄准了海上油气资源的勘探开发。曾有研究机构指出，日本在海上油气勘探船相关技术上处于世界领先地位，此次“加强海底油气方针”再次强调要改良日本勘探船并提升其勘探能力，以上内容均表现出了日本对于海上油气资源勘探开发技术的重视。同时若日本具备了深海油气资源勘探开发技术，结合早期南海课题中有关“日本油气企业与马来西亚国油在海上油气资源勘探开发有着较为良好合作关系”的研究，一旦日本企业将深海勘探技术输出到马来西亚，将对南海问题带来一定影响，对此中国应高度关注日本海上油气资源勘探技术提升方向。
