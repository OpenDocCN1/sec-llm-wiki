# 美国政府传唤华为，中美技术安全猜疑加深

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651526596&idx=3&sn=e6c4156f1aadde4d2bd2eb7b26f60699&chksm=f1826634c6f5ef229308e85fc29b1f078b6eb749e9985ee900bbd365ae593a3a410e84b373ce&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651526596&idx=3&sn=e6c4156f1aadde4d2bd2eb7b26f60699&chksm=f1826634c6f5ef229308e85fc29b1f078b6eb749e9985ee900bbd365ae593a3a410e84b373ce&scene=27#wechat_redirect)

美国政府发出行政传票，要求华为提交与被制裁国家交易往来的所有记录

6月2日，外媒报道，美国商务部已向华为发出行政传票，要求华为提交在过去5年内，将美国技术（科技产品）出口或再出口至古巴、伊朗、朝鲜、苏丹和叙利亚等被制裁国家的所有信息。

  

此次调查旨在确认华为是否违反了美国的出口限制。传票信息显示，美国商务部还试图获得华为通过幌子公司或壳公司间接向这些国家发货的证据。长期以来美国一直禁止向伊朗、朝鲜、叙利亚、苏丹和古巴等被制裁国家销售含有美国技术超过一定百分比的产品。

![](../Images/964dcb286a54b43194746f0a26eadccf.png)  

此次向华为发出的传票为行政传票，这意味着它并非刑事调查，美国商务部尚未指控华为存在任何不当行为。  

  

此次对华为的调查，是美国继3月份对中兴调查后的又一次“出口禁令”调查。3月初，美国商务部曾以中兴绕开美国出口禁令向伊朗出口美国通信科技产品为由，对中兴做出口限制禁令。虽然随后美国商务部暂时停止该出口限制，但这份截止日期为6月30日的“临时许可”，说明此事结果仍难以预料。

  

对中国企业“调查”增多，美国对中国企业技术猜疑加深

除对华为、中兴的“出口禁令”调查外，美国在近期还对中国其他科技企业进行了其他类型的调查，包括对包括中兴、联想在内全球多家电子产品厂商发动了“337调查”，以确定其是否存在专利侵权行为；美国证交会对阿里巴巴进行会计调查，调查其财务数据统计问题。这些调查在实际上，对被调查企业的平稳运营造成了影响。

![](../Images/dec55e9e415313c1c910defd43650b30.png)  

而接连对中国两家通信技术巨头华为、中兴的“出口禁令”调查，则显示出了美国对中国技术企业的猜疑。相应的，中国方面在“斯诺登事件”后，出于信息安全的考虑，在政府采购中更多地采用国内厂商产品，并且打压IBM、思科等美国企业在国内市场的优势地位。  

  

在中美之间的技术猜疑的背后，都体现了两国对于技术安全的担忧；同时，也反应出两国在技术领域的博弈不断加剧。
