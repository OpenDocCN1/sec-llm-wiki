# 美国核武器技术转移到民用，中方应高度关注

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651526596&idx=2&sn=ad7a7a4f70b182e3be1d3b6514e02166&chksm=f1826634c6f5ef22083292435a6e78681da77539d6de8dd120f4df294ac121b99fd0aa27e926&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651526596&idx=2&sn=ad7a7a4f70b182e3be1d3b6514e02166&chksm=f1826634c6f5ef22083292435a6e78681da77539d6de8dd120f4df294ac121b99fd0aa27e926&scene=27#wechat_redirect)

据报道，美国国家核军工管理局（NNSA）的国家实验室表示：目前一项用于核武器计划的技术在其他领域得到应用。桑迪亚国家实验室研究人员Paul Vianco和他的团队因薄膜、金属纳米层技术获得嘉奖。用该薄膜代替铜导体大大减小了电路间的间隔，这样有利于减小电子部件体积，减轻其重量，并降低能耗。这项技术在传感器和电子通讯领域有着十分显著的应用潜力，该技术的公开使美国电子行业大大受益。

  

公开资料显示，2012年10月，美国国防部技术转移工作小组编制出台《2013—2017未来五年国防部技术转移战略与行动规划》，用于指导未来5年国防部技术转移工作的开展。该规划确定了三大重点措施，全面审查与改进技术转移与转化工作：①进行全面的技术转移最佳实践范例调查；②优化公众获取美国国防部实验室资源的环境；③促进国防科研机构与地方和区域机构建立更为紧密的联系。

美国核武器国家实验室曾有在能源领域开展合作的案例：  

  

洛斯阿拉莫斯国家实验室在美能源部的主持下，与GE发动机公司进行合作，开发供运输用的燃料电池动力系统。这种系统可将化学能高效转为电能，进而使不同交通工具可以进行长距离运输。

  

桑迪亚国家实验室专为美国核武器系统开发电池，该实验室曾参与美国能源部先进电池开发项目，并作出了卓越的贡献。

  

除在能源领域外，美国核武器国家实验室在先进无损检查技术、智能公路系统、飞机发动机技术、超导技术、大型容器探测技术等领域与多家公司进行合作，为各项技术的推进提供了极大的支持。

  

美国最新通过的能源草案中提到要重点研发大型储能设施（光伏风电的关键技术）。目前公开的资料显示，美国核武器技术国家实验室有过参与储能设施研究的背景。将两者结合起来看，美核武器技术国家实验室很有可能参与大型储能设施的研发，将先进的武器技术转移到其中。

  

对此我们建议：中国应高度关注美国国防技术到民用的转化情况，尤其是在能源领域。同时中国可借鉴美国在国防技术转移和转化方面的经验，发掘中国国防技术转移转化到民用的机会，增强中国企业竞争力，进而为保障中国能源安全提供更大助力。
