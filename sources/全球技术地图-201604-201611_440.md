# 美军计划部署“战术云网络”提升军事能力

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651526544&idx=1&sn=00e1082878217928f21a901da626e513&chksm=f1826660c6f5ef768d56ee74d53d448a8f6fc1a7f480e6b093ff1666f564b8d663b5ad622d0a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651526544&idx=1&sn=00e1082878217928f21a901da626e513&chksm=f1826660c6f5ef768d56ee74d53d448a8f6fc1a7f480e6b093ff1666f564b8d663b5ad622d0a&scene=27#wechat_redirect)

“ 美国正在借助信息技术增强军事能力近段时间以来，各类信息表明，美国正在借助信息技术增强军事能力。增强的途径主要包括两个方面，直接提升网络攻防能力和依靠信息技术提升现有军事力量作战能力。  
一方面，提升美国网络攻防能力，主要方式是培养美国网络力量，扩充美国网络部队人员数量和技术实力，研发网络攻防技术；另一方面，依靠信息技术对原有空军、陆军、海军及其他军事力量进行改造升级，包括对现有网络和通信系统的安全升级，先进武器的研发和部署，还包括侦查等军事技术的研发等。  
网络战方面，最近的一个例子就是不久前美国国防部高级研究计划局（DARPA）的X计划网络战项目。此项目旨在将军事科学及计算机科学引入网络空间之中，为网络空间作战环境下的士兵打造首套通用性作战规划平台系统，可辅助制定军事决策、筹备和执行任务。  
“ 海军计划部署“战术云网络”提升作战能力而依靠信息技术对海陆空等军事力量的改造方面，美国也在同步持续推进。根据美国海军研究所网站发布的信息显示，美国海军正在构建一个进攻性的“战术云网络”，这一网络能够将来自卫星、飞机、舰船、潜艇和武器本身的多源信息整合并进行分享，组合成一个致命的“杀戮网络”。  
海军少将马丁•达拉称，依托该计划，飞机、舰船等作战单元能够针对目标进行更为有效的武器部署。他称，该项技术将赋予美国海军“全领域进攻性反舰战能力”，能够利用地面、空中、水下的全区域作战能力（包括信息技术网络）集中起来进行攻击；另一方面，该计划将增加海军武器在对抗水面目标时的攻击范围。  
实施上，DARPA早在数年前，就已经提出“战术云”的概念。2013年，DARPA开始测试在战场上用智能手机和无线电通过软件组成“移动战术云”，以应对各种传统通讯基础设施失灵的救灾场合。  
对此，我国相关部门应早应对，积极推动我国国防科技工业的发展，不断进行先进军事技术的研发，增强我国军事装备的技术含量和实力。
