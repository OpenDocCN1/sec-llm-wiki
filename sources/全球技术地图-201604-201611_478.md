# 这场失控的机器人狂欢 国内企业怎么才能赚钱

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651526480&idx=1&sn=05b275163f253d50595c6e82e0dca279&chksm=f18266a0c6f5efb62c69f4bfc88cb2a52520626f7e27956f89159179bc1e70da4d1e1e018275&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651526480&idx=1&sn=05b275163f253d50595c6e82e0dca279&chksm=f18266a0c6f5efb62c69f4bfc88cb2a52520626f7e27956f89159179bc1e70da4d1e1e018275&scene=27#wechat_redirect)

**摘要：**

或许大家都听过这么一句话“三流企业卖产品，二流企业建品牌，一流企业定标准”。中国机器人的市场体量无疑是巨大的，但早就有人担忧：这场浩浩荡荡的“机器换人”运动完成后，最后肥的还是以四大家族为首的外国机器人企业。面对这种困境，中国众多的机器人企业作为后来者又该怎么做呢？

  

无论是德国工业4.0，还是美国AMP2.0，又或者是中国制造2025，无一不表明，以智能制造为主导的第四次工业革命的大幕已经开启，以机器人技术为代表的智能制造产业蓬勃兴起，预示着机器人时代已经到来。

  

![](../Images/f02273869d5cd3d897e76e624d3adf42.png)  

  

我国坐拥全球最大的机器人消费市场和最大的制造业体量，也正享受着一场机器人产业带来的盛宴，从数据上看，一切是那么美好：过去5年，中国机器人市场以年均36%的速度增长，2015年销售量攀升至76000台，连续3年居世界首位。  

  

然而，做机器人本体的业内人士却透露，日子并没有表面看到的那么风光，除了极个别企业能实现微利之外，大部分本体企业拿着国家补贴，依然挣扎在生存线上。

  

**目前中国机器人企业为什么不挣钱？**

  

**1.处于价值链末端**

  

或许大家都听过这么一句话“三流企业卖产品，二流企业建品牌，一流企业定标准”。中国机器人的市场体量无疑是巨大的，**但早就有人担忧：这场浩浩荡荡的“机器换人”运动完成后，最后肥的还是以四大家族为首的外国机器人企业。**

  

这个问题值得深思，国内机器人企业，尤其是工业机器人企业，因为对于包括伺服电机以及伺服系统在内的核心技术要求非常高，要做好需要巨大的投入以及漫长的时间，这些都是国内企业很难实现的。

  

先看一下整个机器人价值链：核心技术研发——核心零部件制造——机器人制造——机器人应用——维修服务。前三个环节也是利润最高的三个环节基本是被外国机器人公司所掌握，而多数国产机器人企业甚至连高端一点的零部件都难以掌握，更不用说整机了。这种硬伤也注定也国产机器人企业难有盈利空间。

  

**2.市场竞争能力差**

  

市场竞争力差不仅表现在技术方面，还表现在市场应对能力方面，比如说外国的机器人企业因为有比较高的利润，所以可以有比较大的降价空间，而国产机器人企业本来就靠着微薄的利润生存，若是再陷入价格战就更加的举步维艰。事实上，这也是那些处于价值链顶端的外企一贯的手法。

  

据一位在机器人设备行业从业20多年的专业人士介绍，在2012年，一部负载5公斤、行程900mm的通用型号机器人，四大家族的产品价格约为三四十万，而最近一两年，价格直线下降至十几二十万元，为了跟国产产品竞争，甚至十万元也有卖出。

  

较早前，一些企业面临自动化的转型，但又不想花太多的钱购买机器人，因为赚回购买机器人的资金耗时太长。近年来，随着产业的发展，国产机器人已经能够满足珠三角企业的要求，面对中国市场上物美价廉的国产机器人产品的竞争，四大家族不得已才纷纷降价，但是，刚起步的国产品牌此时却无力招架，几乎靠国家扶持基金养活。

  

面对四大家族降价，国产品牌为何无力招架呢？这又不得不说回一个老问题，没有掌握核心技术，中高端零部件基本依赖进口。**据资料显示，在中国工业机器人的制造成本中，减速器、伺服系统、运动控制器分别占39%、28%和11%，但国内减速机、伺服电机等关键零部件发展相对滞后，技术水平较低，产品稳定性差，与国外产品相比存在不少差距，导致国内工业机器人减速机、伺服电机等零部件主要依赖进口，国内企业工业机器人生产成本较高，竞争力较弱。**

**中国机器人企业需要怎么做**

  

**1.扬长避短，循序渐进**

  

对于技术壁垒较高的产业，短期内即使有大量大投入也难有明显的效果，而事实上，机器人并不像手机，买了不看说明书大家都会用，目前的工业机器人刚出厂时还有很多的问题，需要经过二次问题处理后才能更高效的使用。这也是目前机器人产业比较大的机会。

  

**机器人系统集成商**

  

由于核心零部件都采购外资品牌产品，机器人本体的差距并没有想象中的大。有业内人士表示，单说机器人，只完成了不到三分之一，还有大量的应用开发没有做，而各个行业的特殊技术是不一样的。因此，解决这个应用难题的机器人系统集成商，成为中国机器人产业链上鲜有的赚钱环节。

  

**机器人核心零部件生产商**

  

机器人核心技术掌握在外国人手中，这是中国机器人产业之痛，在核心技术及零部件实现突破就成为政府和企业共同努力的方向。尽管目前国内还没有能够提供规模化且性能可靠的精密减速器生产企业，但一些企业在精密减速器方面的研发正在稳步推进，浙江恒丰泰、江苏振康、北京中技克美等都先后推出了自己的机器人关节减速器，秦川发展则在1998年就研制出了RV减速器样机。2015年，苏州绿的谐波的谐波减速器的出货量将达到3万台。首先实现国产化的核心零部件企业将拥有最好的前景。

  

**2.充分利用物联网技术，拓展价值链**

  

**传统的工业机器人无论其制作多么的精良，还只是一个“又聋又哑”的大傻个，而在物联网时代，随着传感器、通信技术、云计算、人工智能等新技术的进步与发展，机器人便成为了生产智能化的一个很重要的载体。**这也使得机器人的价值链产生了变化。单独的一台机器人就只是一件硬件，而背后所能拓展与延伸的价值体量可能远大于硬件价值。这背后的服务内容就是便是另外一个市场的机遇。

  

就机器人本身而言，随着物联网技术的大量融合，很多企业也在尝试将原来的卖硬件变为卖服务，比如说沈阳机床就已经将旗下的智能机床采用租赁的方式推送给客户。据悉，i5机床订单中有七成客户采用租赁方式，按小时或者按加工量收费，有的行业一台机床开机一小时只收10元钱。

  

当然，这虽然拓展了机器人的价值链，但绝不是说机器人生产制造环节不重要，作为整个产业链的基础，机器人制造商也处于更加灵活的地位。事实上这种模式对于国产机器人产业有更好的刺激作用，因为服务型产品对于机器人本身的性能要求更高，这便推动了国产机器人厂商摒弃对低端产品抱有侥幸的心理。

  

**你的机器人应该卖给谁？**

  

**用机器人代替人工，主要解决三个层次问题，即人干不了（特种机器人）、人干不好（汽车等高端领域）和人不想干（国内一般制造业）的。**

  

事实上，情况并没有那么乐观，目前全球工业机器人保有量仅为160万台，国际替代率只有5.08%，中国替代率只有0.23%。新松机器人总裁曲道奎认为，现在机器人用得少，替代量勺，原因是工业机器人技术受限，在灵巧性工作、非一致环境制造和人机合作等领域，传统机器人的限制非常明显，面临很大挑战。

  

那么，你的机器人到底该卖给谁呢？

  

**首先是一些特殊领域，**比如高危、高污染作业以及重物搬运的企业，他们拥有迫切的机器换人需求。

  

**另外是顺应时代潮流的赚钱企业，**他们有资本进行机器换人，提高生产效率，赚取更多地利润。

  

最后，从技术层面上来说机器人产业尤其是工业机器人领域硬件难度极大，因为机械臂的结构比较简单，核心部件的技术壁垒又非常高，如减速器，伺服电机等，都属于做出来容易，做好难的产品，即便是伺服驱动器和控制器也是稳定性大于一切，这也是工业领域产品和消费级产品的本质区别，这方面都是需要长时间的积累与沉淀。反而是机器人的软件方面因为物联网等新技术的兴起，让国内众多机器人公司有了更多的机会，比如说可以基于外资企业的机器人进行二次开发，甚至在那些对于机器人硬件方面要求不高的领域也有了更多的发挥空间。
