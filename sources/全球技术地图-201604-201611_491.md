# 俄参与核工业管理学院项目，中国应高度关注

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651526451&idx=2&sn=741c730381037a638045596fbe9ed690&chksm=f18266c3c6f5efd5f5e7d938be4d432940dbf146307ee9d85d71b5acf7e080e499bf2475d55d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651526451&idx=2&sn=741c730381037a638045596fbe9ed690&chksm=f18266c3c6f5efd5f5e7d938be4d432940dbf146307ee9d85d71b5acf7e080e499bf2475d55d&scene=27#wechat_redirect)

据报道，俄罗斯国家核研究大学（NRNU）下属的莫斯科工程物理研究院（MEPhi）将成为第1个按照国际原子能机构制定的核技术管理标准启动研究生项目的俄罗斯大学，第1名学生将于8月份正式登记，并于9月1日正式进入工程物理研究院。早些时候，MEPhi与国际原子能机构签署了一份合作协议，正式成为国际核管理学院项目的成员。英国的曼彻斯特大学是该项目第1个成员，MEPhi成为第2个，国际原子能机构期盼东京大学成为第3个。国际原子能机构认为，核工业对于安全的要求很高，需要高水平决策与高效率的管理。

  

国际原子能机构核管理学院项目从2013年开始进行准备，于2015年随着英国曼彻斯特大学的加入开始了第一期课程，以国际原子能机构的专家为基础，为参与的学校制定教学框架，以统一标准培养出掌握一套核技术领域知识的高级专家。我国核安全监管采用了与国际实践一致的方法，以国际原子能机构发布的安全标准为基础，建立中国的核安全法规标准，并保持与国际先进安全标准同步。目前中国培养核工业安全管理人才的教育机构有：清华大学、核工业大学、东华理工大学及南华大学。该国际核管理学院项目曾在清华大学进行访问考察。

  

综上，我们可以看到：

首先，俄罗斯作为核电技术输出大国，俄罗斯国家核研究大学作为俄罗斯国内首屈一指的研究机构，参与核学院项目或将进一步提高俄罗斯核电国际竞争力。在之前的日报中曾对中、俄核电技术快速发展，有赶超美国的趋势进行分析研究。国际原子能机构的核学院项目成立之初就是为了培养更多的核工业安全管理人才，当前中、俄、美三国核电技术发展水平基本处于一个水平线，在没有取得技术突破之前，哪个国家能够在核电安全管理上做的更加突出将有利于输出更多的核电项目；

  

其次，中国在“十三五规划”中明确提出中国核电未来要快速有序发展，在发展的同时更要兼顾安全，以安全第一、质量第一为发展要义。中国核电安全快速发展，对于相关人才的需求也会逐渐增大，对此我们建议：英国曼彻斯特大学、俄罗斯国家核研究大学及东京大学均在核工业安全管理方面排名世界前列，中国的核工业人才培养机构应积极参与国际原子能机构的核管理学院项目，学习国际领先的核安全经验，为中国储备更多核工业安全管理人才，保障中国核电安全有序发展。
