# 甲骨文5.32亿美元收购节能数据分析公司Opower

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651526451&idx=3&sn=1767d737eed1a0d8c7234658d0293614&chksm=f18266c3c6f5efd5b52ddbcf4c3de6a572614a5afde4fda22093e099857368a781810577035e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651526451&idx=3&sn=1767d737eed1a0d8c7234658d0293614&chksm=f18266c3c6f5efd5b52ddbcf4c3de6a572614a5afde4fda22093e099857368a781810577035e&scene=27#wechat_redirect)

5月2日，软件巨头甲骨文公司已同意以5.32亿美元的价格现金收购利用数据分析帮助用户节能的云服务提供商Opower。

  

Opower是一家创办于2007年的能源数据分析公司，其目标是帮助家庭用户实现节能。通过多种举措，Opower帮助用户实现了平均1.5%-3.5%的节能效果，同时由于用户可以实时了解用电情况，从而避免了不必要的浪费。甲骨文本身此前已经涉足电力领域的业务，在收购了Opower之后，甲骨文在公用事业领域SaaS将少了一个强劲的竞争对手。![](../Images/df60edae1ce89470f1c245ea60fa2769.png)  

2016年以来，甲骨文的五次收购发力  

2016年以来，甲骨文公司持续发力前后收购的五家企业，其中既包括初创企业，也包括较为成熟的竞争对手。收购列表如下：

2016年1月中旬，以1.75亿美元收购大数据服务商AddThis；

2016年2月下旬，以5亿美金收购云软件创业公司Ravello Systems；

2016年4月上旬，以0.5亿美元收购以色列大数据公司Crosswise；

2016年4月下旬，以6.63亿美元收购建筑行业、云服务商Textura；

2016年5月上旬，以5.32亿美元收购基础设施云服务商Opower。

![](../Images/ad8420f8f45b106b4a77fe246ec3a1ce.png)  

甲骨文布局云计算垂直行业领域  

目前，在全球范围云计算和云服务市场内“基础设施即服务”（IaaS）与“平台即服务”（PaaS）等领域的大部分市场份额被亚马逊、谷歌、微软、IBM等公司占据。在此种情况下，甲骨文接连的收购取向表明，其有意进一步拓展垂直领域的云服务，正视图通过收购垂直市场的云服务提供商来扩大在“软件即服务”（SaaS）市场的影响力。依据甲骨文财报信息，其SaaS和PaaS服务按美元计算，2016财年前三季季营收增长率均高达34%、34%和57%，已经成为甲骨文增长最快的业务部门。作为一个老片IT企业，甲骨文已经通过数年来的持续布局，实现了在IT领域垂直整合的战略转型，并有机会成为全球最大的SaaS和PaaS云计算公司。
