# 物联网是怎样帮助警察破案的？

解决犯罪证据的关键问题不在于缺乏监控，而在于能够迅速获得监控录像并及时提供给警方。

  

  

![](../Images/1a2261048e8ac741f96ac104bbf43806.png)

  

在英国，为了保障人们的人身及财产安全，闭路电视被广泛应用。根据英国安全行业协会（BSIA）提供的数据，英国有四到六百万闭路电视摄像机。倘若有犯罪活动发生，这些摄像机的视频资料理论上应该能够提供犯罪证据帮警察破案。

 

然而最近，伦敦警察厅因为破案不利而遭受批评——因为他们并没有及时调看摄像机的镜头，甚至有时候根本就没有调看。

 

**由此思考可知，关键问题不在于缺乏监控，而在于能够迅速获得监控录像并及时提供给警方。**

 

不幸的是，获取闭路电视录像并不容易。“你必须到记录设备所在的位置然后用磁盘或U盘拷下来才能查看，因此警察只能回顾这些视频资料。”云景科技的CEO及联合创始人James Wickes说到。

 

用户往往不能从系统上下载这些录像，警察就不得不用一整套DVD刻录机来解决这个问题。**因为大量的闭路电视疏于监管，很多时候，当用户查看他们的录像机的时候，才发现已经出现故障了，所以并没有记录下任何的镜头！**我估计大约只有1%-2%的闭路电视录像可以正常查看。

 

这里有一段我的亲身经历。在有人试图闯入我家之后，我发现，尽管邻居们都有闭路电视，但是警察要想获得这些录像并按照事件发生的前后顺序进行组合以便于识别犯罪嫌疑人的话，还是非常困难。

 

**这就是物联网起作用的时候了，因为物联网具备即时性。**通过物联网可以把闭路电视摄像机安全连接到云，可视化的监控资料可以按照需求被安全的存储起来。监控视频可以在任何地点任何时间实时通过个人智能手机、个人电脑、平板电脑查看，前提是你得获得授权。

  

而且，如果有需要的话，你可以直接把监控视频通过邮件发给警察，警察可及时查看，就免的再跑到摄像机那边去收集了，这样就能够更好的利用资源，其实也就为纳税人省了钱。

 

**另一个优势是避免罪犯破坏闭路电视装备引起的监控视频的丢失，因为使用物联网技术能够确保非授权的罪犯无法访问这些视频数据。**

 

不论是传输到云还是存储在本地，安全都至关重要。解决方案是在监控视频传输及存储过程中进行加密，从而确保数据安全并且符合数据保护法（DPA）的要求。

 

这可以通过在现有的摄像机上添加一个智能配适器的方式来实现，这样就可以提供物联网的连接，安全和准确的日期和时间戳了。

 

住房协会Family Mosaic已经开始使用这种系统了，在很多地方，他们都在利用闭路电视保障居民的人身及其财产安全，使其免受反社会行为的伤害。

 

最近又出现了新的问题，就是有人正在试图窃取邮件（刑事犯罪）。不过社区经理可以向警察及时发送录像以确认罪犯的身份。以往，这将花费警察多达两周的时间来拷贝录像资料，现在则是实时的。

 

**远程访问系统意味着镜头已经将做出反社会行为的人的所有行为活动都悄悄的记录下来，并不会让他们意识到。**某些情况下，去现场访问DVR时很危险的，因为罪犯很可能会不惜一切代价来阻止警察获取证据。现在Family Mosaic可以在任何地点查看监控视频，适当的情况下，他们还会把访问入口提供给警察。

 

在我看来，物联网无非就是这种类型的应用了。智能冰箱倒是能够很好地照顾你的食物，但是当谈及它可以引起犯罪的时候，我想就不会有人喜欢它了。
