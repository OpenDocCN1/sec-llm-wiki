人们对于如何在网上隐身十分感兴趣，这就是这个难以保护自己个人信息的时代所放出的信号。彻底消除在互联网上的足迹完全是天方夜谭，但是我们可以使用很多方式让你在网上曾经留下的足迹模糊不清。

![](../Images/8b1ebcb1cf7e48745860e5c5c0e2c5da.png)

如何在网上做一个连黑客都找不到的隐形人？虽然这话听起来有些夸张，但是那些形形色色的商业公司比你自己还了解你。

  

如果不信，就打开你的手机或者笔记本电脑试一试。商业公司不仅能够预测你想要买什么，并且按照你的购买意愿为你展示广告。他们知道你的生日，甚至还会告诉你你那十几岁的青春期女儿已经偷偷怀孕了（这可不是我编造出来的，这一著名的结论在早几年已经被证实了）。

  

在皮尤研究中心最近一系列的调查中显示，美国的消费者表示他们害怕自己已经失去了对于个人信息的控制，那些商业公司并没有采取足够的措施去保护他们收集到的客户数据。经调查发现，大多数美国人（64%）都经历过个人信息数据泄露。

  

「人们对于如何在网上隐身十分感兴趣，」伦敦 Trust Media 专攻数字货币问题的 Caleb Chen 如是说，「这就是这个难以保护自己个人信息的时代所放出的信号。」

  

想要在互联网中让你的形象模糊是有可能的，只需要几个简单的步骤并正确运用一些技术。但想要做到在网上绝对隐形非常困难，甚至是不可能实现的。

  

「彻底消除你在互联网上的足迹完全是天方夜谭，」David Cox 是 LiquidVPN 公司的 CEO，他们公司提供的服务专门保护你在网上的位置与身份。「但是我们可以使用很多方式让你在网上曾经留下的足迹模糊不清。」

  

****▌**未雨绸缪**

  

有一个简单的方式可以在你浏览完网页之后扫除留下的痕迹，那就是设定你的浏览器不准提交你的个人信息。比方说你在使用 Chrome 浏览器的时候可以在选项中设置不允许网站跟踪你的个人位置。你还可以切换到一个更为注重隐私的网络搜索引擎，比如说 DuckDuckGo.com，它不会收集或者分享你的个人信息；你也可以在浏览器中使用隐身模式，也就是说不与你访问的网站分享任何个人数据。

  

「当然，如果想要更保险就要在每次使用完之后及时登出那些在线服务，比如 Gmail 和 Facebook，」IT 咨询公司的总裁 Michael Gregg 介绍道，「这会让第三方更加难以追踪你在网上的活动。」

  

这种策略很是合理，如果你不想要每个人都知道你是谁，首先要做的就是别告诉大家你是谁。你可以现在就去检查一下自己最爱的社交网站的隐私设置，虽然这一项在网上可能并不太容易找到。比如说在 Facebook 上你就得先点击屏幕左上角问号旁边的箭头，然后去「隐私」项里面检查并修改账户设置。社交网站不想把这件事弄得很容易，原因很明显，这些社交网站就是靠着你的个人信息来赚钱的，你就是他们的产品。

  

把你的网上足迹大体掩盖一下不会花很长时间，但是想要消除它们就需要额外的工作了。

  

![](../Images/69e11c3fde4259db465e6723804aaf4d.png)

****▌**使用 VPN 与洋葱浏览器（Tor）**

VPN 是一种通过中介服务器加密你的通讯数据的应用，在 VPN 的加持下，你的设备地址如同一个蒙面人，让第三方无法追踪。大多数的 VPN 提供商都会在他们的服务器上共享 IP 地址，这样会有数十、数百乃至数千的用户被分配到同一个 IP 地址，这就使得想要追踪某一个特定使用者的踪迹变得几乎不可能。

  

使用 VPN 还有一个额外的好处，你只要点击一个按钮就可以改变自己的位置。如果你身处纽约，但是却想要你的浏览器认为你在伦敦，使用 VPN 可以很容易做到。

  

如果你是真的想要彻底消除自己的数字痕迹，可能就得考虑改用洋葱浏览器（Tor）了。Tor 这个免费、开源的程序可以给网络流量进行三重加密，帮助你提升互联网使用时的隐私与安全。Tor 不会直接连接，取而代之的是创建一系列的虚拟通道，这就让你可以迂回地连接到某处网站。

  

你可以将使用 Tor 浏览器看成是不停地转机飞行，而不是平常的浏览器那样犹如一架直达目的地的飞机。这架不停转机的飞机运送的旅客就是你的网络行为数据包。在直达航班中，你的信息数据包将从 A 点直接到 B 点，最终目的地是很明确的；而在 Tor 浏览器中，你会经过几番中转，最后仍然到达 B 点，但是你的最终目的地却被那些用来遮掩痕迹的 C 点与 D 点给隐形了。

  

你可能已经料到，使用这种三重加密的浏览器上网的体验不会那么流畅，但是没人会知道你是谁。

**▌****加密！加密！加密！**

  

除了上述几种方式，你还可以略施小计使得信息在发出之前就确保其安全。

  

「如果攻击者不能破译或者读到你的任何电子邮件，那么他们的努力在很大程度上就是白费力，邮件地址的所有者就能够保证自己的隐私与网络匿名性，他们的信息也就被保护了。」Bill Bullock 是 SecureMyEmail 的 CEO，他的公司专门提供加密电子邮件产品。

  

市面上有成百上千的加密产品，绝大多数的作用原理是差不多的。它们使用起来很简单，通常来说成本也很低，几乎不要钱。比如说 Virtru 就是一个使用于 chrome 浏览器的简单拓展程序，它能够提供军用级别的加密，可以让你控制邮件的转发、撤回邮件乃至为邮件设置一个到期期限。

  

但是如今的加密解决方案使用起来是越来越麻烦了，有时候得迫使收件人先下载软件才能阅读你的信息。

  

保护信息安全的方法说到这里也许应该停一下了，先来反问一下我们是怎么走到了这一地步。为什么我们的个人信息能够如此随意地散落在网络之中？虽然有很多原因可以用来解释为何商业公司看上去对我们了如指掌，但是相对而言为什么我们对这些公司了解甚少？有一种说法可以用于解释这一疑问：消费者群体很长时间以来都没有意识到自己的个人隐私会有如此的价值。

  

这就是我们为何走到了这一步的原因。在一个没有秘密的世界里，上面介绍的那些方法可以让你为自己稍微保留多一点秘密。检查你的浏览器隐私设置，切换到一个加密浏览器，使用 VPN 与加密程序，这些都能有所帮助。

  

不过想要做到完全彻底地在网上隐形只有一种方法，那就是不要上网。
