# 美国数据创新中心 : 联邦政府如何利用物联网?

物联网时代为政府部门带来了哪些挑战和机遇？

物联网应用可以为政府部门提高效率，但它却很少在政府部门真正实施。事实上，政府在引入物联网过程中存在诸多挑战，主要包括：缺乏领导、缺乏技术与资金支持、繁琐的采购手续以及长久以来的风险规避意识。

  

除非发生了能够促使政府部门行动的重要改变，否则物联网很难被引入到政府日常办公之中。物联网是由一整套配有嵌入式传感器、处理器的物理实体组成的，它们被连入网络中，可为政府部门的职能运作提质增效。同时由于物联网正向的外部性影响，一旦政府部门引入，也会刺激商业界开始接受物联网基础。

  

联邦政府有很多机会去实施物联网，以提供更高效更迅速的服务，但是很少有政府机构去寻求机会实施。阻碍政府部门实施物联网的主要原因如下。

  

> *   第一， 缺少政府层面的策略引导，政府部门无法便利使用物联网；
>     
>     第二， 政府工作人员通常不具备处理物联网信息的技能；  
>     
> *   第三， 政府部门缺少资金建设信息技术基础设施以及物联网试点工程；  
>     
> *   第四， 即便资金到位，政府采购的繁琐的程序也使得建设物联网平台难上加难；  
>     
> *   最后，风险与不确定性的存在更使得政府部门止步不前。  
>     

  

本文经过分析得出结论，如果没有重要的措施鼓励政府部门应用物联网，则物联网在政府部门的应用将保持在较低水平。

  

**(一) 物联网在联邦政府中的应用**

**1.减少开支**

  

政府部门引入物联网设备的首要目的就是提升效率减少开支。这方面主要的应用方向有智能建筑、增强政府用车效率的远程信息处理、提升资产管理能力以及日常工作自动化。

  

通用服务局的智能建筑可将政府建筑通过网络连接从而提高现代化水平，这样的改变可以提升能源效率，每年可为美国政府减少1500万美元的开销。车队远程管理系统是物联网的又一应用。该技术可远程监控车队中车辆的位置、性能和当前状态。目前有超过75个联邦机构正在使用这一系统。它不仅可解决车辆的定位导航问题，还可检测温室气体排放，目前有20.4万辆政府用车的排放水平被实时监控。将物联网用于资产管理可增强对资产的监控，提高使用率、生产效率和可靠性。还有一些政府部门尝试通过物联网将部分手工流程自动化，同样大幅降低了日常运营费用。

  

**2.开创新的服务**

  

有些政府部门使用物联网开创了新的服务形式来辅助日常工作的完成，主要应用在提升国防水平、监控自然环境，以及增强公共卫生与公共安全方面。

  

美国的防务部门是领导物联网应用的主要部门，他们使用物联网连接技术训练士兵，提升对伤员的护理条件并为部队的补给链提供安保。军用物联网有其独特设计特点，可以适应不同军队各自的操作需求。军事基地收集数据的方式多种多样，可利用相机、红外传感器以及辐射和化学物质传感器。同时也有许多执行平台，例如无人机、监视卫星、舰船、陆地基站或士兵。通过士兵头盔上的头骨能量分析诊断系统等先进物联网设备，每个士兵的健康状况都受到实时监控，大到脑部组织损伤、小到活动情况与睡眠质量。

  

国家海洋大气局为许多重要应用提供地质数据，该部门目前正在考虑如何使用物联网提升其服务。该部门是世界上最大的天气气候数据提供源，他们通过联网汇集了各个大陆上检测站传感器、卫星上传感器、浮标与海洋平台上传感器、气象气球上传感器上的所有数据，为众多公共、私人活动提供数据支持。

  

许多政府部门利用物联网提升灾害应急机制反应能力，大幅降低了自然或人为因素所导致灾难的生命财产损失。例如用于监测地震中大楼结构完整性的传感器可提供是否需要疏散楼内人员的建议。美国疾病预防控制中心正在研究利用现有技术监视地下矿区环境，从而保障矿工的人身安全。美国国家宇航局利用图像和卫星红外数据可以预测、寻找并定位火灾。这些都提升了公共卫生与安全水平。

  

**(二) 推广物联网所面临的挑战**

  

虽然种种迹象表明政府部门正在接受物联网设备，但接受度总体上仍处较低水平。目前，尚有很多因素阻碍物联网技术的拓展，总的来说这些因素包括缺乏战略领导、缺乏技术、缺乏资金、采购政策繁琐、厌恶风险。

  

**1.缺乏领导**

  

政府部门中缺乏战略领导来规划如何在不同部门之间建立整体的技术运用视野，国家缺乏物联网引入与部署的规划，各个政府部门自身也尚未准备好接受这些技术。虽然有些部门正在大力推进物联网工程，但仍有大量高层政府信息技术领导缺乏对物联网技术本身以及其潜在价值的了解。由于缺少战略指导，物联网在部门内部的普及受到阻碍。出于项目需要希望使用物联网技术的项目管理者，得不到后端信息技术部门的技术支持，于是物联网不能被有效推广。

  

**2.缺乏技术**

  

美国政府内缺乏信息技术工作者，缺少可以处理数据的工程师，这使得即便物联网设备得到普及，也无人分析设备产生的数据，也就无法利用好物联网的便利。到2018年，美国将面临19万的数据工程师缺口，以及150万可以利用数据做出更好决策的项目经理的缺口。数据工程师短缺状况为国际化的问题，中国、法国、德国、印度和英国面临着同样的问题。政府部门的雇佣关系僵化也使得他们比私人企业更加缺少高水平数据分析人才。这一点也阻碍了物联网及解决方案的普及与部署。

  

**3.缺乏资金**

  

即便物联网解决方案可以给政府机构带来投资回报，但很多政府部门缺乏普及物联网设备的资金，这与很多其他信息技术设备推广所面临的资金不足相同。大部分政府物联网设备预算都在国防领域，2015年国防机构智能传感器采购量占全部智能传感器采购量的88%。此外，政府大量的信息技术投资被花费在老旧设备的操作和维护，这也拖慢了政府现代化建设。

  

**4.繁琐的采购政策**

  

繁琐、过时的政府采购执行标准是物联网设备普及的另一挑战。首先，政府采购步骤使得采购部署高新技术产品很困难，采购途径只能通过合同或公开市场收购，无法适应更新换代快速的物联网设备发展节奏。第二，政府采购执行僵化，更倾向于将资产支出用于对单纯技术的采购而非对服务或更灵活、形式创新的技术。第三，政府对信息技术的采购宁可独立购买风险更高的技术硬件、软件和服务，也不愿为达到特定商业产出而订立的技术合同付费。

  

**5.厌恶风险**

  

联邦政府有意推广的物联网技术大部分是新兴技术，尚未经过足够的测试，联邦政府更希望推迟技术的引用直到这些技术得到足够的检测变得成熟。推广新的技术都存在风险，在政府部门，决策者推广这些新技术失败所带来的负面影响远大于推广成功后带来的收益，因此政府部门比私人企业更不易推广物联网技术。在这一过程中，政府部门所担心的风险因素包括：隐私保护、安全、信息交互、数据管理与投资回报。

  

**(三) 对于物联网技术推广的建议**

  

在政府部门推广物联网技术不仅可以提高政府部门工作效率，还可以以此及相关产品与服务的商业创新，降低新兴技术的研发成本，提升智能设备的安全性。政府率先接受物联网技术可以带来更广的市场空间，提升美国的国家竞争力。

  

**1.如何扩展政府部门对物联网的使用**

  

扩展政府部门对物联网的使用需要加深领导者们对这一项新兴技术的了解。为解决这一问题：

  

> *   首先，联邦首席信息官理事会应建立负责在政府中起引领作用的物联网特别行动队，普及技术知识、分享实践经验。
>     
>       
>     
> *   第二，每个政府部门都应制定自己的一套方案，规划如何用物联网技术降低成本提升服务，这一套方案还需包含降低风险与不确定性的措施，从而保证政府有意愿推广物联网技术。
>     
>       
>     
> *   第三，尚无首席数据官的部门应立即聘请一名首席数据官，与首席信息官一起，提升部门利用物联网数据做决策的专业性。
>     
>       
>     
> *   最后，总务管理局（GSA）应建立“物联网公司”，专门负责完成政府部门中有较高影响力的物联网项目建设。
>     

  

**2.政府部门应如何支持物联网的发展**

  

物联网产业发展面临很多挑战，其中有些私人企业不能独自解决；政府部门如果携手将问题解决也将获得切实的利益。

  

政府部门应为大型的物联网试点项目提供足够的资金支持，尤其是对于那些可以推广、可复现的应用方向，积累足够的实践经验。

  

政府部门应优先支持有较高经济、社会影响的试点项目，例如那些解决昂贵慢性健康问题的试点，这些项目大多会给政府部门带来可观的利益。虽说物联网在政府部门中的推广进程较慢，但很多政府部门已经建立相应的研发项目，并投入了一定的研发资金。政府部门应重点关注这些项目，重点攻克关键的基础性难点，例如如何提高网络安全或研发低耗电量技术。

  

另一个产生可观价值的政府研发行为是政府主导的风险投资项目，这些风险投资很多支持了研发物联网创新应用的公司。

  

**(四) 结论**

  

政府部门普及物联网技术后将大幅提升服务质量与运行效率。虽然联邦政府启动了一系列推动物联网技术发展的项目，但政府内部总体的物联网接受度仍然很低，尤其是在非国防部门中。另外，政府部门对物联网的推广遇到了许多挑战。这些注定政府部门的物联网普及速度将比私人企业更慢，除非政府内部出现鼓励人们接受物联网的重要改变。
