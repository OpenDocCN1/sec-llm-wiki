# 产学研三方视角共同探讨G20国家科技竞争格局及人工智能领域科技创新力

G20作为拥有世界**80%**以上的GDP，**92%**研究开发经费，**90%**以上科研论文以及**94%**的美国专利商标局授权专利的集团，在全球科技创新中表现出的竞争力和活力将决定世界科技创新的未来和方向。

  

2018年6月25日上午，**中国科学院文献情报中心与科睿唯安将在京联合举办“科技创新的活力与格局——《G20国家科技竞争格局之辩》系列报告发布暨研讨会”**。此系列报告是中科院文献情报中心与科睿唯安历时近一年时间合作完成，分为总体报告及人工智能专题报告，聚焦G20国家的科技发展现状，追踪研究各国总体及人工智能领域的科研表现力和技术创新力，为我国建设科技强国和世界人工智能创新中心提供有价值的信息支撑和决策分析依据。本次研讨会将邀请政府相关部门、学术界以及企业相关领域的专家进行现场解读和研讨。

  

我们热诚邀请您出席本次会议，从科技、产业和经济等视角共同交流G20国家竞争格局的现状和潜在变化，展望人工智能未来的发展前景和趋势。请于**6月21日前在线注册**参与本次会议。与会人员将获赠《G20国家科技竞争格局之辩》系列报告。

**报告亮点抢先看**

**《G20国家科技竞争格局之辩》报告**  

1.  科研表现：G20中，金砖国家和其它新兴工业化国家的科研产出规模及学术影响力呈较快增长；  
    
2.  全球论文引证关系：近5年来，中国论文的学术影响力凸显，逐渐成为论文引证的核心国家；
    
3.  全球国际合作网络：美国和以英国和德国为代表的欧盟28国集团仍然是论文国际合作最具吸引力的国家
    
4.  技术创新力：美国、英国等国专利国外布局较为明显，而中国、韩国、日本等国专利更多侧重在国内布局。
    

****《G20国家科技竞争格局之辩——**人工智能专题****》****报告**

1.  G20各国政府正在积极开展人工智能领域布局，已经形成递进式、持续性的发展动力；
    
2.  美国在研发人力资源和基础研究经费方面一家独大，英国、印度和加拿大等紧随其后，中国尚有明显差距；
    
3.  美国的人工智能总体科技实力位居G20国家首位，中国紧随其后且增速明显；
    
4.  G20国家在医疗、交通、教育和金融行业的人工智能研发及应用呈现百花齐放的景象。‍‍‍‍‍‍‍
