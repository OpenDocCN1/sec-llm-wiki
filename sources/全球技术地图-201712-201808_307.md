# 罢免蒂勒森、干预博通收购高通，我行我素的特朗普正在拉低美国科技发展的速度吗？

**作为一个商人，特朗普无疑是成功的，但在科技引导方面，其对外态度有些过于强硬了。**

  

  

日前，美国总统川普突然解除了国务卿蒂勒森的职务，并提名中央情报局局长迈克·蓬佩奥接替。自2月底以来，这已经是白宫的第5次人事变动了。

  

与此同时，因为川普的干预，博通对高通的收购被叫停。

  

两件事发生后，美国股市瞬间不好了。

  

![](../Images/881cab41def018125f9885a45d4d1de9.png)

  

![](../Images/13d6494590429102b82a91bfc54d65ea.png)

**白宫人事动荡**

**美股芯片股首当其中受拖累**

  

对于当前白宫的人事动荡，有不少人担心此后其在国家安全和贸易问题上的立场将变得更加强硬，从而拖累美股芯片股。

  

似乎是为了验证这一担忧，就在当天，截至收盘，道指收跌0.68%，纳指收跌1.02%，标普500指数收跌0.64%。

  

而就在罢免蒂勒森的前一天，川普发布了一条行政命令，称有可靠的证据使他相信，博通收购高通之后可能采取危及美国国家安全的行动。因此，高通公司应该“立即并永久”放弃这项收购，同时禁止高通和博通任何“本质上等同于”并购交易的计划。此外，博通所提名的所有15名董事会候选人都不符合高通董事会资格。

  

因为川普的“横插一脚”，“博通收购高通”一事被正式按下停止键。

  

不出意外的，白宫人事动荡引发的担忧，也影响到了高通的股价。截至收盘，高通大跌5%领跌标普500成分股，半导体板块在盘中刷新历史新高后跳水，收跌1.4%。

  

![](../Images/13d6494590429102b82a91bfc54d65ea.png)

**新官上任三把火**

**川普第一把火就烧到了科技界**

  

在人们的意料之外，川普赢得了2016年大选的最后胜利，如愿坐上了美国总统的位子。我们都说“新官上任三把火”，作为新鲜出炉的美国总统，川普的“第一把火”就点燃了一颗扔向科技圈的炸弹——禁止7个穆斯林国家的公民在90天内进入美国。

  

讽刺的是，就在2016年8月的竞选还没有白热化之前，川普曾经在社交媒体上发表过支持外来人才的言论：

  

> “我希望有才的人能够来美国，来努力地工作，来成为美国公民。硅谷需要工程师。”

  

众所周知，外来员工一直以来都受到美国科技公司的喜欢，先不谈价格低廉的原因，就是在众多科技公司内部，不少外来人员都担任着重要的职位，比如特斯拉创始人兼CEO马斯克就是移民到美国的。

  

因为这一政策，包括亚马逊、苹果和谷歌在内多家硅谷公司直接“怼”上了川普，在白宫与硅谷之间进行了一场“拉锯战”。举个例子，在移民政策出来后，谢尔盖·布林和桑达尔·皮查伊领导了Google专家的反抗行动，100多家科技公司向法院提交文件对抗这项禁令。

  

![](../Images/0f9bb2a04770a624f36883c88f995947.png)

  

之后，为了缓解与科技公司之间的关系，川普与各科技高管来了一次“闭门谈话”。在会上，微软CEO纳德拉直接向川普抛出了这次谈话的中心话题——移民和政府如何帮助科技企业获得H-1B签证（特殊专业人员/临时工作签证）以留住及引进更多的人才。

  

对于这个问题，川普先是说“让我们来解决这个问题”，接着说“我能做些什么来改善这些问题？”在没有给出任何承诺的情况下，川普以四两拨千斤之势跳过这个引发此次会议的核心问题。这一话题之后，桌上的议题转向了STEM教育、信息安全、气候变化等领域。

  

从整体来看，这次科技高管会议是相对平和的，不过，从结果来看，这一会议又似乎是没什么“成效”的。

  

譬如支持STEM教育，这是川普为了美国本土科技人才缺失问题的策略，又比如信息安全，这一点可以说正中川普下怀。而对于其中的核心问题，川普没有给出任何具体的口头或书面回应。

  

![](../Images/13d6494590429102b82a91bfc54d65ea.png)

**中国AI发展已上升至国家层面**

**而川普却依旧“我行我素”**

  

在科技产业发展方面，“中美竞争”一直是一个恒久不变的话题。而相比于川普政府对于科技的不重视，中国却早已开始对其上纲上线。尤其在当前大热的AI技术发展上。

  

在去年7月份，中国发布了首份围绕AI 的“国”字号文件《新一代人工智能发展规划》，正式将AI的发展上升到了国家战略发展层面。

  

![](../Images/c6994c988c368a01f5c3af0b22502273.png)

  

随着这一份文件露出水面，国内AI界沸腾了，更甚者，远在大洋彼岸的美国硅谷、媒体等群体也都受到了震动。而与此同时，我们见到的是依旧“我行我素”的川普。或者我们换一种说法，在竞争对手已经加大重视AI发展的时候，虽然川普主张科技公司将重心搬回国内，但对于科技本身，却依旧奉行“忽视”策略，甚至是“破坏”！

  

譬如对科技的“忽视”，最为典型的表现或许就是白宫科技政策办公室负责人人选的悬而未定。自成立以来，科技政策办公室担任着美国科技圈和华盛顿之间的关键联络人。

  

随着川普的上台，截至去年4月份，这一办公室的人数已经从奥巴马执政期间的过百人减至不到50左右。其中，以往负责研究网络中立、人工智能和自动驾驶问题的私人助手也从23人变成了迈克尔·克拉夏斯1人，并且他在进入白宫之前没有任何科技背景。

  

与此同时，自约翰·霍尔德伦从科技政策办公室负责人兼总统科技顾问的位子上离开后，川普一直没有任命该职位的接班人。可以说，现在的科技政策办公室已经是形同虚设。

  

![](../Images/596037728218e5648a0fb5d72893b048.png)

图 |《纽约时报》披露的特朗普政府的第一份财政预算

  

至于“破坏”，最值得一说的或许就是科研经费的大幅减少。去年5月，白宫向国会提交了特朗普政府2018财年（去年10月1日至今年9月30日）联邦政府预算报告，报告显示，为了增加国防支出，川普的决定是削减包括国家科学基金会、能源部、科学技术研究局在内的多个部门的支出。

  

今年2月份，川普政府向国会提交2019财年（今年10月1日起至明年9月30日）联邦政府财政预算报告。不出所料，其依旧为安防预算“开绿灯”，增至7160亿美元，占据了总预算的16%，而其他多数联邦政府的部门预算则是有不同程度的缩减。

  

![](../Images/6c7580e270defe8d7be75414bbe6b4f2.png)

  

![](../Images/13d6494590429102b82a91bfc54d65ea.png)

**最后：中美科技竞争加剧**

**川普却变本加厉拖后腿**

  

一直以来，科技与经济都是不分家的。在川普这里，作为一个成功的商人，通过降低税收，他正一步步地将苹果等公司拉回国内。

  

另外，从华为开拓美国手机市场遭阻，到蚂蚁金服收购转账平台Moneygram、博通收购高通计划被叫停……这一系列事件都在告诉我们，川普对于国家安全是极为重视的（虽然也有可能只是个借口）。而他也将这种重视转移到了商业领域。

  

有消息称，美国已经启动了所谓的“301条款”调查（美国《1974年贸易法》第301条的俗称，一般指美国贸易法中有关对外国立法或行政上违反协定、损害美国利益的行为采取单边行动的立法授权条款）。

  

作为过去几年流动最为频繁的产业之一，在接下来，外资对美国数据及信息产业的投资的面前很可能竖起一道更加严苛的壁垒，结果可能是将腾讯等企业拒之门外等等。

  

与此同时，就在今年1月，特朗普表示美国正考虑对中国进行罚款，因为他称中国迫使美国公司分享他们的知识产权，然后才能在中国做生意。随后他在第一次国情咨文中表示，将“强力”执行保护商业机密的美国法规。

  

对于川普的此番言论，研究公司Cowen Washington Research的分析师克里斯·克鲁格指出，美国可能会在数周内发布一份有关所谓中国强迫技术转让的贸易报告，较8月18日的截止期限大幅提前。这份报告可能会建议征收关税，封杀中国的投资或者合资公司。

  

![](../Images/65eaae3a64aa138f97224df77d39e25d.png)

  

据CB Insights的数据显示，中国投资者在去年向美国科技创企发起165笔交易。而从美国角度来讲，根据PitchBook提供的数据显示，在美国去年创企的总融资额中，涉及中国企业的有93亿美元，占据了总额的11%。克鲁格的分析若成真，包括特斯拉、Magic Leap、Uber、Snap在内的多家皆有中国投资商身影的企业又该如何？

  

另外，我们注意到，在此前川普提出的“美国优先”政策所覆盖的六大核心行业中，半导体位列其中，此外还有钢铁、铝、汽车、飞机和造船业等等。

  

如果这一情况属实的话，包括英伟达、高通、美光科技、英特尔和AMD等与中国企业牵扯甚多，以及自动驾驶、无人机等相关科技产业都将受到极大的影响。此次高通股价的下跌或许只是暴风雨前的宁静。

  

对于当前美国科技界在政府干扰下变得“愈加保守”的境况，用盛宝银行（Saxo Bank）首席经济学家斯蒂恩·雅各布森来结尾：“美国科技公司现在非常成功，利润率也非常高，因为他们现在具有行业垄断地位。但如果你预测未来的趋势，那么在未来6个月内，这方面将出现一个中国版本。”
