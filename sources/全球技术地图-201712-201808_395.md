# Lux Research：未来十年，这18项技术将改变世界！

**创新丨前沿丨科普丨资讯**

**技术创新研究与咨询机构Lux Research近日发布了一份名为《展望2018：未来这些颠覆性技术将重塑世界》(18 for 2018: Transformational Technologies Reshaping the World)的报告。本文对这篇报告的重点内容经行了梳理。**

  

![](../Images/d740b632b091e98ae9d1cb7723ca0603.png)

  

从机器学习到合成生物学，从固态电池到微生物，Lux Research结合专家分析和专有数据分析平台，分析得出了18项最有可能在未来十年对全球造成最大影响的技术：

![](../Images/19ad2e22c72b25d980d209d0e142f5f0.png)

1）机器学习和深度神经网络 - 每年相关专利争议30%的速度增长

  

2）3D打印和增材制造 - Lux预计到2025年3D打印将成为一个200亿美元的市场

  

3）基因组编辑 - 风险投资已达12亿美元，影响将覆盖从食品到医疗行业等广泛领域

  

4）5G网络 - 已有超过70,000项专利，为2018年推出5G网络奠定了良好基础

  

5）微生物 - 利用个性化微生物，充分释放健康和营养的力量

  

6）固态电池 - 由丰田等初创企业和巨头主导，将带来更安全和更好性能的电池

  

7）合成生物学 - Ginkgo Bioworks最近获得的2.75亿美元的一轮融资突出了这一领域潜力

  

8）增强现实（AR） - 逐渐走向企业级应用程序，已获得超过44亿美元融资。

  

9）智能手表 - 在不到5年的时间内，专利数量从0增加到超过23,000项。

  

10）无线充电 - 现在用于消费电子产品，针对电动汽车应用的研发正逐渐铺开。

  

11）材料信息学 - 使用IT和AI来打破慢速的材料开发周期。

  

12）物联网安全 - 随着连接设备的激增，专利数量增长了13倍。

  

13）边缘计算 - 当达到毫秒速度时，可以实现本地分析运营，而不是云端操作。

  

14）能源分配系统监测 - 对能源分配不断增长的需求和可再生性运作，需要强大的技术来平衡电网。

  

15）生物基PEF材料 - 相关创新以每年87％的速度增长，以改善其质量和性能。

  

16）降糖 - 超过16.2万项专利旨在消除糖分过多导致的健康问题。

  

17）神经界面 - 阅读和刺激大脑的技术将在2018年得到越来越多的验证。

  

18）合成气体和电力转能源 - 从二氧化碳中提取燃料等技术，将大大推动能源利用专利。

  

![](../Images/b028cd9d9461ac7397f5e65655c46724.png)

  

这份报告除了描述和对这些技术进行排列外，还分析了一些关键的细节，比如受影响的行业、每个领域的关键参与者、各项技术的潜在影响。

  

根据不同的方式，Lux Research将这18项技术分为了三类：

  

**目前最热领域：3D打印（第2名）、5G网络（第4名）、智能手表（第9名）**

  

Lux Research智能化研究副总裁Mike Holman表示：“这些技术在过去几年中一直呈现出平流层式的上升趋势，并且具有实质性的作用，对于相关行业中的任何一家公司来说，这些技术的战略布局都是必不可少的，但是要注意强竞争和期望膨胀的风险。"

![](../Images/83a8448cac472d0b617e87960e1f096b.png)

  

**面临重大难题的领域：生物学（＃7），能量分配系统监测（＃14）和降糖（＃16）。**

  

分析师表示：“这些技术引起巨大的潜力备受瞩目，但目前商业化遭遇重大瓶颈。建议进行组合式投资，而不是押下一个大赌注。”

  

潜力巨大即将爆发的领域：固态电池（＃6），材料信息学（＃11）和边缘计算（＃13）。

  

这些技术被形容为“还在积极酝酿，从绝对的角度上还没有吸引太多的创新注意力，但是它们正处于一个迅速崛起的阶段。”Lux Research提出，企业现在就应该考虑建立相关的项目，以争取在其早期爆发阶段占据主导地位，获得丰厚回报。
