特朗普政府或将5G网络收归国有，引发外界强烈担忧

美国Axios网站近日曝出的敏感文件显示，特朗普政府麾下的国家安全官员正在考虑将国内部分移动网络收归国有，以防范来自于中国的威胁。




此次曝出的敏感文件来自于美国国家安全委员会的一名高级官员，具体内容包括一份PPT幻灯片以及一份备忘录。近日其它政府部门的高级官员也对这些文件进行了审阅。


（文档链接为 https://www.documentcloud.org/documents/4361020-Secure-5g.html#document/p30 可复制到浏览器打开）


文件指出，美国应当在3年期限内，于全国范围建成一个完整的国有5G网络。在未来的6到8个月间，特朗普政府内部将就网络的建设以及开销问题展开激烈讨论。同时，政府将5G网络国有化的行为还将引起通信行业的强烈抗议。

文件中列举了两个实施方案：

    【首选方案】美国政府将亲自出资并主持建立起一个完整的5G网络——长期以来，美国国内的通信基础设施都由私人企业经营，政府的此类国有化尝试在历史上前所未有。

    【备选方案】美国政府将不会亲自主导5G网络的建设，而是允许国内的无线运营商各自建立网络，并且彼此开展竞争——文件认为，该方案的实施成本更高，耗费时间更久。但是，该方案对无线通信产业造成的不利影响要明显小于第一种国有化方案。


一名参与文件起草过程的消息人士透露，第二种方案实际上并不具备可行性，因为，只有一个完整的国有化5G网络才能帮助美国抵御中国以及其它敌对势力的威胁。



然而目前，5G网络的建设以及归属问题仍然悬而未决。


消息人士称，白宫内部将就两个方案（政府亲自主持建设，或交由运营商联合建设）进行讨论。值得注意的是，如果选择第二种方案，有关运营商就需要在其商业模式与国家利益产生冲突时，优先维护国家利益。实施第一种方案意味着联邦政府将大举介入无线通信产业这一传统意义上的私营经济部门。在备忘录中，特朗普政府将其视为“21世纪的艾森豪威尔国家高速公路系统”，在特朗普本届任期结束前，该方案将为无线通信产业创造一个“全新典范”。


但是，规划中的国有5G网络不会覆盖所有频段，私人运营商仍然有足够的空间建设自己的5G网络。


根据PPT文档中的说法，美国发展超高速5G网络技术的需求如此迫切，其原因在于“中国已经在网络基础设施的制造和运营方面占据了主导地位”，而“中国正是网络世界中的头号威胁”。为了表现美国无线网络技术的落后，这份PPT文档用了一张中世纪古城的照片来比喻美国相关领域的现状，随后，文档又用了另外一张高楼林立的纽约曼哈顿街景，预示美国将来可能面临的挑战。



该备忘录认为，由美国政府亲自建立5G网络是目前的最佳选择。网络建成后，政府可以将其出租给其它网络运营商（如AT&T、Verizon以及T-Mobile）。（另据消息人士透露，这项提议只是一份“旧版”草案中的内容，最新草案中并未对美国政府的立场做出建议。）


目前，美国各大运营商基本处于一种“各自为战”的状态，它们通常使用自家的设备独立搭建网络。如果运营商今后必须向联邦政府租用网络，整个通信行业必将掀起一场翻天覆地的变革。


根据备忘录中的说法，联邦政府还可以打着“国家安全”的旗号，为无线网络设备的安装工作建立国家标准，以防止各州市无视国家号召，自行出台相关法规。


备忘录中显示，一个强有力的5G网络不仅能够为新兴技术（例如无人驾驶汽车以及虚拟现实技术）的发展保驾护航，也能有效抵御中国对美国的经济与网络安全所造成的威胁。根据幻灯片某一页中的说法，中国正在通过“一带一路”倡议扩大其国际影响力，因此，美国必须在网络领域中对中国的企图加以反制。与此同时，文件还对中国在人工智能领域如日中天的发展势头表示了担忧，更将其作为美国发展国有5G网络的一项重要依据。


文件中，有关人士甚至建议美国将搭建安全5G网络所需的技术出口至新兴市场，以帮助民主国家共同抵御来自中国的威胁。备忘录表示，“最终，这项努力能够防患于未然，防止其它发展中国家受到中国‘新殖民主义’行为的侵害。”



备忘录称，中国正在成为这场人工智能“算法战”的最后赢家。政府如果继续对5G网络无动于衷，美国就将在信息领域永远屈居于中国之后。我们必须正视中国在人工智能领域取得的一系列成就，而移动网络在其中发挥的作用同样不容小觑。


目前，美国无线通信产业已经开始大举进军5G市场，包括AT&T、Verizon和T-Mobile在内的多家运营商已经对此投入了巨资。5G标准的制定工作也在顺利进行当中。韩国、日本以及其它一些国家同样紧随潮流，正在如火如荼地展开5G测试。备忘录中规定的三年期限也许已经无法满足要求，美国需要制定一份国家战略，加快发展步伐，早日建成5G网络。

这一举动引发外界对相关技术、组织和政治问题的强烈担忧，以及对“政府在商业活动中应发挥何种作用”这一问题的激烈讨论。


实施此项提案意味着美国政府将大举介入私营无线通信市场。这不仅将给美国的产业政策带来重大转变，也会严重打乱国内电信及科技界巨头的商业计划。


据报道，这项提案由特朗普政府国家安全委员会提出，呼吁美国政府在“中频段”（无线网络的工作频段之一）建立一个全国性的5G网络。


对于美国来说，虽然无线网络的安全性能以及来自于中国的竞争都是切实存在的威胁，但是，专家们仍然对该提案的可行性提出了担忧，并且对这项方案最终是否能够帮助国家建立起一个更加快速、更加安全的5G网络表示了怀疑。


根据专家们的意见，这项提案有可能带来以下问题：


1. 打乱私人投资计划


目前，美国各大运营商已经在5G网络的研发工作中投入了巨额资金，全国各地的5G网络测试正在如火如荼地展开。


  • 无线通信产业专家切坦·夏尔马表示：“目前，大部分无线运营商已经完成了初期布局，开始按部就班地推进投资。在这种情况下，如果没有足够的资金稳定市场，政府的介入无疑将给整个业界带来极大的混乱。”

  • 夏尔马认为，实现国有化之后，整个5G网络市场或许将变成缺乏竞争的“一潭死水”，将小型运营商以及其它的潜在参与者排除在外。


2. 业界哗然


该备忘录预测，此项政府提案将遭到卫星通信产业的强烈抵制（卫星同样在中频段工作，与国家安全委员会建议的5G工作频段恰好冲突）。同时，提案还将受到美国最大的两家有线电视运营商康卡斯特 ( Comcast ) 和查特公司 ( Charter ) 的反对。但是，其它公司很可能会对政府持支持态度：


  • 根据预测，T-Mobile将对此项提案表示强烈支持。目前，T-Mobile“正面临着全国范围内5G频率资源短缺的窘境”，政府的这项举动能够帮助T-Mobile与AT&T及Verizon在“一个更加公平的环境中展开竞争”。

  • 美国电信运营商CenturyLink也被视为政府潜在的支持者。CenturyLink拥有完善的光纤网络，而5G网络的运行离不开光纤的支持，CenturyLink可以借此机会大赚一笔。

  • 谷歌公司也将成为政府潜在的盟友。5G网络的推广将吸引更多人成为移动互联网用户，这对谷歌公司的广告业务来说是一次重大机遇。

  • 而其它运营商（包括AT&T、Verizon和Sprint）将对此项提案“喜忧参半”。


3. 时间紧，任务重


据业内人士透露，政府提案中规定的“三年期限”毫无可行性。即使是在激励措施到位，私人企业全力支持的理想情况下，在全国范围内部署完整的5G网络也要花费近十年的时间。


  • 不仅如此，5G网络的大范围部署将对光纤网络的稳定性提出更高的要求，国内光纤网络需要进行一次大规模的更新换代，才能满足5G网络的要求。

  • 该业内人士表示，政府想在三年时间内独立建成5G网络无异于“痴人说梦”。


4. 强大的政治阻力


联邦政府对私人投资经营的基础设施插手干预将招致多方面的强大阻力。


  • 联邦政府剥夺了各州及地方政府对于安装网络设施的主动权，此举将引起各级地方政府的不满。

  • 备忘录指出，国家可以在必要时强行征用建设5G网络所需的通讯频段，这将引起该频段现有用户（包括各级政府以及商业公司）的强烈反对。

  • 美国联邦通信委员会（FCC）负责监督通信频段的商业应用，并参与了现阶段5G网络的部署工作。作为美国政府的一个独立机构，FCC很可能不会积极响应政府的行政命令。这为将来美国政府的内部倾轧埋下了隐患。


5. 安全问题仍是一大挑战


作为提案的目标之一，美国政府希望建立一个高度安全的网络，以应对来自于中国和其他国家日益增长的安全威胁。但问题在于，5G网络由多种不同类型的网络连接共同组成，仅凭一个单频段网络无法确保其安全性。


  • 因此，只有当所有的通讯环节都位于这一网络中时，其安全性才能得到保障。

  • 即便如此，接入该网络中其它网络的安全性仍然无法得到保证。一旦被恶意网络入侵，网络中的所有设备都将面临威胁。


6. 网络设备市场已被高度垄断


文件还提出了另一个观点，即5G网络的国有化可能会使网络设备市场变得更加活跃。但事实上，目前移动网络设备的制造已经由少数公司所垄断。


  • 目前的无线设备生产由三家大型公司主导——其中没有一家是美国公司。

  • 华为（中国）的增长势头最为迅猛，爱立信（瑞典）和诺基亚（芬兰）紧随其后。

  • 考虑到日益强大的华为公司很可能会对美国造成威胁，美国政府已经禁止了国内大型运营商销售华为品牌的移动设备。今后，国有化的5G网络对市场平衡将造成何种影响仍然有待观察。


7. AI与5G毫不相干


文件认为，中国在人工智能领域如日中天的发展势头同样不容忽视。


  • 这的确是一个严重的问题。尤其是目前许多美国公司被中国拒之门外，他们在中国收集的数据也变成了一堆废纸。而中国公司却可以随意进入美国市场。

  • 但是，AI运算通常只在服务器级别的计算机系统中运行，与5G无线网络毫无干系。

  • 夏尔马称：“很明显，AI与5G其实是两码事。AI技术能从5G网络中受益，但5G网络并不是发展AI的必要条件。”
