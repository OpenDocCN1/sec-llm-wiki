# 美国欲用立法挡住中国科技公司，不怕中国反击？

**美国打压中国科技快速发展势头，保持本国绝对优势。**

  

![](../Images/c0b60e70c389f85dcaf6e4dab200ecbc.png)  

继前几日，华为遭美国运营商AT&T单方面取消合作后，美国国会两位重量级议员又提出“H.R. 4747，保卫美国通讯法案”，禁止政府采购或使用华为、大唐及中兴等中国公司的电信设备或服务，禁止把他们的设备和服务作为美国电信设施的核心技术组成部分。

  

该提案已于1月9日被提交到美国国会。在通过美国政府改革委员会的审议和批准后，按照程序将由众议院投票表决，通过后提交到参议院，最终由美国总统特朗普签署后才会成为生效的法律。  

  

![](../Images/e1ab281b72cd1235c48698274a82b92c.png)

  

新年伊始，美国针对中国科技企业的打压可谓是一波未平，一波又起。就在撰写该文之际，又传来消息称，出于国家安全考虑，美国议员敦促国内第二大无线运营商AT&T切断与中国手机厂商华为的所有商业联系，并反对中国电信运营商中国移动进入美国市场。

  

![](../Images/24a4cfceaa5977c889ae0c0ab7b0117f.png)

**为何美国屡次棒打中国企业？**

![](../Images/0db9a40e28d4eeb29b3cddd236e77a0e.png)

# 

# 

****【中国科技公司自身的原因】****

  

以前，在美国销售的廉价Android手机上，曾出现中国广告公司特意预装了后门安全漏洞，收集了数十万人的数据。据《纽约时报》报道，“美国政府表示，目前还不清楚这是出于广告目的的秘密数据挖掘，还是为中国政府收集情报做出的努力”。

  

![](../Images/e0313993ee58349b8203f33728dd717e.png)

  

此外，MacroPolo公布的大量开源数据显示，中国投资者拥有近2400家美国公司，雇佣人数超过114000人。对于美国来说，这些投资都是非常有争议的安全和政治话题。

  

# 

****【美国视中国为危害其“信息安全”和“国家安全”主要对象】****

  

之所以提出此提案，其主要原因是国会议员担心中国通讯厂商的政府背景，认为这些电信公司“时常受制于国家政策，并曾与中国政府共享一些敏感信息”。共和党德州民意代表MikeConaway表示，引进中国厂商的通讯设备将会危及国家安全，美国民众生活会被监控。这种担心也不是无中生有，近年来，美国政府和情报界多次提出对中国企业的警告。

  

![](../Images/0bd39f7806e1236ab4da2a054c0e986b.png)

 

美国政府中的中国委员会、CIA和FBI先后在2011年、2013年和2015年多次在年度报告中指出，华为和中兴等公司的装置可以让“中国政府存取美国敏感资料”。

  

美国众议院情报委员会2012年就曾因国家安全原因而要求美国电信公司不要与华为和另一家中国公司中兴合作。

  

![](../Images/4b9ac88a4f395de9bc3e0883b86c673b.png)

  

# 

****【美国一直对华持防范态度】****

  

美国政府对华为持谨慎立场的历史可以追溯到2004年，从思科对华为的专利侵权诉讼开始，后来便开始对中国企业采取防范态度。2011年以来，美国涉华337调查中华为的涉案频率越来越多。

![](../Images/11de609bf554e3ad39dff773e294f6ba.png)

  

**2011年7月，**美国交互数字通信公司、交互数字技术公司和IPRLicensing公司向美国国际贸易委员会（ITC）提出337调查申请，指控华为和中兴等侵犯了其带有3G功能的手机、无线网络设备、手提电脑等的专利。

  

**2012年4月，**美国Anu IP公司向ITC提出337调查申请，指控华为侵犯了其伸缩式USB接口电子设备的专利。

  

**2012年5月，**美国Flash Point科技公司向ITC提出337调查申请，指控**华为**和**中兴**侵犯了其电子成像设备的专利。

  

**2012年7月，**美国科技资产有限公司、Phoenix Digital SolutionsLLC公司以及PatriotScientific公司向ITC提出337调查申请，指控**华为**和**中兴**侵犯了其无线消费性电子设备及其组件专利权。

  

**2013年1月，**美国无线厂商Inter Digital指控**华为**、**中兴**等公司侵犯其一项关于手机的最新技术专利，美国ITC随即对涉案公司展开了337调查。

  

![](../Images/42dee7b29a30d5975bf65a3a22349afb.png)

 

**在奥巴马执政期间，**美国法案还曾限制中国制造的信息技术产品的进口和使用，特别是禁止美国运营商使用华为和中兴的电信技术。最新的参议院法案似乎要继续延续这一趋势。

  

**爱德华·斯诺登（Edward Snowden）****曝光的文件显示，**美国国安局（NSA）多年来始终在监视华为的服务器。这些文件还显示，AT&T一直协助NSA对华为进行监控。

  

![](../Images/f6353cf2d183a77c32ff8b3b3db259f5.png)

  

# 

****【打压中国科技快速发展势头，保持本国绝对优势】****

  

华为在高科技硬件生产方面与苹果、高通、英特尔、谷歌等公司展开竞争，并且优势正在不断加大。当然，三星的影响力也非常大，但其总部设在韩国，而韩国又是美国的坚定盟友，这可能会对三星有利。

  

![](../Images/76b1261840cad3b2c282b233d90d5b9a.png)

 

华为在研发投入上增长也十分迅猛，上升之势显著。2016年投入118亿美元的研发资金，与此相比，爱立信和诺基亚的研发资金仅为38亿和59亿美元，而且华为在设备制造能力和成本方面都占据着制胜优势。此外，两家欧洲公司的收入都低于华为，可以预料的是，2018年它们间的差距将进一步扩大。

  

![](../Images/d39e886472e0feb9c0993129c9590fd9.png)

 

另外，华为的电信研发方面的优势使其成为第五代无线系统（5G）的领导者，该公司正积极寻求新的标准和合作。在不远的将来，美国基本难以继续避免使用华为的技术。这家中国公司持有5%的5G专利，中兴也持有5%专利。

  

![](../Images/24a4cfceaa5977c889ae0c0ab7b0117f.png)

**中国人为什么不禁苹果？**

![](../Images/0db9a40e28d4eeb29b3cddd236e77a0e.png)  

华为进入美国屡次遭受阻扰，但相比之下美国的苹果却在中国一直畅通无阻，并占有大量份额。

 

究其根本，还是咱们中国的企业实力与美国的差距太大，这些公司出色的产品，让中国消费者欲罢不能，让咱们国内的产品无法替代它们。

  

![](../Images/5b71ea3b6054114c090cccabb4bb1a43.png)

  

再者，苹果作为全球化企业的典型代表，产业链上有太多中国企业参与，从上游到下游都有中国企业的深度参与，典型的比如瑞声科技、通达集团、安捷利实业、高伟电子等苹果“概念股”。可以说中国已形成了一条完整的产业链。

  

![](../Images/bcbb5c8074565b6c6a0bc48c1d76c822.png)

  

在苹果公布的2017最新705家供应商名单中，中国企业（含大陆地区、香港地区和台湾地区）有72家。苹果掌握的是技术和设计能力，将生产制造放在了中国、越南等国。如果限制苹果在中国手机市场上的销售，那在对苹果产生负面影响的同时将不可避免地对中国本土企业带来巨大的负面效应。

 

![](../Images/a1f6af6fcf87acbd4a0b8e151ab66c8f.png)

  

此外，苹果在中国加大投资力度，建立研发中心，招聘本地人才。蒂姆·库克一年要访华好多次，表达对中国市场的关切和投入之情。现在又将中国区iCloud的运营按照中国法律要求放在贵州运营。做好产品、做好公关、做好与政府的沟通，这是苹果能够在中国持续开展业务的重要原因。这对于华为和我国其他企业来说，也是很好的启发。

  

![](../Images/a378a5319b00660acd134c9c949d9f7e.png)

 

因此，经济一体化的同时，我们更要加强产业上游的开发和顶层的控制，形成核心竞争力，不但要有专利，还要有对整个供应链关键点的控制和掌控能力。相信中国会涌现出像苹果一样的本土企业，让全天下的人都想跟我们做朋友！
