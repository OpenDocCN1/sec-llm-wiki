# 艺术+科学之美：1900年的法国艺术家如何预测100年后的世界

艺术与科学是一对好兄弟。他们俩的合作，往往会让我们在美好的享受中，感受到艺术与科学之美，甚至会不经意间在小孩子的头脑里埋下科学的种子。  

同时，艺术家对未来的预测，往往也会让我们对未来满怀憧憬。例如，100年前，也就是1900年前后，Jean Marc CôTé等法国艺术家出版的一套明信片，就预测了100年后的生产与生活场景。

面对这样的预测，我们可能会惊叹，因为那时候的预测，很多已经以各种各样的形式成为现实；我们也可能会思考，如果让我们自己来预测，下一个100年又会是一番怎样的光景？

**公元2000年，学生将怎样上课**

把书本倒进漏斗里，经过机械搅拌，再魔术般地传输到由电线相连的头戴设备，知识就源源不断地输送到了学生们的头脑中。

![](../Images/c9343ee1d263329d3724f65fc8230c25.png)

虽然，此图看上去好笑得不得了，而书本如何通过搅拌就把知识转移到了头脑中，也让人不得其解。但是，在此图中，知识可以实现“电子传输”的真意已然实现。

现如今，大型开放式网络课程（MOOC）早已让我们足不出户，就能学习来自全世界顶级大学的课程。虚拟现实、增强现实技术也已经让我们拥有了一种更高效的学习工具。

**公元2000年的媒体**

艺术家预测，到2000年，男主人在家中躺椅上悠哉乐哉地听音乐或广播，而身旁又有娇妻相伴，真真的其乐融融！

![](../Images/8f140c8222d7656179aff7eee0a0dfc9.png)

现在，听广播这样的享受早已实现，并渐行渐远。目前，我们已经处在一个由电脑、手机、电视、平板、虚拟现实眼镜、街道LED显示器等设备构成的“多屏”世界中。

我们甚至还能通过宝可梦（(Pokemon Go）增强现实游戏，在办公室或街道上随手抓一两只小怪物。与此同时，Siri，Alexa等人工智能助手还可以让我们随时获取所需信息。

**公元2000年，如何与远处的亲友通话**

1900年，电报诞生也就五六十年，电话诞生也就二十多年。但艺术家大胆预测：21世纪，我们将能够用电线发送视频，并与我们的亲人进行现场对话。伟大的艺术家！惊人的想象力！

![](../Images/89b7610d3c23744dd230f8832b492641.png)

如今，我们还没来得及享受有线电话中昂贵的视频通话功能，移动互联网就快速地让我们能通过智能手机进行实时的视频聊天。Facebook、twitter、微信等众多的社交媒体则为人类打开了一个通向全世界的、更广阔的交流平台。

**公元2000年，如何打扫家务**

1900年，带孩子、洗衣服、做饭、打扫卫生——“佣人”在各种家庭辛勤劳作，是整个社会阶层不可或缺的重要组成部分。而艺术家预测，在21世纪，因为清扫机器的出现，她们打扫卫生的工作将变得更为轻松。

![](../Images/fd15aac8edbd64dc3c30fe105f00c9b5.png)

当然，作者的这一想象还相对保守，因为这一工具仍然需要比较麻烦的手动操作。

在今天，各种智能家电，包括扫地机器人，已经让家庭生活变得越来越轻松。当然，也让人们变得越来越懒。

**公元2000年，还有理发师吗**

艺术家预测，到2000年，理发店里，一台台的理发机器人一字排开，为顾客提供优质服务，而原来的理发师则转变成了机器人操作师。

![](../Images/dbc6e1a901d380bcd393a1ee86aa0612.png)

实际上，到目前为止，机器人理发师的想法仍未实现。但是，我们真的需要一名机器人理发师吗？如果有，它是否能为爱美的女士、先生们打造出各有所好，千变万化的发型？

**公元2000年，食物将由化工合成**

21世纪的厨师就像化学家、生物学家一样。他们的工具不再是各种炉灶与锅碗瓢盆，而是各种化学器皿，以及艰深的化学知识、合成生物学知识。因为，这时候的食物烹饪都采用合成方式获得。

![](../Images/244e565a6ec4a079ef00162ee91af603.png)

今天，科技或许正在通过上述革新改变我们延续了数百万年的饮食习惯。

利用干细胞技术从实验室里培养出来的人造牛肉汉堡、人造蛋黄酱等众多替代食品已经上市；蟋蟀、蟑螂等各种昆虫也正在被用于饼干、饮料等更多的食品生产中。此外，3D食品打印机也已经可以让我们方便地打印出我们想吃的食品。

**公元2000年，管弦乐队由机器人构成**

预备，起！

机器人演奏音乐？没问题！一群机器人演奏音乐，不在话下！

来到21世纪，当我们身处歌剧院，我们会发现，为我们演奏的管弦乐队已经被机器人替代。天可怜见，谁知道舞台上的是不是也是机器人？

![](../Images/145c880678d7c3d52db338598a2fe136.png)

当前，人工智能的进步，已经让机器变得日益聪明，甚至在某些方面超越人类：AlphaGo让人类围棋选手全面溃败；索尼用人工智能写了一首名为《Daddy’s Car》的歌；谷歌的人工智能产品A.I.Duet可以弹钢琴；微软人工智能小冰也发布了首支单曲……。

可以说，人工智能正在不断地挑战人类的文艺高度。但有一点毋庸置疑，艺术的多样性，在于人类个性、情感和经历的多样性。在艺术方面，人工智能想要完全替代人类，我们可不答应。

**公元2000年，建筑师的工作**

艺术家预测，在21世纪的建筑工地，可能还会有一些有创造力的人在工作，比如建筑师和设计师。他们会通过电线或无线电把指令发送给那些会进行施工的机器，包括机器人瓦工。这些繁重、枯燥而危险的工作，已经没有人会去做了。

![](../Images/30682d3c13ec2b132aca75cdf90878a7.png)

今天，建筑业这个曾经的“傻大黑粗“行业真的就在经历一场类似的数字化、自动化变革。

在建筑工地，我们已经能看到无人机在工地上空飞翔，并不断传回测绘数据；能看到机器人在工地上穿梭，替代原来的砌砖工人；还能看到可穿戴设备时刻监测、保护工人的健康与安全。

我们还能通过BIM技术，实现从蓝图到建设的全程可视化管理；能通过3D打印技术，以快得多的速度，打造出成本更低的房子。

**公元2000年，农民在干什么**

1900年，全世界的多数人口都在农田里谋生。而在2000年，这一数字将变得非常非常小。

艺术家预测，到2000年，当我们轻轻一按按钮，或者拉起一个闸刀，整个农田里的机器人就会开始自动收割庄稼。

![](../Images/efa633aa8a6d668b295c1586868b1432.png)

因为，与工厂一样，机器同样在接管农场。就像一位未来学家曾说：“未来的工厂只有两名员工，一个男人和一条狗。男人会在那里喂狗，狗会在那里让男人不要接触设备。” 

现如今，虽然我们还没有完全实现农业的自动化，但我们已经可以看到：遍布农田的传感器能够实时反馈土壤、湿度与温度等数据；机器人已经能够实现种子的自动播撒；天上的卫星与物联网能够实时预测农田周边的小气候；无人机能够快速巡视大片农田，并传回作物健康状况数据……。

时光飞逝，100年太短。现在马上就是我们踏入21世纪的第18个年头。

面对未来，我们依旧充满各种各样的憧憬。但是，我们会发现，我们关于未来的想象，在本质上可能会与100年前人们的所想并无区别。那就是：一个更美好的世界。正是这种想象，推动着人类不断前进。
