# 2018全球企业风投榜出炉，百度在AI领域最活跃

**企业风险投资（Corporate Venture Capital）可以说是如今一些科技巨头企业的标配了，无论是国内，还是硅谷。**

  

  

![](../Images/9d60c4cb6ce5bf7edef6fe8d7e9802fd.png)

  

企业风险投资（Corporate Venture Capital）可以说是如今一些科技巨头企业的标配了，无论是国内，还是硅谷。企业通过投资这项武器，对初创企业进行融资，依托母公司的业务为这些创新公司提供扶持，也在探索企业创新边界的同时，获得一定的回报。

  

例如，像硅谷著名的企业风投有Google Ventures，专注于扶持创新企业；微软旗下的企业风险投资子公司M12，主要投资企业软件初创公司等。

  

著名风投数据库 CB Insights 近日发布了 2018 企业风险投资报告，据其透露，全球企业风险投资去年共进行了 2740 宗交易，涉及金额高达 529.5 亿美元。

  

到底哪些企业风投最活跃？哪些企业风投投的独角兽最多？AI领域，最活跃的风投有哪些中国资本身影？硅谷洞察研究院对 CB Insights 2018全球企业风投报告进行编译、解读。

  

**全貌：2018年全球773家企业风投保持活跃**

  

  

相比 2017年，2018 年企业风险投资完成的交易数量增长了 32%，投资总额增长了 47%，达到 529.5 亿美元。其中最大一笔交易是谷歌母公司旗下专注于增长股权的风投基金CapitalG投资的货运物流公司 Manbang 的20亿美元。

  

![](../Images/288f017edf3aa536edfa4eb8a3e4781e.png)

（全球企业风险投资活动创历史新高，2013-2018年全球企业风险投资的交易数量和交易额）

  

仅2018年第二季度，企业风险投资 757 宗个企业风险投资交易和 141 亿美元的融资额更是创下历史新高。

  

![](../Images/2e5218a77a3c3a2f7ca6557e2a19d8ea.png)

（企业风险投资在整体风投生态里的贡献持续增长，浅蓝色代表企业风险投资的占比）

  

从上图可以看到，2013-2018年企业风险投资在整体风投交易里的占比逐渐增加，2018年，企业风险投资参与了所有风投支持的交易中的23%，比2017年增加了3%。相较2013年，这个份额增长了7%。

  

2018年，企业风险投资的平均交易规模达到了历史最高点——2630万美元，超过之前最高的2015年的2410万美元。

  

当然，同样的，没有企业风险投资参与的风投交易规模也达到了历史最高点：2180万美元，比2017年增长35%。

  

2018年企业风投的一大亮点是：众多新企业风投的加入。据 CB Insights 统计，264个企业风险投资进行了首次投资，比2017新增35%。新的企业风险投资公司包括Coinbase风投、Maersk Growth、保时捷风投等等。

  

从总数来看，全球约773家企业风险投资公司在2018保持活跃运作。

  

**地区：亚洲企业越来越吸引企业资本目光**

  

  

##### 从全球各地区来看，亚洲正在越来越多吸引着企业风投的目光，无论是中国、日本，还是印度。

  

##### CB Insights 报告显示，亚洲地区“斩获”2018年 38% 的企业风险投资，高于2017年31%的比例。欧洲交易份额下降至三年来最低——17%，而北美的交易份额也跌至历史最低点41%。其中，在2018年第三季度，亚洲交易数量首次超越了北美。

  

![](../Images/9a1011ed631b663ebd5e81fb186f6f11.png)

（亚洲继续缩小与北美交易份额的差距，2013-2018年按大陆划分的全球企业风险投资交易份额，浅蓝代表北美，橘色代表亚洲，深蓝代表欧洲，绿色代表其他）

  

##### 报告显示，中国初创企业吸引企业风投的兴趣比以往更多，获得投资金额增加51％至108亿美元，企业风险资本支持交易数量增长54％至351亿美元。

  

下图中，2015年，中国企业的融资总额明显高于2016年，这跟滴滴出行两轮 30 亿融资有着紧密关系。

  

![](../Images/a0199b8ac7f2a055bb4923054d19e3c3.png)

（面向中国的企业风险投资在18年创历史新高）

  

与此同时，日本初创企业也吸引了众多企业风险投资公司。

  

2018年，企业风投对日本公司的交易翻了不止一倍，从 2017 年的 158 笔增加到 2018 年的 317 笔，比例增加了101%。资金额度也显著增加，从9亿美金到14亿美金，同比增长56%。年度最大的交易是财富管理平台企业 Folio 的6300万美元的A轮融资。

  

企业风投也继续看到印度的潜力。2018年对印度创业公司的投资交易从2017年的59笔增长了20%到71笔，资金额略有增长，从2017年的16亿美元到2018年18亿美元。

  

尽管对亚洲地区表现出更多兴趣，但全球企业风投向美国企业的投资交易数量和金额仍创下历史新高：对美国投资活动增加了11％，达到1046笔交易，资金增加了28％，达到265亿美元——二者均创下历史新高。

  

**百度AI领域投资居首位**

  

  

从投资数量来看，去年前五大最活跃的企业风险投资集团当中，有两家是中国资本。

  

CB Insights 统计，2018年百度风投和中国投资控股公司君联控股的子公司君联资本，排在谷歌风投、Salesforce创投和英特尔投资之后，成功排在了企业风投的前五位。百度风投去年已经首次进入企业风投前五名。

  

![](../Images/1b2d457f5524d464e03de0073a65fc5c.png)

（2018年全球企业风险投资数量排名）

 

除了投资数量之外，百度以13起投资事件居于AI领域最活跃的企业风投公司名单榜首。M12 （微软）和 GV (谷歌) 分别以11起和10起AI领域的投资事件居第二和第三。

 

![](../Images/86925f4229e8339e716df90fa5ba74c3.png)

（18年人工智能领域最活跃的企业风投）

  

CB Insights 认为，这符合百度风投母公司百度的目标，百度在近年来正从中国领先搜索引擎发展成为一家在包括人工智能平台等各方面投资的全面技术集团。

  

同时，亚洲也成了企业风险投资在人工智能领域交易的温床。

  

CB Insights 认为，企业风险投资对亚洲人工智能创业公司投资份额很快会超过对北美公司的投资份额。2018年，对亚洲的人工智能公司的投资份额增长了13%达到42%，这已经是连续第二年超过两位数的增长了。同期，北美的交易份额大跌。

![](../Images/84b9f348965ea047f73458b631ea6f40.png)

（浅蓝色代表北美，橙色代表亚洲，深蓝色代表欧洲，绿色代表其他地区）

  

总体来说，人工智能的交易量和数额达到历史新高。

  

企业风险投资参与的人工智能交易从2017年的230笔增长了27%到2018年的291笔，交易额也从2017年的42亿美元增加了19%到2018年的51亿美元。2018年全球最大一笔人工智能交易是中国面部识别初创公司SenseTime（商汤科技）获得的6.2亿美元融资。

![](../Images/3f8f575c545cc6c97b684efdd2f57726.png)

（人工智能公司依然很受企业风险投资欢迎）

 

如果从投资的独角兽企业占比来看，谷歌旗下的 CapitalG 则成为投资独角兽最多的企业。

 

CB Insights 统计，CapitalG（谷歌资本，偏中后期）是最活跃的独角兽（十年以下，市值超过10亿美金）投资者，在2018年投资了9家独角兽公司。其次是投资了3家的谷歌风投（GV）、戴尔科技资本、君联资本、橙色数字风投（法国电信巨头旗下的风投）和高通风投则并列第三，分别投资了2家独角兽公司。

  

![](../Images/598676e13f1ddcdfc50e831871067767.png)

（2018年投资独角兽公司企业风险投资排名）

  

**投资关键词：互联网、移动端、网络安全、数字健康**

  

  

除了人工智能之外，CB Insights 还对企业风投的投资重点做出了分析。其中，互联网、移动端、网络安全和数字健康成为全年投资的几大关键词。

  

报告发现，互联网初创公司依然抢手，企业风险投资对互联网初创企业投入巨资。据CB Insights数据，这些由企业风险投资公司支持的交易同比增长36％，从2017的879笔交易增长到了2018年的1199笔交易。资金额则在2018年增长了80％，达到212亿美元。

 

![](../Images/f9511761e3c31ee2308c402079fda719.png)

（2013-2018年企业风险投资对互联网产业的投资数量和金额）  

 

例如，印度一家在线酒店预订初创公司Oyo Rooms，去年9月筹集了10亿美元的新基金，以扩大其国际业务。

 

去年，最吸引企业风险投资的其他行业还包括移动出行，其中东南亚打车巨头Grab和Gojek筹集了数十亿资金。

 

2018年对于网络安全公司来说，也是吸引企业风险投资的标志性一年。2018年总共有112笔交易，比2017年多19笔。但投资金额却增加到22亿美元，高出2017年42%。

  

![](../Images/18261a4ce6b7c03eeb6ddd13177c8b62.png)

（网络安全持续吸引企业风险投资）

  

从投资地区来看，尽管北美网络安全公司在整体企业风险投资交易中的份额相较于前几年有所减少，但比例保持稳定在65%，亚洲网络安全公司的份额则从2017年的20%略微升高到22%。

  

其中，英特尔资本成为了2018年在网络安全领域最活跃的企业风险投资公司，投资了6家网络安全企业。紧随其后的是新加坡电信Innov8和谷歌风投，两者都有5宗网络安全投资，通用电气风投和戴尔科技资本则投资了4家。

  

对于数字健康领域（Digital Health）而言，由于亚洲地区更多的投资活动，企业风投对数字健康领域的投资持续增长，并在一度平稳后终于在2018年爆发：从2017年的138笔交易增长到192笔交易，增幅高达39%。 但总交易额略微有所下降，从2017年的34亿美元下降到2018年的32亿美元。

![](../Images/db4e142405a0982e28fa6ac1984ad501.png)

（企业风险投资对数字健康的投资逐渐增长）

  

从获投地区来看，2018年亚洲占所有企业风险投资对数字健康公司投资交易数量的38%，比上一年高出7%。相比之下，美国地区占比则下降了7%，为41%。欧洲和其他地区仍然相对停滞不前。

  

![](../Images/7670ee41299158df81b348f6119afe62.png)

  

从投资主体来看，谷歌风投是2018年在数字健康领域最活跃的企业风投，投下了10家数字健康初创公司。之后是百度风投（6家）、前软银集团投资部门的SBI投资（5家），以及通用电气风投和Illumina风投（基因测序公司Illumina 2016年为其首个基金筹集了2.3亿美元资金，专注于投资涉及基因组学和精准医疗的初创公司）。
