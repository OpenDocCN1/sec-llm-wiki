# 光伏贸易破壁之路对当前中美贸易争端的启示

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651534911&idx=1&sn=6370debad853616ec335008abe820628&chksm=f18245cfc6f5ccd98a6df78c485fa51eb606d01013e192f3c59b6d028557ecfbd8f96df5745e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651534911&idx=1&sn=6370debad853616ec335008abe820628&chksm=f18245cfc6f5ccd98a6df78c485fa51eb606d01013e192f3c59b6d028557ecfbd8f96df5745e&scene=27#wechat_redirect)

**从2012 年开始，我国光伏产业接连遭到了来自美、欧、土、印等国家和地区的贸易制裁，但这些制裁未能阻碍我国光伏产业的高速增长步伐，我国光伏产业在国际市场竞争中的领先优势持续得到巩固。我国光伏产业贸易壁垒的应对经验，对处理当前中美贸易摩擦问题具有一定的借鉴与启示作用。**
