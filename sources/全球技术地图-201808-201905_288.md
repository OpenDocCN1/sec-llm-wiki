# 中国人工智能人才流失严重？四大学校62%毕业生赴美工作

**据AI初创公司Diffbot近日数据显示，在中国产出机器学习人才最多的四所一流高校中，62%的学生毕业后选择赴美工作。在全球上演高科技人才争夺战的背景下，AI人才流失的现象必须引起高度重视。**

  

  

本周二，全球最大规模的机器学习（Machine Learning，ML）人才调查报告新鲜出炉。

  

![](../Images/39fd6e2743f430f53ade17444490aa46.png)

  

调查报告来自旧金山湾区的数据公司Diffbot，它主要利用人工智能技术自动抓取网页关键内容，并输出软件可以直接识别的结构化数据。2016年，腾讯与硅谷风投机构Felicis Ventures曾领投Diffbot 1000万美元的A轮融资。

  

Diffbot在名为“Diffbot State of Machine Learning Report-2018”的报告中，利用“比谷歌还大”的知识图谱，获取了全球72万余名机器学习人才的分布情况。

  

![](../Images/b2814d3f132fc7a7e917a9f259eb9af1.png)

  

**报告显示：  
**

*   **拥有机器学习技能的近221600名工作者住在美国，占全球人才库的约31%。**
    

*   **在培养机器学习毕业生的四大中国大学中，其中62%的毕业生在美国就业。**
    

  

  

# 全球机器学习人才集中于美国

  

报告认为，全球有720000多人拥有机器学习方面的技能。

  

其中，美国是全球最大的ML人才聚集地。报告数据显示，拥有机器学习技能的近221600名工作者住在美国，占全球人才库的约31%。美国吸引的顶尖AI人才超过了第2到第10国家的综合。  

  

排在美国之后的国家是印度（59980人）、英国（27425人）、加拿大（19259人）和中国（18446人）。  

  

![](../Images/f528d1d51a0d68164df6f36f6d43f105.png)

  

在美国本土，加利福尼亚州是机器学习人才数量最多的州，74791名工作者住在该州。

  

考虑到雇用这方面的人才的多是硅谷科技公司，这一分布情况不足为奇。报告数据显示，排在加利福尼亚州后的三个州分别为：纽约州（约3万人）、得克萨斯州（约2万人）和马萨诸塞州（约2万人）。

  

![](../Images/ebe42cdab8d09127e30fd153878b0b3e.png)

  

  

# 中国名校六成ML毕业生赴美

  

报告显示，中国政府大力推行在2030年前成为全球头号AI创新中心的政策，但中国的大多数机器学习人才流向了美国雇主。

  

Diffbot认为，中国在机器学习人才的培养上成绩斐然。除美国以外的全球培养机器学习人才的TOP10大学中，中国高校就占据了5席：

  

*   清华大学：排名第一，输出毕业生5166名
    
*   北京大学：排名第二，输出毕业生3471名
    
*   上海交大：排名第六，输出毕业生3005名
    
*   浙江大学：排名第七，输出毕业生2899名
    
*   中国科大：排名第十，输出毕业生2740名
    

  

![](../Images/a7fd64af57e692eacdc9eedc712b0246.png)

  

**但数据表明，清华、北大、上交和中科大的毕业生只有31%留在了中国，而62%投奔美国。**

  

这些机器学习人才都被吸引到哪了？从雇佣机器学习人才数量上看，微软（14965人）、IBM（11087人）和谷歌（10247人）等科技巨头以及塔塔咨询（6348人）、埃森哲（5918人）等咨询服务业吸引了最多的人才。

  

![](../Images/1084c3b03041e3e206c3c72fc454ef0f.png)

  

卡内基•梅隆大学（3854人）和斯坦福大学（3526人）则是最大的机器学习学术型雇主。

  

  

# 总结

  

**从报告数据上看，就人工智能人才而言，美国仍然遥遥领先于世界。**另据LinkedIn数据，中国从业经验10年以上的人工智能人才比例不足 40%，而美国的这一比例则超过 70%。

  

从人才分布角度看，中国人工智能领域人才分布不均匀。据2017年数据统计，中国人工智能基础层、技术层和应用层的人才数量占比分别为 3.3%、34.9% 和61.8%。相比之下，美国人工智能领域三个环节的人才数量占比分别为 22.7%、 37.4% 和 39.9%，人才分布更加合理均衡，更有利于产业的持续发展。

  

作为一种颠覆性技术，人工智能在产业升级、经济发展、社会进步中的价值不言而喻。但专业人才不充足、分布不均衡的现象突出，将会限制中国相关产业的发展以及与实体经济的深度融合发展。中国人工智能产业结构与美国存在的差距，或将继续加剧人才分布的不均衡与人才的流失。

  

该报告并未明确定义“输出毕业生”是从哪一年开始算的，参考性尚待进一步讨论。但全球正在上演人工智能人才争夺的大戏，人才流失的现象必须引起我们高度重视。
