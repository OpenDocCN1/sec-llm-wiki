# 新概念武器不断走向实战化

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651533781&idx=1&sn=428f2e23519008a489a02c5250e130f7&chksm=f1824225c6f5cb33367a8e353f59adc065c9ee674e7daee9d5b9a688fada0249da9da42fdfb0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651533781&idx=1&sn=428f2e23519008a489a02c5250e130f7&chksm=f1824225c6f5cb33367a8e353f59adc065c9ee674e7daee9d5b9a688fada0249da9da42fdfb0&scene=27#wechat_redirect)

![](../Images/90a3cdf1ee27e4b183e602b1583dcd36.png)  

  

**当前，世界主要军事强国为增强其军事实力，正加快对激光武器、微波武器、电磁炮武器、高超声速武器等新概念武器的研制工作，以进一步扩大技术优势，力争在未来战争中占据优势地位。新概念武器是一个国家高技术创新能力的综合体现，这些技术一旦突破，或将引起装备体系和作战能力的重大变革。当前，世界主要军事国家的新概念武器正由技术验证转向武器研制阶段，实战化进程不断加快。**

  

  

![](../Images/7cee695f88f09a2d1d9a03e7cc641a31.png)

**激光武器**

![](../Images/181ab6b4b28f04bcc630df0034d9d7f6.png)

  

**激光武器具有快速、灵活、精确和抗电磁干扰等优异性能，可利用高能激光对近距离目标进行精确射击或用于防御导弹。**

  

**美军在激光武器领域的研发进程十分迅速，并已取得阶段性成果，预计于2020-2022年实现武器化 。**目前，美陆军已成功试验5千瓦、10千瓦车载、机载激光武器，并接收了洛马公司交付的60千瓦激光器，计划于2022年试验100千瓦激光器。同时，美空军正在开展“下一代紧凑型环境下激光改进”项目，研发小型光纤合成激光器，计划于2030年前后将激光器集成到战斗机上。

  

![](../Images/1a1fc8b256adad29f5269abfb0023f45.png)

  

2018年3月，美海军授予洛马公司一份价值1.5亿美元的合同，用于研制“高能激光和集成光学杀伤监视系统”（HELIOS）。该系统可摧毁无人机和小型舰艇。另一方面，美军还计划将激光武器应用于无人机反导技术领域，利用无人机携载高功率激光武器进行渗透式打击，摧毁敌方弹道导弹。

  

![](../Images/490652cd6d9982f9bd9485915c71e51a.png)

  

与美国相比，俄罗斯是第一个在激光武器领域取得重要成果的国家，并正不断恢复苏联时期的研制技术和项目。2016年俄罗斯就已研制出激光武器原型机，完成了由试验阶段到武器化的转型。2018年3月，俄罗斯在公布的视频中，展示了大型车载高能激光武器系统。该系统为陆基反导激光武器，可精确击落空中来袭导弹。同时，俄罗斯军工部门成功研发的新型A-60机载激光反卫星武器可携带大功率激光器，通过密集能量激光脉冲的致盲软杀伤方式瘫痪光学侦察卫星。

  

![](../Images/7cee695f88f09a2d1d9a03e7cc641a31.png)

**微波武器**

![](../Images/181ab6b4b28f04bcc630df0034d9d7f6.png)

  

**微波武器，又称电磁脉冲武器，是当今世界主要军事强国的研发热点之一。微波武器通常在远距离上对军事目标和武器的电子设备进行干扰，近距离杀伤有生力量，引爆各种炸药或直接摧毁目标。**

  

![](../Images/f07ae5cd70aff69c451858cd61dedd4d.png)

  

美空军认为高功率微波技术是一种能够改变战争格局的技术。近年，美空军以高功率微波武器（CHAMP） 项目为牵引，重点围绕机载应用，着力发展高功率微波武器技术和相关效应研究，同时积极探索新型CHAMP。该武器可夺取战场内的制电磁权，这对于美军利用微波武器打击重要战略目标具有重要意义。

  

![](../Images/28ace324ac20c8da371cc445caf0d702.png)

  

**俄罗斯的微波武器及其技术经过几十年的研究与发展，已具备武器化能力。**进入21世纪后，俄罗斯已研发出Ranets-E、Rosa-E及Krasukha系列等微波武器。2017年10月，英国媒体称俄罗斯军工企业正在研制新型电磁导弹“阿拉布加”（Alabuga）。该导弹可切断3.5平方千米区域内敌方所有导弹弹头和飞机机载通讯系统之间的联系，还可让坦克的电子系统停止工作，甚至可对地下100米深的电磁设备进行有效打击 。

  

当前，美俄在高功率微波武器的实战化方面，都已取得一定进展，并不断加大对高功率微波武器发展的支持。高功率微波武器将逐渐成为未来战争的主力武器。这类新型攻击手段一旦在战场上应用，将给战场网络空间、电磁空间装备的防御带来巨大挑战。

  

![](../Images/7cee695f88f09a2d1d9a03e7cc641a31.png)

**电磁炮**

![](../Images/181ab6b4b28f04bcc630df0034d9d7f6.png)

  

**电磁炮是利用电磁发射技术制成的一种先进动能杀伤武器，具有速度快、射程远等优势，可提高舰船的火力打击与防御能力。**

  

![](../Images/84751435c04a71bb4fdf6c3b90de04ba.png)

  

**目前，美军正在大力发展基于电磁能的电磁导轨炮，并已建成试验系统。**2018年3月，美海军研究办公室电磁导轨炮的样炮首次重复发射试验取得成功，为电磁导轨炮转入工程研制奠定基础。随着发射器结构与材料技术、高功率脉冲电源技术等关键技术的进一步突破，电磁导轨炮有望于2025年前后安装到下一代美海军主战平台上，弥补舰炮与舰载巡航导弹之间的火力覆盖空隙。

  

当前，美国已突破电磁导轨炮连续发射涉及的电力供应、炮弹填装等技术瓶颈，这标志着电磁导轨炮向实用化迈出重要一步。

  

![](../Images/7cee695f88f09a2d1d9a03e7cc641a31.png)

**高超声速武器**

![](../Images/181ab6b4b28f04bcc630df0034d9d7f6.png)

  

**高超声速武器飞行速度可达5马赫以上，当前的防御系统难以拦截，对提高军事快速打击能力具重要意义。  
**

  

![](../Images/d04b172458a8007367ca642da78fe5f8.png)

  

DARPA在2019财年预算中申请的高超声速科研经费同比增长136%，并呼吁启动国家级高超声速规划。在高超声速导弹方面，目前美国主要依托“高超声速吸气式武器概念”及“战术助推滑翔”项目开展高超声速巡航导弹技术和高超声速助推滑翔导弹技术的飞行演示验证工作。**2018年4月和8月，美空军先后授予洛马公司“高超声速常规打击武器”和“高超声速空射快速响应武器”合同，充分表明美军对高超声速武器研制的重视。**美空军预计战术级高超声速导弹将在2025年形成装备，一旦部署将成为改变战争格局的新的作战利器。

  

![](../Images/f0fca5f0901a29ebf153f4f63de28136.png)

  

**俄罗斯也是世界上最早研发高超声速武器的国家之一，在高超音速技术上处于世界领先地位。**在高超声速导弹方面，2017年4月，俄罗斯成功完成世界首型高超声速反舰导弹“锆石”的试射。该导弹最大飞行速度达到8马赫，是当今世界上飞行速度最快的导弹。2018年3月，俄罗斯成功试射“匕首”高超声速导弹。5月，10架配备了“匕首”高超声速空射巡航导弹的米格-31战斗机完成作战任务试验。同时，俄“先锋”高超声速助推滑翔导弹也进入生产阶段，预计2019年入役。在高超声速飞行器方面，目前俄罗斯在研代号为“4202项目”的Yu-71高超音速飞行器试验。该飞行器可安装在RS-28“萨尔马特”洲际弹道导弹上，最高速度可达7千米/秒，可有效突破美国的国家导弹防御系统。

  

当前，美俄的高超声速飞机依旧处于概念研究或演示验证阶段，但高超声速导弹已由技术验证阶段转向武器化阶段，这将大幅提升其战略打击与威慑能力。

  

![](../Images/7cee695f88f09a2d1d9a03e7cc641a31.png)

**小结**

![](../Images/181ab6b4b28f04bcc630df0034d9d7f6.png)

  

**新概念武器在功率、速度、射程、精度等方面将使未来战争中全维作战成为常态，尤其是电磁空间和太空空间的作战。同时，新概念武器实战化进程加快，将提高作战行动的隐蔽性和突然性，增加侦察、探测及拦截的难度，或将彻底改变战争模式。**
