# 美国防部在关键技术领域持续发力

**编者按：中俄在定向能、微电子、高超声速武器等领域的技术进步一直被美国防部所关注。美国多次表明将加大技术领域投入与中国和俄罗斯展开技术竞赛，也曾公布其技术研发优先领域。现将美国防部高官对技术研发优先领域的最新表态编译如下。**

  

  

在美国国防工业协会8月22日举行的活动中，负责研究和工程的助理国防部长玛丽·米勒阐述了定向能武器、人工智能、量子科学和下一代通信等技术的更多细节。  

  

定向能武器

  

定向能武器将会应用在飞机、船舶、坦克和太空中。米勒表示，除海岸警卫队外，所有军种都在定向能领域展开研究，尝试制造定向能武器的原型。而之所以在定向能领域花费巨额资金，是因为军队必须了解和利用定向能技术。

  

![](../Images/fe541e9d9f3e0da1799cd93d15f368a6.png)

  

如今光纤激光器成本下降，将大规模强力激光武器的制造成本、重量和效率维持在合理水平变得可能，而这在几十年前根本无法想象。国防部也注意到了新近出现的高能微波武器应用，例如雷神公司的反电子高功率先进导弹项目。

  

米勒认为国防部在定向能领域需要做的还有很多，尤其是提升定向能武器的威力。目前国防部可以将定向能武器功率做到100千瓦，而要想在导弹升空阶段对其进行拦截，功率至少要达到300千瓦。

  

但提高定向能武器功率并不能解决所有问题。国防部在海基或陆基1兆瓦定向能武器的研究上发现，由于被称为热晕的物理现象，定向能武器发射时会在前方产生等离子体，导致武器发射出的能量并不会全部击中目标。只有通过定向能武器原型和更多相关研究解决上述问题，国防部才会确定开展定向能武器项目。

  

**美国2018财年在定向能武器领域的支出为6.61亿美元，计划2019年到2023年总支出22.8亿美元。**

  

通讯、网络和太空

  

美军多年来一直为不稳定的通讯系统所困扰。米勒称，在阿富汗基地曾出现作战小队离开离开基地后与通讯网络断开连接，回到基地后重新连回通讯网络的情况。通讯系统的稳定性是美军必须解决的问题。  

  

**在未来战场，每个士兵、卫星、作战车辆，甚至是核武器都应该处于数字网络中。**美军要建立这样的联合网络多域战场，统一且无处不在的通讯系统是关键推动因素。

  

![](../Images/b37627b024be03fc69b389beb5a81912.png)

  

米勒表示，国防部正在研究建立一套联合通讯系统，能够向下兼容所有军事机构，指挥官可以同任一层面人员进行沟通。为实现这样的目标，建立无法切断的通讯系统是必要的，而美军在这一研究上所获甚少。为此，国防部也关注近地轨道卫星成本和尺寸急剧下降等商业趋势，希望从中找到解决问题的方法。

  

国防部面对的另一个问题是，如何在充满复杂干扰的环境中，保证老旧的通讯设备正常工作。多年来，军方和工业界一直在尝试通过软件来创建无线电通讯功能，使通讯功能在老旧设备中也能运行。这种“软件定义的无线电”比传统无线电更容易在频率之间切换，从而加强了它们对抗干扰的能力。

  

目前，国防部还在研究如何使软件定义的无线电向后兼容，相关实验还处于早期阶段，但国防部保证将完成此项开发。

  

**美国2018财年在通讯设备研发上的支出为83.8亿美元，计划2019年到2023年总支出408亿美元。**

  

国防部正在研究适用于太空的新通讯体系，以实现商业卫星与军队更好地结合。为了使士兵和机器与地面和太空之间的通信变得更加稳定，国防部正在将大量资金投入到更不易被拦截的光通信研究中。

  

**美国2018财年在太空现代化研发上的支出为6.19亿美元，计划2019年到2023年总支出24.8亿美元。**

  

微电子

  

微电子将会成为未来十年美国的国家安全问题之一。  

  

米勒表示，中国拥有到2030年主导全球微电子市场的雄心壮志，美国估计未来10到15年内中国将在微电子领域投入1500亿美元。中国政府估计，届时中国将占据全球70％的微电子市场。

  

![](../Images/7474691f55d06914a9a94836438afe35.png)

  

美国对中国在微电子领域的动向非常关注，投入大量资金建立公私合作关系，希望将微电子制造、研究和设计引回美国。对美国而言，研究和设计比较容易，但因为多年前制造业转移至廉价劳动力市场，如何让制造业回归是一个巨大的挑战。制造业外流是一个趋势，国防部急于扭转，至少也要在某种程度上缓解这一趋势。

  

**美国2018财年在微电子研发上的支出为4200万美元，计划2019年到2023年总支出22亿美元。**

  

人工智能和自主性

  

关于国防部建立联合人工智能中心的新计划已经多有提及。米勒警告要注意人工智能的行业炒作，称现在行业宣传中关于“人工智能”的大部分内容只是科学数据。国防部希望人工智能系统可以帮助指挥官和操作员做出更好的实时决策，但人工智能距离这一要求还有很远。

  

![](../Images/642d504ea53f7ea25fe24cbedb2ca974.png)

  

米勒认为自主性的关键在于人与智能机器间的交互，因此她将自主性列为一个独立的类别。如何让人们信任与高度自主性系统之间的交互过程，是一个快速发展的新兴领域。在私人和商业环境中，有与此相关的大量低风险实验。国防部的情况则完全不同。

  

国防部明白如何利用人工智能改进军队后勤和加快决策制定，但其指导如何利用机器自主性的相关政策仍然在不断变化。米勒称，国防部将加快制定政策指导对机器自主性的运用。

  

**美国2018财年在人工智能和自主性上的支出为19亿美元，计划2019年到2023年总支出103亿美元。**

  

量子科学

  

米勒指出，量子科学研究仍处于起步阶段，但已经被过度炒作，尤其是在可扩展量子计算方面，人们对制造一台操纵量子比特而不是二进制比特的计算机炒作尤甚。但国防部已经发现了近期量子科学在精确导航和定时上的一些应用，目前精确导航和定时主要依赖全球定位系统。  

  

![](../Images/e47576b32510b4e18717f8383d7814a9.png)

  

国防部还在探索先进的加密措施以防范未来量子计算机可能带来的威胁，解决信息安全极客普遍关心的安全问题。

  

**美国2018财年在量子科学上的支出为9600万美元，计划2019年到2023年总支出5.65亿美元。**
