# 贸易战思考：药价高企戳痛美国社会，特朗普对原料药下手真的想好了吗？

**辉瑞和其他企业应该为他们毫无理由上调药价感到羞耻，他们在占穷人和其他无力还击的人的便宜，同时却为欧洲等其他地区提供打折优惠！我们会还击！**

**                                         ——唐纳德·特朗普**

特朗普急了。对于2018年5月14日刚在白宫玫瑰园推出《美国病人优先》蓝图，誓要以“最彻底的改革”大幅降低处方药价格之后，以辉瑞为代表的美国药商大幅提高部分药品价格的“唱反调”行为，特朗普在推特上进行了强力“炮轰”。这一炮不仅轰出了美国药价高企的难以撼动，也吐露出美国民众深受高价药剥削的现状以及特朗普对此强烈的不安。毕竟，美国药价之高始终是特朗普的一块心病，降低药价也是其在竞选和国情咨文中给出的核心承诺之一。而在国会中期选举仅剩3个月之际，民调结果民主党却还以45%：41%的比例领先，这怎能不让特朗普着急。![](../Images/8d9974e17284e91098b536fcc3c76c60.png)**美国药价到底有多高？**《我不是药神》中的天价救命药戳中了国人的痛点，而大家想象不到的可能是一向以“民主、保护人权”等形象示人的美国也面临着诸如药企垄断、利益勾结、控价无力、中间商赚差价等一系列问题，导致药价失控上涨成为社会顽疾。据2018年3月美国国会发布的报告显示，2012-2017年间，美国最受欢迎的品牌药价格相比于通货膨胀上涨近10倍；在20种老年人处方药中，近1/3的药品在上涨了100%，其中涨价幅度最大的是一种治疗胸痛的硝酸甘油药品，平均每粒由20美分涨到1.14美元，增幅达477%。在抗癌药的领域，美国过去10余年新抗癌药的平均价格翻了5-10倍，癌症治疗的人均花费达到了10万美元/年。在处方药领域，美国人均处方药年消费额达1000美元，年均总消费额3700亿美元，成千上万的美国人每年在处方药上的花费超过10万美元。![](../Images/8d9974e17284e91098b536fcc3c76c60.png)******    特朗普有没有缓解药价高企的现状？******

  

特朗普自竞选之时便多次承诺将采取有效措施降低药价，上台后还曾邀请包括默克、诺华、礼来等多家制药巨头的高管，以及美国医药行业游说机构、药物研究机构和制药商协会高管进行会谈，督促药厂降价的同时，承诺削减监管规定、精简美国食品和药物管理局、加快新药上市审批流程以及降低药企成本等。  
然而制药巨头对此似乎并不买账。据彭博社2018年8月1日对6大类40种常用药的调查数据显示，自2015年特朗普宣布竞选美国总统至今3年的时间中，这6大类常用药的价格一直在不断上涨，根本没得到有效控制。

  

![](../Images/106a4efd5055abad5eee2c222fe50f4b.png)

  

其中，自身免疫类药物的涨幅最大，达40.1%；癌症治疗类药物涨幅次之，达30.9%；紧随其后的是多发性硬化治疗药物，涨幅为30.6%；哮喘和慢性阻塞性肺病治疗药物涨幅为27.7%；糖尿病治疗药物涨幅为25.6%；艾滋病治疗药物价格涨幅达24.7%。而相比之下，美国社会消费者物价指数CPI为5.6%，意味着这6大类药物的价格增速远超一般消费品。  
从单个药品价格的角度来看，由辉瑞公司风湿疾病治疗药物依那西普的价格上涨了53%；由艾伯维生产的全球最畅销药物修美乐的价格上涨了52%；由拜耳生产的癌症治疗药物多吉美价格上涨了51%，每一片药丸的价格就高达155.59美元（约合1042元人民币），意味着一名患者服用一个月的多吉美的大概花费约达18670美元（合12.5万人民币）。  
据悉，彭博社的调查数据都是市场标价，但美国医药市场价格极不透明，在推广销售过程中还有多级经销商加价和各类回扣，普通患者到手价格通常会比市场标价更高。  

  

![](../Images/899a9c6cfb8312af02ff6b8b843f2e91.png)

2018年以来，从2月1日至7月15日期间，美国共计255种品牌药物的价格有所增加，最为集中的涨幅范围为9%-10％的区间。

  

![](../Images/5fa8df7d02def77baec2677ae572e0c5.png)  

  

由此可见，在特朗普正式执政的这两年间，美国药价上涨的趋势非但没有得到逆转，反而仍保持着较高的上涨速度。对于患者而言，药价仍是美国消费者难以承受的消费开销之一。**特朗普控制药价的承诺沦为了一张空头支票。**

![](../Images/8d9974e17284e91098b536fcc3c76c60.png)  

********制裁中国原料药真的想好了吗？********

  

原料药，即药物活性成分（API），是生产各类制剂的原料药物，其采购价格和供应量直接影响了药物制剂的生产成本，尤其是低成本普通药物。  
  
2018年4月，美国贸易代表办公室公布了新版贸易制裁清单。除航空航天、信息和通信领域外，**首次自中国进口的将糖尿病患者使用的胰岛素、抗过敏药物肾上腺素，以及抗生素、疫苗、血液制品和抗抑郁类药物的原料药纳入其中，建议对其加征25%的关税。**  
该清单一出便引起了美国各界的强烈议论。其中最具代表性的为彭博社发表的《中国对药物的锁定》。文章指出，特朗普打击处方药价格飙升和解决贸易不平衡的两大“支柱”似乎正处于相互矛盾之中。因为美国市场许多基本药物的关键成分，从抗生素、避孕药到癌症、抑郁症、高胆固醇、艾滋病药物，都是从中国购买的。中国是世界上唯一的抗生素来源，包括被称为人类抵御细菌的最后一道防线“万古霉素”。这些药物不仅存在于医院，更存在每一个美国家庭的药箱中，甚至是军队的药物。据美国食品药品监督管理绝（FDA）的统计数据显示，美国使用的API有80％来自中国或印度。北京方面一旦通过提高制造必要药品所需的原料药价格或减少供应对美国加以报复，将迫使制药公司不得寻求中国以外的其他供应商。而这些上涨的部分终将转嫁给消费者，导致价格上涨。  
Global Data表示，特朗普不断提到要降低药价降低患者的医疗成本，但其出具的关于原料药的关税清单却恰恰相反。美国仿制药公司，尤其是潜在的生物仿制药制造商一直专注于简化运营，如果贸易战升级，这些公司将不得不在价格受限的情况下大幅削减利润。**这可能会减少研发投入，从长远来看将会损害美国的创新。**  
美中经济与安全审查委员会前成员丹尼尔斯莱恩甚至提到：**美国对中国原料药的依赖已成为国家安全问题。**

  

综合近期动态来看，不得不说特朗普政府为控制药价上涨的确做出了实质性的努力。包括今年5月推出《美国病人优先》蓝图，提出加快药品审批流程提高生物制剂的创新和竞争、增加医疗保险的药价谈判权利、要求药企标注价格促进价格透明化，以及明令禁止药企限制药剂师告知病人降低药品支出的做法。7月，美国推出《FAIR药品定价法案》，要求制药公司在一次性提高药价10%以上或三年内提高25%时需提前通知、提供理由并公示药物的制造成本、研发成本、净利润及广告费用等。7月19发布《生物仿制药行动计划》，以求促进生物仿制药的研发创新和市场竞争，增加生物制剂产品供应并较低市场价格，进而降低美国的医疗成本。8月7日允许利用“医保优势计划”作为谈判工具，为患者提供与私营部门保险公司相同的议价和选择权力，迫使药企在价格上进行竞争，以降低医保药品的价格。但特朗普显然忽视了美国制药产业对中国原料药的严重依赖。在药价高企戳痛美国人民，威胁自身执政承诺的背景下，特朗普对原料药下手真的想好了吗？
