# 全球科技发展呈现新趋势新特点

**当前，新一轮世界科技革命和产业变革方兴未艾，正在对全球经济发展、社会进步和人类文明产生重大而深远的影响，在2019年浦江创新论坛上，与会专家针对不同领域，从不同角度对科技发展新趋势进行了深入探讨，且一致认为，全球科技创新进入了空前密集的活跃期，科学技术以前所未有的力量驱动着经济社会的发展。****把握好历史大变革的趋势抢抓新的发展机遇，是我国赢得未来发展的关键。**

  

  

**一、认识全球科技创新新趋势和新特点**

  

  

在当前时代背景下，全球科技创新正呈现出新的特点，大会期间，与会者对全球新科技创新新特点各抒己见，并形成了基本共识。  
  
**一是“创新超速”**。新技术的出现，促使创新速度进一步加快，计算能力、大数据发展、传播速度、语音设备、生物科学、3D打印、机器人，这些技术引擎将会帮助研究者以空前的速度取得创新进展。如集成电路领域如今已进入后摩尔时代，超越摩尔已成为竞争趋势，但要实现超越摩尔的路线仍面临诸多困难，集成电路技术发展没有弯路，没有捷径可走，应进一步夯实创新基础，顺应创新超速的契机，奋力前行。再如交通领域，为实现更低甚至接近零的能源边际生产和输配成本，更快捷、更智能和更高效的新型交通体系需求将加速推动超高速、空地一体化的交通技术创新和发展。  
**二是“深度融合”**。如今全球科技创新发展的态势，正呈现“跨界融合、协同联合、包容聚合”的三个突出特点，学科之间、科学与技术之间、不同技术之间、自然科学与人文社会科学之间的交叉融合日益凸显，科技创新正加速突破地域、组织、技术的界限，以开放推动引领创新已成为当今世界的大势所趋。人工智能、云计算、大数据这些新技术领域的一个非常显著的共性特征就是基础科技和社会变革之间的相互交融。  

**三是“应用多样”**。未来新技术的价值将不断在新的应用场景中得以体现。如人工智能已经在不同医疗场景体现了巨大的应用价值，目前人工智能技术已经渗透到了影像分析、智能问诊、健康监测等不同的医疗环节。而大数据和人工智能技术与宏基因组测序技术相结合，将在开展大规模微生物群的数据整理、探索不同基因群与功能之间的关联性等方面体现重要价值。在集成电路领域，随着5G的时代到来，无论是在智能手机、汽车等各种终端领域还是在基站、网络架构环节或者各种由于5G带来的应用场景上，都将给集成电路的技术发展带来很多机会。

**二、把握未来科技创新前沿领域新方向**  

  

围绕“集成电路、人工智能医疗、工业互联网、微生物群”等重点领域，与会者深入探讨了领域技术发展的新方向。  
  
**▷ 集成电路**：**一是新材料、新工艺和新架构将成为未来集成电路的研究重点。**追求高性能、长寿命、低成本是主要趋势，未来我国要在新三代半导体材料、绝缘材料、高分子材料等基础材料的技术突破上进一步下功夫；**二是如何实现超越摩尔是未来集成电路技术创新范式变革的重要方向。**“硅－冯”模式在很长一段时间内仍会是主导，但未来集成电路技术会继续拓展方向。  
**▷ 人工智能医疗**：**一是弱人工智能逐渐向通用人工智能跨越**；当前的AI还处于弱人工智能阶段，在数据感知、知识获取、融合推理等方面还需进一步开展技术攻关，但是包括机器主动学习、人机交互等一系列技术都已经在医疗领域获得了深度应用，所以医疗是未来AI发展的主战场。**二是以患者为中心的智能医院是未来努力的方向**。人工智能+医疗的发展应该围绕复杂医疗场景中进行攻关，围绕疾病的诊断、治疗和医院管理三个方面打造超级医生助手，优化医疗资源的配置，提升医疗服务质量。  
**▷ 工业互联网**：**未来应在数据技术，安全技术，工业APP三个方向上有所突破**。工业APP要向标准化、轻量化、模块化发展，可以采用微服务技术，通过工业互联网平台实现网络化的调用，并将其进行云化改造迁移，实现工业云共享。工业APP的发展主要有三个路径，一是个体自我模式，个人或班组为解决流程操作和数据分析问题而开发的小应用；二是企业自我模式，班组的应用形成生产线，和其他的班组连在一起，实现数据共享；第三是商业共有模式，即工业APP供给公众使用，在平台上实现行业共享。  
**▷ 微生物群**：**一是开展基础研究探索机制原理**，围绕微生物群组成、功能及互作机理，特别是与疾病的关联性等领域，开展广泛深入的基础研究；**二是开展应用研究开发预防诊断治疗产品**。对微生物群进行改造，使其对代谢过程产生影响，有望用于诊断与治疗，并开发微生物制剂，推动产业化应用；**三是开展标准研制保障研究质量控制**。进行标准研制，标准化实验条件与实施方案，规范样本收集与处理，有效控制实验过程，保障数据采集的质量；**四是开展大数据和AI技术应用研究理清高维度系统复杂性**，进行大规模微生物群的数据整理，探索不同基因群与功能之间的关联性。  

**三、重视科技竞争新机遇和新挑战**  

  
当前，站在全球创新发展的十字路口，面对各种变化变革、风险挑战以及一系列的不确定性，要以更加宽广的视野和博大的胸怀，牢牢把握世界科技革命和产业变革的大趋势，不断推动创新从突破走向成熟。  
  
**一是把握新机遇。后摩尔时代为我国集成电路技术自主创新带来新的机遇**，我国巨大的市场需求和在集成电路应用领域积累的丰富经验将给我国企业和应用领域带来更多的活力，可重构计算作为后摩尔时代的一个重要技术创新范式，目前我国已走在世界前列，未来有望能占领先机。上海已经成为国内人工智能医疗产业发展的前沿阵地，研究基础条件在不断夯实，产业发展条件优越，政策条件也初具优势，未来在交叉融合方面的合作研究、深化人工智能技术的应用、推动人工智能创新迭代发展等方面，有望起到示范引领作用。  
**二是应对新问题。首先，人工智能技术的发展，给企业技术发展路线的选择带来新挑战**，是选择单点突破还是全链条布局，需要企业认清大环境，关注实际需求；其次，人工智能的发展会带来创新治理的新问题，人工智能的确会引发一系列的政治、经济、法律、伦理的危机，给国家安全和社会治理带来困惑，比如大规模数据的泄漏等等，需要进一步趋利避害；**第三，生物技术门槛较低，容易产生不诚信、不道德和被人利用的问题，需要高度警惕**。  
**三是强化新基础**。未来中国的科技创新要更加注重原创导向，把从0到1的基础研究摆在更加重要的位置。与会专家也指出，基础薄弱和产业低端仍是我国集成电路产业面临的主要问题，**高端材料电子材料是卡脖子的关键**，还需大力加强基础学科的教育和培养。微生物群领域的基础性问题尚未解决，已经制约了微生物群研究的发展。  

**四、增强科技创新发展的新动力**  

  
为应对全球科技新竞争，赢得发展未来，需要顺应全球科技创新大趋势，进一步增强科技创新发展新动能。  
**一是提升新能力**。更高的技术水平和更广泛的适用性，才能产生可持续的商业价值，是人工智能技术未来竞争的关键；5G技术是工业互联网发展的基础关键，工业互联网平台一定要立足于为工业企业解决问题，网络化协同标识解析成为工业互联网发展的重要环节，商业模式体现工业互联网发展的生命力。  
**二是发掘新应用**。新兴领域的应用越来越明显成为未来增长的驱动力，如集成电路领域，每一次大的跳跃都有一个重要应用领域的出现，未来集成电路发展的驱动力一定还是应用，移动通信技术极大地拓展了集成电路的应用市场，未来新型计算和物联网（要实现人-机-物三方互联，物联网技术发展非常重要）等应用将推动集成电路技术进一步发展。再如工业互联网领域，未来汽车制造的客户数字化直连、未来办公室、无人地面电站巡检都将成为新的应用场景。  
**三是激发新需求**。新技术的发展需要新需求的拉动，如国内工业互联网的发展主要来自三个方面的需求拉动，一是经济转型需要工业互联网发挥强大支撑作用；二是数字经济时代的新生态、新的增长点需要工业互联网赋能；三是国家在智能制造等行业的自主可控拉动工业互联网发展。

**研究所简介**

  

国际技术经济研究所（IITE）成立于1985年11月，是隶属于国务院发展研究中心的非营利性研究机构，主要职能是研究我国经济、科技社会发展中的重大政策性、战略性、前瞻性问题，跟踪和分析世界科技、经济发展态势，为中央和有关部委提供决策咨询服务。“全球技术地图”为国际技术经济研究所官方微信账号，致力于向公众传递前沿技术资讯和科技创新洞见。
