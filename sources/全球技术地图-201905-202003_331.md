# 技经观察 | 各国对Libra的监管梳理及其前景分析

**2019年6月18日，Facebook发布了加密货币项目Libra白皮书，引起全球范围监管机构的高度重视，其中许多国家对Libra表示出不同程度的顾虑和担忧，各国纷纷表态并采取措施，以应对Libra可能带来的风险与挑战。****本文收集了目前各个国家金融部门尤其是监管机构对Libra加密货币的态度立场及应对政策，并基于此分析其未来情况。**

  

  

**一、对Libra加密货币持消极态度国家及地区的监管意向**

  

Libra自推出起就受到一系列监管质疑，尽管该加密项目负责人大卫·马库斯曾多次公开强调，Libra无意干涉国家货币政策或是与任何主权货币竞争，但一些国家仍对其超主权货币的定位抱有较大敌意，担心其将对传统银行业造成负面影响，对现有的金融系统产生冲击。

  

**欧洲央行执行委员会成员表示，针对Facebook等美国科技巨头推出的新金融体系Libra，金融监管机构必须迅速采取行动。**欧洲央行主席此前也强调了加密领域带来的威胁，认为使用分布式账本技术的任何东西包括加密货币，都将撼动整个金融系统，并会破坏金融体系的稳定性。

  

**德国财政部长表示Facebook不应被允许与欧元竞争，他对欧元区可能出现的混乱和消费者的安全表示担忧**，他坚持欧元仍然是欧元区唯一合法的支付手段，广泛使用的数字资产的引入可能会干扰各国通过货币政策管理经济的能力。发币是国家主权的核心要素，私人公司没有权利发行货币。

  

![](../Images/038aed36dcaa60ddec03dff6b38176a4.png)

  

**澳大利亚监管方目前不看好Libra的前景，认为其有很多监管问题要解决。**澳大利亚储备银行行长警告表示，Facebook推出的Libra将可能无法成为主流加密货币。他表示，Libra被广泛应用前存在着很多监管问题，澳大利亚监管层必须确保Libra足够稳定才能考虑接受。

  

**日本央行行长表示Libra可能会对金融系统产生巨大影响，且需要全球政策协同合作对其进行监管**，针对Libra的监管措施还应包括反洗钱政策。他还担心Libra作为由“一篮子”法定货币和政府证券支持的加密货币，将很难被监管，并将对现有的金融体系造成风险。对此，日本当局设立了一个由日本银行、财政部和金融服务局组成联络会议小组，负责调查Libra对货币政策和金融稳定的影响，解决Libra在监管、税收、货币政策和支付结算方面的问题。

  

**韩国金融监管机构称，Facebook最近推出的Libra加密货币项目将威胁到金融体系的稳定。**监管机构担心，随着人们将法定货币转移至Libra，在金融或外汇危机期间可能会发生银行挤兑，Libra货币兑换和汇款简化也将限制韩国央行控制国际资本流动的能力。此外，如果没有适当的银行控制，Libra可能被广泛用于洗钱等金融犯罪活动中。监管方还表示Libra项目是将对传统银行业造成威胁，如果Facebook等公司购买债券，而不是将客户资金存入银行，银行的财务状况可能会恶化。同时，如果Libra推行免费的海外支付，还会使韩国银行汇款收入大幅减少。

  

![](../Images/f7f390ae83395589361df92456c5decb.png)

  

**印度政府一向排斥加密货币，Libra若要在当地推行势必会受到阻碍。**印度经济事务秘书表示：“Facebook尚未充分解释清楚Libra的设计。不过不管怎样，它是一种私有加密货币，我们不会轻易接受它。”此外，最近印度政府还出台了一项禁止加密货币的法案草案，这将对Libra在印度的发行造成很大阻碍。

  

**二、****对Libra加密货币持积极态度国家的监管意向**

  

Libra作为一种新商业模式的代表，具有巨大潜力，一些国家对Libra表现出了乐观积极的态度，认为其如若满足了各国的监管要求，在安全稳定性上提供足够多的保障，将会在金融服务中带来更多的便捷性和广泛适用性，带来加密货币及支付领域的创新。

  

**泰国监管机构近日对Facebook Libra项目持友好态度。**泰国央行行长承认Libra稳定币将给泰国人提供更多的金融准入机会，但他表示仍然需要对Libra的好处和风险进行审慎的研究，并将对其操作和安全系统进行深入讨论。泰国央行计划监控Libra的验证认证标准以及对洗钱政策的遵守情况。目前，泰国央行已成立专案组审查Facebook Libra，且央行正在安排与Facebook及其合作伙伴的会议，将针对加密货币Libra进行讨论。

  

![](../Images/2e0311bcf750ca02ddf39f10d7720adf.png)

  

**以色列银行首席信息官表示，以色列银行将密切关注Libra的发展并积极进行应对。**以色列部际去中心化虚拟货币团队近日与Libra创始人之一Tomer Barel进行了会面。该小组成员包括以色列央行、财政部、司法部、证券管理局、税务当局、洗钱和恐怖融资禁令管理局以及国家经济委员会的代表。会议中Barel承诺Libra将会满足以色列的所有监管要求，表示以色列能够且应该成为一名核心成员。

  

**古巴当前正处于美国的经济制裁中，其正积极探索加密货币的使用。**虽然Facebook和WhatsApp在古巴当地有大量用户，但Facebook发言人表示，由于美国对古巴的制裁，他们目前并没有任何计划向古巴人民投放Calibra（Libra电子钱包）项目。

  

**三、****对Libra加密货币持中立态度国家的监管意向**

  

有些国家对Libra持有相对中立的态度，表示既要对Libra加密货币加强监管，认真分析其可能带来的金融系统冲击，严格把控Libra项目推进，又欢迎加密领域创新，积极接受新兴金融科技成果，甚至承认Libra的优势并进行主动接触。

  

![](../Images/a186672d927af509854889464175427c.png)

  

**美国监管机构现对Libra存在较大疑虑，其疑虑的原因除去Libra本身可能对金融领域的影响，还包括Facebook的用户隐私和消费者安全隐患。**美联储主席表示，在Facebook详细说明如何处理一系列监管问题之前，不应允许其推出加密货币Libra。但美国对加密货币本身抱有积极态度。美国财政部长表示，他们欢迎负责任的创新，包括可能改善金融体系的技术，但是加密货币首要目标应该是保护金融体系免受滥用，因此Facebook Libra必须制定适当的保障措施。美国参议院银行、住房和城市事务委员会和美国众议院于7月16-17日就Libra加密货币举行听证会，Facebook Libra项目负责人大卫·马库斯出席了听证会并发表证词。在两次听证会上，议员们言辞犀利，对Facebook公司普遍持不信任态度，称Facebook发币是妄想，Libra一旦推出，会严重威胁个人隐私和财产安全，影响金融系统稳定。两次听证会虽然表明了美国监管层对这种新商业模式的担忧，但也可以体现其对Libra的监管决心和审慎态度，一定程度来看有助于引导Libra项目的顺利推进。目前，美国国会表示要继续调查Libra，这将是国会金融服务委员会在下一届立法会议上的优先事项。

  

**英国监管方对Facebook Libra有所担忧，不过仍旧表态会以开放态度接触Libra。**英国财政部长表示，应该由监管机构而不是立法者决定Libra的问题，而且如果Libra在接受监管后得到适当的调节，它可能会是一个非常积极的项目。英格兰银行行长表示，英国央行将以开放的态度接近Libra，但不能成为“一扇敞开的大门”。8月5日，英国信息专员办公室同美国、加拿大、澳大利亚等多个国家的数据及隐私保护管理部门一同发布了一份关于Libra网络隐私情况的联合声明。该声明面向Facebook等Libra和Calibra项目背后的28个公司，要求他们解释计划如何根据数据保护法收集和处理用户的个人数据。

  

![](../Images/6b91c213e711f9e846d7076d13a89a5d.png)

  

**瑞士监管机构正在与Libra加密项目的发起者保持联系**，联邦数据保护和信息委员会要求Facebook详细介绍其加密项目Libra。此前Facebook在白皮书中指出Libra协会总部将设在瑞士日内瓦，因此瑞士需要Libra协会告知该项目的信息，以便其对监督程度和适用条例进行评估。近日瑞士监管机构，包括国家国际金融事务秘书处、联邦数据保护和信息专员以及金融市场监管局，同美国国会代表团进行了会面，着重讨论了关于Facebook Libra的监管问题。

  

**新加坡金融管理局局长承认了Libra的潜在利益**，例如支付成本更低、支持无银行账户群体等，但监管机构需要了解该技术巨头的系统将如何运作，同时表示新加坡将在做出监管决定之前，向其寻求安全和隐私问题的保证。目前，新加坡金融管理局已与Facebook就其推出的新型加密货币Libra计划进行了讨论，不过监管机构仍认为这家社交媒体公司的计划存在重大障碍，尽管Libra有潜在好处，但监管层对其运作方式需有所顾虑，审慎对待。

  

**越南表示应当对Libra加密项目高度重视并积极应对。**越南中央经济管理研究所高级经济学家指出，Libra不仅应该被视为一个普通的加密货币，而且应该被视为一个颠覆性的技术问题，它关系到社交网络的地位和发展，关系到全球金融稳定和主要国家的政策主权。Libra是一个不可避免的问题，越南不应该只是坐等它何时诞生，而是应该利用这个机会，推动对颠覆性技术的研究和监督，以制定及时和适当的政策。

  

**四、****Libra目前进展及前景分析**

  

**（一）目前进展**

  

**Libra虽在听证会上备受质疑，但目前未受到美国政府的强制干预，该项目仍处在调整开发中。**与此同时，Facebook正在试图增强自己的游说力量，现已聘请五家游说公司和一家律所，协助处理监管层的担忧。公司高管也在四处奔走，同一些国家的金融监管机构进行洽谈，以寻求更多信任和支持。此外，Facebook还在计划强化旗下合规团队，不少Libra协会的第一批成员，如Coinbase、Xapo等公司也公开表达了对Libra项目的支持立场。而业界对Libra的联系与支持正在增强，如美国加密货币交易所Gemini、日本金融服务巨头Monex以及国内一些企业已公开表示，将积极申请加入Libra协会。

  

**（二）未来前景**

  

根据上述情况，目前各国监管机构对Libra的疑虑主要集中在对Facebook的不信任、Libra对现行金融系统尤其是对银行、支付和外汇的冲击以及Libra自身的安全性（是否有信息泄露和易被网络攻击）等方面。**总体来看，各方质疑体现的更多是对一种新生事物的陌生感和无法掌握事物发展脉络的担忧，这属于对未知事物的常规反应，也并未出现对Libra的强烈抵制和抗拒。**同时，Libra高效率、低成本、支持无银行账户群体等优势是传统金融服务所不具备的，这对一些金融系统并不发达的国家发展普惠金融将有较大助益，更容易受到这些国家的欢迎。如泰国就公开表达了对Libra的友好态度。未来，若Libra的团队能与各国监管机构做好沟通并积极配合，随着国家监管层对数字资产和区块链行业的了解增进，Libra项目有望顺利推进。**当然，美国的监管情况仍是最具决定性的。**

  

![](../Images/e7598ab51ab53636f310062e3d739e9d.png)

  

再结合事物不断发展演进的规律来看，**像Libra这种面向社交用户发行的稳定币，本身就是在解决此前加密货币币值不稳定、应用范围窄等痛点，属于加密货币发展进阶的必然趋势。**从目前的势头来看，各行业均在探索推出基于自身业务和用户优势的商用稳定币，如IT巨头IBM、金融巨头摩根大通和零售业巨头沃尔玛都已发行或准备发行稳定币，这在未来都将是Libra必须面对的竞争，也是金融科技发展的重要变化。此外，**Libra的出现无疑会加速全球金融监管政策的完善，同时也会进一步加剧各国加密货币的竞争。**一方面，面对加密货币发展的新趋势，率先接纳、吸收并尽快平衡好监管与创新的国家，能快速提升商用加密货币的活力与竞争力。另一方面，作为未来重要的金融基础设施，各国的主权加密货币意义重大，其设计研发也将不断加快。
