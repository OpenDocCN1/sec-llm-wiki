# 【战略解读】美国国会研究服务局：中美关系

**美国国会研究服务局（CRS）2019年8月8日更新的“中美关系”报告，对中美关系相关的诸多议题及现状进行了阐述。****以下是对本报告的编译。**

  

  

![](../Images/c74be5b06df26ea5d7479e09f314de71.png)

  

中美两国正在开展特朗普政府所谓的“大国竞争”，尤其在贸易领域的持续争端，为两国正式建交40周年纪念蒙上了一层阴影。两国在经济规模、防务支出及温室气体排放等方面都处于世界领先水平，且均为联合国安理会常任理事国。2018年，两国还是彼此最大的贸易伙伴。  

  

特朗普政府发布的战略文件为美国的对华政策奠定基础。2017年12月发布的《国家安全战略（NSS）》指出：与中国、俄罗斯、朝鲜、伊朗及跨国威胁集团的竞争需要美国对过去20年的政策进行反思。此前的政策基于这样的假设：通过与竞争对手接触，并将其纳入到国际机构及全球贸易体系中，可使他们转变为良性的参与者和可信赖的合作伙伴。美国《国家安全战略》指责中国和俄罗斯挑战美国的综合实力、影响地位和国家利益，企图侵蚀美国的安全和繁荣。  
在一定程度上，特朗普政府已确认中国对其带来的威胁并开始进行反击，美国甚至为阻止芬太尼（一种致命的合成阿片类药物）流入美国而对中国公司发起调查，并在约束朝鲜核武器和导弹项目上持续施压。有评论认为特朗普政府的政策意图是促使中美两国在经济和社会上“解绑”。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**一、贸易**

  

根据美国的贸易数据，2018年美国出口中国的货物和服务总值1780亿美元（占美国出口总额的7.1%），而从中国进口的总值达到5588亿美元（占美国总进口的17.9%）。因此，双边贸易总逆差为3808亿美元，相比于2017年增长了436亿美元（增幅12.9%）。  

  
美国贸易代表办公室（USTR）根据1974年《贸易法案》的第301条，发起了针对中国在技术转让、知识产权和创新方面的调查，并于2018年3月发布调查结果报告，指出中国在知识产权方面的政策诸如强制技术转让、歧视性的许可证、国家资本投资和并购美国企业以获取先进技术和知识产权，以及主导对美商业秘密进行网络窃取等迫使美国采取反制。为了对中国施压以解决这些问题，特朗普政府分三阶段对进口自中国的价值近2500亿美元货物加征25%的关税。作为反制，中国同样对进口自美国的价值1100亿美元的货物提高了关税（税率从5%到25%不等）。  
2019年5月谈判破裂后，特朗普下令美国贸易代表办公室启动对剩余的几乎所有进口自中国的货物加征25%关税的进程。2019年8月1日在上海第十二轮中美贸易谈判之后，特朗普总统宣布从2019年9月1日起，对剩余的进口自中国的货物加征10%关税。  
2019年8月5日，中国做出反击，允许人民币对美元贬值，并提出对美国农产品加征10%的关税。美国商务部根据1988年《综合贸易与竞争力法案》第3004条，将中国视为汇率操纵国，并宣布计划诉诸国际货币基金组织，以消除中国这些举措带来的不公平竞争优势。第十三轮贸易谈判定于2019年9月在华盛顿举行。

**二、针对中国技术公司的行动**

  

中美贸易摩擦及战略竞争使美国对几家主要的中国技术公司采取行动。2019年5月15日，特朗普总统签署了13873号令，授权商务部禁止牵涉到“国外对手”的某些技术交易。同一天，商务部将中国通信巨头华为公司及其68家非美国的关联企业加入到商务部工业安全局的实体清单，要求在向这些企业出售或转移美国技术时必须获得出口许可证。而到2019年5月20日，商务部又发布了一个为期三个月的临时通用许可证，允许继续与华为及其关联企业的交易。2019年8月1日，特朗普表示：“我们可以与华为在不涉及安全的项目上做买卖，但任何涉及国家安全的事，我们不会与华为打交道”。作为对美国这些举措的回应，2019年6月中国商务部长宣布计划制定中国自己的“不可靠实体清单”，将那些损害中国企业合法权利和利益或“出于非商业的理由对中国企业实施抵制或断供”的外国企业列入其中。据报道中国正寻求将解除对华为的商业限制作为与美国贸易谈判的条件。  

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**三、中国“一带一路”****倡议**

  

中国的“一带一路”倡议旨在通过投资大型基建项目来促进陆上经济联系。特朗普政府官员将“一带一路”倡议描述为“给这些国家强加难以持续的债务负担”，用美国国务卿蓬佩奥的话就是付出“远超过经济收益的政治代价”。美国2018年“更好地利用投资促进发展”法案被普遍认为是对美国对中国“一带一路”倡议的回应。2019年4月，习近平主席指出要提高“一带一路”倡议所有项目的透明度以及注重商业和财务上的可持续性。  

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**四、芬太尼及其他合成阿片类药物**

  

根据美国疾病控制与预防中心的数据，2017年，合成阿片类药物——主要是芬太尼——导致了超过28000例药剂过量死亡。美国缉毒局指出非法的芬太尼及其它合成阿片类药物“主要来源于中国和墨西哥”。作为回应，中国在2019年5月1日将所有与芬太尼相关的物质列入管制物质清单。

**五、香港**

  
根据1984年中英“联合声明”，香港于1997年实现主权移交。中国承诺香港除外交和国防事务外，拥有高度自治权，现有社会和经济制度至少50年不变。自2019年6月以来，成千上万的香港人集会表达对一项关于引渡逃犯的法律修正案的反对。香港行政长官林郑月娥和特朗普总统都将游行称为“暴动”。特朗普总统表示中国中央政府和香港特区政府能够处理好这个问题，不需要美国插手。一些国会议员要求特朗普当局停止向香港警察部队出售瓦斯、辣椒水及其它防爆物品。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**六、台湾及美国的“一个中国”政策**

  
根据美国的“一个中国”政策，美国与台湾仅保持非官方关系，但仍维持1979年《台湾关系法》，包括对台军售。中国坚持对台湾地区拥有主权，反对美国与台湾地区朝“官方关系”上发展。中国同样反对美国对台军售以及美海军穿越台湾海峡。而美国反对中国在经济上和军事上对台湾施压以及在国际上孤立台湾。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**七、南海**

  

  
自2013年以来，中国在南海南沙群岛几个争议区域修建了人工岛，并将其转化为军事基地。为了应对中国“过度的海洋诉求”以及维护美国在国际法允许范围内的飞行、航行和作业自由，美军在该海域开展了“航行自由”行动和军事存在行动。2019年6月，中国国防部长魏凤和指出这些行动恰恰是南海最大的不稳定因素。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**八、朝鲜**

  

  

从2006年到2017年，联合国就朝鲜发展核武器和导弹项目提出越发严厉的制裁，中国都投出赞成票。特朗普政府认为中国履行制裁“有时不一致，但很关键”。2018年6月特朗普总统与朝鲜领导人金正恩的会面令本已冻结的中朝关系有所回暖。自2018年3月，金正恩到访中国四次，习近平主席访问朝鲜一次。2019年6月，中国督促朝美双方以“双轨道机制”开展对话，即一方面聚焦无核化，另一方面探讨一种和平机制。

**研究所简介**

  

国际技术经济研究所（IITE）成立于1985年11月，是隶属于国务院发展研究中心的非营利性研究机构，主要职能是研究我国经济、科技社会发展中的重大政策性、战略性、前瞻性问题，跟踪和分析世界科技、经济发展态势，为中央和有关部委提供决策咨询服务。“全球技术地图”为国际技术经济研究所官方微信账号，致力于向公众传递前沿技术资讯和科技创新洞见。
