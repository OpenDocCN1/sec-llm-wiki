# 浅析鲍里斯·约翰逊将带领英国生物技术产业走向何方

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651537446&idx=1&sn=ab1b3dcd09ed707e11bbe5b661561de7&chksm=f18233d6c6f5bac07c22479aaa55f2b260470c0aa80ceb5b9651bd747089eabd840b7fbec214&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651537446&idx=1&sn=ab1b3dcd09ed707e11bbe5b661561de7&chksm=f18233d6c6f5bac07c22479aaa55f2b260470c0aa80ceb5b9651bd747089eabd840b7fbec214&scene=27#wechat_redirect)

![](../Images/10070d1e3f65593f24b4d50c26dfb531.png)![](../Images/e3f09f651cd50803ad28eef9cec27a54.png)

  

**2019年7月23日，英国前伦敦市市长、**前**外交大臣、“脱欧派”领袖鲍里斯·约翰逊在万众瞩目中成为英国新任首相，而其上台后力推脱欧进程，甚至不惜以无协议方式“硬脱欧”的举措将势必对全球经济及各科技领域发展格局产生深远影响。本文将结合英国脱欧背景、约翰逊过往政策主张及就职演讲，浅析新时期英国生物技术产业发展的可能走向。**

  

  

如何确保英国推进脱欧进程中国民经济的安全稳定及脱欧后的可持续发展，是当前英国新任首相鲍里斯·约翰逊推行经济和科技政策改革的头号关切。**在此背景下，作为对拉动英国经济增长、保障国家农业和国民医疗安全、巩固英国全球科技创新活力至关重要的生物技术和生物医药产业，无疑已成为鲍里斯·约翰逊的施策重点。**从其过往的政策主张以及就职演讲中对该产业发展发表的态度来看，新时期英国生物技术产业发展将主要围绕“形成英国脱欧后的经济新动能”展开。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**推动生物技术产业集群成为**

**英国经济新的拉动点**

  

**“正是在英国，我们实现了全球首次利用基因疗法治愈失明”。**——《鲍里斯·约翰逊就职演讲》

  

![](../Images/51f3c26965b0e2037603f855970980ee.png)

  

鲍里斯·约翰逊对英国生物技术产业溢于言表的自豪感并非空穴来风。事实上，**得益于在生物技术和生物医药产业方面的长期深耕，英国已构筑起强大的科学基础、蓬勃的创新活力和活跃的融资生态，并依此形成了全球领先的可持续竞争优势。**据英国政府公布的最新数据显示，英国整个生命科学行业拥有近240900名雇员，约占所有私营经济体就业人数的1%；仅生物医药行业每年营收就超过500亿英镑，被称为英国经济“皇冠上的明珠”。而英国最具活力的生物技术产业集群，恰恰是鲍里斯·约翰逊于2014年任伦敦市长期间倡议发起的伦敦-牛津-剑桥生命科学“金三角”产业中心（MedCity倡议）。这一倡议旨在加强专业基础设施建设，使“金三角”成为相互联系、首屈一指的生命科学研究、开发、制造和商业化集群，以拉动就业、吸引投资并推动新型疗法的发现。约翰逊在彼时倡议发起时，就明确表示要将生命科学产业在英国经济中的地位提升到与金融服务业相同的新高度。也正是在这一理念的指导下，他又发起了价值100亿英镑的“超级基金”（Megafund）提案，旨在通过新的资助模式将伦敦定位为长期药物开发和生物制药增长的全球领先地区。

  

截至2015年11月，“MedCity”已拥有1896家生命科学公司，创造稳定就业62855人，每年产生166亿英镑的效益，拥有欧洲有史以来最多的私人融资，并成为欧洲最大的生物技术产业园区。在这一集群效应的带动下，英国生命科学创新活力被全面激发，对生物技术产业发展的渴望也由“金三角”地区蔓延至整个英国。

  

鲍里斯·约翰逊在伦敦市长任上就能够做出以上举措，说明其高度重视生命科学产业的联动布局，并深刻洞悉了其美好远景和巨大效益。在脱欧需要强力维稳英国经济的关键时刻，鲍里斯·约翰逊或将在这一领域着重发力，通过进一步开放合作、开辟资金来源、加力引进全球化人才和简化监管等积极性、鼓励性措施，推动该领域蓬勃发展，成为英国经济新的拉动点。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**对转基因作物采取鼓励性的政策**

**使其成为经济增长点**

  

**“让我们现在就开始把英国优秀的生物技术产业从反转基因监管中解放出来，开发抗枯萎病的转基因作物，为全世界的人口提供粮食”。**——《鲍里斯·约翰逊就职演讲》

  

![](../Images/b0276d0c4b2e4cef89b76cf210e7624f.png)

  

这句话或许最能体现鲍里斯·约翰逊对欧盟转基因政策的厌恶，以及迫切寻求摆脱欧盟束缚的心态。**在全球范围内，欧盟是对转基因技术管理最为严格的地区之一，一系列繁琐而严格的监管法规致使一种转基因食品上市前要花费近10年时间和上亿美元来通过审核。**尤其是2018年7月，欧洲法院裁定包括基因编辑在内的基因诱变技术应被视为转基因技术，接受欧盟转基因相关法律的监管，无疑是给矢志追求前沿生物技术创新的英国以沉重枷锁。事实上，英国的生物领域研发能力并不弱，在转基因水稻、大豆、小麦、棉花等作物上均有布局，转基因油菜的研发能力甚至全球领先。其农业的精耕细作方式和高度的机械化水准，使得其以不到2%的劳动力满足约60%的食物需求，贡献了GDP的2%。而欧盟的共同农业政策，的的确确给英国的农业带来了大量的负担，甚至使英国的农业出现了衰退的趋势。

  

近年来，英国的反转基因的舆论发生了明显的转变，一方面是科学家不断向公众阐述转基因的科学性，一方面是英国政府认识到转基因技术能够帮助英国的农业和农民，提高英国农产品的国际竞争力。民众对转基因的抵制程度也越来越低。在这样的大背景下，约翰逊在竞选演说中明确表示“我承诺带回英国的影响力，消除欧盟阻止政府支持英国企业的法规”，在就职演讲中也强调“我们强大的食品产业和农业也将会准备就绪，不仅在国内，同时也向全球销售更多的产品”，深刻说明了鲍里斯·约翰逊期望以开放转基因为抓手，推动英国农业技术的解放和农业产业的发展，成为脱欧后英国开展国际贸易，提振国内经济的重要手段。是以，**鲍里斯·约翰逊政府对转基因作物和基因编辑作物方面或将采取开放的鼓励性政策**，以此来调动农民生产积极性、增加农业竞争力、拉动就业和提升国际贸易，推动农业成为英国有效的经济增长点。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**促使生物制药行业为医保体系改革服务，**

**减少医疗负担，****维护国民经济平稳运行**

  

**“我的职责是确保你们不用等待三周才能见到家庭医生，我们将在这周新开始20个医院的升级工作，确保国家医疗服务体系（NHS）的钱用到实处。****我的职责是让你们和你们的父辈和祖辈，不用为了支付医疗费用，而不得不卖掉房子。”**——《鲍里斯·约翰逊就职演讲》

  

![](../Images/ed25a8627504ff44cc3a0d1ba6dc751e.png)

  

这是鲍里约翰逊在就职演说中针对民众对NHS的诟病予以的坚定许诺。英国国家医疗服务体系（NHS）一直承担着保障英国全民公费医疗保健的重任，遵行救济贫民的选择性原则，并提倡了普遍性原则。NHS曾经对改善人民的健康状况起到了非常积极的作用，并受到了社会的广泛欢迎。但是**NHS面临的问题和矛盾也越来越突出，资金不足和效率低成为最主要的问题。**随着公众对医疗服务需求的持续增加，医疗卫生费用不断增长。目前，英国政府每年需向NHS支出1000多亿英镑，财政已不堪重负。

  

药品支出占英国NHS总支出的12％以上，在无法向NHS增补大额财政补贴和解决系统效率低下问题的情况下，使用更便宜、更有效的药品可能是解决问题的办法，而这需要英国制药业的支持。英国的生物制药行业水平是非常高的，同样有着非常高的投入产出率。由此角度而言，**为了保证平稳的脱欧环境，约翰逊会对生物制药行业采取宽松、鼓励的政策态度谋求其在国家医疗保健相关方面的回报。**

  

**总体而言**，在脱欧这个大背景下，利用各种方式鼓励和刺激英国经济的增长点，从而保证英国经济的平稳向好，免受大的冲击，是致力于脱欧的约翰逊的重要任务。是以，**约翰逊对于生物技术相关产业的政策必然是积极性、鼓励性的，力争使该产业对英国经济发展起到有效的拉动作用。**

**研究所简介**

  

国际技术经济研究所（IITE）成立于1985年11月，是隶属于国务院发展研究中心的非营利性研究机构，主要职能是研究我国经济、科技社会发展中的重大政策性、战略性、前瞻性问题，跟踪和分析世界科技、经济发展态势，为中央和有关部委提供决策咨询服务。“全球技术地图”为国际技术经济研究所官方微信账号，致力于向公众传递前沿技术资讯和科技创新洞见。
