# 美国《全球卫生安全战略》主要内容、背后实质及相关思考

**2019年5月9日，美国总统特朗普签署发布《全球卫生安全战略》。该战略确定了卫生主管部门在预防、检测和应对传染病威胁等方面可采取的行动，并希望通过加强国际合作和提高全球卫生安全能力，来保护美国及其合作伙伴免受传染病威胁。美国将协助其合作伙伴提高卫生安全水平，鼓励各国提高技术能力，并在应急准备和疾病监测等领域为特定伙伴国家提供支持。**

  

  

**全球卫生与美国外交及国家安全一直相互交织、如影随形。**

早在19世纪末，美国为推动国际贸易发展的同时确保自身免受外来疾病的威胁，就与多国共同建立了国际卫生组织、确立了相关标准并签订了系列协议。1996年，美国时任总统克林顿颁布总统令，要求“建立一个专门小组，监督美国在全球范围内部署疾病监测和反应网络”，正式将全球卫生安全议程纳入美国外交政策的范畴。从小布什政府起，全球卫生安全进入美国情报机构的视野，并进一步被纳入国家安全的范畴。2000年，美国国家情报委员会发表《全球传染病威胁及其对美国的意义》，并在此后又针对艾滋病、非典等具体的传染病发布了其对美国国家安全意义的多份报告。此后，小布什政府将防止传染病大流行和防范生物恐怖主义纳入2002年和2006年的《国家安全战略》，并列为“优先议题”。奥巴马政府进一步将全球卫生安全与国家安全联系起来，在其2010年的《国家安全战略》中，把在美国本土和海外建立疾病情报和响应能力作为重点，提出美国“在推动全球卫生方面具有更多的道德和战略利益”。特朗普政府2017年的《国家安全战略》更是提出了**从源头检测并遏制生物威胁、支持生物技术和医学创新、加强全球情报共享及加强全球威胁打击能力等具体举措，强调以实力维护和平。**因此，美国此番发布《全球卫生安全战略》，其背后实质值得我深入探讨。

**一、美国《全球卫生安全战略》主要内容**

  

《全球卫生安全战略》概述了美国政府加强全球卫生安全的路径，无论这些卫生安全隐患是自然发生的、无意释放的或故意造成的。美国政府将通过双边及多边机制，与国家合作伙伴开展密切合作，促进目标国家对传染病爆发的预防、发现及应对能力，并保证美国国土生物安全。

  

![](../Images/ccc6cab256756d86b325afe7b2cba593.png)

  

《全球卫生安全战略》将与《国家安全战略》《国家生物防御战略》以及《推进全球卫生议程以实现世界免受传染病威胁的安全保障》的行政命令一道，共同指导美国政府通过与其他国家、国际组织及非政府利益攸关方开展合作，保护美国及其伙伴国家免受传染病的威胁与侵害。《全球卫生安全战略》对《国家安全战略》和《国家生物防御战略》提供支持，并进一步描述了美国在国内外预防、发现和应对传染病威胁的具体措施。作为全球卫生安全体系的一部分，《全球卫生安全战略》还描述了美国如何在国内实施“在源头检测和控制生物威胁”和“改善应急响应”这两项“国家安全战略”中的优先行动。

  

![](../Images/2c7b4f42d2932ccc3e7193b4e5399a15.png)

  

**《全球卫生安全战略》将追求达成三项目标：**

1.加强伙伴国家全球卫生安全能力；

2.增加对全球卫生安全能力建设的国际支持；

3.确保美国国土对抵御全球健康威胁做好准备。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**二、美国《全球卫生安全战略》实质解读**

  

**“大多数将卫生界定为安全和战略问题的话语都是由发达国家所提出，他们所关切的只是疾病如何影响他们的利益，而非政策如何影响全球疾病负担”**。毋庸置疑，美国将卫生治理纳入外交和国家安全的战略轨道，并对相关国家卫生基础设施和卫生安全能力建设进行投资，在一定程度上促进了国际社会更好地应对公共卫生危机这一全球性挑战。然而这种促进知识美国卫生战略的“副产品”，**其本质上是出于地缘政治利益、国家安全利益以及全球主导能力的考量。**

（一）地缘政治利益

  

**美国开展对外卫生援助是实现其地缘政治利益的重要手段。**美国中央情报局早在2000年发布的报告中就提出“传染病可能加剧大国为了控制稀有国家资源的斗争，从而影响美国国家安全。”因此，美国开展对外援助的本质目的是与别国形成比较优势，将卫生援助作为外交工具，更好地控制目标国家的战略资源。例如，美国国家情报委员会2002年的报告中提出，“艾滋病将恶化尼日利亚的国家能力，而尼日利亚对于美国的能源安全具有重要意义”。此后，美国专项划拨了约6亿美元开展对尼援助，并为尼日利亚军队建立了完整的艾滋病检测体系。  

  

![](../Images/c7f9ca3001429bcaca3dbbba13df9066.png)

  

（二）国家安全利益

  

《全球卫生安全战略》在国家安全方面的考量充分体现于与之相配合的《国家生物防御战略》中，即主张运用本国和伙伴国的力量加强全球监测、全球评估，以及全球生物安全危机的应对能力，力图内外结合将生物防御的第一道防线前置，御敌于国门之外。事实上，美国为相关发展中国家建立传染病的全球监测系统对这些国家基本上毫无用途，因为这些国家即使通过检测体系发现了传染病暴发的相关信息，其国内薄弱的公共卫生能力也无法支持其采取任何有效的预防和应对措施。反而是美国假借人道主义之手，为本国国家安全又设置了一道重要防线。**所谓“强化全球卫生安全应对能力”，不过是美国在别国建立监测系统，以维护自身国家安全的借口和工具。**  

  

![](../Images/5518200fb6a3482c3b10ebff42bbe0d1.png)

（三）全球主导能力

  

早在2018年9月美国政府发布《国家生物防御战略》时，美国健康与人类服务部（HHS）就提出将发布《全球卫生安全战略》，以与更新版的《全球卫生安全议程（GHSA）共同支撑《国家生物防御战略》中全球干预能力的实现。因此，《国家卫生安全战略》在多个章节反复提到的“通过双边或多边议程同伙伴国家加强合作，帮助其提高世界卫生组织联合外部评估（JEE）指标分数”的说法，其本质仍是对加强甚至主导未来全球生物安全领域话语权的愿景，**为其维护国家安全和实现自身利益最大化提供了更加灵活高效的手段。**

  

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**三、相关思考**

  

美国新发布的《全球卫生安全战略》与《国家安全战略》《国防战略》《国家生物防御战略》等国家战略保持一致，并提供相应支持，实现了传染病威胁应对路径和生物恐怖主义、生物武器威胁应对路径的有效整合，**进一步突出强调全球卫生议题的安全属性和工具属性。**美国这一战略不但弱化了其应当承担的对发展中国家进行卫生援助的道义责任，而且会加剧潜在的生物安全困境，为全球卫生治理带来了一定的负面影响。长期以来，我国在履行国际义务、参与全球卫生治理方面取得重要进展，为其他国家和地区提供大量卫生发展援助，体现了中国责任和担当。建议进一步将卫生治理深度融入“一带一路”“中非命运共同体”合作机制，健全完善卫生外交法制环境和组织体系，进一步推进与各国政府、国际组织和其他非国家行为体的卫生合作，巩固提升全球卫生治理能力，构筑中国的全球卫生话语体系。

**研究所简介**
