# 《全球创新指数2019（GII）》科技集群专题解读分析

**《全球创新指数》是评估世界各国科技创新发展水平最权威的报告之一，由世界知识产权组织、康奈尔大学、欧洲工商管理学院共同创立，已经连续发布12年。该报告每年均有重点关注主题，2017年开始新增科技集群专题，对全球排名前100位的科技集群城市进行跟踪分析，揭示全球主要创新策源地科学技术发展的聚焦领域与未来趋势。上海市科学学研究所课题组对该专题的主要内容进行长期跟踪分析，对当前全球科技集群的科技前沿领域、创新合作态势进行了深入研究，供读者参阅。**

  

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**全球创新策源地分布新情况与新特点**

  

新兴市场经济体科技集群成为开启“创新超越”之路的重要依托。全球主要国家中超过七成的科技集群城市位于发达国家，发展中国家等新兴经济体的科技集群实力稳步提升。2019年发达国家拥有全球72%的科技集群城市，主导着全球新科学、新技术的诞生和发展。主要分布为美国拥有26个、德国10个、法国5个、英国4个、加拿大4个、日本3个。从变化趋势来看，2019年德国、法国分别新增2个科技集群，其余国家保持平稳。在发展中国家序列中，中国、印度、土耳其的全球科技集群最多，占据发展中国家总数的79%，其中深圳-香港、北京、上海、班加罗尔、伊斯坦布尔等科技集群实力雄厚。

世界科技创新正迎来“亚洲时刻”。当前全球创新策源在美国、西欧、东亚构成“三足鼎立”态势，亚洲科技集群地位凸显。如图2所示，美国、西欧、东亚拥有科技集群近90个，占据全球科技集群数量近9成，成为了全球创新策源的主要区域。其中排名前四的东京-横滨、深圳-香港、首尔、北京四个科技集群均位于东亚地区。

**科学技术最新前沿领域与未来趋势**

  

该报告充分表明，全球创新策源主要由前沿科学与技术创新“双轮”共同推动。当前全球科技集群的科学水平差距正在不断缩小，单个科技集群科学论文占全球份额的均值约为0.50%，表明基础研究“角逐”已进入白热化状态，全球创新策源地都是基础科学研究的重镇。相对而言，全球科技集群的技术创新水平差距较大，单个科技集群PCT专利申请量占全球份额的均值约为0.63%，排名前10位的科技集群这一均值为3.53%，远高于排名前10位的科技集群科学论文占全球份额的均值1.30%，差异主要体现在技术创新对科技集群的核心科学技术禀赋优势要求更高。由此可见，立足基础科学突破与推进技术创新成为全球创新策源地崛起的硬核动力所在，该报告对科学与技术创新前沿领域发展趋势作如下进一步分析。  
前沿科学领域不断聚焦。全球科学论文主要集聚在12个学科，如图3所示，其中化学、神经科学、工程、物理4个学科拥有76%的全球科学论文数量，是当下科学研究的聚焦点。从发展趋势来看，生物医药领域正成为全球科学发展的“热门领域”，以神经科学、普通内科学、心脏学、肿瘤学、医药学、儿科学、公共环境与职业卫生为主要领域的科技集群数量不断增长，体现全球对生物医药领域发展的热度不断提升，其中美国、英国生物医药领域实力雄厚，拥有克利夫兰医学中心、哈佛大学、伦敦大学等顶尖机构，对当地科学发展的贡献率\[1\]分别达到47.33%、53.87%、49.28%。在生物医药领域中神经科学发展最快。聚焦神经科学领域的科技集群从2018年的13个增长到2019年的17个，一半以上位于美国的纽约州、洛杉矶等地区，其中加利福尼亚大学、耶鲁大学、哥伦比亚大学等机构研究能力突出，成为全球神经科学领域的主要创新策源地。

技术创新领域不断收敛。全球科技集群的PCT专利申请主要聚焦在14个领域，如图4所示，其中医疗技术、制药、电机-仪器-能源、数字通信、计算机技术5个领域拥有全球75%的PCT专利申请量，成为发展的热点领域。从发展趋势来看，尤其是2020年全球疫情爆发以来，探求生命密码，攻关医疗新药的迫切需求得到全球共识，医疗成为技术策源的关键领域，其中约一半的医疗技术创新诞生在美国，如俄亥俄州哥伦布的雅培公司、纽约的霍尼韦尔公司俄亥俄州克利夫兰的克利夫兰医学中心等。

**全球高水平创新合作网络的发展态势**

  

全球创新合作“高地”逐步凸显。全球高水平创新合作仍然集中在国家内部集群之间，同时，合作“高地”正快速凸显，成为区域科技发展的关键枢纽，美国26个科技集群的主要科学合作对象为华盛顿、纽约州、波士顿、旧金山4个地区，主要依托对象约翰霍普金斯大学、哥伦比亚大学、哈佛大学；中国的18个科技集群的主要科学合作对象均为北京，其核心机构是中国科学院；德国的科技集群主要科学合作对象均为科隆，主要依托波恩大学和科隆大学，跨国合作始终无法成为区域科技发展的主导模式。

  

硅谷仍是全球最具影响力的科技创新合作中心。硅谷区域参与了全球科技集群20%的专利合作，合作对象涵盖澳大利亚的悉尼、加拿大的温哥华、新加坡、印度的班加罗尔、中国的北京等地区，网络覆盖全球多个国家和地区，在全球专利合作网络中处于核心节点位置。中国科技集群的对外合作主要集中在北京和上海，分别为硅谷及纽约州地区，体现了北京、上海对外开放水平较高，率先代表国家开启全球科技创新竞争与合作。

  

引擎企业是全球专利合作的核心载体。报告指出全球71家引擎企业主导着全球前100个科技集群的PCT专利申请合作，引擎企业引领了全球技术创新合作渠道。其中英特尔、华为分别占据6席、巴斯夫占据4席、爱立信、惠普、默沙东各占3席，成为全球科技集群PCT专利申请合作最重要的企业。从单个企业合作来看，英特尔占据与硅谷合作83.05%的（PCT专利申请）份额，华为占据与深圳-香港合作70.34%的份额，默沙东占据与上海合作63.36%的（PCT专利申请）份额，成为全球PCT专利申请和合作最大门户。

**有关启示及建议**

  

加强国际动态跟踪，紧跟创新策源的前沿领域和核心机构。加强对各类国际权威机构发布的科技创新实力评价的跟踪和研究，时刻把握科技创新策源的前沿领域和主要承载机构，为中国寻找全球创新策源合作切入点提供战略支撑。同时，鼓励相关研究机构、科技智库开展国际合作，逐步构建符合中国国情、科情的科技创新评价标准，率先建立全球创新策源评估的“话语权”。

  

聚力基础研究投入，筑牢创新策源的发展根基。遵循全球创新策源地崛起规律，加大基础研究投入，围绕全球科技集群聚焦的科学前沿领域，结合中国科技创新和产业发展实践，集中资源力量，尽快寻求可行性论证，建设若干大科学设施和关键科研机构，加强全球创新资源配置能力，全面提升全球创新策源力。

  

强化创新主体能力，形成面向未来的战略框架。短期内，积极引入国际科技引擎企业，推动区域技术合作能级提升，同时，围绕国际科技集群发展依托的主要机构，鼓励有条件的科研院所、企业设立离岸科技创新中心，建立跨国合作关系。

**研究所简介**

  

国际技术经济研究所（IITE）成立于1985年11月，是隶属于国务院发展研究中心的非营利性研究机构，主要职能是研究我国经济、科技社会发展中的重大政策性、战略性、前瞻性问题，跟踪和分析世界科技、经济发展态势，为中央和有关部委提供决策咨询服务。“全球技术地图”为国际技术经济研究所官方微信账号，致力于向公众传递前沿技术资讯和科技创新洞见。
