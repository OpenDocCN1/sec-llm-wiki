本期金融科技月度评论重点包括：（1）各国央行数字货币计划提速，其中，法国、泰国进一步推进相关试点项目，七国集团（G7）研究决定将就发行央行数字货币展开合作；（2）数字货币与数字资产监管进展突出，多个国家和国际组织研究出台新政策规范这一市场；（3）近期有多项利用智能合约等技术的新型支付网络落地，多家企业纷纷推出新的改进工具与框架用于提升和拓展以太坊性能；（4）全球权威IT研究与顾问咨询公司Gartner近日发布调查报告，称大型传统企业现在还没有准备好接受数字货币支付，仍有诸多风险挑战有待解决。

  

以下是本期金融科技评论的具体内容：

  

  

1

  

**金融科技监管**

  

本月金融科技监管聚焦于数字货币和区块链领域，其中，除全球央行数字货币计划继续加速落地外，多国数字货币和数字资产立法有较大突破，区块链、人工智能等先进技术在金融领域的应用被多国政府持续看好。

  

**（一）数字货币与数字资产监管**

  

**（1）各国****央行数字货币持续推进**

  

7月份有十余个国家的央行数字货币计划出现新进展。其中，**立陶宛、法国、泰国加快了本国央行数字货币落地进程**。**立陶宛**于本月月底正式推出数字纪念币LBCoin，这是欧洲中央银行发行的第一种数字货币，也是该国央行数字货币研发试验场。**法国**与瑞典、立陶宛等国一同走在欧洲央行数字货币研发前列，该国央行近日开始与埃森哲、汇丰银行等八家银行企业合作筹备数字欧元试点项目，测试这一新型金融工具的银行间结算整合业务。**泰国**央行宣布启动央行数字货币项目第三阶段，将试点对象推广至当地企业，全面深化数字泰铢的应用场景和使用范围。

  

其次，**美国、日本等多国央行和监管机构在央行数字货币战略性研究和技术研发方面有所进展**。**美国**参众两院在本月先后召开听证会，将数字美元研发列为探讨重点，在22日听证会上，美国参议院银行、住房和城市事务经济政策小组委员会主席汤姆·科顿指出维持美元的至上地位不仅是经济问题，也是至关重要战略问题。**日本**央行于本月初公布央行数字货币技术课题总结报告，深入研究在灾害通信中断等极端情况下如何通过数字货币进行离线支付这一崭新课题，挖掘央行数字货币弹性。除美日两国外，**牙买加**央行正在邀请技术解决方案提供商加入该国央行数字货币计划，巴哈马央行表示正在开发基于移动电话的央行数字货币。

  

此外，**加拿大、哈萨克斯坦等国仍在就央行数字货币可行性进行评估**。欧洲央行执委指出欧洲央行是探索中央银行数字货币计划可能性的先行者，新冠疫情危机和货币政策数字化进程的加速或将影响欧元的全球性地位。**加拿大**央行专家组分析数字加元应具有传统纸币的易获得性质。**哈萨克斯坦**央行正在对其数字坚戈进行可行性论证，当地反腐败机构呼吁通过数字法币建立更加透明的金融体系。**英国**仍在评估是否创建本国央行数字货币，总体态度朝向积极方向转变。**捷克**国家银行初次公开谈及这一话题，表示鉴于该国货币体系稳健，因此暂不准备发行央行数字货币。

  

2020年以前关于央行数字货币的讨论多局限于实现普惠金融与应对全球稳定币可能带来的冲击上，如今受疫情危机和数字经济飞速发展影响，更多国家开始强调央行数字货币的战略意义，国际讨论已进入新局面。**七国集团**（G7）近日初步决定将就发行央行数字货币展开合作，拟于8月底到9月上旬的G7峰会上进行详细讨论，此举对中国DCEP的针对性明显，预示着央行数字货币全球竞赛在朝向更激烈的方向发展，各大经济体在这一领域的正面交锋指日可待。

**（2）多国出台政策推动数字货币市场规范化**

  

数字货币在数字化时代下发展至今已受到更多国家和国际组织的关注或认可，相应监管政策也随着这一市场的快速发展而不断革新。**二十国集团**（G20）正在加速调整数字货币监管政策，拟在今年10月G20财务官员会议上围绕数字货币多项挑战展开讨论，或将为数字货币支付开绿灯。**金融行动特别工作组**（FATF）计划加强加密交易所全球监管框架，以协调和共享有关数字货币和数字资产服务提供商的信息。

  

本月美国、俄罗斯、韩国相继出台法规规范国内数字货币与数字资产市场。其中，**美国**监管态度最为积极友好，多项举措并行为该国加密领域的健全发展铺平道路：美国商品期货交易委员会（CFTC）已将全面的数字货币监管作为未来四年工作战略中的优先事项，承诺为数字资产监管制定整体框架；美国证券交易委员会（SEC）宣布将简化投资公司申请程序，以方便加密公司更高效运营；此外，美国货币监理署（OCC）表示全国性储蓄银行和联邦储蓄协会将可以提供数字货币托管服务，此举标志着美国银行业与新生数字货币生态系统之间的关系发生了重大良性改变。

  

**俄罗斯**立法机关在7月底通过数字金融资产法案，同意给予数字资产合法地位，但数字货币支付仍将被禁止。俄罗斯对于数字货币向来秉持严监管态度，很大程度上因为该国加密犯罪屡禁不止，据统计近年来俄罗斯国内通过数字货币实施的网络犯罪数量激增25倍，新任总检察长提议创建自动化跟踪系统，打击数字货币相关网络犯罪。

  

**韩国**政府本月对数字货币的监管重心落在如何提高交易透明度上，国会曾召开研讨会讨论有关反洗钱与建立数字货币交易监管系统的问题，并计划对数字货币征税。

  

**（二）区块链相关政策支持**

  

7月份各国在区块链领域保持了一贯友好的监管态度，美国、韩国、欧洲等多个国家和地区政府支持该领域技术创新。**美国**数字商务协会主席指出新冠疫情迫使国会关注数字经济，其对区块链的态度已发生巨大变化，而众议院在年度国防支出法案中增加两个区块链修正案也证明了这一点。各国政府对区块链领域的投资力度加大，**欧洲**创新委员会已向区块链创业公司提供560万美元的资助，而**韩国**政府计划将对区块链和工业4.0技术投资数百亿美元。

**（三）其他重要监管动向**

  

除上述方面外，本月金融科技重要监管动向还包括：

  

**一是人工智能等前沿技术在金融领域应用获得多个国家和国际组织关注**。国际证监会组织（IOSCO）曾就如何监管市场中介和资产管理机构使用人工智能（AI）和机器学习监管规范发布了一份拟议指南，并于近日发起意见征询，希望协助各国有效提高机构运营速率、降低投资成本；韩国金融服务委员会（FSC）成立“金融服务中的人工智能（AI）技术推广工作组”，旨在促进该国金融领域人工智能应用。

  

**二是国际清算银行创新中心计划将新增欧洲与北美分部**。国际清算银行宣布将在未来两年携手加拿大银行、英格兰银行、欧洲中央银行等在北美和欧洲地区增设创新金融中心。此外，该组织还计划与美国联邦储备系统（纽约）建立战略伙伴关系。

  

  

2

  

**金融科技重要技术进展与应用**

  

**（一）最新技术进展**

7月，金融科技技术发展重点聚焦于区块链技术，多家企业推出新工具或发布新框架以提升和拓展以太坊性能、优化区块链使用路径以加强其应用过程中的安全保障以及有企业推出新的区块链开发支持工具以提高开发速度、降低开发门槛等。

  

**一是多家以太坊底层基础设施提供商或初创企业针对以太坊部分功能推出了新的改进工具及框架等，对以太坊性能进行优化**。**具体包括**：以太坊储存和通讯基础设施Swarm发布首版官方客户端SwarmBee 0.1.0。SwarmBee与提供去中心化的内容存储和分发服务的Swarm中其他节点连接，形成Kademlia拓扑网路，允许操作者共同实现资料的分布式不可变储存、同步检索及推送等功能。区块链初创公司Marlin发布其中继网络框架OpenWeaver，选定一组节点广播新交易以加快以太坊上的区块传播速度，还将通过为待处理的加密交易提供额外路径来加强以太坊的去中心化程度。此外，以太坊智能合约自动执行工具GelatoNetwork上线主网，允许开发人员自动执行用户交易，无需运行任何底层服务器基础架构。

  

**二是部分企业优化区块链使用路径以加强其应用过程中的安全保障**。Bolt Labs宣布将与Tezos区块链合作为比特币集成第二层隐私协议，为匿名支付渠道提供闪电中心屏蔽地址，并附加零知识证明，以支持隐私保护。区块链监控平台PARSIQ与Bitsgap集成，允许用户设置各种链上事件的参数，为基于实时链上数据的自动交易订单执行设定新标准。

  

**三是区块链开发公司Tendermint推出开源且能快速构建新的区块链的工具Starport**。目前大多数基于 Cosmos SDK 开发的区块链需应用 Cosmos Hub 的源代码Gaia。Gaia 中的代码文件杂多，使得构建和维护区块链的技术门槛较高且耗时长，经验丰富的区块链开发人员构建一个新的区块链并启动本地测试网要用近一天的时间。相比之下，Starport 仅包含了构建基于 Cosmos SDK 的区块链所需要的最少文件，开发人员只需使用两个 CLI 命令就可以快速构建新的区块链，在五分钟内启动一个基于 Cosmos SDK 的简单区块链。Starport 的智能搭建功能从根本上减少了开发时间，并降低了开发人员进入区块链行业的门槛。

  

**（二）利用智能合约等技术构建新型支付网络**

  

7月，支付领域仍是金融与科技结合的重点领域，各机构致力于开发和利用智能合约等区块链技术构建新型支付网络，重点关注自动支付、跨境支付以及数字货币支付等方面。

  

**自动支付方面**，萨瓦德尔银行、桑坦德银行、西班牙对外银行等五家西班牙银行已完成智能合约可编程支付概念验证测试，能够在区块链网络中执行由智能合约触发的付款。该测试确认了将区块链技术应用于支付领域的可行性，并允许在签订合同或收发货后，若满足预设条件即自动执行自动付款。

  

**跨境支付方面**，**多家机构在跨境支付网络原型设计、跨境移动支付及其他支付解决方案推广等方面取得突破**。新加坡金融管理局与淡马锡合作完成Ubin项目，开发多币种支付网络原型，可以有效提升交易速率、降低交易费用，并可用于搭建跨境支付基础设施。英国金融科技TransferWise和数字银行N26拟向巴西、墨西哥、新加坡、菲律宾等更多国家提供跨境支付服务。N26应用程序可以通过API集成访问TransferWise服务，因此用户可以直接从其移动设备进行跨境交易。16家欧洲银行联合推出“欧洲支付计划”，为欧洲消费者和商家创建包括支付卡和数字钱包，涵盖到店支付、在线支付、P2P支付和ATM取款等多项常用功能的统一的支付解决方案。

  

**数字货币支付方面，支付场景不断延伸，用户触达大学师生、关联企业以及全球商户**。日本区块链公司Soramitsu计划在本地区块链上发行“白虎币”，并在福岛县会津大学的食堂和商店进行测试，逐渐向校外推广。日本三菱日联金融集团（MUFG）计划与 Recruit Group 合作发行数字货币，用于 Recruit 会员公司的智能手机支付应用程序。Visa与数字货币平台Coinbase和Fold合作，开展FastTrack计划将数字货币与全球商户网络整合。目前已经有超过25个数字货币钱包将其服务链接入Visa，可以在任何接受Visa的地方使用Visa借记卡或预付凭证使用数字货币消费。

  

**（三）去中心化金融应用场景进一步拓展**  

  

去中心化金融（DeFi）是指以区块链技术和密码货币为基础，建立在开放的、去中心化网络中的各类金融领域的应用，如闪电网络、去中心化交易所、网络借贷平台、稳定币等。DeFi可降低中心化机构的组织作用和中介费用，数据较为公开透明。7月，DeFi 热度延续，新型去中心化金融产品和服务增加，应用场景延伸至投资、信贷、资产转换等领域。

  

**投****资方面**，新西兰基金管理公司Techemy Capital推出基于DeFi的可投资产品，包括三个初始托管投资组合，托管在TokenSets平台上，由可编程算法代码运行，消除中间商并直接连接市场主体，从而提高资本效率和收益。

  

**信贷方面**，DeFi借贷协议Aave推出“信用委托”新功能，允许用户提供无正式抵押要求的点对点贷款。该功能依赖于同行之间达成协议，允许借款人自由使用贷款人的信贷额度，借贷双方签订的法律协议条款可以与区块链上的可记录合法合同的OpenLaw项目集成，实现正式化。

  

**资产转换方面**，匿名数字货币系统LOKI推出DeFi资产跨链闪兑服务Blockswap，允许用户将流动性资金池内任何加密资产直接转换为其他资产，支持跨链资产直接交换。

**（四）多家银行完善开放银行体系，推动金融服务转型升级**

  

7月，多家银行利用区块链、人工智能等新技术丰富金融产品、拓宽金融服务渠道、改变经营方式，推动自身数字化、多元化发展，构建开放银行体系。

  

**金融产品和服务方面**，英国巴克莱银行集团与Scalable Captital合作推出数字咨询服务，通过在线银行、移动客户端为用户提供量身定制的个性化投资方案。瑞士加密银行SEBA与DASL合作，在Corda的公共网络上提供资产证券化服务，为托管客户创建钱包，发行数字证券并将其分发给财富管理和其他投资者网络。英国渣打银行的创新平台SC Ventures正在构建“市场上最安全的加密货币托管解决方案之一”，确保客户存储数字资产的安全。

  

**银行业务经营方式方面**，德意志银行集团企业银行部全球首个虚拟数字员工 “Blue Bot Yi”在中国正式上岗，已负责为两家德意志银行在华客户提供实时定制交易报告、现金池报告的服务，并能处理和响应客户查询指令。该数字员工还将与德意志银行应用程序接口（API）及其他人工智能科技进行进一步整合，使得其工作和能力范畴超越基本的机器人流程自动化概念。

  

**（五）其他技术应用重要动向**

  

除上述进展外，7月金融科技领域其他技术应用还包括加强银行客户身份验证、推出移动货币互操作性测试平台等。

  

**一是斯里兰卡央行拟通过区块链技术加强银行客户身份验证，并推动跨部门数据融合**。斯里兰卡央行已选出三家软件开发公司负责进行身份验证（KYC）平台的概念验证（PoC）设计，计划允许银行部门和政府在区块链上实时共享和更新银行客户数据。

  

**二是GSMA推出移动货币互操作性测试平台，助力普惠金融**。GSMA普惠技术实验室启动互操作性测试平台，结合GSMA Mobile Money API和Mojaloop（开源代码）两种技术开发联合测试环境。该平台使金融服务提供商在端到端生态系统中测试其软件实施，通过模拟不同的生态系统实体、不同的API和不同的用例来解决测试复杂方案，从而构建无数新服务来满足服务不足的用户群体的需求，助力普惠金融。

**（二）金融科技领域的重要研究与观点**

  

7月全球有多家研究机构份发布涉及数字货币与区块链领域的相关报告。**在数字货币领域**，全球最具权威的IT研究与顾问咨询公司Gartner发布调查报告，称大型传统企业现在还没有准备好接受数字货币支付，Gartner质疑基于区块链的支付仍不能将费用降低到其所声称的程度，并提出数字货币在会计和税务处理方面缺乏明确性，大多数商户无法处理其兑换风险，数字货币并不能解决传统企业效率低下问题。

  

**在区块链领域**，世界银行发布了《智能合约技术与普惠金融》专题报告，报告中指出区块链智能合约技术以为消费者和中小型企业提高金融服务包容性，并且有助于提高透明度，或能推动新一轮普惠金融浪潮。

  

本月有两个报告讨论了区块链专利话题：一是中国专利保护协会发布《2020年区块链领域全球授权专利报告》，这是权威机构首次公布全球区块链授权专利数量报告。报告显示，在区块链专利授权量上，支付宝以212件位列全球第一，接近第二名IBM（136件）和第三名Coinplug（107件）之和；二是韩国知识产权局发布数据显示该国区块链技术相关专利申请过去五年涨超50倍，2019年韩国国内共注册了1301项区块链专利，而2015年仅有24项。此外，美国Cointelegraph Consulting和VeChain在7月初发表了一项研究报告，对区块链和物联网解决食品供应安全问题的前景表示看好，报告指出区块链具有可追溯性和高透明度，将有效减少整条食品供应链中的信息失真。
