# 从核武器到高超声速核武器，技术的演化还是颠覆？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651548520&idx=1&sn=d9378161c77822a5a68e764b0a8170c0&chksm=f1821898c6f5918ec53e39264454e59f069d4b16c4c29a20959a3275328b72e25e1f9bf04d81&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651548520&idx=1&sn=d9378161c77822a5a68e764b0a8170c0&chksm=f1821898c6f5918ec53e39264454e59f069d4b16c4c29a20959a3275328b72e25e1f9bf04d81&scene=27#wechat_redirect)

  

  
![](../Images/580fed2992045ce67d39dcf0fb781106.png)![](../Images/3e2f9b90953c2e672f02a9d06d839a9f.png)  

  

****在过去20年的高超声速技术发展中，高超声速常规武器已验证具有技术上可行性，但如果将其与核武器结合，形成高超声速核武器（NAHW），情况将更为复杂。本文整理****了美国战略研究季刊登的《高超声速技术：核武器的演化？》文章****，主要内容包括：将未来的NAHW与三个现有核武器系统，洲际弹道导弹（ICBM)、巡航导弹和导弹防御系统进行比较；梳理了现有核武器系统的历史发展脉络，并与NAHW进行了对比；分析了将现有核武器系统升级为高超核武器系统是否具有必要性；同时，文章还分析了在现有系统的背景下，双方都具有NAHW的潜在意义。****

  

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**技术发展**

  

高超声速技术是多领域技术的有效结合体，虽然在过去的几十年间，高超声速各个技术领域都得到了迅速的发展，但并没有对核威慑理论产生颠覆性影响。相比之下，核武器技术的发展显得更为激进，我们需要思考的是，**随着高超声速核投送系统等新技术的发展，威慑思维是否会由现在的核威慑转变为高超核威慑呢？**

要说清楚高超声速投送技术是演化的还是革命性的，需要与现有的核武器投送技术进行比较。

  

**![](../Images/c19dcca273486fefc736e17c78b8fb06.png)**

图1 高超声速技术发展趋势

**现有核武器系统与高超声速核武器对比**

  

NAHW可以看作是三个现有核武器系统的叠加：洲际弹道导弹、巡航导弹和导弹防御系统。

  

洲际弹道导弹射程远，与未来的远程NAHW类似；巡航导弹具有机动性，与NAHW类似，但巡航速度相对较慢，容易被发现和跟踪，留与对手较为充足的防御时间；导弹防御系统相对非复杂，各层之间的协调需要足够的时间，相比之下，高超声速武器时间自由度上不允许。

  
**（一）洲际弹道导弹**

  

下面将从洲际弹道的**速度、射程和精度**这三个方面的变化出发，与高超声速系统进行对比。

![](../Images/f82490225f8af9107fee6206244db55d.png)

图2 美国洲际弹道导弹和潜射弹道导弹速度变化图

  

速度方面，如图2所示，在过去的50年中，ICBM和潜射弹道导弹（SLBM）速度没有显著提高，相反，速度保持相对恒定，甚至下降。由于SLBM和其他短程弹道导弹已能迅速地打击目标，所以为了进行快速打击而开发高超核武器系统可能不是非常必要的。

  

图2还表明，**美国高超声速技术在速度上滞后于ICBM和SLBM技术，所以，从速度上来看，高超声速技术相对于现有弹道核投送系统技术，只能说是演化的。**

  

![](../Images/19aa2772c5e851a4fdc6caabf9435b92.png)

图3 美国洲际弹道导弹射程变化图

  

射程方面，如图3所示，ICBM的射程变化很小，而SLBM的射程随着时间的推移而稳步增加。**但美国目前的高超声速技术在射程上与现有的弹道技术相比相形见绌。**

  

精度方面，传统的高超声速武器精确性较好，虽然美国目前关于高超声速投送系统的数据较少，但ICBM的精度明显低于巡航导弹。**因此，NAHW可能比ICBM更精确。**

  

**（二）巡航导弹**

  

射程方面，如图4所示，在过去70年中，巡航导弹的射程一直相对固定。高超声速武器射程远在现有巡航导弹的射程之内。从射程上的角度来看，NAHW相对巡航导弹是演化的，但没有革命性的改变。  

![](../Images/ad84a3ae8bcda1e511a24062a5a74171.png)

图4 巡航导弹射程变化图

  

速度方面，如图5所示，在过去50年中，美国巡航导弹的速度低于马赫数2。与X-51A高超声速测试系统比较，现有巡航导弹已知速度低于高超声速系统速度。

  

![](../Images/d80a7898db8b76c26248d8e27ca905c9.png)

图5 巡航导弹速度变化图

  

精度方面，巡航导弹的精度远高于洲际弹道导弹，而且巡航导弹的精度随着时间的推移而提高。

  

**小结：尽管高超声速技术经过了几十年的发展，但仍没有超越现有的核武器运载技术，因此，现有的威慑思想仍适用于NAHW。**

  

**（三）导弹防御系统**

  

从历史的观点来看，高超声速核武器投送系统可以看作是对导弹与导弹防御之间竞争的长期发展的一种反应。虽然高超声速武器表示难以防御，但历史表明，终将产生足以对抗这一威胁的防御系统。这也表明，NAHW不具备足够的革命性。

  

所以，NAHW的出现将是一种技术演化，而不是一场技术革命。导弹防御技术能够抵御诸如巡航导弹和洲际弹道导弹等机动武器的高速威胁。也就可以合理地假设，如果将洲际导弹和巡航导弹这两种防御能力结合起来，将有可能发展出能够对抗NAHWs的防御系统。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**对双方拥有武器的影响**

  

从速度、射程、精度和导弹防御这几个方面来看，双方拥有NAHW和双方拥有数量相当的洲际弹道导弹、潜射弹道导弹以及核巡航导弹似乎没有什么区别，NAHW并没有增加对拥有庞大、多样化核武库国家的打击优势。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**结论**

  

文章对NAHW是否会改变现有的威慑思想进行了讨论，其认为，NAHW是现有洲际弹道导弹、巡航导弹和导弹防御等技术的叠加，高超声速技术与现有核武器技术相比，速度、射程和精度等相关要素演化得足够缓慢，将不会对现有的核威慑理论产生颠覆性影响。

  

文章还指出，**将现有的美国核武库升级为高超声速投送系统是没有益处的，**相对于巡航导弹或洲际弹道导弹，NAHW在速度、射程或精度方面没有什么优势。虽然高超声速投送系统在对抗导弹防御系统方面具有一定的潜在优势，但在当前高超声速防御系统持续发展的背景下，这种潜在优势可能只是暂时的。

  

**相对于俄罗斯核常兼备的武器发展思路，美国似乎更倾向于发展常规武器，但随着美俄核军控谈判的进行，美国未来是否会将现有核武器系统向高超声速核武器系统演化，还有待进一步关注。**
