# 俄发布新版《国家核遏制基本政策》

**2020年6月2日，俄罗斯联邦总统普京签署本年度第355号总统令，批准了《俄罗斯联邦国家核遏制基本政策》（以下简称《基本政策》），这是俄罗斯首次公开发布此文件，上版文件于2010年2月出台，但是内容并未公开。新版《基本政策》共四章，阐明了俄罗斯核遏制实质、核武器使用条件、国家权力机关职责等。**

  

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**一、俄罗斯核遏制的总体特征**

《基本政策》指出，俄罗斯核遏制政策具有防御性特点：核力量维持在足以实现核威慑的水平，以有效维护国家主权和领土完整，慑止潜在对手对俄侵略；将核武器视为威慑手段，使用核武器是极端情况下的被迫行为；愿意竭尽全力防止国家间关系恶化，降低核战争爆发风险。

**二、俄罗斯核遏制实质**

  

《基本政策》指出，俄罗斯实施核遏制旨在警告潜在对手，若对手侵略俄联邦和（或）盟国，俄罗斯必定予以反击。

  

**在面临以下6种军事威胁时，俄必须实施核遏制进行反制：**

1.  在俄联邦和盟国周边地区或常规部队所驻邻近海域配装核武器运载工具的潜在对手增多；
    
2.  视俄联邦为潜在对手的国家加强部署反导防御系统、中近程巡航导弹和弹道导弹、高精度常规武器和高超声速武器、无人攻击机、定向能武器；
    
3.  研制和部署应用于太空的反导防御武器和打击武器；
    
4.  某些国家部署可打击俄联邦和（或）盟国的核武器、其他类型的大规模毁伤性武器，以及这类武器的运载工具；
    
5.  核武器及相关运载工具、制造技术设备的失控性扩散；
    
6.  在非核国家部署核武器及运载工具。
    

  

**俄罗斯核遏制7项原则包括：**

1.  遵守国际军备控制协议；
    
2.  核威慑政策存在持续性；
    
3.  核威慑与军事威胁存在适应性；
    
4.  对潜在对手进行核遏制的力量、手段、规模、时间、地点存在不确定性；
    
5.  参与实施核遏制政策的联邦权力机构和组织由国家统一领导；
    
6.  保持核威慑力量结构的合理性，将其维持在达到核遏制目的的最低水平；
    
7.  将核遏制力量和手段保持在战备状态。

**三、俄罗斯联邦使用核武器的条件**

  

《基本政策》指出，对俄联邦和（或）盟国使用核武器和其他种类的大规模毁伤性武器，以及使用常规武器威胁到国家存亡时，俄联邦保留使用核武器的权利。

  

**俄罗斯核武器4项使用条件包括：**

1.  获知向俄联邦和（或）盟国发射弹道导弹的可靠信息；
    
2.  敌方向俄联邦和（或）盟国本土使用核武器或其他种类的大规模毁伤性武器；
    
3.  敌方破坏关乎俄核反击能力的国家重要设施或者军事设施；
    
4.  敌方使用常规武器打击俄罗斯并对国家存亡造成威胁。

**四、俄罗斯联邦权力机构落实核遏制政策的任务与职责**

  

《基本政策》指出，联邦总统对核遏制政策进行总领导；联邦政府负责落实维持和发展核遏制力量的经济政策，以及负责制定和实施核遏制领域的外交与信息政策；联邦安全委员会负责制定核遏制领域军事政策的主要方向，以及负责协调联邦权力机构和组织在落实总统核遏制相关决定过程中的各项工作；联邦国防部通过总参谋部对核遏制政策进行直接规划，并组织实施相关军事工作；其他联邦权力执行机构和组织根据各自职责，有效落实联邦总统的核遏制相关决策。

**五、小结**

  

**（1）俄首次公开《基本政策》，旨在重申核威慑立场**

  

2010年版《基本政策》未对外公开，新版文件在核遏制政策没有根本性变化的情况下公开全部内容，目的是在当前国际军控条约实施前景不明朗的复杂形势下，向国际社会“开诚布公”表明核遏制政策的防御性、动用核武器的强硬性，一是避免不实舆论抹黑俄国家形象，二是将“面面俱到”的核反击条件呈现在潜在对手面前，以慑止向俄使用核武器及高精尖常规打击武器的一切军事行动。

  

**（2）核遏制延续防御性特点，但政策更为全面、具体**

  

《基本政策》与2014年版《军事学说》所体现的核遏制政策相一致，强调“核遏制政策具有防御性的特点”“仅将核武器视为威慑手段”，核武器使用条件依然为“对俄及其盟国使用核武器和其他大规模毁伤性武器，以及使用常规武器威胁国家存亡时，俄联邦保留使用核武器的权利。”

但是《基本政策》作为国家核遏制领域的专门政策性文件，相比《军事学说》更为详尽阐述了核遏制政策的细节，包括明确了核遏制的七项原则、使用核武器的四种条件、需实施核遏制予以应对的六种军事威胁、可威胁国家存亡的几类常规打击武器等。

  

**（3）****新增两种核武器使用条件，核反击条件变广**

  

《基本政策》细化了使用核武器的四种条件，其中两种已在2014年版《军事学说》中有所体现。新增条件中一为“获知向俄联邦和（或）盟国发射弹道导弹的可靠信息”，此观点体现了俄联邦总统曾提出的“得知向俄罗斯方向发射导弹的数据信息就足以发起核反击”；二为“敌方破坏关乎俄核反击能力的国家重要设施或者军事设施”，属此范畴的破坏行为较为“广泛”，如敌方使用常规武器抵消俄核威慑能力、敌方对俄核基础设施实施网络攻击等均可列入其中。
