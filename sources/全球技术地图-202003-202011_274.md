# 构建产业新生态，实现5G行业应用新发展

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651544037&idx=1&sn=8e7568f9e8ad6bc3a47e4740b90dfc89&chksm=f1822a15c6f5a303c1090a02b45ef789b19d12f8225118aaa06dd2b95c552dbbc4a740493507&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651544037&idx=1&sn=8e7568f9e8ad6bc3a47e4740b90dfc89&chksm=f1822a15c6f5a303c1090a02b45ef789b19d12f8225118aaa06dd2b95c552dbbc4a740493507&scene=27#wechat_redirect)

**5G作为支撑经济社会数字化、网络化、智能化转型的关键新型基础设施受到全球各国的关注，行业应用是体现其价值的关键。从国外调研数据情况看，多国采用多元化模式大力推进5G行业应用。我国需要积极构建产业新生态，实现5G行业应用新发展。**

  

  

**一、行业应用是体现5G价值的关键**

  

**生产企业对5G充满了期待。**生产企业应用一项新技术通常需要一个较长的时间，但5G早已引起了众多企业的关注。一项对国外465家企业的调查数据显示，虽然2019年4月5G才首次商用，已有36％的企业认为5G是一项变革性的技术，71%的企业认为5G将对其产生较大影响。尽管5G应用仍处于起步阶段，但其潜力巨大，企业希望通过5G技术提高生产效率，提升自动化水平，改善客户体验。4G促进了移动互联网以及平台经济的快速发展，而5G将在更广泛的生产领域引发大量移动应用和新型商业模式的出现。

  

**5G是多项新应用的使能器。**5G催生了多项行业新应用，目前越来越多的企业关注机器人、自动驾驶、工业自动化、增强现实、无人机、资产管理、安防等方面的新应用。随着5G技术的成熟，企业对基于5G技术的行业新应用充满信心，根据咨询机构OMDIA对国外企业的一项调查显示，有超过70%的受访企业计划使用基于5G技术的多项新应用。

  

**行业应用是体现5G经济价值的关键。**现阶段5G网络重点向消费者提供服务，但业界普遍认为行业应用才是体现5G经济价值的关键。5G技术将广泛应用于各行业的生产制造、供应链管理、产业协同等方面，带来全社会产值的增加。根据咨询机构OMDIA的测算，全球范围5G行业应用的经济贡献将达到13.2万亿美元。5G对不同行业的经济贡献有所差别，制造业将是受益最明显的行业，5G将带动全球制造业新增产出4.7万亿美元，其次是交通运输、仓储物流、零售业、建筑业等行业。

  

**二、5G行业应用面临新形势**

  

**目前5G行业应用存在多种模式。**国外调研数据显示，目前5G行业应用有四种典型模式，其中最受企业欢迎的模式是由企业、电信运营商和设备制造商共同推进5G行业应用，电信运营商和设备制造商协助企业实现相关应用和解决方案，电信运营商主要提供连接服务，该类项目占调研项目总数的40％。第二类受欢迎的模式是企业主导5G应用，自主选择服务提供商，电信运营商仅作为次级供应商，该类项目占调研项目总数的32％，这是5G行业应用早期，热衷使用新技术企业最典型的模式。第三类是由电信运营商主导提供服务，设备制造商或服务商并不直接与企业接触。该模式占21％。第四类是由第三方主导提供5G服务，比例仅占7%。

  

**企业数字化转型需要包括网络、平台、应用在内的完整解决方案。**企业数字化转型需要的是包括5G在内的完整解决方案。尽管5G是基础网络，但服务平台、管理工具、应用程序也很重要，而且企业提出了更多定制化的需求。所以5G行业应用需要电信运营商、系统集成商、软件开发商等多方参与。根据2019年对亚太地区229家企业5G物联网业务的调查显示：47%的企业首选电信运营商提供连接服务，但企业希望电信运营商、系统集成商、软件开发商等合作，发挥各自专业优势，提供涵盖网络、平台、应用的完整解决方案。

**国外行业专网数量增加。**随着德国、日本等国家规划了区域5G频率，多家企业、设备制造商以及系统集成商积极申请频率建设区域5G专用网络。据不完全统计，截止2019年底全球有超过135个企业建设了LTE/5G专网（不含电信运营商LTE/5G网络），相比2018年增长超过6倍。行业用户希望采用专网模式加强对网络的控制。

  

**三、构建新生态是推动5G行业应用的基础**

  

**多元化的供给带来新机遇。**5G行业应用需要引入多元化的供应商。根据2019/2020年对国外企业选择5G应用供应商意愿的调研，行业用户希望有多元化的选择，电信运营商是供应商的首选，除此之外，新的服务提供商、设备制造商、系统集成商、甚至企业自己也是选择。多元化的供给将为5G发展带来新的机遇。

  

**构建融合创新5G行业应用新生态。**构建融合创新的新生态是发展5G行业应用的基础。一是电信运营商、设备制造商与行业伙伴深度合作，努力推进5G行业应用。例如德国电信和爱立信签署战略合作协议，与博世力士乐、西门子等工业装备制造商紧密合作，为德国工业企业提供行业5G解决方案。二是设备制造商与工业装备供应商及IT服务商合作，积极拓展企业市场。例如爱立信与加拿大Ambra Solutions合作发展行业应用；诺基亚与微软Azure签署全球战略合作协议，诺基亚提供5G专网以及SD-WAN产品，微软提供云计算/边缘计算解决方案。诺基亚还与日本系统集成商NS Solutions和日立电子等工业装备制造商合作推进5G行业应用。三是电信运营商与IT服务商加强合作。例如Verizon、沃达丰与亚马逊的云部门（AWS）合作，将边缘计算和存储服务与5G网络融合提供专业服务。

  

**四、国外5G行业应用模式多样**

  

**企业自建5G专网成为新选择。**随着德国、日本等国家区域5G频率许可的发放，部分大型企业选择自建5G专网。例如大众集团计划在其122个工厂部署5G专网。大众集团的5G项目是“数字生产平台”（DPP）的一部分，DPP的目的是在集团内部及其供应链企业中构建一套完整的IT（Informatica Technology）和OT（Operation Technology）技术通用架构。大众集团计划建设独立的5G网络，DPP中数据分析及应用程序由亚马逊AWS提供。目前该网络的维护管理方式尚未确定，试验网络设备由爱立信提供。

  

**出现行业专网服务商。**考虑到行业差别以及需求的多样性，5G催生了专网服务新业态。芬兰Ukkoverkot公司是一家向工业企业及政府提供LTE及5G专网设计、建设和运维的服务提供商，其客户包括港口、机场、芬兰国防部、科尼（起重设备制造商）、Kalmar（港口自动化厂商）和瑞典Sandvik（采矿设备制造商）。在Sandvik的项目中，Ukkoverkot向瑞典电信运营商租借频率建设5G专网。部分企业也有意提供5G专网服务，如美国联邦无线等硅谷初创公司、德国魏德米勒集团（机床制造商）等，部分国家5G专用频率的规划将进一步促进新业态的发展。

  

![](../Images/c5adc70a800141b43fa2faa593ca47ea.png)

  

**设备制造商加强与生态伙伴的合作。**设备制造商加强与生态伙伴的合作，直接向行业用户提供服务。诺基亚一方面加强与IT企业的合作，2019年11月诺基亚与微软合作，将微软的云平台以及基于公有云的机器学习功能集成到专网5G产品中；另一方面诺基亚加强与工业装备制造商的合作，在日本计划与日立电子以及NS集团合作提供专网5G解决方案。目前诺基亚参与了多个企业自建5G项目。

  

**电信运营商作为增值服务商为5G应用提供专业服务。**电信运营商凭借其网络优势为5G行业应用提供增值服务。电信运营商Telia和爱立信合作为斯堪尼亚（瑞典货车及巴士制造商）的南泰利耶工厂提供专网LTE/5G服务。该项目由爱立信主导，Telia作为增值服务商，主要负责提供专业的技术支撑和连接服务。项目中还有行业方案提供商、系统集成商、工业领域合作伙伴参与。

  

**五、我国发展5G行业应用的思考**

  

**加快构建我国5G行业应用新生态。**引导行业用户、电信运营商、网络设备制造商、系统集成商、ICT企业、装备制造商等各方共同参与5G行业应用，一方面培育行业5G应用需求，重点发展制造业、交通运输、仓储物流、零售业、建筑业等5G行业应用；另一方面提高产业供给能力，引导各方共同参与，构建5G行业应用多元生态。

  

**依托电信运营商5G网络推进行业应用。**现阶段我国仍主要依托电信运营商5G网络发展行业应用。一方面电信运营商需要做好5G网络部署和优化，解决行业用户对5G上行带宽、传输时延和安全性等方面的需求。另一方面电信运营商需要融入到行业应用价值链当中，探索灵活多样的合作模式，发挥网络连接优势，与合作伙伴共同推进5G行业应用。

  

**探索5G行业应用新模式。**开展5G行业专用频率规划研究，适时出台5G专用频率规划和管理政策。结合频率规划情况，开展部分重点行业和领域的5G专网试点，探索包括企业自建、专网运营商提供服务等新的模式，满足行业应用多样化需求。
