# 技经观察 | 从 “能源主导”到“页岩危机”，疫情按下了“美国优先”的暂停键

**新冠疫情导致全球能源需求下降，美国能源出口受损，再加上沙俄原油价格战对其能源产业的严重冲击，美国通过原油出口谋求全球能源主导权的长期战略或将面临调整。**

  

  

得益于页岩革命，美国成功转变为世界上最大的油气生产国和主要的油气出口国。IEA数据显示，2017年美国原油产量占全世界原油总产量的13%，天然气占20%。同期，国内能源产量满足了全美98%的一次能源消费，几乎实现了完全的能源独立。在这种转变之下，美国顺势调整其能源政策，从最初的追求“能源独立”转向谋求“能源主导”，在石油、天然气、核能以及新能源领域都表现出了谋求世界能源霸主地位的野心。而新冠疫情导致全球能源需求下降，美国能源出口受损，再加上沙俄原油价格战对其能源产业的严重冲击，美国通过原油出口谋求全球能源主导权的长期战略或将面临调整。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**一、美国从“能源独立”到“能源主导”的战略转变**

  

谋求“美国能源主导权”是特朗普政府“美国能源优先”战略的核心目标。为实现“能源主导”，特朗普政府在国际及国内事务中的政策选择与过去有很大区别，对美国的政治、外交、军事等方面产生了重大和深远的影响。其核心举措包括：退出《巴黎气候协定》以减少国际社会对其能源生产的监管障碍；简化化石能源的出口审批制度以扩大能源生产；制裁他国能源项目以提高本国能源影响力；立法推动核能创新以恢复其核能领导地位；布局新能源产业链以建立一个不依赖国外关键材料的安全供应链；高度重视能源技术研发以维持其全球能源技术领先地位等。在政策转变下，美国大量石油和天然气进入国际市场，冲击以欧佩克为主导的石油市场格局，同时其在核能及新能源上的布局也给新兴能源市场带来深远影响。

**二、通过能源出口谋求全球主导权是特朗普“美国优先”战略的核心目标**

  

特朗普政府“美国能源优先”战略的核心目标是通过能源出口，谋求全球市场的主导权。**从政府行为来看，**为了增加能源出口，特朗普政府做出了很多努力，包括放宽石油管制、简化出口审批、重启多个石油管道项目甚至制裁他国能源项目。在中美贸易磋商中，特朗普政府要求中国从美国大量采购原油。此外，特朗普还希望进一步扩大能源出口，将原油运往欧洲和日本，以占据更大的市场份额。**从出口情况来看，**自2017年以来，美国每年的日均原油出口量大幅增长，其中2019年美国原油日均出口量为298万桶，较2018年增长了45%；2018年美国原油日均出口量达200万桶，较2017年增长70％，出口地区遍及亚洲、欧洲、南美等约40个国家和地区。**从影响来看，**美国原油产量和出口的增加不仅能提振国内石化等传统行业，促进制造业回归，从而带动美国经济和就业，还可在外交和贸易上发挥作用，帮助美国追求更大的国家利益。美国国务卿蓬佩奥就曾表示，美国的能源出口也可作为“美国优先”政策的外交筹码，帮助美国在国际贸易上扩大影响力，从而进一步谋求美国在全球市场上的主导权。

**三、疫情叠加原油价格战对美能源产业带来多重影响**

  

**（一）加剧美国页岩企业的财务和资金困境**

  

在原油价格战和新冠肺炎疫情暴发之前，大部分美国页岩企业已难以盈利。根据穆迪的数据，北美油气公司在未来四年将面临2000亿美元的到期债务，其中2020年的到期债务额达400亿美元。此次疫情叠加原油价格战进一步加剧了美国页岩行业的财务和资金困境。据测算，美国页岩油平均收支平衡价格在40美元/桶左右，仅有埃克森美孚、雪佛龙、西方石油和Crownquest五家页岩钻探公司的新井成本可以保持在31美元/桶的水平，此次油价暴跌加大了页岩油公司的现金流压力。而全球经济衰退叠加新冠疫情在全球传播的影响，使得原油需求和行业投资均出现收缩，一些现金流紧张且负债率较高的页岩油公司有资金链断裂的可能。

  

![](../Images/b8b0e546baa746e2ad80d5dcc88998c7.png)

  

**（二）不利于特朗普政府“能源优先”的长期发展战略**

  

2017年1月特朗普上任以来，一系列化石能源宽松政策叠加页岩油技术发展，推动美国页岩油产量大幅提升。美国能源部数据显示，2020年1月美国原油产量接近1300万桶/天，比2017年1月890万桶/天高出约400万桶/天，寻求原油出口已成为美国能源企业的核心诉求。通过大量的石油出口带来美国内就业和经济的繁荣并在全球石油市场占据主导地位是美国“能源优先”战略的核心目标。而此次石油价格战带来的油价暴跌使得美国大部分页岩油公司亏损运营，大量油气生产商破产倒闭，导致页岩油产量大幅下降；在疫情影响下，全球能源需求下滑，美国油气出口也进一步下降，这将对特朗普政府“能源优先”的长期发展战略带来不利影响。

  

**（三）加速美国页岩市场的出清速度，或有利于增加其整体竞争力**

  

受疫情及石油价格战影响，美国越来越多的页岩油企业深陷债务危机，多家能源公司申请破产，活跃石油钻机数量降至近几年来的最低水平。而该低油价环境导致的美国页岩油企业破产潮或许也是美国大型油气公司等待已久的收购时机。据外媒报道，纽约一家欧洲能源经纪公司的资深交易员曾表示，除了俄罗斯和沙特之外，美国大型油气企业也在阻止特朗普拯救页岩油公司，因为他们希望以低价购买破产倒闭的页岩油公司资产，从而占据更多的市场份额。以埃克森美孚和雪佛龙为首的美国大型石油企业也曾多次明确表态，反对政府在能源价格重挫情况下实施任何石油减产措施。在此次疫情和石油价格战的共同影响下，美国页岩油气市场并购重组的规模和数量大幅增加，非规模性产量被迫大批退出市场，将加速美国页岩产业的出清速度，从长远来看，或有利于增加其市场整体竞争力。

**四、美国扶持能源产业的计划及措施**

  

**（一）对内政策**

  

美国政府为保护页岩油产业，其对内政策主要有四大方面：**一是为石油生产商提供战略石油储备。**随着石油需求锐减，原油供过于求的情况令美国商业储油设施不堪重负，缺乏储存将迫使油井过早关闭，对美国能源工业产业不利影响。对此，美国能源部于4月3日将3000万桶的战略石油储备空间提供给受疫情影响而遇到困难的美国石油生产商，并计划再增加4700万桶的石油储备能力以缓解页岩油供应过剩的危机。**二是改善能源需求。**据外媒报道，美国财政部长姆努钦曾表示，特朗普政府正在考虑以多种方式挽救能源行业，包括提前购买燃料、提前购买机票，以通过政府改善能源需求的方式帮助页岩行业度过危机。**三是入股能源行业。**美国白宫国家经济委员会主任库德洛曾表示特朗普将以联邦政府购买能源企业股票的方式帮助页岩企业缓解资金压力。**四是降低企业费用，如降低从联邦土地提取石油和天然气的特许权使用费等。**

  

**（二）对外政策**

  

为减少石油进口，美国政府主要考虑对国外进口石油征税，或通过非欧佩克法案，起诉沙特阿拉伯等国。3月，美国页岩油厂商哈姆（同时也是特朗普能源政策的非正式顾问）向美国商务部提出申诉，控告沙特“非法”倾销原油，并将与美国国内能源产油商联盟一起对沙特发起调查。4月，特朗普与美国能源企业高管会面时，表示将可能对沙特原油进口实施惩罚性贸易措施。此外，特朗普也曾直接表示将停止从沙特进口原油。

**研究所简介**

  

国际技术经济研究所（IITE）成立于1985年11月，是隶属于国务院发展研究中心的非营利性研究机构，主要职能是研究我国经济、科技社会发展中的重大政策性、战略性、前瞻性问题，跟踪和分析世界科技、经济发展态势，为中央和有关部委提供决策咨询服务。“全球技术地图”为国际技术经济研究所官方微信账号，致力于向公众传递前沿技术资讯和科技创新洞见。
