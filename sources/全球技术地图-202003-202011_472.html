🔈 全球新冠疫情日报（20200316）

一、全球新冠疫情数据

全球疫情数据。截至2020年3月16日12时，全球共146个国家爆发了新冠疫情。除中国外，其他国家累计确诊87261人，累计治愈9775人，累计死亡3284人（涉及41个国家，其中死亡人数前10的国家包括：意大利1809人，伊朗724人，西班牙288人，法国127人，韩国75人，美国65人，英国35人，日本24人，荷兰20人，瑞士和德国各13人）。


二、国际组织动态

1.世卫组织宣布欧洲是全球疫情重灾区，已成新冠肺炎大流行的“震中”

据新华社3月14日消息，世界卫生组织总干事谭德塞表示，欧洲现已成为新冠肺炎全球疫情最严重地区，已成新冠肺炎大流行的“震中”，其确诊和死亡病例超过中国以外其他国家和地区的总和，每日新增病例超过中国疫情流行高峰时数据。谭德塞呼吁欧洲各国采取检测、追踪、隔离等全面措施。


2.国际奥委会主席巴赫表示，东京奥运会能否如期举行将听取世卫组织建议

据德国电视台3月14日消息，国际奥委会主席巴赫表示，关于东京奥运会是否取消或延期，国际奥委会将听取世界卫生组织（WHO）建议。


3. 联合国粮农组织向中国捐赠医疗物资，以支持新冠肺炎防控工作

据新华社3月14日消息，联合国粮农组织（FAO）向中国政府捐赠紧急医疗物资，用于支持抗击新冠疫情。FAO此次捐赠的医疗物资包括无创呼吸机、心电监护仪和输液泵等，都将被用于湖北省新冠肺炎患者的治疗。两批捐赠物资已于3月12日、13日分别从北京、上海发往武汉。


4. 美日欧等六大央行采取联合行动，确保美元在全球范围的流动性

据新华社3月16日消息，美联储、日本央行、欧洲央行、瑞士央行、加拿大央行、英国央行等六大央行15日发布协调行动声明，将利用现有货币互换额度为世界主要储备货币美元的供应提供支持。此举旨在满足世界各地公司使用美元信贷额度之需。同时，六大央行一致同意将互换协议价格下调25个基点。

三、美国新冠疫情相关动态

1. 美国总统特朗普宣布美国进入国家紧急状态

据NBC 3月14日消息，美国总统特朗普宣布美国进入国家紧急状态，并命令美国50个州设立应对新冠病毒紧急行动中心，启动应急计划。特朗普称，该举措可再释放高达500亿美元的资金。

2. 美国食品和药品管理局授权罗氏开展新冠病毒自动检测，检测速度将提高十倍

据NBC 3月14日消息，美国食品和药品管理局（FDA）紧急授权瑞士医药巨头罗氏（Roche）开展新冠病毒自动检测。据悉，该公司的8800系统每天最多能进行4128例检测，将美国新冠病毒的检测速度提高十倍。

3. 美国扩大欧洲旅行禁令范围，增加英国和爱尔兰

据CNN 3月15日消息，美国政府宣布扩大欧洲旅行禁令范围，增加英国和爱尔兰。新旅行禁令将从16日午夜起生效。此前特朗普宣布，自13日凌晨起，对欧洲推出为期30天的旅行禁令，英国除外。

4. 美国商超抢购潮频现，枪支子弹销量激增

据福克斯3月15日消息，随着新冠疫情不断发展，美国商店和超市抢购潮频现，多家大型超市缩短营业时间。尤其是枪支子弹销量激增，部分地区购买量是平时水平的五倍，这一情况在美国亚裔社区中更为明显。

5. 美国白宫敦促联邦政府机构限制公务旅行

据白宫3月16日消息，白宫管理和预算办公室发布备忘录，要求所有联邦政府机构考虑限制政府人员公务旅行，以减少新冠病毒感染。备忘录鼓励联邦政府各机构在可能的情况下通过电话和视频召开会议，并推迟不重要的旅行。此前，美国国防部已宣布一项为期60天的旅行禁令，要求现役军人、文职官员及家属避免前往疫情严重国家。

6.美国于3月16日起开始新冠肺炎疫苗临床试验

据新华网3月16日消息，美联社援引一位匿名政府官员的说法称，美国将开始一项新冠病毒肺炎疫苗临床试验。报道称，试验尚未公开宣布，第一位参与临床试验的人士将于16日接种实验疫苗。该试验将由美国国立卫生研究院（NIH）资助，由华盛顿州西雅图市的凯泽·珀默嫩特（Kaiser Permanente）公司健康研究所负责进行。美国公共卫生官员表示，要完全验证任何可能的疫苗，需要12-18个月的时间。测试将从45名年轻、健康的志愿者开始，他们将使用由NIH和Moderna公司共同研发的不同剂量的疫苗。参与者不会从疫苗中感染，因为疫苗本身不含病毒，试验目的旨在检查疫苗是否存在严重副作用，为更大规模的试验奠定基础。


四、其他国家新冠疫情相关动态

1.意大利新冠肺炎确诊病例接近2.5万例

据新华社3月16日消息，截至3月16日15时，意大利新冠肺炎累计确诊病例升至24747例，累计死亡病例增至1809例，治愈2335人。此外，意大利卫生部副部长西莱里和教育部副部长阿斯卡尼分别确诊感染新冠病毒。

2. 西班牙确诊人数近8000例升至欧洲第二，首相宣布进入国家紧急状态

据中国日报3月16日消息，截至3月16日，西班牙累计新冠肺炎确诊病例升至7753例，较前一日增加1710例，死亡病例升至293例。西班牙首相桑切斯宣布进入国家紧急状态，除药房、食品和其他基本必需品之外的商铺将全部关闭，武装力量将准备就绪，以抗击新冠肺炎疫情。另据外媒报道，西班牙首相桑切斯妻子感染新冠病毒。

3.德国新冠肺炎确诊病例逼近5000例，政府加强对相邻5国的边境管理，并成立疫情应对内阁委员会

据新华社3月16日消息，截至16日15时，德国累计新冠肺炎确诊病例升至5813例，较前一日增加1043例，死亡病例升至13例。德国政府宣布，将从16日起加强对奥地利、瑞士、法国、卢森堡和丹麦五国的边境管控。如无合理原因，将不再允许旅行进出。但货运交通和跨境工作通勤不受边控影响。德国总理默克尔表示，为应对疫情，政府将成立由总理、副总理、内政部长、外交部长、卫生部长和国防部长组成的内阁委员会，共同决定事关德国民众安全和健康的政策。

4.伊朗国家动员计划目前完成750万人的疫情排查

据央视网3月15日消息，伊朗卫生部副部长阿里雷扎·雷西在伊朗国家动员计划数据收集中心表示，14日当天，疫情排查小组完成了对1615000人的情况排查。截至目前，伊朗共完成了对750万人健康状况的排查工作，其中175000人出现相关症状，441人已经住院治疗。

5.非洲26国报告新冠肺炎确诊病例

据人民日报3月16日消息，非洲疾控中心副主任艾哈迈德·奥格威尔在社交媒体上发布的数据显示，非洲大陆报告新型冠状病毒确诊病例的国家增至26个，总数为280例。在过去24小时，塞舌尔、赤道几内亚、刚果（布）、中非共和国等国家报告了本国的首例确诊病例。


五、我国应对新冠疫情相关举措

1.外交部表示，中国愿尽最大努力向菲律宾提供帮助

据央视网3月15日消息，国务委员兼外长王毅应约同菲律宾外长洛钦通电话。洛钦表示，当前菲律宾处在抗击疫情的艰难时刻，正面临医疗物资和设施短缺困难，希望中方伸出援手，并积极考虑向菲律宾派遣医疗专家。王毅表示，当前中菲两国都在全力抗击疫情。菲律宾是中国隔海相望的友好邻邦，中方愿尽最大努力帮助菲方，已决定向菲方提供检测试剂盒以及防护服等急需的医疗物资，并将积极协调派出医疗专家事宜。相信菲方将在杜特尔特总统领导下，一定能尽快战胜疫情。 


2.未如实填报入境健康申明卡，将以妨害国境卫生检疫罪定罪处罚

据新华视点3月16日消息，最高人民法院、最高人民检察院、公安部、司法部、海关总署3月16日联合发布《关于进一步加强国境卫生检疫工作依法惩治妨害国境卫生检疫违法犯罪的意见》，依法惩治妨害国境卫生检疫的违法犯罪行为。检疫传染病染疫人或者染疫嫌疑人采取不如实填报健康申明卡等方式隐瞒疫情等行为，引起鼠疫、霍乱、黄热病以及新冠肺炎等国务院确定和公布的其他检疫传染病传播或者有传播严重危险的，依照刑法第三百三十二条的规定，以妨害国境卫生检疫罪定罪处罚。


3.所有入境进京人员原则上集中隔离，费用自理

据环球时报3月15日消息，在北京市疫情防控第51场新闻发布会中，北京市人民政府副秘书长陈蓓介绍，境外输入已成为北京疫情防控的主要风险，境外输入病例已成为北京新确诊病例的主体。为有效防范境外输入疫情的扩散，首都联防联控协调机制，将采取更加严密、有力的防控措施。从3月16日0时起，所有境外进京人员，均应转送至集中隔离点进行14天的隔离观察，集中观察点将配置专业医护和工作人员，开展健康监测，发现问题及时处理。有特殊情况的，经严格评估可进行居家观察。进行集中隔离观察期间，隔离人员的费用实施自理自备。对于虚报信息隐瞒病情造成疫情传播的人员，将依法依规追究责任，并纳入信用体系。

研究所简介


国际技术经济研究所（IITE）成立于1985年11月，是隶属于国务院发展研究中心的非营利性研究机构，主要职能是研究我国经济、科技社会发展中的重大政策性、战略性、前瞻性问题，跟踪和分析世界科技、经济发展态势，为中央和有关部委提供决策咨询服务。“全球技术地图”为国际技术经济研究所官方微信账号，致力于向公众传递前沿技术资讯和科技创新洞见。
