# 谷歌的芯片布局

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651577849&idx=1&sn=77fbef29b2cd7b0b879c3c3c5d6aa4c3&chksm=f182ae09c6f5271f293ee7aa15836d438c5aeed815d27414c8b6dd23cfc7c53b8208aa8d7752&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651577849&idx=1&sn=77fbef29b2cd7b0b879c3c3c5d6aa4c3&chksm=f182ae09c6f5271f293ee7aa15836d438c5aeed815d27414c8b6dd23cfc7c53b8208aa8d7752&scene=27#wechat_redirect)

**互联网巨头进军半导体行业早已不是新鲜事，谷歌是这其中的一份子。进入到2021年以后，谷歌在芯片领域的消息开始不断地出现在市场当中，这其中不仅包含了推出自研的芯片，还包括了对相关芯片企业进行收购以及宣布开源计划等。从谷歌的这些布局上看，相较于其他互联网巨头，谷歌在芯片领域的谋划似乎更具野心。**

  

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**集贤：开疆拓土的第一步**

  

谷歌进军芯片行业，要从其智能手机说起。  
2016年，谷歌推出了全新Android智能手机Pixel系列以取代原来的Nexus系列。从这两者的定位上看，谷歌每一代Nexus手机都配置了当时最新的硬件并能第一时间升级到最新Android系统，而采用代工生产的他们也捧红了多家代工厂，由此，Nexus系列也被很多人视为是软件开发者程序员才会使用的手机。而谷歌之所以推出Pixel系列手机，也是为了扭转市场对其手机业务的这一印象。这也被视为是谷歌对其手机业务的一次重大调整。  
为了一面向大众而推出的Pixel系列手机，谷歌也在他身上花了不少心思。其中，自研手机芯片便是他们的发力点之一。为此，谷歌招揽了大量的人才。  
2017年，他们从苹果挖角了多位芯片行业的人物，包括前苹果SoC芯片架构师 Manu Gulati、苹果芯片专家 John Bruno、Wonjae Choi 和Tayo Fadelu等，以及来自高通的Mainak Biswas，Vinod Chamarty和Shamik Ganguly等人。谷歌的这些动作似乎都在说明，谷歌正在为其 Pixel智能手机打造自有芯片而努力。  
与此同时，谷歌作为一个互联网企业，他未来对于数据中心的需求也十分旺盛。尤其是在新架构不断涌现的今天，不少互联网企业都在打造自己的数据中心，在这种趋势下，谷歌也希望在这块领域加强其自研芯片的实力。  
据外媒The Verge在2019年的报道显示，谷歌还通过建立新的工程师团队来完善自己智能手机和数据中心的芯片设计，这支团队致力于在印度南部卡纳塔克邦首府班加罗尔一个初展头角的半导体工厂的项目。路透社则有报道称，谷歌在班加罗尔至少招募了16名技术老兵，还有4名招聘人员专门从英特尔、高通、博通和英伟达等传统芯片公司挖人才。  
谷歌广揽贤才的脚步没有停止。今年3月，谷歌还宣布公司已聘请英特尔长期高管乌里·弗兰克（Uri Frank）为副总裁来运营其定制芯片部门。  
由此可见，谷歌已经开始在芯片领域开疆拓土。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**收购：自研芯片的速效方式**

  

除了招揽芯片人才外，谷歌也开始收购相关芯片企业来加强其自研芯片的实力。  
2018年，谷歌宣布完成 11 亿美金对 HTC 智能手机Pixel团队的收购。根据协议，HTC 的移动设备部门的部分成员将加入谷歌硬件部门；谷歌也将通过这项协议获取 HTC 的部分非独家知识产权。  
根据彭博社的报道称，在收购HTC负责Pixel的团队后，谷歌在自主芯片研发上的能力得到了进一步的提升。谷歌的硬件主管在接受采访时表示，自主研发的芯片将会在未来的Pixel设备上出现。  
在今年当中，根据IEEE Spectrum在一项调查中发现，谷歌已悄悄收购Provino Technologies，一家开发用于机器学习的片上网络（NoC）系统的初创公司。  
根据相关报道显示，NoC 能够跨越同步和异步时钟域或者使用不受时间约束的异步逻辑。NoC 将网络原理和方法用于芯片的通讯上，并给传统的总线交互带来了便利。NoC 相比于其它设计来说提高了 系统芯片的可扩展性及复杂系统芯片的功率。  
谷歌收购NoC相关企业，或许能够助力其TPU的发展，从而推动其在云端AI芯片的发展。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**不仅仅是手机**

  

无论是广揽贤才还是收购，都是谷歌为发展芯片产业而进行的招兵买马。而真正要在芯片领域立足，需要拥有可商用化的产品。  
手机可以视作是谷歌进军芯片领域的一个突破口。谷歌拥有自己的手机品牌，同时，在手机厂商都在积极进行自研手机芯片的趋势下，谷歌走向这条路也不无道理，更何况他们还招揽以及收购了这方面的人才和企业。  
但从谷歌发布的产品来看，他们从自研手机芯片的突破口不是手机处理器芯片，而是手机协处理器。  
在2017年谷歌推出的Pixel 2上，他们也推出了其第一颗自研手机芯片PIxel Visual Core，这是一颗尚未激活的图像处理和机器学习协处理器。该芯片初现在谷歌两代PIxel系列手机当中，直到Pixel 4，该芯片才被Pixel Neural Core取代。  
在谷歌力图自研手机芯片的这几年，业界对其何时推出手机处理器芯片也产生了期待。这种期待也终于在今年开花结果了。根据SlashGear报道称，谷歌的自研SoC芯片将会在今年晚些时候出现在谷歌Pixel 6智能手机和另外一台设备上。据消息人士透露，谷歌自研的SoC代号为Whitechapel，由三星代工，采用最新的5nm制程工艺，拥有8颗核心。  
除此之外，谷歌还在在2017年的Google Cloud Next 大会上，谷歌发布了一款名为Titan的安全芯片。其中，Titan M是谷歌专门为智能手机安全而打造的一款芯片，这颗芯片随后也被用在了Pixel 3/XL上。  
智能手机作为现代实现交互功能的核心产品，其安全性越来越受到重视，为了推广智能手机安全元件（Secure Element / SE），谷歌在今年联合一众安全元件的厂商组成联盟 Android Ready SE Alliance，其目的就是加速这元件广泛应用到 Android 设备内的进程，同时也会开发开源套件和预制的applet。如果他们的这种做法成为了业界的共识，那么，谷歌在手机领域的影响力或能得到进一步的提升。  
但从对Titan的定位上看，该芯片旨在用于 Google Cloud Platform（GCP）服务器上的产品，目的是保证其顾客代码和数据的安全性，可以防止窃听硬件和插入固件植入来攻击电脑。这也就是说，Titan系列芯片不仅仅可以用于手机。  
另外，从谷歌首席执行官桑达尔·皮查伊（Sundar Pichai）去年发表声明显示，公司将在硬件方面投入大量资金，并为2021年制定完善的路线图。这引发了一系列猜测，按照技术专家预测，谷歌将涉足SoC领域，并不断发展自己的芯片，用于未来的Pixel和Chromebook。  
结合谷歌发布的产品来看，他们从手机芯片拓展到PC芯片的自研也是很有可能的。一方面是，他们的相关芯片已经在手机上取得了一定的市场认可；另一方面，有了苹果M1芯片的例子，或许能够鼓励他们在成功试水手机SoC后，还会以Arm架构为基础向PC等领域做拓展。  
除此之外，谷歌还在针对视频芯片和汽车芯片进行了布局。  
根据今年4月的报道显示，为了保证YouTube的观看体验，谷歌还开发了一款名为Argos的自定义芯片，该芯片旨在保证YouTube能够给用户提供最佳的视频质量。  
而谷歌在汽车领域的布局则主要是由其旗下 Waymo 的来完成的，根据韩媒报道称，三星电子最近拿到了谷歌母公司Alphabet自动驾驶部门Waymo的一个项目，该项目将为下一代自动驾驶汽车研发芯片。

**从边到云，谷歌一直在布局**

  

在手机、PC和汽车上进行布局是谷歌在终端产品上的新尝试，那么他在云端领域上的发展则早就引起了业界的注意。  
当年AlphaGo打赢了多名顶级围棋选手后，新一代的人工智能浪潮就受到了业界的关注。根据相关报道称，AlphaGo背后的神秘力量正是谷歌的TPU芯片。  
TPU是谷歌在2015年推出的神经网络专用芯片，为优化自身的TensorFlow机器学习框架而打造，与GPU不同，谷歌TPU是一种ASIC芯片方案，是一种专门定制的芯片。时至今日，谷歌的TPU已经迭代到了第四代。根据谷歌方便透露的消息显示，其第四代TPU的平均性能比其第三代TPU高出2.7倍。  
凭借TPU芯片的出色性能表现，也使得谷歌也成为了专用AI芯片的代表玩家。而他所推出的这种新架构，也为新一代的人工智能浪潮带来了新的启发。  
值得注意的是，谷歌还欲将其TPU应用在EDA领域。根据谷歌发布的《芯片布局与深度强化学习》论文中显示，他们公布了一种基于机器学习的芯片设计方法，声称可以将设计流程缩减到6个小时，而常规的芯片设计往往需要数周甚至更久。相关报道称，利用云上资源，进行芯片验证，还可以大大加速芯片开发的时间。  
而芯片设计上云，也正是目前半导体产业继续向前发展的趋势之一。就这一点上来看，虽然谷歌在芯片领域的起步不算早，但他似乎又跑在了前面。  
不仅如此，谷歌还将其TPU芯片逐渐带入到了边缘端。为此，他们在2018年推出了Google Edge TPU。根据谷歌云官网介绍显示，Edge TPU 是对Cloud TPU和Google Cloud服务的补充，提供端到端、云端到边缘、“硬件 + 软件”的基础架构，可协助客户部署基于 AI 的解决方案。  
从云端，到边缘端和手机智能终端，谷歌围绕着AI芯片的布局越来越广。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**开源：谷歌骨子里面的浪漫**

  

我们都知道，谷歌通过安卓开源取得了非常巨大的成功。在他们向芯片领域做拓展的过程中，他们也试图用开源的方式，来进入到这个行业的发展中。  
去年，谷歌的软件工程师Tim Ansell宣布了同SkyWater合作的第一个可制造的、开源的PDK——SkyWater PDK。根据相关报道称，被选中的企业无需承担昂贵的制造费用，谷歌将为其提供完全免费的芯片制造流程。  
据了解，这是同类产品中的第一个开放源代码处理工具，使用此PDK，可以在130nm节点的SkyWater晶圆厂生产芯片。  
2021年，谷歌资助的这个项目也得到了落地。根据公开消息显示，SkyWater Technology和Efabless宣布由Google赞助的开源多项目晶圆（MPW）shuttles的首个流片，该shuttles由Efabless管理，由SkyWater制造。  
如果开源PDK的模式取得了成功，这会降低企业进入半导体行业的门槛。  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**结语**

  
从谷歌目前在芯片行业的布局上看，他们不仅试图在现有的看得见的赛道（包括手机、汽车等领域）上进行竞争，还在向“看不见”的更上游的芯片设计方面发展（包括他们在Cloud EDA、PDK等方面的动作）。  
  
在看得见的领域上，谷歌所涉及的方向都正在经历行业重塑，而他们有机会从新的竞争当中赢得进入到芯片市场的机会。而在看不见的领域当中，无论是PDK开源项目还是芯片设计上云，如果这些新的模式被业界所接受，那么，谷歌将注定在芯片行业的发展史中留下浓墨重彩的一笔。
