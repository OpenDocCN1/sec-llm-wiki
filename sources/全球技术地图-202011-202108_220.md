# 美国最高情报智库预测未来20年全球大趋势

**美国国家情报委员会（NIC）2021年4月8号发布其“全球趋势”报告——《全球趋势2040：更激烈竞争的世界》（Global Trends 2040：A More Contested World），评估未来20年可能塑造全球安全环境、发展趋势和未来世界形态的力量以及未来世界的各种可能情景。**

  

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**《全球趋势》的启动与进程**

  

**1、《全球趋势》报告的启动**

  

1996年美国国家情报委员会（NIC）和国家战略研究所（INSS）在国防大学举行了一系列会议，以确定全球主要趋势及其对全球主要区域和国家的影响。这项工作旨在展望和评估2010年全球地缘政治演变的主要特点与趋势，并于1997年11月发布了其第一份研究报告——《全球趋势2010》（Global Trends 2010》。

  

此后，NIC开启了其四年一次的“全球大趋势”评估与分析，在充分咨询美国和世界各国广泛专家意见的基础上，评估影响未来20年全球战略安全环境的主要趋势和不确定性，为美国政府的战略决策服务。该报告作为对全球战略安全环境的非机密评估，向新一届美国总统和政府提供全球发展趋势的情景评估与预测，该报告也帮助决策者和公民预测和准备一系列可能的未来世界大趋势。

  

**2、《全球趋势》的历年度报告**

  

1997年11月，《全球趋势2010》（Global Trends 2010》。

2000年12月，《全球趋势2015：与非政府专家对话未来》（Global Trends 2015：A Dialogue About the Future With Nongovernment Experts）。

2004年12月，《全球趋势2020：描绘全球未来》（Global Trends 2020：Mapping the Globle Future）。      

2008年11月，《全球趋势2025：转型的世界》（Global Trends 2025：A Transformed World）。

2012年12月，《全球趋势2030：另类的世界》（Global Trends 2030：Alternative Worlds）。

2017年1月，《全球趋势：进步的悖论》（Global Trends：Paradox of Progress）。

2021年3月，《全球趋势2040：更激烈竞争的世界》（Global Trends 2040：A More Contested World）。

  

其中，2017年的报告《全球趋势：进步的悖论》的标题中没有“2035”的年份，原因是NIC认为这样做会在精确度方面传达错误的信息，因为对于“长期”的审视需跨越未来几十年。

**《全球趋势》的定位与意义**

  

NIC自1979年成立以来，一直是情报界和政策界之间的桥梁，在情报问题上拥有深厚的实质性专门知识的来源，也是美国情报界（IC）合作和外联的促进者。国家情报总监担任美国情报界负责人，监督和指导国家情报计划的实施，并担任总统、国家安全委员会和国土安全委员会与国家安全有关的情报事项的主要顾问。

  

国家情报委员会（NIC）每四年便会对未来20年将塑造目前世界的力量和选择的方向进行重要评估，发布非机密评估的《全球趋势》报告。《全球趋势》报告主要围绕影响世界趋势的多种因素的变化开展评估，如：权力性质的变化，宗教信仰的变化，能源问题的改变，未来战略力量的变化等。然后，探讨和评估这些变化将如何加剧人与人之间、社会之间、国家内部和国家间的各种问题，以及一些棘手的跨国问题。

  

《全球趋势》报告，以广泛参与的方式，与世界各地的外部专家（包括学术界、智库和企业界的专家）合作和开展建设性对话，征求外部专家对未来世界情景的看法，将其研究与最新的理论和数据相结合，思考未来世界所面临各种挑战和可能情景。

  

《全球趋势》旨在为政府决策者制定国家安全战略和应对不确定的未来提供一个分析框架。其的目标不是对未来的世界做出具体的预测。相反，其目的是帮助决策者和公民了解未来可能发生的情况，并为一系列可能的未来做准备。特别是报告能够为美国政府中不断发展的战略对话做出贡献，以有助于国家应对未来的挑战和机遇。

  

《全球趋势》报告只是代表了国家情报委员会对于未来的思考，并不代表美国情报界的官方和协调一致的观点，也不代表美国政策。该系列报告无疑会引起学术界对未来世界的形态问题、未来世界将如何呈现的问题的讨论、辩论以及进一步探讨。

**《全球趋势2040》主要内容观点**

  

《全球趋势2040：更激烈竞争的世界》报告，描述了贯穿报告的5个关键主题——全球挑战，碎片化，不平衡/失衡，竞争，适应。

  

报告按照三个步骤对未来世界情景进行分析。首先考察人口与人类发展、环境、经济、技术等塑造未来世界轮廓的结构性力量。其次，分析这些结构性力量和其他因素（包括人类的响应）是如何结合在一起而影响社会、国家和国际体系，形成了在这三个层面正在出现的趋势动态。第三，设想和分析了2040年未来世界的5种可能情景。报告论述的5个关键主题出现在这些部分的论述中。

  

**1、《全球趋势2040》的5个关键主题**

  

以下5个关键主题——全球挑战、碎片化、不平衡/失衡、竞争、适应——贯穿本报告，构成报告的基础。

  

**（1）全球挑战（global challenges）**：全球人类共同面临的挑战，包括气候变化与环境退化、新冠肺炎疫情大流行、金融危机和技术中断等，可能会在几乎每个地区和国家更加频繁和强烈地呈现出来。这些挑战往往缺乏直接的人为因素或行为人，会对国家和社会造成广泛的压力，并带来灾难性的冲击。

  

**（2）碎片化（fragmentation）**：由于国际体系、国家、社区等不同层级的组织体系内部日益分裂等各种原因，应对这些跨国挑战的困难更加复杂。人类社会的自相矛盾的现实是，随着世界通过通信技术、贸易和人口流动变得越来越紧密，这种联系反而已经分裂、成为分裂的、碎片化的人民和国家。物联网在2018年覆盖了100亿台设备，预计到2025年将达到640亿台，到2040年可能会达到数万亿台，所有这些都是实时监控的。反过来，这种连接将有助于产生新的效率、便利和生活水平的提高。然而，它也将在各个层面造成和加剧紧张局势。本身存在核心价值观和目标分野的社会，随着这些联系的加深和传播，它们可能会随着国家、文化或政治偏好而变得越来越支离破碎。

  

**（3）不平衡/失衡（disequilibrium）**：跨越国界的全球性挑战的规模和碎片化的潜在影响，正在超过现有系统和结构的能力，从而突出了第三个主题——不平衡或失衡。在各个层次上，挑战和需求与系统和组织之间的不匹配或失衡越来越大。包括组织、联盟、规则和规范在内的国际体系。

  

**（4）竞争（contestation）**：更大的不平衡/失衡的一个关键后果是国际社会、国家、社区等各层级尺度上更广泛的日益紧张、分裂和竞争竞争。许多社会在身份归属上的分歧越来越大，面临更大的分裂风险。随着各国努力满足民众日益增长的需求，社会和政府之间的关系将持续紧张。结果，各国内部的政治可能会变得更加动荡和充满争议，任何地区、意识形态或治理体系似乎都无法幸免，也无法找到答案。

  

**（5）适应（adaptation）**：最后，适应将成为这个世界上所有行动者的一个必要条件，也是一个关键的优势来源。例如，气候变化将迫使几乎所有国家和社会适应一个更温暖的地球。一些措施既便宜又简单，如恢复红树林或增加雨水储存；另一些措施则复杂，如建造巨大的海堤和规划大量人口的迁移。最有效的国家可能是那些能够建立社会共识和对集体适应行动的信任，并利用非国家行为者的相关专门知识、能力和关系来补充国家能力的国家。

  

**2、塑造全球趋势的4大结构性力量**

  

4大核心领域的结构性力量——人口及人类发展、环境、经济和技术，这4大结构性力量的发展趋势，奠定未来世界的基础、建构未来世界发展的边界。在某种程度上，这些趋势正变得越来越强烈，例如气候变化、人口集中在城市地区，以及新技术的出现。其他领域的趋势则更加不确定，人类发展的成果和经济增长可能会放缓，甚至可能在某些领域逆转，多种因素混合在一起可能会改变发展轨迹。这些趋势的会聚将为创新提供机会，但也将使一些国家和社会难以应对和适应。

  

**（1）人口与人类发展。**随着全球人口增长放缓和世界人口结构迅速老龄化，未来20年最确定的发展趋势将是全球人口结构的重大变化。全球人口增长放缓和年龄中位数上升将有助于一些发展中经济体，但人口迅速老龄化和萎缩将给许多发达经济体带来压力。包括欧洲和东亚在内的一些发达国家和新兴经济体，人口老龄化速度将加快，将面临人口规模的收缩，从而对经济增长构成压力。相比之下，拉丁美洲、南亚、中东和北非的一些发展中国家将受益于更多的劳动年龄人口，如果再加上基础设施和劳动技能的改善，就有机会获得人口红利。

包括卫生、教育和家庭繁荣等人类发展，在过去几十年里在每个地区都取得了历史性的进步。许多国家将努力在这些成功的基础上再接再厉，甚至保持下去。过去的发展进步主要集中在卫生、教育和减贫的基础上，但下一步的发展将更为困难，因为面临着来自新冠肺炎疫情大流行、全球经济增长可能放缓、人口老龄化以及冲突和气候影响等不利因素。这些因素将对寻求提供教育和基础设施以提高21世纪经济中不断增长的城市中产阶级生产力的政府构成挑战。随着一些国家奋起应对这些挑战，而另一些国家却未能如愿，全球人口趋势的变化几乎肯定会加剧未来20年国家内部和国家之间在经济机会方面的明显差距，并将对人口迁移造成更大的压力和争端。

**（2）环境。**在环境方面，气候变化的物理影响在未来20年内可能会加剧，特别是在21世纪30年代。全球气温的上升将导致更多的极端风暴、干旱和洪水，冰川和冰盖融化，以及海平面上升等。这种严重的环境影响将不成比例地落在发展中国家和较贫穷的地区，并与环境退化相互交织，造成新的脆弱性，加剧这些国家和地区在经济繁荣、粮食、水、健康和能源安全等方面的存在的现有风险。政府、社会和私营部门可能会扩大适应和恢复措施以管理现有的环境威胁，但这些措施不太可能平均地分配和实施，从而留下一些人口得不到保护。未来有关如何以及以多快的速度实现温室气体净零排放的争论将会越来越多。

**（3）经济。**一些全球性经济趋势（包括不断上升的国债、更加复杂和支离破碎的贸易环境、贸易的转移，以及新的就业中断等）在未来20年都可能在国家内部和国家之间塑造新的经济发展环境条件。许多国家的政府可能会发现，随着债务负担加重、贸易规则多样化，以及一系列强大的国家和企业行为者施加影响，它们的灵活性有所降低。大型平台公司——为大量买家和卖家提供在线市场——可以推动贸易的持续全球化，帮助较小的公司成长并进入国际市场。

这些强大的公司可能试图在政治和社会领域施加其影响，这可能会导致国家政府对这类公司施加新的限制措施。尽管经济增长可能会放缓，亚洲经济体似乎准备好了至少在2030年前继续保持数十年的增长，但它们不太可能达到现有发达经济体（包括美国和欧洲）的人均国内生产总值（GDP）或经济影响力水平。生产率增长仍然是一个关键变量，增长率的提高可以缓解许多经济、人类发展和其他挑战。

**（4）技术。**技术将提供缓解人类面临的各种问题（如气候变化和疾病）的潜力，并催生出新的意想不到的挑战来（如工作岗位的转移）。技术在世界各地以越来越快的速度被发明、使用、传播，然后被丢弃，新的创新中心正在出现。在未来20年中技术发展的速度和范围可能会越来越快，将会改变人类的一系列经验和能力，同时也会在社会、行业和国家内部和之间造成新的紧张和破坏。国家和非国家的竞争对手将争夺科学技术领域的领导权和主导权，这可能会给经济、军事和社会安全带来连锁风险和影响。

**3、未来世界的5种可能情景**

  

《全球趋势2040》基于推断的各种重要的或者关键的不确定性将如何导致不同的结局，设计了2040年世界的5种可能未来情景。每种可能情景都反映了共同的全球挑战、碎片化、不平衡、适应和更大竞争等关键主题。

  

（1）“民主复兴”情景（Renaissance of Democracies）：世界处于由美国及其盟国领导的开放民主国家的复兴之中。在美国和其他民主社会，公私伙伴关系促进迅速的技术进步，改变全球经济，提高收入，改善全球人口的生活质量。不断上升的经济增长和技术成就使人们能够应对全球挑战，缓和社会分歧，并恢复公众对民主体制的信任。美国和欧洲为促进创新，将以民主为诱饵不断强化对中俄等国主要科学家和企业家的争夺。

  

（2）“漂泊世界”情景（A World Adrift）：在这样情景的世界里，国际体系是无方向、混乱和动荡的，因为国际规则和制度在很大程度上被有关大国、地区参与者和非国家行为者等所忽视。

  

（3）“竞争共存”情景（Competitive Coexistence）：美国和中国都将经济增长放在优先战略位置，并恢复了强劲的双边贸易关系，但这种经济相互依存关系在政治影响力、治理模式、技术优势和战略优势方面存在着长期竞争。爆发大的战争的风险很低，国际合作和技术创新使发达经济体能够在短期内控制全球问题，但长期的气候挑战仍然存在。

  

（4）“分割孤岛”情景（Separate Silos）：以美国、中国、欧盟（EU）、俄罗斯和几个地区大国为中心，世界被分割成几个不同规模和实力的经济和安全的国家集团。这些国家集团专注于自给自足、韧性和国防。信息在独立的网络主权飞地内流动，供应链被重新定位，国际贸易中断。脆弱的发展中国家被夹在这些国家集团中间，有些国家将成为失败的国家。全球问题尤其是气候变化问题，无法得到有效的解决。

  

（5）“悲剧与动员”情景（Tragedy and Mobilization）：欧盟和中国与非政府组织及多边振兴机构合作领导的一个全球联盟，实施意义深远的变革，旨在应对气候变化、资源枯竭和贫困问题，以及由气候事件和环境退化造成的全球粮食灾难。认识到这些全球挑战跨越国界快速扩展，富裕国家转向帮助贫穷国家应对危机，通过广泛的援助计划和先进能源技术的转让，促进向低碳经济转型。

  

上述前3种情景描绘的未来世界中，国际挑战将变得越来越严峻，而相互作用在很大程度上取决于中美之间的竞争。后2种情景则描绘了更为根本的变化，两者都源于特别严重的全球不连续性，并且都违背了关于全球系统的假设。在后2种情景下，中美竞争并不那么重要，因为这两个国家都被迫应对更大、更严峻的全球挑战，并发现当前的结构无法应对这些挑战。
