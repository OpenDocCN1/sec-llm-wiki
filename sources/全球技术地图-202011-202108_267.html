科技战略


Gartner公司发布“2021年政府应关注的10大业务趋势”

据Gartner 3月25日消息，Gartner公司发布文章预测“2021年政府应关注的10大业务趋势”，以协助政府在后疫情时代做出有利于社会政策目标的技术投资决策。文章指出，疫情引发了数字政务的变革，政策与技术融合所带来的数字领导力将是未来政府的基本业务趋势。此外，2021年政府应关注的10大业务趋势还包括3个具体层面，一是增强信任，包括解决技术引发的道德和隐私问题、保护数字平等、通过立法和建立标准约束人工智能等技术等；二是增强敏捷性，包括增加制度和机构的响应能力、增加采购灵活性和速度、增强公民体验管理等；三是增强韧性，包括更新优化公务员队伍、培育分布式政府工作队伍、捍卫数字主权等。


加拿大发布《投资国家安全审查指南》，重点审查涉及31种关键矿产和15个敏感技术领域的投资

据机工情报3月25日消息，加拿大发布《投资国家安全审查指南》，明确提出就涉及关键矿产控制权、敏感个人数据业务及国有成分和政府性质的交易和投资，启动国家安全审查。报告称，此类投资对加拿大的国防能力、关键矿物供应链、基础设施有潜在影响，可能引发外国间谍活动和敏感数据泄露。31种需要进行国家安全审查的战略性关键矿产包括铝、锑、铋、铯、铬、钴、铜、萤石、镓、锗、石墨、氦、铟、锂、镁、锰、钼、镍、铌、铂族金属、钾肥、稀土元素、钪、钽、碲、锡、钛、钨、铀、钒、锌。15个需要进行国家安全审查的敏感技术领域包括先进材料与制造、先进海洋技术、先进传感与监控、先进武器、航天、人工智能、生物技术、能源生产存储和传输、医疗技术、神经技术与人机融合、下一代计算和数字基础架构，位置导航和定时、量子科学、机器人与自治系统、航空技术。


信息


韩国新加密法规或将形成由大型加密公司主导的垄断市场

据TechWeb网3月24日消息，韩国《关于特定金融交易信息的报告与利用等法律》（特别金融法）生效在即，要求所有加密货币企业遵守新的加密报告法规和注册规则。该法规将引领韩国加密产业进入新的发展阶段，但却引发业界担忧。韩国先驱报的一篇文章指出，业内专家担心，《特别金融法》中的新措施将对大多数国内加密货币公司产生破坏性影响。该法案要求所有虚拟资产运营商正式注册，为此他们必须出示证据证明其在韩国银行使用实名账户进行运营。尽管这是为了防止洗钱等金融犯罪，但绝大多数规模较小的加密公司尚无法与当地金融机构建立合作关系。新法规未能区分不同类型和规模的加密公司，可能会导致小型公司难以获得运营资质，从而形成由大型加密公司主导的垄断市场。

 

以色列约650万选民信息在网络上泄露

据cnBeta网3月25日消息，以色列大量公民的个人信息在网络上泄露，其中包括650万以色列选民的详细登记信息以及约318万公民的个人详细资料，而以色列全国总人口约930万。泄露的信息包括个人全名、电话号码、身份证号码、家庭住址、性别、年龄和政治倾向等细节。目前，数据泄露源头已被锁定为网络开发公司Elector，而一名自称为“The Israeli Autumn”的威胁分子称对此事负责。目前，泄露的数据库已被修复，但相关数据包仍在网上传播。


生物


人类基因组编写计划将发布基于CAD的全新基因编辑软件，通过基因编辑和设计创造出全新生命

据学术头条公众号3月23日消息，全球权威组织“人类基因组编写计划（GP-write）”宣布即将发布一款基于计算机辅助设计（CAD）的全新基因编辑软件，使大规模的基因组编辑和设计变得更容易，从而创造出全新的生命或能力。新型基因编辑CAD软件的开发，有利于促进计算机科学和生物学的融合，有助于更好的进行生物研究，使科学家不再局限于对单个碱基进行修改，而是直接通过该软件在生物体内加上任意功能。CAD辅助基因编辑将推动人类基因编辑技术的发展，但其危害性无法预测，因此应制定相关国家法规，并在使用和推广中多加谨慎。据悉，该软件将于今年年底问世。

 

美军生化专家警示合成生物学引发的生物武器威胁

据国防科技要闻3月25日消息，美国西点军校生化专家威克塞斯就其发表的论文《工程病原体和非自然生物武器：合成生物学的未来威胁》接受采访，认为DNA重组、基因编辑等合成生物学技术的快速发展与扩散，降低了修改病原体、制造工程生物武器的门槛，正导致一场可与原子弹发展相匹敌、影响威胁态势的科学革命，利用工程病原体制造生物武器造成的不对称威胁持续增大，军事规划者和研究界应高度重视并重新评估合成生物学发展带来的生物武器威胁，并开发必要技术来防范合成生物体的武器化使用。


能源


美国防部选择两种移动式微堆概念进行最终设计

据byteclicks网3月23日消息，美国防部战略能力办公室（SCO）在“贝利项目”（Project Pele）中已选择两个团队开展移动式微型反应堆的最终设计工作。这两个团队之一由位于美国弗吉尼亚州林奇堡的BWX技术公司（BWX Technologies Inc.）牵头，另一个由位于马里兰州格林贝尔特的探索能源有限公司（X-energy，LLC）牵头。按计划，战略能力办公室将在2022年年初对最终设计进行审查，并根据《国家环境政策法案》进行环境分析，之后可能选择两家团队之一建造并演示原型。据悉，该反应堆原型将设计为在满功率运行至少三年的情况下提供1～5兆瓦的电力。为实现持续快速运输和使用，该原型将被设计为可在交付后3天内投入运行，并在7天内安全地移除。


NASA宣布在月球上建立大规模太阳能电池阵列

据byteclicks网3月24日消息，NASA正在雇用商业公司开发可从月球表面弹起的可垂直部署的太阳能电池阵列系统。NASA选择了包括洛克希德-马丁公司、ATK太空系统公司（诺斯鲁普-格鲁曼公司）、Honeybee机器人公司、太空系统Loral公司（Maxar技术公司）和Astrobotic技术公司共五家公司，在12个月内设计一种能够自主部署到32英尺(9.7米)的高度并可自主收回的太阳能电池阵列系统。该系统还需要适应月球陡峭的地形、月球的尘埃，并需要保持较小的体积和质量。


海洋


芬兰瓦锡兰公司研究船舶碳捕集与封存技术

据广海局3月24日消息，芬兰瓦锡兰技术公司近日表示，船舶碳捕集与封存（CCS）技术发展潜力巨大，可减少航行中二氧化碳的排放量，在脱碳方面发挥着关键作用，对减少现有船舶碳排放尤其重要。目前该公司已经开展研发工作，探索如何在海事活动中开发和推行CCS，现正在挪威莫斯建设试验工厂，用来测试CCS技术。该公司的初步研究表明，船舶CCS在技术上是可行的。

 

挪威海洋研究所利用无人水面艇和水下航行器进行海洋生态系统监测

据广海局3月24日消息，挪威海洋技术装备生产商Kongsberg Maritime公司将为挪威海洋研究所（IMR）提供两台USV（无人水面航行器）和两台AUV（自动水下航行器），AUV计划于今年交付，而USV则在2022年中交付。USV将配备完整的EK80宽带系统，具备声学多普勒流速剖面仪功能。AUV的额定工作深度为1500m，配备强大的有效载荷，可用于环境监测和海底地形测量。两种设备都将配备该公司新研发的Blue Insight系统，这是一种基于云的系统，可远程遥控仪器操作，实现数据可视化以及水文和气象数据的智能化管理。


航空


美国洛马公司推出无人机载高功率微波系统

据空天防务观察3月25日消息，美国洛马公司开发出“莫菲斯”（MORFIUS）反无人机解决方案，通过无人机载高功率微波系统应对无人机威胁。据悉，该无人机封装在直径6英寸（约合15厘米）的发射管中，可空射也可陆基或海基发射，具备重复使用能力。该无人机全重不超过30磅（约合13.6千克），配装有导引头和辐射功率高达吉瓦级（1000兆瓦）的高功率微波武器，可用于打击无人机或无人机“蜂群”。

 

美国L3 Harris公司将为F-16战斗机开发先进电子战系统

据航空简报3月25日消息，美国L3 Harris技术公司获得洛马公司授予的合同，将为F-16战斗机开发一种新的先进电子战(EW)系统“蝰蛇盾”。该系统采用先进的数字技术，可保护F-16战斗机免受新兴的雷达和电子威胁。L3 Harris公司表示，该系统可以与F-16的武器系统无缝集成，将广泛应用于F-16 Block 70/72战斗机。

朝鲜发射两枚弹道导弹

据韩联社中文网3月25日消息，朝鲜于3月25日上午在咸镜南道咸州一带向韩半岛东部海域发射2枚近程弹道导弹。韩国联合参谋本部表示，军方捕捉到朝鲜分别于当天上午7时6分许和7时25分许在咸镜南道咸州一带向东部海域发射近程导弹。该飞行器射程约450千米，射高约60千米。据悉，这是美国拜登政府成立后朝鲜第一次发射弹道导弹。目前，韩美情报部门正在紧密分析具体规格和参数。

 

中国气象卫星在轨发生解体

据腾讯新闻3月25日消息，美国第18空间控制中队称，中国“云海一号02星”气象卫星在轨发生解体，产生21块碎片。该卫星于2019年9月发射，主要用于大气海洋环境要素探测、空间环境探测、科学实验等领域。目前，该卫星的解体原因尚未得知。

英国OneWeb公司成功发射36颗OneWeb卫星

据航小宇3月25日消息，英国OneWeb公司利用“联盟”2-1b火箭成功发射36颗OneWeb卫星。此次发射后，OneWeb星座的在轨卫星数量达146颗。该公司预计将通过与阿里安公司签约的总共19次发射合同，在2023年前完成由650颗卫星组网的初期星座部署工作。该星座旨在让地球上的所有人实现随时随地无缝上网能力，所面向的市场包括航空、海事、回程服务、社区WiFi和应急响应服务等。


新材料


日立造船开发出全球最大级别全固态锂电池

据科技部官网3月25日消息，日立造船集团利用其公司内部技术，采用独特制造方法，成功在无需机械加压的条件下完成了全固体锂离子电池的充放电。该电池容量达到1000毫安时，储电容量被认为是当前世界最大级别，其适用温度范围广，具体为摄氏零下40度到零上100度。由于能够承受高温、真空等严酷环境，所以该电池在人造卫星、工业机械、医疗器械等领域都具有广泛应用前景。


先进制造


美国康奈尔大学研发出可折叠微型机器人

据国防科技要闻3月25日消息，美国康奈尔大学的一项研究突破了微米甚至纳米尺度控制运动速度和精度的极限，研发出一种可用于构造超材料以及高灵敏度传感器的微型机器人。研究人员创造出一种微米级形状记忆执行器，包含具有振荡电压的原子尺度的二维材料，可折叠成3D结构。一旦材料弯曲，即使去除电压，材料也可保持其形状。在技术验证中，研究团队创造出了世界上最小的自折叠折纸鸟。该研究可使机器人自折叠成独特形状，通过爬行完成任务，可用于清除人体组织中的细菌感染，还可以支持智能材料设计，并促进分子生物学技术开发。该项目得到了美国陆军研究办公室、美国国家科学基金会、康奈尔大学材料研究中心、空军科研办公室以及康奈尔大学卡弗里研究所资助。
