# 夹在中美地缘政治之间的欧洲数字主权

**拜登的上任为美国及其盟国打开了新篇章，但欧洲仍被夹在中美地缘政治之间。欧洲对数字主权的追求将继续影响欧洲对中美双方的平衡战略。在保持与美国的安全联盟和与中国的经济利益关系的同时，欧洲如何继续推进其数字主权的前程？**

  

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**欧洲数字主权是什么？为什么重要？**

  

自从特朗普上任以来，“主权”就成了欧洲的时髦词。特朗普政府在过去四年持续单边主义的行为，包括对欧盟国家征收铝和钢进口关税，以及对北约安全联盟承诺的动摇，严重削弱了欧洲对美国的信任。正如德国总理默克尔所说，欧洲必须开始“把命运掌握在自己手中。”

  

从这种态度出发，数字主权的理念指向欧洲管理自己网络以及数字空间的自由，并“加强其定义自己规则的能力”。随着数字领域成为全球权力斗争的前线，欧洲认识到对美国技术惊人的依赖——西方世界92%的数据存储在美国，美国大型科技公司也在全球占据了巨大的市场份额。同时，欧洲在5G、人工智能、云计算等数字科技领域中也处于相对落后的地位。通过数字主权，欧洲不仅希望避开美国对其数字领域的干扰，同时也希望在全球提倡基于欧洲价值观的数字治理体系。

  

然而，中美关系的局势使欧洲数字主权的追求陷入地缘政治的交火。在追求数字主权的道路上，欧洲必须平衡其战略与中美两国的关系，而这也可能在三方地缘政治中制造更多的冲突。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**欧美统一战线下的欧洲数字主权**

  

2020年12月，在拜登获胜之后，欧盟委员会提出了《全球变化下的新美欧关系日程》（A New EU-US Agenda for Global Change）（以下简称“日程”）的提案。该日程表明了双方对继续开展跨大西洋合作浓厚的兴趣。并且，欧盟委员会主席乌苏拉·冯·德莱恩（Ursula von der Leyen）表示： “当跨大西洋伙伴关系强大时，欧盟和美国都会更加强大。”

  

在技术合作领域，该日程提出了建立欧美国贸易和技术理事会的建议，以制定一致的科技标准。此外，该日程还表达了欧洲对合作开发5G和人工智能以及继续促进数据自由流动的态度。为了进一步促进多边主义，欧盟委员会希望在2021年上半年举行一次欧美峰会，以加强联盟并制定未来规划。

  

欧盟委员会提出与美国在数字技术标准、数字监管、全球数字价值链等方面统一战线的行为并非违背了数字主权的原则。欧洲数字主权的一个关键部分是“塑造全球规则和标准”的能力。欧洲成为数字治理领域全球领导者的前提是欧洲能够将多边主义与主权理念结合，确保主权不会演变为保护主义。美国与欧洲仍然共享着许多相似的价值观，比如对民主制度的信念。因此，通过跨大西洋的科技合作日程，欧洲可以更好地促进构成数字主权核心的价值观，例如个人隐私、网络安全、民主制度等。

  

尽管如此，欧洲并不是在数字领域完全站队美国。美国坚持让欧洲加入抵制中国科技公司的行动，例如“清洁网络计划”，但欧洲大部分国家保持着对中国对欧洲供应链的影响的认知，并未积极响应该计划。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**中欧关系背景下的欧洲数字主权**

  

一方面，中欧在数字经济领域的合作潜力得到释放。2020年底，中欧两方初步缔结了《中欧全面投资协定》（CAI）。该协定于2013年首次启动，在2020年底取得了重大突破。尽管有反对的声音认为，由于默克尔对德国企业需求的偏见，该协议草率达成，但CAI仍然是一个雄心勃勃的尝试，旨在为欧洲企业在华投资打开公平的竞争环境。此外，除了在关键行业向欧洲开放市场准入外，中国还承诺了欧洲企业在电信和云服务、计算机服务和金融服务领域投资的机会。因为中国一直限制外国对云计算和在线服务的投资，这些关键行业的开放将为欧洲科技公司提供振奋的前景，加强中欧在数字领域的合作。

  

不过，CAI尚未得到批准，已经在欧洲议会受到质疑，而且其条款可能会在未来做出改变，打破中欧利益的平衡。随着美国持续的施压，CAI面临更多不确定性。在CAI初步缔结的前几周，美国国家安全顾问杰克•沙利文（Jake Sullivan）曾公开表示希望“就中国的经济行为的共同担忧，尽早与欧洲伙伴进行磋商。”然而，欧洲推进CAI的举动似乎表明了对美国的双重态度——在寻求与美国建立一个跨大西洋联盟同时，欧洲保持了对独立经济和科技决策的决心,与其数字主权的观念相符。

  

另一方面，中国欧盟商会和墨卡托中国研究所（MERICS）的一月报告指出，中欧在数字治理领域的分歧可能会形成数字行业的脱钩。在数据治理机制上，中欧存在重大分歧，而欧洲数字主权强调对其价值体系的维护和推广。中欧数据治理的分歧可能会中断跨境数据传输，给两国企业的运营带来难题。因此，欧洲在保持与中国的经济关系的同时，为了更好的维护其数字主权的核心理念，可能寻求管控中欧数字治理的分歧。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**三方地缘政治与欧洲的博弈**

  

欧洲为实现数字主权而对中美两方采取的复杂甚至矛盾的战略，本质上源于三方之间不断升温的战略利益竞争。其中,有三个因素在欧、中、美之间产生三方的推拉，并导致了欧洲目前的地缘政治立场。

  

如上所述，欧洲认识中国与其数据治理理念的分歧可能带来的后果，可能通过与中国采取合作行动，建立可观察的规则和框架，减轻对其企业构成的威胁。第二，欧洲为了捍卫其核心原则，如数据保护、网络安全、道德和负责任的人工智能等，可能寻求在CAI中初步建立多项国际标准。第三，北约仍然是欧洲拥有的最强大的安全联盟，现实主义继续占领上风。跨大西洋联盟不仅符合欧洲长期以来的多边主义，也更是欧洲一个必要的防御安全机制。

  

目前，欧洲并没有表现出在中美集团政治（bloc politics）中选择一边的意愿。在达沃斯世界经济论坛（Davos World Economic Forum）上，默克尔公开表示与习近平主席达成协议，认为各国应该避免加入集团政治，支持多边主义。欧洲正在为数字主权的战略在中欧美关系中寻找三方的平衡点。以数字主权为导向，欧洲选择了在不损害其安全或核心价值观的情况下，可以确保其经济和科技独立的战略。
