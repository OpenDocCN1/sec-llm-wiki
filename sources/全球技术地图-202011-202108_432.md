# 美国维持量子信息科学全球领导地位的战略政策解析

**习近平总书记在主持中共中央政治局就量子科技研究和应用前景集体学习时强调，要充分认识推动量子科技发展的重要性和紧迫性，加强量子科技发展战略谋划和系统布局，把握大趋势，下好先手棋。2020年7月美国能源部（DOE）提出建立全国性量子互联网的战略蓝图，将协同全国各部门建设量子网络，以确保美国处于全球量子竞赛前列。本文通过解析美国关于促进量子信息科学发展所出台的相关法案及政策，提出了我国未来量子信息科学发展的建议。**

  

  

今年7月美国能源部（DOE）提出建立全国性量子互联网的战略蓝图，以支撑《国家量子计划法案》的顺利施行。可以看出，美国正持续以国家意志聚合国家力量，多管齐下，加速量子信息科学发展。解析美国关于促进量子信息科学发展所出台的相关法案及政策，可对我国未来量子信息科学的发展提供相关启示。

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**推动公私部门合作**

**立机制化的协调和管理平台**

  

建立并启用正式的协调机构。在美国国家科学技术委员会（NSTC）量子信息科学小组委员会（SCQIS）的协调下成立“国家量子协调办公室”，负责监督机构间的协调事务，提供战略规划支持，充当利益攸关方的中心联络点，并促进私营部门将联邦政府的研究商业化。

  

建立量子信息科学研发中心。在执行层面，美国能源部将汇集大学、国家实验室等组织在2020-2025年间建立若干个多机构联合、多学科建设、各有侧重的国家量子信息科学（QIS）研究中心，通过建立研发生态系统以激发量子计算、通信、传感等领域的发展潜力。

  

建立量子经济发展联盟。该联盟由美国国家标准与技术研究所（NIST）与非营利性的独立研发中心—SRI国际所领导，旨在有效地协调联邦、学术界和产业界伙伴之间的资源和量子研发工作。

**采取科学优先原则**

**提升量子信息科学的基础科研水平**

  

**1.在不确定性中坚持对量子信息科学的前沿探索**  
尽管量子信息科学的研发及其成果应用仍然存在很大的不确定性，美国政府坚持认为该领域发展潜力巨大，需在基础研究方面坚持探索。一是政府机构、学术界和工业界要共同努力，识别和确定有广泛经济和科学影响的基本科学或技术问题，以及能够带来科学与工业变革性进展的重大挑战，提出优先次序，评估并跟踪其进展情况。二是需要依托量子研究中心和量子联盟等研究团体以维持长期的、兴趣驱动的研究，以及对未来的需求和挑战进行预测并达成共识，协调基础研究领域的工作。三是借助专业学会、首席研究员会议、科学期刊等平台和载体，创造机会维持跨学科的量子研究人员间的对话，充分研讨和分享量子科学研究进展。  
**2.建立多方筹资模式，确保稳定、持续的资助来源**  
《概述》中提出应充分利用美国政府资助体系为量子信息科学研发提供稳定的经费支持。《法案》提出计划未来10年内向量子研究注入12亿美元资金，主要用于指导和资助基础研究和前沿科学发现。特朗普政府2021年的财政预算案中要求三个联邦机构（DOE、NSF和NIST）至少投入5亿美元用于资助量子信息科学领域的研发，包括建设“世界上第一个量子互联网”。为响应《法案》要求，2021年NSF将投入2.3亿美元（比2020年翻一番）持续资助与QIS相关的物理科学、数学、计算机科学和工程的研究，5年内还将投资2.5亿美元成立2-5个“量子研究和教育多学科中心”，用于支持量子科技人才建设等。  
此外，联邦政府还应积极撬动民间科研资源，以补充政府资助所未涉及到的研究领域或相关基础设施。例如设立高风险高回报项目鼓励科技公司、风险投资企业等增加对联合量子信息技术研究的投资，鼓励企业与大学共建量子实验室，以及鼓励私营部门对确定亟需的关键基础设施进行必要的投资。  
**3.培育多元化、专业的量子信息科学从业人员**  
为应对量子信息科学发展中将出现的问题和挑战，《概述》中提出应加强学校与政府机构、相关行业协同，培育多元化的量子信息科学从业人员。首先通过专业协会、工业联盟和地方政府等定期评估未来QIS领域从业人员的规模，以便准确地按照计划培养支撑量子生态系统发展所需的多样化从业人员。其次，支持跨部门和跨学科的基础研究以培养能掌握跨学科知识点的QIS从业人员。在基础教育方面需形成以计算机科学和物理学为代表的中小学计算和科学思想培育体系；鼓励大学将量子科学与工程作为未来的重点学科，设立新的本科课程并鼓励创建专业技术课程等。第三，采用非正式教育工具（如在博物馆进行科普）与公众建立更广泛的联系，逐步培养公众对量子信息科学的兴趣。  
**4.在全球范围内联动优势资源展开广泛的合作**  
为确保美国在全球QIS领域的领导地位和竞争力，《概述》中提出加强国内研究部署战略的同时美国也必须与国际伙伴共同合作。首先是定期审查QIS国际合作活动，确定和跟踪QIS科学和技术发展趋势，了解全球量子信息科学发展格局，并为现有计划提供信息。其次，确定战略双边伙伴关系及其优先顺序，以确保美国继续吸引并留住最优秀的国际伙伴，获得与QIS前沿技术、研究设施以及专家接触的机会。第三，鼓励建立基于绩效且透明的基础研究创新系统，酌情公开QIS研究所产生的公共数据，并推动制定能够使QIS新技术得到采用的国际标准。

**协同量子信息科学研究团体****促进量子科技产业化应用及发展**  

  

  

考虑到QIS技术对推动经济发展的促进作用，《概述》中提出政府应深入参与量子科技产业的发展。首先，应在联邦政府内培养潜在的最终应用领域，推广量子技术。通过SCQIS等政府部门推广QIS技术在国防安全和开拓新的经济增长点等方面应用，协助相关政府部门理解不断变化的QIS发展在促进产业化和经济增长方面带来的影响。同时加强技术评估，引导军事和国防应用开发的QIS技术向消费者市场过渡，通过创造出新产业和新产品带来新的经济增长潜力。

  

其次，让企业成为推动QIS产业化应用及加速发展的重要力量。协助各类企业了解量子信息科技不断变化的需求，并采用企业创新项目同政府联合研究中心协作等方法，对技术处于弱势或尚未研发的领域进行探索，助力企业积极参与量子信息科学的技术开发与产业化发展。加强量子信息科学知识产权保护，为美国产业界提供量子信息科学发展的相关信息，引导企业转化实验室原型为商业产品和服务。

**对我国未来量子信息科学发展的建议**

  
近年来我国在量子信息科学领域取得了多项具有国际影响力的重要突破性进展。未来量子信息科学的发展尚有诸多不确定性，关键的技术竞争还将持续出现，全球量子竞赛将愈发激烈，为抢占我国在世界量子信息领域的“话语权”，需加强前瞻布局和整体谋划以形成战略优势。  
  

**一是加强顶层设计，制定国家计划。**保持战略定力与科技自信，制定稳定和持续的核心发展计划，对目标明确的研究计划进行战略投资。以核心工程项目为支撑，分阶段、按步骤合理有序推进；发挥体制优势，协调各方力量筹划建设的量子信息国家实验室应尽快落地。  

  

**二是注重专业人才的培养与引进。**将量子信息教学发展列入国家量子计划中，制定长期的人才培养战略计划；完善专业学科建设，注重量子信息科学与其他学科的融合发展，培养复合型人才；为在未来拥有一支量子科学的人才大军，从早期开始部署量子科学教育；吸引全球量子通信领域领军人才来华就业、创业。  

  

**三是加快制定行业技术国际标准。**一方面需要增加在制定量子信息科学领域国际标准的力量以在规则制定上掌握更多的主导权。另一方面，围绕量子信息技术涉及的材料、器件、设备和系统等方面建立统一规范的技术标准，为加快量子信息技术在相关领域的应用铺平道路。  

  

**四是统筹科研力量、深化产业协同。**凝聚优势力量，创新运行机制，强化量子信息科学研究团队和行业之间的联系；制订支撑量子技术市场发展的产业优惠政策，培育一批配套工程企业，共同提高工程和工艺水平，形成量子信息技术领域产业核心竞争力。

**研究所简介**
