**拜登的技术和创新政策的基本理念**

  

ITIF主席和报告主要作者Robert D. Atkinson说：“根据他在竞选期间的官方立场和声明，当选总统拜登将会走一条与特朗普总统截然不同的道路。”

  

目前，拜登关于技术、创新和相关贸易政策的计划可以简单概括为:加大支出、加强监管、加强多边主义。未来，拜登领导的新政府可能会大力推动在研发、农村宽带、缩小数字鸿沟以及教育和培训等领域的公共投资。

  

然而与此同时，新一届政府将面临来自民主党内进步派在推动更高的商业税和针对技术及科技行业领域实行更广泛的和限制性监管的巨大压力，这些领域有隐私、人工智能(AI)、自动化、网络平台、宽带、反垄断、药品定价以及许多其他领域。风险在于，这些负担将超过加大对创新的公共投资带来的好处。

  

对一系列重要科技和创新国际议题，包括如何处理与中国的竞争、网络治理、跨境数据流动，与特朗普政府相比拜登政府可能会更多寻求与国际机构接触并与美国盟友密切合作。但是，在应对中国的创新重商主义方面可能不那么强硬。在移民问题上，拜登政府可能会支持增加高技能和低技能移民，但也会限制H-1B移民。

  

总体而言，拜登的技术和创新政策可能会把重点放在让政府作为一个更积极的合作伙伴和产业界一起来促进创新，同时也作为一个更严格的技术产业和技术的监管者。此外，拜登可能会把创新政策的重点放在实现社会目标上，而不是提高竞争力、生产力和国家安全上。他的首要任务可能包括应对气候变化、振兴经济困难的社区和地区，以及为弱势群体，特别是少数族裔提供经济机会。

  

总的来说，拜登在竞选期间的官方立场和声明的公开记录传达了其基本理念，很可能会指导他的政府的技术和创新政策：

  

*   在政策方向上可能让政府成为产业界的积极合作伙伴，支持研发和国内生产，并对许多技术行业和技术领域(如数据隐私)进行更严格的监管。
    
*   新政府可能会扩大诸如少数族裔机会、地区增长和气候解决方案方面的投资以实现社会目标，同时可能削减其他领域尤其是国防支出的投资。
    
*   强调支持大幅增加在研发和先进生产方面的公共投资。
    
*   支持大幅增加清洁能源研发资金。
    
*   提议大幅增加教育和技能方面的公共投资。
    
*   对“华盛顿共识”中的贸易原则提出质疑，并专注于对中国采取强硬态度，但他支持多边方式。
    
*   支持民主党在移民问题上的传统立场，即支持增加高技能和低技能移民，但限制H-1B签证。
    
*   支持加大对农村宽带基础设施的联邦投资，缩小数字鸿沟。
    
*   支持对企业，尤其是大公司，征收更高的税。
    
*   支持加强监管，包括对隐私和宽带提供商的监管，特别是对大型互联网公司更积极的反垄断执法。
    
*   支持加大对230条款保护的限制。

## **教育与技能**

  

| **议题** || **立场** |
| --- | --- |
| 高技术外籍工人移民 || 将与国会一道改革现有临时签证政策，建立一个基于工资的分配过程与执行机制，保障他们和劳动力市场保持一致，并且不会被用来削减工资。将增加高级技能签证的数量，消除国家对工作签证的限制，清理长期形成的积压。 |
| 对科学、技术、工程和数学（STEM）教育的扶持 || 将增加初中和高中开设计算机科学课程的机会。将投资50亿美元到教学和医疗的研究生课程中，并在主要研究机构中建立实习和职业生涯通道，主要集中在服务少数族裔的机构。 |
| 扶持教育创新 || 将投资于学校职业培训和高中、社区大学、雇主之间的合作伙伴关系，来设立那些有助于学生在高中毕业取得产业证书的项目。将增加初中和高中开设计算机科学课程的机会。将投资20亿美元到传统黑人大学（HBCUs）和服务少数族裔的机构中，用于建立高科技实验室、设施以及数字基础设施。 |
| 扶持少数族裔和低收入学生 || 将Title I资助增至三倍，资助有较高比例低收入学生学校的联邦项目，并要求各区使用基金提供给教育工作者更高薪酬，支付幼儿园，在自主使用基金之前须提供严格课程作业的机会。将设立一个新项目挑战当地社区，以保证高中学校符合变化的劳动力需求，首先优先处理在低收入和少数族裔社区设立学校。将让公立大专和大学对所有收入低于12.5万美元的家庭免收学费。将佩尔助学金（Pell grants）的最高值翻倍。通过改革基于收入的分期偿还项目，将超过半数款项用于本科生联邦学生贷款。将投资超过700亿美元到传统黑人大学和服务少数族裔的机构，使他们更加资金充足、装备良好、富有创新力。 |
| 社区大学 || 将提供无贷款的两年社区大学或者其他高质量培训项目，由联邦政府承担75%的费用，州政府贡献其余费用。将设立一个新的助学项目支持社区大学，增加其学生保有率和证书取得率，增加成功项目规模来帮助更多的学生。将给予州财政激励，促进社区大学和社区组织之间的协作，为学生提供帮扶何服务。将设立一个联邦助学金项目，帮助社区大学设立紧急状况助学金，帮助那些因财务状况出现意外而不能继续就读的学生。将投资500亿美元用于劳动力培训，包括社区大学与企业合作以及学徒。将投资80亿美元来帮助社区大学改善设施使其状况良好和安全。 |

  

## **税收**

  

| **议题** || **立场** |
| --- | --- |
| 企业税率 || 将提高企业税率至28%。将针对由国外货物和服务进口回美国而取得的利润提高10%税率。将针对账面收入（book income）实施一项15%的税收来保证所有企业至少支付一些税收。 |
| 离岸外包处罚 || 杜绝那些将产品转移到海外的抵扣和费用注销等在美国做起来“看似有理”的行为。 |
| 美国制造免税优惠 || 向更新旧工厂、扩大生产设备、将工作岗位转移到美国、或者提高制造工资等活动提供一项10%的免税额度。 |
| 制造业免税优惠 || 3年提供60亿美元给那些投资于经历大规模裁员或者关闭主要政府机构的社区的企业。 |
| 研发免税优惠 || 没有表态，但不太可能支持增加。 |
| 加速折旧研究 || 没有表态,但不太可能支持废除拨款终止研究开支。 |
| 税基侵蚀和利润转移行为 || 将对抗全球税收保密与避税，收紧支付反倒置法规的同时，对付那些将利润隐藏在避税天堂来逃避其应付税收的个人和企业。 |
| 数字服务税收（DSTs） || 没有表态。 |
| 外国公司所得税 || 将把最低税率从10.5%提高到21%。该税收将分国实施。 |
| 医药广告 || 将否决广告费用抵扣。 |
| 税收支出 || 减少用于化石燃料生产与商业地产的税收支出。 |
| 创新箱/盒 || 没有表态。 |
| 资本利得税率 || 家庭收入在1百万美元及以上，长期资本利得和合格股息按照普通所得税率应税。短期利得的税务处理保持不变。 |
| 个人税率 || 收入超过40万美元的家庭，税率从37%增加至39.6%。限制税级高于28%的应税者的分项抵扣价值。 |
| 附带权益 || 先前声明过他将废除。 |
| 税赋转嫁企业20%减免 || 将废除。 |
| 社会保障金 || 工资超过40万美元，工资税从0%提高到12.4%。 |

## **贸易**

  

| **议题** || **立场** |
| --- | --- |
| 总体立场 || 与盟友协作建设新贸易协议，将纳入更加严格的原创和气候变化承诺等规则。主要国内投资的优先顺序排在新贸易协议之前。 |
| 跨太平洋伙伴关系 || 如果美国能够重新谈判部分协议，可以重新加入，协议可能包括汇率操纵、劳工和环境标准和ISDS规定。 |
| WTO || 没有提及，不过总体上有利于同WTO伙伴的合作。 |
| 贸易执法 || 致力于建立详尽策略来“激进”执行国内贸易法案。 |
| 对华的特别贸易政策 || 对中美第一阶段谈判持批判态度，认为其并未处理工业产能过剩、网络偷窃以及国有企业角色等关键问题。他声称将解决这些问题。 |
| 出口限制政策 || 没有表态，但可能会比特朗普政府对中国的限制要少，包括不太可能对TikTok等公司以及向华为出口产品采取限制政策。 |
| 进出口银行 || 在奥巴马执政期间支持进出口银行。他在竞选中仅仅表示将禁止资助燃煤电厂。不过，可能会支持进出口银行的扩张。 |
| 贸易调整援助计划 || 没有特别提到贸易调整援助计划，但是拜登支持为更多劳工技能发展项目提供更多资助。 |
| 数字自由贸易 || 没有表态，但可能会推动更强有力的跨境贸易条款 |
| 购买美国产品 || 强烈支持购买美国产品条款（包括通过一个4000亿美元的采购投资议案），要求联邦资助的基础设施项目购买美国的原材料。致力于收紧国内内容法规，限制购买美国需求品的豁免，以及延伸购买美国货条款到诸如公共资助的研发等其他形式的政府援助中。曾表示“当我们花纳税人的钱时，我们应该购买美国产品，支持美国就业。”并且很可能要求国防采购更多的国内产品。 |
| 关税政策 || 将审查现有232关税条款以及其他附加关税。愿意将关税作为新贸易战略的一部分。 |
| 汇率操纵 || 反对把操纵汇率作为获得不公平贸易优势的手段。支持贸易协议中新的透明度、磋商和强制性条款。 |
| 清洁/绿色贸易 || 对来自未能履行气候承诺国家的碳密集产品实施碳调节费或限额。将把巴黎气候协定作为未来贸易协定的一部分。 |
| 美国外资投资委员会(CFIUS) || 拜登政府可能会延续特朗普政府的政策对中国对美国的直接投资进行相对严厉的审查，但可能会对其他国家对美国的直接投资开放。

## **先进制造**

  

| **议题** || **立场** |
| --- | --- |
| 颁布先进制造战略 || 呼吁制定全面的“制造业和创新战略”。 |
| 美国国家制造业创新网络（Manufacturing USA） || 没有计划扩大美国国家制造业创新网络。然而，提议选择超过50个社区作为国家制造业创新网络的技术枢纽，并结合新的联邦研发投资、劳动力发展以及企业参与。 |
| 制造业扩展伙伴计划 || 呼吁将制造业扩展伙伴计划的资助扩大四倍（将达到每年近6亿美元）。 |
| 区域制造业支持 || 扩展“制造业创新伙伴”连接制造业机构、大学和大专、雇主和工会，以及州和地方政府。 |
| 向中小规模制造业企业提供资本 || 建立信贷安排向中小规模制造业企业提供资本，促进工厂现代化和提升能源效率。 |
| 税收相关的制造业激励 || 将通过一项“制造业税收减免政策”，推动现有或者近期关闭的制造业设施重新振兴、更新或者现代化。 |
| 学徒和劳工培训 || 将扩展诸如工业制造业技师学徒项目之类的注册学徒培训计划。 |
| 机会区域（Opportunity Zones） || 支持机会区域，但是呼吁在包括强制性影响报告以及通过调整实现种族平等方面进行改革。 |

## **清洁能源创新**

  

| **议题** || **立场** |
| --- | --- |
| 对能源和气候政策的总体态度 || 呼吁2050年实现美国净零排放，在他第一任期内投资2万亿美元用于清洁能源和绿色基础设施。促进众多低碳能源技术的创新，强调寻求难以减碳行业和负排放的解决方案。 |
| 能源研发的联邦投资 || 提议在4年内提供3000亿美元用于公共研发支出，其中包括清洁能源。呼吁增加能源部实验室和有关区域创新生态系统的资助。创建以“帮助美国实现100%清洁能源目标的颠覆性技术”为目标的“APARC”倡议。 |
| 联邦政府对清洁能源商业化和部署的支持 || 倡导“需求拉动”政策，包括清洁能源税收方案，碳定价，技术中性能源效率以及清洁电力标准等。使用联邦采购带动清洁能源技术的需求尤其是电动汽车，作为政府层面附加4000亿美元支出的一部分。 |
| 创新引导领域特定的政策 || 明确了一些主要领域的减排目标，包括电网2035年脱碳以及减少50%的建筑排放。倡议加速诸如碳捕获（CCUS）等关键技术的进展，帮助实现所有经济部门的脱碳，包括工业和农业。 |
| 将环境正义纳入清洁能源创新 || 致力于保障贫困社区从清洁和绿色能源技术设施投资中获得40%的收益。 |
| 培育国内清洁能源供应链和制造业的创新 || 提议10年内提供4000亿美元投资用于创建实现净零排放的未来产业。通过公共研发加速关乎清洁能源供应链弹性的创新。推动运用政府和社会资本合作来提升制造业产能，例如美国国家制造业创新网络的创新机构。呼吁建立一个涵盖各州的低碳制造业全国性战略。 |
| 美国在全球清洁能源创新中的地位 || 鼓励各国参与创新使命（Mission Innovation），使他们的清洁能源研发投资相对于原先起点增加到4倍。呼吁针对来自未履行国际气候责任国家的进口商品实施碳调节费。  
 |
