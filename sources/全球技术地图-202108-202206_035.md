# 优化调整管理体制机制，着力提高防卫作战能力——2021年日本国防科技管理综述

**当前，全球新冠疫情持续发酵，前沿科技竞争态势日趋复杂，世界战略格局和国家军力布局发生深刻变化，国防科技创新已成为综合国力竞争的关键要素和基础支撑。2021年，日本新老政府交替，军费预算首次突破GDP占比1%的红线，防卫省加快国防科技前沿研究战略部署，优化调整国防科技管理体制机制，深度挖掘民用科技资源能力，不断夯实国防科技人才根基，力促国防科技领域持续创新发展，全方位提升防卫作战能力。**

  

  

**01**

**强化战略规划顶层谋划，瞄准科技前沿加快布局**

  

新一轮科技革命和产业变革加速演进，全球前沿科技创新空前活跃，日本瞄准科技和产业发展前沿，持续出台科技战略规划文件，系统谋划科技发展思路和主攻方向，疫情肆虐下军费预算再刷新高，前沿技术研发投入力度前所未有。

**（一）持续完善科技发展顶层设计，高位谋划突出国家政策引领**

为实质性推进“科技立国”战略，日本立足世界科技形势与自身科技发展现状，基于《科学创新基本法》，每5年编制一期科技创新战略计划，主导国家科技创新突破发展。2021年3月，日本内阁发布《第六期科学技术创新基本计划》，出台系列举措支持科技创新，提出构建激发各创新主体能力的体制机制，加快新价值创造和提升前沿知识与科研能力提升；6月，日本政府发布“科学技术综合创新战略2021”和2021年版《科学技术白皮书》，前者明确了官产学研协同推进重点技术领域创新、强化综合科技创新会议的顶层牵引作用等政策要点；后者强调在超级计算机、人工智能、量子等领域，加大科技基础研究与人才开发力度；10月，日本科技厅科技政策研究所发布《2021年科技创新白皮书》，突出高效促进国家重要战略前沿的研发活动，夯实科技创新基础能力，多举措激发社会创新创造活力。

![](../Images/83538c5d051787d736a319117285f41e.png)

**（二）加速国防战略规划文件修订，深化国防科技顶层指导**

日本基于《国家安全保障战略》《防卫计划大纲》《中期防卫力整备计划》3大战略性文件，形成由总体战略、中长期发展规划、技术发展路线组成的国防科技战略规划体系。总体战略包括《防卫生产和技术基础战略》和《防卫技术战略》，提出国防装备生产研发的基本方针，以及通过技术情报收集、技术培育和技术保护3大循环，提升日本关键领域技术优势；中长期发展规划包括《中长期技术评估》，筹划未来20年前沿科技领域发展方向，突出实现无人化、智能网络化、定向能、现役装备性能提升等重点发展方向；技术发展路线包括《未来战斗机研发愿景》《未来无人机研发愿景》《构建多域综合防卫力量研发愿景》，就某项关键领域技术制定中长期装备研发概念及其实施路线。在国际战略形势急剧转变的背景下，岸田新内阁加快国防战略文件修订步伐。2021年11月，日本执政党正式启动修订3大战略性文件的讨论程序，欲推动“对敌攻击能力”的公开化、政策化和战略化。

**（三）突破军费开支限制，刷新国防研发投入高点**

为应对地缘紧张局势，争夺全球技术优势，2021年，日本军费预算连续第10年创造新高，国防科研预算较上一年度大幅攀升。12月，日本政府内阁会议通过2022财年5.4万亿日元国防预算，加上11月通过7738亿日元的2021财年国防补充预算案（二者作为整体定位为“加快防卫力量一揽子计划”），2022财年国防预算总额高达6.2万亿日元，约占GDP总值1.1%，突破军费GDP实际占比1%的限制。2022财年国防科研预算高达2911亿日元，比2021财年增加37.6%，接连刷新历史高点，其中包括高达65亿日元经费用于研发拦截高超声速导弹的电磁轨道炮等尖端技术。

**（四）聚焦战略性前沿创新领域，指引关键技术统筹发展**

为确保关键技术和核心基础不受制于人，日本加速科技创新领域布局，瞄准半导体、信息通信等具有巨大军用潜力的关键技术领域，出台系列重大技术发展战略、白皮书等文件。6月，日本政府首次发布《半导体数字产业战略》，提出从国家战略层面加大尖端半导体设计研发与产能，全力将日本打造成为集技术创新、系统研发和社会应用为一体的全球中心；同月，日本政府发布新版《2050碳中和绿色增长战略》，鼓励企业大胆投资和创新研发；7月，日本发布2021年版《信息通信白皮书》，强调未来重点谋求在5G等通信基础设施建设、网络安全等关键领域实现重大突破。

  

**02**

**调整优化国防科技管理体制，支撑新兴技术创新发展**

  

2021年，在国家科技创新顶层战略指引下，日本持续深化国防科技管理体制改革，整合装备研发机构，设立加强民技军用的重要职位，成立协调创新的部门机构，促使创新技术快速高效形成作战能力。

**（一）整合防卫装备厅尖端研发机构，聚焦跨域技术高效研发**

2021年，日本防卫省力图在高新技术武器装备研制上发力，加强集成装备研究力量的综合优势。3月末，防卫省整合防卫装备厅电子装备研究所和先进技术推进中心，成立“下一代装备研究所”，负责武器装备前沿技术研发，以及信息通信、电磁领域等涉及多类型装备的跨域技术高效研究，打造跨部门跨领域整体合力。“下一代装备研究所”旨在有效维持和加强试验与评估等基础能力，打破原有体制的技术转化应用壁垒，实现研究成果运用到装备成型的一体化管理。

**（二）新设职位挖掘先进民用技术，确保国防技术领域优势**

当前，军民两用技术转化、融合趋势日益明显，2021年，日本设立多个尖端技术相关重要职位，加快推进民技军用。3月，防卫省在防卫装备厅技术战略部新设“技术合作推进官”，支撑大学、企业、研究机构等基础研究成果的转化运用和落地应用；4月，防卫政策局新设“经济安全保障情报企划官”，搜集和保护具有军用潜力的尖端技术情报；同月，航空自卫队参谋部新设“科学技术官”，负责收集整理参谋部所管辖科技领域有关的资料与情报，向防卫装备厅提出航空装备研发需求和改进建议。

![](../Images/4d8511005ec17357edda9950308a336b.png)

**（三）创立国防科技创新部门机构，加强科技资源统筹协调**

2021年，日本持续深化调整科技创新部门机构，为各方资源统筹协调提供体制支撑。4月，日本新设“科学技术创新推进事务局”，从国家战略高度强化横跨文部省、防卫省等多部门的统筹协调，主导科技创新政策落地落实，突出政府科技创新体系的指挥中枢职能；9月，日本防卫省在山口县岩国市新成立“舰艇装备研究所岩国海洋环境试验评估站”，利用模拟技术对装备可靠性进行各类试验评估，同时为促进民用领域的转化应用，力推高校和科研院所的研发合作及科技资源开放共享。

  

**03**

**健全完善国防科技管理机制，加大官产学研协同创新力度**

  

日本不断优化安全保障技术研究制度，吸引高科技民用企业、科研机构融入国防领域协同创新体系，扶持小企业原创性和先驱性研究，打造科技协同创新发展生态环境。

**（一）优化安全保障技术研究制度,提高创新项目管理灵活度**

日本安全保障技术研究制度，是旨在调动各方科研力量开展具有军用潜力、独创性和颠覆性的基础与前沿技术研究的国防科技创新项目。2021年，防卫装备厅不断优化安全保障技术研究制度，实施项目的电子化、规范化、一元化管理。3月，防卫省修订《安全保障技术研究推进制度委托合同事务处理指南》，精简审批流程，优化合同管理程序，推动项目事务性手续的统一化和合理化进程，提高国防科技创新项目管理效率。包括将经费流转限制从20%扩大到50%，大幅增加经费使用弹性；放宽研究成果公布资料的提交条件；追加知识产权转让时可免除国家批准的规定；明确合同期限、延续条款等规定。

**（二）促进官产学研深度协作，形成开放协同创新合力**

当前，全球开放协同创新生态日臻成熟，日本各政府部门竞相建立协同创新机制，加强官产学研用多方紧密合作，推动军内科研单位、大学、企业形成国家级技术攻关创新联盟，形成国防科技开放创新合力。1月，日本政府宇宙政策委员会发布《加速太空开发利用战略计划的基本方针（草案）》，提出推动官产学研不同参与者共同致力于高技术研发，创设“加速太空开发利用战略计划”；6月，文部省正式启动“小型技术创新卫星研发项目”，由日本宇宙航空研究开发机构主导，联合企业、大学和研究机构开展创新性卫星技术研发活动；此外，日本政府拟委任产业技术综合研究所牵头并领导筑波创新园区各成员单位组建创新联盟，共同搭建并利用技术研发与测试平台，加大开放创新力度。

**（三）优化小企业创新制度,激发民间创新创造活力**

日本自1999年起启动中小企业创新研究制度（SBIR），旨在通过每年400亿日元规模资助，鼓励中小企业开展科技创新开发活动。但由于促进创新产出的成效不足，2021年，日本政府对SBIR制度进行大幅改革，更进一步激励初创企业提高研发创新能力，激发社会革新创造活力。新制度采用更为灵活的促进研究成果转移转化合同制度，从技术萌芽期到产业化落地为中小企业提供强有力支撑。自2021年起，安全保障技术研究制度被指定为SBIR制度经费补助的对象，推动中小企业创新能力引入国防科技领域。

**（四）加大前沿创新和工业基础资助,打造更优创新生态环境**

日本政府不断加大前沿科学领域的创新项目和国防工业的资助力度，营造开放创新生态环境。12月，日本文部科学省决定新设推动原创性和先驱性研究的“国际先导研究”项目，资助拥有出色研究成果和国际人脉的顶尖研究人员，带领其研究团队开展国际联合研究，旨在提升日本科研整体实力和核心竞争力，同时培养具有国际竞争力的青年研究人员。此外，为提振国防工业，防卫省决定自2022年春季起，大力支持军工企业技术改造，资助其购入新设备和新系统，提高生产效率和装备性能，资助比例将高达50%或者2/3，强力推动创新技术变革和提升装备制造综合竞争力。

  

**04**

**数字变革赋能国防技术创新，经济安保体制护航风险防控**

  

在地缘政治冲突加剧、新冠疫情全球蔓延、数字技术迅速发展的背景下，日本防卫省加快推进数字化手段在国防科技领域的应用，并进一步加强经济安保体制建设，确保关键技术供应链安全，防止敏感技术外流。

**（一）加速推动数字化手段，为国防科技创新提供条件**

新冠疫情暴露出日本数字化转型滞后弊端，日本积极推动武器装备成本数据库和数字工程前沿技术创新发展，加快数字化手段在国防科技领域的应用。2021年，防卫装备厅加紧构建武器装备的全寿命周期成本数据库，将实现对装备制造成本的一元化管理与对比分析，大幅提高成本估算精度与效率。同时，防卫省和自卫队目前正致力于数字工程整合能力，以高效采购和操作先进装备。6月，防卫省表明在研发下一代F-X战斗机时引入数字工程技术，将开放式体系架构应用于F-X战机上各任务系统，增强战斗机的可扩展性。防卫省还在探索将民用部门的先进方法更广泛地整合入装备生产项目的可行性。

![](../Images/b7c90067304fb692af7750b5be8b7e3a.png)

日本F-X战斗机概念图

**（二）构建强有力经济安保体制，抓实关键供应链风险管控**

随着新科技革命下国家安全保障意涵延伸、新冠疫情下供应链风险凸显，日本加快经济安保战略布局，通过立法和管理体制调整确保关键产品和技术的供应链安全。7月底，日本政府正式启动“经济安全保障一揽子法案（暂定名）”的草案制定工作，完善战略相关法律环境，提出包括供应链多样化、确保和维持国家的技术优越性等16项重点课题；10月，岸田内阁组阁后，首次设立经济安全保障担当大臣一职，负责酝酿并制定经济安保相关重要政策，强调以有力手段加大对特定产业的支持；12月，日本政府表示正在成立暂定名为“经济安全保障室”的经济安保指挥中枢部门，横跨中央相关省厅联手合作，确保半导体等关键物资稳定供给等。

**（三）加大敏感技术外溢管控，应对新形势下经济活动风险**

为防止国内敏感技术外流，日本岸田内阁加大技术管控力度，以应对国际政经形势复杂化背景下日益凸显的经济活动风险。4月，日本政府“综合创新战略推进会议”决定在2023年内创立调查和研究经济安保相关技术的智库，推动军民两用先进技术开发的同时，防止日本先进技术情报外泄；6月，日本政府宣布拟针对受外国政府“强烈影响”的外国留学生及日本研究人员，采用“经济产业大臣许可制”，防范存在安全隐患的案例发生和敏感技术外流；10月，日本警察厅及各地警局开始面向企业及大学提供“经济安全保障咨询”，介绍技术窃密手段等最新情况并提供应对方案；12月，政府考虑最快在2023年引进尖端技术专利保密制度，并将其作为经济安全保障推进法案的重要组成部分。

  

**05**

**夯实科技人才资源基础，全方位构建人才竞争优势**

  

![](../Images/69a8f37312ba54fb4c1ed620757b2244.png)

面对科技领域高端人才短缺、科技创新步伐放缓等现状，日本通过人才引进、教育培训、财政资助等举措构筑国防科技人才优势。

**（一）多举措挖掘招募人才，借助民间科技打造人才优势**

2021年，日本防卫省开展多样化创新活动，起用民间专家型人才，以确保国防领域专业化人才优势。3月，防卫省线上举办网络攻击对抗赛，包括网络漏洞竞速赛、硬盘数据恢复等，旨在通过竞赛招募网络安全专业人才；4月，防卫省自卫队通过夺旗赛等形式，从全国范围内公开招募掌握网络领域最新趋势知识、技能、经验的“网络安全统筹顾问”，负责向防卫省和自卫队网安政策和相关研究建言献策；自卫队聘请精通数据分析和AI算法的外部专家，指导防卫省推动智能化发展。

**（二）多渠道强化人员培训，打造专业新型作战力量**

为提高自卫队员在新兴领域的专业化水平，日本不断完善自卫队教育培训机制，多渠道、多方式开展自卫队人员培训。2021年，陆上自卫队高等工科学校开设网络专修课程，旨在培养未来的网络安全人才；防卫省积极向专业的网络安全企业学习防范网络攻击；自2016年起，自卫队每年派人参加美国战略司令部主办的“全球哨兵”太空演习；近年来，自卫队向美空军基地派遣人员学习“太空基础课程”，以掌握对太空的整体认识。

**（三）多链条完善人才资助体系，确保未来科技创新人才**

青年人才是科技创新的优质资源，2021年，日本通过延续和新设系列青年科技人才资助项目，为本土高端科技人才提供多元、长期、稳定的资金支持渠道。2021年度起，日本政府全面启动“推动科技创新的大学助学金”项目，面向人工智能、量子等新兴技术领域的博士课程学生提供生活费补助，并与产业界合作，打造确保肩负科研与科技创新重任的高端人才资源。2021年，日本政府继续推动扶持青年人才的“卓越研究员项目”、“特别研究员项目”等，通过官产学研协同，为年轻研究人员创造稳定的研究环境，支持研究人员提高各项能力。

  

**06**

**加强防务领域国际合作，不断拓展全球军事影响力**

  

在国际秩序遭到冲击、地区局势日趋紧张背景下，日本谋求通过装备出口、防务领域联合研发和对外合作，更好更快地提高军事实力，夯实本国国防工业技术基础，带动国家软实力提升。

**（一）加强防务项目和军事联盟合作，实现互利共赢发展**

日本加大防务领域项目合作和联盟交流，接连与欧洲国家签署军事协定，旨在简化军事力量互访、联合演训相关程序以及深化情报共享等防务合作。2月，日本宇宙航空研究开发机构与欧洲航天局签署协议，针对火星卫星探测计划和“赫拉”小行星探测项目展开合作；3月，日德签署《军事情报保护协定》，推动两国军事情报共享、武器装备出口和联合演训等方面合作；10月，日美澳印四国联盟线上召开科学技术部长级会议，就深化人工智能、半导体等先进技术领域合作、国际规则制定等议题开展充分讨论；12月，日法政府就缔结《互惠准入协定》交换意见，协定的签署将极大简化两国相互携带武器入境的程序和海关手续。

**（二）深化拓展防务领域联合研发，提升国防技术国际地位**

为深化合作关系，提升国防技术国际地位，日本不断深化和拓展防务领域联合研发。2021年，日美加快联合研发步伐，由日本三菱重工负责研发，美国洛克希德-马丁公司、波音公司等提供技术支持，共同开发新型战斗机；日美还拟签署国防技术研发合作协议，“共同应对高超声速武器威胁”；7月，日英防卫大臣就加快下一代战斗机发动机研发合作达成一致，力图通过国际合作提高武器装备质量水平。

**（三）实施武器装备出口优惠政策，助推军工企业与先进技术持续发展**

日本加快向发展中国家转移武器装备，并通过提供低息贷款和贸易保险便利，促进国防装备出口，助推本国军工企业和先进技术发展。3月，日本与印尼召开外长及防长“2+2”会议，并签署“防卫装备及技术出口协议”；9月，日本防卫大臣访问越南期间签署最新军事合作协议，可向越南提供海军装备和舰艇军事技术；11月，日越签署推进网络安全防卫合作备忘录。2021年，日本政府提出利用日本国际合作银行向对象国提供低息贷款，使资金短缺的发展中国家也能从日本采购武器装备；同时日本政府还鼓励本国出口企业灵活运用日本贸易保险，承保私人保险公司业务范围之外的高风险海外贸易。
