# 探索更深的蓝——美海军首次“无人集成作战问题”演习特点分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651587641&idx=1&sn=b70d59b022a90a29000db77b3292cfb3&chksm=f18577c9c6f2fedfe78e4c4d5f594bce2860e57cd04f6f56bb24805b44ed2f3e4d085232e7ad&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651587641&idx=1&sn=b70d59b022a90a29000db77b3292cfb3&chksm=f18577c9c6f2fedfe78e4c4d5f594bce2860e57cd04f6f56bb24805b44ed2f3e4d085232e7ad&scene=27#wechat_redirect)

**2021年4月19日至26日，美海军在加州圣迭戈外海举行了为期一周的“无人集成作战问题”-21（UxS IBP 21）演习。这是该军种首次举行涉及多个作战域的有人-无人系统大规模编组协同演习，也是其在今年3月发布《无人作战框架》后举行的首次大型演习，动用数十型无人系统，目的是在真实、复杂的任务场景中探索有人与无人系统如何在空中、水面和水下实现密切跨域协同，使后者成为颠覆性的能力倍增器。该动向表明，美海军正扎实有序推进无人作战力量建设，力图打造有人-无人协同体系优势，对潜在对手的传统海上对抗模式构成了全新挑战。**

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**相关背景**

2018年，美海军部先后出台《无人系统目标》《无人系统战略路线图》等文件，提出了“建设一支有人／无人系统无缝集成部队”的愿景。但随着新版《国防战略》聚焦大国竞争、财年预算逐渐收紧、“烟囱式”研发造成重复采办等因素造成的巨大挑战，迫切需要对无人系统的总体策略进行针对性调整。  

2020年12月，美海军部颁布《海上优势：以一体化全域海上力量制胜》战略文件，首次将我列为唯一长期战略竞争对手，明确将中美海上关系定义为“对抗”，强调由海军、海军陆战队和海岸警卫队组成的“海上三军”必须作为一个整体进行建设和运用，形成从深海到太空、从远洋到陆地、从网络空间到电磁频谱的全域优势。该文件特别指出：①综合运用新兴与传统手段，以实现决策和行动优势；②综合运用武器、平台、传感器等，以实现杀伤力集成与分配；③综合开展各种计划和演习，以验证新型作战概念、鉴定新型武器系统。

2021年3月，美海军部又公开《无人作战框架》文件（以下简称《框架》），要求海军和海军陆战队加速交付可信和可靠的无人系统，使其成为海上兵力结构中可靠、可持续的力量，通过与有人系统快速整合，提升两个军种的杀伤力、兵力规模、生存力、行动速度、威慑和战备。该文件提出了从传统兵力结构向有人－无人混合力量转型的愿景，明确了“少造、少试、多学”的理念，旨在通过发展和部署经验证的能力，实现所有作战域中有人／无人力量的无缝集成，保持战略和战术优势。 

![](../Images/c5c1029c25b63ebb04f45d28ff6bd589.png)

美海军部《无人作战框架》文件封面（美海军部图片）

  

《框架》提出了五大发展目标，包括：①全面发展有人-无人编组协同作战能力，支持海上和联合作战；②构建数字基础，推进无人系统快速集成和规模化应用；③激励快速增量式开发和试验无人系统；④识别和解决共性问题，并跨域、跨平台推广；⑤发展思路从“以平台为中心”向“以能力为中心”转变。《框架》将网络、基础设施、数据与自主性、接口与标准、指挥与控制等划定为共性技术，将通信、导航定位授时、人工智能、网络安全、边缘计算等划定为核心技术，要求一方面增加投资力度、整合研发力量，一方面采用模块化开放系统架构、持续高频升级。《框架》还特别指出，作战部署、演习训练和演示验证是弥补能力短板、降低技术风险、修正概念条令、完善战术战法的有效手段。

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**演戏情况**

“无人集成作战问题”-21演习由美太平洋舰队负责整体规划，第3舰队具体组织实施。

1、参演装备方面，种类多样、阵容庞杂

此次演习中，有人系统主要选取现役装备数量较多、代表性较强的型号，无人系统则在纳入部分技术较为成熟的型号之外，还动用了部分在研甚至保密项目的阶段性成果。

有人系统方面，涵盖除大甲板舰艇（航母和两栖攻击舰）、弹道导弹核潜艇和作战支援舰艇外的几乎全部海空主战平台。典型装备包括：朱姆沃尔特级导弹驱逐舰1艘，舰艉的直升机甲板加装了大型球形天线罩，结合美海军此前透露有意将该级舰等改装为无人系统指控母舰分析，该天线很可能用于无人系统指控任务；阿利·伯克级导弹驱逐舰4艘，其中至少1艘搭载有“海军光学眩目拦截器”（ODIN）舰载低功率激光器；提康德罗加级导弹巡洋舰1艘；自由级和独立级近海战斗舰各1艘；圣安东尼奥级两栖船坞运输舰1艘；洛杉矶级攻击型核潜艇1艘；P-8A海上巡逻机；E-2C舰载预警机；EA-18G舰载电子战飞机，以及MH-60R／S舰载直升机等。 

![](../Images/04b45597e91bec416034a0f495717af2.png)

参加“无人集成作战问题”-21演习的朱姆沃尔特级导弹驱逐舰“迈克尔·蒙苏尔”号，可见其舰艉直升机甲板加装的大型球形天线罩（美国驱动网站图片） 

  

  

![](../Images/0b82942d82a2060bf624c5eb2648d0d8.png)  

参加“无人集成作战问题”-21演习的阿利·伯克级导弹驱逐舰“斯普鲁恩斯”号，可见其舰艉直升机甲板加装的大型球形天线罩（美国驱动网站图片）

  

无人系统方面，共动用29型，其中50%为无人水面艇系统，30%为无人潜航器系统，20%为无人机系统。典型装备包括：中型无人水面艇2艘、“人鱼海神”水面/水下双模无人航行器、“伊弗”-4无人潜航器、MQ-8B舰载无人侦察直升机、MQ-9A第5批次（Block 5）中空长航时察打一体无人机，以及“香草”超长航时无人机和首次曝光的海军研究办公室（ONR）“超级蜂群”计划等。  

“香草”无人机采用模块化设计，成本仅为当前主流长航时无人机的三分之一，该机翼展11米，可架设于皮卡车货厢的支架上，在行驶状态下使用可抛弃式线缆放飞。香草公司称，该机最大飞行高度4600米，最大航程超过34000千米，续航时间最长可达10昼夜，有效载荷45千克。 

![](../Images/23cc044cbaeab7366aed9a7ba548d441.png)

架设在皮卡车货厢上的“香草”无人机。9月24日至10月2日间，该机在美国爱德华兹空军基地上空连续飞行8天50分钟47秒，总航程达19634千米（美国香草无人机公司图片）

  

“超级蜂群”计划源于美海军研究生院工程系于2016年提出的初步设想，旨在研发由水面、水下和空中无人系统，甚至多模无人系统组成，规模超过10000艘／架的巨型无人蜂群系统，从而彻底瘫毁对手的态势感知和判断决策能力，该军种认为其已属于大规模杀伤性武器。2020年，ONR官方出版物披露，美海军已于当年进行了“近战隐蔽自主一次性飞机”（CiCADA）实验，使用1架C-130运输机空投了1000架蜂群无人机。这一数量较2016年国防部战略能力办公室使用F/A-18E/F战斗机空投100余架“山鹑”微型无人机的实验提高了近9倍。  

![](../Images/a1cfe3d461b18b0db5f98b8421624db6.png)

“近战隐蔽自主一次性飞机”及其发射罐。该机仅重65克，成本约250美元。美海军的A型声纳浮标罐可装32架，G型声纳浮标罐可装10架（美国海军认知网站图片）

  

  

2、演习内容方面，紧贴实战、注重协同  

美海军称，“无人集成作战问题”-21演习主要由三个场景组成，包括：①复杂的进攻性实弹发射演练；②有人-无人协同情监侦（ISR）演练；③有人-无人编组作战概念演练。美海军及相关媒体仅对第一个场景的内容作了不同程度的披露，另外两个则严格保密，仅笼统表示使用了多域多型无人系统与有人舰机协同演练。

进攻性实弹发射演练：4月25日，美海军使用有人-无人协同杀伤链，引导1艘导弹驱逐舰发射1枚“标准”-6导弹，对模拟潜艇的水面目标（装有小型角反射器和信号转发器）实施了超地平线精确打击，有效射程超过400千米。

演练过程中，1型天基系统负责对可疑海域实施广域监视，中型无人水面艇等负责搜索与跟踪，确定目标所在海域后由MQ-9A Block 5无人机从高空投放被动声纳浮标，机载“自动识别系统”（AIS）完成精确定位和目标识别，随即与巡弋的P-8A巡逻机和MH-60R舰载直升机建立Link 16数据链通信，并通过其他无人机搭载的“海军全球指挥与控制系统”（GCCS-M）完成超地平线瞄准，将相关信息传输至导弹驱逐舰，实现了杀伤链闭环，全程未使用任何有源传感器。此前，该军种曾在4月22日使用MQ-9A无人机协助1艘导弹巡洋舰对类似目标实施了瞄准，但未发射实弹。 

![](../Images/5a903f73f6e7ece84ffe68bd6890e4b1.png)

飞越独立级近海战斗舰“科罗纳多”号的MQ-9A第5批次无人机。虽然有多家媒体认为参与此次演习的MQ-9无人机型别为MQ-9B，但根据翼梢小翼外形研判，该机应为MQ-9A 第5批次。通用原子公司的后续报道也对此予以证实。（美国《海上力量杂志》图片）

  

  

此外，美海军在该场景中还完成了无人蜂群系统反舰能力演示。该演示使用1艘无人水面艇作为情监侦平台，通过“电子支援手段”（ESM）将目标坐标等信息传输至舰队海上作战中心（MOC），后者新设的信息战指挥官（IWC）主持生成火控数据，最终由水面战指挥官（SWC）核准并下达攻击指令，发射无人蜂群系统完成打击。

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**初步认识**

1、演习达成多个目的，美海军无人作战力量建设取得初步成效

虽然美海军至今仍未透露“无人集成作战问题”-21演习的大部分内容及具体细节，但综合相关信息研判，该军种至少达成了以下目的：①再次验证了“标准”-6导弹的反舰能力；②首次证明MQ-9A Block 5无人机挂载声纳浮标撒布器等吊舱后，具备与MQ-9B无人机相当的反潜战能力；③初步证明其有能力构建有人-无人协同杀伤链；④初步证明其有能力构建横跨水面、水下、空中和太空的复杂混合无源探测网，对现有有源探测体系形成强力补充；⑤初步证明信息战指挥官可显著提升舰艇编队杀伤力和生存力，该职位主要负责收集和整理各种平台、系统获取的信息，并遂行全域火控数据分发；⑥有助于其在《无人作战框架》指导下深入开发可行可靠的新型作战概念。

2、演习实验性质浓厚，依托一体化试验鉴定提升装备实战效能

此次演习的实验性质极为浓厚，美海军希望通过类似活动尽快明确当前兵力结构与理想的“未来混合舰队”之间存在的差距，并初步制定有人-无人编组的战术、技术和操作规程（TTP）。值得注意的是，美海军官员强调通过“试能”与“试不能”在演习中不断探索装备能力边界、形成全新战术战法，并以“验证一批交付一批”的形式向一线部队扩散。这与美空军创建“黑旗”演习的根本目的高度一致，即通过研制试验与作战实验的一体化，持续、快速、可靠地创新作战能力，不断提升武器装备的实战效能。

3、补齐短板加速演变，美海军谋求建立并掌控全面作战优势

随着美海军强调在保持强大对陆攻击、水下作战和两栖投送能力的同时“重回制海”，其愿景已调整为广域分散作战平台、机动部署作战力量，以制海制空为核心，以制陆为目的，通过远程、隐蔽、精确手段对对手实施压倒性、摧毁性打击，最终建立并掌控全面作战优势。从“无人集成作战问题”-21演习情况看，美海军希望在新作战概念、新作战力量和新装备技术的牵引下，打造立体感知、远程突袭、高效致命的全新作战样式，其地理分布更广、体系连通更好、敏捷抗毁更强，将赋予该军种非对称优势。

**研究所简介**

  

国际技术经济研究所（IITE）成立于1985年11月，是隶属于国务院发展研究中心的非营利性研究机构，主要职能是研究我国经济、科技社会发展中的重大政策性、战略性、前瞻性问题，跟踪和分析世界科技、经济发展态势，为中央和有关部委提供决策咨询服务。“全球技术地图”为国际技术经济研究所官方微信账号，致力于向公众传递前沿技术资讯和科技创新洞见。
