英国发布《国家量子战略》

2023年3月15日，英国科技、创新与技术部发布《国家量子战略》（National Quantum Strategy）。该战略回顾了过去十年，英国在量子科技领域的优势地位，描述了未来十年英国成为领先量子经济体的愿景及行动计划，并阐述了量子技术对英国国家安全的重要性。



01

背景

在未来3至5年内，量子计算可在全球增收5-100亿美元；在接下来的15至30年里，这个数字将增加到450到8500亿美元。率先开发量子技术的国家将拥有巨大优势。英国从2014年开始投入10亿英镑研发资金，已在量子计算、传感器和授时、成像和通信领域开辟了市场。但随着量子技术的不断发展，英国也面临越来越多的挑战。

多数量子技术处于研发或早期演示阶段，开发量子产品和服务是一个漫长而具有挑战性的过程，需要持续的投资和支持才能获利。产品研发和部署所需的巨额资金，引发全球投资和竞争正快速增长。英国正面临激烈的人才竞争，与技术转让和贸易相关的潜在风险也在增加。为此，英国将为发展世界级的量子行业做出关键的战略决策。2023年，英国政府成立了科学、创新和技术部( DSIT )，旨在推动英国成为世界上最具创新性的经济体和科技超级大国。量子技术是这一使命的核心，DSIT的重点是巩固英国的优势，保障英国量子技术未来十年的发展，制订并发布《国家量子战略》，与英国量子界携手合作，将这一国家战略付诸实施。


02

主要内容

2.1 未来十年愿景

到2033年，英国将成为世界先进的量子经济体，创造繁荣的量子行业，确保量子技术成为英国数字基础设施和先进制造业不可或缺的一部分，推动建立强大而有弹性的经济和社会。

2.2 未来十年目标
为了实现未来十年愿景，英国承诺从2024年开始，近10年里投入25亿英镑开发量子技术，并将引入10亿英镑私人资本，以实现设定的四个目标。
2.2.1 发展知识和技能，确保英国拥有世界领先的量子科学和工程

2.2.1.1 研究与开发

从2024年到2034年创建一项25亿英镑投资的十年量子研究和创新计划。该计划将分两个5年实施。首个5年核心要素包括：

  • 以应用为中心：由量子技术和相关学科专家联盟以及来自工业界、政府或其他合作伙伴，围绕特定应用领域或主题活动，促进未来量子经济增长和提高国家能力，确保英国长期成为尖端量子科技全球卓越中心；

  • 以任务为中心：以特定任务为中心的创新计划，推动发展实现既定的社会和经济效益；

  • 以行业主导的创新计划：鼓励行业研发，对商业化领域进一步投资。该计划包括探索新的量子技术商业化可行性项目，或协作创新项目，以应对量子技术转化和商业化挑战；

  • 加速器计划：将发展特定技术部门和公司，加速推动商业和技术成熟发展，在具有重大市场机会的领域提升主权能力和市场领导地位。该计划着重于通过在现实环境中与用户和集成商进行演示来弥合早期增长和市场准备之间的差距；

  • 培训和人才计划：投资研究生技能、技术和工程专业人员以及学徒制，提供英国所需量子人才；

  • 国际合作计划：利用现有计划优势，扩大国际研发合作，实现互惠互利；

  • 基础设施投资：满足不断发展的领域和部门需求；

  • 支持基础研究：继续通过现有的工程和物理科学研究理事会（EPSRC）和科学与技术设施理事会（STFC）进行响应模式研究，推动科学发展，使量子技术作为更广泛研究的工具得以利用。

2024年的投资包括：

  • 1亿英镑继续开发现有计算、通信、传感、成像和授时应用；

  • 7000万英镑开发量子计算和定位、导航、授时（PNT）关键技术；

  • 2500万英镑增加对量子奖学金和博士培训投资；

  • 1500万英镑促进政府采购量子技术供公众使用；

  • 2000万英镑用于加速活动，进行量子网络协作研发；

  • 2000万英镑用于国家量子计算中心增加的活动。

政府2.5亿英镑技术任务基金中7000万英镑量子任务：

  • 加速量子技术在PNT中的弹性能力，到2025年在传统卫星拒止环境中展示成熟原理验证样机；

  • 开发量子计算试验台，支持2025年英国量子计算部门发展。

此外，英国期望引入私人资本10亿英镑。

2.2.1.2 技能和人才

英国须确保产业发展所需的量子高技能人才，培养具有量子专业素养的员工队伍。

  • 在未来十年内培训1,000多名量子及相关领域的博士生；

  • 通过投资量身定制一揽子计划，确保英国能够继续吸引、培养和留住世界领先的专家；

  • 在未来两年投资2500万英镑，增加与量子相关的奖学金和博士培训，在十年计划中继续增加资金；

  • 建立量子技能工作组，将工业界、学术界和专业协会与相关政府机构聚集在一起，确保量子技能系统以英国龙头企业需求为导向，在未来12个月内制定并发布技能行动计划；

  • 制订一系列措施来激励下一代量子科学家、工程师和技术人员，制定量子产业安置计划和量子技术学徒计划；

  • 通过签证途径，支持全球量子人才移居英国；

  • 积极吸引和支持最优秀的国际流动科技人才到英国，与国家量子技术计划合作，继续提供资金、设施支持，鼓励世界顶尖量子人才在英国开展研究和商业活动。

2.2.1.3 国际伙伴关系

与盟友和伙伴合作，实现互惠互利，确保英国发挥主导作用。

  • 与国际合作伙伴就量子机遇、挑战和关键用途进行协作并分享专业知识，尤其是在技术帮助实现主要社会目标的领域；

  • 通过深化与国际合作伙伴合作，继续参与全球先进的多边研究伙伴关系，推动量子技术研发；

  • 加强对全球量子风险和机遇定义的领导工作，与国际合作伙伴合作制定负责任和安全的量子开发和部署共同原则。

在加强量子国际合作方面，英国将：

  • 通过与主要量子国家的双边计划，与英国全球科学与创新网络合作，扩大伙伴关系；

  • 与其他领先的量子国家合作，交流有关量子计划、发展、监管和安全知识；

  • 公开呼吁合作研究扩大英国量子全球合作网络；

  • 通过新的国际科学合作基金为国际合作提供额外资金；

  • 在多边论坛中发挥主导作用，支持英国的量子产业增长，并寻找更广泛的合作研发机会，如AUKUS国防协定等；

  • 展示英国在国际标准论坛中的领导地位，优化英国公司条件并制定符合英国规范和价值观标准。

2.2.2 支持量子业务发展，使英国成为量子企业首选地和全球供应链不可分割的一部分，以及投资者和全球人才首选地点

2.2.2.1 关键行业和专业机构在量子领域密切合作

在未来十年及以后，英国将与量子公司以及英国量子、物理研究所、皇家工程院、工程技术研究所等关键行业和专业机构密切合作，了解行业观点并确保政府采取行动支持增长。这种参与将涵盖未来研发计划的详细设计、技能、经济体系中的量子准备、国际参与以及未来法规和标准的共同设计等领域。

2.2.2.2 开展商业化和加速器计划

量子计算和PNT的任务将包括支持这些技术领域的商业化和用户活动。此外，英国将为量子技术开发新的加速计划，支持该行业利用市场机会为英国建立战略优势。加速计划将专注于系统集成、应用和真实世界演示，帮助加速商业化、工业化以及将该行业与最终用户联系起来。英国将持续拓展国家量子技术计划(NQTP)合作伙伴正在开展的现有活动，并促进行业更多参与。加速器计划的投资活动将针对技术领域量身定制，如为关键应用制定市场路线图。英国还将继续提供行业主导的创新融资机会，降低中长期投资风险，鼓励新进入者加入该行业。

2.2.2.3 加大基础设施投资

未来十年的创新将需要获得合适的研究和创新基础设施，在实验室和现实环境中测试、试点和展示这些技术的价值，以加速市场化进程。政府将在提供关键基础设施方面发挥主导作用。将对现有量子技术研究中心建立的研究和创新基础设施网络进行投资，并在西北部与IBM合作建立国家数字创新中心。

  • 与业界合作，对关键基础设施和计划要求进行可行性研究；

  • 委托英国工程院在2023年底之前进行独立的基础设施审查，确定政府未来投资方向；

  • 开放对跨行业、研究机构、大学和政府拥有的设施及参与合作伙伴设施的访问，进行测试、解决问题和性能演示；

  • 制作英国各行业可访问的基础设施目录，并探索未来十年量子行业对基础设施的需求；

  • 通过国家量子计算中心(NQCC)协调跨平台访问量子计算资源，在未来两年内额外提供2000万英镑，推动NQCC工作。

2.2.2.4 提供商业化支持

英国是创业和发展业务的理想之地，可为企业提供如下支持：

  • 中央政府创新中心的发展可确保提供所需业务支持；

  • 知识产权局 ( IPO ) 数字指南和工具可帮助企业了解知识产权制度，在保护知识产权和商业化方面做出明智决定；

  • 国家物理实验室( NPL )提供测试和评估服务，帮助公司弥合从研究环境中的技术样机到行业就绪的创新产品之间的差距；

  • 国家保护安全局 ( NPSA ) 和国家网络安全中心( NCSC )向企业提供建议和支持，帮助企业实施数字保护和物理安全措施；

  • 商业和贸易部 ( DBT )支持企业出口并进入全球市场，帮助海外企业在英国落户，还负责吸引对内投资，帮助企业在英国投资和扩张；

  • 确保量子企业获得所需支持，英国将创建一个量子业务增长清单，帮助企业利用创新业务，保护知识产权。

2.2.2.5 投资释放创新

确保英国企业能够在所有增长阶段获得融资。政府动员更多机构的投资进入生产领域，确保投资者能从英国最具创新力的公司的经济增长中受益。政府继续与行业利益相关者密切合作，制定有效的政策支持。政府通过财政机制使小型企业的金融市场更有效地运作。

2.2.2.6 不断发展全球供应链

英国拥有世界领先的产业集群，英国企业是全球供应链的重要组成部分。为了在国内和全球供应链中推广并促进投资，英国将：

  • 在国内外传播重要用户宣传材料，开展有针对性的全球机会活动，与全球合作，为企业创造贸易机会和开放投资与合作机会；

  • 协同国际合作伙伴，促进该行业可信供应链发展，有利于英国生态系统及伙伴国家生态系统的发展。

2.2.2.7 吸引量子企业到英国

海外量子公司在英国生态系统中占有重要地位，英国将建立吸引海外量子公司的项目和投资机会，与商业贸易部合作，积极支持量子企业进入英国。

2.2.3 推动使用量子技术，以支撑经济、社会和英国国家安全

2.2.3.1 推动量子技术应用，造福社会

预计未来几十年全球将产生1000亿英镑的预期收益。主要包括：

一个环境可持续和有弹性的英国：量子计算机可模拟新材料，提高可再生能源效率；对物流和交通网络流量建模和优化，量子计算可显著提高效率，减少碳排放，量子传感器有助于英国实现排放目标并监督其合规性。

加强国内外安全、防御和弹性：改进用于防御目的的传感器网络，增强传感器实现自治，即，使用量子增强机器学习进行模式匹配、图像和语音识别与分类以及数据融合，在战场上使用量子计算和传感找到热点目标并增强态势感知；量子通信系统无法被拦截，且可隐蔽部署平台上；量子传感、授时和成像能力可提供下一代 PNT支持部队部署的能力。

英国作为数字参与者并为英国释放数据力量：量子计算可增强金融系统内场景规划、物流和风险管理；可加速机器学习并使用无偏数据集提供强化学习；可通过传感、网络和计算能力推动智慧城市发展。

支持英国其他优先技术和部门发展：量子产品和服务通常会通过整合更广泛的技术解决方案进行创新。包括未来的电信网络、太空、国防、人工智能、高性能计算、光子学和半导体行业，须确保在制订路线图和支持其他部门技术进步时，将量子技术整合到现有的传统技术系统中。

2.2.3.2 通过政府采购，展示量子技术价值

量子技术可在许多领域改善公共服务并增强政府能力，政府可作为新兴技术的早期采用者来支持技术发展，并向其他经济部门展示量子技术价值。国防部已确定用于国防的关键量子技术应用，包括传感、成像和授时，以及随后在通信和计算方面的机会。

为了推动量子技术的采用，英国将：

  • 通过展示和演示活动，提高人们对量子技术的认识；

  • 加速最近启动的NQCC SparQ应用程序，确保抵御来自未来可扩展机器的加密威胁；

  • 通过采购样机平台和计算访问权限，扩大NQCC代表政府充当第一客户的能力；

  • 将至少四分之一的NQCC访问计算平台和相关研究项目用于探索社会效益的关键应用；

  • 加速量子技术实现 PNT的弹性能力，展示量子计算优势；

  • 与政府相关领导合作，商定行业或技术特定行动计划，实现技术融合，早期的重点是电信、国防、太空、人工智能、高性能计算和半导体行业等行业；

  • 扩大政府采购使用范围，探索应对公共部门挑战的有益应用；

  • 建立政府用户组，确定量子技术在公共服务和其他公益应用中可提供的优势，帮助实现公共服务提供技术开发方法，以及提高政府工作人员技能以实现成功探索方法潜在用例。

2.2.4 引领量子监管并保护该行业发展

随着量子行业的发展，英国应该提早为未来的监管挑战做好准备，确保监管框架推动负责任的创新，并保护和发展经济以及英国的量子能力。

2.2.4.1 通过各种组织、论坛发挥积极作用

  • 确保未来英国对量子技术的监管支持整个英国经济的创新、业务增长和量子技术负责任的使用；

  • 建立监管测试平台，引领英国试验量子技术

  • 与合作伙伴共同发挥主导作用，制定与量子技术相关的国际规范和标准；

  • 在各种世界组织、论坛和区域组织发挥积极作用，确保英国的繁荣、安全和国防利益，维护英国价值观；

  • 委托监管视野委员会对量子技术应用进行监管审查，制定一项工作计划，指导该部门支持创新监管的演变。

2.2.4.2 保护英国，支持增长

确保英国有效保护自己免敌对受恶意行为影响。

  • 与盟友合作，继续监测和审查当前管制对该行业的影响以及未来监管的各种变化，包括《国家安全与投资法》、出口管制制度，学术技术批准计划、多边合作以预测未来影响，确保监管和安全目标保持一致；

  • 就安全合作以及保护工作和知识产权（包括抵御网络威胁）向量子企业和研究人员提供指导。

2.2.4.3 减轻与量子相关的风险

量子计算将威胁到现有公钥密码学安全，对未来国家网络安全构成风险。国家网络安全中心 ( NCSC )发布了关于向量子安全密码学过渡的指南，对关键信息和服务采取了应对措施。NCSC将继续向每个部门提供定制建议，通过其网站提供有关量子安全密码学建议。NCSC与国际合作伙伴合作，确保英国向量子安全密码学过渡的计划和指南保持一致。各种管理加密基础设施的组织都应将量子安全过渡纳入其长期计划，并确定过渡高优先级系统。

2.2.4.4 技术标准

随着技术从最初的研究发展到样机和产品开发，技术标准变得日益重要：

  • 通过相关全球机构开展工作，确保全球量子技术标准促进英国繁荣和安全利益，包括加速量子技术的商业化和支持英国该行业发展；

  • 与主要合作伙伴协调国家参与量子技术标准开发优先领域的最佳方法。相关行业和学术界将积极参与，跟踪优先标准活动、提高利益相关者意识，并制订路线图支持英国参与量子标准制定。

2.2.4.5 量子技术保证

量子技术用户需对其想要获得的产品或服务的可靠性、成本效益、安全性和保障等情况进行确认。测试和评估以及提供更广泛的保证将发挥关键作用。国家物理实验室 ( NPL ) 和其他组织已开展了大量工作，开发有效的测试和评估技术，推动未来框架的开发。NPL和NQCC将制定一项与标准路线图同等重要的基准测试工作计划。安全保证与性能保证同等重视才能让用户有信心投资或采用这些技术，并将遵守《2022 年网络安全战略》中的安全原则，且须将安全视为推动因素。通过降低使用云与其他企业或用户交互时的网络风险，确保量子技术在设计上是安全的。NCSC将与国家量子技术计划合作开发量子计算机安全模型，帮助公司设计安全架构，以数字安全设计计划为基础，继续为量子企业提供指导。

2.3 开展行动计划

英国政府将携手学术界、工业界以及国际合作伙伴共同努力，采取严格措施实施战略目标。在科学、创新和技术部设立量子办公室，确保重点和推动实施该战略。

  • 量子办公室负责整合量子行业专业知识，向国家科学技术委员会报告进展情况，确保与其他优先技术联合发展；

  • 创建新战略计划委员会，管理该战略实施，确保政府在研发、贸易、外交、与私营公司和投资者合作、公共采购等公共投资方面发挥全方位杠杆作用；

  • 发布年度报告，介绍战略实施情况、优先行动计划以及该行业长期发展愿景，确保该战略实施得到工业、学术和技术专业知识支持；

  • 扩大和深化目前的咨询结构，使之能够就战略实施向政府提出建议。量子战略咨询委员会的职权范围和成员资格将扩大到能涵盖所有量子战略目标的实施；

  • 与英国量子产业部门代表以及其他重要行业和专业机构密切合作，确保了解行业观点并在发展过程中予以考虑。

评述

3.1 新战略将指导英国量子技术未来十年的投资和发展，确保英国继续成为全球量子技术领先者

英国政府2015年3月发布的《量子技术国家战略：英国的一个新时代》对英国量子技术发展和抢占全球领先地位进行了规划。经过近十年发展，英国已成为量子技术全球领先者，在研究人才、跨不同量子技术知识积累、以及在整个量子和相关供应链中都具有明显优势。为进一步巩固和扩大这些优势，英国推出新版《国家量子战略》。该战略描绘出通过未来十年的发展，将使英国变成前沿科学突破的发源地、世界上发展量子业务最佳地点、吸引国际量子人才的磁石的美好愿景；承诺在未来十年资助量子前沿研究，支持量子部门，为量子应用做好准备，确保英国在量子技术监管和负责任的使用方面处于国际领先地位；制订出为实现这一美好愿景和目标而将开展的主要行动计划。该战略将指导英国未来十年量子技术的投资和发展，促进形成一个长期、可持续发展的英国量子产业。英国政府希望借此汇集英国及合作伙伴力量，政府、工业界与学术界紧密协同，抓住量子技术发展机遇，奠定英国在未来量子技术市场中领先地位，推动英国产业链升级。

3.2 英国实施的量子技术发展方式具有一定借鉴意义

一是持续为量子技术发展和商业化提供资金支持。量子产品和服务开发过程漫长且具挑战性，需持续大量投资。新版战略是早期战略的延续，继续采取长期支持策略，承诺在未来十年内投资25亿英镑，吸引10亿英镑私人投资。长期的资助战略最终会带来技术的成熟并引起社会变革，产生非凡的影响力；二是新战略强调联合学术界、工业界、政府机构、合作伙伴和其他利益相关者共同参与战略实施，政府将作为量子产品和服务的首个客户，推动更广泛的参与将有利于形成完整价值链，加速成果转化，快速实现商业化；三是积极塑造市场化环境，为量子技术商业化做好准备。包括培训量子技术研发和产业人才、投资培训劳动力，满足未来产业发展需求、建立全面技术标准和监管体系、通过国际合作最大化推进英国量子技术产业等，这些措施的实施将有利于推动英国量子技术早日实现商业化。
