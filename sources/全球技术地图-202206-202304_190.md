# 技经观察丨实践中的数字主权：欧盟推动塑造新的全球经济

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651599621&idx=1&sn=1cfa296755a47b25620c01ef455eebc3&chksm=f18540f5c6f2c9e390b03b6a618d58e2f51af4cc7dcd77160dee637107c9d30d2d468c34c625&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651599621&idx=1&sn=1cfa296755a47b25620c01ef455eebc3&chksm=f18540f5c6f2c9e390b03b6a618d58e2f51af4cc7dcd77160dee637107c9d30d2d468c34c625&scene=27#wechat_redirect)

**2022年11月，美国智库大西洋理事会（Atlantic Council）发布题为《实践中的数字主权：欧盟推动塑造新的全球经济》（Digital Sovereignty in Practice:The EU’s Push to Shape the New Global Economy）的报告。报告认为，随着数字经济的发展，欧盟正在努力增强其技术能力并建立全球治理规范，且这一努力会对美欧跨太平洋技术合作产生重大影响。报告称，在欧盟委员会主席冯德莱恩的领导下，“数字主权”理念已成为欧盟参与数字技术事务的核心指导原则，将会对全球数字经济格局产生重要的影响。**

  

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**一、欧盟寻求数字主权的历史脉络**

在过去3年中，数字主权已成为欧盟国家推动新兴技术发展和数字政策制定的首要目标。欧盟委员会主席冯德莱恩曾在欧洲议会中明确表示，推动欧盟在一些关键技术上实现“技术主权”是其主要目标之一。2021年3月，欧盟委员会发布了《2030数字指南针：欧洲数字十年之路》（下文简称为“数字指南针”），该文件描绘了到2030年欧盟实现数字化转型的蓝图和目标，旨在引领欧盟构建可持续的数字化社会，加强欧盟的数字主权，以确保欧盟成为世界上数字经济最发达的地区之一。

  

![](../Images/1d5c2fe66335a89d2a12ab58eefcbccf.png)

来源：《Digital Sovereignty in Practice:The EU’s Push to Shape the New Global Economy》报告

  

数字指南针指出，欧盟在数字领域需要解决三个重要性的战略问题：技术短板、产业链脆弱和高风险依赖。为此，欧盟正在加强在数字领域的立法以加强其竞争力。以下为相关法案：

  

1.《数字市场法案》（Digital Markets Act，DMA）于2022年7月获欧盟理事会批准通过,并于2022年11月1日起生效。DMA将大型网络平台定义为“看门人”，要求“看门人”规范自己的竞争行为，不允许优先推广自家产品和跨服务使用数据。DMA中的规定将会对大型科技平台商业模式产生重大影响，如苹果必须允许用户安装第三方应用程序，并允许第三方与其服务互通等。

  

2.《数字服务法案》（Digital Services Act，DSA）于2022年10月获欧盟理事会批准通过。DSA为欧盟提供了一套统一的监管规则。DSA对数字平台规定了全面的新义务，并将数字平台置于全新的透明度和责任框架之下。对于违反DSA的行为，可能导致高达该主体前一财年度全球营业额6%的罚款。

  

3.《人工智能法案》（AI Act）于2022年11月由欧盟立法者提出最终版本。该法案规定了欧盟使用人工智能技术的规则，旨在为可信赖和以人为中心的人工智能提供标准。该法案将适用于欧盟进口包含人工智能技术的所有商品和服务。

  

报告认为，欧盟希望借鉴《通用数据保护条例》（GDPR）的经验在数字技术监管和标准化方面制定全球规范。短期来看，这种方法可能会使欧盟成为数字监管的领导者，但中长期看，欧盟的单边主义做法将对全球贸易的多边框架产生威胁。报告建议，美国和欧盟双方应通过美国-欧盟贸易和技术委员会（TTC）建立共识，并在数字领域展开合作。

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**二、欧盟寻求数字主权的进展和挑战**

在全球数字技术竞争中，欧盟越来越意识到其处于劣势地位。欧盟发布的数字指南针报告指出，全球主要数字技术是在非欧盟地区开发的，90%的欧盟数据由美国公司管理，欧盟地区制造的芯片仅占欧盟市场的10%。为了增强数字主权，欧盟提出了“开放式战略自主权”这一战略理念，旨在更好地平衡欧盟技术的自主权和开放性之间的关系。欧盟贸易总司长萨宾﹒韦恩德（Sabine Weyand）表示，国际秩序已经从基于规则的体系转变为基于权力的体系，欧盟必须从自己的立场出发配备所必需的工具。

  

2013年斯诺登“棱镜门”事件爆发后，欧盟对国际数据传输安全性产生担忧，并不断加大对数据国际流动的监管。欧洲法院相继认定欧美之间的跨大西洋数据流动协议《安全港协议》和《隐私盾协议》无效。经过激烈的谈判，2022年3月欧美就大西洋数据传输达成新的协议《跨大西洋数据隐私框架》，以加强美国情报活动的隐私治理和对欧盟公民自由的保护力度。美国观察家评论称，欧盟对美国情报机构的监视指控已成为其技术治理、数据本地化和寻求技术主权的正当理由。

  

欧盟还将云服务视为数字基础设施的关键部分，并强调云服务本地化对于实现数字主权的重要性。2019年，德国和法国启动云计算生态系统Gaia-X项目，意图在本地服务器上建立存储和处理数据的通用标准，以摆脱欧盟对中美两国大型IT公司的依赖，如亚马逊网络服务（Amazon Web Services，AWS）和微软旗下的软件和服务技术平台Azure。德国经济部长彼得﹒阿尔特迈尔（Peter Altmaier）表示，Gaia-X项目将有助于重塑欧盟的技术主权，并计划邀请欧盟其他国家和公司加入。

**三、欧盟寻求数字主权的未来**

  

2021年6月，欧盟委员会宣布通过“地平线欧洲”（Horizon Europe）框架，计划2021-2027年投资超1000亿欧元，将欧盟建设成为一个更健康、更环保、更数字化的地区。欧盟未来还计划在人工智能、数据治理、网络内容审核和数字经济等领域推出新的监管措施，推动此类措施成为全球标准，并提升欧盟在全球数字经济中的影响力。

  

另外，需注意的是，欧盟成员国在数字主权方面还没有完全达成明确的共识，并非所有的欧盟成员国都对“数字主权”有一致的理解。例如，法国对数字主权的理解更侧重于技术的安全性，而中欧和北欧国家则将理解重点放在培育自己国家的数字经济中心上，并希望欧盟能够更好地协调数字市场，以便为本国的初创企业提供便利。同时，欧盟成员国对于数字主权的限制范围也存在分歧。

《实践中的数字主权》报告指出，随着美欧共同面临的地缘挑战增加，美欧已建立起美国‑欧盟战略标准化信息（SSI）机制以实现国际标准制定的信息共享，并承诺捍卫关键和新兴技术的国际标准活动中的共同利益。报告建议，未来，美欧双方应在现有的多边框架下深化合作，如在七国集团（G7）框架下促进数据在信任下的自由流动。

**四、评述**

  

随着新兴技术的不断发展，关键技术对政治、经济和社会的影响愈发重要。欧盟提出“数字主权”这一概念旨在保持技术发展中开放性和自主性的相对平衡。在这样的理念指引下，无论欧盟数字经济产业最终发展如何，都可以预期一个在监管上更加“显露肌肉”的欧盟。

  

欧盟基于现实需要提出数字主权诉求，其目的是强化自身整体实力，避免在全球数字经济竞争中被边缘化，并保障欧盟内部技术的安全性。从战略层面上看，欧洲数字主权建设既满足了大国地缘政治博弈的需要，同时也适应了新技术革命带来的技术政治化的要求，对欧盟实现自主性具有重要的意义。
