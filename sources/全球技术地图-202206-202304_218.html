兰德报告：大国战略竞争的最新框架

2017年《美国国家安全战略》、2018年《美国国防战略》发布的许多年之后，美国仍然缺乏一个用来理解大国之间战略竞争的明确框架。本报告通过回顾大国竞争和对抗的历史案例、国家力量和竞争力的文献以及对俄罗斯和中国战略目标的评估，为美国国防部战略和部队发展副部长办公室提供了一个有效的大国战略竞争的最新框架。



 评估大国之间竞争的框架


一、竞争的总体背景——竞争所处的环境

1. 一个更加多极化的世界体系

2. 对新自由主义模式的挑战

3. 第四次工业革命

4. 脆弱信息圈的崛起

5. 气候变化和危机


二、国力和竞争力——支持竞争地位的国力和活力的关键组成部分

1. 国家的整体生产能力

2. 建立前沿技术的能力

3. 财政的敏捷性

4. 治理的有效性

5. 军事资源的水平和有效性


三、国际地位和影响——塑造一个国家实力和影响力的要素

1. 经济态势和参与

2. 军事态势和参与

3. 范式和意识形态的竞争

4. 关键国家的结盟


四、双边竞争的形式和地位——确定具体利益冲突和目标

1. 国家的核心利益

2. 利益冲突或交集的领域

3. 竞争领域的频率


大国竞争：美国、中国和俄罗斯的目标


竞争不是偶然产生的，它们是大国利益和目标冲突的产物，竞争的主要内容包括对国际体系及其机构、规则、规范、进程和非正式联盟领导权的争夺、主要地缘政治行为体的价值取向和基于实际利益的结盟以及在关键的新兴技术领域的领导权。



评估大国国际地位和影响力的四个主要类别


通过历史研究以及对各种竞争行为效果的评估表明，国际地位和影响力的四个类别对于确定竞争中的相对成功尤为关键。下面列出了这四个类别，以及对评估该类别特别有用的具体、可衡量的几个指标。


一、经济态势和参与。这一类别是指在关键经济类别中的相对竞争地位，这一类包括国家贸易比例、外国直接投资（FDI）和经济援助。


二、关键盟友和伙伴的结盟。竞争成功的第二个主要国际决定因素是，一个大国在多大程度上得到了其他国家的积极或默示支持和地缘政治联系。这一类包括为研究制定的各种结盟指数。


三、意识形态和范式的影响。竞争的第三个国际决定因素是一个大国对支配主流范式的思想、规则、规范和机构施加主导性影响的程度。这一类别包括公众对大国的态度、在国际机构中的作用以及意识形态亲和力的指数等。


四、军事接触和态势。国际竞争地位的第四大类指标是大国的全球和区域军事态势和军事参与程度。这一类包括基地建设、准入协议、军事演习和训练任务等。


有助于形成长期军事优势的三个关键因素


一、决定性的技术。鉴于美国的整体军事优势，美国的竞争对手一直在寻求各种形式的万金油或一揽子技术来消除美国的优势。俄罗斯和中国已经为这样的目标投资于各种形式的信息战，最引人注目的是中国正在开发的“系统破坏”、“信息化战争”概念，美国国防政策的一个主要目标必须是建立抵御这种以信息系统为重点的攻击的能力。



信息战是美国最可能的弱点军事领域，攻击者将寻求破坏美国的“系统中的系统”，方法是利用以下组合来分裂和蒙蔽信息的收集、交换和分析，具体包括：一般网络能力；电子战；虚假信息和感知操纵技术；攻击美国的天基监视和信息传输能力（包括GPS定位系统）。


二、新的战争方式。战争的特点可能正在发生重大转变，越来越强调信息攻击、无人驾驶系统（包括蜂群概念）和人工智能驱动的决策。无论是否发生全面转型，这些能力在未来几十年的战争中都将发挥越来越重要的作用。俄罗斯和中国都在这些类别中的许多方面进行了大量投资，目的是要超越美国的军事主导地位——以全新的作战方式超越美国当前一代军事系统和作战理念的优势。如果美国没有跟上步伐就有可能看到其军事优势在向这些新的战斗方式的过渡中被削弱，具体包括：



激增的无人驾驶系统——成群的无人机可能对现有的军事系统构成重大威胁；先进的解密技术——对事件信息的有效性产生根本性怀疑的技术；虚拟社会战争——全面攻击敌人的国内信息网络，其物联网、关键基础设施、通信和算法决策过程，瘫痪其社会和军事反应能力。


三、21世纪的作战理念。通常情况下，国家并不是通过单个技术的进步来实现军事优势的，他们是通过掌握一些综合的军事方法或作战概念。目前，军事竞争的大部分焦点是在特定技术领域或作战系统的净平衡。然而，最终它们的效果将通过作战概念来过滤，对概念思维的强调需要和军事系统一样重视，具体包括：


系统的概念——在1991年的 "沙漠风暴 "行动中，美国采用了一种综合的多领域方法，取得了毁灭性的效果；未来的概念——今天正在开发的大多数作战概念都有许多相同的基本原则：许多领域系统的整体整合、分散和隐蔽、信息攻击的主导作用，以及无人驾驶系统的日益增长的作用。掌握这些新兴的战略和作战概念，并转移投资以获得所需的系统，将是衡量竞争优势的一个关键因素。


当前所有的主要趋势线——俄罗斯的“新一代战争”、美国的“多域作战”、中国的“信息化战争”都是在说明通过攻击一套全面的军事和非军事目标来达到决定性的效果。新技术正在提供一种能力，可以在相对不受惩罚的情况下进入敌人的家园。鉴于美国在社会和军事上对先进信息网络的高度依赖，以及它最近在国内信息复原力方面缺乏投资，美国可能特别容易受到这种形式的攻击。


确定国家优先事项


本报告的研究表明了对美国竞争优势有重大价值的优先投资领域。这些建议的基本主题是，投资于竞争实力的基本国家基础与投资于向外的权利运用同样重要。


一、研究确定的国家优先事项包括以下内容：

1. 保持经济和财政实力和灵活性

2. 保持在新兴技术和产业中的领先优势或领先份额

3. 保护美国国土的信息环境

4. 开发工具和技术以参与与对手的持续竞争

5. 保持美国在全球机构中的领先影响


二、在国防投资方面确定了以下优先领域：

1. 避免前沿技术在军事上的应用严重滞后

2. 避免易受产生决定性军事效果的一揽子新技术和作战概念的影响

3. 投资于军事和准军事能力，以便在重大战争的门槛下进行竞争

4. 投资和促进政策，以维持和深化联盟关系

5. 发展概念和联合部队的能力，以便在短期和长期内实现区域突发事件和远程力量投射任务的特定目标

研究所简介
