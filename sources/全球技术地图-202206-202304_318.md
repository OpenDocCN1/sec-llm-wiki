# 技经观察丨世界主要经济体及国际组织发展生物经济的政策规划

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651597487&idx=1&sn=d98f10382c439818a087ccf69ad55e69&chksm=f185595fc6f2d0493211a104face844e1534e51acc64adf327f3aea46dbfb68cad885e4d565b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651597487&idx=1&sn=d98f10382c439818a087ccf69ad55e69&chksm=f185595fc6f2d0493211a104face844e1534e51acc64adf327f3aea46dbfb68cad885e4d565b&scene=27#wechat_redirect)

**近年来，合成生物学、基因编辑等生物技术领域频现重大突破，推动生命科学进步，由生物经济领域的研究和创新推动的经济活动迅速增长。生物技术和生物经济是应对气候变化、确保粮食安全、强化药品供应链、促进农业创新以及可持续发展的巨大机遇。全球各国已将扩大生物经济视为再工业化和创造财富的一种重要手段和战略性资源，以加强和维持本国的生产力和竞争力。**

  

  

![](../Images/9b18ce63215b687a8c2284ed845b713a.png)

**一、世界主要经济体关于生物经济的政策规划**

  

**（一）美国**

1.奥巴马政府于2012年4月26日发布《国家生物经济蓝图》，旨在加强生物科学研究，并将其作为美国创新和经济增长的主要驱动力，利用生物创新来应对美国在健康、食品、能源和环境方面的挑战。这份蓝图确定了五个战略目标，以在未来实现具有活力的美国生物经济，带来经济和社会效益。**一是**支持为未来美国生物经济奠定基础的研发投资；**二是**促进生物发明从研究实验室向市场过渡，包括更注重转化和监管科学；**三是**制定和改革法规，提高监管流程的速度和可预测性，并在保护人类和环境健康的同时降低成本；**四是**更新培训计划，使学术机构的激励措施与国家劳动力需求的学生培训保持一致；**五是**确定并支持发展公私伙伴关系和竞争前合作的机会。

  

2.特朗普政府于2019年10月9日召开美国生物经济峰会，联邦官员与私营部门的生物经济专家共同讨论美国生物经济的领导地位及其挑战和机遇。峰会强调生物技术可以帮助建立生物经济的未来产业，并指出建设未来的生物经济劳动力；促进和保护重要的生物经济基础设施和数据；跨部门合作以及监管创新地域与维持和加强生物经济至关重要。

  

3.拜登政府于2022年9月12日签署《关于推进生物技术和生物制造创新以实现可持续、安全和有保障的美国生物经济的行政命令》，启动20亿美元的“国家生物经济与生物制造计划”，旨在加强美国的生物技术和生物制造。根据该计划，美国卫生和公众服务部将投资4000万美元，扩大生物制造的作用，生产活性药物成分、抗生素以及生产基本药物和应对流行病所需的关键起始材料；国防部将启动三服务生物技术任性供应链计划，五年内投资超2.7亿美元，以更快地将研究转化为产品，并支持国防供应链生物基材料的先进开发；能源部国家核安全局将启动一项新的2000万美元的生物安全计划，以提高美国预测、评估、检测和缓解生物技术和生物制造风险的能力。此外，该行政令指示联邦机构完善其现行法规，并实施与生物经济相关的新政策。到2023年3月，美国国防部、农业部、商业部、卫生与公众服务部、能源部、国家科学基金会和美国航天局等机构需要提出建议，以扩大国内生物制造能力，生产健康、能源、农业和工业部门的产品，并缓解“外国对手”带来的风险，并指示各机构开始创建或扩大支持国内生物制造的项目，特别是在保障供应链方面。

  

**（二）英国**

  

2018年12月5日，英国政府发布《发展生物经济：到2030年的国家生物经济战略》，旨在确保英国生物经济处于世界领导地位，并消除对有限化石资源的依赖，开发经济和环境可持续的解决方案，同时提高所有城镇和社区的生产力。该战略提出四个目标：**一是**推进英国的世界一流研发和创新基础，利用更多投资将前沿理念转化为全球市场的商业成功；**二是**最大限度地发挥英国生物经济资产的潜力，提高现有可再生生物资源的生产力；**三是**为英国经济带来真正、可衡量的利益，创造就业机会，提高生产力，到2030年将生物经济的影响扩大一倍，达到4400亿英镑；**四是**创造正确的社会和市场条件，使创新的生物产品和服务能够蓬勃发展。

  

2021年11月30日，英国政府撤回该战略文件。这项战略已被《2021年创新战略》和其他支持《净零战略》目标的政府战略所取代。

  

**（三）欧盟**

  

2012年2月13日，欧盟委员会通过了“创新促进可持续增长：欧洲的生物经济”战略。2018年，欧盟更新了其生物经济战略，提出加快部署可持续的欧洲生物经济；为实现可持续发展目标作出贡献，以及促进实现《巴黎协议》的目标。相关行动计划基于三个关键目标。**一是加强和扩大生物产业。**欧盟委员会计划建立一个价值1亿欧元的循环生物经济主题投资平台，使生物创新更接近市场，并降低个人投资风险。**二是在欧洲迅速部署生物经济。**中欧和东欧地区具有巨大且未充分利用的生物质潜力，欧盟委员计划制定可持续粮食和农业系统、林业和生物基产品的战略部署议程，通过“Horizon 2020”为成员国提供资金支持，并在农村、沿海和城市地区开展生物经济发展试点行动，例如废物管理或碳农业。**三是了解生物经济的生态局限。**生态系统面临着人口增长、气候变化和土地退化等严峻威胁和挑战。委员会计划实施欧盟范围内的监测系统，以跟踪可持续和循环生物经济的进展；收集数据并确保通过生物经济知识中心更好地访问数据，增强对特定生物经济领域的理解；就如何在安全的生态限度内开展生物经济提供指导。

  

**（四）日本**

  

2019年6月，日本政府发布《生物战略2019—面向国际的生物社区的形成》。目标是“到2030年成为世界上最先进的生物经济社会”，并将日本生物产业市场规模增长到92万亿日元。该战略包括三个目标。**一是建立生物优先思想。**通过发展可持续产业和循环经济实现“超智能社会”，在充分考虑生物技术伦理、法律和社会问题的前提下，从生物技术手段优先的角度进行思考，提升社会发展活力。**二是建设生物社区。**将生物优先思想深植入社会领导者及政府层面，形成具有吸引力的国际社区，以国际合作、领域融合和生物多样性为开放式创新，成为全球数据、人才、资金和研究的催化剂。**三是建成生物数据驱动。**建立生物与数字融合的数据基础，最大限度利用生物活动数据，发展相关研究与产业，整合生产系统、建立国际标准，建设世界一流的生物大数据利用国家。

  

**（五）印度**

  

印度政府采取的有关促进生物经济发展的措施主要分为四个方面。**一是生物燃料**。印度政府于2018年发布了国家生物燃料政策，旨在提高生物燃料在经济中的适应性，并进一步修订了国家生物燃油政策，决定从2023年4月起增加生物燃料产量，并推动引入乙醇混合汽油，混合比例高达20%。**二是生物制药行业**。为鼓励生物制药行业的创业精神和国内生产，印度生物技术部（DBT）的国家生物制药使命“创新印度”计划将企业和学术界汇聚在一起。**三是推广初创公司**。印度各地建立了35个设施一流的生物孵化器，以促进创业。四是国家生物经济使命。印度科技部生物资源与可持续发展研究所（IBSD）于2016年启动了“国家生物经济使命”（National Mission on Bioeconomy），旨在利用生物资源改善农村经济。

  

**（六）中国**

  

2022年5月，国家发改委发布《生物经济发展“十四五”规划》，这是中国首个五年生物经济规划。《规划》预测，到2035年，中国生物经济综合实力将跻身世界前列，基本形成技术水平领先、产业实力强、一体化水平。应用广泛、资源保障强、安全风险可控、制度体系健全的新发展形势。《规划》提出，**一要**促进医药卫生产业发展，加快疫苗研发和生产技术迭代升级，提高应对重大严重传染病的能力；**二要**推动基因检测、生物遗传学等先进技术与疾病预防的深度融合，提高疾病诊断能力和临床医学水平；**三要**有序发展生物育种技术和合成生物学技术，探索开发“人工蛋白”等新食品，提高粮食等重要农产品的生产能力和质量；**四是**推动生物能源和生物环保产业的发展，积极发展生物能源。此外，《规划》将从加速生物技术，增强健康产业的权能；加快生物育种技术，赋能生物农业产业；加速生物制造技术，为生物能源和生物环境保护产业赋能；加速信息技术，为生物信息学行业提供支持四个方面部署和培育生物经济支柱产业。

**二、国际组织对于实施生物经济战略的建议**

  

**联合国（UN）**于2015年通过了《2030年可持续发展议程》。该行动计划涵盖了17个可持续发展目标（SDG），其中关于生物经济的主要可以分为四个领域：**一是**生物经济影响到消除贫困、零饥饿和减少不平等的实现；**二是**生物经济涉及清洁用水和卫生、可持续城市和社区以及负责任的消费和生产等目标；**三是**生物经济推动可持续工业和基础设施，并促进经济增长和工作机会；**四是**生物经济促进健康、福祉和气候行动，有利于水下生命和陆地生态系统生命。

  

**二十国集团（G20）**于2020年11月发布《生物经济：可持续发展战略》。G20作为全球经济和政治合作的首要论坛，致力于促进对生物经济目标和战略的共同理解，并提出三个方案。**一是协同努力，分享和传播与生物经济有关的现有信息和经验。**为生物经济政策和投资达成更广泛的共识奠定基础，同时促进对生物经济相关技术的研发，推动生物经济产品的市场开发。**二是设定用于指导决策和投资以及监测目标进展的可靠的生物经济指标**。包括生物经济对国家经济和社会目标，如经济增长、就业、粮食安全和出口的贡献；生物企业战略组成部分的基本数据，如可用性、投资和能力；生物经济部门与传统经济部门之间联系的性质和程度；环境绩效指标。**三是综合生物经济决策的最佳做法。**目前，美国、英国、德国、西班牙等G20国家已将生物经济纳入其发展战略中，G20呼吁国际合作组织联盟根据这些国家的经验和信息，制定生物经济最佳做法的具体章程。

**三、评述**

  

近年来，生物经济的重要性在全球范围内显著增加。麦肯锡全球研究所预测，生物经济在未来10-20年内可能产生约2-4万亿美元的年度直接经济影响。当前，全球经济中高达60%的实物投入，如木材、牲畜、塑料和燃料等，可通过生物技术获得；高达30%的私营部门研发支出集中于生物学相关产业。生物经济涉及生物制药、生物塑料、复合材料、生物燃料、生物基化学品和高价值食品的生产以及生物信息学或环境工程等生物知识的应用，因而具有广泛的潜在效益，是实现联合国可持续发展目标的重要工具，也是解决疫情、气候问题、自然资源和能源匮乏、粮食不安全等多重挑战的主要驱动力。根据联合国的数据，到2050年，全球人口估计将达到90亿，这将要求粮食和能源生产增加50%。未来，生物经济将帮助确保粮食和营养安全；可持续地管理自然资源，减少对不可再生或不可持续资源的依赖；适应和制约气候变化；加强国家竞争力，创造就业机会；并为监测、检测和应对大流行，以及开发更好的预防工具提供最佳资源。

**研究所简介**

  

国际技术经济研究所（IITE）成立于1985年11月，是隶属于国务院发展研究中心的非营利性研究机构，主要职能是研究我国经济、科技社会发展中的重大政策性、战略性、前瞻性问题，跟踪和分析世界科技、经济发展态势，为中央和有关部委提供决策咨询服务。“全球技术地图”为国际技术经济研究所官方微信账号，致力于向公众传递前沿技术资讯和科技创新洞见。
