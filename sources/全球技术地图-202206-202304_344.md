# 俄罗斯利用“平行进口”规避西方制裁

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1OTExNDY1NQ==&mid=2651597118&idx=1&sn=35411db5d7b704275940024bcb0ec65f&chksm=f1855acec6f2d3d87419642fff4b88a707dfa402736d17b02e182bc8b2a5863b02a8f6bff048&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1OTExNDY1NQ==&mid=2651597118&idx=1&sn=35411db5d7b704275940024bcb0ec65f&chksm=f1855acec6f2d3d87419642fff4b88a707dfa402736d17b02e182bc8b2a5863b02a8f6bff048&scene=27#wechat_redirect)

![](../Images/580fed2992045ce67d39dcf0fb781106.png)

**自2月24日俄罗斯对乌克兰发起特别军事行动以来，美西方对俄实施了史无前例的大规模制裁。大批跨国公司宣布永久或暂停在俄商业活动，俄陷入严峻的“进口危机”，面临生产和生活资料严重短缺的局面。**

  

  

俄信用评级机构ACRA预计，2022年俄进口总量可能下降20%～30%，其中设备进口降幅将高达65%。为应对制裁压力并缓解外贸危机，俄“平行进口”合法化的进程明确提速。3月29日，俄总理米舒斯京签署政府决议，确定了“平行进口”合法化的可能性。6月21日、22日，俄国家杜马和联邦委员会先后批准了“平行进口”商品合法化法案。6月28日，普京总统签署该法案。9月2日，俄经济发展部宣布，将37项范围及措施期限延长一年，其中就包括“平行进口”政策。俄工业和贸易部强调，“平行进口”并不意味着盗版的合法化，该措施涉及进口原装商品，但通过替代供应渠道。

俄罗斯首批“平行进口”清单涵盖化妆品、化工产品、服装、车辆等50类商品。图为2022年8月19日，俄罗斯莫斯科的一家超市。  

何为“平行进口”

所谓“平行进口”，是指一国进口商未经知识产权权利人授权或同意，将在其他国家或地区合法投放至市场的产品进口至该国的行为。国际贸易中的“平行进口”问题与知识产权（主要是商标权）的权利用尽原则紧密相关，要解决“平行进口”的合法性问题，就必须肯定知识产权（主要是商标权）权利用尽原则的合理性。在商标权领域，权利用尽原则主要是指商标权人对于自己生产或经其许可生产的商品，在第一次合法投放市场后，商标权人的商标权即被认为已用尽，商标权人对该商品丧失控制权，任何其他有关该商品的进一步转售、分销行为，该商标权人均不得通过商标专用权进行限制。在没有权利用尽的情况下，权利人拥有垄断权和限制其商标商品进入二级市场的权利。

世界贸易组织（WTO）《与贸易有关的知识产权协议》第六条规定，成员国对其将遵守的权利用尽原则享有自由裁量权，主要包括国际、区域和国家用尽原则。国际用尽原则是“平行进口”合法性的理论基础，即产品在世界任何国家进入流通后都可视为权利用尽；国家用尽原则明令禁止“平行进口”，否则一律视为假冒产品（即使是拥有质量证书的正品）；折衷方案是区域用尽原则，即在某一国家集团中的任何一国进入流通后视为权利用尽，可在特定领土范围内转售。“平行进口”是稀释知识产权的重要因素，在经济全球化与电子商务迅速发展的背景下，一国很难维持严格的国家或区域用尽原则。

苏联解体后，“平行进口”在俄一度经历从合法到非法的转变，既折射出俄对经济转型道路的探索和融入世界经济的努力，也反映了其经济主管部门之间及其与跨国企业集团的博弈。1992年《俄罗斯联邦商标、服务商标和产地名称法》确定了俄知识产权的国际用尽原则。在俄政治经济极度不稳定时期，这种“强用尽”原则具有一定的盲目性，旨在全面开放俄国内市场，引入美西方国家通用的法律和监管手段，其结果是跨国公司于该时期在俄进行了大规模的本土化投资。然而，伴随“全盘西化”经济转型模式的失败，俄进入政策调整期。2002年，俄通过立法确立了对于“平行进口”的“国家用尽”原则，对非法使用品牌的行为最高处以20万卢布的罚款。2010年起，在俄白哈关税同盟建立、俄加入世贸组织、欧亚经济联盟单一经济空间形成等因素影响下，俄又针对“平行进口”部分放开了“国家用尽”原则。

2014年克里米亚危机爆发后，由于外部形势恶化和西方制裁升级，俄经济安全面临威胁，在“平行进口”问题上出现了自由化趋势，催生出两种发展路径：一是维持国家—区域混合原则，使“平行进口”部分合法化，解决生产资料不足或价格虚高以及涉及生命健康的产品短缺问题。二是逐步过渡到国际原则。俄联邦反垄断局是“平行进口”合法化最积极的倡导者，先后两次制定了相关法律草案。

俄经济发展部、工业和贸易部以及大型企业和企业协会反对“平行进口”合法化，主要出于保护国内工业的考虑，担心“平行进口”造成权利人与其他进口商之间的利润再分配，降低其生产本地化的激励，加剧俄经济中的投资不足。此外，消费者购买劣质、过期、假冒产品以及缺乏保修服务的风险增加，也可能助长“影子经济”的发展势头。

  

遏止生产和生活物资短缺

在当前应对美西方制裁的过程中，俄进口不足已经导致生产和生活资料短缺，俄消费者物价指数(CPI)和生产价格指数(PPI)居高不下。俄创纪录的经常账户盈余持续推动本币升值，出口竞争力被严重削弱，财政预算收入随之受到冲击。俄央行坚持通货膨胀目标制，关键利率将保持在适度偏紧的水平，从而增加了企业尤其是中小企业融资成本。在这种情况下，俄急需解决市场商品短缺的问题，确保国民经济正常运转，创造经济增长的投资潜力。

俄首批“平行进口”清单涵盖化妆品、化工产品、服装、黑色和有色金属、车辆等约200个品牌的50类商品。清单依据两种方式编制：一是有针对性的进口许可，包括设备、汽车和某些品牌的化妆品；二是广泛、非排他性的许可，包括衣服、鞋帽、雨伞、手提箱包、肥皂和武器等。农产品（树木和花卉除外）不包括在内，农业部坚持实现百分之百的进口替代。俄工贸部强调，将每季度或每两个月审查一次清单，依据国内市场产品监控情况进行增减。俄官方称，截至今年8月中旬，俄已“平行进口”商品65亿美元，到2022年底可达160亿美元。

“平行进口”有助于俄避免生产和生活资料短缺，但由于交易成本较高，“平行进口”商品的市场价格仍将高于战前。中期内，“平行进口”还将有助于削弱卢布币值并抑制物价上涨，推动俄重建对外经济伙伴关系。此外，很多国家厂商仍有兴趣恢复甚至扩大对俄供货。如在中国生产的优质消费品或高科技产品，在土耳其、塞尔维亚、阿联酋等国生产的家电、生产设备和组件等，可以以相对较小的批次运往俄罗斯。因担心“次级制裁”而拒绝在俄销售的企业，可借助“平行进口”寻找回归俄市场的合法路径，包括利用欧亚经济联盟的经销商网络。还有一些企业依然保持正常运营，如韩国三星在俄卡卢加州的工厂，打算将全部制成品运往中亚国家再转运回俄。

目前看，“平行进口”合法化依然是俄应对制裁的临时措施。“平行进口”政策的落实尚有赖于俄各政府部门尤其是监管部门的密切配合，有赖于企业层面作出更为积极的回应，效果和前景有待继续观察。
