# 日本量子产业早期布局！量子材料等十大量子技术创新基地与主要研究项目全览

**近年来，日本多次表示自身量子研究落后于欧美和中国的紧迫感，同时采取一系列举措，加速研发步伐。2020年1月，日本政府公布《量子技术创新战略》，作为量子技术的研发战略；2021年2月，设立了8个“量子技术创新基地”。同年9月，日本产业界成立了“量子技术新产业创造协议会”（Q-STAR），有组织的推进量子技术研发及产业化的新体制建设；2022年4月，日本内阁府公布《量子未来社会愿景》并与《量子技术创新战略》并行推进。本文就此全面梳理了日本“量子技术创新基地”的最新布局与构成，仅供参考。**

  

  

1.背景

**日本量研新设“量子功能创制研究基地”**  

根据日本4月刚公布的《量子未来社会愿景》，为强化“量子技术创新基地”的体制，日本量子科学技术研究开发机构于2022年5月26日**新设“量子功能创制研究基地”， 以研发最先进的量子材料。**

1.1 目的

**量子功能创制研究基地：**旨在通过高精密的量子束技术进行量子功能开发和高级化，研发世界最尖端的**可发挥高性能量子功能的量子材料，****建设世界领先的高级量子材料供给基地，提供稳定的供给和研发；**此外，还负责基于《量子技术创新战略》推进量子技术研发，以及基于《量子未来社会愿景》推进量子技术的社会实践。

1.2 量子材料

量子材料是制造量子计算机、量子传感、量子网络等量子器件所需的基础材料，用于发挥量子功能。下图为量子材料功能研究项目图示，**具体内容包括：量子传感项目、二维物质自旋光子学项目、激光冷却离子项目、光自旋量子控制项目、量子材料理论项目、稀土类量子器件项目、量子材料超微细加工项目等。**![](../Images/2ce7da33851fe821bc5c885cfcf3c429.png)

1.3 职能

“量子功能创制研究基地”的职能包括：**与国家研究项目的合作，****例如文部科学省Q-LEAP（光·量子飞跃旗舰计划）量子测量传感等；与产业界的合作，范围包括：材料、汽车部件、量子产业等；与研究机构和大学的合作，例如产业技术综合研究所、京都大学等；与国外研究机构的合作，例如斯坦福大学等。**

![](../Images/e2bad5909d8f2e0e2b591e573673d122.png)

**图：“量子功能创制研究基地”的职能图示**  

2.创新基地

  
**量子技术创新基地**

“量子技术创新基地”是根据**日本《量子技术创新战略》于2021年2月成立，当时共设置了8个基地，分别为：**

*   核心组织兼量子计算机开发（理化学研究所）
*   量子计算机应用（东京大学—企业联合）
*   量子器件开发（产业技术综合研究所）
*   量子软件研究（大阪大学）
*   量子安全（情报通信研究机构）
*   量子生命（量子科学技术研究开发机构）
*   量子材料（物质材料研究机构）
*   量子传感器（东京工业大学）

2022年5月，随着“量子功能创制研究基地”的新设，**“量子技术创新基地”已经扩充到10个研究机构及大学参加，新增的基地有：**

*   由冲绳科学技术大学院大学负责的国际教育研究基地（暂称）
*   由东北大学负责的量子解决方案基地（暂称）。

![](../Images/8fe2b95503a9c8091fe0fb2930463112.png)****日本内阁府于2022年4月公布的《量子未来社会愿景》中，“量子功能创制研究基地”的定位和“量子技术创新基地”的整体情况****

2.1 原有8座基地简介

**2.1.1 日本理化学研究所: 量子计算机开发**

*   集结该所在量子技术和计算科学方面的力量，以实现和确立量子计算机系统为目标，形成以超导为首的量子计算机方面的“量子技术创新基地”。
    
*   作为所有基地的核心，形成对“量子技术创新基地”的支持
    
*   以量子比特的集成为目标的芯片开发
    
*   与富岳等超级计算机并用
    
*   以通用型量子计算机为目标的系统安装（Q-LEAP）
    

**近期成果**：世界上首次开发出能够在逻辑量子比特间进行运算的低温环境下的量子纠错方法、发现有限温度状态下量子纠缠的普遍性质等。  
**2.1.2**** 日本量子科学技术研究开发机构：量子生命科学基地**

*   强化研发基础，在量子生命科学方面形成“量子技术创新基地”
    
*   与国内外的大学、研究机构、企业等合作，实施基础研究、技术实践、知识产权管理、国际人才培养等
    
*   量子生命科学研究中心的运营
    

**近期成果**：开始制作新一代重粒子线癌症治疗装置“量子手术刀”实证机等。**2.1.3 日本情报通信研究机构（NICT）：量子安全基地**

*   形成量子安全方面的“量子技术创新基地”
    
*   利用量子密码通信的技术优势，进行相关研发、技术实践、国际标准化、社会实施、人才培养等
    

**近期成果**：发布“使用第三方认证和QKD网络的长期安全分布式存储”等。  
**2.1.4 日本产业技术综合研究所（AIST）：量子器件开发基地**

*   强化该所的研发基础，开发量子器件，形成该方面的“量子技术创新基地”
    
*   在量子计算或量子传感等量子器件方面，与企业、大学、研究机构合作实施研发
    
*   退火型量子计算机、超导门型量子计算机、量子测量・传感
    

**近期成果**：“超导量子电路集成化技术的开发”等。**2.1.5 日本物质材料研究机构（NIMS）：量子材料基地**

*   强化该机构的研发基础，在量子材料方面形成量子技术创新基地
    
*   应用该机构的优势——薄膜生长技术和单晶制造技术等，与大学和研究机构合作研发量子材料，如量子传感器用材料和量子密码通信用材料等
    
*   量子磁传感用金刚石单晶制造等
    
*   物质拓扑探索及创新的光量子功能开发  
    

**近期项目**：“量子物质特性群组”等。**2.1.6 东京大学—企业联合：量子计算机应用**  

*   目标是在世界上率先实现量子计算机的社会实践，促进与该技术有关的产业界学术界及政府的合作
    
*   量子创新计划协议会（2020年7月设立）：负责量子计算软件应用程序、量子硬件及下一代量子计算机开发相关的基础科学技术信息交换。主要会员包括：东京大学、庆应大学，作为开发商企业的东芝、日立、日本IBM，以及作为用户企业的瑞穗FG、三菱化学等
    
*   IBM东大实验室：集中量子计算相关科技，使用IBM商用量子计算机构建量子生态系统
    

**近期项目**：量子计算机安全的加密方式、量子动力学处理器等。**2.1.7 大阪大学：量子软件研究基地**

*   目标是推进量子机械学习和量子化学计算等应用程序的研发和社会实践等
    
*   量子化学和机械学习等量子计算机应用的开拓：实施机构有大阪大学、东京大学、早稻田大学、NICT、NTT等
*   量子软件的开发平台构筑、社会实践和普及等：实施机构有大阪大学、丰田通商、亚马逊网络服务、日立制作所、富士通研究所等

**近期成果**：开发新型量子点，光子—自旋量子接口转换效率提高3倍。**2.1.8 东京工业大学：量子传感器基地**

*   推进起用固体、原子、离子等的量子·准量子传感器的社会实践
    
*   开发超高灵敏度量子传感器：实施机构有东京大学、产综研、量研、日立等
*   使用量子及准量子惯性传感器的超高精度惯性导航装置的开发等：实施机构有大阪大学、产总研、日本航空电子工业、三菱重工业等

**近期项目**：通过固体量子传感器的高级控制创造新型传感器系统。

2.2 基地的变化

变化主要包括两个方面，即现有基地的功能强化及新基地的设置。  
**2.2.1 功能强化**

**理研：核心基地功能得到强化，以期推进世界最尖端研究。**

**产业技术综合研究所（AIST）：**基地名称从“量子器件”变更为“全球产业支援基地”（暂称）；与国内外企业等合作，进行量子芯片和周边机器等的试制、制造、评估；**以全球的视点对产业界进行综合支持。**

**量子科学技术研究开发机构（QST）：**在原有量子生命研究方向之外，新设“量子功能创制研究基地”（暂称），对量子材料进行世界最尖端的研究开发，以发挥高性能量子功能；**建设世界领先的高级量子材料的稳定供应基地。****2.2.2 新基地的设置****东北大学：“量子解决方案基地”（暂称），**满足企业需求；对有价值的解决方案研发提供支援；承担产业界人才培养。近期成果：在数百纳米的半导体量子结构中发现偶数分母的分数量子态。**冲绳科学技术大学院大学：“国际教育研究基地”（暂称），**聚集国内外优秀的量子专家，在推进国际联合研究的同时，实施相关技术的国际教育，担负世界最尖端的国际性研发和教育。近期项目：量子系统研究单元、量子比特和时空单元等。

3.简评

  
日本近年来屡屡强调量子研究落后的紧迫感，称国外谷歌等企业正在加速量子计算机研发，世界范围内量子计算机的实用化正在加速，在国际竞争如此激烈的情况下，日本积极制定政策以加强量子计算机的研发，产业界、学术界、政府须联合强化产业竞争力。《量子未来社会愿景》中称，为了在量子领域激烈的国际竞争中日本不会落后，须引进尖端技术；在加强国际研发和教育等的同时，须本着国际水平建立优良的基地，以提高日本的国际竞争力。**日媒称，日本已在人工智能和“5G”方面落后；在量子通信和密码学研究方面具有一定的优势，但在迈向实用化和产业化方面，日本落后于中美等国。**
