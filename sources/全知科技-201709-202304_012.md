# 全知科技荣获“2022年度网络安全跨越成长新锐奖”

为搭建网络安全行业政产学研用金需求对接平台，充分展示协会成员在推动企业发展、坚持技术创新、强化服务支撑等方面的突出成绩，浙江省网络空间安全协会开展了**2022 年度网络安全行业发展成果评选活动**。

![](../Images/3587a8657bd44a20fc6d04a9bce3b0d0.png)

图源：浙江省网络空间安全协会

依托协会专家技术委员会组织多名专家的严格评选，**全知科技凭借领先的产品创新能力和技术实力得到业内专家一致认可，成功获选“2022年度网络安全跨越成长新锐奖”。**

“网络安全跨越成长新锐奖”的评选，旨在展示能够克服时艰，积极推动企业稳步发展、强化技术创新升级、取得卓越成果的高成长性企业。

  
  
全知科技申报的**“全链路数据流动安全管理平台”**，聚焦企业数据流动场景风险监测难题，整合了数据分类分级、接口安全管理能力、数据链路风险动态识别等关键能力，构建了极具特色的智能化数据流动风险监测平台。目前，产品已获得中国信通院“星熠”案例、大数据技术标准推进委员会“星河”案例、ISC 2022网络安全创新能力百强等多项荣誉，并成功应用于运营商、金融等行业的数字化转型。  
未来，全知科技将继续坚持技术创新，丰富产品体系布局，为客户提供领先、专业的数据安全产品及服务，构建更全面、高效的数据安全防护体系。
