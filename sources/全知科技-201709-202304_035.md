# 聚焦 WOT·2022｜以风险驱动的数据安全体系建设

![](../Images/b64aad8efadbe3a33d45d1f7365e633e.png)9月3-4日，2022· WOT全球技术创新大会在北京正式举办，本次大会汇聚了各行业的顶尖技术领袖，围绕国内外技术领域的热点和趋势，深度分享了独家技术干货和实践经验。![](../Images/d5ed0d0afef33966edd124d642997530.png)自《数据安全法》落地实施以来，各行业对数据安全治理的迫切性和需求性都在上升；而随着数字经济的快速发展，数据面临的风险趋势也在向复杂、隐蔽等方向发展，如何有效建设数据安全体系是迫在眉睫的命题。9月4日，在「数据安全的治与理」专场，**全知科技创始人兼CEO方兴**结合《数据安全法》的技术体系要求、治理路径等，为大家分享了**《以风险驱动的数据安全体系建设》**的主题演讲。**0****1****《数据安全法》下的技术体系要求**随着互联网、大数据等技术的高速发展，海量数据增长迅速，数据泄露风险也随之严峻，对国家安全、社会稳定产生了深刻影响。在《数据安全法》出台的背景下，数据安全治理已成为“数字化发展”不可忽略的底层建设之一。

  

![](../Images/3c1be6a55a7702c2d4c3522c3885e9fa.png)会上，方兴从法律监管层角度切入，深度解析了《数据安全法》对监管部门相关数据安全职责的具体要求、对数据处理活动单位的数据安全保护的具体义务等，提出了应以“**分类分级为纲，数据风险为领**”为核心技术路径有效落地安全能力建设。**02****数据&风险驱动的数据安全治理框架**数据流动有多种视角。在传统安全的体系里，会用数据生命周期的不同阶段如采集、存储、传输、使用来描述数据流动，但是传统的数据生命周期模型存在几个问题：  

*   传统数据生命周期提供的是阶段的最佳安全实践经验，难以替代数据安全治理的体系设计；只有紧密围绕设计里的风险进行管理措施细化，才能将管理和风险威胁结合起来。

  

*   其次就是在数据处理活动的划分上是过程视角。传统的数据生命周期模型对数据生命周期的划分是面向过程而不是面向风险，看不见数据风险的全貌，无法完全覆盖“数据安全”的核心要求。

  
数据安全涉及数据可用与风险的平衡，需要结合关键风险和威胁进行针对性缓解。方兴表示，针对数据流动过程中面临的安全挑战，应该从风险威胁出发，设计**以“数据&风险为驱动”的数据安全治理框架**。  
![](../Images/7269550524a602ee42a60c4333f2054b.png)  
根据《数安法》要求，如果要落实好数据安全保护，其本质就需要对数据进行全流程的刻画和保护。依据全知科技“数据流动可见风险可知”模型，进行数据全流程动态的风险映射，将合规风险、安全风险以及质量和管理风险映射到关键数据要素中，做好数据流动节点、数据去向等行为审计，实现数据流动可见。  
![](../Images/1903bbd771bc578d034aaa535a72eeb6.png)数据作为支撑数字时代稳定运行发展的关键生产要素，其重要性不言而喻。面对仍然严峻的数据泄漏等安全风险，企业应该引起足够的重视并积极做好数据安全能力建设。![](../Images/73618312ec652153bb744743f9e73b9f.png)![](../Images/e6fbd99edc2926b19c84f569027416a1.png)
