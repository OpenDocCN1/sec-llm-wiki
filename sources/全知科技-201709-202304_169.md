# 脱颖而出！全知科技团队挺进全国电信和互联网行业网络安全管理职业技能竞赛全国总决赛

2020年11月6日，**2020年全国电信和互联网行业网络安全管理职业技能竞赛（第九届）**线上选拔赛正式开启。经过激烈比拼，最终由各区域赛场遴选出了40支优秀代表队晋级全国总决赛。其中，**来自****全知科技（杭州）有限责任公司的“小试牛刀”团队成功晋级40强，强势挺进全国总决赛！**

  
  
  

  

![](../Images/0eceb41bed6a818494055fa4c4c12e0c.png)

  

本次竞赛由中国通信企业协会和中国国防邮电工会全国委员会联合主办，中国信息通信研究院、中国电信集团有限公司、中国移动通信集团有限公司、中国联合网络通信集团有限公司等单位协办，中国通信企业协会通信网络安全专业委员会、中国国防邮电职工技术协会等单位承办。本次赛事吸引了基础电信运营企业，互联网企业，网络安全企业,相关高等院校、职业院校（含技工院校）等单位积极参与，赛事覆盖全国各个省份，业界关注度极高，是全国网络安全从业者的一大盛事。

  

![](../Images/abceffd8852eb0db5d491174d544728d.png)

  

网络安全是万物互联时代的基石。在智能制造、数字化转型升级的今天，不论是工业生产还是日常生活，对网络安全保障的需求都在增强。而进一步推动网络安全事业发展的关键在于加快网络安全人才的培养，本次大赛亦是一个全国网络安全专业人才的交流平台。此次，**全知科技“小试牛刀”团队能从众多竞争者中脱颖而出，充分展示了全知科技队员对网络空间安全的综合攻防能力和在安全工作岗位的技术水平和运维能力，也体现了全知科技对于高素质专业人才的培养能力。**

    

全国总决赛定于2020年12月19日-22日在广东省广州市举办。全知科技“小试牛刀“团队将全力以赴，角逐总决赛的五大奖项。点击“阅读原文”了解具体的决赛安排吧！

全知科技是一家聚焦数据保护的公司，以业务零打扰的方式，检测和修复重点场景隐私数据保护的缺陷，全生命周期，感知和响应隐私数据的风险，监控企业隐私数据的内部使用和外部共享等关键场景，从而帮助企业找到安全与业务的平衡点，成为具有社会责任感的企业的最强助力。
