# 全知科技受邀参与中国互联网协会网络数据安全合规性评估服务工作组及App数据安全测评服务工作组成立大会并作为优秀成员代表发言

**2020年9月27日，中国互联网协会网络数据安全合规性评估服务工作组及App数据安全测评服务工作组成立大会在京召开。**工业和信息化部、中国互联网协会、中国信息通信研究院、中国电子标准化院、中国软件测评中心以及在App个人信息保护方面有突出实力的安全服务提供商参加会议，**全知科技作为在数据安全和App个人信息保护方面的业内领先企业，受邀参加大会，并作为工作组代表成员单位进行发言。**

![](../Images/13d5ccc193c607cedba0b5c272a45806.png)![](../Images/bd8c2185e7afd70cfa6cfade43471d42.png)

大会现场图

  

  

近年来，中国互联网协会在工业和信息化部网络安全管理局的指导和支持下，在网络安全领域开展了一系列工作，取得了良好的效果。并且随着数据被明确定义为生产要素，数字流动中的安全已成为了数据安全全新的课题，也就提出了数据安全合规方面的更高要求。App数据安全作为广大人民群众在近年来感受最直观的数据安全领域，也需要更专业的服务规范和标准指导。网络数据安全合规性评估服务工作组及App数据安全测评服务工作组将作为研究发现、梳理总结、扩大推广的核心力量，汇集组内各成员单位和行业专家的能力与智慧，全力支撑我国的数据安全发展要求。

  
![](../Images/13d5ccc193c607cedba0b5c272a45806.png)![](../Images/97747a982c700f18244501efd21e98d0.png)

全知科技（杭州）有限责任公司  朱通发言

  

  

朱通在发言中，从数据安全保护视角，结合全知科技在数据安全领域的丰富实践经验，分析了当前企业在数据安全合规和App个人信息保护中遇到的主要问题和风险，梳理了数据安全治理的思路和实践方法，并在会议上提出了对工作组未来工作开展的倡议，受到了参会成员的一致肯定。

全知科技作为专业的数据安全产品和服务提供商，一直致力于通过服务和技术手段帮助客户落实数据安全合规要求。在众多国家标准制定、安全研究和客户项目实践中，全知科技积累了丰富的数据安全合规经验，覆盖管理和技术的不同视角，并充分考虑数据生命周期过程中各个阶段的场景和应用，不但能提供适用于不同行业的数据安全合规指导，也能提供数据安全风险管理的诸多技术能力，帮助企业自身及时发现、处置数据安全风险，在安全合规的基础上，全面提升数据安全管控能力。  

![](../Images/5b340489c2de9b453765ef29164a3995.png)

  

同时，全知科技持续关注App个人信息保护的研究，深度参与多个国家标准的编制工作，充分结合自身在数据安全领域的技术积累，于2020年初推出了全知科技App个人信息合规评估服务。自该服务推出以来，全知科技多次协助公安、网信、行业监管部门等开展App个人信息安全合规评估，以此积累了丰富的评估经验。目前为政府、运营商、运输、零售、金融、制造等不同行业的多家客户直接提供评估服务，不仅帮助客户在App客户端识别存在的个人信息安全违法违规问题，更能通过充分结合自身技术优势，将App个人信息安全评估扩展到App服务端，实现了前后端的全面覆盖的风险识别和整改指导，为企业App相关业务的合法合规提供全面地保驾护航。
