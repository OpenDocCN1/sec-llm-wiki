# 2018数据安全领域建设及实践分享会成功举办

![](../Images/79b0f96680d45c3b3756f3c3a9e385e8.png)

    10月26日，由全知科技主办的“数据安全领域建设及实践分享会”在北京举行。活动期间来自业界数据安全领域的权威专家来到现场做特邀分享，与现场100多位参会嘉宾共享数据安全领域干货、共商安全建设大计。

  

    此次会议由全知科技创始人方兴主持，百度资深数据安全专家孙硕、全知科技CEO方兴、阿里巴巴数据安全专家薛勇、VIPKID高级安全专家靳晓飞分别进行主题演讲，并交流出了不少火花，为与会者带来不少启发。

![](../Images/690f941b090c9a54662c4c1f53a61a9a.png)

会议现场照片

**方兴：DT时代的数据流动风险防治**

 

    全知科技CEO方兴以“DT时代的数据流动风险防治”为主题，介绍了DT时代数据流动带来的很多安全风险。随着大型互联网业务规模迅猛增长，企业一方面要应对日益激增的数据量，另一方面还需打造更加安全的技术体系，避免海量数据泄露。而行业内人员众所周知的是在企业敏感信息泄露事件中，内部人员泄露占有很高的比例。

    针对企业“内鬼”，全知科技特研究出了相对应的数据安全与合规解决方案，即在应用系统环境部署数据安全管理平台，有效监控系统中的数据流向和敏感信息访问，准确掌握数据流动过程中的安全状态，及时发现数据安全风险事件并实时告警、记录，同时进行安全事件定位分析，事后溯源追查，满足合规性审计要求，解除企业面临的“内鬼”安全威胁与风险。

 

![](../Images/07abb3ef012d691e44d7d983e2f41090.png)

全知科技CEO方兴  

  

**孙硕：甲方数据安全建设的困局与破局思考**

    百度安全专家孙硕抛出了数据安全建设时最常遇到的四个困局：数据安全建设难以面面俱到，如何入手？无法驱动业务，安全建设举步维艰？没有问题不重视，出了问题被追责，为何总是给自己出难题？漏洞百出，防不胜防，如何做好安全管理？

    随后针对每个困局做出了详细分析并总结了破局思路跟与会人员分享。呼吁企业做好内部防攻措施，要实现以业务战略达成为驱动、围绕风险，利用抓手推动的安全举措落地，来打造出公司安全大环境，建立安全威慑力，同时还需要针对数据跨越安全信任边界的行为及关键节点布控，采用一定的工具，对数据环境做到可控、可审、可追溯。随后跟大家分享了百度数据安全能够实施成功的四大要素：战略化、全员化、专业化、系统化，并要时刻记着自己还在路上。

 

![](../Images/bc067a1272d1595f04cdfd2bea00017c.png)

**薛勇：数据安全能力成熟度模型及其建设实施指南**

    阿里巴巴薛勇分享了《数据安全能力成熟度模型及其建设实施指南》，通过介绍指南编写背景和目的，分析指南详细结构及体系框架让大家更了解指南的重要作用。

    该指南由阿里巴巴数据安全研究院发起，作为DSMM配套文档，充分定义级（3级）为目标，结合数据安全合规要求和组织的业务发展需求，从组织建设、制度流程、技术工具和人员能力等四个方面整体框架设计和规划入手，对DSMM的安全域设置目的和要求进行详细解读，并辅以实践案例，为各行各业具体组织的数据安全能力建设提供实践参考。同时表示未来将会邀请各业更多代表参与建设，开放公共平台共同建设和维护，一起探索更有效方法实现数据安全。

 

![](../Images/14377796fb272a28d6a4453b7ddd627a.png)

阿里巴巴数据安全专家薛勇

 

**靳晓飞：VIPKID数据安全探索与实践**

    VIPKID靳晓飞表示当下有由于时代的变化、行业的变革、个鬼的驱动及用户的意识增强导致数据安全越来越受重视，在线教育行业对于数据安全的关注点也不在少数，包括用户数据、企业数据、员工数据、供应链数据、及一些会对公司带来安全事件的数据。

    随后通过分析VIPKID自身关注用户手机号安全保护工作的重要性，对手机号泄漏风险进行详细评估，并联合全知科技做出了对应的解决方案，方案实施后做到了保证数据不被泄漏或被泄露后能及时发现并具备数据泄露溯源能力，一步定位到数据泄露人、系统和还原数据泄露过程，防治再次出现同样事故，让公司的数据安全管理工作做到滴水不漏。

 

![](../Images/0129eecde8ef07ba174815688f0a2bc9.png)
