01—漏洞描述  

Grafana是一款用Go语言开发的开源数据可视化工具，可以做数据监控和数据统计，并带有告警功能。Grafana专注于时间序列图表分析，支持多种数据源，如Graphite、InfluxDB、Elasticsearch、Mysql、K8s、Zabbix 等。  

2021年12月3日，GrafanaLabs发布安全公告，Grafana 中存在一个目录遍历0 day漏洞（CVE-2021-43798），允许访问本地文件，其CVSS评分为7.5。  

12月7日，该漏洞的技术细节和PoC已在互联网上公开，GrafanaLabs 也已发布修复程序。该漏洞的URL路径涉及已安装插件的插件ID，由于每个Grafana实例都有预装的插件，如Prometheus插件或MySQL插件，因此每个实例都容易受到攻击。

  

     影响范围：  

*   Grafana 8.3.x < 8.3.1
    
*   Grafana 8.2.x < 8.2.7
    
*   Grafana 8.1.x < 8.1.8
    
*   Grafana 8.0.x < 8.0.7
    

  
     安全版本：

*   Grafana 8.3.1  
    
*   Grafana 8.2.7  
    
*   Grafana 8.1.8
    
*   Grafana 8.0.7
