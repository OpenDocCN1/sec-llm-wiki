**1、《中华人民共和国个人信息保护法（草案）》首次亮相**

**关键词：****个人信息保护法;审议;违法惩处**

**摘要：**备受关注的个人信息保护法草案于10月13日提请十三届全国人大常委会第二十二次会议审议。草案共八章七十条。从内容上看，草案聚焦目前个人信息保护的突出问题，落实个人信息保护责任，加大违法行为惩处力度。本文对草案进行了详细解读。[【阅读原文】](https://mp.weixin.qq.com/s?__biz=MzIyNjE0NTQ2OA==&mid=2651237994&idx=1&sn=a5d0844a791f8a096814b0e841b7b79d&scene=21#wechat_redirect)

**2、中国信通院联合发布《5G应用创新发展白皮书——2020年第三届“绽放杯”5G应用征集大赛洞察》**

**关键词：******5G;应用;白皮书****

**摘要：**中国信息通信研究院、5G应用产业方阵（5GAIA）和IMT-2020（5G）推进组共同发布了《5G应用创新发展白皮书——2020年第三届“绽放杯”5G应用征集大赛洞察》。白皮书聚焦全球及我国5G融合应用发展态势，重点发布第三届“绽放杯”5G应用征集大赛项目的深度洞察，并对5G十大重点应用（智慧工厂、智慧矿山、智慧港口、智慧医疗、智慧电网、智慧交通、智慧安防、智慧教育、智慧文旅及智慧城市）进行深度分析，研究提出“3+6+X”5G融合应用体系2.0版本和5G应用“4＋1”技术体系架构，并分析5G应用发展三步走路径和三种主要商业模式形态，最后，提出了我国5G融合应用发展建议。[【阅读原文】](https://mp.weixin.qq.com/s?__biz=MjM5MzU0NjMwNQ==&mid=2650786914&idx=1&sn=07d0ffbe751f985fc4e9653022cca848&scene=21#wechat_redirect)  
信息来源：中国信通院CAICT

发布时间：2020-10-15

  

**3、美发布最新《国防部数据战略》**

**关键词：****美国;数据战略;战略资产**  

**摘要：**美国国防部发布的《国防部数据战略》中提出国防部应加快向“以数据为中心”的过渡，在作战速度和规模上利用数据提高作战优势和效率。发布的《国防部数据战略》将通过国防部数据战略通过提供将该部转变为以数据为中心的组织所需的愿景、重点领域、指导原则、基本能力和目标，以支持美国国防战略和数字现代化战略的实现。[【阅读原文】](https://mp.weixin.qq.com/s?__biz=MzA5MDg1MDUyMA==&mid=2650410578&idx=2&sn=9d80d7a48d4ccd3cbb9aafec6e1af7bd&scene=21#wechat_redirect)

**1、Linux内核曝严重蓝牙漏洞，影响多个版本**

**关键词：****Linux;蓝牙;漏洞**

**摘要：**谷歌安全研究人员在Linux Kernel中发现了一组蓝牙漏洞（BleedingTooth），该漏洞可能允许攻击者进行零点击攻击，运行任意代码或访问敏感信息。BleedingTooth漏洞分别被命名为CVE-2020-12351，CVE-2020-12352和CVE-2020-24490。其中最严重的漏洞是基于堆的类型混淆漏洞（CVE-2020-12351），被评为高危漏洞 ，CVSS评分达到8.3。

https://www.freebuf.com//news/252048.html[](https://mp.weixin.qq.com/s?__biz=MzI2MDc2MDA4OA==&mid=2247492489&idx=1&sn=ba28a7409fb1a3d3a95240345aa16f4d&scene=21#wechat_redirect)

信息来源：Freebuf网站  

发布时间：2020-10-15

  

**2、VMware vCenter Server 任意文件读取漏洞通告**

**关键词：****vCenter;漏洞;修复建议**

**摘要：**2020年10月15日，360CERT监测发现 @ptswarm 发布了VMware vCenter任意文件读取的风险通告，漏洞等级：高危，漏洞评分：7.5。远程攻击者通过访问开放在外部的 vCenter 控制台，可以任意读取主机上的文件。(可读取 vCenter 配置文件获得管理帐号密码)进而控制 vCenter 平台及其管理的虚拟机集群。对此，360CERT建议广大用户及时将 vcenter\_server 升级到最新版本。与此同时，请做好资产自查以及预防工作，以免遭受黑客攻击。[](https://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655311332&idx=1&sn=d653692484fdc3b18668a7de28138dc0&scene=21#wechat_redirect)

**3、Microsoft Windows IPv6远程代码执行拒绝服务漏洞（CVE-2020-16898）通告**

**关键词：****微软;IPv6;拒绝服务**

**摘要：**2020年10月14日，在微软每月的例行补丁日当天，修复了一个Windows系统TCP/IP协议栈处理ICMPv6路由广播包时存在的严重远程代码执行漏洞，该漏洞CVSS威胁评分为严重等级的9.0，远程攻击者可能无需用户验证通过发送恶意构造的ICMPv6路由广播包导致目标系统代码执行或拒绝服务。该漏洞影响几乎全版本的Win 10系统，强烈建议相关企业用户安装对应的安全补丁。微软已发布相关补丁更新，见如下链接:https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2020-16898。[【阅读原文】](https://mp.weixin.qq.com/s?__biz=MzI2MDc2MDA4OA==&mid=2247492619&idx=1&sn=ad84436f319cce3fcea713e29e1d99d5&scene=21#wechat_redirect)

观点分享

  
  

  

  

**1、******零信任架构在网络信任体系中的应用****

**关键词：****网络信任体系;零信任架构;动态信任**

**摘要：**网络信任体系作为网络信息安全的重要因素，是保障网络空间实体活动的核心基石；零信任架构作为一种新兴安全模式，以信任评估为基础，强调动态信任，为网络信任体系的建设应用提供了新的思路。通过分析网络信任体系和零信任架构模型的典型结构，总结零信任架构模型在不同网络信任体系环境中的应用情况，指出实际应用部署过程存在的不足和需要关注的重点，为零信任架构在我国党政军民各领域的具体实现提供有力支撑。[【阅读原文】](https://mp.weixin.qq.com/s?__biz=MjM5MzMzNjU4MQ==&mid=2709938442&idx=1&sn=3b922b90833ab33dd95fcc727063dd37&scene=21#wechat_redirect)

信息来源：信息安全与通信保密杂志社

发布时间：2020-10-12  

  

**2、工业企业如何打造网络安全综合防护体系**  

**关键词：****工业控制;网络安全;防护体系**

**摘要：**随着我国关于“中国制造2025”、“工业互联网”等一系列制造强国战略的实施，工业控制系统逐步实现人、机、料、法、环、信息的智能感知、互联互通、协同处理，我国也正式步入工业互联网时代，工业互联网使我国工业自动化、网络化、智能化水平得到快速发展的同时，也引入了诸多互联网信息安全威胁，工业网络安全隐患日益严峻。本文从工业企业网络安全防护要求特殊性、传统IT安全建设思路难以复用在工业网络、网络安全综合防护体系的技术路线指导以及网络安全综合防护体系设计等方面进行了阐述。[【阅读原文】](https://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664132955&idx=6&sn=909523682571b875e002e801b96ab607&scene=21#wechat_redirect)
