**1、中国互联网协会数据治理工作委员会正式成立**

**关键词：****互联网;数据治理**

**2、第八届全球云计算大会·中国站，线下开幕倒计时！**

**关键词：******云计算;数字化;工业互联网****

**摘要：**第八届全球云计算大会·中国站（Cloud Connect China）将于7月21日至23日举行。本届大会主题将聚焦企业数字化转型、逐步迁移上云，并深度探讨上云对企业的实际意义及具体应用，以及对各行业的转型推动作用。论坛主题包含中小企业“上云”及应用落地、基于云计算的数字化转型趋势、工业互联网与数字化转型，拟定议题包含上云政策解读、企业系统迁移上云、工业互联网助力传统制造业、数字化转型实际案例分享等，帮助企业快速了解企业数字化转型重要内容。[【阅读原文】](https://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651090609&idx=2&sn=8a4ec3f1402b533e2df98663a518936f&scene=21#wechat_redirect)  
信息来源：安全牛

发布时间：2020-07-14

  

**3、NIST发布物联网设备制造商网络安全指南**

**关键词：****网络安全;物联网;安全控制**  

**摘要：**美国国家标准与技术研究院（NIST）研究制定了面向物联网设备制造商的网络安全指南，为物联网产品的制造提供了安全控制的方向与指引。近期NIST发布了两份文件，一份文件是NISTIR 8259，该文件为物联网设备制造商提供了详细的路线图，帮助解决 IoT 产品开发过程中遇到的网络安全问题。另一份文件NISTIR 8259A制定了满足常见网络安全控制需要的核心基本要求。[【阅读原文】](https://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651088536&idx=3&sn=38058423485172f9edc35c480d8ebd72&scene=21#wechat_redirect)  

信息来源：FreeBuf

**1、关于Windows DNS Server存在远程代码执行漏洞的安全公告**

**关键词：****漏洞;远程代码执行**

**摘要：**国家信息安全漏洞共享平台（CNVD）收录了Windows DNS Server远程代码执行漏洞（CNVD-2020-40487，对应CVE-2020-1350）。攻击者利用该漏洞，可在未授权的情况下远程执行代码。CNVD对该漏洞的综合评级为“高危”。漏洞影响Windows Server 2008/2012/2016/2019等多个版本，微软公司已发布官方补丁，CNVD建议用户立即升级至最新版本。[【阅读原文】](https://mp.weixin.qq.com/s?__biz=MzU3ODM2NTg2Mg==&mid=2247488261&idx=1&sn=7580900da5670d7e2eeb3921ffd147c2&scene=21#wechat_redirect)

信息来源：CNVD漏洞平台

发布时间：2020-07-16

  

**2、Oracle多个产品安全漏洞通告**

**关键词：****漏洞;远程代码执行;攻击**

**摘要：**Oracle官方发布安全公告，修复了433个安全漏洞，涉及了Oracle Weblogic、Oracle Coherence等多款产品。包括四个评分为9.8的Oracle WebLogic Server反序列化漏洞（CVE-2020-14625、CVE-2020-14644、CVE-2020-14645 、CVE-2020-14687），两个评分为10的Oracle Communications Applications安全漏洞（CVE-2020-14701、CVE-2020-14606）。其中Oracle WebLogic Server反序列化漏洞可导致未经身份验证的攻击者通过IIOP、T3协议发送恶意请求，从而在Oracle WebLogic Server执行恶意代码；Oracle Communications Applications安全漏洞无需身份验证即可远程利用。目前厂商已发布补丁。[【阅读原文】](https://mp.weixin.qq.com/s?__biz=MzU5OTQ0NzY3Ng==&mid=2247486016&idx=1&sn=5f5ada1e4b126cea6dcc6c835a5342d6&scene=21#wechat_redirect)信息来源：信息安全国家工程研究中心

发布时间：2020-07-16  

  

**3、99%的网站JavaScript插件面临攻击风险**

**关键词：****攻击;跨站脚本;数据泄漏**

**摘要：**Tala Security最新web安全报告显示，全球Web安全状况急剧恶化，99%的网站JavaScript插件面临Magecart、formjacking、跨站脚本、信用卡劫持和其他攻击风险。尽管有30％的网站实施了新的安全策略，比2019年增加了10％，但只有1.1％的网站具有有效的安全措施，比2019年反而下降了11％。[【阅读原文】](https://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651090626&idx=3&sn=755d0433baf530d15e8fe843949e574f&scene=21#wechat_redirect)

**1、量子威胁及其应对技术**

**关键词：****威胁;量子计算;网络安全**

**摘要：**本文回顾了量子计算技术的发展状况，结合对现有网络安全技术的影响，建议一是制定我国的量子信息技术发展路线，二是合作制定量子安全技术相关国际标准，三是建立国家量子技术标准体系，以应对可能的量子威胁。[【阅读原文】](https://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664128573&idx=1&sn=285f8cf9d16cb329115e92be16571f9e&scene=21#wechat_redirect)

**2、零信任安全架构及应用研究**  

**关键词：****零信任;信任评估;认证授权;动态访问控制**

**摘要：**随着网络空间高速发展，大规模网络引发的安全运行防护复杂度激增。传统的基于网络边界建立信任体系的安全防护模式逐渐失效，零信任网络安全技术应运而生，并迅速成为当前网络空间安全技术研究热点。本文从传统边界防护存在的问题出发，分析了零信任模型产生的原因、基本概念和优势，并阐述了零信任安全网络架构的组成要素和关键技术，最后探讨了其在企业远程移动办公方面的应用，为新型数字化基建业务安全防护提供相关借鉴。[【阅读原文】](https://mp.weixin.qq.com/s?__biz=MjM5MzMzNjU4MQ==&mid=2709932635&idx=1&sn=52b753d2c7a1d7655bab110730f3aca0&scene=21#wechat_redirect)

信息来源：信息安全与通信保密杂志社

发布时间：2020-07-16  

  

**3、基于威胁的网络安全动态防御研究**

**关键词：****威胁;动态防御;安全能力**

**摘要：**动态防御是对网络空间安全防御技术和体系的探索，通过动态防御技术，让网络系统的安全防御呈现不可预测的变化态势，大大提高了攻击者发动攻击的难度和成本。动态防御需依据系统安全态势、可能遭受的安全威胁等因素进行综合考虑，如何有效感知网络系统的威胁态势，提前洞悉研判、响应处置及动态防御策略的调整，是当前数字化转型时期网络安全技术创新研究领域的重要任务。[【阅读原文】](https://mp.weixin.qq.com/s?__biz=MzIwNjYwMTMyNQ==&mid=2247484266&idx=1&sn=efb532ce0da982046a6cac4d504f0f7e&scene=21#wechat_redirect)

信息来源：虎符智库

发布时间：2020-07-15
