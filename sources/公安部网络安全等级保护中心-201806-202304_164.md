**1、系统或遭完全控制？Cisco IOS路由器中存在严重漏洞**

**关键词：****漏洞;软件;令牌**

**摘要：**思科宣布将修复Cisco IOS路由器中的漏洞，其中包括25个高级严重性级别的漏洞，并针对影响iOS和其他软件的高中级严重性问题发布了建议。此次修复中，最严重的关键问题之一是“CVE-2020-3205”漏洞，它是属于VM通道命令注入漏洞，存在于Cisco 809，Cisco 829和Cisco 1000系列路由器（CGR1000）的Cisco IOS软件VM间通道中。另一个严重漏洞标识为“CVE-2020-3198”，属于思科工业路由器任意代码执行漏洞，影响Cisco ISR 809和829工业路由器以及1000系列的CGR设备。除此之外，思科还确定了CVE-2020-3227是至关重要的漏洞，该漏洞问题出在Cisco IOS XE中针对Cisco IOx基础架构的授权控制，目前已经发布了解决此漏洞的必要软件更新。[【阅读原文】  
](https://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655308986&idx=1&sn=4721d97b7600ef17af9fffa1805cdef1&scene=21#wechat_redirect)

**2、Windows SMB远程代码执行漏洞（CVE-2020-1301）**

**关键词：****漏洞;SMB;远程代码执行**

**摘要：**微软发布6月份安全更新，其中一安全通告称Microsoft Server Message Block 1.0 (SMBv1)在处理某些请求的方式中存在远程执行代码漏洞（CVE-2020-1301）。攻击者可利用此漏洞向目标系统发送精心构造的数据包，从而远程执行代码。[【阅读原文】](https://mp.weixin.qq.com/s?__biz=MzA3MTgwNzQwMw==&mid=2448263946&idx=1&sn=989fecb66bf3cdc47e5a852cb213aeb7&scene=21#wechat_redirect)

**3、百万个WordPress网站数据库面临威胁！大规模黑客活动正在泛滥**

**关键词：****漏洞;攻击; WordPress**

**摘要：**据外媒报道，近期黑客组织试图利用主题和插件中的已知漏洞从数百万个WordPress网站窃取数据库凭据。攻击者使用了多个插件和主题漏洞，尝试从WordPress网站下载wp-config.php配置文件，该文件包含可用于访问WordPress网站数据库的用户名和密码。根据WordPress安全公司Defiant的研究数据，其防火墙在5月29日至5月31日之间阻止了超过1.3亿次尝试从130万个站点收集数据库凭据，请求的数量在5月30日达到峰值，这些攻击影响了WordPress三分之一以上的客户。  

**网址：**  

https://www.sohu.com/a/400481651\_621613  

信息来源：搜狐网

发布时间：2020-06-08

**1、“新基建”视野下网络安全新趋势**

**关键词：****新基建;网络安全;安全保障**

**摘要：**新基建的推进必将带来一轮信息化基础设施建设的高峰，推动社会经济模式和产业模式的新变革。网络安全作为“新基建”必不可少的安全保障，必然会迎来产业发展的新机遇。要抓住新基建带来的网络安全发展新机遇，必须要从政策上保持重视、从投资上找准方向、从行业用户角度提高安全意识、从企业自身角度确定产品布局，积极参与到“新基建”的建设浪潮中去，形成全数据、全能力、全行业、全社会的大协同。[【阅读原文】](https://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664126965&idx=1&sn=d932de1cd7b4b709e0cebe1fb48d4dc4&scene=21#wechat_redirect)

**2、《美国出口管理条例》管辖范围变化情况梳理及对我国5G产业的影响**
