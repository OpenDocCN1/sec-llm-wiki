# 网络安全等级保护服务于“一带一路”建设第二次研讨会在中卫召开

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU3NTQwNDYyNA==&mid=2247483823&idx=1&sn=6799aa6b637f123537defce81627c8b6&chksm=fd22ee90ca55678671331530769426defe27386a43d27595558322899e3bcd22cd74f198ae8c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU3NTQwNDYyNA==&mid=2247483823&idx=1&sn=6799aa6b637f123537defce81627c8b6&chksm=fd22ee90ca55678671331530769426defe27386a43d27595558322899e3bcd22cd74f198ae8c&scene=27#wechat_redirect)

12月7日，由公安部信息安全等级保护评估中心和中卫市人民政府联合主办的网络安全等级保护服务于“一带一路”建设第二次研讨会在中卫红宝宾馆召开。   

![](../Images/5d23ad51eddc32f274a147fdd42b6e6d.png)

**中卫市政府副市长董立军发言**

![](../Images/83f20cd6128b44222f60c34170b6da7d.png)

**公安部网络安全局监察处副处长陆磊发言**

中卫市政府副市长董立军、公安部网络安全局监察处副处长陆磊、区公安厅网安总队调研员张建银围绕网络安全等级保护服务于“一带一路”这一主题做了重要讲话。

![](../Images/be73aab8bd9360c5e87769e6de940bc2.png)

**公安部信息安全等级保护评估中心主任张宇翔发言**

公安部信息安全等级保护评估中心主任张宇翔详细介绍了等保2.0标准体系的制定与推广、云计算平台安全防护要求、等级保护对象的扩展与应用规范。中卫市大数据局副局长李彬介绍了中卫市云产业现状和发展前景，市公安局网安支队支队长俞凤云就深入开展网络安全等级保护服务经济发展做了表态发言。16名与会专家就如何开展网络安全等级保护更好地服务“一带一路”建设、等保2.0标准体系的推广、关键基础信息系统防护措施以及网络安全防护体系建设等内容进行了深入交流和研讨。
