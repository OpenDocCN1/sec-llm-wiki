**功能**

For a domain:  
\- 查找dns服务器  
\- 查找邮件服务器  
\- 通过google搜索子域名  
\- 通过暴力破解来查找子域名  
\- Find possible Clusters / Balancers (different IP, same Host)（ps:不懂啥意思）  
\- 查找与目标有关系的域名  
\- Whois 信息

For Name servers:  
\- 通过域传送查找域名服务器

For IP Addresses:  
\- 查找主机名称  
\- 通过bing接口查找虚拟主机  
\- Whois IP details (Gets ISP / LIR details as well)  
\- 查找ip段  

For Ports (import Nmap xml file):  
\- 端口版本信息  
\- 查找web服务的端口(http/https)  
\- 查找运行在不同IP或端口上的相同站点  
\- 通过OPTIONS方法查看web服务器版本
