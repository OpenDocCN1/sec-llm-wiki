# 

1  引言

车联网是指借助新一代信息通信技术，实现“人-车-路-云”的全方位网络连接和信息交互，提升汽车智能化水平和自动驾驶能力，构建交通和汽车服务新业态，从而提高交通效率，改善汽车驾乘感受，为用户提供智能、舒适、安全、节能、高效的综合服务。

我国政府高度重视车联网产业发展，工业和信息化部联合国家发展和改革委员会、公安部、交通运输部、科技部等20个部门组织成立了“国家制造强国建设领导小组车联网产业发展专项委员会”，统筹推动车联网发展规划、政策和措施，跨部门协调解决车联网发展重大问题。国家发展和改革委员会联合11部委发布《智能汽车创新发展战略》，提出到2025年，中国标准智能汽车的技术创新、产业生态、基础设施、法规标准、产品监管和网络安全体系基本形成，实现有条件自动驾驶的智能汽车达到规模化生产，实现高度自动驾驶的智能汽车在特定环境下市场化应用；智能交通系统和智慧城市相关设施建设取得积极进展，车用无线通信网络（LTE-V2X等）实现区域覆盖，新一代车用无线通信网络（5G-V2X）在部分城市、高速公路逐步开展应用，高精度时空基准服务网络实现全覆盖。2020年4月，国家发展和改革委员会明确新型基础设施范围：一是5G、物联网等信息基础设施，其中车联网既是5G的垂直行业应用，又是物联网的典型应用领域；二是智能交通基础设施等融合基础设施，其中车联网是传统交通基础设施智能化与网联化的重要保障；三是产业技术等创新基础设施。工业和信息化部发布《关于推动5G加快发展的通知》提出，促进“5G+车联网”协同发展，推动将车联网纳入国家新型信息基础设施建设工程，促进LTE-V2X规模部署；建设国家级车联网先导区,丰富应用场景，探索完善商业模式；结合5G商用部署，引导重点地区提前规划，加强跨部门协同，推动5G、LTE-V2X纳入智慧城市、智能交通建设的重要通信标准和协议；开展5G-V2X标准研制及研发验证。

各地方政府积极推动车联网发展，加快构建新基建、新产业和新服务，提出在推动产业数字化转型、构建高质量发展的前提下，重点开展3方面工作。

( 1 ) 构建基础支撑体系，包括建立一些感知和计算的平台、网络连接能力和基础有交叉平台的工作。

( 2 ) 构建产业生态体系，围绕如何构建一个完整的产业链条、如何去发挥数字经济在车联网中的重要作用等。

( 3 ) 构建保障体系，涉及到安全、出行以及城市治理。

以此为基础，各个城市都将形成新的产业集聚。

# 

2  车联网先导性应用发展情况

2.1车联网先导性应用概述

车联网先导区是新技术验证的试验田，是助力推动汽车智能化、网联化发展的核心枢纽，同时也是连接汽车、交通、公安治理体系的一个核心枢纽。所以，车联网助力智能化和网络化的协同发展，能够把所有交通参与要素——人、车、路、云有机地协同在一起，构建、支持实现“聪明车+智慧路”的协同发展，更好地促进交通管理能力的提升。

连接不是目的而是手段，能够更好地把各方面的要素连接在一起，比如计算资源，让计算资源在车端、路端、云端做更好的负载均衡。另外，借助于连接，可更好地实现从单体的智能化向综合性的交通智能体系发展过渡。

2.2车联网先导性应用意义

( 1 ) 服务于交通出行和交通智能化管理，无论是连接还是计算，能够让未来用户的出行体验更加直观。例如，目前在长沙试运行的智慧公交315线，实现了红绿灯的提醒、车速的引导、优先场景的通行等车联网应用场景。另外，借助于网络连接，更好地支持自动驾驶的商业化落地，比如百度在各地开展的Robotaxi工作。

( 2 ) 借助于车联网发展，未来构建一个新的生态体系。生态体系不只是从应用层面构建，而是从整个产业的生态体系和未来发展的整体产能赋能方面，以及整个社会的发展生态体系方面构建。实现全面的数据接入、存储分析、协议开放、服务赋能等能力，具备强大的整合能力，将分散在各处的系统串联、数据打通。

( 3 ) 借助于车联网，依托于平台，可以更好地实现各方数据的汇总。有了这些平台功能，才可以把交通参与的各个要素，如车端数据、路端数据，甚至感知摄像头雷达的一些数据，以及与第三方的汽车远程服务提供商（Telematics Service Provider，TSP）的平台打通，在这个基础上实现更多服务对象的衍生，承载更多的应用场景。

2.3车联网先导性应用进展

2019年5月，工业和信息化部批复支持创建江苏（无锡）车联网先导区，实现规模部署C-V2X网络、路侧单元，装配一定规模的车载终端，完成重点区域交通设施车联网功能改造和核心系统能力提升，丰富车联网应用场景。2019年，在170 km2范围、280 km道路内开展信息化升级改造，包括400个交通路口、5条城市快速道路、1条城际高速公路；开放实时信号灯配时、道路视频监控、交通事件等40余项交管数据。2020年，计划C-V2X新增覆盖无锡城区200个路口，累计达600个路口。

2019年12月，工业和信息化部批复支持创建天津（西青）国家级车联网先导区，发挥在标准机构、测试环境等方面的优势，积极探索跨行业标准化工作新模式，规模部署蜂窝车联网C-V2X网络，明确车联网通信终端安装方案，明确车联网运营主体和职责，构建开放融合、创新发展的产业生态。

后续更多的城市也在积极参与中，包括广州、重庆、长沙、德清、北京、上海等，正在结合不同的产业生态布局和城市的发展优势，差异化地发展车联网先导区，逐渐丰富车联网出行应用场景和模式。

# 

3  车联网先导性应用发展重点

结合车联网先导性应用的重要性及发展趋势考虑，未来其发展的重点应包含以下方面。

3.1导向与需求

以应用为导向，未来的发展要满足应用新方向的发展需求。以前在车联网更多提到的是信息服务类，未来更多会向着协同的服务方向发展，以及安全和效率相关的应用。在当前阶段，无锡有一些应用场景，如红绿灯、交叉路口、碰撞预警、车速引导等，已经相对比较成熟，也已经能够落地；未来，在协同发展方向上，可以远程遥控驾驶、车辆编队行驶等，同时会结合到城市的出行场景，如高速路、缓行路段等；此外，在智能驾驶测试的过程中，遇到一些需要车辆紧急接管的情况，都可能会与车联网应用场景有更强的耦合。面向未来，应用场景的探索一定是车联网先导区核心价值的所在。

3.2应用服务平台的建设和应用

车联网产业跨行业属性较强，涉及到汽车行业、交通行业、交通治理和管理等多方面、多行业综合性的领域，这就需要打通出行服务平台、城市治理平台和交通管理平台，构建一个综合性的应用服务体系，促进平台之间的互联互通和数据之间的共享；尤其借助于连接和计算，包括多接入边缘计算技术（Multi-Access Edge Computing，MEC）多级平台的部署，可以为未来自动驾驶和车联网提供更好的支撑。应用服务平台的建设与应用服务平台促进跨行业平台互联互通是非常重要的建设内容。

3.3标准化的建设方案

标准化的建设方案，在一个城市内可以实现跨平台之间的数据互通，也能支持实现这些应用场景的落地。但不能是在A地实现的应用服务到了B地由于格式或标准采用的不一样就没法实现相同的应用服务，或者说做到相当服务质量的保障。为了实现跨区域、跨地方的互联互通，或者说能体现到相同应用的服务，需要支持实现标准化的建制方案。目前，几大标准化组织签订了合作协议，正加快相关标准的梳理和制定工作。另一方面，车联网相关核心技术标准也已经在逐步完善的过程中，下一步是打通跨行业产业不同环节、具有综合性的标准体系，能够指导建设标准化、规范化的车联网先导区。

3.4安全

在新基建的发展下，未来所有的基础设施都要联网。这里需要关注一个重点，就是安全问题，这个安全不仅是功能安全，还有信息层面的安全和系统的安全。为了保证连接到系统当中不同参与主体相互之间是可信任的，更要结合新基建构建一个身份认证体系，保证车联网新基建安全身份。涉及到跨行业，不同的行业组织也在探讨怎样构建协同和统一的体系，至少在一个地方需要优先构建数字身份的认证体系，保证相互之间的互联互通，以及身份之间互认的过程和规模化部署。

3.5支撑性与规模化

目前，国内已有二三十个相关的区域，对技术的验证和产业化协同有很好的支撑性作用，但仍然面临运营模式和商业模式的困境，需要从小规模的试验验证逐步走向大规模应用。无论是车载终端的安装还是路侧基础设施的部署，都需要实现全场景的覆盖。另外，注重与5G、智能交通发展相互的协同，现有的设备和设施层面已经经过了一些验证，包括在城市内、实验室环境下都有了相关设备的验证，为开展大规模部署提供了很好的基础支撑。

3.6创新与结合

大规模应用势必与运营和商业模式相结合，所以在先导区建设过程中，要更多地创新运营主体和商业模式实现逻辑一张网统一布局，但也有一些差异性商业模式的发展。目前，在申请5.9 GHz车联网频段时，汽车、交通行业的地方属性很强，应鼓励各个城市不同的主体参与到车联网新基础设施建设及车联网生态体系构建当中。

# 

4  结束语

本文介绍的车联网先导性应用发展的重点工作是各个城市发展车联网产业的重点方向。在IMT-2020 C-V2X工作组的组织和指导下，200余家相关的合作伙伴共同探索技术创新、试验验证和应用推广工作，希望借助于车联网先导性应用的发展，更好地构建整个车联网生态体系，为未来新基建、汽车和交通产业的转型升级做更好的支持。
