# 华南首家CCSRP认证培训机构落户广州

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyMzAwMDEyNg==&mid=2247493736&idx=2&sn=c18c5b0136172e1bf5b84c695cd7eced&chksm=c1e96439f69eed2fd285718ccb390c51a18a718562ddbd260b5ea433de48ca33c3b858453dd9&scene=126&sessionid=1681370390#rd](http://mp.weixin.qq.com/s?__biz=MzkyMzAwMDEyNg==&mid=2247493736&idx=2&sn=c18c5b0136172e1bf5b84c695cd7eced&chksm=c1e96439f69eed2fd285718ccb390c51a18a718562ddbd260b5ea433de48ca33c3b858453dd9&scene=126&sessionid=1681370390#rd)

**“网络与信息安全应急人员认证”**（Certified Cyber Security Response Professional , CCSRP）**是由国家计算机网络应急技术处理协调中心**（CNCERT）**推出的面向重点行业网络与信息安全从业人员的技能认证。**CCSRP认证以网络安全应急响应为切入点，覆盖网络与信息安全的事前、事中和事后等各方面的能力。该认证管理和技术并重，通用与特殊兼顾，理论与实践结合，重点培养网络信息安全从业人员解决实际问题的能力，致力于满足重点行业对网络安全人才的迫切需求。

**经国家互联网应急中心的严格考核，广州蓬勃教育科技有限公司成为华南地区首家CCSRP授权培训机构。**蓬勃教育将凭借优质的行业资源、丰富的安全服务经验和强大的师资力量，大力推动CCSRP认证培训在华南地区发展壮大，并通过组织技术沙龙、会议等认证后续服务促进本地区网络安全人才的交流互动。
