# 医疗行业网络安全威胁与消减 | 继Ripple20之后，DHS又发布6个医疗设备警报

物联网设备Ripple20漏洞已经被确认有总数量超高数百万台，甚至有机构认为超过数亿台物联网设备，将受到持续多年的影响。包括输液泵在内的一些医疗设备赫然列在受影响清单之中。

在这一物联网设备漏洞被披露后，网络安全公司接到与医疗设备有关的网络安全问题的咨询量暴增。

然而，现实是，医疗行业的网络安全性长期被忽视或轻视，这类设备在研发时基本都未将网络安全作为一个指标或者要求去考虑。而网络安全公司也非常缺乏在医疗领域的技术积累和处理经验，特别是医疗器械领域。

**01 医疗行业是网络安全的洼地**

医疗行业可能是最后一个对核心数据的收集、数据收集和数据移动等大数据范畴启动革新的行业，有很多原因导致医疗行业落后于其他行业。例如医疗机构所面临的现实难题，新兴技术会破坏业务流程。医疗管理人员必须确定哪些IT投资优先于技术，业务和医疗计划。他们不得不重新设计工作流程并管理这些变更，以确保流程可行并且符合投资回报。

现在，我们至少已经看到，医疗系统，特别是中国的医院，已经在数字化和互联网化等方面在缓慢而持续的发展。软件商，看到大量的医院进行系统招标；患者，感受到医院在很多方面都在受到网络或者互联网的影响，比如远程医疗，在线问诊，病例共享等。  

所以，互联网已经与医疗深刻的绑定在一起，特别是，随着智慧医疗在国内的萌发，物联网也和医疗产生了交融，未来的医疗，物联网将是一个重要的技术推进力量。  

所有这一切，都揭示了一个问题，网络安全，无论是互联网安全还是物联网的网络安全，都将是医疗体系不可回避的一个问题。  

**![](../Images/df7bce36d5517790cc0812d462eb6799.png)**

**02 医疗系统最严重的问题曾是网络勒索**

传统上来说，医疗系统所面临的最多的网络安全问题并没有什么特殊。具体来说，无非是数据库，Web安全等。  

目前披露的涉及医院的一些网络安全事件也多是类似患者隐私和医疗数据泄漏等，网站被攻击等。  

进入，2020年，随着疫情的发展，在国外，针对医疗系统的勒索病毒攻击非常多发。  

勒索病毒并非专门针对医疗系统，但勒索病毒在医疗系统的破坏也是很普遍的。

2017年，英国国立医疗服务（NHS）的248个医疗机构中共有48个受到攻击。

2017年到2020年，国内医疗系统多次受到勒索病毒攻击，据腾讯在2018年发布的《医疗行业勒索病毒专题报告》显示，仅全国三甲医院中，就有247家医院检出了勒索病毒，以广东、湖北、江苏等地区检出勒索病毒最多。

医疗机构为什么成为勒索病毒高发领域，原因简单说有两个方面

首先，医疗机构被黑客认为是有价值的目标。原因不必多说，医疗系统一般都被认为保有重要和敏感的数据也存在支付能力。另外，就是医疗系统，特别是医院向来不重视网络安全，例如：大量老旧和未打布丁的操作系统，弱口令，没有专业人员等等。

03 医疗系统真正的网络安全威胁将来自物联网设备物联网设备Ripple20漏洞披露后，被证实和列在第一个的设备就是医疗设备（输液泵）。医疗设备安全性一直是医疗保健提供者的致命弱点，因为这类设备并不是在本质上考虑到网络安全性而开发的。毫无疑问，医疗设备安全性的当前状态需要更多关注，医疗设备制造商，医疗提供商和使用医疗物联网设备的医疗机构应当开始重视医疗设备的网络安全性能。  
以Ripple20漏洞为例，黑客能够黑入目标设备，并在其上运行他们自己的代码，代码可以执行攻击者想要的任何事情，包括关闭设备。细思极恐，这一漏洞其危害，如果表现在对医疗设备的攻击上，将是如果严重。这将不只是网络安全问题，将是生命安全问题。

Ripple20披露之后，国外高度重视医疗系统的物联网安全，近日，DHS发布了6中最新的医疗设备漏洞警报。  

工业控制系统的计算机紧急响应小组DHS（由美国国土安全部网络安全和基础设施安全局组成的部门

### **Baxter百特设备的四个漏洞**

DHS警报中的四个与来自伊利诺伊州迪尔菲尔德的制造商Baxter的几种医疗设备产品有关，该产品已识别出问题并将其报告给CISA。

**设备警报涉及：**  

**Baxter ExactaMix-**这种药物配制工具中的漏洞包括硬编码密码的使用，敏感数据的明文传输，敏感数据的加密缺失，访问控制不当，资源暴露在错误的领域以及输入验证不正确。成功利用这些漏洞可能导致对敏感数据的未经授权的访问，系统配置的更改，系统资源的更改以及对系统可用性的影响。该公司发布了一份声明 ，其中包含缓解步骤，包括从企业主网络中分割ExactaMix Compounder，以及阻止通过防火墙和ACL配置进行的所有不需要的通信。

**Baxter Sigma Spectrum输液泵** -漏洞包括使用硬编码密码，敏感数据的明文传输，对关键资源的错误权限分配以及过期或释放后对资源的操作。利用可能导致对敏感数据的访问，系统配置的更改以及对系统可用性的影响。百特表示，缓解措施包括将频谱注入系统隔离到其自己的网络VLAN中，以将系统与其他医院系统隔离开，并减少威胁行动者对系统执行“中间人”攻击以观察明文通信的可能性。

**Baxter Phoenix血液透析输送系统** -该漏洞涉及肾脏治疗系统中敏感信息的明文传输。利用该漏洞可能使未经授权的网络访问的攻击者可以查看敏感数据。百特表示，缓解措施包括确保Phoenix机器和Exalis Server PC驻留在专用子网中。

**Baxter PrismaFlex和PrisMax**\-这些用于治疗肾脏疾病的设备中的漏洞和各种其他问题包括敏感信息的明文传输，不正确的身份验证和硬编码密码的使用。利用漏洞将使具有网络访问权限的攻击者能够查看和更改敏感数据。百特表示，缓解措施包括将对设备的物理访问限制为仅授权用户，以及为在设备上被授予较高特权的人员提供培训。

### **BD产品警报**

DHS警报与某些版本的BD Alaris PCU输液泵系统有关，BD通知了该机构有关第三方Linux内核漏洞的问题，该漏洞涉及不受控制的资源消耗。

**警报警告说**：“成功利用此漏洞可能使攻击者在目标系统上造成DDoS，并可能导致BD Alaris PCU与设施的无线网络断开连接。”  

**警报指出：**“无线功能独立于泵系统运行，并且无线连接中断不会影响泵模块功能。” “利用此漏洞将无法提供对BD Alaris PC单元或BD Alaris系统管理器的管理访问。未经授权的用户将无法获得权限或对BD Alaris PC单元执行远程命令。”

该通报指出，BD建议采取几个步骤来帮助降低与该第三方漏洞相关的风险。这些措施包括考虑对无线身份验证进行更严格的网络控制，并使用入侵检测系统监视与患者连接的设备的无线网络是否存在恶意行为。

**BD发布了更详细的缓解步骤以解决这些问题。**

该公司在的一份声明中说：“第三方漏洞披露是我们透明性方法的重要组成部分，使客户能够了解第三方漏洞是否以及如何影响BD产品，以便他们能够适当地管理潜在风险。”

“本着协作的精神，BD自愿向美国食品和药物管理局以及信息共享和分析组织（例如美国国土安全部工业控制系统网络紧急响应小组和健康信息共享）报告第三方（已发现）漏洞和分析中心。”

### **Biotronik脆弱性**

国土安全部说，Biotronick CardioMessenger II设备在某些版本中发现的漏洞是由独立研究人员报告给该机构的。该产品是带有某些心脏设备的患者的家庭监护设备。

这些漏洞包括身份验证不正确，敏感信息的明文传输，敏感数据缺少加密以及以可恢复的格式存储密码。

警报指出：“成功利用这些漏洞可能使攻击者可以物理地访问CardioMessenger来获取敏感数据，从具有植入物序列号的植入式心脏设备中获取传输的医学数据，或者影响Cardio Messenger II产品的功能。” “成功利用这些漏洞可能使具有相邻访问权限的攻击者能够影响家庭监视单元与访问点名称网关网络之间的通信。”  

国土安全部说，Biotronik已经确定了补偿性控制措施，以降低剥削风险并防止患者安全风险。该公司还建议用户采取防御措施，以最大程度地降低利用这些漏洞的风险，包括维持对家庭监控单元的物理控制。

**04 医疗机构减轻网络安全风险五步走**

减轻风险的关键的第一步，是了解组织内所有可能受到影响的设备，和所有设备的网络拓扑。  

想象一下，您是一家拥有成千上万个已连接设备的医院。您必须找出是否有某些受影响的模型。并且您想了解每个模型，因为即使在数十个中只有10个设备数以千计的设备是最薄弱的环节

第二步，当然是对这些已知的缺陷做好补救和防范措施。  

包括对老旧操作系统进行升级，掌握所涉及的安全漏洞并打补丁等等

第三步，就是建设完善医疗网络安全系统

第四步，人的因素。在医疗系统中，从现在起，必须有专业的人来做专业的事，如果不能建立强大的网络安全团队，也应寻求专业公司得安全服务。

第五步，医疗服务提供者应开始对新购医疗设备和系统的网络安全性进行考量；医疗设备的制造商应该在研发设备时，将网络安全列入研发计划；医疗设备集成商或医疗系统提供商应该吧网络安全作为系统的必要组成部分
