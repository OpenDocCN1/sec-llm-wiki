工业互联网标准化工作现状与策略研究

摘要：工业互联网是典型的交叉融合领域，原有信息通信领域和工业领域的标准无法完全适用于工业互联网，为有效推进工业互联网有序发展，避免标准缺失、交叉、重复等问题，急需形成统筹协作、目标明确、高效高质的标准化工作平台环境，加快相关标准研制，推进工业互联网有序发展。

关键词：工业互联网；标准化；总体组

引言

工业互联网是第四次工业革命的基石，工业互联网融合5G、云计算、大数据、人工智能等新一代信息通信技术以及工业网络、工业控制系统、工业软件等工业技术，催生新的业态和模式，包括网络、平台、安全三大体系。其中，网络体系是实现工业全系统、全产业链、全价值链泛在深度互联的基础，平台体系是数据集聚和资源优化配置的核心，安全体系是工业互联网发展的保障。工业互联网是典型的融合领域，原有信息通信领域和工业领域的标准无法完全适用于工业互联网，需要针对工业互联网的融合业务特征和技术需求，制定面向工业互联网的相关标准。

一、工业互联网标准化工作尚处在初期

工业互联网强调构建产业生态，即不同系统、不同设备、产业链上下游不同企业工厂间的协同服务。因此，标准化工作对于工业互联网的可持续发展至关重要，将影响工业互联网的技术路线、产业体系及产业化方向等。当前，标准化成为各国推进工业互联网的战略重点，我国跟发达国家处于基本同步水平。

1.1  国际产业推进组织和标准化组织协同推进

目前，国际上成立了众多工业互联网产业推进组织，包括美国工业互联网产业联盟（IIC）、德国工业4.0、日本产业价值链（IVI）等。这些产业组织通过构建交流平台、汇聚产业发展主体，共同就工业互联网发展过程中的一些核心问题、关键技术需求等形成共识，通过产业发展报告、白皮书等形式发布成果。一般情况下，产业推进组织不直接开展标准的制定工作，而是与标准化组织通过联络函或联合工作组等形式，反馈产业标准化需求，由标准化组织具体开展标准制定工作。IIC成立了联络函工作组，已经与20多个国际标准化组织、开源组织和区域标准研制部门建立了协作关系。工业4.0平台与德国电气电子行业总会（ZVEI）、信息技术通讯和新媒体协会（BITKOM）、德国机械设备制造业联合会（VDMA）、德国标准化协会（DIN）、德国电工委员会（DKE）联合牵头成了工业4.0标准化平台，加快标准化需求和开源领域研究，加速推进国内标准及全球标准研制。

与工业互联网相关的国际标准化组织主要涉及ISO、IEC、ITU、3GPP 等传统标准组织，为了适应融合领域的标准化工作需求，各个国际标准化组织也对标准化工作机制进行了优化，陆续成立了一系列专门工作组，包括ISO/TC184、ISO/IEC JTC1/SWG3、IEC/SMB/SG8工业4.0战略研究组、IEC/MSB“未来工厂”白皮书项目组等。ITU-T电信标准化顾问组（TSAG）也在积极推进工业互联网概览的编制工作，其中我国主导的第一个工业互联网国际标准“基于未来分组网络演进的工业互联网组网需求与架构”也在ITU-T成功立项。

1.2  我国产业界和政府高度重视标准化工作

2016年2月1日，在工业和信息化部的指导下，中国信息通信研究院联合制造业、通信业、互联网等企业共同发起成立了工业互联网产业联盟，考虑到标准的重要性，联盟在成立之初即设立了技术标准工作组，并于2017年、2018年分别发布了《工业互联网标准体系框架（版本1.0）》及《工业互联网标准体系框架（版本2.0）》，2020年正在着手制定的《工业互联网标准体系框架（版本3.0）》在研项目百余项。

2017年9月，在工业和信息化部的指导下，中国通信标准化协会（CCSA）成立了工业互联网特设工作组ST8，包括总体与应用、网络互联、标识解析、平台与数据、安全共5个工作子组，开展工业互联网相关国家标准和行业标准的研究工作。

2019年3月，工业和信息化部、国家标准化管理委员会联合发布关于印发《工业互联网综合标准化体系建设指南》的通知，提出工业互联网标准化建设的思路目标、体系框架及重点标准化领域，引导工业互联网领域后续标准制定工作[1]。

2019年12月，工业和信息化部印发《工业和信息化部办公厅关于成立国家工业互联网标准协调推进组、总体组和专家咨询组的通知》，明确了国家工业互联网标准总体组的主要职责，为后续工作的推进指明了方向[2]。2020年8月，国家工业互联网标准总体组召开工作启动会，后续发布《国家工业互联网标准总体组章程》，规定了国家工业互联网标准总体组的工作总则、工作任务、组织机构和主要职责、工作程序和要求等内容[3]。目前，国家工业互联网标准总体组正统筹开展第一批工业互联网国行标立项协调工作，工业互联网领域标准化工作机制逐步完善。

二、工业互联网标准化工作的挑战

2017年年底，国务院发布的《关于深化“互联网+先进制造业”发展工业互联网的指导意见》在基本形势部分指出，“标准体系不完善”是我国工业互联网发展与发达国家相比的重要差距之一[4]。因此，当前急需从国家层面完善标准体系建设，加快相关关键技术标准的制定。

( 1 ) 标准体系需要更新。随着工业互联网的不断发展，很多新技术、新业态不断创新，需要根据发展情况的变化不断调整标准体系，使之切实发挥引导和指导作用，突出技术和产业重点。目前，2020年《“5G+工业互联网”融合标准体系》正在推动制定中。

( 2 ) 关键技术标准存在缺口。标准是重要的产业支撑，是促进互联互通，打破“信息孤岛”，促进集成共享的重要手段。当前，工业互联网标准缺口还很大，尚无法满足产业发展需求，急需加快制定一批总体性标准、基础共性标准、应用标准、安全标准等，指导产业规范性、可持续发展。

( 3 ) 标准体系需要完善。工业互联网具有较强的跨领域综合性，原有按垂直领域监管及制定标准的工作机制，无法满足融合技术标准化工作需求，易造成标准交叉、重复、缺失等问题，急需在国家工业互联网标准总体组的统筹下有序推进标准化工作。2020年11月，国家工业互联网标准总体组发布章程，并开展第一批工业互联网国家行业标准立项协调工作。

( 4 ) ‍标准工作需加强国际合作。国际化是产业发展的趋势，工业互联网标准化工作需要加强与国际组织的协作，共同制定标准规范和国际规则，推动工业互联网关键技术达成产业共识，带动相关产业创新性发展。当前，国际社会对于工业互联网的总体概念、内涵、体系架构、核心要素等都未达成统一意见，IIC、德国工业4.0、我国工业互联网产业联盟（AII）以及IVI等产业组织正不断加强交流和对接，争取能够尽早在总体认识方面形成一致意见。

三、工业互联网标准化工作推进策略

针对我国工业互联网标准化工作的现状，可按照“统筹规划、协同推进，共性先立、急用先行，兼容并蓄、合作共享”的原则，运用综合标准化的理论和方法，明确重点领域和方向，加强标准体系框架设计及标准化工作的组织实施，具体可从以下几方面推进。

( 1 ) 加快重点领域标准研制。当前工业互联网领域产业实践逐步走深向实，形成了众多的典型应用，但从发布的行业标准和国家标准数量来看，远远无法满足产业发展的实际需求，需要加快重点领域，包括工厂网络组网方式、边缘计算、异构标识的互联互通、工业互联网平台、工业互联网安全等方面标准研制。

( 2 ) 加强新技术研究，不断完善标准体系。推进5G工业应用、工业软件应用、融合增强网络、边缘智能、工业互联网信息模型、工业数据建模等新领域的研究工作，根据技术成熟情况及产业发展情况，适时更新工业互联网标准体系，指导产业发展重点方向。

( 3 ) 推进标准的落地实施。通过标准化试验验证、公共服务平台建设等推进工业互联网领域标准的落地实施。定期开展工业互联网领域的标准培训推广等活动，引导产业规范化发展。

四、结束语

工业互联网融合创新是产业发展的必然趋势，也是推动新旧动能转换的重要动力，工业互联网的发展不会一蹴而就，产业融合需要较长的磨合期，需要产、学、研、企各界共同努力，协同发展不断探索创新。
