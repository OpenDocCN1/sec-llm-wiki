天然气管道站场安全仪表系统的设计与实现

摘要：本文基于天然气管道输气站场的安全运行要求，对站场的安全仪表系统设计方法进行研究，阐述了安全仪表系统设计的重要环节，对系统设计过程中存在的关键问题进行分析，提出改进的方法，为安全仪表系统设计提供参考依据。输气站场作为天然气管线的重要组成部分，其安全仪表系统设计是重中之重，本文提出的设计方案经过现场验证，系统运行稳定可靠，具备一定的推广价值。

关键词：天然气管道；站场；安全仪表系统

一、前言

天然气管道输送是天然气运输的主要方式，输气站场则是整个管输天然气系统的枢纽，它保证了天然气管道安全、平稳运行，一般包括集气站、压气站、清管站、配气站等站场。鉴于天然气易燃易爆的特性，一旦发生事故就会对能源安全和自然环境产生破坏性的影响，因此输气站场的稳定、高效、安全运行显得尤为重要。

在天然气输送过程的控制中，一般包括基本过程控制系统（Basic Process Control System，BPCS）以及安全仪表系统(Safety Instrumented System，SIS)，前者主要完成站场过程工艺控制，对输入信号进行响应从而使过程和设备按既定的程序运行，不执行任何安全仪表功能，后者主要防止站场危险事故的发生或降低事故危害。安全仪表系统的设计是为了应对生产过程中本身发生的危险情况，在工艺生产过程或生产装置中发现潜在的危险工况或出现各种危险条件，安全仪表系统必须按照预先设定的程序，及时输出安全保护指令，使工艺过程或生产装置回到安全状态，以防止任何危险的发生或减轻事故后果，最终保证人员、设备和环境的安全。在管道生产过程中，两套系统相互协作，共同承担着管道生产任务。

本文从安全仪表系统实施的关键环节， 包括HAZOP（Hazard and Operability Analysis）分析、SIL等级评估、安全仪表系统设计、SIL等级验算等四方面阐述系统的设计过程。

二、HAZOP分析

安全仪表系统设计的目的是降低运行装置中存在的风险，只有充分辨识出工艺生产过程中存在的风险，才能够有针对性地设计出降低风险的措施。HAZOP（危险与可操作性分析）作为国际公认的可大幅提高工厂生产安全性、可靠性的一种安全评价方法，也是国家安监总局重点推广的危险分析方法。

HAZOP自上世纪60年代提出，历经50多年的改进与完善，已经在国内外工程项目上得到广泛的应用，成为一种通用的危险及风险分析方法。由于其具备全面性、系统性等特点，被广泛应用在长输油气管道工艺安全分析中。虽然IEC 61508/IEC 61511和ANSI/ISA-84.01-1996等功能安全标准中并未包含HAZOP分析相关的内容，但是在安全仪表系统的整个生命周期中，HAZOP确是至关重要的组成部分。

HAZOP分析过程是由专业团队实施，通过使用“引导词”按照既定流程来分析工艺工程中每一部分可能存在的偏离正常工况的各种“偏差”，辨识其对人员、设备等的潜在风险，保证系统安全的一套结构化、系统化的分析方法发现潜在的风险，最终形成HAZOP分析报告。分析记录表是该报告的重要部分，表格中记录了针对所有偏差的分析，同时给出每个应用场景风险发生的频率、人员伤亡的情况与级别定义，分析流程如图1所示。

三、SIL定级

在得到HAZOP分析结果后，工艺过程中的风险及其危害程度已经识别，下一步需要对这些风险提出保护措施。为了定义这些保护措施的安全级别，需要采用SIL来表征。SIL等级是衡量安全仪表系统可靠性的一个重要指标，用以表征安全仪表系统的功能需求所能达到的风险降低的程度。确定SIL等级就是通过规定安全仪表系统最低失效的可能性，使设备能够在需要时成功执行预定的安全功能。SIL评估的方法有很多，例如：安全层矩阵、风险图、保护层分析（LOPA）、故障树分析（FTA）、事件树分析（ETA），其中保护层分析（LOPA）是目前比较流行的一种评估方法。

站场安全仪表功能的定级，首先要根据实际情况制定输气站场的风险可接受准则，然后确定需要评价的安全仪表功能，再利用HAZOP分析结果得出每个失效的各种原因和导致后果的事故场景，从而得到站场内无保护措施的固有风险水平，然后利用保护层分析法识别出站场的独立保护层，将固有风险水平和减缓措施结合在一起，从而得到事故减缓后的风险。然后与风险可接受水平比较，最终确定安全仪表功能需要的等级。SIL等级的定级步骤如图2所示。

四、安全仪表系统设计

4.1　总体原则

根据站场的工艺过程的危险性及可操作性分析结果得到的各个SIF回路安全完整性等级，安全仪表系统的SIL等级应不低于最高SIL等级的SIF回路的SIL。并且系统的功能设计应满足以下条件：

( 1 ) 当过程达到预定条件时，安全仪表系统动作，使被控制过程转入安全状态。

( 2 ) 安全仪表系统应设计成故障安全型。安全功能执行后，在人工复位前不允许再次启动或投入。

( 3 ) 安全仪表系统应具有符合安全完整性等级要求的故障诊断措施。

( 4 ) 故障诊断应覆盖系统的所有单元，包括传感单元、控制单元与执行单元。

( 5 ) 当系统需完成打印、编程、画面显示时，实时数据采集与控制功能不能被中断。

4.2　控制单元设计

安全仪表系统的逻辑控制单元应采用经过SIL认证的可编程序逻辑控制器（Programmable Logic Controller，PLC）或专用的安全型控制器。鉴于多数天然气站场安全仪表系统按照SIL2等级设计，本方案采用SIL2安全等级作为设计目标。安全仪表系统的PLC/控制器及相关硬件、软件和网络应是经过安全完整性等级认证，达到SIL2安全完整性等级的高可靠性故障安全型系统。PLC/控制器的硬件应采用模块化结构，以利于在容量和功能上的扩展，其主控模块应基于高性能处理器芯片进行设计。

4.3　传感单元设计

SIL2级安全仪表系统的传感器采用独立设置，且对于油气站场的易燃易爆场合，应采用隔爆型。按照IEC 61511的要求进行传感器选型，传感器接线与安装应当做好信号干扰防护，比如安全栅、线缆屏蔽层等，必要时增加传感器冗余，增大故障裕度提升系统可用性。传感单元应支持传感器状态/诊断信息的采集，以及传感器固有的故障安全功能（如非零最小输出信号、断电导向安全态等）。工艺装置的关键部位检测元件是安全仪表系统的重要组成部分，设计时应重点考虑检测元件的可靠性。

4.4　执行单元设计

站场安全仪表系统的最终执行元件通常是截断阀。截断阀的执行机构分为三种类型，包括气动、气液联动和电动。三种类型的执行机构均能支持安全功能的执行，但执行器应满足额外的技术要求。以气动类型为例，气动执行机构为故障安全型执行机构时应采用气动单作用弹簧复位型或带储气罐的气动执行机构，确保在故障态有足够的储能关断阀门，并且应取得相应SIL认证。

4.5　工艺功能设计

站场一般具备气体分离、增压、天然气冷却、清管器收发和压缩空气等功能。对于燃驱压气站，还设有燃料气供给系统。在与干线相连的进、出站管线应设置低压报警及紧急截断阀，紧急截断阀应为失效关闭，且有可靠的动力源。在不同情况下安全仪表系统对应的安全功能如下所述：

( 1 ) 当干线爆管、站内火灾、泄漏、地震等情况发生时，手动触发ESD按钮，全站关闭，并启动站内紧急放空。

( 2 ) 压缩机进出口管线上应设有截断阀、压缩机出口管线应设压力超压报警、温度超高报警等，当设备本身或其配套设施出现故障导致的压缩机出口天然气超压、超温、机组振动、天然气泄漏等不正常工况，压缩机的控制系统使压缩机进出口截断阀关断，压缩机紧急停车，压缩机内天然气紧急放空。此时，若站内其它设施运行正常，压缩机停止运行后，天然气可以通过站内旁通管线越站输送。

( 3 ) 若进出站截断阀因事故紧急关断，则压缩机进出口截断阀也应紧急关断，同时压缩机紧急停车。

( 4 ) 对于燃驱压气站，若燃料气系统出现故障或压力超压报警，则压缩机进出口截断阀也应紧急关断，同时压缩机紧急停车。

五、SIL等级验算

5.1　SIL等级验算原则

SIL等级验算是对工艺流程中安全仪表系统的安全完整性等级进行定量计算，以判断现有安全仪表系统的配置是否能够达到定级时要求的等级，对未达到等级的安全仪表改进或优化设计方案直至达到系统的安全完整性等级要求，以保障工艺流程正常平稳运行。首先要确定中各个元件的失效率，根据现场工艺流程要求，对安全仪表系统的平均失效概率进行定量计算，由结果判断是否能达所需等级要求。满足等级要求则进一步确定相应的现场验证计划，不满足则提出改进建议或优化设计方案。SIL等级验算的步骤如图3所示。

根据IEC 61508，对于低要求模式，一个安全回路的PFDavg为安全回路中各组件的PFDavg之和。对于高要求模式和连续模式，一个安全回路的PFH为安全回路中各组件PFH之和。

该站场ESD系统采用双机架冗余结构的故障安全型控制器，在操作员站上能监视联锁动作及显示报警，在操作界面上设置旁路功能，以便于系统启动、操作和维修。系统紧急停车分为两种级别的功能，一级是泄压关断，就是把进出口阀门均关断，并且在关断的同时，自动启动站内事故放空系统；二级是保压关断，就是把进出口阀关断，不对站内气体进行放空，在排除故障后，又重新启动。安全仪表系统的传感器包括压力变送器9个、温度变送器3个、紧急关断阀6个，驱动方式为气液联动，分别位于进出站区。

5.3　验算过程分析

安全回路由传感单元、控制单元（即LKS安全型PLC）和执行单元组成，其系统的PFD/PFH为这三部分的PFD/PFH之和。在满足IEC 61508规定的SIL2的低操作模式安全应用时，安全回路的PFDavg应在给定的检验测试间隔内处于10-3至10-2之间。在应用于满足IEC 61508规定的SIL2的高操作模式或连续模式安全应用时，安全回路的PFH应处于10-7至10-6之间。

对于低要求模式，假设安全回路中各组件的检验测试间隔均为1年，传感器的PFDavg-S=3E-03，执行器的PFDavg-A=4E-03，LKS的PFDavg-LKS=1.5E-03，因此整个安全回路的PFD如式（1）所示：

PFDavg=PFDavg-S+PFDavg-LKS+PFDavg-A=8.5E-03        （1）

该值在10-3至10-2范围之内，因此该安全回路满足SIL2 安全功能的要求。

对于高要求模式和连续模式，传感器的PFHavg-S=3E-07，执行器的PFHavg-A=4E-07，LKS的PFHavg-LKS=1.5E-07。则整个安全回路的PFHavg如式（2）所示：

PFHavg=PFHavg-S+PFHavg-LKS+PFHavg-A=8.5E-07        （2）

该值在10-7至10-6范围之内，因此该安全回路满足SIL2安全功能的要求。

六、结束语

安全仪表系统是工艺生产过程中至关重要的安全保护措施，HAZOP分析、SIL定级、安全仪表、系统设计、SIL等级验算各环节的贯彻执行可确保系统满足相应的功能安全及完整性的要求。安全仪表系统提出的是全生命周期的概念，无论前期的设计，中期的实施，还是后期的现场管理，每一个阶段的安全理念都需贯彻落实，安全原则执行到位，这样才能真正实现系统的安全功能。本文从安全仪表系统的整个设计流程阐述了天然气站场的安全仪表系统的设计方法，为油气输送管线站场控制中类似的安全仪表系统设计和优化提供了重要参考。
