# 针对机器学习系统的网络攻击和新的对抗性ML威胁矩阵

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyMzAwMDEyNg==&mid=2247504442&idx=2&sn=94fdcb1629617dafc6a2499b1b490db8&chksm=c1e95e6bf69ed77dd1a16f35bedb6e89fca8a9af7c1c2e24733b850b5e7446294aaa5bacb676&scene=126&sessionid=1681370339#rd](http://mp.weixin.qq.com/s?__biz=MzkyMzAwMDEyNg==&mid=2247504442&idx=2&sn=94fdcb1629617dafc6a2499b1b490db8&chksm=c1e95e6bf69ed77dd1a16f35bedb6e89fca8a9af7c1c2e24733b850b5e7446294aaa5bacb676&scene=126&sessionid=1681370339#rd)

随着针对机器学习（ML）系统的网络攻击的增加，Microsoft与MITER以及来自其他11个组织的贡献一起发布了Adversarial ML威胁矩阵。  

Adversarial ML威胁矩阵是一个开放的ATT＆CK样式的框架，可帮助安全分析人员检测，响应和补救针对ML系统的威胁。机器学习（ML）通常被视为人工智能（AI）的子集，它基于系统自动学习并从其经验中改进的能力。金融，医疗保健和国防等许多行业已经使用ML改变了他们的业务，并对全世界的人们产生了积极的影响。但是，随着ML和AI的发展，Microsoft警告说，许多组织尚未跟上其ML系统的安全性。例如，在过去几年中，诸如Google，亚马逊，微软和特斯拉之类的科技巨头都是ML系统攻击的受害者。此外，根据Gartner的报告，到2022年，将有30％的网络攻击涉及数据中毒，模型盗窃或对抗性例子。更糟的是，发给28个组织的一项调查显示，其中25个甚至都不知道如何保护机器学习系统。由于这些原因，Microsoft和MITER发布了新的对抗ML威胁矩阵，该框架“系统地组织了恶意对手在颠覆ML系统中所采用的技术。”由Microsoft和MITRE以及科技公司，IBM，NVIDIA，Bosch和其他多个组织共同开发。ML内容发布在GitHub上，主要包括：

*   对抗性ML 101
*   对抗性ML威胁矩阵
*   实例探究。

# 

**对抗性ML 101**

MITRE的Keith Manville将对抗ML 101描述为“颠覆机器学习系统的乐趣和利润。”“支持生产机器学习系统的方法在系统上容易受到整个机器学习供应链中一类新型漏洞的影响，这些漏洞统称为对抗机器学习。对手可以利用这些漏洞来操纵AI系统，以改变其行为以达到恶意的最终目标。” Manville补充说。曼维尔（Manville）还提供了机器学习攻击的不同示例，例如模型规避，功能提取和模型中毒等。此外，还提供了三种攻击情形以及图表：训练时间攻击，训练时间攻击和对边缘/客户端的攻击。例如，图1中描述了训练时间攻击：

**对抗性ML威胁矩阵**

对抗性ML威胁矩阵的结构以ATT＆CK Enterprise框架为模型。例如，矩阵为“战术”利用了许多相同的列标题（即，侦察，初始访问，执行，持久性，模型逃避，渗透和影响）。但是，图2中突出显示的修订矩阵增加了针对ML系统的不同“技术”（请参见橙色）。其余技术（灰色）适用于ML和ML系统，并且直接来自ATT＆CK Enterprise。

**实例探究**

最后，还发布了多个案例研究，其中包括两个涉及对Microsoft的逃避攻击（Azure Service和Microsoft Edge AI）。还记录了其他案例研究，例如：

*   Clearview AI（配置错误）
*   GPT-2（模型复制）
*   ProofPoint（规避）
*   泰（中毒）。

“关于机器学习（ML）系统的附件正在以越来越高的规律性进行开发和发布。从历史上看，对ML系统的攻击是在受控的学术环境中进行的，但是正如这些案例研究所表明的那样，攻击是在野外看到的。” Manville说。
