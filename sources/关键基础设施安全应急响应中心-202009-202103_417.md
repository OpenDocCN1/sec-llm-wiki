# 车联网中面向 V2V 安全即时通信的密钥分配方案设计

**摘要：**随着无线通信技术在车联网中的广泛应用，基于无线通信技术的“车—车”通信成为车联网目前研究的主要方向之一，“车—车”通信安全问题也成为关注热点。针对“车—车” 安全通信中车辆计算和存储能力有限的问题，分析现有的密钥分配方案及典型加密算法，梳理密码应用需求，使用国产商用密码，利用哈希确保传递信息的完整性，利用对称加密确保传递信息的机密性，完成了一种面向“车—车”安 全即时通信的轻量级密钥分配方案，并通过实例设计典型场景，验证该方案具有去中心化和轻量级密钥分配两大优点，为“车—车”通信安全防护技术的实际运用提供参考与借鉴。

# 0  引言

随着高速网络的普及汽车产业的飞速发展， 汽车与互联网技术相融合形成了新兴产业—— 车联网。特别是近年来 LTE 和 WI-Wifi 等无线技术不断普及，“车—车”通信（Vehicle to Vehicle，V2V）技术亦随之得到快速发展。搭载车联网的汽车可以通过 V2V 通信网络，相互间直接交流无线信息，不需经过基站转发，即可获得位置、速度、车况等信息，也在可能发生危险时，提前对双方发出警告，从而尽量避免交通事故的发生。  

V2V 技术在关注信息交互即时性的同时也存在共享的数据易被泄露利用、车辆易被黑客攻击等致命缺陷 , 对其进行全面的密码防护是保护车辆本身及数据传输最安全可行的方法 。密钥分配管理作为密码系统持续可靠运行的基础，已经成为当前 V2V 网络安全的研究热点。现有诸多密钥分配的方案，普遍具有存储和计算开销大的缺陷，相对于车辆有限的计算和存储能力，设计一个轻量级的、高效的密钥分配方案就具有十分重要的意义。

# 1  密钥分配相关基础理论

**1.1　密钥分配方式**

V2V 密钥分配的目的有两个：一是保证加解密系统对密钥的使用需要，确保交换数据的安全；二是对密钥实施高效快捷的分配，保证能够及时建立共享密钥。

1.1.1  密钥分配定义

密钥分配是指在不让其他用户获得密钥的条件下，将一个密钥共享给希望交换信息的双方的信息交互方法 。

其体系结构可分为点对点（无中心）式和密钥分配中心式两种：

( 1 ) 密钥分配点对点式

以会话密钥分配来说明点对点式的密钥分配过程。在用户 A 和用户 B 的密码设备中都有一个相同的密码算法 E 和密钥加密密钥 KE ，当用户 A 想要与用户 B 保密通信时，通过以下三种方式可以建立相同的会话密钥。

①密传明用

用户 A 首先生成会话密钥 Ks，然后用 E 和KE对 Ks加密，并将![](../Images/256275f4ae88de31e7419ad7a0425491.png)发送给 B，B 收到![](../Images/256275f4ae88de31e7419ad7a0425491.png)后，进行解密处理获得Ks，从而建立共同的回话秘钥Ks。

②明传密用

用户A 生成随机数 R，将 R 明传给用户 B， 这样 A 和 B 就可利用 R 来各自建立起共享的会话密钥![](../Images/b2e02c7408537b0e5f21bbf6d026d19c.png)。

③密钥合成

用户 A 生成随机数R1，将R1加密得到![](../Images/4f04cb0466b03920b543dc5aab7c8a2d.png)后发送给B,用户B生成随机数R2，加密得到![](../Images/9d5f18cb127389fde8610d4c3e92d78f.png)后发送给A,A脱密![](../Images/9d5f18cb127389fde8610d4c3e92d78f.png)后得到R2，B脱密脱![](../Images/9d5f18cb127389fde8610d4c3e92d78f.png)后得到R1。这样A和B 就都拥有了R1 和R2 ，因此都可以通过R1 和R2 合成出会话密钥 ![](../Images/1d924d7599bf53f8a8a02355e1001c12.png)，这里的![](../Images/856f051a52db087ac5a57a8d184dda54.png)表示一种合成算法，一般采用的是杂凑算法。

( 2 ) 密钥分配中心（KDC）式

建立一个密钥分配中心，每个用户都与KDC 共享密钥加密密钥KE。对一个有 n 个用户的需要相互建立连接进行加密通信的网络来说，需要 n 个不同的密钥加密密钥KE，只需要从KDC 进行 n 次分配，每个用户只需要存放一个与 KDC 共享的KE。

1.1.2  V2V通信中密码分配方式选取

在对密钥分配理论进行研究后，基于 V2V 是一种点对点式的通信场景以及 V2V 即时通信对密钥交互速度以及安全通信的相关要求，本文选取点对点式密钥分配方式，使用明传密用的方式以快速建立会话密钥。

**1.2　V2V 密钥分配算法**

加密算法包括对称加密算法、非对称加密算法和单向加密算法三种。其中非对称加密算法虽然安全性高，但是计算复杂度高、加解密速度较慢，资源占用高，不符合“车-车”通信时效性表示。

单向加密算法的核心是通过哈希算法单向传输的特性，检测发送方发送的密钥加密密钥是否在传递过程中被第三方截获并篡改，从而验证接收到信息的完整性，常用的单向加密算法有 SM3、MD5、SHA-256、GOAT、HMAC 等；对称加密算法主要对信息内容进行加密，确保会话密钥在传递过程中的安全。典型对称加密算法包括 SM4、DES、AES、RD2、RD5 等。对称加密总体上具有加解密速度快、加解密密钥一致、效率高的特点，适用于信息量大的数据加密。

考虑“车—车”通信追求快速的共享密钥，所以在选择加密算法时考虑实现难度小、加解密速度快的密钥。方案中车辆间共享密钥过程采用的是一次一密的方式，会话密钥相互独立。

通过对计算复杂度、算法结构、实现难度、实现性能、安全性等的分析比较研究 ，结合V2V 使用场景和使用要求，本方案选择同时使用国产 SM3 哈希算法进行哈希运算，使用国产SM4 对称加密算法 对信息进行加解密。既考虑国密算法具有自主、可控的安全特性，同时保证信息传输过程中有足够高的安全性和实效性。现对算法流程做简要说明：

SM3 算法是一个商用标准 Hash 算法，由中国国家密码局制定，其使用范畴包括数字签名、数字验签、消息认证码与伪随机数的产生。SM3 算法的输入为一个长度为 1(1<2^64) 比特的明文m，经过填加补充操作和迭代压缩操作，生成一个固定长度为 256 比特的杂凑值。其算法流程如图 1 所示。

![](../Images/b15f6cb470b4a4da8a75f197c0cd29b3.png)

图1  SM3 算法流程

SM4 算法是我国一种商用标准的分组密码算法，安全高效、简便易用。SM4 分组密码算法是用于无线局域网和可信计算系统的专用分组密码算法，该算法的分组长度为128 比特，密钥长度为 128 比特。将待加密的明文消息与加密密钥同时设置为固定长度 128 比特，经由异或、移位实现线性变换，使用 S 盒实现非线性变换，该算法能够安全有效地抵抗线性分析攻击和差分分析攻击。其算法流程如图 2 所示。

**2.2　密钥分配方案设计思想**

V2V 密钥分配方案基于密钥管理技术，以密钥分配为核心，通过密钥分配算法实现密钥获取，在 V2V 网络中以明传密用的分配方式让车辆间快速共享会话密钥。

2.2.1  方案设计思路

( 1 ) 设计密钥生成算法，通过 RANDOM函数产生依赖于时间的默认种子值，然后用简单算法实现一个二进制串处理类，产生长度为128 位的密钥加密密钥和会话密钥；设计完整性验证的算法，基于 SM3 哈希算法对密钥加密密钥进行哈希处理将计算得到的哈希值作公开信息进行发布，接收方通过哈希函数单向传输的特性验证传递过程中的密钥加密密钥准确性和完整性。

( 2 ) 设计密钥加解密算法，发送方通过SM4 对称加密算法以密钥加密密钥对会话密钥进行加密，并将密文发送给相遇的接收方车辆。接收方基于 SM4 的加解密算法用于对信息进行加解密获得会话密钥，完成密钥分配过程。

2.2.2  详细的方案设计如下

( 1 ) 方案初始化设计

① V2V 中车辆都具有唯一身份标识 V-ID，且可通过可识别的电子身份标签获取其身份信息。

②每台车配有一个密钥产生器，可以通过RANDOM 函数随时产生密钥，在此初始化过程中，给每辆车分别产生一组密钥加密密钥和一组会话密钥。

③密钥加密密钥用 SM3 进行哈希处理，将哈希值作为公开信息发布。

# 4  结语

本文针对V2V 场景下车辆安全通信的需求， 对传统密钥分配方案、V2V 通信和国密 SM 系列算法进行研究，根据 V2V 场景特点选择性能合适的加密算法，提出了面向 V2V 安全即时通信的轻量级密钥分配方案，并编程对 V2V 密钥分配方案中的核心功能进行实验验证，本文提出的轻量级密钥分配方案具有轻量化、高安全、高时效、可扩展等优点，具有较高的创新性和实用性，能够为后续研究及项目实践提供参考。
