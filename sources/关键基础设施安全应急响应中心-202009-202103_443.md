# 5G 时代IOT与互联汽车的未来

随着车载技术的进步、物联网创新和高速网络的部署，汽车应用中的5G技术正处于上升轨道，5G在车辆联网领域的应用主要体现在道路环境感知、远程驾驶、编队驾驶等方面，车辆联网系统的实现需要依靠强大的通信能力来依赖和支持，5G时代的到来为车辆联网提供了低延迟、高可靠性和大容量的通信设备，使车辆联网的发展和应用更加可靠和迅速。根据美国交通部的一项调查，大约94%的事故是由人为失误造成的，只有2%的事故是由于机械故障造成的。进一步分析数据，发现有四分之一是可以完全避免的。因此，联网车辆将可以大大改变提升交通安全。5G是汽车行业的下一个前沿，5G蜂窝网络和其他新技术的部署有望使自动驾驶汽车成为现实，车辆联网环境下的智能交通环境将更加安全、高效、环保。下面让我们一起探索5G、物联网和汽车应用的未来。

# 

1  联网汽车与自动驾驶汽车的区别

区分联网车辆和自动驾驶车辆很重要。联网车辆是一种可以从外部来源接收信息和/或连接消费者手机的车辆。如今，联网汽车已经很常见了。例如，汽车的导航系统连接到GPS网络。在交通或其他道路中断的情况下，导航系统可以规划一条新的路线来避开这些障碍物。互联车辆的下一阶段将是V2X的进步，其中X可能是行人或十字路口的交通管理系统。V2X也被称为Vehicle-to-Everything，V2X是终极互联车辆的进步，将支持车辆的自动制动，以防止交通事故。安吉星是另一个联网车辆的好例子。在紧急情况下，司机可以连接到帮助中心，帮助中心可以派出拖车或派遣紧急服务。在手机连接方面，许多汽车制造商已经允许司机将手机与汽车同步，以便使用应用程序、播放音乐或启用语音识别。虽然安吉星和GPS是有用的服务，但它们依赖于几十年前的技术。即使是将智能手机连接到汽车仪表盘上，在宏伟的计划中也不是那么令人兴奋。下一代互联汽车将做得更多。5G汽车将连接到5G网络，这不仅可以实现超高速、低延迟的通信，还可以让它们相互通信。例如，两辆5G联网的汽车来到停车标志前，可以提前约定谁先通过，解决了目前技术下自动驾驶汽车在停车标志上往往表现不佳的问题。正如我们所看到的，联网汽车不一定是自动驾驶汽车。互联汽车技术指的是V2X的进步。自动驾驶汽车是下一步，在那里汽车进行驾驶，它最终将依赖于5G技术在汽车系统中的整合。一些最早的自动驾驶汽车并不是联网汽车。他们依靠雷达和规划路线来导航。然而，随着时间的推移，大多数自动驾驶汽车都将联网，因为以相对较小的成本就能获得无数好处。

# 

2  技术推动自动驾驶汽车的未来

要实现完全自动驾驶汽车的前景，需要在一个城市中心同时为数千辆汽车提供高速的5G连接。虽然4G在3G基础上有了巨大的改进，并且非常适合当今大多数物联网应用，但真正的自动驾驶汽车需要更高的带宽和更低的延迟。为此，美国的许多城市，尤其是洛杉矶和纽约这样的大城市，正在扩大5G网络覆盖。虽然这些网络的安装并不总是特别有利于自动驾驶汽车，但5G汽车将能够连接到新的网络并利用这种基础设施。智能速度辅助(ISA)是一项有趣的技术，很可能在自动驾驶汽车的发展中发挥作用。通过ISA，GPS系统可以确定车辆的速度，然后将其与具有已知速度限制的地图进行交叉参考。在汽车超过限速的情况下，ISA系统可以警告司机，或者可能(取决于ISA的设置)，甚至会让车辆减速。在自动驾驶汽车方面，一张包含限速的地图将是必不可少的。虽然机器学习和人工智能将使自动驾驶汽车能够阅读限速标志，但这些标志可能还不够普遍，不足以让车辆随时了解情况。另一项有趣的技术已经被应用在今天的汽车上，比如宝马，那就是lane assist（车道辅助）。汽车可以使用GPS数据、相机或雷达来确定车辆在道路上的位置，并使其保持在适当的车道上。这项技术将继续改进，有朝一日，将会产生一辆可以在任何速度和任何驾驶条件下保持在车道上的自动驾驶汽车。完全开发的车道辅助驾驶将使巡航控制看起来像一匹训练有素的马，总是以相同的速度小跑。

# 

3  5G将如何实现自动驾驶

5G的一个关键特性是它将允许汽车之间进行通信。这将开启数据共享的可能性，从当前的速度和目的地到以前的路况。朝一个方向行驶的汽车将自动与朝相反方向行驶的汽车共享数据。汽车将在红绿灯和停车标志处协调。司机闯红灯将成为过去。从长远来看，几十年后，红绿灯和停车标志将会完全被取消了，因为无人驾驶汽车可以在没有标志或信号的情况下协调他们的行动。由于自动驾驶汽车可以更近地行驶，交通拥堵将得到缓解或消除。5G汽车还将接收行人口袋里5G手机发出的信号。这将是自动驾驶汽车避免在人行横道或十字路口撞人的一种方式。即使在汽车的雷达和摄像头探测不到人的情况下，它们也能探测到手机发出的信号。支持5G技术的自动驾驶汽车还将能够连接到城市的智能电网网络，以确定可用的停车位、接入服务和其他我们可能还没有想象到的好处。例如，也许校车、建筑车辆和救护车会广播它们的位置，这样自动驾驶汽车就可以改变路线。

# 

4  迎接即将到来的5G汽车

实现自动驾驶的一个关键部分是5G网络的构建。据Business Insider估计，到2025年，联网汽车的产量将达到7700万辆。至于全自动或半自动驾驶汽车，到2025年，这一数字将达到1400万辆。但需要注意的是，一旦这项技术变得可靠且便宜，它可能会有很大的发展。市场从1400万增长到1亿所需的时间可能与从100万增长到1400万所需的时间相同。通用汽车已经在努力开发自动驾驶汽车技术。2016年，通用斥资逾10亿美元收购了自动驾驶汽车初创公司Cruise Automation。从那时起，Cruise已经筹集了额外的资金，通用汽车似乎完全致力于让自动驾驶汽车成为现实。向自动驾驶汽车的过渡不会在一夜之间发生;它将是渐进的。随着时间的推移，这些技术将得到改进，新技术将被引入，汽车将逐渐承担越来越多的驾驶任务。总有一天会出现一辆没有方向盘的汽车，我们正在逐渐接近一个完全自动驾驶的未来。
