浅论冶金工业环境下网络病毒的防范与治理

摘要：由于冶金工业工控网络的相对封闭性，目前针对工控系统的攻击以APT（恶意软件为载体）、病毒、木马、勒索软件等恶意程序为主。恶意程序通过自我复制、主动探测、自动传播等方式，可在工业网络内快速扩散，造成网络延迟、主机失效、业务波动，甚至造成物理损坏、业务停产等严重后果，对冶金工业企业安全生产构成极大威胁。

随着国家“智能制造”、“互联网+”、“工业互联网”战略的持续推进，冶金行业迎来了新一轮发展机遇，融合数字化、网络化、智能化的先进生产系统，使原本相对独立的DCS、PLC、仪器仪表、SCADA等控制系统通过网络连为一体，实现对工业生产、能源管理、业务调度的扁平一体化管理，使生产管理由事后、粗放管理模式向事前、精细化管理模式转变，对于强化钢铁企业生产管控水平、规范内部管理、提高运作效率、节能减排、增产降耗发挥了巨大的作用。但大量信息系统和网络技术的应用，也给钢铁冶金企业生产控制系统带来了新的安全挑战。近年来，工业控制系统网络安全事件不断发生，“震网”、“火焰”、“毒区”、“Havex”等恶意软件严重影响了冶金行业等关键工业基础设施的稳定运行，充分反映了工业控制系统网络安全面临的严峻形势。不断爆发的网络安全事件表明，被普遍认为相对安全、相对封闭的工业控制系统已经成为不法组织和黑客的重要攻击目标，黑客攻击正在从开放的互联网向封闭的工控网蔓延。

1  当前问题与风险

随着工控安全行业的蓬勃发展，工控系统漏洞发现数量与日俱增，为网络攻击以及病毒的滋生与传播创造了适宜环境。当前工业系统、工业网络大多以“物理隔离”为核心安全手段，以“黑名单”杀毒软件为辅助防控，其内部工控系统基本处于“原始裸机”状态。以勒索软件为代表的新型恶意软件不断出现，对工业系统安全运营构成威胁。针对工业领域的网络攻击呈组织化、递增化发展，且攻击方式呈现多样性。随着“等保2.0”的出台，工业企业应当迅速转变思路，提升网络安全意识，切实分析工控系统安全保障体系水平，尽快适应新环境、新技术、新政策下的工控安全需求。

2  工控系统安全风险分析

经过对某冶金企业工艺段网络进行现场调研和综合分析，发现存在许多由系统本身脆弱性或内外部威胁所带来的安全风险，典型风险如下：

2.1　一二级网络之间无工业级安全访问控制措施

一二级网络之间无有效安全防护措施，无法将病毒、木马、网络攻击等隔离在一定区域内，易发生全网性安全风险。

2.2　工业控制系统自身存在漏洞、防护措施薄弱

工业控制系统在硬件产品设计之初就很少考虑安全问题，导致安全漏洞不断涌现。国家网络安全漏洞共享平台（CNVD）、中国国家网络安全漏洞库（CNNVD）中已经公布大量知名控制器厂家的PLC高危漏洞。

2.3　操作系统风险

目前大多数控制系统的工程师站/操作员站/HMI采用Windows平台，为保证过程控制系统的相对独立性，同时考虑到系统的稳定运行，通常现场工程师在系统开车后不会对Windows平台安装任何补丁。

2.4　应用软件风险

工控系统的控制软件多为定制化产品，在软件开发阶段缺少安全设计，导致这类软件存在大量的安全漏洞。另外当应用软件面向工业网络应用时，需要使用专用的工业控制网络协议及端口，因此常规的网络安全保护产品很难保障其安全性。

2.5　移动介质使用风险

USB接口类移动存储介质、远程维护通道、移动便携式设备等缺乏有效管控手段，给工业控制系统带来极大安全隐患。

2.6　安全策略和管理流程风险

追求可用性而牺牲安全，是很多工业控制系统存在的普遍现象，缺乏完整有效的安全策略与管理流程也给工业控制系统网络安全带来了一定的威胁。

3  病毒查杀及防控技术分析

3.1　工控系统特点

工控系统信息安全区别于IT系统信息安全。信息安全有三个目标，即保密性（confidentiality），完整性（integrity）和可用性（availability）。保密性是指未经授权的个人、实体或进程，不能利用和获取信息。完整性确保防止不合适地修改或破坏信息。可用性是授权的用户可以按需求，及时、可靠地访问和使用信息的特征。传统的IT系统信息安全按重要性排列顺序为：保密性、完整性、可用性。工控系统信息安全按重要性排列顺序为：可用性、完整性、保密性。信息安全目标重要性排序不同造成了工控系统与IT系统在包括风险评估、安全需求、标准要求、实现方案、部署实现、安全运维等整个安全生命周期过程都有很大不同。

工控系统中，工业主机具有以下特点：

( 1 ) 业务功能稳定。在工业网络环境中，工业主机系统承载业务功能稳定，不会像办公网主机一样经常安装新软件或重装系统。

( 2 ) 工业主机系统配置稳定。工业网络环境中，工业主机系统一旦投入运行，配置即进入“静态”，只有在大修保养或业务调整期才会进行配置更改。

( 3 ) 工业主机系统软件应用稳定。工业网络环境中，工业主机系统一般只承载独立应用和功能，投入运行后应用功能不会随意修改。

( 4 ) 工业主机系统网络流量相对稳定。

3.2　传统杀毒软件的不足

传统防病毒软件以查杀引擎和漏洞库为核心，工业环境的相对封闭性无法保证杀毒软件的及时更新，导致防病毒措施形同虚设。

传统防病毒软件存在误杀、误报，从而对工业主机系统、控制软件、组态软件的稳定运行产生不利影响。

工业环境存在大量Windows XP、Windows 2003等老旧操作系统，传统杀毒软件由于追求新特性、新功能，对老旧操作系统以及软件存在部分兼容性问题。

大量现存工业主机系统由于投入运行时间较长，系统性能普遍较低，安装杀毒软件可能造成业务系统波动。

3.3　白名单技术的适用性

( 1 ) 网络通信白名单技术

选择网络行为的特征作为建立白名单库的依据。由于工控系统的设备和应用间的网络行为相对固定，因此可以选择目标地址、端口、协议、操作指令等特征建立白名单匹配库。通过定义上述特征的可信白名单库，可用于网络行为监测。

( 2 ) 主机应用程序白名单技术

由于工控系统主机上的应用程序和文件相对固定，可以选择基于文件和进程的运行特征建立主机应用程序白名单库。基于文件和文件夹属性的应用白名单，其中文件和文件夹属性有文件的路径、文件名、文件的大小、数字签名或发布者，以及加密使用的哈希值。基于应用资源的白名单，监视与应用相关的文件，如库函数、脚本、宏、浏览器插件、配置文件和应用相关的注册项目。

根据以上特点，基于白名单的病毒防控技术可良好适用于工业场景，消除误杀、误报等安全风险，降低运维成本。另外，白名单机制可在摆脱病毒库的情况下，有效免疫病毒、木马、勒索软件等可执行程序的滋生与运行，同时通过USB外设管理功能，可实现U盘等存储介质的高效管控。

4  病毒的防范与治理

根据工业网络、工业系统的运行与使用特点，病毒防治可从三个要素入手：终端、网络（可分为网络通信和网络边界）、人。

4.1　终端病毒防治

工业终端指具有信息输入、处理以及输出的泛终端，既包括PC、手机、平板等传统设备，也包括控制设备、智能仪器仪表、人机交互等工业现场设备。由于各类型终端设备使用场景不同，目前病毒滋生主要以传统设备为“温床”，因此终端病毒防治以传统终端防治为主，以其他控制以及智能化终端为辅。

防治核心：防止病毒滋生、运行、传播，消除病毒载体隐患。

措施：白名单软件、主机安全加固。

4.1.1　白名单软件

事前病毒防治：根据冶金工业生产业务建立相应的业务软件（工具）库，并对各软件完整性进行校验，保证冶金企业工控软件分发源头的安全，防止带毒软件、带毒工具被分发到各终端系统，实现事前预防。

事中病毒防治：通过白名单软件对终端系统内的可执行文件进行执行权限控制，只允许经授权、认证的程序运行，实现事中的主动防御。

事后病毒防治：通过对主机系统日志、文件日志、操作日志的审计，实现对事后安全事件的调查取证与操作审计。

4.1.2　主机加固

主机加固在主机上线前或离线后进行，以保障主机系统的可用性以及工业业务的连续性。

主机加固包含但不限于以下内容：主机补丁验证与修复、主机病毒查杀与免疫、主机账号权限体系检查、主机密码体系检查、主机配置基线检查。还可根据现场业务需求对主机进行内核加固、双因子认证等安全加固措施。

4.2　网络通信病毒防治

网络通信病毒防治以协议的深度解析以及数据流量、数据包逆向还原为基础，并结合现场业务以及工业网络建立通信数据模型，通过协议、数据包、流量、业务、行为的综合分析实现病毒发现与预警。

防治核心：病毒发现、传播控制、病毒传播预警。

措施：基于协议深度解析的流量、业务、行为的综合审计与监测。

4.3　网络边界病毒防治

网络边界主要指工业网络各分层、各网络以及各安全域的边界。采用工业云的工业企业可采用软件定义边界或虚拟安全技术实现网络东西向以及南北向区域与流量划分。

防治核心：切断病毒传播途径，将病毒限定在特定区域内。

措施：访问控制、深度包检测技术（Deep Packet Inspection，DPI）。

访问控制以及DPI安全检测包含但不限于以下内容：工业防火墙五元组、认证访问体系、工业协议深度内容检测（如Modbus协议的功能码、可读写地址范围、工艺值范围等）、工业协议完整性检测。

4.4　人与病毒防治管理

在网络安全建设中人与产品技术是联系紧密的两个重要实体，人是安全策略的制定者，产品技术是安全策略的具体执行部分。但由于安全制度的缺失以及安全意识的薄弱，人往往成为网络安全中的软肋。

防治核心：切断病毒侵入与传播途径，实现动态、主动型病毒防治模式。

措施：主机外设管理、文件软件上线前杀毒、设备接入管理、日志存储介质管理、操作系统与软件库管理、补丁管理、主机责任人落实、应急响应预案与演练机制、文件数据备份、安全意识培训。

4.4.1　主机外设

主机外设管理主要是对主机外设接口的管理，包括：USB、网口、光驱以及其他串行、并行接口的管控。可通过主机白名单软件对主机外设进行管控，也可对外设接口进行物理封闭。

4.4.2　文件软件上线前杀毒

在适当环境下设置独立杀毒主机，并安装白名单软件，只允许相关杀毒程序运行。在独立杀毒主机内部署安装两种或以上不同类型杀毒软件，对文件软件进行上线或传输前的安全检查。杀毒主机保持病毒库的及时更新。

4.4.3　设备接入管理

设备接入管理主要包含：业务设备的上线接入、第三方运维设备的接入、员工使用设备的接入。根据不同的设备接入类型应制定相应的安全管理制度，保证接入设备的相对无毒环境。

4.4.4　存储介质管理

工业企业可采用统一的USB存储进行日常工业数据的拷贝与传输。USB存储应具备加密与认证两种安全机制。

加密：保证工业数据只能在企业内网且具有权限的主机系统上查看处理，防止工业数据泄露。

认证：保证只有经认证且有权限的USB存储在工业主机上使用，防止其他USB存储的任意接入与滥用。

4.4.5　操作系统与软件管理

工业企业应建立自有的操作系统与软件工具库，并实行统一管理，保证系统与软件的源头安全。定期对系统与软件工具库内的软件进行完整性校验，防止其被病毒感染或恶意替换。如需新的系统或软件，应在病毒查杀主机上充分验证后加入系统与软件工具库，并进行统一管理。

4.4.6　补丁管理

在条件允许的情况下对重大漏洞进行安全更新，更新前需对补丁进行系统安全以及业务安全验证。

4.4.7　主机责任人制

根据主机系统承载的业务类型，对其进行安全分类并设定主机责任人，主要负责主机系统的定期安全维护。

4.4.8　文件数据备份

可根据业务数据类型，对业务数据进行安全分类，并实行不同的备份管理制度，备份应采用异地与本地结合的形式，并对备份文件进行完整性校验和定期恢复演练。

4.4.9　安全培训

对企业员工定期进行网络安全培训，增强网络安全意识，实现安全措施作用最大化，增强工业企业竞争性。

5  结语

病毒的防范与治理是一项复杂的综合性工程，不同工业企业可根据本企业的网络安全战略，灵活运用行业标准、等级保护等规范标准开展病毒治理工作，通过技术与管理手段的综合运用，整体提高工业企业病毒防护水平，达到安全促进业务，安全促进生产的目的。
