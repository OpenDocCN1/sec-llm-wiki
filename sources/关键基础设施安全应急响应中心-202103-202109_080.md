# 国际级控制系统安全大咖"防勒索"建言--传感器监控技术可以降低关键基础设施对勒索软件的吸引力

【编者按】接连不断的勒索软件攻击事件，使工业界和网络安全研究者对于关键基础设施的网络安全问题空前关注。摆脱勒索软件攻击的梦魇，不仅仅是一个技术、管理、治理问题，更是经济、法律和国际合作的系统性问题。国际知名自动化控制专家Joe Weiss近日撰文《Sensor monitoring technology can make critical infrastructures less attractive targets for ransomware》，从自动化控制安全的角度给出了他的解决思路。Weiss认为，控制系统网络安全的范式需要一次变革，即从一个棘手的网络问题转变为一个可处理的工程问题。需要的解决方案不是针对网络异常/攻击，而是识别控制系统过程/传感器的异常。勒索软件的祸患使这个需求变得更加迫切。解决方案需要基于物理，不连接到互联网协议(IP)网络，这样解决方案就不会被黑客攻击。也就是说，这个解决方案并没有阻止勒索软件攻击，而是无视勒索软件或IT攻击。该解决方案可以作为综合应急响应计划的一部分，包括在失去自动化操作时进行手动操作的能力，并可用于任何利用过程传感器测量压力、液位、流量、温度、电压、电流、电机转速等的组织。文章中的观点与其一直以来宣称的控制系统网络安全还是要回到控制系统本身来解决的思路一脉相承。

# 

**背景**

过程传感器中没有网络安全、身份验证或网络登录。然而，操作技术(OT)监控系统假定过程传感器是不受威胁的、经过验证的和正确的。正如我有四十多年现场设备经验的同事所说，**“多年来，我一直在和砖墙和砖头谈论现场设备缺乏安全性的问题。他们的反应通常是，他们是有气隙隔离的，一切都是安全和可靠的。充其量是非理性的幻想。在这个过程中，我并不孤单，但我绝对是少数。”**  

这种特殊的传感器健康监测技术是为传感器和设备监测开发的，但可以作为网络安全的输入，因为传感器是OT网络的输入。从最近的 LOGIIC（连接石油和天然气行业以提高网络安全性）过程传感器研究（项目 12 安全仪表）和 ISA84.09 过程中可以看出，传感器生态系统，包括传感器网络和资产管理系统，

存在已知安全漏洞：(https://www.controlglobal.com/blogs/unfettered/ot-network-security-often-does-not-view-control-system-devices-and-the-process-as )。

过程传感器缺乏身份验证和网络日志记录，如 ISA84.09 对 ISA 62443-4-2标准中组件网络安全规范的审查中所确定的那样，目前最先进的有线安全压力变送器无法满足大多数网络安全要求。因此，可以增加身份验证和日志记录的传感器健康监控系统可以成为传感器生态系统、设备监控、过程安全和网络安全的重要补充。

0级、1级设备没有网络安全、身份验证和网络日志。然而，迄今为止，超过1300起实际控制系统网络事件中，许多都直接涉及过程传感器问题，这些事件已造成人员死亡，并造成超过800亿美元的直接损失。俄罗斯、中国和伊朗都意识到这些设备存在网络安全漏洞，在某些情况下，他们正在利用传感器身份验证的不足。ISA 62443-4-2组件网络安全规范的ISA84.09评审指出，目前有线安全压力变送器的大部分网络安全要求无法满足。希望0级，1级设备将补偿控制，因为他们将在未来10-15年或更长时间内使用。人们还希望在未来的标准工作中解决这个问题，从而产生更安全的0、1级设备生态系统。然而，直到工程师们相信他们的设备和网络的网络安全对他们很重要，IT/OT网络组织相信0级、1级设备和过程对他们很重要，否则控制系统将无法确保我们所有的危险得到解决。

传感器健康监测系统的最初演示是一个装满水的塑料水箱，水箱盖上有一个传感器，传感器与可编程逻辑控制器(PLC)连接，这是一个典型的“玩具”演示系统。引起我注意的是，当盖子和传感器一起被打开时，监测系统检测到传感器的电气特性发生了变化，但水箱内的液位没有变化。

为什么这很重要?陶姆索尔克是密苏里州的一个大坝，大坝的土墙上安装了液位传感器。2005年12月，陶姆·索尔克液位传感器附件破裂，传感器从墙上脱落。水库水位没有变化，但传感器的物理位置发生了变化(水位由高程即高度来测量)。因此，表现出水平读数为低水平。由于显示的水位较低，圣路易斯阿莫林的SCADA系统自动打开水泵，一直开着，直到水库溢满，部分坝体坍塌。传感器并没有失效，它们只是提供了错误的读数(如同Max 737飞机坠毁)，这些读数本可以通过传感器电气特性的变化检测到。传感技术能够指示变化，而不依赖于这些变化是由于无意的还是恶意的事件。

同样的感应问题也发生在震网病毒和Triton上。Stuxnet是一种“中间人”攻击，操作人员的显示器被破坏，表面上显示离心机操作没有任何变化。然而，传感器健康监测可以识别出离心机加速或减速，因为电机速度和流量传感器的电气特性会发生变化。对沙特阿拉伯的Triton袭击也是如此。也就是说，传感器特性不能被破坏，并提供传感器和相关过程性能的实时、真实的评估。

# 

**问题**

勒索软件和其他源自IT的网络攻击可以影响控制系统网络的性能，当IT网络连接到OT网络，被攻击破坏的internet连接设备是连接到OT网络的，或关键操作数据保存在IT网络上而没有备份(例如Colonial Pipeline事件)。因此，美国国土安全部(DHS)提出了确保OT网络与IT网络隔离的建议。假设OT网络是可用的，OT网络监控技术可以极大地帮助诊断OT网络的健康状况。但是，未与IT网络完全隔离的OT网络或使用不充分安全的Internet连接设备（例如IOT设备）可能无法使用。在供水的场景下，OT网络受到影响，孤立的传感器监测系统不受影响。这表明隔离的传感器监控系统不会受到勒索软件、其他IT恶意软件或无意OT网络的影响。

目前，勒索软件不是针对控制系统或控制系统OT网络（编者注：2020年初发现的EKANS勒索软件，是直接针对ICS漏洞的，可以认为是第一个此类恶意软件。Weiss老先生可能不认为这是直接针对控制系统的勒索软件。）。与殖民输油管道攻击一样，设施运行被关闭不是因为OT网络或控制系统受到直接影响，而是“通过大量的谨慎”作为过程的态势感知(例如，我们可以通过网络或控制系统来实现的操作，如水系统操作、制造操作、管道条件等，无法得到保证。降低控制系统对勒索软件攻击者吸引力的一种方法，即使在IT或OT网络受到影响时，也能够保持对过程的态势感知。如果过程设施(无论是管道、供水系统、制造设施、医疗设施等)能够继续保持对过程的态势感知，它们就可以证明继续运行的合理性，从而降低勒索软件威胁的严重性。也就是说，监控过程传感器(如压力、液位、流量、温度、电压、电流、电机速度、位置等)的“物理”性能提供了独立于IP网络的过程可靠性和安全性的态势感知。因此，如果IP网络由于任何原因(无论是无意的还是恶意的)不可用，就不需要关闭过程设施，这可以减少过程设施成为勒索软件的目标。

# 

**解决方案**

这种离线传感器监测技术被安装在一家自来水公司，以监测大型关键水泵。网络安全只是一个副产品。对于这种离线传感器监测技术，对原始的、未经过滤的传感器测量值进行监测，并与其他基于已知物理关系的传感器进行交叉比较。在这种情况下，离线传感器监控技术与基于以太网(IP)的Windows显示进行了比较，以确保它们能够被密切跟踪。正如预期的那样，脱机监控系统“正确地”跟踪了Windows HMI，反之亦然。然而，在这个比较期间，基于windows的SCADA丢失了(可能是由于任何原因，包括恶意网络攻击或勒索软件攻击)。然而，离线传感器监测继续提供过程的态势感知，即使离线OT网络。这种持续的态势感知可以为设施继续运行提供保障，即使IT和/或OT网络受到威胁。在这种情况下，它不是检测到恶意软件攻击，而是检测到过程的任何变化，这为继续运行提供了依据。

# 

**额外的好处**

实时原始的、未经过滤的测量提供了额外的好处，包括传感器的认证、设备诊断和生产力的提高。具体地说,

*   由于单个传感器是直接认证的，认证可以帮助解决网络安全和供应链问题，因为多个传感器“洗掉”了许多供应链问题。这也可能有助于中国变压器的硬件后门，以验证传感器数据没有被欺骗。
    
*   在水厂案例中，离线传感器监控技术识别出过滤的基于Windows 的 HMI 未检测到的设备运行问题。这也发生在其他设施中，包括电力、化学品和建筑控制，在这些设施中发现了基于Windows 的HMI未识别的传感器/设备问题。
    
*   传感器健康监测系统可以检测传感器漂移，这是传感器校准程序和数字孪生模型的输入。此外，传感器测量的不确定度可以降低。通过实时监控传感器数据，可以延长维护周期，因为实时传感器监控本质上是预测性维护。
    
*   如果IT网络没有与OT网络充分隔离，监控传感器提供了一个“支撑”。
    
*   由于传感器中没有网络日志，传感器健康监测可以提供潜在网络事件报告的输入，以满足美国运输安全管理局(TSA)新的网络安全要求。当传感器显示设置为平均值时，这种方法可以检测到奥林匹克输油管道破裂的过程变化。在没有传感器监控项目的情况下，尚不清楚TSA是否能够满足识别潜在网络事件的要求。
    

# 

**总结**

当IT网络或不安全的物联网设备连接到OT网络时，勒索软件和其他源自IT的网络攻击可以影响控制系统。离线传感器监控技术并不能阻止勒索软件攻击，而是对勒索软件或IT攻击毫不在意。该技术不受IP网络攻击或无意影响，可以在勒索软件或其他IT网络攻击发生时提供实时态势感知，为继续运行提供支持，从而降低这些系统对勒索软件攻击者的吸引力。这在供水设施中得到证实，OT系统宕机，离线传感器监测系统继续工作。此外，在供水、电力、化学品和建筑控制中，离线传感器监测技术识别出了基于windows的HMI无法检测到的设备运行问题。该解决方案可以作为综合应急计划的一部分，该计划将包括在自动化操作失去时进行手动操作的能力，并可被任何利用过程传感器来测量压力、液位、流量、温度、电压等的组织使用。
