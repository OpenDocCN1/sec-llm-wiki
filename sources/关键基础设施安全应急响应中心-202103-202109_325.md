# 网安巨头RAPID7又遭黑，Solarwinds供应链攻击余音绕梁，Colonial管道公司刚破财消灾。网络空间永无宁日？

据两名知情人士透露，近日“被黑”的美国输油管道公司Colonial Pipeline上周五向东欧黑客支付了近500万美元，而本周早些时候的报道称该公司无意支付勒索费，以帮助美国最大的输油管道恢复运营。美国政府主管机构对此不予置评。Colonial Pipeline拒绝置评。美国总统拜登称无可奉告。

**知情人士称，网络攻击发生后数小时内，该公司就用无法追踪的加密货币支付了巨额赎金，突显出该公司面临的巨大压力。**

COLONIAL13日晚发布第七号声明，当天下午五点重启服务，运营恢复，预计当地时间夜间十二点油气供给可恢复至正常水平。

美国总统乔•拜登周四表示，弗拉基米尔•普京与俄罗斯针对美国一条巨大输油管道的网络犯罪没有关联，他将在预计举行的峰会上提出这个问题。

当被问及普京或俄罗斯政府是否知道这次袭击时，拜登停顿了一下，然后说:“我相信我准确地读到了FBI的报告，他们说他们不知道，他不知道，政府不知道。”

一波未平，一波又起。

知名企业安全供应商Rapid7说，它是Codecov软件供应链攻击的受害者之一，并在当地时间周四警告说，一部分客户的数据在这次入侵中被访问。  

![](../Images/fe080168e38b9b121dd76ab96429d34f.png)

以自动化安全评估工具而闻名的Rapid7表示，一项内部调查发现，“我们用于MDR服务内部工具的源代码存储库的一小部分被Rapid7之外的人未授权方访问。”  

该公司表示，这些存储库包含针对一部分MDR(托管检测和响应)客户的内部凭证和警报相关数据。  

除了Rapid7, Twilio和HashiCorp已经公开确认受CodeCov供应链影响。  

Rapid7在一份声明中表示，它对Codecov的Bash Uploader脚本的使用是有限的，并且只设置在一个CI服务器上，用于测试和构建其托管检测和响应(MDR)服务的一些内部工具。  

然而，调查发现了一些危害，Rapid7表示它确定了以下情况:  

**一小部分用于MDR服务内部工具的源代码库被Rapid7外的未授权方访问。**

**这些存储库包含一些内部凭证，它们都已被循环使用。**

没有访问其他公司系统或生产环境，没有对这些存储库进行未经授权的更改。  

Rapid7表示，他们联系了受影响的客户，以确保他们采取适当措施来减轻任何潜在风险。  

Codecov供应链攻击造成的巨大范围仍然神秘，安全团队继续评估这次入侵的后果，但受害者继续公开承认可能会暴露敏感的开发者秘密。  

据百度百科显示，Rapid7 是全球领先的安全风险信息解决方案提供商，Rapid7 用来漏洞管理,漏洞扫描,漏洞评估和渗透测试。其安装风险智能解决方案包括集成的风险管理和渗透测试产品 Nexpose 和 Metasploit, 它们使您的机构能对安全威胁和风险形势，主动获得准确的情报以及可操作的情境信息。Rapid7 独一无二地定位于提供安全风险情报的闭环解决方案，通过组合Nexpose的漏洞管理功能和Metasploit的渗透测试与风险验证功能，从而动态确定风险的存在和可能性。通过将数据与漏洞、滥用、恶意软件、错误配置和渗透测试信息相关联， Rapid7 将您电脑环境中的真实风险（Real Risk™）数量化。准确掌握了这些情境信息，我们可以提供清晰简洁的缓解建议和补救策略，并随时检测和跟踪风险趋势。
