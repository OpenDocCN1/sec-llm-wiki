# 美国国防部太空发展局表示网络攻击是卫星面临的最严重威胁

# 2021年4月14日

太空发展局局长（SDA）德里克·图尔尼尔（Derek Tournear）。信用：国防部

SDA负责人德里克·图尔尼尔表示：**不管我有一颗卫星还是我有1000颗卫星，网络攻击都可以将它们全部消灭**

华盛顿消息：情报机构和分析人士警告说，中国和俄罗斯正在研制可攻击美国在低地球轨道上发射卫星的导弹。五角大楼的太空发展局将对此感到担忧，该局计划部署的一个卫星网络在这些导弹的射程内。 

太空发展局局长德里克·图尔尼尔（Derek Tournear）在2021年4月14日表示，SDA一直在研究对其卫星的潜在威胁，与其担心导弹袭击，不如担心网络攻击和入侵供应链。  

SDA计划在2022年开始向太空发射卫星，目标是到2024年将有数百颗轨道用于通信和导弹探测。 

图尔尼尔在华盛顿一个在线太空商业圆桌论坛上说，这些卫星对弹道导弹等地面武器“不会无懈可击”。不过，他解释说，拥有一个由数百颗卫星组成的扩散网络，使得系统能够抵御这些类型的攻击。 

对手将不得不发射一连串的导弹来摧毁这样一个巨大的星座，并将面临重大的报复。图尔尼尔还指出，与国防部在轨的价值数十亿美元的卫星相比，SDA卫星相对较低的成本将使其成为不具吸引力的目标。

Tournear估计，击落卫星的成本要比卫星本身高，“因此，我们已经完全改变了行动的模式。”

即使一颗或几颗卫星被摧毁，由数百个组成的扩展网络也可以继续运行。Tournear说，但另一方面，**网络攻击可能是毁灭性的。** 

他说：“网络和供应链是我关注的两个威胁。” Tournear将网络和供应链问题描述为“共模故障”，这意味着即使系统的几个组件或部分受到攻击，整个网络也将无法使用。

供应链攻击是针对供应链中不太安全的元素的网络攻击。 

Tournear说：“因此，无论我拥有一颗卫星还是拥有1000颗卫星都没有关系，这些类型的攻击可能能够将它们全部消灭。” 

他说：“这些是我最关注的威胁，因为这些威胁我认为可以产生最大的毁灭性影响，而其他威胁，我实际上认为扩展为我们提供了巨大的优势。” 

为了捍卫SDA的网络，该机构正在与其他国防部机构合作，开发用于卫星的加密和其他安全设备。Tournear说，这是一个挑战，因为它们必须轻巧，小巧且功耗低。 

Tournear说：“我们需要使这类系统能够使用的高带宽加密单元，才能在卫星上做到这一点。” “这是一个大问题，有多级安全性，因此我可以在星上进行从秘密到最高机密再到非保密的任何处理。这是很大的事情，需要大量的技术开发。”

为了降低供应链入侵的风险，SDA将与供应商合作以确保他们知道组件的来源。五角大楼特别担心在美国系统中使用中国制造的组件或软件可能会为网络攻击提供途径。 

“正如我提到的那样，供应链是我主要关注的问题之一，” Tournear说。“这不仅是供应链的稳健性，以确保我可以得到零件，而且还可以确保一旦获得零件，我就可以验证零件的来源。”

他说，SDA将接受非美国供应商的报价，但将要求国内供应商提供某些关键组件，例如飞行计算机。“了解供应链的来源是一个大问题，因此在进行任何选择时，我们都会对其进行权衡。”
