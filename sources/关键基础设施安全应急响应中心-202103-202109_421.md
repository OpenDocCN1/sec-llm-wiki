# 美国国家安全局发现4个Exchange远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyMzAwMDEyNg==&mid=2247512265&idx=2&sn=71423c9e16f62ae796b125bc2dcb9a5e&chksm=c1e93c98f69eb58ee0fda63a589b3accbe911374462ddba16c67cf032904bffce863b1994fb4&scene=126&sessionid=1681370294#rd](http://mp.weixin.qq.com/s?__biz=MzkyMzAwMDEyNg==&mid=2247512265&idx=2&sn=71423c9e16f62ae796b125bc2dcb9a5e&chksm=c1e93c98f69eb58ee0fda63a589b3accbe911374462ddba16c67cf032904bffce863b1994fb4&scene=126&sessionid=1681370294#rd)

2021年4月13日，美国国家安全局NSA在Exchange邮件服务器软件中发现4个严重的远程代码执行漏洞(CVE-2021-28480,CVE-2021-28481,CVE-2021-28482,CVE-2021-28483)，并上报给微软。

![](../Images/724a562105ad166b2ee3fca34c6a3ac6.png)

![](../Images/4a2bfdd738505222e7320091c924e579.png)  

负责网络和新兴技术的副国家安全顾问安妮·纽伯格（Anne Neuberger）在声明中表示：“我们意识到漏洞可能会带来系统性风险，所以有必要及时披露。”

微软声称至今并没有发现有谁利用漏洞，但安全社区普遍认为，由于本次上报者是NSA，因此漏洞存在极大的研究价值，所以会吸引大量黑客进行补丁比对研究，就像之前的证书漏洞一样。

预计在两周内可能会出现漏洞poc。

![](../Images/5ab2258825b2ef42bcfdfa850c1beb6f.png)

今年年初时，美国约有2万多台Exchange服务器遭到漏洞攻击，这些服务器主要用来处理Web版Outlook邮件。

如此核弹的漏洞，NSA还是选择了上报，那么……黑鸟认为，Exchange软件还是需要谨慎使用。
