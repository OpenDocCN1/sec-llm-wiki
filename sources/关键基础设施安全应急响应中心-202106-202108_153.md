# 美国：如何提高公民对网络威胁的认识

**前情提要**

在针对关键基础设施的网络威胁激增的情况下，美国两党众议院议员周四提出保护网络安全的立法法案，以提高网络安全素养并提高美国公众的意识。

**具体内容**

![](../Images/876b6f70e197dbcf7ed16e61bbf11dbd.png)

**美国网络安全素养法案将要求国家电信和信息管理局 (NTIA) 开展网络素养运动，以帮助促进了解如何保持在线安全并防止网络攻击。**

该活动将包括有关如何识别恶意网络钓鱼电子邮件、经常更改密码和对敏感帐户使用多因素身份验证的需要，并强调使用公开可用的 WiFi 热点所带来的网络风险等问题的课程。

该法案是在最近几个月针对美国的几次重大网络攻击之后出台的。

**由俄罗斯政府支持的黑客实施的 SolarWinds 黑客入侵了 美国9个联邦机构和100个私营部门团体。**最近，对东海岸近一半天然气供应商 Colonial Pipeline 和美国最大牛肉供应商 JBS USA 的勒索软件攻击威胁到了关键的供应链。

该法案的发起人周四对日益增加的网络威胁敲响了警钟，负责人在一份声明中表示，美国人了解他们身边存在的网络风险至关重要。 

**“在过去的几个月里，我们看到美国各地猖獗的网络攻击扰乱了业务，增加了消费者成本，并威胁到了我们的国家安全，”**金辛格说。“为了防止这些攻击的继续进行，我们必须将公众意识与有针对性的网络教育相结合。”

**美国众议院议员在一份声明中说：**“网络安全攻击和数据泄露越来越普遍，给私营公司和消费者造成了数十亿美元的损失，并暴露了无数美国人的私人信息。” “随着攻击者变得越来越老练，美国人必须拥有识别风险和保护自己免受攻击的工具和能力。” 

美国众议院议员Bilirakis 代表包括佛罗里达州奥尔兹马在内的地区。在今年早些时候，一名黑客在那里获得了水处理计划的访问权限，但未成功毒害供水系统。 

美国众议院另一位议员指出了这一事件，并在周四的另一份声明中指出，“这些事件强调了加强和现代化我们的关键基础设施以防止进一步攻击的重要性。”

他表示，该立法“从长远来看将使我们所有人更安全”，而 Houlahan 则强调“对我们网络基础设施的攻击是我们作为一个国家面临的最严重威胁之一。”

**在一系列网络攻击之后，目前对国会对网络安全立法的兴趣激增，参议院立法者开始提出多项其他法案，以解决外国政府和网络犯罪分子对国家日益增加的网络威胁。**
