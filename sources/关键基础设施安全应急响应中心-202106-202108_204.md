# Amazon、GitHub等网站集体脱机，系Fastly CDN中断

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyMzAwMDEyNg==&mid=2247516530&idx=6&sn=7fe95aa01846b37ff19e037e90d236a0&chksm=c1e90d23f69e8435e1215dcc090e4e124cb18fd1ce0100ecd334bf1d0b18b8eb1936d8a5102c&scene=126&sessionid=1681370274#rd](http://mp.weixin.qq.com/s?__biz=MzkyMzAwMDEyNg==&mid=2247516530&idx=6&sn=7fe95aa01846b37ff19e037e90d236a0&chksm=c1e90d23f69e8435e1215dcc090e4e124cb18fd1ce0100ecd334bf1d0b18b8eb1936d8a5102c&scene=126&sessionid=1681370274#rd)

6月8日，由于全球互联网内容交付网络Fastly CDN出现中断故障，包括Reddit、Spotify、PayPal、GitHub、gov.uk、CNN和BBC在内的全球大量网站遭遇了一个多小时无法访问的“困境”。

Fastly：一家美国云计算服务商，其边缘运算平台为众多网站提供内容分发、网络安全、负载均衡等服务。

![](../Images/a6478d615f951565cf50523eedcc773a.png)

受影响的网站波及数十个国家和地区，包括但不限于以下站点：  

*   Amazon
    
*   Amazon Web Services (AWS)
    
*   CNN
    
*   Debian.org repos (https://deb.debian.org/)
    
*   GOV.UK
    
*   GitHub
    
*   Heroku (https://dashboard.heroku.com/)
    
*   PyPI.org
    
*   Reddit
    
*   RubyGems.org
    
*   Shopify
    
*   StackOverflow
    
*   TechRadar
    
*   The Verge
    
*   TomsGuide
    

故障期间，这些网站在被访问时，会显示“连接失败”、“错误”或者HTTP 503代码。

![](../Images/b0419ce47de043c8e675ef7c1c0f6322.png)

此外，亚马逊和GitHub网站上可能托管于Fastly CDN的图像（或头像）、JavaScript文件、CSS则完全不能正常加载。  

![](../Images/cc23e7d9c13aef4f302f1100534c6c36.png)

CDN中断疑云

当Fastly的服务状态显示其正经历全球CDN中断，这导致了北美、南美、欧洲、亚太、南非和印度的服务性能遭受影响。对于此次中断的原因也引发了诸多猜测。

虽然目前有一定猜测是黑客攻击所致，但根据最新消息。Fastly主动声明，此次中断原因为“服务配置”。一个服务配置问题在全球范围内引发了其POP的中断，并禁用了该配置。现在该问题已经修复，但是Fastly也表示客户可能会继续经历一段时间的源头负载增加。
