# 传说中的伊朗黑客哪儿去了？俄罗斯铁杆朋友伊朗似缺席俄乌网络大战！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyMzAwMDEyNg==&mid=2247525222&idx=2&sn=a784ff2547771a5e6a56f2dc5c6e1952&chksm=c1e9ef37f69e6621215b36573eefbb083ea1e8b27efe5794499cf38f6c187cafbf859db1b0c7&scene=126&sessionid=1681370176#rd](http://mp.weixin.qq.com/s?__biz=MzkyMzAwMDEyNg==&mid=2247525222&idx=2&sn=a784ff2547771a5e6a56f2dc5c6e1952&chksm=c1e9ef37f69e6621215b36573eefbb083ea1e8b27efe5794499cf38f6c187cafbf859db1b0c7&scene=126&sessionid=1681370176#rd)

俄乌冲突在物理空间和网络空间的战事正酣。有专家认为俄罗斯在乌克兰的军事行动在现阶段遭遇重大挫折，具体原因尚不清楚。战场报告指出俄罗斯部队之间缺乏协调和沟通，后勤困难以及部队与总部工作人员缺乏沟通。俄罗斯尚未建立对乌克兰的全面空中优势，其自吹自擂的电子战能力迄今尚未扰乱乌克兰的通信。在网络空间方面，人们翘首以盼的对乌压倒性的网络优势甚至重大挫折或攻击，至少目前还没出现。网络手段也不能有效地中和乌克兰的互联网或使乌克兰的电信和移动电话系统宕机。俄网络战能力似遭质疑。或者说网络战在混合战争中的效能需要重新定义和评估。另一方面，在网络空间，支持俄罗斯的黑客小组，甚至俄罗斯的盟友，这期间也没有被爆出“骄人战绩”。美国对俄罗斯的盟友，比如中国、朝鲜、伊朗，除了摸黑，就是煽风点火。俄乌战事一开，美英就联合发布网络攻击警报，称伊朗的黑客要动手了。ODNI年度威胁评估称伊朗是网络攻击的机会主义者。更有甚者，曾经的NSA特工教练，知名网络安全公司SentinelOne首席安全顾问、网络安全专家Morgan Wright撰文称“普京正在利用伊朗进行网络战”。英美联合警报是一种威慑？俄乌冲突是何其理想的机会。怎么也没看到伊朗黑客掀起什么风浪。伊朗黑客在这期间保持静默了？![](../Images/a5539f1ef68f460a0d8b37081e480d01.png)伊朗历来是俄罗斯的坚定盟友。随着伊朗与西方在其核计划上的敌对行动日益加剧，它比以往任何时候都更加依赖俄罗斯在国际舞台上的支持。虽然伊朗表示反对乌克兰战争，但它拒绝谴责军事行动。在联合国谴责俄罗斯入侵的投票中，它与中国一起投了弃权票。相反，伊朗最高领导人阿亚图拉·阿里·哈梅内伊认为，这场战争的根本原因是美国的“黑手党政权”和西方大国的政策。俄罗斯对乌特别军事行动的当天，美国CISA就联合FBI、美国网络司令部网络国家任务部队 (CNMF) 和英国国家网络安全中心 (NCSC-UK) 就发布了联合警报，称观察到一群伊朗人政府资助的高级持续威胁 (APT) 参与者，称为 MuddyWater，针对电信、国防、地方政府以及石油和天然气等部门的一系列政府和私营部门组织进行网络间谍活动和其他恶意网络行动在亚洲、非洲、欧洲和北美。注意：MuddyWater也称为Earth Vetala、MERCURY、Static Kitten、Seedworm 和 TEMP.Zagros。MuddyWater 是伊朗情报和安全部 (MOIS) 的一个下属部门。2月份美国情报总监办公室(ODNI)发布的最新年度威胁评估报告中，称伊朗是网络攻击的机会主义者。ODNI认为伊朗日益增长的专业知识和开展激进网络行动的意愿使其成为美国和盟国网络和数据安全的主要威胁。伊朗以往的表现，更容易把美国的关键基础设施所有者作为攻击的目标，特别是当德黑兰认为它必须证明它可以在其他领域反击美国时。 3月4日，SentinelOne首席安全顾问、网络安全专家Morgan Wright撰文称“普京正在利用伊朗进行网络战”。Wright是网络战略、网络恐怖主义、国家安全和情报方面的专家。他不止一次在政府委员会作证，包括需要改变美国政府在其数字医疗系统 (healthcare.gov)中收集识别数据的方式。他教授NSA特工行为分析，并在各种执法机构工作了大约18年。除此之外，他还为 Cisco、Unisys 或 Alcatel-Lucent等科技巨头开发了不少解决方案。在中央情报局和国家安全局的工作之间跳来跳去，并为政府和网络公司提供建议和协助。![](../Images/d5aaee0a16848421a101357c933de3f2.png)Wright恶评伊朗时说，俄罗斯在攻击性的网络领域帮助伊朗，更不用说让它得逞了。对俄罗斯人来说，伊朗人是一个“有用的白痴”。他们为俄方提供了影响偏远地区的手段。伊朗人还充当了一种制造混乱的代理人，可以制造一些有利于俄罗斯人不被认为与此事有关的举动。不仅仅是伊朗，白俄罗斯也是这个游戏的一部分，特别是在网络的世界里。Wright说白俄罗斯领导人亚历山大•卢卡申科(Alexander Lukashenko)是弗拉基米尔•普京(Vladimir Putin)的傀儡。Wright称俄罗斯人正在利用伊朗作为代理人。他们互为合作伙伴。俄罗斯在网络领域帮助伊朗人。看看卡巴斯基公司，他们发现了对伊朗核计划计算机造成的火焰和Stuxnet攻击。俄罗斯人正在各个层面帮助伊朗——网络武器、技术支持等等。伊朗对他们有用，因为他们可以远程使用。  然后，俄罗斯将伊朗变成了一个网络强国，为它提供了武器、知识和能力。在卡巴斯基提供对 Flame和Stuxnet的访问权限后，伊朗或俄罗斯对病毒进行了逆向工程，并将其转移到沙特阿拉伯并关闭了沙特国家石油公司。但迄今为止，俄乌战事期间尚没有出现网络事件报告指称伊朗攻击组织，也未见伊朗攻击组织替俄方攻击了乌克兰的目标。在3月12日最新更新的支持俄-乌网络大战的攻击组织名录中，支持俄罗斯的共有18支黑客小组，目前看有6个小组未注明其所处的地区，其余12个团队均标注了俄罗斯或白俄罗斯。因此也无法判断那6个小组里是不是有伊朗黑客小组。至少，目前还未看到支持俄罗斯的黑客小组的比较突出的攻击成果。![](../Images/a841e729d6c028e20740e0eec5b62297.png)不可否认的是，俄罗斯与伊朗之间网络安全的合作，是有很好的基础。2021年1月，俄罗斯外长谢尔盖·拉夫罗夫和伊朗外长贾瓦德·扎里夫签署了网络安全和信息通信技术(ICT)合作协议。该协议包括网络安全合作、技术转让、联合培训以及在联合国等多边论坛上的协调。尽管协议中概述的与莫斯科的合作可以提升德黑兰的进攻性网络能力，但该协议在很大程度上是防御性的，其动机是两国对美国及其在中东影响力的共同敌意，以及减少对西方国家依赖的愿望。然而，期望双方合作的紧密程度是有限度的。长期以来，俄罗斯与伊朗的关系相互猜疑、意识形态分歧和竞争。此外，在过去，俄罗斯和伊朗的运营商一直在交叉经营。例如，2019年10 月，英国和美国官员透露，俄罗斯威胁行为组织Turla作为假旗行动的一部分，劫持了伊朗的黑客基础设施。由于怀疑和相互冲突的目标，莫斯科和德黑兰之间的网络合作很可能集中在情报共享和改善网络防御上，而不是共享进攻能力。这也有可能成为伊朗不会在俄乌网络大战中出头的可能原因之一。美国及西方盟友警惕俄罗斯与伊朗网络安全合作的重点，不仅仅在于俄助力伊朗提升其网络能力，更重要的是俄罗斯黑客可以获取并逆向分析美国或以色列对付伊朗的恶意软件(比如Stuxnet)，伊朗也可以利用从俄方学到的技术支持中东的代理人，如真主党和伊拉克和也门的民兵组织。数字空间的魅力就在于不确定性，你看到的也不一定是事实。就好像目前对俄罗斯在此次特别军事行动中网络战的各种猜测，真相可能永远沉寂于冰山之下，不为人知。伊朗黑客也是一样。**参考资源：**1.https://www.calcalistech.com/ctechnews/article/sk200ds1wc2.https://www.cfr.org/blog/iran-russia-cyber-agreement-and-us-strategy-middle-east3.https://www.cisa.gov/uscert/ncas/alerts/aa22-055a
