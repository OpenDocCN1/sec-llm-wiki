# 主动干预，以黑止黑：美FBI打击涉网犯罪发生重大思路转变

*   FBI宣布成立专门调查加密货币的新部门，司法部任命国家加密货币执法小组负责人，并加大国际合作力度，以全链条打击利用加密货币的勒索软件等犯罪活动；
    
*   司法部副检察长摩纳哥称，FBI和司法部将在调查完成之前采取更多措施来干扰网络犯罪行动，将在调查的每个阶段评估是否使用破坏性行动，即使这意味着要提醒嫌疑人，但至少能够减少损失；

作为美国联邦政府打击勒索软件及其他网络犯罪团伙整体规划的一部分，FBI正在着手组建一个新部门，专门负责调查涉及加密货币的滥用行为。

同时，司法部也启动了一项国际虚拟货币倡议，希望与执行部门、检察官及加密货币平台开展合作，共同跟踪赎金去向、制定法规与反洗钱立法。

这些新举措标志着美国政府打击勒索软件团伙行动的进一步升级，也是对去年以来不断加速的监管行动的延续。

# 

**成立新部门首战告捷**

2021年10月，美国司法部宣布成立国家加密货币执法小组(NCET)，目前该小组已经拥有12名律师成员。

上周四(2月17日)，司法部副检察长丽莎·摩纳哥(Lisa Monaco)宣布，经验丰富的网络安全检察官Eun Young Choi被正式任命为NCET主管，领导它与FBI新成立的虚拟资产利用部门(Virtual Asset Exploitation)密切合作。

摩纳哥透露，虚拟资产利用部门近期没收了价值超过36亿美元的比特币赃款，这正是2016年Bitfinex黑客攻击案中被盗的资产。首战告捷也让新团队更加明确了自己的职能定位与工作重点。

摩纳哥在慕尼黑安全会议的主题演讲中表示，“我们将高度关注涉及加密货币的滥用行为，并将我们自身的努力同各级执法部门对于加密货币的多方关注汇聚起来，共同打击洗钱等违法行为。”

“近期没收巨额比特币赃款，是我们用行动发出的明确信号，犯罪分子绝不应将加密货币视为法外之地。”

# 

**公私/国际合作联合打击**

虚拟资产利用部门拥有具备加密货币与区块链专业知识的特工，负责跟进加密货币与交易所滥用、追踪网络犯罪利润去向、并与其他执法机构合作开展加密货币调查等任务。

摩纳哥强调，尽管司法部与FBI都拥有强大的调查资源，但网络犯罪侦破工作仍需要全球各地机构的通力合作。

她表示，“与其他由加密货币助力的犯罪活动一样，勒索软件攻击只有在恶意一方能拿到报酬时才会起作用。所以我们必须破坏这种商业模式。在这里也呼吁一切经手处理加密货币的企业，根除非法滥用行为。如果未能尽到这项义务，我们也将追究这些企业的相应责任。”

“只要经手加密货币的企业能够及时报告，我们就能跟踪资金动向，从而为企业、更是为下一名潜在受害者提供帮助。在与国际合作伙伴的协同之下，我们的努力必将有所回报。打击加密货币滥用行为是一项复杂的工作，任何一方都不可能孤身取胜。合作才是关键，而且越早越好。”

为此，摩纳哥还表示将任命一位新的网络行动国际联络员，负责与欧洲及其他地区的执法机构合作开展联合调查。“这位联络员将与我们的合作伙伴接洽，加快对抗顶尖网络攻击团伙的脚步。”

# 

**将开展破坏性行动，阻止犯罪者发起网络攻击**

在技术方面，摩纳哥表示，联邦调查局和司法部的目标是在调查完成之前采取更多措施来干扰网络犯罪行动，即使这意味着要提醒嫌疑人，但至少能够帮助受害者减少损失。这可能意味着更多的服务器被查封，在可能的情况下发布勒索软件解密工具，或者使用其他技术手段来阻断或预防攻击。

她说：“展望未来，我们将在调查的每个阶段评估是否使用破坏性行动。在我们提出指控之前，我们将评估是否可以采取措施来防止袭击。我们应该考虑使用所有可用的工具。”

“将这些工具与其他工具结合起来，可以让我们更灵活地破坏网络威胁，尤其是罪犯在敌对国家寻求安全避难所时。如果你继续来‘找’我们，我们就会去‘找’你。”

对于一个从来都是被动而非主动的部门来说，这是一个重大转变。摩纳哥表示，新的思路类似于21世纪初（注：911事件后）美国在国家安全层面上发生的转变。

“从某种意义上讲，这已经是一种文化变革。我们之前在国家安全方面就做出过类似的转变，开始强调对第一波攻击的预防。有了这样的指导思想，我们才知道该如何推进工作，雇用什么样的人才。”
