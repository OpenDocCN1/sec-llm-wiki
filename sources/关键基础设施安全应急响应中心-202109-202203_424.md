美国智库型研究机构国家亚洲研究局文章《赢得与中国的5G技术竞赛——美日合作阻绊竞争、快速发展、解决问题的制胜策略》为美日赢得与中国的5G技术竞赛提供了相应战略。本文进一步总结分析美日针对中国的5G竞争策略及其特征，并据此提出相应战略建议，以期促进我国5G产业发展。

# 

**一、美日针对中国5G的竞争策略:以供应链为核心，联合盟友遏制中国5G发展**

总体而言，该文章所提出的战略可以分为内外两方面。对内，美日两国遏制中国5G产业发展的态度更加嚣张，手段日益多样化。一方面，美日两国以供应链为核心全面遏制中国5G发展。为限制中国企业的市场准入，美国和日本采取了切断有关中国企业进入关键市场、阻断ICT技术投入与人才、收紧外国投资审查程序以阻断资本渠道等多种方式以达到在ICT市场阻碍中国5G技术发展的目的；且美日政府手段更加强硬，越来越多的限制或禁止政府部门或私营企业与中国企业合作。另一方面，美国与日本以产业政策为重点，正在积极投资安全和有弹性的5G技术，并将其作为通向6G解决方案的桥梁，同时利用出口促进和发展融资工具，并这些技术在第三国市场传播，以激发国内5G市场活力并提供中国5G通信技术的替代方案。

对外，美日两国联合其盟友制衡中国5G发展。在要求盟友同时限制中国5G企业的市场准入等方面外，美国在国际社会大肆渲染中国5G威胁，抹黑中国以运用IP盗窃、补贴及贷款优惠等不公平的经济行为来实现华为和中兴通讯等企业的竞争优势。另一方面，美国与日本以数据隐私保护之名，行主导标准制定之实，施展政治外交手段，试图联合包括欧盟、印度、韩国、英国和台湾等国家与地区，共同制定支持和推广受信任的5G技术战略。文章也进一步建议美国与日本制定自己的国家技术战略，为信息和通信技术规范建立基础广泛的支持。不难看出，美国维持全球霸权和主导全球网络空间的也行更加明显，“保护数据隐私，维护技术安全”的背后实质上是美国对于自身领先地位的焦虑和维护全球霸权的战略决心。

综上所述，美日针对中国的5G竞争战略的具体措施手段多样化且态度更加嚣张；对外，联合盟友主导网络空间的野心也愈发凸显。除此之外，当前美国针对5G的系列政策已将5G技术作为一个整体视为保护国家安全、维护全球霸权的关键环节，将技术议题上升到了国家安全的程度，可见5G技术竞争在中美大国博弈中的关键作用。诚然，信息和通信技术长期以来一直是国家竞争和市场准入保护的焦点。目前，美国在于中国的5G技术竞争中处于落后位置，中国潜在的5G优势对美国与日本来说代表着严重“危险”，也可能会使两国在军备竞赛中处于不利地位。在此环境中，中国必须继续坚守国家利益底线、保持改革发展定力，在追比赶超的自主发展中不断争取对美日博弈的战略主动，坚定促进我国5G技术发展。

# 

**二、中国应对5G领域战略竞争的建议**

世界正在进入以信息产业为主导的经济发展时期，在中美战略竞争不断加剧的今天，5G技术竞赛已成为一个重要维度。而随着中国在信息通信技术领域实力的增强和综合国力的提高，必然会遇到美日两国政府的遏制措施。中国应理性看待美日针对中国所提出的5G技术竞争战略，并在此基础上积极应对中美间在科技领域的竞争，在战略博弈中不断发展壮大，化解对方攻势并维护自身利益，促进我国5G发展。中国应坚定5G发展战略，促进自主创新能力，同时化解中国在科技外交上可能面临的不利局面，努力拓展同其他国家在科技领域的合作空间，才能在大国博弈中维护自身利益，发展本国产业并寻求大国共处之路。

**( 一 ) 加强5G战略地位**

与美国与日本相比，中国以其国家主导的决策过程，在战略技术的发展速度和投资规模方面具有若干优势。中国可以直接支持诸如华为和中兴这样的科技公司，并利用“一带一路”倡议等战略计划，来支持其整体经济、技术和国家安全政策目标。在美国与日本也渐渐将5G提升到国家战略的层面的今天，中国需要坚定支持5G发展的战略目标。在制定产业政策进行扶持的同时，也需完善5G产业生态，促进5G产业数字化、网络化、智能化转型。加强5G产业与医疗服务、交通物流、工业互联、煤矿能源、公共事业等行业的融合，把握数字化、网络化、智能化融合发展的契机，最大限度的开发5G在社会发展与经济建设中的作用。

**( 二 ) 增强自主创新能力**

美日两国联合其盟友，通过出台法案、实施贸易实体清单限制、污蔑中国设备对个人隐私和国家安全构成威胁等方式，在美国、日本和部分盟国的技术市场上加快驱逐中国ICT企业，并限制中国获得必要的ICT技术组件。由于技术水平的差距，中国网络安全和信息化领域关键技术仍然受美掌控，中国5G提供商存在着依赖半导体进口的核心弱点。在中美5G技术竞争竞争日益加剧的背景下，中国掌握核心技术的需求更加迫切，中国只有不断增强自主创新能力，才能够妥善应对美日带来的5G威胁。一方面，中国需要加强科技创新人才培养，为5G自主创新提供充足的人才储备，应对美日限制ICT人才回流中国的举措。另一方面，中国需要促进核心产业技术的研发，摆脱对外国ICT技术组件等技术产品的依赖，真正实现自主创新，在国际科技竞争中占据制高点。

**( 三 ) 深化科技外交**

美国与日本联合盟友遏制中国5G发展的全球攻势大多依靠威胁与强迫等手段，且在该问题上各个盟友的反应不一。一方面，倾向于禁止使用中国5G产品与美日联盟的国家大多与美国意识形态相近，美日与其国际同盟的基础也大多侧重于共同抵御威胁、保护数据安全等方面。美日污名化中国5G技术，为其扣上“危害国家安全与数据安全、侵犯人权”的帽子，才使得美日获得其可乘之机。因此，中国应通过拓展第三方科技合作空间，努力消除美国消极言论对中国所造成的负面影响。另一方面，相对低的价格和领先全球的技术水平使得中国5G在更多国家都具有经济优势和技术优势。中国5G企业也可以凭借“一带一路”倡议等国际战略开拓国际市场，促进各国信息互联互通，加强与他国交往并深化科技领域的合作。

**( 四 ) 制定必要反制措施**

中国在提升自身5G实力的同时，也应储备必要的政策工具，制定政策反制措施以应对美国针对性5G竞争政策。一方面，通过政治、外交等多重手段收集美国政府与企业“不友好”或“不安全”行为的证据，为对美国进行反击做必要准备；另一方面，利用国际舆论，披露美国违反国际经济规则、威胁国际市场秩序，在国内外网络空间治理理念和规则上实行“双重标准”的负面信息，从而对美国适当施压，把握网络空间问题的道德制高点，提升中国在全球网络安全治理领域的话语权。
