# 

**01、方案介绍**

电力建设智慧安全监管平台（简称：监管平台）是以科技信息化手段行使电力建设行业安全监管职能的平台，监管平台前端是电力建设项目安全信息管理系统(简称：智慧安全管理系统)，“监管平台”和“智慧安全管理系统”一起构成了电力建设工程项目监管/管理系统。“智慧安全管理系统”通过人工智能、物联网等一系列技术手段采集和收集安全管理基本信息如：通过门禁系统监控入场人员安全培训情况，监督关键岗位人员上岗情况；通过远程视频信息监督施工主要现场安全及文明施工情况；通过无人机观察重要工序实施过程安全管理情况；通过智能算法，掌控和学习现场安全管理情况等。还通过参建各单位的安全管理、技术文件、现场图片等信息的定期输入，发现安全生产管理的薄弱环节。对发现的问题，按安全生产标准化规范的要求，提示有关单位进行问题及隐患整改，并进行项目安全生产管理基本和结果数据的整合及传输。“监管平台”关注工程项目安全监管和管理的重点环节和项目安全生产管理动态过程如：专项施工方案编审批过程是否符合要求、安全交底是否有效落实、隐患排查活动是否有效开展、隐患治理是否得到有效落实、参建单位安全教育培训是否有效开展、从业人员是否真正掌握安全生产常识等，督促有关单位进行问题及隐患整改。若干项目的管理系统安全管理信息将汇集于“监管平台”，经“监管平台”的信息处理系统对整个行业项目安全信息的处理，形成全国电力建设工程项目安全生产的在线和实时监管信息，并在项目安全信息大数据分析软件支持下，生成行业安全监管报告，对电力建设安全形势走向做出判断。“监管平台”和“智慧安全管理系统”都在行业安全管理专家的管理和指导下，依据安全生产法律法规和安全标准化规范运行，在“监管平台”和“智慧安全管理系统”间的沟通机制支持下，将整改、治理安全生产问题和隐患做为监管、管理的最终落脚点，实现“企业负责、职工参与、行业自律、政府监管、社会监督”安全管理局面，提升全行业的安全管理水平和层次。电力建设智慧安全监管/管理系统是新一代信息化技术在电力建设工程领域应用的一次创新，具有先进性、实用性和有效性。通过电力建设安全管理的大数据分析及应用，实现了电力项目建设过程安全的动态管理，有效提升电力建设工程项目安全生产管理水平。

**02、基于平台构架部署的方案**

电力建设智慧安全监管/管理系统以混合云方式进行设计。**(1) 本地数据中心(私有云)：**将监管平台内部核心系统与核心数据放置在自建数据中心以确保核心数据的安全；核心数据部署在本地数据中心，使用高速通道专线接入保证云上数据快速同步，实现云上云下数据互通。**(2) 云上业务(公有云)：**云上部署对外应用服务，实时应对业务访问量激增同时能够减少服务器设备的维护；数据中心使用VPC、RDS、ECS搭建云上业务系统，使用VPN通过建立IPsec隧道将本地数据中心和专有网络VPC快速连接起来，构建混合云，如图1所示。![](../Images/16a52a1d9b92f29cff908f7de85827db.png)图1 混合云方式系统架构图(3) 随着平台运营时间的推移，平台的业务数据、文件日益增加，平台应用计算压力越来越大，平台容器、服务越来越多，规模越来越大，我们需要在不影响系统运转的情况下悄声无息的对系统进行升级扩展，以提高系统的计算能力，数据中心采用超融合服务器部署，不仅解决日益增长的业务数据，还能进一步确保数据的安全性。智慧安全信息化系统采用B/S架构，基于通用平台基础之上进行设计，MVC模式开发；具备通用平台带来的灵活性、安全性和可靠性。MVC框架是软件设计典范，是业务逻辑、数据、界面显示分离的方法组织，将业务逻辑聚集到一个部件里面，在改进和个性化定制界面及用户交互的同时，不需要重新编写业务逻辑，从而提高了代码的可读性和可维护性，是目前比较流行的开发框架之一。电力建设智慧安全管理系统的整体系统架构体现如图2所示：![](../Images/bba77ad6e3d20ee21a9b8d7c1c17cbbf.png)图2 电力建设智慧安全管理系统架构**(1) 数据层：**该层提供数据库读写操作，设计采用MyBatis框架，该框架支持定制化SQL、存储过程以及高级映射，避免了几乎所有的JDBC代码和手动设置参数以及获取结果集，大大提高了开发效率和系统的灵活性。平台默认基于Mysql数据库搭建同时支持MSSQL和ORACLE等主流关系型数据库。对Mysql系统采用Innodb和Infobright两种引擎，Innodb主要对平台中的关系型数据进行存储和处理；Infobright主要对平台中非结构数据进行存储和处理；通过业务类型区分处理引擎的设计有助于提供系统读写和存储效率。**(2) 支持层：**该层是基础平台提供的通用组件，主要包括：组织机构、角色权限、安全认证、工作流、任务调度、UI框架、服务总线、知识库等；通用组件作为业务系统二次开发的基础，使开发人员在进行二次开发时更专注于业务开发，支持客户需求的快速响应。**(3) 业务层：**该层为业务应用层，在业务支持层的基础上进行二次开发，该层主要提供平台的业务模块，业务模块之间通过接口（webservice）相互访问，实现低耦合。本系统中，业务层主要电力建设项目，系统将通过采集、汇总与分析等手段结合业务的各维度全视角展示电力建设项目在安全管理运行过程中的安全指数。**(4) 表现层：**表现层包括PC、Android和iOS移动端；PC采用BS模式MVC框架设计开发，UI层基于Bootstrap、jquery、ajax技术开发，移动端设计采用html5+原生+控件库(SUI Mobile)方式。在安全设计上，电力建设智慧安全管理系统确保了网络、系统、数据、应用及管理的安全，系统具有安全高效的通信机制、身份认证、权限检查，充分采用系统级控制数据库的存取机制和对象级控制数据库的存取机制以保证系统的安全性、保密问题，防止信息泄密和对保密信息的非法侵入，并提供可靠的数据备份与恢复功能。在整体设计和系统有机集成的同时，对安全性和可靠性有统一完整的考虑，要有完善、周密的安全体系，具有安全可靠的加密手段和方法。

**03、系统主要功能**

电力建设智慧安全监管/管理系统实现了对工程项目现场人员、机械、施工的全方位、全过程实时监管和管理，“监管平台”和“智慧安全管理系统”相结合，有效提高电力建设工程监管能力和安全生产管理水平，提升了工程项目现场安全管理效率。监管/管理系统主要功能如下：**(1) 重视人员/机械信息：**全面采集和整合工程项目的人员、机械基础属性和准入资料，为工程项目信息化管理提供原始数据。并通过系统数据中心多维度的信息处理，形成信息化系统各管理模块所需的安全生产要素基本信息。**(2) 关注安全基础信息：**通过对项目施工过程中的作业标准执行、相关技术专项方案、安全管理活动文件、视频信息进行专家评价和沟通管理，构建安全生产安全管理基础信息，形成安全生产监管/管理的动态过程，使安全生产管理过程呈现有效性。**(3) 推进安全标准化管理：**“项目管理系统”的编制依据和基础是《企业安全生产标准化基本规范》(GB/T33000-2016)。在信息化系统的规范运作下，推动安全生产管理思维、行为及结果不断向“标准化规范”的方面靠近，形成以安全法律法规、规程规范为准则的安全生产管理意识。**(4) 强化隐患排查治理：**隐患排查治理是近几年安全生产管理工作不断强化的重要管理环节。应用信息化手段使设置隐患排查问题清单、统计类型和数量、发生的区域和单位、设置预警值、落实隐患治理，使隐患排查治理各环节清晰及可操作，使隐患排查治理的结果可量化及应用。通过安全智库的智能匹配和推送，提高隐患排查的效率和排查依据。**(5) 形成“全员参与”局面：**通过移动手机APP功能，实现项目参建各方、各级管理人员对现场施工人员、机械、管理活动、现场实况的异地查阅、及时决策，提高安全管理信息的交换速度，增强了安全生产管理的透明度，使广大职工更大范围内参加安全生产管理活动。

**04、方案推广价值**

(1) 电力建设工程项目监管/管理系统根据《中国中央国务院关于推荐安全生产领域改革发展的意见》及《关于推进电力安全生产领域改革发展的实施意见》(发改能源规\[2017\]1986 号)关于“建立安全科技支撑体系，加快安全生产信息化建设，运用大数据技术开展安全生产规律性、关联性特征分析，提高安全生产决策科学化水平”的精神，由国家能源局总策划，中国电力建设企业协会专家指导，应用新一代信息化技术，适应大数据时代流程再造，为实现国家能源局“互联网+安全监管”战略提供大数据支撑。(2) 电力建设工程项目监管/管理系统是依据《企业安全生产标准化基本规范》(GB/T 33000-2016)的八个要素和能源局相关安全督查内容进行设计和制作，是电力建设行业实施《企业安全生产标准化基本规范》的体现，是实现电力项目安全监管/管理标准化的重要措施。监管/管理系统重点体现了安全生产标准化规范的相关内容，促使行业安全生产管理向标准化方向发展。(3) 电力建设智慧安全监管/管理系统是工程项目安全生产信息化管理系统，其核心是一套流程化、网络化的工程项目安全生产管理和咨询服务体系，为各电力建设项目各安全管理环节、施工现场各重要部位及工序提供安全信息化管理方法。在人工智能、物联网等先进技术支持下，实现安全数据采集、隐患及时跟踪、风险预测预警、整改过程管理、安全事件分析等，强化了电力建设监测预测、风险预警的能力，全方位降低施工安全及管理风险。(4) 电力建设智慧安全监管/管理系统借助配套《电力安全生产管理云平台》、《机器人巡检系统》、《安全智库》、《4D-BIM管理系统》的辅助系统支撑，可使信息化系统向更智能化和更高级的方向发展，使安全监管和管理工作更上一层楼，在电力新技术不断涌现的市场形势下，将更加促进电力建设安全生产管理工作适应新形势。
