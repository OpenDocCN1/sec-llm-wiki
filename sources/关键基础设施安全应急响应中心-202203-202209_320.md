# 警惕！强制渗透测试式勒索攻击--新的“勒索之家”组织创立了新勒索市场并公布了第一批受害者

最近的勒索攻击活动有些新变化。先是著名的Conti勒索组织宣布从此金盆洗手退出勒索江湖，其实只是采取新的战略战术，化整为零打游击。很快，又出来一个Goodwill勒索组织，不为钱只为名，要求受害者做慈善，得做三件好事！！这第三个，刚刚被安全研究者注意到的，刚刚出现在暗网上的勒索之家(RansomHouse)，是一个勒索数据的网络犯罪组织，威胁行为者会公布被盗文件的证据，并泄露拒绝支付赎金的组织的数据。这项新行动声称不会使用任何勒索软件，而是专注于通过所谓的漏洞破坏网络，窃取目标的数据。然而，他们不为自己的行为负责。相反，他们指责这些公司没有妥善保护自己的网络，并指责它们为漏洞披露提供的漏洞赏金“小得可笑”。RansomHouse实际上是在向从未使用过他们的服务或奖励漏洞赏金的组织强制“渗透测试服务”，一旦他们发现任何漏洞，他们就会充分利用这些漏洞来窃取尽可能多的敏感数据。

“我们认为，罪魁祸首不是发现漏洞或实施黑客攻击的人，而是那些没有妥善处理安全问题的人。罪魁祸首是那些没有锁门的人，让门大开着，邀请所有人进来，”威胁勒索屋的行为者在他们的“关于我们”页面上写道。

“人们天生好奇，渴望了解自己感兴趣的对象。通常情况下，企业对“大门敞开”的回应是负面的、直接的威胁或沉默。在极少数情况下，人们可能会得到感谢，得到的报酬少得可笑，甚至还不到热衷者努力的5%。”

Cyberint公司对2022年勒索软件前景的预测之一是，勒索软件组织将开发并努力在可能的情况下仅要求为被盗数据付款，并消除其活动中的加密阶段。RansomHouse正是采用这种技术的组织之一，因为他们声称他们在活动中不使用任何加密。

**针对受害者的数据**

据信，勒索之家成立于2021年12月，第一个受害者是萨斯喀彻温省酒类和博彩管理局(SLGA)，该机构现在被列在勒索网站上。

自本月推出该网站以来，威胁行为者又增加了三名受害者，最近的是一家德国航空公司支持服务提供商，上周遭到攻击。

![](../Images/c0bd3647cb1a7f2629e3b0b5956b3cef.png)

还在调查中勒索案例的最新受害者名单

有趣的是，RansomHouse列出了仍在被勒索的受害者的媒体帖子url，强调他们攻击的公开性，并将其作为一种额外的勒索手段。

如果受害者不向黑客支付赎金，他们的数据就会被卖给其他威胁行为者。如果没有人有兴趣购买它，被盗的数据集就会发布在Tor网站上。

  

![](../Images/6b1a8908162e5539b5dc167a82949667.png)

声明拒绝谈判的受害者的被窃取的数据将被出售

**一个奇怪的起源**

“勒索之家”的起源有点奇怪，该组织最初是在白兔（White Rabbit ）的勒索信中提到的，但行为者们坚称他们只是与勒索软件团伙合作，自己并没有使用勒索软件。

在Cyberint公司23日天发布的一份报告中，分析人士发现Telegram上有在Lapsus$ gang Telegram频道上推广勒索屋的帖子。这表明威胁行为者同样有兴趣将数据出售给其他威胁行为者以及受害者。

![](../Images/5ed4db8b8990bb7ee9c8a1e4ccb82ce1.png)

RansomHouse在Lapsus的elegram发布的消息 (Cyberint)

因此，虽然“勒索之家”的起源目前尚不清楚，但该组织并不是作为一个完全独立的实体出现的，而是来自其他威胁组织。

Cyberint声称，他们广泛检查了勒索之家核心成员与Telegram上其他威胁行为者的通信，并报告称看到了专业行为。

他们在自己的博客和各种Telegram频道上说话都很礼貌，不会卷入无关的讨论。此外，他们声称非常自由和支持自由。他们不想把商业和政治混在一起，并宣布他们永远不会与激进的黑客活动分子或间谍组织合作，”Cyberint的报告解释道。

这使得Cyberint的分析师认为，“勒索之家”项目是由心怀不满的红队测试人员发起的，他们受够了低赏金和糟糕的网络安全规划。

网络安全公司Emsisoft的威胁分析师布雷特·卡洛(Brett Callow)对Bleeping Computer表示:

据推测，“勒索之家”平台被“俱乐部成员”使用，他们使用自己的工具进行攻击，据他们说，这些工具包括“白兔”等勒索软件。然而，我怀疑他们的说法是不真实的，实施袭击的人也是“赎金之家”的幕后主使。

至于攻击的来源，一名给媒体打电话宣传攻击的“赎金之家”代表说的英语听起来像东欧口音。

然而，其他网络罪犯表示担心，新的数据敲诈项目是可疑的，不值得信任。

![](../Images/0cc71fc830a8b5dc4de11ec38aed3fac.png)

用户在黑客论坛上讨论新的泄露门户(KELA)

**加密的因素**

Cyberint声称，RansomHouse只窃取数据，处理与其他骗子的谈判或销售。此外，新的行动表示，他们不使用勒索软件进行加密，所以勒索仅仅是基于泄露被盗文件的威胁。

这就解释了为什么该组织之前声称它是包括白兔在内的各种勒索软件团伙的平台，这些团伙实际上从事加密工作。

但奇怪的是，“加密”一词出现在“勒索之家”Onion网站上，表示受害组织的数据已被加密，所以这部分是有争议的。

![](../Images/d5430a07cb7b2ea3fe79448ec762edee.png)

目前，这一新的操作规模较小，只有四名受害者，BleepingComputer仍在核实过程中。

“勒索之家”是否会在短时间内成为大规模的危险还值得怀疑，但任何勒索门户网站的推出都应该引起所有网络和安全管理员的关注。

CyberInt总结称，最近几个月，尤其是在俄罗斯-乌克兰冲突开始之后，他们看到新的威胁组织以不同的议程涌入人们的生活，因为Twitter和Telegram继续给威胁行为者发声并充当他们的喉舌。

RansomHouse是这个现实中出现的另一个新生物。一群才华横溢的红蓝队队员，有两张面孔——支持自由、自由主义和反激进主义，以及一个恐吓组织并迫使他们付出或羞辱的团体的面孔。

他们的使命感与许多披着羊皮的狼的崛起相一致，威胁行为者希望在试图让受害者处于不利地位时获得社会的认可。

最后，RansomHouse正在尽最大努力发展并成为网络犯罪行业的主导者，但目前，他们仍处于早期阶段。然而，与最近出现的具有“更高目标”的其他团体不同，例如BlueHornet，显然，个人利益是他们的主要动机。
