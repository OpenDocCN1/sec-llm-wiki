# 多事之秋！风暴旋涡中的Twitter遭遇史上最长最严重的服务中断

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyMzAwMDEyNg==&mid=2247528967&idx=3&sn=6df1f1280d081c136a956d09a0ce2eba&chksm=c1e9fe56f69e7740e42d360a1ae1503758c3e8d9eea0e2d4edeb60a2b9902d76e362a8180598&scene=126&sessionid=1681370130#rd](http://mp.weixin.qq.com/s?__biz=MzkyMzAwMDEyNg==&mid=2247528967&idx=3&sn=6df1f1280d081c136a956d09a0ce2eba&chksm=c1e9fe56f69e7740e42d360a1ae1503758c3e8d9eea0e2d4edeb60a2b9902d76e362a8180598&scene=126&sessionid=1681370130#rd)

综合互联网消息，全球数以千计的Twitter用户报告在桌面和移动设备上连接到该平台时遇到问题。CNN援引Down Detector的监测数据称，Twitter在当地时间7月14日早上遭遇了一次重大中断，数以万计的用户在使用该社交媒体网站时报告了问题。追踪互联网中断的Down Detector数据显示，服务中断的报告似乎在美国东部时间上午 8:00 左右开始激增。到上午9:00，许多用户似乎已恢复服务。本次中断是Twitter多年来最长、最严重的一次事故。虽然Twitter API状态页面当地时间7月14日没有显示任何问题，但在过去 30分钟内，近 55,000名用户报告说该服务无法正常工作。![](../Images/cd627ff3cd25e6fd7094bbf08ab81bb2.png)Twitter用户的问题报告。  
![](../Images/f30e10f5d399610d6a9f393178cf6aea.png)在Bleepingcomputer最早发布消息时，Twitter应用程序的浏览器版本显示典型的“出了点问题，但不要担心——这不是你的错”错误。![](../Images/787753ebed40fbbd7556eb04d23c835c.png)在移动设备上，该服务显示消息“糟糕，出了点问题。但别担心——这不是你的错，”但没有提供更多细节。![](../Images/15d15ad8d5c2d2dcc3c0088df325861c.png)目前，具体中断背后的问题仍不清楚，但它阻止了用户检索或发布推文，以及重新登录其帐户的问题。Twitter公司在当地时间14日上午9点10分发推文说，“你们中的一些人在访问 Twitter时遇到了问题，我们正在努力让它恢复并为每个人运行，感谢您坚持使用我们。”据该公司称，该问题是由Twitter内部系统的问题引起的。“我们回来了！” 该公司在美国东部时间下午12点37 分在推文中写道。“Twitter应该按预期启动并运行——抱歉打扰了。”中断发生在该公司令人担忧的时期。上周五（7月8日），埃隆·马斯克 (Elon Musk ) 终止了他以440亿美元收购Twitter的交易，此前数周对交易能否完成表示怀疑。周二（7月12日），推特的法律团队对马斯克提起诉讼，迫使他推进这笔交易。目前，Twitter的 API状态页面显示所有系统都在运行。但是，尝试重新加载页面所需的时间比正常情况要长得多。![](../Images/1260554b724befab367f709523d89724.png)美国东部标准时间 7 月 14 日 09:09\]：Twitter 的 API 状态页面已更新，通知正在调查“可能的中断”。![](../Images/80f40a436f47613410e574b7f94148a8.png) \[美国东部时间 7 月 14 日，12:41\]：Twitter几分钟前确认“我们的内部系统存在一些问题”，这影响了全球用户。问题已修复，服务现在应该可以正常运行了。![](../Images/edbe41bec4c89ae3976f852f9df3c433.png)当前的 Twitter API 状态尚未添加有关中断的新详细信息。截止北京时间7月15日06:00H，该页面仍然显示调查中。![](../Images/d5c39385b50aa43f990619f2fb56420c.png)本次Twitter中断，是该社交媒体平台多年来最长的中断之一，社交网络在近一个小时内对全球用户在网络和移动设备上完全不可用。与最近的其他重大中断不同，问题仅限于Twitter本身，并且似乎没有任何主要的互联网基础设施层受到影响。去年，“内容分发网络”的一次故障快速导致包括《卫报》在内的大部分互联网瘫痪了近一个小时。参考资源：1.https://www.bleepingcomputer.com/news/technology/twitter-outage-shows-something-went-wrong-error-message/2.https://www.theguardian.com/technology/2022/jul/14/twitter-experiences-longest-global-outage-in-years3.https://edition.cnn.com/2022/07/14/tech/twitter-outage/index.html4.https://downdetector.co.uk/status/twitter/
