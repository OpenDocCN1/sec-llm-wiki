# 工信部召开智能网联汽车推进组会议 强调推动产业发展取得新成效

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MDU0NTQ4Mw==&mid=2247489419&idx=1&sn=14761081974e86f23b0ae1fdab28c8e7&chksm=cf72cc2ff8054539fc0731d984a7cbc6d56e076e15bceaf8fd512c6ac724143d78093f5a2cc8&scene=126&sessionid=1681575199#rd](http://mp.weixin.qq.com/s?__biz=Mzg4MDU0NTQ4Mw==&mid=2247489419&idx=1&sn=14761081974e86f23b0ae1fdab28c8e7&chksm=cf72cc2ff8054539fc0731d984a7cbc6d56e076e15bceaf8fd512c6ac724143d78093f5a2cc8&scene=126&sessionid=1681575199#rd)

![](../Images/29282131479ad884d83198f5d726ec3f.png)

  

2022年1月13日，工信部组织召开智能网联汽车推进组（ICV-2035）工作会议。会议指出，2022年，智能网联汽车推进组（ICV-2035）将把握产业发展的新形势，聚焦重点突出问题，加强技术研发，统筹协调技术创新和产业化推进相关工作，推动智能网联汽车产业发展取得新成效。

  

![](../Images/af6016f50800df9ffc85fca95f97c584.png)

  

中金公司指出，智能化和网联化双轮驱动，汽车产业迎来重大机遇。当前全球新一轮科技产业变革正在蓬勃发展。作为科技创新的重要载体，智能网联汽车正推动着汽车产业形态、交通出行模式、能源消费结构和社会运行方式的深刻变化。**车联网和单车智能作为并行的两条技术路线将随着智能网联汽车的布局节奏加速深度耦合，通过协同感知、决策、控制实现完全自动驾驶，从而为全球汽车产业带来新的发展机遇**。

  

招商证券指出，激光雷达是自动驾驶感知环节重要的硬件配置，随着其成本的下探以及自动驾驶软件的发展，激光雷达装配率有望在2022-2025年之间出现明显提速拐点，打开千亿市场规模。激光雷达领域技术壁垒较高，对研发以及生产工艺都有较高要求，行业未来可能呈现寡头垄断格局。

  

![](../Images/2a077e8a0ef20b0ce232507303fe2db1.png)

  

平安证券指出，随着整车EE架构走向集中，智能车软件价值占比将逐步增加，**智能驾驶逐步向高级别进阶、智能座舱应用空间广阔**。未来汽车供应链增量机会多在高精传感器、主控芯片、域控制器、软件、舒适个性化配置等关键赛道。智能车供应链扩容，科技巨头深度介入，未来几年智能车新的产业链分工合作关系将逐步成型，看好处于关键赛道，且拥有关键壁垒的配件企业。**软件定义汽车加速，汽车算力趋于集中化、算力需求提升，域控制器、智能车操作系统等软硬件服务需求将快速增长**。
