# 第四届“强网”拟态防御国际精英挑战赛亮点连连看（一）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MDU0NTQ4Mw==&mid=2247486323&idx=1&sn=bbef1d9ae2481084426e3c9f19bf16b7&chksm=cf72d0d7f80559c1f47c6948d71c2cda42ee396a8f982c7c913e049802108775040a781d5ab1&scene=126&sessionid=1681575223#rd](http://mp.weixin.qq.com/s?__biz=Mzg4MDU0NTQ4Mw==&mid=2247486323&idx=1&sn=bbef1d9ae2481084426e3c9f19bf16b7&chksm=cf72d0d7f80559c1f47c6948d71c2cda42ee396a8f982c7c913e049802108775040a781d5ab1&scene=126&sessionid=1681575223#rd)

由中国工程院、江苏省人民政府、国家互联网信息办公室网络安全协调局作为指导单位，江苏省互联网信息办公室、南京市人民政府作为主办单位，紫金山实验室、中国网络空间内生安全技术与产业联盟等单位共同承办的第四届“强网”拟态防御国际精英挑战赛即将于11月9日线上开赛，为更好的提升关键信息基础设施的防护意识，本次大赛首次设置了对比测试的比赛环节！

  

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_2123932256187531267](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_2123932256187531267)

2021年8月17日，国务院公布了第745号国务院令，发布了《关键信息基础设施安全保护条例》，要求2021年9月1日起实施。《关键信息基础设施安全保护条例》要求，保护工作部门应当定期组织开展本行业、本领域关键信息基础设施网络安全检查检测，指导监督运营者及时整改安全隐患、完善安全措施。

  

为此，本届大赛针对网络路由、接入交换、Web服务、域名服务、文件存储及云应用等典型设备场景，设置了多款不同厂家的**拟态防御设备靶标和非拟态防御设备靶标。**然后鼓励参赛战队展开“寻宝”和“赛马”等对比挑战！

  

所谓**“寻宝”**，就是要求各参赛战队充分利用相关领域知识积累和多种扫描探测与攻击手段，在多款身份隐匿的靶标设备中，分析、推理、识别和标定出拟态构造的网络靶标设备。这就犹如经典的挖地雷游戏，挖对了奖励积分和红旗，挖错了则地雷爆炸罚分。

  

所谓**“赛马”**，则是鼓励各参赛战队，针对同样的应用场景，分别对非拟态防御靶标和拟态防御靶标开展漏洞挖掘、漏洞利用和逃逸攻击等操作，各个靶标都是商售的设备，既考验各战队的攻击能力，也检验各个商用设备的安全防御能力。

  

常言道，别人家的故事，实际上就是自己家的事故。通过本次比赛新增的对比测试，就是想利用紫金山实验室网络空间内生安全试验场和国际精英挑战赛的机会，“是骡子是马拉出来溜溜”，为关键信息基础设施设备的安全检测提供一个第三方平台，也为更好的落实《关键信息基础设施安全保护条例》提供技术支撑！
