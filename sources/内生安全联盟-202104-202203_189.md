# 联盟秘书处与中国人民财产保险公司就成立联盟保险专委会事宜召开首次视频会议

![](../Images/caec740b81b9a70d6e8e8c61c9adc0c1.png)**一、视频会议召开**![](../Images/61ad29d217c015867c51612de60d43b1.png)

2021年8月31日，中国网络空间内生安全技术与产业联盟秘书处与中国人民财产保险股份有限公司就成立联盟保险专委会事宜举行首次视频会议。

![](../Images/9f15ebdb928261c39c4d4bbc2671cf35.png)

  

![](../Images/caec740b81b9a70d6e8e8c61c9adc0c1.png)**二、参会人员介绍**![](../Images/61ad29d217c015867c51612de60d43b1.png)

联盟秘书处张芳秘书长、邢雁宁副秘书长、唐悦航专员参加了视频会议；中国人民财产保险公司天津分公司李军楠副总经理、中国人保财险总公司本部特殊风险保险部赵帅高级主管、中国人保财险天津分公司经济技术开发区支公司陈婷玉总经理、中国人保财险天津分公司特殊风险保险部秦佳玥高级主管、中国人保财险天津分公司经济技术开发区支公司李静经理代表中国人民财产保险公司参加了视频会议。

![](../Images/caec740b81b9a70d6e8e8c61c9adc0c1.png)**三、会议内容纪要**![](../Images/61ad29d217c015867c51612de60d43b1.png)

联盟秘书长张芳首先介绍了联盟成立背景、发展历程及联盟秘书处的主要工作；邢雁宁副秘书长介绍了对科技保险工作的思考；随后赵帅高级主管分享了中国人保财险公司的发展历程及人保财险网络安全保险业务开展情况；最后天津分公司李军楠副总经理进行了总结发言。

![](../Images/caec740b81b9a70d6e8e8c61c9adc0c1.png)**四、会议总结**![](../Images/61ad29d217c015867c51612de60d43b1.png)

双方就目前国内网络安全的环境背景、技术开发、产品应用、网络安全保险现状等方面充分交换了意见，大家一致认为网络安全保险在中国有广泛的市场前景，有助于推动以拟态防御为代表的内生安全技术和产业的发展，中国人保财险公司应担负起推动网络安全保险发展的时代使命，积极推动联盟保险专业委员会成立，建立起与紫金山实验室以及内生安全联盟的高层交流及互访机制，在适当的时机签署战略合作框架协议，共同开发网络安全保险市场。
