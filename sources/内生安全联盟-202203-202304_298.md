# 白宫网络总监：网络的“防御是新的进攻”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MDU0NTQ4Mw==&mid=2247496564&idx=1&sn=3046983c42b5b03f90f9e5e7d3ea1fe2&chksm=cf7128d0f806a1c6fd057ef9235a6d45088c7d499f9ba2b04265e8cce1fb106d2e0c8d61e57d&scene=126&sessionid=1681575119#rd](http://mp.weixin.qq.com/s?__biz=Mzg4MDU0NTQ4Mw==&mid=2247496564&idx=1&sn=3046983c42b5b03f90f9e5e7d3ea1fe2&chksm=cf7128d0f806a1c6fd057ef9235a6d45088c7d499f9ba2b04265e8cce1fb106d2e0c8d61e57d&scene=126&sessionid=1681575119#rd)

当地时间8月11日，在黑客大会 DEF CON 上与记者 Kim Zetter 的对话中，白宫国家网络主管 Chris Inglis 表示：网络安全的前进方向是**防御、明确的角色和责任以及对弹性和鲁棒性的投资**。  
Chris Inglis:  
近年来主要出现了“三波攻击”：  
第一波“将数据和系统置于风险之中”；第二波，攻击者依旧将数据和系统作为目标，但随后便将其升级为关键系统/功能危机；第三是对网络安全防御信心的打击，例如去年5月美国燃油管道遭受攻击的事件。  
“从中得到的最重要的教训是，**攻击者会让数百万人处于危险之中**，”Inglis说。解决方案是专注于防御，特别是集体防御。  
“唯一合理的解决办法是认真对待防御；让**防御成为新的进攻**，作为网络领域的攻击者，击溃全部系统及人员之后才能够击溃某一个人，”他说，并认为**需要重点关注“弹性”和“鲁棒性”，在这些方面加大前期投资。**不仅在数据和系统方面，更要责任到人，使每个人都能参与到自己的防御项目中。  
Inglis 指出，乌克兰的网络集体防御是他们的准备协作的一个很好的例子，原因在于这种集体防御可以提供给他们弹性和鲁棒性。  
正如 Zetter 所说，我们对未来攻击的样子“缺乏预期或想象力”。谈到主动预防或缓解诸如 Colonial Pipeline、SolarWinds 和 Operation Aurora 之类的攻击时，Inglis表示个人和组织需要明确了解他们自己的角色和职责。  
除了专注于防御之外，Inglis还强调了对问题进行纵向和横向协调的必要性以及关注资本支出的必要性，补充解释责任在整个供应链中的重要性。  
“供应链中的参与者，如果没有建设系统自身的弹性和鲁棒性，我们就应当拒绝它进入我们的系统，”Inglis说。“我们需要将责任和义务分配给供应商、供应商、集成商，以便他们真正投入所需的资金，使这些系统具有内在的弹性和鲁棒性。”  
Inglis补充说，这项措施很重要，“这样在网络链末端运行的人就不会被一个无法防御的系统困住，并且必须完全保护自己免受他们实际上无法击败的人的攻击。”  
Inglis还讨论了使用用于各种关键基础设施的外国制成品，例如半导体，他敦促需要“对依赖外国生产的关键基础设施的真正成本有一个真实的认识。”然而，他表示，这些项目不能拆除和更换，因为美国需要有能力将这些项目上岸或重新上岸。这种努力的一个很好的例子是新颁布的芯片和科学法案，该法案旨在将半导体生产带回美国，这样美国就不会完全依赖外国制造的芯片。  
Inglis指出，联邦政府不能只看一两个部门，在解决这个问题时，必须尝试解决整个问题，而不仅仅是部分问题。
