# 第五届数字中国建设成果展览会最佳成果出炉，拟态防御技术入选十大硬核科技

7月24日下午

**第五届数字中国建设成果展览会**

**最佳成果颁奖仪式**

在福州海峡国际会展中心举办

  //  

此次最佳成果遴选活动为组委会首次组织，旨在挖掘成果展“宝藏单品”，活动前期向本届参展单位进行了广泛征集，共**111**家单位选送**489**项成果参选，由中国科学院梅宏院士等20余位专家经三轮遴选，最终产生**“十大硬核科技”“十佳解决方案”“十佳首展成果”**三大类奖项共**30**项优秀成果，获奖成果在展览现场均进行了统一标识。

  

![](../Images/9b73ee42b3c66ab7fd676ff8dabe5257.png)![](../Images/30b35c533a77942bbb56f46b01397395.png)  

  

**“十大硬核科技”**聚焦高端芯片、操作系统、人工智能关键算法、传感器等技术领域，推动关键基础技术的创新应用。

  

  

![](../Images/6d7fa4f106a22025dfae65fb295bdf18.png)  
![](../Images/2eadf66e0da3e51acc20ecb0cf1db5e4.png)  

  

**“十佳解决方案”**，专注以数字化方案驱动生产方式、生活方式和治理方式变革，推进新基建、市政公用设施、工业园区设施等物联网应用和智能化改造，加快数字社会建设步伐。

  

  

![](../Images/fc11dc371107a41f911f6669a356a80d.png)

  

![](../Images/50c82b6f480cbb9d05c78fc6d0249a4a.png)

  

  

**“十佳首展成果”奖项**，聚焦数字化转型标杆的创新技术，体现数字化浪潮的最新趋势与发展方向，重点展现最新数字产品与数字技术的首次风采。
