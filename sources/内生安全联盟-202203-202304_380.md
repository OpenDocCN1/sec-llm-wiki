# 俄乌冲突100天：网络空间战场

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MDU0NTQ4Mw==&mid=2247494523&idx=1&sn=8119ff9cbb889c2e0faee2e6e6ed46c2&chksm=cf7130dff806b9c9198f292f37aadec7bba6b7f3543844544dbd000aee4ea24b6c6bc42014e3&scene=126&sessionid=1681575147#rd](http://mp.weixin.qq.com/s?__biz=Mzg4MDU0NTQ4Mw==&mid=2247494523&idx=1&sn=8119ff9cbb889c2e0faee2e6e6ed46c2&chksm=cf7130dff806b9c9198f292f37aadec7bba6b7f3543844544dbd000aee4ea24b6c6bc42014e3&scene=126&sessionid=1681575147#rd)

![](../Images/29282131479ad884d83198f5d726ec3f.png)

  
今年1月14日，俄罗斯执法部门的一次突袭成为全世界的头条新闻。此次突袭行动捕获了 Sodinokibi/REvil 勒索软件团伙的14名成员。  
突袭行动是在美国和俄罗斯官员进行了一系列会谈之后开始的，其中包括2021年6月份拜登总统和普京总统在日内瓦举行的会谈。俄罗斯联邦安全局（FSB）证实，作为突袭行动的一部分，**“去年春天对殖民地管道发动袭击的责任人”**已被逮捕。（2021年5月讯，美国最大的燃料管道殖民地管道因勒索软件攻击而被关闭）  
当时，俄乌冲突还没有开始。一些人称之为“俄罗斯勒索软件外交”，认为这是在向美国表明，俄罗斯希望在未来乌克兰问题上获得更轻的制裁措施。  
前一天晚上(1月13日，东正教新年前夜) ，许多乌克兰政府机构、非政府组织和 IT 组织成为 WhisperGate 攻击的目标。WhisperGate 是一种破坏性的恶意软件，根据微软的说法，它“看起来像是勒索软件，但缺乏赎金追回机制”。如ESET研究人员所归类的一致，这种人造勒索软件最终目标是使目标设备无法操作，表明攻击可能并非传统网络犯罪者所为，而是与国家相关。  
1月14日，乌克兰多个部委和政府机构的网站遭到破坏，网站上出现了反乌克兰的图片和一条信息，上面写着“做最坏的打算”。在冲突开始的前几天，政府和私人实体一直是网络攻击的目标，包括一系列分布式拒绝服务攻击（DDoS） ，这些攻击摧毁了乌克兰的几个重要网站。与此同时，乌克兰一家大银行的客户收到了银行ATM机无法使用的虚假短信消息。  
在冲突前不到一个小时，Viasat 的 KA-SAT 卫星遭受了一次重大网络攻击，导致数千名乌克兰人以及其他欧洲客户的宽带互联网服务中断，留下了数千台砖砌的调制解调器。美国和欧盟都谴责了这次袭击，并将其归咎于俄罗斯。美国和欧盟认为，俄罗斯企图在头几个小时直接破坏乌克兰司令部的通信能力。  
  
***01*****头几个小时**  
袭击并没有就此停止。相反，1月和2月初的网络攻击只是即将发生的事情的前奏。2月23日晚，在 DDoS 攻击导致乌克兰几个重要网站关闭之后，ESET 在乌克兰几个组织的数百台机器上检测到了新的数据清除恶意软件 HermeticWiper。有证据证明，恶意软件是在2021年12月28日编译的，这表明攻击可能已经进行了一段时间。  
第二天，当军事冲突展开时，ESET 的研究人员在乌克兰的系统中发现了更多的数据清除恶意软件。IssacWiper 远不如 HermeticWiper 复杂，也没有与 HermeticWiper 相似的代码，最终在清除目标机器上的数据方面也没有那么成功。  
在一个小得多的部署中，ESET 的研究人员还观察到 HermeticRansom 与 HermeticWiper 同时使用。HermeticRansom 在2月24日凌晨首次被报道，是一个人造勒索软件。换句话说，它没有任何经济动机，而是作为一个诱饵，在数据擦除软件造成损害的时候部署。  
![](../Images/210be819bfc9c430bda3b01e166f1991.png)图1：HermeticWiper 中的勒索信，提到美国大选  
  
***02*****接下来的99天**

  

ESET 的研究人员认为，各种数据擦除攻击，包括3月14日发现的涉及 CaddyWiper 的攻击，目的是削弱特定组织充分反应的能力。ESET 确认了金融、媒体和政府部门的受害者，并将 HermeticWiper 和 CaddyWiper 归咎于沙虫组织。美国确认该组织是俄罗斯 GRU 军事情报机构的一部分。  
同时，ESET 和 CERT-ua 在合作中发现，该组织还试图在乌克兰的一个高压变电所上部署“工业王2号”。这个恶意软件是 Industroyer（一个针对电网的恶意软件）的新版本，曾在2016年攻击乌克兰电网，导致数千人断电。  
其他几种攻击继续进行，包括 DDoS 攻击，恶意软件攻击媒体网络、非政府组织和电信供应商以及政府实体。冲突在勒索软件领域也造成了相当大的影响。  
![](../Images/dbd9b4d3f9d75ff63c1ae9dbe316fbff.png)图2：ESET 研究人员在俄罗斯入侵乌克兰之前和之后发现的攻击  
  
***03*****“往来无白丁”**

  

根据 ESET 遥测数据，在2022年的头几个月，俄罗斯是遭受勒索软件攻击的首要目标国家，占总检测量的12% 。这与冲突前的情况形成了鲜明的对比。当时俄罗斯和一些独立国家联合体（独联体）成员国避免了许多勒索软件攻击，可能是由于居住在这些国家的黑客组织害怕俄罗斯的报复。  
其中一些攻击直接针对俄罗斯实体，包括俄罗斯宇航局和国有电视和广播网络 VGTRK。针对 Roscosmos 和 VGTRK 的攻击是由 nb65 黑客组织实施的，此前该组织成员在承诺支持俄罗斯的问题上存在分歧。  
俄罗斯也是 40% 的锁屏勒索软件事件的目标（乌克兰为11%）。就像我们看到 HermeticRansom 展示政治信息一样，在俄罗斯发生的一些攻击旨在向乌克兰致意，如“斯拉瓦 · 乌克兰”(“荣耀归于乌克兰”)。  

  

***04*****全球动荡**

  

不仅仅是卷入这场冲突的国家，全球垃圾邮件数量也出现激增，主要发生在2月24日。截止到4月份，垃圾邮件的检测总量增长了5.8% 。冲突刚刚开始，ESET 就警告说，骗子可能会无耻地利用全世界支持乌克兰的运动，虚构慈善机构和虚假的捐款呼吁。  
随着战争让乌克兰人担心自己的钱被盗，或者海外的俄罗斯人无法使用他们的银行卡，ESET 发现针对加密货币平台的攻击也有所增加。加密恶意软件也在蔓延。  

  

***05*****结语**

  

2022年5月26日 ESET 发布的网络威胁报告，揭示了今年前四个月的威胁状况。报告所描述的攻击显示了网络战与常规战并行的破坏性潜力。与此同时，乌克兰自今年1月以来面临的网络威胁不断增加，也是未来冲突升级的一个警告信号。  
  
正如 ESET 高级探测工程师 Igor Kabina 所观察到的：“我们预测，支持某一特定方的网络攻击行为将在未来几个月内继续，甚至恶化升级。意识形态和战争宣传正成为其传播的主要驱动力。”
