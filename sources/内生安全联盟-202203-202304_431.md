# 首届网络空间内生安全发展大会 | 能源内生安全分论坛回顾

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MDU0NTQ4Mw==&mid=2247493360&idx=1&sn=7e4bb2978505f6e66609b0fa3660fbfb&chksm=cf713d54f806b4426abe106442bedede9b0ecbce45102ecf338fe83301e5824bf06ca63e1b89&scene=126&sessionid=1681575163#rd](http://mp.weixin.qq.com/s?__biz=Mzg4MDU0NTQ4Mw==&mid=2247493360&idx=1&sn=7e4bb2978505f6e66609b0fa3660fbfb&chksm=cf713d54f806b4426abe106442bedede9b0ecbce45102ecf338fe83301e5824bf06ca63e1b89&scene=126&sessionid=1681575163#rd)

![](../Images/29282131479ad884d83198f5d726ec3f.png)

  

2022年4月21日至22日，由紫金山实验室、中国网络空间内生安全技术与产业联盟共同主办的首届“网络空间内生安全发展大会”以线上+线下、多地远程互动的方式成功举办。4月22日，能源领域内生安全分论坛顺利召开。此次论坛采用线上研讨的方式进行，共有8名特邀嘉宾进行专题报告，共计3400人在线参与研讨。  
![](../Images/5a08edfc01c0103146a4bd5e612bcb3f.png)  
此次论坛采用线上研讨的方式进行，以“网络安全技术能源领域发展新生态”为主题，围绕能源行业领域网络安全发展新痛点，共同探索依托网络空间内生安全原创性理论的新技术体系、新产品生态以及新战略伙伴，携手共建内生安全技术与产业发展新范式新生态！  
当下能源行业正面临着供应链安全的巨大压力，能源企业作为保障能源供应和能源行业数字化转型的首要出发点，新一代信息技术将与其生产经营和发展深度融合，网络安全的重要性不言而喻。  
本次论坛特邀能源电力行业各界翘楚，针对电力系统网络、系统本体、系统业务、基础安全设施以及监控系统等多个方面对能源电力领域的安全防御措施和技术做出讨论，抛出能源领域新型防护的多方面思考。  
国网智能电网研究院、国网江苏省电力有限公司、浙江大学、南京南瑞信息通信科技有限公司、南京南瑞继保电气有限公司、郑州昂视信息科技有限公司等多家相关研究单位、企业以及高校参与讨论，着力于能源行业数字化转型及安全变革。  
论坛由国网智能电网研究院电网数字化研究所张涛副所长主持，国网智能电网研究院高昆仑副院长作欢迎致辞。高昆仑副院长表示，我国能源行业正处于数字化转型与低碳转型的叠加期，数字化深入带来了更大的网络安全挑战。以可信计算、拟态防御等为代表的一些内生安全技术日趋成熟，在新型电力系统中将大有作为。希望通过本次分论坛的举办为内生安全技术发展与能源领域数字化安全转型提供交流平台，进一步推进在能源电力领域中的各级应用，促进能源电力网络安全防护体系升级完善。  
![](../Images/32f886108f3fa061ac8699edbc3d2c5c.png) 国家电力调度控制中心原副主任辛耀中主任作《重要工业控制系统网络安全防护体系》报告，解读2022年3月发布的国家标准GB/Z 41288-2022《信息安全技术 重要工业控制系统网络安全防护导则》，表示当前发展背景下，工业控制系统功能安全和网络安全必须合二为一，能源行业网络安全长远发展，需要在体系、规划中践行。 ![](../Images/2498c59071c52449421b11ce74b620b8.png)  
国网江苏省电力有限公司互联网部徐春雷副主任作《新形势下电力网络安全架构防护思考》报告，介绍江苏电力在网络及安全架构发展中的一些工作，分析网络安全形势，并对新型网络安全防护提出思考，构建“保核心、防外围、强互通”为总体原则的安全缓冲区，从“优架构、强技防、育生态”三个方面提升整体防控能力。 ![](../Images/55c48cdb3f756bdb240d1b521ec13a8b.png)  
浙江大学徐文渊教授作《电力终端跨域安全》报告，介绍跨域安全背景、定义、脆弱性检测和脆弱性利用。跨域交互安全往往由带外脆弱性引起，其脆弱性可以被利用，随着电力终端跨域性增强，需要同时考虑带内带外脆弱性，为终端安全提供新的防线。 ![](../Images/3eaf89ba244489795d31ade7dfba5f00.png)  
国网智能电网研究院电网数字化研究所张涛副所长作《新型电力系统网络安全挑战与内生安全防护思考》报告，表示新型电力系统和电网数字化技术紧密关联，网络安全同样面临新问题、新挑战，并在终端安全优化、数据安全防护、本体内生安全方面提出了想法与建议，最后介绍在内生安全方面的一些实践。 ![](../Images/fd03b5f02e19959962ed2a516c25566d.png)  
南京南瑞集团信息通信科技有限公司信息安全研究中心刘苇副主任作《电力工控系统本体安全防护技术研究与工作实践》报告，介绍硬件可信、系统免疫、业务可控、监测响应的本体研究思路及实践，提出三点展望：健全新型电力系统安全体系、完善态势感知体系、构建安全缓冲区。 ![](../Images/606980c2b51cc9456c496d6f5e2ccb02.png)  
南京南瑞继保电气有限公司汤震宇经理作《电力监控系统内生安全实践探索》报告，分别介绍对内生安全的理解、保护监控安全防护的现状和需求、对设备内生安全的实践探索、安全防护方面的相关思考，表示建立设备主动性的内生安全免疫能力，是构建整体网络安全方案的重要分支。 ![](../Images/10cbcc3eb9f6bd627f1b5ed0accecf3b.png)  
郑州昂视信息科技有限公司李昂总经理作《电力关键信息基础设施内生安全防御研究与实践探索》报告，分析电网内生安全需求背景，解读新型电力系统内生安全原理及方案，并介绍正在进行的示范合作工作。 ![](../Images/2916f8e6b4dcf449ae5cb48b534101f5.png)  
论坛特别开设圆桌研讨环节，各位专家学者围绕能源领域内生安全发展现状与需求展开讨论，提出精彩看法与见解，论坛气氛活跃。  
![](../Images/f52e1bdb778f87efa54fbad50bf5766b.png)  
最后，论坛呼吁共建电力行业领域内生安全生态，共商新型能源安全的创新与发展之路。
