需要批量刷注入，需要三个步骤：

**1 通过百度采集URL**

**2 进行去重处理**

**3 使用sqlmap -m**

**步骤1：使用小叶的工具**

git clone https://github.com/xiaoyecent/baidu\_url\_collect.git

用法：

![](../Images/83783bfe1a987eb51cd91fc36693332e.png)

![](../Images/3603f6179d1228911dd5afd7d132d84e.png)

**步骤2：对域名去重，避免无效的测试，使用18的脚本**

需要将采集到的URL放于/root目录下，并重命名为url.txt，脚本写的比较死

![](../Images/514754f74250293cf86ad4455c6bbd17.png)

**步骤3：使用sqlmap -m 挂机测试**

Sqlmap -m --batch

![](../Images/9b80dbf9b7ba0eb1b7c5babcbc01ccf2.png)

剩下的就交给运气了

步骤1和3，可以通过检索的语句缩小测试的范围，灵活应用即可。

如果采集的过多，可以通过Linux命令split进行切割处理，多开几个终端同时跑。
