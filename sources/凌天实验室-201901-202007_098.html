Offensive Security刚刚发布了Kali Linux 2019.1，这是2019年瑞士军刀用于网络安全专业人士的第一个版本。


最新版本的Kali Linux操作系统包括最高版本为4.19.13的内核以及针对众多错误的补丁，以及许多更新的软件，如Metasploit，Harvester，DBeaver等。


Kali Linux 2019.1附带最新版本的Metasploit（5.0版）渗透测试工具，该工具“包括数据库和自动化API，新的逃避功能以及整个可用性改进”，使其成为渗透测试人员的更高效平台。


Metasploit 5.0版是该软件自2011年发布的4.0版以来的首个主要版本。


谈到ARM映像，Kali Linux 2019.1现在再次添加了对内核版本4.19的Banana Pi和Banana Pro的支持。


“Veyron已被转移到4.19内核，Raspberry Pi图像已被简化，因此更容易找出使用哪一个，”Kali Linux项目维护人员在他们的官方发布公告中说。


“对于使用TFT LCD的用户，不再有单独的Raspberry Pi图像，因为我们现在在所有这些图像上都包含了re4son的kalipi-tft-config脚本，因此如果你想设置一块带有TFT的电路板，请运行'kalipi-tft-config '并按照提示进行操作。“


攻击性安全虚拟机和ARM映像也已更新到最新的2019.1版本。


您可以直接从官方网站或Torrent网络下载新的Kali Linux ISO，如果您已经在使用它，那么您只需运行以下命令即可将其升级到最新且最好的Kali版本：


apt update && apt -y full- upgrade
