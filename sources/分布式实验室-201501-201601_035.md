# @Container容器技术大会详细日程

@Container容器技术大会是由DockOne.io主办的顶级容器技术盛会，会议强调实践和交流，话题设置围绕容器、运维、云计算等技术领域，力求全方位、多角度为参会者解读容器技术。

**目前大会的报名人数已经突破750人，讲师全部确认，技术顾问确认16位。**大会将会从私有云、CI/CD、开发部署、社区等角度，以案例的方式来一一剖析别家的容器应用历程，这其中有大型互联网公司、有创业公司，还有传统企业。当然，和别的大会不同，我们希望能更多的讨论一些技术细节，而不只是架构层面的解读。

![](../Images/72866bbb2a1e26710141dcaf1916eda3.png)  

钟成，华为高级工程师。多年软件及互联网行业开发经验，zlog日志函数库作者，曾参与网易PaaS2.0系统的设计和开发，目前就职于华为杭州研究院PaaS开发部。致力于容器集群及云计算架构和产品方面的探索实践。

华为早在2009年进入云计算领域，并在存储、网络方面有深厚的技术积累。2015年7月发布公有云战略，12月推出基于Kubernetes和Docker技术打造的CCE容器云。**本次演讲将和大家聊一聊华为PaaS团队如何以用户为中心建设容器集群，探讨一些未来的技术热点，包括容器复杂网络支持、集群联邦、集群性能优化、图形可视化编排等，以及参与Kubernetes开源社区的全球协同工作模式。**

![](../Images/fa9671a52704a2c363a6c91b785e2e57.png)  

李响，CoreOS工程师，负责CoreOS分布式系统相关项目开发，对分布式一致协议、存储、调度等有很多研究。他是分布式一致性存储系统etcd的作者和开发者。他对容器生态系统也有较多的贡献，目前主要关注提升Kubeternetes的集群规模和调度系统。另外，他也是开源倡导者和go语言的推广者。

我们正处在一个云计算的革新中。像Kubernetes、Mesos、rkt、Docker等以容器为核心的技术不光改变了我们使用云计算的方法，并且带来了更多的机遇和挑战。在CoreOS构建大规模容器平台的过程中，我们不断迎接和解决这这些挑战。**在本次演讲中，我们会着重讨论从有效地对验证容器，安全地运行容器到大规模的管理容器中遇到的实际问题。**

![](../Images/95f76451794d599b11f3408121502f35.png)  

蔡书，红帽资深架构师，开源软件和解决方案的爱好者，技术上崇尚简单实用；追求稳定、简洁、高效的解决方案。14年企业服务经验，专注企业服务市场。

容器技术尤其是Docker的出现，大大的丰富了我们实现应用架构的灵活性。但是就像从来没有银弹一样，在复杂的企业IT环境里，我们仍然需要因地制宜、量体裁衣的搭配使用物理机、虚拟机、容器以及公有云私有云等多种技术满足各种使用需求…如何兼容旧的业务系统，如何处理对于环境有特定要求的应用，等等。**红帽软件提出了完整的解决思路和产品，本次演讲将谈谈红帽的构建之道。**

![](../Images/e25625cca3688ca7bc2978cb17f89c4b.png)  

尧飘海，网易蜂巢技术负责人，目前负责网易蜂巢容器云计算平台建设，致力于自动化平台的架构和实践。在互联网产品开发和规范化的系统建设有较多的经验，对分布式系统设计开发、性能调优，系统架构有一定的经验和理解,热爱开源和技术交流。

网易私有云的建设和发展经过多年的实践，经历了0到1再到万台的大规模发展。在解决了硬件交付的问题后，又面临软件交付的问题，即提升产品的开发效率，又能缩短产品的开发迭代周期，网易内部也开发相关的工具去实施，网易在14年初的时候就开始把Docker技术使用在内部的消息推送平台的线上实施，目前单系统集群规模到达千台，同时也碰到各种技术挑战。如何高效的利用Docker容器等技术来解决开发者的软件交付和运维成本，和开发者共同解决效率问题是网络蜂巢在实践之后的一些思考。本次大会，尧飘海将带来主题为《**网易蜂巢的Docker实践之路**》的演讲。

![](../Images/183ac672f13f0d79f5116a3ab0ec4e23.png)  

何小锋，京东商城高级架构师，拥有17年的研发经验，喜欢技术，追求卓越。2011年加入京东，担任了京东两届架构委员会常委。目前在京东云平台系统技术部，负责弹性计算和分布式消息平台建设。在京东期间支持过多次的618和双11大促，见证了京东的技术演进过程，在弹性 计算、中间 件、存储和大并发分布式系统等方面积累了丰富的实战经验。

京东在2015年启动了弹性云建设项目，以Docker为核心来构建弹性云，机器统一进行池化，按需进行服务容量伸缩。随着廊坊新数据中心在10月份建设完成并投入使用，所有在线应用在新机房都迁移到了Docker容器中，成功的支持了今年的双11大促。**我将给大家分享一下京东的Docker实践，介绍京东弹性计算的演讲历程、架构、调度算法和以数据为驱动进行精细化运营得经验。**

丛磊，新浪云计算总负责人，06年毕业后加入新浪，08年开始带领技术团队进行云计算领域研发，09年合作开发了国内第一个公有云计算平台Sina App Engine，之后经历了SAE所有版本的研发过程，历任技术经理、首席架构师、总监。目前负责云计算相关业务的产品、技术、运营、商务，是国内PaaS领域的先行者。

SAE于2015年11月推出了基于Kuberntetes/Docker的容器云，方便用户创建Node.js等服务，当然，SAE团队针对Kubernetes的一些不足之处也进行了大量的改进，包括网络隔离、自动扩展、build加速、共享存储等方面，同时在线上运维方面也积累了一些经验，本次演讲就针对这些话题展开讨论。

![](../Images/d722f284a83be2891595067c9f82c2eb.png)  

陈纯，腾讯数据平台部工程师， 参与Gaia资源调度平台的开发，目前负责Docker的研发工作。爱好鼓捣源代码，对Hive、Yarn、Docker等开源项目贡献过代码。

Gaia是腾讯数据平台部分布式数据仓库TDW的资源调度和管理平台，支撑公司6大BG的离线作业。从2014年9月开始，为了更好的服务在线类型作业，我们组开始研发Docker on Gaia项目。截至10月底，Gaia平台上已经开始支撑公司实时计算、游戏云、广点通等不同业务的Docker作业。本次大会，他将**分享题为《腾讯Gaia平台的Docker应用实践》的演讲，将主要介绍调度管理、资源隔离、网络模式、存储方面我们的实践经验。**

![](../Images/e42e7fe7e584e39b6f8f389d6297cd8a.png)  

杨成伟，资深工程师，开源软件用户、爱好者、开发者，目前在爱奇艺负责基于Mesos、Docker等技术的弹性计算平台；加入爱奇艺前，在英特尔开源技术中心参与MeeGo、Tizen的开发，并有幸成为DBus项目Upstream Commiter。

爱奇艺从2013年底开始调研Mesos，并于14年初首先将Mesos、Docker应用于公司核心转码业务。随着业务的稳定，我们逐渐将精力用于开发 iQIYI App Engine 上，力求为公司内部应用开发者提供简单易用、同时又不失灵活性的运行平台。本次分享将介绍爱奇艺在基于 Mesos、Docker 等技术构建私有 App Engine 中的实践经验。

![](../Images/367ac6a9c04da789fa35871f5405c5bd.png)  

郭嘉，蘑菇街平台技术部高级架构师，虚拟化组责任人。目前主要专注于蘑菇街的私有云建设、Docker、KVM、OpenStack、Kubernetes等领域。

蘑菇街基于Docker的私有云建设经过了一年多的实践，从无到有，经历了今年双11，双12的实际检验。Docker的稳定性和冗灾能力，是我们关注的重点和难点。我们对Docker的不足做了一系列的优化和加强，包括数据的冷备份，冷迁移，网络IO／磁盘IO的QoS和隔离，多机房的Docker镜像管理，容器粒度的资源load值统计，多维度的阈值监控。我们还自研了基于Docker的PaaS层编排调度，Jenkins持续集成组件，帮助业务方实现了“自动化运维”，“集群调度”和“基于Docker镜像的发布能力”。本次演讲就针对这些话题展开讨论。

![](../Images/9cb83806e150d9b424e89017ad71a148.png)

王鹏，光音网络资深研发经理，云平台负责人，专注于Docker的研究与推广。目前负责云平台的研发工作，积极打造基于Docker的资源自动调度、自动化构建和测试。

通过容器化的解决方案，使得产品能够快速扩容缩容。但在实际的生产环境中，有状态的数据又不可避免。如何利用容器的优势来解决分布式文件系统及Redis、MongoDB等数据库的问题呢？届时，王鹏将会带来题为《光音网络存储容器化方案探索》的精彩演讲，与大家分享一下光音网络在存储容器化方案上的经验与教训。

![](../Images/d86f19ab1c85451560757b1b645cb332.png)  

刘超，Linker Networks技术总监。10年云计算领域研发及架构经验，目前于Linker Networks领科云从事基于容器的移动领域混合云架构工作。长期专注于OpenStack、Hadoop、Docker、Spark、Mesos等开源软件的企业级应用及产品化。

领科云的业务方向为移动应用，包含嵌入式设备，移动流量应用程序，网关转发程序等多种场景，部署方式复杂多样，涉及到嵌入式，虚拟机，物理机，公有云等多种部署方式。本次主要分享领科云的企业级混合云解决方案，即如何基于Mesos管理多种部署方式情况下的Docker应用，以及的基于OVS的网络方案，基于Ceph的存储方案，基于OpenWrt的嵌入式方案，基于OpenStack、AliCloud的VM和Docker的混合方案。

![](../Images/fd5c168770ec2ae1d64123af4c4c7123.png)  

龚正，惠普公司高级顾问，为企业提供IT咨询服务，目前负责企业私有容器化云平台的建设，专注于Docker、Kubernetes、自动化运维等领域。

Kubernetes是谷歌内部使用的大规模集群管理系统Borg的开源版本，是一个完备的分布式容器集群管理平台。Kubernetes设计了强大的集群扩容、弹性缩放、资源限制、应用升级、容器性能监控等机制，使得系统运维难度和运维成本大幅降低。通过将传统应用程序打包成Docker容器，并使用Kubernetes来进行容器集群管理，**实现了一个高可用的容器云平台，为企业提供了一种快速服务扩容和升级的方案。本次大会，龚正将带来题为《中国惠普Kubernetes+Docker容器私有云平台实践》的分享。**

![](../Images/f4036bb0e268c5a2307d888ac4a73d12.png)  

丁彦，暴走漫画技术总监，数据挖掘部门负责人。他现在负责暴走漫画数据收集，分析平台的开发与构建，以及暴走漫画现有架构的Docker化。

在过去的一年，暴走漫画实现了服务器端的全面Docker化，同时实现了原有系统的一定的改造和重构，在自动化运维和弹性扩展上有了较大的提升。本次大会中，丁彦将会分享《**暴走漫画基于公有云的全面容器化架构实践**》，着重讨论中小创业公司如何利用公有云和Docker技术实现 “自动化运维” 与 “易于水平扩展的架构”的一些思考和心得。

![](../Images/4149df00ad7ceff3fe86dcab65c4f937.png)  

郑坤，美团云高级工程师，目前专注于云平台主机，以及基于Docker的镜像管理、调度、自动化部署和可伸缩服务的研发工作。曾就职于华为OS内核部门，负责OS多核可扩展性研发工作。

届时，他将带来**《美团云Docker实践》的精彩演讲，重点介绍美团云在Docker推广中的一些经验**。同时，他将会分享如何基于美团云现有架构和组件实现Docker image仓库；如何打造容器的分布式管理平台，为容器提供多种调度策略；如何与VM API和架构流程相兼容，实现VM和容器的统一管理；借鉴Google borg/Kubernetes等技术，增加对多容器捆绑（set）的支持，并且支持set内单个容器的启停和image替换，实现set灰度升级。

![](../Images/a0f80869466bff923ef0607b833deaaf.png)  

陈飞，微博研发中心技术经理及高级技术专家。2008年获得北京邮电大学获得硕士学位，毕业后就职于华为北研。目前在微博负责Feed用户关系和容器化相关工作，致力于Docker技术在生产环境中的规模化应用。

微博在2015年春晚通过Docker实现私有云平台弹性调度能力，随着公有云技术的成熟，我们发现原有私有云比较困难的问题在公有云上比较容易解决，例如突发峰值情况下弹性资源的成本，小业务快速试错等场景。在2016年，微博尝试利用Docker构建混合云架构，**本次演讲中，陈飞将介绍安全、网络、资源管理、调度管理、跨云服务发现等方面的一些实践经验。**

![](../Images/a3bff648702580d105d219d8128d4a27.png)  

徐磊，去哪儿网运维工程师，负责去哪儿网日志和计算平台的设计、开发和维护工作，对Docker和Mesos感兴趣。曾就职于红帽HSS部门，负责内部工具的开发。

去哪儿网在今年初开始尝试Mesos和Docker，并应用于线上的实时日志分析服务。同时，面向公司内的DEV和QA人员提供方便的环境部署功能，快速部署多模块，多版本的dev/beta环境。届时，徐磊将带来**《利用Mesos和Docker构建dev/beta环境》的精彩演讲，介绍去哪儿网在利用Mesos、Docker和Calico等开源方案构建的私有PaaS平台过程中的实践经验**。
