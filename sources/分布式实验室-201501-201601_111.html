牛津计划


牛津计划听起来有点高大上，到底是个什么东东? 提起火爆全球的How-old.net（测颜龄网站）和TwinsOrNot.net（我们有多像）网站， 您就会想起来了。 牛津计划不只人脸识别，整个计划一共包括四大类：


  1. 人脸识别(Face APIs)， 通过人脸检测和识别技术看见您的用户；

  2. 语音识别(Speech APIs)，通过Bing语音识别和合成技术与您的用户对话；

  3. 计算机视觉(Computer Vision APIs)，理解图像并智能产生缩略图；

  4. 语言理解智能服务(LUIS)， 为您的应用量身打造对自然语言命令的理解能力；

Docker


Docker是当下最火的容器技术，不仅是开源界的super star，更是软件生产力的革新，堪比运输行业的集装箱，『Build, Ship, and Run Anywhere』是他的终极目标。也就是说，未来你可以在任何平台运行你的应用，是不是很赞？


灵雀云就是以Docker容器为中心，全方位支持开发者在应用创建、编译、集成、部署、运行的每一个环节。如果将Docker比作『集装箱』，灵雀云就是运输这些『集装箱』的『远洋货轮』。灵雀云镜像市场通过高性能Docker Hub服务，实现私有、公有的『集装箱』存储；容器托管服务，从云端与Docker技术对接，带着您的『集装箱』畅游整个互联网。

根据主办方公布的开发需求以及免费提供给您的牛津计划APIs， 参赛者可基于网络，PC， 智能手机，可穿戴设备等终端，任意开发一个产品，网站，工具或解决方案，将其打包成Docker镜像，托管在灵雀云上。

谁可以参加？


无论你是程序员、设计师、产品经理，开源社区成员， 还是在校学生、创业者，只要你具备开发相关技能，均可自行组队（最少1人，至多5人），或以公司名义参加比赛。


参赛流程


  1. 每位选手需要有一个灵雀云账号；

  2. 登录开放黑客松（hacking.kaiyuanshe.cn）平台, 进入『牛津计划容器技术在线黑客松』，点击 『我要报名』；

  3. 注册成功后， 系统会给您发送一封参赛确认邮件，邮件中有重要的牛津计划APIs密钥（Key），请保存好此密钥以备您开发使用；

  4. 所有的作品都将需要以Docker镜像形式上传到灵雀云平台。（若您的参赛作品不能Docker化，请发邮件至 info@mathildetech.com 联系技术支持）；

  5. 所有参赛团队或个人请上传你们的作品及其附属文档：Docker镜像，应用链接，功能描述文档，幻灯片，视频等。
