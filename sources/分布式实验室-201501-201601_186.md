# 图文回顾Docker Hack Day北京站

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247542243&idx=2&sn=f4c3879f7067a00d9791e0a7bbbeec0f&chksm=c03b6ff0f74ce6e6b3c86d8fda437b7e66200fe17964b642fece09502dcb17c220b103dad4e4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247542243&idx=2&sn=f4c3879f7067a00d9791e0a7bbbeec0f&chksm=c03b6ff0f74ce6e6b3c86d8fda437b7e66200fe17964b642fece09502dcb17c220b103dad4e4&scene=27#wechat_redirect)

2015年9月19日，DockOne社区在北京成功举办了[Docker Hack Day活动](http://mp.weixin.qq.com/s?__biz=MzA5OTAyNzQ2OA==&mid=207864131&idx=2&sn=af24a91baaafed27d1ec5df74562cdeb&scene=21#wechat_redirect)，Docker Hack Day是Docker公司组织的全球编程马拉松比赛，在2013年和2014年已经成功举办过两届，累计有全球100多个城市参加了该项活动，今年首次来到中国。

Docker Hack Day不仅为中国的Docker爱好者提供了一个与全球Hacker们对垒的机会，而且是中国Docker社区与世界接轨的里程碑。DockOne社区一直致力于为中国广大的容器爱好者和技术人员服务，所以这次毫不犹豫拿下了这次活动，希望为中国的Docker技术圈再尽一份力。

本次活动共有17支团队报名，不曾想无情的加班使6支团队无缘Hacker Day，最终有11支团队到达现场（有两支团队从上海赶来，好感动）。经过一天半的Coding，完成了以下作品：

*   数人云刀客组  
    项目介绍：P2Pull，p2p模式下载Docker镜像。  
    项目地址：https://github.com/Dataman-Cloud/p2pull
    
*   Whale Pirates  
    项目介绍：通过构建一个配置共享中心，使用经典的“消息发布和订阅”模式来统一管理各个微服务的配置选项。  
    项目地址：https://github.com/nevermosby/whalepirates-docker-hackathon-project
    
*   Hulk Team  
    项目介绍：一个可以自动伸缩的Redis集群。  
    项目地址：https://github.com/Goyoo/dodis-server  
    https://github.com/Goyoo/codis-docker
    
*   D&C  
    项目介绍：Service Discovery in Docker Ecosystem。  
    项目地址：https://github.com/wangchunyang/service-scheduler  
    https://github.com/wangchunyang/official-images-repll  
    https://hub.docker.com/r/wangchunyang/service-scheduler/  
    https://hub.docker.com/r/wangchunyang/official-images-replication/
    
*   Jetlab  
    项目介绍：一个logspout的iOS APP，可以通过APP时监控容器的日志。
    
*   Tinycell  
    项目介绍：在Docker中运行的Webkit爬虫，使用swarm进行规模扩展。  
    项目地址：https://github.com/tiny-cell/tinycell
    
*   Rubber  
    项目介绍：Nsqelastic is the trial and implementation of nsqd cluster。  
    项目地址：https://github.com/deepglint/nsqelastic
    

本次活动评委由数人科技CEO王璞、时速云CEO黄启功、Hyper顾问赵鹏、灵雀云市场部副总裁于历濛担任。获奖团队是：数人云刀客组、Whale Pirates、Hulk Team、D&C，我们会将获奖团队信息交给Docker公司，参与全球的Hack Day总决赛评选。
