# 充¥1送¥50，多充5倍返，灵雀云Azure新区任你玩

为庆祝灵雀云本月在微软Azure平台开设新区——北京区／上海区，灵雀云特举办充值送优惠券活动。即日起，客户每月在灵雀云充值即可获得灵雀云新区的优惠券。

  

  

**活动规则**

  

1.  用户每月充值的首个¥1，灵雀云将给您价值¥50的新区优惠券；  
    
2.  首个¥1之后，灵雀云将按照充10元返50的方式返还优惠券，多买多送；
    
3.  用户依然可以使用充值的金额购买所有区域的节点；
    
4.  优惠券将在用户充值之后48小时内发到用户的注册邮箱。
    

  

**举个栗子：**

  

用户小明9月充值31元，那么老王得到的优惠券价值为：¥1 X 50 ＋ ¥30／10 X 50 = ¥200，老王可以在灵雀云的新区使用该优惠券，同时，他充值的31元不受区域使用限制。

  

**活动周期**

  

即日起至11月30日

  

  

**优惠券说明**

  

1.  用户可以在灵雀云的新区（北京区、上海区）使用优惠券；  
    
2.  优惠券自购买之日起即可使用，有效期至11月30日。
    

  

  

**备注**

  

新区暂不支持挂在存储卷，但运行无状态服务，例如测试或者海量计算，是个好的选择。
