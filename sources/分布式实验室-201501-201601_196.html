Docker Hack Day是Docker公司组织的全球编程马拉松比赛，在2013年和2014年已经成功举办过两届，累计有全球100多个城市参加了该项活动。今年，Docker Hack Day首次来到中国，DockOne社区联合Docker公司为广大Docker爱好者们带来了一场编程盛宴，让中国的Docker社区与世界接轨。这次Docker Hack Day活动将于9月的第三周开始，来自全球的万名Docker爱好者们将陆续在自己的城市开始Hack。

在中国，我们把这次Hack Day的地点定在首都北京，时间是9月的第三个周末。相信秋高气爽无雾霾的9月是北京最适合编程的季节。

Docker Hack Day鼓励大家以团队为单位来参赛，每个团队人数为1-3人。参赛团队需要基于Docker相关项目来开发，这些项目包括Docker、runC、Notary。为了最大限度的鼓励大家创新，本次活动不先限定主题和方向，只要基于Docker即可，安全、监控、编排、CI、Bugfix等任意方向都行，Who Care，Let’s Hack。这里只有程序和社区，让我们尽情High吧。

我们还邀请到了北京的Docker Committer前来参加此次Hack活动，他们将会现场解决你遇到的问题，这不仅是Hack，更是一对一培训。更重要的是，还免费。What the fuck。

比赛规则

1. 开发者必须以团队为单位进行报名，当然，你需要为你的团队起一个足够酷的名字。
2. 允许个人开发者现场组队，如果你们一见钟情，那就在一起吧。
3. 你需要提前提交作品信息和团队信息。
4. Docker版本必须在1.7以上。
5. 每人只能参与一个团队。
6. 作品可以基于提前准备的素材，但必须在比赛现场完成。
7. 现场提供WIFI，但参会者需要自备电脑。
