# 5个你应该参加Docker Hack Day的理由

Docker Hack Day第三季即将开赛，你造吗？Docker Hack Day是Docker公司组织的全球编程马拉松比赛，在2013年和2014年已经成功举办过两届，累计有全球100多个城市参加了该项活动。今年，Docker Hack Day首次来到中国，DockOne社区联合Docker公司为广大Docker爱好者们带来了一场编程盛宴，[赶紧报名吧](http://mp.weixin.qq.com/s?__biz=MzA5OTAyNzQ2OA==&mid=207864131&idx=2&sn=af24a91baaafed27d1ec5df74562cdeb&scene=21#wechat_redirect)\~~~~

1近距离了解Docker

![](../Images/9c077cf88d293d3fc77d9670108a0803.png)  
Hack Day上你可以与小伙伴们一起从代码层面上深度了解Docker，同时还可以与其他的参赛团队一起交流。

2赢取大奖

![](../Images/c4ba1371c29492e773aadd7feeb7db5f.png)  
Hack Day为参赛者准备了丰富的奖品，书籍、T恤、DockerCon门票、卫衣、服务器，应有尽有。当然，如果能获得本次大赛的全球冠军，那你就出名了。

3获得Docker公司的纪念品

![](../Images/e4115912e089b4f23a93fecc41bf3097.png)  
所有的参赛队员都将获得Docker公司提供的限量纪念品。

4与其他的Docker爱好者一起协作

![](../Images/d0079c83493b9cdb37c6bf4ef5d50007.png)  
不用想，参加Docker Hack Day的小伙伴都是代码牛人，他们有想法，有创意，更有一颗敢于创新的心。认识他们，与他们为伴，一起改变属于自己的世界。

5提高自己的知名度

![](../Images/f88a5957a2acaa95ad0be918d7726782.png)  
所有的参赛作品都会进入Docker的活动页面中，Docker也将会在Twitter、newsletter中推广这些作品，很快，社区中的人们就会知道你的伟大的作品，也许他们就是你的第一批种子用户。
