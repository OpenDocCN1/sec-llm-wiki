# Oracle、Twitter等公司加入开放容器项目，OCP项目更名为OCI

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247542183&idx=2&sn=27a4439e0a0d41ec3a58d9cff421fc70&chksm=c03b6fb4f74ce6a2797961c60f5e944f88da6703ad92fe69cdb3962c6a6afa79f56e222d84f8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247542183&idx=2&sn=27a4439e0a0d41ec3a58d9cff421fc70&chksm=c03b6fb4f74ce6a2797961c60f5e944f88da6703ad92fe69cdb3962c6a6afa79f56e222d84f8&scene=27#wechat_redirect)

一个月前的Docker的开发者大会上，Docker和Linux基金会（Linux Foundation）发布了开放容器项目（Open Container Project）。随后该项目发展势头甚好。今天早上在OSCON大会上，Linux基金会的执行董事Jim Zemlin宣布该项目的更名为开放容器计划（Open Container Initiative）。Zemlin同时宣布，有14个新的公司签署加入了该项目，而且OCI现在还积极制定着一份宪章草案（draft charter）。

新加入的14个成员包括 AT&T、ClusterHQ、Datera、Kismatic、Kyup、Midokura、Nutanix、Oracle、Polyverse、Resin.io、Sysdig、SUSE、Twitter和Verizon。他们会和该项目的创始成员如Amazon、Microsoft、CoreOS、Docker、Intel、Mesosphere和Red Hat等一起支持该计划，维护并推进Docker的规范，以达成建立起一个围绕容器的通用标准。

![](../Images/3f14751084610f58f4bb72996aa9baf0.png)  
Docker的市场VP告诉我们，现在OCI的支持者包括大公司、小公司和用户。他特别提到Oracle的加入，能让项目获得更多在Solaris上的支持，因为它们对此有丰富的经验。同样的，他相信随着更多的发行商、监控公司和大企业的加入并做出自己的贡献，这有利于协作，并最终带来更好的产品。

“开放容器计划势不可挡，这一方面显示出容器在应用开发方面巨大的潜力，另一方面也暗示着社区分化的挑战。”Linux基金会的Jim Zemlin今天在发布中这样说道，“有如此强大的社区支持和协作，我们相信这些努力一定会变成机遇。”

Docker的工程师 Patrick Chanezon告诉我们，该宪章背后的理念是轻量（lightweight）。将会有一个技术监督的委员会，用来处理有冲突的情况；并且也会有一个商标的委员会来执行即将发布的认证计划（certification program）。该计划会在接下来几个月启动。

随着容器生态圈的扩大，很显然迫切需要有一个容器自身以及容器周边工具的一个通用标准，否则可移植性容器的诺言很难实现。随着Cloud Native Computing Foundation（CNCF，原生云计算基金会）昨日的启动，Linux基金会现在也加入了另外一个跟容器有关的重要开源项目 – 这一次是围绕着Google的Kubernetes容器管理和调度工具。

那么为什么开放容器项目要更名为开放容器计划？Zemlin今天在OSCON的主题演讲中说，人们总是会跟Open Compute Project混淆，所以团队决定对名字做一点点改动。
