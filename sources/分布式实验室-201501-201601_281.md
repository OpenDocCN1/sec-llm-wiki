# OSCON上谷歌发布CNCF，欲联合合作伙伴共同推动容器计算的发展

我们荣幸地代表社区向大家宣布，开源容器集群管理工具Kubernetes已经达到V1的里程碑。这个重要版本包含了400多位贡献者的努力，意味着Kubernetes已经可以在生产环境中使用。这真是个重磅消息，但是要构建整个容器工具集我们还需要做更多的事情。

今天（7月21日），谷歌与Linux基金会以及众多行业合作伙伴一起推动基于容器的云计算的发展。我们准备共同建立一个云计算基金会（CNCF， Cloud Native Computing Foundation），目的有两个，一是与开源社区和合作伙伴一起共同把控Kubernetes未来的发展，二是开发新的软件以让整个容器工具集更加健壮。

**Kubernetes V1：400位贡献者，14000次提交。**

去年二月，Kubernetes的贡献者们齐聚旧金山，对1.0版本进行商讨，并最终确定其范围包括功能性、可靠性和可支持性。现在，我们已经实现了这些目标。已投入生产的Kubernetes有着如下优秀特性：

*APP服务，网络，存储*

*   在生产环境中部署和管理工作负载，包括DNS、负载均衡、扩展、应用级别的健康检查和服务记录。
    
*   与各种本地和网络卷的状态应用支持，如谷歌计算引擎永久磁盘，AWS弹性块存储和NFS。
    
*   在pod中部署容器，pod与容器密切相关，支持简单更新和回滚。
    
*   用命令执行检查和调试应用，通过CLI和UI进行端口转发，日志收集，资源监控。
    

*集群管理*

*   实时升级以及扩展。
    
*   通过命名空间分割集群，更深层次的管控资源。例如，你可以将集群细分给不同的应用或测试生产环境。
    

*性能和稳定性*

*   API响应速度快，平均容器调用时间小于5秒。
    
*   扩展测试，每个集群中，容器1000秒，节点100秒。
    
*   稳定的API
    

一年间， 拥有来自400多名贡献者的14000多份提交使Kubernetes成为人气最高的成功开源项目。这些贡献者分别来自红帽、CoreOS、IBM、英特尔、微软、VMware等公司。

很多客户已经在Kubernetes上运行他们的生产基础设施了，包括Box、eBay、Red Hat、Samsung、Shippable、Zulily。

**云计算原住民基金会：谷歌， Linux基金会和行业合作伙伴携手共同制定基于容器计算的未来**

容器正在改变人们部署和管理应用的方式，但是我们仍处于cloud-native和微服务应用的初级阶段。我们将和Linux基金会以及行业合作伙伴（Docker、IBM、VMWare、Intel、Cisco、Joyent、CoreOS、Mesosphere、Univa、Red Hat等）一起建立CNCF，为容器计算变得更加容易而努力。

第一步，我们计划用Kubernetes作为CNCF成长的开始。CNCF将控制Kubernetes未来开源的发展，以保证其在任何基础设施（公有云、私有云、裸机）上都能良好运行。

Kubernetes仅仅是个开始。CNCF的技术委员会将会推动开源以及合作伙伴社区共同开发容器工具集。他们还将评估列入基金会的其它项目，以保证整个工具集齐头并进。

了解更多关于CNCF的工作原理及加入方式，请访问网站。
