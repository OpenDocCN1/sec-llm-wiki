# Rancher Labs——一个价值1000万美金的容器管理创业公司

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247542139&idx=1&sn=18c1b039bb3bb1813451c5e5fc777d1e&chksm=c03b6f68f74ce67e3436352a14a4c216cf24e17d0129b7913bb5755c19745ed1aaad5f7b5f0c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247542139&idx=1&sn=18c1b039bb3bb1813451c5e5fc777d1e&chksm=c03b6f68f74ce67e3436352a14a4c216cf24e17d0129b7913bb5755c19745ed1aaad5f7b5f0c&scene=27#wechat_redirect)

Rancher Labs，是一个初创公司，他们通过开发一个轻量级的Linux操作系统以及在它之上运行的一套容器管理工具（管理运行在容器中的应用程序）——彻底改变了传统的虚拟机运行方式——刚刚声称今天获得了1000万美金的首轮融资。

这笔融资可以使得Rancher成为容器管理工具“俱乐部”中的一员；在这个“俱乐部”中的Docker已经非常流行，CoreOS的基于容器的Linux操作系统也已经产品化。许多“大厂”——Google、IBM、Microsoft、Red Hat与VMware都争先恐后的以多种方式跳入了容器管理提供商的市场争夺中。云计算提供商——Amazon Web Services与Joyent也已经支持容器的运行。

其他许多创业公司如： C3DNA、ClusterHQ、Mesosphere、StackEngine、Tutum、Twistlock和Weaveworks同样支持容器运行。

“我们现在很难说谁是我们的竞争对手，因为我们刚刚起步而且发展的非常快速，”一个Rancher的发言人通过邮件告诉我们：“所有人都从不同的角度切入这个市场，除开基本的容器数据的堆叠（overlap）技术，我们还提供与Weave与ClusterHQ的集成，我们的用户可以在网络与存储技术上可以有更灵活的选择权，并且从长远来看，Rancher与Docker会对现今主流统治地位的基础设施提供商的依赖越来越少，如：VMware和AWS。”

互操作性（interoperability）是容器的一个基本信条，但是，Rancher是否会利用这个机会向更多公司提供容器互通的能力并从中获利现在仍然不是很清楚。

Rancher的发言人告诉我们：“Rancher Labs是去年刚刚成立的新公司，总部在加尼福利亚的Cupertino；现在拥有20个雇员，其中一些来自于2011Citrix收购的Cloud.com公司；到今年年底Rancher预计会扩充到30人左右的规模。”

梅菲尔德风险投资公司与Nexus Venture Partners参与了此轮投资。
