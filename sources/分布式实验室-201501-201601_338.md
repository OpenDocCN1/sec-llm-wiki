# DockOne沙龙上海站图文回顾：恰逢高考，再交答卷

6月7日，伴随着一年一度的高考，DockOne技术沙龙来到了上海。和许多考生一样，我们的心情是又紧张又激动，这次沙龙对我们来说，何尝不是人生的一次考试？本次沙龙我们聚焦最近大家讨论的Docker热点，重点关注Docker在CI/CD、云计算方面的应用，并对Windows的容器技术以及存储做了详细分析，不知道我们答的这几道题各位考官是否满意？

最开始的沙龙召集信息在这里（http://dockone.io/question/267），上海的小伙伴们对Docker的热情真是挡不住，沙龙信息放出去10天后，就已经报名400多人，由于座位有限，我们就提前停止了报名。用比较流行的一句话说就是好的产品需要打磨，我们把沙龙看作是我们的一个产品，那每一次的沙龙都是一次产品的升级，很显然，这次我们的产品已经发布到了V 0.2，我们也希望各位能积极为我们的产品提出建议，相信有了你们的真知灼见，以后的沙龙就不愁更完美了！

本次沙龙的PPT我们已经上传到了微盘（http://vdisk.weibo.com/s/Fkad7p8ogXH9d），视频也已经发布。过多的话也不多说了，一切尽在片里和下面的图里。

最后的最后，感谢这次活动的赞助商们（特别感谢首都在线），没有你们的资金和礼品支持，我们根本无法举办这样一场活动，谢谢你们对社区的认可。

问卷调查（http://www.mikecrm.com/f.php?t=yaaNNR）发出后，目前我们共收到了112份会后反馈，有88%的小伙伴对我们的活动表示很满意，再次感谢大家对我们的支持和鼓励。同时，大家也给我们提了很多的反馈建议，我简单汇总下：

1.  演讲时，后面的同学有点吵（当时有进行制止，但效果不好。同时，也和我们的场地设计有关系，这次的场地是长方形，后面的同学看不清楚）。
    
2.  PPT应该提前公开（下次沙龙，我们会提前制作好HTML版本的PPT，供大家阅读）
    
3.  前两个的演讲广告严重（广告是我们一直强调不能有的东西，这次PPT审核时，我们也特意看了是否有广告，无奈还是有些小问题。欢迎大家提供如何提前预防演讲包含太多广告的点子，建议一经采纳，奖品马上送上）
    
4.  话题应该更聚焦（这个我们感觉到了，下次话题一定更更聚焦，同时，我们也会提前收集大家的反馈）
    
5.  妹子太少（这个…….）
