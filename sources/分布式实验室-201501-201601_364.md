# 应用Docker相关技术实现容器即服务的探索与实践

2015年6月7日（周日）13点到18点DockOne将在上海组织沙龙，本次沙龙是继4月12号的北京沙龙首秀之后的第二次技术沙龙，沙龙主题是Docker热点剖析。此次沙龙邀请了来自TenxCloud时速云的王磊，王磊老师为我们带来了《**应用Docker相关技术实现容器即服务的探索与实践**》的演讲。

容器技术随着Docker的出现而迅速红遍了全球，越来越多的公司开始关注，并在自己的开发运维系统中使用容器技术，Docker将会重新定义云时代的交付方式。本次演讲主要和大家分享一下如何使用Docker及其生态系统中的相关技术，来更好的使用和管理镜像、容器以及各种资源，并应用于软件产品的迭代开发、运维以及交付部署等各个环节。

**王磊：**时速云联合创始人，原IBM中国开发实验室资深软件工程师。从事过IBM服务器产品的开发，BPM、WebSphere Application Server 等中间件产品的开发；参与设计和开发下一代业务流程管理引擎，更好的适配于IBM Bluemix的云环境，对Blumix的架构有很好的理解。目前主要负责时速云容器即服务产品的技术架构、设计和开发工作。
