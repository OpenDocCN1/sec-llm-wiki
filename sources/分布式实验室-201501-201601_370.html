沙龙介绍

以Docker为代表的容器技术持续火热。其中，在微软的Build开发者大会上，微软对外演示了可以运行Docker的下一代的Windows Server，紧接着在CoreOS的Fest大会上，CoreOS又宣布AppC标准受到了红帽、VMware等公司的支持。看样子，容器之战一触即发！同样，Docker官方已经开始招聘中国区主管，相信过不了多久就会进军中国。不过，不管外面有多乱，DockOne.io只想带你坐下来静静地聊聊技术。

继4月12号的北京沙龙首秀之后，DockOne.io将于6月7日在上海举办第二次技术沙龙，沙龙主题是Docker热点剖析。届时，我们将邀请前微软容器方面的技术负责人独家为您揭秘微软的容器技术，EMC技术专家介绍Docker集群的存储方案以及基于Docker的CI解决方案。

沙龙信息

沙龙时间：2015年6月7日（周日） 13：00-18：00
沙龙地点：上海·科学会堂

沙龙亮点

1. Windows Server容器技术揭秘
2. 基于Docker的解决方案
3. Docker集群的存储方案

讲师介绍

左玥：左玥于2006年从美国德州A&M大学获得计算机科学硕士学位，研究方向为高性能计算和网格计算。毕业后，他加入美国微软公司的Windows部门，负责Kernel底层模块和多种存储、网络设备驱动的研发。 2009年，他加入了刚成立不久的Azure部门的OS和虚拟化团队，与NT总架构师Dave Cutler一起合作，负责研发了多个Azure的关键组件，并成为了网络虚拟化组的开发经理。他设计的Azure vSwitch，获得了美国专利，成为了Azure SDN架构的基础。2012年底，他接管了轻量级虚拟化团队，负责Azure和Windows的Container技术的研发。在微软的8年期间，他获得了六次晋升，成为首席研发经理。他还拥有六项云计算领域的专利。2014年底辞职回国，成立了云雀科技公司。

吴海鹏：DaoCloud技术合伙人，负责build和CI模块的设计和开发；技术geek一枚，喜欢coding，追求简单优雅的编码风格；熟悉互联网后台架构设计、云计算、虚拟化和容器相关的技术；曾任职于蘑菇街和VMware，Cloud Foundry 核心组件开发者。

王磊：时速云联合创始人，原IBM中国开发实验室资深软件工程师。从事过IBM服务器产品的开发，BPM、WebSphere Application Server 等中间件产品的开发；参与设计和开发下一代业务流程管理引擎，更好的适配于IBM Bluemix的云环境，对Blumix的架构有很好的理解。目前主要负责时速云容器即服务产品的技术架构、设计和开发工作。

张芸：EMC中国研究院高级研究员，长期关注和研究云计算相关领域，包括OpenStack、Cloudfoundry以及Docker。
