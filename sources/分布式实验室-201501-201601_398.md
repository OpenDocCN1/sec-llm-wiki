# Docker获9500万美元D轮融资，并牛逼地说B轮的钱还没花完

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247542083&idx=1&sn=2f1c64caa9ab3f598684a8f7f024cb51&chksm=c03b6f50f74ce646d59762b0e23c7253bd4c02ae5782ddb9677ad286f9eb7165517615449c0a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247542083&idx=1&sn=2f1c64caa9ab3f598684a8f7f024cb51&chksm=c03b6f50f74ce646d59762b0e23c7253bd4c02ae5782ddb9677ad286f9eb7165517615449c0a&scene=27#wechat_redirect)

在过去的两年内掀起了容器热潮的创业公司——Docker，今天宣布，**它完成了一笔由Insight Venture Partners领投的9500万美元的 D 轮融资**。在这一轮新的投资者包括Coatue、Goldman Sachs和Northern Trust。Benchmark、Greylock Partners、Sequoia Capital、Trinity Ventures和AME Cloud Ventures等原有投资方也跟进了投资。

在本周早些时候，与笔者交谈时，Docker的企业营销副总裁David Messina曾提到，能在本轮融资者中看到金融服务的公司十分有趣。他认为，这些有些“另类”的投资者，显示了各种公司的开发团队对Docker的支持，而且这些公司现在都把Docker当做他们团队的关键平台。

Goldman Sachs全球技术部联席主管Don Duet在今天的一份声明中说道：“当我们的工程师发现和开始使用Docker的开源平台时，他们立刻就被其应用的便携性所打动。它启发我们使用Docker技术，标准化了应用的打包、移植和运行。”

Messina强调，Docker对本次融资没有任何直接的财务需求。事实上，他告诉笔者，大部分B轮融资还没有被公司花掉，但为了将来能够按需扩大规模，Docker团队决定，借助目前的良好势头积累资本。

目前，Docker重点关注的是市场（go-to-market）和技术栈。而在技术堆栈中，又把网络、安全和存储相关的工具作为重点，并计划通过这些来扩展平台功能。Messina以收购软件定义网络启动SocketPlane作为例子，用以说明公司是如何将Docker推进这些领域的。Docker招聘员工的速度也非常快，公司现有员工120人左右，大约为是一年前的四倍。

Messina还强调，Docker决定发动本轮融资是为了确保解决企业的进一步需求。他引证了一份最近的企业技术报告，其中调查了685个企业的CIO。根据一项长达六年的研究调查，Docker记录了受访者最强的购买意愿得分。Messina还指出，目前，在Docker Hub中百分之五十的公司是世界100强企业。
