Azure容器服务：云端最开放的容器选择

容器是虚拟化技术的下一场革命，能让企业获得前所未有的敏捷性。每一天我都能看到这样的案例在客户身上发生！他们一次性编写好的应用，能部署到任何地方，不论它是开发、测试或者生产环境。容器无需改动就能运行在任何硬件、任何云、和任何环境上。简单的讲，它们给敏捷的DevOps提供了一个真正开放和可移植的方案。

通过Azure Container Service（Azure容器服务，简称ACS），我们为客户在云环境中提供了管理容器的独特方式。它利用经受住了考验的开源容器编排技术，为客户提供了伸缩生产环境中容器的简易之道。今天我们发布了一系列ACS的更新，让客户有更多的云编排器可供选择，这也将继续证明ACS是在云端运行容器最顺畅、最开放和最灵活的方式。这些今天即开放可用的更新包括：

  • ACS上的Kubernetes（预览版）：在2014的七月，差不多在Kubernetes公开发行一个月之后，我们就宣布了在Azure基础设施对Kubernetes的支持。Kubernetes 1.4中提供了与原生Azure网络、负载均衡器和Azure磁盘的集成支持。今天，我们宣布发布ACS上Kubernetes 1.4的预览版本，进一步深化了这方面的支持。这种对Kubernetes更原生、更深度的支持，在Azure上提供了另外一个完全开源的容器编排引擎选项。现在客户在采用云编排器时有了更多的选择，并且有三个受ACS支持的完全开源的方案：DC/OS、Docker Swarm和Kubernetes。你可以在这里（http://blog.kubernetes.io/2016/11/bringing-kubernetes-support-to-azure.html）了解Kubernetes的创始人之一，Brendan Burns，对于ACS上Kubernetes的看法。

  • DC/OS升级到了1.8.4： 我们很高兴地宣布我们已经将ACS对于DC/OS的支持升级到了1.8.4。这个新的版本包括新增的灵活的虚拟网络能力，集成进DC/OS UI的任务调度和基于Marathon的容器编排。另外，现在Gitlab，Artifactory，Confluent Platform，DataStax Enterprise和我们自有的Operations Management Suite现在可以通过DC/OS Universe的应用商店里面一键安装了。

  • Azure Container Service Engine开源了： 今天，我们发布了ACS Engine（https://github.com/Azure/acs-engine）的源码，我们在Azure中用它来创建ACS部署。这个新的Github开源项目将会让我们向社区分享在我们是如何进行DC/OS、Swarm和Kubernetes的部署，以及如何基于Azure编排容器的最佳实践进行协作，不论是在公有云或者Azure Stack上。另外，你可以对Azure Engine中服务部署方式进行更改或者定制，达成各种今日未尽愿望。最后，在你们的帮助下，我们可以借助社区的贡献并继续改善Azure中运行的服务。

我们看到不同规模的企业正在将他们基于容器的解决方案从开发/测试环境推上了云端的生产环境，特别是在他们发现容器可能带来的商业敏捷性之后。除了在ACS上提供了更多的选择和灵活性外，我们正在通过更新来加强流畅的敏捷开发和容器管理体验，包括：

  • Azure Container Registry： Azure Container Rigistry是一个Azure上用来托管容器镜像的私有仓库，将会在11月14日的预览版中可用。通过使用Azure Container Registry，你可以存储Docker格式的镜像，并用于所有类型的容器部署。另外，Azure Contaienr Registry很好地与ACS提供的编排器进行集成。当你使用Azure容器仓库的时候，你会发现它和开源的Docker Registry v2兼容，所以你可以在ACR上使用相同的工具。

  • VS、VSTS和VS Code集成，和向ACS的部署： 同时，在11月14日，我们将会带来一种新的体验，让你可以使用Visual Studio，Visual Studio Team Services和开源的Visual Studio Code轻易地搭建多容器Linux应用的持续集成和开发环境。为了继续提升开发敏捷性，我们可能会采用某种开发和CI/CD解决方案，大力投入于打造卓越的容器“从开发-到测试-到生产”的部署体验。

Azure是唯一提供了能支持选择开源编排技术（如DC/OS、Docker Swarm和Kubernetes）的容器服务的共有云，能让您和您的团队使用偏爱的工具并更容易地采用容器技术。你收获的将不仅仅是敏捷方面的好处！赶快来ACS尝试DC/OS，Swarm或者Kubernetes吧！如果你有兴趣了解更多内容，那一定要观看Microsoft Connect()（https://connectevent.microsoft.com/），就在下周哦！
