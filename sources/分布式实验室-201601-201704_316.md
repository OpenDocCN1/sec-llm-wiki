# 调查 | 容器产品近一年的使用率增长了96%！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247542522&idx=1&sn=6bd6294c776720645fbc0ad2b86212f2&chksm=c03b6ce9f74ce5ff1767550c6a2f23cac0357507caf36f5cf1b1ebce68927eca5981198a0c19&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247542522&idx=1&sn=6bd6294c776720645fbc0ad2b86212f2&chksm=c03b6ce9f74ce5ff1767550c6a2f23cac0357507caf36f5cf1b1ebce68927eca5981198a0c19&scene=27#wechat_redirect)

在过去的一年，容器生态圈正在以惊人的速度发展，几乎实现了增长翻倍。下面我们从第二次年度容器调查中探寻下容器生态圈到底发生了什么变化？查看第一次年度调查报告：https://clusterhq.com/assets/pdfs/state-of-container-usage-june-2015.pdf。

由ClusterHQ委托DevOps.com进行的一项针对310份IT产品的调查显示，我们惊讶的发现，一年来容器技术应用于生产的比例增长了96%。

![](../Images/c7c3889f49e33762a5617b449d703753.png)  
您可以下载完整报告（https://clusterhq.com/assets/pdfs/state-of-container-usage-june-2016.pdf）或查看原始数据（http://dwz.cn/3FxvGO），摘要如下。

  

  

![](../Images/012972ae036968155329ba4bf0391f18.png)调查结论

*   在了解公司金融投资状况的被访者中，52%的公司对容器技术进行了金融投资，有的超过了百万美金。
    
*   对已经在容器方向进行货币投资的公司中，56%的公司是在近一年内新增的。
    
*   采用了容器技术的组织中72%的达到或超过了组织商业及IT规划目标，但是未使用容器技术的组织中平均只有63%的组织达到了商业及IT规划目标。
    
*   超越了安全性，持久化存储成为这一年容器发展最大的瓶颈。  
    这些结论不仅仅证明了容器技术的新兴活力，也预示了快速增长所带来的巨大市场契机，同时采用容器技术的组织也可能赢取竞争性优势。
    

  

![](../Images/012972ae036968155329ba4bf0391f18.png)推进容器使用仍需解决的困难

这次的调查同样显示容器技术应用的困难也明显增加。在2015年，61%的被访者认为安全是容器最大的瓶颈，其次是数据管理（53%）和网络管理（51%）。然而2016年的调查显示持久化存储（生产环境数据库开始大量部署在容器中后此问题明显提升）成为容器部署最大的挑战，安全性反而下降为第三位的问题。被调查者中认为组织未采用容器的首要原因是对容器技术了解不足，而导致未投资资源。

![](../Images/d83490ffbdc7a912f3d00e4b6e927710.png)  

  

  

![](../Images/012972ae036968155329ba4bf0391f18.png)Kubernetes成为最受欢迎工具，但同其他工具流行度相差不大

今年的调查表明Kubernetes容器管理工具使用率明显增长。2015年，50%被访者选择Docker Swarm作为他们首选的容器编排工具，其次是Kubernetes（38%），Mesos（35%）。而今年的调查显示，虽然Docker Swarm保持了强劲的优势地位，但Kubernetes成为被最广泛使用的编排工具。根据被调访者提供的所有在用的容器编排工具数据，排列前五位工具为：

*   Kubernetes：40%
    
*   内部开发工具：32%
    
*   Docker Swarm：32%
    
*   Amazon ECS：24%
    
*   Mesos：15%
    

这组数据表明：员工仍然希望通过同时使用多个容器管理工具来判断哪种更适合。

![](../Images/df474e843ebc1292da31e4b0d91a741a.png)  

  

  

![](../Images/012972ae036968155329ba4bf0391f18.png)开发者并不想寻找一个更好的虚拟机

容器经常被拿来跟虚拟机作比较，然而开发者并不想用容器来替代虚拟机，而是想用容器技术来提升开发效率以及支持微服务架构。

![](../Images/687bf5342b401d074240ac073a9cb419.png)
