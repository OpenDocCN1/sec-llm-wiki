# 互联网公司的技术选型和演进－－以Docker在点融网的使用为例 | @Container容器技术大会

@Container大会是由国内容器社区DockOne组织的专为一线开发者和运维工程师设计的顶级容器技术会议，会议强调实践和交流，话题设置围绕容器、运维、云计算等技术领域，力求全方位、多角度为参会者解读容器技术。

大会上来点融网的基础服务部总监万林涛将给大家带来分享。

**分享题目**：互联网公司的技术选型和演进－－以Docker在点融网的使用为例

**分享摘要**：技术选型可以说是一件既简单又复杂的事情。商用软件的成熟和开源软件的火爆，使得在做方案规划、架构设计和功能实现时都有了更多的技术选择，正所谓“条条大道通罗马”；然而，选择太多未必是好事情，试图从中选出一个最好的技术方案恐怕是一件耗时耗力的任务。

以Docker为代表的容器技术的兴起，让大家在虚拟化技术之外又多了一条路－－当然，这里并不是说容器与虚拟机是完全互相替代的技术。以点融网在采用Docker技术作为基础架构的决策过程和技术演进为例，结合在使用过程中的经验和教训，和大家一起探讨互联网公司在技术选型中需要考虑的种种技术和非技术的因素。

**讲师介绍**：万林涛，点融网基础服务部总监。曾于EMC中国研究院（EMC Labs China）工作多年，主要从事云计算和大数据基础架构领域相关技术的研究和开发；现在就职于互联网金融公司点融网（Dianrong.com），主导开发运维工作，打造了以Docker为基础的开发和运维流程，在开发、测试和生产环境中大规模使用了容器技术。业余热衷于研究 Linux 内核、OpenStack、Docker等开源项目。
