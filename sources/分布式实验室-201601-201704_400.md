# 开源DC/OS介绍：容器的最佳运行平台

自Marc Andreessen提出“软件吞噬世界”口号以来已经过去了五年，而事实也证明了他的断言。我们这里提到的软件类型绝不仅仅是那些与日常生活息息相关的移动应用乃至网站。二十一世纪的企业需要迎接一个新的世界，在这里软件直接支撑一切事物——从电视到汽车，从社交媒体到银行系统。

如果不精于软件之道，那么我们将无法在市场竞争中继续生存。如果大家希望统治二十一世纪的业务领域，那么软件亦不可避免地成为各位手中的武器。如今最为睿智的企业都已经意识到这一点——包括亚马逊、苹果、Facebook、通用电气、谷歌、三星以及优步。

有鉴于此，**我们于今天自豪地公布开源DC/OS项目。**这款产品由Mesosphere倾数年之力打造，并由数十家大小合作伙伴共同参与。DC/OS旨在为企业客户提供实现软件定义经济所需要的根本基石。下面我们就介绍DC/OS的运作原理、开发参与成员以及项目的发展情况。 

为当下及未来的应用程序构建而成

近年来，围绕容器与Docker诞生的开发成果可谓不断涌现。DC/OS能够原生支持这些现代打包系统，且从立项之日起就将容器作为首要考量目标。不过驱动DC/OS出现及发展的核心驱动力在于，目前容器与容器编排仍然无法满足实际需求。

软件并非仅仅局限于运行在容器内的代码，正如其绝非仅仅是直接安装在移动设备或者车辆控制系统内的代码。过去，应用程序往往采用两种实现方式：全面本地化或者接入单一服务器。但如今，最出色的应用程序通常建立在分布式系统之上，并由无数独立服务、存储引擎以及数据处理工具共同构成。即使是基于云的人力资源应用，也只是庞大软件系统中的单一用户接触点。

如今的现代企业应用中包含有运行在容器中的微服务及有状态大数据服务。现代应用广泛采用开源软件，帮助企业通过社区贡献获取各类核心技术成果。

应用程序的构建方式也正是如此，从而处理当下围绕性能、功能、可靠性以及持续改进所提出的各项需求。另外，各组件间的协作效果越好，用户、运维人员及开发者的体验也就越出色。这部分工作非常困难，因此各企业往往需要投入无数时间与精力来构建起足以运行各类软件应用的基础设施平台。

DC/OS直接解决了大部分此类任务，允许用户轻松部署单一平台以运行一切现代应用所必需的元素——从Docker容器到大数据系统——且立足于同一套共享资源集合。

多方协作构建DC/OS

DC/OS是一项开源技术成果，但其同时也是一套生态系统。它由Mesosphere公司牵头打造，同时拥有60多家合作厂商的积极参与——参与各方都很清楚为新型应用开发新型基础设施软件的重要意义。各合作伙伴包括微软等云计算供应商以及埃森哲等领先系统集成商，外加Yelp等全球最具创新能力的消费级技术厂商。

其它参与合作伙伴还包括Autodesk、思科、Confluent、EMC、Equinix、惠普企业业务公司、NGINX、Puppet以及Verizon。

每一家DC/OS合作伙伴都能够接触其早期代码，并以方式提交贡献以推动并塑造这一项目。部分参与方将自己的技术方案添加至DC/OS当中，另一些则以其为基础建立新型产品。也有一些计划在自有数据中心内运行DC/OS，同时贡献代码以确保其能够持续为运行中的容器、微服务、大数据系统以及现代企业应用所必需的一切元素提供最为可靠、可扩展性强且易于使用的平台基础。

DC/OS：不止于Mesos

DC/OS衍生自Mesosphere的数据中心操作系统——这是一款围绕Apache Mesos构建而成的商用产品。开源DCOS一直作为我们战略发展路线图的重要组成部分，而我们也为能够与各合作伙伴并肩作战而感到骄傲。  
DC/OS是一套100%纯开源平台，其中包含超过30项组件技术，最为典型的有Apache Mesos与Marathon。Mesos等组件技术一直遵循开源路线，而其它一些技术则源自由Mesosphere以往开发的专有代码，例如GUI以及我们的Minuteman负载均衡器。

其特性包括：

*   业界最成熟、完全适合生产要求的容器编排平台，以Mesos与Marathon为实现基础。
    
*   快速、一键式、类应用商店型安装方案：利用DC/OS Universe，用户能够轻松安装包括HDFS、Apache Spark、Apache Kafka、Apache Cassandra等在内的各类复杂分布式系统。
    
*   面向全部应用程序、服务及工作负载类型提供内置的高可用性与容错能力。
    
*   基于GUI的监控与管理方案。能够将数千台设备整合为单一逻辑计算机，从而显著简化数据中心管理工作。
    
*   智能化工作负载调度，配合任务及容器自动化部署以提升使用效率。
    
*   可在裸机、虚拟机或云等部署平台上实现统一的标准用户体验。
    

**DC/OS绝不是玩具**——以其为基础的各项技术已经在世界多家大型且最具创新能力的企业中承载生产应用及无数容器环境。作为合作伙伴及用户，Autodesk公司自将其数据流与大数据获取通道服务迁移至DC/OS后，已经实现了可观的效率改进（http://cloudengineering.autodesk.com/blog/2016/04/autodesk-is-forging-ahead-with-dcos.html）：

*   AWS实例数量降低66%
    
*   成本效益提升57%
    
*   40秒即可完成新build部署，且无任何停机时间
    
*   3分钟建立新的服务区
    
*   100%正常运行时间
    
*   1位DevOps工程师即可管理全部基础设施

为什么要对这套数据中心操作系统进行开源

DC/OS属于开源项目，因为我们希望将其强大的能力交付至更多用户手中。具体来讲，DC/OS能够帮助企业客户享受到如苹果、Yelp、Netflix以及Twitter（从广义角度讲，还可算上Facebook与谷歌）等巨头级企业的先进运维与架构实践方案，同时无需“重造轮子”或者雇用顶尖分布式系统工程师。DC/OS的目标是将这类先进数据中心环境及应用平台带来任何有需要的用户。

在Mesosphere，我们笃信开源理念。开源软件能够帮助其缔造者克服自身视角的局限。众多用户、合作伙伴及贡献者社区的参与，意味着我们能够不断根据新的需求及用例对DC/OS做出改进。

DC/OS的核心为Mesos

DC/OS的核心正是Mesos分布式系统内核。DC/OS利用Mesos处理任务调度、资源管理与抽象、高可用性以及其它基础设施层级的流程。苹果、Yelp、三星、Twitter以及其它众多大型企业都已经将Mesos扩展至惊人的规模，并以其为基础运行多种极具创新属性的应用程序。

然而，围绕Mesos构建而成的各项技术成果亦是DC/OS诞生的重要前提。其中包括原生容器编排与应用平台（Marathon）、DC/OS安装工具以及Universe体验、强大而又直观的用户管理与监控界面，外加针对网络、安全性、负载均衡、服务发现等各个层面做出的改进。

DC/OS是目前惟一能够将这些要素结合在单一软件发行版中的开源项目。DC/OS确保每家企业都能与其它早期Mesos采纳者获得同样的收益，又不必受到工程技术难题的困扰。

**Mesos将永远作为DC/OS的核心存在**，而Mesosphere将继续在Mesos社区当中扮演领导者角色。我们的工程技术团队将不断为Mesos做出贡献，Mesos联合缔造者兼Mesosphere公司联合创造人Ben Hindman也将继续统领这一Apache项目。另外，出现在Mesos当中的每一项改进与创新都将被引入到DC/OS当中。

感兴趣的朋友可以点击（https://mesosphere.com/blog/2016/04/19/hindman-mesos-dcos/）此处参阅Ben就开源DC/OS提出的见解。

DC/OS面向容器，但又不局限于Docker

由于拥有强烈的容器指向性，人们往往会将DC/OS与其它高人气容器技术相比较——例如Kubernetes与Docker Swarm。尽管DC/OS Marathon技术确实拥有强大的Docker容器运行能力，但其实际拥有三大突出特性：

*   **DC/OS长于运行Docker，但亦擅长运行其它各类容器**。 DC/OS及其Marathon容器编排组件构建起一套卓越的Docker容器运行平台。但面对不断出现的各类容器格式，用户还需要更为可观的灵活性。  
    DC/OS以Mesos为核心构建而成，其采用可插拔式容器化工具以处理现有及新兴容器格式，并已经能够同时支持Docker容器以及“原生”Mesos容器。后者利用Linuxcgroups与namespaces，并作为启动Spark或者HDFS等DC/OS服务时的默认资源隔离方法。**原生Mesos容器化工具的优势在于，用户并不需要实际考虑与容器相关的问题。**当用户通过Universe GUI或者命令行安装新服务时，其会自动完成调度并对各内部Linux容器进行隔离——这种运行方式类似于裸机运行，且无需创建任何镜像！如此一来，复杂的分布式系统只需几分钟即可部署完成。
    
*   **DC/OS delivers on container operations提供容器操作机制，而非单纯的容器编排**。Marathon服务已经成为目前市场上最为成熟的容器编排引擎，其包含一系列极为强大的功能，足以完成容器（亦适用于长期运行的非容器化应用）的启动、管理、规模伸缩以及网络操作等任务。另外，其还拥有一整套非常积极的新功能发展路线图。目前将Marathon引入生产环境的大型企业包括Verizon、三星、Yelp、Autodesk、迪士尼以及Mattermark等等。
    
*   **DC/OS拥有一套独特的双层调度体系，其能够将包括Kubernetes及Swarm在内的各类系统以服务方式运行**。另外需要强调的是，DC/OS能够运行任何针对其进行过优化的系统，包括Spark、Kafka、Cassandra以及Jenkins等等。这些服务都能够显示在Universe当中，安装在DC/OS之上并与其它工作负载运行在同一套集群之内。

DC/OS面向创新做出优化

DC/OS目前由Mesosphere公司负责运营，并获得了各社区贡献者的帮助与规划。这一开源发展道路已经得到了实践的证明，Linux就是最为典型的例子。我们认为，保持这一发展途径对于建立充满活力并持续发展的DC/OS社区非常重要。

我们已经在GitHub当中为DC/OS建立了单独的组织，并基于Apache License 2.0（http://www.apache.org/licenses/LICENSE-2.0）进行了发布，其允许用户免费下载并使用该软件。我们还将探索更多不同的长期管理方案，包括将其交由Apache软件基金会、Linux基金会或者云原生计算基金会等第三方进行监管的可行性。我们还将立足于社区进行协作，建立长期可靠的运作方式，同时优化代码并提升平台稳定性。

Mesosphere的业务定位仍然基本不变

Mesosphere仍是一家软件公司，向全球两千强企业客户销售我们的产品——目前仍是如此。我们的Mesosphere Enterprise DC/OS产品（此前曾名为DCOS Enterprise Edition）利用多项关键性企业功能对安全性、性能、网络、合规性、监控与多团队支持做出了强化（DC/OS项目并不具备这些功能）。两套版本未来将继续保持差异化设计，但我们仍会不断为DC/OS与Mesosphere Enterprise DC/OS同时添加新型功能，从而尽可能为对应用户创造最大价值。

Mesosphere公司还拥有其它针对性软件产品，即Infinity与Velocity，其设计目标在于同Enterprise DC/OS协作并将很快正式推出。二者属于预集成解决方案，分别负责实时数据处理与持续集成/持续部署（或者应用程序开发生命周期管理）任务，能够显著简化包含多种组件的高复杂度流程系统的部署、运维与扩展难度。
