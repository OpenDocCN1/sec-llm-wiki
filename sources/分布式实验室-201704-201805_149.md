# 时速云完成近亿元 B 轮融资，单季度销售额破千万

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247543090&idx=3&sn=6da8599aea6ae493440966110dd20f91&chksm=c03b6321f74cea37cec3d3be9f82673892a3f16f251ae5ab3c05ec9d324c5520be4956bf992f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247543090&idx=3&sn=6da8599aea6ae493440966110dd20f91&chksm=c03b6321f74cea37cec3d3be9f82673892a3f16f251ae5ab3c05ec9d324c5520be4956bf992f&scene=27#wechat_redirect)

2018 年 1 月 17 日，技术领先的企业级容器云 PaaS 平台和解决方案提供商时速云宣布完成近亿元 B 轮融资，目前资金已经全部到账。本轮融资由泰达科技投资领投，原投资方朗玛峰创投、九合创投、众海投资继续跟进。时速云是国内容器云领域最早完成 B 轮融资的企业之一。  
![](../Images/ade97b9d8cc70d7de3d125500c4ba02b.png)时速云早期创始人：王磊、黄启功、杨乐  
时速云 TenxCloud 成立于 2014 年 10 月，是新一代容器云计算领域的领军企业，业务涵盖容器云 PaaS、微服务治理、DevOps、自动化运维、AIOps 等领域。时速云核心团队由来自 IBM、微软、Oracle、BAT 等知名企业的高管和技术专家组成，为金融、能源、运营商、制造、教育等行业客户提供私有云 PaaS 解决方案。时速云总部位于中国北京，并设立了上海、广州、武汉等分支机构。

  

首个基于 Kubernetes 的容器云 PaaS，引领私有云 PaaS 市场

![](../Images/570356efcc05d37119511bfb7a699a03.png)

随着容器云市场的深入发展，容器云、PaaS、微服务、Kubernetes、DevOps 等迅速火热 。自 2015 年起，以 Docker 为代表的容器技术生态主要经历了三大阶段：  
1）2015 年，Docker 最早作为应用快速打包、部署的工具出现在大家面前，并深受开发人员的推崇。Docker 一开始主要应用在开发、测试环节比较多，因为它能快速打包部署，而且能保持开发测试环境的一致性，极大的提高了开发测试的效率。这一时期的用户群主要以互联网公司为主，市面上的玩家多为创业公司，通过公有云提供容器云服务开始切入市场。  
2）2016 年，中大型企业开始关注容器技术，传统行业在进行企业数字化转型过程中，企业IT面临了一系列挑战：如何提高业务的交付效率、如何实现运维流程标准化、如何实现应用的微服务化等。而企业面临的这些痛点，容器技术能很好的解决，这促使企业开始大胆尝试新技术。催生了容器云 PaaS、微服务治理、开发测试云等一系列需求和应用。这一时期以 Kubernetes、Mesos、Swarm 三大容器编排技术平分天下，大型企业开始采用容器云。时速云是市场中最早支持和拥抱 Kubernetes 技术的服务商。  
3）2017 年，一个标志性的事件：Kubernetes 成为容器云市场的主流，并成为容器编排领域的事实标准。容器云 PaaS、微服务治理、DevOps 等项目纷纷进入金融、能源、电信、央企、制造等行业并逐步落地。  
时速云的产品主要包括容器云 PaaS 平台和微服务治理平台。前者是国内首款基于 Kuberenetes 打造的容器云 PaaS 平台，涵盖应用管理、交付中心、CI/CD、DevOps、集群管理等功能，帮助客户快速构建云原生应用、支持微服务架构、通过持续集成和持续部署，加速应用迭代。微服务治理平台为微服务框架应用的开发、部署、运行、运维提供支撑能力，提供包括服务注册、API 网关（限流、路由策略等）、服务调用链追踪、配置管理、应用性能管理、协议转化、授权、熔断、异常处理等主要能力，帮助企业轻松进行微服务项目的实施。

  

单季度实现千万级销售业绩的背后

![](../Images/34c506307c6d57264d269adcec2618cb.png)

在刚过去的第四季度，时速云实现了千万级的销售业绩。这主要得益于以下两点：  
**1）重视产品体验**时速云是全球云原生应用 CNCF 基金会银牌会员，也是Linux基金会会员。以及开源容器编排技术 Kubernetes、容器引擎 Docker、分布式存储 Ceph 等的贡献者。2017 年 3 月，时速云成功加入中国开源云联盟组织以及超融合联盟。 公司拥有多名 Kubernetes、Docker 等开源技术的源码贡献者，是国内第一家从事 Kubernetes 研发与应用的公司。时速云基于 Kubernetes 的 PaaS 产品在业内拥有良好的口碑效应，团队十分重视用户体验与产品细节。**2）与行业的深入融合**  
时速云最早是提供公有云容器服务，在 A 轮融资完成后，率先推出私有云 PaaS 产品，并深入金融、能源、运营商等行业，了解客户需求，针对性的给出行业解决方案。由于要实现一套完整的容器云 PaaS 产品，除了要精通容器技术本身包括 Docker、Kubernetes 等，还需要熟悉一系列的技术解决方案，包括容器网络、存储、日志监控、安全、微服务等等。其中不是简单的各种技术框架的应用，而是在这些底层系统出现问题的时候，团队能进行源代码级别的分析和解决。而能熟练开发和运维好这样一个平台至少需要几十名研发人员。在企业数字化的转型过程中，时速云 PaaS 平台针对性的帮助行业客户解决了企业 IT 面临的困难，赋能企业并创造价值。

  

布局”PaaS+”战略，助力行业 PaaS 落地

![](../Images/34c506307c6d57264d269adcec2618cb.png)

时速云主要提供基于 Kubernetes 的私有云 PaaS 服务，目前正在积极打造“PaaS+”战略，未来将以 PaaS 为核心，打造包含微服务、大数据、人工智能、IoT 等体系化产品矩阵。时速云将同广大应用服务开发商、SaaS 厂商等合作伙伴进行广泛的合作，通过 PaaS 的快速部署、敏捷运维、弹性扩展的能力，汇聚优质的企业应用，为客户提供更多的价值。  
目前时速云的客户主要集中在金融、能源、运营商、制造、教育等领域，标杆客户包括：国家电网、新奥集团、戴姆勒奔驰、链家、慧科集团、铂涛集团等。  
本轮融资完成后，时速云将加大研发投入，完善和丰富产品体系，同时扩大市场销售团队，提高销售的区域覆盖能力。未来，时速云将携手广大合作伙伴，为企业数字化转型赋能，并提供优质的 PaaS 云产品和解决方案。
