CNCF启动Kubernetes一致性认证计划，32家云系统及平台厂商获得通过

负责为Kubernetes以及Prometheus等开源技术提供支持与集成助力的云原生计算基金会（ Cloud Native Computing Foundation®，简称CNCF®）今天宣布推出Kubernetes一致性认证计划，旨在确保一切具备认证Kubernetes™的产品皆可提供必要的一致性与可移植性。目前已经有32套认证Kubernetes发行版与平台可供用户选择。


过去三年当 ，Kubernetes已经逐渐建立起一套充满活力且高度多元的贡献者社区。作为新计划的一部分，各供应商可利用新的自动化测试套件证明自身成果的一致性，而CNCF则负责认证其贡献成果。


以下产品已经通过认证Kubernetes一致性计划的审核：


  • Alibaba Cloud, Alibaba Cloud Container Service（阿里云，阿里云容器服务）

  • Apprenda, Kismatic Enterprise Toolkit (KET)

  • Appscode, Pharmer

  • Caicloud, Compass（才云）

  • Canonical, Canonical Distribution of Kubernetes

  • Cloud Foundry基金会， Cloud Foundry Container Runtime

  • CoreOS, Tectonic

  • DaoCloud, DaoCloud Enterprise

  • Docker, Docker企业版

  • Google, Google Kubernetes Engine（谷歌，谷歌Kubernetes引擎）

  • Heptio, AWS-Quickstart

  • Huawei, Huawei Cloud Container Engine（华为，华为云容器引擎）

  • IBM, IBM Cloud Container Service与IBM Cloud Private

  • Loodse, Kubermatic Container Engine

  • Mesosphere, Kubernetes on DC/OS

  • Microsoft, Azure ACS-Engine

  • Poseidon, Typhoon

  • SAP, Cloud Platform – Gardener

  • SUSE, SUSE CaaS (Container as a Service) Platform

  • VMware, Pivotal Container Service (PKS)

云原生计算基金会执行董事Dan Kohn表示：“新的认证Kubernetes一致性计划为各企业机构提供了信心，确保任何认证Kubernetes发行版或平台上可正常运行的工作负载亦可在其它认证版本上运行。Kubernetes承诺提供单一开源软件堆栈，可部署在任何公有、私有或混合云之上——这一互操作性保障在帮助Kubernetes获取各类供应商支持方面可谓至关重要。”


CNCF的认证Kubernetes计划目前已经覆盖了超过20种平台。 包括Docker，IBM，红帽，微软，甲骨文以及华为在内的各重量级企业都表示支持这个项目。


Kohn解释称：“在面向Kubernetes的某个版本进行认证时，您可以随时开始实施。 您目前可以认证1.7版本，但如果希望认证后续1.8或1.9版本，则原有1.7版本不必重新接受审查。 但如果完全脱离Kubernetes版本发布指导，而单纯认定1.8版本能够满足客户的所有需求，那么一年之后，您的软件版本将不再具有Kubernetes认证资质。”


“我们正在与各厂商进行通力合作，并且支持用户使用旧版本软件——尤其是在金融领域。只要您每年认证一个版本，即可长期持有认证资质。您可以认证1.7版本，而后每三个月认证一个新版本。您也可以首先认证1.11与1.15版本，而后认证1.17版本——总而言之，最低认证频率为每年一个版本。”

他同时补充称，采取每年一个版本的最低认证策略不仅是为了帮助用户始终与创新进度接轨，同时也是一项安全保障措施——因为安全功能将始终涵盖最后发布的三个Kubernetes版本。


认证Kubernetes产品承诺根据规范运行完整Kubernetes API，旨在为用户提供无缝化稳定体验。


认证Kubernetes实现方案亦获准使用新的认证Kubernetes标识，并可将Kubernetes标志与其产品名称加以结合。认证程序的发展则要求CNCF与整个Kubernetes社区开展密切合作——特别是同测试与架构特别兴趣小组（简称SIG）进行合作。


Kubernetes架构SIG担任该API一致性定义的最终仲裁方。此项计划还包括作出有力保证，要求各Kubernetes商业供应商持续发布后续新版本，帮助客户随时利用快速发展当中的各项技术成果。Kubernetes已经成为开源历史上发展速度最快的软件项目之一。

Mesosphere联合创始人兼CTO Tobi Knaup：“我们对认证Kubernetes计划的出台感到兴奋，其能够确保一致性水平并防止项目fork降低用户体验。在Mesosphere，我们致力于保证各团队能够轻松安装并操作100%纯Kubernetes集群。这些Kubernetes集群具备高度可用性、默认安全，且能够轻松与DC/OS所提供的生产级数据服务相集成。”


微软Auzre、容器首席项目经理Gabe Monroy：“微软公司对Kubernetes作出的承诺涵盖多种产品，我们将在未来几周内将更多新的托管Kubernetes服务（简称AKS）添加至自身兼容服务列表当中。我们致力于为客户提供最佳体验，包括为其容器工作负载寻求可靠、可扩展且可移植的运行环境。”

我们诚挚邀请各供应商运行此一致性测试套件，并提交一致性测试结果以供CNCF进行审查与认证。最终用户应确保其供应商合作伙伴接受Kubernetes产品认证，并可利用同样的开源测试套件确认这一认证结果。
