# CNCF启动Kubernetes一致性认证计划，32家云系统及平台厂商获得通过

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247543029&idx=1&sn=e69e9a822195e97a46c52893628eca35&chksm=c03b62e6f74cebf0fc69c41c1d997971c2cf7975b5bdc639930512d7acd3942f4e92d0c59328&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247543029&idx=1&sn=e69e9a822195e97a46c52893628eca35&chksm=c03b62e6f74cebf0fc69c41c1d997971c2cf7975b5bdc639930512d7acd3942f4e92d0c59328&scene=27#wechat_redirect)

负责为Kubernetes以及Prometheus等开源技术提供支持与集成助力的云原生计算基金会（ Cloud Native Computing Foundation®，简称CNCF®）今天宣布推出Kubernetes一致性认证计划，旨在确保一切具备认证Kubernetes™的产品皆可提供必要的一致性与可移植性。目前已经有32套认证Kubernetes发行版与平台可供用户选择。

  

过去三年当 ，Kubernetes已经逐渐建立起一套充满活力且高度多元的贡献者社区。作为新计划的一部分，各供应商可利用新的自动化测试套件证明自身成果的一致性，而CNCF则负责认证其贡献成果。

云原生计算基金会执行董事Dan Kohn表示：“新的认证Kubernetes一致性计划为各企业机构提供了信心，确保任何认证Kubernetes发行版或平台上可正常运行的工作负载亦可在其它认证版本上运行。Kubernetes承诺提供单一开源软件堆栈，可部署在任何公有、私有或混合云之上——这一互操作性保障在帮助Kubernetes获取各类供应商支持方面可谓至关重要。”

  

CNCF的认证Kubernetes计划目前已经覆盖了超过20种平台。 包括Docker，IBM，红帽，微软，甲骨文以及华为在内的各重量级企业都表示支持这个项目。

  

Kohn解释称：“在面向Kubernetes的某个版本进行认证时，您可以随时开始实施。 您目前可以认证1.7版本，但如果希望认证后续1.8或1.9版本，则原有1.7版本不必重新接受审查。 但如果完全脱离Kubernetes版本发布指导，而单纯认定1.8版本能够满足客户的所有需求，那么一年之后，您的软件版本将不再具有Kubernetes认证资质。”

  

“我们正在与各厂商进行通力合作，并且支持用户使用旧版本软件——尤其是在金融领域。只要您每年认证一个版本，即可长期持有认证资质。您可以认证1.7版本，而后每三个月认证一个新版本。您也可以首先认证1.11与1.15版本，而后认证1.17版本——总而言之，最低认证频率为每年一个版本。”

他同时补充称，采取每年一个版本的最低认证策略不仅是为了帮助用户始终与创新进度接轨，同时也是一项安全保障措施——因为安全功能将始终涵盖最后发布的三个Kubernetes版本。

  

认证Kubernetes产品承诺根据规范运行完整Kubernetes API，旨在为用户提供无缝化稳定体验。

  

认证Kubernetes实现方案亦获准使用新的认证Kubernetes标识，并可将Kubernetes标志与其产品名称加以结合。认证程序的发展则要求CNCF与整个Kubernetes社区开展密切合作——特别是同测试与架构特别兴趣小组（简称SIG）进行合作。

  

Kubernetes架构SIG担任该API一致性定义的最终仲裁方。此项计划还包括作出有力保证，要求各Kubernetes商业供应商持续发布后续新版本，帮助客户随时利用快速发展当中的各项技术成果。Kubernetes已经成为开源历史上发展速度最快的软件项目之一。

**华为云**业务PaaS产品部门副总裁Jiayongli：“华为公司很荣幸能够在新近建立的CNCF认证Kubernetes一致性认证项目当中，成为首批认证云供应商。通过获得CNCF的认可，华为再次强调我们向客户与合作伙伴许下的承诺，以一致性、可移植化为云服务为核心建立起真正的开源云技术总体发展愿景。这充分体现出华为云平台产品的品牌完整性，亦增强了华为云平台对自身能力的信心以及客观实力水平。”

  

**IBM云**研究员、副总裁兼CTO Jason McGee：“Kubernetes在开发者群体当中获得了前所未有的普及速度，也正因为如此，我们才决定将其作为IBM Cloud Container Service与IBM Cloud Private产品的核心组成部分。通过Kubernetes开放技术社区提供的互操作性标准认证，IBM公司正在积极投资Kubernetes的未来发展，并确保开发人员能够更轻松地通过IBM云以及其它平台立足数据与应用实现创新。”

  

**Mesosphere**联合创始人兼CTO Tobi Knaup：“我们对认证Kubernetes计划的出台感到兴奋，其能够确保一致性水平并防止项目fork降低用户体验。在Mesosphere，我们致力于保证各团队能够轻松安装并操作100%纯Kubernetes集群。这些Kubernetes集群具备高度可用性、默认安全，且能够轻松与DC/OS所提供的生产级数据服务相集成。”

  

**微软**Auzre、容器首席项目经理Gabe Monroy：“微软公司对Kubernetes作出的承诺涵盖多种产品，我们将在未来几周内将更多新的托管Kubernetes服务（简称AKS）添加至自身兼容服务列表当中。我们致力于为客户提供最佳体验，包括为其容器工作负载寻求可靠、可扩展且可移植的运行环境。”

  

技术与市场营销内容负责人Nick Chase：“随着今年9月最新Mirantis云平台的发布，我们开始全面接受Kubernetes作为我们未来发展的一部分，并将新的容器服务引入托管开放云组合，从而充分发挥其背后愈发成熟的开源项目所带来的巨大力量。认证Kubernetes计划使客户能够对其所选择的产品或服务的互操作性充满信心，而这一点对于多云世界而言至关重要。”

**红帽**副总裁兼首席技术官Chris Wright：“对于红帽公司而言，我们的核心在于坚信上游应首先发展的模式与跨社区协作开发的巨大能力，这一切是为技术业务带来标准化机制的前提。通过对开源创新与开放标准的支持，红帽公司正在帮助世界各地的客户应用容器技术——包括红帽OpenShift容器平台，一款领先的Kubernetes企业级发行版。”
