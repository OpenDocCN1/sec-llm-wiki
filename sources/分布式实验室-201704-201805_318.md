# SDN实战特训营第八期 三天打通SDN任督二脉

SDN实战特训营是未来网络学院的特色培训项目，目前已在各一线城市开展了七期。该项目以实战为牵引，结合OpenDaylight和OpenStack两大主流开源项目，帮助学员快速全面的掌握SDN编程方法和思路，同时解决如何利用SDN设计云数据中心网络。最终目的是为学员在SDN的世界里闯荡打下坚实的基础，在学习中少走弯路，学会快速融汇贯通，蜕变成行业精英和科研骨干。

  

SDN实战特训营由未来网络学院提供实战平台和专业的技术支持，来自国家电网、腾讯、H3C、中兴等知名企业、运营商以及有志于从事云计算或SDN工作的在职人员（其中不乏编程和网络高手），在经验丰富的讲师团的带领下，在码农与网工双重技能加持下，完成了数十个精心设计的实验，系统掌握了SDN编程的切入点、方法和思想，及SDN如何与云计算平台OpenStack集成等知识。受到了学员和业界的认可，现**SDN实战特训营第八期即将开营**。

课程特色

  

*   有全部来自一线实战部队的讲师团
    
*   有真实的网络试验平台供学员使用和学习
    
*   案例分享全部是基于真实的客户部署
