# 容器技术大会 | Container Day 2017

云计算领域发展正当其时，而容器技术作为云计算技术发展的新阶段，正改变着IT服务交付的方式和云计算的未来。容器技术在过去两年的发展中，已从最初的一个新兴理念，变成了如今以燎原之势被大量企业应用的技术。

  

Rancher Container Day是由硅谷著名容器技术公司Rancher Labs主办的容器技术盛会，大会为期一天，特邀来自**海航、华为、恒丰银行、阿里、民生保险、电信**等企业的IT负责人带来共计14场主题演讲。大会聚焦容器技术落地经验，结合实战场景，云计算领域行业领袖将全力助力您洞悉云端先机。
