开发定制化应用的重要性

数字化变革正催生出众多新的商业模型。无论是掌上银行、个性化零售、智能医疗抑或联网汽车，定制化应用正不断涌现，并在现代企业的客户品牌体验与创收当中扮演至关重要的角色。


要完成这场数字化转型，企业需要积极搭建通往云原生彼岸的道路。具体而言，其将应用重新打包成容器格式、为开发者提供框架和工具以及拓展跨私有云和公有云的容器服务等方式积极开启应用的现代化转型，进而在构建十二因子和基于微服务的应用及其基础设施的道路上不断前进。


企业依靠定制化应用取得竞争优势。反过来，定制化应用则依赖容器服务以加速革新，缩减市场投放时间，并不断提升扩展性和可用性。最终，IT机构需要为开发团队提供容器基础设施，从而确保其取得成功。


Kubernetes与容器生态系统


Kubernetes是一套用于对容器化应用进行部署、伸缩和管理自动化的系统，并已经成为客观层面的标准化容器编排平台。Kubernetes框架提供诸多关键性应用层能力，如应用编排、伸缩、运行状态监控与修复等。更值得一提的提，Kubernetes的各项功能可通过一套简洁而一致的REST API供用户全面运用。


尽管 Kubernetes 处于云原生生态系统的中心，但在生产环境中构建并运营一套强大、可靠的企业级容器服务体系仍然充满挑战。


  • 尽管Linux容器并非新鲜事物，但开源容器项目仍然处于不断进化、尚未成熟的状态 – 特别是在交付企业所需能力方面。

  • 容器框架在某些领域缺少一些关键能力，如安全、多租户、身份和访问管理。

  • 尽管Kubernetes 在应用层提供多种实用工具，但可用于对底层基础设施进行可靠部署、维护、监控和伸缩的工具仍然较为滞后。

  • 最后，来自可信任伙伴的端对端整体技术堆栈支持仍较为有限。


VMware Pivotal Container Service介绍

为了迎接这些挑战，VMware、Pivotal与Google Cloud 正携手开发 VMware Pivotal Container Service（http://vmware.com/go/vmware-pivotal），又称VMware PKS。


VMware PKS 是一款定制化产品，旨在推动 Kubernetes 于企业及服务供应商环境中支持生产环境。其特点包括：


  • 一套具备全面支持且整合了 vSphere 的 Kubernetes 发布版本

  • 使用 BOSH 进行编排，部署简单，集成有生命周期管理和运营机制

  • 与NSX进行深度集成，在容器网络和安全方面表现良好

  • 与Google Container Engine（GCE）保持兼容，并通过内置的Open Source Broker（OSB）与Google Compute Platform 进行集成

  • 诸多生产级特性，如高可用性、安全性、身份与访问控制、监控、基础设施与应用层日志等



为了实现简易部署、伸缩和自我修复能力，VMware PKS 以 BOSH（https://bosh.io/）为基础进行构建；为了取得最佳的网络和安全性能，其采用了NSX-T（https://www.vmware.com/support/pubs/nsxt_pubs.html）；同时与vRealize Suite及Wavefront等现有 VMware 工具链进行了无缝整合。


VMware PKS 是开源项目 Kubo（Kuberenetes on Bosh）的商业版本。Kubo 由 Pivotal 和 Google 在2017年2月推出，用于满足客户本地部署 Kubernetes 的需求，并随后在同年6月被捐赠给Cloud Foundry基金会。其结合了 Kubernetes 的容器调度和编排能力，以及 BOSH 的集群管理、发布工程（release engineering）和自动化能力。


BOSH 为一款用于配置及管理大规模分布式系统的开源软件。它属于一款智能化集群管理工具，集成有运行状态管理与日志功能，同时提供各种专家级选项——这一切都使得 PKS 能够运行良好。BOSH 已经在 Pivotal Cloud Foundry 当中效力多年，帮助众多管理者构建起一致化、自我修复且具备零宕机更新能力的环境。作为一款至关重要的组件，其通过定时且及时更新 Kubernetes 主线发布版本，使得 VMware PKS 与 GKE 始终保持兼容。


WMware NSX 的关注点在于应对不断推出的各类应用框架和架构。其访问点与技术堆栈具有异构性特质。除了 vSphere 的 hypervisor，这些环境中还可能包含其它 hypervisor、容器、裸机和公有云。NSX 在设计中亦考虑到开发部门的管理、运营和使用场景——而非仅限于IT（部门）。


VMware PKS 还将包含一个共同开发和维护的 Open Service Broker API，它会不断保持与GKE间的兼容性。这使得PKS 用户能够在应用中利用 GCP 的一部分创性的服务——如 BigQuery、Spanner 和 Machine Learning，同时确保应用可以快速、简单地在 PKS 和 GKE 之间进行移植。


在管理和运营方面，VMware PKS 将会与整个VMware vRealize产品线无缝集成，包括vRealize Automation、vRealize Operations 和 vRealize Log Insight。vRealize Suite是一套企业级云管理平台，可提供业内最为完整的异构与混合云环境管理解决方案。


VMware PKS 同时亦将与 Wavefront及vRealize Network Insight（vRNI）整合，旨在帮助企业获得跨虚拟与物理网络的可见性，从而实现对微型区隔（ micro-segmentation）进行规划和部署的能力。对于当今每秒百万级实时数据点的应用场景，Wavefront 提供的运营层面可见性也将在优化方面发挥重要作用。


另外，VMware PKS 还将被纳入 VMware Cloud Provider 计划，同时可通过集成VMware Cloud Director 被交付至其它服务供应合作商。


PKS 将在2017年第季度发布，Pivotal 与 VMware将会通过各自的渠道以及VMware Cloud Provider 伙伴计划进行销售并提供技术支持。VMware PKS 同时也会由戴尔-EMC 通过 VxRail Appliances 和 VxRack Systems进入市场，并由戴尔方面提供了一套认证型超融合基础设施与数据保护实现基础。
