# 精灵云Ghostcloud获2000万A轮融资，将全面拓展国内容器云服务市场

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247542942&idx=2&sn=ef1e53d743d1275310efb3d439c46abf&chksm=c03b628df74ceb9bfe0c504204fa85f0eac1fe14fe133f192d0dcd8fea2373c29d2ff30b374c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247542942&idx=2&sn=ef1e53d743d1275310efb3d439c46abf&chksm=c03b628df74ceb9bfe0c504204fa85f0eac1fe14fe133f192d0dcd8fea2373c29d2ff30b374c&scene=27#wechat_redirect)

**8月28日，企业级容器云PaaS服务商Ghostcloud精灵云正式对外宣布获中美创投领投2000万元A轮融资。**

  

本轮融资的完成，进一步证明了精灵云的技术、产品、服务能力被容器和资本市场的高度认可，同时也进一步加强了精灵云作为西南地区最大容器云服务商的地位。新一轮的资本的注入不仅能帮助精灵云在技术和产品方面的进一步提升，也将加快精灵云向全国容器云服务市场的拓展速度。

  

Ghostcloud创始人晏东表示，本轮融资将用于三个方面的建设：1、增强研发和投入，扩大核心竞争优势；2、提升开源社区影响力；3、强化市场推广。

  

![](../Images/73dee3ab7c388263e808e7350bbf80cf.png)

  

精灵云的核心团队来自Veritas, EMC，微软和华为，平均拥有10年以上企业级和云计算行业经验，自2015年成立至今，一直致力于Docker容器领域的核心研发，公司80%以上为研发人员，在容器调度引擎这一最核心技术领域，成功研发出国内领先的自主调度引擎——Newben，旨在成为“中国的Kubernetes”。精灵云也于7月推出兼容Kubernetes的EcOS-Kubernetes (Enterprise Container OS for Kubernetes)，成为国内唯一一家同时支持自主调度引擎和开源调度引擎的容器云平台。

  

Docker作为云计算2.0的触发器，自2013年开源至今，一直是硅谷最火的云计算方向，几乎所有的云计算厂商都在这个生态圈。作为国内首批从事容器虚拟化研发的企业，精灵云一直紧跟国际趋势，专注于容器私有云落地。经过近两年的发展，Ghostcloud目前已成为西南地区最大的基于Docker的服务商，旗下企业级容器云平台EcOS (Enterprise Conatainer OS) 已在金融、互联网、电信、大型制造业、IDC等行业领域落地实施，累计获得包括长虹、天府软件园在内的超1000家企业使用，并同GDS等多家企业建立战略合作关系。

  

精灵云作为成都市高新区软件园重点扶持企业，坐落于国家级产业园区——成都天府软件园。成立两年间斩获多项殊荣，其所参加的创业大赛都是成都赛区的冠军，包括阿里巴巴诸神大赛和“菁蓉杯”创业大赛等。目前是成都市云计算联盟理事会成员和四川省软件协会会员单位， 并强势入围了素有云计算界“奥斯卡”之称的2017云鼎奖“最具潜力企业”和“全球最佳实践”两项大奖。

  

本次融资完成后，精灵云将一如既往专注核心技术研发，将在北京和广州成立研发中心，加大自主调度引擎——Newben的研发投入。同时，积极参与Kubernetes社区，开源和闭源两个方向齐头并进，为客户在Docker、微服务、DevOps等方面提供多元化服务。
