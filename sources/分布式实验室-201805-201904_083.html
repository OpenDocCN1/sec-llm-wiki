职位：高级容器平台工程师

职责：

  1. 基于Docker开发应用编排和调度平台；

  2. 负责构建、持续改进PaaS云平台，实现自动化运维，提供自动化和弹性的运行时环境；

  3. 参与公司产品容器化，提升持续集成、持续交付的效率；

  4. 独立自主的调研和应用容器编排系统。


要求：

  1. 本科及以上学历，计算机等相关专业，3年以上工作经历；

  2. 熟悉 Linux 内核，对Docker容器技术相关的操作系统基础设施（文件系统、网络、CGroups等）有深入的理解，并能够深入源码级别排查问题或进行改进；

  3. 熟悉当前热门的云开源项目，至少熟悉其中之一：Docker Swarm、Kubernetes、Mesos等。


职位：Linux操作系统专家

职责：

  1. 负责基础设施（机房、服务器、Linux操作系统）的交付与运维；

  2. 负责保障系统基础服务的稳定运行；

  3. 负责自动化运维工具开发；

  4. 负责系统部的日常运维工作，对生产环境的服务器进行部署及优化，编写相关的技术文档。


要求：

  1. 5年以上互联网企业系统运维工作经验，熟悉主流X86服务器硬件；

  2. 有超过万台以上服务系统管理经验优先；

  3. 熟悉Linux系统，了解Systemd、Nmcli、FirewallD等新一代操作系统组件。

  4. 了解互联网企业主流和常用的开源系统（如LVS、Redis、Nginx等）的架构、配置、优化，并有丰富的方案策划、部署、实施和应用经验，有二次开发经验者优先；

  5. 精通Python、Shell、Perl、Ruby等至少一种脚本语言，能熟练使用来完成日常系统运维等工作，有自动化运维工具开发经验；

  6. 精通Puppet、Cfengine、Saltstack等至少一种自动化管理工具；

  7. 热爱运维工作，能承担压力，具备较强的交流、沟通和表达能力，乐于分享，具备很强的逻辑判断、问题分析和解决能力。


职位：存储平台高级工程师/架构师

职责：

  1. 负责OPPO自研EB级对象存储系统的技术选型、规划、架构设计及研发工作，提供稳定可靠的存储服务；

  2. 负责组建完整的存储平台团队。


要求：

  1. 3年以上百PB级存储集群研发、运营经验；有丰富的大规模分布式文件存储系统架构设计、故障解决等经验；

  2. 对存储系统，文件系统等有深入理解，有分布式文件系统或分布式对象存储的使用和开发的经验（如Ceph、自研分布式存储系统 等）；

  3. 充分了解业内实践和趋势，有较好的前瞻性，为项目决策提供有力支持；

  4. 有团队管理经验及较好的业界知名度，能较快的建立起能力完备的存储团队。


工作地点：深圳
