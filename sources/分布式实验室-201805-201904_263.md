# Docker公司筹得9200万美元新资金，将用于增加其销售和营销人员规模

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247543364&idx=1&sn=aee2ebc4c4bc9fdcef4b3a40dff26dea&chksm=c03b6057f74ce941bb1bed033dd6aaf1c81db9d17e4929a725ab21a523d43b5e262faec88aef&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247543364&idx=1&sn=aee2ebc4c4bc9fdcef4b3a40dff26dea&chksm=c03b6057f74ce941bb1bed033dd6aaf1c81db9d17e4929a725ab21a523d43b5e262faec88aef&scene=27#wechat_redirect)

![](../Images/48b11d797b382af09371fcb66d314c6f.png)

根据美国证券交易委员会提交的一份文件显示，Docker公司在构建当前现代化容器计算环境方面异军突起，并已经在新一轮总额达1.92亿美元的融资计划中成功筹得9200万美元。  
这轮新的融资活动代表着一大重要信号，即虽然Docker可能已经无法与谷歌Kubernetes相抗衡，但这家位于旧金山的企业希望凭借着可观的采用广泛度，在现代混合应用程序开发与信息技术程序操作模式层面成为重要的业界支柱。  
只有理解容器技术在现代编程当中的重要意义，我们才能真正找到上述决定的原因。简而言之，容器技术类似于不需要操作系统即可运作的虚拟应用程序执行环境。以往，这类功能需要利用虚拟机来实现——即将软件与操作系统组合而成的解决方案。  
相比之下，容器方案更具实际效率。由于其中仅包含有应用程序以及运行所必需的库、框架等，因此大家可以将其全部纳入单一主机操作系统当中。服务器上的唯一操作系统即为主机操作系统，而容器能够与之直接通信。这意识着容器体积更小，且运行资源需求更低。企业客户之所以快速转向容器阵营，是因为他们希望进一步改善软件的开发与管理方式，从而获得更快的速度表现。然而，单凭企业自身无法实现这一目标，他们还需要Docker这类合作伙伴的有力推动与帮助。  
有很多朋友对Docker抱有一定的误解，实际上Docker并不只是容器编排层——Kubernetes已经在这一领域占据绝对优势——而是一套用于构建及管理容器的完整工具链。  
对于任何一个开源项目，各类技术企业都能够快速采用（并适应）这些项目并了解如何熟练使用。然而，对于很多业务重心并不在技术方面的大型企业来讲，与Docker这类公司合作以帮助其管理由这些工具开发出的项目则成为更理想的选择。  
而Docker也确实经历了这种作为技术初创企业的自然演变，其为大型企业客户提供的无偿服务很快带来了商业回报。企业利用率提升，Docker开始盈利，炒作之声也转化为脚踏实地。很明显，一旦该公司能够向大型企业客户出售产品，双方的合作关系就会得到稳定保证。  
在Docker公司创始人兼前任首席执行官Solomon Hykes在今年早些时候决定离开时，他做出了如下说明：……在我们的首席执行官、传奇人物Steve Singh的领导下，Docker公司已经悄悄转变为实现爆炸性收入增长的企业级业务供应商以及拥有数百万参与者的开发者社区。我们的战略非常简单：世界上每一家大型企业都有意将其应用程序与基础设施集中迁移至云端。他们当然需要一款可靠且安全的解决方案，无需昂贵的代码或流程变更，也无需将自身锁定至单一操作系统或云。如今，满足这些要求的唯一解决方案，就是Docker企业版。这使得Docker成为巨大的发展机遇中心。为了利用这一机遇，我们需要一位在全球最大规模企业中拥有数十年软件交付与支持经验的CTO在Steve身边出谋划策。因此，我现在迎来了新的角色定位：帮助公司找到理想的CTO人选，偶尔提供建议，并在后续的企业发展当中退居幕后。作为一名股东，我非常乐于接受这样的角色转换。利用这笔资金，Docker公司很可能会增加其销售与营销人员规模，并为可能于2019年开始的首轮公开募股（简称IPO）提供良好的营收数字。此外，该公司已经设置了一系列独立董事席位（这同样明确表明该公司有意进入股市）。  
Docker公司已经成为市值超过10亿美元的“独角兽”企业。根据报道，Docker上一轮资金筹集活动发生于2017年年底。当时《华尔街日报》发现了美国证券交易委员会收到的一份文件，其中表明该公司已经在总目标为7500万美元的融资计划中筹得6000万美元。当时的投资参与方包括AME Cloud Ventures、Benchmark、Coatue Management、高盛投资以及Greylock Partners。到这个时间点上，Docker公司的估值已经高达13亿美元。
