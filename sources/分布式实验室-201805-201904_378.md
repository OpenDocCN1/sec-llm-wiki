# 谷歌发布Google Kubernetes Engine On-Prem

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247543281&idx=1&sn=3b9703ca3433b47e08514a57fdd89bce&chksm=c03b63e2f74ceaf4c26af6b0e6fcffc64222b52a68904980df56ad9d480a86a5dd8c2e9a6775&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247543281&idx=1&sn=3b9703ca3433b47e08514a57fdd89bce&chksm=c03b63e2f74ceaf4c26af6b0e6fcffc64222b52a68904980df56ad9d480a86a5dd8c2e9a6775&scene=27#wechat_redirect)

![](../Images/e925254e7dccd27cc97d4ba038cf305d.png)Google Cloud正在构建自己的Kubernetes Engine（简称GKE）服务版本，以供用户在自有数据中心内运行。GKE On-Prem，旨在为企业客户提供一种立足内部与公有云端的应用程序基础设施统一管理方式，目前尚处于alpha测试阶段。该公司于本周二在旧金山召开的年度Next大会上公布了这一消息。Google Cloud正在准备推出一套专门的Google Kubernetes Engine服务版本（简称GKE），可供客户运行于自己的数据中心之内。  
这一简称为GKE On-Prem的服务实例在使用感受上类似于Google Cloud用户仪表板上的一个可用区。用户能够利用与其它云环境相同的工具对其进行监控与管理。  
谷歌公司技术基础设施高级副总裁Urs Hölzle同另外两名同事于本周二在旧金山召开的谷歌年度云盛会Next大会上公布了这款产品。在现场演示当中，他们通过一套仪表板展示了GKE On-Prem如何运行在安装有VMware vSphere的硬件机架之上，且该机架可作为与谷歌数据中心内各云可用区域并列的新可用区。  
此次公告旨在推进谷歌公司的混合云战略。目前大多数追求企业IT资金的技术供应商都在努力构建相关方案，确保已经拥有计算基础设施的企业客户能够将其与公有云实现轻松结合。目前尚处于alpha测试阶段的GKE On-Prem承诺利用高人气应用程序容器编排平台Kubernetes为谷歌云客户带来理想的解决方案。  
Urs Hölzle指出，“我们正努力结束内部部署与云端部署二选其一的错误现状。着眼于长远未来，立足所有环境建立一致性混合平台才是众多企业的自然选择。”  
谷歌公司在企业云市场上的最大竞争对手已经走上了自己的混合云之路。微软开发出Azure Stack，这是一套基础设施软件堆栈，旨在为用户提供与Azure云服务相同的内部使用体验。  
Amazon Web Services则与VMware公司合作将后者的虚拟化与云基础设施软件套件集成在AWS数据中心内的裸机基础设施之上。这一合作关系的目标，在于帮助VMware客户（也就是大多数企业IT部门）轻松将现有本地VMware环境扩展至AWS当中。  
谷歌公司在下一代VMware之上演示这项云端功能应该不是巧合。由于数据中心软件巨头的产品正运行在全球众多服务器集群当中，因此展示GKE On-Prem在VMware上的部署效果，预示着Google Cloud希望全面进军这一潜在市场。  
VMware “代表着最大的发展机遇”，Gartner公司研究副总裁Ed Anderson在接受采访时表示。“因为VMware在企业环境当中拥有着极为庞大的安装基础与用户群体。”  
在活动揭幕主题演讲的公布与演示环节之后，思科公司副总裁也走上了舞台，谈论两家公司之间的联合混合云产品——这可能同样不是巧合。  
谷歌公司与思科方面于去年建立起合作关系，这是由于思科在网络技术领域拥有着类似于VMware在企业数据中心领域的整体领先地位。思科网络与安全业务执行副总裁David Goeckler在本周二的Next大会上发表讲话，指出这一合作关系的重点解决方案将于今年8月全面投放市场。  
Goeckler表示，Cisco Hybrid Cloud for Google Cloud将成为市场上的首个GKE认证混合云平台。  
思科公司企业产品管理高级主管Jeremy Oakey指出，这套思科解决方案拥有谷歌希望通过GKE On-Prem实现的各类功能。“这也是我们一直以为的努力方向。”  
利用Kubernetes作为云端或内部环境中的通用应用程序部署方法，企业IT管理者们将得以轻松管理其下的混合基础设施，同时设置策略并强制执行合规性保障举措。此外，Oakey表示思科的解决方案还提供对VMware等现有数据中心环境的可见性。  
Gartner公司的Anderson认为，GKE On-Prem的公布并不会对谷歌与思科之间的合作关系造成阻碍。他指出，没有什么能够阻止谷歌在未来的双边合作关系当中发挥积极作用。  
总体而言，混合云已经成为目前各大技术巨头的关注重点。
