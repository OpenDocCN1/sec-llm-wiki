# 曾经价值超10亿美元的Docker公司，如今却向员工表示需要进一步融资以应对“艰难挑战”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247543739&idx=1&sn=17211d8b0369294e13076e1c07f9608f&chksm=c03b61a8f74ce8be59ff16824deb32a01d10c97087b36f9ecd351b7338169e719aef73a4ac93&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247543739&idx=1&sn=17211d8b0369294e13076e1c07f9608f&chksm=c03b61a8f74ce8be59ff16824deb32a01d10c97087b36f9ecd351b7338169e719aef73a4ac93&scene=27#wechat_redirect)

![](../Images/66815e74fa93afe44edb7a27f24d9d2d.png)

  

要点汇总：  

*   Docker公司CEO Rob Bearde本周向员工们发出一封邮件，感谢大家在公司财务面对巨大压力下仍然坚守岗位。
    
*   Bearden在Hortonworks与Cloudera合并之后，于今年早些时候出任Docker第四任CEO职务。
    
*   与Elastic以及MongoDB等开源厂商不同，Docker公司一直在努力寻找可行的商业模式。
    

  

作为曾经的商业软件佼佼者、曾是于2015年获得高达10亿美元估值的Docker，如今却在挣扎着寻找下一笔资金以支撑自身运营。  
今年5月出任公司CEO的Rob Bearden在本周向全体员工发出一封邮件，感谢大家“在迷茫与艰难的过去几周当中，仍然不懈努力。”在这份邮件中，他也明确向员工表示，公司目前需要更多资金的注入。  
曾任Hortonworks公司CEO，并在与老对头Cloudera合并后出任Docker掌门人的Bearden写道，“正如在上一次All Hands大会上所提到，我们一直在努力与投资者合作，以确保获得更多融资，用以继续推动我们的发展战略。这里，我要分享一下公司的现状。我们目前正在与两家投资者进行积极谈判，并着手确定最后期限。我们应该能够在接下来的几周之内，向大家公布更完整的融资计划。”  
Docker公司的一位发言人拒绝对此发表评论。  
尽管Docker方面有望再拿下一笔数额可观的资金，但其前景仍然比较晦暗。事实上，在经历了本世纪初繁荣时期的旺盛人气后，迅速陷入不利境地的初创企业其实并不少见。在Bearden于今年5月接手CEO职务时，他替代的是SAP前任高管Steve Singh——这两位也成为2017年以来先后上任的第三与第四届CEO。Docker公司创始人Solomon Hykes于去年决定离职，而战略发展执行副总裁Mariana Tessel也早在2017年就转投Intuit怀抱。  
Docker公司最大的贡献。在于普及了容器这项重要的源代码打包技术，允许开发人员更轻松地将应用程序从便携式计算机移动至服务器乃至云端，且无需对代码做出任何更改。目前，管理员们正在服务器上将容器技术作为虚拟机的替代性方案，这也使得Docker成为威胁VMware数据中心生存空间的一股重要力量。  
尽管得到了广泛应用，但Docker核心软件实际上属于开源项目，因此任何人都可以免费下载并对其进行修改。该公司虽然一直在销售产品以帮助企业管理容器部署事务，但由此带来的收入并不像其他高价值订阅软件厂商那样保持高速增长。

  

开源之殇

![](../Images/1708fdcac61cedac5979fc1b01e5ac23.png)

  

亚马逊与微软等云基础设施供应商已经开始广泛提供能够在其服务器上运行容器系统的服务。谷歌也在2014年发布了用于管理容器集群的Kubernetes开源软件，并与IBM、红帽以及VMware的产品实现了紧密集成。  
与其他现代开源模式相比，Docker的商业化之路走得同样不算成功。近年来，Elastic与MongoDB先后上市，其市值均超过50亿美元。这要归功于双方成功构建起能够充分满足客户需求的专有工具，以帮助他们全面发挥软件的固有功能优势。MongoDB去年的收入超过2.6亿美元，Elastic的收入更是超过2.7亿美元。  
Docker公司迄今已经筹集超过2亿美元资金，其中包括四年之前由高盛参与的9500万融资。除此之外，Benchmark、红杉资本以及Greylock Partners也提供了支持，并帮助Docker在2017年获得了高达13亿美元的估值。  
根据LinkedIn网站上的数据，目前位于旧金山的Docker公司共拥有约500名员工。  
以下是Bearden写给员工的完整邮件内容：各位：  

正如在上一次All Hands大会上所提到，我们一直在努力与投资者合作，以确保获得更多融资，用以继续推动我们的发展战略。这里，我要分享一下公司的现状。我们目前正在与两家投资者进行积极谈判，并着手确定最后期限。我们应该能够在接下来的几周之内，向大家公布更完整的融资计划。

  

我意识到这种不确定性带来了巨大的挑战，也要感谢大家在迷茫与艰难的过去几周当中，仍然不懈努力。产品与工程团队一直致力于开发“Barracuda”版本，工作进度也非常理想；正是每一个人的付出，成就了我们的“当下”。

  

再次感谢每个人的专注、奉献与支持，感谢大家在推动业务继续发展方面付出的努力。

  

请大家仅将本邮件中的机密信息作为内部使用。在全部流程完成之后，我们将发表正式的公开声明。

  

Rob
