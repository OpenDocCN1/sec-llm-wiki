# IBM 340亿美元红帽收购案完成：定义混合云的开放未来

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247543651&idx=1&sn=632884b818e69fb0a9f79612ae53e07b&chksm=c03b6170f74ce8664645117e8fac1de589f048c65fc9e0ed148e37a19ecb4e1274d370d77467&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247543651&idx=1&sn=632884b818e69fb0a9f79612ae53e07b&chksm=c03b6170f74ce8664645117e8fac1de589f048c65fc9e0ed148e37a19ecb4e1274d370d77467&scene=27#wechat_redirect)

![](../Images/1396cac51e46f3ccf4a6543b0c0096f6.png)

通过与IBM的合作，红帽有机会为更广泛的组织机构提供更多开源创新成果，并使我们得以提供真正灵活可选的混合云解决方案。  
——红帽公司总裁兼CEO，Jim Whitehurst

*   此次收购意味着IBM正式跻身为领先混合云提供商，加速IBM的高价值业务模式，并将红帽的开源创新成果扩展至更为广泛的客户群体当中。
    
*   IBM将保留红帽的独立运营与中立定位；红帽则将加强现有合作关系，继续为客户提供自由、可选及灵活的解决方案。
    
*   红帽将继续保持对开源精神的坚定承诺，决不动摇。
    
*   IBM与红帽双方将共同推出下一代混合多云平台。
    

  
IBM与红帽今天宣布，双方已经完成了以每股190.00美元现金对红帽全部已发行股票及普通股的收购交易，全部总股本价值约为340亿美元。  
此次收购将重新定义云市场的业务态势。红帽的开放混合云技术，加上IBM无与伦比的创新能力以及行业专业知识的规模与深度，将共同在覆盖超过175个国家的领先销售渠道当中实现结合。而通过共同推出下一代混合多云平台，IBM与红帽将共同加速创新步伐。该平台基于Linux与Kubernetes等开源技术，允许企业在本地以及私有/多公有云之上对各类数据及应用程序进行安全部署、运行与管理。  
IBM公司董事长、总裁兼CEO罗睿兰表示，“企业客户目前正在启动数字化转型的下一阶段，包括推动基础设施现代化，并将私有云以及来自多家供应商的多种云环境相结合，并跨越这些环境进行任务关键工作负载的往来迁移。因此，他们需要开放且灵活的技术手段管理这些混合多云环境，也需要由可依赖的合作伙伴帮助其完成系统的管理与保护。IBM与红帽非常适合此类业务需求。作为领先的混合云提供商，我们将为客户提供能够在未来几十年持续支撑其业务体系的技术基础。”  
红帽总裁兼CEO Jim Whitehurst也指出，“通过与客户的交流，他们对当前面临的挑战拥有非常明确的认知：他们需要加快发展脚步并通过技术实现业务差异化。他们希望建立更强大的协作文化，需要借助解决方案的力量更灵活地在任意位置构建并部署任何应用程序或者工作负载。我们认为，开源已经成为客观层面上的技术标准，因为开源成果足以支持此类解决方案。通过与IBM的合作，红帽公司有机会为更广泛的组织机构提供更多开源创新成果，并使我们得以提供真正灵活可选的混合云解决方案。”  
红帽公司将继续由Jim Whitehurst及其现任管理团队负责领导。Whitehurst也将加入IBM的高管团队，并向罗睿兰直接汇报工作。IBM将在北卡罗来纳州罗利市保留红帽公司的总部设施、品牌以及实践方针。红帽将作为IBM内部的独立单位继续运营，并作为IBM云与认知软件业务部门的一部分进行报告。  
两家公司目前都已经建立起领先的企业级云业务，并通过帮助客户将传统业务模式转化为云模式获得持续且强劲的收入增长。  
IBM公司云收入在整体收入中的比重已经由2013年的4%增长至目前的25%。如此强劲的增长源自其全面的即服务类产品与软件、服务以及硬件。完备的解决方案使得IBM能够为客户跨越公有、私有以及本地环境的云解决方案提供建议、构建、迁移乃至管理服务。截至今年第一季度，IBM公司在此前12个月中的云计算收入已经增长至超过190亿美元。而此次红帽收购交易，预计将在未来五年内为IBM公司带来约2%的年均复合收入增长率。  
红帽公司2019财年收入为34亿美元，较上财年增长15%。2020财年第一季度收入（2019年6月报告）为9.34亿美元，同比同样增长15%。本季度，订阅服务收入同比增长15%，其中与应用程序开发相关的产品、以及其它新兴技术产品带来的收入总和同比增长24%；服务收入亦增长达17%。

  

混合云带来的新机遇

![](../Images/1708fdcac61cedac5979fc1b01e5ac23.png)

  

随着企业逐步迈入云转型旅程的新阶段，数字化转移也迎来了历史性拐点。如今，约有20%的企业开始转向云时代。在云计算之旅的第一阶段当中，企业在降低成本、提高生产力以及强化面向客户的创新计划方面取得了一系列长足的进步。面对未来，第二阶段中的重点则在于如何将任务关键型工作负载迁移至云端，并对从供应链到核心银行系统的全部业务内容加以整体性优化。  
为了在下一阶段当中取得成功，企业需要以简单、统一且集成化的方式管理整个IT基础设施——包括内部环境、外部环境以及由私有云与公有云共同构成的多云环境。企业正在寻求一种只需构建一次，即可在任意设施当中快速灵活部署的通用型环境。IBM公司的产品一直在据此发展，旨在反映客户的最新需求并推动更为可观的业绩增长。收购红帽，则将进一步巩固IBM公司在企业混合云领域的领导者地位。  
IDC公司高级副总裁兼首席分析师Frank Gens表示，“随着企业努力加快创新步伐以保持市场竞争力，他们正在寻求开源与分布式云环境，从而实现以往无法想象的新一轮数字创新。在未来五年内，IDC预计企业将在云计算以及创新领域投入大量资金。其中大部分投资都将被用于混合及多云环境，以确保企业自身能够在不同环境中实现应用程序、数据与工作负载的顺畅迁移。相信这方面投资还将不断增长。通过收购红帽，加上IBM方面对红帽运营独立性做出的承诺，相信IBM能够在这一新兴的混合、多云世界中凭借着开源的强大力量脱颖而出。”  
IBM与红帽联手帮助企业释放混合云真正价值的努力，已经引起了客户的广泛共鸣，并使得更多客户得以迈向数字化转型的下一阶段。  
达美航空公司CEO Ed Bastian表示，“在不断改变航空旅行体验的过程中，达美航空一直在不断探索当前以及更多新兴技术。多年来，我们一直与IBM及红帽合作推动这一目标。在双方共同组成下一代IT企业之时，相信他们也将成为我们数字化转型工作当中的重要组成部分。”  
摩根士丹利公司企业技术与服务部总经理兼首席信息官Michael Poser指出，“作为红帽与IBM的长期合作伙伴，我们期待着这两家公司能够携手合作。我们亲身体会到了云技术在实现业务价值当中起到的重要作用与巨大影响力。”

  

IBM加强对开源以及红帽中立性的保障承诺

![](../Images/1708fdcac61cedac5979fc1b01e5ac23.png)

  

IBM与红帽双方都拥有深厚的开源贡献与参与经验。两家公司已经拥有20多年的合作历史，并将开源作为现代IT解决方案的默认选项。其中包括充分尊重开放治理的重要意义，并脖持续贡献帮助开源项目与技术社区实现蓬勃发展。  
在吸纳红帽之后，IBM将获得IT行业中最重要的软件厂商之一，而红帽的开创性商业模式也将进一步推动开源项目（包括Linux、Kubernetes、Ansible、Java以及Ceph等技术成果）被主流企业所接纳。如今，Linux已经成为最常用的开发平台。2019年，预计红帽企业Linux带来全球企业客户的运营收入贡献将超过10万亿美元。到2023年，预计将有64万名员工从事与红帽技术成果相关的工作。  
IBM公司一直致力于帮助各行各业中的企业扩展并加速开源与混合云方案，同时将继续保持红帽所坚守的开源独立性与中立性传统。其中包括红帽所建立的开源社区领导、贡献与发展模式；产品组合、服务与市场战略；强大的开发者及合作伙伴生态系统以及独特的文化传统。  
红帽则一直将开源视为自身使命与坚定不移的承诺，这一点在并入IBM后仍将得以保持。红帽将继续提供开源与混合IT环境中所固有的选择性与灵活性。红帽还将继续建立并扩展自身合作伙伴关系，包括与各大主要云服务提供商之间的合作关系，例如Amazon Web Services、微软Azure、Google Cloud以及阿里巴巴等。  
IBM与红帽双方还将共享在社会责任层面的坚定承诺，努力运用技术与专业知识帮助解决世界上最重要的一系列社会性挑战与发展目标。两家公司将共同通过新的联合性举措满足教育与技能、公民以及社会需求，并大力培养更多科学、技术、工程与数学（STEM）人才以巩固这一长期承诺。
