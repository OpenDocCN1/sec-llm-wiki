本文从最基础的 VirtualBox 虚机主机开始，逐步介绍如何在自己的电脑上虚拟出多台 CentOS 7 操作系统，并使用 kubeadm 部署多 Master、多 Node 节点的 Kubernetes HA 集群。分享在整个部署过程中的重要步骤和可能遇到的问题，帮助初学的朋友更顺利的部署 Kubernetes，从而方便进行后续的 Kubernetes 各项学习与测试。  
Kubernetes 常见的高可用集群部署大致分为 3 种：  

*   手工部署以“进程”方式运行
    
*   用 kubeadm 部署以“容器”方式运行
    
*   手工部署为以“容器”方式运行
    

  

以“容器”方式运行有很多的优点，也是推荐的方式。  
如果对以“进程”方式运行感兴趣，可以访问以下 URL 了解 etcd cluster 的部署方式：https://github.com/zhangjiongdev/k8s/blob/master/etcdsetupfor\_centos7.md。  
安装部署的顺序、设置和后面介绍的顺序需保持一致，在实际的测试中不要轻易打乱文档步骤的顺序和修改设置，以避免部署问题。

第三部分：Keepalived + HAProxy 安装配置

![](../Images/1708fdcac61cedac5979fc1b01e5ac23.png)

  

这是 Kubernetes HA cluster的最后一步准备工作。  
三台（Master）控制平面安装 Keepalived + HAProxy。  
设置环境 IP：  

```
1.  `yum install -y net-tools`
    
2.  
    
3.  `vip=30.0.2.10`
    
4.  `master1=30.0.2.11`
    
5.  `master2=30.0.2.12`
    
6.  `master3=30.0.2.13`
    
7.  `node1=30.0.2.14`
    
8.  `` netswitch=`ifconfig | grep 'UP,BROADCAST,RUNNING,MULTICAST' | awk -F: '{print $1}'` ``
    
```

  
设置 hosts：  

```
1.  `cat >>/etc/hosts<<EOF`
    
2.  `${master1} master1`
    
3.  `${master2} master2`
    
4.  `${master3} master3`
    
5.  `${node1} node1`
    
6.  `EOF`
    
```

  
配置 /etc/sysconfig/modules/ipvs.modules：  

```
1.  `cat > /etc/sysconfig/modules/ipvs.modules <<EOF`
    
2.  `modprobe -- ip_vs`
    
3.  `modprobe -- ip_vs_rr`
    
4.  `modprobe -- ip_vs_wrr`
    
5.  `modprobe -- ip_vs_sh`
    
6.  `modprobe -- nf_conntrack_ipv4`
    
7.  `EOF`
    
8.  
    
9.  `chmod 755 /etc/sysconfig/modules/ipvs.modules && bash /etc/sysconfig/modules/ipvs.modules && lsmod | grep -e ip_vs -e nf_conntrack_ipv4`
    
```

  
安装 Keepalived + HAProxy：  

```
1.  `yum install -y keepalived haproxy ipvsadm ipset`
    
```

  
在 Master1 配置启动 Keepalived+HAProxy。  
配置 Keepalived：  

```
1.  `mv /etc/keepalived/keepalived.conf /etc/keepalived/keepalived.conf.bak`
    
2.  
    
3.  `` nodename=`/bin/hostname` ``
    
4.  `cat >/etc/keepalived/keepalived.conf<<END4`
    
5.  `! Configuration File for keepalived`
    
6.  `global_defs {`
    
7.  `   router_id ${nodename}`
    
8.  `}`
    
9.  `vrrp_instance VI_1 {`
    
10.  `    state MASTER`
     
11.  `    interface ${netswitch}`
     
12.  `    virtual_router_id 88`
     
13.  `    advert_int 1`
     
14.  `    priority 100`
     
15.  `    authentication {`
     
16.  `        auth_type PASS`
     
17.  `        auth_pass 1111`
     
18.  `    }`
     
19.  `    virtual_ipaddress {`
     
20.  `      ${vip}/24`
     
21.  `    }`
     
22.  `}`
     
23.  `END4`
     
```

  
配置 HAProxy：  

```
1.  `cat >/etc/haproxy/haproxy.cfg<<END1`
    
2.  `global`
    
3.  `        chroot  /var/lib/haproxy`
    
4.  `        daemon`
    
5.  `        group haproxy`
    
6.  `        user haproxy`
    
7.  `        log 127.0.0.1:514 local0 warning`
    
8.  `        pidfile /var/lib/haproxy.pid`
    
9.  `        maxconn 20000`
    
10.  `        spread-checks 3`
     
11.  `        nbproc 8`
     
12.  
     
13.  `defaults`
     
14.  `        log     global`
     
15.  `        mode    tcp`
     
16.  `        retries 3`
     
17.  `        option redispatch`
     
18.  
     
19.  `listen https-apiserver`
     
20.  `        bind ${vip}:8443`
     
21.  `        mode tcp`
     
22.  `        balance roundrobin`
     
23.  `        timeout server 15s`
     
24.  `        timeout connect 15s`
     
25.  
     
26.  `        server apiserver01 ${master1}:6443 check port 6443 inter 5000 fall 5`
     
27.  `        server apiserver02 ${master2}:6443 check port 6443 inter 5000 fall 5`
     
28.  `        server apiserver03 ${master3}:6443 check port 6443 inter 5000 fall 5`
     
29.  `END1`
     
```

  
启动 Keepalived 和 HAProxy：  

```
1.  `systemctl enable keepalived && systemctl start keepalived `
    
2.  `systemctl enable haproxy && systemctl start haproxy `
    
```

  
检查：  

```
1.  `ping 30.0.2.10`
    
```

```

```

```

  
配置 /etc/sysctl.d/k8s.conf：  

```
1.  `cat <<EOF > /etc/sysctl.d/k8s.conf`

```

```

21.  `---`
     
22.  `apiVersion: kubeadm.k8s.io/v1beta1`

24.  `apiServer:`
     
25.  `  timeoutForControlPlane: 4m0s`
     
26.  `certificatesDir: /etc/kubernetes/pki`
     
27.  `clusterName: kubernetes`
     
28.  `controlPlaneEndpoint: "${vip}:6443"`
     
29.  `dns:`
     
30.  `  type: CoreDNS`
