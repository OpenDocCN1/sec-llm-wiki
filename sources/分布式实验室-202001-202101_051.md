# 2020云原生生态大会，最值得期待的技术盛会！

随着云原生技术的迅猛发展，IT 基础设施正在发生巨大变革，许多企业都将其架构迁移至云原生平台，通过云原生技术，使得企业在公有云、私有云和混合云等云环境之中构建和运行应用变得更加容易，更能充分利用云环境的优势。

  

为了推广云原生技术理念、推进和优化云原生生态发展，一场来自** CNCF、VMware、PingCAP、网易数帆、阿里云、字节跳动、Zilliz **等十多位重磅演讲嘉宾集结的云原生领域盛会-“**2020云原生生态大会**”即将揭幕！ 

  

在大会上将听到这些云原生领军企业和组织分享各自的云原生战略与实践，剖析云原生技术带来的机遇与挑战，帮助云原生技术使用者和爱好者加深对技术的理解，同时推进云原生与企业 IT 的融合，更有来自头部用户的技术实践和创新分享。

  

**福利：**参加本次会议的观众中还有机会获赠云原生领域巨著 ——《Harbor权威指南》一书。
