自诞生之日开始，Istio项目就一直奉行着贡献者主导、开放、透明且人人可用的基本理念。本着这种精神，我们今天兴奋地宣布，Istio项目商标的所有权将正式被移交至Open Usage Commons。

Istio是一个开源项目，根据Apache 2.0许可发布。基于此项许可，大家可以复制、修改、发布、制作、使用及出售项目源代码。但在Apache 2.0许可当中，我们无法自由使用Istio名称及其徽标，这可能会令部分使用者感到不便。

作为项目创始人之一，谷歌为Istio项目商标的当前所有者。但历史所有权的变更，导致行业对Istio项目的名称以及具体使用方式产生了困惑乃至不确定性，甚至因此给社区发展带来一定障碍。为此，作为Istio开放性承诺的一部分，谷歌公司今天宣布将Istio商标移交给新的组织，即Open Usage Commons，由后者负责对商标进行中立且独立的监督。

Istio商标的中立之源


Open Usage Commons是一家新的组织，致力于以开源代码定义相统一的方式为开源项目的商标提供管理与指导。对于像Istio这样拥有强大生态系统的项目，保证任何依照许可使用软件的用户也能够同时使用其商标，无疑是一项极具意义的工作。只有统一使用商标，维护者才能不断壮大技术社区并着力强调Istio这一名号，鼓励生态系统合作在项目之上创建更多服务，并帮助开发人员创建出引用项目成果的工具与集成方案。从长远角度看，维护者、生态系统合作伙伴与开发人员对于相关投入的信心，也将与Istio商标的使用息息相关。我们认为，将Istio商标移交给Open Usage Commons正是维持这种明确性与参与信心的正确方法。

Open Usage Commons将与Istio指导委员会一道制定商标使用指南。但指南整理需要时间，大家目前可以继续按照现有指南使用Istio商标。

关于更多详细信息，请参阅openusage.org上的开源项目IP[1]与Open Usage Commons部分[2]。


关于持续开放的承诺


Open Usage Commons专注于管理项目商标，但并不涉及开源项目中例如决策投票规则等其他方面事务。与许多早期项目类似，Istio委员会最初由创始成员小组构成。但随着Istio项目的发展成熟（去年在GitHub成长速度最快的开源项目中排名第四！[3]），如今是时候将项目治理工作推向新的阶段了。

最近，我们有幸任命Aspen Mesh公司联合创始人兼首席架构师Neeraj Podder担当技术监督委员会成员，该委员会专门负责项目中的各类技术决策工作。Neeraj本人也是Istio项目的长期贡献者，目前任工作组负责人。现在的Istio技术监督委员会由来自4家公司（Tetrate、IBM、谷歌以及Aspen Mesh）的7名成员组成。

我们的社区目前正在讨论如何进一步调整负责监督市场营销与社区活动的项目指导委员会的治理模式，借此反映不断壮大的社区与生态系统现状。如果大家有关于新型治理模式的建议与意见，请参与GitHub上的相关讨论[4]。

过去12个月以来，Istio项目已经得到100多家组织的支持，目前拥有来自14家不同企业的70名维护者。这样的发展态势不仅符合项目创始者们所期望的贡献者多样性，同时也将成为我们下一阶段需要维持的重要优势。我们对Istio的未来充满期待，也诚挚邀请更多朋友参与其中。
