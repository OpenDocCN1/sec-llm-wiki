**阿里云**  
岗位描述：  

1.  负责阿里云容器服务（面向企业客户的专有云）的平台化服务能力建设，支撑阿里云大数据、中间件、数据库等产品的专有云输出，同时支撑多个垂直领域的企业业务运行；
    
2.  负责容器平台相关云原生技术的架构演进，包括但不限于安全容器、Serverless基础设施、AI等新计算技术；能在具备创新活力的上游生态（如开源技术创新、阿里经济体内部创新），把握行业需求，推动创新产品化落地。
    
3.  负责容器服务平台智能化运营系统的架构与建设，能结合容器平台之上复杂多样的业务类型，提出产品能力的评估模型与优化建议，提升平台的稳定性与高效性。
    
4.  负责阿里云企业级云产品的实战演示环境的设计与实现，打造互联网化的专有云运营平台，覆盖企业产品的商务体验、售前云化实施、售后问题复现、真实环境赋能培训等。
    

  
岗位要求：  

1.  对容器和基础设施相关领域的云原生技术充满热情，在相关的领域如Kubernetes、Serverless平台、容器网络与存储、运维平台等云原生基础设施其中某一方向有丰富的积累和突出成果（如产品落地，创新的技术实现，开源的突出贡献，领先的学术研究成果等）；
    
2.  有3年以上互联网应用运维、开发的经验，有额外企业级应用运维、开发经验者优先；
    
3.  优秀的表达能力，沟通能力，和团队协作能力；对技术和业务有前瞻性的思考；具备较强的ownership，以结果为导向，负责或强项业务领域内善于决策；
    
4.  熟悉Java、Golang其中至少一项编程语言。
    

  
工作地点：杭州、北京  
薪资：35K起（P7~P9）  
学历：本科及以上  
**腾讯云**  
岗位职责：  

1.  参与腾讯自研业务上云的超大规模容器平台和调度系统的设计和开发工作，提升应用交付效率，提供集群资源利用率。
    
2.  参与自研上云容器云平台的核心模块设计与开发，支持无状态、有状态，大数据、AI作业编排调度。
    
3.  参与超大规模调度系统、高性能可扩展的弹性伸缩系统等设计、开发、性能优化等工作。
    
4.  参与超大规模容器集群的问题定位，包括容器技术、操作系统/内核、网络、存储等相关技术栈。
    

  
岗位要求：  

1.  熟悉Linux系统、TCP/IP网络协议等计算机基础知识；
    
2.  熟悉Golang语言开发，同时熟悉Java、Python、Shell等其他一种或者多种语言，熟悉前台开发更好；
    
3.  有Kubernetes/Docker项目经验的同学优先，熟悉源代码和原理者加分；
    
4.  有Kubernetes/Docker/Istio二次开发，扩展开发者、社区经验者优先；
    
5.  有大规模在离线作业混部研发经验者优先；
    
6.  较强的沟通和协作能力、自我驱动能力，愿意投身云原生领域。
    

  
学历要求：本科及以上  
薪资：30K-60K  
工作地点：北京、上海、深圳、西安、成都  
**SmartX**  
岗位职责：  

1.  负责SmartX分布式块存储与Kubernetes集成工作，为Kubernetes提供最佳持久化存储方案；
    
2.  优化 SmartX 分布式块存储在 Kubernetes 平台的存储性能表现与用户体验；
    
3.  提供其他 SmartX 应用在 Kubernetes 运行的能力；
    
4.  撰写设计文档，并对其他同事的代码进行审查；
    
5.  与测试和产品部门密切配合，不断提升产品质量以及产品文档化程度。
    

  
任职要求：  

1.  熟悉Kubernetes的基本工作流，能够独立部署 Kubernetes 环境，对其工作原理有深入理解；
    
2.  熟悉Docker原理，至少熟悉一种除Kubernetes外的容器编排解决方案，如 Swarm， Mesos等；
    
3.  热爱编程，并有扎实的Go编程功底；
    
4.  熟悉C/C++/Python，有相关项目的研发经验。
    

  
学历要求：本科及以上  
薪资：50K-80K  
工作地点：北京、深圳
