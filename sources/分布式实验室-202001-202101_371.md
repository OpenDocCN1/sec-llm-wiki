# Google Cloud CEO表示将把Istio项目捐赠给基金会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247543953&idx=1&sn=d225d84128d54c8e8ed03e21f4fc4ebc&chksm=c03b6682f74cef946b4d0a3b42bc3ac7d91acf99e811bf549819358138d765d0aa4595c595d4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247543953&idx=1&sn=d225d84128d54c8e8ed03e21f4fc4ebc&chksm=c03b6682f74cef946b4d0a3b42bc3ac7d91acf99e811bf549819358138d765d0aa4595c595d4&scene=27#wechat_redirect)

多年之后，Google Cloud CEO Thomas Kurian终于为旗下最重要的一大开源项目找到了理想的发展方向。在采访中，他表示谷歌将在近期内把Istio捐赠给基金会。  
在周二接受Protocol的独家采访时，Kurian解释称该公司正在评估目前哪个基金会的治理政策最适合Istio。对这个谷歌旗下最知名的开源项目之一，他表示公司需要“认真考量交给哪个基金会更为合适。”  
Istio是一种“服务网格”，可帮助技术组织以微服务架构为中心构建并管理应用程序策略。为什么以微服务为中心？因为其允许开发者立足应用程序中的各项独立功能进行工作，而不再受限于庞大的单体式结构——如此一来，即使某项服务出现故障，也不致对应用程序造成全局影响。  
去年年底，谷歌方面曾暗示称不打算将Istio项目捐赠给基金会，这意味着搜索巨头将能够更紧密地控制Istio的使用方式与使用场景。不过此种反常的表现也让Istio项目的长期合作伙伴们感到惊讶。  
Kurian的最新声明则让人们放下心来，Istio项目的发展方向将与谷歌在2015年向基金会捐赠的开源云计算工具Kubernetes基本一致。谷歌甚至专门建立了云原生计算基金会（属于Linux基金会的一个分支）以移交Kubernetes项目。而自从脱离谷歌以来，Kubernetes已经在客观层面成为全球范围人的标准容器（应用程序构建单元，有助于在云环境内提升灵活性水平）管理方案，甚至得到Google Cloud竞争对手AWS与微软的大规模应用。  
在被问及谷歌为什么花了这么长时间才决定捐赠Istio时，Kurian表示主要原因是项目本身还不够成熟。  
他指出，“Kubernetes的情况有所不同，毕竟它已经拥有多年的发展历史，而且早已在内部应用当中积累起丰富的成熟使用经验；与之对应，Istio项目的开发与使用一直在同步推进。人们误解了这个精雕细琢的过程，以为我们不想把项目移交给社区。”  
多年以来，谷歌一直通过以上标准回应解释Istio项目的发展规划。但熟悉该项目内情的消息人士指出，真正的原因是谷歌内部有一派观点认为将Kubernetes捐赠给基金会是个战略性失误。因此谷歌方面去年年底产生了动摇，一度想把项目据为己有。不过在今年早些时候向谷歌方面求证时，对方拒绝对这方面情况做出进一步解释。  
一般来讲，企业可以采取多种形式将开源项目捐赠给基金会；但在大多数情况下，基金会方面会要求捐赠方放弃对项目相关商标的控制权——换言之，允许其他企业用户利用开源项目建立起自己的商业服务体系。  
此外，基金会还需要确保项目的未来发展方向不会被掌握在某一家单独企业的手中。仍然以Kubernetes为例，虽然谷歌工程师多年以来为项目做出大部分贡献，但在基金会的控制下，Kubernetes仍然在众多不同参与者的共同引导之下找到了属于自己的前进道路。Istio项目也应该遵循同样的发展思路。  
美国空军首席软件官Nicholas CHaillan在今年1月接受采访时指出，如果谷歌不将项目捐赠给基金会，那么美国空军（同时也是Kubernetes与Istio项目的重要用户）将被迫放弃对相关技术的支持。  
凭借成功运营Kubernetes而声名大噪的云原生计算基金会在很多人眼中已经成为Istio的理想归宿，但在周二的采访当中，Kubrian表示谷歌的考量范围其实更广。他表示，“某些基金会的治理模式更科学，有些基金会的模式则相对较差。”他强调，谷歌将为Istio选择一家能够保证技术社区不断为项目发展提供动力的基金会。  
Kurian总结道，在COVID-19疫情结束之后，整个科技行业的发展优先级将发生重大变化，但这应该不会影响Istio的捐赠时间表。谷歌方面将“尽快”向公众披露关于Istio项目的更多移交细节。
