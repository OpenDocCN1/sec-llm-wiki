# 「行云创新」完成阿里云独家投资的B轮融资

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247544451&idx=3&sn=2fe60c8b7569d3d955f006c113350961&chksm=c03b6490f74ced8606515871d816e04384f54692e7b7c70d1970241ea405e1663c21d8a5fa5c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247544451&idx=3&sn=2fe60c8b7569d3d955f006c113350961&chksm=c03b6490f74ced8606515871d816e04384f54692e7b7c70d1970241ea405e1663c21d8a5fa5c&scene=27#wechat_redirect)

一站式云原生开发平台产品及解决方案提供商「行云创新」已于日前完成B轮融资，本轮投资方为阿里云，融资金额暂未披露。据悉，此前公司曾于2017年获得青岛国投Pre-A轮，2019年获正轩投资、高新投A轮融资。本轮资金将主要用于进一步推动产品矩阵核心技术的研发与创新、业务市场规模扩张、行业解决方案的生态建设和渠道合作伙伴生态建设。  
行云创新创立于2016年8月，公司定位于一站式云原生开发平台产品和解决方案提供商，希望帮助企业提升其在云原生时代的开发效率、帮助企业用好云。谈及创业契机，公司创始人兼CEO马洪喜介绍，这和其过去十多年工作背景以及近年国内大环境相关。马洪喜早前在甲骨文、思杰等外企从事云计算相关的研发和咨询工作，从很多工作接触的客户处感受到对采用科技创新驱动业务发展的强烈需求，另在“双创”驱动下萌生了创业的念头。在选择赛道时，马洪喜认为，在数字化转型的大背景下，每一家企业的业务创新都或多或少与软件相关，而今天软件变革需要开发人员通过一行行代码实现。行云创新则希望通过帮助企业开发人员提升效率，帮助企业推进数字化转型过程。  
具体在产品端展开，行云创新一站式云原生开发平台产品Cloud OS，主要以私有云和混合云形态为中大型B端企业提供整体云原生解决方案及服务，包含云原生应用架构设计、在线协同编码开发、基于云原生的API管理和接口测试、多云交付和应用调度、灰度发布、流水线、应用运维、服务治理、多容器集群管理、云边一体化业务交付等能力。目标是提升应用架构敏捷度，大大加快软件开发迭代速度，提高IT资源的弹性和利用率，帮助企业客户加速实现业务价值。  
![](../Images/6464745b4055a8506def0957e522bece.png)  
同时，行云 Cloud OS体系中，部分模块兼具独立产品形态，以满足不同客户对“大而全”的整体解决方案或是“小而美”的聚焦型产品的诉求。如：高效可视化业务流量管理平台（SolarMesh）、全云端开发环境（TitanIDE）、云原生时代接口管理及自动化测试（KeplerAPI）等。此外，针对小B和C端企业用户，公司提供公有云形态SaaS化开发云服务。  
马洪喜认为，在过往五年打造产品过程中公司跨越了不少难点，主要包括产品设计理念和落地过程中的技术管理能力。马洪喜介绍，首先云原生等先进理念和相关技术还没有被客户广泛认知，甚至还有一部分客户认为云原生就是容器，采购了容器产品就“云原生”了。但在现实情况中，虽然容器等先进技术是今天云原生拼图中重要的基础设施，但不少开发测试人员仍对此感到陌生，这让企业在云原生的探索道路变得更为艰难。  
也正是观察到此类现象，行云在产品设计中也尝试把复杂的技术细节用简单、易用的产品设计来掩饰。所以在产品体现上，行云引入了可视化拖拉拽，以拼积木方式设计复杂的云原生架构图，并且在线上就可以完成代码编写、自动化测试，最后按需一键发布到企业的多云环境，整个过程中使用者感觉不到容器的存在。像类似的产品设计还有很多，包括使用者可以采用一致的体验便捷地开发边缘应用，一键交付复杂的云边一体化应用等。另外，不少企业当前会有混合云的诉求。为了满足客户需求，公司需要在底层打造跨云管控能力，这也是技术难点之一。  
而在商业化方面，当前行云创新的主要收入来源是行云Cloud OS、SolarMesh、TitanIDE、KeplerAPI等产品的销售。公司在近三年左右也经历了多行业的客户拓展期。2018和2019年聚焦于华南为主、华中、华东为辅的市场，在金融行业、制造业、教育行业等领域实现标杆客户案例。2020年，公司在拓展华南市场基础上，重点开发华东市场，在上海设立分公司、成立了销售职能团队，开拓包括互联网、政府等新领域客户。  
谈及当前客户方以及伙伴方对云原生产品的认可度，马洪喜认为可以从不同客户类型展开分析。对于国有企业和大中型企业而言，当数字化转型的压力在前，再加上新技术的推广和普及，越来越多的企业会意识到“云原生是企业数字化转型的最短路径”，因此制造业等客户选择行云这类企业参与到其包括工业互联网建设等数字化转型的战略中来。另外，金融行业客户则对内部科技创新、软件研发的提效提出需求。它们除了引入包括DevOps等方法论的同时，也须从核心生产力模式上加以变革，而行云的云原生开发相关产品和解决方案也会成为这类客户的选择。还有一些合作伙伴，他们在诸如证券、机器人等领域的客户，需要云侧能力构建云上创新平台、形成“云上大脑”，行云创新的产品也能体现出价值。  
在2021年及之后的规划上，公司将持续推进云原生相关产品向金融、制造业、政府、能源等客户在开发测试云、PaaS、DevOps等应用场景的项目落地，同时开拓能源、运营商等行业，重点关注云原生应用开发、测试、交付等场景的解决方案落地，同期针对与不同合作伙伴针对垂直行业SaaS作更多的探索。  
另外，本轮融资之后，阿里云和行云创新也将通过产品组合的方式，在公共云、专有云及混合云领域，为企业客户提供云原生应用开发、业务智能运维等服务，满足企业日益增长的业务数字化需求。  
团队方面，公司CEO马洪喜有近二十年软件产品研发和管理经验， 曾在甲骨文公司、思杰公司、Rancher Labs公司等云计算领域外企担任研发管理、首席顾问、技术总监等职务，服务过国内外大中型企业数十家。与马洪喜一起创业的伙伴，技术、市场、销售等各团队更是有来自多家云计算相关厂商的云领域专家，具备多年容器、DevOps市场和解决方案销售领域丰富工作经验。  
关于投资：  
阿里云云原生应用平台负责人丁宇表示：“随着云原生的迅速普及，全云开发的时代已经到来，一站式的云原生开发平台将成为刚需。行云创新拥有人才储备与技术基础，还具备市场需求前瞻洞察，研发了业内领先的云原生开发平台产品，我们十分看好行云创新的发展。阿里云希望通过跟行云创新 CloudOS 产品及更多生态伙伴的合作，为更大范围的企业市场客户提供涵盖云原生开发、测试、运维、可观测全场景的产品及解决方案，帮助企业数字化创新升级。”
