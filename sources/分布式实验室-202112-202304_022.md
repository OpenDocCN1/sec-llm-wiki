# Twitter的部分源代码已在网上泄露，马斯克的乱

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247561795&idx=1&sn=c69e78dde395375ab66c9e9601728b8b&chksm=dc3bd071c3d188d54bd6eba64ef2092dc7f29f3776deb70ae74d30d58d93d46fff789661b3c6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247561795&idx=1&sn=c69e78dde395375ab66c9e9601728b8b&chksm=dc3bd071c3d188d54bd6eba64ef2092dc7f29f3776deb70ae74d30d58d93d46fff789661b3c6&scene=27#wechat_redirect)

**GitHub 已经下架了一个名为 “FreeSpeechEnthusiast” 的用户的存储库，该存储库包含 Twitter 的专有源代码**，此前社交网络已经提交了 DCMA 版权法下架请求。该用户名显然是对 Twitter 拥有者 Elon Musk 的讽刺，后者多次声称自己是 “言论自由绝对主义者”。  

周五，Twitter 在北加利福尼亚地区法院提交请愿书，要求 GitHub 撤下代码，并帮助找到泄露者。传票要求 GitHub 提供与 “FreeSpeechEnthusiast” 相关的 “姓名、地址、电话号码、电子邮件地址、社交媒体资料和 IP 地址”。

这一事件发生在 3 月 31 日 [Musk 将公开 Twitter 推荐推文算法](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247561679&idx=1&sn=a532ea54878338006f18543658f47a94&chksm=c03abbdcf74d32cab39137c939c981edcf85698c07c521d22014f76653b9828f93e9fcb0e057&scene=21#wechat_redirect)之前。Musk 一直承诺将公开此算法。

![](../Images/c677239791b86fa6a7234c4915fee69e.png)

目前尚不清楚在 GitHub 上泄露的是 Twitter 的哪部分源代码，以及泄露时间有多长。GitHub 的 DCMA 版权法下架博客只说它下架了包含 “Twitter 平台和内部工具的专有源代码” 的存储库。

该代码托管网站没有说公司在下架存储库之前是否有任何用户能够访问该存储库。我们在向 GitHub 了解最新情况，如果我们收到回复，我们将更新该报道。

**Twitter 可能还担心那些未上传到 GitHub 的代码副本。**据《纽约时报》报道，Twitter 的内部调查表明，泄露代码的人去年已离开公司。该报道还暗示，公司高管最近才知道泄露事件。

自 Musk 去年接手 Twitter 以来，该公司一直处于动荡之中。最近的报道表明，特斯拉首席执行官现在将 Twitter 估值为 200 亿美元，不到他为这家公司支付的 440 亿美元的一半。据《纽约时报》报道，Musk 写了一封电子邮件向员工宣布了一项新的股票补偿计划，其中提到 Twitter 未来可能价值 2500 亿美元。

Musk 采取了激进的措施来削减 Twitter 的成本，包括大规模裁员，并重新推出了一个新的订阅计划，包括账户认证。根据分析公司 Sensor Tower 的数据，Twitter 已经从这项新服务中获得了 1100 万美元。

**在最近的一个会议上，Musk 表示，Twitter 用户花费在该平台上的时间并没有被很好地用于获得商业利润。**

“每天 2.5 亿（月活跃用户）人在 Twitter 上花费的平均时间大约是半个小时左右。所以我们最感兴趣的事情是 —— 每天大约有 1.2 亿到 1.3 亿小时的人类注意力在 Twitter 上。” 他说。

“平均每天有这么长的时间聚焦在 Twitter，但是 Twitter 的商业化运作却非常糟糕。1 到 1.3 亿个小时的价值是多么大啊，这些时间的拥有者通常是世界上最聪明、最有影响力的人。”
