# Developer Tools 2.0时代来了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247561771&idx=1&sn=5c2b14229bd391e5a0b9477014a8b210&chksm=f81f9851ebf988bdf0f0e57245b6990d28590d9cb44197b709e25203672a5b45b8ff0eac28fe&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247561771&idx=1&sn=5c2b14229bd391e5a0b9477014a8b210&chksm=f81f9851ebf988bdf0f0e57245b6990d28590d9cb44197b709e25203672a5b45b8ff0eac28fe&scene=27#wechat_redirect)

**Copilot 获得了不可思议的成功。**它是 GitHub 为开发者提供的基于 AI 驱动的的智能工具，它可以在你写代码的时候，建议你接下来可能要编写的代码，同时它在很多其他方面也很受欢迎。

它深受工程师的喜爱，差不多一年时间就吸引了超过一百万的开发人员，同时它也显著的提高了生产力。（即使你是顶级工程师，它也可能会写出你一半或更多的代码。）它也有望成为成功的商业明星产品。Copilot 每个席位每月收费 10-19 美元，这可以在 GitHub 的 1 亿用户中产生 10 亿美元或更多的年收入。  

**Copilot 的成功掀起了淘金热。**创始人们竞相将大型语言模型的强大功能带到其他各种行业，构建工具来帮助专业人士写作、编码、设计和创建媒体。有 “律师的 Copilot”、“医生的 Copilot” 和 “设计师的 Copilot”，还有更多 “X 的 Copilot”。

这些都是令人兴奋的方向。我们认为生成式（generative） AI 将改变一个又一个行业，**使各类专业人士的工作效率更高，并让更多的消费者收益**。

但是对于开发人员来说还有很多事情要做。利用 OpenAI 模型 Codex 的 Copilot 可能只是 AI 转变软件工程师工作方式的开端。Andrej Karpathy 在 2017 年预测，神经网络将创造新一代软件，即 “软件 2.0”，同样我们也会看到制作软件工具的重塑（reinvention）——“开发者工具 2.0”。

这里有很多机会。一些创始人正在迭代 Copilot 推广的编辑器内编码体验，尝试不同的交互模式或不同的模型。想想 Replit 的 Ghostwriter、Soucegraph 的 Cody、TabNine 等。

往更远的方面思考，我们还有许多其他的机会。你可能会针对工程师在编写代码之外所做的工作，如调试和文档 —— 或者其他工程组织所做的工作，如事件响应。除了 “更快地编写代码” 之外，你可能会想到价值属性（value props），例如 “编写性能更高或更安全的代码”。你可能会抛弃插件形式封装（plugin from factor），然后重建整个应用程序。你可能会关注软件工程师以外的角色，例如需要提高写作能力的数据科学家，或者努力编写 SQL 查询的数据分析师。有广阔的机会可以探索，许多地方可以接入开发人员的工作流程。

![](../Images/f64bc7099e8ef3751de4d36fc9ffc4a1.png)

建立传奇公司来实现这一点并不容易。Copilot 因软件盗版问题而面临法律审查。微软是 GitHub 和 VS Code 的控制者，享有显著的分销优势。许多创始人已经开始使用 LLM 来进行构建，**这带来了许多有竞争力的机会**。GitHub 刚刚[宣布计划通过由 GPT-4 提供支持的全新版本的 Copilot 来提供更广泛的 AI 功能](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247561733&idx=1&sn=6edf2e38f3b4df593e41a59c6a77cacb&chksm=c03ab816f74d310000f7530028c01b3fa8d5d4d9eb8a21825fb0a5e9239c72da0ea5f7eba622&scene=21#wechat_redirect)。

我们认为，AI 可以在软件工程领域发挥巨大作用，这是一个关于谁而非是否的问题。我们认为，谁能胜出的重要因素包括**专注于开发者体验、提供全新的功能，并对如何在开发者工作流中落地和扩展做出战略性选择**。在这里取得成功可以意味着改写工程的发生方式，并有机会建立一家世代相传的企业。
