Docker公开道歉：各位免费用户受惊了

3 月 15 日，Docker 向所有创建了 “组织” 的 Docker Hub 用户发出电子邮件提醒，称如果不升级至付费团队计划，则他们的账户和所有镜像都将被删除。这引发了各种批评，并且批评声音越来越激烈。最终，Docker 顶不住社区的压力，做出了妥协，为其草率行为进行了道歉，并对之前的邮件进行了说明。下面是他们的道歉公告和说明。

我们对之前关停 Docker “Free Team” 订阅一事的表达方式深表歉意，让开源社区的用户们受惊了。

我们最近通过电子邮件向 Free Team 组织的成员账户发出通知，提醒他们除非转向我们支持的免费或付费产品，否则将无法正常使用 Docker 功能。受此影响的用户占比不足 2%。请注意，此次调整不会影响到 Docker Personal、Docker Pro、Docker Team 或 Docker Business 账户、Docker 赞助开源成员、Docker 认证发布者或 Docker 官方镜像。

Docker Free Team 订阅将被关停，部分原因是其针对性较差。我们近期更新的 Docker-Sponsored Open Source（DSOS，Docker 赞助开源）程序正在为开源受众提供服务，而且实际表现已经优于 Free Team。

这里还要澄清一下，只有当维护者决定删除公共镜像时，它们才会从 Docker Hub 中被删除。最初的通知中未明确强调这一点，我们深感抱歉。

总之，我们对于此次关停事件的沟通和执行确有不当，这里再次表示歉意，我们也将继续听取社区的反馈。

我怎么知道我会不会受影响？

你可以查阅 Docker 账户的 Organizations 页面，所有受影响组织在 “Subscription” 栏中均被标记为 “Docker Free Team”。根据统计，只有不足 2% 的用户在账户中拥有 Free Team 组织。

即使你的某些组织受到影响，你的个人 Docker 账户（及其他组织）也不会受到波及。

此次变更不会影响 Docker Personal、Docker Pro、Docker Team（付费）或 Docker Business 等订阅账户。

我使用的开源镜像是否会被删除？

Docker 绝不会删除开源镜像。只有当镜像的维护者主动决定在 Docker Hub 中将其删除时，公共镜像才会消失。如果维护者不采取任何操作，我们将继续分发其公共镜像。（当然，如果维护者迁移至 DSOS 或 Docker 付费订阅，我们也会继续分发其公共镜像。）

我运行的开源项目会受影响吗？

Docker 将继续为开源项目提供 DSOS 程序，这不会受到 Free Team 关停的影响。对于有意由原本的 Free Team 加入 DSOS 的新用户，我们将在 DSOS 申请审核期间推迟对你的组织的关停或删除。如果申请最终被拒，我们也将为你提供至少 30 天的缓冲期，之后才会将组织关停。我们正在听取反馈，并可能根据你的意见提供额外的计划或方案选择。

我们鼓励所有开源项目申请 DSOS 程序。我们已经于 2022 年 9 月更新了计划并扩大了支持范围，即使你之前的申请未能通过，也欢迎再试一次。我们还指派了更多工作人员，将尽量及时审查所有申请。

如果我发布的是 Docker 官方镜像（DOI），或者我是 Docker 认证发布者（DVP），会受影响吗？

DOI 或 DVP 计划中的代码仓库不受此次变更的影响。

如何保持对私有代码仓库的访问？

私有代码仓库是 Docker 推出的一项付费订阅功能，如果你目前正在访问 Free Team 组织并使用其私有代码仓库，这项服务将从 2023 年 4 月 13 日起被关停。你可以在多种订阅套餐中选择，借此保持对私有代码仓库的访问权。

其他人会 “抢占” 我的命名空间吗？

不会，即使你的组织被关停、删除，或者你自愿选择脱离 Docker，你组织的命名空间也不会被释放，其他用户无法 “抢占” 你的镜像。

我可以迁移至个人账户吗？

你可以提交支持工单，将 Free Team 组织迁移至个人用户账户。在工单处理过程中，Docker 不会对你的账户做任何处置。

我决定使用 Docker 之外的代码仓库，可以从账户中将数据导出吗？

没问题。在 2023 年 4 月 13 日之前，你可以随时从 Docker 注册表上的私有代码仓库中提取镜像，并将这些镜像推送至你指定的其他注册表。

Docker 订阅费是多少？

我们提供三种付费订阅套餐，从 Docker Pro 起步。具体情况，请查看：https：//www。docker。com/pricing/

Docker 付费订阅有哪些好处？

  • Docker Pro 适用于希望提高生产力的个人开发者。

  • Docker Team 适用于希望高效协作的小型团队。

  • Docker Business 适用于需要集中管理和高级安全功能的企业。

我该如何升级至 Docker 付费订阅？

  1. 在 docker.com 上登录你的账户。

  2. 在 banner 中选择 Upgrade 升级。

  3. 选择你要升级到的付费订阅级别与座席数量。

  4. 付款并完成。

我的镜像会自动被转移至付费订阅账户吗？

是的，在你升级为 Docker 付费订阅后，你的账户及所有关联配置、镜像和代码仓库都将 100% 保留原有名称和设置。
