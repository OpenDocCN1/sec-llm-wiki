# GitHub Copilot商业版正式发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247559218&idx=1&sn=347f74c61f42eb56a9491c23c0268988&chksm=c03aa221f74d2b37e11f29e9f7e333a3269e13916fdfdfe14439c37df3811c59e42554fd94f9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247559218&idx=1&sn=347f74c61f42eb56a9491c23c0268988&chksm=c03aa221f74d2b37e11f29e9f7e333a3269e13916fdfdfe14439c37df3811c59e42554fd94f9&scene=27#wechat_redirect)

GitHub去年推出了GitHub Copilot预览版，这是一个AI工具，被称为“你的AI结对程序员”，可根据命名或者正在编辑的代码上下文为开发者提供代码建议。

GitHub Copilot是GitHub与OpenAI合作开发，由OpenAI Codex提供技术支持的，是一个由OpenAI创建的新人工智能系统。OpenAI Codex对人们如何使用代码有着广泛的了解，并且在代码生成方面的能力明显强于GPT-3，部分原因是它是在包含大量公共源代码的数据集上进行训练的。

GitHub Copilot适用于广泛的框架和语言集，但此技术预览版尤其适用于Python、JavaScript、TypeScript、Ruby和Go等。

GitHub日前宣布，经过去年12月以来的短暂测试后，该公司打造的企业级AI代码补全工具Copilot商业版现已全面上市，费用为19美元/月。Copilot商业版新增了许可证管理、组织内策略管理及其他隐私功能。此前，用户必须与GitHub的销售组织合作才能注册使用商业版，但现在也同时提供自助购买选项。

GitHub CEO Thomas Dohmke表示，“Copilot 1.0版本的故事就此终于告一段落。2021年6月我们发布了预览版，现在回想起来似乎是很久以前的事了。去年夏季，Copilot全面上市。现在，我们又准备将其推广到组织、公司、团队、部门，或者说每一个人手中。事实上，Copilot商业版在发布之初就吸引到了400多家组织。他们都表现出了巨大的兴趣。”

![](../Images/6805112a4d4beca002f6fefad4f7dca9.png)

  

GitHub同时宣布，Copilot现已支持代理连接，包括使用自签名证书的连接。其AI驱动的Copilot代码补全工具，现由OpenAI驱动的改进模型提供支持。在通过Azure OpenAI Service发布以来，该团队一直在不断完善这套模型并添加新的功能。他将整个过程比作硬件业务中的规格调整，一切都是为了让模型更加强大，之后团队才能将成果引入Copilot。

随着模型的演进，开发团队也让很多新功能成为了现实。例如“中间填充”，该模型不仅能够补全单行，甚至可以精细补全光标指定的起始和结束位置间的特定单词。

Dohmke指出，为了提高补全质量，模型还会查看用户正在处理的相关文件，据此建立模型查询。“它不仅能参考用户当前打开的文件中已经键入的内容，还能结合相邻文件与相邻信息做出推理。”

通过这些最新更新，开发团队又在另一个模型的帮助下，让Copilot获得了从返回代码中识别常见安全漏洞的能力。一旦发现漏洞，它会自动提供更安全的补全建议。

光是变得更好还不够，整个过程还必须要变得更快。Dohmke提到，开发团队一直在努力改善延迟。GitHub的数据显示，一旦Copilot在生成代码时耗时过长，开发人员就会很快变得焦躁不安。

Dkohmke预计，Copilot很快就能为开发人员生成80%的代码。至于目前的覆盖水平，在全部编程语言中约为46%，在Java中则为61%。当下，ChatGPT和Bing搜索引擎已经能够通过简单的提示生成完整应用程序（或者至少其中一部分），而且其采用的底层模型与Copilot完全相同。这不禁让人好奇，Copilot什么时候才会提供类似的直接生成功能。

“我们对Bing团队推出的这项强大功能非常赞赏，但我们目前还不能说太多。总而言之，我们有自己的计划，而且这功能确实非常令人振奋。”Dkohmke最后强调，Copilot属于专业开发辅助产品，所以用户对于生成代码的要求肯定会更高。考虑到当前模型经常会输出不正确的代码，项目团队还是希望先把开发辅助方面的工作做好。
