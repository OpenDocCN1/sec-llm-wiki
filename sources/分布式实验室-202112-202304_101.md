# 刚刚，Google 宣布计划裁员一万多人

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247557954&idx=1&sn=9dcb03216c67d65ead41c501d42faf5f&chksm=c03aa951f74d20475af4fc2dee9a6d42a393091780b863bf876b1b01dc0706312c6c29d28eae&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247557954&idx=1&sn=9dcb03216c67d65ead41c501d42faf5f&chksm=c03aa951f74d20475af4fc2dee9a6d42a393091780b863bf876b1b01dc0706312c6c29d28eae&scene=27#wechat_redirect)

谷歌母公司Alphabet本周五表示计划裁员12,000人，也标志着又一家科技巨头决定在疫情招聘热潮退去后选择裁员。疫情时期的大规模招聘，加上人们对整体经济继续广泛放缓的担忧，已经令科技行业成为减员增效的重灾区。

此次裁员也是Alphabet有史以来规模最大的裁员，约占全球员工总数的6%。公司CEO Sundar Pichai表示，Alphabet在疫情期间扩张速度太快，当时市场对于数字服务的需求激增，因此现在必须重新关注其未来的核心产品和技术，特别是人工智能。

Pichai在公司网站上写给员工们的备忘录中写道，“我们招聘时预见的经济现实，与我们当下面临的实际情况并不相同。”

除了最迟行动的谷歌以外，亚马逊、Meta、微软、Salesforce和Twitter等已经宣布裁员数千人，各方都将疫情引发的短暂繁荣误判成了新的常态，因此导致人员规模过度扩张。

根据关注科技行业的Layoffs.fyi网站公布的数据，自2022年初以来，科技企业已累计裁员超19万人。

这些举措标志着科技行业快速扩张期的结束，各相关企业已无法继续用丰厚的津贴和高昂的薪资争夺人才。令人感慨的是，成立于1998年的谷歌曾定义了新的工作文化，该文化对硅谷内外的众多公司造成了深远影响。然而，如今谷歌自己似乎也守不住这份理想了。

总部位于加利福尼亚州山景城的Alphabet截至去年9月底有近187,000名员工，远高于前一年的150,000名。

Pichai在题为《为未来做好准备的艰难决定》的备忘录中表示，裁员将涉及各个产品领域、职能岗位和工作地点。公司正面临前所未有的竞争压力，特别是竞争对手已经开始在互联网上提供新的信息搜索方法：ChatGPT是OpenAI开发的一种流行聊天机器人，能够用自然语言直接向用户提供令人难以置信的清晰书面答案。

Pichai解释道，“这些都是重要的历史性时刻，能让我们更加专注，重新规划自身成本基础，并将我们的人才和资本引导到优先级最高的事务当中。收缩某些领域，可以让我们在其他重点领域上加大投入。”

上个月，谷歌刚刚针对ChatGPT启动了“红色代码”，Pichai要求颠覆现有项目、专注于AI领域。随着裁员的继续，谷歌明显是在削减优先级较低的工作。

作为AI事务的支柱，谷歌研究院负责研究、健康和AI的高级副总裁Jeff Dean向员工们发出一封电子邮件，计划削减部分前景一般的项目职位，包括医疗保健。该公司还打算缩减面向医疗保健服务商的Google for Clinicians工具的投入。Dean补充称，谷歌和Alphabet还打算将机器人研发团队合并起来。

过去几年来一直快速招聘的Google Cloud也未能免于裁员。Google Cloud CEO Thomas Kurian在写给员工们的邮件中表示，“此次消息主要影响那些非面向客户、非工程以及运营性质的职位。”他同时强调，该部门将继续在战略领域招聘人才，包括产品开发、与客户直接相关的各种有助于促进业务增长的职位。

据两位知情人士（因未得到评论授权，此处保持匿名）介绍，Alphabet旗下的“登月工厂”、负责孵化新公司的X，则解雇了其战略和业务运营团队的成员。在X中建立的很多公司一直无法产生可观的收入并实现盈利。

公司其他部门也有裁员。一位知情人士称，谷歌解雇了Fuchsia团队中16%的员工。这支400人团队主要负责为公司的家居设备开发操作系统。数据中心维护团队，其他工程师、用户体验研究员和产品设计师也均受到裁员影响。

尽管Alphabet和其他科技巨头纷纷裁员并强调需要提高效率，各家的利润收益也仍然相当可观。2021年，Aphabet的利润为760亿美元，总收入接近2580亿美元。

代表1100名成员的Alphabet员工工会已经对裁员提出批评。

工会执行主席Parul Koul在一份声明中称，“公司每年几十亿美元的利润未受影响，高管们的薪酬也未受影响。我们的工作岗位不该被裁掉。”

但科技行业确实受到了存款利率上升和全球经济下滑的影响。随着广告市场陷入困境，谷歌搜索引擎和谷歌旗下YouTube的广告销售额缩水，Alphabet的利润也受到打击。该公司的云计算业务继续落后于亚马逊和微软。去年10月，Alphabet表示季度净利润下降了27%。

华尔街分析师倒是对Alphabet的举动表示认可。Evercore ISI的Mark Mahaney在研究报告中写道，裁员是保持利润的必要步骤。在周五宣布裁员之后，Alphabet的股价立即上涨了超5%。该公司将于2月2日报告2022年财务业绩。

面对这股席卷整个硅谷的裁员浪费，谷歌有不少员工已经为此做好了准备。部分小型办公室被关停，再加上更加严苛的新型员工评估制度的上线，已经明白无误地向员工们发出了公司有意裁员的信号。

此次裁员消息发布选在美国当地时间的凌晨，不少受到影响的员工当时都在睡觉。他们一觉醒来遭到短信和新闻报道的轰炸，某些岗位甚至立刻失去了对谷歌企业系统的访问权限。

周五被解雇的YouTube网站可靠性工程师Chewy Shaw表示，此次裁员的规模和速度令人愤怒。“高层随时可能发布裁员令，只要一个响指，普通员工就完蛋了。”

Alphabet表示，美国国内的员工们将拿到一份遣散费，基础额度是相当于16周的工资，另外每在谷歌工作一年会额外拿到两周工资。被裁员工将获得为期六个月的带薪医疗保健。该公司表示，美国以外的员工薪酬将按照当地劳动法执行。
