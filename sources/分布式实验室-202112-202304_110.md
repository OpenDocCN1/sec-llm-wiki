# 《Rust实战集训营》来了，年后开课

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247557660&idx=1&sn=ea1d5ddb80aed6faffe43dc61a701347&chksm=c03aa80ff74d211975f334b1cc865c2126246a25d951c2e6d85744e22f5535ca5cee6147f188&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247557660&idx=1&sn=ea1d5ddb80aed6faffe43dc61a701347&chksm=c03aa80ff74d211975f334b1cc865c2126246a25d951c2e6d85744e22f5535ca5cee6147f188&scene=27#wechat_redirect)

Rust是一种快速、高并发、安全且具有授权性的编程语言，于2006年发布。从2016年起，连续7年成为Stack Overflow用户评选出来的最受喜爱的语言。

国内大厂比如字节跳动就选择了Rust来写软件，前段时间还开源了国内首个基于Rust语言的RPC框架Volo。

华为也在积极的推动Rust发展，内部参与Rust社区贡献的员工非常多，华为也是国内唯一的Rust基金会创始成员。

快手也开源了其使用Rust语言实现的开源分布式训练框架Bagua。

可以预见，不久Rust将会在更多的领域被采用，成为开发者的主力语言。
