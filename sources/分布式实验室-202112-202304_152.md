# 持续交付工具Flux正式从CNCF毕业

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247556309&idx=1&sn=27783a41b6be44a61b5d605ccad8845c&chksm=c03b56c6f74cdfd079fd4e09b961a2645d937dc0e27e278c01448b2d61438ddb96985477af78&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247556309&idx=1&sn=27783a41b6be44a61b5d605ccad8845c&chksm=c03b56c6f74cdfd079fd4e09b961a2645d937dc0e27e278c01448b2d61438ddb96985477af78&scene=27#wechat_redirect)

今天CNCF宣布Flux正式毕业了。

Flux是一款面向Kubernetes的持续渐进式交付解决方案，具有开放性和可扩展性，能够为开发人员和基础设施团队提供GitOps与渐进式交付。Flux也是第18个正式毕业的CNCF项目。

Flux具备多租户、多集群和多云属性，且原生支持Kustomize、Helm和HashiiCorp Vault。包括沃尔沃、SAP和RingCentral在内的多家全球企业都依赖Flux保障企业级安全与规模，包括其对开放容器倡议（OCI）和Cosign验证的支持。同样，AWS、D2iQ、微软、Red Hat、VMware以及Weaveworks等也都坚信Flux能够为他们的企业客户带来GitOps新体验。

云原生计算基金会CTO Chris Aniszczyk表示，“随着GitOps成为主流，Flux一直是个令人兴奋的项目。Flux用户不仅接纳了GitOps的高级应用和渐进式交付，同时也与CNCF中的Flagger、Helm、Prometheus等关键项目携手并进。Flux的毕业，很好地表明了云原生技术的当前成功与光明前景。”

自2021年3月加入CNCF孵化器以来，Flux及其子项目Flagger就做出了坚定的治理与社区包容性承诺，并借此在用户规模、集成度、软件使用量、用户参与水平和贡献量等指标上增长达200%至500%。

Flux维护者、Flagger创建者兼Weaveworks公司首席工程师Stefan Prodan表示，“过去五年以来，我对能够加入Flux和Flagger团队感到既荣幸又谦卑。在社区的帮助下，Flux从GitOps运动的浪潮中诞生并走出，一路取得长足进步。如今，Flux已经成为成熟的Kubernetes持续交付解决方案，受到世界各地组织的信任和支持。Flux团队非常感谢多年来支持我们的云原生社区和CNCF，感谢大家的努力让Flux成长为今天的样子。”

“出于客户利益的考虑，D2iQ选择通过Flux将GItOps引入D2iQ Kubernetes平台（DKP）。我们的客户得以享受到GitOps在简化应用程序和基础设施管理方面带来的优势，而Flux从CNF的毕业也进一步证明其为Kubernetes部署贡献的重要价值。Flux拥有非常稳健的设计和安全水平，其提供的关键功能使得DKP客户能够轻松管理整个机组内的应用程序和集群。”——D2iQ公司产品副总裁Dan Ciruli

“开源社区的各项协作的确令人受益匪浅。感谢Flux，我们的Gardener社区现在能够通过真正的GitOps实现Kubernetes工作流程自动化。”——SAP开发高级经理Frank Heine，SAP云原生战略副总裁、首席架构师兼CNCF理事会代表Vasu Chandrasekhara

Vasu Chandrasekhara还补充道，“借助LCM和Flux，我们的用户能够订阅支持GitOps的本地化包，各包即使在隔空环境下也可持续部署。Flux已经成为实现此类用例的关键框架和标准。”

“作为Flux和Flagger的企业用户，Flux确实降低了平台团队的Kubernetes使用门槛，Flux和Flagger还让开发人员更安全地运用GitOps，这一切都令我们获益良多。”——Ivan Anisimov，RingCentral公司工程总监

J.B. Hunt公司主软件工程师Daniel Trimble表示，“在J.B.Hunt，Falgger帮助我们的开发人员以超越计划的速度加快部署节奏。Flagger的渐进式交付则帮助我们为客户带来可靠的关键业务应用程序。我们也开始使用Flux的OCI功能，并对Flux的毕业以及在未来的持续成功感到无比期待。”

Flux社区目前正携手合作，推动Flux的正式发布、继续构建核心功能、进一步扩展集成范围，并共同提供最佳社区支持。社区对Flux的可扩展性表示高度期待，而且目前已经能够与Terraform和Visual Studio Code等流行开发平台快速集成。

为了正式由孵化状态走向毕业，Flux项目展现出了先进的安全性、快速增长的采用率、开放的治理流程以及令人印象深刻的技术设计。该项目夺得Core Infrastructure Initiative的最佳实践奖章，并于去年通过了第三方安全审查。审计人员表示，“我们从项目中发现了许多积极因素，可以看到Flux的开发者们明显在安全工作上付出了大量心力。”
