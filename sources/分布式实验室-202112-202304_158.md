# Facebook内部红宝书

Facebook认为企业在发展过程中，可能会面临各种问题，但是其中最重要的，可能是向陆陆续续加入公司的员工说明公司的理念、追求、历史和文化。所以Facebook专门为新加入的员工设计和印刷了一本小红书来介绍公司的价值观。

下面介绍一下类似于Facebook员工手册东西——Facebook小红书。

介绍从封面开始。

这是封面：

![](../Images/53dc59317ed9104f347f4ca8a1bd8102.png)

创办Facebook，最初并不仅仅是为了成立一家公司。

![](../Images/cd0aa5efb4c1eb974ef75014e909d13b.png)

创办Facebook，是为了完成一个社会使命——连接世界、更加开放。

![](../Images/5447e3929cbde54e4910d645d8e1f8cd.png)

改变人们的沟通方式，将会改变这个世界。

![](../Images/215a3cb79aa9179dbb339a996df1abba.png)

  

历史上谁控制了媒体谁就控制了信息。如果控制了唯一的报纸、电台或电视，就控制了人们的全部信息来源。但是，如果任何人都可以成为媒体，世界将会怎样？

![](../Images/c215c35f6f65959530ed9aa4b0b287f8.png)

  

Facebook的每个工程师都在为数以百万的用户服务。

![](../Images/ed9839bda773a8e1f14790efce1e2c49.png)

6个月或30年。在互联网行业里，做个5年计划没什么意义，每走一步，形势都会发生变化。所以我们只会为未来6个月制定完美的计划，作为未来30年的一部分。

![](../Images/494a63e2ccb64da70f98d16219d07bf2.png)

伟大和安逸很难共存。

![](../Images/e990c23e9445f661a306cef690b34c27.png)

唯快不破。

![](../Images/da1bd987325a8a3af09c7a4389121816.png)

记住，人们不会为了“赞”我们而上Facebook。人们上Facebook，是为了“赞”他们的朋友们。

![](../Images/9befa9c4ea95bc9b3424d0fec1fc6c9c.png)

  

我们向用户提供服务不是为了赚更多钱，我们赚钱是为了向用户提供更好的服务。

![](../Images/153cf5eeda7fb5d1e9a099121fb02911.png)

与其让别人创造出可以灭掉Facebook的东西，不如我们自己来！

![](../Images/04f7a1cbcca62806d2def77172f400c1.png)

  

这就是Facebook小红书的样子。
