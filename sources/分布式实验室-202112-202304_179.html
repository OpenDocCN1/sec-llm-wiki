.NET 7正式发布，帮助开发者简化代码上云路径

原文：http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247555446&idx=1&sn=d0240252fe7e2ae0538e557fd3b87740&chksm=c03b5365f74cda738e5432231ad1863ee2b5bfcffa6c9cf6cbe9f1497f9172990d4ba66f1305&scene=27#wechat_redirect

昨天微软发布了.NET 7，新版本带来了一系列新的功能和特性，包括C#11[1]/F#7[2]、.NET MAUI[3]、ASP.NET Core/Blazor[4]、Web API、WinForms、WPF以及轻松对.NET应用程序进行容器化的云原生功能。

简而言之，.NET 7几乎适用于一切开发人员，也无怪乎微软要在本届.NET Conf 2022大会上高调公布。


— 1 —
一套堆栈，承载所有应用类型


微软Azure开发者体验产品副总裁Scott Hunter在采访中表示，“我们是唯一一套能够构建控制台、Web、云、移动、桌面等应用成果的堆栈。.NET的最大亮点就是，大多数其他堆栈只擅长构建服务器应用或者客户端应用中的一种，而我们每种都擅长。”

此外，通过.NET 7，微软还简化了将.NET代码引入无Docker云原生工作流的方式。


— 2 —
容器化


微软开发者平台及变速器产品负责人Gaurav Seth也提到，“容器正成为云端部署的客观标准，而我们则使用.NET 7让整个流程变得更简单。现在，大家无需在设备上启用或安装Docker Desktop，就能轻松将应用程序部署在云端。只需一条简单的CLI命令，你就可以构建和部署自定义容器，而且支持任何容器运行时：Docker、Podman、Containerd等。”

这项功能不仅可以通过CLI使用，微软还在自家Visual Studio IDE中引入了相应支持。

Seth解释道，“Visual Studio不仅能够实现应用程序的无缝开发，还可以无缝部署和配置各类Azure PaaS服务，例如Azure App Service、Container Apps等等。”

此外，借助.NET 7，开发人员还可以直接右键点击GitHub Actions来轻松设置CI/CD。

Hunter说，“在.NET 7当中，我最喜欢的功能就是无Docker和无Docker Desktop支持。我的日常工作需要在Azure当中构建容器服务，所以就得频繁将代码调用到云端。因此，我们想要弄清楚这种代码上云的路径到底可以做得多简单。接下来，我就一点一点简化这个流程，让它变得越来越轻松快捷。”

对于构建客户端应用程序来说，开发者往往希望能有更多的选项，从中选择正确的堆栈来构建客户端应用。这种选择体现的是范围与功能之间的权衡，并没有一定之法或者最佳答案。

Scott表示，“根据实际应用的需求，大家会灵活做出技术组合选择，例如纯Web以扩大覆盖范围、纯原生以深度集成操作系统或设备等等。如果有些开发者希望二者兼而有之，那就会选择混合客户端应用程序。现在，.NET 7能够全面提供支持。”

关于可观察性功能，.NET 7与Azure App Insights相集成，并支持OpenTelemetry框架。因此，开发人员可以测量其.NET 7云原生应用程序的可靠性和性能。


— 3 —
Linux支持


.NET 7还是微软宣布与Canonical合作之后发布的首个.NET主要版本，因此.NET 7能够与Chiseled Ubuntu Containers协同工作。

微软最近宣布，从Ubuntu 22.04 LTS版本开始，.NET将被纳入默认工具包源。微软也一直在努力让.NET平台在Linux上拥有良好的运行体验。

Hunter强调，“在2016年刚刚探索Linux世界时，谁能想到Red Hat或者Fedora会向我们伸出橄榄枝？但如今，各家Linux发行商已经把.NET同Java、Node、Python和Go紧密结合。相较于2002年时完全闭源的状态，.NET如今的成就着实令人赞叹。”


— 4 —
其他功能


.NET 7还附带其他多款产品、库和平台，包括ASP.NET Core 7、Entity Framework Core 7、.NET MAUI、Windows Forms、WPF和Orleans 7等。此外，.NET 7还开始原生支持ARM 64架构。

其中的Orleans是一套微软跨平台软件框架，也是让.NET成为云分布式应用程序编写利器的关键要素。Seth介绍称，“我们将Orleans视为.NET家族中的核心成员。Orleans能够大大降低分布式应用程序的构建难度。实际上，微软Halo、Mesh和Azure等服务都已经在使用这项技术。”

Hunter也提到，“如果大家要构建API，以往的.NET是种非常冗长的语言，导致开发者的实际代码编写量很大。我们一直在努力减少代码编写量，从Node.js和Python身上学习先进经验，希望把更好的功能带给我们的.NET客户。”


— 5 —
社区支持


.NET的月度活跃开发者数量趤570万，并在2019、2020和2021年的Stack Overflow调查中连续被评为开发者最喜爱的框架之一。

开源社区也为新版本中的不少增强功能贡献了力量。Seth表示，.NET 7中共包含来自10000多名社区成员的28000多次贡献。
