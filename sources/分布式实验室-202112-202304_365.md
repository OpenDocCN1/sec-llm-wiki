# 刚刚，Google宣布把Istio捐赠给CNCF

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5Mjc3MjIyMA==&mid=2247544965&idx=1&sn=13ac5917218afbb505105c99b3f0012e&chksm=c03b7a96f74cf380365d40ad77972bb4838a0e916e208ec9a9c516e1fc3c25bce3c5bf48905b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247544965&idx=1&sn=13ac5917218afbb505105c99b3f0012e&chksm=c03b7a96f74cf380365d40ad77972bb4838a0e916e208ec9a9c516e1fc3c25bce3c5bf48905b&scene=27#wechat_redirect)

谷歌将Istio服务网格赠予云原生计算基金会（CNCF）的决定并不让人意外，支持者们表示此举有助于扩大Istio在市场上的份额占比。

鉴于之前因为[将Istio服务网格纳入自建开源组织](http://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247544033&idx=1&sn=ea0e43cc2a399eb377befa04810009a2&chksm=c03b66f2f74cefe4d4347112cc2ab7a6197a690da6ea8b300bc32f0470a8639106fc9f1c9bac&scene=21#wechat_redirect)而备受争议，谷歌最终决定将该项目捐赠给云原生计算基金会。

Istio商标将由谷歌的Open Usage Commons被移交至云原生计算基金会（CNCF）。顺带一提，CNCF属于Linux基金会于2015年成立的子机构，最初专门负责管理Kubernetes等项目。

捐赠消息公布于本周召开的IstioCon线上大会，时间也正值谷歌捐赠事件驱动计算项目Knative的五个月之后。人们普遍认为，只要Knative迎来捐赠的命运，那么Istio这边也就是早晚的问题了。谷歌官员则强调，最终之所以决定捐赠Istio，部分原因是希望能让三大容器自动化框架拥有同一个基础。

谷歌副总裁兼研究员在IstioCon的主题演讲中解释道，“Istio商标将被移交给CNCF，并由该基金会如同Kubernetes等其他商标一样负责管理，由此降低广泛的社区风险并建设真正开放的生态系统。如此一来，Istio将成为完整Kubernetes集合堆栈中的组成部分。”

Istio服务网格的支持者及其他IstioCon与会者对此纷纷表示赞赏，认为这将扩大Istio项目在用户及供应商合作伙伴中的采用比例。事实上，由谷歌把控一直是影响人们选择Istio的重要阻碍。

曾在美国防部任职、目前身为Istio商业供应商Tetrate公司独立顾问及顾问委员会成员的Istio早期采用者Nicolas Chaillan表示，“多年以来，我一直在努力推动Istio的真正捐赠。如今愿望达成，Istio必将赢下整个市场。毕竟只要CNCF推什么，大家就愿意用什么。”

此外，Istio商业供应商Solo.io公司开源主管、另一位IstioCon演讲嘉宾Lin Sun也对捐赠做出了积极评价。

Sun在这场线上会议直播中表示，“从现在开始，大家用不着到处寻找不同的服务网格项目了——直接选择在生产环境中部署量最大的选项即可。相信Istio也将在CNCF中找到家的感觉。”

Istio服务网格由谷歌、IBM及Lyft于2017年共同推出。尽管项目实力很强，但之前一直没能像Kubernetes那样主导整个市场。根据CNCF年度调查报告，CNCF下辖的服务网格项目Linkerd在易用性与部署灵活性方面一直紧跟Istio，2021年在北美市场的份额增长甚至还超过了Istio。

另有分析师表示，在Istio断绝了跟Google Cloud之间的联系之后，供应商合作伙伴及企业用户很可能会再次对Istio给予重视。

RobustCloud独立分析师Larry Carvalho表示，“Istio将迎来更快的发展节奏；更重要的是，企业用户现在可以选择AWS或者Azure等其他超大规模云服务，同时借Istio之力轻松走向混合云的发展道路。”

CNCF方面还没有正式接收Istio项目，但这基本只是时间问题，整个过程应该跟之前接收Knative差不多。

![](../Images/ee07d541d18507d1564c28da195dc339.png)谷歌副总裁兼研究员Eric Brewer在本周的IstioCon大会上宣布将Istio捐赠给CNCF

Linkerd社区负责人们也表示，此次捐赠将为CNCF各服务网格项目间的协作铺平道路。

Linkerd商业支持公司Buoyant.io创始人兼CEO William Morgan指出，“我们一直欢迎谷歌参与到Linkerd项目中来，也希望此次捐赠预示着更深层次的转变。但愿谷歌等科技巨头能够与我们携手，共同贡献、维持并改善整个开源生态系统。”

Istio的部署已经相当广泛，主要受众就是需要细粒度安全功能的大型企业。然而，项目本身过于复杂限制了Istio进一步扩大领先地位，也给竞争对手留下了挑战的空间。除Linkerd之外，Kong Mesh与HashiCorp Consul也纷纷表示有一战之力。

Solo.io的Sun认为，上游社区一直在努力“让Istio用起来更无脑”，包括在新版本中引入Pod网络优化以及更加清晰的独立代理配置界面。Solo.io及Tetrate等商业供应商也不断引入更易于使用的功能，希望持续扩大Istio的市场吸引力。

Sun在IstioCon演讲中总结道，“我们知道Istio的无脑程度还比不上Kubernetes，但我们一直在为此而努力。”
