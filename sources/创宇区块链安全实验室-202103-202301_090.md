**知道创宇区块链安全实验室 **通过分析 ENS 持仓大户和 ENS Airdrop Farmer 的交易数据，发现了薅 ENS Token 的羊毛党。

  

**什么是 ENS**

ENS（Ethereum Name Service）是基于以太坊区块链的域名系统，可以为钱包、网站和其他内容提供去中心化的域名。常见的用例：转账给某个地址时，不需要输入形如0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045的地址，仅需输入vitalik.eth即可发起转账；  
构建 Web 应用时，也可以通过 https://vitalik.eth.link 链接进行访问。

ENS 作为以太坊公共基础设施，在整个以太坊生态中覆盖面较广，如 Etherscan 区块浏览器、Metamensask 钱包以及常见 dApp（Uniswap、Opensea）均支持 ENS 服务。

  

此前，以太坊基金会和 ENS 也发起制定通过以太坊账号登录第三方 Web 应用的技术规范，使得用户能够通过以太坊帐户和 ENS 配置文件控制其链上身份，通过定义技术规范来进行标准化，使得 Web2 服务也能便捷接入。

  

近日，ENS 宣布创建去中心化组织（DAO）并分发 ENS Token，将治理权转交给社区，ENS Token 总量共 1 亿枚，总供应量的 25% 会空投给用户（超 13.7 万个地址），还有 25% 会分给 ENS 贡献者，另外 50% 则分配给 DAO 社区金库。

  

ENS 社区用户发现在空投规则公布前，有用户为大约 700 个独立地址均存入了 0.1 ETH，然后注册了一个独立的 ENS 地址，以期获取 ENS 的空投，ENS 团队权衡后决定将这些地址设为黑名单，这些地址将无法收到 ENS 的空投。

  

**ENS空投大户**

本文主要从 ENS 持仓大户和 ENS Airdrop Farmer 这两类用户的行为数据进行分析，通过链上数据识别以太坊多账户实体，从而为 Token 公平分发提供数据支撑；  
同样地，从数据中也可以看出 ENS 重度用户，除了参与 ENS 合约，还关注了哪些热门项目。  
  
据 Dune Analytics 数据显示，以太坊域名服务 ENS 空投的 Token 已有 52% 的地址参与认领，共计 72323 个地址，领取 Token 数量超 1420 万枚。

**揭密ENS羊毛党**

由于历史上分发过许多高价值的 Token 空投，也吸引了大量的羊毛党，同一个用户创建多个地址频繁与 dApp 合约进行交互，以期获得空投资格；或提前知晓内部消息，按特定规则与合约进行交互，达到获得空投的目的。  
通过分析链上多深度的大量交易数据，提取同一实体多地址数据，就显得尤为必要。  
通过解析这些用户的行为特征我们可以发现，当用户从 ENS 空投合约提现后，会将多个地址中的 ENS Token 进行汇集，汇集至同一个地址管理。  
再由这个地址充值到交易所平台，或通过 DEX 进行交易，从而达到节约交易成本的目的。  
以当前领取过 ENS Token 的地址交易作为数据集，对数据集进行聚类分析，根据**链探（https://ti.knownseclab.com/）**的标签数据对其中的交易所地址、合约地址进行清洗过滤。  
同时捕获地址间单一流入、单一流出和直接交易行为来聚合多个账户归属一个实体的数据，最后我们可以得到 689 个地址集合，其中最大的地址集合为 62 个，共领取了 5411 个 ENS Token。  
![](../Images/617055c88e10c5a8a046c19deaf7836a.png)  
另外从这些地址集的交易数据中可以看出，不仅与 ENS 合约进行了交互，同时也与 zkSync （未发行 Token）二层网络的合约进行了频繁交互。  
当然也不排除有的用户会批量从 Tornado 这类混币平台提取资金，进行合约交互，但这样交易成本更高，不算是一种较为经济的“薅羊毛”方式。  
我们也可以通过降低匿名集的方式提取交易特征，从而提取部分同一实体控制的多地址，同时也可以通过链探产品的地址同源分析查询某一地址关联的其它地址，帮助分析地址的实体信息。
