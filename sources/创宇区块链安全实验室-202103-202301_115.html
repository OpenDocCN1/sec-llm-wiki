在过去几个月的 NFT 热潮中，各种加密资产被不断推上神坛，价格飙升，而在近半个月内，在 NFT 这一加密领域内，再次出现了持续带动热潮的现象级资产——Loot。

关于 Loot 的具体链上存在形式很容易让初次见到的人费解。总结来说，Loot是一种文字形式的 NFT，该 NFT 资产包含随机组合的 8 件物品/装备（均为简单文字描述），8 件物品整体被称为“Bag”（表达一袋子的装备）。

具体表现形式十分简陋，目前在 NFT 交易平台均以黑底白字的图片形式出现。

Bag #693 Loot (for Adventurers)

额外说明 Loot 并不是交易平台所展示的黑底白字图片本身，Loot 即为这 8 个文字词条，本身不具备图片的存在形式，NFT 交易市场为了便于用户理解，以更具象化的形式进行展示。

而正是这个最开始连前端铸造界面都没有实现，需要手动调用合约铸造 NFT 的项目，8 行简单的英文说明形式所出现的 Loot，在短短一周内便席卷了 NFT 交易市场。


加密市场的情况瞬息万变，前段时间仍以 CryptoPunks 这些“JEPG”形式的头像 NFT 引导庞大的市场，瞬间就切换到文字“TXT”形式的 NFT 热潮。

Loot 这一项目从被铸造到被市场推崇的仅仅历经几周时间，价格已经出现了翻天覆地的变化。

Loot 本身的 NFT 免费铸造（仅需缴纳铸造费用），任何人都可以领取#1到#7777 号 Loot NFT，而#7778 到#8000 号（共 222 个Loot）由合约部署者保留。

但是截至 2021 年 9 月 8 日，在 Opensea 交易平台上，Loot 项目的NFT地板价已经高达 8.95 个 ETH（文章编写时ETH单价为 3431USD），约 30000 美金。


一些 NFT 专家以及加密爱好者认为项目的核心思路颠覆了 NFT 一贯而来的设计方法，真正实现了“自下而上”的去中心化，这正是 Loot 项目的最大价值。

在 Loot 出现之前，人们对传统NFT的主要思路限制在加密收藏品、加密生成艺术品、游戏物品、域名等等。尤其是“JPEG”类型的NFT，例如 Cryptopunks、Pudgy Penguins、BAYC 等，这些 NFT 项目利用了区块链的不可篡改等特性，来向人们展示持有用户的数字所有权。

这种传统的 NFT 的建设思路是“自上而下”的，即 NFT 内容创造者已经建立了较为成熟的 NFT 内容，同时以项目发行方为主体，拓展项目生态以及建立社群基础。

总的来说，NFT 创作者所提供的是像住房一样的“成品”， 基于此点，NFT 创作者会围绕“成品”进行下一步的拓展运营，例如为住房进行不同风格的装修、定制家具等等。


而 Loot 则打破了长此以往的传统 NFT 建设思路，每一个 Loot bag 仅仅有几行文字，对于常规 NFT 来说，Loot 本身除了文字以外，没有任何数值、相关图像或背景描述，这些内容被 Loot 的创造者刻意地进行了省略。

其省略的目的是能够让社群进行更多无拘束的思路拓展。

社群制作的Loot bag的具象化展示，图中为上文的Bag #693

也就是说，基于这些不可篡改的文字 NFT，其他人可以按照任何自己希望的意愿来阐释并进行其他思路的设计构建，Loot 就像是加密世界或元宇宙里的一块基石，它无须许可，任何人都可以使用它的相关信息搭建加密游戏、元宇宙、NFT 等各种项目中，社群或者其他开发者可以按照自己所构想的方式去创造新的世界。

于此同时，由于 Loot 并非“自上而下”的 NFT 成品，所以它不会专属于某个项目或者背景，而会跟随其 NFT 的持有人在其他任何游戏或者项目中使用。

这是将 NFT 转为更为理想的去中心化的方案，Loot 以一种“自下而上”的方法，通过自身信息的“留白”，让社群来决定 NFT 的价值与可拓展性。就开创性而言，Loot 与去年 DeFi 热潮时期 YFI 所给人们带来相同的冲击感类似。

Loot(for Adventurers)的衍生项目Characters(for Adventurers)

但是一切都过于实验性了，没有项目运营方，没有规划路线图，没有核心开发者，没有内容艺术家，一切都是去中心化的。

纯粹依托于项目的热情以及社群的支持，能否长久发展下去？在市场从沸腾转变为平静时，能否仍旧保持大量的拥护者及生态？其他生态是否会对这种形式感兴趣，参与到这个体系架构之中？

这些内容我们不得而知，Loot 就像 NFT 加密市场发起的一次未来实验，我们要追求创新精神，但是也要有面对失败的勇气，尤其是在现阶段 NFT 市场的泡沫下，更不要因为一时的投机冲动做出错误决定。
