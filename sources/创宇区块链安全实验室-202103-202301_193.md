# 知道创宇区块链实验室 与 Huobi Global 达成战略合作

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyMzQ0ODE0NA==&mid=2247488275&idx=1&sn=e85330c0c66252ed9dcfcf190fc87bc7&chksm=c1e5b52cf6923c3a682a1e6ee26e977455e29e45bcef2a569c54944d70966101424e6868076e&scene=126&sessionid=1681668772#rd](http://mp.weixin.qq.com/s?__biz=MzkyMzQ0ODE0NA==&mid=2247488275&idx=1&sn=e85330c0c66252ed9dcfcf190fc87bc7&chksm=c1e5b52cf6923c3a682a1e6ee26e977455e29e45bcef2a569c54944d70966101424e6868076e&scene=126&sessionid=1681668772#rd)

4 月8 日，**知道创宇区块链安全实验室** 与 **Huobi Global **达成战略合作关系 ，双方将在保障用户资产安全、提高平台安全性等方向进行深度合作。

 

![](../Images/9e5e916c4631104fc1fbef993ba08be5.png)  
**Huobi Global**，是火币集团旗下服务于全球专业交易用户的创新数字资产交易平台，致力于发现优质的创新数字资产投资机会。2017年10月，火币集团全面开启国际化战略布局，以交易服务为布局重点，以 Huobi Global 作为原点向全球区域辐射，作为全球合规牌照数量最多的数字资产服务商之一，在美国、日本、泰国、直布罗陀等12个国家和地区设有子公司或合作公司。 **知道创宇区块链安全实验室** 拥有国际顶级的区块链安全专家团队、9年头部区块链企业安全服务经验，已为全球多家领先的数字货币交易所、钱包、底层公链、智能合约等项目进行安全审计及防御部署，在区块链技术安全、风控安全、防黑客安全保持着国内领先的核心竞争力。创宇实验室相信通过此次合作，能为 Huobi Global 提供更好的安全保障，更大程度地保证平台安全，保障用户资产安全。  
  
目前，知道创宇安全实验室提供**智能合约安全审计、交易所安全审计、公链安全审计、联盟链安全审计、钱包渗透测试、Web渗透测试、钱包密码找回、数字资产安全托管、数字资产追踪溯源、数字资产风控防火墙、AML风控防火墙、区块链威胁情报、区块链舆情监测、安全咨询、安全应急响应**等服务。
