说起来“黑客”这个名词第一次接触是在七年级吧，那个时候在一个很小很狭隘的乡村补课，也是那个时候学校“发”的校园卡，类似于一个定位装置，一个tcl手机一张手机卡，还有一个据说可以不通电就能定位的卡片，宣传的可玄乎，在那个暑假，毫无疑问的我报了暑假班，虽然天天摸鱼（不得不说初中的东西确实简单）那个拥挤的教室在疯狂地燃烧补课老师的经费，如果没记错的话只有一个大风扇，人手一个手机，我们大概25个人左右，一个路由器都没有，只能连隔壁的一个WiFi（ph开头的叫斐讯），两格左右的信号，我想，那应该是路由器超负荷工作最惨的一段时间，还好有我，要知道人在情绪特别激动的时候容易蹦出来想法，有个UC浏览器，直接搜手机WiFi屏蔽器，结果还真有，是外国的作者写的攻击工具WiFikill能攻击同一局域网的IP需要root权限连电脑直接root，第一次称霸局域网，说实话很多人需要的动力是成就感![](../Images/b8c85d7bce71033a7fc32e66341b2a3b.png)

![](../Images/8f9e1d7e5e5012016ba2a965c628ec45.png)

说实话后来做了个硬件的WiFi杀手  

![](../Images/846a47ccdf7de8850ea6be4b9a7342c3.png)

这个威力更强，方圆20米有热点就能搞，ESP8266那个文章有我写的详细教程

也是那个时候我在某群知道了有存活主机和rouji ,c   java  sql注入 和易语言，当年那群挂黑页的估计都是安全专家了吧（虽然有几个进去的），只不过我那时年少贪玩沉迷网游，追悔莫及  

![](../Images/b3f1dea38983e00b05ea409bad648137.png)

再说高中，初中毕业去工地体验生活，三入三出工地，高中也是擦边进的，有幸当了一次凤尾

![](../Images/a078d402ee6bd1a9e609588afffb72e3.png)

在里面学的人情世故，学会了为人处世，高中看编程一心二用吧，没咋听过课，还有当班委的原因，事实上主线是上学，直至现在我依然感觉上学是副本，因为是半桶水多一点，不至于太差所以不太重要，混学历，撑排面，副线打比赛拿证书练技术，提升自己的筹码，总有人把学习和上学混为一谈，活到老学到老才是学习，就拿我认识的人来说初中没上完的基本都是拜师学技术让自己有竞争力，光看学历也不太现实，要考核，硬实力才是真道理  

![](../Images/e34311a9292f23783217ce60a8f8a0c4.png)

。。。。。。。。。。继续滑下去看公鸡下了几个蛋![](../Images/b8c85d7bce71033a7fc32e66341b2a3b.png)

  

  

  

从刚进这个所谓的大学，迷茫了，说实话，不是没有目标，是因为太贪心，啥都想学，有点选择恐惧的感觉，也是遇见形形色色的人，但我从开始到现在没看到一个能长久发展的伙伴，因为网络安全算是后起之秀，其次门槛极高，入个门快的得一两年，怎么说，也是各种机缘巧合，参加了几场比赛，  

可以说是鱼龙混杂，或者换句话说标题内容不符（简称：图片仅供参考）

这个比赛也是机缘巧合，因为当时在搬砖，顺便锻炼身体，然后看的群消息，报的名，实际上的参加的第一个比赛![](../Images/b8c85d7bce71033a7fc32e66341b2a3b.png)虽然PPT做的很炫酷绿色背景（致敬黑客帝国）

就这种

![](../Images/dcf525334c60ba08d7716c8e30dd9263.png)

在之前PPT领导初审过了然后几经波折，PPT改PPT一直改二十几次吧，最后又让改成了视频视频也是各种毛病加片头加背景音乐加片尾，期间拜访了五六个人，反正过程极其繁琐，好在是个二等，也学会了用剪辑软件  

再者电脑也经常出各种问题蓝屏早已经是家常便饭，全都自己解决不百度

有问题先拆后盖断电拔内存

![](../Images/36dc706cdf2e096cf1a505125b9e61b3.png)

就这个，还算可以，（学校环境真的可以）；在这三个比赛前两个，网络安全我只看到了网络，安全只占20%左右![](../Images/b8c85d7bce71033a7fc32e66341b2a3b.png)

标题改为“运维大赛”比较合适，运维管理的权重比较大。  

我个人也在积极像群里大佬靠拢，像以前止步不前，原地踏步，那我现在的状态就是在原地仰卧起坐，自强不息![](../Images/b8c85d7bce71033a7fc32e66341b2a3b.png)

也可能是圈子的缘故，看不到特别优秀的人，我本人也承认我并不优秀，身边的人水平相差无几，这就是所谓的舒适圈，于是决定跳出去看看外边的世界，虽然可能被虐的\*\*\*\*，但当鸡头的就像体验体验凤头的感觉，从那一次我就不再是井底之蛙，我很庆幸这几次比赛，让我摸清了自己几斤几两，也搞清楚了自己的定位，也非常谢谢我的指导老师，让我跳出了自己的圈子认识了好多人![](../Images/b8c85d7bce71033a7fc32e66341b2a3b.png)，也希望同行越来越卷，站的高才能一览众山小，兄弟们砥砺前行吧
