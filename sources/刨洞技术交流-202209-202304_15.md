`Nuclei`是基于`YAML`模版文件的概念，这些模版文件定义了如何发送和处理请求。这使得`Nuclei`具备了易于扩展的能力。这些模版是用`YAML`编写的，它指定了一种简单的人类可读格式，以快速定义执行过程。

id

  

编写模板第一行定义的就是`id`，每个模版都有一个`唯一ID`，输出写入过程中用于指定输出行的模版名称。模版文件以`.yaml`扩展名结尾

```
*id: xxxx-sql*
```

例如，下面的这个`POC`，`id`为 nginx-version

![](../Images/aa07f490e264ba90f8ffac45a0d38630.png)

  

使用这个`poc`扫描的结果，开头显示的就是我们定义的 `id`值

  

![](../Images/d643332c73c4a97422f7ee58b1925964.png)

  

我们尝试把`id`修改成 nginx-version-test

  

![](../Images/116f196a576bca728d3e5b9328533ae0.png)

  

再来看我们的输出，也已经跟着改变了

  

![](../Images/50ed4bc45c2727849fc23c0f862a6048.png)

  

注意点：`ID`不能包含空格；这样做是为了更容易的进行输出解析

  

Info

  

关于模版下一个重要信息就是`info`，它提供了`name`,`author`,`severity`,`description`,`reference`,`tags`和`metadata`。它还包含了指示`POC`严重程度的严重性字段

```
*

info:*
```

`reference`是`info`中常用的标签，用于定义模版的外部参考链接

```

```

`info`中要添加另一个有用的标签是`tags`，它允许您为模版设置一些自定义标签，比如`CVE`、`RCE`等。这使得`nuclei`能够识别带有你输入标签的模版，并且只运行带有这些标签的模版

![](../Images/78849aac4b419f708d626781706ecfa3.png)

  

使用`--include-tags`参数可以设置只运行指定的标签模版

  

![](../Images/9505551bb746af4725c9104ae16efebf.png)

  

`info`块的示例：

```
*

info:*
```

在前端显示的漏洞严重程度标签，就是由`info`下的`severity`标签定义的

  

![](../Images/626d72cc8db05e1df52a3390bcd20a5f.png)

  

很方便的一点是，你可以与你的队友或者安全团队共享你编写的`nuclei`模版，以便轻松的在其他地方复现问题

  

![](../Images/8a88b0d63600a0369065636d9d1e694a.png)

  

  

Metadata

  

在`nuclei`中，`metadata`是一个可选的模板项，用于提供一些额外的信息，以便过滤或分组扫描。

  

`metadata`项可以包含多个键值对，例如：

```
*

info:*
```

这样的`metadata`项表示该模板适用于`WordPress 5.8.2`版本的`CMS`以及一些其他搜索引擎的举例：

  

```
*

info:*
```
