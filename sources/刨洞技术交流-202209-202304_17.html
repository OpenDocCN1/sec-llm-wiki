进攻性安全发布了 Kali Linux 2023.1，这是 2023 年的第一个版本，也是该项目的 10 周年纪念日，推出了一个名为“Kali Purple”的新发行版，针对蓝色和紫色团队进行防御安全。

Kali Linux 是一个专为道德黑客设计的发行版，用于对网络进行渗透测试、安全审计和网络安全研究。

在此版本中，Kali Linux 团队引入了各种新功能，包括：

  • 蓝色和紫色团队的紫色

  • 八种新工具！

  • 有关 Python 更改的警告

  • 主题

  • 等等！

介绍

作为今天Kali Linux版本的一部分，Kali Linux团队还宣布了一个名为“Kali Purple”的新项目，这是一个专为防御性安全而设计的发行版。

“多年来，我们已经完善了我们的专长，即进攻性安全。我们现在开始涉足一个新的领域，防御性安全！“今天的公告解释道。

“我们正在对”Kali Purple“进行初步技术预览预发布。这仍处于起步阶段，需要时间才能成熟。但你可以开始看到Kali正在扩张的方向。你也可以成为帮助塑造方向的一部分！

这个新的发行版仍处于早期阶段，但已经包括100多个防御工具，包括Malcolm，Surricata，Arkime，TheHive和Zeek，以及一个专门的Wiki来帮助您入门。

Kali Purple可以作为x64 / AMD64系统的ISO下载。

Kali Linux 2023.1 中的八个新工具

这将是一个没有新工具的无聊的Kali Linux版本，这个版本带来了八个新工具，包括CyberChef和Arkime。

以下是 Kali 2023.1 中添加的八个新工具：

  • Arkime - 一个开源的数据包捕获和搜索工具。

  • CyberChef - 被称为“网络瑞士军刀”，CyberChef允许您使用各种工具分析，解密，去混淆和解码数据（您可以在此处查看在线版本）。

  • DefectDojo - 一个开源应用程序漏洞管理关联和安全编排工具。

  • Dscan - “分布式 Nmap，围绕 Nmap 的包装器以允许分布式网络枚举。

  • Kubernetes-Helm - 一个开源的 Kubernetes 包管理平台。

  • PACK2 - “密码分析和破解工具包”。

  • Redeye - “Redeye 是一种工具，旨在帮助您在渗透测试操作期间以最有效和最有组织的方式管理数据。

  • Unicrypto - “某些加密算法的统一接口”

Python 更改和警告

Kali 团队警告说，有许多 Python 更改与 Debian 即将发布的稳定版本相吻合。

“Debian 正准备推出下一个稳定版本（大约每 2 年发布一次，看起来可能是今年夏天），”Kali 团队解释道。

“因此，包裹到处都在更新。活跃的软件包维护者正在将他们的工作升级为最新版本，否则，下一个版本需要等待很长时间！

但是，这些更改可能会导致 PIP 出现问题，导致 Kali 团队引入一个临时补丁，以防止包管理器破坏系统范围。

该团队还分享了另外三种更新包的方法，以防止系统范围的包管理系统中断。

主题

与今年的所有第一个版本一样，Kali 引入了主题更新，其中包括新壁纸、启动屏幕和登录/锁定屏幕，包括新的 Kali 紫色壁纸（左下角）。

Kali Linux 还添加了一些桌面更改，对 Xfce 4.18（2022 年 5 月发布）进行了一些调整，并添加了 KDE Plasma 27.<>。

英伟达警告

Kali 团队警告说，此版本在使用 NVIDIA GPU 的设备可能存在问题，系统会导致操作系统变慢、无响应或完全冻结。

“对于英伟达用户来说，这个版本可能不是有史以来最好的。众所周知，525系列的Nvidia驱动程序会与某些GPU型号相撞，“Kali发行说明解释说。

“我们不知道究竟是哪一个，但基本上所有开始分发这些驱动程序的Linux发行版都有各种报告，包括Debian，Ubuntu和Arch Linux。我们都受到了影响，Kali Linux 也不例外。

如果您遇到任何这些症状，您可以通过执行以下命令来删除 NVIDIA 驱动程序：

sudo apt purge "*nvidia*"
sudo reboot -f


如何获得 Kali Linux 2023.1

要开始使用 Kali Linux 2023.1，您可以升级现有安装、选择平台或直接下载 ISO 映像（也是 Kali 紫色）以进行新安装和实时分发。

对于从以前版本更新的用户，可以使用以下命令升级到最新版本。

echo "deb https://http.kali.org/kali kali-rolling main non-free contrib" | sudo tee /etc/apt/sources.list

sudo apt update && sudo apt -y full-upgrade

cp -rbi /etc/skel/. ~

[ -f /var/run/reboot-required ] && sudo reboot -f

如果您在适用于 Linux 的 Windows 子系统上运行 Kali，请升级到 WSL2 以获得更好的体验，包括对图形应用程序的支持。

您可以在 Windows 命令提示符下检查 Kali 使用的 WSL 版本和“wsl -l -v”命令。

完成升级后，可以使用以下命令检查升级是否成功：

grep VERSION /etc/os-release
