WebApi说明

查看代理池情况：

*   

```
`http://127.0.0.1:8080/`
```

  

获取代理

*   
*   
*   
*   
*   
*   
*   
*   

```
`http://127.0.0.1:8080/get?type=HTTP&count=10&anonymity=all``可选参数：``type        代理类型``anonymity   匿名度``country     国家``source      代理源``count       代理数量``获取所有：all`
```

  

删除代理

*   
*   
*   
*   

```
`http://127.0.0.1:8080/delete?ip=127.0.0.1&port=8888``必须传参：``ip      代理ip``port    代理端口`
```
