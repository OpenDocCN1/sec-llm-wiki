据报道，GPT3.5 的训练使用了微软专门建设的 AI 计算系统，由 1 万个 V100 GPU 组成的高性能网络集群，总算力消耗约 3640 PF-days (即假如每秒计算一千万亿次，需要计算 3640 天)在上周二，微软推出结合了 ChatGPT-4 的全新 Bing 搜索引擎，相比于之前的ChatGPT，他使用的模型更加的先进，最重要的一点是他能够使用最新信息更好地回答搜索查询，知道最新的事件热点，而不是停留在2021年以前！  
申请条件—

```
`注册或已拥有一个微软账号``使用电脑安装最新稳定版 Edge 桌面浏览器``跟着教程操作，核对好输入信息，耐心等待资格通过`
```

关于网络问题的说明：*微软的服务，本身是可以直接访问的，不需要梯子，但是由于各地运营商比较复杂，访问会变慢，主要体现为转圈等待，请耐心等待，尤其是下载插件和登录微软账户时。*  
  
下载 Microsoft Edge—  
直达地址：*https://www.microsoft.com/zh-cn/edge/download?form=MA13FJ*下载 Microsoft Edge，选择适合你系统的安装包进行安装![](../Images/a2a0b4dfb5ad5346a22e033cad652fcd.png)  
  
安装插件 ModHeader—  
在 Edge 自带的插件中心，搜索 ModHeader直达地址：*https://microsoftedge.microsoft.com/addons/detail/modheader-modify-http-h/opgbiafapkbbnbnjcdomjaghbckfkglc?hl=zh-CN*点击「获取」进行安装，安装完成会弹出软件介绍页面可直接关闭，进行下一步![](../Images/d580ef8b5dfbfd683a4a5b95b6e651ef.png)点击插件，开始创建规则（注：若插件安装完不显示，点击插件按钮，点亮小眼睛）![](../Images/4e27b97881c4831a4cc40c5ac7ca0139.png)  

*   
*   

```
1.假装 HK 地区访问，左边填入 X-Forwarded-For，右边填香港 IP 段 1.36.x.x，比如 1.36.2.22.设定规则针对 Bing 生效，点击「FILTER」，选择「URL filter」，填入 .*://www.bing.com/.*
```

![](../Images/4dcd22eb236418087e891caedaedf73a.png)设置完成后检查一下是否能访问原版 Bing  

*   
*   

```
1.访问时插件图标会显示 1，代表生效一个规则。若未显示，需要检查上一步规则是否填写正确。2.并且不会跳转 cn.bing.com 国内特供版
```

![](../Images/afb93c043c7b5ccea6f823f89cf6219f.png)都设置成功后就登录你的微软账号，并设置地区  

*   
*   

```
1.设置地区为非大陆地区，建议选择「香港特别行政区」和 IP 对应2.在此之前已经登录的用户，更需要检查地区是否为大陆，是则需要手动进行切换。
```

![](../Images/e5fe3aa31acc1adbe9de43095b88ce24.png)  
  
加入新必应

*   
*   

```
1.访问 www.bing.com/new 点击「加入等待列表」2.若未会要求登录，若已登录账号但不显示登录状态则刷新页面，重新点击加入3.加入候选后，页面会更新为「你已加入候选名单」，并且会收到微软发来的邮件
```
