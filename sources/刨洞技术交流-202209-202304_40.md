# Windows10渗透集成环境 v4.0发布!

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzk0OTM5MTk0OA==&mid=2247484268&idx=1&sn=8fd9cfc5698dc389ca98dcc05a88257d&chksm=c358444ff42fcd59281ff2bca32c00cdd6caefe2cfe5167e70d6cafb8853cc00806ae0c48d73&scene=126&sessionid=1681666706#rd](http://mp.weixin.qq.com/s?__biz=Mzk0OTM5MTk0OA==&mid=2247484268&idx=1&sn=8fd9cfc5698dc389ca98dcc05a88257d&chksm=c358444ff42fcd59281ff2bca32c00cdd6caefe2cfe5167e70d6cafb8853cc00806ae0c48d73&scene=126&sessionid=1681666706#rd)

本项目制作的初衷是帮助渗透新手快速搭建工作环境，工欲善其事，必先利其器。

  
  
系统简介—  

*   
*   
*   
*   

```
基于Win10 Workstation 21H2 x64 原版镜像制作（不适用于ARM设备）；完整安装WSL Kali Linux 2022.3；精简系统自带软件，美化字体及部分图标，适度优化；使用单磁盘文件存储，提升性能；
```

  
建议运行环境—  

*   
*   
*   

```
vmware:16.x（vmware图形内存1G）运行内存:8G固态硬盘:200G
```

  
更新说明—  

*   
*   
*   
*   
*   
*   
*   
*   
*   

```
由于Kali的图形化模式占用资源造成卡顿，且使用率不高，特此去除图形化模式
补充了大量实用工具，升级部分软件为最新版；重构了“漏洞工具” 的目录分类，查找更方便快捷；重构了开始菜单及快捷启动索引；
今后的更新方式:添加或升级软件等小幅更新会同步在迅雷网盘发布软件安装包；重大升级更新或迭代会重新制作虚拟机镜像。
```
