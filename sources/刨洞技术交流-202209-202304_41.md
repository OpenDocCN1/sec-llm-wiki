# 刚出的outlook后渗透信息收集工具

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzk0OTM5MTk0OA==&mid=2247484251&idx=1&sn=84fa5c521892c71de094d5312250bf0b&chksm=c3584478f42fcd6e11b9b40c35fb76f9389ece173c0eec74aa0807f34897c268f5bb92705972&scene=126&sessionid=1681666710#rd](http://mp.weixin.qq.com/s?__biz=Mzk0OTM5MTk0OA==&mid=2247484251&idx=1&sn=84fa5c521892c71de094d5312250bf0b&chksm=c3584478f42fcd6e11b9b40c35fb76f9389ece173c0eec74aa0807f34897c268f5bb92705972&scene=126&sessionid=1681666710#rd)

几个小时前开源的一款 Burp 插件，用于 Outlook 用户信息收集，在已登录 Outlook 账号后，可以使用该插件自动爬取所有联系人的信息  
  
  
获取所有用户—  
Burp 加载插件后，进入 Outlook 联系人面板，点击 All Users![](../Images/aa21b41efc9ed1e4d0dd61ee5ad392ae.png)在 Burp 中 Proxy -> HTTP history 筛选 api 接口

*   

```
`/owa/service.svc?action=FindPeople&app=People`
```

![](../Images/628c70338593ef94fb90373b69abd984.png)选中该请求，右键菜单 Extensions -> OutLook information collection -> Do OoutLook Email scan![](../Images/07ed0e064e54fbaeff2f7915ad399bfa.png)插件会自动爬取所有数据包并生成目录树，可以查看每一个请求响应包  
![](../Images/e3a706e77efc549c39fd4b56620d9e0b.png)右击该请求会弹出右键菜单，选择获取所有用户邮箱，即可获得所有的邮箱![](../Images/5c7e1b3025a4da49efa35666e6082982.png)提取结果![](../Images/34614d4933a24048469188f45440020d.png)  
获取联系人信息—  
必须在加载 All Users 的所有数据包才能正常使用，联系人信息基于 All Users数据包信息在 Burp 中 Proxy -> HTTP history 筛选 api 接口

*   

```
`/owa/service.svc?action=GetPersona&app=People`
```

![](../Images/eca4884da3c7a181f097f645bafec75c.png)选中该请求，右键菜单 Extensions -> OutLook information collection -> Do OoutLook Email scan![](../Images/25924e94262f4f2130ab1df84095e010.png)插件会自动爬取所有数据包并生成目录树，可以查看每一个请求响应包  
![](../Images/bf5f097ca3cf0200190f654445921373.png)右击该请求会弹出右键菜单，选择获取 All User 个人信息，可获取所有联系人信息![](../Images/3adc2cb06eeff0908e30d5298ad0eb34.png)提取结果![](../Images/7c7ba86a0dca46103553b6d2417bb7ad.png)
