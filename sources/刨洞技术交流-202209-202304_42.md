欧拉一号是一套模拟企业内网环境的渗透靶场，其中包含共五台靶机，其中 Linux三台、Windows 两台。入口点为一台 Linux 靶机，获取权限后可以通过内网访问其他靶机

为了减少对 nps主机的网络压力，这里使用 nps 的 p2p 模式转发端口

![](../Images/2790a8f83dfeab2a416f7252dd12b90c.png)

靶机上执行  

![](../Images/62e86ec909d5e5af60cdc9cc4952d43a.png)

因为反弹 shell 的 payload 有一些特殊字符，先使用 base64 编码一下  

![](../Images/275fed3379e3c9d1f5ee3923943ca813.png)

然后使用 php 的 base64\_decode 函数解码后执行  

![](../Images/4ac5fe443ec27283b51b56f36fe0d167.png)

成功反弹 shell，但只是一个 nginx 权限，flag 路径在 root 目录下，要读取 flag 需要提权  

![](../Images/76b5fb957e84f2a22bace6b86c9e6a42.png)

跑一下 linpeas.sh 看看能从什么地方进行提权

![](../Images/5d1df61c0bc4a245810d3cb04242cc5c.png)

发现一个 catcat 账户  

![](../Images/e810b11df8cd6527ff5a30230242d62c.png)

还找到一个密码，

![](../Images/52932a418025d97072fcef409fd4a9e7.png)

找了一下，密码是出自网站根目录的 config.php 文件，但是 db\_username 是 catcat

![](../Images/c87fa08ae234ee7ca3eb6a9fa1dfc0c6.png)

会不会是通用密码呢？验证一下试试

![](../Images/6c3a7a7a31dc6bfa8a94418c5710a3f8.png)

成功登录 catcat 账户，再跑一遍 linpeas.sh 也没发现什么有趣的东西，那跑一下 pspy 看看

![](../Images/572dfdb3c00176743668df5a98285142.png)

可以看到 root 的定时任务每分钟都会执行一次 catcat 账户目录的 backup.sh 脚本，那么我们只要改掉这个脚本就可以拿到 root 权限了

![](../Images/bb37f5a7fc1a2509621bbfb5237f4c68.png)

![](../Images/b793be5917a709873f2640b13e285b3a.png)

这里我们给 /bin/bash 加上了 SUID 权限，由 GTFOBins 可知当 /bin/bash 有 SUID 权限时，我们可以通过它提到 root 权限

![](../Images/7960ea6be8bcdd0b6eb7281c33ca4aba.png)

可以看到 euid 变成了 root，成功读到了 flag
