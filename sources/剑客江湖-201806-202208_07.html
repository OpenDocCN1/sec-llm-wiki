HackMyVM 是一个共享易受攻击的VM 和知识的平台，给想要学习和测试他们的黑客技能的人。所以可以免费注册，下载易受攻击的 VM 并开始玩耍！ 并且有一个排名和一些奖杯给喜欢 “竞争”的人，不是公司，只是一个热爱学习和学习的社区。

首先我们下载了一个名为gift的靶机

难度：简单

这是一个非常简单的盒子，我们所要做的就是进行 SSH 蛮力攻击。这将为我们提供一个 root shell。让我们来玩吧！


实战开始

首先我们需要确认目标机IP

使用netdiscover进行网络发现

# netdiscover -i eth0 -r 192.168.1.0/24 

目标机：192.168.1.109


端口扫描

我们将使用nmap工具，-sV启动版本扫描，-sC启动默认脚本进行扫描

# nmap -sV -sC -p- 192.168.1.109  

由上图可以看到有两个服务正在目标机器上运行。22(SSH)和80(HTTP)。由于我们没有SSH的登录凭证，我们将从HTTP服务进行入手。

枚举

为了枚举HTTP服务，我们在web浏览器上打开目标机器的IP地址，查找一些有用的东西。

从主页上，它告诉我们不要想得太多。真的，很简单。然后我们F12查看有没有其他的隐藏信息我们获得了“ Trust me”，让我们相信它。按照以往的经验，肯定不能这样放过它。

枚举

接下来我执行了 dirsearch 扫描以查找隐藏的文件或目录。

dirsrarch -u http://192.168.1.109

好吧，我现在信他的话了。除了index.html别的啥也没有。

SSH爆破

所以让我们来做最简单的事情，那就是暴力破解 root 密码。

# hydra -l root -P /usr/share/wordlists/rockyou.txt ssh://192.168.1.109

经过一段时间的爆破得到了root用户密码“simple”，现在我们进行登陆。使用root用户访问系统。

ssh root@192.168.1.109

登录成功

然后进行查找flag

ls -la

两个文件1.root.txt，2.user.txt

cat root.txt #得到root-flagcat user.txt #得到user-flag

现在进行提交我们获取的flag进行提交就可以了。
