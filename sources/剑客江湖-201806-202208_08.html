在本文中，我们将学习如何使用 Dirsearch，又名网络路径扫描器。它是一个简单的命令行工具，旨在暴力破解网站中的目录和文件。这是一个基于 Python 的命令行网站目录扫描器，旨在暴力破解站点结构，包括目录和文件。



安装和使用

要求：python 3.7 或更高版本

选择以下安装选项之一：

  • 使用 git 安装： 

    git clone https://github.com/maurosoria/dirsearch.git

  • 使用 Kali Linux 安装： 

    sudo apt-get install dirsearch

  • 使用 PyPi 安装： 

    pip3 install dirsearch

本次使用的kali系统，所以直接使用 apt-get install dirsearch 。安装此工具后，我们需要浏览其目录并搜索 dirsearch。现在，我们只需要使用 [-h] 参数运行这个 python 编写的工具，通过这个我们可以看到它的所有参数及其功能。

dirsearch -h

扫描目标站点

接下来我们需要进行一次完整的扫描，在上图中我们可以看[-u]参数是指定一个URL目标进行web内容扫描。

dirsearch -u http://testphp.vulnweb.com/

从截图中我们可以看出最上面被圈起来的，默认扩展[php,aspx,jsp,html,js]，默认HTTP方法是[GET]，默认线程是[30]，默认字典列表大小[10877]。这些东西在目录扫描攻击中会起到重要的作用。

实现完整URL

常规扫描只会显示目录后缀，但并不会有完整的路径，这个时候我们可以使用[-full-url]的参数，此参数可以帮助我们轻松的浏览这些结果。

dirsearch -u http://testphp.vulnweb.com/ --full-url

箭头指引可以看出，此次列出了完整的url路径信息。

状态码&指定文件扩展名

[-i]参数表示包含状态，可列出我们只需要的状态代码。多的用逗号隔开

dirsearch -u htt://testphp.vulnweb.com/ -i 200,301

[-x]参数可排除某些HTTP状态代码。它会删除不需要的状态码，它和指定扩展是相反的。

dirsearch -u http://testphp.vulnweb.com/ -x 301，403


1XX
Informational信息性状态码，表示接受的请求正在处理
2XX
Success成功状态码，表示请求正常处理完毕
3XX
Redirection重定向状态码，表示需要客户进行附加操作
4XX
Client Error客户端错误状态码，表示服务器无法处理请求
5XX
Server Error服务器错误状态码，表示服务器处理请求出错

[-e]参数可指定要搜索的文件扩展名。

[-X]参数 --exclude-extensions带有扩展名列表将删除包含给定扩展名的单词列表中的所有路径

dirsearach -u http://testphp.vulnweb.com/ -e php -x 403

QUIET 模式

安静模式以更安静的方式用于运行 dirsearch。如果您不想要一个巨大的横幅来告诉每个人您在您的系统上做什么，那么您会喜欢这个选择。基本上，这可以在执行您发送的命令时让屏幕更干净。

只需将此 [-q] 参数与此命令一起使用即可查看结果

dirsearch -u http://testphp.vulnweb.com/ -q



自定义字典

[-w]此参数可以自定义爆破字典。

dirsearch -u http://testphp.vulnweb.com/ -w /字典位置


以不同格式输出保存

我们可以以不同的格式保存我们从攻击中获得的输出，以便进一步学习。这个参数帮助我们了解这些格式的那些细节。

simple格式保存

我们可以在参数的帮助下以简单的格式保存我们的扫描结果。这样我们可以更好的分析我们从这次扫描的结果。

dirsearch -u http://testphp.vulnweb.com/ -o /输出文件名称.格式

创建此报告后，我们可以验证其在系统中的位置。现在使用命令nano查看此报告

我们可以清楚地看到，我们的简单格式结果已经成功创建。现在，我们可以轻松地分析我们的结果

将输出保存为 JSON 格式

JSON 是一种开放的标准数据交换和文件格式，它使用人类可读的文本存储和传输由属性值对和数组数据类型组成的数据对象。它是一种非常常见的数据格式，用途广泛，例如在 AJAX 系统中用作 XML 的替代品。使用这种方法，我们只需按照这些命令就可以构建这种输出结果格式。

dirsearch -u http://testphp.vulnweb.com/ -o /输出文件名称.json

与前一种情况一样，我们使用命令nano开始分析我们的结果即可。

以 XML 格式保存输出

可扩展标记语言 (XML) 是一种标记语言，它指定一组人类和机器可读的规则，用于以某种格式对文档进行编码。使用一些命令，我们可以使用此工具构建 XML 格式的结果副本。

rsearch -u http://testphp.vulnweb.com/ -o /输出文件名称.xml

同上情况，使用nano分析即可，其他还支持

plain,  md, csv格式。

POST方法

我们知道，对于给定的资源，HTTP 定义了一组请求方法来指示要执行的所需操作。

但是在post方法中，POST是万维网使用的一种支持HTTP的请求方法。POST 请求方法在设计上要求 Web 服务器接受包含在请求消息正文中的数据，最有可能存储它。它通常与 GET HTTP 方法一起使用，该方法在名称或值对中用于将表单数据附加到 URL。如果您使用 GET，则 URL 长度将保持受限。这使用户能够提交书签的结果。

现在，我们正在此命令的 [-m] 参数的帮助下探索另一面。

与我们之前执行的 GET 请求方法相比，这些结果是不同且独特的。它显示了一些不同的网页和网页目录。

dirsearch htttp://testphp.vulnweb.com/ -m POST

代理

dirsearch 支持 SOCKS 和 HTTP 代理，有两个选项：代理服务器或代理服务器列表。

dirsearch.py -u https://target --proxy 127.0.0.1:8080dirsearch.py -u https://target --proxy socks5://10.10.0.1:8080dirsearch.py -u https://target --proxylist proxyservers.txt

线程

我们可以增加或减少线程数。这将根据我们提供的线程数量增加或减少我们的攻击速度。正如我们之前在 URL 攻击中看到的，默认情况下线程数设置为 30。

dirsearch http://testphp.vulnweb.com/ -t 100
