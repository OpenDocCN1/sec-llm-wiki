Ubuntu中安装使用nessus的方法

第一步：从官网下载nessus的deb包，官网地址为：

https://www.tenable.com/downloads/nessus?loginAttempted=true

第二步：将deb上传到ubuntu中。注意：我这里的ubuntu是虚拟机。

第三步：在ubuntu中安装nessus的deb包。注意包放的路径。

命令：

sudo dpkg -i Nessus-10.4.1-ubuntu1404_amd64.deb

安装的目录为/opt/nessus

第四步：启动nessus服务，并在浏览器中进行访问。

 命令：

systemctl status nessusd.service 查看nessus服务运行状态systemctl start nessusd.service 启动nessus服务systemctl stop nessusd.service 关闭nessus服务

第五步：通过浏览器进行访问。默认端口为8834。注意需要使用https进行访问。选择Managed Scanner项，点击continue按钮。

选择Tenable.sc，单击continue按钮，进行下一步操作。

输入账号密码，选择提交。

进行安装，等待安装完成。

安装完成进入配置页。

第六步：离线激活nessus。通过官方提交试用信息，之后邮箱会收到激活码。激活地址如下：

https://zh-cn.tenable.com/products/nessus/nessus-essentials

注册完成后，邮箱会收到相应的激活码。

进行离线激活，切换到/opt/nessus/sbin目录下，看到有三个文件，分别是nessuscli、nessusd、nessus-service。

使用nessuscli工具获得询问码，命令为:

sudo ./nessuscli fetch --challenge

输入之后会得到一个challenge code，这就是询问码，还会得到一个网站，访问该网站进行下一步工作。网址如下：

https://plugins.nessus.org/v2/offline.php

点击提交按钮，会得到你的license。上面的链接地址是漏洞库插件，可以点击选择下载该插件。

将下载下来的插件包放到虚拟机中。将插件包放到/opt/nessus/sbin目录下。

使用nessuscli工具更新插件包。

看到显示update seccessful说明更新插件成功。更新成功后在version后有一串代表时间的数字串，如图中为202210071240，记住此数字串，后面需要用到。

回到nessus设置页面，进行手动激活。

点击Activation Code 后面N/A后的小笔。选择Offline，在下方的空白处填写license。license可以从网页中复制，也可以从下载的license文件中复制，是一样的。如下图所示：

点击activate，返回到登录页面，重新登录。

此时已经可以扫描，但是只能扫描16台主机，接下来我们要破解主机数量的限制。

第七步：此时我们需要修改一些文件，先把nessus服务停止掉。命令为：

sudo systemctl stop nessusd.service

此时我们需要在虚拟机中进行操作，创建一个文件，文件名为：plugin_feed_info.inc

文件件内容为：

PLUGIN_SET = "202210071240";PLUGIN_FEED = "ProfessionalFeed (Direct)";PLUGIN_FEED_TRANSPORT = "Tenable Network Security Lightning";

注意：第一行的时间为更新插件包时产生的时间数字串

将修改后的文件放入到下面的两个目录中，分别为

/opt/nessus/var/nessus//opt/nessus/lib/plugins/

给该文件赋予只读权限，命令为：

sudo chattr +i /opt/nessus/var/nessus/plugin_feed_info.inc 

给插件包目录下的所有文件赋予只读权限，命令为：

sudo find /opt/nessus/lib/nessus/plugins/ -name "*.*" | sudo xargs -i chattr +i {}

插件数量比较多，可能会比较慢，需耐心等待。

赋予只读权限之后，需要将插件包目录下的inc文件权限取消只读。

命令为：

sudo chattr -i /opt/nessus/lib/nessus/plugins/plugin_feed_info.inc

第八步：此时重新启动nessus服务，登录nessus服务后发现已没有数量限制。已经可以正常使用。
