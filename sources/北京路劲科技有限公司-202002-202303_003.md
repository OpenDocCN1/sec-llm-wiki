# Ubuntu中安装使用nessus的方法

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMjAyODU1NA==&mid=2247491216&idx=1&sn=f0d321c606d0b3a4a387000913b2eb52&chksm=f9d34df5cea4c4e3c2ed3947e3e606cfb6fb92270aa4b787d0a048aeb7927513077b53665e6b&scene=126&sessionid=1681400785#rd](http://mp.weixin.qq.com/s?__biz=MzUyMjAyODU1NA==&mid=2247491216&idx=1&sn=f0d321c606d0b3a4a387000913b2eb52&chksm=f9d34df5cea4c4e3c2ed3947e3e606cfb6fb92270aa4b787d0a048aeb7927513077b53665e6b&scene=126&sessionid=1681400785#rd)

第一步：从官网下载nessus的deb包，官网地址为：

https://www.tenable.com/downloads/nessus?loginAttempted=true

![](../Images/0e5d43078697d6386ec5506f75281feb.png)

第二步：将deb上传到ubuntu中。注意：我这里的ubuntu是虚拟机。

![](../Images/2b9f252445947d33b58ce0589b5ca29e.png)

第三步：在ubuntu中安装nessus的deb包。注意包放的路径。

命令：

*   

```
`sudo dpkg -i Nessus-10.4.1-ubuntu1404_amd64.deb`
```

![](../Images/166c40db4b45c087572abd23ca0832cf.png)

安装的目录为/opt/nessus

![](../Images/edb4a448df041afe46accc3692be9e86.png)

第四步：启动nessus服务，并在浏览器中进行访问。

![](../Images/d470c3b9d5c9e3d020f6d1d2dfb0d857.png)

 命令：

*   
*   
*   

```
`systemctl status nessusd.service 查看nessus服务运行状态``systemctl start nessusd.service 启动nessus服务``systemctl stop nessusd.service 关闭nessus服务`
```

第五步：通过浏览器进行访问。默认端口为8834。注意需要使用https进行访问。选择Managed Scanner项，点击continue按钮。

![](../Images/ed8ddd64e4c2f5ddc4e2685c206b41ec.png)

选择Tenable.sc，单击continue按钮，进行下一步操作。

![](../Images/f7d62eef3be50951a1c714b3db937669.png)

输入账号密码，选择提交。  

![](../Images/78163b26e3a2c7b3d411623fc0c32eb6.png)

进行安装，等待安装完成。  

![](../Images/ea11874964a125e919b66cee566d946b.png)

安装完成进入配置页。  

![](../Images/efd77a075d84d041d733117cf6297629.png)

第六步：离线激活nessus。通过官方提交试用信息，之后邮箱会收到激活码。激活地址如下：

https://zh-cn.tenable.com/products/nessus/nessus-essentials

![](../Images/64037c0a33c2b8bb3c6234ebdac6c9db.png)

注册完成后，邮箱会收到相应的激活码。

![](../Images/4c08cd6c34787a237ea2b87004c1e15c.png)

进行离线激活，切换到/opt/nessus/sbin目录下，看到有三个文件，分别是nessuscli、nessusd、nessus-service。  

![](../Images/df04c4669671fbe9cf5d772bf23a205c.png)

使用nessuscli工具获得询问码，命令为:

*   

```
`sudo ./nessuscli fetch --challenge`
```

![](../Images/24e0698ca17135e7d4720675ab53287c.png)

输入之后会得到一个challenge code，这就是询问码，还会得到一个网站，访问该网站进行下一步工作。网址如下：

https://plugins.nessus.org/v2/offline.php  

![](../Images/e56b3f9e17b9dadc9b850e53120adf2e.png)

![](../Images/c22275eed793f17e6197461035ba8d38.png)

点击提交按钮，会得到你的license。上面的链接地址是漏洞库插件，可以点击选择下载该插件。

![](../Images/7be7e92efe6ad43ee6013eedc6751272.png)

将下载下来的插件包放到虚拟机中。将插件包放到/opt/nessus/sbin目录下。

![](../Images/a5638ade21e741e81f7afac960dabec1.png)

使用nessuscli工具更新插件包。

![](../Images/55c9c4b492530c0eae7e52b932b16883.png)

看到显示update seccessful说明更新插件成功。更新成功后在version后有一串代表时间的数字串，如图中为**202210071240**，记住此数字串，后面需要用到。

回到nessus设置页面，进行手动激活。

![](../Images/431f01a554ea6f2237fb4060aa29d5ce.png)

点击Activation Code 后面N/A后的小笔。选择Offline，在下方的空白处填写license。license可以从网页中复制，也可以从下载的license文件中复制，是一样的。如下图所示：

![](../Images/515da7b9f79ddc31ec934678e0cb98b6.png)

点击activate，返回到登录页面，重新登录。

![](../Images/9ca2bd8c1c5da795f0640a8dce44c8c5.png)

此时已经可以扫描，但是只能扫描16台主机，接下来我们要破解主机数量的限制。

第七步：此时我们需要修改一些文件，先把nessus服务停止掉。命令为：

*   

```
`sudo systemctl stop nessusd.service`
```

![](../Images/c5da3bcffd816523341e2f2382fbb897.png)

此时我们需要在虚拟机中进行操作，创建一个文件，文件名为：plugin\_feed\_info.inc

文件件内容为：

*   
*   
*   

```
`PLUGIN_SET = "202210071240";``PLUGIN_FEED = "ProfessionalFeed (Direct)";``PLUGIN_FEED_TRANSPORT = "Tenable Network Security Lightning";`
```

注意：第一行的时间为更新插件包时产生的时间数字串

![](../Images/b758faf8ef457b36c53652ee36267ad7.png)

将修改后的文件放入到下面的两个目录中，分别为

*   
*   

```
`/opt/nessus/var/nessus/``/opt/nessus/lib/plugins/`
```

![](../Images/e5aa2130c93463b9eeae762e4f810b0b.png)

给该文件赋予只读权限，命令为：

*   

```
`sudo chattr +i /opt/nessus/var/nessus/plugin_feed_info.inc `
```

![](../Images/3900f0f85ea9fcf5c3f0381a0db7cb4f.png)

给插件包目录下的所有文件赋予只读权限，命令为：

*   

```
`sudo find /opt/nessus/lib/nessus/plugins/ -name "*.*" | sudo xargs -i chattr +i {}`
```

![](../Images/afd49b503420d211242c0092febbefee.png)

插件数量比较多，可能会比较慢，需耐心等待。

赋予只读权限之后，需要将插件包目录下的inc文件权限取消只读。

命令为：

*   

```
`sudo chattr -i /opt/nessus/lib/nessus/plugins/plugin_feed_info.inc`
```

![](../Images/1025553f2fb813a7dc60de1fa6514f7f.png)

第八步：此时重新启动nessus服务，登录nessus服务后发现已没有数量限制。已经可以正常使用。  

![](../Images/aec2ac476a212b1ac3bc6e0a688f858c.png)
