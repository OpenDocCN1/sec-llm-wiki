\--> L comment:  my fav line is iamjustic3

```

wpscan --url http://deathnote.vuln/wordpress -e u

gobuster dir -u http://deathnote.vuln/wordpress/ -w ../seclist/../direct-2.3-m.txt -x php,html.txt

查看fake-notebook-rule文件下的内容：

\--> case.wav 和 hint 文件

case.wav是一串十六进制：

```

hint   -> use cyberchef
