# 记一次Tomcat8-弱口令与后台上传getshell的漏洞复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMjAyODU1NA==&mid=2247490778&idx=1&sn=364bf0b657c925a880a3ea2794f5e9e1&chksm=f9d34fbfcea4c6a99375a5fbb8b2c4373ca066e0a2d20ef6462d7a62efa4be947db0e07dd3d1&scene=126&sessionid=1681400806#rd](http://mp.weixin.qq.com/s?__biz=MzUyMjAyODU1NA==&mid=2247490778&idx=1&sn=364bf0b657c925a880a3ea2794f5e9e1&chksm=f9d34fbfcea4c6a99375a5fbb8b2c4373ca066e0a2d20ef6462d7a62efa4be947db0e07dd3d1&scene=126&sessionid=1681400806#rd)

![](../Images/668a193e0580211e370c602428a9e958.png)

  

漏洞形成原因

    Tomcat manager 登录界面存在弱口令漏洞（tomcat,tomcat），登录成功后有上传点，压缩包 xxx.wa r的.war不会被解析，直接访问 xxx/里面的一句话路径，可直接拿到shell。 

  

漏洞如何利用

    msfconsole 中弱口令爆破，爆破成功后登录；找到上传点，上传带有一句话jsp文件的名为xxx.war的包；访问 攻击ip地址/xxx/jsp文件路径，再用 webshell 连接工具进行连接。

 

漏洞复现过程

1、在kaili docker中启动此漏洞

命令：docker-compose up -d

![](../Images/212e70a86ad7ef2b866594d73fc73446.png)

备注：已经启动

2、nmap进行扫描端口

![](../Images/9b3a8fbaa851a02bac5366a2735819c4.png)

3、浏览器访问 Kali 的 ip 地址并接上8080端口

![](../Images/88add69465df8ea288384468a839d9ed.png)

4、进入msfconsole

![](../Images/e18fbbb2a1c01b318bbbf4c7c980d494.png)

5、查找相应的模块命令：search tomcat

![](../Images/589394f2bd3b1ac26c51917fd175d6c5.png)

6、使用这个模块 

use auxiliary/scanner/http/tomcat\_mgr\_login

![](../Images/4ead009cd2576422bcddc32b75ceadb0.png)

7、将rhosts设置为目标主机 set rhosts ip

![](../Images/6e7e4e634503163ed4f45cacd66b9d92.png)

8、run进行爆破 带有+号的即为爆破成功的账号密码

![](../Images/9d451c667c4dafe8abb6cb8dd29aef72.png)

9、点击 Manager App 进行登录

![](../Images/3192dcc40957fafff8f318cf8346f5eb.png)

10、找到上传点

![](../Images/b3ddb910605ae8f0b6cd6337b2997b47.png)

11、将带有一句话的shell.jsp文件压缩成zip，并且将压缩后的zip文件改名为shell.warjsp 一句话木马，密码为rebeyond

![](../Images/fd1f539b45ab806e7643353c479ae159.png)

12、访问kali ip:8080/shell/shell.jsp 无显示

![](../Images/4f334ae9a920d2e5813fd38ed61b978c.png)

13、使用冰蝎进行连接

![](../Images/ecb2dd09390982f0acb15861820e7675.png)
