**域名是什么？**

域名（Domain Name），又称网域，是由一串用点分隔的名字组成的Internet上某一台计算机或计算机组的名称，用于在数据传输时对计算机的定位标识（有时也指物理地址）。由于IP地址具有不方便记忆并且不能显示地址组织的名称和性质等缺点，人们设计了域名，并通过网域名称系统（DNS，Domain Name System）来将域名和IP地址相互映射，是人们更方便的访问互联网，而不用去记住能够被机器直接读取的IP地址串。

**域名的分类以及分级是什么样的？**

域名一般会分为三个级别，分别是顶级域名，二级域名，三级域名。其中顶级域名又分为两类，一类是国家顶级域名，比如.cn，.us，.en等；另一类是国际顶级域名比如表示工商企业的.com，表示网络提供商的.net，表示非盈利组织的.org，表示国际性组织的.int，表示学校教育机构的.edu，表示政府机构的.gov，表示军事机构的.mil等等，以上提到的7个为最初的7个顶级国际域名。

二级域名是指顶级域名之下的域名，在国际顶级域名下，他是指域名注册人的网上名称，比如我们熟知的baidu，tencent，weibo等等。我国在国际互联网络信息中心（Inter NIC） 正式注册并运行的顶级域名是.cn，这也是我国的一级域名。在顶级域名之下，我国的二级域名又分为类别域名和行政区域名两类。类别域名共6个， 包括用于科研机构的.ac；用于工商金融企业的.com；用于教育机构的.edu；用于政府部门的.gov；用于互联网络信息中心和运行中心的.net；用于非盈利组织的.org。而行政区域名有34个，分别对应于我国各省、自治区和直辖市。

三级域名是指用字母（ A～Z，a～z，大小写等）、数字（0～9）和连接符（－）组成，各级域名之间用实点（.）连接，三级域名的长度不能超过20个字符。如无特殊原因，建议采用申请人的英文名（或者缩写）或者汉语拼音名（或者缩写）作为三级域名，以保持域名的清晰性和简洁性。比如im.qq.com，weixin.qq.com这两个分别是QQ的三级域名与微信的三级域名。

**什么是子域名？**

我们通常说的子域名指的是什么呢，子域名在百度百科上的定义是这样的，是顶级域名（一级域名或父域名）的下一级，域名整体包括两个“.”或包括一个“.”和一个“/”。而我们的三级域名以及三级域名以下的，都可以认为是子域名。

**子域名挖掘工具有哪些？**

针对于子域名挖掘的工具有很多，这里我们介绍一下OneForAll这个工具，项目地址为：https://github.com/shmilylty/OneForAll

OneForall基于python3.6开发和测试，需要python版本高于3.6.0才能安装运行，kali目前的python版本已经更新到3.9.2，可以支持OneForAll的安装与使用。

安装使用：

1、首先将项目克隆到本地

git clone https://github.com/shmilylty/OneForAll.git

2、克隆到本地之后，我们首先要安装一下工具需要用到的python模块，在目录中存在一个requirements.txt的文件，里面存放了安装该工具需要用到的模块。

python3 -m pip install -r requirements.txt

3、安装完成所需的模块之后，便可以使用该工具了

python3 oneforall.py --help

![](../Images/f6eb55255a13b43bcdb0fc1b8b38d0e7.png)

需要注意的是，安装完成之后你需要手动进行一些配置的更改，主要的点便是config目录下的api.py文件。当然，不进行配置也可以使用该工具哟。
