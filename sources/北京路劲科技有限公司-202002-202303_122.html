kali学习笔记之微信与WPS的安装

在我们日常使用kali的工作的过程中，我们经常需要使用WPS来进行文档的处理，也需要使用微信来处理消息，在kali中这些软件应该怎么安装呢，今天就跟大家分享一下我们安装使用WPS、微信等软件的安装方法。

前面我们提到过，目前已经有很多软件都有linux版本，那么我们该怎么去下载使用呢，我们可以看到，微信的官方页面之提供了三种方式，分别是网页版、Mac版、windows版，就是没有linux版！当然，全球最大的同性交友网站GitHub上肯定是有的，但是我们这里介绍另外一种方法。

不知道大家有没有听说过深度操作系统，这是一个国产的基于linux的操作系统，今天我们的方法就是从该操作系统的源中进行微信等软件的下载，接下来跟大家分享方法。

首先，我们先修改一下kali的更新源，上篇文章已经详细的讲过方法了，这里我们就简单一提，我的习惯是在/etc/apt/sources.list.d/这个目录下创建一个deepin.list文件，里面存放deepin的更新源。


deb [by-hash=force] https://community-packages.deepin.com/deepin/ apricot main contrib non-freedeb https://community-store-packages.deepin.com/appstore eagle appstore

 

这是2.0版本的商店源，大家有感兴趣的可以去深度官方网站去查找相关信息以及文章哟。

由于kali系统默认只有AMD64的架构，微信支持的是i386架构，因此，我们要先在kali中添加一下i386的架构，命令为

dpkg --add-architecture i386

 

添加完成架构之后，我们来更新一下软件列表，sudo apt update更新你会发现出现缺少公钥的问题，接下来导入公钥就可以了。

导入公钥的命令为

apt-key adv --keyserver hkp://keyserver.ubuntu.com:80 --recv xxxxxxxxxxxxx

注意，这里的xxxxx指的是你缺少的公钥，缺少几个公钥便需要导入几个，导入成功便可以成功更新软件列表了。

 

顺利更新完软件列表之后，便可以下载deepin商店中的软件了，知道其包名便可以进行安装使用了。

安装微信需要的命令是：

sudo apt install com.qq.weixin.deepin

 

如此，便可以安装使用微信了。此时有朋友可能就问了，我按照你的方法装完了，为什么找不到启动微信的图标？在左上角的快速启动中也找不到微信的启动项，这该怎么办呢？

不要慌，我们慢慢来讲。在/下存在一个opt目录，该目录下的apps目录保存了你从deepin商店中下载的软件，我们从deepin源中下载的软件，启动项都在这个目录下面。

根据上图的目录名我们可以清晰的看到，这台kali中安装了网易云音乐、百度网盘、QQ、QQ音乐跟微信，接下来介绍如何将这些启动项添加到快速启动中。以微信为例，我们进入com.qq.weixin.deepin这个目录，可以看到有一个entries目录，进入之后可以看到一个applications目录跟一个icons目录，其中applications目录便存放着微信的启动项，icons目录中存放着微信的图标。此时，我们双击com.qq.weixin.deepin.desktop这个文件便可以启动微信了。

如果每次启动都要这样的话肯定是非常麻烦的，接下来我们只要将这个文件拷贝一份到/usr/share/applications目录下便可以在快速启动中找到启动项了。

日常工作中，我们需要对文档进行处理，在windows下我们可以使用office进行处理，在kali中我们可以安装WPS。当然，linux下也可以安装office，这里我们不进行介绍，感兴趣的朋友可以自己研究，这次只介绍安装WPS。安装WPS就比较简单了，只需要去WPS官网下载包之后再安装便可以了。打开WPS官网后我们选择下载Deb格式的For X64，下载之后使用dpkg -i 下载的包名便可以安装了。

如此，我们便可以使用kali愉快的办公了。欢迎加群一起交流学习网络安全中遇到的问题！
