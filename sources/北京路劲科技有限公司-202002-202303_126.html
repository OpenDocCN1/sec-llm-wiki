什么是vulhub？

Vulhub是一个基于docker和docker-compose的漏洞环境集合，进入对应目录并执行一条语句即可启动一个全新的漏洞环境，让漏洞复现变得更加简单，让安全研究者更加专注于漏洞原理本身。Vulhub的官方地址为www.vulhub.org。

使用之前需要先安装docker环境，这里我们选择使用Ubuntu来进行介绍。此次我们使用的是GitHub上面的vulhub项目，项目地址为：

https://github.com/vulhub/vulhub

首先我们先安装一下python3环境与pip

curl -s https://bootstrap.pypa.io/get-pip.py | python3

如果这条命令不能使用，可以使用下面这两条命令

apt install python3apt install python3-pip

我这里便用的第二种方法进行的安装，接下来安装docker环境

使用

curl -s https://get.docker.com/ | sh

安装完成之后效果应该如下

安装完成之后可以使用docker -v 来查看docker版本

docker安装完成之后，如果环境没有启动，我们便需要启动该服务，命令为

systemctl start docker.service

如果不知道你的docker服务是否启动，可以使用下面这条命令来检查服务状态

systemctl status docker.service

如上图所示便为启动状态。

安装完成docker环境之后还需要安装docker-compose这个工具，该工具需要使用pip进行安装，安装命令如下

python3 -m pip install docker-compose

安装完成之后可以使用docker-compose -v 命令查看版本

安装完成基本环境之后就可以下载靶机环境了，这里推荐两种方式。

第一种是将整个项目都clone下来，命令为

git clone https://github.com/vulhub/vulhub.git

这样的方式可能会比较慢，使用科学上网的方法可以加速下载

第二种方法为使用wget命令单独下载某一个漏洞环境

wget https://github.com/vulhub/vulhub/archive/master.zip -O vulhub-master.zip

这种方法可以针对性的进行复现。

笔者这里用的是第一种方法，将整个项目clone了下来，如下图所示

当我们将环境下载下来之后，就可以使用docker-compose启动环境了，具体方法为

cd activemq          //进入到相应漏洞环境的目录cd CVE-2015-5254docker-compose up -d  //启动该环境

如此，我们便启动了漏洞环境，访问你的靶机地址便可以进行复现操作了。

如果你不知道响应的端口是多少，可以使用下面这条命令来进行查看。

docker-compose ps

当我们测试复现完成之后，可以使用下面这条命令来关闭该环境。

docker-compose down
