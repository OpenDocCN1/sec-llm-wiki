# Windows安装Nessus无限制IP

**简介**

Nessus 是目前全世界最多人使用的系统漏洞扫描与分析软件。总共有超过75,000个机构使用Nessus 作为扫描该机构电脑系统的软件。就我而言：漏洞扫描方面**最**强大的工具**之一**

##   

## **软件特色**

\* 提供完整的电脑漏洞扫描服务, 并随时更新其漏洞数据库。

\* 不同于传统的漏洞扫描软件, Nessus 可同时在本机或远端上摇控, 进行系统的漏洞分析扫描。

\* 其运作效能能随着系统的资源而自行调整。如果将主机加入更多的资源(例如加快CPU速度或增加内存大小),其效率表现可因为丰富资源而提高。

\* 可自行定义插件(Plug-in)

\* NASL(Nessus Attack Scripting Language) 是由 Tenable 所开发出的语言，用来写入Nessus的安全测试选项。

\* 完整支持SSL (Secure Socket Layer)。

**安装 **  

1、到官网https://www.tenable.com/downloads/nessus下载系统对应版本的Nessus，我的是 win 10 x64。然后安装。

2、安装好之后，Nessus 会自动打开浏览器，进入到初始化选择安装界面，这里我们要选择Managed Scanner。

![](../Images/e7521cc21296f492e2c144e909bdb46c.png)

   

3、点击继续，然后这里一定要选择 Tenable.sc。

![](../Images/d8e35cbb70b11d955afbc58be8b69a94.png)

  

4、点击继续，进入到设置用户名和密码界面，设置自己的用户名和密码   

![](../Images/281e02d7fecf4e849e0f1a00eb4659d7.png)

   

5、等待初始化完成，然后退出登录。

![](../Images/9ecf923d524f5adc8bd015c1a3a95b00.png)

  

![](../Images/42641e5c111e03dd84e7971e2ed63ff1.png)

  

6、以管理员权限运行CMD，切换到 Nessus 安装目录，执行命令：nessuscli.exe fetch --challenge 得到 Challenge Code。（这里的Challenge Code 接下来会用到）

![](../Images/d683a2462a4e0fa3b02fd2357be113ed.png)

  

7、注册一个免费的激活码Activation Code，一会儿会用到。https://zh-cn.tenable.com/products/nessus/nessus-essentials

![](../Images/7422124a78f149915151d96d0b09684c.png)

注:激活码会给你发到邮箱里。

 

8、访问 https://plugins.nessus.org/v2/offline.php 填写 Challenge Code 和 Activation Code 获取 all-2.0.tar.gz 和 Nessus-license 文件。

![](../Images/0ecb4158a6eadd78ae15192377ccebbe.png)

9、下载这两个文件。可以选择挂代{过}{滤}理下载，或者离线到百度云网盘上下载，正常下载的话会有点慢。

![](../Images/7fc66b7e240a148a76e91eddb5ebe436.png)

![](../Images/4068c008c855eb96a504e9f2fe4c28c0.png)

 

10、进入到 Nessus 安装目录下，更新插件，运行命令：nessuscli.exe update D: \\all-2.0.tar.gz（这里是all-2.0.tar.gz目录）

![](../Images/3c402ecaadfb6d89483cc48860555bb9.png)

  

11、将 Nessus-license 放到安装目录下。

 

12、覆盖替换 plugin\_feed\_info.inc 文件。由于我安装的是windows版本，没有找到 plugin\_feed\_info.inc 文件，所以自己创建了个 plugin\_feed\_info.inc 文件,内容如下：

 

PLUGIN\_SET = "202003210000";（这里是你第十步得到的plugin set值，就是插件版本号）  
PLUGIN\_FEED = "ProfessionalFeed (Direct)";  

PLUGIN\_FEED\_TRANSPORT = "Tenable Network Security Lightning";

 

13、创建完成后放到以下两个目录（如果有plugins文件夹不存在的情况，自己创建一个）：

D:\\Nessus\\nessus\\plugin\_feed\_info.inc  
D:\\Nessus\\nessus\\plugins\\plugin\_feed\_info.inc

 

14、在服务里重启 Tenable Nessus 服务。

1\. 在CMD中（需要管理员权限）：

net stop "Tenable Nessus" && net start "Tenable Nessus" 

 

2. 也可以重启 Nessus 服务。

![](../Images/992be1fbb0a8aac5a9d7239d504bc8e3.png)

   

15、再次打开Nessus界面，等待初始化完成后，就可以就入Scans界面啦，可以看到此时是无IP限制的。

![](../Images/26416a5aac6313b4314551e677a1e401.png)
