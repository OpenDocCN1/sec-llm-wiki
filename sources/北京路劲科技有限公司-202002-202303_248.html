1. 查看用户信息文件

cat /etc/passwd

2. 查看影子文件

cat /etc/shadow

3. 查看历史命令文件

#roothistory#普通用户/home 下的.bash_historycat .bash_history >> history.txt

4. 查看端口 

netstat -anplt | more

5. 查看进程 

ps -efps auxps aux | grep pid

6. 定时任务查看 

#crontab/etc/crontab//var/spool/

7. 查找异常文件 

find / -name *.php-type f //文件-type d //文件夹

8. 检查日志文件 

/var/logcat test.log | more | less按/ 进行查找

9. 打开日志文件 

head -5 file //显示前5行tail -5 file //显示后5行

10. 查看进程cpu使用率 

top第一行，任务队列信息，同 uptime 命令的执行结果第二行，Tasks — 任务（进程）第三行，cpu状态信息第四行,内存状态第五行，swap交换分区信息第七行以下：各进程（任务）的状态监控按数字1查看每一个cpu占用率

11. 打包log文件 

tar zcvf file.tar.gz dirtar zxvf file.tar.gz
