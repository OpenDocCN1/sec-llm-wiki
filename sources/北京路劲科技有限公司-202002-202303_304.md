# WannaRen勒索病毒作者竟然这么怂？

**前言**

  

昨天上午，我们公众号刚发布了文章《[勒索病毒再次袭来](http://mp.weixin.qq.com/s?__biz=MzUyMjAyODU1NA==&mid=2247484113&idx=1&sn=b1452db260614b0d4e0b41a34392f49a&chksm=f9d351b4cea4d8a25211ba517c1b6a63ea70aa555991f38482f4e877138328cce8122ec304c2&scene=21#wechat_redirect)》，结果这个看起来很厉害的勒索病毒作者竟然怂了，主动“自首”了。

  

**事件详情**

  

话说最近，这个名为WannaRen的新型比特币勒索病毒开始在国内快速传播。近日来，各类贴吧、社区、安全论坛中，表示中招求助的人数更是急剧上升。  
  
短短几天内，这个WannaRen就闹得沸沸扬扬、满城风雨，威力十足。关注网安领域的网友们应该也都被WannaRen给刷屏了。  
  
据网上公开资料显示，该勒索病毒能够通过QQ群、论坛、下载站、外挂、KMS激活工具等进行传播，且大部分感染者为个人用户。而不幸感染WannaRen勒索病毒的用户，重要文件会被加密，并被黑客索要0.05BTC（约2500元人民币）赎金。企业用户一旦不幸中招，WannaRen勒索病毒还可能在内网扩散。  
  
勒索团队扬言，3天内不付款赎金就会翻倍，一个星期之内不付款就会永远恢复不到被加密的文件。

![](../Images/6ddd4e8e14e952de20b37bda50cf3738.png)

当时，根据各个论坛网友反馈的结果表明，主流的杀毒软件都无法对此病毒进行拦截——若电脑感染，杀毒软件不会报毒，且查杀无效。不过，此事在上报反馈给安全论坛后，国内的杀软很快就做出了反映，多家软件已第一时间增加了支持对WannaRen”新型勒索病毒的拦截查杀。  
  
然而谁也没想到的是，黑色幽默的戏剧性一幕就在今天发生了：这一次，“神通广大”的**WannaRen勒索病毒的作者，竟然向安全厂商递交了解密密钥！**  
是的，你没看错，就是解密密钥。  
4月9日下午，火绒安全创始人马刚在微信朋友圈发表动态称：“4月9日，‘WannaRen’勒索病毒作者通过多方主动联系到火绒，并提供了相关解密密钥。”经火绒工程师分析后，验证密钥有效，稍后会发布针对该病毒的解密工具。连马刚自己也笑称不知道为啥对方会主动提供，可能是被火绒破解震慑到了吧。

![](../Images/1f2359251d47c513e9be2452977583b4.png)  

火绒随后还公开了勒索病毒作者“自首”的详细经过：9日上午，一名火绒用户以解密为由，通过邮件尝试联系WannaRen勒索病毒作者获取更多信息。  
而勒索病毒的作者在要求火绒用户支付比特币作为赎金未果后，竟主动提供病毒解密钥匙，并要求该火绒用户将密钥转发给火绒团队，制作“相应解密程序”。  
![](../Images/bea3876d19db04d9babde65def0075e2.png)  
从上述邮件可以看出，该病毒作者在使用英语进行交流后，又使用了中文进行沟通，再加上火绒此前披露该病毒使用易语言编写的情况来看，极有可能为国人所为。  
而这大概也是网安史上第一次，拥有“赫赫战绩”的勒索病毒作者，主动提供解密秘钥，还要求杀毒软件开发商查杀自己的![](../Images/d6f0f32199f9131affa08586bbd287ea.png)  
至此，随着事件发酵，各媒体、安全厂商进行了大量的曝光和溯源调查，截止目前，该病毒作者提供的比特币钱包未收到任何赎金，而该作者也已经停止下发、传播“WannaRen”勒索病毒。  
对于勒索病毒作者的这一波操作，具体原因我们也不得而知，不过有网友调侃，该勒索病毒作者是史上最怂黑客。
