渗 透 测 试






之  X S S (5)


简介

XSStrike是一款用于探测并利用XSS漏洞的脚本，包含四个手写的解析器，一个智能有效的 payload 生成器，一个强大的模糊搜索引擎和一个非常快速的爬虫。它还会扫描DOM XSS漏洞。


特点

对参数进行模糊测试之后构建合适的payload

使用payload对参数进行穷举匹配

内置爬虫功能

检测并尝试绕过WAF

同时支持GET及POST方式

大多数payload都是由作者精心构造

误报率极低


下载地址

https://github.com/s0md3v/XSStrike


安装

1）工具支持python3，python3安装pip，使用命令如下：

sudo apt-get install python3-pip

2）下载XSStrike，命令如下：

git clone https://github.com/s0md3v/XSStrike.git

3）安装依赖模块，命令如下：

pip3 install -r requirements.txt

4）运行工具，基本不会出现什么问题。

python3 xsstrike.py

举例用法

1. 扫描单个URL

参数：-u或--url

测试一个使用get方法的网页

python3 xsstrike.py -u  "http://example.com/search.php?q=query"

测试一个使用post方法的网页

python3 xsstrike.py -u  "http://example.com/search.php" --data "q=query"

2. 测试URL路径

参数： --path

python3 xsstrike.py -u  "http://example.com/search/form/query" --path

3. 从目标网页开始搜寻目标并进行测试（实用）

参数： --crawl

python3 xsstrike.py -u "http://example.com/page.php" --crawl

可以指定爬网的深度,默认2：-l（这是l不是1）

python3 xsstrike.py -u "http://example.com/page.php" --crawl -l 3

4. 查找隐藏的参数：

参数： --params

通过解析HTML和暴力破解来查找隐藏的参数

python3 xsstrike.py -u "http://example.com/page.php" --params

5. 盲测XSS：

参数： --blind

爬行中使用此参数可向每个html表单里面的每个变量插入xss代码

python3 xsstrike.py -u http://example.com/page.php?q=query --crawl --blind

6. 模糊测试--fuzzer

参数： --fuzzer

该模糊器旨在测试过滤器和Web应用程序防火墙，可使用-d选项将延迟设置为1秒。

python3 xsstrike.py -u "http://120.78.82.39:9999/vul/xss/xss_stored.php " --fuzzer

7. 跳过DOM扫描

参数： --skip-dom 

在爬网时可跳过DOM XSS扫描，以节省时间

python3 xsstrike.py -u "http://example.com/search.php?q=query" --skip-dom

8. 更新

参数： --update

如果跟上--updata选项，XSStrike将检查更新。如果有更新的版本可用，XSStrike将下载更新并将其合并到当前目录中，而不会覆盖其他文件。

python3 xsstrike.py --update


扩展

关于python版本的问题，可能会遇到有2和3切换本的问题。 

1.打开终端分别输入下面两条命令：

update-alternatives --install /usr/bin/python python /usr/bin/python2 100update-alternatives --install /usr/bin/python python /usr/bin/python3 150

2.然后查看版本：

python --version

3.如果需要切换python版本：

update-alternatives --config python

4.然后选你需要的python版本，输入序号就可以了。如果需要重新切换回python版本：

update-alternatives --config python （选号）
