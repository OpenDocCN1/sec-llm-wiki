# 北方实验室开展党史学习教育活动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2Mjg2NjkzOA==&mid=2247487092&idx=1&sn=7d232866fd80793a373f98ebba3a8f66&chksm=fc63b1e1cb1438f7bdc6e2b3f190d1d0058527cebad292842ae83e75baa45149723a8f67e9f4&scene=126&sessionid=1681668620#rd](http://mp.weixin.qq.com/s?__biz=MzU2Mjg2NjkzOA==&mid=2247487092&idx=1&sn=7d232866fd80793a373f98ebba3a8f66&chksm=fc63b1e1cb1438f7bdc6e2b3f190d1d0058527cebad292842ae83e75baa45149723a8f67e9f4&scene=126&sessionid=1681668620#rd)

中国共产党领导中国人民走过的百年历程，是光荣辉煌的一百年，是艰苦卓绝的一百年，是奠基立业的一百年，也是开辟未来的一百年。为贯彻落实党中央《关于在全党开展党史学习教育的通知》要求，结合沈阳市委、浑南区委关于开展党史学习教育的部署，4月15日下午，作为浑南区非公有制企业党建工作示范点，北方实验室联合浑河站东街道党工委，组织两新企业党支部书记、党务专干、浑南区内高新企业等50余人，由浑河站东街道党工委副书记徐柏钢及北方实验室党支部组织委员齐晶带队，共同开展了“两新党组织活动第二期——学习党史教育活动”。

  

![](../Images/e2e1a5963f70e556c6e2a1d38c1ac3c8.png "1-16.png")**第一站 “红色驿站”   ****NORTHLAB**

翻开红色记忆，沿着历史足迹，感受初心力量，活动首站走进浑南区创新天地“红色驿站”。在一幅幅精选的史料图片前，一段段精彩的历史故事中，党员同志们依次参观了“红色印记”——中国共产党在沈阳发展历程主题展区、“红色引擎”——沈阳基层党建工作成就展区、“红色基因”——组织生活室及宣誓区、“红色讲堂”——综合性会议中心四个展区，以实景沉浸的方式回顾了历史，展望了未来，追忆了初心，重温了使命。

![](../Images/e2e1a5963f70e556c6e2a1d38c1ac3c8.png "1-16.png")**第二站 辽宁鲲鹏生态创新中心 ****NORTHLAB**

活动的第二站来到辽宁鲲鹏生态创新中心展厅。创新中心由辽宁省政府主导，北方实验室作为辽宁唯一官方认可的运营单位，联合华为技术有限公司共同打造。北方实验室副总经理、创新中心总经理白杨向党员同志们详细介绍了创新中心的建设背景、发展理念、主要职能及阶段性工作成果。作为一名刚转正的新党员，白总表示将以高质量党建引领高质量发展，内外兼修，力争成为鲲鹏产品、应用孵化创新平台的标杆，壮大辽宁鲲鹏产业联盟，推动辽宁产业转型升级，助力辽宁信创产业发展，主动融入“数字辽宁、智造强省”建设大局。

![](../Images/e2e1a5963f70e556c6e2a1d38c1ac3c8.png "1-16.png")**第三站 浑河站东街道   ****NORTHLAB**

活动终点站到达浑河站东街道，浑南区总工会于铁志老师为党员同志们带来了一场别开生面的党史讲座，语言平实、情感真挚，让大家接受了一次深刻的党性教育洗礼。互动环节，广大党员同志们积极参与，现场气氛热烈美好。  

▼ 浑南区总工会于铁志老师带来主题党课 ▼

![](../Images/4e562e45358223136a8a6426255320f8.png)

活动进入尾声，浑河站东街道党工委副书记徐柏钢做总结性发言，他表示希望通过本次活动引导党员干部从党的百年伟大奋斗历程中汲前进的智慧和力量，增强攻坚克难的勇气和信心，坚定信念，抓好2021年各项工作落实。

北方实验室成立于2003年8月，是一家专业从事第三方信息技术服务的高科技创新企业。深耕信息领域十余载，公司紧随信息技术发展趋势，已经形成以网络安全咨询与服务为战略、以信息化全过程工程咨询服务为主线的新发展格局，业务覆盖信息化项目全生命周期，为客户提供综合性、跨阶段、一体化的项目质量保障。同时，北方实验室与华为联合打造辽宁鲲鹏生态创新中心，通过使能生态伙伴，开展基于鲲鹏技术底座的软件适配认证、人才培养、产业聚合、联合创新等，领先进入第三方信息技术创新服务赛道。
