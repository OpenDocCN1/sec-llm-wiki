# 北方实验室成功召开半年工作总结会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2Mjg2NjkzOA==&mid=2247485072&idx=1&sn=179bb6eb6873fbb1767f857e4046d207&chksm=fc63b905cb1430135a5c4c3f4a37f5dedeb7ba2e96ad4a57a92ceb42515873406840101f8a92&scene=126&sessionid=1681668632#rd](http://mp.weixin.qq.com/s?__biz=MzU2Mjg2NjkzOA==&mid=2247485072&idx=1&sn=179bb6eb6873fbb1767f857e4046d207&chksm=fc63b905cb1430135a5c4c3f4a37f5dedeb7ba2e96ad4a57a92ceb42515873406840101f8a92&scene=126&sessionid=1681668632#rd)

  
  
  

2020年8月2日，北方实验室成功召开2020年半年工作总结会，公司董事长国务院政府特贴专家杨丽春女士、公司管理层及业务骨干共70余人现场参会，省外分公司领导及外阜现场工作的领导约20人线上参会。

  

![](../Images/a2728b7d16d04c82d273a29041fcd7f8.png)

2020年上半年注定是不平凡的一年，因新冠肺炎疫情，各行各业均受到不同程度的影响。会议首先听取了各部门负责人及公司管理层上半年度工作汇报，着重听取当前工作中遇到的问题、问题分析及对策思考，并制定下半年工作措施、计划，并根据上半年运行情况，修订下半年目标。

  
  
  

![](../Images/9d21f8563c8263f77cd873fbc7c6a389.png "7fccb31050200f74d89c7d96c98bf16.jpg")

会上，技术中心刘总经理站在技术的角度对公司的业务发展提出了新思路。经历了在业务中研究技术的萌芽期、技术与业务相互融合的融合期后，当前公司已转向探索由技术引领业务发展的新模式，打破固有思路，实现从“研制”向“研发”转变。以技术服务产品作为“核心竞争力”，依托自有的产品服务为品牌，实现高效的收益和企业的可持续。

  
  

![](../Images/003d0fb990af69f55ce55fc49a9a7896.png "微信图片_20200804170308.jpg")

总经理张健楠在汇报时指出，当前信息技术服务业正处于高速增长阶段，北方实验室作为国民经济分类中的信息技术咨询服务企业，迎来极大的发展机遇期。除了在技术服务工作中恪守独立科学、捍卫公正权威外，公司的内控管理对企业发展同样至关重要。既要保证企业资产、财务信息的准确性、真实性、有效性、及时性，又要保证对企业员工、工作流程的有效的管控，要建立起对企业经营活动有效的监督机制。这些都需要公司的全体员工齐心协力、共同努力来实现。

  
  

![](../Images/09c230395f78dbf1341ce80378096d32.png)

会议最后，董事长杨丽春女士以“德行最重要”为主题，进行了总结性发言。当前对公司来说，既有机遇也有挑战。在拥有信息化工程建设全业务链的第三方信息技术服务资质的同时，北方实验室应发挥最大优势打造平台，筑巢引凤，吸引并凝聚了一支品德优秀的专业团队。杨董事长引用前华为人力资源副总裁吴建国在《华为的人才管理之道》中提出的：“核心要点有两个：一是德才兼备，以德为先，二是动态管理，能上能下!”，强调公司团队的德行对企业发展起到的关键性作用。以德为先，打造一支有素质、有技术的优秀团队，“做中国最受信赖的第三方技术服务机构”，北方实验室会越来越好，追求可持续发展。

  
  

![](../Images/15b91814a89e9a36f2a5aa387be33c38.png "微信图片_20200804191152.jpg")

北方实验室自2003年成立以来，已走过17个春秋。公司以信息化项目全过程工程咨询服务为业务主线，开展咨询设计、工程监理、网络安全服务等业务，为客户提供综合性、跨阶段、一体化的第三方质量保障。公司业务覆盖信息化项目全生命周期，提供投资咨询、设计、造价；事前绩效评估；工程监理；系统测评；网络安全风险评估、网络安全等级测评；事后绩效评价；项目管理等专业化技术咨询与测评服务。目前，公司拥有信息化工程建设全业务链的第三方信息技术服务资质，同时还拥有国家保密局颁发的涉密监理甲级、国防科工局颁发的军工涉密咨询服务资质及住建部的工程设计资质，已经成为一家聚焦于提供关键信息基础设施网络安全解决方案的高科技创新企业，一支维护国家网络安全的主力军。
