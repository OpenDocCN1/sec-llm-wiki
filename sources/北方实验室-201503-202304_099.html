人力资源助理


薪资：面议

工作地点：沈阳


岗位职责

1. 管理劳动合同、员工信息资料及各类人事档案资料；

2. 制作各类考勤报表、填写考勤记录、管理公司年假和福利等数据；

3. 收集相关的劳动用工等人事政策及法规；

4. 协助执行招聘工作流程，办理员工招聘、入职、离职、调任、升职等手续；

5. 协助组织安排对员工的培训和绩效考核；

6. 人力资源报表的编制，人力资源数据的统计；

7. 协助完成公司薪酬福利管理工作（包括工资、社保、公积金、商保等方面）；

8. 协助综合部日常工作的开展。 


任职资格


1. 男士优先；

2. 人力资源专业本科以上学历；

3. 具有良好的职业道德，踏实稳重，工作细心，责任心强；

4. 良好的沟通、协调能力，有团队协作精神；

5. 熟练使用相关办公软件。

6. 会开车者优先。




资质/体系管理专员


薪资：面议

工作地点：沈阳


岗位职责


1. 负责公司资质、体系认证等申请、维护工作；

2. 负责公司资质、体系认证等信息收集、申报、升级、年审、延续、会费缴纳等相关工作；

3. 负责公司人员资质的注册、变更、续期和换证等一系列相关工作；

4. 负责公司管理体系运行维护管理等工作；

5. 负责公司管理体系文件的变更升级换版工作；

6. 负责国家、省市级科技课题专项资金项目申请、验收等工作；


任职要求


1. 有资质、体系认证管理经验，有外审员证者优先；

2. 具有优秀的书面、口头表达能力,工作细致认真,有良好的执行力及职业素养；

3. 具有较强的应变能力和内外沟通能力,有强烈的责任感及敬业精神；

4. 择优录取，男女不限。




商务经理


薪资：面议

工作地点：沈阳


岗位职责

1. 负责项目招投标信息收集工作；

2. 负责政府采购领域法律法规收集及整理，组织开展相关知识培训；

3. 负责收集公司重点行业、重点区域项目业绩及项目案例；

4. 协助客户经理投标报名、投标文件编制等相关工作；

5. 负责项目中标结果跟踪及中标通知书领取事宜；

6. 负责维护销售系统数据，督促客户经理及时上传更新数据；

7. 负责为市场人员提供相关工作咨询；

8. 负责商务合同的输出与归档管理。


任职要求


1. 学历本科、文科生优先。

2. 行政管理、工商管理、计算机等相关专业；

3. 能适应短期出差工作，吃苦耐劳；

4.有组织纪律性，严格要求自己，有上进心和对自己工作上的规划；

5. 熟练应用办公软件。



业务助理


薪资：面议

工作地点：沈阳


岗位职责

1. 协助项目部对项目进行管理，保障项目顺利进行；

2. 项目信息登记及过程材料整理；

3. 阶段性成果物汇总、存档；

4. 业务知识库收集、管理；

5. 设备的借出管理；

6. 其他相关工作。


任职资格


1. 学历：本科及以上学历；

2. 教育背景（专业）：计算机相关专业；

3. 年龄：20周岁以上；

4. 经验资历：有项目管理经验者优先；

5. 专业知识：熟练掌握办公软件。




咨询工程师


薪资：6000-15000元/月

招聘人数：3人

招聘区域：沈阳

项目地点：全国

社保缴纳地：沈阳


岗位描述

1. 负责信息化项目编制类咨询工作（主要包括信息化规划、项目立项咨询、初步设计等）；

2. 负责信息化项目评审类咨询工作（主要包括绩效评价以及采购方式、技术方案、招投标参数和投资造价的技术评审）；

3. 负责组织咨询文件的编制；

4. 负责协调解决实施过程中遇到的各类技术问题；

5. 完成上级交办的其它工作。

任职要求


1. 掌握IT咨询规划方法，熟悉项目管理理论与实践，能够提供信息化咨询和项目方案的策划和设计；

2. 有良好的沟通能力、表达能力和问题分析能力，具有良好的写作能力和方案演示能力，对新事物敏感、勇于挑战新领域；

3. 工作积极主动、责任心强，有良好的客户意识；

4. 有电子政务领域信息化咨询规划、项目实施管理工作经验者优先考虑；

5. 有政府相关行业经验优先考虑；

6. 有注册咨询师、造价师、项目管理师等资质证书优先考虑。

招聘人数：5-10人

招聘区域：全国

项目地点：全国

社保缴纳地：沈阳


岗位描述

• 负责网络安全等级保护测评项目、信息安全风险评估项目、密码应用安全性评估项目的实施工作，包括编写测评方案、现场测评、使用测评工具、编写测评报告等。

任职要求

3. 具有较强的组织能力、较好的文档处理能力；

4. 具有信息安全等级保护测评、风险评估、运维和集成经验者优先；

5. 具有网络安全相关证书，如等级保护测评师证书、密码专业相关证书优先，待遇高于原工作岗位。




信息系统监理工程师①


薪资：5000-15000元/月

招聘人数：2人

招聘区域：全国

项目地点：北京

社保缴纳地：沈阳/北京


岗位描述

1. 对项目进行质量、进度、投资控制，合同、信息进行管理，负责项目的全面协调工作，保障项目顺利进行； 

2. 协助审查承建单位的计划、方案； 

3. 负责核查工程中所用的设备和材料； 

4. 负责监理资料的收集、汇总及整理； 

5. 负责北京市及周边地区信息系统工程监理项目实施工作。

任职要求


1. 本科及以上学历，要求软件或计算机相关专业；

2. 有责任心、具备一定的沟通协调及语言表达能力；

3. 可适应短期出差；

4. 具备信息系统监理师资格证的人员优先录用。

软件测评工程师


薪资：面议

招聘人数：2人

招聘区域：宁夏

项目地点：宁夏

社保缴纳地：银川市


岗位描述

1. 根据测试需求和设计文档，分析测试需求，制定测试计划；

2. 根据测试需求完成实施方案的编写；

3. 设计并执行测试用例，进行缺陷跟踪和答疑，完成测试结果分析以及测试报告的编写；

4. 在测试各环节与开发方沟通保证测试输入和输出的正确性和完备性。

岗位要求


1. 计算机类相关专业本科及以上学历；

2. 应届毕业生或两年以上相关测试工作经验；

3. 学习能力强，具备良好的业务沟通和理解能力,有较强的责任感及进取精神；

4. 扎实的测试基础知识,良好的功能测试技能和文档写作能力；

5. 热爱软件测试工作，工作积极主动、踏实认真，具有强烈的责任心；

6. 具备团队协作能力，集体荣誉感强烈；

7. 熟悉loadrunner、Jmeter、AppScan等测试工具者优先。


任职要求


1. 本科及以上,计算机相关专业;具备一定测试工作经验；

2. 掌握基本的软件测试理论,熟悉软件测试的基本方法、流程和规范；

3. 具有较强的组织能力、较好的文档处理能力；

4. 可适应宁夏地区内短期出差。
