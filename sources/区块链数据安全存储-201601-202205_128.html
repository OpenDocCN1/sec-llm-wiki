在你开始之前

这里唯一的先决条件是Nim，这是一种编程语言，具有类似Python的语法，并且性能类似于C。可以在此处找到详细信息。

cd nim-libp2p

3.浏览到examples文件夹。

cd examples

nim c -r --threads:on directchat.nim

# --threads:on means to turn on support for multi-threading

开始编码！

在本节中，我们将从最基础的内容开始逐行处理代码。如果您已经对Nim很有经验，请随时跳过它。

设置主要程序

首先创建一个输出字符串“ hi” 的函数（在Nim中称为过程）！

  1. start.nim在tutorial目录下创建一个新文件。

  2. 将以下代码复制并粘贴到我们的新文件中。

import chronos

proc main() {.async.} =
  echo "hi"
  
when isMainModule:
  waitFor(main())

第一行导入模块“ chronos ”，这是异步编程的有效库。chronos由Status开发，最初是Nim标准库async的分支，但此后出现了很大的分歧。您可以在其Wiki中找到更多文档，说明和示例。

然后，proc关键字使用name定义我们的主过程main。该{. .}语法是叫编译 位于稔。其中的async关键字告诉编译器为我们的过程启用异步功能。

该代码的最后部分等待waitFor关键字的异步主过程执行。在倒数第二行中，有一个特殊的常量isMainModule，它将true在将此模块编译为主文件时使用。

3.尝试通过在终端中键入上述代码段来运行上述代码段。您应该看到“ hi”打印出来。

cd ../tutorial
nim c -r start.nim

读取并处理控制台输入

在此示例中，我们希望在侦听用户输入的同时处理我们的过程。为了实现这一点，我们将使用多线程。

  1. 首先，创建一个过程来监听用户输入。

proc readInput(wfd: AsyncFD) {.thread.} =
  ## This procedure performs reading from `stdin` and sends data over
  ## pipe to main thread.
  var transp = fromPipe(wfd)

  while true:
    var line = stdin.readLine()
    discard waitFor transp.write(line & "\r\n")

在此过程中，我们用于while true连续侦听来自stdin的用户输入，并将结果写入写文件描述符wfd。输入将被转发给rfd以后进行处理。

2.创建另一个过程以打印输入。

proc processInput(rfd: AsyncFD) {.async.} =
  var transp = fromPipe(rfd)
  while true:
    let a = await transp.readLine()
    echo a

在此博客中了解有关什么管道，stdin，stdout和文件描述符的更多信息。简而言之，管道用于连接标准输入和输出。

3.然后，编辑我们的主过程以创建一个管道，以在不同线程之间发送数据，并根据对象将其处理程序分配给新实例。

proc main() {.async.} =
  var (rfd, wfd) = createAsyncPipe()
  if rfd == asyncInvalidPipe or wfd == asyncInvalidPipe:
    raise newException(ValueError, "Could not initialize pipe!")
  
  var thread: Thread[AsyncFD]
  thread.createThread(readInput, wfd)
  
  await processInput(rfd)

在代码的第一部分中，rfd代表读取文件描述符，wfd代表写入文件描述符。createAsyncPipe设置并返回一个异步管道，该管道转发写入的数据wfd以供读取rfd。如果返回值无效，则会引发异常。

其余部分不言自明。我们创建一个线程来连续监听用户输入，然后处理我们的输入数据。

4.最后，提醒我们的用户threads:on在执行脚本时添加多线程选项。在我们的import语句之前添加此行。

when not(compileOption("threads")):
  {.fatal: "Please, compile this program with the --threads:on option!".}

5.运行start.nim，查看您的输入/输出是否正常。请记住在threads:on这里添加，因为我们正在使用多线程。

nim c -r --threads:on start.nim
