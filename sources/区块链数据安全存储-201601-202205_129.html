IPFS：区域和复制


在过去的几个月中，我们的团队一直在努力工作，为 Pinata 编写了下一个主要版本。

现在，我们很高兴地宣布我们一直在努力的工作。

我们称此更新为：“区域和复制”。


区域和复制


对于寻求更高速度和额外冗余的用户，Pinata 现在允许你在多个节点和多个区域中复制内容。




多次复制的好处

从 IPFS 检索内容时，首先必须在网络上“找到”该内容。复制内容的 IPFS 节点越多，网络上其他节点可以更快地找到该内容。


对于用户直接从其设备运行自己的 IPFS 节点的应用程序，多重复制特别有用。这些用户节点通常与 IPFS 网络的连接较少，因此，如果该内容不能广泛使用，则可能很难快速找到该内容。换句话说，在多个节点上复制内容通常会为用户带来更快的内容发现时间。


多个区域的效益

对于拥有全球客户群的公司而言，重要的是要确保所有客户都能快速获得内容。通过让你在多个区域中复制内容，Pinata 允许你将内容移动到更靠近最终用户的位置。对于居住在复制区域附近的用户来说，这意味着更快的检索时间和更好的用户体验。


如何复制你的内容


你可以通过几种不同的方法来确定如何在 Pinata 上复制内容：你的帐户级别“Pin Policy ”

每个 Pinata 用户都有与他们的帐户关联的“ PIN Policy”。每个新的内容都将使用此帐户级别的固定政策来确定应如何复制内容。你可以通过访问“ 帐户页面”来查看此 Pin Policy。


在这里，你应该看到标题为“ PIN POLICY”的部分。




从这里开始，只需更改你的 Pin Policy 即可反映你希望在每个区域中进行多少次复制。设置此新的 Pin Policy 后，默认情况下，所有固定到 Pinata 的将来内容都会根据此帐户级别的 Pin Policy 进行复制。


上传时提供“自定义 Pin Policy”

如果你通过我们的 API 上传一个新的内容到 Pinata，你现在可以选择作为请求的一部分传递一个“customPinPolicy”。如果 customPinPolicy 作为上传请求的一部分传递进来，那么将使用该 pin policy，而不是上面提到的帐户级别 pin policy。有关如何传递 customPinPolicy 的示例，请参阅我们的文档。


上传后更改 Pin Policy

如果你已经将内容上传到了 Pinata，并且想要更改该内容的复制方式，则可以使用我们的 hash Pin Policy API 端点或通过 Pin Explorer 进行。要通过 Pin Explorer 更改复制策略，只需打开该内容的“更多菜单”，然后单击“ Change Pin Policy”以更改该特定内容的 Pin Policy。

区域和复制如何影响定价？


复制的价格与普通存储的价格相同。每复制 1GB，则算作每月额外存储 1GB。因此，在两个不同的区域中复制 1GB，或在同一区域中复制两次的 1GB，将被视为每月存储 2GB。要了解有关复制的更多信息，请查看“ 复制文档”。
