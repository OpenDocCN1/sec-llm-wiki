## **IPFS 上的空缺职位**

  

*   社区工程师 libp2p：帮助向 libp2p 引入新的开源项目，并为他们清除采用 libp2p 堆栈作为系统网络层的障碍，远程协议实验室
    
*   IPFS 工程经理：工程经理具有艰巨而激动人心的任务，即支持和授权工程团队在好奇心，热情和对开源的热爱所定义的环境中交付复杂的 Internet 规模的系统。远程协议实验室
    
*   IPFS 社区负责人：为 IPFS 社区提供战术支持，创建全球社区战略，并在实地执行该战略，远程协议实验室
    
*   IPFS 项目运营商：使用灵活的问题解决能力来解决 IPFS 的一些最高优先级计划。还负责确定项目最重要的问题，对其进行组织并与跨职能团队合作以寻求解决方案，远程协议实验室
    
*   规范工程师，libp2p：帮助为 libp2p 编写清晰的规范，从而有助于新语言能够正确实现 libp2p 规范。远程协议实验室
    
*   IPFS 或 libp2p 的高级软件工程师：经验丰富的分布式系统设计和实施？加入我们的全职开源团队，在这里我们重视独立设计和实施复杂系统的重要组件以及执行重点和纪律以完成项目的经验，远程协议实验室
    
*   Underlay 项目的软件工程师：强大的全栈 Web 开发人员，对语义 Web 和去中心化 Web 技术感兴趣。知识期货小组，远程
    
*   3Box 技术产品经理：在 3Box 开发人员 API，SDK 和插件套件中拥有新技术产品和功能的交付，并管理入职，参与和合作伙伴关系活动，以确保社区和网络蓬勃发展，3Box，NYC，柏林或远程
