区块链存储不是简单意义上将数据存储在区块链上，它是一种去中心化存储加上奖励机制。去中心化存储不一定是区块链，但利用区块链奖励机制可以让更多节点和用户参与进来，从而构建更加稳定、更低成本的存储系统。

![](../Images/d26d29a07545fd6810c48f6543681f45.png)

就当下而言，区块链存储并不是普通用户的刚需，普通用户只需一个硬盘就足以存储数据，用不到区块链存储。而真正让区块链存储成为刚需则是在5G普及之后。5G之后，每个人上网更加普遍，届时我们的电脑没必要再配备大内存和强悍CPU，每个人都可以在电脑上通过区块链进行存储，这时候区块链存储就会大火起来。随着技术水平的发展，大数据、人工智能、物联网都需要大规模的存储空间，因此区块链存储在未来必然会占有一席之地。

  
  

** IPFS 是什么？**

  
  

IPFS（Inter Planetary File System）是一个点对点的分布式超媒体分发协议，它整合了过去几年最好的分布式系统思路，为所有人提供全球统一的可寻址空间，包括Git、自证明文件系统SFS、BitTorrent和DHT，同时也被认为是最有可能取代HTTP的新一代互联网协议。

**IPFS**

  

**协议**

定义了基于哈希寻址内容文件系统，并结合来自Kademlia、 BitTorrent、Git等的想法来协调内容传输

  

**IPFS**

  

**P2P**  

支持世界范围点对点文件传输，具有完全分散的架构，没有中心点故障

  

**IPFS**

  

**互联网**

文件可以通过HTTP网关来访问，例如https://ipfs.io。浏览器通过扩展能直接使用ipfs://域，且哈希寻址保证了内容的真实性

  

**IPFS**

  

**文件存储**

超媒体，有文件夹、文件、视频和基于FUSE的可挂载文件系统

  

**IPFS**

  

**CDN**

在本地库中添加一个文件，立即对世界可用，并拥有对缓存友好的内容哈希地址和BitTorrent一样的带宽分发

  

**Filecoin**

  

Filecoin 作为IPFS的激励层，是一条区块链，链上流通的 Token 也叫 Filecoin（FIL），这条链是基于 IPFS 协议，也就是使用 IPFS 的技术，再加上加密货币（FIL）这种经济激励的引入，让 IPFS 协议能够被更多人使用，让更多的人愿意贡献出自己的带宽和存储空间给其他人使用。

01

  

价值交换

用户和交易所：用户购买FIL，以备使用

矿工和交易所：矿工出售FIL，换取法币

用户和检索矿工：交换流量，用户付费下载数据，矿工发送数据并获取用户支付的FIL

用户和存储矿工：交换存储空间，用户付费存储数据，矿工帮用户存储数据并获取用户的FIL

    ▼此流程没有新币FIL分发，只有已有代币之间的价值交换，称为价值交换

  

  

02

  

共识协议

存储矿工和Filecoin协议：

●存储矿工使用已存储的数据，参与共识协议，获取新币的分发

●存储矿工需抵押一定量FIL代币，以此来出售自己的存储空间

    ▼检索矿工不参与新币分发，即不参与共识协议

  

  

03

  

存储矿工收益

存储收益：帮用户存储数据，获取用户支付的存储费用（价值交换）

新币分发：参与共识协议，获取新币分发

交易手续费：参与共识协议，获取交易手续费

  

  

04

  

检索矿工收益

检索收益：用户下载数据，获取用户支付的下载数据费用（FIL）

  

  

05

  

存储矿工数据来源

用户付费存储数据

   ▼作为存储矿工，存储的数据只能由Filecoin区块链分发一种方式
