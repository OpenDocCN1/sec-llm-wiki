**新基建推进**

  

  

中共中央政治局常务委员会3月4日召开会议，会议指出，加快5G网络、数据中心等新型基础设施建设进度。

这次疫情期间， 随着不出门抗疫的号召下和复工的推迟，全国各地各行业在线办公在线消费在线娱乐业务流量持续高涨。其他行业也在这种极端环境下开始思考数字化转型。激增的线上业务需求，对现有的通信网络、数据中心形成了极大的考验，部分应用服务器出现承载能力不足，网络传输速度和稳定性也出现下降的问题，传统的以云为中心的互联网架构已不堪重负，对应的运营商不得不临时扩容。这也为新型基础设施建设进度需求按下了快进键。

  

![](../Images/e0d33db748a55f7e8e8f8905d52a95d5.png)

  

  
**5G的发展**

  

  

而再次强调加快5G网络建设，说明了国家抢先发展5G的决心。除了我们国家，全球已有34个国家378个城市部署了5G商用网络。美国和韩国都纷纷出台了有关“5G商用”的相关政策和战略布局计划。发展5G已是世界各国的普遍共识，抢抓5G发展机遇是占领国际竞争制高点、全面构筑经济社会数字化转型，5G的快速发展将会为产业、商业和社会成长带来重大的变革和机遇。所以2020年将会是5G商用的关键之年。

![](../Images/7efef4b9260aa87f6e8b622e95da8f64.png)

  

  

  
**传统互联网压力**

  

  

不难看出，国家此次提出的关于加快新基建进度的要求，将会加速互联网的快速发展，用户需求和数据将会大量产生。数据量的大小将会由TB级增长至PB级，并随着社会的发展，各行业、各领域的数据量都会不断地增长。然而传统的互联网是以云为中心构建，在面对上升若干个数量级数据和网络服务的需求量时，已难以满足终端侧“ 大连接，低时延，大带宽” 的云资源需求。

![](../Images/9fcdc88799c5376c63044f3e5806a3c6.png)

  

  

  
**关于SDVN项目**

  

  

对此，SDVN项目非常具有前瞻性地提出一种可无限扩展的分布式全新网络架构，彻底重构现有的以云为中心的互联网应用框架，形成边缘位置的计算、网络、存储、安全等能力全面的分布式弹性网络基础架构。通过将网络转发、存储、计算，智能化数据分析等工作放在边缘处理，降低响应时延、减轻云端压力、降低带宽成本，保证数据安全，并提供全网调度、 算力分发等服务。

SDVN即软件定义虚拟网络，在物理网络（互联网和局域网）基础之上，采用Multi code packet encryption技术、Multi layered技术、Network Slicing技术、DLT技术、Next-Hops技术等先进技术，构建出一个安全的，封闭的，不受网络物理拓扑限制的、私有的可任意分片的虚拟网络。

**SDVN技术的特点**

  

  

  

\- 去中心化分布式组网：采用Multi code packet encryption技术、Multi layered技术、Network、Slicing技术、DLT技术、Next-Hops技术等技术，快速实现基于internet的点对点、点对网、网对网的安全私有网络搭建。

  

  

  

\- 高可靠数据安全保护：以可信身份验证、加密通讯、授权访问等安全技术，保证数据在虚拟网中的安全传输，保护价值的可靠流动。

  

  

  

\- 基于应用的端到端网络切片：基于身份、资源、SLA、QOS、SL等策略集，动态的在虚拟网络中切出多个网络分片，每个虚拟网络分片在逻辑上隔离，实现端到端的基于用户、应用场景的按需服务。

  

  

  

\- 高带宽低延时处理性能：结合端到端通讯、边缘转发、智能路由等技术，有效缩短通讯延时，随时随地都能快速访问目标资源。

  

  

  

\- 共识机制：采用DPOS股份授权证明机制，实现快速共识

  

  

  

\- 智能合约：保障交易的可追溯性、不可逆转和安全

\- 开放机制：通过DOCKER、网络分片、DAPP等技术，支持各种应用的快速上链
