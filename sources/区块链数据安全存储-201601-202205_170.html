以下是官方线路图更新博客全文。


在此博客文章中，我们介绍了自启动测试网以来的最新进展，以及有关测试网第二阶段和主网启动的路线图信息。请查看我们的路线图更新Q4 2019和Testnet Phase 2更新（按此顺序）以获取更多背景信息。


我们现在在哪？


提醒一下，我们于 2019年12月11日启动了第一阶段测试网。撰写本文时，测试网已有经验证的3.6PiB +的存储容量。尽管我们期望Filecoin主网会大几个数量级，但这是一个很好的开始！让我们继续发展网络！



在stats.testnet.filecoin.io上查看更多testnet统计信息



自两个月前启动测试网第一阶段以来，我们取得了重大进展。以下是一些要点：



（一）Engineering️工程学


在此期间，我们在代码库的测试和优化上投入了大量资金。


（1）➕ 升级网络。发现错误和网络攻击后，我们已经解决了这些问题，并通过分叉升级推出了更改。感谢许多社区成员，他们参与了发现错误并在这些分叉之后努力重新加入网络！


（2）⚖️链安全。我们提高了链同步速度和链稳定性。这些优化显着改善了现有和新网络参与者的测试网体验。


（3）🌐其他实现。我们最近宣布了Filecoin协议的另外两个实现：fuhon（由Soramitsu用C ++实现）和forest（由ChainSafe在Rust中实现）。我们很高兴Soramitsu和ChainSafe成为发展Filecoin生态系统的早期合作伙伴！


（4）🔗可互操作的实现。对于我们来说，在Filecoin主网上进行多种实现互操作是我们网络安全的重要目标。Lotus和go-filecoin已接近完全的互操作性，并计划在未来数星期内都实现推出一个互操作的网络。几个星期后，我们推出我们的第一个互操作网络与Lotus和go-filecoin的fuhon和森林的实现也将准备进行互操作的网络上。


（5）🏃‍♀️复制证明优化。我们对复制证明（PoRep）的实现进行了相当大的改进。我们在Rust中开发了Poseidon哈希函数的高效实现，并将其集成到我们的证明协议和库中。我们还在SNARK证明中进行了电路优化，从而使证明速度提高了2倍。最终，这些优化和其他优化提高了我们SDR PoRep实施的速度和性能。


（二）协议


（1）可执行角色规范。我们为使用Go编写的Filecoin协议参与者实现了完全可执行的规范（可执行规范存在于specs-actors存储库中）。除了实施此可执行规范之外，我们还对库进行了广泛的测试，以行使actor的功能并验证其正确性。Lotus和go-filecoin现在也直接集成的功能，角色库，大大增加我们的执行者，这是安全关键协议组件的正确性和安全性的信心。


（2）📈加密经济。我们在加密经济结构方面取得了重大进展，缩小了可以使网络长期保持一致的机制和参数。协议规范中的Cryptoecon占位符概述了正在考虑的经济杠杆。我们正在运行广泛的模拟，以验证并最终确定构造。


（3）🛡️ 协议安全审核。Filecoin研究团队深入研究协议安全审核，非常仔细地研究了Filecoin证明，共识，市场设计等。我们致力于启动安全的网络。在启动Testnet Phase 2之前，我们将解决通过此次审核提出的所有主要问题。



（三）生态系统亮点



（1）🌟Textile


Textile团队最近宣布即将举行的若干工具，以使其“一样简单123”开发应用程序的支持由Filecoin网络。我们预计这项工作将降低新开发人员的进入门槛，增加启动和以后发布在网络上的应用程序的种类和质量。


（2）🔥 Terminal.co


终端最近启动，以简化在IPFS上开发和托管网站的过程。该团队表示，他们的路线图中具有Filecoin功能。我们期待使用终端托管通过Filecoin备份的IPFS网站！


（3)🛳️ filscan.io


查看Filscan，它是Filecoin测试网的块浏览器！您可以使用Filscan观察链的进展，查看每个区块的内容，查看消息和每个矿工开采的区块数量以及更多信息！这是探索Filecoin网络上活动的好方法。该项目得到了Wave 1的Filecoin Dev Grants计划的资助，该项目得到了支持。我们很高兴看到这样有用的社区资源在测试网上得到积极维护和使用。


(4)😎应用程序


本周，Zondax团队发布了一个包含正在进行中的Ledger Filecoin应用的仓库。此外，Open Work Labs正在构建一个非托管的Web钱包，该钱包集成了Ledger Filecoin库，并在屏幕快照中显示了在Ledger上显示Filecoin本地版本的屏幕截图。尽管这项工作仍在进行中，但我们为即将发生的事情而感到兴奋-希望很快能在Ledger上看到Filecoin！


(5)❄️ Trustwallet


Trustwallet合并了对Filecoin的支持！该应用程序将能够在主网启动时支持Filecoin令牌。


(6)💾矿工们！


本周，我们看到几个采矿团队在Filecoin主网发布之前发布了其采矿设置的图片和视频。看看下面的一些设置！ 


(7)👟开发补助


我们最近关闭了Filecoin Dev Grants的 Wave 2 。非常感谢社区成员提出的富有创意的建议！我们将很快宣布赠款获得者。如果您错过了这波浪潮，请放心-Wave 3当前开放，我们正在接受申请，直到2020年3月31日。我们期待着您的建议！



测试网阶段2：重新安排


提醒一下，我们的下一个主要里程碑是：



（一）测试网阶段2


我们的测试网第二阶段将以多种安全，可互操作的实现启动。根据我们上一次的路线图更新，“ Testnet第2阶段将标志着功能冻结，并且至少要进行为期两个月的正式测试，验证和安全审核。提醒一下，我们启动主网的最关键要求是Filecoin是安全的。我们不会启动不安全的网络。如果发现任何严重的安全问题，我们可以延长这一阶段。” 我们还将在Testnet第二阶段中启动一系列生态系统计划，包括我们值得信赖的安装仪式的下一阶段。


（二）主网启动


我们将有一个月的启动窗口，以完成启动准备并启动Filecoin主网。


当我们为Testnet Phase 2的发布做好准备时，我们的团队正在向所有气缸开火。在我们努力尽快启动Testnet Phase 2和mainnet的同时，我们有责任确保Filecoin在启动时是安全的。我们的团队需要一些额外的时间来完成协议开发，交叉实现互操作，内部协议安全审核以及完善我们的加密经济体系。


此外，引起我们注意的是，我们在中国的许多社区继续受到冠状病毒爆发的影响。我们的一些华人社区成员直接要求我们等待启动Testnet第二阶段两三个星期，直到他们可以安全地返回工作为止。我们听到您的声音，而您的安全是我们的首要任务！


我们将把Testnet第2阶段延迟大约6周，以便有足够的时间进行最终协议融合和功能冻结。要查看最新的计时信息，请访问我们的公开Filecoin路线图甘特图。与往常一样，这些日期是最佳估计，并且可能会发生变化。


我们正在尽力提供准确的时序信息，但是请您理解，该信息不是静态的，它会发生变化。我们希望这6周的发布延迟能够为中国的情况改善提供足够的时间，并使我们所有的全球社区都可以在不影响其安全的前提下参与该网络。


下一步是什么


从现在开始到Testnet第二阶段，我们目前的优先事项是：


（一）启动我们的第一个互操作网络。


如上所述，使用多种安全实现启动网络是我们网络安全策略的重要组成部分。提前Testnet第2阶段，我们将推出的互操作网络开始与我们的两个内部实现，Lotus和go-filecoin。几周后，Forest和Fuhon也将在测试网上进行互操作。


发布第一个互操作的网络需要与双方的更新版本重置testnet Lotus和中间人filecoin。重置此网络后，任何人都应能够运行任一实现以参与Filecoin测试网。这是一个巨大的里程碑，我们预计在未来几周内启动互操作网络。


（二）协议安全审核


在启动Testnet Phase 2之前，我们将完成内部协议安全审核并解决所有导致的问题。我们预计协议安全性审核和解决方案将继续进行一个月。


我们正在竭尽全力安全地启动Filecoin网络。像这样的时刻让我们想起了更大的前景：安全不仅仅是我们协议的功能；它不仅是协议的功能，更是安全性。


我们深切关注使这个生态系统成为现实的人们的安全。我们非常感谢社区的持续支持，并很高兴与您一起建立这个生态系统。
