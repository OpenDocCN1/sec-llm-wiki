# 重庆市侨联党组书记、重庆市委统战部副部长史全波带队调研涪陵知名民营医院 ——李志沧中医骨伤医院

       2016年5月19日上午冒着大雨，重庆市侨联党组书记、重庆市委统战部副部长史全波一行专程赴涪陵知名民营医院——李志沧中医骨伤医院进行民营医院的发展前景进行调研，陪同调研的涪陵区领导有涪陵区委委员、常委、统战部部长常金辉部长，区侨联主席蹇玲等。

![](../Images/454fb8a372d12d62188bde5296c4c673.png)  
   史部长在李志沧中医骨伤医院李朝阳院长的陪同下参观了位于宏声大道66号已开始试营业的新医院。    

![](../Images/3a6cbf41b267080846aa84db6e5ad5fa.png)

![](../Images/b6e2fa65cc8edad5e790e9ef00269647.png)  

![](../Images/9ab65d2bbcba9eec89f5e1d5c5cc84b3.png)

    参观过程中史部长详细的了解了医院的起源、现经营过程中遇到的问题以及今后医院发展的规划。参观结束后史部长向医院陪同的领导们指出：

    一、民营医院的发展不光是发展硬件，软件方面也应当跟上，在这些方面一定要向国内外知名的同行学习。

    二、克服家族企业发展中的瓶颈，坚持制度化的管理。

    三、坚持中医特色，注重细节管理。

![](../Images/d359ed814b01c2a48660f3ec064623ee.png)  
     陪同人员也对医院的软、硬件给予了高度评价，总结出了新医院有几大好：设施好、服务好、技术好、空气好、环境好、交通便利.

![](../Images/1e8f94058fb9bfe5e63feaf8ba8b411f.png)  

```
     涪陵李志沧中医骨伤医院是一家中医特色突出的大型民营医院。医院位于宏声大道66号天湖小镇旁，毗邻宏声度假村、森林公园，占地8亩，建筑面积10000余平方米，床位200张。以骨伤科为主、中西医诊疗、社区卫生服务兼具。

```

所施行的“李志沧传统中医正骨术”源远流长,“不开刀、不吃药、康复快、花钱少”，是祖国传统医药中一支绚丽夺目的奇葩。

  
       涪陵李志沧中医骨伤医院荟萃一批有识之士，在李朝阳院长的带领下，打造出中医正骨特色更加突出的大型专科医院。这家医院现正以全新的面貌展现在涪陵人民面前，全心全意为广大伤患者的健康服务，努力为涪陵卫生事业发展做出更大的贡献。
