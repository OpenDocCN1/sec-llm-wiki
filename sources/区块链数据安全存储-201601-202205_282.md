李志沧中医骨伤医院

护士技能大赛

     李志沧中医骨伤医院不仅重视对医生的培养，护士直接面对病人的护理，医院对护士的培训工作也一直很重视，近日，医院举办了护士技能大赛，对护士的实际操作能力进行全面检验提高。

       值5.12国际护士节来临之际，涪陵李志沧中医骨伤医院的护士们在院领导以及工会的组织、筹划下全员开展了岗位大练兵活动，并于5月6日开展"护士技能大赛"。        

![](../Images/cb2b719f8a3a940e4a6e27358e29e3ff.png)

  

  

  

  

  

       今年的比赛时间，虽然在刚刚搬了新院比较忙碌，可经过院领导的重视、在护士们的精心准备下，比赛赛出了风格、赛出了水平全员操作合格。这比往年的技术水平大大的提高了，这与护士们平日里的岗位练兵是密不可的，加上平日里也常常自觉的利用业余时间勤加练习，才能有此收获。

  

  

  

     特别是男护士们认真、到位的操作过程，更为医院里亮丽的色彩增彩了不少！

  

  

  

  

  

  

  

  

```


     此次比赛勇夺第一的是骨一科的王颖护士长，她精细到位、一气呵成的操作获得了院内专家组的一致好评！取得第三名：池文君、聂会、陈岑、潭敏
```

```


        涪陵李志沧中医骨伤医院是一家中医特色突出的大型民营医院。医院位于宏声大道66号天湖小镇旁，毗邻宏声度假村、森林公园，占地8亩，建筑面积10000余平方米，床位200张。以骨伤科为主、中西医诊疗、社区卫生服务兼具。

```

所施行的“李志沧传统中医正骨术”源远流长,“不开刀、不吃药、康复快、花钱少”，是祖国传统医药中一支绚丽夺目的奇葩。

  
       涪陵李志沧中医骨伤医院荟萃一批有识之士，在李朝阳院长的带领下，打造出中医正骨特色更加突出的大型专科医院。这家医院现正以全新的面貌展现在涪陵人民面前，全心全意为广大伤患者的健康服务，努力为涪陵卫生事业发展做出更大的贡献。
