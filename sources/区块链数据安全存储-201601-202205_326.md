# 这个国家的孩子不爱上大学，为何却成了世界最强大国家之一

再过一个月左右，高考又要到了。相比国内莘莘学子千军万马过独木桥决战高考，个别考生甚至非一流名牌大学不去，作为西方发达国家的瑞士，这里年轻人的择学、择业观让人耳目一新：超过半数的瑞士初中毕业生会进入各类职业技术学校学习深造，成为拥有熟练技术的“现代工匠”。他们也铸成了闻名全球的“瑞士制造”基石。  

  

![](../Images/2e9da5b3dee74882e3d6eea9e4bdf4ee.png)  

**他们为何不进大学进技校**

  

据新华社今天（5月1日）报道，在瑞士，家长对子女不考大学而是上技校的决定，多采取尊重态度。他们认为，只要孩子有兴趣、肯钻研，上职业学校未必不是一种很好的选择。在日内瓦联合国办事处工作的帕特里克告诉新华社记者，他的孩子上职业技校已经一年，学的是室内设计专业。他认为，假如高端研究人员成堆，失业的风险不可避免。在职业学校只要肯学，学生就可能成为某行业的专家，各行各业都有高素质的人才储备，国家发展创新才有依靠。  
  
得益于职业技校精准的教学内容，走出校门的学子正是社会各行各业所需人才。职业技校毕业生在完成学业后，一般更容易找到适合自己的工作，有的甚至在培训期间就被企业“预定”了。技校生的薪酬也不比高校毕业生差。

  

![](../Images/2480a24c5986868c3e9d30f1fc4e6649.png)  

  

解放日报去年6月有一篇报道中提到，斯蒂凡是日内瓦一家著名钟表厂的技校学生，他中学毕业后选择技校学习钟表制造。经过两年的学习，他和两名同学在师傅的带领下开始组装一套豪华怀表。这套表只有4块，需要一年时间才能完成，但可以卖出3000万瑞士法郎（约为人民币2亿元）的价格。也就是说，作为一名学徒工，斯蒂凡一年可为企业创造1000万瑞郎的价值！他算了笔账：4年技校生活期间，每个月可得到1000瑞郎的报酬，每年有带薪假，毕业后，每月的工资数达5000瑞郎；而上大学的同学，要上3年高中和4年大学，7年后才开始找工作。  
  
瑞士最大的银行——联合银行的大老板施图德尔就是技校出身。据统计，在瑞士日内瓦，75%的老板均出自技校。  
  
当欧洲多个邻国因金融危机而失业率高企时，瑞士的失业率却一直稳定在3%左右。

  

![](../Images/bd2f54d0ec007eb32910272bb1ee90c2.png)  

  

瑞士国土面积只有4.1万平方公里，人口仅800多万。然而，总部位于日内瓦的世界经济论坛每年发布的《全球竞争力报告》排行榜上，瑞士却一直名列前茅，成为全球最具竞争力的国家之一。报告得出了这样的结论：领先经济体具有的共同特征是，对人才合理的培养与使用。  
  
出口世界各地、精致而实用的瑞士钟表、机械等，正是这种人才培育体系下，一代代瑞士工匠们智慧与技艺的结晶。  

  

![](../Images/2e9da5b3dee74882e3d6eea9e4bdf4ee.png)  

# **我为什么要在中国当技工**

#   

# 在中国的传统观念里，技校是学习成绩不好的学生才去读的。家长觉得孩子读技校，将来是技术工人，低人一等，面子上抹不开。长期以来，由于职教生多数是应试教育中相对低分录取的学生，导致有些人认为他们上学就是学一门手艺，混口饭吃。  

  
另一方面，职业院校定位不清，专业设置仿照大学，职业教育特色不突出也是一大问题。中、高职专业课设置和教学内容重复，造成教育资源和学习时间的浪费。专业结构不尽合理，对市场的适应性较差，职业教育存在着重理论、轻实践，重知识、轻能力。

  

![](../Images/e2a2293c0886731d418405efe1664adf.png)  
▲中国商飞上海飞机制造有限公司高级技师胡双钱。图片来自央视

  

对照国外经验，我们可以学什么？一，崇尚一技之长、不唯学历凭能力，培养形成高素质的劳动大军。特别是提高技能型人才的社会地位和待遇，让他们能够凭借自己的手艺获得体面的收入。二，正社会风气。有不少人不甘于做寂寞的工匠，而是期望不劳而获、一夜暴富、飞黄腾达。我们是否该好好思考一下，如何创造“工匠精神”生长的空间？三，企业方面也是如此。根据统计，德国约有370万家企业，其中95%都是家族企业。它们往往专注于某个领域、某项产品，公司小、慢，但是专注。  
  
今年《政府工作报告》发出“培育精益求精的工匠精神”的号召，引发全社会热议，已经带来了很多可喜的变化。4月29日出版的人民日报就举了一个例子：  

  

胡明祥来自日照市东港区河山镇小卞庄村，他现在是青岛市黄岛区职业教育中心学校学生。  
  
小胡在家排行第三，家里不富裕，父母和大姐靠种地供小胡哥俩上学。“我想学技术，一是喜欢，二来减轻父母压力。”胡明祥说，选择焊接技术缘起于参观一家大型造船基地，“有工人拿着一根小棒子发出亮光，不一会儿就把两块分离的钢板拼接在一起，我觉得太神奇啦，当技术工人也挺厉害的！”胡明祥说，他的同学中，大部分是因为考不上大学才来读技校的，“我倒是真喜欢做这个，身怀绝技就有了铁饭碗。我大哥在重点大学读飞行器设计与制造专业，我跟他开玩笑 ‘你这大学生的图纸画得再好，没有我们技术工人，也造不出来飞机啊！’”说这话时，小胡一脸阳光。
