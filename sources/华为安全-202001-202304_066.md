# 国内唯一，华为再次入选2022 Gartner SIEM魔力象限

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwODU5NzYxOA==&mid=2247498091&idx=1&sn=30d92f3fd2ce4915d398bf360d52a83d&chksm=9b6ec076ac19496053da9d808dd9b4f76a51d67e35ddb539d4ca1121c752095606635c6b23cf&scene=126&sessionid=1681371143#rd](http://mp.weixin.qq.com/s?__biz=MzAwODU5NzYxOA==&mid=2247498091&idx=1&sn=30d92f3fd2ce4915d398bf360d52a83d&chksm=9b6ec076ac19496053da9d808dd9b4f76a51d67e35ddb539d4ca1121c752095606635c6b23cf&scene=126&sessionid=1681371143#rd)

2022年10月，业界知名分析机构Gartner®公司发布2022年SIEM（Security Information and Event Management，安全信息和事件管理）魔力象限(Magic Quadrant™)报告，**华为凭借HiSec Insight安全态势感知系统入选了2022年Gartner SIEM魔力象限。**本年度Gartner SIEM魔力象限入选厂商从2021年的20个减少到16个，华为是国内唯一入选Gartner SIEM魔力象限的厂商，也是国内唯一连续两年入围Gartner SIEM魔力象限的厂商。

  

![](../Images/ffd24a83f64d9274023229b0aedaf7bd.png)

  

华为HiSec Insight安全态势感知系统是华为安全的重点战略方向，作为华为智能安全解决方案的分析器，是整个解决方案的“安全大脑”，也是生态构建的基础。凭借全球顶尖安全人才的技术积累和持续的研发投入，华为HiSec Insight安全态势感知系统不断挑战安全业界难题，持续产品打磨和客户实践。

  

华为HiSec Insight安全态势感知系统具备三大方案亮点：

  
**0****1****智能检测：**  

30+全攻击链智能检测，精准识别勒索病毒、挖矿病毒、加密攻击、0day等高级威胁；动态行为检测，智能算法自进化，高级威胁检测准确率>96%。

**0****2****智能运维：**  

自动告警降噪、关联分析聚合，降低无效告警，运维效率提升30%；安全编排自动化响应，支持多租户，灵活满足多分支运维场景。

**0****3****智能防御：**  

云、网、边、端协同联动，威胁事件秒级处置，实现云上、云下统一协同防御，威胁近源阻断零扩散。

目前，华为HiSec Insight安全态势感知系统广泛应用于政府、金融、电力、大企业、教育等众多行业。华为将继续构筑智能检测和智能响应的优势，携手合作伙伴打造高质量的整体安全解决方案来提升企业的安全防护能力和安全运营效率，为客户数字化转型保驾护航。
