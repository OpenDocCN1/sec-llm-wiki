# 聚焦网安周丨华为参加邯郸、承德、沧州等河北省区域网安周，以三大能力构筑网络安全新屏障

随着网络技术的发展，人们的生活越来越离不开互联网，网络安全就显得尤为重要。国家网络安全“顶级盛会”——2022年第九届国家网络安全宣传周在河北邯郸、承德、沧州等地拉开序幕。大会由中央宣传部、中央网信办、教育部、工业和信息化部等部门联合举办，汇集了网络安全行业领先企业和行业专家。大会以“网络安全为人民，网络安全靠人民”为主旨，聚焦网络安全技术，宣传网络安全理念、普及网络安全知识、推广网络安全技能，重点展示网络安全领域新型产品及示范应用。**作为全球领先的ICT基础设施和智能终端提供商，华为始终以网络安全为公司的最高纲领，“2022国家网络安全宣传周”期间，华为携全新升级的安全解决方案、明星产品、核心技术亮相邯郸市博物馆C2展区。**

![](../Images/8d72cf0da24137cecc30995497d06736.png)   

过去30年，华为服务全球30亿以上的人口，支持全球170多个国家和地区的1500张运营商网络的稳定运行，在全球范围内一直保持着良好的网络安全记录，在网络安全上的实践得到客户的广泛认可。华为提出基于“正向建、反向查”构建安全可信一张网的网络安全建设目标，华为HiSec3.0智能防御体系具备全流程安全可信、全智能威胁防御、全云网边端协同、全新安全云服务等优势，并以此来构筑云网边端一体安全防护体系。

**华为乾坤安全云服务三大能力，**

**构建智能运营服务体系**

随着数字化转型的深入和互联网+应用的快速普及，网络安全的重要性也越来越高，本质上数字化程度越高伴随着的就是安全风险也越高。各企事业单位会投入大量资金采购安全产品及方案进行安全建设，但是对于大部分企业和客户来说，没有充足的预算也没有专业的安全队伍，但他们也有强烈的意愿做好安全建设和运营，针对传统安全方案无法适配广大用户安全诉求的现状，华为推出了华为乾坤安全云服务。

  

华为乾坤云服务具有三大能力。首先服务按需订阅，本地天关扫码开局，“零配置”上线，云端的SaaS服务也即时开通。其次能力实时更新，不管是云端、还是本地天关的防御能力，都是实时在线升级且同步的，任何一个地方检测到威胁，全网立即同步共享威胁信息，实现分钟级全局免疫。第三，威胁自动闭环，华为乾坤采用云边端一体化的安全架构，云端分析的威胁可以自动化处置，自动化处置率高达96%，做到实时感知全局威胁，秒级闭环。

  

在具体应用场景上，以近期国家发改委重拳整治“挖矿”为例，虚拟货币“挖矿”能源消耗和碳排放量大，其盲目无序发展对推动经济社会高质量发展和节能减排带来严重不利影响。防挖矿对促进我国产业结构优化、推动节能减排、如期实现碳达峰、碳中和目标具有重要意义。华为乾坤可以提供服务化的防挖矿解决方案，云边协同通过云端海量的矿池域名信息、网络侧的挖矿协议和行为分析，结合AI智能分析，可以快速发现挖掘主机并实现精准处置。全方位展现了华为乾坤安全云服务的简单、智能、快速的特质，安全实效触手可及。未来华为将持续打造更多服务化场景解决方案，让网络安全变得越来越普惠、越来越简单。

**华为全新HiSec 3.0安全解决方案，**

**构筑云网安端一体安全防护体系**

华为全新的HiSec 3.0安全解决方案，采用云端、本地、边缘三层架构，构筑云网安端一体安全防护体系。解决方案具有全新的四大亮点：全流程安全可信、全智能威胁分析、全云网边端协同、全新安全云服务。

  

华为HiSec安全解决方案已经广泛应用在各行各业，在全场景行业实践展位，重点介绍了政府等行业解决方案及应用实践。华为在政府行业通过云网安一体架构构筑了电子政务一体化安全防护体系，该体系为客户提供三大价值方案。第一、一机两用终端零信任解决方案，该方案具备严防一机双用、政务敏感数据防泄露关键能力，实现终端安全防护的动态授权和防护。第二、政务安全检测一体化方案，该方案云内东西向流量和云外流量检测，构筑威胁全域监测和统一运营能力。第三、IPv6+网络安全一体防护解决方案，该方案基于APN6精准溯源，威胁事件通过广域网/城域网溯源到委办局接入位置，近源阻断威胁。

**构筑端到端的全球网络安全保障体系，**

**护航千行百业数字化转型**

数字化发展已经上升为国家战略，网络安全是数字世界的基石，网络空间安全已经影响到国家安全、社会效率、公民隐私等诸多方面，做好网络安全防护仍然面临重重挑战，任重道远。华为在网络安全领域有着20余年的专业积累，华为拥有6大安全技术实验室，5大安全研发团队。华为认为在当前数字化蓬勃发展的浪潮下，提供安全可信的网络安全基础设施尤为重要。华为一直在研发全流程构筑安全可信能力，关键核心器件实现自主研发，保障供应链安全。

  

  

在数字化转型的大趋势下，华为将继续在网络安全技术创新上持续投入，依托强有力的产品，打造顶尖的网络安全解决方案，继续强化各领域安全防护体系构建，守护网络空间安全，为数字化转型提供坚实安全保障。
