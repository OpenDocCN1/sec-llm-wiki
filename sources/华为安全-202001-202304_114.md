# 华为乾坤，立根铸本，为数智时代而生

**华为乾坤亮相IPv6及下一代互联网安全论坛 打造数智时代网络安全底座。**

  

9月6日，2022年国家网络安全宣传周期间，IPv6及下一代互联网安全论坛在合肥同步举办。本论坛汇聚众多工程院院士、国内顶尖安全专家学者，共同探讨新形势下，如何更好地守护国家网络基础设施安全。华为NCE数据通信领域副总裁王辉受邀参加，并发表主题为《构建IPv6+智能安全防线，筑未来信任基石》的主题演讲。

![](../Images/b9a5e754a00985e448667ca45dc2833a.png)

华为王辉发表主题演讲

  

  
**国际形势加剧网络安全风险，****自主可控网络不等于安全可信**

今年以来，受国际形势等因素影响，全球针对网络安全的攻击呈指数增长，特别是数智时代的到来，我国各类关键基础设施实现了与数字化的深度融合，网络基础设施的安全和自主可控获得了更高的关注。

  

与此同时，IPv6新技术优势逐步兴起，并广泛应用在下一代业务中，如物联网、云、无线业务等，这对建立国家数字主权有着重要的意义。相比IPv4， IPv6虽然有诸多安全方面的优势，但是IPv6依然存在大量的安全隐患，例如IPv6引入了很多与IPv4基本一致的协议，针对这些协议的攻击方式依然有效；IPv6的海量地址空间也给漏洞扫描和资产发现带来困难；IPv6部署范围小，漏洞暴露不充分，攻击的威胁信息库也很有限。

  

由此可见，企业数字化引发安全边界外扩，传统的“外挂式”安全方案无法防范突破边界的攻击，事事流程都要靠人来保障，企业急需构建一个全面监控、提前预知、及时反制的安全网络防御体系。

  

![](../Images/e22ad9449f9f3c2f36748a634979c28d.png)

新形势下网络安全面临的挑战  

在新形势下，网络安全产业面临如下**三大挑战****：**

  

**挑战1：国家网络空间冲突愈演愈烈，关键基础设施单位网络防御挑战大。**

由“黑客”冲锋的网络攻防战，已成为物理对抗以外的第二战场，金融、能源等关键基础设施单位的整体防御等能力亟待加强。

  
  

**挑战2：传统“先建网络，再补安全”管理模式，无法实现安全的可见性和安全效能。**

网络关心的是转发时延，安全则注重传输内容。现实中攻击流量往往与真实流量混杂，需要网络与安全的统一融合。

  
  

**挑战3：网络威胁持续进化，碎片化的安全工具无法抵挡现代化的攻击。**

随着网络威胁的持续进化，要真正实现“防坏人，管好人”的目标，需要提供一个充分开放、连通、可扩展的云化平台来整合广泛分布的网络、数据和安全工具。

  

![](../Images/869900b14afd9754227336138692d70f.png)

华为重新定义安全模式：Unified Security Network

  

面对以上挑战，华为一直在寻找破题之法。经过不断探索与反复实践，华为重新定义了“**Unified Security Network”的安全新模式，基于网安一体、设备可信、原生智能构建统一的安全网络。**

  

**设备可信****：**首先，需要建设一个全面可信的ICT基础设施，通过硬件可信、操作系统可信、软件可信，来构建ICT基础设施的“可信基座”。

  

**网安一体：**基于门类全、功能强的网络通信设备，获取最全面的网络实时数据。可基于网络数字地图（涵盖拓扑、策略、流量、路径、终端、人和应用等），同时结合安全数据统一进行分析建模，提供最完整的企业MDR（托管检测和响应服务）和XDR（扩展威胁检测和响应），让企业安全从监控采集，到抵御防护各个方面做到极致。

  

**原生智能：**基于云边端一体创新架构，提供一站式的安全和网络服务，让安全成为网络的默认属性，为企业带来网络安全智能防护新体验。

  

  

**边侧：**基于融合路由、防火墙、加速代理、安全审计等功能的智能机，实现一台设备按需加载App，完全融合网络和安全功能。网络设备可以订阅安全能力，安全可以管理网络设备，实现网安一体。

  

**端侧：**安全终端融合接入、杀毒、入侵检测与响应等功能，整合网络准入和应用信息，实现终端接入可信、应用可信。

  

**云端：**基于网络管理服务、安全管理服务、边界防护服务、SDWAN服务、日志审计服务等自由组合服务，提升客户运营效率的同时保护客户投资。

![](../Images/5c713b46fd0b2e4b962f47eba2c5bc5f.png)

华为乾坤，立根铸本，为数智时代而生

  

华为凝聚公司35年在网络和安全的研发能力，打造了自主可控、E2E可信、网安一体、原生智能的华为乾坤，通过芯片、系统、平台、设备和软件的全栈自主研发，实现了自主可控，从根上保障E2E可信和原生智能，为客户提供网安一体的数字化服务。

  

![](../Images/7f71db9492fc9a73df02ef5784ba500d.png)
