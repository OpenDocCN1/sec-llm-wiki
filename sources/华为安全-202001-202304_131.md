# 晋阳湖·数字经济发展峰会｜云网安一体，助力数字政府安全建设

\[中国，山西太原，2022年8月18日\]初秋时节，龙城太原已褪去暑热，以清凉迎接8月18日至20日举办的晋阳湖·数字经济发展峰会。本届峰会定位数字经济，以“数字筑基、创新引领、绿色发展、拥抱生态”为主题，既是贯彻落实国家大力实施数字经济发展重大战略的集中体现，也是进一步发挥峰会蓄势赋能作用的充分考量。旨在深化新一代信息技术在各行业领域示范应用，加快产业转型升级，推动数字经济高质量发展，以数字经济赋能实体经济。

  
  
  
华为作为网络安全的引领者，肩负着国内安全建设使命，一直深耕网络安全产业。本次华为数据通信产品线安全产品领域副总裁王任栋在数字政府论坛发表了**《云网安一体，助力数字政府安全建设》**主题演讲。  

  

![](../Images/52f8a0e428ff15b6bc34a3571e04a5f0.png)

华为数据通信产品线安全产品领域副总裁王任栋

  

王任栋在演讲中重点介绍了**数字政府云网安一体安全解决方案**。该方案包括零信任安全、云网安协同、安全云服务三大领先能力，构筑“安全可信”的数字政府安全底座。王任栋表示通过零信任安全构建持续风险评估、逐次授权的动态信任模型；云网安协同实现联防联控，精准溯源，威胁自动处置；安全云服务本地轻量部署，通过云边融合的创新架构，打造简单高效、安全可靠的云化安全服务。

**能力1：零信任安全**  
  

**终端侧**针对政务办公终端、移动终端和物联终端，采用终端标识，终端可信准入验证，实现终端零信任；**用户侧**对访问的主体进行统一的身份标识、可信身份验证，实现身份零信任；**网络侧**采用智能检测技术进行全面的威胁检测与防御，实现流量零信任；**应用侧**采取单一应用访问方式对应用进行集中管控，实现应用零信任。构建终端、用户、网络、应用四维零信任实现终端接入全面感知管控，构建零信任接入访问安全体系。

**能力2：云网安协同**  
  

云网安协同进一步夯实IPv6能力，围绕网络层、管控层和分析层打造纵深防御、业务编排、全域监测的立体防御体系，并支持基于SRv6的安全资源池按需引流防护和基于APN6精准溯源，威胁事件关联溯源到设备，网安协同处置。确保网络建设的先进性，支撑未来网络安全的持续演进。

**能力3：安全云服务**  
  

为了解决政府各委办局单位安全运维工作量大、运维难度高、实际防御效果差的问题，华为创新性地提出乾坤安全云服务的业务模式，通过云边融合的创新架构，打造简单高效、安全可靠的云化安全服务。针对一些用户网络无法通过互联网连云的场景，以及一些用户业务数据敏感不能连接云服务的场景，华为推出云服务本地部署模式。各委办局单位出口部署天关设备，在政务云上本地部署10+种网络安全云服务，通过云服务模式即订即用多种安全能力。服务开通快、持续升级快、威胁处置快，解决大部分单位的安全服务化诉求。

  

  
![](../Images/9abb26ef3fb31b7d6f3118aa79762a77.png)  
华为数字政府云网安一体安全解决方案通过端侧可信访问、网侧纵深防御、云侧全面监测和服务化智能运营，为政务园区网、政务外网和政务云提供端到端一体化安全保障，护航政府数字化转型。  
除了上述的安全能力外，华为认为在当前政府数字化蓬勃发展的浪潮下，为数字化转型提供安全可信的网络安全基础设施尤为重要。华为一直在研发全流程构筑安全可信能力，关键核心器件实现自主研发，保障供应链安全。未来华为将继续在安全根技术和解决方案创新上持续投入，为数字化转型提供坚实安全保障。
