**0****1****热点事件一**  
**Spring Data MongoDB CVE-2022-22980 SpEL表达式注入漏洞简介**

  

**TA是什么？**

2022年6月22日，华为乾坤感知Spring Data MongoDB组件** 3.4.0、3.3.0、3.3.4，以及更早的版本**存在漏洞。当系统使用@Query或@Aggregation注解进行查询时，若通过SpEL表达式中形如“?0”的占位符来进行参数赋值，同时应用程序未对用户输入进行过滤处理，则Spring Data MongoDB可能受到SpEL表达式注入的影响，成功利用该漏洞的攻击者可在目标服务器上执行代码。

  

华为乾坤**迅速启动应急响应机制**，分析漏洞原理，并面向全网率先发布针对性防御特征库，为用户网络安全保驾护航。

**02****热点事件二**  
  
**Atlassian Confluence Server and Data Center   CVE-2022-26134 远程代码执行漏洞简介**  
**TA是什么？**

2022年6月4日，华为乾坤感知到Atlassian Confluence发布了CVE-2022-26134漏洞补丁。Atlassian Confluence Server and Data Center存在OGNL注入漏洞，漏洞等级高危。该漏洞允许远程攻击者在服务端执行任意代码，**建议广大用户及时排查，对受影响的产品进行升级或安装补丁**。

  

华为乾坤迅速启动应急响应机制，分析漏洞原理，并面向全网率先发布针对性防御特征库，为用户网络安全保驾护航。

**专家观点**

  

通过持续跟踪现网，6月0day漏洞集中于**通用组件漏洞及企业应用漏洞，此类漏洞危害度高、修复成本高，攻击者利用难度降低**，建议客户排查**是否有引用问题版本软件，对受影响的软件进行升级或安装补丁**，避免遭受黑客的攻击。华为乾坤依托强大的安全专家团队，第一时间捕获现网0Day并开展分析，快速发布针对性防御特征库，将专家经验与AI能力结合，实现对攻击者的自动识别，并全局快速共享威胁信息，秒级封禁攻击源。

  
  
  
**03****现网安全态势—医疗行业**  
  
  
**0****1****失陷主机持续增加，狙击病毒迫在眉睫**

  

随着国家数字化进程的不断深入，医疗行业数字化建设也如火如荼，电子系统、业务、个人数据的不断增多，行业面临的网络威胁也愈加频繁。

  

华为乾坤统计，6月份医疗行业客户主机感染失陷类型告警**共4310**起，其中**挖矿病毒占所有恶意程序类型的37%**，其次为Ramnit病毒。数据表明，约65%的客户存在主机失陷情况，狙击病毒已经成为网络安全防护的主要任务。

  

感染病毒的失陷主机多集中于办公PC主机，由于网络安全防御能力薄弱，成为各类病毒的混乱战场，**部分客户的失陷主机数量高达100+**。由于感染病毒类型众多且存在同网段传播行为，造成短时间清除失陷主机的难度极大。

  

![](../Images/34ad6dd1572dbec71ff60cba2ec8872f.png)

TOP 10病毒类型统计分布  

  

  

  

**专家观点**

各类主机病毒通常使用**暴力破解、组合漏洞、激活软件等方式**进行传播，尤其在办公场景下，**PC下载或点击不明文件**，极易感染病毒。针对传染性病毒，当转发感染病毒的医疗文档或医疗工具等文件，传染速度会指数性提高。由于医疗行业业务的复杂性、业务定制性，导致感染病毒后，难以在短时间修复，再次延长了响应时间。

**建议客户对新业务主机或系统摸底排查，防范存在携带恶意文件情况，同时加强安全运维监控，严格限制访问互联网的区域 ，组织开展员工培训，提升安全意识，杜绝无意下载或点击病毒。**

  

华为乾坤依托全网情报，持续对失陷主机病毒进行特征及行为跟踪分析，同时天关设备具备恶意文件防护能力，实现对失陷主机病毒的**全面检测、快速阻断、快速通知。**

  

  

**0****2****0Day、NDay漏洞组合攻击，业务风险徒增**  

根据华为乾坤统计，6月份**医疗行业**客户遭受外部攻击**共36万起**，**攻击方式800多种，约80%攻击为直接漏洞攻击**，攻击目的十分明确。

  

同时华为乾坤发现，6月最新安全漏洞【Spring Data MongoDB CVE-2022-22980 SpEL表达式注入漏洞】攻击痕迹，从漏洞技术细节公布，**到发现成熟的现网自动化攻击，时间间隔仅为1天**，防护形式严峻。

  

![](../Images/2e080705a6948ddf49c027d1d389bb01.png)

TOP外部攻击事件

  

  

**专家观点**

目前数字医疗发展迅猛，**医院等机构**建立大量系统，快速迈向智能化，如在线问诊系统或挂号系统等，新系统建设的同时，也逐步引入了新的系统组件，产生了新的漏洞风险。

  

由于医院系统特殊性，系统升级流程缓慢，在面对现网0day漏洞或NDay漏洞攻击中，感知较弱。同时**存在网络区域混合问题**，导致网络系统直接面临大量的互联网攻击。

  

华为乾坤边界防护与响应服务，可**快速更新现网特征库，秒级阻断或下发黑名单，**覆盖0Day及NDay漏洞防御，保障客户安全时效。

  

  

**0****3****对外暴露资产众多，攻击面收敛缓慢**

  

华为乾坤安全运营团队，对医疗客户的对外开放业务分析统计显示，**平均每个客户对外开放11例端口，其中80%为WEB业务**，业务包含医疗管理平台、办公协同OA系统，业务系统存留大量的医疗敏感数据，此部分业务一旦被不法分子控制，大量敏感数据将遭受泄露或遭遇勒索病毒，可能将**导致医疗数据被强行锁死、医院系统瘫痪，**严重影响医疗行业的正常业务开展。

  

其余对外开放的端口**包含RDP远程桌面、Telnet、SSH等**业务。部分大型机构业务逐步上云，导致本地业务与云上业务的割裂，对于整体网络中的**物理划分、功能划分、安全等级**划分等也带来巨大安全防护挑战。

**专家观点**

医疗机构的安全威胁**主要在于应用漏洞及敏感业务**，例如**远程登录、数据库、FTP等**服务。日常的运维运营，健康医疗机构要**定期针对内外网排查高危漏洞、弱口令、开放的高危端口等**情况，及时进行防御修护，并且尽量关闭不必要的服务端口，定期对医疗信息化安全系统进行全面体检。

  

华为乾坤漏洞扫描服务及互联网开放端口检测服务可快速发现现网风险项，提升攻击者攻击成本，保障客户安全时效。
