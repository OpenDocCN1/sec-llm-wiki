**0****1****Spring4Shell (CVE-2022-22965)远程代码执行漏洞攻击**  
****TA是什么**？**

Spring 是目前全球最受欢迎的 Java 轻量级开源框架，3月底互联网爆出Spring框架存在RCE漏洞，该漏洞影响在 JDK 9+ 上运行的 Spring MVC 和 Spring WebFlux 应用程序，非授权的攻击者可利用该漏洞获取服务器的控制权限。**华为乾坤迅速启动应急响应机制，分析漏洞原理，**并面向全网率先发布针对性防御特征库，为用户网络安全保驾护航。3月31日凌晨首次捕获到现网攻击，根据华为乾坤持续观测，4月1日针对该漏洞的攻击达到峰值。

  

![](../Images/aeae1fc954071e39279264f1cea0c253.png)

应急响应流程

  
**现网观测**

华为乾坤全网数据显示，约17%的用户已经成为攻击者的攻击目标。3月31日，漏洞爆发的第一时间，华为乾坤就检测到了大量攻击，被攻击对象集中于**政府、教育、医疗、制造业**等领域。4月1日，现网攻击频率达到巅峰，后续呈逐步下降趋势，**华为乾坤持续为用户提供全面防护，分钟级识别并自动封禁攻击者IP。**

![](../Images/73e06da2a864ce9791e0309dab8cb026.png)

攻击趋势图

  

华为乾坤对攻击源归属地进行分析，TOP3攻击IP归属地域为：A国、德国、英国，对攻击源进行威胁信息分析，发现其中半数攻击IP为首次投入使用。

![](../Images/3cf779ca63e676ffd0c75783bf2f32c5.png)

攻击源归属地统计

  

**专家观点**

通过持续跟踪现网，华为乾坤发现0day漏洞呈现逐年快速递增的趋势，且由漏洞爆出到武器化时间越来越短，攻击组织往往会启用资源池中的未被威胁信息收录的地址，以增加攻击行为的隐蔽性，避免攻击被捕获，延长攻击的时间窗。华为乾坤依托后端强大的专家团队第一时间捕获现网0day并开展分析，快速发布针对性防御特征库，将专家经验与AI能力结合，实现对攻击者的自动识别，并**全局共享威胁信息，分钟级封禁攻击者IP**，缩短攻击时间窗。  

  

  

  

  

**0****2****BlackMoon僵尸网络大规模传播**

  

******TA是什么**？****

BlackMoon是一个具备远控和DDoS攻击能力的僵尸网络，据国家互联网应急中心CNCERT数据显示，BlackMoon僵尸网络在互联网开始大规模传播，截止到22年1月，终端感染规模已超100万。BlackMoon僵尸网络传播方式之一是借助独狼（Rovnix）僵尸网络进行传播。**独狼僵尸网络通过带毒激活工具（暴风激活、小马激活、 KMS等）进行传播，**常被用来推广病毒和流氓软件。

  
**现网观测**  

华为乾坤现网观测发现，该木马已经完成一次版本更新，两个版本样本的行为特征如下图所示，华为乾坤通过对该僵尸网络的持续跟踪和分析，已实现对BlackMoon特征的全面覆盖：

**0****2****企业案例**

华为乾坤全网数据显示，被攻击对象集中于**教育行业、中小科技企业。**以四川某科技行业客户为例，该客户被感染主机已超300台，严重影响生产办公等日常工作的开展。

![](../Images/766c1f1d29824f0362df6208e6b15b56.png)

  

  

**专家观点**  

BlackMoon是近期新出现的僵尸网络，**借助带毒的系统激活工具等**实现了快速传播，这也是大量恶意软件传播的渠道，大家在日常工作过程中应**避免从不可信的网站下载此类激活软件**，避免遭受不明感染。华为乾坤依托全网威胁信息持续对流行恶意软件进行跟踪分析，实现对恶意软件的全面检测覆盖。  

  
![](../Images/9ebebf61ce70348962520c96629e50b2.png)**华为乾坤****精准防御**![](../Images/44cc6b3ff9de775366c8031c6705157d.png)![](../Images/69f174eb8c6e84bf17b9c5fdb58b9f75.png)**APP扫码，开通服务**![](../Images/a91e5b3e7b98900362c449dc71ebfba6.png)**一处检出，全局免疫**  
![](../Images/12e0b68193ba8e9912b95bc9d266bef0.png)**自动处置，秒级闭环**![](../Images/3dd5ee2ea6a776d619c2ad75240172f2.png)**专家观点一**  
  

**高危服务对外开放危险大，建议用户持续监测并关闭非必要服务。**

据华为乾坤统计，客户对外开放的TOP2业务为HTTP、HTTPS，占比分别是44%、34%，即web业务占比为78%，但依然有一定数量的用户将SSH服务、Telnet服务、Ftp服务、MySQL服务、RDP服务等高危服务直接暴漏到公网，高危服务占比10%，存在比较大的风险隐患。据华为乾坤现网实验，对外开放一个 RDP远程桌面服务，经过15分钟就遭受到来自国外5个攻击IP的暴力破解攻击。**用户可通过部署漏扫设备对开放的端口和服务进行定期扫描，并及时关闭非必要开放的端口和服务。**

![](../Images/28dba0cfd7a3f554c8593be254570e65.png)

公网开放服务统计

  

  

RDP、SSH、MySQL等高危服务，往往会受到攻击者的重点关注，攻击者通过暴力破解、漏洞利用等获取服务器权限进而进入企业内网，实施勒索、挖矿等攻击。如果没有必要，禁止对公网开放高危服务，如果业务需要，可采用白名单访问策略，并设置高强度的口令。**华为乾坤具备持续的用户公网服务开放监测能力并主动识别高危服务。**

  

![](../Images/3dd5ee2ea6a776d619c2ad75240172f2.png)**专家观点二**  
  

**失陷主机破窗效应明显，建议用户及时对失陷主机进行隔离查杀。**

破窗效应：如果有人打坏了一幢建筑物的窗户玻璃，而这扇窗户又得不到及时的维修，别人就可能受到某些示范性的纵容去打烂更多的窗户。企业内部失陷主机在感染的病毒现象方面也遵循破窗效应，华为乾坤全网数据显示，5%的失陷主机同时感染了多种病毒。在本月应急响应的案例中发现，某上市企业的服务器被植入了Wannamine、麻辣香锅、Xred、CARROTBAT、Autolt3、 Ramnit 共计6种病毒，根据病毒文件时间，梳理各病毒感染过程如下图所示。**用户可利用本地杀毒软件或人工处理对失陷主机进行隔离查杀，梳理主机的薄弱点并加固。**

![](../Images/30bb381d9ca14146ee3e6e1c76300879.png)

主机感染病毒流程

  

失陷主机会导致企业内网面临持续性的安全威胁，如果不及时查杀病毒并修复漏洞，可能面临多种病毒的反复感染，造成企业财产的重大损失。**华为乾坤可秒级识别用户网络中的失陷主机并主动进行邮件、短信通知，对挖矿、C&C等恶意流量进行实时阻断。**

  

  

![](../Images/3dd5ee2ea6a776d619c2ad75240172f2.png)**专家观点三**  
  

  

**外部攻击强度大，建议用户及时封禁攻击源。**  

华为乾坤全网数据显示，平均每个用户每天会受到来自近百个攻击源的超8000次网络攻击，中高危攻击占比超90%，其中运营商、政府、医疗、教育、制造业等行业面临攻击较为严重。**用户可通过在边界安全防护设备主动封禁攻击源，阻断攻击者的持续攻击。**

  

![](../Images/1e05df36172309ed8a63d138621118a3.png)

  

网络攻击无处不在、无时不在，会对企事业单位的生活生产造成严重影响，我们需要能够自动识别攻击者并从源头对攻击进行封堵，为安全生产保驾护航。**华为乾坤将专家经验与AI能力结合，实现对攻击者IP的自动识别，并全局共享威胁信息，分钟级封禁攻击源。**
