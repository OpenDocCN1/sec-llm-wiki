**漏洞概述**  

2021年09月08日，微软发布了位于MSHTML组件的漏洞通告，编号为CVE-2021-40444，CVSS 3.0评分为8.8，**漏洞等级为高危**。

  

MSHTML是微软的浏览器渲染引擎，**在Office套件、IE浏览器中广泛应用**。攻击者可构造带有恶意ActiveX控件的Office文档触发漏洞，**成功利用可在目标主机执行任意代码。微软表示已检测到针对该漏洞的在野利用样本，目前尚无补丁发布，**建议广大用户及时做好预防工作。

**受影响的产品**  

\- Microsoft:MSHTML

  

说明：所有涉及使用ActiveX控件调用MSHTML组件的产品，都受此漏洞影响，包括Windows Server 2008、Windows 8.1、Windows 10各个版本操作系统上的Office 365、Office 2019等。

  

  
**解决方案**  

当前微软尚未发布安全补丁，建议关注如下官方声明链接，待补丁发布后及时更新。

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-40444

在这个声明链接中，也给出了两个临时解决方案。

  

**方案1：**

**禁用IE浏览器中的ActiveX控件**

  

根据微软官方建议，创建以下内容的x.reg文件，双击执行后重启操作系统，即可防护针对该漏洞的攻击。

  

Windows Registry Editor Version 5.00  

  

\[HKEY\_LOCAL\_MACHINE\\SOFTWARE\\Policies\\Microsoft\\Windows\\CurrentVersion\\Internet   Settings\\Zones\\0\]

"1001"=dword:00000003

"1004"=dword:00000003

  

\[HKEY\_LOCAL\_MACHINE\\SOFTWARE\\Policies\\Microsoft\\Windows\\CurrentVersion\\Internet   Settings\\Zones\\1\]

"1001"=dword:00000003

"1004"=dword:00000003

  

\[HKEY\_LOCAL\_MACHINE\\SOFTWARE\\Policies\\Microsoft\\Windows\\CurrentVersion\\Internet   Settings\\Zones\\2\]

"1001"=dword:00000003

"1004"=dword:00000003

  

\[HKEY\_LOCAL\_MACHINE\\SOFTWARE\\Policies\\Microsoft\\Windows\\CurrentVersion\\Internet   Settings\\Zones\\3\]

"1001"=dword:00000003

"1004"=dword:00000003

  

**方案2：**

**使用Microsoft Defender进行防护**

  

微软的Microsoft Defender Antivirus和Microsoft Defender for Endpoint产品已支持针对该漏洞攻击的检测和防护：用户需要开启自动更新以保持反病毒产品处于最新版本，对于手动管理更新的企业用户，需要部署build 1.349.22.0或以上版本。

  

Microsoft Defender如果检测到该事件，其名称为“Suspicious Cpl File Execution”，请广大用户关注。
