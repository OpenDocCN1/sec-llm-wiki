# RSA2021丨从安全到韧性：以退为进，守住安全底线

本次RSA大会的热门话题，除了近几年比较火的零信任、威胁情报、云安全（SASE）、5G安全、人工智能等客户直接可感受的解决方案以外，还有一个突出的特点，就是有好几个话题涉及到了产品和解决方案自身的安全可信：包括本次大会的主题Resilience，以及供应链安全、数据安全和隐私等。数据安全和隐私是前几年的热点，这里不再讨论，重点关注前两点。

  
![](../Images/37c80c48e535ba231d6e898f0a82bb72.png)![](../Images/37c80c48e535ba231d6e898f0a82bb72.png)

  

开幕式上的第一个演讲者是RSA首席执行官Rohit Ghai，他分享的主题是“A Resilient Journey”，网上许多人翻译成“弹性之旅”，**我们更愿意翻译成“韧性之旅”，因为前者主要含义是业务扩展情况下的系统伸缩能力，而后者才体现在安全攻击和压力下的系统坚韧程度。**今年的RSA大会至少有10个以上的主题演讲直接探讨韧性，而在往年最多也就3到5篇，可以看出一个安全系统韧性方面的能力，已经成为企业客户和安全厂商普遍关注的话题。

  

韧性这个主题，和华为在安全能力构建上近几年的努力不谋而合。Rohit Ghai举出的飞机加固的案例，也是华为在构建安全韧性能力中经常引用的例子。而IPDRR模型是NIST提出的，华为也是采用的这个方法论。

  

![](../Images/6400e1c85e66fe1932cb1cfa3cd3b724.png)

  

从2018年起，**华为实施网络安全2.0战略，其核心就是实现网络韧性。**在网络安全1.0时代，更多关注的是产品安全、服务安全、供应/交付和验证安全、人员安全，这些也是客户侧更为直接感受得到的。而网络安全2.0则面向未来有进一步的假设和规划。云计算、万物联接、人工智能等新技术将对ICT 产业带来深刻的改变，也带来了更大的网络安全挑战和机遇。在新形势之下，基于“网络环境是不安全的，网络攻击是常态化的”假设，华为启动网络安全2.0 工作，**目标是把网络安全打造成华为产品、解决方案和服务的核心竞争力之一，助力客户实现网络韧性。**

  

2019年初，华为启动可信变革工作，目标是全面提升软件工程能力与实践，打造可信的高质量产品。在这项工作中，把**可信总结为六个方面的要求：可靠性，可用性，Safety安全性，隐私，Security安全性以及韧性（Resilience）**，韧性在华为研究并提出得最晚，却是可信变革的核心内容。这六个要求的关系如下图所示：

  

![](../Images/79198cb631160dee60dd6b5606a5ad79.png)

  

从这个定义中，可以看到安全和韧性的核心差别。**安全性（Security）是指产品有良好的抗攻击能力，保护业务和数据的机密性、完整性和可用性，而韧性（Resilience）指系统受攻击时保持有定义的运行状态（包括降级），遭遇攻击后快速恢复并持续演进的能力。**

  

同时，可信远不止是一个技术问题，而是涉及到管理、流程、文化等多方面的系统工程，**华为定义了可信任框架**如下：

  

![](../Images/b4e7a4b0749a7c2ba5713afe5815a302.png)

  

**每一个产品在产品定义和完整实现环节、在创新中融入可信思考和控制，从源头就注入可信；保证产品从创新到客户现场的整个过程是完整、双向一致可追溯的，并在必要的时候提供恰当的（权限分离、信任、行为监控）机密性保护，确保产品没有被仿冒、篡改，确保部署、维护、处置作业过程和作业工具可信，敏感数据没有被泄漏；各产业通过可信产品定义、可信系统设计、可信软件实现、可信交付运维、产品生命周期管理的变革，最终实现过程和结果的可信。**

  

这里其实已经涉及到了本次RSA大会的另一个热点：**供应链安全。**供应链安全成为热点，一定程度上是因为2020年底的SolarWinds事件，另一个典型的事件是2015年的苹果XcodeGhost开发环境事件，加上今年4月刚刚曝出的明尼苏达大学研究人员植入Linux内核漏洞的研究，都说明供应链安全问题离我们并不遥远，技术上也不是那么困难。

  

中国的制造类公司走向海外，最容易受到的这类安全问题的怀疑和挑战。华为是走向海外最早的公司之一，遇到了很多挑战。华为在2016年6月就发布了针对解决供应链风险的《全球网络安全挑战》白皮书，详细阐述了华为的观点和经验。

  

![](../Images/985660304d4dd84c62693421c5278a75.png)

  

华为认为，蓄意破坏会出现在供应链的任何活动中。因此，不仅要关注单一活动，还要关注整个供应链，这很重要。供应链威胁分为两个主要类型——受篡改产品和伪造产品。可以导致受篡改和伪造产品的威胁包括：恶意软件、未授权部件、未授权配置、废弃或不合格部件、未授权生产、蓄意破坏。为了应对供应链风险，华为建立了一个符合ISO 28000的全面供应链安全管理体系，从来料到客户交付的端到端流程中识别和控制安全风险。
