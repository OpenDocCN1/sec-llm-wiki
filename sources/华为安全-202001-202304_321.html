01

事件概述


当地时间5月7日晚，美国最大的成品油运输管道运营商公司Colonial Pipeline在其一份声明中称，该公司遭受勒索软件攻击，受攻击影响暂停了所有管道的运行。同时，美国运输部发布了紧急立法，放宽了陆路石油运输规则，以减轻勒索软件攻击造成的供应中断。


 

Colonial Pipeline在美国东海岸分发了几乎一半的石油相关燃料，该起事件成为勒索软件攻击影响关键基础设施运作的最新事件。



02

事件分析


5月10日，相关调查机构发表声明，确认将Colonial Pipeline攻击归因于DarkSide勒索软件组织。DarkSide在2020年8月被发现，由几家勒索软件制造商联合创建，期望制造“完美的产品”以满足需求。从技术角度来看，该勒索软件与同类软件无太大区别。但是，该组织以类似公司的方法运营勒索软件业务开创了业界的先例。


从该起事件回头看勒索软件攻击演变的趋势，从攻击目标上，从蠕虫式广撒网攻击逐步演变为针对特定行业和组织的定向勒索攻击，勒索赎金越来越大，勒索攻击逐渐演变成APT+勒索形式，成功的勒索会加速勒索攻击资源向头部聚集，进而提升攻击的技术，防御方急需建立纵深的防御体系；从勒索方式上，经过多个阶段的演变，逐步形成了更复杂的勒索方式，迫使受害者不得不交付赎金。




第一阶段：

只是勒索软件，加密文件，然后删除勒索，攻击者等待在比特币付款。



第二阶段：

两次勒索。阶段1 + 数据泄漏，并威胁要发布数据。如Maze 。



第三阶段：

三重勒索。阶段1 +阶段2并威胁使用DDoS。如：Avaddon。



第四阶段：

四重勒索。第1阶段+（可能是第2阶段或第3阶段）+ 直接通过电子邮件发送给受影响的受害者的客户群，让受害者的客户施压受害者支付赎金。如：Cl0p。 


虽然勒索技术发生了显著的变化，但从入侵方式上，调查显示在所有导致勒索软件攻击的网络破坏中 RPD 占比达到 70-80％，因此围绕RDP账户、口令的防护依然是首要问题。



03

勒索事件应急处置建议


3.1
主机侧


1. 隔离被勒索的设备，拔掉网线或者修改网络连接设置等，防止勒索软件进一步传播。


2. 保留被攻击设备现场，求助专业技术人员进行取证操作，以便分析勒索软件的攻击路径。


3. 在局域网内其它未感染设备上关闭或者设置常见高危端口（包括135、139、445、3389等）等的访问策略。


4. 如果内网中其它设备使用了相同的密码，需要及时修改并确保密码的复杂度。


5. 为了对抗勒索软件，众多杀软公司联合推出的解密工具：https://www.nomoreransom.org/，可以破解部分勒索软件病毒家族，用户可以进行尝试还原。



3.2
网络侧


1. 阻断常见高危端口的访问，如135、139、445、3389等。


2. 设置网络访问控制策略，仅允许可信任网段接入到用户内网。


3. 关注网络设备安全日志，如漏洞告警、暴力破解等，辅助定位攻击路径和攻击手法。



04

勒索长效防护建议


4.1
主机侧


1. 根据数据的重要程度，建立合适的数据备份策略，定期进行数据备份，如果是云服务器，一定要做好快照，保证数据可以恢复，业务可以正常运转。


2. 不打开来源不明的邮件附件或链接，如包含.js，.vbs，.exe，.scr，.bat等的邮件附件。


3. 使用复杂密码，由字母大小写，数字及特殊符号组合的密码，不低于10位字符，避免使用电话号码，工号等纯数字密码，增加暴力破解难度。


4. 设置帐户锁定策略，输入5次错误密码后禁止登录或者锁定用户账户一段时间，增加暴力破解难度。


5. 及时更新Windows、浏览器等系统软件补丁，预防勒索软件通过漏洞进行攻击。


6. 安装杀毒软件，并及时更新病毒库，提升已知病毒防御能力。


7. 根据业务需要，关闭或者设置常见高危端口（包括135、139、445、3389等）等的访问策略。


8. 开启并设置主机防火墙策略，仅允许受信任IP访问特定服务。


4.2
网络侧


1. 在网络边界处，设置严格的网络访问策略，对外仅开放必需的服务，且仅允许受信任IP访问必要的服务。


2. 对内部网络分段，不同功能网络间设置严格的访问控制策略，尤其关注高危端口：包括135、139、445、3389等，降低勒索软件横向扩散的可能性。


3. 如果已部署防火墙设备，建议开启入侵检测功能，设置阻断暴力破解，提升暴力破解难度。


4. 如果已部署邮件安全设备或文件检测设备，建议关注可疑邮件及其附件，防止勒索软件通过邮件传播。


5. 关注防火墙等安全设备日志，发现可疑的攻击行为并提前预防。


6. 针对企业内部网络建立白名单机制，防止浏览器跳转到恶意网页。


4.3
解决方案


根据上文中提到的勒索软件的几种传播方式，减轻和缓解勒索软件攻击依赖于对勒索软件传播途径的全面感知、检测和分析，同时也要通过建立良好的数据备份策略降低遭受勒索软件攻击带来的损失。


以部署华为态势感知整体解决方案为例，主要组件包含：


1. 部署防火墙和入侵检测与防御设备，阻断勒索病毒投递前的侦测行为，如：爆破、漏洞利用；


2. 部署支持诱捕特性的交换机和防火墙，诱导勒索病毒入侵仿真业务并捕获其入侵行为上报检测结果至HiSec Insight安全态势感知系统，降低真实系统被攻击的概率，最大限度减少损失。


3. 部署沙箱设备，检测邮件中的文件， 防火墙可将流量还原成文件，并将需要检测的文件发送到沙箱进行检测，沙箱检测结果可发送给HiSec Insight态势感知系统。


4. 部署HiSec Insight态势感知系统，通过接收诱捕交换机、防火墙、沙箱的流量信息及检测结果，HiSec Insight可全网下发策略阻断勒索病毒传播。
