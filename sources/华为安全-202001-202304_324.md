# 硬核安全丨未然实验室研究成果被国际顶会USENIX Security 2021收录

近日由**华为未然实验室、中科院信息工程研究所、清华大学合作完成的论文《MAZE: Towards Automated Heap Feng Shui》**，成功被USENIX Security 2021会议录用（点击文末阅读原文下载论文）。华为未然实验室副主任王琰为该论文第一作者。

  
![](../Images/37c80c48e535ba231d6e898f0a82bb72.png)![](../Images/37c80c48e535ba231d6e898f0a82bb72.png)

  

USENIX Security始于上世纪90年代初，已有30余年历史，与IEEE S&P，ACM CCS，NDSS并称为“网络安全四大学术顶会”，被中国计算机学会（CCF）列为网络安全A类国际学术会议，过去五年的平均录用率17%。USENIX Security会议涵盖了二进制安全、固件安全、取证分析、Web安全、隐私保护、恶意分析等多个安全领域，有鲜明的实践特色。

  

本次录用论文的研究属于自动化攻防领域。随着近年来漏洞数量的激增，软件厂商需要自动化评估漏洞的危害性，并针对性的优先修补高危漏洞。与此同时，安全厂商也需要快速生成IPS检测规则以应对快速迭代的网络安全形势。这些需求都依赖于自动化漏洞利用生成技术（AEG），而AEG技术面临多个技术难题。本文主要针对其中的内存布局自动化构造问题进行研究。

  

![](../Images/40a9081c28610a12a62e37a00e5f05e5.png)

  

已有的研究方案主要基于模糊测试（Fuzzing）去自动化构造特定的内存布局，但由于内存申请噪声（noise）的存在，现有的方案不仅耗时长而且成功率低（约33%）。本研究提出了一个新的技术方案——Maze，创新性的使用线性丢番图方程（组）对内存布局构造问题进行建模，并通过求解方程（组）的方式，指导程序自动化构建复杂的内存布局，同时保持了较高的效率（分钟级）和极高的成功率（大于95%）。

  

![](../Images/fb5899938e38c7d03f9bc310a74189b2.png)

  

本研究也通过符号执行结合静态分析，以及模糊测试结合污点分析等方式，组合使用常见的程序分析技术，取长补短，扩展了本研究适用的程序类型，使其不仅适用于CTF竞赛程序，也适用于PHP，python，perl等真实世界的脚本解释器程序，有力的支撑了未然实验室的自动化安全评估产品。

  

  
  
  
  
  
  
**![](../Images/37c80c48e535ba231d6e898f0a82bb72.png)**

**未然实验室**长期致力于研究自动化攻防技术，从黑客视角出发，以攻促防，在攻击来临之前进行防御，使客户网络环境能够防患于未然。未然实验室最新产品——自动化渗透测试模拟工具（Breach and Attack Simulation，简称BAS）已可通过MSSP模式进行试用，欢迎各位提出宝贵意见。
