火速收藏丨网络安全演习中应对0day与未知威胁的防护锦囊

网络安全演习为了高度模拟真实网络运行场景，往往其攻击链与实际的网络攻击一样，包括信息搜集、边界突破、威胁工具投送和横向扩散等，在实际场景当中，利用率较高的战术有0day利用、流行漏洞利用、弱口令（简单口令、重复口令）爆破和钓鱼邮件等。



网络安全演习是有规则的，约定开展时间、确定靶标系统、设定战果分数、限制影响面大小等，所以常态化的安全建设要求必须逐步高于网络安全演习特定要求，才能真正提升整体能力。


当前网络安全演习已经开展了很多年，经过多年的复盘总结和网络安全建设改进优化，常规的攻击手段已经很难渗透到防护内网。即便基于指纹特征的防护网关没有及时拦截小部分渗透行为，全网布防的流探针也可以有效补充发现渗透行为并在边界网关完成拦截。


但是，随着网络安全演习攻防双方思路和技战术的不断提升，越来越多的0day利用、未知威胁特征工具发起的渗透行为被应用到网络安全演习中，而边界纵深防护网关和全流量检测对此防护效果达不到预期，往往无法发现渗透行为，导致内网安全风险加剧。


在历年演习场景中，通过欺骗防御体系主动诱捕，诱敌深入，采集信息达到追踪溯源至最终反制，是可以减少被渗透风险并加强威胁发现和追踪溯源的最重要方式。


网络安全演习攻击方常常在使用常规渗透手段无法突破取得目标的控制权时，为了演练目标达成，也会使用更高级的攻击策略和技术。包括但不限于基于自研的特征未知渗透和0day漏洞利用等。网络安全演习场景下，应对0day和未知威胁的安全体系结构如下：



应用场景


1.   攻击方在渗透初期会对目标网络进行摸索，通常采用的战术包括：子域名爆破、C网段扫描等；


2.   欺骗防御要产生效果，非常依赖攻击方的触碰，提高诱捕效率扩大欺骗防御的节点；


3.   业务网络资产量级的成倍上升，部署维护成本大增，蜜罐的高交互性决定了扩展欺骗防御节点的成本非常高；


4.   如果攻击方直接对真实业务IP（域名）地址、服务端口发起渗透，而非扫描行为时，防守方很难对攻击方进行捕捉的。攻击方发动精准渗透时，往往已经锁定IP和域名地址，但对业务目录结构不掌握，往往会发起目录扫描行为；


5.   攻击方通过0day或特征未知渗透突破边界进入内网任意位置防守方无从判断。



解决方案


1.   在互联网边界区域映射伪装业务系统与真实业务融合在一起。如登录后台、OA、VPN等，参考域名字典设置子域名，增加被访问的概率；


2.   选择真实业务临近的IP地址映射蜜罐，使用真实业务IP的非业务常用端口映射蜜罐，增加被访问的概率；


3.   边界诱捕探针监听互联网边界流量，将访问空闲公网IP流量转发到蜜罐，精准定位攻击者。通过边界诱捕探针联动蜜网，扩大互联网感知面，映射关系可随时改变，建设动态蜜网；


4.   旁路监听互联网边界流量并设置诱饵目录，发现诱饵目录被访问时，抢先及时应答，误导拖延攻击方渗透行为，并能及时分析溯源并响应拦截；


5.   通过在核心或汇聚交换节点部署内网诱捕探针，配置使用多VLAN内空闲IP资源，使单台诱捕探针可覆盖多VLAN，大面积对内网进行覆盖增强感知面；


6.   与HiSec Insight和防火墙联动可以联动处置，自动高效拦截恶意攻击；


7.   将关键入侵日志同步给HiSec Insight可以关联精准渗透线索进行溯源分析，结合威胁情报可以溯源到攻击方虚拟身份乃至真实身份。



应用效果


1.   关口前移、事前感知；


2.   边界与内网欺骗防御面大增。可高效快速捕获攻击方源IP地址、设备指纹和网络身份，快速身份溯源和画像呈现；


3.   通过旁路仿真诱饵目录，精准识别对真实业务的定向渗透行为；


4.   感知并转移渗透行为，联动分析平台、控制器和防火墙网关能够同步溯源和自动化拦截处置闭环。



整体建议


形成全方位欺骗防御系统在实网场景下的感知面，在南北与东西向360度主动诱捕，精准诱捕，最终对攻击源进行全自动化处置能力。


1.   扩大欺骗防御感知面，诱使攻击者触碰蜜网几率大增，提高诱捕效率；


2.   构建动态网络，全方位欺骗攻击者；


3.   精准溯源分析攻击源、攻击路径及手法类型；


4.   与现网纵深防护体系联动，形成检测、研判、溯源和处置一体化闭环能力。
