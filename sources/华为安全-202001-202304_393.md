# 逐鹿中原，兴豫扬帆丨一站式安全等保服务，华为河南安全等保解决方案能力中心正式成立

为共建华为安全智慧生态，打造安全和谐的网络环境，更好的协助广大客户做好网络安全建设，华为联合河南省鼎信信息安全等级测评有限公司，河南鑫网优电子科技有限公司，河南合众信泰科技有限公司正式成立华为河南等保解决方案能力中心。等保解决方案能力中心的成立，是华为一贯秉承的安全真生态理念的成功实践。

  
![](../Images/37c80c48e535ba231d6e898f0a82bb72.png)![](../Images/37c80c48e535ba231d6e898f0a82bb72.png)

  

2020年9月17日，以**“新安全、智等保”**为主题的华为安全等保高峰论坛暨河南安全等保解决方案能力中心揭牌仪式在郑州隆重举行，共计100多位生态合作伙伴莅临参会，多位受邀嘉宾发表了精彩的主题演讲，并举行河南安全等保解决方案能力中心揭牌仪式。

![](../Images/c56af8f09f22226516c58cd90806fc07.png) ![](../Images/cf0030e401231f96b7d4db0aa0ce6534.png)

华为河南安全等保解决方案能力中心成立

  

华为河南政企业务总经理石艳东在致辞中表示，随着云计算、大数据、人工智能、5G等新技术的大量应用，业务上云、移动办公、物联网等新业态不断涌现，IT边界逐步模糊化、业务模式日益复杂化、安全对抗逐步高级化，网络安全面临空前巨大的挑战。尤其在安全对抗方面，不法分子发动的攻击正在不断进化，勒索病毒肆虐、APT攻击加剧，导致用户数据泄露、业务系统被破坏，企业用户的资产受到威胁。

  

信息化建设离不开网络安全建设，没有网络安全就没有国家安全。石艳东进一步表示，当前国家对网络安全空前重视，大力发展网络空间战略，2020年国家网络安全宣传周高峰论坛于9月14日在河南郑州举办，本届国家网络安全宣传周以**“网络安全为人民，网络安全靠人民”**为主题，自14日起在全国31个省区市统一开展。河南作为国家中心省份，以承办这次盛会为契机，统筹推进网络安全和信息化发展，加快建设网络强省、数字河南。此次**“华为安全等保高峰论坛暨河南安全等保能力中心揭牌仪式”**的顺利举行，将有助于推进河南网络安全生态建设，更好地协助客户做好网络安全工作，满足等保合规的要求，真正提升企业网络安全能力，另一方面也希望能推动河南的网络安全产业朝着健康的方向发展。

  

![](../Images/d95e25b999cf25cdd4d90fc2e761aff3.png)

华为河南政企业务总经理石艳东致辞

  

**在线购物、在线医疗、在线课堂、远程协同办公**，数字世界不断融入我们生活的方方面面。如何能够有效保护数字世界的安全，华为中国政企安全产品和解决方案市场总监黄为东分享了华为在这方面的思考和规划。黄为东表示，在技术和政策的双轮驱动下，国内网络安全产业呈现高度繁荣的景象，然而繁荣的背后，却存在资源重复投入、产品国际竞争力不足等一些问题。而真正做大做强网络安全产业，每一个安全公司需要舍得持续投入、精耕细作。

  

安全产业技术细分，产品众多，任何一家公司都不可能所有产品都做，所有产品都做到最好，这是自然规律。因此华为坚持聚焦前沿技术和核心产品研发，将自己的长板做到最长，做出世界领先的产品，同时联合安全细分领域头部公司，将各自最有竞争力的产品系统的、有机的结合，形成完整的解决方案，发挥1+1>2的效果。为此，华为牵头成立了**华为安全商业联盟，并在今年将联盟升级到了2.0版本。**华为安全商业联盟通过汇聚一批志同道合，愿意投资未来，产品质量和竞争力领先的安全细分领域公司，建设一个真正的安全生态，来共同促进安全产业发展，保护数字世界安全。

随后，河南省鼎信信息安全等级测评有限公司总经理陈宇先生发表了“攻防博弈环境下等级保护工作的思考”的主题演讲。在信息化的不断发展的今天，攻防博弈已成常态，新技术、新应用的普及，等保政策也需要与时俱进，等级保护也从最初的等保1.0发展到等保2.0。最后陈宇呼吁网络安全业者努力构建网络安全生态体系，不负时代赋予的使命，携手拥抱技术变革，共同增强博弈能力。

![](../Images/c56af8f09f22226516c58cd90806fc07.png) 

![](../Images/c3e7b37e1c385f4acd2cb289af53ea7d.png)

会后，华为与华为安全商业联盟伙伴安恒信息、北信源、联软科技、盛邦安全等生态伙伴举行闭门研讨，与会嘉宾主要围绕华为安全商业联盟如何在河南区域有效落地，与等保解决方案能力中心如何紧密结合，如何高效促进区域安全市场发展和业务开展进行深入交流。各联盟合作伙伴一致认为后续要建立有效沟通机制，发挥各自优势，推出标准化安全解决方案，将等保解决方案能力中心建设成联盟共同的能力中心。

华为河南安全等保解决方案能力中心的成立，必将大幅提高华为及其合作伙伴在安全领域内的实力，有效助力河南各企业网络安全建设，将会给河南各行业客户提供从安全产品到安全服务的**“一站式安全等保服务”**，帮助企业解决安全建设“入门难、挑战大、太繁琐”的难题”。同时，安全等保解决方案能力中心也是华为安全商业联盟在区域的落地实践，可以有效整合商业联盟各伙伴的能力优势，共同做大做强河南网络安全产业。
