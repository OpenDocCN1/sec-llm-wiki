一、CRLF

CRLF: 回车换行符


HTTP响应报文的结构是：状态行、响应头部和响应包体。在HTTP规范中，换行使用CRLF来表示。其中响应头部中响应头与响应头之间用一个CRLF分隔，响应头部中最后一个响应头和响应包体之间用两个CRLF分隔


二、环境搭建
https://github.com/cckuailong/nginx_vultargetcd headerinject/docker-compose up --build -d

三、环境中的 nginx配置

location / {  return 302 http://backend:8000$uri;}

四、原理解析

一是配置中的$url是我们可以控制的,这样我们就可以在$url处填入CRLF,然后对服务器进行访问实现头部注入。

二是服务器会返回一个302跳转给用户,所以我们注入的头部参数又会返回到客户这边。
