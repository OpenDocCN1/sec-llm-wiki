    F5 BIG-IP 是美国 F5 公司的一款集成了网络流量管理、应用程序安全管理、负载均衡等功能的应用交付平台。
    近日，F5发布了F5 BIG-IQ/F5 BIG-IP 代码执行，代码执行的风险声明，F5安全公告更新了BIG-IP，BIG-IQ中的多个严重漏洞。建议广大用户及时将f5 big-iq,f5 big-ip升级到最新版本，避免遭到攻击。

def save_file(target_url, t):    output_name = 'Output_{0}.txt'.format(t)    f = open(output_name, 'a')    f.write(target_url + '\n')    f.close()
def format_url(url):    try:        if url[:4] != "http":            url = "https://" + url            url = url.strip()        return url    except Exception as e:        print('URL 错误 {0}'.format(url))
