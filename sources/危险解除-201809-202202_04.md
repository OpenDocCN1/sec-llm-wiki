# 我是凌云，不是田浩，人肉我干啥呢？

我在外边旅游，待会还得出门玩，所以长话短说了。

  

昨天微信有很多人发信息问我，说我咋被黑产扒了，昨天开了一天车，我没法一一回复大家的关心，所以今天发个公众号统一说下。

  

**黑产出我户籍，我没那么在意，因为我叫什么，哪里人，这些信息都是公开的。**

**但****说****我搞诈骗搞勒索搞刷枪，我就必须说清楚**

  

**你们查的是田浩，人肉我干几把毛呢？我又不是田浩，我他吗给他运营账号的。**

**而且我还没毕业，是个学生，你觉得我能是田浩？**

  

先从我自身的经历开始，我目前这个公众号，现在关注的都是当年一路看着我长大的老粉，我为人怎么样，他们很清楚。

  

**1.**  

  

大概两三年前，我最早在知乎上写写东西，当时怼了一个叫花某涯的人，他没法反驳我发出的文章，于是他就写了这一篇文章出来。

  

![](../Images/29ffac286b33a938c539da6e2f3642fa.png)

  

其中编造了一个聊天记录，说我勒索他一万块，黑吃黑啥的，狗屁都没有！！！

  

这件事在当年我做了回应，花某涯的名声用屁股都能想到。

  

现在我这个公众号基本都是当年老粉一路关注过来，看着我长大的，当年具体啥情况他们比你们更清楚。

  

![](../Images/40b5cbb549a8f17579a665ba78df327f.png)

  

还有这个所谓的黑客联盟，就他吗是个假的，当时在一个qq群里跟他对骂，气急败坏就要查我，但也没有查到什么几把毛信息。

  

![](../Images/ce98b4b2b97a7bd0235424a3ab751e0b.png)

  

花某涯就说我之前是个骗子，给我整不会了。  

  

之后花某涯检索到一个cf刷枪的网盘内容，好家伙，直接锤我刷枪。

  

![](../Images/48b61cede0f9560fffc90963f3caacc0.png)

  

拜托动一下脑子，我连自己都不知道刷枪这一回事，莫名其妙给我整个刷枪的帽子带上来，给我整不会了。

  

![](../Images/a7967c3f27cefdfbbc90e2ee3853abba.png)

  

之后就是说我搞诈骗，搞钓鱼网站，咱就是说，谁他吗搞诈骗用自己的域名搞啊，而且再看后台截图，数据一共就两条，有没有可能是因为某个钓鱼网站没找到漏洞，但从网上找到了这套模板，用来审计的呢？？？？？

  

![](../Images/406c012e5b77ca732cca98e68d75d614.png)

![](../Images/a85beda663b49586066ea00f891b93ab.png)

  

  

所以当时这篇文章发出来，属实给我整笑了，这些所谓的黑料完全经不起猜测，用屁股都能想的到，为锤而锤就没必要了。

  

同年，我开了一个小蜜圈，现在叫知识星球，在里面分享我学习了哪些东西，例如这个星期，我学会badusb，那么我就会分享在里面。  

  

  

![](../Images/0333b370f0c3fce2a278be889a844840.png)

  

  

  

这个圈子是收费的，大家也都知道，之后就到了18年网络安全这一块新增了刑法修正案去规则制。

  

那就意味着涉及到黑客技术这一块的内容是被不允许的了，所以便不再发布相关的内容，顺应国家政策法律去走。

  

![](../Images/8712e092a7e42aa02a17c13ceb1cf549.png)

  

同时我在写知乎开始，我就是以自己的真实姓名作为昵称，坦坦荡荡，没有什么好隐瞒的。

  

在那之后我就没怎么接触网络安全方面的技术，偶尔会协助警方调查一些案件，跟黑产诈骗都比较少，主要是各种奇奇怪怪的事比较感兴趣。

  

**2.**  

  

19年之后我就开始写一些半虚构故事，田浩就是在那时跟我认识的，一直写到年底，因为连续写了一年，各方各面都遇到了瓶颈，感觉太他吗累了，不想干了，于是把账号卖了出去。  

  

20年1月左右，又想把自己的文章转成视频，发在抖音和b站上，发了一两条，有了几万粉丝后，又觉得太他吗没意思了，做内容创作很累人，于是不想干了，把账号注销掉，准备专心学习，等着毕业。  

  

而田浩也是一直默默关注着我，于是给我发了信息，让我用这些年自媒体运营经验，帮他运营账号，内容他来做，不用我搞内容，舒服很多。

  

于是20年3月份应该，反正是疫情最严重那会，我跟田浩聊了聊，决定做代运营。  

  

因为我马上面料着毕业，我又不想从事网络安全工作，我更喜欢自媒体多点，我希望自己在毕业前能运营出一个百万级别的账号作为敲门砖，找到一份好点的工作。  

  

第二点则是田浩跟我的一些观念，观点，也就是所说的三观，蛮符合。

  

所以他的账号在我名下负责运营，除了田浩，我也帮一些小达人做账号，但不是网络安全这一块，偏向科技数码，程序员。

  

后来有的号主不想弄了，就委托我帮他们账号卖掉。

  

  

![](../Images/8c3d6fc6b73363e2a0df8e0246d311fd.png)

  

  

我的工作是负责运营内容，给他对接商务。  

  

但田浩的账号盈利很低，他不想让利益过早参与进来，但不管咋说，一个真正好的账号是必须有盈利的，不然哪怕你一千万粉丝，没有良好的收入，也是失败的。  

  

到了后面我就忙着旅游，忙着玩摩托车，忙着玩改装车，我也有点不务正业了，偶尔会把旅游过程写在公众号里。

  

而自从田浩的账号破百万粉丝之后，就是他一个人在搞了，因为这号收益差，基本靠他自己在发电。

  

他想更新就更新，有很多人过来希望合作，我自己都找不到他人。

  

而我也有了一个百万粉丝的案例，有了一块敲门砖，于是21年年底，我发了个公众号动态，希望介绍一份运营，或者跟调查有关的工作。

  

![](../Images/bf2af241fbe82ed03272dc3627dd96c5.png)

  

跟我相处过的大哥都知道，我人品不敢说特别好，但起码还不错，一两年没正经写东西，也仍然还有很多人记得我。  

  

当时印象比较深的是有个警察大哥把我的动态转发到一个警察群里，好多阿sir加了过来，十分感谢你们。  

  

讲了那么一大堆，我从一开始写知乎就没有鬼鬼祟祟，都是以真实姓名去做事的，早几年一路关注过来的老粉中，里面就有不少的警察大哥，如果我真的浑身黑料，搞诈骗搞勒索的，你觉得有可能嘛。

  

跟我现实接触过，相处过都知道我20岁，我从来没有隐瞒真实身份。

  

大概也就这些要解释了，不知道有没有遗漏，有遗漏后边再补把，也有可能太忙，忙着玩。。。。

  

几万年没写过那么长的稿子，两千字，把我累的不行，可能也没那么流畅，凑合着看把，我要出门去玩了，过两天再更新旅游了。。。
