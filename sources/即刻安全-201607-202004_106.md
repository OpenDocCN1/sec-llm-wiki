## **1.源代码**

```
#include <stdio.h>
#include <windows.h>
#include <stdio.h>
#include <iostream>
using namespace std;
string userName("ONDragon"), passWord("666");   \\\\设定用户名密码
#define  Log(str) {{printf("\[Log\] => %s\\n",str);}}
BOOL check(string name, string pass)
{
  if ( name.empty() || pass.empty() )
  {
    return FALSE;
  }
  if (name == userName && pass ==passWord)   \\\\判断用户名和密码是否正确，逻辑判断
  {
   return TRUE;
  } 
  else
  {
    return FALSE;
  }
}
int main()
{
  Log("Begain Main");   
  char name\[100\];   \\\\定义用户名和密码是char类型
  char pass\[100\];
  while (TRUE)
  {
    cout << "Please input your userName :" << endl;     \\\\输入用户名和密码
    cin >> name;
    cout << "Please input your passWord :" << endl;
    cin >> pass;
    if (check(string(name), string(pass)))    \\\\关键函数check
  	{
      Log("Login Successful");   \\\\登录成功
      Sleep(5000);
      return 1;
    }
    else
    {
      Log("Login Failed");    \\\\否则失败就会循环重复输入用户名密码
    }
  }
  Log("End Main");
  return 0;
}
```

## **4.载入Olldebug**

接下来我们将程序载入OD 看看。前面我们已经知道程序的整个流程了，我们需要找到jmp的关键处

![](../Images/ac5d4e9baf6585cec31112e4071746f3.png)

我们在反汇编窗口右键使用字符串搜索功能，搜索关键处。

![](../Images/fb100bef9f70281d182556da25067360.png)

在搜索处，我们可以看到熟悉的字符串

![](../Images/06db9f4fb41df6ee8ec065cd2595dd66.png)

这里我们可以找Login successful ,我们这里双击跟进跟踪，我们找到Login successful相关的汇编代码，在往上看我们可以看到，我们之前在IDA看到的 jnz 汇编跳转指令。

![](../Images/d97f5e507449a5a4c154ecb5deecf527.png)

我们这里可以使用几种方法。判断后如果不跳，就会到下一个jmp，jmp是无条件跳，既然错误的话，jnz会跳到错误信息，那么我们输入错误后，jz就肯定不跳. (Akkuman师傅也教了我很多)

## 

## **修改Z标志位**

我们来看看 jnz ，也就说jmp not zero（跳转不是0的地方） 现在z标志位为1，需要将其修改为0即可实现输入错误信息，跳转到成功登陆。

1.我们在 jnz 处下个断点。（断点快捷键F2）

![](../Images/a2936bb8218756e82cf52057a277cdbc.png)

2.我们将其程序运行，输出错误的用户名和密码，断点处，自动断下。

![](../Images/39508835f817d79bbbee4d9cac9c49fb.png)

这里我们可以看到Z标注处为1

![](../Images/6e515da8cb7e10be1be26357a3bfe697.png)

我们将其z标志位 双击 修改成1

![](../Images/ce6daa4bd87a6812c8e524d374b4414b.png)

![](../Images/987239365a82d925bc9bc2924cbf87b5.png)

我们运行程序，显示登录成功

![](../Images/ce2b98b23f650452066637af2475e978.png)

程序停止

![](../Images/25e81ae9990e19dda303afaaf85519ea.png)

## 

## **修改汇编指令**

我们重新载入OD ，依旧找到 jnz位置，双击jnz处汇编代码，将jnz修改为je

![](../Images/cc0560f7e46c3cbbe01ccdfbe806a953.png)

JE——若ZF=1，则跳转，jnz与je相反

![](../Images/bc1f85e44f42b4c6951bc98180500a89.png)

修改完后，我们运行程序，同样登录成功
