前段日子看到r00t-3xp10it大牛出了个新教程（传送门：https://www.youtube.com/watch?v=Z51jBiFnPGE），自己也打算尝试下 ：

**0x00**

下载：

```
git clone https://github.com/r00t-3xp10it/Meterpreter\_Paranoid\_Mode-SSL.git
```

![](../Images/1ec252397d376845f86fc2c0a5adf2e7.png)

然后进入目录给予权限：

```
cd Meterpreter\_Paranoid\_Mode-SSL

sudo chmod +x \*.sh
```

**0x01**

运行：

```
sudo ./Meterpreter\_Paranoid\_Mode.sh
```

![](../Images/251766132ec5ff668f1f849c8bb37731.png)

**0x02**  
回车后我们可以看到如下界面，这里我选择impersonate domain (模拟域)，点击确定后我们随便输入一个网址：

![](../Images/8fb38a31d2a363b0e94e95a2fcff01fa.png)

这里我以百度的网址为例，并点击确定：

![](../Images/b9628b5d3bfa281ffbd92eaaf79b2973.png)

![](../Images/83ae0fe459c7cdf0af4ded52e3a6b62e.png)

接着会在output生成一个www.baidu.com.pem RSA私钥文件：

![](../Images/a5c44122ea4bcb84fa5ac7b3f76e353d.png)

**0x03**

选择要输出的payload格式bat/exe，这里我选择的是bat格式，点击确定：  
![](../Images/4d35e0cf4129fcb2947aed62e19b9b84.png)

以及要求我们输入攻击者的ip和端口，以及msf PAYLOAD反向shell的连接方式：

![](../Images/e086a5318730b3472e380d79e2863925.png)

![](../Images/b8f3a9761ea0108519cdaa192f9c000c.png)

![](../Images/f54a8ca9ed1909cf9af0be5802558239.png)
