## **11：本地的诱惑**

通关地址：http://lab1.xseclab.com/base11\_0f8e35973f552d69a02047694c27a8c9/index.php

习惯性先查看源码，不过尴尬的发现。。

![](../Images/d46d7ef3ea9f99a8f08dd04b2f593c5a.png)

那好吧，解释一下这段php代码：

```
<?php 
//print\_r($\_SERVER);
$arr=explode(',',$\_SERVER\['HTTP\_X\_FORWARDED\_FOR'\]);
if($arr\[0\]=='127.0.0.1'){
    //key
    echo "key is ^&\*(UIHKJjkadshf";
}else{
  echo "必须从本地访问！";
}
?>
```

获取**HTTP\_X\_FORWARDED\_FOR**中的内容，然后进行一个判断，如果等于**127.0.0.1**，那么久输出key的值，如果不是则输出必须从本地访问！

好吧，Key都已经给了，那么下一关！
