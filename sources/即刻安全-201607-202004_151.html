背景介绍：


Metasploit 项目，是一个有关计算机安全的项目。它可以很好的帮助渗透测试者，完成一系列渗透测试任务，以及帮助开发者完成一些 IDS 签名的开发。其最知名的子项目，当属开源的 Metasploit 框架，用于开发和漏洞利用。其他重要的子项目，还包括例如 Opcode 数据库 shellcode 存档及相关的研究。Metasploit 项目以其反取证及强大的逃逸技术而闻名。在这篇文章中，我将简单介绍在 Metasploit 中，加载使用 wmap 的方法。

Wmap 是从 SQLMap 派生的工具，可以以类似方式对 Web 应用程序漏洞执行检查。

在 Metasploit 中使用 WMAP


在 msfconsole，通过 load  WMAP 加载命令。

使用 help 命令，查看所有帮助信息：

使用 wmap_sites 的 -a 选项指定目标站点：

指定列表后，将使用 -l 选项检查在检查列表时创建的目标站点列表。

使用 -t 选项扫描远程系统，这允许你在实际执行之前进行简单测试。

可以通过 -e 选项进行测试。

通过 wmap 发现的任何漏洞，都将会被存储在 metasploit db 中，可以通过 vulns 命令进行查看。
