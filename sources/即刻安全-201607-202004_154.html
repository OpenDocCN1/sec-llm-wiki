TechRepublic和数据公司Affinio对新兴网络安全趋势的调查分析

去年，消费者，企业和政治目标都遭到了不同程度的勒索软件勒索，网络钓鱼和DDoS攻击。 在这一轮 高调攻击的驱动下，网络安全俨然已成为那些中小型企业公司，在 2017 年需要优先考虑的事项之一。


企业公司为了可视化新兴的网络安全问题，TechRepublic 和数据公司 Affinio 对来自有影响力的社区的社交媒体数据进行了抽样和图表化。TechRepublic 之前使用 Affinio 的技术，使其更好地了解了数字业务趋势，包括 2016年 总统竞选，技术组织如何谈论 爱德华·斯诺登，以及与 俄罗斯网络攻击 相关的网络媒体。


Affinio 从网络，移动和社交媒体数据中提取和洞察重要数据。该公司的算法会捕获自然形成的关联用户组和社区快照，然后可视化每个组是如何连接的。 例如，不出所料，卫生保健专家往往会与其他卫生保健专家进行在线沟通。Affinio 分析显示，医疗保健专家还与信息专家，技术新闻消费者和数字营销人员进行沟通。

Affinio 发言人 Maura Woodman 表示，这些数据对企业公司非常有帮助，因为数据可以帮助垂直行业更好地了解市场，并“在更广泛的受众群体中展示基于兴趣的社区”。她解释说，这种方法是成功的，因为它“帮助企业在人类层面了解目标受众，并以可重复，可预测和可扩展的方式利用这些信息。


公司利用的机器学习技术，不断地获取 web 和 移动内容。内部数据库则依赖于 Microsoft 的 Azure 云，它允许公司可以快速处理和可视化这些不同来源的大量数据。“我们能够在一两个小时内，分析数十亿的数据点，”Woodman 说。

虽然 Affinio 擅长于对社交媒体 Twitter 的分析，但该软件不仅限于社交网络，还可用于挖掘几乎任何链接或故事，短语，标签，用户名和网页相关的活动。“我们的分析可以大致反应出，用户们的一些共同偏好及关注点。”Woodman 说。[包括] 互联性，相关性，心理学，地理学，人口统计学以及...社区和集群的形成。“这有助于企业掌握产品受众之间的共同特征，从而推动内容战略，识别潜在的合作伙伴及赞助商。

从 2016年11月 至 2017年1月初，TechRepublic 和 Affinio 合作开发社交网络，深入了解网络安全趋势，主题和影响者。我们从 163,792 个用户中，截取了两个 Twitter 数据样本，包括用户名，帖子内容，时间和日期戳，关注者和其他一些信息。我们主要通过识别内容和主题类型，以及与网络安全相关的交互和密度，来判断及分析。

网络安全人口统计的调查数据显示，男性占 66.1％ 女性占 33.9％，25-44 岁的占比为 70.1％。虽然沙特阿拉伯，拉丁美洲，澳大利亚和印度正在成为网络安全话题的热点地区，但他们绝大部分集中在纽约，波士顿，华盛顿特区，巴黎和伦敦地铁区。


知名网络安全帐户 - 格林·格林沃尔德，内特·贝尔，保罗·克鲁格曼，沃尔特·莫斯伯格，凯文·莫里森，TechCrunch，华尔街日报，纽约时报和 Ted 在技术，政治和文化社区也很有影响力。

根据数据分析，关于对网络安全的讨论，在企业信息安全专家，数字营销人员和政治家中呈同样趋势。IT 社区的讨论则相对有点孤立，他们往往只与主流技术的影响者在线互动。Twitter 数据还显示，创建内容的机器人数量正快速增长，并参与与网络安全问题相关的自动对话。


网络安全行业并不是一座孤岛，似乎有被卷入其它热门技术和商业的趋势。Affinio 数据显示，整个行业似乎都将讨论恶意软件和勒索软件的重心，转向了医疗保健和金融，政治黑客，人工智能，区块链和 IoT 漏洞方面。


这些趋势，无疑将在 2017 年扩散到其它行业中。中小型企业仍然特别容易受到勒索软件的攻击，物联网是一个广泛的开放目标，而简单的 DDoS 攻击就可能使整个城市的机器脱机。“社交媒体和网络数据，可以为我们积极应对这些新兴威胁及技术趋势，提供宝贵的意见。“ Woodman 说。“[数据]给你一个优势。”
