以上我们可以看出，eibPort 是整个系统的最为核心的部分。因此，我们必须保证 eibPort 附带的所有软件组件的安全性。然而事实并非如此，在这篇文章中我将介绍关于 eibPort 存在的一些漏洞问题。

  

**分析 UpdateTool**

与其他嵌入式设备的更新方法不同，BAB TECHNOLOGIE GmbH 设计设备的更新是单独通过一个 Java Jar文件的更新工具来进行更新的。   

这非常的有趣，因为它的更新过程非常独特。通常，更新是通过 web 应用程序安装，并提供存储所有相关更新数据的单个文件。这样，更新文件将提供给 UpdateTool，并且在下一步中，更新工具会将数据传送给设备。

  

更新工具启动后，它会搜索位于同一网络中的 eibPort 设备。 如果找到 eibPort，则将显示关于设备的一些信息，例如： IP地址，序列号，安装的固件版本以及不同的端口。

  

![](../Images/3819dfac5a1aadd3095904b95860400f.png)

下面我们来查看下，这个更新工具的源代码，其实它并不复杂。 如果编译Java代码，它将以中间形式（JVM字节码）传输，该中间形式保留了原始 Java 代码中包含的大量信息。 这使得反编译包含在 Jar 文件中的 .class 文件变得非常容易。

  

**更新工具（Update Tool）的源代码**

在使用 Java 反编译器打开文件“UpdateTool-20141219.jar”后，我们可以看到其中的代码结构，以及 Update Tool 所中包含的软件包。

  

![](../Images/39ae4bab3cab47b8a7f2fa15a6ef57c7.png)

我们可以看到这里有两个值得我们注意的包“babtec”和“eibport”。经过一段时间对源代码中不同类和方法之间的关系分析，我们在类“KeyStorageStatic”类中找到了一个加密的 DSA 私钥。

![](../Images/ada6c347b893571bc92e6d4b7df39666.png)

该密钥被用于方法 “startUpdate”以及“getRescueVersion”来连接 eibPort 用户“bt1”。我们可以简单分析下，该 DSA 私钥会在另一个类中用于连接到设备，那么必然会有加密密钥来解密它。另一种可能是，如果更新工具要连接到 eibPort，则必须输入密码以解锁密钥，但我们排除了这种可能。 经过进一步的研究分析，我们发现一个字符串符合 DSA 私钥的上下文，看起来像一个密码。 此字符串位于类“UpdateController”中，如下图所示：

**连接到 EibPort**

通过收集的信息，我们可以尝试通过 SFTP 连接到设备。现在我们有用户名，加密的 DSA 私钥 以及 解锁密钥的密码。

  

![](../Images/1e7b4757b7a596c3a959c9ee067ada7e.png)

从以上截图我们可以看到我们此时工作在“/config/chroot/”下的 chroot 环境中。

显然，此时我们的操作权限是非常有限的。为了获得一个功能更加强大的 shell，我们可以来上传一个 PHP 的 shell。（我们可以通过 HTTP 响应头 X-Powered-By ，来判断系统所使用的服务器语言及版本信息） 如果 PHP 文件，成功上传到 bt1 用户的主目录下，那么我们就可以通过 Web 浏览器来访问该文件了。

  

一旦我们的 webshell 成功上传，那么我们就获得了该设备的 root 权限。原因是因为 Web 服务器，当前是 以 root 权限运行的，因此我们上传的 PHP 脚本也被赋予了 root 权限。   

现在您已经获取到了，设备及智能家居的完全控制权。你可以控制灯和电源插座，可以打开窗户或门，甚至可以关闭报警系统等。

  

当然我们的乐趣并不在于此，接下来我对 web 应用程序，进行了进一步的分析研究。我们检测到一个 PHP 脚本，像是用来提取数据的。 脚本通过 GET 方法，来接受参数“src”和“dst”这两个值。参数处理如下：

  

**“exec(“unzip ../..”.$src.” -d ../..”.$dst);”**

可以看到，这两个参数并未对用户输入进行检查，并直接使用 exec 方法执行 unzip 命令。 这种较为随意的处理方式，也直接导致了远程代码执行漏洞的产生。攻击者可以利用该漏洞，来远程执行任意其它操作系统命令，并获取 root 权限。

**总结：**

智能家居设备（如 eibPort）是智能家居安装的重要组成部分。 人们为了方便，希望能从任何地方来控制他们的家居。但带来便利的同时，很多人却忽略了一些潜在的后果。

  

通过 Google 搜索或通过编写一个简短的 Python 脚本（可针对特定路径进行爬网），你就可以非常轻松地找到这些设备。如果你知道 eibPort 上的 web 应用程序的结构，你就可以在互联网上找到成千上百个这样的设备，其中一些甚至没有激活任何认证机制。

  

BAB TECHNOLOGIE GmbH 为受影响的 eibPort 版本（2.1）提供了升级更新。eibPort 2.1 的用户应尽快更新其设备，并遵循 BAB TECHNOLOGIE 提供的 建议。下载更新： http://bab-tec.de/。
