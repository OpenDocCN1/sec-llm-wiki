谷歌修复12个Chrome浏览器高危漏洞

 

Google 希望Windows，Mac和Linux用户更新其Chrome浏览器，以修复可能允许恶意第三方控制目标系统的多个漏洞。


发布于周四，适用于Windows，Mac和 Linux 的 Chrome版本55.0.2883.75 修复了这些安全问题。 同时该浏览器中也引入了一些新的功能，比如增强了其处理平移手势的能力，以及支持 CSS 连字功能。


美国计算机应急准备小组（US-CERT）在星期四与Google联系时发布了一项关于Chrome更新的警报，共发现了26个 bug 。为此，谷歌像外部研究人员花费了总共70000美金的修补费。 根据谷歌声明，另外10个安全问题由谷歌自己解决。


漏洞列表中的前几个是等级显示为“high”的严重性问题。 其中的五个缺陷与Chrome的Blink组件（一个作为开源网络浏览器项目Chromium Project的一部分开发的Web浏览器引擎）中的 XSS 相关联。


安全研究员Mariusz Mlynski 因为发现这三个严重的与Blink相关的 XSS 漏洞，而获得了谷歌22500美金的奖励。波兰的研究人员在5月发现了类似的缺陷，也赢得了15000美元。


其他4个高危漏洞与 Chrome 默认的PDF查看器（称为PDFium）problem-plagued 有关。 根据谷歌6月份对该漏洞的描述，如果他们被诱使在默认的PDF查看器中查看被嵌入jpeg2000图像的PDF文档，用户就会存在安全风险。 Google在周四的更新中，没有透露此最新PDFium漏洞的详细信息。


两个高危漏洞被绑定到Chrome的V8 JavaScript引擎。其中一个漏洞被描述为“在V8中私有属性的访问“漏洞，另一个发现是，免费使用 V8 的问题。此外还有9个中等程度的漏洞，其中两个是与Chrome的多功能框（地址栏）有关，黑客可以利用它进行地址欺骗。
