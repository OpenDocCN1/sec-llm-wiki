Terminal下的无线管理工具之Nmcli

在 windows 下我们都知道怎么连接无线网络，因为是图形化界面，因此操作相对简单。其实在 Linux 平台，也自带有一款专门用于连接无线AP的网络管理工具，它就是 Nmcli ！它的功能也非常强大。利用它，我们可以轻松的连接到之前我们已经建立过连接的AP，列出当前网络可用AP，AP连接状态查看管理等功能。下面我们简单学习下它的基本使用！

如何我们直接输入 nmcli 它将显示其基本使用命令及帮助文档：

nmcli

列出所有曾经连接过的 AP：

nmcli co

co: connection

当我们想连接某无线，我们可以通过其 UUID 来建立连接：

nmcli co up UUID (通用唯一标识符)

查看当前连接状态,这里有三种方法可以查看：

nmcli co show --a

nmcli device status

nmcli dev status

查找当前网络可获取的 AP ：

nmcli device wifi list

nmcli dev wifi list (效果同上)
