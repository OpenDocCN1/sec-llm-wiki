# 调查取证之图像还原

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5MTM4NzYwNw==&mid=2247483886&idx=1&sn=2316b77422f7e3549d23f861457ccafe&chksm=ec102056db67a940c3c8c0c0eae3180fe8a0f45424ab66735e03a801228f20d968646346e904&scene=126&sessionid=1681663723#rd](http://mp.weixin.qq.com/s?__biz=MzI5MTM4NzYwNw==&mid=2247483886&idx=1&sn=2316b77422f7e3549d23f861457ccafe&chksm=ec102056db67a940c3c8c0c0eae3180fe8a0f45424ab66735e03a801228f20d968646346e904&scene=126&sessionid=1681663723#rd)

场景：将画图板进程 dump 下来的内存数据，以图片形式还原。

利用工具：

procdump  

gimp

首先，我们使用画图打开一张图片，并使用 tasklist 查看进程情况：

![](../Images/d966afba5a810639893eed30e8ce906b.png)

接着我们使用 procdump 来 dump 下 mspaint.exe 进程数据：

**procdump64.exe -ma mspaint.exe mspaint.dmp**

![](../Images/8d56de0aab1718c628184de4ffb6d14f.png)

使用 CMD dir 命令查看是否 dump 成功并保存为 dmp 文件：

![](../Images/ef8876b6da59771704ef3ef9f117efdd.png)

将 dmp 文件拷贝至 kali 并下载安装图像处理工具 gimp：

**apt-get install gimp  
**

![](../Images/16baccd7dd04224a2a8ec38a6b228f99.png)

将 **mspaint.dmp** 修改为 **mspaint.data** 格式，使 gimp 支持：

![](../Images/23e989da7e0fe34e17fd3c7640d45dfb.png)

打开 gimp 选择文件＞打开：

![](../Images/a2cbc925ccb7d1baef39724f5fcd9350.png)

在右下角全部图像处选择 **.data** 格式，并打开：

![](../Images/a0977dbbc7285d7958893033cfb467a5.png)

通过对 RGB 的调整，我们可以将数据还原为图像：

![](../Images/f10f081561d6110faff22c33bb366779.png)
