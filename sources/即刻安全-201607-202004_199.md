YouTube 作为全球用户量最大，及内容最丰富的视频网站，在天chao被墙，确实是我们的一大遗憾！但是天chao人民总能翻山越岭，我就不多说了！对于一些 Linux 的爱好者而言，它们又该如何在整天的枯燥的 Terminal 窗口下，观看 youtube 及下载自己喜爱的视频呢？其实，有一款工具就是专门为此而设计的，它就是 mpsyt ！  

我们来看看，它都能为我们做什么？

**1\. 查找并播放 youtube 的音频文件。**

**2\. 通过相册标题搜索。**

**3\. 查询并导入 youtube 播放列表。**

**4\. 创建并保存本地播放列表。**

**5\. 下载音频文件。**

**6\. 格式转换。**

**7\. 查看视频评论。**

**8\. 可以在 Python 3.x 环境下操作。**

**9\. 跨平台支持 Windows, Linux and Mac OS X 。**

这里要说明的是，此工具支持mplayer和MPV的播放选项。它实际上是基于 mps 编写的，而它的默认播放器则是 mplayer ！在我们对它有了初步的认识及了解后，下面我们来安装使用。

首先我们先来安装一个 python 文件 get-pip-py\_ :  

```
sudo python get-pip.py
```

接着安装 mps-youtube ：

```
sudo pip3 install mps-youtube
```

进行简单的更新：

```
sudo pip3 install mps-youtube --upgrade
```

现在我们启动进入 mpsyt ：

```
mpsyt
```

使用也很简单：  

```
/video song 名字
```

通过以上命令，它会为我们列出我们搜索的歌曲及歌曲id，我们只需输入对应的 id 并回车就能为我们播放音频！当然如果这里没有正常进行音频的播放，那么可能是我们没有正确安装 **mplayer mpv** 。我们可以通过以下命令进行安装：

```
sudo apt-get install mplayer
 
sudo apt-get install mpv
```

如果你想对播放器进行设置，我们可以使用** set** 命令：

例如设置 mpv 相关的：

```
set player mpv
```

如果你不清楚一些配置的使用方法，我们同样可以通过 help 命令来查看帮助信息：

```
help 配置项
```

最后关于下载也很简单，只需输入对应参数及 音频 id 即可。例如：

```
d id
```

成功执行以上命令，它将会帮助我们从远程提取音频，并提供选项，让我们来指定下载音频的格式大小及质量情况！
