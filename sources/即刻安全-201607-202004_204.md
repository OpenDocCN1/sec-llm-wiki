上篇文章,简单介绍了 find 的一些基本使用方法：http://www.secist.com/archives/1341.html  
  

这篇文章，将继续带大家探秘 find 命令的奥秘！

1.根据权限查找

操作系统文件及目录，都具有读写执行的权限设置。那么我们就可以通过区分不同的权限来查找文件：

**find -perm 777**

![](../Images/d813366fd00a6d210dd0ff9a5890cb1f.png)

2.权限反转匹配

不查找某些权限的文件：

**find -not -perm 777**

![](../Images/8f8fdd2ba6f308ff6dc5928fa97a1acf.png)

3.类型匹配查找

只查找当前目录下的文件：

** find -type f**

只查找当前位置下的目录：

**find -type d**

同样，我们还可以结合 -name 来查找指定的目录或文件：

**find -type f -name sources.list**

![](../Images/b6d0880d4f122a104de890f51342ea0d.png)

4.指定用户查找

**find / -user root**

指定用户及文件名称查找：

**find / -user root -name sources.list**

![](../Images/3b8423f77ef07df43f697ad353998963.png)

5.指定用户组查找

**find /etc/passwd -group root**

![](../Images/4f1c3a12118f84a13400097f836d0b16.png)

6.指定大小查找

**find -size 20M**

![](../Images/13a4a6e746960b9680838700d19aa5c7.png)

利用该原理，我们还可以查找小于20M或大于20M的文件：

**find -size +20M**

**find -size -20M**
