用 kali 的小伙伴一定少不了使用 proxy ！今天为大家介绍一款免费的 proxy ，由于种种原因我就不打的太明显了。

首先我们先到红标指示的网址，并下载页面中的指示文件：

![](../Images/7c889c68d1e90471f213d814be959b9d.png)

点击文件保存文件：

![](../Images/b33f998bc5f320948e6ba5c49f175298.png)

在kali上找到该文件右键单击选择 用归档管理器打开 ：

![](../Images/1a0d01695d897ce2f3063ce9707f6b50.png)

打开后我们可以看到有四个文件，我们将其拷贝到与压缩包同级目录下：

![](../Images/e6986449570c3ec6730d6d1113647528.png)

然后，我们选择其中一个文件进行 proxy 。这里我选择通过 https 加密的隧道，右键单击选择重命名复制其文件名前半段即可：

![](../Images/42ed653ef1ae237fb6ced389ddb85561.png)

现在我们在 terminal 下输入以下命令开启 proxy ：

![](../Images/bde6d9b56751b12c570872b496c1260e.png)

在开启过程中要求我们输入账户密码信息，我们可以通过最先那个网址页面下找到官方提供的账户密码：

![](../Images/71259fb418332a541952ebee63ebeb59.png)

最后我打开百度页面，查看当前IP是否已实现 proxy :

![](../Images/648edd8667ee4bff7176d4a02f1d181f.png)
