# Linux命令之强大的find该如何玩转？

熟悉 Linux 系统的小伙伴，一定都使用过 find 命令。可以说它是 linux 系统下使用最广泛的命令之一，因为合理正确的使用它，可以为我们带来不小的便利！下面让我带大家对 find 命令，一探究竟！

1.简单的 find 查找

find 最简单的使用方法就是直接在终端输入 **find** ，它将会列出当前目录中的每一个文件，和目录下面的层次结构。

![](../Images/1c4b107fc46a10e021bf10098fc78530.png)

2.查找指定路径下的文件目录

**find /usr/share**

![](../Images/b7ca87dc0809aea5195ec69966350b47.png)

3.指定文件名查找

**find -name sources.list**

![](../Images/3f445769c6d0e466b807affc01a9ce24.png)

4.通过索引号来查找文件

linux 系统，对每个文件及目录都富裕了独一无二的索引ID号。我们可以使用以下命令查看：

**ls -li**

![](../Images/5d0ba01b5f062cf1221c0b132f61fff0.png)

因此我们可以通过 索引号来查找文件：

**find -inum 655361**

![](../Images/7819be6175cf142a3134e1cbe2cffc51.png)

5.反转匹配查找

当我们不想让查找结果显示某文件时，我们同样可以排除它：

**find -not -name XXXX**

**find ! -name XXXX**

6.制定查找的深度

**find –mindepth 2 –maxdepth 3 –name linuxmint**

**–mindepth：**最小目录深度

**–mandepth：**最大目录深度
