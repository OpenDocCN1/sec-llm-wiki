# FileZilla提权及后门

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5MTM4NzYwNw==&mid=2247483720&idx=1&sn=607777644ec490cd94f1ddec63c4889d&chksm=ec1020f0db67a9e6cbefbecdb7cdfeeb91c55ed2877c44d79c20faef513c0bb7929545507c16&scene=126&sessionid=1681663747#rd](http://mp.weixin.qq.com/s?__biz=MzI5MTM4NzYwNw==&mid=2247483720&idx=1&sn=607777644ec490cd94f1ddec63c4889d&chksm=ec1020f0db67a9e6cbefbecdb7cdfeeb91c55ed2877c44d79c20faef513c0bb7929545507c16&scene=126&sessionid=1681663747#rd)

话不多说，我们直接操作！

首先我们通过 webshell 找到 FileZilla 的文件目录，找到 **FileZilla Server Interface.xml** 文件，打开。我们可以看到它的连接地址：**127.0.0.1** 及端口：**14147**，密码这里为空。

![](../Images/ee6608ddefaa8a32cc1db97fade00dc4.png)

在得到以上基本信息后，我们找到可读写文件，上传** lcx.exe** 端口转发程序。因为从以上信息我们可以知道，它只侦听在本地的14147端口上。

![](../Images/d4acc2f189900d9404445554863300f8.png)

然后执行端口转发命令：

**lcx.exe -tran 14148 127.0.0.1 14147**

![](../Images/a9095fbb02a01c092431ff6c462d1bc5.png)

接着我们在我们本地机器上，通过 FileZilla 的服务端程序，来连接它！地址填写，目标地址端口为转发后的 **14148** 端口，密码为空！

![](../Images/8d1ec66eaa93b7453cf1e57e2b85e984.png)

我们成功连接上了！现在我们来添加用户，并将我们的分享目录改为** c:\\** 盘，并赋予足够大的权限！

![](../Images/327ec039bf8dd6bd0eb5c179e5effd82.png)

在拥有账户和 c:\\ 控制权后，我们再通过 FileZilla 的客户端来进行正常连接！我们可以看到成功连接！

![](../Images/15b6cf14414a59d1efd3c9710fa2e8bb.png)

现在，我们就用自己准备好的cmd客户端，替换 **system32** 下的 **sethc.exe** ，并选择 **覆盖** ！

![](../Images/aa42943a9e54895647e0823fd34301ca.png)

最后我们来通过 远程桌面来进行连接！在登录界面，我们连续按 **5 下 shift 键**，可以看到成功调出 cmd 的命令客户端！

![](../Images/07a284fc3fb987d60aa27e36070ca785.png)

我们来添加一个用户，并将其提升为管理员权限！

**net user secist 123 /add**

**net localgroup administrator secist /add**

![](../Images/e5c65de2a0a082e7636d1d4ca2535cf2.png)

这样，我们就成功取得了该服务器的控制权限！
