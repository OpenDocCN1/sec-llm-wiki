# raspbian系统如何安装Kali tools？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5MTM4NzYwNw==&mid=2247483717&idx=1&sn=802540d46badf435681359927e2af9ba&chksm=ec1020fddb67a9eb5afbb7cc0ede0cea1b18298d6e8229a2aba13f8cd6fafb656b06251d330f&scene=126&sessionid=1681663747#rd](http://mp.weixin.qq.com/s?__biz=MzI5MTM4NzYwNw==&mid=2247483717&idx=1&sn=802540d46badf435681359927e2af9ba&chksm=ec1020fddb67a9eb5afbb7cc0ede0cea1b18298d6e8229a2aba13f8cd6fafb656b06251d330f&scene=126&sessionid=1681663747#rd)

**之所以要在raspbian系统上结合Kali功能，是因为经本人测试直接在小派上安装Kali，部分功能无法正常使用。 例如无线破解无法检测到网卡驱动。其次，对于一般人而言，下载安装一个kali不仅没必要，还显得过于臃肿。话不多说，下面让我们一起来动手操作。**

1.打开百度搜索 kali2.0国内更新源，找到中科大更新源。

#中科大kali源

deb http://mirrors.ustc.edu.cn/kali sana main non-free contrib

deb http://mirrors.ustc.edu.cn/kali-security/ sana/updates main contrib non-free/

deb-src http://mirrors.ustc.edu.cn/kali-security/ sana/updates main contrib non-free

2.复制粘贴中科大更新源至:

sudo nano /etc/apt/sources.list 保存退出。

3.终端输入 sudo apt-get update 出现以下错误提示。

![](../Images/49bae7440f013937512e37ed6e6b0f0c.png)

这是因为我们没有授权在raspbian系统上使用kali更新源。因此，只要我们添加公钥就行了。

国内可用key server:

keyserver.ubuntu.com

pgp.mit.edu

subkeys.pgp.net

www.gpg-keyserver.de

命令如下:

gpg –keyserver  keyserver.ubuntu.com –recv-keys ED444FF07D8D0BF6 这条命令是获取公钥。

![](../Images/a667d6bfd6df8589f7d2029a21348984.png)

 gpg -a –export ED444FF07D8D0BF6 | sudo apt-key add –  这是导入公钥。

![](../Images/bd5095a2d5086abac6d8aedc3084b6b0.png)

 此时我们在执行更新命令:sudo apt-get update 发现末尾没有出现报错提示。

![](../Images/c4a435b41c2bbe0c2332f31956fd707b.png)

现在让我们来测试下 能否进行kali 工具的安装。输入命令:

sudo apt-get install metasploit-framework

   

输入启动命令:msfconsole 成功启动metasploit框架。

![](../Images/a255478379834efd86666e156547e217.png)
