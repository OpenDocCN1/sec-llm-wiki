因为是在 vmvare 里进行安装，所以我们先将 ISO 文件，进行挂载！我们使用命令查看挂载情况：

**df -T **

可以看到已经挂载上。

![](../Images/2763cf25925cb5da429c3b74cf411b68.png)

我们更改它的挂载点。

**unmount /dev/sr0**

**mount /dev/sr0/media**

![](../Images/174c3a4043f927fd58e8fbfd50020516.png)

查看是否挂载到 media 。

**ls /media**

![](../Images/46a0ad876eba2a9b099ad97acc41104e.png)

接着我们进入 yum 配置源文件：

**vi /etc/yum.repos.d/rhel-source.repo**

未进行修改前如下：

![](../Images/4db9a3b3c1343f2d8ccc6db25413ec62.png)xia

修改成如下配置：

并将 gpgkey 公钥复制下来，稍后需要进行 公钥的导入！

![](../Images/b981547282c0d4127c2dc1b36dd5a258.png)

导入 yum 源的下载公钥：

**rpm --import /etc/pki/rpm-gpg/RPM-GPG-KEY-redhat-release**

![](../Images/de497c354b36474a77d83e19203756ae.png)

现在我们就可以使用 yum 源进行安装了。

**yum -y install httpd php php-mysql mysql mysql-server**

![](../Images/cb0ca673ed2f4080307ce4ba0bfa4314.png)

启动Apache和MySQL服务。

**service httpd start**

**service mysqld start**

![](../Images/4ac541f05c9781c836cb4d6988f68245.png)

设置MySQL的登录密码：

**mysqladmin -uroot password root**

登录：

**mysql -uroot -proot**

![](../Images/e0eca596419e1d562fbff0f4b5279ef7.png)

为了能让物理机也能访问到虚拟机中的 lamp 环境，我们还需要两步。

**清空防火墙设置： iptables -F**

**关闭 selinux ：setenforce 0**

![](../Images/cf15891504c646133f5ae733611e8205.png)

最后我们在物理机进行访问！访问成功！

![](../Images/be0baf80f12f0e2813a1ca4ad4b2adde.png)
