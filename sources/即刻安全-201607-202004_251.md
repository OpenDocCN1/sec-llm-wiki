# 详解:EFS文件加密与解密

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5MTM4NzYwNw==&mid=2247483658&idx=1&sn=857932bf8c50ca6a3fdb589845d6025c&chksm=ec1020b2db67a9a463138d6b15b785b8fa1fbae11d60ddd9df61010ab59e95a15ea78e54ca16&scene=126&sessionid=1681663751#rd](http://mp.weixin.qq.com/s?__biz=MzI5MTM4NzYwNw==&mid=2247483658&idx=1&sn=857932bf8c50ca6a3fdb589845d6025c&chksm=ec1020b2db67a9a463138d6b15b785b8fa1fbae11d60ddd9df61010ab59e95a15ea78e54ca16&scene=126&sessionid=1681663751#rd)

今天为大家介绍个Windows下的，文件加密系统 EFS 。它可以实现对各种文件的加密，并且加密对用户是透明的。只有当加密用户改变时，它才会进行拒绝访问提示。因此它的加密验证过程，也是在用户登录Windows系统是进行验证的。下面让我为大家介绍下，如何设置EFS加密。

例如我要加密一个文件，我们选中该文件，并单击鼠标右键，选择 属性 。

![](../Images/004fcd33e129957eda87a953b6cc784a.png)

在下个弹窗选择 高级 。

![](../Images/5891e4ed6229f7970dd673c11f1ccf06.png)

接下来我们选择 加密内容以便保护数据 。

![](../Images/9251a605dec39e6c15d44a6448e3be55.png)

在弹框内，我们点击 确定 。

![](../Images/950acfca13fc759238e666eb8c297e65.png)

然后点击应用并确定。

![](../Images/9f1a499225d3a321d4422c1bd1b4ef81.png)

此时，当我们打开该文件，我们可以发现文件夹下的文件，颜色都变成了绿色 。证明加密已经生效。

![](../Images/19fb8cba62eaeb15adab4b77b4681726.png)

如果现在我们将该文件放到其他系统进行双击打开，你会发现弹出一个拒绝访问警告框。

![](../Images/092f8d82cfddace58c3beafd6f19fb49.png)

那么，如何对加密的文件进行解密呢？有时，由于种种原因。为了方便，我们不得不随时随地的来打开文件。EFS同样支持解密功能。下面我们来看看，如何进行解密。

同样选中文件，单击鼠标右键，选择 属性–高级。在弹框内，我们选择详细信息。

![](../Images/cdd9c8210c43e9b9a84ebd4551b22c3b.png)

选中 用户 并 备份密钥 。

![](../Images/7cc38c664d42452acbc49e34522161c7.png)

单击 下一步 。

![](../Images/0e414b9157dec267c52d01775ed15c1e.png)

进入证书导出向导，选择 所有证书 和 所有扩展属性 并单击 下一步。

![](../Images/00c2fdc67caff6f36147ccba94ad81d2.png)

设置私钥保护密码。

![](../Images/7ebebcfc0c9770f4964034988d797a72.png)

选择 私钥导出保存路径。

![](../Images/4c4fdd424885c9231c27e8b0050438f8.png)

点击完成。

![](../Images/8c4276775de9ec32019110b14a9443ec.png)

导出成功。

![](../Images/7517330c92cb654c63a1b11df1d3616d.png)

有了私钥证书，此时如果我们想在其他系统上打开加密文件，只需将该证书拷贝至目标系统，并双击打开。它会跳出一个验证请求框，要求我们输入私钥密码。成功验证后，我们便可以在其它系统上，双击打开加密文件了。
