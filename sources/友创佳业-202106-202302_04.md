# 友创佳业发现微软Microsoft Edge浏览器存在0day漏洞，请勿随意点击访问不明网址，及时保持版本更新！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzk0MTAyMzAxNg==&mid=2247484252&idx=1&sn=638a574184696abe110a2767f624a4af&chksm=c2d9891bf5ae000d4acdff2c1985b92a5ae6dde25467181b2cabeb14c1a407aa96ef8865d5a0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzk0MTAyMzAxNg==&mid=2247484252&idx=1&sn=638a574184696abe110a2767f624a4af&chksm=c2d9891bf5ae000d4acdff2c1985b92a5ae6dde25467181b2cabeb14c1a407aa96ef8865d5a0&scene=27#wechat_redirect)

  

![](../Images/b186176e83b966832f6f9d0455d38fa2.png)前言

  

友创佳业安服团队发现微软Microsoft Edge浏览器存在0day漏洞，本次漏洞预警不公布漏洞细节，以防被恶意利用，请用户保持版本更新，勿点击不明链接。

相关漏洞已经提交CNVD(国家信息安全漏洞共享平台)和CNCERT(国家互联网应急中心)。

![](../Images/5e21ae06b0028f474bf27dc833e33028.png)

  

  

  

![](../Images/b186176e83b966832f6f9d0455d38fa2.png)关于微软Microsoft Edge浏览器

  

Microsoft Edge是一款美国微软公司开发的快速而安全的浏览器，可帮助您保护数据，节省时间和金钱，被全世界数十亿用户广泛使用。

![](../Images/4fc1d87179b02e958c7a92b8b4e69f73.png)

  

![](../Images/b186176e83b966832f6f9d0455d38fa2.png)漏洞危害

  

在用户访问的内容中若执行特定代码，则可以触发拒绝服务漏洞，无法响应用户的正常操作。

  

![](../Images/b186176e83b966832f6f9d0455d38fa2.png)结语  

在互联网日益发达的今天，无论是个人或企业所使用的IT产品都有可能存在网络安全隐患，网络安全和每个人息息相关，在生活与工作中，都需注意网络安全问题，及时升级、加固所使用的IT产品，避免产生更严重的危害，对个人和企业造成不必要的损失。
