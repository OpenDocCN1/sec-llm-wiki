# **取证小知识-21** \[2019-12-04发布\]

Windows10系统中，可以在PowerShell中使用Get-FileHash命令获取文件哈希值，具体语法为“Get-FileHash<文件路径> -A <哈希算法>”，例如“Get-FileHash C:\\Users\\胡壮\\Desktop\\新建文本文档.txt -a SHA1”。相比命令提示符中的“Certutil -hashfile”命令，此PowerShell命令更简短容易记忆，且命令中各部分大小写均不敏感。Get-FileHash命令支持的算法有MD5、SHA1、SHA256、SHA512等，参数“A”是单词“Algorithm”的缩写。因Get-FileHash从PowerShell 4.0开始内置，所以默认情况下Windows7中使用不了此命令。

# **取证小知识-22** \[2019-12-05发布\]

两个月前发布的19.10版本的Ubuntu系统一大特性就是加入了ZFS文件系统的实验性特性安装选项，对于桌面版的Ubuntu 19.10，全新安装时，用户可以选择将磁盘格式化成ZFS文件系统。ZFS是一个开源的现代文件系统，最早发布于2005年，被SUN公司称之为终极文件系统。ZFS作为128位的文件系统，支持的最大容量某种程度上接近无限，按照维基百科上面的形容，假设每秒钟创建1000个新文件，达到ZFS文件数极限需要大约9000年。另外ZFS文件系统还支持写入时复制、快照、数据完整性校验及自动修复等高级功能。这些特性没办法在此一一展开，个人了解的也比较有限，但可以肯定的是，ZFS等新型文件系统，迟早会取代EXT等老旧文件系统，ZFS等新兴文件系统的众多特性，也必将会对取证造成重大影响，届时数据恢复、取证分析的思路也会有很大的变化。

# **取证小知识-23** \[2019-12-06发布\]

E01和Ex01应该是除DD外最常见的取证镜像格式了。E01和Ex01看起来都有“加密”功能，但实际上实现方式完全不同。Ex01的“加密”对数据区域真正进行了加密，没有密码就访问不了数据，而E01的“加密”实际仅仅是镜像打开密码而已，数据并没有真正加密。有个名为“EWF MetaEditor”的免费工具，可以直接移除E01格式镜像的打开密码，其官网是https://4discovery.com/，这个网站还有其他多款免费工具，可以解析文档打开记录、程序运行记录、USB使用记录等。

# **取证小知识-24** \[2019-12-09发布\]

MacOS从2011年7月20日发布的OS X Lion (10.7）开始支持原装SSD的TRIM功能，并在OS X10.10.4中增加了对第三方SSD TRIM的支持。固态硬盘写入新数据时，需将对应区域先置零然后再写入数据，这正是固态硬盘使用一段时间后会掉速的原因之一，TRIM指令正是为了解决此问题。文件删除后，操作系统能通过TRIM指令通知固态硬盘这些数据块已经不再使用，固态硬盘会适时将这些区域清零以提高下次写入性能。所以，对于苹果笔记本、一体机、台式机，如果里面全部是固态硬盘，基本就不要想着做传统意义上的文件恢复了，结果会让人非常失望。

# **取证小知识-25** \[2019-12-10发布\]

前面有几期提到用命令提示符或PowerShell计算文件的哈希值，有人反馈命令行中输入文件路径太痛苦了。命令行中输入文件路径有两种简便方法，这两种方法对CMD命令提示符和PowerShell都有效。第一种是用鼠标将文件拖到命令行窗口即可获取到文件路径。第二种是在命令行中先定位到文件所在路径就可以直接输入文件名而不用完整路径（其实就是相对路径）。最快定位到文件所在目录的方法是在文件所在目录按Shift键不放，然后右击，选择“在此处打开命令窗口”（WIndows7）或“在此处打开Powershell窗口”（Windows10）。在输入文件名的时候可以通过tab键自动补全，例如文件test.txt，直接输入t，然后按tab键即可补全文件名，如果按一次没有自动补全test.txt，说明当前目录下还有其他以t开头的文件，多按几次即可。

# **取证小知识-26** \[2019-12-11发布\]

PowerShell中的Compress-Archive命令可以很方面地对文件或文件夹进行打包压缩。该命令的基本语法为“Compress-Archive \[需要压缩的文件、多个文件或文件夹\] \[目标压缩文件\]”，多个文件可以通过逗号分隔。通过参数-update可以将文件添加至现有压缩包。例如需要将D盘根目录下example1.txt、example2.pdf两个文件打包压缩为“测试.zip”，只需在PowerShell中执行下列命令——“Compress-Archive D:\\example1.txt,D:\\example2.pdf 测试.zip”。

# **取证小知识-27** \[2019-12-12发布\]

X-Ways是少有的可以对以缩略图形式批量预览各种文件的取证软件。EnCase、AXIOM，以及国内的取证大师、取证神探等都有图库视图，可以直接批量预览图片，但对于其他类型的文件，则只能一个一个地预览。X-Ways中与之对应的预览模式叫“缩略图”视图，默认情况下，此视图和其他的取证软件一样可以对图片进行批量预览，但经过一番设置，可以在一个界面中批量预览各种文件。设置方法为：点击“选项”→“查看器程序”，勾选“使用独立的查看器”并设置好Viewer组件的路径，勾选“将非图片文件也以缩略图方式表示”，点击“确认”。

# **取证小知识-28** \[2019-12-13发布\]

通过S.M.A.R.T.信息可以判断硬盘的状态信息，例如序列号、使用时间、通电次数、健康状态、SSD数据写入量及读取量等。S.M.A.R.T.全称为“Self-Monitoring Analysis and Reporting Technology”，即自我监测、分析及报告技术。估计大多数取证工作者对以上知识都了解，而且也知道常见的S.M.A.R.T.读取工具有HDTune、CrystalDiskInfo等，但估计绝大多数人都不知道其实取证大师也可以查看S.M.A.R.T.信息。取证大师加载硬盘（镜像不行）后，在“证据文件”视图选中某磁盘，然后点击查看“摘要”视图，就可以看到硬盘型号、序列号、固件号、通电时间、通电次数、温度等信息，就是数据量少了点。

# **取证小知识-30** \[2019-12-17发布\]

最近购买、整理了一些标准规范文件，趟了一些坑，和大家分享一下。标准规范的查询推荐两个地方，一个是中央人民政府网站，这个绝对权威了，可以查询到国家标准、行业标准及地方标准，网址是http://www.gov.cn/fuwu/bzxxcx/bzh.htm,数据由中国国家标准化管理委员会提供；另一个是全国标准信息公共服务平台，也是官方的，可以查询国内外各种标准，网址是http://std.samr.gov.cn/。标准购买推荐京东以及中国标准出版社的中国标准在线服务网，网址是https://www.spc.org.cn/，非常不建议去非官方的工标网，体验一言难尽。
