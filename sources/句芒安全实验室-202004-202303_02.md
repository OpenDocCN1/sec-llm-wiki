# DNSLog服务器自建

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5ODQyMTM2Ng==&mid=2247484616&idx=1&sn=24955ffe62025adb0f6c669f65fdd469&chksm=332cb68079da5c617d6b2cfe7558b23ed97ce5675bdb5e9d764feaec76f1f31f1a9cd8938262&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI5ODQyMTM2Ng==&mid=2247484616&idx=1&sn=24955ffe62025adb0f6c669f65fdd469&chksm=332cb68079da5c617d6b2cfe7558b23ed97ce5675bdb5e9d764feaec76f1f31f1a9cd8938262&scene=27#wechat_redirect)

前置条件：

1.阿里云域名一个，例如 xxx.com

2.公网服务器一个, 例如 1.2.3.4

  

步骤：

1.进入域名控制台，添加A记录并指向公网IP,添加两个NS记录指向添加的A记录

![](../Images/0e213dfa878ef976b42c69d07dfc8dd6.png)

2.创建2个自定义DNS服务器，为之前填写的ns1.xxx.shop  、ns2.xxx.shop 并将域名指向公网IP地址

![](../Images/8ef37663b6e1edab7d66f483bfc5e63d.png)

修改DNS服务器为自己创建的DNShost

![](../Images/39947f32ca47f57171155106359b4644.png)

3.dns修改后有24-48小时dns生效时间。需等待一段时间。

  

4.下载dnslog平台搭建

下载地址：https://github.com/lanyi1998/DNSlog-GO/releases/

以ubutun为例。下载后修改配置文件启动即可

![](../Images/7fff4eead88dfe2571086449e346d085.png)

需要注意服务器的安全策略记得开放53端口和需要使用的端口，若启动失败，提示53端口占用，可查看端口并关闭。

  

查看监听的端口

sudo netstat -anlp | grep -w LISTEN

假设是情况如下为systemd-resolved使用：

...... tcp 0 0 127.0.0.53:53 0.0.0.0:\* LISTEN 735/systemd-resolved

使用命令关闭即可

sudo systemctl stop systemd-resolved

  

最后启动成功后，在浏览器访问IP:端口即可，输入正确的token即可登录使用

  

![](../Images/c4ed995481d77fbdb4c262a568b21088.png)

  

附该项目api

```


import requests
```
