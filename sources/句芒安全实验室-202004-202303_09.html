溯源小脚本

需求：溯源一般根据攻击者IP反查域名，之后根据域名查询Whois信息，当攻击者IP较多或查询C段时需要进行快速删选有价值信息。

一、根据攻击IP查找域名-批量

利用fofa扫描数据根据IP批量爬取域名
项目地址：https://github.com/qiygan/fofa-dump

1.根据fofa语法写入需要查询的IP

2.运行脚本生成csv文件


3.复制domain列数据进行去重

4.在线去重网址：http://quchuchongfu.renrensousuo.com/

5.结果保存为dom.txt

二、根据域名查找whois信息-批量

利用python-whois模块批量查找whois信息
项目地址：https://github.com/start-cat/scan_whois

git clone https://github.com/start-cat/scan_whois.git
pip install python-whois
python scan_whois.py

源码：

#!/usr/bin/python3
# -*- coding: UTF-8 -*-
import whois

f = open('./dom.txt','r')
for lines in f.readlines():
    try:
        print (lines)
        data = whois.whois(lines.strip())
#       print(data) #去除注释输入完整whois信息
        print ("注册公司：",data.registrar,"注册人：",data.name,"注册邮箱：",data.emails,"注册时间：",data.creation_date,"过期时间：",data.expiration_date)
        print("______________________________")
    except :
        pass
        continue
f.close()
