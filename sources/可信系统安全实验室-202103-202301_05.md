# 喜讯： Teecert labs硕士生邓森荣获2022年度国家奖学金

    **近日，喜讯传来，Teecert labs硕士生邓森代表计算机系荣获国家奖学金****。**

![](../Images/655d0c31e6b6ccc4a1ee3edf9eba44a9.png)专谨志成   行稳致远![](../Images/769654b79d382196ed0dfacb0e4b6e01.png)

邓森是Teecert labs在读硕士生，研究方向聚焦机密计算，程序分析，形式化方法等。他已经以第一作者和共同第一作者发表计算机安全顶级学术会议论文两篇。他的研究基于形式化验证的方法，揭示了如何利用机密计算架构实现高效安全的分布式协议，属于针对“分布式机密计算”这一新概念的前沿探索。相关成果发表于ACM CCS 2022。除此之外，他还首次针对一种新型的测信道攻击给出定性的建模，实现并开源了针对该攻击的自动化漏洞检测工具。同时，所提出的软件防御方案已经被主流的开源社区所采纳，并得到署名致谢。相关成果已被Usenix Security 2023接收。

科研工作之余，他还积极参与志愿者活动，多次参观深圳市党群活动中心，学习党史与深圳发展史。他在研究生阶段的多门课程中取得优异成绩，还曾担任本科生课程助教，得到老师与同学们的认可。

  

  

![](../Images/d82cf89948f7c96602aa4dc0ff5276ef.png)

  

Teecert labs注重学生科研能力与综合素质的培养，已经有多名同学在安全四大顶会上发表文章。实验室氛围融洽，负责人张殷乾教授是计算机安全领域国际知名学者。此外，实验室与海内外多家大学与公司保持紧密合作关系，包括杜克大学，俄亥俄州立大学，香港科技大学，上海交通大学，蚂蚁集团等。目前，实验室围绕机密计算，聚焦前沿且有实际价值的科研问题，致力于成为机密计算人才培养的重要阵地。
