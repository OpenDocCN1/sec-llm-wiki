# 【12 月 10 日下午】2021年CCF 计算机系统大会 系统安全论坛“下一代安全计算系统”简介

System security is the cornerstone of modern computer systems and software applications. Research on system security focuses on low-level software and hardware security issues, including the security of micro-architecture, virtualization, operating systems, and runtime environments. System security has been a focus area in academia and industry. The gist of this forum is to bring together system security researchers from both academia and industry, to discuss recent advances in the area of computer architecture design, operating system implementation, software security, data privacy and security, as well as other hot security topics on cloud, edge, IoT, blockchain, and emerging computing infrastructures.

**论坛主席：**

张殷乾 （南方科技大学）

**论坛主席简介：**

![](../Images/e7ac4dd4de5e45139ebb333fc685a38d.png)

张殷乾教授是南方科技大学教授，博士生导师。他归国前曾任美国俄亥俄州立大学计算机科学与工程系的终身副教授。他的研究涉及体系结构安全、软件和系统安全、分布式系统和应用安全、安全与人工智能、形式化验证等诸多领域，研究成果多次发表在国际知名的计算机安全会议和期刊上，其中三十多篇发表在国际四大安全顶会。他曾荣获美国国家科学基金青年科学家奖，俄亥俄州立大学Lumley研究成就奖和计算机系杰出教学奖，北美计算机华人学者协会颁发的明日之星奖，还曾在2018和2020 连续两次获得AMiner 最具影响力的安全和隐私学者提名。
