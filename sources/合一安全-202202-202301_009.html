wifi 密码安全枚举测试，需要自己生成密码本，脚本会对附近的wifi进行获取。

请用python3,安装pywifi 模块

pip install pywifi

运行界面

选择要破解wifi的编号

选择字典路径

最后密码枚举出来了。


注意：脚本会删除该计算机已连接的wifi密码，使用后需要重新输入密码连接自己的wifi。
