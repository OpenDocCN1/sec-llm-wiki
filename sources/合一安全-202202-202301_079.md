# Spring-Cloud-Function SpEL RCE复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2Mzc0ODA0NQ==&mid=2247484267&idx=2&sn=9ae6294909d1df11aee03410875d700f&chksm=ce72a9c9f90520df98726a3a3d0e429c350746f9224d9393c756a6d0b248968c8025d4e615fc&scene=126&sessionid=1681659846#rd](http://mp.weixin.qq.com/s?__biz=Mzg2Mzc0ODA0NQ==&mid=2247484267&idx=2&sn=9ae6294909d1df11aee03410875d700f&chksm=ce72a9c9f90520df98726a3a3d0e429c350746f9224d9393c756a6d0b248968c8025d4e615fc&scene=126&sessionid=1681659846#rd)

**漏洞描述**

  

Spring Cloud Function SpEL表达式注入漏洞(CVE-2022-22963)，远程攻击者在无需认证的情况下，构造特定的数据包，在header中添加"spring.cloud.function.routing-expression"参数并携带SpEL表达式，成功利用此漏洞可实现任意代码执行。

  

**影响版本**

3.0.0.M3 <= Spring Cloud Function <=3.2.2
