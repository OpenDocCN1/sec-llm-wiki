**漏洞描述**

  

3月31日，spring 官方通报了 Spring 相关框架存在远程代码执行漏洞，并在 5.3.18 和 5.2.20.RELEASE 中修复了该漏洞。

  

**影响版本**

Spring Framework 5.3.X < 5.3.18 

Spring Framework 5.2.X < 5.2.20
