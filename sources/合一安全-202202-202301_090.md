# 2022年弱密码报告揭露了网络安全的5大秘密

半个多世纪以前，密码就成为了信息技术的一部分。由于使用密码的时间非常长，似乎密码安全的最佳实践已经被完善得无懈可击，而使用常见的密码最佳实践也似乎是密码安全的重要保障。   

  

即便如此，Specops Software的第一个季度弱密码报告也透露了一些有趣的结果，可能会让您重新思考您管理密码的方式。

  

**1\. 密码长度不能保证密码安全**

  

长期以来，要求所有设置的密码长度至少为8个字符。这种密码比较实用的原因是较长的密码需要更多的计算资源才能破解。

  

然而，这一方法的问题在于，泄露的密码数据库允许网络罪犯创建查找表，这些表可以根据密码的哈希值来获取密码，而不需要实际破解密码，因此密码长度对网络罪犯来说就不是什么问题了。

  

这一想法在2022年的弱密码报告中得到了验证，该报告发现，暴力破解攻击中使用的93%的密码至少包含8个字符。同样，在现实世界中使用的41%的密码长度为12或12以上。这些统计数据强调了一个观点，即使是很长的密码也可能被泄露。

  

**2\. 密码往往受季节性或流行文化的影响**

  

弱密码报告发现，密码通常是季节性的，而且密码受流行文化的影响也很常见。例如，42%的季节性密码中包含“summer”一词。

![](../Images/a9b377c19c7b27207bae97331b055cb0.png)

密码选择通常是季节性的

  

而且似乎影响密码使用的不仅仅是季节。棒球赛季是另一种类型的赛季，该报告发现，辛辛那提红人队(Cincinnati Reds)在被攻破的密码列表中出现了近15万次。类似地，洛杉矶天使队、坦帕湾高地队、纽约大都会队和明尼苏达双城队也经常出现在被泄露的密码名单上。

  

令人惊讶的是，运动队远非常见于密码中的唯一流行文化参考。最畅销的音乐艺术家，如AC/DC、Kiss和Metallica，以及《星球大战》、《蜘蛛侠》和《阿凡达》等大片，通常都包含在密码中。对于那些可能好奇的人来说，在泄露的密码中最常被提及的电影是《洛奇》，它出现了近96000次。

  

当然，密码中引用的不仅仅是电影的标题，还有这些电影中最受欢迎的角色。对于《星球大战》电影和各种超级英雄电影来说尤其如此，影迷们对这些电影很是痴迷。

  

**3.密码复杂性不能防止凭证被盗**

  

另外，还要求密码的复杂性。例如，一个组织可能需要混合使用大小写字符、数字和符号。即便如此，《弱密码报告》发现，在真正的攻击中，68%的密码至少包含两种不同类型的字符。包括大小写字母和数字的密码泄露超过2000万个，，包括大小写字母、数字和特殊字符的密码泄露超过150万个。

  

仅包含大写和小写字母和数字的密码比包含大写和小写字母、数字和符号的密码多出13倍，这一事实最初可能表明，复杂性虽然不是万无一除的证据，但确实有助于密码安全。

  

然而，更合理的解释是，那些使用更复杂密码的人可能更有可能避免那些经常导致凭证被盗的危险行为。

  

**4.密码重用是一个大问题**

  

报告还发现，密码重复使用是一个主要问题。Specops最近调查了2000多名用户，以了解密码在他们日常生活中扮演的角色。

  

48%的受访者表示，他们在工作中需要记住11个或更多密码。71%的人说他们有11个或更多的密码需要记住。调查发现，其中361名受访者承认在多个系统上使用了相同或类似的密码。

  

这可能是因为用户必须记住这么多不同的密码。

  

**5\. 组织可以做更多工作来保证密码安全**

  

一个简单的事实是，有一个泄露的密码数据库包含了数百个遵循长期建立的最佳实践的密码，这清楚地表明，组织需要采取更多措施来确保密码的安全。即便如此，《2022年弱密码报告》发现，54%的组织没有管理工作密码的工具。此外，48%的组织没有为他们的服务台提供用户身份验证机制，这使服务台面临很多风险。
