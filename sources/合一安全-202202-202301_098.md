# 乌克兰遭部署Windows假防病毒更新程序

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2Mzc0ODA0NQ==&mid=2247483989&idx=2&sn=4a2e83557f4b636448e0d1bb2a8eda94&chksm=ce72a8f7f90521e1a04914adaeb598b8485fc77ca0688adedd44ed04cac5e91c8cc7d67cc442&scene=126&sessionid=1681659854#rd](http://mp.weixin.qq.com/s?__biz=Mzg2Mzc0ODA0NQ==&mid=2247483989&idx=2&sn=4a2e83557f4b636448e0d1bb2a8eda94&chksm=ce72a8f7f90521e1a04914adaeb598b8485fc77ca0688adedd44ed04cac5e91c8cc7d67cc442&scene=126&sessionid=1681659854#rd)

![](../Images/f711ca42f799a688e3594caa1c9de210.png)

乌克兰计算机应急反应小组警告说，威胁分子正在散布安装了Cobalt Strike和其他恶意软件的Windows假防病毒更新。  
网络钓鱼电子邮件冒充乌克兰政府机构，提供提高网络安全性的方法，并建议收件人下载“重要安全更新”，该更新名为“BitdefenderWindowsUpdatePackage.exe”，大小为 60 MB 。

![](../Images/fea249144f1342198acda6435e3362d9.png)

图：催促下载假防病毒软件更新程序的钓鱼电邮

这些电子邮件包含指向法国网站（现已离线）的链接，该网站提供所谓的防病毒 软件更新的下载按钮。另一个网站 nirsoft\[.\]me 也 被 MalwareHunterTeam 发现充当该活动的命令和控制服务器。

![](../Images/b2c4237cf7027f341d80e767c5bf6a6b.png)

图：恶意软件投放网站

当受害者下载并运行这个伪造的 BitDefender Windows 更新 \[ VirusTotal \] 时，将显示下面的屏幕，提示用户安装“Windows 更新包”。

![](../Images/2c7cbb9a303ae4f40c11b5de29e0989a.png)

图：Bitdefender Windows 更新包

然而，这个“更新”实际上是从 Discord CDN 下载并安装 one.exe 文件 \[ VirusTotal \]，这是一个 Cobalt Strike 信标。Cobalt Strike 是一个被广泛滥用的渗透测试套件，它提供攻击性安全功能、促进横向网络移动并确保持久性。同样的进程获取一个Go downloader (dropper.exe)，解码并执行一个base-64编码的文件(java-sdk.exe)。该文件添加了一个新的Windows注册表项用于持久性，并下载了另外两个有效负载，GraphSteel后门(microsoft-cortana.exe)和GrimPlant后门(oracle-java.exe)。

![](../Images/e1720f28bbd7f4d926461ca66489d86b.png)

活动中的所有可执行文件都打包在 Themida 工具中，从而保护它们免受逆向工程、检测和分析。

  

**装载有效载荷**

GraphSteel 和 GrimPlant 都是用 Go 编写的恶意软件，Go 是一种通用的跨平台编程语言，占用空间小，反病毒检测率低这两个工具的功能涵盖网络侦察、命令执行和文件操作，因此将两者部署在同一系统中很可能是为了冗余。

GraphSteel 特点：

*   收集主机名、用户名和 IP 地址信息
    
*   执行命令
    
*   窃取账户凭据
    
*   使用 WebSocket 和 GraphQL 与 C2 通信，使用 AES 和 base64 加密
    

GrimPlant 能力：

*   收集 IP 地址、主机名、操作系统、用户名、主目录
    
*   执行远程接收到的命令并将结果返回给 C2
    
*   使用 gRPC (HTTP/2+SSL) 进行 C2 通信
    

这两个有效载荷没有提供太多技术细节，我们不能排除它们在本报告中被称为新名称的已知后门的可能性。

  

**归因**

考虑到乌克兰目前的局势，我们很容易将所有的敌对活动归咎于俄罗斯和亲俄罗斯的威胁行为者，这里的情况似乎也是如此。乌克兰计算机应急反应小组将检测到的活动与UAC-0056组联系在一起，具有中等可信度。UAC-0056，也称为“Lorec53”，是一种复杂的俄语 APT，它使用网络钓鱼电子邮件和定制后门从乌克兰组织收集信息。自 2021 年 12 月以来，人们发现 UAC-0056 加大了在乌克兰的网络钓鱼和网络攻击活动。

在最近的一段时间里，有人发现同一个参与者用网络钓鱼诱饵瞄准了格鲁吉亚政府机构，因此与俄罗斯国家的利益有着高度的协调和一致性。
