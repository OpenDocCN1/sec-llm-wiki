**一、AWVS更新介绍**

  

该版本更新日期为3月1日，该更新Acunetix版本引入了多个IAST更新，将有助于检测多个高严重性漏洞，全面覆盖新支持的web框架，并改进服务器端错误配置的检测。它还为知名的web应用程序引入了新的漏洞检查，包括对CSRF令牌处理的一些更新，并提供了许多改进、更新和产品修复。

  

**二、新功能更新日志**

  

这个NET IAST传感器（AcuSensor）现在可以安装在上。Windows上的NET Core v3和v5（带有Kestrel服务器）

Acunetix扫描仪已更新，以支持IAST传感器（AcuSensor）支持的框架路由

在PHP IAST传感器（AcuSensor）中增加了对Laravel框架的支持

在PHP IAST传感器（AcuSensor）中增加了对CodeIgnitor框架的支持

在PHP IAST传感器（AcuSensor）中添加了对Symphony框架的支持

增加了对ASP的支持。NET中的MVC。NET Core iST传感器（AcuSensor）

在中添加了对Razor页面的支持。NET Core iST传感器（AcuSensor）

在中添加了对Web API的支持。NET框架和。NET Core iST传感器（AcuSensor）

在JAVA iST传感器（AcuSensor）中增加了对Spring MVC的支持

在JAVA iST传感器（AcuSensor）中增加了对Spring Struts2的支持

  

**三、新加入的漏洞检查**

Acunetix已更新，可使用IAST检测以下漏洞：

LDAP注入  

不受信任数据的不安全反映  

XPath注入  

电子邮件头注入  

反序列化不受信任的数据  

MongoDB注射液  

服务器端模板注入（SSTI）  

服务器端请求伪造（SSRF）  

Acunetix IAST（AcuSensor）已更新，可检测所有传感器中30多个新的服务器端错误配置：  

Magento配置文件泄露的新检查  

BillQuick Web套件SQL注入新检查（CVE-2021-42258）  

Apache气流实验API认证旁路（CVE-2020-13927）的新检查  

Apache默认凭据的新检查  

Apache配置的新检查  

针对Apache Airflow未经授权访问漏洞的新检查  

GoCD信息披露新检查（CVE-2021-43287）  

Grafana插件目录遍历的新检查（CVE-2021-43998）  

对nodeb任意JSON文件读取的新检查（CVE-2021-43788）  

ManageEngine桌面中央反序列化RCE（CVE-2020–10189）的新检查  

SolarWinds Orion API认证旁路新检查（CVE-2020-10148）  

Citrix ADC NetScaler本地文件包含的新检查（CVE-2020-8193）  

VMware vCenter vcavbootstrap任意文件读取的新检查  

Pentaho API认证旁路的新检查（CVE-2021-31602）  

Sonicwall SMA 100非预期代理的新检查（CVE-2021-20042）  

VMware vCenter Log4Shell RCE的新检查  

VMware Horizon Log4Shell RCE的新检查  

MobileIron Log4Shell RCE的新检查  

Ubiquiti Unifi Log4Shell RCE的新检查  

Apache OFBiz Log4Shell RCE的新检查  

Apache Struts2 Log4Shell RCE的新检查  

Apache Solr Log4Shell RCE的新检查  

Apache JSPWiki Log4Shell RCE的新检查  

新WordPress核心和WordPress插件检查  

  

**四、更新**  

IAST传感器（AcuSensor）功能已更新，以改进对以下各项的检测：

任意文件创建  

目录遍历  

SQL注入  

远程代码执行  

如果web应用程序上安装了旧版本的iST传感器（AcuSensor），Acunetix将开始报告  

对CSRF代币处理的重大更新  

漏洞页面现在包含一个唯一的漏洞ID  

多个UI更新  

多个深度扫描更新  

  

**五、修复**  

修复了GitLab问题类型未显示在UI中的问题

修复了Amazon AWS WAF导出的问题  

修复了几个扫描仪故障  

修正了一个问题。NET IAST AcuSensor在10版之前的IIS上不工作  

修复了Node的一个问题。js IAST AcuSensor导致web应用程序停止工作  

修复了PDF综合报告中多次扫描的排序问题  

修复了导致最后数据无法到达Acunetix扫描仪的超时问题
