随着计算机技术的发展，计算机网络的应用领域和应用人群急剧增加，网络安全问题也日益严重。本课程通过从不同角度，不同类型，整理出目前互联网比较流行的安全类实验，来帮助对信息安全有兴趣的童鞋们，打开一扇通往信息安全领域的大门。


实验1：windows2003~Shift后门实验

后门是一种登录系统的方法，它不仅绕过系统已有的安全设置，而且还能挫败系统上各种增强的安全设置。本实验主要介绍了windows系统中的漏洞以及危害，如何防御漏洞带来的危害。学会使用windows2003系统粘滞键漏洞建立后门程序并利用该后门。


实验2：GET注入-显错注入

SQL 注入是一种攻击方式，在这种攻击方式中，恶意代码被插入到字符串中，然后将该字符串传递到 SQL Server 的实例以进行分析和执行。本实验主要介绍了GET显错注入。


实验3：401基础认证钓鱼

本实验主要介绍了401认证钓鱼，通过本实验你能了解到401认证，学会利用401认证进行钓鱼。


实验4：Android_Web攻击

本实验主要介绍了Android_Web攻击，通过本实验的学习，你能够了解漏洞攻击原理，了解Android Web攻击，知道如何执行远程指令、网页挂马。


实验5：Mini木马

“木马”程序是目前比较流行的病毒文件，与一般的病毒不同，它不会自我繁殖，也并不“刻意”地去感染其他文件，它通过将自身伪装吸引用户下载执行，向施种木马者提供打开被种者电脑的门户，使施种者可以任意毁坏、窃取被种者的文件，甚至远程操控被种者的电脑。


实验6：由12306撞库事件引发的思考

本实验主要介绍了12306撞库事件，通过本实验的学习，你能够了解撞库的原理、攻击方法和过程，学会如何加强个人各种网络密码的安全设置。


实验7：openssl协议heartbleed漏洞分析

本实验主要介绍了openssl协议对heartbleed漏洞的分析，通过本实验的学习，你能够了解Openssl安全协议的基本概念，了解Openssl安全协议的应用，了解Openssl“心血”安全漏洞形成的原因，掌握基本的漏洞利用及使用方法。
