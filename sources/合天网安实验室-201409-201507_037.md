# 实验推荐 | Redis数据库安全实践

Redis是一款优秀的NoSQL数据库，然而其存在的安全问题可能导致服务器的沦陷，本实验将对Redis数据库及其安全攻防实践进行详细介绍，即使从未使用过Redis的你也将会对其基本操作和安全特性有一个完美的认知。

  

实验一：在CentOS上体验Redis数据库  

本实验将详细介绍如何在CentOS下通过源码编译的方式安装Redis数据库，并详细讲解如何通过redis-cli和Redis Desktop Manager来管理Redis数据。

  

实验二：Redis数据库安全攻防实践  

本实验将详细介绍Redis的安全特性，包括配合Web服务器获取Redis所在服务器的控制权限，以及如何对Redis服务器进行安全加固。

  

实验三：使用Python打造Redis安全扫描器  

了解Redis的基础知识以及安全特性之后，让我们自己动手实现一个Redis安全扫描器吧，通过扫描器可以帮助发现脆弱的Redis主机哦！
