# 学无止境——合天geek见面会|山东大学 山东科技大学

4月13日，合天网安实验室校园geek活动在百年名校山东大学举行。当天傍晚，山东大学齐鲁软件学院教学楼5区107教室，一大波网安极友在此聚集。这是合天校园活动的第十八站，也是在山东开展的第四场geek见面会。

山大，东临黄海南望泰山，自有一种巍峨与气魄，山大学子更是勤敏好学、朝气蓬勃。

![](../Images/eda0b66f2663df072b60aa9a25ab6f35.png)  

合天校园活动山东行得到山东各高校的热烈欢迎，许多未及时排上活动的学校纷纷表示希望下次活动能在本校开展，山东科技大学合天geek见面会的顺利举行正是得力于学校老师的积极安排与协调。也正是因为学校师生的热情组织，合天geek校园行于昨晚刚结束山大的活动后又立即马不停蹄赶往位于青岛的山东科大。

14日下午，合天做客山东科技大学【信息视野讲坛】，开始了与同学们的亲密接触。

合天校园活动每到一处都格外珍惜与大伙儿相聚的时光，原本并不认识的人们因为相同的爱好，因为同在合天网安实验室而建立了一种互帮互助的情谊，更也许在不久的将来，他们都将成为未来的网安大咖，成为网安界的精英翘楚。  

感受MOOE学好信安是合天geek活动的主题，惟愿合天网安实验室能成为大家信安学习路上的好帮手。

年轻的同学们，祝福你们！合天愿与你们同进步、共成长！
