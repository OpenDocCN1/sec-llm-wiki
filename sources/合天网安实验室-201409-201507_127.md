# 合天网安实验室校园行——中南大学站圆满结束

11月25日下午，合天网安实验室Geek达人会走进中南大学，为该校的信安专业学生带去了一场相关专业学习与实验的分享。活动在当天下午四点正式开始，大伙儿都早早的来到了会场，还有的同学因为下午还有功课，就趁着课间休息的空档来旁听，合天的同事们都被同学们的热情所感动。此次来到现场的大多是大一、大二的学生，理论加实践是他们认为较好的提升自己专业技能的学习方式，就像中南大学校训中所提到的知行合一，合天网安实验室MOOE的理念也很好地契合了这一点。合天网安实验室欢迎同学都来实验室做实验，若我们的实验室能为大家在今后的学习中起到哪怕是一点点的促进作用，那也是我们为此而努力的不绝动力。

同时深深感谢中南大学的老师和同学们对合天的支持与鼓励！
