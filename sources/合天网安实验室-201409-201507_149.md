# 2014年全国特定音视频检索识别挑战赛将于10月15日开赛

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTYxNjQxOA==&mid=200591115&idx=2&sn=cbb1be387ed3ea4beb6ec75b6968fe6b&chksm=28b2bbc61fc532d03165408102fd9aff91f3743f105e33d4fda20e7bc016cca6e3fda58893d1&scene=126&sessionid=1681574397#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTYxNjQxOA==&mid=200591115&idx=2&sn=cbb1be387ed3ea4beb6ec75b6968fe6b&chksm=28b2bbc61fc532d03165408102fd9aff91f3743f105e33d4fda20e7bc016cca6e3fda58893d1&scene=126&sessionid=1681574397#rd)

由竞评演练工作组主办、湖南合天智汇信息技术有限公司承办的全国特定音视频检索识别挑战赛将于10月15日开赛。

本次竞赛有视频拷贝检测、人物检测、特定标识检测、视频类型检测、音频检索、语种识别、说话人识别、关键词检出、相近音频发现竞赛等涵盖视频、音频两大部分共九个内容的比赛项目。

截至目前为止，已有28家参赛队伍顺利通过报名，即将参加比赛。参赛队伍包括中国科学院信息工程研究所、北京大学计算机科学技术研究所多媒体信息处理研究室、清华大学、国防科学技术大学VAP研究中心、同济大学、复旦大学等多个团队。可以说，本次音视频大赛汇聚了国内顶尖学术、科研单位和机构，是一场高智商的技术较量。

10月15日上午9点，比赛将在位于长沙岳麓区的湖南合天智汇信息技术有限公司电子靶场部火热展开。届时，数十家参赛团队和相关领导、专家、用户将齐聚赛场，一场声势浩大的音视频饕餮赛事将为大家激情呈现！
