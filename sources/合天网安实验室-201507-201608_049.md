# @合粉 【反对网络攻击倡议书】

**背景**：综合外媒报道，29日下午16时许，河内和胡志明这2家越南最主要机场的航班资讯、柜台报到系统显示屏突然改变，疑似遭黑客入侵，出现辱骂越南和菲律宾的不雅词汇、显示“南海是中国的”等信息。

  

![](../Images/f903a6532b32a2961db1b3261662136b.png)  

  

对于上述事件，可能很多人会觉得很解气，甚至还会有一丝自豪，但是小编想提醒大家，应该理性的看待这件事，首先这是违法的，是对法律法规的挑衅，且涉及到国际关系后果更严重。其次会对国家在国际上的形象造成不良影响，将会对处理南海问题产生一些困扰，使矛盾激化，爱国也许变成闯祸。

**因此合天网安实验室向合粉们发出倡议：**

**一、坚决反对各种网络攻击。**

不进行任何形式的网络攻击，不参与有害和无用信息的制作和传播，不利用互联网发表不当言论或发泄个人情绪、破坏社会稳定的信息，切实履行应有的社会责任。

  

**二、做好自我约束，不被利用。**

要增强明辨是非、判别对错的能力；要提升网络素养，防止上当受骗，被某些居心不良个人或组织利用。

**三、理性爱国，不给祖国添麻烦。**

面对国家、民族核心利益，政府会用各种有理有利有节的手段和方法，根据事态的情况，采取相应的措施，我们要充分相信政府，做到理性爱国，不能通过过激的行为，破坏国家战略布局，给国家造成不必要的麻烦。

 

                                    合天网安实验室
