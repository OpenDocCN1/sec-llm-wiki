# 英国安全报告“网络军备竞赛”黑客完胜

企业与执法机构联合对抗网络犯罪，谁会赢呢?根据英国国家犯罪局给出的消息，恐怕在这场“网络军备竞赛”中，黑客要笑到最后了。

 ![](../Images/e29ddd8b925d308c0fb4a0ceb5bfdeec.png)  

根据BBC的报道，英国的网络犯罪团伙技术能力已经超过了英国的管控能力，在去年246万个网络事件中，70万犯罪分子里有几百个罪犯就可以给英国的网络环境带来巨大的威胁，而且他们甚至是无解的存在，英国的网络安全部门对他们几乎无能为力。

 

据悉，英国的网络犯罪主要威胁来自于国际犯罪团伙，在这些团伙中有着十分明确的分工，甚至包括呼叫中心和翻译中心等部门的划分。而且，这些先进的国际犯罪团伙通常会有组织的进行集体作案，针对英国部分企业进行高额的恶意欺诈。

 

而且英国国家版权局表示，与网络罪犯的对抗会是一个长期的挑战，为了应对这一局面，英国政府预计将在未来5年内投入190亿英镑来增强加快刑事侦破和网络技术能力的发展，英国政府将会协同执法、行业监管、审查和商业领袖共同对抗这一挑战。
