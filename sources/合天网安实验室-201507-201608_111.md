# 黑客在暗网出售29万多名美国民众驾驶证记录信息

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTYxNjQxOA==&mid=2652839334&idx=1&sn=0d0c86f2e7af32f9029a0e67dd37b655&chksm=bd59616b8a2ee87dbf59e917891e436d60541cc9028678e773e803a4f816550e2fd2bfe6f353&scene=126&sessionid=1681574220#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTYxNjQxOA==&mid=2652839334&idx=1&sn=0d0c86f2e7af32f9029a0e67dd37b655&chksm=bd59616b8a2ee87dbf59e917891e436d60541cc9028678e773e803a4f816550e2fd2bfe6f353&scene=126&sessionid=1681574220#rd)

  

据外媒报道，近日一位自称为“NSA”的黑客在暗网（Dark Web ）出售一份包含29万多名美国民众个人信息及驾驶证信息的数据集。该名黑客声称攻破了路易斯安那州几个组织的网站，因此大部分信息来自路易斯安那州当地民众。这名黑客表示他窃取的数据库中包括了违章驾驶记录等。

 ![](../Images/448a54bb2412d902a7f63b4aab6a7674.png)  

这名黑客称，这些数据包括了交通违法行为、罚款总额、姓名、出生日期、驾驶证号码、驾驶证发行地、家庭地址、城市、州、邮编地址、电话号码及邮箱地址等。黑客还透露有些信息并不完整，但全部包括了驾驶证号码。

 

黑客NSA表示，在全部29万多名民众中，1983年出生的人最多，此外还包括了一些青少年和老年人的信息。另外，非路易斯安那州的居民占一小部分。

 

黑客将这个数据集命名为“The Real Deal”，并已开始在暗网兜售。他表示：“忽略上面的标价。提供一个我们双方都同意的报价，我会另外为你创建一个能够购买这份数据集的个人清单。如果只能出低价，请勿打扰。”
