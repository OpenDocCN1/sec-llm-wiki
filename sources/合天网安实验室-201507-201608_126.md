# “匿名者”为2016年最活跃黑客组织

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTYxNjQxOA==&mid=2652839239&idx=1&sn=f3ca7d5a65fa19e703809a3ff43392d1&chksm=bd59618a8a2ee89cef68c6bf4de343b9f1f414453a0609a388df7316d6b7435b572b7213e502&scene=126&sessionid=1681574225#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTYxNjQxOA==&mid=2652839239&idx=1&sn=f3ca7d5a65fa19e703809a3ff43392d1&chksm=bd59618a8a2ee89cef68c6bf4de343b9f1f414453a0609a388df7316d6b7435b572b7213e502&scene=126&sessionid=1681574225#rd)

根据SurfWatch Labs最新公布的一份调查报告显示，匿名者(Anonymous)在黑客组织热门榜中仍旧保持领先地位，紧随其后的为Turk Hakc Team、New World Hacking、Ghost Squad Hackers。相关数据披露，虽然黑客组织在近几年来的行动有所放缓，但由其带来的危害仍旧足够引起主流媒体的注意。

 ![](../Images/2c59138c98df7d5a287aaef51b31a21f.png)  

SurfWatch称，政府机构是受黑客网络攻击最严重的区域，其中该类型大规模行动来自匿名者菲律宾分支COMELEC和Lulzsec菲律宾分支，他们曾泄露了近5000万名菲律宾选民的信息。

 

而这些黑客组织在今年年初对BBC发起的DDoS攻击、对美国总统竞选人特朗普发起的#OpTraump运动、对希腊央行等大型银行发起的DDoS攻击以及对日产发起的#OpKillingBay都成功地吸引了人们的注意。此外展开的一些规模相对小一些的网络攻击同样也达到了这个目的。

 

#OpTrump、#OpKillingBay、#OpWhales、#OpIsrael、#OpAfrica为2016年前期黑客网络攻击规模排在前五的运动。

SurfWatch Labs在报告中指出，此前曾臭名昭著的叙利亚电子军和Lizard Squad不知为何就像从地球上消失了一样，他们没有在网络上检测到关于这两个黑客组织的网络攻击行动。也许，叙利亚电子军成员正忙于逃离美国政府的追捕，所以自然也就没有来自他们的网络攻击了。
