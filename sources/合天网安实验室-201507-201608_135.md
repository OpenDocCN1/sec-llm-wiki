# 淮南师范学院合天geek活动顺利举行

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTYxNjQxOA==&mid=2652839201&idx=1&sn=7614a0a15099d9a7cfe9f713df861edf&chksm=bd5961ec8a2ee8faa51845b2b7502ea2f8ccd28fc58f8735acf3ed64b5dc4fb7f1e08e0a12e9&scene=126&sessionid=1681574230#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTYxNjQxOA==&mid=2652839201&idx=1&sn=7614a0a15099d9a7cfe9f713df861edf&chksm=bd5961ec8a2ee8faa51845b2b7502ea2f8ccd28fc58f8735acf3ed64b5dc4fb7f1e08e0a12e9&scene=126&sessionid=1681574230#rd)

5月20日下午，淮南师范学院合天geek活动在该校顺利举行。

 

本次活动受该校老师热情邀请而隆重开展，应学校老师要求，为了契合学校的网络安全宣传日主题，淮南师范学院的合天geek见面会内容增加了部分分享议题。

![](../Images/bcb60d34db218d50af0f1662fddcb1e6.png)  
 

在本次的geek见面会中，首先由学校网络工程系孙主任在见面会上做了欢迎致辞，接下来合天智汇安全工程师姚振宇为现场的老师和同学们介绍了近期发生和影响较大的安全新闻，比如网络空间安全一级学科、中国网络空间安全协会成立、国外的一些针对网络安全的计划举措等，以加深大家对网络空间安全的理解。

 

![](../Images/1185fd36334865992077ec5ff09e43fa.png)

![](../Images/23c4c5b9045b3894cb95bf1207916778.png)

  

同时，姚振宇还与同事王一帆为同学们带来了一次现场攻防演示——“Strust2远程代码植入”。这是4月末发生的真实网络安全事件，姚振宇和王一帆通过合天网安实验室已经搭建好的环境还原了这一攻击行为，介绍了原理、如何防御，给学生展示了神秘的黑客撸站过程！

 

![](../Images/cb7952dddb45d7055ee0bf3672495ee5.png)

![](../Images/17c28f7b93d174ddfafd369b63202045.png)

  

期间，关于“虫洞漏洞”、“APT之水坑攻击”等安全事件，合天安全部的帅哥们也一一向大家做了展示，让大家进一步深刻理解安全的重要性，让学生真正了解到网络安全就在身边。

 

当讲到学习网络安全的方式、方法时，现场童鞋们的提问一个接着一个，合天帅哥均耐心解答，并通过串联合天网安实验室的一些实验课程，为大伙儿生动地讲解了网络安全学习之路，让学生对如何学习网络安全有了更为清晰的认识。
