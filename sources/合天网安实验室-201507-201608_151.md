# 聚网络英才·筑安全生态——2016中国网络安全年会即将举行

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTYxNjQxOA==&mid=2652839145&idx=1&sn=d3f26f4511f7f7715ac6120dca9a6ce3&chksm=bd5960248a2ee9326d130f0bb1c959a7e6db6a005797a6465cdcfaf9abf39420eaf1648addd1&scene=126&sessionid=1681574235#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTYxNjQxOA==&mid=2652839145&idx=1&sn=d3f26f4511f7f7715ac6120dca9a6ce3&chksm=bd5960248a2ee9326d130f0bb1c959a7e6db6a005797a6465cdcfaf9abf39420eaf1648addd1&scene=126&sessionid=1681574235#rd)

中国网络安全年会是由国家互联网应急中心（CNCERT/CC）主办的国内网络安全领域的顶级会议。年会自2004年举办以来，得到了工信部、科技部、公安部、中国人民银行等主管部门和相关部委的大力支持。年会以“服务信息社会、共建和谐网络”为宗旨，紧扣互联网技术与社会发展脉博，吸引了国内网络安全领域政府部门、重要信息系统单位、企业、高校、科研院所的广泛参与，国际化程度高，有力推动了业界的合作交流。

 

“2016中国网络安全年会”将于2016年5月24日至26日在四川成都举行。本次会议将邀请政府部门、重要信息系统单位、基础电信企业、非经营性互连单位、科研和产业机构的领导和专家700余人参会。

 

此次会议旨在交流国内外网络安全工作新趋势、新问题、新思路；促进国家公共互联网网络安全应急体系成员间的合作；加强互联网行业的网络安全保障和突发安全事件的应急处置联动，普及宣传网络安全及网络安全应急工作知识，提升社会网络安全意识。

 

会议将以“聚网络英才·筑安全生态”为主题，围绕“网络安全威胁情报”、“网络安全人才培养”、“个人隐私保护与数据安全”、“移动互联网安全生态”、“漏洞安全及价值秩序”、“CNCERT-CIE网络安全学术论坛”等六个专题设置分论坛进行交流探讨。

 

同期，还将举办“2016中国网络安全技术对抗赛”，寻找具备渗透测试、漏洞分析、漏洞修复、安全防护等网络攻防实战能力的优秀团队和技术人才，推动网络安全技术的发展与应用，宣传普及网络安全知识，提高用户网络安全防护意识。
