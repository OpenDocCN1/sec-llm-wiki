首先到官网下载安装包

https://www.mongodb.org/dl/win32/i386

这个网址里对应的是32位windows系统各个版本的mongodb，本次实验使用的是2.6.4版本的mongodb。试验机内已经下载并解压好了(在C:\mongodb-win32-i386-2.6.4)，请大家根据接下来的实验步骤指导来进行安装。

实验任务二

Mongodb的错误配置及利用

MongoDB安装时不添加任何参数,默认是不开启权限验证的,登录的用户可以对数据库任意操作而且可以远程访问数据库。

在刚安装完毕的时候MongoDB都默认有一个admin数据库,此时admin数据库是空的,没有记录权限相关的信息。当admin.system.users一个用户都没有时，即使开启了权限验证,如果没有在admin数据库中添加用户,此时不进行任何认证还是可以做任何操作,直到在admin.system.users中添加了一个用户。

没有权限验证的MongoDB可被Mongodb管理工具（如：Mongo-cola）远程匿名连接及进行数据库操作。

实验任务三

Mongodb未授权访问漏洞修复

1、添加用户认证

首先mongodb没有炒鸡无敌万能的管理用户，只有能管理用户的用户权限userAdminAnyDatabase。并且要切换到admin数据库，添加的账号才是管理员账号权限。用户只能在用户所在数据库登录，包括管理员账号。

进入server服务器，打开 mongo shell：

添加管理用户

useadmin   #切换到admin数据库

#在admin数据库里增加一个用户，权限为userAdminAnyDatabase，用户名为admin，密码为123456

db.createUser(

  {

   user:"admin",

   pwd:"123456",

   roles:[{role:"userAdminAnyDatabase",db:"admin"}]

   }

)


然后执行db.shutdownServer()关闭数据库，


接下来重新打开一个cmd，输入命令 mongod --auth，启动mongodb服务器


然后我们重新连接mongodb数据库，发现依然可以连接上，但是却无法显示数据库和表了。


 

现在我们来新建一个可以管理heetian数据库的用户。

命令：

use admin 切换到admin表，在admin表进入用户认证。

Db.auth(“admin”,”123456”) 进行用户认证，认证成功返回1


 

use heetian   切换到heetian数据库

添加一个可以对heetian数据库进行读写的用户test，密码为654321

db.createUser(

 {

  user: "test",

  pwd: "654321",

  roles: [{ role: "readWrite", db: "heetian" }]

 }

)


接下来再在heetian数据库里进行test用户的认证，认证过后，我们就可以对数据库进行操作了，如下图所示。


 

2、更改mongodb默认端口号

首先关闭数据库(可以直接关掉运行mongod的cmd窗口）,然后重新打开一个cmd执行如下命令启动mongodb。

Mongodb --auth --port 1234


这样我们就把mongodb的端口改到了1234，这样mongo就要加上端口才能访问了。


3、限制连接IP

在mongodb启动时可以通过添加–bind_ip参数来绑定IP，如进行下面的绑定后则只能够从本机访问：

Mongod --auth --port 1234 --bind_ip 127.0.0.1
