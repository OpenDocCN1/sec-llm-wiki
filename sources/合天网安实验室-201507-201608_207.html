程序破解是指利用逆向工程手段分析某个软件或者二进制程序，以反汇编阅读源码的方式去推断其数据结构、体系结构和程序设计信息，从而理解程序逻辑，以达到破解程序部分或全部功能的目的。

攻击者可以通过现有的逆向工具或者调试工具来破解程序。根据程序的运行级别不同，可以分为操作系统级、用户级软件，因此调试工具也可以分为操作系统级调试工具（内核级，RING0）和用户级调试工具（RING3）。常见的操作系统级调试工具有IDA，SoftICE等，用户级调试工具有OllyDbg。

OllyDbg（简称OD）是一个强大的动态追踪工具，将IDA与SoftICE思想结合起来，RING3级调试器，非常容易上手，己代替SoftICE成为当今最为流行的调试工具。同时还支持插件扩展功能，是一款小巧但是强大的调试工具。

下面让我们从OllyDbg工具入手来学习软件破解：

1. 学会利用OllyDbg工具调试普通用户程序；

2. 学会利用OllyDbg工具分析普通用户程序的注册逻辑；

3. 学会编写注册机程序来破解普通用户程序的注册逻辑。

 

实验步骤一

用OD工具打开桌面“测试样例1”文件夹下的“CrackMe.exe”，载入程序并开始调试。

 

实验任务一

任务描述：学会用OD工具调试普通用户程序。

1、打开桌面的汉化版OD调试工具，单击“文件”-“打开”，或者快捷键F3载入CrackMe.exe程序。并单击“调试”-“运行”，或者快捷键F9运行待破解的程序。


运行CrackMe.exe后，在上面和下面的输入框中分别输入注册的账号名和注册的序号，这里我们输入测试的账号名test123和测试的注册序号123456，单击“test”按钮可以看到错误提示的弹窗“Try again”。


2、用OD查找特征字符串：

首先，在反汇编窗口右键单击“查找”-“所有参考文本字串”，在弹出的查找面板中右键单击“查找文本”，并输入查找的特征字符串测试账号“test123”，测试序号“123456”，以及错误信息“Tryagain”。当定位到这些字符串后，通过在特征字符串处设置断点（单击F2），设置好后，双击定位到反汇编窗口中的特征字符串所在的代码处。

3、用OD查看注册逻辑。

设置好断点后，切换到“CrackMe.exe”程序的界面，并再次单击“test”按钮，确定后OD运行到断点位置。通过步过F8进行调试，以此来快速熟悉注册逻辑的前后运行过程。


 

实验步骤二

用OD工具调试待破解程序的注册逻辑，并详细分析程序中的注册逻辑。

 

实验任务二

任务描述：学会用OD工具来分析程序的注册逻辑。

在设置好特征字符串的断点后，我们通常选择用F8进行单步步过调试，当遇到不明白的过程调用再用F7进入过程内进行调试。调试时，需要观察寄存器中的变化、堆栈中的变化。

根据不断反复用F8单步步过调试，可以发现整个注册逻辑的大致运行过程如下：

第一步，注册逻辑获取用户输入的注册用户名（00401148处调用GetDlgItemTextA函数）。

第二步，判断用户输入的注册用户名字符数是否符合要求，不符合要求跳转到004011EF处的错误消息弹窗提示，符合要求则根据用户名计算注册码。

第三步，根据注册用户名计算得到对应的注册码。

第四步，将计算得到的注册码和用户输入的注册码进行比对，相等则提示成功，否则弹窗提示错误消息。

 

下面对整个注册逻辑的详细运行过程进行解释说明：

第一步，获取用户输入的注册用户名（00401139-00401148）

push 32                            ; nMaxCount=32;

pushCrackme1.004020F3             ; lpNameBuf=004020F3

push 0C8                           ; nIDDlgItem=C8

push dword ptr ss:[ebp+8]             ;

call<jmp.&USER32.GetDlgItemTextA> ; GetDlgItemTextA系统函数调用，即eax=GetDlgItemTextA(hDlg,nIDDlgItem,lpNameBuf,nMaxCount)，调用GetDlgItemTextA系统函数来获取注册用户名，用户名存到004020F3，用户名字符个数存到eax寄存器中。


第二步，判断用户输入的注册用户名字符数是否符合要求（0040114D- 00401159）

cmp eax,0                          ; eax为注册用户名字符数

je Crackme1.004011EF               ; 若用户名字符数为0则跳转到004011EF处的注册失败

cmp eax,4

jb Crackme1.004011EF               ; 若用户名字符数小于4跳转到跳转到004011EF处的注册失败


第三步，根据注册用户名来计算对应的注册码（0040115F-004011A8）

xor ecx,ecx

xor ebx,ebx

xor esi,esi                       ;ecx=ebx=esi=0，寄存器ecx,ebx,esi清0

mov dword ptrss:[ebp-4],eax      ; 将字符个数保存在局部变量中

movsx eax,byte ptrds:[ecx+4020F3] ; eax=UserName[ecx]，ecx初始值为0，取用户名第ecx+1个字符到eax（实际存储的和比较的都是字符的ASCII码值，注意是十六进制）

cmp eax,20                  ; 判断eax是否等于20（空格符的ASCII码）

je shortCrackme1.0040117B         ; 如果eax为空格符，则跳转到0040117B处，即计算注册码时忽略用户名中的空格字符；如果eax不为空格符，则往下进行注册码的计算

imul eax,eax,4                     ;eax=eax*4;

add ebx,eax                        ; ebx=ebx+eax;

mov esi,ebx                        ;esi=ebx;

inc ecx                            ;ecx=ecx+1;计数器增加1

cmp ecx,dword ptrss:[ebp-4]          ; 判断ecx计数器是否等于注册用户名的字符个数；

jnz shortCrackme1.00401168       ; 如果ecx计数器不等于注册用户名的字符个数，则跳转到00401168继续取下个字符进行计算，直到循环取完注册用户名的所有字符完成注册码第一部分的计算；

cmp esi,0

je shortCrackme1.004011EF         ;如果esi等于0，则跳转到注册失败

 

mov ebx,654789                     ;ebx=654789;

movsx eax,byte ptrds:[ecx+4020F2] ; eax=lpNameBuf[ecx-1]，ecx初始值为7，取第ecx个字符，即循环从最后倒着取字符进行第二部分注册码的计算

dec ebx                            ;ebx=ebx-1;

imul eax,ebx,2                     ;eax=ebx*2;

add ebx,eax                        ;ebx=ebx+eax;

dec ebx                            ;ebx=ebx-1;

dec ecx                            ; ecx=ecx-1，计数器ecx减1

jnz shortCrackme1.0040118B         ;如果ecx不等于0，则跳转到0040118B处继续取字符进行计算;

 

push esi                           ; arg1=esi，注册码第一部分

push ebx                           ; arg2=ebx，注册码第二部分

push Crackme1.004020C7             ; lpFmt="BS-%lX-%lu"，注册码输出格式为"BS-注册码第二部分（16进制长整数）-注册码第一部分（无符号10进制长整数）"

push Crackme1.004021BB             ; lpOut=004021BB，注册码存储位置

call<jmp.&USER32.wsprintfA>       ;调用系统函数  wsprintfA，wsprintfA(lpOut,lpFmt,arg2,arg1)，用esi,ebx的值和格式"BS-%lX-%lu"生成正确的注册码存入004021BB，可以在此处可跟踪004021BB得到正确的注册码，例如在测试中注册用户名为test123，计算得到的注册码第一部分为958（16进制），按格式输出为"2392"，注册码第二部分为613A0E4F，按格式输出为"613A0E4F"，因此最终的正确注册码为"BS-613A0E4F-2392"。


第四步，注册码比对（004011B7-004011EE）

xor ecx,ecx                         ;

push 32                            ;

pushCrackme1.00402157             ;

push 0C9                           ;

push dword ptrss:[ebp+8]             ;

call <jmp.&USER32.GetDlgItemTextA>;获取用户输入注册码到0402157

cmp eax,0

je shortCrackme1.004011EF         ; 如果用户输入注册码字符数为0，则跳转到004011EF处的注册失败

xor ecx,ecx                        ;ecx=0;

movsx eax,byte ptrds:[ecx+402157] ; eax=用户输入注册码第ecx+1个字符

movsx ebx,byte ptrds:[ecx+4021BB] ; ebx=正确注册码第ecx+1个字符

cmp eax,ebx

jnz shortCrackme1.004011EF       ; 逐位比较注册码，如果eax和ebx不相等，则跳转到004011EF处的注册失败;

cmp eax,0

je shortCrackme1.00401204         ; 如果eax为0，即当对比到字符串的最后一位'\0'，表示两个字符串完全相等，则跳转到00401204处的注册成功

inc ecx                            ; ecx=ecx+1，ecx计数器加1

jmp short Crackme1.004011D4        ; 跳转到004011D4处，循环继续下一位注册码的比较;

retn                               ; 返回


至此，整个注册逻辑的判断结束，接下来就是根据注册逻辑来编写注册机程序。


实验步骤三

在以上用OD工具分析完程序的注册逻辑后，接下来学习编写通用的注册机。

 

实验任务三

任务描述：学会编写简单的注册机程序。

根据CrackMe程序的注册逻辑，首先根据用户输入的注册用户名计算注册码第一部分，然后计算注册码第二部分，最后按照"BS-%lX-%lu"格式输出注册码即可。注册机程序的整个代码如下：

 

#include "stdafx.h"

#include "stdio.h"

#include "conio.h"

#include "string.h"

 

// 注册机的注册码计算函数

int KeyGen(char *userName)

{

   long  eax = 0, ebx = 0, ecx = 0,esi = 0, len;

    charKey[50] = "";

       len= strlen(userName);

 

   if(len < 4 || len > 50) {

              printf("Illegaluser name!");

       return 0;

       }

   

   // 计算注册码第一部分

   for(ecx=0; ecx < len; ecx++)

    {

       eax = userName[ecx];

       if(eax == 0x20)

           continue;   

       ebx += 4 * eax;

    }

   esi = ebx;

   

   // 计算注册码第二部分

   if(esi == 0)

       return 0;

   ebx = 0x654789;

   

   while(ecx)

    {

       ebx--;

       ebx += 2 * ebx - 1;

       ecx--;

    }

   

   // 按照注册码格式输出注册码

   sprintf(Key, "BS-%lX-%lu", ebx, esi);

   printf("Key: %s\n", Key);

   

   return 1;

}

 

 

// 注册机主函数   

int main(int argc, char *argv[])

{

   char userName[50] = "";

}

 

通过编译器编译后，就可以生成注册机程序了。大家可以在桌面-测试样例1文件夹下面，双击"CrackMe_KeyGen.exe"，即可运行注册机程序。

随便在注册机中输入用户名，回车即可得到有效的注册码。然后再打开CrackMe程序，输入注册用户名和注册码，可以看到提示注册成功。
