# 抢红包神器藏木马 专家提醒：微信绑卡要谨慎

手指一点，红包到手。临近农历年，抢红包“大战”即将打响，为了保证抢到“大红包”，不少人将目光对准“抢红包神器”。殊不知，这类软件有不少是恶意软件，有的暗藏木马病毒，轻则用户个人信息被窃取，重则失窃。

“元旦前一天下载的这款抢红包外挂软件，试了几次，确实能帮我抢到最大面额的红包。可是到了第二天，微信账号突然登不上去了，接着发现绑定的银行卡里的500多元钱也没了。”1月11日，说起自己安装抢红包神器被盗刷银行卡的经过，家住省城学府小区的张波后悔不已：“幸亏卡里钱不多！”

不法分子是如何知道张波的微信支付密码的？对此，记者试验后发现，以忘记微信支付密码为由，只要依次输入绑定银行卡、用户身份证还有预留手机号，就可以重新设置，一旦这些信息丢失，绑定的银行卡难免遭受损失。

之后，记者在淘宝网上搜索“抢红包神器”，共搜到3618件宝贝，价格从0.2元至6000元不等。其中一款价格不菲的“微信红包透视” 打出这样的宣传口号：“只要你有人脉有群，日赚千元已经过时，日赚万元才是真。”记者咨询了几家店，有家店主甚至告诉记者：“如果担心安装后赚不到钱可以合作，拉我进你的群，赚钱后五五分成。”

对此，相关专家表示，不少恶意抢红包外挂软件会植入恶意代码，获取用户的地理位置、银行卡账号、手机联系人等私密信息，一旦用户允许软件获取这些权限，个人信息就很容易被不法分子上传到外部的特殊服务器中，而且还会在其中嵌入广告与应用的推送代码，在通知栏、桌面、移动应用窗口中弹出恶意广告，甚至在后台偷偷下载推广应用。专家提醒微信用户安装此类软件要慎重，最好不要与银行卡绑定。

记者了解到，不久前，微信团队曾提醒用户，切勿使用刷抢红包插件，刷抢红包威胁自身以及他人微信聊天、微信支付安全。同时声称，将对利用第三方软件刷抢红包，危害客户安全的行为进行严厉打击。

对多数人来说，微信抢红包不在于钱的多少，而在于“抢”的过程，以及抢到红包后的惊喜感受。可也有少部分人，竟将之作为“生财门路”。这一点，从淘宝网上抢红包神器的销量就可看出，高达几千元的宝贝居然也有人购买，更有网友留言称：“今年过年大赚一笔，就靠它了。”这种想法和做法其实暗藏风险。
