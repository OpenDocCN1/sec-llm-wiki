# 河南理工大学合天geek活动顺利举行

12月22日下午，合天网安实验室geek活动在河南理工大学如期举行。

学校老师同学对合天的此次活动非常热心，当天上午，应学校刘老师邀请，合天安全部同事向诸位老师演示、介绍了合天网安实验室，老师们对合天的在线实验平台纷纷表示赞赏，并将鼓励同学们多去合天做实验，加强实践动手能力。

![](../Images/cfabb1125738a6149f87a352b6b84e96.png)  
下午的见面会，同学们均积极参与，互动、抽奖、提问，整个活动顺利进行。

感谢老师、同学的喜爱与支持，合天愿和大家一起进步、成长！
