# 北方工业大学合天geek活动圆满举行

12月2日下午，合天网安实验室第38场geek校园活动在北方工业大学举行。北方工大geek活动得到了该校老师同学的大力支持与关注。照学校杜老师的话来说，同学们热烈的要求与提议是本次活动得以快速顺利开展的主要因素。

自今年9月21日该校合粉网安俱乐部成立以来，俱乐部成员们就期盼着能与合天来一次近距离的接触。于是，合天与北方工大合粉们的约会就在学校宽敞明亮的机房开始了。
