# 热烈庆祝四川师范大学合粉俱乐部成立

四川师范大学合粉俱乐部依托该校信息安全协会的技术小组而成立，俱乐部承载了成员们的网安梦想！

![](../Images/52f9f2aec9a3036041e58c282e8a9d08.png)  

如同该校合粉俱乐部负责人杨同学所说，学习信息安全的道路是艰苦的，有时会觉得枯燥和茫然，希望四川师范大学合粉俱乐部能帮助童鞋们度过迷茫的时期，帮助所有对信息安全感兴趣的小伙伴坚定梦想，在信息安全这条道路上坚持走下去。
