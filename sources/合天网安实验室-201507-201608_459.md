当大家正在关注免费的Windows10时，**你却执着的守着自己的苹果OS X？**

　　当"3.15晚会"爆出苹果各种"安全隐患"时，你却在电视机前淡然一笑，**依旧玩着苹果手机？**

　　你是不是每当苹果公司出一款新产品时，**一定要去苹果店看看，哪怕买不起？**

![](../Images/c0f8a9ec83b08a6fbcce0cafd7b3f478.png)  

**果粉 一批人的信仰**

　　你是忠实的果粉，但我却要残忍地告诉你，没有绝对安全的系统。近日，意大利的开发者Luca Todesco在Mac OS X上发现一个漏洞，很容易被黑客利用。可以在不使用密码的情况下访问你的操作系统。而且如果你足够关注苹果系统安全，你会发现在不久前，苹果刚刚修复了一个 Mac OS X 10.10 Yosemite（优胜美地）系统上的一个漏洞。

　　此次发现的零日漏洞会影响每一个版本的OS X Yosemite，但在即将发布的OS X EL Captian当中影响不大。

　　而零日漏洞或许你并不会陌生，之前IE、Java都曾不行中枪。"零日漏洞"(zero-day)又叫零时差攻击，通俗地讲，即安全补丁与瑕疵曝光的同一日内，相关的恶意程序就出现。这种攻击利用目标缺少防范意识或缺少补丁，从而能够造成巨大破坏。

![](../Images/58a2fc360e7807122becbaa86e463186.png)  
**我是谁:没有绝对安全的系统**

　　这里跟大家科普一下OS X 。OS X Yosemite（10.10版本）是2014年6月苹果在全球开发者大会(WWDC 2014)发布的新一代Mac操作系统，该版本采用扁平化的设计，带来了不少新功能。如，在通知中心，增加了日历、日程、始终、天气应用。

　　OS X El Capitan 继承了OS X Yosemite 开创性的功能和精致设计，并在众多看似微不足道、实则影响重大的方面提高了用户体验。例如，同时在多个 app 中进行操作，搜索信息，关注自己喜欢的网站，查收电子邮件，以及做笔记等等。
