# 新课推荐 | 网络安全技术

网络安全技术横向覆盖了信息安全的各个方向，包括物理安全，系统安全，数据安全和应用安全，纵向又囊括了很多综合安全技术。通过本课程的学习，学生可以掌 握信息安全涉及的方方面面，不但增长了自身的知识储备，也扩宽了自身的知识领域。

**实验一：Linux服务器通用安全加固指南**

Linux 是一个开放式系统，在网络上能找到许多现成的程序和工具，这既方便了用户，也方便了黑客，因为他们也能很容易地找到程序和工具来潜入 Linux 系统，或者盗取 Linux 系统上的重要信息。所有我们需要对我们的服务器进行加固。

**实验二：Windows系统加固**

通过本次的实验，能够掌握windows 的安全加固方案，保证服务器的安全。

**实验三：防病毒软件**

通过本次实验，能学会手动查杀熊猫烧香病毒并掌握如何配合杀毒软件彻底清除病毒，保证系统安全性。

**实验四：简单部署IRC僵尸网络**

本实验讲述了如何部署IRC服务器，以及如何构建僵尸网络。

**实验五：基于破壳漏洞的蠕虫实践**

本实验介绍了一款基于shellshock漏洞的简单蠕虫程序，通过本实验，你可以了解蠕虫的使用与传播方式，也可以亲自动手随心所欲的改造这款蠕虫程序。

**实验六：DDOS攻击之SYN\_FLOOD攻击**

本实验简洁明了的说明了DDOS攻击的原理与利用过程，以实例呈现syn flood攻击的危害，对三次握手机制的缺陷进行分析以及防御手段的实施。

**实验七：DDOS攻击之CC攻击**

通过该实验了解CC攻击的原理，掌握CC攻击的基本方法和思路，能够理解整个过程。

**实验八：APT之邮件钓鱼**

某日，公司前台反映收到一封提示OA需要升级的邮件，需要用户填写OA登陆账号密码等信息。对此，我们合天网安实验室制作APT钓鱼邮件实验。主要分析该钓鱼邮件使用的手法。模拟窃取用户密码信息。

**实验九：APT之水坑攻击**

本实验对apt水坑攻击的大致过程进行了模拟，通过本实验能够建立对APT水坑攻击的直观印象和大致了解。

**实验十：Android短信、来电安全隐患**

本实验主要介绍了短信拦截、来电拦截的原理，通过本实验的学习，能够实现简单的拦截应用。

**实验十一：Android应用权限安全隐患**

本实验主要演示了如何获取SIM卡信息和通讯录信息，通过本实验的学习，能够理解SIM卡和通讯录存储的相关原理。

  

该实验汇聚了合天网安实验室多位设计师的心血。
