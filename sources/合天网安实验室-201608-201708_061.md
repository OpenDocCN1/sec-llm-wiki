0x02 **准备**

![](../Images/e90bc457e70aa55bed04f7df9c39ff16.png)

  

首先，要准备一些东西，因为大家的环境大部分都是Windows，所以我就用Windows环境来演示了（其实是懒得搞Linux环境了）。需要的工具是DockerToolBox或者Docker for Windows，由于Docker for Windows需要64位的Win10系统，我这里的系统是Win7，所以就选择DockerToolBox了。

下载安装好一路NEXT没啥好说的，直接跳过了。安装好后桌面上有三个图标，点开“Docker Quickstart Terminal”，这个是主程序。第一次运行会检测更新、初始化一系列问题，速度有点慢，之后再运行就好了。一切正常是这样的：

![](../Images/5535787b50fae85034565dae8623599e.png)

  

至此准备工作也就完美的成功了。

这里来说一下几种报错的情况，如果报错以下的内容，说明权限不够：

host is not running

  

docker is configured to use the default machine with IP

  

For help getting started, check out the docs at https://docs.docker.com

  

请右键以管理员身份运行就可以正常启动了。如果是其他未知的错误，可以尝试重启进BIOS将virtualization technology的Disabled状态设置为Enabled，即可支持虚拟化。

**0x03 正文**

![](../Images/e90bc457e70aa55bed04f7df9c39ff16.png)

  

正片会给各位讲好几种在Docker中运行Kali的方法。大概分以下几种：

  

1.直接安装Kali镜像

2.将Ubuntu升级为Kali

3.在Ubuntu中安装Katoolin工具集

  

安装镜像

  

我们一种一种来说。先说直接安装Kali镜像，这个是比较简单的，但是我在测试的时候发现系统下载到最后一层的时候发现永远是Waiting（只怪我的网速是龟速）。下载Kali-Linux-Docker镜像的命令是docker pull kalilinux/kali-linux-docker，正确无误的输入完命令后docker会如图显示：

  

![](../Images/7860dcc11cacd06755db36203a576dcf.png)

  

这种方法下载/安装完成镜像之后，我们就可以运行他了，命令也很简单docker run -t -i kalilinux/kali-linux-docker。这时候，你的Docker-Kali已经安装好了。

  

添加源

接着是第二种方法。将Ubuntu升级为Kali。这个下载/安装系统的过程和第一种方法大同小异，命令为docker pull ubuntu。这里就不截图了，安装好Ubuntu之后我们就可以运行这个镜像了。然后来运行这个镜像，需要先命名一下这个镜像，才能运行，命令为

docker run --name \[NAME\] -i -t ubuntu

docker start \[NAME\]

docker attach \[NAME\]

其中的\[NAME\]可以根据各位的喜好给镜像取名。下面是成功进入Ubuntu的截图：

![](../Images/a051122896d36b281345135d4c0e014b.png)

这个Docker版本的Ubuntu没有安装VIM，需要各位安装一下。如何安装VIM就不是本文章的范畴了，各位请百度一下，很简单的。装好VIM之后，需要切一下目录，如下图：

![](../Images/d91913a7d150dbcee7a33538132a23e0.png)

接着输入vim sources.list，就可以进入VIM编辑sources.list了，如下图：

![](../Images/f571245453246876268846962380d94e.png)

国内的Kali源如下：

#kali官方源

deb http://http.kali.org/kali kali-rolling main non-free contrib

#中科大的源

deb http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib

保存退出之后，就可以更新系统了，命令也非常简单，如下：

apt-get updata && apt-get upgrade

apt-get install \[TOOLNAME\]

其中的\[TOOLNAME\]就是Kali中的工具名称，注意，这里要写全程，空格用“-”代替。如果想安装全系统，可以写成kali-linux-all。经过漫长的等待，你的Kali就装好了（大概10GB左右）。

  

Katoolin工具集

最后是Katoolin工具集的安装，在你装好Ubuntu后，输入以下命令：

sudo su

git clone https://github.com/LionSec/katoolin.git && cp katoolin/katoolin.py /usr/bin/katoolin

chmod +x /usr/bin/katoolin

sudo katoolin

就可以安装了。因为我这里已经安装这个了，所以不方便截图。希望我写的文字可以让大家明白（毕竟语文不太好）。下边我给大家翻译了一下选择菜单：

1.安装Kali全部工具

2.升级工具包

3.删除所有Kali工具

4.查看Kali工具列表

根据自己情况需要选择一下就好了。没有什么可说的，就这样吧。
