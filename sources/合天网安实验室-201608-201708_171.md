# 合粉俱乐部家族欢迎重庆科技学院

合粉俱乐部旨在为大家找到志同道合的学习伙伴，方便交流，促进学习，并可优先享有合天各类学习资源，因此吸引了众多热爱网安的同学聚集在一起，建立了属于他们自己的网安小联盟。为了得到更多的学习资源和动力支持，4月7日重庆科技学院合粉俱乐部正式成立！

  

![](../Images/e04b767f745301ee4b71e9a0b428f97d.png)

  

重庆科技学院合粉俱乐部依托于学院信息安全小组建立，成立之初小组成员共有二十几人，为了避免大部队一起学习造成的个别同学掉队现象，大家把成员分为3个小组，平时每个小组内部单独讨论学习，然后在每周都会有一个大聚会，不懂的问题提出来由指导老师领头一起讨论和学习。这样精细化的管理和学习，使同学们保持了较高的学习积极性和自觉性。

 

精细化的管理在没有统一的实验指导下，大家的学习就会出现分散的现象，为了寻找突破口，信息安全小组决定成立合粉俱乐部，一起在合天网安实验室中学习，这样大家的学习就会更有目标性和统一性，讨论学习也会更有了针对性。

 

不断前进的标志就是在不断的克服一个又一个的困难，成立合粉俱乐部就是同学们前进中一个里程碑，在这里他们解决了学习道路上的一个阻碍，合天智汇希望同学们能够一直勇往直前，无为困境，不忘初心。
