# 合粉俱乐部家族欢迎邵阳学院

“天街小雨润如酥，草色遥看近却无。”初来乍到的春，用和煦温暖的阳光唤醒了一冬的沉寂，一年之计在于春，春天给人们带来了希望和美好，在这美好的日子里，**邵阳合粉俱乐部正式成立了！**  

![](../Images/4aaadeab3d2a6a949b45dfe3c32ff671.png)

  

邵阳学院合粉俱乐部主要由邵阳学院信息工程系网络工程专业、计算机科学与技术专业以及对信息安全感兴趣的同学自发组建，学习方向主要分为：WEB安全方向、PWN方向、逆向方向和加/解密方向 。

 

![](../Images/43d2f4c3a5e80e7f287adb2ba3e55e27.png)

  

虽然目前俱乐部的规模还比较小，一些方面还不够完善，在学习的过程也会遇到一些障碍，但热爱会让一切困难变得不那么可怕，做的所有的事情都会让自己感到幸福和满足。在梦想的牵引下，对于未来，邵阳学院的小伙伴们制定了一些计划：

 

1、在14、15、16级网安相关专业中进行宣传，鼓励同学们加入俱乐部，毫无保留的分享关于网络安全方面的知识，增加自身对本专业的了解，增长见识和提高能力，调动大家对专业的信心和学习的积极性。

  

2、定期举行校内CTF比赛，用“以赛促学”的模式，提高俱乐部成员的技术水平和参赛经验，同时也为以后参加各类CTF安全比赛积累相关的经验。

  

3、寻找外援，找一些技术大牛进行分享交流，让新手和大牛面对面进行技术交流和疑难问题探讨，使得双方扩大各自的知识面，碰撞出新的思维火花。

  

4、等到人员和制度等各方面完善后，向学校社团联合会申报合粉俱乐部社团组织，努力将其作为正规的社团组织去发展，使其更正规、健康的运作下去。

 

虽然这些计划不够详细和具体，但所有的路都是一步一步走的，在执行的时候我们相信，邵阳学院的小伙伴一定能完美的落地。

 

春风正暖，朝阳正好，希望邵阳学院合粉俱乐部的小伙伴们能够勇往直前，无所畏惧，昂首挺胸，阔步向前，用生命的燃烧之火照亮茫茫前途，用滚烫血液印证无悔人生！
