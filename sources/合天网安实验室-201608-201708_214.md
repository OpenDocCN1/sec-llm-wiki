# \[第93站\] 合天网安见面会之中原工学院完美落幕

三月，扶摇着疏疏的林影风华，轻踮着丰满踏实的年后余韵，于流萤蝶翩中旖旎而至。唤醒了沉闷的大地，带来了蜂鸣莺啼，抚柔狂妄的寒风，擦绿了阴郁的天空。于是，山醒了，水活了，海蓝了，风暖了,合天网安见面会也如期而来了。3月7日，合天网安见面会的第一站来到了中原工学院。

  

![](../Images/1244ca1caf26b43b0020e0a01461c77c.png)

（合天工作人员与俱乐部指导老师合影）

 

此次校园活动由中原工学院合粉俱乐部负责人孙同学申请组织，该同学认真、负责、充满热情的态度和快速敏捷的执行力对此次活动能够顺利举行起到了非常重要的作用， 另外俱乐部指导老师在活动时间和活动地点等方面也给予非常大的帮助，在此合天非常感谢老师和同学们对合天的支持和肯定。     

 

![](../Images/9d8474487213fb4176b0f61bc789a3e8.png)

（活动现场）

此次校园活动，合天GG主要分了三个大模块与同学们进行交流分享；第一部分从最近半年漏洞新增情况为大家揭开网安目前的情况，包括漏洞类型的分布、漏洞危害等级分布及修补情况以及最近发生在身边的安全热点事件如Linux高危漏洞：按Enter键70秒获得root权限 、支付宝曝“熟人漏洞”等；

 

第二部分从国内一些大型网安比赛来扩展同学们对网安的眼界，并且还准备了几道X-NUCA比赛的题目，在活动现场一道Web和一道逆向的题目都被同学解了出来，能看出来同学们的水平还是很高的，据合天GG讲述，现场还遇到了一位女黑客，希望能有幸认识这位同学，把自己的学习经验分享给更多的合粉；

 

第三部分是同学们比较关心和关注的话题——就业，合天GG对就业的岗位，技能，学习技巧给同学们进行了详细的解答， 让同学们根据自己的兴趣点，学习能力来选择合适自己的岗位。知识和能力都来源于积累、沉淀和总结，不要害怕吃苦，牛逼的背后都是苦逼，合天GG希望大家能够有锐意进取的毅力在网安的道路上不断前行。

  

![](../Images/b860f313862e9fb087e5e728a07e7799.png)

（赠送礼物）

欢乐的时光总是过得飞快，合天好舍不得与同学们说再见，为了表达对同学们的感谢，给大家准备了一些礼物记录下这美好的时光。我们期待与中原工学院同学们的下一次重逢。
