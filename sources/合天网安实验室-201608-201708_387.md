# 热烈祝贺青岛工学院合粉俱乐部成立

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTYxNjQxOA==&mid=2652841054&idx=2&sn=9da5589cdd63353aa38a32313775ed86&chksm=bd5958938a2ed185723a42e38cb681da4c0c440aca8b384a00c3594825a98865ad40e15c17a6&scene=126&sessionid=1681574170#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTYxNjQxOA==&mid=2652841054&idx=2&sn=9da5589cdd63353aa38a32313775ed86&chksm=bd5958938a2ed185723a42e38cb681da4c0c440aca8b384a00c3594825a98865ad40e15c17a6&scene=126&sessionid=1681574170#rd)

**2016年10月21日，青岛工学院合粉俱乐部正式成立了！这是合天网安实验室第26家线下俱乐部。**

📹 [https://v.qq.com/iframe/preview.html?vid=l0335e23y18&width=500&height=375&auto=0](https://v.qq.com/iframe/preview.html?vid=l0335e23y18&width=500&height=375&auto=0)

 

“用怀疑的眼光看待问题，从不轻易相信某种观点。”这是青岛工学院合粉俱乐部的宗旨，他们敢于质疑，勇于挑战，用互助、互爱、团队合作、创新求变、积极发展、勤奋锻炼、坚持实践的俱乐部精神去证明事实的真相。

  

![](../Images/68f20e172aaeb1cb7f9aaeb653853e7c.png)  

**着眼当下  
**

  

 1\. 参加合天实验室组织的各类CTF比赛，开阔视野，增加实战经验。

 2. 参与乌云白帽，漏洞盒子，各类漏洞平台的漏洞提交，并成为漏洞平台会员。

 3. 开展经验交流会，集大智，学大用，分享个人的writeup以及针对社团发展和活动组织等问题各抒己见。

 4. 组织讲座，三人行，必有我师焉。邀请参加工作的学长进行在线视频传授。

  

**勾画未来**

  

1. 发现漏洞，贡献自身力量

在学习中发现漏洞，提交漏洞平台，尝试编写自己的脚本，形成payload，针对漏洞攻击，编写漏洞原理报告，向合天等交流社区分享自己的收获。

2. 不忘初心，保持好奇

时刻保持一颗好奇探索未知的心，对身边的硬件进行拆解，逆向，实际动手寻求答案。

3. 分享知识，一起成长

俱乐部不定期的在学校内进行网络安全知识宣传和分享，让更多的同学了解到如何在互联网这个复杂的大环境中保护自己。

  

站在新起点，迎接新挑战，创造新成绩。相信青岛工学院俱乐部的小伙伴们一定能创造自己的光辉的未来，合天在这里祝福大家！
