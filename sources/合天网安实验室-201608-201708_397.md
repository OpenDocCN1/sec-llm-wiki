7\. Code Monkey 

  

这款游戏主要内容就是抓香蕉，在这个过程中可以学习到编程知识，可被用于教学使用（此部分收费）。

### 8\. Saga   

  

这款游戏的第一个挑战就是在15秒之内送走15个人，一起来试试吧。

  

![](../Images/539a0e8336ad533a45733677208923c3.png)  

  

9\. Codewars   

  

一款编程挑战游戏，支持 JavaScript、 Python、 C#、 Java、 Python等语言。  

  

![](../Images/8bf8d0e6f8c8ae74b14ea4045b5715e5.png)  

  

### 10.Ruby Quiz  

  

这款游戏主要适合Ruby编程语言挑战，目前这款游戏有156 个测试环节。

  

![](../Images/799be67431a80fa1d0c4b57ec3cbc16d.png)  

  

11.git-game     

  

这个游戏可以被看成是一个基于终端的游戏（ git scm），使用git命令找到“线索’,最后解决问题。

  

![](../Images/2b875d223fbe3575def70d39517cae0a.png)
