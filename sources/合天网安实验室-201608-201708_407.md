# 第72站合天网安见面会之河北科技大学 完美落幕

2016年10月13日合天网安见面会在河北科技大学顺利举行！

  

![](../Images/c4b127537fa3a6be46f96a3939e20949.png)  

  

此次校园活动能够顺利举行，首先非常感谢河北科技大学老师和同学们前期的宣传，吸引了众多对网络安全感兴趣的学生来参加此次活动，确保了活动的顺利开展。

  

![](../Images/8d6cbc6fabbc99ff6ffbe160df4d88f6.png)  

  

再者，在今天严重雾霾的恶劣天气下，依然没有阻挡同学们参加活动的热情，90多人的大教室座无空席，一些后来的同学只能站在教室后面听合天GG分享网安技能。在整个活动中同学们都听的非常认真，不断的有同学提出自己对问题的不同看法，交流氛围非常的活跃轻松。

  

![](../Images/9d50c64d29fd8d7aa9380ea5e18c714a.png)  

![](../Images/034768735ebc268ad8d43e9da30f17df.png)

  

短短的两个小时的交流，并没有满足同学对网安知识的渴望，活动结束后，一些同学又和合天GG针对黑客攻击网站的思路，网安学习方向、技巧、工具等方面进行了深入的沟通和交流。

  

![](../Images/68c784ec7eb3888a01b781f3bc2394ca.png)  

  

“牛奶”有了，当然还要有“面包”才行，合天GG带去的礼品，河北科技大学的小伙伴们，喜欢吗？

  

合天网安见面会期待和全国各大高校的同学们见面， 点击**阅读原文报名**吧！
