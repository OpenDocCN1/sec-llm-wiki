# 第67站合天网安见面会之重庆工程学院 完美落幕

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTYxNjQxOA==&mid=2652840622&idx=3&sn=908b3489c76ebff275b51051ba4b4801&chksm=bd595e638a2ed775f197ce86b96e61be8ed6164b4a9390cd535cd08f0341450e0453cdecc48e&scene=126&sessionid=1681574180#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTYxNjQxOA==&mid=2652840622&idx=3&sn=908b3489c76ebff275b51051ba4b4801&chksm=bd595e638a2ed775f197ce86b96e61be8ed6164b4a9390cd535cd08f0341450e0453cdecc48e&scene=126&sessionid=1681574180#rd)

2016年9月21日合天网安见面会在重庆工程学院顺利举行！

 

![](../Images/3415813ee54cf29e7347e5a59b381a33.png)  

  

对此次活动重庆工程学院表示了高度的重视，大力动员信安相关专业的学生参加活动，系主任万老师亲自主持活动。在此合天感谢重庆工程学院老师和同学们对合天网安见面会的支持与厚爱！

  

![](../Images/681c4cd38c0fc8da971a641508c42c58.png)  

  

活动过程中，boss刘分四个部分：认识网络空间安全、 X-NUCA联赛辅导、在线网安学习方法、 合粉俱乐部创建，为同学们进行了详细的介绍，如在X-NUCA联赛辅导中，讲解了竞赛真题，并进行了现场演示，同学们都全神贯注的听讲，积极回答提出的问题，现场气氛十分活跃。

  

![](../Images/1471e24c4db25f1300505dfe7327ba7e.png)  
![](../Images/44eaae8ad69793b6c4ae0a803e8151d2.png)  

  

当然现场抽奖也让同学们兴奋不已，因为可以和boss刘合影啦！

  

![](../Images/151da65ba84702f5cc9325b09956429c.png)
