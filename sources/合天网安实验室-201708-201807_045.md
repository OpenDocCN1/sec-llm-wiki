# 合天网安见面会之西南大学圆满落幕

它依山建筑是“山城”，它云轻雾重是“雾都”，它夏长酷热是“火炉”，本次合天网安见面会，合天GG与山城重庆西南大学的学子们开启了网络安全的探索之旅。

  

![](../Images/38c51658c7b128f47294638131d735e6.png)

网安知识宣讲正式开始，合天GG开始网安知识分享；首先给同学们介绍到了Web常见漏洞，SQL注入，XSS跨站，文件上传等，为充分调动学生的积极性，合天GG演示百度云撞库案例，该事件造成多数账号被盗；学习信安不仅仅是为了维护自身信息安全，对于以后的学习与工作都会有帮助，学习信安是为了营造清朗的网安环境，合天GG告诫同学们要将所学技术利用在正途上；不要从入门到入狱。

同学们表现出了对网络安全极大的兴趣，合天GG给同学们介绍到合天网安实验室，丰富的实验设置，可以满足同学们不同兴趣的课程学习。

树立网络安全意识，掌握网络安全基础知识，做合格的新时代网安强国建设者。合天讲师给同学们分享到，网络安全的供需情况以及网络安全人才岗位的设置情况，网络安全人才和计算机人才的关系；只有具备扎实的网络安全知识与实操技能，才能满足社会的需要以及相关用人单位需求。
