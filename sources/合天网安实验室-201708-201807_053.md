# 2018中南大学实习实训宣讲会圆满完成

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTYxNjQxOA==&mid=2652848160&idx=2&sn=74aa0363ab233fc3381dd73bebd2f4bf&chksm=bd593ced8a2eb5fb4bb5b00cbefa3f2a4a42f4bf3565a9cd8c069d402da531fd01dafa0a8364&scene=126&sessionid=1681573956#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTYxNjQxOA==&mid=2652848160&idx=2&sn=74aa0363ab233fc3381dd73bebd2f4bf&chksm=bd593ced8a2eb5fb4bb5b00cbefa3f2a4a42f4bf3565a9cd8c069d402da531fd01dafa0a8364&scene=126&sessionid=1681573956#rd)

![](../Images/5859e77776aed85e1653cb9bee725bda.png)

  
为充分配合国家网络安全人才培养战略，协助高校完善网安人才培养体系，满足企事业单位用人需求，我公司特面向各高校毕业生开展网络信息安全相关专业实习实训服务。2018年6月13日，由合天智汇承办的“中南大学信息安全专业实习实训宣讲会”圆满完成！

![](../Images/f81a066f6881a0b678945e8d894c1c5d.png)

首先，由湖南合天智汇丁尚瑜为大家做了公司企业文化、信息安全专业行业前景以及实习实训主要工作等内容的介绍。在介绍实训内容时，强调本次实习实训主要以用人单位需求为出发点，并针对岗位来设计课程内容，进而增强学员们的就业竞争力。

![](../Images/d8ae729b7733e634ea67653f121a8002.png)

随后，由合天GG吴文涛简单介绍了黑客入侵，Web常见漏洞，SQL注入，XSS跨站，文件上传等，充分引起了学生的注意力，让同学们感觉到学习信安不仅仅是为了维护自身信息安全，更是为了营造清朗的网安环境，讲解期间，我们合天GG也准备了一些题目，同学们在解题过程中积极的向我们技术请教讨论，从而拉近了彼此之间的距离。

![](../Images/e3d21278f52617d8918401ed91d8c8b6.png)

![](../Images/ff090386852a9e19ca343b6f082c9b9a.png)

最后，中南大学信息安全专业段老师为本次宣讲做了补充及总结，并强调合天智汇在信息安全人才培养方面是非常成熟的，其三大系统足以为此作技术支撑。

  

很感谢段老师对我们合天智汇的信任与支持，我们会为本次实训定制出一个适合咱们中南学生实习实训的方案，让同学们深入感受一下职业人的生活。
