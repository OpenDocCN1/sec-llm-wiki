# 合天智汇—哈工大（威海）教育部产学合作协同育人项目联合实验室正式挂牌

2018年5月14日，合天智汇—哈工大（威海）教育部产学合作协同育人联合实验室揭牌仪式在哈尔滨工业大学（威海）顺利举行；哈工大（威海）校区副校长曲世友、湖南合天智汇信息技术有限公司总经理刘江宁一同为联合实验室揭牌。揭牌仪式由哈工大（威海）计算机科学与技术学院院长初佃辉主持，湖南合天智汇信息技术有限公司副总经理刘欢迎、网络安全工程师吴文涛，威海校区计算机学院副院长王佰玲、季振洲，计算机学院教师刘杨参加了本次揭牌仪式。

![](../Images/ab430280ea2cf1738ff6d44d55361c2d.png)

![](../Images/c2e136d376ab6486c4b46cdd732954f6.png)

哈尔滨工业大学（威海）是哈工大一校三区办学格局的重要组成部分，学校位列211工程，985工程，是理工类研究型大学。哈工大（威海）与合天智汇共建教育部产学合作协同育人项目联合实验室，校企联合优势互补，充分发挥校企双方各自特长、实现产学研无缝对接、同时达到网络安全人才培养目标、满足核心技术研究和产品化需要。  

  

哈工大（威海）副校长曲世友感谢合天智汇对学校人才培养的大力支持，他讲到联合实验室的成立响应了国家深化产教融合、校企合作的号召，对推动学校人才培养模式的变革有积极意义。他希望双方能在此平台上加强联合开发和研究，把产业需求与高校的科研优势结合起来，推动企业核心技术的发展，为中国信息产业贡献力量。  
  
刘江宁总经理讲到公司主要从事网络与信息安全工程研发，初期人员与技术均来自哈工大的一支科研项目团队，合天智汇与哈工大渊源颇深。合天与哈工大及威海校区合作已久，每一步成长都离不开校方大力支持，希望通过联合实验室的形式更好地回报学校，助推学校教育和科研发展，校企携手共上新台阶。  
  
揭牌仪式结束后，一场针对该校合粉俱乐部成员以及部分大二学生的技术交流顺利进行，湖南合天智汇信息技术有限公司网络安全工程师吴文涛通过介绍SQL注入、XSS跨站、撞库、伪造信息等黑客常用攻击手法，带领同学们现场体验真切的网络攻防。

![](../Images/eb827ccd7b08c4f26d4d44e3a8823cc4.png)

网络空间的竞争，归根结底是人才的竞争，相信，在哈工大（威海）和合天智汇扎实工程基础的叠加下，双方共建的产学合作协同育人联合实验室将培养出更多网安领域高精尖的实践型人才，为国家，为社会，做出贡献。
