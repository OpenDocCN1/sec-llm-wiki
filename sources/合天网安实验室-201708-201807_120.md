 数组

  

 数组在Python中是比较常见的，是用来存储一组有序数据的，就是数据的前后顺序不会乱，Python中的数组本来被称为列表和元组，但是为了方便就说数组了，大家都听得懂，这个数组是可变长度的，元组的长度不可变

![](../Images/1bc539192699fa1d557f9f4666ffbb21.png)

  

不同于其他语言，Python的数组也没有类型的限制，可以使用任意的类型，可以使用任意类型插入进去

  

**常用方法有**

append  添加到末尾，例如 \[\].append(“123”)

count     统计某元素的出现次数 \[123,123,456\].count(123) //有返回值

extend    和另一个数组合并     \[123\].extend(\[123,234\])

index     查询某元素第一次出现的位置 \[123,234\].index(234) // 有返回值

insert     把某元素插入到某位置 \[123\].insert(0,12)

pop        弹出某元素 \[123,234\].pop(0)  //有返回值

remove   移除某元素 \[123\].remove(0)

reverse   反转列表   \[123\].reverse()

sort         排序列表   \[123,234\].sort()

 pop函数是比较特殊的，真的像pop一样，传入参数是数组下标，在移除的同时，会返回回来被移除的元素，可以进行其他操作

**索引和分片**

在python 中有一种针对字符串非常神奇的操作，就是索引和分片，这种操作在数组上面展示的就没那么神奇了

![](../Images/0115f6a0fce741ffd501b27f75a63e38.png)

  

索引是从0开始的，这种字符串后面通过方括号里面写一个数字，数字指定位置的取字符或者成员的方式就是通过下标来取的，这种方式如果是在Java中是通过charAt的方法来取的，直接通过下标的方式在字符串中取字符的操作真的是让人眼前一亮

  

分片就是通过索引的方式取一部分，是一片的

![](../Images/911d9f4961bf5703d37ffbbb217e6d37.png)

  

从上图第二个>>>开始说起

a\[1:5\] 表示从下标为1的位置，一直取到下标为5的位置，需要注意的是，这个取值的范围是包括第一个，不包括最后一个，就是1-5，包含下标为1的，不包含下标为5的，在其他语言中也是如此的

  

a\[1:5:2\] 比上一个多了一个特殊的:2，这个:2表示的是每两个取一个，也就是隔一个取一个

  

a\[5:\] 表示从下标为5的一直取到末尾，可能看第一个1:5的时候大家没有注意到，就是取片的时候是包括第一个，不包括最后一个，这个数字是不可以超过总长度的，也就是说不能取到最后一个，但是这个不写后面的值的时候是可以取到的，相应的，还可以有a\[:5\]就是从头取到下标为5的，但是不包含下标为5的

  

a\[-1\]表示的就是最后面的第一个，也就是倒数第一，也有a\[-2\]这种操作，但是不可以超出下标，超出就会报错

  

![](../Images/472f67a5f52bfbdcf3876a731b193e94.png)

通过最后一个可以知道范围能写负数，实际上三个值都可以写负数，甚至可以有两个不写的，比如a\[::-1\]就是把这个字符串倒过来
