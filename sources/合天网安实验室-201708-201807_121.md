开始：

JIS靶机全解：

探测网络, IP:192.168.1.135

![](../Images/bd6f62b6747c84ac9f3b2d13a0f29140.png)

nmap神器开路

![](../Images/e1d1d448eac8abb8e99dd0a89d2eaf05.png)

可以看到靶机开启了22，80两个端口

我们打开http://192.168.1.135 使用御剑等神器跑跑目录，本菜使用dirb神器

![](../Images/9cf950ca097c1057d9c808c8f9c0976f.png)  
  

访问 http://192.168.1.135/flag/ 得到第一个flag,

The 1st flag is : {8734509128730458630012095}

![](../Images/ca5e5a5eaa14ea6dbb9aaa2c67e75558.png)  
  

访问 http://192.168.1.135/admin\_area/  查看源码得到第二个flag和账号密码， 此次第一次看时略过了。。。

The 2nd flag is : {7412574125871236547895214}

username : admin

password : 3v1l\_H@ck3r

![](../Images/86ea8275141c5231120aa02862068199.png)

下一步肯定是用账号密码登陆了。。

登陆后就是一个上传页面，这里的上传点没有做任何限制，直接上shell

![](../Images/58520820afc32baacba8d902fc7d64d0.png)

上传成功以后那么问题来了，路径在哪呢？ 我们记得前面跑目录时，发现有robots.txt 我们通过访问可以看到多个目录，其中 /uploads 、/uploaded\_files 2个文件是什么你应该懂得，访问/uploaded\_files/你shell的名字.php ， 你会发现那个美丽的shell静静的躺着等待着你….

![](../Images/ba25e884c14646d8753efd63f7768284.png)![](../Images/3a8a645e33c70fb17738e6d91eacee6b.png)

  

本次使用的是PHP大马，登陆shell在网站根目录发现 hint.txt ,访问得到第3个flag并得到提示信息:

try to find user technawi password to read the flag.txt file, you can find it in a hidden file   

The 3rd flag is : {7645110034526579012345670}

![](../Images/f1851a9cfa87bb1fc756ad0bd8601301.png)

根据提示信息，让我们找一个隐藏文件，是technawi用户的，怎么找呢，本菜因为比较菜，所有使用了最笨的方法，全盘逐一搜索关键字：

“grep -r flag /etc/” 得到文件路径、flag、账号密码    

![](../Images/dc5d2d642d0dc38e050044e8f981d6c5.png)![](../Images/1efe7ef52274d6aa9914595133ce2414.png)

The 4th flag is : {7845658974123568974185412}

username : technawi

password : 3vilH@ksor

前面我们看到该靶机开启了SSH服务，我们直接使用该账号密码登陆

![](../Images/439e25e783a2b0aac5d8253e94c07f79.png)

最后一个flag，本菜继续使用搜索关键词的方式拿到

grep -r “The 5th flag is :” /var/       （此次关键字是结合前面几个flag规律）    

![](../Images/5f76e2d4cab57d1e223848f56dd0ba91.png)

得到flag和路径:

/var/www/html/flag.txt

The 5th flag is : {5473215946785213456975249}

![](../Images/ad6dd8134e3e3b95a623316cc944cf56.png)

  

本次仅为完成获取靶机中全部flag为目的。 

Kioptrix靶机过程      

先获取靶机IP：  192.168.1.138

![](../Images/9adfd5b62959fdeef7aac7300a195abd.png)

nmap开路：

![](../Images/580ffe2dbc57953013b856da9a931f8a.png)

  

可以看到开启了多个端口，本菜本来是想以80端口做为突破口的，使用目录猜解工具走一波，为发现可利用目录

![](../Images/40e7c9d507588aec92a8562c42c345de.png)

  

在端口探测时也看到了有一个139端口 使用的是samba服务，然后你懂得！！

为了省事本菜就直接怼上扫描器了

![](../Images/2edb8bab014fd4edfc3cf42cad8e3d20.png)![](../Images/286c6ec2f47ee343961eb9687029f19c.png)

  

可以看到漏洞还是比较多的，本文以samba为突破口做进一步渗透，

我们利用samba对应的版本搜索互联网漏洞

![](../Images/804f3d9b1c1308ad616df9c79872e01e.png)

看到有一个远程代码执行的漏洞，查看该EXP

![](../Images/a7cd68a824915e3e2b012bddb1968ae9.png)

  

使用命令：

cp/usr/share/exploitdb/exploits/multiple/remote/10.c /root/10.c   

拷贝该EXP到本机root目录下

使用gcc编译该EXP

gcc 10.c -o fuck\_samba 

![](../Images/2ff6607c352cb366f9c522e6b5c189f6.png)

一切准备就行，直接执行该EXP拿shell。

![](../Images/1fa9634cb4c347c508ccb0b18692e240.png)
