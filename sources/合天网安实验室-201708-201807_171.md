# 合天网安校园行之湖南铁道职业技术学院圆满落幕

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTYxNjQxOA==&mid=2652847343&idx=2&sn=13b72b30da09675681bf8cc7a63dbd5c&chksm=bd5940228a2ec9345547f5f544f4b4ef9c068d1ebdf2b0bf71a72770f7a527c65632ce72cff6&scene=126&sessionid=1681573987#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTYxNjQxOA==&mid=2652847343&idx=2&sn=13b72b30da09675681bf8cc7a63dbd5c&chksm=bd5940228a2ec9345547f5f544f4b4ef9c068d1ebdf2b0bf71a72770f7a527c65632ce72cff6&scene=126&sessionid=1681573987#rd)

2018年3月29日合天网安校园行来到了美丽的株洲！与湖南铁道职业技术学院的计算机网络专业与信息化专业的同学们在他们的网络综合实训室进行网络安全的学术交流。

![](../Images/6de1513c04eaf5ccb83de08adf409d99.png)

  

此次合天网安校园行是由学校吴献文主任带队，合粉俱乐部负责人胡强帮助宣传。在活动开始前，学校吴主任与咱们合天就网络安全现状进行了简单的交流，吴主任对合天网安校园活动表示了充分的肯定，也希望借此机会能传播给同学们更多的网络安全知识。

  

![](../Images/603593a8bf1ec35520f5d5cc5d46b1bd.png)

  

活动开始后，合天智汇人气讲师首先进行了网安科普及漫谈，为同学们细致的讲解了网络安全主要表现形式，以及自身在使用电脑过程中如何防范风险，如何保障信息安全，预防网络诈骗。结合最新出现的漏洞问题与支付安全、WiFi安全等实际问题，为同学们讲解网络安全行业的现状。同时强调学习网安知识技能是以维护网络安全为目的，正确利用技能提高自身水平，切勿将其利用在违法犯罪的事情上。让同学对信息安全知识有更直观的了解及对行业未来的发展有一个正确的认识。

  

![](../Images/f70d389a8700a6b10afc0034b006dc75.png)

  

网络安全知识分享结束后，讲师接着跟大家分享如何更好地学习网安，结合网安岗位切实的给同学们介绍从入门到进阶应该学习哪些课程。老师在介绍完学习课程之后，也介绍了一些热门赛事，通过赛事更清晰的同学分析网安所需要掌握的技能。

  

![](../Images/ca5469a1eb8619d0b78f94771efc8070.png)

  

接着为同学们介绍了诸多的知识竞赛活动和公司独特的的MOOC＋MOOE培养模式，解析目前网络安全的优越性以及公司的一大特色——网络实验室，运用线上开放实验同学们可以在任何时间、任何地点进行不受时空限制的信息安全知识学习和实验。实验内容多种多样，包括 Web 应用安全、逆向分析、计算机病毒、安全协议、防火墙、网络攻击与对抗等等上百个实验。

  

![](../Images/8d5744da37759280522e5c8f5eccb02d.png)

  

最后根据现状，给同学们分析最为关心的网安行业就业形势。从现今人才需求与人才输出的比率严重失衡到专业性人才的欠缺等多个方面进行了阐述，提出培养高素质岗位实用人才迫在眉睫。为同学们以后的学习及就业提供了一个方向。

  

![](../Images/43f5a9dd8ef4543ccb05e590b4133af1.png)

  

合天网安校园行能够得到众多同学的喜爱，不仅仅只是分享有用的内容，抽奖互动更是其乐无穷。为了获得合天带去的礼品，同学们激动的呼喊声可谓是此起彼伏，热闹非凡。

  

合天网安校园行此次时间虽然不长，但是能够给同学们在以后学习网安的道路上提供一点帮助，合天智汇就感到满足。期待着再一次的相见，也希望未来能有更多机会进行学术及技术交流。
