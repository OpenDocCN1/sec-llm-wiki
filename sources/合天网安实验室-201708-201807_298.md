# 第145站合天网安见面会之湖南理工学院圆满落幕

岳阳楼上、洞庭湖中、汨罗江边，每每提及湖南岳阳，浮现的词汇大抵是这些，我们往往对有着悠久历史文化的城市有着崇敬之情，对这一历史文化深深的敬畏，今天合天网安见面会在众多期盼声中来到了这座城市，与湖南理工学院百名学子展开了网安分享交流。

![](../Images/7c8a8f064a4b8dd5e1312ed40c4653f9.png)

合天网安校园行旨在促进我国网络安全领域人才培养，响应“中国网络空间安全协会人才与教育分会”号召，为网络安全事业贡献一份力量。本次活动除了有我们的人气讲师合天GG之外，合天高级安全咨询顾问小安老师也加入其中，强强联手又会碰撞出什么精彩的火花，让我们拭目以待。

![](../Images/7887fc0928f123398f883b661ea67cce.png)

本次活动分为两个部分进行，首先第一部分是咱们合天GG的网安知识show，网络安全知识的普及是引领同学们认识网络安全的第一步；合天GG讲到，随着电子智能设备的广泛使用，对无线网络的依赖也随之加深，在尽情享受网络给我们生活带来方便快捷的快感的同时，维护自身信息安全就容易被忽视 为加深同学们对此类网安知识的认知 合天GG通过演示公司绵羊墙产品 给同学们带来更直观的体验。

![](../Images/7f7683de5710c0ca12a8348fe91b988f.png)

合天网安实验室是国内大型MOOE实验网站，合天GG介绍到，运用线上开放实验 同学们可以在任何时间、任何地点进行不受时空限制的信息安全知识学习和实验。实验内容多种多样，包括 Web 应用安全、逆向分析、计算机病毒、安全协议、防火墙、网络攻击与对抗等等上百个实验。合天GG也强调学习网安知识技能是以维护网络安全为目的，正确利用技能提高自身水平，切勿将其利用在违法犯罪的事情上。

![](../Images/3b2ae953e24099b7891a846a4b9a7d2f.png)

进入到活动的第二部分，学习网络安全，除了维护自身网络信息安全助力网络安全事业，更重要的是掌握技能为今后的学习以及工作打下坚实的基础，小安老师为同学们展示了网络安全就业的现状及市场情况，从现今人才需求与人才输出的比率严重失衡到专业性人才的欠缺等多个方面进行了阐述，提出培养高素质岗位实用人才迫在眉睫，由此合天智汇推出WEB岗位培训，致力为广大学子提供技能学习的平台。

![](../Images/24454fc43e434ed11623fdad2fd05feb.png)

合天GG与小安老师的分享圆满结束，活动最后随机抽取了三名幸运儿送出了我们合天宝宝，在轻松愉悦的环境中结束了本次校园行活动。山水有相逢 期待合天网安见面会也期待着与湖南理工学院的再一次相见！
