# 合天智汇亮相2017教育部产学合作协同育人项目对接会

11月9日-10日，2017教育部产学合作协同育人项目对接会在北京盛大召开。本次会议在教育部高教司指导下，由产学合作协同育人项目专家组主办，共吸引了来自全国高校、企业的代表1800余人与会并进行对接交流。

![](../Images/c15fec2f717e0f3687959936dc4af2ea.png)

  

党的十九大吹响了建设教育强国，加快推进教育现代化的集结号，产学合作项目对接会围绕高等教育发展战略、新兴产业发展趋势及技术方向、产学合作项目规范展开了深入探讨。教育部高教司吴岩司长，工信部信息化和软件服务业司副司长任利华，产学合作协同育人项目专家组组长、哈尔滨工业大学副校长徐晓飞教授等领导、专家在会议上做了精彩讲话，本次会议由教育部高教司理工处吴爱华处长主持。

![](../Images/d8ba8656d31a4729fcf0c612f5c2fae5.png)

  

为贯彻落实《国务院办公厅关于深化高等学校创新创业教育改革的实施意见》（国办发〔2015〕36号）文件精神，“合天智汇产学合作协同育人项目” 深入配合高校网络安全人才体系建设，面向全国高校网络信息安全及计算机相关专业，建设内容包括“教学内容和课程体系改革”与“实践条件建设”两个大类各50个项目，支持高校专业综合改革和创新创业教育，协助高校完善专业人才培养体系。

![](../Images/7d894a407820aa47594c26241844cb50.png)

  

在10号上午的项目对接分会场，合天智汇相关负责人为现场的老师详细介绍了合天智汇产学合作协同育人项目。

![](../Images/b7e904d6051ca6699c36e67b7721dd61.png)![](../Images/ae15c3c5432aada5f5be2a58430fa65c.png)

  

**在线实验课程开发与定制**

该项目面向全国本专科院校网络空间安全、计算机科学与技术、信息与计算科学、信息科学与工程、软件工程、信息安全等相关专业的优秀教师，推出以网络信息安全为主要技术方向的在线实验课程资源建设项目,通过对高校的在线实验课程开发与定制，打造一批优秀、精品课程，加快高校网络安全人才体系建设。

  

申报项目经过评审后，合天智汇将给予每项3万元经费支持，总金额共计150万元。通过在线实验+教师视频+实验指导书的方式，支持高校教学，课程定制等。帮助教师建设紧贴技术前沿和产业人才需求的网络信息安全课程，助力高校快速灵活地构建网络信息安全课程体系，培养适合国家需求的网络空间安全人才。

 

**高校联合实验室**

该项目共计50项，合天智汇为每所立项高校提供价值30万元的支持，通过建设面向网络与信息安全教学与科研实验的网络安全实验室，高校可以快速建立各种场景的网络与信息安全测试环境，展开相关的网络与信息安全攻防实验；同时基于平台提供过程监控工具，可以对所进行的实验教学结果进行分析评估。

  

合天智汇与高校共建的联合实验室将支持100套以上实验环境的一键创建和销毁；含不少于60个信安比赛类型实训实验，不少于40个常见网络安全工具实训实验；提供大规模在线实验服务的能力，支持100人以上教学班同时操作。

 

合天智汇产学合作协同育人项目希望为各个高校的网安人才培养体系建设提供大力支撑，同时进一步与高校开展校企深度合作，加强网络信息安全学科专业建设，打造经验丰富的网安教学队伍，加强与学校在培养目标、课程设置、教材编制、实践教学、课题研究等方面的合作，帮助学校改革人才培养模式、提升教学水平，深化创新创业教育改革，从而提高学校自身竞争力，进一步跻身国家一流、世界一流行列。

 

欢迎各个高校申请合天智汇产学合作协同育人项目，项目申请人需在11月30日前提交由学校或院校加盖公章的申请书（电子版）， 12月合天智汇将组织专家对申报项目进行评审并立项。
