# 合天智汇受邀参加中南林业科技大学涉外学院就业宣讲会！

随着计算机技术的飞速发展，信息网络已经成为社会发展的重要保证；很多敏感信息或是国家机密，难免会吸引来自世界各地的各种人为攻击。与此同时，信息安全人才缺口大，网安人才培养工作迫在眉睫。2017年 10月25日，合天智汇受邀来到中南林业科技大学涉外学院，就网络信息安全与人才培养为话题和同学们进行了深刻的沟通与交流。

![](../Images/bbd9b710b57ecfc4503aaeb3dac755af.png)

  

首先合天资深讲师彭文韬为同学们介绍了信息安全专业行业趋势、岗位需求等内容，让学生对网络空间安全领域有了全面了解。在介绍信息安全行业趋势时，彭文韬老师强调：因为信息安全人才需求量大，就业缺口大，保障网络空间安全已然成为国家战略重点和核心利益。“网络空间的竞争，归根结底是人才的竞争。”截至2017年，我国网络安全专业人才缺口达70万，每年递增1.5万人，各大公司对网络安全人才求贤若渴，而高校的人才如何能更好的对接企业，却也成了高校的一大难题。

![](../Images/1a3ba4079a44d69b3275ddbd09c2cd6e.png)

  

如何才能成为市场需要的人才？彭老师强调：那就是充分利用好一根线，一根链接知识仓库的线，那就是网络。在这条线的一段连接着MOOE的高效学习方法，而合天，作为“ MOOE”的开创者，从用人单位需求为出发点，对准岗位开设课程，让同学可以针对性的去学习，实际操作，提升岗位技能。彭老师也鼓励大家去合天网安实验室学习，为今后就业打下良好的基础！

![](../Images/c080c16ef573ab5e5c95ba7b42559997.png)

  

同时，彭老师介绍到：为更好的帮助高校毕业生就业，合天智汇在合天网安实验室学习、培训平台的基础上，2017年推出了面向广大高校网安学生，提供实习、实训、人才推荐等服务。目前合天智汇为业界数百家企事业单位保持人才推荐联系,合天智汇作为连接企事业单位和高校毕业及实习生之间的桥梁，以期实现网安人才和企业之间的精准快速对接。

![](../Images/284c6f24cb9551ec48ac97384dae2516.png)

  

活动最后，彭老师也祝福了在场的所有同学，希望他们能明确自己的学习目标和就业方向，最后走出一条属于他们的阳光大道!

  
合天智汇也在此祝福所有的同学都怀着梦想出发，最终实现梦想！
