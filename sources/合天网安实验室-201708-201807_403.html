陕西工商职业学院合粉俱乐部正式成立了！

陕西工商职业学院合粉俱乐部依托校内智能与信息学院原有的计算机协会成立。协会里的小伙伴对于网络安全均有着的浓厚兴趣，却因校内开设的信息安全课程较少且不是很专业，一直以来无法更深入层次的学习网络安全，始终徘徊在网络安全殿堂的大门之外。合天网安给予陕西工商学子这样一个深造学习的机会，共同努力去探索网络安全这条充满挑战的道路。

梦的尽头叫做闯。只要敢想敢做，我们坚信我们一定会成功！！！


学习标语：There is no absolute security system



俱乐部学习计划：

  1. 主要是朝着web安全组、移动安全组、Linux运维组等方向去努力学习发展。

  2. 在组建学习兴趣小组的过程中因材施教，因趣而学。首先学习学校的基础课程体系来加强理解基础概念的思维模型。

  3. 然后在校内授课老师和合天网安的指导下一步步深入学习网络安全模块。通过合天网安分类型的实验来让大家轻松有趣地进入到网络安全的海洋中尽情遨游。

  4. 此后会定期组织开展线下知识分享&经验交流沙龙会议和CTF信息安全对抗赛来一起提高大家的学习能力。


扩大俱乐部、增加其影响力吸引更多有着共同喜好的同学加入；同时在以合天为主的合作伙伴的技术支持下不断提高俱乐部的整体技术水平。
