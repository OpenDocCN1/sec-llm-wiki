# 合粉俱乐部家族欢迎北京理工大学

北京理工大学合粉俱乐部依托于软件学院学生创新基地的信息安全实验室，初期成员均为实验室成员，都对信息安全有着极大的兴趣，大家在信息安全方面的学习基本上都是从合天网安实验室上面的实验开始的。

![](../Images/745ea9a018c0bbf98c49df6112d96376.png)

  

以原来的实验室为基础，北京理工大学合粉俱乐部将分为WEB安全、二进制安全、Linux、密码学等不同方向，并鼓励俱乐部成员探索其它目前实验室未探索的方向，如物联网安全等。

  

俱乐部成立后，俱乐部成员的学习将分为线上学习、线下培训和线上比赛三部分，

*   线上学习包括合天网安实验室丰富的课程资源，以及北京理工大学软件学院信息安全实验室已有的CTF训练平台；
    
      
    
*    线下培训则将安排俱乐部内的优秀成员给其他成员讲授各个研究方向的基础知识以及介绍CTF比赛中的一些技巧；
    
      
    
*   在比赛方面，北京理工大学合粉俱乐部将组织俱乐部成员一起参加如X-NUCA、XCTF等各种国内信息安全竞赛，此外，以实验室的CTF训练平台为基础，俱乐部将不定期举办校内的CTF训练赛，为本校所有对信息安全感兴趣的同学提供实战练习的机会。
    

  

北京理工大学合粉俱乐部欢迎所有对信息安全感兴趣的同学过来一起学习，更欢迎那些在研究新方向的同(da)学(lao)过来为俱乐部拓展新的方向（如硬黑客）。
