# 第128站合天网安见面会之安阳工学院完美落幕

“惊世惊天龟甲片，神奇神秘卜辞骨。” 甲骨文上承原始刻绘符号，下启青铜铭文，是汉字发展的关键形态，让无数的文人为之折腰。合天网安见面会的第128站就来到了甲骨文的故乡——安阳，来到了文化底蕴深厚的安阳工学院，与学校一群热情四溢，聪明好学的同学开启了一场自由而又深度的分享交流讲座。

  

![](../Images/671300efb5138178ed9df5a9932ead24.png)

![](../Images/22ae27c03d2d5d0205315e77881ecc12.png)

  

在活动开始前，合天GG被安阳工学院合粉俱乐部的同学们拉到实验室里，要求给他们开个小灶，专门辅导一下他们平时学习遇到的问题。比如大家在实验室做实验过程中遇到的知识理解以及操作问题，比赛过程中解题方法和技巧等，合天GG对此都详细的给大家做了讲解，也赢得了同学们的一致好评。

  

![](../Images/2bc4737d4e99b948ab099be045dafe2a.png)

  

活动正式开始后， 合天GG主要通过以下几个部分进行了分享：第一部分从最近半年漏洞新增情况为大家揭开网安目前的情况，其中合天GG通过演示一些智能设备（如摄像头）被入侵的过程，让大家对此加深认识和理解，感受目前网络安全领域的情况；

 

第二部分从合天智汇承办过的一些大型赛事，如XP挑战赛、网安中国行，X-NCUA（全国高校网安联赛）、湖湘杯等，为大家讲解不同赛事的区别，参赛选手的水平，以及一些经典题目的讲解和演示；

  

![](../Images/1bd09fcc9d7956d5a8cd0ab4e511a5dd.png)

  

第三部分是为大家讲解如何在合天网安实验室中正确的学习，怎么样才能充分利用网站的优势资源提高自身技能。最后合天GG着重强调了网络安全相关的法律法规，告诫同学们千万不要以身犯险，存在任何的侥幸心理，学习网络安全是为了维护这个领域的安全，而不是为了自身的利益做违法的事情。

 

此次分享交流会进行了两个多小时，大家也在最后畅所欲言，发表自己对网络安全的感受，同时也对合天GG的演讲给予的高度的赞赏。

 

最后晒出一波好评\~~~

  

![](../Images/a6e839a09d5049d85e007a15dc887b9e.png)
