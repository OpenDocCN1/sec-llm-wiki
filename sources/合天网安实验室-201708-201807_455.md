# 立足开放环境 在实践中求真知

“安全‘是开放的而不是封闭的’，只有立足开放环境，在实践中不断进取，网络安全能力才会不断提高。”这是中国工程院院士、中国网络空间安全协会理事长方滨兴院士在“2017年国家网络安全宣传周网络安全技术高峰论坛”发言中的开篇之词。

![](../Images/9ff01ffba9496a90e1c440b405ab5e75.png)

  

9月18日，由中央网信办和上海市人民政府指导、上海网信办主办、中国网络空间安全协会承办的“2017年网络安全技术高峰论坛”主论坛在上海国家会展中心举行。方滨兴院士在本次论坛上作了《从“六论”视角论网络空间安全观念》的主题报告，从实践论、相对论、进化论、认识论、方法论、矛盾论六个视角提出了网络空间安全观念的“六论”。在提到实践论时，方滨兴院士对合天网安实验室的大规模开放在线实验表示高度认可，并强调，只有在实践中不断进取，网络安全能力才会不断提高。

“网络空间安全是实践论。”如方滨兴院士所说，合天网安实验室正是一个面向信息安全领域学习爱好者、从业人员的学习实践平台。

合天网安实验室采用软硬一体模式，可以私有云方式安装部署在指定网络中。实验室不仅支持信息安全概论、网络安全检测与防范技术、防火墙技术、病毒机制与防护技术、密码学等安全课程教学，还支持面向渗透测试工程师、Web安全工程师、网络安全工程师、系统安全工程师、安全开发工程师等岗位教学。同时为广大网络信息安全爱好者提供了针对最新网络攻防技术，热点网络安全事件，以及安全意识教育的课程教学。

合天网安实验室能快速，准确，大批量构建出适合各种学习用的信息安全、网络攻防的虚拟实验环境。同时为了增加学习过程的趣味性和通俗性，还提供了除虚拟实验环境以外的，其他各种课件资源，如视频、动画、文档、工具软件、文章等。另外实验室还在私有云里提供了社区服务，来增强互动性和共享性，为网络安全爱好者打造一个积极向上的网安学习圈子。

![](../Images/ac5e8b608d675b7798262673548b7103.png)

合天智汇作为专业的“网络安全人才培养服务提供商”，将继续以国家网安人才培养需求为导向，以网安实战技能提升为目标，从用人单位网安相关岗位技能需求出发，在网安教学、实习实训与教学科研等关键人才培养环节，通过“线上+线下、理论+实践”的方式，与全国高校深入开展校企合作，联合育人。合天智汇将协助高校完善专业人才培养体系，提升网安专业学生实战技能水平，推出满足企业用人需求的“网络安全人才培养实践方案”，并通过其广泛的合作企业进行优秀网安毕业生推荐，从而打通网络安全人才培养的最后一公里，为国家网络安全事业贡献力量。
