# 合粉俱乐部家族欢迎浙江师范大学

![](../Images/b1b605d32cd7a208d33484ce3e0a8993.png)俱乐部是依托浙江师范大学CTF集训队成立的，团队由十多名多名来自本校计算机系相关专业的学子组成，成员之间相互之间团结友爱，互相帮助，一起在网安学习的道路上共同进步。  
![](../Images/ed8b5b626f89574902bafe39e4d4cd41.png)

  

**学习计划**

1、对现有成员分成WEB、逆向、PWN几个学习小组，对各自方向进行深入学习，并定期组织培训，交流分享知识点；

2、结合过往的参赛经验，组织俱乐部成员进入合天网安平台进行实战学习；

3、组织成员参与线上比赛，对参与的每一场比赛结合解题报告进行总结和补充知识点；

4、俱乐部成员定期在各大CTF练习平台上刷题，在确保数量的同时，要求成员书写解题报告或者学习的知识点，确保刷题的质量。

5、充分利用合天平台资源，学习新的知识和利用实验平台模拟实战巩固知识点。
