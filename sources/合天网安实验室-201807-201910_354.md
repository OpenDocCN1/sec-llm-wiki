# 存储型XSS漏洞验证过程：

在评论的称呼中写入

test</textarea><script>alert(1)</script>

![](../Images/f4c6b46ad3532e2d280bcd38f6194b2d.png)

  

提交发表，发现已经弹窗执行了脚本（在此之前并没有注入xss脚本）；

![](../Images/eeaab872dafc762686c4094f2d71663e.png)

  

登录后台：

![](../Images/23c2b04d7d00dad17398e7f6f6be85cf.png)

在后台管理界面，点击评论管理可以看到代码也已经执行：

![](../Images/b37b8255043f2ae90e21d414273f75d2.png)

  

所以，存在存储型xss漏洞；

# 漏洞分析

查看源代码：

![](../Images/65682af0e0d3163ee0059a5c53e3b5e5.png)
