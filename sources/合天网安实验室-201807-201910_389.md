# 合天智汇助力南昌大学2018 “护网杯”竞赛培训

10月19日，湖南合天智汇受邀来到南昌大学，给南昌大学信息工程学院参加2018“护网杯”竞赛的同学们进行赛前培训。本次培训为期3天，湖南合天智汇共有3名安全专家参与此次培训，为同学们带来了CTF实战培训。

![](../Images/ef308d030a3b0584faad99ff47976eac.png)

![](../Images/1d1ff8206eea670fed0dabac233a5baa.png)

培训现场

合天智汇多次为业内赛事提供专业可靠的技术保障，对于CTF赛制充分了解，拥有丰富的安全从业人员培训经验，师资雄厚，更有合天网安实验室、合天攻防演练系统、合天网安竞赛系统三大平台支撑。在培训课程的安排上，合天的安全专家针对此次比赛，结合同学们的专业知识，调整打磨出最为合适的课程，在3天时间内将对同学们进行专业系统的强化训练，帮助参赛同学充分提升专业知识水平。

培训内容包括CTF常见工具的介绍使用，同时以注重实战的深入分析CTF竞赛的技术知识点，对逆向、加密、网站等技术应用原理进行深入分析讲解。希望通过此次系统的赛前培训，同学们能增强实践能力和操作技能，并在此预祝同学们在10月25日开展的决赛中取得好成绩。

![](../Images/6a87ddb7892f212fadb035eda812e4a8.png)

培训现场沟通指导

在维护国家网络安全、建设网络强国的要求下，身为国内信息安全领域的领军企业，合天智汇一直肩负着为信息安全行业人才培养的重任，专注网络空间安全实用型人才培养。
