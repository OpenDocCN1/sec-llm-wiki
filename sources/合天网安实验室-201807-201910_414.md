# 第157站合天网安见面会之北京工业大学圆满落幕

9月，学子们回归校园，与众多学子一样，合天网安见面会在这个9月再次回到大众视野；我们始终坚持将网络安全知识带去各大高校，本次的北京之行也不例外，合天讲师与学生们交流网安知识，带领学子们探索网络安全的世界。

与北京工业大学的缘分亦是相当深厚，在2016年及2017年便已开展多场网安见面会；而此次北工大之行，更多的感觉像是与旧友重逢。

![](../Images/0c592d324c8e0e1dec70de085c9f31ee.png)

合天网安知识分享开始，合天讲师通过一系列热点事件展示分享，让同学们了解网安的世界；树立网络安全意识，掌握网络安全基础知识，做合格的新时代网安强国建设者。同学们刚刚进入大学校园，应积极把握学习机会，充实自我；合天讲师给同学们分享到，网络安全的供需情况以及网络安全人才岗位的设置情况，网络安全人才和计算机人才的关系；只有具备扎实的网络安全知识与实操技能，才能满足社会的需要以及相关用人单位需求。

![](../Images/57b2cc13991f2afa27f0392b7b291061.png)

勿以恶小而为之，这句话在网络安全领域中一定要严肃对待，随着网络安全法的颁布，国家对网络安全的重视，任何一件损害他人的违法之事都逃脱不了法律的制裁。合天讲师也告诫同学们千万不要让好奇心害了自己，不要拿自己学到的技术随便试刀。不要从入门到入狱。
