**渗透测试-实习生**（2k，转正后3K-8K） 

  

**岗位职责**

1、挖掘 WEB 程序中的安全漏洞，并提出加固建议 ； 2、主要负责等级保护、风险评估项目主机、 应用安全检查、漏洞扫描和渗透测试等工作；

3、对工具扫描结果进行人工验证并编写报告；

4、跟踪国内外信息安全动态，进行安全攻防研究 ； 5、等级保护、风险评估项目的实施工作；

6、在项目实施阶段为用户提供技术培训；

  

**任职要求**

1、计算机相关专业本专科（含）以上学历； 2、对主流操作系统和网络应用的漏洞和弱点 有深入了解和研究；

 3、熟悉常见的 WEB 漏洞攻击方法：sql 注入、 xss、文件上传、文件包含、命令执行等漏洞；

 4、熟悉渗透测试的步骤、方法、流程、熟练 掌握各种渗透测试工具，熟悉常见脚本语言 和数据库，熟悉 web 应用，具备 WEB 渗透技 能，恶意代码检测和分析能力；

 5、熟悉常见的WEB漏洞防范方法与安全审计， 熟悉常用网络协议，熟悉 windows、apache、 Oracle、mysql、php 等安全配置与安全检查；

 6、有过渗透测试经验，有独立渗透测试项目 经验，能够手工检测漏洞、验证漏洞； 

7、分析问题和实际动手能力强，具备一定的 文 档 撰 写 能 力 和 表达能力 ； 

8、具有良好的品质和道德，良好的沟通能力 和团队协作精神，能适应湖南省内出差； 

9、掌握一种或几种脚本语言，能编写脚本或 者相关安全工具者优先；
