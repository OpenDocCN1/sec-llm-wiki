我们的目标很简单，如何从这些式子得到答案

cdcd

首先根据

m≡cd mod nm≡cd mod n

因为

m=cd+k∗nm=cd+k∗n

n=p∗qn=p∗q

m=cd+p∗q∗km=cd+p∗q∗k

为什么kpq没了,因为这是p或者q的倍数呀~然后我们继续由式1可以得到

def decrypt(dp,dq,p,q,c):

    InvQ = gmpy2.invert(q, p)

    mp = pow(c, dp, p)

    mq = pow(c, dq, q)

    m = (((mp-mq)*InvQ) % p)*q+mq

    print libnum.n2s(m)
