联立公式$1 \\times q$和公式$2 \\times k(p-1)$，可以得到公式

$$ed\_0q = q + kq(p-1)(qr-s+1) \\tag{3}$$

$$k(p-1)qr = kq(p-1)(s-q) \\tag{4}$$

相加得到：

$$ed\_0q + k(p-1)qr = q+kq(p-1)(qr-q+1)$$

即：

$$ed\_0q + k(p-1)qr-k(p-1)q(qr-q+1) = q \\mod 2^{kbits}$$

解上述同余方程，即可得到$q \\mod 2^{kbits}$
