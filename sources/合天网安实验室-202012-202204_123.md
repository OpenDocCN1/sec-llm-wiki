##### Windows Server 2019 Install SQL Server 2016

#####   

##### 准备工作

操作系统：Windows Server 2019 标准版

下载SQL Server 2016 安装文件

下载SQL Managerment Studio

#####   

##### 开始安装

双击 `setup.ext`，启动`SQL Server 安装中心   `

  

![](../Images/52a076c29d21f9b83b596caba8911c99.png)

  

选择`安装`，然后在右侧选择`全新SQL Server独立安装或向现有安装添加功能   `

  

![](../Images/0445fda3331fbdc6f46c84ddbc2152cc.png)

  

在弹出的安装对话框中，选择要安装的版本，这里以`Express`版本为例  

  

![](../Images/b4ec1425197e0ba53b767a86c5f7898d.png)

  

点击下一步，勾选`我接受许可条款`，然后点击下一步  

  

![](../Images/a8c4637607d952f277a5bf168a185673.png)

  

是否勾选`使用Microsoft Update检查更新(推荐)`，这里我们不选择。直接点下一步  

  

![](../Images/93db58ed73b7c5dc052313899560ae61.png)

  

进入`产品更新`步骤，保持默认，然后点击下一步  

  

![](../Images/2364d45c429f5bcbc39aca693e1a32f1.png)

  

等待"安装程序文件"安装完成  

  

![](../Images/3fd6a23d811158742a25c8e80c9b73e6.png)

  

安装规则步骤会检查一些项目，如果未通过无法进行后续的步骤，然后点下一步  

  

![](../Images/42aea182a67a6d58ff9786c3a30aedfa.png)

#####   

##### 功能选择

勾选`数据库引擎服务-SQL Server 复制`，`共享功能-客户端工具连接、SQL客户端连接SDK`，目录保持默认，然后点击下一步。  

  

![](../Images/c95acd9fa09b0606bab4c01252a70149.png)

#####   

##### 实例配置

指定`SQL Server`实例的名称和实例`ID`。目录结构、注册表结构和服务名称都会复制实例名称和特定的实例ID。实例ID将成为安装路径的一部分。

在`命名实例`中输入 实例名，在`实例ID`中输入实例ID，这里可以保持默认，如果存在已有实例，请注意不要重名。

然后点击下一步。  

  

![](../Images/15a0fc858d0b0e27d8201b1a416c2d84.png)

  

进入服务器配置，设置`服务帐户`和`排序规则`。`Microsoft`建议您对每个`SQL Server`服务使用单独的帐户。选择`SQL Server数据库引擎`和`SQL Server Browser`类型位`自动`。你可以根据需求选择`AQL Server Browser`的启动类型。

然后点击下一步  

  

![](../Images/a8e83dfb76781a0101c50476085b98cf.png)

#####   

##### 数据库引擎配置

为数据库引擎指定身份验证模式和管理员

默认情况下，`MS SQL`的管理员名称是`sa`

在`身份验证模式`中选择`混合模式（SQL Server身份验证和Windows身份验证）`，然后设置一个密码  

  

![](../Images/0063a19b7e34785e7f10136a4388a72b.png)

  

在`指定SQL Server管理员`，点击`添加当前用户`，可以把当前用户加入SQL Server管理员  

  

![](../Images/55565b96014e9a8b62b781db34cd827c.png)

  

然后点击下一步，可以看到一个安装配置清单，如有需要修改的，可以点上一步进行修改，确定无误后点击`安装`进行安装。  

  

![](../Images/213cf041facf8493e3bf25dda713f752.png)

  

等待安装完成  

  

![](../Images/aa1dc305ed631a892b5f0a8e1c51cf8e.png)

  

完成安装，点`关闭` 退出安装向导  

  

![](../Images/f950c83d1dce9ca7557259e519a028c5.png)

#####   

##### 启用端口监听

  

打开`SQL Server 2016 配置管理器`

![](../Images/372eecedb82524c24b73fa880b2f5504.png)

  

打开`SQL Server 网络配置-->SQLEXPRESS协议`，在右侧的`TCP/IP`上右键，选择`属性   `

  

![](../Images/8850aba88c439cf7923280ef37b121b8.png)

  

在`TCP/IP属性`对话框的`IP地址`选项卡中，设置 TCP Port 端口为`1433`，然后点击`应用`。  

  

![](../Images/80226b4fd037b54a7639001f2aaf7750.png)

  

然后右键启用`TCP/IP   `

  

![](../Images/3139dde933561d44b6bbd93cef1b0852.png)

#####   

##### 安装配置 SQL Management Studio

打开`SQL Server Managerment Studio`的安装程序

按需设置安装目录，然后点`安装   `

  

![](../Images/795486a6bd4fba093aac806d752b8dd8.png)

  

等待安装完成  

  

![](../Images/b28b2d94c04ded91a72a5e3368c1ad03.png)

  

安装完成提示要重启，我们点击重启  

  

![](../Images/28bf9d8cd26ca3815b0e56909bf736e5.png)

  

打开`SSMS`工具  

  

![](../Images/db1bb2cfcd5ed3521234980bb7b5ff15.png)

  

输入管理员凭据登录到`SQL Server`，点击`连接   `

  

![](../Images/2ef84e9fc00ecfa40abb463919aa2bf0.png)

  

在实例上右键，然后选择`Facets   `

![](../Images/45de360ad4954d83a27448a5051fba40.png)

  

在常规中，方面选择`外围应用配置器`，找到`XPCmdShellEnabled`属性，设置为`True`，然后点击确定  

  

![](../Images/903bd1a76a6c581bd8aa4b07fadc4f21.png)

######   

###### 新建用户

在`安全性--登录名`右键，选择`新建登录名   `

  

![](../Images/8612a93a39d7711c092a13303449c1ce.png)

  

设置登录名，设置密码，设置数据库，然后点确定  

  

![](../Images/045fe3e0c6ba57fb0579f086e09509ed.png)

#####   

##### SQL 客户端连接SQL Server

HeidiSQL是一个自由开源的数据库管理工具，用于MySQL及其分支，以及Microsoft SQL Server和PostgreSQL。

下载地址：https://www.heidisql.com/download.php

打开`heidisql`，新建连接  

  

![](../Images/6512d678f4d9d962c95b527414309e04.png)

  

选择 SQL Server TCP/IP ，输入服务器的ip地址、用户名和密码，然后点`打开   `

  

![](../Images/ac66bb5ba7d3ae75c266b223eebde13a.png)

  

![](../Images/c47d6efdbae3eedf80c24214e6e2c8d0.png)

  

如果连不上，可以在服务端执行以下`powershell`命令放行`1433`端口流量

*   
*   

```
New-NetFirewallRule -DisplayName "SQLServer default instance" -Direction Inbound -LocalPort 1433 -Protocol TCP -Action AllowNew-NetFirewallRule -DisplayName "SQLServer Browser service" -Direction Inbound -LocalPort 1434 -Protocol UDP -Action Allow
```
