```


漏洞产生的原因是因为 Spring 与 Shiro 之间对 url 的处理不同从而导致权限绕过即：Shiro权限配置必须为 /xxxx/\* ，同时后端逻辑必须是 /xxx/{variable} 且 variable 的类型必须是 String

环境搭建参考参考文章漏洞原理：利用shiro在做匹配的时候，如果是e0mlja/\*格式，则只会匹配e0mlja目录下，如果再加一层目录可绕过匹配，如e0mlja/123/123就绕过了e0mlja/\*对123的匹配。也可以利用;取到;之前的链接进行绕过。看看效果
```
