# 概述:

线性反馈移位寄存器（LFSR）归属于移位寄存器（FSR）,除此之外还有非线性移位寄存器（NFSR）。移位寄存器是流密码产生密钥流的一个主要组成部分。上一个n级反馈移位寄存器由n个二元存储器与一个反馈函数组成，如下图所示。

![](../Images/a20784a1a0872860d9fd907379304a98.png)

  
移位寄存器的三要素：

*   初始状态：由用户确定
*   反馈函数：是n元布尔函数，即函数的自变量和因变量只取0和1这两个可能值
*   输出序列

如果反馈函数是线性的，那么我们称其为 LFSR,如下图所示：

![](../Images/f52cdf75afcbbb38dbab51fdd9f54735.png)

  
LFSR的输出序列{  }满足:

*   
*   
*   .....
*   (i = 1,2,3,...)

举例：下面是一个5级的线性反馈移位寄存器，其初始状态为

![](../Images/940ef3e3078f090c1310613776258988.png)

反馈函数为：，(i = 1,2,...) 可以得到输出序列为：1001101001000010101110110001111 100110…周期为31。

> 对于 n 级线性反馈移位寄存器，最长周期为（排除全零）。达到最长周期的序列一般称为 m 序列
