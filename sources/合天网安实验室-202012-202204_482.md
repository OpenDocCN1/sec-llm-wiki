# 2021年网络安全高级研修班圆满结束

2021年1月，由中国网络空间安全人才教育论坛指导，湖南蚁景科技有限公司、湖南合天智汇信息技术有限公司、湖南会览网安教育服务有限公司主办的2021年网络安全高级研修班顺利举行，线上与线下课程同时开展；来自全国各高校的数十位骨干教师参与其中。

  

为保障本次研修班的顺利进行，开班前，主办方从教学安排、师资配备、后勤保障以及组织管理等诸多方面做了精心策划与安排。

![](../Images/1c4141d573f6da5d2612fa2d2afbb13c.png)

  

研修班为期8天，课程围绕“渗透测试”与“Web安全”展开，针对高校教师授课的重点、难点，我司资深网安工程师“理论”+“实践”双管齐下，给到参会教师切实有效的技能提升帮助。不同方向，不同专业领域的资深讲师齐聚此次研修班；从专业角度出发，为参会教师精心准备课程讲解。  
每节课配套靶场实验实操，保证每项内容实操落地！

近年来，各高校纷纷开设网安专业或者相关课程，网络安全的重要性得到高度肯定；加强专业师资队伍建设成为众多高校的紧要目标。我司凭借专业的研修班课程开展经验，圆满完成本次高校网络安全高级研修班；在此，感谢参会教师对我司的信任与支持。同时，期待着与更多高校教师探讨网络安全。
