# Joomla未授权访问漏洞(CVE-2023-23752)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTYxNjQxOA==&mid=2652895022&idx=1&sn=ea39e8efd0ac7bf98209cfdb68a6d759&chksm=bd598be38a2e02f5012a8ea6283db86947f1046e1aa6b1deb04b92cb27fc67ac3d39bdf28f98&scene=126&sessionid=1681573315#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTYxNjQxOA==&mid=2652895022&idx=1&sn=ea39e8efd0ac7bf98209cfdb68a6d759&chksm=bd598be38a2e02f5012a8ea6283db86947f1046e1aa6b1deb04b92cb27fc67ac3d39bdf28f98&scene=126&sessionid=1681573315#rd)

## 漏洞简介

　　![](../Images/5a76c19cd0351f560d148fd10aca64b3.png "null")

　　在 Joomla! 版本为4.0.0 到 4.2.7中发现了一个漏洞，在Joomla受影响的版本中由于对Web服务端点的访问限制不当，远程攻击者可以绕过安全限制获得Web应用程序敏感信息。

## 影响版本

　　4.0.0 <= Joomla <= 4.2.7

## 环境搭建

　　文件下载地址 https://downloads.joomla.org/cms/joomla4/4-2-7/Joomla\_4-2-7-Stable-Full\_Package.zip?format=zip

## 漏洞复现

　　构造路由 `/api/index.php/v1/config/application?public=true`

## 漏洞分析

　　经过调试分析发现是对 api 路径下的身份校验进行了绕过，默认在未登录的情况下访问 返回 `{"errors":[{"title":"Forbidden"}]}`
