## 前言 

Windows Installer 使用安装包，其中包含 Windows Installer 需要安装、卸载或修复产品以及运行安装程序用户界面 (UI) 的信息。每个安装包都包含一个.msi文件，该文件包含安装数据库、摘要信息流和安装的各个部分的数据流。

## 加载dll 

导出函数

```
extern "C" __declspec(dllexport) void DllRegisterServer(HWND hwnd, HINSTANCE hinst)
{NULL, "1", "DllRegisterServer"

, MB_OK);extern "C" __declspec(dllexport) void DllUnRegisterServer(HWND hwnd, HINSTANCE hinst)
{NULL, "2", "DllUnRegisterServer"

, MB_OK);
```

msiexec程序也可以加载DLL执行，前提是DLL文件在磁盘上存在并且是64位的。通过命令行调用DLL中的`DllRegisterServer`或`DllUnRegisterServer`

```


# DllUnRegisterServer
```
