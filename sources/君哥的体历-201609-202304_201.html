今天是第10期，20K-40K/月，16薪，Soul app 三大安全岗位开启招聘！简历速来！


公司介绍：

Soul App上线于2016年11月，是基于心灵的智能社交网络平台。用户可以在平台上善意平等地自我表达，发现可以深度交流的好友。

Soul App通过“智能匹配算法”一键推荐用户可能喜欢的人和内容，帮助用户随时随地和聊得来的朋友沟通交流，降低孤独感，提升每个人的生命质量，让个人更幸福，社会更加和谐美好。

Soul App打造了全新的线上社交体验，已有上亿的年轻人在Soul上分享生活和传达善意。


应用安全工程师

【岗位职责】

1. 负责soul相关产品的安全评估，代码审计，安全测试，漏洞应急响应等工作；
2. soul内部生产网络的安全测试及安全防护；
3. soul应用安全能力建设（SDL建设、安全培训、内部安全规范及流程制定等）；
4. 内部安全工具及安全组件的开发。

【任职要求】


1. 有应用安全建设及渗透测试、攻防、应急响应、代码审计等相关工作经历
2. 熟练掌握渗透测试的技巧及相关技术的基本知识，掌握安全测试涉及到的各种工具使用方法及原理;
3. 具备良好的沟通表达能力，有团队合作意识;
4. 熟练掌握漏洞原理，有过独立分析或挖掘漏洞的经验，有CTF经验或者src排名靠前者加分；
5. 精通一种或几种以下语言，JAVA/Python/Go/C++等，精通java加分。

【工作地点】北京中关村或者上海浦东
【薪资范围】20k-40k，16薪制（待遇视能力而定）
【招聘名额】1位


安全开发工程师

【岗位职责】

负责soul内部安全平台开发建设，包括不限于：soc（安全管理平台），漏洞扫描器，vms（漏洞管理平台）、waf、hids、统一认证平台等。


【任职要求】

1. 精通python、go、java、lua等其中一项或者多项，对应语言的主流框架有比较深入的理解和使用；
2. 熟悉了解安全开发、安全测试、漏洞检测等安全知识；
3. 熟悉elk、kafka、redis、rabbitmq、activemq等大数据处理框架，并能分析处理数据；
4. 善于独立思考，能够主动发现问题、分析问题，有系统化的问题分析能力和解决问题的能力，抽象能力强；
5. 有soc、扫描器、WAF、HIDS等开发经验、安全研发经验者优先；
6. 对安全感兴趣，了解常见Web攻击技术和漏洞原理者优先；
7. 具备良好的沟通表达能力，良好的团队合作意识和自驱力。

【工作地点】北京中关村或者上海浦东
【薪资范围】20k-40k，16薪制（待遇视能力而定）
【招聘名额】1位


安全合规专家

【岗位职责】

1. 对公司基础架构和业务平台的信息安全合规风险进行调研、梳理、评估；
2. 跟进数据安全、个人隐私、个人信息安全等国家、业界信息安全法规、政策，推进业务部门进行合规整改；
3. 负责ISO27001管理体系及信息安全等级保护体系建设及维护；
4. 协助信息安全制度的修订、宣导；
5. 负责制定数据安全相关规范并逐步落地。

【职位要求】

1. 本科及以上学历；
2. 熟悉信息安全项目的实施和管理；
3. 熟悉信息安全、数据安全、个人隐私保护等相关法律、标准和流程等；
4. 具有3-5年及以上甲方或者咨询机构工作背景优先；
5. 沟通能力强，推动能力强，富有团队协作精神；
6. 具有互联网数据安全、个人隐私保护经验优先。


【工作地点】北京中关村或者上海浦东（安全合规上海优先）
【薪资范围】20k-40k，16薪制（待遇视能力而定）
【招聘名额】1位
