# 一个有趣的问题

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MjQ1NTA4MA==&mid=2247484066&idx=1&sn=e1283d1fa3d75b2cc67fc40506172062&chksm=ea4ba8e5dd3c21f3727dcf7fdca338af335a47cd375565e95828f536ec8402774cc5997ba9cd&scene=126&sessionid=1681322346#rd](http://mp.weixin.qq.com/s?__biz=MzI2MjQ1NTA4MA==&mid=2247484066&idx=1&sn=e1283d1fa3d75b2cc67fc40506172062&chksm=ea4ba8e5dd3c21f3727dcf7fdca338af335a47cd375565e95828f536ec8402774cc5997ba9cd&scene=126&sessionid=1681322346#rd)

有一次中午吃饭完和boss散步，boss问我一个问题：聂君，你会的这点东西，新来的员工培训半年全会了，但年轻人比你能加班，要价是你一半。聂君啊，你怎么办啊？

  

面对这么难（挑）搞（衅）的问题，大家怎么回答啊？教教我。

  

我的回答很俗：知识可以短时间迅速提升，思维模式和经验不能。

  

我们也都年轻过，年轻就是：

  

1.  时间多，多的可以加班、通宵动手做实验，反复玩；
    
2.  好奇心重，什么新玩什么，不玩明白不下班，回家接着弄；
    
3.  不富裕，很穷，有墙裂的想赚钱的冲动。
    

  

可惜我们现在是中年人：

  

1.  有很多阅历了，什么都经历过一些，开始靠经验和思维模式工作和赚钱；
    
2.  身体不行了，加个班，通个宵，一周都缓不过来，就像病了一样；
    
3.  家庭杂事多，老人、小孩、亲戚朋友都找来了；
    
4.  分化明显，平庸的愈趋平庸并不断下滑，进入良性循环的走入发展快车道。没有中间态。
    

  

你要是和年轻人比拼身体和加班时间（如果说的这么直接，傻子都知道拼不过，但想想很多人还在不断的重复基础劳动工作，比如安装防火墙、配置别人定好的规则，这不就是比拼身体和加班时间吗？），那肯定是不行的。

  

就好比怎么配置juniper防火墙属于知识，很容易学会。但如何管理好防火墙规则（1、防火墙规则自动化配置、检查（比如发现违规配置、失效配置）；2、防火墙规则遵循的原则（比如除了源地址外，不允许出现any，长短连接问题..etc））就不太容易。

  

这就好比你具有开发一款和QQ一模一样的IM软件能力，但你无法开一家腾讯这样的公司。

  

很多朋友问：领导问我的动机是什么？我理解领导在点醒我吧。

  

我的表现是“本我”，没有做出“超我”的业绩。本来我是个掏粪工（本我），偏要让我做音乐家（超我），我只能努力努力再努力，可能模样会有点像，但终究要回归本我。所以大boss管理员工，是识别员工现阶段的表现是本我，还是超我，如果是本我，就要加大鞭策，如果是超我就要降低压力，否则会出事的（比如跳楼、抑郁）。他可能觉得我现阶段的表现是“本我”。哎，我忘记和他说那已经是“超我”了。

  

扯淡扯的太远了，大家谈安全吧。
