*   
*   
*   

```
move-result v0    if-eqz v0, :cond_0    const-string v0, "this phone is root! can not use odn!"
```

首先是move移动返回值V0,这里如果eqz,v0=cond\_0就调到cond\_0

Eqz在smail是如果相等，就跳转=cond\_0

![](../Images/96e3caebfabd62273fcaad64526a9212.png)

  

跳到cond\_0，那么就肯定会触发this phone is root! can not use odn!执行了isroot()代码那么我们可以想一想，

*   
*   

```
 if-eqz v0, :cond_0= if-nez v0, :cond_0
```

  

让他不相等跳到cond\_0，利用反方向逻辑，那么是不是就实现了不相等就跳转，那么相等就不跳转，另外一种就是注释掉他的引用方法的代码，那么就是P2注释掉，发现只有1处

![](../Images/78730ce2f96e564c2ae829db89b583dd.png)

  

这样的话，这个调用的P2()就不会被执行了。
