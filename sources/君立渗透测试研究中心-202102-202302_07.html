概述


2021 年 11 月中旬，俄罗斯政府联邦安全局应美国当局的要求，在一场集中搜查行动中，逮捕了 REvil 勒索组织的 14 名成员。

之后不久、我司便在日常威胁狩猎过程中发现一个代号 ALPHV 的新兴勒索组织在俄语地下社区中开始不断活跃。


AlphaV（亦名 BlackCat 或 AlphaVM) 勒索组织。

因其用于收取赎金的 TOR 支付站点都使用了相同的黑猫图标，而用于泄露勒索受害者数据的站点则都使用了一把滴血的小刀, 故在 11 月底首次被安全社区发现时命名为 BlackHat


实际上，在 REvil 组织相关成员被捕后不久，BlackCat 在地下社区中一直鼓吹的就是其 新时代勒索软件 的口号。

而其主打的则是一款基于 LLVM 架构混淆、由 Rust 开发、老练灵活、且高度成熟的勒索软 件，该款勒索软件尽管不是第一款基于 Rust 编写的勒索病毒，但确实称得上是 2021 年最复杂成熟的一款勒索软件，倒也可以说是印证了其口号。

该组织与其它高级勒索组织类似，在获取受害者网络的入口权限之后，毫无疑问地也会通过后 续的内网侦察、横向移动等攻击手段窃取受害者的核心高价值数据并加密。

但与其它高级勒索组织不同的地方在于，该组织的确有猫一般谨慎灵活的特点。其会根据不同受害者的特征来进行定制化的勒索攻击策略。

例如为了考虑加密效率有时可能选择只加密大文件、有时也可能利用获取到的受害者凭证来嵌 入到勒索软件中以便后续的自动化横向传播。

同时在对受害者目标的选择上，更专注于勒索投入产出比较高的目标、并且极有可能是全球性 的选择受害者。

如在勒索意大利时尚巨头 Moncler 价值约 300 万美元左右的比特币或门罗币的同时，又对美国、印度等多个国家的多个机构实施了勒索赎金从 40 万美元到数百万美元不等的勒索攻击。


随着美俄等执法机构对老牌勒索组织的不断打击，在老牌勒索组织暂较缺席地下勒索市场的情 况下，该组织从一众 Raas (勒索即服务) 组织中迅速崭露头角，且目前该组织在地下市场中仍保持着一个高速发展的态势。

目前据安全社区威胁情报，该组织可能已有前 REvil、BlackMatter 以及 DarkSide 等勒索组织的成员相继加入。

另外，从该勒索组织的下线最高可以占有九成的勒索所得这一营销策略来看，该组织极具成为

全球性的复杂威胁之一的潜力。

勒索样本特点


目前已捕获到的该组织样本具备如下特质:

  • 默认 AES 加密模式

  • 基于 Rust 开发、跨平台、可高度自定义

  • 内置 UAC Bypass、CVE-2016-0099、PEB 伪造 等提权方式

  • 内置 PsExec 横向传播模块

  • 通过 VSS Admin 删除 Windows 卷影副本防止受害者进行系统恢复

  • 内置关闭 VMware ESXi 等虚拟机及删除快照功能






Windows 版样本执行流程如下:



其中主要是这么几点:

  • 通过 fsutil 来操作符号链接以便拓展远程执行的能力

  • 通过修改注册表配置，将可以发出的网络请求数量设置为最大，避免在执行加密过程时 出现任何远程文件访问问题。

  • 通过 vssadmin 来删除 Windows 卷影副本以防受害者恢复系统， 通过 arp 及 nebios 以及扫描 SMB 来进行网络发现

  • 通过 Windows 事件日志工具 wevtutil 来列出并清除所有的事件日志。

  • 如果开启了 --propagated 参数的话，还会通过内置的 psexec 来进行横向传播。

  • 内置的提权的功能有：

    • 通过伪造 PEB 来提权

    • 通过滥用 COM 操作接口来进行提权比如这里分析的样本就安装了 COM 对象

    • 通过 CVE-2016-0099 提权漏洞
