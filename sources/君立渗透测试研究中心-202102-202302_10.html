fofa


谈到许多资产，就不得不提一下 fofa 了， fofa 相信大家也都不陌生了。

 fofa 的社区其实挺完善的，有很多开源的 fofa 采集工具了，例如（ Glass、fofa_viewer、以及某GUI 版的 fofa采集工具）， 在使用过很多表哥些编写的 fofa 采集工具之后，最终我个人还是更喜欢 HGather 一点，尽管每次都需要修改其配置 config.txt 中的内容， 为我们登录 fofa 之后 cookie 中的 fofa_token的值显得稍微麻烦一点



但不可否认的是，瑕不掩瑜，由于其具备直接通过自定义 fofa 搜索语句的 qbase64 值来进行采集的功能。

所以我们其实是可以在平时，就针对性的，对一些目标单位来形成一个对其资产的 fofa 语句字典库，比如说一堆目标相关 icon 的 qbase64 值。

我们可以批量地执行命令嘛🤣

一个粗糙的方法是用下边这种 python3 来调用多个 python2 来执行 HGather 脚本的方式:

import oswith open('cidr_ips.txt', 'r') as f:           j = 0           for i in f.readlines():                      target = i.replace('\r', '').replace('\n', '')                      command = 'python2 HGather.py -i ' +  target + ' -o fofa_'+str(j)+'.txt'                      os.system(command)                      j += 1

然后我试了，在 ipython3 下边会卡死

所以我们尝试另一个粗糙的方法

用 shell 来批量调用:

# 这里 j 作为扫描结果输出文件名中的变量

j=0;while read rows;do python2 HGather.py -i $rows -o fofa_$j.txt;((j=$j+1));done < cidr_ips.txt

然后会输出一堆以 fofa_数字 形式的结果文件：


这时候在 linux 下边可以很方便的处理这些文件:

cat fofa_*.txt |tee |sort -u >> fofa_result.txt

得到所有结果文件之后我们可以再使用 httpx 来对其中的 url 进行简单的指纹探测及可访问性检验：

cat dy_result.txt|cut -d " " -f 1|cut -d 'h' -f 2|awk '{print "h"$0}'|httpx -tech-detect -title -status-code -threads 100|tee httpx_result.txt



关于 httpx 可以参考freebuf:

调用多个云主机扫描




选择好某个 fleet 之后，我们就可以通过 axiom-scan 来调用刚创建的这个 fleet 中的所有主机来执行某个 axiom 中集成的模块了，比如说这里我们使用 nmap 模块对文件中的资产进行全端口-p-扫描并以 .xml 格式输出方便后续用 xsltproc 来进行格式化:

axiom-scan dyIPs.txt -m nmap -oX nmap.xml -T4 -p- -sV

这里我对 724 个 C 段进行 nmap 全端口探测， 而 axiom 则会通过其模块配置文件中的行为来对文件中的任务进行分解到每个云主机上，然后批量调用我们选中的机器进行对应的扫描操作， 最后再将扫描结果进行合并输出到我们指定的输出中


ps 可能出现的问题：

3

一些常见的使用方式




# 1. 通过 subfinder 来从根域名文件中发现子域名

axiom-scan roots.txt -m subfinder -o subs.txt --threads 10

# 2. 从子域名中解析 dns 来获取目标相关 ip

axiom-scan subs.txt -m dnsx -resp -o dns.txt

# 3. 从解析出来的 ip 中去重

cat dns.txt| awk '{print $2}'|tr -d '[]'|anew ips.txt

# 4. 从去重的 ip 中获取没有 cloudflare CDN 的 ip

cat ips.txt| cf-check > ips.txt

# 5. 扫描 ip 的全端口及服务(这里 axiom 会自动将生成的 xml 结果生成 html)

axiom-scan ips.txt -m nmap --open -oX nmap.xml -T4 -p- -sV

# 6. 直接对前边获取到的子域名 ip 进行 web 指纹探测、网站标题探测

axiom-scan subs.txt -m httpx -title -follow-redirects -random-agent -tech-detect -status-code -o subs_web_title.txt

# 7. 从 httpx 检测结果中过滤出 api 后端资产

grep -Hrni "/api" subs_web_title.txt

# 8. 对发现的 web 网站通过 ffuf 来根据字典进行目录扫描

axiom-scan urls.txt -m ffuf -w /home/op/lists/seclists/Discovery/Web-Content/common.txt -o content.csv

# 9. 或通过 gowitness 来获取网页快照

axiom-scan http.txt -m gowitness -o screenshots

# 10. 通过 gau 来爬取 url 中的链接

axiom-scan http.txt -m gau -o gau.txt
