谈到许多资产，就不得不提一下 fofa 了， fofa 相信大家也都不陌生了。

 fofa 的社区其实挺完善的，有很多开源的 fofa 采集工具了，例如（ Glass、fofa\_viewer、以及某GUI 版的 fofa采集工具）， 在使用过很多表哥些编写的 fofa 采集工具之后，最终我个人还是更喜欢 HGather 一点，尽管每次都需要修改其配置 config.txt 中的内容， 为我们登录 fofa 之后 cookie 中的 fofa\_token的值显得稍微麻烦一点

  

![](../Images/f491b038e6b022910fd66f216fa8a756.png)

所以我们其实是可以在平时，就针对性的，对一些目标单位来形成一个对其资产的 fofa 语句字典库，比如说一堆目标相关 icon 的 qbase64 值。

```
import oswith open('cidr_ips.txt', 'r') as f:           j = 0           for i in f.readlines():                      target = i.replace('\r', '').replace('\n', '')                      command = 'python2 HGather.py -i ' +  target + ' -o fofa_'+str(j)+'.txt'                      os.system(command)                      j += 1
```

然后我试了，在 ipython3 下边会卡死

所以我们尝试另一个粗糙的方法

用 shell 来批量调用:

\# 这里 j 作为扫描结果输出文件名中的变量

j=0;while read rows;do python2 HGather.py -i $rows -o fofa\_$j.txt;((j=$j+1));done < cidr\_ips.txt

然后会输出一堆以 fofa\_数字 形式的结果文件：

![](../Images/65b072b3a852812ab84165591547d8df.png)

  

这时候在 linux 下边可以很方便的处理这些文件:

cat fofa\_\*.txt |tee |sort -u >> fofa\_result.txt
