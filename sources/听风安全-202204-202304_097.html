（一）设备介绍及初始化声明


设备介绍

wifi_pineapple 由国外 hak5 社区原创，是一款无线安全审计设备。我们提供的菠萝，硬件配置与官方版一致，固件也是官方固件，只是移除了第一次使用时的一个验证。外形小巧，便携性极佳，金属机身，质感出众，散热性好，适合多种环境下使用。


硬件介绍：

1. cpu 为高通 SOC 2. 内存 RAM 为 64MB DDR2，ROM 空间为 16MB，ROM 可通过 micro SD 卡扩展3. 硬件接口有 1 个 usb 接口，1 个 Micro SD 卡接口，用来扩展 ROM 空间。1 个 micro usb 接口，用于供电，可以使用移动电源供电。1 个网口，可用来进行联网。4.内置两张网卡，一个做 AP，一个用于无线桥接或者 工作在 monitor 模式。

初始配置

连接好天线及电源后，大菠萝会自动启动。并开启ssid为Pineapple_xxxx的wifi。连接此wifi后即可访问后台：http://172.16.42.1:1471/

第一次使用会有初始化。按要求设置密码。管理端wifi即可。如下图。

设置好的后后台界面


登陆后界面如下


设备联网

给大菠萝联网有两种方式，直接接入网线或者无线桥接。直接接入网线就不多说了。

由于我这里的校园网连接要客户端认证，操作比较麻烦，所以我选择无线桥接到手机热点来进行操作。

点击侧边栏的Networking选项。选择网卡。然后点击scan会扫描附近的wifi 。选择要连接的即可。



（二）固件升级，安装插件，使用绵羊墙


检查固件更新



安装插件

点击图示箭头所指，即可获取插件列表，选择自己想玩的安装即可。
有sd卡建议安装再sd卡内，大菠萝提供的储存很有限。


开启无加密ap

在networking选项中设置无加密wifi


使用绵羊墙

这里我选择安装使用绵羊墙插件（DWall）。
按上一步的操作安装好DWall插件。

点击上图所示的enable即可启用dwall插件。
点击开始监听即可。
