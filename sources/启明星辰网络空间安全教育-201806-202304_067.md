# 再次入选！教育部2022年供需对接就业育人项目企业名单公布，启明星辰欢迎各大院校申报

10月18日，教育部高校学生司专家组发布《教育部高校学生司关于公布第二期供需对接就业育人项目申报指南的函》，启明星辰集团申报的“定向人才培训项目、就业实习基地项目、人力资源提升项目、重点领域校企合作项目”4大类项目再次成功入围。

  

**一**

**建设目标**

在教育部高校学生司指导下，开展供需对接就业育人项目，将企业用人需求纳入高校教学和培养体系，提升毕业生就业能力和综合素养。定向人才培养项目主要举办“网络空间安全”兴趣班、“工业互联网控制安全”特色班、“网络安全自动化RPA”研究班，定向输送紧缺实用人才；就业实习基地项目采取“轮岗实习”的方式，培养学生实践能力，提供后备人才资源；人力资源提升项目在高校挂牌“启明星辰知白学院网络安全人才工作站”，互派工作人员挂职交流，开展人力资源建设研讨，形成紧密的人才供需对接关系；重点领域校企合作项目与学校深入进行产教融合、校企合作，双方共同打造特色学科，共建教学资源库，联合打造高技能人才。

**二**

**项目内容**

启明星辰拟设立定向人才培养培训项目50项，就业实习基地项目55项，人力资源提升项目50项，重点领域校企合作项目55项。

**1**

**定向人才培养培训项目**

**1**

项目合作时间1年。

**2**

在高校设立2个特色班级，拟从网络空间安全、网络工程、信息安全、计算机科学与技术、信息安全技术应用、工业互联网技术、计算机网络技术、计算机应用技术专业遴选优秀学生，每班计划培养40人。科学合理制定人才定向培养方案，实施校企“双导师”制度，定期考核学生学习情况，确保学习质量。

**3**

校内课程包括但不限于防火墙技术及应用、入侵检测技术及应用、审计技术及应用、渗透测试技术、网络攻击与防护、网络安全等级保护设计与实践、云安全防护技术，其中渗透测试技术课程不少于64学时，网络攻击与防护不少于96学时。部分课程可由启明星辰和学校共同开发。

**4**

设立职业导师项目2项。由高校和公司专家共同担任大学生职业(专业)导师，设计专门课程，引入启明星辰内部职工培训方法，共同开展职业生涯教育、业务培训和就业研究，助推高校人才培养模式改革。

**2**

**就业实习基地项目**

**1**

项目合作时间1年。

**2**

授予合作高校为毕业生就业实习基地，每年接纳网络空间安全、网络工程、信息安全、计算机科学与技术、信息安全技术应用、工业互联网技术、计算机网络技术、计算机应用技术专业专业40名学生进企业实习。

**3**

针对企业生产、业务环节对学生进行多岗轮训，同时，以企业项目为设计课题，派出企业工程师对学生开展实习指导。

**4**

主动向高校提供人才需求信息，在学生社会实践、就业等方面，为协议高校学生提供便利与支持。

**3**

**人力资源提升项目**

**1**

项目合作时间1年。

**2**

校企双方定期互派工作人员开展挂职交流，协同开展毕业生就业创业、行业发展、团队建设等专门研究，深化互利合作和流程再造。

**3**

启明星辰与高校建立定向招聘关系，优先到合作高校举办校招活动，打造人才工作站或专门人才基地。

**4**

公司与高校合作举办人力资源专门研讨会，或设立课题进行专题研究，提高公司人力资源建设水平。

**4**

**重点领域校企合作项目**

**1**

项目合作时间1年。

**2**

启明星辰为合作高校网络空间安全、网络工程、信息安全、计算机科学与技术、信息安全技术应用、工业互联网技术、计算机网络技术、计算机应用技术专业大学生提供科研机会，并给予全方位支持。

**3**

企业为合作高校网络空间安全、网络工程、信息安全、计算机科学与 技术、信息安全技术应用、工业互联网技术、计算机网络技术、计算机应用技术专业大学生提供就业岗位，优先到高校举办招聘活动。

**三**

**高校条件**

**1**

**定向人才培养培训项目**

**1**

本科高校和高职院校均可申报。

**2**

高校应开设网络安全专业或计算机相关专业，每届相关专业毕业生不低于40人。

**3**

高校相关专业开设2年以上，项目应以现有计算机专业为基础，高校能独立完成计算机基础课程，并且有计算机专业机房等实训基础条件。

**4**

高校同意启明星辰参与相关课程和教学内容设置，以开放的态度共同研制培养计划和教学方案，为专业课程设计和职业能力培训提供必要的师资和专业支持，同时定期举办师资培训、技术交流等活动，增强双方的合作密切度。

**2**

**就业实习基地项目**

**1**

本科高校和高职院校均可申报。

**2**

高校应开设网络安全专业或计算机相关专业，每届相关专业毕业生不低于40人。

**3**

高校按照协议配合办理学生实习手续，会同公司对学生进行考核；考核合格后由公司出具相应证书，并优先落实就业岗位。

**3**

**人力资源提升项目**

**1**

本科高校和高职院校均可申报。

**2**

高校相关专业开设3年以上，配备具有相应计算机专业、网络专业专职及兼职教师团队不少于6人，相关专业学生熟悉TCP/IP分层及各层包含的协议，Windows/Linux操作系统基本操作，网络、路由及防火墙配置，有一定的网络知识跟网络设备知识和数据库知识等技能，同时对工作积极认真负责、思维敏捷、有良好的沟通能力及分析总结能力。

**3**

学校聘请公司有关专家担任学校大学生职业导师，动员知名专家学者参与公司人力资源建设及产品研发，为企业员工提供相关培训。

**4**

**重点领域校企合作项目**

**1**

项目面向“强基计划”试点高校或开设网络安全专业、信息安全、信息安全技术应用的高校。

**2**

高校意向重点打造网络空间安全专业，有相关实训场地和师资资源。

**3**

重视学科建设，并且在人才培养体系改革上有需求的高校。

**四**

**时间安排**

根据教育部高校学生司项目专家组通知要求：

**\***

**11月15日后**，我司将对高校《项目申请书》进行论证评审，并与评审合格的高校签订项目协议。

**\***

**12月15日前**，我司将上传评审合格的《项目申请书》及《校企合作协议》，供教育部复核，公布项目立项名单。  

**五**

**如何申报**

 ··· 

  

![](../Images/4e7c6f151eb97d34c4cc6f36854555e2.png)

  

各高校项目申报人可通过教育部供需对接就业育人平台https://www.ncss.cn/jyyr，进入“指南公布”栏目，在单位名称处搜索“启明星辰信息技术集团有限公司”，查看项目申报详细内容。

  

项目申报人须在项目申报截止时间（11月15日17:00）前填写申报相关信息，并加盖高校就业部门公章的申请书扫描文件发送至企业邮箱。《2022年启明星辰信息技术集团有限公司教育部供需对接就业育人项目申请书》模版请在平台“模版下载”中下载。若有任何疑问，请与企业项目负责人联系。
