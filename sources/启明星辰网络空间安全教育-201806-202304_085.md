# 直播回顾丨启明星辰知白学院联合吉林师范大学成功举办网络安全主题报告会！

直播现场参会领导合影留念

  

为落实中央网信办2022年网络安全宣传周活动有关通知要求，知白学院联合合作院校吉林师范大学围绕“网络安全为人民，网络安全靠人民”为主题，于2022 年 9 月 9 日下午成功举办了2022年网络安全宣传周专题报告活动。

  //  

![](../Images/c2641154a29d707307cb70ca92e0eaa1.png)

直播现场特邀多位专家进行专题报告

  

活动采取知白讲堂线上直播，微信视频号和哔哩哔哩同步转播的形式，邀请校方专家及知白学院专家展开网络安全主题专场报告会，共同打造一堂面向全体师生的网络安全公开课。据悉，本次报告会吸引近3000名师生参与观看直播。

  //  

![](../Images/c0619732ad61a41372377903b584f002.png)

北京启明星辰集团高级合伙人、知白学院院长孙涛

  

  

北京启明星辰集团高级合伙人、知白学院院长孙涛，在会议上提出，基础设施、核心技术及行业人才是网络安全行业健康发展的三大基础，其中人才更是核心中的核心，是维护网络安全的重点。

作为网络安全行业的佼佼者，启明星辰在为用户提供优质产品和服务的同时，有责任、有义务把安全人才培养放在公司战略中重要的地位。启明星辰从公司创立开始就非常注重网络安全人才的培养，在1997年成立了培训认证部，是国内最早的网络安全培训机构和厂商之一。2017年培训部升级成为知白学院，学院以行业化视角和产业人才的需求为依据，将来自于培训与教学的实践积累，融合“产、学、研、训、赛、证”为一体，形成闭环，同时将人才综合能力评价贯穿整个培养周期。从“学”开始，经历教学、测评、竞赛、认证、科研，最后到学生的高质量就业。

孙院长指出，知白学院与吉林师范大学依托教育部印发的《现代产业学院建设指南》，以及《吉林省现代产业学院建设实施方案》，在2020年成功共建了信息安全产业学院，坚持育人为本、产业为要、创新发展，助力吉林省“一主六双”发展战略，在产业学院建设中，把通识教育、专业教育、实践教育相融合，培养基础坚实、技能扎实、思想朴实的网络安全新人才，加强与产业间的有机联系，落实新工科人才培养内涵，从而助力国家和地方的战略需求。

  //  

通过此次活动的成功举办，将促进启明星辰知白学院和吉林师范大学的深度产学合作，持续宣传国家网络安全有关法律法规和政策标准，加强学校网络信息安全宣传力度，提升院校师生的网络安全意识，同时，结合双方已建成的网络空间安全创新产业学院落地成果，继续深化网络安全人才梯队建设。在未来，定能探索出一条网络安全人才建设的新模式、新路径和新方法。
