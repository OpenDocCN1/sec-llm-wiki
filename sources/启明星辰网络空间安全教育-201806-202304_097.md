# 开班通知丨网络安全能力认证CCSC

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDg0NTc1NA==&mid=2247492542&idx=1&sn=5376e46d74f8b612776566bfcfb53571&chksm=fa8c23ebcdfbaafd265b9a24201667923c09b5a35e27bd6aaf8ce17b9cbc5571b5fbf0ef8b28&scene=126&sessionid=1681655611#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDg0NTc1NA==&mid=2247492542&idx=1&sn=5376e46d74f8b612776566bfcfb53571&chksm=fa8c23ebcdfbaafd265b9a24201667923c09b5a35e27bd6aaf8ce17b9cbc5571b5fbf0ef8b28&scene=126&sessionid=1681655611#rd)

2019年12月30日召开的国务院常务会议决定“分步取消水平评价类技能人员职业资格，推行社会化职业技能等级认定”。“网络安全能力认证”（Certified Cyber Security Response Professional, CCSC）是CNCERT推出的，面向重点行业网络与信息安全从业人员的社会化职业技能认证。该认证致力于补充网络信息安全人才，提高人员的安全管理、应急响应等方面的能力，满足重点行业对网络安全人才的迫切需求。

**发证机构CNCERT简介：**国家计算机网络应急技术处理协调中心（CNCERT）为中央网信办直属事业单位，是“网络安全万人培训资助计划”的发起和技术指导单位之一，熟悉政府部门、行业协会、企事业单位的网络信息安全人才需求，对外提供多元化的持续教育机会。

CCSC认证包含管理和技术两个方向，每个方向设置不同的等级。另外为兼顾行业差异性，CCSC还提供面向通信、电力、石油炼化等特定行业的附加认证。![](../Images/f7ebf16154d4c1bd4a772727fb142ed4.png)

**一  
  
**

**CCSC认证特色**

**01**

**面向重点行业：**面向电信、银行、能源、制造等重点行业，认证体系设计与行业需求紧密结合。

**02**

**培养核心能力：**以应急为切入点，管理与技术并重，实践能力优先，能力等级递进，培养实践能力。

**03**

**提供学习平台：**优先使用CNCERT共享数据、众研众测平台、在线学习平台等资源，获得参加CNCERT网安年会、安全大赛的机会。

**04**

**增加合作机会：**获得参加CNCERT安全保障、安全服务等活动的机会。

  

**二  
**

**CCSC个人收益**  

**01**

获取CCSC认证，提升个人在网络安全技术、管理等方面的专业性和服务能力，促进职业发展。  

**02**

具备一定的安全意识，能有效应对日常工作中的各类安全问题。  

**03**

对具有一定信息安全基础，想从事网络安全相关工作的人员是一块重要的职场“敲门砖”。  

**04**

提升职场竞争力，在同等岗位上比他人更胜一筹。  

  

**三**

**CCSC适用人群**  

  //  ![](../Images/c3cc7ee9ccfc49ee49b72167c0c1248c.png)

  

党政机关、重点行业（电信、金融、制造、能源等）的**网络安全从业人员**，职位包括但不限于安全管理类的首席安全官、网络安全经理、安全总监、合规经理、审计员等，安全技术类的系统安全管理员、安全运维中心分析员、工业控制系统工程师等。

**

**五**

**考试安排**

集中授课后需要参加统一考试，考试形式为**闭卷**上机考试，技术Ⅰ级、管理Ⅰ级、管理Ⅱ级时间均为90分钟，满分120分，**及格线84分**。学员经培训和考试合格后，由国家计算机网络应急技术处理协调中心颁发网络安全能力认证（CCSC)技术等级证书。
