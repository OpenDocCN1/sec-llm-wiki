# “东数西算”挑战与机遇并存

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDg0NTc1NA==&mid=2247488949&idx=1&sn=ba8f55bc3df42922a1c9b65f0bc9856f&chksm=fa8fd5e0cdf85cf622e886e336cb3f115368bea8f1950c45b813e18f27f9a9b68e25ab057739&scene=126&sessionid=1681655637#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDg0NTc1NA==&mid=2247488949&idx=1&sn=ba8f55bc3df42922a1c9b65f0bc9856f&chksm=fa8fd5e0cdf85cf622e886e336cb3f115368bea8f1950c45b813e18f27f9a9b68e25ab057739&scene=126&sessionid=1681655637#rd)

近日，由国家发展改革委员会、中央网信办、国家能源局等部门联合印发通知，启动国家“**东数西算**”战略。

![](../Images/68ca9b2457437326e62e37aa6e2e6a0f.png "未标题-1.png")**

****什么是****“东数西算”？****

**![](../Images/f4ae17f3a83dd5e3415dbbb551b62a69.png)

“**东数西算**”即“**东数西算工程**”，指通过构建**数据中心**、**云计算**、**大数据一体化**的新型算力网络体系，将东部算力需求有序**引导到西部**，优化数据中心建设布局，促进东西部协同联动。简单地说，就是让**西部的算力资源更充分地支撑东部数据的运算**，更好为数字化发展赋能。

  

![](../Images/115c50cf5249e068c0aff8660ea43d03.png)

  

2022年3月，提请十三届全国人大五次会议审查的计划报告提出，实施“东数西算”工程。数字时代正在召唤一张高效率的“算力网”。“**东数西算**”是把东部密集的算力需求有序引导到西部，使数据要素跨域流动。打通“数”动脉，织就全国算力一张网，**既缓解了东部能源紧张的问题，也给西部开辟一条发展新路**。

  

业内专家估算，“东数西算”工程每年投资体量会达到**几千亿元**，对相关产业拉动作用会达到**1:8**。这也意味着该工程将大大超过“西气东输”和“南水北调”工程。

![](../Images/68ca9b2457437326e62e37aa6e2e6a0f.png "未标题-1.png")**

****“东数西算”********面临的挑战****  


**![](../Images/f4ae17f3a83dd5e3415dbbb551b62a69.png)

**“东数西算”背后需面临哪些安全大考？****数据安全问题首当其冲**。《全国一体化大数据中心协同创新体系算力枢纽实施方案》强调，“加强对基础网络、数据中心、云平台、数据和应用的一体化安全保障，**提高大数据安全可靠水平**。加强对个人隐私等敏感信息的保护，**确保基础设施和数据的安全**。” 在网络传输、业务部署、数据治理等关键环节，“东数西算”工程可能还会面临诸多挑战。

  

![](../Images/70955849469980c082dfdfa2a98aa51c.png)

  

  
**0****1****数据传输能力**  

    无论是数据传输到西部地区进行计算，还是传输到西部地区进行存储，对数据传输能力都是极大的挑战。因此在东数西算的整个布局中除了西部的数据中心建设，必不可少的就是建设数据中心之间的高速网络通道。

**0****2****业务部署模式**  

    从单个云数据中心部署业务的模式，也会逐渐向中心云+边缘云、分布式的混合架构部署模式进行转变，也会成为技术挑战，比如分布式协同的要求高、数据实时一致性要求等。

**0****3****数据安全风险**  

    在数据传输过程中被窃取和篡改的风险、数据中心的服务器是否会遭受各种病毒入侵，网络层经常见到的DDoS攻击、cc攻击、SQL注入攻击、XSS跨站攻击等都让业务和数据面临业务中断、数据损坏的窘境，会导致各种经济损失和企业名誉受损。

![](../Images/68ca9b2457437326e62e37aa6e2e6a0f.png "未标题-1.png")**

“东数西算”给我们带来的机遇  


**![](../Images/f4ae17f3a83dd5e3415dbbb551b62a69.png)

“东数西算”打通了“数”动脉，织就全国算力一张网，把东部密集的算力需求有序引导到西部，使数据要素跨域流动。“东数西算”带来的，是巨大的市场及产业发展：**数据安全**、**信息通信**、**数据存储**、**基础软件**、**IT设备制造**……这样一个庞大的系统性工程给我们带来了新的发展机遇。

  
**0****1**  

**数据安全人才**

  

![](../Images/2c3a3e262da7fcb894fb06cb0812414d.png)

  

数据需要东数西算，需要东西传输，传输过程不可避免会遇到数据安全问题，数据安全成为紧迫且基础的安全问题，对**数据安全人才的需求也愈加迫切**，而当前数据安全行业人才缺口高达百万！

  

中国信息安全测评中心推出**CISP-DSG**认证，针对**数据安全人才培养**，具有数据安全治理过程管理、数据安全技术体系设计，数据安全管理体系设计的基本知识和能力。为培养高质量人才做准备。

![](../Images/68ca9b2457437326e62e37aa6e2e6a0f.png "未标题-1.png")  
**0****2**  

**云计算人才**

  

![](../Images/9b5cf4dcb25abc08ebdcccfa1b5d4813.png "393593354317987904.jpg")

  

“数”和“算”指的是对数据的处理能力。“东数西算”是通过构建数据中心、云计算、大数据一体化的新型算力网络体系，将东部算力需求有序引导到西部。人社部中国就业培训技术指导中心的《新职业在线学习平台发展报告》也指出，**未来5年云计算产业人才缺口将高达150万**。《2021人才市场洞察及薪酬指南》显示，云计算领域人才薪酬涨幅接近40%，由此可见，**市场对云计算人才的刚需显而易见，但精英人才却“高薪难求**”。

  

**CCSK**（Certification of Cloud Security Knowledge 云计算安全知识认证）作为**云计算领域面向个人用户的全球首个安全认证**，能确保与云计算相关的从业人员对云安全威胁和云安全最佳实践有一个全面的了解和广泛的认知，帮助从业人员提升云安全专业技能，为国家战略性工程提供保障。

![](../Images/68ca9b2457437326e62e37aa6e2e6a0f.png "未标题-1.png")

在“东数西算”工程背景下，**启明星辰知白学院将为培养安全体系人才做有力支撑**，大力发展人才，提供培训认证支持：**CISP-DSG**（注册数据安全治理专业人员）、**CCSK**（云计算安全知识认证）、**CISP**（注册信息安全专业人员）、**CISD**（注册信息安全开发人员）、**NSACE**（高级Web安全专家）......助力安全体系人才发展，保障“东数西算”工程的顺利推进。
