**入门网络安全，**

**如何挑战百万年薪？**

  

![](../Images/f9442766f6f4210ff2598f9f7fca61bd.png)

  

当前网络空间安全建设刻不容缓，成为国家安全建设的重中之重。由于境内外大规模敌对势力安全事件的发生，**《国家网络空间安全战略》《网络安全法》《网络安全等级保护2.0》**等一系列政策/法规/标准不断落地，使网络安全产业逐渐成为国家战略性新兴产业，与人工智能、大数据、云计算等领域并驾齐驱。

  

![](../Images/103a9a3846c90526d22dcbb72cde994e.png)

过去，许多政企单位在IT部门和岗位划分时，只有研发、运维部门，安全人员直接归属于基础运维部。如今，越来越多的单位为了满足国家安全法律法规的要求，**必须成立独立的网络安全部门，寻求各方安全人才，组建 SRC (安全响应中心)，为自己的产品、应用、数据安全提供保障**。

  

![](../Images/9f0e43823b0de9c27665c7c617c20cea.png)

目前**互联网、通信、新能源、房地产、金融证券、电子技术**等行业迫切需要网络安全人才，因为网络安全的重要性，每一行业同时又催生出不同的需求方向，从业者完全可以根据自己的喜好自主择业。

  

"**没有网络安全，就没有国家安全**"。对大多数政府和企业单位而言，网络安全已从\[**可选择**\]转变为\[**必须选择**\]甚至是\[**强制**\]，**不懂安全不做安全就意味着违法**。

  

  

**安全人才一将难求 年薪高达百万**

![](../Images/822185431968f46186fa1a8122bde9ed.png)

安全团队不再是大厂或者互联网公司专有，只要是**“触网”企业，都需要安全人才加入**。

![](../Images/03c715b67ba17d1558157a84d3533749.png)

由于行业人才输送与人才缺口的比例问题，网络安全对从业人员的经验要求偏低，而且大多数对从业人员的学历没有设限。

**网络安全应该怎么学**

  

  

  

学习网络安全的过程，一直伴随着以下问题：

 

🔥网络安全包括什么技术？

🔥应该选择哪个方向？

🔥网络安全岗位到底有哪些？

🔥具体工作在做什么？

🔥网络安全的职业发展和成长路线是什么？

 

安全行业的岗位和需求层出不穷，可以站在甲乙双方分类，可以站在攻防两端分类，可以站在技术链上分类，也可以根据具体的业务岗位进行分类。

  

根据**应用场景或技术实现**，网络安全可以简单细分以下方向：

 

🔥网络安全（Network Security）

🔥Web安全（Web Application Security）

🔥移动安全（Mobile Security）

🔥云计算安全（Cloud Security）

🔥桌面安全（Desktop Security）

🔥数据安全（Data Security）

🔥无线安全（Wireless Security）

🔥人工智能安全（AI Security）

🔥 ……

![](../Images/2fbed1c00d11c787db0321deb59037e4.png)

网络安全还可以基于**攻击和防御视角**来分类，我们经常听到的 “**红队**”、“**渗透测试**” 等就是研究攻击技术，而“**蓝队**”、“**安全运营”**、“**安全运维**”则研究防御技术。无论网络、Web、移动、桌面、云等哪个领域，都有攻与防两面性。例如 Web 安全技术，既有 Web 渗透，也有 Web 防御技术（WAF）。**作为一个合格的网络安全工程师，应该做到攻守兼备，毕竟知己知彼，才能百战百胜**。

  

如果你是一个安全行业新人，建议你先从**网络安全或者Web安全/渗透测试**这两个方向先学起，原因如下：

 

🔥 首先，这两个方向目前已有较为成熟的学科知识体系，**对初学者比较友好，入门学习简单**；

🔥 其次，这两个方向在企业招聘和项目工作中被广泛应用，如大型企业经常招募的**安全服务工程师、 Web安全工程师、渗透测试工程师、安全运维工程师等岗位**，其主要技能组合就是网络安全和Web安全。

🔥 第三，这两个方向的**岗位薪酬在安全行业也是很可观的**。

  

值得注意，**学习网络安全，就是先网络后安全；学Web安全，也是先Web再有安全。**安全并非独立存在，而是建立在其它技术基础上的上层应用技术。脱离基础，很容易变成纸上谈兵，变得“知其然，不知其所然”，职业安全之路也难以走远。

 

因此，学习Web安全方向需要有一定的编程基础，**如果对代码没兴趣，建议走“网络安全”方向**，学习网络安全方向不需要太多计算机编程功底（不是走研发路线而是走安全服务工程师路线），更多需要掌握常见安全网络架构、对网络协议和故障能抓包分析，对网络和安全设备能熟悉配置。

**《全栈网络安全工程师》课程优势**

**知白学院**
