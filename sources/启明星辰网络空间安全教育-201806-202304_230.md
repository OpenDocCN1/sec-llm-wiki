8月10日-8月23日，8月20日-23日，启明星辰知白学院组织全国来自上海、山东、江苏、浙江、江西、河南、湖南、甘肃、新疆、贵州等省市近**50多所院校超100名教师在知白讲堂进**行了1+X网络安全风险管理（中级）职业技能等级证书师资培训。师资培训以“**线上讲授+实验操作+理论考试+实操考试**”的形式举行，受到教师的一致认可与好评。

  

  

 8月27日上午9点-12点在启明星辰**知白学院自研的知白网络安全攻防演练系统**上举行的实操考试采用CTF竞赛模式，在比赛过程中老师们通过解题获得 flag 信息，选手将 flag 提交到比赛平台获取相应分数，老师们通过此次CTF比赛赛出了水平，赛出了风格，成为了本次师资培训最大的亮点。

**网络安全的本质是网络安全风险管理**

  

     网络安全风险管理不仅仅是一个简单的理论或方法，它是贯穿信息系统规划、建设、运行的全生命周期的系统化、结构化工程。

     通过开展网络安全风险管理职业技能认证，可以帮助学员能够有效地理解和落实组织安全策略，从风险管理的角度，对信息系统及由其处理、传输和存储信息的保密性、完整性和可用性等安全属性进行评价的过程，持续优化安全防护体系效能。

     同时，网络安全风险管理职业技能认证可适应更多层次院校学生考取，学生就业面更广，就业层次更丰富，就业竞争力更强。

启明星辰1+X网络安全风险管理职业技能等级证书主要围绕4个知识领域：

Web安全分析与防御

Web与系统安全分析与防御

系统安全分析与防御

安全事件分析

涵盖8项核心技能知识点展开：  

Web 漏洞分析

Web 漏洞利用

Web 漏洞加固

系统漏洞分析

系统漏洞利用

系统漏洞加固

风险情报分析

风险用例编写
