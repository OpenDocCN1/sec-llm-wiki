# 启明星辰网络空间安全学院CISD官方授权培训资质首落大连市互联网协会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDg0NTc1NA==&mid=2247483973&idx=1&sn=268913801cb4a8f24cdc09a60a4f6621&chksm=fa8fc210cdf84b06b981d3b020550e1ef20b921be8769f7fbc6b71d124db86e4976930c76f93&scene=126&sessionid=1681655708#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDg0NTc1NA==&mid=2247483973&idx=1&sn=268913801cb4a8f24cdc09a60a4f6621&chksm=fa8fc210cdf84b06b981d3b020550e1ef20b921be8769f7fbc6b71d124db86e4976930c76f93&scene=126&sessionid=1681655708#rd)

  

2019年4月19日是习近平总书记就网络安全和信息化工作重要讲话发表三周年，**作为中国信息安全测评中心CISD项目官方唯一运营单位，**启明星辰网络空间安全学院常务副院长刘岗与大连市互联网协会会长王学通共同签署了《注册信息安全开发人员授权培训机构协议》，**授予大连市互联网协会国内首家CISD注册信息安全开发人员官方授权培训机构，**积极推动了国内CISD培训认证工作的开展。

 

![](../Images/e38747998f2e4b94625293c7c665d5b9.png)

  

签约仪式现场，大连市委网信办副主任姜健高度评价了此次启明星辰网络空间安全学院与大连市互联网协会在软件开发安全人才培养方面的合作事宜。姜副主任指出，大连作为我国软件产业的排头兵，经过20多年的发展，聚集了大量软件和信息技术服务企业及专业技术人才。启明星辰网络空间安全学院此次与大连市互联网协会在软件开发安全人才培养的合作开展，将会大力促进大连市软件产业向更高质量更高层次发展新阶段迈进。

  

注册信息安全开发人员（英文为 Certified Information Security Developer，简称 CISD）是经中国信息安全测评中心认定的国家信息安全开发人员，具备为软件全生命周期中提供安全保障的能力，是对我国网络基础设施和重要信息系统的软件开发人员安全开发能力实施的一种资质评定。启明星辰网络空间安全学院作为中国信息安全测评中心CISD项目官方唯一运营单位，负责CISD注册信息安全开发人员在全国的渠道工作，包括CISD的授权培训机构管理和维护。

  

![](../Images/64a40bbb6ee4ae89e39d75cf2aa4fdd3.png)

  

随着国家网络安全战略的落实，软件行业作为信息技术的关键基础设施，安全的重要性日益凸显。启明星辰凭借多年的技术沉淀及行业实践积累，一直积极支持网络安全人才体系的构建，提升信息安全技术及能力教育培训，联合开发了CISD课程，是国内最早开展CISD认证培训的专业培训机构，积极为用户提供网络安全培训服务，旨在培养国内一流、专业的网络安全人才。

**启明星辰网络空间安全学院**

  

启明星辰网络空间安全学院于2017年成立，其前身为启明星辰集团培训认证部，是国内最早的安全培训机构之一。

  

启明星辰作为国内信息安全行业领军企业，拥有二十余年来自应用与实践的深度技术积累及沉淀，对建立专业有效的信息安全人才培养体系形成深刻的理解和思考。

  

目前，已形成安全运维课程体系、安全攻防课程体系、安全竞赛课程体系、认证类培训体系、安全管理课程体系、安全开发课程体系、前沿技术课程体系、网络安全微课程体系八大课程体系，近百门课程。
