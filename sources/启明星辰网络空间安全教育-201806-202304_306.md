# 35所高校新增网信安全专业 全国网信安全相关专业建设院校超过130所

3月29日下午，教育部最新公布2018年普通高等学习专业备案和审批结果。**35所高校获批网信安全专业建设资格**，其中25所高校获得网络空间安全专业建设资格，10所高校获得信息安全专业建设资格。至此，全国网信安全相关专业建设院校超过130所。

 

  
![](../Images/89d8200d984493e7756cfc94ad8a2ac2.png)

**网络空间安全专业**

  

网络空间安全专业是网络空间安全一级学科下的专业，学科代码为"0839"，专业代码代码为080911TK，授予"工学"学位，涉及到以信息构建的各种空间领域，研究网络空间的组成、形态、安全、管理等。

 

2015年6月，为实施国家安全战略，加快网络空间安全高层次人才培养，国务院学位委员会决定在"工学"门类下增设"网络空间安全"一级学科。该专业以网络空间安全专业理论和技术为主，还借助新闻学、法学、情报学等学科的优势，培养既具有扎实的网络空间安全基础理论、专业知识和技术技能，又具有一定网络信息传播知识，且懂法律及管理的复合型人才。

**信息安全专业**  

 

信息安全专业属于计算机类(0809)，专业代码为080904K，授予“工学”学位。进入21世纪，随着信息技术的不断发展，信息安全问题也日显突出，如何确保信息系统的安全已成为全社会关注的问题。

 

在网络信息技术高速发展的今天，信息安全已变得至关重要，信息安全已成为信息科学的热点课题。但目前我国在信息安全技术方面的起点还较低，国内只有极少数高等院校开设“信息安全”专业，信息安全技术人才奇缺。

 

![](../Images/bbf30e66371aaceea569b1156fd413ac.png)  

该专业要求学生具有全面的信息安全专业知识和进一步发展的基本能力，和应用已掌握的基本知识解决实际问题的能力。致力于培养理论基础扎实、适应性强、工程实践能力强、综合素质高，掌握信息系统与信息安全的基本理论，并能从事信息系统以及信息系统中信息安全技术的研究 、设计、开发、应用、管理等工作的高级工程技术人才。

**启明星辰网络空间安全学院**

  

启明星辰网络空间安全学院于2017年成立，其前身为启明星辰集团培训认证部，是国内最早的安全培训机构之一。

  

启明星辰作为国内信息安全行业领军企业，拥有二十余年来自应用与实践的深度技术积累及沉淀，对建立专业有效的信息安全人才培养体系形成深刻的理解和思考。

  

目前，已形成安全运维课程体系、安全攻防课程体系、安全竞赛课程体系、认证类培训体系、安全管理课程体系、安全开发课程体系、前沿技术课程体系、网络安全微课程体系八大课程体系，近百门课程。
