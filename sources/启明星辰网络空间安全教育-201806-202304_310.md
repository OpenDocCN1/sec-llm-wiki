# 扒给你看 | 影响近5亿用户的WinRAR安全漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNDg0NTc1NA==&mid=2247483934&idx=1&sn=969a48e9c03d3c95e25c58fe45b1b298&chksm=fa8fc24bcdf84b5d016325261c8ad603957df77fb245f077f88c0ffa419d87d08eea80ace5ae&scene=126&sessionid=1681655713#rd](http://mp.weixin.qq.com/s?__biz=MzUzNDg0NTc1NA==&mid=2247483934&idx=1&sn=969a48e9c03d3c95e25c58fe45b1b298&chksm=fa8fc24bcdf84b5d016325261c8ad603957df77fb245f077f88c0ffa419d87d08eea80ace5ae&scene=126&sessionid=1681655713#rd)

  

  

最近WinRAR爆出了严重的目录穿越漏洞，进而造成任意代码执行，超过五亿用户将面临风险，此漏洞已存在超过19年并迫使WinRAR完全放弃对易受攻击ACE格式的支持。本篇文章将详细进行WinRAR目录穿越漏洞的复现以及针对此漏洞的防御方法。

  

  

 0x01 漏洞描述 

  

2019年 2 月 20 日Check Point团队爆出了一个关于WinRAR存在19年的漏洞，利用该漏洞，攻击者可以通过构造恶意的压缩文件，当目标使用受影响的版本解压提取存档，就能触发漏洞，造成任意代码执行。

 

WinRAR 代码执行相关的 CVE 编号如下：

  
CVE-2018-20250

CVE-2018-20251

CVE-2018-20252

CVE-2018-20253

  

该漏洞是由于 WinRAR 所使用的一个陈旧的动态链接库UNACEV2.dll所造成的，该动态链接库在 2006 年被编译，没有任何的基础保护机制(ASLR, DEP 等)。该动态链接库的作用是处理ACE格式文件。unacev2.dll中因为处理filename时只校验了CRC，所以黑客可以通过更改压缩包解压时候的filename，并且修改响应的CRC校验码来触发这个Path Traversal漏洞，完成路径穿越，进而完成代码执行。

  

 

 0x02 影响版本 

  

WinRAR < 5.70 Beta 1

Bandizip < = 6.2.0.0

好压(2345压缩) < = 5.9.8.10907

360压缩 < = 4.0.0.1170

 

  

 0x03 漏洞危害 

  

通过WinRAR的目录穿越漏洞，黑客可以进行文件路径的修改，可以将恶意木马程序放入用户电脑的开机启动项，当用户电脑重新启动时，恶意代码或者木马程序自动运行，黑客就能轻松获取用户主机的控制权；也可以投放恶意dll文件进行dll劫持或进行任意配置文件的覆盖来获取到目标主机的权限。

 

 

 0x04  漏洞复现 

  

漏洞复现过程：新建一个测试文件（可以是木马后门），利用WinAce软件存档为ace格式，然后通过修改filename与相应的CRC值，使解压路径为开机启动项。

 

环境所需如下：

  

WinAce：因为创建ACE存档受专利保护，唯一允许创建ACE存档的软件是WinAce。

  

WinRAR（版本< 5.70 Beta 1）：WinRAR 是一款功能强大的压缩包管理器， 解压缩从 Internet 上下载的RAR、ZIP及其它类型文件，并且可以新建 RAR 及 ZIP 格式等的压缩类文件。

  

WinHex：可以用来检查和修复各种文件、恢复删除文件、硬盘损坏造成的数据丢失等，是一款非常不错的 16 进制编辑器。

 

下载并安装winace软件，链接如下：

https://en.softonic.com/download/winace/windows/post-download

利用winhex修改filename，例如最终解压路径为启动项，构造payload如下：

C:\\C:C:../AppData\\Roaming\\Microsoft\\Windows\\Start Menu\\Programs\\Startup\\venus.txt

  

经过WinRAR的CleanPath函数处理会变成如下：

C:../AppData\\Roaming\\Microsoft\\Windows\\Start Menu\\Programs\\Startup\\venus.txts

  

如果是在桌面解压，那么完整的解压路径为：

C:\\Users\\whj\\Desktop../AppData\\Roaming\\Microsoft\\Windows\\Start Menu\\Programs\\Startup\\venus.txt（启动项）

  

![](../Images/70a1ba463e62e56f661fccd20d4e0968.png)

 

新的filename长度为81字节，修改第一个hdr\_size的hex值为51

  

![](../Images/be125df165de43fdff18d1a5fccaead8.png)

 

新的hdr\_size长度为112，修改hex值为70，具体ace文件解析参考如下：

  

http://purpleroc.com/MD/2019-02-22@ACE%20File%20Format%20And%20Modify%20Path.html

  

![](../Images/05568984c956750418b59bd3966fb108.png)

 

检测修改后的CRC校验值，可以使用github上面的脚本

https://github.com/backlion/CVE-2018-20250/blob/master/acefile.py

  

![](../Images/58d615ac66b2746ced8bdcd45aa6f96c.png)

 

经过校验，得到正确的CRC值，winhex修改CRC值为0eC9（注意，winhex是小端序的）

  

![](../Images/06617b09fabd65cced2da1987fe54d77.png)

 

继续使用脚本检测，没有发现报错，说明修改正确，并且能够看到文件解压路径

  

![](../Images/c0805b1372d4ca1dd9420ef94eff2247.png)

桌面使用WinRAR解压ace文件，启动项多出了venus.txt，漏洞复现完成，如果ace文件为木马文件，那么当目标电脑重启时，木马被执行，攻击者就能轻松获得目标电脑控制权
