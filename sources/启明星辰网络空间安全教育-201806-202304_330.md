# 启明星辰网络空间安全学院助力大连网络安全宣传周 ----副院长贺新朋受邀为大连网民普及安全知识

2018年9月17日，2018大连网络安全宣传周如期召开，大连市互联网协会会长王学通、启明星辰网络空间安全学院副院长贺新朋受邀参加大连电视台财经频道访谈栏目，就“如何搭建网络安全防护网”为话题进行了讨论。

  

![](../Images/34e3c095917e107fdde1cabc84debbeb.png)

  

王学通会长就当前大连乃至全国面临的网络安全形势进行了深入的分析，同时介绍了在大连网信办的领导下，网络安全工作内容以及取得的工作成果。并对本次网络安全周活动做了精彩的介绍。

  

启明星辰网络空间安全学院副院长贺新朋在节目中谈到，当前国家、政府和企业投入了大量人力、物力和财力来保障我国信息网络安全，也取得了明显的成效。但是网络安全不单单是国家、政府和企业的事情，与广大人民群众也是息息相关的，网络安全需要全民参与，共同建设网络安全防护网。企业和组织需要建立与之业务相匹配的专业安全队伍。全体人民群众也需要不断提升安全意识，只有这样才能真正建立起有力的安全防护网，而要解决这个问题，**教育和培训是最有效的方式**。

  

![](../Images/2ae27964e779611fb05d395f090da871.png)

  

此外，贺新朋同时介绍，启明星辰集团除了对传统的网络安全、系统安全、应用安全等领域持续保持深入研究之外，在物联网安全、云安全、工业互联网安全等领域均投入了大比例资源进行深入研究，研究成果也一步步融入相应的网络安全培训课程体系，通过学院面向各行业安全从业人员输出安全能力。

  

■■■■

  

启明星辰网络空间安全学院拥有完整的课程体系，包括但不限于国内国际认证课程体系、安全运维课程体系、安全攻防课程体系、安全竞赛课程体系、安全管理课程体系、软件安全开发课程体系、前言技术课程体系等体系化的课程，以适用于不同需求的客户，满足不同层次的人才培养需求。

**启明星辰网络空间安全学院**

  

启明星辰网络空间安全学院于2017年成立，其前身为启明星辰集团培训认证部，是国内最早的安全培训机构之一。

  

启明星辰作为国内信息安全行业领军企业，拥有二十余年来自应用与实践的深度技术积累及沉淀，对建立专业有效的信息安全人才培养体系形成深刻的理解和思考。

  

目前，已形成安全运维课程体系、安全攻防课程体系、安全竞赛课程体系、认证类培训体系、安全管理课程体系、安全开发课程体系、前沿技术课程体系、网络安全微课程体系八大课程体系，近百门课程。
