# 淬火锻钢 打造实战型网络安全尖峰人才 ——启明星辰出席网络安全人才培养与需求高峰论坛

6月26日，网络安全人才培养与需求高峰论坛在北京召开，此次论坛由教育部高等学校信息安全专业教学指导委员会、中国网络安全审查技术与认证中心指导，中国关键信息基础设施技术创新联盟主办，以重要行业网络安全人才需求和关键岗位网络安全能力要求为牵引，来自高等院校及安全行业的专家、企业从业人员等近300人共同探讨实战型、实用型网络安全人才培养模式。启明星辰集团应邀演讲，并成为网络安全人才淬火（三个一百）工程首批签约“大学生网络安全尖峰训练营联合培养基地”，启明星辰集团高级副总裁、启明星辰网络空间安全学院院长孙涛受聘首批“大学生网络安全尖峰训练营就业导师”。

网络安全人才淬火工程  锻造实战型网安人才

“网络空间的竞争，归根结底是人才竞争”，但我国在网络安全人才方面仍然存在总量不够、能力不足、评价手段有限等问题。应届毕业生从走出校门到步入工作岗位的“最后一公里”问题仍然突出，在职安全从业人员专业技能也需要与时俱进，以应对复杂多变的网络安全环境。  

为更好的解决网络安全人才从理论到实践、从实训到实战的问题，中国关键信息基础设施技术创新联盟宣布实施网络安全人才淬火（以下简称“三个一百”）工程，即签约100所高校、100家用人单位、100名就业导师，共同探索实战型、实用型网络安全人才培养的新模式，拓宽用人单位引进人才渠道，提高网络安全专业大学生就业能力和就业率，实现人才供需精准对接。  

“大学生网络安全尖锋训练营活动”作为三个一百工程中的一号项目，也于论坛当天正式启动。高校、用人单位、就业导师三方签约，以培养创新型、实用型网络安全人才为目标，通过导师一对一指导、岗位实战锻炼和集中封闭训练等方式，帮助学生补足知识短板、提高实战能力、做好职业规划，更好更快的完成从求学到就业的转变。

启明星辰成为三个一百工程签约首批 “大学生网络安全尖峰训练营联合培养基地”，启明星辰集团高级副总裁、启明星辰网络空间安全学院院长孙涛受聘首批“大学生网络安全尖峰训练营就业导师”。

启明星辰网络空间安全学院院长孙涛成为首批导师

启明星辰作为信息安全行业的领军企业，自成立之初并致力于安全人才的培养及储备，二十多年来对于安全行业的沉浸，对于用户业务的持续深入研究，使启明星辰能够以深耕实践与攻防前线的安全防护技术为基础，对真正有效的信息安全人才培养体系有着深刻的理解及思考。在此基础上，启明星辰成立了网络空间安全学院，提出层次化信息安全人才培养课程体系，并根据多年业务实践开发了全面覆盖安全培养知识体系及攻防培训体系知识的八大课程体系，近百门课程，且持续更新。

结合实践 构建网络安全人才培养创新体系

![](../Images/7fe9392da7aea4bfd36a0dfad280106f.png)

在此次论坛上，启明星辰网络空间安全学院副院长张镇做了《实战型安全人才培养框架设计》的主题演讲，基于对政府、行业、企业多年业务的深入实践及对网络安全人才培养体系的思考，张镇总结了用人单位对安全专业技能的要求，并根据实际业务需求，提出了网络安全人才培养创新体系的构建方案。  

![](../Images/8955f3210f7ddfb77d683c60028bdea9.png)用人单位对安全专业技能的要求  

![](../Images/249c539e26f82e0a9181f7a24ab502c1.png)网络安全人才培养创新体系  

此外，张镇还提出完备的网安人才培训体系应具有：

*   完备的课程体系
    
*   海量的培训题库
    
*   多层次实践平台
    
*   专业的师资力量
    
*   成功的培训实例

    “不积跬步无以至千里”，启明星辰已在信息安全民族品牌发展的道路上摸索了二十余年，并在聆听来自前线的无数次枪炮声后，总结了符合我国网络安全人才发展需求的培养体系，且已成功实践于政府及各行业。未来，启明星辰网络空间安全学院将以国家网络安全事业发展为己任，培养符合网络安全发展需求的专业性人才，为建设网络强国提供有力的人才支撑。
