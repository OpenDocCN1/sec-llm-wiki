# 【汉化教程】--第5课：程序的语言包文件制作

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Mjc3MDM2Mw==&mid=2651132830&idx=5&sn=a3486fca8e5c0893d4e0bf42bb2637fc&chksm=bd5083ca8a270adc5cf341b50be5053442be1631a7c29bc69622bafb1999a495f7b23cc92b42&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Mjc3MDM2Mw==&mid=2651132830&idx=5&sn=a3486fca8e5c0893d4e0bf42bb2637fc&chksm=bd5083ca8a270adc5cf341b50be5053442be1631a7c29bc69622bafb1999a495f7b23cc92b42&scene=27#wechat_redirect)

大家好，今天主要教大家Sisulizer 4的基本教程和学习语言包制作的方法，需要Sisulizer 4汉化工具。  
Sisulizer 4工具在汉化Delphi编程语言写的软件，有着很强的支持，而且在汉化软件中所见所得。  
  

进入教程：  
**一、打开Sisulizer 4工具“文件”--“新建”，再点击“下一步”，选择需要汉化的FontCreator.exe文件，如下图：**  
![](../Images/07c2b00533295ab95a4713dcd516ad8b.png)   
**二、下一步之后，就到这下面这个界面，可以默认，也可以全部打钩（一般我都是全部打钩的），如下图：**  
![](../Images/bb99744bb271f4b21f765dea51cac5b2.png)   
**三、下面这一步是重点，在“输出文件”下面有几个选项。**  
1、如果选择“本地化文件”，构建之后，将生成的文件将是exe格式。  
2、如果选择“资源DLL”，构建之后，生成的文件将是汉化语言包格式。  
这节课要求选择第2个，如下图：  
![](../Images/7cfcabe2731ced4f1149f7aca1325037.png)   
**四、下一步再确定之后，就选择正确的语言，如下图：**  
![](../Images/f0963ecebb87c83ad04fe4ece01b504b.png)   
**五、如果需要汉化特定的英文“File”，就点击搜索，如下图：**  
![](../Images/8ceaf9613ee51b6cbcb97537d5b8d9ae.png)   
**六、翻译完成了，大家要养成另存工程文件，之后就生成语言包文件，如下图：**  
![](../Images/6481a038d1c29c38e115e2080f5baa77.png)   
**七、最后看看效果吧，如下图：**  
![](../Images/3b8b4d06a8e8f42f07469568528e22ac.png)   
这只是一种的语言包文件制作方法，Radialix 3等等汉化工具也能够制作语言包文件。
