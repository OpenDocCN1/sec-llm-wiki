**0x01 反编译APK**  
将apk拖入Android killer中反编译生成工程目录   
![](../Images/221d410879d170bc54ab7f1ff38852d7.png)   
  
**0x02 Android Studio 安装smalidea**  
1\. 打开Android Studio ，点击File,选择Settings,或者按快捷键Ctrl+Alt+S打开设置界面，点击Plugin，再点击install plugin from disk。。  
![](../Images/384bf5a57ae33e6d3e1700becaa158bf.png)   
2\. 在弹出的框中选择我们下载好的smalidea，点击OK   
![](../Images/0b9b37cb7172b43387ba9028fc9a9101.png)   
经过上面两步就安装好了smalidea插件，特别说明一下，添加成功后，smali代码会语法高亮，如果没有添加成功  
原因自查。。。。。。  
  
**0x03 导入反编译后的代码**  
1\. 在Android Studio中选中Import Project   
![](../Images/426d17353b10b6bb856054ea54340176.png)   
2.选择反编译后的Project根目录   
![](../Images/49e8a9a417d8491c6d08f29bb2a11c63.png)   
  
3.弹出的窗口选择第一项，一直点击Next，直到Finish完成导入项目  
![](../Images/aa0d06bcafbb7565ab834880d391542c.png)   
4.导入完成后就可以就可以看到smali了   
![](../Images/851c2bb5138295d82a3eb2c640205387.png)   
  
**0x03 进行调试配置**  
1.在Android Studio中按照如图方式进行配置，添加一个调试  
![](../Images/87e7a2d31b08f2058413c43250c378fb.png)   
  
2.添加完调试，修改调试名字和调试端口  
![](../Images/0077135eaa5542007f8038a49ce2b2fb.png)   
3.配置完成后可以的效果   
![](../Images/5ddb8a9d0b3542edf256ad5ec3376c5e.png)   
  
**0x04 安装并开始调试**  
1.首先我们现在MainActivity中的OnCreate函数中鼠标左键下一个断点如图   
![](../Images/a104bbc64d0ee6b45fe5148102f116fe.png)   
2.在手机中安装我们的应用并且以调试方式打开   
使用的命令  
adb install -radb shell am start -D -n packageName/ActivityName  
![](../Images/7711a5f0e49f4c92826f1162789fe019.png)   
3.打开一个Monitor选中想要调试的应用 ![](../Images/b2e45c439d4c3358ba147d27fe322ded.png)   
![](../Images/b9f1b8aa1a63c413f614f3ec0cd15604.png)   
4.这里我们监视v0寄存器，F8单步，F7步入，其实和OD的调试差不多的，可以看到寄存器的值改变![](../Images/13ccce35f5ef8743c6d34ce21075d2b4.png)   
5.变量监视窗口，我们可以在这添加并且监视寄存器 ![](../Images/6060a37eb1f38b2362a20146a7d6319d.png)   
![](../Images/0a166d5cb449898d042e2036da618498.png)   
这样就可以开始调试smail了，比较简单。
