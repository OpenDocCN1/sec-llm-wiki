# 【Mac程序破解】修改Mac版微信客户端使其支持账号密码方式登录

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Mjc3MDM2Mw==&mid=208996857&idx=2&sn=341c74736d9ea95f94322773640f1b34&chksm=2f2099ad185710bbb2978166265e78817e3e9f5fc754f258060026edcfa69943558ac310cbe6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Mjc3MDM2Mw==&mid=208996857&idx=2&sn=341c74736d9ea95f94322773640f1b34&chksm=2f2099ad185710bbb2978166265e78817e3e9f5fc754f258060026edcfa69943558ac310cbe6&scene=27#wechat_redirect)

原文作者名称为：backtrace（由于微信限制，无法写全）

最近Mac App Store提示更新了新版的微信客户端，打开之后，却发现只有扫码登录这一种登录方式了   
  
![](../Images/4eb74694e7c965d0f80319102d0438d3.png)  
  
这对平时习惯用账号密码方式登录微信客户端的用户来说造成了很大困扰。  
  
所以试着用Hopper载入了微信，看看能否通过修改的方式找回原来的账号密码登录方式![](../Images/4c0c750c274575ba847bd9f773babc00.png)  
  
在几个关键处下了断点，动态调试后，定位到关键点 （定位的过程比较简单，不赘述）：  
  
![](../Images/45a8e2023835b93ee4e68f185e21fbea.png)  
  
可以看到，在调用过程中，直接指定了扫二维码的登录方式，而普通的登录方式并未在代码中删除，所以可以通过修改图中的关键点的调用让账号密码的登录方式重新显示  
  
确定了关键点，这就开工  
  
//关键代码如下  
mov rsi, qword \[ds:0x100a7ce28\] ;@selector(showQRCodeView) //此处对应的16进制代码为 488B35EDE88D00  
mov rsi, qword \[ds:0x100a82618\] ;@selector(showPasswordLoginView)  
  
通过计算可以得知   
0x100a82618 - 0x100a7ce28 = x - 0x8DE8ED  
x = 8E40DD  
  
由于hopper对于图中的调用没办法直接修改成预期的结果，所以得通过hopper的Hex Editor来修改  
![](../Images/838fd16864b78919115d304d96e9cb79.png)  
  
将图中标注的地方修改成DD 40 8E  
  
![](../Images/5b0e9684ac00ab62a431a71b70f9ffa4.png)  
  
然后通过 File -> Produce New Executable... 来保存刚才修改的文件，现在再来运行一下微信  
  
![](../Images/85e0e071f7d9baddbf101cf454360299.png)  
久违的账号密码登录方式又出现了![](../Images/ae700ca68dc166862d40c0b575a82ca1.png)  
  
再试下登录，可以正常登录  
  
![](../Images/06b2089dc3ab366e9595a0b6e96562a4.png)
