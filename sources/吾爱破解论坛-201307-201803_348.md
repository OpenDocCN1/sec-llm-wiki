2.登陆机器码限制

  
  

机器码一般会在登录的时候提交或者拿到，查看程序集，在WaterSoft.Common.dll 找到了一个 CUser类。

![](../Images/e8063cc97586275dca543c6419bbb86d.png)

基本上登录方法都在这里了。查看login()方法

![](../Images/c3a69c67850f21fb9271df55bb5c8cd7.png)

正则匹配，匹配规则："errorhandle\_\[\\\\w\\\\-\]\*\\\\(\[\\"'\](?<error>\[^\\"'\]+)\[\\"'\]" ，如果匹配成功，直接登录失败。

修改比较简单，直接破坏掉以后的匹配规则即可。

![](../Images/df7a8eceb715cfbb414466c500a7b21e.png)

3.启动50次限制

![](../Images/7022e1e10eb089483359a7ad4578b21c.png)

观察软件一打开就弹出这个界面，那么可以从Main函数入手。

可以直接导出整个工程，用VS2010打开以后查找，这算比较快的方法，当然也可以根据经验自己在工程类中查找。

![](../Images/984887f6b98abb79006e9acefb81c722.png)

查看代码有 LicenseManager.Validate(typeof(Class40)); 方法，从字面意思就可以推断出是授权控制，直接IL删除以后，成功去掉50次限制。

![](../Images/a6b9edf76dca75f9895c85f6da35397e.png)

关于怎么精确定位删除位置，可以看看特征变量，特征类，比如这里有一个特征是Class40，可以很快定位到删除位置。

4.30分钟自动退出暗装

![](../Images/0155d545d4b6cb20e3aebbb134059861.png)

1、观察到界面会同步更新时间，直接在Reflector里面搜索字符串 “运行时间”。

![](../Images/653e02a800407bf5eded27c3fd209348.png)

  
  

![](../Images/91a4da54e65784e498ad71bf606f2f13.png)

第一处：

 这里不太好改，可以直接把退出代码删掉即可，修改好如下：

![](../Images/25f71f1a7155e6f0b0471edb950ed2b4.png)

第二处：

(!Class4.bool\_0 && (totalMin >= Class31.fAnOoPvqyf.LimitExitTime))

Class4.bool\_0 前面已经修改好了返回True

Class31.fAnOoPvqyf.LimitExitTime 改成一个返回无限大的时间就不会触发。

  

![](../Images/208f5f37f0b080073f54fd029d519198.png)

IL直接诶修改

![](../Images/25763701498dbac7658127fc828bfd0a.png)

  

第三处：

if (((totalMin % 30) == 0) && !Class31.smethod\_4())

 {

 base.Invoke(new Delegate26(this.ExitApp), new object\[\] { false });

 }

退出条件为①30分钟的整数倍，②Class31.smethod\_4() 返回False

比较好的修改方法为直接修改Class31.smethod\_4() ，使其一直反回True即可。
