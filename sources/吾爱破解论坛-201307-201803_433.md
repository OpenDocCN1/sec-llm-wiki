活动背景

**** ||   
 ||   
 |
| 吾爱破解论坛至今成立已有6 年8个月3周1天，吾爱破解论坛是一个致力于软件安全与病毒分析的非营利性技术论坛在此期间产生了无数技术牛人，例如：Peace、Hmily、Shark恒、小生我怕怕、Kido、WillJ、Chief、L4Nce、珈蓝夜雨、ximo等等他们的ID在论坛耳熟能详，前辈们留下了无数的精彩破文以及个人职业破解生涯的经验技巧，陪伴吾爱一起风风雨雨走到了现在同时论坛也有一批即使没有技术、却始终能坚定不移的会员陪伴论坛走到现在，对论坛的热情一直不减，吾爱破解论坛因你们而更精彩故举办此次活动，来收集大家几年来在论坛在论坛的感受，无论你是大牛还是小白，都可以写下您在吾爱这几年的感受感想亦或菜鸟成长之路、或水经验之路、或论坛未来发展之路，一切尽你所想、所思，均可投稿至论坛，一起书写论坛发展史 |
| ****

比赛时间

**** ||   
 ||   
 |
| 从即日起2014年12月5日至2014年12月19日接受投稿，12月20日至12月24日进行评审，25日公布获奖会员及颁发奖励 |
| ****

活动要求

**** ||   
 ||   
 |
| 1.征文大赛可以分为加密解密经验分享，或论坛未来发展、或论坛升级之路、或小白成长历险记、或论坛小故事、或传奇人物传记2.本次吾爱有感征文可以从上边提供的思路出发，大家亦可自行进行主题发挥，但必须能与吾爱论坛挂上勾，具体内容不限，**字数不得少于800字**3.作品不可复制抄袭他人作品，非原创的取消大赛资格，并扣取一定数量的论坛币作为惩罚4.作品内不可含有：(1)危害国家安全、泄露国家机密的内容(2)任何跟国家有关的政治舆论(3)发布侵犯她人权利的图片和文字(4)含有非官方许可的宣传，比如Q号、Q群、个人网页等内容(5)散步法律法规禁止的内容(6)含有色情内容或者低俗内容(7)发表未经他人同意的照片等隐私内容 |
| ****
