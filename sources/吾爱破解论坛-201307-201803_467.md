# \[原创\] MAC软件破解初探—Hopper Disassembler使用

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5Mjc3MDM2Mw==&appmsgid=10017432&itemidx=1&sign=3f4b93196367892de9bfa3de0a5cfb52&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5Mjc3MDM2Mw==&appmsgid=10017432&itemidx=1&sign=3f4b93196367892de9bfa3de0a5cfb52&scene=27#wechat_redirect)

以yangjt大牛的作品为例子，具体移步 http://www.52pojie.cn/thread-226485-1-1.html ，给像我一样的初学者一点帮助。  
向H大和各位52的大牛致敬，跟他们学到了很多东西。  
  
1、MAC系统具体的操作就不再讲解了，下载安装MAC版的虾米音乐，安装完成后如下。  
![](../Images/7516d9a26189818107df9ef989e8a760.png "1.png")   
  
2、鼠标右键虾米音乐，点击进入显示包内容，然后进入Content文件夹——>MacOS文件夹，找到xiami文件  
![](../Images/c5901c0c96fa85d95eba816d353d1582.png "2.png")   
  
  
![](../Images/698a0cd99383a480c7bbb9bfe1fb0414.png "3.png")   
  
3、打开MAC下的反编译软件，就是强大的Hopper Disassembler，静态反编译效果很强，下载地址如下，已经有key，可以升级。http://www.52pojie.cn/forum.php?mod=viewthread&tid=192516  
  
![](../Images/5ad491161d322b281276e2922f55db03.png "4.png")   
  
4、把xiami文件拖入Hopper Disassembler中，可以看到左边栏目中把文件的所有函数和字符都读了出来  
![](../Images/58b6ab76b5205b238ed5842f4033fde9.png "5.png")   
  
5、我们在搜索框里面输入isVIP,选中第一个函数  
![](../Images/04295b8d30d46e87ad96ebbb05eb54dc.png "7.png")   
  
6、（通过阅读函数，或者GDB动态调试方法）（这里我直接反编译yangjt大牛的文件了）知道修改rax为1即可，具体软件操作方法如下  
![](../Images/9b408a304c771b9db09bf1993f58463e.png "8.png")   
后面跟OD一样了，输入需要修改的命令, xor rax,rax  ;  inc rax ;  
![](../Images/a9fb9acfe8e51b57e11db41e45a6ad17.png "9.png")   
  
7、保存文件  
![](../Images/6d647723fd3dfb6731372ea4672936b4.png "10.png")   
保存文件，然后替换原来的xiami文件  
  
8、打包成dmg文件，具体见这里 http://www.cocoachina.com/macdev/tips/2010/0805/1979.html  
  
向52的各位大牛致敬，跟他们学到了很多东西。
