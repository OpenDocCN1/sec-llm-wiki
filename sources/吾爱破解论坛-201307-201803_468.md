# \[原创\] 一枚恶意Android样本的简单分析

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5Mjc3MDM2Mw==&appmsgid=10017432&itemidx=2&sign=f961c2583c86b79252cc2402662b3b1f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5Mjc3MDM2Mw==&appmsgid=10017432&itemidx=2&sign=f961c2583c86b79252cc2402662b3b1f&scene=27#wechat_redirect)

| 1、在权限列表中，可以发现样本拥有诸多可疑权限，如：开机自启动、发送接收短信、打电话等。  
![](../Images/bad5223280e04cd790cbef9dd021f43b.png "图一.png")   
  
2、从AndroidManifest.xml得知，主Activity为：com.GoldDream.pg.PureGirls16  
![](../Images/951c23869feafa6a59fbc40b33f5422e.png "图二.png")   
  
3、在PureGirls16的onCreate方法中，启动了一个服务：zjService  
![](../Images/890deed056e40df3f9995b110b9f8701.png "图三.png")   
  
4、在AndroidManifest.xml也可看到注册了zjService和zjReceiver  
![](../Images/cd2b143cb87c2a80c3a7f1b67513711b.png "图四.png")   
  
5、当接收到短信息时，会记录下短信的时间内容，并保存在zjsms.txt中。  
![](../Images/fd4fce2573ba2c3d32b5f696cfd655f9.png "图五.png")   
  
6、当打、接听电话时，会记录下电话时间和电话号码，并保存在zjphonecall.txt中。  
![](../Images/7ebc939f915dfc8aa426a066ba0560e7.png "图六.png")   
  
7、保存的这些内容不单单保存在本地，还会上传到服务器  
![](../Images/30feb55d89d146c680657a3e11ea7609.png "图七.png")   
  
8、此外，该样本还收集了很多敏感信息，不一一列举了，大家感兴趣可以继续深挖。
