# 0x01 程序详情

本文测试程序版本为`11.0.0.33162`，官网目前只开放12.5版本，但是可以遍历下载ID进行下载【已失效】  
![](../Images/9637e2f340665679457d7eeec48dcee2.png)

  
向日葵为C++编写，使用UPX3.X加壳故此分析前需要进行脱壳处理（github上有UPX项目，可以直接脱）  
![](../Images/0b03e01dee5f63ac1d063456a41df49f.png)  
![](../Images/b03c7eadfdc1110f4ce0780599db0f61.png)  
  

此外向日葵在启动的时候会监听0端口，在Windows中监听0端口会随机监听一个动态高位端口并记录在日志中，（可使用`netsh int ipv4 show dynamicport tcp`查看起始端口），具体在`sub_140E0AAE8`可看到  
![](../Images/da49b9b411712064af1b030ec9676744.png)

  

# 0x02 根据日志找session

根据网上流传的视频，社会孙在发布的视频中有一段疑似session的字符串  
![](../Images/d36787fc20538ad322f105c1ac460c51.png)

  
根据这段疑似`session`的关键字在向日葵一次正常远程的日志中找到了关键字`CID`  
![](../Images/22412d2cd2dc39fe19787c02dc2b30c9.png)  
  

随后载入IDA，对CID关键字进行搜索  
![](../Images/3f7a42d56f3a37e836b6accebfd0e017.png)  
  

找到3个函数存在CID关键字字符串  
`sub_140E20938`、`sub_140E1C954`、`sub_140E1A1F4`  
往上跟发现分别对应接口  
`/cgi-bin/rpc`和`/cgi-bin/login.cgi`  
![](../Images/400c8aa1633857af1c8e28c1b824565a.png)  
  

分析后发现在函数`sub_140E1C954`对应接口功能`/cgi-bin/rpc`中，传入如下参数即可在未授权的情况下获取到有效session

# 0x07检测手段

## 主机层

主机层可通过检测向日葵连接日志中是否存在`ping`、`../`等关键字进行检查是否被入侵  
![](../Images/ac76efeeeabb18275ce31f574d1acaad.png)

  
帐号暴力破解可通过检查事件查看器中的类似日志进行排查  
![](../Images/ce05877d5c917da5ad2382d7c8d0df57.png)  
![](../Images/7a0d1c8986fa0ff9b56f9b0c7e126eb9.png)  
![](../Images/00621da421460217e5290ba8d484d4c2.png)

  

## 网络层

1.  检查高位端口流量中是否存在向日葵指纹特征
    
2.  检查流量中的`URI`是否存在类似`ping../`、`nslookup../`等且`Header`中包含"`Cookie: CID`关键字
