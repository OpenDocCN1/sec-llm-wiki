# 三、代码分析

在IDA中分析，先找到Winmain入口函数

![](../Images/dfa03b2de333a598e3c89d34c1a9b1bf.png)

通过F5生成伪C代码，我们先分析第一段，发现大量重复操作都是将文件的内容移动后,在将文件删除掉，然后进行相应的休眠，猜测是为了恶意代码执行的更为流畅。如下图所示

![](../Images/b66e660f418d06f54df9118866312c0f.png)

![](../Images/ec17cfcc1e0bc38728ee7f9a1dd00556.png)

下如图，判断是否为乌克兰的主机，如果是乌克兰的主机的话就直接退出。之后对一些变量进行了初始化。猜测病毒作者可能是个乌克兰人，亦或者是一种栽赃手段

![](../Images/38d0c29ce09658be66de37ed8899fae7.png)

如下图，Check\_IP\_Get\_GPS\_402960()  这个函数主要是通过http://api.wipmania.com/ 网址来获取当前中招主机所在的地理位置信息，如果是UA也就是乌克兰的话，return 1，不是的话return 0

![](../Images/34da773ffbcbb31956d066946d949a2b.png)

http://api.wipmania.com&#160;是一个判断国家区域的网址，关键字符&#160;UA&#160;是乌克兰的缩写

![](../Images/790a0147d324c9192fb592d278f145aa.png)

如下图，继续往下分析，做了Com库的初始化，同时生成了事件种子，并且获取了CSP密钥容器环境，获取了当前病毒进程的完整路径，并病毒文件名检测是否包含svchost.

# 四、病毒行为

该病毒会判断主机是否为乌克兰的主机，是乌克兰的主机直接退出，不是的话，会关闭微软的安全服务、更新服务、和防火墙服务，并通过预先设定好URI请求恶意资源，本地免杀后执行下载的恶意程序。在根目录下创建文件夹"\_\_ "设置属性系统、只读、隐藏为同时自我复制为DriverMgr.exe，劫持剪切板过滤内容将比特币的地址替换为自己的地址。
