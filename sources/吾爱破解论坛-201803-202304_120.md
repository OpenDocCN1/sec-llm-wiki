## Windows 中等题 2/3

魔改upx，OEP脱掉

输入UID、Key，一堆单字符变换后对比数据

![](../Images/3b86c97fa3e846f3a7342d9945b4a0b6.png)

  

简单看了下变换，分成a\\~z、A\\~Z、其他字符。

规定

*   `v11 = UID % 25`
    
*   `v10`来自函数`sub_401110`
    

有下面处理规则

*   a\\~z：`flag[i] = v10 * (flag[i] - v11 - 97) % 26 + 'a'`
    
*   A~Z：`flag[i] = v10 * (flag[i] - v11 - 65) % 26 + 'A'`
    

        而后`flag[i] += 26`

*   其他字符：不作处理
    

实际上是仿射密码（Affine Cipher），其加解密公式如下

```
 复制代码
 隐藏代码C = (a * P + b) mod 26
P = (a ^ -1 * (C - b)) mod 26
```

具体可以前往Affine cipher - Wikipedia了解
