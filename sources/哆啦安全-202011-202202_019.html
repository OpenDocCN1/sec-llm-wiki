今天介绍的是一款开源windows图形化日志分析工具：LogonTrace

LogonTracer是一款分析 Windows安全日志日志来调查恶意登录的可视化工具。它可以将登录相关事件中主机名（或 IP 地址）和帐户名相关联，并将其显示为图形。这样，就可以看到在哪个帐户登录尝试发生以及使用了哪个主机。因为使用图形化展现，使得在日志取证时直观清晰。

项目地址：

https://github.com/JPCERTCC/LogonTracer

部署方式：

1.源码安装

由于LogonTracer是基于Python编写的，并使用Neo4j作为其数据库，因此采用源码安装配置比较繁琐，而且容易出错，不建议使用该种方式。

2.docker部署（推荐）

该镜像为官方镜像，可以放心使用

拉取镜像 

docker pull jpcertcc/docker-logontracer


由于软件源代码中引用了几个外网链接，在国内可能无法正常访问，从而运行软件报错，各位看官可以自行网上搜索下解决方法，在此不赘述。


启动容器

docker run \

   --detach \

   --publish=7474:7474 --publish=7687:7687 --publish=8080:8080 \

   -e LTHOSTNAME=[IP_Address] \

   jpcertcc/docker-logontracer

3.访问LogonTracer

http://ip:8080

上传日志文件：

启动主界面后，在左下方找到如下按钮，上传日志文件进行分析

上传界面一定要选择时区，否则会报错，上传解析完成后点击close按钮，再刷新下网页就可以查看各项分析结果了。


左侧功能列表对应的是各项登录类型，点击后会使用图形化连线展示账户与计算机之间的关系，连线上的数字代表登录类型。


点中账户或计算机名还可查看详细信息，下方的search可跳转到与计算机或域名相关的关系图。


在主界面的右边按登录次数列出了用户名与主机名或IP地址。

时间线功能可以展示每个账号在制定日期段的登录次数，通过时间线可以很方便的查看每个账号的登录历史，过滤出有问题的账号，以便进一步分析。
