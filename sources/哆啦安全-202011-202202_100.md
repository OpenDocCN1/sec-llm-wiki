**第一种方式：通过 Android Studio 默认的方式**

**1\. 创建带有 native 方法的类，build 项目**

  

环境：Android Studio 3.0 Canary 1 ， 下载并配置 NDK 。

  

![](../Images/5e833221af0b888a3ef7a0a08700e678.png)  

  

![](../Images/828e4268f1d87f344f6b0a5567da4950.png)

  

![](../Images/4ba6e17f8dba299d19b36c22a45ca135.png)

  

![](../Images/0678a3649fc8b38828748422da39a2c6.png)

  

**2. 生成与类名相关的 .h 文件**

进入 app -> build -> intermediates -> classes -> debug 目录下执行：javah com.haohao.hellojni.MyJNI（先配置好 JDK 的环境变量）,生成 com\_haohao\_hellojni\_MyJNI.h 文件

  

![](../Images/a5323ba57aeca74231a657d6fd7bd692.png)

  

**3\. 创建 C++ 文件**

在 main 文件夹下，新建 jni 目录，剪切 .h 文件到 jni 目录下，创建 hello.cpp 文件

  

![](../Images/a608695bedb86ded87360682395012d9.png)

  

hello.cpp

  

![](../Images/68a026391e5b917409f6c2f52b71714b.png)

  

**4\. 配置 build.gradle 文件**

修改 app / build.gradle 文件， muduleName 为引入的 .so name , 直接运行项目，安装 apk ，运行就 OK 了。

  

![](../Images/347936af656ec957298dc3a95576ff0f.png)

  

生成的 .so 文件位置

  

![](../Images/bb7b972a6520ea36731c58af9856f596.png)

  

PS：未指定 CPU 框架时，AS 会生成支持所有 CPU 框架的 .so 文件。

  

**第二种方式：通过 ndk-build**

**1. 创建 Android.mk 和 Application.mk 文件**

新建一个项目，在 app 目录下（任目录下都可以）新建 jni 文件，添加 Android.mk 和 Application.mk 文件，以及 com\_haohao\_hellojni\_MyJNI.h 文件（运用上一小节的方法生成）。

  

Android.mk

  

![](../Images/d4f8ee780c4e954ef3b7de093bddbe4a.png)

  

Application.mk

  

![](../Images/6a2afbc0954503ed1fbc5ed1c171bf06.png)

  

在 jni 目录下（配置好NDK环境变量）直接执行 ndk-build ， 生成 .so 文件。

  

![](../Images/8e55d617373788f71faf09bceedeccf2.png)

  

![](../Images/a3546477b58e9948f29f8b5fe6118eef.png)

  

**2\. 配置项目工程**

在 main 目录下新建 jniLibs 目录，并拷贝 armeabi arm64-v8a armeabi-v7a 文件夹，运行 proj 。

  

![](../Images/ab0a20761a5d80c267c20e2c07c1b956.png)

  

**第三种方式：通过 CMake 工具**

从 Android Studio 2.2 开始，就默认使用 CMake 工具构建 NDK 项目，请确保你的 AS 版本大于 2.2 。

  

**1. 通过 IDE 自动构建**

创建项目时，勾选 Include C++ support 。

  

![](../Images/d0cee799187abb85790d0a520b0f2263.png)

  

选择默认的 Toolchain Default 。

  

![](../Images/c0b6cba10ad2cfe35b557d59a1b3117b.png)

  

AS 自动生成 CMakeLists.txt 文件（CMake 构建脚本）。

  

![](../Images/51182d566b23abcf448ee54f16acf44c.png)

  

![](../Images/4fe6d617a8ed2fbaf9cc0394257830cf.png)

  

CMakeLists.txt

  

![](../Images/a795a657c752fbe1ff28fa993e9eedd7.png)

![](../Images/686b7e46a4973081fc2859c46d3f1087.png)

  

再配置 app/build.gradle ，针对特殊平台 abiFilters 。配置完成之后，同步，运行。

  

![](../Images/9f1e13ee0ef92293dc73e2beacd27656.png)

  

**2\. 手动构建**

新建一个工程，创建 native 类，快捷键 Alt + Enter ,自动创建 jni 目录和相应的 .cpp 文件。

  

![](../Images/a07dfde02a446c41a758d720cec66a3d.png)

  

native-lib.cpp

  

![](../Images/4044f392df64b81da67fb5847681e17d.png)

  

在工程根目录下创建 CMakeLists.txt 文件。

  

![](../Images/6c48a5bf3055f76755d92dc49456bc41.png)

  

选择 app modulde ，右击选择 Link C++ Project with Gradle。

  

![](../Images/fe6516f73fa19ed560583ab3845cdd33.png)

  

选择脚本文件的路径。

  

![](../Images/06f48225c7b0b270740a321928318a4a.png)

  

app/build.gradle 会自动同步。同步完成后，运行项目。

  

![](../Images/693fde66e2147965b4e7af774968a261.png)
