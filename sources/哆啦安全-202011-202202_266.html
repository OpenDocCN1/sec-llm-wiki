0x00 简介

域就是将多台计算机在逻辑上组织到一起，进行集中管理，也就是创建域控制器上的组，将组的账户信息保存在活动目录中。域组可以用来控制域内任何一台计算机资源的访问和执行系统的权限。域是组织和存储资源的核心管理单元，域的核心是域控制器，域控制器的核心是活动目录，活动目录实质上相当于一个数据库。如果要学习内网知识，就需要在本地搭建一个复杂的域环境，用以测试内网中的各种攻击手法，本文将详细描述如何搭建一个基础的域环境。

0x01 环境准备

虚拟机：VMware Fusion系统：windows 7 、windows 10 、windows server 2012

0x02 设置静态IP

在创建域之前，需要给每一台主机设置一个静态IP。cmd -> ipconfig/all 查看当前的IP

ipv4地址、默认网关、dns服务器是我们所需要的，在我的电脑右下角网络接口图标点击，打开网络和共享中心 -> 更改适配器

选择网络接口 -> 属性(右键) -> Internet协议版本4 -> 属性

填写上面ipconfig命令得出的信息。

现在同时需要在windows 7 windows 10两台主机上安装同样的方式，查看 ipv4地址、默认网关、dns服务器。注意：由于win7和win10作为域中的成员主机，所以要设置首选dns服务器为windows servier 2012的ip地址。也就是域控的地址。

0x03 安装域

在windows server 2012虚拟机上安装域。计算机重命名为howe7,我的电脑 -> 属性 -> 更改设置 -> 计算机名(howe7) -> 重启

暂时不要立即启动重启，现在需要取消ctrl+alt+dalete组合键。

找到开始 -> 运行输入(gpedit.msc) ，进入组策略编辑器

打开组策略编辑器之后，依次找到 计算机配置--安全设置--- 安全选项，找到“交互式登陆，不需要按 ctrl+alt+delete”

点击打开“交互式登陆，不需要按 ctrl+alt+delete”选择设置为“已启用”

设置好之后，再次返回确认一下。

输入gpupdate /force命令，刷新一下组策略规则。

重启后点击添加角色和功能

点击下一步

默认(基于角色或基于功能的安装)，点击下一步

默认(从服务器池中选择服务器)，点击下一步

勾选Active Directory 域服务，点击下一步，弹出窗口，点击添加功能

默认就行了，点击下一步

继续点击下一步

点击安装，安装完成后，点击将此服务器提升为域控制器

选择添加新林，设置根域名为howe7.local，这里最好不要填外网有的域名，不然容易出错，点击下一步

输入还原模式密码(Qwe666666)，这个密码可以与 Administrator 账号密码不一致

使用默认，点击下一步

使用默认，点击下一步

点击下一步

出现问题，解决方案如下：打开 -> 运行输入(control) ->打开控制面板

用户账户 -> 配置高级用户配置文件属性 -> 点击要创建新的用户账户,点击此处

点击用户 -> Administrators -> 右键设置密码 -> 弹出窗口点击继续

设置密码(QWe666666)，点击继续

回到先决条件检查那里，点击上一步，再点击下一步，点击安装，安装完后系统户重启，耐心等待

重启后，在输入账户处。可以看到账户名称已经发现了改变，变成了HOWE70/HOWE-7 ,这是域账号的登录模式，要登录一个域，需要在账号前面加上域名称和斜杠。输入密码登录系统。如果要登录本地账号，则需要输入.\administrator来登录。密码(666666)

登录后可以看到多了个AD DS和DNS服务

查看IP,看到首选DNS服务器已经变成了127.0.0.1 ,也就是域控制器自己。如果需要上网，可以把备用DNS服务器设置成之前多值。

成功安装howe7.local域。

0x04 加入域

创建好域后，需要将另外两台主机加入到域中。

  • windows 7 

右键计算机 ->属性 -> 更改设置 -> 点击更改

计算机名填howe77 ，隶属于howe7.local域

点击确定后会要求输入howe7.local域的域管理员密码，也就是windows server 2012上的administrator账号的密码。

点击确定，成功加入域，点击确定重启。

成功加入域

  • windows 10

使用同样的步骤，把win 10加入到域中，计算机命名为howe777

现在可以去DC上查看新加入的计算机了，打开windows server 12，点击左下角的window键 -> 点击管理工具 ->双击Active Directory 用户和计算机

点击howe7.local，点击Computers，可以看到域中已经添加了两台计算机，分别是HOWE77和HOWE777。

加入域后，还需要有域账号才能登录域。在howe7.local里创建两个组，分别为A组和B组。howe7.local -> 右键新建 -> 组织单位

创建A组，使用同样的方式创建B组

在A组中，右键新建 -> 用户 -> 输入用户登录名，下一步

设置一个密码(Qwe666666)，为了以后方便，这里选择密码永不过期

点击下一步，完成。

创建完用户后，到win7上登录howe账号，点击切换用户 -> 输入HOWE70\howe作为账号，以及密码(Qwe666666)

成功登录到howe7.local域中

同样的方式，使用howe账号登录到window 10中

使用cmd运行，执行以下命令查看一些信息

//查看域内用户net user /domain//查看域管理员net group "domain admins" /domain

注：给win 7 、win 10 、windows server 12 保存快照。
