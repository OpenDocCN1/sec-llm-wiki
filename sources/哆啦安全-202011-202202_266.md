0x00 简介  

域就是将多台计算机在逻辑上组织到一起，进行集中管理，也就是创建域控制器上的组，将组的账户信息保存在活动目录中。域组可以用来控制域内任何一台计算机资源的访问和执行系统的权限。域是组织和存储资源的核心管理单元，域的核心是域控制器，域控制器的核心是活动目录，活动目录实质上相当于一个数据库。如果要学习内网知识，就需要在本地搭建一个复杂的域环境，用以测试内网中的各种攻击手法，本文将详细描述如何搭建一个基础的域环境。

## 0x02 设置静态IP

在创建域之前，需要给每一台主机设置一个静态IP。cmd -> ipconfig/all 查看当前的IP

![](../Images/0ffc3d692b7ded2515128489a6c171df.png)

![](../Images/5b02425b89e17ddcc050a20e1f51697b.png)

选择网络接口 -> 属性(右键) -> Internet协议版本4 -> 属性

![](../Images/eda60d598693c2a7687904f3edaa1c11.png)

填写上面ipconfig命令得出的信息。

![](../Images/eb0128e1054a1c3ff83a7c18643645c4.png)

现在同时需要在windows 7 windows 10两台主机上安装同样的方式，查看 ipv4地址、默认网关、dns服务器。注意：由于win7和win10作为域中的成员主机，所以要设置首选dns服务器为windows servier 2012的ip地址。也就是域控的地址。

## 0x04 加入域

创建好域后，需要将另外两台主机加入到域中。

*   windows 7 
    

右键计算机 ->属性 -> 更改设置 -> 点击更改

![](../Images/46416053aa916bb496f17030aeea453d.png)

计算机名填howe77 ，隶属于howe7.local域

![](../Images/a0ec85448cf58db043f0ce7210349439.png)

点击确定后会要求输入howe7.local域的域管理员密码，也就是windows server 2012上的administrator账号的密码。

![](../Images/baf4f7487d2c36674dd5ae827adcb970.png)

点击确定，成功加入域，点击确定重启。

![](../Images/58f4e733fcd90130f0b21e2a97db0db8.png)

成功加入域

![](../Images/8cff4c4eb86f75294be7732c9fa1cbdc.png)
