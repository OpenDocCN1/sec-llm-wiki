> ❝
> 
> 唯一需要修改一下的就是框架的登陆是MD5验证的，所以当你添加MyUser之前，记得加上一句Entity.Password = Utils.GetMD5String(Entity.Password);把密码MD5加密一下

## 3、控制器Action拦截日志，能只记录异常日志吗？

生成框架代码时，未勾选只记录异常日志，那么框架会将Action的每次调用都记录入库：

![](../Images/135708f0f5ec77c2ef9b7ff1a197291b.png)

Action记录日志

实际项目上，没必要记录这么详细，只记录Information日志或者异常日志即可，记太多不方便查找，也占数据库空间，怎么修改呢？原文档中建议修改`appsettings.json`的`LogExceptionOnly`属性即可，实际操作时不生效的。

```

LogExceptionOnly：当启用日志时，是否只记录异常
```

这个时候，站长又厚着脸皮在`DotNet Core WTM 交流群`【694148336】**求解，谢谢开源框架WTM作者，也是群主`刘亮`大大解惑。

框架升级很及时，可能文档还未更新，现在实现上面的需求只需要像下面截图中修改即可：

![](../Images/6946e3eccb4de663e5c2c7057c70adab.png)

修改WTM一节
