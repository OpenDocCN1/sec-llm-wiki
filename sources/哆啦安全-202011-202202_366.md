# 基础篇

     俗话说得好：万丈高楼平地起，这句话说的就是基础的重要性。我们锻炼跑步同样如此。

     几年前因为一份热情和好奇，我就开始了我的跑步之旅，事先没有任何的热身我就凭激情就徜徉在跑步的路上，当然也没有了解，也没有热身的这一概念，就是传说中的小白一个，第一次我就给自己定了10公里的目标，凭着热情我完成了既定目标，但是休息了一个星期才恢复，腿还差点废了，情况很严重，但是自己却浑然不知，后来又过了很久才偶然得知要热身不然容易受伤的道理，所以走了不少弯路。

![](../Images/00e835f2c360a3a7a9a5128439267eb8.png)

      所以本期要讲的就是基础，而所谓的基础就是热身，不管你是要锻炼还是要去跑步，都别忘了去之前记得热身，让身体先热起来，能避免受伤，也可以让锻炼的效果更佳。

        小白的路上很苦，因为什么都需要去摸索去发现，去总结，希望你少走弯路，多锻炼，多跑步，拥有完美身材，拥有健康的体魄。加油，锻炼人！
