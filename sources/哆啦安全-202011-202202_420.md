sudo apt update  

sudo apt install software-properties-common

sudo add-apt-repository ppa:deadsnakes/ppa

sudo apt install python3.9

python3.9 --version

sudo update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.6 1

sudo update-alternatives --config python3

**ModuleNotFoundError: No module named 'apt\_pkg'问题的解决方法**

cd /usr/lib/python3/dist-packages/

sudo ln -s apt\_pkg.cpython-36m-x86\_64-linux-gnu.so apt\_pkg.so

**如果报apt\_pkg.so已存在，则使用命令**

sudo ln -fs apt\_pkg.cpython-36m-x86\_64-linux-gnu.so apt\_pkg.so
