1.解锁

解压unlocker压缩包，并关闭VMware所有进程，且以管理员身份运行脚本文件


管理员身份运行win-install.cmd脚本后在VMware中会有Apple Mac Os选项




2.修改配置

(1).修改Mac OS X 10.10.vmx或Mac OS X 10.11.1.vmx的配置，找到guestOS的配置在下面添加如下配置

keyboard.vusb.enable = "TRUE"mouse.vusb.enable = "TRUE"




(2).并且继续找到smc.present = "TRUE"，在下方添加smc.version = "0"，为了防止出现开机时报错的问题

smc.version = "0"


(3).USB控制器，USB兼容性设置USB2.0
