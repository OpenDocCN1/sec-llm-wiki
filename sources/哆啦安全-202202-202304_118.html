Linux环境运行.sh出现Syntax error:"fi"unexpected(expecting "then")解决方案

问题原因

由于.sh文件是dos格式文件，但是Linux的shell需要unix格式的文件


解决方案

先转换dos格式为unix格式，再执行sh

sudo apt-get install dos2unixdos2unix <filename>dos2unix *
