# Linux环境运行.sh出现Syntax error:"fi"unexpected(expecting "then")解决方案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NzUzNzk1Mw==&mid=2247494615&idx=2&sn=3b034728282e0f47f10e55a24df3d0c8&chksm=ceb8ae99f9cf278fa0e4be42be55ac70877b75e5d2b6e6984fb4616282306e2a57e1af143601&scene=126&sessionid=1681666690#rd](http://mp.weixin.qq.com/s?__biz=Mzg2NzUzNzk1Mw==&mid=2247494615&idx=2&sn=3b034728282e0f47f10e55a24df3d0c8&chksm=ceb8ae99f9cf278fa0e4be42be55ac70877b75e5d2b6e6984fb4616282306e2a57e1af143601&scene=126&sessionid=1681666690#rd)

**问题原因**

由于.sh文件是dos格式文件，但是Linux的shell需要unix格式的文件

  

**解决方案**

先转换dos格式为unix格式，再执行sh

*   
*   
*   

```
sudo apt-get install dos2unixdos2unix <filename>dos2unix *
```
