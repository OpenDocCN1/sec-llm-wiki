系统采用：CentOS7.6

优势

出众的管理面板，能够轻易实现邮件收发、多域名控制、邮箱容量控制、邮件杀毒、邮件过滤以及Webmail等基础功能。

提供了投递统计分析、客户端自动适配、一键安装SSL证书、邮件转发、邮件别名、Catch-All等相当有用的功能。

Poste邮件服务器基于Docker搭建，搭建过程比较方便。

包含的组件：

SMTP + IMAP + POP3 + Antispam + AntivirusWeb administration + Web email

安装docker

安装yum-utils软件包（提供yum-config-manager 实用程序）并设置稳定的存储库。

$ sudo yum install -y yum-utils

$ sudo yum-config-manager \
    --add-repo \
    https://download.docker.com/linux/centos/docker-ce.
#阿里云镜像

 yum-config-manager --add-repo http://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo

修改hostname

首先，需要编辑/etc/hosts文件，找到含有你的VPS的IP地址的那一行；如果没有，则添加一行。内容如下：

xx.xx.xx.xx    mail.xxxx.com    mail

编辑好后，在SSH中执行：

echo "mail" > /etc/hostname
hostname -F /etc/hostname

这样，就设置好了主机名。

使用hostname 和hostname -f 来进行测试

安装poste

docker run \
    -p 25:25 \
    -p 80:80 \
    -p 110:110 \
    -p 143:143 \
    -p 443:443 \
    -p 587:587 \
    -p 993:993 \
    -p 995:995 \
    -v /etc/localtime:/etc/localtime:ro \
    -v /opt/poste/data:/data \
    --name "sometimesnaive" \
    -h "mail.xxxxx.com" \
    -t analogic/poste.io

等待10分钟左右，跑起来后。
