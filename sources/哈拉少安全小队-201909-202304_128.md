# 1\. 介绍

http://rustdesk.com/zh/

`RustDesk`是一款开源远程桌面软件，优点是普通权限即可运行，而且支持纯内网环境，可以讲就是一个远控。

![](../Images/5e2945287449839defe33801391a24e6.png "null")

# 2\. rustdesk优缺点

rustdesk的优点是普通权限即可运行，而且支持纯内网环境。

RuskDesk控制端和被控制端是同一个应用。

>   
> 
> 根据师傅踩坑来看，有两个比较大的坑：
> 
> *   • 要下载RustDesk的portable版本，不要下载puts版本。portable版本免安装，puts版本会弹框提示安装，portable免安装版本下载地址：https://gitee.com/rustdesk/rustdesk/releases
>     
> *     
>     
> *   • 第一次在目标上运行RustDesk，RustDesk不会立即将密码保存到配置文件，而此时你把鼠标放在显示密码时则会保存到文件，遇到这种情况我们只需运行RustDesk，生成配置文件后结束RustDesk进程，然后修改配置文件里password为指定密码，再运行RustDesk即可。
>

# 4\. rustdesk自建ip

在内网里面，如果不出网等，只有`webshell`权限，在这个时候就需要这个功能了。

![](../Images/d0b17855080b42050e6baa1dcd5b67d0.png "null")

## 4.1 本地修改

在win7本地修改`RustDesk2.toml`文件：

![](../Images/5e61708b824181651e0db2f715393d6e.png "null")![](../Images/e6637f094655b2814821883d21a7fe8f.png "null")

在`options`下增加一句话：

```
direct-server = 'Y'
```

保存该文件，并且重启本地的rustdesk：

![](../Images/38a2df5eb038bc57d66f818fd0040da1.png "null")

此时就可以允许ip直接访问了，在这里还可以自定义被访问时候的端口：

![](../Images/f427acf278adef532f9d941cdc1f2230.png "null")

  

RustDesk的实现IP直接访问功能监听的默认端口是21118，此时在本地可以通过鼠标修改为其他端口：

![](../Images/a4cb154f42c37d1143cd57660dbeaca7.png "null")

  

如果在靶机上，是不可能通过这种方式来修改的，所以还需要去看下配置文件：

![](../Images/16ad8cfbe42aba2eb9303f33983bded4.png "null")

在我们修改默认端口之后，在这里会多出来一行：

```
direct-access-port = '8080'
```

## 4.2 靶机修改

同样，这种方法可以适配到靶机上，同样的步骤，先关掉`rustdesk`的进程，然后修改配置文件，再启动`rustdesk`：

![](../Images/8f9ad70e675d90d2410e09be62c7cd6b.png "null")

将下面的信息写上去，端口自定义：

```

direct-server = 'Y'
```

![](../Images/34c0171a3d35c018a041152a04a242b7.png "null")

此时再启动rustdesk，用win7来连接下：

![](../Images/c4d1c2468a272a7b820ebe52fdfa6858.png "null")

再输入密码即可：

![](../Images/446f57e7d4977985666f5a1d051155ee.png "null")
