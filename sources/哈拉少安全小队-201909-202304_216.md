### Weblogic后台部署War包

 对于我这个不懂Weblogc架构的人来说很多时候实战遇到Weblogc写Shell都是一个问题，很多时候写完了访问不了，所以一般都依靠Console控制台来解决部署Shell，于是本地复现记录下来此篇文章。

* * *

我这里复现的版本是 12.2.1.3.0，如果是 10.3.6(11g) 可参考文章

https://blog.csdn.net/weixin\_39190897/article/details/107332742

* * *

这里我是用vulhub进行搭建，用来复现漏洞非常方便。

```
cd /home/ubuntu/vulhub/weblogic/CVE-2018-2894
docker-compose up -d
```

耐心等待docker拉取镜像完成，这里启动的话默认是7001端口，如果要修改的话直接修改 `docker-compose.yml` 文件即可。

*   
*   

```
默认后台用户名为weblogic,使用如下命令获取随机密码docker-compose logs | grep password
```

![](../Images/cf543786f0cd91bc9d63ab2d8ec6de4f.png)

等待启动后，访问 ip:7001 路径后面加 Console 会跳转到控制台登录页面。

![](../Images/6191b1fbeec2ba1421a5bbba1c74ab0d.png)

使用默认用户名和获取到的密码登录控制台。

![](../Images/d7d0b8561952d8192b62b4ad86cafa4b.png)

首先制作一个 War 木马文件，制作方法：准备一个 Webshell，将其压缩为 zip，然后重命名为 war后缀文件。

开始部署，点击部署 --> 安装。

  

![](../Images/6e53054935a1b7c518aaab7762a10417.png)

点击页面上的上载文件。

![](../Images/dc8df3408b89dabdea167c32039c31b2.png)

上传我们只做好的war包，点击下一步。

![](../Images/0c03225665656cb37d095f05dab50688.png)

然后再点击下一步，这里注意要点击上面的下一步，不要点错了。

![](../Images/b61cda29e85fbb6db68cadfe5d1216aa.png)

点击下一步，完成。

![](../Images/2a325611a6a0fa548a95fa2f6ac8e758.png)

![](../Images/949c17fdf2a3ad925a941569c92b81cd.png)

然后就可以访问了shell了。

![](../Images/d175ec03b170accb3f85926964fac480.png)
