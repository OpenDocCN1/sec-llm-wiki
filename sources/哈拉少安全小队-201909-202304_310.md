**材料准备：**  
burp suite、模拟器(把微信装好)、node.js、wxappUnpacker、root explorer  
  
**操作流程：**  
步骤1: 配置Burp和模拟器（模拟器需导入ca证书），打开模拟器的WLAN-->高级设置-->输入物理机的ip以及一个没被占用的端口，Burp用于代理该端口  
  
![](../Images/32bfdfa97732993683558bfdd5d8fc27.png "点击查看原图")  
  
  
步骤2：打开微信-->随便点击一个小程序进入小程序主界面，然后打开文件管理器  
  
![](../Images/15003a3c728757cd779d5cd5427c7535.png "点击查看原图")  
  
在/data/data/com.tencent.mm/MicroMsg/xxxxxxx(不同微信文件夹也不同)/appbrand/pkg/目录下存放着刚才访问这个小程序的两个数据包，  
![](../Images/380c935b1844290bd5739fedac6e6de9.png "点击查看原图")  
  
两个包分为子包和主包   
压缩后通过模拟器的微信发送到物理机进行反编译  
![](../Images/8f9fe78ae8644cebcb6d2a79b7289994.png "点击查看原图")  
  
可以直接用notepad++ 但是会有乱码，这里使用git下载的wxappUnpacker进行反编译  
CMD进入wxappUnpacker的下载目录，安装依赖包  

Shell

```
1.  npm install esprima
    
2.  npm install css\-tree
    
3.  npm install cssbeautify
    
4.  npm install vm2
    
5.  npm install uglify\-es
    
6.  npm install js\-beautify 
    
```

 复制 文本

  
![](../Images/e695f2eb1dd49ecd48e614dde62b8e2c.png "点击查看原图")  
  
依赖包安装好后 使用命令node wuWxapkg.js C:\\xxxxxx\\xxxxxx\\\_-1971317095\_1.wxapkg  
进行反编译(如果是子包的话需要加-s参数)  
![](../Images/fa9320a5a10b916354d806d3d6fbc200.png "点击查看原图")  
  
反编译完成  
接下来就是针对所有js、html进行漏洞分析，寻找突破口  
![](../Images/8f3ac124ac7ce5fa11562937410c8481.png "点击查看原图")![](../Images/eabb70da1d2cd58f582d6dbf6d0abb0c.png "点击查看原图")  
  
通过简单的信息收集得知该小程序是windows+iis7.5+.net+mssql  
80、443、3389端口开启  
且程序采用了svc接口  
  
从js中得到一个接口用于判断手机号是否注册  
![](../Images/1e080aa903c5ba11544736b47bf7fa5e.png "点击查看原图")  
  
通过单引号 和 '--（单引号+mssql闭合） 发现返回包不同   
  
使用单个单引号 报错:系统故障  
![](../Images/0eee02938446b5620a58695913fe4fea.png "点击查看原图")  
  
  
使用 单引号跟闭合 返回正确数据包  因此判断该处通过单引号闭合  
  
![](../Images/d00584b48425c819649042880802c96d.png "点击查看原图")  
  
最后验证存在SQL注入  
  
![](../Images/bf37b070ee673aa1cfd3374c9aec6fd6.png "点击查看原图")  
  
注入点权限很小 --os-shell权限为iis  
且注入点只能布尔和延迟，列目录写shell属实浪费时间  
通过子域名扫描得到后台一枚，且发现该程序居然还是一个通用系统。。  
![](../Images/b5726aef590a04ef0f5021f73ffdf6ef.png "点击查看原图")![](../Images/5c529e88e7b7f7d0405dc5b461d09346.png "点击查看原图")  
  
通过注入点拿到后台账号密码后 就是常规的渗透思路了，本文着重于微信公众号的反编译(最后好像有点跑题)，有不足之处希望评论区留言指正，反正我也不会改的
