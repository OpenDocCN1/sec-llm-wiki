 sql注入的原理就是把前端的恶意代码插入到后端的数据库中并执行，违背了数据与代码分离的原则，存储账号密码的时候也都会存储到数据库中，而我们去登录的时候后端代码会去连接数据库去查看是否有这个账号

select * from user whereusername='$name'and pass='$pass'


 name就是账号名字，pass就是密码 

 我们在页面输入账号密码后后端的sql语句会去验证输入的账号密码

select * from admin where `username` ='$name' and `password` = '$pass'

如果我们在输入账号的时候改为name' or 1=1 # 前提是有name这个账号 这时候后端的代码就会是

select * from admin where `username` ='name' or 1=1 #' `password`= ''


后面的代码会被执行掉 所以我们密码不管输入什么都可以登录。
