##01漏洞描述  
  
CVE\_2017\_7269漏洞属于高危漏洞，是由Zhiniang Peng和Chen Wu发现的。IIS6.0开启Webdav服务的服务器被爆存在缓存区溢出漏洞导致远程代码随意执行，目前针对 Windows Server 2003 R2可以稳定利用。

  

下面开始复现cve\_2017\_7269 漏洞并拿下windows 2003 R2权限并远程登录服务器：
