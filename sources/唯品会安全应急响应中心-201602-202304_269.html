漏洞背景介绍


Atlassian Confluence是澳大利亚Atlassian公司的一套专业的企业知识管理与协同软件，也可以用于构建企业WiKi。该软件可实现团队成员之间的协作和知识共享。

Atlassian Confluence 5.8.17之前版本中存在安全，该漏洞源于spaces/viewdefaultdecorator.action和admin/viewdefaultdecorator.action两个文件没有充分过滤decoratorName参数。远程攻击者可利用该漏洞读取配置文件。

描述信息请参考：https://nvd.nist.gov/vuln/detail/CVE-2015-8399

祖传修复指导


由于某些众所周知的原因，我在测试环境的这款产品无法通过官方渠道升级，所以只能靠这点祖传的手艺来修复了了。大概思路路如下：

1. 找到关键 Jar 文件

2. 反编译 Jar 包，找到class，导出为 Java

3. 重新编译 Java 文件为 class

4. 重打包 Jar 文件

5. 覆盖旧的 Jar

6. 重启服务



1
下载原始安装包


下载5.8.10原始文件

https://downloads.atlassian.com/software/confluence/downloads/atlassian-confluence-5.8.10-x64.bin

根据官方文档提示安装，并得到文件目录/opt/atlassian/confluence/。



2
反编译核心文件confluence-5.8.10.jar


导出文件：/opt/atlassian/confluence/confluence/WEB-INF/lib/confluence-5.8.10.jar

通过反编译工具 Luyten 打开该 Jar 文件进行反编译。



3
导出两个类文件


通过Luyten浏览到 com.atlassian.confluence.admin.actions.lookandfeel，分别导出其中的AbstractDecoratorAction.class 和 ViewDefaultDecoratorAction.class 为 AbstractDecoratorAction.java 和 ViewDefaultDecoratorAction.java 。



4
分别修改代码，进行文件后缀检查


修改源代码实现：只允许访问 .vm 和 .vmd 两种模板文件。

AbstractDecoratorAction.java

ViewDefaultDecoratorAction.java


5
安装JDK1.8


略过。


6
重编译补丁Java文件

逐个重编译 AbstractDecoratorAction.java 和 ViewDefaultDecoratorAction.java。

得到两个 class 文件： AbstractDecoratorAction.class 和 ViewDefaultDecoratorAction.class。



7
重打包Jar文件


解压缩confluence-5.8.10.jar到 /tmp文件夹，将刚刚重新编译生成的文件 AbstractDecoratorAction.class 和 ViewDefaultDecoratorAction.class 覆盖文件到目录 /tmp/confluence-5.8.10/com/atlassian/confluence/admin/actions/lookandfeel/进入文件夹 confluence-5.8.10 重打包生成 confluence-5.8.10.jar 。



8
替换补丁文件


备份原始文件 /opt/atlassian/confluence/confluence/WEB-INF/lib/confluence-5.8.10.jar 为 /opt/atlassian/confluence/confluence/WEB-INF/lib/confluence-5.8.10.jar.bak 。复制 /tmp/confluence-5.8.10confluence-5.8.10.jar 到 /opt/atlassian/confluence/confluence/WEB-INF/lib/ 目录，实现补丁文件更新。
