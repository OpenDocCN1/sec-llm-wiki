漏洞表现

  

访问下面这个 URL，你就能看到一些神奇的内容。你还可以发挥想象力，优化decoratorName参数，看到更多少儿不宜的内容。

**http://example.com/spaces/viewdefaultdecorator.action?decoratorName=file:///etc/passwd**

![](../Images/987d6fe75faeb74d752b721ea17b196e.png)

  

  

  

漏洞背景介绍

  

Atlassian Confluence是澳大利亚Atlassian公司的一套专业的企业知识管理与协同软件，也可以用于构建企业WiKi。该软件可实现团队成员之间的协作和知识共享。

Atlassian Confluence 5.8.17之前版本中存在安全，该漏洞源于**spaces/viewdefaultdecorator.action和admin/viewdefaultdecorator.action**两个文件没有充分过滤decoratorName参数。远程攻击者可利用该漏洞读取配置文件。

描述信息请参考：https://nvd.nist.gov/vuln/detail/CVE-2015-8399

  

  

漏洞PoC

  

  

http://example.com/spaces/viewdefaultdecorator.action?decoratorName=file:///etc/passwd

  

  

官方修复建议

  

升级到最新版（合法姿势）

  

  

祖传修复指导

  

由于某些众所周知的原因，我在测试环境的这款产品无法通过官方渠道升级，所以只能靠这点祖传的手艺来修复了了。大概思路路如下：

1\. 找到关键 Jar 文件

2\. 反编译 Jar 包，找到class，导出为 Java

3\. 重新编译 Java 文件为 class

4\. 重打包 Jar 文件

5\. 覆盖旧的 Jar

6\. 重启服务

  

  

1下载原始安装包

  

下载5.8.10原始文件

**https://downloads.atlassian.com/software/confluence/downloads/atlassian-confluence-5.8.10-x64.bin**

根据官方文档提示安装，并得到文件目录**/opt/atlassian/confluence/**。

  

  

2**反编译核心文件****confluence-5.8.10.jar**

  

导出文件：**/opt/atlassian/confluence/confluence/WEB-INF/lib/confluence-5.8.10.jar**

通过反编译工具 Luyten 打开该 Jar 文件进行反编译。

  

  

3导出两个类文件

  

通过Luyten浏览到 **com.atlassian.confluence.admin.actions.lookandfeel**，分别导出其中的**AbstractDecoratorAction.class **和** ViewDefaultDecoratorAction.class **为 **AbstractDecoratorAction.java **和** ViewDefaultDecoratorAction.java **。

![](../Images/8847b3d4036ab90c2a1bf518f56d7ff9.png)

  

  

4分别修改代码，进行文件后缀检查

  

修改源代码实现：只允许访问 .vm 和 .vmd 两种模板文件。

**AbstractDecoratorAction.java**

![](../Images/f2bb3ef6aad81f5120db50b007fee8a3.png)![](../Images/14fd9b17e8a2cc8316bc05ebf4fe2a4e.png)

**ViewDefaultDecoratorAction.java**![](../Images/d0916dfe34e56b100f8dbfdcda804226.png)

  

5安装JDK1.8

  

略过。

  

6重编译补丁Java文件

逐个重编译 **AbstractDecoratorAction.java** 和 **ViewDefaultDecoratorAction.java。**![](../Images/a509fd75fdd9c43430aa1d6005b6663b.png)

得到两个 class 文件： **AbstractDecoratorAction.class** 和 **ViewDefaultDecoratorAction.class。**

  

  

7重打包Jar文件

  

解压缩confluence-5.8.10.jar到 /tmp文件夹，将刚刚重新编译生成的文件 **AbstractDecoratorAction.class **和 **ViewDefaultDecoratorAction.class** 覆盖文件到目录 **/tmp/confluence-5.8.10/com/atlassian/confluence/admin/actions/lookandfeel/**进入文件夹 **confluence-5.8.10 **重打包生成 **confluence-5.8.10.jar 。**![](../Images/ea6ce8ca2571d9fbbaf434b9cce82981.png)

  

  

8替换补丁文件

  

备份原始文件 **/o****pt/atlassian/confluence/confluence/WEB-INF/lib/confluence-5.8.10.jar**为 **/opt/atlassian/confluence/confluence/WEB-INF/lib/confluence-5.8.10.jar.bak 。**复制 **/tmp/confluence-5.8.10confluence-5.8.10.jar **到 **/opt/atlassian/confluence/confluence/WEB-INF/lib/ **目录，实现补丁文件更新。

  

  

9重启confluence服务
