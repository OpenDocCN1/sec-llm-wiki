关于Zeppelin

“Apache Zeppelin是一个让交互式数据分析变得可行的基于网页的开源框架。Zeppelin提供了数据分析、数据可视化等功能。

Zeppelin 是一个提供交互数据分析且基于Web的笔记本。方便你做出可数据驱动的、可交互且可协作的精美文档，并且支持多种语言，包括 Scala(使用 Apache Spark)、Python(Apache Spark)、SparkSQL、 Hive、 Markdown、Shell等等。”——百度

这么优秀的软件，你团队中的大数据分析师一定喜欢并且正在使用！

但是，Zeppelin默认安装监听0.0.0.0的8080端口，并且允许任何人访问，可能会产生灾难性影响!

解释器功能强大，能够为数据工程师提供强大的数据分析和处理能力。

这里有两个解释器我非常喜欢， shell.ShellInterpreter 和 python.PythonInterpreter 。

不是它们强大，而是我只会这两个……

以 shell解释器为例，Zeppelin后台配置了 sh 解释器调用操作系统 /bin/sh 来执行命令。既然解释器能够执行数据工程师的脚本，也就可以执行黑客的命令咯：）

。

。

Zeppelin后台执行操作系统命令

首先，通过 Zeppelin 管理界面菜单 Notebook|Create new note 创建一个新的note，名称暂定为 test。


创建成功后，你就拿到系统权限了。什什么？？这么简单？对，就这么简单，看看咱的演示。直接在新建 note的命令输入框中输入 %解释器名称 以及需要解释器执行的命令，就可以看到回显啦，

例如：

%sh

id


或

%sh

cat /etc/passwd


或

%python

print file('/etc/passwd').read()


简直不敢相信，这台服务器居然是以 root 身份在运行Zeppelin……

。

。

其他

如果遇到找不到解释器或解释器无法运行的情况，很可能是管理员取消了默写解释器的功能，你可以通过Web 页面右上角的 Interpreter 设置自己需要的解释器。

你甚至可以设置 sh 和 Python 解释器对应的程序路径。

到这里，你还有什么做不到的呢？

。

。

总结

这篇文档真的没有什么技术含量，我只是想告诉你：Zeppelin安装配置不当将导致系统权限暴露，甚至被入侵！


下面是一些建议

务必对Zeppelin启用身份校验

不要将Zeppelin端口开放到外网

不要以 root 身份运行Zeppelin服务

不要使用Zeppelin-All安装包，

应选择性地安装解释器组件
