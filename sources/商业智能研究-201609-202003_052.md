# 医院数据价值化的秘诀——让数据文化深入人心

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwMzg5MTI0OQ==&mid=2247486249&idx=1&sn=782f2180a3c082550e614e07f930fc15&chksm=96c93c77a1beb5612e080e2a89e2713a7d5a37802a3974c6cf1384abeca0096609479de291a1&scene=126&sessionid=1681268579#rd](http://mp.weixin.qq.com/s?__biz=MzIwMzg5MTI0OQ==&mid=2247486249&idx=1&sn=782f2180a3c082550e614e07f930fc15&chksm=96c93c77a1beb5612e080e2a89e2713a7d5a37802a3974c6cf1384abeca0096609479de291a1&scene=126&sessionid=1681268579#rd)

现在进到医院，大家一定会发现医院的现代感越来越强，不管是门诊前台、接诊台信息大屏，还是逐渐电子化的病历、就诊卡、移动支付等等，医院似乎在不知不觉中往更加智能化、现代化的方向前进。那么在这样不断进化的医院中，怎么让医院的人员的意识也不断前进，让所有人更加重视信息和数据，也就变成了很多管理人员和信息化人员头疼的问题之一。

  

云南省新昆华医院的信息科团队在多年医院信息化的建设总结出了自己的心得，本文就从信息科的视角来讲述如何让全院的意识逐步统一，构建让全院不断向前的数据意识。

  

**从能到好用**

  

2016年，新建医院的信息科刚刚成立，所有人开始着手筹划医院的信息化规划。信息科成员都具备多年的医院信息化经验，大家知道，像以往那样简单的业务系统堆砌，将无法满足医院的信息化需要，要做信息化建设就一定要能面向未来十年的医院发展。**未来十年可用，现在却要从零起步，现实与理想的冲突是如此明显。**

  

但是一家还没有开业，业务不定、人员不定、管理模式不定的医院，还怎么做项目？怎么做系统？信息科团队给出了自己务实的回答：从实际出发，小步快跑。先按照大型三甲医院的常规模型，搭建一个可靠的数字化医院系统，而且要分阶段建设。在构建数字化医院模型的同时，要能支撑医院开业和正常运行。

  

既然规划了，就开始干。历时一年多时间，信息科出色地完成了医院主要业务系统的建设，还一步步完成了医院的智能楼宇、网络拓扑、虚拟化的计算服务、高可用的数据存储集群、BAS系统、网络安全、内部所有系统统一接口等等设计，成功支撑了医院的正常开业和运行。但大家并不满足，他们更加深刻的体会到，要想真正做好医院信息化，支撑医院业务是远远不够的，还要让信息系统伴随着医院发展而进化！

  

**从信息向数据**

  

任何一种进化都是需要选择方向的，那么医院信息化变革的方向在哪里？在17年，院长和信息科团队外出学习，逐渐找到了方向：**数据价值化**。医院数据的重要性已经被越来越多的人认可，但是医院的数据价值却难以发挥。信息团队分析下来，有五大障碍阻碍了医院发展数据应用：

  

1.  **数据质量差**：业务系统只能支撑割裂的业务模块，缺少连续性，同时各家系统的标准不一样，造成了标准化、一致性差；
    
      
    
2.  **缺少支撑工具**：his报表只能用作简单查询，定制化开发his报表的成本又很高，靠导出数据成excel又变成了重复性劳动，医院的所有想法都难以落地；
    
      
    
3.  **组织不重视**：业务经常提一堆临时性的数据需求，没有形成标准的路径，也没有针对这块进行系统性建设的意识，导致每次都是用最低效的方式去解决；
    
      
    
4.  **数据利用率低**：业务不知道有什么数据可以用，信息不知道业务有什么样的应用场景，最后就变成了业务部门无法创新、信息部门无法提供更好的服务；
    
      
    
5.  **缺乏复合型人才**：业务人员和信息人员常常无法互相理解，但数据应用的打造离不开对于业务的理解、对于数据的熟悉和可视化的合理设计，而医院正是缺少了这样的复合型人才充当沟通的桥梁。  
    

  

针对这五大障碍，主管联合信息科人员开始寻找合适的工具，并打算培养一支复合型工程师团队，为后期的数据转型打好基础。要说什么是好的数据产品，那它一定要符合医院的发展需求。在市场上选型很久，功夫不负有心人，最终选上了帆软。当时还是8.0版本的FineReport，因为它的易上手、具备填报、展示效果好等特性打动了信息科所有人。

  

产品买回来了，人员准备好了，系统的数据库也掌握在自己的手中了，一切齐备，数据应用的曙光似乎就在眼前了。大家却没有感觉到轻松，因为要打好数据价值化战役，接下来才是重中之重。

  

**协作到文化**

  

数据价值化实战一开始，就遇到了难题。科室对于信息科自己制作报表，打造数据应用非常欢迎。但科室提出的需求越来越多，工程师们做了一堆的报表，却都是临时的，价值极低。

  

主管发现这一情况后，果断联合业务科室主任和职能部门召开了一次会议，在会议上确认了目标：**要改变工作的协同模式，从单机报表向在线报表转变、从关注数据本身向关注价值分析转变。**

  

同时，对于科室和信息部门沟通有障碍的情况，大家决定了两件事：

  

1.  每个科室都安排一个数据对接人，有对接人负责数据分析业务，定期开会；
    
      
    
2.  建立包含业务人员的数据分析项目小组，制定数据分析业务的建设规划，将包含全院级、科室级、专项KPI统计等内容。  
    

  

事实证明，只要坚持，美好的事情一定会发生。在坚持了一年的数据价值化实战之后，数据分析的硕果累累。

  

首先，全院的数据都联通到了帆软数据平台上，甚至连停车场车库的车牌信息都能方便的查询到。通过一个简单的填报页面，就可以将员工的车牌填入系统，员工车进入到停车场就不会再计费。

  

![](../Images/4630317fc7dce69d50698d1881960e23.png)

  

其次，帆软数据平台上逐渐形成了几大分析模块：财务模块、医务模块、经营模块、门诊模块和院长模块。

  

![](../Images/51c880cdbcbf627a4646bfa43802e9b3.png)

  

比如门诊人员，只需要进入到门诊工作日报，就能看到自己一天完成情况的完整数据。

  

![](../Images/9f966eccffc08a62809161c5176b7133.png)

  

当财务人员需要制作月度财务分析报告时，只需要在财务报告的在线报告里核对当月的数据，然后导出成word保存即可，避免了之前花两周在一份报告上的情况。

  

![](../Images/d678d670b73037cd9e8d9a762431f99f.png)

  

院长和科室主任再也不用让科室人员统计数字，只需要打开日概况或者院长驾驶舱就可以轻松观察到医院的全面数据。

科室的对接人负责不断创新应用场景，工程师不断给科室提供信息化的思路，一年下来，每一张开发落地的页面都找到了坚实的应用场景。通过不断磨合与试错，每个科室都逐渐认可了数据应用带来的实际价值，而工程师团队则培养了打造数据应用的能力。数据价值化实战的成果体现在了方方面面，科室主任开全院大会时，每个人都直接打开了分析页面讲自己科室的数据。信息科还得到了院长的认可，之前院长要一份数据，需要等待十天，**而现在，信息科提供完善的分析页面，只需要半个小时**。

  

     

  

台上一分钟，台下十年功。在医院信息化转型的过程中，没有人可以随便成功，总有需要克服的障碍。信息科团队始终不变的坚持打造数据文化，让数据反哺业务，最终实现了从信息向数据的转型。但在未来的规划中，团队认为还有更多的数据应用可以探索。比如精准营销、融合内外部数据，帮助医院找准自身定位、不断发展。数据价值化，我们永远在路上。
