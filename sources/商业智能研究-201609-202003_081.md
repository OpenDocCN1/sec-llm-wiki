# 如何打破传统制造业信息孤岛，实现企业一体化决策管理

**引言：**如今传统制造业不再局限于单一化的产供销生产链，企业的业务系统覆盖面越来越广，为企业积累了海量的数据资产的同时，也给企业带来了许多问题。传统制造业内部人员数据整合和分析能力无法迎合瞬息万变的市场需求，给企业一体化决策带来不良影响。本文就山西重汽深度解读数字化管理如何解决传统行业“信息孤岛”问题，实现企业信息一体化管理。

  

公司简介

  

陕西重型汽车有限公司成立于2002年9月19日，是由湘火炬汽车集团股份有限公司与陕西汽车集团有限责任公司合资组建的大型汽车制造企业。 公司前身陕西汽车制造总厂，是国有大型一类骨干企业，是国家保留的唯一的重型军用越野车生产基地。2002年2月份，陕西汽车制造总厂整合宝鸡车辆厂，联合陕西东隆集团有限责任公司、重庆卡福零部件有限责任公司、重庆红岩弹簧有限责任公司等企业组成多元化投资母子公司-陕西汽车集团有限责任公司。  

  

项目背景

  

*   陕西重型汽车有限公司信息化建设始于2004年，经过十余年的发展，企业业务系统覆盖面广，目前已建设覆盖生产供应、研发设计、营销服务、综合管控等核心价值链的各类信息系统数十个。
    
*   企业海量的数据资产和原有独立的业务系统模式在一定程度上成为了企业进一步信息化交流的阻碍，也为企业的一体化决策带来困扰。
    
*   公司认为，如何有效利用这些海量数据，进行精确地、深入的市场分析，并将分析的结果应用于企业发展决策当中，将会对企业发展带来巨大的推动作用。
    

为此，如何将各信息系统串通，让数据灵活运用，从海量数据中挖掘价值数据，为领导层决策提供即时有效的支持，实现运营可视化和数字化辅助决策，成为信息化建设中的新方向。基于以上背景，公司决定选择FineReport作为数据平台搭建。

项目应用场景

  

1、项目整体规划：

*   业务数据梳理分析：开展公司业务数据的梳理与分析，建立满足公司运营管理监测需要的主题数据库；
    
*   数据手工填报平台：建立数据手工填报平台，对不能从系统中直接取得的数据进行线上填报，使得数据分析更加完整，结果更加可信；
    
*   运营、财务分析模型：根据决策需求，首先建立运营、财务主题域的分析模型，后期扩展生产、采购、营销等其他业务域数据的分析模型；
    
*   建立领导驾驶舱：设计综合看板，定制各类分析报告，为各级领导提供可视化、实时化数据展示；
    
*   定制企业专属APP：定制企业专属APP，用于移动端报表展示，实现各类经营数据实时查询、自由分析、支持数据填报；
    

![](../Images/60ec9c0232bc9ced08b73ae305d19ae8.png)

  

2、项目应用范围：

主要分为两个主题、六个场景，运营主题包括数据填报、运营报表、主题分析，财务主题包括数据填报、财务报表、财务驾驶舱。

![](../Images/6bf7761bfe155fd7d482398e51361064.png)

  

3.应用场景分享：

①经营日报主题：反映每日生产经营概况，主要涵盖订单、产量、销量、回款等核心经营指标，每天系统自动生成并定时推送至高管邮箱，减少人工制作报表工时，提升工作效率，方便高层领导快速直观了解当日经营状况。

![](../Images/921b4a36d502ec75c39ec5715acd31ce.png)

  

②营销主题分析：该看板反映陕重汽整车月度营销概况，由月度指标完成情况、订单分析、销量分析及库存资源状况4部分组成。通过可视化图形展现，让管理者快速了解当月营销状况，有助于及时洞察市场状况，寻求业务突破点。

![](../Images/40525d3dbd061ed1bbcb30c36e5305a4.png)

项目价值与思考

  

价值在于整合海量数据资源,搭建统一共享分析平台 ,激活业务人员分析思路,提供经营决策数据支撑。

1.  数据整合,系统互联集成MES、DMS、海外DMS、HFM等业务系统,定时同步业务数据,整合综合分析数据资源。
    
2.  报表自动化,提升效率综合性报表自动化生成,减少人工工作量,提升报表准确性,通过权限配置提升数据安全性。
    
3.  暴露问题,倒逼管理通过系统建设,暴露目前核心业务管理与业务系统运行问题，倒逼相关单位进行制度规范提升管理水平。
    
4.  脑力激荡,引导需求需求驱动，迭代开发，通过不断调研及领导访谈,激活业务人员的分析思路,提升企业数据分析水平。
