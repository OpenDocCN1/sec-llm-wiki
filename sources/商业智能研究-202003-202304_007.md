# 实施BI项目遇到阻力？1个对策巧妙破局

都说 BI 好，但 BI 项目失败的也不少。场景、数据、人、方法流程、工具、项目建设及运营等要素都可能是造成 BI 项目失败的原因。

但归根结底，企业应用 BI 本质上是一个不断决策的过程，各项要素是作为决策的对象或者条件参与到整个过程之中的。从这个角度来看，企业应用BI 失败的原因就是某个或某些环节的决策没有做好，而各项要素出现问题的根本原因也就是**需求和供给之间的矛盾**。

纵览企业应用 BI 的过程，无外乎“**是否需要应用 BI**”、“**能不能应用 BI**”、“**BI 选型怎么选**”以及“**应用 BI 后具体做什么**”等几个大的决策节点。本文便从供需的角度，来解析企业在这些节点如何突破决策困境，同时也对一些共性的 BI 问题做出解答。

## 01

## 是否需要应用 BI

这是企业面对的首要决策，决定着是否会有后续的更多决策。从供需的角度来看，这个问题的决策思路其实很简单，就是**企业需要什么，BI 能不能提供**。

能提供企业就可以应用 BI，不能提供则不应用。当然，在一开始并不知道自己的需求能够通过 BI 来解决时，**反过来思考 BI 能提供什么，企业是否需要这个也是可以的**。

那么 BI 能提供什么，也就是能干什么呢。帆软数据应用研究院在《商业智能（BI）白皮书 2.0》中对 BI 有这样的定义：

“BI 是在打通企业数据孤岛，实现数据集成和统一管理的基础上，利用数据仓库、数据可视化与分析技术，将指定的数据转化为信息和知识的解决方案，其价值体现在满足企业不同人群对数据查询、分析和探索的需求，从而为管理和业务提供数据依据和决策支撑。”

从定义来看，BI 本质上是将数据转化为信息和知识，为企业管理和业务提供决策支持，能实现的功能有打通数据、数据查询、数据分析探索、数据可视化等。

了解到 BI 的作用后，企业就可以思考是否存在相关的需求。综合大量企业的实际情况来看，**企业应用 BI 通常是由信息化建设与数据应用需求驱动**。具体来说，由于存在信息孤岛，很多企业的 IT 人员需要在业务系统频繁取数，并通过手工整理制作报表和分析报告，整个过程耗时耗力，并且存在数据口径不统一、数据不准确等问题。

这个时候企业其实就有了应用 BI 的需求，就可以通过 BI 来释放 IT价值，推动企业数据驱动决策的文化，赋能管理和业务。

## 02

## 能不能应用 BI

需要应用 BI 和能不能应用 BI 是两回事，**应用 BI 对企业也有着一定的要求**，这时候供需双方就互换了，企业需要思考能不能满足这些要求。

那么应用 BI 对于企业有着怎样的要求呢，我们从 BI的实现过程来看。如图 1 所示，BI 的核心是人依据数据解决问题，中间需要通过工具、流程方法等将数据转化为信息或知识。因此，要完成一次完整的 BI 分析，就需要有问题（场景）、数据、人、工具、流程方法等要素参与，上升到项目层面，还需要项目建设与运营的方法论作为指导。

![](../Images/03cc0274ce851a7cdc5cbe5fe52fd658.png)

  

明确 BI 项目成功的需求或者说要求后，企业便可以对号入座，查缺补漏。

首先是**要有问题，也就是场景**，这个在“是否需要应用 BI”的问题中已经初步明确过。

其次是**数据**，企业要思考的是信息化建设是否达到一定的水平，是否积累了一定的数据支撑分析，另外数据质量是否过关，有没有很严重的质量问题等。

接着是**数据人才和高层的认可**，企业要盘点是否具备或者能够培养相应的人才，是否能够获取高层的认可等。

再就是**工具**，这个是工具选型阶段的任务，可以先放着。还有流程方法，企业需要思考是否有或者是否能够建立完善的流程方法来支撑整个分析流程，从而能够得到科学的分析结论。

最后是**项目层面的建设和运营**，如果企业有项目实施团队，那么便需要评估相应的能力并作针对性提升；如果是交由厂商实施，那么项目建设和运营方法论就是考察厂商的一个重点。

## 03

## BI 选型怎么选

在确定需要应用 BI，并且满足一定的条件后，企业就进入了 BI 工具的选型阶段，**核心问题就是 BI 选型怎么选**。面对市场上鱼龙混杂的 BI 工具，不少企业眼花缭乱，无从下手。这里我们再次应用供需的思路拆解，选型问题就变成了企业需要怎样的 BI 工具和市场上能提供怎样 BI 的工具两个问题。

对于企业需要的 BI 工具，从选型要素的角度来看，企业需要考虑的不外乎易用性、稳定性、功能、采购成本、BI 厂商的能力等几点。

图 2 所示为帆软数据应用研究院的调研数据，可以看到企业在选择 BI 工具时，最**关注的是 BI 工具是否高效、易用和便捷**（69.10% 的受访 企 业 看 重 这 一 点）。而 Gartner 在 Survey Analysis: Key Selection Criteria for Business Intelligence and Analytics Platforms 报告中指出，工具的易用性对企业获取商业价值也是排在第一位的影响要素。

![](../Images/9802fb5a71875c02a1dee18149d58e39.png)

具体来看，细化到某一项选型要素时，也是利用供需的思路来分析。

例如功能技术层面，某些企业可能希望 BI工具提供一些先进的功能技术。那么企业就需要考虑清楚，一方面是否用得上这些功能技术，另一方面这些功能技术的应用对企业有怎样的要求，市场上提供这些功能技术的BI 工具是否能满足企业的需求，是否成熟，是否存在风险等。

一般来说，采用技术太过前沿的 BI 工具，如果没有落地场景，这些工具最终将变成 IT 部门的成本，而技术落后的 BI 工具很快就会过时，对企业发展也有很大的制约。这样分析下来，具体怎么选型企业就能够有很清晰的思路了。  

总的来说，**企业 BI 工具选型的根本原则就是两个字：合适**。报表式也好，自助式也好，只要是适合企业的，能够满足企业需求的，就可以选用。既关注工具本身，也要考虑企业自身实力。从场景出发选择 BI 工具，必将带来不错的回报。

## 04

## 应用 BI 后具体做什么

决定是否应用 BI 时只是初步梳理了大致的需求，应用 BI 后具体要做什么场景应用也是困扰企业的一大难题，而这一难题仍然是来源于对需求和供给的把握不够清晰。

**先看供给，也就是 BI 工具能够实现哪些场景**。前面提到的数据报表、数据查询、数据分析与探索都太笼统，我们可以**从功能和业务两个方面**来看 BI 的应用场景。

**功能方面**主要有数据大屏、移动应用及自助分析三大典型 BI 应用。其中，数据大屏更专业的说法是大屏数据可视化，其特点是“面积大、动效炫酷、色彩丰富”。数据大屏的优势在于能提供更直观的信息，并支持动态交互，具体可用于企业形象展示、数据查看、经营分析会议、数据监控等场景，例如图 3 即为某公司生产车间运行监控大屏。

![](../Images/f152d886c0a3f432041664b799645e5c.png)

移动应用即 BI 的移动端，由于移动端本身的特性，BI 在移动端上的功能和 PC 端相比有所扩展，除了常规的数据分析外，还有消息推送、手机扫码、应用集成等。自助分析则是一种能够解放 IT 人员，赋能业务，提高效率的 BI 分析模式，主要的理念是 IT 人员准备数据，业务人员自主分析。

**从业务的角度，BI 能提供的场景围绕业务活动展开**，大到供应链管理、营销管理、财务管理、智能巡检、门店补货、退货分析等，小到人事考勤监控、采购节点效率分析、商品补货提醒等，图 4 给出了制造、零售、金融、教育四个行业的部分业务场景示例。应用场景是 BI 项目得以落地的最终载体，也是体现 BI 价值的最终途径。企业在不知如何落地 BI 项目时，不妨尝试从这些典型功能应用入手，寻找适合的场景，使 BI 应用落地。

![](../Images/6b11d2d042304a0ba030a2231fa5660a.png)

**当然，不是说 BI 提供什么企业就做什么，具体是需要通过调研得出的。**需求调研的总体思路是以模块为线，以整体为面，由粗到细，先整体后局部，先集团后部门。在总体思路的基础上，**一个非常重要的原则就是在收集和确认需求时做到“抓痛点而不是抓痒点”**。通过一层层地抓痛点，让管理层、业务人员明确其需求，也就是项目边界，IT 人员的开发就不会偏离方向。最后即便 BI 系统不能保证完美契合需求，但是核心需求得到了满足，BI 系统在企业中能用起来，项目也不算是失败的。

总而言之，企业应用 BI 是一个需要谨慎决策的事情，用的好能给 IT 部门给企业带来很大的价值，用的不好就是消耗企业的成本。**当面临不同阶段的决策选择时，企业可以从供需的角度去思考、破局**，从而明确自身的需求和目标，少走弯路，不花冤枉的时间和精力。
