# 成功的 BI 战略的 8 个关键

根据调查，商业智能成功的十大障碍包括软件相关问题、缺乏足够的预算、缺乏培训和专业知识、缺乏战略、战略目标不明确以及缺乏全公司采用。  
这些发现表明，一个成功的商业智能项目不仅仅是技术，这里有 12 个基本要素，可以帮助克服这些挑战以创建成功的BI战略。  

## 

在选择 BI 工具时考虑现有的基础架构

  

## 

数字咨询公司 Appnovation 的数据科学和分析高级总监 Ashley Fitzgerald 曾与一位客户合作，该客户购买了价值数百万美元的 BI 软件包，即使通过 API 也无法连接到公司数据库。

  

相反，该公司必须构建集成工具来实现数据流。本质上必须在他们购买的工具之上构建一个工具。

  

这种额外的技术给产品增加了不必要的成本和复杂性，这可以通过更加关注现有基础设施、可用的 BI 软件、每种技术的限制以及这些限制将如何影响部署来避免。

  

Jackson 表示同意，他说信用合作社曾经有一个难以扩展的 BI 应用程序，并且需要很难找到的专业技术技能。因此，当该组织寻求新的解决方案时，找到可以利用现有基础设施的最佳解决方案是我们的首要任务。

  

## 

在选择 BI 工具时考虑业务目标

  

IT 服务管理公司 Trianz 的首席执行官 Sri Manchala 说，IT 基础设施要求不应该是影响 BI 工具选择的唯一要求。CIO 和 IT 采购人员应该让将要使用该软件的员工了解他们想要回答什么样的问题，以及他们希望如何获得这些问题的答案。

  

花足够的时间与企业打交道，了解他们的优先事项是什么，他们正在寻找什么样的洞察力和可视化。让业务描述他们想要什么，然后 IT 可以弄清楚如何实现它。

  

此类信息将有助于确定企业需要哪些数据存储来满足其 BI 需求、哪些类型的界面可能对用户最有用，以及哪些特性和功能最能满足业务需求。

  

这不是关于技术，而是更多关于业务、他们拥有的数据以及他们如何与之交互。这是关于创建以数据为中心的文化，以便能够将这些见解反馈给最终用户，以讲述该组织的故事。

  

## 

在采购过程中进行尽职调查

  

管理和 IT 咨询公司 Swingtide 的高级分析师和合同专家 Chris Herman 说，在某种程度上，BI 工具已经成为商品。这可能会减轻选择和采购过程的一些压力，因为“当市场上的一切都相当不错时，你就不会冒一场彻底的灾难。”

  

但是，当 CIO 和采购团队因此在合同流程中走捷径时，他们可能会得到无法满足业务预期的产品。

  

公司在为其 BI 系统签订合同时要像核心应用程序一样勤奋，对提案的竞争性要求、详细的服务水平协议和明确的可交付成果。

  

## 

培养信任数据的文化

  

业务转型服务公司 Genpact 的首席数字官 Sanjay Srivastava 表示，希望数据真正为决策提供信息的组织需要培养一种拥抱这一愿景的文化，并建立一个支持它的基础设施。

  

企业领导者必须提供正确的数据——单一版本的事实。然后，他们必须向业务用户证明他们可以信任数据，从而信任他们的商业智能工具产生的答案。

  

拥有数据的真实性和信任是非常关键的，需要通过对如何使用 BI 满足日常业务需求进行建模来展示数据带来的价值。

  

## 

不要缩短变革管理和培训

  

类似地，想要优化其 BI 计划价值的企业领导者需要将变革管理纳入他们的战略，并包括足够的用户培训。不过，这种情况并不总是发生。

  

人们通常认为你打开电灯开关，你就有了一个程序，即使你用干净的数据构建了完美的平台，也只有一小部分公司会考虑培训、采用和优化。

  

通常计划进行三到六个月的变更管理和培训，以确保充分利用 BI 工具，并指出“我们需要告诉人们他们需要看什么来推动他们的决策。浏览他们的日常活动，然后说在这里您可以使用该工具。研究哪些小部件正在使用，哪些没有，人们还在哪里使用 Excel。

  

她曾与一家医疗设备公司合作，该公司只有不到 10% 的销售人员使用新部署的 BI 平台，但发现使用 BI 的员工销售量更高。然后，公司高管展示了这些早期采用者的成功，并让这些早期采用者举办会议，教他们的同事如何也可以使用 BI 来提高工作绩效。

  

## 

数据民主化，赋能用户

  

## 

我们都知道:分析只有在回答你需要回答的问题时才有价值，你需要业务需求和业务需求的交集，需要回答的问题和你想都没想过要问的问题。

  

为了实现这一目标，首席信息官必须将“探索和询问数据的能力交到业务用户手中”，这意味着提供使用户能够以促进推荐或引导他们进行新查询的方式可视化数据的功能。

  

这是关于数据的民主化，当首席信息官“构建可供业务用户而非数据科学家使用的工具”时，就会发生这种情况。

  

## 

将治理纳入 BI 战略

  

BI 工具应该将数据带给整个企业的更多员工，这种可访问性可以创建对业务的更多实时可见性，但如果没有通过控制进行充分管理，也会产生隐私和安全风险。

  

CIO 必须带上这个工具包，治理应解决数据隐私和安全以及法规遵从性问题。

  

但根据 Swingtide 分析师赫尔曼的说法，它不应该就此结束。他说，治理还应该包括检查 BI 工具在其生命周期内运行情况的程序，以便 CIO 能够确定需要的调整、改进和升级。

  

## 

迭代和推进

  

与 IT 和一般业务中的许多其他方面一样，有效的 BI 策略涉及迭代改进以及更高级的数据使用的飞跃，例如预测性和规范性分析，有效的 BI 策略应该反映这一点。

  

数据是一个旅程，而不是一个目的地，因此 IT 应该继续发挥战略支持作用，以了解新的和不断发展的工具和技术，以支持业务用户访问和利用数据的能力。

  

BI 的最佳方法是迭代方法，随着业务部门选择 BI 满足其需求的位置或是否满足其需求，这也会导致扩展。该战略应被视为一个动态且不可阻挡的过程，可以在未来的业务或环境中做出任何决策。
