在瞬息万变的世界中，IT 和业务主管们需要共同努力，以使他们的企业朝着正确的方向发展。

 

您的企业是否已经无法协调一致工作？一些明显的症状包括往错误的方向发展、管理不善，或许最糟糕的是，工作效率和业绩下降。

 

当 IT 和业务团队无法协作时，则各方都将面临一个艰难的工作过程。“在企业如何为客户带来价值方面，数字化转型正在推动发生根本性变化，”IT 和商业咨询公司 – 凯捷美洲 (Capgemini Americas) 的副总裁兼应用管理服务卓越中心主管萨米尔·巴格瓦特 (Sameer Bhagwat) 说。

 

巴格瓦特指出，随着目前整个商业生态系统彼此互联，企业必须灵活应对不断变化的业务需求和市场需求。“当 IT 和业务部门可以恰当地协作时，则领导者可以更有效地实现他们的目标，”他说。

 

您的企业是否正朝着正确的方向前进？请关注以下七个技巧，使 IT 和业务部门更好地协作。


了解您的业务

 

首席信息官不再只是一名技术专家。在如今的生态系统中，首席信息官还是一个业务决策者，公有云托管服务和数据分析提供商 Siepe 的首席执行官兼创始人迈克尔·普萨特瑞 (Michael Pusateri) 说。

 

首席信息官需要了解整个业务工作以及任何现有或潜在的技术痛点。通过专注于当前的业务难题，首席信息官可以帮助管理层针对某一问题制定多维度解决方案，而不是仅仅从技术角度来提供建议。

 

“这使得首席信息官能够设计或选择一个适合业务工作的解决方案，而不是仅仅选择一个可能无法满足现阶段业务需求的最新技术。”普萨特瑞说。

 

普萨特瑞指出，首席信息官和首席执行官之间的沟通顺畅可确保带来更高的透明度和更准确地预测企业的未来发展方向。首席信息官还应该在战略规划委员会以及整个公司规划过程中发挥核心作用。

 

“那么，首席信息官就能够提出最佳技术解决方案来实施首席执行官的愿景，而不是被各个业务部门拉向多个方向。”普萨特瑞解释道。

 

加强管理层之间的关系

 

除了与首席执行官合作外，当代首席信息官还需要与销售、营销、财务、人力资源和其他关键管理领域的企业主管们协作。“与这些职能部门之间的协作，对于准备好迎接下一波机遇至关重要。”人力资源、薪资和财务管理软件服务提供商 Workday 的首席信息官雪莉•罗兹 (Sheri Rhodes) 说。

 

罗兹指出，例如，首席信息官和首席财务官之间有强有力的合作关系，可以为成功推动创新奠定基础。“我们的首席财务官罗宾•西斯科 (Robynne Sisco) 和我比以前更密切地合作，讨论数字化转型，以及重新思考和平衡我们的优先工作事项。”她说。

 

罗兹指出，糟糕的部门间协作和孤立的决策工作会削弱组织机构快速应对其内部或外部环境变化的能力。她表示，随着时间的推移，这一缺陷会对网络升级、协作工具、办公室共享、云应用和基础设施等各领域的举措产生负面影响。

 

“我们使用目标和关键结果 (OKR) 框架来帮助促进协作和步调一致，从而最终帮助我们变得更加敏捷，并实现我们想要的结果。”罗兹说。“那些团结一致、各项工作完善、能快速应对不断变化的需求的公司，更有可能制定出最成功和最持久的数字化战略。”


组建专注于关键业务领域的跨职能团队

 

技术现代化公司 SPR 的首席技术官马特·米德 (Matt Mead) 建议，除了与企业同事进行沟通之外，还应营造一种跨职能的环境，鼓励在产品开发、营销和销售等关键业务领域组建跨部门团队。他表示，这种协作关系将有助于使 IT 部门从成本中心转变为战略性业务参与者。“成为战略性合作伙伴……将使 IT 部门成为一个更有价值的部门，得到更多的信任和尊重。”

 

米德补充说，让 IT 人员与其他企业专家合作，将有机会学习到新的概念和方法。这将鼓励员工从战略上思考产品和服务目标，以及开发具有明确业务目标的创新技术。总之，这可以使 IT 部门更协调一致的工作，成为一个侧重于实现企业目标而不仅仅是实现技术目标的部门。

 

此外，在 IT 专业人员需求旺盛且留住人才比以往任何时候都更为重要的大环境下，与业务部门同事密切合作的 IT 部门可以实现更高的价值和关注度。“这可以带来更大的使命感和重要性，从而有助于企业留住顶尖的 IT 人才。”米德说。


利用全栈的可观测性

 

任何 IT 部门工具包中的一个关键组件就是全栈的可观测性。对整个 IT 堆栈的监控可以在潜在差异变为严重问题之前发现它。“(该组件)具备一种重要的功能，可以直接给出对业务结果的影响。”应用性能管理和 IT 运营分析服务提供商(思科公司下属的)AppDynamics 的技术战略副总裁兼执行首席技术官乔·博恩 (Joe Byrne) 说。

 

博恩解释说，通过了解 IT 堆栈的变化如何影响最终用户的体验和整体业务的成功发展，首席信息官可以帮助优化业务功能，将资源和时间调配到最重要的领域。“这可使首席信息官具备相关专业知识，以有利于业务和 IT 团队的方式来影响创新和数字化转型工作。”


使 IT 部门的 KPI 与企业成果挂钩


凯捷美洲公司的巴格瓦特表示，将 IT 部门的KPI 与企业成果挂钩是一种相对简单的方法，可使 IT 运营工作与业务运营工作更加相关。随着数字化转型的到来，以客户为中心已成为企业长期成功发展的关键。

 

“人工智能和自动化领域的最新进展，以及这些技术进展如何帮助解决问题，是 IT 如何对业务部门的 KPI 产生直接影响的一个例子。”他指出。

 

此外，IT 团队可能需要采用与客户体验直接相关的新 KPI，以满足侧重于客户满意度的业务需求。“整个商业生态系统是相互关联的，企业需要灵活应对不断变化的业务需求和市场需求。”巴格瓦特说。此外，客户情绪和体验对于保持竞争优势变得越来越重要。“将这一市场现实转化为 IT 要求，这需要业务与 IT 部门之间的密切配合。”

 

巴格瓦特指出，当 IT 和业务部门可以适当地协作时，业务主管就可以更有效地实现其目标。同时，当可以进行适当地协作后，“首席信息官们就更容易解释他们的预算和具体计划，因为这些计划与业务相关者的目标直接关联。”


建立一种 DevOps 模式


尽管改善业务和 IT 部门间的协作始终是几十年来的一个目标，但这两个部门在很大程度上仍存在分歧。DevOps 平台提供商Delphix 的首席技术官丹·格雷夫斯 (Dan Graves) 表示，通过了解DevOps 模式的一些示例，可以找到实现部门间更好关系的灵感，DevOps 模式结合了旨在使(过去始终无法协调一致工作的两个团队)软件开发和运营团队协调工作的文化理念、实践和工具。“一家公司必须有意识地选择变革，并对转型进行投入。”

 

格雷夫斯解释说，要成功实现业务和 IT 部门间的协调一致，双方必须愿意合作，为所有利益相关者带来更好的结果。收集业务需求、用一年时间来开发某一产品，然后收获一个大的新产品，这一传统模式现在已经无法跟上更快、更精简的竞争环境的步伐。“只有通过强有力的协作，新产品和服务才能推动产生最佳业务成果，”他说。


要考虑可组合性


商业智能和大数据分析软件提供商 GoodData 的首席执行官罗曼·斯坦里克 (Roman Stanek) 认为，可组合性是业务和 IT 部门协作的一个有用工具。可组合式数据分析通过一种旨在提供更多、更深入的业务见解的方法，以消除阻碍协作的业务孤岛。这种方法还可使那些不熟悉 SQL 的业务主管们轻松获得和定制数据见解。

 

无代码用户界面将分析能力直接交给业务用户，并促进业务与 IT 部门更紧密地协作。“在这类可组合的企业中，业务部门可以横向开展工作，通过更具协作性和流畅的运营工作来实现整个企业的目标。”斯坦里克说。“凭借可组合式分析，企业可以变得更加灵活和敏捷，可开发新的应用程序，并可更快速、更轻松地连接到新的生态系统。”
