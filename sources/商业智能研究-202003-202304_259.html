在又一个动荡的一年之后，一些IT管理者回顾了过去12个月的经历，以下是他们给出的2021年最重要的7个收获。


不可预测性和不断变化是新常态


信安金融集团的首席信息官 Kathy Kay表示许多人在回顾2021年1月对今年的预期时，会意识到他们的预期和实际差别很大。


所有 CIO 必须时刻准备好迎接变革，无论是由客户需求还是世界事件驱动——通过现代化和简化公司的技术堆栈并专注于不断提高员工的技能。


我们需要有转向的能力。它必须成为我们前进方式的一部分。


 IT 必须更快发展


Intermountain Healthcare 副总裁兼首席信息官 Ryan Smith 表示，过去一年的经验表明，首席信息官不仅要灵活而且要快速。


数字化转型正在加快业务步伐，要求 IT 加快步伐并与整个业务的运营领导保持一致，IT 团队必须继续提升自己的技能，并在人工智能、机器人流程自动化、云、移动、环境智能等数字技术方面积累专业知识。


CIO首先必须是商业领袖


越来越明显的是，技术领导者也必须是业务领导者，他们将战略作为他们团队的主要交付成果。


公司的工作和经营方式在疫情期间都发生了变化，这些变化现在已经成为永久性的。这使得为了保持相关性并为业务合作伙伴提供价值，理解运营并将计划与业务结果相一致变得更加重要。


CIO 现在必须能够就重大转型项目迅速做出适当的决策——这要求他们从业务角度采取行动，以更好地确保成功和预期结果。


同时IT 专业人员不仅需要了解业务，而且还需要教育他们的同行了解技术如何可以推进公司的成果。


可组合的体系架构


CIO们在2021 年的另一个重要收获：需要可组合的架构来实现快速的轴心。


我们经历了两次不同的情况，既需要更改我们使用的软件产品，也需要更新集成以支持业务流程。在这两种情况下，我们都在处理没有原生 API 功能的传统点对点集成和产品。这两种情况大大减缓了我们对市场机会的反应，以至于在一种情况下错过了机会，而在第二种情况下，运营风险没有得到充分缓解，从而导致其他结果挑战。


对于22年的计划，一些CIO已经制定了转向基于 API 的架构以及一些数据恶化更改的路线图，以支持更可组合的架构。


CIO 应该在教育员工方面发挥作用


随着商业越来越受数据驱动和数字化，员工也必须培养这些数字化的工作。素养


 CIO 在这里可以发挥作用，对数据素养和数字流畅性的快速增长的需求为 CIO 提供了一个机会，可以影响整个公司的技能和能力，而不仅仅是 IT。IT管理者该考虑如何利用他们的团队和培训方法来创建卓越中心、数据意识文化或培训活动。一些CIO正在创建和使用卓越中心来提高意识和知识，同时建立适当的框架和安全性。


CIO 需要重新考虑安全问题


混合工作为一系列全新的安全问题打开了大门，需要重新考虑传统策略。我们还赋予了安全新的面貌。威胁行为者及其发起的攻击变得更加复杂。为了对抗它们，一些CIO使用零信任网络访问等框架和 DevSecOps 等实践在运营中集成了安全性，这些做法可以缓解摩擦并确保系统和信息安全，而不会让用户感到沮丧和妨碍他们的体验。


面对面的团队互动具有真正的价值


这是施耐德电气数字技术高级副总裁兼北美首席信息官 Abha Dogra 去年吸取的教训。她的员工在虚拟环境和远程团队中高效工作。


但她也意识到，没有什么能取代亲自联系的实际机会以及身体互动带来的快速工作。当你与一个新人在物理空间面对面交流，在两个小时内建立的网络和信任，将胜过在线会议平台进行很多很多次会议。


考虑到这一教训，Dogra 更加意识到需要确保这些面对面的互动是她和她的团队日程安排的一部分。当然，她更喜欢面对面的互动类型，还有一种持续的日常互动，愿意保持距离。


因此她也在研究如何通过政策、流程和最佳实践来增强技术和数字工具，使远程和混合团队能够营造一种社区感和团结感。
