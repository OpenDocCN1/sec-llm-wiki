疫情期间，IT保持组织运转方面发挥了巨大作用，因此疫情过后，企业更加依赖于IT，并且对IT部门寄予了创收的新期望。

根据IDG的《2021年CIO状况》报告，绝大多数首席信息官(96%)表示，他们的角色正在超越传统的IT职责。在收入驱动或支持新产品和服务的创造方面，扮演者越来越重要的角色，包括自动化业务-IT流程，直接与客户互动，以及开发客户旅程等等

随着企业高管越来越关注IT部门，IT必须做一些创收的新创新。

以下是4个IT领导者将信息技术应用到工作中，为他们的组织创造收入的真实案例。

将内部应用系统变成产品


很多2B的商业化产品，最初都是为了满足企业的某个业务需求。是一个从企业自身内部需求出发，逐步验证、逐步完善，再整合经验技术并向外输出解决方案的过程。比如美团云，美团外卖在短短的时间内出现了100 万单、 1000 万单到 1400 再到 1600 万单的峰值，美团点评的外卖订单迅速上涨。与此同时，配送体验要求也在不断提升，平台也始终面临运力的挑战，必须不断平衡配送成本和配送体验的要求。在自身业务需求的推动下，美团开始部署私有云。一年后，公司基于私有云的实践经验，上线公有云项目美团云 MOS，成功实现了内部产品的商业化。从内部延伸至外部的过程中，产品形态的转化是美团面临的一大考验。比如，计费的形式以及用户的管理，内部产品偏向于更加简化、规模及效率，外部则强调功能、安全性合理性，包括用户的友好程度，内部使用 API 可以搞定，外部必须有操作界面的设计。

也许在由内转外的商业化产品项目中，CIO不再是项目主导，但CIO一定在其中扮演着重要角色，这是CIO为企业创收的典型案例。

所以笔者一直认为，CIO是一个强业务要求的管理岗，而不是技术岗，CIO必须有这种抓需求和抓机遇的敏锐洞察力，要保持时刻对市场的关注。

流程数字化，减少客户受阻


新加坡博彩公司的 Teck Guan Yeo 也看到了围绕增加业务价值进行IT转型的必要性。作为国彩的首席业务技术官，Yeo 不仅寻求改善客户体验，还致力于提高信息技术(IT)的认知。将其视为提供信息报告的成本中心。

他首先解决了公司的基础设施问题。Yeo 说，新加坡博彩公司实施了一个基于云的 ERP 系统，由数据湖提供支持，该系统有助于分离和保护其数据，随着其服务的数字化，数据呈指数级增长，然后 IT 应用分析工具。

随着远程工作的继续，Yeo 说他和他的团队正在继续努力确保公司变得完全数字化。一方面，他们开发一个名为“电子了解客户”(eKYC)的在线注册平台。

在新冠疫情之前，新加坡的顾客如果想合法下注，必须带着个人身份证明文件去实体的新加坡Pools门店。为了简化这一过程，Singapore Pools部署了人工智能来在线验证客户。

IT 还使用人工智能来分析客户行为，以帮助提供更好的体验。他们的做法是在顾客有问题时提供帮助，并“发现赌博习惯何时失控”。

新加坡博彩公司的新数字分支机构旨在提供完全无纸化、无排队和无现金的零售体验。他们正在实施视觉光通信和面部识别，使客户能够使用一款应用程序下注。杨说，这项技术将使客户能够数字化下注，无需等待或现金支付。

他表示，eKYC的能力还使新加坡博彩公司能够在创建账户时充分了解客户，从而在打击洗钱和恐怖主义融资活动方面尽自己的一份力。

IT通过提高运营效率，继续为公司的底线做出贡献。例如，Yeo正在部署RPA、下一代数据中心以及敏捷和DevOps方法，“所有这些都是支持安全数字零售业务的基础，”他说。

构建良好的IT架构，以加快产品交付


IT通过构建良好的IT架构、平台，保证企业基础技术环境的的高效运转，这就是降本增效的最基础思路，也是为企业增收的稳妥方式。

这里举一个美国varo bank 公司的案例。Varo Bank的使命是通过提供实时信息，帮助美国人改善财务健康状况，让美国人更容易在网上银行交易。作为一家成立于2020年10月的初创公司，CTO Deep Varma不依赖任何遗留技术，所以他构建了一个微服务架构，以小块的方式开发独立的服务。

“构建一段不关心技术状态的代码更容易，”Varma说。“通过构建微服务，你可以以更快的速度前进，因为你已经有了构建模块。”他表示，微服务通过服务网进行通信，这使得该行能够更快地提供新产品。

平台本身花了一年半的时间来构建，但现在新的应用程序可以在几个月的时间内启动。他说，如今这家银行正在为“数百万客户”提供服务，推出了两款主要产品，微服务业务的规模达到了三位数。

“微服务”的理念是在学习的过程中不断添加，”Varma说。

“IT使虚拟银行变得灵活，能够更快、更大规模地批准新的支票和储蓄账户，”Varma说。“最终，能够为企业直接或间接的增收，我们是两者的一部分。”

通过建设IT、打破数据孤岛来改变销售流程，提高销售效率


BDO Digital公司的CIO 卡明斯说，她的团队与各种内部业务利益相关者合作，从组织内的不同来源收集数据。

他们的目标是研究以前孤立的数据之间的关系。然后他们开发了一款移动应用程序，让销售人员能够进入客户环境，讨论过去的购买模式，并查看产品提供的竞争性价格——所有这些都是动态的。

这是一个“非常广泛的项目”的第一阶段，这一项目为组织立即带来了收入，并击败了竞争对手，因为他们能够很快地通过移动应用程序将信息传递给销售人员，并缩短销售周期。”

现在，BDO Digital的IT团队正在开发一个自助门户，以使客户能够找到问题的答案。她说，这让销售人员获得了更多的自由，提高了工作效率。他们还在努力替换其CRM系统和实施RPA。

有时候组织不知道他们需要什么数据，也不知道数据之间的关系，因为这些数据被隔离在不同的业务领域太久了。所以这也是IT要持续努力的一个大领域——挖掘数据，并将其整合到一起，为客户提供他们从未有过的见解。

通过对数据进行清洗、整合，并将其转换为一种可用于驱动决策的格式，这是it部门能做的最重要的事情之一。
