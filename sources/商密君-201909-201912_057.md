# 打造高质量发展新引擎，习近平心中有“数”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247486541&idx=1&sn=c4d9374f933a631b6ff7141c0ef545a0&chksm=ec551c16db229500ff2170c7f2f3d3e53a529f5a7d0f444e17e1c0b8d2ce5323839d64540525&scene=126&sessionid=1681315221#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247486541&idx=1&sn=c4d9374f933a631b6ff7141c0ef545a0&chksm=ec551c16db229500ff2170c7f2f3d3e53a529f5a7d0f444e17e1c0b8d2ce5323839d64540525&scene=126&sessionid=1681315221#rd)

　　2017年12月8日，习近平总书记在中共中央政治局第二次集体学习时强调，推动实施国家大数据战略，加快完善数字基础设施，推进数据资源整合和开放共享，保障数据安全，加快建设数字中国，更好服务我国经济社会发展和人民生活改善。

![](../Images/527b6cc38261fff17609aaa92a321605.png)

　　2018年4月20日至21日，全国网络安全和信息化工作会议在北京召开。习近平出席会议并发表重要讲话。

　　两年来，我国信息基础设施建设不断加强，信息资源深度整合，大数据发展和应用快速推进。区块链技术和产业创新发展前景广阔，数字经济成为中国经济新引擎，数字中国建设成果丰硕。

　　面对全球信息化浪潮，习近平总书记高瞻远瞩，敏锐把握中华民族千载难逢的历史机遇，为建设数字中国把舵定向，绘就蓝图。

  

01**发展数字经济 用新动能推动新发展**

　　“中国数字经济发展将进入快车道。”2017年12月3日，习近平在写给第四届世界互联网大会的贺信中，作出明确的判断。

　　2018年4月20日，习近平总书记在全国网络安全和信息化工作会议上发表重要讲话强调，网信事业代表着新的生产力和新的发展方向，应该在践行新发展理念上先行一步，围绕建设现代化经济体系、实现高质量发展，加快信息化发展，整体带动和提升新型工业化、城镇化、农业现代化发展。

　　两天后，习近平致信祝贺首届数字中国建设峰会开幕时再次强调，加快数字中国建设，就是要适应我国发展新的历史方位，全面贯彻新发展理念，以信息化培育新动能，用新动能推动新发展，以新发展创造新辉煌。

　　以习近平总书记系列重要讲话为引领，中国数字经济渐入佳境，数字产业化和产业数字化“双轮驱动”、数字经济和实体经济深度融合，推动经济高质量发展。

  

![](../Images/7b7c76f0f3157b03e664eac33a7769ec.png)

　　2019年9月12日，湖南一家企业工作人员正在“5G+智慧天车远程操控台”上远程操作废钢吊运。

　　今年4月，中国信息通信研究院发布《中国数字经济发展与就业白皮书（2019年）》显示，2018年，我国数字经济规模达到31.3万亿元，占GDP比重为34.8%。其中，数字产业化规模达6.4万亿元，产业数字化规模超过24.9万亿元。2019年6月6日，我国5G商用牌照正式发放，以5G和IPv6为代表的数字基础设施建设稳步推进。

![](../Images/bf35b3a7bc9188caba45539d67ad12f4.png)

  

02**推进电子政务 让“最多跑一次”再提速**

　　2016年10月9日，中共中央政治局就实施网络强国战略进行第三十六次集体学习，习近平总书记主持学习并发表重要讲话强调，我们要深刻认识互联网在国家管理和社会治理中的作用，以推行电子政务、建设新型智慧城市等为抓手，以数据集中和共享为途径，建设全国一体化的国家大数据中心，推进技术融合、业务融合、数据融合，实现跨层级、跨地域、跨系统、跨部门、跨业务的协同管理和服务。

　　让百姓少跑腿，让数据多跑路。以互联网的扁平化、交互式、快捷性优势为依托，全国各地大力推进政府决策科学化、社会治理精准化、公共服务高效化，“互联网+政务服务”取得了突破性进展，线上线下一体化政务服务体系扎实推进，“最多跑一次”“不见面审批”“一网通办”等措施，让人民群众的获得感和满意度不断提升。

　　据腾讯研究院5月发布的《数字中国指数报告（2019）》显示，2018年中国数字政务整体水平稳步提升，数字政务指数比2017年增长32%，数字政务服务向“多服务汇聚、全流程在线”方向不断深化。

![](../Images/6f355a15baa8ead161bf822d7fe33221.png)

　　2018年6月5日，在广州市妇女儿童医疗中心，市民殷彩欣展示儿子的出生医学证明电子证照。这是广东省第一张省内通用的出生医学证明电子证照。

　　如何打破数据孤岛、突破部门之间的行政隔阂，实现政务信息资源共享和业务协同，实现智慧政务？区块链技术提供了新可能。

　　10月24日，习近平在主持中共中央政治局第十八次集体学习时强调，“要探索利用区块链数据共享模式，实现政务数据跨部门、跨区域共同维护和利用，促进业务协同办理，深化‘最多跑一次’改革，为人民群众带来更好的政务服务体验。”

　　如今，全国已有近半数城市发布新型智慧城市总体规划和专项规划。据中国信息通信研究院11月发布的《区块链赋能智慧城市白皮书（2019）》显示，新型智慧城市建设呈现省级城市领跑、地级市跟进、县级市及城市群起步的态势，其中超过94%省级城市、超过71%地级市、超过20%的县级市及城市群均提出建设智慧城市，并涌现出一批城市智脑、“最多跑一次”、数据资产登记、多功能智慧杆柱、公众广泛参与等特色亮点应用和模式，中国已成为全球智慧城市技术产业创新发展的重要力量。

![](../Images/8d67012fb99f53f27ff9771b077a1283.png)

  

03**释放数字红利 让百姓“ｅ”起共享**

　　数字中国建设，必须贯彻以人民为中心的发展思想。

　　2016年4月19日，习近平在网络安全和信息化工作座谈会上发表重要讲话强调，要适应人民期待和需求，加快信息化服务普及，降低应用成本，为老百姓提供用得上、用得起、用得好的信息服务，让亿万人民在共享互联网发展成果上有更多获得感。

  　2017年12月8日，习近平在主持中共中央政治局第二次集体学习时再次强调指出，要运用大数据促进保障和改善民生。

 　 数字经济下，新模式新业态孕育而生，带动配套服务业蓬勃发展，创造了大量灵活就业机会，就业空间极大扩展。数据显示，2018年我国数字经济领域就业岗位为1.91亿个，占当年总就业人数的24.6%，同比增长11.5%，显著高于同期全国总就业规模增速。

  

![](../Images/6467ccbfffe4f87790c1891c2e623c1f.png)

　　江西省南丰县益农信息社工作人员在收集农产品信息（2018年2月5日摄）。

　　在教育、健康、扶贫、旅游以及公共安全等民生领域，大数据技术的应用也取得了很多成果，“政务平台”“智慧社区”“智慧旅游”“天网工程”“健康医疗”等大数据应用成果已经为人们的日常生活提供了许多便捷与保障。

![](../Images/116318480a801b7d7b330baa4c1e39e8.png)

　　数字中国，未来已来。

　　按照习近平总书记擘画的宏伟蓝图，把握信息化发展的历史契机，全面贯彻新发展理念，加快数字中国建设步伐，我们定当心中有“数”，更加奋发有为。
