# 加快推进广电和网络视听治理，聂辰席提六点要求

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247486348&idx=2&sn=55d4ec77692e74265d79390d329b7c1c&chksm=ec551bd7db2292c14c2096e977862e3c6f05f6a66c0a6b615325bcfa6a6480f6e89a2895b67b&scene=126&sessionid=1681315931#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247486348&idx=2&sn=55d4ec77692e74265d79390d329b7c1c&chksm=ec551bd7db2292c14c2096e977862e3c6f05f6a66c0a6b615325bcfa6a6480f6e89a2895b67b&scene=126&sessionid=1681315931#rd)

**网络视听生态圈（ID：wlststq）：**从政策监管到内容生产，从技术创新到企业运营，从市场营销到资本运作，带您全面了解网络视听行业的生态变化。

  

近日，广电总局党组理论学习中心组召开集体学习会。会议围绕“深入学习贯彻党的十九届四中全会精神，履行职责使命，加快推进广播电视和网络视听治理体系和治理能力现代化”进行学习研讨。  

  

聂辰席强调，加快推动广播电视和网络视听治理体系和治理能力现代化，必须要做到以下六点：

> 一要紧紧围绕“坚持马克思主义在意识形态领域指导地位的根本制度”，在强基固本上下功夫，坚定不移高举习近平新时代中国特色社会主义思想伟大旗帜，坚定不移做到“两个维护”。
> 
>   
> 
> 二要紧紧围绕“坚持以社会主义核心价值观引领文化建设制度”，在铸魂聚魄上下功夫，弘扬主旋律、传播正能量。
> 
>   
> 
> 三要紧紧围绕“健全人民文化权益保障制度”，在完善服务体系、提高服务能力上下功夫，为人民提供更多更好的视听服务。
> 
>   
> 
> **四要紧紧围绕“完善坚持正确导向的舆论引导工作机制”，在提高宣传舆论工作水平上下功夫，唱响新时代最强音，做大做强主流思想舆论。**
> 
>   
> 
> **五要紧紧围绕“建立健全把社会效益放在首位、社会效益和经济效益相统一的文化创作生产体制机制”，在强化行业担当、体现行业价值上下功夫，推动广播电视和网络视听高质量创新性发展。**
> 
>   
> 
> 六要紧紧围绕“坚持和完善党的领导制度体系”，坚持党的建设和全面从严治党抓牢抓实、贯穿始终，为推进广电行业治理体系和治理能力现代化提供坚强保证。  

  

高建民在发言中指出，**深入学习贯彻落实会议精神，以制度机制建设强化导向管理，推进精品创作，加强行业治理，加强党建工作，开创广播电视和网络视听高质量发展新局面。**

  

范卫平在发言中指出，深入学习贯彻落实会议精神，联系广播电视和网络视听工作的实际，就是要**加快推进广播电视和网络视听治理体系和治理能力现代化，从政治保障、思想保障、组织保障、宣传保障、发展保障、服务保障、法治保障、人才保障等各方面抓好落实。**
