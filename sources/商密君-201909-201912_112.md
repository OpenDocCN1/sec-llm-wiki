美国和日本的密码战实际上早在一战末期就已经开始。一战的硝烟还未散尽，以美日英为主的世界列强之间一场造舰大战即已上演。原本希望在战后取得世界一哥地位并且大幅度超越其他各国的美国海军迫不及待的制定计划，准备建造十六艘超弩级战列舰。所谓弩级战舰就是大家熟知的无畏级战舰，排水量接近2万吨，而超弩级比这一吨位有更大的提升。可惜美军尴尬的发现自己的动作激起了日本强烈的争胜心，在日军的计划中八八舰队将从质和量两方面与美国一较高下，刚好也是十六艘。同时英国窘于自己昔日世界首强的颜面不得不全力跟进以免落后于第一阵营。为了避免过度的军备拖累各国经济，1921年11月，根据美国提议，在华盛顿召开了五强会议协商限定各国的造舰配额。这看起来仅是一次普通的国际会议，但实际上背后的情报战和密码战早已打响。华盛顿会议期间，美方一共破译了超过5千份的来自各地的日本外交电报，甚至包括直接发给谈判代表团的绝密训令。比如1921年11月28日，东京向日方全权代表藤友三郎发出了一份标有“十三号机密”的电报，其中划定了此次谈判日本的底线。电报指示藤友在必要时可以放弃日方尽力争取的第一方案（10比7），甚至第二方案（10比6.5）。如果美方同意维持目前其在太平洋的防务部署态势，不进入西太平洋的话，则在不得已之时还可以接受（10比6）的第三方案。这里面提到的比例就是美日海军的吨位配额之比。就是这么一份无比重要的电令，事先却被美军完全掌握。谈判的底牌让人看清，结果自然不会有利，日方最后果然接受了第三方案。

![](../Images/f112c7a1a25bb270c07e118e50342b4f.png)

**1921华盛顿海军会议**

破解这些日本电报的功臣是美国军队情报事业的早期奠基人赫伯特·亚德利（Herbert Osborn Yardley），他也是最早一代的密码英雄。亚德利最初在美国国务院密码室工作。在那儿，酷爱钻研电文破解技术的亚德利发现整个国务院的加密系统脆弱不堪，甚至连威尔逊总统本人的密码在十年之中都不曾更换过。为此他特意撰写了一份“美国外交密码解决方案”的报告。1917年5月，美军刚刚参加一战后，亚德利投笔从戎，作为陆军中尉加入陆军情报机关。他说服负责人拉尔夫·范·德曼（RalphVan Deman）少将在情报机构中设立了一个专门的密码第八科（MI-8），亚德利担任科长。一战期间，MI-8主要负责处理和破译往来于巴西、阿根廷、智利、古巴、墨西哥等拉丁美洲国家的西语和葡语外交电报。一战结束后的1919年5月16日，亚德利向陆军参谋长提出建立一个永久的密码研究和破译组织。鉴于战时亚德利的出色组织能力和表现，三天后这一建议得到批准。这个由国防部和陆军情报机构联合资助的密码局就是后来大名鼎鼎的黑屋（BlackChamber），办公地点设在纽约市。黑屋每年依计划从国防部和陆军获得大约10万元的拨款，不过在实际过程中从来没有满额给付。

20年代初，美国黑屋的密码侦破重心毫无疑问的放在了日本方面。日本外务省当时使用的是安全性不高的字母替换式加密方法，就是把每个日本字母替换成两个罗马字母，这在破解时很容易找到各种线索。比如最常用的日文字母，最高频率使用的音节，还有电报开头和结尾最容易出现的固定字母等等。日本怎么会使用如此弱的密码？其实考虑到不久之前，美国总统使用的密码也十年没有改变的事实，这一情况就不难理解，关键还在于当时的人们普遍性的缺乏保密意识。

![](../Images/32cd08230e5df4e5392576b2459ebca7.png)

**杨·科瓦列夫斯基（****Jan Kowalewski****）**

在华盛顿会议结束之后的1923年，日本意识到了这一不足。他们从波兰请来了密码专家杨·科瓦列夫斯基（Jan Kowalewski）上尉来进行授课培训。科瓦列夫斯基刚刚在苏波战争的密码破译工作中立下大功。尽管有些同事形容他破解密码的方式是凭借蛮力和运气，但是他仍有一项贡献是不容忽视的，那就是他发现和召集了雷耶夫斯基这些密码天才，而这些人正是盟军破译德国恩格玛机真正的首功之臣。科瓦列夫斯基教会日本人如何把密码拆成三到四个不同的部分，如何把每个部分的内容全部打乱次序，以及如何使用多种密码系统进行交替加密，在他的帮助下，日本人建立了多达十一种的密码本体系，这无疑改善了加密体系的安全性。不过，在华盛顿裁军会议这段时间，日本的防线还是很容易突破的。亚德利从1919年接受任务开始，废寝忘食的工作。尽管他对日语一窍不通，他还是克服种种困难，终于在1920年1月12日，提交了第一份破解出来的密码。亚德利把第一个破解开的日本密码称作Ja，J代表日本，a的意思是第一个，这意味着后面还会有b，c，d等等。到1921年华盛顿会议召开之前，日本突然改用的所谓《西暗号书》的新密码被破译之后，亚德利将其编号为Jp，这代表他的小组已经掌握了16种日方密码。就是这些密码帮助美国在华盛顿会议谈判中占尽了信息优势，从而迫使日本在12月10日最终接受了一个很低的舰队体量限制吨位。而可怜的是就连这份屈服的电报实际上也是美国人先于日本代表团知悉的。

![](../Images/0c7bad0d884aa93c1f1f4409246c7762.png)

华盛顿会议期间破解的日本电报既是亚德利一生光辉的顶点，也是他职业生涯下坡路的开始。由于战争已经结束，美国重新失去了对密码事业的热情，亚德利逐渐丢掉了饭碗，甚至要靠撰写回忆录为生。不过，他的回忆录《美国黑屋》（TheAmerican Black Chamber）取得了空前的成功，闻所未闻的大量隐秘情节和密码战吸引了众多读者。该书在美国销售了17931本，在英国销售了5480本，在日本更是惊人的售出了33119本。一时间，整个日本从政界到民间，举国上下一阵骚动，特别是书中所披露的大量华盛顿会议期间密码战的细节，让完全蒙在鼓里的日本军方成了众矢之的。许多人都对政府与军队加强保密工作给出了建议。某种程度上来说，正是这本书帮助日本这个未来二战中美国的主要对手全面提升了保密意识。而且，这本书还迫使十九个国家纷纷更换了正在使用的密码，所以美军稍后的另一位密码奇才弗里德曼才会说：“他（亚德利）对我们国家的巨大损害，也许未来的很多年都不会显现出来。”后来美国政府在1933年，针对亚德利这本书引起的种种后患专门修正了间谍法（TheEspionage Act），禁止出版物中披露任何外国的密码或者加密的信息。二战期间，亚德利受蒋介石之邀还曾来到中国重庆帮助国民政府破解日军密码，不过客观的来说亚德利的密码破译能力在一战时代或许还可以有些成绩，但到了20年代之后他已经落伍了。在中国，他破解的也都是一些很简单的假名移位密码。

![](../Images/fd49caa169a37d0c7ca0a13b13f646f5.png)

**赫伯特·亚德利（Herbert Osborn Yardley）**

亚德利为美国政府建立了最早的密码机构，但是在他之后的美国国务院却完全忽视了密码体系的重大价值。主政者更多的是出于所谓的道德考虑而自我设限。1929年，亨利·斯蒂姆森（HenryLewis Stimson）就任胡佛总统的国务卿。这位绅士最喜欢说的一句话就是“绅士们才不去读别人的信件”（Gentleman do not readeach other's mail）。1930年，当斯蒂姆森得知国务院内竟然还保留有秘密的俗称黑屋的密码机关时，他愤怒的终止了拨款，因为这种机构破坏了他所坚持的“想让别人相信自己，先要自己相信别人”的政治原则。所以有人曾经戏称，二三十年代的美国政府就是一条玻璃鱼缸里的金鱼。以至于到了后来二战刚开始时，罗斯福总统宁愿使用海军的加密系统也不愿通过国务院与重要单位进行通信。

然而与美国政府相对应的却是军方在密码方面的飞速进展，这就不得不提到刚才那位批评亚德利损害国家的弗里德曼。威廉·弗里德曼（WilliamFrederick Friedman）是继亚德利之后美国密码事业的另一位重要英才。与亚德利略有不同，弗里德曼的能力主要体现在破解密码的硬实力上。当一战末期，亚德利随同参战美军建立了MI-8密码科在战场上驰骋时，弗里德曼却仍在国内的河岸研究孜孜以求，专注于探求密码学的奥秘。

![](../Images/d256fcef8995898bdf4c8c4f29b690fd.png)

**美国黑屋**

有意思的是，弗里德曼首先要对付的破解对象竟然是一群印度人。这些追求独立的印度民族主义青年在德国支持下，趁着宗主国英国忙于欧陆战场而进行游击战。当时他们不断向柏林拍报，这些文字全部送到了弗里德曼眼前。印度人使用的是一种许多初级密码爱好者非常热衷的而且自认为极为安全的书本密码，这也就是电视剧《潜伏》里余则成使用的那种密码。加密者和解密者同时约定一本书，密文是一系列的定位数字，通过数字锁定书本上的字还原出信息。其实，这种密码是极易破解的。尤其是这些印度青年在密码学上的无知更加暴露了自己。他们总是在一次电报中传递好几页的内容，其中大部分又是明文，只有在个别的需要保密的地方才使用书本密码。更糟糕的是当他们要对同一个字母加密时，甚至都懒得去替换成另一个位置而总是重复的使用相同坐标。弗里德曼根据明文非常容易猜到密文的大致含义，又因为大量重复的存在，这让他很快就明白了每个坐标代表的字母。到最后，甚至连作为密钥的书都给找出来了，那就是1913年出版的学术著作《德国与德国人》。

弗里德曼在河岸研究所撰写了大量的技术论文并收录在《河岸文集》当中，在这些作品中他提出了一系列重要的破译思想，其中影响力最大的就是《河岸文集》的第22篇论文，这里面提到的两个概率参数把密码学带到了新的高度。

![](../Images/7472fe377b40196973f76148c9e073d7.png)

**密码夫妻-弗里德曼和妻子**

设想有一个罐子，里面装着26个字母。每次从中抽取到某个特定字母的该率，例如抽到字母a的概率，是1/26，而连续两次抽到同一个字母a的概率就是(1/26)×(1/26)。很自然的，连续抽到两个b的概率也是(1/26)×(1/26)，以此类推其他的每个字母被连续抽到两次的概率都是(1/26)×(1/26)。把以上所有字母的二连中概率加起来，就是在连续两次抽取字母的操作时，所有可能的组合中，发生字母相同的概率，即1/26，约等于0.0385。

对于加密后的密文而言，此前的节目已经说过，为了抹平任何字母间频率的差异，避免由此带来的信息抓手被用于解密。在一般情况下，密文中的各字母频率是完全相等的。这是一种必要的隐藏，而这就相当于上面例子中所说的均匀分布字母的罐子，所以从中抽出两个字母而又恰好相同的概率就是0.0385，这叫做碰撞概率。也就是说，当我们把两段由相同密钥加密后的密文上下叠放在一起查看的时候，同一位置出现相同字母的概率就应该是0.0385，即每查看100个字母对，大约有3.85对是一样的。

再来看明文的情况，我们做类似的考察。明文就是自然文字，每个字母出现的频率符合统计字频。现在还是给出两个罐子，里面的字母比例不再是均匀的而是符合统计字频的。简单来说，大约每100个字母里有8个a，1个b，3个c，13个e等等。这个时候连续抓到两个a的概率就是(8/100)×(8/100)，连续抓到两个b的概率就是(1/100)×(1/100)，以此类推，可以得到每个字母二连中的概率。把所有这些加起来，就可以得出在统计字频分布下，两个字母的碰撞概率为0.0667。这意味着，把两段明文并排放在一起并拿出100个字母对时，大约有6.67对会是相同的。

![](../Images/9df45cd4b8bbf6125a204102bd67a2ad.png)

0.0667和0.0385这两个概率是明文与密文的天然属性，它和具体的明文内容无关也和具体的加密方法无关，0.0385是字母在均匀分布下的碰撞概率，用Kr表示，称作随机字母重码率，或者密文字母重码率，简称为密重率；而0.0667是字母在自然分布下的碰撞概率，用Kp表示，称作明文字母重码率，简称明重率。数学上把明重率Kp叫做Kappa值。从统计角度来看，明重率和密重率这两个数值显著不同，易于分辨，所以它们就为密码破解提供了宝贵的突破口。当然以上的两个具体数值是针对英文而言的，对其他的语言，Kappa值肯定不同，例如法语的Kp是0.0778，德语是0.0762，俄语是0.0529。Kappa值为什么重要，因为它解决了密码破译当中一个最重要也是最优先的归类问题。一份密码为了安全性，加密者会使用不同的密钥来加密其不同部分。所以反过来要想破解，首先应该把那些使用了相同密钥加密的内容归集在一起，这样才可能取得后面的突破。Kappa值就具有这样的归类和鉴别能力。当两段密文叠在一起的时候，如果它们不是相同密钥加密的结果，那同字母对儿出现的概率一定接近Kappa值；只有当它们属于同密钥加密文时，统计几率才会接近于密重率数值。之所以出现这样的结果，是因为同一个密钥才能够让密文中的字母呈现均匀分布，而不同密钥的加密文混合在一起后，均匀分布就被打破了，反而构成了随机分布。此时字母碰撞的概率自然就更接近于Kappa值而不是接近密重率。由此，破译人员可以使用一种简单粗暴但非常有效的方法来找出所有的由相同密钥加密的内容。这个方法就是不断地尝试把密文中的各句各段叠放在一起，进行同字母对的频率统计。当出现Kappa值时，可以快速排除，继续向下移位比对；当出现密重率时，即可认为此时叠放在一起的两段内容为共同密钥所致，这就是最简单的Kappa检测。两段密文通过Kappa检测的过程也叫做对准。

![](../Images/c9171af1eec09eeab569213f80ad6e96.png)

在Kappa检测的基础之上，弗里德曼的助手所罗门·库尔巴克（Soloman Kullback）进一步的从实用化的角度提出了操作性更强的Phi检测和Chi检测。Phi检测通过比较理论Phi值和统计Phi值判定一份密文是由单一密表加密所得还是多份密表加密所得，区分原理大体相同于Kappa检测。而Chi检测则可以通过比较Chi值判定出两份密文的密钥是否一致。举个例子，现在有三份密文A、B、C，如何根据Chi检测来判断其密钥相同性呢？很简单，把全体字母从A到Z排成一行，每一份密文都可以统计出该文中各字母出现的次数。把这个次数填入到所对应的字母横行下方的位置构成新的一行数字,如此一来三份报文会填写出三个数字行A、B、C。

A B C D E FG H I J K L M N O P Q R S T U V W X Y Z

A：0 1 0 1 0 4 0 1 3 2 1 0 2 4 0 0 1 1 0 2 1 1 0 0 0 0   

B：2 1 2 2 0 2 3 0 0 4 0 3 4 0 3 0 0 0 0 0 6 0 0 0 2 1   

C：0 0 0 1 0 2 2 1 0 2 0 4 1 1 0 0 0 1 0 0 2 0 0 2 0 0   

例如密文A的数字行就表示字母B出现了1次，D出现了1次，F出现了4次，H出现了一次...。

现在把A行中各字母出现的次数相加得到总次数25，同样也算出BC行的总次数，例如是35,19。接下来分别交叉计算两行间的Chi值。

A行和B行： 25×35×0.067=58

A行和C行： 25×19×0.067=32

B行和C行： 35×19×0.067=44

58,32，44就是Chi的理论值。

然后在两行间按照字母次数×字母次数的规则在对应字母位置计算出两个交叉行的结果，并且求和，可以得出AB行的累计值33，AC行累计值23，BC行累计值48。这就是Chi的统计值。

对比Chi值的理论值和统计值，可以发现，只有BC行的理论值44和统计值48非常接近，所以B报文和C报文使用的是相同密钥。

弗里德曼团队发现的这一理论至关重要，因为他们甚至可以不需要借助任何的对明文的猜测就能够将密文进行准确的分类，并判断出密钥字母之间的移动关系。这对于后来出现的以恩格玛机为代表的机械轮盘密码的破解非常关键。轮盘式密码不论多么复杂，本质上其都是在使用一个具有复杂移动关系的组合密表。而Kappa检测既可以分辨出密表是否已经分解到了单一的程度，又能够检测出单一密表间的密钥字母的移动关系。这无疑是人类密码破解技术史上最伟大的一次突破。其价值甚至在某些方面超越了图灵团队的贡献。因为图灵使用的暴力破解是用抓辫子的方法利用小抄儿（Crib）作为已知线索来缩小搜索范围，这毕竟对外面的输入信息是有依赖的。而弗里德曼等人仅仅通过复杂变换间的频率关系就找到了机械式密码无法遁形的漏洞，这才是真正的命门。所以到了后来，弗里德曼不需要找到一台日本的密码机器也可以复制出工作原理相同的原型机，成功破解了日军的紫色密码。

1956年，美国国会决定支付弗里德曼十万美元。这可不是什么奖金，而是名副其实的商业费用。因为弗里德曼凭借自己的知识不仅在解密，也发明了大量的加密技术和器械。出于保密的关系，他无法为这些发明申请专利。实在觉得不好意思的美国国会最后决定以十万美元授予弗里德曼，此次弥补美国人们心中的亏欠。然而实际上，这些技术又何止十万美元呢？
