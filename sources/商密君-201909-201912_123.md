# 2018年中国工业互联网市场规模同比增长13.8%（内附完整报告）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247486316&idx=6&sn=502c6d2eb93aab7e1ed64d823ecf858d&chksm=ec551b37db229221018b21de200529587858237a8959f238adca3dc9d3a9b4232b9c38d62f40&scene=126&sessionid=1681315931#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247486316&idx=6&sn=502c6d2eb93aab7e1ed64d823ecf858d&chksm=ec551b37db229221018b21de200529587858237a8959f238adca3dc9d3a9b4232b9c38d62f40&scene=126&sessionid=1681315931#rd)

近日，赛迪顾问发布了2018年工业互联网市场数据的报告。报告显示，2018年，全球工业互联网市场规模达到8059.1亿美元，同比2017年增长5.5%。其中，**2018年，中国工业互联网市场规模总量达到5358.9亿元，同比增长13.8%。**

根据报告，**2018年全球工业互联网产品市场结构主要聚焦在硬件与网络、软件与平台及工业信息安全**三方面，其中，硬件与网络产品市场占比最大，规模达到4017.1亿美元，占比达49.8%；其次是软件与平台市场，规模达到3892.9亿美元，占比达48.3%，最后是工业信息安全市场，规模达到149.1亿美元，占比达1.9%。

而中国在工业互联网细分产品领域中，**工业软件保持着较快的增长速度**，主要受益于软件和大数据应用范围扩大，智能制造流程自动化进一步深入带来的信息化需求，而硬件设备产品占比仍居首位。

此外，中国在2018年工业互联网区域市场上，**中南、华北及华东市场仍占据主体地位。****以京津冀为核心的华北市场增长迅猛，市场占比达到25.3%，中南地区仍是市场规模最大的区域，为1607.7亿元。**
