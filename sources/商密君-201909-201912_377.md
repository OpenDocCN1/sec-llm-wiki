# 

读博期间，

# 

发现一种将损失降到0的材质：超导体，

# 

但令人遗憾的是，

# 

  

此后百年间，

无数科学家在黑暗中摸索，

一直希望研制出能够在常温条件下，

实现超导体性能的材料，

**直到中国天才少年曹原的出现。**

  

![](../Images/ffac84ae3133d6a34e849ac777b8b331.png)

彼此之间发生轻微偏移的时候

有可能实现超导体性能！

对这一猜想嗤之以鼻，

他们无论如何不相信

这个仅仅23岁的中国学生

能够解决困扰物理届107年的难题！

  

面对物理前辈们的质疑，

曹原唯一能做的，

就是用成果证明自己！

然而把理论转为实验十分困难，

伴随他最多的就是各种失败。

不知经历多少不眠之夜后，

**在一次实验中曹原将**

**两层石墨烯以1.1°的角度叠加时，**

**奇迹出现，超导体诞生了！**
