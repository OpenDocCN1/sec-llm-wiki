# 最终倒计时：微软将在99天之内淘汰Windows 7/Server 2008/2008R2

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247485206&idx=5&sn=e0453a8fdaac14e049c2e745c1aa6358&chksm=ec55174ddb229e5bfaad187fca0def18f7363f20f48831fe0e16a43992c6ab3c32ce91461dc9&scene=126&sessionid=1681316205#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247485206&idx=5&sn=e0453a8fdaac14e049c2e745c1aa6358&chksm=ec55174ddb229e5bfaad187fca0def18f7363f20f48831fe0e16a43992c6ab3c32ce91461dc9&scene=126&sessionid=1681316205#rd)

**微软将于2020年1月14日正式结束对Windows7和Windows Server 2008及2008 R2 系统的所有支持。**  

![](../Images/8070327d5bc1b1895bbbba8917d3df37.png)

  

Windows 10已经是全球排名第一的台式机操作系统，仅在最近就达到了9亿台活动设备，但另一方面，Windows 7仍然是微软的主要难题。

  

![](../Images/0f778247c3e0c68e48d4d94ea5a9a52f.png)

  

Windows 7不仅是全球使用率第二高的PC操作系统，而且还快要被淘汰了，这使Microsoft回到说服用户升级到较新Windows的痛苦斗争上。

  

随着Windows 7即将终止支持，用户只有99天的时间来安装Windows 8.1或Windows 10，或者显然是迁移到Linux或macOS等其他平台。

  

微软推荐的选择是Windows 10，特别是考虑到公司为使该版本正确所做的一切努力。

  

对于更多企业服务器的安全警告  
**对Windows Server 2008 和 2008 R2 的支持将于 2020 年 1 月 14 日结束。**这意味着定期安全更新将结束。不要让你的基础结构和应用程序处于不受保护的状态。我们随时帮助您迁移到当前版本，以获得增强的安全性、性能和创新技术。

  

![](../Images/19460c562e74cf0564e4ad4b3d6f9b98.png)

支持结束意味着定期安全更新将结束。随着网络攻击变得越来越复杂和频繁，在不受支持的版本上运行应用和数据会造成严重的安全性和合规性风险。2008 系列产品在当时很棒，但是我们强烈建议升级到最新版本，以获得更好的性能、效率和定期的安全更新。

  

（其实早在2012年9月，微软延长了Windows Server 2008的两年周期。本定于2013年9月7日正式结束支持的Windows Server 2008将延期至2015年1月15日。从2015年1月15号开始，Windows Server 2008将提供免费安全更新，但其他更新则需要付费。而在主流支持方面，所有的更新和补丁都将免费提供。到2015年，微软再次决定延长这两个产品的生命周期。）

**对于愿意再掏钱企业用户，好消息：**

微软对此曲线的提出了另一个解决方法：用户如果同意将其工作负载迁移至Azure，微软就将为这些他们延长三年维护时间。同意这一做法的用户，他们使用的Windows Server 2008/2008 R2将继续免费获得安全更新直至2023年1月，对SQL Server 2008/2008 R2则至2022年7月。

  

用户若不愿意或在时间截止前仍无法迁移至Azure平台的，可以选择付费获取更新，费用为过去这些产品授权的75%。

  

![](../Images/000fcd9976767bb7debc9fceb67ec5fd.png)

  

  

此外，移动到云端选项的客户也可以将他们的Windows Server / SQL Server工作负载移动到Azure Stack，这是Microsoft的本地版Azure。三年免费支持期结束之后，用户若想继续获得支持，可以升级到新版本的Windows Server和/或SQL Server。

  

**Windows 7上的时钟在滴答作响**

但是，将用户从Windows 7迁移到Windows 10可能要比2014年初将Windows XP设备升级到受支持的Windows困难得多。这全都是因为从Windows 7过渡到Windows 8.1或Windows 10的意义在第一地点。

  

Windows 7通常被描述为提供传统Windows体验而无需存储和其他所有现代功能的最后一个操作系统。Windows 8是第一个带有内置应用程序商店和Metro UI的版本，尽管Windows 10极大地改善了所有这些方面的体验，但无论如何仍被认为是现代平台。

  

即使仅在获得支持终止后，仅希望经典Windows感觉的用户也愿意使用Windows 7，据Microsoft和安全专家称，这意味着由于仍然存在的操作系统缺陷，他们的系统可能仍然容易受到攻击，不被修补。

  

另一方面，在EOL之后保护Windows 7并不是一件容易的事，特别是对于可以设置特殊策略以防止系统受到攻击的高级用户而言，仍将使用Windows 7的舰队的企业也可以使系统脱机，从而使黑客更难以破坏这些设备。
