# 武大樱花直播日程公布，“云春游”正式上线！不仅云赏樱还能云养樱！

今日，武大樱花直播日程公布！继云监工后，新的云上活动出现了！  
"云春游"！  
3月16日起，上淘宝直播，就能云游武大网红景点，不仅云赏樱，还能云“养”樱！此外，布达拉宫、四川大熊猫基地等国内外著名景点也将纷纷入驻直播间，宅家旅行终于实现了~  
![](../Images/39a56101ad674d21a598b604491a7b02.png)据悉，今年淘宝直播将连续10天，以多路信号、多个直播间全景呈现武大樱花的盛况。全国上亿网友足不出户就能在淘宝APP里搜“武大樱花开了”，直达赏樱现场。  
![](../Images/f50547789e8d4b9d6cb6868df9605918.png)  
每年3月都是武大樱花盛放的时节，今年的武大樱花如约开放，由于校园封闭，淘宝直播将邀请全球网友在线看武大樱花。据悉，为了更加深度的呈现武大樱花，淘宝直播特别安排了多种直播形式。3月16日上午11:30，在淘宝直播间里，武大老师和校友将带领大家走樱花大道，游老斋舍、老图书馆等校园网红景点，一一盘点校园内美景以及樱花趣事，体验更加深度的武大赏樱体验。而未来10天，“慢直播”的体验会更加奇特。每天10-16点，打开淘宝直播就能看到正在一点点绽放的樱花。武大樱花绽放的全过程都将一一呈现，有网友评论：这不仅是云赏樱，还是云“养”樱了。![](../Images/a1f2d0b43b21ad4eea5236e2f7aef5f9.png)3月上旬的武大樱花  
当前，淘宝直播已经成为人们丰富日常生活的重要平台，除了此次直播武大樱花，布达拉宫、四川大熊猫基地等国内外著名景点都纷纷登陆淘宝直播，直播间里迎来上千万游客。
