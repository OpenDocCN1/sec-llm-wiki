1月31日，美国国会研究服务局发布了《5G移动技术对国家安全的影响》(National Security Implications of Fifth Generation (5G) Mobile Technologies)报告。报告认为：与4G相比，5G将提高数据传输速度并提高带宽，从而实现新的军事和商业应用。预计5G技术将更好地支持互联和自主设备，如智能家居、自动驾驶汽车、精密农业系统、工业机械和先进的机器人技术。在军事领域，5G可以进一步改善情报、监视和侦察(ISR)系统及处理能力；有助于启用新的命令和控制方法、精简后勤系统等。


报告指出：随着5G技术的开发和部署，国会可能需要考虑频谱管理、国家安全问题以及对美国军事行动的影响。

  

一、频谱管理


5G的发展需要在多频段部署相关的技术，包括毫米波及6 GHz以下频段。毫米波可以提供更大的带宽和更快的传输速率，一些电信公司认为自动驾驶汽车和其他数据密集型应用（例如智能城市）需要使用毫米波。但是，毫米波传输的距离相对较短，可能被雨水吸收或被建筑物和车辆等有形物体破坏。与6 GHz以下技术相比，5G 毫米波技术需要安装更多数量的蜂窝基站，成本更高、部署时间更慢。因此，5G的部署依赖于毫米波进行高速、高带宽的通信，而依靠6 GHz以下频段来覆盖全国。


世界各地的电信公司正在以不同的方式部署5G。中国电信公司将重点放在价格较低的6 GHz以下频段，而美国电信提供商在毫米波和6 GHz以下频段都有部署。


目前，美国大量的可用频谱资源归美国国防部（DOD）所有。DOD将某些毫米波频段用于备受瞩目的军事应用程序，例如为美国部队提供可靠的全球通信的极高频卫星，但是DOD更广泛地使用6 GHz以下频段，这使得美国在6 GHz以下频段的可用性低于其他国家。国防创新委员会（DIB）建议DOD考虑共享6 GHz以下频段，以促进5G网络的建设以及在该频段5G技术的发展。虽然DOD一直致力于在更大范围实现频谱共享，但也对共享可能带来的运营、干扰和安全等方面的问题表示担忧。作为替代频谱共享的方案，一些分析人士认为6 GHz以下频段应保留用于商业用途。但是，上述替代方案将要求DOD将某些应用重新转移到其他频段。DIB估计，此方案将需要大约10年时间才能完成，而频谱共享只需要5年。


二、国家安全问题


根据DIB的评估，目前中国在6 GHz以下频段技术中处于领先地位，并有可能在全球范围内部署首个5G广域网。报告中单独提到了华为，指出仅华为一家中国公司就与大约30个国家/地区签署了5G基础设施建设的合同，其中就包括美国的盟国冰岛、土耳其和英国等。该报告中分析的国家安全相关问题，主要针对来自中国的供应商和设备。


一是指责中国设备的漏洞可能被用来进行网络攻击以及军事或工业间谍活动。报告指出：一些专家声称，漏洞是由许多中国公司的经营不善导致的，但是他们同时指出漏洞也可能是出于恶意而故意引入的。针对中国《国家情报法》关于“任何组织和公民都应当依法支持、协助和配合国家情报工作，保守所知悉的国家情报工作秘密”的规定，报告提到一些分析人士将上述法律规定解释为要求中国电信公司与情报部门合作，包括被迫安装后门或向政府提供私人数据。


二是对中国设备的风险有不同认识。一些分析人士认为，中国电信设备带来的风险程度因设备在蜂窝网络架构中所处的位置不同而变化。大多数蜂窝网络分为两类：核心网络和无线电接入网络，其中前者提供连接到互联网的网关并确保设备符合提供商的标准，后者由广播和接收无线电信号的蜂窝塔组成。这部分分析人士指出，中国核心网络引发的风险是非常重要的，中国无线接入网带来的风险是可以管控的。另外，还有其他一些分析人士认为，在网络中安装任何中国设备都可能引发安全隐患，这类分析人士认为美国应限制与使用中国5G设备的国家共享情报。


三、对军事行动的影响


报告指出：5G技术可能具有许多潜在的军事应用，尤其是对于自动驾驶汽车、指挥与控制、后勤、维护、虚拟现实以及情报、监视和侦察系统，所有这些都将受益于5G技术更高的数据速率和更低的时间延迟。


对于无人驾驶军事车辆，其可以通过在云中存储大型数据库（如地图）来潜在地规避机载数据处理的限制，而安全的车辆运营将需要5G的高数据速率和低延迟来快速下载车外信息，并将其与车内传感器数据进行合成。同时，5G可用于传输操作员与无人驾驶车辆之间的传感器数据，这可能会创造新的军事行动概念，如车辆自主协调完成任务。对于ISR系统，该系统越来越需要高带宽来处理、利用和传播来自越来越多战场传感器的信息，5G技术的应用可以使指挥官及时访问可采取行动的情报数据，从而改善作战决策。对于其他数据密集型活动（如物流和维护），5G可以减少延迟，并且可以额外启用增强的或虚拟现实环境来加强培训。对于指挥和控制系统，目前美国军方使用卫星通信来进行长距离通信，但由于信号需要传播的距离，轨道上的卫星会大大增加延迟，从而导致军事行动的执行出现延迟，5G的利用将改善这一现状。


报告提到尽管DOD处于5G应用测试和试验的初期阶段，但其已经选择了四个军事基地作为测试平台，就智能仓库、频谱共享、增强与虚拟现实发布了原型建议书请求草案（A draft request for prototype proposals）。


四、国会需要考虑的问题


在上述分析的基础上，报告最后提出了美国国会需要考虑的问题，包括：


  • 在满足日益增长的商业需求的同时，什么样的频谱管理方法（如频谱共享、频谱重新分配）能够最好地保障DOD的任务？


  • 盟国和伙伴国使用中国5G基础设施对美国国家安全构成哪些风险，这些风险能否得到控制？如果可以，如何管理？


  • 盟国和伙伴国对中国5G基础设施的使用会对军事效能和互操作性产生什么影响？美国是否应限制与使用中国5G设备的国家进行情报共享？


  • 由于5G在军事方面的发展应用，是否需要对作战概念、部队结构、相关学说或立场进行更改？
