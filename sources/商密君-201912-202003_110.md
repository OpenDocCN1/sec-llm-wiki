# 人气爆棚的副教授易中天为何没能转正？他离职时说：武汉天气不好

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247488288&idx=4&sn=c22a47ad58f323a9a0dc76f15efe6d44&chksm=ec55037bdb228a6d8d5843c6697971a6e015dc7616bae63215ffec157ea7f559ea9b418cb4ab&scene=126&sessionid=1681314078#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247488288&idx=4&sn=c22a47ad58f323a9a0dc76f15efe6d44&chksm=ec55037bdb228a6d8d5843c6697971a6e015dc7616bae63215ffec157ea7f559ea9b418cb4ab&scene=126&sessionid=1681314078#rd)

“无一日敢懈怠，无一事敢马虎，心存敬畏之心，不要得意忘形”，易中天是这么说的，也是这么做的。

![](../Images/b2cc5eaa2ee84fa36d022b7f666d13bb.png)

他在武汉大学、厦门大学和《百家讲坛》任职期间都是兢兢业业，未曾有一点马虎。这样的处事态度也使易中天备受同学的敬爱，武汉大学曾经的校长刘道玉也是非常欣赏他，然而，易中天在武大却只是“永远的副教授”，这是为何？

# 最受欢迎的中文老师，课上座无虚席

易中天是湖南人，因为父亲工作的原因来到了武汉这座城市，很快，武汉的美丽吸引了易中天，让他决定一直待在这里。虽然他曾经去新疆支教过一段时间，但是他最终还是回到了武汉这一方天地。在武汉大学毕业以后留在了这里，成为了学校里的四大名嘴，非常受学生欢迎。

大学生逃课的本事一直很厉害，除了高数、线代这样的课程，或者是查勤特别厉害的老师的课，很少有一节课人是来齐的。虽然说抢前排一直都不是什么容易的事情（部分被视为“水课”的除外），但没有座位的时候真的是很少。

![](../Images/5159a4ceb6e41ef23b2a37dae7651969.png)

然而当时要想能坐在座位上听易中天讲一节课，至少要提前半小时到，要抢到前排更是困难重重。能容纳三百人的教室，座无虚席，连过道上都是搬着小板凳来听课的人。

作家野夫来武汉插班的时候，向学长询问在武大里都有什么要注意的事情。那位学长就告诉他，一定要听易中天老师讲课，无论他讲什么课，有机会听就一定要去。

我们大多数人都在《百家讲坛》里见识过易中天的妙语连珠、风趣幽默，也就不难理解为什么武大的学生都如此敬爱他。他兢兢业业的态度，让听他课的学生都学到了真正的知识。易中天讲课绝不照着ppt直接念，他是一定要对自己的所有课认真负责的。

当时的老校长刘道玉，也是个伯乐，一眼就相中了易中天这匹千里马。他作为一个学者，非常欣赏易中天，和易中天的交情颇深。因为赏识，当时还提拔易中天当系副主任。

![](../Images/a284cda83066822e588201d24abdf9c8.png)

  

  

# 受到其他人的排挤，生活困苦

如此有名，按理说易中天的工资应该是很高的，起码能让一家人都过得滋滋润润。然而事实却很令人惊讶。他没有搬进舒适宽敞的教师宿舍，而是住着三十多平米的房子，小到不够一家三口住，连女儿也要被送进父母家。他工资很少，连黄鹤楼的烟也抽不起，竟然因为穷戒掉了烟。因为钱不够，他还不得不兼职来补贴家用。在上完课后，还要在简陋的住所里奋笔疾书，写下一篇篇的稿子。

这般困苦，只是因为他太过耀眼。在武汉大学，其他的老师都没有他受欢迎。那些课堂里学生从来都没有来齐过的老师，不是去想怎么提高自己的水平，而是去嫉妒易中天。易中天也是个耿直的人，有话就直说，从来不会因为是领导就溜须拍马，加上有同事暗中迫害他，易中天一直都没有被提拔为教授。

![](../Images/8886fbf6387d87e2882837f566405fdd.png)

在校长刘道玉离职后，易中天的日子更是难过。因为新校长上任，易中天又是曾经老校长青睐的人，现在武大里支持易中天的人可以说是寥寥无几。最后，在易中天离职的前夕他才被提拔为副教授，自始至终没有当过教授。

他离开后，其他的老师是舒坦了，觉得除掉了眼中钉、肉中刺。只有原来的老校长觉得非常遗憾，武汉大学失去了一个人才。

# 中年时到厦门大学，后又主持《百家讲坛》，生活逐渐变好

日子还是得过，既然不能够留在武汉大学，就去其他地方找工作。于是，易中天来到了厦门大学。在这里，他的课堂依旧是人满为患，学生们抢着要听他的课。并且他很快得到了晋升，终于成为了教授，工资是以前的五倍之多，生活一下子明朗起来。

![](../Images/61c49163e284595f447098f1a8e5ca8d.png)

后来他还被《百家讲坛》这档节目邀请来，因为语言幽默生动，见解独到，故事叙述的条理清晰，得到了很多人的喜爱。易中天由此名声大噪，被全国人民知晓。这还让他的生活更上一个台阶，再也不用为生计发愁了。所以他也不用兼那么多的职，有时间和精力去写作，去出书，让更多的人了解中国文化。他的《易中天文化史》得到了极高的赞誉，在学术界占用着重要的地位。

在成名后，他没有膨胀起来，而是一直不忘初心，做什么事情都实打实去干，不会为了出名而拿没有经过考量的故事来哗众取宠，更不会胡编乱造。许多年过去，我们再去看《百家讲坛》，还是会觉得那么有趣，给人思考和启迪。

# 谈及母校，不言坏处，老校长为他道出无奈

后来在央视《面对面》节目中有人问起来易中天他的离职原因，他不言当初的委屈，只说是武汉天气不好，夏天太热，就此离开。但估计是有的人听出了这其中的意味，不是自然环境问题，而是社会环境的问题。做贼心虚，又去辱骂易中天。

![](../Images/d7af4c9b825060304678eda1c2da0c3f.png)

易中天便反驳，他提出三个观点。一是武汉天气不好是客观事实，二是这样说绝没有对不起武汉人的意思，三是如果连天气恶劣这点小事都不敢承认，那就更别指望武汉发展起来了。

面对如此多的观众，易中天必定不能提及他曾经受到过的排挤，环境问题只是个说辞，如果还是不领情面，便只能回怼过去了。

也有人问过刘道玉老校长这个问题，他便坦言了当初的那些委屈。原本易中天是准备一直在武汉大学干到干不动为止，但是各方各面对他有意打压。原来当初提拔为副教授，还是“提调”，意思就是，只有易中天离开武大，才给他副教授这个职位。不仅如此，易中天身为一个学者，他可以穷，但思想言论一定要向世人道出，可校方竟然在这方面都打压他，让他不得不走。

![](../Images/fb27cbd9b7cbdbff6fc366d7affac3e7.png)

我们只是见过那个在《百家讲坛》上开心幽默的易中天老师，却少有人知道他曾经的心酸苦楚。一个团体里面的人，应该是向最优秀的那个看齐，而不是去排挤这个人来保全自己的地位。当我们遇到这样的事情时也不要怨天尤人而失了本心，一条路走不了，不妨换条路继续走，一定能够有出头之日。
