# 思科准备收购网络安全公司 FireEye，目前市值 35.7 亿美元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247488108&idx=3&sn=7d5f0f27015e6eb0ba71121c2d6ff357&chksm=ec550237db228b219ce2fe3efb24320b01e8d591279160ff10a6f15a5c60391b779c9eb625f2&scene=126&sessionid=1681314093#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247488108&idx=3&sn=7d5f0f27015e6eb0ba71121c2d6ff357&chksm=ec550237db228b219ce2fe3efb24320b01e8d591279160ff10a6f15a5c60391b779c9eb625f2&scene=126&sessionid=1681314093#rd)

知情人士告诉西班牙新闻媒体《Okdiario》，思科和FireEye已进行了长期的谈判，双方的立场“比以往任何时候都更一致”，这意味着思科可能会在接下来几周发出正式的收购要约。  

![](../Images/6c878f5a5268a116789d5a6c5f62f8f4.png)

  
知情人士告诉《Okdiario》，思科与FireEye之间的谈判已进入到很后期的阶段，预计接下来几周会有报价。《Okdiario》的这篇报道出来四个月前，另一大外媒《商业内幕》报道FireEye已聘请高盛提供咨询服务：它准备挂牌出售，有望找到私募股权公司买家。  
  
FireEye已聘请高盛处理出售事宜。  
![](../Images/6025481e747e7a804f2d86594f07a81f.png)  
  
FireEye股价在周四交易日上涨0.72美元（涨幅4.57%），涨至每股16.46美元，这是该公司股票自1月21日以来的最高价。与此同时，思科股价在周四交易日却下跌了2.61美元（跌幅5.23%），跌至每股47.32美元。由于企业决策周期较长、宏观经济不确定性和地域问题，思科周三公布季度销售额下降。  
  
《Okdiario》的报道在周四清晨发布，后被金融市场内容服务网站Seeking Alpha援引而广为人知。《Okdiario》报道，思科和FireEye已进行了长期的谈判，双方的立场“比以往任何时候都更一致”，这意味着思科可能会在接下来几周发出正式的要约。  
  
知情人士告诉《Okdiario》，一家规模较小的公司也表示有意收购FireEye，鉴于思科的规模和财力，预计这家小公司的努力将落空。  
  
这不是思科和FireEye头一回在收购传闻中密切相关。实际上，Seeking Alpha和纳斯达克在2015年5月的一篇报道称思科出价90亿美元欲收购FireEye，该报道促使时任思科首席执行官的John Chambers做出了罕见的否认，尽管是间接的否认。  
![](../Images/6ad5ec0833cabf12e18db64cac9d3661.png)  
  
Chambers在2015年5月的财报电话会议上对投资者说：“我们不对还没有宣布的收购发表评论，我不会理睬你们今天听到的收购传闻。”  
  
后来《商业内幕》在2019年10月报道，由于FirEye在之前的过程中未能吸引战略性买家的兴趣，据信私募股权公司最有可能收购这家公司。知情人士当时告诉《商业内幕》，洽谈处于初期阶段，无法确定是否会达成交易。  
  
10月下旬DealReporter声称，FireEye在很难找到收购整个公司的买家之后，积极洽谈以出售旗下产品。同一天FireEye的首席执行官Kevin Mandia告诉投资者，他专注于打造最出色的安全公司。  
  
Mandia在10月29日对投资者说：“就个人习惯而言，我不会被谣言分散注意力。因此，我通常每天都露面，不去思考‘我们如何退出？’，而是思考‘我们如何执行？’”  
  
本月早些时候，向来是Mandia得力助手的Travis Reese宣布于3月1日退休，原因是FireEye在精简组织结构图，以加快执行速度、提升运营能力。为了接替Reese，FireEye请来了长期担任Vertical Communications首席执行官的Peter Bailey为首席运营官，以帮助该公司在今后一年将运营支出削减2000万美元至2500万美元。  
  
自2013年上市以来，FireEye一直在努力扭亏为盈。在截至12月31日的最近一个财年，该公司净亏损2.574亿美元，合稀释后每股亏损1.24美元。  
  
同样，自2016年初以来，FireEye的股价一直长期在每股20美元以下徘徊。这与FireEye在公司上市五个月后的2014年2月创下的历史最高价：每股逾85美元相去甚远。  
  
FireEye目前的市值为35.7亿美元，远低于目前备受华尔街推崇的两家网络安全公司：CrowdStrike和Okta，这两家公司都自2017年以来上市，今天的市值都超过了130亿美元。
