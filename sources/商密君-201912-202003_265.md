# 台积电、长江存储的“抗疫”官宣来了，半导体厂力抗“断链”危机

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247487803&idx=5&sn=a784f61e8723f769fe3a5f65ff9a9a02&chksm=ec550160db228876415177ac5d96d6e0e51de8199d0605a9c421a177e96999c9302c1ec58d59&scene=126&sessionid=1681314109#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247487803&idx=5&sn=a784f61e8723f769fe3a5f65ff9a9a02&chksm=ec550160db228876415177ac5d96d6e0e51de8199d0605a9c421a177e96999c9302c1ec58d59&scene=126&sessionid=1681314109#rd)

受到武汉肺炎疫情影响，各家半导体厂上紧发条进行**“抗疫大作战”**，确保人员健康安全和生产延续，由于疫情会持续多久很难预测，各厂也都积极沟通应对，**避免后续的供应产生“断链”。**

 

**台积电和长江存储也陆续针对这一波疫情的因应措施发出官宣。**

  

**台积电作出以下声明：**

 

**在台湾地区着重预防/提醒/监控，在上海，南京等生产依据点更积极加强，包含每日员工的监控体温，以及加强环境消毒等工作，有旅游或接触湖北省的员工当前都会先自主隔离14天。**

 

再者，台积电在南京有12寸厂，以及上海松江的8寸厂，分别因应当地政府延后开工时间，但实际上厂房内部的营运没有中断，员工仍照常轮班。

 

**参考在2003年SARS期间，台积电也执行几项内控“抗煞”**，包括自疫区返回工作职位需要自我隔离14天，部门秘书戴N95口罩负责登记部门员工和工程师的体温记录列表等。

 

再者，**厂区和生产部门也隔成不同的区域，让空调和出入口都替换，内部的常规性会议也分开两队，彼此不可对谈，只能用电话沟通。****另外，不同层级的主管和代理人不能碰面和交谈。**

  

![](../Images/38eafcf583ff868ad2aaec484fea61d3.png)  
**长江存储位处疫情中心的武汉，针对防疫的一系列措施，也进行了以下官宣：**

 

**1，保障员工健康安全**

  

长江存储始终坚持“人员安全第一”的原则，严格按照政府规定的保障人员的安全，**延缓外地员工的返岗时间**，并在条件允许的情况下，鼓励远程办公，对在岗员工做好防疫宣传和分发口罩，体温检测，加强消毒，动线隔离等工作。

  

**2，保障生产延续性**

  

当前的长江存储生产经营正常有序进行，**驻守在厂区的长存及厂商员工无感染病例，并采用分区隔离管控措施，避免外部病毒的带入。**

 

**3，将降低影响降低到最小**

  

由于外部环境变化带来的影响，长江存储积极协调政府部门，在保证安全措施下，把影响降到最小。

 

在科学有效的防控措施下，确保在保障员工健康的同时，有效避免了停电停产可能带来的安全隐患。除了半导体产业以外，能源，化工，钢铁等基础产业都存在类似的情况，不可能停下来。
