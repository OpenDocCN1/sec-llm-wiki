# 香港警方首次破获地下电台，5头目涉嫌协助暴徒被拘捕

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247487243&idx=2&sn=045eb011577cf09a634c4ecd87ac33fa&chksm=ec551f50db22964607a3496c4318e5686d41059fbe7522f6c6e4d2afb00e9c1efb192c7517a6&scene=126&sessionid=1681314995#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247487243&idx=2&sn=045eb011577cf09a634c4ecd87ac33fa&chksm=ec551f50db22964607a3496c4318e5686d41059fbe7522f6c6e4d2afb00e9c1efb192c7517a6&scene=126&sessionid=1681314995#rd)

【环球时报驻香港特约记者 杨伟民】香港“修例风波”爆发以来，警方首次破获专为激进示威者“助攻”的非法电台。

![](../Images/33c8ab89edc059bb9898e41dee149c74.png)

▲香港警方检获的无线电中转机和高频无线电对讲机（图源：香港《文汇报》）

据香港《星岛日报》2日报道，警方发现过去多次冲突包括去年10月1日、10月31日及11月7日等，都有人通过非法使用无线电广播公开警方布防位置，协助前线暴徒避开警员搜查及进行冲击，同时在近来的拘捕行动中，也在被捕人员居所或个人财物中查获为数不少的非法无线电对讲机。经调查，警方锁定操纵非法无线电台的5个头目。1日中午12时许，警方分别在跑马地、秀茂坪及尖沙咀拘捕3男2女，年龄介于25岁至68岁之间，报称从事银行、零售、工程师等职业，其中部分人具备相关无线电知识;现场搜获无线电收发器、天线及高频无线电对讲机等，相信用于售卖或提供年轻人参与非法行动。报道提及，暴徒把广播站设在公屋单位内，通过现场“哨兵”向广播站通报警员及警车所在位置，再由广播站转达给示威者。

![](../Images/1a2a8a1f639c53042107f630bbec9a00.png)

▲中转机天线（图源：大公网）

针对元旦游行演变成纵火破坏，警察公共关系科总警司郭嘉铨2日称，过去几天警方共拘捕420人，包括307男、113女，年龄介于12岁至81岁之间，他们涉嫌袭击造成身体伤害、藏有攻击性武器、非法集结、阻差办公以及刑事毁坏等。香港《大公报》的社评称，暴乱已经使香港社会付出沉重代价，游客减少、失业率上升、经济陷入技术衰退，苦日子还在后头。同样不能忽视的是，特区政府的主要精力用于止暴制乱，在发展经济、改善民生等方面难免分身不暇，这难道是港人希望看到的吗?

《星岛日报》2日的社论称，警方元旦应对破坏行动的策略有变，主要是包围拘捕及埋伏突击，而不是过去的“对峙、驱散、再对峙”。此举可以大大缩减暴徒的兵源，借用军事术语就是削弱其有生力量。同时，警方加大力度直击源头，暴徒近日在行动中使用的汽油弹数量明显减少，与警方努力捣毁“兵工厂”有关。参与破坏的未成年中学生似乎已开始减少，相信是开学之后，不少学校加强了对学生的辅导。文章说，只要当局与整个社会能共同努力从源头阻截，遏制暴力是可期的。
