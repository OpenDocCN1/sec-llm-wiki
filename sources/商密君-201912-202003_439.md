# 泰国一监狱摄像头遭攻击后被黑客全球直播，监狱网络或开辟新战场

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247487094&idx=5&sn=fbb7e42955de8ef794b5cc01607d7c50&chksm=ec551e2ddb22973b2f39a3c563fcfc2a1bb1894b62b6360f95b4df07743acb5d90e8b7b8c1de&scene=126&sessionid=1681314995#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247487094&idx=5&sn=fbb7e42955de8ef794b5cc01607d7c50&chksm=ec551e2ddb22973b2f39a3c563fcfc2a1bb1894b62b6360f95b4df07743acb5d90e8b7b8c1de&scene=126&sessionid=1681314995#rd)

12月27日消息 据外媒报道，泰国南部春蓬府一所监狱的闭路监控电视系统遭到黑客攻击，在押犯人的日常生活隐私被人放在YouTube网站直播。

  

这一看不得了，原来泰国的监狱环境如此恶劣，简直和XXX有的一比。

![](../Images/9b60c4ba0dd72e9e3687c1e617a32e4d.png)

![](../Images/397c5522df3ce1c72e41f080eb1fe469.png "泰国一监狱视频摄像头被黑客攻破：牢狱生活遭在线直播")

![](../Images/4c2126071a88786327ddced49bc27d9f.png "泰国一监狱视频摄像头被黑客攻破：牢狱生活遭在线直播")

  

据称，黑客在油管上以BigBrother’s Gaze为名进行了这场视频直播。据悉该名黑客已可以访问**整个监狱的监控系统**，而泰国官方后期承认监狱遭到入侵但是并没有透露更多信息。目前尚无更多有关黑客的相关信息以及入侵手段。泰国惩教部门主管纳拉特·萨瓦塔南上校表示，监狱官员已及时关闭了整个监控系统，目前该YouTube频道没有任何影像资料。

  

![](../Images/d5202276252f5facb56ea654e4bb4af5.png "泰国一监狱视频摄像头被黑客攻破：牢狱生活遭在线直播")

  

不过有网友提前截获油管频道的简介截图，上面出现了疑似频道创建者的道歉：“我向那些因我的直播而被冒犯的人致歉，虽然所有的摄像头都位于公共领域，同时该频道再也不会出现类似的视频内容”。最后疑似入侵者还提醒泰国监狱部门“更改标准密码。”

  

![](../Images/6323bfe21442cdc98b0031fee6a9e999.png "泰国一监狱视频摄像头被黑客攻破：牢狱生活遭在线直播")

▲清空了

这位名为Big Brother's Gaze的黑客在YouTube上的帐户还显示了来**自俄罗斯，澳大利亚和美国**等国家的监狱摄像头录像片段。

  

这充分说明了，这名黑客，是一名监狱摄像头hunter，肯定是有一定的特征可以发现这些布置在监狱的摄像头特征了，有兴趣也可以发掘一下。

  

叽里呱啦的泰语报道，听着听着就很出戏，就，很僵硬。

从该例安全事件完全可以看出一点：监狱的网络安全仍需要加大投入，若被监狱同伙入侵了监狱的摄像头，很有可能成为帮助犯人越狱提供便利，同时从如今很多“人权”家眼中，犯人如果在监狱过得不好总会出来闹两句，对于本国的形象也有所影响，因此，下次去监狱推销安全产品的时候，记得拿出黑鸟这篇文章，绝对效果翻倍。
