导读：昨晚（8月1日），有媒体报道称，在美国总统特朗普周五宣布已决定禁止TikTok之后，字节跳动已经同意完全剥离TikTok在美国的业务。


最新消息，外媒报道称微软已暂停与Tik Tok的购买交易谈判。谈判没有终结，两家公司正在努力搞清楚白宫的立场。


TikTok美国区总经理表示“我们不会离开”。

图片来源 / 视觉中国
美国总统特朗普于当地时间周五晚（北京时间周六早上）表示，他将动用他身为美国总统的权力，封杀由中国公司“字节跳动”开发并在美国广受年轻人喜爱的短视频社交软件“TikTok”（又称“美国版抖音”）。
最新的消息是，据路透消息，两位知情人士说，在特朗普周五宣布将禁止TikTok在美国的业务后，字节跳动已同意完全出售TikTok在美国的业务。
另外，据观察者网援引《华尔街日报》报道，由于总统特朗普在周五晚上明确反对由一家美国公司收购TikTok并继续在美运营的协议，目前微软已暂停收购TikTok美国业务的谈判。据称谈判并未因此终止，两家公司正努力弄清白宫的立场。

报道称，7月31日，特朗普明确表示，他反对由一家美国公司收购TikTok并继续在美运营的协议，这让微软和TikTok母公司字节跳动的收购谈判陷入僵局。

字节跳动同意放弃在TikTok的股份

据路透报道，中国字节跳动已同意出售美国业务TikTok。
字节跳动此前曾试图在TikTok的美国业务中持有少数股权，但遭到了白宫的拒绝。
消息人士称，根据新的交易提议，字节跳动将完全退出，微软将接管TikTok在美国的业务。消息人士补充称，一些总部位于美国的字节跳动投资者可能有机会获得该业务的少数股权。
消息人士称，根据字节跳动的新提议，微软将负责保护所有美国用户数据。该消息人士补充称，该计划允许微软以外的另一家美国公司收购TikTok。
根据这个方案，字节跳动全部退出后，微软将接管TikTok美国业务，负责保存管理所有美国用户数据，也允许除了微软之外另一家美国公司接管TikTok美国业务，而某些总部在美国的字节跳动投资者可能有机会获得其中少数股权。

白宫尚未就此作出回应。北京的字节跳动和微软对此均未予置评。

TikTok美区总经理：我们不会离开

“我们听到了你们的支持，我们想说声谢谢，我们哪里也不打算去。”

就在特朗普7月31日晚宣布将禁止短视频应用TikTok在美国运营后，当地时间8月1日，TikTok美国总经理瓦妮莎·帕帕斯(Vanessa Pappas)在推特上回应称，TikTok将在美国长期运营，“哪里也不打算去”，并计划在美国创造更多就业机会。
视频中TikTok美国区总经理凡妮莎·帕帕斯（Vanessa Pappas）对TikTok社区的用户致谢，并称“我们不会离开”（We‘re not going anywhere）。
帕帕斯还表示，自己感谢数百万美国民众对TikTok的支持，也为该社区中各种背景的创作者和艺术家以及1500名美国区员工感到骄傲。
她透露，未来三年TikTok将在美国提供1万个工作岗位。
她强调，TikTok会打造“最安全的应用”。
视频大意为：

我们感谢上千万每天使用TikTok的用户，以及富有创意的创作者们，我们不会离开去任何地方。


TikTok是创作者与艺术家们表达自己的地方，连接了来自世界各地的人们，非常感谢有人将TikTok称之为“家”。我同样为1500位的美国员工感到骄傲，他们每天都在为这个App工作，未来三年，我们还将为美国提供1万份的工作岗位。我们还在7月底刚刚成立了“美国创作者基金”，要用10亿美元扶持TikTok创作者们。


在隐私安全方面，我们正在建设一个最安全App，因为这是正确的事。我们追求在美国长期而稳定的运营，希望你们也能继续分享自己的声音，继续支持TikTok。

知名博主纷纷告别
在特朗普宣布将禁止TikTok在美运营后，TikTok知名博主们纷纷向粉丝们告别。
他们向大家分享心声，并鼓励粉丝在其他社交媒体平台上继续支持他们。

TikTok是怎样蹿红的？

这款软件为什么受欢迎？

图片来源 / 图虫创意
2017年，抖音推出海外版TikTok，登入苹果安卓等应用商店，并且「字节跳动」以10亿美元收购北美音乐短视频社交平台Musical.ly。
2018年8月，字节跳动放弃了Musical.ly的名称，将这款应用更名为TikTok。
随后，TikTok在印度、美国、日本等多个国家蹿红。

分析认为，字节跳动更名的做法有助于抖音在美国获得成功。许多用户在使用这些应用程序时并不知道它们是由中国公司开发的。更改名称已成为中国公司试图在美国扩张时有意采用的策略。

Sensor Tower数据分析师Sanders Tran表示，中国应用程序开发商越来越善于了解美国用户，并引起他们的共鸣。


之后，TikTok受到全球特别是年轻一代的欢迎，用户数量急剧增长，2019年全球下载量已经突破15亿次。
随着TikTok在全球的迅猛发展，它在洛杉矶，纽约，伦敦，巴黎，柏林，迪拜，新加坡，首尔，东京，孟买，雅加达，莫斯科等国际上的都市都设立了办公室。

印度2019年曾经是TikTok下载量增速最快的国家，一年达到2.776亿。

据统计，2019年，在出现后短短三年里，它的市场占有率已经超过了脸书，推特等西方所有的社交媒体平台。2020年5月的一份数据显示，抖音和TikTok在全球手机应用商店下载超过20亿次。


目前TikTok在美国的月活用户在3000万左右，占全球受众的5％。42%的用户年龄在18-24岁之间，27％的用户年龄在13-17岁之间。

也就是说，美国“Z世代”的用户，合起来占总用户群的69％，接近七成。 

有报告认为，在不被美国封杀的情况下，2020年TikTok的美国用户数量将达到 4540万人，同比增长 21.9%。而在2021年，用户规模将达到5220万。App Annie的数据则显示，TikTok的海外全球月活用户在2亿左右。而且，TikTok目前依然处于快速增长状态，因广告收入增加，字节管理层预期2021年营收将达到60亿美元，而字节跳动自设的2020年营收目标约为280亿美元。
中央纪委国家监委网站官微发布了一条视频，解释了为什么抖音海外版受欢迎。

TikTok在美国大获成功

脸书压力山大

图片来源 / 新华社
TikTok在美国市场广受追捧，也一度威胁到脸书的市场地位，Facebook之前推出的竞品根本不是TikTok对手。
据媒体报道，Facebook旗下Instagram近日向TikTok红人提供重金奖励，以说服他们加入，Instagram给其中部分创作者的开价达数十万美元。
美国的很多公司和初创公司曾多次尝试与TikTok竞争，但没有一家能达到它的受欢迎程度，而且TikTok至今仍在持续扩张。

今年一季度，TikTok的下载量比紧随其后的全球第二大最受欢迎应用WhatsApp（下载量接近2.5亿次）高出26%。


同期，Facebook下载量为1.861亿次，Instagram下载量1.518亿次。

十几岁的青少年和二十多岁的年轻美国人最喜欢TikTok。


美国调查数据显示，Tiktok对美国年轻人不仅用户增速惊人，过去半年日活用户增长高达50%，更让人惊讶的数字是用户浏览时长，18岁以上用户每月累计浏览时长高达858分钟，意味着单个用户每月看13小时以上......

TikTok在美国的强势崛起，也让Facebook感受到沉重的压力。

500亿美元的“卖身契”？

微软接盘？

图片来源 / 图虫创意
外媒分析指出，被美国资本收购，可能是应对TikTok被全美封禁风险的解决方案之一。
据悉，字节跳动日前已经收到来自美国泛大西洋投资集团和红杉资本的投资提案，他们给TikTok提出了约500亿美元的估值。如果协议成交，意味着TikTok的主要所有权将让渡于他们。消息人士还说，还有其他公司和投资公司表达了对TikTok的收购兴趣。
对于TikTok来说，500亿美元的估值相当于其2020年预计收入（约10亿美元）的50倍，这一估值已经远高于Snap等同类产品。
此外，微软目前的市值约为1.5万亿美元，手上也有足够的现金储备，它可以更轻松的支付收购费用，而不像其他投资公司一样，还需要再去筹集收购资金。
对于此事，中国专家对《环球时报》记者评论称，这是上至美国总统，下至硅谷企业，对于中国高科技创业新星的一场“超级围猎”，是商业史上一场巧取豪夺的“掠夺盛宴”。
有分析认为，在字节跳动不得不出售TikTok的情况下，微软可能是最合适的人。因为从美国最近针对科技巨头进行的反垄断调查看来，让微软和TikTok结合，可以在谷歌母公司Alphabet以及Facebook之外，再建立起一个强大的数字广告巨人，从而让市场更具活力，而不是被掌握在少数公司手中。
另外关于微软，字节跳动创始人张一鸣和该公司还有过交集，当年张一鸣毕业后，曾短暂进入过微软，但后来感觉在大公司的目标感太弱，即选择离职。

字节跳动将推动上市？

相关概念股拉升
图片来源 / 图虫创意
日前，据相关媒体报道，抖音、今日头条的母公司字节跳动正考虑推动国内业务上市，上市地点可能为中国香港或上海，或更倾向于香港。此外，公司还考虑将非中国业务在欧洲或美国上市的选项。对此，字节跳动方面7月31日下午公开表示，“对市场传言，不予置评”。
而就在消息传出的周五下午，A股相关概念股也出现急速拉升，10多只股票涨停，包括天创时尚、引力传媒、环球印务、省广集团、宣亚国际、佳云科技、美盛文化等。
具体概念股方面，苏宁易购、浙江龙盛等个股为字节跳动影子股。其中，苏宁易购2019年年报披露，公司子公司ShinyLion出资1亿美元认购BytedanceLtd.E轮优先股2,028,882股。另外，浙江龙盛出资3000万美元合伙建立LVC Advantage Fund公司, LVC Advantage Fund公司参股字节跳动公司5000万美元。
