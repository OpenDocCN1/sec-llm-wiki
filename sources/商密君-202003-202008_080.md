# 福建省密码管理局开展 2020年度密码管理部门行政执法资格考试

**福建省密码管理局开展****2020年度密码管理部门行政执法资格考试** 为贯彻落实《中华人民共和国密码法》，依法加强商用密码管理，建设高素质的行政执法队伍，保障网络与信息安全，维护国家安全和社会公共利益，2020年7月22日，福建省密码管理局与省司法厅共同组织开展密码管理部门行政执法资格考试，全省50名密码干部参加了考试。  
![](../Images/3b9b8c09fc5346e5f44cf1046aea0e83.png)

福建省密码管理部门行政执法资格考试现场

此次行政执法资格考试分为综合法律知识考试和密码专业法律知识考试两部分，范围涵盖《宪法》《立法法》《行政处罚法》《行政许可法》《行政强制法》《行政复议法》《行政诉讼法》等综合法律知识，以及《密码法》《商用密码管理条例》《电子认证服务密码管理办法》《福建省密码应用与创新发展实施方案（2019-2022年）》等密码专业法律知识。  
![](../Images/77e78f8d915909ff6acc919e03a2dc7d.png)  
福建省密码管理部门行政执法资格考试现场考试过程，参考人员认真应考，秩序井然，展现了良好的业务水平和精神风貌。省司法厅法治督察处郑志奋处长到场巡考，并充分肯定了此次考试的组织和考场防疫防控工作。

![](../Images/4118630c68d28a0618bddc1205f85434.png)

参考人员体温检测通过此次考试，掀起了学习《密码法》、行政执法相关法律的热潮，真正达到以考促学的目的，提升执法人员学法、用法、执法、守法的意识和能力，促进执法行为规范和执法水平的提升，为今后执法工作打下坚实基础。
