# 女租客房内现偷拍摄像头报警！房东系山西文旅厅处级干部已被传唤

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247497781&idx=4&sn=27dfb55f713d7a432a4b19173092c7de&chksm=ec56e86edb216178a6241a12a62bd1209a5d9d3bf6e1753de2201eb8f87b2adccf13dc2f0c01&scene=126&sessionid=1681313929#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247497781&idx=4&sn=27dfb55f713d7a432a4b19173092c7de&chksm=ec56e86edb216178a6241a12a62bd1209a5d9d3bf6e1753de2201eb8f87b2adccf13dc2f0c01&scene=126&sessionid=1681313929#rd)

![](../Images/260398b4d33d7a0aaf3e468ab644dfb8.png)近日，有媒体报道山西省文旅厅一名处级官员名下出租屋现摄像头偷拍租客，事件引发关注。7月22日，南都记者从山西省文化和旅游厅财务处确认，涉事房东正为该处副处长王某龙。据山西太原市公安局迎泽分局同日通报，涉事房东王某某已被依法传唤到案。

据媒体此前报道，租住在山西省太原市一小区的小琳（化名）与合租室友在其租住的屋内挪动家具时，突然发现了两个偷拍摄像头，内有32G存储卡，已有4000多条偷拍视频，视频中有多名女生在卧室起居日常和浴室洗澡的画面。小琳表示，涉事男房东经常来该房屋。小琳随后报警。

![](../Images/5855aec5ee6feb0812e7c2ab7fda49b1.png "imagefile")

**偷拍画面**

根据小琳提供两张房屋租赁合同显示，她从今年3月起租该房，短租1个月；随后又签署续租，从2020年5月12日到2021年3月12日。每月租金为350元。出租方为王某龙。7月22日，山西太原市公安局迎泽分局发出通报称，2020年7月18日，郭女士报警称其租住的房屋中，发现被安装摄像头偷拍，接警后，该分局高度重视，老军营派出所依法受理此案进行调查。目前，涉事房东王某某已被依法传唤到案，正在加快侦查调查。涉事房东王某龙曾回应媒体称，自己为山西省文化和旅游厅规划财务处工作人员，他否认曾安装偷拍设备，但表示对该事件负有连带责任，将积极配合调查处理。7月22日，南都记者尝试联系涉事房东王某龙未果。同日，南都记者致电山西省文化和旅游厅财务处，确认涉事房东王某龙为山西省文化和旅游厅财务处副处长。“王副处长今天已请假，不在办公室，明天是否上班还不知道，我们厅已经了解到该事件，一切以警方调查为准。”该处工作人员表示。
