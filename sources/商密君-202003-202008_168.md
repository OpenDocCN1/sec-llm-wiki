# 新创工委会：关于开展信息技术应用创新安全解决方案征集工作的通知

**各相关单位：**

目前我国信息技术应用创新(以下简称“信创”)产业正不断发展，软硬件技术能力稳步提升，信息系统安全问题也愈加凸显。为全面提升信创产业安全保障能力和服务水平，推进安全技术及解决方案的完善和升级，中电标协信息技术应用创新工作委员会拟开展第一批信创安全解决方案征集工作，遴选一批可复制、可推广、具有指导意义的信创安全解决方案，为产业发展提供安全保障。现将有关事项通知如下：一、征集对象面向信创产业广泛征集技术水平先进、应用示范效果突出、产业带动性强的安全解决方案。二、征集程序（一）申报企业单位填写信息技术应用创新安全解决方案申报书（见文末链接），纸质版一式两份加盖公章后邮寄至联系人地址，电子版发送至联系人邮箱。（二）安全中心技术委员会对征集的解决方案进行审核、评估。优秀案例将收录在《信息技术应用创新领域优秀安全解决方案案例集》中，并在相关活动及行业用户中进行宣传推广。三、报送时间纸质版报送截止日期为2020年8月14日（以邮戳为准）；电子版报送截止日期为2020年8月14日。联系人：景晓晨 15661095493 jingxiaochen@cics-cert.org.cn杨  安 13161010325 whomya@163.com邮寄地址：北京市石景山区鲁谷路35号信息技术应用创新工作委员会
