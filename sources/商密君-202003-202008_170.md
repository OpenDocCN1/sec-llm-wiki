# 一键检测你的账号密码是否被泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247495990&idx=4&sn=aa0f4151353cae50302ceda92b65f15b&chksm=ec56e16ddb21687b84a8d7672c1d489f4feda2bff3eaf223b0f18a0019247c1770978241089e&scene=126&sessionid=1681313955#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247495990&idx=4&sn=aa0f4151353cae50302ceda92b65f15b&chksm=ec56e16ddb21687b84a8d7672c1d489f4feda2bff3eaf223b0f18a0019247c1770978241089e&scene=126&sessionid=1681313955#rd)

大家都知道 Chrome 上可以存储登录账号、密码，每次登录其它账号的时候可以自动填充密码，直接登录，但是这些密码有可能会遭遇「撞库」泄露，而你现在用的密码是否还安全，其实 Chrome 自带一个工具可以检测。

之前 Chrome 有一个密码检查的扩展，可以检查密码是否被泄露，并且还能检测我们的用户名和密码是否因为在某些网站或者应用程序上使用从而被黑客窃取。

后来谷歌将这项功能收纳在设置里面 Chrome 密码管理器中。

方法很简单，在 Chrome 登录 Google 账户后，在浏览器的设置界面中搜索「安全检查」，并点击「立即检查」按钮，即可自动检测密码是否被泄露。

![](../Images/7070d6e7f50e93a92268f19a1e4cb9f3.png)

如果出现泄露的情况，点击查看即可了解具体是那些平台的账号和密码被泄露。

![](../Images/73178d71389573d8ca99bf64ee987632.png)

已经泄露的密码就得赶紧更改了。

![](../Images/f5c088051973b80e18e2c6d064fd88bb.png)

根据 Chrome 官方解释，原理就是：

这个安全检查功能会存储以下信息：扫描到的使用不安全密码的登录次数；如果密码安全检查发现输入的密码和用户名不安全，则会生成针对相应信息的经过哈希处理的部分代码，并将此部分代码存储到我们的 Chrome 浏览器中。不过他人无法利用此部分代码重新创建我们的信息的完整版本。

如果想要更详细的解释可以直接打开这个网址了解一下。

https://support.google.com/accounts?p=password-checkup
