# 为支持抗议者，加密聊天软件Signal引入自动模糊人脸功能

**加密聊天软件 Signal 更新了！**

它们从 Android 和 iOS 版本更新中引入了人脸模糊功能。通过该应用分享的照片能够快速模糊人脸，虽然不一定能完全隐藏主体身份，但可以为图片增加另一层隐私保护。

![](../Images/5c6af0a98f26aa03b1676fe9efa7f149.png)

目前，全世界的人们都在为种族主义和警察的野蛮行径游行示威，对最近发生的乔治·弗洛伊德（George Floyd）和布罗娜·泰勒（Breonna Taylor）的谋杀案感到愤怒。而Signal称其支持那些走上街头表达自己声音的人们。他们认为，美国的某些事情需要改变，即使不确切知道如何改变，但也支持并信任全美国各地自我组织的人来解决它。

Signal 联合创始人 Moxie Marlinspike 表示，本次更新和乔治·弗洛伊德被执法者跪杀事件有关。伴随着全球范围内反对种族主义和警察暴力的抗议活动增多，导致 Signal 的下载量创下了历史新高。Signal 采用端到端的加密技术，使信息更难被拦截。

Marlinspike 写道：**“我们正竭尽所能的为参与游行的人提供帮助。但有一点是肯定的，2020 年需要遮挡面部。”**当你通过Signal拍摄照片并选择工具栏中的模糊选项时，应用程序会自动检测到图像中的人脸。用户也可以手动模糊人脸，或者模糊任何他们想隐藏的其他特征。所有的处理都在设备上完成，这意味着未经审查的图像永远不会离开用户的手机。

![](../Images/d214d4e51255322220022df703f6f869.png)

组织这种变革的许多人和团体正在使用Signal进行交流，Signal官方表示正在努力跟上不断增长的流量。他们还一直在努力寻找其他方法，现在可以为街上的每个人提供支持。

**更新signal即可使用该功能。**

适用于Android和iOS的Signal的最新版本在图像编辑器中引入了新的模糊功能，可以帮助保护共享照片中人员的隐私。现在，很容易为每张脸提供一个隐藏的地方，或者在要擦除的物体上绘制模糊的痕迹。只需点击新的模糊工具图标即可开始。

![](../Images/d774607b2d0c56b562e5d3156eb54c4d.png)
