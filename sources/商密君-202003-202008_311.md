# Gartner发布云安全能力报告：阿里云位列全球第二，超过亚马逊

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247491317&idx=3&sn=7b725ac2b3d1288c4847e8ed6aaf7366&chksm=ec550eaedb2287b8d439f339d1907163f3c3f68a9279ecfc4588ea69ca8d7919681726996c8b&scene=126&sessionid=1681313985#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247491317&idx=3&sn=7b725ac2b3d1288c4847e8ed6aaf7366&chksm=ec550eaedb2287b8d439f339d1907163f3c3f68a9279ecfc4588ea69ca8d7919681726996c8b&scene=126&sessionid=1681313985#rd)

近日，全球知名的IT研究与顾问咨询公司发布《Solution Comparison for the Native Security Capabilities 》报告，首次全面评估全球TOP云厂商的整体安全能力。作为亚洲唯一入围厂商，阿里云整体安全能力拿下全球第二，11项安全能力被评估为最高水平（High），超过亚马逊，仅次于微软。

![](../Images/2d45d8808457853023ea0dc4d69efd82.png)

本文图片：云安全能力报告显示：阿里云全球第二，超过亚马逊（央广网发 阿里云供图）  
该报告评估对象为亚马逊、微软、阿里云、谷歌、IBM和Oracle六大云厂商，评估维度包括“基础设施安全，云治理和合规，网络安全，应用和容器安全，数据安全，日志和预警，应用和工作负载保护”7大模块24项能力。其中，阿里云在网络安全评测中斩获了最高评分。

![](../Images/83683c81fb7d6b60dde7e83f9f5b54ff.png)

据悉，这是目前业界针对云安全最全面也最权威的评估报告之一，只有兼具市场影响力和技术实力的厂商才能进入评选。
