# 央行数字货币发行在即，匿名性能避免个人数据泄露吗？

日前，央行数字货币DC/EP已小范围落地。这是央行数字货币自传出研发消息以来的首次实际落地应用。

DC/EP的内测图片一经发出，全网都表现了高度的关注。据悉，DC/EP具有可追溯、加密、可穿透式监管特性，将极大提升金融风险监管效率，以及杜绝金融诈骗等行为。提到金融诈骗，就不得不提起一个被大众忽视的问题：个人数据泄露。

01**个人数据泄露严重：人人都可能在披着“国王的新衣”**

个人数据泄露，是当前互联网时代与每个人息息相关的“痛点”。

2018年Facebook用户数据泄露丑闻早已让全世界都明白：科技巨头公司面前，我们都是披着“国王的新衣”的透明人。3月份被爆出的微博用户数据泄露事件，4月初被爆出的酒店巨头万豪的数据泄露事件，以及近日疑似在暗网上有大量国内银行的个人客户数据正在被出售，疑似涉及百万条个人信息。

![](../Images/bcda45e18c330a005b72f52127de8ab9.png)

图片来源：《隐私一览无余!微博泄漏事件卧底调查报告》  

个人数据泄露事件频发，据统计，仅2019年前三季度，全球披露的数据泄露事件就有5183起，泄露的数据量更是高达79.95亿条。而这些数据都仅仅是浮出水面的数据。面对不断爆出的数据被泄漏与交易事件，如何保护个人数据成了迫在眉睫的事情。

02**区块链技术：匿名性与隐私权**

区块链技术自诞生以来，就因其诸多特点吸引了大众的目光。其中，匿名性是区块链的第二大特点，仅排在分布式之后。说到匿名性，用户更熟悉的是在区块链上可以实现身份与交易的匿名性。身份匿名是指用户身份信息和区块链地址之间的无关联性，交易匿名则是指区块链中存储的交易记录和交易记录背后的主体匿名。简单来说，就是你的资产余额和转账信息得到了匿名加密的保护。

用区块链浏览器来举例，我们可以通过区块链浏览器查询到每一笔交易的数据信息。却无法得知每一个接收或者发送地址背后对应的实体。假设在区块链技术得到大范围应用，渗透到大众生活之后，我们的转账信息都只能通过在区块链浏览器上输入一长串哈希值来验证后，诈骗分子将无法得到背后对应的实体信息，或许我们就能远离诈骗电话了。

除了资产方面的匿名性，大多数基于区块链技术的应用也具备匿名性，在隐私保护方面也能大有所为，例如投票、选举、慈善事业等等。

比特币是作为匿名加密货币被开发的，但它的匿名不是彻底的。虽然其他人并不知晓你的真实信息，却仍可通过各种交易信息关联到你本人。在比特币网络上交易时，你会留下“链上信息”和“链下信息”，前者可以通过区块链浏览器将你的交易信息与他人相关联，后者可以揭示你的身份信息。

于是Zcash、Monero，以及基于Mimblewimble的Grin和Beam相继出现，它们的技术虽然各不相同，但主要目的都是切断“联系”。但这一特点又让不少人担心，匿名性能保护个人隐私，却也会被利用为犯罪行为提供“保护伞”。

03**区块链浏览器：平衡隐私保护与溯源的工具产品**

比特币可以说是区块链技术的第一个应用，但因其最初被大量应用于暗网的交易，也被不少人质疑过。诚然，比特币的加密性与匿名性很好地保障了各类交易的隐私，但隐私的保护并不等于包庇犯罪。

暗黑版淘宝“丝绸之路”被查处后，一位参与丝绸之路调查过程的前联邦检察官Kathryn Haun曾发表言论称，犯罪分子是利用了比特币进行交易，而FBI也正是利用了区块链技术完成了刑事调查。在接受外媒采访时，Haun表示，政府人员，国税局、FBI、国土安全调查局等相关人员在调查中，正是借助了区块链浏览器，利用链上数据追溯找到了有力证据，从而抓捕嫌犯后成功将其判决。

欧科云链OKLink区块链浏览器就曾被用于还原巨鲸账户被盗事件的真相。区块链浏览器在隐藏用户真实信息之外，对多笔交易的可追溯性也很好地平衡了隐私保护与犯罪追踪两者的关系。以欧科云链OKLink区块链浏览器为例，输入与输出地址旁的箭头就能追溯一笔交易的来源，追踪资金的最终流出与流入地址。

![](../Images/2653974a400c1feb75c894fc54bd9412.png)

**此次DC/EP和现行的电子货币最大的不同也就在于其具有可追溯功能、加密和可穿透式监管等。这些特点能提高商业银行对于机构或个人金融行为的合法性辨识和风险管控效率，在穿透式、加密和可溯源特性的加持下，金融诈骗、专款挪用、资金盗用等违法行为，将难以规避监管的追踪。**

隐私权是一项基本人权，匿名是实现这项权利的有效途径之一。区块链技术的匿名性可以防止个人身份的盗用，防止个人消费习惯被不良商家利用，是保护人们隐私权的利器之一。区块链的应用尚处于初级探索阶段，如何发挥最大作用，在保护隐私权与实现透明可追溯也尚未见分晓。此次DC/EP的初曝光透露给我们的仅仅是会带有加密、可追溯等特性，但能否利用到区块链技术，为大数据时代提供一个公开可信的技术支撑，就让我们拭目以待。
