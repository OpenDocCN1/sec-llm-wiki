# 重磅！迎接《密码法》实施一周年，深圳商用密码协会&商密君联袂倾情推出密码宣传培训平台“深圳专区”

《中华人民共和国密码法》**第三十条** 商用密码领域的行业协会等组织依照法律、行政法规及其章程的规定，为商用密码从业单位提供信息、技术、培训等服务，引导和督促商用密码从业单位依法开展商用密码活动，加强行业自律，推动行业诚信建设，促进行业健康发展。

![](../Images/24460740716cc22f777c95910ae6ff72.png)

  

  

为贯彻落实习近平总书记有关重要指示精神，宣传推广《密码法》，在深圳市密码管理局指导下，深圳市商用密码行业协会（以下简称协会）在《密码法》实施一周年之际，联合商密君倾情推出密码法宣传培训平台“深圳专区”，旨在面向深圳市民和社会各界提供专业全面、生动有趣的密码政策解读和密码知识普及，引导社会各界将学密码、知密码作为时尚，推进重点行业将懂密码、用密码融入工作，激发青年一代将爱密码、干密码作为事业。

  

**直击主题：**关注“深圳密码”官方公众号，直戳首页底部中间“培训平台”，进入“深圳专区”，33 道精美密码菜肴尽在其中，**密码从业者必品！**

目前深圳专区已经上线的33 门课程，内含诸多密码行业大咖独家精彩分享。  

  

中国科学院大学荆继武教授分享了对学习《密码法》的体会与思考，他认为在我国信息产业高速发展的今天，《密码法》出台实际上是一次全民科普，它传达了网络安全的真正含义，没有网络安全就没有国家安全，当密码进入公众视野的时候能给我们带来更多的发展优势。

  

上海交通大学教授、2020 年“科学探索奖”数学物理学领域获得者郁昱分享隐私保护下的关键技术——全同态加密技术。郁教授认为，全同态加密技术概念理论上允许任何用户直接在密文的状态上进行相关的计算。典型应用场景就是用户将他的隐私数据发送给服务商，服务商在加密的数据上为用户进行相关的计算，最后将加密的结果返还给用户，用户解密后得到正确的计算结果，整个过程由于服务商没有直接对数据进行解密，所以用户的数据隐私得到了保护。

  

中国科学院大学教授、信息安全国家重点实验室副主任林璟锵分享密码的诞生与攻防。林教授认为，不管是国内外的战争，任何一方为了在友军之间安全的传递消息，确保消息不被敌人窃听，不恶意将消息篡改，密码不可或缺。今天我们把密码学用到网络空间中，其实是让密码学回到它本来应该有的位置，密码学的研究实际上是走在网络攻击的前面。
