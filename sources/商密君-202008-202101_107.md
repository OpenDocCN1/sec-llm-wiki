# 关于责令有关网络安全等级保护测评机构限期整改的公告

为加强网络安全等级保护测评机构监督管理，规范测评行为，提高测评机构技术能力和规范化、标准化水平，促进全国网络安全等级保护测评体系健康发展，国家网络安全等级保护工作协调小组办公室开展了2020年度全国网络安全等级保护测评机构监督检查工作。根据在监督检查中发现的问题，按照《网络安全等级保护测评机构管理办法》有关规定，经研究决定：

一、取消新疆大学（推荐证书编号：DJCP2016650166）测评机构推荐证书，三年内不再受理其申请。二、责令河北省信息安全测评中心（推荐证书编号：DJCP2011130040）开展为期12个月的整改，整改期间暂停开展等级测评业务。整改期为2020年12月24日至2021年12月24日。三、责令宁夏大学（推荐证书编号：DJCP2011640164）开展为期6个月的整改，整改期间暂停开展等级测评业务。整改期为2020年12月24日至2021年6月24日。四、责令山东道普测评技术有限公司（推荐证书编号：DJCP2010370108）、云南瑞讯达通信技术有限公司（推荐证书编号：DJCP2013530150）开展为期3个月的整改，整改期间暂停开展等级测评业务。整改期为2020年12月24日至2021年3月24日。五、责令河北恒讯达信息科技有限公司（推荐证书编号：DJCP2011130041）、济南时代确信信息安全测评有限公司（推荐证书编号：DJCP2011370109）、吉林省启明安信信息安全技术有限公司（推荐证书编号：DJCP2011220062）、天津顺时信息技术有限公司（推荐证书编号：DJCP2018120038）、中科信息安全共性技术国家工程研究中心有限公司（推荐证书编号：DJCP2011110023）、固平信息安全技术有限公司（推荐证书编号：DJCP2012660168）开展为期3个月的整改，整改期间不影响开展等级测评业务。特此公告。
