# 首个多方安全计算的金融行业标准正式发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247514090&idx=2&sn=4468f9c4933ff8d057e8c720216a7a52&chksm=ec56a7b1db212ea751e4a419ad6ab4172dd961eed5cbcf7fb5c3ce040cac9dc1bf2a204a51c0&scene=126&sessionid=1681313573#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247514090&idx=2&sn=4468f9c4933ff8d057e8c720216a7a52&chksm=ec56a7b1db212ea751e4a419ad6ab4172dd961eed5cbcf7fb5c3ce040cac9dc1bf2a204a51c0&scene=126&sessionid=1681313573#rd)

2020年11月24日，中国人民银行正式发布**《多方安全计算金融应用技术规范》**（JR/T 0196—2020，以下简称《规范》）金融行业标准。

《规范》规定了多方安全计算技术金融应用的**基础要求、安全要求、性能要求**等，适用于金融机构开展相关产品设计、软件开发、技术应用等。《规范》的发布有助于实现在不泄露原始数据、保障信息安全前提下**推动多个主体间的数据共享与融合应用，确保数据专事专用、最小够用，杜绝数据被误用、滥用**。《规范》由全国金融标准化技术委员会归口管理，由中国人民银行科技司提出并负责起草，行业内有关单位共同参与。标准经过广泛征求意见和论证，并通过了全国金融标准化技术委员会审查。![](../Images/d684997042585f5b02184092aa656905.png)![](../Images/595a81c0cd28806b84da3ac77ed6bd2e.png)![](../Images/af972e004fb38d56c344a261c6580b2a.png)来源：金标委官网注：内容均来源于互联网，版权归作者所有，如有侵权，请联系告知，我们将尽快处理。
