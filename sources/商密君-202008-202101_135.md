# 车联网密码应用课题组第二次会议在京召开

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247514014&idx=3&sn=8aa93823eb65d50523787b66f14b3f80&chksm=ec56a7c5db212ed3983e042f60679901d8e48c5bddbb6a1f4996301f4d3fef539a085b75d075&scene=126&sessionid=1681313573#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247514014&idx=3&sn=8aa93823eb65d50523787b66f14b3f80&chksm=ec56a7c5db212ed3983e042f60679901d8e48c5bddbb6a1f4996301f4d3fef539a085b75d075&scene=126&sessionid=1681313573#rd)

![](../Images/9a3c3ea4e6f0238150d705c16259a661.png)2020年12月15日，密标委应用组与通标协TC10车联网工作组在北京召开车联网密码应用课题组（以下简称“联合课题组”）第二次会议暨车联网密码应用研讨会，中国信息通信研究院（以下简称“中国信通院”）支撑召开此次会议。![](../Images/bed63ba3580664ea356bc2516a99246e.png)中国信通院、北京数字认证、国家密码管理局商用密码检测中心、国汽智联、中汽数据、中国移动、大唐移动、吉大正元、飞天诚信、兴唐通信、信安世纪、三未信安、信大捷安、中安云科、高通、东软、星云互联、上海芯钛、华大信安等单位的30余位专家代表参加了本次会议。本次会议由密标委应用组专家夏鲁宁与通标协TC10车联网工作组专家于润东共同主持，通标协TC10车联网工作组组长葛雨明参加此次会议。**会议重点围绕车联网密码应用的技术现状、产业分析、白皮书编制展开讨论：**  

*   密标委应用组专家夏鲁宁、大唐移动专家徐晖、吉大正元专家韩宏伟分别就车联网安全风险和密码应用、密码技术在车联网领域的应用现状、基于密码技术的车联网安全应用与实践等进行了深入介绍。  
    
*   会议重点讨论了车联网密码应用的产业推进建议，与会专家围绕C-V2X安全认证管理、车联网密码应用标准化推进等工作展开深刻探讨。  
    
*   会议明确了**《车联网密码应用白皮书》**编制重点和计划。针对前期收集与整理的意见进行了反馈，对白皮书章节划分和重点编制内容进行了讨论梳理，明确了白皮书编制计划和任务分工。

  
联合课题组将继续发挥通标协和密标委的协同作用，围绕车联网密码应用技术标准研制、应用验证、产业推进等方面联合开展系列工作，推动相关标准的协调制定，协同助力车联网密码应用产业化推进。
