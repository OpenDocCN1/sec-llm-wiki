# 陕西省商用密码协会成立陕西密码专家委员会并举行授牌仪式

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247513541&idx=1&sn=651819116b8cab5a273d68a682cdd836&chksm=ec56a59edb212c883c135b1e874d1d13d24e3af2313370d2d64a68e4f2bf25f1849343ab9c6b&scene=126&sessionid=1681313584#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247513541&idx=1&sn=651819116b8cab5a273d68a682cdd836&chksm=ec56a59edb212c883c135b1e874d1d13d24e3af2313370d2d64a68e4f2bf25f1849343ab9c6b&scene=126&sessionid=1681313584#rd)

![](../Images/9a3c3ea4e6f0238150d705c16259a661.png)**陕西省商用密码协会****成立陕西密码专家委员会并举行授牌仪式**\----冯登国任名誉主任 李晖任主任

2020年12月10日,陕西省商用密码协会理事会暨陕西密码专家委员会成立大会在西安召开。西安电子科技大学网络与信息安全学院执行院长李晖、陕西省国家密码管理局商密处有关领导受邀出席本次会议。本次理事会由协会会长白选民主持，21家副会长单位参加了本次会议。

![](../Images/f2da412cfba9f5a6a34a58c2330946f8.png)理事会上，选举申燕为协会秘书长；审议并通过了《陕西密码专家委员会管理办法》及《陕西密码专家委员会名誉主任、主任、副主任建议名单》。中国科学院院士冯登国任名誉主任，西安电子科技大学网络与信息安全研究院执行院长李晖任主任。

![](../Images/c66637f272920051e289be6a818e7df0.png)

陕西省国家密码管理局商密处处长王勇卫宣布陕西密码专家委员会正式成立，并向陕西省商用密码协会会长、陕西密码专家委员会主任授牌。

![](../Images/addbefe1bba7973f9828350d94e56bfc.png)

陕西密码专家委员会主任李晖表示，陕西密码专家委员会将按照省国家密码管理局的要求，在省商密协会的领导下，积极发挥专家作用为陕西省商密事业发展提供全方位支撑，在企业与学术界之间架起桥梁，为企业做好服务对接，促进最新研究成果的应用转化。

![](../Images/4ea4fba4bde53448e8130a5b29751cdc.png)

陕西密码专家委员会旨在完善陕西省密码及信创产业专家团队建设与管理，充分发挥专家技术优势作用，积极推动协会在专业领域的决策民主化、科学化水平，对于推进陕西省商密产业及密码信息技术创新发展，具有十分重要的意义。会上，协会会长白选民作了2020年度协会工作报告，通报了陕西密码及信息技术应用创新产业基地的规划筹建工作推进情况，并对协会下一步重点工作做了安排部署。

![](../Images/affc32d41ad4c9fd77f6b1020c128c5e.png)

陕西省国家密码管理局商密处处长王勇卫对陕西密码专家委员会的成立表示祝贺。他充分肯定了协会成立以来所做的各项工作，并对协会发展提出了期望与建议。王勇卫同时表示，陕西拥有一批在密码研究领域具有深厚积淀的高等院校和科研院所，有西安电子科技大学这个全国密码行业的“黄埔军校”，我们在密码产业发展上有得天独厚的人才优势和“一带一路”桥头堡的地域优势，协会及各企业应顺应大势提高陕西密码行业的水平。陕西省国家密码管理局将继续大力支持协会发展，为密码企业提供更多扶持政策和奖励措施，共同将陕西密码事业向前推进。

![](../Images/c0eaeb21b5ef64d0b68077d5908ee3f9.png)

最后，协会理事会成员们畅谈了对陕西密码产业发展现状的分析和对未来发展方向的建议。大家一致认为陕西省的密码及信创产业将迎来发展的春天，并表示将全力支持配合协会工作，携手共创陕西商密产业发展新环境，为陕西经济社会发展做出贡献。

![](../Images/3a5a72e6835720f935f6e22e86de5381.png)

本次会议由商密在线、西安得安信息技术有限公司、西安银信博锐信息科技有限公司支持。![](../Images/af972e004fb38d56c344a261c6580b2a.png)来源：陕西省商用密码协会注：内容均来源于互联网，版权归作者所有，如有侵权，请联系告知，我们将尽快处理。
