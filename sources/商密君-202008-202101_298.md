# 贵州省首届商用密码技术与应用科普大赛报名开始

10月13日,贵州省届商用密码技术与应用科普大赛开始报名与作品征集。

众所周知,当前已经进入万物互联的时代,信息安全变得越来越重要,随着2020年1月1日**《密码法》**的正式实施,推动国产密码的快速发展,网络安全与信息安全向全域安全发展,**强信任、强安全、强可控、强防护**成为必然要求,而密码是解决网络安全与信息安全最可靠、最有效的核心手段。为进一步科普与推动重要信息系统和网络安全中的商用密码技术及应用,鼓励广大科普工作者。基于此,本次大赛围绕信息系统及网络安全的商用密码技术与应用,聚焦**商用密码技术、法律、标准、应用、评估**等内容征集作品。大赛面向大众征集参赛作品,个人、企业(单位)均可报名参赛。报名及作品征集时间**截至2021年1月16日**,后将对参赛作品经为期9天的网上评选与专家评审,同时,在评选期间,将选取票选优秀作品进行展播。最终于2021年1月举行大赛颁奖。![](../Images/af972e004fb38d56c344a261c6580b2a.png)来源：贵州日报注：内容均来源于互联网，版权归作者所有，如有侵权，请联系告知，我们将尽快处理。
