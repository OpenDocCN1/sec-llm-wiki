# 全球软件巨头遭遇勒索1.3亿RMB，创全球勒索赎金之最

作为全球最大的软件公司之一，德国Software AG在上周末遭受了勒索软件攻击，并且该公司尚未完全从事件中恢复过来。

![](../Images/2f5e93af6c85d3b59c8489f70bed3212.png)**公司背景介绍**Software AG成立于1969年，是欧洲最成熟的系统软件供应商，目前成为欧洲第二大软件公司（第一大是SAP）。公司总部设在德国达姆施塔特（Darmstadt），并在法兰克福上市。2010年销售收入为11.22亿欧元。 Software AG通过集成应用与系统，以及对大机和开放系统IT环境的更新，让用户能够实时地获取统一的战略性业务信息。其解决方案主要基于Adabas、Natural、WebMethod、Centrasite、ARIS Platform产品系列。分布在全球70个国家的5000名员工支持着全球10000多家客户的关键任务系统。公司在三个全球大陆板块都设有研发中心。

![](../Images/7bbb36d53ba85410f312f04a96dd379c.png)

**Software AG全球办事处**

Software AG 亚太区业务是公司全球地区业绩最佳之一。得益于新老客户对XML解决方案的日益重视。Software AG在全球拥有10,000家客户，包括德国汉莎航空公司、戴姆勒-克莱斯勒、MCI、日本索尼、德国电讯、富士通、西班牙电信、沃达丰，DHL和空中客车等国际知名机构。在亚太区，Software AG服务于马尼拉电力公司、上海市政府、香港空运货站、日本汽车制造商尼桑、Seven Network、Colonial First State Investments、澳大利亚金融投资集团及澳大利亚证券投资委员会等等。**遭遇全球史上最多赎金勒索**一个名为“ Clop ”的勒索软件犯罪集团于10月3日星期六破坏了公司的内部网络，加密了文件，并**要求提供超过2000万美元（1.3亿人民币）以换取解密密钥。**今天早些时候，在谈判失败之后，Clop团伙在黑客在其所谓的泄漏站点上发布了公司数据的屏幕截图。屏幕截图显示了来自公司内部网络的员工护照和ID扫描，员工电子邮件，财务文件和目录。![](../Images/73e930065029570e313ffd8649049929.png)本周一，Software AG公开披露了该事件，当时该事件表明该公司“由于恶意软件攻击”而面临内部网络中断。![](../Images/bf3c4282691dedb951abd317d599cf72.png)该公司表示，为客户提供的服务（包括基于云的服务）仍然不受影响，并且他们不知道“恶意软件攻击正在访问任何客户信息”。本周三也就是两天后，**Software AG承认发现数据盗窃的证据时，此声明在后来的新闻发布中被取消。****有关攻击的消息整周（包括今天）都保留在其官方网站主页上。**![](../Images/235369c349b48c651aea04241281ee12.png)Software AG也没有在媒体对该事件释放出更多详细信息或评论。安全研究员MalwareHunterTeam在本周早些时候发现了针对Software AG的勒索软件二进制文件的副本 。**2000万美元（1.3亿人民币）的赎金需求，创目前全球有史以来勒索软件攻击中要求的最大赎金记录。**![](../Images/4a9424a63f407c8eb21b05a850e4e644.png)通过此勒索记录中提供的ID，安全研究人员可以在由勒索软件组管理的Web门户上查看Clop帮派和Software AG之间的在线聊天。在撰写本文时，没有证据表明德国公司支付了赎金要求。![](../Images/7b3c40faaef1d0608019e23a8489e8eb.png)![](../Images/af972e004fb38d56c344a261c6580b2a.png)来源：红数位注：内容均来源于互联网，版权归作者所有，如有侵权，请联系告知，我们将尽快处理。
