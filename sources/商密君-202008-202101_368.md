# 特斯拉遭遇 1 个小时的网络故障：因 API 引起

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247507447&idx=2&sn=2381131da2653cdde31183dfa478e7ea&chksm=ec56cdacdb2144ba7ca975bfbabc2143a5b3c62505ad714e6a5760eaa6a12a8d30e8bb6e03a8&scene=126&sessionid=1681313867#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247507447&idx=2&sn=2381131da2653cdde31183dfa478e7ea&chksm=ec56cdacdb2144ba7ca975bfbabc2143a5b3c62505ad714e6a5760eaa6a12a8d30e8bb6e03a8&scene=126&sessionid=1681313867#rd)

![](../Images/9a3c3ea4e6f0238150d705c16259a661.png)据几位消息人士声称，由于一起故障影响了特斯拉的整个网络，周三早上众多特斯拉车主被锁住，无法正常使用车辆及随附的应用程序约一个小时之久。

![](../Images/5628e41aa0248042c69c44fc26462c79.png)

据知情人士透露，特斯拉的这次故障是其应用编程接口（API）内部出问题引起的。

这次故障有可能与推出双因子身份验证这项新的安全功能有关，特斯拉首席执行官Elon Musk在上个月的一条推文中称这项新功能“推出晚了，令人尴尬”。

![](../Images/ced2d79921c5e74e2cd2696ce130b2a1.png)

双因子身份验证（又叫两步验证）将你已知的信息（比如密码）与你拥有的信息（比如手机）结合起来。它让应用程序得以验证正在登录的是真实的帐户持有者（或汽车所有者），而不是黑客。

一些网站实行双因子身份验证的方法是通过短信向你发送代码，但黑客可以截获这些代码。一种更安全的方法是通过手机应用程序（常常名为身份验证器）发送代码，安全专家们青睐这种方法。

虽然自2018年以来特斯拉的汽车采用PIN码输入，并添加了让车主可以跟踪车辆的GPS功能，但缺乏双因子身份验证一直是个问题。

特斯拉应用程序是车主的一个关键工具，可让他们控制车辆上的众多功能。特斯拉车主们一直呼吁将双因子身份验证功能作为额外的安全保护层。

诸如此类的故障无异于给这家汽车制造商抹黑，它需要说服越来越多的消费者：虽然出现了更多的品牌以挑战特斯拉在电动汽车市场的霸主地位，但特斯拉电动汽车仍是他们的首选。

大批电动汽车会在2021年和2022年上路，在几乎每个价位全面挑战特斯拉；而长时间锁住车主显然不是说服潜在买家掏钱购买特斯拉汽车的好方法。

不过，特斯拉正积极推行可能影响消费者情绪的计划——具体来说就是通过像该公司在昨天宣布的那种电池创新，努力降低汽车成本。

在该公司备受关注的电池新闻发布会上，特斯拉首席执行官Elon Musk与特斯拉动力总成和能源工程高级副总裁Drew Baglino阐明了计划和取得的进展，力争电池年产量最终达到10至20兆瓦时。最终目标是减少足够的电池，以便能够制造和销售价格仅25000美元的电动汽车。
