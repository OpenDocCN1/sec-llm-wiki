# 美国波特兰市通过最严人脸识别禁令！商业私营机构也不得使用！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247505583&idx=3&sn=17818697c20b0f67c472eff37172a9b8&chksm=ec56c6f4db214fe261d988f8057199b53a65cc632930cc01a773715930e02a98afef0b704b2c&scene=126&sessionid=1681313877#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247505583&idx=3&sn=17818697c20b0f67c472eff37172a9b8&chksm=ec56c6f4db214fe261d988f8057199b53a65cc632930cc01a773715930e02a98afef0b704b2c&scene=126&sessionid=1681313877#rd)

![](../Images/260398b4d33d7a0aaf3e468ab644dfb8.png)据外媒报道，9月9日，美国俄勒冈州波特兰市通过了一项美国最严格的人脸识别禁令，不只是当地政府部门不能使用人脸识别技术，**包括商店、饭店和旅馆在内**等机构也被禁止使用该技术。![](../Images/8306fe2a8bba3f672da6832dea22ec9c.png)  
该禁令写到，波特兰市居民和游客在进入**公共空间**时，他们的**个人隐私都应该获得保障**。同时，该禁令援引相关的城市法规，称“每个人都应当拥有参与城市生活的平等机会，妨碍（大众）公平参与的歧视性障碍应当被消除”。相比于美国美国旧金山、奥克兰和波士顿等城市的禁令，波特兰市范围更广，从政府延伸至商业私营机构，目前这是美国**第一次禁止商业私营机构使用人脸识别技术**的禁令。据悉，该禁令将于2021年1月1日起生效。该禁令并**不禁止个体为了个人验证目的而使用人脸识别技术**，比如解锁iPhone的Face ID功能，也允许社交媒体应用程序存在人脸自动检测服务。为什么会是波特兰市？收集网上资料，主要是两个方面的原因：一是与波特兰市近期局势相关，在上个月美国警方曾承认使用一架小型飞机监视波特兰市中心穆尔特诺玛县司法中心附近的示威人群。美国波特兰市议会委员Jo Ann Hardesty将对高科技执法工具的担忧，其在媒体平台上表示，“人脸具有十分私密的属性，**任何人的人脸都不应被随意地拍摄、存储和出售给第三方牟取利益**。任何无辜者也不应该遭受司法系统不公平地对待，只是因为算法将他们错误识别成嫌疑人”。担心因技术或者算法的误判导致无辜的人被不公平对待，是其原因之一。二是与波特兰市的人口结构相关，目前种族与民族多样化等原因形成政府管理的挑战，与之前禁止人脸识别技术的城市一样，担心人脸识别技术侵犯人们隐私，加剧种族歧视与性别偏见是主要原因。据国际权威人脸识别供应商测试Face Recognition Vendor Test (FRVT)发布的一些研究结果现：与白脸相比，这些算法中的许多算法错误识别黑脸或东亚脸的照片的可能性要高10到100倍。在搜索数据库中查找给定的面孔时，大多数人在黑人女性中选择的不正确图像的比例大大高于其他人口统计学中的比例。截至目前，美国公开表示禁止人脸识别技术的城市已经达到8个。
