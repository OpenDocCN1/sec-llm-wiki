# 想花25888元买个大神号，刚转完账就被拉黑

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247502830&idx=4&sn=0e37016aed6f53c4f775817746d0eb0a&chksm=ec56dbb5db2152a39d0f2cbdeec627f69a7ba61dda43bfcdb7547deb1714667d4062d136c4c6&scene=126&sessionid=1681313888#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247502830&idx=4&sn=0e37016aed6f53c4f775817746d0eb0a&chksm=ec56dbb5db2152a39d0f2cbdeec627f69a7ba61dda43bfcdb7547deb1714667d4062d136c4c6&scene=126&sessionid=1681313888#rd)

在网络游戏的世界里，不少玩家都希望拥有一个高级别账号或拥有一身极品装备，许多玩家为了一个心仪账号，不惜一掷千金。然而，这样的“商机”也被不法分子给盯上了。  

  

8月28号，常州市公安局魏村派出所成功**破获一起****涉案价值25888元的网络诈骗案**，嫌疑人胡某某、刘某某二人凭空捏造一高级账号骗取被害人钱财，将自己送进了派出所。

  

![](../Images/0af1e28a9f466031a75ccaf904b510eb.png)  
7月底，小孙在玩一款网络游戏时，发现自己因游戏账号等级不高无法“大杀四方”，便用QQ添加了一个名为“A\*\*代练工作室”的账号，经一番交涉，**双方以500元的价格约定为小孙代练账号等级**。几天后，小孙操作着新鲜出炉的高等级账号，又眼馋起了别人的高等级账号。  
由于之前已有过交易，小孙对该工作室十分信任，经过一番砍价，小孙**先后汇款10000元以及15888元，以总价25888元的价格买下了一个“175级化9”的高级账号。**  
然而，当小孙完成两次汇款，再次联系该工作室获取账号密码时，却发现自己被拉黑了。大意的小孙方知自己是遇上了网络诈骗。  
![](../Images/817e84829c763a917714663a16e6937b.png)![](../Images/4ff7d0afb68e81f63940d021bd1105be.png)  
魏村派出所民警接到报警后，迅速组织警力展开侦查，并在河南省许昌市锁定了犯罪嫌疑人胡某某、刘某某二人。民警随即赶赴河南，在当地警方的配合下将其二人抓获归案。  
经审查，胡某某、刘某某二人如实交代了自己在网上以出售游戏账号的方式实施诈骗的违法犯罪事实，**胡某某称自己也是游戏账号买卖诈骗的受害者之一**，受之前自己被骗的启发，便也走上了网络诈骗这条歪路。  
目前，**2名涉案嫌疑人已被依法采取刑事强制措施。**  
  
  
  

***警方提醒***

  
  
  
  
在网上购买游戏账号、游戏装备等虚拟物品时，一定要提高警惕，**“虚假出售账号”、“提现要交手续费”、“账号冻结”**是骗子的惯用伎俩。  
**不要轻易进入不熟悉的网站**，可通过知名搜索引擎确认网站的真伪。  
**不要轻易点击对方提供的网址链接、填写个人资料，更不能直接向交易对象的账户汇款**，避免上当受骗。  
一旦发现上当受骗，请立即拨打110报警。
