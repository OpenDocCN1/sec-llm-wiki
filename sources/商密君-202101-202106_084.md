# 2021年商用密码大会执委会第一次全体会议召开

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247530152&idx=1&sn=4ea179fcc7945a02948b316d15e22269&chksm=ec5666f3db21efe5f02949192d52fea02e353c1cdefa8345d629484553a005a522b299b13726&scene=126&sessionid=1681313415#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247530152&idx=1&sn=4ea179fcc7945a02948b316d15e22269&chksm=ec5666f3db21efe5f02949192d52fea02e353c1cdefa8345d629484553a005a522b299b13726&scene=126&sessionid=1681313415#rd)

为贯彻落实习近平总书记总体国家安全观的重要论述，深入实施《密码法》，充分运用密码这一重要战略资源，提升保障网络与信息安全的核心技术、强化基础支撑，经国家密码管理局批准，2021年商用密码大会将在郑州举行。

![](../Images/77fee1b27eac47c81d848dc906750140.png)

**2021年5月29日，2021年商用密码大会执委会第一次全体会议暨动员大会在河南郑州召开**，传达学习习近平总书记关于机要密码工作的重要讲话精神，贯彻落实中央、省委关于密码工作的指示要求，安排部署大会筹备工作。  

会议传达了中央、省委关于大会筹办工作的指示精神。河南省委副秘书长江文玉指出，要进一步提高站位，增强政治意识、责任意识，深入落实中央、省委要求，以大会筹办为契机，推进新兴产业发展，推动创新高地建设，更好服务融入新发展格局。要进一步完善机制，扁平化、实体化、属地化做好筹备工作，统筹推进场馆布置、疫情防控、会务接待、交通组织、消防安全等工作，创新方式方法搞好宣传推广和布展招商等，充分展现中原出彩形象、确保办会质效。要进一步发扬奋斗精神、奉献精神，落实责任、倒排节点、挂图作战，确保如期高质量完成大会各项筹备工作。  

河南省国家密码管理局局长张世平出席会议，郑州市委常委、市委秘书长牛卫国汇报了执委会工作进展情况，市领导吴福民、高永、王万鹏参加会议。  

据悉，**2021年商用密码大会将于8月28日至30日在郑举行**。届时，全国商用密码科研、生产、服务、检测、认证、使用企业单位将齐聚郑州、共襄发展。
