# 数字时代下网络安全既是安防命脉，也是安防机遇？

### **需求暴涨的视频网络安全市场**

![](../Images/5d39e0f4c2b16092620b71dfe23604cb.png)IDC数据显示，2020年全球视频监控产生额数据约为18.1PB，占同期物联网数据量的83.1%，构成物联网数据的主体。而随着安防产品端联网需求越来越强，相关的网络安全事件也层出不穷。2015年某月，某安防厂商产品遭到境外黑客大规模攻击，某公安机关视频信息遭到泄露，虽然相关企业很快便修复了漏洞，并且也声明了黑客袭击成功的原因是由于机关密码设置过于简单，但仍然为企业带来了难以估量的经济和声誉损失。2017年，某知名厂商被曝出设备存在漏洞，黑客声称通过该漏洞攻击者可以在没有任何凭证的情况下得到摄像头设备的用户名和哈希密码等敏感信息，通过这些信息，攻击者将很容易通过网络掌握摄像头的控制权。同样，这个漏洞被厂商闪电般地修复了，但同样也为企业带来了巨大的损失。2021年，美国知名监控厂商Verkada摄像头被黑，包含特斯拉工厂摄像头在内的15万监控摄像数据被黑客盗窃，黑客还声称可以通过网络直接控制摄像头。![](../Images/489ca8ec44562ea1db27d7331c94adf3.png)**黑客甚至通过摄像头，直接获取了美国某监狱的监控画面**随着物联网时代的到来，以视频监控技术为核心的安防产业，在网络安全方面已经迎来了更为严峻的挑战，但与此同时随着《个人信息保护法》、《数据安全法》、《网络安全法》等配套法律进入审查阶段，视频监控网络安全相关市场也迎来了发展的重要风口。有调研机构统计，目前已暴露全球范围的网络视频监控系统设备IP数量为1154万，中国拥有260万。而随着网络安全复杂性和安全问题逐渐上升，预计到2023年相关市场规模将达到29.3亿美元。而在其中，视频数据安全传输、监控设备漏洞扫描、视频监控网络安全审计等细分市场，正迎来发展的风口时期。有报告统计，2019年国内网络安全技术、产品及服务总收入约为523.09亿元，同比增长25.37%，网络安全从业人员约为10万人。到2023年底，中国网络安全市场规模将突破千亿元。在业务比例方面，目前国内主要分为三大类网络安全业务，即硬件产品、软件产品和安全服务，在占比方面，软件及硬件产品收入约占安全业务总收入的66%，安全服务收入约占安全业务总收入的24%，安全集成收入约占安全业务总收入的10%。同时，随着技术的推进，预计未来两年，软件层面的业务将迎来爆发式增长，并将与硬件的市场份额逐渐持平。从上述资料我们不难看出，随着物联网发展的层级递进，网络安全技术的应用场景及市场规模正迎来发展的历史性机遇。然而对于很多安防企业来说，在过去他们大多时候对于网络安全业务都采取了外包的方式，这个市场发展如何，到底值不值得砸钱进入心里其实都很没底。更何况就算进去了，渠道如何铺设，该如何盈利同样是让他们费解的问题，所谓知己知彼，在了解网络安全市场值不值得进入之前，先来看看其市场的竞争格局到底是怎样的。![](../Images/a41668c233d7dd6d10996507a9aa30f4.png)

### **尚无寡头，蓝海市场亟待发掘**

![](../Images/5d39e0f4c2b16092620b71dfe23604cb.png)想看市场发展的进程如何，就要先看该市场内是否有寡头企业诞生，一个具有成熟商业模式的市场，一般来说都会有寡头企业存在，比如电商行业的阿里巴巴和京东。如果按照这个理论来看，目前的网络安全市场显然还处于蓝海时期。2019年，我国有13家企业网络安全业务年收入超过10亿元，占网络安全业务总收入的48.82%，平均收入为22.31亿元;收入1亿元以上的共有94家，占比40.52%，平均收入为2.56亿元，收入1亿元以下的企业近400家，占比10.66%。尽管头部企业占比相对较大，但尚未形成垄断之势。![](../Images/4507ec9112fc5a2960e2abb02a770348.png)**大头企业对行业的占有仍然较小，所有企业都有机会**也就是说，目前的网络安全市场，仍然处于“诸侯地方割据”的局面。为什么说是地方割据呢，因为从企业分布的地域来看，目前北京的网络安全企业数量一骑绝尘，除此以外，广东、浙江、四川、福建、上海、山东和江苏业务线的发展也比较全面，具有广泛的发展空间。而对于安防企业来说，准入的有利条件不仅在于市场发展处于上升期，还在于安防行业巨大的市场需求。有报告指出，从投资融资金额的质量和数量上可以看出，云安全、数据安全、移动安全、身份安全和工控安全均为近几年来市场投资的重点。而这五项技术恰好对应安防行业的智慧成熟、大数据、智能家居、人脸识别和智慧工地，可以说，目前网络安全市场所急需的技术，同安防行业的产业热点几乎是不谋而合的状态。此外，科创版的成立，也给予了立志发展网络安全企业新的机会，整个市场目前对于网络安全企业的态度几乎是清一色的看好。而在此基础上，各大安防龙头也早已行动起来，开始布局网络安全市场。以海康威视为例，从2015年开始，海康威视就进行了一系列针对网络安全的改进，包括成立安全应急响应中心、成立网络安全与信息实验室、发布多个《网络安全白皮书》、同国际安全机构合作，通过CC、CSA-STAR等重要安全认证。大华股份也建立了基于HOC“1+2+N”架构的安全体系，以终端安全、网络安全、应用安全、数据安全、安全运营中心为基础的安全中心整体架构在城市解决方案和各行业解决方案中得到了配套应用。对于这些头部企业来说，他们已经意识到了网络安全作为物联网时代视频技术的护城河，其技术核心流向其他企业是十分具有风险的一项行为。而对于一般安防企业来说，研发网络安全技术不仅能够给企业的技术增加一份保险，更重要的是，在未来几年，其很有可能反馈给企业以巨大的利润。随着视频监控覆盖范围的逐渐加大，数据信息安全的挑战和伴随着的利润也会成倍增加，这会给不少企业以发展的机遇。但我们也要认识到，信息安全形势是一个长期奋斗的目标，不是突发市场挣的“快钱”，想要布局数据安全，同样要有打持久战的准备。
