# 商密群星云集，2021密码大兴峰会成功举行

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247526909&idx=2&sn=5d536da37f9ef05725b9033bd9c9276a&chksm=ec5679a6db21f0b0b97c18761fc2b905d26391c68464504e1bd2c1c99dd88a2b362e6f60639c&scene=126&sessionid=1681313436#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247526909&idx=2&sn=5d536da37f9ef05725b9033bd9c9276a&chksm=ec5679a6db21f0b0b97c18761fc2b905d26391c68464504e1bd2c1c99dd88a2b362e6f60639c&scene=126&sessionid=1681313436#rd)

近日，首届密码行业的盛会“2021密码大兴峰会”在北京大兴国家新媒体产业基地成功举行，本次峰会定位于商用密码全产业链发展的高度，围绕商密产业更好更快的发展展开讨论和探讨，是密码人和密码产业链从业人员迎来的第一个密码领域行业级峰会，是密码人渴望已久的属于自己的峰会盛宴。

“2021密码大兴峰会”由北京市密码管理局、大兴区人民政府、中国电子学会指导，国家新媒体产业基地、信息安全与通信保密杂志社、中关村中安高速密码产业联盟（筹）主办。由数盾科技发起并策划组织，联合三未信安、渔翁信息、商密在线、炼石网络、数观天下共同承办，峰会得到了龙芯、龙芯中科、大唐网络、长城网际、视联动力、清华同方、中铁信安、北信源、麒麟软件、德昱嘉诚、安帝科技、梆梆安全、江南天安、海泰方圆、铵泰克、沐创、世纪龙脉、群安科技、天威诚信、数世咨询、嘶吼等众多商用密码企业和商密产业链企业及媒体的支持，新华网客户端作为峰会的官方支持媒体对峰会进行全程报道。  

![](../Images/cc2df38ab5c221f4bfd631de15fae4b4.png)

“2021密码大兴峰会”新华网客户端官宣后引起了行业热潮，短时间内报名人数突破300人，峰会前夕报名人数已突破600多人。因考虑防疫安全要求，峰会对参会人数规模做了严格的限制，经组委会仔细慎重的审核筛选，最终发出了200张邀请函，组委会负责人向未收到邀请函的报名者表示非常抱歉，将计划在峰会后续系列活动中予以补偿。

本次峰会现场高朋满座、大咖云集，北京市密码管理局、大兴区人民政府、中国密码学会领导隆重出席，中国工程院沈昌祥院士莅临峰会并进行了主旨演讲和2020年度商用密码优秀企业颁奖，密码专家刘平、翟起滨出席峰会并发表主旨演讲，国家密码检测认证中心、数盾科技、渔翁信息、三未信安、炼石网络、商密在线、安帝科技、中国工业互联网研究院等单位和企业代表分别就商密产品检测认证管理、商密企业产品与发展、商密产业链发展、商密人才培训、密评等主题进行了精彩的演讲，是商用密码管理、发展、产业及人才的首次集体亮相。同时，峰会还吸引了多个省市的商用密码协会、密码管理机构、地方开发区政府等领导参会。

本次峰会的成功举行创造了商用密码领域多个第一，同时开创了商用密码产业的全新局面。

1、由地方政府、主管机构和商密产业链企业

合力打造密码产业第一个全国峰会平台

峰会得到了北京市密码管理局的指导，得到了大兴区人民政府的大力支持，全力为密码产业、密码人才创造良好的沟通交流平台和创业环境。大兴区和峰会组委会已达成战略共识，计划将峰会会址永久落户在大兴区，以峰会为平台，充分发挥大兴区区位优势，将着力打造商用密码人才、研发、可持续经营的良好环境，为我国密码产业发展、密码人创业提供全方位支撑，不久的将来，将会为密码人奉献一份精彩的大礼。

2、首次发布商用密码领域

第一份权威的产业报告

组委会与赛迪网络安全研究所、赛迪区块链研究院合作，首次发布了我国第一份权威的商用密码产业报告《2020-2021中国商用密码产业发展报告》。报告由赛迪网络安全研究所、赛迪区块链研究院主编，信息安全与通信保密杂志社、中关村中安高速密码产业联盟（筹）、深圳商用密码行业协会、甘肃省商用密码行业协会、陕西省商用密码协会、山东省商用密码协会、重庆商用密码行业协会、江西省商用密码应用协会、天津市商用密码行业协会、江苏省商用密码产业协会等作为联合发布单位参与报告。赛迪网络安全研究所所长、赛迪区块链研究院院长刘权在峰会上做了报告介绍演讲，引起了密码行业、产业链、投资界的广泛关注。《2020-2021中国商用密码产业发展报告》正在紧张的校对审核，预计5月中旬将正式出版发售。![](../Images/7868d4b867d5c43840e694cc23ed1c0f.png) **赛迪网络网络安全研究所所长刘权做《报告》简报**![](../Images/a2f6fd14b136fa7025ad722cc74f48ef.png)

3、首次推出商用密码行业大奖

本次峰会由信息安全与通信保密杂志、数观天下联合面向商用密码企业进行专业的评选，采用全免费、公开、公正的评选方式和流程，峰会现场揭晓了商用密码领域第一份优秀企业和优秀解决方案榜单。最终数盾科技、格尔软件、渔翁信息、西安得安、天威诚信、北京数字认证、深圳奥联、三未信安、格尔软件、渔翁信息、华测检测认证、北京数字认证、吉大正元、亿赛通获得优秀解决方案奖。中国工程院沈昌祥院士和中国密码学会徐茂智副理事长分别为优秀企业和优秀解决方案的获奖企业颁奖。![](../Images/986ee0b31a79bd49c030c22df0efd16c.png) ![](../Images/f52cec5f744883bd07172b187e3d6b91.png)

4、首次特别策划推出“商密木兰对话”

作为本次峰会的特别策划亮点，“商密木兰对话”从一开始就备受关注，寻找“商密木兰对话”嘉宾的过程也是和商用密码产业杰出女性交流的精彩历程。“商密木兰对话”由信息安全与通信保密杂志社主编/执行副社长唐莉主持，数盾科技朱云、国家密码检测认证中心刘芳、兴唐副总工刘尚焱、人民银行资深专家袁慧萍、中国工业互联网研究院于成丽组成商密产业超强的木兰嘉宾团，与主持人就商密产业政策管理、商密产业发展、应用展开了一场精彩的对话，同时他们丰富多彩的个人生活故事也博得了现场来宾热烈的掌声。“商密木兰对话”开创了商用密码领域巾帼精英的精彩序曲，主持人表示，首届“商密木兰对话”将作为峰会的传统项目保留下来，并将围绕商密产业杰出女性延续扩展，成为商用密码产业中巾帼精英的展示舞台、成为峰会的标志和名片、成为商用密码产业最亮的风景线。![](../Images/4fcd6e280d75714200afd22a225972c3.png)峰会现场精彩不断，“密码强国”系列活动启动仪式隆重举行、商密产业高峰论坛精彩上演，同时在近四十家商密产业链企业的参与下中关村中安高速密码产业联盟筹备工作启动仪顺利举行。
