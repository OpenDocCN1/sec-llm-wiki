# 张小松教授：区块链安全技术与应用

![](../Images/34dba026e70cecd7812b0c6a05ce3730.png)2008年，“Blockchain”的概念在中本聪的文章《比特币：一种点对点的电子现金系统》中被首次提出。区块链技术诞生之初主要用于加密货币，如比特币、莱特币、以太坊等。随着人们对其了解的深入，区块链技术逐渐应用到更广阔的领域，从银行等金融机构，再到云计算、边缘计算、物联网等技术领域，我们都能看到区块链的身影。但是区块链技术大规模应用其自身存在的技术性问题也逐渐暴露了出来，包括安全、隐私、性能等，这些仍然需要我们继续探索解决方案。  
![](../Images/88f9a16b06b76bb000e20c0109ce08b8.png)

  

  
  
  
  
  
  

《**区块链安全技术与应用**》是一部关于区块链安全与应用的技术专著，主要内容源自电子科技大学网络空间安全研究院近年来在区块链交易行为分析、性能优化、安全架构等方面的研究成果，这些成果先后在国际顶级学术会议和顶级期刊上发表，部分成果获得了国际学术会议最佳论文的荣誉称号。作者**张小松**教授通过细心的整理融合，以专著的形式为广大读者系统介绍区块链安全和应用领域的最新研究进展；基于计算机科学、现代密码学、软件工程等多个学科的基础理论，对区块链的安全和应用开展专题研究，并给出严谨的理论分析和实验结果。  

  

![](../Images/8b79b1b08b13d8cbe0e52705b1d5cf3a.png) 

中国工程院院士

2021 年1 月   

  
  
  
  
  
  

  

《**区块链安全技术与应用**》（张小松著. 北京：科学出版社，2021.3）针对区块链在体系架构、性能和安全方面的问题，以当前最具代表性的区块链平台—以太坊为实验研究对象，在交易行为分析、智能合约性能优化、安全架构和策略以及监管机制方面，进行深入的研究和探讨。

 

▋ **在交易行为分析方面**，提出采用复杂网络方法分析区块链交易行为，构建出三种复杂网络，获得了35 个新发现，设计出通用区块链数据分析平台。

 

▋ **在智能合约性能优化方面**，首次发现智能合约浪费交易费的问题，设计出第一款合约自动化优化软件，提出能有效遏制磁盘操作系统攻击、动态自适应的燃料费方案，发现智能合约静态分析的基础性难题，检测出数千种不一致代币合约，包括50 个未报道的漏洞，提出使用执行轨迹提高控制流转移识别的精度，从而精确识别代币行为的方法。

 

▋ **在安全架构和策略方面**，设计出扩展性好、性能好、兼容性好的区块链安全威胁检测框架，实现针对八种安全威胁的检测，并在三条不同的区块链上检测到大量的安全威胁。

 

▋ **在区块链的监管机制方面**，针对区块链去中心化和匿名化的性质被用户恶意利用的情况，提出一种门限变色龙哈希函数，并基于该函数设计了一种分布式可编辑的联盟区块链，用于构建安全和可靠的信任底层；进一步基于公钥密码算法和可证明安全理论，提出一种可撤销的变色龙哈希函数，设计了一种可自我修复的可编辑区块链。

 

本书汇集了电子科技大学网络空间安全研究院区块链团队近年的主要学术研究成果，已经分别在国际顶级学术会议和顶级期刊上发表，并先后获得了INFOCOM(International Conference on Computer Communications)2018 最佳论文奖、ISPEC (International Conference on Information Security Practice and Experience)2017 最佳论文奖、CCF(China Computer Federation，中国计算机学会)区块链专委会2018 区块链最佳论文奖、ESEM(International Symposium on Empirical Software Engineering and Measurement)2019 最佳论文提名等学术荣誉。

  

本书共14章。具体章节安排如下：

  

*   第1章主要介绍区块链的一些基本定义；
    
*   第2章主要介绍共识机制；
    
*   第3章主要介绍智能合约安全；
    
*   第4章主要介绍智能合约的优化方法；
    
*   第5章主要介绍以太坊的交易分析；
    
*   第6章主要介绍以太坊虚拟机的安全问题；
    
*   第7章对公钥哈希函数在区块链中的应用进行讨论；
    
*   第8章对数字签名在区块链中的应用进行讨论；
    
*   第9章围绕安全和隐私保护具体实现的问题，给出了相关定义、需求和实例；
    
*   第10章主要介绍基于区块链的身份管理相关内容；
    
*   第11章主要介绍基于区块链的云数据管理相关内容；
    
*   第12章主要介绍区块链用于解决数据漫游服务的问题；
    
*   第13章主要介绍区块链面临的挑战及在其他领域的应用；
    
*   第14章主要介绍可编辑区块链的必要性以及相关研究。
    

  

  
  
  
  
  
  

区块链是当下热门的话题，上至国家战略，下至学科建设、技术研发、人才培养、成果应用，各行各业无不积极关注和投入，均把区块链视为数字经济发展的理想载体和平台。但是冷静下来，区块链技术仍然面临共识算法机制、运行效率、存储机制、实体资产可信绑定、匿名与可信矛盾、监管等方面的一系列问题，希望该书的出版能为广大学者提供一部优质和严谨的区块链研究学术专著，给加快区块链技术研究、突破应用和安全中的瓶颈问题提供重要的启迪。

本书是一部关于区块链安全与应用的技术专著，主要内容包括区块链简介、共识机制与智能合约、区块链隐私保护以及区块链技术应用四个部分。第一部分简要介绍区块链的定义、架构、相关技术、分类等；第二部分重点讨论区块链智能合约安全、优化、交易行为、以太坊虚拟机的安全问题；第三部分讨论数字签名在区块链安全与隐私保护中的应用与实例；第四部分介绍区块链技术的几个应用场景，对实现区块链监管的可编辑区块链技术进行讨论。
