# 数字人民币跨境支付来了！深圳率先测试

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247523395&idx=2&sn=984476c054552ab4c6b5e48c7183092a&chksm=ec568c18db21050e234abcd045a8cb60495cae524dbfc46f17b893d6fbc3166266c976919763&scene=126&sessionid=1681313466#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247523395&idx=2&sn=984476c054552ab4c6b5e48c7183092a&chksm=ec568c18db21050e234abcd045a8cb60495cae524dbfc46f17b893d6fbc3166266c976919763&scene=126&sessionid=1681313466#rd)

近日，深圳市人民政府和人民银行深圳市中心支行指导罗湖区人民政府，与中国银行和中国银行香港股份有限公司合作，在全国率先完成了面向香港居民在内地使用数字人民币的测试工作，为探索数字人民币更加广阔的使用场景迈出了重要一步。

本次测试主要面向香港两类居民：一类是经常往来深圳的香港居民，可通过香港居民来往内地通行证（以下简称“回乡证”）进行实名认证；一类是偶尔来深圳的香港居民，即仅持有香港居民身份证的居民，通过香港手机号匿名开立五类数字人民币钱包。“这是我首次体验数字人民币消费，感觉兑换很方便，支付很流畅。”长期在深圳工作的香港居民梁女士在一家珠宝店体验了这一测试场景。梁女士开立数字人民币钱包后，通过回乡证成功完成了实名认证，然后绑定银行借记卡升级至二类钱包，扫描数字人民币支付二维码，购买了价值2000多元的项链。此外，经测试验证，香港居民可使用香港手机号码匿名注册开立数字人民币五类钱包进行小额消费，购买商品时仅需出示付款码即可通过POS机完成支付。此次测试成功构建了香港居民往来深圳使用数字人民币跨境支付场景，进一步扩大了数字人民币使用范围，验证了数字人民币钱包的匿名性、便捷性、安全性，有效降低了香港居民来深圳消费的跨境交易成本，为下一步推动数字人民币深港跨境流通、解决跨境旅游等经常项目的支付奠定了实践基础。![](../Images/a48e2c23db86de75831ccc4f9c69de15.png)来源：财联社注：内容均来源于互联网，版权归作者所有，如有侵权，请联系告知，我们将尽快处理。![](../Images/00a024d4f318db2d10c3f0988ca5d5fc.png)
