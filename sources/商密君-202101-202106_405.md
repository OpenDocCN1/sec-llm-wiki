# 我国SM9标识加密算法作为ISO/IEC 18033-5:2015补篇正式发布

2021年2月，我国SM9标识加密算法作为国际标准ISO/IEC 18033-5：2015/AMD1：2021**《信息技术安全技术加密算法第5部分：基于标识的密码补篇1：SM9》**正式发布。

![](../Images/8f76c55316ac925ce9b99a5544354b1f.png)2018年4月，我国提交了将SM9标识加密算法纳入ISO/IEC 18033-5的国际标准提案，随后作为研究项目启动研究；2019年6月，SM9标识加密算法作为ISO/IEC 18033-5补篇正式立项；经过一年多的编制工作，于2021年2月正式发布。我国专家分别担任该补篇的编辑和联合编辑。SM9标识加密算法是继SM9数字签名算法成为国际标准后发布的第二项SM9算法。其发布促进了非对称密码算法体系的完善，有助于增强我国密码产业在国际上的竞争力。![](../Images/a48e2c23db86de75831ccc4f9c69de15.png)来源：国家密码管理局注：内容均来源于互联网，版权归作者所有，如有侵权，请联系告知，我们将尽快处理。![](../Images/00a024d4f318db2d10c3f0988ca5d5fc.png)
