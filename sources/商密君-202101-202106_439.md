# 因用户数据收集使用不当，Facebook再被意大利罚700万欧元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247518691&idx=3&sn=457049fe94118a021ced4bdf27031049&chksm=ec5699b8db2110ae347ca45a4aba58479b5202a549e60edb9676bed5351bc1d09864eddef7d5&scene=126&sessionid=1681313517#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247518691&idx=3&sn=457049fe94118a021ced4bdf27031049&chksm=ec5699b8db2110ae347ca45a4aba58479b5202a549e60edb9676bed5351bc1d09864eddef7d5&scene=126&sessionid=1681313517#rd)

当地时间2月17日，意大利反垄断执法机构竞争与市场管理局（AGCM）发布一则公告称，由于Facebook公司未能遵守不当使用用户数据的整改令，被罚款700万欧元。

![](../Images/b016e74eda8616e14e2c3f827e88c6d6.png)

**意大利反垄断机构公告官网截图**

公告显示，AGCM曾于2018年4月对Facebook的用户数据使用行为进行调查，随后在2018年11月下发整改令，对Facebook处以500万欧元的罚款，并要求Facebook在公司网站首页发布整改声明。根据2018年11月的调查报告，AGCM认为Facebook并未充分告知用户数据将被商用。Facebook所提供的不完整信息，使用户无法明确区分数据是被用于完善个性化服务，还是被传送至第三方机构开展商业活动。具体而言，Facebook对用户的“活跃平台”功能进行数据共享同意的预先设定，使第三方网站或应用无需得到用户同意就可访问相关数据。当用户选择退出预设时，他们在使用社交网络和访问第三方平台方面将面临大量限制，AGCM认为这将诱使用户维持预设。由于上述行为违反了《消费者法》，AGCM对Facebook下达了整改令。但在昨日发布的最新公告中，调查表明Facebook并未更正用户数据的不当使用行为，也未发布该局要求的整改声明。AGCM表示，尽管Facebook称用户注册是免费的，但鉴于数据对Facebook商业价值的影响，用户提供的数据本身就可被视为享受平台服务所需的费用。因此用户有权利得知数据被使用的情况，以决定是否使用Facebook。公告发出后，Facebook并未发出声明。但据媒体报道，Facebook发言人回应称，公司已注意到监管机构的公告，并已提起上诉。同时该发言人表示，Facebook已更新有关服务条款，以阐明如何使用数据提供定制广告的服务。![](../Images/a48e2c23db86de75831ccc4f9c69de15.png)来源：商密君注：内容均来源于互联网，版权归作者所有，如有侵权，请联系告知，我们将尽快处理。![](../Images/00a024d4f318db2d10c3f0988ca5d5fc.png)
