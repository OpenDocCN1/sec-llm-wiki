# 商用密码证书可信计划发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247543604&idx=2&sn=2d5201ca83cea8face6ed658ce9e105f&chksm=ec563b6fdb21b279a18aeaf0b95f96babfb734e0e34c947096154aa10305c3b67dc0cf95ded0&scene=126&sessionid=1681313338#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247543604&idx=2&sn=2d5201ca83cea8face6ed658ce9e105f&chksm=ec563b6fdb21b279a18aeaf0b95f96babfb734e0e34c947096154aa10305c3b67dc0cf95ded0&scene=126&sessionid=1681313338#rd)

近日，以“经营安全，安全经营”为主题的2021北京网络安全大会（简称BCS 2021）产业峰会线上启幕，十余位两院院士，200多位全球嘉宾，围绕数字城市安全、数据安全与治理、密码应用与实践、网络安全产业担当与发展等热点议题展开交流讨论。

  

作为BCS 2021大会重要论坛之一的第五届网络安全产业担当与发展高峰论坛由中国计算机学会（简称CCF）主办。以“共担产业使命 共创产业未来”为主题，BCS大会顾问委员会委员、CCF计算机安全专业委员会荣誉主任严明主持，中国工程院院士沈昌祥、CCF计算机安全专委会主任、公安部一所副所长于锐、格尔软件副总经理朱立通受邀做客，与近百家网络安全骨干企业深入探讨产业发展机遇背景下的中国网络安全企业的“机”与“责”。

  

**01****商用密码证书可信计划发布**  
  

为加速国产密码推广应用，8月26日下午，在第五届网络安全产业担当与发展高峰论坛上，奇安信联合麒麟、统信、格尔软件等生态合作伙伴共同发起“商用密码证书可信计划”，为用户提供证书校验、加密通讯、网站证书验证等国密证书应用环境支持。  

  
![](../Images/e7ae265907c1ba617d0e5a205e4a6eb4.png)  
02共赢安全生态  
  

格尔软件副总经理朱立通在会议上表示：密码是国之重器，是保障网络与数据安全的核心技术，是网络信任的“底座”。国家高度重视商用密码工作，先后发布相关法律法规、采取重大举措，促进商用密码普及应用。  

  

![](../Images/50058170af4d83c433cfb28882bd5f91.png)  

关于助力国密应用“安全最后一公里”的问题，他认为：密码融入千家万户，是商用密码证书可信计划要达到的目标。实现这个目标，需联合信创生态上下游厂商，共同推进商用密码证书可信计划，加快生态建设，夯实数字证书安全根基！

  

朱总倡议大家要心往一起拧，劲往一起使，怀着保家卫国的情怀，提供更好的产品和服务，并步入创新协同、高质量发展的快车道。努力开创属于我们自己国家的商密事业！
