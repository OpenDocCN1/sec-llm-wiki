# 职业教育改革：职业教育与本科融合，打破学历天花板

![](../Images/34dba026e70cecd7812b0c6a05ce3730.png)职业教育，一直被大家所认知为中专、高职、中职、技校，被大众认知为三流学校，在目前的社会教育价值认知中，职业教育是比不上大专及三本的学校。甚至有些学生或者家长看不起职业教育毕业的人才。**但是社会是逐渐发展变化的，职业教育改革正在打破原有的学历价值观。**  
新闻联播针对目前职业教育的改革发表的热评，主持人康辉还直言：你说香不香？这次的职业教育改革，人民日报也相应发表了热评。具体职业教育的改革是怎么样的呢？

![](../Images/ef11861dd90010005dcf9b8d8b0354ab.png)

  
  
  

**职业教育与普通教育是两种不同教育类型**

**具有同等重要地位**

  
  
早在19年我国就印发过关于职业教育不同类型相同地位的文件，但是近两三年的发展，并没有在社会主要认知上发生改变。其实不论是本科综合性教育还是职业技术性教育都是教育，同样值得被尊重。  
  
  
  

**职业教育前途广阔、大有可为**

  
  
当今世界正经历百年未有之大变局，我们要构建新发展格局、推动高质量发展，在国际竞争中赢得主动，不仅需要大批拔尖创新人才突破“卡脖子”技术，也需要数以亿计的高素质技术技能人才。  
  
  
  

**职业教育与本科融合**

**打破学历天花板**

  
  
  
当今社会，学历是敲门砖。学历是制约很多年轻人发展的重要障碍，用人单位因为出于人事成本的考虑，在快速招人的基础上选择学历高的人，这也是情有可原的。  
在未来本科生需要向职业教育一样学习实用性技术教育，也就是说把技术性的实用性的东西让本科生也得学会，比如电焊、修车、厨师等等，职业教育也可以拥有同等的学历地位，从教育基础上打破学历天花板。当本科生拿着有技术性的学历走入社会时，这样的学历才更能说服自己，你说香不香呢？  
  
  

**中考改革**

**一半学生将流向职业教育中**

  
  
2021的中考改革可谓比高考改革还要让人激动，中考的升高率从之前的80%逐年下降，到如今已经接近于50%，也就是说将有一半人流向职业技术教育中，中专、高职、技校等等。面对这样的改革，有可能对一些学生来说是一次人生的选择，但是在成绩并不优秀的人群中，拥有一技之长不是更香么？
