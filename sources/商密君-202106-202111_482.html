以往，Windows系统升级只会因为处理器、内存性能较跌而导致运行卡顿，可这一次，Windows 11升级竟抛出了强制硬件支持条件，用户PC平台满足不了则无法升级，这样的消息让不少小伙伴多少有些惊讶——我是否自愿升级和我能否升级明显是两回事儿啊！

01


Win 11为何强制TPM 2.0硬件支持


在微软发布了 Windows 11 操作系统之后，本周有许多喜欢尝鲜的用户在运行“系统升级检查器”时看到了对于“可信安全模块”（TPM）的强制性提示。这意味着在崭新的用户界面（UI）、Android 应用程序支持（WSA 子系统）、手写笔交互等体验刷新之外，微软更加注重 Windows 11 能够带来的安全性改进。所以对 TPM 2.0 的支持，也没了商量的余地。



微软最新的Windows 11系统配置需求页中写道：

·Windows 11有新的最低硬件要求，为了运行Windows 11，设备必须满足硬件规格。不符合硬件要求的设备不能升级到Windows 11。

·处理器：1千兆赫（GHz）或更快，在兼容的64位处理器或片上系统（SoC）上有2个或更多内核

·内存：4千兆字节（GB）

·存储器：64GB或更大的存储设备

·系统固件：可信平台模块（TPM）2.0版

·图形卡：兼容DirectX 12或更高版本的WDDM 2.0驱动

·S模式只支持Windows 11的家庭版。如果你在S模式下运行不同版本的Windows，你需要在升级前先切换出S模式。

注意：本文已经更新，以纠正关于Windows 11的TPM要求的指导。欲了解更多信息，请参阅Windows 11规格这一章节。


要检查你的设备与Windows 11的兼容性，请从升级到新的Windows 11操作系统获得PC健康工具。



据悉，TPM 是一种能够存储加密密钥和账户凭据等内容的芯片，通常与 PC 主板或处理器有关，但并非近年的所有系统用户都选择了启用。


争议的另一大焦点，就是微软在“Windows 11 兼容性”描述中有些含糊其辞。直到该公司企业与操作系统安全总监 David Weston 在 Windows 安全博客上发表了一篇新文章：“未来 PC 需要借助这种现代硬件的信任根（root-of-trust）来帮助抵御常见和复杂的攻击，比如勒索软件和重量级黑客组织的复杂攻击。通过强制内置的信任根，Windows 11 对 TPM 2.0 的要求，也将有助于提升硬件的安全标准。”



基于此，在默认情况下，任何通过 Windows 11 认证的系统，都将包含 TPM 2.0 芯片。


它将成为一套更加全面的安全工具的一部分，包括使用 Windows Hello 的能力、以及支持 Intel / AMD 系统上的硬件级强制堆栈保护，且这类 PC 能够开箱即用。


David Weston 补充道：新版 Windows 操作系统附带的对新硬件的安全要求，旨在构建一个更强大、更能抵御针对认证设备攻击的基础。


我们深知这套方案的有效性 —— 拥有安全核心的 PC 产品，对恶意软件感染的抵抗力，将是以往的两倍。


目前已知的是，包括宏碁、华硕、戴尔、惠普、联想、松下等在内的 OEM 厂商，都将为新系统提供对 TPM 2.0 的坚实支持。至于消费级 PC DIY 市场将如何发展，还请拭目以待。



02


微软并非第一次提TPM硬件支持


“Windows 11强制TPM2.0硬件支持”这一次引发如此高关注加上网上讨论，让微软官方都不得不出来解释，让小编都有些惊讶，毕竟这并非微软第一次提出TPM硬件支持了，不排除这一次的热议有网络媒体互相炒作，可以引导不明所以的消费者关注加八卦的可能，在具体展开Windows 11系统升级和TPM2.0硬件关系以前，小编还是建议大家全面了解下TPM2.0硬件。


TPM（Trusted Platform Module，可信任安全平台模组）是一种基于硬件的安全标准，该标准要求设备配备专用的防损芯片，以此提升设备的安全性，该标准可以使设备更加安全地进行解码密钥的生成、储存和认证。TPM是Windows BitLocker进行加密的关键标准，微软将其称为“Win10履行对用户安全承诺的关键”。


大家还可以通过微软官方文档了解详情：https://docs.microsoft.com/zh-cn/windows/security/information-protection/tpm/tpm-fundamentals。那么，微软要求安装、升级Windows 11必须拥有TPM是否是为了帮助硬件厂商卖新电脑吗？非也。从文档我们能够知道TPM可以提高系统安全性，但是其普及率并不高。这点微软也十分清楚，并早在8年前Windows 8发布的时候，微软就已经和Intel等合作伙伴一起为今天Windows 11普及TPM做了准备。


在Windows 8发布的时候，微软与Intel合作推出Platform Trust Technology（PTT），通过将安全芯片内置于CPU内，然后配合UEFI固件实现等效于TPM 2.0的fTPM（Firmware based TPM）。Inetel Hasewell（4代）以后的处理器，都支持该技术。


 2016年，微软再次要求新安装Windows 10的计算机必须支持TPM（旧机器升级不强制要求）。

AMD方面，其ZEN架构都支持fTPM。因此，虽然大部计算机没有硬件TPM，但其实只需要简单的在BIOS开启Intel PTT或者AMD fTPM功能，即可实现TPM 2.0的要求，满足Windows 11的升级要求。


因此，对于主流PC而言，TPM恐怕真得不是太大的问题，毕竟三大巨头都明确了TPM需求并进行了功能设定，看到这里，似乎更倾向这是一次老新闻的炒作。



03


怎么知道我的电脑是否有TPM芯片？


当然，即使是老需求，可抵不住“三人说虎”啊，怎么知道我的电脑是否有TPM芯片？成为不少小伙伴想要一试究竟的存在，毕竟，我想要知道我能不能升级Windows 11，至于是否升级，暂且不论。


事实上现在主流的电脑都是支持TPM的，即使没支持到TPM2.0，也会支持TPM1.2，TPM的设置是集成在主板的BIOS中的，无论是Intel的主板还是AMD的主板，都能在BIOS中找到TPM。只不过在大多数时候，这个功能默认是关闭的，需要用户手动打开才行。


在Intel的BIOS中，TPM被称为PTT功能，默认是关闭的，一般来说对应的选项会放在Interl主板BIOS中的Advanced/进阶项目中；而在AMD主板上，TPM功能被称为AMD fTPM，同样是放在Advanced/进阶项目。具体TPP功能的位置。会根据不同的主板品牌会有所差异，但多数都是与CPU有关的设置里，用户找到了后打开即可！



主要是兼容机用户为提升性能，都会把这些多余的功能主动关闭，很少有人会推荐打开TPM功能的。但是在笔记本电脑或者品牌台式机上，TPM基本默认都是打开的，这是因为在PC厂商看来，电脑使用安全才是第一位的，所以会主动将这个功能开启。


要检查您的计算机是否具有兼容的 TPM，请在 PowerShell 窗口中运行命令 get-tpm。打开“开始”菜单并搜索 Windows Powershell。右键单击“Windows PowerShell”并点击以管理员身份运行。



窗口打开后，键入并输入get-tpm。



最后检查 TPM 是否存在并启用。

非常有意思的是这一次大张旗鼓炒作下， TPM 2.0模块价格已经出现了暴涨。



04


TPM 2.0模块价格暴涨3倍


在Windows 11的硬件要求中，CPU、内存、显卡、硬盘这些要求对当前的玩家来说没有压力，但是最容易被卡住的地方就是TPM 2.0，相比Windows 10都要严格很多，所以很多人的PC健康检查工具都不过关（其实大多数是因为TPM在BIOS里面未开启）。


但对一些稍微旧点的平台，物理上就是没有TPM 2.0的，这些玩家怎么升级？

答案是购买TPM 2.0模块，网上就有卖的，现在被Windows 11系统带热了，电商上的TPM 2.0模块价格也在迅速上涨，原本售价24.9美元的产品不到2个小时就涨价到了99美元，暴涨3倍。


考虑到自己安装TPM 2.0模块的麻烦，估计大部分人并不会通过这种方式让系统符合Windows 11要求，而微软现在也注意到了问题所在，已经降低要求到TPM 1.2，门槛低了很多，老机器也能升级了。


别以为这是瞎折腾，因为不支持TPM 2.0可能让部分内置Intel处理器的Mac也无缘Windows 11。


6月26日消息，据9to5Mac报道指出，搭载英特尔处理器的Mac设备无缘Windows 11操作系统，即便是搭载最新一代英特尔处理器的Mac设备，可能也无法运行Windows 11。因为苹果公司从未在英特尔版Mac设备上提供对TPM 2.0的支持，这使得它们与Windows 11不兼容。



理论上来说，苹果可以更新固件让Mac设备实现对TPM 2.0的支持，但是似乎不太可能了，因为苹果正在用自家的M系列芯片取代英特尔芯片。当然，M1芯片的Mac设备自然无法运行Windows 11。
