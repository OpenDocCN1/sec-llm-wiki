# 首批基于商用密码算法的智能网联汽车信息安全标准项目发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247558422&idx=1&sn=97cc3ab96b15e64ec65f008437fc5af0&chksm=ec57f54ddb207c5ba4adbbd07744927cf37eb2dcf6bf4febbaba62d82c8425751bc0f849b977&scene=126&sessionid=1681313230#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247558422&idx=1&sn=97cc3ab96b15e64ec65f008437fc5af0&chksm=ec57f54ddb207c5ba4adbbd07744927cf37eb2dcf6bf4febbaba62d82c8425751bc0f849b977&scene=126&sessionid=1681313230#rd)
