# 重庆市密码管理局组织参加密码行业标准化技术委员会二届三次会议

12月21日，密码行业标准化技术委员会（以下简称“密标委”）二届三次会议采取线上线下相结合的方式召开。重庆市密码管理局组织重庆密码应用专家组成员、重庆商用密码行业协会成员单位采取线上方式参会，重庆共设立3个会场，50余人参会。

  

![](../Images/9d8b557c88516b4e63fba1a4cc1981a5.png)

  

与会人员认真聆听了国家密码管理局局长刘东方的讲话，国家密码管理局副局长徐汉良对第二届密标委工作的总结和下一阶段工作部署，以及王小云、杨富玉、郭沛宇、刘民、刘平、冯登国等专家领导所作的主题演讲。

  

会后，市密码局连线其它两个会场，召开视频会议。市密码局局长傅光渝强调，新时代赋予新使命，高质量呼唤高标准，密码行业标准化工作取得可喜成绩。各单位要以密码行业标准化工作新发展为契机，充分发挥标准引领创新发展作用，通过密码标准实施应用促进自身发展；要加强前沿技术研究，以密码行业标准牵引带动密码团体标准、企业标准的制定；要牢牢把握密码发展方向，服务国家发展战略，在维护国家安全、促进经济社会发展、保护人民群众利益中做出重庆的贡献。

  

![](../Images/af0480898c7fe32d70ec417b49305b9b.png)

  

与会人员纷纷表示，下一步，将深入贯彻落实密码国家标准、行业标准，以标准为导向，促进重庆密码产业高质量发展。
