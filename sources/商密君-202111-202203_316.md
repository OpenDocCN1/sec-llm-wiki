# **关于举办2021年商用密码应用安全性评估工作培训的通知**

**各密评试点机构：**兹定于2021年12月24日-25日在线举行商用密码应用安全性评估工作培训。现将有关事项通知如下：**一、主办单位**中国密码学会密评联委会**二、培训形式**在线直播，输入报名手机号获取验证码登录观看。线上直播电脑端链接：http://mudu.tv/live/watch?id=mv7db2jm**三、培训费用**培训费用按单位收取，每家5000元（含线上直播平台租赁服务费、讲课费、线下场地租赁费等），每家缴费单位分配1个接入账号。**四、培训时间**远程接入调试时间：2021年12月23日（周四）15:00-17:00开放远程接入调试，接入后请保持在线。**培训时间：**2021年12月24日（周五）9:00-18:002021年12月25日（周六）9:00-15:30**五、培训交费**1.扫码支付![](../Images/a93d444683eac058b711b5225c175dad.png) 2. 银行汇款请通过银行汇款交纳培训费用户  名：中国密码学会账  号：0200 1864 1920 0001 727开户行：中国工商银行北京万寿路南口支行注  意：请在汇款附言中注明“单位+密评培训”。**六、培训报名**培训报名回执（参加附件）请于2021年12月21日（周二）17时前，发送至联系人邮箱：mppx2021@nitsrc.cn。**七、联系人**会务：梁老师18911228248魏老师15064019109财务：米老师13718641920（决算）梁老师18600651587（收费、开票）
