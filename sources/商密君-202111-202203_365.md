# 共享学术交流 共谋创新发展 ——2021第十四届中国密码学会年会举办

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_1381560996854185984](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_1381560996854185984)12月4日-5日，2021第十四届中国密码学会年会在贵阳举办。本次年会由国家密码管理局指导，中国密码学会主办，贵州大学承办。贵州大学校长、中国工程院院士宋宝安，国家密码管理局正局长级督察专员于传斌，中国密码学会理事长、中国科学院院士王小云，贵州省密码管理局副局长陆长宏等出席开幕式并致辞。国家密码管理局商密办副主任吴立刚出席开幕式，中国密码学会副理事长兼秘书长安晓龙宣布获奖名单。开幕式由本届程序委员会主席、贵州大学彭长根教授主持。开幕式上，贵州大学校长、中国工程院院士宋宝安指出，贵州大学密码学研究历史深厚，早在1998年举办过全国性密码学术年会。今天，在中国密码学会的主办下，贵州再次汇聚密码领域专家学者和业界精英，共同探寻密码的奇特与奥秘，共话密码创新发展，对促进国内密码产学研深入融合，推动贵州密码学术发展具有重要意义。![](../Images/486ea2fb7ca7acb8b2dc186bb98f5f87.png)贵州大学校长、中国工程院院士宋宝安致欢迎辞国家密码管理局正局长级督察专员于传斌指出，**科技创新已经成为国际战略博弈的焦点，**新一代信息技术正在深刻改变全球技术产业体系、世界经济发展方式和国际产业分工格局。**中国密码学会作为密码领域唯一一家全国性社会组织，是国家密码创新体系的重要组成部分，是推动密码科技创新的一支重要力量。**希望中国密码学会切实履行“四个服务”职责使命，不断加强思想引领力、学术影响力、科普渗透力和公共服务竞争力。![](../Images/d22c44f074465561b234b9105d5957fb.png)国家密码管理局正局长级督察专员于传斌致辞中国密码学会理事长、中国科学院院士王小云指出，在网络攻击多样化、计算机运算速度不断提高以及密码应用需求不断增长的情况下，迫切需要发展更为完善的密码分析理论、密码设计理论以及相关密码数学基础理论。**如何在密码理论、密码技术、密码保障、密码管理等方面进行创造性、前瞻性的研究与应用，是当前最为紧迫的问题。希望我国密码专家学者经过不懈努力，面向应用、协同创新，不断突破密码与信息安全技术研究新高度。**![](../Images/147693aeb479a02498139b10398924a2.png)中国密码学会理事长、中国科学院院士王小云致辞中国密码学会副理事长兼秘书长安晓龙宣布了2020年密码创新奖、2019-2020年度中国密码学会奖、2021中国密码学会优秀博士论文及2018年度《密码学报》最佳论文获奖名单。本次会议设有特邀报告和优秀青年学者、密码学前沿交叉和应用、论文报告等分论坛。国际著名密码学家Adi Shamir、Craig Gentry、Joan Daemen和王小云院士、冯登国院士及杰出青年密码学家翁健教授和郁昱教授作特邀报告。分论坛邀请了来自中国科学院、清华大学、贵州大学、武汉大学、上海交通大学、华为、卫士通、兴唐、矩阵元等多所高校和企业的29位专家作精彩学术报告。

会议采用线上线下相结合方式，线下设贵阳会场和北京会场，线上线下约8500余人次观看。
