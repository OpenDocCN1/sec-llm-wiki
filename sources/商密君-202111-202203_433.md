# 安全多方计算IEEE国际标准发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247553325&idx=4&sn=6c0c7ed7aac4706a9982c10298419dec&chksm=ec560176db218860eca39b5d6804e6c171000490848f910a2e7739ece22413a1f4584a303f69&scene=126&sessionid=1681313271#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247553325&idx=4&sn=6c0c7ed7aac4706a9982c10298419dec&chksm=ec560176db218860eca39b5d6804e6c171000490848f910a2e7739ece22413a1f4584a303f69&scene=126&sessionid=1681313271#rd)

![](../Images/f53bcdf4d756ec25ca1c0643402f0872.png)

  

近日，国际标准组织电气与电子工程师协会（IEEE-SA）正式发布了阿里巴巴牵头制定的安全多方计算IEEE国际标准——《IEEE2842-2021 - Recommended Practice for Secure Multi-Party Computation》。

  

阿里巴巴相关负责人介绍，该标准主要聚焦于数据协作共享过程中的信息泄露风险问题。一直以来，传统的解决方案是通过一个可信的第三方实现数据的安全共享和计算，但“可信第三方”有时也会成为信任的“瓶颈”。为此，学术界和产业界都在研究相关的创新技术。安全多方计算(Secure Multi-Party Computation，简称MPC)就是其中一种，可以实现“数据可用不可见”。

  

据悉，该标准规范了安全多方计算的定义，以及安全多方计算的基本要求、可选要求和安全模型、系统角色以及工作流程、部署模式等，并在附录给出了安全多方计算的具体实现案例。 

  

自2019年阿里巴巴在IEEE牵头立项了此标准，历时2年标准制修订，经过多轮辩论、沟通，起草等大量推动和研究工作，并成立了SecureMulti-Party Computation Working Group安全多方计算工作组，阿里巴巴担任工作组主席，联合参与单位一起推进了MPC国际标准。阿里巴巴标准化业务副总裁朱红介绍，此IEEE安全多方计算国际标准帮助业界形成了关于MPC技术的共识，从而可以具体指引MPC技术在实际业务中的部署和实践。可以更好地帮助业界解决数据共享场景下的数据安全问题，并有效降低协作成本，让数据在各行各业合作过程中可以更加安全地发挥更大作用。
