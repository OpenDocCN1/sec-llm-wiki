# 安恒信息首席科学家刘博：发展数据要素市场，必须安全先行

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_1381560996854185984](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_1381560996854185984)数据作为要素参与市场化配置为数字经济发展注入新的红利，数据共享流通力度不断加强，防范化解网络安全、数据安全风险任务也更加艰巨。7月8日，“2022·云山论剑”广州数据安全峰会在白云区召开。峰会上，安恒信息首席科学家、之江实验室网络安全研究中心副主任刘博作题为“数据安全：激活数据潜能、释放数据价值”的演讲。![](../Images/35de5ac30ac6c0cd34acdfe6bd1b4815.png)安恒信息首席科学家刘博发表主题演讲。南都记者 马强 摄刘博表示，近年来，数据暴露面增大，数据安全风险频发，数据泄露事件涉及工业、政务、金融、教育、医疗、个人信息等多个领域，需网络安全、数据安全和隐私计算技术联合应对，共同构建安全可信的数字世界。其中，网络安全技术针对外部网络攻击所导致的泄露，数据安全技术针对企业员工或者合作伙伴在内部数据使用过程中有意或者无意导致的泄露，隐私计算技术针对数据在开放给组织外第三方或者与第三方进行联合计算导致的泄漏。以隐私计算技术为例，典型应用场景包括政务公共数据授权运营、大数据交易中心、多方联合计算、敏感高价值政务数据共享开放、企业内部敏感数据使用和分析、外包计算等。在刘博看来，网络安全是数据安全的前提，数据安全是网络安全的一种体现，数据安全强调全生命周期中的数据保护，或数据作为生产力，或强调数据主权、数据主体权利、长臂管辖权、隐私保护等场景。总体来说，数据安全更多的是强调赋能，如数据要素市场，必须安全先行，只有数据安全到位，才能开展这块业务。刘博表示，数字全球化加剧了各国围绕国家主权和安全的博弈，从《网络安全法》重视网络空间的主权，《数据安全法》越来越关注数据的主权，既要筑牢安全底座，又要营造良好数字生态，提高数字政府建设水平，打造数字经济新优势。此次峰会由中共广州市委网络安全和信息化委员会办公室、广州市国家保密局、广州市公安局、广州市政务服务数据管理局指导，白云区人民政府主办，中共广州市白云区委网络安全和信息化委员会办公室、白云区政务服务数据管理局承办，杭州安恒信息技术股份有限公司、广州安恒智慧城市网络安全技术有限公司、南方都市报、南都大数据研究院联合承办，广州市网络安全产业促进会、广州市白云区信息化发展协会协办。
