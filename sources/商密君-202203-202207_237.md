# 博通拟 4000 亿收购 VMware：预计周四官宣

![](../Images/ff556c849d588a6476edc45d4e6d8cf9.png)  
知情人士表示，这两家科技公司都旨在周四宣布一笔现金加股票收购的交易（收购价是每股140美元），前提是谈判不会破裂。  
一些人士警告说，收购价尚未确定，仍有可能出现变动。  
  
其中一位知情人士表示，为了帮助筹措这笔交易所需的资金，博通计划与几家银行合作，提供约400亿美元的债务融资。  
VMware 5月23日的市值403亿美元，5月24日市值503亿美元，暴涨100亿美元。
