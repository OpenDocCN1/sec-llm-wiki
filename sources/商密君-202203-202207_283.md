# **中国密码学会2022年密码算法学术会议通知**

为进一步促进国内外密码算法领域专家学者的交流与合作，由中国密码学会密码算法专业委员会主办，福建师范大学承办的中国密码学会2022年密码算法学术会议将于2022年5月28日在线上举办。会议以“密码算法的设计分析与应用”为主题，旨在汇聚国内密码算法领域中从事学术研究和应用技术开发的专家教授、研究学者、行业精英、工程技术人员、管理人员和在校研究生，共同探讨密码算法领域各方向的最新成果、学术热点、学术动态及发展趋势，促进密码学术界和产业界的相互交流与合作。本次会议将围绕密码算法这一主题，采取线上方式，邀请国内知名专家做特邀报告。热烈欢迎密码算法相关领域的广大科技人员和管理人员踊跃参加会议。现将会议有关事项通知如下：**一、主办单位**中国密码学会密码算法专业委员会**二、承办单位**福建师范大学**三、会议时间**2022年5月28日**四、会议形式**线上直播方式**五、会议链接**点击以下链接http://www.aconf.cn/live/191729输入“参会码”进入会议直播室**六、会议注册**1\. 缴费方式（1）扫码支付
