# 美刊：“电报”软件成俄乌数字战场

美国《时代》周刊网站3月21日发表题为《“电报”软件如何在俄乌战争中成为数字战场》的文章，作者是薇拉·贝根格林。

  

**全文摘编如下：**

  

在2月24日俄军“入侵”乌克兰之前，纳塔利娅·涅任斯卡从未使用过“电报”。现在，她一天都离不开这个通信应用软件。它把来自她的家乡乌克兰东部城市哈尔科夫的源源不断的最新消息，推送到她现在位于美国弗吉尼亚州洛顿的家中。她不假思索地说：“军队在做什么，他们摧毁了多少直升机，有关补给的新闻，各种流传的笑话，当地传奇人物。”

  

涅任斯卡作为军医在美国陆军中服役5年，从而获得了美国公民身份。她说，这款应用软件上的帖子作为战争的证据，数量将成倍增加。

  

她说：“我认为，这是记录战争罪行的一个非常有用的工具，因为它包含大量轰炸的实时镜头，这些视频来自居民的手机和当地监控摄像头。”

  

难以想象，如果没有“电报”，俄罗斯在乌克兰的战争会如何发展。这款去年下载量达到10亿次的通信应用软件已经变成这场冲突的数字作战空间。对两国政府来说，它是有用的工具。对两国的公民来说，它是一个信息中心。

  

包括总统弗拉基米尔·泽连斯基在内的乌克兰政府官员，事事都要依赖这款应用软件。他们通过该应用软件争取全球支持、发布空袭警报、提供当地防空洞的地图等等。

  

俄罗斯政府和俄罗斯反对派的各信息渠道也严重依赖这款应用软件，因为他们现在已经同大多数主流社交媒体断了联系。业余侦探和高级军事官员之类的人会对乌克兰的各个信息通道进行全天候仔细搜寻，以了解有关最新袭击或军事进展的细节。

  

“电报”已经成为这场战争最重要的社交媒体平台，为世界提供着未经过滤的对战争的看法。

  

在300多万乌克兰难民的出逃过程中，这款应用是至关重要的，因为它帮助他们找到安全路线和援助。

  

数以百万计身在国外的乌克兰人，要用它获取来自家乡的消息，拼命浏览无穷无尽的照片和视频，以寻找熟悉的地标性建筑或面孔。俄罗斯军人的家属也是如此。

  

前联邦调查局人员、外交政策研究所专门研究外国虚假信息的研究员克林特·沃茨说：“这是从西方世界进入俄罗斯世界的最后一个社交媒体桥梁……在这里，你能在一定程度上看到正在发生什么，以及战斗如何发展。谁能在‘电报’上维持他们的信息战，谁就最有可能影响世界对乌克兰国内局势的看法。”

  

“电报”的力量和危险性是其缺乏监督的产物。如今流亡在外的俄罗斯兄弟尼古拉·杜罗夫和帕维尔·杜罗夫于2013年创建了这个应用软件。该应用很快变得臭名昭著，成为“伊斯兰国”组织等极端分子的避风港。

  

当脸书、推特和YouTube等社交媒体平台，对来自“圣战组织”和“极端主义”组织的内容进行“清理”之际，这个当时默默无闻的通信服务软件却为它们提供了速度、安全和隐私——因为它几乎没有内容审核。
