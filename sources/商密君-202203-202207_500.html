密码科技国家工程研究中心（筹）是我国密码领域设立的唯一国家级工程研究中心，于2021年11月由国家发改委正式批准筹建，由中国电子科技集团有限公司主管。中心立足党中央决策部署和国家使命，推进国产密码在重要行业领域应用，聚焦密码关键核心技术攻关，承担密码领域重大科技成果工程化、系统集成和产业转化等任务。
中心总部位于北京市，未来将依据发展情况设置省部及行业分中心。为支撑中心业务发展，培养高水平的人才队伍，根据筹建工作需要，现面向社会和网安系内部公开招聘行业应用高级研究员、行业应用研究员、密码技术高级研究员、密码技术研究员、产业促进专员等岗位，中心期待青年才俊的加盟，为您提供大展身手的舞台！

岗位名称：行业应用高级研究员
1. 招聘形式：网安系内部、社会招聘
2. 工作地点：北京
3. 岗位职责描述：
  1. 面向国家关键基础设施等重要行业领域密码应用需求，组织开展密码应用总体研究和系统架构设计工作；
  2. 承担大型信息系统密码应用总体设计技术研究工作；
  3. 为各行业主管单位提供密码规划咨询、行业密码应用总体研究、系统总体设计服务。
4. 岗位能力要求：
  1. 信息安全、密码学、计算机科学与技术、网络与通信、应用软件等相关专业，熟悉系统工程相关知识、有应用经验者优先；
  2. 熟悉国家关键基础设施等重要行业领域业务及信息系统相关的政策标准、技术规范、顶层规划等，有相关行业领域信息化、信息安全总体设计经验者优先；
  3. 具有较强的总体研究、总结归纳能力，擅长系统工程总体设计方案、技术研究报告、标准规范编制工作，承担过863或国家重大科技项目者优先；
  4. 具有积极进取、踏实负责的工作态度，团队沟通合作意识强，能够承受较强工作压力；
  5. 硕士3年以上工作经验，博士不限。

岗位名称：行业应用研究员
1. 招聘形式：网安系内部、社会招聘
2. 工作地点：北京
3. 岗位职责描述：
  1. 分析信息系统安全威胁和业务应用场景的密码应用需求；
  2. 设计重要信息系统密码保障应用规划和实施方案；
  3. 从事信息系统的密码应用融合方案设计工作；
  4. 从事信息系统密码应用态势监控系统设计工作；
  5. 提供密码应用技术咨询、密码职业技能培训、密码科普等相关服务。
4. 岗位能力要求：
  1. 密码学、通信网络、信息安全、计算机软件、等相关专业毕业；
  2. 在金融、能源、水利等国家关键基础设施行业领域有多年业务积累，熟悉业务需求了解业务特点；
  3. 有比较丰富的重要行业领域或技术领域解决方案编制经验；
  4. 了解信息系统等级保护和商业秘密保护相关标准和规范，可准确把握客户需求，具备行业密码应用方案设计能力；
  5. 具有积极进取、踏实负责的工作态度，团队合作意愿强，能够承受较强工作压力；

岗位名称：密码技术高级研究员
1. 招聘形式：网安系内部、社会招聘
2. 工作地点：北京
3. 岗位职责描述：
  1. 研究国内外前沿密码理论、密码技术及密码应用发展趋势；
  2. 牵头密码基础共性技术、前沿技术研究；
  3. 负责面向新设施新要素、新场景新业务条件下的密码应用技术及行业标准研究；
  4. 承担商用密码相关重点专项、重大课题、重要任务等工作。
4. 岗位能力要求：
  1. 计算机、信息安全、密码学、通信等相关专业；
  2. 熟悉商用密码相关政策法规和标准规范，有相关领域工作经验；
  3. 熟悉车联网、物联网、工业互联网、5G等领域；
  4. 具备信息系统密码总体技术方案设计能力或科技创新项目策划论证能力；
  5. 具备独立或领导团队开展关键技术攻关能力，乐于学习新知识、新技术，敢于接受挑战性工作任务；
  6. 具备较强的沟通能力和书面表达能力；
  7. 硕士3年以上工作经验，博士不限。

岗位名称：密码技术研究员
1. 招聘形式：网安系内部、社会招聘
2. 工作地点：北京
3. 岗位职责描述：
  1. 承担密码基础共性技术、前沿技术研究任务；
  2. 参与商用密码相关标准研究和编制；
  3. 参与商用密码相关重点专项、重大课题、重要任务等工作。
4. 岗位能力要求：
  1. 计算机、信息安全、密码学、通信等相关专业；
  2. 具备网络安全或密码相关工作经验；
  3. 具备独立承担关键技术攻关能力，乐于学习新知识、新技术，敢于接受挑战性工作任务；
  4. 具备较强的沟通能力和书面表达能力；
  5. 硕士3年以上工作经验，博士不限。

岗位名称：产业促进专员
1. 招聘形式：网安系内部、社会招聘
2. 工作地点：北京
3. 岗位职责描述：
  1. 负责密码工程中心品牌形象建设与宣传推广；
  2. 负责产业生态关系维护，密码创新技术的合作、引进、转移、扩散和应用推广等；
  3. 组织密码产业及相关网信产业生态单位开展技术交流合作、信息共享，推动产业融合发展；
  4. 收集并分析产业相关政策，组织重大产业类项目申报，争取政策与资金支持；
  5. 收集整理产业情报数据，编制发布产业发展蓝皮书；
4. 岗位能力要求：
  1. 本科及以上学历，理工科类相关专业，985、211院校优先；
  2. 五年及以上密码或网络安全行业工作经验，有公共关系相关工作经验；
  3. 对相关国家政策、法律、法规有比较深入的了解；
  4. 熟悉国家级、省、市、区级各类扶持、奖励项目和相关政策；
  5. 沟通能力、应变能力强，有亲和力，对信息有敏锐的观察力，有较强的口头和文字表达能力。
