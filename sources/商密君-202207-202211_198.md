# DID分布式数字身份系统在上海股交中心正式上线

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247583271&idx=3&sn=2f3dba2a957adefcecf9f00786c60700&chksm=ec57967cdb201f6a6f9fe6cb635185bde01709513c7eb33ac27bd7ce1f9bb4b57c4159dd52c0&scene=126&sessionid=1681312965#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247583271&idx=3&sn=2f3dba2a957adefcecf9f00786c60700&chksm=ec57967cdb201f6a6f9fe6cb635185bde01709513c7eb33ac27bd7ce1f9bb4b57c4159dd52c0&scene=126&sessionid=1681312965#rd)

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_1381560996854185984](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_1381560996854185984)为了全面贯彻落实中国证监会《区域性股权市场区块链建设要求》和《国家区块链创新应用试点工作方案》的总体要求，今年3月份，上海股权托管交易中心（以下简称“上股交”）与上海市联合征信有限公司（以下简称“上海征信”）启动了区域性股权市场DID分布式数字身份建设试点工作，克服疫情影响，经半年技术攻关，于近日在上股交上线运行，属区域性股权市场全国首创。基于梧桐链分布式数字身份技术，率先在区域性股权市场上线应用DID分布式数字身份技术解决数据授权采集，融合使用的问题。DID分布式数字身份系统是基于区域性股权市场先进的双层区块链架构，构建了新型数字信任体系，创新性地解决了跨机构、跨行业的身份认证问题。通过DID数字身份系统的可验证凭证有效解决了数据的授权认证问题、简化了数据的交互、规范了数据的流通格式，加强了数据的隐私保护。本次试点首次引入企业征信服务，对DID数字身份证明进行在线解析和验证，实现身份认证全过程闭环管理，开创了征信数据服务标准化资本市场创新，为区域性股权市场更好服务优质中小企业提供了数据赋能,进一步推动区域性股权市场建设形成数据共享、资源互通的生态体系。**什么是DID**分布式数字身份（DID-Decentralized Identity）是基于区块链技术构建的新一代数字身份系统，具有保证数据真实可信、保护隐私安全、互操作性强、可移植性强等特点，是构建数字经济、发展未来数字技术的基础设施，相较于目前主流的PKI（Public Key Infrastructure,公钥基础设施）身份体系，其优势在于：1、身份自主可控：基于DPKI（分布式公钥基础设施），每个市场主体的身份不是由可信第三方控制，而是由其自身控制，市场主体可以自主管理自己的身份；2、可信数据交换：身份相关数据存储在区块链上，具备身份的安全性和自解释性，认证的过程不需要依赖于提供身份的应用方；3、身份的交叉验证和查询：基于区块链的分布式数字身份技术，可以在不同的应用场景中进行身份信息的交叉验证和查询。各参与方组建的区块链中各个节点拥有自己的身份信息库，通过区块链连接各身份数据源，从而形成一个DID网络，并且各节点为各方在区块链上开展业务生成一个链上的唯一身份标识符，同时提供一套可验凭证的工具。**展望未来**展望未来，在强化了隐私保护、安全性和自我主权之后，DID（分布式数字身份）可能成为市场监管接纳的关键组成部分，市场主体将能够以目前无法想象的便利体验在不同平台或不同业务场景之间无缝切换。本次上海股权托管交易中心在区域性股权市场探索建设的分布式可互操作的数字身份体系为下一步区块链在区域性股权市场的创新应用奠定了一定的基础，期待DID（分布式数字身份）未来可以在区域性股权市场生态体系建设过程中进一步证明其巨大价值，发挥其重要作用。
