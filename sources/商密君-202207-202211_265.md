# 360政企集团更名360数字安全集团，华南区大幅裁员

9月22日，360集团创始人周鸿祎发布内部信。  

信中，他公布了集团最新的三项战略调整：360政企集团更名360数字安全集团；成立城市产业事业群，直接向集团汇报；继续为中小微企业用户提供免费SaaS服务。

周鸿祎称，数字安全集团以客户价值为导向调整组织与阵型，未来的关键岗位要竞聘上岗。

近期，职业社交平台脉脉上一则“传360人员变动”的话题词条引发热议。根据网友转发的一张群聊截图显示，群人员所在的地区公司安全团队已经完全解散，其他部门也大幅裁员，涉及安全服务、销售、售前、交付等。区域部门后续整体转向城市运营。评论区多位认证为360员工的匿名用户留言证实所涉公司为360，所指业务为政府企业安全服务。

界面新闻进行了多方采访，一名已经离职的360华南区的安服技术人员跟记者确认此一变动属实。他所在的华南区域上半年已经多轮裁员，安全服务业务处于停滞状态。广州安服业务部门几乎全部被裁，包括项目经理与业务领导。深圳仅保留少数几个岗位，大多也都经历了调岗。

另外一名目前在职的360安服业务人员告诉记者，其所在公司的业务调整与人事变动政策，内部了解要等到下个月开始做正式安排。

界面新闻就安服业务变动向360集团求证，公司表示目前没有可以统一对外公布的通知。

今年年初，360集团宣布将聚焦安全，全面转型数字安全。周鸿祎在内部信中称，360以互联网和数字化的基因做安全，“手里拿着中国甚至全球安全行业最好的一副牌”。

根据上月发布的半期财报披露，360集团上半年由盈转亏，净亏5亿元，总营收为48亿元，同比下滑14%。三大业务线只有安全一项实现增长。
