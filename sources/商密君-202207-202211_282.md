# 2022年“金融密码杯”全国密码应用和技术创新大赛挑战赛即将开启

2022年“金融密码杯”全国密码应用和技术创新大赛（以下简称“大赛”）挑战赛将在9月19日（明天）于苏州正式拉开帷幕。

  
  
  

![](../Images/96a35d8dcc39312869050ee53341ec2f.png)

经匿名评审、优中选优，来自全国各大高校、科研院所、密码产业单位和金融从业单位的20支队伍共计100余人入围挑战赛，将展开为期11天的同场竞技。

![](../Images/6a49945c09d24a829ee81f1e335f5103.png "333.png")

本届大赛由中国人民银行和国家密码管理局指导，中国人民银行数字货币研究所、清华大学密码理论与技术研究中心联合主办，中国密码学会、苏州市人民政府支持，苏州市相城区人民政府承办。大赛沿续了首届“金融需求引导，密码技术创新”的办赛宗旨，紧扣金融密码创新前沿，设置“挑战赛”和“创新赛”两条赛道。

![](../Images/8d2c60e978f44213915b2feb5db7cf01.png "22.jpg")

  

其中，挑战赛是在传统CTF（夺旗赛）模式的基础上围绕数字人民币安全、金融科技密码技术应用等实用需求与挑战设置选题，邀请国内知名密码学家、密码应用专家、安全专家、金融科技专家等担任评委，通过“开幕赛”和“正式赛”两个赛段，竞争式选拔出优胜团队。

挑战赛旨在从实际的金融业务场景出发重点考察参赛者实战密码应用分析能力，发掘技术实力扎实、技战法灵活的优秀团队和个人。从赛事规则看，挑战赛将于比赛开启时为选手发放赛题，采用渗透演练、任务挑战的方式，要求选手在规定时间内针对同一套模拟场景中的指定题目内容开展渗透实战；赛程最后，参赛团队将模拟场景发现的问题及渗透过程报告提交评审委员会，由评审专家对团队综合实力进行评审。

![](../Images/5d94f8c52db50b15272564652e5b7d2d.png)

金融是国家重要的核心竞争力，密码技术是实现金融科技安全与可信的核心要素。主办方希望通过大赛的常态化举办，推动国产密码在金融领域的应用与创新，在金融科技创新领域发掘和储备密码人才和密码技术，同时向社会公众传达金融科技基于密码保障安全性的理念。
