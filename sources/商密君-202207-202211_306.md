# 美国安局发布“商业国家安全密码算法套件2.0”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NTM4OTQ5Mg==&mid=2247581092&idx=4&sn=5bc129271810093abf020bddef38d2d4&chksm=ec57adffdb2024e9e2c70ab823cdaa2afe607c502842910e08a5cf10a66f52102c90df682efa&scene=126&sessionid=1681312985#rd](http://mp.weixin.qq.com/s?__biz=MzI5NTM4OTQ5Mg==&mid=2247581092&idx=4&sn=5bc129271810093abf020bddef38d2d4&chksm=ec57adffdb2024e9e2c70ab823cdaa2afe607c502842910e08a5cf10a66f52102c90df682efa&scene=126&sessionid=1681312985#rd)

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_1381560996854185984](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_1381560996854185984)美国国安局（NSA）在周三发布了旨在帮助美国政府及其他运维或研制国家安全系统（National Security Systems）的利益相关方应对量子计算时代密码安全挑战的“商业国家安全密码算法套件2.0”（Commercial National Security Algorithm Suite 2.0/CNSA 2.0）方案（请参考原文链接），这个继承自2016年10公布之原“商业国家安全密码算法套件”方案（含AES、椭圆曲线、DH、RSA等算法）的新方案，纳入了由美国国家标准与技术学会（NIST）已审批及标准化的若干新加密算法，将助力美国政府、军方及情报界等相关方达成拜登政府今年5月出台的《关于推动美国在量子计算领域的领导地位并应对密码系统所面临之相关风险的国家安全备忘录》（NSM-10）中确定的“在2035年前完成可抵抗量子计算机破解的全面安防升级”目标。在各大经济体加速推进量子计算机研制的背景下，可抵抗量子计算机破解的后量子时代密码系统越发成为各大国推动自身网络安全建设的重点考虑。美国国家标准与技术学会在今年7月发布了CRYSTALS-Kyber，CRYSTALS-Dilithium，Falcon和SPHINCS+四种有机会入选其后量子时代密码标准的加密算法，以为美国公共和私营部门规划和建设后量子时代密码系统提供参考。美国安局网络安全部门负责人罗布.乔斯（Rob Joyce）指出，将密码系统升级至可抵抗量子计算机破解的水平，需要美国政府、国家安全系统所有者及运营者、相关产业的通力合作；他希望“商业国家安全密码算法套件2.0”方案的发布，能帮助各相关方更高效地就向后量子时代密码系统迁移开展规划和建设。“商业国家安全密码算法套件2.0”方案推荐：① 软件及固件签名使用国家标准与技术学会SP 800-208文件中确定的Leighton-Micali Signature（LMS）和Xtended Merkle Signature Scheme（XMSS）密码算法；② 对称密钥密码算法使用美国联邦信息处理标准（FIPS）PUB 197和PUB 180-4确定的AES（256位密钥）、SHA（384或512位密钥）算法；③ 通用抗量子计算机破解的公钥密码算法推荐新的CRYSTALS-Kyber和CRYSTALS-Dilithium算法；美国安局提出：软件及固件签名的算法升级即日起开始，到2025年实现所有新软件和新固件使用“商业国家安全密码算法套件2.0”推荐的密码算法进行签名，到2030年所有软件和固件均使用新标准密码算法进行签名；Web浏览器/服务器和云服务应在2025年前开始支持“商业国家安全密码算法套件2.0”推荐的密码算法，至2030年全面使用新标准密码算法；虚拟私有网络、路由器等传统网络设备应在2026年前开始支持“商业国家安全密码算法套件2.0”推荐的密码算法，至2030年全面使用新标准密码算法；操作系统应在2027年前开始支持“商业国家安全密码算法套件2.0”推荐的密码算法，至2033年全面使用新标准密码算法；其他定制应用及老旧系统应在2033年前完成升级或退出使用。
