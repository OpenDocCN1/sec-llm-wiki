# 记者观察：网络安全人才供不应求 今年市场端有可喜变化

据中央广播电视总台经济之声《天下财经》报道，网络安全人才培养和供给的话题在8月15日举行的网络空间安全高峰论坛上受到关注。从网络安全人才市场端的情况来看，今年有一些可喜变化。

根据工业和信息化部人才交流中心等发布的《网络安全产业人才发展报告》显示，**我国网络安全专业人才缺口在140万以上，而每年网络安全相关专业的高校毕业生只有2万余人。**我国网络安全人才存在着供不应求的情况。除了人才供给总量较小，**现有网络安全人才队伍“塔尖”较小也是一个现实问题。**中国工程院院士黄殿中在网络空间安全高峰论坛上表示，首先要努力锻造一批网络安全战略科学家，为国家网络安全发展把好方向、带好队伍；同时要大力培养具有原始创新能力、学科带头人能力的网络安全领军人才；此外要梯队化培养青年网络安全专业人才，不断输送维护网络安全的生力军。尽管网络安全人才的培养和供给有待跟上，但从今年人才市场的情况来看，仍然有一些可喜变化。根据奇安信日前发布的《网络安全人才市场状况研究报告》显示**，2022年，网络安全人才在北京地区的求职占比已从2020年的57.8%降至29.8%，**这说明其他地区的网络安全人才就业环境在改善，市场需求在提升，相关专业人士不需要在北京扎堆就业。随着全国各地加强对网络安全人才的培养，相关人才会不断涌现。

相关负责人李桐说：“**近几年，市场对于网络安全人才的需求是持续升温的**。对于一般的政企机构，他们并不具备对网络安全人才的在职培养能力，他们需要的是具有一定技能、能迅速上手的专业人才。但对于专业安全企业来说，其则可以借助自身优势，培养更多实战型的高精尖网络安全人才。”
