# 工业和信息化部密码应用研究中心发布“首届全国商用密码应用优秀案例”及《全国商用密码应用优秀案例汇编》

为深入贯彻落实《密码法》，加快推进商用密码规范应用，在工业和信息化部和国家密码管理局的指导下，工业和信息化部密码应用研究中心（以下简称“中心”）组织开展了首届全国商用密码应用优秀案例征集活动。  

  

本次活动征集到涵盖了工业互联网、车联网、电子政务、信息通信等重点行业领域案例共计102项。为实现本次活动的公正、严谨，中心组织开展两轮案例评审。其中，第一轮重点针对申报材料的专业性、编写质量、与密码应用的相关性等方面开展评价，共选出25项案例进入次轮评审。第二轮评审，成立了以中国科学院院士冯登国为组长、以密码行业产、学、研、政等领域专家为评委的评审组，通过集中评审，现场质询、材料查阅等环节，最终评选出15项优秀案例，名单如下。

同时，为持续发挥案例征集活动产业促进效用，进一步凝聚智慧、形成合力，中心统筹安排相关单位对案例内容进行提炼总结，编制形成《全国商用密码应用优秀案例汇编》（以下简称“《汇编》”）。《汇编》聚焦于商用密码新业态，详细介绍了商用密码在工业互联网、车联网、信息通信等重要行业领域的的应用现状、风险挑战以及应对策略，可为商用密码厂商、商用密码检测机构以及广大信息系统运营者的建设应用提供思路。  
![](../Images/5cfd0b9e986024a691bc6d30242afd5e.png)![](../Images/0ab8eff568e0e8b03242431db4946b97.png)  
后续，中心将以案例征集活动为契机，不断丰富活动内容、完善开展方式，从标准、测评、研发等角度促进应用技术创新与实践推广，助力商用密码产业高质量发展。
