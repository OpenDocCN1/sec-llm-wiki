# 银行卡检测中心网络安全等级测评与检测问题被要求整改6个月

**关于银行卡检测中心处理结果的公告**  
近日，中关村信息安全测评联盟（以下简称“联盟”）组织专家对银行卡检测中心进行了飞行检查，发现该单位存在不符合《网络安全等级测评与检测评估机构自律规范》有关要求的情况。根据飞行检查中发现的问题及严重程度，依据《网络安全等级测评与检测评估机构自律规范》第二十九条规定，经联盟理事会研究决定：  
银行卡检测中心开展为期六个月的整改，整改期自2022年12月2日至2023年6月2日。  
特此公告。  
中关村信息安全测评联盟2022年12月2日  
  
据了解，此前中关村信息安全测评联盟发布的多个处理结果显示：  
云南云盾信息安全测评有限公司开展为期六个月的整改，整改期自2022年11月24日至2023年5月24日。  
北京市电子产品质量检测中心开展为期三个月的整改，整改期自2022年11月24日至2023年2月24日。  
航天开元科技有限公司开展为期三个月的整改，整改期自2022年10月27日-2023年1月27日。  
江苏君立华域安全测评有限公司取消联盟会员资格。  
中国信息通信研究院开展为期一年的整改，整改期自2022年9月30日-2023年9月30日。  
福建省森阳网络科技有限公司开展为期六个月的整改，整改期自2022年9月30日-2023年3月30日。  
道普信息技术有限公司开展为期三个月的整改，整改期自2022年9月30日-2022年12月30日。
