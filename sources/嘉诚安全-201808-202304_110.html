近日，安全研究人员发现一种名为 BPFdoor 的后门恶意软件已开始对 Linux 和 Solaris 系统进行远程访问。


BPFdoor 是一个 Linux/Unix 后门，它允许攻击者远程连接到 Linux shell 以获得对受感染设备的完全访问权限。该恶意软件不需要打开端口，无法被防火墙阻止，并且可以响应来自网络上任何 IP 地址的命令，使其成为企业间谍活动和持续攻击的理想工具。















解析“魔术”数据包


BPFdoor 是一个被动后门恶意软件，这意味着它可以在一个或多个端口上侦听来自一个或多个主机的传入数据包，攻击者可以使用这些端口将命令远程发送到受感染的网络。该恶意软件使用 Berkeley Packet Filter（后门名称中的BPF），它在网络层接口上工作，能够查看所有网络流量并将发送数据包发送到任何目的地。


由于BPF定位在如此低的级别，所以不遵守任何防火墙规则。它有适用于 Linux 和 Solaris SPARC 系统的版本，但它也可以移植到 BSD 中。


安全研究员 Kevin Beaumont 在 BPFdoor 上发表了 一篇博文称，操作员使用“魔法”密码来控制植入的行为。BPFdoor 仅解析ICMP、UDP 和 TCP 数据包，检查它们的特定数据值，以及后两种数据包的密码。它的突出之处在于它可以监视任何端口的魔术包，即使这些端口被其他合法服务使用，例如网络服务器、FTP 或 SSH。















绕过本地防火墙


安全研究人员表示，更改防火墙规则特别重要，因为它允许攻击者通过防火墙无法标记为可疑的流量与后门通信。


当受感染的主机收到一个特殊的 BPFdoor 数据包时，恶意软件将生成一个新实例并更改本地iptables规则，以从请求主机重定向到 shell 端口。例如，植入程序可以使用 TCP 端口 443（加密网络）将来自攻击者的所有流量重定向到外部。在外部，流量看起来像 TLS/SSL 流量，但实际上攻击者正在与系统上的远程根 shell 交互。


Rowland 表示，对于本地 shell，恶意软件会修改“iptables”配置，将来自攻击者的所有流量通过合法端口重定向到恶意软件中定义的端口范围。















命令和检测


安全安全人员说，攻击者定期更新 BPFdoor，用不同的命令、进程或文件名称改进每个版本。


例如，较新的植入程序变体从使用命令关键字切换到 MD5 哈希，可能是为了避免微不足道的检测。


目前在Virus Total扫描平台上检测到的BPFdoor至少有21个版本，最早的版本是2018年8月提交的。
