漏洞背景  
  

2022年3月9日，嘉诚安全监测到Microsoft发布了3月份的安全更新公告，共发布了71个漏洞的补丁，影响众多组件，如Azure Data Explorer、Kestrel Web Server、Defender for IoT、Microsoft Office和Office组件、SQL Server、DNS Server、Windows和Windows组件等。其中共有3个被微软官方标记为“Critical”，68个被标记为“Important”。

  

鉴于漏洞危害较大，嘉诚安全提醒广大Microsoft用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。

漏洞详情  
  

### **经研判以下漏洞影响较大**  

**CVE-2022-21990**

远程桌面客户端远程代码执行漏洞，该漏洞在远程桌面连接的情况下，当受害者使用易受攻击的远程桌面客户端连接到攻击服务器时，具有控制远程桌面服务器的攻击者可能会触发RDP客户端计算机上的远程代码执行（RCE）。

  

**CVE-2022-23277**

Microsoft Exchange Server 远程代码执行漏洞，利用此漏洞的攻击者可以针对服务器帐户进行任意或远程代码执行。作为经过身份验证的用户，攻击者可以尝试通过网络调用在服务器帐户的上下文中触发恶意代码。

**CVE-2022-24508**

经过身份验证的攻击者才可以使用此漏洞针对服务器帐户进行任意或远程代码执行。该漏洞存在于 Windows 10 version 2004 中添加的新功能中，并且存在于较新的受支持 Windows 版本中。旧版本的 Windows 不受影响。建议存在该漏洞的企业在边界防火墙处阻止 TCP 端口 445或遵循 Microsoft 指南，以防 SMB 流量形成横向连接进入或离开网络。

  

**CVE-2022-24507**

Windows Ancillary Function Driver for WinSock 存在权限提升漏洞，该漏洞允许本地用户提升系统的权限。该漏洞是由于应用程序没有正确地对 WinSock 的 Windows 辅助功能驱动程序施加安全限制而造成的，经过身份验证的攻击者可在目标系统上以提升的权限执行任意代码。

  

**CVE-2022-23299**

Windows PDEV 存在权限提升漏洞，经过身份验证的攻击者可通过在目标系统上执行特制程序来利用此漏洞，成功利用此漏洞可在目标系统上以 SYSTEM 权限执行任意代码。

  

**CVE-2022-23285**

Remote Desktop Client 在处理内存中的对象时，存在远程代码执行漏洞。要利用此漏洞，攻击者需要控制服务器，然后诱导用户连接到该服务器。攻击者可通过多种方式欺骗用户连接，如利用社会工程学、DNS中毒或使用中间人攻击（MITM）。攻击者还可以破坏合法服务器，在其上托管恶意代码，并等待用户连接。成功利用此漏洞的攻击者可在目标系统上执行任意代码。

  

**CVE-2022-24509**

Microsoft Office Visio 中存在任意代码执行漏洞，攻击者利用该漏洞需要交互，最终可导致代码执行。

  

**CVE-2022-23286**

Windows Cloud Files Mini Filter Driver 存在权限提升漏洞，成功利用此漏洞需要攻击者赢得竞争条件。经过身份验证的攻击者可利用此漏洞以提升的权限在目标系统上执行任意代码。

  

**CVE-2022-23253**

Point-to-point Tunneling Protocol（点对点隧道协议，PPTP）使得用户可以在非安全的通信通道中建立安全的远程连接。经过身份验证的远程攻击者可通过向目标PPTP服务发送特制请求来利用此漏洞，从而导致拒绝服务。
