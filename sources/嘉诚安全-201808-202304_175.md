漏洞背景  
  

2022年3月2日，嘉诚安全监测到CVE官方发布了Spring Cloud Gateway远程代码执行漏洞的安全风险通告，漏洞编号为：CVE-2022-22947。

  

Spring Cloud Gateway旨在为微服务架构提供一种简单而有效的统一的API路由管理方式。Spring Cloud Gateway作为Spring Cloud生态系统中的网关，目标是替代Netflix ZUUL，其不仅提供统一的路由方式，并且基于Filter链的方式提供了网关基本的功能，例如：安全，监控/埋点，和限流等。

  

鉴于漏洞危害较大，嘉诚安全提醒相关用户尽快更新版本，避免引发漏洞相关的网络安全事件。

漏洞详情  
  

使用Spring Cloud Gateway的应用程序的Actuator端点在公开的情况下容易受到代码注入的攻击，攻击者可以构造恶意请求，在远程主机上执行任意代码。目前已在野利用。

  
危害影响  
  

![](../Images/5caf9e18bec00ef002179d940ce38dd6.png)

  
修复建议  
  

**1.通用修复建议：**

根据影响版本中的信息，排查并升级到安全版本：

  

3.1.x用户应升级到3.1.1+

3.0.x用户应升级到3.0.7+

  

**2\. 缓解方法：**

如果不需要Actuator端点，可以通过

management.endpoint.gateway.enable：false配置将其禁用

如果需要Actuator端点，则应使用Spring Security对其进行保护
