这种新型攻击模式首先是由综合网络安全提供商安博士的ASEC研究人员发现的，黑客在易受攻击的微软SQL服务器上部署Cobalt Strike信标，以实现对目标网络的初始访问，并部署恶意负载。















◆ 使用 Cobalt Strike 定位 MS-SQL 

攻击从威胁参与者扫描具有开放 TCP 端口 1433 的服务器开始，这些服务器可能是面向公众的 MS-SQL 服务器。然后攻击者执行暴力破解和字典攻击来破解密码。为了使攻击能够使用任何一种方法，目标密码必须是弱密码。


一旦攻击者获得对管理员帐户的访问权限并登录服务器，ASEC 研究人员就会看到他们丢弃了 Lemon Duck、KingMiner 和 Vollgar 等硬币矿工。此外，威胁参与者使用 Cobalt Strike 对服务器进行后门，以建立持久性并执行横向移动。 


Cobalt Strike 通过命令 shell 进程（cmd.exe 和 powershell.exe）下载到受感染的 MS-SQL 上，并在 MSBuild.exe 中注入和执行以逃避检测。 



执行后，信标会被注入到合法的 Windows wwanmm.dll 进程中，并等待攻击者的命令，同时隐藏在系统库文件中。


报告解释道：“由于接收攻击者命令并执行恶意行为的信标不存在于可疑内存区域，而是在正常模块 wwanmm.dll 中运行，它可以绕过基于内存的检测 ”。


下载 Cobalt Strike (ASEC) 的进程 


Cobalt Strike 是一种商业渗透测试（攻击性安全）工具，被网络犯罪分子广泛滥用，他们发现其强大的功能对他们的恶意操作特别有用。 


它现在被 Squirrelwaffle、Emotet、恶意软件运营商、Linux 目标团体、老练的对手等使用，并且通常被勒索软件团伙在进行攻击时使用。














威胁攻击者如此滥用它的原因在于其丰富的功能，其中包括以下内容：


  • 命令执行

  • 键盘记录

  • 文件操作

  • SOCKS 代理提权

  • Mimikatz (凭据窃取)

  • 端口扫描 


此外，称为“信标”的 Cobalt Strike 代理是无文件的 shellcode，因此被安全工具检测到的机会降低了，尤其是在管理不善的系统中。 


AhnLab 的数据显示，所有支持最近攻击波的下载 URL 和 C2 服务器 URL 都指向同一个攻击者。 


为了保护您的 MS-SQL 服务器免受此类攻击，请使用强大的管理员密码，将服务器置于防火墙后面，记录所有内容并监控可疑操作，应用可用的安全更新，并使用数据访问控制器检查和执行策略 每笔交易。
