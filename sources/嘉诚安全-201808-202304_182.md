FortiGuard Labs 刚刚发布了最新的半年度 FortiGuard Labs 全球威胁态势报告，它表明网络犯罪分子正在以比以往更快的速度发起攻击。他们继续利用混合型员工和 IT 不断扩大的攻击面，并使用先进的持续性网络犯罪策略，这些策略比过去更具破坏性且更难以预测。 

  
  
  
  
  
  
  
  
  
  
  
  
  

回顾威胁报告中的四个重要内容

  

**1\. Log4j 展示了漏洞利用的速度 **

  

去年 12 月，Apache Log4j 基于 Java 的日志框架中披露的一个严重漏洞几乎影响了所有使用 Java 应用程序的环境。该漏洞非常容易利用，并为攻击者提供了一种完全控制易受攻击系统的方法。几天之内，Log4j 成为下半年最流行的 IPS 检测。在最初披露后不久，又发现了另外两个漏洞，迫使组织在一周内更新其 Log4j 部署 3 次。此外，Log4j 的活动量几乎是众所周知的2021年早些时候爆发的 ProxyLogon 的50倍。虽然在 Log4j 漏洞被发现后的一个月内，没有关于涉及重大危害的报告，但是攻击者很可能利用这个漏洞破坏了网络，现在只是在等待合适的时机发动攻击。

  
  
  
  
  
  
  
  
  
  
  
  
  

**2\. 攻击者迅速瞄准新载体 - Linux **

  

不久前，Linux 是 IT 中受攻击最少的平台之一，尽管它运行许多网络的后端系统，以及用于物联网设备和关键任务应用程序的基于容器的解决方案。然而，威胁参与者正在扩展他们的工具集并迅速增加他们对基于 Linux 的恶意软件的使用。2021 年期间，针对 Linux 的二进制格式的可执行和可链接格式 (ELF) 文件的恶意软件检测翻了一番。此外，Fortinet 创建所需的新的反病毒检测数量翻了两番。变种和传播的增长表明 Linux 恶意软件正在增加。随着微软积极将 Windows Subsystem for Linux (WSL) 集成到 Windows 11 中，恶意软件不可避免地会随之而来。

  
  
  
  
  
  
  
  
  
  
  
  
  

**3\. 勒索软件攻击持续不断 **

  

勒索软件的复杂性、侵略性和影响力在 2021 年下半年继续无情地继续存在。威胁行为者继续使用各种新的和以前未见的勒索软件毒株攻击组织。Kaseya VSA 远程监控和管理技术攻击因其广泛的影响而备受关注。该事件再次证明了软件供应链攻击的一次破坏多次攻击的有效性。另一个令人不安的趋势是使用正在积极更新、增强和重用的旧勒索软件。例如，BlackMatter 曾多次用于针对美国基础设施的攻击，它被认为是对DarkSide的品牌重塑，后者是 Colonial Pipeline 攻击中使用的勒索软件。借助勒索软件即服务的企业模式下，多个威胁参与者可以更容易地传播恶意软件。 

  
  
  
  
  
  
  
  
  
  
  
  
  

**4\. 更深入地了解攻击技术可以更快地阻止犯罪分子**

  

为了观察各种攻击的恶意结果，FortiGuard 实验室通过引爆收集的恶意软件样本来分析检测到的恶意软件的功能。更早地阻止对手比以往任何时候都更加重要，并且通过专注于少数已识别的技术，在某些情况下，组织可以有效地关闭恶意软件的攻击渠道。

**更智能的解决方案，提供更好的保护 **

  

这些攻击只是安全人员在 2021 年下半年看到的众多攻击中的一部分。随着攻击速度越来越快，组织需要从单点产品的集合转向旨在协同工作的集成解决方案。为了抵御不断发展的攻击技术，组织需要更智能的解决方案，能够获取实时威胁情报、检测威胁模式和指纹、关联大量数据以检测异常情况，并自动启动协调响应。网络安全网状平台的集中管理和广泛可见性有助于确保一致地执行策略，及时交付配置和更新，并在检测到可疑活动时启动协调的威胁响应。
