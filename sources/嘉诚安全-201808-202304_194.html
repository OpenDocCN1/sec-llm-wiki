漏洞背景


2022年2月14日，嘉诚安全监测到CVE官方发布了Apache APISIX batch-requests 插件身份验证绕过漏洞的安全风险通告，漏洞编号为CVE-2022-24112。


Apache APISIX 是一个动态、实时、高性能的 API 网关，基于 Nginx 网络库和 etcd 实现， 提供负载均衡、动态上游、灰度发布、服务熔断、身份认证、可观测性等丰富的流量管理功能。


鉴于漏洞危害较大，嘉诚安全提醒相关用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。

漏洞详情


启用了 Apache APISIX  batch-requests 插件的 Apache APISIX 存在重写 X-REAL-IP 标头的风险，攻击者通过batch-requests 插件绕过 Apache APISIX 数据平面的 IP 限制（例如绕过IP黑白名单限制）。如果用户使用默认的 Apache APISIX 配置（启用管理 API，使用默认管理密钥且未分配额外的管理端口），攻击者可以通过batch-requests 插件调用管理 API。


危害影响



修复建议


通用修复建议：

1. 在 `conf/config.yaml` 中显式配置启用的插件，确保 `batch-requests` 被禁用。（或者注释掉 `conf/config-default.yaml` 中的 `batch-requests`）


2.升级到 2.10.4 或 2.12.1
