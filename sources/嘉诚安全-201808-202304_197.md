漏洞背景  
  

2022年2月8日，嘉诚安全监测到CVE官方发布了GitLab CE/EE 任意 POST 请求执行漏洞的安全风险通告，漏洞编号为CVE-2022-0427。

  

GitLab是由GitLabInc.开发，使用MIT许可证的基于网络的Git仓库管理工具，且具有wiki和issue跟踪功能。使用Git作为代码管理工具，并在此基础上搭建起来的web服务。

  

鉴于漏洞危害较大，嘉诚安全提醒相关用户尽快排查并升级到安全版本，避免引发漏洞相关的网络安全事件。

漏洞详情  
  

自 14.5 版以来，所有版本的 GitLab CE/EE 中的 Jupyter 笔记本中缺少对 HTML 属性的清理，这使得攻击者可以代表用户执行任意 HTTP POST 请求，从而导致潜在的帐户接管。
