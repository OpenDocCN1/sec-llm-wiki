漏洞背景  
  

2022年2月6日，嘉诚安全监测到CVE官方发布了JPressProjects jpress远程代码执行漏洞的安全风险通告，漏洞编号为：CVE-2022-23330。

  

JPress 是一个类似 WordPress 的开源软件，使用 Java 语言开发，已有超过10万+网站使用 JPress 搭建。

  

鉴于漏洞危害较大，嘉诚安全提醒相关用户尽快排查并升级到安全版本，避免引发漏洞相关的网络安全事件。

漏洞详情  
  

jpress v4.2.0的HelloWorldAddonController.java 中的远程代码执行 (RCE) 漏洞允许攻击者通过特制的 JAR 包执行任意代码。
