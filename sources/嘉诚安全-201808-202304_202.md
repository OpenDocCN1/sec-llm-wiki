漏洞背景  
  

2022年2月3日，嘉诚安全监测到CVE官方发布了Django 拒绝服务漏洞的安全风险通告，漏洞编号为：CVE-2022-23833。

  

Django 是一个开放源代码的 Web 应用框架，由 Python 写成。

  

鉴于漏洞危害较大，嘉诚安全提醒相关用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。

漏洞详情  
  

Django 在文件上传表单中存在拒绝服务漏洞，在解析文件时，将某些输入传递给多部分表单可能会导致无限循环。
