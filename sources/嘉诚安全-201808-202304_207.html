漏洞背景


2022年1月27日，嘉诚安全监测到CVE官方发布了Apple WebKit 信息泄露漏洞安全风险通告，漏洞编号为：CVE-2022-22594。


AppleWebKit是苹果公司开发的浏览器核心，WebKit 所包含的WebCore排版引擎和 JSCore 引擎，要用于Safari，Dashboard，Mail 和其他一些Mac OS X 程序。


鉴于漏洞危害较大，嘉诚安全提醒相关用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。

漏洞详情


在 WebKit 存储中的 IndexDB API 存在跨域问题，远程攻击者可以利用此漏洞诱骗受害者访问特制网站，从而访问 WebKit本地存储的敏感信息。


危害影响


影响版本：


Apple iOS < 15.3

iPadOS < 15.3


修复建议


通用修复建议：


根据影响版本中的信息，用户请及时更新到安全版本。
