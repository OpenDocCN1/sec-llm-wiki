据研究人员称，一个伊朗国家资助的威胁组织正在使用消息平台 Slack 上的免费工作空间在一家亚洲航空公司的系统中部署一个后门。IBM Security X-Force 的一份报告称，被称为 Aclip 的后门可能使黑客能够访问航空公司的乘客预订数据。



报告称，后门将受害系统上的系统信息、文件和数据截图发送到其命令和控制服务器，与收到的命令相对应。


目前还不清楚攻击者是否能够成功地从受害者的环境中窃取数据，尽管在黑客的命令和控制 (C2) 服务器上发现的文件表明他们可能已经访问了预订数据。


黑客的重点是监视，因为在黑客的 C2 服务器上只能找到名称中带有“保留管理”的文件。它没有透露泄露的存档文件的内容。

Slack 关闭滥用的工作区



但该公司告诉研究人员，它已经调查并立即关闭了所报告的 Slack Workspaces，因为它违反了我们的服务条款。 我们确认 Slack 没有在此事件中以任何方式受到损害，并且没有 Slack 客户数据暴露或面临风险。我们致力于防止滥用我们的平台，并对违反我们服务条款的任何人采取行动 。


交付途径


报告称，使用合法的、常用的平台（如 Slack）进行命令和控制，让攻击者有机会伪装他们的恶意软件流量，并使安全分析师无法察觉。


该策略已在多个实例和多个消息传递平台中部署，特别是自 COVID-19 爆发以来。


研究人员说，虽然 Slack 以前曾被用来传送恶意软件，但在最新的案例中，该平台的 API 被用来传送 Aclip 后门。


Aclip后门

该后门的名称来自名为“aclip.bat”的 Windows 批处理脚本。报告称，它通过添加注册表项来建立持久性，并在受感染设备的系统启动时自动启动。在成功安装后，后门收集基本系统信息——包括主机名、用户名和外部 IP 地址——并使用 Base64 加密数据并将其泄露给黑客。它补充说，执行进一步的命令以将 Aclip 连接到演员控制的 Slack 工作区上的不同通道。

研究人员说，总而言之，有三个 Slack 通道：基本的泄露信息被发送到第一个，第二个通道接收下一步执行的命令，使用第三个通道上传API文件。


Aclip 还具有截图功能，该功能使用 PowerShell 的图形库，并保存到 %TEMP% 目录直到被泄露。据报道，在图像上传到 C2 后，它们将从库中删除。 


研究人员的分析还发现了两个自定义工具——后门“Win32Drv.exe”和网络外壳“OutlookTR.aspx”——证实了研究人员对 MuddyWater 参与的怀疑。他们说，该组织在早期的活动中使用了这些工具。 

提高防御


由于涉及的流量大，基于协作工具防御威胁很困难。因此，研究人员表示，针对它建立防御机制更加困难。该报告建议加强 PowerShell 安全性，因为该脚本首先允许攻击变得具有侵入性。对策包括： 


● 将 PowerShell 更新到最新的稳定版本并禁用早期版本

● 通过限制能够运行某些命令和功能的用户来控制对 PowerShell 的访问

● 监控PowerShell日志，包括模块日志记录

● 通过禁用或限制 Windows 远程管理服务来防止使用 PowerShell 进行远程执行

● 创建并使用 YARA 规则来检测恶意 PowerShell 脚本


除此之外，建议实施一项重点突出且持续不断的教育计划，以降低员工对网络钓鱼攻击的敏感性，以及网络分段和实施零信任策略以阻止攻击者的横向移动。他表示，应用纵深防御和默认拒绝原则将增加违规所需的工作量。


保护软件供应链至关重要。对于构建软件的组织而言，这意味着将安全性纳入软件开发的每个阶段，使用自动化安全测试工具来定位和消除漏洞和管理第三方和开源组件进入应用程序并了解它们来自何处以及它们具有哪些漏洞。


软件的购买者需要知道构建者已经使用了安全的开发生命周期，并且需要查看测试和工件的证据，例如软件材料清单或 SBOM。你不会在不知道食物成分和来源的情况下购买食物；同样的原则适用于购买软件。
