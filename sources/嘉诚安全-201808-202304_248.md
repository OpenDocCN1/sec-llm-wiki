漏洞背景  
  

2021年12月16日，嘉诚安全监测发现 Microsoft Windows Active Directory 域服务权限提升漏洞安全风险通告，漏洞细节与POC已在互联网公开，漏洞编号为：CVE-2021-42287、CVE-2021-42278。

  

Microsoft Active Directory 是面向Windows Standard Server、Windows Enterprise Server以及 Windows Datacenter Server的目录服务，是Windows 平台的核心组件。Microsoft Active Directory存储了有关网络对象的信息，并且让管理员和用户能够轻松地查找和使用这些信息。

  

鉴于漏洞危害较大，嘉诚安全提醒相关用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。

漏洞详情  
  

该漏洞是由于Active Directory 域服务没有进行适当的安全限制，导致可绕过安全限制进行权限提升。

修复建议  
  

**通用修复建议：**
