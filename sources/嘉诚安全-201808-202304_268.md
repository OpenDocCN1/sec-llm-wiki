昨日，英国交通部 (DfT) 的一个网站被发现提供色情服务。

  

在大多数情况下，事故背后特定的 DfT 子域为公众和部门的业务计划提供重要的 DfT 统计数据。 

**非常英式的感恩节**  
  

据 BleepingComputer 证实，英国 DfT 的 charts.dft.gov.uk 网站昨天被发现提供色情服务。

  

过去，Charts 子域提供了各种 DfT 服务的商业计划文件和重要统计数据，例如公共交通利用率、道路可达时间和驾驶考试的数字。

  

尽管该站点不再可访问，但在几个小时前，访问

 charts.dft.gov.uk **为一些不正常的流量铺平了道路：**

该事故首先由 The Crow 发现，该公司还观察到整个 dft.gov.uk 域本身都被重定向到 WordPress 插件页面，而该部门似乎正在调查该问题。

  

在测试中，BleepingComputer 观察到官方 dft.gov.uk 网站导致一个受密码保护的 WordPress 页面位于：eu-hauliers.dft.gov.uk。 

  

![](../Images/577de0b61fa9f25a0658414989ace1b4.png)

**整个 dft.gov.uk 重定向到了一个受密码保护的 WordPress 页面**

  
**不稳定的 DNS**  
  

尽管 Charts 迷你站点提供色情内容的确切原因尚不清楚，但该子域似乎确实有一个指向 Amazon S3 实例的 CNAME DNS 记录。

  

违规 (NSFW) 实例仍在 charts.dft.gov.uk.s3-website-eu-west-1.amazonaws.com，显示非法内容。。

  

尚不清楚的是，这是否仅仅是域劫持的情况——即 Charts 站点指向的一个未实名的 AWS S3 实例，被威胁行为者认领并用于提供成人内容，或者攻击者是否获得了足够的访问权限到 DfT 的注册商系统，并更改了 charts.dft.gov.uk 的 DNS 条目。

  

第二种情况更具挑战性，并且会引发一些关于 DfT 数字基础设施安全性的严重问题。

  

这也不是第一次发现政府网站提供露骨内容。

  

今年 9 月，在攻击者利用多个政府网站使用的 Laserfiche Forms 软件产品中的漏洞后，美国政府网站收到了伟哥广告和成人内容的垃圾邮件。

  

7 月，在 vid.me 域名被第三方收购后，包括《华盛顿邮报》和《赫芬顿邮报》在内的主要新闻网站的访问者看到新闻故事中的嵌入视频被色情内容取代。
