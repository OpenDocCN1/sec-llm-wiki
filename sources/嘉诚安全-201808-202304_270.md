# 【资讯】新型隐蔽的JavaScript恶意程序会用RAT病毒感染Windows电脑

一个名为 RATDispenser 的新型隐蔽 JavaScript 加载程序正被用于在网络钓鱼攻击中感染具有各种远程访问木马 （RAT） 的设备。

  

这款新型的加载程序很快与至少8个恶意软件家族建立了分发合作伙伴关系，所有这些恶意软件家族都旨在窃取信息并让参与者控制目标设备。

  

在 HP Threat Research 团队分析的 94% 的案例中，RATDispenser 不与参与者控制的服务器通信，仅用作第一阶段恶意软件投放器。

  

与使用Microsoft Office文档投放有效负载的趋势相反，该加载程序使用JavaScript附件，HP发现其检测率较低。

**传染链**  
  

感染始于一封包含以“.TXT.js”双扩展名命名的恶意 JavaScript 附件的网络钓鱼电子邮件。

  

![](../Images/499f22eaa8fa6f285089cb213b9b2783.png)

**带有 JS 附件的钓鱼邮件**  

  

此文本文件经过重度混淆以绕过安全软件的检测，并在双击并启动文件时进行解码。

  

启动后，加载程序会将 VBScript 文件写入 %TEMP% 文件夹，然后执行该文件以下载恶意软件 （RAT） 有效负载。

  

![](../Images/4295882077c8a2ddc90194779cccbcbb.png)

**消除了命令行参数的混淆**

  

这些混淆层可帮助恶意软件在 89% 的时间内根据 VirusTotal 扫描结果逃避检测。

  

尽管 JavaScript 是一种比微软 Office 文档更少见的恶意软件格式，但在许多情况下，它更容易被检测到。在我们的155个鼠药样本中，有77个可以在 VirusTotal 上找到，这使我们能够分析它们的检出率。

  

使用每个样本最早的扫描结果，平均只有11% 的现有反病毒引擎检测到了RATDispenser 样本。

  

但是，如果组织启用了对可执行附件（如.js、.exe、.bat.com文件）的阻止，则电子邮件网关将检测加载程序。

  

阻止感染链展开的另一种方法是更改 JS 文件的默认文件处理程序，仅允许运行经过数字签名的脚本，或禁用 WSH（Windows 脚本主机）。

  
**丢弃恶意软件**  
  

在过去的三个月中，惠普的研究人员能够从RATDispenser中检索到八种不同的恶意软件有效载荷。

  

已识别的恶意软件系列是

STRRAT，WSHRAT，AdWind，Formbook，Remcos，Panda Stealer，GuLoader和Ratty。

  

在分析的155个样本中的10个样本中，加载程序建立了C2通信来获取第二阶段恶意软件，因此虽然这种情况很少见，但功能仍然存在。

  

![](../Images/19fb5712c9d5507c3296cbb725ac4814.png)

**恶意软件加载过程来源**

  

在81%的恶意软件投放案例中，RATDispenser分发STRRAT和WSHRAT（又名"Houdini"），这两个强大的凭据窃取者和键盘记录器。

  

Panda Stealer 和 Formbook是仅有的两个总是被下载而不是被投放的有效载荷。

  

总体而言，RATDispenser似乎可以适应新旧恶意软件的分布，为拥有各种技能水平的威胁行为者提供多功能加载程序。
