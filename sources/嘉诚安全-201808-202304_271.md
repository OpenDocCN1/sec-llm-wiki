# 【资讯】一个在网上易受攻击的蜜罐可能在24小时内被攻破

研究人员部署了多个易受攻击的系统实例，**发现320个蜜罐中有80% 在24小时内被攻破。**  

  

Palo Alto Networks的研究人员部署了一个包含320个节点的蜜罐基础设施，以分析三个参与者如何在公共云中锁定暴露的服务。

  

该公司在2021年7月至2021年8月间建立了蜜罐，**以分析针对他们的攻击的时间、频率和来源。**

  

实例包括公开远程桌面协议(RDP)、安全 shell 协议(SSH)、服务器消息块(SMB)和 Postgres 数据库的系统。专家们发现，320个蜜罐中有80% 在24小时内被入侵，所有的蜜罐都在一周内被入侵。

  

**以下是专家们分享的一些调查结果:**

  

● 受攻击最严重的应用程序是 SSH。

● 受攻击最严重的 SSH 蜜罐在一天内被攻破169次。

● 每个 SSH 蜜罐平均每天被攻破26次。

● 专家们观察到，一个威胁行为者破解了研究人员部署的80个 Postgres 蜜罐中的96% ，并且所有的实例都在30秒内被黑客入侵。

● 仅在一天内就观察到85%的攻击者ip，这表明基于第三层ip的防火墙对这些攻击无效，因为威胁参与者轮换相同的ip来发起攻击。

  

“四种类型的应用程序，SSH、Samba、Postgres和RDP，在整个蜜罐基础设施中均匀部署。我们故意配置了一些具有弱凭据的帐户。

  

如admin:admin、guest:guest、administrator:password。这些帐户授予对沙盒环境中的应用程序的有限访问权。当检测到危害事件时，即当威胁参与者成功通过一个凭据进行身份验证并获得对应用程序的访问权时，蜜罐将被重置并重新部署。帕洛阿尔托网络公司发布的帖子写道。“为了分析阻断网络扫描流量的有效性，我们阻断了一个蜜罐子集上的已知扫描ip列表。”

  

研究人员根据观察到的网络扫描流量每天更新一次防火墙策略，以防止用扫描仪进行的侦察和攻击。每个防火墙策略可能阻止600-3,000个已知的扫描器 IP 地址。

  

每当组成蜜罐基础设施的虚拟机失去响应时，控制器就会重新部署虚拟机和应用程序。

  

![](../Images/59b16646150fa7c56ebc79458d875ded.png)

  

专家们分析了不同服务的首次妥协时间(系统被破坏之前的时间)。Samba 安装的首次妥协时间为2485分钟，RDP 为667分钟，Postgres 为511分钟，SSHD 为184分钟。

  

Palo Alto的研究还关注于平均失陷间隔时间，即目标应用程序两个连续失陷事件之间的平均时间。

  

互联网上一个脆弱的服务通常会被多个不同的攻击者多次攻击。为了争夺受害者的资源，攻击者通常试图删除其他网络犯罪组织(如Rocke、TeamTNT)留下的恶意软件或后门。报告继续写道。平均失陷间隔时间类似于下一个攻击者出现之前攻击者在一个被失陷的系统上的时间。与第一次攻击的时间相似，应用程序的平均攻击间隔时间也与针对该应用程序的攻击者数量成反比。”

  

研究人员还分析了攻击的地理分布，部署在亚太地区的系统最容易受到威胁者的攻击。

  

![](../Images/212c0f55982415ff7f01638ba6c3d049.png)

  

“不安全暴露服务的问题对公共云来说并不新鲜，但云基础设施管理的灵活性使得创建和复制此类错误配置的速度更快。这项研究强调了这种错误配置的风险和严重性。当一个脆弱的服务暴露在互联网上时，机会主义的攻击者可以在几分钟内找到并攻击它。由于大多数这些面向互联网的服务都连接到其他一些云进行工作负载，任何违反的服务都可能导致整个云环境的破坏。报告总结道。

  

**下面是针对保护云服务的建议:**

● 创建一个防护策略，以防止特权端口被打开。

● 创建审计规则以监视所有打开的端口和公开的服务。

● 创建自动响应和补救规则以自动修复错误配置。

● 在应用程序之前部署下一代防火墙， WAF，以阻止恶意流量。
