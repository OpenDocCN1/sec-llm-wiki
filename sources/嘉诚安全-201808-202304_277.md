# 【资讯】Glitch 服务被用来托管短期钓鱼网站

钓鱼行为者现在正在使用 Glitch 平台，免费托管短期盗取证书的URL，同时规避检测和撤销。

  

最近的运动针对的是在中东工作的大公司的雇员。

  

根据域名工具研究小组的分析，这次网络钓鱼活动始于2021年7月，目前仍在进行中。

**“干净”的pdf文件可以逃避检测**  
  

钓鱼行为者发送电子邮件与 PDF 文档附件，不包含任何恶意代码，因此没有生成防病毒警报。

  

相反，这些 pdf 文件包含一个链接，引导用户到一个网页托管在 Glitch，这将显示一个登陆页面。

  

这些 PDF 文档中嵌入的 URL 示例如下:

![](../Images/96e7a0569579753eceac778d6b79102b.png)

  

DomainTools 为70个这种类型的 pdf 文件提供了源代码，并发现它们都使用一个独特的电子邮件和 URL 链接到各种 glitch 托管的“ red.htm”页面。

  

![](../Images/e462a62e7f224a25ab19c06c4dcb8161.png)

**PDF 指向的站点列表**

  
**滥用故障**  
  

Glitch 是一个云托管服务，允许人们使用 Node.js、 React 和其他开发平台部署应用程序和网站。

  

这个平台对网络钓鱼攻击很有吸引力，因为它提供了一个免费版本，用户可以创建一个应用程序/页面，并在网上保持5分钟。之后，用户必须再次手动启用它。

  

因为 Glitch 是一个普遍值得信赖的平台，所以网络安全工具对其域名给予优待，而不是在访问网站时提供警告。

  

这种由安全平台提供的有利观点，再加上短命的 URL，以及威胁参与者可以免费托管它们的事实，使 Glitch 成为钓鱼参与者滥用的绝佳目标。

  

通过深入挖掘，DomainTools 发现了一个与商业恶意软件沙盒服务相关的 Glitch 网站，其中包含一个 SharePoint 钓鱼登录页面的截图。

  

![](../Images/6cbe632df19f72a75c032c0d64520682.png)

**SharePoint phishing page SharePoint 钓鱼页面**

  

由此产生的 PDF 文档已经提交给 VirusTotal，这样研究人员就可以将样本与几个 HTML 文档联系起来。

  

在拉出这些页面之后，研究人员发现了大量模糊的 JavaScript 代码，这些代码用于在 WordPress 网站上传递信息后，将信息过滤到一个电子邮件地址。

  

解除混淆显示了一个收到被盗凭证的Outlook电子邮件地址，导致发现了2021年9月创建的一组额外的pdf文件。

![](../Images/99a44a81d78c4b203a8d56bdf850f5c3.png)

**用于 URL 重定向的 JavaScript 代码**

  

威胁参与者通过类似 Glitch 的各种服务(如 Heroku)或 SelCDN 这样的内容发布网络托管这些文档。

  

这意味着 Glitch 只是网络钓鱼者用来逃避检测和盗取凭证的众多渠道之一。  

  

DomainTools已经联系了Glitch，告知他们他们的发现，但还没有收到回复。
