一个国家支持的朝鲜威胁行为者(被追踪为TA406)最近被观察到在间谍活动中部署了定制的窃取信息的恶意软件。


威胁行为者被认为是几个被称为 Kimsuky 的团体之一。自2018年以来，TA406留下了少量活动的痕迹，主要集中在间谍活动、敛财骗局和敲诈勒索上。


然而，在2021年3月和6月，TA406针对外交政策专家、记者和非政府组织成员发起了两次不同的恶意软件传播运动。


在一份新的报告中，Proofpoint 的研究人员追踪 TA406，采样他们的工具，发现他们滥用的服务和他们使用的钓鱼诱饵。

一次大规模但有针对性的行动


TA406从事恶意软件传播、网络钓鱼、情报收集和加密货币盗窃，导致广泛的犯罪活动。


根据 Proofpoint 的报告，演员们大约从早上9点工作到下午5点(KST) ，一周工作7天，全职从事黑客工作。


目标范围相当广泛，包括北美、俄罗斯、中国、韩国、日本、德国、法国、英国、南非、印度等等。


TA406发送的钓鱼邮件通常使用有关核安全、政治和韩国外交政策的诱饵，同时针对高级当选官员。


Proofpoint 的报告解释说: “这场运动的受益者包括几个不同政府机构的一些最高级别的民选官员、一家咨询公司的雇员、与国防、执法、经济和金融有关的政府机构，以及一家大型金融机构董事会和客户关系的通用邮箱。”


这些邮件是从受到威胁的网站发出的，发件人通常会冒充真实的人，而不是创建虚假的人物角色。


例子包括 Global Asia 的一位编辑，是延世大学的一位教授，以及文在寅总统的顾问。


真实识别假设 TA406网络钓鱼电子邮件


特别令人感兴趣的是，在开展网络钓鱼活动以获取凭证时，TA406通常不会创建复杂的登陆页面来冒充知名服务器。相反，它们使用基本的 HTTP 身份验证，这会显示一个浏览器对话框，请求用户的凭证。


使用基本 HTTP 身份验证窃取凭据


诱饵通常是 PDF 文件，要求收件人使用他们的个人或公司凭证登录到主机平台来查看它们。


定制盗取信息的恶意软件


从2021年1月开始，TA406开始通过钓鱼邮件向7z 档案投放恶意软件。这些档案包含一个带有双扩展名的 EXE 文件，显示为 .HTML 文件。


如果打开该文件，将创建一个名为“Twitter Alarm”的预定任务，该任务允许威胁行为者每15分钟发送额外的有效载荷。


执行过程中，exe 还会打开一个网页浏览器，打开一个 PDF 文件，其中包含一篇合法的《朝鲜新闻》文章，这篇文章存放在威胁行为者的基础设施中，试图欺骗受害者，让他们以为自己正在阅读一篇新闻网站上的文章。


2021年6月，TA406开始部署一个名为 FatBoy 的自定义恶意软件，该软件以 HTML 附件的形式出现在受害者的磁盘上。


FatBoy installation process 安装过程


每个附件都有一个唯一的散列，并且具有一个不可见的 iframe 来与攻击者通信，并告诉他们是哪个接收者(IP 地址)打开了文件。


FatBoy 是一个小型的第一阶段恶意软件，其目的是每20分钟从 c2下载一个 CAB 文件。


CAB 文件包含一个批处理脚本(ball.bat) ，它执行一个 VBS 脚本，该脚本旨在通过 HTTP POST 请求执行侦察和外泄信息。


下载的恶意软件中一个值得注意的 TA406恶意软件是 YoreKey，一个伪装成 MetaTrader 4 Manager 的自定义 Windows 键盘记录器，一个合法的电子交易平台。


YoreKey 通过创建注册表项并将其日志以纯文本形式存储在受感染的系统上，从而确保持久性。


键盘记录器允许威胁参与者窃取用户在使用其设备时输入的其他登录凭证。

窃取加密货币


与上述情况平行的是，TA406也在从事密码窃取业务。根据 Proofpoint 的调查结果，TA406至少收到了3.77比特币，价值约22.2万美元。


通过各种方式，包括冒充非政府组织募捐，通过一个名为“ Deioncube”的网站提供(可能是假的)文件解码/解密服务，以及性交易诈骗。


TA406提供的去模糊化服务


有可能被盗的加密货币数量要大得多，因为威胁参与者可能使用 Proofpoint 研究人员未知的额外钱包。

恐怖袭击预计将继续


随着 TA406和 Kimsuky 黑客进行的广泛恶意活动，我们应该会继续看到他们代表朝鲜政府进行进一步的攻击。


Proofpoint 的研究人员表示: “ Proofpoint 预计这一威胁行为者将继续频繁地进行企业证书盗窃行动，目标是朝鲜政府感兴趣的实体。”


这些攻击包括进一步针对美国国防承包商和核研究机构，窃取朝鲜政府可以使用的有价值的情报。
