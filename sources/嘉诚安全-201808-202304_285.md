Emotet 是一种恶意软件感染，通过带有恶意附件的垃圾邮件活动传播。如果用户打开附件，恶意宏或 JavaScript 将下载 Emotet DLL， 并使用 PowerShell 将其加载到内存中。

 

加载后，恶意软件将搜索并窃取电子邮件以用于未来的垃圾邮件活动，并投放额外的有效载荷，如 TrickBot 或 Qbot，这通常会导致勒索软件感染。

**Emotet 垃圾邮件再次开始**  
  
  

昨天晚上，网络安全研究员布拉德 · 邓肯发表了一篇 SANS Handler 日记，内容是关于 Emotet 僵尸网络是如何开始在多个电子邮件广告中散布垃圾信息，以感染带有 Emotet 恶意软件的设备。

 

据邓肯说，垃圾邮件运动使用重播链电子邮件，诱使收件人打开附加的恶意 Word、 Excel 和密码保护的 ZIP 文件。

 

回复链式网络钓鱼电子邮件是指，之前被盗的电子邮件与欺骗性回复一起使用，以将恶意软件分发给其他用户。

 

在邓肯分享的样本中，我们可以看到 Emotet 使用与“丢失的钱包”、网络星期一促销、取消的会议、政治捐赠活动，以及终止牙科保险有关的回复链。

 

这些电子邮件下的附件是包含恶意宏的 Excel 或 Word 文档，或者是具有密码保护的ZIP文件，示例如下。

目前有两种不同的恶意文件正在分发的新的 eotet 垃圾邮件活动。

  

第一个是 Excel 文档模板，其中说明文档只能在台式机或笔记本电脑上使用，用户需要点击“启用内容”才能正确查看内容。

  

![](../Images/a5a4af854d68dcfcc2a27946bfcfee06.png)

**恶意 Microsoft Excel **

  

第二个是Word附件。恶意 Word 附件使用的是“Red Dawn”模板，并表示由于文档处于“受保护”模式，用户必须启用内容和编辑才能正确查看它。

  

![](../Images/127d948c5944671d288a160512624987.png)

**Microsoft Word Red Dawn 附件**

  
**Emotet 附件如何感染设备**  
  

当您打开 Emotet 附件时，文档模板将声明预览不可用，您需要单击“启用编辑”和“启用内容”以正确查看内容。

  

然而，一旦你点击这些按钮，恶意的宏就会被启用，启动 PowerShell 命令从一个受损的 WordPress 站点下载 Emotet loader DLL 并保存到 c: ProgramData 文件夹。

  

![](../Images/045251099422f2c4420c10acb5b555cb.png)

**下载和运行 Emotet DLL 的 PowerShell 命令**

  

一旦下载完成，这个DLL将使用

C:\\Windows\\SysWo64\\rundll32.exe 启动，它将把DLL 复制到 %LocalAppData% 下的随机文件夹，然后从该文件夹重新运行DLL。

  

![](../Images/5d94f7bc87e62de82b45ccddaca624be.png)

**包含重命名的 Emotet DLL 的文件夹**

  

一段时间后，Emotet 会在

HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run 下配置一个启动值，以在 Windows 启动时启动恶意软件。

  

![](../Images/82fff125ab3654431d4fa4bca226e134.png)

**注册表运行条目用于在启动时加载 Emotet **

恶意软件 Emotet 现在会静静地在后台运行，等待命令从它的命令和控制服务器执行。

  

这些命令可以搜索要盗取的电子邮件，传播到其他计算机，或者安装额外的有效载荷，比如 TrickBot 或 Qbot trojans。

  

![](../Images/e25d91d1db8c738aff770b33cfdc467c.png)

**Emotet 攻击流程**

  

邓肯告诉我们: “我只看到我最近感染了 Emotet 的主机发送垃圾邮件。”我认为Emotet 本周才刚刚重新站稳脚跟。到目前为止，我们还没有看到任何额外的有效载荷被Emotet投放，这也已经证实了邓肯的测试。

 

“也许我们会在未来几周看到一些额外的恶意软件有效载荷。”研究人员补充说。

**防御 Emotet**  

恶意软件和僵尸网络监控组织 Abuse.ch 已经发布了一个包含245个命令和控制服务器的列表，外围防火墙可以阻止这些服务器与命令和控制服务器的通信。

  

阻止与 C2s 的通信还可以防止 Emotet 将更多的有效负载丢弃到受损的设备上。

  

2021年1月，一项国际执法行动摧毁了 Emotet 僵尸网络，而且该恶意软件已经有10个月没有活动了。

  

然而，从周日晚上开始，活跃的 TrickBot 开始在已经感染的设备上下载 Emotet 装载程序，重建僵尸网络进行垃圾邮件活动。

  

Emotet 的回归是一个重大事件，所有网络管理员、安全专家和 Windows 管理员都必须监视新的开发。

  

在过去，Emotet 被认为是分布最广泛的恶意软件，并有很好的机会重新获得其以前的排名。
