# Windows 10 App Installer 在 BazarLoader 恶意软件攻击中被滥用

TrickBot 团伙运营商现在正在滥用 Windows 10 应用安装程序，将他们的 BazarLoader 恶意软件部署到成为高度针对性垃圾邮件活动受害者的目标系统上。

  

BazarLoader（又名BazarBackdoor、BazaLoader、BEERBOT、KEGTAP 和 Team9Backdoor）是一种隐蔽的后门木马，通常用于破坏高价值目标的网络并将对受感染资产的访问权出售给其他网络犯罪分子。

  

它还被用于提供额外的有效载荷，例如 Cobalt Strike 信标，可帮助威胁行为者访问受害者的网络并最终部署危险的恶意软件，包括但不限于 Ryuk 勒索软件。

  

在 SophosLabs 首席研究员 Andrew Brandt 最近发现的活动中，攻击者的垃圾邮件通过使用威胁性语言并冒充公司经理，要求提供有关客户对电子邮件收件人的投诉的更多信息，从而引发紧迫感。

![](../Images/6a13dbce5efd4f0274b98d442b0a4580.png)

  

  

据称，该投诉可从托管在 Microsoft 自己的云存储（在 \*.web.core.windows.net 域上）的站点以 PDF 格式进行审核。

  

为了增加这个诡计，这个垃圾邮件活动接收端的人被双重诱骗使用 adobeview 子域安装 BazarLoader 后门，这进一步增加了该计划的可信度。

  

“攻击者整天使用两个不同的网址来托管这个虚假的‘PDF 下载’页面，”布兰特说。

  

“这两个页面都托管在微软的云存储中，这可能会给它一种（不劳而获的）真实感，而且 .appinstaller 和 .appbundle 文件都托管在每个网页存储的根目录中。”

![](../Images/ad1e58a85bd252e682642eb97e6cef01.png)

  

  

但是，钓鱼网站上的“预览 PDF”按钮不是指向 PDF 文档，而是打开一个带有 ms-appinstaller: 前缀的 URL。

  

单击该按钮时，浏览器将首先显示警告，询问受害者是否允许该站点打开 App Installer。

  

但是，大多数人在地址栏中看到 adobeview.\*.\*.web.core.windows.net 域时可能会忽略它。单击警告对话框中的“打开”将启动 Microsoft 的应用程序安装程序（自 2016 年 8 月发布 Windows 10 版本 1607 以来的内置应用程序），以伪造的 Adobe PDF 组件的形式在受害者设备上部署恶意软件。

  

作为 AppX 应用程序包。一旦启动，App Installer 将首先开始下载攻击者的恶意 .appinstaller 文件和一个链接的 .appxbundle 文件，其中包含嵌套在 UpdateFix 子文件夹中的名为 Security.exe 的最终有效负载。

![](../Images/d61a47bb4805b3cc95ae589e5a151957.png)

  

有效载荷下载并执行一个额外的 DLL 文件，该文件被启动并产生一个子进程，该子进程又产生其他子进程，最终通过将恶意代码注入基于 Chromium 的无头 Edge 浏览器进程来结束字符串。

  

在被感染的设备上部署后，BazarLoader 将开始收集系统信息（例如，硬盘、处理器、主板、RAM、本地网络上具有面向公众的 IP 地址的活动主机）。

  

该信息被发送到命令和控制服务器，伪装成通过 HTTPS GET 或 POST 标头传递的 cookie。

  

“应用程序安装程序包中的恶意软件在攻击中并不常见。不幸的是，现在这个过程已经被证明，它可能会吸引更广泛的兴趣，”布兰特说。

  

“安全公司和软件供应商需要有适当的保护机制来检测和阻止它并防止攻击者滥用数字证书。”您可以在 SophosLabs 的 Github 页面上找到与此 BazarLoader 活动相关的妥协 (IoC) 指标，包括恶意软件样本哈希、命令和控制服务器和源 URL。

  

在接到 Sophos 的通知后，微软于 11 月 4 日删除了攻击者在这些攻击中用来托管恶意文件的页面。
