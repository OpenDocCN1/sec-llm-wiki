漏洞背景


2021年8月11日，嘉诚安全监测到Microsoft发布了8月份的安全更新公告，共发布了49个漏洞的补丁，影响众多组件，如Azure、office、.NET、Visual Studio、Windows Defender、Windows更新组件等等。其中共有7个被微软官方标记为“Critical”，42个被标记为“Important”。鉴于漏洞危害较大，嘉诚安全提醒广大Microsoft用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。

漏洞详情


经研判以下漏洞影响较大

CVE-2021- 26424

Windows TCP/IP 远程执行代码漏洞，该漏洞源于 tcpip.sys 在处理通过 IPv6 协议发送的 TCP/IP 数据包时存在边界错误。恶意的 Hyper-V 来宾向 Hyper-V 主机发送 ipv6 ping 可远程触发此漏洞。攻击者可利用 TCPIP 协议栈 (TCPIP.sys) 来处理数据包，然后将一个经过特殊设计的 TCPIP 数据包发送给它的主机。

CVE-2021-34535

远程桌面客户端远程执行代码漏洞，WindowsRDP 客户端存在一处RCE漏洞，该漏洞只影响RDP客户端，不影响RDP服务端。攻击者利用此漏洞可以使一个RDP客户端连接至攻击者控制的RDP服务端，从而完全控制受害主机。

CVE-2021-36942

Windows LSA 欺骗漏洞，LSARPC接口可以被攻击者使用NTLM中继攻击，强迫域控制器使用NTLM对另一个服务器进行身份验证。该漏洞影响所有服务器和域控服务器。

CVE-2021-36936、CVE-2021-36947

Windows打印后台处理程序中存在远程代码执行漏洞，这两个漏洞允许有低权限的攻击者在无需用户交互的情况下在目标主机远程执行代码。目前，CVE-2021-36936漏洞详情已公开披露。

CVE-2021-36948

Windows Update Medic 存在权限提升漏洞，该漏洞的存在是由于 Windows Update Medic 服务中的边界错误。本地用户可以运行特制的程序来执行具有提升权限的任意代码。目前，该漏洞已检测到在野利用。
