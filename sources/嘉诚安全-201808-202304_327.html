漏洞背景


2021年7月14日，嘉诚安全监测到Microsoft发布了7月份的安全更新公告，共发布了117个漏洞的补丁，主要涵盖了以下组件: Windows操作系统、Dynamics、Exchange Server、Microsoft Office、Windows Storage Spaces Controller、Bing、SharePoint Server、Internet Explorer (IE)、Visual Studio、 OpenEnclave。其中,共有13个被微软官方标记为“Critical”，103个被标记为“Important”,存在多个0day在野利用漏洞，鉴于漏洞危害较大，嘉诚安全提醒广大Microsoft用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。

漏洞详情


经研判以下漏洞影响较大

CVE-2021-34527 

Windows Print Spooler是Windows的打印机后台处理程序，广泛的应用于各种内网中，攻击者利用此漏洞可以实现本地权限提升或远程任意代码执行，在特定配置的域控环境下甚至可以完全控制域控服务器。目前，该漏洞已检测到在野利用。

CVE-2021-31979

Windows 内核特权提升漏洞，经过身份验证的本地攻击者可以在目标主机进行特权提升。目前，该漏洞已检测到在野利用。

CVE-2021-33771

Windows存在内核特权提升漏洞，经过身份验证的本地攻击者可以在目标主机进行特权提升。目前，该漏洞已检测到在野利用。

CVE-2021-34448

脚本引擎内存损坏漏洞，该漏洞源于处理微软脚本引擎中HTML内容时的边界错误。远程攻击者可创建一个特殊构造的网页，诱导用户打开，从而触发内存损坏，实现在目标系统上执行任意代码。

CVE-2021-34473

Microsoft   Exchange Server存在远程执行代码漏洞，未经身份验证的攻击者可以对目标Microphone Exchange Server远程攻击，并在目标服务器上执行代码。
