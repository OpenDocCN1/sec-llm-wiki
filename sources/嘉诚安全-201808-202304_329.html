漏洞背景


2021年6月9日，嘉诚安全监测到Microsoft发布了6月份的安全更新公告，共发布了49个漏洞的补丁，主要涵盖了以下软件:Windows、Office、.NET Core 和 Visual Studio、Hyper-V、Paint 3D等。其中共有5个被微软官方标记为“Critical”，44个被标记为“Important”。其中，有6个漏洞存在在野利用。嘉诚安全提醒广大Microsoft用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。

漏洞详情


经研判以下漏洞影响较大

CVE-2021-33742

该漏洞是Windows IE浏览器使用的渲染引擎 Trident中的一处远程代码执行漏洞。攻击者通过诱导用户访问特殊构建的WEB页面，即可控制用户的计算机设备。目前，该漏洞已检测到在野利用。

CVE-2021-33739

该漏洞是Windows Desktop Window Manager(DWM)组件中的一处权限提升漏洞，攻击者通过诱导用户打开特殊构造的EXE可执行文件来利用此漏洞。该漏洞细节已公开，并检测到在野利用。

CVE-2021-31956

该漏洞是Windows NTFS文件系统组件中的一处权限提升漏洞，攻击者通过诱导用户打开特殊构造的EXE可执行文件来利用此漏洞。目前，该漏洞已检测到在野利用。

CVE-2021-31955

该漏洞是Windows内核组件中的一处信息泄露漏洞，攻击者可以利用此漏洞从系统中泄露Windows内核中的敏感信息。已发现有攻击者将此漏洞与CVE-2021-31956结合起来进行攻击。目前，该漏洞已检测到在野利用。

CVE-2021-31199、CVE-2021-31201

该漏洞是Windows加密程序中的一处本地权限提升漏洞，本地用户可以绕过Microsoft Enhanced Cryptographic Provider实施的安全限制并读取或修改其他受限制的信息。已发现有攻击者将其用于与Adobe Reader漏洞CVE-2021-28550结合使用进行远程攻击。目前，该漏洞已检测到在野利用。

CVE-2021-31959

Jscript Engine 存在远程代码执行漏洞，JScript 是由微软公司开发的动态脚本语言，是微软对 ECMAScript 规范的实现，攻击者可以通过构造恶意网页诱使用户进行访问，实施攻击，从而在用户机器上执行任意命令。
