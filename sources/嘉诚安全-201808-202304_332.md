漏洞背景  
  

2021年5月26日，嘉诚安全监测到VMware官方发布了VMware vCenter Server远程代码执行漏洞安全风险通告，漏洞编号：CVE-2021-21985。

VMWare vCenter Server 提供了一个可伸缩、可扩展的平台，可集中管理 VMware vSphere 环境，并能实现资源优化分配和插件扩展。攻击者可利用该漏洞在可访问443端口的条件下，直接通过请求在目标主机上执行任意代码，并接管目标主机。对此，嘉诚安全提醒广大用户尽快将VMware vCenter Server产品升级到最新版本，避免引发漏洞相关的网络安全事件。

漏洞详情  
  

**CVE-2021-21985：****VMware vCenter Server****远程代码执行漏洞**

由于插件Virtual SAN Health Check缺少输入验证而包含远程代码执行漏洞，并且该插件在vCenter Server中默认情况下处于启用状态；可以访问443端口的攻击者可能会利用此漏洞在托管vCenter Server的基础操作系统上以不受限制的特权执行命令。

vCenter Server 6.7
