漏洞背景


2021年4月14日，嘉诚安全监测到Microsoft官方发布了4月份的安全更新公告，共发布了109个漏洞的补丁，主要涵盖了以下组件: Windows操作系统、Exchange Server、Azure、Office、SharePoint Server、Hyper-V、 Visual Studio和基于Chromium内核的Edge。其中共有19个被微软官方标记为“Critical”，89个被标记为“Important”。远程代码执行漏洞56个，安全功能绕过漏洞5个，信息泄露漏洞 17个，特权提升19个。嘉诚安全提醒广大Microsoft用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。

漏洞详情


经研判以下漏洞影响较大

CVE-2021-28480/CVE-2021-28481: Exchange Server代码执行漏洞

这两个漏洞都是未授权远程代码执行漏洞且攻击者无需向易受攻击的Exchange服务器进行身份验证即可利用此漏洞。

CVE-2021-28310: Win32k特权提升漏洞

Win32k存在权限提升漏洞，经过本地身份认证的攻击者可利用此漏洞在目标主机上以SYSTEM权限执行任意代码。根据微软官方的描述，该漏洞很可能已经出现了在野利用。

CVE-2021-28324/CVE-2021-28325: Windows SMB信息泄露漏洞

该漏洞使远程攻击者可以访问潜在的敏感信息。其中，CVE-2021-28324不需要身份验证，这意味着远程攻击者可以未经授权访问系统上的敏感信息。

CVE-2021-28319: Windows TCP/IP Driver拒绝服务漏洞

该漏洞可使远程攻击者执行拒绝服务（DoS）攻击。由于Windows TCP/IP驱动程序对用户提供的输入的验证不足，远程攻击者可以将特制的输入传递给应用程序，从而导致目标系统拒绝服务。

CVE-2021-28442: Windows TCP/IP信息泄露漏洞

经过身份验证的远程攻击者可以未经授权访问系统上的敏感信息。

CVE-2021-28444: Windows Hyper-V安全功能绕过漏洞

成功利用该漏洞的攻击者可以绕过Hyper-V上的Router Guard配置，将Windows配置为中间人路由器，最终可以截获流量并修改数据包。
