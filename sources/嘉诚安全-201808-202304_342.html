漏洞背景


2021年3月10日，嘉诚安全监测到Microsoft发布了3月份的安全安全更新公告，共发布了89个漏洞的补丁，主要涵盖了以下组件: Windows操作系统、Azure、IE和Edge、Exchange Server、Office、SharePoint Server，Visual Studio，和Hyper-V。其中共有14个被微软官方标记为“Critical”，75个被标记为“Important”。此外，在本月的安全补丁中，有45个远程代码执行漏洞，30个权限提升漏洞，4个拒绝服务漏洞以及6个信息泄露漏洞。嘉诚安全提醒广大Microsoft用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。

漏洞详情


经研判以下漏洞影响较大

CVE-2021-26897

Windows DNS Server存在远程代码执行漏洞，攻击者可通过向目标主机发送特制请求来利用此漏洞，成功利用此漏洞可在目标主机上以SYSTEM权限执行任意代码。启用安全动态更新可暂时缓解此漏洞，但攻击者依然可以通过加入域的计算机攻击启用了安全区域更新的DNS服务器。

CVE-2021-26411

Interne Explorer在处理DOM对象时，存在一处double free漏洞，攻击者可通过诱导用户点击恶意链接或文件来利用此漏洞，此漏洞可导致远程代码执行，从而使攻击者控制用户系统。

CVE-2021-26877

Windows DNS Server存在远程代码执行漏洞，攻击者可通过向目标主机发送特制请求来利用此漏洞，成功利用此漏洞可在目标主机上以SYSTEM权限执行任意代码。启用安全动态更新可暂时缓解此漏洞，但攻击者依然可以通过加入域的计算机攻击启用了安全区域更新的DNS服务器。

CVE-2021-27076

Microsoft SharePoint Server存在远程代码执行漏洞。利用此漏洞，攻击者需要能够使用SharePoint服务器创建或修改网站。经过身份认证的攻击者可利用此漏洞获得远程代码执行。

CVE-2021-26863

Win32k存在权限提升漏洞，经过本地身份认证的攻击者可利用此漏洞在目标主机上以SYSTEM权限执行任意代码。
