漏洞背景


2021年2月25日，嘉诚安全监测到VMware官方发布了VMware ESXi与vCenter Server的多个安全漏洞的风险通告，漏洞编号：CVE-2021-21972，CVE-2021-21973，CVE-2021-21974。VMware更新了ESXi和vSphere Client(HTML5) 中的两个高危漏洞，具有网络端口访问权限的恶意攻击者可以通过漏洞执行任意代码。对此，嘉诚安全提醒广大用户尽快将VMware ESXi与vCenter Server产品升级到最新版本，避免引发漏洞相关的网络安全事件。

漏洞详情


CVE-2021-21972：vSphere Client远程执行代码漏洞

vSphere Client（HTML5）在vCenter Server插件中包含一个远程执行代码漏洞。攻击者可直接通过443端口构造恶意请求，执行任意代码，控制vCenter。


CVE-2021-21973：vSphere Client SSRF漏洞

vSphere Client（HTML5）包含SSRF（服务器端请求伪造）漏洞，攻击者可通过443端口发送恶意POST请求，发起内网扫描，造成SSRF漏洞。


CVE-2021-21974：ESXi OpenSLP 堆溢出漏洞

VMware ESXi提供OpenSLP服务的427端口存在堆溢出漏洞，当在OpenSLP服务中处理数据包时，由于边界错误，本地网络上的远程非身份验证攻击者可以将伪造的数据包发送到端口427/tcp，触发基于堆的缓冲区溢出，并在目标系统上执行任意代码。

VMware vCenter Server 6.7

VMware vCenter Server 6.5

VMware Cloud Foundation（vCenter Server） 4.x

VMware ESXi  6.7

VMware ESXi  6.5

VMware Cloud Foundation (ESXi)  4.X
