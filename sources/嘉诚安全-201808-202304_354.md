漏洞背景  

2021年1月13日，嘉诚安全监测到Microsoft发布了1月份的安全更新公告，共发布了83个CVE的补丁程序，涵盖了Azure、Microsoft Office、SQL Server、Microsoft Edge、Visual Studio等众多组件和软件。其中共有10个被微软官方标记为“Critical”，71个被标记为“Important”。此外，在本月的安全补丁中，有24个远程代码执行漏洞，32个权限提升漏洞以及11个信息泄露漏洞。嘉诚安全提醒广大Microsoft用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。

漏洞详情  
  

### 经研判以下漏洞影响较大  

### CVE-2021-1707

Microsoft SharePoint Server远程代码执行漏洞。该漏洞是由于SharePoint服务器未对用户输入的内容进行校验，并解析未校验的数据。攻击者可以通过对特定的api发送精心构造的数据实现任意命令执行, 从而接管服务器。

### CVE-2021-1709

Windows win32k权限提升漏洞。该漏洞为win32k的本地提权漏洞，在win32k释放某些对象时存在释放后使用（UAF）漏洞，该对象释放后仍有指针指向该对象的地址空间，形成悬垂指针，当用户再次使用该指针时将会产生内存错误。攻击者可以通过构造恶意的利用程序，利用该漏洞进行任意地址读写，通过写入指定payload造成本地提权。

**CVE-2021-1647**

Microsoft Defender远程代码执行漏洞。Microsoft Defender在扫描文件的过程中存在内存损坏漏洞，因此攻击者可以通过构造恶意PE文件，并使存在漏洞的Microsoft Defender扫描该恶意文件来执行任意代码。攻击者可以通过恶意网页，电子邮件附件或USB驱动器等方式诱导目标下载恶意文件，进而远程破坏易受攻击的系统。该漏洞已发现在野利用，危害较大。
