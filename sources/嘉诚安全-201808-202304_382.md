漏洞背景  
  

2020年8月13日，嘉诚安全监测到Apache Struts 官方发布安全公告，披露 S2-059 Struts 远程代码执行漏洞，漏洞编号CVE-2019-0230。  

Apache Struts2框架是一个用于开发Java EE网络应用程序的Web框架。  

目前官方已发布补丁修复该漏洞，建议相关用户尽快进行自查更新，避免引发漏洞相关的安全事件。

漏洞详情  
  

Apache Struts于2020年8月13日披露S2-059 Struts远程代码执行漏洞（CVE-2019-0230）,在使用某些tag等情况下可能存在OGNL表达式注入漏洞，从而造成远程代码执行，风险极大。  

  
危害影响  
  

Apache Struts 2.0.0 - 2.5.20

  
修复建议  
  

**安全建议  
**

将Apache Struts框架升级至最新版本。
