漏洞背景  
  

近日，嘉诚安全监测到F5官方发布了F5 BIG-IP远程代码执行的风险通告，漏洞编号CVE-2020-5902，漏洞等级：严重。

F5 BIG-IP是美国F5公司一款集成流量管理、DNS、出入站规则、web应用防火墙、web网关、负载均衡等功能的应用交付平台。

目前官方已发布新版本修复该漏洞，建议相关用户尽快进行自查更新，避免引发漏洞相关的安全事件。

漏洞详情  
  

在F5 BIG-IP产品的流量管理用户页面 (TMUI)/配置实用程序的特定页面中存在一处远程代码执行漏洞。

未授权的远程攻击者通过向漏洞页面发送特制的请求包，可以造成任意 Java 代码执行。进而控制F5 BIG-IP的全部功能，包括但不限于: 执行任意系统命令、开启/禁用服务、创建/删除服务器端文件等。该漏洞影响控制面板受影响，不影响数据面板。

  
危害影响  
  

F5 BIG-IP < 15.1.0.4

F5 BIG-IP < 14.1.2.6

F5 BIG-IP < 13.1.3.4

F5 BIG-IP < 12.1.5.2

F5 BIG-IP < 11.6.5.2

  
修复建议  
  

**目前该漏洞POC已泄露，鉴于漏洞影响较大，建议相关用户参考以下链接尽快进行升级：**

*https://support.f5.com/csp/article/K52145254*

**临时性修复建议：**

1.通过输入以下命令登录到TMOS shell

Tmsh

2.通过输入以下命令编辑httpd属性

edit /sys httpd all-properties 

3.将文件中<include>部分改为以下内容

include '

<LocationMatch ".\*\\.\\.;.\*">

Redirect 404 /

</LocationMatch>

'

4.保存退出

Esc

:wq!

5.重启httpd服务

restart sys service httpd

建议同时禁止外部IP对于TMUI的访问，或只允许管理人员在安全网络环境下访问来缓解漏洞。
