漏洞背景  
  

2020年6月30日，嘉诚安全监测到Apache Dubbo官方发布的Dubbo 2.7.7版本（用于修复反序列化漏洞，漏洞编号：CVE-2020-1948）存在补丁绕过风险，攻击者可以绕过补丁执行任意指令。

目前官方暂未发布修复后的版本，建议及时关注官方Github代码或版本更新。

漏洞详情  
  

### Apache Dubbo Provider 存在一个反序列化远程代码执行漏洞（CVE-2020-1948），攻击者可以构造并发送带有恶意参数负载的RPC请求，当恶意参数被反序列化时，可以造成远程代码执行。

  
危害影响  
  

Apache Dubbo 2.7.0 ~ 2.7.7

Apache Dubbo 2.6.0 ~ 2.6.7

Apache Dubbo 2.5.x 所有版本 (官方不再提供支持)。

  
修复建议  
  

目前官方暂未更新版本，建议更新到漏洞修复后的最新版本（2.7.8或更高版本），GitHub更新版本地址：

*https://github.com/apache/dubbo/releases/*
