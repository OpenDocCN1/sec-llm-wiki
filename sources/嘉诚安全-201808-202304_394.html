漏洞背景


近日，嘉诚安全监测到应用广泛的Apache Dubbo出现一个较为严重的漏洞：反序列化漏洞（漏洞编号：CVE-2020-1948）。

Apache Dubbo 是一款高性能、轻量级的开源Java RPC框架，它提供了三大核心能力：面向接口的远程方法调用，智能容错和负载均衡，以及服务自动注册和发现。

鉴于该漏洞影响较大，嘉诚安全提醒相关用户尽快进行自查修复。

漏洞详情


Apache Dubbo Provider 存在一个反序列化远程代码执行漏洞（CVE-2020-1948），攻击者可以构造并发送带有恶意参数负载的RPC请求，当恶意参数被反序列化时，可以造成远程代码执行。


危害影响


Apache Dubbo 2.7.0 ~ 2.7.6

Apache Dubbo 2.6.0 ~ 2.6.7

Apache Dubbo 2.5.x 所有版本 (官方不再提供支持)。


修复建议


鉴于漏洞危害较大，建议相关用户及时升级到Apache Dubbo 2.7.7或者更高版本，下载地址：

https://github.com/apache/dubbo/releases/tag/dubbo-2.7.7
