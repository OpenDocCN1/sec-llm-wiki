# WebSphere 远程代码执行漏洞安全通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU4NjY4MDAyNQ==&mid=2247483897&idx=1&sn=24a1b4a8536a6d87eb4f61d8cc518988&chksm=fdf6d24fca815b592f738220b0ea8c99cef0aeeb1a150e1fb21d494d5c79b93350ac69c9f2a5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU4NjY4MDAyNQ==&mid=2247483897&idx=1&sn=24a1b4a8536a6d87eb4f61d8cc518988&chksm=fdf6d24fca815b592f738220b0ea8c99cef0aeeb1a150e1fb21d494d5c79b93350ac69c9f2a5&scene=27#wechat_redirect)

**一、漏洞编号**

CVE-2020-4276 、CVE-2020-4362

****二、漏洞详情****

WebSphere Application Server 是一款由IBM 公司开发的高性能的Java 中间件服务器，可用于构建、运行、集成、保护和管理部署的动态云和Web 应用。它不仅能够确保高性能和灵活性，还提供多种开放标准编程模型选项，旨在最大程度提高开发人员的生产力。WebSphere SOAP Connector 服务用于管理远程节点和数据同步，因此主要是在服务器与服务器之间进行通信。它的默认监听地址为0.0.0.0:8880。CVE-2020-4276 和CVE-2020-4362 是存在于WebSphere SOAP Connector 服务中的远程代码执行漏洞。远程且未经授权的攻击者通过利用此漏洞，可以在目标服务端执行任意恶意代码，获取系统权限。

**三、影响版本**

*   WebSphere Application Server 9.0.x
    
*   WebSphere Application Server 8.5.x
    
*   WebSphere Application Server 8.0.x
    
*   WebSphere Application Server 7.0.x
    

**四、安全建议**

各版本WebSphere 的漏洞修复步骤：

WebSphere Application Server 9.0.x：更新安全补丁PH21511及PH23853

WebSphere Application Server 8.5.x：更新安全补丁PH21511及PH23853

WebSphere Application Server 8.0.x：升级到8.0.0.15 版本，然后更新安全补丁PH21511及PH23853

WebSphere Application Server 7.0.x：升级到7.0.0.45 版本，然后更新安全补丁PH21511及PH23853

修复方法一：

可以通过运行IBM Installation Manager 进行更新，根据程序提示进行补丁下载、漏洞修复的工作。

修复方法二：  

前往官方地址，手动进行补丁下载、漏洞修复的工作:

https://www.ibm.com/support/pages/node/6118222

https://www.ibm.com/support/pages/node/6174417
