# Firefox在野利用漏洞安全通告

**一、漏洞背景**监测发现2020年04月03日Mozilla官方发布了安全通告，该安全通告包含了两个Firefox严重漏洞，CVE编号分别为CVE-2020-6819和CVE-2020-6820。Mozilla Firefox和Mozilla Firefox ESR都是美国Mozilla基金会的产品。Mozilla Firefox是一款开源Web浏览器。Mozilla Firefox ESR是Firefox(Web浏览器)的一个延长支持版本。**二、漏洞详情**上述漏洞都是在某些条件下，当处理nsDocShell析构函数或处理ReadableStream时，竞争条件可能会导致use-after-free（释放重用）使恶意攻击者将代码放入Firefox内存中，并在浏览器的上下文中执行该代码。目前Mozilla官方已经捕获到在野利用尝试。建议广大用户做好安全自查工作，及时更新Firefox和Firefox ESR版本，以免遭受攻击。**三、危害影响**Firefox < 74.0.1Firefox ESR < 68.6.1**四、修复建议**更新Firefox到74.0.1版本更新Firefox ESR到68.6.1版本
