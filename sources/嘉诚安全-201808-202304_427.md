# Apache ShardingSphere远程代码执行漏洞安全通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU4NjY4MDAyNQ==&mid=2247483808&idx=1&sn=6c6f45c8cfd554cc3ef2440e92da34e3&chksm=fdf6d216ca815b004c7e5939f3da2c2a6caabfa0096390714904c92ba0680b53b542f5e96199&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU4NjY4MDAyNQ==&mid=2247483808&idx=1&sn=6c6f45c8cfd554cc3ef2440e92da34e3&chksm=fdf6d216ca815b004c7e5939f3da2c2a6caabfa0096390714904c92ba0680b53b542f5e96199&scene=27#wechat_redirect)

**一、漏洞名称**

Apache ShardingSphere远程代码执行漏洞

**二、漏洞编号**

CVE-2020-1947

**三、漏洞背景**

近日，监测发现ApacheShardingSphere存在远程代码执行漏洞，官方已为该漏洞分配CVE编号：CVE-2020-1947。截止今日，该漏洞已修复，鉴于漏洞危害较大，建议用户尽快升级到最新版本。

Apache ShardingSphere是一套开源的分布式数据库中间件解决方案组成的生态圈，它由Sharding-JDBC、Sharding-Proxy和Sharding-Sidecar（规划中）这3款相互独立，却又能够混合部署配合使用的产品组成。它们均提供标准化的数据分片、分布式事务和数据库治理功能，可适用于如Java同构、异构语言、云原生等各种多样化的应用场景。

**四、漏洞详情**

经过验证的攻击者可以通过提交任意YAML代码实现远程代码执行。相关截图如下：

![](../Images/072099f5ed51fd366786784ec62d0191.png)

通过对Apache ShardingSphere代码分析，发现开发人员直接使用unmarshal方法对输入的YAML直接进行解析，没有做校验。

![](../Images/6cc164fa225765830c9c6c044702f7df.png)

对比补丁发现新增ClassFilterConstructor来对此进行校验。

![](../Images/71a7fc590312ab4236544615bca8ad47.png)

  

注：Apache ShardingSphere后台的管理账号密码默认均为admin

**五、危害影响**

ApacheShardingSphere < 4.0.1

**六、修复建议**

目前，官方已发布最新版本修复该漏洞，建议用户尽快升级：

https://github.com/apache/incubator-shardingsphere/releases
