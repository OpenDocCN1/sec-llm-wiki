# Optiv申请纽交所上市，是福是祸？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247483755&idx=3&sn=878eb6ff6af7905a76e020dc88365dc4&chksm=e916d151de6158470b76e888949f4329a125dc4090df5cad389c692f15cd0db5d3d989ac7f60&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247483755&idx=3&sn=878eb6ff6af7905a76e020dc88365dc4&chksm=e916d151de6158470b76e888949f4329a125dc4090df5cad389c692f15cd0db5d3d989ac7f60&scene=27#wechat_redirect)

Blackstone 集团主要控股的网络安全公司Optiv Inc.正在向美国监管机构提交上市申请。在向美国证券交易委员会提交的S-1文件中，该公司计划筹集金额1亿美元，但并没有透露其股票的预计价格。

 

2015年，Accuvant和FishNetSecurity两家安全公司宣布合并，更名为Optiv，公司地址坐落于科罗拉多州丹佛市。自从两公司合并之后，Optiv发展迅速，业务不断扩张。Optiv提供了一套全面的信息安全服务和解决方案，可以帮助企业制定网络安全策略，评估安全风险，选择和部署正确的安全防护技术等。目前Optiv服务的客户有政府、企业、教育机构等，已经成功的为他们制定并实施了一套信息安全流程。

 

根据S-1文件中的信息得知，Optiv公司计划在纽约证券交易所上市，发行普通股，股票代码为 "OPTV"。

 

今年是一个很冷淡的一年，全球呈现出了一种上市荒的状态，到目前位置，美国只有两家科技公司获准上市。一家是戴尔公司(Dell)旗下名为SecureWorks的安全公司，另外一家是光纤承办商Acacia Communications公司。但是他们上市后，却被泼了一盆冷水，股价一路下滑。ForeScout公司的首席执行官迈克·德切萨雷（Mike DeCesare）感慨道：“眼下为何要上市？你如果不需要这笔钱，那你觉得当下的环境吸引你又如何？”

 

那么问题来了，Optiv公司提交上市申请能被批准吗？是否也会遇到SecureWorks那样的寒冬呢？
