# 加拿大军方招聘网站被黑，中国又被背锅？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247483755&idx=4&sn=b592c611cb934988f2ea5e7c99d125ec&chksm=e916d151de615847bcc3eb759deee6be04cac906ea37c0bc652c813cb67aa174b0aa3bf815c8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247483755&idx=4&sn=b592c611cb934988f2ea5e7c99d125ec&chksm=e916d151de615847bcc3eb759deee6be04cac906ea37c0bc652c813cb67aa174b0aa3bf815c8&scene=27#wechat_redirect)

近日，加拿大武装部队的招聘网站出现异常，打开页面后，页面会自动跳转到中国政府网站的首页。这已经不是加拿大政府或军事网站第一次被黑客入侵，而中国常常被当做怀疑对象。

 

近日，网友在登录加拿大武装部队招聘网站时发现，页面会立即跳转到中国政府网站的首页。该网站的头条新闻与中国的国家能源委员会会议有关。

 

![](../Images/9a88bb91c6211d0cc6f8eefb48d9e61c.png)  

  

加拿大国防部发言人Ashley Lemire已通过《卫报》确认了此次网络攻击事件。据悉，该网站是国防部主网站下的独立网站。发现攻击的第一时间，武装部队就立即将相关网站撤下线，目前为止，该网站还是无法访问，提示404错误。而军队的主要网站仍能正常运作。加拿大军方正在调查这一事件，但尚不清楚幕后黑手。

 

另据环球邮报报道，黑客们袭击加拿大政府的自然资源、能源及环境部门网站的频率几乎是袭击其他部门次数加起来的总和。

 

据联邦政府本周公布的统计数据显示，政府系统内的自然资源、能源及环境部门网站在今年已经遇到了2078次“系统受损”情况，而同一时期内其他部门遭遇到的入侵次数总和为2493次。

 

加拿大国家情报局CES(Communications Security Establishment)在发表的声明中表示，2016年至今，联邦政府已经发生超过4500次电脑系统被入侵的情况，这个数据还不包括情报局没有侦测到的情形。目前能确定的是，其中有三次电脑系统被入侵时，政府的数据被盗取，不过其中并不涉及国家机密。这三例分别发生在自然资源部门、安全情报与国防部门以及政府行政部门。

 

情报局没有透露这些黑客入侵网站的具体动机，只表示一些黑客是纯粹的恶作剧，一些涉及到间谍活动，还有一些黑客是想要制造严重破坏。

 

加拿大安全官员长期抱怨，外国黑客经常试图入侵政府计算机系统。虽然国防部称，定论幕后黑手还为时过早，但页面的确被重定向至中国政府网站。

 

2014年，加拿大保守党政府通过非同寻常的措施，发现中国黑客攻击关键计算机网络，保守党政府当时公开指责中国窃取国家研究委员会的机密，但中国政府提出抗议。

 

加拿大公共安全部长Ralph Goodale周四下午表示，

  

![](../Images/9c2f30363402f2b5ff9bef7c233b9687.png "undefined")

一旦我们确定了更多事实，了解了问题的确切性质以及问题源，我们会透露更多细节。他强调，加拿大政府正认真对待该事件。他不确定新兵或加拿大军人的个人信息是否受到影响。

![](../Images/440e907b4fa7a0ae990fa0a8c423b746.png "undefined")

   

加拿大政府不是首次遭遇黑客事件。2015年6月，知名黑客组织“Anonymous”声称十几个加拿大政府网站遭受的DoS攻击负责。

 

中国经常被认为有黑客入侵的“嫌疑”，窃取西方国家的技术机密。美国和英国近期已经与中国签订了协议，双方都不为了经济利益而参与或支持窃取对方的情报信息或商业机密。加拿大公共安全部长Ralph Goodale的发言人Scott Bardsley表示，加拿大与中国也可能签订一个类似的协议。加拿大自由党政府也正努力促进与中国的贸易关系。
