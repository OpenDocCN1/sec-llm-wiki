# 苹果中国员工私下出售iPhone用户敏感信息，这个会被判几年？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247484983&idx=4&sn=026a03ec2aa77bfdc4f8bde1cb627534&chksm=e916d60dde615f1b7c05a962895184edbce8a8eaa7c664401e04437a34f78eac57fa0f60e8dc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247484983&idx=4&sn=026a03ec2aa77bfdc4f8bde1cb627534&chksm=e916d60dde615f1b7c05a962895184edbce8a8eaa7c664401e04437a34f78eac57fa0f60e8dc&scene=27#wechat_redirect)

据新华社消息，近日浙江苍南警方破获一起非法获取计算机信息系统数据、侵犯公民个人信息案，抓获嫌疑人22名，其中有苹果国内直销公司、外包公司员工20人。

今年1月，警方发现有苹果公司国内员工利用内部系统平台，非法查询iPhone手机关联的手机号、姓名、Apple ID等信息，再将信息以每条10元-180元不等的价格售卖。

经数月侦查，警方于5月初实施抓捕行动，抓获犯罪嫌疑人22名，扣押了电脑、手机、银行卡等作案工具，初步查明涉案金额高达5000万元以上。

目前，该案22名犯罪嫌疑人已分别被采取刑事拘留等强制措施，案件正在进一步审理中。

**嘶吼评：**

以涉案金额5000万元以上、每条信息10元-180元不等售价来计算，这伙人至少卖了几十万的用户个人信息，按最新司法解释，属于“情节特别严重”，至少三年起判，且还会有高额罚金。

苹果内部员工出售的这些信息能干什么用呢？许多人iPhone被偷，激活了iCloud锁强制锁定手机，这些信息就是小偷可以解锁手机的关键。如果没人提供信息，小偷们不知道手机主人个人信息，解锁能力要下降一大半。

这次的苹果内部员工只是黑产幕后隐藏的一小部分，明面上的还有某宝、某聊天工具上的各种商品、群。现在在某宝上搜索“Apple ID解锁”，还能找到许多声称提供“官方解锁Apple ID”服务的商家。
