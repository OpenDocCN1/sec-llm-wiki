所谓IP地址就是给每个连接在Internet上的主机分配的一个32bit地址。为了方便人们的使用，IP地址经常被写成十进制的形式，中间使用符号“.”分开不同的字节。IP地址被用来给Internet上的电脑一个编号。大家日常见到的情况是每台联网的PC上都需要有IP地址（范围在0.0.0.0到255.255.255.255之间），才能正常通信。我们可以把“个人电脑”比作“一台电话”，那么“IP地址”就相当于“电话号码”。

垃圾邮件发送者和黑客通常会代理自己的IP地址，使其他人难以识别其真实的IP地址。但是，值得注意的是，他们IP地址的物理位置不一定是计算机的位置。

网站需要使用IP地址与您的计算机进行通信。例如，当你正在浏览4hou网站时，我们的网站将使用您的IP地址将您需要的信息发送到您的计算机上。如果在没有IP地址的情况下，4hou网站也不知道要将信息发送到哪台计算机上。

而所谓“IP追踪”指的是通过一定的技术手段，根据相关信息定位攻击流的真正来源，以及推断攻击数据包经过的完整路径。数据包的来源可能是发出数据包的实际主机或者网络，也可能是实施追踪的网络中的被攻击者控制的某台路由器。

如果依赖基本的IP跟踪工具，就只会为你提供计算机使用的互联网服务提供商（ISP）的位置。所以在某些情况下，如果有些计算机——黑客或者垃圾邮件发送者，试图与你的计算机进行通信和连接，我们要了解这些威胁来自哪里就显得十分有用，以下这些推荐工具将帮助您实现这一点。

1. Geotool

Geotool是最简单的IP地址跟踪网站之一，它能够提供有关您正在尝试跟踪的IP地址的足够信息，而您只需要在底部查询框中输入需要跟踪的目标IP地址即可。

该网站将为你提供如下相关信息，包括主机名（您的ISP）、国家、城市、邮政编码、当地时间、经度和纬度等。该网站还可以在谷歌地图上显示跟踪IP地址的大致位置。

   2. DomainTools

作为其中最精美的一个IP地址查找网站之一，DomainTools为您提供了一个非常简洁易用的界面，称为“Whol Lookup”工具。

DomainTools提供的搜查结果包括，与IP地址相关联的联系人姓名、号码、电子邮件地址和位置等。

虽然上述的信息都可以免费访问，但是DomainTools还提供更多工具来帮助您获得更为详细的信息，但前提是您必须花费一些钱才能够使用。付费的高级工具包括，反向IP地址查询、广泛的域属性、跟踪路由、ping以及DNS查找等。

   3. MyIPTest.com

MyIPTest是最全面的的IP地址查找工具之一，不仅可以为您提供ISP、主机名、经度以及纬度等相关信息，还可以为你提供代理检查器、反向IP和DNS查找、跟踪路由和电子邮件等工具。这是一个功能强大且可以免费使用的网站，应该足以满足您的个人需求。

   4. IP Address Location

IP Address Location是另外一款简单易用的查找工具，虽然它看起来太过杂乱，但是功能方面还是较为完善的。除了提供常见的IP地址信息外，它还提供其他一些有用的信息，例如DNS、电子邮件和ping查找等。

它还有一个工具让你可以发现特定网站的IP地址，并查找与特定地理位置（例如，一个国家）相对应的IP地址，以防您需要对特定IP地址的地理位置进行双重检查。

   5. ipinfodb

ipinfodb是一个免费的IP地址地理位置定位工具。它可以为客户提供了五种地理定位数据库，且支持下载。此外，由于ipinfodb的LITE是开源数据库版本，其准确性和记录数量相对商业版本而言非常有限，可供个人和商业用途。

   6. IP Location Finder

IP Location Finder 是一款在线IP查询工具，可以定位你的IP地址为您提供ISP、主机名、国家、城市、经度以及纬度等相关信息。除了具备查询功能，IP Location Finder网站还会提供关于IP地址及其相关概念的常识介绍。

   7.Best Trace 

国内用户最常用的应该还是ipip.net提供的Best Trace工具，ipip.net是一个IP查询网站，数据库是基于BGP/ASN数据分析处理而得来的IP库，非常准确可信。Best trace除了提供基本的查询功能外，还附带地图，为用户提供直观的视觉效果。

   8. What Is My IP Address.com 

What Is My IP Address.com是一个提供互联网协议地址查询和设置的网站。该网站提供的服务有IP查找、黑名单检查、电子邮件追踪、互联网速率测验、隐藏IP和改变IP等等。

   9. Trace My IP.org

TraceMyIP.org是一个高级的在线网站访问者统计，地址追踪和网站流量分析站点，使用了美国马萨诸塞州私有电脑实验室开发的专用技术为客户提供服务。

它是一个非常可靠的服务网站，严格依照相关条款执行网站访问者网址查询和追踪任务的工具，不会利用任何恶意代码，导致网站受到安全威胁或者隐私提醒，而且配备了反垃圾工具和杀毒软件都可以使用。用户不会从网站收到任何的垃圾邮件，或者广告信息等。网站的访问者追踪服务是与所有的服务系统都兼容的，甚至对与一些移动设备都是非常实用的。

此外，由于设计的网站统计数据分析软件和电脑数据储存是在TraceMyIP.org 的专用服务器上托管的，为此，它不会占用宽带的利用率。TraceMyIP.org电脑基础设施中的重要处理器将会支持整个网站的流量分析。

用户可以使用以上网站提供的任何一个工具来跟踪IP地址，有些工具提供了一些更为高级的功能（付费和免费两种版本）来适应您的各种需求。如果您有其他任何高效的IP地址查询工具，欢迎在评论区与小编分享。
