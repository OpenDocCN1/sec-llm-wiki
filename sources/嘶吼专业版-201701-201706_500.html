2016年已经在新年钟声敲响之后正式结束了，而在对2016年所有的漏洞进行归纳总结后我们发现，在过去的一年里Android系统毫无疑问的成为了漏洞最多的产品，而 Oracle则成为了曝出最多漏洞的产品供应商。

这一情况主要是基于安全漏洞研究人员们在过去一年所曝光的CVE进行的统计。


Android成为2016年最不安全的产品

根据一个针对CVE漏洞进行安全漏洞数据收集网站的细节描述，在2016年安全研究人员共发现以及曝光了523个谷歌Android操作系统的漏洞，也因此赢得了产品漏洞最多“奖项”。

排名第二的是Debian Linux ，它被爆出了319个安全漏洞。第三的则是Ubuntu Linux ，其共有278个漏洞。剩下的有Adobe Flash Player(266个BUG),openSUSE Leap(259个BUG),openSUSE(228个BUG),Adobe Acrobat DC（227个BUG),Adobe Acrobat ReaderDC(227个BUG),Adobe Acrobat(224个BUG),Linux内核(216个BUG)。

而2015年的冠军Mac OS X今年以215个安全漏洞排名第11位，去年这一数字则是444个。

之前的情况则是如下：

Apple Mac OS X in 2015 (444 bugs)

Internet Explorer in 2014 (243 bugs)

The Linux Kernel in 2013 (189 bugs)

Google Chrome in 2012 (249 bugs)

Google Chrome in 2011 (266 bugs)

Google Chrome in 2010 (152 bugs)

Mozilla Firefox in 2009 (126 bugs)

Mozilla Firefox tied with Apple OS X in 2008 (96 bugs)

PHP in 2007 (114 bugs)

Apple OS X in 2006 (106 bugs)

Linux Kernel in 2005 (133 bugs)

Internet Explorer in 2004 (59 bugs)

Solaris OS in 2003 (44 bugs)

Internet Explorer in 2002 (54 bugs)

RedHat Linux in 2001 (47 bugs)

RedHat Linux again in 2000 (47 bugs)

Windows NT in 1999 (64 bugs)


Oracle成了最不安全的产品供应商

当我们对软件供应商进行一个分析后发现，Oracle 公司所获得的新CVE编号漏洞最多，高达798个。其中的大多数漏洞集中在Oracle的几个产品,如MySQL,Solaris,以及其定制Linux操作系统版本上了。

紧随Oracle其后的是谷歌，他的漏洞则主要集中在Android和Chrome，第三则是Adobe，共有548个漏洞，多数集中在Flash Player上。剩下的十大是微软(492),Novell(394),IBM(382)、思科(353),苹果(324),Debian项目(320),和Canonical (280)。
