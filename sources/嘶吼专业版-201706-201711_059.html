 iPhone X的面部识别真的安全吗？

在对硬件的完美追求中，苹果似乎一直都在寻找简化操作和确保安全两个方面的平衡，虽然六位数的数字密码已经足以让小偷无法通过随意猜测而简单破解，但在苹果看来，这样的输入方式仍然不方便，而近期市场上普及的的TouchID指纹识别技术虽然实用，不过显然，一向追求完美的苹果还是不太满意，随着这款没有Home键的全面屏旗舰机iPhone X的高调推出，果粉们才发现，苹果采用了更加的智能的人脸识别技术作为密码和指纹的替代品，而这也成为了这部iPhone X手机的超大亮点。

通过这项FaceID人脸识别技术，你只需要看着手机屏幕就可以在一秒钟内实现手机解锁功能，而除了锁屏功能，FaceID还在苹果的应用商店中实现了整合，这意味着无论是下载APP还是Apple Pay支付功能，凡是需要安全验证的地方都可以用到FaceID人脸识别功能。苹果的执行官Phil Schiller在主题发布会上也表示：

通过iPhone X，你需要看着这部手机，它就会自动识别你并迅速解锁，相比之前任何方式都显得更简单，自然且毫不费力，这也将成为我们解锁手机和保护敏感信息的未来技术。

不过在近几年来，虽然许多技术公司都在研究人脸识别技术，不过多次的实验都证明这种方法其实很容易被破解，在2009年，研发人员就利用打印的人脸照片成功蒙骗了用户笔记本的人脸识别登录系统，而在2015年，流行科学作家Dan Moren也通过一段录制的会眨眼的人脸视频成功骗过了阿里巴巴的人脸识别系统。那么苹果此次推出的iPhone X是否也会遇到同样的难题呢？

在网络上很多人做过实验，最简单的莫过于双胞胎实验，而目前测试的仅有一对双胞胎测试解锁成功，可见人脸识别并非绝对的安全。

安全公司用面具成功瓦解iPhone X的Face ID 

除了双胞胎解锁外，近日，来自越南安全公司Bkav的研究人员表示，虽然苹果公司试图阻止这种利用面具的欺诈行为，但是他们可以通过使用专门构建的面具成功挫败苹果的人脸 ID 识别系统。

Bkav公司为了挑战苹果公司的面部识别技术，而专门构建了这样一款面具：该面具是通过将3D打印与化妆和二维图像向结合，用手工制作的“皮肤”，3D 打印产生的人脸模型（包括雕刻的硅胶鼻子），其他部分（如眼睛、嘴唇）属于2D 图像，以此来成功欺骗iPhone X的面部识别功能。据Bkav公司介绍，整个面具的制造成本约在150美元左右（其中不包括现成的3D打印机）。

根据该公司上传到YouTube上的演示视频显示，公司的一名员工使用这款特制的面具面对iPhone X，手机即刻便解锁成功。虽然目前尚不清楚Bkav在制作一个可以流畅运行的面具之前经历了多少错误。该公司表示，11月5日开始进行面具工作，所以完成这个项目大概花费了5天的时间。

影响分析

不过，大家也不用过分恐慌。因为Bkav也承认，他们的技术需要对目标iPhone所有者的脸部进行精确的测量或数字扫描，此外，制造面具也涉及非常复杂的工作，普通用户很难实现。所以，这种欺诈手段多被用于高度针对性的间谍活动领域，而不是像大多数iPhone所有者可能面临的那种普通的黑客行为。

Bkav的研究人员说道，

这种威胁的潜在目标不应该是普通的用户，而可能是亿万富翁、大型企业的领导人、国家领导人以及联邦调查局等具有高价值数据的人群，如此才值得花费长达数天的付出。

最后，Bkav公司还警告称，

虽然经过了近十年的发展，人脸识别技术还是不够成熟，不足以保证电脑和智能手机的安全。早在2008年，Bkav就已经成为第一家站出来表示‘东芝、联想以及华硕等公司使用的这种技术（人脸识别）对笔记本电脑而言并不是有效的安全措施。’

事实证实，Phone X的Face ID似乎并不像苹果所说的那样是一个有效的安全措施，人脸识别技术还有很长的路需要走。
