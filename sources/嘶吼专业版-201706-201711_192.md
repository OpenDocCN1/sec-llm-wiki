# 勒索软件也有“流氓版”：想要解锁电脑，请交出你的裸照！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247485720&idx=2&sn=2f0acd4e26382aed19fea467083414da&chksm=e916d922de61503433d53f8e3eaeb3f1ecf3dd938bcba981c438025643c1baf258c81309d656&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247485720&idx=2&sn=2f0acd4e26382aed19fea467083414da&chksm=e916d922de61503433d53f8e3eaeb3f1ecf3dd938bcba981c438025643c1baf258c81309d656&scene=27#wechat_redirect)

提到“勒索软件”你最先会想到什么？“WannaCry”、“勒索”、“赎金／比特币”……确实，大多数的勒索软件都会要求受害者通过支付一定的赎金（而且通常为比特币等加密货币）来解锁文件。但是据外媒报道称，近日出现了一款特立独行的“流氓”勒索软件，其索要的不是财物而是受害者的裸照。

![](../Images/90a35f7f524ddce54add53015d9aea56.png)不爱金钱爱裸照的“另类”勒索软件

据悉，来自MalwareHunterTeam的一名研究人员率先发现了这种名为“nRansomware”的勒索软件，并在网上展示了该勒索软件的赎金通知屏幕截图。该赎金通知显示，勒索者要求受害者交出自己“裸照”作为赎金来换回对自己电脑的控制权。信件中还有一段简短的提示，告知受害者如何将照片发送给勒索者。

nRansom的勒索通知信息大致如下所述：

![](../Images/b3f8bba3f09dc5253eaa5442b1d0fb06.png "undefined")

你的电脑已经被锁定。你只能使用特制的解锁密码才能完成解锁，请转到protonmail.com并创建一个帐户，发送电子邮件至1\_kill\_yourself\_1@protonmail.com。我们可能没有办法立即回复你，但当我们回复之后，你必须发送至少10张裸体照片给我们。之后，我们将会验证这些裸照是否真的属于你本人，验证成功后，我们才会为你提供解锁密码，并在深网（deep web）出售这些照片。

![](../Images/e449db7dc52d85ced7b3721fa56122dd.png "undefined")

一旦勒索软件程序（nRansom.exe）被执行，它将显示一个蠢萌的锁屏界面，界面上是《托马斯和他的朋友们》的剧照，同时还会显示索要“裸照”的勒索通知，以及播放名为“your-mom-gay.mp3”的音频文件。

![](../Images/651cdf70ad8f1e7c6eb851e19fcfa263.png)

事实上，这并不是一款真正意义上的勒索软件，而是一个简单的电脑锁屏工具，你只需要输入代码就可以解锁屏幕。此外，想要终止锁定的话，你还可以通过手动最小化屏幕，然后在任务管理器终止进程nRansom.exe进程既可。

不过，还是不免会存在一些不知情的受害者会选择发布自己的裸照来解锁，所以谨以此文广而告之，切勿上了勒索者设计的陷阱，毕竟裸照流入暗网后，一切都将无法挽回！
