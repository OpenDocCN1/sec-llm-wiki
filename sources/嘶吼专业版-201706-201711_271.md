搭建一个FFMPEG任意文件读取漏洞靶场，可用于漏洞练习或者攻防题目。

![](../Images/17353b00c408781e8f3f6709e108fe94.png)2\.  Win2003下复现FFMPGE任意文件读取漏洞

最初想法：优先尝试了win下复现FFMPEG任意文件读取漏洞。

![](../Images/d66ade2aa4b734f08e1ea0e28271b36a.png)

结果在WIN上搭建FFMPEG，出现补丁报错的情况。

![](../Images/fc84a8bfde850c8b35944019e7ddf6be.png)

找到解决办法，安装如下补丁：WindowsServer2003-KB914961-SP2-x86-CHS，地址：https://www.microsoft.com/zh-cn/download/details.aspx?id=41。

解决后可以正常运行ffmpeg并实现视频、图片等文件的格式转换，但问题由来了。 Windows下无法复现ffmpeg任意文件读取漏洞，原因如下：ffmpeg任意文件读取漏洞payload中需要利用类似linux中的/dev/zero的空文件进行对数据进行读取和不断的写入。Win下不存在这种文件或者功能。尝试修改payload无果，最后没能在win下复现该漏洞。

![](../Images/511ce80cf37150be1ddc151defcf9bd8.png)

![](../Images/17353b00c408781e8f3f6709e108fe94.png)3\.  Linux下复现FFMPGE任意文件读取漏洞

那么，先搭建LAMP环境。

Ø  安装&修复PHPmyamdin报错

 sudo apt-get install phpmyadminsudo cp /usr/share/phpmyadmin /var/www/html -a

通过apt-get安装的phpmyadmin可通过sudo dpkg-reconfigure phpmyadmin解决报错问题。

![](../Images/17353b00c408781e8f3f6709e108fe94.png)6\.  解决Wordpress配置访问IP问题

本以为大功告成了，结果又遇到了一个坑。wordpress在安装时会向数据库中写明站点URL，在站点迁移或者想同时部署多个靶机时，会出先因为IP地址和URL地址不一致问题，导致无法正常使用。如原始服务器IP为192.168.222.13。当站点被迁移到其他机器，服务器IP变更为192.168.222.133时候，你再访问http://192.168.222.133/便会出现如下情况：站点无法正常显示，而且很慢。

![](../Images/64025875c0ff06180f609182fe694156.png)

访问后台地址http://192.168.222.133/wp-admin/，网站会自动跳转到初始配置IP。

http://192.168.222.133/wp-login.php?redirect\_to=http%3A%2F%2F192.168.222.13%2Fwp-admin%2F&reauth=1

![](../Images/049cd7a39dc80b346325647bff0327c6.png)

这样肯定不行呀，怎么解决楠？

参考了网上提供的方法，不太实用需求，这里也说下吧。对于个人的站点，可通过进入后台修改（此方法不适用于黑盒实验）

WordPress支持自动重定位方法，该方法可自动计算定位并更新定位值。将网站从一台服务器重新定位到另一台服务器上时，该方法能够快速协助网站开始运行。用法如下：

1.、编辑wp-config.php 文件，在“define”语句后添加如下代码：define('RELOCATE',true); 

![](../Images/a4bf29d4005a466e992a718d2e1ff5b0.png)

2、 在web浏览器中访问wp-login.php页面，进入后台可更改配置IP：

![](../Images/237ec03f5f338072fcc59a5967e0c54b.png)

后来仔细想想，既然配置文件写在数据库中的，那么我完全可以通过动态修改数据库中的数据达到修改IP的目的。过程如下：

在首页包含的代码中增加一条语句自动更新数据库中的URL地址，这里我选择了wp-blog-header.php，只要有人访问网站就会执行这条语句，获取服务器IP并修改配置IP的字段。

![](../Images/44bfe016abd7a5fcfae46d0bf1eaf12e.png)

 $iipp=$\_SERVER\['SERVER\_ADDR'\];$sql1="UPDATE   \`wordpress\`.\`wp\_options\` SET \`option\_value\` = 'http://".$iipp."'   WHERE \`wp\_options\`.\`option\_id\` = 1;";$sql2="UPDATE   \`wordpress\`.\`wp\_options\` SET \`option\_value\` = 'http://".$iipp."'   WHERE \`wp\_options\`.\`option\_id\` = 2;";mysql\_query($sql1);mysql\_query($sql2);

修改后，便能自动修改后台中的URL。

![](../Images/69643ad0e8f70534052d7c49aaf7c31b.png)

这样一来就可以随意更改服务器IP了。
