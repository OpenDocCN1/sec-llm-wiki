# 世界上最大的两个暗网市场 AlphaBay 与 Hansa 相继被关闭，创办者自杀

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247485264&idx=1&sn=456c90acae139f9aa0ffb6086a6db092&chksm=e916d76ade615e7c7dbd521251021a190bd248610c9e1be9ee8ef521f7c44101ab39f7ab5aff&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247485264&idx=1&sn=456c90acae139f9aa0ffb6086a6db092&chksm=e916d76ade615e7c7dbd521251021a190bd248610c9e1be9ee8ef521f7c44101ab39f7ab5aff&scene=27#wechat_redirect)

7月20日，欧洲刑警组织和美国联邦调查局、美国缉毒署以及荷兰国家警察局携手关闭了Hansa暗网市场，随着7月4日AlphaBay被关闭，世界上两大暗网就彻底被端掉了。截至目前，它们已为成千上万的客户提供非法服务，帮助他们在线买卖违法商品。

此前最出名的比特币暗网交易平台“丝绸之路"于2013年被FBI取缔后，在2014年，AlphaBay黑市就在暗网中出现，尽管类似的网站不断倒闭，但是AlphaBay的知名度以及人气却在不断上升，AlphaBay外号为“暗网Amazon”，此前允许用户以匿名的方式用比特币交易毒品、武器、黑客工具和其他非法商品。

根据欧洲刑警组织的说法，在关闭前，Alphabay上非法药品和化学品的交易条目超过25万个，失窃身份证和信用卡数据的交易条目超过10万个。根据克里斯坦的研究，卡内基梅隆大学（Carnegie Mellon University）教授尼古拉•克里斯坦（Nicolas Christin）的调查，Alphabay上每天的交易规模在60万美元到80万美元之间，差不多是当时“丝绸之路"的两倍多。

而Hansa黑市则是全球第三非法商品的网上集市，根据欧洲刑警组织的说法，荷兰官员在6月底首次获得了Hansa的控制权，并继续隐秘地运营该集市，并收集有关其用户的数据。

随着Alphabay被关闭，许多用户转移至Hansa，这让荷兰当局收集的情报变得更有价值。根据荷兰警方的估计，Hansa的卖家数量从不到1000名迅速增长到10000多名，马上成为暗网中最大的交易黑市，光荷兰当局就收集了超过1万个Hansa用户的地址。　

与“丝绸之路"及AlphaBay不同的是，Hansa市集并未销售军火或儿童色情，主要是以违禁药物为主。

![](../Images/4a5eaafcc1bdf559f82f255c8a8abdfc.png "undefined")

在华盛顿的一个新闻发布会上，美国司法部长塞申斯（Jeff Sessions）表示：“我相信，由于此次行动，美国人民的网络活动会变得更安全，免受身份欺诈、恶意软件以及致命毒品的威胁。”

谈到了执法机构面临的新挑战，塞申斯表示：“这些犯罪组织认为它们可以通过暗网不受惩罚而实施犯罪，而此次协调行动对全世界的贩毒和其他犯罪行为造成重创。”

![](../Images/893fb5d5eab546543c36f62cd29638bd.png "undefined")

有消息说， Alphabay创办者、在泰国过着奢侈生活的25岁加拿大人亚历山大-卡兹（Alexandre Cazes），已与上周在狱中自杀身亡。
