SSH隧道：隧道的概念是将一种网络协议封装在了另外一个协议里面。这里我们是将这些通讯协议放到了ssh协议里面，所有的流量都是加密的。由于隧道协议传输涉及将流量数据重新打包为其他格式的内容，于是打包前进行加密可以有效的防止数据丢失或窃取，并且通信过程和传统隧道相比是非常隐蔽的。  

SSH隧道的种类：  

 1. 动态SSH隧道

2\. 本地SSH隧道

3\. 远程SSH隧道

让我们开始今天的内容吧～  
目的：建立远程PC和不同网络的本地系统之间的SSH连接。

我已经搭建好了实验环境，在以下网络中包含三个系统：  

 SSH 服务端(两个网卡):

IP 192.168.1.104 和远程系统连接

IP 192.168.10.1 和本地网络192.168.10.2进行连接。

SSH 客户端:

IP 192.168.10.2远程系统(不在内网当中)

在左边框选择SSH->Tunnel项目，然后在源端口上填写7000，类型选择动态连接，然后点击添加。

![](../Images/b0942bde456c7f50e3a9f9be416d4b25.png)

![](../Images/9564cc3a047e729cea1c5f626b1f781c.png)

打开之前putty运行的窗口，在Proxy(代理模块)进行如下操作：

 ssh -D 7000 ignite@192.168.1.104

输入完这条命令之后会提示你输入登录密码，如下图：

![](../Images/3b9fdd263fbc0b61c0d696fde0d78e40.png)

接下来就是设置网络代理了：  

 打开浏览器中的网络代理板块，选择手动设置代理，然后开启SOCKS v5。

![](../Images/6366c87cfd52c006c07b482a584adae9.png)

于是我们通过浏览器就可以访问到了内网机器192.168.10.2的80端口。

  

![](../Images/472a3f2f35cc32696d8dea84a4e19e27.png)

![](../Images/15b455afcee67493c4af27eb6c7b05b3.png)在22端口上通过kali linux进行动态ssh隧道建立

用下面命令与SSH服务端进行连接：

![](../Images/d754052a9d091b56377e361e91ece074.png)

通过apt安装tscoks:  

 apt install tsocks

tsocks是用于拦截传出网络的连接，并且将所有连接都进行socks服务重定向的库。

![](../Images/325fd9adc6381d383692476db6ae75cd.png)

打开tsokcs.conf文件编辑socks服务器的IP以及端口，在我们这种情况下，我们需要添加下面两行代码，然后保存就可以了。

 Server = 127.0.0.1Server\_port = 7000

![](../Images/4ade2eb206b991c5ca30b7ad9f628f49.png)

现在我们通过代理就可以连接到SSH的客户机:  

 tscoks ssh raj@192.168.10.2

输入密码就可以好好享受SSH隧道带来的乐趣了～

![](../Images/15b455afcee67493c4af27eb6c7b05b3.png)在windows下进行本地隧道建立

本地隧道是访问特定SSH客户机进行通信的过程。他可以允许你连接到没有在互联网上的机器。  
远程隧道和本地隧道的唯一区别就是:动态隧道需要SOCKS代理进行传输TCP流量，本地隧道只需要目标的IP地址就可以进行传输。  
本地SSH转发过程：  
使用putty通过22端口连接到SSH服务器(192.168.1.104)，在左侧菜单中选择SSH转发。

![](../Images/6d39661765c34d6bc6836b6233c3a6a4.png)

将源端口填写为7000，连接种类为本地  
目的地址为102.168.10.2:22，点击添加  
当所有步骤都进行完毕之后就可以点击OPEN

![](../Images/57c04c3cd0ee993baf7b861b2b6a3054.png)

首先他会将远程PC和SSH服务端进行连接。

![](../Images/ef87bb6b1ce53d7ecb37616dda9e89e3.png)

再重新打开一个putty界面，进行以下步骤：  
主机名填写localhost，端口填写7000，连接类型：SSH  

点击OPEN进行连接

![](../Images/b9c08c184b2b701f8a92bfa42db4949b.png)

我们成功的通过7000端口连接到了SSH客户机

  

![](../Images/af439c4d019231888284262528c6047b.png)

**通过Kali Linux进行本地SSH隧道建立**

现在切换到Kali Linux来进行本地SSH转发，和动态转发相比，这一过程是非常简单的。在本地机器上执行以下命令：  

 ssh -L 7000:192.168.10.2:22 ignite@192.168.1.104

![](../Images/e943053314f0eccdb2df04bd575a065d.png)

再重新打开一个终端，输入下方命令访问SSH客户端：  

 ssh raj@127.0.0.1 -p 7000

我们可以成功的通过7000端口连接到了SSH客户机。

![](../Images/0cbf5b5eb2cd5de2c15ef82e8b849919.png)

![](../Images/15b455afcee67493c4af27eb6c7b05b3.png)通过Putty进行远程SSH隧道

远程隧道是用于当客户机想要访问不在本地网络的远程系统时起作用。  
首先我们需要在SSH服务端(ignite)安装putty，然后进行以下步骤：  
输入远程系统的IP 192.168.1.108  
连接端口：22  
访问SSH->转发模块

![](../Images/289f886708e189724977476b9486bf7a.png)

在源端口中填写7000，连接类型为远程连接  
目的地址为192.168.10.2:22  

当所有步骤进行完毕之后点击open进行连接：

![](../Images/4459b43067cba44d91e6e61ee4b51852.png)

现在我们已经连接到了远程系统：

![](../Images/26aadf3867a1bfc4778ccab180c9d37e.png)

继续回到远程系统，执行以下命令：  

 ssh raj@127.0.0.1 -p 7000

从下图中可以看出，我们已经通过7000端口与SSH客户机成功通信:

![](../Images/9d5f3fcd2b7bbb63074ed31b0170dfae.png)

![](../Images/15b455afcee67493c4af27eb6c7b05b3.png)通过ubuntu进行远程SSH隧道

如果你不喜欢使用putty进行远程隧道,你可以执行下面命令：  

 ssh -R 7000:192.168.10.2:22 root@192.168.1.108

192.168.10.2是我们本地客户机(raj)的IP，102.168.1.108是远程系统的IP。

![](../Images/3b931e02aa19f15c063d6df3a98f3aeb.png)

在远程系统中执行下面命令,就可以与SSH客户机进行连接：  

 ssh raj@127.0.0.1 -p 7000

如下图，就可以看到已经成功建立：
