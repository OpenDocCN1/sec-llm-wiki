# 安全堪忧！全球最大比特币交易所Bitfinex遭到DDoS攻击，API瘫痪！

近日，据外媒报道称，全球最大的加密货币兑换商Bitfinex于本周二（12月12日）遭遇分布式拒绝服务（DDoS）攻击，导致该公司当天不得不关闭了其所有交易服务。据悉，这已经是近期以来Bitfinex遭遇的第二次DDoS攻击了，让业界对比特币交易的安全性深感担忧。

其实，随着比特币价格的不断攀升，比特币交易所成为攻击者的重点攻击目标也是不出所料的事情。

所谓“分布式拒绝服务”攻击（或DDoS攻击）是指借助于客户/服务器技术，将多个计算机联合起来作为攻击平台，对一个或多个目标发动DDoS攻击，从而成倍地提高拒绝服务攻击的威力。虽然目前Bitfinex公司对攻击来源尚不知晓，但是可以百分百确定的是，此次攻击是一场有针对性的故意攻击行为。

针对此次攻击事件，总部位于香港的Bitfinex回应称，

![](../Images/b25ede8172a90356ccbe316694e19a4c.png "undefined")

这次攻击是近几周以来的第二次，只是这一次我们遭遇的是更大规模、更高强度的DDoS攻击，公司的API也陷入瘫痪状态。目前我们正在努力研究解决方案来迁移交易流量以保护客户的订单安全，进一步缓解受损情况。

![](../Images/c667b04d72cffb6793c8994f9d1eaa32.png "undefined")

实际上，Bitfinex在过去几天里一直处于严重的拒绝服务攻击之中，只是这次攻击强度明显增加了，致使API瘫痪，业务服务全面停止。

据悉，就在此次攻击发生前的12月11日晚上，美国证券交易委员会（SEC）就曾警告称，加密货币存在“被盗窃或损失，包括黑客攻击”等重大风险，尤其是那些缺乏保护措施的加密货币交易所。

美国证券交易委员会（SEC）主席杰伊·克莱顿（Jay Clayton）周一警告称，

![](../Images/b25ede8172a90356ccbe316694e19a4c.png "undefined")

这些加密货币交易市场一般都是跨越国界的，所以在美国以外的系统或平台上发生重要的交易活动都是很常见的，所以说，你的投资资金可能会在你不知情的情况下流出境外，因此投资风险也就可能随之扩大了。这种情况下，如果发生资金失窃情况，即便是市场监管机构——如美国证券交易委员会也可能无法有效地帮你追捕到窃贼或是追回失窃资金。 

![](../Images/c667b04d72cffb6793c8994f9d1eaa32.png "undefined")

这一警告，至少在比特币期货市场上得到一定程度的反映。周二，Cboe期货交易所比特币期货合约交易量大幅下跌，这是该期货第二日上市交易（周一发行）。

截至美国东部时间周二上午10点，Cboe期货交易所比特币期货交易量为615份合约，这意味着交易价值约为1100万美元（基于上月同期一份合约18000美元的价格得出）。而在周一，比特币期货交易量约为4100份合约，交易价值约为7380万美元。根据CoinDesk提供的数据显示，周二比特币的价格为16975美元，比特币下跌约1.1%。

其实，早在2016年的8月2日，比特币交易所Bitfinex就曾经遭遇过一次巨大的“灾难”。当时由于遭受网络黑客的DDOS攻击，Bitfinex总计有119，756枚比特币被盗，按当时的行情算，折合约7000万美元。

如今，针对比特币平台的攻击活动日盛，相关机构还需加强重视和强化防护措施，避免进一步激化比特币投资者的恐慌情绪，造成无法挽回的损失。
