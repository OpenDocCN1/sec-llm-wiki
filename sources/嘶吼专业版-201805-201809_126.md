# 第四届互联网安全领袖峰会三大亮点曝光 揭秘网络安全顶级峰会

第四届互联网安全领袖峰会（Cyber Security Summit,简称CSS2018）将于8月27-28日在北京昆泰酒店（望京）举办，本届峰会将以“安全强驱动，数字新生态”为主题，以两大圆桌会议为主、九大分论坛为辅，邀请国际顶尖极客先锋共商数字安全技术新趋势，共建强阵容、高水准的领袖交流平台。  

在安全环境的复杂变化的背景下，除论坛主题讨论外，CSS2018还将针对十大年度安全议题，以全球安全事件、国际趋势为中心，揭示出2018年度网络安全界发展的新风向。

![](../Images/080e0b903ced2d89610e62cf3c427900.png)

![](../Images/1b6e4cd185a1540eef021af956832d24.png)2018年度十大安全议题首发 揭示全球网络安全新风向

从2015年起，CSS每年都将综合全球安全产业趋势，从世界范围内搜集十大年度安全议题。今年，伴随着更多全球安全事件的发生，CSS共总结出2018年度最具前瞻性的十大全球安全议题，代表全球顶级极客思维揭示网络安全发展的新风向。

在欧盟推出最严格《通用数据保护条例》、特朗普废除“互联网中立原则”的大环境下，CSS2018将聚焦全球网络安全格局，以国际安全形势新变化为讨论议题，在“一立一废”的变革中找到立身的应对措施。而在产业政策、技术风向等方面，CSS2018将针对国内外硬件设施新局势，将基础设施保护政策、超大型技术设施保障通信网络安全两大议题推上议论风口。

此外，在未来互联网安全的趋势探讨方面，CSS2018也将提出AI技术、安全日常性需求，安全联盟体系等三大分支，从构想蓝图与发展趋势出发，探讨规避互联网安全风险的新路径。

![](../Images/15b455afcee67493c4af27eb6c7b05b3.png)四大顶尖极客首日亮相 两大圆桌会议聚焦未来安全变革

2017年，世界头号传奇黑客凯文·米特尼克首度来华，在CSS大会上分享了作为世界头号黑客的传奇人生，引来安全技术拥趸们的强烈关注。今年，出席嘉宾量级不减，不仅囊括国际上知名度颇高的极客先锋，还包括行业内极具发言权的学术大咖与企业领袖，堪比世界顶级安全会议的嘉宾规格。  

值得一提的是，来自国内外的四大重量级嘉宾将在首日亮相，并分别代表各自专攻领域进行发声。其中，出现在《达·芬奇密码》的信息安全巨擘Bruce Schneier此次将聚焦物联网漏洞，在中国首度披露其新作中关于智能设备安全隐患的相关议题；在当前正热的“车联网入侵”恶意攻击方面，汽车黑客开山鼻祖Charlie Miller将针对自动驾驶与汽车网络安全，提出面对挑战应有的安全构架设想；而作为最早破解GSM网络加密算法的白帽黑客，新兴IT威胁终结者Karsten Nohl将围绕“GSM劫持+短信嗅探”技术进行分享；在未来安全趋势方面，颇受国人瞩目的“华人之光”、中国科学院王飞跃教授则将针对目前大众关注的“平行世界”问题，引入研究者思维进行超前理论探讨。

![](../Images/45c88305037399ab2aa831b420ec3071.png)

除发表演讲，四大重量级嘉宾还将参与两大圆桌论坛，为未来网安问题出谋划策。如今，安全不仅是互联网发展的保障，更逐步成为其发展的基础所在，探讨未来安全边界，已成为国际网络安全的新焦点。鉴于此，CSS2018两大圆桌会议将分别以“数字新生态下未来世界的安全边界”“以极客之名论未来安全之道”为主题，以未来安全、安全边界等前沿议题为基点，共商网络技术、格局、政策方面的安全之道。

![](../Images/15b455afcee67493c4af27eb6c7b05b3.png)九大分论坛全新升级 搭建网安尖端交流新平台

作为网络安全新生态的首创平台，CSS2018将推出九大分论坛，拉动全行业视线聚焦安全领域最前沿动态。升级后的九大分论坛共包括TSec腾讯安全探索论坛、P16基础设施安全领袖圆桌、金融安全分论坛、人工智能安全分论坛、AE50安全产学研分论坛、云安全分论坛、工业互联网安全分论坛、FP50 安全新锐力量分论坛以及数字支付安全分论坛，讨论领域囊括最前沿、最尖端的新兴技术，以及互联网安全最新发展可能性趋势，代表了前沿科技的最新探索成果。  

其中，腾讯安全探索论坛（TSec）不仅邀请了腾讯安全玄武实验室负责人“TK教主”于旸等国际顶尖安全技术精英，还将针对目前最具含金量的云安全、物联网安全等安全技术，为全球信息安全的发展提供技术创新支持。同样作为九大论坛之一的P16基础设施安全领袖圆桌，也将聚集国内安全上市企业全部力量，围绕信息安全技术、产业、战略等维度进行深入合作，致力于推动网络安全产业的全面升级。

如今，大数据、云计算、AI等新技术不断进入人们的日常生活，数据安全隐患也逐步浮现。在网络背景日益复杂的今天，网络安全已成为数字时代所有0前面的1，是基础，是保障，更是网络健康发展的前提和基础。CSS2018的召开，有助于搭建一个新锐安全企业、专家、媒体、创投圈共同交流的平台，将当下及未来的安全议题以智慧碰撞的形式逐步输出，为网络安全的发展与稳定提供解决之道。
