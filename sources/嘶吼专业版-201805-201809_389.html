腾讯安全探索论坛:国际前沿安全技术研究“首发地”

腾讯安全探索论坛(TSec)是腾讯安全打造的一个全球前沿、尖端安全技术的高质量安全信息交流平台,也是中国互联网安全领袖峰会(Cyber Security Summit,简称“CSS”)的重要组成部分。TSec聚焦当前最具含量与亮点的云安全、移动安全、物联网安全以及人工智能等多领域的安全技术,为全球信息安全的发展,提供学术和技术创新支持。 TSec不仅仅是一个全球信息安全领域尖端技术展示与未来趋势探讨的盛会,更是作为全球前沿技术首发地的真正开端,TSec将为加速技术创新、共享重要技术成果持续提升连接价值,搭建一个长期、持续的沟通合作平台,让更多国内外尖端安全研究、前沿安全技术在这里汇聚。 

TSec2017:含金量比肩BlackHat 十大议题带来国际安全新视角

作为全球前沿、尖端安全技术的首发平台,首届腾讯安全探索论坛(TSec)以“安全新探索”为主题,云集了来自谷歌、McAfee、腾讯安全玄武实验室、腾讯安全科恩实验室、清华大学、上海交通大学等国内外互联网巨头的安全技术精英和顶尖学府的专家学者,在TSec现场悉数展示了各自在信息安全领域具有首发性、独创性的尖端技术。演讲议题涵盖机器学习与网络安全、工控系统开发、操作系统漏洞攻防、纯数据技术来劫持只读内存并绕过内存缓解措施、电信设备与IoT安全、新型移动安全威胁模型等当下信息安全领域炙手可热的研究方向,共同探讨全球信息安全领域前沿技术、研究成果及未来趋势。 

TSec2018:重磅评审团 为你揭晓“极客琅琊榜”

今年第二届TSec将以“极客琅琊榜”为主题,邀请腾讯安全玄武实验室负责人“TK教主”于旸、腾讯安全湛泸实验室负责人袁仁广等众多顶尖安全技术精英,共同针对新时代的信息安全发展需求,谋求信息安全技术的新机遇和新思路。我们诚邀全球信息安全领域的研究者针对“网络安全攻防”相关议题参与投稿,议题入选者将在现场与国际顶尖安全技术专家进行深入探讨和对话。所提交的演讲议题经组委会确认通过,并在CSS 2018 TSec峰会发言后,经过专家团、媒体团、观众团进行现场打分,最终公布“极客琅琊榜”,榜单得主共享22万奖金。

关于CSS

中国互联网安全领袖峰会 (Cyber Security Summit,简称“CSS”)是由腾讯公司、中国电子技术标准化研究院、中国信息安全认证中心共同创办,得到了国家网信办、工信部、公安部等国家部门的大力支持和指导。峰会始终致力于聚合互联网产业领域与网络安全行业的力量,共筑“互联网产业安全交流与合作平台”,共建“互联网安全新生态”,进而推进产业快速、稳定创新,为国民经济的升级转型和蓬勃发展做出贡献。峰会更致力于聚合国内外安全企业、传统行业、媒体等,共商网络安全的未来,现已成为行业发展的风向标。
