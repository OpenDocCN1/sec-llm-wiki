# 唯品会2018电商安全峰会 共探信息安全防护新生态

5月5日，由唯品会信息安全部主办，唯品会安全应急响应中心（VSRC）承办的2018“因唯安全，所以信赖——唯与同行，智御未来”第三届唯品会电商安全峰会在上海召开。本次大会邀请了9位知名互联网企业安全领域技术专家，围绕信息安全漏洞防护、云安全、安全网关等一系列用户最关心的核心安全话题进行主题演讲，为到场参会的400余位行业同人奉献了一场行业盛宴。  

![](../Images/c10d63e0624b3dcf4888939d82d98b85.png)

2018年唯品会第三届电商安全峰会现场图

唯品会首席技术官黄彦林表示，“网络安全生态圈需要社会各界的共同支持，我们希望凝聚各方面的力量，从不同角度分析判断网络安全问题，分享他们的安全技术和产品领域的经验，并与唯品会一起，将这种安全能力输出给生态圈内的每一个用户，这也是唯品会VSRC（Vip Security Response Center）成立的初衷。”

![](../Images/47489403e1e3269319fcae98bf4a7834.png)

唯品会CTO黄彦林博士演讲现场图

![](../Images/15b455afcee67493c4af27eb6c7b05b3.png)携手9位网络安全行业大咖共话电商信息安全新形势

唯品会电商安全峰会自2016年至今已经连续举办3届，此次将继续秉持“技术分享、深度探讨、经验交流、前景共望”的初衷，在展示近一年来唯品会在电商信息安全建设的重要环节及关键阶段的实践与收获的同时，探讨电商信息安全建设的进一步举措。

会议期间，唯品会信息安全专家朱应龙、唯品会金融大数据部主任卢铮等人分别就数据安全、风控产品与产品风控、设备指纹、信息反欺诈等等方面进行了经验分享。

腾讯安全应急响应中心TSRC负责人钟武强分享的腾讯通用型漏洞应急响应系统、京东资深研发工程师寿如阳展示的虚假交易识别系统等全新安全技术都为消费者的互联网电商安全提供了强有力的保障，也为互联网行业同仁提供了宝贵的经验。

此外，国内大型企业应用安全专家钟卫林、千寻位置信息安全部负责人傅奎、猪八戒网的安全技术负责人资深安全工程师齐迹等人也分享了他们在相关领域的心得和经验。

![](../Images/15b455afcee67493c4af27eb6c7b05b3.png)唯品会全面深化信息安全壁垒建设

2015年，唯品会安全应急响应中心（VSRC）正式成立，以“为用户提供更加安全公平的购物环境”为基础，将对外收纳唯品会相关安全漏洞为使命，在不断的发展中打造出全方位的自有信息安全堡垒，不断深化安全产品设计，从无到有地搭建起自有的安全风控平台。近四年来，依托VSRC的“白帽黑客”们，唯品会收纳了大量漏洞，形成了良好的软件安全开发生命周期闭环，不断保护3亿用户的购物安全。在此基础上，唯品会全新上线安全应急响应中心平台3.0，为外界提供了反馈安全风险问题通道，帮助唯品会建设更安全可靠的线上购物平台，进一步维护用户权益，同时也通过此平台加强安全研究人员间的交流。

为鼓励“白帽子”们积极反馈平台风险问题，同时加强青少年网络安全建设，此次峰会上，唯品会安全应急响应中心还联合唯品会公益宣布共同启动“唯爱守护计划”，并向贫困地区中小学现场捐献《唯爱守护—网络安全手册》。此后VSRC收取到的所有相关安全漏洞，都会根据评定的漏洞等级，替漏洞提交者向贫困地区中小学，捐赠相等级的《唯爱守护—网络安全手册》书籍，并且颁发捐赠证书！

![](../Images/7a1fde5c699119c501509aa037c8ed37.png)

“唯爱守护计划”捐赠现场图

“因唯安全，所以信赖——唯与同行，智御未来”，2018唯品会第三届电商安全峰会的召开不仅为电商信息安全发展引领了新风向，同时也将指引着一批又一批信息安全人在探索电商安全建设的实践中坚定脚步。“唯品峰会”将努力发展成为中国互联网电商安全领域“规格高、水平好、影响力广、含金量足”的技术性会议，积极开拓，不断前行，为国内互联网电商与信息安全行业的发展助力。
