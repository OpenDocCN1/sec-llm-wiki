# 2018年网络安全“金帽子”奖年度评选活动获奖名单公布——专家评审奖

![](../Images/aafdcf06844ea89342ea7f31c648e71f.png)

2018年网络安全“金帽子”奖年度评选活动经过紧张的投票阶段，获奖名单已新鲜出炉，本次公布的是专家评审奖的获奖得主。

![](../Images/5d4c42f542f60d42ec9b9961a48ba98e.png)

根据活动评选投票规则，专家评审奖将选出年度杰出安全实验室五个、年度领先安全企业五个、年度优秀安全产品五个、年度贡献投资机构五个。四类奖项由根据专家评委的票数排名得出，结果如下：  

![](../Images/15b455afcee67493c4af27eb6c7b05b3.png)年度杰出安全实验室获奖者：

知道创宇404实验室、腾讯安全科恩实验室、蚂蚁金服光年安全实验室、360 Vulcan Team、深信服千里目安全实验室。  

![](../Images/570ef5e5791b09a87032693fa643114f.png)

![](../Images/daeb99f0f0638abb444411c2d37e6dcc.png)年度领先安全企业获奖者：

360集团、腾讯安全、天行网安、安恒信息、知道创宇。  

![](../Images/47f495014d5ab7016ee95c5d521c92f8.png)

![](../Images/daeb99f0f0638abb444411c2d37e6dcc.png)年度优秀安全产品获奖者：

椒图科技云锁、安天网络安全态势感知和应急处置平台、网宿科技基于CDN的全球抗DDos攻击防御系统、娜迦智能网联汽车管控平台、四叶草感洞全时风险感知平台。

![](../Images/b136fa9ec2ca360ea2842eab3c31cdee.png)

![](../Images/15b455afcee67493c4af27eb6c7b05b3.png)年度贡献投资机构获奖者：

苹果资本、线性资本、盈动资本、发现创投、赛伯乐投资。  

![](../Images/231a7f3d4c15ff0b76e38c481e2e0bc6.png)

注：以上各奖项的获奖者排名不分先后。

至此，2018年网络安全“金帽子”奖年度评选获奖名单已全部公布完毕。2019年1月将举办现场颁奖盛典，为所有获奖者及公司颁发荣誉奖杯，庆祝激动人心的时刻。
