# “金帽子”年度盛典第八弹：年度贡献投资机构

2018年11月，由公安部第一研究所指导，嘶吼传媒主办的网络安全线上评选大会——“金帽子”奖年度评选活动正式上线。活动上线后众多投资机构积极参与评选，嘶吼在此展示已经参与评选的年度贡献投资机构。

![](../Images/4c20b4ca98ef42186c407f0fa1051bae.png)

![](../Images/15b455afcee67493c4af27eb6c7b05b3.png)

![](../Images/bb2b9635e0c4a0c537ba76db803ce4d6.png)

**苹果资本：**苹果资本专注于全球网络安全产业项目投资，目前管理了I期、II期、III期、IV期人民币天使基金和I期美元天使基金，同时正在筹建10亿规模的成长期安全基金I期。苹果资本投资过的早期项目包括安全宝、上网快鸟、长亭科技、数字联盟网络、瀚思安信、指掌易、云法通、锦佰安、志翔科技、全知科技、红手指等企业，其中一些企业的技术水平更是在国际市场占据领先水平。  

![](../Images/8cbc0ba3d472ad91e00c717cc02592cb.png)

**线性资本：**线性资本 (Linear Venture) 由Facebook早期员工王淮和京东、天猫原高管张川共同创立，关注泛智能、大数据领域的技术驱动型早期项目。目前已投资地平线机器人、Rokid、同盾、点融等超过30个创业团队，并正在努力成为中国最好的应用性数据智能基金 (Applied-Data-Intelligence)。我们的有限合伙人既有来自亚洲的顶级对冲基金，又有来自阿里巴巴、腾讯、百度、大众点评，去哪儿，百姓网，Facebook、Twitter、Linkedin等国内外知名互联网公司的创始人或高管，以及薛蛮子、梁伯韬等纵横资本界数十年的投资元老。我们努力用专业知识和行业资源，帮助被投公司move fast and break fewer things，最终实现linear path and nonlinear growth。  

![](../Images/c1ab7528acee8ea6212c74cddc7b8130.png)

**盈动资本：**盈动资本是一家价值导向、研究驱动、独立思考的风险投资公司，专注于互联网为代表的新经济领域的早期投资。我们致力于寻找并帮助那些心怀崇高而热切愿望、有企业家精神的创业者，和他们一起构建一个新的“我们想要的世界”。迄今，已投资包括51信用卡、in、开始众筹、小电科技、别样红、人人视频、亿欧网、袋鼠云在内的一批行业领先企业，并在多个榜单中斩获「最佳投资机构」奖项。旗下拥有良仓孵化器和创投媒体B座12楼。荣膺 「2017年中国早期投资机构TOP30」「2017年最佳天使投资机构」「2017年度年度最受创业者欢迎天使机构TOP20」。  

![](../Images/1c093de7f015d7b850d33a66900458f4.png)

**赛伯乐投资**：浙江赛伯乐科创股权投资管理有限公司起源于美国硅谷，是一家专注于服务中早期科技创新和模式创新的创业投资基金管理公司。私募基金管理规模超过100亿人民币，系全国最大的创投及股权私募基金之一。浙江赛伯乐是浙江省股权投资行业协会轮值会长单位，浙江省创业投资常务副会长单位。公司被评为“2016年度优秀股权投资机构”，清科2016中国创业投资机构15强，2015年度17强，被评为福布斯2015最佳创投30强，2014年度24强，2008、2009年度、2010年度和2011年度浙江本土十佳创投机构”。  

![](../Images/26f65895f21288ebdb8d57b933f91e8f.png)

**发现创投**：发现创投成立于2016年3月，是一家创新型的天使投资机构，致力于 “发现改变世界的人” 。我们的愿景是十年内成为能独立投资并长期陪伴企业成长的投资公司，二十年内成为各行业领域创新的风向标。发现创投坚持 “做真正的天使” ，并把五个核心价值观 “五颗心” 作为企业文化的基石和公司DNA的重要部分。我们认为真正优秀的人，才能改变世界，所以我们通过共享模式，整合并调动最优质的资金、资源、人脉帮助我们发现那些潜在的改变世界的人，并尽全力且无私地助力他们成为给世界带来价值的伟大企业家。

![](../Images/15b455afcee67493c4af27eb6c7b05b3.png)

目前，“金帽子”奖各奖项参选正在持续征集中，欢迎大家自荐和推荐。参选资料征集及审核将在11月30日截止，并于12月1日正式开启评选投票入口，12月30日前将在官网公示获奖结果，2019年1月份将举办现场颁奖盛典，为所有获奖者及公司颁发荣誉奖杯。
