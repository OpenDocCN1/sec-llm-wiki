# 在超微攻击事件之后，中国科技巨头股价暴跌

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247489578&idx=1&sn=f5b92a2e3b661f8676ff73c48c27e494&chksm=e916c810de6141067fb2041d0905d2aa15aa4c298bd1192a9fac112483af19e061b45d9cdc35&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247489578&idx=1&sn=f5b92a2e3b661f8676ff73c48c27e494&chksm=e916c810de6141067fb2041d0905d2aa15aa4c298bd1192a9fac112483af19e061b45d9cdc35&scene=27#wechat_redirect)

超微攻击事件是指中国政府特工向苹果和亚马逊所使用的超微服务器中植入窥探芯片，这件事被爆炸性报道后，它所造成的连锁反应影响了中国科技巨头的股价。

彭博指控称，包括美国政府在内的30多家投注者购买的数据中心服务器中，包含了一些看起来像信号调理耦合器的芯片。这些芯片由中国的分包商制造，据说可以获得高度敏感的数据。

这份报告使超微市值下跌了50%，尽管股价有所回升，但截至撰写目前仍下跌超过40%。苹果(Apple)和亚马逊(Amazon)的股价下跌了2%，并且目前仍维持在这一区间。

然而，与这颗重磅炸弹没有关联的中国厂商，今天的市值也出现了缩水：今天凌晨，联想股价暴跌逾五分之一，截止目前下跌15%；电信设备制造商中兴(ZTE)股价下跌近11%。

联想发表声明，证实超微没有为其制造服务器，也不是联想的任何供应商。

该公司补充称:

![](../Images/c928fae6970595356b6a4a9c44d134a4.png)

此外，作为一家全球公司，我们采取了广泛措施，以保护我们供应链的持续完整性。

![](../Images/d2be1a14fa6fa2cc3f20dbb95243d026.png)

金融服务公司Core Pacific-Yamaichi Financial Group的研究主管庞伟荪告诉《南华早报》，股价暴跌与超微故事有关。

![](../Images/c928fae6970595356b6a4a9c44d134a4.png)

“可疑的芯片渗透到服务器似乎是股价下跌的主要原因”。这个消息的真实性还是值得怀疑。如果情况果真如此，那么基于国家安全方面的担忧，从欧洲、美国和迪拜等其他地区购买联想服务器的政府采购数将会大幅减少。

![](../Images/d2be1a14fa6fa2cc3f20dbb95243d026.png)

这些所谓的冒名顶替芯片并没有出现在最初的设计中，据报道，这些芯片是在工厂老板被贿赂或被胁迫时，以某种方式修改最初的设计后添加的。

据称，这些间谍活动是在2015年被发现的，当时亚马逊开始审查潜在的收购目标Elemental Technologies，并雇佣了第三方来破坏其安全。它发现了彭博所说的“麻烦问题”，即由超微公司制造的服务器。Elemental的客户包括国防部、美国中央情报局的无人驾驶飞机和美国海军军舰的舰载网络。

苹果内部人士还被指控在同一年发现了超微主板上的“恶意”芯片，这可能导致库比蒂诺与超级微断绝关系，甚至取消对3万多台服务器的订单。

就苹果(Apple)、亚马逊(Amazon)和超微(Super Micro)而言，它们断然否认了彭博报告的调查结果。超微的问题已导致其股票在纳斯达克(NASDAQ)退市。

正如El Reg已经指出的那样，上市公司故意欺骗市场并不是典型的行为。如果有更多的证据浮出水面，所有公司都会损失惨重。

但是有一件事是肯定的：有关筹码和中国偷窥者的指控，注定会加剧中美两国政府之间本已剑拔弩张的关系。
