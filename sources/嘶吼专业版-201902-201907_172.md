# 2019年 DEF CON China 1.0 | 这可能是最嗨的一场极客大会

北京。

这座城市的魅力在于，不论白天经历多少凹糟，一场恰到好处的大雨伴着通透的电闪雷鸣，最好是在一个夏日的午夜，人们总能在这种时刻洗刷一下神经，尽情享受属于自己的时间。

但不管你享受了多么自由的一个夜晚，白天还是会如约而至的，这就是北京的另一大魅力。

视线还是回到极客大会现场。

6月2号，清晨，为期三天的DEF CON China 1.0进程已过大半，751D-Park园区经历了两天两夜的燥热与激情，也终于在昨夜迎来了一场雷雨。 

![](../Images/9cfd7e7e93be96121c5aa8c4bcae2ad3.png)

2号清晨，雨水冲刷过的园区准备迎接最后一波来客

再把时间拉回到大雨到来之前的1号下午，大会第二天，大会各项议题陆续结束，各个部落村仍在迎接着极客爱好者的到来，另一边BCTF赛场的比赛还在如火如荼的进行。

![](../Images/a2ac6c41bf9df2616c193e0b30e3fccd.png)

与此同时，会场同时迎来了两位网络红人，引发围观。

手工耿携带着自制的手工艺品现身DEF CON China 1.0现场。

![](../Images/44a893a140d9c0ffc979a61e2fb54e8f.png)

红极一时的手工耿，手捧自制红酒杯，据说这样喝可乐不长胖

![](../Images/871c378866cf173857d0077bdc41d229.png)

尽管耿哥不会敲代码，但是这些作品和会场里随处可见的电焊、开锁相得益彰

作为一场极客大会来说，DEF CON可能是包容度最高的一类了，当然有人可能觉得耿哥与极客不是很相配，但是我觉得，既然像我这样的技术小白都能在会场穿梭自如，那么耿哥这样将发明创造发挥到淋漓尽致的牛人出现在现场自然非常合适（的确很绕嘴），更何况耿哥是如此的腼腆、可爱。

现场展位在耿哥的旁边一位小哥哥不温不火的在给观众做讲解，细看一下，竟然是知乎网红季文瀚，徒手在“我的世界”游戏里搭建计算机cpu的奇男子，而我只会在游戏里砍树、宰羊……

![](../Images/40687db4ee1a9a1d2d1d4df8ad4b0740.png)

季文瀚在给观众讲解如何在游戏“我的世界”里造出一台计算机

随着一整天大会议程的结束，DEF CON China 1.0 终于祭出了保留曲目，极客音乐会。 

![](../Images/3434eacd78a0a316df4a7f53de4797df.png)

看这等候的人群，我猜有人就奔着音乐会来的，顺带一提，会场入口的冰啤酒味道还不错！

等候间隙路遇大佬，“呆神”领着两个娃在坐机车。 

![](../Images/9a5a1dda49c37afddf4906d9e1450e5d.png)

车上的女萌娃是Jeff闺女，委屈巴巴的男娃是小呆神

用啤酒灌满我的枸杞杯，迈起矫健的步伐，步入会场，音乐会正式开始了。

![](../Images/9f5f11c4e8953da47f62c3cb16c43649.png)

边上小姐姐嘲笑我跳的像老年迪斯科，她不知道我听到了，我会在小本本上记她一笔。

![](../Images/0f08603386a583e5a3e66c6e40a927f8.png)

外国友人悠扬的舞步

蹦迪结束，时间回到现在，成稿之际，大会即将举行闭幕式，会场各处的解谜彩蛋都已经陆续被挖出，但这处耗费数万块榫卯模块，历时三天，全程不用钉子胶水搭建起来的太和殿才刚刚揭开神秘面纱。

![](../Images/75b5fae91ff620fae0a0b8b4553f74c7.png)

刚搭好就要拆掉，我要是设计师我肯定是要崩溃的

此时主会场闭幕式的音乐已经响起。

![](../Images/9061e9a8c52206b3a0c2192346aceab0.png)

闭幕式上，Jeff对呆神和马杰致谢

一年一度的极客大会进入尾声，DEF CON与中国的邂逅已经度过两个春秋，极客社区在中国的发展随着DEF CON China 1.0 的出现已经迈入了新的阶段，希望明年继续在北京与各位朋友再会。
