# DEF CON China 1.0 | “专注”是对解谜最好的褒奖

如果你是一个极客爱好者，那么每年总会有那么几天会被DEF CON大会刷屏。

这场全世界最大的极客聚会真正的魔力是什么？我问了几个自掏腰包赴会的朋友，也没人说的清楚，于是我准备自己去感受一下。

5月31号的早上，地点，北京751D-Park。

晨练的大妈拦下我问，“小伙砸，里边画的那乱七八糟都是些啥，我们老年人进去免门票不？”，我也不知道怎么回答，只能告诉大妈，一群年轻人在里边开party，闻言大妈告诫我“年纪轻轻的可别学坏啊！”，“得嘞大妈！” 

辞别大妈，进入751园区。

![](../Images/ecba980127c035fa80d75a55bf7d7205.png)

随处可见大刀阔斧的涂鸦、锈迹斑斑的集装箱、未来主题的场景搭建、以及巨型水泥罐“改造”而成的主会场，重金属与科幻主题交织出来的极客氛围让人有种身在《阿丽塔》电影宇宙中的错觉。

![](../Images/5b11ad29c446dba95a950d0ed53a0aa3.png)

正所谓“擒贼先擒王”，为了搞清楚Defcon真正的魔力，我准备先听听Defcon创始人Jeff Moss和主办方百度安全总经理马杰的想法。

![](../Images/1891a267237e270f1ffcb7b42c3c9206.png)

偷拍到Jeff在偷拍

特别彩蛋：Jeff手中有一个胸卡打卡点，只有在会场捕捉到他还能点亮哦！

![](../Images/3856725c7ac2af4022e09fe580f7d2a6.png)

据说马总T恤上的黑色方块是躲避摄像头识别的高端攻击方法，虽然我看现场百度人手一件……

当我们聊到今年Defcon今年依旧亮眼的设计，马杰与Jeff相视一笑，“这是我们两个都特别喜欢的风格，复古未来主义”马杰如是说。

作为一个艺术白痴，我是无法理解那些主义的，但是我猜测和《阿丽塔》的比喻应该是一个道理。这不免让我觉得好奇，十多年来Defcon的视觉设计从不预设套路，但偏偏又每次都让人觉得达意精准，到底是什么元素能够同时戳中这两个来自不同国家顶级极客的神经呢？

![](../Images/71f0305b7659af6c2a2d210bd357dd5d.png)

2019Defcon官宣画

“画中这个人是以Defcon团队的小哥小伙伴为原型的，设计师捕捉了日常工作中的一个很平常的瞬间，但是我们都一致认为这很极客。”Jeff很认真的解释了设计由来。

对于圈外人来说，电焊和极客是两个不搭边的东西，但是就像我们熟悉的“漫威极客”钢铁侠，托尼史塔克除了是个计算机天才，初代钢铁侠战甲可不就是靠着电焊拼接起来的。

![](../Images/d70e3edac0bf6c3950fc636ee974b351.png)

但是，不是每个人都是抱着拯救世界的伟大目的走进极客的，想找出答案，还是要亲身体会一下Defcon的魔力。

走进Defcon的部落村，这里有开锁、焊接、硬件破解、AI破解，如果你实在不懂，不妨拉个大神组队，在这里辨别大神与小白一目了然，区别的方法就是Defcon的专属标志——胸卡。 

![](../Images/6f4fcf92e6df443e8fdc7d27b5c67634.png)

历尽千辛点亮了四个灯，会场上随处可见亮闪闪的大神

今年Defcon胸卡延续了点灯的传统，在整个会场中有十多处打卡点，几乎每个部落村都有专属任务。

我的第一个打卡点，开锁部落，“一把锁就是一个最小最完整的安全防护体系。”

![](../Images/5089ffc84e047525236ff10341df3598.png)

乱入的防盗门也很极客范儿

![](../Images/f9fa7288f996448f78db7d7f0093894a.png)

首次尝试开锁成功

来到焊接部落村，这次打卡目标是手工制作一个计时器。作为零基础的小白，要熟练把电路板上的电子元件匹配好位置，再用烙铁和焊锡焊接好并不简单。

![](../Images/6311bf2704112ec568c0a711821725ac.png)

放出一张成品图，计时器显示出时间的一刻，仿佛自己已经是一名成熟的极客了，成就感爆棚！

![](../Images/7edfcef16b5aff3fe655c305990e2d2d.png)

不论是沉浸在开锁的乐趣中，还是在焊接台上消磨时间，又或者为了点亮胸卡穿梭在各个打卡点，Defcon特有的解谜属性都贯穿其中。

Defcon吸引众多爱好者不远万里来参加的魔力是什么？除了能够瞻仰大神，和顶级极客近身肉搏，我可能找到了些不一样的答案。

专属于Defcon的极客精神是什么？我看到的是：

大家享受锁芯弹开时清脆的“咯嘣”声和来自观众的阵阵喝彩；享受在焊接台上完成每一个精致的焊接点和最后串联起整个线路带来的小小成就感；享受搜寻到不为人知的胸卡彩蛋时那份激动。

而最吸引我的，正如Jeff与马杰所说，是属于爱好者的专注，是当我倾心于某件小事时，浑然不觉日上三竿。
