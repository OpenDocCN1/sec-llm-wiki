# 实战为王 | DEF CON China 1.0 Village一日游

![](../Images/420eebaabdd6d1a2df52ecface4cf38c.png)

在DEF CON China 1.0上，Village是一个既有趣又亲民的环节。其优点在于，它可以把枯燥的理论知识与实战相结合，无需携带设备工具，全部由Village负责人准备，并且任何参会者都可以在现场动手体验。

本届DEF CON China 1.0共包含10个Village，小编带大家简单了解下。

![](../Images/64cd0006bdcedf95e8f3ebfe4ce76c8f.png)BugZee焊接Village

![](../Images/d4d07a2353d06f98d7a1c007bb816849.png)

如上图介绍，BugZee焊接village是以富有创意和乐趣的方式教会你焊接基础电子。在这里你会拿到一个小包裹，里面装有焊接用的各种小部件和一份操作说明，按照操作说明安装完成后是小蜜蜂形状的物品，而且蜜蜂腹部装有2个电池凹槽，焊接成功装上电池后，蜜蜂翅膀顶端的两个LED会点亮，并且伴有嗡嗡的震动声音。

![](../Images/ff5d5f207b36e855da37e06a98747e31.png)

完成后最终形态

这个焊接挑战并不难，只要你有一颗不放弃的心和一双不太颤抖的手，小白也能蜕变大神。在这里你将体验到取得成功时的那份喜悦。

![](../Images/64cd0006bdcedf95e8f3ebfe4ce76c8f.png)开锁Village

作为历年DEF CON最受群众欢迎的解密项目，开锁Village对小白的接纳度非常高。两个小工具足够撬动一把榔头都敲不碎的大锁，你可以从最简单的一阶开始逐步开启你的解密之旅。完成五阶挑战可以点亮badge灯，建议小白从这里迈出走向大神第一步。

![](../Images/a5870899a5866c71f3598132a58d90e8.png)

当然，接受挑战之前还要提醒大家，“不是自己的锁不要开哦！”  

![](../Images/64cd0006bdcedf95e8f3ebfe4ce76c8f.png)黑窗village

如果要评选整个会场里最违和的东西是什么，这三扇铁门一定能入选。

![](../Images/70b717d71623d27fc2a0692f32804fb5.png)

本以为是一个密室逃脱的挑战，没想到接下来的场面让人大跌眼镜。

![](../Images/c5c9990671b174bf878d848d0bb52820.png)

黑窗village主要是为参与者提供物理入侵基础教学，模拟环境给参与者尝试物理入侵，譬如躲避红外报警器、安装窃听器、盗取机密文件等，毕竟知攻才知防。

![](../Images/64cd0006bdcedf95e8f3ebfe4ce76c8f.png)区块链Village

![](../Images/b84ac0937cd7a60ab09cd3e13e09ae6f.png)

区块链相信大家都不陌生，这个Village主要是让学员们深入了解区块链技术并实际应用，通过学习掌握如何建立一个安全的密钥。

说起区域块，马上就联想到了比特币。众所周知，比特币就是利用的区块链技术。打个比方：你使用的各种电子支付方式都是需要密码的，而这些“密码”对于黑客而言可能就是金库的钥匙，他们可以利用社会工程等等的攻击手段，达成他们最终的目标。而如果你的支付密码被别人知道，那么你将处于一个极为危险的处境。而采用区块链技术的比特币钱包就很好的规避了这个问题。

嘶吼小编提醒大家：

![](../Images/a977056881d7ec2c1f5d39973c7e9640.png)

科技道路千万条，安全防护第一条，防御不规范，亲人两行泪。

![](../Images/6823db49d53cdf53c400dac2e8c8d345.png)

![](../Images/64cd0006bdcedf95e8f3ebfe4ce76c8f.png)侦查Village

![](../Images/0782a95c92da195622b200543c587d61.png)

这个village较适向对开源智能（OSINT），威胁情报，侦察和网络情景意识等领域感兴趣的专业人士。来到这里可以学到一些侦查技巧，还会实战组队，对一些网络、数据等进行侦查行动。旨在鼓励和传播有关这些主题的意识。

![](../Images/64cd0006bdcedf95e8f3ebfe4ce76c8f.png)AI Village

![](../Images/119f51f6ea91ca663e32567f5f7a479e.png)

如今人工智能发展迅猛，利用机器学习技术可以帮助我们解决很多难题。这个Village的村长会在这里教你如何利用Ai技术检测恶意软件。

![](../Images/64cd0006bdcedf95e8f3ebfe4ce76c8f.png)数据包攻防极客village

![](../Images/a06fda443bb576c7b9b34283c8680636.png)

这个Village的地点是在Workshop区域里，如此分配的原因可能是，它与其他Village相比技术实现更加困难一些。其主要针对CTF方面的学习，让学员深入了解数据包攻防技巧。

![](../Images/64cd0006bdcedf95e8f3ebfe4ce76c8f.png)汽车极客Village

![](../Images/43dd44469a30130ad788fabe9b5fe579.png)

汽车极客village是一个互动的实践村庄，看现场犹如汽车修理厂一样的画风，其实是极客在向参加者讲授汽车极客攻击行为，介绍汽车极客攻击的工具。  

![](../Images/3de894963458e90f186618ac470e3ca7.png)

![](../Images/64cd0006bdcedf95e8f3ebfe4ce76c8f.png)硬件极客Village

随着大会进入第二天，硬件极客Village是第一个做出项目调整的部落，从第一天的简易计时器变成一个简单的灯光设备。

![](../Images/bed9c6ebd0eea33b489388d9f1832e3f.png)

主要也是需要对其进行焊接，体验不同的操作流程，赶快加入硬件极客Village吧！

![](../Images/64cd0006bdcedf95e8f3ebfe4ce76c8f.png)VXCON Village

作为唯一一家来自香港的Village，VXCON带来的项目绝不乏味。

![](../Images/02de8b0a3b406b0abb4a2826a3929f34.png)

看这个高端的工作台就知道这个项目的不凡，VXRL的项目会带领参与者体验如何从一台废弃手机中重新获取有用的讯息，记得带上自己的电脑，完成任务后把自己的作品接入电脑，会收获专属彩蛋。

以上就是本届DEF CON China 1.0的10个Village，其中涉及各各领域的极客技术，可满足不同的极客人才，锻炼实操能力，提升自身技能。我们晚上音乐会见！
