# 2019 Windows杀毒软件市场份额

OPSWAT连续5年发布了Windows杀毒软件市场份额报告。2019年10月底，OPSWAT发布了最新的Windows杀毒软件市场份额报告。其中Symantec, ESET, McAfee是Windows平台中上使用最多的杀毒软件。  

![](../Images/6d3d7b3ae2ccc27fdbf524fd72e3040a.png)市场份额

OPSWAT称收集的数据来源于3万多个安装了其免费APP的企业和家用系统用户。根据最新的数据显示，Symantec在Windows系统杀毒软件市场所占的市场份额最高，为13.56%，排名第二的是ESET，市场份额为12.84%，排名第三的是McAfee 12.21%。

![](../Images/952525615ce793024dddbc782715a292.png)

OPSWAT Windows杀毒软件市场份额，2019年10月

其他top 10的厂商和产品分别是Bitdefender (10.77%), Kaspersky (7.66%), Avast (6.98%), Cylance (5.95%), Webroot (5.88%), Malwarebytes (5.8%), Sophos (3.62%)。

![](../Images/6d3d7b3ae2ccc27fdbf524fd72e3040a.png)WINDOWS DEFENDER

OPSWAT的报告中并没有将Windows Defender纳入考虑范围内，因为Windows Defender是默认安装在所有Windows操作系统中的。同时，OPSWAT承认报告并不能完全代表整个杀毒软件市场。因为其产品主要是英语国家在使用，所以英语国家使用这些应用的概率会高一些。

![](../Images/6d3d7b3ae2ccc27fdbf524fd72e3040a.png)数据分析

从2019年的数据来看，没有哪家公司一家独大，各厂商所占市场份额都差不多。多样化的厂商生态系统是健康和竞争的市场的一个最明显的标志。

在过去3年，Windows杀毒软件生态系统充满流动性。不仅各厂商的市场份额在变化，占市场份额最多的企业也在不断变化中。变化最大的就是Avast。2014年1月，Avast的市场份额为13.2%，到2015年12月，市场份额增长到了15%。2年后，2017年6月Avast的市场份额为20.48%。但是到了2018年12月，市场份额锐减至17.42%，10个月后，市场份额降低到了6.98%，排名第6。

![](../Images/f0c393ef312510c96ae504e1ee4cce2d.png)

OPSWAT Windows杀毒软件市场份额，2015年12月

在过去3年，Avast的市场份额在变。同时市场份额最高的公司也在变化，2019年3月色McAfee，2019年6月是ESET，2019年8月变成了Symantec。

OPSWAT报告显示新产品仍然有很大的空间。最好的例子就是Cylance，Cylance是一家AI驱动的方法来运行预测安全产品的企业。
