<?php

一般来说，反序列化的入口都可以从\_\_destruct()发起，我们可以看到起调用了一个方法\_show()，而这里如果str属性赋值为S6ow的对象，那么就会触发S6ow类的\_\_call魔法方法，而当S6ow调用$name变量(\_show)时，又会触发其\_\_get方法，在\_\_get方法中，由于之前访问的不可访问方法，会变为  

 return $this->params\['\_show'\];

那么此时，只要给其赋值为file\_get，即可利用echo触发show类的\_\_toString魔法方法：

 params\['\_show'\] = 'file\_get'

最终在show类的\_\_toString魔法方法完成利用：

   public function \_\_toString()  

    {

        $text= $this->source;

        $text = base64\_encode(file\_get\_contents($text));
