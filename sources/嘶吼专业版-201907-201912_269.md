# Chrome Bug破坏MacOS文件系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247495536&idx=2&sn=4d4a363923f07c57e2d57b0d3666ebb7&chksm=e9153f4ade62b65cdbb92417bed6b2c1517fafba3ab1fff1c843445b13752969f30802ccf3a3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247495536&idx=2&sn=4d4a363923f07c57e2d57b0d3666ebb7&chksm=e9153f4ade62b65cdbb92417bed6b2c1517fafba3ab1fff1c843445b13752969f30802ccf3a3&scene=27#wechat_redirect)

![](../Images/420eebaabdd6d1a2df52ecface4cf38c.png)

研究人员追踪引起macOS用户文件系统破坏的问题，发现根本原因是Google Chrome升级的bug引发的，而不是之前以为的Avid Media Composer的问题。

![](../Images/50337bfe1b2197ea9e634bc788ce17c2.png)

有在macOS平台上使用Avid软件进行视频编辑的用户MarcusPun周二在Facebook和其他社交媒体上发文建议用户不要关机计算机，因为会造成文件系统破坏，而且关机后无法恢复一些文件。MarcusPun发推称UNIX root级文件夹被破坏了，要备份所有的文件，不仅仅是服务器上的文件。

Avid是一款专业的电影与视频编辑工具，可用于编辑电影、电视节目、广告或是其他视频等。苹果系统的Avid Pro版本是众多专业用户的选择。

9月25日，Avid发文称影响部分Avid用户的文件系统破坏问题的根源与Avid无关，并没有Avid用户提交关于数据丢失的报告。

谷歌在Google Chrome帮助站点发布声明称前述重启造成数据丢失问题经查收由于谷歌Chrome浏览器升级造成的。在系统完整性保护（System Integrity Protection）禁用的macOS机器上，Chrome升级会引入一个新的bug。谷歌已经暂停该更新版本的发布，并用一个新的浏览器更新来解决该问题。

![](../Images/486c50db61a35b6aca2eb0a8958c872f.png)

谷歌建议受影响的用户通过恢复模式启动机器，并提供了命令来移除受影响的Google Software Update，以及恢复被破坏的文件系统部分。并称运行OS X 10.11及之后版本的用户不受到该漏洞的影响。
