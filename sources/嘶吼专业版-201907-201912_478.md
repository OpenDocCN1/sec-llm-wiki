# 美俄将网络攻击目标转向民用基础设施

近期，全球有政府背景的网络攻击活动不断增多，而攻击活动的目标开始从军事和政府转向关键的民用非接触设施，最近的报道显示电网成为最主要的攻击目标。上个月纽约时报就报道称美国网络部队在俄罗斯电网中植入了木马。  

从2012年开始，美国和俄罗斯就开始互相攻击对方的基础设施，攻击活动的侵略性和范围都是前所未有的。俄罗斯和美国的网络攻击破坏活动有很多共同点，比如，都将对方视作极具挑战性的对手。美国官方对俄罗斯联合学术界、私有企业和网络分子来增加其网络攻击的能力心存恐惧。俄罗斯对美国开发出震网病毒这样的恶意软件也很担忧。最近，美俄双方官员都将民用基础设施作为攻击对方的必要目标。

![](../Images/ad8a47517ed89b9d47680b3ea15eb170.png)

美国和俄罗斯在网络攻击方面虽有这些相似之处，但在网络战的能力和政策方面仍有不同，这主要表现在双方对一些全球性的网络安全事件的解释和分析。  

美国军方构建了网络攻击的能力，而美国何时何地应当使用网络攻击能力并没有与其新的网络攻击能力保持一致。在这方面俄罗斯针对潜在攻击目标的能力就超过了美国。自2016年开始，与俄罗斯相比，美国更愿意发起针对俄罗斯的网络攻击活动，而俄罗斯通过人员招募和开发恶意软件增加了其军事网络能力。

![](../Images/ffcb4f491619a82bf60a656cdcfc9772.png)相关事件

2010年，（美国开发的）震网病毒席卷全球工业界，并攻击了伊朗核电站等基础设施。

2015年12月，黑客攻击了乌克兰电网约60座变电站。还对电力公司的电话通讯进行了干扰，导致受到停电影响的居民无法和电力公司进行联系。

2019年6月，美国网络司令部透露了美国网军的电网攻击计划，并表示俄罗斯电网已经被植入了木马。

2019年7月，委内瑞拉称遭美国“电磁攻击”导致全国大范围停电。

2019年7月15日，美国方面报道称，7月13日晚间，伊朗革命卫队信息战部队成功的突破了美国信息战部队的围堵，闯入了纽约市三十多个变电站的控制中心，并对控制中心进行信息站破坏，导致了纽约全城大约4个小时的停电。
