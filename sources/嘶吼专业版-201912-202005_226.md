# 安全圈大动荡：受疫情影响，国内外大量安全会议延期或取消

受新冠肺炎疫情影响，处于安全和健康考虑，大量近期举行的大型会议采取了延期、取消和线上举行等形式。  

下面是一个被取消、延期或选择线上举行的安全会议列表：

**FIRST CTI**

会议举行时间：3月9日-11日，会议地点：瑞士 苏黎世，会议当前状态: 取消。

**Wild West Hacking Fest**

会议举行时间：3月10日-13日，会议地点：美国 圣地亚哥，会议当前状态: 线上举行。

**Red Team Summit**

会议举行时间：3月11日-12日，会议地点：美国 门洛帕克，会议当前状态: 推迟至6月11日-12日。

**Women in Cybersecurity**

会议举行时间：3月12日-14日，会议地点：美国 奥罗拉（科罗拉多州），会议当前状态: 取消。

**ICS West**

会议举行时间：3月17日-20日，会议地点：美国 拉斯维加斯，会议当前状态: 推迟至7月，具体时间待定。。

**Cyber Security & Cloud Expo**

会议举行时间：3月17日-18日，会议地点：英国 伦敦，会议当前状态: 推迟，具体时间待定。

**Pwn2Own CanSecWest (黑客大赛)**

会议举行时间：3月18日-20日，会议地点：美国 华盛顿，会议当前状态: 可选远程参与。参与Pwn2Own黑客大赛的黑客可以选择线上参与，也可以让组织者以自己名义执行漏洞利用。

**InfoSecurity Belgium**

会议举行时间：3月18日-19日，会议地点：比利时 布鲁塞尔，会议当前状态: 推迟至5月27-28日。

**InsomniHack**

会议举行时间：3月19日-20日，会议地点：瑞士 日内瓦，会议当前状态: 推迟至6月4-5日。

**Fast Software Encryption**

会议举行时间：3月22日-26日，会议地点：希腊 雅典，会议当前状态: 推迟，具体时间待定。

**BSides Budapest**

会议举行时间：3月26日，会议地点：匈牙利 布达佩斯，会议当前状态: 推迟至5月28日。

**Black Hat Asia**

会议举行时间：3月31日-4月3日，会议地点：新加坡，会议当前状态: 推迟至9月29日-10月2日。

**BSidesCharm**

会议举行时间：4月4日-4月5日，会议地点：美国 巴尔的摩，会议当前状态: 会议正常举行，但对规则进行了调整。参与者可以选择通过远程视频会议的方式参会。

**BountyCon**

会议举行时间：4月4日-4月5日，会议地点：新加坡，会议当前状态: 推迟至8月31日。

**FIRST ****TC**

会议举行时间：4月6日-4月8日，会议地点：荷兰 阿姆斯特丹，会议当前状态: 推迟明年。

**GISEC**

会议举行时间：4月6日-4月8日，会议地点：迪拜，会议当前状态: 推迟至9月1-3日。

**Kaspersky's Security Analyst Summit**

会议举行时间：4月6日-4月9日，会议地点：西班牙 巴塞罗那，会议当前状态: 推迟至9月，具体时间待定。

**DEF CON China**

会议举行时间：4月17日-4月19日，会议地点：北京，会议当前状态: 推迟，具体时间待定。

**Mediterranehack**

会议举行时间：4月18日，会议地点：意大利 萨莱诺，会议当前状态: 推迟至9月15日。

**Internet Freedom Festival**

会议举行时间：4月20-24日，会议地点：西班牙 瓦伦西亚，会议当前状态: 取消。

**ISSA Summit**

会议举行时间：5月5-8日，会议地点：美国 洛杉矶，会议当前状态: 推迟，具体时间待定。

**Fortinet Accelerate**

会议举行时间：5月16-21日，会议地点：美国 纽约，会议当前状态: 取消。

**Area41**

会议举行时间：6月11-12日，会议地点：瑞士 苏黎世，会议当前状态: 推迟至2021年6月。

**BSides Liverpool**

会议举行时间：6月29日，会议地点：英国 利物浦，会议当前状态: 推迟，具体时间待定。

5月之后的会议大多没有发布会议变化的公告，大多希望疫情到时候可以过去。Tech news做了一个类似的网页来更新相关会议的状态，参见https://www.techmeme.com/events

Facebook的F8开发者大会、谷歌的I/O开发者大会、IBM的Think 2020、Zoho的Zoholics等科技巨头的技术大会也都安排取消了。Microsoft的WSL大会、NVIDIA的GTC、Adobe Summit、Atlassia Summit和Google Cloud Next都选择线上举行。
