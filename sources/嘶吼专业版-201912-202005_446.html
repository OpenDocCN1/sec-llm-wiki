DEF CON CHINA从0到1

2018年5月，全球顶级的安全会议DEF CON走进国门，以DEF CON CHINA Beta（测试版）问世，号召了众多国内外极客人才，进行了维持三天的技术研讨、学习、实践、交流。在那里，我们看到了中国安全人的极客精神，那种对技术的探索、追求与执着让他们散发出了神之光芒。

DEF CON CHINA Beta现场照

2019年5月，DEF CON CHINA 1.0（正式版）再次在中国首都举办，我们看到了更多国人的参与，包括一些远在台湾、香港的朋友也慕名而来。世界各地不同国家的极客人才集聚于此，共同追求他们心中的目标与梦想。

DEF CON CHINA成功在中国扎根，不仅仅是借助DEF CON的名声，历届DEF CON CHINA的主题方向、Keynote、Villages、Workshops等等一系列框架构思，都由DEF CON创始人Jeff Moss及组委会严格把关，因此它完美继承了全球最顶级安全会议DEF CON的灵魂，成为了一个极具研讨性和特色的安全会议。

Keynote——全球最前沿的技术分享

DEF CON CHINA Beta主演讲会场爆棚的画面

小编手机被劫持后的定位

历届DEF CON CHINA的主演讲会场都是焦点中的焦点，不管你从事行业中那个领域的工作，来到DEF CON CHINA Keynote，都能得到不一样的收获与思考。

Villages——有趣的体验实操课

参加过DEF CON CHINA的朋友都知道，Village是一个既有趣又亲民的环节，任何参会嘉宾都可以在这里体验到极客世界。

比如门槛较低的焊接Villages，在这里，你会接到一个简单的焊接任务，完成后就可以收获自己焊接的小礼物。

还有开锁Villages或黑窗Villages，老师会现场教学，让参与嘉宾体验物理破解的完整过程。

当然这里也少不了门槛较高的Villages，比如，教你如何从一台废弃手机中重新获取有用的讯息、一些侦查和反侦查技巧等。

Villages可以说是一个体验式学习的集中营，它可以将知识与技巧以体验的方式表达，学者通过创造加深回忆，让其有所感受，留下难忘的印象。

趣味环节
