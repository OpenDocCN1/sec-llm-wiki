# Win10 File Explorer 的Bug将于圣诞假期后修复

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247496776&idx=2&sn=ee7bf435474ce02d8286df39e5c3fae5&chksm=e9152472de62ad641bf5174812535bb890c4c1a6e0bd2fae33b8f45e058d6dbc11d8bc3c13aa&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247496776&idx=2&sn=ee7bf435474ce02d8286df39e5c3fae5&chksm=e9152472de62ad641bf5174812535bb890c4c1a6e0bd2fae33b8f45e058d6dbc11d8bc3c13aa&scene=27#wechat_redirect)

![](../Images/420eebaabdd6d1a2df52ecface4cf38c.png)

微软正在开发Windows 10 1909发布版本中File Explorer中引入的一些搜索相关的bug的补丁。  

Win10 v1909发布时，微软直接将Windows Search嵌入在了File Explorer中，所以搜索的结果会直接显示。

![](../Images/d61902656bb52950a4554fccb2168901.png)

 File Explorer搜索  

随着该特征的引入，也引发了很多新的bug，比如导致File Explorer挂掉、搜索框模糊不清、搜索域没有响应、在搜索域右击无效等。

许多用户都提交了类似的bug，并希望微软能够尽早解决。微软回应称，这并非重要的漏洞，并称可能将在假期结束后修复。

![](../Images/9fabe5eac67a239fffaeddfacb091033.png)

虽然微软对该bug的修复并不上心，但开发者已经在努力开发补丁了。

在11月发布的Win 10 Insider build 19013版本中，微软已经修复了导致File Explorer搜索框无法点击的bug。在12月发布的Windows 10 Insider build 19536版本中，实现了搜索域右击来移除记录的功能。

目前仍不清楚Windows 10 1909版本更新发布的具体时间，但File Explorer相关的bug很有可能正式完成内部测试并正式发布。
