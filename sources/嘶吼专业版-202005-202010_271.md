# 你遭受网络攻击影响的可能性有多大？

没有哪个国家、企业或个人可以免受网络犯罪的影响，随着互联网发展对我们日常生活的影响呈指数增长，全世界范围内的恶意活动也将成倍增长。

瞬息万变的互联网趋势总是会带来新的威胁，但每个企业或个人面临的问题都是一样的吗？谁经常会成为攻击目标？谁受到的威胁最大？谁最容易遭受网络犯罪？

从获得未经授权的访问、窃取数据、勒索软件到虚拟化和云计算等技术掀起的黑客攻击热潮，网络犯罪采取的形式各式各样。新的网络威胁在不停息的涌现，然而网络安全应对措施并不是那么紧随其后。

网络犯罪无孔不入，没有人可以保证不会受到网络攻击的影响，但重要的是要记住，风险的本质可以归结为事件的发生率。虽然一个人或一个组织不可能完全避免被攻击的风险，但是如果他们准备好进行防御，那么情况就不会那么可怕了。

# ![](../Images/de3fcc2f9d6d36168061f914e6723c6b.png)谁最容易遭受网络攻击的影响？

PasswordManagers.co选择在108个国家/地区研究恶意攻击的频率以及网络安全的水平，以反馈每个国家/地区遭受网络犯罪的风险。

网络安全暴露指数可以按国家/地区计算网络犯罪的暴露水平由高到低评级。分数越高，曝光度越高（意味着最危险）。

![](../Images/026e7f1aa578daa3b7a5a632f0e5ab81.png)

来源：PasswordManagers.co –网络安全暴露指数

在108个国家中，阿富汗受到的影响最大，其次是缅甸，埃塞俄比亚，巴勒斯坦和委内瑞拉。

依赖移动和卫星连接的国家，尤其是那些对数字领域还比较陌生的非洲国家，更容易受到网络攻击的影响，这在指数中有所反映。

**· **非洲的暴露指数最高，每个国家平均为0.643分，其75％的国家被划分为高风险和极高风险暴露级别。 

**· **南美紧随其后，每个国家平均得分为0.577，属于第二危险的暴露区域。其中委内瑞拉暴露程度最高，而乌拉圭暴露程度最小。

**· **北美方面，67％的国家被划分为中度、低度和极低度暴露国家，使其成为第二低暴露指数的大陆。美国的暴露程度最低，排在后四位的分别是加拿大、哥斯达黎加、墨西哥和多米尼哥。

**· **亚太地区方面，虽然平均得分为0.540，但其中包含一些全球暴露程度最高的国家，其中阿富汗的得分为1.0，缅甸为0.91。而且，包括巴基斯坦和乌兹别克斯坦在内的中东地区以及蒙古和尼泊尔等中亚地区仍然是国际关注的焦点，这意味着它们将继续吸引网络犯罪分子的窥视。

**· **欧洲的暴露指数最低，每个国家平均为0.329分。71％的欧洲国家被划分为低暴露和非常低暴露级别。总体而言，67％低暴露与非常低暴露国家的来自欧洲。其中，芬兰暴露程度最低，得分为0.11。紧随其后的是丹麦，卢森堡，爱沙尼亚和挪威。它们是全球暴露程度最低的五个欧洲国家。

# ![](../Images/de3fcc2f9d6d36168061f914e6723c6b.png)芬兰的网络安全态势

芬兰强大的网络安全态势是公共和私营部门共同努力的结果。最值得一提的是，芬兰政府采用了一项网络安全策略，可确保在当今的威胁形势下，安全工作保持稳健，以保障重要功能。这些策略分为三个关键领域：

1.国际合作：无国界保护网络环境

2.更好地协调网络安全管理，计划和准备工作

3.发展网络安全能力  

这与其他国家（尤其是非洲国家）相去甚远，这些国家很少制定严格的国家网络安全策略，更不用说法规和法律了。

# ![](../Images/de3fcc2f9d6d36168061f914e6723c6b.png)暴露率很重要性

暴露率突显了发展强大的政府技术机构和框架来应对网络犯罪的重要性，并鼓励企业积极提高员工的网络安全教育水平并实施必要的安全系统，从而防止攻击。

互联网超越了国际边界，因为我们面对的网络犯罪是很特别的，网络犯罪分子不必踏入特定国家，就能攻击其公民或商业实体。全球现有的刑法典只能处理在各自国家/地区范围内犯下的罪行，但为了更好地打击网络犯罪，需要更紧密的全球合作。那些暴露最少的国家应考虑与暴露率较高的国家分享知识和专长。

这些暴露率对教育每个国家的居民暴露水平方面也发挥着重要作用。需要采取行动的不仅是政府和企业，个人同样重要。

# ![](../Images/de3fcc2f9d6d36168061f914e6723c6b.png)加强网络防护

越来越多的数据泄露报告成为了网络安全意识和最佳实践教育的伊始，这些报告可以清楚的表明黑客发起攻击的经济目的。根据Verizon的2020年数据泄露调查报告，网络犯罪分子能够通过使用丢失的凭据来获得收益，而80％的泄露事件也都出于此目的。

如果一个普通人拥有70-80个密码，在没有适当的软件来管理这些密码的情况下，是非常困扰的。这通常会导致不良的密码习惯，比如：密码重用。虽然为多个帐户重用同一密码似乎是一个方便的选择，但用户会大大增加暴露率和被黑客利用的风险。

为了降低网络犯罪的暴露率，一个简单而有效的保护方法是通过使用密码管理器来保护所有帐户的登录凭证，从而将加密中的敏感信息隐藏起来，使其远离窥探者的视线。同样，使用安全软件删除设备中的恶意软件、病毒和其他威胁，以及使用安全的VPN保护在线隐私，对于维护网络安全和减少网络犯罪风险都是至关重要的。
