# 嘶吼产业链图谱网站上线，我们怎么定位产业链图谱的价值？

![](../Images/420eebaabdd6d1a2df52ecface4cf38c.png)上周四，经过三个月的连续奋战，嘶吼产业安全研究院正式发布了《2020网络安全产业链图谱》。图谱发出后，我们收到了许多入驻厂商发出的感谢、建议，以及新增的入驻申请。  
**《嘶吼2020网路安全产业链图谱》**![](../Images/9fdccb3933ef850e47fa963bc52f4a29.png)![](../Images/18dd992c931d20b0eb02f5998d4d5ae2.png)![](../Images/c8116c0cf94f4113b49f540bc9a6583b.png)![](../Images/0ec4d7d6fe89797b58ed6e1329fd497a.png)![](../Images/faa9cf219decf4f4d718c9bd94a2c628.png)![](../Images/def3939912ff4f9917446ac77f6066ac.png)坦白讲，这些反馈对于图谱的继续更新至关重要，长达三个月的时间里我们完成了与二百多家厂商沟通、背景调查、资质检验、资料整理、视觉设计，亟需一些外界的反馈来修正和理顺产业链图谱的相关功能。实际上，在最初提出图谱的专题方案时，我们无法预料图谱能够产生多大的效应，能否产出正向的连锁反应，能否得到足够的关注度，一切都是未知数。幸运的是，图谱的确引起了业界大部分厂商的关注，并且入驻厂商的数量仍在上升中。这些正向的反馈，笃定了我们继续打磨网络安全产业链图谱的信心，所以我们上线了嘶吼网络安全产业链图谱的网站版。![](../Images/73695302ba821170ce74d652785b9efc.png)欢迎访问4hou.com体验我们在网站中将已入驻《嘶吼2020网络安全产业链图谱》的厂商产品单独设置了页面展示，希望打造一个帮助用户全方位了解产品信息的平台。![](../Images/a00fd1f11f67d2e84cc027ba92e3f4a8.png)上线网站的另外一方面意义在于，后期我们会将其作为产业链图谱更新的专属参考数据库。为此我们专门开通了线上的自助入驻通道，尽量保持图谱内容与最前沿的市场接轨。![](../Images/feba1ff28677f9754bf09e76fef335ff.png)**持续邀请：**  
1、 已入驻2020图谱的厂商，为了帮助客户更直观的了解产品，需要继续提交更详细的产品信息资料填充资料页面。2、 未入驻2020图谱的厂商，开通网站入驻通道，您提交的产品入驻信息经审核后会显示在网站，这会作为下一版图谱的重要参考资料。3、 欢迎厂商关注嘶吼专业版公众号，回复“嘶吼产业安全研究院”加入我们的微信社群。实现图谱持续更新的目标，离不开持续的关注与交流，所以我们也计划将“嘶吼企业访谈”栏目对各位图谱合作伙伴敞开，欢迎加入社群后咨询图谱入驻、联系合作、专访事宜。再次感谢各位合作伙伴的帮助。
