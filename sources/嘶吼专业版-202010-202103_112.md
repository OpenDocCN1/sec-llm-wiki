# 数据中心需要演进为智算中心

**数据中心四大核心需求影响因素**

**人工智能新机遇：**如果把数字化业务比作一位国王，数据中心就是国王的王冠，而人工智能就是皇冠上的明珠。**对于未来数据中心的建设，数据智能方向是第一位的影响因素。**人工智能的发展经历了三个阶段。第一个阶段是面对小型数据集的早期的人工智能，以二战时期弹道导弹和密码的研究为主要代表；第二阶段以深蓝事件为代表，面向大型结构化数据集，机器学习算法开始应用。这一阶段相当于半自动化的系统，需要人工参与大量过程。目前的第三个阶段基于深度学习的方式，相较前两阶段有了跳跃发展，已经接近理想状态。具体到行业应用而言，有些应用相对成熟，如基于图像的应用和客服类、语音类应用；其他领域尚处在在发展过程中，既是机遇又有挑战。虽然没有完全成熟，但是它更有可能构成数字化转型中智能经济的核心竞争力，**这****是数据中心未来建设里面重要的影响要素。**

**行业应用创新：****应用模式正在发生深刻变化，由大型的应用程序到分布式微服务的小应用程序的转变。**传统的信息化建设，主要采用瀑布式的设计模型，如WMS系统、ERP系统都是自上而下的设计方式，参与厂商也遵循这样的特点进行项目建设。而目前新的应用形式是平台化的设计模式，应用未必在建设之初已经设计完全，而是将数据集中之后，基于数据以快速迭代的方式产生新的应用。例如IOS的APP应用商店发布，每年的增长幅度也比较大；安卓系统发布应用量更多。而工业级的应用相对处于起步阶段，应用的形态也存在很多变化。

**基础设施重构：**主要的影响要素来自两个方面：**一是上层的软件和应用算法方面的变化，导致硬件基础设施的变化；二是后摩尔时代带来的影响变化**。以往数据中心建设中，硬件的配置和产品的构成是比较固化的，而目前单纯依靠处理器的性能升级走到了瓶颈阶段，这影响了专用领域优化的技术路线建设；另一方面，数据量的激增带来对存储层面的影响。目前，计算、存储、人工智能和网络专业应用领域面已经实现产品化，未来将在芯片级别上出现深层次的解耦和重组合的架构，而安全方面可能影响硬件的设计。

**国家政策指引：**从2013年开始，**国家发布了多个关于数据中心的指导意见，将数据中心建设划到了新型工业化产业示范基地中，并在新基建政策中将智能计算中心明确划为新基建范畴。**目前，数据中心建设本身出现了一些挑战，在数据中心绿色、节能方面，国家逐渐加强了监管和引导。从统计数据看到，现有的数据中心能效和绿色相比全球水平差距较大，一些地方已经出台限制性政策，将PUE使用率低于1.4作为标准。

**基于以上四个影响因素，数据中心目前的建设需要演进到智算中心，也就是人工智能计算中心。**

**智算中心的定义**

智算中心概念，主要是帮助企业实现五个方面的能力：感知能力、连通能力、洞察能力、执行能力、安全能力。可以感知到生产线、设备现场数据；数据可以连通、进行汇聚；基于这些数据做出洞察和智能决策；基于洞察的决策能够反馈到现场，返回相关业务部门、业务系统进行对应的执行，最后新增加新的安全能力建设。这五种能力的建设是需要新一代的智算中心来承接。

2020年11月国家信息中心联合浪潮正式发布《智能计算中心规划建设指南》，对下一代数据中心建设提出了建议。基于经验，我们认为下一代的数据中心（智算中心）建设需要符合三、四、六，即三大原则、四层智能、六大特征。三大原则：开放标准；集约高效；普适普惠。四层智能是边缘智能—系统智能—数据智能—应用智能。六大特征指开放敏捷、分层解耦、资源池化、数据共享、多云融合和云边协同。

# 智算中心建设模型与演进之路

![](../Images/26e06dad976dc6aef67223b16bb801c2.png)

**智算中心的逻辑架构、全生命周期和关键域建设内容**

**逻辑架构：**落地建设中，最核心的是**智慧运营**，主要涉及到的问题是企业数字化组织的重构。有些行业的运行监控部门和信息化部门整合，原先的运营中心和信息中心是两个不同的部门，现在很多是把这两个部门合二为一做智慧化运营。比较重要的建设模式是基于数字化平台、比较核心的是数据智能，涉及到数据中心建设的技术领域相关话题。数字平台领域中，由原先的非你即我的竞争形态，改变为融合式的生态系统型的竞合关系。目前企业数字化建设主要涉及到两个领域，一是核心部分，**智算中心**的建设，增加了云、数、智这方面新的技术。二是**智能边缘**，既包含原有的生产线等现场，也包含了新增加的数字空间。从安全视角来看，现在的网络安全和传统的网络安全最主要的变化是云的安全、物的安全、数的安全。一个系统只要放到公网上，15分钟之内一定会受到攻击，云的安全如何保障成为重要的问题。关于物的安全，原有生产线系统采用物理隔离方式，工业互联网建设模式中要求有一定程度的连接，物的安全如何做保障？云、数、物的安全中，如蜜罐技术、数据沙箱技术、物的安全技术已有比较大的发展变化。

**全生命周期：**数据中心全生命周期的各阶段也有很多新变化。重点是一头一尾，一头是规划设计阶段，和以往的规划很大的不同是设计阶段和业务关联性比较高，投、建、运模式也不同。运行阶段是由原先的单纯的运维设计需要上升到运营的设计。

**七大关键域建设内容：****智算中心的建设包括绿色基础设施、智能基础架构、运维、安全可控、云化运营、智能洞察和分布互联七个关键建设领域，依托创新的产品技术，促进业务的数字化转型。**

**结语：智算中心的演进之路**

下一代数据中心的建设，是上升到第五代智算中心的建设，里面涉及三个关键步骤：**一是云化**，通过云化数据中心建设实现业务整合，并从行业、区域维度能够发挥更大的作用；**二是融数**，打破数据孤岛，实现数据共享，为智算中心提供生产资料；**三是赋智**，拉通生产算力、聚合算力、调度算力、释放算力四大作业环节，为智算中心构建创新引擎。
