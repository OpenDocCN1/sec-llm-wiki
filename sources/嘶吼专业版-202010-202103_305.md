# ![](../Images/4a7266f35eeaa775218073857f2a3602.png)直播抽奖，开启金帽子线下联动

2020ROARCTF赛段至此已接近尾声，嘶吼在12月11日将在陌陌直播平台开启最后一轮线上抽奖，参与直播抽奖请关注主播陌陌号：573093813

直播抽奖时间：2020年12月11日19：00

奖品预告：

![](../Images/3258a9b10378ba460dd2d458cda9657c.png)

![](../Images/6f877a38b07e77bcdabc6fcf7943dcb9.png)

欢迎大家积极参与线上抽奖，赢取幸运礼包！

除此以外，嘶吼2020年金帽子年度盛典已经进入公开报名阶段。

2020年12月23日，由北京市经济和信息化局、北京市通州区人民政府主办；网安园通州工作专班、北京通州科技创新投资发展有限公司、北京嘶吼文化传媒有限公司承办的【2020网络安全行业生态大会暨金帽子年度盛典】将在国家网络安全产业园区（通州园）北京汽车动力总成研发基地一层正式拉开帷幕。

届时，2020网络安全行业生态大会暨金帽子年度盛典将以主题论坛、网络安全产业白皮书发布、网络安全产业100强公布、金帽子年度盛典、金帽子CTF线下邀请赛五个环节展开年终的精彩盛典。

点击阅读原文金帽子线下报名参会。

届时，ROARCTF将与金帽子年度盛典正式开启联动，我们将对本次线上赛取得前八名积分战绩的战队发出定向邀请，参与到金帽子CTF线下邀请赛中来。

# ![](../Images/4a7266f35eeaa775218073857f2a3602.png)结语

再次感谢，我们相约明年再见！
