IBM发展了用于混合云控制的自动化和数据功能

IBM在继续增强其核心的Cloud Pak混合云软件产品。本周IBM加强了自动化和数据功能，这些功能将简化客户从软件配置和修补到数据发现和文档处理的所有工作。

IBM Cloud Paks是Red Hat基于Kubernetes的OpenShift容器平台与Red Hat Linux以及各种连接技术的捆绑包，使企业客户可以根据自己选择的私有或公共基础架构部署和管理容器平台，包括AWS，Microsoft Azure，Google Cloud和阿里巴巴。

Cloud Paks背后的核心思想是简化构建、编排和管理企业工作负载的多个容器。  

在自动化方面，新版本的Cloud Pak for Automation包括对IBM机器人流程自动化（RPA）的支持，以在日常任务的自动化上更进一步。IBM表示已经整合了RPA和7月份从WDG Automation手中收购的人工智能技术。 

RPA支持具有自动bot的功能，这些bot可以从不同来源起草信息，以帮助快速定义新的工作流。IBM表示，该平台包括工作流和决策工具，以加速自动化。

当注入AI的自动化应用于业务流程和IT运营时，它可以帮助缩短识别问题和做出响应之间的时间。IBM认为这是至关重要的，因为不可预见的IT事件和中断等等都可能会给企业带来收入和声誉的损失。

IBM还表示，它与myInvenio进行了合作，将自动化流程挖掘引入Cloud Pak for Automation。集成功能包括模拟、业务规则和任务挖掘。IBM表示，集成流程挖掘和任务挖掘的思想为全套超自动化功能提供了平台，myInvenio可以在其中发现和分析流程，而IBM Cloud Pak for Automation中的其他企业解决方案将对流程执行任何更改。

Gartner说，超级自动化理论涉及多种机器学习、打包软件和自动化工具的结合，在过去几年中这一理论一直在坚持不懈地前进发展，但是Covid-19大流行使得人们对所有东西都要“数字化优先”的需求却不断增加。Gartner说，积压的业务请求促使70％以上的商业组织采取了数十种超级自动化计划，“现在，超自动化的结果是不可避免的和逆转的。所有可以而且应该自动化的东西都将实现自动化。”

在数据方面，IBM推出了新版本的Cloud Pak for Data，IBM表示该版本可帮助企业收集、组织和分析数据，可以进行数据管理、DataOps、治理、业务分析和AI。

新版本的Cloud Pak for Data包括用数据科学属性构建的程序或加速器，用于银行、保修管理、供应链预测和零售。IBM Industry Accelerators(https://community.ibm.com/accelerators/?context=analytics&type=Cloud%20Pak%20for%20Data%20industry)，目前共有30个，是为解决特定行业用例而构建的样本数据科学资产。例如，IBM表示，资产包括示例数据集、预建的机器学习模型和示例仪表板。 

这些加速器背后的设计理念是用于帮助客户解决特定的业务问题，例如防止银行业中的信用卡欺诈。

IBM还增加了对新的深度学习服务功能(deeplearning service)的支持，该功能可监视名为Watson Machine Learning Accelerator的工作负载，以及一项名为Federated Learning的新功能，该功能使用户能够使用远程的安全数据集训练通用模型。IBM表示，借助此功能，数据集可以保持安全，而由此生成的模型则可以从扩展的培训中受益。

新的自动化和数据控制功能是对最近更新的Cloud Pak(https://www.networkworld.com/article/3584464/ibm-expands-role-of-core-hybrid-cloud-security-platform.html)的补充，用以提高其安全性。今年10月，IBM通过改进在客户网络内收集的安全数据集合，并利用第三方威胁情报源以及其他升级功能，扩大了其用于混合云部署的安全软件包的作用。

IBM的Cloud Pak for Security以搜索威胁的开源技术和加快对网络攻击响应的自动化能力为特色，它可以将客户现有安全点产品收集的数据整合到一个控制台上。新版本扩展了其集成功能，包括从分布式位置存储和访问的数据源，并支持Big Blue提供的IBM安全卫士系统(Security Guardian system)，该系统用于保护数据库、数据仓库和Hadoop等大数据环境。

IBM表示，有了这些信息，安全团队可以确定敏感数据在混合云环境中的位置、谁有权访问这些数据、如何使用这些数据以及最佳数据的最佳方法。新版本还包括对多供应商威胁情报数据库的支持。除了自己的X-Force威胁情报源外，该平台还将包括与AlienVault OTX、Cisco Threatgrid、MaxMind Geolocation、SANS Internet StormCenter和Virustotal的预构建集成。
