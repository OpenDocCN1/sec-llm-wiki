# 您的隐私很重要！隐私防护搜索引擎Top榜

诚如视频所示，我们的隐私正通过不同渠道“被分享”，我们的秘密早已暴露无遗。但是，正如电子前沿基金会（Electronic Frontier Foundation）所言，“如果你有什么不想让任何人知道的事情，也许你一开始就不应该做。如果你真的需要这样的隐私，事实上，包括谷歌在内的搜索引擎都会在一段时间内保留这些信息，明确这一点很重要。”

一方面，搜索引擎追踪你的数据是有道理的——它们必须将不连贯的词汇组合，比如“我附件的披萨”（pizza near me）翻译成有用的结果。否则它们怎么知道什么披萨是“靠近你”的呢？正是由于您的数据已经实现货币化，所以众多网站、广告商、浏览器和搜索引擎才会跟踪您在网上的行为，以便为您提供针对性广告、改进算法或改善服务。

当然，这并不等同说所有搜索引擎都是如此，还有很多其他的搜索引擎正试图将隐私改进作为其产品的基础。下面就为大家介绍几款真正注重隐私保护的搜索引擎：

# ![](../Images/4ad0ab71272ea6a41b97e1ca2e9e64e6.png)1. Mojeek

Mojeek是英国的一个隐私搜索引擎，其宣传口号是“独立、公正的搜索结果，没有用户跟踪。”作为一名隐私保护搜索引擎领域的“新人”，Mojeek的搜索量在去年增长了500%。这个以隐私为导向的搜索引擎表示不会追踪用户的任何身份信息，包括IP地址、搜索历史或点击行为等等。

Mojeek并不认同这种数据收集行为可以帮助它们提供更好的结果的想法，而是仅仅根据你输入的关键字对结果进行排名。此外，该公司还通过英国最环保的数据中心之一CustodianDC进行托管和运行。

据悉，Mojeek是基于C编程语言构建，不依赖于其他搜索引擎构建的索引。相反，Mojeek拥有自己的搜索索引，该公司声称它是世界上最大的搜索索引之一。而使Mojeek能够从其他搜索引擎中脱颖而出的功能是“情感网络”搜索功能。Mojeek 用户现在可以在网页上搜索，并按照内容是否可能会引发爱恋、欢笑、惊讶、愤怒或悲伤来选择结果。

链接：https://www.mojeek.com

# ![](../Images/4ad0ab71272ea6a41b97e1ca2e9e64e6.png)2. Swisscow

![](../Images/f557cce0acd2ae983b3e74be543b0c71.png)

Swisscow是由Hulbee AG（一家总部位于瑞士的科技公司）开发制作的搜索引擎。与该列表中的其他隐私搜索引擎一样，Swisscow也不会收集你的IP地址，也不会记录你正在使用什么浏览器进行搜索。除此之外，该公司还放弃了地理定位或使用cookie来确定用户的额外信息等策略。Swisscow强调它不会与第三方共享任何信息，或者说它没有能力与第三方分享信息，因为它压根就不会收集或存储你的信息。

不过，Swisscow也坦率地谈到了它们方法的局限性，指出一旦你通过搜索中出现的链接离开它们的网站，那么它们的隐私政策便不再适用了。这是一个很有用的提醒，大家使用时需要注意。

唯一值得考虑的一点是，Swisscow会对其搜索结果进行审核，以确保其适合家庭使用（类似未成年保护模式），这一点对于一些人来说可能是有利的。该网站指出，它们宣扬道德价值观，憎恨暴力和色情，并促进数字媒体教育。对于家长来说，这样一来可以帮助帮助保护孩子的隐私，限制其浏览不健康的内容。然而，对于另外一些人来说，这可能是放弃使用它的一个原因。

链接：https://swisscows.com/

# ![](../Images/4ad0ab71272ea6a41b97e1ca2e9e64e6.png)3. Duck Duck Go

![](../Images/1a246b326b7b13842e2fec69bc673622.png)

这可能是最知名的隐私搜索引擎。DuckDuckGo成立于2008年，在关注网上隐私的用户中颇受欢迎，目前总搜索量已达20亿次。

DuckDuckGo不使用日志或跟踪，有一个非常友好的用户界面，及最少化的广告。其首席执行官Gabriel Weinberg曾表示，  

“如果联邦调查局来找我们，我们也交不出任何东西。”

正是因为不会跟踪你的搜索行为，所以它们无法一举切中目标，给出你最理想化的结果，但是它仍然能够提供一个非常良好的搜索质量，因为它的搜索主要是通过Yahoo！话虽如此，但它也并非万无一失的：它不会通过本地加密保护你，不会删除浏览历史，而且是一家总部位于美国的公司，运行着亚马逊的云计算服务，这意味着你的隐私可能会在某些地方受到损害。  
2017年，Brave将DuckDuckGo添加为您在移动或桌面端使用浏览器时的默认搜索引擎选项。在Brave浏览器中，当您进入私密标签页（隐身模式）时，搜索结果将由DuckDuckGo提供。

去年，谷歌也将DuckDuckGo添加到安卓及平台上的搜索引擎列表中。苹果现在也允许用户使用DuckDuckGo作为iOS 14首选的搜索引擎。

DuckDuckGo最近还为其产品线添加了新的扩展。它不仅可以保密您的搜索，还可以对您访问的网站的隐私进行评分。

链接：https://duckduckgo.com/

# ![](../Images/4ad0ab71272ea6a41b97e1ca2e9e64e6.png)4. Qwant

![](../Images/ca5fcda568e231c0c3391f0a379cbf9e.png)

Qwant是一家总部位于法国的以隐私为导向的搜索引擎。根据其网站介绍，它们从不记录你的搜索或收集你的个人数据用于广告投放。Qwant提供了许多与DuckDuckGo类似的功能，其中包括一项名为“Qwick搜索快捷键”的功能，允许用户使用键盘快捷键对许多特定网站进行搜索。通过添加符号“&”或“!”然后加上你最喜欢的网站的名字，你马上就能看到结果。

值得一提的是，Qwant甚至得到了官方的支持。2018年，法国军方和议会均表示，它们决定放弃使用谷歌，而改用Qwant作为他们的默认搜索引擎。

链接：https://www.discretesearch.com/

# ![](../Images/4ad0ab71272ea6a41b97e1ca2e9e64e6.png)5. Search Encrypt

![](../Images/b629800cf2278401590a1a8a621436e0.png)

Search Encrypt 是另一个把隐私放在首位的搜索网站。该公司声称，它不会追踪用户的任何可识别信息，而且使用本地加密来保护您的搜索安全。根据该网站的数据显示，它每天有2300万的访问者。与其他引擎不同的是，它是一个元搜索引擎。这意味着它使用另一个搜索引擎的数据来产生自己的结果，从其搜索合作伙伴网络中检索您的搜索结果。

该引擎最独特的功能是自动删除你的本地浏览历史记录，这些记录在网站上存在15分钟左右就会自动清除，所以，即便有人访问了你的计算机设备，上面也不会残留任何你的本地搜索历史记录。  
最近,Search Encrypt 又添加了更多新功能，包括隐私友好视频，新闻和地图搜索。通过视频搜索，您可以直接在搜索引擎上观看视频，并提供额外的隐私保护，并且无需预先制作广告。

链接：https://www.searchencrypt.com/home

当然，除此之外，像是StartPage、Gibiru以及Ecosia等等都是非常优秀的隐私搜索引擎，你可以根据自身需求，寻找适合自己的工具。
