# 珞安科技连续完成B+、B++两轮融资，金额1亿元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247526865&idx=2&sn=c0d930c373e6c84858c78d909d79e09f&chksm=e915b9ebde6230fd54422f7cc4749fa119f307a2a6ba8cf6635149c337eb4b4d0d7bb01591b6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247526865&idx=2&sn=c0d930c373e6c84858c78d909d79e09f&chksm=e915b9ebde6230fd54422f7cc4749fa119f307a2a6ba8cf6635149c337eb4b4d0d7bb01591b6&scene=27#wechat_redirect)

近日，工控安全企业珞安科技连续完成B+、B++两轮战略融资，合计融资金额1亿元人民币。B+轮融资由容腾5G产业基金、上汽产业基金联合投资，B++轮融资由背靠苏州工业园区的品牌基金元禾重元独家投资。继获得深信服旗下琥珀资本领投，加盛投资、同创伟业追投的B轮融资后，再次引入多家产业战略投资方。  

![](../Images/36c096ef8b91841ad79f64454df7b1d9.png)

随着网络安全等级保护2.0制度的正式颁布，工控安全作为保障国家关键信息基础设施的重要组成部分被严格规范，已上升到国家战略高度。与此同时，随着工业互联网建设提速，信息化与工业化持续深度融合，网络与业务安全场景越发复杂，工业互联网不同业务层级间的数据交互，对安全防护又提出了更高要求。在多种因素共同作用下，国内工控安全行业需求迎来集中爆发。  

珞安科技成立于2016年，是国内技术实力领先的工控安全企业。公司以技术创新作为核心驱动引擎，自成立以来一直坚持自主研发，拥有30余项发明专利，7大类20余款自主研发的安全产品，与多个自动化厂商的业务系统实现了深度融合。拥有面向电力、石油石化、轨道交通、智能制造等多个重点行业的工控安全产品和服务解决方案，为国内超1500家监管机构和工业企业提供安全服务，获得多家行业龙头客户认可。  

![](../Images/262a262330d6a994eb9294d9b7c466ed.png)

随着工业互联网的普及，信息技术与工业生产深度融合，行业应用加速拓展纵深，安全问题的影响更加广泛。在工业互联网安全方向上，依托三一重工、深信服、上汽集团等产业股东的赋能，珞安科技有望更加深入工业场景，进一步迭代和打造高防护能力、稳定可靠、业务实用的安全产品，成为工业互联网安全行业中的塔尖企业。

在坚持产品创新、加大技术领先优势的基础上，珞安科技积极践行“生态赋能”战略，与渠道合作伙伴共享长期生态合作价值链，创造最大化客户价值。迄今为止，公司核心渠道已覆盖全国百余个省市，涉及全部工业环境，实现工业应用场景全覆盖、工业安全产品全覆盖。依托遍及全国的销售渠道，2020年，珞安科技的收入规模已达到亿元级别。

珞安科技CEO张晓东表示：“在国家政策和市场需求的双核驱动下，可预见未来几年工控安全行业将面临井喷式高速发展。接下来，珞安科技将继续砥砺前行、牢记使命，坚持自主创新，将产品、技术、人才和品牌作为公司长期核心竞争力，不断巩固既有行业优势的同时，进一步提升区域渠道支撑能力，努力为用户提供专业、便捷、及时、高效的安全服务和技术支撑，为国家关键信息基础设施安全稳定运行保驾护航。”

上汽恒旭资本董事长陆永涛表示：“祝贺珞安科技本次融资。珞安科技在工业安全漏洞检测、攻击事件溯源方面具备资深技术积累，同时为客户提供安全治理与规划、风险评估，我们也在积极推动工控安全与整车厂产线的平稳衔接。”

容亿投资投资总监闻茗萱表示：“5G与工业互联网融合发展是抢占新一代科技革命制高点的重大抉择，同时5G+工业是推动产业数字化的重要抓手。工业互联网作为5G的两大重要应用场景，是容腾5G产业基金重点布局的方向。安全是工业互联网建设的基石，其安全关系到经济发展与社会稳定。容亿投资在工控安全赛道的选择更加注重的是企业产品的持续研发能力，珞安科技就是工控安全领域为数不多的具备全产品线研发能力的企业，创始人张晓东、孔令武对产品定位和规划思路清晰，能够准确把握下游市场的发展趋势。我们看好的是珞安科技在业务安全上的认知和布局，对于工业企业而言，工业的现场边缘侧是其工业数据的重要入口，工控安全厂商占据该入口，向上延伸的弹性是非常大的。由于等保合规要求，工控安全产品已经逐渐同质化。对于工控安全厂商而言，只有立足于工控安全，向外延伸，才能打破自身成长的天花板，在市场激烈竞争中占据一席之地。随着近两年的深耕，珞安科技已经在电力、油气等行业有大量产品和落地案例，我们相信珞安科技在业务安全领域将发展得越来越好。”

元禾重元合伙人李炜琦表示：“随着国内工业数字化水平的提升以及政策的持续推进，工业互联网顶层设计逐步清晰，安全已经成为工业生产的核心要素，也给工业互联网安全市场带来了巨大的产业机会。我们坚定看好以产品技术作为核心驱动力的珞安科技，将协调元禾体系的优质资源赋能企业，也期待通过珞安科技和产业合作伙伴的资源，在工业信息化领域进行更广泛的布局。”

眼下，以5G、物联网、人工智能等技术为代表的第四次工业革命正蓬勃兴起，工业网络安全领域也将面临更多、更新、更复杂的挑战。

作为国内工控安全领域的技术推动者，未来，珞安科技将紧跟技术变革快速创新，保持产品竞争力及核心技术优势，并通过与产业合作伙伴在业务、资源等方面展开深度合作，持续打造更实用、更全面的工业网络安全解决方案，助力工业企业网络安全防护能力提升，为国家关键信息基础设施建设和发展贡献力量。
