# 美英澳联合发布2020年被利用最多的安全漏洞

美英澳联合发布公告，分析2020年被利用最多的安全漏洞。  

近日，美国国土安全部下网络安全和基础设施安全局（CISA）、英国国家网络安全中心（NCSC）和澳大利亚网络安全中心（ACSC）三国网络安全机构联合发布了一份网络安全公告，其中详细描述了2020年被攻击者利用最多的30个安全漏洞。

根据美国政府的数据，2020年被利用最多的30个安全漏洞中大多数是过去2年中公开的。

其中利用最多的4个漏洞影响远程办公、VPN和基于云的技术。2020年许多VPN网关设备漏洞仍然未被修复，受疫情影响，远程办公用户数量激增，要求企业及时进行补丁修复。

![](../Images/b7601594c12a399c9a9d78f0e2055292.png)

其中CVE-2019-19781是2020年被利用最多的安全漏洞，是Citrix Application Delivery Controller（ADC，应用交付控制器）中的安全漏洞，ADC是美国广泛应用的web、应用、数据库服务器的负载均衡应用。该漏洞被利用最多的原因是该漏洞容易利用、Citrix服务器被广泛使用，漏洞成功利用可以被目标系统上实现非授权的远程代码执行。

2020年初发现的未修复的漏洞CVE-2019-19781和CVE-2019-11510被国家级APT组织广泛利用。CVE-2019-11510是Pulse Connect Secure VPN中的安全漏洞，攻击者利用该漏洞可以窃取被黑的Pulse VPN服务器上的未加密的凭证。

2021年，恶意攻击者仍然在利用这些漏洞来攻击企业和用户。其中2021年被利用最多的漏洞是微软、Pulse、Accellion、VMvare和Fortinet中的漏洞，包括：

◼Microsoft Exchange: CVE-2021-26855、CVE-2021-26857、CVE-2021-26858、CVE-2021-27065

◼Pulse Secure: CVE-2021-22893、CVE-2021-22894、CVE-2021-22899、CVE-2021-22900

◼Accellion: CVE-2021-27101、CVE-2021-27102、CVE-2021-27103、CVE-2021-27104

◼VMware: CVE-2021-21985

◼Fortinet: CVE-2018-13379、CVE-2020-12812、CVE-2019-5591

安全公告中包含漏洞的详细技术细节、IoC和修复方法，详见https://us-cert.cisa.gov/sites/default/files/publications/AA21-209A\_Joint%20CSA\_Top%20Routinely%20Exploited%20Vulnerabilities.pdf
