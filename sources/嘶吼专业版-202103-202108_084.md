# 中科网威完成B轮融资， 深耕自主可控安全平台及军工电子信息安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247525704&idx=4&sn=5666b760177ff6c466095d5534608b6f&chksm=e915b572de623c64de32f0ffe2253547c90900ef4d5571d05f1e86c35ded6025c7bef791a26d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247525704&idx=4&sn=5666b760177ff6c466095d5534608b6f&chksm=e915b572de623c64de32f0ffe2253547c90900ef4d5571d05f1e86c35ded6025c7bef791a26d&scene=27#wechat_redirect)

2021年7月，北京中科网威信息技术有限公司（以下简称“中科网威”）成功完成B轮近亿元融资，由专注于网络信息安全领域的专业投资机构奇安投资领投，京福资产跟投。  

当前，国家对信创产业高度重视，围绕数字化转型，从办公应用和终端替换入手，以政策拉动国产软硬件的市场，着力打造信创产业群、培养一批龙头企业。中国电科、中国电子等大型央企代表国家队积极构建较为完善的自主可控产业链，越来越多的厂商正在参与进来，重点适配产业链上下游，增强自身的兼容性，构建产业生态。目前军工行业和政府部门已各自建立了自主可控产品名录，把基础软硬件和网络安全纳入了入围名录。

中科网威是国内最早从事自主可控网络信息安全产品技术研发的企业之一。早在2011年就开始布局并确立了国产自主可控网络安全产品的技术发展路线，先后与申威、飞腾、龙芯等企业和机构建立了深入合作关系，共同研发基于国产处理器芯片的防火墙、入侵检测、入侵防御等网络安全防护产品。多年来，中科网威一直关注和跟踪国内外安全发展形式及前沿技术，拥有大量的发明专利和相关创新技术，尤其在国产化平台系列产品的研发过程中，摸索和研发了多项关键核心技术；针对未来技术发展方向，在充分调研国内外市场需求和技术发展趋势下，结合自身的技术和业务积累，在云安全、零信任、拟态安全、高性能多态网关、自主可控国产化高性能加密机等新技术方向上，正在进行技术和产品的研发工作，部分产品已经开始在市场得到应用。经过十多年的耕耘和努力，目前已基于申威4核、16核、32核等处理器、龙芯多款处理器、飞腾多款处理器研制并推出了系列自主可控网络安全产品，其中近二十款产品成功入围政府和军队关键软硬件自主可控产品选型目录，并实现了政府、军工等行业的规模应用。值得一提的是，中科网威于2021年5月并购整合了国产处理器硬件平台厂商北京正阳天成科技发展有限公司，从业务层面实现产销研一体化，有力推动了供应链和产品整体交付能力的升级，尤其是军工产品定制能力得到进一步加强，综合实力得到极大提升。

奇安投资副总经理张俊善表示，在国家大力扶持信创产业的背景下，中科网威基于国产处理器研发产品的十年积累将迎来市场机遇期。公司主要创始团队来自于军队军工体系，熟悉军队军工业务，近年来业务增长迅速，“十四五”期间增长潜力巨大。中科网威是市场上少数同时拥有上层应用能力以及底层硬件设计及研发能力的企业，可以通过纵向一体化能力在市场竞争中取得技术及成本优势，是为数不多的能够真正实现“自主可控、安全可靠”的平台化产品及解决方案提供商。本轮融资后，希望中科网威更加聚焦军工电子网络安全方向，进一步加大研发及创新投入，围绕国产平台夯实产品能力，充分利用在自主可控领域积累的核心竞争力和技术优势，更好地满足军队军工以及党政客户需求，发展成为具有军工特色的国内领先的网络安全厂商。

中科网威董事长刘兵表示，本轮成功融资是中科网威继2019年完成MBO后又一重大里程碑事件。本次业内专业投资机构的资本注入，将加快中科网威在自主可控和安全可靠产品技术上推进的步伐，加大研发创新投入，继续布局自主可控产品和技术创新，进一步形成基于自主可控技术的新型多态网关产品、拟态安全产品、云安全产品和零信任架构产品为核心的安全产品解决方案，同时聚焦军工电子网络安全领域，扩大企业在军队军工电子领域的影响力。

随着国内国际形势的发展变化，网络信息安全国产化、自主化已成共识和趋势，中科网威将进一步积极致力于为用户尤其是军队军工客户提供安全可靠的产品和服务，协助用户构建多维度、多层面的网络信息安全防御体系，为实现成为军工电子领域自主可控网络信息安全领先企业的愿景踏实迈进！

# ![](../Images/518a54c953536c226f1c227b96b8351d.png)本轮投资方简介

奇安（北京）投资管理有限公司成立于2017年9月，是国兴投资、奇安信集团、熙诚金睿和核心团队成立的专注于网络安全方向的投资平台，核心团队来自大唐电信、中国网安、奇安信、宽带资本、晨晖资本等国内网络安全产业集团及专业投资机构，具有深厚的网络安全产业背景和丰富的网络安全项目投资经验。

奇安投资以“构建网安行业生态、赋能创业企业成长”为使命，通过赋能式投后管理，实现被投企业之间以及被投企业和网络安全龙头企业、甲方客户、第三方行业咨询机构等形成网安行业生态，实现共同成长。致力成为中国网安行业最专业、最具影响力的投资机构！

截止目前，奇安投资已投资二十多家优秀网络安全企业，包括永信至诚、上海观安信息、威努特、江南信安、国舜股份、天际友盟、盛华安、悬镜安全、观成科技等。

京福资产管理有限公司成立于2007年8月，注册资本金1亿元人民币,是在中国基金业协会登记备案的股权、创业投资基金类私募基金管理人，以及中国保险资产管理业协会会员单位，具备管理保险资金的资质。京福资产发起人和核心团队均为金融市场的资深专业人士，大多具备20年以上的海内外投资背景。

公司拥有PE/VC基金、产业并购基金、政府引导基金、证券投资基金、实业投资五大业务板块，截止2020年12月，累计资产管理规模达230亿元人民币。公司发行PE/VC基金九只，共投资了40余家已上市及拟上市公司股权，聚焦在半导体科技、新能源、信息安全、医疗等多个有潜力的行业赛道。
