# Windows 11中将禁用IE浏览器

即将发布的Windows 11系统中将禁用IE浏览器。  

6月24日，微软召开新闻发布会，宣布推出新的Windows 11系统。这是微软近6年来首次推出新的Windows系统，新版Windows 11系统预计7月开始向应用开发者推送，年底正式发布。

微软在官方发布Windows 11系统后，同时也列出了一些新操作系统中移除的应用和特征，其中就包括Internet Explorer。微软称，IE在Windows 11中将不可用IE，但微软Edge浏览器中仍然包含了IE模式特征，因此，Edge浏览器可以作为微软IE浏览器的替代。

今年5月，微软就宣布对部分版本的Windows 10系统，IE将于2022年6月15日停止支持。部分必须使用IE来访问某些应用的用户可以使用微软edge浏览器的IE模式，可以兼容所有的IE功能。

用户在使用IE模式时，地址栏会有一个小的IE图标来表明处于IE模式，如下图所示：

![](../Images/f2f6348816560364f8514b7af7c2579f.png)

Edge 浏览器IE模式

目前，Windows 11系统不再可用IE浏览器，edge 浏览器中也包含了IE模式，目前还不清楚微软是否会加速Windows 10中的不可用。由于IE的应用包含Windows 10企业版，因此微软可能会继续支持IE浏览器，直到Windows 10结束生命周期。
