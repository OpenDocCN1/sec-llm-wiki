# Google I/O 2021开发者大会 | 安卓12 隐私新特性

在5月18日举行的Google I/O 2021开发者大会上，谷歌官宣史上最个性的Android系统——Android 12，安卓12系统中引入了许多新的隐私特征。  

虽然这些隐私特征与iOS非常相似，但与iOS的隐私特征相比，在许多方面都做了改进。

# ![](../Images/23875c55575c8b1b95cde9e7f2d439ba.png)摄像头和麦克风的访问通知

当APP访问摄像头或麦克风时，用户会收到通知。但是通知位于屏幕顶端，而且非常小，只是提示用户摄像头或麦克风正在使用。

![](../Images/b994e522ce8e8b034786ac43858693c1.png)

摄像头和麦克风访问通知

摄像头和麦克风访问通知的实现与苹果iOS系统非常类似。在iOS系统中使用的是绿色和橘色的小点。谷歌额外增加了独立的按钮来关闭APP对于麦克风和摄像头的访问，使得用户可以对隐私有更好的控制。

# ![](../Images/23875c55575c8b1b95cde9e7f2d439ba.png)位置信息

安卓12中引入的另外一个隐私特征就是位置信息的访问。与iPhone类似，在安卓12系统中，用户可以授予APP访问非精确位置数据的权限。

![](../Images/62c2f567f305f207377e1b69fb6580b6.png)

大致位置数据

# ![](../Images/23875c55575c8b1b95cde9e7f2d439ba.png)剪贴板读取通知

当APP从剪贴板读取数据不是从APP中生成的内容时，用户也会收到通知。这一特征关注窃取用户剪贴板信息的APP。

# ![](../Images/23875c55575c8b1b95cde9e7f2d439ba.png)其他隐私特征

相比iOS系统，安卓12中也引入了许多新的iOS中不存在的隐私特征。比如，谷歌相册中锁定文件夹，使得用户可以有空间来保存隐私照片。

在安卓12 beta 2中，还引入了隐私时间轴的功能，用户通过该功能可以查看过去24小时访问了位置信息、麦克风、摄像头的APP。通过该功能，用户可以更好地管理隐私相关的权限。

![](../Images/aa1b432de3acee4f400995dc9cb43429.png)

隐私时间轴
