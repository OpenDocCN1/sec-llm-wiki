# 微软遭遇大规模宕机：神秘bug删除Microsoft Teams、SharePoint文件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247517946&idx=1&sn=54c6189476c0675cad291e5530bcf3cc&chksm=e91556c0de62dfd6249046a7909c7c2a2a2be81b47b329d8d94d354101c1dbc2d2eb4f48d023&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247517946&idx=1&sn=54c6189476c0675cad291e5530bcf3cc&chksm=e91556c0de62dfd6249046a7909c7c2a2a2be81b47b329d8d94d354101c1dbc2d2eb4f48d023&scene=27#wechat_redirect)

![](../Images/420eebaabdd6d1a2df52ecface4cf38c.png)

3月15日，微软遭遇了大规模的宕机，影响了几乎私有的云服务，包括Microsoft 365、Microsoft Teams、Xbox Live、Exchange Online、Outlook.com、SharePoint等。随后，微软确认这次宕机事件是由于Azure Active Directory 服务配置问题引发的。近日，多个Microsoft SharePoint 和 Microsoft Teams 用户报告称，Azure Active Directory服务宕机后其SharePoint文件夹中的文件莫名其妙消失了或被移到了垃圾箱。  

Microsoft SharePoint管理员分析该问题时发现，SharePoint文件夹结构没有任何问题，但是其中所有的文件都消失了。最后，研究人员发现这些被删除或莫名消失的文件位于SharePoint 的云回收站或本地电脑回收站中。

![](../Images/958b1338103c99bf06138f1325676fe4.png)

因为文件夹都在，只是文件消失了，而且回收站的文件是几乎同时被移动到回收站的，因此对于普通用户来说，在很短的时间内删除这么多的文件几乎是不可能的。唯一的方式是删除所有的文件夹，但是文件夹的的子文件夹还在啊。

微软给出的公告只是描述了问题，并称文件会在重新同步后恢复。部分用户收到过文件会被移动到回收站的消息。受影响的用户可以通过重启机器的方式重新同步来解决这一问题，之后的文件同步会恢复文件到对应的本地文件夹中。

文件被删除的原因就是周一的Azure Active Directory (AAD)宕机。但是为什么文件会被删除，目前还未可知。

此外，Microsoft Teams Free也受到该宕机事件的影响。用户在访问文件时会显示错误，文件被删除，或用户没有查看权限等。

![](../Images/3480a972d1309ba1086d1faae95dceba.png)

Microsoft Teams 产品经理Sam Cosby称，已经找到了文件被删除的原因，将会尽快修复，但是仍然没有解释文件消失的具体原因。
