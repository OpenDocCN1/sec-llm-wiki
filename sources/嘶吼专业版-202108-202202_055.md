# 安全加码！安全玻璃盒\[孝道科技\]完成数千万首轮融资

安全玻璃盒【孝道科技】近日完成数千万首轮融资，本轮融资由国内领先的安全上市公司杭州安恒信息股份有限公司（股票代码：688023）主投，资金将用于DevSecOps、软件供应链安全及云原生应用安全保护平台的技术研究、产品开发与升级。  

# ![](../Images/ec0634813d07e80e283770391c7a16da.png)开发安全与软件供应链安全的创新先行者

“十四五”时期，我国数字化转型已经进入新阶段、达到新水平，在乘势而上向第二个百年奋斗目标进军的今天，全面保障网络信息系统安全可靠运行日益成为带动全国数字化升级的首要任务之一。尤其是开发安全与信息软件安全供应链中囊括的一系列信息系统基础设施，均需要严格执行安全保障目标和安全要求。

安全玻璃盒【孝道科技】自主研发了基于全球领先的AI智能动态检测防护技术的自鉴系列-交互式应用安全测试系统IAST、自鉴系列-开源组件安全分析系统SCA、自御系列-数字化应用软件安全平台ASTP等开发安全与软件供应链开发安全系列工具。让安全赋能到开发、测试及运营等各个环节，对数字应用以及所引用的三方组件漏洞，实现在线无风险、高效自动化、全面精确可视化的漏洞检测和风险定位。从安全源头解决根本性的安全风险，以保障数字应用上线前的安全性，避免应用带病运行，让应用自身具备抵抗力和抗攻击能力。当发现漏洞或遇到异常攻击时将立即激活自适应防护机制，实现攻防结合。让数字应用具备自我检测和自我免疫的安全能力，从而构建适应数字化、云原生环境下的一体化全生命周期数字应用软件安全解决方案。满足数字应用在线化、数据化和智能化场景下的安全赋能，适应当下开源软件安全以及软件供应链安全的迫切需求。

# ![](../Images/ec0634813d07e80e283770391c7a16da.png)DevSecOps实践引领者

安全玻璃盒【孝道科技】在国内率先推出DevSecOps安全解决方案。DevSecOps安全解决方案集开发、安全、运营于一体化。聚焦于DevSecOps实践以及安全的流程化，规范化。让安全渗透在软件生命周期的每一个阶段，实现技术与安全的同步、安全与成本的均衡。从最初的立项、设计到集成、测试、部署直至软件交付、运营以及监控，能够在软件开发生命周期的每个阶段自动集成安全性，实现多维度体系化的安全赋能。能够助力于安全工具链的建设，解决开源安全风险、软件漏洞风险等安全问题。同时，在更高的层面上，也能够作为助力软件供应链安全的重要手段，全面提升整体的安全效率和安全水平。

目前已为金融、政府、企业、医疗、教育等行业提供了DevSecOps安全解决方案并得到市场的高度认可。
