# 某加密货币交易平台483个账号被黑，提现3400万美元

Crypto.com受到网络攻击，确认有483个账号被黑，价值3400万美元的加密货币被提现。  

# ![](../Images/dfa1e5b7e249f8c110af499b1a49a5d9.png)Crypto.com事件分析

从每日交易量来看，Crypto.com是全球第三大加密货币交易平台。该平台旨在加速全球向加密货币的过渡。1月17日，Crypto.com 风险监控系统检测到有账号存在非授权的可疑活动，用户在没有双因子认证的情况下进行了交易。经过分析Crypto.com确认有483个账户受到此次网络攻击的影响。

研究人员分析认为受此次被黑事件影响的加密货币价值在1500万到3300万美元之间。最终确认有价值3380万美元的比特币、以太币和其他各种加密货币被提现。其中有443.93BTC，价值约1861.36万美元，4836.26ETH，价值约1513.25万美元，以及价值6.6万美元的其他数字货币。

![](../Images/844e6c4f42cfe3a83bce83ab99d0b3a5.png)

但Crypto.com Marszalek强调，安全团队立即响应并评估事件影响，平台的所有提现都被中止了，客户资金是不受影响的。为阻止提现活动，提现基础设施下线约14小时，直到2022年1月18日才恢复运行。所有提现交易在2022年1月18日被恢复到之前状态。

# ![](../Images/dfa1e5b7e249f8c110af499b1a49a5d9.png)Crypto.com采取的安全措施

受该事件影响，Crypto.com平台采取了新的安全加固措施，并撤销了所有用户的双因子认证token。此外，还要求用户登录APP来设置新的双因子认证token。
