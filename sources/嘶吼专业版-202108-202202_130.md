# 《信创安全典型行业应用专题报告》正式发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247534114&idx=1&sn=c61665484eb8ee31ac978f051d156e1a&chksm=e9159618de621f0e8d368dcb8688dc3acc393b1b9519908d7e7acb9af9706b3133a39252453b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247534114&idx=1&sn=c61665484eb8ee31ac978f051d156e1a&chksm=e9159618de621f0e8d368dcb8688dc3acc393b1b9519908d7e7acb9af9706b3133a39252453b&scene=27#wechat_redirect)

国产化信息技术创新应用安全（信创安全）是我国长期重要的国家战略，目前在内部需求和外部压力下，其战略和经济意义逐步凸显。一方面，国产化信息创新安全发展有利于我国在信息安全方面进一步可靠；另一方面，在当前国家经济“双循环”的发展格局下，对于加快企业数字化转型和推动经济持续发展具有护航赋能的现实意义。站在第二个百年奋斗目标的起点，推进信创安全发展是重中之重。虽然信创安全的本质是护航国产化厂商/产品的数字化转型，为各行各业提供安全基石与技术服务保障，但现实情况是目前信创安全普遍以政策驱动为主，真正市场驱动较少，尚未形成规模化发展态势。  

基于对行业的深入研究与观察，嘶吼安全产业研究院在“2021网络安全行业生态大会暨金帽子年度盛典”上正式发布《2021信创安全典型行业应用专题报告》，首席分析师王盈在大会上发表主旨演讲。报告涵盖三大部分10个细分内容，具体包括产业背景、行业现状、市场痛点、投融资情况、生态环境、盈利模式、安全厂商解决方案应用案例和趋势分析等。

报告指出，信创安全厂商的能力构建需要四个方向的积累：安全能力、开放能力、业务能力和融合能力，对于安全厂商来说，叫醒用户的预期可以降低，先聚焦在【叫醒信创安全厂商自己】。在典型应用部分，选取三大典型场景——政务场景、金融场景和能源场景进行深度梳理，通过六家安全厂商——天融信、360集团、信安世纪、通付盾、瑞数信息和融安网络的具体案例进行解读剖析。对于国产化信息技术创新应用安全行业所关注的几个重点问题在报告中也有体现，下面简单梳理下以飨读者。

# ![](../Images/13892f7626110cf740aa3e3e30f9454f.png)问题一：信创安全到底处于什么阶段？

**嘶吼安全产业研究院：****信创安全产业整体处于发展初期阶段，需要跨越鸿沟**

整体来看，信创安全目前渗透率仅为2%-4%，根据创新扩散理论，还处于创新者到早期采用者时期，属于发展初期阶段，需要跨越鸿沟，才能迎来真正高速发展。国家大力支持信息技术应用创新的深度构建，搭建产业标准，构建产业生态，保障产品和技术安全可控，只是从政府侧进行了推进，但真正的市场需求还尚待挖掘。

![](../Images/e7abd2eb6b3894d634fd0a3308119ee2.png)

# ![](../Images/13892f7626110cf740aa3e3e30f9454f.png)问题二：信创安全市场规模情况如何？

**嘶吼安全产业研究院：**2020年国产化信息安全的市场规模为14.5亿元，仅占整体网络安全的3%。2018年是信创安全元年，从这一年开始，一部分信息安全企业开启适配国产化服务器、芯片、数据库的安全产品建设，资本开始出现新一批涌动，风投、运营商或安全厂商开始加快对具有国产化安全能力的创新企业的投入，但市场规模仍然主要来源于政府、军工以及部分金融企业。

![](../Images/c8c854da6ed75786e6ab03779e8e7bb7.png)

# ![](../Images/13892f7626110cf740aa3e3e30f9454f.png)问题三：信创安全的主要玩家都有谁？

**嘶吼安全产业研究院：****目前信创安全产业玩家喷涌而出，但需求和安全保护还是各自为营，并未实现有效融合**

![](../Images/7c14cdc8bb7e086301ec4bf7bd893625.png)

**信创安全全景图谱解读：**嘶吼安全产业研究院的产业图谱是从需求端和安全端两个视角来对比设计的。从需求端，按照自主可控设备、设备的应用、产生的数据和设备存在的环境四个方面进行划分；而安全端则不能按照对应的需求进行梳理，只能按照安全产品大类来划分，这些大类包括：安全防护、安全审计检测、终端安全、安全管理、数据安全、密码安全和身份安全等，这背后反映出需求和安全能力并未更好融合的现状。

# ![](../Images/13892f7626110cf740aa3e3e30f9454f.png)问题四：信创安全的应用行业有哪些，典型的行业应用案例是什么？

**嘶吼安全产业研究院：**本报告着重选取三大典型应用场景——政务、金融和能源，通过厂商商业路径、产品布局、具体行业应用案例、主要亮点进行深度剖析，让生态更好的了解变化中的安全厂商的整体情况和具体应用情况。

# ![](../Images/13892f7626110cf740aa3e3e30f9454f.png)问题五：信创安全的未来趋势有哪些？

**嘶吼安全产业研究院：**随着国产化信息技术创新应用安全产业的快速发展，安全以更加真实而富有生机与挑战的模样展示在我们面前，从技术到产品、从解决方案到具体场景。就未来的发展趋势，嘶吼安全产业研究院认为主要有三方面：1从终端替换逐步回归业务本源——安全原生；2 从叫醒信创厂商自己到叫醒用户；3 现阶段对于安全厂商来说，能力提升仍是关键。
