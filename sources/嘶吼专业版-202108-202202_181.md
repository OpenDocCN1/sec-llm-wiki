# 信长城百日资本再破局，彰显物联网安全潜力

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247533005&idx=3&sn=7ed7b6d4539cc7afa205f3d71e29c25e&chksm=e91591f7de6218e18b5b0741768094464b5add12dc552d37f75840b75a64f09d84c88481cbcf&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247533005&idx=3&sn=7ed7b6d4539cc7afa205f3d71e29c25e&chksm=e91591f7de6218e18b5b0741768094464b5add12dc552d37f75840b75a64f09d84c88481cbcf&scene=27#wechat_redirect)

![](../Images/420eebaabdd6d1a2df52ecface4cf38c.png)

近日，物联网安全领军企业信长城百日内再获资本青睐，千万融资助力持续领跑物联网安全市场。信长城积累多年的物联网底层安全能力和未来物联网安全的巨大潜力，获得了资本的一致认可，彰显了资本对信长城和物联网安全赛道的信心。此次B+轮投资由知名机构朗玛峰创投和联储创投联合投资，密码资本继续担任企业独家财务顾问。  

自2017年成立以来，信长城始终致力于以密码技术为基础，结合可信计算思想，为物联网产业提供安全产品和服务。目前，公司已初步搭建了交付轻量化、模块标准化，快速适配多场景的物联网安全体系。本次融资不仅彰显了信长城的技术能力和市场潜力，也意味着市场对信长城的科技市场地位，特别是物联网安全市场地位的认可。

对于本轮融资，信长城创始人及CEO罗燕京表示：

本轮融资将在现有企业发展的基础上，着力推进产品研发、市场推广、团队建设等方面建设。在产品研发层面，信长城将继续推动物联网安全产品标准化进程，促进技术和产品模块化、可视化、系统化，形成更能适应市场需求的标准化产品体系，保证客户能够获得性价比更高，对接更便捷，实施更迅速的安全服务；在市场推广方面，信长城将加大品牌建设力度，扩大信长城的品牌知名度和美誉度，同时以品牌为导向，搭建由渠道代理、直销、市场推广共同构成的市场销售体系；在团队建设层面，信长城将以开放的姿态，持续引入车联网、安防监控、网联智能锁等领域高精尖研发、销售人员，打造一支专业性强、经验丰富、响应迅速、技术领先的团队。

朗玛峰创投负责人惠超表示：

2018年以来，伴随全球各行业数字化转型和信息化建设的进一步加快，数据安全和隐私安全问题日益突出。国家陆续发布了《网络安全法》、《密码法》、《数据安全法》等法律法规，高度重视我国网络安全、数据安全、物联网安全发展和应用。信长城聚焦物联网安全多年，在车联网、安防监控、网联智能锁等领域均崭露头角，拥有多家头部战略客户。朗玛峰作为一家致力于投资高科技细分领域领军企业的创业投资公司，聚焦网络安全行业多年，拥有诸多具有代表性的投资案例。我们看好信长城的专业技术和市场潜力，期待信长城能够在物联网安全领域夯实基础，拔得头筹；也希望秉承企业一贯精神，为促进国家物联网安全贡献力量。

联储创投负责人王瑞东表示：

近年来，随着物联网设备数量快速增长、物联网安全事件频发，物联网信息安全问题成为一道摆在我们面前的“必答题”。然而，传统互联网安全防护技术难以满足物联网设备低延时、低功耗、低成本、低带宽等要求，面对海量的物联网终端，亟需新的安全体系解决物联网安全问题。这就为物联网安全公司创造了巨大的发展机遇。信长城自成立以来，深耕物联网安全数年，不仅拥有领先的物联网安全技术和研发能力，还积累了丰富的实践经验，能够帮助客户解决众多细分场景的物联网终端安全问题。联储创投作为一家专注于科技赛道的股权投资机构，始终致力于资本助力科技创新，未来将持续赋能信长城发展，共同推进物联网安全发展。

未来，信长城将继续深耕物联网安全领域，秉承“让万物安全互联”的发展理念，以国家法律法规为依据，提高企业创新研发能力，推进产品标准化进程，完善团队建设，促进客户安全方案落地实施，为国家关键信息基础设施、各类企事业单位提供合规的信息、数据安全能力，推动物联网安全发展！
