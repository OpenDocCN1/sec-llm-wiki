# 聚铭网络完成新一轮融资，加速推动网络安全托管服务发展

![](../Images/0cc4d9c681590311cd2034b2a3b6d18c.png)**2021年12月13日，南京聚铭网络科技有限公司宣布完成B轮融资****，投资方为毅达资本**。这是继2020年初获得腾讯战略投资后获得的新一轮投资。本轮融资将**用于加大SaaS云服务体系建设，引领网络安全托管服务技术发展，致力成为行业标杆企业。**

  
  
  
  
  
  
**潜心钻研，聚铭让安全更简单**  
  
  

南京聚铭网络科技有限公司（简称：聚铭网络），是国内领先的安全产品提供商和安全运营商。聚铭网络自2016年成立以来，专注于安全智能分析及检测产品的研发和安全智能化运维的SaaS服务的探索，将SaaS化安全运营服务作为发展主航道。

  

公司创新规划的**“云+端”产品服务一体化解决方案**，从产品全面自动化检测分析到云端全方位智能化监控，加之安全专家专业化分析指导，云和端相辅相成，为客户提供全面的安全防护服务以及贴心的管家式安全运维托管服务。凭借这一产品体系和领先的技术、优质的服务**聚铭网络已经连续四年营业额增长率超过100%，服务客户覆盖全国32个省市地区。**

  

![](../Images/a6a8006d9c007ea9cea82c216e52da91.png)

聚铭网络“云+端”产品体系

  

数字化时代下，安全政策日渐规范，日趋严峻的网络安全环境让广大安全建设预算不足和缺少专业网络安全团队的中小企业在面对网络安全问题时分身乏术，举步维艰。也因此，安全托管服务在网络安全新形势下，逐步成为了各行业用户提升安全水平、化解安全风险的有效措施，安全托管服务已然兴起。  

  

针对中小企业安全建设预算不足和缺少专业网络安全团队的痛点，作为国内最早开展安全托管服务的厂商之一，聚铭网络**依托产品核心团队近20年的安全产品研发和安全运营平台建设运维经验打造的聚铭云端安全管家可7\*24小时实时监控企业安全风险，提供安全预测预警、安全策略制定、应急响应支撑等一系列服务，**帮助中小企业减少安全硬件投入和运维人力成本，以有限的安全建设投入，享受到省事、省心、省时、省钱的安全服务，真正做到让安全更简单。

  

![](../Images/cfef0bc5c536e745f96d5b3a82b60a10.png)

聚铭云端安全管家服务体系

  

  
  
  
**勇于创新，聚铭引领安全托管服务新航向**  
  
  

围绕“云+端”的产品服务战略，聚铭云端安全管家和安全智能检测分析产品已经得到了市场的验证。从2016年公司成立开始研发，2017年中期上线，2018年60家云端客户，到2019年超1500家，再经过2020年品牌元年的快速扩张，**目前聚铭云端安全管家服务的客户已经超过了6000家，本地化安全产品服务客户也已超10000家**，业务覆盖全国32个省市地区，囊括了电信、教育、能源、金融、政府、医疗等多个行业领域。

凭借先发优势和服务超6000家云端客户积累的经验，聚铭网络在安全技术、运维服务和托管服务市场占有率等方面均已取得市场领先地位，在企业应急响应支撑、企业安全解决方案提供、企业安全策略制定等方面更加得心应手。  

  

下一步，聚铭网络将依托本轮融资资金和投资方的资源支持，**加大在技术研发和营销体系的投入力度，推动安全托管运营服务体系的优化升级，扩大聚铭网络在安全托管服务业务的领先优势，引领安全托管服务的新航向。**

  

  

本次毅达资本投资的基金为中小企业发展基金（江苏有限合伙贰号）以及江苏高投毅达宁海创业投资基金。

**毅达资本**是国内最具影响力的创业投资机构之一，在2021年上半年IPO战绩排行中名列前茅。

**中小企业发展基金（江苏有限合伙贰号）**出资方包括国家中小企业发展基金和江苏高投集团等**。**国家中小企业发展基金由国务院决定设立，政府与市场携手，支持企业创业创新发展。

**江苏高投毅达宁海创业投资基金**是由江苏高投集团联合各方资本组建，在江苏省政府指导下开展创业股权投资。
