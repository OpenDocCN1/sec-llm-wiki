# 为竞争浏览器市场，Microsoft Edge和Google Chrome互掐

Microsoft Edge和Google Chrome浏览器互掐，竞争浏览器市场。  

微软Edge开始展示浏览器内告警信息，建议用户不要下载谷歌Chrome浏览器。开发者在竞争浏览器市场的控制权过程中，会尝试建议用户不要下载竞争对手的浏览器。

2020年2月，微软开始在开始菜单中向安装Firefox浏览器或将Firefox浏览器配置为默认浏览器时向用户展示建议用户转用微软Edge 浏览器的消息。

![](../Images/17b8021138ef7f33d8e072265c6b5e8e.png)

Windows 10开始菜单针对Firefox 用户的告警消息

几周后，谷歌开始向微软Edge浏览器用户建议其转用Chrome浏览器，因为使用Chrome 浏览器扩展更加安全。

![](../Images/2a78ca815830f1ad395e3a188a47038c.png)

建议转用谷歌Chrome浏览器的消息

# ![](../Images/549906ce2b683dbe3546190e102d4ff1.png)Microsoft Edge新举措抵制Chrome

1年后，微软Edge 浏览器开始在用户尝试下载Chrome浏览器时在浏览器内展示通知消息。

当用户使用微软Edge浏览器访问Chrome下载页时，用户会看到浏览器内的一个通知消息，说服用户不要做出这一改变。

![](../Images/fe65377da72fdee2fc461c80997d166e.png)

微软Edge浏览器建议用户不要安装谷歌Chrome

这些抵制谷歌Chrome的浏览器内通知称Edge 浏览器比Chrome更加安全，而且Chrome浏览器已经过时了，而且速度很慢且不够可靠，还可以通过Edge浏览器省钱。

这些通知保存在%LocalAppData%\\Microsoft\\Edge SxS\\Application\\98.0.1092.0\\Locales\\en-US.pak 文件中，其中包含5种不同类型的通知消息：

◼微软Edge与Chrome使用相同的技术，但添加了更加安全的技术。

◼该浏览器是2008的，你知道最新的吗？微软Edge浏览器。

◼想要高速、可靠上网？微软Edge浏览器是唯一针对Windows 10系统优化了的浏览器。

◼微软Edge浏览器是是在线购物最好的浏览器。

◼微软Edge浏览器是微软推荐的快速、安全的浏览器。

研究人员在测试过程中成功触发了微软更安全可信、是在线购物的浏览器的通知。但是这5个通知都在程序里。

虽然微软Edge 浏览器的行为比较恶心，但是谷歌Chrome也有类似的行为。

![](../Images/02434afe239b250a040c517e306a73b4.png)

谷歌建议微软Edge用户转向Chrome

微软Edge浏览器和谷歌Chrome都是基于Chromium的浏览器，所以性能和安全本质上都是一样的。因此，用户无论是选择谷歌Chrome还是微软Edge浏览器，性能都是一样的。

谷歌Chrome和微软Edge浏览器仍将不断竞争浏览器市场份额，因此未来这两款互掐也是必然的。
