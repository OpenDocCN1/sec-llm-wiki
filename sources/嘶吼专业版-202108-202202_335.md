# ![](../Images/ff20630cea64eafc789d7641f041c0c8.png)背景介绍 

由国家网络安全产业园（通州园区）主办，嘶吼文化传媒有限公司承办的**2021年第四届“金帽子”年度盛典**将在12月与大家线上见面。金帽子年度盛典是网络安全领域具有影响力的大型会议，每年盛典都会评选出具有典型性的网络安全代表企业/团队、产品进行表彰。

2021年，更为智能的安全和尊重个人的安全意识形态开始渐成，基础设施层面的安全逐步得以深化，网络安全产业的高质量发展顺利展开，这些都为网络安全产业进一步蓬勃发展奠定良好基础。

为推动网络安全产业更加健康有序深化发展，同时鼓励在本年度辛勤耕耘并持续创造价值的网络安全企业，嘶吼安全产业研究院将在金帽子年度盛典发布**《2021中国网络安全产业势能榜单》**，本次发布是继[《2020 中国网络安全产业百强》](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247513924&idx=1&sn=7ec8a7a05649e9a7689a9c0eac81842d&chksm=e915677ede62ee68e22af8367970b7500c454ca78fbedf081bb3a460f88a7fd3ba05d875269a&scene=21#wechat_redirect)榜单的升级与深耕，最终评选出在**“综合型”、“专精型”、“创新型”**三个领域各自排名靠前的优秀厂商并颁发荣誉奖杯。

# ![](../Images/ff20630cea64eafc789d7641f041c0c8.png)评选方式

**厂商自主报名，**根据自身企业性质从“综合型”、“专精型”、“创新型”三类中选择一类进行材料申报，嘶吼安全产业研究院分析团队**从报名厂商中依据填写的真实数据进行公平评选。**

**“综合型”、“专精型”、“创新型”的界定如下：**

**✦ “综合型”的界定：**企业定位立足于提供全方位综合解决方案/产品而非专一方向，公司业务可能涵盖数据安全、信创安全、基础设施安全、业务安全、物联网安全、工控安全、移动安全、应用安全、云安全、安全服务、安全管理等至少5个方向；

****✦ **“专精型”的界定：**企业定位立足于提供专项方向解决方案/产品，如只专注数据安全、信创安全、基础设施安全、业务安全、物联网安全、工控安全、移动安全、云安全、应用安全等，已形成较为稳定的客户和销售渠道；

****✦** “创新型”的界定：**企业成立时间为2018年1月1日以后或主营业务转移网络安全方向时间不超过3年，融资轮次为B轮以下（不含B轮），成立之初是基于某种创新，如技术、服务、解决方案等，目前企业的主要精力为打磨产品，拓展销售渠道和客户。

# ![](../Images/ff20630cea64eafc789d7641f041c0c8.png)评选维度

《2021中国网络安全产业势能榜单》调研开始，本次调研主旨为：**数据说话。**在问卷设计上，嘶吼安全产业研究院采用数字填写为主的方式，通过价值势能、创新势能、组织势能和贡献势能四大维度评估厂商的具体表现，根据厂商所填的实际数据综合打分评定。
