# RSA 2022热门的10家网络安全初创公司

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247542792&idx=1&sn=b1f51714e71f92b2a16e3c973a74e7e0&chksm=e915f832de62712469bb341adf05e96725a28adc16e122218aaa56ae4e374599846cad07f72b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247542792&idx=1&sn=b1f51714e71f92b2a16e3c973a74e7e0&chksm=e915f832de62712469bb341adf05e96725a28adc16e122218aaa56ae4e374599846cad07f72b&scene=27#wechat_redirect)

6月6日，第32届年度安全活动RSA大会正式开幕，诸多热门安全初创公司公开亮相，所涉及的特色技术和安全方法包括devsecops、身份和访问管理（IAM）、威胁管理和云安全等等。

据悉，大约有35家初创公司在“早期展会”（Early Stage Expo）——RSAC的创新空间，致力于鼓励安全行业的后起之秀——公开亮相，展示各自的能力。以下是最热门的10家初创企业名单（按字母顺序排列）：

# ![](../Images/c28bb0194820ae9a68bb5db11bf4b86c.png)Cado Security：云事件响应

Cado Security成立于2020年4月，提供云调查平台，旨在让安全团队通过上下文分析快速响应云工作负载中的威胁。通过自动化数据捕获和处理程序，Cado Response平台提供取证级别的详细信息和上下文以简化响应流程。在此次RSA大会上，这家总部位于伦敦的公司将展示其平台如何加快云事件响应速度。

# ![](../Images/c28bb0194820ae9a68bb5db11bf4b86c.png)Cympire：网络培训和评估

总部位于以色列的Cympire成立于2018年，提供网络安全培训和评估平台，帮助组织建立网络弹性。它的软件即服务（SaaS）产品Cyweria提供了多样化的培训场景，还允许公司为红队和蓝队定制自己的培训场景。该公司表示，它的构建是为了模拟任何网络类型或IT系统。

# ![](../Images/c28bb0194820ae9a68bb5db11bf4b86c.png)Fend：物联网安全与智能

Fend成立于2017 年，是一家网络安全公司，提供专注于关键基础设施保护的物理、硬件解决方案。这家总部位于弗吉尼亚州的公司将硬件和基于云的设备监控和分析相结合，为物联网、工业应用和嵌入式系统（包括公用事业、政府和房地产）提供安全保障。

# ![](../Images/c28bb0194820ae9a68bb5db11bf4b86c.png)Flow Security：云数据安全

Flow成立于2020 年，专注于为用户提供通过整个应用程序环境以及外部服务来保护云数据的方法。这家总部位于以色列的初创公司，主要通过发现数据流、根据其敏感性对其进行分类，以及执行持续的数据风险评估和补救来实现这一目标。

# ![](../Images/c28bb0194820ae9a68bb5db11bf4b86c.png)Fuzzbuzz：Devsecops提供商

总部位于加利福尼亚州的Fuzzbuzz成立于2018 年，开发了一种自动模糊测试工具，该工具通过程序生成的测试用例运行代码以查找错误和漏洞。该公司表示，其模糊测试平台不需要任何安全技能即可使用，允许开发人员在30分钟内上手。

# ![](../Images/c28bb0194820ae9a68bb5db11bf4b86c.png)GitGuardian：Devsecops平台

总部位于巴黎的GitGuardian是一家成立于2017年的网络安全初创公司，致力于解决通过源代码散布的秘密问题，该问题会导致凭据最终进入受损甚至公共场所。该公司表示，它主要通过自动检测应用程序安全和防止数据丢失来解决这个问题。

# ![](../Images/c28bb0194820ae9a68bb5db11bf4b86c.png)Infinipoint：设备身份即服务（device- identity-as-a-service）

Infinipoint的设备身份即服务是一个基于云的机器身份管理安全平台，旨在保护任何用户和设备从任何地方访问所有应用程序。这家总部位于以色列的初创公司表示，它提供与基于风险的策略相集成的单点登录授权，并为不合规和易受攻击的设备提供一键修复功能。Infinipoint成立于2019年。

# ![](../Images/c28bb0194820ae9a68bb5db11bf4b86c.png)SafeBase：企业安全性和合规性

SafeBase成立于2020 年，提供旨在简化安全和合规审查的智能信任中心（Smart Trust Center）。这家总部位于加利福尼亚州的初创公司，旨在帮助公司分享他们的安全态势并自动访问敏感的合规信息。该公司表示，其智能信任中心可以将企业销售周期缩短数天，并将问卷调查量减少50%以上。

# ![](../Images/c28bb0194820ae9a68bb5db11bf4b86c.png)ShardSecure：云安全

总部位于纽约的ShardSecure专注于帮助客户保持对云中数据的控制，在面对攻击和服务中断时提高数据可用性和完整性，并在降低管理开销的同时满足合规性要求。该公司成立于2019年，采用的是一种称为“微分片”（microsharding）的技术——即将数据切碎成微分片，并以某种方式混合和分发它，以防止未经授权的用户拥有可理解的数据集。

# ![](../Images/c28bb0194820ae9a68bb5db11bf4b86c.png)ShiftRight：安全商业智能

总部位于加利福尼亚州的ShiftRight，成立于2019年，声称可以通过客户关系管理（CRM）平台弥合安全工程团队之间的差距，该平台通过整合来自整个企业的适当资源来完成安全任务并跟踪安全性能，帮助公司掌握安全事件投资。
