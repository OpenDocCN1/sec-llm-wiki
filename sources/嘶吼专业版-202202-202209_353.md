# VMware服务端模板注入漏洞在野利用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247539906&idx=2&sn=7e1acd1bead58030ac864b4bffa426ff&chksm=e9158cf8de6205eea75c03df8f20ef9cbdfce2aa4e7bd1ed09a6d3366a44c2a421364dd14a98&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247539906&idx=2&sn=7e1acd1bead58030ac864b4bffa426ff&chksm=e9158cf8de6205eea75c03df8f20ef9cbdfce2aa4e7bd1ed09a6d3366a44c2a421364dd14a98&scene=27#wechat_redirect)

![](../Images/420eebaabdd6d1a2df52ecface4cf38c.png)

研究人员发现VMware CVE-2022-22954漏洞在野利用。  

4月6日，软件厂商发布了CVE-2022-22954漏洞的安全公告，称攻击者可以利用该漏洞可以触发服务端的模板注入，最终实现远程代码执行。CVE-2022-22954漏洞是VMware Workspace ONE Access和Identity Manager中的一个远程代码执行漏洞，CVSS评分9.8分，影响VMware Workspace ONE Access和VMware Identity Manager 2个广泛使用的软件产品。

# ![](../Images/cea9c566ed7616a7177926fe5eaa1c8c.png)漏洞在野利用

漏洞公开后，多个研究人员独立发布了漏洞的PoC代码，可以用于攻击受影响的系统。

![](../Images/04d3ff28c1d83e2ed3aa507171934844.png)

研究人员在推特上发布的安全漏洞PoC  

上周，网络安全情报公司Bad Packets研究人员也发现了有攻击者在扫描有漏洞主机，以及该漏洞的武器化在野利用，攻击者利用该漏洞感染服务器来进行加密货币挖矿。

![](../Images/e568e988dc6acdda784e0cda962261b9.png)

Bad Packets发布的推特

Payload中使用的IP地址106.246.224.219也被用于其他攻击中释放Linux Tsunami木马。

安全研究人员Daniel Card也发推称发现该漏洞被用于释放coinminer加密货币挖矿payload，这也是攻击者利用一个新漏洞的最常用方式。攻击者在获取服务器控制权后就不再利用该漏洞。Card称，很快就会看到勒索软件团伙使用该漏洞利用来在网络中传播。

# ![](../Images/cea9c566ed7616a7177926fe5eaa1c8c.png)安全建议

考虑到该漏洞已经出现在野利用，而且VMware也发布了漏洞补丁，因此建议用户尽快安装安全更新。
