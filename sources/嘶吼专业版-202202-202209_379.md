# 警方强制关闭暗网交易市场

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MDY1MDU4MQ==&mid=2247539406&idx=2&sn=9986742d71444fe33a1f7fc48da52e35&chksm=e9158af4de6203e263c1c00b7774d9b96c4e47f20a3a2c511157b31e4f53d6047fec56733fe5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247539406&idx=2&sn=9986742d71444fe33a1f7fc48da52e35&chksm=e9158af4de6203e263c1c00b7774d9b96c4e47f20a3a2c511157b31e4f53d6047fec56733fe5&scene=27#wechat_redirect)

德国当局已经强制关闭了Hydra市场，这是一个在暗网中非常知名的非法商品和服务交易市场，其中交易的物品包括网络攻击工具以及被盗的数据。  

本周，警方已经关闭了众多的服务器等基础设施，并在一个正在运行的网站首页上展示了一个“本站已被拆除” 的横幅，同时在这个过程中缴获了2500万美元（2300万欧元）的资金。

根据法兰克福检察官（ZIT）和德国联邦刑事警察局（BKA）周二的一份声明，该非法市场是一个俄语暗网交易平台，该平台至少从2015年开始就可以通过Tor网络进行访问了。他们的核心业务是进行非法麻醉品交易。此外，该平台还提供了全球范围内的数据交易、伪造文件和数字服务，并从中获利。

安全公司Elliptic表示，根据周二关于针对Hydra打击行动的帖子，现在已经确认4月5日当天发生了88笔交易，金额为543.3 BTC。除此之外，自成立以来，Hydra平台的交易额已经达到了大约50亿美元的比特币。

根据该通知，警方的打击行动自去年8月开始，并积极与美国当局进行合作。调查发现，Hydra平台有1700万个客户账户，并拥有超过19000个注册卖家，仅2020年的全球营业额就达到了13.4亿美元（12.3亿欧元）。这些执法机构指出，找到这些数据信息并不容易。 

该帖子指出，尤其是比特币数据混淆器，这是一个由平台提供的混淆数字交易服务，这种技术使得执法机构针对加密货币的调查变得非常困难，最后他们发现，Hydra可能是全球营业额最高的非法市场。

检察官正在指控Hydra的运营商和管理员，罪名是：在互联网上经营商业性的犯罪交易平台；商业性地购买或给予未经许可购买或未经许可销售的麻醉品以及商业性洗钱。

![](../Images/55687d6ffb3372c2fb8b09a742ade25f.png)严厉打击非法黑市行为

由于其在网络犯罪以及毒品交易的暗网地下市场中处于重要地位，国际当局一直在努力摧毁地下市场。

最早的胜利之一是在2020年底摧毁了 “Joker’s Stash”。这是一个很受欢迎的网络违法交易网站，并且专门从事支付卡数据交易，向买家提供了数百万张被盗的信用卡以及借记卡。任何购买这些信息的人都可以创建一个克隆卡，在自动取款机或不支持芯片的店内的机器上进行使用。或者，他们可以简单地使用这些信息在网上购买商品。执法部门还设法禁用了其区块链DNS网站以及Tor地址。

然后在去年，欧洲刑警组织宣布捣毁DarkMarket组织，根据执法机构的说法，这是世界上最大的暗网交易非法市场。

DarkMarket是网络犯罪分子买卖毒品、假币、被盗或伪造的信用卡数据、匿名SIM卡和恶意软件的市场。据欧洲刑警组织称，在关闭该组织时，DarkMarket有近50万用户和2400多名卖家。

此外，根据Elliptic的说法，在2021-22年的冬天，几个暗网服务也自己关闭了。
