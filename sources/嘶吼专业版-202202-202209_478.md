# 乌克兰招募黑客军团攻击俄罗斯网络

乌克兰招募IT黑客军团（IT Army）攻击俄罗斯31个实体机构网络。   

俄罗斯和乌克兰战争爆发以来，乌克兰网络和政府机构网站也受到了来自俄罗斯黑客的攻击。目前，乌克兰正在招募由安全研究人员和黑客组成的“黑客军团”（IT Army）对31个俄罗斯实体机构进行网络攻击，其中包括政府机构、关键基础设施和银行机构。

当地时间周六下午，乌克兰数字化转型部长Mykhaylo Fedorov宣布其需要数字人才志愿者来组件黑客军团来对俄罗斯进行攻击。

在乌克兰的号召下，黑客军团招募了乌克兰的黑客社区来帮助对俄罗斯的网络攻击。

Cyber Unit Technologies创始人Yegor Aushev在Facebook上发布了申请表。Aushev称来自全球各地的黑客都愿意帮助乌克兰，其中还包括来自俄罗斯的黑客。

![](../Images/f4f684269c94503e38ab4675a52471ef.png)

Yegor Aushev Facebook发帖

从目前情况来看，黑客军团的行动已经取得了效果。目前，俄罗斯克里姆林宫、国家杜马、国防部等网站都因为遭受DDoS攻击而无法访问。

匿名黑客称其成功黑掉了俄罗斯国防部的网站，并窃取了网站数据库的内容。

俄罗斯克里姆林宫网站仍然无法访问，目前尚不清楚该网站是受到了攻击，还是俄罗斯政府为预防攻击而关闭了网站。

此外，俄罗斯政府和其他相关部门的网站运行速度也都非常慢。
