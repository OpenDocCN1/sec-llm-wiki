# 黑客从BTC.com窃取价值300万美元的加密货币

黑客从BTC.com窃取价值300万美元的加密货币。

BTC.com是全球最大的加密货币矿池之一。近日，BTC.com称其受到网络攻击，被窃取了加密300万美元的加密货币。目前，部分被窃的加密货币已经恢复。

矿池tracker数据显示，BTC.com是全球第7大加密货币矿池，占全网总哈希率的2.66%。12月26日，BTC.com称在12月3日遭受了网络攻击，有价值300万美元的加密货币资产被窃，其中包括属于客户的价值约70万美元的加密货币和公司所有的价值约230万美元的加密货币资产。

在监测到网络攻击后，BTC.com将该事件报告给了深圳的相关部门。12月23日，执法机构开展了调查取证工作，并寻求了相关机构的帮助。目前，尚无攻击者如何窃取加密货币，以及是否有用户信息泄露的公开信息。

![](../Images/b8d0d8eec0f316bc6a959e9fd06018c0.png)

BTC.com称在检测了网络攻击后，就采取了相应的补救措施。目前，BTC.com已经恢复了部分被窃的加密货币，但是具体金额并未公开。

此外，BTC.com称已采取了对应的措施来预防此类攻击。BTC.com业务未受到影响。
