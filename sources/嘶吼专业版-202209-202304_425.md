# GPS干扰器被用来劫持卡车和击落无人机：该如何应对？

借助GPS的卫星导航和跟踪已成为全球快速发展的物流和货运生态系统中的一个关键环节。公司企业使用GPS来跟踪卡车，并确保卡车准点、货物安全。

因此，难怪犯罪分子们现在将目光投向成本低廉的GPS干扰设备来偷盗公路和海上的货物，这个问题正变得越来越严重，但有望借助旨在克服干扰威胁的新一代安全技术得到改善。

你可能不是犯罪高手或秘密特工，有必要介绍一番背景知识。任何使用GPS的系统的核心问题是，信号极其微弱，这是这些信号需要传播很远的距离不可避免的结果。干扰器的原理是，通过发射频率相同的信号，功率上压倒GPS信号，但只是比原来的信号强一点而已。用于劫持货物的典型干扰器能够干扰最远5英里以外的频率，从而使GPS跟踪和安全设备（比如卡车运输企业使用的那些设备）完全毫无用处。

在墨西哥，大约85%的货车货物盗窃案使用了干扰器。美国方面的统计数据比较难获得，但毫无疑问，这些设备很普遍，并被广泛使用。俄罗斯目前正在利用这项技术，干扰乌克兰境内的商用飞机。

正如外媒所介绍，蓬勃发展的商用无人机领域也受到攻击。无人机常常依靠GPS进行导航和安全跟踪，这使得它们特别容易受到攻击。配备备用方法的无人机仍然常常依赖GPS进行定位、导航和保持稳定性，这使得干扰器成为击落无人机，并可能对生命和财产造成危害的一种工具。在2018年香港的一场灯光秀中，一个干扰装置导致46架无人机从空中掉下来，公众因此更意识到了这个问题。

如今市面上出现了解决这个问题的技术。一家名为infiniDome的公司已开发出一种抗干扰解决方案，该解决方案与几乎所有基于GPS的车载通讯单元兼容。车载通讯这个术语是统称，指货运公司用于跟踪和监控其运输途中资产的那些技术。InfiniDome的“OtoSphere”是为商业GNSS接收器研制的小型附加设备，可以提供保护，并增强GPS设备防御干扰攻击的能力。通过识别和防止干扰事件，车队运营商能够防止货物被盗。

Sepentrio等其他公司也推出集成式传感器解决方案，认真对待无人机应用环境中的GPS干扰问题。

与此同时，多国政府希望通过法规监管进行反击，不过这可能是一场无望取胜的仗。墨西哥在2020年底通过了一项反干扰法，实施犯罪时使用这类设备的人将被处以入狱12年至15年的重罚。

不过，干扰器仍然在网上唾手可得，只要花50美元就可以买到。
