# 嘶吼专访 | 融安网络创始人陈桂耀：创业是一条通往山顶的路，你只能上，不能下

上学的时候，老师可能都会问过我们一个问题：长大后的梦想是什么？成为老师、职业军人、科学家......

陈桂耀是当时他们班唯一一个说想成为一名工程师的同学。

时光荏苒，岁月葳蕤，儿时梦想终会照进现实。

近日，嘶吼对融安网络创始人兼CEO陈桂耀进行了人物专访，分享一下他的创业故事与行业心得。

![](../Images/1239b56ce1a9e5757277ee9ae421080a.png)

融安网络创始人兼CEO  陈桂耀

# ![](../Images/aa4acac3473aee15315f397a88515221.png)种下一个工程师的梦想种子

**80年代出生的陈桂耀，可以说是见证了中国自动化发展最高光时刻的一代。**当初自动化专业可以说是实打实的热门专业，就像这几年全国各地设立人工智能专业一样。比如，当时很多选择读无线电子专业，最后成为了“工程师”。

“比较影响我们这一代的比较家喻户晓的几个早期实干型企业，如康佳、海尔等企业，而张瑞敏则可以说是我读书时期以来的偶像。再如，后续了解到的国内早期第一个引入现代化管理制度的企业——万科。这些实干型企业特别是他们的灵魂人物，可以说给我后续的创业带来影响。**我当时也毅然决然地选择了电气工程及自动化专业，希望有朝一日能进入这些实干型的企业。**”陈桂耀对嘶吼讲到。

并不像当初大多同学的职业规划是选择在国有企业体制内担任工程师后走上了从政之路，而是选择一条更充满荆棘的拼搏之路，他只身一人来到深圳这一座崭新的城市打拼，从此与深圳结下不解之缘。

也许是热爱更能催生人向上的心，练就一身“内功”。陈桂耀凭借着在求学期间过硬的专业知识以及扎实的基本功，成功进入了企业“黄埔军校”的华为，开启了“打怪炼级”之路。

正如任正非所言**：****我们曾经十数年的相处，我们近似严苛的管理，将你们一批天真浪漫年青的小知识分子改造成能艰苦奋斗的“战士”。陈桂耀也曾在这军事化管理体系下，历经华为熔炉的淬炼。**

在华为的十余年时间里，陈桂耀既参与和负责过防火墙、入侵防御网关、OPS/IDS、终端安全等安全产品的打磨，也负责过整个政府系统的网络安全搭建，比如公安部的金盾三期、中宣部网站、金税三期等等大型项目，从前期的策划项目方案，到后面整个落地过程都有参与，积累了实践经验。

在华为黄埔军校出来，进入了网络安全领域，也许是多年在军事化和独具国际视野的工作经历，练就“火眼金睛”之能，**让他察觉到了常人未能察觉到的机会点——网络安全与工业系统结合的发展前景**，在与现如今的另两位创始人，组建最佳“中国合伙人”，走上了创业之路。

谈及创业的看法，他认为，过去网络安全更多考虑的是数据通讯网，运营商、政府、金融等行业都有大规模的应用以及落地项目。**但在2014年以后，传统的网络安全发展到一个阶段，在技术上没有太多本质上的创新，市场更多是陷入从商务关系和价格层面出发的低水平竞争。**

随着“德国工业4.0”、“中国制造2025”的提出，整个数字化浪潮大力推动了产业互联网的发展，大量的IT技术与云计算、物联网技术、人工智能技术被应用到大规模的工业生产里，由此引发的技术安全问题岌岌可危。

另外，在政策层面，因为工业控制系统的安全，国家过往的大型基础设施的控制系统基本都是来自国外品牌，**国内网络安全领域还处于空白，本身来讲，它就是一个增量市场。**尤其是2010年伊朗核设施"震网"病毒事件之后，国家开始加强重视工业控制系统网络安全的管理。

这或许在别人看来是一场“跨界”的挑战，但在陈桂耀看来，更愿意视作为一场“机遇”。

**“把IT技术用到工业自动化里，在跨界的地方最容易创新。**近10年，很多创新成果其实都在跨界、跨学科的边界里，创业也是跨界的一个发展结果。”

对于创业者来讲，一定是有某种社会担当和源动力的，陈桂耀希望用一种平衡的科技手段，通过产品技术的创新，结合安全管理体系，建立更高效的整体安全防护体系，真正能够给我们国家的关键信息基础设施提供全面防护。

# ![](../Images/aa4acac3473aee15315f397a88515221.png)工业植入“安全基因”，用技术筑牢“安全底座”

融安网络的定位是一个技术驱动型的企业，会一直围绕着公司主业，也就是工业控制系统的网络安全创新，适当地延伸到数据安全技术和工业控制控系统的网络安全检测防护两大方向，目前已形成自己的知识产权自主的产品体系，拥有30多项软件著作权，五十多项发明专利。

在技术上，陈桂耀坚持“平台化”理念，比如工业防火墙，通过模块化的方式，快速地进行技术特性更新和迭代，能够快速地满足客户的需求，也更稳定、可靠、安全。

**通过适合用在工业场景的算法模型以及机器智能学习，自动学习行为可以实现各种行业的工业控制系统，从而建立安全规则****。**针对恶意代码，结合静态分析、动态分析以及行为分析，可以解决大型系统以及分布式系统的APT攻击问题。

另外，陈桂耀表示，**可信技术与工业自动化的结合将会成为未来重要技术趋势之一。**

工业系统在设计的时候，基本不考虑网络安全问题，包括芯片和软件操作系统的选型以及应用软件的代码编写等过程，导致从最初的设计开始，就会存在一些风险。

对于安全厂商来讲，选用国产的自主可控的芯片，比如处理器、内存、逻辑器件、存储硬盘等。可以把可信模块这种安全能力植入到设备里面，再结合终端安全技术去跟第三方自动化智能装备厂商集成，解决工业工作系统的本质安全问题。

**在实践上，融安网络设计研发了一套工业互联网边缘智能控制平台，在虚拟化的基础上部署边缘计算安全模块，该系统在国内属于首创**，应用在油气田领域，目前已经通过验收，开启规模化商业应用阶段。

从产品本身来讲，持续地对工业控制系统去做安全研究，里面包括工业协议、工业病毒特征、工业设备漏洞特征、工业控制网络模型等等，形成很有竞争力的知识库。现在融安网络掌握30多种专有工业协议、100多种私有协议，积累了数千条的工业设备漏洞特征、数百个攻击行为模型和数十万种工业病毒特征等。

一般网络安全公司偏软件跟算法，陈桂耀不仅组建了强大的软件算法团队，还组建了硬件团队，研发出针对工业控制系统的平台化硬件体系。同时，提供高性能的工业控制网络安全引擎，包括工业协议的深度解析、并行计算等，能够很好地解决工业系统实时性的产品要求。

**基于技术以及行业理解能力，打造全生命周期的解决方案。**不仅仅是提供一个合规性解决方案，更从工业控制系统的脆弱性检测、边界防御，到内部监测与审计、计算环境安全管理，再延伸出工业互联网边缘智能控制平台等优势产品，与网络安全做进一步的融合。

# ![](../Images/aa4acac3473aee15315f397a88515221.png)厚德载物：一步一步，走的扎扎实实

正如稻盛和夫的人生哲学——付出不亚于任何人的努力。谈及企业经营理念，在陈桂耀看来，当下创业，首先要具备行业认知，其次，要有坚韧不拔的坚毅品格，持之以恒，经得住不同的打击。再者，资源很重要，在构建核心团队时，要有一些志同道合的朋友，会有很多良策。

**知行合一，正如其办公室悬挂“厚德载物”四个大字。**“比如在与自己相处的时候，在困难的时候，在待人接物上，也会告诉我很多事情如何处理，最终会选择一种向善向上的处理方式，一步一步，扎扎实实，坚持”。

比如在产品和解决方案的交付上，陈桂耀**采用“矩阵式”管理，行业垂直线与销售体系双驱动，针对不同行业需求和特点深入研究**，从一开始入局电力行业，慢慢地扩展到石油、化工、冶金、交通等行业领域；销售也从华南区，陆续建立了融安网络华中区、西南区、西北区、华东区、华北区分部，一步步去落地项目。

关于公司的未来规划和愿景，在他的规划里，融安网络**计划在未来几年完成IPO，迎来公司发展的一个里程碑的节点，逐步打造多元化的产业集团。**

如同融安网络的名字，“融合网络、安全同行”是最早的第一层含义，企业在做数字化战略时，要把业务战略、IT战略、安全战略三大战略融合起来；“通达”是第二层含义，借助融安网络的网络安全体系，帮助用户走更远的路；第三曾是希望借助资本力量，进一步发展产业化战略。

当工程师，最终成为一个成功的企业家，去打造产业，这种梦想早早地埋在陈桂耀的心底，如今随着他的稳扎稳打，正在步步生花。

# ![](../Images/aa4acac3473aee15315f397a88515221.png)人物简介

陈桂耀，1981年出生，天津大学电气工程及其自动化专业。深圳市高层次专业人才，凭借多年工业控制系统网络安全的实践经验，担任多个重要社会职务，如：广东省及工程技术研究中心——广东省工业互联网安全工程技术研究中心执行主任、中电标协工业控制系统 信息安全防护能力推进分会会员、中国智慧能源产业联盟会员、中国城市轨道交通协会会员、中国应急管理学会石油石化安全与应急工作 委员会常务理事、工业互联网产业联盟理事、工业信息安全产业发展 联盟理事、工业控制系统信息安全产业联盟理事等。曾任职华为企业 BG，从事防火墙、入侵防御网关、OPS/IDS、终端安全等安全产品的研发和市场工作，有多年研发项目管理、国内区域和行业市场管理工作。
