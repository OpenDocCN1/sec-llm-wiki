# 大会抢先看丨第四届国际工业信息安全应急大会即将开启！

2022年第四届国际工业信息安全应急大会将于9月14日-16日在北京市举办。届时将联合各政府机关广泛邀请各地工信局领导、国内外政府代表、国际组织代表、工业信息安全企业领军人物、专家学者等为嘉宾，围绕工业信息安全应急管理、监测预警、信息共享、事件处置和人才培养等方面，开展交流讨论，分享最佳实践经验。

# ![](../Images/cd3a10af564d0d1b5238c2f4e7ffb0d7.png)时间地点

时间：2022年9月14日下午-16日下午（2.5天）

地点：国家网络安全产业园区（通州园）——北京通州·北汽动力总成研发中心

# ![](../Images/cd3a10af564d0d1b5238c2f4e7ffb0d7.png)组织机构

主办单位：北京市通州区人民政府、国家工业信息安全发展研究中心

承办单位：工业信息安全产业发展联盟、国家网络安全产业园区（通州园）

**看点一：开幕式暨主论坛**

**时间：9月15日09:30-12:00**

**地点：主会场**

为推动工业领域网络安全国际合作，共同应对工业领域网络安全风险挑战，此次大会围绕“共话安全，共赢发展，共建开放协同新生态”主题，设置主题演讲、技术经验分享、研究成果发布、优秀案例发布、应急演练、圆桌对话等环节，届时将邀请工信部及北京市领导、地方行业主管部门，国内外行业知名学者、联盟协会负责人、行业专家、领军企业高管等参加，聚焦行业重点、热点问题，开展多维度探讨、深层次交流。

![](../Images/ed3362f9e0c2c726343efc15de08d243.png)

**看点二：网络安全产业创新型企业投融资路演**

**时间：9月14日14:00-18:00**

**地点：2L 分会场B**

以“赋能产业创新，守护数字安全”为主题的网络安全产业创新型企业投融资路演将聚焦科技创新领域，集合专业投融资机构及创新型中小企业，通过企业介绍自身优质项目，与投融资机构进行现场交流，沟通合作可能，探讨当下企业发展所面临的需求与问题。进一步拓宽通州区创新型企业的融资渠道，降低融资成本，搭建起辖区内创新型企业与金融机构的有效对接平台，帮助企业解决融资问题。

![](../Images/3ccd16bdee566330926247d3e66d7083.png)

**看点三：网络安全产业高质量发展推介会**

**时间：9月14日15:00-17:00**

**地点：主会场**

在网络安全产业高质量发展推介会上，将围绕“产业赋能，集势共赢”的主题，重点聚焦北京市通州区、国家网络安全产业园（通州园）的产业发展规划与相关政策，充分展示通州区及网安园（通州）的资源禀赋和发展优势，共同绘制网络安全产业发展的宏伟蓝图，探索网络安全与工业信息产业的深度融合发展，进一步推动网络安全工作创新建设，为网络安全产业高质量发展提供强有力的支撑。

![](../Images/d9a8f131aa01da39b996148e92083608.png)

**看点四：工业信息安全产业创新发展论坛**

**时间：9月15日13:30-18:00**

**地点：主会场**

为加速构建工业领域网络安全管理体系，推动工业大数据深度发展，工业信息安全产业创新发展论坛以“探索新思路，共创工信安全新未来”为主题，聚焦工业信息安全领域，共同分析当前工业信息安全发展趋势、安全防护方法，通过发布工控报告、网络安全产业图谱等，分享最新技术研究成果，探讨制造强国、网络强国建设和工业信息安全之间的重要关系，探索符合新时代发展需要的新思路，共筑工业互联网信息安全防护墙。
