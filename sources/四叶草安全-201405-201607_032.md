# 祝贺CSA（Cloud Security Alliance）云安全联盟大中华区西安分会成立仪式圆满成功

    CSA（Cloud Security Alliance）云安全联盟大中华区西安分会成立仪式于5月26日下午14时，在曲江国际会议中心306厅成功举办。

    本次会议邀请嘉宾由CSA西安分会副会长、华为技术有限公司IT安全标准总监葛小宇先生担任主持人。会议正式开始后，首先由CSA大中华区主席、中国首席信息安全官李雨航先生发表致辞。国家发改委国际合作中心秘书长刘峰先生与中国科学院院士、原西安交通大学副校长徐宗本先生，作为特邀嘉宾表达了对CSA西安分会的美好祝愿。陕西省委网信办副主任黄永宏先生、陕西省通信管理局副局长、国家计算机网络与信息安全管理中心陕西分中心主任尚凯莺女士、西安交通大学管理学院院长黄伟先生等行业内翘楚应CSA西安分会会长、四叶草安全CEO马坤先生的邀请齐聚会场，围绕信息安全、云计算、云安全等相互关切的热点话题进行交流，共议全球信息安全与云计算领域的新发展、新格局。会议现场嘉宾云集、高朋满座，汇聚政、学、商等多领域精英，使CSA西安分会的成立仪式庄重而热烈。

  

![](../Images/d9557d41261d21af895e2e70cb1c4dcb.png)  
   

    CSA（Cloud Security Alliance）云安全联盟发起于2008年12月，2009年在美国正式注册。2011年美国白宫在CSA峰会上宣布了美国联邦政府云计算战略，目前云安全联盟已协助美国、欧盟、日本、澳大利亚等多国政府开展国家网络安全战略、国家身份战略、国家云计算战略、国家云安全标准、政府云安全框架、安全技术研究等工作，它代表着云安全领域的国际最高水准。

    云安全联盟（CSA）是中立的非盈利世界性行业组织，致力于国际云计算安全的全面发展。云安全联盟的使命是“倡导使用最佳实践为云计算提供安全保障，并为云计算的正确使用提供教育以帮助确保所有其它计算平台的安全”。

CSA源自美国，于2009年RSA大会上宣布成立之后，和ISACA、OWASP等业界组织建立了合作关系。一众国际领袖公司，如微软、惠普、谷歌、亚马逊、华为、ITU等都是其企业成员。

 

![](../Images/6092f17efb00606b3553ddf8aad4f670.png)  

   

    联盟在全球拥有六万多位个人会员，两百多个公司、机构会员，如微软、惠普、谷歌、亚马逊、华为等，三个职业化云安全联盟大区（包括美洲区，欧洲区，亚太区）。2015年，云安全联盟设立大中华区，包括大陆和港澳台地区分会，并将协调中心与办事处合并为安全协调司，由从美国归国的原云安全联盟全球首席战略外交官兼中国区理事长李雨航院士担任CSA大中华区主席/协调司司长；方滨兴院士担任大中华区协调顾问；陕西首家专业安全公司“西安四叶草信息技术有限公司”CEO马坤担任全球云安全联盟（简称CSA）大中华区协调顾问、西安分会会长。 

  

![](../Images/af229c4dd97c3fc8ffcb473d9428e4ec.png)  

    

    西安背靠西北，面朝四方。不仅是文化古城，也是科技强市，高校环立，人才济济。作为西部大开发的“桥头堡”,西安市正利用自己的科技力量,不断提高竞争力,对西部经济的发展起到了突出的示范作用。CSA目前在北京、上海、华南、深圳已成立分会，西安分会的成立意义深远，将有机会直接与国内外顶级云计算厂商合作，共同促进云安全和云计算相关信息和知识交流，为陕西企业和渠道商提供更优质、更安全的云服务解决方案。

  

![](../Images/f23ba245ec6146e9b2f73ac8abd024d7.png)  

    

    当前，是网络信息安全的新时代，是全面数字化、信息化的共享交流时代，也是一个全球可持续发展的重要转型时期。随着计算机技术的飞速发展，信息网络已经成为社会发展的重要保证。信息网络涉及到国家的政府、军事、文教等诸多领域。云安全联盟大中华区西安分会的成立，会进一步促进云计算安全的全面发展，让我们拭目以待。本次会议圆满召开，必将开启国内外信息安全事业的新篇章！
