# 威客众测设立四叶草安全为西安办事处

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTI2NDQzNg==&mid=201920763&idx=1&sn=409bdbe64a4c299762d751d02387b2ce&chksm=2f458b20183202360925fb52149e6adda3c525d58432e8c212de27935b9b338a51b3eaf9a01c&scene=126&sessionid=1681375387#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTI2NDQzNg==&mid=201920763&idx=1&sn=409bdbe64a4c299762d751d02387b2ce&chksm=2f458b20183202360925fb52149e6adda3c525d58432e8c212de27935b9b338a51b3eaf9a01c&scene=126&sessionid=1681375387#rd)

> 威客众测是锦龙信安旗下的品牌，随着今年威客众测线上的业务开展，北京锦龙信安科技有限公司与西安四叶草信息技术有限公司已经建立了深度的合作关系。两家公司自合作以来，先后为多家大中型客户单位提供安全产品及服务，具有良好的服务口碑。2014年11月锦龙信安公司西安办事处正式挂牌成立，这标志着西北地区安全服务将进一步加强，威客众测近3000名安全测试人员（白帽子）有助于给当地的安全服务注入更多活力，并且推动西安及周边地区的安全技术水平。
> 
>   
> 
> 西安办事处的正式成立，将承担整个西北地区的安全服务及产品推广，提高该区域内的安全众测服务水平，进一步缩短客户服务响应时间。同时，西安办事处还将与西北地区广大客户以及合作伙伴分享最前沿的安全众测技术和解决方案，特别是在安全服务领域。
> 
>   
> 
> 锦龙信安公司将在2015年进一步扩大在西安办事处的投入，支持和帮助整个西北地区包括宁夏、新疆、青海、陕西、甘肃的安全建设，加强合作、提高信息化水平，构筑与区域经济共同成长长期发展战略。
> 
>   
> 
> 威客众测（www.secwk.com）做为锦龙信安公司旗下品牌也是中国最专业信息安全众包任务平台，致力于为国内外的信息安全机构、个人和有信息安全需求的企业主，提供信息安全网络中介服务。威客众测在2013年10月1日正式进行内测并公布在互联网上，网站拥有数千人来自国内外的注册信息安全专业从业者，以及专业的信息安全机构、企业，威客众测创造了互联网安全产品与服务的新模式，让信息安全不在孤独，打造了信息安全需求与解决方案快速对接的专业平台，为更多的企业、个人提供基于威客众包商业模式的信息安全交易服务平台。
> 
>   
> 
> 威客众测作为一个IT圈儿新型的奢侈品交易市集，我们坚持和发展了传统威客网站的任务模式，还添加更具专业性人才招聘模式，解决甲方、乙方招人难，招人不可靠的问题，移植游戏思维好玩的安全组队、安全特攻队、开源安全项目、安全开发、信息安全攻防大赛等游戏项目与任务，引爆全国信息安全界。吸引了社会和公众关注的特点，同时，引入了“项目请愿”“漏洞银行”“安全众筹”“战队系统”“安全店铺”模式，为安全开发者和安全产品经理开设了功能多样化的人才商铺，展示成功案例、交易记录和机构（个人）简介、服务理念、联系方式等。
> 
>   
> 
> 威客众测历时近2年的市场调查与模式创新，最终尘埃落地。我们拥有国内最顶尖的信息安全专家与信息安全机构，遍布全国各大城市，不但可以跨越空间界限，参与平台上的头脑风暴，更可就近提供“任务速配”复杂的信息安全项目服务、与产品销售服务。让安全与生活零距离，提供专业的信息安全一对一防护服务，7\*24小时专家响应模式。开拓了中国信息安全领域信息安全服务与产品销售的崭新天地。
