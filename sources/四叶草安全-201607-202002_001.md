# 感洞系列产品支持Apache Tomcat 文件包含漏洞(CVE-2020-1938)检测

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTI2NDQzNg==&mid=2654527697&idx=1&sn=3a786961c42a44cc2505cdfe2d359ad0&chksm=bd747b0a8a03f21c72331d1080803429ec02afb2ba2e07315f3401657fcd6df5780fcbc87285&scene=126&sessionid=1681375121#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTI2NDQzNg==&mid=2654527697&idx=1&sn=3a786961c42a44cc2505cdfe2d359ad0&chksm=bd747b0a8a03f21c72331d1080803429ec02afb2ba2e07315f3401657fcd6df5780fcbc87285&scene=126&sessionid=1681375121#rd)

**漏洞背景**

北京时间2020年02月20日，国家信息安全漏洞共享平台(CNVD) 收录了 Apache Tomcat文件包含漏洞（CNVD-2020-10487/CVE-2020-1938）。

Apache与Tomcat都是Apache开源组织开发的用于处理HTTP服务的项目，两者都是免费的，都可以做为独立的Web服务器运行。该程序实现了对Servlet和JavaServer Page（JSP）的支持。

  

**漏洞详情**

该漏洞是由于Tomcat AJP协议存在缺陷而导致，攻击者通过精心构造的请求可读取或包含 Tomcat 上所有 webapp 目录下的源代码、配置文件等。

经过四叶草安全应急响团队确认，此漏洞真实存在。

![](../Images/5756eeec18edd57e24e1c0a63cbb6aa0.png)![](../Images/69e75aff519cd06caef4920e67ccb166.png)

  

**漏洞影响范围**

受影响版本：

Apache Tomcat 6

    Apache Tomcat 7 < 7.0.100

    Apache Tomcat 8 < 8.5.51

    Apache Tomcat 9 < 9.0.31

  

**漏洞危害**

**高危**

  

**自查方案**

 推荐使用四叶草安全感洞系列产品进行检查：

![](../Images/fab88f1d9134ad2496a06e94e2479dae.png)

  

**修复建议**

目前官方已经在最新的版本中修复了该漏洞，受影响用户尽快升级到指定版本：

Apache Tomcat 7.0.100       http://tomcat.apache.org/download-70.cgi

Apache Tomcat 8.5.51        http://tomcat.apache.org/download-80.cgi

Apache Tomcat 9.0.31        http://tomcat.apache.org/download-90.cgi

Apache Tomcat 6 已经停止维护，请升级到最新受支持的 Tomcat 版本以免遭受漏洞影响。
