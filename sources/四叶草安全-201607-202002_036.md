# 四叶草安全荣获陕西省信息网络安全协会2019年度优秀会员单位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTI2NDQzNg==&mid=2654527471&idx=2&sn=61db8a25b59a475a127036c99ea9b087&chksm=bd7444348a03cd227c37937e6e1df0dbf2b82100b49ea2c19908869122411d02a407fc384934&scene=126&sessionid=1681375136#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTI2NDQzNg==&mid=2654527471&idx=2&sn=61db8a25b59a475a127036c99ea9b087&chksm=bd7444348a03cd227c37937e6e1df0dbf2b82100b49ea2c19908869122411d02a407fc384934&scene=126&sessionid=1681375136#rd)

12月26日，由陕西省互联网信息办公室、陕西省公安厅指导的陕西省信息网络安全协会2019年度学术年会在西安召开。省委网信办副主任鲁世宗、省公安厅网安总队政委刘磊、省密码管理局总工程师王二鹏、省网安协会会长孙大跃等领导嘉宾出席并讲话。

  

![](../Images/a5f9c0653db44fb83de02ba1b1dabd25.png)

  

此次会议全面总结了陕西省2019年网络安全建设工作，充分解读了网络安全方面的法律法规和标准规范，同时省网安协会详细汇报了2019年度工作成果，并部署了2020年的工作计划。**表彰大会上，四叶草安全荣获“2019年度优秀会员单位”称号**。

  

![](../Images/a34f8014ed959085a3b2e85e038126a6.png)![](../Images/5d16edf61bf26d639d3db90d86e9ea74.png)

**🔺四叶草安全荣获“2019年度优秀会员单位”称号**

![](../Images/a01ac01a427a5adf8d58a6bfb52edf1a.png)

作为陕西省信息网络安全协会会员，四叶草安全服务过政府、互联网、事业单位、医疗、运营商等多种行业近百项项目，支持CTF比赛及相关培训60余场，参与各项会议论坛40余场。2019年四叶草安全积极参与协会组织的多项活动，协办2019第三届丝绸之路网络安全论坛暨“丝路杯”网络安全技能大赛、响应陕西省第六届国家网络安全宣传周号召，在多地多市展开多种形式的支撑工作，在8月份举办的2019第四届SSC安全峰会及SSCTF夺旗赛上，协会作为协办单位受邀参加，搭建“开放、共享、创新”的网络安全协同互促平台。
