# 【紧急通告】Windows 远程桌面无需授权认证的远程代码执行漏洞（CVE-2019-0708）更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTI2NDQzNg==&mid=2654527198&idx=1&sn=bc4eb22ae7cdcfbdf19fe4529cdf8418&chksm=bd7445058a03cc13ff909eede3f6ac487ef423a3d128838a60e39570de2d2beea2d52d700734&scene=126&sessionid=1681375151#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTI2NDQzNg==&mid=2654527198&idx=1&sn=bc4eb22ae7cdcfbdf19fe4529cdf8418&chksm=bd7445058a03cc13ff909eede3f6ac487ef423a3d128838a60e39570de2d2beea2d52d700734&scene=126&sessionid=1681375151#rd)

  

漏洞背景

2019年5月15日，微软Windows系统被爆出高危漏洞CVE-2019-0708。该漏洞利用远程桌面端口3389的RDP协议进行攻击。当未经身份验证的攻击者使用远程桌面连接到目标系统并发送特制请求时，可以在目标系统上执行任意代码。该漏洞当时被微软定义为严重级别。

近日，Metasploit发布了CVE-2019-0708的EXP，是针对Windows 7 SP1 x64 与 Windows 2008 R2 x64系统。四叶草安全建议用户尽快更新安全补丁。

漏洞等级

**高危-紧急**

经过四叶草安全应急响应团队测试，该漏洞可以被成功利用。

修复建议

**方式一：安装补丁**

官网已经在2019年5月14日修复了该漏洞。如果您使用的系统在该漏洞影响范围内，我们建议您及时为系统打上补丁。

针对Windows 7，Windows Server 2008 R2，Windows Server 2008系统的补丁下载：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2019-0708

停止维护Windows XP，Windows2003版本的补丁链接如下:

https://support.microsoft.com/zh-cn/help/4500705/customer-guidance-for-cve-2019-0708

**方式二：临时解决方案**

1．禁用远程桌面服务。

2．在防火墙处阻止远程桌面端口(默认为3389)。

3．启用网络级别身份验证（NLA），此操作适用于Windows 7，Windows Server 2008和Windows Server 2008 R2版本的系统上。
