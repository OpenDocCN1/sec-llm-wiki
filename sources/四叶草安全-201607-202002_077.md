**php for fun**

返回包中可以看到提示，经过分析提交的的数据需要满足三个条件才能拿到flag

**条件一：**

提交的数不能是数字包括小数

**条件二：**

该数的反转与它本身的整数值为一个回文数

**条件三：**

提交的数不是一个回文数

  

我们可以构造一个绕过第一个条件和第三个条件即可，isnumeric函数在开始判断前，会先跳过所有空白字符可是题目获取$req\[‘number’\]的时候明明使用trim过滤了空白字符这时候我们可以引入\\f（也就是%0c）在数字前面，来绕过最后那个ispalindrome\_number函数

所以payload：

?number=%00%0c191

**感洞全时风险感知平台管理系统**

题目为登录界面，经过测试发现存在inde.php~源码泄露

<?php  
error\_reporting(0);  
$flag = 'SSCTF{\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*}';  
if  ("POST" == $\_SERVER\['REQUEST\_METHOD'\])  
{  
    $username = $\_POST\['username'\];  
    $password = $\_POST\['password'\];  
    if($username == 1024){  
        if(intval($username)<1024){  
            if (0 >= preg\_match('/^\[\[:graph:\]\]{12,}$/', $password))  
                {  
                    echo '<script>alert("Password wrong Format");</script>';  
                    exit;  
                }  
                while (TRUE)  
                {  
                    $reg = '/(\[\[:punct:\]\]+|\[\[:digit:\]\]+|\[\[:upper:\]\]+|\[\[:lower:\]\]+)/';  
                    if (6 > preg\_match\_all($reg, $password, $arr))  
                        break;  
                    $c = 0;  
                    $ps = array('punct', 'digit', 'upper', 'lower');  
                    foreach ($ps as $pt)  
                    {  
                        if (preg\_match("/\[\[:$pt:\]\]+/", $password))  
                            $c += 1;  
                    }  
                    if ($c < 3) break;  
                    if ("2048" == $password) echo '<script>alert("'.$flag.'");</script>';

**第一步**要求username==1024且intval($username)<1024，此可使用四舍五入绕过

**第二步**要求0 >= preg\_match('/^\[\[:graph:\]\]{12,}$/', $password)，必须是12个字符以上

**第三步**

if (6 > preg\_match\_all($reg, $password, $arr))

**第四步**

**NES**

n次DES而已，des密钥为8位因此将key分为8位一组，且解密顺序倒过来，解密脚本如下：

from pyDes import CBC,des,PAD\_PKCS5  
import binascii  
str = "\*\*\*"#密文  
KEY = "536503CD6F7665725379DE4C6F766AED5365634FB5E66552"  
NEW\_KEY= "B5E665525365634F6F766AED5379DE4C6F766572536503CD"  
for i in range(0,6):  
    lv = NEW\_KEY\[i\*8:(i+1)\*8\]  
    secret\_key = lv  
    iv = secret\_key  
    k = des(secret\_key, CBC, iv, pad=None, padmode=PAD\_PKCS5)  
    str = k.decrypt(binascii.a2b\_hex(str), padmode=PAD\_PKCS5)  
    print str
