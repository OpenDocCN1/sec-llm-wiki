# Windows远程桌面服务远程代码执行漏洞预警

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTI2NDQzNg==&mid=2654527115&idx=2&sn=3874610d1dfe38ecceb2de7e9bdbe179&chksm=bd7445508a03cc4653b27dabd47a7233d2ed1c62b7000866def28b9b7e5fddc847016e5eaeac&scene=126&sessionid=1681375157#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTI2NDQzNg==&mid=2654527115&idx=2&sn=3874610d1dfe38ecceb2de7e9bdbe179&chksm=bd7445508a03cc4653b27dabd47a7233d2ed1c62b7000866def28b9b7e5fddc847016e5eaeac&scene=126&sessionid=1681375157#rd)

**漏洞背景**

2019年8月14日，微软官方发布了本月的安全补丁更新，其中CVE-2019-1181和CVE-2019-1182影响最为严重，均属于远程代码执行漏洞。该漏洞主要是微软在对之前0708漏洞进行研究时，发现的新的漏洞，目前尚未发现该漏洞被恶意利用。

  

**漏洞描述**

远程桌面协议（RDP,RemoteDesktopProtocol）是一个多通道的协议，让用户连上提供

微软终端机服务的电脑。该服务中存在远程执行代码漏洞。当未经身份验证的攻击者使用RDP

连接到目标系统并发送特制请求时，无需其它交互，便可以在目标系统上执行任意代码。

**影响范围**

**受影响的windows版本：**

Windows 7SP1

Windows 8.1

Windows Server 2008R2SP1

Windows Server 2012

Windows Server 2012R2

服务器版本在内的所有Windows10

  

**不受影响的windows版本:**

Windows Server 2003

Windows Server 2008

Windows XP

**高危**

  

  

**防护措施**

方式一：安装补丁

CVE-2019-1181漏洞补丁获取链接：

https://portal.msrc.microsoft.com/en-us/security-guidance/advisory/CVE-2019-1181

CVE-2019-1182漏洞补丁获取链接：

https://portal.msrc.microsoft.com/en-us/security-guidance/advisory/CVE-2019-1182

方式二：临时解决方案

1．禁用远程桌面服务。

2．在企业外围防火墙处阻止TCP端口3389。

3．修改RDP服务3389端口为其它不常见端口。

4．在运行Windows7，WindowsServer2008和WindowsServer2008R2的受支持版本的系

统上启用网络级别身份验证（NLA）。
