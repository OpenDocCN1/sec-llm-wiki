# 2019年6月感洞插件持续更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTI2NDQzNg==&mid=2654526876&idx=1&sn=ea8aceade9e47962cc2b320b4f1417d3&chksm=bd7446478a03cf513c9de2bb5ef825f9131b25bfdd7d57d680f3c903bfe6939e5703b16215f5&scene=126&sessionid=1681375172#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTI2NDQzNg==&mid=2654526876&idx=1&sn=ea8aceade9e47962cc2b320b4f1417d3&chksm=bd7446478a03cf513c9de2bb5ef825f9131b25bfdd7d57d680f3c903bfe6939e5703b16215f5&scene=126&sessionid=1681375172#rd)

2019年6月，感洞（BugFeel）系列产品上线插件数量**66个**，其中覆盖**27个**应用,涉及有内容管理系统、建站系统、视频管理系统、教学办公平台、商城系统、企业网站、企业社交管理系统等。

  

重点插件  

**Oracle WebLogic Server反序列化远程命令执行补丁绕过漏洞**

该漏洞主要是针对CVE-2019-2725漏洞的补丁绕过，主要是由于支持weblogic的jdk版本存在缺陷从而导致攻击者可以绕过补丁在远程执行任意命令。

  

**致远OA A8无需认证代码执行漏洞**

致远OA A8 是一款协同管理软件，是面向中型，大型，集团型组织的数字化协同运营中台。

该漏洞存在于此应用的某些版本上。攻击者在无需认证的情况下，通过上传构造的恶意文件就可以实现代码执行，从而进一步获得目标服务器权限。
