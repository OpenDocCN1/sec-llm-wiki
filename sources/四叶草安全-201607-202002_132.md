# Oracle WebLogic Server反序列化远程命令执行补丁绕过漏洞检测

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTI2NDQzNg==&mid=2654526811&idx=1&sn=24f00d54cb10eb88fdb212bf06474ca7&chksm=bd7446808a03cf96b5b7698b34c573d49b18569ec82f2591a78d77109abd51c36a49d24b3c72&scene=126&sessionid=1681375177#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTI2NDQzNg==&mid=2654526811&idx=1&sn=24f00d54cb10eb88fdb212bf06474ca7&chksm=bd7446808a03cf96b5b7698b34c573d49b18569ec82f2591a78d77109abd51c36a49d24b3c72&scene=126&sessionid=1681375177#rd)

**漏洞背景**

近日，在互联网上曝出Oracle Weblogic反序列化远程命令执行漏洞，特征与CVE-2019-2725漏洞类似。

WebLogic是美国Oracle公司出品的一个application server，确切的说是一个基于JAVAEE架构的中间件，WebLogic是用于开发、集成、部署和管理大型分布式Web应用、网络应用和数据库应用的Java应用服务器。

  

  

**漏洞描述**

该漏洞主要是针对CVE-2019-2725漏洞的补丁绕过，主要是由于支持weblogic的jdk版本存在缺陷从而导致攻击者可以绕过补丁在远程执行任意命令。

  

**影响范围**

**以下版本的weblogic受到影响：**

Oracle WebLogic Server 10.3.6.0.0

Oracle WebLogic Server 12.1.3.0.0

**影响组件：**

Wls9\_async\_response.war

Wls-wsat.war

  

  

**漏洞危害**

**高危**

  

经过四叶草安全应急响应团队确认，此漏洞真实存在。

![](../Images/84fdf57566502e6d4e596ed8844b4448.png)

  

**检查方式**

**方式一**：使用感洞系列产品进行检测(推荐)

![](../Images/7f70ab606e0c2cc28b102d3fdfede759.png)

  

**方式二**：自查 

检查WebLogic Server版本，并通过访问路径/\_async/AsyncResponseService和/wsl-wsat/CoordinatorPortType来判断组件Wls9\_async\_respone.war和Wls-wsat.war是否开启。

  

**修复建议**

**目前，Oracle官方暂未发布补丁，临时解决方案如下：**

1.升级java版本。 

2.通过访问策略控制禁止/\_async/跟/wls-wsat/路径的url访问。

3.删除wls9\_async\_response.war和wls-wsat.war文件及相关文件夹并重启weblogic服务。

**文件路径如下：**

版本号10.3.\*

\\Middleware\\wlserver\_10.3\\server\\lib\\

%DOMAIN\_HOME%\\servers\\AdminServer\\tmp\\\_WL\_internal\\

%DOMAIN\_HOME%\\servers\\AdminServer\\tmp\\.internal\\

版本号为12.1.3：

\\Middleware\\Oracle\_Home\\oracle\_common\\modules\\

%DOMAIN\_HOME%\\servers\\AdminServer\\tmp\\.internal\\

%DOMAIN\_HOME%\\servers\\AdminServer\\tmp\\\_WL\_internal\\

**执行该步骤，请用户进行影响评估，并对此文件进行备份后，在执行此操作。**
