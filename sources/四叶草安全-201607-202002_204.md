# 四叶草安全连续三届成为蚂蚁金服安全生态优秀合作伙伴

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTI2NDQzNg==&mid=2654525805&idx=1&sn=fd70092af1bf6534d4fb0949529502cc&chksm=bd7442b68a03cba00340afff59d8c6492910842c7f2537046b6030c1d166dd20baca1c0ac048&scene=126&sessionid=1681375207#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTI2NDQzNg==&mid=2654525805&idx=1&sn=fd70092af1bf6534d4fb0949529502cc&chksm=bd7442b68a03cba00340afff59d8c6492910842c7f2537046b6030c1d166dd20baca1c0ac048&scene=126&sessionid=1681375207#rd)

![](../Images/d8610826755f45ef467f4999a0daa77b.png)

2019年1月10日，蚂蚁金服年度安全生态交流会在成都成功举办，汇聚安全圈内知名安全企业、高校、互联网巨头及白帽英雄等，共同续写网安传奇。四叶草安全作为2018年度蚂蚁金服安全生态合作伙伴受邀出席。

![](../Images/b5d9c3b4e740127093a3a6ea7871ab3f.png)

四叶草安全创始人兼CEO马坤（左二）

马坤曾在首届蚂蚁金服年度安全生态交流会上表示，作为蚂蚁金服安全服务平台首批战略合作伙伴，将会用新一代漏洞风险探测技术“感洞（BugFeel）”产品为蚂蚁金服安全服务平台全力做好技术支撑，为平台商户提供全面全时段的安全检测和监测服务，3年来，四叶草安全与蚂蚁金服共同致力于安全生态建设，更好的服务于80万商户和亿万用户的信息安全，让每一个人安心上网，放心消费。

![](../Images/ee1b36c47d2cc6a5144de5447d33586f.png)

四叶草安全感洞（BugFeel）系列产品（感洞全时风险感知平台、感洞网络安全态势感知平台、感洞关键信息基础设施风险排查系统、感洞协同作战综合管理平台（Bug Cloud）等），是基于‘AI+安全’的开发理念的国内首款基于插件的分布式风险感知平台，开创了风险感知的新模式，引领国内外安全检测（监测）领域，能够第一时间发现用户系统存在的风险和安全隐患，使用户先于黑客发现并及时解决用户自身安全问题。

![](../Images/276c6223fdc40a77eb8039b916753af2.png)

蚂蚁金服安全产品技术资深总监冯春培

冯春培曾在会上表示：“在安全领域，只有队友，没有对手”。在安全生态中更是这样，生态不是一个人的生态，也不是一个就能建立的生态，它是多方面、多人力的聚合体，所以基于生态而言，所有人都应是队友，没有对手。

![](../Images/56b748ddeb96485a0161f837e597bdf1.png)

四叶草安全创始人兼CEO马坤（左二）

2017年1月6日，蚂蚁金服年度安全生态交流会在三亚隆重召开，会上“蚂蚁金服安全服务平台”正式发布，距离今天，已三届，该平台的发布旨在引入行业顶尖安全公司帮助千万中小商户解决安全问题，让行业内外共同携手，为营造和谐有序的安全生态环境而努力。
