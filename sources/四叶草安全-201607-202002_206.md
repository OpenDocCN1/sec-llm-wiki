# 12月感洞插件更新600+涉及工控类，物联网类，教育类等

2018年**12月**，四叶草安全感洞（BugFeel）系列产品更新插件**数量600+**，其中涉及工控，物联网，安全网关，电商，教育，物流，网站建设，内容管理系统，资源管理系统，微信管理系统等。

四叶草安全自主研发的感洞（BugFeel）系列产品，是基于‘AI+安全’的开发理念，开启安全行业“人工智能”新时代，是国内首款基于插件的分布式风险感知平台，开创了风险感知的新模式，第一时间发现用户系统存在的风险和安全隐患，使用户先于黑客发现并及时解决用户自身安全问题。

感洞全时风险感知平台

依次点击**用户中心-更新日志**可看到更新插件

感洞（BugFeel）系列产品（感洞全时风险感知平台、感洞网络安全态势感知平台、感洞关键信息基础设施风险排查系统、感洞协同作战综合管理平台（Bug Cloud）等）都进行了插件更新，请使用四叶草安全相关产品的用户登录设备进行查看。

专注于为客户提供网络信息化安全服务

四叶草安全专注于为客户提供网络信息化安全服务，致力于帮助用户先于黑客发现并及时解决安全问题，是国内外安全检测（监测）领域的领军企业。凭借着在网络安全领域的专注与创新，为客户提供更专业的网络安全解决方案、网络安全产品、安全应急响应服务、网络安全认证培训、安全赛事技术支撑等。业务范围覆盖政府、运营商、互联网、教育、金融、能源、企业等。
