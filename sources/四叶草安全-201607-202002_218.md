# 高层次网络安全人才培养要从青少年抓起

网络空间安全人才教育培养具有知识面广、难度大、学科交叉、知识更新快等特点，仅仅依赖于高等教育培养人才明显力度不够。

西电附中“白帽”社团交流分享

![](../Images/f7b5ebbc7f380710651320ddc4018bcc.png)

2018年11月2日，四叶草安全在西安电子科技大学附属中学进行了一场网络安全兴趣科普分享，该社团名为“白帽社团”，共有59名兴趣爱好者，相对于大学四十人左右的网络安全社团，这无疑是一只“庞大”的队伍。

![](../Images/c47a2129daa086989a6f166c38f6f2ba.png)

**四叶草安全研究院研究员：Jane**

关于网络安全人才培养，四叶草安全创始人马坤说过，网络安全人才培养是作为网络安全企业的社会责任，应该积极与高等院校、高等专科学校、初高中等进行合作互动，为网络安全行业和社会输出更多新生力量。

![](../Images/5f52d83770e7ebeee1c930899630b67b.png)

**看着一群充满求知欲的小眼神**

**直勾勾的看着帅气的小帅锅**

在初高中层面，培养青少年兴趣是关键，需要有平台来引导，建立“天才选拔”机制，发现具有天赋的青少年学生，为有兴趣、有特长的学生创造更好的条件，唯有重视针对青少年人才的平台建设，网络安全人才培养才能赢在未来。

西电网安协会来我司交流学习

![](../Images/b9f4bda5fb85eb9502e8728b2d7e14d5.png)

 2018年11月9日，由西安电子科技大学裴教授带队网络与信息安全协会20余名同学来我司交流学习。活动内容设置CTF介绍及案例分析、漏洞插件相关知识介绍、公司实习就业介绍和交流互动等环节。

裴教授：西电博士生导师

要注重理论与实践的相结合，加强网络安全技能的提升，希望社团能够开展更多类似这种校企交流互动，为网络安全爱好者提供更多接触网络安全前沿知识和交流学习的机会。

***四叶草安全致力于网络安全人才培养***

![](../Images/25e6be584ee66ec0eaa3852a3f36fc57.png)

四叶草安全从创立之处就注重网络安全人才的培养，选择西安创业也是基于西安的科教资源和高校人才优势。四叶草安全组织或支撑过30余场网络安全技能大赛、数十场校园沙龙活动、一年一度的SSC安全峰会、自主研发搭建的bugscan漏洞插件社区和云演开放式学习平台，为数万网络安全爱好者提供了交流互动、分享学习的平台，同时，也向社会输出了大量的网络安全人才。

今年，[9月18日在第三届SSC安全峰会上](http://mp.weixin.qq.com/s?__biz=MjM5MTI2NDQzNg==&mid=2654525381&idx=1&sn=d8547a5331af048fbd22fff456d044e6&chksm=bd744c1e8a03c508dc515f9258957900e6f9514f1ca0b2f93f40119f04035cefba9d503c41d6&scene=21#wechat_redirect)，中国信息产业商会信息安全产业分会秘书长位华在峰会致辞中表示：要担当起时代使命，全面落实贯彻产学合作、协同育人的指导思想，继续投身网安人才培养实践和探索工作，以扎扎实实的成效为网络强国建设作出积极贡献！同时，中国信息安全测评中心与四叶草安全联合成立“网络安全人才培养联合实验室”，致力于发展不同地域、领域的网络安全从业人才，不断提升从业人员素质和技能，为国家网络安全发展作出更重要的贡献。

![](../Images/ff460e4c169104c1ec5af664e6c68713.png)

在沈昌祥看来，人才培养是一个系统性的工程，人才需求也分为基础研究型、工程应用型、推广实用型。高精尖人才是少数，维护维修、管理人才的需求很大。“光靠大学培养不行，网络空间安全教育应该普及到中学、小学，网络空间安全要从娃娃开始学。”沈昌祥表示，要把眼光放远、空间放大，要全方位进行人才培养，才能解决这方面人才短缺、急需的问题。
