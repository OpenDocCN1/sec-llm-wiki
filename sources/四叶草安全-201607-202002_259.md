# 2018SSC安全峰会“企业安全建设论坛”嘉宾议题及名单公布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTI2NDQzNg==&mid=2654525222&idx=1&sn=163482a4765e65981033315cdeeae111&chksm=bd744cfd8a03c5eb74781aee9e25e6165e3ee07dfe3b3f7d453abd440777b651d6efbb5eeb61&scene=126&sessionid=1681375227#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTI2NDQzNg==&mid=2654525222&idx=1&sn=163482a4765e65981033315cdeeae111&chksm=bd744cfd8a03c5eb74781aee9e25e6165e3ee07dfe3b3f7d453abd440777b651d6efbb5eeb61&scene=126&sessionid=1681375227#rd)

  

![](../Images/ddb9ff354625454da022a075ae0031ec.png "箭头引导关注")

  

2018第三届SSC安全峰会的嘉宾演讲名单现已确定，共有**18**位嘉宾将在本届SSC讲台上发表演讲，方向涵盖数据库、工控安全、AI等。

  

我们将在本周内分别发布**企业安全建设论坛（出品方：唯品会安全应急响应中心）、白帽子技术论坛（出品方：百度安全）、安全技术创新论坛（出品方：BugScan漏洞插件社区）**的嘉宾议题及名单。

  

![](../Images/c2036776d74fb1aff7d6570e227e888d.png)

  

本次大会也得到了百度安全、蚂蚁金服、WIFI万能钥匙安全应急响应中心、平安安全应急响应中心、腾讯安全应急响应中心、唯品会安全应急响应中心、小米安全中心、帕拉迪、极验等企业的大力支持。
