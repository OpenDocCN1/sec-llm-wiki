2018年8月22号, Apache Struts2 官方发布了安全通告以及补丁，披露了一个远程命令执行漏洞。漏洞编号为CVE-2018-11776(S2-057)。

  

  

**漏**

**洞**

**描**

**述**

  

当没有为基础 XML 配置中定义的 result 设置 namespace,且其上层的 action 配置没有 namespace 或使用通配符 namespace时,即可能造成远程代码执行漏洞。

  

同样地,当使用没有设置value 和action 的 url 标签,且其上层的 action 配置没有 namespace 或使用通配符 namespace时,也可能会造成远程代码执行漏洞。

 

经过四叶草安全应急响应团队的确定，此漏洞能够成功复现。在实际场景中需要满足一定条件。
