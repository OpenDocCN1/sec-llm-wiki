CODI NG技术小馆

CODING 技术小馆，是由国内专业的一站式软件服务平台 CODING 主办的一系列技术沙龙。秉持服务开发者的理念，每场 CODING 技术小馆将邀请数位业内知名大牛分享技术，交流经验。与此同时，CODING 技术小馆只为开发者们带来纯粹的技术分享沙龙。


本次的CODING西安行将是全国巡讲的第九站，也是四叶草安全与CODING的首度合作。活动以「 Spring 与 Docker」为主题，围绕后端开发实践，力邀各行各业技术大牛对议题展开探讨，分享自身多年的技术应用与实践。届时，我们会将最干货的议题呈现给各位客官



议题简介



Medici.Yan
四叶草安全高级安全研究员、漏洞插件社区负责人

 

《安全与Docker》

BugScan 漏洞插件社区在擂台赛题目环境大量使用了 Docker 容器技术，与白帽子打交道的过程中，Docker 的安全性一直备受挑战。本议题主要讲述 Docker 在安全领域中的应用，Docker 布署时会面临的安全问题以及如何安全的使用 Docker。




施天高

Coding 全干工程师

 

《 Spring Cloud Config 应用、原理及实践 》

Coding WebIDE 项目后端存在各种语言和框架实现的服务，Java 为主要语言，多数项目使用 SpringBoot 的众多工具和组件，践行了微服务的各种思想。但是众多的服务以及分布式的环境带来了复杂的配置管理和应用管理，Spring Cloud Config 项目正是解决微服务配置管理问题的解决方案，所以 WebIDE 也在这方面做了尝试。手工管理众多配置显然不可能，应用各种远程工具也显得很复杂，所以有一个统一的配置中心显得极其重要。Spring Cloud Config Server 正是这样一个实现，所以研究一下其实现原理以及应用到我们的项目还是很有必要的。




张亚鹏

ThoughtWorks 咨询师

 

《 Spring Boot与RESTful服务实践 》 

REST 风格流行已久，然而每个人在对其理解和实现上，都不完全相同。本次分享希望能从实践出发，与大家一起探讨高质量的RESTful 服务的实现方法，议题分为三个部分：重新认识 RESTful；利用 Spring Boot 实现 RESTful 接口；RESTful 接口的功能优化。
