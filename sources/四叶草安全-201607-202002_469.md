# 西北安全行侠义风，百度安全-四叶草安全联合发起安全大武林联盟

9月24日，以**『****安全****·传继』**为主题的2016 SSC安全峰会进入第二天，来自网络安全领域的从业者以及企业安全负责人50余人参加闭门会议环节，共谋网络安全行业的发展大计。百度安全联合四叶草安全发布安全大武林联盟。百度安全事业部总经理马杰、西安四叶草CEO马坤阐释了安全大武林的内涵，发展思路，得到了与会者的积极响应。

  

![](../Images/7ac72557980b1f17d3a0c990dae64aab.png)  

  

俗话说有人的地方，就有江湖。与三教九流皆为江湖不同的是，武林是一个侠肝义胆的世界。什么是安全大武林联盟？四叶草安全CEO马坤阐释了安全大武林联盟的内涵：『古代的武林人士心系天下，打抱不平，劫富济贫，保一方百姓平安。网络世界错综复杂，公认为是非常江湖的存在。

  

网络江湖中，黑客、安全厂商、企业中的安全管理者，都是武林侠士，他们胸怀的是整个网络的安全，保护网络世界的信义、荣誉和正义，阻击破坏者，守护网民利益。但是单个武林中人、某一个武林门派的力量都是微弱的，所以我们需要集天下武林中人之合力，缔结安全大武林联盟，才能实现群英卫四方。

 

百度安全马杰表示，仅2016年上半年，涉嫌泄漏或窃取用户信息超过10.6亿次，基于实时数据的精准诈骗暴增12倍。安全大武林的联盟的建立，就是要联合将联合一切可以团结的力量，包括企业、安全厂商、白帽子和用户，共同应对肆虐的黑产，净化互联网环境，为网民还原一个安全的互联网生态。

 

四叶草安全CEO马坤常说：“抱团取暖”，的确，安全不是任何一个安全厂商能够做到的，必须联合起来共同建设安全大武林联盟，才能有效对抗网络黑产的威胁。这也正是四叶草安全联合百度安全发起这一组织的初衷。

俗话说，天下大势分久必合合久必分。从安全大武林联盟，我们能够清晰地看到这个趋势：百度收购安全宝、阿里巴巴收购瀚海源、腾讯控股知道创宇，互联网公司对安全的重视可见一斑。网络安全厂商也从竞争走向合作，如马坤所言，互相『报团取暖』，绿盟收购亿赛通，奇虎360收购网神、持股网康，启明星辰收购赛博兴安、安方高科、合众数据……

黑产的技术和能力已经领先安全行业很多年，攻防双方的失衡使得网络安全事件频频发生。网络江湖刀光剑影、血雨腥风不断，各大『门派』其实早已意识到，合作联合势在必行，打破『门派』之间的芥蒂，更多地交流和资源的共享，才能让网络安全尽早地赶上黑产的脚步。
