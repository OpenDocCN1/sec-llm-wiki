# 这或许就是首届SSC安全峰会的初衷和意义

2015年我们办了第一届Bugscan沙龙，大家玩的都很high，社区年轻的核心们现场也都分享了他们比较新颖的安全观，这无疑是对安全行业注入了兴奋剂。而随后的秦岭篝火晚会和烧烤娱乐也让我们久久难以忘怀…  

  

![](../Images/2cc9385aedebc743280a63a0f6d26f7a.png)  
  

去年的Bugscan沙龙我叫了一些行业内的前辈和年轻的核心们，彼此互动交流了整个昼夜，大家都很欢乐，后来我就在想，如何才能让国内安全行业的年轻力量在老一辈的提携下健康成长起来，让他们在玩乐的同时也能更轻松的学习，这或许就是首届SSC安全峰会的初衷和意义，它的全称是**Clover**S******ec****  Security Conference**，目的是凸显安全精神的代代传承！

  

![](../Images/7ff4e81acf0ef830f98df9bfed715504.png)  

  

届时我们将会邀请社区年轻有活力的核心安全成员与老一辈的安全爱好者们(如lion、冰河、桂林老兵、熊猫烧香等等)来做更深入的交流和分享，这也是我们一直以来想要做的一件事。

  

与此同时，四叶草安全也已经举办了两届SSCTF，我们将会邀请在SSCTF中出现并成长的队伍(如FlappyPig、NuLL等)来和大家互动，并在现场设置了神秘的游戏环节，对于一路“过关斩将”的高手我们更是准备了丰厚的奖品。

  

在这里，有代表年轻安全力量的新面孔，也有曾经为安全付出过青春的老伙计们；有曾经的泪水，也有现在的欢乐，当然，也有美酒…
