**01 摘要**

2023年4月11日，微软发布了2023年4月份安全更新。

本次更新共修复了103个漏洞，其中包含严重漏洞7个、高危漏洞90个、中危漏洞2个、低危漏洞4个。

**03 漏洞详情**

  

**CVE-2023-28252：Windows通用日志文件系统驱动程序权限提升漏洞**  

CVE编号：CVE-2023-28252

受影响组件：Windows Common Log File System Driver

漏洞类型：特权提升

是否在野利用：**是**

**详情:**

该漏洞是影响 Windows Common Log File System Driver 的特权提升漏洞。

Windows Common Log File System Driver 是操作系统中的一个重要组件，用于存储系统日志。

攻击者可以通过该漏洞进行未授权的访问，并在受攻击的系统中获取最高权限。

影响版本和补丁下载：

*https://msrc.microsoft.com/update-guide/vulnerability/CVE-2023-28252*  

  

  

**CVE-2023-28303：Windows截图工具信息泄露漏洞**  

CVE编号：CVE-2023-28303

受影响组件：Apps

漏洞类型：信息泄露

是否在野利用：否

**详情:**

该漏洞是影响Apps的信息泄露漏洞。

Apps是指Windows 10中的Snip and Sketch应用和Windows 11中的Snipping Tool应用，是一种用于在Windows操作系统中截取屏幕截图的应用程序。

攻击者可以通过该漏洞进行信息泄露攻击，在用户修改并保存图片文件时，可以通过特殊工具恢复部分原始图片内容。

影响版本和补丁下载：

*https://msrc.microsoft.com/update-guide/vulnerability/CVE-2023-28303*

  

  

**CVE-2023-21554：Microsoft消息队列远程代码执行漏洞**  

CVE编号：CVE-2023-21554

受影响组件：Microsoft Message Queuing

漏洞类型：远程代码执行

是否在野利用：否

**详情:**

该漏洞是影响Microsoft Message Queuing的远程代码执行漏洞。

Microsoft Message Queuing是一种Windows组件，用于实现分布式应用程序之间的消息传递。

攻击者可以通过该漏洞进行未经授权的远程代码执行攻击，在受攻击的服务器端上执行恶意代码。

影响版本和补丁下载：

*https://msrc.microsoft.com/update-guide/vulnerability/CVE-2023-21554*  

  

  

**CVE-2023-28219：第2层隧道协议远程代码执行漏洞**

CVE编号：CVE-2023-28219

受影响组件：Windows Layer 2 Tunneling Protocol

漏洞类型：远程代码执行

是否在野利用：否

**详情:**

该漏洞是影响Windows Layer 2 Tunneling Protocol的远程代码执行漏洞。

Windows Layer 2 Tunneling Protocol是一种用于在不安全网络上建立虚拟专用网络（VPN）连接的协议。

未经授权的攻击者可以通过该漏洞进行远程代码执行攻击，在RAS服务器上执行恶意代码。

影响版本和补丁下载:

*https://msrc.microsoft.com/update-guide/vulnerability/CVE-2023-28219*

**04 修复建议**

  

**Windows自动更新**  

Windows Server / Windows 检测并开启Windows自动更新流程如下:

1、点击“开始菜单”，点击进入“设置”；

2、选择“更新和安全”，进入“Windows更新”；

3、选择“检查更新”，系统将自动检查并下载可用更新；

4、重启计算机，安装更新。

  

  

**手动安装补丁**  

对于不能自动更新的系统版本，可参考以下链接下载适用于该系统的4月补丁并安装：

*https://msrc.microsoft.com/update-guide/releaseNote/2023-Apr*
