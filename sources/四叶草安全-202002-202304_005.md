# 四叶草安全再获TSRC年度优秀合作伙伴

2023年3月31日，TSRC 2022年度盛典于线上圆满举办，众白帽参与这场充满干货与温情的盛会。在本次年度颁奖典礼中，四叶草安全再度成为TSRC年度优秀合作伙伴，这已经是四叶草安全连续第八年获此殊荣！

![](../Images/3aebed6cc1dec195304f76340f4cc5df.png)

感谢TSRC对四叶草安全的认可与信任  

四叶草安全将继续与TSRC加深合作，共同探索互联网安全新方向共建互联网生态安全，用“向善的力量”让未来的生命与资产更加安全！
