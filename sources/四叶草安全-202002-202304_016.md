# 聚焦两会｜网络安全的建设与风险

**01**

**聚焦两会**

![](../Images/02ecef9cff7aef327246bc58fb41322c.png)

3月5日，全国两会开幕，网络安全是人工智能最大的细分市场，同时作为重要的“民生问题”和国家安全战略基石，正处于日趋严峻的全球网络安全态势与人工智能驱动的下一代工业革命交汇的技术奇点。

![](../Images/64569558a6ac9723fdb25db57ab75b32.png)

**01**

**声音1：关注基层单位网络安全建设**

会上全国人大代表、中国电信股份有限公司湖北分公司党委书记、总经理张敏就提出：当前数字化转型升级、数字经济蓬勃发展，但频频发生的数字安全事件，对生产运行、社会治理、公共服务都存在一定威胁。

  

基层网络安全，在数字化进程中出现的安全问题，早已突破传统的信息系统安全和网络安全的范畴，由于受安全意识不足、资金等因素制约，基层单位往往无法独立有效解决数字化转型中面临的网络安全威胁。

  

维护基层网络安全是一项长期的系统工程，需要全面的数字化准备、健全网络数据监测预警和应急处置工作体系等方面多方合作发力。

  

![](../Images/4b8844fbf72eed9f4309b2d38e5f6b5f.png)

1、强化安全法律法规的普及教育与执行；

2、是运用数字技术提升基层治理的现代化水平，完善共建共治共享的社会治理制度，提升基于数据的治理效能；

3、构建分布式的一体化智能安全网络，强化数字安全供给侧能力提升和服务改善，国资央企骨干力量应承担主业主责，抓好数字安全产品和安全服务；

4、完善网络安全保障，加强能力建设和人才培养。

人大代表张敏表示，当前，数字化转型升级、数字经济蓬勃发展，但数字安全事件的发生，对生产运行、社会治理、公共服务等造成不利影响。

  

社会在数字化进程中出现的安全问题，已突破传统的信息系统安全和网络安全的范畴。其中，网络基层安全尤应予以重视，需要化基层“末梢”为治理“前哨”。

![](../Images/64569558a6ac9723fdb25db57ab75b32.png)

**02**

**声音2：重视****未成年人网络安全风险**

《2021年全国未成年人互联网使用情况研究报告》显示未成年人遇到网络诈骗、个人信息泄露等形式多变的新问题的比例有所升高，20.0%的未成年网民对于网络诈骗、个人信息泄露、网络谣言等没有防范意识，且年龄越小，防范意识越弱。

对此，全国政协共青团和青联界别委员、团河南省委书记王笃波提出：当代未成年人是活跃在网络世界里的重要群体，他们接触网络早、普及范围广、使用频度高、上网方式丰富多样。

  

与此同时，未成年人网络安全风险形态也在不断翻新，他们的网络安全风险防范能力较弱。

  

**提出建议**

![](../Images/d1f56bb77bba5d5170e149a1522d9616.png)![](../Images/a4305c5bbfd8dbc756de5acd1c5b2173.png)

一是需要我们全力加强全方位法治保障，优化未成年人网络安全保护环境。在网络立法、执法、普法、守法各个环节全面发力，构建未成年人网络安全保护法治屏障。

二是强化平台企业社会责任，推动技术升级加强安全保护。对青少年模式进行改良升级，完善未成年人身份识别机制，防范网络安全风险隐患。三是深入开展网络素养教育，提高未成年人网络自护能力。加强中小学校网络常识、网络技能、网络规范、网络安全等方面的教育，提高未成年人信息辨别能力、时间管控能力、隐私保护能力和网络安全自我防护能力。
