**01 摘要**

2023年1月18日，Oracle发布了2023年1月份安全更新。

本次更新共修复了327个漏洞, 其中有219个漏洞无需身份验证即可远程利用。

  

**02 漏洞列表**

![](../Images/16b26fa7a321284e0e79c5f14af643b9.png)

\*危害较大漏洞指的是无需身份验证且可远程利用的漏洞。

  

**03 漏洞详情**

  

**CVE-2023-21842**

**受影响产品:**

Oracle WebLogic Server：12.2.1.3.0、12.2.1.4.0、14.1.1.0.0

**详情:**

该漏洞影响的产品包括Oracle WebLogic Server。

Oracle WebLogic Server是一种用于构建、部署和管理大型分布式Web应用程序、网络应用程序和数据库应用程序的中间件产品。它提供了一组强大的工具来管理应用程序的生命周期，并且支持多种编程语言和多种协议。WebLogic Server是一种商业产品，由Oracle公司开发和销售。未经身份验证的攻击者通过HTTP协议发送恶意请求，最终可未授权访问Oracle WebLogic Server的所有数据。

  

  

**CVE-2023-21837**

**受影响产品:**

Oracle WebLogic Server：12.2.1.3.0、12.2.1.4.0、14.1.1.0.0

**详情:**

该漏洞影响的产品包括Oracle WebLogic Server。

Oracle WebLogic Server是一种用于构建、部署和管理大型分布式Web应用程序、网络应用程序和数据库应用程序的中间件产品。它提供了一组强大的工具来管理应用程序的生命周期，并且支持多种编程语言和多种协议。WebLogic Server是一种商业产品，由Oracle公司开发和销售。未经身份验证的攻击者通过IIOP协议发送恶意请求，最终可未授权访问Oracle WebLogic Server的所有数据。

  

  

**CVE-2023-21868**

**受影响产品:**

MySQL Server：8.0.31及之前版本

**详情:**

该漏洞影响的产品包括MySQL Server。

MySQL Server是一种关系型数据库管理系统(RDBMS)，它使用SQL语言来管理数据库。MySQL是开源并免费使用的，被广泛应用于许多网站和应用程序中，同时支持Windows、Linux和Mac等平台。MySQL Server提供了高性能、可靠性和可伸缩性，同时还支持多种存储引擎，如InnoDB和MyISAM。未经身份验证的攻击者通过MySQL的多种协议发送恶意请求，最终导致Oracle MySQL被拒绝服务攻击, 严重情况会导致服务崩溃。

  

  

**CVE-2023-21875**

**受影响产品:**

MySQL Server：8.0.31及之前版本

**详情:**

该漏洞影响的产品包括MySQL Server。

MySQL Server是一种关系型数据库管理系统(RDBMS)，它使用SQL语言来管理数据库。MySQL是开源并免费使用的，被广泛应用于许多网站和应用程序中，同时支持Windows、Linux和Mac等平台。MySQL Server提供了高性能、可靠性和可伸缩性，同时还支持多种存储引擎，如InnoDB和MyISAM。未经身份验证的攻击者通过MySQL的多种协议发送恶意请求，最终导致Oracle MySQL被拒绝服务攻击, 严重情况会导致服务崩溃, 同时可能会导致Oracle MySQL服务器的任意数据被创建、删除或修改。  

  

  

**CVE-2023-21835**

**受影响产品:**  
Oracle Java SE：11.0.17、17.0.5、19.0.1  
Oracle GraalVM Enterprise Edition: 20.3.8、21.3.4、22.3.0

**详情:**

该漏洞影响的产品包括Oracle Java SE, Oracle GraalVM Enterprise Edition。

Oracle Java SE (Standard Edition) 是由Oracle公司开发和发布的Java平台的标准版本。它提供了一组核心的Java类库和工具，用于开发和运行Java应用程序和applet。Oracle GraalVM Enterprise Edition是一种高性能的、多语言的虚拟机，由Oracle公司开发。它支持Java、 JavaScript、 LLVM语言（如C和C++）和其他语言，可以提高程序性能和启动速度。未经身份验证的攻击者通过DTLS协议发送恶意请求，最终导致Oracle Java SE、Oracle GraalVM Enterprise Edition被拒绝服务攻击。

  

  

**CVE-2023-21830**

**受影响产品:**  
Oracle Java SE：8u351、8u351-perf  
Oracle GraalVM Enterprise Edition: 20.3.8、 21.3.4

**详情:**

该漏洞影响的产品包括Oracle Java SE, Oracle GraalVM Enterprise Edition。

Oracle Java SE (Standard Edition) 是由Oracle公司开发和发布的Java平台的标准版本。它提供了一组核心的Java类库和工具，用于开发和运行Java应用程序和applet。  
Oracle GraalVM Enterprise Edition是一种高性能的、多语言的虚拟机，由Oracle公司开发。它支持Java、 JavaScript、 LLVM语言（如C和C++）和其他语言，可以提高程序性能和启动速度。未经身份验证的攻击者通过多种协议发送恶意请求，最终导致对某些Oracle Java SE、Oracle GraalVM Enterprise Edition中可访问的数据,  进行未授权的更新、插入或删除。

  

  

**CVE-2023-21886**  

**受影响产品:**

Oracle VM VirtualBox：6.1.42之前、7.0.6之前

**详情:**

该漏洞影响的产品包括Oracle VM VirtualBox。

Oracle VM VirtualBox是一种免费的虚拟机软件，由Oracle公司开发和维护。它允许用户在单个物理计算机上运行多个操作系统，并且支持Windows、Linux、macOS等平台。VirtualBox使用虚拟硬件来模拟客户机硬件，并且可以在不同的操作系统之间共享文件和网络资源。未经身份验证的攻击者通过多种协议发送恶意请求，最终接管Oracle VM VirtualBox。  

  

  

**CVE-2023-21898**

**受影响产品:**

Oracle VM VirtualBox：6.1.42之前、7.0.6之前

**详情:**

该漏洞影响的产品包括Oracle VM VirtualBox。

Oracle VM VirtualBox是一种免费的虚拟机软件，由Oracle公司开发和维护。它允许用户在单个物理计算机上运行多个操作系统，并且支持Windows、Linux、macOS等平台。VirtualBox使用虚拟硬件来模拟客户机硬件，并且可以在不同的操作系统之间共享文件和网络资源。
