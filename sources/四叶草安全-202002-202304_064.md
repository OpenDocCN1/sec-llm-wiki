**CVE-2022-41091: Windows MOTW绕过漏洞**

CVE编号: CVE-2022-41091

受影响组件: Windows Mark of the Web (MOTW)

漏洞类型:  权限绕过

是否在野利用:  是

*详情:  *

该漏洞是Windows Mark of the Web（MOTW）功能的绕过漏洞。

MOTW是一项安全功能，用于标记从互联网下载的文件，并防止它们执行某些操作(如运行 打开等)。被MOTW标记的文件将在Microsoft Office的 "保护视图 "中打开, “保护视图”会提示用户，要求用户通过选择 "启用内容 "确认该文件是可信的并打开。

攻击者可以制作一个可以绕过MOTW的文件, 通过邮件发送包含恶意文件的附件, 或使用户通过网站下载恶意文件,  从而使用户在没有MOTW防护的情况下打开恶意文件。

**CVE-2022-41128:Windows脚本代码远程执行漏洞**

CVE编号: CVE-2022-41128

受影响组件: JScript脚本引擎

漏洞类型:  远程代码执行

是否在野利用:  是

*详情:*

该漏洞是影响JScript脚本语言的远程代码执行漏洞。

JScript是由微软公司开发的动态脚本语言，其最初随Internet Explorer 3.0于1996年8月发布。

攻击者可通过该漏洞制作一个恶意的JScript脚本, 使用户访问恶意的网页, 从而使得在用户机器上执行远程代码。
