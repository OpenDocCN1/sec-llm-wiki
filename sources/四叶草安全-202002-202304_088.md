# 马坤受西北工业大学邀请“开讲”网络安全

**马坤**受西北工业大学邀请

**“开讲”网络安全**  

Talk about Internet security

  

**达摩克利斯之剑**

** 黑暗中的威胁**

  

  

  

![](../Images/2c1c060d5ed83435677023f1d0d8b8fa.png)

  

近日，四叶草安全董事长兼总裁马坤，应西北工业大学网络空间安全学院的邀请，在网络安全文化节上，为广大师生带来一场题为《达摩克利斯之剑——黑暗中的威胁》的线上讲座。

![](../Images/ff76638f9c417261793b8d2f5395a5e5.png)

  

  

![](../Images/41c889de3590711606f7e528a7e35fe5.png)

  

在西工大网络安全文化节系列活动中，西安四叶草信息技术有限公司创始人马坤先生作为教育部全国高校毕业生就业创业指导委员会专家委员、陕西省网络安全风险防控实验室副主任。受邀为西工大师生带来了主题讲座。内容围绕“网络安全形势”、“网络安全事件”以及“安全体系建设”三部分展开。生动地将他本人及四叶草安全擅长的网络安全知识与理念进行传递与分享。

  

  

![](../Images/da37f789d407d89fbeb7d997735ea320.png)

  

  

马坤在讲座中对师生们说：现在的互联网像是一棵树的树冠，树冠不管多茂盛，如果根茎出了问题，树冠则会迅速枯萎。根茎是传感器芯片和操作系统，各种各样的应用是树冠，当初的开发者考虑不足，如今日益增多和庞大的应用并不能被很好的支撑，于是出现了各种各样的第三方系统，不过都是在原有的基础上修改。就和盖楼的地基一样，坑就是那么浅，楼却盖的越来越高，难以保证不出问题。而“算法和协议”是浇灌树的水，如果水出了问题，树也会面临死亡。  

  

通过一系列形象的比喻，马坤让大家对目前的网络安全形势与现状有了更深入的认识。他还用不少网络安全案例分析，为西工大师生进行网络攻击手法、黑客对于重点目标的选择方法以及在网络安全事件发生后对攻击的追踪、溯源、反制方式等知识进行分享与探讨，与师生们在线上精彩互动。

  

“网络信息安全应回归以人为本。”马坤多年专注网络安全领域，深知专业人才对于网络安全的重要性。他在讲座中也将四叶草安全多年来针对网络安全人才培养方面的实践总结拿出来与西工大师生进行分享，同时将公司旗下的网络安全人才教育平台产品“云演”免费提供给西工大相关专业师生使用。

  

  

  

  

![](../Images/1b422a31ba943001723228c6d7b62ebd.png)

  

通过本次的主题讲座，马坤先生希望更多的网络安全专业学生能够学会“以黑客的思维对抗黑客”，从固有的书本思维中跳出来。因为只有了解了对手以及出招，才能更好的进行应对；也更加希望能够有更多的人才加入网络安全大家庭，共同建立起国家、社会、网络空间的安全防御体系。整个讲座气氛轻松愉快，内容干货满满，赢得师生们的一致好评。

  

![](../Images/2c1c060d5ed83435677023f1d0d8b8fa.png)

为贯彻落实习近平总书记关于网络安全的重要指示精神，提升师生网络安全意识与防护技能和学校的网络安全水平，西北工业大学网络空间安全学院在2022国家网络安全宣传周期间，举办包括大咖讲座在内的形式多样的网络安全文化节，旨在培养西工大师生维护网络安全的意识与责任感，使“**网络安全为人民，网络安全靠人民**”的观念在师生心中扎根。
