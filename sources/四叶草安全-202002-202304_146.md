# 小草日 | 四叶草安全趣味活动成功举办

2022年Q1转瞬间就飞逝而去，正值Q1总结以及Q2开启节点，除工作任务、业绩压力外，夏天的风悄悄吹过，西安快速升温的天气也给每一位小草“添了一把火”。

  

4月21日，为加强团队凝聚力、活跃团队气氛，使新小草加速融入团队，由四叶草安全人力行政部牵头策划组织了本年度第一波员工趣味活动。

  
  
![](../Images/1babd81b081366294274d4b0359a0b8d.png)

**小草趣味活动**

![](../Images/849b7a4936b32cc221df99017acdf7a5.png)  
  
本次小草趣味活动设置个人赛、团队赛两大项，让小草们暂时从紧张的工作氛围中抽离出来，在放松娱乐中焕发新的活力与热情。

**趣味运动安排**

![](../Images/fa2d9ff378469dd209ab6191f67dec27.png)

**个人赛**

“套圈游戏”、“报纸拔河”、“emoji表情猜美食”三个个人赛项目可谓“战况激烈”，小草们手脑并用彰显热情。

![](../Images/dacbf15fe2d40cced72b9b021c48e7cd.png)

![](../Images/bca512b2aa7cc32811e9e5de6ddb8f42.png)

**团队赛**

团队赛中，以公司部门为主体的参赛队员本着为团队荣誉“拼命”的信念参赛，分秒必争。

![](../Images/ba15244fb85049eeb188d4ca40e1d7cf.png)

![](../Images/d7d9c4d11b2847630a4438c395dd0ed1.png)

“一圈到底”、“手脚并用”、“夹气球跑”、“吹乒乓球”四个团队战项目正式将整场活动推向高潮，喝彩声此起彼伏。

**领奖喽**

经过激烈角逐，本次小草趣味活动也在愉快快乐的氛围中落下帷幕，各团队成员虽都包含荣誉之心，但也没忘了活动的初衷——“趣味”与“放松”。

4.21日的小草热闹沸腾，每个人都沉浸在喜悦之中。小草们挥洒汗水、张扬青春，带给我们的不仅仅是欢乐，更是一份感动、一种团结向上的力量。

  

名次和奖品固然重要，但更重要的是**收获了属于自己团队的凝聚力**，这将是本次活动中最无可比拟的宝贵财富。

**致谢**

![](../Images/d569559b55f6da4307c090dd8dbab6ba.png)

裁判宣读规则中感谢人力行政部的精心策划与组织，作为工作人员和裁判纵使无法参加比赛，但每一位签到、组织、协作的小伙伴都全身心投入活动，她们都是最可爱的人，值得我们献上大大的一个赞。  
  
  

回首过去，四叶草安全多层次发展员工综合素质、激发员工潜能，使每位员工都能最大限度发挥自我特长与激情；

  

展望未来，我们将不断激发员工激情、提升企业活力，用创新思维为公司建设事业作出贡献发展，齐心协力共促小草未来。
