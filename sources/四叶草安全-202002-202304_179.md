# 再起征程|2022四叶草安全线上年会圆满举办

2022年1月25日，四叶草安全年终盛典如约而至，受疫情影响，年会第一次以线上形式与大家见面。

![](../Images/70a39705179ac0f5fd6583f5422fae10.png)

  

![](../Images/6dd3d32500822970f9d81f530386fcac.png)

**新年致辞**

![](../Images/3b112e06789394f042b45b7d9b7e9ee6.png)

  

  

会议伊始，由四叶草安全董事长兼总裁马坤为大家发表新年致辞，首先他对于过去一年每位小草的努力及付出表示感谢。在2021年，四叶草安全由地方性企业成长为国家级重点专精特新小巨人企业，完成了B+轮融资，两款产品入围中央集采名录，产品服务也从单一模式拓展到解决方案模式...收获满满但也稍有遗憾。2022已经到来，他期望每一位小草能够立足当下，本色做人，角色做事，唯有奋斗，才能让未来的资产和生命更加安全。

  

  

  

![](../Images/02ea9c30470042571297e6350a85732b.png)

  

  

本次年会分为三个篇章——“后浪们”、“卷起来”、“去远航”。在每个篇章中公司领导都会发送一轮红包雨，年会也设置了惊喜连连的抽奖环节！

  

第一篇章：“后浪们”。一段鼓舞人心的视频点燃了线上年会的氛围，该视频由四叶草安全市场部在疫情期间作词选曲，面向全公司的后浪们收集演唱视频，并完成剪辑，意在为大家居家办公期间的枯燥生活送去一份温暖及快乐。

  

![](../Images/b34c7df44d02a4b13fa2362d733bdd95.png)![](../Images/352ec6bbfa5ba1467feaa5cc4412ee7b.png)![](../Images/900e30bd175fff300c001aae094ab559.png)![](../Images/643a48a5d11fca57b9e280e2e15a66fc.png)

  

第二篇章：“卷起来”。本环节对在过去一年中，对公司有突出贡献的小草及团队进行表彰与认可。他们无畏困难，勇往直前的精神，让团队内部良性竞争真正“卷起来”！  

  

![](../Images/eaa07969f89d8fd1d4caede9591041cf.png)![](../Images/fa64553bb052a030c1e44b8ab41e2e15.png)![](../Images/4b736138e078bcb100915d38e94d7438.png)![](../Images/bdf1c49ae7c7aafafb6a22efe8192d6c.png)

（以上为部分荣誉员工及团队）

  

第三篇章：“去远航”。2022年将是四叶草安全走过的第十个年头，第一个十年，每一位小草、每一个团队都已经摩拳擦掌，准备在这具有里程碑意义的一年大展宏图，四叶草安全各团队负责人代表大家献上了誓词。

  

  

  

![](../Images/02ea9c30470042571297e6350a85732b.png)

  

  

活动最后，又一轮抽奖环节将欢乐的氛围拉向最高潮，本轮抽奖以量多取胜，中奖率为55%！四叶草安全创始团队也为小草们送上了满满的新年祝福，最后，年会在大家的欢声笑语中圆满落下帷幕。

  

![](../Images/62fc23878d158a1ef316915b15ca7d97.png)![](../Images/ac39b65cdebdccd20f9ac81a820ba81f.png)![](../Images/1b5986dc59aecf4a8a952ad873ace53f.png)![](../Images/e6147450e5587d59a1b04df1c0e3d782.png)

  

  

  

![](../Images/02ea9c30470042571297e6350a85732b.png)

  

  

站在2022年新的起点，相信我们共同努力，一定能取得一个又一个胜利！心中有爱，眼里有光，四叶草安全祝大家新年快乐，虎虎生威！
