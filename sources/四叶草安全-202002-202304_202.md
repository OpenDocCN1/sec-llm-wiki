# 如何应对屡见不鲜的“偷拍” 与无处不在“针孔” ？

近半年来，全国范围内的高校相继曝出8起偷拍事件。而出现在校园内的偷拍事件真的可以说只是冰山一角。无良的偷拍者愈发肆意妄为满足自己变态心理欲望的同时，也在不停的更新自己的“作案工具”以及“作案地点”。  

  

作为偷拍者利用最多的工具——针孔摄像头可以说是无所不在。酒店、厕所、出租房、公交地铁、扶手电梯…仿佛现实版《楚门的世界》，可能某一瞬间，你的隐私正在被别人肆意窥探。  

  

![](../Images/d68e5074b2c082579f8a8d45715bbd0e.png)

  

针孔摄像头，即超微型摄像机，拍摄孔径只有针孔大小，而其摄像头的大小，则大概有一元硬币那么大。针孔摄像头本来是用于记者暗访、警察调查取证等环节上，用来维护正义保护人民安全的，可是少数不法分子将这种技术用在了邪路上。  

  

酒店里，一定要重点关注墙上莫名其妙的洞和位置诡异的照片与画，这些地方极有可能是针孔摄像头的藏匿点。此外，还要注意烟雾探测器 / 报警器、电源插座、电器插头、照明灯、书本、影碟、游戏碟、诸如立柜和桌台等大件家具的边角、笔记本电脑、鼠标、台灯等。

  

另外，如果是偷拍者，肯定要放置摄像头到视野最开阔的地方，寻找更好的视角。因此，房间上层的四个定角以及钟表这种顺理成章挂在高处的物件，必须重点检查。

  

![](../Images/b9c4896ed074fcb384374b3e28b67be9.png)

  

  

**如何检测隐藏的摄像头？**

  

方法一，可以关灯后在黑暗中寻觅盗摄摄像头。因为摄像设备通常会有或红或绿的发光二极管来显示运作状态。如果安装它的人活糙，就留下了最显眼的证据。用纸卷就能强化侦查效果。把不透明的纸卷成筒，贴近眼睛，闭上另一只眼。然后打开手电筒，与闭着的眼平齐。此时，关上室内所有的灯，拉上窗帘，遮挡住任何外来光，缓慢移动视线，检查你觉得可疑的地方。

  

方法二，用手机检查针孔摄像头。关闭房间中的所有电器设备，打开手机，随便拨一个号码，走遍房间的各个角落，听到异响，就能断定有意料之外的设备了。借助的原理不复杂：某些摄像头在成像时，会不断扫描像素点，从而形成一定频率的电磁波泄漏。

  

另外，有许多网帖称，手机自带的相机可以识别间谍摄像头。只要打开对准房间的角落绕一圈，哪里有红点哪里就有问题。这是智能机时代（2008 年）前诞生的经验，早就已经过时了。因为当时的手机没有高清，只有高糊。但今天，人们对手机拍照的要求越来越高，动辄千万像素的高端对焦，加装红外滤光镜早已成了顺理成章的事。

  

  

最后，一旦发现针孔摄像头偷拍，应立即报警和联系酒店相关负责人，不要嫌麻烦，更不要不好意思。

  

违法偷拍者会得到应有的处罚，违法生产销售针孔摄像头者也会受到法律的制裁。

  

对销售偷拍设备的行为，法律有规定。如在《中华人民共和国刑法》第二百八十三条规定：非法生产、销售专用间谍器材或者窃听、窃照专用器材的，处三年以下有期徒刑、拘役或者管制，并处或者单处罚金；情节严重的，处三年以上七年以下有期徒刑，并处罚金。

  

对偷拍等侵犯人身权利的行为，法律也有规定。如《中华人民共和国治安处罚法》规定，偷窥、偷拍、窃听、散布他人隐私的，可以给予罚款与拘留。

  

《民法典》第一千零三十三条：除法律另有规定或者权利人明确同意外，任何组织或者个人不得实施下列行为。这些行为就包括进入、拍摄、窥视他人的住宅、宾馆房间等私密空间；拍摄、窥视、窃听、公开他人的私密活动；拍摄、窥视他人身体的私密部位等。

  

最后，不法分子偷拍“无处不在”，大家外出记得要多留一个心眼，注意时刻保护个人隐私哦！
