# 2021年国家网络安全宣传周人工智能安全产业发展论坛邀您参与！

近年来，以AI、大数据技术以及第五代移动通信网络技术（5G）等为代表的新一轮数字革命迅速发展。人工智能作为数字化技术与数学、脑科学、认知科学等多学科交叉的前沿领域，是数字经济驱动核心的关键技术。

然而，人们在享受自动驾驶、高频金融交易、刷脸支付等AI新技术发展带来的便利同时，AI不断进化、自我训练式成长和变异的特征，以及基于机器学习和深度搜索提升攻击效果的能力，也带来了新的攻击面和攻击手段，数字经济时代下的AI安全机遇与挑战，已成为时下最具研究价值的热点之一。

为加快人工智能安全、可靠、可控地高质量发展，助力构建与城市数字化转型相适应的大安全格局，为中国乃至世界人工智能安全发展贡献力量，特定于2021年国家网络安全宣传周期间举办人工智能安全产业发展分论坛。论坛相关信息：

  

**论坛简介**

  

人工智能安全产业发展分论坛将从政策、产业、法律和技术四个维度，围绕人工智能安全对国家安全、社会安全、城市安全、关键信息基础设施安全和个人信息安全等方面进行深入探讨，同时，现场将发布人工智能安全典型实践案例评选结果。届时，中国网络空间安全协会、中国信息通信研究院、全国工商联大数据运维（网络安全）委员会、数字丝路安全智库等专家学者，网络安全企业、互联网企业、企事业单位等的技术人员以及高校师生、媒体等受邀参加论坛。

  

**时间地点**

  

时间：2021年10月12日14:00-17:30

地点：西安国际会展中心303厅

**疫情防控要求**

  

按照《2021年国家网络安全宣传周重要活动疫情防控和医疗保障工作方案》，本论坛疫情防控相关要求如下：

1.  所有参会人员需完成新冠病毒疫苗全程接种，并持有参会当天前48小时内新冠病毒核酸检测阴性报告；
    
2.  所有参会人员会前必须进行健康申报，并如实填写新冠肺炎疫情防控健康承诺书。在参会当天将近14天健康监测记录表和新冠肺炎疫情防控健康承诺书提交至签到处工作人员；
    
    健康申报表下载链接：
    
    https://pan.baidu.com/s/1L8fzMW-GmGpSXhjO\_DWOjA
    
    提取码：hrxh
    
3.  会前14天内本人未被诊断或确诊为新冠肺炎确诊病例、疑似病例、无症状感染者和密切接触者、密接的密接；
    
4.  会前14天内本人没有出现发热（体温≥37.3℃）、乏力、咳嗽、胸闷等新型冠状病毒感染有关的症状；
    
5.  会前14天内本人未到过疫情中、高风险地区所在地级市；28天内未出国（境）、近14天本人未接触境外回国人员。
