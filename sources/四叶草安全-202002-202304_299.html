六一专栏|中小学生应该了解的网络安全知识

又到了一年一度的“六一”儿童节，不知从什么时候开始“儿童节”不再专属儿童，有很多“大朋友”也会在这一天寻找失去的童真，一颗棒棒糖、一次游乐场之旅仿佛会让每个人都回到美好的童年。



随着科技的发展、网课的需要以及手机和平板电脑的普及，很多小朋友从小就开始接触网络，但是网络上什么东西都有，小朋友的辨别能力不够，所以为了让小朋友安全上网，很多学校都会组织学生以手抄报、板报等形式普及学习网络安全知识，那么中小学生需要知道的网络安全知识有哪些呢？借着六一儿童节之际，四叶草安全也来给大朋友、小朋友们普及一下中小学生在日常的网络使用中需要注意什么。希望能够帮助小朋友和家长朋友。



上网查阅信息时，请注意：

  1. 坐姿要端正、眼睛不要离屏幕过近。

  2. 屏幕设置不要太亮也不要太暗。

  3. 每次在电脑屏幕前不要持续超过1小时。

  4. 不要随意在网上购物。

  5. 要适当到户外呼吸新鲜空气。


学生上网交友时，请特别注意：

  1. 不要说出自己的真实姓名和地址、电话号码、学校名称、父母信息等信息。

  2. 不与网友见面，如非见面不可，要去人多的地方。

  3. 对谈话低俗的网友，不要反驳或回答，以沉默的方式应对。

  4. 学会自我保护，小心谨慎总没错。


密码安全常识：

  1. 设置足够长度的密码，最好使用大小写混合加上数字和特殊符号。

  2. 不要使用与自己相关的资料作为密码，比如生日、电话和姓名简写等等。

  3. 不要将多个账户的密码口令都设置为相同的。

  4. 密码需要经常更换，建议两个月左右换一次。

  5. 不要让任何系统或者软件保存你的密码，因为它们的加密方式抵挡不住任何黑客攻击。


上网冲浪安全常识：

  1. 尽量不要下载个人站点/有风险的程序，因为它们可能感染了病毒，或者带有后门。

  2. 不要运行自己不熟悉的可执行文件，尤其是一些看似有趣的小游戏。

  3. 不要随意接受陌生的聊天请求，避免遭受端口攻击。

  4. 不要随便打开陌生人的邮件附件，因为它们很可能是恶意软件。

  5. 不要去逛一些可疑或者另类的网站，因为浏览器的许多漏洞会被利用，对你造成攻击。


写在最后：长时间使用电子产品，不仅会影响小朋友的视力，还会改变脑电波，给身体带来不利影响。有美国的学者曾做过研究，认为这种不利影响首先是对脑电波的影响，会形成两种有害脑电波，一种是睡眠性的脑电波，还有一种是快速锯齿脑电波，会使人失去判断能力，容易使儿童患上痴呆症。所以小朋友们使用电子产品一定要适度哦！
