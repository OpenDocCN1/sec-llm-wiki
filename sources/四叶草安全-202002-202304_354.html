安全服务工程师

岗位职责：

1. 负责客户的信息安全风险评估、渗透测试、安全加固、漏洞扫描、基线检查、应急响应等相关内容项目实施，把控项目进度及项目质量，对项目工作方法和质量进行改进；

2. 负责日常安全服务技术交流及解决方案编写；

3. 协助销售进行安全服务交流或向客户讲解安全服务方案，汇报服务成果等；

4. 指导和协调项目成员完成项目工作，与客户沟通协调项目实施，向客户和领导进行项目工作汇报，报告工作进展和工作计划；

5. 完成对客户的技术支持和应急事件处理。

岗位要求：

1. 大专以上学历，计算机相关专业，2年以上工作经验；

2. 具有网络安全项目服务工作经验者优先考虑；

3. 具有较强的沟通能力、团队合作能力、学习能力、文档撰写能力，工作态度认真负责；

4. 对信息安全有兴趣，致力在信息安全行业发展；

5. 能适应短期出差。

渗透测试工程师

岗位要求：

1. 大专以上学历，计算机相关专业，3-5年渗透测试经验；

2. 精通渗透测试步骤、方法、流程，具备独立开展渗透工作的能力；

3. 熟练掌握WEB安全和漏洞挖掘，熟悉漏洞的原理、方法、利用手段及解决方案；

4. 掌握perl、python、java等编程语言至少一种，能编写漏洞检测或利用工具；

5. 掌握c／c++/c＃/go等编程语言至少一种；

6. 满足以下至少一项条件者优先录用：

a) 大型独立渗透项目经验；

b) 在t00ls、freebuf、Seebug等网站发布过漏洞、文章者；

c)参加过CTF比赛获取名次的优先；

d)熟悉常见的网络安全设备；

e)具有Python开发经验，熟练掌握Python的使用；

f)有内网渗透经验优先。

3. 熟悉常见的网络安全设备；
4. 参加过CTF比赛获取名次的优先；

7. 有内网渗透经验的优先。

1. 负责分析与跟进国内外热点安全事件的漏洞及原理，并对相关产品提供检测，修复，防御感知等方案；

2. 负责前沿安全技术研究和漏洞挖掘，提升公司在安全行业的影响力；

3. 从事病毒、木马、漏洞等恶意样本的分析与研究，与其他产品线团队配合，完成产品检测能力的提升。

岗位要求：

1.熟悉汇编语言、c/c++语言、能熟练读懂汇编代码；

2.有较好的逆向功底，熟练使用IDA、GDB、OD等；

3.了解操作系统的相关安全机制,掌握绕过漏洞缓解措施的基本方法；

4.了解漏洞挖掘和分析相关技术、工具以及平台，如Fuzzing测试；

5.学习能力强、富有团队精神、有责任心和进取能力；

6.具有恶意代码分析经验者优先，参加CTF并且获得奖项者优先，具有实际安全培训经验（讲师）者优先。

1.根据项目的具体需求进行部署环境调研并编制实施方案，并记录实施过程中遇到的问题和解决办法；

2.根据项目的具体需求点对部署完成的项目进行测试和检验，确保各项需求点满足；

3.配合项目经理同客户负责人对项目进行验收并对客户的疑问点进行解答；

4.根据项目中部署的产品对客户进行培训（功能点介绍，操作讲解）；

5.对内部使用相关产品的部门进行产品操作使用培训；

6.通过多种方式对客户提出的问题及时处理和反馈。

岗位要求：

1.计算机软件、通信工程、信息安全、信息对抗相关专业，拥有CCNP/HCNP/CISP优先；

2.1年以上的安全行业工作经验，熟悉OWASP TOP 10，具有网络安全、系统安全、Web安全等方面的理论基础；

3.熟悉常见网络安全产品（防火墙、IDS/IPS、Waf、漏洞扫描、安全审计、SOC等）的部署及Linux、shell/python编程、熟悉web安全相关技巧；

4.具备较好的沟通协调能力，积极主动，抗压力强，良好的团队合作能力、良好的服务意识，勇于承担的责任心。
