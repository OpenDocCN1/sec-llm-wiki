# 四叶草安全荣获“中国十大网络安全新兴企业”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTI2NDQzNg==&mid=2654533152&idx=2&sn=8d523dd24dbcec9a5f8689149298d10f&chksm=bd746dfb8a03e4ed92470acd03e1d247ab49c2574e6a0eb7082a246de94a9fbb0861a043f53e&scene=126&sessionid=1681375060#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTI2NDQzNg==&mid=2654533152&idx=2&sn=8d523dd24dbcec9a5f8689149298d10f&chksm=bd746dfb8a03e4ed92470acd03e1d247ab49c2574e6a0eb7082a246de94a9fbb0861a043f53e&scene=126&sessionid=1681375060#rd)

近日，国内等级保护领域权威媒体——等级保护测评发布“中国十大网络安全新兴企业”名单。**凭借着在网络安全领域的专注与创新，四叶草安全成功入选。**

  

![](../Images/340510899228fb2817cb4172095a6dff.png)

四叶草安全是一家领先的实战创新型网络安全企业，专业的网络安全综合解决方案提供商。公司秉承“以攻促防”的安全理念，为客户构建“AI+安全”的主动安全防御体系，致力于让安全风险可控，防御更简单。

  

公司成立于2012年，立足西安，服务全国，经过8年的发展，已是国家高新技术企业、硬科技优秀企业、培育独角兽企业、科技小巨人企业、CNCERT技术支持单位、CNNVD技术支撑单位、CNVD技术组单位，拥有百余项技术专利和完善的网络安全资质，业务覆盖全国28个省份，建设过政府、互联网、运营商、金融、医疗、军工、公安、教育、能源等行业的数百个大型项目。

  

公司安全产品划分“攻”和“防”两个系列：

![](../Images/64d15f23aa07e64342180669a3b15a7b.png)![](../Images/64d15f23aa07e64342180669a3b15a7b.png)![](../Images/ca3c2864e60e91d855994494e81526c1.png)

“攻”为感洞系列。主要用来检测/监测用户系统弱点，于第一时间发现用户系统存在的安全隐患。产品包括：感洞网络安全态势感知平台、感洞全时风险感知平台、感洞网络风险监测平台、洞镜异常行为实时监测平台、洞见日志收集分析系统、洞查安全配置核查系统、洞彻运维安全审计系统、洞彻数据库审计系统、赤瞳关键信息基础设施风险排查系统等。  

“防”为御系列，产品包含：御垒防御体系、御盾下一代防火墙、御盾工业防火墙系统、御守入侵防御系统等，实现对用户、应用和内容的深入分析，为用户提供高性能、可视化、精准有效的应用层一体化安全防护体系。

凭借自主研发的核心技术、强大的产品功能及贴心的安全服务，参与多个国家级项目和省级项目。

  

此次从众多竞争者中脱颖而出成功入选，是等级保护测评对四叶草安全行业影响力和综合实力的高度认可。未来，四叶草安全将以此为契机，不断提升综合技术能力，为我国建设网络强国做出更大贡献。
