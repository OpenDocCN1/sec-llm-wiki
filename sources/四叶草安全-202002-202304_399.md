# 网络安全创新技术论坛议程发布|华山论剑•2020网络安全大会！

华山论剑•2020网络安全大会由第三届全国信息安全企业家高峰论坛与第五届SSC安全峰会联合举办，作为西安市“四会一节”的重大活动之一，聚焦网络安全行业，助力企业数字化升级。“两会”联合旨在助推西安打造“网络安全示范城市”建设，发出网络安全的“西安声音”。

5G被誉为“数字经济新引擎”，将为“中国制造2025”和“工业4.0”提供关键支撑，AI技术正在改变世界，也正在推动着传统网络安全格局的变革，面对全新的挑战，生态的开放，新技术正在重塑安全行业的新格局。大会将于10月14日13:30-17:30举办网络安全创新技术分论坛，该论坛主要讨论5G、AI、云计算等新技术相关的网络安全话题。
