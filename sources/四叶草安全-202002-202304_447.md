# Fastjson <= 1.2.68远程代码执行漏洞通告

**漏洞背景**

Fastjson是阿里巴巴的开源JSON解析库，它可以解析JSON格式的字符串，支持将Java Bean序列化为JSON字符串，也可以从JSON字符串反序列化到JavaBean。

  

**漏洞详情**

Fastjson采用黑白名单的方法来防御反序列化漏洞，导致当黑客不断发掘新的反序列化Gadgets类时，在autotype关闭的情况下仍然可能可以绕过黑白名单防御机制，造成远程命令执行漏洞。

经四叶草应急响应团队安全研究员证实，该漏洞利用门槛较低，可绕过autotype限制，风险影响较大。

  

**漏洞影响范围**

Fastjson <= 1.2.68

Fastjson sec版本 <= sec9

Android版本不受此漏洞影响

  

**漏洞危害**

**高危**
