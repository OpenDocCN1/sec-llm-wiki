# vBulletin5\_5.6.1 SQL注入漏洞（CVE-2020-12720）通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTI2NDQzNg==&mid=2654528017&idx=2&sn=7a4b5f08e0fbcc3795c9e1a068dce967&chksm=bd7479ca8a03f0dcfc10f2d6f21e24fd88e5c5fa02bc035d7728db539fc14229d57100df21cc&scene=126&sessionid=1681375106#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTI2NDQzNg==&mid=2654528017&idx=2&sn=7a4b5f08e0fbcc3795c9e1a068dce967&chksm=bd7479ca8a03f0dcfc10f2d6f21e24fd88e5c5fa02bc035d7728db539fc14229d57100df21cc&scene=126&sessionid=1681375106#rd)

![](../Images/2685e625f2476ccd03abf9b003cbf8f1.png)

**漏洞背景**

vBulletin是美国InternetBrands和vBulletinSolutions公司的一款基于PHP和MySQL的开源Web论坛程序。近日，vBulletin官网发布了最新5.6.1版本安全补丁，提示修复一处安全漏洞。

  

**漏洞详情**

未经授权的攻击者可以通过特定URL的nodeid参数进行SQL注入获取数据库敏感信息。

经四叶草安全应急响应团队验证，该漏洞真实存在。

![](../Images/9948dea04f866e9ff8c009f23c50af9f.png)

  

**漏洞影响范围**

vBulletin 5.5.6 Patch Level 1之前版本

vBulletin 5.6.0 Patch Level 1之前的5.6.0版本

vBulletin 5.6.1 Patch Level 1之前的5.6.1版本

  

**漏洞危害**

**高危**
