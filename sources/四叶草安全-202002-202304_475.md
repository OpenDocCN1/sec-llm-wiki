# 【漏洞通告】通达OA前台任意用户伪造登录漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTI2NDQzNg==&mid=2654527901&idx=1&sn=6b55c92d932365846dab4e94bd445437&chksm=bd747a468a03f350746e10e0db185d8c7308c758f7c4e86057b6ec996de6290b8ec1fdc8b76c&scene=126&sessionid=1681375111#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTI2NDQzNg==&mid=2654527901&idx=1&sn=6b55c92d932365846dab4e94bd445437&chksm=bd747a468a03f350746e10e0db185d8c7308c758f7c4e86057b6ec996de6290b8ec1fdc8b76c&scene=126&sessionid=1681375111#rd)

**漏洞背景**

通达OA（Office Anywhere网络智能办公系统）是由北京通达信科科技有限公司自主研发的协同办公自动化软件。2020年04月17日，通达OA官网发布了最新11.5版本，其中修复了11.5版本之前存在的一个任意用户伪造登录漏洞。

  

**漏洞详情**

未授权的远程攻击者可以通过精心构造的请求包，伪造任意用户登录，包括管理员。经过四叶草安全应急响应团队确认，此漏洞真实存在。![](../Images/c7a18f59971eb48d4e28957357dfa549.png)

  

**漏洞影响范围**

通达OA < 11.5版本

  

**漏洞危害**

**高危**
