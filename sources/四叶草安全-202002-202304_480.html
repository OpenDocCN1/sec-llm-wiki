漏洞背景

近日，IBM官网发布WebSphere Application Server权限提升漏洞（CVE-2020-4362）安全通告。该漏洞影响WebSphere Application Server 7.0 - WebSphere Application Server 9.0之间多个版本。IBM WebSphere Application Server（WAS）是美国IBM公司的一款应用服务器产品。该产品是JavaEE和Web服务应用程序的平台，也是IBM WebSphere软件平台的基础。


漏洞描述

当WebSphere在SOAP connector的管理请求中使用基于令牌的身份认证时，攻击者通过向WebSphere SOAP connector发送精心构造的恶意请求，可能在受影响的服务器上进行权限提升。


漏洞影响范围

WebSphere Application Server 9.0

WebSphere Application Server 8.5

WebSphere Application Server 8.0

WebSphere Application Server 7.0


漏洞危害

高危
