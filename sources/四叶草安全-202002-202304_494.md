# 在线教育如何更安全?来看这份解决方案！

**●****行业背景****●**

2020年的新冠肺炎，为防控疫情，教育主管部门提出停课不停教不停学，统筹整合国家、地方和学校相关教学资源，开通网络云课堂，供开学后各地学校组织中小学生开展网上学习。2月14日，国务院教育督导委员会办公室发出紧急预警，明确疫情期间严禁开展任何形式的线下培训，不得举办任何形式的聚集性培训活动。与此同时，一些线下的校外培训机构纷纷转至线上，线上机构也扩大原有的运营规模。疫情带来了危机，但也是部分企业调整方向和孕育转变、发展的契机。

  

**●****线上教育安全风险分****析**** ●**

互联网时代，越来越多的应用从C/S架构转为B/S架构，线上教育平台对学生的服务窗口就是Web网站，随着教学应用层业务规模不断扩展，遭受的Web应用安全攻击也越来越频繁。对线上教学而言，信息安全就是教学系统的安全，必须保证教学内容的政治性、科学性、一致性和可用性，否则再华丽的平台非但没有起到教学目的，反而可能成为黑客攻击的阵地。  
目前信息安全攻击有 75% 以上都是发生在 Web 应用层，而目前超过2/3的 Web 站点都相当脆弱，易受攻击，这些攻击形式多种多样，手法也越来越隐匿，我们往往需要去对多台安全设备中记录的日志进行大量的日志分析，进而去配置针对性的策略，这无疑对安全运维人员的水平提出了很高的要求。因此导致**当前教育培训行业常见的风险如下：****安全漏洞**：教学系统一旦有严重的安全缺陷，将会受病毒或者黑客利用，对信息安全、系统的使用、网络的运行构成严重的威胁，从而导致学生信息泄露。**网络攻击**：教学系统面对DDOS拒绝服务攻击，—旦资源被耗尽，可能中断服务，导致学生无法正常连接教学系统，严重影响教学质量和教学的顺利进行。**系统篡改**：系统篡改是指攻击者利用漏洞将正常的内容替换为攻击者提供的网页/文字/图片等内容。如果挂上涉政、反政府、威胁学生健康成长的信息，就意味着教学服务将被迫停止服务，对教学机构的形象及信誉会造成严重的损害。

  

**●****教育移动应用的相关数据合规要求**** ●**

我国已初步形成了以《民法总则》、《网络安全法》等法律为基础，辅之以法律、行政法规、部门规章、国家标准等配套规定而形成的网络安全和个人信息保护的法律体系。教育移动应用主要是通过网络平台提供家校（包括学生和家长）沟通的平台，或者提供线上的教育和培训，因此教育移动应用提供者属于网络经营者范畴，应当按照《网络安全法》等适用法律法规等规范确保网络安全，并履行个人信息保护合规要求。《网络安全法》规范网络运营者即网络的所有者、管理者和网络服务提供者运营网络、使用数据（包括个人信息）的行为，其要求网络运营者实行网络安全等级保护制度，并就个人信息的保护作出基本要求，包括在个人信息主体知情同意等合法情形依法收集个人信息，公开信息收集和使用规则以明示收集、使用信息的目的、方式和范围，不得收集与其提供的服务无关的个人信息，未经被收集者同意，不得向他人提供个人信息（经过处理无法识别特定个人且不能复原的除外）等。

  

**●****应对思路**** ●**

目前很多教育机构都缺乏必要的信息系统漏洞风险管理机制，由于教学课程和内容的日益复杂，大量IT资产难以梳理，很难彻底找到漏洞位置进行修复。一旦这些未被发现的漏洞被黑客利用，将对教育机构造成灾难性的损失。信息安全攻防对抗愈演愈烈，而防总是慢于攻，攻防并不对等，每次新漏洞出现，都是各个黑产团队火拼的时刻，安全管理员需要下班休息，而黑客不会，午夜奋战，正是挂马、篡改、DDOS各类攻击的最佳时机。假如网络安全人员在休息期间，黑客就极有可能利用漏洞控制服务器进行非法活动，导致教育机构的核心数据外泄。面对当前疫情肆虐的情况，必须做好教学系统网络安全工作。线上教育要想走得更远更好，必须遵守网络安全和数据保护的合规要求，以保证教学系统的安全，保护学生的个人隐私，从而保证学生的学习顺利进行。否则将对招生、续费及退费等产生重大影响，甚至导致企业面临生死存亡境地。

  

**●****解决方案**** ●**

《网络安全法》第二十一、三十四条，要求企业要明确网络责任人，出现安全事故，直接负责人需要承担责任并且接受法律处罚。为响应客户网络与信息系统安全建设工作要求，将网络与信息系统安全纳入信息化日常工作中，深化信息安全监测手段，扩展监控范围，实现对各类网站及应用系统的全方位、实时安全监控，做好信息安全监测预警、指标发布及深化治理工作。因此，需要建设全覆盖、全方位、全天候的风险感知平台，通过先进的安全监测技术实时检测网络安全风险和威胁、综合分析网络安全态势、及时通报预警来应对网络安全威胁尤为迫切。

  

**四叶草安全感洞网络风险监测平台**，综合应用多种内容采集技术获取互联网图文内容并通过AI算法以及海量样本资源库，实现对涉政暴恐、敏感人物、色情违禁等网络违法内容的智能监管，通过自有漏洞库和可验证的插件式扫描方式对互联网资产中存在的漏洞进行快速发现。在发现风险时能将结果实时取证并及时通知监测人员，让整改有据可依。运用数据可视化技术，对风险源、风险发现和风险类别进行实时动态展示。**教学系统的内容监测：**系统篡改是指攻击者利用应用程序漏洞将正常的内容替换为攻击者提供的非法内容，主要包含教学课程内容篡改/文字/图片/等内容。一般来说篡改对计算机系统本身不会产生直接的影响，但对于教育机构而言，就意味着教学服务将被迫停止，对教育机构在业内的形象及信誉会造成严重的损害。四叶草安全感洞网络风险监测平台支持针对学校、教育机构等系统对网站、微博、微信公众号的内容进行监测，帮助教育机构及时发现系统被黑客的恶意篡改威胁，避免经济损失、名誉损失、政治风险等。

*   网站内容采集能够根据网站首页URL，对网站首页和网站全站采用不同策略，获取网站源码、文本、图片和视频内容 。
    
*    微博内容采集能够根据微博ID，获取其历史和最新发布的微博帖子的标题、正文、图片以及评论等内容。
    
*   微信公众号内容采集能够根据公众号ID，获取其历史和最新发布的公众号文章的标题、正文、图片以及留言等内容，图像识别。
    

**教学系统的漏洞扫描：**随着互联网技术的飞速发展，教育机构的业务纷纷转至线上，大量IT资产难以梳理，很难彻底找到漏洞位置进行修复，教育机构的数据具备较高的价值，极易成为黑客攻击目标，这些数据包含有：教学课程、家长和学生资料、身份证信息、账户信息、联系方式等敏感信息，数据被攻击者获取、这对于教育机构而言是毁灭性的打击。

  

**四叶草安全采用自主研发的漏洞扫描引擎**，可以有针对性地对海量预设系统目标开展漏洞扫描分析工作。支持对教育机构的IT硬件、操作系统、数据库、中间件、框架、脚本语言等各种可利用漏洞进行检测，并对检测结果进行综合分析和提供专业修复建议。

*   能够获取系统中存在的各种类别的漏洞，包含漏洞详情、漏洞描述、漏洞的修复建议，并且提供了可操作的漏洞验证指引方案；
    
*   可以对系统进行单次、周期性的监测，周期监测支持每天、每周、每月等多种巡检周期选择，并且可以为不同的网站设置定制化的监测参数。
    

  

**●****效益分析**** ●**

**1、详细的内容监测**发现页面出现敏感关键词，第一时间通知用户。用户可参考四叶草安全提供的安全建议及时删除敏感内容，避免事件影响扩散给自身带来的声誉和法律风险。**2、实时漏洞检测**四叶草安全感洞网络风险监测平台通过7\*24小时对教学网站进行漏洞监测和可用性监测，防止更新新业务后出现新的漏洞。专设应急响应团队，7\*24小时及时响应。**3、零部署、零维护的云端动态安全监测**所有的安全监测设施部署在四叶草安全的云平台上，教育机构仅需要将学生访问的教学系统的域名添加至四叶草安全的感洞网络风险监测平台。之后无需在本地部署任何安全设备，所有的部署和安全策略添加工作全部由四叶草安全技术专家在云上完成。**4、提升客户网络安全管理水平**四叶草安全感洞网络风险监测平台整合了网站安全风险感知、内部信息系统风险感知等，并逐步实现对教学业务网络体系的全覆盖和全方位、全天候风险感知。因此，四叶草安全感洞网络风险监测平台能够让教学机构实时掌握单位内各网站、业务系统以及信息系统的网络安全风险、安全威胁，大大提升网络安全管理水平。
