在做项目的过程中，处理数据报告有时候是一件十分头疼的事情。可能搞定一个目标两三天就可以，但是报告却需要写上一周甚至更长，又或者说是对大量扫描报告进行批量化处理。要是此时能有脚本帮我们处理岂不甚好。

针对于这种情况，今天来安利python是如何处理docx文档的。

本篇推荐一个python库:python-docx

这是一个用于创建和更新docx文件的强大的python库，主要用来创建docx文档。

安装

依赖条件:

python 2.6,2.7,3.3,3.4

lxml>=2.3.2

如果已经安装了lxml，先查看版本。

pip list | findstr "lxml"
pip install python-docx

操作

先通过生成一个扫描报告框架来学习常规的操作

打开文档

首先我们打开一个基于默认模板的空白文档。

document = Document()

添加标题

document.add_heading("xxx")

默认情况下，添加顶级标题，如果需要设置标题级别，指定level(1-9)即可

添加段落

段落是word的基础。

paragraph = document.add_paragraph('xxx')

此方法返回一个引用。其中style的两个值，'List Bullet'跟'List Number'分别指定段落为无序跟有序。

如果需要加粗的话，可以这么使用。

p = document.add_paragraph('xx')
p.add_run('yy').bold = True

那么yy字符串就是加粗显示。

添加分页

如果你希望文本在单独的页面存放。即使当前的页面未铺满。采取硬分页符完成。

document.add_page_break()

添加表

当我们需要以表格的内容展示的时候，也可以使用python完成。

table = document.add_table(rows=1, cols=2,style="Medium Grid 1")

定义行，列，以及style。如果没有定义style，那么显示在word中的将没有表的分隔符，不是那么优雅。

style的样式有很多，可以参考https://blog.csdn.net/ibiao/article/details/78595295 选择想要格式。

当然，添加完table之后，还有几个属性跟方法是经常会遇到。

#获取第一行单元格列表对象
hdr_cells = table.rows[0].cells

#为单元格赋值
hdr_cells[0].text = 'xx'
hdr_cells[1].text = 'yy'

#为表格增加一行

row_cells = table.add_row().cells

#计算表中行数跟列数

row_count = len(table.rows)
col_count = len(table.columns)

添加图片

当需要向word中插入图片时候，该怎么办

document.add_picture('image-filename.png')

默认情况下，word中图片的大小跟图片原本大小一致。如果想获得所需的图像大小，需要指定另一个参数width。

保存文档

document.save('demo.docx')

可以指定需要保存的绝对路径。

最后在补充一点，一个库的函数有很多，要想快速查找或者掌握其用法，熟练使用help跟dir将会提高很大效率。
