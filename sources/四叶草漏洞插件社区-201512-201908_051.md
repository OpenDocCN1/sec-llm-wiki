```python

document = Document()
```

### 添加标题

```python
document.add_heading(
```

### 添加段落

段落是word的基础。

```python
paragraph = document.add_paragraph(
```

此方法返回一个引用。其中style的两个值，'List Bullet'跟'List Number'分别指定段落为无序跟有序。

如果需要加粗的话，可以这么使用。

```python

```

那么yy字符串就是加粗显示。

### 添加分页

如果你希望文本在单独的页面存放。即使当前的页面未铺满。采取硬分页符完成。

```python

document.add_page_break()
```
