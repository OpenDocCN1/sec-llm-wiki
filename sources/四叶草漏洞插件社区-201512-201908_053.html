Scapy 的使用

之前的一篇文章中，我们使用 socket 解析了数据包的内容，也分享过 scapy 实现明文密码嗅探的例子。本篇中我们从几个方面讲解 scapy 的用法。本篇作为一个入门引子。喜欢的爱好者可以添砖加瓦。

简介

Scapy 是一个功能强大的交互式数据包操作程序。使我们可以伪造，嗅探和解析网络数据包。

安装

  • 以 ubuntu 14.04 为例

  • apt-get install python-pip

  • pip install scapy

嗅探

我们可以使用 sniff 轻松捕获数据包。

主要实现功能的函数是 sniff

sniff(filter="",ifoc="any",prn=packet_callback,count="",store=0)

简单解释一下:

filter: 指定一个过滤器，比如tcp port 80，如果留空，默认监听所有的数据包。
iface:设置需要嗅探的网卡。
prn:指定嗅探到符合过滤条件数据包的回调函数。
count:嗅探数据包的个数，为空则嗅探无数个。
store:当设置为0时，将不会再内存中保留原始的数据包，如果渗透过程中，长时间的嗅探，建议设置。

简单使用 packet.show 方法输出一下,看会是什么样子。

from scapy.all import *

def packet_callback(packet):
    print packet.show()   
sniff(prn=packet_callback,count=1,store=0)

看到这是一个 arp 数据包，其中 0x806 是 arp 帧的类型值。0x0800 说明上层为 IP 协议。

嗅探数据包中的 FTP 用户名跟密码

1. 安装 ftp 服务器。

apt-get install vsftpd

#!/usr/bin/env python
# -*- coding: utf-8 -*-
#sniff(filter="",iface="",prn=packet_callback,count=1)

'''
    嗅探ftp用户名跟密码

'''

from scapy.all import *

def packet_callback(packet):
    if packet[TCP].payload:
        ftp_packet=str(packet[TCP].payload)
        if "USER" in ftp_packet or "PASS" in ftp_packet:
            print "Ftp_client_ip is: %s" % packet[IP].src
            print "Ftp_server_ip is: %s" % packet[IP].dst
            print ftp_packet
            print "--------------"


sniff(filter="tcp port 21",prn=packet_callback,count="",store=0)

ARP 监控

#! /usr/bin/env python
from scapy.all import *

def arp_monitor_(pkt):
    if ARP in pkt and pkt[ARP].op in (1,2):
        return pkt.sprintf("%ARP.hwsrc% %ARP.psrc%")

sniff(prn=arp_monitor_, filter="arp", store=0)
