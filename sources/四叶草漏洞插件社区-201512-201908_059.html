简介

Web 应用程序防火墙（或 WAF ）用于过滤，监视和阻止与 Web 应用程序之间的 HTTP 流量。 WAF 与常规防火墙的区别在于，WAF 能够过滤特定 Web 应用程序的内容，而常规防火墙则充当服务器之间的安全门。 通过检查 HTTP 流量，它可以防止源自 Web 应用程序安全漏洞的攻击，例如 SQL 注入，XSS，文件包含和安全性错误配置等等。

WAF 指纹

发送一个恶意请求: 可以看到在 Cookie 中有 safedog:

GET / HTTP/1.1
Accept-Encoding: gzip,deflate
Connection: close
Accept: */*
User-Agent: Mozilla/5.0 (Windows NT 6.1; WOW64; rv:25.0) Gecko/20100101 Firefox/25.0
Host: 192.168.20.135
Cookie: safedog-flow-item=
Cache-Control: no-cache

这只是一个例子, 绝大部分特征可以从 header 中的 server, X-Powered-By, Cookie 中获取到.

同时还有一些可以通过特定资源文件, 如在返回的告警页面中含特定的 CSS 或者 JS 文件.

WAF 探测工具

  • Sqlmap

Sqlmap 用来探测每种 WAF 设备都是一个 python 文件，同样是从 Cookie 信息或者返回头信息进行判断。

举个例子: Cloudflare

可以在 sqlmap/waf 中找到规则文件:

#!/usr/bin/env python

"""
Copyright (c) 2006-2016 sqlmap developers (http://sqlmap.org/)
See the file 'doc/COPYING' for copying permission
"""

import re

from lib.core.enums import HTTP_HEADER
from lib.core.settings import WAF_ATTACK_VECTORS

__product__ = "CloudFlare Web Application Firewall (CloudFlare)"

def detect(get_page):
    retval = False

    for vector in WAF_ATTACK_VECTORS:
        _, headers, _ = get_page(get=vector)
        retval = re.search(r"cloudflare-nginx", headers.get(HTTP_HEADER.SERVER, ""), re.I) is not None
        retval |= re.search(r"\A__cfduid=", headers.get(HTTP_HEADER.SET_COOKIE, ""), re.I) is not None
        if retval:
            break

    return retval

这里可以看到 Sqlmap 也是通过 header 来判断特征的.

Sqlmap 探测 WAF 命令

sqlmap -u "target" --identify-waf

如 ModSecurity

#!/usr/bin/env python


NAME = 'Trustwave ModSecurity'


def is_waf(self):
    detected = False
    for attack in self.attacks:
        r = attack(self)
        if r is None:
            return
        response, responsebody = r
        if response.status == 501:
            detected = True
            break
    # the following based on nmap's http-waf-fingerprint.nse
    if self.matchheader(('server', '(mod_security|Mod_Security|NOYB)')):
        return True
    return detected

可以看到 wafw00f 大部分规则也是通过 header 来判断的.
