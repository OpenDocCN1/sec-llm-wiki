### 简介

Web 应用程序防火墙（或 WAF ）用于过滤，监视和阻止与 Web 应用程序之间的 HTTP 流量。 WAF 与常规防火墙的区别在于，WAF 能够过滤特定 Web 应用程序的内容，而常规防火墙则充当服务器之间的安全门。 通过检查 HTTP 流量，它可以防止源自 Web 应用程序安全漏洞的攻击，例如 SQL 注入，XSS，文件包含和安全性错误配置等等。

### WAF 指纹

发送一个恶意请求: 可以看到在 Cookie 中有 safedog:

```

GET / HTTP/1.1Accept-Encoding: gzip,deflate
Connection: close
Accept: \*/\*
User-Agent: Mozilla/5.0 (Windows NT 6.1; WOW64; rv:25.0) Gecko/20100101 Firefox/25.0
Host: 192.168.20.135
Cookie: safedog-flow-item=
Cache-Control: no-cache

```

这只是一个例子, 绝大部分特征可以从 header 中的 server, X-Powered-By, Cookie 中获取到.

同时还有一些可以通过特定资源文件, 如在返回的告警页面中含特定的 CSS 或者 JS 文件.
