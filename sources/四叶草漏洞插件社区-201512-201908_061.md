各位大佬下午好，很多人最近都在问，老司机徽章的订单明明显示已发货，怎么查不到快递信息呢？

  

![](../Images/f56af0bddc90a215b61854e38b88e0a1.png)

在前两周的“[七夕插件大奔跑](http://mp.weixin.qq.com/s?__biz=MzI0MTE0MjYxOQ==&mid=2649296892&idx=1&sn=fdb2cd10cf74873fac6f2b29c8f01336&chksm=f10db1c8c67a38de9e2fdaec26a88baf7f9cdf257734f107ab0ae9a89dc2473f916d2954f0a8&scene=21#wechat_redirect)”（点击链接可查看详情）活动中，各位大佬也是毫不留情地将10000元大奖尽收囊中，不少没来得及参加活动或者没有取得理想成绩的大佬又开始问，还有没有新的活动可以赚rank？

  

![](../Images/8148a8667051d9fbb564b1acae3360ce.png)

  

说有咱就有~主流应用插件奖励计划仍在持续进行中，**提交国内主流CMS的用户，可获得双倍奖励+特殊加成的奖励！**

  

![](../Images/90819f0c40965704b7227bca1f57a8eb.png "分割线 gif 动图")

  

1**老司机回归计划（持续进行中）**

**针对用户:**2018年1月1日以后未提交过插件且rank大于等于1的老司机。

  

**活动内容:**在2018年1月1日以后未提交过插件且Rank大于等于 1的司机，提交的前3个插件所获Rank翻倍，与本活动可叠加为三倍 Rank。

  

2**国内主流应用插件奖励计划**

![](../Images/2b0f1cdd59293e52407d63f28764430c.png)

  

**针对用户****:**全体用户  

  

**活动内容:**根据应用级别并结合我们实际情况分为**高、中、初**，分别对应**一级，二级，三级**。针对不同级别的应用奖励方式不同。

  

**插件奖励:****总rank=双倍奖励+特殊加成**

特殊加成根据应用不同奖励方式如下:

*   权值为3的应用:+3rank
    
*   权值为2的应用:+2rank
    
*   权值为1的应用:+1rank
    
      
    

**活动时间：**8月28日00：00——9月10日00：00

  

**页面链接：**http://www.bugscan.net/eventlist/1/

  

**活动奖励：**在活动期间，按照提交插件数获得不用的现金奖励。具体如下:

  

| **插件数量范围（i）** || **奖励机制** |
| --- | --- |
| 10<i<=20 || 200京东卡 |
| 20<i<=30 || 300京东卡 |
| 30<i<=40 || 500京东卡 |
| 40<i<=50 || 800京东卡 |
| 50<i<=60 || 1000京东卡 |
| 60<i<=70 || 1200京东卡 |
| 70<i<=80 || 1800京东卡 |
| 80<i<=90 || 2000京东卡 |

  

# **审核时间：**

当天17:00点前的插件当天审核，17:00以后的插件次日审核。

周五17:00到周日17:00提交的插件将于周日当晚审核。

  

# **更新内容：**

本次活动更新了插件提交规范，以及奖励标准。可以访问**doc.bugscan.net**查看。

 

![](../Images/295dd516e9a9cd5ad56d7b88bc121d18.png "分割线")
