hackhttp

首先先了解下POC中经常要使用的第三方库hackhttp。

hackhttp 是四叶草安全旗下 BugscanTeam 打造的一款 Python 语言的 HTTP 第三方库。

我们致力于帮助安全测试人员快速编写代码，除了最基本的基础功能之外，hackhttp支持直接发送原始的HTTP报文，我们可以将浏览器或者burp等抓包工具中截取的HTTP报文复制后，无需修改，可使用hackhttp进行重放。

hackhttp怎么用

废话不多说，先看效果。

发送一个GET请求

code为int型

In [1]: from dummy import *

In [2]: code,head,body,redirect,log=hackhttp.http("http://www.bugscan.net")

In [3]: code

Out[3]: 200

发送表单POST请求

根据RFC的标准，可选的请求方式有:OPTIONS,GET,POST,HEAD,PUT,DELETE,TRACE,CONNECT。

自定义请求头

第一种:使用字典形式，需要使用将请求头字典传给 headers

注意:如果同时指定header跟headers，只会使用header中内容

返回值

返回值类型为tuple，长度为5.

code---http状态码，类型为int

head---http响应头，类型为string

body---http响应体，类型为string

redirect---遇到 HTTP 302 后的跳转地址，如果无跳转则为请求的地址,类型为string

log---http日志信息，类型为dict，其中key为url，request，response。
