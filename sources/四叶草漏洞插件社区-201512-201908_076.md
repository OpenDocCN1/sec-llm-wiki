## hackhttp

首先先了解下POC中经常要使用的第三方库hackhttp。

**hackhttp 是四叶草安全旗下 BugscanTeam 打造的一款 Python 语言的 HTTP 第三方库**。

我们致力于帮助安全测试人员快速编写代码，除了最基本的基础功能之外，hackhttp支持直接发送原始的HTTP报文，我们可以将浏览器或者burp等抓包工具中截取的HTTP报文复制后，无需修改，可使用hackhttp进行重放。
