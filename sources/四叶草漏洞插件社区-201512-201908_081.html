>>>  线程  <<<


简单来说，进程是程序的一次执行，拥有自己的地址空间，内存，数据栈等。而所有线程运行同一个进程中，共享相同运行环境。


详细区别请参考线程与进程的区别(点击链接可查看相关文章):

https://baike.baidu.com/item/%E7%BA%BF%E7%A8%8B/103101?fr=aladdin


python 提供了多个模块支持多线程编程，包括thread，threading和Queue等。



丨为什么使用线程?


对比两个例子，看两个伪代码不使用线程的情况:


不使用线程的情况:


def loop1():
    sleep(4)
def loop2():
    sleep(2)

def main()：
    print 'start at:',ctime()
    loop1()
    loop2()
    print 'end at:',ctime()

#start at: Wed Jul 11 11:32:06 2018
#end at: Wed Jul 11 11:32:12 2018



使用线程的情况：


丨向右滑动查看全部代码丨

def loop(nloop, nsec):
    sleep(nsec)

def main():
    loops = [4,2]
    print 'start at:',ctime()#开始时间
    threads=[]
    nloops=range(len(loops))
    for i in nloops:
        t=threading.Thread(target=loop,args=(i, loops[i]))#实例化Thread类
        threads.append(t)

    for i in nloops:
        threads[i].start()#开始执行该线程
    for i in nloops:
        threads[i].join()#主线程等待所有线程执行完毕。除非指定timeout

    print 'end at:',ctime()

#start at: Wed Jul 11 11:35:43 2018
#end at: Wed Jul 11 11:35:47 2018


通过结果对比可以看到，同样的功能，使用线程之后，脚本运行时间提高了2秒，有没有感觉到一丝丝厉害呢？




>>>  threading模块  <<<


threading模块支持守护线程，如果把一个线程设置为守护线程，就表示这个线程是不重要的。进程退出的时候，不用等待这个线程执行完成。


如果主线程准备退出时，不需要等待某些子线程完成，就可以为这些子线程设置为守护标记。


threading模块的Thread类是主要的执行对象，包括很多属性跟方法。


丨属性和方法


import threading

help(threading)

 class Thread(_Verbose)

     |  __init__(self, group=None, target=None, name=None, args=(), kwargs=None, verbose=None)


target:供run方法调用的回调对象。默认为None。


name:线程名。


args:是传递给target调用的元组，默认为()。


    getName(self)#返回线程名

    isAlive(self)#表示这个线程是否存活

    isDaemon(self)#如果是守护线程，返回True;否则，返回False

    join(self, timeout=None)#直至启动线程终止之前一直挂起；除非给了timeout。否则一直阻塞。

    run(self)#定义线程功能的方法，(通常在子类中被应用开发者重写)

    setDaemon(self, daemonic)#把线程的守护标志设定为布尔值

    setName(self, name)#设定线程名

    start(self)#开始执行该线程


就如同上边例子一样。我们创建线程的方法是先创建一个Thread实例，然后传给它一个函数。


t=threading.Thread(target=loop,args=(i, loops[i]))


当线程开始执行时，loop函数也会开始执行。当所有线程分配完成，调用每个线程的start方法让他们开始执行。调用join方法，等待线程结束。

队列是线程之间常用的交换数据的形式。

Queue(maxsize)创建一个队列。

put(item)将item放入队列。

get():从队列中取元素。

full():如果队列已满，则返回True。

empty():如果队列为空，则返回True。

qsize():返回队列的大小。

task_done():向任务完成的队列发送信号。



>>>  多线程扫描脚本(二)  <<<


#!/usr/bin/env python
# -*- coding: utf-8 -*-

import socket
import optparse

from socket import *
from threading import *

screenLock = Semaphore(1)     # 信号量


# 输出主机名 抓取应用的Banner
def connScan(tgtHost, tgtPort):
    try:
        connSkt = socket(AF_INET, SOCK_STREAM)
        connSkt.connect((tgtHost, tgtPort))
        #connSkt.send('ViolentPython\r\n')
        connSkt.send('Python\r\n')
        results = connSkt.recv(100)
        screenLock.acquire()
        print "------------"
        print '[+] %d/tcp open' % tgtPort
        print '[+] ' + str(results)
        print "------------"
    except:
        print '[-] %d/tcp closed' % tgtPort
        screenLock.acquire()
    finally:
        screenLock.release()
        connSkt.close()


# 接收主机名和目标端口列表
def portScan(tgtHost, tgtPorts):
    try:
        tgtIP = gethostbyname(tgtHost)      # 确定主机名对应的IP地址
    except:
        print "[-] Cannot resolve '%s': Unknown host" % tgtHost
        return
    try:
        tgtName = gethostbyaddr(tgtHost)
        print '\n[+] Scan Results for: ' + tgtName[0]
    except:
        print '\n[+] Scan Results for: ' + tgtIP
    setdefaulttimeout(1)

    for tgtPort in tgtPorts:
        t = Thread(target=connScan, args=(tgtHost, int(tgtPort)))
        t.start()


def main():

    parser = optparse.OptionParser(
        'usage %prog ' + '-H <target host> -p <target port>')

    parser.add_option(
        '-H', dest='tgtHost', type='string', help='specify target host')
    parser.add_option(
        '-p', dest='tgtPort', type='string',
        help='specify target port[s] separated by comma')

    (options, args) = parser.parse_args()
    tgtHost = options.tgtHost
    tgtPorts = str(options.tgtPort).split(',')

    if (tgtHost is None) | (tgtPorts[0] is None):
        print '[-] You must specify a target host and port[s].'
        exit(0)

    portScan(tgtHost, tgtPorts)


if __name__ == '__main__':
    main()
