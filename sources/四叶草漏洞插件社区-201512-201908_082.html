多线程端口扫描器(一)

Python安全爱好者专题

简介

有时候，我们在渗透测试或者安全研究的过程中，需要执行一些有目的的端口扫描。那么本期我们来撸一个内网中端口扫描的脚本(见文章末尾)。

socket

socket 通常称为"套接字"，用于描述ip地址和端口，应用程序通常通过套接字向网络

发出请求或者应答网络请求。

socket 使用

创建TCP/IP socket套接字

In [2]: import socket #导入socket模块

In [3]:  TCP_sock=socket.socket(socket.AF_INET, socket.SOCK_STREAM) #创建socket套接字

socket.AF_INET参数表示IPv4协议。

socket.SOCK_STREAM参数表示面向流的TCP协议。

这样我们就初始化了一个使用IPv4，TCP协议的socket。

有了套接字之后，可以使用套接字对象的方法。

客户端套接字方法

TCP客户端举例:

 def client_socket():

    ...:     client=socket.socket(socket.AF_INET,socket.SOCK_STREAM)# 建立socket套接字

    ...:     client.connect(("127.0.0.1",80))#连接服务端

    ...:     client.send("hello world")#发送数据

    ...:     client.close()#关闭套接字

connect(): 发起TCP服务器连接。若报错，返回socket.errror错误。

connect_ex():同上。区别连接成功返回0，失败返回编码。例如:10061。

send(): 发送数据。

close():关闭套接字。

服务器套接字方法

TCP服务器举例:

def server_socket():

   ...:     TCP_sock=socket.socket(socket.AF_INET, socket.SOCK_STREAM)#建立TCP套接字

   ...:     TCP_sock.bind(("127.0.0.1",80))#将socket绑定到地址

   ...:     TCP_sock.listen(5)#监听循环，指定最多允许5个客户连接到服务器

   ...:     while True:

   ...:         ss,addr=TCP_sock.accept()#接受客户端连接。有客户端请求时，返回一个包含新的socket对象以及客户端的地址。

   ...:         print 'connected from:',addr

   ...:         data=ss.recv(1024)#从客户端接受信息

   ...:         print data

   ...:     TCP_sock.close()

bind(): 套接字与地址绑定,已元组形式传入(ip,port)。

listen():监听循环，指定最多允许多少客户连接到服务器。

accept():接受客户端连接。有客户端请求时，返回一个包含新的socket对象以及客户端的地址。

recv():接受客户端的请求。返回值是收到数据的字节对象。

一个简单的多线程端口扫描例子

#!/usr/bin/env python
# -*- coding: utf-8 -*-

import socket
import threading
import sys

lock = threading.Lock() #Lock对象

openNum = 0

threads = []

def socketPort(ip,port):

    '''传入ip/port 进行端口扫描'''

    try:

        global openNum

        server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)#创建套接字

        result = server.connect_ex((ip,port))

        lock.acquire()

        if result == 0:

            openNum+=1

            print('Scan %s Port %d: OPEN'%(ip,port))

        lock.release()

        server.close()

    except:

        pass


def threadScan(ip,port_list):

    for p in port_list:

        ''''调用Thread对象的start方法，线程启动后将执行socketPort函数'''

        t=threading.Thread(target=socketPort,args=(ip,p))

        threads.append(t)

        t.start()#启动线程

    for t in threads:

        t.join()

    print('[+++] scan is complete!')

    print('[+++] A total of %d open port ' % (openNum))

if __name__=='__main__':

    ip=sys.argv[1]

    port_list = [21, 22, 23, 25, 80, 135, 137, 139, 445, 1433, 3306, 3389, 8000]#定义端口列表

    print '[+++] Scanning the target is:',ip 

    threadScan(ip,port_list)
