ARP毒化实战

python安全爱好者专题

简介

本专题希望从Python安全爱好者的角度出发，利用Python来完成或者辅助完成安全领域的一些操作。

以干货为主，拒绝吹水。

简单的ARP毒化例子

使用Python中的scapy库ARP模块

from scapy.all import *    # 导入scapy库
p = ARP()                  # 新建ARP请求
p.psrc = '192.168.137.1'   # 发送端IP地址
p.pdst = '192.168.137.7'   # 目标IP地址
send(p)                    # 发送封包数据
# Sent 1 packets.

想要搞Python的攻防还是打牢基础，脚踏实地带你入门Python Hacking

变量赋值

Python 中的变量赋值不需要类型声明。

就像这样，

rank = 10    # 赋值整型变量

这样，

money = 100.00    # 浮点型

这样，

community = 'BugScan'    # 字符串

或者这样，

true_boolean = True    # 布尔型

条件

使用 if 进行条件判断，这点和其他编程语言一样。

score = 3
if score == 0:
    print 'out'
elif score == 1:
    print 'dogfall'
else:
    print 'rise'
# rise

循环

循环主要有两种：while 和 for 。

while循环

count = 0
while count < 5:
    print count
    count += 1
# 0
# 1
# 2
# 3
# 4

for 循环

import os    # 导入 os 库

# 遍历当前文件夹中的 python 文件
for dirpath, dirnames, filenames in os.walk(os.getcwd()):
    py_files = [f for f in filenames if f.endswith((".py"))]    # 遍历 .py 结尾的文件
    for py_file in py_files:
        fullpath = os.path.join(dirpath, py_file)
        print fullpath    # 输出绝对路径

列表

序列是Python中最基本的数据结构。

创建列表：

world_cup = [2018, 7, 3, 'Switzerland', 'Sverige']
print world_cup
# [2018, 7, 3, 'Switzerland', 'Sverige']

添加元素：

world_cup.append('Belgium')    # 使用 append() 添加元素
print world_cup
# [2018, 7, 3, 'Switzerland', 'Sverige', 'Belgium']

删除元素:

del world_cup[3]    # del 删除第三个元素，从0开始计数
print world_cup
# [2018, 7, 3, 'Sverige', 'Belgium']

元组

Python的元组与列表类似，不同之处在于元组的元素不能修改。

元组使用小括号，列表使用方括号。

创建元组：

world_cup = (2018, 7, 4, 'Columbia', 'England')
print world_cup
# (2018, 7, 4, 'Columbia', 'England')

访问元组中的元素：

print world_cup[3]    # 访问元组第4个元素，从0开始计数
# Columbia

元组中不允许修改元素值，但可以对元组进行拼接

world_cup2 = (2018, 7, 6, 'Uruguay', 'France')
world_cup3 = world_cup + world_cup2
print world_cup3
# (2018, 7, 4, 'Columbia', 'England', 2018, 7, 6, 'Uruguay', 'France')

字典

字典是另一种可变容器模型，且可存储任意类型对象。

Dictionary 是 key-value 对的集合，创建一个字典：

schedule = {
    'date': '2018.7.3 22:00',
    'country': 'Switzerland VS Sverige'
}

访问字典中的元素：

print schedule['date']
# 2018.7.3 22:00

增加元素：

schedule['winner'] = '???'
print schedule['winner']
# ???

修改字典中的元素：

schedule['date'] = '2018.7.3 23:00'
print schedule['date']
# 2018.7.3 23:00

删除字典中的元素：

del schedule['date']
print schedule
# {'country': 'Switzerland VS Sverige', 'winner': '???'}

集合

set和dict类似，也是一组key的集合，但不存储value。由于key不能重复，所以，在set中，没有重复的key。

创建set：

s = set(['Switzerland', 'Sverige', 'Columbia', 'England'])
print s
# {'Columbia', 'England', 'Sverige', 'Switzerland'}

添加元素：

s.add('China')
print s
# {'China', 'Columbia', 'England', 'Sverige', 'Switzerland'}

删除元素：

s.remove('China')
print s
# {'Columbia', 'England', 'Sverige', 'Switzerland'}
