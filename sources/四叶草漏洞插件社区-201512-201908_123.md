# 闰秒调整，2017年1月1日中国将有7时59分60秒

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MTE0MjYxOQ==&mid=2649296514&idx=1&sn=d60faa18bf22afb0f8eac6aead4b088e&chksm=f10db0b6c67a39a053cf6f72aace04197090bc4cee2b01ddb7350b586b181bbd64e20ded9f9e&scene=126&sessionid=1681310949#rd](http://mp.weixin.qq.com/s?__biz=MzI0MTE0MjYxOQ==&mid=2649296514&idx=1&sn=d60faa18bf22afb0f8eac6aead4b088e&chksm=f10db0b6c67a39a053cf6f72aace04197090bc4cee2b01ddb7350b586b181bbd64e20ded9f9e&scene=126&sessionid=1681310949#rd)

2016年7月6日，巴黎国际地球自转服务组织IERS发布闰秒公告：

国际标准时间UTC（Coordinated Universal Time,协调世界时）将在2017年1月1日实施一个正闰秒，即增加1秒。也就是说由于时差的原因，中国将于北京时间2017年1月1日7时59分59秒和全球同步进行闰秒调整，增加1秒，到时候将会出现7:59:60这一奇妙的现象。

本次闰秒的调整时间为：

国际标准时间：  

2016年12月31日，23时59分59秒

2016年12月31日，23时59分60秒

2017年1月1日，0时0分0秒

北京时间：

2017年1月1日，7时59分59秒

2017年1月1日，7时59分60秒

2017年1月1日，8时0分0秒

从1972年1月1日0时起，UTC秒长采用原子时秒长；时刻与世界时UT1时刻之差保持在±0.9秒之内，必要时用阶跃1整秒的方式来调整。这个1整秒，称为闰秒。

据悉，IERS这次重申这一决定，主要是希望引起科技行业和IT领域的注意。在2012年的闰秒调整中很多公司都发生了数据丢失事件，但这些问题在发生之前本可以避免，由于未作出相应措施而丢失了大量的用户数据这是严重的失职。希望大家这次可以未雨绸缪，有效的将风险规避掉。^ \_ ^
