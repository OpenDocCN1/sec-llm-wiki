回顾一年前：

—————————————

2015年2月，四叶草安全团队正式发布了业界首个基于插件的在线分布式扫描框架—BugScan。

历经4次重构的BugScan拥有杰出的框架设计，以插件众筹的模式快速成长，它让安全检测变的轻量化和及时化，让安全服务从传统模式飞跃到互联网上。

BugScan从不鼓励tools hacker，它的出现是为了更快更准的发现安全隐患，使得更多的安全难题得到解决。

注重插件淡化扫描是BugScan的宗旨，从未改变过。

如果有一个社区，可以让安全爱好者去研究交流漏洞，还可以调用BugScan的框架，会不会更加美好？

于是2015年4月，国内第一个漏洞插件社区诞生了，它的名字叫圈子，圈子让越来越多的安全爱好者相互成长。

——————————————

如今：2016年5月7日

——————————————

努力过的日日夜夜，从坚持念想到不放弃，使得我们心怀感恩。

BugScan承诺过对个人免费，但拒绝tools hacker，只为发烧友而生。

为了提高社区的能力和保持初衷，做出如下改进：

**1、正式更名四叶草漏洞插件社区为BugScan社区，简称BugScan。**

**2、BugScan社区免费开放，小伙伴们可通过第三方登录到BugScan社区。**

**3、论坛中有各种好玩的板块及帖子，可通过论坛大家互相交流、成长。**

**4、商城中会上更多好玩的商品供小伙伴们兑换。**

**5、每天登录的小伙伴都会有1积分送出。**

**6、插件贡献者提交插件来获取Rank/积分，Rank/积分可兑换扫描次数。（见规则）**

> **1、扫描平台\[新\]由于数据还在跟圈子对接，也将马上上线。框架与功能都有很大改进敬请期待**
> 
> **2.DNSlog是一款监控 DNS 解析记录和 HTTP 访问记录的工具，在检测盲注类漏洞时有着非常重要的作用，是分布式漏洞扫描框架 BugScan 中核心库之一。DNSLog 基于 Django 框架编写，将 DNSServer 集成进 DNSLog 中，使用者可轻松搭建使用环境。源代码在这里https://github.com/BugScanTeam/DNSLog**
> 
> **3.hackhttp 是四叶草安全旗下 BugscanTeam 打造的一款 Python 语言的 HTTP 第三方库。是分布式漏洞扫描框架 BugScan 中核心库之一。**
> 
> **hackhttp 致力于帮助安全测试人员快速编写代码，除众多基础功能外，hackhttp 支持直接发送 HTTP 原始报文，开发者可以直接将浏览器或者 Burp Suite 等抓包工具中截获的 HTTP 报文复制后，无需修改报文，可直接使用 hackhttp 进行重放。**
> 
> **hackhttp 使用连接池技术，在应对大量请求时自动对连接进行复用，节省建立连接时间与服务器资源，这种天生的特性，在编写爬虫时尤为显著，测试用例中提供了一个爬取乌云所有漏洞的爬虫。**
> 
> **源代码地址：https://github.com/BugScanTeam/hackhttp**
