# 2018年APCERT年会在沪召开

由国家互联网应急中心（CNCERT）主办的2018年APCERT年会于10月21日至24日在上海成功举办。来自全球30个国家和地区的50多个组织的150余名代表参加了本次会议，中央网信办、工业和信息化部、上海网信办、CNCERT上海分中心领导参会并致辞。CNCERT再次当选APCERT指导委员会委员。

本次APCERT年会主题为“加强信息共享，开展有效协作的应急响应”，分为工作组会议、技术培训、指导委员会会议、闭门会议、全体成员大会、开放会议暨第三届CNCERT国际合作论坛。在为期4天的会议中，APCERT的27个组织成员（APCERT共30个成员）出席了会议，对APCERT政策、运行、成员规则和工作组进展等问题进行了交流研讨。会议选举了APCERT指导委员会委员，CNCERT第4次成功竞选连任指导委员会委员，并继续担任信息共享组召集人。另外在开放会议暨第三届CNCERT国际合作论坛中，APCERT成员、应邀嘉宾和中外政府和企业的代表对最新网络安全态势、蜜网项目、运用人工智能开展威胁检测与防御、物联网安全标准化、漏洞、应急响应等话题发表了演讲。

作为APCERT成立以来的第17次年度盛会，本次会议有效促进了网络安全信息共享，进一步推动了APCERT愿景的实现，通过全球协作构建一个安全、清洁、可信的亚太网络空间。
