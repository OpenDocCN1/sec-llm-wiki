# 2018中国网络安全年会新闻发布会在京举行

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwNDk0MDgxMw==&mid=2247485688&idx=1&sn=1802a7222cc5e238cb557986419c7789&chksm=97393b9aa04eb28c51a303861f242f91d7e3eb3422f2e9faf4305e8f17c2f7a0fc6e4331010f&scene=126&sessionid=1681370971#rd](http://mp.weixin.qq.com/s?__biz=MzIwNDk0MDgxMw==&mid=2247485688&idx=1&sn=1802a7222cc5e238cb557986419c7789&chksm=97393b9aa04eb28c51a303861f242f91d7e3eb3422f2e9faf4305e8f17c2f7a0fc6e4331010f&scene=126&sessionid=1681370971#rd)

2018年8月9日，由国家互联网应急中心（以下简称CNCERT/CC）主办的“2018中国网络安全年会新闻发布会”在北京举行。

CNCERT/CC自2004年以来连续14年举办中国网络安全年会，旨在交流国内外网络安全工作新趋势、新问题、新思路，促进国家公共互联网网络安全应急体系成员间的合作，加强互联网行业的网络安全保障和突发安全事件的应急处置联动，促进政府部门、重要信息系统单位与网络安全产业界间的交流，普及宣传网络安全及网络安全应急工作知识，提升社会网络安全意识。

本届大会将于2018年8月14日至8月16日在北京国家会议中心召开，以“荟聚安全大脑、护航智能生态”为主题，设置全体大会、8个特色分论坛和技术培训活动，围绕着应急响应、态势感知、网络攻击与溯源、威胁情报、物联网、人工智能、安全漏洞、数据安全等一系列热点领域展开讨论与交流，并邀请相关部委领导、工程院院士、国内外网络安全产业界的知名人士分享观点、交流思想，为各路大咖带来一场顶级网络安全头脑盛宴。

会议期间，还将举办2018中国网络安全技术对抗赛、中国互联网网络安全威胁治理联盟专业工作组竞选会和2018年网络安全创新产品（技术）评选活动。

CNCERT/CC将联合百度、阿里巴巴、腾讯、360等四家国内知名企业共同举办2018中国网络安全技术对抗赛，围绕网络安全分析引擎、关键基础设施、移动设备、无线路由、车联网、物联网（IoT）产品、工业互联网等领域开展网络安全引擎比赛、夺旗赛和破解赛。

中国互联网网络安全威胁治理联盟将于8月16日召开专业工作组竞选会，选举“威胁情报共享工作组”和“DDoS攻击治理工作组”两个专业工作组的组长和副组长单位，并现场举行两个专业工作组的成立仪式。该专业领域协作机制通过公开民主的开放模式广泛联合成员单位等行业力量，依托CNCERT/CC开放资源，提高安全行业的整体技术能力。

2018年网络安全创新产品（技术）评选活动是CNCERT/CC首次针对网络安全产品（技术）举行的公开评选，旨在凝聚近年来我国网络安全行业优秀的创新产品和创新技术成果，促进我国网络安全行业的自主创新和行业发展，评选胜出的创新产品（技术）成果将获得CNCERT/CC颁发的证书。

目前，该会议已成为国内网络安全“用、产、学、研”各界技术和业务交流的重要桥梁和纽带，对于推动我国网络安全、提高社会网络安全意识起到了积极作用。
