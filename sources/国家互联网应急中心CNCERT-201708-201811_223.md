# 网络安全信息与动态周报2018年第16期（4月16日—4月22日）

本周网络安全基本态势  

本周，互联网网络安全态势整体评价为良。我国互联网基础设施运行整体平稳，全国范围或省级行政区域内未发生造成重大影响的基础设施运行安全事件。针对政府、企业以及广大互联网用户的主要安全威胁来自于软件高危漏洞、恶意代码传播以及网站攻击。

![](../Images/9afd5ae48bb37cbc8cea9740592027da.png)

本周网络病毒活动情况  

本周，境内被木马或僵尸程序控制的主机数量约为19.8万。

放马站点是网络病毒传播的源头。本周，CNCERT监测发现的放马站点共涉及域名546个，涉及IP地址2743个。在546个域名中，有27.8%为境外注册，且顶级域为.com的约占40.5%；在2743个IP中，有约43.8%位于境外。根据对放马URL的分析发现，大部分放马站点是通过域名访问，而通过IP直接访问的涉及44个IP。

本周网站安全情况  

本周CNCERT监测发现境内被篡改网站数量为1266个；境内被植入后门的网站数量为1294个；针对境内网站的仿冒页面数量为842个。

![](../Images/12a09f8a9b97ff509ddfe1f0ff4f0aab.png)

*图3 本周境内网站感染情况*

本周境内被篡改政府网站（GOV类）数量为33个（约占境内2.6%），较上周环比下降了2.9%；境内被植入后门的政府网站（GOV类）数量为36个（约占境内2.8%），较上周环比上升了28.6%；针对境内网站的仿冒页面涉及域名366个，IP地址153个，平均每个IP地址承载了约6个仿冒页面。

本周重要漏洞情况  

本周，国家信息安全漏洞共享平台（CNVD）新收录网络安全漏洞248个，信息安全漏洞威胁整体评价级别为高。

![](../Images/d3a03250d9e258b05bd1a1eaec8d1605.png)

*图6 本周收录网络安全漏洞情况*  

本周CNVD发布的网络安全漏洞中，应用程序漏洞占比最高，其次是操作系统漏洞和WEB应用漏洞。

![](../Images/d5f9eabb2077edb7dad86c8f2a178a4e.png)

*图7 本周CNVD收录漏洞按影响对象类型分布*  

更多漏洞有关的详细情况，请见CNVD漏洞周报。CNVD漏洞周报发布地址：http://www.cnvd.org.cn/webinfo/list?type=4

本周事件处理情况  

本周，CNCERT协调基础电信运营企业、域名注册服务机构、手机应用商店、各省分中心以及国际合作组织共处理了网络安全事件1070起，其中跨境网络安全事件403起。  

![](../Images/7bc5c042a6d7ecfe37012ceb1ae6f50a.png)

*图8 本周网络安全事件处理情况*

![](../Images/c9cc8b4ce5371e4ebb5abd44e0b0a8e3.png)

*图9 本周CNCERT处理的事件数量按类型分布*

本周，CNCERT协调境内外域名注册机构、境外CERT等机构重点处理了1007起网页仿冒投诉事件。根据仿冒对象涉及行业划分，主要包含银行仿冒事件982起和政府公益仿冒事件15起。
