# 国家信息安全漏洞共享平台（CNVD）2019年工作会议在京召开

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwNDk0MDgxMw==&mid=2247489273&idx=2&sn=696f5eb46bee0083be31e059152df544&chksm=9739259ba04eac8d940396b65194f33308bf8893a2786d55c780996bc2f0e023c50bbffc573f&scene=126&sessionid=1681370855#rd](http://mp.weixin.qq.com/s?__biz=MzIwNDk0MDgxMw==&mid=2247489273&idx=2&sn=696f5eb46bee0083be31e059152df544&chksm=9739259ba04eac8d940396b65194f33308bf8893a2786d55c780996bc2f0e023c50bbffc573f&scene=126&sessionid=1681370855#rd)

12月30日，国家信息安全漏洞共享平台（CNVD）2019年度工作会议在京召开。会议由国家互联网应急中心（CNCERT）主办，CNCERT党委副书记卢卫出席会议并致辞。来自CNVD平台的26家技术组和27家用户组单位，以及来自29家特邀企事业单位的专家和代表参加会议。会议还特别邀请了对CNVD漏洞提交有突出贡献的8位白帽子。

![](../Images/3ea5eef2400509b65243d81326b3d3db.png)

会议总结了CNVD平台2019年的工作情况，介绍了《CNVD平台管理办法》的制定情况，对35家CNVD优秀成员单位和行业单位，以及10名优秀白帽子进行了表彰（名单附后）。会议还邀请了腾讯玄武实验室、爱加密研究院、腾讯刀锋团队、恒安嘉新、国网思极检测和360诺亚实验室的专家从软件空间测绘、APP合规监管、基带漏洞挖掘、应急响应分析、行业安全建设等角度分享了技术报告。  
卢卫副书记指出，CNVD平台经过十年努力建立了安全漏洞的统一收集验证、信息发布和应急处置体系，在党政机关和重要行业单位威胁预警、网络安全保障以及大规模漏洞攻击威胁应急方面发挥了重要作用，但漏洞消控工作仍然任重而道远，各CNVD支撑单位要深入学习贯彻习总书记的总体国家安全观，继续做好网络安全漏洞信息的共享、处置和防护工作，为维护国家网络安全，保护广大信息系统用户切身利益，作出新的贡献。
