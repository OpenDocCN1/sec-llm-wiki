# 2019（第十六届）中国网络安全年会将于7月17日-18日在广州举行

2019年7月17日至18日，**“2019年第十六届中国网络安全年会”**将于广东省广州市举办。  

本届年会将在国家互联网信息办公室指导下开展，由国家互联网应急中心（简称CNCERT/CC）主办，深信服科技股份有限公司、奇安信集团、天融信科技集团、恒安嘉新（北京）科技股份公司、阿里云计算有限公司、北京启明星辰信息安全技术有限公司、360集团联合主办（排名不分先后）。

会议旨在深入贯彻落实习近平总书记关于网络强国的重要思想，加强全国网络安全应急体系建设，促进政府部门、重要信息系统单位与网络安全产业界间的交流，聚焦国内外网络安全工作新趋势、新问题、新思路,同时普及宣传网络安全及网络安全应急工作知识，提升社会网络安全意识。

本届年会以**“**智能感知态势•携手构建安全**”**为主题，开设开幕论坛、全体会议及7个分论坛，同期还将举办网络安全技术对抗赛。会议将邀请来自政府部门、重要信息系统单位、基础电信企业、域名服务从业机构、互联网企业、网络安全机构和企业、科研院所等业界同仁参加会议，共同探讨网络安全技术、应急处置和信息共享等问题。

自2004年以来，CNCERT已连续15年举办中国网络安全年会。会议已成为国内网络安全“产、学、研、用”各界交流技术和业务的重要桥梁和纽带，对于推动我国网络安全工作、提高社会网络安全意识起到了积极作用。

会议日程及参会方式等信息将陆续公布，扫描二维码关注国家互联网应急中心CNCERT公众号了解“中国网络安全年会”最新动态。点击阅读原文链接访问中国网络安全年会官方网站，了解详细信息。
