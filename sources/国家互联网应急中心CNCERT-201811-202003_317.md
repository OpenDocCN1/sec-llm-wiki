# 每周移动恶意程序传播渠道安全监测报告 （2019年04月15日—04月21日）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwNDk0MDgxMw==&mid=2247487642&idx=1&sn=76e1c4788530d5109b9db50c6c21b30f&chksm=973923f8a04eaaee86003bfd93f74b9c06fe68b32636b739da6a59f016e0bfd49baae71ccecf&scene=126&sessionid=1681370905#rd](http://mp.weixin.qq.com/s?__biz=MzIwNDk0MDgxMw==&mid=2247487642&idx=1&sn=76e1c4788530d5109b9db50c6c21b30f&chksm=973923f8a04eaaee86003bfd93f74b9c06fe68b32636b739da6a59f016e0bfd49baae71ccecf&scene=126&sessionid=1681370905#rd)

自2014年起，国家互联网应急中心（以下简称“CNCERT”）形成了基于全国31个分中心联动的移动互联网恶意程序传播渠道监测体系，对各地已备案的应用商店、广告平台、云平台等各类移动互联网应用程序传播渠道流通的移动应用程序进行网络安全监测，提升已备案移动应用程序传播渠道的安全性。

2019年4月15日至4月21日期间，通过自主监测、商店送检、主动爬取、投诉举报等四大方式共检测为恶意的APP有80个，分别通知14个分中心协调26个应用商店、11个广告平台、9个个人网站、3个云平台等49个传播渠道下架APP总数有80个，具体情况请见后文表格1到表格14的内容。

  

  

2017年ANVA建立了移动APP预置与分发渠道安全监测平台（https://appstore.anva.org.cn），面向手机制造企业、应用商店、网盘、广告平台等APP预置与分发渠道提供APP安全监测服务，并根据属地化管理要求，通过CNCERT各分中心对应用商店中出现的恶意程序进行通知下架处理。

目前本平台接入应用商店的省份总数14个，已备案的应用商店的总数137个，其中排名前三的省份是福建省、上海市、湖北省，分别有32个、26个、19个应用商店，全国分布情况如图所示：
