**一、境外厂商产品漏洞**

**1、****hessian二进制web服务协议java版本存在命令执行漏洞**

Hessian是一个跨平台的序列化工具。hessian二进制web服务协议java版本存在命令执行漏洞，攻击者可利用该漏洞获取服务器控制权。参考链接：https://www.cnvd.org.cn/flaw/show/CNVD-2020-58400**2、Netis系列路由器存在未授权访问漏洞**WF2419、WF2780、WF2412、WF2409E、WF2411是Netis Systems的路由器产品。Netis系列路由器存在未授权访问漏洞，攻击者可利用该漏洞获取敏感信息。参考链接：https://www.cnvd.org.cn/flaw/show/CNVD-2020-58399

# **3、RouterOS smb服务存在拒绝服务漏洞**

MikroTik RouterOS是拉脱维亚MikroTik公司的一套基于Linux开发的路由器操作系统。该系统可部署在PC中，使其提供路由器功能。RouterOS smb服务存在拒绝服务漏洞，攻击者可以利用该漏洞构造smb恶意连接请求，造成内存耗尽攻击，可导致系统重启。参考链接：https://www.cnvd.org.cn/flaw/show/CNVD-2020-58401

# **4、SAP NetWeaver AS ABAP授权问题漏洞**

SAP Netweaver是德国思爱普（SAP）公司的一套面向服务的集成化应用平台。该平台主要为SAP应用程序提供开发和运行环境。SAP NetWeaver AS ABAP (WebDynpro)存在安全漏洞，允许远程攻击者利用漏洞提交特殊的请求，可未授权访问Web Dynpro组件，允许读取和删除数据库日志文件。参考链接：https://www.cnvd.org.cn/flaw/show/CNVD-2020-65553

# **5、spring-webmvc基于hessian的远程服务调用存在命令执行漏洞**

spring-webmvc是一款java开发框架。spring-webmvc基于hessian的远程服务调用存在命令执行漏洞，攻击者可利用该漏洞获取服务器控制权。参考链接：https://www.cnvd.org.cn/flaw/show/CNVD-2020-58404 **二、境内厂商产品漏洞****1****、广东天宸网络科技有限公司互传存在命令执行漏洞（CNVD-2020-59421）**互传（PC端）用于手机和电脑之间进行资料备份、恢复，电脑投屏，游戏按键映射，以及文件传输的一款软件。广东天宸网络科技有限公司互传存在命令执行漏洞，攻击者可利用该漏洞在卸载的过程中可执行包含任意代码的可执行程序。参考链接：https://www.cnvd.org.cn/flaw/show/CNVD-2020-59421

# **2、****武汉良师在线教育科技有限公司良师网校系统存在SQL注入漏洞**

武汉良师在线教育科技有限公司总部位于九省通衢的武汉市，由光谷计算机学校教育信息技术中心改制成立的高新技术企业。武汉良师在线教育科技有限公司良师网校系统存在SQL注入漏洞，攻击者可利用该漏洞获取数据库敏感信息。参考链接：https://www.cnvd.org.cn/flaw/show/CNVD-2020-59426

# **3、中国移动通信有限公司和飞信存在代码执行漏洞**

和飞信是中国移动推出的面向团队通信沟通升级服务及面向企业移动办公的应用软件。中国移动通信有限公司和飞信存在代码执行漏洞，攻击者可利用该漏洞执行包含任意代码的可执行程序。参考链接：https://www.cnvd.org.cn/flaw/show/CNVD-2020-59435

# **4、ZZCMS存在任意文件读取漏洞**

ZZCMS是一款站长招商网内容管理系统。ZZCMS存在任意文件读取漏洞，攻击者可利用该漏洞遍历网站文件获取敏感信息。参考链接：https://www.cnvd.org.cn/flaw/show/CNVD-2020-59425

# **5、深圳市迅雷网文化有限公司光影看图存在二进制漏洞（CNVD-2020-59418）**

光影看图为一款面向摄影人群和设计师人群的看图软件。深圳市迅雷网文化有限公司光影看图存在二进制漏洞，攻击者可利用该漏洞通过该poc可导致该软件崩溃，造成拒绝服务。参考链接：https://www.cnvd.org.cn/flaw/show/CNVD-2020-59418 说明：关注度分析由CNVD秘书处根据互联网用户对CNVD漏洞信息查阅情况以及产品应用广泛情况综合评定。
