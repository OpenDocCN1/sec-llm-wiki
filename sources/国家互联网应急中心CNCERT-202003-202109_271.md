# 上周关注度较高的产品安全漏洞(20201116-20201122)

**一、境外厂商产品漏洞**

**1、Drupal远程代码执行漏洞（CNVD-2020-64563）**

Drupal是Drupal社区的一套使用PHP语言开发的开源内容管理系统。Drupal存在远程代码执行漏洞。该漏洞是由于Drupal core未能正确地处理上传文件中的某些文件名，攻击者可利用漏洞通过上传恶意文件，在某些特定的配置下可能会被当作php解析，从而导致远程代码执行。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2020-64563

**2、Mozilla Firefox MCallGetProperty代码问题漏洞**

Mozilla Firefox是美国Mozilla基金会的一款开源Web浏览器。Mozilla Firefox存在安全漏洞，攻击者可利用该漏洞通过Firefox的MCallGetProperty强制使用释放的内存区域，以触发拒绝服务，并可能运行代码。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2020-64301

**3、Cellinx NVT Web Server访问控制错误漏洞**

Cellinx NVT Web Server是韩国Cellinx公司的一个应用于虚拟终端管理（NVT）的Web平台。该平台主要用于管理视频监控设备，平台分为监控页面和设置页面对终端进行控制。Cellinx NVT Web Server 5.0.0.014b.test 2019-09-05版本存在访问控制错误漏洞，该漏洞源于身份验证是在客户端进行，远程攻击者可利用该漏洞通过SetFileContent.cgi以root身份运行命令。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2020-64306

**4、Linux kernel perf\_event\_parse\_addr\_filter()代码问题漏洞**

Linux kernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。Linux kernel存在安全漏洞，攻击者可利用该漏洞可以通过perf\_event\_parse\_addr\_filter()来创建内存泄漏，从而触发拒绝服务。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2020-64300

**5、SprecherAutomation Sprecher SPRECON-E命令注入漏洞**

SprecherAutomation Sprecher SPRECON-E是奥地利SprecherAutomation公司的一套提供包括运行咨询、规划、开发，工程和设备现场安装、调试和操作员培训的服务包应用程序。Sprecher SPRECON-E firmware 8.64b之前版本存在安全漏洞，该漏洞源于缺少设备端输入值的验证。攻击者可利用该漏洞插入任意代码。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2020-64939

  

**二、境内厂商产品漏洞**

**1、Moxa MXView installation文件权限系统授权问题漏洞**

Moxa MXView是中国台湾摩莎（Moxa）公司的一款专用于管理网络的软件。该软件可用于对网络内的所有设备进行配置处理等操作。Moxa MXView installation 3.1.8版本中的文件权限系统存在授权问题漏洞，该漏洞可导致攻击者以系统特权去执行执行任意命令。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2020-63631

**2、盾灵原创文章投稿系统1.0前台存在SQL注入漏洞**

盾灵原创文章投稿系统1.0是一个简洁的投稿系统。盾灵原创文章投稿系统1.0前台存在SQL注入漏洞，攻击者可利用该漏洞获取数据库敏感信息。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2020-58384

**3、zzcms框架存在文件上传漏洞**

zzcms(站长招商网内容管理系统)，由zzcms团队开发，融入数据库优化，内容缓存，AJAX等技术，使网站的安全性 、稳定性 、负载能力得到可靠保障。源码开放，功能模块独立，便于二次开发。zzcms框架存在文件上传漏洞，攻击者可利用该漏洞获取服务器管理权限。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2020-58388

**4、首岳资讯建站系统存在SQL注入漏洞**

首岳資訊網路股份有限公司(Atteipo Internet Information Co., Ltd.)，是一家結合資訊網路、行銷通路、系統軟體等各項專長人才的公司。首岳资讯建站系统存在SQL注入漏洞，攻击者可利用该漏洞获取数据库敏感信息。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2020-58389

**5、通达OA11.2存在文件包含漏洞**

北京通达信科科技有限公司隶属于中国兵器工业信息中心，简称通达信科。通达OA11.2存在文件包含漏洞，攻击者可利用该漏洞获取服务器管理权限。

参考链接：

https://www.cnvd.org.cn/flaw/show/CNVD-2020-58386
