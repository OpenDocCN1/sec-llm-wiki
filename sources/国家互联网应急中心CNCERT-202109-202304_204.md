# Oracle发布2022年7月的安全公告

安全公告编号:CNTA-2022-0018  

2022年7月19日，Oracle发布了2022年7月份的安全更新，修复了其多款产品存在的349个安全漏洞。受影响的产品包括：Oracle Database Server数据库（9个）、Oracle Big Data Graph（3个）、Oracle Essbase（1个）、Oracle Global Lifecycle Management（1个）、Oracle GoldenGate（4个）、Oracle Graph Server and Client（1个）、Oracle REST Data Services（2个）、Oracle Spatial Studio（1个）、Oracle TimesTen In-Memory Database（1个）、Oracle Commerce（12个）、Oracle Communications Applications（17个）、Oracle Communications（56个）、Oracle Construction and Engineering（7个）、电子商务套装软件Oracle E-Business Suite（6个）、Oracle Enterprise Manager（6个）、Oracle Financial Services Applications（59个）、Oracle Food and Beverage Applications（3个）、中间件产品Oracle Fusion Middleware（38个）、Oracle Health Sciences Applications（6个）、Oracle HealthCare Applications（3个）、Oracle Hospitality Applications（2个）、Oracle Java SE（5个）、Oracle JD Edwards（6个）、Oracle MySQL数据库（34个）、Oracle PeopleSoft（11个）、Oracle Policy Automation（3个）、Oracle Retail Applications（17个）、Oracle Siebel托管型CRM软件（1个）、Oracle Supply Chain（24个）、Oracle Systems（7个）、Oracle Utilities Applications（1个）和Oracle Virtualization（2个）。  

本次安全更新提供了针对205个高危漏洞的补丁，有314个漏洞可被远程利用。CNVD提醒广大Oracle用户，请及时下载补丁更新，避免引发漏洞相关的安全事件。
