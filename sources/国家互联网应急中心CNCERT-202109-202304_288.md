# 国家互联网应急中心(CNCERT/CC)勒索软件动态周报-2022年第7期（总第15期）(20220212-20220218)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwNDk0MDgxMw==&mid=2247496385&idx=3&sn=23f48f6a5c92c01af2da32aa6042f8e5&chksm=973ac1a3a04d48b5fbdeca6114c27125b327eb4862ab135556025b66ebd95e8ac1efbce9ab02&scene=126&sessionid=1681370673#rd](http://mp.weixin.qq.com/s?__biz=MzIwNDk0MDgxMw==&mid=2247496385&idx=3&sn=23f48f6a5c92c01af2da32aa6042f8e5&chksm=973ac1a3a04d48b5fbdeca6114c27125b327eb4862ab135556025b66ebd95e8ac1efbce9ab02&scene=126&sessionid=1681370673#rd)

国家互联网应急中心（CNCERT/CC）联合国内头部安全企业成立“中国互联网网络安全威胁治理联盟勒索软件防范应对专业工作组”，从勒索软件信息通报、情报共享、日常防范、应急响应等方面开展勒索软件防范应对工作，并定期发布勒索软件动态，本周动态信息如下：

**一**

**勒索软件样本捕获情况**

本周勒索软件防范应对工作组共收集捕获勒索软件样本1480927个，监测发现勒索软件网络传播2194次，勒索软件下载IP地址522个，其中，位于境内的勒索软件下载地址201个，占比38.5%，位于境外的勒索软件下载地址321个，占比61.5%。

**二**

**勒索软件受害者情况**

**（一）Wannacry勒索软件感染情况**

本周，监测发现3804起我国单位设施感染Wannacry勒索软件事件，较上周上升15.6%，累计感染95634次，较上周上升407.4%。与其它勒索软件家族相比，Wannacry仍然依靠“永恒之蓝”漏洞（MS17-010）占据勒索软件感染量榜首，尽管Wannacry勒索软件在联网环境下无法触发加密，但其感染数据反映了当前仍存在大量主机没有针对常见高危漏洞进行合理加固的现象。

![](../Images/197efe8456f37b16b3b7add121faa938.png)

教育科研、电信、政府部门、卫生健康、互联网行业成为Wannacry勒索软件主要攻击目标，从另一方面反映，这些行业中存在较多未修复“永恒之蓝”漏洞的设备。  

![](../Images/de1eed0bc795ec48dacbd2d4c16ed54d.png)

**（二）其它勒索软件感染情况**  

本周勒索软件防范应对工作组自主监测、接收投诉或应急响应22起非Wannacry勒索软件感染事件，事件数与上周相同，排在前三名的勒索软件家族分别为Phobos（36.4%）、Hive（13.6%）和GlobeImposter（9.1%）。

![](../Images/4550f22fbae067878c466aadefd7c50a.png)

本周，被勒索软件感染的系统中Windows 7系统占比较高，占到总量的31.8%，其次为Windows Server 2008系统和Windows 10系统，占比分别为18.2%和4.5%，除此之外还包括多个其它不同版本的Windows服务器系统和其它类型的操作系统。  

![](../Images/4594e7590adee5ec07c2bc1442698b54.png)

本周，勒索软件入侵方式中，远程桌面弱口令和漏洞利用占比较高，分别为50%和9%。Phobos勒索软件利用弱口令漏洞特别是远程桌面弱口令频繁攻击我国用户，对我国企业和个人带来较大安全威胁。  
![](../Images/96882f47b69d55540089d0cfcde91dd2.png)

**三**

**典型勒索软件攻击事件**

**（一）国内部分**

**1、Coffee勒索软件新型变种感染国内多所高校和科研机构**

本周，工作组成员自主监测并响应了多起Coffee勒索软件新型变种感染国内高校和科研机构事件。攻击者通过钓鱼邮件、社交软件或捆绑软件等方式传播勒索软件并对受害者主机上的文件进行加密，将文件后缀修改为.coffee，随后向受害者索要一种不常见的ZEC数字货币作为赎金。此事件中，攻击者通过钓鱼邮件或社交软件等传播勒索软件，建议用户加强网络安全意识，不下载、不接收来源不明的文件，及时安装软件安全补丁修复漏洞，对重要的数据定期备份。

**（二）国外部分**

**1、BlackByte勒索软件团伙攻击美国关键基础设施**

近日，美国联邦调查局（FBI）披露，在过去三个月中，BlackByte勒索软件团伙至少入侵了三个美国关键基础设施 (政府设施、金融、食品和农业)实体。BlackByte是一个自2021年7月以来十分活跃的勒索软件即服务（RaaS）组织，该团伙利用软件安全漏洞获得对其目标网络的初始访问权限，进而植入勒索软件。在2月份的最近一次攻击活动中，BlackByte团伙声称攻击了美国旧金山橄榄球队49ers的信息系统，并泄露了近300MB的数据文件。
