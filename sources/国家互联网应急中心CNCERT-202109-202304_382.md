# 国家互联网应急中心(CNCERT/CC)勒索软件动态周报-2021年第8期(20211225-20211231)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwNDk0MDgxMw==&mid=2247495897&idx=3&sn=c7083e63b1c1f07690f6b6cfc3e38e96&chksm=973ac3bba04d4aad3ab800c39501837b74d6644f77fe1819bed5c8ff14d07a4dc8f1e036afc7&scene=126&sessionid=1681370698#rd](http://mp.weixin.qq.com/s?__biz=MzIwNDk0MDgxMw==&mid=2247495897&idx=3&sn=c7083e63b1c1f07690f6b6cfc3e38e96&chksm=973ac3bba04d4aad3ab800c39501837b74d6644f77fe1819bed5c8ff14d07a4dc8f1e036afc7&scene=126&sessionid=1681370698#rd)

国家互联网应急中心（CNCERT/CC）联合国内头部安全企业成立“中国互联网网络安全威胁治理联盟勒索软件防范应对专业工作组”，从勒索软件信息通报、情报共享、日常防范、应急响应等方面开展勒索软件防范应对工作，并定期发布勒索软件动态，本周动态信息如下：

**一**

**勒索软件样本捕获情况**

本周勒索软件防范应对工作组共收集捕获勒索软件样本785490个，监测发现勒索软件网络传播100次，勒索软件下载IP地址5个，其中，位于境内的勒索软件下载地址2个，占比40%，位于境外的勒索软件下载地址3个，占比60%。

**二**

**勒索软件受害者情况**

**（一）Wannacry勒索软件感染情况**

本周，监测发现5145起我国单位设施感染Wannacry勒索软件事件，较上周下降5%，累计感染76132次，较上周下降17.2%。与其它勒索软件家族相比，Wannacry仍然依靠“永恒之蓝”漏洞（MS17-010）占据勒索软件感染量榜首，尽管Wannacry勒索软件在联网环境下无法触发加密，但其感染数据反映了当前仍存在大量主机没有针对常见高危漏洞进行合理加固的现象。

![](../Images/9b4403cce5d6137a40195c6568e226d1.png)

政府部门、教育科研、互联网、卫生健康、电信行业成为Wannacry勒索软件主要攻击目标，从另一方面反映，这些行业中存在较多未修复“永恒之蓝”漏洞的设备。  

![](../Images/a34ac4029aad2ba855c7f202e602ac0a.png)

**（二）其它勒索软件感染情况**  

本周勒索软件防范应对工作组自主监测、接收投诉或应急响应42起非Wannacry勒索软件感染事件，较上周上升16.7%，排在前三名的勒索软件家族分别为Magniber（21.4%）、TellYouThePass（14.3%）和Phobos（11.9%）。

![](../Images/7a959bd3fa9a4df8c8d5bb796ba0c7d6.png)

本周，被勒索软件感染的系统中Windows7系统占比较高，占到总量的40.5%，其次为Windows10系统，占比为11.9%，多个版本的Windows 服务器系统包括Server 2012和Server 2008分别占4.8%和2.4%，除此之外还包括多个其它不同版本的Windows系统和其它类型的操作系统。  

![](../Images/eded3b3e76048a26c0f57b91798e3905.png)

本周，勒索软件入侵方式中，漏洞利用排在第一位，其次为远程桌面弱口令和挂马网站。Magniber勒索软件利用漏洞利用和挂马网站频繁攻击我国用户，对我国企业和个人带来较大安全威胁。  
![](../Images/b540ad556ad6182c69cb79443a631c53.png)

**三**

**典型勒索软件攻击事件**

**（一）国内部分**

**1、NAS设备制造商威联通（QNAP）遭受eCh0raix勒索软件攻击**网络附加存储（NAS）设备制造商威联通（QNAP）用户在圣诞节期间遭遇eCh0raix勒索软件（也称为 QNAPCrypt）攻击。据悉，大规模的勒索软件攻击始于圣诞节前一周，并于12月26日左右结束。本次事件中，eCh0raix勒索软件的传播途径被认为可能是由于用户的安全意识薄弱而将NAS设备接入了不安全的网络链接，此外， QNAP Photo Station 中的一个安全漏洞也可能加速勒索软件的传播。

QNAPCrypt勒索软件在加密文件前从命令和控制服务器（C＆C）请求钱包地址和公共RSA密钥，并为每个攻击目标分配一个唯一的比特币钱包。建议用户遵循QNAP的安全加固建议，以保护其NAS设备及其存储的数据安全。
