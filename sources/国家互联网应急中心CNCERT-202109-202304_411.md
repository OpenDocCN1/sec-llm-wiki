# 国家互联网应急中心(CNCERT/CC)勒索软件动态周报-2021年第6期(20211211-20211217)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwNDk0MDgxMw==&mid=2247495730&idx=3&sn=97a43cc64b0e0c45e3fbaa7f26acbcaa&chksm=973ac350a04d4a46c4656b9a29fe3cd474a9dc95bc10cfb23d840b681633d834454be1026781&scene=126&sessionid=1681370703#rd](http://mp.weixin.qq.com/s?__biz=MzIwNDk0MDgxMw==&mid=2247495730&idx=3&sn=97a43cc64b0e0c45e3fbaa7f26acbcaa&chksm=973ac350a04d4a46c4656b9a29fe3cd474a9dc95bc10cfb23d840b681633d834454be1026781&scene=126&sessionid=1681370703#rd)

国家互联网应急中心（CNCERT/CC）联合国内头部安全企业成立“中国互联网网络安全威胁治理联盟勒索软件防范应对专业工作组”，从勒索软件信息通报、情报共享、日常防范、应急响应等方面开展勒索软件防范应对工作，并定期发布勒索软件动态，本周动态信息如下：

**一**

**勒索软件样本捕获情况**

本周勒索软件防范应对工作组共收集捕获勒索软件样本434755个，监测发现勒索软件网络传播2699次，勒索软件下载IP地址33个，其中，位于境内的勒索软件下载地址18个，占比54.5%，位于境外的勒索软件下载地址15个，占比45.5%。

**二**

**勒索软件受害者情况**

**（一）Wannacry勒索软件感染情况**

本周，监测发现4085起我国单位设施感染Wannacry勒索软件事件，较上周下降17.9%，累计感染103499次，较上周下降18.4%。与其它勒索软件家族相比，Wannacry仍然依靠“永恒之蓝”漏洞（MS17-010）占据勒索软件感染量榜首，尽管Wannacry勒索软件在联网环境下无法触发加密，但其感染数据反映了当前仍存在大量主机没有针对常见高危漏洞进行合理加固的现象。

![](../Images/6e340ce11076519ee420e0cf8e4cc103.png)

政府部门、教育科研、电信、互联网、工业制造行业成为Wannacry勒索软件主要攻击目标，从另一方面反映，这些行业中存在较多未修复“永恒之蓝”漏洞的设备。  

![](../Images/c1cc527eebf9243b28e83ada5d9fdb65.png)

**（二）其它勒索软件感染情况**  

本周勒索软件防范应对工作组自主监测、接收投诉或应急响应355起非Wannacry勒索软件感染事件，较上周上升1443.5%，排在前三名的勒索软件家族分别为GandCrab（52.4%）、PolyRansom（7.9%）和Locky（6.5%）。

![](../Images/96ece9a8025171aa8c3ea24c927f71dd.png)

本周，被勒索软件感染的系统中Windows7系统占比较高，占到总量的93.2%，其次为Windows Server 2012和Windows Server 2008系统，占比分别为0.8%和0.6%，除此之外还包括多个其它不同版本的Windows服务器系统和其它类型的操作系统。  

![](../Images/4bb1e488174228b3346d9758792e3185.png)

本周，勒索软件入侵方式中，漏洞利用排在第一位，其次为挂马网站和远程桌面弱口令。Tellyouthepass勒索软件利用最近爆出的Apache Log4j漏洞攻击我国多个行业用户，对我国企事业单位带来较大安全威胁。  
![](../Images/6cfb4b2bcf6f0769404953d46feedf2c.png)

**三**

**典型勒索软件攻击事件**

**（一）国内部分**

**1、多起利用最新Log4j漏洞感染Tellyouthepass勒索软件**本周，工作组成员单位自主监测结果显示，多起投递Tellyouthepass勒索软件的攻击者使用Apache Log4j漏洞对网络上暴露的某品牌OA产品发起勒索攻击，近300台部署了存在上述漏洞的OA服务器遭到攻击。

此事件中，攻击者利用存在最新Apache Log4j漏洞（CVE-2021-44228）的某OA产品发起勒索攻击，首先获得服务器的控制权，再植入Tellyouthepass勒索软件。建议用户尽快修复CVE-2021-44228漏洞。

**2、山西某医院多台服务器感染LockBit勒索软件**

近日，工作组成员单位应急响应了山西某医院HIS系统、PACS系统等服务器感染LockBit勒索软件事件。攻击者通过软件捆绑勒索软件的方式传递攻击载荷，医院用户在其中一台服务器上下载并激活了LockBit勒索软件，随后LockBit勒索进行横向移动，扫描并持续感染本地网络中存在漏洞的其他主机。

LockBit勒索病毒目前尚没有公开的解密工具，感染后造成目标主机的服务中断和数据破坏。建议用户加强信息安全意识宣贯，定期检测系统漏洞并及时修复。

**（二）国外部分**

**1、美国弗吉尼亚州IT机构遭受勒索软件攻击**

弗吉尼亚州官员周一表示，为弗吉尼亚州立法机构提供服务的信息技术机构遭到勒索软件攻击，严重影响了其运营。州长发言人证实了这起对弗吉尼亚州立法自动化系统部门的攻击事件。在提供给美联社的一份简短声明中显示，州长已听取了有关此事的简报并指示行政部门提供帮助，以“评估和应对这种持续的情况”。立法自动化系统司(DLAS)是议会的IT下属机构。此次袭击发生的时机尤为敏感，因为议员和工作人员正在为定于1月开始的立法会议做深入准备。此次攻击也标志着过去一年爆发的勒索病毒大规模事件迎来了的最新一波针对政府、关键基础设施和大公司的攻击。
