**一、境外厂商产品漏洞**

****1、Veritas Enterprise Vault代码执行漏洞（CNVD-2021-95586）****

Veritas Enterprise Vault是美国Veritas公司的一款企业级文件保护、归档自动化软件。Veritas Enterprise Vault14.1.2及之前版本中存在安全漏洞，Enterprise Vault 应用程序启动时会启动多个服务，这些服务在随机 .NET Remoting TCP 端口上侦听来自客户端应用程序的命令。由于 .NET Remoting 服务固有的反序列化行为，攻击者可以利用Enterprise Vault服务器上的TCP远程服务和本地IPC服务。

参考链接：  

https://www.cnvd.org.cn/flaw/show/CNVD-2021-95586  

****2、Eltima USB Network Gate整数溢出漏洞****

Eltima Usb Network Gate是阿拉伯联合酋长国的一款软件。用于通过Internet或Lan 进行远程Usb访问。Eltima USB Network Gate存在安全漏洞，本地攻击者可利用该漏洞在内核模式下执行任意代码或通过特别精心设计的IO请求包导致拒绝服务（内存损坏和OS崩溃）。

参考链接：  

https://www.cnvd.org.cn/flaw/show/CNVD-2021-95607

****3、DELL Dell EMC iDRAC9跨站脚本漏洞（CNVD-2021-94891）****

DELL Dell EMC iDRAC9是美国戴尔（DELL）公司的一套包含硬件和软件的系统管理解决方案。该方案为Dell PowerEdge系统提供远程管理、崩溃系统恢复和电源控制等功能。Dell EMC iDRAC9在4.40.40.00之前版本中存在跨站脚本漏洞，该漏洞源于产品未能过滤输入数据的特殊字符，攻击者可通过该漏洞导致客户端代码执行。

参考链接：  

https://www.cnvd.org.cn/flaw/show/CNVD-2021-94891

****4、Apache Log4j2存在远程代码执行漏洞****

Apache Log4j是一个基于Java的日志记录组件。Apache Log4j2是Log4j的升级版本，通过重写Log4j引入了丰富的功能特性。该日志组件被广泛应用于业务系统开发，用以记录程序输入输出日志信息。Apache Log4j2存在远程代码执行漏洞，攻击者可利用该漏洞向目标服务器发送精心构造的恶意数据，触发Log4j2组件解析缺陷，实现目标服务器的任意代码执行，获得目标服务器权限。

参考链接：  

https://www.cnvd.org.cn/flaw/show/CNVD-2021-95919

****5、Adobe Acrobat/Reader栈缓冲区溢出漏洞（CNVD-2021-94917）****

Adobe Reader(也被称为Acrobat Reader)是Adobe公司开发的一款PDF文件阅读软件。Adobe Acrobat是由Adobe公司开发的一款PDF编辑软件。Adobe Acrobat/Reader存在栈缓冲区溢出漏洞。攻击者可利用该漏洞执行任意代码。

参考链接：  

https://www.cnvd.org.cn/flaw/show/CNVD-2021-94917
