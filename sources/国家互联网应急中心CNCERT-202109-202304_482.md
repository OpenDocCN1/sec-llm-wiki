# 国家网安宣传周个人信息保护分论坛！等你来！

为贯彻落实习近平总书记关于“要坚持网络安全为人民、网络安全靠人民，保障个人信息安全，维护公民在网络空间的合法权益”的重要指示要求，推动《个人信息保护法》全面落地实施，2021年国家网络安全宣传周“个人信息保护日”将举办主题为“加强个人信息保护 维护公民合法权益”的个人信息保护分论坛。本次论坛将于10月17日上午在陕西省西安市西安高新国际会议中心举办，论坛由中央网信办网络数据管理局主办，陕西省委网信办、西安市委网信办、国家计算机网络应急技术处理协调中心、中国网络空间安全协会联合承办。  

届时，中央网信办、公安部、市场监管总局等有关主管部门领导将出席论坛，并发表主题演讲。同时个人信息保护法律专家和教育、金融、铁路、通信等行业专家将开展以“践行法律理念，加强个人信息保护”为主题的圆桌对话。敬请关注。
