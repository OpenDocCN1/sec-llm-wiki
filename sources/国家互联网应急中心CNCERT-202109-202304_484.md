# 网络安全众测平台国产计算机外设及信创产品安全竞赛在武汉举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwNDk0MDgxMw==&mid=2247494731&idx=2&sn=0779cc23072bc66bfe9799d9a2be3e49&chksm=973adf29a04d563fc0d7f8bbcf6f6ea75910061816c86d452daf435e06f4375af45b045e0f30&scene=126&sessionid=1681370718#rd](http://mp.weixin.qq.com/s?__biz=MzIwNDk0MDgxMw==&mid=2247494731&idx=2&sn=0779cc23072bc66bfe9799d9a2be3e49&chksm=973adf29a04d563fc0d7f8bbcf6f6ea75910061816c86d452daf435e06f4375af45b045e0f30&scene=126&sessionid=1681370718#rd)

近日，由国家计算机网络应急技术处理协调中心主办的网络安全众测平台国产计算机外设及信创产品安全竞赛活动在武汉市国家网络安全人才与创新基地培训中心举办。

此次竞赛活动，得到了中国电子工业标准化技术协会信息技术应用创新工作委员会的大力支持，旨在挖掘国产计算机外设及信创产品高价值漏洞，有效提升产品安全能力。众测竞赛为期两周，共有9家打印机外设和3家信创企业的20台设备参与众测项目。

网络安全众测平台是在中央网信办指导下，由国家计算机网络应急技术处理协调中心和武汉市人民政府发挥双方优势，充分利用国家信息安全漏洞共享平台（CNVD）资源优势，依托武汉国家网络安全人才与创新基地共同建设。CNVD平台是2009年成立的国家漏洞库，目前已成为国内收录漏洞数量最多的共享平台，截至2021年8月，CNVD平台共收录针对软硬件产品漏洞13.8万余个，针对具体信息系统漏洞59.7万余个，平台注册的测试人员共2.5万余人。

网络安全众测平台将开展大规模网络安全和信创产品的网络安全众测工作，并形成原创漏洞、测试流量等数据资源，有效提升网络安全产品安全性能，带动网络安全产业发展。同时，网络安全众测平台有助于加强网络安全人才的实训培养，促进形成人才培养、技术创新、产业发展的良性生态。

自今年7月以来，网络安全众测平台已为18个网络安全产品和信创产品进行众测，组织200余名专业测试人员，发现并帮助相关企业修复大量安全漏洞。
