# 国家工业控制系统与产品安全质量监督检验中心西南实验室招聘人才

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDA4NjgwMw==&mid=2247485710&idx=1&sn=8ab4af674ef8d95104ed4031ddedf526&chksm=e9626872de15e16425aa8b24e9cc94da2dcc81ff37c3e03c3a94a572e8dd0c9d06d9190386aa&scene=126&sessionid=1681668524#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDA4NjgwMw==&mid=2247485710&idx=1&sn=8ab4af674ef8d95104ed4031ddedf526&chksm=e9626872de15e16425aa8b24e9cc94da2dcc81ff37c3e03c3a94a572e8dd0c9d06d9190386aa&scene=126&sessionid=1681668524#rd)

国家工信安全发展研究中心将“国家工业控制系统与产品安全质量监督检验中心西南分中心”的牌子授予四川哨兵信息科技有限公司。  
我司面向西南地区各级科研究所、各类工业控制、工业自动化、工业互联网及公共安全相关公司，提供工业信息安全产品检测、工业信息安全检查评估、重大工业项目信息安全审查、工业互联网仿真测试、工业信息安全实训演练等服务。

现为拓展实验室发展，特聘技术人才，现聘职位如下：

1、测试工程师

2、系统评估岗

3、实验室质量体系工程师
