# 聚焦 | 全国两化融合标委会工业互联网管理标准工作组（TC573/WG6）第一次全体成员大会召开

6月17日，全国两化融合标委会工业互联网管理标准工作组（TC573/WG6）第一次全体成员大会以线上线下相结合的方式在京顺利召开。工业和信息化部信息技术发展司二级巡视员王少朋，全国两化融合标委会秘书长、国家工业信息安全发展研究中心副主任何小龙及中国航空工业集团信息技术中心原首席顾问宁振波出席会议并讲话。来自TC573/WG6的50余家成员单位（第一批）参加了会议。会议由工作组秘书处单位国家工业信息安全发展研究中心主办,系统所所长陶炜主持会议。![](../Images/0290b9467e83997dc093376c7fee7e25.png)![](../Images/fad5821a9ca12feee03b0b7951fa7eba.png)王少朋指出，**工业互联网是制造业数字化转型的关键支撑,加快工业互联网应用推广对于实现经济高质量发展具有重要意义。**党中央、国务院高度重视工业互联网创新发展，工信部实施了一系列衔接有序的政策措施，推动工业互联网平台逐渐从概念走向落地并取得了积极成效。下一步，工作组要充分发挥桥梁纽带作用，联合产学研用等各方力量，加快关键领域标准研制和推广，构建标准引领产业发展的良好生态。![](../Images/c39596354887800fd5694e3640f7034e.png)全国两化融合标委会（TC573）秘书处代表、国家工信安全中心交流合作处处长李君正式宣布WG6工作组召集人及秘书长提名。全国两化融合标委会秘书长、中心副主任何小龙和中航工业集团信息技术中心原首席顾问宁振波担任工作组召集人，中心系统所研究部主任夏宜君、交流合作处标准三室主任周勇分别担任工作组秘书长和副秘书长。工作组召集人宁振波、何小龙分别作主题讲话。宁振波强调，**工业互联网是产业数字化转型的关键支撑，要正确认识我国工业互联网发展的模式特点，形成多层次、系统化的工业互联网标准体系。**何小龙指出，当前，中国工业互联网正处于从**单项赋能**向**综合赋能转变****、从试点应用进入规模化应用推广的阶段，标准化工作有助于统一产业共识、扫清合作障碍、实现规模化推广。**下一步，工作组要顺应产业发展规律，发挥成员单位优势，加强行业自律，有序推进标准编制、验证与推广。![](../Images/97a9ef3f272499b7f2ba176d4d3db745.png)标准工作组秘书长夏宜君介绍了WG6的组织结构、工作进展和22年重点方向。中国电子信息产业发展研究院、中国工业互联网研究院、中关村信息技术和实体经济融合发展联盟、用友网络科技股份有限公司、重庆忽米网络科技有限公司、卡奥斯工业智能研究院（青岛）有限公司、安世亚太科技股份有限公司、石化盈科信息技术有限责任公司、北京天泽智云科技有限公司等成员单位代表分别就工作组发展目标和重点任务进行了讨论和交流。中心系统所所长陶炜介绍了中心在工业互联网标准化领域的工作进展及成效，并分享了下一步推进工业互联网管理标准化工作的思路。![](../Images/d1bec0fdcb75df1397d8ff6f18e3f903.png)下午，工作组围绕《工业互联网平台 服务商评价方法》、《工业互联网平台 解决方案分类方法》两个已立项国家标准开展研讨交流，来自参编单位的87位专家结合产业实践提出宝贵意见。下一步，在工信部的指导与支持下，全国两化融合标委会工业互联网管理标准工作组（TC573/WG6）将不断完善工作机制，进一步调动**产学研用**各方积极性**，聚焦设备上云、平台+园区、共享制造等工业互联网管理相关热点领域**，共同推动国家标准、行业标准、团体标准研制和推广工作。在此，诚挚欢迎相关科研院所、高校、协会、企业等共同参与工业互联网管理标准化工作。原文来源：国家工业信息安全发展研究中心![](../Images/caf560257d8cdb968f18cedf35a13175.png)

**哨兵信息科技集团有限公司**  

哨兵信息科技集团有限公司（简称“哨兵科技”）成立于 2019 年 1 月，注册资本 6500 万元。2019年7月，**国家工业信息安全发展研究中心成立了国家工业控制系统与产品安全质量监督检验中心西南实验室**（简称“西南实验室”），**哨兵科技作为西南实验室落地实体企业**，开展西南地区工业信息安全业务，支撑政府主管部门提升网络安全监管能力，主要提供安全服务、安全产品、工控系统与产品安全检测三类服务。  
哨兵科技（西南实验室）是国家高新技术企业，以“提升防护能力捍卫工信安全”为己任，被评选为国家工业信息安全应急服务支撑单位、国家工业信息安全测试评估机构、国家CICSVD技术支持组成员单位，连续两届被评为成都市工业信息安全应急服务支撑单位。拥有CNAS、CMA、风险评估等多项资质，各类知识产权20余项，至今服务大型企业和各类企业几百余家。
