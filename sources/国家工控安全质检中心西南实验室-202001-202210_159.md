# 七人虚设投资平台诈骗均获刑 “杀猪盘”因黑客攻击提前崩盘

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDA4NjgwMw==&mid=2247492342&idx=1&sn=451503922ec4d917f9c30d8f71cbe394&chksm=e961838ade160a9c08dadae400f60a1862997ff80e9c323de79c0f3188f2c2c1a70b2f0e2e14&scene=126&sessionid=1681668383#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDA4NjgwMw==&mid=2247492342&idx=1&sn=451503922ec4d917f9c30d8f71cbe394&chksm=e961838ade160a9c08dadae400f60a1862997ff80e9c323de79c0f3188f2c2c1a70b2f0e2e14&scene=126&sessionid=1681668383#rd)

10月18日，湖南新化法院审理并当庭宣判的廖某辉等七人虚设投资平台诈骗案。据多名共同作案人及被告人的供述，该虚假投资网络平台被黑客攻击后无法运行，因此决定提前崩盘。

![](../Images/f48a065d70c7702305e4a8c988259230.png)

法院经审理查明，2020年11月，王某光、廖某辉、刘甲、刘乙、伍某波（均另案处理）商量筹资以虚假投资网络平台实施诈骗。王某光、廖某辉负责购买了手机、银行卡等作案工具，王某光联系被告人曾甲召集业务员，曾甲便纠集被告人李某强、刘某浩、伍某磊，李某强纠集被告人李某某、彭某宝参与诈骗。曾甲与陈某雄（另案处理）负责管理业务员，李某强为小组长。王某光等人租下新化县某镇某村某宾馆，团伙成员均聚集于此并在虚假平台正式上线前大量添加好友聊天，物色并确定作案目标。陈甲（另案处理）为技术员，负责平台管理等工作，2020年12月27日，“领技共享”投资平台正式上线，业务员便诱骗聊天对象到该虚假平台投资。自2020年12月27日至2021年1月5日，该团伙从被害人刘某南等人处骗取钱款共计361693.9元，其中刘某浩从刘丙处骗得127466元，李某强从刘丁处骗得64053.8元。2021年1月5日下午，王某光将廖某辉、曾甲等七人遣散，后将作案地点转移至娄底。

  

据共同作案人伍某波供述，该团伙诈骗的流程是：购买作案手机、微信、电话卡后，先养号，然后业务员在网上引流加目标受害人的微信，目标一般会选择那些之前受过骗的，让业务员冒充受害人，更快地获取受害人的信任。每个业务员拿1-2台作案手机，包装成成功人士等，和加的好友进行微信聊天，获取信任，等资金盘（虚假投资网络平台）弄好后，就喊他们到资金盘投资。一般介绍对方先投资一点钱，然后让对方得点利息，把钱取出来，让对方相信这个平台，等对方进行大额投资时，他们股东就商量，把平台关闭，让受害人提现不了，从而成功实施诈骗。概括一下就是：先通过热门网络平台引流，加微信取得信任后，诱骗被害人到虚假投资网络平台投资，以钓鱼的方式，先通过支付利息（投资收益）获取被害人信任，让被害人放下防备，放心大胆地多次追加“投资”，在达到一定数额后，关闭平台，卷款“失联”。据多名共同作案人及被告人的供述，该虚假投资网络平台被黑客攻击后无法运行，因此决定提前崩盘。

  

法院认为，被告人廖某辉、曾甲、李某强、刘某浩、李某某、彭某宝、伍某磊以非法占有为目的，虚构事实骗取他人财物，数额巨大，其行为均已构成诈骗罪。根据各被告人的犯罪事实、犯罪性质、情节、社会的危害程度以及在共同犯罪中的作用，新化法院以诈骗罪分别判处廖某辉等7名被告人八年至三年六个月不等有期徒刑，并处人民币十万元至二万元不等罚金，各被告人的违法所得，依法应当退赔给被害人。
