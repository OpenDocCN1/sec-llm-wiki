# 聚焦丨工信安全中心在2021中国500强企业高峰论坛上联合发布《2021中国企业数字转型指数研究》报告

9月24日至25日，以“新征程 新使命 新作为：全力推进大企业高质量发展”为主题的2021中国500强企业高峰论坛在长春举行。国家工信安全中心与埃森哲联合主办以“加速数字化转型 提升全球竞争力”为主题的2021中国企业数字转型指数报告发布平行论坛，共同发布《2021中国企业数字转型指数研究》报告。中心副主任何小龙出席论坛，并围绕新发展格局下的制造业数字化转型发表主旨演讲。

![](../Images/ea84a4d3b947d4ac56a6aa0a8afcff0b.png)

何小龙指出，新一代信息技术引领了新一轮科技革命和产业变革，推动了全球从工业经济向数字经济加速迈进。“十三五”期间，我国制造业数字化转型成效显著，转型基础不断夯实、工业互联网平台赋能水平大幅提升、新模式新业态加速涌现。原材料、装备、消费品等重点制造领域，因所处产业链位置、行业结构、生产特征、发展需求各有不同，数字化转型具有鲜明的差异化特征。展望“十四五”，推进我国制造业数字化转型，要创新发展制造业数字化转型的技术应用体系，持续拓展制造业数字化转型的广度和深度，繁荣制造业数字化转型的生态体系。
