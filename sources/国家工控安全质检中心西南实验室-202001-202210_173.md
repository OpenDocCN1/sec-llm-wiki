# 成都市网络信息安全产业影响力TOP30企业榜单出炉

![](../Images/8d05bde73d30c2cefea1ea15959e3ea7.png)![](../Images/77b2f38f61468544bce51680678b6d1d.png)9月18日，由工业和信息化部、财政部指导，工业和信息化部网络安全产业发展中心（信息中心）、成都市经济和信息化局、成都高新技术产业开发区管理委员会联合主办的**第六届“创客中国”网络安全中小企业创新创业大赛决赛**在成都顺利举行。  
为激发网络安全企业创新活力，鼓励优秀企业争先创优，促进我市网络信息安全产业高质量发展，在成都市经信局、市密码管理局、市科技局、市公安局等市级有关部门指导下，成都信息网络安全协会、成都市工业互联网发展中心联合开展了榜单评选活动，并在决赛现场发布了**成都市网络信息安全产业影响力榜单TOP30**。
