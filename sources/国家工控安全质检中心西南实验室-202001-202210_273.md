# 三次两院院士大会 习近平一直关注这些话题

　　近日，中国科学技术协会发布通知，中国科协第十次全国代表大会将于5月28日至30日在北京召开。作为我国科技界盛会，中国科协全国代表大会、两院院士大会历来备受国内外关注。

　　习近平总书记高度重视科技创新，始终将创新摆在国家发展全局的核心位置。党的十八大以来，他出席了中国科协第九次全国代表大会，三次出席两院院士大会并发表重要讲话，对推动世界科技强国建设作出重要部署。

　　“科技兴则民族兴，科技强则国家强。”总书记在两院院士大会上一以贯之关注哪些科技创新话题？本文特梳理总书记重要讲话要点，与您一起学习领会。
