# 聚焦丨中心与华为公司联合发布《数据安全白皮书》

![](../Images/76f30ee2ea0ed9feb00d0bbdd96d00bb.png)5月26日，2021中国国际大数据产业博览会(以下简称“数博会”)在贵州省贵阳市隆重开幕，中共中央政治局委员、国务院副总理刘鹤在北京现场视频出席大会开幕式并作重要讲话，中央财办副主任尹艳林、国务院副秘书长陆俊华、国家发展改革委副主任林念修、工业和信息化部副部长王江平一同视频参会。大会以“数智变·物致新”为主题，通过线上线下融合模式，重点讨论后疫情时代数据要素融合与创新发展。5月27日下午，中心与华为技术有限公司（以下简称“华为公司”）在数博会上联合举办了《数据安全白皮书》现场发布会。中心副主任郝志强出席会议，与华为公司数据存储与机器视觉产品线副总裁庞鑫、数据存储与机器视觉产品线战略规划部副总裁丁南森，中心产业促进所副所长于志成等共同发布了《数据安全白皮书》。

![](../Images/369f9ac605bbcb46deb2c15ca7834ea3.png)

《数据安全白皮书》是中心联合华为公司共同研究编制，是国内首部聚焦国家数据战略，基于数据安全存储研究的白皮书，具有较强的前瞻性、创新性和战略性。该白皮书全面梳理了全球新经济形态以及主要经济体的数据战略，剖析了数据安全在新产业生态中的需求与挑战，提出了数据安全总体策略及治理思路。在此基础上，深入分析了我国数据安全产业、技术、法律法规现状，从提升数据安全产业基础能力、加快研究和应用数据安全防护技术、强化法律法规在数据安全主权的支撑保障作用三方面，展望数据安全发展未来，提出数据安全发展建议，为行业发展提出借鉴和参考，助力产业数字化和数字产业化安全发展。

![](../Images/43dcd34c79d80f516d3d74aa6513b9d2.png)

郝志强指出，我国数字化建设前瞻布局且成效显著，安安全发展始终贯穿在我国数字化建设的全过程，数据安全已经上升到国家安全的战略高度。中心作为国家级信息安全研究和推进机构，多年来深耕数据安全领域研究，在支撑部委数据安全政策起草、加强数据安全防护能力建设、推进数据安全标准规范编制与试点应用、面向行业企业开展数据安全评估服务等方面开展了大量卓有成效的工作，有力地支撑了我国数据安全保障能力和体系建设。

![](../Images/f45a604465bf3584c16c40479b5f2644.png)

会议期间，郝志强与华为公司数据存储与机器视觉产品线、贵阳分公司等有关负责人围绕数据安全、信创安全等方面进行了深入交流，了解了华为公司近年来的数据安全成果。双方一致表示，将进一步在政策法规研究、标准研制、技术研讨等方面深化数据安全合作，共同为构建开放、健康、安全的数字生态贡献力量。
