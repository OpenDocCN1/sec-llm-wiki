# 聚焦 | 郝志强组织召开2021年一季度分管部门工作汇报会

为做好定期汇报，持续推进业务发展，按照工业信息安全板块工作计划要求，4月27日上午，中心副主任郝志强组织召开板块第一季度工作汇报会，听取各分管部门工作开展、各部委司局支撑以及重点突破业务工作情况汇报，并部署下一步工作。

![](../Images/4f84ff3e8161974bd2e1e9a0b491d13e.png)

会上，郝志强通报了中心第一季度各板块收入完成情况，对工业信息安全板块2021年度工作要点制定、顶层设计和总体谋划、跨部门协作机制建立、对外服务清单梳理等情况表示了肯定，板块现已一定程度上形成了工作合力，有条不紊地推进各项任务开展，初见成效。

各部门主要负责人分别从政府支撑、专项执行、基础研究、市场拓展等方面汇报了当下工作进展、存在的问题及下一步工作计划。各部委司局支撑牵头人分别汇报了对工信部、中央网信办、国防科工局等相关司局的支撑情况及计划。各重点突破业务部牵头同志分别汇报了车联网安全、信创安全、数据安全工作进展情况及计划安排。

![](../Images/99a8b32eb8d7c008748b14807c419376.png)

郝志强对上述工作开展情况表示了充分的认可和肯定，对板块下一阶段工作提出了三点要求：**一是锚定目标，积极做好政府支撑、拓展行业服务。**各部门要提高认识、达成共识，秉持“大网安”格局，站在整个安全板块、整个中心乃至国家的高度开展工作、加强服务，按照板块年度工作计划，推动落实中心改革发展规划，共同加强工信安全服务能力，共谋工信安全新发展格局。**二是分解任务，有序推进各项工作执行。**参考检查评估所制定的经济指标方案，各部门要进一步细化工作任务和经济指标，围绕主责主业和长期布局，建立“杀手锏”能力，树立品牌优势，务实推进各项工作任务实施。在加强政府支撑和做好市场服务的同时，要兼顾好质量和效益。**三是坚持安全与发展同步，党建和业务融合。**在秉持发展是第一要务的同时，做好安全风险防控工作。尤其是在项目执行和市场拓展中，要严格遵守中央八项规定精神，保持廉洁自律，严禁出现违规违法现象。没有脱离政治的业务，也没有脱离业务的政治，要杜绝“两张皮”现象，创新党建开展方式，在业务推进中同步抓好党建工作。此外，要求各部门抓紧人才队伍建设、加快项目执行，以及相关负责人员调整等工作。

检查评估所、监测应急所、保障技术所、产业促进所等部门负责同志和业务骨干参会。
