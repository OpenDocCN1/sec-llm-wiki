# 哨兵科技（西南实验室）创新平台入选成都新经济“双千”新场景新产品清单

**创新引擎 智启天府**

![](../Images/fceffaa5cee356ab3ff69d8535994a1c.png)

4月26日下午，2021成都新经济“双千”发布会提升产业功能区创新基础能力专场活动成功举行，400多个新场景新产品共同亮相，进一步释放新机遇。本次发布会以“创新引擎 智启天府”为主题，并在线上线下同步发布《成都市提升产业功能区创新基础能力新场景新产品清单》。**哨兵科技（西南实验室）“基于工控系统仿真与网络安全攻防验证的产品检测服务平台”入选新产品机遇清单**，助力创新平台建设，共架合作互通桥梁。

  

![](../Images/6925f0f6b7c82a3a290844c4b6b48042.png)

哨兵科技（西南实验室）“基于工控系统仿真与网络安全攻防验证的产品检测服务平台”主要针对实训、工业网络安全靶场、仿真与测试、红蓝对抗等系统进行研究，购置国、内外先进检验检测设备和组建专业技术团队，建设工业信息安全仿真与检测攻击实验室，为工业企业提供包含检测、评估、等保、咨询、培训等服务的整体咨询服务方案，现已与80多家单位签订了咨询服务和产品检测业务的合作协议。

  

![](../Images/cb3976c5cdde6489d6b53f8602a72ff2.png)

![](../Images/cf13a301b29a213a0421f24e7a929da2.png)

  

未来，哨兵科技（西南实验室）还将继续“加码”，在工业信息安全领域深耕，增强产业发展韧性，开展多种形式的合作交流，为进一步推动成都产业功能区高质量发展展现新作为。
