# 国家工业信息安全发展研究中心领导莅临西南实验室（哨兵科技）指导工作

4月22日，国家工业信息安全发展研究中心检查评估所所长张格莅临国家工控安全质检中心西南实验室（哨兵科技）就2021年业务开展工作进行深入指导。

  

张格代表国家工业信息安全发展研究中心对西南实验室（哨兵科技）2020年取得的成绩给予充分肯定。今年，是国家工业信息安全发展研究中心及西南实验室建设发展的关键期，张格结合中心的工作部署对西南实验室（哨兵科技）提出了明确要求：一是要统一思想、提高站位、深化认识；西南实验室（哨兵科技）作为国家工业信息安全发展研究中心在西南地区的下设机构，要紧扣中心的业务板块和服务能力，加强与中心在工信安全、信创安全、数据安全、车联网安全等领域的紧密联系。二是要紧密连接市场；借助十四五开局、大运会保障等机遇，为西南地区企事业单位提供更为优质、高效的信息安全服务。

  

西南实验室（哨兵科技）主任（总经理）林方涛在会议中表示，西南实验室（哨兵科技）今年将在国家工业信息安全发展研究中心的全面领导下，以市场为导向，在电力、能源、化工、交通、智能制造等重要领域实现重点突破，以优异的成绩献礼建党100周年。
