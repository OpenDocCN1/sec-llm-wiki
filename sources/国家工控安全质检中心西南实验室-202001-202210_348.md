# 表彰丨西南实验室（哨兵科技）喜获“工业信息安全产业发展联盟2020年度优秀成员单位”！

12月4日，由国家工业信息安全发展研究中心、工业信息安全产业发展联盟（以下简称“联盟”）主办的2020年中国工业信息安全大会暨全国工控安全深度行（京津冀站）在北京召开。政府部门、学术研究、行业企业等“全明星阵容”出席，纵论工信安全未来发展。国家工控安全质检中心（西南实验室）作为优秀联盟成员单位参与大会多个环节。大会聚焦工业信息安全发展现状和重点任务，邀请中央网信办、工业和信息化部、公安部、国防科工局领导、院士专家、行业领袖等围绕工业信息安全技术和标准研制，产业发展、工业控制系统安全和工业大数据安全等前瞻热点展开交流，共同探讨工业信息安全发展新路径，助力工业信息安全产业高质量发展。

  

“奖”先进：为行业发展提供智力支持

  

![](../Images/5ad2915b60cfc064c6206aef52e481d9.png)

  

为激励更多力量投入工业信息安全建设，大会还对一批热心参与联盟活动、积极投身工信事业、社会评价度高的成员单位进行表彰。国家工控安全质检中心西南实验室（哨兵科技）在国家工业信息安全发展研究中心的指导下，积极服务西南地区各类工控企业，同时积极承办“天府杯2020国际网络安全大赛”、“2020年工业信息安全技能大赛”等大型赛事、培训活动，因各项活动的高效开展，被评为“2020年度优秀联盟成员单位”荣誉称号！
