# 喜讯丨热烈祝贺国家工控安全质检中心西南实验室（哨兵科技）入围 2020年“优秀联盟成员单位”！

为表彰热心参与联盟活动、积极投身工信事业、社会评价度高的成员单位，11月30日10:00—12月3日00:00工业信息安全产业发展联盟（以下简称“联盟”）特开展了2020年“优秀联盟成员单位”评选活动。经过3天的投票评选，国家工控安全质检中心西南实验室（哨兵科技）、北京天融信网络安全技术有限公司、北京威努特技术有限公司等10家公司成功入围2020年“优秀联盟成员单位”。
