# 国家工控安全质检中心西南实验室（哨兵科技）与多家顶级安全单位齐聚成都·世界信息安全大会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDA4NjgwMw==&mid=2247488652&idx=2&sn=bc150432490ed5c3c9d81057498d2f91&chksm=e96275f0de15fce637b9baad14edc04ef0928602bcb7a26c3d7bbbb2fdc538e4fe471c097dda&scene=126&sessionid=1681668449#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDA4NjgwMw==&mid=2247488652&idx=2&sn=bc150432490ed5c3c9d81057498d2f91&chksm=e96275f0de15fce637b9baad14edc04ef0928602bcb7a26c3d7bbbb2fdc538e4fe471c097dda&scene=126&sessionid=1681668449#rd)

![](../Images/3307d2f0e18ceb74e75555381d8d9a9d.png "微信图片_20201127163943.jpg")

11月24-27日，2020年INSEC WORLD成都·世界信息安全大会在成都展开，大会由中外3大院士共同领衔，逾40家网安品牌同台，近60位海内外演讲嘉宾倾情奉献，突破2000位线下参会人士出席，开幕式及主论坛网上直播吸引了逾70万名全球观众。国家工控安全质检中心西南实验室（哨兵科技）受邀参展，并亮相特装展区。

![](../Images/fa3ba07e5703903213fee9fc053ca705.png)![](../Images/4122296cf0ecc194638cd09de51a6d79.png)![](../Images/4eef1ef3f126d0a1c75aed02f0b26700.png "多家企业.jpg")

在“新基建”全面启动的背景下，大会以“新基建——安全为本”为主题，探讨与新基建相关的智慧城市安全，5G安全、云与数据安全、物联网安全及工业互联网安全等话题，吸引来自金融、地产、零售、制造、医疗行业的信息安全“一把手”齐聚一堂、共话安全。

  

![](../Images/495c583b95e895a42647a72863cf3892.png)

 今年“新基建”词汇频频在政府会议和政策中亮相。为促进国家工业产业转型升级，带动工业信息安全创新发展，国家工控安全质检中心西南实验室（哨兵科技）在国家工业信息安全发展研究中心的指导下，借助成都·世界信息安全大会等平台，不断与安全行业内部充分碰撞、交流，深刻理解安全是发展的前提，发展是安全的保障，安全和发展要同步推进，实现高质量发展；为西南地区各工控安全企事业单位提供技术保障力量，协助提升其产品和系统的信息安全水平，建立工业互联网安全保障体系，为国家“2025智能制造”、“新基建”提供技术支撑。
