# 大会预告 | 两化融合暨工业互联网平台大会将在苏州举办

以“融合新业态 产业新生态 发展新格局”为主题，由工业和信息化部联合江苏省人民政府等部门共同主办的两化融合暨工业互联网平台大会，将于**10月21日-22日**在**江苏省苏州市**举行。大会承办单位为国家工业信息安全发展研究中心、江苏省工业和信息化厅、苏州市人民政府、产业互联网发展联盟、中电标协工业互联网平台生态工作委员会。

2020年是工业互联网发展三年行动计划的收官之年，也是开启国家“十四五”发展新征程的关键之年。大会将深入贯彻落实党的十九大关于“推动互联网、大数据、人工智能和实体经济深度融合”精神，高举深化新一代信息技术与制造业融合发展旗帜，明确新时期两化融合的新使命、新要求，聚焦产业链、价值链、金融链当前痛点难点问题，加速推进制造业转型升级和高质量发展。大会将汇聚业内相关部门领导、著名专家学者、工业互联网平台企业高管，以及行业组织、金融机构、科研院所及其他企事业单位代表等各方精英，搭建可持续发展的对话和交流平台，共同探讨发展大计。

本届大会高峰论坛部分，领导发言、嘉宾演讲等将以新一代信息技术与制造业融合为主线，解读当前重要政策，厘清发展脉络方向。工业互联网平台企业将与用户同台分享真实案例，剖析应用难点，共同探讨工业互联网平台应用的发展经验及成效。大会七大分论坛将分别聚焦工业信息安全、工业区块链、工业大数据、工业云、新模式制造、信息技术应用创新等方面，直击当前制造业数字化转型发展的关键问题。同时，大会还将举办数字化转型暨两化融合管理体系贯标2.0推进会、中国工业互联网产融合作座谈会暨投融资对接会、工业互联网产教融合生态专题会、5G应用及产业供需对接会等专题会，针对性地满足行业当前迫切需求，务实解决实际问题。大会成果展览展示筹备工作已初步完成,工业互联网、十大双跨平台、重点行业平台以及防疫复工复产解决方案企业等，将携近年来在工业互联网领域取得的成果和典型案例等参展。

大会同期举办的工业互联网解决方案现场会、“工业互联网看苏州”外场活动、平台双创大赛等特色专项活动，将为企业与用户、园区搭建沟通交流平台，构建产业新生态。大会还将在重点地区设立多个分会场，同步开展线上线下培训活动，展示和检验工业互联网平台应用创新推广中心建设成效，确保无法亲临现场的观众就近选择分会场参与大会。大会还将聚焦两化融合、工业互联网平台、数字化转型等领域，发布《工业互联网平台发展指数》《中国两化融合发展数据地图（2020年）》等系列重磅研究成果。

大会现正处于最后筹备阶段，报名通道已经打开，大会相关信息将通过**官方微信公众号“两化融合生态圈”和官方微博发布**。因防疫需求，大会将采取限流措施，请各方留意报名通知。
