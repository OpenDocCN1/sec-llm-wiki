# 微软Windows XP源代码泄露？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDA4NjgwMw==&mid=2247487681&idx=1&sn=da6b228d5a06ab013e3f3dfe603fb205&chksm=e96271bdde15f8ab5ab73620ed5b056b6cce4473341232d94823b208d1659cd2260b93958f43&scene=126&sessionid=1681668464#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDA4NjgwMw==&mid=2247487681&idx=1&sn=da6b228d5a06ab013e3f3dfe603fb205&chksm=e96271bdde15f8ab5ab73620ed5b056b6cce4473341232d94823b208d1659cd2260b93958f43&scene=126&sessionid=1681668464#rd)

  
  

  

据4channel及多位推特网友爆料，疑似微软Windows XP系统的源代码在网上泄露，被公开放在MEGA网盘，文件名为“nt5src.7z”，2.93GB。

（ps：还有一个42.93GB的BT种子文件分享，但分享链接已无法访问）

  

![](../Images/d9301f1e8d52fb9dc33cb0091cd106d5.png)

  

![](../Images/a9a4069392ca255fe3245eee1339a51d.png)

  

Windows XP是微软在2001年发行的操作系统版本，如今微软早已终止对这款陈旧操作系统的支持。据 The Verge（一家美国科技媒体网站）消息，Windows XP和Windows Server2003的源代码最近在多个文件分享网站出现。

泄露文件称这些代码已经在个人分享下流传多年，但这是Windows XP的源代码首次被公开曝光。The Verge已经确认这些代码的真实性，微软发言人表示，目前公司正对此展开调查。

有网友下载了泄露包，称这应该是Windows XP SP1和2003的源代码，其中还可以发现能和“永恒之蓝”漏洞结合的bug。获得了xp的源代码之后，不法分子就会利用这些代码漏洞进行攻击，最后导致很多用户的个人信息泄露，造成巨大的损失。

![](../Images/011aa5d8f8e2a78b3cc17156db3b367b.png)

  

![](../Images/f187020217b8caeee75b5a4eec4f93c0.png)

  

好在现在微软旗下的win10系列比较上心，安全性也是非常可靠的。Windows XP源代码的泄露，其实也为整个行业敲响了警钟，大多人都不在意电脑安全知识，导致个人信息大肆泄露，给了不法分子可乘之机。最后提醒那些想要怀旧而使用开放版本系统的用户还是要注意一下系统的安全防护。
