# 精彩！成都市2020年国家网络安全宣传周今天开幕

**成都市2020年国家网络安全宣传周**

  
  

  

“诈骗犯嘴巴甜，看到看到要骗钱”……网络安全与成都民谣的融合，为网络安全宣传增添了许多趣味性。今天上午，成都市2020年国家网络安全宣传周活动开幕式在宽窄巷子东广场举行，今年的网络安全宣传周活动将从9月14日起持续至9月20日。围绕“网络安全为人民，网络安全靠人民”，以古风游园+知识科普为主题的成都市国家网络安全宣传周公众体验活动也正式面向公众开放。

  

除了公众体验活动外，今年网络安全周期间，成都市还将举办2020蜀山论剑•网络安全大会、网络安全应急演练总结汇报会等重要活动，以及校园日、电信日、法治日、金融日、青少年日、个人信息保护日等主题日活动，通过线上线下全方位参与，切实提高广大人民群众网络安全意识和防护技能。

  

![](../Images/68f32b407b1e4edbd090260044190b94.png)

  
  

  

  

网络安全宣传周今开幕

市民公开课每日开讲

  

据介绍，此次以古风游园+知识科普为主题的成都市国家网络安全宣传周公众体验活动由中共成都市委网信办主办，成都文旅集团、成都市青羊区网信办协办，成都全搜索新闻网承办。

  

在开幕式上，《2019年成都互联网发展状况报告》线下发布，报告从互联网基础资源、网民结构与互联网应用状况、属地自研APP应用情况、互联网产业发展状况、政务新媒体应用及互联网传播等多个方面展示了2019年成都市互联网发展状况。

  

随后，成都市少城小学的同学们代表青少年向广大网友发起倡议，携手共筑网络安全防护网。杭州安恒信息技术股份有限公司现场演示破解平衡车，提示市民注意智能家居安全。据悉，网络安全公开课将在接下来的公众体验活动每天开讲，成都市律师协会、亚信安全、中国网安卫士通等企业会为市民带来浅显直白、生动趣味的网络安全科普。

  

![](../Images/10c2b1ec6bb491f1c6d546a97a724859.png)

  

  

上网提防啥？

本地企业带来花式黑科技科普体验

  

每年举办的网络安全宣传周公众体验活动是成都的特色活动，今年在延续往届活动科普性、互动性、趣味性的同时，将网络安全宣传与中国传统文化结合，让人眼前一亮。活动囊括了古风打卡场景、游戏互动体验、网络安全黑科技展示等，市民在此既可以获取知识，还能参与游戏、赢取奖品。据了解，公众体验活动开展时间为9月14日至9月19日，每日11点至19点。

  

“警惕清粉服务——你清粉，它侵你”“看好熊孩子，网上花巨资”……现场，网络安全趣味标语无处不在。专程前来参与活动的成都市民刘英今年67岁了，她告诉记者：“现在网上花样太多了，我们老年人必须长个心眼，学习一下新知识，才不得被骗！”

  

为此，针对大众科普，成都本地网络安全企业带来了精彩纷呈的黑科技科普大餐，无糖信息准备了模拟网络交友诈骗的“杀猪盘”体验游戏，立鑫科技的手机安全服务自助机可以让市民DIY检测手机是否有安全隐患，亚信安全能为企业信息安全提供免费“体检”，中国网安则带来了古风网络安全知识漫画和安全手机体验。

  

成都电信5G创新应用巡展车也来到活动现场，展示了5G+8K、5G+VR、5G电竞体验舱、智慧家庭和云游戏等丰富的5G应用，充满“未来感”的体验让游客市民大呼过瘾。此外，还有流动摊位“走街串巷熊猫车”，在景区内与游客市民互动，邀请大家参与H5网络安全知识问答。

公众体验活动古风场景“吸睛”

吸引COSER网红打卡

  

传统糖画匠人、活字印刷体验、老成都茶馆……每幕景都是国潮风“穿越大片”。宽窄巷子游人如织，这样的场景无疑为活动增加了人气，甚至吸引了知名二次元网红前来打卡。抖音网红riko呆呆说：“现场适合拍照的地方很多，和小伙伴身着汉服来游园。”从江苏到成都旅游的王子健说：“科普很有中国味儿，这次来成都旅游顺便也增长了网络安全知识。”  

  

![](../Images/0a6fc21ae79626af83d8a00092db80c4.png)

  

活动现场，在“糖画铺·诈骗醉醉甜”板块，市民需接受网络安全知识问答挑战，答对即可获得转糖画机会。不过糖画转盘上不止是传统的龙凤、蜻蜓等，还有代表互联网的元素、手机等糖画造型，不少市民拿着糖画打卡拍照。在“传书局·千里寄平安”板块，市民可以DIY活字印刷，制作一份网络安全祝福语的精美古风信笺。在“大理寺·普法处”，成都市律师协会每日坐镇为市民解答互联网相关的法律疑难问题。

  

除了逛展游园，现场还有丰富奖品。据介绍，参与活动的市民均可获得一张“任务卡”，上面标出了活动各大版块的位置和名称，市民在各板块打卡集章后，便能参与抽奖，奖品包括电信5G手机、火锅底料、熊猫公仔等。
