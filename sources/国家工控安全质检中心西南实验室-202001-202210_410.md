# 新区动态丨决赛！2020年工业信息安全技能大赛落幕

**2020年工业信息安全技能大赛圆满落幕**

9月4日，2020年工业信息安全技能大赛在中国西部国际博览城9号馆内圆满落下帷幕。

  

![](../Images/5c95b718e9bf1a881eefb7a7ee210652.png)

  

决赛充分考察选手们攻防对抗、风险验证、众测等方面的积累与实力。根据专家组的现场成绩确认，决赛结果在当日下午产生，最终来自恒安嘉新（北京）科技股份公司的Everseclab战队获得大赛一等奖。

**项目招引，全员出击**

日前，新兴街道召开项目招引工作专题会，要求打造“三向延伸”立体推进项目招引工作格局。

  

一是责任压力向下延伸。树牢“人人都是招商员”理念，教育引导街道全体干部职工招商引资“主力军”意识。二是招引诚意向外延伸。坚持“上门拜访”和“以商招商”联动，吸纳和盛田园东方、天府家宴村等项目负责人加入街道招商引资团队，搭建以商招商“朋友圈”。三是保障服务全程延伸。积极做好项目用地指标覆盖、报规报建、证照代办等服务工作；深化“360”网络理政模式，积极解决企业公建配套、员工招聘等难题。

**如何抓牢抓实审查调查工作？推进会上“划重点”**

近日，新区纪工委召开2020年下半年审查调查工作推进会，对当前和今后一段时期的审查调查工作进行安排部署，并提出明确要求。

  

深入推进全面从严治党、做好监督执纪问责工作，使命光荣、责任重大，新区纪工委如何继续把纪检监察工作抓牢、抓实、抓好，确保全年工作目标顺利完成，会议强调，一要认识到位，二要务实工作，三要专业专注，四要敢管敢干，五要坚持问题导向，六要安全办案，七要争取多方支持。
