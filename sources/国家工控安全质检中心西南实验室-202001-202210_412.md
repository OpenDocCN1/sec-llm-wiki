# 要闻：国家工业信息安全发展研究中心纪委书记郝志强一行调研国家工控安全质检中心西南实验室（哨兵科技）！

9月4日上午，国家工业信息安全发展研究中心纪委书记郝志强一行调研国家工业控制系统与产品安全质量监督检验中心西南实验室（四川哨兵信息科技有限公司）。郝志强书记一行实地考察了工业信息安全检测评估中心等实验室科研办公环境，听取了一年来工作情况汇报，询问了实验室技术和市场能力建设情况，并就全面开展西南地区检测业务、地方政府支持等问题与西南实验室相关负责同志进行了座谈交流。哨兵科技公司董事长张晓彬、国家工控安全质检中心西南实验室主任、哨兵科技公司总经理林方涛分别从业务发展、技术能力发展、运营团队建设等重点工作进行了汇报。

  

郝志强书记在交流中指出，西南实验室作为国家工业信息安全发展研究中心在西南地区的重要布局，经过一年多的发展，业务工作已逐步走向正轨，核心团队建设趋于稳定，技术能力不断提升，市场方向逐步清晰，项目开展也取得了新的突破。希望实验室在能力建设和业务开展上加大与中心全面业务对接，立足安全辐射两化融合等多个业务领域，加强人才引进，全面服务和保障好中心西南战略布局，服务好地方政府做好工业信息安全保障工作，带动西南地区工业信息安全行业发展，开拓思路，广泛合作，全面推进工业企业的信息安全综合保障能力提升。

  

![](../Images/797794bed12d572fba6e9f7640ad59fc.png)

  

西南实验室全体职工将在国家工业信息安全发展研究中心强有力的领导下，肩负起维护西南地区工信安全的使命，加强自身能力建设，服务好政府、行业和相关企业。
