# 服务能力 —— 培训 赛事

培训 赛事  
  
  

**培训 赛事****：**对政府、企业、高校进行法律法规的宣贯、政策标准的了解、 国内外ICS事件及相应处罚案例、安全意识、安全运营、安全渗透、应急响应与处置等方面的培训；组织举办工业企业行业信息安全大赛。

  

![](../Images/26d77554b45f34881bd3f22575be6388.png)

  

**（一）培训** 

  

**1、培训内容**

  

A.安全意识培训：通过信息安全意识提升实现对业务的有效支撑。首先从全员层面，提升企业内部员工认知可能存在的安全问题，认识信息安全事故对组织的危害，实现信息安全“人防”保障有效支撑业务高效稳定运行。提升重点领域从业人员的信息安全意识整体处于较高水平。  

  

B.安全运营培训：企业安全解决方案、各类设备的安全管理与分析、网络事件的分析调查与处置。操作系统及交换机加固、防火墙/入侵检测日常管理，态势感知和威胁情报系统的搭建运营等。

  

C.安全渗透培训：针对于高阶安全技术人员的培训，通过进行操作系统、应用系统、数据库、网络等各种环境的安全攻击与渗透，包括burpsuit、kali、nessus、awvs等各类工具的安全使用。

  

D.网络分析培训：采用如wireshark、sniffer、科来等各类软硬件工具，对网络流量的原始数据渗透与分析，能够从大量数据中快速发现并掌握网络管理的关键技术，提高对网络问题尤其是网络安全的解决与保障能力，促进网络运维管理水平的提升。

  

E.应急响应与处置培训：网络安全应急处置预案的建立，网络安全应急处置各类工具的操作、应急响应与处置的事后分析等。

  

以及其他针对用户需求定制化的安全培训课程，如安全加固培训、异常分析培训、红蓝对抗实训等。

  

**2、培训对象**

  

A.高校：中小学研学和职高、大学的辅修；根据市场需求提出针对性较强的学习 大纲及课时，组织相关院校师生的学习、实训并通过参与赛事的方式最终取得工业信息安全领域有含金量的资质或证书，促进就业为导向。

  

B.政府（含经信）：法律法规的宣贯、政策标准的了解、国内外ICS事件及相应处罚案例的学习等。

  

C.企业（工业企业、联盟）：除了针对政府的培训内容外，还需引导加强企业网络安全运维人员的技能培训、新技术在不同领域的应用学习等。

  

**（二）赛事承办** 

  

我们拥有自主研发的虚拟化靶场系统，可以为大赛量身定做的在线签到系统，不仅提高了赛事组织效率，还同步构建工业信息安全人才智库。拥有工业信息安全行业软实力工控系统安全的比赛策划、承办能力。拥有网络安全比赛相关的设计支持能力。  

  

**（三）我们的优势** 

  

1、我们拥有国家级的工业信息安全攻防靶场；  

  

2、背靠工信部，拥有庞大的国家级智库专家团队；

  

3、中心前身为电子情报所，专注于网络安全情报研究，熟知国内及全球的网络安全形势；

  

4、有丰富的攻防对抗经验、工控安全工程经验，熟悉国内工业企业的信息安全；

  

5、丰富的赛事组办经验并多次承办过省部级以上信息安全论坛、网络安全宣传等相关活动（2018年网络安全博览会（成都）、2019年国家网络安全宣传周、2019年国际软件博览会、2019年中国工业信息安全技能大赛（成都）、2019年“天府杯”国际网络安全大赛等）。

**（四）带给客户的价值** 

  

✓ 帮助企业提升员工的网络安全意识，规范使用信息和网络；  

✓ 帮助企业规范员工网络安全行为，遵守企业网络安全管理制度；

✓ 帮助企业提升网络安全管理能力，规范企业网络安全建设、管理和运营。
