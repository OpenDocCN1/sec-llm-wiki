# 国家工业控制系统与产品安全质量监督检验中心西南实验室

国家工业控制系统与产品安全质量监督检验中心西南实验室（简称“国家工控安全质检中心西南实验室”）坐落于成都市天府新区天府菁蓉中心；国家工业控制系统与产品安全质量监督检验中心是**国家工业信息安全发展研究中心下设机构、国家认证认可监督管理委员会批复的国家级质检机构、国内第一家从事工控安全检测工作的专业技术机构，**我们具备CNAS、CMA、信息安全应急处理服务、信息安全风险评估、网络安全等级保护等行业资质。

  

![](../Images/ad8a6935e0664785c5c4bbadb42014c7.png)

  

**国家工控安全质检中心西南实验室作为立足于西部地区开展工业信息安全及工业互联网安全的第三方检测机构**，主要为西南地区各级科研院所、各类工业控制、工业自动化、工业互联网及工控安全相关公司，提供**工业信息安全产品检测、工业信息安全检查评估、重大工业项目信息安全审查、工业互联网仿真测试、工业信息安全实训演练等服务**，弥补西南地区工控系统及产品安全质检的市场空缺，协助企事业单位提升其产品和系统的信息安全水平，建立工业互联网安全保障体系，为国家“2025智能制造”、“新基建”提供技术支撑。

实验室内景和部分实验设备

目前，国家工控安全质检中心西南实验室已与中国石油、东方电气、攀钢集团、成都国检等企事业单位提供工业互联网信息安全检测、风险评估、安全咨询等服务，协助工信部、公安部、国家工业信息安全发展研究中心、四川省经信厅、成都市经信局等多部门承办“2019年中国工业信息安全大会”、“2019世界信息安全大会”、“2019工业信息安全技能大赛”“天府杯2019国际网络安全大赛”、“2019成都市工业信息安全培训会”等工业互联网信息安全赛事、培训业务。
