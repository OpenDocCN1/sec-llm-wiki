# 要闻丨成都工业职业技术学院领导考察组一行莅临国家工控安全质检中心西南实验室考察交流！

2020年7月28日

  
  

![](../Images/11390a0352474bc090af55025190b729.png)

 7月28日下午，成都工业职业技术学院党委书记姚凯等领导一行莅临国家工业控制系统与产品安全质量监督检验中心西南实验室（简称“国家工控安全质检中心西南实验室”）参观考察交流。考察组一行参观了工业网络安全检测评估中心实景展示；观看了工控仿真系统信息安全的现场模拟演练；并就产学研合作、培训基地建设等内容进行深入交流。

  

![](../Images/c96d6447f5e80d0c6697fc5d27232ed1.png)

考察组一行参观工业网络安全检测评估中心

  
  
  
![](../Images/79aea039d415b1563283091bc4046034.png)

  

![](../Images/ca4727653d1f44bbafa1855f2605ade9.png)成都工业职业技术学院党委书记 姚凯

 交流会上，国家工控安全质检中心西南实验室主任林方涛就实验室建设情况、服务能力等方面内容进行了介绍，成都工业职业技术学院党委书记姚凯在聆听完介绍后表示，近年来随着互联网的快速发展，互联网信息安全被放到了更加突出的位置，成都工业职业技术学院的信息工程学院正在为信息安全工作提供人才输出。

  

![](../Images/28eafd77834cd0c8d9fae06f95333420.png)

  

 成都工业职业技术学院作为成都市人民政府举办、四川省教育厅主管的一所以工科为主的公办全日制高等职业技术学院，具有深厚的办学经验，实训条件一流；学院拥有天府校区、公交校区等四个校区，并建有**28个具有国际水准的实训基地**，曾荣获省委、省政府表彰的“**全国职业教育先进单位”和首批国家改革发展师范学校**等称号。

  

  

 国家工控安全质检中心西南实验室作为国家工业信息安全发展研究中心下设机构，具备工控安全检测、评估、等保、咨询、赛事培训等服务能力，并已完成对工控系统仿真类靶场的搭建，可开展培训和组织专项竞赛提供必要的实战环境与技术支撑。今后双方将在高校科研、人才培养、实训基地建设等方面展开校企合作，为产业发展和社会效益做出突出贡献。
