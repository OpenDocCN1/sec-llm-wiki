# 聚焦丨浪潮与国家工信安全中心签署战略合作协议

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDA4NjgwMw==&mid=2247485598&idx=1&sn=710186b716cb4cca974f34253033604a&chksm=e96269e2de15e0f48f2545597713e96961daaaeb1031908fe2482305e872bfad2cdf8b6c28ad&scene=126&sessionid=1681668474#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDA4NjgwMw==&mid=2247485598&idx=1&sn=710186b716cb4cca974f34253033604a&chksm=e96269e2de15e0f48f2545597713e96961daaaeb1031908fe2482305e872bfad2cdf8b6c28ad&scene=126&sessionid=1681668474#rd)

7月21日，浪潮与国家工业信息安全发展研究中心（以下简称：国家工信安全中心）签署战略合作协议，国家工信安全中心主任、党委副书记尹丽波，浪潮集团高级副总裁、浪潮云董事长兼CEO肖雪出席签约仪式。

  

![](../Images/533c58f297df2b03c8f9fcbc5b084e98.png)

  

双方将发挥各自优势，重点聚焦工业互联网，在工业信息安全技术研发、基于标识解析的QID（质量码）、云洲工业互联网平台、边缘计算+工业内网网络安全、安全检测实验室等方面展开全方位合作。

作为工业和信息化部直属单位，国家工信安全中心是工业领域国家级信息安全研究与推进机构，是推进工业互联网产业发展的国家队，在工业互联网平台建设、运行监测分析、Handle标识技术研发应用、安全保障技术研发、数据安全监测以及相关标准研制、产业生态培育等方面具有深厚积累和独特优势。

目前，浪潮云洲工业互联网正依托“云、质量码、云ERP”和智能制造方面的优势，逐渐形成“云、数、用”一体化的工业互联网发展模式，并独创地将国家标识解析体系与区块链、国家商用密码技术融合的“云码”平台结合在一起，形成了标准化规模应用——QID质量码，通过描述“物”全生命周期质量数据链接企业与消费者，涵盖“研产供销服”全流程的标准化高质量发展体系。

接下来，浪潮也将加大与国家工信安全中心基于QID的相关合作，包括开展标识解析+区块链+密码+IPV6等方面的联合研发，共建QID安全检测实验室，联合推广QID安全检测服务以及共同制定和发布QID安全标准等。

国家工业信息安全发展研究中心领导在西南实验室调研

  

 国家工业信息安全发展研究中心是支撑我国工业领域信息安全的国家级研究与推进机构，2019年与哨兵科技联合建立的“国家工业控制系统与产品安全质量监督检验中心西南实验室”落地成都天府新区，旨在为西南地区工控领域信息安全做好技术支撑，为各企事业单位提供工控安全检测、评估、等保、咨询、培训等相关服务。国家工控安全质检中心西南实验室一直秉持国家工业信息安全发展研究中心的服务理念，落实国家工业信息安全发展研究中心在西南地区的战略部署，以实际行动助力国家工业互联网安全保障体系建设，促进工业产业转型升级，带动西南地区工业信息安全创新发展。
