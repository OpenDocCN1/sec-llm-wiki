# 热烈欢迎民建成都市委仰协主委一行莅临哨兵科技考察调研

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDA4NjgwMw==&mid=2247485625&idx=1&sn=0755a1559bd15d303336b61c61b013fe&chksm=e96269c5de15e0d30f8307cfc4ea80322c5a78a138d889fe9bdbcb832a768114e4d4e350101a&scene=126&sessionid=1681668489#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDA4NjgwMw==&mid=2247485625&idx=1&sn=0755a1559bd15d303336b61c61b013fe&chksm=e96269c5de15e0d30f8307cfc4ea80322c5a78a138d889fe9bdbcb832a768114e4d4e350101a&scene=126&sessionid=1681668489#rd)

![](../Images/ca825ad9c8b75acf37abd0f9b84c04b6.png)![](../Images/146a1a93e20088f292381a2b7c261c8a.png)

5月8日，民建成都市委会主委、成都市人大常委会副主任仰协一行莅临哨兵科技考察调研，调研组一行首先参观考察了国家工业控制系统与产品安全质量监督检验中心西南实验室，观看工控仿真系统安全的现场模拟演练，了解哨兵科技的工业信息安全态势感知平台的建设情况；并就疫情期间企业发展现状和哨兵科技进行交流座谈。

![](../Images/9a892d582c4c9e544cf3895e6cc0ea14.png)![](../Images/84e26fc62e7d4dffbd0d9585287cad40.png)  
![](../Images/6cabb6ae5190845498d91d7ead021f7e.png)

交流座谈会上，哨兵科技就企业建设和发展现状向调研组进行了汇报。

  

![](../Images/293e4ca85e519c5ac923f5337954c7c8.png)

![](../Images/5539393d51e3a8a26e4df8ed07258268.png)

![](../Images/6cabb6ae5190845498d91d7ead021f7e.png)  
![](../Images/7771530d4fd21198691eda4d596dc260.png)

哨兵科技（西南实验室）作为国家工业信息安全发展研究中心下设机构、国家认证认可监督管理委员会批复的国家级质检机构、国内第一家从事工控安全检测工作的专业技术机构，旨在提升西部地区工业信息安全与工业互联网安全，协助企事业单位提升其产品和系统的信息安全水平，建立工业互联网安全保障体系，为国家“2025智能制造”、“新基建”提供支撑。

![](../Images/5c9d66568700c94f3cb6801f27a7c7d3.png)

聆听完汇报后，调研组一行对哨兵科技的技术能力、业务开展情况和服务方向给予了充分的肯定。民建成都市委仰协主委在总结发言中表示，工业信息安全领域是一片蓝海，前景广阔，哨兵科技具有强大的技术团队支撑力量，对哨兵科技未来的发展十分看好。

![](../Images/32288230d1e4e95340089e7019718b6a.png)

尤其在涉及交通、电力、石油、化工等民生和国家安全领域的行业，希望哨兵科技能够借助国家工业信息安全发展研究中心的技术实力，延伸出更多的服务板块，为西南地区工业企业提供更优更好的信息安全咨询服务，为国家工业信息安全的发展提供支撑。

![](../Images/9ec863a934bb4b8de2678b9943ad1920.png)![](../Images/a11bec4caa52bb193da0e7901cacafeb.png)

最后，仰协主委还对哨兵科技开展的培训、赛事活动给予了厚望。哨兵科技承办了“2019年工业信息安全技能大赛”、“天府杯”2019国际网络安全大赛”等大型赛事活动，结合成都正在创建国际赛事名城的契机，仰协主委期待哨兵科技能够将企业开展的信息安全赛事活动打造成企业未来发展的另一张名片。

![](../Images/a63f9c400f168b7e99b11a471acab4a4.png)![](../Images/10db4bed4e1b7b82d2cba57d93928191.png)中国民主建国会（简称民建）是主要由经济界人士组成的、具有政治联盟特点的政党，是接受中国共产党领导，与中国共产党通力合作的中国特色社会主义参政党。民建会员企业、哨兵科技董事长张晓彬陪同考察调研。
