关键词
网络钓鱼活动、供应链攻击、PyPI

JuiceLedger是一个相对较新的攻击者，专注于通过名为“JuiceStealer”的.NET 程序集窃取信息，在短短6个月多的时间里迅速将其攻击链从欺诈应用程序演变为供应链攻击。8月，JuiceLedger对PyPI提供者进行了网络钓鱼活动，并成功入侵了多个合法软件包，已识别出数百个提供JuiceStealer恶意软件的仿冒包，至少有两个总下载量接近700,000的软件包遭到入侵。PyPI表示，已知的恶意软件包和仿冒域名现已被删除或下线。

1. 概述


SentinelLabs与Checkmarx合作，一直在跟踪被称为“JuiceLedger”的攻击者的活动和演变。2022年初，JuiceLedger开始开展相对低调的活动，使用“JuiceStealer”传播欺诈性Python安装程序应用程序，该.NET应用程序旨在从受害者的浏览器中窃取敏感数据。2022年8月，攻击者感染开源软件包，以此作为通过供应链攻击将信息窃取者瞄准更广泛受众的一种方式，大大提高了该组织构成的威胁级别。
JuiceLedger经营者在网络钓鱼活动中积极针对 PyPI 包提供者，成功地用恶意软件感染了至少两个合法包，另外还有数百个程序包被恶意假冒。
在这篇文章中，详细介绍了 JuiceLedger 的演变，描述了该组织的攻击向量和活动，并提供了对 JuiceStealer 有效负载的分析。
2. 虚假应用和供应链攻击


图 1 PyPI 事件活动

对PyPI包提供者的供应链攻击似乎是今年早些时候开始的活动的升级，该活动最初通过虚假的加密货币交易应用程序针对潜在受害者，其中使用的一个名为“特斯拉交易机器人” 的机器人，被其经营者称为“AI Crypto交易机器人”。

8月份对PyPI的攻击涉及一个更为复杂的攻击链，包括向PyPI开发人员发送网络钓鱼电子邮件、域名仿冒以及旨在用JuiceStealer恶意软件感染下游用户的恶意程序包。该向量似乎与早期的JuiceLedger感染方法并行使用，因为类似的有效载荷大约在同一时间通过假加密货币分类帐网站交付。

3. 针对PyPI提供者


2022年8月24日，PyPI发布了针对PyPI用户的持续网络钓鱼活动的详细信息。根据他们的报告，这是已知的第一个针对PyPI的网络钓鱼攻击。网络钓鱼电子邮件指出，强制“验证”过程要求提供者验证他们的包，否则有可能将其从 PyPI 中删除。

图 2 发送给 PyPI 提供者的网络钓鱼电子邮件示例

网络钓鱼电子邮件将受害者指向模仿PyPI登录页面的Google网站登录页面。那里提供的凭据被发送到一个已知的JuiceLedger域：linkedopports[.]com.

图 3 PyPI 钓鱼网站

其中一些网络钓鱼攻击似乎已经成功，导致其提供者凭据被泄露的合法代码包遭到破坏。PyPI还报告说，他们发现了许多符合类似模式的域名仿冒包。JuiceLedger还使用域名仿冒来传递其恶意应用程序。

抢注流行的代码包并不是什么新鲜事。在过去几年中出现了类似攻击的报告，例如最近由SentinelLabs报道的针对Rust开发人员的CrateDepression活动。

JuiceLedger在8月份的活动中上传的受损包包含一个简短的代码片段，负责下载和执行JuiceStealer的签名变体，添加的恶意代码如下所示。

图 4 恶意代码片段

添加到这些包中的代码片段与在域名抢注包中添加的代码片段非常相似。根据PyPI，恶意代码片段存在于以下软件包中：

exotel==0.1.6
spam==2.0.2 and ==4.0.2

查看受感染包的代码片段表明，参与者在注册 URL 中添加了受感染包的指示。

图 5 来自exotel感染代码的片段

JuiceLedger的8月活动还包含一个以Ledger为主题的欺诈应用程序。Ledger是一种用于加密资产的硬件“冷存储”钱包技术，其用户已成为嵌入假 Ledger安装包中的数字签名版本的JuiceStealer的目标。

图 6 用于签署JuiceStealer恶意软件的证书

该证书13CFDF20DFA846C94358DBAC6A3802DC0671EAB2用于签署总共四个样本，其中一个似乎与本次活动无关，尽管所有样本都是恶意的。

4. JuiceStealer恶意软件分析


JuiceLedger的信息窃取器，称为JuiceStealer，是一个相对简单的.NET应用程序，内部命名为“meta”。 信息窃取器是在今年2月开始出现的，其后经过多次迭代，它被嵌入到许多欺诈性应用程序和安装程序中。

Python安装程序

2月13日上传到VirusTotal的第一版JuiceStealer (d249f19db3fe6ea4439f095bfe7aafd5a0a5d4d2)似乎不完整，可能是开发人员提交的测试，它是一组模仿Python安装程序的变体中的第一个。

此示例遍历包含单词“chrome”的进程，将其关闭，然后搜索Google Chrome扩展日志文件。信息窃取程序会遍历包含单词“vault”的日志，可能会搜索加密货币库，并通过HTTP向嵌入的C2服务器报告。

private static void Main(string[] args)
{
  Console.WriteLine("Please wait while Python installs...");
  string[] directories = Directory.GetDirectories("C:\\Users\\" + Environment.UserName + "\\AppData\\Local\\Google\\Chrome\\User Data");
  foreach (Process process in Process.GetProcessesByName("chrome"))
  process.Kill();
  Thread.Sleep(2500);
  Console.WriteLine("Python is almost ready...");
几天后，一个完整版本的欺诈安装程序作为名为“python-v23.zip”(1a7464489568003173cd048a3bad41ca32dbf94f)的可执行程序出现。

图 7 伪造的Python安装程序说明文件
此版本的信息窃取程序引入了一个名为“Juice”（因此得名）的新类，并且还搜索Google Chrome密码、查询Chrome SQLite文件。它还会启动包含在名为“config.exe”的zip中的Python安装程序。将合法软件命名为“config.exe”似乎在各种JuiceStealer变体中很常见。

像分析的许多JuiceStealer样本一样，它被编译为一个独立的.NET应用程序，这使文件显着变大。许多早期版本的JuiceStealer共有的pdb路径中包含了用户名“reece”和内部项目名称“meta”。

C:\Users\reece\source\repos\meta\meta\obj\Release\netcoreapp3.1\win-x86\meta.pdb

5. JuiceStealer的进化


以观察到的pdb路径为中心能够将其他活动链接到JuiceLedger，再加上对 JuiceStealer开发阶段的其它发现，表明该组织于2021年底开始运营。

（1）Pre-JuiceStealer 虚假安装程序

1月30日，一组三个编译为独立应用程序的虚假安装程序从位于英国的提交者f40316fe上传到VirusTotal。同一提交者还上传了JuiceStealer的第一个变体，这似乎也是一个测试。所有伪造的安装程序都有一个相似的pdb路径，包含用户名“reece”，并且似乎是攻击者对JuiceStelaer的第一次迭代。

C:\Users\reece\source\repos\install-python\install-python\obj\Release\netcoreapp3.1\win-x86\install-python.pdb

（2）Nowblox 诈骗网站

在整个研究过程中发现了与Nowblox的可能联系，Nowblox是一个于 2021 年运营的骗局网站，提供免费的Robux。几个名为“Nowblox.exe”的应用程序从英国的提交者系统地上传到VirusTotal，所有应用程序都具有以下pdb路径：

C:\\Users\\reece\\source\\repos\\Nowblox\\Nowblox\\obj\\Debug\\Nowblox.pdb
虽然路径本身并不是一个很强的指示，但在研究中发现了另一个指向 Nowblox的链接，其形式为名为“NowbloxCodes.iso” (5eb92c45e0700d80dc24d3ad07a7e2d5b030c933)的文件。使用ISO文件可能表明它是通过网络钓鱼电子邮件发送的，因为ISO文件已成为绕过电子邮件安全产品的流行攻击媒介，但是没有数据可以验证这一点。

该文件包含一个LNK文件(e5286353dec9a7fc0c6db378b407e0293b711e9b),触发执行混淆的PowerShell命令，然后运行mstha以从当前离线的hxxps://rblxdem[.]com/brace.hta加载.HTA文件。

该域名rblxdem[.]com分配的IP为45.153.35[.]53，该IP还托管了多个Ledger网络钓鱼域名以及JuiceStealer的C&C域名thefutzibag[.]com，提供了Nowblox与JuiceLedger有联系的另一组证据。

6. 欺诈性应用程序


随着时间的推移，JuiceLedger经营者开始使用直接以加密货币为主题的欺诈应用程序，其中，他们命名为“Tesla Trading bot”的应用程序。以与 Python 安装程序类似的方案交付，它嵌入在带有其他合法软件的 zip 文件中。JuiceStealer在此期间发生了重大变化，增加了对其他浏览器和Discord的支持。

嵌入的指令消息与假Python安装程序中的消息非常相似，提示用户禁用他们的安全解决方案。

图 8 JuiceLedger安装程序敦促用户绕过自己的安全性
虽然交付机制仍不清楚，但JuiceLedger经营者似乎为虚假交易机器人维护了一个网站，促使用户下载欺诈性应用程序。

图 9 恶意特斯拉交易机器人的下载站点
8. 结论


JuiceLedger似乎已经从几个月前就随机小规模的感染迅速演变为对主要软件分销商进行的供应链攻击。对PyPI提供者的攻击的复杂性升级，包括有针对性的网络钓鱼活动、数百个域名仿冒包和受信任开发人员的帐户接管，这表明攻击者有时间和资源可供使用。

鉴于PyPI和其他开源软件包在企业环境中的广泛使用，诸如此类的攻击令人担忧，建议安全团队审查提供的威胁指标并采取适当的缓解措施。
附录1 PyPI响应


PyPI表示他们正在积极审查恶意软件包的报告，并已下线了数百个仿冒域名。同时敦促包维护者在尽可能对其帐户使用双因子认证授权，并确保http://pypi.org为输入凭据时确认地址栏中的URL。用户还可以检查站点的TLS证书是否颁发给pypi.org。

建议认为自己可能是JuiceLedger攻击受害者的维护者立即重置密码并将任何可疑活动报告给security@pypi.org。
