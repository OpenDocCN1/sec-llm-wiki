# 2022年威胁预测-下

上篇介绍了面向云服务威胁、勒索软件威胁、漏洞利用，在下篇中，主要介绍商品恶意软件攻击、物联网威胁、供应链威胁，并对2022年预测的威胁给出几条预防的建议。（上篇链接：[https://mp.weixin.qq.com/s/IGStKrfXk9AVE9qvg3sewg](https://mp.weixin.qq.com/s?__biz=MzU5MjEwNjQzNg==&mid=2247498976&idx=1&sn=b3f34c1cf40afdf6075e56f6845eb471&scene=21#wechat_redirect)）NO.5【商品恶意软件攻击】  
  
  
  
     攻击者继续认为小型企业是容易被攻击的对象，众多的中小型企业将准备好安全措施，以抵御大量可能发生的商品攻击。

*   当所有人都在关注勒索软件时，传统的商品攻击和服务攻击将有时间创新更复杂的工具。
    

企业仍将是勒索软件运营商寻求巨额回报的猎物，但是，大型恶意软件的大肆利用只会让中小型企业(smb)成为勒索软件选中为目标的最佳时机。在过去的几年里，公众的注意力一直集中在勒索软件上，而勒索软件被认为是一种商品恶意软件和一种服务模式。其他现成的恶意软件类型，如远程访问木马(RATs)、信息窃取器、加密货币挖矿器、下载器和恶意软件加载器，也在网络犯罪圈中传播，这将推动恶意软件市场成为一个潜在而可怕的威胁。勒索软件运营商利用商品恶意软件工具使他们的攻击更有效，其他恶意行为者则利用商品攻击工具发起有政治动机的活动。勒索软件运营商也被检测到使用商业恶意软件工具，如Cobalt Strike、Koadic、PowerShell Empire和Metasploit40与现有的系统管理工具协同使用——一种被称为“living off the land”的技术——以避免被发现。

这些工具的功能越来越先进，价格越来越便宜，获取越来越容易，加上越来越多的定制恶意软件最终在地下网络市场被商品化并提供给其他恶意行为者使用，可以预见，下一代的网络罪犯将比15年前开发勒索软件时的网络罪犯更有创意，装备更精良。可以预测，伴随商品攻击工具的市场，不仅会缩短新手恶意行为者的成熟时间，而且还给他们提供了与其它网络犯罪者联系的网络。毕竟，卖家不仅提供了随时可用的恶意软件，而且还提供了使用说明、提示和故障排除指南。

这种服务模式，将商用恶意软件作为服务的一部分出售，而不是一次性购买恶意软件，将非常适合初级攻击者，他们必然会从寻求恶意软件工具过渡到寻找可靠的犯罪伙伴。随着他们成长为更有经验的攻击者，这种合作将导致更大的犯罪活动，正如恶意攻击者能够利用银行木马Trickbot的僵尸网络重建Emotet恶意软件的僵尸网络所证明的那样，仅仅几个月后，Emotet自己的基础设施就被执法机关摧毁了。可以预测，到2022年，恶意攻击者将不再需要开发定制的恶意软件，在这种情况下，此类恶意软件需要在复杂的定向攻击中能更好地管理其附属设施。

考虑到这一点，恶意软件领域早就应该有一个更复杂的产品，让恶意攻击者可以升级他们的武器库。明年可能会出现一种僵尸网络服务，就像ZeuS僵尸网络的增强版那样，同时具备突破和控制基于云和物联网的平台。由于讲俄语地下网络犯罪组织的“臭”名声，这样的工具有可能来自于他们，但随着不断增加的附加功能，FreakOut僵尸网络也将成为一个竞争者。

可以预见，由于商业模式取决于恶意软件代码而不是攻击者的网络内部移动，商品攻击市场在采取更健壮防御措施（比如使用机器学习的安全系统）的企业面前，很大程度上是无效的。可以预测商用恶意软件工具将在2022年获得更大的成功，因为它们将被恶意攻击者用来对付采用较少安全防御措施的目标，以及较少来自其他网络罪犯的竞争。具体来说，可以预测中小企业使用的物联网设备将成为此类攻击的主要目标。因此，中小企业在选择供应商时必须更加挑剔，从拥有可靠补丁历史的制造商那里购买物联网设备更加有效。

中小企业很少有专门的安全团队，即使有，这些团队也可能受到资金有限的限制，因为网络安全只是一项运营费用。从全球来看，到2021年底，网络安全支出将超过1500亿美元，但中小企业每年在IT安全解决方案上的支出仅超过400亿美元，仍然是一个服务不足的市场。但是，一些中小企业可能比其他企业准备得更充分，那些更依赖网络、更依赖云服务和平台的公司，由于其业务性质，将更清楚地意识到商品恶意软件对其关键业务运营构成的风险。这些公司更有可能将安全问题作为议事日程的一部分，将网络安全解决方案列为销售成本的一部分。

NO.6【物联网威胁】  
  
  
  
     企业将努力增进网络监控和可见性，以保护其IT环境免受物联网威胁。

*   与物联网相关的信息将成为地下网络犯罪的热门商品，促使企业考虑可能导致数据泄露或篡改的安全漏洞。

大多数物联网设备有限的计算能力几乎没有为内置安全留出空间，这一事实使恶意攻击者长期以来对智能设备进行攻击一直抱有幻想，物联网设备可以遭受不同类型的攻击，例如分布式拒绝服务攻击。可以预测，诸如智能制造之类的一些公司，在向混合工作模式过渡并使用远程连接服务时,将遭遇更多的网络威胁。

为了保证运营的安全性，更多依赖于物联网设备的企业将转向入侵防御和检测系统(ips / ids)、网络取证工具(NFTs)、网络行为异常检测工具(NBAD)、以及网络检测和响应(NDR)工具，这些工具可以帮助他们密切关注来年网络的动态。依赖于第三方安全供应商的云采用者，将不得不警惕地跟踪他们对云资源的使用，以防任何异常活动，保护他们的虚拟私有云(VPC)免受云基础设施中可能发生的攻击，并审查潜在供应商的功能，以确保这些功能符合他们的需求。

但是到2022年，恶意行为者不再只把劫持物联网设备作为为其犯罪活动提供方便的基地，或者仅作为在网络中横向移动的手段，他们有更大的抱负。随着包括通用汽车、本田和丰田在内的越来越多的汽车制造商正从联网汽车提供的数据流量中获利，网络罪犯将对联网汽车实施攻击。这些汽车配备了一系列摄像头、激光和其他传感器，它们可以共同记录驾驶状况和驾驶员行为，包括汽车的驾驶速度和距离，以及乘客消费的娱乐媒体类型。这些实时数据为商业客户带来了无数商业应用，例如衡量广告的成功，衡量消费者的需求，以及基于驾驶数据确定汽车保险的折扣等，对于汽车制造商来说，这些数据也可用于监测汽车零部件的性能，这将增强他们自己的供应链。

对智能汽车信息的需求将成为一个蓬勃发展的新业务，预计到2030年，智能汽车信息的价值将达到450亿美元至7500亿美元，并且没有迹象显示其失去动力。随着越来越多的联网汽车上路，恶意攻击者正准备从不断增强的连通性中获利。可以预测，这将推动对非法数据过滤器的需求，这种过滤器可以阻止风险数据的报告，或者黑客可以从智能汽车的记录中删除不良驾驶记录。如果将智能汽车更复杂的数据收集功能和流程转移到云端，智能汽车的架构也可以进一步简化——事实上，许多较新的智能汽车模型所使用的应用程序和系统已经托管在后端云服务器上，但这样做可能会使汽车制造商面临其他威胁，如拒绝服务(DoS)和中间人(MitM)攻击。

如果汽车制造商想要他们的产品经得起未来的考验，那么在2022年，他们将需要与安全供应商密切合作，共同决定他们想要如何实现安全。这种伙伴关系的例子已经在进行中，比如，MIH（Mobility in Harmony：和谐移动 ) 联盟及其合作伙伴Arm、微软、趋势的早期倡议—开放电动汽车软件平台。大众和微软之间也有合作，寻求创建一个基于云的平台，汽车制造商可以使用该平台开发更先进、更安全的联网汽车自动驾驶解决方案。更多此类项目将为汽车行业开发智能汽车专用操作系统奠定基础，最终目标是建立一个基于统一操作系统的汽车生态系统，这将使未来的联网汽车模型都配备标准化的安全特性。

NO.7【供应链威胁】  
  
  
  
    当企业专注于通过多样化和区域化使他们的供应链更强大时，他们需要采取零信任原则，以保持他们的环境更安全

*   随着企业供应链运作的演变，全球供应链将成为四种勒索技术的目标。

2019冠状病毒大流行使供应链的脆弱性成为人们关注的焦点。大量的经济短缺是由几个因素造成的，包括需求的增加、集装箱和工人的短缺、以及对精益生产系统长达65年的依赖。当供应链问题开始成为世界范围内的负担时，供应链的价值也开始变得更加明显——不仅是苦苦挣扎的企业，对于不仅不受影响、反而从中受益的网络罪犯来说同样如此。尤其是今年，供应链攻击与勒索软件活动之间的联系越来越紧密，比如备受瞩目的REvil/Sodinokibi67对广达电脑(QuantaComputer)、JBS食品(JBS Foods)、和Kaseya等大型组织的攻击。

2022年，恶意攻击者将进一步利用并加剧供应链的破坏，并引发四重勒索模型的激增。持有受害者的关键数据以勒索赎金，威胁泄露数据并公布违规行为，威胁要追踪受害者的客户，以及攻击受害者的供应链或供应商，通过四倍勒索技术迫使知名受害者支付大笔金钱，进一步增强他们的网络攻击能力。

今年，网络犯罪组织DarkSide将矛头指向了美国最大的成品油管道系统ColonialPipeline。该组织阻止该公司访问其计算机系统，并窃取了超过100gb的公司数据。据观察，该组织一直在通过提供 DDoS 和呼叫中心服务来不断创新其攻击策略。这样做使得 DarkSide 分支机构能够推出可能严重影响供应链的四重勒索技术。因此，恶意攻击者可能拒绝访问制造机密等关键数据，拒绝访问用于生产中使用的机器，或联系客户和利益相关者，以迫使受害者组织支付费用。

供应链也将是访问即服务(AaaS)代理的重点。一旦脆弱的环境遭到破坏，AaaS代理就可以以不同的价格向网络犯罪分子出售公司的网络访问权限、管理帐户和身份验证凭证。

疫情引发的经济变化将推动企业投资于其供应链开发流程。他们将专注于通过多元化的方式建立更强健的供应链运营。多年来，各国一直支持全球化，这被批评为许多国家过度依赖单一地理来源获得供应的原因。供应链运营将从全球化向区域化转变，这有助于确保企业能够应对不断增加的需求和不稳定的生产成本。多样化战略对所有公司来说都是不同的——供应链中的一些环节将是本地的，而其他环节将是在不同的国家或地区。

然而，多样化并不是一件容易的事，这需要很大的努力。当组织寻找离家较近的供应商以降低经济风险并帮助维持业务运营时，他们可能也在不知不觉中向安全风险敞开了大门。与他们合作多年的长期供应商将被他们需要评估的新公司所取代，这些新供应商提供的云应用程序和服务的安全策略可能达不到标准，或者根本没有优先考虑云安全。

组织对其流程进行调整的时期非常关键——恶意攻击者可以发动有针对性的攻击，以利用与新伙伴不熟悉的特点。例如，一个攻击者可以冒充来自新供应商的某个人，发送一封鱼叉式网络钓鱼电子邮件，要求收件人在一个恶意网站上填写相关的公司信息。

随着公司战略的发展，为了保证供应链的安全，他们应该在安全实践中应用零信任方法。零信任模型有助于确保组织与其他公司进行交互和交换数据的方式，这些方式通过在连接的整个生命周期中进行持续的验证来实现。通过该模型，组织可以确保不断监控和评估与之交互的用户、设备、应用程序和服务的健康状况。

【安全建议】  
  
  
  
     安全专家对迫在眉睫的安全问题和安全技术进行研究和观察，对2022年可能出现的威胁和风险进行了预测。在处理这些问题时，将受益于全面的、多层次的网络安全策略，其中包括以下安全建议：

**坚持安全基础**。这看起来可能很简单，但是坚持安全基础可以帮助组织在未来的一年里对抗大多数的新旧威胁。恶意攻击者将继续利用系统和应用程序中的旧漏洞，因此，对组织来说，掌握他们的补丁管理策略是非常重要的。这将帮助它们避免数据泄露，进而避免昂贵的罚款和声誉损害。企业还应该理解和应用共享责任模型，并定期对关键数据进行加密。

**应用零信任模型以保证应用程序和环境的安全**。企业可以通过应用零信任模型来改善其安全状况，在此模型中，任何试图连接应用程序和系统的用户或设备都需要在被授予访问权限之前进行验证，并在之后继续进行验证——无论该用户或设备是否在网络内部。

**加强服务器安全并使用访问权限控制**。随着各组织转向混合工作模型，组织必须制定和实现疫情后无固定工作场所时的安全策略，即使员工从任何地方和不同的设备访问敏感或关键的办公程序和数据，访问控制和应用程序控制也可以使组织更好地处理其整体安全性。

**优先考虑可见性**。在未来的一年里，随着员工继续远程访问云应用程序、服务、系统和数据库，对组织来说，提高能见度以帮助加强网络安全防御是非常重要的。安全团队必须了解所有云提供商、帐户和服务，以便密切关注它们，并确保它们的配置尽可能安全。这将有助于减少意外暴露和错误配置的风险。

**通过正确的解决方案和专业水平，转向更强的安全性**。为了成功地保护系统和环境免受不断变化的威胁，组织需要灵活、自动化和先进的安全解决方案，以有效检测电子邮件、端点、网络、服务器和云工作负载中的攻击。
