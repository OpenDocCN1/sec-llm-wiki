NO.1 【摘要】


SideWinder（又名RattleSnake）是一个具有印度政府背景的APT组织，其主要目的是对南亚的多个国家进行间谍活动以满足印度政府的利益。其主要攻击的行业为南亚国家的国防和政府部门。

近期， Sidewinder 发起了一个针对巴基斯坦海军招募中心的攻击活动，通过鱼叉式网络钓鱼邮件投递恶意附件，使用了与以往活动稍有不同的DLL侧加载技术。他们利用合法的control.exe 可执行文件加载一个恶意的 DLL 。最终在受害者主机中植入 SideWinder 在过往攻击活动中使用的 RAT 以完成命令执行和数据外渗。

NO.2 【诱饵文档】


恶意附件在原始形式下的病毒引擎检出率非常低。在 Virus Total 上可以找到这个恶意附件的检测结果，如图 1 所示。

图 1: Virus Total 的样本检出结果

该诱饵文档在 Virus Total 上一个非常有趣的细节是：样本的上传地址位于巴基斯坦旁遮普省的拉瓦尔品第（Rawalpindi），也是巴基斯坦海军招募中心的所在地。诱饵文档的主题也与巴基斯坦海军相关的，文档内容要求支付巴基斯坦海军的阿兹玛特号与德哈特号上舰载雷达的维修费用，如图 2 所示。因此有理由相信，本次 SideWinder 的攻击目标很可能是这个巴基斯坦海军招募中心，而该中心在被攻击后在 Virus Total 上传了该诱饵文档样本。

图 2: 这次攻击中的Sidewinder 诱饵文档


NO.3【感染初期阶段】


一旦受害者打开诱饵文档并点击“Enable the Content”，该恶意文档将尝试使用模板注入的方法，从一个 URL 地址中下载一个投递器，如图3所示。 

图 3: 恶意文档通过模板注入的方法从该 URL 地址下载第二阶段的 RTF 文档


下载得到的 RTF 文件利用 CVE-2017-11882 漏洞，可以在其嵌入的第一个对象上启动 mshta.exe 工具以执行 hta 文件，如图 4 所示。

图 4: RTF 中嵌入的对象


图 4 中的 htm 文件 1.a 由一个 Javascript 片段组成，作为下一阶段的 dropper。JS 片段使用一种基于字符操作和移位的自定义算法进行混淆。这个JS片段嵌入了一段由 C# 编写的恶意有效载荷代码并被反序列化，使用 .NET 框架的函数加载到内存中。C# 代码 使用 "CreateInstance" 和 "Dynamic Invoke" 方法启动主类，然后调用恶意函数 “Work”并访问恶意URL。

图 5: JS代码片段

NO.4【感染中期阶段】


攻击者利用新下载的 DLL 来收集受害者系统的信息，在环境中实现持久化，并对 AV/EDR等安全产品进行规避。首先，该恶意 DLL 删除之前所有的感染痕迹，用字符串//FFFF替换了存储在%TEMP%中的 Javascript 内容，并删除了位于 INetCache 文件夹中用于存储临时文件的 Content.Word 文件。随后，它开始使用以下 wmic 命令收集受害者系统的版本信息。所有收集到的数据都以base64编码，并以 POST 的方式发送到C&C服务器（paknavy.edu-cx.org）上使用的URL如下：

感染中期 C&C URL

hxxps://paknavy.edu-cx.org/2862/1/35022/3/3/1/1819546697/KUFpgf2ZQguIEaCzyQ1fpeDGP9nll9OhfUtavT U5/files-4b55499f/1/cuui?data={BASE64_COLLECTED_DATA}

通过 HTTP 请求，恶意软件能够获得用于下一阶段感染活动的字符串和文件。恶意软件在C:\ProgramData\AtlasFiles 下创建了一个新的文件夹，其中存储了三个文件

• control.exe

• propsys.dll

• oihg1qyj.k3k

攻击者使用合法的可执行文件 control.exe 来完成 DLL侧加载，该文件是从 System32 或SysWow64 文件夹复制得到的。当 control.exe 被执行时，它会在同一内存空间中加载攻击者存储在同一文件夹中的恶意文件 propsys.dll。根据作为参数传递的 URL 中所包含的反病毒软件列表结果，DLL 会进行规避，以便不被发现，使用不同的方法来启动control.exe。

• 如果 URL 参数中包含卡巴斯基，则使用 mshta.exe 启动可执行程序。           

• 如果 URL 参数中包含 360，则使用 .NET 进程创建函数执行 control.exe。

• 其他情况下，则创建计划任务来执行 control.exe。              

恶意软件的持久化行为也会依据不同的安全防护软件指定不同的方法：

• 如果 URL 包含了 AVG 或 Avast，恶意软件会建立一个计划任务来在HKCU\Software\Microsoft\Windows\CurrentVersion\\Run 中创建一个名为 ATLASFILES 的注册表键，值为 control.exe 的路径：

               

• 如果 URL 包含了 360，恶意软件将 control.exe 的文件路径直接设置为HKCU\Software\Microsoft\Windows\CurrentVersion\Run。和 AVG 或 Avast 安防软件存在的情况类似，但不通过 schtasks.exe 的计划任务完成。

NO.5【感染末期阶段】


名为 propsys.dll 的 DLL 作为最终的加载器，以加密的方式包含在 oihg1qyj.k3k 中。用于解密该文件的程序由于多年来一直被 SideWinder APT 使用，因此早已在社区中公开。该加载器最终会植入一个 SideWinder 曾使用的远控工具（RAT）。该工具可以执行命令并渗出文件和系统信息。RAT 会与 C2 服务器进行通信。C2 的 URL 以加密的形式存储在 Default 资源。用于加解密该 URL 的算法和解密最终加载器的算法相同。

NO.6【总结】



通常情况下，随着地缘政治局势的加剧或者紧张，亦或是位于特定区域的特定团体在政治，经济或军事的利益增长，可以观察到以信息收集为目的的网络攻击行动的指数会随之增长。印巴两国的地缘政治问题由来已久，本文所描述的这次 SideWinder APT 攻击正是以印巴地区当前的紧张局势为背景展开的新一轮情报收集活动。
