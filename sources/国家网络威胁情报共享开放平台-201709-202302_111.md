# yoroi：UNC1945组织分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5MjEwNjQzNg==&mid=2247493003&idx=1&sn=276a6cfeeb790bcd782235984be3b9d0&chksm=fe266320c951ea36be51207906726621f985dd0cb0e8cc2ae051957c16f8bbdd1f5f6106ce40&scene=126&sessionid=1681275353#rd](http://mp.weixin.qq.com/s?__biz=MzU5MjEwNjQzNg==&mid=2247493003&idx=1&sn=276a6cfeeb790bcd782235984be3b9d0&chksm=fe266320c951ea36be51207906726621f985dd0cb0e8cc2ae051957c16f8bbdd1f5f6106ce40&scene=126&sessionid=1681275353#rd)

  

01

简介

![](../Images/0f97b741031ff3d893dd58b31ce530c6.png)

  

当今的网络犯罪团伙，主要针对商业机构进行攻击。很多威胁攻击者会利用现有的工具和技术，来开发破坏力更强大的新工具。本文介绍的是一个特定的网络犯罪组织的案例，该组织攻击目标明确，主要针对银行进行网络入侵。yoroi公司称，在过去的几年中，至少从2015年起，其研究人员就发现并追踪了一个特定的威胁组织。该组织针对欧洲，尤其是意大利的金融机构进行针对性攻击。另一家厂商Fireeye旗下的Mandiant公司，之前也发表了一篇关于该组织的报告，报告中将该网络犯罪组织命名为UNC1945（yoroi公司内部的名称为：TH-239），报告中介绍了他们最近的一项特定调查的结果，并提到该组织可以追溯到2018年的入侵，具体报告见：

> 《Fireeye Mandiant: UNC1945组织分析》
> 
> CNTIC情报组编译，公众号：国家网络威胁情报共享开放平台[Fireeye Mandiant: UNC1945组织分析](https://mp.weixin.qq.com/s/bFX2ucHAAHVOtKYpNgqWpw)

而yoroi的这篇报告，则着重分析该组织是如何将一个现代化网络军火库，移植到几十年前的旧系统的。

  

02

溯源

![](../Images/0f97b741031ff3d893dd58b31ce530c6.png)

  

目前认为该活动的组织者是已知的威胁攻击者，但具体是哪个组织尚无定论。实际上，即使根据Yoroi的情报信息可关联到Carbanak/Anunak romainan组织2015-2016年的活动，但仍然没有确凿的证据，证明这两个组织是否有关。尽管Mdiant最近报告的入侵事件的目的尚不明确，但有一点是非常清楚的：即该组织有能力进行长期持续的行动。虽然该勒索软件运营者有能力长期行动，但是研究人员发现他们的入侵活动通常不会持续太久。大多数入侵活动只持续了几周或至少几个月，原因很简单：持久性的活动对入侵者来说是非常危险的，而且可能会让他们失去整个盈利机会。yoroi根据历史推断，TH-239背后的攻击者是出于财务动机，在很多大型企业中，有些设备运行的是比较老旧的操作系统（例如旧的Red Hat，Solaris OS和其他Linux系统），攻击者在入侵这些企业时，已经做好了充分的准备。大多数勒索软件开发者，只对微软Windows环境比较熟悉。而该组织对其他系统的架构也很熟悉，因此具备了对金融机构和银行等，运行着复杂系统的庞大机构进行攻击的能力。  
标签：UNC1945组织，QEMU系统，虚拟武器库

  

03

技术分析

![](../Images/0f97b741031ff3d893dd58b31ce530c6.png)

  

为了和相关操作系统兼容，该组织使用了自定义QEMU linux虚拟机映像，其中包含了攻击中需要用到的必要工具，特别是他们的便携式虚拟武器库基于QEMU映像，如下图所示：

  

![](../Images/805ea8f6a127c9c69e5871b96d2f7a0b.png)

图1 虚拟武器工具结构

  

其中：

*   bios.bin：QEMU seabios，一个开源的x86 BIOS。
    
*   core：基于Tiny Linux的原始映像。
    
*   efi-e1000.rom：QEMU自定义的ROM映像。
    
*   en-us：美式键盘布局的映射文件。
    
*   hda.mini.qcow2：QEMU QCOW2映像（HD）。
    
*   kvmapic.bin：KVM内核APIC支持。
    
*   qemu-system-i386：QEMU PC系统仿真器；
    
*   start.sh：虚拟机的初始化脚本。
    

启动脚本的内容非常简单：

*   
*   
*   
*   
*   
*   
*   

```
!/bin/sh
if [ -z "$1" ] ;then      ./qemu-system-i386 -m 166 -kernel vmlinuz -initrd core -hda hda.mini.qcow2 -append "tce=sda1 home=sda1 opt=sda1 noswap nozswap superuser" -net nic -net user,tftp=/,hostfwd=tcp::2222-:22 -curseselse       ./qemu-system-i386 -m 166 -kernel vmlinuz -initrd core -hda hda.mini.qcow2 -append "tce=sda1 home=sda1 opt=sda1 noswap nozswap superuser" -net nic -net user,tftp=/,hostfwd=tcp::19227-:22 -vnc none >/dev/null 2>&1 &fi
```

  

bash脚本非常简单。它的目的是启动QEMU仿真器系统：如果未提供参数（$ 1），则脚本将使用显示库“ curses”执行第一个分支，以使客户端22端口转发到主机端2222。此设置是为了与通过主机2222连接的VM进行交互。如果没有任何参数，因为未列出“ curses”库并且已禁用VNC服务器，该脚本通过使用SSH来配置访问。但是，这两个分支都允许通过SSH协议进行通信，第一种情况是在端口2222上开始通信，第二种情况是在端口19227上开始通信。

  

04

QEMU系统

![](../Images/0f97b741031ff3d893dd58b31ce530c6.png)

  

QEMU启动后，显示界面如下图：

![](../Images/fc061ec8c9ac21bf02e261b3ab1c9872.png)  

图2 Arsenal 启动

攻击者采用特定的Linux发行版（Tinycore Linux 7.2），它是运行在4.2.9 Linux内核上的轻量级发行版。有趣的是，Tiny Core 7.2发行大约有4年的历史，但yoroi有证据表明，它在2020年仍是其网络武器的一部分。 由此，yoroi的研究人员认为虚拟QEMU环境的创建和配置是2016年，并且威胁参攻击者从那时起就一直在使用该技术。在浏览文件系统时，还发现了大量用于漏洞利用、特权升级、横向移动以及渗透的工具。

  

05

用户

![](../Images/0f97b741031ff3d893dd58b31ce530c6.png)

  

浏览所有文件系统并剖析每种恶意功能是具有挑战性的，因为需要探研究整个模块化VM，因此研究人员首先查看“ / etc / passwd”文件中包含哪些用户。

![](../Images/37ec04f7944e639756958d7d95c5f618.png)

图3 虚拟武器库用户配置

  

除了“ root”用户（Linux系统中具有最高权限的用户）之外，“ lp”和“ nobody”都没有特定权限；“ lp”是后台打印程序服务，“ nobody”是没有特权，yoroi的研究人员在磁盘映像中没有找到有关目录“/nonexistent”的任何内容。TinyCore Linux发行版的默认用户是“ tc”，默认密码为空，这是攻击者通常采用的用户。在“ / etc / fstab”配置文件中，“ TC”用户添加了三个条目，如下所示：

![](../Images/25749996982f5ede97cd3585c7e2db8e.png)

图4 FSTAB配置

  

根据QEMU系统管理应用程序的命令行，通过命令“ -append”提供了将设备添加到虚拟系统的模式，该命令的目的是将新的虚拟磁盘附加到TinyCore Linux系统上。 在虚拟磁盘内部，这个强大的威胁攻击者采用了完整的后渗透武器库，这种特殊的配置使其能够执行完全模块化的武器库。实际上，攻击者仅通过更换虚拟QCOW2磁盘就可以做到更新虚拟设备而使VM的核心保持不变。三个最重要的目录是“ deploy”，“ python”和“ responder”。

![](../Images/d44e16f9ca711bb7103aca699cabffab.png)

图5 TC用户文件夹结构

  

06

“Deploy”目录  

![](../Images/0f97b741031ff3d893dd58b31ce530c6.png)

  

该目录包含网络武库中的许多工具。它由许多类型的可执行二进制文件、脚本文件和压缩文件组成，例如.py、.exe、.txz或.js等后缀文件。这表明该存储库是虚拟武器库，最初是根据不同种类的计算机而设计的。

![](../Images/fa6c4451fb4226eecede02c17147e192.png)

图6 “Deploy”目录内容

  

该目录中的许多子文件夹引用了已知的工具，其中大多数是公开可用的。例如：

*   LaZagne：从异构环境（例如微软的 Windows，基于Linux的系统和Apple的OSX）中收集凭据的工具。
    
*   UACME：绕过微软Windows环境上用户访问控制限制的工具。
    
*   Mimikatz：也许是现在最流行的漏洞利用和特权升级工具。
    
*   Bcwipe：一种合法的数据擦除软件，能够以不可恢复的方式永久性和有选择地删除文件，这表明该组织特别注重隐身性。 
    
*   procdump：sysinternal命令行实用程序，用于监视和转储进程内存。
    
*   Screen和screen\_xp：包含自定义识别工具，以监视其目标的桌面屏幕。  
    
*   tshd：包含TinyShell后门-典型的unix工具-但针对Windows环境进行了定制和编译。
    

![](../Images/7f4d923247d25245afcc8792c0211852.png)

图7 动态捕获客户端屏幕的工具

  

![](../Images/3b44f10eeccccb81321ade7d2e813654.png)

图8 针对Windows系统定制的TSHD后门

  

还有一些静态编译的工具，例如winexe。原因是拥有独立且可以执行的工具，并且不需要在目标计算机上进行任何其他安装。

08

“Responder”目录

![](../Images/0f97b741031ff3d893dd58b31ce530c6.png)

  

此文件夹中存放同名的“ Responder”工具。“ Responder”是由Laurent Gaffie编写的LLMNR / NBT-NS / mDNS Poisoner，并且能够在本地子网中在线侦听NetBIOS名称服务（NetBIOS）和链接本地多播名称解析（LLMNR）广播以及来自其他计算机的主机名的多播请求 ”。使用正确的参数执行后，便可以在NetBios和LLMNR上进行监听，以窃取NTLMv1 / v2密码哈希。  攻击者的网络武器库中存在着这种工具，这意味着该威胁组织确实非常危险。在公司网络中，中间人攻击是其作案手法的一部分，因此，在隔离措施不足的网络中进行入侵就会很危险。无论如何，Responder工具包的2.3版本可以追溯到2016年，这表明该工具是在虚拟武器库上安装的首批工具之一。

09

虚拟武器库能力

![](../Images/0f97b741031ff3d893dd58b31ce530c6.png)

  

经过分析，yoroi确定了恶意虚拟机中存储的所有工具，并能够将它们分类为以下类别：

*   枚举（T1261）：
    

*   使用工具通过各种协议（例如LPAD，NETBIOS，Active Directory和RPC）枚举用户。
    

*   网络通讯（TA0011）：
    

*   使用tcp，tftp，http隧道进行网络通信
    
*   数据包处理工具，例如Inpacket或Scapy
    

*   操作系统凭证转储（T1003）：
    

*   通过LaZagne等开源工具收集存储在用户和系统配置中的凭据。
    
*   使用Mimikatz等升级工具或系统进程转储，并绕过UAC等操作系统保护，以获得更高的特权和身份验证令牌。 
    

*   漏洞利用（T1404）：
    

*   破坏了滥用的1-Day漏洞（例如MS17-010）的远程系统。
    

*   中间人攻击（T1557）：
    

*   将他们的目标与“中间人”攻击相结合，以操纵网络交互来获取哈希和令牌（例如，通过“Responder”）
    

*   现成工具（T1218）：
    

*   许多合法的工具（例如sysinternal工具（例如“ procdump”））都可以在工具包中被滥用，Linux工具（例如“ winexe”，“ find”，“ touch”，“ grep”，“ head”，“ less”或“ wget”）也已经交叉编译，可以在Windows环境中进行部署了。   
    

它们都用不同的方式(静态或动态)编译，并用不同的语言(javascript、汇编语言、python等)编写。该TTP证实了QEMU虚拟机是一个完整的漏洞利用框架媒介，可以根据攻击者的各种需求进行定制。如果考虑经典的洛克希德·马丁公司网络杀伤链，可以配置虚拟机的中期和最新阶段，即“横向移动”和“行动和目标”。实际上，QEMU虚拟机是由攻击者通过SSH隧道手动控制的，已被用作一个功能强大的框架。

  

10  

结论

![](../Images/0f97b741031ff3d893dd58b31ce530c6.png)

  

这种基于QEMU的虚拟武器库并不是该威胁者攻击的唯一工具。他们也能够利用0day漏洞（比如在预警公告中描述的CVE-2020-14871 N031120），并利用完全自定义的植入和工具，实现入侵和横向移动，即使在隔离措施最好的网络中也是如此。同样，该组织的定制能力很显著，在虚拟武器库中观察到的thsd后门的定制只是他们作案手法的一小部分。
