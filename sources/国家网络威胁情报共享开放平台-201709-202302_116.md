# ESET：拉撒路在韩国的供应链攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5MjEwNjQzNg==&mid=2247492761&idx=1&sn=bccc87d09225123c23069539ebadc64e&chksm=fe266232c951eb24c6b83662ec86f14a0986875910b416f30b2beeb18bc0199bd1101195b458&scene=126&sessionid=1681275358#rd](http://mp.weixin.qq.com/s?__biz=MzU5MjEwNjQzNg==&mid=2247492761&idx=1&sn=bccc87d09225123c23069539ebadc64e&chksm=fe266232c951eb24c6b83662ec86f14a0986875910b416f30b2beeb18bc0199bd1101195b458&scene=126&sessionid=1681275358#rd)

ESET的研究人员最近根据检测的数据发现，拉撒路组织试图通过供应链攻击，在韩国部署恶意软件。为了传递恶意软件，攻击者使用了一种与以往不同的供应链机制，滥用合法的韩国安全软件和从两家不同公司窃取的数字证书。  

  

# 01

  

  

拉撒路工具集

  

2016年2月，拉撒路（Lazarus）组织首次出现在诺维塔（Novetta）的报告“Operation Blockbuster”中， US-CERT和FBI将该组称为“ HIDDEN COBRA”。这个攻击组织因攻击索尼影业而声名鹊起。过去归因于拉撒路组织的一些攻击吸引了安全研究人员的兴趣，他们依据Novetta公司发表的白皮书继续追踪拉撒路组织，其中数百页描述了攻击所使用的工具，包括针对波兰和墨西哥的银行的攻击、WannaCryptor爆发、利用网络钓鱼攻击美国国防承包商、针对中美洲赌场的拉撒路 KillDisk攻击等，并为将这些攻击归因于拉撒路组织提供了依据。需要注意的是，拉撒路工具集(即安全行业认为可以作为该组织活动痕迹的所有文件的集合)非常广泛，ESET认为拉撒路组织内部分成了很多小组。与其他一些网络犯罪组织使用的工具不同，拉撒路组织工具的源代码从来没有公开泄露过。  
  

# 02

  

  

最新的拉撒路供应链攻击

  

要了解这种新颖的供应链攻击，就需要了解 WIZVERA VeraPort应用程序，是一个韩国的集成安装程序。韩国互联网用户在访问政府或互联网银行网站时经常会被要求安装额外的安全组件，WIZVERA VeraPort可帮助用户安装这些附加的组件。（例如，浏览器插件，安全软件，身份验证软件等）。  

![](../Images/c86459bf9f4ffe025c1a4f1b6726f367.png)

图1. 在安装其他软件时向用户显示的WIZVERA VeraPort窗口

  
拉撒路组织滥用了VeraPort的安装机制，通过攻陷合法网站，植入恶意软件。从而使用户电脑上VeraPort客户端下载到恶意软件。 但是，使用此方式将恶意软件植入用户计算机，必须同时满足以下条件：

*   受害者必须安装WIZVERA VeraPort客户端
    
*   受害者必须访问安装了WIZVERA VeraPort服务端的被攻陷网站
    
*   该网站的VeraPort配置文件中必须包含特定条目，攻击者才能用其恶意软件替换VeraPort软件包中的常规软件
    

  
需要注意是，ESET的研究人员的分析认为这些供应链攻击发生在使用WIZVERA VeraPort的网站上，而不是在WIZVERA软件本身上。支持WIZVERA VeraPort软件的网站包含服务器端组件，尤其是一些JavaScript和WIZVERA配置文件。这些配置文件是base64编码的XML，包含网站地址，需要安装、下载URL的软件列表以及其他参数。

![](../Images/9607dd69debd831b7b39a9fe76d45401.png)

图2. WIZVERA VeraPort配置的示例（由ESET编辑）

  

WIZVERA对这些配置文件添加了数字签名。被下载后，就会使用强大的加密算法（RSA）进行验证，这就是为什么攻击者无法轻松修改这些配置文件的内容或建立自己的假网站的原因。虽然配置文件中的下载链接无法被修改，但是攻击者可以替换下载链接指向的组件。这会导致受害者客户端访问正确的下载链接，但是下载到的却是已经被替换了的恶意软件。绕过了配置文件的签名校验。ESET的研究人员认为这也是拉撒路攻击者使用的方案。

![](../Images/ca343168ac568e0c30a7cc853da971b4.png)

**图3. 拉撒路组织WIZVERA供应链攻击流程图示**  

应当注意，WIZVERA VeraPort配置包含一个选项，可以在运行已下载的二进制文件之前对其进行数字签名验证，并且在大多数情况下，默认启用此选项。但是，VeraPort仅验证数字签名是否有效，而不检查它属于谁。因此，要滥用WIZVERA VeraPort，攻击者必须具有任何有效的数字证书，或者能够找到关闭VeraPort对数字签名进行验证的配置选项，才能通过此方法投递恶意载荷。到目前为止，ESET的研究人员已经观察到使用此供应链攻击提供的两个恶意软件样本，并且都已签名：

| SHA-1 || 文件名 || 数字签名 |
| --- | --- | --- |
| 3D311117D09F4A6AD300E471C2FB2B3C63344B1D ||   
Delfino.exe || ALEXIS SECURITY GROUP, LLC |
| 3ABFEC6FC3445759730789D4322B0BE73DC695C7 || MagicLineNPIZ.exe || DREAM SECURITY USA INC |

攻击者使用非法获取的代码签名证书来对恶意软件样本进行签名。有趣的是，其中一张证书已颁发给韩国一家安全公司的美国分支机构。

![](../Images/0ec8b47b3e9500d64d641d54b715c35f.png)

图4.ALEXIS SECURITY GROUP，用于签署拉撒路恶意软件的LLC代码签名证书

  

![](../Images/74ef869085e8c599c0ecdaf349b53960.png)

图5.用于签署拉撒路恶意软件的DREAM SECURITY USA INC代码签名证书

  

拉撒路组织将恶意软件样本伪装成合法软件。这些样本的文件名、图标与合法软件的相似。通过WIZVERA VeraPort软件的下载机制将恶意二进制文件存储在％Temp％\\ \[12位的随机数\] \\ 目录中。  
WIZVERA VeraPort的配置不仅可以验证数字签名，还可以验证下载的二进制文件的哈希。如果启用此选项，即使攻击者攻陷了运行WIZVERA VeraPort服务端的网站，也无法轻松地进行这种攻击。

  

  

# 03

  

归因

  

ESET的研究人员将这次供应链攻击归因于拉撒路组织，基于以下几个方面：

1.  业界共识：当前的攻击是被韩国互联网应急中心（KrCERT）称为“Bookcodes行动”的延续。尽管KrCERT尚未将该活动归因于拉撒路组织，但卡巴斯基在其有关2020年第二季度APT趋势的报告中提到了。
    
2.  工具集特征和检测：
    

*   最初的dropper是一个控制台应用程序，它需要正确的参数才能执行后续步骤，针对波兰和墨西哥银行的水坑攻击中曾使用这种方式。
    
*   最终的恶意载荷是一个远控木马，使用TCP通信，控制命令是32位的整数。
    
*   此次供应链攻击中投递的一些恶意模块，ESET的报毒名为NukeSped。下文中“恶意软件分析”里面介绍了一个含有数字签名的下载者模块，此模块下载的样本 （878F0D9053CCD81B4589CECAEFC306CF2）与之前Blockbuster行动中的样本（CB818BE1FCE5393A83FBFCB3B6F4AC5A3B5B8A4B）有关联。它们都使用异或0x23的方式解密API函数名。例如dFWwLHFMjMELQNBWJLM异或解密后为GetTokenInformation。
    

3.  受害者研究：拉撒路组织对韩国受害者进行攻击已有很长的历史，例如Troy行动。包括2011年的DDoS攻击“ Ten Days of Rain”、2013年针对韩国网络的攻击，以及2017年针对韩国加密货币交易所的攻击。
    
4.  网络基础结构：KrCERT的白皮书＃2 详细地介绍了此攻击组织服务端的WebShell技术和C＆C服务器的组织架构。当前的活动也使用了非常相似的设置。
    
5.  其他方法：
    

*   在入侵方法中：不寻常的渗透方法是一个线索，可以归因于像拉撒路这样的成熟而专业的组织。过去可以发现该组织如何利用在特定网络中存在的软件漏洞，而在其他的APT攻击者活动中都没有发现该漏洞。例如，通过ManageEngine Desktop Central软件传递的“ A Strange Coinminer”案例。
    
*   在加密方法上：在针对波兰和墨西哥银行的水坑攻击中，发现了RC4的Spritz变体；后来，拉撒组织在Operation In(ter)ception中使用了改良的RC4。在此活动中，它是一种经过修改的A5 / 1流密码，在许多情况下会降级为单字节XOR。

# 06

  

  

含有数字签名的下载者模块

  

此模块是利用上文中提到的VeraPort下载而来。此模块使用Themida加壳，可以下载、解密和执行内存中的其他有效负载，而无需将它们放到磁盘上。该下载器将HTTP POST请求发送到硬编码的C＆C服务器，使用RC4算法解密服务器的响应，然后使用自己的PE文件加载程序在内存中执行恶意程序。

# 08

  

加载器

  

此组件使用了Themida加壳保护，研究人员推测使用的是Themida2.0-2.5版本，这与KrCERT的报告(第20页)一致。这个加载器的功能是，从自身资源中解密出恶意程序，注入到指定进程中。注入的目标进程和注入的方法与Dropper相同。此模块还创建了一个名称为“Global\\RRfreshRA\_Mutex\_Object”的互斥体。

  

# 09

  

  

下载器，又名WinHttpClient

  

如上文所述，此模块由Dropper释放，由加载器注入到指定服务进程。它的主要功能是传递后续阶段的恶意载荷到受害者的计算机。使用HTTP协议，但需要经过几个阶段才能建立可信连接。该恶意软件会通过指纹识别受害者的系统，如图9：

![](../Images/680e9c7f328add9bcb971f11c6f4e1ff.png)

图9.缓冲区的长度为0x114，其中包含活动ID，本地IP地址，Windows版本，处理器版本（请参阅KrCERT第59页，图\[4-17\]）

  

第一步是授权。发送随机生成的通用参数代码和ID后，预期的响应以<！DOCTYPE HTML PUBLIC Authentication En>开头，后面试其他以分号分隔的数据。但是，在下一个POST请求中，就已经是基于受害者IP的参数。因为不知道针对哪些受害者，所以在调查期间，总是收到“Not Found”回答，而不是“OK”。

![](../Images/8f7f62ea3b72c7abc9cc07bdebc74c2c.png)

图10.与具有通用参数代码和ID的C＆C的主要消息交换

  

![](../Images/e47c2dfa445e59662a48031b769e1d77.png)

图11.与具有特定参数名称的C＆C的辅助消息交换

  

如果受害者通过了这些介绍性消息并确认了连接，则解密后的响应将以一个有趣的组件开始：关键字ohayogonbangwa !!。目前尚未在互联网上找到该词，但最接近的含义可能是“ Ohayo，Konbangwa”（おはようこんばんぐぁ），日语中的意思是“早上好，晚上好”。从这开始，交换了更多的消息，最终的交换请求将可执行文件加载到了内存中。

# 10

  

  

最终的恶意载荷是远控木马（RAT）

  

这是拉撒路组织曾使用过的典型远控木马。此木马的功能包括对受害者文件的操作，以及从攻击者的服务器下载和执行其他恶意模块。控制命令的格式为32位整数，与KrCERT发表的报告第61页中的内容一致。

# 11

  

结论

  

攻击者一直在努力寻找将恶意软件传播到目标计算机的新方法。攻击者对供应链攻击特别感兴趣，因为供应链攻击可以使他们同时秘密地在多台计算机上部署恶意软件。ESET研究人员预测，未来供应链攻击的数量将会增加，特别是针对服务在特定区域或特定行业中的公司。
