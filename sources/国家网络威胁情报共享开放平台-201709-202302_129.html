一、简介



Check Point Research 的研究揭示了伊朗多年来一直在对伊朗侨民和持不同政见者进行监视的活动。此前，其他研究人员和记者曾报道过一些零星的攻击事件，但Check Point Research 的调查能够将这些活动联系起来，并将其归因为同一攻击者。

Check Point Research 发现了不同的攻击载体：

  • 信息窃取程序Windows版本的四个变种，旨在窃取受害者的个人文档，访问受害者的即时通讯软件Telegram桌面版和密码管理工具KeePass。

  • 安卓版的后门程序，具有从短信中获取到双因素身份验证码，监听手机的话筒等功能。

  • 使用伪造的 Telegram服务帐户分发的Telegram网络钓鱼页面。

上述的工具和方法似乎主要用于攻击伊朗少数民族、反政权组织和抵抗运动，例如:

  • 阿什拉夫营地和自由居民家庭协会（AFALR）

  • 阿塞拜疆国家抵抗组织

  • 俾路支人




二、初次感染



原作者第一次遇到了一个名称为وحشت_رژیم_از_گسترش_کانونهای_شورشی.docx的文档。这句话的大致翻译为 The Regime Fears the Spread of the Revolutionary Cannons.docx。文件的标题实际上指的是伊朗政权与伊朗人民圣战者组织(Mujahedin-e Khalq)之间进行的斗争。

伊朗人民圣战者组织(Mujahedin-e Khalq)是一个反政府组织，其目的是使伊朗摆脱目前的领导。1986年，Mujahedin-e Khalq（MEK）开始在伊拉克小镇哈利斯附近，建造他们的新总部，这里后来被称为阿什拉夫营地。然而，伊拉克多年的政治紧张局势最终导致该营地的居民转移到一个新的偏远的且不太可能的目的地：阿尔巴尼亚。

上面的文档利用了外部模板技术，允许它从远程服务器加载文档模板，这个样本访问的服务器域名为 afalr-sharepoint[.]com。

三、感染链



当受害者打开文档并下载了远程模板后，模板中的恶意宏代码会执行一个批处理脚本，该脚本会试图从 afalr-sharepoint[.]com下载并执行下一阶段的恶意程序：

图4：感染链

然后，有效载荷会检查受感染的计算机上是否安装了Telegram，如果是，它将继续从其资源中提取另外三个可执行文件：

  • BOBC3953C59DA7870 – 加载器，由 RunDLL 执行，将恶意程序的主模块注入 explorer.exe

  • CO9D5A739B85C37C1 – 信息窃取的有效载荷

  • Updater.exe – 修改过的Telegram更新程序



四、有效载荷分析



该恶意软件的主要功能包括：

  • 信息窃取

    • 从受害者的计算机上传相关的 Telegram文件。 
    • 这些文件使攻击者可以充分利用受害者的Telegram帐户。
    • 从KeePass应用程序中窃取信息。
    • 上传任何它能找到的以预定义扩展名结尾的文件。
    • 记录剪贴板数据并获取桌面截图。

  • 模块下载器

    • 下载并安装其他几个模块。

  • 独特的持久性

    • 实现了一种基于Telegram内部更新过程的持久性机制。

3. C&C通信


该恶意软件使用SOAP进行通信。SOAP是用于Web服务通信的基于XML的简单数据结构。SOAP服务的API是公开的，可以通过浏览器来访问：

图7：C＆C网站中的SOAP API


消息(命令)可分为以下几类：

  • 身份验证：

    • HelloWorld – 身份验证消息

  • 模块下载：

    • DownloadFileSize – 检查是否应该下载模块

    • DownloadFile – 从远程服务器下载模块

  • 数据窃取：

    • UploadFileExist – 检查是否已上传特定的受害者文件

    • UploadFile – 上传一个特定的受害者文件

(1) 认证方式

有效通信频道的第一个消息应该是 HelloWorld，它实现了简单的用户名/密码身份验证。在示例中，凭据是硬编码的，并且该消息的SOAP响应包含一个会话ID，该会话ID必须用于其余的会话。

(2) 模块下载

该程序尝试获取其当前模块的更新，并下载几个其他模块。

一些额外的缺失模块无法获取：

  • D07C9D5A79B85C331.dll

  • EO333A57C7C97CDF1

  • EO3A7C3397CDF57C1

(3) 数据窃取

该恶意软件的核心功能是从目标设备中窃取尽可能多的信息。有效载荷主要针对两个应用程序：Telegram Desktop和著名的密码管理器KeePass。

一旦上传了相关的Telegram Desktop和KeePass文件，该恶意软件就会枚举可在受害人的计算机上找到的任何具有以下扩展名之一的相关文件： .txt;.csv;.kdbx;.xls;.xlsx;.ppt;.pptx;。对于每个这样的文件，恶意软件通过base64算法编码之后上传。


4. 持久性


该恶意软件使用一种独特的持久性方法，该方法与Telegram更新程序相关。

它定期将Telegram的主可执行文件复制到 Telegram Desktop\tupdates中，一旦启动，它将触发Telegram应用的更新程序。恶意软件持久性方法的一个隐藏技巧是更改默认的Telegram更新程序文件– Telegram Desktop\Updater.exe，并删除其中一个有效载荷(具体为- CO79B3A985C5C7D30）。该更新程序最显著的变化特性是再次运行有效载荷：

九、归因


虽然Check Point Research发现了多年来在此攻击中使用过的许多文件和网站，但它们并不是来自特定的威胁集团或实体。尽管如此，可以从威胁行动者在恶意组件中留下的一些指纹来推断攻击可能来自何处。


1. 攻击来源


首先，一些恶意网站的WHOIS信息显示，它们可能是由伊朗个人注册的:

图18：endupload[.]com  和 picfile[.]net的WHOIS信息



endupload[.]com 的WHOIS记录还提到了一个电子邮件地址 nobody.gu3st@gmail[.]com。显然，该网站的注册用户在网上非常活跃，因为在伊朗黑客论坛上查找用户名“ nobody.gu3st ”发现了很多帖子：

图19：nobody.gu3st翻译的帖子

2. 政治目标


Check Point Research观察到的目标清单反映了一些伊朗内部的斗争和这次袭击背后的动机。他们精心挑选的目标包括圣战者组织和阿塞拜疆民族抵抗组织的支持者，这两个著名的抵抗运动提倡解放伊朗人民和伊朗境内的少数民族。

图20:Mujahedin-e Khalq和阿塞拜疆民族抵抗组织的标志


这些运动与伊朗当局之间的意识形态冲突使它们成为这种攻击的自然目标，因为它们与该政权的政治目标是一致的。

此外，后门的功能以及窃取敏感文件、访问KeePass和Telegram账户这些重点表明，攻击者对收集受害者的情报、了解他们的更多活动很感兴趣。




十、结论


根据这次攻击的踪迹可以发现，这次大规模的行动在很大程度上成功地隐藏了至少6年。根据Check Point Research收集到的证据，这些似乎来自伊朗的攻击者利用多种攻击载体暗中监视他们的受害者以及他们的个人电脑和移动设备。

由于Check Point Research确定的大多数目标都是伊朗人，似乎与其他伊斯兰共和国发动的袭击类似，这可能是伊朗的威胁行动者正在收集关于该组织潜在对手的情报。



十一、技术附录


1. PC后门变种分析


(1) TelB变种

“ TelB”是Check Point Research遇到的最新变种，其分析见上文。之所以这样命名是因为以下调试字符串： D:\Aslan\Delphi\TelB\BMainWork\SynCryptoEN.pas 。


(2) TelAndExt变种

此变种可能是“ TelB”的旧版本，并且主要在2019年和2020年处于活跃状态。它与新版本都具有以下特征和技术：

  • 在Delphi中开发

  • 与“ TelB”变种共享大量代码

  • 专门针对Telegram Desktop应用程序

  • 类似的持久性和更新方法

  • 使用FTP而不是SOAP进行数据窃取

Check Point Research将这个变量命名为“TelAndExt”，因为以下调试字符串: D:\Aslan\Delphi\TelAndExt\TelegramUpdater\SynCryptoEN.pas


(3) Python信息窃取器变种分析

Check Point Research发现了一些使用以下方法的样本：

  • 双层SFX（自解压存档），可提取多个.bat / .vbs / .nfs / .conf文件。

  • 通过将可执行文件（以 .nfs结尾）复制到

  • %appdata%\Microsoft\Windows\Start Menu\Programs\Startup\audio-driver.exe来维持持久性。

  • 可执行名称为 speaker-audio.exe 还是 keyboard-EN.exe，取决于样本。

  • 该可执行文件是用Pyinstaller创建的。

  • 下载名为net-update.exe的第二阶段有效载荷。

  • 在上传之前，使用带有硬编码密码的库pyAesCrypt对数据进行加密。


a. 信息窃取

据Check Point Research的分析，该脚本使用硬编码的凭据与FTP服务器通信，并窃取以下数据：

Telegram Desktop应用程序相关文件。

Paltalk NG应用程序相关文件。

Chrome，Firefox和Edge的相关数据。

在给定配置中列出的扩展名结尾的任何文件。如果没有给出配置，它会搜索以下扩展名的文件:.txt;.docx;.doc;.exe;.jpg;.html;.zip;.pdf。


b. 操作

在调查过程中，Check Point Research发现了几个Python信息窃取器与同一台FTP服务器通信，但是将窃取的信息以不同的别名存储在不同的页面中。


Check Point Research怀疑这是恶意软件作者的操作方式：

  • 选择一个目标，并在FTP服务器中为它们创建一个指定的文件夹。

  • 使用针对数据上传的唯一AES密钥和FTP凭证构建针对目标定制的样本。

  • 通过一个感染链负载向量提供武器化的可执行文件。


c. 第二阶段有效载荷– HookInjEx

它的核心功能之一是获取第二阶段的有效载荷。如果指定的FTP文件夹包含名为 net-update.exe的文件，则它将下载并执行该文件。

Check Point Research分析了一些 net-update.exe 示例，发现它与下面的“HookInjEx”变种完全重叠，从而使其成为更有针对性的高级有效载荷。


(4) HookInjEx变种

该变种自2014年以来一直在使用，并具有32位和64位版本。随着时间的推移，该变种不断演变并添加了一些功能，同时还更改了其感染链中不同组件的名称。


a. 感染链

Check Point Research发现了两种主要的感染链:

  1. SFX（自解压存档）包含所有组件。它将所有这些文件放入一个文件夹中，然后执行主加载程序–  DrvUpdt.exe （旧版本中为ehtmlh.exe ）。

d. 持久性

该恶意软件将配置文件的 <Reg> 值中的注册表项(这几乎总是 RunOnce 的键)设置为以下值——将其名称设置为 SunJavaHtml 或DevNicJava ，其值为 DrvUpdt.exe 11。这样恶意软件就知道它已经被执行了。


在旧版本中，该恶意软件用来提取名为 rreegg.exe 或Capdev.exe的文件。它被添加到 RunOnce 中，然后依次执行 DrvUpdt.exe 11。


e. 信息窃取

该恶意软件的主要功能是从受害者的计算机中窃取信息，然后使用FTP将其发送到C2。


该恶意软件窃取了不同类型的数据：

  • Opera / Chrome / Firefox登录数据。

  • Firefox信息：配置文件，密钥和数据库文件。

  • tracert www.google.com的输出

  • WHOIS信息（基于 <Ws1> 的值）。

  • 前台窗口的屏幕截图和标题。

  • 一分钟的波形音频记录。

  • 来自可移动驱动程序的文件。文件类型基于文件 Devufl1.tmp（在较早版本中为winufl1.tmp）中的 <cpy> 标记。在某些版本中，该逻辑是在名为 uflscan.exe的文件中实现的。有趣的是，如果驱动程序名称是以下之一： A65RT52WE3F， 09353536557 或 transcend20276，恶意软件就会终止线程。Check Point Research 认为这是一个永久存在的调试代码（图22），其目的是防止恶意软件从作者的计算机中收集文件。

  • 来自其他驱动器的基于 Devufl2.tmp(旧版本为winufl2.tmp )文件中 <cpy> 标记的文件。

  • 各种格式的键盘记录和剪贴板数据-拖放/  CF_HDROP， CF_TEXT， CF_TEXT， CF_UNICODETEXT，虚拟键代码， CF_OEMTEXT， CF_LOCALE， CF_BITMAP 和 CF_DIB。

  • 从2018年开始 -Telegram Desktop数据。

f. C2通信

此变种使用FTP协议将文件上传到其C2域。FTP域位于 <S_n> 标记内的配置文件中。

连接首先使用配置文件中的密码和用户名进行身份验证。

然后，该恶意软件根据 <F_f> 标记创建一个目录，使用之前生成的用户id创建一个子目录。用户id是根据写入文件 Mcdata.dat （旧版本中为PAdata.dat ）的网络适配器信息生成的。

2. Android后门分析


第一个活动是MainActivity，它负责向用户提供诱饵内容并请求执行特权活动的权限。它还启动一个名为MainService的后台服务，并在服务器发送命令时启动第二个 MainActivityFake (GmailActivity)。

(1) 数据收集

一旦 GmailActivity 启动了 GmailActivity ，它将依次负责以下任务：计时器注册、配置监视、显示虚假通知(如下所示)和敏感数据收集。

在初始数据收集过程中，将读取并准备以下信息：

  • 已安装的应用程序列表

  • 账户信息

  • 短信

  • 联系人信息

从C＆C服务器收到命令后，其余信息将按需收集：

  • 录音–默认情况下为30秒录音。

(2) Google凭据窃取

从C＆C服务器收到正确的命令后，通过激活 MainActivityFake (GmailActivity)，向受害者显示Google登录页面。

如前所述，它的核心功能之一是打开麦克风并记录周围环境。为了实时实现这一目标，应用程序需要在后台运行其服务。

任何想要执行此类操作的Android应用程序都需要向用户发布正在进行的通知，提醒用户设备上有未启动的活动。为了规避这个问题，恶意软件开发者选择向用户显示一个“已启用Google保护”的假通知。
