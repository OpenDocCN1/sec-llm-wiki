# DarkCrewFriends构建僵尸网络用于盈利

 **一、简介**  

最近Check Point研究人员发现一个由知名黑客组织“DarkCrewFriends”发起的黑客活动。该活动主要针对PHP服务器，重点是创建僵尸网络基础设施，该基础设施可用于多种目的，如盈利和关闭关键服务。

DarkCrewFriends在过去的几年里非常活跃。该组织提供许多网络服务，并被认为是造成意大利一家新闻网站数据泄露的责任方。

当前活动的攻击链包括利用一个不受限制的文件上传漏洞、上传一个恶意的PHP webshell以及使用IRC通道与C&C服务器通信。攻击者可以在各种情况下利用该恶意软件实现不同的功能，例如发起不同类型的DDoS攻击和shell命令执行。

![](../Images/ea134f327ceb74a55ae465908caa5249.png)

  **二、****攻击链**

这次活动的攻击链包括以下几个步骤：

![](../Images/f88e1084999ff878b90351208713230b.png)

**(1)漏洞利用**

在最初的分析中，原作者在受害者的服务器上检测到PHP后门。这些PHP Web Shell文件由攻击者上传到易受攻击的服务器。

许多应用程序允许用户将某些文件（例如图像或文档）上传到他们的服务器。如果处理不当，这些文件可能会使系统面临风险。远程攻击者可以绕过服务器的文件扩展名检查，将特制的请求发送到易受攻击的服务器并上传不受限制的文件。这最终可能使攻击者可以在被攻击系统上执行任意代码。

根据原作者的研究，受害者的服务器大多数是内容管理系统。这些平台有多个不受限制的文件上传漏洞，攻击者可以将恶意文件上传到这些易受攻击服务器。这些漏洞存在一个由DarkCrewFriends创建和发布的EXP。

**(6)恶意软件分析**  

该恶意软件具有广泛的功能，包括：

*   同时打开多个进程。
    
*   暂停脚本以避免被检测。
    
*   执行shell命令。
    
*   提取主机上所有正在运行的服务。
    
*   下载/上传FTP文件。
    
*   扫描打开的端口。
    
*   进行多种DDos攻击
    
*   执行多个IRC命令
    

该恶意软件使用IRC(Internet Relay Chat)协议进行通信。IRC包含各种命令，以允许用户在IRC通道中执行某些操作。恶意软件选择了这些命令来执行其攻击活动。此外，恶意软件还使用IRC命令感染或者攻击其他IRC服务器，并与远程c&c服务器通信。

如上文所述，该恶意软件支持各种DDoS攻击，并且可以通过PRIVMSG (IRC用户之间私密消息传输协议)将相关攻击类型的菜单发送给恶意软件操作人员。最后，受害服务器从c&c的应答中获取所需的操作。

**(7)安全影响**

该恶意软件具有多种攻击类型和手段，可用于实现各种目的。例如可以用来窃取敏感信息，破坏受影响的系统，甚至使系统完全崩溃。根据上述恶意软件分析中描述的各种场景和攻击方法，原作者得出结论，该恶意软件对受害者基础设施的影响可能很严重。

** 三、总结**  

原作者一直在跟踪DarkCrew Friends开展的一项不断发展的新活动，该活动针对PHP服务器以创建庞大的僵尸网络基础结构。关联的僵尸网络具有广泛的攻击功能，可以用来窃取敏感信息并破坏受害者的系统。
