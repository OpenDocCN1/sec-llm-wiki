| **安全要闻** |
| --- |
| **美国奥尔巴尼市政府受到网络攻击，影响市政服务及警方网络系统**据外媒报道，美国纽约州首府奥尔巴尼市市长Kathy Sheehan于3月30日在社交媒体上发帖称，奥尔巴尼市遭遇了勒索软件攻击，但没有透露被攻击的程度。市政府官员整个周末都在努力应对这起事件。奥尔巴尼市长Kathy Sheehan表示，在受到网络攻击之后，除了办理出生证、死亡证明和结婚证之外，其他的市政服务于4月1日上午恢复。据称，警察局也受到网络攻击的影响。警察工会副主席Gregory McGee在Facebook上发帖称，因为网络攻击，警局已无法使用联网系统。员工无法访问通过互联网连接运行的调度系统、部门电子邮件或其他服务或程序。这意味着警察无法看到谁在工作，以及每个巡逻队的人手是多少。目前为止，调查仍在进行中。警察工会成员也还没有得到这次袭击的具体细节，只声明公众的个人信息还是安全的。**沙特政府从亚马逊 CEO 贝索斯手机获取到个人数据**安全主管加文·德贝克尔（Gavin De Becker）在3月30日表示，沙特政府黑入了亚马逊首席执行官杰夫·贝索斯（Jeff Bezos）的手机并获取到了个人数据。贝索斯先前曾要求德贝克尔调查《国家问讯报》是如何获取到其与电视主持人劳伦·桑切斯（Lauren Sanchez）发送的私密信息一事。德贝克尔表示自己在完成调查之后，非常确信“沙特曾经黑入贝索斯的手机并获取了个人信息”。“一些美国人也许会对此感到很惊讶，事实上沙特政府从去年十月开始便一直试图对杰夫·贝索斯不利，当时《华盛顿邮报》报道了卡舒吉被残酷迫害一事。”德贝克尔之后表示，目前尚不清楚AMI是否知道其中详情，但他指出AMI董事长戴维·佩克尔（David Pecker）与沙特政府关系密切。**Earl Enterprise ****餐馆系统遭黑客入侵 200 多万张信用卡资料遭窃取**据外媒The Verge报道，Planet Hollywood、Buca di Beppo和Mixology等餐厅的母公司证实，该公司遭遇了安全漏洞的影响。此前安全研究人员发现该公司客户的200多万张信用卡资料遭窃取，黑客还在网上叫卖窃取的信用卡信息。KrebsOnSecurity安全研究人员表示，在其发现“有力证据”表明客户的信用卡和借记卡号码正在网上销售后，于2月份联系了该公司。黑客使用“在其销售点系统上安装的恶意软件”从210个州的餐馆位置窃取了215万个信用卡和借记卡号码，到期日期以及一些持卡人姓名。该公司还建议客户检查他们是否遭遇可疑活动，并在发现欺诈性交易时通知相关银行。 |

 

| **威胁分析报告** |
| --- |
| **FireEye****发布利用WinRAR漏洞攻击活动分析**WinRAR是一个超过20年历史的文件存档工具，全球超过5亿的用户在使用它，最近在其代码库中发现了长期存在的漏洞。由Check Point  Research在CVE-2018-20250（路径遍历零日漏洞）中指出，该漏洞允许攻击者提取“ACE”格式文件时指定任意位置，而不考虑用户输入。攻击者可以通过创建恶意存档实现持久性和代码执行，这些恶意存档将文件提取到敏感位置，比如“Startup”开始菜单文件夹。虽然此漏洞已在最新版本的WinRAR（5.70）中得到修复，但WinRAR本身不包含自动更新功能。**微步：“Bitter****”****团伙持续对我国发起定向攻击**Bitter，又名“蔓灵花”，是一个长期针对中国、巴基斯坦等国家的政府、军工、电力、核等部门发动网络  攻击的 APT 团伙，具有较强的政治背景。微步在线威胁情报云近日再次捕获大量“Bitter”团伙的专用木马，发现此次攻击以自解压木马作为附件对相关目标进行鱼叉式钓鱼邮件攻击，其中诱饵文档内容来自于我国外交部网站 3月的新闻。从近期捕获的“Bitter”样本分析认为，该团伙正使用相同的基础设施同时针对中国和巴基斯坦两国发起攻击，并继续沿用原有核心木马框架，活动较为猖獗。**电商平台云集话费充值活动遭薅羊毛事件分析**2019年3月11日起有黑产团伙针对电商平台云集“话费充值9.7折”的营销活动进行持续的“薅羊毛攻击”，攻击量于2019年3月24日达到顶峰，远超日常黑灰产攻击流量的阈值。该营销活动每个帐号每天可享受一次9.7折话费充值的优惠（50元以上）。于是，有黑灰产团伙利用接码平台批量注册云集帐号。然后通过代充平台（蜜蜂等）向正常用户发布提供9.85折充值话费的服务。接到代充平台订单后，再通过囤积的帐号在云集平台上以9.7折的价格进行话费代充。也就是说，每充值100元话费，黑灰产团伙就可赚取1.5元差价，根据不完全统计，黑灰产仅2019年3月24日的单日获利可达80～100万。**幸运大象攻击活动使用多个曾被使用过的APT域名进行伪装**在2019年3月初，ASERT的研究人员发现了一个主要针对南亚国家政府的证书盗窃活动（其称之为“LUCKY  ELEPHANT”），攻击者者使用相似的网页来模仿合法实体，如外国政府、电信和军队，以此来收集登录凭证。该攻击活动涉及到的IP地址与之前一个可疑的印度APT组织（DoNot Team）有关，并且用于凭证收集的域名中至少有一个属于中国APT活动。研究人员还没有发现任何与此活动有关的恶意软件。 |

 

| **会议政策赛事** |
| --- |
| **日本将在2023年与美国建设联合太空态势感知系统**美两国将于2023年开始联结美军与自卫队的太空态势感知（SSA）系统，对别国卫星和宇宙垃圾情报进行实时监视和情报共享，用于应对未来可能面临的卫星攻击，建立联合防御的机制。预计在4月召开的华盛顿日美安全保障委员会议（“2+2“会议），进一步对强化日美太空联合防御方阵进行确认。日本宇宙航空开发机构（JAXA）为了准确掌握其他可疑卫星和宇宙垃圾信息，对200~1000千米的低轨道进行监视。在新《防卫大纲》公布后，为了构筑日本自卫队在太空的军事力量，防卫省将建设能够监视36000千米的地球同步轨道的SSA系统，从2018年开始通过美国的有偿军事援助得到技术支持，将在2022年完成系统建设。**美国防部希望在2020年形成针对其承包商的新网络安全标准**3月25日，美国防部负责采购和后勤保障的国防次长艾伦.洛德（Ellen Lord）在媒体组织的一次活动上透露，该部正在与美国家标准与技术学会（National  Institute of Standards and Technology，NIST）合作，制订针对美国防承包商企业的新网络安全实践测量基线标准，美国防部希望能在未来十八个月内就开始应用该标准，来评估承包商企业是否具备获得国防承包合同的资格。洛德指出，美国防部正在参考美国家标准与技术学会的现有标准定制适用于其承包商的新网络安全标准及与之配套的测量指标体系，该部还计划安排第三方负责审计其承包商是否已合规。美国防部还将与约翰霍普金斯大学应用物理实验室（Johns Hopkins University Applied Physics Laboratory）合作推动相关标准的制订工作。对于美国防部将出台的网络安全新要求，美相关行业协会则认为中小规模的承包商企业可能会面临没有足够资源来满足合规要求的问题。美国航空航天行业协会（Aerospace Industries Association，AIA）负责国家安全事务的副总裁约翰.鲁迪（John Luddy）在3月26日写给美国会参议院武装力量委员会网络安全子委员会的一份书面证词上指出，尽管他赞成要加强网络攻击的汇报工作和应用新的网络安全标准，但中小规模承包商很难针对当前大规模的复杂网络安全风险实施可持续的网络安全项目。因此该协会已提出制订行业网络安全标准、避免对不同规模的承包商实施一刀切合规要求的建议。 |

 

| **前沿技术** |
| --- |
| **英国开通全球首个商用级量子网络，测试量子密钥分发**英国开通全球首个用于测试的商用级量子网络，将测试量子密钥分发(QKD)。该机制采用量子力学原理(观察影响结果)而非数学复杂度来保证密钥安全。该125公里长的光纤链路是英国量子网络计划的一部分，该计划属于研究与工业界的协作项目，受到英国国家量子技术项目的支持。新网络连接电信巨头英国电信(BT)位于英格兰东部伊普斯维奇市的阿达斯楚科技园和剑桥。测试将先聚焦COW协议，即相干单向 (Coherent  One-Way) 量子密钥分发协议。粗略地说，就是在单个光子(光的粒子)上编码密钥。由于只要观测光子就会改变光子的编码，密钥的安全性便能在链路另一端得到测试和保证。将BT的研究带入光纤网络尤其是QKD的 Andrew Lord 在发给媒体的电子邮件中评论道：该QKD链路是2年的合作成果。链路采用已铺设的BT光纤，走的BT交换，涉及的全部设备都是商用级的。该网络本身的数据传输率为500Gbit/s，使用现成的IDQ和ADVA设备，是标准的高损耗光纤。QKD面临的一个主要问题还是距离，目前依旧限制在几百公里的光纤长度上。这是因为承载信息的光子会逸散，降低形成密钥的速度。(截至目前，QKD最长演示距离为404公里特低损耗光纤，安全密钥速率为1.15比特/小时。)**以色列公司开发指令安全硬件阻止黑客破坏武器系统**以色列IMI Systems公司推出了一种硬件系统，可保护计算机控制的军事硬件免受网络攻击。该硬件系统称为“被动缓冲区”，可保护基于计算机和计算机控制的系统和应用程序。确保完整和连续的操作可以实时监视和控制受保护系统与外围元件和组件之间的数据流，确保仅实现合法的消息、控制和协议。此被动缓冲区监控确保所有系统的操作符合系统工程师定义的参数、逻辑和顺序。被动缓冲系统保护的典型系统是：武器和弹药、关键系统基础设施的计算机化组件，有人驾驶或无人驾驶车辆、飞机和船舶、以及基础设施、医疗系统和工业车间中的各种关键计算机化组件。系统的设置由一组规则和过滤器定义，这些规则和过滤器确定每个协议的配置、内容、上下文和角色。用于子系统和用户的内置硬连线识别消除了未经授权的操作员的篡改。除了对系统和功能的保护级别之外，被动缓冲区还可以防止访问受保护系统中高度机密的核心级元素。一旦激活，被动缓冲区就会持续监控系统，实时分析和表征受保护资源和协议（专有）的完整性和状态。如果怀疑受保护的系统受到损害，则会启用预防措施，从而限制不良行为。虽然系统会阻止可能危及用户或设备的自动操作，但它也具有一定级别的手动覆盖以使用户能够在战斗中继续和操作系统。 |
