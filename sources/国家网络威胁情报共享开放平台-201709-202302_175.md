| **安全要闻** |
| --- |
| **交易所10086coin存在多处严重漏洞，可致用户大量敏感信息泄露**从今年9月17日开始，就有多个白帽在BUGX.IO平台上提交了关于10086coin交易所的漏洞，其中不乏严重漏洞，能够造成大量的敏感信息泄露漏洞活动。根据白帽子反馈的漏洞情况显示，在10086coin的某处连接处泄露处xml文件目录树，在此连接处泄露出大量的用户信息，有用户敏感信息（邮箱、手机号、姓名、身份证号等信息），平台用户交易信息，还有大量用户手持身份证照片。通过正常访问可以泄露的网页，可以发现这个泄露信息的页面共泄露出来346个excel表格信息和表格访问路径。这张表里有几千个用户信息，有用户姓名、手机号、身份证号、邮箱等敏感信息。在这些信息泄露出来用户的身份证图片加上excel表格泄露的用户敏感信息，这样10086COIN交易平台把用户很全面的个人信息全都泄露了出来，对用户的损害极大。**VMware****为关键虚拟机逃逸漏洞发布安全补丁**据报道，VMware针对在最近一次中国黑客大赛中发现的虚拟机（VM）逃逸重要漏洞发布安全补丁。VMware已为该虚拟机（VM）逃逸重要漏洞（CVE-2018-6981与CVE-2018-6982）发布安全补丁，该漏洞由研究员张焱宇近期在中国GeekPwn2018黑客大赛中发现。这些程序错误是由vmxnet3虚拟网络适配器中未初始化的堆栈内存使用错误导致的。而这些错误仅在vmxnet3适配器允许的情况下才可用。由VMware发布的通知可知，“VMware ESXi、Fusion与Workstation的vmxnet3虚拟网络适配器中包含未初始化的堆栈内存使用。启用vmxnet3时，该问题会允许虚拟机在宿主机上执行代码。所有的vmxnet3均受此问题影响。” |

 

| **威胁分析报告** |

| **卡巴斯基 - 2018年Q3垃圾邮件与网络钓鱼报告**卡巴斯基近日发布了第三季度垃圾邮件与网络钓鱼报告。报告显示，在第三季度，在垃圾邮件中发现了大量的诈骗邮件。以前，攻击目标主要是英语用户，但在9月份观察到其它语言的一个大爆发，包括德语、意大利语、阿拉伯语，还有日语。犯罪分子勒索的赎金从几百美元到数千美元不等。不同的邮件中使用的付款地址（比特币钱包地址）都不相同。第三季度，同样检测到一个针对企业用户的恶意垃圾邮件活动。犯罪分子的主要目的是窃取密码。为了达到这一目的，犯罪分子将恶意软件Loki Bot封装成ISO文件，附加在邮件的附件中。僵尸网络Necurs曾被发现在第二季度分发携带恶意IQY（Microsoft Excel Web查询）附件的垃圾邮件，但现在它已经将兴趣转移至银行业。犯罪分子对获得大学网站账户的访问权限的兴趣有所增长。观察到针对16个国家的131所大学的攻击活动。犯罪分子不仅仅想要窃取个人数据，还瞄准了学术研究成果。**Linux****系统在互联网中面临的安全威胁分析报告**Linux系统作为主流五大操作系统之一，目前在服务器市场占有率超过80%。随着云计算与IoT的发展，Linux作为物联网领域的主流底层操作系统，所涉及的应用场景将呈几何级增加。全球已有超过5000万的Linux主机暴露SSH端口，其中美国与中国的暴露数量最多，而这些服务器将会面临严峻的网络攻击，如端口扫描、口令爆破、漏洞扫描等。据观测，全网每天有大量的扫描流量对系统的SSH或数据库类端口进行探测，一旦探测成功则进行爆破，获取主机权限。Linux主机失陷后，多被应用于挖矿、发起DDoS攻击以及内网蠕虫扩散捕获肉鸡，最常见的木马有盖茨木马、树莓派等。这一现象将严重影响了网络空间安全，建议在后续的网络安全感知与治理过程中，加强对此类系统的安全规范化管控，对僵尸主机进行及时清理。**黑客利用加拿大大学的网络进行大规模的加密劫持活动**圣弗朗西斯泽维尔大学上周发现了有黑客利用学校网络进行大规模的加密劫持活动，并通过禁用其网络以切断袭击。据报道，黑客安装了恶意软件来进行攻击。该大学表示，他们没有发现任何证据表明有个人信息被泄露或窃取。该大学还表示，它将重置所有账户密码作为预防措施。圣弗朗西斯泽维尔大学发表声明说：“周四，ITS与安全专家协商，禁用所有网络系统，以切断来自'Crytpocoin  Mining'系统的自动攻击。恶意软件试图利用StFX的集体计算能力来创造或发现比特币以获取金钱利益”。该大学仍在致力于恢复其网络资源。与此同时，Cryptojacking  Attacks在网络犯罪分子中的使用也越来越频繁。采矿攻击的目标已慢慢从比特币转移到Monero，因为后者占用较少的CPU能力。 |

| **最近修补的Adobe ColdFusion漏洞被用于APT**研究人员发现，修补过的一个Adobe  ColdFusion漏洞，正被一个与中国有关的APT组织在野外加以利用。这个漏洞CVE-2018-15961，是一个不受限制的文件上传错误，可能导致任意代码执行。在voleperple检测到的攻击中，一个可疑的中国APT团体通过直接上传中国直升机的webshell，破坏了一个脆弱的ColdFusion服务器。目标服务器丢失了Adobe仅在两周前发布的一次更新。Adobe在9月份发布了一项针对未经身份验证的文件上传漏洞的修复程序。这些缺陷影响了Adobe的ColdFusion产品。具体影响是ColdFusion 11(更新14及更早版本)、ColdFusion 2016(更新6及更早版本)和ColdFusion  2018(7月12日发布)。通过对文件上传的简单HTTP POST请求，可以很容易地利用这个漏洞。不受限制，也不需要任何认证。**WordPress GDPR ****插件漏洞在野外被利用**Wordfence的研究人员报告说，WordPress GDPR插件受到漏洞的影响，未经身份验证的攻击者可以利用漏洞添加新的管理帐户。“报告的漏洞允许未经身份验证的攻击者实现特权升级，允许他们进一步感染易受攻击的站点。任何使用此插件的网站都应立即优先更新到最新版本，或在无法更新时禁用并删除它。”Wordfence的研究人员观察到了两种类型的攻击。在第一个攻击场景中，攻击者利用漏洞修改“users\_can\_register”选项并允许注册新用户。攻击者还将新用户的角色改为“管理员”，以获得网站的全部特权。通过利用这个缺陷将users\_can\_register选项设置为1，并将新用户的default\_role更改为“administrator”，攻击者只需在/wp-login.php填写表单即可。第二个攻击场景中，攻击者使用了更复杂的技术。攻击者通过向网站的WP-Cron日程表中注入恶意操作来安装后门，以建立一个持久的后门。**谷歌Home首个无接触攻破漏洞**腾讯安全团队发现并报告了谷歌Home智能音箱多个全新漏洞，并在无需用户交互的情况下成功破解。谷歌安全团队第一时间致谢并确认此漏洞为高危安全漏洞，这也是谷歌Home首个对外确认的无接触攻破安全漏洞。据了解，此次发现的谷歌Home漏洞，允许攻击者在一定条件下远程执行恶意代码，在无需任何用户交互的情况下实现窃取资料与隐私，静默录音等。目前，谷歌安全团队表示将在近期全线推送安全更新。 |

| **StopLift****人工智能技术可检测自助结账系统中异常或潜在欺诈行为**NCR公司于周二表示，其正收购StopLift Checkout Vision Systems，这是一家为零售销售点提供计算机视觉系统的制造商。StopLift的人工智能技术可用于检测自助结账系统中异常或潜在的欺诈行为。销售点终端龙头制造商NCR计划将StopLift的人工智能技术融入其POS产品组合中。NCR公司首席执行官迈克尔·海福德（Michael Hayford）表示，“NCR在自助结账及商店转型方案领域领先市场，此次收购将提升我们在这两个领域的市场占有率，将为全球零售商客户创造新价值。此外，StopLift的欺诈检测技术将成为我们“平滑商品”（frictionless commerce product）战略发展的关键推动力。”长期以来，自助结账中的偷窃行为一直困扰着各大零售商，而目前有一系列系统可防止零售业缩水。StopLift的视频分析技术通过计算机图像视觉分析来监控每次交易活动过程，区分结账时的合法行为与非法欺诈行为。例如，该系统可识别钱包、可重复使用的购物袋及其他放置在装袋区域的非出售商品，还可标记未经扫描而绕过扫描仪的商品。一旦检测出偷窃行为，系统将在顾客离开柜台走出商店前向店员员发出警报。**安全研究人员：英伟达 GPU 存在旁路攻击漏洞**加州大学河滨分校的研究人员，发现了三种可能被黑客利用 GPU、来攻破用户安全与隐私防线的方法。这些技术可用于监视浏览器活动、窃取密码、以及向基于云端的应用程序发起攻击。研究报道中描述的第一项，指出了 GPU 旁路攻击导致的渲染不安全：“计算机科学家们认为这是可行的，并且描述了他们如何通过对 Nvidia GPU 进行反向工程，将图形渲染和计算机堆栈都拉下水”。论文原标题为《渲染也不安全：计算机旁路攻击是可行的》（Rendered Insecure: GPU Side Channel Attacks are Practical）。其声称，这是人们首次成功地对 GPU 发起旁路攻击。当然，执行这类攻击，也有着几项前提。首先，受害设备上必须被安装了间谍软件程序，这种恶意代码可以嵌入一个无害的应用程序。其次，攻击者必须拥有可以分析 GPU 内存分配机制的机器学习方法。然后，间谍软件和机器学习程序才可以利用现有的图形 API（如 OpenGL 或  WebGL）发起攻击。换言之，一旦用户打开了恶意应用程序，它就会调用 API 来分析 GPU 正在呈现的内容（比如网页信息）。GPU 的存储器和性能计数器被其所监视，并馈送给机器学习算法，以解释数据和创建的指纹。加州大学河滨分校指出，鉴于渲染对象数量和尺寸的不同，每个网站在 GPU 内存利用率方面都会留下独特的痕迹。在多次加载同一个网站时，这个信号的样式几乎时一致的，而且不受缓存的影响。 |
