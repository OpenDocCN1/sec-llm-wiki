| **GeekPwn2018****国际安全极客大赛上海站开幕**10月24日，GeekPwn2018国际安全极客大赛于上海举办。本次大赛以“人‘攻’智能，洞见未来”为主题，设有不同挑战场景的命题专项赛、不设限制的非命题开放赛，以及PWN FOR  FUN趣味挑战赛三大赛项。命题专项赛搭建了不同的场景，设置了CAAD对抗样本攻防赛、数据追踪挑战赛、黑客屋挑战赛以及机器特工挑战赛四大赛项，覆盖机器学习、机械、安全等多个领域，鼓励安全、AI、机械等不同领域专家及爱好者共同参与。非命题赛事鼓励选手们发挥奇思妙想，将选手自由提交比赛项目的挑战设为基于漏洞攻破挑战赛和非基于漏洞攻破挑战赛。非基于漏洞攻破挑战赛的攻击目标可以是市场在售的或者常用的所有智能设备，攻击时并不要求利用攻击目标的0 day漏洞，而是采用新颖的攻击手段和方法突破安全限制。同时，为了鼓励更多人享受PWN的乐趣，GeekPwn发起了PWN FOR FUN趣味挑战赛系列，目前有“GAN 掉马赛克”和“RFID远距离读写挑战赛”。本次Geekpwn2018上海站共举办两天时间。**英国呼吁欧盟开展打击网络黑客行动**英国首相特雷莎·梅（Theresa May）呼吁欧盟各国领导人联合采取行动，惩治网络黑客。包括英国在内的八个欧盟成员国呼吁，欧盟应尽快通过一项新的制裁措施，打击网络恶意活动。在演讲稿中，首相特雷莎·梅将提出要求：“我们应当加快建立包括强力制裁机制在内的限制性措施以应对和阻止网络攻击”。她补充说：“恶意的网络活动对我们的经济造成了伤害，并破坏了我们的民主（制度）”。立陶宛及其他波罗的海沿岸国家，拉脱维亚与爱沙尼亚表示，他们几乎每天都会遭受网络攻击，而大部分攻击来自俄国，网络攻击的目标多种多样，包括银行及政府机构和交通基础设施。本周，英国国家网络安全中心(NCSC)透露，自成立两年来，共处理了1100余件网络安全事件。特雷莎·梅一再强调，尽管英国将于明年3月脱欧，英国仍希望在后脱欧时代尽可能与欧盟保持良好安全关系。****上海网信办约谈23家APP 要求加强个人信息保护****近日，上海市网信办对上海市民最常用的23个Android APP获取用户个人信息等相关权限申请情况开展抽查，将APP申请的权限分为三类，一是存在与之对应服务功能且不存在风险的“合理”权限，二是存在与之对应服务功能,但如被恶意利用会存在潜在风险的“合理但存在风险”权限，三是不存在与之对应服务功能的“不合理”权限。抽查发现，约有30%的权限与所提供的服务没有对应关系，属于“不合理”范畴。上海市网信办已分别约谈运营这些APP的23家企业，要求其认真整改。市网信办相关负责人表示，从抽查结果来看，现在上线的APP几乎都有过度索取用户个人信息的问题，运营企业都要对此进行自查自改。市网信办今后将定期抽检，并向社会公布抽检结果。 |

| ****人工智能类开源软件源代码安全缺陷分析报告****近日，CNCERT发布了《开源软件代码安全缺陷分析报告——人工智能类开源软件专题》。随着软件技术飞速发展，开源软件已在全球范围内得到了广泛应用。“人工智能”近年来发展迅猛，已成为高精尖科技创新的代名词。本期报告聚焦国内外知名机器学习、人工智能类开源软件安全开发现状，通过分析多款知名开源软件产品的安全缺陷，评估开源项目的代码安全控制情况。选取关注度高的开源项目，结合缺陷扫描工具和人工审计的结果，对各开源项目安全性进行对比。本期报告聚焦国内外知名机器学习、人工智能类开源软件安全开发现状，通过分析多款知名人工智能类开源软件产品的安全缺陷，评估开源项目的代码安全控制情况。（http://www.freebuf.com/articles/paper/186281.html）**“黄金鼠”组织近期攻击样本分析**黄金鼠组织(APT-C-27)是一个长期针对叙利亚等阿拉伯国家实施网络间谍攻击的恶意团伙。其团伙主要以APK、PE、VBS、JS文件作为攻击载体，涉及Android和Windows两大平台，利用社交网络和鱼叉邮件等方式散布和传播恶意载荷。本次360 CERT捕获的恶意样本是内嵌Package对象的Office钓鱼文档。从样本类型来看，此次攻击行动疑似采用鱼叉邮件的方式向受害者进行投递。样本伪造联合国近东巴勒斯坦难民救济和工程处发布内嵌一份重要表格的公函诱使受害者执行Package对象执行攻击载荷。 （https://www.secrss.com/articles/5794）****逃避沙箱并滥用WMI：新型勒索软件PyLocky分析****在目前的网络威胁领域中，勒索软件仍然扮演着十分重要的角色。2018年上半年勒索软件的活动有所增加，并且相关勒索软件还通过各种升级更新来尝试避开现有的安全解决方案，比如说PyLocky。在7月下旬和整个8月份，研究人员发现了一个通过垃圾邮件来传播PyLocky勒索软件的攻击活动。其具备反机器学习的能力，同时使用了Inno Setup Installer和PyInstaller，增加了静态分析方法的检测难度，其中就包括了基于机器学习的解决方案。（http://www.freebuf.com/articles/system/186626.html）**APT32****“海莲花”近期多平台攻击活动**“海莲花”，又名APT32和OceanLotus，是越南背景的黑客组织。近期，微步在线黑客画像系统监控到了“海莲花”组织多平台的攻击活动，经过分析发现：APT32的攻击活动仍在持续，有多个国家的金融、政府和体育等行业相关目标遭到定向攻击。攻击平台包含Windows和macOS，攻击手法相比之前变化不大，除都使用了伪装Word文档的可执行程序之外，针对Windows平台的还利用了CVE-2017-11882漏洞。针对Windows平台的木马部分利用了白加黑技术，部分利用了Regsvr32.exe加载执行OCX可执行文件。此外，相比之前多利用Symantec公司签名的程序进行白加黑利用来投递Denis木马，APT32近期增加了对Intel和Adobe公司签名程序的白加黑利用。针对macOS平台的木马相较之前其Dropper和Payload加了壳和虚拟机检测。（http://www.freebuf.com/articles/network/186493.html） |

| ****雅虎就数据泄露案提出和解****10月24日消息，据NBC News报道，在数据泄露引起的诉讼中，雅虎提出和解。在雅虎提出的一份和解协议中指出，同意向2亿用户支付5000万美元(约合3.47亿元人民币)赔偿金，并为他们提供为期两年的免费信用监控服务。这份和解协议需要美国联邦法院的批准才能生效。协议中，赔偿主体为2012年至2016年期间的2亿美国和以色列用户，他们总共持有10亿左右个账户。赔偿金将用于补偿他们因身份盗窃、延迟退税、或个人信息泄露引发造成的损失。具体来说，雅虎会以每小时25美元的标准进行补偿。对于那些记录在案的损失，受害者最多可要求15小时的赔偿，即375美元。此外，如果用户购买了高级电子邮件服务，可获得25%的退款。****多种NSA黑客工具被用于攻击航空航天和核能行业****卡巴斯基实验室安全专家19日发布文章表示，有攻击者正在利用NSA黑客工具DarkPulsar、DanderSpritz和Fuzzbunch来感染俄罗斯、伊朗和埃及的50多家机构所使用的Windows Server 2003和2008系统。受感染的易受攻击服务器被广泛应用于航空航天和核能等行业，尤其是拥有大型IT和研发部门的机构。DanderSpritz和FuzzBunch框架是Shadow Brokers在2017年3月公布的工具，FuzzBunch插件负责侦察和攻击受害者，DanderSpritz框架中的插件用于管理已感染的受害者，DarkPulsar后门在两个攻击框架之间起到桥梁作用。**日本政府要求Facebook加强数据保护，及时告知安全措施变动**10月22日消息，继今年发生的一系列影响全球数千万用户的数据泄露事件后，日本政府要求美国科技公司Facebook更好地保护用户的个人数据。日本政府称，作为全球最大的社交媒体网络，Facebook应向用户充分传达安全问题，提高对平台上应用供应商的监管，并及时向监管机构告知任何安全措施的变更。上述要求发生在Facebook本月宣称黑客袭击者窃走2900万用户账户数据之后。而在此之前的4月份，英国公司剑桥分析不当使用8700万用户个人数据的事件刚刚曝光。日本个人信息保护委员会与英国和其他地区的监管机构一并调查了剑桥分析的事件。周一，该委员会发布声明，详细说明了委员会对Facebook提出的要求。这些要求并不附带行政命令或处罚，也不具有法律约束力。日本个人信息保护委员会称，Facebook已承诺将在其日语网站上详细说明如何处理上述要求。委员会还表示，剑桥分析事件可能也影响到10万日本用户，并且之后的网络攻击也可能对日本用户造成影响。Facebook发言人未立即发表评论。 |

| **NFCdrip****攻击：近场通信NFC也可用于长距离数据渗漏**应用安全公司Checkmarx的高级研究员Pedro Umbelino研究证明，近场通信（NFC）协议可用于在相对较长的距离内泄露少量数据，如密码和加密密钥。NFC协议可供两个设备在10厘米距离内相互通信。但经研究发现，NFC实际上可以在更长的距离上工作，并且可以从具有其他通信系统（例如WiFi、蓝牙和GSM）的设备中提取数据。Pedro Umbelino将自己的攻击方法命名为NFCdrip，该攻击通过改变NFC操作模式以调制数据。安卓手机上安装的恶意软件可以几十米外连接了普通调幅(AM)收音机的另一部安卓手机传输数据。在实验中，2.5米距离内该攻击可以每秒10-12比特的速率实现无错传输。随着距离的延伸，2.5-10米距离内，虽然速率不变，但会出现一些错误，不过这些错误可以修正。距离超过10米，信号会衰减，错误会增多，但Umbelino仍成功在60米距离上传输了一些数据。Checkmarx计划将公布NFCdrip的PoC。****研究人员发现假冒官方McAfee的新技术支持骗局****22日消息，研究人员发现了一个伪装McAfee的新技术支持骗局，窃取受害者的信用卡详细信息和个人隐私信息。这个虚假的McAfee页面显示：“您的Mcafee订阅已到期”。接着此页面提示用户续订，出现两个表单要求填写用户的信用卡信息和个人信息。完成后，该页面会将用户重定向到“感谢”页面，告知用户在安装购买的软件时需要电话求助。如果拨打此号码，对方会提示用户需要通过McAfee的网站（虚假的）购买该软件。从本质上讲，诈骗者不仅可以获得销售提成，还可以窃取用户的信用卡和个人信息。另外，这些被窃取的信用卡信息可用于支付其他采购费用，个人身份凭据信息被用于其他恶意活动。**IBM ****宣布推出针对网络安全应用的云计算社区平台**日前，IBM公司宣布推出一个针对网络安全应用的全新云计算社区平台IBM SecurityConnect。这是首个基于开放联合技术构建的安全云计算平台。它以人工智能为核心，能够分析以前并不互联的多种工具和环境中的安全数据。IBM在研究客户环境后发现，通常网络安全团队需要使用由40家不同厂商提供的80多种不同的安全产品。研究还表明，这些产品只有不到20%的功能得到了利用，而且由于集成性和复杂性的挑战，可能无法提供客户预期的结果。IBM Security Connect能够将来自IBM Security产品的安全数据与安全厂商、客户和业务合作伙伴的生态系统相集成，从而提高安全团队防范网络犯罪的效率，促进团队间的协作。该平台使用户能够使用包括Watson for Cyber Security在内的机器学习技术和AI技术进行数据分析，从而帮助识别威胁或风险，提高威胁检测与应对的效能与效率。用户可以设计并部署新的定制的解决方案，例如SOC Operations或Digital Trust。该平台提供的关键服务包括：用于共享和标准化威胁情报的开放式安全数据集成服务，跨本地部署数据资源库、云端数据资源库及各种安全解决方案的联合数据搜索，以及与平台集成的应用和解决方案都可利用的安全警报、事件的实时共享。
