| **2018****（第五届）中国网络安全技术对抗赛在京举办**2018年8月16日，第五届中国网络安全技术对抗赛（以下简称“对抗赛”）在北京国家会议中心成功举办。对抗赛由中共中央网络安全和信息化委员会办公室指导，国家互联网应急中心主办，百度、阿里巴巴、腾讯、360公司联合主办，中国科学院信息工程研究所提供技术支持。对抗赛启动仪式于8月15日上午在2018中国网络安全年会全体大会上举行。国家互联网应急中心党委副书记卢卫、360集团董事长兼CEO周鸿祎、阿里巴巴集团首席风险官郑俊芳、腾讯副总裁马斌、百度安全产品总经理韩祖利出席启动仪式，共同开启2018（第五届）中国网络安全技术对抗赛。本届对抗赛以网络安全引擎比赛、夺旗赛、破解赛等形式展开，吸引了来自北京、上海、石家庄、青岛等城市的近70家队伍报名参赛，参赛选手的单位包括高校、研究所、互联网企业、信息通信企业等。对抗赛共设立5个比赛项目，分别是：网络安全引擎比赛、人工智能安全夺旗赛、攻防实战对抗赛、智能安全破解挑战赛、PC安全夺旗赛。**微软称俄黑客试图干扰美中期选举？俄外交部:毫无证据**针对微软公司所说的“俄黑客试图干扰2018年美国国会中期选举”一事，当地时间8月21日，俄罗斯外交部发表声明称，微软公司上述说法毫无证据。日前美国微软公司发表声明称，俄罗斯黑客组织已参照美国哈德森研究所、国际共和研究所以及国会参议院官方网站建好了虚假网站，诱骗访问者点击进入，从而达到入侵访问者电脑的目的。对于这种说法，俄外交部当天发表声明称，微软公司的说法毫无证据，明显是在最大程度地哗众取宠。俄外交部表示，俄方一直以来提议就网络安全问题与美方举行工作组会议。会议上俄美专家可就具体问题进行讨论。“但很明显，美国同行们不想出示任何所谓俄方干涉的证据”。自特朗普当选美国总统以来，美国会以及独立检察官一直就“俄黑客影响美国大选”等事件进行调查，目前已有多家俄公司和数名俄黑客被起诉。**以色列政府将不再使用微软软件**8月22日消息，据国外媒体报道，由于微软授权条款发生变化，导致授权价格将增长一倍，以色列政府当地时间周二表示，到今年年底时以色列政府使用微软各种桌面软件的合同将不会再续签。根据目前与微软的框架协议，以色列每年要支付1亿谢克尔(约合2700万美元)，用于为各部和政府机构采购办公桌面软件、Windows和服务器软件。根据以色列财政部称，微软正试图将以色列从拥有该软件并可以随意使用该软件的授权政策，调整为类似于租赁的订阅方式。以色列财政部指出，这一改变——包括将数据转移到云端——并不能满足政府的需求。财政部表示，以色列政府已经与驻以色列的微软官员进行了长达一年的谈判，但没有结果。针对以上消息，驻以色列的微软人员拒绝置评。 |

| **安全厂商发现针对墨西哥用户的恶意活动Dark Tequila**Dark Tequila是针对墨西哥用户的复杂恶意活动，其主要目的是窃取财务信息，以及获取热门网站的登录凭据，包括从代码版本存储库到公共文件存储帐户和域名注册商。大多数受害者都位于墨西哥。该活动自2013年以来一直活跃，因此它是一款非常成熟的产品。已知的感染媒介有两种：鱼叉式网络钓鱼和USB设备感染。它背后的威胁行动者严格监控和控制所有操作。如果存在不在墨西哥或不感兴趣的偶然感染，则从受害者的机器远程卸载恶意软件。**BackSwap****恶意软件针对西班牙的六家银行**IBM X-Force研究人员分析了一种名为BackSwap的相对较新的银行木马的活动。BackSwap于2018年3月出现，直到最近，仅仅针对过波兰的银行。该恶意软件的目标列表现在包含西班牙的六家主要银行。恶意软件的运营商将代码保存为自己的项目；从这个意义上说，它被认为是团伙所有，而不是商业恶意软件。BackSwap并不比任何其他活跃的银行木马更复杂。通过模拟用户输入来访问浏览器的地址栏并直接在其中插入恶意脚本，BackSwap执行JavaScript脚本，并绕过浏览器和银行第三方安全控件的保护。**32000****个智能家居和企业面临数据泄露风险**全球网络安全产品领导者Avast的最新研究发现，由于配置错误的MQTT协议，互联网上公开显示超过49,000个消息队列遥测传输（MQTT）服务器。这包括超过32,000台没有密码保护的服务器，使它们面临泄露数据的风险。MQTT协议通过智能家庭集线器互连和控制智能家居设备。虽然MQTT协议本身是安全的，但如果MQTT被错误地实现和配置，则会出现严重的安全问题。网络犯罪分子可以获得完全进入一个房间的权利，操纵娱乐系统，语音助理和家用设备，并查看智能门窗是打开还是关闭。在某些情况下，网络犯罪分子甚至可以追踪用户的下落，这可能是严重的隐私和安全威胁。**黑客组织TA505意图攻击金融机构，利用新型恶意软件Marap收集情报**来自网络安全公司Proofpoint的研究人员最近在一场规模相当大的垃圾电子邮件活动中发现了一种新的恶意软件Marap，主要针对了金融机构。这种被称为Marap的恶意软件不仅能够收集系统信息，而且具备下载其他模块或恶意软件的能力。从垃圾电子邮件活动所体现出的一些特征来看，它似乎由黑客组织TA505发起的。研究人员表示，虽然到目前为止Marap所实施的恶意行为仅限于收集有关受感染设备的系统信息并发送到由攻击者控制的命令和控制（C＆C）服务器，但模块化的特性允许攻击者随时为它添加新的功能或利用它来下载其他恶意软件。 |

| **美国科技巨头大力游说 印度数据本地化方案遇阻**美国科技巨头们正计划加强游说力度，以应对印度更严格的数据本地化要求。这些巨头称，数据本地化将破坏他们在印度的发展。代表亚马逊、美国运通和微软等公司的美国贸易组织已经对印度打算在本地存储数据的计划提出反对。尽管保护用户数据在全球范围内日益受到关注，但印度的举措可能会受到企业在印度市场上的投资计划的影响。科技高管和贸易组织已经商量向印度总理莫迪政府提出他们的担忧。另外，根据两名知情人士透露，行业还打算在即将于9月份在新德里召开的美印会谈上将此问题引申为贸易问题。虽然最终决定尚未出台，但协商恰逢美国和印度陷入美国关税增加的纠纷以及印度限制医疗器械价格的政策之际，后者给美国的制药企业带来不少损失。**中国互联网网络安全威胁治理联盟专业工作组成立会议顺利召开**由CNCERT主办的、一年一度的中国网络安全年会于2018年8月14日至16日在北京国家会议中心举办。中国互联网网络安全威胁治理联盟（简称“CCTGA联盟”）专业工作组竞选会于16日上午同期举行。CCTGA联盟自2016年2月26日成立以来，目前成员单位数量已达133家。为提高安全行业的整体技术能力，CNCERT愿意通过开放资源，在联盟中建立专业领域协作机制，通过公开民主的开放模式广泛联合成员单位等行业力量，成立“威胁情报共享工作组”和“DDoS攻击治理工作组”两个专业工作组。通过CCTGA联盟成员单位的踊跃报名，“威胁情报共享工作组”共收到30家成员单位的报名，其中有5家单位报名竞选工作组组长和副组长，“DDoS攻击治理工作组”共收到21家成员单位的报名，其中3家单位报名竞选工作组组长和副组长。**美国22个州联名诉FCC要求恢复****”****网络中立****”****规则**8月21日消息，据国外媒体报道，当地时间周一晚些时候，一个由22名州检察长和哥伦比亚特区组成的小组，要求美国一家上诉法院恢复奥巴马政府2015年出台的具有里程碑意义的网络中立规则（Net neutrality）。美国联邦通信委员会（FCC）去年12月投票表决，废除了关于禁止互联网服务提供商阻塞、限制流量或提供付费快车道(也称付费优先次序)的规定。FCC表决通过的新规定于6月初生效，新规定授予互联网服务提供商广泛的新权力，改变了美国人使用互联网的方式。各州认为，FCC的新规定会伤害消费者。这些州还表示，FCC没有任何“有效权威”来越过州及其保护网络中立性的地方法律。截止目前为止，有六个州的州长签署了关于网络中立的行政命令，三个州颁布了网络中立法律。 |

| **俄罗斯购买中国设备破解社交软件**据BBC报道，俄罗斯调查委员从中国公司——美亚柏科信息股份有限公司采购了型号为iDC-8811的取证魔方，用以从智能手机和其他移动设备中提取私人通信和社交媒体数据。据称，该取证魔方能提取100家厂商3000多种智能手机型号的信息，也就是说几乎能够获取所有已知智能手机和各种硬盘中的内容。根据俄罗斯政府采购文件显示，该调查委员会2018年7月采购了两套取证魔方系统，花费500万卢布。取证魔方外表有些像“核手提箱”的设备打开后，内部有可以折叠和竖起的屏幕，以及各种硬盘插口和通讯设备连接接口，可检测并解密通讯应用的消息记录，自动提取设备ID，此外还能在几分钟内破解Facebook和Twitter社交账号的数据。**俄罗斯公司将肥料实验室改造成该国最大的加密货币采矿场**俄罗斯似乎准备挑战中国对加密货币开采的垄断。一家俄罗斯公司已将一家前肥料实验室改造成该国据称最大的加密货币采矿业务。该部门名为Kriptoyunivers中心，将支持比特币和莱特币的开采。该中心在圣彼得堡附近的基尔希镇建造了超过4000平方米的矿场，投资额为5亿卢布（740万美元）。Kriptoyunivers的联合创始人阿列克谢科罗廖夫告诉日本时报说：“这是迄今为止俄罗斯唯一一家提供完整服务的矿场，不仅仅是生产加密货币，而且还为采矿者提供服务。加密货币矿工在任何区块链或加密货币的平稳运作中发挥着至关重要的作用，尤其是基于工作量一致性一致性算法的区块链或加密货币。由于创建了新货币并且根据网络上大多数矿工的共识来验证交易，因此确保没有网络控制足够的散列能力来操纵区块链是很重要的。**美国大多数州已部署技术来跟踪选举时黑客的入侵**据路透社报道，美国大多数州已采用技术，允许联邦政府查看州内部计算机系统来铲除黑客，这些系统被用来管理选民数据或投票设备。据三位了解部署情况的消息人士称，在俄罗斯黑客入侵伊利诺伊州和亚利桑那州的选民登记数据库两年后，大多数州已经开始使用政府批准的设备。选民登记数据库用于在选民访问投票站时核实选民的身份。美国政府网络安全专家告诉路透社，所谓的Albert传感器的快速采用，说明了州政府官员在2018年中期选举之前的广泛关注。CIS 是一家位于纽约东格林布什的非营利组织，致力于帮助政府、企业和组织打击计算机入侵。加州奥兰治县选举主席表示：“我们最近在我们的系统中添加了Albert传感器，因为我相信投票系统存在巨大漏洞；但选民登记制度也令人担忧。这是导致我失眠的事情之一：我们可以做些什么来保护选民登记系统？”根据美国国土安全部官员的说法，截至8月7日50个州中有36个州在“选举基础设施层面”安装了Albert传感器。这位官员表示，已经在38个县和其他地方政府办公室安装了74个传感器。2016年美国总统大选前只安装了14个此类传感器。安装这些传感器使网络安全专家可以开始跟踪入侵并与所有州分享这些信息。该技术通过非营利性网络情报数据交换直接提供有关网络事件的数据，然后提供给美国国土安全部。 |
