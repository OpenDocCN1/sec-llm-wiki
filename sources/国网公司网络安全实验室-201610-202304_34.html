【 网络安全政策】

1.  《中华人民共和国个人信息保护法 (草案) 》全文公布

    摘要：10月21日，全国人大法工委公开就《中华人民共和国个人信息保护法(草案)》征求意见。草案共八章七十条，主要内容包括：一是明确本法适用范围；二是健全个人信息处理规则；三是完善个人信息跨境提供规则；四是明确个人信息处理活动中个人的权利和处理者义务；五是明确个人信息保护职责的部门。此外，草案还对违反本法规定行为的处罚及侵害个人信息权益的民事赔偿等作了规定。【阅读原文】（来源：网络法前哨）

 

2.美国国务院发布《关键与新兴技术国家战略》

    摘要：10月15日，美国国务院发布《关键与新兴技术国家战略》，详细介绍了美国为保持全球领导力而强调发展“关键与新兴技术”，并提出推进美国国家安全创新基地和保护技术优势两大战略支柱，明确了人工智能、通信和网络技术、数据科学和存储等20项关键与新兴技术的清单，以避免中国、俄罗斯等战略竞争对手在相关领域削弱或取代美国的领导地位。该战略提出美国在发展关键与新兴技术的过程中将采取三个不同策略，按重要程度自高到低分别是：投入政府整体力量来发展具有最高优先度的技术领域；作为盟国及合作伙伴的合作方共同发展高优先度的技术领域；管理其他优先度相对较低的技术领域可能存在的技术风险。【阅读原文】（来源：学术plus）

 

【 网络安全事件】

1.NSA发布中国黑客最常用的TOP25漏洞

    摘要：10月20日，美国国家安全局（NSA）发布了一份报告，详细介绍了据称是中国黑客组织扫描、定位和利用最多的25个漏洞。所有25个安全漏洞都是众所周知的，并且可以从产品供应商处获得补丁程序。NSA在报告中指出，许多漏洞的利用程序都可公开获取，有些不仅被中国黑客利用，还被收入勒索软件帮派、恶意软件团体以及其他国家（例如俄罗斯和伊朗）黑客组织的武器库，攻击者可利用存在报告中列出的这些漏洞的联网产品作为跳板和网关，访问企业内部网络。其中，F5 BIG-IP 远程代码执行漏洞、Citrix VPN设备远程代码执行漏洞、保思安VPN任意文件读取、Microsoft Exchange远程代码执行漏洞在美国US-CERT官方网站发布的“中国国家安全部（MSS）相关网络攻击”预警报告中也曾提到过。【阅读原文】（来源：安全牛）

 

2.美起诉俄黑客：指控其导致乌克兰断电、干扰奥运会等

    摘要：10月19日，美国发布了一份起诉书，指控隶属俄罗斯武装部队总参谋部的主要军事情报机构情报局（GRU）74455部队的6名黑客。据诉讼书称，这几名俄罗斯黑客实际上为著名的Sandworm（沙虫）组织成员，该组织从2015年11月左右开始，一直持续到至少2019年10月左右，进行了非常多著名的网络攻击，主要包括：一是使用BlackEnergy、Industroyer和KillDisk的恶意软件对乌克兰的电网、财政部和国家财政部进行破坏性恶意软件攻击，使乌克兰造成了二次断电；二是2017年法国大选期间针对法国总统马克龙的钓鱼攻击，并泄露部分信息；三是2017年著名的NotPetya勒索软件感染全球计算机，旨在破坏目标系统，造成近10亿美元损失；四是通过网络钓鱼攻击运动和恶意APP应用攻击平昌冬奥会的主办方、参与者、合作伙伴和与会人员，利用OlympicDestroyer恶意软件攻击平昌冬奥会IT系统，数千台计算机被破坏，造成奥运会会场混乱。【阅读原文】（来源：黑鸟）

 

3.蔓灵花APT组织利用恶意CHM文档针对国内研究机构的攻击活动分析

    摘要：近期，奇安信安全能力中心捕获到“蔓灵花”APT组织针对特定单位群体展开的定向攻击活动。攻击者采用鱼叉钓鱼的方式，对相关目标单位的个人直接发送嵌入了攻击诱饵的钓鱼邮件。本次攻击行动中使用的诱饵为rar压缩包，而压缩包里携带恶意的chm文档。该组织最早在2016由美国安全公司Forcepoint进行了披露，是一个长期针对亚洲地区进行攻击活动的APT组织。主要针对目标区域的政府、军工业、电力、核工业等单位进行攻击，试图窃取敏感数据。【阅读原文】（来源：奇安信威胁情报中心）

 

【 网络安全漏洞】

1.Apache Solr ConfigSet API文件上传漏洞

    摘要： 近日，Apache官方发布了solr组件文件上传漏洞（CVE-2020-13957）的风险通告。攻击者可以通过结合 UPLOAD/CREATE这两个功能在 ConfigSet API 上进行未授权操作，从而获取服务器权限。Apache Solr是一个独立的企业级搜索应用服务器，目前很多企业运用solr开源服务。它具有高效、灵活的缓存功能，垂直搜索功能，高亮显示搜索结果，通过索引复制来提高可用性，提供一套强大Data Schema来定义字段，类型和设置文本分析，提供基于Web的管理界面等。【阅读原文】（来源：奇安信 CERT）

 

2.多款SAP软件存在高危漏洞(CVE-2020- 6364&6296)

    摘要：近日，全球最大的企业管理和协同化电子商务解决方案供应商、全球第三大独立软件供应商SAP发布安全更新表示，共计修复了20处高危漏洞。其中，SAP Solution Manager 和 SAP Focused Run 中存在一处命令注入漏洞（CVE-2020-6364），远程攻击者通过构造特制的数据包，发送到受影响的主机，可造成远程命令执行；SAP NetWeaver (ABAP) and ABAP Platform中存在一处代码执行漏洞（CVE-2020-6296），远程攻击者通过构造特制的数据包，发送到受影响的主机，可造成远程代码执行。【阅读原文】（来源：三六零CERT）

 

3.Windows操作系统TCP-IP远程代码执行漏洞（CVE-2020-16898）

    摘要：10月15日，微软官方发布安全公告，修复了存在于Windows操作系统内的TCP/IP远程代码执行漏洞（CVE-2020-16898）。Windows 签名验证绕过漏洞是验证文件签名存在设计缺陷，攻击者可通过远程攻击者通过构造特制的ICMPv6 Router Advertisement（路由通告）数据包 ，并将其发送到远程Windows主机上，即可在目标主机上执行任意代码。【阅读原文】（来源：三六零CERT）
