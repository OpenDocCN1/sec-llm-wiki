一、公司简介


全球能源互联网研究院有限公司（以下简称“联研院”）前身为国网智能电网研究院，2016年2月更名为全球能源互联网研究院，2017年10月改制为全球能源互联网研究院有限公司，联研院是国家电网公司直属科研单位，国内首家专业从事全球能源互联网关键技术和设备开发的高端研发机构。


二、招聘需求


本次面向社会公开招聘网络安全红队精英人才待遇优厚，薪资高、有分红，录用人员均与全球能源互联网研究院有限公司签订劳动合同（PS:就是有编制），办公环境舒适，班车、食堂、定期疗养全都有，欢迎小伙伴们踊跃报名。

岗位名称：渗透测试工程师

岗位职责

1. 负责公司内部网络安全漏洞挖掘；

2. 负责安全漏洞情报跟踪及研究，针对0day漏洞开发POC和EXP；

3. 负责突发网络安全事件应急响应；

4. 负责网络安全漏洞挖掘技术和攻防前沿技术研究；

岗位要求

1. 熟练掌握WEB/内网/社工/供应链等攻击手法与漏洞原理、挖掘方式等，具备独自开展渗透能力。

2. 熟练掌握一门或数门技术：如代码审计、软件漏洞挖掘、逆向分析免杀、web漏洞挖掘、内核漏洞挖掘等。

3. 在某一个领域拥有独特的全面的良好的知识和技能，并能有效指导他人工作。

4. 至少掌握一门开发语言，包括但不限于JAVA/C/C++/Python/C#/GO。（渗透能力强可放宽）

5. 熟悉代码安全审计（php/asp/jsp/python）的流程、方法及主流代码审计工具的使用，并挖掘常见漏洞。

6. 具备良好的沟通表达能力，良好的团队合作意识和自驱力；

7. 三年以上漏洞挖掘和渗透测试工作经验。

加分项

有获取CVE（CNVD、CNNVD）编号和电力行业工作经验者优先录用。

岗位名称：二进制安全工程师

岗位职责

1. 负责二进制网络安全漏洞挖掘技术研究，跟踪国内外最新网络安全漏洞挖掘验证技术;

2. 负责针对操作系统和移动应用app进行漏洞挖掘；

3. 对漏洞挖掘工具实现有深入理解，负责对网络安全漏洞挖掘工具的调试；

4. 负责对恶意样本的逆向溯源分析，编写技术分析报告。

岗位要求

1. 有较强的反汇编和逆向分析能力,熟练使用IDA、Ollydbg、Windbg、OD等调试工具，掌握C、C++、python、go等语言中的一种或多种；

2. 对Linux操作系统或国产操作系统有深入研究，熟悉Linux内核并具备安全分析和漏洞挖掘能力；

3. 熟练掌握固件逆向分析技术，熟练使用二进制、Android 反编译工具进行分析调试；

4. 熟练掌握软件逆向静态分析、动态调试、代码跟踪等；熟悉各种通用加密算法；

5. 熟悉具有病毒/木马逆向分析、安全威胁分析取证和应急响应经验

6. 具备良好的沟通表达能力，良好的团队合作意识和自驱力；

7. 三年以上漏洞挖掘或病毒分析工作经验。

加分项

有Linux或安卓相关漏洞CVE编号、电力行业工作经验或追踪分析APT攻击经验者优先录用。

岗位名称：工控安全工程师

工作职责：

1. 负责工控协议逆向分析、特征指纹提取、积累；

2. 负责电力工控系统安全工具的研发；

3.负责工控系统安全漏洞情报跟踪及研究，研究开发工控系统安全漏洞poc、exp脚本；

4.负责工控系统安全漏洞挖掘；

岗位要求

1. 熟悉工业控制系统（如PLC、DCS、SCADA）或主流工业控制协议：OPC、Modbus、Profinet、IEC104、IEC61850、S7等，并具备安全分析和漏洞挖；

2. 熟悉嵌入式操作系统或常规无线通讯协议BLE/RF/NFC/ZigBee等，并具备安全分析和漏洞挖掘能力；

3. 有较强的反汇编和逆向分析能力,熟练使用IDA、Ollydbg、Windbg等调试工具，掌握C、C++、python、go等语言中的一种或多种；

4. 熟练掌握逆向静态分析、动态调试、代码跟踪等；熟悉各种通用加密算法；

5. 具备良好的沟通表达能力，良好的团队合作意识和自驱力；

6. 三年以上工控系统或嵌入式系统漏洞挖掘经验。

加分项

有获取CVE编号和电力行业工作经验者优先录用。


三、报名条件


1.事业心和责任心强，求真务实，开拓进取，品行端正；有较强的学习能力和科研能力，勇于创新；

2.身体健康，具有良好的个人品质和职业操守，无违法违纪和不良从业记录。

3.所有岗位人员要求硕士研究生及以上学历；

4.要求3年以上相关工作经历，年龄一般不超过40周岁；

5.国网公司系统内单位员工报名参加社会招聘的，应在该单位工作满3年，近3年绩效等级积分累计应达到4.5分且上年绩效等级达到B及以上。



四，进度安排


1.报名阶段

应聘者填写《人员信息表-姓名》（见附件，若无法下载，请访问联研院官网地址进行下载）并附上全日制学历学位证书、最高学历学位证书扫描件，同时发送至chenyuxin@geiri.sgcc.com.cn和wangwenhui@geiri.sgcc.com.cn，邮件标题为“招聘简历 -姓名-手机号”，以便于接收和查阅。

报名截止时间：2020年10月31日。

2.资格审查

按照报名条件，对应聘人员报名材料进行分类整理、资格审查筛选。经初步审查筛选后，通知有关应聘人员参加统一考试测评。

3.面试。

初步安排在2020年11月，具体时间、地点另行通知。
