【 网络安全政策】

1. 工信部开展纵深推进APP侵害用户权益专项整治行动

    摘要：7月24日，工信部发布《关于开展纵深推进APP侵害用户权益专项整治行动》，专项整治将依规加强监督检查，督促相关企业强化APP个人信息保护，及时整改消除违规收集、使用用户个人信息和骚扰用户、欺骗误导用户、应用分发平台管理责任落实不到位等突出问题，净化APP应用空间。整治对象包括：APP服务提供者、软件工具开发包（SDK）提供者、应用分发平台。【阅读原文】（来源：工信微报）


2.国标《信息安全技术 信息技术产品供应链安全要求》公开征求意见

    摘要：7月27日，《信息安全技术信息技术产品供应链安全要求》公开征求意见。该标准规定了信息技术产品供应方和需求方应满足的供应链基本安全要求，适用于政务信息系统、关键信息基础设施的信息技术产品供应链安全管理活动，也可为其他信息系统的供应链安全管理活动提供参考。【阅读原文】（来源：信安标委）


【 网络安全事件】

1.联想、海思中招，错误配置致数十家公司源代码泄露

摘要：7月28日消息，数十家公司因基础设施的错误配置致源代码泄露，包括微软、Adobe、联想、AMD、高通、摩托罗拉、华为海思等。代码泄露是由开发者兼逆向工程师TillieKottmann从不同渠道以及错误配置的devop工具中获取的。Kottmann称在代码库中发现了硬编码的凭证，且已经尽可能删除凭证等重要信息，以防由于代码泄露导致的进一步信息或数据泄露。【阅读原文】（来源：互联网安全内参）


2.佳明遭勒索软件重创：业务瘫痪产线停运，被勒索千万美元赎金

摘要：7月23日，健身追踪器、智能手表和GPS产品制造商Garmin遭受勒索软件攻击，导致其服务中断，商用航空产品停运，且被索要高达1000万美元赎金以恢复数据和业务。据悉，Garmin的IT部门关闭了该公司的所有计算机，包括通过VPN连接的在家工作的员工的计算机，以阻止勒索软件在其网络中的传播。此外，据中国台湾当地媒体报道，攻击也导致Garmin生产线停运两天，同时，Garmin官方网站还宣布，由于系统维护，该公司（包括客户服务系统、地图软件更新和应用程序更新）已暂停相关服务。【阅读原文】（来源：安全牛）


3.印度数十万患者医疗影像信息存在泄露风险

摘要：7月28日消息，互联网上暴露了印度各地数十万患者医疗影像数据和个人隐私信息，并可以针对其中一些数据信息执行任意查看、编辑和删除等操作。据悉，通过SHODAN等查找工具发现直接曝露在网上且可直接访问的影像归档和通信系统，可以在线访问获取患者影像信息。此外，还可通过Web医学影像系统admin/admin的弱口令漏洞，登录查看到所有病患的医疗数据记录。【阅读原文】（来源：FreeBuf）


4.美国地方选举官员的电子邮件可能受到网络钓鱼攻击影响

摘要：7月27日消息，根据《华尔街日报》的一份新报告，美国各地的许多选举官员正在使用的电子邮件系统，容易受到网络钓鱼攻击的影响。据报道，几个州的司法机构正在使用免费Exim软件，而俄罗斯GRU情报部门从2019年开始针对该软件进行在线攻击。但安全专家称，由于电子邮件系统并没有连接到计票的系统，因此电子邮件安全薄弱导致选票被黑客攻击的可能性较小。据悉，美国1万个州和地方选举管理机构中，只有不到20%的机构具备先进的反钓鱼控制措施，其中约666名选举官员依靠个人电子邮件地址处理选举相关事务。【阅读原文】（来源：安服信息服务平台）


5. Zoom 再爆安全漏洞：会议默认使用 6 位数字密码能在几分钟内被破解

摘要：近日，安全研究人员公布了 Zoom 的一个关键安全漏洞。通过这个漏洞，任何人都可以加入受密码保护的 Zoom 会议。Zoom的网络客户端允许任何人检查会议的密码是否正确，没有任何尝试次数的限制，6位数字密码可被几分钟内破解。（来源：cnBeta）


6. 数万台 MS SQL 服务器遭爆破入侵，已沦为门罗币矿机

摘要：近日，腾讯安全威胁情报中心检测到针对MS SQL服务器攻击的挖矿木马，该挖矿木马主要针对MS SQL服务进行爆破弱口令攻击，爆破成功后会植入门罗币挖矿木马进行挖矿。同时攻击者下载frpc内网穿透工具安装后门，并会添加用户以方便入侵者远程登录该服务器。从挖矿木马的HFS服务器计数看，已有上万台MS SQL服务器被植入挖矿木马，另有数十台服务器被安装后门。攻击者在失陷服务器上安装内网穿透工具会进一步增加黑客入侵风险，企业数据库服务器沦陷会导致严重信息泄露事件发生。建议企业在所有服务器上避免使用弱口令。【阅读原文】（来源：腾讯安全威胁情报中心）


【 网络安全漏洞】

1.云锁服务器端Windows版本SQL注入漏洞

摘要：CNVD发布了北京椒图科技有限公司主机、终端安全产品“云锁”Windows服务器win_3.1.18.12版本中存在SQL注入漏洞的公告，攻击者可利用该漏洞获取数据库敏感信息。“云锁”是基于操作系统内核加固技术的免费服务器安全管理软件，支持windows/linux服务器跨平台实时、批量、远程安全管理，其与奇安信、公安一所等多家终端安全产品服务商存在合作关系，部分产品也可能使用了受影响组件，请各单位对终端安全产品进行排查是否存在漏洞。（来源：CNVD）


2. 多款SAP软件存在高危漏洞(CVE-2020-6287)

摘要：全球最大的企业管理和协同化电子商务解决方案供应商SAP发布安全更新表示，修复了一个在旗下多款应用系统中广泛使用的SAP NetWeaver AS Java（LM配置向导）模块中存在的严重漏洞（CVE-2020-6287）主要存在于7.30至7.50版本中的模块中。据了解，该漏洞是由于SAP NetWeaver AS forJava Web组件中缺少身份验证，导致未经身份验证的远程攻击者可以通过创建具有高权限用户账户，并执行任意操作系统命令，从而不受限制地访问相关SAP系统。【阅读原文】（来源：虎符智库）


3.安全启动漏洞 BootHole 曝光，几乎影响所有 Linux 和 Windows 设备，超 10 亿台设备中

近日，安全启动漏洞 BootHole（ CVE-2020-10713）曝光，几乎影响所有 Linux 和 Windows 设备，超 10 亿台设备中招。该漏洞CVSS 评级高达 8.2，位于默认的 GNU GRUB2(GRUB2) ，即使运行系统不使用 GRUB2，也会受到影响。如果被成功利用，即使在启用了安全启动的情况下，也可打开 Windows 和 Linux 设备，任意执行代码。【阅读原文】（来源：SegmentFault）
