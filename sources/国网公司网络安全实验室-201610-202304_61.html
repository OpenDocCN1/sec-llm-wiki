BuleHero挖矿蠕虫最新变种分析

原文：http://mp.weixin.qq.com/s?__biz=MzIzMzU4ODQ1Mg==&mid=2247484051&idx=1&sn=04a70b0b316c5344a569dbc1eec3513f&chksm=e8821118dff5980ea4b0af78b492f1afce08641ef4af615a46dec6ddca46b3721483ed85c75c&scene=126&sessionid=1681668621#rd

近日，联研院网络技术分析中心在日常监测中发现了感染BuleHero挖矿蠕虫的僵尸网络发起的网络攻击。BuleHero挖矿蠕虫病毒通过端口扫描程序发现攻击目标，利用永恒之蓝漏洞（MS-17-010）、Apache Struts2远程代码执行漏洞（CVE-2017-5638）、WebLogic WLS组件远程代码执行漏洞（CVE-2017-10271）、WebLogic 反序列化远程代码执行漏洞（CVE-2019-2725）和（CVE-2019-2729）、Tomcat PUT方式任意文件上传漏洞（CVE-2017-12615）和thinkphp5命令执行漏洞（CNVD-2018-24942）和暴力破解等手段攻击目标主机并植入病毒程序进行传播，同时释放门罗币挖矿程序进行挖矿盈利，消耗主机计算资源。

经分析此次攻击的BuleHero挖矿蠕虫是该病毒的新型变种（通过病毒配置文件更新时间推断为2019年7月22日版本），本次变种取消了从外部获取的弱口令字典的链接，改为只使用内置口令字典进行暴力破解（130个），新增了CVE-2019-2729漏洞利用代码。

1.    病毒简介

BuleHero挖矿蠕虫病毒执行过程是通过下载模块（download.exe）下载病毒本体spwrvtifa.exe，释放mimikatz模块，获取服务器密码，释放门罗币挖矿程序和远控木马进行挖矿，释放网络扫描工具（s.exe和masscan），对内置IP.TXT中的目标IP进行445和512端口扫描，发起MS17-010漏洞、Struts2、Weblogic、Tomcat、ThinkPHP5和暴力破解攻击，进行蠕虫传播。

2.1主程序分析

病毒主体文件spwrvtifa.exe执行会拷贝自身文件重命名为ydcbzlk.exe。病毒本体文件会加载远程配置文件、进行IPC$暴力破解攻击，暴力破解使用的用户名、密码字典为程序内置。同时本体文件中还含有weblogic、struts2、thinkphp5、tomcat相关漏洞的攻击利用代码。

远程配置文件http://uio.hognoob.se:63145/cfg.ini

暴力破解功能和使用的字典：

Struts2漏洞：S2-045(CVE-2017-5638)

WebLogic WLS组件远程代码执行漏洞（CVE-2017-10271）：

2.2 挖矿模块

  释放挖矿程序uezubs.exe到C:\windows\temp目录下，挖矿程序执行时会连接矿池46.173.217.80:35791进行挖矿，当挖矿程序运行时主机CPU使用率为100%，无法响应用户操作。

    矿机程序采用XMRig 2.14.1编译

2.3 远控木马

本体释放动态调用API的远控木马ycogcg.exe到系统目录，并将其安装为随机名服务进行启动，并连接C&C地址haq.hognoob.se接收服务端远程控制指令。

2.4 扫描模块

  egbmbeckp.exe（端口扫描工具masscan），gjtqceqbz.exe（端口扫描工具s.exe），并调用scan.bat，针对指定IP段（IP.txt）进行扫描445段口和512端口，保存易受攻击的IP地址段到result.txt中，供NSA武器库和暴力破解攻击进行调用。                         

2.5mimikatz模块

vfshost.exe实际是Windows 明文密码抓取工具mimikatz，利用这个程序抓取感染主机的密码明文，加入到暴力破解的字典中进行局域网暴力破解，因此在局域网中使用通用密码易受这类蠕虫病毒攻击。

2.6NSA武器库

样本携带了挖矿蠕虫常见的NSA武器库进行扩散，NSA武器库利用MS17-010漏洞，内涵永恒之蓝(spoolsrv.exe)、双脉冲星(svschost.exe)、永恒浪漫(docmicfg.exe)、永恒冠军(schoedcl.exe)等多个攻击工具，以及SMB漏洞检测工具Smbtouch（vimpcsvc.exe）来检测易受攻击的目标，提高漏洞攻击效率。漏洞利用成功后执行Payload(AppCapture32.dll、AppCapture64.dll)，控制被攻击主机上下载download.exe，并重复整个攻击过程。

3.安全建议

针对BuleHero挖矿蠕虫，可以通过以下方法进行预防：

1.关闭不必要的端口（如135、139、445）。

2.针对恶意软件利用的漏洞及时排查和修复。补丁下载地址如下：

MS17-010漏洞

Windows Vista SP2、Windows Server 2008 R2及以上版本：https://docs.microsoft.com/zh-cn/security-updates/Securitybulletins/2017/ms17-010

Windows XP、Vista和Windows server 2003、2008等老旧版本：http://www.catalog.update.microsoft.com/Search.aspx?q=KB4012598

Weblogic漏洞

CVE-2017-10271漏洞补丁：https://www.oracle.com/technetwork/security-advisory/cpuoct2017-3236626.html

CVE-2019-2725漏洞补丁：https://www.oracle.com/technetwork/security-advisory/alert-cve-2019-2725-5466295.html

CVE-2019-2729漏洞补丁：https://www.oracle.com/technetwork/security-advisory/alert-cve-2019-2729-5570780.html

Struts2漏洞

S2-045漏洞补丁：https://cwiki.apache.org/confluence/display/WW/S2-045

Tomcat漏洞

CVE-2017-12615漏洞补丁：https://tomcat.apache.org安装最新版本tomcat或在Tomcat的web.xml 文件中配置org.apache.catalina.servlets.DefaultServlet的初始化参数

<init-param>

<param-name>readonly</param-name>

<param-value>true</param-value>

</init-param>

确保readonly参数为true（默认值），即不允许DELETE和PUT操作。

ThinkPHP5漏洞

CNVD-2018-24942漏洞补丁：https://blog.thinkphp.cn/869075
