预警信息描述：

新型病毒：EternalRocks，该病毒利用了7个NSA泄露的工具，同样还是针对SMB协议进行攻击。该病毒会在感染后下载Tor路由（进行匿名通信），然后向C&C服务器发送信号，请求控制指令，然后进行潜伏。24小时后下载NSA泄露的工具，开始对445端口的扫描和传播。

风险等级：

高风险。

漏洞编号：

MS17-010，CVE-2017-0146、CVE-2017-0147、MS14-068、MS10-061、MS09-050、MS08-067。

Windows 7

Windows 10、

Windows 2000

Windows Server 2003

Windows Server 2008 R2

Windows Server 2012

WindowsServer 2016

Windows XP到windows server 2016
