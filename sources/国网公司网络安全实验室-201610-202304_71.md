## “电力芯片设计分析公司重点实验室”开放交流会顺利召开

公司实验室信息通信协作组（以下简称“协作组”）首次开放日活动，于2017年4月12日在北京智芯微电子科技有限公司顺利召开，此次活动由国网信通产业集团智芯公司“电力芯片设计分析国网重点实验室”主办，全球能源互联网研究院信息通信研究所协助组织，活动从技术交流与服务、专题研究、资源共享、科技创新和专业培训等多个方面探讨国网实验室的未来发展，为国网公司在信息通信领域的联合技术攻关孕育良好的环境。

“电力芯片设计分析国网重点实验室”首先介绍了实验室研究及管理经验，然后就“芯片专业技术现状及未来发展方向”做了主题发言，并组织参观了智芯公司芯片分析实验室、安全实验室，与会人员一致对“电力芯片设计分析国网重点实验室”的研究能力和实验室建设成果给予了高度评价。

会上，协作组围绕国家科研体制改革顶层设计和国家电网对重点实验室扶持政策等方面进行了交流，就协作组如何发挥技术领军作用，如何以产业为支撑，以项目为依托吸引人才、培养人才，开展科研合作，联合申报国家级实验室和技术研究中心，以及建立协同机制开展联合攻关，推进北京市国家技术创新中心的建设，孵化国家级和更多省部级资质实验室等方面开展了热烈的讨论。最后协作组组长单位——全球能源互联网研究院——宣贯了后续工作计划，明确了近期工作重点。

## 工业控制系统安全防护国家标准制定工作启动

全国电力系统管理及其信息交换标准化技术委员会组织的“工业控制系统安全防护国家标准”研讨会于2016年4月18日在北京顺利召开，标志着《工业控制系统安全防护导则》的制定工作正式启动。

工控系统往往处于不间断运行状态，任何系统故障都会造成重大损失，而信息安全漏洞、隐患均需要绕过系统的安全防护机制,为指导电力行业建立完善工控安全防护体系，电力领域制定了《电力监控系统网络安全防护导则》。为了进一步扩大工控安全防护体系的建设范围，指导多行业其工控系统的安全防护，联研院、国调中心、中国电科院、南瑞集团、许继集团联合航天科工集团，共同开展《工业控制系统安全防护导则》的制定工作。

此标准的制定，将指导国家重要基础设施行业建立自己的安全防护体系，适用于规划设计、研究开发、施工建设、安装调试、系统改造、运行管理、退役报废等各个环节，将有效提高各行业工业控制系统的安全管理水平，保障其系统安全稳定的运行。

## OPGW覆冰在线监测及融冰技术取得重大突破

中国电力科学研究院信息通信研究所电力特种光缆研究室，历时4年，牵头完成了公司重点科技项目《光纤复合架空地线（OPGW）抗冰技术及措施研究》产学研用协同攻关。研究成果经中国电机工程学会鉴定整体达到国际领先水平。项目构建的OPGW覆冰在线监测技术与融冰控制方法和装置样机系统、技术标准为一体的OPGW抗冰技术体系，结束了OPGW不能融冰历史，为电力通信线路抵御冰灾技术的研究和应用奠定了基础，开拓了方向，有力推动输电线路抗冰技术和冰灾治理技术进步，为促进坚强电网的建设和发展提供保证。

架空线覆冰长期以来都是输电线路的天敌，尤其2008年发生在我国南方地区的大范围雨雪冰冻灾害对输电线路造成了严重危害，停运电力线路计39033条，停运变电站计2037座。OPGW光缆挂点高、运行温度低、缆径小，覆冰更严重，是线路倒塔、跳闸事故发生的主要诱因。长期以来OPGW一直处于覆冰灾害的威胁当中，仅2011年-2015年，我国四川、湖南、重庆、贵州、浙江、华北地区均相继出现了冻雨和覆冰灾害，造成断缆、倒塔、导地线放电等事故，给通信网业务的传输构成严重威胁，对电网安全稳定运行造成严重影响。

近年来的研究成果对输电导线融冰问题已基本得到解决，但OPGW融冰问题始终是线路融冰的技术难点，未得到解决。主要是出于线路防雷需求，OPGW与铁塔之间的连接方式基本都采用逐塔接地方式，使得用于导线融冰的几种技术及装置都无法应用于OPGW线路除冰；且OPGW中光纤对应力和温度极为敏感，对融冰的技术条件和实施方案提出了更为苛刻的要求，一旦融冰电流控制不当，对光缆将产生严重损伤，甚至损毁，造成通信中断。

本成果以基础研究和技术开发相结合，充分考虑OPGW线路特点，创新性地提出适用于线路绝缘化改造和非绝缘化改造的OPGW融冰技术方法和整套技术解决方案；攻克了耐高温、耐高压、抗腐蚀融冰用绝缘导线关键技术，在国内外首次研制出具有自融冰功能的OPGW及附件系列产品；提出了基于覆冰厚度和光纤温度自反馈的OPGW融冰过程自动化控制技术，搭建了集OPGW覆冰融冰在线监测技术和融冰电源温度反馈自动化调节功能于一体的OPGW融冰控制平台，保证了融冰安全性；建立了OPGW动态覆冰与融冰过程计算模型，提出了带并联间隙绝缘子设计布置取值方法和融冰电流计算方法，解决了OPGW在绝缘化改造方式下融冰时易发生冰闪、击穿和光纤烧断等技术难题；提出了可融冰OPGW连接和融冰电源接入方法，研制了可融冰OPGW综合接续盒，开发了轻型化可移动融冰电源，解决了灵活应对微地形、微气象条件影响的局部融冰问题；并建成了OPGW抗冰示范应用工程。

![](../Images/a953b23f3e8016c2323715c3d5aeabe2.png)

通过应用，效果良好，经济效益显著，为覆冰期OPGW线路运行维护工作节省了开支，有效避免了因OPGW覆冰导致的通信系统及线路故障。为抵御OPGW雨雪冰冻灾害工作发挥了重要作用，保障了电网、通信网运行安全。实施光纤复合架空地线防冰综合治理，为解决OPGW线路覆冰问题，显著提高输电线路整体抗冰能力，保障电网供电可靠性有着十分重要的意义。

## 区块链技术在电力行业中的应用

区块链技术是利用块链式数据结构来验证与存储数据、利用分布式节点共识算法来生成和更新数据、利用密码学的方式保证数据传输和访问的安全、利用由自动化脚本代码组成的智能合约来编程和操作数据的一种全新的分布式基础架构与计算范式。  

区块链技术的优势在于以下几点：

1、分布式去中心化，区块链中每个节点都必须遵循同一记账交易规则，而这个规则是基于密码算法，每笔交易需要网络内其他用户的批准。所以去中心化的交易系统不需要单独的一套第三方中介结构或信任机构背书，而是依赖与区块链各节点的整体。

2、不可篡改，区块链中一旦信息经过验证并添加至区块链，就会永久的存储在各节点中，单个节点上对数据库的修改是无效的，因此区块链的数据稳定性和可靠性极高。

3、匿名性，由于节点之间的交换遵循固定的算法，区块链中的程序规则会自行判断活动是否有效，交易双方手无须通过公开身份的方式让对方自己产生信任，所有节点的隐私都进行了加密保护。

4、自治性，区块链采用基于协商一致的规范和协议（比如一套公开透明的算法）使得整个系统中的所有节点能够在去信任的环境自由安全的交换数据。

5、开放性，区块链系统是开放的，除了交易各方的私有信息被加密外，区块链的数据对所有人公开，因此整个系统信息高度透明，监管和审计更为容易。

随着对区块链理解的深入，区块链在电力行业应用的范围也在逐渐扩大。 在电力交易环节，特别是电力改革后，如何在发电方和售电方之间建立均可信任的主体、形成发电方和售电方的任意交易，是当前的一大难点。区块链技术的应用，能够实现能源数字化精准管理，解决交易过程中授信主体问题，使得购电过程更为透明、公正。

在调度控制环节，稳定、持续的记录各调动指令的下达、动作和反馈，进行快速的历史状态追溯是这个环节的一个工作重点。区块链技术的应用，能够稳定、持续的记录各调动指令的下达、动作和反馈，所有调度单位不再需要从各自独立单位的数据库之间进行同步，任何网络上的节点都可以检查、追溯历史状态。

在用电环节，光伏、电动汽车等分布式能源的渗透率不断提高，这些设备都具有向系统倒向功率的能力。如何能源实时地、自动地验证和确保不同节点之间的海量交易，如何低成本实现对上述设备出售的能量进行安全可靠的支付和结算时当前面临的技术难题。通过区块链技术的应用，用电售电环节能够快速交易和清算，且具有较好的审计能力，能够快速处理和追溯任意一笔历史交易。

在源网荷自治与智能配用电环节，现有电网的能源输配网络日益复杂，电网波动时有发生。通过区块链的应用，负荷控制设备能够快速与输配电设施进行互动，根据预源端输入变化进行负荷预测和控制。 

 

## Spring数据处理技术在大数据中的应用

大数据的定量分析能否成功，在很大程度上要依赖于其收集、存储与处理数据的能力。如果企业决策者能获得及时、可靠的见解分析，那么大数据项目的成功几率就会有所提高。如今，想要为数据处理搭建合适的架构，需要付出颇为可观的努力。数据处理的类型主要集中在三个方面：批处理：多用于处理大量具有可扩展性与分布性的静态数据。 实时处理：主要用于处理流式数据（连续不断的无限数据流），这类数据具有分布性与高速率特质。 混合计算模式：这种模式是批处理与实时处理的结合，可处理大容量的高速率数据。

大数据工程很花时间，同时要求工程师具备数据采集与数据处理的相关技巧，在大多解决方案中，时间与技能这两点都必不可少。Pivotal公司发布的Spring XD和Spring Cloud Dataflow这两款产品，都可以大大减少大数据工程中的时间开销。

Spring XD（eXtreme Data，极限数据），这项技术为解决大数据处理的相关任务提供了易于使用的解决方案。Spring XD建立在成熟的Spring技术之上，为数据获取、迁移、处理、深度分析、流处理以及批处理任务提供支持。

Spring XD提供的框架可用于实时处理及批处理任务，该框架具有复杂性、稳定性及可扩展性。有了Spring XD，无论是收集数据，还是将数据从不同的数据源迁移到目标上，都变得更为简单。Spring XD的关键模块包括：Source：数据流的创建总是始于source模块。Source可以使用轮询机制或事件驱动机制，并且只会输出一个结果。 Processor：接受信息输入，并对输入的信息执行某种类型的处理，然后再输出信息。 Sink：顾名思义这个模块是负责终止数据流的，然后将输出结果发送到HDFS之类的外部资源中。 Job：这个模块负责执行批处理任务。

在Spring XD中，本质上不断变更的应用与需求之间还存在着缺口，需要我们在新一轮创新中解决，在第二轮的创新中，Pivotal公司推出了Spring Cloud Data Flow，作为Spring XD的替代产品。Spring Cloud Data Flow继承了Spring XD的优点，并提供了更有扩展性的解决方案——利用云技术的原生方式。Spring Cloud Data Flow是一个混合计算模型，结合了流数据与批量数据的处理方式。开发者可以通过Spring Cloud Data Flow，在诸如数据获取、实时分析、批处理等常见用例中执行数据流的创建与编排。Spring Cloud Data Flow的目标就是为了方便数据工程师，让他们能专注于分析工作和具体的问题。Spring Cloud Data Flow仅提供了管理服务的模型。Spring Cloud Data Flow是Spring XD的修订版，在功能的构成方式上，还有如何协助原生云架构扩展应用方面，都做出了根本性的改变\[1\]。Spring Cloud Data Flow不再使用传统基于组件的架构了，而是采用了信息驱动的微服务架构，这种架构更适合原生云应用平台的原生应用。Spring XD的模块现在被部署到云上的微服务取代。

Spring Cloud Data Flow利用原生云平台引进了新的服务提供商接口（SPI），取代Spring XD原有的运行层。虽然类似Admin REST API、shell层和UI层之类的用户接口与集成元素都与Spring XD中的一致，但底层架构发生了变化。服务提供商接口或者SPI取代了基于Zookeeper的运行方式。现在，SPI能够协同Pivotal的Cloud Foundry或者Yarn之类监控/发布微服务应用的系统一同运作。

核心域模块数据流的主要基础组成，包含了类似source、sink、stream之类的模块，以及批处理任务，所有这些模块都是Spring Boot Data的微服务应用。

模块注册使用Maven维护着可用的模块。ModuleDeployer SPI 在不同的运行环境（比如Lattice、Cloud Foundry、Yarn和Local）中部署模块的抽象层。　　Admin 属于Spring Boot应用，提供REST API和UI。Shell 使用Shell可以运行DSL命令以创建、处理、撤销数据流或执行其他的简单任务，并连接Admin的Rest API。

Spring Cloud Data Flow使用了Spring Cloud stream模块，我们可以利用这些模块以Spring Boot应用的形式创建运行信息传递微服务，这样它们就能部署在不同的平台上，独立运行并相互交互\[2\]。在使用Spring Cloud stream模块创建数据流通道的时候，Spring Cloud Data Flow扮演了粘合剂的作用。目前，在数据收集、实时分析与数据载入方面有很多独立的开源项目。Spring Cloud Data Flow为数据收集、实时分析、批处理与数据输出提供了统一、分布式的可扩展服务。

## 电网信息物理融合系统（GCPS）助力全球能源互联网建设

信息物理系统（CPS）是一个综合计算、网络和物理环境的多维复杂系统，通过3C（Computing、Communication、Control）技术将计算、网络和物理环境有机融合与深度协作，实现大型工程系统的实时感知、动态控制和信息服务。

为进一步贯彻落实《国务院关于深化制造业与互联网融合发展的指导意见》（国发〔2016〕28号）的要求，推动我国CPS发展，支撑制造业与互联网融合，在工信部信息化和软件服务业司的指导下，信息物理系统发展论坛整编归纳了近期关于CPS的主要研究成果，发布了《信息物理系统白皮书（2017）》。

2015年3月9日，《国家电网报》论坛专栏全球能源互联网研究院邱宇峰书记署名文章--《电网信息物理融合系统：面向未来的能源互联网》，首次提出电网信息物理融合系统（Grid Cyber Physical Systems GCPS）的概念。随着电网自动化系统、大容量传输网、泛在传感网的建设，与互联网、能源网等深度融合，智能电网将持续演进形成广域协同、具有自主行为的复杂网络，从而构成电网信息物理融合系统（GCPS）。GCPS通过电网信息空间与物理空间的深度融合和实时交互来增加或扩展新的功能，以安全、可靠、高效和实时的方式监测或控制电网物理设备或系统。

![](../Images/c5d6374e3441d976513660b476ee69f4.png)

图1 电网信息物理系统（GCPS）的概念模型

国家电网公司高度重视电网信息物理融合系统（GCPS）的研究，在2016年国网公司科研指南中部署了基础前瞻类科技项目“电网信息物理融合系统（GCPS）架构及部分关键技术研究”，以期提出信息通信与电网融合的总体框架及网络支撑技术，形成国家电网公司电网信息物理融合系统（GCPS）的行动路线图，目前该项目正按计划、保质保量的顺利推进。

![](../Images/c581036ffb8798c65b2242f4b2287a7b.png)

图2 电网信息物理系统（GCPS）的能力提升

GCPS将显著提升电网的信息感知和状态认知能力。如GCPS可实现多物理量或数据统一采集和共享，突破各专业之间的数据壁垒，使跨越时间、空间、物理障碍的协同成为可能，实现对电网状态的准确认知。

GCPS将通过融入性网络，支持全局优化与局部控制的协同。例如通过具有自适应和自优化能力的网络拓扑，可实现对物理设备的局部控制和控制中心对参数的在线调整，从而实现不间断的负荷控制。GCPS支持标准的电气接口和信息接口，能基于信息/物理空间的融合实现自适应控制。GCPS将和互联网融合，形成开放的公共服务平台，促进用户与电网双向互动。充分利用互联网及大数据，通过互动化服务引导GCPS的不同参与者与总体的控制策略配合，实现人、能量和信息协同，推动生产生活方式转变。

GCPS将综合物理电网的连续模型与计算机的离散模型，突破传统集中式计算平台的约束，具备大规模分布式实时计算的能力。GCPS的任何关键的动态变化，如短路故障，就会以和信息系统的(控制)数据相等的速度扩散开去。GCPS的计算系统包括信息中心及物理设备中嵌入的计算部件，通过计算进程与物理进程的交互，为解决大规模分布式设备的协调优化问题提供了新途径。

GCPS兼顾信息空间安全和物理实体安全，创新分析信息/物理交互影响的耦合性风险，极大提高电网的安全性。电网和信息通信网构成了双层复杂网络，GCPS对物理设备的控制与相互协调在很大程度上依赖信息通信系统。

当今的电网已经进入智能化时代，广泛使用广域传感和测量、高速信息通信网络、先进计算和柔性控制等技术，实现发电、输电、变电、配电、用电和调度六大环节的信息化、自动化、互动化，在一定程度上已经具备CPS的基本特征。随着全球能源互联网的发展，在电网/通信网两个实体网络互联、分布式清洁能源接入、“云物大移”等新技术应用、多种能源网络互联等方面都提出了一系列重大需求。智能电网源网荷互动，与互联网、传感网等深度融合，将持续演进形成广域协同、具有自主行为的复杂网络，从而发展成为电网信息物理融合系统（GCPS）。
