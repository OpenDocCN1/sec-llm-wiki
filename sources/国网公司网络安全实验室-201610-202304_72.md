# 实验室红队取得第三届XCTF国际联赛综合赛二等奖

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzU4ODQ1Mg==&mid=2247483903&idx=1&sn=1d0bd46b5063e90fb661fb57d2715e05&chksm=e8821274dff59b62599437a4d94506257fa895d8f11dd94571aef2a990b085627b7c89e15638&scene=126&sessionid=1681668626#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzU4ODQ1Mg==&mid=2247483903&idx=1&sn=1d0bd46b5063e90fb661fb57d2715e05&chksm=e8821274dff59b62599437a4d94506257fa895d8f11dd94571aef2a990b085627b7c89e15638&scene=126&sessionid=1681668626#rd)

4月27日，“360春秋杯”国际网络安全挑战赛暨第三届XCTF国际联赛北京邀请赛落下帷幕。本次决赛集结了国内外各大知名安全赛事的顶尖战队50支队伍，覆盖地区和国家范围之广，影响力之大是历届赛事之最。

国网公司信息网络安全实验室韩龙玺、王文辉、王杰等三名红队队员组成的GSEC队通过6小时的激烈角逐，最终取得总决赛综合赛二等奖、企业组第一名。公安部副部长陈智敏、公安部网络安全保卫局总工程师郭启全，国家电网公司总部信通部副主任陈春霖出席并观摩了总决赛。
