# 国舜股份出席可信联盟第二届第八次会员大会暨第二届第九次理事会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3NjU5MTIxMg==&mid=2650571940&idx=2&sn=d1bd6cbf53f2707321cef46844a4019d&chksm=8756dda7b02154b1897747aa3eb03f07b3f7393141b6ef49ba43575f20c62bffd74dbef602e3&scene=126&sessionid=1681370648#rd](http://mp.weixin.qq.com/s?__biz=MzA3NjU5MTIxMg==&mid=2650571940&idx=2&sn=d1bd6cbf53f2707321cef46844a4019d&chksm=8756dda7b02154b1897747aa3eb03f07b3f7393141b6ef49ba43575f20c62bffd74dbef602e3&scene=126&sessionid=1681370648#rd)

![](../Images/ca921cfa7aab087d6f9c3176c9635f30.png)

中关村可信计算产业联盟（以下简称：联盟）在北京召开第二届第八次会员大会暨第二届第九次理事会会议，孙瑜副理事长受程春平理事长委托主持会议。国舜股份作为联盟理事单位受邀出席会议。

![](../Images/1b414ae51dd4c2f2418b624bf39710d9.png)

**孙瑜 副理事长**

会议听取了王振宇书记、秘书长等人报告的联盟《2022年工作报告与2023年工作规划》，联盟《2022年财务情况报告》和联盟《2022年会员变动情况》。

![](../Images/6a8f42ccd78265bf5e4a6f8325acd441.png)

**王振宇 书记、秘书长**

联盟监事长贺卫东宣读了第二届第七次监事会会议决议。

![](../Images/dfb46337f8aa2eb4b589d1457d491ce9.png)  

**贺卫东 监事长**

公安部第三研究所副研究员杨元原宣贯解读了《可信认证标准体系》。

![](../Images/53992b727b9d87ba2bab9332d9d51147.png)

**杨元原 副研究员**

四川大学网络空间安全学院研究院院长陈兴蜀作为理事单位代表，向与会代表分享了《安全可信保障数字新基建发展》。

![](../Images/4b5f5e27b28eeb4118dc9009810e2224.png)

**陈兴蜀 院长**

北京工业大学可信计算重点实验室常务副主任张建标作为监票组长宣读了表决结果。

![](../Images/cb482bec752c8dece900a087fc1bde3a.png)

**张建标 常务副主任**

![](../Images/076e37d737d3a9de9d1f8d70ae872edd.png)

**与会代表合影**  

  
会员大会全票通过了内部管控制度、会员代表增补名单、可信联盟延期换届等多项决议。会议还听取了增补理事的候选单位的自我介绍，投票选举增补了相关理事单位。作为新型网络安全企业，国舜股份自成为可信联盟理事单位、金融安全专委会主任单位多年来，始终积极参与联盟牵头的标准制定、技术学术交流等工作，助力良好的产业发展环境营造，推进联盟内外、产学研领域交流与合作，践行网络安全成员企业的责任与担当。来源：可信联盟
