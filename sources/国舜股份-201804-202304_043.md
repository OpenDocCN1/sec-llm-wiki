# 国舜股份携手中邮邮惠万家银行，助力Web应用安全防护新升级

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3NjU5MTIxMg==&mid=2650571594&idx=1&sn=444d8d5df2b43a1ff8fab7e480b27231&chksm=8756da49b021535f4d654084dc2bf8108c8c2fb1f2425250ce7a3e5245085c611aa7a70d0145&scene=126&sessionid=1681370685#rd](http://mp.weixin.qq.com/s?__biz=MzA3NjU5MTIxMg==&mid=2650571594&idx=1&sn=444d8d5df2b43a1ff8fab7e480b27231&chksm=8756da49b021535f4d654084dc2bf8108c8c2fb1f2425250ce7a3e5245085c611aa7a70d0145&scene=126&sessionid=1681370685#rd)

**近日，国舜股份网页防篡改能力再获认可：**国舜股份与邮惠万家银行达成合作，将以UnisGuard网页防篡改保护系统V6.0为客户Web安全提供保障和大力支持，助力客户在不影响网络用户正常浏览网站、不改变原有的网站结构、不增加维护方式的前提下对网站实施最大的限度的保护，防止Web页面文件、后台数据库被非法操作。

![](../Images/a87ebba1a32d5a36ec05db79b568266a.png)中邮邮惠万家银行有限责任公司（简称“邮惠万家银行”）是中国邮政储蓄银行出资50亿元发起设立的直销银行子公司，邮惠万家银行作为邮储银行数字化转型发展的试验田，以“服务三农、助力小微、普惠大众”为使命，致力于打造金融服务乡村振兴、科技助力美好生活的创新平台。邮惠万家银行构建了具有数字银行特征的以微服务和分布式生态为主的技术体系，投产了包括核心系统、信贷系统、统一支付系统等13个信息系统，如何加强网站的内容安全与运行安全，一直是邮惠万家银行关注的问题。近年来国家不断出台完善网络安全法律法规，强调主体责任要求。如**《党委（党组）网络安全工作责任制实施办法》（厅字〔2017〕32号）**第三条规定了“各级党委（党组）的网络安全责任：各级党委（党组）对本地区本部门网络安全工作负主体责任，领导班子主要负责人是第一责任人，主管网络安全的领导班子成员是直接责任人。”**《中华人民共和国网络安全法》**第五十九条第一款：网络运营者不履行本法第二十一条、第二十五条规定的网络安全保护义务的，由有关主管部门责令改正，给予警告；拒不改正或者导致危害网络安全等后果的，处一万元以上十万元以下罚款，对直接负责的主管人员处五千元以上五万元以下罚款。

![](../Images/dd257838cb3091e2f19ca10c6e8b0b80.png)

同时，**《信息安全技术网络安全等级保护基本要求》**的发布，金融行业也出台行业规范（如银发〔2019〕237号文等），对信息安全要求越来越高，邮惠万家银行下定决心加强Web安全。  

**主要威胁**

*   总网络与各级单位的连接，可能遭到来自各地的越权访问；  
    
*   恶意攻击和计算机病毒的入侵；
*   恶意软件或从Internet 下载的黑客程序恶意攻击内部站点，致使网络局部或整体瘫痪；
*   SQL注入、XXS跨站脚本、信息泄露安全风险被利用；
*   对目标网站挂马；
*   关键页面被篡改伪认证，攻击者可以上传后门文件等。

  

**国舜方案**

邮惠万家银行经过广泛调研、深入交流和严格的产品测试，在多个竞品中选中了国舜的网页防纂改用于Web应用安全方案中的网站内容安全防护。  
国舜为保障邮惠万家银行网站内容安全，提高互联网网站类系统的页面防篡改能力，在服务器上安装了网页防篡改软件，为客户网站的重要文件提供高层级的保护，不仅可防止黑客篡改网页或文件，也可防止勒索病毒纂改重要文件，助力解决在 Web 应用系统中面临的内容安全问题，确保对外运行的网站页面不被非法篡改，以免以此带来巨大损失。        

**UnisGuard网页防篡改保护系统**是国舜股份设计开发的一套以文件过滤驱动技术为基础，结合核心内嵌技术和事件触发技术等多种技术开发的Web网页防篡改产品，遵循Internet相关标准协议，针对Web网站服务器上的页面文件、数据库内容等Web系统相关组件，进行访问控制。可对Web应用网站提供文件保护、数据交互保护、主动防御、防扫描、防暴力篡改、安全漏洞防护、攻击事件阻断等防护功能，保护客户Web应用网站的安全、稳定、及时地运行。

国舜股份的安全技术和解决方案已在上千家金融、通信、政企、能源、交通、医疗等机构成功落地，拥有众多典型应用案例并多次荣获行业大奖，赢得客户们的广泛认可和好评。  
未来，国舜股份将继续坚持“以客户为中心，以奋斗者为本”的核心价值观，为客户提供优秀的产品、服务与解决方案，护航安全、合作共赢，为构建安全可信的网络空间而不懈奋斗。
