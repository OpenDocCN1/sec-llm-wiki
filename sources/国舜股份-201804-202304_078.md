# 国舜股份通过国际软件工程领域最高级别CMMI5级评估认证

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3NjU5MTIxMg==&mid=2650571251&idx=1&sn=704b3eb069d35a3ca782945a9abb60eb&chksm=8756d8f0b02151e613880c6bb6354cba885656699beb8e2d734e3a821433f5a5533a46c3d469&scene=126&sessionid=1681370700#rd](http://mp.weixin.qq.com/s?__biz=MzA3NjU5MTIxMg==&mid=2650571251&idx=1&sn=704b3eb069d35a3ca782945a9abb60eb&chksm=8756d8f0b02151e613880c6bb6354cba885656699beb8e2d734e3a821433f5a5533a46c3d469&scene=126&sessionid=1681370700#rd)

近日，经过严格的现场审核和评估，**国舜股份正式通过国际软件工程领域最高级别CMMI5级认证。**CMMI5级认证的成功通过标志着国舜股份资质工作更加完善，软件过程能力、产品研发能力、实施交付能力、项目管理能力等均达到国际先进水平。

![](../Images/cdaf2e4dc7a460aee6c72f099843a795.png)

**CMMI（Capability Maturity Model Integration）**即能力成熟度模型集成，是由美国卡内基梅隆大学SEI研究所制定的一套评估认证体系，是衡量软件企业能力成熟度和项目管理水平的权威标准。CMMI5级为该体系最高等级评估，是目前国际软件行业对管理成熟度要求最高、申请难度最大、级别最高的评估，同时也是对企业在标准化、规范化、成熟度方面的最高认证。

CMMI5级认证的通过，是对国舜股份在软件设计、开发、项目管理及为用户提供高质量产品和服务提供体系保障实力方面的进一步认可，标志着国舜软件过程能力、产品研发能力、实施交付能力、项目管理能力等多个方面均达到国际先进水平。将进一步增强国舜软件产品和服务层面的核心竞争力，助力为客户提供更优质、更完善的产品与服务。  
作为新型网络安全企业，国舜股份始终致力于从安全云化、安全数据化、安全服务化、全生命周期开发等多维度把关键行业的安全服务精深化，着力推动全线安全产品与服务的高性能化。以此次CMMI5级认证通过为契机，国舜股份将不断锐意创新、扎实前行，运用在安全领域十余年的行业研究与探索积淀，为客户提供更优质、更专业的网络安全产品及网络安全整体解决方案，以更高标准助力网络空间安全建设。
