# 国舜网页防篡改保护系统与南大通用安全数据库管理系统完成兼容互认证

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3NjU5MTIxMg==&mid=2650570024&idx=1&sn=c1b304e621b87d701a115543f554733f&chksm=8756242bb021ad3d37ad1fef9199a1f7eedc32b11c51f9f014212ea38904c15ba846d44702d7&scene=126&sessionid=1681370731#rd](http://mp.weixin.qq.com/s?__biz=MzA3NjU5MTIxMg==&mid=2650570024&idx=1&sn=c1b304e621b87d701a115543f554733f&chksm=8756242bb021ad3d37ad1fef9199a1f7eedc32b11c51f9f014212ea38904c15ba846d44702d7&scene=126&sessionid=1681370731#rd)

近日，**国舜网页防篡改保护系统与南大通用安全数据库管理系统完成了兼容互认证。**经过双方严格的共同测试表明，国舜UnisGuard网页防篡改保护系统V5.0与南大通用安全数据库管理系统GBase 8s V8.8可以顺利适配，相互良好兼容、稳定运行。![](../Images/316dbbcd7c7f09f7ec2e0f159001497d.png)

网页防篡改保护系统是国舜股份设计开发的一套以文件过滤驱动技术为基础，结合核心内嵌技术和事件触发技术等多种技术开发的Web网页防篡改产品，遵循Internet相关标准协议，针对Web网站服务器上的页面文件、数据库内容等Web系统相关组件，进行访问控制。可对Web应用网站提供文件保护、数据交互保护、主动防御、防扫描、防暴力篡改、安全漏洞防护、攻击事件阻断等防护功能，保护客户Web应用网站的安全、稳定、及时地运行。国舜网页防篡改系统适用于政府、金融、运营商、工商、社保、教育、电子商务等涉及Web应用的各个行业，十余年来为客户提供稳定、规模化和可持续运营的安全护航。

作为新一代场景化网络安全综合解决方案供应商、国家高新技术企业，国舜股份持续以创新的技术研发、丰富的认证资质致力于为客户提供DEVSECOPS、XDR、Web应用安全、等保合规等领域的产品、服务和整体解决方案。加速发力信创捷报频传，国舜股份上榜由中国科学院主管权威媒体《互联网周刊》评选的“2021中国信创500强”名单，国舜UnisGuard网页防篡改保护系统已陆续与中国长城、麒麟软件、武汉达梦、神舟通用等完成兼容认证，共推国产化生态建设。

以此次兼容互认证为契机，未来，国舜股份将持续发力国产化生态合作共建，以扎实的技术积累、成熟的产品体系、高效的服务跟进，为网络安全建设保驾护航。
