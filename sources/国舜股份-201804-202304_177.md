# 国舜股份上榜2021年度“中国信创500强”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3NjU5MTIxMg==&mid=2650569812&idx=1&sn=7145278a99df2a955f44e097317792df&chksm=87562557b021ac415f960bc45bb9cf56fb6a91ec85b7738fbd857b3d0392f7375f9cfc539415&scene=126&sessionid=1681370741#rd](http://mp.weixin.qq.com/s?__biz=MzA3NjU5MTIxMg==&mid=2650569812&idx=1&sn=7145278a99df2a955f44e097317792df&chksm=87562557b021ac415f960bc45bb9cf56fb6a91ec85b7738fbd857b3d0392f7375f9cfc539415&scene=126&sessionid=1681370741#rd)

近日，中国科学院主管权威媒体《互联网周刊》评选的**“2021中国信创500强”**名单正式公布，**国舜股份成功上榜。**  

  
![](../Images/2640e685183aac0154f03788444d1c9c.png)  
据悉，此次榜单综合了技术、影响力、用户评价等多维度，对2021年“信创”领域上下游企业进行全方位的综合评估，以展现“信创”发展的成果全貌，为国内企业“信创”发展进一步深化提供行业参考与实践方向。  
在这次信创企业500强榜单中，上榜企业从上游基础软硬件到下游应用软件和信息安全，覆盖了通讯、政务、科技、金融、医疗等多个终端应用领域。其中，在榜单的前150名企业中，有71家为基础硬件类，21家专注于基础软件，64家提供应用软件和服务，12家深耕信息安全。  
  
信创产业，据《中国信创产业发展白皮书（2021）》的归纳，其核心就在于通过行业应用拉动构建国产化信息技术、硬件底层架构体系和全周期生态体系，解决核心技术关键环节“卡脖子”的问题，为中国未来发展奠定坚实的数字基础。   
作为新一代场景化网络安全综合解决方案供应商、国家高新技术企业，国舜股份持续以创新的技术研发、丰富的认证资质致力于为客户提供DEVSECOPS、XDR、Web应用安全、等保合规等领域的产品、服务和整体解决方案。持续发力信创领域，国舜UnisGuard网页防篡改保护系统近期更与中国长城擎天DF7系列（飞腾FT2000+/64+银河麒麟高级服务器操作系统V10）、麒麟软件银河麒麟高级服务器操作系统（飞腾版、鲲鹏版）V10达到通用兼容性要求及性能、可靠性要求，满足用户的关键性应用需求，获得兼容认证，助力信创生态发展。  
![](../Images/37f6466f7f386bfe76fe15b76b0bab57.png)  
未来，国舜股份将继续发力信创领域，以扎实的技术积累、成熟的产品体系、高效的服务跟进，为网络安全建设保驾护航。
