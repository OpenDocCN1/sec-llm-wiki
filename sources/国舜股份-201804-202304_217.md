# 全国信安标委公布《2022年网络安全国家标准需求清单》

近日，全国信息安全标准化技术委员会秘书处发布通知，调研国家网络安全重点工作和技术产业发展需求，研究形成了2022年网络安全国家标准需求清单并面向社会征求意见，旨在加强网络安全国家标准在国家网络安全保障工作中的基础性、规范性、引领性作用。
