# 国舜股份入选首批工信部车联网产品安全漏洞专业库技术支撑单位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3NjU5MTIxMg==&mid=2650568814&idx=1&sn=1c4a984617ed82f36f11adb5f94af7c7&chksm=8756216db021a87bda3d5b3ce889b59425ae4c8e1f637974d2f93f67e4f53f02f90ac4a36b43&scene=126&sessionid=1681370771#rd](http://mp.weixin.qq.com/s?__biz=MzA3NjU5MTIxMg==&mid=2650568814&idx=1&sn=1c4a984617ed82f36f11adb5f94af7c7&chksm=8756216db021a87bda3d5b3ce889b59425ae4c8e1f637974d2f93f67e4f53f02f90ac4a36b43&scene=126&sessionid=1681370771#rd)

近日，CAVD秘书处（中汽数据有限公司）通过组织行业专家综合评审，遴选出10家单位成为工信部车联网产品安全漏洞专业库（CAVD）首批技术支撑单位并正式公布，**国舜股份成功入选。**

![](../Images/46b1c48ed8be9ed4975728c8580aa7cb.png)

  

为贯彻落实《网络产品安全漏洞管理规定》的要求，在工业和信息化部网络安全管理局组织指导下，中国汽车技术研究中心有限公司承接工业和信息化部车联网产品安全漏洞专业库（CAVD）的建设工作。

#   

# 为了进一步提高车联网产品重大漏洞和重要安全事件发现、分析、处置的能力，建立车联网产品安全漏洞管理的良性机制，CAVD秘书处（中汽数据有限公司）于9月28日发布公告，遴选在车联网信息安全、网络安全、数据安全领域具有较强技术实力以及较强社会责任感的优秀技术队伍成为CAVD技术支撑单位，截至12月15日，共26家单位自主申报成为CAVD技术支撑单位，国舜股份凭借综合安全实力成功脱颖而出，入选首批支撑单位。

  
未来，国舜股份将充分发挥自身网络安全技术服务优势，与CAVD通力协作，开展车联网漏洞挖掘、漏洞验证、漏洞分类分级等相关工作，为车联网网络安全保驾护航。
