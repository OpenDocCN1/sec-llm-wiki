# 国舜物联网安全网关、数据防泄漏系统发布，多元护航网络安全

12月7日，国舜线上新品发布会成功举行。本次国舜股份共带来物联网安全网关、数据防泄漏系统两款新品介绍，展现国舜聚焦多领域客户的网络安全防护痛点，汇聚自身全新安全力量，多元化护航客户网络安全的初心。

  

**物联网安全网关**

  

国舜股份借助多年的行业积累，结合自身研发体系，将各种功能模块间进行了融合创新，打造出多功能适配的物联网安全网关产品，采用通用的硬件架构设计，结合物联网市场的实际需求，以业务量为基准进行产品体系的规划布局，符合等保2.0及公安部的安全区域边界防护的相关要求，适用于多种物联网的安全防护场景。

  

![](../Images/7ddb73d9c17f9eeb7bfd3ff16c77c6c6.png)

  

**数据防泄漏系统**

  

**国舜数据防泄漏系统**是一款致力于解决企业内部数据泄漏问题的终端安全产品。不论是敏感数据的识别与分类规则，还是数据泄漏场景的覆盖，针对复杂的数据泄漏场景，数据泄漏防护通过终端 Agent 收集数据+大数据后台分析数据的模式，将海量终端原始日志进行关联分析，实现从敏感行为监控到风险预警到证据链追溯的完整解决方案，为企业安全运营提供高效的监管能力。

  

![](../Images/3bd200ac98b438dfa4bc0c16d83cefcd.png)

  

“为国家网络空间守护安全，为商业巨人业务保驾护航”是国舜股份一直坚持的发展理念。本次线上产品发布会得到了行业用户的积极响应和广泛参与，并在答疑环节纷纷就关心的问题进行了沟通讨论。国舜股份也将继续秉承创新发展观，持续发挥自身多年来的网络安全积淀，为更多用户的网络安全保驾护航，助力构建高效、可控的安全网络环境。
