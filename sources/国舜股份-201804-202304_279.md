# 观点 | 工业 4.0离不开工控安全的支撑

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3NjU5MTIxMg==&mid=2650568351&idx=1&sn=e026b4faedb835a5534ff688f4bc995d&chksm=87562f9cb021a68a9e02f525fc2940826a3cf2812543d5f465055055ee4bb07f7178eb7eb68f&scene=126&sessionid=1681370776#rd](http://mp.weixin.qq.com/s?__biz=MzA3NjU5MTIxMg==&mid=2650568351&idx=1&sn=e026b4faedb835a5534ff688f4bc995d&chksm=87562f9cb021a68a9e02f525fc2940826a3cf2812543d5f465055055ee4bb07f7178eb7eb68f&scene=126&sessionid=1681370776#rd)

![](../Images/ca921cfa7aab087d6f9c3176c9635f30.png)  

缺乏工控安全加固的工控系统将无法真正体现工业4.0的优势，企业必须采取措施以减轻安全风险。

  
工业 4.0 有望为制造业带来前所未有的变革。物联网 (IoT)、人工智能 (AI) 和边缘计算等技术可以使制造业比以往任何时候都更加高效、灵活和有弹性。然而，糟糕的工业网络安全正在威胁着这一未来。  
网络攻击在所有行业都是一个日益严峻的问题。根据一份报告， 全球 86.2% 的组织在 2021 年发生了数据泄露。这是迄今为止的最高百分比，也是六年来年度攻击增幅最大的一次。  
随着国家关键信息基础设施采用更多的数字化技术，它变得更容易受到这些攻击。  

**工控安全的现状**

![](../Images/543493e173d8274a17962f6c38a0966e.png)  
鉴于当今工控安全的状况，网络攻击的增加令人担忧。大多数工业基础设施对网络犯罪的准备不足。攻击在 2020 年几乎频繁袭击了每个行业，据一份相关报告显示，工控企业已成为是第二代攻击目标。  
黑客可以渗透到高达 91% 的工控企业，渗透测试人员能够访问其中75% 的工业控制系统 (ICS) 网络。  
这种缺乏工控安全防护的现状是可以理解的。过去，对于关键信息基础设施和其他工业应用来说是没问题的，因为只能通过面对面的方式进行控制访问。随着企业数字化转型升级，必然对新威胁而且要保持开放的态度，但很多公司基本上没有意识到这一点。  
无工控安全防护已经成为历史，但很多企业都不知道如何面对安全现状以及如何加强防护，甚至觉得没必要做，这是大错特错了。  

**IT与OT的融合如何威胁工业 4.0？**

![](../Images/543493e173d8274a17962f6c38a0966e.png)  
虽然缺少工控安全可能是可以理解的，但现实却是不可接受的。如果没有必要的工控安全计划，该行业可能会遭受更大的损失，从而限制工业 4.0的转型。  
对工业目标的网络攻击代价高昂。当臭名昭著的 NotPetya 勒索软件攻击默克公司位于费城的生产工厂时，造成了 8.7 亿美元的损失并导致生产停止。如果工业 4.0 技术在没有加固工控安全的情况下发展，类似的攻击将变得更加普遍。  
如此巨大的损失会抵消工业 4.0 带来的成本节约。随着国家关键信息基础设施的加速转型升级，事态也可能走向更极端。此类网络攻击可能导致数百万人失业、削弱国防或中断政府通讯。  

**工控安全如何改善？**

![](../Images/543493e173d8274a17962f6c38a0966e.png)  
制造业和其他工控企业面临着艰难的选择。他们要么加固工控安全系统，要么将自己的利益、员工和客户置于危险之中。值得庆幸的是，选择前者是一个非常有效的方式。以下是一些可以加固工控安全的关键方法。  

**物联网安全**

  
工控安全最关键的领域可能是物联网安全。随着工业 4.0 的发展，增加了更多的连接设备。尽管有这些好处，但拥有更多连接的设备也就意味着有更多的攻击渠道或路径，而这些物联网设备本身通常缺乏强大的内置安全机制。  
保护物联网设备的第一步是加密其数据流量。加密使黑客无法读取设备之间传输数据，即使被拦截，也几乎毫无用处。设备还应具备密码口令的安全访问机制，并及时更新这些密码，尽量避免采用默认登录信息。  
其次，企业应该将他们的物联网设备进行独立组网，很多物联网设备传输的信息是比较敏感的，并且要采取必要的隔离手段，保护物联网外部接口的安全接入与访问。  

**员工培训**

  
必须改进工控安全另一个方面是要进行员工培训。德勤的一项研究发现， 10大网络威胁中有4种是来自于企业内部员工的， 人为错误甚至可能危及先进的安全系统，因此所有员工都应了解工控安全的原则理念。  
工控企业应对所有员工进行安全培训，可以识别出企图欺骗用户泄露信息或访问权限网络钓鱼。如果员工能够识别攻击并做出适当的响应，工控系统就可以免受网络攻击。  
当然，即使提供了充分的安全培训，工控企业也应考虑限制用户级别的访问。每个员工拥有的访问权限越少，被盗帐户造成的损害就越小。针对企业员工分配最小特权是一种比较理想的安全手段。  

**持续改进**

  

最后，工业公司应该秉持不断改进的精神。就如同制造商探索不断改进的业务流程一样，也应该对工控安全措施做同样的工作。  
工控企业应考虑定期渗透测试。渗透测试即让网络安全专家试图破坏系统以揭示系统的弱点，其可以揭露企业如何应对新出现的威胁，在网络攻击逐渐升级的过程中保持工控系统的安全。  

**工业 4.0 需要高工控安全支撑**

![](../Images/543493e173d8274a17962f6c38a0966e.png)  
工业 4.0 是产业的发展趋势与必然，企业要借此转型获益，就需要加固工控安全。丰富的安全标准将保证新技术不会产生不必要的安全问题。  
工业 4.0 本身并不危险，但确实带来了新的安全风险。企业必须积极应对这些风险，才能充分体验第四次工业革命的利益。
