# 国舜股份入选贵州省2021-2023年网络安全技术支撑单位

近日，贵州省通信管理局公布了2021-2023年网络安全技术支撑单位遴选结果，**国舜股份成功入选。**

  

![](../Images/6d10ffadea3460a645d1b1b0874e2feb.png)  

  
本次遴选坚持“自愿申请、公开透明、择优评选、动态管理”的原则，依据《网络安全法》《数据安全法》《关键信息基础设施安全保护条例〗》等法律法规，结合工作实际，旨在应对日越严峻复杂的公共互联网网络安全形势，提升网络安全管理工作综合应对能力，切实保障贵州省公共互联网安全、稳定运行。  

入选单位未来将配合贵州省通信管理局开展支开展网络安全监测预警、风险评估、渗透测试和漏洞扫描、工业互联网安全、网约车线上服务能力审核、APP安全检测、数据安全、软件安全检测、项目建设申报等方面工作，切实护航网络安全。  

  
国舜股份长期坚持纵深、动态、主动的网络安全理念，以扎实的安全技术，多样的安全资质，高效的安全服务队伍，丰富的安全咨询、安全系统集成及安全服务经验，为用户提供定制化、多元化的综合安全解决方案，助力网络安全水平提升。  
此次成功入选网络安全技术支撑单位是对国舜股份综合实力的肯定。未来，国舜股份继续坚持业务驱动、数据驱动、价值驱动，运用在安全领域十余年的行业研究与探索积淀为更多行业客户的网络安全保驾护航，助力构建高效、可控的安全网络环境。
