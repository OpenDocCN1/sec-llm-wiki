物联网安全吗？


物联网大家并不陌生，许多耳熟能详的产品已经融入到物联网庞大的体系中。伴随着互联网+、工业物联网（IIoT）、人工智能物联网（AIoT）等概念的提出与泛化，驱动了物联网市场的飞速发展。据《中国互联网发展报告（2021）》统计，2020年的物联网市场规模高达1.7万亿。如此大的市场规模已经成为行业界不得不重视的关键领域。

物联网作为一种传统网络的扩展与延伸，融入了更多、更大、更广的产品体系，从日常生活中的无线路由器、网络电视、智能家居到公司企业中的交换机、路由器、扫描仪、打印机、门禁、投影仪、IP摄像头、公共广播等，基本是无处不在，涉及到我们工作生活的方方面面。物联网在带来便利的同时，也因为其固有的特点和特定的场景带来了各种不确定的安全风险。近几年安全事件层出不穷：

2016年10月，Mirai僵尸网络针对美国主要域名服务商Dyn发送大规模DDoS攻击，导致美国大面积网络中断，其攻击源很多来自物联网终端。


2017年9月，出现针对物联网终端漏洞的IoT_reper病毒，专门针对物联网终端的漏洞进行攻击。


2018年5月， Talos 研究人员发现VPNFilter 感染了全球 54 个国家的超过 50 万台路由器与 NAS 设备，品牌包括 Linksys、MikroTik、Netgear、TP-Link、华硕、华为、中兴和 D-Link 等。利用恶意程序的中间人攻击模块 ssler，攻击者通过被感染路由器的流量注入恶意负载，甚至能悄悄修改网站发送的内容。


2019年6 月，一名未成年人使用Silex的恶意软件专门针对运行 Linux 或 Unix 操作系统，破坏设备的磁盘分区，删除其防火墙和网络配置，并最终使其完全“变砖”。


2020年12月，某实验室的研究人员发现了一个名为“Gitpaste-12”的蠕虫。该蠕虫针对web应用程序、IP摄像头、路由器等进行了一系列广泛的攻击，具备DDOS攻击、恶意挖矿、文件操作等功能及蠕虫自我传播等功能。


2021年9月，据Kaspersky分析统计，今年上半年监测到了15亿次的物联网攻击，而去年下半年仅6.39亿次，攻击数量增长一倍多，增速高达130%。据监测分析其主要攻击目的集中在窃取数据、挖矿或僵尸网络等。

看起来网络架构与传统架构基本类似，从某种角度上看比传统网络要简单许多，但为什么还有众多的安全问题呢？主要是前端感知层存在短板效应所致。我们进行了基础性的分析，主要体现在以下三个方面：

  • 终端数量庞大、安装部署分散、很难有效的进行安全管理。
  • 大多数终端处于无人值守状态，很容易受到毁坏、篡改、仿冒。
  • 终端操作系统容易受到网络攻击、漏洞无法及时修复。

物联网安全思考


面对如此多的安全风险自然需要有相应的安全措施进行应对：

首先，需要构建有效的物联网资产清单。资产清单是物联网体系最基础也是最根本的管控单元，没有资产管理，安全管控就失去了作用体系。我们通常的资产管理都是简单的识别IP地址、端口等基础信息，而面对如此巨大而且功能简单的物联网终端就不太合适，我们需要借助深度探测与识别技术进行全方位立体化的对资产进行扫描、识别、分析、确认等，保证资产本身具有其自身特有的“指纹”，尽量避免资产多和杂而带来的管理安全风险。

其次，需要关联资产构筑资产唯一画像能力。基于“指纹”模式的资产准入比对可以有效提升接入侧的安全性，有效避免非法资产或受损资产，增强准入门槛。如果遇到针对性非常强的仿冒或克隆设备可能就无法区分，此时就构建行为画像基线来丰富限制模式。例如构建链路基线、业务基线、流量基线等，借助“指纹”和“基线”构筑资产唯一的行为画像，安全防护能力自然可以大幅度提升。

最后，需要具备内置风险探测与威胁阻断措施。物联网资产初始的弱口令、弱通信机制需要及时探测，及时发现并进行适当的修复或增加其他管控措施。针对系统本身的威胁、漏洞、缺陷、配置错误等问题应采取积极主动的扫描、检测、监控、告警等，并辅以相应的安全管控措施，提升安全风险的处置能力和应对能力。

解决方案思路


物联网安全解决方案通过对措施的落地就可以形成，但是这样至少需要资产管理系统（扫描+识别）、资产画像系统（准入+行为+访问控制）和资产威胁分析处置系统（传统防火墙+入侵防御/检测+防病毒）等三个产品。这对于物联网本身就是一个奢华的方案，如何才能转变这种局势，似乎只有一种方案，安全功能All-in-One。
 
【国舜物联网安全解决方案】国舜股份借助多年的行业积累，结合自身研发体系，将各种功能模块间进行了融合创新，打造出一个全功能适配的物联网安全网关产品。该产品采用通用的硬件架构设计，结合物联网市场的实际需求，以业务量为基准进行产品体系的规划布局，形成特有的物联网安全网关产品。




产品的主要特点如下：
  1. 深度识别，自动提取指纹
  2. 终端准入与行为特征结合
  3. 整合安全，防御漏洞
  4. 集中管理，分布式部署
  5. 通过大数据技术的行为分析
  6. 支持旁路部署，不增加故障点
