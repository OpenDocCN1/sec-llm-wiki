# 北京交通大学软件学院和计算机学院领导一行莅临国舜股份参观交流

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3NjU5MTIxMg==&mid=2650567975&idx=1&sn=e57a37537face33c89d9c9cd2e0485b7&chksm=87562c24b021a532d3427873c4e1dc84c65f4f44eea38c3339cf453619acc1ff800610a70970&scene=126&sessionid=1681370791#rd](http://mp.weixin.qq.com/s?__biz=MzA3NjU5MTIxMg==&mid=2650567975&idx=1&sn=e57a37537face33c89d9c9cd2e0485b7&chksm=87562c24b021a532d3427873c4e1dc84c65f4f44eea38c3339cf453619acc1ff800610a70970&scene=126&sessionid=1681370791#rd)

![](../Images/ca921cfa7aab087d6f9c3176c9635f30.png)  
近日，北京交通大学软件学院刘吉强院长、车啸平副院长、计算机与信息技术学院信息安全系王健主任等领导一行莅临国舜股份北京总部参观交流，国舜股份董事长兼总裁姜强热情迎接并全程陪同。  
![](../Images/65d01cd624bc1171cd0e0858b6dcd5cd.png)  
姜强董事长对到访来宾表示热烈欢迎，并介绍了国舜股份的发展历程、业务布局、研发团队等情况。国舜股份作为一家面向政府、金融、通信、能源、电力、交通等关键行业的专业化信息安全产品及整体解决方案咨询服务商，多年来不断创新完善自有知识产权的安全业务体系，助力用户在开发安全、大数据交易反欺诈、态势感知、Web应用安全、工业安全等方面的痛点突破。  
北京交大软件学院和计算机学院相关领导就学院的专业布局、师资科研力量、校企合作经历等做了简要介绍，并希望双方就学术交流、实训项目、人才培养等多方面加强合作。双方均表示将就契合的点加强沟通合作，实现优势互补、多方共赢。  
经过本次参观交流活动，增进了校企双方的相互了解，为日后进一步合作交流拓宽了道路。
