# 国舜股份受邀出席工信部移动互联网APP产品安全漏洞库发布会暨特设工作组成立仪式

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3NjU5MTIxMg==&mid=2650567868&idx=1&sn=dcb3eb78d84343a80161c1e68e09c147&chksm=87562dbfb021a4a90d1b4aaab569942a2f03c36367359e0921430e8da827aac4a9780a93b341&scene=126&sessionid=1681370796#rd](http://mp.weixin.qq.com/s?__biz=MzA3NjU5MTIxMg==&mid=2650567868&idx=1&sn=dcb3eb78d84343a80161c1e68e09c147&chksm=87562dbfb021a4a90d1b4aaab569942a2f03c36367359e0921430e8da827aac4a9780a93b341&scene=126&sessionid=1681370796#rd)

![](../Images/ca921cfa7aab087d6f9c3176c9635f30.png)  

近日，由中国电子信息产业发展研究院、中国软件评测中心（工业和信息化部软件与集成电路促进中心）主办，中国计算机行业协会协办的工业和信息化部移动互联网APP产品安全漏洞库发布会暨安全漏洞管理特设工作组成立仪式在京举办。**国舜股份作为中国计算机行业协会常务理事单位受邀出席。**  

  
![](../Images/db3383e5ce52104358842bd783283dc3.png)  
**工信部网络安全局副局长陶青表示**, 当前，网络技术与国民生产生活高度融合，伴随着移动互联网应用业务的高速发展，网络产品安全漏洞风险日益突出。《网络产品安全漏洞管理规定》的出台将推动网络产品安全漏洞管理工作的制度化、规范化、法治化，提高相关主体漏洞管理水平。下一步，工信部将从政策宣贯、机制完善、平台建设多方面抓好落实，组织做好网络产品安全漏洞综合管理。  
![](../Images/9e0502d1804859f7077b484559c0a330.png)  
**北京市通信管理局副局长王晖表示**, 北京市通信管理局将在工信部指导下承担起电信和互联网行业网络产品安全漏洞监管管理职责。同时希望各单位以《规定》为基本遵循，在部网络安全管理局的指导下，共同为维护首都的网络安全贡献一己之力。  
![](../Images/74a866ac1b17133dd4e8bbc631dd7ab3.png)  
**中国电子信息产业发展研究院副院长黄子河表示**，当下的网络安全防护不再只是依赖某个个体或组织，而是基于情报共享、协同合作的网络安全生态链。移动互联网APP产品安全漏洞库及安全漏洞管理特设工作组将联合业界各方建立统一规范的收集、验证、处置体系，聚集多方能力要素，切实提升我国在移动互联网App产品安全漏洞管理水平，促进移动互联网产业安全有序发展。  
据悉，为贯彻落实《中华人民共和国网络安全法》《网络产品安全漏洞管理规定》，提高网络产品安全漏洞管理水平，在工业和信息化部网络安全管理局的组织指导下，中国软件评测中心建设了工业和信息化部移动互联网APP产品安全漏洞库，并在中国计算机行业协会下成立安全漏洞管理特设工作组，负责相关漏洞收集、认证、修补和发布等全生命周期管理。
