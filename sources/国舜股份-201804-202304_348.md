# 国舜宙斯盾互联网安全应急响应中心、太湖网络安全培训基地正式成立

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3NjU5MTIxMg==&mid=2650567631&idx=1&sn=7a1a88484f8ad5dcd05ea0e5ecd9955a&chksm=87562accb021a3daf120974c5cf2f61adec0b422fa8459878a381598f45a9017e5b795e7577c&scene=126&sessionid=1681370807#rd](http://mp.weixin.qq.com/s?__biz=MzA3NjU5MTIxMg==&mid=2650567631&idx=1&sn=7a1a88484f8ad5dcd05ea0e5ecd9955a&chksm=87562accb021a3daf120974c5cf2f61adec0b422fa8459878a381598f45a9017e5b795e7577c&scene=126&sessionid=1681370807#rd)

![](../Images/ca921cfa7aab087d6f9c3176c9635f30.png)  
  

在近日举行的苏州国舜开业仪式上，国舜宙斯盾互联网安全应急响应中心、太湖网络安全培训基地正式揭牌。 

  

**宙斯盾互联网安全应急响应中心**

  
![](../Images/88c74a185eb7a06261ba16202554baac.png)

原国家计算机网络与信息安全管理中心主任、中国互联网协会副理事长、中国网络空间安全协会副理事长黄澄清（右）与吴中经济技术开发区党工委委员、管委会副主任郁克铭为宙斯盾互联网安全应急响应中心揭牌

  
宙斯盾互联网安全应急响应中心是由具有经验丰富的应急响应服务团队、身经百战的专业分析专家作为后端技术支撑，形成全面的技术人员体系。并依靠多年对高级威胁攻击以及广泛企业内部安全事件的研究，配置高级安全分析人员，全面做到攻陷检测和高危攻击检测，保证了应急结果的精准性和广度。再加以结合历年来千余起现场应急实战经验，为后续处置安全事件积累了丰富的实战经验和宝贵的案例分享。  
![](../Images/8245a8b0678871e9a6ac733efb93f3c2.png)  
  

**太湖网络安全培训基地**

  
为适应网络安全行业变化迅猛的特点，提高企业网络安全人才专业技术水平和职业化素养，国舜正式成立太湖网络安全培训基地，搭建企业网络安全人才培养体系和网络安全人才技能提升阶梯，最终实现为客户创造更大价值的目标。  

![](../Images/4dccbc03e43954befbcbb922725c268f.png)

赛迪工业和信息化研究院集团（苏州）有限公司总经理杜娇（右）与国舜股份董事长兼总裁姜强为太湖网络安全培训基地揭牌

  

**分类别、分层次、分阶段开展培训工作**

![](../Images/3bf6d5a0397c1db271c3df2e97c5763c.png)  
太湖网络安全培训基地针对企业安全业务需求分别开设了多个培训项目:（1）为企业安全业务量身定制安全培训课程，提升安全运营人才专业技能。（2）与学校、机构合作，定制网络安全人才培训体系，为网络安全行业输送人才。  

**承担社会责任，延伸企业价值链**

![](../Images/3bf6d5a0397c1db271c3df2e97c5763c.png)  
太湖网络安全培训基地为相关非政府组织和政府组织机构进行网络安全知识培训等一系列公益活动，宣传网络安全知识，普及信息安全意识。  

![](../Images/c70de1f6435fc1b976e214b46198dec2.png)

  
**课程研发**由国舜网络安全研究院、毕加索攻防实验室结合多年攻防实战经验，研发教学课程，根据企业岗位定制。  
**实战平台**由国舜网络安全研究院、毕加索攻防实验室研发的实战项目，对于学习成果进行考核，并可参与真实的企业渗透、安服、风险评估等项目。  
**仿真靶场  
**仿真企业网络安全环境，基于真实的案例搭建仿真环境，以实际操作感受攻防对抗，学习与工作融合，以助于快速进入企业安全岗位角色。  
**师资团队  
**教学团队由业内资深白帽子、网络安全专家授课，以实战项目驱动教学，使学员在学习中不断提升安全技能。  

作为一家新型网络安全公司，苏州国舜将通过充分发挥自身产品研发和安全服务的特长，为客户搭建从专业网络安全人才培养到企业网络安全应急响应全生态服务，为区域网络安全发展贡献力量。
