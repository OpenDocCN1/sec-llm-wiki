# 国舜股份出席可信联盟2021会员代表大会暨理事会并作金融专委会工作汇报

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3NjU5MTIxMg==&mid=2650567480&idx=1&sn=e1b700c5a4ab57db6049991780bf16d1&chksm=87562a3bb021a32d4617afe33cfa783fbdbb8320f597838dc3d05feb58aa3fde7215c20035ee&scene=126&sessionid=1681370807#rd](http://mp.weixin.qq.com/s?__biz=MzA3NjU5MTIxMg==&mid=2650567480&idx=1&sn=e1b700c5a4ab57db6049991780bf16d1&chksm=87562a3bb021a32d4617afe33cfa783fbdbb8320f597838dc3d05feb58aa3fde7215c20035ee&scene=126&sessionid=1681370807#rd)

近日，中关村可信计算产业联盟（以下简称：联盟）在北京召开2021年第一次会员代表大会暨理事会会议，程春平理事长主持会议，国舜股份作为联盟理事单位出席此次会议。

  

![](../Images/c31a2f342060c59d3e26ecab00957408.png)

  

会议听取了王振宇秘书长等人报告的联盟《2021年上半年工作报告》《2020年财务决算及2021年财务预算》《2021年上半年党建工作汇报》；会议投票选举增补理事单位与副理事长单位；会员代表大会投票表决通过《中关村可信计算产业联盟2021年第一次会员代表大会暨理事会会议决议》。

  

本次会议听取了联盟各专委会工作汇报。作为金融安全可信专委会主任单位，国舜股份介绍了金融专委会的成立背景与成员阵容，汇报了在联盟的管理监督与业务指导下所开展的灵活多样的网络安全工作及下半年工作规划，继续为促进我国网络安全与金融科技健康可持续发展发挥桥梁和纽带作用。

  

程春平理事长在总结讲话中肯定了联盟在本阶段取得的工作成绩，并希望联盟加强与会员之间的联系，更好地了解会员的发展情况与诉求，提供战略合作的机会，将交流平台变为协作平台，在技术上形成共识，最终达到共享。
