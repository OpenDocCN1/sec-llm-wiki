# 天津市河东区区委副书记、区长周波一行莅临国舜股份调研交流

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3NjU5MTIxMg==&mid=2650567398&idx=1&sn=5aa9bd527856c9779d079cd28e293517&chksm=87562be5b021a2f327bfa2864c63ccf08d5e83ea885d991b35942942eed50caa047a2960faeb&scene=126&sessionid=1681370812#rd](http://mp.weixin.qq.com/s?__biz=MzA3NjU5MTIxMg==&mid=2650567398&idx=1&sn=5aa9bd527856c9779d079cd28e293517&chksm=87562be5b021a2f327bfa2864c63ccf08d5e83ea885d991b35942942eed50caa047a2960faeb&scene=126&sessionid=1681370812#rd)

![](../Images/ca921cfa7aab087d6f9c3176c9635f30.png)

  
近日，天津市河东区区委副书记、区长周波，天津市河东区政府办主任丁晓峰、天津市河东区发改委副主任胡晓廷一行走进国舜股份北京总部调研交流，国舜股份董事长兼总裁姜强热情迎接并全程陪同。

  

![](../Images/ebd3f834e1b979169ecb8bb0d524dc08.png)

  

姜强董事长向来宾们介绍了国舜股份的发展情况。作为一家新型网络安全企业，国舜股份为政企、金融、通信、能源、航空、医疗等行业客户提供专业化信息安全产品及整体解决方案，助力用户在开发安全、大数据交易反欺诈、态势感知、Web应用安全等方面的痛点突破。

  

![](../Images/739cbbb8590b1582f963c8b3fa939069.png)

  

周波区长介绍了河东区的发展情况，天津河东区历史悠久、商业发达、交通便利、区位优势明显，是天津城区商品经济的发祥地，漕运文化、民俗文化等历史底蕴深厚。在京津冀协同发展的大战略背景下，河东区正迎来全新的发展机遇，国舜股份作为网络安全典型企业与河东区产业定位高度一致，欢迎国舜股份未来在天津加大投资，继续赋能产业转型升级。

  

姜强董事长表示国舜股份此前在天津已设立了一家子公司，表示将会认真考虑加大在天津的合作力度和投资力度。双方均表达了在城市安全运营指挥中心领域加强合作的意愿。

  

![](../Images/cf49a9c4acee6fbaa73f5728612ccdf2.png)

  

国舜股份多年来一直坚持自主创新，着力推动全线安全产品与服务的高性能化，多维度助力客户网络安全综合防护能力的整体提升。未来，国舜将持续创新研发，以相关行业的成功经验和技术赋能更多领域用户，助力构建安全可控的安全网络环境，持续为客户网络安全保驾护航。
