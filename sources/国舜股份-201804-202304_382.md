# 感谢信 | 国舜股份开发安全及反欺诈支持能力获某大型股份制银行认可

**喜报频传！新春将至，国舜股份不断收获客户认可：**某大型股份制银行发来感谢信，对2020年国舜股份在开发安全及反欺诈方面给予的网络安全支持表示认可，对国舜安全技术服务团队成员端正的工作态度、突出的工作能力、敬业的职业素养表示赞赏，并希望双方今后继续加强合作，共同奋斗取得更长足的进步。

  
![](../Images/10e6288e1df84217a5108da003b42a8b.png)  
作为国家高新技术企业，国舜股份始终坚持自主创新，通过将AI、大数据、UEBA等技术融入安全攻防技术，以丰富的产品体系及安全服务资质助力用户在开发安全自动化管理、实时交易反欺诈、网络安全态势感知、Web应用安全等方面的痛点突破，从安全云化、安全数据化、安全服务化、全生命周期开发等多维度精深化客户安全防护。  
![](../Images/bd94382b7864b0810ec2de2dc2382e62.png)  
国舜股份的安全技术和解决方案已累计在上千家客户机构成功落地，拥有众多典型应用案例并多次荣获行业大奖，赢得客户们的广泛认可和好评。  
![](../Images/3073743f0f2598cb2fda7d03000bc948.png)  
**客户的肯定是国舜股份前行的巨大动力。**未来，国舜股份继续坚持业务驱动、数据驱动、价值驱动，运用在安全领域十余年的行业研究与探索积淀，以扎实的技术积累、成熟的产品体系、高效的服务跟进，全力为客户的网络安全保驾护航！
