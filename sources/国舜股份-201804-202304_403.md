# 国舜股份签约贵州某农商行，助力网络风险排查与综合安全加固

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3NjU5MTIxMg==&mid=2650565577&idx=1&sn=963935651af4da65bba9af247ee33fec&chksm=875632cab021bbdc052efadb81f916b4a2926da3b141f034b7b117763a7cdf0fd325c071dfa6&scene=126&sessionid=1681370832#rd](http://mp.weixin.qq.com/s?__biz=MzA3NjU5MTIxMg==&mid=2650565577&idx=1&sn=963935651af4da65bba9af247ee33fec&chksm=875632cab021bbdc052efadb81f916b4a2926da3b141f034b7b117763a7cdf0fd325c071dfa6&scene=126&sessionid=1681370832#rd)

![](../Images/ca921cfa7aab087d6f9c3176c9635f30.png)

  

近日，国舜股份与贵州某农商行达成签约合作，将以系统上线风险评估、安全咨询与培训等多种方式为客户核心业务系统风险检测和安全加固提供综合技术服务支持，助力客户防范风险隐患，满足合规要求和不断成长的业务发展需求，确保客户整体业务的平稳、健康、持续运行。

  

***Security***

**携手合作共铸安全**

  
![](../Images/7d00c919844d315bca7ff3486446b715.png)  

此次双方开展紧密合作，国舜股份安全技术团队将依据国家及行业相关安全标准和技术规则，通过网络架构分析、源代码审计、恶意代码排查等形式，以及对相关业务系统进行风险评估和有计划的渗透测试，验证核心系统防渗透、防泄漏、防入侵能力，及时识别潜在安全问题并出具专业的分析报告，为实施风险处置和安全加固提供专业参考。针对发现的网络安全问题提出建议和安全加固方案，协助行方进行安全整改，进一步完善客户的网络安全防护。

  

国舜股份安全技术团队将以专业的技术能力、优质的服务水平、高效的工作效率全面助推客户网络安全防护的巩固与升级！  

  

***Security***

**国舜护航金融网安**

  
国舜股份长期坚持纵深、动态、主动的网络安全理念，以成熟的安全技术，高效的安全服务队伍，丰富的安全咨询、安全系统集成及安全服务经验，为客户提供定制化、多元化的综合安全解决方案，助力客户网络安全水平提升。  
  
国舜股份以安全服务能力为基础，结合国内外信息安全行业标准及丰富实践，建立起【天服】安全服务体系，从安全咨询、安全技术、安全运维、安全培训等层面切入，通过渗透测试、漏洞扫描、等保咨询、安全咨询、开发安全咨询、风险评估、安全评估、安全代维、合规咨询、代码审计等综合性安全服务，助力客户识别资产本身存在的脆弱性和面临的安全威胁，设置风险处置计划，降低风险损失；实现紧急事件发生后快速恢复系统的保密性、完整性和可用性，降低安全威胁事件的严重影响；保障客户业务系统满足业务安全和信息安全的需求，保障业务的稳健持续发展。  
![](../Images/0d7927d7ba0ded19edf8f764286241dd.png)国舜股份的安全技术和解决方案已在上百家银行、证券、保险等金融机构成功落地，拥有众多典型应用案例并多次荣获行业大奖，赢得客户们的广泛认可和好评。  
  
未来，国舜股份将继续坚持“以客户为中心，以奋斗者为本”的核心价值观，为客户提供优秀的产品、服务与解决方案，护航安全、合作共赢，为构建安全可信的网络空间而不懈奋斗！
