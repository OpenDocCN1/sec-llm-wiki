# 飞速发展的网络技术提供良性互联网环境的同时也是黑产层出的依托

**前言**随着互联网的飞速发展，网络安全事件层出不穷，越来越多的黑灰产业人员瞄准了对于安全疏漏的企业或是个人，以盈利/非盈利进行恶意攻击、操控，轻则钱财受损，重则重要数据被窃取用于他处，损毁个人/集体利益。他们利用非法无线上网设备，在公共无线上网环境中伪装免费WiFi，待链接成功后窃取个人信息，为诈骗人员非法搭建“钓鱼”平台、制作钓鱼“APP”以及提供该平台的运维技术服务、技术支持等。2  
**2020事件摘要****出行平台**

在如今共享出行常态化的方式下，随着资本逐利下的起起伏伏近段时间又涌出了几家出行服务平台，平台为了增加拉新及留存率推出多种营销活动，这些平台的营销活动利己的同时也催生了黑产业的攻击，根据统计出行平台第三方打车平台头部企业逐渐成为黑产攻击的目标。

整体行业成“吸黑”体质，用户端更是已黑红化，在操作流程中存在不同的风险。

| **业务场景** || **业务风险** || **作弊方式** |
| :-: | :-: | :-: |
| 注册登录 || 扫号、撞库、垃圾注册、虚假注册 || 自动化软件/人工 |
| 营销 || 虚假裂变、真人作弊 || 自动化软件/人工 |
| 下单 || 认证绕过、实名伪造、代下单 || 人工 |
| 支付&绑卡 || 预支付绕过、冒名代绑、黑卡支付 || 人工 |

  
  
  
  
  
  
同时，黑产人员会利用平台特点及其薄弱点去使用黑产资源、工具来进行黑灰产操作行为，一般有：  

```


1、IP资源（主要为代理IP及秒拨IP）

2、号码资源（常走接码平台/线下对接获取资源）

3、设备资源（常用有模拟器、云手机、群控设备）

4、工具资源（常用多开、改机工具、虚拟定位等绕过设备维度的风险识别）

5、其他资源（社交软件、发卡平台、众包平台真人作弊来达到绕过风控目的）


```

**黑话&术语**

```


线报平台：为羊毛党提供最新薅羊毛、赚钱活动的信息平台；

接码平台：接收手机验证码平台；

发卡平台：提供虚拟软件、卡密、数据等资源的自动交易平台；

打码平台：自动化识别验证码平台；

众包平台：链接上游发布任务及下游真人作弊的平台；

新型众包平台：提供接口给开发者/羊毛党使用的真人作弊平台，涉及到第三方账号的授权；

料子：公民个人相关信息，涉及姓名、身份证、银行卡、手机号等数据；

毛c：国际信用卡，可用于账号绑定及交易；

卡商：提供手机号资源的供应商。


```

**封装及第四方支付平台**

由于目前安全厂商识别一些钓鱼网站越来越快，致使他们开始借助第三方技术服务提供商（第三方封装、分发平台等）对自身进行包装躲避安全识别，贷款诈骗就是一种，他们用不法途径获取被骗人员信息进而联系，话术引导使用贷款平台进而获取利益。

针对于移动端支付更是运用第四方非法平台进行资金流转行为。黑灰产平台用传统方式收款时，使用第三方二维码，但是会有很大的限制，无法进行大量的个人账户汇款，极易被管控，所以借助第四方平台，利用搭建的跑分平台（类似于兼职平台中介），用户在此平台上缴纳押金，将个人收款二维码租借平台，这样来收取转账资金并给用户返回佣金（例如博彩业）

跑分平台用途、操作

针对此黑产情况下，平台审核流程需加强规范及校验力度，加强技术防御、售卖渠道的打击拦截等来阻断此种情况的继续恶化。

**传统黑卡、短信拦截卡**

新型短信拦截手机黑卡，通过设备硬件后门或软件APP植入木马，拦截设备收到的内容，利用其进行恶意注册。因手机的给卡上游渠道急需补充的渠道问题及人机识别、真人对抗的攻防演练结果致使黑产开始打起短信拦截手机黑卡的注意，相较于国内，国外则是主要攻击目标，海外特征以及价值增值快都是被列为主要原因。

在传统黑卡具有持有SIM卡特征可直接标记为恶意，但是在短信拦截卡中无法立即判断是否为持卡人本人操作，需多出操作流程进行判定，判定方式有：

机型的绝对差异、设备指纹的异常特征、结合IP、行为特征多维度判断、拦截卡的识别等。3  
**结语**黑灰产工具日益更新迭代变化，一些企业忙于前行却忘了去考量、**完善**背后潜在的**安全隐患问题**，假使企业的风控设施改造、升级未与部署的步调一致，那么企业安全将会隔出一阶段的**暴露期**，黑灰产可明目张胆的在平台上攻击、篡改等，因此可知，在针对此种形态下**未雨绸缪**才是应对风险的最有效并且最佳方法，应及时对于内部系统及开发的软件进行**定期检测扫描**，聘用专业人员或企业进行测试，出规范的阻断措施建议，避免出现巨大的经济非经济损失情况。![](../Images/90d1d3367e779c5fcd259410ed11e832.png "纯图片动态粽子小图标引导阅读原文")**请关注我们的公众号****！**
