# 被誉为互联网最可怕的搜索引擎Shodan

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4NjEyMjk0OA==&mid=2247485039&idx=2&sn=688cee240fddb018653e7917cfbe9c1d&chksm=cf9f36c4f8e8bfd2bd103cd4ed959172f0104aebeb90fac47eacd37c83b82089595d7035cdfa&scene=126&sessionid=1681668235#rd](http://mp.weixin.qq.com/s?__biz=Mzg4NjEyMjk0OA==&mid=2247485039&idx=2&sn=688cee240fddb018653e7917cfbe9c1d&chksm=cf9f36c4f8e8bfd2bd103cd4ed959172f0104aebeb90fac47eacd37c83b82089595d7035cdfa&scene=126&sessionid=1681668235#rd)

对于常逛百度、Google等传统浏览器的人来说，当听“shodan”时会极其陌生，小编也是在了解网络安全资讯时看到的相关文章才浅略了解一些，shodan是被称作为“超级可怕的搜索引擎”。

Shodan并不是大众所熟知的一般类型的搜索引擎，在shodan搜索出来的内容并不单纯的信息，最可怕的是shodan不是在网上搜索网址，它是直接进入互联网的背后通道，它可以找的到任何东西-从可以远程控制的打印机到可公开访问的摄像头，以及在没有任何保护措施的情况下链接到网络的许多其他设备。据调查每个月shodan都会在大约5亿个服务器上日夜不停的搜集信息。

搜索引擎初始界面如文章开头上方所示。  

在相关一些文章中有些试验员进行了部分实验操作，小编也按部就班的进行粗略的实验下。  

首先，在初始搜索引擎中输入JAWS,代表为“CCTV”的网络摄像头关键词，界面视图如下：

![](../Images/83c3ebd82d5a4b1484e324e98444fc18.png)

下一步，随机选择红框对应的IP地址，选择端口点击红色区域即可进入访问界面，如下：

![](../Images/5a33a71ac4ec0f88d728af6f244f73cc.png)

在IP界面中，点击红框里的红色图标，进入到该摄像头的登录界面，对于大多数情况来说使用的设备是默认密码，黑客也可直接密码爆破你后台的密码，从而登录摄像头查看信息。

登录界面如下图：

![](../Images/3370566a215622d2406c08684529801e.png)

进入之后的图像大多数为下图所示（小编并未进入摄像内界面，此处为文章内截图）

![](../Images/f52cd2ea6f9e548a868e6dd037e8c8ed.png)

如果你想要筛选国内的结果，你需要的就是在搜索时加入关键词“country:'CN'

”（这为shodan的搜索语法）。也可为更加精准的地理坐标，家附近等等，shodan支持很多更精准的搜索情况，可自行百度操作。

Shodan搜集信息是及其惊人的，只要是链接到互联网的红绿灯、安全摄像头、家庭自动化设备等等都会被轻而易举的搜索到。Shodan几乎能找到所有和互联网关联的东西，而这些设备几乎都没有安装安全防御措施，就可随意进入。

据了解到，shodan除用作搜索摄像头外，曾有研究者搜得到本国的核电站控制系统；并且还有人通过shodan控制别人家智能音响的……。

由此可见，虽然shodan一直被用于正规查询，但是并不能筛除有人将其用于违规、违法事物操作，当我们把设备接入互联网就如同在互联网上敞开了一扇大门，给网络其他成员以可乘之机。无论是有恶意的还是无恶意的，把自己的设备暴露在互联网上都不是明智的选择，如果确实有这个需要，建议用户一定要设置密码。如果没有必要，请勿将你的任何设备接入互联网。
