# Netwalker无文件勒索软件分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4NjEyMjk0OA==&mid=2247484638&idx=1&sn=9011eda3e7c20bd3c9f3ac98773b3de6&chksm=cf9f3475f8e8bd63429f366211e62a620f402eb45c281939b2e2b1f1dfcf7c154e1480e25b86&scene=126&sessionid=1681668249#rd](http://mp.weixin.qq.com/s?__biz=Mzg4NjEyMjk0OA==&mid=2247484638&idx=1&sn=9011eda3e7c20bd3c9f3ac98773b3de6&chksm=cf9f3475f8e8bd63429f366211e62a620f402eb45c281939b2e2b1f1dfcf7c154e1480e25b86&scene=126&sessionid=1681668249#rd)

**攻击者正不断研究更复杂的方式逃避恶意软件检测，近期发现攻击者利用PowerShell编写Netwalker勒索软件，直接在内存中执行，没有将实际的勒索软件二进制文件存储到磁盘中。恶意软件利用了反射动态链接库（DLL）注入的技术，也成reflective **DLL加载，可以从内存注入**DLL，不需要实际**DLL文件，也不需要任何Windows加载程序即可注入。********

1  
PowerShell分析

powershell脚本行为如下图：

![](../Images/36d00fec8996f0172e72cb1c6197bb3b.png)

该脚本使用了多层加密，混淆和编码技术，最顶层为base64编码：  

![](../Images/fd1ba0c289b4438d28f07202e49d04a9.png)

base64解码将显示下一层代码，该层是十六进制编码XOR加密：

![](../Images/171fac4f6f5f49a6b046450cdf062bfb.png)

解码和解密后会显示主要脚本，该脚本仍有混淆，分析人员难以读懂内容：

![](../Images/7eb7d5ebe5db198e3d4afbc93267afeb.png)

该文件以反射方式将勒索软件DLL注入到合法进程explorer.exe中， 勒索软件以十六进制格式嵌入在脚本中。

![](../Images/a0e1d7f8c918476eb21d496df204d8af.png)

脚本将其解码产生两个DLL，一个是勒索软件的x86版本（用于32位OS），另一个是x64版本（用于64位OS）。它会对运行环境进行检测，以便可以确定要使用的DLL版本：

![](../Images/a5eb94bb8acac63df586d72be8be2825.png)

它首先从kernell32.dll中找到所需功能的API地址：

![](../Images/ce43b80b08fbef6d70e170498ff5b17d.png)

然后计算内存地址：

![](../Images/001d87e00278d44252a9768099f06a2f.png)

![](../Images/00181834071f2e86f598fbf2c6b39d78.png)

脚本本身充当DLL加载程序，可以自行计算并解析定位其所需的内存地址。然后指定要注入的进程，搜索正在运行的Windows资源管理器进程。

![](../Images/d9784e7f9f9c842509ab6771607b00ca.png)

通过以下代码将勒索软件DLL写入explorer.exe的内存空间并执行：

![](../Images/f353f4e6bd61a451cccab96f04c83029.png)

最后删除副本，防止受害者使用副本恢复文件。  

![](../Images/66472b72b1a65e88810ce978a33612f4.png)2  
无文件勒索软件分析

Netwalker使用6个随机字符作为扩展名重命名加密文件：

![](../Images/9bdb380b61e2aaefbd1bd73df71f063a.png)

它将勒索信息放在系统各个文件夹中，并在对受害者数据文档加密后打开，其内容为：  

![](../Images/52e899435444e24c6b1226c98ac16ab8.png)

添加以下注册表项：

```


HKEY\_CURRENT\_USER\\SOFTWARE\\{8 random characters}

{8 random characters} = {Hex **values**}


```

![](../Images/6a7f2037da4286c7ef3a6eefe2559a54.png)

勒索软件会终止某些进程和服务，其中一些与软件数据备份有关。以下是勒索软件终止的一些服务示例：

```


**\*backup\***

**      \*sql\***

**
      AcronisAgent**

**
      ARSM**

**
      server Administrator**

**
      ShadowProtectSvc**

**
      wbengine**

**      \*sql\***

**      excel****.exe**

**      ntrtscan****.exe**

**      powerpnt****.exe**

**
      wbengine\***

**      winword****.exe**

**      wrsa****.exe**



```

勒索软件还会停止与安全软件相关的进程，逃避安全软件对其恶意活动的检测防御。  

Netwalker加密文件时主要针对常见用户文件，例如Office文档，PDF，图像，视频，音频和文本文件等。它通常会避免对关键文件，可执行文件，动态链接库，注册表或其他与系统相关的文件进行加密，防止系统完全失效。

3  
总结与建议攻击者现在正在向勒索软件中添加反射DLL注入，从而使攻击难以被安全分析人员分析追踪。勒索软件本身对组织就具有很大的危害，成为无文件攻击后，其风险再次加大。组织必须使用各种安全技术来保护其端点，例如采用行为监控和基于行为检测的安全方案等。以下是避免被勒索软件攻击的一些建议：

```


1、定期备份关键数据，减轻勒索软件攻击的影响；

2、安装来自操作系统和第三方供应商的最新软件补丁；

3、遵守良好的邮件和网站安全规范；

4、及时发现警告可疑的电子邮件和文件；

5、在端点上实施应用程序白名单,阻止所有未知和不需要的应用程序；

6、定期组织员工进行安全培训。


```
