# 黑产砧板上的鱼

之前有写过一篇关于个人信息安全的推文，附加了一些安全措施及计算机加固方法等，信息量不多，只是想能尽量使个人对于安全意识及其防护有些许提升，对于网络安全专业人士可跳过阅读。  

**网络安全现今态势**

在今年网络安全宣传周（每年9月第三周）前夕，总书记对国家网络安全宣传周作出重要指示强调，举办网络安全宣传周、提升全民网络安全意识和技能，是国家网络安全工作的重要内容。  
![](../Images/4d800c45f0c4169a614734868b230a56.png)

国家越来越重视网络安全教育、宣传、人才培养，积极推出相关法律法规，保障体系日益完善，以维护网络安全环境；

在国家及领导的高度重视下以及近年来网络安全事件频发，涉及企业及个人，所以现今许多中大型企业都已经组建了自己的安全团队或是聘请专业的安全服务团队进行内部整体、及时的安全检测、监控及维护；相应的针对于企业安全监控产品也相继而出，领导者可一目了然知其资产安全状态及相应出现的漏洞及优化措施。  

**个人对于安全认知**

在整体大环境积极发展的前提下按常规来说个人应该是会有所提升，但是实际情况是：除却一些就职于网络安全的互联网企业、国家一些安全机构类和学习网络安全专业的相关人员了解些基础情况外，社会一般人员依然处于茫然+自我安全麻痹状态。由于近几年网络诈骗、信息盗用等案例屡出，大部分已知其信息被泄露情况，但却自我认为无利用价值则将个人信息毫无防范地暴露于平台或其他地方；也就导致了黑客轻松获取信息以此牟利，并将信息内容进行n次出售直至榨干利用价值被公开挂于网络。

多数人可能认为电脑或是一些移动端设备已经安装了杀毒软件，则认为基本无安全隐患，也就削减了网络安全意识，但其实对于一些大众所熟知的杀毒软件其重点在于保护用户端的电脑安全，但对于存储在运营商服务器上的数据安全鞭长莫及。  

我们在提升企业信息安全的同时也呼吁社会人员多多关注传播信息安全知识及其基础防御技术，虽不至于完全可以防御黑客的攻击，但却可尽多地减少个人/家人财产及人身侵害。

**应对方法小结**

iTerm 2是全球最热门的终端模拟器之一，是开发人员经常使用的 MacOS 终端工具，是Mac内置终端app最有力的热门开源工具替代品之一，被很多开发人员称为“Mac终端利器”。1、勿轻信、勿贪利：小心防范街头各种市场调查及产品推销，勿为小礼品留存自己及家人的信息；  
2、其他电脑不留底：外出打印复印时，完成后及时完全清理信息文件，切勿留存于垃圾桶防止被复制、废弃资料进行碎纸处理；  
3、减少个人信息暴露：对于必填个人信息的项目尽量少填写信息，复印件资料表明用途防止被印刷利用；  
4、勿泄露信息：对于个人某些涉及财产及相关内容时，勿对相关人员以外的人泄露内容及敏感信息；5、及时清理非必要应用信息：对于不常用或不用的网站及手机端的应用及时清理信息，减少被曝光内容及风险；6、详细阅读隐私保护：对于进行网上交易或涉及隐私邮件等时，要仔细阅读“隐私保护协议政策”防止信息泄露第三方；

7、谨防“网络钓鱼”：一些含欺诈类的钓鱼邮件，以各种理由要求其收件人登录特定网站并提交个人信息甚至银行卡账户信息。
