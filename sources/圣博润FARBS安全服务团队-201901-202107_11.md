# 记一次Redhat系统MySQL数据库重新安装流程

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5MjgwNTc3Mg==&mid=2247484104&idx=1&sn=8f117f854820de4b65a99b91d33a3d62&chksm=fe1b682bc96ce13d8e1f3710996a73b13fb909a76ee9c267c59da4fbe596890b93f8ac3d48bd&scene=126&sessionid=1681575500#rd](http://mp.weixin.qq.com/s?__biz=MzU5MjgwNTc3Mg==&mid=2247484104&idx=1&sn=8f117f854820de4b65a99b91d33a3d62&chksm=fe1b682bc96ce13d8e1f3710996a73b13fb909a76ee9c267c59da4fbe596890b93f8ac3d48bd&scene=126&sessionid=1681575500#rd)

在针对MySQL漏洞进行修复时，考虑到漏洞数量较多的情况下，挨个打补丁耗时耗力，如果情况允许，我们可以选择重新安装最新版MySQL。接下来简单分享下MySQL数据库在 RedHat linux环境下的安装流程。

**测试环境如下：**

操作系统：RedHat 6.4

原版本：MySQL5.7.25

计划升级版本：MySQL5.7.28

**下面为大家演示Red Hat系统下MySQL重新安装流程：**

**1、   ****查看测试环境MySQL版本信息**

**方法一：**直接在命令行连接MySQL ，使用**mysql -u root -p**连接数据库后，会显示MySQL版本信息。如下图所示：  

![](../Images/8527b30360407ff827d2bdb72708746e.png)

**方法二****：**在命令行连接输入mysql-V, 会显示MySQL版本信息。

![](../Images/2381177a7fe7ef2b1e9fae9a7fae566c.png)

**方法三：**成功连接MySQL后，输入命令status，也会显示MySQL版本信息。如下图所示：  

![](../Images/715eadcf612c471304416cac6b39937a.png)

**方法四：**命令行输入\\s 也能达到上一步同样的效果。

![](../Images/ae4fd7970beb3220e6404a2352deb245.png)

**方法五：**使用sql查询语句：select version() ;，也可以显示MySQL版本信息。

![](../Images/45da2d78bb625fa0aebf696acf4c6477.png)

**方法六：**使用第三方工具（如Navicatfor MySQL）连接MySQL也会显示版本信息。

![](../Images/4848cf3fe42b593c94854d7a7268d16e.png)

注：默认情况下MySQL都是localhost访问权限，如需远程访问，需要开通权限。参考链接：https://jingyan.baidu.com/article/335530dae6c83919ca41c357.html

**2、下载所需的MySQL安装包**

在MySQL官方网站选择合适的版本下载安装，根据官方记录，目前MySQL 5.X最新版本为5.7.28。

下载链接：https://dev.mysql.com/downloads/mysql/

![](../Images/0514c2d5e62dad9bca1dcf1ef7948273.png)

**3、对数据库中重要数据文件进行备份**

为避免操作中发生紧急情况，对数据造成影响，升级前一定要对数据库进行备份，或者使用快照、创建系统镜像等方式，这里我列举两种常见的备份方式。

**方法一:**使用mysqldump备份所有的数据库

代码格式：mysqldump-h主机名 -P端口 -u用户名 -p密码 --all-databases > 文件名.sql

参考链接：https://baijiahao.baidu.com/s?id=1612955427840289665&wfr=spider&for=pc

例如：mysqldump-h192.168.215.132 -P3306 -uroot -p123456 --all-databases >/home/beifen20200327.sql  

![](../Images/ef2c586f839eb1d4cad56b2983ca0768.png)

**方法二:**使用第三方工具（如Navicat for MySQL）备份数据。

参考链接：https://www.cnblogs.com/nengka/p/myisam\_backup.html

**4、完全卸载旧版MySQL数据库。**

关闭MySQL服务：service mysqld stop

查看MySQL服务状态:service mysqld status

检查服务器是否已安装MySQL：rpm -qa|grep mysql  

![](../Images/2d5879be8b7a42ac9a00b9606bb7cdca.png)

按照上图所示，测试服务器中安装了MySQL 5.7.25版本，需要完全卸载。值得注意的是，MySQL各安装包存在依赖关系，可能因依赖关系无法卸载，如下图所示：  

![](../Images/44863501a7e4eb4942868bed501ee373.png)

此时可以使用命令:rpm -e –nodeps进行卸载。  

![](../Images/3c21230a51453fe14cd77130e9ff801b.png)

紧接着我们需要删除残留的mysql目录：

使用命令：**find / -name mysql**查找，将找出来的目录用  rm -rf 命令全部删掉

![](../Images/a736283217032a154277704be1733e81.png)

删除MySQL的主配置文件my.cnf  **rm -rf/etc/my.cnf**

做完上述步骤，最好使用命令**rpm -qa|grep mysql**和**find / -name mysql**确保删除干净。

**5、安装最新版MySQL**

卸载完成后，将下载的安装包导入服务器，并解压。(网络允许的情况下可以使用wget下载)

相关命令：tar  -xf mysql-5.7.28-1.el6.x86\_64.rpm-bundle.tar

![](../Images/ec97b672e97dab5c4485c4029f6431fb.png)

**安装方法一：安装过程中因依赖关系，需要安装以下顺序安装：**

rpm -ivhmysql-community-common-5.7.28-1.el6.x86\_64.rpm

rpm -ivhmysql-community-libs-5.7.28-1.el6.x86\_64.rpm

rpm -ivhmysql-community-devel-5.7.28-1.el6.x86\_64.rpm

rpm -ivhmysql-community-client-5.7.28-1.el6.x86\_64.rpm

rpm -ivhmysql-community-embedded-5.7.28-1.el6.x86\_64.rpm

rpm -ivhmysql-community-embedded-devel-5.7.28-1.el6.x86\_64.rpm

rpm -ivhmysql-community-server-5.7.28-1.el6.x86\_64.rpm  

![](../Images/80d507c810cc494bf3c7fb3003468ab9.png)

**安装方法二：**由**yum****为你解决依赖关系**

相关命令：yum -y install mysql-community-\*  

![](../Images/a8cf7bb468a681b15e1320e503f5bfe5.png)

安装过程中报错，需要添加--skip-broken解决。  

相关命令：yum -y install mysql-community-\* --skip-broken，安装过程部分截图如下：  

![](../Images/7ba8f42a21d7251eb5d47dccd02568fb.png)

![](../Images/043f12d62694fa310ad70287cdeab4ef.png)

**6、启动新版MySQL服务**

启动MySQL服务：**service mysql start或service mysql restart**

启动过程报错，无法启动：

![](../Images/2c4be5e5f155579c553281d9e3c8fcd2.png)

解决步骤：

1.重新初始化数据库

依次使用命令 **rm -fr /var/lib/mysql**和**mysqld --initialize --user=mysql**

2.查看配置文件内容指定的pid-file：cat /etc/my.cnf  
  显示为pid-file=/var/run/mysqld/mysqld.pid  

![](../Images/72ff0ef72171ee3e272e194b76d21c52.png)

3.查看/var/run/mysqld/是否存在。

\[root@localhostlib\]# ll /var/run/mysqld/#不存在

如没有，则创建，并修改属主属组。

mkdir -p /var/run/mysqld/

chown -R mysql:mysql /var/run/mysqld

![](../Images/9a51da217bdfc2e9aa9c01240ee1a2ca.png)

4.重启MySQL服务：servicemysqld restart。如果还报错，则关闭selinux.并重启服务。相关命令：**setenforce 0 **和** service mysqld restart**永久关闭selinux.方法：修改/etc/selinux/config配置文件，改SELINUX=enforcing为SELINUX=disabled，重启后即可生效。  

![](../Images/7ee1aaccb3a935137d969665b9261ba0.png)

参考链接：https://blog.51cto.com/a40406/2478800

**7、对新版MySQL进行相关配置**

修改MySQL配置文件：vim /etc/my.cnf，在文件末尾加上：skip-grant-tables（登陆成功后记得将其注释），这样做开启安全模式登录，方便我们第一次登录设置密码。

![](../Images/bb3c07acab8a6d3dfc0aa12e943d4e26.png)

保存后重启MySQL服务：service mysqld restart

登录MySQL数据库：mysql -u root -p，初次登录密码为空，直接回车即可登录。  

![](../Images/d947ba305df8f1230d8d619d06de07e2.png)

设置登录密码，以root为例:

mysql> **update user setauthentication\_string=password('123456') where user='root';**

mysql> **flush privileges;  
**

![](../Images/9a45731a9b250264209a20eb4815dcf3.png)

**查看版本信息，显示为5.7.28，说明MySQL已经更新成功。只需要将备份的文件导入就可以正常使用了。**

![](../Images/774094579ad7ee0fe7ecf9968144c861.png)
