   1     Windows SMB 协议简介

Windows SMB（Server Message Block）通信协议是微软（Microsoft）和英特尔(Intel)在1987年制定的协议，主要是作为Microsoft网络的通讯协议，可实现Windows系统下文件、打印机共享功能。

   2     漏洞描述

   3     影响范围

漏洞影响如下:

Windows 10 Version 1903 for32-bit Systems

Windows 10 Version 1903 forARM64-based Systems

Windows 10 Version 1903 forx64-based Systems

Windows 10 Version 1909 for32-bit Systems

Windows 10 Version 1909 forARM64-based Systems

Windows 10 Version 1909 forx64-based Systems

Windows Server, version 1903(Server Core installation)

Windows Server, version 1909(Server Core installation)

以及其他开启了SMBv3版本的Windows系统

   4     漏洞细节

微软官方发布安全通告称Microsoft Server Message Block 3.1.1（SMBv3）协议在处理某些请求的方式中存在远程代码执行漏洞。攻击者可利用此漏洞在目标SMB服务器或SMB客户端上执行代码。

针对SMB服务器，攻击者可以将特制的数据包发送到SMBv3服务器来触发漏洞。若要针对SMB客户端，攻击者需要配置好一个恶意的SMBv3服务器，并诱使用户连接该服务器。

该漏洞被利用后可能形成蠕虫漏洞，建议广大用户予以重视。

   5     修复方案

首先需要确定操作系统版本，在cmd命令下输入winver，查看Windows具体版本。

输入systeminfo，查看系统属于32位还是64位。

然后即可下载、安装对应的Windows补丁进行修复，下载链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2020-0796
