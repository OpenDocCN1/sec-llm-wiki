# “入”教前的技术探测

最近疫情比较紧张，周末也不让出去，在家闲着就想了解下国外网站架构和安全防护情况，于是目标就定位到了一个宗教网站，防护是真的好，经过我的不懈努力，终于拿下来数据库和主站了。所以要把这次经历写出来，记录自己的成长。  

最开始拿到这些站真的是没法入手。没办法，我开始搞站的话一般都是先看 JS 文件，因为 JS 文件中容易出现一些莫名其妙的接口，会给我们一些突破口。  

![](../Images/c32620733243a8b866b8a6bbb3628b3b.png)  

发现编程语言是 LUA 的，我也不懂这个语言啊，接着扫文件试试。

![](../Images/3faa326da2fa3326c98adc18eec03d65.png)  

扫出来了一些目录我也不知道为啥，这个 dirsearch 竟然不封 IP 我用御剑就会被封，太神奇了。接下来就一个一个访问呗。当我访问到 index.shtml 的时候就发现了很多功能。  

  
![](../Images/8bcc92c91c5bb7dc9c8e4b15d9edabba.png)

这我可太开心了发现了好多功能，估计是最开始安装的时候忘了删除的页面吧。接着一个一个测试。除了第三个和第六第七个剩下全都被删除了，开心的是能访问的两个全都是登录。

![](../Images/8f69edc5fa0e56c3e83a488dcfe6c5a5.png)

![](../Images/7c2850d73b8ac9de3655da03d26d1b0a.png)  

第一个也全都测试了，啥东西都没有，只能看第二个了，最开始的时候也没发现什么东西，但是不知道莫名奇妙点了什么竟然进入安装页面，这个东西是个日历，我本以为是个很好拿的东西，但是等我进去之后才发现这个东西是真的恶心。进入安装页面之后直接能登录，账号为 Administrator 密码为空开开心心登录上去。  

![](../Images/3a939d88e8d6ae31b4cfdaf2b4e2a50c.png)

上网查了一下，官网都没了。没什么线索，但是发现这个东西是 PERL 写的，而且不存在文件上传啥的，只有一个点，这个点是添加一个新日历。

![](../Images/3ff234fd80fe90ac6ba0e7bf443bc94b.png)

![](../Images/39bd57b29551100b1c86e986613ca8d7.png)

他会让添加一些东西，我发现这个东西会直接再服务器上创建一个文件夹，并且会直接添加进数据库。  

![](../Images/e8d83b6b266c02baac1ecf0696f195d4.png)  

所以我猜测如果我能直接写进去一个文件那么就可以直接拿到 shell。但是没办法，防护还是有的。

![](../Images/c683830007f965337fd14d2535a0ee9c.png)  

而且把我创建的 123.php 当成文件夹了，但是并不允许出现这种情况，就会报错，而且根本绕不过，于是又放弃了。我这个时候突然回头测了一下这个日历登录框，竟然有其他的发现。  

![](../Images/c29a250c5fcd44ed6e711e2f3cbc0633.png)  

发现这个参数是读取一个模板，那么可不可以读取其他的东西呢？所以我就试了一下，没想到，终于找到突破口了，任意文件读取，但是用户权限不够，很多服务器上的权限文件读取不到。  

![](../Images/6ace5975ee85d80c8b08c74e44e986cd.png)  

由于没有之前那个添加日历的时候爆出来了一个路径，经测试发现是绝对路径，但是由于并没有什么东西，所以就先测了一下主页，但是也并没有发现什么东西，扫描的时候扫出来了一个 xxx.htm 读了一下发现竟然包含了一个 php 文件，我才知道这个网站竟然是 PHP 的，真是隐藏的太深了。  
![](../Images/0084ba865ef384d3113d6993d848c227.png)  
   继续读这个 PHP 文件，竟然直接发现了数据库，真的是一步到位。  
![](../Images/59a52f9f6949cb834cb7615f9686adb0.png)  

到此拿到了数据库权限，但是这个网站是站库分离。和网站服务器一点关系没有啊。  
这时候我突然想起来这个网站可以 FTP 登录的，我就试了一下，发现竟然数据库账号密码就是 FTP 账号密码，直接上传，拿到 shell。  

但是由于过了一天网站被发现入侵了，但是并没发现是怎么入侵的，但是 shell 连不上了，而且也上传不了，但是数据库的位置并没有变，但是这回不知道为什么好像是流量被监控了，一句话不能连，只能上了一个大马。至此告一段落...
