# 墨云科技上榜2021 Chrome VRP漏洞奖励Top20

关注**墨云安全**  

![](../Images/712082745461bfc0af6c0cf915e93a4a.png)近日，谷歌官方公布了2021 Chrome（VRP）Top20名单，对全球前20位安全研究员为Chrome和Chrome操作系统的安全性提升作出杰出贡献名单。榜单显示，本年度Top20榜单中至少有11名国内个人或企业安全研究员上榜，形成了中国安全研究员霸榜之势，墨云科技安全研究员也在榜单之内。![](../Images/0231683c0c24896a7885bb1b7b2d4f4f.png)Chrome漏洞奖励计划于2010年1月启动，旨在帮助奖励安全研究人员的贡献，鼓励他们投入时间和精力来帮助提高Chrome和Chrome操作系统的安全性。本次上榜团队为墨云科技旗下Vlab实验室。VLab实验室是墨云科技旗下专注于信息安全领域的渗透测试、红蓝对抗、攻击模拟、漏洞挖掘等方向前沿技术研究的实验室。截至2021年12月，墨云VLab实验室今年已累计向Google、Apple、Oracle、VMware、Apache等国际顶级厂商报告了30多个漏洞，获得十余次公开致谢。墨云科技作为国内领先的网络攻防科技安全服务提供商，一直秉持着让网络攻防更智能的使命，不断创造突破性技术，专注人工智能在攻防安全领域的应用研究，打造智能化产品体系，为客户提供全方位的信息安全服务。目前，墨云科技已在北京、南京、上海、广州、深圳、成都、青岛、济南、西安等多地设有研发中心及分支机构，服务行业客户上百余家。参考来源：公众号 安全419
