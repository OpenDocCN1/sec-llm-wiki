**漏洞说明**

  
近日，Positive Technologies 的专家 Mikhail Klyuchnikov 发现了 BIG-IP 应用交付控制器（ADC）的配置接口中的一个漏洞，该漏洞在网络上已有 EXP 披露。F5 官方也紧急发布公告修复了一个存在于流量管理用户界面（TMUI）的远程代码执行漏洞（CVE-2020-5902）。该漏洞可导致未经身份验证的攻击者通过 BIG-IP 管理端口或自身 IP 访问 TMUI，可构造恶意请求以获取目标服务器权限，CVSS 评分为 10 分，并且目前已有利用该漏洞的攻击行为出现。

![](../Images/b1744b3bb23cd1c033a45e454f05efa9.png)

![](../Images/07b910105e6698441e5098900ab43c3e.png)

**经研判，墨云尖峰安全实验室确认该漏洞严重，建议用户立即进行补丁更新处理。**

![](../Images/e51f56ef8649c71bee8854f7e7ef7f55.png)

**漏洞影响范围**

  
F5 BIG-IP 15.x：15.1.0、15.0.0  
F5 BIG-IP 14.x：14.1.0 - 14.1.2F5 BIG-IP 13.x：13.1.0 - 13.1.3F5 BIG-IP 12.x：12.1.0 - 12.1.5

F5 BIG-IP 11.x：11.6.1 - 11.6.5

墨云科技通过千寻引擎发现全球互联网上有 8,000 多个易受攻击的设备可供使用，其中 40％位于美国，16％位于中国大陆，3％位于中国台湾，2.5％位于加拿大和印度尼西亚。在俄罗斯，不到 1％的易受攻击设备被检测到。

![](../Images/e51f56ef8649c71bee8854f7e7ef7f55.png)

**修复建议**

  

*   **通用修补建议**

升级到以下版本：  
BIG-IP 15.x: 15.1.0.4BIG-IP 14.x: 14.1.2.6BIG-IP 13.x: 13.1.3.4BIG-IP 12.x: 12.1.5.2

BIG-IP 11.x: 11.6.5.2

*   **临时修补建议**

官方建议可以通过以下步骤临时缓解影响：1）使用以下命令登录对应系统：      tmsh2）编辑 httpd 组件的配置文件：      edit /sys httpd all-properties3）文件内容如下：


4) 按照如下操作保存文：    件按下 ESC 并依次输入:wq5) 执行命令刷新配置文件     save /sys config6) 重启 httpd 服务     restart sys service httpd

     并禁止外部 IP 对 TMUI 页面的访问
