客户提交的目标类型为外部公用型网站。经过墨云SaaS-Vackbot平台的渗透检测，仅用两个小的时间，产出该目标有高危漏洞3个、中危漏洞21个、低危漏洞2个。其中，高位漏洞包括后台弱口令漏洞和SQL注入漏洞；中危漏洞包括OpenSSH用户枚举漏洞、后台地址泄露漏洞、HTTP账号密码明文传输和敏感信息泄漏漏洞；低危漏洞包括响应头未设置X-Frame-Options。每种类型漏洞的具体危害和解决方法如下：//

**高危漏洞**

//

*   后台弱口令漏洞

危害：会导致攻击者直接访问网站后台，进一步入侵网站，从而引发信息泄露。  
解决方法：1. 增加口令复杂度  2. 只允许指定ip登陆

*   SQL注入漏洞

危害：攻击者可以通过构建特殊的输入作为参数传入Web应用程序，从而控制整个web应用系统对数据做修改或者窃取，引发信息泄露。  
解决方法：  
1\. 对用户的输入进行校验，可以通过正则表达式，或限制长度来实现；或者通过对单引号和双引号进行转换。  
2\. 应当尽量避免使用动态拼装sql，可以使用参数化的sql或者直接使用存储过程进行数据查询存取。  
3\. 不要使用管理员权限的数据库连接，为每个应用使用单独的权限有限的数据库连接。  
4\. 不要把机密信息直接存放，加密或者hash掉密码和敏感的信息。  
5\. 应用的异常信息应该给出尽可能少的提示，最好使用自定义的错误信息对原始错误信息进行包装。  
//

**中危漏洞**

//

*   OpenSSH用户枚举漏洞
    

危害：通过该漏洞，攻击者可以判断某个用户名是否存在于目标主机中，从而造成信息泄露。  
解决方法：升级OpenSSH版本大于7.7版本。

*   后台地址泄露漏洞
    

危害：泄露后台登录入口，攻击者可通过弱密码、表单绕过、暴力破解等方法获得网站登录权限，导致信息泄露。  
解决方法:  
1\. 加强访问此类文件的认证和使用安全;  
2\. 如果不需要此类文件，请删除;  
3\. 修改为不可预测的文件名。

*   HTTP账号密码明文传输
    

危害：在登陆时对数据没有进行加密，导致在传输过程中以明文的形式在http协议中，若被恶意用户劫持流量，可导致用户密码泄漏。  
解决方法：采用加密算法在传输过程中进行加密(例如：md5、DES等) 。

*   敏感信息泄漏漏洞
    

危害：泄露的敏感信息会让攻击者更全面了解网站的架构，使得攻击者更容易入侵网站。  
解决方法：  
1\. 建议删除探针等无用的程序，或者为其创建难以破解的名字。  
2\. 禁用泄露敏感信息的页面或应用。//

**低危漏洞**

//

*   响应头未设置X-Frame-Options
    

危害：由于应用未设置响应头X-Frame-Options，容易受到点击劫持攻击。  
解决方法：  
1\. 通过javascript代码来禁止iframe的嵌套，即frame busting方法；  
2\. 通过设置响应头X-Frame-Options来限制iframe的加载，DENY：拒绝浏览器加载任何frame页面；SAMEORIGIN：frame页面地址只能是同源域名下的页面；ALLOWFROM：可自定义允许frame加载页面地址；  
3\. 有的浏览器厂商也可以通过增加扩展功能来防御clickjacking，如firefox的“content security policy”和“No-script”。
