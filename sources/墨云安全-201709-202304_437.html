Spring Cloud Security是Spring Cloud内置的一个安全框架。Spring Cloud Security提供了一组开发原语，用于构建安全应用程序和服务，其操作简单便捷，可以在外部（或集中）进行大量配置的声明性模型，帮助大型协作的远程组件系统实现相关功能任务。Spring Cloud Security具有中央身份管理服务的功能。

Spring Cloud Security包含了Spring Security 和Spring Security Oauth两个框架。Spring Security实现了一组过滤器链。Spring Security Oauth实现了对认证中心的搭建。通过两者的组合，可快速实现常见的系统功能，如单点登录、令牌中继、令牌交换和管理授权等。

”

配置Spring Security

Gradle配置如下：

compile group: 'org.springframework.boot', name: 'spring-boot-starter-security', version: '2.1.5.RELEASE'


Maven配置如下：

<dependency>    <groupId>org.springframework.boot</groupId>    <artifactId>spring-boot-starter-security</artifactId>    <version>2.1.5.RELEASE</version>  </dependency>


在服务的配置文件（yml或properties）中配置如下信息：

security:  basic:        enabled: true


完成上述配置后，启动服务，如登录成功，控制台会显示如下信息：密码进行加密，则表示Spring Security配置成功。



配置Spring Security Oauth中的认证模块

Gradle配置如下：

compile group: 'org.springframework.security.oauth', name: 'spring-security-oauth2', version: '2.3.4.RELEASE'


Maven配置如下：

<dependency>    <groupId>org.springframework.security.oauth</groupId>    <artifactId>spring-security-oauth2</artifactId>    <version>2.3.4.RELEASE</version></dependency>

Spring Security启动CSRF保护

Spring Security具有出色的CSRF支持，如果您正在使用Spring MVC的<form>标签或Thymeleaf @EnableWebSecurity，默认情况下处于启用状态，CSRF令牌将自动添加为隐藏输入字段。如果你使用的是像Angular或React这样的JavaScript框架，则需要配置CookieCsrfTokenRepository以便JavaScript可以读取cookie。
