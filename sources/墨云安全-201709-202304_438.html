Spring Cloud简介

Spring Cloud是一套基于Spring Boot 框架实现的微服务解决方案，准确的说它是一个大的容器，将市面上较好的微服务框架集成进来，为微服务架构中涉及的配置管理、服务治理、断路器、智能路由、微代理、控制总线、全局锁、决策竞选、分布式会话和集群状态管理等操作提供了一种简单的开发方式，从而简化开发者的代码量，提高开发效率。

Spring Cloud主要项目

 项目名称

功能描述

Spring Cloud Config

配置管理工具包，让你可以把配置放到远程服务器，集中化管理集群配置，目前支持本地存储、Git以及SVN云端存储。

Spring Cloud  Eureka

云端服务发现，一个基于 REST 的服务，用于定位服务，以实现云端中间层服务发现和故障转移。

Spring Cloud  Zuul

Zuul 是在云平台上提供动态路由,监控,弹性,安全等边缘服务的框架。Zuul 相当于是设备和 Netflix 流应用的 Web 网站后端所有请求的前门。

Spring Cloud Stream

数据流操作开发包，封装了与 Redis、Rabbit、Kafka等发送接收消息。

Spring Cloud Ribbon

提供云端负载均衡，有多种负载均衡策略可供选择，可配合服务发现和断路器使用。

关于Spring Cloud更多项目，请参考官网：https://spring.io/projects/spring-cloud


Spring Cloud应用场景

目前Spring Cloud 主要应用与电商平台、微信小程序及APP后台管理等场景，相信随着访问量的增加会有越来越多的产品或平台转向SpringCloud技术栈。
