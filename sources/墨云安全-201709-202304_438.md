**Spring Cloud简介**

Spring Cloud是一套基于Spring Boot 框架实现的微服务解决方案，准确的说它是一个大的容器，将市面上较好的微服务框架集成进来，为微服务架构中涉及的配置管理、服务治理、断路器、智能路由、微代理、控制总线、全局锁、决策竞选、分布式会话和集群状态管理等操作提供了一种简单的开发方式，从而简化开发者的代码量，提高开发效率。

”

**Spring Cloud主要项目**

|  项目名称 || 功能描述 |
| --- | --- |
| Spring Cloud Config  
 || 配置管理工具包，让你可以把配置放到远程服务器，集中化管理集群配置，目前支持本地存储、Git以及SVN云端存储。 |
| Spring Cloud  Eureka  
 || 云端服务发现，一个基于 REST 的服务，用于定位服务，以实现云端中间层服务发现和故障转移。 |
| Spring Cloud  Zuul  
 || Zuul 是在云平台上提供动态路由,监控,弹性,安全等边缘服务的框架。Zuul 相当于是设备和 Netflix 流应用的 Web 网站后端所有请求的前门。 |
| Spring Cloud Stream  
 || 数据流操作开发包，封装了与 Redis、Rabbit、Kafka等发送接收消息。 |
| Spring Cloud Ribbon  
 || 提供云端负载均衡，有多种负载均衡策略可供选择，可配合服务发现和断路器使用。 |

关于Spring Cloud更多项目，请参考官网：https://spring.io/projects/spring-cloud

  

**Spring Cloud应用场景**

目前Spring Cloud 主要应用与电商平台、微信小程序及APP后台管理等场景，相信随着访问量的增加会有越来越多的产品或平台转向SpringCloud技术栈。

  

**Spring Cloud安全开发**

** 1、数据交互**

由于Spring Cloud是前后端分离框架，在数据交互时，需通过token进行认证（登录时，生成统一的token凭证及过期时间），每次前端请求数据时，都应把token放在header中，服务端解析token，来确定用户身份及用户权限。

**2、Spring Cloud XSS脚本过滤**

XSS跨站脚本攻击的基本原理是利用系统执行了未经过滤的危险代码，XSS是一种基于网页脚本的注入方式，也就是将脚本攻击载荷写入网页执行以达到对网页客户端访问用户攻击的目的。

修复建议：

 增加系统XSS攻击过滤功能，防止XSS攻击，如下：

![](../Images/56612679cf6b3cc8cf791fe870f7b892.png)

![](../Images/6e018c0445b1a8d2b35ea301f3d60300.png)

如果需要处理富文本数据，可通过XssHttpServletRequestWrapper.getOrgRequest(request)，拿到原始的request对象后，再进行富文本数据处理。

  

**3、SpringCloud SQL注入脚本过滤**

SpringCloud持久层框架一般使用Mybatis框架，若特殊情况下需要使用${}拼接SQL，则存在SQL注入风险，可以对参数进行过滤，避免SQL注入。
