# 墨云科技与数字资产交易平台FCoin达成合作

近日，墨云科技与全球首家自治型数字资产交易平台FCoin达成战略合作。

目前，以区块链技术为基础的数字资产蓬勃发展，但安全问题也层出不穷。对于数字资产交易来说，安全是重中之重，定期的外部安全审计工作和项目上线前的安全审计是保障平台交易数据隐私安全性的必要条件。

墨云科技已为多家区块链领域的交易平台进行了安全审计工作。在业内，从技术能力到服务水平都得到了专业的认可。墨云科技致力于为各行业用户在云计算、大数据、移动互联网、物联网、人工智能、区块链等领域，打造新一代网络安全验证服务保障体系，帮助您在风险控制及安全合规方面提供全新的技术手段！相信此次与FCoin的合作，墨云科技会成为FCoin信赖的安全伙伴。
