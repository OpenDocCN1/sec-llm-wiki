域名&解析

  

做一个网站首先需要注册一个域名，用域名来代替冗长的ip地址，起到方便记忆的作用。常见的有：.com、.net、.org。为什么没说.cn，因为.cn属于国别域名，不是通用顶级域。![](../Images/726334474cbfdfe2328a33548e7a552c.png)

通用顶级域在1985年1月创立，有6个后缀，主要是给美国使用。

.com- 供商业机构使用

.edu- 供教育机构使用

.gov- 供政府及其属下机构使用

.mil- 供军事机构使用

.net- 供网络服务供应商使用

.org- 供不属于其他通用顶级域类别的组织使用

注：上述6个后缀解释摘自百度百科—通用顶级域。

![](../Images/acae8c3939986a0af6183257a30179f0.png)

  

我们常见的都是xxx.com这种，实际上后面隐藏了一个“.”，隐藏的“.”代表着根域。所以“com.”是顶级域又称作一级域名，而我们注册一个域名，如：shikangsi.com，则是二级域名，该域全形式：“shikangsi.com.”，我们通常称“shikangsi.com”为主域，“data.shikangsi.com”为子域。

一级域名也是可以建站访问的！![](../Images/6441f1fd6ee3d0da652d7b1a7095fbcb.png)

比如：http://ai./

![](../Images/9c066cf7c7eddb0f648a99393e464ebb.png)

![](../Images/de1bdab9d77f162917a3978d4099d674.png)

查看解析  

![](../Images/4a6247552fc758c7a40b002108805615.png)

其实等于解析记录中的主机记录是“@”

![](../Images/dfce40a91dabc469d4e81963c40450c8.png)

这就是一级域名建站案例，实际上http://com.也可以建站，但没有。![](../Images/b6804a3fb9294464b3b165e6cfe26a30.png)

  

那么域名有了，我们需要将域名指向服务器ip，只有指向了IP，才能访问到指定服务。那么需要引入DNS，DNS-**D**omain **N**ame **S**ystem-域名系统，该系统作用就是将域名解析为ip。通常流程如下：用户在浏览器地址栏输入地址—>首先进行DNS解析（先查hosts文件，没有映射关系，下一步一般会发起递归解析）—>获得返回信息（也就是对应的服务器IP）—>浏览器取回网页数据，将网页渲染到用户面前。

  

买到域名后我们要进行解析，将域名解析到服务器，一般的域名注册商都提供了DNS解析服务，如：阿里云DNS、DNSPOD、22CN、XINNET等。还有第三方DNS提供商，如：CloudFlare、HE.NET等

在解析的时候会有类型，以下以DNSPOD做示范

![](../Images/568462cc336a7e9c3bc8df9bd22df890.png)

上图来源于：DNSPOD  

我们常用的就是A、CNAME、MX记录。

一般我们都是直接解析A记录，那么DNS记录都需要主机记录  

![](../Images/a2e1bd75ff9c1723c2fdcac7812a6d4b.png)

如上图，主机记录可以理解为xxx.shikangsi.cn中的xxx。

不一样的地方在于记录值，不同的解析类型的记录值是不一样的。  

A记录只允许填写IP地址，CNAME记录只允许填写域名，TXT记录只能填写文本。

| **记录类型** || **使用目的** |
| --- | --- |
| A 记录 || 将域名指向一个 IP 地址（外网地址）。 |
| CNAME 记录 || 将域名指向另一个域名，再由另一个域名提供 IP 地址（外网地址）。 |
| MX 记录 || 设置邮箱，让邮箱能收到邮件。 |
| NS 记录 || 将子域名交给其他 DNS 服务商解析。 |
| AAAA 记录 || 将域名指向一个 IPv6 地址。 |
| SRV 记录 || 用来标识某台服务器使用了某个服务，常见于微软系统的目录管理。 |
| TXT 记录 || 对域名进行标识和说明，绝大多数的 TXT 记录是用来做 SPF 记录（反垃圾邮件）。 |
| 隐、显性 URL 记录 || 将一个域名指向另外一个已经存在的站点。 |

为了保护我们的服务器，隐藏真实IP，我们通常会使用CNAME记录，防止某些黑客直接攻击服务器。

![](../Images/18cedbd3ed17cee199adfe5f319fc5f9.png)

域名解析是公开的，任何人都可以查看一个域名的解析记录，在windows上，我们在命令提示符下使用nslookup命令即可。

MX记录值与优先级

接上文，下面我们详细说一下解析流程。

①用户输入域名

②计算机开始查hosts文件，如果hosts文件没有映射记录，那么查本地DNS缓存，如果还没有进行下一步

③DNS服务器没有记录就会继续查询，一般会有递归查询和迭代查询

④查询到记录就返回记录，没有就会报错，一般浏览器提示“ERR\_NAME\_NOT\_RESOLVED” 

![](../Images/87a624f41a71e58cff8f8093ff74d2b1.png)![](../Images/e1b7236fe48f420f31ff553364d56d76.png)

  

网站备案

  
  

网站备案通常指：ICP备案。

备案只需要备案主域名，如：shikangsi.com备案后，data.shikangsi.com是不需要再次备案的。  

未备案时解析域名到境内主机，使用HTTP/HTTPS访问会被拦截。![](../Images/30b84732f2f4429102b6b140037b20f5.png)境外不影响。![](../Images/5be8147faeadc20e3df3100e1d2ce471.png)

相关法律：①《互联网信息服务管理办法》、②《非经营性互联网信息服务备案管理办法》，施行日期：2005年3月20日。

①参考链接：

http://www.gov.cn/zhengce/2020-12/26/content\_5574367.htm

②参考链接：

http://www.gov.cn/gongbao/content/2005/content\_93018.htm

在境内开设网站需要进行备案，境外则无需。  

注：使用IP访问也是不需要备案的。（专线IP需要找ISP备案，一般ICP不提供IP备案服务）某些网站就是用的IP跳转。

![](../Images/46836d242822542d7a75730328d2c0d9.png)

自2018年01月01日起，从事互联网信息服务使用的域名应为其依法依规注册所有，个人性质备案域名注册者应为本人，单位性质备案域名注册者应为单位（含公司股东）、单位主要负责人或高级管理人员。

参考法律：

①《工业和信息化部关于规范互联网信息服务使用域名的通知》②《互联网域名管理办法》

参考链接：

①https://www.miit.gov.cn/jgsj/xgj/gzdt/art/2020/art\_bd227219b16d4cb3901960e1cca504f5.html

②http://www.cac.gov.cn/2017-09/28/c\_1121737753.htm

  

我们只关注个人备案，这个意思是，个人备案只能自己名字备案自己域名，比如我现在要备案，那么需要备案的域名必须为我自己的实名认证。A备案，那么A将要备案的域名必须是A实名认证的。![](../Images/349e6eea6800f12a8a9e2380d0d0140b.png)

  

当然不是什么域名后缀都可以备案的，只有批准的域名后缀才可以，比如.org就没有备案资格，具体可备案域名后缀列表可访问：http://域名.信息/ 进行查看（这个地址就是中文的，没有错。）。同时域名需在境内服务商注册，境外注册的域名无法备案。

![](../Images/53fe06354d3cb51a5773d7393506286d.png)

具体备案要求各地通管局和各服务商要求不同，以实际为准。  

备案通过后会获得备案号：【省份简称】ICP备【数字】号-【序号】  

如：鄂ICP备15020128号-4就是shikangsi.com的备案号。

备案信息可通过ICP/IP地址/域名信息备案管理系统查询

地址：https://beian.miit.gov.cn

![](../Images/fc89af5df885c35593897ed89aa0d860.png)

查询条件：ICP备案查询：请输入单位名称或域名或备案号查询，请勿使用子域名或者带http://www等字符的网址查询

  

注意：已经获得备案号的经营性网站必须在主页上标明其经营许可证编号或者备案编号，非经营性质的网站则必须在主页添加备案号，且备案编号应链接至工业和信息化部备案管理系统网址。
