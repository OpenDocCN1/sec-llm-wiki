今天无聊，玩玩思科吧，正好我也学过。
环境：Windows XP
软件：Cisco PacketTracer 6.2（就是PT）
目标：小目标，给设备配一个IP地址。
基础


首先我们要知道什么是路由器什么是交换机，路由是什么？
路由（routing）是指分组从源到目的地时，决定端到端路径的网络范围的进程。——百度百科
说简单点，就像我们用的导航，导航告诉我们从家到一个景点该怎么走，网络中数据包也需要导航，负责这个的就是路由，路由一般是路由器提供的功能，它会告诉我们的数据包应该去哪里，怎么过去。
下面我们认识一下PT这个软件。

这是软件启动后的左下角

第一行从左到右依次是路由器、交换机、集线器、无线设备、线缆。
第二行从左到右依次是终端、安全设备、仿真云、定制设备、多用户连接
今天我们只需要使用路由器、PC和线缆。
首先点击路由器。

拖动就可以拉上去

然后再拉一个PC上去。

这样就OK了

然后我们选择一个线缆给他们连起来。

点击第四个，然后点PC，选择网口，再点路由器，给它们连起来。

就是这个样子

然后我们点击路由器

看到这个界面，点击开关，打开路由器

点击CLI选项卡，等#结束后就是启动完毕

是否以对话模式进行配置，选否。

输入no然后回车

如上图，按回车开始。
学习第一个操作，输入一个问号(?)（一定要是英文输入法）

如图，会显示当前模式下的指令。

下面我们输入：enable然后回车
意思是进入特权模式。

Router后面的箭头变成了#，这就是进入了特权模式。

然后打个问号

看到方框处，configure进入配置模式

我们输入configure加空格加问号

如图，我们加上terminal

就是configure terminal然后回车

进入了配置模式。
那么我们来给网口配置ip。
interface GigabitEthernet 0/0——进入端口G0/0配置模式
语法：interface+空格+网口+序号

可以看到显示了Router(config-if)

下面我们使用ip address配置ip地址。
语法：ip address ip-address subnet-mask（子网掩码）

没有报错，配置上了。

由于接口默认都是down的状态，我们要执行：no shutdown来启用接口。

可以看到，显示changed state to up

然后我们点击PC。

点击Desktop

点击IP Configuration

配置IP地址和掩码，然后关闭。

点命令行

输入ipconfig检查配置，正确。

执行ping 192.168.12.254可以看到，已经通了。

那么这就是给路由器配置IP地址，很简单对吧。
我们回顾一下：
1、打开CLI2、输入enable3、输入configure terminal4、输入interface GigabitEthernet 0/05、输入ip address 192.168.12.254 255.255.255.06、输入no shutdown
就这么简单。其实具有唯一性的命令都可以简写，刚学就学完整点。
