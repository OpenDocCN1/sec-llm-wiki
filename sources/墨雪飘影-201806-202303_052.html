在我们平常上网中接触比较多的就是IP地址了，其应用场景通常为：在web中进行IP过滤（指定某些ip可以访问某些资源）。
那么IPv4与IPv6都是什么？

简述

IP==>网际协议（英语：Internet Protocol，缩写：IP），又称互联网协议，是用于分组交换数据网络的协议。
IP地址==>IP地址（英语：IP Address，全称Internet Protocol Address），又译为网际协议地址、互联网协议地址。是网际协议中用于标识发送或接收数据报的设备的一串数字。
网际协议版本4（英语：Internet Protocol version 4，缩写：IPv4，又称互联网通信协议第四版）是网际协议开发过程中的第四个修订版本，也是此协议第一个被广泛部署和使用的版本。其后继版本为IPv6，直到2011年，IANA IPv4位址完全用尽时，IPv6仍处在部署的初期。
网际协议第6版（英语：Internet Protocol version 6，缩写：IPv6）是网际协议的最新版本，用作互联网的协议。用它来取代IPv4主要是为了解决IPv4地址枯竭问题，同时它也在其他方面对于IPv4有许多改进。
IP是特指协议，IP地址是IP协议中用于标识设备的一串数字，就像我们的家庭住址，来了一封信，邮差根据地址送到我们手中，那么这个地址必须是独一无二的，否则就无法准确投递。实际上IP地址也是这样的。
数量

目前我们正在使用的IPv4，正在建设的是IPv6，因为IPv4地址已经耗尽（尽管使用了NAT技术），在未来万物互联时将会没有IP地址可用，而IPv6号称可以给地球上每一粒沙子分配一个地址，解决了地址不够用的问题。

IPv4使用32位（4字节）地址，因此地址空间中只有4,294,967,296（232）个地址。不过，一些地址是为特殊用途所保留的，如专用网络（约1800万个地址）和多播地址（约2.7亿个地址），这减少了可在互联网上路由的地址数量。随着地址不断被分配给最终用户，IPv4地址枯竭问题也在随之产生。基于分类网络、无类别域间路由和网络地址转换的地址结构重构显著地减少了地址枯竭的速度。但在2011年2月3日，在最后5个地址块被分配给5个区域互联网注册管理机构之后，IANA的主要地址池已经用尽。
IPv6具有比IPv4大得多的编码地址空间。这是因为IPv6采用128位的地址，而IPv4使用的是32位。因此新增的地址空间支持2128（约3.4×1038）个地址，具体数量为：
340,282,366,920,938,463,463,374,607,431,768,211,456 个，也可以说成1632个，因为每4位地址（128位分为32段，每段4位）可以取24=16个不同的值。
IPv4

IPv4是一种无连接的协议，操作在使用分组交换的链路层（如以太网）上。此协议会尽最大努力交付数据包，意即它不保证任何数据包均能送达目的地，也不保证所有数据包均按照正确的顺序无重复地到达。这些方面是由上层的传输协议（如传输控制协议）处理的。
IPv4地址长度为32位，我们常见的是它的点分十进制表示法，就是A.B.C.D这种形式，实际上在点分格式中，每个字节都可用任意的进制表达。
比如：192.168.1.1==>192.0250.1.1（八进制）

或者：192.168.1.1==>192.0xa8.1.1（十六进制）

除此之外，还支持零省略写法（IPv6里面的地址压缩也可以省略0）
比如：127.0.0.1==>127.1

还有另一种，数字IP
127.0.0.1==>2130706433

以上都是合法ip地址，其中数字IP计算方法为：
A*256^3+B*256^2+C*256^1+D*256^0
IPv4地址分类：

1993年，无类别域间路由（CIDR）正式地取代了分类网络，后者也因此被称为“有类别”的。
由于每个人一个地址是显然不够用的，IPv4地址有限，所以我们平常都是用了NAT技术在上网，我们在家里、学校、公司等地方实际上只有很少的公网IP，这少量的公网IP分配在出口网关，我们的计算机和手机等设备都是分配的内网地址，当我们的数据包到达边界会获得一个公网IP的使用权，A.B.C.D:port（网络地址端口转换NAPT）与我们的设备内网地址一一对应，实现一个IP供多个设备上网。
从20世纪80年代起，一个很明显的问题是IPv4地址在以比设计时的预计更快的速度耗尽。这是创建分类网络、无类别域间路由，和最终决定重新设计基于更长地址的互联网协议（IPv6）的诱因。
IPv6

IPv6的设计目的是取代IPv4，然而长期以来IPv4在互联网流量中仍占据主要地位，IPv6的使用增长缓慢。
IPv6二进位制下为128位长度，以16位为一组，每组以冒号“:”隔开，可以分为8组，每组以4位十六进制方式表示。例如：2001:0db8:86a3:08d3:1319:8a2e:0370:7344 是一个合法的IPv6地址。类似于IPv4的点分十进制，同样也存在点分十六进制的写法，将8组4位十六进制地址的冒号去除后，每位以点号“.”分组，例如：2001:0db8:85a3:08d3:1319:8a2e:0370:7344则记为2.0.0.1.0.d.b.8.8.5.a.3.0.8.d.3.1.3.1.9.8.a.2.e.0.3.7.0.7.3.4.4，其倒序写法用于ip6.arpa子域名记录IPv6地址与域名的映射。

同时IPv6在某些条件下可以省略：

  1. 每项数字前导的0可以省略，省略后前导数字仍是0则继续，例如下组IPv6是等价的。

  • 2001:0db8:02de:0000:0000:0000:0000:0e13

  • 2001:db8:2de:0000:0000:0000:0000:e13

  • 2001:db8:2de:000:000:000:000:e13

  • 2001:db8:2de:00:00:00:00:e13

  • 2001:db8:2de:0:0:0:0:e13

  • 可以用双冒号“::”表示一组0或多组连续的0，但只能出现一次：

  • 2001:0000:0000:0000:0000:25de:0000:cade

  • 2001:0000:0000:0000:25de:0000:0000:cade

  • 2001:0000:0000:25de:0000:0000:0000:cade

  • 2001:0000:25de:0000:0000:0000:0000:cade

  • 2001:db8:2de:0:0:0:0:e13

    • 2001:db8:2de::e13

  • 2001:0db8:0000:0000:0000:0000:1428:57ab

    • 2001:0db8:0000:0000:0000::1428:57ab

    • 2001:0db8:0:0:0:0:1428:57ab

    • 2001:0db8:0::0:1428:57ab

    • 2001:0db8::1428:57ab

    1. 如果四组数字都是零，可以被省略。遵照以上省略规则，下面这两组IPv6都是相等的。

    2. 2001::25de::cade 是非法的，因为双冒号出现了两次。它有可能是下种情形之一，造成无法推断。

    3. 如果这个地址实际上是IPv4的地址，后32位可以用10进制数表示；因此::ffff:192.168.89.9 相等于::ffff:c0a8:5909。

    另外，::ffff:1.2.3.4 格式叫做IPv4映射地址。

    IPv4位址可以很容易的转化为IPv6格式。举例来说，如果IPv4的一个地址为135.75.43.52（十六进制为0x874B2B34），它可以被转化为0000:0000:0000:0000:0000:FFFF:874B:2B34 或者::FFFF:874B:2B34。同时，还可以使用混合符号（IPv4-compatible address），则地址可以为::ffff:135.75.43.52。
