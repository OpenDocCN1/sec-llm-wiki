**0****1****打开SSO**  
腾讯企业邮箱登录经常需要微信扫码验证，很是傻逼。好在有办法解决。还是比较简单的，就是用SSO来处理这个问题。  
首先打开：**https://exmail.qq.com**先登录。登录后选择**工具箱**

![](../Images/7bdb582a84dc45fd7b9b2a05b23681e3.png)

**02****操作流程**  

步骤说明

1.获取登录企业邮的url。如需使用个性域名，将域名替换成相应域名，并使用HTTP协议

首次登录需要进行授权，用户需要输入正确的登录密码来完成授权。

后续可直接一键跳转到企业邮

2.修改密码或者重置CorpSecret都会取消授权关系

*   请求说明：
    

HTTPS请求方式：GET

请求地址：https://api.exmail.qq.com/cgi-bin/service/get\_login\_url?access\_token=ACCESS\_TOKEN&userid=USERID

**03****具体实现**  

①开启单点登录，获取**CorpID**&**单点登录secret**

②获取**access\_token**

③调用单点登录获取登录地址

④访问登录地址

⑤成功登录

```
import webbrowserimport requestsimport json
print("获取密钥")corpid='这里是企业ID'corpsecret='这里是企业密钥'userid='这里是需要登录的邮箱'mailback=requests.get("https://api.exmail.qq.com/cgi-bin/gettoken?corpid="+corpid+"&corpsecret="+corpsecret)mailjson=json.loads(mailback.text)access_token=mailjson["access_token"]mailloginback=requests.get("https://api.exmail.qq.com/cgi-bin/service/get_login_url?access_token="+access_token+"&userid="+userid)mailloginjson=json.loads(mailloginback.text)login_url=mailloginjson["login_url"]print("打开浏览器")webbrowser.open(login_url)
```

如上，保存为xxx.py即可。需要python环境，默认3.x，填写信息后双击打开即可直接访问到邮箱首页
