**03****配置IIS**

PHP最低7.4，我们直接下载个7.4

下载PHP

**04****配置数据库**  

找到MySQL目录

![](../Images/b6ed73fdb68d8d86abbaeda81ddb4dac.png)

新建一个文件my.ini内容如上图，新建一个文件夹data（给users用户组全部权限）

然后进入bin目录按住shift然后右键空白处，打开命令提示符  

![](../Images/8c63ee62ecee389be35eeb167b0b40fc.png)

输入mysqld –initialize-insecure –user=mysql（是mysqld不是mysql）

![](../Images/3c15bff82bd9fd019064a56b29ed13c8.png)

初始化完成  

  

继续输入mysqld -install（注册为系统服务）  

![](../Images/c90b91a4968e54f7c27e99acf6c5fb45.png)

继续输入net start mysql（启动MySQL）

![](../Images/452f785908805c60463ee21ee934fd91.png)

输入mysql -u root -p
