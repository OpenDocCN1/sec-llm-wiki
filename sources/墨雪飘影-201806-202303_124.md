# 利用kali完成telnet密码嗅探与ssh密码破解

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzI4OTkyNw==&mid=2247484872&idx=1&sn=e4c78ae0d727997e889d33c011a8a4c2&chksm=eb69cb60dc1e427643c332f85f52b92c1a28317c35c813bbb1e8b149abaad34563aedf61556c&scene=126&sessionid=1681664938#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzI4OTkyNw==&mid=2247484872&idx=1&sn=e4c78ae0d727997e889d33c011a8a4c2&chksm=eb69cb60dc1e427643c332f85f52b92c1a28317c35c813bbb1e8b149abaad34563aedf61556c&scene=126&sessionid=1681664938#rd)

  

        对于这两种攻击防御起来也不是很难，telnet是基于明文传输的，非必要我们不会开放该服务，目前在网络设备上开放该服务也是进行了权限限制，至于ssh服务，最好采用证书连接，在ssh配置中禁用密码登录和root用户登录。在实际环境中也不会随意对外开放ssh、rdp服务，即使开放也会限制登录尝试次数，同时会在防火墙后，对于此类攻击不必过于担心。本文为模拟实际环境，采用了生成社会工程学字典的方法替换了通用的字典，以提高成功率，实际情况下通用密码字典的破解是基于弱密码的漏洞，利用软件代替手工进行自动化破解，实际上跟自我信息相关的密码在作者看来也是弱密码的一种，我们可以在做好信息收集后进行精准的密码爆破。成功率将会大大增加，与此同时工作量更少，效率更高。  

        本文采用了网上的办法进行测试，以验证是否可行，其中arp欺骗的准备工作可以看[Kali2020修改root用户密码、修改源、配置环境变量](http://mp.weixin.qq.com/s?__biz=MzI3NzI4OTkyNw==&mid=2247484837&idx=1&sn=285e1d18eeaf8d0a6f31b1b53a04764a&chksm=eb69cb0ddc1e421b2c71e56950401c84d15d2e1fe050f50e21343b6628961f7dcb4b2a97ec5d&scene=21#wechat_redirect)这篇文章可以解决bash:aprspoof:command not found的问题，以及sudo apt-get install dsniff提示无法定位软件包的问题，同时解决了在kali2020版本下默认禁用root用户，使用普通用户运行wireshark提示权限不足的问题。

        本文未涉及到IPC$漏洞的复现测试，IPC$漏洞仍可用于校园网，单位内部网络，作者亲测在win10与Windows Server 2003进行rdp无法传输文件，可以采用IPC$漏洞映射磁盘，或者利用rdp的映射磁盘功能，将本地磁盘映射至对端，即可解决无法传输文件的问题。
