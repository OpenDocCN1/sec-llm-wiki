启用root用户

原文地址：https://www.cnblogs.com/ITIT007/p/11380927.html


实操

sudo passwd root

其中第一个是当前用户密码，后面是要设置的root用户密码


优点：不需要重启修改配置，方便快捷


更改源（要用权限修改）

原文地址：


实操

sudo vim /etc/apt/sources.list

然后更新

sudo apt-get update


优点：使用阿里云的源比较稳定


安装软件后无法使用（需要配置环境变量）


原文地址：https://www.freesion.com/article/6434426078/


实操

查看当前环境变量

echo $PATH

使用以下命令修改环境变量

export PATH="/usr/local/sbin:/usr/local/bin:/sbin:/bin:/usr/sbin:/usr/bin:/root/bin"

尝试运行软件

成功


优点：无需重启，无需超级权限，立即可用
