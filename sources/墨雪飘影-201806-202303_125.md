启用root用户

原文地址：https://www.cnblogs.com/ITIT007/p/11380927.html

  

实操

sudo passwd root

![](../Images/308325c53744c53f5a31be22285801d6.png)

其中第一个是当前用户密码，后面是要设置的root用户密码

  

优点：不需要重启修改配置，方便快捷

  

更改源（要用权限修改）

原文地址：

  

实操

sudo vim /etc/apt/sources.list

![](../Images/7c4175d76af1694d5eaabb683ae87e99.png)

然后更新

sudo apt-get update

![](../Images/27612b7e474642d0a4e76c12d9ee2cd1.png)

  

优点：使用阿里云的源比较稳定

  

安装软件后无法使用（需要配置环境变量）

  

原文地址：https://www.freesion.com/article/6434426078/

  

实操

查看当前环境变量

echo $PATH

![](../Images/ea7e92e947151ab444387ed85bb2dec4.png)

使用以下命令修改环境变量

export PATH="/usr/local/sbin:/usr/local/bin:/sbin:/bin:/usr/sbin:/usr/bin:/root/bin"

![](../Images/4e350b6a55c50aa0bcf6cf65d2493ba4.png)

尝试运行软件

![](../Images/be6ca3263b9f544c39b026aa9f00b749.png)

成功

  

优点：无需重启，无需超级权限，立即可用
