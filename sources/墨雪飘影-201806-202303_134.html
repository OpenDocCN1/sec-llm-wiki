本API可获取湖北省大学生毕业高中名称，本文档适用于v1版本。

请合理使用该接口，不得用于违法犯罪等不符合规定的地方！

接口说明：

  • 湖北省毕业高中查询接口

修订历史：

版本号制定人修订日期
    1史康思2019-11-23

URL:

http(s)://api.shikangsi.com/api/v1/HighSchool/Info


请求参数:

参数名是否必须类型说明
  year     是string毕业年份
 stuname     是string姓名
  sfz      是 string 身份证号

请求示例:


http(s)://api.shikangsi.com/api/v1/HighSchool/Info?stuname=【姓名】&sfz=【身份证号】&year=【毕业年份】

返回示例:

正确时返回:

            直接在浏览器中显示json

错误时返回:

{
    "StatusCode": 状态码,
    "Detail": 详情,
    "CopyRights": "版权信息"
}

返回参数说明:

参数名类型说明
StatusCodeint状态码
Detailstring错误详情或结果
CopyRightsstring版权信息
