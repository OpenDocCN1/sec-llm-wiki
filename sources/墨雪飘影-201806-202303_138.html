本API可获取指定人员照片，本文档适用于v1版本，目前可用于调用图片与查询剩余次数。

请合理使用该接口，不得用于违法犯罪等不符合规定的地方！

接口说明：

  • 照片接口

修订历史：

版本号制定人修订日期
    1史康思2019-03-29

URL:

http(s)://api.shikangsi.com/api/v1/GetPic/Pic


请求参数:

参数名是否必须类型说明
  Year     是long年级
 Name     是string姓名
StuNum      是 long 学号
   User
      是 long 用户
SecretKey      是 string 秘钥

请求示例:


http(s)://api.shikangsi.com/api/v1/GetPic/Pic?Year=【年级】&Name=【姓名】&StuNum=【学号】&User=【用户】&SecretKey=【秘钥】

返回示例:

正确时返回:

            直接在浏览器中显示图片

错误时返回:

{
    "StatusCode": 状态码,
    "Detail": 详情,
    "CopyRights": "版权信息"
}

返回参数说明:

参数名类型说明
StatusCodeint状态码，详情请参考备注
Detailstring错误详情，详情请参考备注
CopyRightsstring版权信息


备注:

  • 错误代码说明

  • 000 //非法请求

  • 100 //缺少参数

  • 101 //必要参数错误

  • 102 //次数扣除失败

  • 201 //返回已授权用户信息

  • 401 //秘钥错误

  • 402 //次数不足

  • 403 //用户未授权

  • 404 //未找到

  • 405 //程序故障


接口说明：

  • 查询次数接口

修订历史：

版本号制定人修订日期
    1史康思2019-03-29

URL:

http(s)://api.shikangsi.com/api/v1/QueryTimes/Times

请求参数:

参数名是否必须类型说明
  User     是long年级

请求示例:


http(s)://api.shikangsi.com/api/v1/QueryTimes/Times?User=【用户】

返回示例:


正确时返回:

{
    "StatusCode": 状态码,
    "UserRole": 用户角色，
    "Times": 剩余次数,
    "Detail": 详情,
    "CopyRights": "版权信息"
}

错误时返回:

{
    "StatusCode": 状态码,
    "Detail": 详情,
    "CopyRights": "版权信息"
}

返回参数说明:

参数名类型说明
StatusCodeint状态码，详情请参考备注
Detailstring错误详情，详情请参考备注
CopyRightsstring版权信息
 UserRole
 string

 用户角色，0=测试，1=普通，2=高

级，6=内测

Times
 string 剩余查询次数


备注:

  • 错误代码说明（同上）
