本API可获取指定人员照片，本文档适用于v1版本，目前可用于调用图片与查询剩余次数。

**请合理使用该接口，不得用于违法犯罪等不符合规定的地方！**

## 接口说明：

*   照片接口

## URL:

http(s)://api.shikangsi.com/api/v1/GetPic/Pic

  

## 请求参数:

| 参数名 || 是否必须 || 类型 || 说明 |
| --- | --- | --- | --- |
|   Year ||      是 || long || 年级 |
| --- | --- | --- | --- |
|  Name ||      是 || string || 姓名 |
| StuNum ||       是 ||  long ||  学号 |
|    User  
 ||       是 ||  long ||  用户 |
| SecretKey ||       是 ||  string ||  秘钥 |

## 请求示例:

## 

  

```
http(s)://api.shikangsi.com/api/v1/GetPic/Pic?Year=【年级】&Name=【姓名】&StuNum=【学号】&User=【用户】&SecretKey=【秘钥】
```

## 返回示例:

**正确时返回:**

**            直接在浏览器中显示图片**


## 返回参数说明:

| 参数名 || 类型 || 说明 |
| --- | --- | --- |
| StatusCode || int || 状态码，详情请参考备注 |
| --- | --- | --- |
| Detail || string || 错误详情，详情请参考备注 |
| CopyRights || string || 版权信息 |

  

## 备注:

*   错误代码说明
    

*   000 //非法请求
    
*   100 //缺少参数
    
*   101 //必要参数错误
    
*   102 //次数扣除失败
    
*   201 //返回已授权用户信息
    
*   401 //秘钥错误
    
*   402 //次数不足
    
*   403 //用户未授权
    
*   404 //未找到
    
*   405 //程序故障
