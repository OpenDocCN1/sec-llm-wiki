1.  首先选一个服务提供商，今天我们就用Amazon的云服务吧（免费一年）。免费一年的AWS需要信用卡，并且至少有1美元的余额，验证信用卡会扣1美元，后面会返还的。关于AWS一年的具体方案可以参考（https://aws.amazon.com/free/）。这里不再赘述，需要的准备好卡自行上车。

注意，实例的用户名不是root

o    对于 Amazon Linux 2 或 Amazon Linux AMI，用户名称是 `ec2-user`。

o    对于 Centos AMI，用户名称是 `centos`。

o    对于 Debian AMI，用户名称是 `admin` 或 `root`。

o    对于 Fedora AMI，用户名为 `ec2-user` 或 `fedora`。

o    对于 RHEL AMI，用户名称是 `ec2-user` 或 `root`。

o    对于 SUSE AMI，用户名称是 `ec2-user` 或 `root`。

o    对于 Ubuntu AMI，用户名称是 `ubuntu`。

o    另外，如果 `ec2-user` 和 `root` 无法使用，请与 AMI 供应商核实。

在 **Host Name** 框中，输入 `*user_name*`@`*public_dns_name*`。确保为您的 AMI 指定相应的用户名。

下载一键脚本

wget -c --no-check-certificate https://vpsyou.com/wp-content/uploads/2015/06/l2-2015.tar.gz

默认是一键装了wget的

解压

tar zxvfp l2-2015.tar.gz

然后执行

sudo ./l2.sh 2>&1 | tee install.log

（如果不用sudo提升权限，会无法执行脚本）
