# 武软数据获取—版本更新

经过一周的修改，第二版已经开发完成。

第一版地址：[一键获取武软信息](http://mp.weixin.qq.com/s?__biz=MzI3NzI4OTkyNw==&mid=2247484234&idx=1&sn=014559f008584f09ef12fecf806ea640&chksm=eb69cde2dc1e44f45868cc9be1b5930571b671f556eaf63f39827407c9642a0a12e1ee908189&scene=21#wechat_redirect)

主要功能：可自动抓取数据，目前支持抓取姓名、身份证号、学院、专业。范围仅限武汉软件工程职业学院。**新增：****电子邮箱、电话号码（在有的情况下，邮箱仅抓取QQ邮箱。电话号码，号段多达34个）**

  

**更新内容：**

1、增加电子邮箱、电话获取。

2、在连接互联网的情况下获取IP更加准确。（由腾讯IP地址库更改为工业和信息化部电信研究院IP地址库）

3、更改学院匹配方法，本次更新程序可匹配全部共八个学院。

4、新增所有原版本不可匹配专业，本次程序可匹配全部共五十二个专业，使用最新2018年专业库。

5、优化获取数据存储方式，可自动分离空数据。

**修正内容：**

1、IP地址获取错误。

2、批量获取写入文件中的英文半角冒号更正为中文冒号。

**输入授权码后报错解决方案**

解决方法如下：

按windows+r打开运行窗口输入regedit,回车打开注册器。然后进入如下路径中

HKEY\_LOCAL\_MACHINE\\SYSTEM\\CurrentControlSet\\Control\\Lsa\\FipsAlgorithmPolicy将enable设置为0 即可。
