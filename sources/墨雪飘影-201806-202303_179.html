HQ-Sw

·     配置远程管理访问（包括 IP 编址和 SSH）：

配置远程访问就是配置一个ssh服务

启用版本号为2的ssh服务

-   域为 cisco.com

配置域，域名为cisco.com

-   用户 Admin ，密码为 letmein

配置用户名和密码

-   加密密钥长度为 1024

-   SSH 第 2 版，限制为 2 次身份验证尝试和 60 秒的超时时间

首先是ssh第二版

然后是限制两次身份验证尝试

最后是60秒超时

-   在VTY线路启用ssh认证

使用本地数据库验证

-   应加密明文密码。

·     配置、命名和分配 VLAN。端口应手动配置为接入端口。

首先把VLAN都命名好

然后分配端口

接入模式

配置VLAN60

设为中继TRUNK模式

最后允许VLAN通过

·     实施端口安全：

-   在 Fa0/1 上，当检测到 MAC 地址时，允许 2 个 MAC 地址自动添加到配置文件中。不应禁用端口，但当发生违规时，应捕获 syslog 消息。

启用端口安全

允许2个MAC地址

发生违规不禁用端口，捕获syslog消息

-   禁用其他所有未使用的端口。

关闭f0/21端口

关闭g0/2端口

-   为该交换机配置默认网关

HQ

·     配置 VLAN 间路由。

·     配置 VLAN 30 中的 DHCP 服务。将 LAN 用作区分大小写的池名称。

设置DHCP地址池名称

设置默认网关

设置地址池IP

·     实施路由：

-   使用 OSPF 进程 ID 1 和路由器 ID 1.1.1.1

-   为整个 192.168.45.0/24 地址空间配置一条 network 语句

-   禁用不应发送 OSPF 消息的接口。

-   配置通往互联网的默认路由。

·     实施 NAT：

-   配置一个只含一条语句，编号为 1 的标准 ACL。允许所有属于 192.168.45.0/24 地址空间的 IP 地址。

-   参考您的文档，为文件服务器配置静态 NAT。

-   通过 PAT 使用您选择的池名称和这两个公有地址配置动态 NAT：

    198.133.219.128 and 198.133.219.129
