**第一部分**

**第**** 1 ****步：**  **拒绝**** PC1 ****访问**** Server1 ****和**** Server2 ****的**** HTTP ****与**** HTTPS ****服务。**

a.     创建命名为ACL 的扩展IP 访问列表，该列表将拒绝 **PC1 **访问**Server1 **和 **Server2 **的 HTTP 与 HTTPS 服务。因为无法直接观察互联网上服务器的子网，所以需要建立四条规则。

创建命名为ACL的扩展IP访问列表

创建命名标准ACL命令是

ip access-list standard ACL名称

创建命名扩展ACL命令是

ip access-list extended ACL名称

这里要求的是扩展ACL，所以用第二条命令

![](../Images/4679890ee9e57ec21b206684c513e80d.png)

b.     记录拒绝从**PC1 **访问**Server1 **的语句，只针对 HTTP（端口 80）。

创建访问控制列表记录

这里要求的是扩展记录命令是

![](../Images/6e84f796dcaf66217e1b7b6c164fe665.png)

其中deny表示拒绝，tcp是协议，host是指定单个主机，172是源地址，然后host如上，64是目标地址，eq是等于，80是端口

c.     记录拒绝从**PC1 **访问**Server1 **的语句，只针对 HTTPS（端口 443）。
