# 喜报丨我实验室喜获两项全国信息安全竞赛作品赛一等奖

2022年8月22日，第十五届全国大学生信息安全竞赛作品赛圆满落幕。经过长达四个多月的角逐，来自我们系统软件与安全实验室的两支本科生队伍分别凭借作品《玄鉴：互联网黑产应用威胁情报平台》和《基于具象化用户意图感知的最小化隐私收集合规检测》斩获**全国一等奖**，其中《基于具象化用户意图感知的最小化隐私收集合规检测》作品同时获得大赛**最具创业价值奖**（全国仅有10项），团队指导教师杨珉和杨哲慜老师获得**优秀指导教师奖**。

  

![](../Images/699155543eadd3ae8401a7821d7cb2c8.png)

  

![](../Images/8f3e73e0401394d13a86b9a75fbfabe7.png)

  

  

全国大学生信息安全竞赛是我国级别最高、覆盖范围最广、影响力最大的网络安全赛事，旨在选拔和推荐优秀网络空间安全专业人才，培养学生的创新意识与团队合作精神，提高学生的网络安全技术水平、创新实践与综合设计能力，推动我国高校网络空间安全专业建设与改革。本次大赛为第十五届，由中央网信办网络安全协调局、教育部高教司、共青团中央学校部指导，中国互联网发展基金会、国家网络安全人才与创新基地主办，湖南大学承办，同时邀请中国工程院沈昌祥院士、教育部网络空间安全教指委秘书长封化民等顶尖信息安全专家以及信息安全知名企业代表出席。本届比赛吸引了来自全国共191所高校的2692名师生，参赛作品达到了840份，经过线上初赛和决赛的激烈评选，全国共产生180支队伍分别获一、二、三奖，其中一等奖40项，二等奖61项，三等奖79项。

  

![](../Images/39b8e02e9e73ef47c13086e0e738cc6b.png)

  

自收到大赛邀请，两支团队开始积极准备参赛，以当下有迫切需求和影响力的打击网络黑产及保护用户隐私为切入口，分别构建了具有零天黑产应用发现能力的威胁情报平台，以及面向最小化隐私收集的移动应用隐私合规检测系统。两项团队作品整体从线上初审的作品文档和介绍视频，到决赛的现场展示，队员们与指导老师反复斟酌、不断改进，在无数次的打磨之下最终力压群雄，突出重围。获奖作品《基于具象化用户意图感知的最小化隐私收集合规检测》将亮相国家网络安全周并被邀请参加将在安徽由中国网络安全产业联盟举办的2022年网络安全优秀创新成果大赛。

  

本次获奖是我实验室继2021年获得第十四届全国大学生信息安全竞赛作品赛一等奖以来再次获得该比赛最高奖项，也是学院系统软件与安全实验室对本科生培养的又一次成功实践。我实验室始终以致力于培养新一代网络安全顶尖人才为目标，近年来斩获全国大学生信息安全竞赛创新实践能力赛总决赛冠军、鹏城杯全国网络安全竞赛决赛、腾讯TCTF安全攻防赛等二十余项国内比赛冠军。未来，在师生的共同努力下，我团队将继续高歌猛进，昂扬向前，书写新的篇章！
