蓝队工具

01

工具介绍

做过防守的都知道大HW时的攻击IP量，那么对于这些攻击IP若一个个去溯源则显得效率低下，如果有个工具可以对这些IP做批量初筛是不是更好？基于这种需求写出该工具。


02

工具功能及使用

TrackAttacker 是一个通过IP追踪攻击者指纹工具

TrackAttacker目前版本为1.0，已满足功能如下

IP批量IP查域名IP查地址IP查端口IP查主机名域名查备案域名查Whois

Install

python3 -m pip install -r requirements.txt

开始使用

urls.txt放入需扫描ip

加all参数=加端口扫描

python3 TrackAttacker.py3python3 TrackAttacker.py3 all
