# **admin/upload.php 后台文件上传**

全局搜索**move\_uploaded\_file()**

![](../Images/94eb5d069a79df8c521b50fd6c27ec51.png)

  

```
















function up_img($file,$size,$type,$thumb=0,$thumb_width='',$thumb_height='',$logo=1,$pic_alt=''){
```

发现上传函数up\_img只对文件类型做了校验，之后就进行上传

```


if(!move_uploaded_file($file['tmp_name'],$file_name)){
```

那么file\_type这个字段是MIME类型，我们抓包可以修改，所有此处文件上传存在问题，看一下谁调用了这个方法

![](../Images/cc3208a1e24c3295fd6d1026c81aca22.png)

![](../Images/80fdf4a18e2f9988132e02ea80239c1a.png)

admin/upload.php处的上传，限定mime类型为这几种

```
$value_arr=up_img($_FILES['up'],$is_up_size,array('image/gif','image/jpeg','image/png','image/jpg','image/bmp','image/pjpeg'),$is_thumb,$thumb_width,$thumb_height,$logo);
```

![](../Images/d30e60aaf0a1f78e22f2ae4971b428eb.png)

这里只需要上传时修改mime类型就行

![](../Images/bd5068d7f41301b6333dc7daf1a2ba69.png)
