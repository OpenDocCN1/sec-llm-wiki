大家好，这里是 **大余安全**的第 **132** 篇文章，本公众号会每日分享攻防渗透技术给大家。

  

  

靶机地址：https://www.hackthebox.eu/home/machines/profile/140

靶机难度：高级（5.0/10）

靶机发布日期：2018年10月13日

靶机描述：

DevOops is a relatively quick machine to complete which focuses on XML external entities and Python pickle vulnerabilities to gain a foothold.

  

请注意：对于所有这些计算机，我是通过平台授权允许情况进行渗透的。我将使用Kali Linux作为解决该HTB的攻击者机器。这里使用的技术仅用于学习教育目的，如果列出的技术用于其他任何目标，我概不负责。

可以看到靶机的IP是10.10.10.91..

访问这是一张图片...爆破看看

dirb有点慢，gobuster获得了upload目录...

![](../Images/152cd238bc5272e0a44b14490a66a270.png)

文件上传漏洞...

提示XML elements，仅允许xml文件...就上周做了一台类似的XML\_XXE漏洞信息收集...

![](../Images/8f5896df7442c3fb1cc1d660ea4b3978.png)

google搜索下EXP...

![](../Images/5ec2e10109bebbe970498583406475e5.png)

直接利用即可...

![](../Images/94672eebd8b62e9416f480d3d4fbfc9b.png)

上传...

![](../Images/3ebf08196af942c415bd476b64958492.png)

利用bp拦截上传代码..好利用获取信息...

获得了底层用户名信息...

![](../Images/b350abf2d8bbd6f17a22ceaed59f815e.png)

直接获得了user\_flag信息...

这里可以获得user\_flag和上次靶机一样了...

![](../Images/c33872ecb84c0aeaa443ced7c51be484.png)

直接查看该用户的ssh\_rsa即可...

![](../Images/4f2fd8fc6653d9e4ac9310fc8b281cb6.png)

赋权，成功登陆roosa用户...

![](../Images/3c6ef3f1cba854c4e752856cf2598180.png)

遍历枚举了各个目录，在work目录下发现了.git目录...这目录类似服务器中github保存.git文件地方...

![](../Images/10e530f12c9fcef4546ef0de25e57538.png)

通过git log查看到了历史更改密匙的日志记录信息...

![](../Images/607c17fddb9b280877168ca96ff6d603.png)

这里很多信息..add key吸引着我，key密匙...

![](../Images/81a86fdab61839a692829e39ea0d74bb.png)

通过git show读取到了日志信息...是个rsa...

![](../Images/8ac12a587506add791334be1cb4faa23.png)

继续尝试登陆root...失败...

![](../Images/aacae18650cce71910ef4f771d13d082.png)

进过检查，发现左边得去掉+符号...

![](../Images/e7d3c361b26003dd4270c539b98d71f0.png)

修改完后，继续重新操作，成功登陆root用户获得root权限...

并获得了root\_flag信息...

该靶机前期XXE漏洞获得rsa是做过一次的...
