二、提权

![](../Images/663732ee85ad6d09a87e9d37c5b4cc6b.png)

  

  

![](../Images/9253114ff34ae44c67b154949cc5f949.png)

直接利用rsa成功登录，获得了user\_flag信息....

![](../Images/232d01c7fb83829c5550788cc897ac98.png)

在www/html页面发现隐藏页面信息....很多内容....

![](../Images/cadc5ae5ddb7d5d5a1b420ca7264c3a9.png)

直接访问发现存在问题，页面无法读取...应该是域名问题...

直接将aragog aragog.htb添加到hosts即可...

![](../Images/bdd676db89f3e39ee1fd572ecf6cead3.png)

cliff告诉我们两件事，他经常登录该页面，并且该站点也正在恢复....仔细检查

![](../Images/434e6ad1dc54c9d974fa914658bcb303.png)

我通过访问admin.php直接进入了登录页面，但是页面url跳转到了wp-login.php文件下...

![](../Images/79157bebcd5fe37a5e85a244565bda8d.png)

利用pspy32监听了靶机内所有进程情况，等待了5~7分钟，发现了一个规律，wp-login.php为UID = 1001在调用，然后每一分钟准时调用一次....

![](../Images/95cf8953c7798472727f92c37b21b0f9.png)

*   

```

```

如何利用wp-login.php获取admin-php页面的登录密码？在google看到了这篇调用文章....

![](../Images/1caa73f68c1dcfa8929e8023d693cc5c.png)

直接删除掉该文件，重新创建个，将文章方法添加入测试....

等待一分钟后，成功获得了administrator密码....

![](../Images/590115f1010bc1c2d52dd8bf13cd0cd7.png)

  

![](../Images/0897f36711f530920cb82ddd2dce7c3f.png)

由于前面知道这是UI=1001在调用的，以为该密码是cliff用户的登录密码...但是无权登录...

尝试su\_root直接成功登录获得了root权限用户外壳....

成功获得了root\_flag信息....
