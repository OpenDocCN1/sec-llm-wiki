# 注意：微软4月安全更新与多款防病毒软件冲突

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MzM0NjcxNw==&mid=2247484801&idx=1&sn=bac73f77a67b0cc8935dd5369f22aa76&chksm=eabc0af3ddcb83e5d50f8f84a0725b6bf9a9c3a8212fc88126fcc2dd6aba6284994bafa95d0d&scene=126&sessionid=1681653844#rd](http://mp.weixin.qq.com/s?__biz=MzI2MzM0NjcxNw==&mid=2247484801&idx=1&sn=bac73f77a67b0cc8935dd5369f22aa76&chksm=eabc0af3ddcb83e5d50f8f84a0725b6bf9a9c3a8212fc88126fcc2dd6aba6284994bafa95d0d&scene=126&sessionid=1681653844#rd)

部分防毒软件用户在部署微软于4月9日释出的Patch Tuesday安全更新之后，也许会发现系统的性能变差了、反应迟顿，甚至是死机了，那是因为此更新与多个品牌的防毒软件相冲，涵盖McAfee、Avast、Sophos、Avira与ArcaBit。

  

受到波及的安全产品涵盖McAfee Endpoint Security（ENS）Threat Prevention、McAfee Host Intrusion Prevention、McAfee VirusScan Enterprise、Avast CloudCare、AVG Business Edition防毒软件、Sophos Endpoint Protection、Sophos Central or Sophos Enterprise Console、Avira防毒软件与ArcaBit防毒软件。

  

所涉及的Windows版本则有Microsoft Windows 7、Microsoft Windows 8.1、Windows Server 2012 R2及Microsoft Windows 10不等。

  

安装这些防毒软件的Windows用户在部署微软的4月安全更新并重启之后，可能会发现系统性能变差、反应迟钝或根本动弹不得。  

  

目前微软正在与McAfee共同调查此一问题，而Avast已经释出了紧急更新来解决，Sophos也发出声明以通知客户，微软亦暂时禁止安装Sophos Endpoint、Avira及ArcaBit等防毒软件的Windows装置接受4月更新。
