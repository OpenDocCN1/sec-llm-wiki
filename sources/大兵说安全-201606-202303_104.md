# 企业信息安全投资回报率ROI的计算

网络在给我们打开一扇窗的同时，也打开了潘多拉魔盒。病毒攻击、硬件意外、数据丢失和业务停顿等，接二连三，只能让人叫苦连天，后悔不堪。做为单位的信息主管，很多人考虑的是如何给单位网络最大的安全，但往往报上去的方案和预算被领导否掉，是领导不懂吗？还是领导不重视？其实对于公司决策者来说，安全固然是他要考虑的问题，但更重要的是他要考虑投资回报率ROI（Return of Investment，ROI），任何企业对投资都有回报的要求，回报可能是直接的「利润」，达到短期、长期的目标，或者通过投资减少损失。因此每个项目的决策者在每笔投资前都要衡量 ROI，证明该投资能达到的效果和收益，以便在项目结束时可以考核和衡量项目是否成功。

ROI 通常是通过如下的公式来计算的： ROI = （收入- 投资总额） / 投资总额×100%

比如说你投资10000元，带来了25000元的收入，那你的投资回报率就是（25000-10000）/10000\*100%=150%

  

但传统的投资回报率计算方式并不十分适合信息安全投资，ROI的计算对于信息安全方面的投资来说却是一件很艰难的事，因为安全投资对大多数企业来说，并不能带来非常直接的收益和利润。它通常是防止公司财产损失，换句话说就是投资安全不要期望有利润回报。因此计算信息安全投资回报率应该计算通过安全投资避免了多少损失。也有人称之为“ROSI（Return of Security Investment，ROSI）”

  

信息安全投资决策者也需要知道信息安全投资的底线在哪里，哪些地方进行安全投资是收益最高的，哪些安全产品是投资回报率最高的。在信息安全投资领域，ROSI 能给决策者提供定量的指标：

• 是否对信息安全投资过度，造成浪费

• 信息安全缺乏是否会对企业收益造成影响

• 安全投资到什么程度就够了

• 什么安全产品或者方案对企业有利

  

我们在选择安全产品的时候，除了要考虑产品本身的性能、价格等因素以外，也要结合单位的实际情况，综合评估信息安全投资回报率(ROSI)。做为一个信息主管，在给领导上报方案预算的时候，不能只考虑能解决什么问题，还要学会算帐，算一算投资回报率。

  

比如说，我们给车买保险的时候，就是一个典型的计算ROSI的代表。如果您车价值四十万，假设一年有可能出现一次事故，单次维修费用约为两万元，如果让你花5000元买保险，那你就感觉是值的。同样，如果您的车价格十万元，单次维修费用约为5000元，让你花5000元去买保险，你就会觉得不值。

  

       

如果每支出100元能够在年内避免约1000的高风险安全事件，那么相信企业管理层肯定乐于掏出这点小钱。一般来讲，实现这项目标的难题分为两点：一是如何证明我们确实需要这100元（而非70元或者80元），其二则是这100元是怎样帮助企业预防可能出现的1000元直接经济损失的。

  

  

这里就涉及到如何计算安全投资回报率的问题。

  

我们在计算一个安全产品的投资回报率的时候，**首先需要对显性和隐性的意外事故进行一个分类整理的工作，并对其发生有一个初步预估，做到即使泰山崩于顶而面不改色。其次要能够评估一项安全投资能避免什么样潜在的安全风险（风险评估），然后根据定量的方法将这些风险带来的损失，转换成可以衡量的货币价值。**

  

我们需要计算所谓年度预期损失（即ALE）：指在预期之内的、由特定风险及威胁（如果未受合理控制）所造成的经济损失约值。为了给出较为准确的结果，我们可以使用一项来自CISSP®-ISSMP®官方指南的简化ALE计算公式： 

  

**ALE = (每年事故数量ARO) X (单一预期损失SLE)**

  

• **单一预期损失(SLE）**：就是一项安全事故发生时预期会造成的损失，这里单指这项风险发生一次产生的损失。网络威胁的特殊性，在计算损失时相对比较复杂，比如一台电脑硬盘坏了，我们在计算损失的时候不能只计算硬盘的价值，还应该加上购买成本，业务的损失，声誉，知识产权损失等等。  

安全事件的总成本应包括直接损失的成本（网站停机时间、硬件更换、数据丢失更换等）和间接损失成本（调查时间、声誉损失、人力成本等）

关于如何计算网络攻击对企业的具体损失，没有统一的标准，具体的计算取决于企业的经营目标、文化价值观和现有的安全措施等。还是用硬盘损坏的电脑来说，如果仅仅是一台普通的电脑，损失也就是买硬盘的1000块钱，但如果是财务或医院的HIS服务器，那损失就不是1000块钱了，更值钱的是上面的数据，以及影响的业务所产生的损失，甚至重新录入时的人力成本等，损失可能有数十万元，而如果是对于保密单位的电脑，甚至是知识产权或者涉及国家机密，那这所产生的损失就无法估量了。

虽然计算损失的方式依赖的条件多种多样，但是统一的计算方式还是非常重要的。前一段和一个医院的信息中心主任聊天，他说起他计算损失的方法，他说我们医院每年的收入为1亿元，目前全部依赖HIS系统，那么相当于每天收入27.4万，每小时1.1万，每分钟190元。如果因为HIS系统停机，那么停机一天，造成的损失就是27.4万元。

  

• **网络威胁在一年中发生的概率（ARO）**：就是某种网络威胁在一年中可能发生的概率和次数，这种评估也是根据具体的网络环境和安全保护措施，也是根据经验得出的一个估计得值。

例如洪水发生的概率是根据当地的地质条件和降水情况而定的。地震的概率是根据当地是否在地震带上以及历史情况来定的。安全威胁发生的概率也是根据企业的成熟度，人员的安全意识和技能以及安全防护工具的完备性决定的决定的，比如软件提供商通过严格的安全检验和测试，漏洞很少，那么漏洞攻击发生的概率就小很多。再比如企业在每台机器装上最新反病毒软件，那么被病毒感染的几率就小很多。电脑操作人员经过培训，有强烈的安全意识，那么网络威胁产生的机率也会少。

这个概率可以根据之前没有进行安全投资之前的经验得出，也可以由安全产品部署后从日志中得到。比如，在没有部署杀毒软件之前，一年有过二十例病毒感染报告，那我就们可以得出病毒威胁在一年的发生的概率约为二十次。

  

  

如某单位去年一年出现勒索病毒2次，每次损失金额为10000元，硬盘损坏一次，损失金额20000元，则

ALE=10000\*2+20000\*1=40000元。

  

  

ROSI 主要是综合定量预估的风险损失和部署安全措施的花销。在最后比较减少的损失和实际通过部署安全措施挽回的损失，根据 ROI，ROSI 的计算公式如下：

  

**ROSI = （减少的损失 - 安全措施的花销） / 安全措施的花销。**

  

使用有效的安全措施可以有效的减低 ALE：安全措施越得力，ALE 降低的越多，我们实际的收益就越高，实际的收益就是不使用安全措施的 ALE 和使用安全措施以后的 ALE（用 mALE 表示）之差。ROSI 公式可以改为： 

  

**ROSI = （ALE - mALE - 安全措施的花销） / 安全措施的花销**

  

还可以通过缓解率来计算，缓解率就是实施某个安全措施后减少攻击的比例，ROSI 公式可以表示为：

  

**ROSI = （ALE \* 缓解率 - 安全措施的花销） / 安全措施的花销**

  

举个例子：A 公司正在考虑投资一个防病毒解决方案。每年该公司遭受5个病毒攻击（ARO = 5）。该组织估计，在数据和生产力损失的成本每攻击约15000元（SLE = 15000）。实施防病毒解决方案预计将减少80%的攻击（缓解率= 80%），实施成本25000（每年授权费1500 + 10000培训、安装、维护等）。

该解决方案的安全投资回报，可以通过计算如下：（5 \* 15000）\* 0.8 - 25000 / 25000 = 140%

根据 ROSI 公式计算，这个反病毒解决方案是一个收益率非常不错的解决方案。

  

而如果反病毒的实施成本为35000元。

则该解决方案的投资回报为：（5 \* 15000）\* 0.8 - 35000 / 35000 = 71.4%

根据ROSI公式计算，这个反病毒解决方案就不是一个很好的解决方案。

  

当然，这里还有一个因素就是缓解率，这个是跟所选择安全的品质是有一定关系的，比如同样是杀毒软件，有的可能会达到90%，而有的可能只能达到60%，还以上面的例子计算：

A:（5 \* 15000）\* 0.9 - 35000 / 35000 = 92.9%

B:（5 \* 15000）\* 0.6 - 25000 / 25000 = 80%

虽然A方案比B方案贵了一万元，但由于缓解率比B方案高，所以投资回报率要比B方案更高一些。

  

总结: ROSI 的计算是基于3个变量：估计潜在损失（ALE），估计风险缓解，和解决方案的实施成本。如果解决方案的成本比较容易预测,所有间接成本都考虑进来,其他两个变量也预估的比较正确，这样 ROSI 就比较好算了。

  

在实际的工作中前期的预测是一件比较困难的事情 ，我们也可以在每年的工作总结中根据上一年通过现有的安全投资拦截和避免的安全风险进行计算，得出已投资的安全产品的ROI。
