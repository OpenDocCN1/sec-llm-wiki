# 【精华分享】Gabriela Ehrlich：ABC of cyber security

在国际网络安全与合格评定论坛上，国际电工委员会（IEC）公关事务与传播全球负责人加Gabriela Ehrlich女士在论坛上就国际电工委员会（IEC）在网络安全领域的战略和工作进展情况进行了介绍。她阐述了网络攻击的数量日益增多，复杂程度逐渐加深的现状。网络安全主要被信息技术主导，然而对于制造业和关键基础建设，则需要其他解决方案。她进一步阐释了信息技术与运营技术的不同，同时通过借助IEC标准与合格评定体系，为提高制造业和关键基础建设行业的网络弹性提出应对策略。
