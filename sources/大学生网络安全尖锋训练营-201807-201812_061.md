# 【专家观点】魏昊：增进与国际社会的相互了解，推动我国认证认可工作发展

2018年9月18日，由成都市人民政府主办，中国网络安全审查技术与认证中心和IEC共同承办的“国际网络安全与合格评定论坛”在国家网络安全宣传周成功举办。中国网络安全审查技术与认证中心主任魏昊在论坛上进行了发言。

*（以下内容由国际网络安全与合格评定论坛上的录音整理而成）*

![](../Images/8516b549474eb29288c2aefdb383cb5a.png)

  

尊敬的各位来宾，女士们、先生们：

大家上午好！

非常欢迎大家参加国家网络安全宣传周的“国际网络安全与合格评定论坛”。大家知道网络空间是人类活动的新疆域、新领地，是陆海空之外的空间。网络安全问题是人类面临的严重挑战，网络安全的治理是构建人类命运共同体的重大课题。从全球范围看，标准与合格评定是支撑网络安全的重要手段和基础性机制。尤其是近年来，由于网络安全受到国际社会的高度关注，世界各国的网络安全法律法规、标准规范和合格评定制度也正在快速的发展，我国高度重视网络安全的标准认证工作，把这项工作上升到战略和法律的层面。

 

网络安全认证制度也在我国法律体系中占有重要的地位，2017年6月1日实施的《中华人民共和国网络安全法》对利用标准和认证认可手段维护和促进网络安全作出了明确的规定。网络安全领域的认证认可工作与网络和信息技术产业的发展关系密切，因此受到了国内外各方的关注。同时，在建立和完善认证认可制度方面，也离不开政、产、学、研、用等方面的协同配合。这次论坛我们邀请了网络安全领域的相关政府部门、网络安全企业、科研院所和大学、安全技术产品和服务的典型用户，我们希望通过这个活动交流分享信息，集思广益，共同推动我国网络安全领域认证认可工作的发展。

 

我们看到在全球化的今天，面对网络安全问题没有哪个国家能够独善其身，因此加强国际合作是应对网络安全威胁的必由之路，在网络安全标准和合格评定领域尤其如此。我国十分重视国际交流与合作，这次论坛在国家网信办、国家市场监督管理总局的指导下，我们和在标准化合格评定领域有着重要国际地位和广泛影响力的国际电工委员会IEC合作举办，旨在增进我国在国际社会网络安全标准和合格评定领域的相互了解，推动合作，共同审视和探讨网络安全标准化与合格评定体系的现状和未来发展之路。

  

本次国际网络安全与合格评定论坛，我们邀请了认证认可以及网络安全领域的国家主管部门的相关领导，给我们介绍了我们国家的法律法规体系、网络安全战略体系、市场监管体系当中，标准和合格评定的要求和发展方向。我们也邀请了从事信息安全、网络安全、标准制订认证工作、认证机构的代表和我们分享了标准制定及认证活动开展的情况。通过这样的交流和分享，我们有这样共同的认识：

**第一，标准和合格评定是网络安全保障体系当中非常重要的、不可或缺的组成部分。**

**第二，网络安全新技术、新挑战需要我们更加努力地在标准和合格评定领域付出更多的努力。**

**第三，网络安全全球威胁的特征使我们必须加强国际合作。**
