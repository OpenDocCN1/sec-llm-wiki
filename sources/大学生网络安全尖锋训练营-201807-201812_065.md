# 【专家观点】李春江：大力推行认证认可标准应用，加强国际交流合作

2018年9月18日，由成都市人民政府主办，中国网络安全审查技术与认证中心和IEC共同承办的“国际网络安全与合格评定论坛”在国家网络安全周成功举办。国家市场监督管理总局认证监管司副司长李春江发表了致辞。

*（以下内容由国际网络安全与合格评定论坛上的致辞录音整理而成）*

![](../Images/fc1a1abbced6921732b0e70587125cdb.png)

  

  

尊敬的各位来宾、女士们、先生们：  

  

大家上午好。  

今天国家网络安全宣传周论坛，国家网络安全与合格评定论坛在成都隆重召开，我谨代表国家市场监督管理总局认证监管司对前来参会的IEC的嘉宾，还有国家安全和合格评定行业的同仁、专家学者、工商业组织和企业代表表示最诚挚的欢迎！感谢国家网络安全宣传周组委会对本次论坛的重视，感谢成都市人民政府成都市网信办统筹策划安排，感谢中央网信办、IEC国际电工委员会对本次论坛的大力支持，感谢全体来宾对网络安全合格评定事业的管理和参与，同时也感谢中国网络安全审查技术与认证中心和IEC为承办本次论坛付出的辛勤劳动，谢谢大家！

大家知道当今阶段网络安全已成为全球范围都十分关注的话题，网络时代小到个人生活，公司机构的运营，再到技术更新，经贸往来，乃至国家基础建设和世界政治格局的建立，都依从于有形或者无形的网络的发展和联通，因此网络的安全不仅关系到对个人隐私的保护，和对技术及商业机密的捍卫，也维系着国家的安全繁荣和世界的稳定和平。

党中央和国务院高度重视网络安全和信息化工作，特别是习近平主席强调，没有网络安全就没有国家安全，没有信息化就没有现代化。建设网络强国的战略部署要与“两个一百年”奋斗目标共同推进，党的十八大以来我国坚持规划引领及法律制度现行，出台的网络安全法和相关政策文件，并积极应用国际通用的标准、技术管理手段，我国网络安全保障体系建设取得了可喜的进步。大家知道标准认证认可、检验检测等合格评定是国际公认的国家质量技术基础，世界各国普遍应用质量技术基础，构建网络安全保障体系，保障网络安全，引领产业进步，提升国际竞争力。

近几年来，依据相关法律法规及国家政策，在中央网信办的协同组织下，国家市场监督管理总局会同各部门、各有关方面构建了既符合国家同行规则，又符合我国国情的现实网络安全标准体系，认证认可和检验检测合格评定体系，大力在各行各业推行国际标准应用，大力推行实施信息安全产品，信息安全管理体系和服务资质等认证。截止到2017年年底，累计颁发与信息安全相关的各类认证证书14000多张，覆盖30多类信息安全领域常用产品和1000余家获证组织，得到了政府、行业组织的广泛采信，有力提升了系统和服务的质量。有利于产业的创新，为促进出口创造了条件，在国家网络安全保障引导产业发展中发挥了重要的作用。我国标准及认证认可的深入应用和推进得益于与IEC等国际组织的合作与指导，早在1957年我国就正式加入了国际电工委员会。

自上世纪80年代起，中国陆续成为IEC合格评定委员会的成员，2010年成为IEC常任理事国。在与IEC的合作交往中，我国从IEC学习借鉴了很多优秀先进的标准化与合格评定的技术和方法。可以说中国的产品认证制度，始于IEC电子元器件合格评定体系，即IECQ，并以此推动了我国的标准化及合格评定与电子电工产业的发展。与此同时，我国也一直是推进IEC进步的推动者，我国是IEC委员会和分委员会的技术成员，参与了IEC国际标准制订与合格评定工作，在IEC组织内的管理层和管理决策机构均有代表。近年来我国与IEC的合作又有了新的方向，2006年中国网络安全审查技术与认证中心魏昊主任当选IEC大使，专门负责在网络安全领域与IEC的合作，这不仅表明IEC的关注范畴已经从传统的电工领域转向新兴的网络安全领域，也同时表明IEC非常重视中国在国际网络安全格局中的作用，重视中国巨大的充满活力的信息技术与网络市场。

今天举办的论坛活动，标志着中国和IEC网络领域合作方面迈出了新的步伐。尤其是在这个论坛能够作为我国国家网络安全宣传周的重要活动之一，汇集了这么多网络安全行业的敬业机构和企业，更令人关注。在此我希望大家能够以此为平台交流合作、贡献智慧、分享经验、相互启发，为明年我国顺利举办第83届IEC大会奠定一个好的基础，取得更广泛的合作进展，向全世界展示我们的合作成果。

谢谢大家！
