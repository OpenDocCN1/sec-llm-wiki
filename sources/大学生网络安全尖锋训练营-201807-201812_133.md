# 【会议通知】中国关键信息基础设施安全高峰论坛即将在乌兰察布举办

2018年7月21日，中国关键信息基础设施技术创新联盟将与乌兰察布市人民政府共同主办中国关键信息基础设施安全高峰论坛。

  

会议背景

  

随着国际网络空间斗争的不断加剧和互联网技术的极速发展，关键信息基础设施保护面临着全新的挑战。“云物移大智”无不对关键信息基础设施产生或正或负的影响，尤其是大数据时代的到来，既为关键信息基础设施保护提出新的要求，也为关键信息基础设施保护提供了新的手段。为研究探讨新形势下关键信息基础设施保护的法律、政策、理论、技术、产品、服务、人才等问题，拟举办中国关键信息基础设施安全高峰论坛。  

  

论坛将邀请中国科学院院士、中国工程院院士、国家级检测评估认证机构领导、法律政策法规专家、关键信息基础设施运营单位代表、产业领袖、技术专家共同探讨关键信息基础设施保护问题。

  

会议主题

  

新环境、新机遇、新挑战，大数据环境下的关键信息基础设施安全。

主要议题：

1、国际关键信息基础设施保护现状与发展趋势；

2、《网络安全法》关键信息基础设施保护相关条款解读；

3、关键信息基础设施安全态势分析；

4、重点行业关键信息基础设施保护现状与需求；

5、关键信息基础设施安全与等级保护；

6、关键信息基础设施数据保护实践；

7、关键信息基础设施保护技术方案分享；

8、关键信息基础设施保护优秀产品、解决方案征集。
