# 【权威发布】封化民秘书长启动尖峰训练营

2018年6月26日由中国网络安全审查技术与认证中心指导、中国关键信息基础设施技术创新联盟（筹）主办网络安全人才培养与需求高峰论坛在北京渔阳饭店圆满闭幕。教育部高等学校信息安全专业教学指导委员会秘书长封化民在论坛上正式宣布启动“大学生网络安全尖峰训练营”工程并发表了致辞。

大学生网络安全尖锋训练营启动仪式致辞稿  

  

各位领导，各位专家，大家好。感谢中国关键信息基础设施技术创新联盟对我的信任，由我来宣布大学生网络安全尖锋训练营的正式启动。

自从2015年网络空间安全一级学科设立以来，网络安全人才问题成为各界关注的热点。院校是我国人才培养的最重要、最广泛的来源。在网络安全人才培养方面，院校教育面临一个突出问题：如何让培养出的人才在毕业步入社会走上工作岗位时，能够很快的胜任自己的工作任务、满足用人单位的需求、充分发挥自己在校期间所学知识、为国家和社会尽快的创造实际的价值，也就是刚才主持人所说的“最后一公里问题”。这一问题是众多高校教育从业者一直在不断努力进行探索和研究、力求取得突破的热点。

为了解决这一问题，我有两点建议：一是探索网络空间安全创新人才培养机制，学校与业界深度融合协同培养人才。高校加强与行业主管部门、信息安全相关企事业单位、科研院所开展合作，共同制定网络空间安全人才培养目标、共同开设相关课程和编写教材、共同实施培养过程、共同评价培养质量。推动有关院校网络空间安全类专业积极参与教育部“卓越工程师教育培养计划”，促进网络空间安全人才培养与国家网络安全事业发展紧密结合，培养更多卓越网络空间安全人才。二是强化网络空间安全实战技能培养和实习实训。规划建设一批网络空间安全实习实训基地，统筹安排网络空间安全类专业学生到国内信息安全参加实习实训。倡导国内信息安全企业与高校共同制定学生实习实训方案，主动接收学生开展实习实训。

大学生网络安全尖锋训练营在高校和用人单位之间建立良好的协作平台，一方面创新的网络安全人才定制化培养机制，有利于促进校企深度融合、协同育人；另一方面，由企业家和行业主管领导担任参训学员的导师，有助利于迅速提高学生的实战能力和职业规划水平；与此同时，由高校和企业组成联合培养基地，有利于校企共同制定学生实习实训方案，最大程度的提升实训效果。

希望尖锋训练营的主办单位在有关主管部门的指导下，发挥资源平台的优势，按照既定计划组织好训练营的选拔、集训和演练工作；希望训练营的各参与单位能够精诚配合，在协同育人方面不断开拓创新；希望各位尖锋导师高度重视人才培养工作，将各自的从业经验无私传授给学员，打造出一批品学兼优的网络安全尖锋人才。

最后，我宣布“大学生网络安全尖锋训练营”启动。
