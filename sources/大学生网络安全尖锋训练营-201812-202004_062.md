# 【知识分享】CPU领域的“新世界”

        3月26日19：30-20:30，飞腾行业解决方案专家申友志做客网安尖锋大讲堂，带大家走入CPU领域的“新世界”。

本期尖锋大讲堂以CPU为主线，从CPU生产的工艺流程，CPU的发展历史，现在的历史阶段，以及未来的发展方向，几个维度带领大家从CPU的过去，现在，未来以及中国CPU的历史机遇有一个深层次的了解。 

![](../Images/210eaeb475669f111682d227d70764c9.png)

      申老师首先讲述了CPU的发展历史，对CPU的工艺进行了科普性的简述。同时还介绍了现在CPU的几种架构，并从技术及生态方面评估了X86、ARM、riscv、MIPS等架构的优劣势。此外，申老师还介绍了中国在这个历史阶段各CPU厂商选择的技术方案，以及飞腾在技术及生态方面的考虑。
