# 【知识分享】网络空间安全生态系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODkwMDMxNA==&mid=2247486939&idx=2&sn=c49a83aed0a3f28976181827c70e3012&chksm=fad1efeecda666f8bb7837b46e20b12556fd119eb2a7c2dcbc827d302e76b1ecfe81c4554fcc&scene=126&sessionid=1681655994#rd](http://mp.weixin.qq.com/s?__biz=MzUzODkwMDMxNA==&mid=2247486939&idx=2&sn=c49a83aed0a3f28976181827c70e3012&chksm=fad1efeecda666f8bb7837b46e20b12556fd119eb2a7c2dcbc827d302e76b1ecfe81c4554fcc&scene=126&sessionid=1681655994#rd)

       3月20日下午2点，中国人民大学信息学院教授、博士生导师石文昌坐客网安尖锋大讲堂，为大家作了一堂关于网络空间安全生态系统的生动报告。

       报告的出发点是宣传已经引起国际社会重视的网络空间安全生态系统（简称安全生态）的理念，结合实例介绍其中的基本概念和基本思想及其在解决网络空间安全问题中的重要作用。安全生态的理念得益于自然生态的启发。报告首先选择欧美和我国的实情为代表，展示问题的现实背景。

  

![](../Images/e8c90c267ad76c53385042e4cbb2530e.png)

  

![](../Images/3670693112c70f19ef747c1f44139ba0.png)

  

       接着，报告简要介绍了自然生态系统的基本思想，主要对自然生态系统的统一整体、物质循环、能量流动、信息网络和反馈控制等思想进行简要的展现，目的是通过观察自然系统寻找把控人工生态之道。

  

![](../Images/408ffe396cdb9ba9c1d669994ddbb717.png)

  

        报告的核心是数字生态和安全生态，对自然生态的回顾是理解这一核心的基础。报告最后借助现实案例阐述在缺乏生态思维情况下安全问题的严峻性，针对这种严峻性，引出数字生态和安全生态的关键内容，同时展示国际上的最新发展状况。以期能给学员传播安全生态的基本思想，为现实安全问题的解决拓宽思路。
