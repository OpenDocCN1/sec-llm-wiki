# 【知识分享】LINUX文本过滤高级应用

      3月22日下午14:00-15:00，北京交通大学海滨学院信息中心副主任高级工程师贺秋雨坐客网安尖锋大讲堂，同大家分享了LINUX文本过滤的高级应用。

  

![](../Images/4ec308b6f731a97e684c909202033d65.png)

  

       众所周知，LINUX在信息安全领域应用非常广泛，学习好LINUX是进入信息安全领域必备的基础技能。此次贺老师分享的主要内容包括：学习信息安全LINUX的重要性、文本过滤对于LINUX的重要性、正则表达式和实际操作。

  

![](../Images/d335330d4e64006012ad93ebe4883536.png)

  

       首先，贺老师介绍了学习安全为什么要学习LINUX，以及学习LINUX为什么要学习文本过滤，层层递进的说明，充分的展现了文本过滤的重要性，它是学习安全的基础。

  

![](../Images/5b3bb43722ffee5741949bf16a0a742a.png)

  

![](../Images/1bb1db5e8418e0def10c57fa16ba6602.png)

  

       接着，贺老师介绍了LINUX环境下常用的文本过滤命令及正则表达式的知识。为了克服LINUX命令用法、选项、参数众多不容易记忆的困难，课程把众多文本过滤命令特别是grep、sed、awk命令融合到了一个实例里面，通过实例快速掌握命令的用法，且达到记忆深刻的目的。
