# 【课程预告】网络空间安全生态系统

     3月20日，中国人民大学信息学院教授石文昌将坐客网安尖锋大讲堂，就网络安全生态问题发表演讲。

      石教授是北京大学理学学士，中国科学院工学博士，中国科学院院长奖获得者；中国人民大学信息学院教授，博士生导师，信息安全专业/学科的创建者和责任教授；兼任中国科学院信息工程所博士生导师；主要研究方向为网络空间系统安全、人工智能安全博弈；主持承担了国家一系列重要科研项目，在国内外高水平学术会议和期刊（包括ICSE、WWW、IJCAI、CHI、ESEC/FSE、DSN、ICSME、IEEE TIFS、IEEE TSE、IEEE TDSC、Computer Network、Information Science等）发表学术论文一百多篇，出版了《信息系统安全概论》等著作和教材，任《网络与信息安全学报》等期刊编委；中国计算机学会杰出会员，教育部网络空间安全专业教指委委员，中国法学会网络与信息法学研究会副会长，中国云安全联盟专家委员会副主任；曾任中科院软件所开放系统与中文信息处理中心主任，上海浦东软件园有限公司副总经理，中国人民大学计算机系主任。

      石教授在思考网络安全生态系统的时候，联想到了自然生态系统，将两个方面的主题糅合到一起，发现了解病毒生态系统对认识网络安全生态系统还是挺有帮助的，并着手把病毒生态系统的内容整理成文字。需要说明一下，这些不是医学内容，更不是病毒学内容，是和病毒相关的生态方面的内容。具体内容请参考：
