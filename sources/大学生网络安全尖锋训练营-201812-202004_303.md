# CISAW-岗位能力（医疗、数据安全）开班计划

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODkwMDMxNA==&mid=2247485347&idx=1&sn=a9653323126aa1666fb59d05c6ca093f&chksm=fad1e596cda66c800f4940923fa3d413ea188c6369b073375a50467c96c20f8cc9c39be72aa1&scene=126&sessionid=1681656081#rd](http://mp.weixin.qq.com/s?__biz=MzUzODkwMDMxNA==&mid=2247485347&idx=1&sn=a9653323126aa1666fb59d05c6ca093f&chksm=fad1e596cda66c800f4940923fa3d413ea188c6369b073375a50467c96c20f8cc9c39be72aa1&scene=126&sessionid=1681656081#rd)

北京卫达信息技术有限公司将于7月在北京开展“信息安全保障人员认证-岗位能力”培训。其中，信息安全保障人员认证-医疗行业安全岗位能力（CISAW-HSP）培训的时间为7月27日至7月30日；信息安全保障人员认证-数据安全岗位能力（CISAW-DSP）培训的时间为7月31日至8月4日。
