# 彭江波：聚焦关键信息基础设施中数据安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODkwMDMxNA==&mid=2247485314&idx=1&sn=0e0b3f275f5596561bdff026aaf3af8c&chksm=fad1e5b7cda66ca1efb4b5856e760a31fd92d888dd6e062848ba9045d6089238bc04186627ee&scene=126&sessionid=1681656086#rd](http://mp.weixin.qq.com/s?__biz=MzUzODkwMDMxNA==&mid=2247485314&idx=1&sn=0e0b3f275f5596561bdff026aaf3af8c&chksm=fad1e5b7cda66ca1efb4b5856e760a31fd92d888dd6e062848ba9045d6089238bc04186627ee&scene=126&sessionid=1681656086#rd)

2019年6月29日，2019数据安全峰会关键信息基础设施安全论坛圆满落幕。浙江华途信息安全技术股份有限公司技术总监彭江波先生带来《聚焦关键信息基础设施中数据安全》的演讲。

  

![](../Images/f2ba633f977c3fec2686d2b4cb0862a6.png)

**浙江华途信息安全技术股份有限公司**

**技术总监彭江波先生**  

  

关键信息基础设施是网络安全的重中之重，也是极易受到攻击的重点目标，日益严峻的网络安全环境呼唤更多的网络安全企业带来防护方案、思路、经验。彭江波先生从网络安全产业、技术的角度分享了关键信息基础设施面临的风险，提出数据安全保护的思路。
