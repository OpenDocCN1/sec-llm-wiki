# 厘清思路、明确目标、关键重保 ——2019 数据安全峰会关键信息基础设施安全论坛成功召开

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODkwMDMxNA==&mid=2247485278&idx=1&sn=b6c3c676bfc2337ee2aaeb5defd2b74b&chksm=fad1e56bcda66c7ddd782438ad2bc37bcac06b3c2248eda4e37a8c10b639a6efe5042c6bcc45&scene=126&sessionid=1681656086#rd](http://mp.weixin.qq.com/s?__biz=MzUzODkwMDMxNA==&mid=2247485278&idx=1&sn=b6c3c676bfc2337ee2aaeb5defd2b74b&chksm=fad1e56bcda66c7ddd782438ad2bc37bcac06b3c2248eda4e37a8c10b639a6efe5042c6bcc45&scene=126&sessionid=1681656086#rd)

2019 第二届数据安全峰会今日在杭州召开，由中国网络安全审查技术与认证中心指导，中国关键信息基础设施技术创新联盟、中国计算机学会计算机安全专委会、浙江华途信息安全技术股份有限公司主办，中国关键信息基础设施人才智库支持的关键信息基础设施安全论坛也同期召开。

来自关键信息基础设施行业代表、来自全国各地的网络安全一线管理者、众多的网络安全从业者200多人参加了论坛。

![](../Images/4c225a62775bc17a0e1388918b23d9d1.png)

中国网络安全审查技术与认证中心魏昊主任、中国科学院郑建华院士、浙江省委网信办宋皆荣副巡视员、中国计算机学会计算机安全专委会严明主任、中国电子商会自主可控技术委员会冯燕春理事长、杭州市保密局顾江局长、交通通信信息集团有限公司李璐瑶总经济师、中国人民银行金融信息中心信息安全部袁慧萍主任、公安部网络安全保卫局唐前临处长、中国网络安全审查技术与认证中心体系与服务认证部张剑主任、清华大学特别研究员金涛、《中国信息安全》杂志主编崔光耀、浙江移动信息安全部方国强总经理等出席论坛。

中国网络安全审查技术与认证中心魏昊主任在致辞中表示，面对严峻的数据安全形势，如何做好数据安全保障工作，特别是关键信息基础设施相关的数据安全保障工作，需要从技术和管理两个层面入手，网络安全审查和认证制度将发挥越来越重要的作用。

![](../Images/d8baf8a9d75a2e7add5bf58df8ca2832.png)中国网络安全审查技术与认证中心魏昊主任

  

中国科学院郑建华院士长期从事复杂信息系统分析和相关基础理论研究。郑院士在致辞中表示，数据安全需要基于成熟的密码技术建立其保护体系。国家、科研机构、企业三方共同努力，才能有效的保障关键信息基础设施的安全。

![](../Images/bbe8d5ab2beea932ce097e67fef56a98.png)

中国科学院郑建华院士  

  

中国计算机学会计算机安全专委会严明主任，结合《网络安全法》和今年5月13日，国家市场监督管理总局、国家标准化管理委员会发布的等保2.0相关的国家标准，进行了题为《等保2.0与关键信息基础设施安全保护》的演讲。介绍了等保2.0的特点，并从重要性、监管对象、网络安全等级保护的措施、基本要求等方面进行了详细的论述。

![](../Images/8e12f413091553c42424fe6c2ff584bd.png)中国计算机学会计算机安全专委会严明主任

  

针对哪些单位可以被定义为CII运营者，CII运营的哪些网络设施、信息系统是关键业务持续、稳定运行所必须的，关键信息基础设施的边界如何识别等问题，中国电子商会自主可控技术委员会冯燕春理事长进行了《关键信息基础设施边界识别现状与趋势》的演讲，系统的梳理了对于关键信息基础设施边界识别的概念、进展、必要性，结合具体的实践，明确了对CII的边界识别问题。  

![](../Images/64e9f2bf284c272781f4767c292c49d8.png)中国电子商会自主可控技术委员会冯燕春理事长

  

论坛还邀请了来自关键信息基础设施行业的专家为大家带来一线的报告分享。

浙江移动信息安全部方国强总经理带来《数据安全治理思路探讨》。方总介绍了从中移动集团到浙江移动公司在数据安全方面的安全策略、安全管理、安全运营的建设思路和经验。

![](../Images/63c388e4799693075081f4090398621f.png)浙江移动信息安全部方国强总经理

  

交通通信信息集团有限公司总经济师李璐瑶女士带来《交通关键信息基础设施安全》。分享了对交通关键信息基础设施定位的理解，分析了交通关键信息基础设施信息系统的特征，并且提出了交通运输行业对自主可控技术的需求。

![](../Images/fe96fa2c8f06455646959e594a4799e6.png)

交通通信信息集团有限公司总经济师李璐瑶

  

清华大学特别研究员金涛为大家带来《健康医疗数据安全国家标准研制与实践》。他表示，关键信息基础设施的安全保护，标准是前提，在确保健康医疗数据安全的前提下促进数据开发利用，才能更加有效的保障医疗行业的数据安全。

![](../Images/866ee81b977334e24d64eb55c1064ad9.png)清华大学特别研究员金涛

  

中国人民银行资深安全专家袁慧萍主任为大家带来《银行关键基础设施网络安全的思考与实践》。她从当前网络安全的形势研判出发，回顾了近期国内外金融行业的安全事件，介绍了金融关键信息基础设施的行业主管部门“关口前移，防患于未然”的体系化建设思路。

![](../Images/ccab6e413c81bcf49e1c665fa18d3360.png)

中国人民银行资深安全专家袁慧萍主任

  

数据的产生、流通、存储、使用等是一个动态的过程，审查、检测认证和评估工作是保证安全管理和技术防护措施落实到位的重要保障。中国网络安全审查技术与认证中心体系与服务认证部张剑主任在《数据安全的思考》中对数据安全的范围、分级分类和保护框架等进行了详细的介绍。

![](../Images/96ff68fdae79c4f6064343bcfffb3075.png)中国网络安全审查技术与认证中心

体系与服务认证部张剑主任

  

关键信息基础设施是网络安全的重中之重，也是极易受到攻击的重点目标，日益严峻的网络安全环境呼唤更多的网络安全企业带来防护方案、思路、经验。浙江华途信息安全技术股份有限公司技术总监彭江波先生带来《聚焦关键信息基础设施中数据安全》，从网络安全产业、技术的角度分享了关键信息基础设施面临的风险，提出数据安全保护的思路。
