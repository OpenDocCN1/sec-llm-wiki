**“信息安全保障人员认证-岗位能力” **

**培训课程介绍**

  

《网络安全法》对网络运营者（特别是关键信息基础设施运营者）开展人才培训和考核做出了明确规定，要求定期对从业人员进行网络安全教育、技术培训和技能考核。为了落实《网络安全法》，中国网络安全审查技术与认证中心（CCRC）依据《网络安全人员角色分类和能力要求框架》发布了“信息安全保障人员认证-岗位能力”，并组织专家开发了相关培训课程，力争实现以下目标：培训内容服务于现实工作、培训模式理论结合实训、培训效果有助于提高工作能力。

CISAW-岗位能力课程包含三个维度：一是行业岗位能力认证培训，主要面向医疗、金融等重点行业的网络安全岗位；二是专业岗位能力认证培训，主要面向数据安全、DPO、工业信息安全等各行业通用的网络安全岗位；三是从业基础能力认证培训，主要面向以在校大学生为主的拟从事网络安全工作的人员。

相关认证和培训课程情况如下。

**认证和培训项目**

“信息安全保障人员认证-岗位能力”包括“行业岗位能力认证”、“专业岗位能力认证”和“从业基础能力认证”三个维度。

![](../Images/db992845a59f1d82c9bcd44ff272a7ef.png)

  

**（一）行业岗位能力认证**

行业岗位能力认证定位于特定行业网络安全岗位能力评价。认证对象为在特定行业拥有2年以上工作经验的网络安全从业人员。认证价值体现在为特定行业网络运营者招聘、培训、考核中高级网络安全人员提供参考和依据，为特定行业网络安全从业人员的能力水平提供评价和背书。  

  

1、**信息安全保障人员认证-医疗行业安全岗位能力培训**（Certified Information Security Assurance Worker - Competency Requirements of HealthCare Information Security Post, 简称CISAW-HSP）

  

培训内容包括：医疗信息化发展与安全挑战、医疗信息安全合规性要求、医疗信息安全技术基础、医疗信息安全管理实践、传统医疗信息安全保护案例分析、互联网医疗发展与安全设计。课程围绕医疗行业信息安全的疼点和难点问题，突出前沿性和实践性，重点从管理和技术两个层面提高参训人员的能力水平。同时针对互联网医疗中普遍存在的安全问题（如云计算安全、物联网安全、个人信息保护等），进行有针对性的讲解。

  

  

2、**信息安全保障人员认证-金融行业安全岗位能力培训**（Certified Information Security Assurance Worker - Competency Requirements of Financial Information Security Post, 简称CISAW-FSP）

  

培训内容包括：法律法规及金融监管要求、安全治理与管理、通用安全技术、业务安全、安全事件与应急管理、业务连续性与灾难恢复、金融科技安全。课程紧贴金融行业网络安全岗位需求，知识点分类合理、覆盖全面，强调理论与实践相结合、管理与技术相结合，立足现有技术和产业能力实现安全目标，并面向前沿趋势进行了适当扩展。

  

  

**（二）专业岗位能力认证**

专业岗位能力认证定位于特定网络安全岗位能力评价。认证对象为特定专业方向拥有2年以上工作经验的网络安全从业人员。认证价值体现在为网络运营者招聘、培训、考核专业方向的中高级网络安全人员提供参考和依据，为专业网络安全从业人员的能力水平提供评价和背书。

  

3、**信息安全保障人员认证-数据安全岗位能力培训**（Certified Information Security Assurance Worker - Competency Requirements of Data Security Post, 简称CISAW-DSP）

  

培训内容包括：数据安全法规标准、数据安全管理体系、数据安全防护技术、数据安全分析技术、数据安全工程。课程强调全面性、前沿性、针对性和实践性，在传统数据安全基础上重点突出了大数据时代安全治理的新理论、新技术、新方法，涉及数据脱敏、数据溯源、数据分类分级、个人信息保护等内容。

  

  

4、**信息安全保障人员认证-数据保护官培训**（Certified Information Security Assurance Worker - Data Protection Officer, 简称CISAW-DPO）

  

培训内容包括：国内数据安全法规标准、国外数据安全法律环境、数据安全管理与治理体系、数据安全防护技术发展趋势、数据安全产业现状、个人信息保护与重要数据出境。课程以国内外数据安全监管要求和个人信息保护监管要求为主体，重点提升参训人员对数据安全及其保障体系的认知程度，以及数据保护法律和实践方面的专业知识和履行职责的能力。

  

  

5、**信息安全保障人员认证-工业信息安全岗位能力培训**（Certified Information Security Assurance Worker - Competency Requirements of Industry Information Security Post, 简称CISAW-ISP）

  

培训内容包括：工业信息安全概述、工业信息安全现状和发展趋势、工业生产系统基础、工业信息安全威胁、工业信息安全技术、典型工业信息安全事件解析、工业信息安全实训。课程以工业控制系统和网络安全技术的融合为基础，专门设计了实训环节，基于典型工控安全设备提出了实训环境的指标要求，着力提升参训人员的实操能力。

  

  

**（三）从业基础能力认证  
**

从业基础能力认证定位于网络安全从业基础能力评价。认证对象为拟从事网络安全工作的人员。认证价值体现在为网络运营者招聘网络安全人员提供参考和依据，为拟从事网络安全工作人员的能力提供评价和背书。

  

  

6、**信息安全保障人员认证-从业基础能力（预备级）培训**（Certified Information Security Assurance Worker - Competency Requirements of Beginners - Pre, 简称CISAW-BP）

  

培训内容包括：网络安全职业路线、网络安全职业道德与法律要求、网络安全技术和产业概论、网络安全管理概论。课程目标是在基础理论之外，为参训人员提供必备的法律、技术和产业常识，提升其职业规划能力和从业能力。

  

  

7、**信息安全保障人员认证-从业基础能力（专业级）培训**（Certified Information Security Assurance Worker - Competency Requirements of Beginners - Major, 简称CISAW-BM）

  

培训分为软件安全开发、网络安全运营、网络安全服务和数据安全四个方向，参训人员可选择一个或多个方向参加培训。

软件安全开发课程内容包括：软件安全开发原则、软件攻击案例、软件安全开发生命周期、软件安全编码、软件安全测试。

网络安全运营课程内容包括：信息系统安全威胁与脆弱性、信息系统安全要素、信息安全策略、风险管理框架、信息安全事件应急处置、信息系统安全工程、网络攻防技术原理、日常运维操作、主流网络安全产品和服务、安全运维实操。

网络安全服务课程内容包括：风险评估流程与方法、主流安全防护技术、网络安全审计方法、网络安全检测技术、网络安全应急响应。

数据安全课程内容包括：数据安全法规标准、数据生命周期、数据安全保障体系、数据挖掘与利用、数据脱敏技术、数据溯源技术、数据分类分级、主流数据库安全配置、主流大数据平台安全防护。
