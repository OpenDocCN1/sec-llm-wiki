# 海泰方圆：安全可靠浏览器助力关键信息基础设施保护

       2019年4月19日，为纪念习近平总书记在全国网信工作座谈会上发表重要讲话三周年，[第二届关键信息基础设施自主安全创新论坛在北京隆重召开](http://mp.weixin.qq.com/s?__biz=MzU0NzI2NDU1Ng==&mid=2247486757&idx=1&sn=778233080e0497985528d2b06ae80b2c&chksm=fb504c66cc27c57058e869cdd15236c4ec4c5be66eaca86b93fb057f9127a0aa0aa467fa00ae&scene=21#wechat_redirect)。北京海泰方圆科技股份有限公司柳晶副总经理演讲的题目是《安全可靠浏览器助力关键信息基础设施保护》。

  

  

![](../Images/798342e22f621b9188d7779b20dbde88.png)

      她介绍了海泰方圆针对国产信息化支撑中存在的网络应用和安全交互等问题，自主设计研发的企业级安全浏览器及使用情况。
