**作品概述**

随着网络技术的不断发展，网络上的攻击事件越来越频繁，造成了越来越大的损失。然而，大部分的攻击活动都是有源可寻的，他们来自于论坛以及相关的聊天室。本项目正是基于黑客社区以及论坛的用户画像构建。通过抓取知名黑客社区的数据，然后使用自然语言处理以及机器学习等技术，构建论坛中所有用户的画像。基于此画像还可以实现威胁事件的预测以及取证溯源。

**作品设计中出现的问题及解决方法**

1、项目最初计划对人体耳部的静脉分布检测，但实践发现耳部血管过细，对红外吸收太弱，拍摄到的图片偏白。进而对掌部的血管进行拍摄，掌部的皮肤组织太厚，红外光难以穿透。最终选择了皮肤厚度适当且血管粗细适当的指部进行拍摄，实验证明指部血管图像清晰可见，适合进行后续识别。  

2、作品在嵌入式平台开发遇到的问题：首先进行驱动程序的开发。在阅读智龙开发板的 linux 源码后，发现源码中包含了 mt9v032 进近红外摄像头模块的设备驱动，但市面上 mt9v032 模块已经停售，较常见的是本作品选用的 my9v034 模块，二者比较接近，但在寄存器的配置上有所不同，所以不能直接使用精英百强组织方所提供源码中的驱动程序。

经过查阅 github 上最新版本的 Linux 内核源码，发现后续更新已经完善了对 mt9v034 模块的支持，之后又在 github 上查阅到了龙芯开发者刘世伟老师的代码仓库，发现了升级到 3.18.130 版本的龙芯 1c 处理器 Linux 内核源码，这个版本的摄像头驱动已经能够支持 mt9v034 模块。因此克隆了刘老师的项目，参考精英百强活动组织方提供源码中的 platform 平台文件，通过 menuconfig 裁剪内核，打开了对本作品使用的摄像头模块和无线网卡 rtl8192cus 的支持，使用 busybox 制作根文件系统，并使用刘老师的 pmon 项目更新了智龙开发板的引导程序，将内核和文件系统镜像烧写进了开发板上的 flash 芯片。

上述开发过程均在 ubuntu 18.04LTS 环境中进行，使用过精英百强组织方提供的 4.3 版本和刘老师的 4.9 版本的编译器，在编译过程中都会报错，网络上出现这种情况的案例很少，关于龙芯的教程也大多不够详细，导致开发效率很低。在看到精英百强评委专家的初评意见后，决定先使用社区资源丰富的树莓派进行开发，实现基本的功能，来验证系统的可行性，后续完善后再向龙芯平台进行移植，构建功能完善、容错性好的系统。

3、图像的采样方法还不是很完善，采样的角度和采样的位置都需要固定，不然很容易出现噪声导致图像处理的精度达不到想要的结果。

图像的预处理还不是很完善，在现有的条件下还不能很好的提取出血管的分布情况，导致最后得到的采集样本不是很可靠。

运算能力的限制导致我们处理的样本有限，另外采集的样本多样性差，对大范围的图像识别的能力不是很好。

卷积神经网络的建模和参数存在一定的问题，需要经过后续的测试再进行调整，因为对不同的样本容量所采用的参数是不尽相同的，如果一些参数稍微有一点偏差，如学习率就会造成模型得出的结果不佳。

**现场专家点评及改进思路**

专家认可项目可行性，但目前还没有在智龙开发板上实现，需要研究如何将程序移植到智龙开发平台。

在图像加密方面，需要研究保密性更高的算法取代现在使用的 Base64 算法。

另外，要解决云端安全问题，辨识伪装服务器等问题。

接下来团队成员将在尖锋导师指导下，补齐短板知识，进一步提高作品质量。
