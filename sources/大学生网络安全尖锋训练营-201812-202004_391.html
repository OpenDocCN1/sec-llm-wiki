● 精英百强团队展示

作品名称：基于中标麒麟安全操作系统的安全路由器的研发

成员：高文宏、申肖阳、李博、王鹏飞

指导老师：王晓君

学校：河北科技大学

01

作品概述

作品分为一级路由器和二级路由器，一级路由器使用国产中标麒麟操作系统和 QUAGGA 开源路由软件搭建路由器的基本软件平台，负责各个子网之间的通信和安全防护；二级路由器基于国产嵌入式平台搭建，通过 hostapd 将无线网卡配置为 AP 模式，进行 WiFi 热点覆盖。

作品设计中出现的问题及解决方法

2

因为作品采用一级和二级路由器，为了保证作品设计及开发进度，一开始团队做了明确分工，各司其职。

初次使用国产系统和嵌入式硬件平台，我们遇到了各种问题：

首先，需要在一级路由器安装中标麒麟操作系统和搭建嵌入式开发平台。通过精英百强活动主办方的支持，我们获得了中标麒麟 Linux 的 ISO 镜像，用软碟通直接写入镜像文件之后，直接从 U 盘启动来安装，先是找不到 U 盘，测试了电脑所有 USB 口都失败，最后换了 U 盘重新写入镜像文件，再次从 U 盘启动，终于进入了安装界面，但是进入安装过程后不一会儿，就出现了莫名其妙的提示符，说是安装 ERROR ，网上搜索解决方法，大多数人说是 ISO 镜像写入工具软件的问题，于是先后换了软碟通、universal usb installer、rufus、win32disk 四款写入软件，一个一个试验，几乎折腾了一天时间，终于将中标麒麟 Linux 操作系统装上。

对于二级路由器的研发，我们开始使用的开发板是龙芯 1C 嵌入式平台，经过对软路由的分析，我们把研究内容分为以下几个部分：

第一步，龙芯 1C 嵌入式平台有一个以太网接口，开启 AP 路由器需要再拓展一块无线网卡，我们选择使用 RTL8188USB 无线网卡。这款网卡资源丰富稳定性好，容易在龙芯 1C 嵌入式平台下移植驱动。

第二步，在龙芯 1C 上移植 hostapd 工具，hostapd 可以开启无线网卡的 AP 模式，但是移植的过程并不顺利。要移植 hostapd，先要移植 libnl 和 openssl 开源库，并且这三个软件包版本需要匹配。libnl 交叉编译起来没有太多问题，但是 openssl 源码在交叉编译的时候问题很多，如 cms.pod around line 457:Expected text after =item, not a number 经查阅资料，解决方法是在 ROOT 权限下执行 rm –f /usr/bin/pod2man 经过逐步摸索，最终编译出需要的工具。

第三步，配置系统和工具软件。启动hostapd 时出现 nl80211 初始化失败错误。分析原因可能是内核编译时缺少一些选项，重新编译后还是没能解决。最终没能移植到龙芯 1C 嵌入式开发平台上。我们依照这个流程，将这个方案移植到了另外一款国产平台上，实现了二级路由器 WiFi 热点覆盖功能。

接下来是一级路由器的安装 QUAGGA 路由软件的阶，在中标麒麟 Linux 下，我们尝试了 yum、apt、rpm 安装方式。yum 安装 QUAGGA 提示找不到源，我们尝试着用从网上找到的源更新本地的 yum 源文件，试了一个上午，以失败告终。使用 apt-get，发现中标默认不支持。最后尝试 rpm ，我们满怀信心从 QUAGGA 官网下载了一个 rpm 安装包并开始安装，输入 rpm 安装命令后，提示依赖文件缺失，一共 5 个，接着我们一个一个从网上下载依赖文件，提示的依赖文件一个一个减少，直到第五个依赖文件！可是，5个文件备齐之后，它提示依赖 10 个文件，我们不厌其烦的安装第一个，结果从第一个开始就连环依赖， rpm 包安装方式失败！只剩最后一根救命稻草了---源码安装，于是我们又从网上下载了 QUAGGA 的源文件，解压后，./configure ;make;make install 一系列命令之后，没有出现任何错误。

在两级路由器调试连通阶段，我们需要 ping 通两个跨网段的 IP 地址，成功 ping 通才能说明我们设计的路由器功能实现了，结果鹏飞的机子总是 ping 不通我的，我的却可以 ping 通他的，结果发现是他的防火墙没有关闭，关闭防火墙之后终于两台机子可以相互 ping 通了。

在设计作品并实现的过程中，我们感受到了团队的力量，每个人贡献一点自己的力量，结果会产生 1+1+1+1>4 的化学反应。

现场专家点评及改进思路

3

现场专家肯定了我们的作品思路，但是作品安全性体现不足，后续需要完善和提高。

对于作品安全性的问题，经过评委老师提点，我们会研究 ISO 7498-2，并对中标麒麟的安全机制进行深入研究，在作品中添加相关安全措施。
