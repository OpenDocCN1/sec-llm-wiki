  基于智龙开发板搭建的 web 运行环境

成员：徐业、刘胜、高华东、陈飞宇

指导老师：何欣枫

学校：河北大学

01



作品概述

针对龙芯开发板现有的资源进行开发利用，选取了安全快速的 web 服务端程序 lighttpd、轻量级的数据库 sqlite、脚本语言 PHP，为智龙开发板提供一套实用可靠的 web 运行环境。

基于龙芯的开源软件定制，实现环境的国产安全自主可控。传统的物联网设备大多都是通过向第三方服务器发送信息，存在不可靠性，如果每个用户拥有自己的龙芯微型 web 服务器，就可以规避这种不可靠性。随着人们安全意识的提高，规避这种不可靠性是很必要的。

微型服务器环境通过接口接收到数据，避免对第三方服务器的依赖，具有很强的通用性，可用于生活中的各个方面。

03



作品设计中出现的问题及解决方法

团队在作品设计过程中遇到的问题也是我们创建这个作品的原因。

最开始我们计划基于龙芯开发板开发一个 web 应用，结果发现并没有一套基于龙芯的完整 web 环境，所以我们给龙芯定制了一套较为完整的 web 环境。既然要定制完整的 web 服务器，必定会遇到取材的问题，我们最初想选用 Apache 作为我们的 web 服务器，但是最后编译完软件后，发现其体积过大，无法为开发板存储空间所容纳，走过一次弯路后，我们将取材定位到针对嵌入式领域各方面性能较好的软件上。最终选定了lighttpd、php、sqlite 三个组件。

接下来遇到的是编译问题，这个过程是踩过坑最多的地方，因为不知道需要什么配置参数才能达到预期的编译结果，要么编译出错，要么编译好后不可用，要么功能不完备，还需要注意移植后的配置，经过 n 次重复测试后，最终形成了我们今天的作品。

04



现场专家点评及改进思路

专家对我们的作品给予了肯定，但也一针见血地指出了作品的几个痛点：web 服务器应用领域是什么？相比传统的服务器有什么优势？产品化后，web 服务器的性能能提升多少？

关于作品的应用领域以及相比传统服务器的优势，我们在设计作品时从技术方面进行了考虑，这也是作品的前景所在：首先，采用的龙芯开发板是国产的，我们为其定制的 web 环境是自主可控的。其次，我们的微型服务器通过接口接收数据，具有很强的通用性，可以避免对第三方服务器的依赖，可用于生活中的各个方面。

关于升级硬件配置后的作品性能的提升，之前并没有考虑，后期在尖锋导师的指导下会重点考虑这个问题。
