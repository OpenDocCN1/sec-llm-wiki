一、备份和还原的基本概念 

备份是指制作数据库结构、对象和数据的复制，以便在数据库遭到破坏时能够修复数据库，还原则是指将数据库备份加载到服务器中的过程。 

备份和还原的工作主要是由数据库管理员来完成的。如果在备份或还原过程中发生中断，则可以重新从中断点开始执行备份或还原。这在备份或还原一个大型数据库时极有价值。在下述情况下，需要使用数据库的备份和还原： 

（1）存储介质损坏时，例如存放数据库数据的硬盘损坏。 

（2）用户操作错误时，例如非恶意地或恶意地修改或删除数据。 

（3）整个服务器崩溃时，例如操作系统被破坏，造成计算机无法启动。 

（4）需要在不同的服务器之间移动数据库时，把一个服务器上的某个数据库备份下来，然后还原到另一个服务器中 去。 

SQL Server 2008 支持在线备份，所以通常情况下可以一边进行备份，一边进行其他操作。但是，在备份过程中 不允许执行以下操作： 

（1）创建或删除数据库文件。

（2）创建索引。 

（3）执行非日志操作。 

（4）自动或手工缩小数据库或数据库文件大小。 

二、数据备份的类型 

1．完整数据库备份 

数据库完整备份，包括所有的数据以及数据库对象。实际上备份数据库的过程就是首先将事务日志写到磁盘上， 然后根据事务创建相同的数据库和数据库对象以及复制数据的过程。由于是对数据库的完全备份，所以这种备份类型不仅 速度较慢，而且将占用大量磁盘空间。 

2．差异数据库备份 

差异数据库备份是指将最近一次数据库备份以来发生的数据变化备份起来，因此，差异备份实际上是一种增量数据库备份。 

3．事务日志备份 

事务日志备份是指对数据库发生的事务进行备份，包括从上次进行事务日志备份、差异备份和数据库完全备份之后，所有已经完成的事务。 

常用的备份方案：在实际中为了最大限度地减少数据库还原时间以及降低数据损失量，一般经常综合使用数据库备份、事务日志备份和差异备份，从而采用下面的备份方案：

（1）有规律地进行数据库完整备份，比如每晚进行备份。

（2）较小的时间间隔进行差异备份，比如三个小时或四个小时。 

（3）在相邻的两次差异备份之间进行事务日志备份，可以每 10 分钟或 30 分钟一次。 

还原方案：进行还原时，可以先还原最近一次的数据库完整备份， 接着进行差异备份的还原，最后进行事务日志备份的还原。 

4．文件和文件组备份 

文件或文件组备份是指对数据库文件或数据库文件组进行备份，它不像完整的数据库备份那样同时也进行事务日志备份，使用该备份方法可提高数据库还原的速度，因为它仅对遭到破坏的文件或文件组进行还原。 

三、还原模式 

1．简单还原 

简单还原就是指在进行数据库还原时仅使用了完整数据库备份或差异备份，而不涉及事务日志备份。简单还原模式可使数据库还原到上一次备份的状态。选择简单还原模式时，常使用的备份策略是：首先进行数据库完整备份，然后进行差异备份。 

2．完全还原

完全数据库还原模式是指，通过使用数据库完整备份和事务日志备份，将数据库还原到发生失败的时刻，因此几乎不造成任何数据丢失。这成为应对因存储介质损坏而丢失数据的最佳方法。 

选择完全还原模式时，常使用的备份策略是：首先进行完整数据库备份，然后进行差异数据库备份，最后进行事务日志备份。如果准备让数据库还原到失败点，则必须对数据库失败前正处于运行状态的事务进行备份。 

3．批日志还原 

批日志还原在性能上要优于简单还原和完全还原模式。它能尽最大努力减少批操作所需要的存储空间。 

选择批日志还原模式所采用的备份策略与完全还原所采用的备份策略基本相同。 

四、备份与还原操作 

（一）数据库的备份 

方法：在“对象资源管理器”窗格中→右击已创建的数据库名—任务—备份。 

说明：

（1）“仅复制备份”是独立于常规 SQL Server 备份序列的 SQL Server 备份。通常，进行备份会更改数据库并影响其后备份的还原方式。但是，有时在不影响数据库全部备份和还原过程的情况下，为特殊目的而进行备份还是有用的。为此，SQL Server 2008 引入了仅复制备份。

（2）可以接受“名称”文本框中建议的默认备份集名称，也可以为备份集输入其他名称。

（3）指定备份集何时过期以及何时可以覆盖备份集而不用显式跳过过期数据验证：若要使备份集在特定天数后过期，单击“之后”（默认选项），并输入备份集从创建到过期所需的天数，此值范围为 0 到 99999 天，0 天表示备份集将永不过期。若要使备份集在特定日期过期，单击“在”，并输入备份集的过期日期。 

例：创建 XSGL 数据库备份 XSGL-备份。 

（二）数据库的还原 

方法：在“对象资源管理器”窗格中→右击“数据库”→ “还原数据库”。 

说明：一定要勾选“覆盖现有数据库”。

五、备份与还原计划 

前面介绍的是手工备份和还原数据库，如果要让 SQL Server 2008 系统自动定时备份数据库，需要使用 SQL Server 2008 系统提供的维护计划功能。 

方法：在“对象资源管理器”窗格中→“管理”→右击“维护计划”→“维护计划向导”。例：创建 XSGL 数据库维护计划。 

说明：维护计划运行失败，需要重新注册 dts.dll 文件。

以 管理员身份运行 cmd，输入以下内容：C:\\Windows\\syswow64\\regsvr32 "C:\\Program Files (x86) \\Microsoft SQL Server\\100\\DTS\\Binn\\dts.dll"（64 位机器）。
