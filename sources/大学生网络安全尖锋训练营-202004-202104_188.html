服务器的安全性

服务器的安全性是通过设置系统登录账户的权限进行管理的。用户在连接到 SQL Server 2008 时与登录账户相关联。在 SQL Server 2008 中有两类登录账户：登录服务器的登录账号和使用数据库的用户账号。 

登录账号是指能登录到 SQL Server 2008 的账号，它属于服务器的层面，本身并不能让用户访问服务器中的数据库，而登录者要求使用服务器中的数据库时，必须要有用户账号才能存取数据库。 

就如同公司门口先刷卡进入（登录服务器），然后再拿钥匙打开自己的办公室（进入数据库）一样。用户名要在特定的数据库内创建并关联一个登录名（当一个用户创建时，必须关联一个登录名）。 

用户定义的信息存放在服务器的每个数据库的 sysusers 表中，用户设有密码同其相关联。SQL Server 2008 通过授权给用户指定可以访问的数据库对象的权限。 

SQL Server 2008 中有一个超级登录账号 sa。这个账号具有操作 SQL Server 服务器的一切权限。也正因为如此，保证这个账号的安全就是一个十分重要的问题。要保护SQL Server 2008 服务器的安全，首要的问题就是要保证 sa 账号 的安全。 

在 SQL Server 2008 系统安装以后，系统自动创建sa账号，但其密码为空。因此，用户在安装 SQL Server 2008 系统以后，首先要做的工作就是为此账号设置一个密码。需要说明的是，有相当一部分系统管理员为了省事，不为 sa 账号设置密码。这样做，无疑为 SQL Server 2008 数据库系统留下十分危险的隐患。 

一、查看登录账号 

在安装 SQL Server 2008 以后，系统默认创建几个登录账号。 

方法：在“对象资源管理器”窗格中→展开“安全性”→ 展开“登录名”。 

说明：saSQL Server 2008 系统管理员登录账号，该账号拥有最高的管理权限，可以执行服务器范围内的所有操作。通常 SQL Server 2008 管理员也是 Windows 的管理员。 

二、创建一个登录账号 

方法：在“对象资源管理器”窗格中→展开“安全性”→ 右击“登录名”→“新建登录名”。 

三、更改、删除登录账号属性 

方法：在“对象资源管理器”窗格中→展开“安全性”→ 右击“登录名”→“属性”。 

四、禁止登录账号 

如果要暂时禁止一个使用 SQL Server 身份验证的登录账号连接到SQL Server 2008，只需要修改该账户的登录密码就行了。如果要暂时禁止一个使用 Windows 身份验证的登录账户连接到SQL Server，则应当使用SQL Server Management Studio 或执行 T-SQL 语句来实现。 

方法：在“对象资源管理器”窗格中→展开“安全性”→ 右击“登录名”→“属性”→“状态”→“登录”→“禁 用”。 

五、删除登录账号 

永久禁止使用一个登录账号连接到 SQL Server，则删除登录账号。 

方法：在“对象资源管理器”窗格中→展开“安全性”→ 右击“登录名”→“删除”。
