# 【精英百强】开发资源介绍04-龙芯1C智龙开发板

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODkwMDMxNA==&mid=2247492194&idx=1&sn=99e8c36d1d5ce86e319a9f8c91437167&chksm=fad20057cda589416dcd64b15ee1820b22264b84d3d8af8be292d27089ea828f01f98f70f457&scene=126&sessionid=1681655872#rd](http://mp.weixin.qq.com/s?__biz=MzUzODkwMDMxNA==&mid=2247492194&idx=1&sn=99e8c36d1d5ce86e319a9f8c91437167&chksm=fad20057cda589416dcd64b15ee1820b22264b84d3d8af8be292d27089ea828f01f98f70f457&scene=126&sessionid=1681655872#rd)

龙芯1C智龙开发板  
  

**参赛团队可以免费申请以下资源和相关技术支持。**

**资源简介：**

      采用国产龙芯1C处理器，集成龙芯1C SOC ，网口、USB口、电源，SD卡插槽和RTC时钟等主要部件，可以运行嵌入式 Linux、RT-Thread等操作系统。

  

  

**开发指南：**

1）基于智龙开发板的数据采集和加密通信系统，组委会可提供基于VPN的网络安全传输参考设计；

2）基于智龙开发板的智能家居控制和安全管理平台，对有线或无线设备，如传感器、开关控制器、人机交互终端等组网，实现在智能家居、智能农业、智能交通、智能电力等方面的应用演示；

3）数据采集控制类，通过控制电机或舵机实现各种应用，如智能车、机器人、工业控制终端等，参考应用如无人智能车控制、人机交互控制（组委会可提供基于智龙主板的触控屏GUI基本参考设计）、自动数据采集控制和显示（组委会可提供基于智龙主板的点阵屏基本参考设计）。
