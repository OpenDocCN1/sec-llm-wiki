![](../Images/b9be7b3116b3439a842db68adcffcfdb.png)       SQL Server 提供了内置函数帮助用户执行各种操作。内置函数不能修改，可以在 T-SQL 语句中使用。内置函数包括：聚合函数、配置函数、加密函数、游标函数、时间和日期函数、数学函数、元数据函数、排名函数、行集函数、安全函数、字符串函数、系统函数、系统统计函数、文本和图像函数等。06其他字符串处理函数  

（1）求字符串中字符个数函数 LEN 

格式：LEN(字符串表达式) 

功能：返回给定字符串表达式结果中的字符个数，其中不包含尾随空格。 

说明：参数是要计算的字符串表达式。返回值即字符的个数，为 int 数据类型。

（2）替换函数 REPLACE 

格式：REPLACE（字符表达式 1, 字符表达式 2, 字符表达式 3） 

功能：用“字符表达式 3”替换“字符表达式 1”中出现的 11 所有“字符表达式 2”。

（3）重复字符函数 REPLICATE 

格式：REPLICATE（字符表达式,数值表达式） 

功能：以指定的次数重复字符表达式。 

（4）逆序排列函数 REVERSE 

格式：REVERSE（字符表达式） 

功能：将字符表达式逆序排列。 

（5）返回空格函数 SPACE 

格式：SPACE (整型表达式) 

功能：返回由重复的空格组成的字符串。 

说明：（1）参数是表示空格个数的正整数。（2）如果为负， 则返回空字符串。（3）返回值是空格字符串，为 char 数据类型。 

（6）数字转换字符函数 STR 

格式：STR (表达式 \[ , 总长度 \[ , 小数位数\] \] ) 

功能：将数字数据转换成字符数据。 

说明：（1）参数表达式是带小数点的近似数字(float)数据类型的表达式。（2）总长度包括小数点、符号、数字或空 12 格，默认值为 10。（3）小数位数是小数点右边的位数。（4） 返回值是转换为字符的数字，为 char 数据类型。 

07系统函数  

系统函数用于获得有关服务器、用户、数据库状态等系统信息。

1．返回最后执行的 T-SQL 语句的错误代码函数@@ERROR 说明：T-SQL 语句执行时，如果语句执行成功，则@@ERROR 被 SQL Server 设置为 0。若出现一个错误，@@ERROR 被设置为错误信息的代码，并且@@ERROR 在下一条语句执行后 将被清除并且重置。由于随着不同 T-SQL 语句的执行， @@ERROR 的值是变化的，所以应在语句验证后立即检查它， 或将其保存到一个局部变量中以备事后查看。一般情况下 常常利用该函数来判断某条语句执行的成功与否。

2．数据类型转换函数 CAST 和 CONVERT 函数

功能：将某种数据类型的表达式显式转换为另一种数据类型的函数。CAST 和 CONVERT 提供 相似的功能，但 CONVERT 功能更强一些。 

（1）CAST 函数 

格式：CAST ( 表达式 AS 数据类型)  

说明：（1）参数“表达式”是任何有效的 SQL Server 表达 式，是要转换数据类型的表达式。（2）“数据类型”是系统所提供的数据类型，是表达式要转换的数据类型。它不能使用用户定义的数据类型。 

（2）CONVERT 函数 

格式：CONVERT (\[数据类型(长度)\], 表达式\[, 样式\]) 

说明：（1）参数“数据类型”和“表达式”与 CAST 函数中 的相同。（2）可选参数“长度”用于为 nchar、nvarchar、 char、varchar、binary 或 varbinary 类型的数据指定长 度。（3）“样式”的取值较复杂，分两种情况。①datetime 或 smalldatetime 数据类型与字符数据类型互相转换时，为日期格式样式，取值及字符串的输入输出格式参考表 8-2。
