AntSword安装与使用  
  
  
  
  
  
  

## **前言：其实安装非常简单。**

1、下载加载器，然后打开。  
2、如果有源码，就选择源码所在文件夹作为工作目录。  
3、如果没有，就选择一个空文件夹就行（加载器会自动下载）。

  

* * *

  

## **一、下载 AntSword（中国蚁剑）**

中国蚁剑之前的旧版本是下载之后解压即可使用的。

但是在 v2.0 版本以后引入了加载器的概念，使用加载器加载源码的方式启动程序。  
如果升级版本只需更换源码即可，比较方便。

注：AntSword 官方文档：https://doc.u0u.us/zh-hans/index.html

### **1.1、下载加载器和源码**

你可以去官网下载加载器和源码，但是现在 Github 的速度实在不敢恭维。

### **1.2、校验文件 Hash 值（可选）**

这一步是为了安全，你可以使用校验工具计算你下载的文件 Hash 值与下载源提供的 Hash 值是否相同。如果不相同应立即删除该文件（理论上）。

注：安装 7z 的时候会带一个校验工具，可以校验文件的 sha1、sha256 等 Hash 值。其他工具亦可。

## **二、无源码安装方法**

如果你只下载了加载器，而没有下载源码，则打开加载器主程序，选择一个空白文件夹作为工作目录即可。

1.解压 AntSword-Loader-v4.0.3-win32-x64.zip，然后双击其中的 AntSword.exe 即可。

![](../Images/45fcde5edf7f5b218c02022562dbb4dd.png) 

2\. 然后点击初始化，会弹出一个对话框让你选择目录，选择一个空白目录即可（以后数据就会存放在这个目录）。

 ![](../Images/bb9dc79ef4ed2fb287dbf554dab4548d.png)

3\. 等待源码下载完成，重新打开加载器即可。  
注：左上角（如图）可以查看主页，帮助文档等信息。

 ![](../Images/68f465873dc78401875645fd29ffa1de.png)

## **三、有源码安装方法**

有源码的安装方法和无源码相同，只是在选择工作目录的时候选择有源码的文件夹即可。  
注：要选择到源码的第一个父级文件夹，如果源码放在多级子文件内，会不识别。

1.选择源码后会出现如下图：

![](../Images/148b583547e072ae5a8d24b19454f44c.png) ![](../Images/5035fa59a2309663ace5259ce9d1d401.png) 

2. 再次打开加载器即可，主界面如下图。

![](../Images/eeb1c7b4e68f020755322ac0a1df8886.png) 

3.设置语言（可选），点击左上角 AntSword 、语言设置，即可进入到语言设置界面。

![](../Images/ff48c634162f7c556fb5a51eba7badc6.png) 

## **四、如何使用**

### **3.1、添加 shell**

1. 在工作区右键

![](../Images/38e1b56f14f119b13aa6bd1ca6163d62.png) 

2. 填入地址和密码，点击添加即可

*注：这里的地址是你已经获取到 shell 的地址，密码是你 shell 的密码。*  
![](../Images/7b6313a789a837274bbde83006080cc3.png)3. 添加成功如下图所示

![](../Images/7e4c7cab6b3ca10eee6875c036e36dab.png) 

### **3.2、如果操作数据**

1. 对目标进行操作（在添加的数据上右键，可以看到操作选项）

![](../Images/309a53474d0d8733cacc8e8e1c89dda5.png) 

2. 进行文件管理获取数据  
在文件或文件夹上右键，可以在弹出的菜单上看到可用的选项。  
包括上传下载编辑等等几乎"无所不能"。  
更多功能等你去探索~~

![](../Images/64b66678cb42b466b441acddd5dba1fc.png)
