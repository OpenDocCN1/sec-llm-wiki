![](../Images/42a37e2cbd271810ff1306618e2d0860.png)       SQL Server 提供了内置函数帮助用户执行各种操作。内置函数不能修改，可以在 T-SQL 语句中使用。内置函数包括：聚合函数、配置函数、加密函数、游标函数、时间和日期函数、数学函数、元数据函数、排名函数、行集函数、安全函数、字符串函数、系统函数、系统统计函数、文本和图像函数等。01聚合函数  

     聚合函数用于对多个参数进行不同功能的计算，并返回单个值。所有聚合函数都具有确定性，任何时候用一组给定的输入值调用它们时，都返回相同的值。聚合函数可以在 SELECT 语句的选择列表、GROUP BY 子句、HAVING 子句、COMPUTE BY 子句中作为表达式使用。

02时间、日期函数  

1．返回日期时间的指定部分函数

（1）DATENAME 函数 

格式：DATENAME(日期部分,日期表达式) 

功能：以字符串形式返回给定的日期时间数据的指定日期部分。

![](../Images/c5d4e0b628ffba566905faecf1090a4f.png)

（2）DATEPART 函数 

格式：DATEPART (日期部分, 日期表达式) 

功能：以整数形式返回给定日期型数据的指定日期部分。 

说明：参数“日期部分”是要返回的日期部分，它可取的关键字日期表达式”是给定的日期时间数据。

2．返回当前的系统时间函数 

格式：GETDATE()

功能：返回当前的系统时间。 

3．DAY(日期表达式)：返回指定日期 DAY 部分的数值。 

4．MONTH(日期表达式)：返回指定日期 MONTH 部分的数值。 

5．YEAR(日期表达式)：返回指定日期 YEAR 部分的数值。

03数学函数  

     SQL Server 提供的数学函数能够在数值型表达式上进行数学运算，然后将结果或结果集返回给用户。能在 SQL Server 的数学函数中使用的数据类型包括：integer、float、 real、money、smallmoney、smallint 和 tinyint。

    数学函数把传递给它的数字默认解释为 decimal 数据类型，可用 CAST 或 CONVERT 函数将传递数字转换为其他的数据类型。在 SQL Server 中，数学运算的顺序与普通数学运算一致：(1) 执行括号里的运算；(2) 执行乘方与开方运算；(3) 按先乘除后加减的规则进行运算；(4) 执行逻辑运算。 

     常用的 SQL Server 数学函数： 

1.返回整数值函数 

CEILING 与 FLOOR 函数都用于返回数值表达式的整数值,但返回的值不同。 

（1）CEILING 函数 

格式：CEILING(数值表达式) 

功能：返回最小的大于或等于给定数值型表达式的整数值。 

说明：返回值的数据类型与参数的数据类型相同。

（2）FLOOR 函数 

格式：FLOOR(数值表达式) 

功能：返回最大的小于或等于给定数值型表达式的整数值。 

说明：返回值的数据类型与参数的数据类型相同。 

2．乘方运算函数 

格式：POWER(数值表达式 1,数值表达式 2) 

功能：返回数值表达式 1 的数值表达式 2 次方。 

说明：乘方运算函数返回值的数据类型与第一个参数数据类型相同。 

3．自然指数函数 

格式：EXP(float 表达式) 

功能：求指定的 float 表达式的自然指数值。 

说明：返回 float 型的值。 

4．平方根函数 

格式：SQRT(float 表达式) 

功能：求指定的 float 表达式的平方根。 

说明：返回 float 型的值。 

5．产生随机数函数 

格式：RAND(整型表达式) 

功能：用于返回一个位于 0 和 1 之间的随机数。 

说明：整型表达式在这里起着产生随机数的起始值的作用。

6．四舍五入函数 

格式：ROUND(数值表达式，整数) 

功能：该函数将数值表达式四舍五入成整数指定精度的形式。 

说明：参数整数可以是正数或负数。正数表示要进行运算的位置在小数点后，反之要运算的位置在小数点前。

04元数据函数  

    元数据函数用于返回有关数据库和数据库对象的信息。 

1．返回列的定义长度函数 COL\_LENGTH 函数 

格式：COL\_LENGTH ( '表名' , '列名' ) 

功能 ：返回指定表的指定列的定义长度(以字节为单位)。 

说明：（1）参数“表名”为要确定长度的列所在的表的名称，它是一个 nvarchar 类型的表达式。

（2）“字段名”为要确定长度的字段名称，它是一个 nvarchar 类型的表达式。返回值是字段的长度，单位是字节，为 int 数据类型。  

2．返回数据库对象标识号函数 OBJECT\_ID 函数 

格式：OBJECT\_ID ( '对象名' ) 

功能：返回指定数据库对象的标识号。 

3．返回列的名称函数 COL\_NAME 函数

格式：COL\_NAME (表标识号,列标识号) 

功能：返回指定列的名称。 

说明：（1）参数“表标识号”属于 int 类型。“列标识号” 属于 int 类型。表中第一个字段的标识号为 1，依此类推。

4\. 返回数据库标识 DB\_ID()函数 

格式：DB\_ID ( \[ '数据库名' \] ) 

功能：返回指定数据库的标识号。 

说明：（1）参数“数据库名”是用来返回相应数据库 ID 的数据库名，是 nvarchar 型。如果不填“数据库名”，则返回当前数据库 ID。

（2）master 数据库中的 sysdatabases 表保存着每个数据库的名称及信息，通过它来查询数据库 名称，再根据数据库名称来确定数据库 ID。 

5\. 返回数据库名函数 DB\_NAME()函数 

格式：DB\_NAME ( \[数据库标识号\] ) 

功能：返回指定数据库 ID 的数据库名称。 

说明：

（1）参数“数据库标识号”是应返回数据库的标识号(ID)，为 smallint 类型的数据。如果没有指定 ID，则返回当前数据库名。

（2）返回值即数据库的名称，为 nvarchar(128)数据类型。

05字符串函数  

    用于对字符串进行处理。 

1.字符串转换函数 

（1）ASCII 函数 

格式：ASCII (字符表达式 ) 

功能：返回所求字符串的 ASCII 值，为 int 数据类型。 

说明：参数是类型为 char 或 varchar 的表达式，其值是要转换成 ASCII 值的字符串。 

（2）CHAR 函数 

语法：CHAR (整数表达式) 

功能：将 ASCII 码值转换为字符。 

说明：（1）参数是介于 0 和 255 之间(即 ASCII 值的范围) 的整数表达式。（2）如果整数表达式不在此范围内，将返回NULL值。（3）返回值即ASCII值所对应的字符，为char(1) 数据类型。 

（3）UPPER 函数 

格式：UPPER ( 字符表达式 ) 

功能：将小写字符转换为大写字符。 

说明：（1）参数是由字符数据组成的表达式即是要转换的字符串，可以是常量、变量，也可以是字符数据的字段名。（2）返回值是转换后的字符串，为 varchar 数据类型。 

（4）LOWER 函数 

格式：LOWER (字符表达式) 

功能：将大写字符数据转换为小写字符数据后返回字符表达式。

2．删除空格函数 

（1）LTRIM 函数： 

格式：LTRIM (字符表达式 ) 

功能：删除起始空格后返回一个字符串。 

说明：（1）参数是字符或二进制数据表达式，可以是常量、变量或字段名。（2）返回值即删除空格后的字符串，为 varchar 类型。 

（2）RTRIM 函数 

语法：RTRIM ( character\_expression ) 

功能：截断所有尾部空格后返回一个字符串。 

说明：参数与 LTRIM 函数中的相同。

 3．字符串截取函数 

（1）LEFT 函数 

格式：LEFT(表达式 1 , 表达式 2)

功能：返回从字符串左边开始，指定个数的字符串。 

说明：（1）参数表达式 1 为字符型表达式，可以是常量、变量，也可以是字符数据的字段名。（2）表达式 2 为正整 数表达式，指定返回的字符个数。（3）返回值是返回的子 串，为 varchar 数据类型。 

（2）RIGHT 函数

格式：RIGHT (表达式 1 , 表达式 2 ) 

功能：返回字符串中从右边开始指定个数的字符。 

说明：与 LEFT 函数的参数相同。 

（3）SUBSTRING 函数 

格式：SUBSTRING (表达式 , start , length ) 

功能：返回字符串、binary、text 或 image 表达式的一部 分。 

说明：（1）参数表达式是字符串、二进制字符串、text、 image、字段名或包含字段名的表达式。（2）不要使用包含集合函数的表达式。（3）start 是一个整数，指定子串的开始位置。length 是一个整数，指定子串的长度(要返回的字符数)。

4\. 字符串比较函数 

（1）CHARINDEX 函数

格式：CHARINDEX(字符表达式 1, 字符表达式 2) 

功能：查找字符表达式 1 是否包含在字符表达式 2 中，找到返回值大于 0,找不到返回值为 0。

（2）PATINDEX 函数 

格式：PATINDEX(%字符表达式 1%, 字符表达式 2) 

功能：返回字符表达式 1 在字符表达式 2 中的位置。 

说明：字符表达式 1 需要使用通配符“%”。 

5\. 其他字符串处理函数 

（1）求字符串中字符个数函数 LEN 

格式：LEN(字符串表达式) 

功能：返回给定字符串表达式结果中的字符个数，其中不包含尾随空格。 

说明：参数是要计算的字符串表达式。  

（2）替换函数 REPLACE 

格式：REPLACE（字符表达式 1, 字符表达式 2, 字符表达式 3） 

功能：用“字符表达式 3”替换“字符表达式 1”中出现的 11 所有“字符表达式 2”。

（3）重复字符函数 REPLICATE 

格式：REPLICATE（字符表达式,数值表达式） 

功能：以指定的次数重复字符表达式。

（4）逆序排列函数 REVERSE 

格式：REVERSE（字符表达式） 

功能：将字符表达式逆序排列。 

（5）返回空格函数 SPACE 

格式：SPACE (整型表达式) 

功能：返回由重复的空格组成的字符串。 

说明：（1）参数是表示空格个数的正整数。（2）如果为负， 则返回空字符串。（3）返回值是空格字符串，为 char 数据 类型。

（6）数字转换字符函数 STR 

格式：STR (表达式 \[ , 总长度 \[ , 小数位数\] \] ) 

功能：将数字数据转换成字符数据。 

说明：（1）参数表达式是带小数点的近似数字(float)数据 类型的表达式。（2）总长度包括小数点、符号、数字或空 12 格，默认值为 10。（3）小数位数是小数
