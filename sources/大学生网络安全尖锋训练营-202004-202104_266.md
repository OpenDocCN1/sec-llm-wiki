**1.软件介绍**

"Everything"是Windows上文件名搜索引擎，其基于名称快速定位文件和文件夹。软件小巧轻便，高效易用，具有以下特点：

1.  *轻量安装文件；*
    
2.  *干净简洁的用户界面；*
    
3.  *快速文件索引；*
    
4.  *快速搜索；*
    
5.  *快速启动；*
    
6.  *最小资源使用；*
    
7.  *轻量数据库；*
    
8.  *实时更新。*
    
9.    
    

Everything像是搜索引擎和文件资源管理器的结合体，在搜索框中输入关键词可快速筛选符合条件的文件或文件夹，在结果列表等区域的操作（含快捷键）则与文件资源管理器类似，学习成本极低，但效率惊人。实际上，Everything也支持搜索文件的内容，但因未提前建立索引，速度很慢，不建议使用。

| 6 || 状态栏 || 显示Everything当前状态和当前搜索选项 |

**3.快捷键介绍**

高效能人士很重要的一个习惯就是大量使用快捷键。Everything快捷键分为全局快快捷键、搜索框快捷键和结果列表快捷键。因Everything的快捷键很多与Windows默认快捷键相同，例如Ctrl+c复制，Ctrl+v粘贴等，故下面将不再列举与Windows默认快捷键相同的列子。

 Everything全局快捷键列表

| 快捷键 || 动作 |
| --- | --- |
| Escape || 关闭当前窗口 |
| F3或Ctrl + F || 聚焦和高亮搜索框 |
| Tab || 切换于搜索框与结果列表 |
| Ctrl + Shift + 1 || 切换超大图标视图 |
| Ctrl + Shift + 6 || 切换详情视图。还能与其它数字组合，常用就大图标视图和详情视图 |
| Ctrl + 1 || 按名称排序 |
| Ctrl + 2 || 按路径排序。还能按照其它方式排序，常用就是按照名称排序 |
| Ctrl + P || 打开选项页面 |
| Ctrl + R || 切换正则表达式匹配 |
| Ctrl + S || 扫除当前搜索为Everything文件列表、csv或txt文件 |
| Ctrl + D || 添加当前搜索为书签。同浏览器 |
| Ctrl + Shift + B || 管理书签。同浏览器 |
| Ctrl + H || 显示全部搜索历史。同浏览器 |

**4.自定义设置**

尽管Everything的快捷键与浏览器和文件资源管理器的类似，已经非常符合多数用户的使用习惯。但适当自定义快捷键将更利于提高效率，具体方法如下

1.  依次单击【工具】，【选项】，【快捷键】即可进入自定义快捷键界面；（快捷键：Ctrl+p）
    
2.  在“显示包含的命令”后的输入框中输入“关键词”可筛选相关命令，如“运行次数“；
    
3.  选中需要自定义快捷键的命令；
    
4.  单击【添加】；
    
5.  选择“快捷键的适用范围”，一般选择默认的“全局”即可；
    
6.  单击在‘快捷键“下的输入框，并按下自定义的快捷键；（例子：Ctrl+9）
    
7.  单击两次【确认】。（例子：结果列表按照运行次数排序的快捷键设置完毕
    
8.    
    
9.    
    

![](../Images/6d2d4bbc7e1c33c74ce3d3eb5a699937.png)

新建窗口快捷键、显示窗口快捷键、切换窗口快捷键默认留空即可，因为这三个快捷键在Everything后台运行时才起作用。

为了方便随时随地打开Everything，建议将Everything图标固定在任务栏首位，使用全局快捷键Win+1打开Everything
