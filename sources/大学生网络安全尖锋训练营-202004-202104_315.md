# 【课程回顾】龙芯平台应用开发课程（四）：Web开发技术

      9月17日，龙芯中科技术有限公司·通用事业部的资深技术专家韩广老师，为大家讲授了龙芯平台应用开发系列课程（四）：Web开发技术。

![](../Images/47c7fe7758298c767db30441350a9c95.png)

       本课程包括七部分：龙芯支持的浏览器、浏览器编程语言和框架、浏览器的辅助工具、C/B/S:本地程序嵌入Web页面、Node.js:服务器端的JavaScript、项目实战、数据库。

![](../Images/5764442c0f0bf7c3759e5f24e5c20e57.png)

       首先，韩广老师介绍了在龙芯平台支持的两款浏览器、以及在龙芯平台上对浏览器编程语言和框架的支持，如常用的语言框架JavaScript和Ajax等。

![](../Images/29f409c1191cc33b83f6f6e1131dac22.png)

![](../Images/c1a0793bc1fe0a7b27e4f37c74aeb889.png)

      接着，韩广老师对浏览器的辅助工具——查看器、控制台、调试器、样式编辑器、内存、网络逐一进行了讲解。并介绍了在龙芯电脑上实现C/B/S的两种模式：CEF框架、Electron，以及一种面向Web服务器编程的脚本语言Node.js的特点、安装和案例。

![](../Images/0e0ede58807fd57c1ec1edda4923449a.png)

![](../Images/10c4416cc94a1cb62c8cb8c49fb99c3c.png)

![](../Images/2f4e865e2ce258723635580a973c5f90.png)

       课程的最后向大家展示了浏览器通用替代方案的测试结果，同时对关系型数据库MySQL、非关系型数据库MongoDB和数据库的集群方案进行了讲解。
