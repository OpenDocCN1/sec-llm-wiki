# 从网络安全企业用人需求看网络安全人才培养

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODkwMDMxNA==&mid=2247490209&idx=1&sn=56699d6c71889d06012f6ed7e9ddc43b&chksm=fad1f894cda671824911b9000927fad5f82813fe9f58b090e55f9fa556bcb4fe601010658a5a&scene=126&sessionid=1681655918#rd](http://mp.weixin.qq.com/s?__biz=MzUzODkwMDMxNA==&mid=2247490209&idx=1&sn=56699d6c71889d06012f6ed7e9ddc43b&chksm=fad1f894cda671824911b9000927fad5f82813fe9f58b090e55f9fa556bcb4fe601010658a5a&scene=126&sessionid=1681655918#rd)

 ![](../Images/5ece9c960eb6d82024ba2cd19823bf47.png)        9月11日，在黄鹤杯网络安全人才与创新峰会网络安全人才培养与需求论坛暨大学生网络安全尖锋训练营年度总结表彰大会上，山石网科通信技术股份有限公司高级副总裁杨庆华做了题为《从网络安全企业用人需求看网络安全人才培养》的报告。

![](../Images/f28351036d79b634fe620fb198986e27.png)

       杨庆华表示网络安全是复杂的、多领域、高技术、深度业务融合的系统，同时分析了网络安全人才现状和面临的问题，并结合山石网科的实践经验探讨了网络安全企业的用人需求。
