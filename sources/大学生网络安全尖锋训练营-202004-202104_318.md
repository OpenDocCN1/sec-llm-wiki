# 用科学网络安全观加强网络空间安全学科建设与人才培养

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODkwMDMxNA==&mid=2247490187&idx=1&sn=8c28f241ed820c69a0feaae77a9be3ce&chksm=fad1f8becda671a8b1de68901fb7294c32d3e59d3f29ef500cec12fb85fb3ce9f100c16adbe8&scene=126&sessionid=1681655918#rd](http://mp.weixin.qq.com/s?__biz=MzUzODkwMDMxNA==&mid=2247490187&idx=1&sn=8c28f241ed820c69a0feaae77a9be3ce&chksm=fad1f8becda671a8b1de68901fb7294c32d3e59d3f29ef500cec12fb85fb3ce9f100c16adbe8&scene=126&sessionid=1681655918#rd)

    9月11日，在黄鹤杯网络安全人才与创新峰会网络安全人才培养与需求论坛暨大学生网络安全尖锋训练营年度总结表彰大会上，中国工程院沈昌祥院士做了题为《以科学网络安全观做好学科建设和人才培养工作》的报告。  

![](../Images/f3e8c17a43608e235edee2247a753ab7.png)

      沈院士在报告中表示，网络空间安全一级学科要解决计算科学少攻防理念、体系结构缺防护部件、重大工程应用无安全服务三大问题，学科涉及数学、计算机科学与控制、信息与通信工程等多个领域，已形成了一个相对独立的教学和研究领域。要使学生掌握基础理论和技术方法，具有较高网络空间安全综合专业素质。
