数据查询-嵌套查询

  
  
  
![](../Images/0e706bb18dcd49950dbbe3f986a9929d.png)1、嵌套查询的概念

   嵌套查询类似于程序语言中的循环嵌套。在 SQL 语言 中，把一个 SELECT-FROM-WHERE 语句组称为一个查询块， 将一个查询块嵌套在另一个查询块的 WHERE 子句或 HAVING短语条件中的查询称为嵌套查询。子查询总是写在 圆括号中，可以用在使用表达式的任何地方。括号内的查 询块称为子查询或内层查询，与之相对的概念就是父查询 或外层查询。SQL 语言允许多层嵌套查询。 

注意：子查询的 SELECT 语句中不能使用 ORDER BY 子 句，因为 ORDER BY 子句只能对最终查询结果进行排序，也 不能包括 COMPUTE 或 FOR BROWSE 子句。SQL Server 2008 对嵌套查询的求解顺序是先内后外。即每个子查询在上一级查询处理之前求解，子查询的结果用于建立父查询的查找条件。有了嵌套查询，可以用多个简单的查询构造复杂查询（嵌套不能超过 32 层），提高 SQL 语言的表达能力。

![](../Images/0e706bb18dcd49950dbbe3f986a9929d.png)2、单值嵌套查询

父查询与子查询之间通过比较运算符连接 ，子查询返回的是必须一个单值，否则数据库服务器将报错。返回的单个值被外部查询的比较操作（如：=、!=、<>、<、<=、>、>=）使用，该值可以是子查询中使用聚合函数得到的值。

![](../Images/0e706bb18dcd49950dbbe3f986a9929d.png)3、多值嵌套查询

指子查询的返回结果是一列值的嵌套查询，通常使用 条件运算符 IN、ANY(或 SOME)、ALL、EXISTS。 

1.带有 IN 运算符的子查询 父查询通过IN谓词将父查询中的一个表达式与子查询 返回的结果集进行比较，如果表达式的值等于子查询结果 集中的某个值，父查询中的条件表达式返回真（TRUE），否则返回假（FALSE）。还可以在 IN 前加上关键字 NOT，其功 能与 IN 相反。

2.带有 ANY（或 SOME）、ALL 运算符的子查询 子查询返回单值时可以使用比较运算符，但返回多值时则使用ANY或ALL运算符，还必须同时使用比较运算符。

![](../Images/849f8af32980dbd0e82992eb8ea9eeaf.png "0905-11.png")

![](../Images/1df110b4656dc2499ce89922a35e6372.png "0905-22.png")

3\. 带有 EXISTS 运算符的子查询 EXISTS 是存在量词，使用 EXISTS 谓词的子查询不返回 任何数据，若子查询结果非空（即至少存在一条记录），则父查询的 WHERE 子句返回真（TRUE），否则返回假（FALSE）。由 EXISTS 引出的子查询，其目标列通常都用“\*”，原因在于该查询只返回逻辑值，给出列名毫无意义。

   不相关子查询：子查询的查询条件不依赖于父查询，并且每个子查询都只执行一次。

   相关子查询即子查询的查询条件依赖于父查询中的某个值，必须反复求值，供父查询使用。相关子查询运行速度慢，尽量避免使用，一般可用嵌套子查询实现。

结论：所有带 IN、比较运算符、ANY 或 ALL 运算符的 子查询都能使用带 EXISTS 运算符的子查询等价替换。

补充：查询结果保存与查看：（1）全选—将结果另存为— 定义.csv 文件名。（2）可以使用记事本、excel 等打开 csv 文件（纯文本文件）。（3）在 Excel 中数据都显示在第一列， 可以分开多列显示，方法：数据—数据工具—分列。
