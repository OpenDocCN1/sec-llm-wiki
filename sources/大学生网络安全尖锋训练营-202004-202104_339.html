数据查询-简单查询



1、完整的 SELECT 语句的基本语法格式

格式：

SELECT [DISTINCT] [TOP n [PERCENT]] <列名 1> 
[,<列名 2>„] 
[INTO  新表 ]
FROM <数据表名 1｜视图 1> [,„n]
[WHERE <筛选条件>]
[GROUP BY <分组条件>]
[HAVING <分组筛选条件>]
[ORDER BY <排序表达式>[ASC|DESC]]

说明：

（1）SELECT 子句用于指定选择的列或行及其限定，每个表达式通常是从中获取数据的源表或视图的列的引用，但也可能是其他表达式，例如常量或 T-SQL 函数。在选择列表中使用*表达式指定返回源表中的所有列。

（2）INTO子句用于将查询结果集存储到一个新的数据库表中。

（3）FROM子句是结果集数据来源于哪些表或视图，FROM 子句还可包含连接的定义。

（4）WHERE子句用于指定对数据行的筛选条件。

（5）GROUP BY子句用于对查询到的数据行进行分组。

（6）HAVING子句用于指定分组统计条件，要与GROUP BY 子句一起使用。

（7）ORDER BY子句用于对查询到的数据行进行排序处理。ASC和DESC关键字用于指定行是按升序还是按降序排序。

（8）在这些子句中，只有 SELECT 子句和 FROM 子句是必选项，其他子句均为可选项。

2、使用 SELECT 子句选择表中的若干列

  选择表中的全部列或部分列这就是表的投影运算。这种运算可以通过SELECT子句给出的字段列表来实现。字段列表中的列可以是表中的列，也可以是表达式列。所谓表达式列就是多个列运算后产生的列或者是利用函数计算后所得的列。 

  1. 使用“*”输出表中的所有列。

  2. 输出表中部分列，将要显示的字段名在 SELECT 关键字后依次列出来，列名与列名之间用英文逗号隔开，字段的顺序可以根据需要来指定。

  3. 为结果集内的列指定列标题。有时，“结果”窗格中的列不是表中现成的列，而是通过表中的一个或多个列计算出来的，这时，这个计算列需要指定一个列名，同时该表达式将显示在字段列表中。

可使用三种方法：
方法一：用“AS”关键字    格式：表达式 AS 列标题 【例 5-2】：查询 XS 表中全体同学的姓名及年龄。
方法二：用赋值运算符“=”
格式：列标题=表达式 
方法三：用空格号
格式：表达式 列标题。

3、选择表中的若干记录

   选择表中的若干记录 选择表中的若干记录这就是表的选择运算。这种运算可以通过增加一些谓词(例如 WHERE 子句)等来实现。 

  1. 使用 DISTINCT 消除重复行
    关键字 DISTINCT 的含义是对结果集中的重复行只选择一个，保证行的唯一性。

  2. 使用 TOP 限制返回行数     

    如果要限制返回的行数，可以在字段列表之前使用TOP n 关键字，则查询结果只显示表中前面 n 条记录，如果在字段列表之前使用 TOP n PERCENT 关键字，则查询结果只显示前面 n％条记录。

  3. 使用 WHERE 子句查询满足条件的元组

4、用 ORDER BY 子句对查询结果进行排序

格式：ORDER BY {列名 [ASC|DESC]}[,„n] 

功能：对查询结果按照一个或多个属性列的升序（ASC）或 降序（DESC）排列，默认为升序。 

说明：

（1）当按多列排序时，先按前面的列排序，如果值 相同再按后面的列排序。

（2）如果不使用 ORDER BY 子句， 则结果集按照记录在表中的顺序排列。

5、对数据进行统计

1、在 select 子句中使用集合函数  

   为了进一步方便用户，增强检索功能，SQL Server 提 供了许多集合函数，主要有：

（1）COUNT( [ DISTINCT | ALL ] * )统计记录个数。（2）COUNT( [ DISTINCT | ALL ] <列名> )统计一列中 值的个数。 

（3）SUM( [ DISTINCT | ALL ] <列名> )计算一列值的 总和(此列必须是数值型)。 

（4）AVG( [ DISTINCT | ALL ] <列名> )计算一列值的 平均值(此列必须是数值型)。 

（5）MAX( [ DISTINCT | ALL ] <列名> )求一列值中的 最大值。 

（6）MIN( [ DISTINCT | ALL ] <列名> )求一列值中的 最小值。 

说明：

（1）在 SELECT 子句中集合函数用来对结果集记录进 行统计计算。DISTINCT 是去掉指定列中的重复信息的意思， ALL 是不取消重复，默认是 ALL。

（2）COUNT(*) 返回指定 表中行数，包括包含空值的行。COUNT(列名) 不包括包含空值的行。 

2、使用 GROUP BY 子句对查询结果进行分组

GROUP BY 子句将对查询结果集分组的目的是为了细化集合 函数的作用对象。 

格式：GROUP BY 列名 [ HAVING 筛选条件表达式 ] 

功能：查询结果集按某一列或多列值分组，分组列值相等的为一组，并对每一组进行统计。 

说明：

（1）“BY 列名”是按列名指定的字段进行分组，将 该字段值相同的记录组成一组，对每一组记录进行汇总计 算并生成一条记录。

（2）“HAVING 筛选条件表达式”表示 对生成的组筛选后再对满足条件的组进行统计。

（3）SELECT 子句的列名必须是GROUP BY 子句已有的列名或是计算列。 

（4）HAVING 与 WHERE 子句的区别在于作用的对象不同。HAVING 作用于组，选择满足条件的组，WHERE 子句作用于 表，选择满足条件的记录。

（5）HAVING 子句中的列名必须是．GROUP BY 子句已有的列名或是计算列。

3.使用 COMPUTE 子句 

格式：COMPUTE 集合函数 [ BY 列名] 

功能：对查询结果集中的所有记录进行汇总统计，并显示 所有参加汇总记录的详细信息。 

说明：

（1）集合函数指 SUM()、AVG()、COUNT ()等。

（2）“BY 列名”按指定“列名”字段进行分组计算，并显示被统计记录的详细信息。

（3）BY 选项必须与 ORDER BY 子句一起使用。

6、用查询结果生成新表

格式：INTO 新表名 

功能：用查询结果创建新表。 

说明：

（1）新表名是被创建的新表，查询的结果集中的记录将添加到此表中。

（2）新表段由结果集中的字段列 表决定。

（3）如果表名前加“#”则创建的表为临时表。

（4） 用户必须拥有该数据库中建表的权限。

（5）INTO 子句不能与 COMPUTE 子句一起使用。

7、使用 UNION 语句合并结果集

格式：SELECT 语句 {UNION SELECT 语句}[，„n] 

功能：将多个查询结果集合并为一个结果集，也就是集合的合并操作。 

说明：

（1）参加 UNION 操作的各结果集的列数必须相同，对应的数据类型也必须相同。

（2）系统将自动去掉并集的重复记录，所以在表连接后会对所产生的结果集进行排序运算，删除重复的记录再返回结果。

（3）最后结果集的列名来自第一个 SELECT 语句。
