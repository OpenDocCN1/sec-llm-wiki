维护数据库

查看和设置数据库信息

方法一：菜单法

在【对象资源管理器】中右击该数据库名一属性一文件。

方法二：命令法

格式：EXEC sp_helpfile

说明：EXEC执行命令语句。

打开数据库

方法一：菜单法

在【对象资源管理器】窗格一可用数据库组合框。

格式：USE 数据库名

注意：如果没有指定操作数据库，查询是针对当前打开数据库进行，用户默认数据库是master,可以使用USE命令切换到指定数据库。

修改数据库

1、增加数据库的容量

一种是通过增加数据库的初始分配空间以及加大已有文件的最大容量限制来实现，另一种是向数据库添加新的文件来达到扩充数据库容量的目的。先介绍第一种解决方法。

方法一：菜单法

在对象资源管理器中右击改数据库名—属性。

方法二:命令法

格式: ALTER DATABASE 数据库名

MODIFY FILE

(NAME=文件名  -（要修改的数数据库文件的逻辑文件名）

[,SIZE=newsize[KB/MB/GB/TB]] - (指定数据库文件的初始容量大小）

[,MAXSIZE={max_size[KB/MB/GB/TB]/UNLIMITTED}] -（指定数据库文件的最大文件限制）

[,FILEGROWTH=growth_increment[KB/MB/GB/TB/%]]-(设置数据库文件的自动增长量)

注意:修改的数据库的容量只能比最初分配给数据库的容量要大。

2、缩减数据库容量

造成数据库空间存在大量浪费的情况有两种原因：一种情况是创建数据库初期对要存储的数据量估计不够准确，造成初始空间过大；另一种情况是当数据库运行一段时间后，由于删除了数据库中的大量数据，使数据库所需的空间减小，这时就可以根据实际情况缩减分配给数据库的数据文件和事务日志文件的磁盘空间，以免造成浪费。

(1)设置数据库“自动收缩”

方法:右击数据库-[属性]-[选项]-[自动]-[自动收缩]-[True ]。

说明:数据库引擎会定期检查数据库空间的使用情况，并减小数据库文件中文件的大小。该活动是后台进行的，不会影响数据库中用户的活动。

(2)手工收缩数据库

手工收缩数据库分为两种情况，一种是收缩数据库中某个数据文件或日志文件的大小，另-一种是收缩整个数据库中全部文件的大小。

方法:右击数据库-[任务]-[收缩]-[数据库]-[文件]。

说明:当数据库中没有数据时，可以在“对象资源管理器”中直接修改数据库属性，但有数据时，这样做会破坏数据库中的数据。

3、创建和更改文件组

用户可以在首次创建数据库时创建文件组，也可以在创建完数据库后添加数据文件时创建文件组，值得注意的是，一旦将文件添加到文件组中，就不能再将这些文件移动到其他文件组中。文件组中只能包含数据文件，日志文件不能是文件组的一部分。

方法：在[对象资源管理器]中右击该数据库名-[属性]-[文件组]-[文件]-[新文件组]。

4、增加或删除数据库文件

可以通过添加数据文件和日志文件的方法来扩大数据库空间，也可以通过删除文件的方法来减小数据库空间。

方法：在[对象资源管理器]中，右击数据库-[属性]-[文件]-[添加]-[删除]。

说明：(1)只有当文件中没有数据或日志信息，文件完全为空时，才可以从数据库中删除该文件。(2)如果要让某个数据文件为空，可以使用“收缩文件”中的“通过将数据迁移到同一个文件组中的其他文件来清空文件”，然后就可以删除。

5、更改数据库名称

方法一：菜单法

在[对象资源管理器]中，右击要更改名称的数据库-[重命名]。

说明：在配置管理器中-SQL SERVER 服务-重新启动。

方法二：命令法

格式：ALTER DATABASE 旧名 MODIFY NAME=新名

分离数据库

分离数据库就是将数据库从SQL Sever实例中删除，使其数据文件和日志文件在逻辑上脱离服务器，但实质上它并没有从磁盘中删除，这样该数据库中的数据文件和日志文件还可以再附加到其他的SQL Sever 2008的实例上去。

方法一：菜单法

(1)在对象资源管理器中右击已创建的数据库名-任务-分离。

(2)把分离后的主数据文件和日志文件拷贝到其他存储设备上，以备日后需要。

方法二：命令法

格式：EXEC sp_detach_db 数据库名

说明：分离后的数据库对象在对象资源管理器中看不到，但仍然在磁盘上。

附加数据库

附加数据库是分离数据库的逆操作，通过附加数据库，可以将没有加入SQL Server服务器的数据库文件加到服务器中。另外，通过分离和附加数据库的操作，可以将数据库Sever SQL库从低版本的SQL Server升级到高版本的SQL Server中。

方法一：菜单法

在[对象资源管理器]窗格中，右击[数据库]-[附加]-[添加]-主数据文件。

说明:“以用户管理员身份”打开对象资源管理器，否则无权限出错。

方法二:命令法

格式: CREATE DATABASE 数据库名

ON<数据文件的物理名称>[,...n]

FOR {ATTACH |ATTACH_ REBUILD_ LOG}

功能:创建数据库。

删除数据库

删除数据库是将数据库及其全部内容从系统中删除。

方法一:菜单法

在[对象资源管理器]窗格中，右击[数据库]-[删除]。

方法二:命令法

格式: DROP DATABASE <数据库名>

功能:删除数据库。

说明:删除数据库进连同其中的包含的文件全部删除。s
