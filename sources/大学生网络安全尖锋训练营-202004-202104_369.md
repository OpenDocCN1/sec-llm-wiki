系统要求：

  

    根据安装类型，无论是在真实硬件上还是在虚拟机中安装，请确保指定的系统满足以下要求：

*   8 GB RAM（可以使用更少的RAM，但可能会导致交换/不稳定）
    
*   128 GB SSD（可能更小，但限制了存储事件的容量）
    
*   通过DHCP网络
    
*   正常的非代理互联网连接
    

  
安装类型：  
    有预构建的安装类型可用，每种安装都着眼于不同方面，可立即开始使用。docker-compose文件位于中/opt/tpot/etc/compose。如果要构建自己的撰写文件，只需在其中创建一个新文件（基于预构建的布局和设置），/opt/tpot/etc/compose然后运行tped.sh即可将T-Pot指向新的撰写文件并运行个性化版本。![](../Images/1fd31f6e764a9f8a68d6ba7eea8555f9.png)

安装步骤：

  

    T-Pot的安装简单明了，在很大程度上取决于能否正常工作，透明且无代理且正在运行的Internet连接。否则，安装将失败！    首先，确定是要从GitHub下载预构建的安装ISO映像，自己创建 还是 在现有的Debian 10（Buster）上进行后安装。其次，确定您的系统在哪里运行：真正的硬件还是虚拟机？  
预先建立的ISO映像    可以下载安装ISO映像（〜50MB），该映像是由ISO Creator创建的，您可以自己使用它来创建自己的映像。基本上，它只是节省您一些时间来下载组件和创建ISO映像。您可以从GitHub下载预构建的安装ISO 并跳至安装部分。创建自己的ISO映像    出于透明的原因，为了使您能够自定义安装，请使用ISO创建器，该创建器使您可以创建自己的ISO安装映像。创建ISO映像的要求：

*   Debian的10主机系统（别人可以工作，但仍未经测试）
    
*   4GB的可用内存
    
*   32GB的免费存储空间
    
*   正常的互联网连接

```

```

    成功构建之后，您将在文件夹中找到ISO映像tpot.iso以及SHA256校验和tpot.sha256。  
在VM中运行    您可能要在虚拟环境中运行T-Pot。虚拟系统配置取决于您的虚拟化提供商。    仅需对默认计算机配置进行少量修改，即可使用VirtualBox和VMWare成功测试T-Pot 。    在确保网络桥接的同时，确保满足系统要求并根据要求分配虚拟硬盘和RAM 非常重要。    您需要为网络接口启用混杂模式，才能使fatt，suricata和p0f正常工作。确保在配置期间启用它。    如果要将wifi卡用作T-Pot的主要NIC，请注意，并非所有网络接口驱动程序都支持所有无线卡。例如，在VirtualBox中，您必须选择NIC 的“ MT SERVER”模型。    最后，将tpot.isoISO 挂载到VM并继续安装。  
在硬件上运行    如果决定在专用硬件上运行T-Pot，请按照以下步骤操作：

1.  从ISO映像刻录CD或使用该映像制作可引导的USB记忆棒。
    

尽管大多数CD刻录工具都允许您从ISO映像进行刻录，但是从ISO映像创建可启动USB记忆棒的过程取决于您的系统。有多种Windows GUI工具可用，例如，本技巧可能对您有所帮助。在Linux或MacOS上，可以使用工具dd或通过T-Pot的ISO Creator创建USB记忆棒。

2.  从USB记忆棒启动并安装。
    

请注意：对Intel NUC平台执行的测试有限，其他硬件平台未经测试。没有提供任何形式的硬件支持。安装后用户    在某些情况下，必须自己安装Debian 10（Buster）：

*   云提供商不提供安装的ISO映像。
    
*   硬件设置需要特殊的驱动程序和/或内核。
    
*   在公司内部，您必须设置特殊的策略，软件等。
    
*   您只是喜欢紧贴事物。
    

T-Pot通用安装程序将升级系统并安装所有必需的T-Pot依赖项。只需按照以下步骤操作：

*   
*   
*   

```
git clone https://github.com/dtag-dev-sec/tpotcecd tpotce/iso/installer/./install.sh --type=user
```

    现在，安装程序将启动并指导您完成安装过程。    安装后自动    如果您提供自己的安装程序，也可以让安装程序自动运行tpot.conf。中提供了一个示例tpotce/iso/installer/tpot.conf.dist。如果您想自动化安装（例如使用Ansible），这将使事情变得更容易。只需根据tpot.conf需要调整以下步骤：

*   
*   
*   
*   

```
git clone https://github.com/dtag-dev-sec/tpotcecd tpotce/iso/installer/cp tpot.conf.dist tpot.conf./install.sh --type=auto --conf=tpot.conf
```

安装程序将自动启动，并指导您完成安装过程。  
云部署    位于cloud文件夹中。    当前有Ansible＆Terraform的示例。    如果您愿意做出贡献，则可以添加其他云部署，例如Chef或Puppet，或将当前方法扩展到其他云提供商。请注意：云提供商通常会提供调整后的Debian OS映像，该映像可能与T-Pot不兼容。没有提供任何形式的云提供商支持。  
  
第一次运行    安装需要很少的交互，对于基本的Linux安装，只需回答语言环境和键盘设置。系统重新引导时，保持活动的Internet连接。T-Pot安装程序将启动，并询问您安装类型，tsec用户的密码和Web用户的凭据。其他所有内容将自动配置。所有docker映像和其他组件将被下载。根据您的网络连接和所选的安装类型，安装可能需要一些时间。降低250Mbit /增加40Mbit的安装通常会在15-30分钟内完成。安装完成后，系统将自动重新启动，并且将显示T-Pot登录屏幕。在控制台上，您可以登录：

*   用户：\[tsec或用户\] 您在一种安装后方法中选择的
    
*   pass：\[密码\] 您在安装过程中选择的
    

所有蜜罐服务均已预先配置并自动启动。您可以从浏览器登录并访问管理界面：https://<your.ip>:64294或通过SSH访问命令行：ssh -l tsec -p 64295 <your.ip>

*   用户：\[tsec或用户\] 您在一种安装后方法中选择的
    
*   pass：\[密码\] 您在安装过程中选择的
    

您也可以从浏览器登录并访问Web UI：https://<your.ip>:64297

*   用户：\[用户\] 您在安装过程中选择的
    
*   pass：\[密码\] 您在安装过程中选择的
    

  
系统放置    确保您的系统可以通过您怀疑入侵者（或来自Internet）的网络访问。否则，T-Pot除了内部网络的攻击之外，很可能不会捕获任何攻击！对于初学者，建议将T-Pot放在未过滤的区域中，在该区域中所有TCP和UDP流量都转发到T-Pot的网络接口。但是，为避免指纹，您可以将T-Pot放在防火墙后面，并将端口范围1-64000中的所有TCP / UDP通信转发到T-Pot，同时仅允许从受信任的IP访问大于64000的端口。    作为技术概念的一部分，提供了所有相关端口的列表    基本上，您可以根据需要转发任意多个TCP端口，因为glutton＆honeytrap动态绑定任何其他honeypot守护程序未覆盖的TCP端口。如果需要外部Admin UI访问，请将TCP端口64294转发到T-Pot，请参见下文。如果需要外部SSH访问，请将TCP端口64295转发到T-Pot，请参见下文。如果需要外部Web UI访问，请将TCP端口64297转发到T-Pot，T-Pot需要传出git，http，https连接进行更新（Debian，Docker，GitHub，PyPi），攻击提交（ewsposter，hpfeeds）和CVE / IP信誉转换图更新（logstash，listbot）。端口和可用性可能会因您的地理位置而异。此外，在首次安装期间，还需要额外的传出ICMP / TRACEROUTE，才能找到最接近和最快的镜像。  
更新    对于那些想活在T-Pot开发前沿的人们，我们引入了更新功能，该功能将使您可以更新所有与T-Pot相关的文件，以便与T-Pot master分支保持最新。 如果您对T-Pot相关配置文件进行了任何相关更改，请确保首先创建备份。更新脚本将：

*   无情地覆盖本地更改以与T-Pot主分支同步
    
*   将系统升级到Debian（Stable）中可用的软件包
    
*   更新所有资源以与T-Pot主分支同步
    
*   确保将所有与T-Pot相关的系统文件打补丁/复制到原始T-Pot状态
    
*   从以下位置还原自定义的ews.cfg和HPFEED设置 /data/ews/conf
    

您只需运行更新脚本：

*   
*   
*   

```
sudo su -cd /opt/tpot/./update.sh
```

    尽管进行了所有测试，但请注意，有时更新可能会带来无法预料的后果。请为您的工作创造最大价值的计算机或文件的备份。  
选件    该系统设计为无需任何交互或维护即可运行，并自动为社区做出贡献。对于某些人来说，这可能还不够。因此，这里有一些示例可以进一步检查系统并更改配置参数。SSH和Web访问默认情况下，SSH守护程序允许使用用户名/密码组合访问tcp / 64295并使用阻止凭据暴力破解尝试fail2ban。这也算作Admin UI（tcp / 64294）和Web UI（tcp / 64297）访问。如果您没有SSH客户端，但仍想通过命令行访问计算机，则可以通过从中访问Admin UI来进行https://<your.ip>:64294，请输入

*   用户：\[tsec或用户\] 您在一种安装后方法中选择的
    
*   pass：\[密码\] 您在安装过程中选择的
    

您也可以仅通过2fa.sh在命令行上运行就将两因素身份验证添加到Cockpit 。
