创建SQL Server2008 的数据库

     使用对象资源管理器提供的图形界面来创建数据库是最为简单易行的方案，因为对象资源管理器提供给我们的是一个“傻瓜式”的操作界面，我们只需要用用鼠标单击就可以完成数据库的创建，比较符合我们的操作习惯。

01

（1）启动SQL Server管理器。单击开始菜单，在弹出的菜单中选择【所有程序】/ 【MicrosoftSQL Server  2008】/ 【SQL Server  Management  Studio】命令，打开【连接到服务器】对话框，使用windows或SQL Server身份验证建立连接，如图所示。然后单击【连接】按钮。就进入Microsoft  SQL Server  2008  Management  Studio。

02

（2）启动【新建数据库】命令。在打开的“SQL Server Management Studio”窗口中，右击【对象资源管理器】窗格中的【数据库】结点，在弹出的快捷菜单中选择【新建数据库】命令，如图所示。

03

（3）此时就会打开如图3-6所示的【新建数据库】对话框，在这个窗口的左边有3个页，分别是【常规】、【选项】和【文件组】页。

（4）在窗口中选择【常规】页，然后根据表3-1的内容要求输入或设置该数据库文件的相关属性（至少是一个主数据文件和一个日志文件）。

（5）可以通过【添加】按钮来为该数据库增加一些次数据文件和日志文件。

04

（6）设置【选项】页属性。在左边的窗格中选择【选项】页，在【选项】窗格中，可设置数据库的排序规则、恢复模式、兼容级别，以及其他一些选项的设置。

（7）添加或设置数据库的文件组。每个数据库都至少有一个主文件组（PRIMARY），也可以为数据库添加用户文件组。在图3-6中，选择左边的窗格中的【文件组】页，在该【文件组】窗格中，可为数据库添加文件组并设置其属性，如是否只读，是否为默认值等。如图所示。

05

（8）当数据库的名称和相关内容都设置好后，如图3-9所示。点击下方的【确定】 按钮。在“数据库”的树形结构中，就可以看到刚才创建的students数据库，如图所示。

06

除了使用图形界面创建数据库外，还可以在SQL Server Management Studio集成的查询分析器中使用Transact-SQL语言中的CREATE  DATABASE语句来创建数据库，CREATE DATABASE的常用语法格式如下：

CREATE DATABASE datebase_name

[ON [PRIMARY]

{

[NAME=logical_file_name,

    FILENAME='os_file_name'

    [,SIZE=size]

    [,MAXSIZE={max_size|UNLIMITED}]

    [,FILEGROWTH=grow_increment])

  }

[,…n]

  LOG ON

  {

(NAME=logical_file_name,

    FILENAME='os_file_name'

    [,SIZE=size]

    [,MAXSIZE={max_size|UNLIMITED}]

    [,FILEGROWTH=grow_increment])

  }

[,…n]

COLLATE collation_name

注意事项：

（1）方括号“[]”表示该项可省略，省略时各参数取默认值。

大括号{}为必选语法项。

（2）[，…n]指示前面的项可以重复n次。各项之间用逗号分隔。

|（竖线）分隔括号或大括号中的语法项。只能使用其中一项。

（3）“{}[，…n]”表示大括号括起来的内容可以重复写多次。

（4）SQL语句在书写时不区分大小写，为了清晰，一般都用大写表示系统保留字，用小写表示用户自定义的名称。

（5）一条语句可以写在多行上，但不能多条语句写在一行上。
