# 【学习园地】SQL Server 2008概述

2010年5月,Microsoft公司正式发布Microsoft SQL Server 2008 R2。

![](../Images/4f537a2d8af2419ce1a58940d601f058.png)PART  01   SQL Server2008体系结构  

       SQL Server 2008是基于C/S模式的关系型数据库管理系统，将事务处理合理地分配到客户机与服务器上，两者共同协调进行处理，充分发挥客户机与服务器的各自优势和性能，减少网络流量，提高了整个系统的服务性能与效率。例如,将输入、显示与校验数据这样需要用户频繁交互处理的任务分散在客户端的(多台)机器上进行，而将共享数据、文件1/0 服务和数据查询处理等大流量的事务集中在数据库服务器上完成，尽可能地发挥和利用服务器的高处理性能与客户机的交互灵活性，提高了系统的性能与效率。

      在管理的具体实现上, SQL Server 2008又分为单机管理架构、主从式管理架构和分散式管理架构三种类型。

(1)单机管理架构:由同一台计算机包办数据库系统的所有工作,即数据库服务器端和客户端都在同- 台计算机上。

(2)主从式管理架构:在-台主机上安装数据库服务器,另外一些计算机作为客户端安装相关的连接与管理程序，在客户端通过网络操作及管理数据库服务器。

(3)分散式管理架构:在主从式管理架构基础上增加多台数据库服务器。可自由选择是将服务器嘴和客户腊工具分开在不同主机上，还是集中于同一台主机上。

![](../Images/4f537a2d8af2419ce1a58940d601f058.png)PART  02 SQL Server 2008 的组成  
![](../Images/a78c8279ee66c3c9f5c4d761031cfe33.png)

1、数据库引擎

       是SQL Server 2008 系统的核心服务，负责完成业务数据的存储、处理、查询和安全管理。在大多数情况下，使用数据库系统实际上就是使用数据库引擎。

2、商业智能

(1)分析服务:提供联机分析处理和数据挖掘功能，可支持用户建立数据库。

(2)报表服务:为用户提供支持Web的企业级报表功能，可以方便地定义和发布满足自己需求的报表。

(3)集成服务:是一个数据集成平台，可以完成有关数据的提取、转换、加载等。

![](../Images/4f537a2d8af2419ce1a58940d601f058.png)PART  03 SQL Server 2008  的主要特性  
![](../Images/a78c8279ee66c3c9f5c4d761031cfe33.png)

1、简单友好的操作方式

    提供强大功能的同时又便于管理和使用。

2、支持高性能的分布式数据库处理结构

    使应用系统中的数据可以存储在分散的多台服务器上，构成分布式数据库体系，为实施电子商务等大型系统提供了较好的可扩展性。

3、动态锁定的并发控制

    有效防止在执行查询和更新操作时出现冲突，既方便了开发者和用户，也提高了数据的共享可靠性。

4、丰富编程接口

  SQL Server 支持Transact-SQL、DB Library for C/Visual Basic和嵌入式SQL等多种开发工具，而且还支持DBLIB、ODBC、OLEDB规范，允许使用DBLIB、ODBC 和OLEDB的接口函数访问SQL Server数据库。基于以前版本建立的数据库与应用，可以非常可靠地运行在SQL Server 2008 的数据库平台上。

5、单进程、多线程体系结构

    由执行内核统--分配和协调网络环境中多个用户对资源与数据的访问和存取，只需很小的额外负担就可同时处理多用户的并发访问，不但减少了内存的占用空间，而且有利于提高和保持系统的运行速度、服务效率和可靠稳定性。
