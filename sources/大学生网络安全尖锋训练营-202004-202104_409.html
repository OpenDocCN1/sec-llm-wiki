前言：

随着网络安全被企业和社会愈加重视，网络安全人才也受到越来越多的青睐。如何培养网络安全人才？如何在合法的场景下训练网络安全人才？CTF（Capture The Flag）赛事着实是一个不错的方式！自己是否可以搭建一个CTF训练平台呐？当然，CTFd满足你的期望！

什么是CTFd：

CTFd用Python编写，并使用Flask Web框架，专注于易用性和可定制性。它包含运行CTF所需的一切，并且很容易通过插件和主题进行自定义。而且项目完全开源，可以拥有更多的个人化内容。

演示官网：https://demo.ctfd.io/

GitHub地址：https://github.com/CTFd/CTFd


特点：

通过管理界面创建自己的挑战，类别，提示

o动态计分挑战

o解锁挑战支持

o挑战插件架构，以创建自己的自定义挑战

o基于静态和正则表达式的标志

o解锁提示

o文件上传到服务器或与Amazon S3兼容的后端

o限制挑战尝试并隐藏挑战

o自动保护

    个人和团体比赛

o让用户自己玩或组队一起玩

    具有自动平局解决方案的计分板

o隐藏公众得分

o在特定时间冻结分数

o电子邮件确认支持

o忘记密码支持

    自动比赛开始和结束

    团队管理，隐藏和禁止

    使用插件和主题界面自定义所有内容

    导入和导出CTF数据进行存档

部署方式：

CTFd提供自动生成的Docker映像，而部署CTFd实例的最简单方法之一就是使用Docker Compose。

1、安装Docker

2、安装Docker Compose

3、使用以下命令克隆CTFd存储库

git clone https://github.com/CTFd/CTFd.git

修改docker-compose.yml存储库中的文件SECRET_KEY以为CTFd服务指定环境。

environment:  - SECRET_KEY=<SPECIFY_RANDOM_VALUE>  - UPLOAD_FOLDER=/var/uploads  - LOG_FOLDER=/var/log/CTFd  - DATABASE_URL=mysql+pymysql://root:ctfd@db/ctfd  - REDIS_URL=redis://cache:6379  - WORKERS=4

4、运行

docker-compose up


您现在应该可以在http://localhost:8000上访问CTFd


同时，您也可以使用常规方式部署CTFd，

以ubantu为例

1、安装git

sudo apt install git

2、安装pip

sudo apt install python-pip

3、安装Flask

sudo pip install Flask

4、克隆CTFd

sudo git clone https://github.com/CTFd/CTFd.git

4、安装CTFd

sudo cd /usr/local/CTFd/sudo ./prepare.sh

或者

sudo cd /usr/local/CTFd/sudo pip install -r requirements.txt

5、启动CTFd（默认运行在4000端口）

sudo pyhton serve.py# 或者 sudo pyhton3 serve.py
