 Web应用安全

01 新的流量入口带来新的安全风险






       除了网页之外，API（Application Programming Interface，使用HTTP协议通过网络调用的应用程序接口）和各种小程序作为新的流量入口快速崛起。更多的流量入口和更易用的调用方式在提高Web应用开发效率的同时，也带来了更多和更复杂的安全问题。一方面，传统的SQL注入、XSS、CC攻击等攻击手段和各种新曝出的Web漏洞，对Web应用安全方案的健壮性、灵活性和安全团队的快速反应能力提出了更高的要求；另一方面，随着大数据技术和流量产业的成熟，互联网中自动化程序流量占比迅速增长，由爬虫带来的数据泄露、流量作弊等问题也日益为业界所重视。

近年来“互联网+政务服务”正在成为我国新一代的政务服务模式。随着政府网站向电子政务云迁移，以及IPv6、HTTPS、容器等技术的升级，大量移动应用和新门户出现，原有安全能力并不足以对新的应用场景提供有效防护。主要矛盾表现在以下两个方面：一是Web应用漏洞层出不穷。由于管理和技术等多方面的原因，漏洞长时间不修复导致大量安全风险；二是API广泛使用带来新的风险。不安全的API接口引起不安全的数据访问和操作行为，同时超频访问和在JSON/XML实体中恶意调用，加重了后端Web应用系统的性能负载，并对其承载的数据带来不良影响。





02 国内Web应用安全技术水平总体不弱部分领先






国外Web应用安全技术发展趋势





WAAP组合

        Gartner的研究认为，Web应用安全服务越来越多的通过四个核心安全功能的组合，提供综合的Web应用安全保护的能力。这四种安全能力包括：WAF，Web应用防火墙通过对Web应用流量监控，过滤其中带有攻击的URL流量；Bot缓解，防止网络爬虫应用对网站随意扫描和敏感信息抓取；DDoS保护，检测针对Web应用的独特网络拒绝服务攻击，并进行阻断；API保护，对应用系统提供API接口，进行监控和防护。

云化Web应用保护

目前WAF以物理或虚拟设备的形式存在，但是随着未来越来越多Web应用迁移到云平台，Web应用防护的交付方式也变成云方式交付。云WAAP服务采用了最新的传输层安全(TLS)加密套件，并实现了Web应用安全反向代理的部署模式。将WAF与网络负载均衡、网络内容缓存（CDN）或网络DDoS缓解等云服务其他技术的整合带来了全新的发展动力。


API 安全

API安全性遵循应用发展的轨迹。目前市场服务需求依然没有得到满足，主流安全产品还不够成熟。国际上更多的WAF供应商在提供API安全功能方面取得了进展，但是在这一领域仍有很多工作要做。Gartner在《API安全性：保护API所需采取的措施》中预测，到2021年将有90%的Web应用采用HTML5 的前端页面，并且在服务器端启用API服务的形式，这使得Web应用暴露出更大的攻击面，而目前针对API开展安全防护的Web应用只占到了总数的40%。


 Web应用安全检测

Gartner将应用程序安全测试（AST，Application Security Testing）定义为旨在分析和测试应用程序中的安全漏洞的产品和服务，其主要测试目标为Web应用程序。AST的三种主要形式包括：静态AST（SAST）技术，在编程和（或）测试软件生命周期阶段分析应用程序的源代码、字节码或二进制代码是否存在安全漏洞；动态AST（DAST）技术，在测试或操作阶段分析处于动态运行状态的应用程序，通过模拟对应用程序的攻击分析应用程序的反应，从而确定其是否易受攻击；交互式AST技术，同时结合了SAST和DAST的元素，通常作为测试运行时环境的代理，用于观察操作或攻击并识别漏洞。





国内Web应用安全技术水平





Web应用防火墙和Web安全云服务处于并跑阶段

在Web应用防火墙方面，以Imperva为代表的国外厂商处于领先地位，开创了许多安全功能场景，包括最早引入社区安全（威胁情报共享）的概念，通过实时分享威胁情报中的IP信誉信息进行未知威胁的确认与防御等。目前，该领域国内厂商专注于WAF产品适应新环境、新攻击手段的各类功能研发工作，针对传统数据中心、云环境、大规模集群、网站HTTPS加解密性能优化、IPv6升级改造等场景，进行了产品适配及配套系统改进，整体水平与国外厂商相当。

在Web安全云服务方面，Websaas云监测及防护设施由国外的Cloudflare和国内的安恒信息等厂商主导建设，国内外技术水平和产品性能基本相当。但国外厂商在安全场景的引入方面（如边缘计算实时防护等）更为领先。


 网页防篡改技术具有本土特色

在网页防篡改技术方面，国内厂商高度重视国产化操作系统的适配，目前已经适配了银河麒麟、统信UOS等多个国产化操作系统，未来还会不断拓展其他国产化环境。在入侵检测与审计技术方面，国内厂商自主创新了页面重现技术，并结合行业用户实际需求，定义了以网站运营视角展现的可视化报表与性能分析功能。在应用网关技术方面，国内厂商的产品普遍支持“双证书、双中心”，实现了基于SM2、SM3、SM4算法及国密标准的国产密码算法SSL协议。


 Web漏洞扫描技术处于跟跑阶段

国内厂商根据自身在安全服务和攻防实践领域的经验，广泛采用了DAST（动态安全测试技术），目前该技术已经成熟。在SAST（源代码安全检测技术）方面，国内厂商处于起步阶段，产品的成熟度与国外相比还有一定差距，目前主要通过人工结合开源工具的方式对源代码进行检查，无法完全满足Web应用发展的需求。





03 国内厂商以问题为导向开展创新并取得一定的成果





基于国产处理器的Web漏洞扫描




在充分考虑率HTTPS、登陆限制等场景，以及扫描技术对Web应用本身带来的性能消耗与安全影响的基础上，国内厂商在扫描器和扫描沙箱技术上实现了突破。国瞬、安恒信息等厂商在国产处理器的基础上，完成了扫描器整体功能的迁移，并针对多核CPU进行了性能优化，提升了并发性能。





基于国产操作系统的网页防篡改




网页防篡改属于我国特色技术产品。安恒信息的新一代防篡改软件通过自主创新的操作系统底层文件驱动检测技术、核心内嵌技术、事件触发技术等，保证网站文件系统不被恶意篡改。目前相关产品已经适配了银河麒麟、统信UOS等多个版本的国产操作系统，同时也积极探索与操作系统内置安全API进行联动的技术方案，未来还会不断拓展其他国产化环境。





满足国密标准的应用安全网关




为了提高Web应用的安全访问速度，国内企业基于SM2、SM3、SM4算法，研发了支持“双证书、双中心”且满足标准的应用安全网关。该类产品自主创新了快速协议处理、快速证书解析、快速CRL解析等专有技术，大量减少了证书处理和数据处理中的数据多次载入问题，同时通过专业的硬件平台与定制化的内核，提供了高速处理和并发能力。





基于Web应用入侵流量的深度分析




针对APT攻击流量，国内厂商以网站运营视角，采用国产芯片和操作系统，对攻击流量进行梳理并深度解析，发现流量中的0day漏洞、恶意代码等高级攻击手段，同时记录威胁的来源、攻击手段、攻击过程、攻击目标、攻击影响等信息。在风险可视化的情况下，进行过程分析和溯源分析，提供全面的检测和预警能力。安恒信息等厂商，已推出基于兆芯、鲲鹏芯片的国产化APT产品，在保留原有产品功能的基础上，实现了国产芯片的包解析性能提升，同时结合对国产操作系统的攻击研究，发现了针对国产操作系统的定向攻击。





基于国产基础软硬件的Web应用开发SDL





在国产化操作系统、中间件等基础软件环境下，Web应用开发过程实施安全开发生命周期（SDL，Security Development Lifecycle）。从需求、设计到发布产品的每一个阶段都增加相应的安全措施，减少软件漏洞数量并将安全缺陷降低到最小程度。实施SDL对于减少国产化环境下Web应用程序的漏洞具有显著的效果。安恒信息在国产化安全产品的开发工作中，推出了基于国产基础软硬件SDL开发咨询服务。
