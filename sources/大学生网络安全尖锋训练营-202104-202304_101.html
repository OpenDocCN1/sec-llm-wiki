【学习园地】selenium（1）

1

selenium



Selenium 是最广泛使用的自动化测试套件之一。Selenium支持：C#，Java，Perl，PHP，Python 和 Ruby。其中Selenium最受 Python 和 C＃欢迎。Selenium可以直接在大多数Web浏览器中运行。selenium能够解决大部分的网页的反爬问题。今天训练营就带大家搭建Selenium环境和利用python对Selenium进行调用


2

环境搭建



因为Selenium是模拟浏览器真实访问，所以需要对浏览器进行操作，这就需要对应的驱动进行支持。

这里训练营给大家列举出三款比较常用的浏览器的驱动下载地址

  1. 火狐：https://github.com/mozilla/geckodriver/releases

  2. 谷歌：https://chromedriver.storage.googleapis.com/index.html

  3. Edge：https://developer.microsoft.com/en-us/microsoft-edge/tools/webdriver/


如果没有同学们使用的浏览器可以前往Selenium的官网自行查找下载

https://www.selenium.dev/zh-cn/documentation/webdriver/getting_started/install_drivers/


经过下载可以发现只有一个可执行文件，将其放入我们的python项目文件夹中或者添加环境变量，这里训练营使用的是火狐的驱动为大家做演示

好的，接下来我们再python中安装Selenium库

pip show selenium


这里训练营推荐大家再额外下载seleniumwire库，这个库可以额外加入或获取header让我们的爬虫更具有DIY性


下面我们使用selenium打开一个浏览器并访问下淘宝

from seleniumwire import webdriverdd = webdriver.Firefox(executable_path=r'geckodriver.exe')#获取驱动的路径dd.get("https://www.taobao.com/")


现在就表示我们的selenium环境配置成功




3

定位页面元素



这个可以说是selenium.webdriver的重要功能了，通过定位元素我们可以模拟很多用户的操作，例如通过元素的定位我们可以查找文字框和按钮，并对其进行一些操作，例如我们现在知道了baidu的搜索框id为kw,搜索框的id为su：

那么我们可以写一个脚本来自动化查询某些东西

例如


from selenium import webdriverdd = webdriver.Firefox(executable_path=r'geckodriver.exe')dd.get("https://www.baidu.com/")
dd.find_element("id","kw").send_keys("大学生网络安全尖锋训练营")dd.find_element("id","su").click()


运行下可以看到

浏览器完全按照我们的指示进行了搜索


当然我们可以有不同的搜索方式，下面是一个xpath的例子


from selenium import webdriverdd = webdriver.Firefox(executable_path=r'geckodriver.exe')dd.get("https://www.baidu.com/")
dd.find_element("xpath","//*[@id='kw']").send_keys("大学生网络安全尖锋训练营")dd.find_element("id","su").click()


以及CSS的例子


from selenium import webdriverdd = webdriver.Firefox(executable_path=r'geckodriver.exe')dd.get("https://www.baidu.com/")
dd.find_element("css selector","#kw").send_keys("大学生网络安全尖锋训练营")dd.find_element("id","su").click()



4
浏览器简单操作


利用set_window_size(长，高)我们可以调节窗口大小

利用set_window_position(x,y)我们可以调节窗口位置

利用refresh()可以完成刷新

通过back()和forward()我们可以完成网页的前进和后退

通过execute_script()可以执行js代码


整体代码


from selenium import webdriverdd = webdriver.Firefox(executable_path=r'geckodriver.exe')dd.get("https://www.baidu.com/")
dd.find_element("css selector","#kw").send_keys("大学生网络安全尖锋训练营")dd.find_element("id","su").click()
dd.set_window_position(0,0)
dd.refresh()
dd.back()
dd.forward()
dd.execute_script("window.open('https://www.bilibili.com/')")
