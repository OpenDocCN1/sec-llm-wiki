**selenium**

  

  

**Selenium** 是最广泛使用的**自动化测试**套件之一。Selenium支持：**C#，Java，Perl，PHP，Python 和 Ruby**。其中Selenium最受 Python 和 C＃欢迎。Selenium可以直接在大多数**Web浏览器**中运行。selenium能够解决大部分的网页的反爬问题。今天训练营就带大家搭建Selenium环境和利用python对Selenium进行调用

## ****定位页面元素****

  

  

这个可以说是**selenium.webdriver**的重要功能了，通过定位元素我们可以模拟很多用户的操作，例如通过元素的定位我们可以查找文字框和按钮，并对其进行一些操作，例如我们现在知道了baidu的搜索框id为kw,搜索框的id为su：

![](../Images/ac7a8d692b1e2be0a955f38428d72604.png)

那么我们可以写一个脚本来自动化查询某些东西

例如

  

```

```

*   
*   
*   
*   
*   
*   

```
from selenium import webdriverdd = webdriver.Firefox(executable_path=r'geckodriver.exe')dd.get("https://www.baidu.com/")
dd.find_element("id","kw").send_keys("大学生网络安全尖锋训练营")dd.find_element("id","su").click()
```

  

运行下可以看到

![](../Images/182144b9f7d7f3e91ad143b6dd9c4a9f.png)

浏览器完全按照我们的指示进行了搜索

  

当然我们可以有不同的搜索方式，下面是一个xpath的例子

  

```

```

*   
*   
*   
*   
*   
*   

```
from selenium import webdriverdd = webdriver.Firefox(executable_path=r'geckodriver.exe')dd.get("https://www.baidu.com/")
dd.find_element("xpath","//*[@id='kw']").send_keys("大学生网络安全尖锋训练营")dd.find_element("id","su").click()
```

**4******浏览器简单操作  
****  

  

利用set\_window\_size(长，高)我们可以调节窗口**大小**

利用set\_window\_position(x,y)我们可以调节窗口**位置**  

利用refresh()可以完成**刷新**

通过back()和forward()我们可以完成网页的**前进和后退**

通过execute\_script()可以**执行js代码**

  

整体代码

  

```

```

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
from selenium import webdriverdd = webdriver.Firefox(executable_path=r'geckodriver.exe')dd.get("https://www.baidu.com/")
dd.find_element("css selector","#kw").send_keys("大学生网络安全尖锋训练营")dd.find_element("id","su").click()
dd.set_window_position(0,0)
dd.refresh()
dd.back()
dd.forward()
dd.execute_script("window.open('https://www.bilibili.com/')")
```
