# 【红旗漫卷西风】写在中国人民解放军建军95周年之际

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODkwMDMxNA==&mid=2247503407&idx=2&sn=712068a5b1a44bdfadbd50fad3ee0315&chksm=fad22c1acda5a50c946fd3fd40ce2c919b61e94a38a5ed10eaa1281d8d1cb93df1fc80ba54ba&scene=126&sessionid=1681655681#rd](http://mp.weixin.qq.com/s?__biz=MzUzODkwMDMxNA==&mid=2247503407&idx=2&sn=712068a5b1a44bdfadbd50fad3ee0315&chksm=fad22c1acda5a50c946fd3fd40ce2c919b61e94a38a5ed10eaa1281d8d1cb93df1fc80ba54ba&scene=126&sessionid=1681655681#rd)

    军旗猎猎，又逢八一。  
    今年8月1日是第95个建军节，同盛夏一样炙热的，是中国军人的热血军魂。今天我们回首激情燃烧的革命岁月，尽数苦难辉煌的烽火征程，致敬铁骨铮铮的中国军人。  
　　1927年8月1日，伴随南昌起义一声枪响，一支新型的人民军队登上历史舞台，揭开了中国共产党独立领导武装斗争和创建革命军队的序幕。“军叫工农革命，旗号镰刀斧头。”点点星火迅成燎原之势，中国革命的历史新纪元开启了。  
　　从南昌城头雨到井冈山上风，从大渡河的激浪到太行山的古松，伟大的人民军队数次反“围剿”始终长缨在手，踏上长征路不怕风雨如磐；折断了日寇的尖刀，突破国民党的封锁；跨过鸭绿江保家卫国，驻守国境线筑牢边防……如今，从搏击云天到挺进深蓝，面对洪流滚滚、山崩地裂、疫情暴发，人民军队无畏无惧、冲锋在前，尽显英雄本色。  
　　“雄关漫道真如铁，而今迈步从头越。”95年的峥嵘岁月见证了人民军队的浴血荣光。在中国共产党的领导下，在血与火的斗争中，中国军人始终与中华民族命运共系，与中国人民血肉相连，为人民解放、民族独立、国家富强英勇战斗。  
　　2019年7月31日，习近平主席为“排雷英雄战士”荣誉称号获得者杜富国佩挂英模奖章、颁发证书。失去双眼双手的杜富国举起手肘，向习主席敬了一个特殊军礼。习主席亲切地拍着他的肩膀，深情叮嘱他把身体养好。今年7月27日，习近平主席为获得“八一勋章”的杜富国佩挂勋章、颁发证书，同他合影留念。  
　　没有从天而降的英雄，只有挺身而出的凡人。从战争年代的硝烟到和平年代的风雨，在当前国际环境更趋复杂严峻的背景下，中国军人赤胆忠心，舍生忘死，以血肉之躯铸起保卫国家人民安全的钢铁长城。军人的坚守、英雄的不朽，是一个国家民族最闪亮的坐标，让他们享有尊崇的地位和待遇，是不容回避的时代课题。  
　　“该保障的要保障好，该落实的政策必须落实，不能让英雄流血又流泪。”党从领导建立人民军队之日起，就高度关注军人地位和权益保障。这是我们党领导军队建设的重要经验，是人民军队成长壮大、从胜利走向胜利的重要保证。  
　　2021年6月10日，十三届全国人大常委会第二十九次会议表决通过《中华人民共和国军人地位和权益保障法》，该法自2021年8月1日起施行。作为一部全面规范军人地位和权益保障的基础性、综合性法律，施行一周年以来，军人地位和权益保障法在维护军人荣誉、保障军人待遇、优待抚恤军属等方面展现出一派崭新气象。  
军人地位和权益保障法治化、体系化、精确化  
　　从福建、浙江检察机关办理军人地位和权益保障法实施后本省首例该领域公益诉讼案件，到《军人及军队相关人员医疗待遇保障暂行规定》等一系列利军惠兵好政策出台，从法律实施到政策完善，军人待遇保障制度更加系统化，军人地位权益保障内容更加精细化，切实为军人解除后顾之忧。  
弘扬拥军爱军理念，尊崇军人礼遇军人蔚然成风  
　　颁授“八一勋章”、全国所有运输机场开通军人依法优先通道、悬挂“光荣之家”牌匾和送立功喜报……彰显尊崇军人的具体措施更加明确规范，军人荣誉体系更加健全完善。政府部门、社会组织、新闻媒体等各行各业学习宣传军人地位和权益保障法，推动形成尊崇军人、礼遇军人的浓厚氛围和良好风尚。  
厚植强军兴军根基，激励广大军人履行职责使命  
　　“逐梦海天的强军先锋”张超、新时代卫国戍边英雄群体、火箭军“东风第一旅”等一大批模范人物和先进单位涌现，凝聚军心，鼓舞士气，激励全军将士有效履行职责使命。广大适龄青年踊跃应征入伍，今年上半年，多地入伍新兵中大学生占比超过70%，高素质人才正源源不断汇入强军洪流。  
　　“崇尚英雄才会产生英雄，争做英雄才能英雄辈出。”包含军人地位和权益保障法在内，国防法、退役军人保障法、兵役法、英雄烈士保护法等法律，都围绕提升军人社会地位、职业荣誉、待遇保障等方面作出了明确规定，共同唱响维护军人尊崇地位、保障军人合法权益的时代赞歌，真正让军人成为全社会尊崇的职业。献身国防、矢志强军的无悔追求深深植根于军人的血脉中，崇敬军人、关爱军人的坚定信念正成为全社会的价值引领和共同遵循。  
　　一身戎装，一世英雄。从95年前石破天惊第一枪，到如今神州大地上遍地军旗迎风扬，面对千山关隘、万水激流，中国军人忠诚本色历久弥坚，为民情怀澎湃依旧。嘹亮军歌不会忘记，边关明月不会忘记，山川大河不会忘记，祖国人民不会忘记——红旗漫卷西风，军魂永远沸腾！
