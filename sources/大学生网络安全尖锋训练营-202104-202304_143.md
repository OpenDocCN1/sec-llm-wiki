**【学习园地】Cs二次开发准备**

**1****

## ****反编译****

**  

  

建立两个文件CS\_old用来存放cobaltstrike.jar文件，CS\_new用来存放反编译cobaltstrike.jar后的文件，之后我们使用IDEA自带的反编译工具java-decompiler.jar对cobaltstrike.jar进行反编译操作，使用命令

java -cp java-decompiler.jar org.jetbrains.java.decompiler.main.decompiler.ConsoleDecompiler -dgs=true cobaltstrike.jar ../CS\_new/

工具会开始对cobaltstrike.jar进行反编译

![](../Images/b8f49ba7dd4737d012d6da4253a7b4a8.png)

获得的结果是jar包的形式，可以将其解压就可得到所有的JAVA文件了

![](../Images/746cb2091d82f186177a6341f53d03fe.png)

  

**2****

## ****配置新项目****

**  

  

先建立一个decompiled\_src文件夹放源码，之后再建立一个lib文件夹放依赖（cobaltstrike.jar）。

![](../Images/3d2ecc2dc3235f5227a3747c120828c7.png)  

将反编译好的cobaltstrike.jar解压到cs\_src，将未反编译的cobaltstrike.jar放到lib中

接下来我们设置项目依赖

文件->项目结构->+->选择刚才放到lib文件的cobaltstrike.jar

![](../Images/a500340d9d5b103a43bd0cee17f19d3b.png)

接下来设置工件，左侧工件->+->JAR->来自具有依赖项的模块，主类填入

aggressor.Aggressor

![](../Images/4f1e85f52a9a4ffdb27da633c3e3c28b.png)

在创建项目时本来就有的src文件中建立一个aggressor文件

![](../Images/fce993348d5b9850d1bd20dde4cee288.png)

接下来cs\_src中找到已经反编译完的aggressor主类

![](../Images/3318fe6c63157c1ba7503548a788be32.png)

将其复制到src文件下的aggressor文件

![](../Images/6552e785663cb2c972e0a1d3b849e806.png)

现在我们可以看到主类的源代码了

![](../Images/d2f239079dadf847f0e8e2e27389789b.png)

我们可以对其修改在main中加入

```
JOptionPane.showMessageDialog(**null**,**"****你好，网安****"**);
```

来显示一下信息，之后点击构建->构建工件->构建

![](../Images/e11cbc5e4eccbc13d5d134718cd7679f.png)

可以在我们的out文件下找到我们新的jar文件
