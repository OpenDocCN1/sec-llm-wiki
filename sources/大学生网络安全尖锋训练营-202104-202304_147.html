PyQt



PyQt实现了一个Python模块集。它有超过300类，将近6000个函数和方法。它是一个多平台的工具包，可以运行在所有主要操作系统上，包括UNIX，Windows和Mac。今天训练营带大家利用qtdesigner快速制作桌面应用

Qtdesigner


使用Python设计GUI界面的时候，使用纯代码进行GUI设计实在有点不太直观便捷，于是PYQT和PySide都提供了一个统一的工具QTdesigner来辅助设计

这是我们打开QTdesigner的一个画面，刚刚下载安装好后是英文的可以通过下载designer_zh_CN.qm汉化包，然后复制粘贴进入对应的目录即可

..\QTDesigner\translations

之后我们新建一个Main Window窗体


左边的栏位是我们控件栏右边是空间对应的属性，有点类似我们前几期的Unity布局。

这里训练营将制作一个简单计算器作为演示，从左边拖入一个LineEdit控件,并在右边的属性栏位QObject下修改对象名字为showEdit,这个将作为计算器的显示器

之后修改点大小为20，这样我们呈现的字体可以相对大一点，我们借鉴windows自带的计算器布局拖入PushButton并修改点大小和加粗


之后根据我们需要的数量进行复制并放置到对应的位置根据Button的功能对对象进行命名比如：按钮7为Button_7。当然也可以按你的喜好进行命名


这样我们的计算器页面就做好了,接下来我们对其进行一些美化，比如添加一个背景，我们可以使用QT的样式表右键背景->编辑样式表->添加颜色->background color


QT自定义几乎是没有上限的选择一个喜欢的颜色点击APPLY即可

如果不想修改按钮的颜色也可以这样操作添加一个list view右键->放到后面

之后对list view修改样式表，重复刚才的操作

大功告成，当然如果想要让背景更活跃一点也可以添加动图这个我们放在结尾讲。

功能实装


建立一个新项目，并下载PYQT6

保存刚才设计好的ui放到新项目的文件里之后右键项目打开于终端

输入以下命令

pyuic6 -o uitest.py untitled.ui

就可以看到pyqt已经将我们的ui文件转换为python文件马上可以直接使用了

建立一个新的python文件，输入以下导入

from PyQt6 import QtWidgets
from uitest import Ui_MainWindow

之后构建一个继承类用来封装所有计算器的功能

class myMain(QtWidgets.QMainWindow,Ui_MainWindow):    def __init__(self):        super(myMain, self).__init__()        self.setupUi(self)

接下来完成入口并调用类
if __name__=="__main__":    app = QtWidgets.QApplication(sys.argv)    ui_add = myMain()    ui_add.show()    sys.exit(app.exec())
app = QtWidgets.QApplication(sys.argv)
sys.exit(app.exec())
这两条代码是保证我们的点了右上角叉子程序能正常退出，我们尝试进行启动
启动正常，但是此时计算器还不具备功能，我们需要通过python代码让其拥有计算器的功能，还记得我们刚才的命名的那些QObject么可以通过我们的命名进行调用，比如程序启动后我们的显示器就会有个1+1很难受可以通过Qtdesigner修改也可以这样来修改
在我们建立的类下输入代码
self.showEdit.clear()
这个时候再运行下试试，发现我们的1+1已经没了
之后我们来建立按钮事件
self.Button_0.clicked.connect()
connect中的括号是按钮一旦被点了所执行的方法所以我们需要再定义一个方法
def _print(self,print_char):    self.showEdit.insert(print_char)#输入对象
之后给每个按钮信号连接对应的方法
self.Button_0.clicked.connect(lambda:self._print('0'))self.Button_1.clicked.connect(lambda: self._print('1'))self.Button_2.clicked.connect(lambda: self._print('2'))self.Button_3.clicked.connect(lambda: self._print('3'))self.Button_4.clicked.connect(lambda: self._print('4'))self.Button_5.clicked.connect(lambda: self._print('5'))self.Button_6.clicked.connect(lambda: self._print('6'))self.Button_7.clicked.connect(lambda: self._print('7'))self.Button_8.clicked.connect(lambda: self._print('8'))self.Button_9.clicked.connect(lambda: self._print('9'))self.Button_add.clicked.connect(lambda: self._print('+'))self.Button_sub.clicked.connect(lambda: self._print('-'))self.Button_eq.clicked.connect(lambda: self._print('='))self.Button_div.clicked.connect(lambda: self._print('/'))self.Button_dot.clicked.connect(lambda: self._print('.'))self.Button_tim.clicked.connect(lambda: self._print('*')
现在我们就能输入任何按键了
接下来我们需要让计算器计算给出的算式，还记得我们上一期的exec么我们可以用那个函数进行执行，但是这里有一些小变化由于我们需要获取结果就需要调用exec内部执行的变量，而在方法下的变量我们接收不到例如
def tests():    exec("b=1+1")    print(b)
tests()
这样的代码b是无法被检测到的，因为exec函数执行的时候相当于开辟了一块新的地方，而b在那个新的地方我们并没有它的控制域，这里有个粗暴的方法可以直接将b转换为全局变量即
a = self.showEdit.text()a = "b=" + str(a)exec(a, globals())self.showEdit.clear()self.showEdit.setText(str(b))
这样我就能获取到b的值，好的现在所有的功能已经完成

整体代码：

import sys
from PyQt6 import QtWidgetsfrom uitest import Ui_MainWindow
class myMain(QtWidgets.QMainWindow,Ui_MainWindow):    def __init__(self):        super(myMain, self).__init__()        self.setupUi(self)        self.showEdit.clear()        self.Button_0.clicked.connect(lambda:self._print('0'))        self.Button_1.clicked.connect(lambda: self._print('1'))        self.Button_2.clicked.connect(lambda: self._print('2'))        self.Button_3.clicked.connect(lambda: self._print('3'))        self.Button_4.clicked.connect(lambda: self._print('4'))        self.Button_5.clicked.connect(lambda: self._print('5'))        self.Button_6.clicked.connect(lambda: self._print('6'))        self.Button_7.clicked.connect(lambda: self._print('7'))        self.Button_8.clicked.connect(lambda: self._print('8'))        self.Button_9.clicked.connect(lambda: self._print('9'))        self.Button_add.clicked.connect(lambda: self._print('+'))        self.Button_sub.clicked.connect(lambda: self._print('-'))        self.Button_eq.clicked.connect(lambda: self._print('='))        self.Button_div.clicked.connect(lambda: self._print('/'))        self.Button_dot.clicked.connect(lambda: self._print('.'))        self.Button_tim.clicked.connect(lambda: self._print('*'))

    def _print(self,print_char):        if(print_char == "="):            a = self.showEdit.text()            a = "b=" + str(a)            exec(a, globals())            self.showEdit.clear()            self.showEdit.setText(str(b))        else:            self.showEdit.insert(print_char)

if __name__=="__main__":    app = QtWidgets.QApplication(sys.argv)    ui_add = myMain()    ui_add.show()    sys.exit(app.exec())
