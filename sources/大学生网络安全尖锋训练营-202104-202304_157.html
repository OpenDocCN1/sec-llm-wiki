【学习园地】为对象添加Cs脚本

1

Csharp



和JAVA语言一样Csharp(C#)都属于高级编程语言并且都是面向对象的。主要集中应用桌面编程，WEB编程，游戏编程领域，还可以做移动开发。那么我们上一期已经创建好了一个平台和一个物体（紫色小球），那么今天训练营带大家利用C#脚本让小球动起来。


2
创建一个Csharp脚本


首先点击我们的小球 ->添加组件->new script->给脚本起个名字，训练营这里是movement


此时可以看到我们的资产栏下已经生成了一份Cs脚本，双击打开（需要Visual Studio），此时我们可以看到Unity初始化好的一份脚本模板


using System.Collections;using System.Collections.Generic;using UnityEngine;
public class movement : MonoBehaviour{    // Start is called before the first frame update    void Start()    {            }
    // Update is called once per frame    void Update()    {            }}

这里的有两个函数Start()、Update()，其中Start()代表了启动游戏场景时所做的操作，而Update()代表了这个操作不做一次而是伴随着游戏场景的运行而一直运行下去，可以将其理解为一个死循环while(true)

我们输入第一个Cs代码

    void Start()    {        Debug.Log("Game Start");    }

在启动时输出"Game Start"启动游戏后可以在控制台中看到

接下来我们可以为刚体创建一个对象，用来继承刚体，进而对该物体的物理特性在代码上进行操作加一条

public Rigidbody testForce;

我们便可以观察到我们新建的脚本下多出了一个选项，然后我们把小球的Rigidbody拖到选项上

然后可以在start下输入代码

    void Start()    {        testForce.AddForce(600, 0, 0);    }

即对X轴的正方向上施加一个力使其可以到X=600的位置，我们再测试下场景

可以看到小球收到X轴正方向的力向右移动了，不再是直直的落下


3
移动


我们重新回到Visual Studio中，重新添加三个变量和两个对象
    public float SPEED;    private float horizontalMove,verticalMove;    private Vector3 dir;    public CharacterController cc;



其中SPEED是控制我们整体的速度，horizontalMove,verticalMove代表了前后左右移动，Vector3 dir负责记录移动的方向，CharacterController cc是Unity的组件，包含了物理的碰撞和刚体。

在Start下初始化我们的CharacterController对象cc

    void Start()    {        cc = GetComponent<CharacterController>();
    }

在Update中通过

        horizontalMove = Input.GetAxis("Horizontal") * SPEED;        verticalMove = Input.GetAxis("Vertical") * SPEED;

来监听键盘的WASD来控制小球的前后左右移动。其中Horizontal和Vertical则是Unity自带的变量，可以在编辑->输入管理器->轴线中进行查看

通过

dir = transform.forward * verticalMove + transform.right * horizontalMove;

记录物体的移动

因为我们Update函数的重复速度默认以电脑屏幕的刷新速度为准，比如你的电脑刷新速度为144那么update在每秒钟执行了144次，这就导致了物体的速度不再是由SPEED单独决定而是SPEED和刷新率共同决定，这并不是我们希望的，所以加上

cc.Move(dir * Time.deltaTime)

来限制移动的速度不要那么快，也相当于抵消掉了刷新率对速度带来的影响。

整体代码

using System.Collections;using System.Collections.Generic;using UnityEngine;
public class movement : MonoBehaviour{    public float SPEED;    private float horizontalMove,verticalMove;    private Vector3 dir;    public CharacterController cc;    // Start is called before the first frame update    void Start()    {        cc = GetComponent<CharacterController>();
    }
    // Update is called once per frame    void Update()    {        horizontalMove = Input.GetAxis("Horizontal") * SPEED;        verticalMove = Input.GetAxis("Vertical") * SPEED;
        dir = transform.forward * verticalMove + transform.right * horizontalMove;        cc.Move(dir * Time.deltaTime);    }}

接下来我们像刚才绑定刚体那样，对CharacterController组件进行绑定

最终测试场景，可以看到小球现在收到我们的键盘控制。
