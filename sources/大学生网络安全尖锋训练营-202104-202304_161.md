## **pyinstaller**

在我们完成python项目时可以对其进行导出变为exe可执行文件，这样可以极大增加python项目使用的方便程度，也使得我们的项目可以更好的完成传播，使得没有python环境的系统也可以运行我们的项目。  

  

**2****pyinstaller打包**  

  

```

```

对我们上一期的被控端进行打包，首先下载安装pyinstaller

pip install pyinstaller

然后在文件位置中找到我们上一期的被控端py文件，然后输入指令

pyinstaller -F -w pymuma\_target.py

这里的参数-F是代表打包一个py文件，而-w是在py运行时不弹出命令行窗口

  

![](../Images/57eb28f1708531036dc47ed45dd208cc.png)

  

在导出完成后我们可以在dist文件下找到被导出的exe文件，但是在检视exe文件时可以发现文件足足有90MB的大小，这是因为pyinstaller在导入时会把所有依赖库全部打包，但是我们在项目中可能用不到那么多的库，所以我们可以在import项目时仅将需要的方法进行导入，就可以缩小pyinstaller导出的大小。

  

**3****Nuitka进行打包**  

  

该工具首先将 py 文件转成 c 文件，然后编译成 .o 文件，最后合并成 .bin 可执行文件，从 bin 到 C 是不可逆的，从 C 到 Python 也是不可逆的，因此代码是安全的。工作量小，安全性高，使用加密之后的 Python 便捷；但编译时间长，过程复杂。  

使用代码

pip install Nuitka

安装Nuitka，在安装完Nuitka后我们还需要安装C编译器。

然后在文件位置中找到我们上一期的被控端py文件，然后输入指令

  

python -m nuitka --follow-imports --standalone main.py

  

![](../Images/109403eb8b72c1c11671c449530d5416.png)

  

可以看到打包成exe的单个文件要比pyinstaller要小，但是需要多文件完成exe的依赖

  

\--follow-imports 导入所有库

\--standalone 不需要python环境

\--windows-disable-console 取消命令行弹框
