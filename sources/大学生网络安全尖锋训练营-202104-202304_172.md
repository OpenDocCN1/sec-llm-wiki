# 【小满】最爱垄头麦，迎风笑落红

![](../Images/db4d102073d945a59dad4312abf46d5a.png "null")**小****满****诗****意****《小满》**\[宋\] 欧阳修夜莺啼绿柳，皓月醒长空。最爱垄头麦，迎风笑落红。![](../Images/e7d30ac61b23c9328311806c390183bd.png)【解读】  

小满时节，宋代诗人欧阳修漫步于田埂之上，夜莺啼鸣，皓月当空，麦穗随风摇摆，一派惬意闲适之美。

![](../Images/c06da1c39c88ddbca2723f7bfb9ed25c.png)**一候苦菜秀**

此时节麦子青黄不接，苦菜却生长繁茂，遍布四海，古时百姓在这个时期常采摘苦菜充饥。小满时暑气开始侵蚀，此时吃苦菜，刚好降火消暑。

![](../Images/c06da1c39c88ddbca2723f7bfb9ed25c.png)**二候靡草死**

此时节一些枝条细软、喜阴的草类在强烈的阳光下开始枯死，说明各地开始正式步入夏天。

![](../Images/c06da1c39c88ddbca2723f7bfb9ed25c.png)**三候麦秋至**

此时节麦子开始成熟。虽是夏季，对麦子来说却到了成熟的“秋”，新鲜麦穗可尝出甘甜之味。
