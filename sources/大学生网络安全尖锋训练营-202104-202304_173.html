【学习园地】搭建简单聊天室

1

Socket



Socket是应用层与TCP/IP协议族通信的中间软件抽象层，它是一组接口。在设计模式中，Socket其实就是一个门面模式，它把复杂的TCP/IP协议族隐藏在Socket接口后面，对用户来说，一组简单的接口就是全部，让Socket去组织数据，以符合指定的协议。今天训练营带大家利用python和Socket搭建一个简单的个人聊天室


2
思路


我们建立一个服务端为我们的客户端进行服务，首先我们希望服务端实现这么几点

  • 检查（监听）客户端的连接

  • 同时服务多个客户

  • 转发消息

接下来我们希望客户端可以实现以下的功能

  • 拥有一个简洁的前端

  • 可以看到所有聊天室用户的消息

  • 自己可以编辑消息进行发送

最终形成很多客户端和一个服务端的结构


3
服务端


首先我们先构建一个服务端第一步构建一个Socket对象（创建一个套字节）


server = socket(AF_INET, SOCK_STREAM)


套接字最初是为同一主机上的应用程序所创建，使得主机上运行的一个程序（又名一个进程）与另一个运行的程序进行通信。这就是所谓的进程间通信（Inter Process Communication，IPC）

有基于文件的和面向网络的两种套字节

1.AF_UNIX

这是基于文件的，类似地，AF_LOCAL（在2000～2001年标准化）将代替AF_UNIX

2.AF_INET

这是面向网络的，另一个AF_INET6用于第6版因特网协议（IPv6）寻址。目前，在面向网络中AF_INET是使用得最广泛的


调用bind()函数把自己绑定在一个地址上

bind(("你的IP", 端口号))

再使用listen()确定接入数目

server = socket(AF_INET, SOCK_STREAM)
server.bind(("", 2341))  # 端口
server.listen(5)
print('等待接入')


再创建一个列表用来存放接入的用户。

使用一个无限循环的函数来监听接入的请求，定义监听

new_s, addr = server.accept()

其中new_s记录套字节信息，addr记录地址和端口。

接下来我们使用Thread来创建线程，为收和发服务。

t1 = threading.Thread(target=shou, args=(new_s, users_list))

然后构建我们的收发功能

接受套接字的数据。数据以字符串形式返回，括号内的变量是指定最多可以接收的数量。

new_s.recv(1024).decode('utf-8')

首先我们需要确定进来的人是谁，所以我们进行第一次确定昵称的工作

nikename = new_s.recv(1024).decode('utf-8').strip()

接下来我们建立一个无限循环来不断接收信息

while 1:
    recv_data = new_s.recv(1024).decode('utf-8')

    for i in socket_list:

        i.send(f'{nikename}:{recv_data}'.encode('utf-8'))  # 广播

但是目前还并不够，我们需要做一个异常判定因为中途如果有用户退出那么我们的服务端会报错

因为没有删除对应退出的套字节那么在第二次使用时服务端会直接崩溃

所以我们针对=报错设置一个try对错误进行处理

try:
    nikename = new_s.recv(1024).decode('utf-8').strip()
except:
    new_s.close() #关闭一个套字节
    socket_list.remove(new_s)  # 去除套字节里面残留的信息防止下次有人进来卡死
    for i in socket_list:
        i.send('\n公告:一个未知的人离开了聊天室......'.encode('utf-8')) # 处理再输入用户名之前的人退出由于我们不知道他的用户名所以需要处理
    return None
for i in socket_list:
    i.send(f'\n公告:欢迎{nikename}进入了聊天室........\n'.encode('utf-8'))
while 1:
    try:
        recv_data = new_s.recv(1024).decode('utf-8')
        print(recv_data)  # 在服务端记录
        for i in socket_list:
            i.send(f'{nikename}:{recv_data}'.encode('utf-8')) # 发用户信息
    except:
        new_s.close()
        socket_list.remove(new_s)
        for i in socket_list:
            i.send(f'公告:{nikename}离开了聊天室......'.encode('utf-8'))  # 广播
        break


到这里我们服务端的基本功能都已经做完了。


4
客户端




客户端中我们的重点要放在前端制作的问题上，首先我们导入tkinter库，这个库可以帮助我们进行UI制作


首先还是创建套字节

custome = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
custome.connect(("127.0.0.1", 34426))

print('已连接')


初始化一个tk对象，并使用title()确定窗口题目

app = tk.Tk()
app.title('聊天室')


设计消息框

msg_frame = tk.Frame(app, width=480, height=300)  # 确定窗口大小
msg_frame.grid(row=0, column=0, padx=100, pady=3)  # padx和pady控制控件的位置，row和column表示某个控件要放在第几行网格或第几列网格，下标都是从0开始计的
msg_frame.grid_propagate(False)  # 固定Frame的大小
msg_text = tk.Text(msg_frame, bg='white')
msg_text.grid()


输入框

input_frame = tk.Frame(app, width=480, height=100)
input_frame.grid(row=1, column=0)
input_frame.grid_propagate(False)
input_text = tk.Text(input_frame, bg='white')
input_text.grid()


发送框

btn_frame = tk.Frame(app, width=480, height=20)
btn_frame.grid(row=2, column=0, sticky='E')
button = tk.Button(btn_frame, text='发送', command=fa) # command表示事件激活函数
button.grid()



接下来我们制作发送函数

将输入框的内容发送出去，最后对输入框内容进行清除。

def fa():
    msg = input_text.get('0.0', tk.END)
    custome.send(msg.encode('utf-8'))
    input_text.delete('0.0', tk.END)


建立接收模块

def shou(s, msg_text):
    while 1:
        recv_data = s.recv(1024).decode('utf-8')
        msg_text.insert(tk.END, recv_data)


建立线程为接收模块服务并启动整个UI界面

t1 = threading.Thread(target=shou, args=(custome, msg_text))
t1.daemon = True
t1.start()
app.mainloop()
