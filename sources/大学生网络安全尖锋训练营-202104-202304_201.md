# 【尖锋讲堂】2022年度精英百强赛前培训即将开始

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODkwMDMxNA==&mid=2247501306&idx=1&sn=f57abff4cdabb3250fbb1c35b6724438&chksm=fad227cfcda5aed93d94a85c7fc70a888176c46d27444ea7d3da19ae51c5f085dd80c9c8952c&scene=126&sessionid=1681655716#rd](http://mp.weixin.qq.com/s?__biz=MzUzODkwMDMxNA==&mid=2247501306&idx=1&sn=f57abff4cdabb3250fbb1c35b6724438&chksm=fad227cfcda5aed93d94a85c7fc70a888176c46d27444ea7d3da19ae51c5f085dd80c9c8952c&scene=126&sessionid=1681655716#rd)

**2022精英百强尖锋讲堂**![](../Images/a162ca324f9fdac5eff72c229b819a75.png)

    2022年度精英百强大赛初赛现已正式开启。

    训练营在报名时提供了八种资源以供学员开发选用，八种资源包括：龙芯云平台线上环境、龙芯云主机及 Docker 容器、龙芯国密云平台线上环境、龙芯1号开发板套件、基于龙芯平台的跨平台桌面应用开发工具、安天终端系统日志提取 SDK、安天端点响应框架 SDK、昆仑固件开发环境。

    为方便参赛学员更好地使用相关资源，完成开发。训练营邀请到相关资源厂商的工程师，将为同学们提供在线课程指导，相关资源也将随课程同步发放。
