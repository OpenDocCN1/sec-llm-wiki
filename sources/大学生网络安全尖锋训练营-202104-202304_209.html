【学习园地】Matplotlib

1

Matplotlib



是一个Python 2D绘图库，它以多种硬拷贝格式和跨平台的交互式环境生成出版物质量的图形。它可与Numpy 一起使用，提供了一种有效的 MatLab 开源替代方案，也可用于Python脚本，Python和IPython (opens new window)Shell、Jupyter (opens new window)笔记本，Web应用程序


使用Matplotlib可以帮助我们进行可视化处理

可视化是在整个数据挖掘的关键辅助工具，可以清晰的理解数据，从而调整我们的分析方法。

  • 能将数据进行可视化，更直观的呈现

  • 使数据更加客观、更具说服力




以及可以帮助我们更好的理解神经网络

使用示例



    生成一个坐标系

from matplotlib import pyplot as plt
fig = plt.figure()ax = fig.add_subplot(111)ax.set(xlim=[0, 10], ylim=[0, 10], title='坐标系的名字',       ylabel='Y轴名字', xlabel='X轴名字')

plt.show()


3

基本绘图2D



绘制线

我们可以使用函数plot()

来绘制一系列的点，并且用线将它们连接起来

例如：

from matplotlib import pyplot as plt
fig = plt.figure()ax = fig.add_subplot(111)ax.set(xlim=[0, 10], ylim=[0, 10], title='Test',       ylabel='Y', xlabel='X')
plt.plot([1,7],[4,5],color='black',marker='+')
plt.show()


绘制散点

使用scatter()函数绘制散点

import random
from matplotlib import pyplot as plt
fig = plt.figure()ax = fig.add_subplot(111)ax.set(xlim=[0, 10], ylim=[0, 10], title='Test',       ylabel='Y', xlabel='X')
for i in range(0,10):       x = random.randint(0,9)       y = random.randint(0,9)       plt.scatter(x, y, color='red', marker='+')
plt.show()


需要注意matplotlib的作用在于展示数据，关于处理数据我们还需要靠代码完成


绘制条形图

使用bar()函数

import matplotlib.pyplot as pltplt.rcParams['font.sans-serif'] = ['SimHei']  # 用来正常显示中文标签plt.rcParams['axes.unicode_minus'] = False    # 用来正常显示负号fig = plt.figure()ax = fig.add_subplot(111)ax.set(xlim=[0, 10], ylim=[0, 50], title='Test',       ylabel='Y-Axis', xlabel='X-Axis')langs = ['农业', '工业', '服务业', '保障', '科研']a = [30,19,45,30,25]ax.bar(langs,a,color='b')plt.show()

3D绘图




需要额外导入mpl_toolkits.mplot3d包


import matplotlib.pyplot as pltfrom mpl_toolkits.mplot3d import Axes3D
fig = plt.figure()ax = Axes3D(fig)
ax.scatter(5, 6, 7, marker='+', s=100)  # s为大小plt.show()
