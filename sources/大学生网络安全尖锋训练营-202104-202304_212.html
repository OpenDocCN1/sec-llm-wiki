【学习园地】配置torch

1

pytorch



它是一个基于python的科学计算库，致力于为两类用户提供服务：

  1. 一些想要找到Numpy搭建神经网络替代品的用户；

  2. 寻找一个可提供极强的可拓展性和运行速度的深度学习研究平台；


2
可能会出现的问题



    我们在安装torch时如果只是去使用pip install torch命令的话可能会出现与CUDA不匹配的情况，进而会影响我们后期神经网络的训练如何查看是否匹配呢，我们可以在导入后输入以下代码进行查看

import torch
print(torch.cuda.is_available())

如果结果为false那么有可能时torch版本与CUDA版本不匹配的情况在控制台中输入nvidia-smi对可以对CUDA版本进行查看


此时我们可以访问torch的官网去寻找对应的CUDA版本进行下载

https://pytorch.org/get-started/previous-versions/

但是这里可能又会出现问题，如果我目前的CUDA版本没有对应支持的torch版本该怎么办？


3

Anaconda



那么下一步给大家推荐Anaconda环境

Anaconda是一个用于科学计算的Python发行版，支持 Linux、 Mac、Windows系统，提供了包管理与环境管理的功能，可以很方便地解决多版本python并存、切换以及各种第三方包安装问题。

Anaconda是一个打包的集合，里面预装好了conda、某个版本的python、众多packages、科学计算工具等，其中conda是用来进行包管理与
环境管理的工具/命令。

https://www.anaconda.com/

我们可以去Anaconda官网上下载Anaconda3，安装时记得勾选add to path将它添加到我们的环境变量中。

好消息是pycharm还可以和我们的Anaconda联动使用

在创建新项目时可以把解释器设置到Anaconda安装的文件夹下的python环境中即可

在pycharm中点开下方的终端即可来到项目文件，然后我们可以输入对应的conda命令

conda -V              //获取对应版本号

conda --help//获取帮助

conda create --name your_env_name python=3 //创建对应版本的python


4
conda安装torch




访问torch官网，复制对应命令，放到装载了anacodna环境的pycharm的终端中去执行

conda install pytorch torchvision torchaudio cudatoolkit=11.3 -c pytorch

然后conda就会自动开始下载所需对应的一切，如果下载出现问题可以切换国内镜像

下载完成后再次输入代码

import torchprint(torch.cuda.is_available())

可以发现这次是返回为true的，到此我们的pytorch安装完成，也可以正常使用了
