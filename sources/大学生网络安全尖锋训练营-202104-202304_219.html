【学习园地】Docker部署Seafile

1

Seafile



Seafile是一个开源、专业、可靠的云存储平台；解决文件集中存储、共享和跨平台访问等问题，由北京海文互知网络有限公司开发，发布于2012年10月；除了一般网盘所提供的云存储以及共享功能外，Seafile还提供消息通信、群组讨论等辅助功能，帮助更好的围绕文件展开协同工作。

今天训练营带大家了解并在ubuntu系统的VPS上搭建属于自己的私人网盘


2
需要的准备



搭载了ubuntu系统的VPS以及Docker



3
具体操作


  1. 检查Docker版本

    docker -v

  2. 拉取Seafile的镜像(以下过程需要root)

    docker pull seafileltd/seafile


  3. 运行容器并配置端口

    docker run -d --name target \
      -e SEAFILE_SERVER_HOSTNAME="你的IP" \
      -e SEAFILE_ADMIN_EMAIL="写一个到时候登录管理员的账户" \
      -e SEAFILE_ADMIN_PASSWORD="到时候登录管理员的密码 \
      -v /opt/seafile-data:/shared \
      -p 8000:8000 \
      -p 8082:8082 \
      seafileltd/seafile:latest

  4. 配置防火墙策略

    firewall-cmd --zone=public --add-port=8000/tcp --permanent

    firewall-cmd --zone=public --add-port=8082/tcp --permanent

    8000端口为我们的登录操作的端口，8082为上传下载的端口

    firewall-cmd --reload

  5. 访问云盘

    地址为你的IP加上对应端口8000

    这是登陆后的界面

  6. 配置上传下载

    访问系统管理->设置,修改

    SERVICE_URL:http://"你的IP":8000

    FILE_SERVER_ROOT：http://"你的IP":8082

    如果我们配置了 Nginx/Apache， 这个 URL 的值是 “SERVICE_URL/seafhttp”

如果我们想拿给小伙伴用还可以在访问系统管理->设置，勾选允许用户注册
