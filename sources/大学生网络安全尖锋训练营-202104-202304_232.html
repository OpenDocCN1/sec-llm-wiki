【学习园地】JAVAcommons-beanutils

1
CommonsBeanutils


commons-beanutils是Apache开源组织提供的用于操作JAVA BEAN的工具包。使用commons-beanutils，我们可以很方便的对bean对象的属性进行操作。那么今天训练营带大家了解一下CommonsBeanutils


2
前置准备


CommonsBeanutils 版本为1.8.3

<dependencies>    <dependency>        <groupId>commons-beanutils</groupId>        <artifactId>commons-beanutils</artifactId>        <version>1.8.3</version>    </dependency></dependencies>

可以通过maven进行配置


3
Java Bean


JavaBean是一种JAVA语言写成的可重用组件。为写成JavaBean，类必须是具体的和公共的，并且具有无参数的构造器。JavaBean通过提供符合一致性设计模式的公共方法将内部域暴露成员属性，set和get方法获取。众所周知，属性名称符合这种模式，其他Java类可以通过自省机制(反射机制)发现和操作这些JavaBean的属性。以下的条件是JavaBean的格式

1) 必须提供无参构造器；
2) 类中属性必须私有化（private）；
3) 类中提供公共的getter和setter方法。

在CommonsBeanutils中提供了对JavaBean格式的类进行操作的手段



4

PropertyUtils



比如说我们修改了前几期用的Human类让其符合一个JavaBean的格式，今天主要对PropertyUtils进行介绍，其余的类也可以照着对PropertyUtils类分析的方法自己进行尝试即可

import java.io.IOException;import java.io.ObjectInputStream;import java.io.Serializable;

public class Human_Bean implements Serializable {    private String eye;    private String hair;    private int height;

    public Human_Bean() {    }
    public Human_Bean(String eye,String hair,int height){        this.eye = eye;        this.hair = hair;        this.height = height;    }
    public String getEye(){        return eye;    }
    public String getHair(){        return hair;    }
    public int getHeight(){        return height;    }
    public void print() {        System.out.println(eye);        System.out.println(hair);        System.out.println(height);    }
    private void readObject(ObjectInputStream cmd) throws IOException, ClassNotFoundException {        cmd.defaultReadObject();        Runtime.getRuntime().exec("calc");    }
    @Override    public String toString(){        return "Human{" +                "eye=" + eye +                ", hair='" + hair + '\'' +                ", height='" + height + '\'' +                '}';    }}

之后我们可以在主类中去使用commons.beanutils下的PropertyUtils类来对我们创建的符合JavaBean格式的Human类进行操作getProperty会自动调取对应的get属性的方法

import org.apache.commons.beanutils.PropertyUtils;

public class Test {    public static void main(String[] args) throws Exception{        Human_Bean Zhang_San = new Human_Bean("black","yellow",178);        System.out.println(PropertyUtils.getProperty(Zhang_San,"eye"));    }}

我们可以去查看一下getProperty方法的定义

public static Object getProperty(Object bean, String name)        throws IllegalAccessException, InvocationTargetException,        NoSuchMethodException {
    return (PropertyUtilsBean.getInstance().getProperty(bean, name));

}

可以发现这里又调用了PropertyUtilsBean.getInstance().getProperty继续跟进

public Object getProperty(Object bean, String name)        throws IllegalAccessException, InvocationTargetException,        NoSuchMethodException {
    return (getNestedProperty(bean, name));}

继续跟进getNestedProperty

可以发现这里开始进行JavaBean类型的判断最终我们进入了getSimpleProperty方法，继续跟进可以发现descriptor存储了我们的类的属性和方法

最终返回输出对应的属性，这个就是我们Java Bean以及CB链下的PropertyUtils用法。


5

MethodUtils



MethodUtils通过反射访问对象的方法并且执行方法。

在尝试之前先对我们刚才修改的Human类再加三个对应的set方法

public void setEye(String eye){    this.eye = eye;}
public void setHair(String hair){    this.hair = hair;}
public void setHeight(int height){    this.height = height;}

然后在主类中进行尝试

import org.apache.commons.beanutils.MethodUtils;

public class Test {    public static void main(String[] args) throws Exception{        Human_Bean Zhang_San = new Human_Bean("black","yellow",178);        MethodUtils.invokeMethod(Zhang_San, "setEye", "white");//修改        System.out.println(Zhang_San);    }}

通过MethodUtils.invokeMethod方法我们可以修改已经初始化的类

ConstructorUtils


ConstructorUtils通过反射提供了构造方法相关的便捷操作方法。例如

import org.apache.commons.beanutils.ConstructorUtils;import org.apache.commons.beanutils.MethodUtils;

import java.lang.reflect.Constructor;

public class Test {    public static void main(String[] args) throws Exception    {        Constructor<Human_Bean> constructor = ConstructorUtils                .getAccessibleConstructor(Human_Bean.class, new Class[] {                        String.class, String.class,int.class});        Human_Bean Li_Si = constructor.newInstance("black", "yellow",183);        System.out.println(Li_Si);    }}
