**1**CommonsBeanutils  

  

`commons-beanutils`是Apache开源组织提供的用于操作JAVA BEAN的工具包。使用`commons-beanutils`，我们可以很方便的对bean对象的属性进行操作。那么今天训练营带大家了解一下CommonsBeanutils

**3**Java Bean  
  

  

**JavaBean**是一种JAVA语言写成的可重用组件。为写成**JavaBean**，类必须是具体的和公共的，并且具有无参数的构造器。**JavaBean**通过提供符合一致性设计模式的公共方法将内部域暴露成员属性，set和get方法获取。众所周知，属性名称符合这种模式，其他Java类可以通过自省机制(反射机制)发现和操作这些**JavaBean**的属性。以下的条件是JavaBean的格式

> 1) 必须提供无参构造器；  
> 2) 类中属性必须私有化（private）；  
> 3) 类中提供公共的getter和setter方法。

在CommonsBeanutils中提供了对JavaBean格式的类进行操作的手段

# MethodUtils

  

  

`MethodUtils`通过反射访问对象的方法并且执行方法。

在尝试之前先对我们刚才修改的Human类再加三个对应的set方法

```
import org.apache.commons.beanutils.MethodUtils;
public class Test {    public static void main(String[] args) throws Exception{        Human_Bean Zhang_San = new Human_Bean("black","yellow",178);        MethodUtils.invokeMethod(Zhang_San, "setEye", "white");//修改        System.out.println(Zhang_San);    }}
```

通过MethodUtils.invokeMethod方法我们可以修改已经初始化的类
