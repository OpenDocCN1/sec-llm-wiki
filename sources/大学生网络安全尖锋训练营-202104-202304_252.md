**1**序列化和反序列化  
  

  

    在了解序列化和反序列化之前，我们需要了解的是类、对象、字节序列的概念、

  

>     类就是拥有共同特征的实体（对象）的集合，在面向对象的程序设计语言（例如JAVA）中，类是对一类“事物”的属性与行为的抽象。
> 
>     对象就是类的一个具体的映射，所以对象是一个具体的概念。  
> 
>     类是对象的集合，对象是类的实例;对象是通过new className产生的，用来调用类的方法和类的构造方法。

      

    举一个例子我们整体人类就是一个类，而我们个人就是类下的每一个对象

  

>     字节序列（二进制），用来存储数据，至于这些数据到底表示什么内容（例如：数字、字符串、图片、音频等），完全由程序的解析方式决定。字节序列非常适合在互联网上传输，可以用于网络通信编程。

  

    把**对象**转换为**字节序列**的过程称为对象的序列化。

    把**字节序列**恢复为**对象**的过程称为对象的反序列化。

import java.io.FileOutputStream;import java.io.ObjectOutputStream;
public class Main {    public static void main(String[] args) throws Exception {        Human Zhang_San = new Human("black","black",180);        Zhang_San.print();        serializeHuman();    }
    private static void serializeHuman() throws Exception {        Human Li_Si = new Human("black", "yellow",175);        System.out.println("=================开始序列化================");        ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("Li_Si.bin"));        oos.writeObject(Li_Si);        oos.flush();        oos.close();    }}

我们分别用张三和李四来对比，张三仅仅进行赋值，而李四是在构造函数赋值之后被序列化，换句话说李四被我们保存在计算机的硬盘里了，而张三随着程序的运行结束从我们的内存中被清除出去了。只要我们再进行反序列化就可以把李四在还原回来，等于说我们通过序列化和反序列化保存了李四，再往抽象的说序列化和反序列化可以帮助我们对数据进行保存

import java.io.FileInputStream;import java.io.FileOutputStream;import java.io.ObjectInputStream;import java.io.ObjectOutputStream;
public class Main {    public static void main(String[] args) throws Exception {        Human Zhang_San = new Human("black","black",180);        Zhang_San.print();        serializeHuman();        UnserializeHuman();    }
    private static void serializeHuman() throws Exception {        Human Li_Si = new Human("black", "yellow",175);        System.out.println("=================开始序列化================");        ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("Li_Si.bin"));        oos.writeObject(Li_Si);        oos.flush();        oos.close();        System.out.println("=================序列化完成================");    }
    private static void UnserializeHuman() throws Exception {        System.out.println("=================开始反序列化================");        ObjectInputStream ois = new ObjectInputStream(new FileInputStream("Li_Si.bin"));        Human Li_Si_2 = (Human) ois.readObject();        ois.close();        Li_Si_2.print();        System.out.println("=================反序列化完成================");    }}
```

**5**安全问题

import java.io.*;
public class Human implements Serializable {    private String eye;    private String hair;    private transient int height;
    public Human(String eyes, String hairs, int heights) {        eye = eyes;        hair = hairs;        height = heights;    }
    public void print() {        System.out.println(eye);        System.out.println(hair);        System.out.println(height);    }
    private void readObject(ObjectInputStream cmd) throws IOException, ClassNotFoundException {        cmd.defaultReadObject();        Runtime.getRuntime().exec("calc");    }
}
```
