批量获取验证码样本


从目标网站入手

import requestsfrom fake_useragent import UserAgentdirpath = "I:/target/"#设定存储路径for i in range(1,201):    url = ""#给出验证码的页面    headers = {"User-Agent": UserAgent().random}  # 获取一个随机请求头    requests.packages.urllib3.disable_warnings()  # 禁用安全警告    r = requests.get(url, verify=False, headers=headers)    savename = dirpath + str(i) + ".png"    with open(savename, 'wb') as f:        f.write(r.content)

通过以上的脚本我们可以先批量下载目标网站生成的验证码，这样最有针对性，训练出来的数据库也更加的有效

处理样本


得到的样本是需要处理的，这样更有利于我们电脑的识别，首先利用python的OpenCv接口配合OS对图片进行批处理，将其灰度化也就是变成黑白的

import cv2import osimport numpy as npdef img_handle(img, outdir):    i = 0    im = cv2.imread(indir + '/' + img)    im_gray = cv2.cvtColor(im, cv2.COLOR_BGR2GRAY)    cv2.imwrite(outdir + '/' + img, im_gray)    i = i + 1

outdir = "I:/target/OK"indir = "I:/target"imlist = os.listdir(indir)
for img in imlist:    img_handle(img, outdir)

之后再将其进行二值化处理，二值化处理就是如果我们看灰度化处理就是我们一般的黑白照片其中的黑色不一定是黑色，还有可能是灰色，但是经过二值化处理后图片就剩下纯黑色和单纯的白色

ret, im_inv = cv2.threshold(im_gray,137,255,cv2.THRESH_BINARY_INV)

再加这样一段代码来进行二值化处理，其中137为像素值的阈值这样我们尽可能优化重要信息帮助电脑进行识别，接下来应用高斯模糊对图片进行降噪。高斯模糊的本质是用高斯核和图像做卷积

import cv2import osimport numpy as npdef img_handle(img, outdir):    i = 0    im = cv2.imread(indir + '/' + img)    im_gray = cv2.cvtColor(im, cv2.COLOR_BGR2GRAY)    ret, im_inv = cv2.threshold(im_gray,137,255,cv2.THRESH_BINARY_INV)    kernel = 1/16*np.array([[1,2,1], [2,4,2], [1,2,1]])    im_blur = cv2.filter2D(im_inv,-1,kernel)    cv2.imwrite(outdir + '/' + img, im_blur)    i = i + 1

outdir = "I:/target/OK"indir = "I:/target"imlist = os.listdir(indir)
for img in imlist:    img_handle(img, outdir)

之后再进行二值化处理进一步减少干扰，这次的二值化的像素值阈值要比第一次小一点具体多少需要进行调试我的是90，经过上面一系列处理之后我们尽可能去除了干扰并保留了图片的重要信息，接下来需要转换我们的格式为tiff

import globfrom PIL import Imagefor i in glob.glob(r'I:\target\OK\*.png'):    im = Image.open(i,"r")    print(i.split(".")[0])    im.save("{}.tif".format(i.split(".")[0]),quality=95)


4
准备训练



安装Tesseract

OCR，即Optical Character Recognition，光学字符识别，是指通过扫描字符，然后通过其形状将其翻译成电子文本的过程。对于图形验证码来说，它们都是一些不规则的字符，这些字符确实是由字符稍加扭曲变换得到的内容。

官方网址：https://digi.bib.uni-mannheim.de/tesseract/

下载4.0.0版本

安装完成后，需要设置环境变量。在Path中设置C:\Program Files (x86)\Tesseract-OCR，具体位置以自己的为准，之后再额外设置一个TESSDATA_PREFIX的环境变量地址为C:\Program Files (x86)\Tesseract-OCR\tessdata

之后输入Tesseract -v可以进行检查

安装Tesserocr

通过CMD命令行的pip或者pycharm当中安装pytesseract即可，可以先找一张数字图片进行尝试。

下载jTessBoxEditor

在基于tesseract-ocr的图片文字识别中，可以通过jTessBoxEditor 进行训练，以提高图片文字的识别率。

官方下载（较慢）：https://sourceforge.net/projects/vietocr/files/jTessBoxEditor/

注意这里需要使用JDK版本为1.8.0（我使用的具体版本是8u202)


5
训练


合并样本文件并生成BOX文件

打开jTessBoxEditor点击Tools->Merge TIFF将刚才输出好的tif格式全部选择后打开提示需要输入一个合并后的文件名字

pachong.patype.exp0.tif

我们现在相当于是建立一个全新的语言库为识别验证码做数据支持所以pachong为定义的语言，patype定义的字体名称

执行命令

tesseract pachong.patype.exp0.tif pachong.patype.exp0 -l eng -psm 7 batch.nochop makebox

生成BOX文件

校准识别

可以说这是最麻烦枯燥的一步了，我们需要亲自教给 AI识别的验证码,打开jTessBoxEditor然后Box Editor,Open打开刚才合并的样本文件pachong.patype.exp0.tif,程序会自动打开相对应的BOX文件，然后逐一排错把AI识别的错误排除，这里再说一下用法Merge是合并分块；Split剪切分块；Insert插入新的分块,Delete删除选中的分块。纠错完成后就可以点击保存了

生成properties文件

执行echo命令生成font_properties

echo patype 0 0 0 0 0 >pa_properties


生成训练文件

tesseract pachong.patype.exp0.tif pachong.patype.exp0 -l eng -psm 7 nobatch box.train


注意如果训练文件没有生成，建议返回jTessBoxEditor中再查一遍有没有无内容的情况

生成字符集文件

unicharset_extractor pachong.patype.exp0.box 


生成shape文件

shapeclustering -F pa_properties -U unicharset -O pachong.unicharset pachong.patype.exp0.tr


生成聚集字符特征文件

生成3个特征字符文件，unicharset、inttemp、pffmtable


mftraining -F pa_properties -U unicharset -O pachong.unicharset pachong.patype.exp0.tr


生成字符正常化特征文件

执行命令，生成正常化特征文件normproto。

cntraining pachong.patype.exp0.tr


更名

rename normproto patype.normproto
rename inttemp patype.inttemp
rename pffmtable patype.pffmtable
rename unicharset patype.unicharset
rename shapetable patype.shapetable


合并训练文件

combine_tessdata patype.


复制

将生成的patype.traineddata文件复制到

C:\Program Files (x86)\Tesseract-OCR\tessdata


测试

tesseract 6.png output -l patype -psm 7
