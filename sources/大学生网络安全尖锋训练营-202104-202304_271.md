**python爬虫（一）**  
  
**爬虫原理**

浏览网页时，在浏览器里输入一个网址，然后敲击回车，过程实际上就是这个浏览器请求了一些服务器然后获取到了一些服务器的网页资源，然后我们看到了这个网页，例如使用BP进行抓包

![](../Images/d2c77a403ea07a951621abff4b838391.png)

左边是我们对服务器发出的请求，而右边则是服务器对我们返回的资源。

在这一过程中，我们可以通过代码来模拟这个浏览器向服务器发起请求，然后获取这些网页资源。那么一般来说实际上获取的这些网页资源是一串HTML代码，这里面包含HTML标签，还有一些在浏览器里面看到的文字。那么我们要提取的一些数据就包含在这些HTML文本里面。我们要做的下一步工作就是从这些文本里提取我们想要的一些信息（比如一段话，一个手机号，一个文字这类的），这就是我们提取的一个过程。提取出来之后呢我们就把提取出来的信息存到数据库啊文本啊这类的。这就是完成了一个数据采集的过程。

![](../Images/994a343595847c8a0d79bc087ed5e7a9.png)

**前置**

pip install requests

requests中最主要的就是以下方法：

*   
*   
*   
*   

```
requests.get()：获取HTML网页的主要方法，对应于HTTP的GETrequests.head()：获取HTML网页头信息的方法，对应于HTTP的HEAD
requests.post：向HTML网页提交POST 请求的方法，对应于HTTP的POST
```

**请求：**

*   
*   
*   

```
import requestsreq = requests.get("https://www.csdn.net/")print(req.text)
```

以爬取CSDN的首页为例

get()方法下必须有需要爬取的url，而将回显文本化则是req.text

**重新定制请求头：**

有的时候服务器可能会对我们的请求头进行检查，那么我们可以进行一个伪造

*   
*   
*   
*   
*   
*   

```
import requests
header = {"User-Agent":"Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:96.0) Gecko/20100101 Firefox/96.0"}res = requests.get("url",headers=header)
print(res.request.headers)
```

我们可以在BP中看到我们伪造的就是User-Agent

![](../Images/58272a36e793a1e87b098ef367f23626.png)

**cookie伪造：**

服务器在cookie中可以记录我们的登录信息，如果爬虫要爬取的内容是登录才能进行查看的内容，那么伪造cookie是很重要的

*   
*   
*   
*   
*   
*   
*   
*   

```
import requests
url = "url"header = {"User-Agent":"firefox"}coo = {"name":"bob"}
res = requests.get(url=url,headers=header,cookies=coo)print(res.text)
```

**BeautifulSoup**  

BS的使用其目的是帮我们解析爬取下来的html文件，如果对html不加以解析那么就不能对数据进行更好的保存以及可视化

我们通常在使用浏览器时可以使用F12进行前端代码的查看，其主要内容便是HTML

  

### **get\_text()：**

爬取网站时目的便是获取数据，而数据又大多在text文本内容中，那么便可以使用get\_text()

例如

  

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
from bs4 import BeautifulSoup
html = """<html><head><title>这里是主题</title></head><body><p class="story">主要内容</p>"""
soup = BeautifulSoup(html, 'lxml')print(soup.prettify())print(soup.get_text())
```

通过get\_text()便可以得到

这里是主题

主要内容

### **select\_one()：**

一个网页会有很多标签，那么有些标签下的信息是我们不需要用的，所以我们可以通过一些查找函数去把我们需要的信息筛选出来

  

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
from bs4 import BeautifulSoup
html = """<html><head><title>这里是主题</title></head><body><p class="story">主要内容</p>"""
soup = BeautifulSoup(html, 'lxml')#print(soup.prettify())print(soup.select_one('head'))print(soup.get_text())
```

  

通过select\_one('head')我们可以查询当中的<head>标签，如果说我不想再带着标签做输出，那么我们可以在select\_one('head')后面加上.get\_text()

> print(soup.select\_one('head').get\_text())

即可

### **find\_all()：**

> soup.find\_all('p')

查找所有p节点

> soup.find\_all("p", class\_="clazz")

查找所有class为clazz的p节点

  

  

  

**爬虫实例**

掌握了以上的知识时我们就可以爬取一下自己想要的文件，制作一个简单的爬虫

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
from bs4 import BeautifulSoupimport requestsimport timefor i in range(1,20):    req = requests.get("https://www.dlkoo.cc/down/index.asp?act=search&keyword=&movskey=%E7%81%BE%E9%9A%BE&page="+ str(i) +"")    soup = BeautifulSoup(req.text, 'lxml')    for itme in soup.find_all("span", class_="movTi3"):        print(itme.text)    print(i)    time.sleep(5)
```

这个爬虫的目的可以爬取指定页数的所有电影的所有电影名称
