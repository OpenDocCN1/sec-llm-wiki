大学生网络安全尖锋训练营在各界人士的关注和支持下，与大家共同走过了三个年头。过往的一切历历在目，总有万千感慨，落笔却未曾抒发。

为此，我们整理了大学生网络安全尖锋训练营从成立至今3年以来的点点滴滴，其中不乏您的支持与帮助。

三年来，我们坚持以自主创新为底线，坚持以提高实践能力为目标，坚持以解决最后一公里问题为使命，尝试走出一条网安人才培养的创新之路。尽管受到了疫情的影响，大学生网络安全尖锋训练营仍然踔厉奋发、笃行不怠。

不忘初心、方得始终，2022年精英百强大赛将于3月1日正式启动，欢迎老师和同学们积极参与。


# 扬帆启程 #

    2018年6月26日，网络安全人才培养与需求高峰论坛在京举办，网络安全人才淬火“三个一百”工程正式发布。签约百所高校、百所用人单位、百名尖锋导师，与此同时，大学生网络安全尖锋训练营正式启动，尖锋奖学金计划正式发布！



# 首席科学家 #

    为了保证精英百强比赛过程的科学性、严谨性，网络空间安全教指委名誉主任、中国工程院沈昌祥院士担任训练营的首席科学家。

# 尖锋导师 #

    2018年7月，大学生网络安全尖锋训练营公众号上线，于公众号首页开辟“尖锋导师”栏目，展示首届60余位尖锋导师风采。

    截至2022年1月，训练营共签约212名尖锋导师，为“精英百强”大赛学员提供职业规划指导。

# 尖锋招聘 #

    2018年9月12日，“尖锋招聘”系列首次上线，收到近百家用人单位的近万个岗位需求，于每周陆续推出校招岗位，推出岗位近千个，推荐了1500学生实习、就业。2020年，训练营开启专题栏目“尖锋聘”，邀请行业“掌门人”参与招聘过程，为同学们答疑解惑。



# 尖锋课堂 #

    2018年10月9日，“尖锋微课堂”上线，第一年先后推出7节尖锋微课，受众超过2000人。

    

    2018年11月21日，为更好地帮助学员学习网络安全相关知识，在原有尖锋微课堂的基础上，开辟新栏目，“在线课堂”上线，先后共计播出5节线上直播课，受众超1000人。截至2020年1月，19年度“在线课堂”共播出7节直播课，收看人数超过了2000人。


    2020年年初，新冠疫情呼啸而至，深刻地影响了全国人民的生活与学习方式。2020年2月17日开始，训练营借助钉钉平台组织了多场【尖锋课堂】和【在线沙龙】活动，仅在两周内已经吸引了2500多人的关注，钉钉群规模持续扩大。


    2020年3月26日，新华社《经济参考报》和新华网客户端报道了网安尖锋大讲堂。介绍了一系列在线课堂和在线沙龙活动助力网安行业复工复产的情况。截至3月26日晚，全国上千家媒体转发，浏览量突破150万。

    


    2020年，平凡的我们也在不平凡的生活着。尖锋大讲堂用111场直播，与20000名在校大学生和网安从业者，共同记录了疫情期间停课不停学和抗疫复产的坚守和情怀。如果网络是有记忆的，会记住平凡的我们做出的所有努力！


# 精英百强 #

    2018年10月15日，首届“精英百强”选拔活动正式启动，同年11月，面向“精英百强”各参选战队发放软硬件资源（龙芯开发板、中标麒麟操作系统、昆仑固件开发环境），“精英百强”参选战队数量也同时破百。2019年9月，网络安全人才需求与培养论坛暨大学生网络安全尖锋训练营总结表彰大会在武汉召开。首届精英百强精英百强选拔活动共获得了来自全国28个省、市、自治区38所高校，超过400人的积极参与。最终28支学生团队、101人入选精英百强。


    2019年10月，第二届精英百强选拔活动如期启动，共有来自全国12个省市自治区43所高校，超过1600人参与选拔，部分学生表现出了相当高的技术水平和综合素质。2020年9月11日，黄鹤杯网络安全人才与创新峰会网络安全人才培养与需求论坛暨大学生网络安全尖锋训练营年度总结表彰大会在武汉国家网络安全人才与创新基地召开。会上对获奖学员进行表彰，同时对新晋联合培养基地进行授牌。虽有疫情阻挡，同学们仍克服困难，完成了当年的比赛，吾辈自强！


    2021年3月，第三届精英百强选拔正式拉开帷幕，当年度的“精英百强”大赛得到了行业企业的大力支持，共有来自全国30个省市自治区的235所高校和高职院校，1624名在校大学生参赛，部分学生表现出了相当高的技术水平和综合素质。同年10月23日，网络安全人才培养与需求论坛暨大学生网络安全尖锋训练营年度总结表彰大会在武汉市东西湖区网安大厦召开。会上表彰了优秀联合培养基地、优秀尖锋导师、优秀指导老师和“精英百强”大赛获奖学生，公布了新晋联合培养基地和新晋尖锋导师名单。


    截至2022年1月，“精英百强”大赛累计参赛人数五千余人。



# 联合培养基地 #

    参天大树离不开稳固的根基，训练营与行业企业与高校共同建设培养基地，为网信自主创新人才的培养提供坚实的基础，截至2022年1月，参与训练营联合培养基地的企业共327家、高校378所。



# 尖锋志愿者 #

    2020年2月，训练营发布校园志愿者招募令，协助处理训练营的日常工作及推广，经过自愿报名和选拔，来自北京、重庆、山东、山西、湖北、四川、贵州7个省市15所高校的20名同学成为首批志愿者。截至2022年1月，已经有近40名志愿者同学加入，其中有些已经踏入工作岗位，我们也收到了来自用人企业的积极反馈。



# 致敬英雄 #

    大学生网络安全尖锋训练营在五四前夕，举办了“我眼中的抗疫英雄”大学生新媒体创新大赛，比赛共收到来自湖北、四川、山西、新疆、北京等十多个省市自治区五十余所高校的200余名同学制作的300余件参赛作品。他们用海报、微视频、动画等形式表达了对“抗疫英雄”的敬意。



# 师资竞赛 #

    2020年10底，大学生网络安全尖锋训练营与武汉赛博网络安全人才研究中心，共同发起2020网络安全师资能力（课程设计＆教学）竞赛，比赛启动之后，得到了社会各界的广泛关注，共有来自全国各地全国各地的176名讲师报名参赛，最终，12名优秀讲师脱颖而出。



# 全媒体平台 #

    训练营于2020年开启全媒体平台运营，包括微信公众号，QQ群，B站，抖音等，将知识传播到更多平台，我们也收到了许许多多同学的积极反馈与赞赏，这让我们无比感动，我们还会坚持下去，让更多人因此有一些小小的收获，我们便心满意足。

    截至2022年1月，训练营共拥有全平台关注者5200余人，刊发文章1297篇，日阅读用户200+；视频累计播放量达44000余次。
