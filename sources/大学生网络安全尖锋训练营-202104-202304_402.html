2021网信自主创新成果推荐手册



北京奥星贝斯科技有限公司
核心系统数据库全面迁移 OceanBase 解决方案


1
·概述

目前国内大量客户的核心业务系统基于封闭式的软硬件架构构建和运行，各种系统特点不一，数据规模从几百 GB 到十几 TB 不等、TPS 需求从数百到数万、既有高频交易也有跑批场景、以及复杂递归类SQL。面对复杂业务场景，OceanBase 以业务价值为基线，依托良好的兼容性和强大的数据迁移能力，让技术适配业务，减少核心系统改造成本，让迁移更高效稳定。 

1. 在线不停服的数据迁移：支持将核心系统数据库在线不停服的迁移至 OceanBase，同时在应用切换至 OceanBase 数据库后，将 OceanBase 数据库上所有的变更数据会实时同步至切换前的核心数据库。 

2. 兼容性评估：提供了核心数据库对象迁移 OceanBase 的兼容性分析和自动化的改写建议，极大降低了数据迁移的门槛和业务改造的难度。 

3. 一站式交互：支持数据传输的全生命周期管理，使用管理控制台轻松操作即可完成数据传输项目的创建、任务配置和传输组件的监控运维，辅助链路维护和故障诊断，交互简便。 

4. 完备的数据校验：提供了全面、稳定而高效的数据校验功能，极大保证了数据传输的完整性和正确性；对于数据校验结果展示差异数据，提供一键订正的方案。

2
·应用场景

OceanBase 做为通用关系型数据库，可以广泛应用于在线事务处理及决策分析场景，包括核心业务系统、渠道服务、数字化业务、客户关系管理系统及技术中台等业务，保证客户数据的完整性、一致性，以及业务系统的连续性。 

1. 开门红大促场景：面对开门红大促场景，可以提前预估性能需求，进行集群在线扩容，应对开门期间性能高出平常几十倍的需求； 

2. 强大的兼容功能：OceanBase 高度兼容传统数据库，从库表对象、数据类型、SQL语法兼容、SQL优化器、PLSQL等各方面进行了全面的支持和兼容，能够在核心系统保持不变情况下，从原有架构上快速平滑迁移； 

3. Pro*C+TUXEDO 核心场景：OceanBase 自主研发的嵌入式 SQL 预编译器，平滑替换旧的 Pro*C 预编译器，将基于 Pro*C 和 Tuxedo 开发的核心系统，快速平滑的迁移到 OceanBase 上来，避免大量代码的重写； 

4. 精算处理场景：OceanBase 实现了集群快照功能，一键生成快照，耗时极短，并在原有集群内部即可进行精算分析，减少了对高端存储的依赖。

3
·典型案例

OceanBase 支撑某大型金融客户进行核 心系统改造

在某大型金融客户，从 2020 年 8 月至今，200 多天内 OceanBase 完成了 200+ 套 Oralce 数据库的整合，顺利完成了十多套核心业务系统的迁移改造，覆盖了该客户所有核心业务系统，并持续保障核心系统多个月的平稳运行。




平滑迁移、稳步推进

1. 平滑移植老系统 tuxedo+Pro*c，避免业务改造；

2. 系统整体优化，如递归语句效率优化、全局临时表性能优化； 

3. 停机窗口短，平滑迁移，并在异常情况下可以及时回退；

4. 已迁移的数十个系统在原有 Oracle 使用空间约 30TB，到 OceanBase 后不到 4TB。




业务收益

1. 满足金融行业分布式技术架构转型要求； 

2. 满足“高性能、高可用、高扩展、高一致、高安全、高可控”的国家级金融基础设施需要；

3. 提升互联网 + 能力，开门红业务期间可提前根据业务负载进行扩容，高峰期过后可在线缩容；

4. 平台化管理能力提升，整合竖井式应用，集中化管控，统一资源分配和运维。
