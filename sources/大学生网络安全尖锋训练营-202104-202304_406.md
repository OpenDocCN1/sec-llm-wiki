![](../Images/752477e02dc5e96a739839c0b4dc98bd.png)**1****·概述**

牧云（CloudWalker）主机安全管理平台由长亭科技自主研发，以资产安全为核心，以安全事件为驱动，在庞杂的混合云环境下，提供给用户一个不同的观察网络环境的安全视角，提升资产能见度并有效防御入侵。 

产品集资产管理、入侵检测、风险感知三大维度 20 余项防护功能于一体，形成具有精准预测、实时监测、快速检测、多维分析、自动响应的安全管理体系，让企业全方位掌握服务器安全态势，帮助金融、能源、教育等关键信息基础设施构建最后的安全防线。 

牧云（CloudWalker）对主机资产进行持续监测和管理分析，细粒度掌握全局资产信息和资产变更信息。基于长亭服务器安全监测系统自身安全探针能力，牧云（CloudWalker）引入海量威胁情报信息，深度检测入侵事件、漏洞信息、安全合规等系统指标，提供针对性的修复方案，对安全风险进行全 周期持续跟踪管理；自适应调度安全探针，快速建立主机安全管理机制。牧云（CloudWalker）系统内置安全监测模型、生命周期管理、风险排序等多种核心引擎，将多源异构安全数据聚合，自动建立符合组织内部规范的主机安全管理平台。

![](../Images/472d56a4fb3743c77dd86b527cd8388a.png)

产品功能矩阵

![](../Images/752477e02dc5e96a739839c0b4dc98bd.png)**2****·应用场景**

关键信息基础设施已成为网络攻击的主要目标，但传统的 HIDS 类产品对新型网络入侵技术缺乏对应的检测手段，无法高效解决日益复杂的全网安全威胁和入侵事件。长亭科技依据《中华人民共和国网络安全法》对关键信息基础设施安全保护的要求，推出关键基础设施主机安全管理解决方案，以主机资 产为核心充分发挥运营主体作用，帮助客户有效整合资源、流程、人员并构建整体联动的安全管理体系，切实提升客户应对风险的能力，高筑安全防线。

平台的部署架构分为两部分：管理服务和探针。

![](../Images/7e88597b97ab7feee705362344bcb91a.png)

平台可完美兼容 Windows Server、CentOS、Ubuntu、Debian、Suse 及常用的 Linux 发行版。

![](../Images/46d3d68686004412e77fd3e90b316ec7.png)

![](../Images/752477e02dc5e96a739839c0b4dc98bd.png)**3****·典型案例**  
  
  
**案例一**

某银行对现网主机资产进行持续监控，发现主机资产变更状况，重点关注 WebShell 检测、恶意文件检测与隔离、合规基线检查以及全网漏洞预警。 

20000 探针分别部署在生产与测试区域的服务器资产上，与 SIEM 系统进行 syslog 对接，实时同步风险事件详情以及主机变化情况。 

1\. 提升 SIEM 平台主机层面的入侵事件感知能力，感知互联网新启用 IP 地址、感知已知资产新启用服务端口、感知新增风险事件及状态。 

2\. 具备服务端主机资产实时监控以及入侵检测能力。 

3\. 系统联动、数据联动、人员联动，运用自动化技术，实现快速发现、快速分析和快速响应。

  
  
  
**案例二**

某保险公司需要满足等保2.0三级中恶意代码防范的要求,牧云（CloudWalker）检测主机层的恶意文件并将其隔离，满足客户对于等保 2.0 主机防护的需求。 

20000 探针分别部署在开发、生产、测试区域的服务器资产，与 CMDB 系统、工单系统、邮件系统通过接口联动，进行业务数据、用户信息和资产信息的同步。  

  
  
  
**客户收益**

全局掌握业务系统的应用风险态势，如系统类型、系统对比等多维度态势分析图表，通过安全事件的分布情况进行专项整改。 

持续跟踪事件状态，考核是否逾期，是否残留等一系列指标，将安全管理制度落实到位。 

以业务系统为核心，加速实现主机资产风险收敛，提高了应用系统安全水平和交付效率，减少业务系统上线前时间成本以及上线后的安全运维成本。

  

![](../Images/752477e02dc5e96a739839c0b4dc98bd.png)**4****·公司简介**

长亭科技是国际顶尖的网络信息安全公司之一，全球首发基于智能语义分析的下一代 Web 应用防火墙产品。目前，公司已形成以攻（安全评估系统）、防（下一代 Web 应用防火墙）、查（主机安全管理平台）、抓（伪装欺骗系统）为一体的全方位企业级应用安全防护塔防体系，并提供优质的安全测试及咨询服务，为企业级客户带来智能的全新安全防护。 

公司产品入选 Gartner、Forrester、IDC 等权威报告，获得广泛认可，已成功服务中国银行、农业银行、工商银行、建设银行、交通银行、国家电网、中国水利、河南机场、中国南方航空、清华大学、南开等系列知名客户。
