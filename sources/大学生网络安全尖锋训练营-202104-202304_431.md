![](../Images/500c0678a0bb4656ca41678c0b386d47.png)

![](../Images/793d18a1f7bf77c22a5c28238e92d22f.png)**1****·概述**

威胁情报云查服务依托覆盖全网（移动，PC，云）海量安全数据，通过数据清洗，建模，分类，感知，快速的识别出海量数据中威胁因素，依托腾讯安全强大的机器学习平台和专业的运营能力，将威胁因素生产运营成实时有效，具有丰富上下文信息的威胁情报，对外提供 7 种类型 API 接口服务，包含基础分析接口、高级查询接口，如下表所示。

![](../Images/5b3f0708cd75e35dbeddae856959721a.png)

**腾讯安全威胁情报云查服务，为您提供以下价值：** 

（1）对内部资产进行失陷检测和威胁发现； （2）对内部安全管理中心或安全设备的日志进行告警收敛和关联分析；  （3）对公网开放的应用或服务的对外访问 IP 进行风险识别和信誉决策； （4）对终端 / 服务器的可疑文件 / 进程是否属于恶意程序进行分析甄别； （5）对外部安全事件进行关联外拓、溯源追踪等。![](../Images/793d18a1f7bf77c22a5c28238e92d22f.png)**2****·应用场景**  
  
  
**安全告警分析**

获取最新威胁趋势，将情报数据用于分析日常的设备报警，对报警进行过滤、筛选和上下文丰富。

  
  
  
**检测能力提升**

在现有安全防护能力之上，附加更多的威胁检测能力；与现有安全产品及工作流程有效结合，提高安全运营的效率。

  
  
  
**全流量威胁感知**

对全网流量，应用情报进行持续的威胁感知与监控，深入覆盖多区域，覆盖已知威胁与未知威胁。

  
  
  
**态势感知 / 集中运营**

向态势感知平台提供威胁情报检测与分析能力，利用情报发现的威胁事件作为网络安全要素提供给需要态势感知平台作为数据。

  
  
  
**全方位的情报中心（TI inside）**

提供威胁情报数据接入，基于情报中心建设平台提供情报数据分发、服务与通报机制，提供自有情报挖掘能力。

  
  
  
**攻击者视角的情报**

基于红队视角来提供情报专项服务，对攻击成功的手法和工具进行统计分类，针对红队事先搜集的攻击信息进行发现和提取，从而提前保护和收敛，如漏洞监测和 PoC 服务，社工类信息，对攻击步骤全链条进行梳理，对内网各 关键薄弱点情报提供加固服务。

  
  
  
**黑灰产工具，暗网监控，信息泄露**

提供黑灰产工具，IP 画像，手机号画像，接码平台、行业安全态势等；监测 Github 代码泄漏、监测百度文库和云盘敏感数据泄漏、监测暗网数据泄漏等。

![](../Images/793d18a1f7bf77c22a5c28238e92d22f.png)**3****·应用实践**  
  
  
**金融行业 - 某大型银行**

背景介绍： 

该银行已经具备了边界防护、入侵检测、终端杀软等设备，传统的安全防御体系建设较为完善，但针对已经进入内网的威胁无法进行及时发现、响应。此外，总部通过态势感知将全部流量进行统一采集，但是威胁发现能力不足，安全人员无法定位关键威胁并进行处置。如何提高该银行的威胁检测能力成为安全管理人员必须要解决的问题。 

  

核心优势： 

安全态势集中呈现提升内网失陷威胁检测能力情报赋能安全产品分析能力  

  
  
  
**政府行业 - 某某省政务服务数据管理局**

背景介绍： 

XX 省政务外网的网络安全防御体系主要由防火墙、IPS、WAF 等传统安全设备组成，高级威胁事件发现能力弱。安全运营人员相对短缺，威胁检测分析工作主要依靠厂商人员，安全运营工作自主化、自动化、智能化、可视化程度低。

  

核心优势： 

情报赋能传统政务安全

检测、分析、响应三位一体

取证溯源提升安全专业能力
