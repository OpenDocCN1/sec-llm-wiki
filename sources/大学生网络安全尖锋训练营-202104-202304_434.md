![](../Images/ff41ad1ea08427a804159d306a73007d.png)**1****·概述**优炫数据库（UXSINO Database 简称 UXDB）是北京优炫软件股份有 限公司研发的企业级数据库，自主知识产权，符合 ANSI SQL 国际标准，提 供完善的数据存储与数据管理功能，具有众多优异的产品特性，可满足各类信 息化业务需求。产品支持关系型、XML/JSON，非结构化等多种数据类型。支持在线事 务处理与在线分析处理。具备高可用性、高性能、高安全、数据即服务等特性。可实现单机、大规模并行处理、分布式存储、实时应用集群、云端部署。广泛 应用于管理信息、高频联机、生产管理、地理信息、全文检索、商业智能等多 业务场景。 产品已完成与国内外主流芯片、操作系统、中间件适配，支持众多应用软 件稳健运行。通过公安、保密、军工、信创等领域多项国家级测试，及云计算、 金融、能源等重大行业测试。可规模替代国外数据库，满足我国电子政务、军 工、金融、电信、医疗、教育等各行业产业升级需求。

![](../Images/4165c9db7e47f39906abbe7a0dd084aa.png)

![](../Images/95f52137d4c9b3dddfe6cae0df6cc334.png)**2****·应用场景**

优炫数据库是新一代数据库管理系统，相比传统关系型数据库，主要特性 包括：

  
  
  

**多业务场景支持**

支持关系型数据、XML、JSON、GIS、时序、空间等多种数据类型，支持 Oracle、MySQL 等主流数据库迁移，可同时满足事务型业务与分析型业务场景需求。

  
  
  
**高可用、高性能**

提供实应用集群，支撑业务服务“准零中断“，可 用 性 超 过99.999%，满足金融、电信等重点行业关键业务 7×24 小时运行；提供大规模并行处理能力，支持 PB 级数据在线分析业务

  
  
  
**高安全性**

符合国家信息安全技术标准，融合访问控制、授权、审计、加密、灾备等全面数据安全技术，达到国内数据库最高安全级别，可提供一揽子数据安全解决方案，确保客户数据资产安全。

  
  
  
**可拓展性**

可自定义数据类型、索引、函数等数据库对象。支持多种插件，实现功能性能最优实践。支持无限空间存储横向扩容，实现集群的弹性伸缩。

  
  
  
**多种部署模式**可根据配置不同，实现单机、分布式存储集群、大规模并行处理、实时应用集群与云端多种模式部署，优化客户 IT 资产配置，降低投资与运维成本。![](../Images/95f52137d4c9b3dddfe6cae0df6cc334.png)**3****·典型案例**

**4****·公司简介**

北京优炫软件股份有限公司（简称“优炫软件”），成立于2009年，是一家基于IT技术和软件研发、产品、服务及全方位解决方案的数据库和数据安全产品运营服务商。

优炫软件聚焦数据库和数据安全领域，建立操作系统安全、数据库安全、 边界防护、云安全、运维安全、业务安全六大方向的核心数据保护产品体系，并依据行业属性为用户提供全方位整体解决方案。公司自主创新研发的优炫数据库UXDB，已广泛应用于工信部、公安部、国家统计局、中国人民银行、湖南省环保厅、上海市高级人民法院等客户单位，并稳健高效支撑住第七次全国人口普查等国家级重点项目。
