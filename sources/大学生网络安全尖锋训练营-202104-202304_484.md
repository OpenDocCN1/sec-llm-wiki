![](../Images/ec18bff48d40437ad614717518736348.png)IP网络

  

  

     随着 IP 网络的规模不断扩大，连接属性不断增强，支撑的应用场景持续丰富，网络设备承载着越来越多的关键业务，已经成为数字世界中的关键基础设施。

 IP 网络设备细分为路由器、交换机和无线局域网（Wireless LAN，也叫 WiFi 无线接入点 AP（Access Point））三大类别。其中路由器可以细分为核心路由器、汇聚路由器和接入路由器。交换机可以细分为数据中心交换机和园区网交换机。数据中心交换机连接数十甚至上万台服务器，为了保障业务连续性，需要高扩展、高可靠和高效率。园区网交换机用于机构内部组网, 提供稳定、可靠、安全的高性能 L2/L3 层交换服务。无线局域网通过无线通信技术将计算机等终端设备互联起来，构成资源共享的网络体系，从而使网络的构建和终端的移动更加灵活。 

 在 IP 网络设备内部架构中，CPU 在硬件层负责设备的管理、调度和计算，操作系统在软件层面负责资源的调度和管控，专用芯片（转发、交换、NP （Network Processor）芯片）负责 IP 数据包的处理。因此，转发、交换、NP 芯片决定了网络设备的性能，是网络设备的最核心的部件。IP 网络设备自主可控的判断标准主要是，设备是否采用国产 CPU、操作系统和专用芯片。

**01 国产IP网络设备**

**达到业界领先水平**

  

   
  

路由器

  

 通过产业协同和技术攻关，以华为为代表的国内网络厂商基于自主研发的交换 /NP 芯片和国产盛科转发芯片，推出了支持 SRv6（IPv6+ 协议）的路由器产品。产品性能已经达到或接近使用美国博通、Marvell 等公司的商用转发交换芯片的产品，以及思科、Juniper 等国外厂商自研芯片产品的同等水平。其中华为的 NetEngine 8000 全业务智能路由器基于新一代硬件平台，使用国产自主 CPU 和 NP 芯片、在电源工艺、能耗设计、高阶调制技术等领域取得了技术突破，实现业界领先的单槽位 14.4T 能力，支持 SRv6 协议。 

 标准协议的制订对路由器的产品引领非常重要。华为投入专家在 IETF 等国际标准组织中参与标准协议的制订，对 SRv6 标准的贡献度占了 60%。 

  

  
![](../Images/3da5ac1080e701a97b5f314076fec80d.png)  
  
  
  
  

  

  
  
  

交换机

  

 以华为和盛科为代表的交换 / 转发芯片厂商加大研发投入，加快推进交换机生态建设。下游交换机整机厂商华为、紫光、迈普、风云、卫士通等企业，陆续推出了丰富的自主创新交换机产品。特别是华为公司采用自研芯片开发的数据中心交换机整机最多支持高达 768 个 400GE 接口，园区交换机整机最多支持高达 288 个 400GE 接口，性能已在业界领跑。

  

  
![](../Images/3da5ac1080e701a97b5f314076fec80d.png)  
  
  
  
  

  

  
  
  

无线接入点

  

 目前国内厂商在无线 Wi-Fi 芯片领域还没有建立完整的生态，除华为在最新一代 Wi-Fi6 产品中全线采用了自研芯片外，其他厂商主要以商业套片为主。华为自主研发的 Wi-Fi 产品已达到甚至超越了国外同类产品的性能水平。

**02 业务需求和知识产权壁垒**

**促使国产IP网络创新发展**

  

  
  
  

IPv6+ 网络新技术创新需求

  

  5G、云网融合、工业互联网、车联网、远程医疗等新业务场景对 IP 网络体系架构的创新发展提出了新的要求。电力行业对 IP 网络提出了更高的 SLA（Service-Level Agreement）保障要求，希望实现端到端低时延（<15ms） 和高可靠行要求（99.999%），在安全隔离故障快速恢复方面提出了分钟级要求；金融行业希望网络实现自动化部署，简化业务上线流程 ( 天级 ) 和 智能运维 ( 分钟级 )；智慧医疗和远程 VR 对带宽的要求达到了 50Mbps 和 60Mbps，VR（Virtual Reality，虚拟现实）对丢包率要求小于 0.01%；党政办公为了实现数字化转型，对网络建设也提出了新的需求，要求建设基于 IPv6+ 的网络，实现上下联动、部门协同、服务导向的“互联网 + 政务服务”。 

 产业界持续探索 IP 网络的发展演进。我国率先提出了第三代互联网创新体系“IPv6+”。IPv6+ 是面向 5G 和云时代的智能 IP 网络，包括以 IPv6 分段路由（SRv6）、网络切片（FlexE）、确定性传输、随流检测（iFit）、新型组播（BIER6）和应用感知网络等协议为代表的协议创新，和以网络分析、自动调优、网络自愈等网络智能化为代表的技术创新。“IPv6+”可以满足 5G 承载和云网融合的灵活组网、业务快速开通、可靠性保护、确定性传送、 简化网络运维、优化用户体验按需服务、差异化保障等需求。

  

  
![](../Images/3da5ac1080e701a97b5f314076fec80d.png)  
  
  
  

  

  
  
  

数据中心网络场景的自主创新需求

  

  在数据中心的 FC(Fibre Channel) 集中式存储网络和高算力、高性能计算 HPC（High Performance Computing）和 AI 训练等场景的网络，还主要依赖非自主创新的 FC 光纤交换机和 IB（Infifiniband）交换机。FC 光纤通道主要应用于建设连接服务器和集中式 FC 存储的后端存储网络。由于 FC 技术上的专利壁垒，目前支持该场景的仅有博通、思科和 Marvell 三个国外厂商。自主创新的交换机基于传统以太协议还无法实现替代。 

 IB(Infifiniband) 是当前用于高性能计算网络的一个通信标准，用于计算机与计算机之间的数据互连。IB 也用作服务器与存储系统之间的直接或交换互连，以及存储系统之间的互连。同样的，由于专利壁垒，目前该场景主要是 Mellanox 一家国外供货厂商，自主创新交换机基于传统以太协议还无法实现替代。FC 和 IB 都是出于对应场景业务的需要，服务器和存储对网络传输效率和质量提出了更高的要求。传统以太网数据传输上尽力而为的特点不能满足 这两个场景应用的要求。RoCE（RDMA over Converged Ethernet）协议的发展，为自主创新以太交换机替代 FC 和 IB 提供了机会。目前华为的数据中心 交换机已经支持 RoCE 协议，可以替换 FC 交换机，且性能超越 FC 交换机；全系列自主可控数据中心交换机都可以替换 IB 交换机，性能持平。

  
![](../Images/3da5ac1080e701a97b5f314076fec80d.png)  
  
  
  

  

  
  
  

园区网络场景的自主创新需求

  

 随着物联网、移动互联网、云计算等技术的广泛应用，园区网络将承载多种业务形态，迫切需要实现全场景业务的综合物联接入、差异化承载、端到端质量保证、自动化智简运维管理，有效提升企业整体运营效率。在无线接入领域，增强现实 / 虚拟现实、沉浸式办公、全息视频、物联接入等新的应用场景需要可靠的带宽和端到端低延时保障，并做好海量接入应用带来的威胁防护。

**03 国产IP网络的创新发展路径**

  

  
  
  

推进IPv6+ 规模应用，  
助力行业升级

  

 为了实现 IPv6+ 网络的产业发展和技术演进，需要加快在政府、金融、能源等行业的 IPv6+ 产业规模部署，推动网络、应用、终端多个产业协同，在协议上全面支持 IPv6+。通过“IPv6+”产业应用创新，为用户提供更加完 善的多层次服务能力，力争到 2025 年基本建成超宽带、低时延、服务化、智能化的新一代“IPv6+”网络。 

 政务领域基于行业维度实现切片云网，打造前瞻性、全覆盖、安全智慧的“一网多平面”，支持海量接入。通过镇村 / 小区广覆盖，实现行业切片云网万级节点，广覆盖支持政务网下沉。实现重保业务安全隔离，通过切片云网，保障不同业务差异化体验。实现云网融合，业务通过网络一跳入云、入网即入云，专线业务快速自动开通并灵活调整。最终建成云网安一体的超融合、超联接、服务化的数字政府网络。

 金融行业进行数字化转型，实现网点生产、办公数字化，业务快速开通和视频化，加快金融物联网的泛在联接。基于 IPv6 进行创新的 SRv6，仅在两端配置、一跳直达，缩短业务开通时间 80%。IPv6+AI 将有利于金融行业 突破商业边界，通过智能 IP 网络弹性扩容，助力客户业务实现及时拓展。IPv6+ 突破连接边界支持海量接入，能够提供无处不在的金融服务。IPv6+ 突破体验边界，通过确定性网络协助用户极速上云，带来极致的用户体验。 

 能源行业建设端到端的能源生产网络，通过 IPv6+ 支持跨域、海量接入、端到端可达。生产网络端到端的 IPv6，使能源企业具备海量物联接入能力，SRv6 Underlay IPv6 实现各分支单位和生产园区一键入云。能源骨干网部署网络分配保障稳定带宽的工控业务质量，SRv6 Policy 实现多级视频调度场景带宽调优。IPv6+ 随流监测实现业务故障快速定位，提升运维效率。IPv6+ 构建网络新基础、智能新业务、网络新安全，更好的满足能源企业数字化转型发展。

  

  
![](../Images/3da5ac1080e701a97b5f314076fec80d.png)  
  
  
  
  

  

  
  
  

发展超融合数据中心网络

  

 为了实现数据中心场景网络的自主创新，需要业界厂商不断优化传统以太网络，实现能够承载高性能存储（FC 替代）、高性能计算（HPC）和高并行计算（AI）业务的超融合数据中心网络。 

 RoCE（RDMA over Converged Ethernet）协议的发展，为自主创新交换机替代 FC 和 IB 提供了机会，使高性能存储、高性能计算和高并行计算可以承载在以太网上。但这需要对现有以太网络进行优化，以满足应用对以太网络更高的传输质量和效率的要求。其中最关键的需求是降低业务的端到端时延，优化设备内丢包、拥塞控制、流量均衡、混合流调度等。经过优化的超融合数据中心交换机可满足现有 FC 网络和 IB 网络的替代，还可满足人工智能应用更优承载的需要。 

 此外，在生态上还需要大力推动自主创新网卡厂商对 RoCE 协议支持，以实现计算侧的适配；推动自主创新操作系统对 NoF 和 RoCE 的支持；推动高性能计算平台自主创新，提升高性能计算的整体效率。

  

  
![](../Images/3da5ac1080e701a97b5f314076fec80d.png)  
  
  
  
  

  

  
  
  

发展面向智简运维、  
智能物联接入的园区网络

  

 面对园区网络日益复杂的运维场景，智简运维成为未来发展的重要方向。设备即插即用、免配置入网、运行状态实时图形化可视、常见故障自动识别、智能推荐改进建议等智简运维功能将越来越受到关注。 

 在物联接入方面，要通过 SD-IOT（软件定义 IOT）能力归一物联接入，结合国产操作系统和 SDK 构建物联园区接入生态，实现物联终端的智能安全接入管控和身份规约。面对多种接入终端带来的网络威胁，需要智能识别终端和应用类型，对于非法终端和终端异常行为、异常流量、异常访问等行为，自动识别并隔离告警将成为主流功能。 

 为了打造面向未来业务发展方向的智简运维、支持智能物联接入的园区网络，需要产业界协同合作，在 CPU、专用芯片等硬件领域加大自主研发和生产力度。
