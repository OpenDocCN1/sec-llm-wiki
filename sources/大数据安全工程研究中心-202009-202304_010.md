# DSMM证书可抵扣个税

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Nzg0NzUxOQ==&mid=2247485159&idx=1&sn=f1cceda5bab7172dd16a2b0dce4bc3ee&chksm=a6d28e5791a507412880683f421e99b715a9151b643e2f237cad223942d8ba1dce90d5b0b152&scene=126&sessionid=1681266382#rd](http://mp.weixin.qq.com/s?__biz=MjM5Nzg0NzUxOQ==&mid=2247485159&idx=1&sn=f1cceda5bab7172dd16a2b0dce4bc3ee&chksm=a6d28e5791a507412880683f421e99b715a9151b643e2f237cad223942d8ba1dce90d5b0b152&scene=126&sessionid=1681266382#rd)

各位“领航计划”学员，若您已获得**DSMM测评师、****注册数据安全官（Certified Data Security Officer，CDSO）或注册数据安全工程师（Certified Data Security Engineer，CDSE）**证书，别忘了在汇算清缴时选择专项附加扣除哦！具体操作如下：  

1、打开个人所得税APP首页，点击专项附加扣除填报,如下图。

![](../Images/e5394bc29333e27f849500544a9101da.png)

2、进入专项附加扣除填报,选择好扣税年份,点击继续教育,如下图。

![](../Images/134b0487747c185584d8fcfa1753756a.png)

3、然后点击下一步即可,选择职业资格继续教育,如下图:

![](../Images/e2f3d8ad576f405b3dc6d2b4aaf7fd56.png)

4、选择专业技术人员职业资格,如下图:

![](../Images/d6493cb0aa85cda070541a3612bef82c.png)

5、选择证书名称是计算机技术与软件专业技术资格,选择发证机关是工业和信息化部人才交流中心,至于证书取得时间和证书编号,可以登录国家工信部官网通过身份证号进行查询,填写真实。

![](../Images/23372d3f69af7832f149a34cb4e969c8.png)

6、点击下一步提交，至此，就能完成退税啦！

**02** **培训方式**

1\. 线上授课

2023年3月30日~4月2日。

2\. 考核方式

**DSMM测评师**考试内容为线上测验（40%）、模拟测评考试（30%）和课后作业（30%），模拟测评考试在培训结束后另行通知时间考核，考核方式由老师将学员随机分为3-4人一组，学员模拟DSMM测评现场进行考试，课后作业在课程结束后两周内提交，总分为 100 分，成绩 60 分以上（含 60 分）为通过。

**注册数据安全官和注册数据安全工程师**考试内容为线上测验（70%）和课后作业（30%），课后作业在课程结束后两周内提交，总分为 100 分，成绩 60 分以上（含 60 分）为通过。

**03** **讲师团队**

讲师团队由DSMM产业发展专业委员会、大数据协同安全技术国家工程研究中心十一家联合单位、技术委员会和顾问委员会的资深安全专家，以及具有丰富行业经验的业内知名大咖组成，****杜跃进、李京春、陈际红、钟力、钱晓斌****等业内人士和知名数据安全公司的CEO/CTO，将为学员提供专业化的并结合实际应用场景的培训，以确保业内顶级的教学质量。
