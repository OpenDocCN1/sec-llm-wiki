为适应大数据应用环境安全规范的不断完善，提升组织数字化从业人员的数据安全意识、数据安全能力和数据处理能力，加强数字化人才培养。贵州大数据安全工程研究中心联合大数据协同安全技术国家工程研究中心推出DSMM测评师、数据安全管理员、注册数据安全官（Certified Data Security Officer，CDSO）和注册数据安全工程师（Certified Data Security Engineer，CDSE）人才专业培训，帮助客户培养专业的数据安全管理人才和技术人才，从而系统提升企业或组织的数据安全能力。

培训讲师

本次培训的讲师团队由大数据协同安全技术国家工程研究中心十一家联合单位、技术委员会和顾问委员会的资深安全专家，以及具有丰富行业经验的业内知名大咖组成，包括杜跃进、李京春、李新友、张兴、钟力、钱晓斌等业内人士和知名数据安全公司的CEO/CTO，将为学员提供专业化的并结合实际应用场景的培训，以确保业内顶级的教学质量。

培训证书

1、线上学习（因疫情防控，暂不举办线下培训）
2022年12月26日-12月29日。
2、考核方式
DSMM测评师考试内容为线上测验（40%）、模拟测评考试（30%）和课后作业（30%），模拟测评考试在培训结束后另行通知时间考核，考核方式由老师将学员随机分为3-4人一组，学员模拟DSMM测评现场进行考试，课后作业在课程结束后两周内提交，总分为 100 分，成绩 60 分以上（含 60 分）为通过。
数据安全管理员、注册数据安全官和注册数据安全工程师考试内容为线上测验（70%）和课后作业（30%），课后作业在课程结束后两周内提交，总分为 100 分，成绩 60 分以上（含 60 分）为通过。

培训证书

培训结束后，通过考试的学员将获得贵州大数据安全工程研究中心（DSMM测评师证书、数据安全管理员证书）或大数据协同安全技术国家工程研究中心（注册数据安全官、注册数据安全工程师证书）颁发的证书和工业和信息化部人才交流中心颁发的《工业和信息化人才岗位能力评价证书》，并纳入工信人才序列。
“领航计划·未来数据安全人才培训”2022年第四期（总第十一期）正火热招募中，让我们相约2022年12月26日-29日未来数据安全人才培训。
