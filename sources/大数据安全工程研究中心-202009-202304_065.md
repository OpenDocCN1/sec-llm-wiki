****培训背景****  

# 

当前我国在数据安全领域的立法和监管力度的持续加大，广大单位纷纷增设数据安全岗位。在目前的大数据应用环境下，拥有专业的数据安全管理和技术人才已经成为企业不可或缺的重要安全保障。

![](../Images/fb4d74008595e7b74f954a1168e7223f.png)

贵州大数据安全工程研究中心联合大数据协同安全技术国家工程研究中心推出**DSMM测评师、注册数据安全官（Certified Data Security Officer，CDSO）和注册数据安全工程师（Certified Data Security Engineer，CDSE）**人才专业培训，帮助客户培养专业的数据安全管理人才和技术人才，从而系统提升企业或组织的数据安全能力。

****培训对象****

****1\. DSMM测评师培训着眼于数据安全能力成熟度测试评估，旨在培养专业的DSMM测评师，主要面向：****

*   信息安全咨询服务机构、信息安全测评机构等拟从事数据安全测评工作的专业技术人员；
    
*   政府和企事业单位的数据安全工程技术人员；
    
*   有志于从事数据安全测评的专业技术人员。
    

****2.注册数据安全官（CDSO）培训着眼于数据安全顶层规划设计与统筹管理，旨在培养业界一流的数据安全领导者，主要面向：****

*   政府机关单位的信息化主管领导；
*   企业CIO、CSO等信息化相关的高层领导；
*   大数据部门研发总监、架构师、数据安全管理人员；
*   政府机关、企事业单位的法务人员/合规人员。

****3\. 注册数据安全工程师（CDSE）培训着眼于数据安全方案的落地实施，旨在培养********专业的数据安全工程技术人才，主要面向：****

*   上述数据安全管理岗位的人员；
*   数据安全产品的设计、开发、测试人员；
*   数据安全解决方案的售前、技术支持及运维人员；
*   数据运营和数据安全运营人员；
*   高校、职业教育学校的相关专业学生。

# ******培训证书******

****1\. 发证机构****

DSMM测评师证书由**贵州大数据安全工程研究中心**授权发放。贵州大数据安全工程研究中心成立于2017年11月28日，由贵阳市人民政府和阿里巴巴联合发起，中国网络安全审查技术与认证中心、国家信息技术安全研究中心、中国电子技术标准化研究院、中科院计算所、中科院软件所贵阳分部、国家cert贵州分中心、360集团等单位共同建设的省级重点工程研究中心，聚焦在数据安全领域“标准+认证+产业发展”等方面的研究应用与落地实践。

注册数据安全官及注册数据安全工程师证书由**大数据协同安全技术国家工程研究中心**授权发放。工程研究中心于2017年1月由国家发改委批复成立，2021年12月正式列入国家工程研究中心新序列，是我国大数据安全领域唯一的国家工程研究中心。由360集团承建，中电长城网际、公安三所、复旦大学、中科院信工所、国家信息中心、中国信通院、中国信息安全测评中心、中测安华和安天科技等单位联合建设。

同时，数据安全人才系列培训证书（含DSMM测评师、注册数据安全官CDSO、注册数据安全工程师CDSE）现已**纳入国家工业和信息化部人才序列**，实现“一考双证”。通过培训及考核的学员，可同时获得工业和信息化人才岗位能力评价证书，并且能够在工信部工业和信息化人才评价系统（https://pj.miitec.cn/）同步查询证书信息。

# ****培训方式****

****1.线上培训（因疫情防控，暂不举办线下培训）****

2022年10月20日~10月23日。

****2.考核方式****

**DSMM测评师**考试内容为线上测验（40%）、模拟测评考试（30%）和课后作业（30%），模拟测评考试在培训结束后另行通知时间考核，考核方式由老师将学员随机分为3-4人一组，学员模拟DSMM测评现场进行考试，课后作业在课程结束后两周内提交，总分为 100 分，成绩 60 分以上（含 60 分）为通过。

**注册数据安全官和注册数据安全工程师**考试内容为线上测验（70%）和课后作业（30%），课后作业在课程结束后两周内提交，总分为 100 分，成绩 60 分以上（含 60 分）为通过。
