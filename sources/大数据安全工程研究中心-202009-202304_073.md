# “领航计划——未来数据安全人才专场培训”2022【第二期】即将开课啦

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Nzg0NzUxOQ==&mid=2247484252&idx=1&sn=5393cb9deaa05e6d26966ab1ec2a851f&chksm=a6d28bec91a502fa97f108061988e03dbfe3f0dc931b50b75bdf091da75da06416031b02dac9&scene=126&sessionid=1681266463#rd](http://mp.weixin.qq.com/s?__biz=MjM5Nzg0NzUxOQ==&mid=2247484252&idx=1&sn=5393cb9deaa05e6d26966ab1ec2a851f&chksm=a6d28bec91a502fa97f108061988e03dbfe3f0dc931b50b75bdf091da75da06416031b02dac9&scene=126&sessionid=1681266463#rd)

 为落实国家层面法律法规的相关要求，服务国家数据安全治理体系的构建，提高人员数据安全意识，促进数字经济的健康持续发展，培养数据安全专业人才，贵州大数据安全工程研究中心和大数据协同安全技术国家工程研究中心推出了DSMM 测评师、注册数据安全官（Certified Data Security Officer，CDSO）和注册数据安全工程师（Certified Data Security Engineer，CDSE）人才培训。  

目前，“领航计划——未来数据安全人才专场培训”2022年第二期已开始招生，将在6月30日-7月3日开展为期四天的培训。培训日程及师资阵容如下。
