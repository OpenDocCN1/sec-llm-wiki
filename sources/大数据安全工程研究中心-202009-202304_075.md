# “领航计划——未来数据安全人才专场培训”2022【第二期】开始招生啦

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Nzg0NzUxOQ==&mid=2247484233&idx=1&sn=1504348d999e75613cfb6f6af9699121&chksm=a6d28bf991a502ef85206f32f2bb5d1a45eaef672f9b4ddb03dc90710d388497aa70f8fc76cb&scene=126&sessionid=1681266463#rd](http://mp.weixin.qq.com/s?__biz=MjM5Nzg0NzUxOQ==&mid=2247484233&idx=1&sn=1504348d999e75613cfb6f6af9699121&chksm=a6d28bf991a502ef85206f32f2bb5d1a45eaef672f9b4ddb03dc90710d388497aa70f8fc76cb&scene=126&sessionid=1681266463#rd)

    《数据安全法》要求“重要数据的处理者应当明确数据安全负责人和管理机构，落实数据安全保护责任”，相关法规标准也都对数据安全人才培养和人员能力提出了清晰的要求，数据安全专业人员已成为保障数据依法合规安全的关键因素。而且，很多数据安全问题的解决比如如何确保数字化转型过程中的数据安全？如何安全地进行数据的开发利用？如何促进数据的流通共享？大数据平台如何保障安全？如何提升数据安全整体能力以抵御威胁？都需要企业和组织拥有专业的数据安全管理和技术人才。  

  因此，为落实国家层面法律法规的相关要求，服务国家数据安全治理体系的构建，提高人们的数据安全意识，提升企业或组织的数据安全能力成熟度，促进数字经济的健康持续发展，培养数据安全专业人才，贵州大数据安全工程研究中心和大数据协同安全技术国家工程研究中心推出了DSMM测评师、注册数据安全官（Certified Data Security Officer，CDSO）和注册数据安全工程师（Certified Data Security Engineer，CDSE）人才培训。

  

一、**培训对象**

1、DSMM测评师

着眼于数据安全能力成熟度测试评估，旨在培养专业的DSMM测评师，主要面向：

*   信息安全咨询服务机构、信息安全测评机构等拟从事数据安全测评工作的专业技术人员；
    
*   政府和企事业单位的数据安全工程技术人员；
    
*   有志于从事数据安全测评的专业技术人员。
    

  

2、注册数据安全官（CDSO）

着眼于数据安全顶层规划设计与统筹管理，旨在培养业界一流的数据安全领导者，主要面向：

*   政府机关单位的信息化主管领导；
    
*   企业CIO、CSO等信息化相关的高层领导；
    
*   大数据部门研发总监、架构师、数据安全管理人员；
    
*   政府机关、企事业单位的法务人员/合规人员。
    

  

3、注册数据安全工程师（CDSE）

着眼于数据安全方案的落地实施，旨在培养专业的数据安全工程技术人才，主要面向：

*   上述数据安全管理岗位的人员；
    
*   数据安全产品的设计、开发、测试人员；
    
*   数据安全解决方案的售前、技术支持及运维人员；
    
*   数据运营和数据安全运营人员；
    
*   高校、职业教育学校的相关专业学生
    

  

**二、培训证书**

1\. 发证机构

DSMM测评师证书由贵州大数据安全工程研究中心授权发放。贵州大数据安全工程研究中心成立于2017年11月28日，由贵阳市人民政府和阿里巴巴联合发起，中国网络安全审查技术与认证中心、国家信息技术安全研究中心、中国电子技术标准化研究院、中科院计算所、中科院软件所贵阳分部、国家cert贵州分中心、360集团等单位共同建设的省级重点工程研究中心，聚焦在数据安全领域“标准+认证+产业发展”等方面的研究应用与落地实践。    

注册数据安全官及注册数据安全工程师证书由大数据协同安全技术国家工程研究中心授权发放。工程研究中心于2017年1月由国家发改委批复成立，2021年12月正式列入国家工程研究中心新序列，是我国大数据安全领域唯一的国家工程研究中心。由360集团承建，中电长城网际、公安三所、复旦大学、中科院信工所、国家信息中心、中国信通院、中国信息安全测评中心、中测安华和安天科技等单位联合建设。

学员在完成培训学时并通过考试后，可同时获得由工业和信息化部人才交流中心颁发的《工业和信息化人才岗位能力评价证书》，并能够在全国DSMM公共服务平台（https://www.dsmm.org.cn/）、大数据协同安全技术国家工程研究中心人才培养系统（https://edu.nelab-bdst.org.cn）以及工信部工业和信息化人才评价系统（https://pj.miitec.cn/）同步查询证书信息，实现“一考双认证”。

**三、培训方式**

1\. 线上授课

线上培训（因疫情防控，暂定不举办线下培训）。

2\. 考核方式

考试内容为考卷和论文，论文在课程结束后两周内提交，总分为 100 分，成绩 70 分以上（含 70 分）为通过。

  

四、**课程设置**

1. DSMM测评师培训内容

培训周期：4天

课程体系：课程共六个模块，主要包含DSMM测评师能力体系中的数据安全治理方法论、数字经济与数据安全形势、数据安全法规标准、数据安全技术与产品、DSMM测评方法、DSMM测评行业最佳实践&观点等内容。

  

![](../Images/31273b1ef9c3c5ee1e441a8abfdbdfc9.png)

  

学员收获：

*   数据安全的演进过程，国内外常见的数据安全治理框架，基于DSMM的数据安全治理体系；
    
*   国内外数字经济与数据安全发展态势趋势、相关法规政策和标准，特别是DSMM标准；
    
*   数据安全技术、产品和典型应用场景的数据安全解决方案，特别是大数据场景与数据流通共享场景的安全保障技术；
    
*   DSMM测评方法学习和训练，掌握全流程和测评要点；
