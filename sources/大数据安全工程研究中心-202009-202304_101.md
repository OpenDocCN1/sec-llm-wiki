# 2021数据安全专业技术人才培训班暨DSMM培训（第六期）成功开班

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Nzg0NzUxOQ==&mid=2247483810&idx=1&sn=4ec50d46c1c0746b3f6ebe0d4fee31b5&chksm=a6d2891291a50004954917ade01cbd700389da493bf1045bea9124d3f63caee4e80dc132b400&scene=126&sessionid=1681266473#rd](http://mp.weixin.qq.com/s?__biz=MjM5Nzg0NzUxOQ==&mid=2247483810&idx=1&sn=4ec50d46c1c0746b3f6ebe0d4fee31b5&chksm=a6d2891291a50004954917ade01cbd700389da493bf1045bea9124d3f63caee4e80dc132b400&scene=126&sessionid=1681266473#rd)

2021年1月7日，在中国信息协会信息安全专业委员会的指导下，由大数据协同安全技术国家工程实验室和贵州大数据安全工程研究中心共同主办的“2021数据安全专业技术人才培训班暨DSMM培训（第六期）”在贵阳成功开班。

本次培训邀请到360集团首席安全官杜跃进博士、中国信息协会信息安全专业委员会常务副主任陈晓桦博士、大数据协同安全技术国家工程实验室副主任钟力博士、全知科技CEO方兴先生、DSMM国家标准核心起草者薛勇先生以及政府主管部门的领导专家作为培训讲师采用线上线下的方式为60余名学员开展为期4天的培训。

![](../Images/15319a6f6a221c74d715be0ea29ff0e8.png)

图1 开场讲话

在正式培训前，贵州大数据安全工程研究中心副主任、秘书长、大数据安全工程研究中心（贵州）有限公司董事、CEO刘东昊先生做开场讲话，代表主办方欢迎各位学员参加此次培训。

![](../Images/1bc6890518879b7c6f252a91c3b5e988.png)

图2 贵阳培训现场

![](../Images/d1bb311543a4f5cbf00245646c497f23.png)

图3 远程培训画面

在数据作为重要生产要素的今天，数据安全是国家安全的重要基础保障。此次培训按照不同的层级要求，分别设置了数据安全管理员和DSMM测评师的培训课程，为数据安全领域储备专业技术人次，促进数据安全产业的健康发展。
