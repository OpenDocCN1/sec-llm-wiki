为落实《网络安全法》《数据安全法》等法律规范要求，切实提升数据安全保障能力，培育和发展数据安全产品及产业体系，促进数据安全产业健康发展，中国软件评测中心、中国信息通信研究院安全研究所（以下简称“中国信通院安全研究所”）等单位在工业和信息化部指导下开展数据安全产业研究工作，研究数据安全技术和产品服务体系，建设数据安全产业公共服务平台，旨在做大产业规模，夯实我国数据安全产业高质量发展基础。


为更好满足基础电信和互联网、金融、能源、医疗和教育等行业用户实际业务需要，中国信通院安全研究所依托“大数据应用与安全创新实验室”，联合中国软件评测中心开展“数据安全产品能力联合验证计划”活动，本次邀请数据分类分级产品厂商、用户参与此次产品评价，通过评价的数据安全产品，将获得由中国信通院安全研究所和中国软件评测中心联合颁发的《数据安全产品检验报告》与《数据安全产品检验证书》，测评结果将于“大数据应用与安全创新实验室”和“数据安全产业公共服务平台”存档公示。
{
一、产品评价对象范围
}
本专项面向数据分类分级产品、数据资产梳理产品，或包含相关功能模块的工具、系统、平台等。
{
二、产品评价主要内容
}
数据分类分级产品评价主要内容：数据源梳理（主动嗅探数据源发现、被动监测数据源发现、数据源信息管理）、数据分类分级识别与标注（分类分级映射模板制定、数据识别、数据标注）、数据分类分级结果管理（结果展示、结果更新、结果查询）等。

本次数据分类分级产品评价专项分为基础级评价与进阶级评价两部分。基础级评价主要检验产品基础功能是否符合行业标准要求；进阶级评价通过支持数据源数量、任务耗时、识别准确率等技术指标的检测，进行产品能力的评估。被测产品通过基础级评价后，方可进行进阶级能力评价。
{
三、产品评价报名方式
}
请有意参加数据分类分级产品评价的相关单位填报《数据分类分级产品评价申请书》（点击文末“阅读原文”即可下载）并提交相关申报材料。以上材料要求加盖单位公章后发送扫描件至指定联系人邮箱。
{
四、产品评价报名截止时间
}
2022年06月30日。
