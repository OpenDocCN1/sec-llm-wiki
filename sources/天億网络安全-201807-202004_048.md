# 紧急预警！境外黑客组织扬言攻击我国视频监控系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU4ODU1MzAyNg==&mid=2247487823&idx=1&sn=54b56a658d94dc42699972e25a8055df&chksm=fdda5f62caadd6749a3bf630d2ece3ca36c2dfb3d5ef91470a42526a1e8557285c938b4f51bd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU4ODU1MzAyNg==&mid=2247487823&idx=1&sn=54b56a658d94dc42699972e25a8055df&chksm=fdda5f62caadd6749a3bf630d2ece3ca36c2dfb3d5ef91470a42526a1e8557285c938b4f51bd&scene=27#wechat_redirect)

![](../Images/9313d4717e67d8d7747d35f2afd5bcf3.png)

据广东省网络安全应急响应中心支撑单位微步在线近日监测发现，有境外黑客组织发布推文扬言将于2020年2月13日对我国视频监控系统实施网络攻击破坏活动。

  

  

  
  
  
  
  
  
  
  

![](../Images/d7c81e5b0ae13ddc56cb5ac653fb17be.png)

  

其声称已掌握我境内大量摄像头控制权限，并在某平台公布了70余个视频监控设备信息。  

![](../Images/60feacc373017f65a28a412a27db9b0b.png)

  

经核查后，上述的链接均属于某某光电技术有限公司生产的监控设备视频查看地址，通过互联网搜索发现该设备存在大量漏洞且至今仍未修复，黑客可以绕过登录界面直接看到监控内容甚至直接获取控制权限，潜在危害较大。  
此次黑客公布的视频监控设备信息主要涉及辽宁、山东、河北、河南等地，具体分布如下：  

![](../Images/e417484d60d0658c7d1adc8c0a5dbfe8.png)

  

针对以上情况分析，疑似境外黑客组织掌握我国暴露在互联网上的视频监控设备，并利用其漏洞进行攻击控制，建议加强针对视频监控网络的安全监控和防护工作：  
![](../Images/ed1e0ee668943c85f5ad753b38803288.png)

1、梳理暴露在互联网上的视频监控网络设备，如非业务必须，请避免直接暴露在互联网，同时对资产加强安全监控和防护措施。

  

![](../Images/ed1e0ee668943c85f5ad753b38803288.png)

2、对暴漏在互联网上的视频监控设备进行安全监测，对视频监控设备进行扫描，及时发现视频监控设备漏洞、弱口令等问题，并及时针对漏洞进行修复。

  

![](../Images/ed1e0ee668943c85f5ad753b38803288.png)

3、采用流量检测技术手段，对视频监控设备与外部通信行为进行持续监控，尤其是境外通信行为，及时采取阻断措施。

  

![](../Images/ed1e0ee668943c85f5ad753b38803288.png)

4、建议用户自查使用的视频监控产品是否存在安全隐患，若存在隐患需及时隔离公网访问或停用相关设备，防止被黑客利用。
