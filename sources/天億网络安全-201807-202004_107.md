在互联网上撕逼的时候，总能看见那些说「我要人肉你」，「我要查你户口」这些威胁的话语。那么，人肉搜索真的有那么神秘吗？接下来我将为大家揭示那些不为人知的人肉方法套路。

(PS: 本文纯属是解密以及教大家如何防止被人肉，本文所介绍方法不可用于违法犯罪活动！)

    

**1\. 一张照片查出你的拍摄地点**

随着智能手机的普及，现在人们大部分使用手机进行拍照，而大多数相机已经默认开启地理位置，如下图：  
![](../Images/e508edebb6d174ca08de2f8ee51eb0e5.png)

  

在开启了这种功能的情况下拍摄的照片会自动存有你所拍照地点的经纬度信息：  
![](../Images/c57719afec4db753cb297a92b25d1b3c.png)

  

有了经纬度信息，我们可以在 MagicExif 软件里查询到照片拍摄地的具体地址（精确到门牌号的那种地步！！！）  
![](../Images/0f45f642126e7433cbccfd5ef08a7b29.png)

  

**2\. 给你打个语音通话获取你的 IP 地址**

我们在 QQ 聊天时都是通过数据进行传输，那么使用一个抓包工具，只要数据传输到对方并且对方在线，我们就可以获取到对方的 IP 信息：  
![](../Images/53059cd63e73099774de8054e2319f38.png)  
当我们打开这个工具的时候，只需要给对方拨打一个电话，不管对方有没有接听，你都可以获取到对方的 IP 地址：  
![](../Images/1c98674c276166ccef0e06cf0fb6d003.png)

  

**3\. 通过 IP 进行定位**

当我们获取到了对方的 IP 地址之后，也可以通过 IP 进行大概位置的定位（有五公里以内的误差）：IP查询网址：www.ipplus360.com  

  

![](../Images/ada1019f82ddfebad0ba3fef26d5517c.png)

  

**4\. 利用经纬度进行二次解析**

当我们通过IP地址进行查询后可以获得对方的大概地理位置，如果想进行二次精确定位的话，我们可以复制经纬度，在解析网站里面进行查询：  

  

**经纬度解析网站：****map.yanue.net**  
![](../Images/35c226ddd902bef02374de11c3d458bd.png)

  

**5\. 通过你的邮箱/手机号查询你注册过的网站**

查询网址：www.reg007.com

  

这个网站就是利用你提交的信息去进行模拟注册来查询是否在该平台已经注册过：  
![](../Images/9526094b2e9eec4d543ef32c744ce6b2.png)

  

**6\. 利用支付宝查询你的名字**

现在支付宝已经全面普及，我们可以利用已经获得到的一些信息，进行姓名猜解。

  

我们可以随意转账一笔大额资金给对方，这时，为了资金安全，支付宝会显示对方的名字，要求你补全对方的姓氏。那么，我们可以使用常用的姓氏一个个进行尝试来暴力破解获取到对方全名。  
![](../Images/e9a7e8cc8b2e3664a4f5eb1860dd6797.png)

  

**7\. 把你知道的信息丢给百度查询**

![](../Images/b3dc43b8eba34abee65e9e77a0344f96.png)![](../Images/d71004d0b4b3487026dad5f21e23a1ba.png)

  

这只是一个例子，不仅是QQ，还有 微信/常用ID/手机号 全部都可以进行查询，不法分子就可以利用这些信息进行电信诈骗！

  

**防止被人肉的措施：**

1、不要在网络上留下自己的QQ，手机号码等相关个人信息，否则会被搜索引擎保存成快照，从而被不法分子所获取；

  

2、不要在所有网站使用同一个用户名；

  

3、最好使用两张手机卡，一张日常通话使用，另一张在网上注册信息时用于接收验证码等操作；

  

4、QQ，微信等社交软件最好不要使用同一个账户。
