**工业控制系统信息安全防护指南产品匹配表**

 

| **指南要求** || **涉及产品和措施** || **备注** |
| --- | --- | --- |
| **一、安全软件选择与管理** |
| 1.1在工业主机上采用经过离线环境中充分验证的防病毒软件或应用程序白名单软件，只允许经过工业企业自身授权和安全评估的软件运行。 || 1、工控主机卫士（应用白名单软件）；2、防病毒软件。 || 工控主机卫士策略配置一次可长期保障主机安全，免去升级病毒库或补丁的困扰。 |
| 1.2建立防病毒和恶意软件入侵管理机制，对工业控制系统及临时接入的设备采取病毒查杀等安全防御措施。 || 1、防病毒软件。 ||   
 |
| **二、配置和补丁管理** |
| 2.1做好工业控制网络、工业主机和工业控制设备的安全配置，建立工业控制系统配置清单，定期进行配置审计。 || 1、工控主机卫士（主机加固软件）2、相应的管理制度3、建立安全基线配置库，定期进行配置对比 || 工业主机和工业设备的配置建议通过软件技术手段实现统一配置核查。 |
| 2.2对重大配置变更制定变更计划并进行影响分析，配置变更实施前进行严格安全测试。 || 1、相应的管理制度2、验证仿真环境（仿真平台） ||   
 |
| 2.3密切关注重大工控安全漏洞及其补丁发布，及时采取补丁升级措施。在补丁安装前，需要对补丁进行严格的安全评估和测试验证。 || 1、验证仿真环境（仿真平台） ||   
 |
| **三、边界安全防护** |
| 3.1分离工业控制系统的开发、测试和生产环境。 || 1、可信网关（工业防火墙）2、网闸3、物理隔离措施 ||   
 |
| 3.2通过工业控制网络边界防护设备对工业控制网络与企业网或互联网之间的边界进行安全防护，禁止没有防护的工业控制网络与互联网连接。 || 1、可信网关（工业防火墙）2、网闸 || 工业防火墙策略配置更灵活 |
| 3.3通过工业防火墙、网闸等防护设备对工业控制网络安全区域之间进行逻辑隔离安全防护。 || 1、可信网关（工业防火墙）2、单向网闸3、VLAN等隔离技术 || 工业防火墙在策略配置灵活更适用于区域隔离 |
| **四、物理和环境安全防护** |
| 4.1对重要工程师站、数据库、服务器等核心工业控制硬件所在区域采取访问控制、视频监控、专人值守等物理安全防护措施。 || 1、相应管理制度2、视频监控系统3、门禁系统 ||   
 |
| 4.2拆除或封闭工业主机上不比要的USB、光驱、无线等接口。若确需使用，通过主机外设安全管理技术手段实施严格访问控制。 || 1、工控主机卫士（终端安全管理） ||   
 |
| **五、身份认证** |
| 5.1在工业主机登录、应用服务资源访问、工业云平台访问等过程中使用身份认证管理。对于关键设备、系统和平台的访问采用多因素认证。 || 1、身份认证管理系统2、USBkey、生物指纹、IC卡等认证设备 || 在应用系统开发阶段就符合相应的安全开发规范 |
| 5.2合理分类设置账户权限，以最小特权原则分配账户权限 || 1、工控主机卫士（终端安全管理）2、应用系统开发遵循相应的安全要求3、相应的管理制度 || 通过技术手段管理超级管理员账户，对各个账户进行审核 |
| 5.3强化工业控制设备、SCADA软件、工业通信设备等的登录账户及密码，避免使用默认口令或弱口令，定期更新口令。 || 1、工控主机卫士（主机加固）2、口令管理制度 || 通过技术手段强制口令的强度、更换周期等 |
| 5.4加强对身份认证证书信息保护力度，禁止在不同系统和网络环境下共享。 || 1、相应的管理制度2、证书、密钥管理系统 ||   
 |
| **六、远程访问安全** |
| 6.1原则上严格禁止工业公职系统面向互联网开通HTTP、FTP、Telnet等高风险通用网络服务。 || 1、防火墙2、相应管理制度 ||   
 |
| 6.2确需要远程访问的，采用数据单向访问控制等策略进行安全加固，对访问时限进行控制，并采用加标锁定策略。 || 1、单向网闸2、可信网关（工业防火墙）3、相应的管理制度，如加标锁定等 ||   
 |
| 6.3确需远程维护的，采用虚拟专用网络（VPN）等远程接入方式进行。 || 1、VPN ||   
 |
| 6.4保留工业控制系统的相关访问日志，并对操作过程进行安全审计。 || 1、监测与审计平台2、日志服务器3、相应的管理制度 ||   
 |
| **七、安全监测和应急预案演练** |
| 7.1在工业控制网络部署网络安全监测设备，及时发现、报告并处理网络攻击或异常行为。 || 1、监测与审计平台 || 建议采用白名单的方式实现异常发现和告警 |
| 7.2在重要工业控制设备前端部署具备工业协议深度包监测功能的防护设备，限制违法操作。 || 1、可信网关（工业防火墙） || 可信网关可现实深度工业协议解析，不仅能判断协议的合法性，还能针对数据进行值域控制 |
| 7.3制定工控安全事件应急响应预案，当遭受安全威胁导致工业控制系统出现异常或故障时，应立即采取紧急防护措施，防止事态扩大，并逐级报送直至属地省级工业和信息化主管部门，同时注意保护现场，以便进行调查取证。 || 1、相应的管理制度2、工控监测与审计平台3、网络审计系统 || 通过监测审计平台完成调查取证工作 |
| 7.4定期对工业控制系统的应急预案进行演练，必要时对应急响应预案进行修订。 || 1、相应的管理制度 ||   
 |
| **八、资产安全** |
| 8.1建设工业控制系统自查清单，明确资产责任人，以及资产使用及处置原则。 || 1、相应的管理制度 ||   
 |
| 8.2对关键主机设备、网络设备、控制组件等进行冗余配置。 || 1、冗余、集群等措施 ||   
 |
| **九、数据安全** |
| 9.1对静态存储和动态传输过程中的重要工业数据进行保护，根据风险评估结果对数据信息进行分级分类管理。 || 1、数据全生命周期安全管理软件（如数据加密等）2、咨询服务（完成工业企业数据分类分级） ||   
 |
| 9.2定期备份关键业务数据。 || 1、数据备份软件 ||   
 |
| 9.3对测试数据进行保护。 || 1、数据全生命周期安全管理软件（如数据加密等DLP软件） ||   
 |
| **十、供应链管理** |
| 10.1在选择工业控制系统规划、设计、建设、运维或评估等服务商时，优先考虑具备工控安全防护经验的企事业单位，以合同等方式明确服务商应承担的信息安全责任和义务。 || 1、相应的管理制度 ||   
 |
| 10.2以保密协议的方式要求服务商做好保密工作，防范敏感信息外泄。 || 1、相应的管理制度 ||   
 |
| **十一、落实责任** |
| 11.1通过建立工控安全管理机制、成立信息安全协调小组等方式，明确工控安全管理责任人，落实工控安全责任制，部署工控安全防护措施。 || 1、相应的管理制度 ||   
 |
