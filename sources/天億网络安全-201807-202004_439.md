**关于2018年上半年互联网信息服务备案工作落实不力企业有关情况的通报**

  

　　互联网信息服务备案工作是互联网管理的基础，未备案互联网信息服务是国家网络信息安全的重要威胁。2018年上半年，我局组织相关单位开展了未备案互联网信息服务（ICP）核查工作。1至6月共发现未备案ICP29,721个。为进一步做好ICP备案工作，对行业内相关企业起到警示作用，现对未备案ICP数量前十名的企业予以通报批评。

  

| 单位 || 未备案ICP数量 |
| --- | --- |
| 郑州市景安网络科技股份有限公司 || 1713 |
| 腾讯云计算（北京）有限责任公司 || 1662 |
| 宿迁蒲公英网络有限公司 || 883 |
| 中国教育和科研计算机网网络中心 || 806 |
| 成都西维数码科技有限公司 || 701 |
| 中国电信集团公司 || 648 |
| 深圳市万维网信息技术有限公司 || 597 |
| 中国联通辽宁分公司 || 571 |
| 江苏微子网络科技有限公司 || 562 |
| 镇江市广源网络科技有限公司 || 551 |

  
　　以上单位要高度重视ICP备案相关工作，认真学习国家相关法律法规要求，立即开展自查自纠行动，确保各项措施落实到位。
