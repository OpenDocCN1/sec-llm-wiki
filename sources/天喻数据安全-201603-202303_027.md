# 东电技术资料智能管控系统—解决图纸追踪\\借阅\\催归\\升版等业务痛点

**项目背景**

随着东方电机有限公司(下称东方电机)日益剧增的生产任务及中国GE(企业发展目标)先进制造的生产管理需要，东方电机要求对技术资料的借阅过程进行更加有效、规范的管理，从而提高档案中心及图纸使用部门的工作效率。在现行的档案管理模式下，档案中心因现场图库设备性能不够高效、管理方式单一等因素，已不能满足公司生产管理的要求，具体体现在:

1、管理方式单一，图纸存放区域划分不清晰，借阅及归档过程无法及时有效的区分、定位图纸的存放位置，管理人员在图纸借阅、图纸归还过程中的工作投入大。

![](../Images/e8a8b8279291dbeed05d0ea9c509a6f7.png)

2、借出记录采用手工登记的方式进行，无法快速进行图纸借阅信息的统计，也无法对图纸进行有效的追踪管理和使用范围控制。

![](../Images/2ffa53ded53cfc68e4dd4a2ce51ea59b.png)

3、图纸管理人员对图纸借阅人的借阅资格无法进行准确判定。

4、图纸归还靠自觉，图纸催收靠打电话通知。

5、图纸发放、图纸归还依赖手工登记，统计分析数据依靠人工进行，统计过程费时费力，手工填写单据时的数据不规范因素进一步加大了统计时的工作量。

![](../Images/8f854cc413dd82a1439c76483f052790.png)  

6、手工记录图纸改版状态，旧版的借阅图纸无法及时回收，极易造成图纸升版后，工人仍使用旧版图纸的生产状态，产生不合格品，给企业带来经济损失。

7、东方电机年平均借阅图纸20万张以上，档案中心因人员老龄化等因素减员减岗，人工管理模式已无法满足业务需求。

![](../Images/55e0ae9abc8c5b9c6227e91c147ea1be.png)

在上述背景下，东方电机档案部门需要应对图纸借阅量大、人工管理成本高、图纸回收不及时、图纸借阅无法追溯、借阅信息无法精准统计等问题，急需打造一个智能、实用、易用的技术资料管控系统，用信息化的手段改变人工静态管理的弱势，实现对纸质图纸、电子文件的一体化、流程化、智能化管控，改善并增强档案部门对图纸借阅过程的管理模式，提高公司人力资源的利用率，降低因返工/废件等因素增加的额外成本，加速实现东方电机步入高端管理型企业的目标。  

  

**系统功能**

**技术资料追踪:一图一码**  

在图纸/文件生成时，系统自动在每一份图纸/文件（pdf）上，自动标记一个二维码标识，实现“一图一码”。 

通过“一图一码”，使每份图纸、每个文件信息都被唯一标示。通过该二维码，系统可在图纸借阅过程将文件信息关联用户、在图纸使用过程中追踪图纸流向、在图纸归还管理时实现精准催收；同时，将图纸信息和文件柜信息关联后，亦可实现对图纸的归档存放管理、文件柜分类管理等内容。

![](../Images/f3efd009eb8d896b35da4a2bf818bf6a.png)  

**实物图纸借阅**  

用户借阅实物图纸时，首先通过借阅流程获取借阅图纸许可；流程通过后，系统自动执行图纸入库或分配图纸操作；用户到档案中心凭相关凭证(工牌)将图纸借出。

![](../Images/1310b9ba562689e134d9966edacceffd.png)  

图纸借阅过程由扫码枪扫描图纸二维码快速识别图纸信息，图纸信息自动绑定借阅人及借阅流程。

![](../Images/dc95eaf8cd2818b0ac8eeeda01bac076.png)

自动化的借阅过程极大的提高了借阅效率，系统通过借阅流程审核、工牌与图纸信息绑定等功能，解决了用户身份判别问题。

在借阅管理的基础上，考虑到档案部门的业务场景，系统增加了如下功能：

**1****、文件柜管理**

文件柜图纸区域划分管理和文件柜使用状态管理，提高了图纸管理的便利性。

![](../Images/175398553ee99733c2c25406b5214ef2.png)

**2****、图纸自动增补**  

智能判断某图号的图纸在文件柜中的库存状态，库存不足时自动增补打印该图号图纸，以备借出。

**3****、线内/线外图纸区分**

与PLM系统深度集成，PLM系统中存在该图纸，则定义为线内图纸；PLM中不存在该图纸，则定义为线外图纸。对线内图纸的借阅，系统自动从PLM中获取；对线外图纸的借阅，若存在电子版，录入打印贴码借出；若不存在电子版，复印贴码借出。

![](../Images/6fd07c460964f34dc2d44b0dd0d9bcb2.png)

**电子图纸借阅**

电子图纸借阅过程不需要打印实物图纸，用户通过电子借阅流程获取电子图纸。流程审批通过后，系统按照流程信息，自动将对应电子图纸(自动从PLM系统中获取)转换为安全的、限定使用权限和使用时效的外发管控文件，供东方电机借阅用户下载后，提供给外部供应商使用。

![](../Images/f98d599703ca4c44c0447ad72dac2a0b.png)

东方电机的外部供应商接收到电子外发管控图纸后，通过指定方式，即可在安全参数设置的权限范围内浏览、使用电子图纸。  

**图纸归还/催归**

用户使用完图纸后，归还至档案部门。档案中心图档管理员通过扫码枪扫描完成归还。归还时，系统自动将图纸分配到原始存放位置。同时，图纸归还时系统自动判断图纸当前版本状态，如果用户归还的图纸存在新版本，则系统自动将图纸报废处理。

当图纸临近归还期时，系统自动通过短信、邮件等方式发送催归信息给借阅人员和部门辅助催收人员。  

![](../Images/cbc2bf1c6dc344760b868dd800eae30b.png)

若图纸逾期后仍未归还，图档管理员可以在系统中生成逾期表，对相关借阅人员进行处罚，敦促用户自觉、按时归还图纸。  

![](../Images/f2a9bb13f70edad30533adf48218d11d.png)  

**图纸升版管理**

PLM系统中新发布的定版图纸信息，会自动推送到本管控系统中。管控系统接收到新版图纸信息时，自动判断旧版图纸是否存在用户借阅，若有用户借阅，系统自动推送催归信息，督促用户归还。

![](../Images/2fcc140df4eb8f3f8bc98f5910e978fb.png)

当用户借阅的资料为电子图纸时，若图纸信息发生升版，在借阅有效期内，系统自动远程报废旧版电子图纸，同时根据用户历史申请的流程内容，自动生成新版图纸的电子外发管控文件，通知用户重新下载使用。

本系统通过升版催收即时提醒功能，及时通知借阅用户更新使用新版图纸，避免借阅用户使用旧版图纸而产生废品、废件，降低企业经营成本。  

**智能快递柜集成**

档案部门在各分厂、车间设置智能投递柜，以便方便的投放各分厂、车间所需的纸质图纸。本系统与智能快递柜集成后，档案管理人员可以根据用户借阅申请，打包纸质图纸，并根据系统自动分配的柜号将图纸投递到智能快递柜中。投递完成后，系统自动发送取件信息给图纸借阅人，借阅人通过工号、手机号、验证码等信息，即可到投递柜中凭号取图。

![](../Images/4d4d8004b786def816610c7f6bd6b526.png)  

**移动端应用**

本管控系统提供了移动终端设备上的应用功能支持，主要包含借阅流程申请、流程审批、借阅状态查询、借阅图纸延期等功能。审核人员可随时通过移动终端进行流程的审核；用户可以随时进行流程申请，及时查看自己的借阅信息及状态。   

![](../Images/15e94fce050ba54de765435f22369631.png) **应用成效**  

通过技术资料智能管控系统的建设，改变了东方电机在纸质/电子图纸、文件借阅过程中的传统管理模式，通过软硬件结合方式将登记借阅、签字取图、口头催还的图纸借阅模式通过信息化的手段予以线上完成。系统实现了对纸质\\电子图纸、文件的信息化管控，实现了智能电子借阅、智能图纸升版、数字化档案管理、资料借阅安全管控等功能。项目取得的具体成效如下：

●系统上线至今，已有近五个月，系统及时、正确的发放了7000余套图纸；

●档案中心图纸囤积量由平时20万张成功实现了图纸囤积0库存；

●为档案中心节省了至少3个工作人员以上的工作量，缓解了档案部门人员紧缺的困境；

‍●有效避免了因图纸发放错误、发放不及时、回收不及时等原因而给东方电机造成的经济损失。

目前，东方电机技术资料智能管控系统已经上线应用近五个月，并于2019年2月顺利完成验收工作。本项目得到了东方电机相关领导及用户的高度评价，用户对天喻软件项目组表示了诚挚感谢，并希望项目能在东方电气集团推广应用。
