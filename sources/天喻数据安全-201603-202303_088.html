客户介绍  customer profile

吴忠仪表有限责任公司是我国流程工业自动化控制领域中控制阀行业的龙头企业，始建于1959年。分别于1980年、2002年两次全面引进日本山武、德国ARCA控制阀制造技术，通过引进技术再创新，吴忠仪表控制阀生产制造工艺达到了国际先进水平，是国家振兴装备制造业的骨干企业。

项目背景  Project background

吴忠仪表是天喻软件的长期合作客户，通过对天喻软件PLM系统平台的应用，使产品数据存储更加安全有序，有效的提高了产品数据质量和研发效率。

但是，许多流程任务较紧急，而流程审批者因开会、出差等原因出现“下周审批”的现状普遍存在。为了更有效的提高审批流程的流转效率，吴忠仪表的各级领导迫切希望PLM系统能在移动终端上运行，使流程审批用户能够实时关注流程状态，让业务流程更顺畅，工作更高效。

项目目标  Project objectives

综合天喻软件全系列产品在吴忠仪表的良好应用情况，PLM App 项目以IntePLM为基础，以InteKEY数据防扩散系统为辅助，支持iOS、Android平台，实现流程的移动审批、查看、转交（含批量转交）、委派、文档和零部件查询、安全浏览（含三维轻量化、二维图纸、工艺文档及办公文档）、审批消息推送等功能。

项目功能  Project function

>>>>流程审批移动化

天喻PLM App 能够在移动端进行流程审批，解决了移动办公应用需求，为企业的审批流转提高了效率。该模块实现了待办流程和已办流程的查看；待办流程的审批和转交（含批量转交）；已办流程的筛选及查询、流程委派、审批消息推送等功能。

>>>>文档浏览轻量化

文档审批时，不仅可以查看流程的内容信息，还支持在移动端直接预览三维轻量化文件、二维图纸、办公文档等附件。

该功能兼容标准格式（dwg、office、pdf等）的文档和天喻软件全系列产品所产生的文档（iva、ivp、tyc等），无须额外安装第三方浏览器应用。

>>>>文档浏览安全化

移动端应用为我们带来便捷的同时，也存在数据被扩散的安全隐患。

天喻PLM App 采用创新的APP应用授权和文档加密分发模式，只有被授权的移动终端才可以使用此APP；同时，在移动端的数据以密文形式存放，无法被非法扩散或传播，保证企业数据安全！

移动终端与PC端InteKEY数据防扩散系统共享一套加密密钥，PC端的数据与移动端的数据能保持正常流转。

>>>>数据查询便捷化

数据查询提供文档库查询和零部件库查询两个功能。

在该模块中，可以详细查看文档和零件的各种属性信息、关联零件、关联文档、版本清单、流程处理情况等信息，并支持直接安全浏览文档。
