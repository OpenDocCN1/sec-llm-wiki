# **制药行业典型案例介绍**

# **成都倍特药业集团**

  

“ 制药行业是我国国民经济的重要组成部分，是传统产业和现代产业相结合，一、二、三产业为一体的产业。其主要门类包括：化学原料药及制剂、中药材、中药饮片、中成药、抗生素、生物制品、生化药品、放射性药品、医疗器械、卫生材料、制药机械、药用包装材料及医药商业。”

  

1****制药行业数据特点分析****

![](../Images/e291948ce95e95c280a27f279fd06d34.png "267860-150Q3100H630.jpg")

制药行业的药品品种多、更新快，需要不断进行产品的技术开发和应用开发，所以研究阶段会产生大量且重要敏感数据，这些敏感数据主要以药品配方、规格、合成技术等数据内容为主；同时，制药行业严格要求产品质量稳定，对原产品要求纯度高，复配以后不仅要保证物化指标，而且更注意使用性能，经常需要配备多种检测手段进行各种使用试验。所以，在试验阶段产生的详细试验报告，也是制药行业需要重点保护的敏感数据类型。

  

2****倍特药业集团简介及需求****

![](../Images/8352f91a8283b4115057b32614b94be2.png "20151228145115_60611.jpg")

倍特药业集团成立于2007年，是一家集药品研发、生产和销售于一体的高新技术企业，国家医药工业百强企业之一，2003年建成“成都高新区企业博士后科研工作站”，2011年，被评为四川省、成都市“企业技术中心”、“国家级高新技术企业”，是国内知名制药企业之一。

在数据安全需求方面，倍特药业集团需要确保集团内的药品研发数据、试验结果数据、制造工艺及配方说明数据，均处于安全的涉密状态。

  

3****天喻数据安全解决方案****

  

![](../Images/bef0196bb97f0e8d37a78b277dfc0657.png "630.jpg")

天喻数据防扩散系统从源头入手，对药品从研发、试验、复配、生产（工艺）等各环节的数据均进行了安全涉密处理，保证了制药过程中的每个阶段产生的敏感数据，均处于安全状态。
