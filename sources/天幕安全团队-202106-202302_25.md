# 幕光之镰

我发现大家都在用fofa，但是作为一个穷货，我用zoomeye已经好几年了，毕竟注册就每个月有一万条查询权限（强推zoomeye，这个很良心啊，而且黑哥还不定时的直播，给大家解决问题）。用zoomeye一直都是web，想用下工具，找了找就一个坤舆，还是命令行，作为一个菜鸡，真心不想用命令行，所以想了想就攒一个zoomeye的gui吧。用了几个小时攒出来的东西，现在还是beta版本，所以可能会有一些bug，如果有哪使用不方便的地方或bug，各位表哥可以直接公众号后台留言或在github提issue，感谢

## 使用

> 进入github后点击release界面，下载release，在 UserInfo.json中写入你的zoomeye的API-KEY（这里直接在zoomeye注册，点击个人中心的个人资料，最下面的api授权，把那里的API-KEY直接复制到UserInfo.json中）,双击打开exe文件，填入查询条件，填入页数，选择查询类型点击查询即可，支持多行选中，点击鼠标右键即可复制到剪贴板
> 
> #
