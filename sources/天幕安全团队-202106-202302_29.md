# **一、样本概述**  

此次事件中使用的木马疑似红队远控，通过钓鱼链接下载下来，伪装成一个带有12306数字签名的ET系统浏览器插件，运行之后会释放两个文件，一个伪装成浏览器更新一个执行后门功能。

  

ET浏览器插件：

1. 是一个带签名的白文件

2. 会释放2个pe文件分别执行欺骗和后门功能

3. 加载ET\_SYSTEM\_EXT.exe

4. 加载conhost.exe

  

      ET\_SYSTEM\_EXT.exe：

1. 弹出一个对话框显示更新插件

  

      Conhost.exe：

1. 执行恶意代码的后门文件

2. 获取计算机信息上传到c2地址

3. GetStartupInfoA进行反调试

4. 执行远控指令

## **3****.4****反调试**
