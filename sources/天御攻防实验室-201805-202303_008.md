# 愿时光能缓，愿故人不散。愿你不再独闯，不再孤独！

人来人往的红尘，每天擦肩无数，你曾经为谁停下过脚步，谁又曾为你敞开过心扉？明月有情，大海无心，擦肩错落之后，路归路，桥归桥，有情的人，留下一生的记忆，无心的人，是一场风轻云淡的遗忘。

曾经有人这样说过，无论怎样，我都会等着你，可我却迷路了，最后你却把心掏出来，作一盏心灯，指引我回来的路！

当我回到你身边时，你说上天自有安排，我却想说亲爱的，不用在骗我了，我怎么会不知道，那是你的良苦用心！对不起，我让你等了那么久！我再也不会离开你了，在也不会问你当初是真是假 ，因为我知道那是在伤害你 ！

不要让爱你的人等得太久！一辈子碰到一个爱你的人不容易，错过一辆车，可以等，错过一个爱你的人，也许就是一辈子。有一种东西不可以利用，那就是善良；有一种东西不可以欺骗，那就是感情。别让爱你的人把心掏出来缝了又补！这样真的会很疼！

进了心的人，最难忘，动了情的人，最难放！人都是有感情的，相处时间长了，惦念是自然的。彼此的感情深了，忘不了是真实的。感情不是交换，无需算计得失。人心不是欺骗，不必费尽心机，记住一句话，爱你的，不会走，不爱你的，留不住！知缘，惜缘，才得缘，将心比心，才有真心！树的方向，是由风决定的，人的方向，是由心决定的。

时光从来不曾为任何人停下前行的脚步。岁月无声，我们只是其中的一个过客，时光流逝中，不管是人生如戏，还是世事无常，那些生活的风云万象，都是我们永远忘不了的风景！

思而不语，念而不忘，想而不见，爱而不得，懂得望爱却步……有些人终是，可望,可念,不可及……

过度理性会让生活丧失美感，过分感性是在慢性的杀S自己，看得越透，活得越累，一尺多宽的小肩膀又能扛住多少事？

人最怕主动后的冷淡，付出后的心寒，亲密后的疏远，熟悉后的厌倦，深情后的敷衍，相知后的分离，珍惜后的失去。

曾经很喜欢一句古诗：“ 白茶清欢无别事，我在等风也在等你，后来才知道；苦酒折柳今相离，无风无月也无你。

认识一个人靠缘分，了解一个人靠耐心，和睦相处靠的是包容，一见如故很容易，难的是来日方长。

人生苦短，在变老的路上要善待自己，糊涂一点不较真，大度一点不生气，凡事看淡，一切随缘，人生本是过客，何必千千结。

沉默，是一个人对爱最苍白的表情；是一颗心对情最无力的回应。沉默的人，爱的最深；沉默的心，伤的最重。人这一生，总有不愿接受的现实，不想承受的心情。不是你的梦，再美也要醒。爱情是个奢侈品，来来去去无踪迹，常常是当它被意识到时，已经走远。有幸在人生中体味到爱情的人，都是幸运儿，月光依旧，故人不见。

愿时光能缓，

愿故人不散。

愿你不再独闯，
