一、简介

    近期，Apache Log4j和Log4j2多个漏洞曝光，引发社会广泛关注。尤其是Log4j2远程代码执行漏洞（CNVD-2021-95914/CVE-2021-44228），攻击者利用该漏洞，可在未授权的情况下远程执行代码，获得服务器控制权限。经我们综合技术分析研判，该漏洞具有危害程度高、利用难度低、影响范围大的特点。为正确处置突发漏洞风险，降低漏洞带来的损失，我们整理《Apache Log4j/Log4j2相关漏洞识别、保护、检测和响应技术指南》以供相关单位、企业及个人参考。


二、漏洞信息

此次曝光的漏洞涉及Apache log4j 1.x to 2.x 多个版本，漏洞基础信息如下：


- CVE-2021-44228 Apache Log4j 2.x 远程代码执行漏洞

- CVE-2021-4104 Apache Log4j 1.x 远程代码执行漏洞

- CVE-2021-45046 Apache Log4j 2.x 拒绝服务和远程代码执行漏洞 

- CVE-2021-45105，拒绝服务漏洞


三、漏洞情况分析

1.CVE-2021-44228

受影响的版本：从2.0-beta9到2.12.1和2.13.0到2.14.1的所有版本


Apache Log4j是一个基于Java的日志记录组件。Apache Log4j2是Log4j的升级版本，通过重写Log4j引入了丰富的功能特性。该日志组件被广泛应用于业务系统开发，用以记录程序输入输出日志信息。


Log4j2组件在处理程序日志记录时存在JNDI注入缺陷，未经授权的攻击者利用该漏洞，可向目标服务器发送精心构造的恶意数据，触发Log4j2组件解析缺陷，实现目标服务器的任意代码执行，获得目标服务器权限。


Apache Log4j的默认配置支持JNDI（Java命名和目录接口）查询，可以执行由LDAP、RMI和DNS等远程服务提供的任意代码。


2.CVE-2021-4104

当攻击者对Log4j配置具有写访问权限时，Log4j 1.2中的JMSAppender容易受到不可信数据的反序列化。攻击者可以提供TopicBindingName和TopicConnectionFactoryBindingName 配置，导致JMSAppender以类似于CVE-2021-44228的方式执行JNDI请求，从而导致远程代码执行。注意这个问题只有在特别配置为使用JMSAppender时才会影响Log4j 1.2，而这不是默认的。


3.CVE-2021-45046

受影响的版本：从2.0-beta9到2.12.1和2.13.0到2.15.0的所有版本

Apache Log4j 2.15.0中针对CVE-2021-44228的修复在某些非默认配置中不完整。当日志配置使用非默认模式布局和上下文查找（例如，$${ctx:loginId}）或线程上下文映射模式（%X、%mdc或%MDC）使用JNDI查找模式制作恶意输入数据，从而导致拒绝服务 (DOS) 攻击。Log4j 2.16.0通过删除对消息查找模式的支持和默认禁用JNDI功能来修复此问题。

CVE-2021-45046同样存在远程代码执行风险：

1.如果Java应用程序满足受CVE-2021-45046影响的先决条件，并且使用log4j2 < 2.15，则影响为RCE（远程代码执行）。

    https://twitter.com/wdormann/status/1471522903963353095

2.当攻击者可以控制模式布局的**非消息**部分时，则影响为RCE（远程代码执行）。

    https://twitter.com/pwntester/status/1471511483422961669

3.绕过 Log4J 2.15.0 中的 allowedLdapHost 和 allowedClasses 检查

    https://twitter.com/marcioalm/status/1471740771581652995


4.CVE-2021-45105

受影响的版本：从2.0-beta9到2.16.0的所有版本

在某些非默认的配置中，Apache Log4j2不能防止自引用查找的不受控制的递归。对线程上下文映射（MDC）输入数据有控制权的攻击者可以制作包含递归查找的恶意输入数据，导致StackOverflowError，从而终止进程，导致拒绝服务攻击。

五、保护

5.1 升级软件版本

1.Log4j 2.x

在Log4j 2.12.2（适用于Java 7）和2.17.0（适用于Java 8或更高版本）中，消息查询功能已被完全删除。此外，JNDI被默认禁用，其他默认配置设置也被修改，以缓解CVE-2021-44228、CVE-2021-45105和CVE-2021-45046。


操作步骤：

升级到Apache Log4j 2.17.0

下载地址：

https://logging.apache.org/log4j/2.x/download.html


2.Log4j 1.x

删除JMSAppender类或不配置它。Log4j 1不再支持，且可能包含未修复的错误和漏洞，例如CVE-2019-17571。

操作步骤：

$ zip -d log4j-1.2.17.jar org/apache/log4j/net/JMSAppender.class


5.2 缓解措施

1.阻止来自内部主机的LDAP、RMI、nis、nds、corba、iiop协议的出站连接，可以在边界防火墙和操作系统防火墙上进行设置。，推荐在操作系统防火墙上进行设置（边界不可控且需要防止黑客在内网发起攻击）。

2.将以下dnslog域名进行屏蔽，在企业内部的DNS服务器或边界设备上实施。
