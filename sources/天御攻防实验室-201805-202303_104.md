# 欧盟实施首个针对网络攻击的制裁措施，制裁俄中朝实体和个人

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0MzgyMzM2Nw==&mid=2247484153&idx=1&sn=3b7382ae521e77cc4d9f1b3a55d06e2b&chksm=fb04c191cc7348879212bb8ec9cf240cc7e7d7fe1b8d76208d6f7dac87a24ab9d00d387f1b51&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU0MzgyMzM2Nw==&mid=2247484153&idx=1&sn=3b7382ae521e77cc4d9f1b3a55d06e2b&chksm=fb04c191cc7348879212bb8ec9cf240cc7e7d7fe1b8d76208d6f7dac87a24ab9d00d387f1b51&scene=27#wechat_redirect)

![](../Images/b90718f105b7d3f90a150653432f332c.png)  

  

  

    2020年7月30日（周四）,**欧盟****首次**宣布对涉嫌**网络攻击**者实施**单边制裁**。根据欧盟成员国共同发布的一份声明，措施包括对俄罗斯军事情报人员以及朝鲜公司和中国公司的财务和旅行限制。  
  
    *制裁措施包括旅行禁令及资产冻结。欧盟的个人、企业和其他实体不得向被列入黑名单者提供资金。*  
  
    此举标志着欧盟首次向那些对欧盟成员国及其公民实施网络攻击的黑客行使法定权力。  
  
    2019年5月17日，欧盟建立了有针对性的限制性措施的制裁框架，以制止和应对针对欧盟或其成员国构成外部威胁的网络攻击。"理事会决定"（CFSP）2019/797和 "理事会条例 "2019/796两个文件对新框架进行了阐述。  
  
    声明指出，受到制裁的6名个人和3个实体参与了许多网络攻击，包括在2018年入侵总部位于荷兰的禁止化学武器组织（OPCW）。攻击手段包括利用"WannaCry"、"NotPetya"、"Operation Cloud Hopper"等恶意软件。

  

    欧盟指控来自俄罗斯GRU军事情报部门的74455部队，这是一个被称为"沙虫（Sandworm）"的网络攻击组织，于2018年使用勒索软件对数家欧洲公司发动两次网络攻击，致其遭受重大财务损失。据称这家名为"沙虫（Sandworm）"的网络攻击组织是恶意软件NotPetya袭击的幕后黑手，曾在2015、2016年两度攻击乌克兰电网。制裁还针对四名俄罗斯黑客，他们与调查叙利亚使用化学武器情况的禁止化学武器组织的网络攻击有关。

  

制裁名单中还包括一家朝鲜出口公司和两家中国公司，

  

   朝鲜公司Chosun Expo因涉嫌支持黑客组织“Lazarus Group”而受制裁。Lazarus集团被认为是全球一连串重大攻击的幕后黑手。据称该公司涉嫌支持恶意软件WannaCry以及全球一系列重大金融攻击，包括对孟加拉银行的网络盗窃以及2014年对索尼影业（Sony Pictures）的黑客攻击。

  
    被制裁的中国公司之一是海泰科技发展有限公司（Haitai Technology Development），欧洲理事会指控该公司支持"云端跳跃行动"（Operation Cloud Hopper）网络攻击，从全球跨国公司窃取商业敏感数据，致其遭受重大损失。  

  

中方回应：

中国驻欧盟使团：反对欧盟以网络攻击为由实施单边制裁

  

欧盟30日以从事网络攻击活动为由，决定对包括中方个人和实体在内的有关人员和机构实施制裁。中国驻欧盟使团发言人30日晚在回答记者提问时表示，反对单边制裁，主张通过对话共同维护网络安全。

  

使团发言人说，中国是网络安全的坚定维护者，也是黑客攻击的最大受害国之一，始终依法打击一切形式的网络黑客攻击行为。我们也一贯主张，国际社会应当在相互尊重、平等互利的基础上，通过对话合作共同维护网络空间的安全，反对动辄诉诸单边制裁措施。

  

欧盟外交与安全政策高级代表博雷利30日发表声明说，欧盟理事会决定对包括中国个人和机构在内的6名自然人和3个法人实体实施制裁。

  

俄方回应：

  

俄罗斯外交部表示，反对单边制裁，莫斯科将效仿欧盟对涉嫌网络攻击的制裁措施。

  

Разумеется, недружественная акция ЕС не будет оставлена без ответа. Как известно, в дипломатии все «зеркально».

毋庸置疑，欧盟的不友好行动不会没有回应。在外交上，一切都是对等的。

  

评论说，欧盟7月30日决定以网络攻击为借口对俄罗斯进行单边制裁，这个借口是没有根据和凭空捏造的，令人感到不理解和遗憾。欧盟此举背后带有明显的政治色彩。

  

评论说，在快速发展的跨境数字空间内网络冲突不可避免，但是冲突的解决应该建立在多边磋商的基础上。目前，国际社会需要的是通过协作和专业对话制定关于网络空间的通用规则，而不是单边制裁。单边制裁只会引起网络混乱和政治对抗。
