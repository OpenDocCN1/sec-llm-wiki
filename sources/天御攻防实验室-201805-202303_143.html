Dalton - Suricata和Snort IDS规则测试系统添加物理Sensor

 

1.Dalton Controller 配置

在/opt/dalton/engine-configs/{snort,suricata}下添加对应版本的配置文件，如：suricata-4.1.0.yaml，且此配置文件需要跟物理Sensor的配置一致

2.Sensor配置

# git clone https://github.com/tianyulab/dalton.git
# cd dalton/dalton-agent
# vi dalton-agent.conf
  DALTON_API = http://labs.tianyulab.com/dalton/sensor_api
# python dalton-agent.py -c dalton-agent.conf &
