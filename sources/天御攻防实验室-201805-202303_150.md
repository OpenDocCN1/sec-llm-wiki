# Bro FAQ（一）：如何让Bro支持提取文件大少 > 1GB的文件？

So What is Bro?

  

Bro是一款开源且功能强大的网络安全监控平台（Bro Network Security Monitor），常用于入侵检测、应急响应、取证和威胁猎杀（Threat Hunting）等方面。第一版由美国UC Berkeley大学Vern Paxson教授于1995发布。

  

![](../Images/9c8d48b6be3cb10107edbea3f90129e3.png)

  

1.配置Bro

*vi $prefix/etc/node.cfg*

\[bro\]

type=standalone

host=localhost

interface=eth0 # 指定监听网卡

  

*vi $prefix/etc/networks.cfg*

192.168.x.0/24      Private IP space # 指定本地网段

  

*vi $prefix/etc/broctl.cfg*

SitePolicyStandalone = local.bro # 加载站点定义的策略脚本

LogDir = /var/log/bro # 日志存储目录，软连接到SpoolDir

SpoolDir = /var/spool/bro # 数据存储目录

CfgDir = /etc/bro # 配置文件目录

  

2.网卡配置

禁用网卡TSO (TCP Segmentation Offload）功能：

1.  for i in rx tx sg tso ufo gso gro lro; do ethtool -K eth0 $i off; done
    
2.  ethtool -k eth0
    

  

3.加载文件提取脚本

vi $prefix/site/local.bro

@load /usr/share/bro/policy/frameworks/files/extract-all-files.bro

默认$prefix：

1.  /usr/share/bro/
    
2.  /etc/bro/
    

  

4.修改文件提取的默认值

vi /usr/share/bro/policy/tuning/defaults/extracted\_file\_limits.bro

@load base/files/extract

\# 默认值是100MB，0代表没有限制.

redef FileExtract::default\_limit = 0;

#另外注意检查：/usr/share/bro/base/files/extract/main.bro对应的限制

  

5.配置检查&部署、重启

broctl check

broctl deploy
