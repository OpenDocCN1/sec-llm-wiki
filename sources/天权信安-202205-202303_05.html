在Kali Linux安装Parallels Tools


HELLO


本文所使用的环境如下

1、Parallels Desktop 18 for Mac Standard Edition2、MacBook Pro M2 Ventura 13.13、kali-linux-2022.4-installer-arm64.iso

安装好系统后，点击右上方三角感叹号，安装Parallels Tools。

点击继续

右键挂载光盘

双击打开光盘，在当前文件夹打开终端

切换root身份

sudo su

在根目录下（或其他目录下）创建一个文件夹，将当前目录下所有文件全部复制至该文件夹

mkdir /Parallels\ Tools && cp -r ./* /Parallels\ Tools

为这些文件赋予可执行权限

chmod + x /Parallels\ Tools/*

执行./install

按Enter键。直到出现


留意此处需要的包，继续Enter，一段时间后会出现



在Kali中打开FireFox，进入网址http://old.kali.org/kali/pool/main/l/linux/



寻找以下几个包

linux-headers-6.0.0-kali3arm64_6.0.7-1kali1_arm64.deblinux-headers-6.0.0-kali3-common_6.0.7-1kali1_all.deblinux-kbuilk-6.0_6.0.7-1kali1_arm64.deb


进入到下载文件夹，并在此打开终端



使用dpkg安装

sudo dpkg -i linux-kbuild-6.0_6.0.7-1kali1_arm64.deb && dpkg -i linux-headers-6.0.0-kali3-common_6.0.7-1kali1_all.deb && dpkg -i linux-headers-6.0.0-kali3-arm64_6.0.7-1kali1_arm64.deb



安装完成后，重新回到文件夹，执行./install

可以看到第一个包的需求已经没有了，Enter下一步。等待后



至此，Parallels安装成功，重启即可



此方法同样适用于2021.1版本的Kali Linux，下载对应内核版本的linux-headers和linux-kbuilk安装即可。

   注意软件包因依赖问题需按顺序安装。首先安装linux-kbuild-6.0_6.0.7-1kali1_arm64.deb，再安装dpkg -i linux-headers-6.0.0-kali3-commo_6.0.7-1kali1_all.deb，最后安装linux-headers-6.0.0-kali3-arm64_6.0.7-1kali1_arm64.deb。
