```
linux-headers-6.0.0-kali3arm64_6.0.7-1kali1_arm64.deblinux-headers-6.0.0-kali3-common_6.0.7-1kali1_all.deblinux-kbuilk-6.0_6.0.7-1kali1_arm64.deb
```

![](../Images/734741fc8f34ef6d66a6e8f5f7ff8dd4.png)

*


安装完成后，重新回到文件夹，执行./install![](../Images/79d0759cd1c84678e7ce7226572d880e.png)  

可以看到第一个包的需求已经没有了，Enter下一步。等待后

![](../Images/ed6742640a702502ac7a84bfb66f7418.png)  
  

至此，Parallels安装成功，重启即可

![](../Images/2c9fd681d51ad88cf7ea5590a3b4eab7.png)  
  

此方法同样适用于2021.1版本的Kali Linux，下载对应内核版本的linux-headers和linux-kbuilk安装即可。  
  
   注意软件包因依赖问题需按顺序安装。首先安装linux-kbuild-6.0\_6.0.7-1kali1\_arm64.deb，再安装dpkg -i linux-headers-6.0.0-kali3-commo\_6.0.7-1kali1\_all.deb，最后安装linux-headers-6.0.0-kali3-arm64\_6.0.7-1kali1\_arm64.deb。
