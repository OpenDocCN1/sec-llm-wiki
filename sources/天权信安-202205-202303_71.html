01 crypto-xor2


Winhex 查看 cipher 文件，发现是很规整的数据（不是 zip、png 之类的文件），于是猜测这是题目导出后的数据，已知异或是可以逆回去的（异或 ord(key[count % 4] 回去），因此只要知道了 key 值就可以解出 flag 了，思考解出来的前几个字符一定是 flag，因此我们可以逐个枚举（这里我使用 check 作为枚举串），最后解出 key 就是 xxxx，根据下面的脚本就可以解出 flag 啦

#! /usr/bin/env python# -*- coding: UTF-8 -*-
from Crypto.Util.number import *
with open('cipher', 'rb') as f:    cipher = f.read().encode('hex')
print(cipher)
check = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz""""for i in check:    for j in check:        for m in check:            for n in check:                key = str(i)+str(j)+str(m)+str(n)"""
for j in check:    key = "xxxx"    flag = ""    count = 0    for i in range(0, len(cipher), 2):        tmp = cipher[i] + cipher[i + 1]        num = int(tmp, 16)        flag += chr(num ^ ord(key[count % 4]))        count += 1    print(flag)

02 easy_ctf


此类型题目属于python爬虫信息处理(参考文章https://www.cnblogs.com/daiorz/p/12294963.html)

 

这类题目一般都是给一个页面，页面中有算式或者是一些数字，要求在很短的时间内求出结果并提交，如果结果正确就可以返回 flag，因为所给时间一般都很短而且计算比较复杂，所以只能写脚本，其中我用到了 re 库和 requests 库，前者可以定位到目标位置（就是给出字符串的位置），后者用于 get 与 post 网页（先 get，后接 post 再一直循环接 post），另外要说明本题的脚本可能需要运行多次才能得到 flag，存在一定的误差性

#! /usr/bin/env python# -*- coding: UTF-8 -*-
import reimport requests
r = requests.Session()
# ans = "IUfZgB6obzK0XScHhPwq5J1"
s = r.get("http://120.79.191.238:41280/")
for i in range(3):    text = s.text    print(text)    obj = re.compile(        r'<td style="WORD-WRAP: break-word" width="1600">(?P<data>.*?)<td>',        re.S)    result = obj.finditer(text)    for item in result:        data = item.group('data')    print(data)
    result = {}
    for i in data:        if (i not in result):            result[i] = 0        result[i] += 1    del result['\n']    del result['\r']    # print(result)    lenn = len(result)    ans_tmp = ""    for j in range(lenn):        minn = 1000000        tmp = ""        for a, b in result.items():            if (b < minn):                tmp = a                minn = b        for a, b in result.items():            if (b == minn):                haha = a        ans_tmp += haha        result.pop(haha)    # print(ans_tmp)    ans = ans_tmp    # print(ans)
    upload = {"ans": ans}    s = r.post("http://120.79.191.238:41280/", data=upload)
