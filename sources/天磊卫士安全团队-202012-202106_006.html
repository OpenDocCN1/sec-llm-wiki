如果常见的信息收集方法都试过了一遍后，没有找到网站比较敏感的东西，这时候可以试试我这个技巧

 

大家扫描网站都会遇到这么一个路径：https://www.baidu.com/favicon.ico

 

一般人可能就忽略过去了，因为这个路径打开也就是个网站图标文件，可能觉得没什么利用价值

 

这时候我们可以用shodan加上一个python脚本来获取网站icon的hash值来模糊查询相同icon的站点

 

先要知道网站icon的地址，一般都是路径/favicon.ico，扫描器或者f12基本都可以找到

 

接着用python脚本跑出hash值，这边我们已百度为例子

 

先上脚本

import mmh3import requestsimport urllib3urllib3.disable_warnings()from requests.packages.urllib3.exceptions import InsecureRequestWarningrequests.packages.urllib3.disable_warnings(InsecureRequestWarning)response = requests.get('https://zhaopin.meituan.com/favicon.ico',verify=False)favicon = response.content.encode('base64')hash = mmh3.hash(favicon)print "http.favicon.hash:"+str(hash)


跑出hash值后，打开shodan 利用语法

http.favicon.hash:-1588080585

 

这边可以看到还是搜索到不少东西的

 

我们修改下脚本，上面那个需要每次都修改代码里面的url来获取hash值

import mmh3import requests,sysimport urllib3urllib3.disable_warnings()from requests.packages.urllib3.exceptions import InsecureRequestWarning
def Main(url):    requests.packages.urllib3.disable_warnings(InsecureRequestWarning)    response = requests.get(url=url,verify=False)    favicon = response.content.encode('base64')    hash = mmh3.hash(favicon)    print("http.favicon.hash:"+str(hash))if __name__=='__main__':    if len(sys.argv) != 2:        print("python hash.py http://127.0.0.1")    else:        url = sys.argv[1]        Main(url)


我们修改一下，可以直接输入url获取hash值
