1世界级游戏外挂黑产被捣毁！江苏昆山警方抓获该组织核心成员  
**关键词：**外挂  
  
  

  

近日，江苏昆山警方抓获全球最大游戏外挂组织核心成员，打断“世界级”游戏外挂“黑色产业链”。  

  

****1******·****游戏外挂“NO.1”“浮出水面”  
**

近年来，随着一些网络游戏的热度不断提升，外挂也日渐猖獗。所谓“外挂”，是指通过修改游戏数据而为玩家谋取利益的作弊程序或软件。一直以来，外挂都被视为游戏界的“毒瘤”，尤其是恶性外挂，严重损害玩家的游戏体验，影响游戏正常运营。

2020年3月，昆山警方接腾讯公司报案称有人开设“和平精英”外挂境外销售网站，针对该公司“和平精英”游戏销售一款名为“鸡腿”的外挂程序。

在掌握相关线索后，昆山警方立即进行专案攻坚，在苏州市公安局的指导下，辗转6省9地，一举捣毁17个在线外挂交易网站和发卡机器人平台，李某、曹某等10人涉嫌提供侵入、非法控制计算机信息系统程序、工具罪被依法采取刑事强制措施，这条集外挂制作、维护、分销于一体的“黑色产业链”被初步摧毁。

在昆山警方持续打击的过程中，“鸡腿”外挂全球官网论坛发布这样一则公告：“由于腾讯公司与有关部门的联合执法行动导致两名中国区版主以及多名主要代理商被抓，我们不得不决定停止在中国市场的销售‘鸡腿’和平精英辅助”。

面对“初步胜利”和犯罪分子的“举白旗”投降，昆山警方打击的脚步没有停，而是不断的深入推进。

  

![](../Images/f563e87d80365ad9d793c20602bc0d89.png)

  

在进一步侦查的过程中，该“黑色产业链”的“头部”人员王某某进入了警方的视线，随着对其身份信息的调查，警方发现王某某背后是全球最大的游戏外挂组织，涉案人员遍布全球，经营国内外多个游戏外挂，流水达数亿元。

2021年1月12日，昆山警方在初步掌握王某某的行踪后前往湖南长沙，在其住处将其抓获，同时查获的，还有他名下价值千余万的劳斯莱斯、法拉利、兰博基尼等豪车。

  

![](../Images/cad1d7cc563af0a1ca1a1909199162d1.png)

**2·幕后大鳄竟是小职员**

通过对王某某的调查，警方了解到他是该游戏外挂组织的全球财务负责人，他的上家是代号为“Li”的成员，是该组织全球的运营负责人，同时负责全球的多项销售业务，其他成员分布在各地，而王某某每隔十天需要给成员发放薪酬，发放的方式十分隐蔽。

![](../Images/20485aedcaa3c9b0d65ef1beb2870149.png)

  

案件专班开始高速运转，信息组、研判组、抓捕组等开始分头行动，同时办案民警以王某某的身份通过境外聊天软件与“Li”进行联系，制造王某某仍“安然无恙”的假象，从而稳住对方。  

1月12日至1月17日，昆山警方陆续在深圳、杭州、郑州等地抓获多名该组织的技术人员，但“Li”的相关信息“仍然成谜”。

1月18日，案件有了突破性的进展，通过海量的数据筛选，Li的身份初步凸显，很可能是位于天津的何某某。这时，专班连夜乘坐飞机前往，对接当地公安开展外围更缜密的侦查。

  

![](../Images/4db81fb0cc0fa9773a7e3b9581737664.png)

  

1月20日上午，在一切准备就绪后，昆山警方迅速行动，在何某某（Li，网络代号九条杠“IIIIIIIII”）住所将其抓获，同时查获何某某名下价格2600余万的虚拟币以及房产、车辆等涉案财物，而此时距离发放薪酬只剩几个小时。  

值得一提的是，在何某某被抓获的时候，他仍住着相对简陋的公寓，在一个小公司内上着班，每个月拿着3000元的工资，与王某某的生活状态截然不同，完全看不出是一位游戏外挂届的“大鳄”。  

目前，何某某、王某某某等人涉嫌提供侵入、非法控制计算机信息系统程序、工具罪，已被依法采取刑事强制措施，该组织的境外涉案人员的打击工作，仍在进一步开展中。

  

****3********·********警方提醒****     制作 " 外挂 " 行为本身就涉嫌破坏计算机信息系统罪，是违法犯罪行为，作为网民应当具备守法意识，不要为违法犯罪行为推波助澜。

同时，广大网民在日常上网时，应当通过正规渠道下载官方软件，拒绝下载来源不明的可疑APP，避免手机被植入木马病毒，造成不必要的财产损失。

**关键词：**白帽  黑帽  数据泄露  

  

**1·白帽变“黑帽”？提报数据泄露惹官司**

  

前不久，英国白帽子 Rob Dyke 向非营利组织 Apperta 上报了一起数据泄露事件，然而看似寻常的威胁提报，却让Rob Dyke陷入了法律纠纷。  

  

![](../Images/5da22fc6240ad448a99638a9bcedc679.png)

  

Apperta 基金会，由英国国家医疗服务系统 ( NHS ) 和 NHS 公司 ( NHS Digital ) 发起成立，致力于在数字医疗和社会护理领域推广相关标准的非盈利组织。

*   事起 GitHub，提报数据泄露
    

月初，白帽子Rob Dyke 在 GitHub 上发现了一个存储着 Apperta 基金会的密码、API 密钥和财务信息的仓库，遂向Apperta 基金会报告该事件，并得到了 Apperta 基金会的致谢。

3月9日，白帽子Rob Dyke不仅收到了律师函，还收到了警方邮件，称其涉嫌“计算机滥用”等罪名。

*   倒打一耙OR法规问题？
    

Apperta基金会律师称，Apperta 认为 Rob Dyke 的行为是非法的，并且要求他承诺删除相关所有数据。警方也称Rob Dyke涉嫌“计算机滥用”相关罪名。

对此，Rob Dyke则表示，他发现的数据在 GitHub 上已公开两年多时间，且并非通过非法攻击行动所得。之所以进行提报，也是因为曾与Apperta 基金会有过合作，且熟悉安全漏洞提报的行业惯例。  

  

从法规上来看，英国1990年颁布的《计算机滥用法案》中，的确将报告数据泄露事件视为违法行为。只不过在2021年，提报安全问题已成为行业惯例的的今天，这样的法规却成为吓走白帽，束缚安全建设的制约。
