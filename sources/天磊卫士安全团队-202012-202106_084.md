# **前言**

Apache Shiro是一个强大且易用的Java安全框架，执行身份验证、授权、密码和会话管理。使用Shiro的易于理解的API，您可以快速、轻松地获得任何应用程序，从最小的移动应用程序到最大的网络和企业应用程序。

当它和 Spring 结合使用时，在一定权限匹配规则下，攻击者可通过构造特殊的 HTTP 请求包完成身份认证绕过。

影响范围：Apache Shiro < 1.7.1

# **漏洞分析**

org.apache.shiro.web.filter.mgt.PathMatchingFilterChainResolver#getChain 

  

![](../Images/cfebd496dfee00a77562155ff2ece779.png)

这个if语句判断请求地址是否以/结尾，为真则去掉/。  

 

![](../Images/7d46a2cdc7bd7876a6462ee26ea11b68.png)

  

这个while里的pathMatchs()方法是个重点。

这里设置了拦截器链进行三次循环匹配

1  pathMatches("/doLogin","/admin/ ")

2  pathMatches("/admim/\*","/admin/ ")

3  pathMatches("/\*\*","/admin/ ")

![](../Images/4fdc76290df1c4ee680642898b9560c2.png)

  

在这里我们探究为什么在doMatch方法中”/admin/\*” 和”/admin/ “为什么不能匹配

 

先来试试/admin/\*与/admin/1

![](../Images/43422df21f4f7755ef5a901a071a7ce4.png)

  

先执行表达式看看结果，返回true，表示成功匹配此路径，继续跟进。

![](../Images/8569c0111e39d64745af888a5e0df113.png)

  

![](../Images/587fd07913475af2b4342000a1ff513c.png)

 

在这里调用tokenizeToStringArray方法对请求路径用/进行切割，返回数组。

![](../Images/c29bb84412ca1f876d7c787479e0542c.png)

  

第一个字符串为admin。

![](../Images/252b05750de7eaf6bcc488c621c78004.png)

  

PathDIrs为{“admin”,”1”}

PattDirs为{“admin”,”\*”}

![](../Images/ca6d159ef93b0b53c3a5138fc75026af.png)

  

在进行字符串逐一匹配都为true.

![](../Images/5f3245d6f76a9fc3a9372a7b1e5c8ecf.png)

  

这里匹配最后一个字符 \*和1，进行判断，最终结果返回true。

![](../Images/66965f8c1a792c8f86ea9180545dce48.png)

最后return pattern为/admin/\*说明被拦截器拦截到了。

 

再以同样方式看下”/admin/\*”和”/admin/ ”

![](../Images/28fff9a83f3a49dfa36f27de3038a8a7.png)

  

关键也在于调用tokenizeToStringArray会对字符串进行trim（）处理。

token = token.trim()，这里token去掉空格，导致无字符串返回。

![](../Images/4d8de43190b6b300e1ab04421a189feb.png)

  

其实这里的路径经过trim()后相当于/admin/\*和/admin 匹配校验。

![](../Images/8a37add50b694897e965ead83ada4243.png)

返回false，匹配失败，导致权限绕过。

 

![](../Images/a349461086591c2bde8274f3b6614231.png)

 

再进入第三个默认的全路径匹配，这里就没什么影响了 

![](../Images/fb84585862a41e2dd6606bf52a237cbe.png)

  

后面spring接受到的路径为”/admin/ “，按照正常逻辑返回admin页面。

![](../Images/d2c1d03823784e215f14c621e3a1cf33.png)

  

![](../Images/652d010677d46dffe6b2d8e06cb47952.png)
