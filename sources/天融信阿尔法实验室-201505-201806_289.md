# 1 总体情况

## 1.1 本周漏洞情况

*   本周统计CVE漏洞82个，其中高危漏洞24个，中危漏洞51个，低危漏洞7个。漏洞数与前一周环比减少了41.8%，与去年同比减少了29.9%；
    
*   本周记录了思科公司最新发布的几个漏洞，涉及到ASA、 IOS 、Social Miner、FireSight Management Center、Secure Access Control Server等，漏洞类型主要是拒绝服务、信息泄露、SQL 注入、跨站点脚本等，在本周增加的漏洞数量中，按公司累计排名，思科公司最新发布的漏洞数量位居第一；还记录了IBM公司最新发布的几个漏洞，涉及到InfoSphere、Tivoli、WebSphere、Domino等，漏洞类型主要是权限提升、信息泄露、缓冲区溢出、安全限制绕过等；也关注了有关Android 5.1.1 之前的版本存在的多个漏洞；
    
*   本周记录的安全公司的产品漏洞是美国惠普（HP）公司的一套日志管理软件工具HP ArcSight Logger存在的几个漏洞，漏洞类型是密码硬编码、权限提升、信息泄露等；
    

## 1.2 本周恶意域名与IP地址跟踪情况

*   本周恶意IP地址数量在前两周持续出现向上突破的形态后，开始出现反向调整，重回前期的整理区间的形态，突破走势看来暂时告一段落；
    
*   本周单个IP地址对应的恶意域名数量前10位列表显示，大陆出现一个地址的更替，目前在前十位列表中有八个地址跟一组恶意域名组有关，此状态已经持续了两周；海外地址没有变化，标志着上周我们跟踪的恶意域名组对应的IP地址迁移现象从美国蔓延到韩国的现象继续保持；
    
*   在大陆的恶意IP地址数量地理分布排名列表中，北京、江苏、广东、浙江、河南位居前五，山东、上海、湖南、河北、四川位居六至十位，跟前一周相比，西部省份四川取代山西进入前十；
    
*   在海外的恶意IP地址数量地理分布排名列表中，美国、荷兰、香港、韩国、德国位居前五，跟前一周相比没有变化；

# 3 恶意域名与IP地址跟踪

## 3.1 总体情况

本期从国家权威部门获取的恶意域名数是26个，同时重新整理前期输入的恶意域名，将长期不再有效的恶意域名剔除，得出目前最新的恶意域名数是13774个，将这些域名进行例行的IP地址解析，本周的验证结果如下：

*   本周单个IP地址对应的恶意域名数量前10位列表显示，大陆出现一个地址的更替，目前在前十位列表中有八个地址跟一组恶意域名组有关，此状态已经持续了两周；海外地址没有变化，标志着上周我们跟踪的恶意域名组对应的IP地址迁移现象从美国蔓延到韩国的现象继续保持；
    
*   在大陆的恶意IP地址数量地理分布排名列表中，北京、江苏、广东、浙江、河南位居前五，山东、上海、湖南、河北、四川位居六至十位，跟前一周相比，西部省份四川取代山西进入前十；
    
*   在海外的恶意IP地址数量地理分布排名列表中，美国、荷兰、香港、韩国、德国位居前五，跟前一周相比没有变化；
    
*   本期全部有效IP地址数量是3028个，其中海外有效IP地址数量是1963个，大陆有效IP地址数量是1065个，全部有效IP地址较上周相比减少了184个，降幅为5.73%，跟前一周相比，海外IP地址数量和大陆的IP地址数量均出现一定幅度的下降；
    
*   本统计期恶意IP地址数量在前两周持续出现向上突破的形态后，开始出现反向调整，重回前期的整理区间的形态，突破走势看来暂时告一段落。以下是本统计期的数量趋势图：
