# 1 总体情况

## 1.1 本周漏洞情况

*   本周统计CVE漏洞52个，其中高危漏洞18个，中危漏洞33个，低危漏洞1个。漏洞数与前一周环比减少了43.5%，与去年同比减少了58.7%；
    
*   本周记录了思科公司最新发布的多个漏洞，涉及到Web安全设备、内容安全管理设备等多个产品，漏洞类型主要是拒绝服务等；本周该公司产品的漏洞数量排名第一；还记录了IBM公司最新发布的多个漏洞，涉及到WebSphere，WEB服务器等多个产品，漏洞类型主要有缓冲区溢出、信息泄露、拒绝服务等；
    
*   本周还继续跟踪了一些安全公司的漏洞，本周是HP ArcSight Logger存在的一个安全策略绕过漏洞；
    

## 1.2 本周恶意域名与IP地址跟踪情况

*   本统计期恶意IP地址数量首次突破了前期的高位平台区间，初步打破了长期整理的区间，这个整理的局面是否会彻底打破，还有待继续观察；
    
*   根据分析单个IP地址对应的恶意域名数量前10位列表的结果，大陆没有出现新的地址，而海外出现了两个地址的更替。这标志着2014年上半年爆发的多个恶意域名组再次沉寂；不过“大陆前十位列表中有七个地址跟两组恶意域名组的爆发有关，集中度很高”这个趋势依旧持续；
    
*   在大陆的恶意IP地址数量地理分布排名列表中，北京、江苏、广东、浙江、河南位居前五，跟前一周相比，江苏排名靠前到第二位，山西取代四川进入前十；
    
*   在海外的恶意IP地址数量地理分布排名列表中，美国、荷兰、香港、韩国、德国位居前五，跟前一周相比没有变化；

# 3 恶意域名与IP地址跟踪

## 3.1 总体情况

本期从国家权威部门获取的恶意域名数是86个，同时重新整理前期输入的恶意域名，将长期不再有效的恶意域名剔除，得出目前最新的恶意域名数是13643个，将这些域名进行例行的IP地址解析，本周的验证结果如下：

*   根据分析单个IP地址对应的恶意域名数量前10位列表的结果，大陆没有出现新的地址，而海外出现了两个地址的更替。这标志着2014年上半年爆发的多个恶意域名组再次沉寂；不过“大陆前十位列表中有七个地址跟两组恶意域名组的爆发有关，集中度很高”这个趋势依旧持续；
    
*   在大陆的恶意IP地址数量地理分布排名小表中，北京、江苏、广东、浙江、河南位居前五，跟前一周相比，江苏排名靠前到第二位；山西取代四川进入前十；
    
*   在海外的恶意IP地址数量地理分布排名列表中，美国、荷兰、香港、韩国、德国位居前五，跟前一周相比没有变化；
    
*   本期全部有效IP地址数量是3048个，其中海外有效IP地址数量是1946个，大陆有效IP地址数量是1102个，全部有效IP地址较上周相比增加了70个，增幅为2.35%；跟前一周相比，海外IP地址数量出现轻微下降而大陆的地址数量出现大幅上升；
    
*   本统计期恶意IP地址数量首次突破了前期的高位平台区间，初步打破了长期整理的区间，这个整理的局面是否会彻底打破，还有待继续观察。以下是本统计期的数量趋势图：
