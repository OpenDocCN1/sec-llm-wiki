# 1 总体情况

## 1.1 本周漏洞情况

*   本周统计CVE漏洞92个，其中高危漏洞56个，中危漏洞29个，低危漏洞7个。漏洞数与前一周环比减少了29.7%，与去年同比减少了79.4%；
    
*   本周记录了微软公司最新发布的九月安全公告中的五十多个漏洞，大部分是高危漏洞，涉及到IE浏览器、Windows、Lync Server、Exchange Server、Office、dot NET Framework等多个产品，漏洞类型包括任意代码执行、拒绝服务、访问限制绕过、权限提升等高危漏洞，本周该公司产品的漏洞数量排名第一；
    
*   本周还记录了思科、Adobe、EMC、ISC-BIND、FFmpeg等公司的多个产品的多个漏洞；并且继续跟踪了一些安全公司的产品的漏洞，本周是Sophos公司的防火墙产品存在的一个安全漏洞；
    

## 1.2 本周恶意域名与IP地址跟踪情况

*   本统计期恶意IP地址数量已经是连续六周在前期的高位平台区间整理运行了，这种平衡的局面何时打破，有待继续观察；
    
*   根据分析本统计期单个IP地址对应的恶意域名数量前10位列表，发现尽管大陆和海外均没有出现新的地址，不过以下趋势依旧存在：如“2014年上半年爆发的多个恶意域名组开始从沉寂变为活跃，其对应的IP地址正在向海外（韩国）迁移” 和“大陆前十位列表中有七个IP地址跟两组恶意域名组的爆发有关，集中度很高”；
    
*   在大陆的恶意IP地址数量地理分布排名列表中，北京、广东、浙江、江苏、河南位居前五，跟前一周相比，广东排名靠前到第二位，其余排名均不变；
    
*   在海外的恶意IP地址数量地理分布排名列表中，美国、荷兰、香港、韩国、德国位居前五，跟前一周相比没有变化；

# 3 恶意域名与IP地址跟踪

## 3.1 总体情况

本期从国家权威部门获取的恶意域名数是18个，同时重新整理前期输入的恶意域名，将长期不再有效的恶意域名剔除，得出目前最新的恶意域名数是13557个，将这些域名进行例行的IP地址解析，本周的验证结果如下：

*   根据分析单个IP地址对应的恶意域名数量前10位列表的结果，尽管大陆和海外均没有出现新的地址，不过以下趋势依旧存在：如“2014年上半年爆发的多个恶意域名组开始从沉寂变为活跃，其对应的IP地址正在向海外（韩国）迁移”；“大陆前十位列表中有七个地址跟两组恶意域名组的爆发有关，集中度很高”；
    
*   在大陆的恶意IP地址数量地理分布排名列表中，北京、广东、浙江、江苏、河南位居前五，跟前一周相比，广东排名靠前到第二位，其余排名均不变；
    
*   在海外的恶意IP地址数量地理分布排名列表中，美国、荷兰、香港、韩国、德国位居前五，跟前一周相比没有变化；
    
*   本期全部有效IP地址数量是2978个，其中海外有效IP地址数量是1954个，大陆有效IP地址数量是1024个，全部有效IP地址较上周相比增加了4个，增幅为0.13%；跟前一周相比，海外IP地址数量出现轻微下降而大陆的地址数量出现轻微上升；
    
*   本统计期恶意IP地址数量已经是连续六周在前期的高位平台区间整理运行了。这种平衡的局面何时打破，有待继续观察。以下是本统计期的数量趋势图：
