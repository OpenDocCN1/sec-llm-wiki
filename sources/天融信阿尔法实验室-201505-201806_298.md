# 1 总体情况

## 1.1 本周漏洞情况

*   本周统计CVE漏洞49个，其中高危漏洞21个，中危漏洞24个，低危漏洞4个。漏洞数与前一周环比下降2.0%，与去年同期同比上升4.3%；
    
*   本周主要记录了IBM公司的Tivoli Storage Manager、MQ Light、WebSphere 产品的十几个漏洞，漏洞类型包括缓冲区溢出漏洞、拒绝服务、信息泄露等；还主要跟踪了Symantec Endpoint Protection Manager的多个高危漏洞，漏洞类型有目录遍历、SQL注入、提权、任意文件读取，安全产品自身的安全性还要高度重视；
    
*   另外还记录了思科、西门子、Dell、斯奈德电器等公司的产品的多个漏洞;
    

## 1.2 本周恶意域名与IP地址跟踪情况

*   本统计期恶意IP地址数量在前一周重回前期的高位平台区间后出现小幅增加，目前依旧在此区间中整理运行，目前还难以判断这波上升趋势是否就此打住，只能继续观察跟踪；
    
*   根据分析单个IP地址对应的恶意域名数量前10位列表的结果,大陆的前10位列表和海外的前10位列表与前一周相比均保持不变，这已经是连续七周保持不变了，我们需要关注这种稳定的情况还能保持多久；
    
*   在大陆的恶意IP地址数量地理分布排名列表中，北京、江苏、浙江、广东、河南位居前五，跟前一周相比没有变化；不过发现最近位于西部的四川已经有三周连续进入前十位，预示着其对应的恶意地址数量有所增加，需要关注；
    
*   在海外的恶意IP地址数量地理分布排名列表中，美国、荷兰、香港、韩国、德国位居前五，跟前一周相比没有变化；

# 3 恶意域名与IP地址跟踪

## 3.1 总体情况

本期从国家权威部门获取的恶意域名数是20个，同时重新整理前期输入的恶意域名，将长期不再有效的恶意域名剔除，得出目前最新的恶意域名数是13410个，将这些域名进行例行的IP地址解析，本周的验证结果如下：

*   根据分析单个IP地址对应的恶意域名数量前10位列表的结果,大陆的前10位列表和海外的前10位列表与前一周相比均保持不变，这已经是连续七周保持不变了，我们需要关注这种稳定的情况还能保持多久；
    
*   在大陆的恶意IP地址数量地理分布排名列表中，北京、江苏、浙江、广东、河南位居前五，跟前一周相比没有变化；不过发现最近位于西部的四川已经连续三周进入前十位，预示着其对应的恶意地址数量有所增加，需要关注；
    
*   在海外的恶意IP地址数量地理分布排名列表中，美国、荷兰、香港、韩国、德国位居前五，跟前一周相比没有变化；
    
*   本期全部有效IP地址数量是2946个，其中海外有效IP地址数量是1912个，大陆有效IP地址数量是1034个，全部有效IP地址较上周相比增加了42个，增幅为1.45%；跟前一周相比，海外IP地址数量和大陆IP地址数量均有上升；
    
*   本统计期恶意IP地址数量在前一周重回前期的高位平台区间后出现小幅增加，依旧在此区间中整理运行，目前还难以判断这波上升趋势是否就此打住，只能继续观察跟踪。以下是本统计期的数量趋势图：
