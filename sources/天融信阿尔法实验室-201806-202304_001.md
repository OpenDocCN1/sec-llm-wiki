**1、****加州隐私权法案 (CPRA) 主要规则摘要**

  

![](../Images/87db74c1de4eba03349320c319cabfab.png)  Tag：CPRA、隐私

  

加州隐私权法案( CPRA) 是对加州消费者隐私法案(CCPA)的修正案，两者结合形成了加州的单一数据隐私制度。CPRA 于 2023 年 1 月 1 日生效，并从 2023 年 7 月 1 日起由加州隐私保护局强制执行。

  

https://trustarc.com/blog/2023/04/06/california-privacy-rights-act-cpra-main-rules-summary/

  
  

****重点漏洞情报****

**1、****WordPress Elementor Pro插件访问控制漏洞**

  

![](../Images/87db74c1de4eba03349320c319cabfab.png)  Tag：WordPress

  

Elementor Pro是一个流行的WordPress页面生成器插件，用户可使用它在不懂代码的情况下轻松构建具有专业外观的网站，WordPress Elementor Pro 插件中修复了一个访问控制漏洞，经过身份验证的用户可利用该漏洞更改站点设置，甚至完全控制网站，目前该漏洞已发现被利用。

  

https://blog.nintechnet.com/high-severity-vulnerability-fixed-in-wordpress-elementor-pro-plugin/

  

**2、HP LaserJet打印机信息泄露漏洞**

  

![](../Images/87db74c1de4eba03349320c319cabfab.png)  Tag：CVE-2023-1707

  

HP某些打印机型号中存在信息泄露漏洞（CVE-2023-1707），该漏洞的CVSS评分为9.1。当某些HP Enterprise LaserJet 和 HP LaserJet Managed 打印机运行FutureSmart 固件版本5.6并启用 IPsec 时，存在信息泄露漏洞，可能导致威胁者访问易受攻击的HP 打印机与网络上其他设备之间传输的敏感信息。

  

https://support.hp.com/us-en/document/ish\_7905330-7905358-16/hpsbpi03838

  

**3、SonicOS 拒绝服务漏洞**

  

![](../Images/87db74c1de4eba03349320c319cabfab.png)  Tag：CVE-2023-0656

  

SonicOS 中存在栈溢出漏洞允许未经身份验证的远程攻击者通过发送特制HTTP请求造成栈溢出，覆盖canary，导致防火墙崩溃重启。

  

https://ssd-disclosure.com/ssd-advisory-sonicwall-ssl-vpn-out-of-bounds-write-dos/

  

**4、SvelteKit 框架跨站点请求伪造漏洞**

  

![](../Images/87db74c1de4eba03349320c319cabfab.png)  Tag：CVE-2023-29003

  

SvelteKit 是一个 Web 开发框架。SvelteKit 框架为开发人员提供了创建简单 REST API 的选项。这是通过定义一个 \`+server.js\` 文件来完成的，该文件包含用于不同 HTTP 方法的端点处理程序。SvelteKit 为其用户提供开箱即用的跨站点请求伪造 (CSRF) 保护。虽然实施在缓解常见 CSRF 攻击方面做得足够好，但在 1.15.1 版之前，可以通过简单地指定不同的“Content-Type”标头值来绕过保护。如果被滥用，这个问题将允许从第三方域提交恶意请求。

  

https://github.com/sveltejs/kit/security/advisories/GHSA-5p75-vc5g-8rv2

  
  

**恶意代码情报**

**1、针对 Cacti 和 Realtek 漏洞的攻击爆发, 传播 ShellBot 和 Moobot 恶意软件**  

  

![](../Images/87db74c1de4eba03349320c319cabfab.png)  Tag：Cacti、Realtek

  

在今年 1 月和 3 月观察到多次针对 Cacti 和 Realtek 漏洞的攻击爆发，然后传播 ShellBot 和 Moobot 恶意软件。ShellBot 是一种使用 Perl 开发的恶意软件，它使用 Internet 中继聊天 (IRC) 协议与服务器通信，也称为 PerlBot。Moobot 是 Mirai 变体僵尸网络，以暴露的网络设备为目标。

  

https://www.fortinet.com/blog/threat-research/moobot-strikes-again-targeting-cacti-and-realtek-vulnerabilities

  

**2、****一种新的攻击, 攻击者利用加密的 OneNote 文档来传播恶意软件**

  

![](../Images/87db74c1de4eba03349320c319cabfab.png)  Tag：OneNote

  

一种利用受密码保护的 OneNote 文件来传播恶意软件的攻击。通过诱骗收件人下载看似无害的 OneNote 文件，攻击者可以有效地感染系统并窃取敏感信息。

https://perception-point.io/blog/hackers-use-password-protected-onenote-files-to-spread-malware/

  

**3、CryptoClippy 恶意软件: 针对葡萄牙语用户的恶意软件活动, 其目的是将加密货币从合法用户的钱包重定向到由攻击者控制的钱包中**

  

![](../Images/87db74c1de4eba03349320c319cabfab.png)  Tag：加密货币

  

该活动使用了一种称为加密货币剪辑器的恶意软件，它会监视受害者的剪贴板以查找正在复制加密货币钱包地址的迹象。CryptoClippy 的恶意软件试图用威胁行为者的地址替换用户的实际钱包地址，导致用户无意中将加密货币发送给威胁行为者。

  

https://unit42.paloaltonetworks.com/crypto-clipper-targets-portuguese-speakers/

  

**4、Winter Vivern 使用已知的 Zimbra 漏洞来瞄准欧洲与北约结盟的政府的网络邮件门户**

  

![](../Images/87db74c1de4eba03349320c319cabfab.png)  Tag：Winter Vivern、北约

  

TA473 是 Proofpoint 跟踪的一种新出现的高级持续威胁 (APT) 攻击者，它利用 Zimbra 漏洞 CVE-2022-27926 滥用面向 Zimbra 的公开托管网络邮件门户。据评估，这项活动的目标是获得对参与俄罗斯乌克兰战争的整个欧洲的军事、政府和外交组织的电子邮件的访问权限。

  

https://www.proofpoint.com/us/blog/threat-insight/exploitation-dish-best-served-cold-winter-vivern-uses-known-zimbra-vulnerability
