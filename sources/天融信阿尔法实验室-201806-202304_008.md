# 【风险提示】天融信关于VMware vRealize Log Insight多个漏洞组成的漏洞利用链的风险提示

**0x00 背景介绍**  

* * *

近日，天融信阿尔法实验室监测到国外安全团队公布了VMware vRealize Log Insight产品漏洞CVE-2022-31704、CVE-2022-31706、CVE-2022-31711的细节，并公布了漏洞利用程序。该漏洞利用程序通过将这三个漏洞组合起来，可以使未经身份认证的远程攻击者在目标系统上以root权限执行任意代码。天融信阿尔法实验室建议使用该产品的用户尽快进行自查和防护。**0x01 重点****漏洞描述**  

* * *

VMware vRealize Log Insight是一种日志收集和分析的虚拟设备，使管理员能够收集、查看、管理和分析系统日志数据。Log Insight为任何环境中的基础架构和应用程序提供智能日志管理。这种可高度扩展的日志管理解决方案在物理、虚拟和云环境中提供了直观的可操作仪表板、精细的分析以及广泛的第三方可扩展性。  

*   **CVE-2022-31711：VMware vRealize Log Insight信息泄露漏洞**
    

CVE-2022-31711是VMware vRealize Log Insight产品中的一个信息泄露漏洞。未经身份验证的远程攻击者可利用此漏洞收集敏感会话和应用程序信息。

*   **CVE-2022-31704：VMware vRealize Log Insight损坏的访问控制漏洞**
    

CVE-2022-31704是VMware vRealize Log Insight产品中的一个损坏的访问控制漏洞。未经身份验证的远程攻击者可利用此漏洞向目标系统写入恶意文件，从而导致远程代码执行。

*   **CVE-2022-31706：VMware vRealize Log Insight目录遍历漏洞**
    

CVE-2022-31706是VMware vRealize Log Insight产品中的一个目录遍历漏洞。未经身份验证的远程攻击者可以通过目录遍历达到任意文件写入，利用计划任务等导致远程代码执行。

**0x02 漏洞等级**

* * *

CVE-2022-31704：9.8(CVSS:3.1)，高危  
CVE-2022-31706：9.8(CVSS:3.1)，高危

CVE-2022-31711：5.3(CVSS:3.1)，中危

**0x03 受影响版本**

* * *

CVE-2022-31704、CVE-2022-31706、CVE-2022-31711：  

VMware vRealize Log Insight 8.x < 8.10.2 

VMware Cloud Foundation (VMware vRealize Log Insight) 3.x

VMware Cloud Foundation (VMware vRealize Log Insight) 4.x

**0x04 修复建议**  

## 

* * *

VMware已在2023年1月24日发布VMware vRealize Log Insight 8.10.2，建议受影响用户尽快更新至8.10.2或应用临时缓解措施。

可通过如下链接下载最新版本的VMware vRealize Log Insight 8.10.2。
