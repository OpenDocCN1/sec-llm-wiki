0x00背景介绍


11月22日，天融信阿尔法实验室监测到一个Microsoft Exchange Server漏洞的POC被公开，经研究该漏洞是11月9日微软补丁日分配编号为CVE-2021-42321的漏洞。


0x01漏洞描述

Microsoft Exchange Server 是个消息与协作系统。Exchange server可以被用来构架应用于企业、学校的邮件系统或免费邮件系统。CVE-2021-42321属于反序列化类型漏洞，目前已经出现公开POC，建议受影响用户及时安装安全更新补丁。


0x02漏洞编号

CVE-2021-42321


0x03漏洞等级


严重


0x04数据分析


天融信安全云服务运营中心通过风险探知系统对国内部署Microsoft Exchange Serve的服务器进行统计，结果显示国内部署Microsoft Exchange Serve的服务器约有20152台。按区域统计来看，排名前三的省份是上海市3656台，香港特别行政区3595台，广东省3393台。
