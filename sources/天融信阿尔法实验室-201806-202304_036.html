0x00  背景介绍


10月8日,天融信阿尔法实验室监测到Apache官方发布的Apache HTTP Server 2.4.49 和 2.4.50 中的路径遍历和远程代码执行的风险通告，漏洞影响以下组件:
Apache HTTP Server


0x01 漏洞描述


CVE-2021-42013: 路径穿越与代码执行漏洞
组件介绍：
Apache HTTP Server（简称Apache），是Apache软件基金会的一个开放源代码的网页服务器，可以在大多数电脑操作系统中运行，由于其具有的跨平台性和安全性，被广泛使用，是最流行的Web服务器端软件之一。
漏洞描述：
10月8日被Apache官方披露，受到影响的组件是Apache HTTP Server，由于对CVE-2021-41773修复不完善，如果敏感文件没有被“require all denied”包含在内，攻击者可以构造恶意请求进行访问；同时CGI 如果开启，攻击者可以执行恶意命令，从而控制服务器。

0x02 影响版本


Apache HTTP Server：2.4.49 、 2.4.50


0x03 修复建议


根据受影响版本中的信息，排查并升级到安全版本，下载链接参考官方通告的References：
https://httpd.apache.org/security/vulnerabilities_24.html
