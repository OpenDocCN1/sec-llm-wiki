**0x00背景介绍**  

* * *

  

近日微软发布了一个安全公告ADV200006 ，Windows Adobe Type ManagerLibrary在处理Adobe Type 1字体时存在远程任意代码执行漏洞。微软已经发现利用该漏洞的攻击行为并正在进行漏洞修复工作，目前还没有发布更新补丁。

  

## **0x01****漏洞描述**

* * *

  

Windows Adobe Type ManagerLibrary在错误的处理Adobe Type 1字体时可以导致远程任意代码执行，攻击者诱使受害者打开恶意构造的文档或在预览窗格查看恶意构造的文档可以在受害者计算机上执行任意代码。漏洞风险高，受影响的系统版本多，微软目前正在进行漏洞的修复工作，未发布更新补丁，建议用户使用提供的缓解方案对该漏洞进行缓解。

## **0x05修复建议**

* * *

  

1.在资源管理器中禁用预览窗格和详细信息窗格  

在Windows资源管理器中禁用“预览”和“详细信息”窗格可以阻止在Windows资源管理器中自动显示OTF字体。

Windows Server 2008, Windows 7, WindowsServer 2008 R2, Windows Server 2012, Windows Server 2012 R2和Windows8.1可以进行以下步骤：

1)打开Windows资源管理器，单击“组织”，然后单击“布局”。

2)清除“详细信息窗格”和“预览窗格”的菜单选项。

3)单击组织，然后单击文件夹和搜索选项。

4)单击查看选项卡。

5)在“高级设置”下，选中“始终显示图标，从不显示缩略图”框。

6)关闭Windows资源管理器的所有打开的实例，以使更改生效。

![](../Images/2cc93349992d9240b63e20dcc5cb1013.png)Windows10可以进行以下步骤：

1)打开Windows资源管理器，单击“查看”选项卡。

2)清除“详细信息窗格”和“预览窗格”的菜单选项。

3)单击选项，然后单击更改文件夹和搜索选项。

4)单击查看选项卡。

5)在“高级设置”下，选中“始终显示图标，从不显示缩略图”框。

6)关闭Windows资源管理器的所有打开的实例，以使更改生效。

![](../Images/92964d3ce28156375ee908d8528648e1.png)

![](../Images/7c370c13aab9daa8b50ea7c49466bf18.png)

  

#### 2\. 重命名ATMFD.DLL

注意：从Windows10版本1709开始的Windows 10安装中不存在ATMFD.DLL。

32位系统可以进行如下步骤：

1)在资源管理器输入%windir%/system32进入system32路径

![](../Images/7f428bae1ca93ae97cee4f57b0f8b2c5.png)

2)在该路径下搜索找到cmd.exe，右键单击以管理员权限打开

![](../Images/de8e445962911a17506b866f994f42fa.png)

3)输入以下命令并重启计算机

cd"%windir%\\system32"

takeown.exe /f atmfd.dll

icacls.exe atmfd.dll /saveatmfd.dll.acl

icacls.exe atmfd.dll /grantAdministrators:(F)

rename atmfd.dll x-atmfd.dll

![](../Images/7aa74a1c00b4dee60df6d58e4d580e6a.png)

64位系统可以进行如下步骤：

1)如上述32位系统步骤1、2打开管理员权限cmd

2)输入以下命令并重启计算机

cd"%windir%\\system32"

takeown.exe /f atmfd.dll

icacls.exe atmfd.dll /save atmfd.dll.acl

icacls.exe atmfd.dll /grantAdministrators:(F)

rename atmfd.dll x-atmfd.dll
