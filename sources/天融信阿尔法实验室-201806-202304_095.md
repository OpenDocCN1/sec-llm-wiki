一、背景介绍  

  
  

近期，有境外黑客组织扬言将于2020年2月13日对我国视频监控系统实施网络攻击破坏活动，并声称已掌握我国境内大量视频监控设备权限。国家信息安全漏洞共享平台（CNVD）收录了OpenCV（开源计算机视觉库）4.1.0版中的2个缓冲区溢出漏洞（漏洞1编号：CNVD-2020-01148，对应国际公共漏洞库编号：CVE-2019-5064；漏洞2编号：CNVD-2020-01149，对应国际公共漏洞库编号：CVE-2019-5063）。攻击者可利用特制文件触发该漏洞，进而可对视频监控系统进行远程控制。

1.1

漏洞描述

Open Source Computer Vision Library (OpenCV)是一个跨平台的开源计算机视觉库。主要应用于解决计算机图像识别、机器人技术问题。CVE-2019-5063、CVE-2019-5064都是OpenCV在解析本地文件时的产生的堆溢出漏洞，攻击者可以通过构造恶意XML和JSON文件触发这两个漏洞。其中CVE-2019-5063是OpenCV在解析恶意XML时触发，在解析string标签时若遇到‘&’字符则继续读取直到遇到结束符‘;’，如果读取的字符串与switch中的字符串不匹配，则读取的字符串复制进缓冲区，造成溢出。CVE-2019-5064是OpenCV在解析包含空字节的JSON文件时触发的，当遇到空字节时，直到该点的整个值均被复制进缓冲区中，但未检查JSON值是否会造成目标目标缓冲区溢出。

1.2

受影响版本

OpenCV 4.1.0及以下版本

2.2

### 漏洞分析

编译完成后运行./harness poc.xml可以看到崩溃在malloc的位置

![](../Images/e4bd60ba54183e5b91732d0c7c276920.png)

漏洞触发时拷贝memcpy第三个参数字符串长度0x2c83为xml中字符''&''后边截止到结束符';'的字符串长度即空格+B\*0X2c80=0x2c81，

![](../Images/b002e7027545704c15488add4167be1a.png)

源码出现漏洞的位置第三个参数为len+2，所以最终拷贝长度为0x2c83

![](../Images/eab2b223a6775ff12af31685bea02a02.png)

memcpy字符串拷贝时的参数

![](../Images/71c4783977187e5d610760b47d8da43f.png)

拷贝0x2c83长度会覆盖0x555555579320处topchunk的metadata，所以运行harness poc.xml会报错corrupted top size。

![](../Images/fa8473096f579548ba844040c54123e3.png)

所以得出覆盖topchunk metadata最小字符串长度为0x555555579320-0x5555555782f0-2+0x10=0x103e。

修改poc中字符串长度并重新生成xml进行测试

#!/usr/bin/env python

from struct import pack

poc = b'<?xml version="1.0"?><opencv\_storage><strings>'

poc += b'string'

poc += b' & '

poc += b'B' \* 0x103e

poc += b';'

poc += b'</strings>'

with open("123.xml", "wb") as f:

    f.write(poc)

f.close()

![](../Images/6eae7d2f948bcc44842cdec7e07d3c61.png)

可以看到这时topchunk的metadata同样被覆盖

![](../Images/e7cc01907469ebde85651ff674824b62.png)

所以只需要检测xml中<string>标签字符'&'到结束符';'之间的长度是否大于0x103e即可，若大于则可认为触发了漏洞。

  

通过以上分析可以发现这个漏洞只能覆盖topchunk的metadata，在开启了aslr的系统中是很难达到任意代码执行的效果的。

  

  
  

三、检测与修复

  
  

3.1

检测方法1-天融信工具脚本快速检测

  

天融信针对CVE-2019-5063和CVE-2019-5064漏洞提供专属检测工具脚本，包括两个工具detect\_opencv\_windows3.exe和detect\_opencv\_linux，分别支持Windows和Linux系统。该工具支持在Windows7、Windows8、Windows10上进行漏洞检测，覆盖OpenCV大部分版本；支持在Ubantu、Redhat等系统上进行漏洞检测，覆盖OpenCV 4.1.0（linux）、OpenCV 3.4.9（linux）、OpenCV 3.1.0 （linux）、OpenCV 4.1.0.25 python和OpenCV 3.4.8 linux java等版本。

  

3.2

检测方法2-天融信漏扫系统检测

  
采用登录扫描的方式进行漏洞扫描。扫描器登录到目标靶机后（Windows采用SMB的登录方式，Linux采用ssh或者telnet的登录方式），通过操作系统命令获取OpenCV的版本信息，通过版本比对的方式确认漏洞。已确认OpenCV不能安装patch。

3.4

### 修复建议

1.OpenCV 4.2.0版本已经修复这两个漏洞，建议用户进行更新，下载地址https://opencv.org/releases/。

  

2.建议安装天融信EDR或相关杀毒软件做好防护。

  

3.开启系统aslr功能（系统默认开启，开启aslr只是提高攻击难度，并不能从根本上解决问题，建议OpenCV升级到高于4.2.0的版本），Linux下使用以下命令重新开启aslr功能，命令如下：

sudo bash -c "echo 2 > /proc/sys/kernel/randomize\_va\_space"
