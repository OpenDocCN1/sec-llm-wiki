0x00背景介绍

5月14日，微软发布了针对远程桌面服务远程执行代码漏洞（CVE-2019-0708）的补丁，未经身份验证的攻击者使用RDP连接到目标系统并发送特制请求时触发该漏洞。

该漏洞可能引发类似于Wannacry这样的蠕虫级勒索病毒的产生，其严重性不低于永恒之蓝。2019年9月7日，针对该漏洞的远程代码执行利用工具已经公开发布，且经天融信阿尔法实验室测试该工具可以实现远程代码执行。该工具的公开导致此漏洞的安全威胁再次升级，有可能为Wannacry这样蠕虫级的病毒所利用，强烈建议用户安装微软官方漏洞补丁或者使用天融信产品进行漏洞防护，以避免该漏洞引发的安全威胁。

0x03修复建议

2.1官方补丁

微软已经为该漏洞发布更新补丁（包括官方停止维护版本），请用户及时进行补丁更新。获得并安装补丁的方式有三种：内网WSUS服务、微软官网Microsoft Update服务、离线安装补丁。离线安装补丁下载地址如下：下载对应补丁安装包，双击运行即可进行修复。

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2019-0708

官方已停止维护版本漏洞补丁下载地址如下：

https://support.microsoft.com/zh-cn/help/4500705/customer-guidance-for-cve-2019-0708

2.2临时解决方案

若暂不便安装补丁更新，可采取下列临时防护措施：

1、禁用远程桌面服务。

2、 通过主机防火墙对远程桌面服务端口进行阻断（默认为TCP 3389）。

3、 启用网络级认证（NLA），此方案适用于Windows 7、Windows Server 2008和Windows Server 2008 R2。启用NLA后，攻击者首先需要使用目标系统上的有效帐户对远程桌面服务进行身份验证，然后才能利用此漏洞。

4.2 天融信日志收集与分析系统3389端口开放和访问统计方案

天融信日志收集与分析系统收集企业内部各类设备、主机、服务等日志，可通过日志分析与统计来发现一些风险，如在日志查询中查询收集到的防火墙日志，并对目的端口做筛选，过滤出目的端口为3389的日志，如下：

然后可通过统计主题功能来发现防火墙访问日志中高频访问高危端口的IP，从而发现可能的攻击者IP（这里以统计3389端口为例），也可发现开放了高危端口的IP，从而对这些可能的漏洞资产进行针对性的安全防护，具体配置方法如下：

1、配置统计主题

1）选择 日志 > 查询统计，激活“统计主题”页签，进入统计主题列表，点击【新建】按钮，弹出“创建主题”。

2）在分组字段勾选“源地址”，统计字段勾选“目的端口”，添加过滤条件“目标端口”等于3389，保存后，执行主题就可完成统计。

 

2、统计完成后的结果查看

选择 日志 > 查询统计，选择当前统计任务，点击预览“   ”预览统计结果。

这样就把高频访问3389端口的IP统计出来了，这些IP作为攻击者的可疑性较高，建议有针对性的进行安全检查和处置。

查看开放3389端口的资产，可用上述配置方法，效果如下，这些IP均开放了3389端口，建议有针对性的采取关闭3389端口或通过主机防火墙进行限制访问等安全防护措施。

其他高危端口的统计分析配置方法同上，还可根据统计需要加入其他的统计字段以精确匹配。
