# **0x00背景介绍**

* * *

  

谷歌研究人员发现IOS系统中存在多个高危漏洞，其中（CVE-2019-8660、CVE-2019-8662、CVE-2019-8647、CVE-2019-8641）四个漏洞可在无交互的情况下造成任意远程代码执行，（CVE-2019-8646）该漏洞可造成任意远程文件读取。  
这四个RCE漏洞中，其中（CVE-2019-8660、CVE-2019-8662、CVE-2019-8647）三个已经在最新的iOS12.4中获得修复，并在网上放出POC以供测试使用，（CVE-2019-8641）由于未完全被修复，故而未公布具体漏洞细节。

  

## **0x01漏洞描述**

* * *

  

CVE-2019-8647（RCE 远程任意代码执行）该漏洞为UAF漏洞存在于iOS Core Data中，当调用NSArray.initWithCoder方法时，由于不安全的反序列化问题而产生，从而导致任意代码执行。经测发现该漏洞可通过iMessage进行远程无交互的漏洞触发，该漏洞的POC已在网上公布，提供给大家进行测试。

 

CVE-2019-8662（RCE 远程任意代码执行）该漏洞存为UAF漏洞存在于iOS QuickLook组件中，经测试发现该漏洞可通过iMessage进行远程无交互的漏洞触发，最终可以导致任意远程代码执行，POC已在网上公布，提供给大家进行测试。

 

CVE-2019-8660（RCE 远程任意代码执行）该漏洞是一个内存损坏漏洞存在于Siri组件中以及iOS Core Data框架中，。经测试发现该漏洞可通过iMessage进行远程无交互的漏洞触发，执行成功后会造成应用程序的恶意终止例如导致Springboard程序的崩溃，同时也可能会造成任意远程代码执行，POC已在网上公布，提供给大家进行测试。

 

CVE-2019-8641越界读取漏洞，可导致应用异常终止，或导致任意代码执行(由于该漏洞未完全被修复，故而研究人员未公布漏洞具体细节)。

 

CVE-2019-8646（远程任意文件读取）此漏洞是存在于Siri以及iOS Core Data中的越界读取漏洞，经测试发现该漏洞允许攻击者在没有用户交互的情况下通过iMessage远程读取存储在iOS设备上的任意文件内容，POC已在网上公布，提供给大家进行测试。
