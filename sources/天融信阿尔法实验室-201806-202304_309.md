# **0x00背景介绍**  

* * *

  
阿尔法实验室研究人员发现了多个Adobe XD软件任意代码执行漏洞，天融信阿尔法实验室在发现该漏洞后，第一时间通知了Adobe公司，进行修复。

Adobe XD 是目前最全面、可靠的 UI 设计应用之一，在这款产品上面用户可以进行移动应用和网页设计与原型制作。用户可以在 Mac 和 Windows 系统免费安装和使用它，Adobe 期望它能够成为 UI 设计师的首选工具。

Adobe官方公开地将XD称为Adobe的旗舰产品，越来越多的 UI 设计师被Adobe XD所吸引，设计师在XD中获得更多的权力，Adobe XD可以直接打开PSD文档，Photoshop几乎被集成到了XD当中。Adobe XD还吸收了Sketch等优秀设计软件的优点，由此看见XD是“Photoshop杀手”的身份坐实了。

  

## **0x01漏洞描述**

* * *

  
该漏洞通过钓鱼攻击诱骗用户点击，用户如果点击后缀名为.xd、.sketch、.indd的恶意文件，就可执行任意代码。

# **0x03漏洞修复**

* * *

  

**3.1受影响版本**

<= 16.0 MacOS

  

**3.2漏洞检测**

    检查Adobe XD版本。

  

**3.3解决方案**

1. 在未升级到最新版本之前，请不要打开后缀名为.xd、.sketch、.indd的文件。

2.Adobe官方修复方案：

https://helpx.adobe.com/creative-cloud/help/creative-cloud-updates.html
