# 天融信阿尔法实验室收到Adobe官方致谢

近日，天融信阿尔法实验室收到了Adobe公司的致谢，阿尔法实验室研究人员发现了多个Adobe XD软件任意代码执行漏洞，天融信阿尔法实验室在发现该漏洞后，第一时间通知了Adobe公司，进行修复。

致谢链接：

https://helpx.adobe.com/security/products/xd/apsb19-22.html 

https://helpx.adobe.com/security/products/indesign/apsb19-23.html

Adobe官方致谢

Adobe XD 是目前最全面、可靠的 UI 设计应用之一，在这款产品上面用户可以进行移动应用和网页设计与原型制作。用户可以在 Mac 和 Windows 系统免费安装和使用它，Adobe 期望它能够成为 UI 设计师的首选工具。  

Adobe官方公开地将XD称为Adobe的旗舰产品，越来越多的 UI 设计师被Adobe XD所吸引，设计师在XD中获得更多的权力，Adobe XD可以直接打开PSD文档，Photoshop几乎被集成到了XD当中。Adobe XD还吸收了Sketch等优秀设计软件的优点，由此看见XD是“Photoshop杀手”的身份坐实了。

![](../Images/ff786abd796c26e44afddb9bd5ae4b4f.png)

  

漏洞发现时间表：  

2018年12月16日 发现并向adobe提交漏洞

2019年1月4日 确认漏洞并着手修复漏洞

2019年3月14日 计划在下个月发布安全公告

2019年4月10日 获得adobe致谢

天融信阿尔法实验室成立于2011年，一直以来，阿尔法实验室秉承“攻防一体”的理念，汇聚众多专业技术研究人员，从事攻防技术研究，在安全领域前瞻性技术研究方向上不断前行。作为天融信的安全产品和服务支撑团队，阿尔法实验室精湛的专业技术水平、丰富的排异经验，为天融信产品的研发和升级、承担国家重大安全项目和客户服务提供强有力的技术支撑。
