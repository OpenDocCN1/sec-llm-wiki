0x00背景介绍


Apache HTTP Server （简称Apache ）是Apache软件基金会的一个开放源码的网页服务器软件，可以在大多数电脑系统中运行。由于其跨平台和安全性，被广泛使用，是最流行的Web服务器软件之一。 它快速、可靠并且可通过简单的API扩充，将Perl ／ Python等解释器直接编译到服务器中。


0x01漏洞描述


Apache httpd在2.4.39的更新中修复了一个漏洞（CVE-2019-0211），根据Apache在4月1号公布的信息指出，该漏洞为特权提升漏洞，在权限较低的子进程中执行的代码在触发漏洞后，会以父进程（通常是root）的权限运行。该漏洞影响Apache HTTP Server 2.4版本的2.4.17到2.4.38间发布的版本，受影响的操作系统为Unix类系统。


1.1漏洞编号


    CVE-2019-0211


1.2漏洞等级


     高危


0x02修复建议


2.1受影响版本


Apahce HTTP Server 2.4.38, 2.4.37, 2.4.35, 2.4.34, 2.4.33, 2.4.30, 2.4.29, 2.4.28, 2.4.27,2.4.26, 2.4.25, 2.4.23, 2.4.20, 2.4.18, 2.4.17


2.2漏洞检测


目前官方没有透露更多的漏洞细节，广大用户可以通过对比Apache HTTPServer的版本号，确认是否为“受影响版本”。



2.3修复建议


Apache已经在httpd 2.4.39版本中修复了该安全漏洞，建议所有类Unix系统平台的Apache HTTP Server用户检查软件版本是否受到影响，受影响的用户尽快更新。

更新链接：

https://httpd.apache.org/download.cgi
