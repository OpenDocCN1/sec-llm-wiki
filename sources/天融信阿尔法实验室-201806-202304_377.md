# **0x00背景介绍**  

* * *

  

ThinkPHP 是一个快速、简单的基于 MVC 和面向对象的轻量级 PHP 开发框架，遵循 Apache2 开源协议发布。ThinkPHP从诞生以来一直秉承简洁实用的设计原则，在保持出色的性能和至简的代码的同时，也注重开发体验和易用性，为 WEB 应用和 API 开发提供了强有力的支持。  

  

## **0x01漏洞描述**

* * *

  

在ThinkPHP中存在远程代码执行漏洞，攻击者可通过$\_POST传入参数，利用变量覆盖漏洞设置filter属性值，从而导致任意代码执行。

## **0x02漏洞复现**

* * *

  

目前我们在THINKPHP 5.1.20及5.0.x部分版本中成功复现。

![](../Images/13bad181208f128d2b09b9dff8fa640d.png)

其中5.1.20需要屏蔽error才能触发。

![](../Images/b61756867022921bee5a2d4b7000300c.png)

在5.0.10中，不要需设置任何限制条件即可触发漏洞。

  

## **0x03修复建议**

* * *

  

## **3.1受影响版本**

  

THINKPHP 5.0.x部分版本

THINKPHP 5.1.x - 5.2版本

  

## **3.2****漏洞检测**

检查THINKPHP框架的版本号。

  

## **3.3****解决方案**

天融信TOP-WAF目前已经可以防御此漏洞：

1.TOP-WAF产品防御规则ID：2159102 Thinkphp5.1 ~ 5.2 全版本代码执行漏洞，请更新Top-WAF知识库到waf-v2019.01.15.tir、topwaf-v2019.01.15.tir版本即可防御。

  

天融信TOP-IDP目前已经可以防御此漏洞：

2.TOP-IDP产品的防御规则 ID：26320 ThinkPHP 5.x远程代码执行漏洞攻击，请更新Top-IDP知识库到ips-v2019.01.15版本即可防御。

  

3.利用Composer 或官网更新至最新版本。

  

4.如果不能及时更新，建议参考最新版本的Request类的method方法进行手工修复。
