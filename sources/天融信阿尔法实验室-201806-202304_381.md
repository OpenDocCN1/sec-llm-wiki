# **0x00背景介绍**  

* * *

  

ThinkPHP 是一个快速、简单的基于 MVC 和面向对象的轻量级 PHP 开发框架，遵循 Apache2 开源协议发布。ThinkPHP从诞生以来一直秉承简洁实用的设计原则，在保持出色的性能和至简的代码的同时，也注重开发体验和易用性，为 WEB 应用和 API 开发提供了强有力的支持。  

  

## **0x01漏洞描述**

* * *

  

该漏洞攻击者通过$\_POST作为函数的参数传入，利用“表单伪装变量”进行变量覆盖实现对该类任意函数的调用，导致任意代码执行。

## **0x02漏洞复现**

* * *

  

目前我们在THINKPHP 5.0.23版本中的DEBUG模式下成功复现。

![](../Images/182dec5eae4f0ab0c1f9810e1287269b.png)

  

## **0x03修复建议**

* * *

  

## **3.1受影响版本**

  

THINKPHP 5.0.0–5.0.23

  

## **3.2****漏洞检测**

检查THINKPHP框架的版本号。

  

## **3.3****解决方案**

1.TOP-WAF产品防御规则ID：2159103 ThinkPHP5.0.X 远程代码执行漏洞，将在 topwaf-v2019.01.11.tir和waf-v201901.11.tir规则库版本中发布此规则。

  

2.TOP-IDP产品的防御规则 ID：26303 ThinkPHP5.0.X 远程代码执行漏洞，将在 ips-v2019.01.11版本中发布此规则。

  

3.利用Composer 或官网更新至5.0.24 以及更高的版本。

  

4.如果不能及时更新，建议参考最新版本的Request类的method方法进行手工修复。
