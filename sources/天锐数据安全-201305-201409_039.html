【资讯】微软Win7退役在即 Win8接棒难迈三道坎

WinXP的退役让众多习惯XP系统的用户恋恋不舍，而仅仅三个月后，微软在系统上又有了新的举措。微软公司近日在官网公布，将于明年停止对windows7操作系统的主要支持，意味着微软将不再提供免费的功能更新。

　　微软如此迫切地将Win7下线，其主要目的十分明显——为了提高Win8乃至即将推出的Win9的市场占有率。但Win8与XP、Win7相比，进步并不明显，而且最关键的是许多用户的PC设备是多年前购买的，硬件配置不高，难以支撑Win8或Win9，因而如何解决兼容性问题是微软想要推广后续系统所必须要先解决的。

微软宣布Win7即将退役

　　关于WinXP退役的讨论依然环绕于耳边，Win7即将“戛然而止”的消息又传来。近日，微软公司宣布，到2015年1月13日前将停止对Win7操作系统的主要支持。据悉，在2015年1月13日前，微软还将终结对所有版本的Windows Server 2008和2008 R2，以及所有版本Windows Storage Server 2008的“主要支持”；而针对Dynamics C5 2010、NAV 2009 和NAV 2009 R2的“主要支持”也将同时在2015年1月13日结束。

　　在这里首先要了解两个概念，即“主要支持”与“延伸支持”。 主要支持一般延续五年时间，微软免费对软件产品提供补丁、安全更新等内容，在主流支持结束之后，微软还会提供一段时间的延伸支持，用户仍然可以获得免费的安全补丁，不过其他的软件更新，则需要付费获得，另外用户必须和微软签署独立的延伸支持协议。那意味着，Windows7操作系统的主要支持将会在明年1月14日终结，延伸支持则将在2020年1月14日结束。

　　也有一些行业观察人士指出，Windows7操作系统使用广泛，渗透率较高，因此在技术支持上，微软可能会重复XP系统的做法，即对结束支持的时间做出推迟。不过到目前为止，微软官方并未宣布有这样的计划。

微软支撑Win8上位

　　微软的这一单方面举动，显然让数量庞大的Windows用户有些措施不及。Win7是微软2009年发布的操作系统，至今年的10月22日才刚刚够6岁，微软就宣布停止其主流服务支持，其寓意又在哪？

　　一方面，扶持Win8的市占率提升。据国外两家数据分析公司对PC操作系统的市场份额的一份最新调查显示，截至6月，Win7的市场份额为55.02%，为全球第一，而XP紧随其后，市场份额16.29%，全球排名第二，Win8排名落后苹果(94.78, -0.54, -0.57%)的Mac OS X，市场份额仅为8.57%，排名第四，OS X排名第三。这些数据可以看出，即便微软公司推出了新产品，但是用户却仍然对旧产品情有独钟，这已十分明显的反映出用户的操作惯性与微软的发展意愿已经出现了差异。

　　另一方面，随着用户对自身信息安全的关注日益加深，微软也迫切需要给用户做出一个“安全卫士”的形象。据《福布斯》网站报道，微软发布的2013年下半年度《安全情报报告》显示，Windows 7和Windows Vista操作系统遭受恶意代码和病毒攻击的几率，甚至超过了退役的Windows XP系统。报告显示，Windows XP系统的病毒感染率为2.42%，而Windows Vista和Windows 7系统的病毒感染率分别为3.24%和2.59%。而Windows 8和Windows 8.1系统的感染率分别为1.73%和0.08%。

　　可见，微软这么早就停止Win7主流支持，说白了，就是微软在救Win8，同时为将来可能发布的Win9铺路。

Win8后续普及有难度

　　不过，就目前的情况而言，微软想要改变Win 8的尴尬市场局面还面临种种压力。

　　首先，系统有很强的先入为主性质，人们总是会用自己习惯的，只有一部分人会去尝试新的。除非新的确实比旧的优秀太多太多。就像当初XP系统能够风靡全球，因为XP跟微软公司之前的系统相比进步太大，甚至是颠覆，所以用户很容易的、很心甘情愿的就转投入了XP的怀抱。而Win8与XP、Win7相比，进步并不明显。并且，Win8主打的是触控功能，也就是说，只有采用触控屏的电脑才能完全地发挥Win8系统的功效，虽然Win8也能支持非触控屏电脑，但是若改变了UI界面来迎合，Win8与Win7又有什么区别呢？

　　其次，升级到Windows 8的用户对于这款软件的槽点主要集中在：双模式操作系统混乱、无“开始”按钮、有悖常理的滑动手势、使用鼠标控制很不方便、Windows应用商店里程序太少，远远达不到实用的地步等诸多方面，而如何改善这些吐槽点，并非一早一夕之事。

　　最后，硬件的普及赶不上软件的发展速度。就用户方面而言，一般都是几年才更换一台，这就直接导致了操作系统超出了电脑硬件的承受范围。许多国家的用户使用的电脑还是四五年前甚至七八年前的产品，除了运行XP，Win7跟Win8完全不能流畅使用。因而，与其使用新的操作系统，不如用更适合电脑的操作系统。

　　微软停止对win7操作系统的主要支持的举动，从侧面反映出其对2012年底推出的Win8操作系统软件非常自信。但是微软推出Win8后，因为XP的占有率过高，Win8发展成疲软态势。而今市场效果不明显也再次反映出上述制约因素对于Win8市场拓展影响重大。可以说，Win8兼容性是成为困扰用户的重要因素。是想，若是用户当下的PC设备能够很好的支撑Win8，Win8本身又很好操作，那么有谁不想用更好、更新、更好看的系统呢？问题的关键还是在于创新的太激进，如何让创新与现实更好的接轨，如何更好的引导用户上手新系统是当前微软面临的最大问题，而一味通过终止系统服务支持来博得后续系统上位，或许只会更多的引起用户的不满和抱怨。
