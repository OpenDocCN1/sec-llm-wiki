# 【资讯】报告称重要数据遭泄露令亚太地区企业担忧

 中新社北京6月17日电 (记者 李晓喻)高伟绅律师事务所17日发布的一份研究报告显示，重要数据安全不保证成为亚太地区大型国际企业高管们非常担心的问题。

　　这家英国著名的律师事务所调查年营业额超5亿美元的大型国际企业的320名董事会成员，其中亚太区企业的高管占受访者总数的三分之一。

　　报告称，56%的亚太地区受访者对重要数据的安全性感到担忧，这一比例高于任何其他地区。高管们担心客户的机密信息被泄露给公众，进而引发公关灾难。

　　此外，亚太区80%的受访者认为，企业品牌受损的声誉风险是未来两年内最值得关注的问题。97%的中国受访者表示，他们越来越重视声誉风险。随着亚太企业成为区域和全球市场愈发重要的参与者，保卫企业声誉将变得更加重要，因为声誉受损不仅会影响企业的股价，企业的利润和融资成本也会受到影响。

　　贿赂和腐败问题也令这一区域的企业家们焦虑。30%的亚太地区受访者非常担心贿赂和腐败问题，远远超过美国13%和欧洲16%的比例。

　　政治对商业的干预也是一大潜在风险点。报告指出，这种干预在所有行业板块中无处不在，会对企业造成严重影响，能源和采矿行业尤甚。(完)
