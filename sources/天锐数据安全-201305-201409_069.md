# 【新闻】天锐科技杉杉科技强强联手 双双鼎力行业第一品牌

　　在全球资源、环境压力日益凸显的今天，新材料、新能源的应用无疑是纾解地球压力的一大良方。而在这一新兴领域，中国企业的表现也可圈可点。  
　　上海杉杉科技有限公司是近来崛起的新材料、新能源黑马。成立于1999年的杉杉科技，一直专注于锂离子电池材料的研究开发与生产经营，是中国锂离子电池材料第一品牌，被誉为中国锂电材料超市。近期，杉杉科技与数据安全第一品牌厦门天锐科技有限公司上海分公司签订信息安全合作协议，为其崛起做好信息安全保障。  
　　杉杉科技在锂离子电池负极材料的研发、生产方面，积累了深厚的经验和知识产权，加强对这些重要电子文件和日常生产、经营过程中产生的文件的安全保护，是杉杉科技现阶段最为紧迫的任务。  
　　通过对天锐绿盾制造业数据安全解决方案的深入了解和试用，杉杉科技对这一功能完善、防护理念先进的数据安全解决方案推崇备至，天锐科技上海分公司和杉杉科技迅速达成了合作。  
　　据了解，天锐科技上海分公司根据杉杉科技的实际情况、功能需求，为其定制了天锐绿盾文件安全综合防护系统。  
　　天锐绿盾文件安全综合防护系统采用高效、先进的文件内核驱动层加密技术，运用256位高强度算法，在文件创建或编辑过程中自动强制加密，不影响用户操作习惯。当加密文件通过非正常渠道流转至外部，打开时便会显示乱码或无法打开，确保文件安全。  
　　该系统还具有全球独一无二的三重密钥体系——主密钥、企业密钥、文件密钥。每个文件加密时，都采用三个密钥同时参与运算，每个文件解密时，必须三个密钥同时验证才能完成。主密钥是由天锐科技分配给每个用户全球唯一的密钥，保证了每个安装天锐绿盾产品的用户之间加密文件无法互相访问；企业密钥由用户自己设置，并支持修改，保证了企业在需要时可修改密钥，确保文件安全，对密钥的使用更加自主；文件密钥则是在每个文件加密时自动生成，提高了文件加密的安全性。  
　　此外，严密的途径控制也为文件安全增添了更多保障。天锐绿盾文件安全综合防护系统采用控制剪贴板复制、禁止截屏、禁止OLE插入等方式控制文件泄密途径，与其他功能相辅相成，为文件安全保驾护航。  
　　通过这一系列行之有效的措施整合，天锐科技上海分公司为杉杉科技树立起了全面的数据安全防护体系，杉杉科技更能倾心于钻研。
