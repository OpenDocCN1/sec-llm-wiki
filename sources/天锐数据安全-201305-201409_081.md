# 【资讯】WindowsXP系统今天中午12时正式"退休"

　　美国东部时间4月8日午夜12点、即北京时间9日中午12点起，微软将正式终止对“WindowsXP”系统的支持服务。伴随了用户近13年的“WindowsXP”操作系统将正式“退休”。

微软:服役13年Windows XP已跟不上时代

　　所谓停止服务，是指今后微软公司将不再提供“Windows XP”系统的技术帮助，包括停止提供该系统的补丁和安全更新，不再解决此后发现的新漏洞。此外，微软的免费防病毒软件也将不再为“Windows XP”用户提供更新服务。

　　微软公司对此的解释是：这一系统“服役”了将近13年，已经不能满足互联网时代的需求，不足以应对层出不穷、且变化多端的网络安全威胁。因此，微软决定停止停止对“Windows XP”的支持服务，并建议用户尽早升级到新一代Windows操作系统，以便更好地适应最新的网络、硬件和软件环境，获得前所未有的安全保障。

Windows XP停售6年 市场份额仍超27%

　　数据显示，2014年3月，Windows XP在全球的市场份额仍在27%之上。对于一款停止销售近6年的操作系统来说，这一数字足以让它傲视群雄。在我国，约2亿用户正在使用Windows XP系统。虽然升级到新版的操作系统无疑更加安全，但由于诸多原因，不少消费者仍选择坚守。

　　对于微软来说，Windows XP“太过成功”，以至于自己都难以重现辉煌。作为Windows XP的升级产品，2005年推出Windows Vista的业绩惨淡。到2009年10月新一代“Windows 7”发布时，Windows Vista的全球份额仅为XP的十分之一。“Windows 7”也用了整整2年时间，才在市场份额上超过了WindowsXP。

如果续用 安全风险大增

　　众多依然依赖Windows XP的用户中，不乏政府机关、学校等重要的公共服务机构。有电脑专家提醒，微软退出支持后，Windows XP的系统风险将会大大增加。

　　专家分析，作为一款目前依然拥有大量用户的经典操作系统，相比固守WindowsXP而言，升级到Windows 7或Windows 8无疑会更加安全，不过，除了升级之外，用户也可以选择第三方安全软件对Windows XP进行防护。

　　虽然Windows XP系统停止了补丁更新的服务，但是国内的一些安全厂商纷纷推出了相应的防护软件，并举办了Windows XP防漏洞挑战赛用来展示防护软件的性能，其中一家安全厂商的防护软件自比赛开始至结束都没有被黑客攻破。

“处决”旧系统 微软意在何为？

　　近些年来，随着平板电脑和智能手机等移动终端的出现，全球的个人电脑业务遭遇寒冬，微软公司的业务不可避免受到波及，因为向电脑厂商收取Windows系统预装费，一直是微软公司收入的主要来源之一。

　　微软公司2013财年年报显示，受到全球个人电脑出货量大幅下滑拖累，微软从电脑厂商获取的系统预装收入同比下滑达10%。

　　为了转而在移动终端市场争夺一席之地，微软公司推出了基于个人电脑和移动平台的Windows 8操作系统，以及预装了Windows 8的平板电脑Surface。但是在2012年上市后，windows 8并没有取得预期的业绩。截至2013年底，市场份额仅为Windows系统总市场的10%。大部分的个人电脑客户都习惯性的依旧在使用windows XP系统。XP系统的全球市场份额约为25%；在中国的市场份额高达70%。

　　DCCI互联网研究中心总裁胡延平称，微软本身非常看重移动互联网未来的竞争和发展，而停止windows XP的服务对于微软的移动互联网战略是有利的，Windows 8操作系统既适用于电脑，又适用于平板 ，因此微软需要借此扩大Windows 8的市场份额。

牺牲XP提升Windows 8占有率绝非易事

　　虽然微软希望通过叫停Windows XP，提升Windows 8的市场占有率。但想在移动领域扩大地盘，其还需要拿出比苹果和安卓更好的系统，这绝非易事。而从另一个角度来说，微软不再支持Windows XP或许可为国产软件商提供契机。

　　最明显的机会是这可以给为Windows XP用户提供安全保障的企业提供一个证明自身技术实力的机会，获得实实在在的营收。另一方面，Windows XP退役也给国内市场制造了大量的用户需求，国产的操作系统也有了更广阔的发展空间，国产软件企业理应抓住机遇推出更适合这些需求的替代品。
