# 【资讯】印度政府将禁用美国电子邮件服务 保护信息安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTk0MzIzMQ==&appmsgid=10000389&itemidx=1&sign=f342ec316e8c6c48144b188b0b7aa439&scene=126&sessionid=1681270612#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MTk0MzIzMQ==&appmsgid=10000389&itemidx=1&sign=f342ec316e8c6c48144b188b0b7aa439&scene=126&sessionid=1681270612#wechat_redirect)

　　据国外媒体报道，印度政府正打算在官方通信中禁用美国的电子邮件服务，如Gmail。印度政府很快会向全国50多万官员发出正式通知，要求他们使用国家信息中心提供的邮件地址和服务。  
　　当美国国家安全局陷入全球监听丑闻后，印度政府的这项举动意在保护政府数据和信息的安全。  
　　电子与信息科技部的秘书蒂亚纳拉亚纳（J. Satyanarayana）表示，美国邮件服务的服务器都不在印度境内，政府目前担心大量重要的数据会寄存在这些服务器中。  
　　大约一周前，印度通信与信息技术部长卡比尔•西巴尔（Kapil Sibal）就表示，政府正在研究新的邮件政策，用以确保政府通信的安全性。西巴尔当时披露，新政策会加强静态IP，虚拟私人网络的使用；当不在国内的官员使用电子邮件服务时，要获得一次性密码。西巴尔还表示，政府会使用国家信息中心的电子邮件服务。因为其服务器就位于国内。  
　　政府监听及间谍活动让很多网络私人服务苦不堪言。Lavabit和Silent Circle就是最近的受害者；新西兰议会最近也通过饱受争议的监听法案，将情报机构秘密监听该国民众的行为合法化。
