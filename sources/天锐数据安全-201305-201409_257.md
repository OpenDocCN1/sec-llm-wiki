# 【媒体报道】版本细分，原是研发团队的无暇心态驱使

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTk0MzIzMQ==&appmsgid=10000247&itemidx=1&sign=35a1e213c2edbb26bd88a27b3d17385a&scene=126&sessionid=1681270638#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MTk0MzIzMQ==&appmsgid=10000247&itemidx=1&sign=35a1e213c2edbb26bd88a27b3d17385a&scene=126&sessionid=1681270638#wechat_redirect)

      2013年3月，厦门天锐科技有限公司震撼推出天锐绿盾信息安全管理软件V3.0，这一次的天锐绿盾信息安全管理软件再次体现了厦门天锐科技有限公司的创新思维：软件细分为专业版、行业增强版和旗舰版三个版本，又是行业首创。

经过3个月的市场考验，依旧迅猛增长的终端客户数量和其他数据安全产商软件细分版本的跟进推出很好地说明了厦门天锐科技有限公司这一创新举措受到市场和业界的认可程度，天锐科技再一次引领了数据安全行业技术创新风潮。

那么，厦门天锐科技有限公司是如何想到进行版本细分这一前所未有的尝试的呢？

“其实，这是研发团队主导的一次创新。”接受采访的厦门天锐科技有限公司总经理邱总的话让我们惊诧，如此接地气的产品创新竟然不是一线团队主导，反而是“后方”支援的。

不管是业内，还是客户市场，大家都知道，加密软件对其他软件的兼容性十分重要。厦门天锐科技有限公司的软件在研发时进行了大量兼容性测试，对众多行业性软件、日常办公软件以及特殊软件等各类软件都有非常强的兼容性。而随着客户不断增加，厦门天锐科技有限公司旗下软件对各行各业软件的兼容越来越多，公司也对相关行业有了深入了解，软件在各行各业的适用性不断增强。

“在研发天锐绿盾信息安全管理软件V3.0时，研发工程师们就提出，把我们以往在各行各业实施的经验融入到新版软件中，全面增强软件的适用性和兼容性，使软件做到安装便能适应客户的需要，彻底为客户提供便利。于是，公司便调动售前、售后等各部门齐心协力研发，而软件推出后的市场反应也证明我们的想法没错，研发团队主导的这次创新受到了认可。”

据悉，天锐绿盾信息安全管理软件分为专业版、行业增强版、旗舰版三大版本，专业版针对企业的普通需求，若公司没有特殊软件或是行业性软件，专业版便能满足企业的数据安全防护需求；行业增强版则是针对行业特征比较明显的企业而设计，软件预装相应的行业增强包，支持对行业性软件、特殊软件的全面兼容；旗舰版则是针对大型集团客户设计，在大面积应用、分布式部署、数据多方采集等方面进行了特殊优化，全面满足大客户的特别需求。

“我们公司自创立以来便是研发团队占多数的团队，至今，研发团队在公司决策中仍占有较大的话语权，这样，商业性的东西会少一些，而产品、技术方面的考量会更多。很多时候，不必考虑太多经济利益，多关注一下产品和技术本身反而离我们公司成立的初衷更近。”

“研发团队更偏向于打造精品、钻研技术，他们有种无暇心态，希望做出来的产品接近完美。我想，这就是天锐绿盾信息安全管理软件V3.0能够受认可的原因，让产品更完美一些，离客户也更近一些。”

在追逐利益的时候，让追求产品和技术的一方也不失话语权，这便是中国信息安全领导品牌、数据安全第一品牌的商业智慧。
