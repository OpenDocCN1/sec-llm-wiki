# 【第三期内刊】天锐课堂——当商业邂逅社交媒体

       不知何时起，微博控们刷微博不再关注冷笑话和“全球”类微博，转而关注起宝马中国、桔子酒店、杜蕾斯官方微博等企业微博。与企业微博互动，“调戏”企业微博运营人员成了部分微博控的新选择。

国内外知名企业、国内中小企业纷纷入驻微博，通过微博宣传、营销，创造了诸多成功案例。

戴尔是世界著名的电脑直销品牌，过去，戴尔通过其官方网站进行直销，为其带来了诸多收益。但随着时间的推移，戴尔仅仅将新产品信息、促销信息和库存信息公布在自己的官方网站上，影响的人群越来越有限。

社交媒体的出现，让戴尔看到了新的营销途径。戴尔的方法是在Twitter上注册许多账号，每个账号发布专门的内容，目标受众非常精确，这样就避免了骚扰其他人。

比如，戴尔在产品账号上，经常发表的信息内容是：①经过翻修的二手产品信息，价格很诱人，并且有库存数据；②超低价格的清仓甩卖活动信息；③新产品信息；④优惠信息。

在每年的节假日，戴尔会向Twitter上的数百万粉丝发送独家折扣大优惠，有12000名购买戴尔新产品的人享受了七折优惠。戴尔在Twitter上发给客户的折扣礼券，可以链接到专门的网页，在订购产品时享受到优惠。通过Twitter，戴尔在全球已经直接创造了近700万美元的营业额。

享受到Twitter带来的好处之后，戴尔在新浪微博也开辟了官方账号，进行营销活动，继续追寻社交媒体带来的种种好处。

与戴尔这种在新浪微博上复制Twitter模式相比，土生土长的新浪微博营销案例或许更有说服力。膜法世家便是利用新浪微博进行营销的成功案例。

膜法世家是个在淘宝网上专做面膜产品的小微企业，不到2年做了20万笔生意，保持了100%的好评率。

新浪微博流行后，膜法世家成立了一个7人的微博团队，她们以美容专家的身份出现，专门回复受众各种有关面膜、美容、护肤类的话题，帮助大家纠正错误做法。

在淘宝网做成20万笔生意，并且保持100%的好评率，已经可以看出他们在产品和服务上的成功。他们的生意做得如此井井有条，每天在广告上的花费也都在百万级别。他们深知广告的重要性，但这么多钱花出去，和自己的客户却说不上几句话，这让他们很郁闷。

他们的产品是天天敷在女人脸上的，知道客户的体验非常重要。看到新浪微博的兴起后，他们意识到，微博将成为他们与客户沟通的最佳工具。于是，7人的微博团队便迅速组建起来了。

微博确实有很好的互动条件，但很多企业微博常常忽略了每个人在微博上的自由，经常骚扰别人。因此，建立自己的通道，组织自己的粉丝群体，让对话通达，十分必要。

膜法世家很快就在新浪微博上摸索出了自己的道路，他们为自己制定了一些游戏规则：

1.           要写有感觉的内容，真实，自然，能够体现企业整体的价值观和理念；

2.           不要在自己的微博里批评任何企业和品牌，也不能说贬低对方的话；

3.           不要主动推销自己的企业和品牌，除非对方非常明确地问到膜法世家的产品和品牌；

4.           要避免任何一种有可能被认为是不正当竞争的做法，对同行尤其要尊重，不能轻易地以自己的个人主观意识去批评对方，切忌切忌。这是品牌文化的表现。在微博的言论，要充分体现膜法世家的理念和价值。

利用新浪微博，膜法世家不仅建立了数量庞大的粉丝群体，而且做到了不骚扰别人，不贬低同行，传播了企业文化，树立了品牌价值。而且，通过新浪微博，膜法世家与顾客建立了非常迅速的联系，至今，其31分钟内处理顾客投诉，让顾客转变评价的案例仍为人称道。

各种社交媒体的出现，符合科技发展的要求，顺应大众的需要。企业也逐渐意识到，社交媒体对于商业营销方式的重塑具有举足轻重的作用，因此企业也十分愿意引入社交媒体，进行全新的商业营销。但企业引入社交媒体进行商业营销时应注意，社交媒体最重要的精神是沟通，企业引入社交媒体应将其沟通的价值最大化，而不是简单地进行硬性营销推广，舍本逐末。
