# 自主创新引关注 厦门天锐科技有限公司受到《厦视直播室》报道

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTk0MzIzMQ==&appmsgid=10000190&itemidx=4&sign=b25c2a5dea38849274d6cd695b7b125f&scene=126&sessionid=1681270643#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MTk0MzIzMQ==&appmsgid=10000190&itemidx=4&sign=b25c2a5dea38849274d6cd695b7b125f&scene=126&sessionid=1681270643#wechat_redirect)

       厦门天锐科技有限公司一直致力于自主创新，以创新的理念与技术影响并推动中国数据安全技术的发展。多年来，数据安全领域内网管理与文件加解密相结合、多重密钥技术、全方位一体化数据防泄密解决方案等多次技术与理念的进步与革新，都可以看到厦门天锐科技有限公司作为创新者与推动者的身影。

对自主创新的孜孜不倦追求，不仅使厦门天锐科技有限公司赢得各行各业数百万用户的信任与青睐，也赢得了普通大众和各类媒体对厦门天锐科技有限公司的认知和认可。

2013年4月21日，厦门卫视二套《厦视直播室》栏目对厦门天锐科技有限公司进行了相关报道，引发各界关注。
