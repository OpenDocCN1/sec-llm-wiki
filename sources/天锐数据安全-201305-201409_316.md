# 【资讯】《关于开展电力工控信息安全专项行动的通知》

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTk0MzIzMQ==&appmsgid=10000089&itemidx=1&scene=126&sessionid=1681270659#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MTk0MzIzMQ==&appmsgid=10000089&itemidx=1&scene=126&sessionid=1681270659#wechat_redirect)

       据国家电力监管委员会江苏省电力监管专员办公室发布通知：为进一步加强电力工控信息安全监管工作，维护电力系统安全稳定运行和电力可靠供应，根据国家电监会《电力工控信息安全专项监管工作方案》要求，江苏省电力监管专员办公室决定开展江苏电力行业工控信息安全专项行动。

这一专项行动要求针对工控系统及设备信息安全方面的薄弱环节，建立电力工控信息安全风险管控工作机制，开展工控设备信息安全风险排查处置，规范和加强核电、风电、光伏及配电侧二次系统安全防护，组织开展二次安全评估和等级测评及整改工作，旨在落实《国务院关于大力推进信息化发展和切实保障信息安全的若干意见》和工业和信息化部《关于加强工业控制系统信息安全管理的通知》(工信部协〔2011〕451号)要求，建立电力工控信息安全监督管理工作机制，以工控系统安全评估和等级测评为抓手，进一步督促落实电力企业信息安全主体责任，重点做好工控设备信息安全风险排查处置和核电、风电、光伏及配电侧二次系统的安全防护工作，维护电力系统安全稳定运行。

行动共分为部署启动（3月）、组织实施（4—10月）和总结提高（11月）三个阶段，目前已平稳地进入组织实施阶段。
