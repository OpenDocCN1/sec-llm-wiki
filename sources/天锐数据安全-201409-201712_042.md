# 创新突破 继往开来——天锐股份2017年中总结暨表彰大会圆满闭幕

7月8日，天锐股份年中总结暨表彰大会在厦门总部圆满落下帷幕。此次会议既是对上半年工作的总结，同时也是为下半年工作的顺利展开提供不竭动力。诚如此次大会口号——“**创新突破 继往开来**”，此次会议的圆满结束也标志着2017年下半年的各项工作正式启动，天锐股份董事长涂高元出席了此次年中大会，总经理邱志斌针对公司下半年发展目标发表重要讲话。

一、加强联动，全面提升品牌影响力

经过十几年的发展，天锐股份稳步成长，历练出了适合自身发展之路，并形成了天锐绿盾信息安全管理平台、天锐绿盘文档安全管理平台、天锐数据泄漏智能防护系统等核心产品及服务体系，共同构成了一个信息安全产品生态圈。

17年上半年天锐业绩稳步增长，超过去年同期增长水平。并获得了一系列的荣誉资质，预计2020年公司的发明专利将达到四十余项。公司领导全面阐述国际国内信息安全态势及天锐信息安全产品与公司整体服务主要策略。在天锐上半年整体发展态势良好的基础上，明确下半年产品与服务的发展目标。

二、创新思维，提升技术与服务实力

针对下半年的展规划，研发适应当下信息安全市场的产品。挖掘产品的核心价值和增值空间。加大客户维护力量，提高客户满意度；加强技术巡检工作，改善用户体验，发现新的需求改善产品；大力支持各分部拓广线下活动，创新销售思路，进一步完善大区负责制的营销体系建设，建立有天锐特色的信息安全产品全国服务体系；以天道酬勤、锐意进取为核心，打造积极进取的企业文化。

全国各个大区域及总部各部门是公司在发展道路上的中流砥柱。在会议期间，各部门与各大区域负责人利用此机会，对上半年工作进行了总结，进一步明确下半年的目标与任务，行政副总张艳蓉为大家介绍了公司的保障体系，让大家对下半年的目标充满信心。

与此同时，公司领导为获奖的三个优秀团队和十名天锐精英进行了颁奖。“一切以结果为导向，敢于创新，敢于突破，并在高效工作中发挥价值。”激励天锐全体员工齐心协力、再创辉煌。

大会最后，公司领导给全体人员提出三点要求和期许：第一，围绕公司三大产品线，公司全员明确各自业务体系的目标和策略;第二，全面利用公司资源，充分发挥才能和才华，实现自我价值;第三，公司上下团结协作，携手共同努力，创造更大的收获。  

不忘初心，梦想起航，奋勇前行。参会人员纷纷表态，一定会带着会议中的感悟和收获，以全新的面貌回到各自的工作岗位，锐意进取、砥砺前行，全面加强业务冲刺，力争促进各项业务发展再上新台阶，为天锐股份跨越式发展贡献出自己的一份力量！
