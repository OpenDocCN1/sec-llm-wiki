# 天锐绿盾携手敏行医学，共建虚拟医学技术防泄密大环境

苏州敏行医学是一家从事虚拟医学技术研发的高科技公司。公司在北京、上海、武汉、成都等地都设有分支机构和技术支持中心。公司的创业团队在医学领域和生物力学领域具有多年的研发积累、雄厚的技术储备以及丰富的实践经验。医学教育手段与模式随着教育理念和科学技术的发展而改变，敏行医学利用创新的技术手段来丰富、提升医学教学方法，不断追求更贴近临床的教学训练效果。

![](../Images/edbcc742eeae1457c08d2ca77431dec9.png)![](../Images/89790747372496f9b038fa17014ef08e.png)![](../Images/fec269ffeca92d85a30c5740e95ec332.png)

那么问题来了，涉及高知识产权研发行业如何确保长期辛苦研发的成果不会拱手相让给竞品企业？

主要面临以下问题：

1.  知识产权数据保护如何从被动防御到主动管理？

2.  虚拟教学新研发产品不同应用场景下如何保护？

3.  技术保密方案如何通过技术手段加密隔离访问？

4.  如何保障敏行总部与分部技术资源在传输过程中技术成果不会无控泄密？

5.  如何确保企业与客户共同研发的VR系统数据安全？

6.  企业员工终端和移动终端办公敏感数据如何防止泄密和失密？

7.  因业务需要外发到第三方人员或组织的重要数据如何受控？

8.  如何防止企业内部人员有意或无意泄漏重要敏感数据？ 

9.  公司的信息安全保密制度如何才能有效落地？

![](../Images/fec269ffeca92d85a30c5740e95ec332.png)

通过部署天锐绿盾数据防泄密系统、天锐绿盾桌面管理系统、天锐绿盾行为审计系统，敏行研发及相关人员保密意识显著增强，配合公司现有的保密制度，公司核心模型、开发数据、财务数据、客户资料等都得到了有力保障，业务系统的安全也得到提升，大大提高了企业内部信息管理的安全性 。
