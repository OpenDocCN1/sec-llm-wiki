# 天锐绿盾捍卫育创园丁智慧成果

上海育创网络科技股份有限公司致力于IT培训业,以就业和企业解决方案为导向、以人才为根本、以技术为核心。公司和长三角地区软件园区以及全国各地一流软件企业建立了长期合作关系，汇聚了中国IT培训方向优秀的教学团队，立足于中国IT在线教育技术的前沿，为在校大学生、应届毕业生、社会就业者提供热门、高实战性、高性价比的IT在线培训服务，已成为目前国内IT在线培训领先品牌。

对于教育培训行业来说，核心竞争力——教育资源、师生资料保护的重要性毋庸置疑，同时由于普遍存在IT资源管理匮乏的情况，机构要求防泄密软件做到灵活的管控、有用、好用且易用，有效保障资料数据安全的同时，又不会给运营维护造成压力。

通过部署**天锐绿盾数据防泄密平台**，上海育创网络科技股份有限公司对院校内部的重要教学资料，教研PPT、包括课件、文档、教育资料、动画资料、音频、视频以及学生个人资料，实现加密保护。如果文件需要外发，则可通过制作可控的外发文档，限制使用者的打开次数、能否复制、能否打印、能否抓屏等权限，有效保障外发文档安全，防止外发资料被盗用、扩散。同时文件进行权限设置，实现校内包括分校、分部流转安全保护。教育培训行业的另一大特点就是异地授课，当老师需要外带笔记本出差办公时，可通过离线策略设置离线时间，如超出离线时间则需管理者审批。

**天锐绿盾数据防泄密系统**从基层源头上保障数据安全和使用安全的软件系统。包含了文件透明加解密、内部文件流转、密级管控、离线管理、文件外发管理、灵活的审批流程、工作模式切换、服务器白名单等功能，并全面覆盖Mac、Windows、Linux系统。从根本上严防由于疏忽或职员流动导致的自主知识产权、教育资源遗失、被盗或外泄，保障教育培训单位信息安全。
