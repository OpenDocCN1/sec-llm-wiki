# 诈骗短信来袭，深知其害却无动于衷？

小编今早收到了一条令人振奋的短信“尊敬的建行用户， 您的账户已满5000积分，可兑换5%的现金，请登录手机网www.955\*\*\*\*.com查询兑换，逾期失效！【建设银行】”

建行在发工资前夕来了这么一条赤果果的诱惑，会有多少人中招呢？小编在这边就要给大家提个醒了，这就是一条**诈骗短信**。

![](../Images/54b2dd97dfd2fbea1ea5efd947cde930.png)

近几年，网络诈骗越来越泛滥，骗子手段也越来越高明，很多人一不留神就被骗了，辛辛苦苦攒的钱就这么付诸东流，分分钟想将骗子撕成两半。报警不失为一种正道的解决方法，可是我想告诉你，其实并没有什么卵用，钱很难追回来。

在现实生活中，最常见的骗术莫过于孩子生病或车祸要打钱，中了大奖花小钱领取，冒充官方客服、房东等。骗子套路深，可我们也不傻，一个不经意就把骗子逗得团团转。看到骗子气急败坏地说：“你这个骗子”，很解气有木有？

说到这里，小编不得不引申出更为重要的一点，为什么诈骗的频率会这么高呢？真的是这些骗子手段高明到能够黑到这么多人的信息吗？造成这一现在最主要的原因则是因为**没有加密！没有加密！没有加密！**（重要的事情要说三遍）将信息袒露在空气中，总是会引来别人的虎视眈眈。在网络上总有那么一拨人，为了利益，倒卖网民信息。电商平台、银行系统甚至公安部门等等，都可能会遭此“毒手”。在大家提高自身防诈骗技能的同时，信息安全防泄漏一样是刻不容缓啊！

  

诈骗电话神回击NO.1

那天接到诈骗电话，我直接用沙哑的声音开始讲一个精彩的鬼故事，讲到一半，挂了电话。对方紧接着又打过来，说：大哥，麻烦你讲完嘛。我说：5000，指定卡号，可听结尾。

诈骗电话神回击NO.2

有次我接电话说：喂，哪位？那边就是小孩哭声，然后有个男的说叫妈妈，小朋友就叫，我问你想怎么样，他让我打钱，说：“你儿子在我手里”，可问题是我还没有儿子啊，如果是个妈妈，恐怕就没理智了吧！

诈骗电话神回击NO.3

接到一个推荐股票的电话，我就问他怎么炒，是不是搁锅里炒？大锅还是小锅？铁锅还是电饭锅？骗子嘟囔一句“还锅里炒”就挂了，然后我就开心极了。

诈骗电话神回击NO.4

一个骗子电话说自己是某某单位的，我就一直追问骗子你的单位在什么地方，什么区，哪条路，几号，旁边有什么大型建筑，最后告诉他我就住这旁边，业务不精怎么出来混，把骗子骂得不敢吭气。

诈骗电话神回击NO.5

骗子：我们是建设银行，刚才查询发现您的银行卡昨天在境外消费180万零8千美元，请问是您本人消费么？ 我说：是我本人消费的。 骗子沉默了5秒后说：您真能吹牛逼……把我的思路都打乱了。

诈骗电话神回击NO.6

一个广东来的电话说我的手机号码中了她们公司一等奖，奖是一辆奇瑞QQ，说我要缴纳五千块税钱才能提车，我最后给她说：要不这样，我把我的卡号告诉你，你往里打五千块，这车就是你的了，还没说完对方把电话挂了。
