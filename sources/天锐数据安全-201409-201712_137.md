# 媒体专访天锐股份：十年磨剑 数据安全显锋芒

今年“十三五”规划纲要《草案》出台，明确提出：要完善国家网络安全保障体系，保障国家信息安全。可见信息安全领域得到国家和社会的高度重视。

  

8月9日，中国企业报道记者对厦门天锐科技股份有限公司总经理邱志斌先生进行了采访。厦门天锐科技股份有限公司是信息安全产品与整体解决方案提供商，专注于信息安全领域产品研发，致力于为政府、军工等涉密单位及其它企事业单位提供专业的信息安全产品、顾问咨询和技术服务。以下是采访内容：       ![](../Images/2cd0f7f17de72f7e68f0d54739b74bd3.png)

**中国企业报道：随着云计算、大数据、移动互联网等新兴技术的快速兴起，安全威胁和安全挑战也越来越突出。面对这样的环境，您认为目前信息安全产业应该何去何从？贵公司又将有怎样的应对策略？**

  

**邱志斌：**有挑战才有机遇，现在对信息安全威胁这块的关注这么高，也表明社会对数据价值的认可，将带动更多的企业投入到信息安全建设中。目前，数据的应用场景越来越复杂，同时涉及到的安全主体也越来越多，从硬件设备安全、网络安全到终端环境把控，一环出错，都可能造成企业信息建设的“满盘皆输”，病毒查杀、封闭断网已经无法真正解决信息泄露问题。所以，信息安全产业需要整体布局，走合作的道路，根据客户的实际情况，从各复杂应用场景出发，制定全面的信息安全解决方案。

  

作为国内领先的数据安全厂商，天锐将始终专注数据安全领域，专研数据防泄密、文档安全管理前沿技术，根据不同客户的实际需求，提供适合、全面的解决方案，保障客户的核心资产安全，保障客户应用价值的最大化。

  

**中国企业报道：天锐这几年一直站在数据防泄密的技术前沿，企业发展速度也非常快，作为天锐的创始人，能否介绍一下天锐的技术理念以及经营之道？**

 

**邱志斌：**天锐是2006年创办的，在当时企业对数据安全的认识还没有现在这么成熟，但正是选对了发展方向，我们才能从大浪淘沙的浪潮中生存并迅速发展。数据安全是我们的核心理念，不管是做加密，内网管理，还是文档云存储，数据安全始终是我们关注的重点，构建从数据的产生、使用、存储到流转、销毁等整个数据周期的安全。相信在大数据的环境下，未来该市场还将继续强势的发展态势。

 

在经营方面，我们主要面向技术密集型和创新产业的客户，客户一般集中在制造业、医药、工程设计、政府等行业。在客户看来，我们的产品安全可靠，用起来也更加方便，服务也更好，所以更值得信赖。迄今为止，天锐已经为超过上万家的政府机构、大型国企和中小型企业提供数据防泄密服务，使上百万终端用户享受数据安全保护。

 

**中国企业报道：天锐公司实现了两大平台产品天锐绿盾信息安全管理平台和天锐绿盘文档安全管理平台的技术革新，下一步在产品创新方面还有什么新动向？**

 

**邱志斌：**产品技术够高端是不够的，还要充分了解客户需求。如今，以客户为中心，“为客户创造最大化价值”是很多行业的服务理念，因此在信息安全行业催生了移动化、云端、智能识别等的产品服务。所以，除了进一步把现有产品的功能做细做强之外，我们的主要投入方向将集中在移动安全和DLP数据防泄露这两大方面，满足客户日益增强的移动办公需求，以及进一步实现数据的自动识别、智能防护。而事实上，从很早我们的信息安全研究中心就加大了对这两块的研发投入，并应用到一些客户数据安全项目的定制服务中，相信过不了多久，相关的产品就会和大家见面。

 

**中国企业报道：天锐股份成功在新三版上市,这对公司未来的经营和发展创造了怎样的机遇?公司未来是否会有新的战略部署?**

 

**邱志斌：**在新三板成功挂牌，标志着天锐股份作为国内领先的信息安全产品与整体解决方案提供商，走过十年磨一剑的奋斗历程，踏上了一个新的台阶，不管是从品牌知名度上，还是资金融资渠道上，公司都将迈入一个新的发展阶段。未来，我们将继续加大在产品研发上的投入，掌握前沿技术，紧跟国内国际信息安全的发展方向，不断提升客户体验感，同时与更多的上下游信息安全厂商合作，为客户构建一站式信息安全防护体系；在市场开拓上，我们将不再局限于国内，将进一步开拓东南亚及其他国家市场，相信凭借创新与符合信息安全市场需求的产品，开拓国际市场存在可能与机会，天锐的下一个目标是飞得更高、走得更远。可以说，过去十年天锐在磨剑、在积淀，现在天锐已经做好了迎接数据安全下一个黄金十年的准备，为广大国内外客户提供更尖端的产品、更优质的服务。

天锐始终秉承“天道酬勤、锐意进取、研发创新、客户至上”的企业核心价值观，旗下的系列产品及解决方案已成功应用于数百万终端，产品在政府、军工、金融、制造、建筑设计、轻工纺织、教育、通讯等几十个领域得到广泛应用，占据领先的市场地位。天锐在全国多个省市高密度部署服务网络，已拥有覆盖全国的渠道和售后服务体系，最大程度实现本地化服务，为客户提供及时、高效的技术服务支持。(中国企业报道记者王琪)
