# 2015中国网络安全人才需求调查结果

安全牛于9月18日发起了一项针对网络安全从业人员需求的调查，该调查于9月30日结束，并且是一项完全透明的调查，所有当时参与调查的人员（需为关注安全牛公众号的读者）均可即时看到调查结果，但还是有许多未参与调查的业内人士对此次调查结果并不了解。现安全牛将结果整理归纳如下，谨做参考。

  

![](../Images/e8324c24b96f832d7e0d5f5cd352455e.png)  

**调查结果一：**

  

网络安全、系统安全、数据库安全、Web安全、移动安全、大数据安全、业务安全的人员需求均在7%至18%之间，其中网络安全与Web安全人员为两大需求之最。物联网安全与工控安全人员需求较少，均不到5%。

  

**调查结果二：**

  

职位需求相对平均，但网络攻防与安全运维仍为最大的两个需求，接近40%的受访者选择了这两个职位。安全管理、安全审计和安全研发也均在10%以上。

  

**调查结果三：**

  

需求人数方面，选择1到10人的占58%，选择0人的只有1%。选择11-20的占15%，选择50人以上的占13%。大致可以判断出，受访者的企业的规模比例。需要50人以上的，可能是大型互联网公司，需求10到20人的为大型网络安全公司，需要1到10人的小型企业最多。

  

**调查结果四：**

  

在现有安全从业者人数的选项中，1到10人为42%，11到30人为19%，100人以上为17%。31到50人和51到100人，分别为7%和9%。

  

**调查结果五：**

  

参与调查的人所属行业，27%为互联网企业，25%为网络安全企业、11%为金融行业，电信、政府、能源、制造业为列8%、7%、4%、4%，教育、贸易、交通均为2%，房地产、医疗仅为1%。从中大致可以看出，各行各业对网络安全的关注程度。

  

互联网>网络安全>金融>电信>政府>能源/制造>教育/贸易/交通>房地产/医疗

  

**调查结果六：**

  

受访者所属企业的规模，100人以下占29%，100到500人占25%，500到5000人占30%，5000人以上占16%。

  

**调查结果七：**

  

49%的受访者为中高层，50%为普通员工。

  

**结语：**

  

根据第三项和第五项调查结果，可通过抽样和平均算法，大致计算出未来一年内国内企业对网络安全人员的需求数量区间大致为：

  

8.7万~14.7万（人）

  

但目前信息安全类毕业生每年的毕业人员数量仅为2万人，安全人才需求明显确处于非常紧缺的状态。
