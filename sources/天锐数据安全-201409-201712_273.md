# 天锐·快讯 | 天锐科技喜签阿特贝尔景观设计数据安全项目

快讯近日，上海阿特贝尔景观规划设计有限公司携手厦门天锐科技，提升企业内部信息安全建设。通过部署天锐绿盾数据防泄密一体化解决方案，公司对重要文件实现加密保护，成熟的驱动层加密技术致力于构建“对内无碍、对外受阻”的数据安全环境；同时进行有效的桌面和行为管理，引导员工合理的使用计算机和网络。特别在文件外发这块，天锐绿盾可以根据公司的需要对外发的重要文件设定谁能看、哪台电脑上看、可以看几次、是否可以打印、截屏等，可以控制外发文件的使用对象和操作权限，外发文件不再是“断线的风筝”，文档依旧安全可控。  
公司简介：阿特贝尔（ARTBELL）是一家专业从事国内外景观规划与设计的国际品牌服务机构。机构创立于澳大利亚悉尼，目前分别在澳洲、欧洲、亚洲等地设有办公室。为了更好的服务于大陆市场，先后在上海、福建等地成立阿特贝尔景观规划设计有限公司。以“创新设计+品质服务”为宗旨，以“创造一座园，荣耀一座城”为目标，阿特贝尔已成长为中国极具创新力及专业影响力的景观设计队伍。
