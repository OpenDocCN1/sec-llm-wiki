# 天锐·快讯 | 天锐科技喜签珠海审计局信息安全建设项目

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTk0MzIzMQ==&mid=204212128&idx=3&sn=04e126583b1e2edb000a79b367e940c2&chksm=2f7578f01802f1e686aac34509732398d28e067630066f8afff81835a4001acbbc6e0c8e59f6&scene=126&sessionid=1681270475#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTk0MzIzMQ==&mid=204212128&idx=3&sn=04e126583b1e2edb000a79b367e940c2&chksm=2f7578f01802f1e686aac34509732398d28e067630066f8afff81835a4001acbbc6e0c8e59f6&scene=126&sessionid=1681270475#rd)

快讯近日，天锐科技成功签约珠海市审计局，部署数据防泄密升级解决方案。针对电子文档的使用、网络管理、存储介质的使用、计算机维修等信息安全问题，除了常规性的保密管理外，珠海市审计局还需要采取有效的技术手段和方法。  
作为政府部门，采购设备软件一般都要求比较严格，有周密的产品选型过程。在使用天锐绿盾解决方案测试之前，审计局一再确认产品的功能，并进行了产品比对。最后，凭借优质稳定的解决方案以及完备的资质实力，天锐科技成功拿下项目，主要从数据加密安全、内部规范化的网络管理和文件密级管理等三个方面进行信息安全部署。
