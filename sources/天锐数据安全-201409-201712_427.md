# 银行信用卡信息泄露 10万条只卖2000元

概述　　最近，银行卡信息泄露事件颇受关注，在感叹信息外泄防不胜防的同时，金融机构也应该加快自身的信息安全建设。

　　银行信用卡客户数据泄露现象颇为严重。一位微信群卖家说：“最便宜的一份2000元10万条，算下来每条数据只要2分钱。”最新信用卡开户数据按照0 .5元一条出售；已经出售过一次的二手数据，可以便宜到0 .35元每条；部分高端客户如金卡、白金卡持卡人信息每条售价则高达5元。  
  
　　信用卡关乎个人的财务和资金安全，假如信用卡信息被用于信用卡犯罪，意味着持卡人的财产安全，将受到极大的威胁与侵害，现实中，银行卡复制，信用卡盗刷的案例，也早有发生。客户信用卡信息被售所形成的个人金融风险，显然绝非儿戏，更不容低估。  
  
  
　　既然个人信用卡信息是由银行方面管理，这一信息的泄露，银行当然难辞其咎。无论银行流程多么严密，一个信用卡办理流程，在银行内部要经很多人的手，要做到信息保密上完全天衣无缝，的确并不现实。对于“内鬼”与合作公司的违规行为，让银行来承担，似乎也有些冤枉。然而，作为个人信用卡的登记办理机构，银行对于信用卡信息安全的保障，显然需承担第一责任。无论泄露在哪个环节，“内鬼”也好，合作公司也罢，也都与银行对个人信用卡信息的保护不力，管理漏洞有关。  
  
　　相形之下，国外银行对于客户信息，则有着严格的信息保护守则，银行必须承诺有合理的预防措施，必须有控制风险的政策、程序及系统。为此，银行对接触客户敏感数据的雇员背景要进行详细调查，以剔除银行内部流程中信息泄露的风险。而在选择合作商时，保护消费者个人财务隐私，同样是必须遵循的准则。银行在保护客户信息上不敢掉以轻心且舍得投入，并非出于自觉，而是一旦泄露客户信息，将面临法律追责与经济处罚。  
  
　　而反观国内，违反客户信息保密业务，除了民事责任与行政责任之外，并无刑事责任的规定，携程信用卡泄露之类的严重案例，也往往不了了之。违规成本如此之低，信用卡信息售卖又怎能不猖獗？ （来源：中国网）  
  

天锐观点银行机构亟需加强信息安全建设　　杜绝用户银行信息泄露，还要从源头抓起，个人信用卡信息是由银行方面管理，所以银行对用户的信息安全负有不可推卸的责任。　　　　银行如何防范“内鬼”盗窃数据？一方面从数据源头加密，设置某些岗位某些文件类型的资料在生成、复制、修改时自动加密，即使外泄也无法打开；另一方面通过对员工的上网行为进行监控记录，规范员工办公行为，防止信息外泄。
