# 天锐股份入选2022年度福建省重点上市后备企业

近日，福建省地方金融监督管理局公示了**2022年度福建省重点上市后备企业**名单，厦门天锐科技股份有限公司凭借健全的治理机制，合法的规范经营及良好的信用记录列入该名单中。

![](../Images/c9e599d3252e52511db91d8523d383a3.png)

（图片来源：福建省地方金融监督管理局）

![](../Images/bb4ccc737265dfadad0277f222ea31a4.png)

（拟列入2022年度福建省重点上市后备企业名单）

  

厦门天锐科技股份有限公司作为始终坚持自主研发的创新型国家高新技术企业，十六年来专注于数据安全领域产品研发，通过终端安全管理、数据泄露防护、网络准入控制等技术为企事业单位打造全方位的数据安全解决方案。
