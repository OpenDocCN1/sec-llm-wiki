# 网络强国丨共筑网络安全防线 习近平这些话指明路径

党的十八大以来，以习近平同志为核心的党中央高度重视、统筹推进网络安全和信息化工作，推动网信事业取得历史性成就、发生历史性变革。习近平总书记举旗定向、掌舵领航，提出一系列具有开创性意义的新理念、新思想、新战略，形成了内涵丰富、科学系统的习近平总书记关于网络强国的重要思想。在这一重要思想的指引下，我国正从网络大国向网络强国阔步迈进。

一直以来，习近平总书记始终高度关注网络强国建设。让我们回顾总书记关于树立正确网络安全观的一些重要论述！  

![](../Images/3160a2427bc706ce67a193e1d01ce4d0.png)

**感知网络安全事态**  

  

“感知网络安全态势是最基本最基础的工作。**要建立统一高效的网络安全风险报告机制**、情报共享机制、研判处置机制，准确把握网络安全风险发生的规律、动向、趋势。要建立政府和企业网络安全信息共享机制，把企业掌握的大量网络安全信息用起来，龙头企业要带头参加这个机制。”

  

  

  

  

  

**强化关键信息 基础设施防护**  

  

“要筑牢网络安全防线，提高网络安全保障水平，强化关键信息基础设施防护，**加大核心技术研发力度和市场化引导，加强网络安全预警监测**，确保大数据安全，实现全天候全方位感知和有效防护。”

  

  

  

  

  

**要切实保障国家数据安全**  

  

“要切实保障国家数据安全。要加强关键信息基础设施安全保护，**强化国家关键数据资源保护能力，增强数据安全预警和溯源能力**。要加强政策、监管、法律的统筹协调，加快法规制度建设。要制定数据资源确权、开放、流通、交易相关制度，完善数据产权保护制度。”

  

  

  

  

  

**积极发展网络安全产业**  

  

“要树立正确的网络安全观，加强信息基础设施网络安全防护，加强网络安全信息统筹机制、手段、平台建设，加强网络安全事件应急指挥能力建设，**积极发展网络安全产业，做到关口前移，防患于未然。”**

  

  

  

  

  

“维护网络安全是全社会共同责任，需要政府、企业、社会组织、广大网民共同参与，共筑网络安全防线。”党的十八大以来，习近平总书记高度重视网络安全和信息化工作，为做好网络安全工作提供了根本遵循和强大动力。

（上述新闻来自《央视网》）
