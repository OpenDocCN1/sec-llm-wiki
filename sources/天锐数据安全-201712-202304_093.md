# 天锐股份入选“福建省科技小巨人企业名单”

![](../Images/2778a405a19d607952fe5b3734cf1e28.png)![](../Images/5969ec04af7105a108af5bc87e3fe17e.png)

近日，福建省科学技术厅网站公示了“2022年福建省科技小巨人企业名单”，厦门天锐科技股份有限公司成功入选！

![](../Images/95736b67a3e1d1d7cfec8e8e2f2e2119.png)![](../Images/a15a51034b8f199b891b906541a7a24d.png)

福建省科技小巨人企业遴选的对象需在企业营收、研发投入、知识产权、社会信用等综合维度均表现优异，且具有较强创新能力和发展潜力，在行业内有代表性和领头示范作用。天锐股份作为中国数据安全行业的先行者，始终以理念创新和技术创新为驱动，以“做可信赖的数据安全产品与服务提供商”为愿景，打造高水准的数据安全防护体系，构建安全高效的信息化办公环境。

此次入选2022福建省科技小巨人企业，是对天锐股份科研创新实力的高度认可。今后，天锐股份将继续加强研发创新力度，提升产品与服务质量，助力推动数据安全行业发展！
