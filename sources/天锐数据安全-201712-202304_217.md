# 天锐股份 第七届技术工程师认证培训圆满完成

    天锐股份第七届技术工程师认证培训于2021年1月23、24日在上海召开，十余家核心代理商的技术骨干及精英合作伙伴们通过两天的学习完成了此次培训和考核，公司为通过测评考试的工程师们颁发了天锐股份认证工程师证书。

**认证工程师**

  

天锐股份

  

  

  

![](../Images/b38417dcdb6eac959ddcf9a671017826.png)

    此次上海分公司“天锐股份认证工程资格培训”内容主要涉及天锐绿盾信息安全管理平台的三大系统（天锐绿盾加密系统、天锐绿盾桌管系统、天锐绿盾审计系统），具体主要包含：天锐绿盾产品功能演示培训、天锐绿盾售前标准流程培训、天锐绿盾实施标准流程培训、天锐绿盾售后排查等，并进行主要功能实践操作，采取理论结合实践，加深理解并体验天锐绿盾的功能和效果，使学员们深度了解天锐绿盾的功能和作用，以及如何快速部署安装使用，后续更多技术的加深可以根据提供的培训资料和测试环境进行自我个人能力的提高。

    通过培训学习及测试，加强了合作伙伴们工程师对天锐绿盾体系系列产品的深入了解，提高了技术人员的服务水平，更好的帮助天锐股份用户保障企事业信息安全。天锐股份全国多地市进行认证工程师培训计划，加深本地化服务深度，提高本地化服务质量，与全国各地合作伙伴一起更好的服务于天锐绿盾客户。携手天锐共同发展，实现合作共赢！
