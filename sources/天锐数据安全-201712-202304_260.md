# 如何防止外发图纸文件的内容外泄

随着现代企业业务的快速发展，企业与合作伙伴之间有大量文件数据需要进行交换，比如向甲方提供产品设计图纸、市场营销方案、工程设计图纸等等。

  

![](../Images/4f2a0b1ff6b914f31ce3f32d43f03619.png)

  

尤其是从事设计行业的公司，如平面设计稿、家居方案图、CAD图等等，是设计人员日日夜夜凝聚的心血。但是由于图纸文件的特殊性，图纸内容易泄露，所以企事业单位必须采取有效的措施来保护外发图纸的安全性。

  

外发图纸文件会遇到什么问题？

1.例如psd源文件、CAD图纸等，如果发送给客户后，客户任意盗用。

2.客户擅自修改、打印使用外发图纸文件，并拒绝后续的合作付款。

3.对外发图纸文件内容通过截图、拷贝、拍照等非正规手段，获得图纸内容信息。

4.无法对外发行为进行管控和审计，若发生图纸泄漏事件不能追根溯源，及时止损。

5.缺乏有效的审批审核过程，无法杜绝通过邮件、QQ、微信以及U盘拷贝随意进行文件交换的现象。

6\. 因研发设计的流程较长，研发人员的开模图纸容易在工作流程中遭到泄露风险。

  

  

#解决方案#

# 设置外发图纸文件不同的认证方式；

  

# 限制外发图纸文件的打开次数、打开时间、打印权限、截屏权限、过期自毁；

  

# 外发图纸文件添加屏幕水印；

  

# 部门权限隔离，创建不同的管理权限；

  

# 审计并记录外发图纸文件的操作行为。

***01***

  

根据外发图纸文件的重要性，设置不同的认证方式，如口令、机器码、PC绑定、联网证书等方式。只有获得认证的用户才能打开图纸文件，其余用户即便是打开文件，无法读取图纸内容，会呈现乱码；

***02***

  

设置外发图纸文件的权限，包括浏览次数、使用时间、打印、修改、拷屏等方式，对于那些有意盗用图纸的客户，还可以设置自动销毁的权限，除此之外还可以通过天锐云平台追踪外发文件的实际使用情况，保护公司的利益；

***03***

  

添加外发水印的功能，有效防止那些有心之人，通过拍照、截屏等手段获取图纸信息。可自行选择水印方式，保障研发人员的图纸文件在工作流转过程的安全性；

***04***

  

天锐绿盾可建立完善的管理框架，所有内外部用户上传、下载外发文件的行为都留有完整记录，并经过上层业务流程审批系统的审批和授权，确保外发过程有据可循，实现外发图纸工作的安全合规；

***05***

  

创建不同的管理权限，随时掌握外发图纸的状态。天锐绿盾根据企业管理者可以基于部门、业务、项目、团队等不同逻辑，创建不同的文件管理权限进行共享与协作，即时跟踪掌握文件发送和接收状态，随时跟踪业务协作进程。

  

天锐绿盾适用于多种场景的企业加密，包括企业内部流通、外发、员工在非公司环境办公等环境，保护企业的相关电子文件以及设计图纸的知识产权。保证在办公内外环境下，能够有效防止图纸文件被非法篡改、拷贝或盗用，全方位守护图纸文件的安全。
