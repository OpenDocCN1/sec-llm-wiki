远程办公可能面临的风险


因新冠肺炎疫情开启了数字时代最大规模的一次远程办公试水，同时远程办公应用会带来一系列严重的安全问题，尤其是大量隐私和数据安全问题。如何保障远程办公的数据安全，是当今天国内、国际不可回避的问题。如何规避远程办公泄密问题？天锐绿盾从多角度多层面给出了远程办公数据安全解决方案。


 场景一：终端远程办公 


安全隐患

  1. 加密系统无法进行申请、审批；

  2. 离线时间到期后，文件无法打开；

  3. 办公电脑无监管，可能通过拍照途径泄密；

  4. 员工需要访问内部服务器，映射到公网，数据安全存在隐患。


天锐绿盾防护措施

  1. 将公司加密服务器映射到公网，让加密终端可以连接服务器；

  2. 将应用服务器映射到公网，让员工可以访问应用服务器；

  3. 架设应用服务器安全网关，对访问进行控制；

  4. 开启屏幕水印策略，对电脑屏幕进行保护。


场景二：远程桌面接入 


安全隐患

员工远程拷贝数据到私人电脑，对屏幕进行拍照、截屏泄密。


天锐绿盾防护措施

  1. 所有文件都处于加密状态，通过任何方式带离公司内部，文件都无法打开；

  2. 对拍照以及截屏行为进行警示，出现泄密事件时，可快速追溯事件源头；

  3. 详细记录远程操作当出现文件泄露或者故意删除时，可提供有力证据。


 场景三：VPN接入 


安全隐患

私人电脑拷贝公司内部共享数据，导致泄密，对网络以及终端行为无审计，远程办公效率无法得到保障。


天锐绿盾防护措施

  1. 客户电脑安装天锐绿盾才可以通过VPN接入公司内网；

  2. 安装天锐绿盾才可以访问内部应用服务器，下载文件自动加密；

  3. 接入内网后，所有文件操作以及U盘拷贝都有记录以及备份；

  4. 详细记录员工在远程办公期间的工作情况，了解员工办公效率；

  5. 人性化的工作模式切换，上班工作，下班娱乐两不误。


 场景四：搭建临时环境 


安全隐患

办公资料发给员工以后完全不受控，泄密风险极大。办公支持系统访问不受控，扩大了泄密风险。员工对涉密文件操作无记录。


天锐绿盾防护措施

  1. 搭建办公支持系统；

  2. 搭建绿盾服务器；

  3. 搭建应用服务器接入系统；

  4. 在家办公人员安装绿盾客户端；

  5. 办公所需资料经过加密后发送给员工；

  6. 开启工作模式切换。


 场景五：混合远程模式 


安全隐患

企业核心办公文档数据的存在泄密的风险，在没有行政监管下，截屏、拍照成了极大隐患，员工办公效率得不到保障。


天锐绿盾防护措施

  1. 安装天锐绿盾终端系统；

  2. 开启加密策略、屏幕水印、行为审计、工作模式切换；

  3. 应用服务器接入系统；

  4. 移动终端服务器。


 场景六：接入云桌面 


安全隐患

即时通讯工具、邮件泄密，员工屏幕拍照、截屏泄密以及操作及网络行为没有记录。


天锐绿盾防护措施

云桌面开启透明加解密、屏幕水印、操作审计、邮件记录、聊天工具记录等。
