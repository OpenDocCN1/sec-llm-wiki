# 天锐绿盾如何保障高新技术企业内部核心信息数据安全？

上海至纯科技，成立于2000年，是一家在上交所上市的高新技术企业，致力于为高端先进制造业企业提供高纯工艺系统的解决方案。

![](../Images/117f7c1bd7183084e82a41446379b2f1.png)

提供系统和专业服务，广泛应用于半导体、微电子、生物医药、光伏、光纤、TFT-LCD、LED等领域，系统解决方案涵盖整个系统的设计、选型、制造、安装、测试、调试和系统托管服务。  

  

**信息安全需求分析**

  

至纯科技企业业务涵盖微电子、生物医药、光伏等领域，而系统解决方案涵盖整个系统的设计、选型、制造等服务。

  

至纯科技是典型的知识技术密集型行业，具有科技含量高、专利多，知识产权丰富，核心数据密级高等特点，正因如此，保护企业内部的文件数据就变得尤为重要。

![](../Images/fa390eadf1ca1b3ef8352278732301c6.png)

数据安全是信息安全的核心，信息安全的目的就是保障企业长期经营、研发、生产、设计的数据成果，天锐绿盾围绕数据安全提供终端数据安全、服务器数据安全和介质数据安全的解决方案。  

  

**1\. **针对研发成果全面防泄密的情况，在不影响员工对电脑任何正常操作的前提下，数据在复制、新建、修改时被系统强制自动无感知加密。

  

**2\. **加密数据只能在至纯科技内部电脑上正常使用，未解密的情况下脱离企业内部的网络环境，在外部电脑上打开便会显示乱码或无法打开。

  

**3\. **勘测数据、设计方案的外带安全掌控基于单位员工要经常出差到现场办公的情况，天锐绿盾加密系统提供离线管理功能来保证员工出差时对加密文档的正常使用。

  

**天锐绿盾桌面管理系统**

  

桌面管理系统的定位就好比企事业单位的规章制度，严格规范员工们的日常操作行为，主要包括策略管理、资产管理、系统运维、任务推送。实施桌面管理系统，可以实现终端桌面的标准化管理，解决桌面安全管理问题，提升信息运行维护部门的工作效率，同时规范员工操作行为。

![](../Images/6358150b7104ccd5f6e540bf25108144.png)

  

**天锐绿盾移动终端防泄密**

  

天锐绿盾移动终端管理模块支持Android、IOS移动客户端，既能满足用户的移动办公需求，还能保障移动办公的安全性和高可靠性。  

![](../Images/27fcd0aa48b708c824488ef9452b3274.png)

  

**（1）高效移动办公**

在外出过程中，用户可随时随地调用在企业内部加密文件，实现随时随地的移动办公；

  

对于手机QQ、邮箱等通讯工具上接收的加密文件，可通过天锐绿盾移动终端app直接在线打开阅读；

  

支持通过Android、IOS移动客户端在线处理审批工作，且审批消息实时推送，保证审批及时性，还可以追溯审批历史记录。

![](../Images/2ae62e9760d3169f6e36db871ffb91a6.png)

  

**（2）安全移动办公**

安全身份认证，保证操作者的合法性；

  

用户还可设置定时无操作自动锁屏，保护移动端上的数据安全；

  

对Android移动终端上存储的重要文件，可保存到文件管理区，自动加密保护，且用户可直接在线阅读加密文件。

  

移动端支持文档密级、文档权限控制功能，对于下载下来的文档仍然保持原来的密级等权限控制状态，未授权用户无法正常读取。
