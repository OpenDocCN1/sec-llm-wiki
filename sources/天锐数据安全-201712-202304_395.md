# 2018天锐股份年终总结大会暨尾牙晚会

天锐股份2018年终总结大会暨2019新年尾牙晚会于2019年1月11日在厦门总部顺利召开。

![](../Images/902dcb34f82482ea221eeb508f297c57.png)

伴随着每一位小伙伴迎新年的喜悦之情，天锐股份全体成员欢聚一堂，满怀激情的迎接新年到来。新年新启程，领导提纲挈领的致词，十年风雨共同舟的老员工贺词，激动人心的优秀员工表彰，精彩纷呈的歌舞表演，卯足干劲，让我们共同以新的起点迎接2019年！天锐股份注定要开启一场不同凡响的年会盛宴！  

  

在天锐股份2018年终总结大会中，各体系领导纷纷致词，总结了这一年中的不足与进步，促使产品持续创新，提升服务质量，为信息安全领域创造出更大的贡献。  

![](../Images/06f138b209c30578b2134cc163524d23.png)![](../Images/29e02e870d21447e2d6700a28ab70ac3.png)

2018天锐股份业绩不断增长，市场领域不断拓展，行业影响力不断加深，与此同时，天锐也涌现出一批优秀的员工代表和部门楷模，他们在自己的工作岗位上勤勤恳恳，起到了标杆和榜样的作用。  

![](../Images/7013036b0a276e18003bcb13eb1a08d4.png)![](../Images/c20c718827fab957415cddab2fb320a2.png)

![](../Images/99eff8d0c681512730b8ad089f8f152c.png)![](../Images/a34729ebfcf9b18bfd3f846943b91104.png)

会议的最后，远在全国各地的各分部小伙伴纷纷送上新年祝福！

![](../Images/873e37905aeb971cbb18ea315cee3401.png)

  

![](../Images/9766a5b4be6e178dc8a6adcea82ddfa3.png)

  

新年新气象，总需要歌舞助兴。天锐股份今年的表演团队不仅颜值才艺都在线，服装道具百里挑一不含糊。十余年老员工同台倾情献唱《真心英雄》，节目另外还有歌舞、粤剧、二人转、小品、瑜伽等等，相信吃瓜群众都按耐不住了。

![](../Images/eab5193c8245351229995cdc3ef4d186.png)![](../Images/94d1c3dbf2baf010f3cfb27c12daa1c0.png)![](../Images/d76a4466d50145a68552f892fc30ed08.png)![](../Images/6cfcb704969ce6dcd3b44115e8012623.png)![](../Images/009134ca1505fbf120881b46991fc156.png)![](../Images/70d4a1a6b935c30d245fd67484d86813.png)![](../Images/00387a1249db3ffdf99debf9fde3dca6.png)

天锐股份在过去的一年中成绩斐然，这要感谢天锐股份大家庭中的每一位成员，我们共同努力创造了今天的成绩，希望在今后的岁月里，我们能够更加紧密地携手走下去，创造更多的奇迹。

  

美好永不停转，新年的钟声即将敲响，感恩相遇、感恩有你，愿往后你的每一个5年、10年，天锐股份都不缺席。
