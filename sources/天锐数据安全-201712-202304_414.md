# 湖北某企业遭内部“卧底”窃取商业机密倒卖，经济损失超1400万！

**商业机密泄露**

![](../Images/ff7d6be4606544832300c952e081f2ce.png)

为了窃取化工领域ADMP核心生产技术，他隐瞒总工程师的职务，伪造身份证件“卧底”打工。

**他用窃取的技术生产出相同的产品，3年时间卖了1500万余元。****经司法鉴定，给相关企业造成经济损失1400余万元****。**

  

11月14日，湖北日报全媒记者从荆州开发区公安分局获悉，历经重重挑战，该局破获这起化工领域重大侵犯商业秘密案。

  

**曝光：“创新明星”卧底身份**

“张金阳（化名）所引领的技术团队，不断创新研究，生产的……”电视中，正在播出孝感企业湖北某诚化工科技有限公司（后简称某诚化工）创新人物展的相关节目。电视这头，湖北某达科技发展有限公司（后简称某达科技）相关负责人定了定神，画面中出现的张金阳，怎么越看越眼熟。

  

该负责人到公司人事部门查询相关档案，发现在2011年2月，有一个名为章晶扬的男子到该公司应聘，由于表现突出被任命为ADMP车间副主任。然而，章晶扬仅工作了3个月便莫名离职。这个章晶扬与张金阳，名字同音但不同字，通过照片比对，确定就是同一人。

  

与此同时，某达科技通过市场调查发现，张金阳早在2009年就担任某诚化工副总经理、总工程师。某诚化工所推广的ADMP产品，与某达科技所生产的产品相同。

  

ADMP是国际大型化工企业开发绿色、超高效黄酰脲类除草剂关键中间体。某达科技通过自主研发，国内率先实现以某物质为原料生产ADMP，成本相对于老工艺降低20%以上，在市场竞争中存在显著优势，该项目获国家科技部“十二五”科技支撑计划支持。

  

如此多的吻合，某达科技有理由相信这绝不是偶然，张金阳在汇达化工工作期间，实际接触并熟练掌握该公司ADMP生产工艺技术，有盗取核心技术的重大嫌疑。某达科技迅速到荆州开发区公安分局经侦大队报案。2017年4月14日，该大队迅速成立专班立案侦查。

  

**破冰：案件攻坚挑战重重**

专班民警调查发现，张金阳在某达科技应聘时，所提供的“章晶扬”身份证和学历证，全都是伪造的。

  

由于该案属于侵犯商业秘密犯罪，案件认定较为复杂，技术鉴定更为关键。警方委托第三方权威机构，并从北京邀请知识产权化工领域的技术专家参与鉴定。经对两家公司ADMP产品生产技术信息进行鉴定，存在多处同一性。

  

别看只是几处同一性，这可是鉴定团队和民警们，历时近一年的奋战成果，困难程度可想而知。游离氯、AP、水解、缩合……这些陌生的专业名词，曾一度让专班民警犯难。为利于案件侦查的深入开展，该大队二中队中队长李军，在网上购买了大量书籍自学，并多次到某达科技找工人请教，熟悉设备一览表、操作流程、操作术语等知识，为以后的审讯工作“充电”。

2018年5月，专班民警决定对张金阳进行收网。

  

张金阳住在孝感应城，反侦查意识极强，不定期更换住址，上下班都开着不同的车辆。白天基本都在公司不出来，偶尔会到距离5公里外的新厂房。李军介绍，这5公里当中，只有中间的几百米，居住的居民和过往的车辆较少，是抓捕张金阳的“黄金地段”。

  

3名民警和4名辅警分成两组，守在这条5公里的道路两头，这一守就是4天。终于在5月9日晚6时许，一辆黑色小车驶出某诚化工，向新厂房方向驶去，张金阳坐在后排。民警驾车尾随其后等待时机，但没走多远，黑色小车发现跟踪，猛然加速向前逃离。

  

“我们是警察，前方车辆请靠边停车！”民警迅速喊话，要求黑色小车配合调查，但该车并未减速。在该车驶入“黄金地段”后，位于前方的李军驾车将黑色小车拦停。李军出示证件要求配合，不料张金阳弃车而逃，李军和同事追了几百米后，将张金阳成功抓获。

![](../Images/240f2b34c0ec5d0e7ab6d435c874188b.png)

**智斗：逐一击破三大谎言**  

张金阳落网后，对自己窃取商业秘密的行为矢口否认，连续编造了3个谎言，企图误导民警侦查方向。“这些技术都是我自主研发的”，张金阳通过口述一连串的专业术语，来讲解自己的研发过程，但没想到李军早有准备，同样运用专业术语来一一回击，张金阳顿时傻了眼。李军还让张金阳提供所有的研发资料和参与人员名单，这让张金阳开始有些手足无措。

  

“我和某高校共同研发的”，张金阳迅速转移方向。民警通过对该高校进行走访调查，发现其与张金阳在ADMP产品中确实有过研发合作，但仍处于实验阶段，还未进行到工业化生产阶段。

  

第二个谎言被揭穿，张金阳又说，“这是某达科技一名离职员工提供的技术。”民警调查，张金阳确实与该员工有过接触，但张金阳无法提供直接证据证明。

  

接二连三的败北，张金阳终于低头，承认虚构身份证、学历证书并隐瞒职务身份，以窃取等不正当手段获取某达科技生产技术工艺秘密，用于某诚化工生产相同侵权产品的犯罪事实。从2012年至2015年，某诚化工销售该产品收入达1500万余元。

  

目前，张金阳以涉嫌侵犯商业秘密罪，被依法批准逮捕。

**商业秘密，究竟该亡羊补牢，还是防患未然？**

  
商业秘密一旦泄露，企业必将受到重大损失，即便通过维权使窃密者受到惩罚，但秘密已经被公开，如果被竞争对手所利用，后续将会带来不可估量的损失。从上述新闻来看，很明显窃密者已经把某达科技的核心技术机密高价卖给了竞争对手。

  
虽说在保护商业秘密方面，亡羊补牢为时不晚，但是未雨绸缪、防患未然才是上策，像公众熟知的“可口可乐”就是一个很成功的例子。该饮料的核心配方至今已保密120年，它是一个绝对的秘密，全世界知此配方者屈指可数。只有全面注重商业秘密的法规制度、监督机制、措施手段，才能更有效的保护好企业的商业秘密。

那么，既然人为保护安全系数不高，就得采取必要的终端加密软件措施来保障企业内部核心商业机密。

天锐股份经过多年的研发积淀和市场积累，形成自身全面又极具竞争优势的天锐绿盾加密软件产品体系。天锐股份以数据安全为核心，自主可控的国密算法应用技术为基础，研发的天锐绿盾品牌系列涵盖了**网络安全、终端安全、数据安全、文档安全**等全方位信息安全产品及解决方案。

因此，为保障企业信息数据安全，天锐股份依靠数十年经验研发天锐绿盾四大安全体系，只为有效的防护企业核心数据安全。
