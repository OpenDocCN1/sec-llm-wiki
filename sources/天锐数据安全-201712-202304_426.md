# 用户数据泄露约50万，Google宣布关闭个人版Google+

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTk0MzIzMQ==&mid=2652008975&idx=1&sn=374026c677e3ad8c57e0773d737e1692&chksm=bd4b0d5f8a3c8449be5b0f2b6bde8ec29c0e53f3ab7e4440d5df4b704d695c7f7340ff8624a6&scene=126&sessionid=1681270276#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTk0MzIzMQ==&mid=2652008975&idx=1&sn=374026c677e3ad8c57e0773d737e1692&chksm=bd4b0d5f8a3c8449be5b0f2b6bde8ec29c0e53f3ab7e4440d5df4b704d695c7f7340ff8624a6&scene=126&sessionid=1681270276#rd)

**Google 今天通过官方博客宣布，将在未来 10 个月内关闭社交平台 Google+ 的消费者版本。这一决定是在披露了之前未公开的安全漏洞后发布的，该漏洞暴露了最多 50 万名用户的个人资料数据，并在 2018 年 3 月得到了补救。**

  

Google 称，目前 Google+ 的“使用率和参与度都很低”，90％ 的 Google+ 用户会话持续时间不到 5 秒。尽管如此，该公司仍计划为企业客户提供服务。Google 表示，将针对企业版推出新功能。

  

除了个人版 Google+ 的陨落之外，该公司还宣布对其他 Google 服务进行新的隐私策略调整。 API 的更改将限制开发人员访问 Android 设备和 Gmail 上的数据。开发者将不再接收 Android 设备上的通话记录和短信权限，并且无法通过 Android 通讯录 API 获取联系人互动数据。

  

Gmail 方面，Google 正在更新其针对个人版电子邮件服务的用户数据策略，变更后将限制应用程序及其访问用户数据的范围。Google 研究员兼工程副总裁 Ben Smith 写道：“只有那些直接增强电子邮件功能的应用——如电子邮件客户端、电子邮件备份服务和生产力服务（比如 CRM 和邮件合并服务）——才有权限访问这些数据。”

  

而拥有上述访问权限的任何开发者都必须接受安全评估并同意有关数据处理的新规则，例如不转移或销售用于定位广告、市场调查、电子邮件广告跟踪或其他无关目的的用户数据。

![](../Images/b3a31414c12235f62a3ac46db7d13cd6.png)

在华尔街日报详细介绍了第三方应用程序开发者能够读取和分析用户 Gmail 邮件的情况后，Google 此前曾试图在今年早些时候平息相关的隐私问题。当时，该公司的 Google Cloud 安全、信任和文件加密隐私部门主管Suzanne Frey 强调，用户应该查看哪些应用可以访问其帐户，并在必要时撤消应用的访问权限。去年，Google 宣布将停止长期的为了广告目的而扫描个别 Gmail 用户内容的做法。当然，该公司仍然拥有大量可以定位广告的数据，例如搜索记录、YouTube 浏览记录和其他 Chrome 动作。  

  

Google 表示，这些新变动归功于 Google 内部的一项名为 Project Strobe 的项目，其中包括审核“第三方开发者访问 Google 帐户和 Android 设备数据以及我们围绕应用程序数据访问的理念”。

从上述新闻得知，Google宣布，将在未来 10 个月内关闭社交平台 Google+ 的消费者版本。这一决定是在之前未公开的安全漏洞后发布的，是因为该漏洞暴露了最多 50 万名用户的个人资料数据并在 2018 年 3 月得到了补救。所以，企业安装数据加密软件，则可防患于未然。

![](../Images/51d49d68cad0196d98e9fba962786e91.png)

天锐绿盾的整体解决方案首先是运用数据防泄密系统对数据本身进行文件加密，从源头上保障数据安全，然后运用桌面安全管理系统对终端进行规范化管理，对事中进行管控。最后运用行为审计系统对各种操作信息做记录，从而让管理者在事后有据可查。  

  

所谓探本朔源，抓住事物的源头，做的事情也会事半功倍，天锐绿盾很好的从源头出发，在重要文档生成的时候就自动透明加密，而透明加密，就是在不影响员工原始的文档操作习惯下文件加密，员工仍保持原来的操作习惯，不用因为加密而做改变。当然，文件一旦离开了使用环境，将无法打开，也就非常有效的扼止了文件外泄后的数据泄密了。

  

桌面安全管理系统则是对各个电脑终端进行规范化的管理，从而来达到事中行为的管控。通过对终端规定使用允许范围内的程序、网站，对一些违规行为及时的制止来减少终端在使用时信息数据的泄密。

  

世界上没有完美无缺的东西，在数据安全隐患让人应接不暇的情况下，拥有天锐绿盾行为审计系统，在可能发生信息泄密的情况下，及时发出警报，让管理人员有所察觉，同时给予信息安全泄密一个有迹可循的途径，让管理人员更加放心。

  

现今时代，网络信息更新迭代的很快，信息安全泄露隐患也越来越多，天锐绿盾会在信息安全防护的道路上坚定的往前走，技术在更新，我们在努力，为客户的信息安全做最有力的防护。
