## 一、前言

编写XSS漏洞测试脚本的最主要思路是，如何检测页面的弹窗呢？方法是多种多样的，本文利用的是selenium模块来检测页面是否有弹窗，从而判断页面是否存在XSS漏洞。

## 二、知识点

1.  selenium模块的使用
    
2.  XSS漏洞原理和攻击方法
    
3.  pikachu靶场
    

## 三、源代码

### 方法1

直接在url上面注入测试脚本（该脚本开启了无界面访问）：

```


from selenium import webdriver
```

### 方法2

直接在页面进行定位注入（该脚本开启了无界面访问）：

```


from selenium import webdriver
```
