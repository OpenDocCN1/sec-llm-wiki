*

```
# pip install opencv-pythonimport cv2
img = cv2.imread('img.jpg')grayimg = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)grayimg  = cv2.medianBlur(grayimg, 5)
edges = cv2.Laplacian(grayimg , cv2.CV_8U, ksize=5)r,mask =cv2.threshold(edges,100,255,cv2.THRESH_BINARY_INV)img2 = cv2.bitwise_and(img, img, mask=mask)img2 = cv2.medianBlur(img2, 5)
cv2.imwrite("cartooned.jpg", mask)
```

**12\. 转换：十六进制到 RGB**

该脚本将简单地将 Hex 转换为 RGB。查看下面的示例代码。

*   
*   
*   
*   
*   
*   

```
# Conversion: Hex to RGBdef Hex_to_Rgb(hex):    h = hex.lstrip('#')    return tuple(int(h[i:i+2], 16) for i in (0, 2, 4))print(Hex_to_Rgb('#c96d9d'))  # (201, 109, 157)print(Hex_to_Rgb('#fa0515')) # (250, 5, 21)
```
