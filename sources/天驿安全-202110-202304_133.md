# 一款开源的数据库在线预览、导出工具

database-export是一款多线程生成数据库结构文档的开源springboot工程，能支持最新的数据库版本，可以导出docx格式和xlsx的文档，也能直接在网页上预览  

  

## 项目使用技术

*   JDK1.8
*   VUE2.0
*   Element-UI
*   Axios
*   Thymeleaf
*   Spring Boot
*   Maven
*   POI-TL

## 项目特点

*   导出sql支持多线程查询，导出速度更快
    
*   使用element-ui，界面更美观
    
*   支持导出word和excel，更支持网页预览
    
*   支持MySQL8.0版本、Oracle 11g、sqlserver以及Postgresql
    
*   导出速度高于现在的所有导出工具
