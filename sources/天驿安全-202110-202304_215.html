Zinc，一款Go语言开发的搜索引擎，可用于替代 elasticsearch，在 GitHub 开源不到一个月，已收获 4.3k Star。

提供了全文索引、单个二进制文件安装和运行、开箱即用的身份验证等功能，兼容 Elasticsearch API，自带可用于查询数据的 Web UI。

GitHub：github.com/prabhatsharma/zinc
