SQL审核的开源神器Yearning

该工具致力于帮助开发者快速完成 SQL 语句的审核、检测、执行、回滚等操作，使日常的 SQL 变动得以更加规范化、标准化。此外，该工具还支持对不同操作人员进行权限划分，独立搭配任务。

网站的整体操作体验也非常舒适，前端基于 Vue.js 构建，另提供 SQL 语法高亮、智能补全、可视化等基础功能。

总而言之，这款工具可谓极大解放了 DBA 人员的生产力，免去了很多繁琐的人工审核流程，让他们可以更加专注于产品业务的细节实现。

现在，Yearning 已基于 AGPL-3.0 协议将源码开放到了 GitHub 上，觉得好用的同学，可以用平台上的赞赏功能请作者喝杯咖啡。

"自从我用了 Yearning 之后，老板再也不用担心我删库跑路了"
