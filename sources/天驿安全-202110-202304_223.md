# wLogger，一款Web日志管理工具

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxNjIxNDQyMQ==&mid=2247491101&idx=1&sn=a55f7d5ee6efe26bcf211ea339bf3a2f&chksm=c15219e7f62590f14c61e2bdf15bc177a5f107c085d57fb92eda88eed813ba6d24cf25b8b1e7&scene=126&sessionid=1681667090#rd](http://mp.weixin.qq.com/s?__biz=MzkxNjIxNDQyMQ==&mid=2247491101&idx=1&sn=a55f7d5ee6efe26bcf211ea339bf3a2f&chksm=c15219e7f62590f14c61e2bdf15bc177a5f107c085d57fb92eda88eed813ba6d24cf25b8b1e7&scene=126&sessionid=1681667090#rd)

wLogger，一款集日志采集、日志解析持久化存储、Web 流量实时监控，三位一体的 Web 服务流量监控应用。

  

三大功能模块均可独立部署启用互不干扰，目前已内置 nginx 和 apache 的日志解析存储器，简单配置一下，开箱即用。

  

GitHub：github.com/jyolo/wLogger
