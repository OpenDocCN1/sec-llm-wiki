EDRHunt 扫描 Windows 服务、驱动程序、进程、注册表以查找已安装的 EDR（端点检测和响应）。  

  

![](../Images/b2f98668cba5970fdff7b0dd30c7dbb9.png)

## 安装

*   从发布部分下载最新版本。发行版是为 windows/amd64 构建的。
    

*   GO安装
    

*   需要在系统上安装 Go1.17+ 。
    
*   `go install github.com/FourCoreLabs/EDRHunt/cmd/EDRHunt@master`
