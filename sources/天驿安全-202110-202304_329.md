# 一种新型钓鱼攻击技术出现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxNjIxNDQyMQ==&mid=2247489107&idx=1&sn=5fc361f57fe99ab6adc779a34c44d070&chksm=c15211a9f62598bf4f8d026c01d11d1299bea6ac00b806948732e938cf6e0c90fbf3782d3acd&scene=126&sessionid=1681667140#rd](http://mp.weixin.qq.com/s?__biz=MzkxNjIxNDQyMQ==&mid=2247489107&idx=1&sn=5fc361f57fe99ab6adc779a34c44d070&chksm=c15211a9f62598bf4f8d026c01d11d1299bea6ac00b806948732e938cf6e0c90fbf3782d3acd&scene=126&sessionid=1681667140#rd)

对于安全人员来说，URL是域名可信度评估的最重要方式。IDN Homograph和DNS劫持等攻击会使得URL可信度降低。近日，研究人员发现一种模拟浏览器窗口进行欺骗的新型钓鱼攻击方式。

  

![](../Images/97e19423e94f18193826bffc3c80daee.png)

  

**弹窗登录窗口**

  

在用谷歌、微软、苹果等服务登入网站时，都会提供一个进行认证的弹窗。下图是用尝试用谷歌账户登入Canva时的弹窗：

  

![](../Images/028396a0bc3a59aff51dd7d7f6432e86.png)

  

使用谷歌账户登入Canva

  

**复制窗口**

  

使用基本的HTML/CSS来复制整个窗口的设计非常简单。将窗口设计和指向保存有钓鱼页面的恶意服务器的iframe融合后基本上是不可区分的。下图就是真实窗口和伪造的恶意窗口的对比，基本上无法区分这两个窗口：

  

![](../Images/6419eebaee651fb7d011f1dbdf30271a.png)

  

**定制的URL模板**

  

```
< a href="  >Google< /a >
```

在启动了JS的页面上，如果加入onclick event返回错误，那么在链接上划过仍然会显示href 属性中的网站，但点击后链接的href 属性会被忽略。因此，可以使用该技术让弹窗变得更加可信： 

```


< a href="https://gmail.com" onclick="return launchWindow();" >Google< /a >
```

研究人员分别创建了Windows和Mac OSX系统Chrome浏览器的模板，参见Github：https://github.com/mrd0x/BITB
