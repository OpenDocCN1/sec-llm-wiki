### 前言

闲着金币在edusrc里面，刚好某学校上架了新礼物，就有了这次的渗透,此文章中所有漏洞均已提交至edusrc并已经修复。

### 0x1信息泄露

在url后面随便输入字符,页面报错得到框架为ThinkPHP3

![](../Images/afff794319fccb759bb515f327a1fd92.png)

  

然后我们尝试访问默认日志路径

```
Application/Runtime/Logs/控制器/年份_月份_日期.log
```

访问成功,不过每隔几分钟日志就会被自动删除

![](../Images/523b7286ce16690aeabadc4d27bbda1c.png)

  

### 0x2由日志泄露导致的任意用户注册

用户注册的地方,一定要使用该校的邮箱@xxxxxxxxx.edu.cn进行注册

![](../Images/99d701dab951c9200685bf1fa02ccadb.png)

  

我们通过GitHub搜索 该校域名+邮箱关键字，成功找到一个可以登入的邮箱

  

![](../Images/f872964dd506339280c2de2a43dfba53.png)

  

然后登入

  

![](../Images/2f0fff8a4f98f0f40963b9d56f63ef0d.png)

  

利用得到的邮箱进行注册，查看激活邮件URL构造

```
http://xxxxxxxxx.edu.cn/index.php/activation?accessToken=f6d785fb9470d5fd604fb8897778f740
```

![](../Images/06e9ce991d75fa65bd972de2e125e52f.png)

  

accessToken我们可以通过日志去查看,然后即可构造激活链接实现任意用户注册

edusrclalala@xxxxxxxx.edu.cn

![](../Images/ee41c5861b074ebe3b7d322ceb98209f.png)

  

查看日志得到accessToken

  

![](../Images/0bd7b1939afa0a5dc48fc5124d107278.png)

  

构造激活链接，访问成功激活

  

![](../Images/fe06103bdf6e1b57696313bb78635354.png)

  

### 0x3sql注入

问题出现在验证手机号处

  

![](../Images/d562c6a2fc5cfe757a19f16f11aa53de.png)

  

此处后端调用的阿里云发送短信,当发送次数过多后会触发号码天级流控,后端记录日志处xff未过滤导致的注入

  

![](../Images/16ef54a97d03fc6f3782cf23643b1532.png)

  

天级流控说明 https://developer.aliyun.com/ask/137083

  

![](../Images/2039fe47067437beedbc584996e7da32.png)
