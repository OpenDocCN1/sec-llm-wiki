# Sqlite可视化工具推荐(附简单使用方法)

1、sqlite database browser功能较少，简单易用。常用功能：编辑表、编辑列（field）、编辑行（record）、编辑单元格，创建列时，可是设置列类型为主键自增另外，还可以在软件内执行SQL语句。

2、SQLiteExpert个人版：SQLiteExpertPers

  

专业版是收费的，个人版是免费的0、使用过程中发现个问题，某些表的某些列显示不出来，用的不爽。特色功能：1、修改列的顺序，进入design选项卡->columns，点击move up/down即可

![](../Images/8ec5b13e63d950583de63d7d25ff0852.png)

  

2、支持从EXCEL粘贴数据直接在excel中复制矩形区域，进入data选项卡，右击选择粘贴，会弹出对话框，然后手动选择excel的某一列应粘贴到数据库表的哪一列。

![](../Images/defee2f13d7eeac7fdf965f2b5633655.png)

  

3、SQLiteStudio

  

特色功能：1、支持直接粘贴EXCEL的数据，进入数据选项卡，点击+\*插入指定数目的空行，然后就能右键粘贴excel数据了，缺点：不能一次行粘贴太多行，太多的话它会提示数据过多，禁止粘贴。2、支持csv格式的表格导入导出，excel文件可以另存为csv格式后，导入进去

![](../Images/71ffaf3a977bf34bab571b470210ebc6.png)
