二、实施步骤  
  

1.Hacker 克隆钓鱼网站，以 139 邮箱登录网站为例：http://mail.10086.cn，在用户 A 上进行测试目标网站是否克隆成功，查看 hacker 和用户 A 的 IP 配置。

（2）Hacker（kali）的 IP 配置

  

![](../Images/91d861cfdb9a38408b9a8f0e2a072628.png)

  

2.在 KALI 终端 输入 setoolkit 打开 kali 自带的社会工程学工具集

  

![](../Images/8e1d64fee66b4de0c04a648c511bab90.png)

  

3\. 输入 1，选择社会工程攻击

  

![](../Images/12b80b688f35f0bf53cd7b1af05c6953.png)

  

4\. 输入 2，选择网站攻击

  

![](../Images/c1a0ab454344f78402e34d6ae7ba143e.png)

  

5\. 输入 3

  

![](../Images/4180bf82bddf22c9703bc4872db233bb.png)

  

6\. 输入 2，克隆网站和域名

  

![](../Images/68bf35cb000a13ee1b8d55fc030e8d43.png)

  

7\. 在 kali 的浏览器上用 IP 登录克隆的网站,表示克隆成功

  

![](../Images/8e93f66846ea7b4d99a3d444db640b06.png)

  

8\. 开启 kali 的数据包转发功能

  

![](../Images/8688ee0c78117e2cbbda6d421308629f.png)

  

9．启动 ettercap

  

![](../Images/9d30d045ba3214a3010d52653f1dc3aa.png)

  

10．编辑 Ettercap 的文件(vim /etc/ettercap/etter.dns)，

  

使得用户 A 访问 http://mail.10086.cn 时，域名解析为 Hacker 的 IP

  

![](../Images/eafae4a7a5c9633cf4893f404bd151d1.png)

  

11．我们使用抓包的方式实现中间人攻击。

  

选择 sniff|unified sniffing|选择嗅探网卡，默认 eth0，点击确定，见下图：

  

![](../Images/bf69c41c8b04666d576bfd17d21e743f.png)

  

12．启动接口之后，菜单栏选择 hosts | scan for hosts，就可以  
扫描所有主机了。见下图：

  

![](../Images/7f2948658c24e73a2c0383d91a8469ae.png)

  

13.选择 Hosts| host list，查看扫描到的主机信息。

  

该界面显示了用户 A 的 IP 和 MAC 地址。

  

见下图：

  

![](../Images/0417e81adf7a9f84e7cdaabeba0d11c4.png)

  

14．从中选择 192.168.100.129 作为目标机，单击“Add Target 1”按钮

  

![](../Images/4ab914e041bb66bc3ee7f7f3226fe386.png)

  

15．启动 ARP 欺骗攻击，在菜单栏中依次选择 Mitm|Arp poisoning..，然后出现弹出框选择攻击的选项，我们使用“Sniffer remote connections”，然后点击“确定”按钮。

  

![](../Images/4dad1dc94bc05ef91f9012da691f5224.png)

  

16．在 windows server 2003 上访问 mail.10086.cn，并查看 arp 缓存表

  

![](../Images/3b750fe2947e47d5cbd88bd6ab347124.png)

  

![](../Images/de4045cb72d72a7b20ea535e5626a6e2.png)

  

17．在菜单栏中依次选择 Plugins|Manage the Plugins, 双击启用DNS\_Spoof（DNS 欺骗）

  

![](../Images/af131b43e431fa6a41b5347d90970b63.png)

  

![](../Images/e2f03b6c9c1c43a650c57493d6921956.png)

  

18．在 windows server 2003 上访问 mail.10086.cn 时，现在已经解析为 hacker 主机的 IP

  

![](../Images/98c25914db6674aecb3083c5c778d121.png)

  

19．在 windows server 2003 用浏览器访问 mail.10086.cn，并输入用户名和密码登录 139 邮箱

  

![](../Images/ca8448cd1a2a4590e12f6aac1c4b4cb4.png)

  

20．在 kali 的 Ettercap 上可以截获到用户 A 输入的用户名和密码信息

  

![](../Images/c6230320003426e75de236b3615b0df0.png)

  

**注:**

**ettercap**是一个基于ARP地址欺骗方式的网络嗅探工具，主要适用于局域网。ettercap是一款现有流行的网络抓包软件，它利用计算机在局域网内进行通信的ARP协议的缺陷进行攻击，在目标与服务器之间充当中间人，嗅探两者之间的数据流量，从中窃取用户的数据资料。
