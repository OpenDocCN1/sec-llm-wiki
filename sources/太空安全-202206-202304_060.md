# 破解Starlink卫星终端只需25美元。2022年，八月，在拉斯维加斯召开的 Black Hat Security Conference 峰会上，比利时鲁汶大学(KU Leuven)的安全研究员Lennert Wouters现场演示成功破解了SpaceX的星链终端，获取了设备的ROOT权限，可在设备执行任意指令操作，成功破解了 SpaceX 的其中一个 Starlink 用户终端。

# 星链系统主要由空中卫星群、地面网关、用户终端三部分组成：  

  

![](../Images/0e8ed93b27ebfa38a31e2d992f074f38.png)

  

Wouters 在展示过程中，所使用的破解装置总成本仅为 25 美元，成功侵入 Starlink 的卫星天线终端并获得系统访问权限。破解硬件如图所示：

![](../Images/9a9454efee3b7afdad2e0c9df460dc17.png)

  

Wouters 写道：“我们的攻击可以让 Starlink 的用户终端无法使用，并允许我们任意执行代码”。  

  

![](../Images/426aa9d6654d941542975d762e4b45f5.png)

![](../Images/3a512b844423b1a0ddf62eb6e05088e9.png)

![](../Images/9d4fc33e06576aa44ee26db803544001.png)

  

在拉斯维加斯会议上展示他的发现之前，Wouter 曾警告 SpaceX 其用户终端的漏洞。Starlink 已经更新了系统，但研究人员回答说，避免此类攻击的唯一可靠方法是创建一个新版本的主芯片。
