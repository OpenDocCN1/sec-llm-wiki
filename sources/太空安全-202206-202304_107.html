1、TinyGS简介

TinyGS 是一个开放的地面站网络，分布在世界各地，使用廉价和多功能的模块接收和操作 LoRa 卫星、气象探测器和其他飞行物体。
TinyGS 最初以 ESP32 Fossa Groundstation 的名义诞生，它是作为 FossaSAT-1 LoRa 卫星的“周末”项目开发的。我们对太空充满热情，并创建了这个项目，以便能够跟踪和使用卫星以及学习和试验无线电。目前该网络对任何 LoRa 卫星开放，我们还支持与我们的硬件具有兼容无线电调制的其他飞行物体，例如 FSK、GFSK、MSK、GMSK、LoRa 和 OOK。并且该项目被重命名为 TinyGS。


2、TinyGS硬件

该项目基于 ESP32 板，目前兼容 sx126x 和 sx127x LoRa 模块，但我们计划在未来支持更多无线电模块。目前，我们正式支持以下经过验证的 LoRa 板：
Heltec WiFi LoRa 32 V1（433MHz 和 863-928MHz 版本）
Heltec WiFi LoRa 32 V2（433MHz 和 863-928MHz 版本）
TTGO LoRa32 V1 (433MHz & 868-915MHz 版本)
TTGO LoRa32 V2 (433MHz & 868-915MHz 版本)
TTGO LoRa32 V2（手动将SX1267换成SX1278）
T-BEAM + OLED（433MHz 和 868-915MHz 版本）
T-BEAM V1.0 + OLED
FOSSA 1W 地面站（433MHz 和 868-915MHz 版本）
ESP32 开发板 + SX126X 带晶体（定制构建，OLED 可选）
ESP32 开发板 + 带有 TCXO 的 SX126X（定制构建，OLED 可选）
ESP32 开发板 + SX127X（定制构建，OLED 可选）

但是，任何带有 sx126x 或 sx127x 模块的 ESP32 板都可以使用模板进行配置。

TinyGS 软件配置界面

TinyGS 固件提供了一个用于电路板配置的 Web 面板。这样可以轻松查看地面站的状态、更改任何参数，甚至远程上传新固件。它还确保在上传新固件版本后保留配置。

板子第一次启动时，它会生成一个名为：My TinyGS 的 AP。连接到该网络后，应使用 Web 面板提示您配置工作站的基本参数。如果不是这种情况，您可以使用网络浏览器访问网络面板并转到 url 192.168.4.1。

必须填写的参数如下：

  • 地面站名称：您的地面站的名称。您可以使用任何您想尝试选择唯一名称的名称。 GROUNDSTATION PASSWORD：这是您的地面站的密码，下次您通过 Web 面板连接到地面站时会要求您输入此密码。用户总是admin

  • SSID 和 PASSWORD：您家庭 WiFi AP 的配置参数，以便地面站可以连接互联网。

  • 时区：您的时区，这是为了向您显示您所在时区的时间信息。

  • LATITUDE 和 LONGITUDE：地面站的地理坐标。这有助于在您收到来自卫星的包裹时定位您的地面站。您可以在TinyGS.com 网站上查看所有电台。

  • MQTT_SERVER 和 MQTT_PORT：这些是项目 MQTT 服务器的地址和端口，如果您希望地面站能够连接主服务器，则不应更改它们。

  • MQTT_USER 和 MQTT_PASS：这些是项目 MQTT 服务器的凭据，目的是能够从卫星收集最多的数据包并管理来自该中央服务器的所有地面站。您可以在此 Telegram 组中询问用户和密码：https ://t.me/joinchat/DmYSElZahiJGwHX6jCzB3Q

  • BOARD TYPE：您正在使用的硬件板。固件能够自动检测您的电路板，但如果选择错误或您知道自己在做什么，您可以通过修改此参数手动更改它。

  • OLED Bright：控制 oled 的亮度，您可以根据自己的喜好对其进行配置。建议设置低于 100 的值以延长 OLED 的使用寿命。

  • Enable TX：此参数启用或禁用 TX 功能。在卫星使用的某些频率中，只有获得许可的无线电运营商才能传输。没有您的干预，电台永远不会传输，但如果您没有许可证，我们建议禁用此选项以避免错误触发 tx。

  • 自动调谐：（实验性）如果激活此选项，系统将尝试从卫星获取预测并自动设置无线电参数以最大化接收卫星的选项。

  • 遥测给第三方：一些卫星运营商，通常是大学，要求我们发送网络接收到的数据，以便他们有更多的数据来研究。如果您禁用此选项，则不会向第三方发送任何数据。

  • 测试模式：此选项将您的工作站设置为测试模式。所有的数据包都将被标记为测试。如果您要进行测试，例如重新传输旧数据包以使数据不计为实际数据，请使用此选项。

  • 自动固件更新：此选项启用或禁用自动固件更新。我们建议将其始终启用，以便您的主板始终接收最新更新。

  • 板模板：此字段提供了一种简单的方法来配置任何类型的具有自定义引脚的板。在此处了解有关板模板的更多信息。

  • 调制解调器启动：此选项包含板的初始无线电配置，这将由服务器更改，但在重新启动后保留配置并允许离线操作很有用。

  • 高级参数：此选项提供一组高级参数，主要用于开发和调试任务。

关于 LoRa的一些背景知识

LoRa（远程）是一种专有的低功耗广域网调制技术。[1]它基于源自啁啾扩频 (CSS) 技术的扩频调制技术。[2]由法国格勒诺布尔的Cycleo开发，被LoRa联盟创始成员Semtech收购并获得专利。[3]

LoRa 使用 433 MHz、868 MHz（欧洲）、915 MHz（澳大利亚和北美）、865 MHz 至 867 MHz（印度）和 923 MHz（亚洲）等免许可的亚千兆赫兹无线电频段。LoRa 能够以低功耗实现远距离传输。

从卫星发送和接收数据有什么特别之处？嗯，真的没什么。使用 TinyGS，更多的是关于所需的硬件和软件。它是现成的，只需少量预算（< 30 欧元），您已经拥有一个非常体面的系统并正在运行。

当然，卫星传输已经有几十年了。例如，使用 Iridium 网络，您可以发送和接收来自世界各地的消息。LoRa 的不同之处在于，Iridium 需要高成本的调制解调器（几百欧元），并且需要大量电力才能发送到卫星，而 LoRa 价格便宜，需要一小部分电力才能到达卫星。

这里最重要的部分是：LoRa 能够以低功耗实现远距离传输。这意味着它非常适合通常在电力和能源方面预算有限的卫星。

如果传输需要更多功率，则意味着它必须存储更多能量并拥有收集更多能量的太阳能电池板。但是，如果您的传输需要更少的能量，您可以更频繁地传输，或者有更低的能量预算，因此需要更少的存储和/或太阳能电池板......这将导致它的设备更小。这就是立方体卫星发挥作用的地方。

立方体卫星，什么？

Pa3weg at English Wikipedia, CC BY 3.0 , via Wikimedia Commons

立方体卫星本质上是尺寸为 10x10x10cm 的卫星。它们体积小，而且发射起来相当便宜。立方体卫星实际上有很多尺寸，比如 0.3U 即 10x10x3cm，甚至 6U 即 10x10x60cm。

这些卫星通常部署在近地轨道 (LEO) 中，这意味着它们部署在 2000 公里或以下的高度。这导致在 125 分钟或更短的时间内绕地球一圈。其中大部分在500公里左右，往返90分钟。这意味着卫星将像一天两次一样覆盖整个地球，因为地球在往返之间移动了一点。

由于在这些高度上的辐射远低于地球同步赤道轨道（GEO，GPS 卫星所在的轨道），因此立方体卫星可以配备现成的硬件，从而进一步降低这些卫星的成本。

地球同步赤道轨道意味着卫星距离地球赤道35.786公里，这导致从我们的角度来看，卫星在我们上方静止不动（它以与地球自转相同的速度移动）。

数百颗立方体卫星已经发射，未来几年还将发射数百或数千颗。

 

使用 TinyGS 平台从卫星（发送和）接收数据

TinyGS 最初于 2019 年 11 月以ESP32 Fossa Groundstation的名义诞生，它是作为FossaSAT-1 LoRa 卫星的“周末”项目而开发的。

 2021 年 2 月，该项目更名为 TinyGS，并在更名的同时发布了新的 beta 固件。目前该网络对任何 LoRa 卫星开放，并且还支持其他具有兼容无线电调制与支持的硬件的飞行物体，例如 FSK、GFSK、MSK、GMSK、LoRa 和 OOK。

基本上，该网络与接收来自卫星的消息的地面站一起运行。这些消息被推送到 MQTT 代理，并在那里存储和解码消息。作为附加功能，收到的消息也会发送到 Telegram 组。

地面站是非常低成本的常规 LoRa 设备，可从 AliExpress、Banggood 或其他（转）销商处购买。目前几乎所有带有 LoRa 模块的 ESP32 处理器都受支持。该设备可以使用 TinyGS 创建的特殊固件（一键安装）进行刷新，它需要一些配置，然后您就可以开始使用了。无需编程技能，只需点击即可。就这么简单。
