**特朗普竞选诉讼证据收集网站发生数据泄露** |
| :-: |

|      据悉，特朗普竞选团队不久前建立的DontTouchTheGreenButton.com网站发生了选民数据泄露，遭泄露的数据包括选民姓名、地址、唯一标识符等。该网站是特朗普竞选团队为从选民中收集诉讼证据而建立的，以支撑其上周在亚利桑那州提起的竞选诉讼。该诉讼要求，对亚利桑那州马里科帕县投票站选举日当天不正当拒绝部分选民投票的行为进行人工核查。有报道称，由于该网站在提起诉讼后迅速启动，未进行彻底的安全评估，从而存在大量数据泄漏和SQL注入漏洞。其中，该网站为限制其他人使用、保证仅让马里科帕县选民发声而设置的用于检索选民信息的API，导致了此次选民数据泄露。该API允许用户通过“搜索”姓名自动填充选民信息，黑客利用该API从服务器中批量获取到投票者数据，包含投票者姓名和地址列表，以及基于搜索查询的唯一标识符。目前，该API已从DontTouchTheGreenButton.com网站上移除。

**26项网络安全国家标准近期实施**

  

| 近日，26项网络安全相关的信息安全技术及安全技术标准正式实施，其中包括了等保2.0版《定级指南》、新的防火墙技术要求和测试评价方法、智慧城市建设信息安全保障指南、7项密码相关国家标准等。其中，《信息安全技术 防火墙安全技术要求和测试评价办法》将替代原有的防火墙国家标准、《信息安全技术 网络安全等级保护定级指南》将作为国家等级保护标准体系的核心标准之一。 |

**GitHub 源代码疑遭泄漏**

|   
TypeScript的开发者Resynth 在发布的一篇题为《GitHub 源代码泄漏》的文章中表示，GitHub.com 的所有源代码因不明原因被公开。对此，GitHub的CEO Nat Friedman在Hacker News上做出了回应。他表示，“GitHub 并未被黑，几个月前，我们不慎将未脱敏/混淆的 GitHub Enterprise Server 源代码发给了一些客户，它和github.com共享了代码。”不过，也有人指出，由于 GitHub是闭源的，因此这起事件仍然可定性为“泄漏“。 |

**巴西高等司法法院因遭重大网络攻击停业一周**

  

| 据外媒报道，巴西高等司法法院(STJ)由于遭遇重大网络攻击，未来一周其业务将无法正常运转。STJ称，攻击事件是在11月3日被发现的，当时有几个审判庭正在进行审判。相关人员在法院的网络中发现了一种病毒，作为应对措施，法院迅速切断了与互联网的链接，正在审判中的会议不得不取消。目前，法院所有网络系统都因此无法使用。在STJ的要求下，联邦警方已经展开调查。 |
