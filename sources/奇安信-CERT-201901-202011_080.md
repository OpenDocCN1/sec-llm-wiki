美国时间7月22日，思科官网发布安全公告，公开了Cisco Adaptive Security Appliance (ASA) 防火墙设备以及Cisco Firepower Threat Defense (FTD)设备Web服务接口存在未授权的目录穿越漏洞和远程有限任意文件读取漏洞。未经身份验证的攻击者可通过向目标设备的Web服务接口发送特制请求包读取Web目录下的文件。经研判，该漏洞无需交互、不需要身份认证且Web目录下存在较多敏感信息，目前，该漏洞细节已公开。鉴于该漏洞影响较大，建议客户尽快安装软件更新。

奇安信 CERT  

  

**漏洞描述**

  

思科自适应安全设备（ASA）软件是思科ASA系列的核心操作系统。它为各种分布式网络环境的ASA设备提供了企业级防火墙功能。据思科官网统计，在全球范围内部署了超过100万个思科ASA设备。Cisco Firepower Threat Defense (FTD)是将CISCO ASA和FirePOWER功能组合到一个包含硬件和软件的系统中的集成软件映像。

  

美国时间7月22日，思科官网发布安全公告，公开了Cisco Adaptive Security Appliance (ASA) 防火墙设备以及Cisco Firepower Threat Defense (FTD)设备的Web服务接口存在未授权的目录穿越漏洞和远程有限任意文件读取漏洞。未经身份验证的攻击者可通过向目标设备的Web服务器发送特制请求包读取Web目录下的文件。成功利用该漏洞的攻击者可以查看WebVpn配置信息、书签、Web Cookies、部分Web内容、HTTP URLs等敏感信息。不过攻击者只能查看Web目录下的文件，无法通过该漏洞访问Web目录之外的文件。

  

如下图，奇安信CERT安全研究员已于第一时间复现此漏洞。经研判，该漏洞无需交互、不需要身份认证。目前，该漏洞细节已公开。鉴于该漏洞影响较大，建议客户尽快安装软件更新。

**产品线解决方案**  

**奇安信网神网络数据传感器系统产品检测方案**

奇安信网神网络数据传感器（NDS3000/5000/7000/9000系列和vNDS1000/2000/3000系列）产品，已具备该漏洞的检测能力。规则ID为：5737，建议用户尽快升级检测规则库至2007231550以上版本并启用该检测规则。

  

**奇安信网站应用安全云防护系统已更新防护特征库**

奇安信网神网站应用安全云防护系统已全局更新所有云端防护节点的防护规则，支持对 CISCO ASA远程任意文件读取漏洞的防护。

  

**奇安信天眼产品解决方案**

奇安信天眼新一代安全感知系统在第一时间加入了该漏洞的检测规则，请将规则包升级到3.0.0723. 12130及以上版本。规则名称：CISCO ASA远程任意文件读取(CVE-2020-3452)，规则ID：0x1002098F。奇安信天眼流量探针（传感器）升级方法：系统配置->设备升级->规则升级，选择“网络升级”或“本地升级”。

  

**奇安信网神天堤防火墙产品防护方案**

奇安信新一代智慧防火墙（NSG3000/5000/7000/9000系列）和下一代极速防火墙（NSG3500/5500/7500/9500系列）产品系列，已通过更新IPS特征库完成了对该漏洞的防护。建议用户尽快将IPS特征库升级至 “2007231400” 及以上版本并启用规则ID:1132501进行检测。
