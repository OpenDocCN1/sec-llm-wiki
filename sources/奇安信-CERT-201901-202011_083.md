# 【补丁库更新】奇安信集团2020年07月补丁库更新通告第一次更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5NDgxODU1MQ==&mid=2247488047&idx=1&sn=fa7750293c7772bf1344779727155707&chksm=fe7a36b7c90dbfa100ecf3b364ec5b4b7018d25919704fa3a3c2dd68f99998e91fc13d70cb2d&scene=126&sessionid=1681373241#rd](http://mp.weixin.qq.com/s?__biz=MzU5NDgxODU1MQ==&mid=2247488047&idx=1&sn=fa7750293c7772bf1344779727155707&chksm=fe7a36b7c90dbfa100ecf3b364ec5b4b7018d25919704fa3a3c2dd68f99998e91fc13d70cb2d&scene=126&sessionid=1681373241#rd)

![](../Images/f0a3953f25d645bd69cb7009fb737ddb.png)  

奇安信集团最新补丁库2020.07.15.1已发布，本次更新推送了46个微软安全补丁，修复了206个安全漏洞，其中21个微软官方评级为“严重”，183个评级为“重要”，1个评级为“中”，1个评级为“低”，这些漏洞影响产品Windows、Internet Explorer、.NET Framework和Microsoft Office。同时推送了5个非安全Office补丁。

  

其中包括一枚Windows DNS Server远程代码执行漏洞（CVE-2020-1350）。未经身份验证的攻击者可通过向目标DNS服务器发送特制数据包从而目标系统上以本地SYSTEM账户权限执行任意代码。微软将该漏洞标记为“Exploitation More Likely”，并认为该漏洞可引发蠕虫式传播。经研判，该漏洞无需交互、不需要身份认证且Windows DNS Server默认配置可触发， 目前，该漏洞细节已公开 。鉴于该漏洞影响较大，建议客户尽快安装更新补丁。

  

2019年4月10日发布的天擎6.6.0.2000及以上版本支持Windows 10安全更新补丁管理，如需此功能请更新版本。
