**漏洞描述**

  

近日，奇安信CERT监测到F5 BIG-IP TMUI 远程代码执行漏洞（CVE-2020-5902），经过了解，F5 BIG-IP是美国F5公司的一款集成网络流量管理，应用程序安全管理，负载均衡等功能的应用交付平台。2020年7月1日，F5公司公布其流量管理用户界面（TMUI）存在未授权远程代码执行漏洞。

  

成功利用此漏洞的攻击者，通过构造请求，在未授权的情况下获得目标服务器的权限，实现远程代码执行，目前该漏洞PoC已泄漏。鉴于该漏洞影响较大，建议客户尽快自查修复。

**处置建议**

  

请参考以下链接升级产品以修复此安全问题

https://support.f5.com/csp/article/K52145254

  

或采取缓解措施：

1.通过输入以下命令登录到TMOS shell

tmsh

2.通过输入以下命令编辑httpd属性

edit /sys httpd all-properties 

注意：此命令会进入vi编辑器

3.找到以include none开头的行，改为以下内容

include '

<LocationMatch ";">

Redirect 404 /

</LocationMatch>

'

注意：您可以忽略任何前置空格

4.写入配置并保存退出

Esc

:wq!

5.当系统进一步提示您：Save Changes (y/n/e)，输入y

6.通过输入以下tmsh命令来保存配置

save /sys config

7.重启httpd服务来激活缓解措施

restart sys service httpd

**产品线解决方案**  

**奇安信网神统一服务器安全管理平台更新入侵防御规则库**

奇安信网神虚拟化安全轻代理版本可通过更新入侵防御规则库2020.07.07版本，支持对F5 BIG-IP TMUI远程代码执行漏洞的防护，当前规则正在测试中，将于7月7日发布，届时请用户联系技术支持人员获取规则升级包对轻代理版本进行升级。

奇安信网神统一服务器安全管理平台可通过更新入侵防御规则库10276版本，支持对F5 BIG-IP TMUI远程代码执行漏洞的防护，当前规则正在测试中，将于7月7日发布，届时请用户联系技术支持人员获取规则升级包对融合版本进行升级。

  

**奇安信网站应用安全云防护系统已更新防护特征库**

奇安信网神网站应用安全云防护系统已全局更新所有云端防护节点的防护规则，支持F5 BIG-IP TMUI远程代码执行漏洞的防护。

  

**奇安信天眼产品解决方案**

奇安信天眼新一代威胁感知系统在第一时间加入了该漏洞的检测规则，请将规则包升级到3.0.0706. 12064及以上版本。规则名称：F5 BIG-IP TMUI远程代码执行漏洞(CVE-2020-5902)，规则ID：0x1002095C。奇安信天眼流量探针（传感器）升级方法：系统配置->设备升级->规则升级，选择“网络升级”或“本地升级”。

  

**奇安信网神网络数据传感器系统产品检测方案**

奇安信网神网络数据传感器（NDS3000/5000/7000/9000系列和vNDS1000/2000/3000系列）产品，已具备该漏洞的检测能力。规则ID为：5681，建议用户尽快升级检测规则库至2007061220以上版本并启用该检测规则。
