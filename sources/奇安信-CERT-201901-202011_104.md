**漏洞描述**

  

本月，微软共发布了129个漏洞的补丁程序，其中CVE-2020-1301、CVE-2020-1206、CVE-2020-1284漏洞是基于微软SMB协议相关的漏洞。

  

CVE-2020-1301是基于SMBv1协议的远程代码执行漏洞，CVE-2020-1206是基于SMBv3协议信息泄漏漏洞，CVE-2020-1284是基于SMB协议的拒绝服务漏洞。漏洞细节分别如下：

  

**CVE-2020-1206 Windows SMBv3 Client/Server信息泄露漏洞：**

Microsoft Server Message Block 3.1.1 (SMBv3)协议在处理特定的请求时，存在一个信息泄露漏洞。未经身份验证的攻击者可通过向目标SMB服务器发特制数据包来利用此漏洞，或配置一个恶意的 SMBv3 服务器并诱导用户连接来利用此漏洞。成功利用此漏洞的远程攻击者可获取敏感信息。

  

**CVE-2020-1301 SMB远程代码执行漏洞：**

Microsoft Server Message Block 1.0 (SMBv1)服务器在处理特定的请求时，存在一个远程代码执行漏洞。经过身份验证的攻击者可通过向目标SMBv1服务器发特制数据包来利用此漏洞，成功利用此漏洞的远程攻击者可在目标系统上以该用户权限执行任意代码。

经过进一步分析，CVE-2020-1301漏洞通过SMB\_COM\_NT\_TRANSACT请求触发整数下溢，此问题会导致攻击者进行越界内核写入，从而导致远程代码执行的可能。

总的来说，CVE-2020-1301漏洞的危害性要比SMBGhost（CVE-2020-0796）与永恒之蓝小得多，因为它有几个先决条件其中之一是：

  

需要经过授权的用户来连接到远程共享文件夹

  

奇安信CERT已第一时间测试了泄漏的POC：

  

在现阶段的测试中，POC只能造成蓝屏，不排除有进一步利用可能。

![](../Images/ef7a5f99bed54699713412f45012adb1.png)

  

**CVE-2020-1284 SMB拒绝服务漏洞：**  

Microsoft SMB服务器在处理特定的请求时，存在远程代码执行漏洞。攻击者可通过向目标SMB服务器发特制请求包来利用此漏洞，成功利用此漏洞可导致目标系统拒绝服务。此拒绝服务漏洞不会使攻击者执行代码或提升权限，但是会导致目标系统停止接收请求。

![](../Images/d657a683b2bc966c1b7b64adcc6aa32b.png "金属质感分割线")

**CVE-2020-1301 Windows SMB远程代码执行漏洞处置建议：**

目前，微软官方已发布针对此漏洞受影响版本的补丁程序，该安全更新通过更正SMBv1协议处理这些特制请求的方式来解决此漏洞。建议用户参考以下链接尽快安装补丁程序：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2020-1301

 

如果暂时无法安装补丁程序，可采取临时缓解措施：

**一、禁用SMBv1**

对于运行Windows Vista和更高版本的用户，请参阅文章：https://support.microsoft.com/kb/2696547。

 

**运行Windows 8.1或Windows Server 2012 R2及更高版本客户端操作系统的缓解方案：**

打开控制面板，单击“程序”，然后单击“打开或关闭Windows功能”。

在“Windows功能”窗口中，清除“SMB1.0 / CIFS文件共享支持”复选框，然后单击“确定”关闭该窗口。

重新启动系统。

 

**对于服务器操作系统的缓解方案：**

打开服务器管理器，然后单击“管理”菜单，选择“删除角色和功能”。

在“功能”窗口中，清除“SMB1.0 / CIFS文件共享支持”复选框，然后单击“确定”关闭该窗口。

重新启动系统。

该方法会造成SMBv1协议在目标系统上禁用。

 

如撤消缓解方案，回溯以上步骤，选中“SMB1.0 / CIFS文件共享支持”复选框，以将SMB1.0 / CIFS文件共享支持功能恢复为活动状态。
