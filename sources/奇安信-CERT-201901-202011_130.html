奇安信 CERT

升级提示通告


奇安信CERT监测到4月15日Oracle发布关键安全补丁集合（CPU）共发布了多达405个漏洞的补丁程序，其中，有三个漏洞（CVE-2020-2829、CVE-2020-2798、CVE-2020-2963）由奇安信CERT安全研究员提交。另外，经研判以下漏洞影响较大：CVE-2020-2915 Oracle Coherence MVEL表达式注入漏洞， Oracle WebLogic Server核心组件的T3反序列化漏洞 CVE-2020-2801与CVE-2020-2884、CVE-2020-2949、CVE-2020-2883。鉴于这些漏洞危害较大，建议客户尽快安装更新补丁。



发布时间


官方通告发布日期

2020-4-15

奇安信 CERT 通告日期

2020-4-15


重点关注漏洞

 CVE-2020-2829 

  • CVSS：暂无

  • 影响版本：详见《Oracle融合中间件高危漏洞安全风险通告》

  • 概述：Oracle WebLogic Server的管理服务存在漏洞，该漏洞影响10.3.6.0.0版本，成功利用此漏洞的高权限攻击者可对关键数据进行未授权访问或拥有所有Oracle WebLogic Server可访问数据的完全访问权限。


 CVE-2020-1798 

  • CVSS：暂无

  • 影响版本：详见《Oracle融合中间件高危漏洞安全风险通告》

  • 概述：Oracle WebLogic Server的WLS Web服务存在漏洞，受此漏洞影响的版本包括10.3.6.0.0、12.1.3.0.0、12.2.1.3.0和12.2.1.4.0。拥有高权限的攻击者可通过精心构造的T3请求来利用此漏洞，成功利用此漏洞的攻击者可接管Oracle WebLogic Server。


 CVE-2020-2963 

  • CVSS：暂无

  • 影响版本：详见《Oracle融合中间件高危漏洞安全风险通告》

  • 概述：Oracle WebLogic Server的Web服务存在漏洞，受此漏洞影响的版本包括10.3.6.0.0、12.1.3.0.0、12.2.1.3.0和12.2.1.4.0。拥有高权限的攻击者可通过精心构造的T3请求来利用此漏洞，成功利用此漏洞的攻击者可接管Oracle WebLogic Server。

  • 概述：Oracle Coherence存在MVEL表达式注入漏洞，受此漏洞影响的版本包括3.7.1.0、12.1.3.0.0、12.2.1.3.0和12.2.1.4.0。未经身份验证的攻击者可通过精心构造的T3请求来利用此漏洞，成功利用此漏洞的攻击者可接管Oracle Coherence。
