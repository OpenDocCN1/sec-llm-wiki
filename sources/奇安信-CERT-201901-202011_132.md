# 【安全风险通告】Oracle 融合中间件高危漏洞安全风险通告

![](../Images/f0a3953f25d645bd69cb7009fb737ddb.png)

Oracle于美国时间2020年4月14日星期二发布了今年第二季度的关键安全补丁集合（CPU），本次关键安全补丁集合修复了405个安全漏洞。其中，有三个漏洞（CVE-2020-2829、CVE-2020-2798、CVE-2020-2963）由奇安信CERT安全研究员提交。另外，经研判以下漏洞影响较大：CVE-2020-2915 Oracle Coherence MVEL表达式注入漏洞， Oracle WebLogic Server核心组件的T3反序列化漏洞 CVE-2020-2801与CVE-2020-2884、CVE-2020-2949、CVE-2020-2883。由于这些安全漏洞的危害性，奇安信CERT建议客户尽快应用本次关键安全补丁集合（CPU）。

  

![](../Images/f0a3953f25d645bd69cb7009fb737ddb.png)

  

奇安信 CERT  

  

**漏洞描述**

  

奇安信CERT 信息安全工程师发现Oracle公司旗下产品Oracle WebLogic Server多个安全漏洞（CVE-2020-2829、CVE-2020-2798、CVE-2020-2963）并第一时间向Oracle公司报告。北京时间2020年4月15日星期三，Oracle公司发布第二季度关键补丁更新公告 Critical Patch Update - April 2020。

  

公告中公开致谢了奇安信CERT：

![](../Images/f2968ddee6f34b24540fde1cbc53c892.png)

  

另外值得关注的漏洞还有CVE-2020-2915 Oracle Coherence表达式注入漏洞、CVE-2020-2883 Oracle Coherence远程代码执行漏洞以及位于Oracle WebLogic Server核心组件的T3反序列化漏洞 CVE-2020-2801与CVE-2020-2884。

  

以下为漏洞详情：

**CVE-2020-2829**

Oracle WebLogic Server的管理服务存在漏洞，该漏洞影响10.3.6.0.0版本，成功利用此漏洞的高权限攻击者可对关键数据进行未授权访问或拥有所有Oracle WebLogic Server可访问数据的完全访问权限。

奇安信CERT第一时间复现了该漏洞：

![](../Images/fcb739a2759d486821e1723829ecb98e.png)

  

**CVE-2020-2798**

Oracle WebLogic Server的WLS Web服务存在漏洞，受此漏洞影响的版本包括10.3.6.0.0、12.1.3.0.0、12.2.1.3.0和12.2.1.4.0。拥有高权限的攻击者可通过精心构造的T3请求来利用此漏洞，成功利用此漏洞的攻击者可接管Oracle WebLogic Server。

奇安信CERT第一时间复现了该漏洞：

![](../Images/e70747c8ff9d6eac8513bf6c5ece1c0d.png)

  

**CVE-2020-2963**

Oracle WebLogic Server的Web服务存在漏洞，受此漏洞影响的版本包括10.3.6.0.0、12.1.3.0.0、12.2.1.3.0和12.2.1.4.0。拥有高权限的攻击者可通过精心构造的T3请求来利用此漏洞，成功利用此漏洞的攻击者可接管Oracle WebLogic Server。

奇安信CERT第一时间复现了该漏洞：

![](../Images/4324e0a25ac8141b1104a92a4cc7031f.png)

  

**CVE-2020-2915**

Oracle Coherence存在MVEL表达式注入漏洞，受此漏洞影响的版本包括3.7.1.0、12.1.3.0.0、12.2.1.3.0和12.2.1.4.0。未经身份验证的攻击者可通过精心构造的T3请求来利用此漏洞，成功利用此漏洞的攻击者可接管Oracle Coherence。

奇安信CERT第一时间复现了该漏洞：

![](../Images/4a105ae3874eb5cc0e2f4157990646fd.png)

  

**CVE-2020-2801**

Oracle WebLogic Server核心组件存在T3反序列化漏洞，受此漏洞影响的版本包括10.3.6.0.0、12.1.3.0.0、12.2.1.3.0和12.2.1.4.0。该漏洞允许未经身份验证的攻击者通过T3进行网络访问，未经身份验证的攻击者可通过精心构造的T3请求来利用此漏洞，成功利用此漏洞的攻击者可能接管Oracle WebLogic Server。

奇安信CERT第一时间复现了该漏洞：

![](../Images/29fb4fe4ff63f1e788f8b810850f08e1.png)

  

**CVE-2020-2884**

Oracle WebLogic Server核心组件存在T3反序列化漏洞，受此漏洞影响的版本包括10.3.6.0.0、12.1.3.0.0、12.2.1.3.0和12.2.1.4.0。未经身份验证的攻击者可通过精心构造的T3请求来利用此漏洞，成功利用此漏洞的攻击者可能会接管Oracle WebLogic Server。

  

**CVE-2020-2949**

Oracle Coherence产品中存在漏洞，受此漏洞影响的版本包括3.7.1.0、12.1.3.0.0、12.2.1.3.0和12.2.1.4.0。未经身份验证的攻击者可通过精心构造的HTTP请求来利用此漏洞，成功利用此漏洞的攻击者可执行任意代码。

奇安信CERT第一时间复现了该漏洞：

![](../Images/e22771ccc2e95672c53a0c285e58bf2e.png)

  

**CVE-2020-2883**

Oracle Coherence组件存在高危漏洞，未经身份验证的攻击者可通过精心构造的T3请求来利用此漏洞，成功利用此漏洞的攻击者可能接管Oracle WebLogic Server。

奇安信CERT第一时间复现了该漏洞：

**产品线解决方案**  

**奇安信天眼产品解决方案**

奇安信天眼新一代威胁感知系统在第一时间加入了该漏洞的检测规则，请将规则包升级到3.0.0415. 11795及以上版本。

规则名称：WebLogic SSRF漏洞(CVE-2020-2829)，规则ID：0x5a9b； 

规则名称：WebLogic 反序列化漏洞(CVE-2020-2883)，规则ID：0x5a9a；

规则名称：Oracle WebLogic XXE注入漏洞(CVE-2020-2949)，规则ID：0x5a99；

规则名称：WebLogic远程代码执行漏洞(CVE-2020-2915)，规则ID：0x5a9c；

规则名称：WebLogic 反序列化漏洞(CVE-2020-2798)，规则ID：0x5a9d；

规则名称：WebLogic远程代码执行漏洞(CVE-2020-2801)，规则ID：0x5a9e；

规则名称：WebLogic 反序列化漏洞(CVE-2020-2963)，规则ID：0x5a98。奇安信天眼流量探针（传感器）升级方法：系统配置->设备升级->规则升级，选择“网络升级”或“本地升级”。

  

**奇安信网神天提防火墙产品防护方案**

奇安信新一代智慧防火墙（NSG3000/5000/7000/9000系列）和下一代极速防火墙（NSG3500/5500/7500/9500系列）产品系列，已通过更新IPS特征库完成了对该漏洞的防护。建议用户尽快将IPS特征库升级至” 2004151000” 及以上版本并启用规则ID: 1059101、1059201、1059301、1059401、1059501、1059801、1059901进行检测防御。

  

**奇安信网神网络数据传感器系统产品检测方案**

奇安信网神网络数据传感器（NDS3000/5000/7000/9000系列和vNDS1000/2000/3000系列）产品，已具备该漏洞的检测能力。规则ID为：50674、51424、5539、5540、51459、51433、51460，建议用户尽快升级检测规则库至2004151530以上版本并启用该检测规则。
