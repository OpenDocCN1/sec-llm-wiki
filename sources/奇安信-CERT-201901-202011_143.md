# 【补丁库更新】奇安信集团2020年03月补丁库更新通告第三次更新

奇安信集团最新补丁库2020.03.20.1已发布，本次更新推送了7个Adobe Reader安全补丁，修复了13个安全漏洞。  

  

本月第二次更新紧急推送补丁4551762，修复SMBv3的漏洞(CVE-2020-0796，成功利用此漏洞的攻击者可以在目标服务器或客户端上远程执行代码，风险类似永恒之蓝)，影响Windows 10 1903、1909版和Windows Server 1903、1909版(Server Core installation)，建议尽快修复。

  

本月第一次更新推送了14个微软安全补丁，修复了106个安全漏洞，其中25个微软官方评级为“严重”，76个评级为“重要”，4个评级为“低”，1个评级为“无”，这些漏洞影响产品Windows、Internet Explorer和Microsoft Office。同时推送了4个非安全Office补丁。

  

由于SHA-1算法的缺陷，微软从2019年7月起在Windows中强制使用SHA-2代码签名。如果Windows 7 SP1、 Windows Server 2008 R2 SP1和Windows Server 2008 SP2没有安装4474419（SHA-2 代码签名更新）、 4490628或者4493730（服务堆栈更新）补丁并重启操作系统，则不能安装7月及之后的安全补丁。

  

2019年4月10日发布的天擎6.6.0.2000及以上版本支持Windows 10安全更新补丁管理，如需此功能请更新版本。
