本周安全大事件

**国内多家企业OA系统服务器遭勒索病毒攻击** |
| :-: |

|      3月13日，国内办公软件厂商通达OA在官方论坛发布紧急公告称，有部分用户的OA服务器遭到网络攻击，服务器上文件被重命名加密，并有勒索病毒提示。并在当天晚上通达OA再次发布公告，提供了修复建议：通达OA产品团队紧急制作了针对勒索病毒的安全加固程序，请广大用户立即下载更新。根据业内安全厂商的分析，该勒索病毒由Go语言编写，在进入用户系统后会自动运行，并会尝试结束mysql.exe进程，再对.mdb、.sqlitedb、.doc、 .docx、.xls、 .xlsx、.ppt、.pptx等180种数据文件进行加密。文件被加密后末尾被添加"1"，并会在桌面生成文件为"readme\_readme\_readme.txt"的勒索信，并索要0.3个比特币。 |

| 全国信息安全标准化技术委员会秘书处针对远程办公安全问题，组织相关厂商和安全专家，编制了《网络安全标准实践指南——远程办公安全防护》。《实践指南》给出了远程办公的典型应用场景，分析了远程办公可能面临的办公系统、数据、设备和个人信息保护等方面的安全风险，针对远程办公系统的使用方和用户，分别给出了安全控制措施建议。更多详细内容请查看原文。 |

**MITRE发布通用弱点枚举CWE 4.0版本**

  

| 以ATT＆CK框架，对抗策略和技术的丰富来源以及缓解措施而闻名的MITER，现又发布另一项资源：通用弱点枚举（CWE）。CWE是由网络安全和基础结构安全局（CISA）发起的一项社区计划，对于主动管理风险非常有用。CWE枚举了常见的安全弱点，是漏洞管理的必备利器，并且可以有效地检查企业内部潜在的危害点。目前CWE已更新到4.0版本，更多详细内容请查看原文。 |

**奇安信应急响应数据显示：针对医疗行业勒索事件仍然突出**

|   
在上周中，奇安信网络安全应急响应中心共接到应急响应22次，共计244.22小时，覆盖13个省市，9个行业。其中，医疗卫生行业应急次数最多，累计应急6次。根据上周实际应急情况，在医疗卫生行业相关的应急事件中，勒索问题最为突出。奇安信网络安全应急响应中心根据这22起应急事件从失陷区域、事件影响、攻击目的、木马类型、自身弱点方面，全面分析得出上周的应急响应简报。 |

**2019年开源软件漏洞数量激增**

  

| 一份新的WhiteSource报告称，2019年公开的开源软件漏洞数量达到了6000多个，而2018年仅为4,000多个。业内有安全公司指出：这可以归因于开源组件的广泛采用以及过去几年开源社区的大规模增长，以及媒体对近期数据泄露的关注，对开源安全的意识增强。此份报告还提出了现已披露超过85％的开源安全漏洞并提供了修复程序，编写漏洞代码语言以C语言为主，以及漏洞性质最常见的为跨站脚本漏洞。 |

**Intel处理器新漏洞打补丁后性能下降77％**

|   
在2月10日，安全研究机构BitDefender发现了Intel处理器的LVI漏洞，该漏洞影响了Intel Sandy Bridge二代酷睿以来的绝大部分产品。可以让攻击者绕过Intel SGX软件保护扩展机制，从处理器中窃取敏感信息，类似幽灵漏洞，不过Intel、BitDefender都认为它只有理论攻击的可能，暂不具备实质性威胁。Intel对此漏洞发出了安全补丁，但是根据Phoronix的测试，打补丁后安全性能下降77%。 |

 |
