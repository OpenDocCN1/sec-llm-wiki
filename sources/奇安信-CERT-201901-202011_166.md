# 【补丁库更新】奇安信集团2020年02月补丁库更新通告第二次更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5NDgxODU1MQ==&mid=2247486407&idx=2&sn=b3a54737635497732ae2065317d9402b&chksm=fe7a2f5fc90da649f93bd51efd34384771870c74120fa4a27cbdb7fee77771a205614ff4135f&scene=126&sessionid=1681373271#rd](http://mp.weixin.qq.com/s?__biz=MzU5NDgxODU1MQ==&mid=2247486407&idx=2&sn=b3a54737635497732ae2065317d9402b&chksm=fe7a2f5fc90da649f93bd51efd34384771870c74120fa4a27cbdb7fee77771a205614ff4135f&scene=126&sessionid=1681373271#rd)

![](../Images/f0a3953f25d645bd69cb7009fb737ddb.png)

奇安信集团最新补丁库2020.02.16.1已发布，本次更新将补丁4532693、4524244奇安信等级调整为可选的高危。补丁4524244会导致部分型号的HP电脑不能开机，补丁4532693可能导致桌面和开始菜单都不显示应用图标和快捷方式。  

  

本月第一次更新推送了18个微软安全补丁，修复了95个安全漏洞，其中14个微软官方评级为“严重”，80个评级为“重要”，1个评级为“低”，这些漏洞影响产品Windows、Internet Explorer、Adobe Flash Player和Microsoft Office。同时推送了2个非安全Office补丁、8个Adobe Reader安全补丁。

  

由于SHA-1算法的缺陷，微软从2019年7月起在Windows中强制使用SHA-2代码签名。如果Windows 7 SP1、Windows Server 2008 R2 SP1和Windows Server 2008 SP2没有安装4474419（SHA-2 代码签名更新）、 4490628或者4493730（服务堆栈更新）补丁并重启操作系统，则不能安装7月及之后的安全补丁。（服务堆栈2020年2月最新更新：WindowsServer 2008（4537830）、Windows7/Server 2008 R2（4537829））

  

2019年4月10日发布的天擎6.6.0.2000及以上版本支持Windows 10安全更新补丁管理，如需此功能请更新版本。

  

解决Internet Explorer 0day漏洞CVE-2020-0674的补丁4537767，在已停服的Windows 7和Server 2008系统上不能免费安装，需要向微软付费购买扩展服务，奇安信不推送此补丁。
