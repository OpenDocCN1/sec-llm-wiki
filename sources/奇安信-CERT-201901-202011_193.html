MITRE首发针对工业控制系统的ATT＆CK知识库

     

1月7日，MITER发布了ATT＆CK for ICS知识库，主要介绍了网络攻击者在攻击工业控制系统（ICS）时所使用的策略和技术，为关键基础设施和其他使用工业控制系统的组织评估网络风险提供了参考。据了解，来自39个组织的100多名参与者都参与了此份知识库的调研，其中包括专注于ICS的网络情报和安全公司、工业产品制造商、国家实验室、研究机构、大学、信息共享和分析中心以及支持公共和私有关键基础架构的政府机构。目前，此份ATT＆Ck for ICS知识库涵盖了ATT＆Ck for ICS技术框架、ICS威胁者使用的软件、威胁团体和资产四大维度。就现在看来，对工业控制系统建立针对性的标准的语言，不仅能让资产所有者和维护者了解对手攻击工业控制系统的手段和技术，用来提升帮助其防御能力，而且对于安全从业人员进行事件报告，开发事件响应手册、确定防御优先级和发现漏洞等也都有着重要意义。

Firefox 等浏览器将不再支持加密协议 TLS 1.1 及以下版本


Firefox 浏览器自 74.0 版本开始，将完全放弃对加密协议 TLS 1.0 和 TLS 1.1 的支持。届时，浏览器将通过显示“安全连接失败”错误页面来阻止用户访问不支持 TLS 1.2 或更高版本的网站。早在 2018 年，Mozilla 和其他浏览器制造商（包括谷歌、微软和苹果）就宣布计划于 2020 年弃用 TLS 1.0 和 TLS 1.1，以提高互联网连接的安全性。

谷歌Project Zero团队将漏洞公布日期延长至90天


谷歌 Project Zero 团队以披露大量严重漏洞而被人们所熟知，但也因为严格的快速披露政策而遭到了行业内的批评。于是 2020 年的时候，谷歌安全团队试图制定新的政策，将问题披露的宽限期给足了整整 90 天。若企业顺利或提前完成了修复，也可以与谷歌 Project Zero 取得联系，以提前公布漏洞详情。在此政策正式实施之前，Google 将给予 12 个月的试用。

https://www.cnbeta.com/articles/tech/930183.htm

微软发布互联网 RDP 爆破攻击研究报告


微软在上个月发布一项关于RDP爆破的攻击研究报告，对于这项，研究微软表示，它从运行Microsoft Defender Advanced Threat Protection（免费的Defender防病毒应用的商业版本）的超过45,000个工作站上收集了有关RDP登录相关事件的数据。此项研究表明了大约有0.08％的RDP暴力攻击是成功的，并且RDP暴力攻击平均可持续2-3天。
