2020年1月15日，ATLASSIAN公司公开了其产品Bitbucket的服务器和数据中心的3个远程代码执行（RCE）漏洞，漏洞编号为：CVE-2019-15010、CVE-2019-20097、CVE-2019-15012。这些漏洞影响 Bitbucket服务器和数据中心的多个版本。

![](../Images/f0a3953f25d645bd69cb7009fb737ddb.png)

  

奇安信 CERT  
**漏洞描述**

  

Bitbucket是ATLASSIAN公司提供的一个基于web的版本库托管服务，支持Mercurial和Git版本控制系统。

  

2020年1月15日，Bitbucket支持网站公开了影响Bitbucket服务器和数据中心多个版本的3个远程代码执行漏洞，漏洞详情如下：

  

**CVE-2019-15010：**

此漏洞影响从3.0.0开始的Bitbucket服务器和数据中心版本。具有用户级别权限的攻击者可通过构造特制的有效载荷作为用户输入，尝试远程利用此漏洞，成功利用时可以在受害者的Bitbucket服务器或数据中心实例上执行任意命令。

  

**CVE-2019-20097：**

此漏洞影响从1.0.0开始的Bitbucket服务器和数据中心版本。攻击者在有权克隆文件并将其推送到受害者Bitbucket服务器或数据中心实例上的项目仓库的前提下，可通过使用包含特制内容的文件尝试远程利用此漏洞，成功利用时可在Bitbucket服务器或数据中心系统上执行任意命令。

  

**CVE-2019-15012：**

此漏洞影响Bitbucket服务器和数据中心高于或等于4.13的版本。攻击者在对某个项目仓库具有写权限的情况下，可以通过对受害者的以可写权限运行的Bitbucket服务器或数据中心实例写入任意文件尝试远程利用此漏洞，成功利用时可以致使受害者的Bitbucket服务器实例执行任意代码。

![](../Images/d657a683b2bc966c1b7b64adcc6aa32b.png "金属质感分割线")

**处置建议**

  

奇安信CERT建议尽快您升级到最新版本（6.9.1）。您可以从Atlassian网站下载最新版本的Bitbucket服务器和数据中心：

https://www.atlassian.com/software/bitbucket/download。

  

如果无法升级到最新版本（6.9.1），可以根据您的软件的自身版本升级到以下对应的包含漏洞修复程序的Bitbucket服务器和数据中心修复版本：

 

| 当前版本 || 对应漏洞修复版本 |
| --- | --- |
| 1.xx，2.xx，3.xx，4.xx或5.xx || 5.16.11 |
| 6.0.x || 6.0.11 |
| 6.1.x || 6.1.9 |
| 6.2.x || 6.2.7 |
| 6.3.x || 6.3.6 |
| 6.4.x || 6.4.4 |
| 6.5.x || 6.5.3 |
| 6.6.x || 6.6.3 |
| 6.7.x || 6.7.3 |
| 6.8.x || 6.8.2 |

  

**漏洞修复版本可以从此地址下载**：****

https://www.atlassian.com/software/bitbucket/download-archives

  

**如果您无法立即升级Bitbucket服务器或数据中心，则可以采取以下步骤作为临时缓解方案：**

对于CVE-2019-15012，可以按照以下步骤禁用编辑文件功能：

在bitbucket.properties中，设置feature.file.editor=false

  

**有关更多信息，请参见：**

https://confluence.atlassian.com/bitbucketserver/bitbucket-server-config-properties-776640155.html

  

对于CVE-2019-15010或CVE-2019-20097没有已知的解决方法，因此请尽快升级版本。
