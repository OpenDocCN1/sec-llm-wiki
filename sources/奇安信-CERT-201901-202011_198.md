## 什么是ECC椭圆曲线密码

ECC椭圆曲线密码(Elliptic curve cryptography)是由Miller和Koblitz提出的一种基于有限域上椭圆曲线这一代数结构的公钥密码学。与其他加密方案（基于普通有限域）相比，在提供相同等级的安全性下，ECC需要的密钥长度更短。凭借这种优势，ECC被广泛应用于密钥管理、数字签名等领域，同时吸引了研究者们的高度关注。

公钥密码学的安全性主要基于解决某些数学问题的困难性，例如整数分解问题以及离散对数问题，而ECC所基于的困难问题为椭圆曲线离散对数问题ECDLP。简单来讲，椭圆曲线是有限域（而不是实数）上的平面曲线，由满足以下等式的点以及一个无穷远点组成：

```
E: y² = x³+ ax + b (mod p)
```

![](../Images/13a9a954348ad38906d469a066995560.png)

  

这些点在群运算下构成群，习惯上群运算写作加法。根据群的性质，若`P=(x,y)`是E上的一个点，则mP也是E上的一个点，其中m是一个整数。这样，给定曲线E上的一个点对（P, Q=mP），当点P有大的素数阶时，普遍认为求解m是困难的（计算上不可行的）。因此，基于ECC构建公钥方案时，一般令Q为公钥，m为私钥。椭圆曲线的大小（点P阶的大小）决定了问题的困难程度。

## 漏洞分析

CVE-2020-0601漏洞原理在于Windows 10增加了对参数ECC密钥的支持，但在`crypt32.dll`中验证签名时，并不检查底层参数即生成元P是否一致。具体来讲，官方私钥为m，对应的公钥为`Q=mP`，利用私钥对其认可的文件进行签名。用户利用官方的公钥对该签名进行验证，若验证通过，则此文件是可信赖的。而由于Windows 10支持自定义生成元，因此恶意攻击者定义生成元`P’=Q=mP`，令伪造的私钥为e（素数域中单位元），则此伪造私钥所对应的公钥`Q’=eP’=P’=Q`。简单来讲，当生成元是P时，（mP, m）是一对合法的公私钥，当生成元是mP时，（mP, e）也是一对合法的公私钥。而签名的安全性在于给定生成元时，通过公钥无法获得对应的私钥。但由于`crypt32.dll`不检查对应的生成元，通过这种方式就可以绕过ECDLP困难问题获得一个可以通过验证的私钥e，与官方的私钥具有同等的能力，即，利用e对文件进行的签名可以被官方的公钥验证成功，使得用户认为该文件是被官方信赖的。

该漏洞可以使攻击者为恶意可执行文件签发可以通过验证的签名，导致用户信息泄露或系统被破坏，使用户权益受损。

## 受影响版本

此漏洞只影响Windows 10、Windows Server 2016/2019的相关版本，具体受影响版本请参考[《微软多个产品高危漏洞安全风险通告》](http://mp.weixin.qq.com/s?__biz=MzU5NDgxODU1MQ==&mid=2247486166&idx=1&sn=75ab29085a76565c599f45e683b86f27&chksm=fe7a2e4ec90da758d64af6f71a9edae6764f18638c741aa309e2707c9b99fc68f3369dacf272&scene=21#wechat_redirect)

## 修复方案

目前软件微软已经发布了漏洞相应的补丁，建议受影响用户尽快安装，以有效缓解所有Windows 10和Windows Server 2016/2019系统上的漏洞。如果短时间对企业范围进行自动化的修补难以实现，建议系统所有者优先考虑对关键服务进行修补。可参考奇安信CERT发布的[《Microsoft Windows核心加密库漏洞（CVE-2020-0601）客户端/服务器修补通告》](http://mp.weixin.qq.com/s?__biz=MzU5NDgxODU1MQ==&mid=2247486166&idx=2&sn=93a4512cab9b9d8e92beea462f7ba623&chksm=fe7a2e4ec90da758a0c412fb3bcfa2b60c33a6a8215ed8b7623394a9ea0096163c36d1ac0719&scene=21#wechat_redirect)
