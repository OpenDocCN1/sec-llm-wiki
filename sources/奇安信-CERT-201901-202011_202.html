Citrix ADC和Citrix Gateway存在一个远程代码执行漏洞，攻击者可通过精心构造的请求攻击Citrix ADC或Citrix Gateway服务器。成功利用此漏洞的攻击者可以在目标主机上执行任意代码。近日，奇安信CERT监测到此漏洞远程代码执行效果的EXP被爆出，我们在第一时间复现了此漏洞，鉴于该漏洞影响较大，建议及时采取缓解措施。


本次更新内容如下：

1.针对此漏洞的远程代码执行效果的EXP爆出

2.Citrix官方补丁预计发布时间

3.本次更新新增奇安信网站应用安全云防护系统以及奇安信网神网络数据传感器系统针对该漏洞的产品防护方案


鉴于该漏洞EXP已被爆出，建议及时采取缓解措施。


奇安信 CERT


漏洞描述


Citrix ADC 是一款应用交付和负载均衡解决方案，这款解决方案提供多种形式和部署选项，并且允许在云部署之间移动功能。


Citrix Gateway 是一款客户托管解决方案，支持在内部和任何公共云中部署，如 AWS、Azure 或 Google Cloud Platform。Citrix Gateway 能够为用户提供针对保障生产力所需的所有虚拟、SaaS 和 Web 应用程序的安全访问和单点登录。


Citrix ADC和Citrix Gateway存在一个远程代码执行漏洞，攻击者可通过精心构造的请求攻击Citrix ADC或Citrix Gateway服务器。成功利用此漏洞的攻击者可以在目标主机上执行任意代码。近日，某代码托管平台出现了此漏洞的远程代码执行利用代码，并且MSF也集成了该漏洞的攻击代码。



风险等级


奇安信 CERT风险评级为：高危

风险等级：蓝色（一般事件）


影响范围


Citrix ADC 和 Citrix Gateway version 13.0 的所有受支持的构建版本

Citrix ADC 和 NetScaler Gateway version 12.1 的所有受支持的构建版本

Citrix ADC 和 NetScaler Gateway version 12.0 的所有受支持的构建版本

Citrix ADC 和 NetScaler Gateway version 11.1 的所有受支持的构建版本

Citrix NetScaler ADC 和 NetScaler Gateway version 10.5 的所有受支持的构建版本

目前官方还没有发布补丁，Citrix预计将在2020年1月底之前为所有受支持的Citrix ADC和Citrix Gateway版本提供固件更新。请参见下表来了解发布日期。另外，用户可通过以下链接订阅官方固件更新提示来获取固件更新消息：https://support.citrix.com/user/alerts

产品线解决方案

奇安信网站应用安全云防护系统已更新防护特征库：

奇安信网神网站应用安全云防护系统已全局更新所有云端防护节点的防护规则，支持Citrix ADC和Citrix Gateway远程代码执行漏洞的防护。


奇安信网神网络数据传感器系统产品检测方案：

奇安信网神网络数据传感器（NDS3000/5000/9000系列）产品，已具备该漏洞的检测能力。规则ID为：5475，建议用户尽快升级检测规则库至2001141700以上版本并启用该检测规则。
