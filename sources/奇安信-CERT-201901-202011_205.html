【安全风险通告】ThinkPHP 6.0 “任意”文件创建漏洞安全风险通告

近日，奇安信补天漏洞响应平台收到ThinkPHP 6.0 “任意”文件创建漏洞。该漏洞源于ThinkPHP 6.0的某个逻辑漏洞，成功利用此漏洞的攻击者可以实现“任意”文件创建，在特殊场景下可能会导致GetShell。


奇安信 CERT

漏洞描述


ThinkPHP是一个免费开源的，快速、简单的面向对象的轻量级PHP开发框架，是为了敏捷WEB应用开发和简化企业应用开发而诞生的。ThinkPHP从诞生以来一直秉承简洁实用的设计原则，在保持出色的性能和至简代码的同时，更注重易用性。遵循Apache2开源许可协议发布，意味着你可以免费使用ThinkPHP，甚至允许把你基于ThinkPHP开发的应用开源或商业产品发布/销售。


近日，奇安信补天漏洞响应平台收到ThinkPHP 6.0 “任意”文件创建漏洞，该漏洞源于ThinkPHP 6.0的某个逻辑漏洞，成功利用此漏洞的攻击者可以实现“任意”文件创建或覆盖，可能造成 Web 应用被破坏（远程拒绝服务），特殊场景下还可造成 GetShell。建议各单位自查，并尽快升级至修复版本。



风险等级


奇安信 CERT风险评级为：高危

风险等级：蓝色（一般事件）


影响范围


ThinkPHP = 6.0



处置建议


建议采用奇安信产品线解决方案或更新到官方最新版本



产品线解决方案


网神天堤防火墙产品防护方案：

奇安信新一代智慧防火墙（NSG3000/5000/7000/9000系列）和下一代极速防火墙（NSG3500/5500/7500/9500系列）产品系列，已通过更新IPS特征库完成了对该漏洞的防护。建议用户尽快将IPS特征库升级至” 2001102015” 及以上版本并启用规则ID: 5474进行检测。


奇安信天眼产品解决方案：

奇安信天眼新一代威胁感知系统在第一时间加入了该漏洞的检测规则，请将规则包升级到3.0.0110. 11598及以上版本。规则名称：ThinkPHP 6.0“任意”文件创建漏洞，规则ID：0x100207BB。奇安信天眼流量探针（传感器）升级方法：系统配置->设备升级->规则升级，选择“网络升级”或“本地升级”。


奇安信网神网络数据传感器系统产品检测方案：

奇安信网神网络数据传感器（NDS3000/5000/9000系列）产品，已具备该漏洞的检测能力。规则ID为：5474，建议用户尽快升级检测规则库至2001102015以上版本并启用该检测规则。


网神虚拟化安全管理平台已更新入侵防御规则库：

网神虚拟化安全管理平台无代理版本可通过更新入侵防御规则库10248版本，支持对ThinkPHP 6.0“任意”文件创建漏洞的防护，请用户联系技术支持人员获取规则升级包对虚拟化产品无代理版本进行升级。


奇安信开源卫士检测方案：

奇安信开源卫士在第一时间加入了该漏洞的信息，请将知识库升级到20200110.164及以上版本。


奇安信网站应用安全云防护系统已更新防护特征库：

奇安信网神网站应用安全云防护系统已全局更新所有云端防护节点的防护规则，支持ThinkPHP 6.0 “任意”文件创建漏洞的防护。


奇安信网神云锁产品解决方案：

奇安信网神云锁产品（私有云版/公有云版）可通过更新网站漏洞防御规则实现ThinkPHP 6.0 “任意”文件创建漏洞的防御，请用户联系技术支持人员获取防护规则。
