# 【安全风险通告】SharePoint Server 信息泄漏漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5NDgxODU1MQ==&mid=2247485968&idx=2&sn=07a86cc51889a2a41037a69869bfe6ee&chksm=fe7a2e88c90da79e6268a66caa74e8ece49e3735cbb93d6532f256cb34afb27f4e8ea3d2f3df&scene=126&sessionid=1681373287#rd](http://mp.weixin.qq.com/s?__biz=MzU5NDgxODU1MQ==&mid=2247485968&idx=2&sn=07a86cc51889a2a41037a69869bfe6ee&chksm=fe7a2e88c90da79e6268a66caa74e8ece49e3735cbb93d6532f256cb34afb27f4e8ea3d2f3df&scene=126&sessionid=1681373287#rd)

本月17日，微软官方发布了Microsoft SharePoint Server信息泄漏漏洞安全补丁，漏洞编号为CVE-2019-1491。

  

SharePoint Server中存在一个信息泄漏漏洞。要利用此漏洞，攻击者需要向特有的SharePoint Server实例发送特制请求。利用此漏洞的攻击者可能能够读取服务器上的任意文件。

![](../Images/f0a3953f25d645bd69cb7009fb737ddb.png)

  

奇安信 CERT

  

**漏洞描述**

  

Microsoft SharePoint是美国微软（Microsoft）公司的一套企业业务协作平台。该平台用于对业务信息进行整合，并能够共享工作、与他人协同工作、组织项目和工作组、搜索人员和信息。

  

SharePoint Server中存在一个信息泄漏漏洞。利用此漏洞的攻击者可能能够读取服务器上的任意文件。

  

要利用此漏洞，攻击者需要向特有的SharePoint Server实例发送特制请求。

![](../Images/d657a683b2bc966c1b7b64adcc6aa32b.png "金属质感分割线")  

  

**风险等级**

  

奇安信 CERT风险评级为：高危

风险等级：蓝色（一般事件）

  

**影响范围**

  

Microsoft SharePoint Enterprise Server 2016

Microsoft SharePoint Foundation 2010 SP2

Microsoft SharePoint Foundation 2013 SP1

Microsoft SharePoint Server 2019
