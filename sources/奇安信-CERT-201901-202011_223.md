# 奇安信集团2019年12月补丁库更新通告

奇安信集团最新补丁库2019.12.11.1已发布，本次更新推送了27个微软安全补丁，修复了29个安全漏洞，其中4个微软官方评级为“严重”，25个评级为“重要”，这些漏洞影响产品Windows、Internet Explorer和Microsoft Office。同时推送了2个非安全 Office补丁、7个Adobe Reader安全补丁。

  

由于SHA-1算法的缺陷，微软从2019年7月起在Windows中强制使用SHA-2代码签名。如果Windows 7 SP1、 Windows Server 2008 R2 SP1和Windows Server 2008 SP2没有安装4474419（SHA-2 代码签名更新）、 4490628或者4493730（服务堆栈更新）补丁并重启操作系统，则不能安装7月及之后的安全补丁。
