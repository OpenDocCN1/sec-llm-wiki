**美陆军将与太空局合作研发可实时跟踪地面威胁的太空能力** |
| :-: |

|      国际安全简报显示，美国陆军正在与美太空发展局（SDA）就研发“可实时跟踪地面威胁，向美国陆军地面作战单位提供深度瞄准（Deep Targeting）信息”的太空传感层进行合作。太空发展局代理局长德里克·图尔尼尔在10月中旬的美国陆军协会（AUSA）年会上指出，太空发展局当前正在发展三个太空传感能力层：一层专用于跟踪高超音速武器和弹道导弹，一层用于太空态势感知并调查环月轨道上运行的物体，一层用于探测并跟踪时间敏感目标。而对于美国陆军来说，探测并跟踪时间敏感目标的太空传感器层是影响最大、最有吸引力的新能力——它将能“探测和跟踪任何体积大于卡车的目标，为美国陆军提供覆盖全球、针对前线武器系统的实时瞄准及火力控制方案”。图尔尼表示，太空局针对传输层技术演示的项目建议征集文件将“马上发布”。 |

**俄罗斯《主权互联网法》正式生效**

  

| 俄罗斯《主权互联网法》目前已正式生效，该法律赋予俄罗斯政府使整个国家脱离全球互联网的能力，其法律核心为：要求所有本国互联网服务提供商，都通过俄罗斯监管机构Roskommadzor的特殊服务器来管理路由流量。更多有关俄罗斯”脱离互联网“相关的布局、原因和其他信息，请查看原文。 |

**中国互联网金融协会：《关于增强个人信息保护意识依法开展业务的通知》**

  

| 中国互联网金融协会向其会员单位下发的《关于增强个人信息保护意识依法开展业务的通知》时指出：一些互联网机构以”大数据“为名，通过”爬虫“业务涉嫌违法违规收集个人信息，或窃取、滥用、买卖、泄露个人信息，侵犯了消费者个人隐私，造成了不良的社会影响。为此协会要求各单位机构要依法开展业务，并下发了五点通知。 |

**《中美俄情报法律制度比较》**

|   
《中美俄情报法律制度比较》指出我国情报立法理念具有总体性、系统性和综合性特征，更具有前瞻性。我国在情报收范围内容上，规定了非常宽泛的收集内容范围，而在情报收集手段的规定相对粗犷，对情报工作人员的保护相对薄弱，在情报工作法律监督上，我国的规定相对笼统缺乏强有力的操作性。为此，我国在机构设置、收集手段、情报人员保护以及法律监督等方面需要予以完善。 |

|

**Apache Shiro Padding Oracle漏洞安全预警通告**

  

| Apache Shiro是一个用于执行身份验证、授权、密码和会话管理的Java安全框架，该框架因cookie中通过AES-128-CBC模式加密的rememberMe字段存在问题，容易受到Padding Oracle攻击，最终可导致远程代码执行。目前此漏洞暂无补丁和缓解措施，建议尝试在外部设备上拦截爆破流量或采用奇安信产品线解决方案防护此漏洞。 |
