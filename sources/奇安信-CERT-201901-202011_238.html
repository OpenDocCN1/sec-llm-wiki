奇安信集团最新补丁库2019.11.13.1已发布，本次更新推送了14个微软安全补丁，修复了43个安全漏洞，其中5个微软官方评级为“严重”，36个评级为“重要”，2个评级为“中”，这些漏洞影响产品Windows、Internet Explorer和Microsoft Office。同时推送了9个非安全 Office补丁。


2019年11月12日，英特尔发布了有关英特尔处理器 机器检查错误漏洞的技术公告，该漏洞已分配给CVE-2018-12207，微软已发布更新。此更新默认情况下，Hyper-V保护处于禁用状态。启用此保护需要在主机上执行操作，请按照https://support.microsoft.com/en-us/help/4530989中有关注册表设置的指南进行操作。


由于SHA-1算法的缺陷，微软从2019年7月起在Windows中强制使用SHA-2代码签名。如果Windows 7 SP1、 Windows Server 2008 R2 SP1和Windows Server 2008 SP2没有安装4474419（SHA-2 代码签名更新）、 4490628或者4493730（服务堆栈更新）补丁并重启操作系统，则不能安装7月及之后的安全补丁。

拒绝服务（DoS）：

永久：利用此漏洞可能导致操作系统或应用程序永久无响应，直到手动重新启动或意外退出而不自动恢复。同时，任何会导致系统自动重启的漏洞也被视为永久性DoS。

临时：利用此漏洞可能会导致操作系统或应用程序暂时无响应，直到攻击停止，或意外退出但自动恢复。攻击完成后不久，目标将返回正常的功能级别。

不适用（N/A）：不会遭到DoS破坏。
