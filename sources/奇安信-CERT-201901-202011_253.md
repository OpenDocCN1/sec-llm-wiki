**BriansClub被黑，2600万张银行卡被移除** |
| :-: |

|      大型的地下黑市“BriansClub”被攻击，超过2600万张信用卡和借记卡从该黑市中移除。据KrebsOnSecurity的报告显示，BriansClub被发现出售了超过910万张被窃取的信用卡信息，并从中获利超过1.26亿美元。此站点正在利用其广受欢迎的特点和在广告中塑造的形象来开展各种活动。在此站点被售卖的数据包括支付卡的各种信息和历史数据，研究分析表明，同一张卡的信息被多个源互相共享，并且任何BriansClub账户均可检索这些数据。在本次被移除的2600万张信用卡和借记卡中，尚有1400万张卡的使用期尚未到期。这些在此站点出售过的2600万张信用卡的信息目前已与金融机构共享，用于识别和监视这些信用卡或者重新发行被窃取的信用卡。更多信息请查看原文。 |

**WebLogic多个组件高危漏洞安全预警通告**

|   
Oracle 官方发布了2019年10月的关键补丁程序更新 CPU（Critical Patch Update），其中修复了多个存在于WebLogic 中的漏洞包括CVE-2019-2891、CVE-2019-2890、CVE-2019-2887。从官方CVSS分数和我们的技术判断，这三个漏洞的利用都有很高的条件限制，危害程度不及CVE-2019-2725和CVE-2019-2729，但也请及时安装更新补丁。 |
