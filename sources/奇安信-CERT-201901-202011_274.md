**微软远程桌面服务远程代码执行漏洞安全预警** |
| :-: |

|      近日，奇安信安全监测与响应中心监测到Windows远程桌面服务（RDP）远程代码执行漏洞（CVE-2019-0708）的EXP代码已被公开发布至metasploit-framework的Pull requests中，经测试已经可以远程代码执行。Windows远程桌面服务（RDP）主要用于管理人员对Windows服务器进行远程管理，使用量极大。成功利用此漏洞的攻击者，可在目标系统上执行任意代码。该漏洞EXP公开发布后，随着工具的扩散，已经构成了蠕虫级的现实安全威胁。针对此漏洞，微软已经发布了安全补丁（包括那些不再提供技术支持的老旧操作系统），强烈建议用户及时安装相应的补丁或采取其他缓解措施以避免受到相关威胁。 |

**《开源漏洞管理现状》：70% 漏洞无效**

  

| 最新发布的《开源漏洞管理现状》指出了开源组件安全的现状和趋势。近年来开源漏洞的数量急剧上升，迫使开发人员花费大量时间来解决开源漏洞，但由于缺乏标准实践和以开发人员为中心的工具，使得相关工作的效率非常低下。此外，报告指出有70%的相关漏洞“无效”，开源漏洞的优先级策略对确保公司按时解决最紧迫的问题至关重要。 |

**新技术“分裂”使密码破解难度提升1400万倍**

  

| 澳大利亚非营利性组织Tide的研究人员发明了一种新的方法“分裂（splintering）”来保护用户名和密码，并声称该密码可以将密码安全性提升1400万倍。据了解，使用该方法，加密密码会被分裂并存储在相关公共区块链的20-26个节点之间，并且只有相关节点能够解密。目前，该方法尚未商业化，但可从该组织的GitHub上找到相关的代码和文档。 |

|   
《专题|5G商用初期运营商移动网络安全分析》中指出，在5G商用部署初期，为实现从4G网向目标网络的平滑过渡，运营商大概率会采用非独立组网NSA架构Option 3X方案。为此安全研究院对NSA Option 3X网路对5G商用初期运营商移动网络安全性进行分析，并指出5G整体安全风险是可控的。更多详细内容，请查看原文。 |
