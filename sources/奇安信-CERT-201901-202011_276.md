尊敬的客户：  

  

奇安信集团最新补丁库2019.09.11.2已发布，本次更新推送了40个微软安全补丁，修复了65个安全漏洞，其中14个微软官方评级为“严重”，51个评级为“重要”，这些漏洞影响产品Windows、Internet Explorer、Microsoft .NET Framework和Microsoft Office。同时推送了8个非安全 Office补丁和 3个Adobe Flash Player安全补丁。

    此外，本次更新还推送了补丁3133977，解决了在安装2019.7月及以后的只使用SHA-2代码签名的Windows更新补丁后，可能出现的因系统使用 EFI 启动而无法验证SHA-2数字签名导致的无法启动问题。建议用户安装此补丁。该补丁在使用华硕主板的Windows 7系统上安装，可能会出现兼容性问题导致启动错误，禁用华硕的安全引导可修复此问题，参照：http://www.asus.com/support/FAQ/1016356/。

由于SHA-1算法的缺陷，微软从七月起在Windows更新中只使用SHA-2代码签名。请用户安装适用于Windows 7 SP1、Windows Server 2008 R2 SP1和Windows Server 2008 SP2的签名支持更新KB4474419；适用于Windows 7 SP1、Windows Server 2008 R2 SP1的服务堆栈更新(SSU) KB4490628，以及适用于Windows Server 2008 SP2的服务堆栈更新(SSU) KB4493730。以上补丁安装完成在重启后生效。

  

奇安信安全监测与响应中心将持续关注该漏洞进展，并第一时间为您更新该漏洞信息。
