本周安全大事件

**Poshmark泄漏了超过3600万用户的个人信息** |
| :-: |

|      近日，据国外媒体报道，美国线上市场Poshmark披露了一起2018年5月发生的数据泄露事件（Poshmark泄露了3600万账户的详细信息）。据了解，该公司发现了有未经授权访问其服务器的记录，从而发现了此次攻击事件。在此次攻击事件中，未授权的攻击者入侵了Poshmark的相关服务器，并窃取了超过3600万客户的个人信息，这些个人信息包括：姓名、电子邮件地址、用户名、性别、位置信息和密码哈希。目前，这些被泄露的Poshmark用户数据被相关人员以明文的形式公开售卖。尽管Poshmark官方声明，账户密码以哈希形式泄露，难以被利用。仍然建议拥有Poshmark账户的用户及时更改密码，以将损失降到最低。 |

| 最新发布的《IDC全球半年度网络安全支出指南，2018H2》指出，2019年全球网络安全相关硬件、软件、服务投资将达到1066.3亿美元，相比2018年增长9.4%，全球政府和企业对网络安全的重视程度逐年提升，市场发展潜力巨大。当前，中国已是除美国以外网络安全支出最多的国家，但也应该清楚的意识到，相对于全球平均水平仍有较大差距。 |

**工信部对“ZAO”进行约谈，AI换脸需谨慎**

|

**首例微信支付勒索软件作者被判处6年6个月**

  

| 9月3日，东莞市第三人民法院对国内首例微信支付赎金的勒索病毒案作出一审判决，以犯破坏计算机信息系统罪判处制作该病毒的“95后”男子罗某有期徒刑六年六个月。据了解，罗某在该起案件中以微信收款二维码的方式，向每台感染病毒的计算机用户进行敲诈勒索，共获得收款37笔，其中一笔30元，非法所得共3990元。 |
