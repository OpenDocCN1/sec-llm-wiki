# 【漏洞预警】Exim 远程代码执行漏洞 CVE-2019-15846 安全预警通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5NDgxODU1MQ==&mid=2247485162&idx=1&sn=a471817d13adde04caccf31b69f51022&chksm=fe7a2272c90dab64bd574afe4f3710dd182092f0cc87075173ee079788b5b3520a19deabe899&scene=126&sessionid=1681373312#rd](http://mp.weixin.qq.com/s?__biz=MzU5NDgxODU1MQ==&mid=2247485162&idx=1&sn=a471817d13adde04caccf31b69f51022&chksm=fe7a2272c90dab64bd574afe4f3710dd182092f0cc87075173ee079788b5b3520a19deabe899&scene=126&sessionid=1681373312#rd)

尊敬的客户：

近日，知名的邮件传输代理程序 Exim 被发现存在远程代码执行漏洞，该漏洞被分配 CVE编号 CVE-2019-15846。攻击者可通过发送特殊构造的请求远程触发此漏洞，成功利用此漏洞后可以root权限在系统上执行任意代码。通过网络空间测绘发现，Exim 在互联网上的使用量巨大。

目前相关漏洞细节已被公开，且已有安全人员开发出漏洞利用程序，暂未监测到有漏洞利用程序被公开传播。建议用户赶紧升级到最新修复版。

  

奇安信安全监测与响应中心将持续关注该漏洞进展，并第一时间为您更新该漏洞信息。

**漏洞描述**

  

Exim 4.92.1中的SMTP投递过程存在缓冲区溢出。在默认运行时配置下，在TLS协商期间，通过发送以反斜杠空{ '\\\\', '\\0' }序列结尾的SNI，可以利用此漏洞。在其他配置中，可以使用精心构造的客户端TLS证书进行利用。

  

**风险等级**

  

奇安信安全监测与响应中心风险评级为：高危

预警等级：蓝色预警（一般事件）

  

**影响范围**

  

Exim <= 4.92.1

**处置建议**

  

升级到4.92.2，https://ftp.exim.org/pub/exim/exim4/exim-4.92.2.tar.gz

  

**缓解措施：**

不使用TLS（不建议）。
