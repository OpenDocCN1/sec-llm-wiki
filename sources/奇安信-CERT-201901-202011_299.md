### **前言**

2019年6月，ESET研究人员发现一个win32k 0day攻击被用于东欧的高度针对性攻击\[1\]。该0day主要存在于windows 7 和 Windows Server 2008 系统中，微软已发布相关补丁\[2\]。

 

### **产生漏洞的地方**

从ESET 发布的文章了解到在win32k!xxxMNOpenHierarchy 存在空指针解引用漏洞。

补丁前:

![](../Images/44cb509c7702bc6849166c43a1cadaf1.png)

  

补丁后: 

![](../Images/88140d6043b879554a734366b33bebd4.png)

  

  

补丁针对弹出菜单对象的ppopupmenuRoot 域进行了校验，为0时则跳过函数HAssignmentLock 函数。

弹出菜单对象中ppopupmenuRoot 域指向根部弹出菜单对象。

kd> dt win32k!tagPOPUPMENU-y ppopupmenuRoot  
   +0x020ppopupmenuRoot : Ptr32 tagPOPUPMENU

用户层模拟用户点击弹出菜单，在内核层存在一种情况，弹出菜单由xxxCreateWindowEx 函数创建，xxxCreateWindowEx函数存在返回用户层执行代码的情况。而如果在创建子弹出菜单的情况下，通过用户层设置钩子接收到子弹出菜单发出的 WM\_NCCREATE* 消息时，对根部弹出菜单发出 MN\_CANCELMENUS *消息，子弹出菜单还未加入到根弹出菜单延迟释放链表中，未设置fDestroyed标志位。在根部弹出菜单将进入延迟销毁的阶段，最终在MNFlushDestroyedPopups 函数对延迟链表中的对象进行释放，由于子弹出菜单fDestroyed未置位，程序流进入else if (fUnlock ) ， 对子弹出菜单ppopupmenuRoot 域进行清除。

![](../Images/e13ab9da6153630b21b6131f93fd4f84.png)

   

  

而在后面通过一些手段，使该子菜单重新进入xxxMNOpenHierarchy 函数，并执行到HAssignmentLock函数，ecx 为ppopupmenuRoot 的值，并未经过检查，这时，漏洞得以触发。

![](../Images/c27e579150d0addd2fed572da3f15d8c.png)

win32k!xxxMNEndMenuState函数调用MNFreePopup 对弹出菜单进行销毁，MNFreePopup函数进一步将根弹出菜单传递给win32k!MNFlushDestroyedPopups

  

 

此时MNFlushDestroyedPopups将根据根弹出菜单对象的pppmDelayedFree 指向的弹出菜单进行释放

![](../Images/907fbada9f90710591c7297bb98eb16f.png)

  

 

而子弹出菜单对象fDestroyed 并未置位从而相关的资源不会进行释放

![](../Images/74210a89993cf563507db147901237df.png)

  

 

MNFlushDestroyedPopups函数中将子菜单弹出对象的ppopupmenuRoot 域进行清除

![](../Images/8999ce7d841a53b4ab971fbaff0fc3b7.png)

  

  

根菜单销毁后，xxxTrackPopupMenuEx 结束，而如果继续对子菜单发送消息，会因为销毁根弹出菜单过程中tagMENUSTATE对象也一并销毁了，导致xxxRealMenuWindowProc 不会正常处理某些消息。

tagMENUSTATE 对象由xxxMNAllocMenuState 函数分配，并初始化一些成员，加入大全局线程信息对象中。

![](../Images/81e0851a6b27f4ae8d22522ba3f5ead1.png)

  

 

xxxTrackPopupMenuEx函数创建菜单窗口并调用xxxMNAllocMenuState 创建tagMENUSTAE对象，为此可以通过再次调用用户层TrackPopupMenuEx对漏洞进行触发，这里菜单句柄为ppopupmenuRoot为0的子菜单句柄。

### **利用**

既然是空指针解引用，ecx 指向tagPOPUPMENU 对象，所以方法很直接。通过分配零页内存，在零页上伪造tagPOPUPMENU对象，同时分配一个新窗口，通过翻转bServerSideWindowProc位使wndProc 在内核层执行从而进行提权。
