本周安全大事件

**美国空军情报中心上千页绝密文档外泄** |
| :-: |

|      据美媒福布斯报道，美国联邦调查局（FBI）正在调查一起严重的空中与太空情报部门信息泄露事件，该事件涉及到超过1000页高度敏感的绝密文件。据了解，此次泄露事件发生在俄亥俄州代顿市周边莱特-帕特森空军基地，被泄露的文件来自于NASIC，而NASIC是长期关注军事活动与技术的重要中心之一，掌握着很多珍贵情报。嫌疑人Kemp，是一名NASIC的承包商，于工作时打印了相关文件并直接带回家中“存放”。美方空军表示该承包商并未得到过挪用机密文件的授权，因此在将其带回家中之前必须想办法绕过安全检查站。现任大西洋理事会数字取证实验室主管的Brookie称，绝密资料泄露是一种非常严重的状况，背后几乎总是存在一定程度的预谋，而非一时冲动。因为这些材料都受到负责的多层系统严格保护。截止7月3日，FBI尚未进行任何回应。 |

**美国披露电网防护方案：拟采用 “倒退” 技术对抗电网网络攻击**

|

|

**英国航空公司将因数据泄露问题面临1.83亿英镑的创纪录处罚**

  

| 据媒体报道，英国数据监管机构近日宣布，针对英国航空公司去年数据泄露的安全事故，将对其处以1.83亿英镑的罚款处罚。在此起数据泄露中，英国航空公司泄露了50万名左右客户的信用卡信息、姓名、地址、旅游预订和登录信息。据BBC报道称，此次罚款处罚，将成为 ICO有史以来开出的最高罚单，远高于Facebook剑桥分析丑闻的50万英镑。 |

**MongoDB泄露了来自搜索引擎的1.88亿个人信息**

|   
6月18日，安全研究人员Bob Diachenko发现，某未受保护的数据库泄露了大量个人敏感数据，并且任何人都可以在未经身份验证的情况下访问这些数据。这些数据包含1.88亿个人信息，部分记录来自两家搜索引擎：LexisNexis和Pipl。其中Pipl被认为是世界上最大的人物搜索引擎。被泄露的信息的详细维度可查看原文。 |
