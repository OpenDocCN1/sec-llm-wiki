本周安全大事件

**Windows远程桌面服务远程代码执行漏洞预警** |
| :-: |

|      北京时间2019年5月15日微软发布补丁修复了CVE编号为CVE-2019-0708的Windows远程桌面服务（RDP）远程代码执行漏洞，该漏洞在不需要身份认证的情况下即可远程触发，危害与影响面极大。利用该漏洞，未经身份认证的攻击者可使用RDP协议连接到目标系统并发送精心构造的请求从而触发该漏洞。成功利用此漏洞的攻击者可在目标系统上进行执行任意代码、安装应用程序、操纵数据、创建完全访问权限的新账户等操作。根据奇安信全球鹰网络空间测绘服务分析，截止15日国内共有1543410台主机对外开放3389端口，可能会受到该漏洞影响。目前奇安信安全监测与响应中心已发布该漏洞安全预警通告，并提供针对该漏洞的专修工具。具体详情可点击图片查看原文。 |

**美国监管机构拒绝中国移动进入美国市场**

  

| 上周四美国监管机构拒绝了中国移动在美国市场运营并提供国际电信服务的要求，称其与中国政府的联系对美国国家安全构成了威胁。联邦通信委员会的声明表示，该决定是在与国家安全局和执法机构进行“广泛审查”和“密切磋商”之后做出的。同时该声明称，这也标志着美国行政机构首次建议联邦通信委员会因国家安全问题和执法问题拒绝他国申请。 |

**2019年第一季度数据泄露情况**

|   
根据Risk Based Security的数据，在今年的第一季度共有1903起公开披露的数据泄露事件，被泄露的数据超过19亿条，这是有记录以来最糟糕的第一季度。某公司执行副总裁兼网络风险分析主管Inga Goddijn称，今年第一季度的数据泄露数量，无论是因缺失密码、不安全服务还是凭证泄露导致的，都超过了以往。 |

**苹果设备存在无线漏洞，可被强行接入恶意热点**

|   
苹果设备在PEAP认证上存在的漏洞（CVE-2019-6203），可允许攻击者强行使苹果设备接入恶意热点，从而使用户的上网数据透明。该漏洞影响2019年3月25日以前的IOS、macOS、tvOS版本，包括MacBook、iPhone、iPad、Apple TV等多种苹果设备。在该漏洞的实际利用中，需要对信任证书进行交互，但绝大多数用户都会选择同意。 |

**Windows Server DHCP服务远程代码执行漏洞预警**

  

| 5月15日，微软发布补丁修复了一个存在于WindowsServer DHCP服务中的远程代码执行漏洞（CVE-2019-0725）。未经身份验证的远程攻击者通过构造恶意数据包并发送至受影响的目标系统，在成功利用该漏洞的情况下可在目标系统上执行任意代码并攻陷系统。奇安信安全监测与响应中心提醒广大用户及时进行自查和修复。 |

**优衣库遭黑客攻击46万客户信息遭泄露**

|   
5月13日，日本最大的服装连锁Fast Retailing（迅销集团）发布消息称，优衣库以及GU品牌的在线商城遭到黑客攻击，约46万用户的数据被泄露。在此次事件中被泄露的数据包括：用户姓名、详细地址信息、电话号码、电子邮箱、出生日期、历史订单、收件信息以及信用卡信息。优衣库官方次日表示，此次泄露事件不涉及中国区域的网站和平台。 |
