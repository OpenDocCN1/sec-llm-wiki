**漏洞描述**

  

Microsoft Windows Server DHCP服务存在远程代码执行漏洞，可能允许未经身份验证的远程攻击者通过构造恶意数据包并发送至受影响的目标系统，成功利用此漏洞的攻击者可在目标系统上执行任意代码并完全攻陷系统，该漏洞是因未能正确地处理网络数据包而导致。

  

**风险等级**

  

奇安信安全监测与响应中心风险评级为：高危

预警等级：蓝色预警（一般事件）

**处置建议**

  

**1\. 官方补丁**

l  微软官方已经推出安全更新，请参考以下官方安全通告下载并安装最新补丁：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2019-0725

  

**2\. 缓解建议**

l  微软官方尚未发布相关缓解措施，若暂时无法安装相应补丁，可参考思科给出的以下缓解建议：

*   建议管理员应仅允许受信任的用户进行网络访问。
    
*   建议管理员应同时运行防火墙和防病毒应用程序，以最大限度地降低入站和出站威胁的可能性。
    
*   管理员可以考虑使用基于IP的访问控制列表（ACL），仅允许受信任的系统访问受影响的系统。
    
*    管理员可以使用可靠的防火墙策略来帮助保护受影响的系统免受外部攻击。
    
*   建议管理员监测受影响的系统。
