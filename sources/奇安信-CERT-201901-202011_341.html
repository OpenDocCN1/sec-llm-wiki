2019年4月16日，Oracle官方发布2019年4月关键补丁更新公告，此次更新修复了297个不同程度的安全漏洞。其中包含Oracle Communications Unified InventoryManagement、Oracle WebLogic Server、Oracle Java SE等常用Oracle产品的高危漏洞，Oracle强烈建议用户尽快应用关键补丁更新修复程序，对漏洞进行修复。


奇安信安全监测与响应中心将持续关注该漏洞进展，并第一时间为您更新该漏洞信息。

CVE-2018-1258

Oracle  Communications Unified Inventory Management

Security  (Spring Framework)

此漏洞允许攻击者通过HTTP网络协议在低权限认证的前提下破坏Oracle  Communications Unified Inventory Management。成功攻击可能导致Oracle  Communications Unified Inventory Management被接管
