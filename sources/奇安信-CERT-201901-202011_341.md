尊敬的客户:

2019年4月16日，Oracle官方发布2019年4月关键补丁更新公告，此次更新修复了297个不同程度的安全漏洞。其中包含Oracle Communications Unified InventoryManagement、Oracle WebLogic Server、Oracle Java SE等常用Oracle产品的高危漏洞，Oracle强烈建议用户尽快应用关键补丁更新修复程序，对漏洞进行修复。

  

奇安信安全监测与响应中心将持续关注该漏洞进展，并第一时间为您更新该漏洞信息。

**漏洞描述**

  

在2019年4月16日，Oracle官方发布的关键补丁更新公告，提及了以下高危漏洞：

  

| **漏洞编号** || **影响产品** || **影响组件** || **危害** |
| --- | --- | --- | --- |
| **CVE-2018-1258** || Oracle  Communications Unified Inventory Management || Security  (Spring Framework) || 此漏洞允许攻击者通过HTTP网络协议在低权限认证的前提下破坏Oracle  Communications Unified Inventory Management。成功攻击可能导致Oracle  Communications Unified Inventory Management被接管 |
| **CVE-2019-2615** || Oracle  WebLogic  Server || WLS  Core Components || 此漏洞允许攻击者通过HTTP网络协议在高权限认证的前提下破坏Oracle  WebLogic Server。成功攻击可能导致未经授权访问关键数据或完全访问所有Oracle  WebLogic Server可访问的数据 |
| **CVE-2019-2618** || Oracle  WebLogic  Server || WLS  Core Components || 此漏洞允许攻击者通过HTTP网络协议在高权限认证的前提下破坏Oracle  WebLogic Server。成功攻击可能导致未经授权访问关键数据或完全访问所有Oracle  WebLogic Server可访问的数据以及未经授权更新、插入或删除某些Oracle  WebLogic Server可访问的数据 |
| **CVE-2019-2645** || Oracle  WebLogic  Server || WLS  Core Components || 此漏洞允许攻击者通过T3网络协议在未经身份认证的前提下破坏Oracle  WebLogic Server。成功攻击可能导致Oracle  WebLogic Server被接管 |

| **CVE-2019-2648** || Oracle  WebLogic  Server || WLS  - Web Services || 此漏洞允许攻击者通过HTTP网络协议在未经身份认证的前提下破坏Oracle  WebLogic Server。成功攻击可能导致未经授权访问关键数据或完全访问所有Oracle  WebLogic Server可访问的数据 |
| **CVE-2019-2649** || Oracle  WebLogic  Server || WLS  - Web Services || 此漏洞允许攻击者通过HTTP网络协议在未经身份认证的前提下破坏Oracle  WebLogic Server。成功攻击可能导致未经授权访问关键数据或完全访问所有Oracle  WebLogic Server可访问的数据 |
| **CVE-2019-2650** || Oracle  WebLogic  Server || WLS  - Web Services || 此漏洞允许攻击者通过HTTP网络协议在未经身份认证的前提下破坏Oracle  WebLogic Server。成功攻击可能导致未经授权访问关键数据或完全访问所有Oracle  WebLogic Server可访问的数据 |
| **CVE-2019-2658** || Oracle  WebLogic  Server || WLS  Core Components || 此漏洞允许攻击者通过HTTP网络协议在未经身份认证的前提下破坏Oracle  WebLogic Server。成功攻击可能导致Oracle  WebLogic Server被接管 |
| **CVE-2019-2568** || Oracle  WebLogic  Server || WLS  Core Components || 此漏洞允许攻击者通过HTTP网络协议在低权限认证的前提下破坏Oracle  WebLogic Server。成功攻击可能导致未经授权更新、插入或删除某些Oracle  WebLogic Server可访问数据 |
| **CVE-2019-2699** || Oracle  Java  SE || Windows  DLL || 此漏洞允许攻击者通过多种网络协议在未经身份认证的前提下破坏Java SE，攻击者也可以使用此漏洞影响其他产品 |
