**WinRAR被曝绝对路径穿越漏洞，5亿用户受影响** |
| :-: |

|      在全球都享誉盛名的必备装机软件WinRAR，近日被安全厂商checkpoint披露存在严重的绝对路径穿越漏洞（详见：《Extracting a 19 YearOld Code Execution from WinRAR》）。该漏洞存在于WinRAR里用于ace文件解析的UNACEV2.dll文件中。UNACEV2.dll文件在对解压目标的相对路径（filename）进行解析时，由于CleanPath函数过滤路径不严格而导致存在该漏洞。利用该漏洞，攻击者可以精心构造压缩文件将恶意文件加入系统开机启动项中，从而达到任意代码执行的目的，而在这个过程中，受害者可能只是仅仅进行了“提取文档”交互。根据披露该漏洞的安全研究人员的描述，该漏洞已存在超过了19年，全球约有5亿用户会受到该漏洞的影响。 |

**报告：5.9万GDPR数据泄露事件仅91起被处罚**

  

| 欧华律师事务所（DLA Piper）报告称：欧洲委员会官方统计数据显示，《通用数据保护条例》（GDPR）从2018年5月25日实施至2019年1月28日期间，共有41502起数据泄露被通报（仅包含欧盟成员国），但在上述时间段内，监管机构对GDPR违规行为作出处罚的仅有91起，这可能跟监管人员人手不足有关。 |

**印度国有天然气公司泄露了至少580万的Aadhaar 号码**

  

| 据国外媒体报道，印度天然气国有公司Indane泄露了数百万的Aadhaar号码。该数据泄露事故由一名不愿透露身份的安全研究人员发现，Indane数据库中的内容虽然需要通过用户名和密码才能访问，但该网站的部分内容已在Google索引中。据安全研究人员称，他使用了特定的脚本挖掘了11,000个经销商的数据，并估计至少有580万客户信息被泄露。 |

**黑吃黑，博彩网站篡改家用路由器DNS劫持违法网站**

|   
国家互联网应急中心（CNCERT）监测发现，境内部分用户通过家用路由器访问部分网站时被劫持到涉黄涉赌网站。CNCERT的通报称，黑客将家用路由的DNS地址恶意窜改到江苏及扬州等地的IP地址段的多个地址，从而将用户访问劫持到指定的博彩网站。在此次事件中，受影响的IP地址共有400万余个，被劫持的网站涉黄涉赌类域名达190个。 |

|

**马耳他最大银行遭遇黑客攻击，中断所有业务**

  

| 上周，马耳他最大银行瓦莱塔银行遭遇黑客攻击，攻击者试图盗取银行1300万欧元。据当地媒体称，攻击者将1300万欧元转入外国账户，并试图在英国、美国、捷克共和国和香港的银行转移该笔资金。在此次事件中，瓦莱塔银行于上周三早上关闭了所有业务（分支机构、ATM、手机银行、电子邮件服务等），直到周四才重新上线其移动应用程序。 |
