**安全通告**

  
  
Chrome是一款由Google公司开发的免费的、快速的互联网浏览器软件，目标是为使用者提供稳定、安全、高效的网络浏览体验。Google Chrome基于更强大的JavaScript V8引擎，提升浏览器的处理速度。支持多标签浏览，每个标签页面都在独立的“沙箱”内运行。  

  

近日，奇安信CERT监测到Google发布Chrome新版本，公开了已被在野利用的Chrome V8 类型混淆漏洞(CVE-2022-4262)。Chrome V8 存在类型混淆漏洞，攻击者可通过诱导用户打开恶意链接来利用此漏洞，从而在应用程序上下文中执行任意代码。**目前，此漏洞已检测到在野利用。****鉴于此漏洞影响范围较大，建议客户尽快做好自查及防护。**

处置建议

目前，Google Chrome已发布新版本（Google Chrome for Mac/Linux 108.0.5359.94、Google Chrome for Windows 108.0.5359.94/.95），建议用户尽快升级至最新版本。
