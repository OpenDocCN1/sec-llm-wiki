**风险通告**

  
  

近日，奇安信CERT监测到Apache 官方发布Apache HTTP Server 2.4.51版本，修复了Apache HTTP Server 2.4.49 和 2.4.50 版本中存在的路径遍历和远程代码执行漏洞，漏洞编号为CVE-2021-42013，官方定级为 Critical。  

  

Apache HTTP Server 存在目录遍历漏洞，攻击者可利用此漏洞将 URL 映射到由 Alias-like 指令配置的目录之外的文件。同时若Apache HTTPd开启了cgi支持，攻击者可构造恶意请求执行命令，控制服务器。此漏洞由Apache HTTP Server 2.4.49引入，但由于 2.4.50 版本中对 CVE-2021-41773 的修复不够充分，因而此漏洞影响 2.4.49 和 2.4.50 版本。经奇安信CERT验证，使用默认配置“require all denied”可保护这些目录之外的文件，不受此漏洞影响。**目前，这两个漏洞细节、POC及EXP均已在互联网上公开。**鉴于此漏洞影响较大，建议客户尽快自查修复。

漏洞描述

Apache HTTP 服务器项目致力于为现代操作系统（包括 UNIX 和 Windows）开发和维护开源 HTTP 服务器。该项目的目标是提供一个安全、高效且可扩展的服务器，该服务器提供与当前 HTTP 标准同步的 HTTP 服务。  

  

近日，奇安信CERT监测到Apache 官方发布Apache HTTP Server 2.4.51版本，修复了Apache HTTP Server 2.4.49 和 2.4.50版本中存在的路径遍历和远程代码执行漏洞，漏洞编号为CVE-2021-42013，官方定级为 Critical。此漏洞为CVE-2021-41773的补丁绕过，该漏洞由Apache HTTP Server 2.4.49 ap\_normalize\_path 函数引入，但2.4.50版本中对CVE-2021-41773的修复不够充分，此漏洞影响 2.4.49 和 2.4.50 版本，修复版本为2.4.51。
