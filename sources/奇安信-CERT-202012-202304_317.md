**风险通告**

  
  

近日，奇安信 CERT 监测到IOT INSPECTOR发布了多个Realtek SDK高危漏洞的漏洞细节和POC。“UDPServer”MP工具缓冲区溢出漏洞和任意命令执行漏洞（CVE-2021-35394），HTTP web 服务器“boa”缓冲区溢出漏洞（CVE-2021-35395）。鉴于漏洞危害较大，建议用户及时升级版本。

漏洞描述

近日，奇安信 CERT 监测到IOT INSPECTOR发布了多个Realtek SDK高危漏洞的漏洞细节和POC。“UDPServer”MP工具缓冲区溢出漏洞和命令执行漏洞（CVE-2021-35394），HTTP web 服务器“boa”缓冲区溢出漏洞（CVE-2021-35395）。鉴于漏洞危害较大，建议用户及时升级版本。  

****1、CVE-2021-35394********“****UDPServer****”****MP****工具缓冲区溢出漏洞和命令注入漏洞****

| **漏洞名称** || “UDPServer”MP工具缓冲区溢出漏洞和命令执行漏洞 |
| --- | --- |
| **漏洞类型** || 缓冲区溢出、命令注入 || **风险等级** || 紧急 || ****漏洞****I********D**** || CVE-2021-35394 |
| **公开状态** || 已公开 || **在野利用** || 未知 |
| **漏洞描述** || Realtek Jungle SDK v2.x 至 v3.4.14B 提供了一个名为“MP Daemon”的诊断工具，通常编译为“UDPServer”二进制文件。该二进制文件受多个内存损坏漏洞和任意命令注入漏洞的影响，远程未经身份验证的攻击者可以利用这些漏洞。 |
| **参考链接** |
| https://www.iot-inspector.com/blog/advisory-multiple-issues-realtek-sdk-iot-supply-chain |

 

****2****、****CVE-2021-35395 HTTP web ****服务器“****boa****”缓冲区溢出漏洞****

| **漏洞名称** || HTTP web 服务器“boa”缓冲区溢出漏洞 |
| --- | --- |
| **漏洞类型** || 缓冲区溢出 || **风险等级** || 紧急 || ****漏洞****I********D**** || CVE-2021-35395 |
| **公开状态** || 已公开 || **在野利用** || 未知 |
| **漏洞描述** || CVE-2021-35395：Realtek Jungle SDK 版本 v2.x 至 v3.4.14B 提供了一个 HTTP Web 服务器，公开了一个管理接口，可用于配置接入点。这个管理界面有两个版本：一个基于名为 webs 的 Go-Ahead，另一个基于名为 boa 的 Boa。它们都受到这些漏洞的影响。具体来说，这些文件容易受到以下问题的影响：1\. formRebootCheck/formWsc/formWlanMultipleAP 中“submit-url”参数的不安全复制；2\. formWlSiteSurvey 中“ifname”参数的不安全复制；3\. formStaticDHCP 中“主机名”参数的不安全复制；4\. formWsc 中“peerPin”参数的不安全复制，由于提交 url 参数的不安全复制，formRebootCheck 中的堆栈缓冲区溢出。 |
| **参考链接** |
| https://www.iot-inspector.com/blog/advisory-multiple-issues-realtek-sdk-iot-supply-chain |

  

  

风险等级

奇安信 CERT风险评级为：高危风险等级：蓝色（一般事件）

  

  

影响范围

Realtek SDK v2.x  

Realtek “Jungle” SDK v3.0

Realtek “Jungle” SDK v3.1

Realtek “Jungle” SDK v3.2

Realtek “Jungle” SDK v3.4.x

Realtek “Jungle” SDK v3.4T

Realtek “Jungle” SDK v3.4T-CT

Realtek “Luna” SDK <= 1.3.2

  

  

处置建议

尽快升级Realtek SDK到安全版本  

Realtek SDK分支2.x：Realtek不再支持

Realtek“Jungle”SDK：补丁由Realtek提供

Realtek“Luna”SDK：1.3.2a版包含修复
