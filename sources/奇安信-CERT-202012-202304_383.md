**致力于**第一时间为企业级用户提供安全风险**通告**和**有效**解决方案。

  
  
  

**风险通告**

  
  

近日，奇安信CERT监测到Apache OFBiz官方发布安全更新，修复了两个由Apache OFBiz反序列化造成的远程代码执行漏洞，漏洞编号分别为CVE-2021-29200、CVE-2021-30128。攻击者可通过构造恶意请求，触发服务端反序列化，从而执行任意代码。目前官方已有可更新版本，鉴于漏洞危害较大，建议用户及时安装更新补丁。

漏洞描述

Apache OFBiz是一个电子商务平台，用于构建大中型企业级、跨平台、跨数据库、跨应用服务器的多层、分布式电子商务类应用系统。近日，奇安信CERT监测到Apache OFBiz官方发布安全更新，修复了两个由反序列化造成的远程代码执行漏洞。漏洞编号分别为：CVE-2021-29200、CVE-2021-30128，攻击者可通过构造恶意请求，触发服务端反序列化，从而执行任意代码。  
  

其中CVE-2021-30128主要是针对Apache OFBiz 17.12.06版本中对反序列化漏洞防护方法（黑名单：屏蔽RMI相关的类；以及仅允许白名单中定义的类）的绕过。具体由于反序列化时，org.apache.ofbiz.base.util.SafeObjectInputStream#resolveClass方法中调用loadClass()方法加载类时，对序列化数据中的类描述符中 < 后面的内容进行截断，只取 < 前面的内容作为加载类的className，故利用这种处理方式可绕过其白名单的限制。

风险等级

奇安信 CERT风险评级为：高危风险等级：蓝色（一般事件）

  

  

影响范围

Apache OFBiz < 17.12.07

  

  

处置建议

升级到最新版本 Apache OFBiz 17.12.07，下载链接：https://archive.apache.org/dist/ofbiz/  

或根据以下链接手动更新补丁代码：

CVE-2021-29200：https://issues.apache.org/jira/browse/OFBIZ-12216

CVE-2021-30128：https://issues.apache.org/jira/browse/OFBIZ-12212

  

  

产品解决方案

**奇安信网神智慧防火墙产品防护方案**

奇安信新一代智慧防火墙（NSG3000/5000/7000/9000系列）和下一代极速防火墙（NSG3500/5500/7500/9500系列）产品系列，已通过更新IPS特征库完成了对该漏洞的防护。建议用户尽快将IPS特征库升级至” 2104291500” 及以上版本并启用规则ID: 1240201进行检测。

  

**奇安信网神网络数据传感器系统产品检测方案**

奇安信网神网络数据传感器（NDS3000/5000/9000系列）产品，已具备该漏洞的检测能力。规则ID为：6621，建议用户尽快升级检测规则库至2104291600以后版本并启用该检测规则。

  

**奇安信天眼产品解决方案**

奇安信天眼新一代威胁感知系统在第一时间加入了该漏洞的检测规则，请将规则包升级到3.0.0429.12814上版本。规则名称：Apache OFBiz 反序列化漏洞(CVE-2021-30128)，规则ID：0x10020D6C。奇安信天眼流量探针（传感器）升级方法：系统配置->设备升级->规则升级，选择“网络升级”或“本地升级”。

  

**奇安信网神统一服务器安全管理平台更新入侵防御规则库**

奇安信网神虚拟化安全轻代理版本将于4月29日发布入侵防御规则库2021.04.30版本，支持对Apache OFBiz 反序列化漏洞 CVE-2021-30128的防护，届时请用户联系技术支持人员获取规则升级包对轻代理版本进行升级。

奇安信网神统一服务器安全管理平台将于4月18发布入侵防御规则库10365版本，支持对Apache OFBiz 反序列化漏洞 CVE-2021-30128的防护，届时请用户联系技术支持人员获取规则升级包对融合版本进行升级。

  

**奇安信网站应用安全云防护系统已更新防护特征库**

奇安信网神网站应用安全云防护系统已全面支持对Apache OFBiz 反序列化漏洞 (CVE-2021-30128） 的防护。
