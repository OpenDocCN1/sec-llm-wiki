奇安信CERT

致力于第一时间为企业级用户提供安全风险通告和有效解决方案。


奇安信A-TEAM 团队专注于网络实战攻击研究、攻防安全研究、黑灰产对抗研究。早在Oracle第二季度关键补丁更新公告中，就被评为了“在线状态安全性贡献者”。A-TEAM 团队还曾多次率先提供Windows域、Exchange、Weblogic等重大安全问题的风险通告及可行的处置措施并获得官方致谢。


同时，A-TEAM 还是奇安信CERT的支撑团队，在Web渗透、互联网底层协议分析、APT攻防对抗，前瞻性攻防工具预研等方面均积累了丰富的实战经验。


奇安信A-TEAM团队，现多个岗位开放，期待你的加入。


01

漏洞分析岗


岗位描述

及时关注、跟进、挖掘最新的 Web 类漏洞，维护公司的漏洞情报库，为产品线防护能力与公司的实战攻防能力赋能，输出研究文章、演讲、报告等为团队及公司提升影响力。


岗位职责

1. 对最新的 Web 类漏洞进行及时的研判、分析、复现、PoC/Exp 与技术文章编写；

2. 对已爆出的影响面大的漏洞进行持续关注与跟进，维护团队的漏洞情报数据库；

3. 对影响面广的应用进行主动漏洞挖掘并产出高质量原创漏洞。


岗位要求

1.对安全有浓厚的兴趣和较强的独立钻研能力，有良好的团队精神；

2.理解常见安全漏洞产生原理及防范方法；

3.具有 Web 漏洞分析与挖掘能力；

4.了解至少一门编程语言，熟悉其主流应用与框架，具备较强的代码审计能力；

5.独立分析过公开漏洞，能快速输出漏洞利用EXP。


加分项

1.独立撰写过较深入的漏洞分析文章（附文章链接）；

2.独立开发过中大型项目（附GitHub链接或项目截图）；

3.独立挖掘过通用型漏洞（附CVE或CNVD编号）。



02

运营岗（内容运营，偏安全方向）


岗位职责

1.负责关注最新的安全动态，配合技术人员拟写重大漏洞\安全事件的紧急风险通告；

2.负责部门相关周期性报告的拟写；

3.负责部门新媒体方向的运营工作，文章发布、扩大部门影响力等；

4.负责审核技术人员的情报输出质量；

5.负责对部门业务进行运营和支撑。


岗位要求

1.运营基础扎实；

2.对信息安全行业有浓厚的兴趣或者有一定的了解；

3.熟练使用office等办公软件；

4.有良好的的沟通能力、良好的抗压能力，工作细心负责。


加分项（包括但不限于）

1.具备安全知识背景，信息安全相关行业优先；

2.能使用PS等图片和视频处理软件优先。



03

安全开发岗


岗位职责

1.负责开发内部业务支撑系统；

2.负责开发漏洞方面安全研究相关支撑系统和工具；

3.配合漏洞分析人员开发漏洞利用EXP等。


岗位要求

1. 熟练使用 Python/Go 常用框架，熟悉 Restful API；

2. 熟悉消息队列，有分布式开发/系统架构设计能力，熟悉 Linux 环境；

3. 熟练掌握常用关系型和非关系型数据库，MySQL/PostgreSQL/Redis 等；

4. 具有良好的数据结构/算法、网络、操作系统等计算机基础知识；

5. 有良好的编码习惯、较强的自我驱动能力；有独立工作和解决问题的能力；具备英文技术文档阅读能力。


加分项

1. 有安全相关背景；

2. 有前端相关开发能力；

3. 了解 ElasticSearch；

4. 对自己有较高的技术要求，对代码和设计质量有严格要求，重视 Code Review。
