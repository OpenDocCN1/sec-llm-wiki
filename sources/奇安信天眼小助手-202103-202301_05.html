高危Apache Log4j 远程代码执行漏洞-天眼检测方案

近日， Apache Log4j被发现存在一处任意代码执行漏洞，由于Apache Log4j2某些功能存在递归解析功能，攻击者可直接构造恶意请求，触发远程代码执行漏洞。


经奇安信CERT验证，Apache Struts2、Apache Solr、Apache Druid、Apache Flink等众多组件与大型应用均受影响，鉴于此漏洞危害巨大，利用门槛极低，奇安信CERT建议用户尽快参考缓解方案阻止漏洞攻击。


影响版本

Apache Log4j 2.x <= 2.14.1


漏洞描述


Apache Log4j 远程代码执行漏洞

由于Apache Log4j2某些功能存在递归解析功能，攻击者可直接构造恶意请求，触发远程代码执行漏洞。


奇安信天眼检测方案

奇安信天眼新一代安全感知系统已经在第一时间加入了该漏洞的检测规则，请将规则包升级到3.0.1210.13140或以上版本。


规则名称

规则ID

Apache Log4j 远程代码执行漏洞

0x10020E2E

Apache Log4j 远程代码执行漏洞

0x5e08

 

另外, 可以通过搜索历史告警0x5a7c，0x100207CD评估次漏洞是否被成功利用。


漏洞修复方案


1
升级到最新版本


请联系厂商获取修复后的官方版本：

https://github.com/apache/logging-log4j2


已发现官方修复代码，目前尚未正式发布：

https://github.com/apache/logging-log4j2/releases/tag/log4j-2.15.0-rc2或采用奇安信产品解决方案来防护此漏洞。


2
缓解措施


（1）jvm参数 -Dlog4j2.formatMsgNoLookups=true

（2）log4j2.formatMsgNoLookups=True

（3）系统环境变量 FORMAT_MESSAGES_PATTERN_DISABLE_LOOKUPS 设置为true

奇安信天眼流量探针（传感器）升级方法：

系统配置->设备升级->规则升级，选择“网络升级”或“本地升级”
