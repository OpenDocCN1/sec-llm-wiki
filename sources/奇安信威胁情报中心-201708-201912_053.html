 Donot APT组织伪装克什米尔新闻APP的攻击活动分析

披露时间：2019年9月10日

情报来源：

https://ti.qianxin.com/blog/articles/analysis-of-the-attack-activity-of-donot-apt-organization-(bornar-Insects)-camouflage-kmisch-news-app/

 

相关信息：

Donot“肚脑虫”（APT-C-35）是疑似具有南亚背景的APT组织，由奇安信威胁情报中心红雨滴团队（@RedDrip7）持续跟踪发现并命名，其主要针对巴基斯坦等南亚地区国家进行网络间谍活动。

此次发现的Donot新样本通过仿冒Kashmir News Service（克什米尔新闻服务）的APP“KNS”，诱骗用户安装使用。克什米尔新闻服务公司KNS是查谟和克什米尔的第一家在线新闻机构，成立于2002年1月，现已成为该州首屈一指，可信赖的双语，英语和乌尔都语新闻机构。

恶意APP运行以后，并没有以往的隐藏自身图标，而是通过仿冒Kashmir NewsService（克什米尔新闻服务）展现给用户一个完整的新闻APP功能，从而达到欺骗用户放心使用，更加安全的保存了自身。

样本运行以后会在后台，通过最新服务端（mangasiso.top）下发15种远控指令，其远控操作有：获取用户手机通话记录信息、获取用户手机通讯录信息、获取用户手机短信息、获取外置存储卡文件列表信息、获取WiFi、设备厂商等信息、获取用户地理位置信息、获取用户手机已安装软件列表等。

 境外APT 组织“响尾蛇”对我国发起攻击事件报告

披露时间：2019年9月6日

情报来源：

https://mp.weixin.qq.com/s/0iuuQ3As6zvImvGwPjUCaQ

 

相关信息：

近日，瑞星安全研究院捕获到两起针对中国的APT攻击事件，一起是针对各国驻华大使馆，另一起是针对某科技有限公司驻外代表处。攻击者利用Office远程代码执行漏洞（cve-2017-11882）通过钓鱼邮件等方式发起APT攻击，一旦有用户打开钓鱼文档，电脑就会被攻击者远程控制，从而被盗取如电脑系统信息、安装程序、磁盘信息等内部机密数据资料。

据瑞星安全研究院分析，虽然这两次攻击对象和内容不同，但通过对攻击者使用的技术手法来看，断定与APT组织“响尾蛇”有着莫大的关系，该组织以窃取政府，能源，军事，矿产等领域的机密信息为主要目的。此次的攻击事件以虚假邮件为诱饵，利用Office远程代码执行漏洞（cve-2017-11882），发送与中国驻外使馆与科技类企业相关的钓鱼邮件，其目的应以盗取我国重要机密数据、隐私信息及科技研究技术为主。

 疑似国际黑人产业组织TA505针对东亚国家的一些金融从业者发起的攻击报告

披露时间：2019年9月5日

情报来源：

https://www.antiy.net/p/report-on-attacks-launched-by-international-organizations-of-black-industry-to-target-some-financial-practitioners-in-east-asian-countries/

 

相关信息：

Antiy CERT于2019年2月13日至3月7日针对一些东亚国家（主要是日本和韩国）发现了几次大规模有组织的网络钓鱼攻击。这项活动涉及大量样本。电子邮件正文和攻击文件都是用日文和韩文写的。攻击的目的是提供远程访问特洛伊木马以利用僵尸网络获取利润。攻击者利用大量被盗电子邮件帐户向日本和韩国的商业公司和金融机构批量发送网络钓鱼电子邮件，提供带有恶意Excel 4.0宏的攻击文件，并传播FlawedAmmyy远程访问木马。

根据韩国安全从业人员的统计和分享，截至2月19日，超过9,000个韩国电子邮件帐户受到前两次网络钓鱼攻击的攻击。发件人姓名主要是“조효상”，少量是“정재민”。涉及的邮箱主要属于韩国金融企业和组织。有1,124个电子邮件地址用于发送网络钓鱼电子邮件。但是，针对日本的网络钓鱼电子邮件数量只有几百个，而且它们也针对商业公司。

通过分析遥控木马的命令功能和网络行为，判断为FlawedAmmyy遥控器。FlawedAmmyy Remote Control基于商业远程桌面软件Ammyy Admin V3 [6]泄露的源代码。功能包括远程桌面控制，远程文件管理，音频监控，击键记录和凭证被盗。带C2的样本的流量也显示了FlawedAmmyy远程控制木马的典型字段格式。

从攻击者的意图，风格，技术和战术过程以及使用的特洛伊木马，攻击可能由着名的黑人组织TA505发起。从目前的角度来看，这一事件是由一系列针对日韩金融业的大规模，有组织的黑暗行业活动引起的。攻击者的动机是为了获利而培育僵尸网络。TA505组织于2017年9月首次由Proofpoint公开。自2014年以来，它经常向世界各地的特定目标行业或地区发送个性化网络钓鱼邮件传递特洛伊木马，以通过非法渠道获取非法经济利益。

 OceanLotus APT攻击中国的最新样本分析

披露时间：2019年9月5日

情报来源：

https://www.antiy.net/p/the-latest-sample-analysis-of-oceanlotus-apt-attacks-against-china/

 

相关信息：

自2018年12月以来，安天CERT已经针对中国用户捕获了一些针对宏观文档的攻击样本。这些恶意文件在模糊文本的背景下伪造反病毒软件的安全检测结果，诱导受害者启用恶意宏代码，将Shellcode注入Word进程本身，最后解密并运行后门程序。

所有相关的攻击有效负载都是Word文档，但没有利用漏洞。相反，恶意宏代码嵌入其中，从而触发后续恶意行为并最终将后门植入目标主机。这是自该阶段以来的一种流行方式。为了使受害者能够启用宏代码，攻击者诱导用户通过欺骗性段落点击文档正文中的“启用内容”以触发恶意宏代码执行。

相关文档样本采用社会工程技术，假装是360防病毒软件的安全测试结果，并诱导受害者启用附加的恶意宏。后门将为受害主机生成指纹。它的功能包括：进程操作，注册表操作，获取硬盘信息，本地文件操作，释放和执行程序，内存注入等。

 Stealth Falcon：针对中东的政治活动家和记者的APT组织

披露时间：2019年9月9日

情报来源：

https://www.welivesecurity.com/2019/09/09/backdoor-stealth-falcon-group/

 

相关信息：

Stealth Falcon自2012年以来一直活跃，主要针对中东的政治活动家和记者。ESET称安全研究人员根据2016年发布的该组织网络攻击分析报告以及路透社于2019年1月发布了一份关于Project Raven 的调查报告表明Stealth Falcon和Project Raven实际上属于同一组。

CitizenLab发现的攻击的关键部分是通过包含在恶意电子邮件中的武器化文档提供PowerShell的后门。目前ESET的研究人员发现了一个新的二进制后门，该二进制后门和PowerShell脚本的后门共享相同的C＆C服务器，两者之间尽管使用了不同的编译语言，但是底层逻辑相同，内部使用的硬编码标识符有重叠之处，也同样使用硬编码密钥为RC4进行加密。

披露时间：2019年8月9日

情报来源：

https://www.fortinet.com/blog/threat-research/new-infostealer-attack-uses-lokibot.html

参考链接：

 微软远程桌面服务远程代码执行漏洞（CVE-2019-0708）预警通告

披露时间： 2019年9月9日

情报来源：

https://ti.qianxin.com/advisory/articles/microsoft-remote-desktop-services-remote-code-execution-vulnerability-(cve-2019-0708)-alert-notice/

 

相关信息：

2019年05月15日，微软公布了5月的补丁更新列表，在其中存在一个被标记为严重的RDP（远程桌面服务）远程代码执行漏洞，攻击者可以利用此漏洞远程无需用户验证通过发送构造特殊的恶意数据在目标系统上执行恶意代码，从而获取机器的完全控制。此漏洞主要影响的设备为Windows 7、Window Server 2008以及微软已不再支持的Windows 2003、Window XP操作系统，涉及系统在国内依然有大量的使用。至2019年9月7日，已有可导致远程代码执行的Metasploit模块公开发布，随着工具的扩散，已经构成了蠕虫级的现实安全威胁。

到2019年9月7日，奇安信全球鹰系统评估互联网上国内可被直接攻击的受影响RDP服务器还有10万量级。

受影响系统及应用版本

Windows 7 forx64-based Systems Service Pack 1

Windows Server2008 for 32-bit Systems Service Pack 2

Windows Server2008 for 32-bit Systems Service Pack 2 (Server Core installation)

Windows Server2008 for Itanium-Based Systems Service Pack 2

Windows Server2008 for x64-based Systems Service Pack 2

Windows Server2008 for x64-based Systems Service Pack 2 (Server Core installation)

Windows Server2008 R2 for Itanium-Based Systems Service Pack 1
