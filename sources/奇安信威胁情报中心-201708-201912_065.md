攻击团伙情报

 

1

 Bitter针对中国政府和组织的钓鱼攻击  

披露时间：2019年8月8日

情报来源：

https://www.anomali.com/blog/suspected-bitter-apt-continues-targeting-government-of-china-and-chinese-organizations

 

相关信息：

Anomali威胁研究小组发现了一个网络钓鱼网站冒充中华人民共和国外交部电子邮件服务的登录页面。当访问者尝试登录欺诈页面时，会向他们显示弹出验证消息，要求用户关闭他们的窗口并继续浏览。Anomali对Bitter基础设施的进一步分析发现大约有40个钓鱼网站。从其用到的证书发现该攻击活动应该是从2019年5月左右开始的。

网络钓鱼网站有6个域和40多个子域，具体针对性攻击的网站包括四个中华人民共和国政府机构网站，六个国有企业网站，一家香港拍卖行以及两个电子邮件服务提供商。

  

2

 VenusLocker组织正在利用垃圾邮件分发Sodinokibi勒索软件  

披露时间：2019年8月12日

情报来源：

https://blog.alyac.co.kr/2469

 

相关信息：

ESRC发现VenusLocker组织正在利用垃圾邮件分发Sodinokibi勒索软件，恶意邮件伪装成申请工作邮件。当收到邮件的用户被误认为正常文件并解压压缩文件时，会释放伪装成PDF文件的可执行文件，可执行文件名称中插入了大量的空格来误以为文件格式为PDF，实则该文件为可执行文件。

  

3

 近期Cloud Atlas攻击活动  

披露时间：2019年8月12日

情报来源：

https://securelist.com/recent-cloud-atlas-activity/92016/

 

相关信息：

    CloudAtlas使用鱼叉网络钓鱼电子邮件来攻击受害者，恶意文档托管在远程服务器上的恶意远程模板。旧版本的Cloud Atlas利用过CVE-2018-0802与CVE-2017-11882漏洞，还是用 PowerShell部署一些文档窃密模块，系统环境侦察模块以及系统密码窃取模块。在新版本中Cloud Atlas不再依赖PowerShower，而是执行托管在远程服务器上的HTA，用于在本地系统上释放三个不同的文件：VBShower后门，VBShower启动器以及HTA文件。

  

攻击行动或事件情报

 

1

 针对法国人的恶意软件分发垃圾邮件攻击活动  

披露时间：2019年8月8日

情报来源：

https://www.welivesecurity.com/2019/08/08/varenyky-spambot-campaigns-france/

 

相关信息：

在2019年5月，ESET研究人员发现了分发各类垃圾邮件的恶意软件。其中一个是导致一项调查重定向到一个狡猾的智能手机促销，而另一个是一个sextortion活动。垃圾邮件针对的是法国ISP的Orange SA用户。

该垃圾邮件可以窃取密码，当他们在线观看色情内容时使用FFmpeg监视其受害者的屏幕，并且通过Tor完成与C＆C服务器的通信，攻击者最终的目的可能是通过对观看色情内容的用户进行勒索或敲诈。

邮件中的Office文档中有恶意的宏代码，当宏代码执行之后会根据计算机的区域设置过滤掉非法国受害者，随后从服务器下载和执行恶意软件。

  

恶意代码情报 

1

 知道创宇404实验室对某次攻击样本分析  

披露时间：2019年8月12日

情报来源：

https://paper.seebug.org/1011/

 

相关信息：

攻击者通过发送鱼叉式钓鱼邮件，配合社会工程学手段诱导用户运行宏代码，进而下载尾部带有恶意payload压缩包的可执行文件。通过层层释放最终运行可窃取受害人员各类机密信息、维持权限、接收远端控制的木马。

文档打开后，会诱导用户需要开启宏才能查看被模糊的图片，用户点击开启宏之后该宏代码作为实施攻击的入口，实现了恶意样本的下载和执行。会释放多个可执行文件以及Autolt脚本，Autolt脚本包含的功能有检测运行环境、修改注册表、解密最终的.net木马。恶意样本将会在用户电脑上运行、潜伏、收集相应的信息、等待攻击者的进一步指令。

2

 PsiXBot使用短链接搜索DNS服务器地址  

披露时间：2019年8月13日

情报来源：

https://www.proofpoint.com/us/threat-insight/post/psixbot-continues-evolve-updated-dns-infrastructure

 

相关信息：

Proofpoint的研究人员发现PsiXbot（v1.0.2）的另一个新版本，PsiXbot被攻击者利用恶意垃圾邮件分发，恶意软件将检查受感染机器的语言版本，如果当前语言是俄语PsiXbot将退出。

PsiXbot利用通过URL缩短服务创建的URL来收集每个域的DNS服务器地址。解析获取得到了服务器地址之后，会请求后续命令，命令中可能会包含要执行命令的Json体，解析之后执行相应的控制命令。新版本PsiXBot包含多个模块，包括删除僵尸网络进程、监视剪贴板中加密货币钱包地址并窃取、表单抓取、使用Microsoft Outlook发送出站电子邮件等功能。

  

漏洞情报 

1

 Microsoft Windows RDP远程桌面服务多个远程代码执行漏洞通告  

披露时间：2019年8月14日

情报来源：

[https://mp.weixin.qq.com/s/wtApYzTzJ9wJNPcD-Z0Hng](https://mp.weixin.qq.com/s?__biz=MzI2MDc2MDA4OA==&mid=2247489065&idx=2&sn=463d8263dacf156862a1c010c646a603&scene=21#wechat_redirect)

参考链接：

https://cert.360.cn/warning/detail?id=7397733e4f19c6aca5f6191559173dc2

 

相关信息：

2019年8月13日，微软发布了8月例行补丁更新列表，其中包含四个威胁评级为严重的RDP（远程桌面服务）远程代码执行漏洞。攻击者可以通过构造恶意特殊的RDP请求触发漏洞，获取在目标系统上的远程代码执行权限。需要注意的是从微软公告中来看，该漏洞为预身份验证，即无需用户交互（即利用的要求可能较低），这意味着该漏洞有可能被蠕虫所利用，其中漏洞CVE-2019-1181/CVE-2019-1182是微软在升级加固远程桌面服务期间所发现。目前，没有证据表明任何第三方都知道这两个漏洞的存在，但随着漏洞补丁的发布技术细节极有可能被包括攻击者在内的第三方所分析了解。

奇安信威胁情报中心红雨滴团队第一时间跟进了这些漏洞，从目前来看该漏洞主要影响Windows主流操作系统(详见漏洞概要)，而Windows XP、Windows Server 2003和Windows Server 2008不受影响，远程桌面协议(RDP)本身也不受影响。
