 PoshAdvisor后门更新迭代 - 疑似TA555针对乌克兰国家边防卫队的最新

披露时间：2019年7月31日

情报来源：

https://mp.weixin.qq.com/s/xzO3pG45CNN-HGKDokI92A

 

相关信息：

近日，奇安信威胁情报中心红雨滴团队在日常的样本监测过程中，捕获一例针对乌克兰国家边防卫队伊斯梅尔支队的攻击样本，该样本伪装成乌克兰国家财政局进行鱼叉邮件投递，诱导受害者启用带有恶意宏代码的附件文档。一旦恶意宏代码得以执行，便会在受害者机器上运行PoshAdvisor恶意软件，从而控制受害者计算机。

本次攻击活动的诱饵文档与之前TA555的文档基本一致，获取系统信息powershell代码与TA555基本一致。经关联分析，红雨滴团队安全研究员发现本次攻击活动实现的后门与2018年proofpoint披露的TA555组织的PoshAdvisor后门基本一致，只是在功能上更加完善丰富，因此我们认定本次攻击活动幕后团伙是TA555的可能性极大。

在以往的攻击活动中，该组织的目标通常为酒店，餐厅，电信行业，本次攻击活动是该组织第一次针对政府机构的活动。

 商贸信家族新活跃：利用钓鱼邮件传播商业远控木马RevetRAT

披露时间：2019年7月30日

情报来源：

https://s.tencent.com/research/report/767.html

参考链接：

https://s.tencent.com/research/report/770.html

https://s.tencent.com/research/report/766.html

 

相关信息：

近期腾讯安全御见威胁情报中心发现商贸信开始传播商业远控木马RevetRAT。黑客精心构造的带有宏代码的xls文档，作为邮件附件发送至外贸从业人员的邮箱。当文档被打开时，宏代码执行并获取保存在代码托管平台pastebin上的远程恶意代码，代码执行后继续下载pastebin上保存的二进制数据，然后将其还原成PE文件(远控木马RevetRAT)，然后注入Powershell进程执行。攻击过程无文件落地，中招后会窃取用户隐私信息泄露，同时开启后门。从而造成严重影响。

RevetRAT会创建互斥体以保证在电脑上执行时具有唯一实例，通过创建计划任务以达到持久化。其接收的C2指令功能包括下载文件、执行文件、更新以及暂停，重新启动和卸载自身。还会收集包括本地IP地址，电脑名称，用户名，操作系统，物理内存，安全软件等信息并发送到远程服务器。

 Guildma RAT分析

披露时间：2019年7月24日

情报来源：

https://decoded.avast.io/threatintel/deep-dive-into-guildma-malware/

 

相关信息：

Avast的研究人员称Guildma背后的网络犯罪分子主要集中针对巴西用户，但自2019年5月以来，他们已经扩大了攻击目标范围，现在针对全球130多家银行和75家其他网络服务公司。

Guildma通过网络钓鱼电子邮件进行传播，这些邮件包括发票，税务报告，邀请函以及包含带有恶意LNK文件的ZIP附件的类型邮件。当用户打开恶意LNK文件时，它会滥用Windows ManagementInstrumentation命令行工具并以静默方式下载恶意XSL文件。XSL文件下载Guildma的所有模块并执行第一阶段加载器，该加载器随后会加载其余恶意模块。最终恶意软件等待来自C＆C服务器的命令。恶意软件作者在Guildma的长期存在期间使用了大量的域，各种感染和窃取技术以及不同编程语言（Delphi，JS，VBS等）编写的网络攻击武器。

 Java ATM恶意软件

披露时间：2019年7月30日

情报来源：

https://blog.yoroi.company/research/java-amt-malware-the-insider-threat-phantom/

 

相关信息：

ZLAB-YOROI最近捕获到了一个很可能与最近针对银行业的网络犯罪行为有关的样本。该恶意样本可以与自动柜员机进行交互，能够访问自动提款机硬件并从ATM中窃取现金。

恶意软件使用Java Instrumentation技术来操纵合法的基于Java的ATM管理软件的控制流程。它执行的第一个操作是识别ATM软件使用的正确运行的Java虚拟机（JVM）。一旦识别出目标JVM，恶意软件就会使用“ vm.loadAgent（path_to_jar，options） ”方法强制在其中加载Java代理。加载器使用嵌入其中的“ MANIFEST.MF”文件识别指定JAR文件中的代理类，然后将类加载到目标JVM的上下文中。该样本还有一个HTTP服务器，用来充当攻击者和受攻击的ATM之间的接口。

MyDoom蠕虫持续活跃

披露时间：2019年7月26日

情报来源：

https://unit42.paloaltonetworks.com/mydoom-still-active-in-2019/

 

相关信息：

MyDoom的传播方法是通过使用SMTP的电子邮件。Unit42将包含MyDoom附件的电子邮件与包含任何类型恶意软件附件的电子邮件进行了比较。在2015年到2018年的四年间，平均有1.1％的恶意电子邮件包含MyDoom。在同一时期审查个别恶意软件样本时，MyDoom对通过恶意电子邮件看到的所有个别恶意软件附件平均持有21.4％。

与2018年相比，MyDoom活动2019年的前六个月显示出相似的平均值，电子邮件和恶意软件样本的比例略高。2019年1月至6月MyDoom发送的电子邮件大约有465896封。其中受影响最大的国家和地区包括中国、美国、中国台湾、德国、日本、新加坡、大韩民国、罗马尼亚、澳大利亚以及英国。针对的行业包括高科技、批发和零售、医疗保健、教育、制造业、专业和法律服务、电信、财务、运输和物流以及保险。

 Mirai使用Tor隐藏通信

披露时间：2019年7月31日

情报来源：

https://blog.trendmicro.com/trendlabs-security-intelligence/keeping-a-hidden-identity-mirai-ccs-in-tor-network/

 

相关信息：

    趋势科技发现了一个新的Mirai样本，与以前的Mirai变种一样，可以使攻击者通过IP摄像头和DVR等物联网设备中的暴露端口和默认凭据进行远程访问和控制，并允许攻击者通过各种方法（如用户）使用受感染设备进行分布式拒绝服务攻击数据报协议UDP攻击。然而，与之前的变体相比，趋势发现这个样本不同，因为网络犯罪分子使用的命令和控制（C＆C）服务器在Tor网络中匿名。进一步分析发现恶意软件从列表中选择随机服务器作为代理，开始与socks5的连接并查询它以将数据包中继到地址为Tor的C＆C服务器。如果无法建立中继连接，它将使用另一个代理服务器尝试该过程。

 RTOS VxWorks 多个高危漏洞预警

披露时间：2019年7月31日

情报来源：https://cert.360.cn/warning/detail?id=74859e930c98a2b18e4f3f13e299fd30

 

其他参考链接：

https://armis.com/armis-discovers-vulnerabilities-in-vxworks-in-critical-devices/

 

https://armis.com/urgent11/

 

相关信息：

Armis研究人员在VxWorks中发现了11个零日漏洞，VxWorks是最受欢迎的实时操作系统（RTOS），被超过20亿台设备使用，包括工业，医疗和企业设备等关键任务设备。这些漏洞被称为'URGENT / 11'，存在于IPnet，VxWorks的TCP / IP堆栈中，影响了过去13年的版本，并且是影响操作系统的漏洞的罕见示例。在其32年的历史中，MITER仅列出了13个影响VxWorks的CVE，其中没有一个像URGENT / 11那样严重。近年来，广泛使用的TCP/IP栈实现中的漏洞变得极其罕见，尤其是那些能够在目标设备上实现远程代码执行的漏洞。这种类型的漏洞是攻击者的圣杯，因为它们不依赖于特定应用程序，只要求攻击者能够通过网络访问目标设备。当在TCP实现中发现这样的漏洞时，它们甚至可以被用来绕过防火墙和NAT解决方案，因为它们隐藏在看起来无害的TCP流量中。URGENT/11漏洞影响自6.5版以上的所有VxWorks版本。

 Linux本地提权漏洞(CVE-2019-13272)

披露时间：2019年7月31日

情报来源：

https://mp.weixin.qq.com/s/LvwQpkj7druS88a9TwPJfQ

 

相关信息：

2019年07月20日，Linux正式修复了一个本地内核提权漏洞。通过此漏洞，攻击者可将普通权限用户提升为Root权限。

当调用PTRACE_TRACEME时，ptrace_link函数将获得对父进程凭据的RCU引用，然后将该指针指向get_cred函数。但是，对象struct cred的生存周期规则不允许无条件地将RCU引用转换为稳定引用。

PTRACE_TRACEME获取父进程的凭证，使其能够像父进程一样执行父进程能够执行的各种操作。如果恶意低权限子进程使用PTRACE_TRACEME并且该子进程的父进程具有高权限，该子进程可获取其父进程的控制权并且使用其父进程的权限调用execve函数创建一个新的高权限进程。

攻击者最终控制具有高权限的两个进程ptrace关系，可以被用来ptrace suid二进制文件并获得root权限。

目前受影响的Linux内核版本：Linux Kernel < 5.1.17。
