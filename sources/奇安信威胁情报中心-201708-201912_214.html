Sidewinder：使用全新的攻击脚本

披露时间：2018年10月18日

情报来源：

https://medium.com/@Sebdraven/apt-sidewinder-changes-theirs-ttps-to-install-their-backdoor-f92604a2739

 

相关信息：

APT组织Sidewinder放弃了以前在HTA中使用的Powershell脚本，投入使用了新的Vbs编写的攻击脚本。

HTA中会检测是否存在杀毒软件，如果存在则退出下一步的感染行动。如果没有杀软则后续就会通过cmd来执行后门程序，并将其写入注册表自启动以达到持久攻击的目的。

Cylance发布“海莲花”SpyRAT的分析报告

披露时间：2018年10月12日

情报来源：

https://www.cylance.com/content/dam/cylance-web/en-us/resources/knowledge-center/resource-library/reports/SpyRATsofOceanLotusMalwareWhitePaper.pdf

参考链接：

https://threatvector.cylance.com/en_us/home/report-the-spyrats-of-oceanlotus.html

 

相关信息：

在2017年年末Cylance发现了OceanLotus的几个定制后门以及该组织使用CobaltStrike Beacon攻击载荷执行C2的样本。OceanLotus通常会使用PowerShell来下载和部署恶意软件以及各种漏洞利用工具包。其中PE和ShellCode的加载器可以在内存中直接执行代码而不占用磁盘空间。

OceanLotus使用的恶意软件协议针对不同的目标而定，从原始套接字到Http/Https。其中该组织定制的RAT中Roland，Remy和Splinter包含许多相似性的代码。

Cylance一共发现了8个后门程序，并对各后门支持的控制命令、通信协议以及文件特征进行了分析。

Lazarus：Battle Cruiser攻击活动

披露时间：2018年10月23日

情报来源：

http://blog.alyac.co.kr/1945

http://sfkino.tistory.com/71

 

相关信息：

Lazarus本次投递的恶意文件名为"국가핵심인력등록관리제등검토요청(10.16)(김경환변호사).hwp"。Hwp文件是韩国国内使用较多的文档编辑工具。

该HWP文档中包含一个“Bin0001.ps”的流数据，该数据中有一个恶意的PostScript代码，如果解压出压缩代码会看到其中的ShellCode代码。当恶意脚本被执行时，恶意脚本打印普通文档内容并将用户伪装成普通文档文件。文件包括国家核心技术人力资源登记管理系统的内容，并包括韩国特定律师的姓名。当ShellCode 执行之后从服务器下载“battle32.avi”、 “battle64.avi”、 “akism1.pgi”和“akism2.pgi”，通过异或解密为可正常执行的DLL文件。

DarkPulsar：涉及核能、电信、IT和航空航天的APT攻击

披露时间：2018年10月19日

情报来源：

https://securelist.com/darkpulsar/88199/

 

相关信息：

卡巴斯基通过对NSA泄漏的网络攻击武器DanderSpritz和FuzzBunch中的常量数据进行跟踪发现了x86和x64版本的后门，这些后门程序感染了大约50个位于俄罗斯、伊朗和埃及的Windows2003和Windows2008的服务器，受害者涉及核能、电信、IT、航空航天和研发。

Darkpulsar通过两个无名函数在系统中安装后门，通过与TSPI以及SSPI相关的函数名称来实现自启动以及加载攻击载荷。通过调用具有管理员权限的Secur32.AddSecurityPackage参数为后门路径来启动后门，从而使lsass.exe将DarkPulsar加载为SSP / AP并调用其导出函数SpLsaModeInitialize。AddSecurityPackage会将代码注入到lsass.exe。在HKLM \ Software \ Microsoft \ Windows \ CurrentVersion \ Telephony \Providers中添加了后门DLL，在RasMan启动的时候便会加载该DLL。Darkpulsar还能够将恶意软件流量嵌入到系统协议中，它使用协议保留的系统端口，而不会妨碍系统正常运行。

TRITON：针对工控系统的入侵活动相关信息的扩展

披露时间：2018年10月23日

情报来源：

https://www.fireeye.com/blog/threat-research/2018/10/triton-attribution-russian-government-owned-lab-most-likely-built-tools.html

参考链接：

https://www.fireeye.com/blog/threat-research/2017/12/attackers-deploy-new-ics-attack-framework-triton.html

 

相关信息：

FireEye称针对工控系统(ICS)的入侵活动TRITON背后收到俄罗斯政府中央化学与力学研究所（CNIIHM又名ЦНИИХМ）的支持。

FireEye发现了很可能支持TEMP.Veles活动的恶意软件开发活动。这包括测试多个版本的恶意软件，其中一些版本在TRITON入侵期间由TEMP.Veles使用。

FireEye对TRITON与CNIIHM之间的关联概述如下：

对此测试活动的调查显示CNIIHM和莫斯科特定人士的多重特定联系。

TEMP.Veles已经将注册到CNIIHM的IP地址用于多种攻击目的，包括监控TRITON的覆盖，网络侦察和支持TRITON入侵的恶意活动。

在TEMP.Veles活动中观察到的行为模式与CNIIHM所在的莫斯科时区一致。

FireEye还推断CNIIHM可能拥有必要的机构和人员，以协助TRITON和TEMP.Veles业务的安排和发展。

Promethium：针对土耳其、叙利亚和埃及的恶意软件

披露时间：2018年10月23日

情报来源：

https://threatvector.cylance.com/en_us/home/whack-a-mole-the-impact-of-threat-intelligence-on-adversaries.html

 

相关信息：

Promethium又名StrongPity，主要是针对土耳其和叙利亚。Citizen Lab’s

的安全研究人员经过分析得出曾经被ESET报道的Promethium恶意软件还针对埃及发起攻击。

Cylance发现Promethium又开始更新了域名和IP，文件名称做了修改，部分代码也做了混淆。

“netplvliz.exe”会作为服务安装在系统中，该文件主要作用是启动真正执行恶意操作的文件“IpeOve32.exe”。新的Dropper还使用了Powershell来修改Windows10上Windows Defender的默认行为。
