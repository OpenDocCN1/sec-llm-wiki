 Silence APT组织针对全球25个国家银行的攻击行动 
 

披露时间：2018年9月5日

情报来源：

https://securityaffairs.co/wordpress/75921/apt/silence-group-apt.html

参考链接:

https://www.bleepingcomputer.com/news/security/white-hats-go-rogue-attack-financial-institutions/

攻击目标： 银行

主要攻击目的： 收集银行凭证及资金窃取

 

相关信息：

Group-IB的研究人披露了Silence APT组织。有证据表明该组织曾针对全球25个国家的银行展开过APT攻击。Silence从2017年至今窃取的金额不断增加,目前已确认的盗窃金额已达到80万美元。

Group-IB最早是在2016年发现的Silence的攻击活动，该组织曾通过AWS CBR取款，但是由于一些原因未能成功。2017年，Silence开始针对ATM发起攻击，并盗取了10万美金。2018年使用Supply-Chian攻击在一夜之间盗走了ATM机上的10万美金，两个月之后又盗走了大约15万美金。

与大多数网络犯罪组织一样，Silence使用网络钓鱼邮件进行攻击，其中使用了CVE-2017-0199，CVE-2017-11882 + CVE-2018-0802，CVE-2017-0262和CVE-2018-8174的漏洞。他们注册了钓鱼域名并创建自签名的证书，以银行员工的名义发送钓鱼邮件。在俄罗斯和荷兰租用服务器，在乌克兰租用了服务器作为C&C服务器，这些服务器已在2018年5月被欧洲警察封锁。

研究人员还发现该组织利用了APT28使用过的漏洞，对其修改之后用于进行攻击。

Cobalt Group针对俄罗斯和东欧金融机构的攻击活动

披露时间：2018年8月30日

情报来源：

https://asert.arbornetworks.com/double-the-infection-double-the-fun

攻击目标： 银行及金融机构

 

相关信息：

Cobalt Group自2016年至少开始活跃，涉嫌在数十个国家发起攻击。该组主要针对金融机构，通常使用ATM恶意软件。研究人员还认为，他们应对SWIFT银行系统的一系列攻击负责，该系统对受影响的实体造成数百万美元的损失。

研究人员发现Cobalt Group针对俄罗斯和罗马尼亚的钓鱼攻击，钓鱼邮件中有两个恶意URL，其中一个是包含VBA脚本的Word文档，一个是带有jpg后缀名的二进制文件。Word文档通过有道用户运行宏运行，通过VBA脚本下载攻击载荷。通过对二进制文件的比较ASERT称带jpg后缀的二进制文件则和Cobint后门软件及其相似。

 Urpage:一个与Bahamut,Confucius和Patchwork都存在关联的新组织
 

披露时间：2018年8月29日

情报来源：

https://blog.trendmicro.com/trendlabs-security-intelligence/the-urpage-connection-to-bahamut-confucius-and-patchwork/

组织名称:  Urpage

 

相关信息:

趋势科技将一个与Bahamut, Confucius和Patchwork都存在关联的新组织命名为Urpage。

该组织利用乌尔都语和阿拉伯语的文字处理器InPage的漏洞发起攻击。

Urpage与Bahamut使用的部分恶意Android样本存在相似性。其中一些C＆C网站充当网络钓鱼网站，诱导用户下载并执行，也有获取MAC地址、短信 、联系人窃取、录音、GPS定位等功能,且他们加密的过程也极为相似。除了充当C＆C并分发类似Bahamut的恶意软件之外，其中一些网站还充当其他恶意文档的主机。

Urpage与Confucius拥有相同的Delphi文件窃取程序，还有两个利用不同漏洞的恶意RTL文件，下载两个Base64编码的URL，其中一个URL用于下载诱饵文档，而另一个用于下载有效攻击载荷。

Patchwork与前两者相似也是使用的Delphi窃取文件，其Android恶意代码类似于Bahamut，趋势认为他们三者存在关联性。

研究人员通过Urpage使用的域名(pikrpro.eu及其子域islamicfinderfeedback .pikrpro .eu和memrifilesforinfo.pikpro.eu)认为攻击目标似乎为中东的用户和伊斯兰教信仰者。

 卡巴斯基检测到Andriod间谍软件BusyGasper

披露时间：2018年8月29日

情报来源：

https://securelist.com/busygasper-the-unfriendly-spy/87627/

恶意代码名称：BusyGasper

 

恶意代码描述：

在2018年初卡巴斯基通过移动入侵检测技术检测到Android间谍软件BusyGasper。

研究人员通过对样本分析，发现该恶意软件是一个未知的恶意软件家族。其功能包括设备传感器监听和运动检测器，支持多种协议，其命令大约有100个，包括在Android恶意软件中很少见到的IRC协议。BusyGasper能够从消息应用程序（WhatsApp，Viber，Facebook）中提取数据，收集用户点击的屏幕坐标位置,并转换为相应的字符。可从自己的C&C服务器下载或更新攻击载荷，而其FTP服务器属于免费的俄罗斯网络托管服务Ucoz。此外，该恶意软件可以登录攻击者的电子邮件收件箱，在特殊文件夹中解析电子邮件以获取命令，并通过电子邮件附件将任何攻击载荷保存到设备中。大约从2016年5月至今，该软件一直处于活跃状态。

从C&C服务器上下载的模块功能有:屏幕截图、隐藏图标、执行shell、转发控制命令给其他模块、将命令写日志、复制特定组件到系统目录、使用Root权限、键盘记录等功能。

研究人员还发现了有关”华硕”固件的文件名,这表明该攻击软件可能对”华硕”相关产品相当感兴趣。

研究人员从邮箱账户中收集的信息发现了更多受害人的信息,包括很多即时通信软件的信息，这其中包括使用Sqlite3存储的基于网络的位置数据、基于GPS的位置信息、短信、FaceBook消息、Viber消息以及WhatsApp的消息。

 伊朗APT组织OilRig使用的OopsIE木马的更新

披露时间：2018年9月4日

情报来源：

https://researchcenter.paloaltonetworks.com/2018/09/unit42-oilrig-targets-middle-eastern-government-adds-evasion-techniques-oopsie/

攻击目标： 中东地区政府机构

 

攻击TTP总结：

2018年7月OilRig针对中东政府机构发起鱼叉攻击，电子邮件主题是阿拉伯语翻译为”业务连续性管理培训”，并将OopsIE作为攻击载荷。

此次攻击中使用的OospIE通过WMI查询风扇、CurrentTemperature、鼠标、硬盘、主板的信息来判断当前程序是不是在虚拟机中运行。通过检查是否加载了SbieDll.dll、vboxmrxnp.dll、vmGuestLib.dll或vmbusres.dll来检查沙箱是否存在。首次运行时OopisIE会要求用户点击弹窗来区分是否在分析环境中被分析程序自动执行的。

OospIE创建一个GUID并将其写入％APPDATA％\ Windows \ GDI.bin。然后它将自己移动到％APPDATA％\ Windows \ WindowsImplantment.exe并将这两个文件设置为隐藏和系统文件。

此外OopsIE还增加了对当前程序运行的时区进行检查，如果系统没有设置特定的时区OopsIE将不会执行任何代码。OopsIE还会将TimeZone.CurrentTimeZone.DaylightName与伊朗、阿拉伯和中东的字符串进行比较，这五个时区，包含10个国家，这些国家属于UTC + 2，+3，+ 3.5或+4，表明该组织只针对特定目标区域国家进行APT攻击。

360发现攻击者利用CVE-2018-14847漏洞针对MikroTik路由器发起攻击

 

披露时间：2018年9月4日

情报来源：

https://blog.netlab.360.com/7500-mikrotik-routers-are-forwarding-owners-traffic-to-the-attackers-how-is-yours/

漏洞编号：CVE-2018-14847

 

相关信息

涉及20个国家的多台MikroTik路由器中开放TCP/8291端口的设备中存在CVE-2018-14847漏洞。

360发现恶意软件正在利用MikroTik CVE-2018-14847漏洞植入CoinHive挖矿代码，启用Socks4代理，监听路由器网络流量等。

攻击者在启用MikroTik RouterOS http代理功能后，使用了一些技巧，将所有的HTTPProxy请求重定向到一个本地的HTTP 403 error.html 页面。在这个页面中，攻击者嵌入了一个来自CoinHive.com 的挖矿代码链接。通过这种方式，攻击者希望利用所有经过失陷路由器上HTTP代理的流量来挖矿牟利。

部分设备的FTP-data，FTP，SMTP，POP3，IMAP协议端口被监听，这些应用协议都是通过明文传输数据的，攻击者可以完全掌握连接到该设备下的所有受害者的相关网络流量，包括FTP文件，FTP账号密码，电子邮件内容，电子邮件账号密码等。
