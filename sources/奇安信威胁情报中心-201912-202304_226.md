**01**

**FamousSparrow：针对酒店行业的威胁组织披露**

**披露时间**：2021年09月23日

**情报来源**：https://www.welivesecurity.com/2021/09/23/famoussparrow-suspicious-hotel-guest/

**相关信息**：

FamousSparrow为ESET研究人员于2021年9月披露的新威胁组织，该组织至少自2019年8月以来一直活跃，主要针对酒店，受害者也包括政府、国际组织、工程公司和律师事务所。目前FamousSparrow组织的攻击分散在全球范围内，包括巴西、布基纳法索、加拿大、以色列、法国、危地马拉、立陶宛、沙特阿拉伯、南非、台湾、泰国和英国。

FamousSparrow在攻击活动中利用MicrosoftExchange、MicrosoftSharePoint和OracleOpera（用于酒店管理的商业软件）中已知的远程代码执行漏洞，投放各种恶意样本。一旦服务器遭到入侵，FamousSparrow就会部署一系列自定义工具，包括：用于横向运动的Mimikatz变体、一个用于收集机密信息的实用程序、Nbtscan：NetBIOS扫描器，用于识别LAN中的文件和打印机、SparrowDoor后门的加载器。SparrowDoor后门的恶意行为包括：重命名或删除文件、创建目录、关闭进程、发送文件属性、文件大小、文件写入时间等信息，提取指定文件的内容、将数据写入指定文件、建立一个交互式的反向shell、终止开关用于从受害机器中删除持久性设置和所有SparrowDoor文件。

FamousSparrow在2021年3月利用过ProxyLogon远程代码执行漏洞，也利用过服务器应用程序中的已知漏洞。这表明快速修补应用程序的漏洞至关重要。尽管FamousSparrow和SparklingGoblin组织以及DRBControl组织之间存在一些联系，但研究人员认为FamousSparrow是一个旨在展开间谍活动的独立的组织。

**02**

**Operation "Armor Piercer"：利用商业RAT针对印度次大陆的攻击活动**

**披露时间**：2021年09月23日  

**情报来源**：https://blog.talosintelligence.com/2021/09/operation-armor-piercer.html

**相关信息**：

Cisco Talos于9月23日披露了一起针对印度政府和军事机构的攻击活动，并命名为“Operation ArmorPiercer”。

此次活动中的恶意文档伪装成与受害者相关的会议日程相关的文件，或与印度政府IT基础设施相关的技术指南。这些文件作为鱼叉式网络钓鱼电子邮件中的附件传播，旨在通过社会工程使受害者打开或下载恶意文档附件。最终有效载荷为NetwireRA、WorzoneRAT(AveMariaRAT)。研究人员还发现了基于.NET的自定义文件枚举器模块的部署，这些模块生成和泄露受感染系统上特定文件扩展名的文件路径列表。

攻击者使用的一些诱饵和策略与TransparentTribe、Operation SideCopy非常相似。活动中发现的恶意文档的一个常见主题是印度政府的Kavach应用程序，该程序是政府雇员用来访问其电子邮件的双因素身份验证(2FA)应用程序。SideCopy在针对印度政府人员的攻击活动使用过Kavach相关诱饵。此外，攻击者依靠受感染的网站和虚假域的组合来执行恶意活动，这种策略与TransparentTribe的策略非常相似。

**03**

**疑似APT-C-56透明部落攻击预警**

**披露时间**：2021年09月24日  

**情报来源**：https://mp.weixin.qq.com/s/hHBsy\_B3jECr2FLk5g9gbA

**相关信息**：

APT-C-56（透明部落）别名APT36、ProjectM、C-Major，是一个具有南亚背景的APT组织，长期针对周边国家和地区（特别是印度）的政治、军事目标进行定向攻击活动，开发有自己的专属木马CrimsonRAT，还曾被发现广泛传播USB蠕虫。透明部落在2019年下半年一直非常关注阿富汗地区， 在2020年开始再次转为关注印度用户。到了2021年，先是利用疫情相关信息对印度医疗、电力行业进行信息窃取，随后伪装印度国防部会议记录的诱饵文档尝试进行信息窃取。

近日，360高级威胁研究院在日常情报挖掘中发现并捕获到了与Cisco Talos相同的多批疑似透明部落攻击印度的文档，恶意文档最终释放NetWireRAT。

  

**04**

**FoggyWeb：有针对性的NOBELIUM恶意软件导致持久后门**

**披露时间**：2021年09月27日  

**情报来源**：https://www.microsoft.com/security/blog/2021/09/27/foggyweb-targeted-nobelium-malware-leads-to-persistent-backdoor/

**相关信息**：

Nobelium是微软SolarWinds供应链攻击活动中命名的APT组织，也被FireEye称为UNC2452。该组织已被美国政府认定为俄罗斯外国情报局 (SVR) 支持的黑客组织。

近日，微软威胁情报中心发现了Nobelium利用新的恶意软件部署持久性后门，并将其称为FoggyWeb。FoggyWeb是一种被动且针对性强的后门，可以远程渗透受感染的（联合身份验证服务）AD FS服务器的配置数据库、解密的令牌签名证书和令牌解密证书，还可以从命令和控制(C2)服务器接收并执行其他恶意组件。在入侵AD FS服务器后，NOBELIUM在系统上释放两个文件：Windows.Data.TimeZones.zh-PH.pri以及version.dll，FoggyWeb存储在.pri加密文件中，而恶意文件version.dll就是其加载程序。AD FS服务可执行文件通过DLL搜索顺序劫持技术加载加密的FoggyWeb后门文件，并利用自定义的轻量级加密算法(LEA)例程来解密内存中的后门。

**05**

**Kimsuky在攻击活动中的VNC恶意软件**

**披露时间**：2021年09月23日  

**情报来源**：https://blog.alyac.co.kr/4130

**相关信息**：

近日，ASEC研究人员在跟踪Kimsuky组织的攻击活动时发现了其新的VNC恶意软件。Kimsuky通过最初的渗透过程在目标系统上安装AppleSeed后门，并通过AppleSeed安装VNC恶意软件，从而控制攻击目标系统。

在已安装的VNC恶意软件中，TinyNuke恶意软件排名第一。TinyNuke是一种2016年发现的银行恶意软件，其中包括HVNC（HiddenDesktop/VNC）、反向SOCKS4代理和Web浏览器表单抓取等功能。TinyNuke的源代码于2017年左右发布，已经被各种攻击者利用，其中HVNC功能被其他恶意代码（如AveMaria和BitRAT）部分借用。

**披露时间**：2021年09月27日  

**情报来源**：https://www.trendmicro.com/en\_us/research/21/i/fake-installers-drop-malware-and-open-doors-for-opportunistic-attackers.html

**相关信息**：

Trend Micro最近发现一些流行软件的盗版安装程序，这些程序会在受害者的设备上释放批量恶意软件。被假冒的流行软件涉及TeamViewer、VueScan Pro、Movavi Video Editor以及Autopano Pro for macOS。部分用户在互联网上搜索付费应用程序的免费或破解版本时就有可能中招。

以Trend Micro发现的一个TeamViewer破解工具为例，一旦被下载和执行，就会使用BITS工具安装大量恶意软件，并且会在AutoStart注册表中输入可执行文件，并创建计划任务来保证长期的感染。

  

**02**

**FinSpy利用UEFI引导工具感染Windows设备**

**披露时间**：2021年09月28日  

**情报来源**：https://securelist.com/finspy-unseen-findings/104322/

**相关信息**：

Kaspersky在9月28日发布了有关恶意软件FinSpy新变种的研究结果。FinSpy是由Gamma Group开发的一种间谍软件，专门用于出售给世界各地的政府组织和执法机构。该新变体并未感染UEFI固件本身，而是利用恶意代码替换了Windows启动管理器(bootmgfw.efi) ，这种方式可以使攻击者在不绕过固件安全检测的情况下安装bootkit。

与之前的版本不同，该变体还利用了non-persistent pre-validator和post-validator来防止恶意软件分析。

**01**

**新远程覆盖木马ZE Loader攻击网银用户**

**披露时间**：2021年09月23日  

**情报来源**：https://securityintelligence.com/posts/new-ze-loader-targets-online-banking/

**相关信息**：

IBM Trusteer最近发现了一个新的远程覆盖木马，名为ZE Loader。用户通常通过恶意垃圾邮件、钓鱼网页或恶意附件被感染，之后木马就会开始监控特定银行网站的浏览器窗口名称。一旦用户登陆目标网站，攻击者就会得到实时通知并使用木马远程接管设备。攻击者监视用户的活动，并选择一个时间来插入，全屏覆盖web页面，以欺骗用户泄露认证码或其他个人数据。

ZE Loader通过动态链接库(DLL)劫持来伪装为合法软件的一部分。合法软件被打开时，恶意dll也会被加载。首先，ZE Loader检查它是否以管理员权限运行，然后执行两个Netshell命令来创建一个与C2服务的RDP连接。接下来，ZE Loader加载加密文件“operationB”，解密并解包。此文件同样负责设置与C2的RDP连接。

**02**

**新恶意加载器Squirrelwaffle传播Cobalt Strike**

**披露时间**：2021年09月28日

**情报来****源**：https://www.zscaler.com/blogs/security-research/squirrelwaffle-new-loader-delivering-cobalt-strike

**相关信息**：

Zscaler ThreatLabz一直在跟踪一种名为Squirrelwaffle的新型恶意软件加载程序，该程序被用于传播Cobalt Strike。该活动自2021年9月中旬以来一直在运行。Squirrelwaffle加载器和Qakbot银行木马由相同的基础设施传播。

攻击者通过嵌有url的垃圾邮件传播恶意文档文件。垃圾邮件使用了一种邮件线程劫持技术，这种技术以前曾用于Emotet和Qakbot恶意软件活动。恶意文档包含一个宏，它释放并执行%ProgramData%文件夹中的一个VBS文件。被执行的VBS文件下载Squirrelwaffle加载器，该加载器又下载另一个加载器，最后的加载器进一步下载Cobalt Strike。

目前还不清楚Squirrelwaffle是由已知的威胁组织还是一个新的组织开发和传播的。

**03**

**恶意软件Sutersu Rootkit针对Linux平台**

**披露时间**：2021年09月23日  

**情报来源**：https://www.lacework.com/blog/hcrootkit-sutersu-linux-rootkit-analysis/

**相关信息**：

Lacework Labs最近识别了与HCRootkit/Sutersu Linux rootkit活动相关的新样本和基础设施。恶意安装器携带的附件包括：一个内核模块、用户空间ELF文件。这些文件通过标准rootkit功能感染主机。攻击者使用一个独特的定制的基于protobuf的协议进行C2通信。

ELF安装器是coreutils库中kill文件的修改版。kill的大部分核心功能保持不变，但是在执行过程中增加了两个ELF文件的写入操作。其中一个组件是用户空间二进制文件，另一个是内核模块，Avast识别为Sutersu rookit。

  

**04**

**勒索软件PYSA深入分析**

**披露时间**：2021年09月27日  

**情报来源**：https://www.cybereason.com/blog/threat-analysis-report-inside-the-destructive-pysa-ransomware

**相关信息**：

PYSA是一个没有自我传播能力的需手动操作的勒索软件，攻击者通常通过泄露的身份凭证或通过网络钓鱼邮件获得进入目标系统的初始权限。在部署勒索软件之前，攻击者使用公开可用的开源工具进行凭证盗窃、隐蔽、提权、横向移动等等。

PYSA使用C++编程语言实现，并使用开源的CryptoPP C++库进行数据加密。该勒索软件结合使用AES-CBC和RSA加密算法加密数据，以最大化加密性能和安全性。同时，攻击者还会使用双重勒索策略——如果受害者拒绝为数据解密付费，就威胁泄露数据或出售数据牟利。

**05**

**恶意软件BloodyStealer分析**

披露时间：2021年09月27日  

**情报来源**：https://securelist.com/bloodystealer-and-gaming-assets-for-sale/104319/

**相关信息**：

Kaspersky曾发现了一个名为BloodyStealer的恶意软件。BloodyStealer能够获取会话数据和密码，甚至是cookie，并能躲避反向工程和恶意软件分析。值得注意的是，BloodyStealer能够获取安装在受感染系统上的电脑游戏相关信息，主要瞄准Steam、Epic Games Store、EA Origin等主流在线游戏平台。

BloodyStealer能够给每个被感染的受害者分配一个唯一的标识符。标识符是通过提取数据创建的，例如系统的GUID和序列号(SID)。在分配好标识符并获得C&C的IP地址后，BloodyStealer从受感染的机器中提取各种数据，创建一个带有泄漏数据信息的POST请求，并将其发送给C&C。BloodyStealer也会被攻击者用于其他恶意软件，如KeyBase、AgentTesla的攻击链中。同时，也有攻击者将类似Themida的恶意软件与BloodyStealer结合起来，以避免查杀。

**01**

**CVE-2021-22017 VMware vCenter Server rhttpproxy 绕过漏洞**

**披露时间**：2021年09月28日  

**情报来源**：https://mp.weixin.qq.com/s/9Q6M5eZePZ6MdJ9hXzrOxA

**相关信息**：

近日，奇安信CERT监测到VMware官方发布安全通告，其中包括VMware vCenter Server rhttpproxy 绕过漏洞（CVE-2021-22017）。攻击者可绕过 rhttpproxy 限制，访问内部接口。通过访问vmware-analytics服务中的端点，构造请求修改日志记录的位置，将恶意代码通过日志记录的方式写入指定jsp文件中，从而造成远程代码执行。

目前，奇安信CERT已监测到VMware vCenter Server rhttpproxy 绕过漏洞（CVE-2021-22017）细节及部分EXP流出，攻击者可通过现有信息编写出漏洞利用代码，成功利用此漏洞即可在无需身份认证的情况下远程执行任意代码。目前官方已发布修复版本，鉴于漏洞影响较大，奇安信CERT强烈建议客户尽快修复漏洞并自查服务器的安全状况。
