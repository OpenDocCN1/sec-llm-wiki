# 奇安信红雨滴APT扫描引擎 (RAS) 加入Polyswarm平台

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MDc2MDA4OA==&mid=2247496689&idx=1&sn=4b58e060139de40726d5b6f63090675c&chksm=ea660486dd118d903be2a5fcf25bfdbd4dec97ec0ed572a45bdc8ba67e2f913445525cc0bfc4&scene=126&sessionid=1681277509#rd](http://mp.weixin.qq.com/s?__biz=MzI2MDc2MDA4OA==&mid=2247496689&idx=1&sn=4b58e060139de40726d5b6f63090675c&chksm=ea660486dd118d903be2a5fcf25bfdbd4dec97ec0ed572a45bdc8ba67e2f913445525cc0bfc4&scene=126&sessionid=1681277509#rd)

奇安信联合Polyswarm公司荣幸地宣布，奇安信自研的红雨滴APT扫描引擎 (RAS) 现已集成至Polyswarm平台。该引擎借助红雨滴团队多年积累的APT分析经验，可对文件进行深入分析，从而判定文件是否为特定的APT团伙开发并用于定向攻击。  

![](../Images/9119bb9580853915cac3b4db3807c3cb.png)奇安信威胁情报中心负责人汪列军评价这次合作：“PolySwarm作为另一个别具特色的恶意代码鉴定和威胁情报数据平台，对于探索和挖掘安全社区的潜力提供了非常有吸引力的服务，奇安信将与PolySwarm密切合作一起为业界带来惊喜。“

Polyswarm 首席执行官Steve Bassi评价这次合作：“我们非常高兴地欢迎奇安信加入Polyswarm平台。我们致力于引入有专长的引擎来完善Polyswarm生态系统，今天红雨滴APT扫描引擎的加入将带来针对中国恶意软件及其背后团伙的独特洞见”。
