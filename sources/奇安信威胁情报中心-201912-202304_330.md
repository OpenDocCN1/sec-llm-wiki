# SolarWinds供应链攻击事件最全IOC

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MDc2MDA4OA==&mid=2247493379&idx=1&sn=3a856688cc74e423e97d52ab2efcd056&chksm=ea661074dd11996299bdc6ffbc34916f970e70f597df2239e37d8a1169dcf8f387888ebf931c&scene=126&sessionid=1681277554#rd](http://mp.weixin.qq.com/s?__biz=MzI2MDc2MDA4OA==&mid=2247493379&idx=1&sn=3a856688cc74e423e97d52ab2efcd056&chksm=ea661074dd11996299bdc6ffbc34916f970e70f597df2239e37d8a1169dcf8f387888ebf931c&scene=126&sessionid=1681277554#rd)

奇安信威胁情报中心于近日发布了一篇关于美国著名网络安全公司FireEye披露的流行网管软件厂商SolarWinds供应链攻击事件通告。

链接：[https://mp.weixin.qq.com/s/ms7u5PtvU36M3aYbTo2F5A](http://mp.weixin.qq.com/s?__biz=MzI2MDc2MDA4OA==&mid=2247493373&idx=1&sn=f0eed582bc140e4000149008f7d9e778&chksm=ea66118add11989ce63977d36d01a362ed135d03543b8df29cd602c768bec219d49505a3f667&scene=21#wechat_redirect)

今天，除了微软和FireEye以外，国外安全厂商Volexity也发布了一篇此团伙（Volexity将其命名为DarkHalo）的其他攻击活动的分析文章，揭露了相关团伙更多的攻击活动，同时给出了进一步的IOC信息。

在经过对相关的报告、样本、域名和IP进行扩展和验证后，目前整理得到了一份目前看来比较全面的IOC列表，用于分享本次SolarWinds供应链攻击事件的信息，供用户或者其他厂商执行相应的检测。 

值得注意的是，本次提供的域名除了avsvmcloud.com之外，其他的域名建议按照访问发生的时间来分析。这是因为部分域名的注册历史可追溯到很长时间(例如thedoccloud .com的最早注册时间为2013/07/08), 还有的域名目前是过期、可拍卖的状态（例如下图）。

![](../Images/3bc2a1e4d2c57e137b1b4fe4e2e07b07.png)

同Volexity的分析一样，我们认为攻击者之所以使用这些正处在过期但被还未删除的老域名，是因为可以避开一些基于新注册域名数据相关的检测手段，同时注册历史较久的老域名也更不容易被安全分析人员注意到。目前，基于奇安信威胁情报中心的威胁情报数据的全线产品，包括奇安信威胁情报平台（TIP）、天擎、天眼高级威胁检测系统、奇安信NGSOC等，都已经支持对本次SolarWinds事件的样本和IOC的精确检测。（ti.qianxin.com）
