Operation TrickyMouse——以新冠病毒为主题攻击乌克兰

披露时间：2020年2月25日

情报来源：

https://mp.weixin.qq.com/s/o6KC0k43AuOY5F8FKGbmMg

参考链接：

https://twitter.com/RedDrip7/status/1230683740508000256

 

相关信息：

近期，安恒威胁情报分析中心监测到一起以“COVID-19”(新型冠状病毒肺炎)为主题的恶意攻击，攻击目标指向乌克兰。

这次攻击采用了带有恶意宏代码的伪装文档。标题为“Коронавірусна інфекціяCOVID-19.doc” (冠状病毒感染COVID-19.doc)，文件内容仿制乌克兰卫生部公共卫生中心。文档中的恶意宏代码最终会在用户目录下释放“conhost.exe”恶意程序并执行。恶意程序 conhost.exe 由 C#编写，并硬编码了一个回连地址。其功能包括收集用户名、机器名、网络适配器、获取进程信息、键盘记录、屏幕信息以及注册表相关操作的功能。

安恒威胁情报分析中心通过多多个文件的相似行分析发现本次活动可能和Hades 有一定的关联。Hades 组织至今没有一个非常明确的定论，根据已有披露的信息，一种被认为可能来自朝鲜，又有一种说法认为和俄罗斯组织APT28 有关。该组织最早发现并披露是因为2017 年 12 月22 日对韩国平昌冬奥会的攻击，使用了命名为“OlympicDestroyer”的恶意软件。后续国外友商又发现了几起Hades 的攻击活动。攻击目标包括俄罗斯、乌克兰和其他几个欧洲国家，俄罗斯金融部门、欧洲和乌克兰的生物和化学威胁预防实验室等都是其瞄准的对象。

Higaisa组织近期攻击活动报告

披露时间：2020年2月26日

情报来源：

https://mp.weixin.qq.com/s/69txMEgT3fWsum-Mt-6HMg

 

相关信息：

腾讯安全威胁情报中心检测到“higaisa（黑格莎）”APT组织在被披露后经过改头换面再次发动新一轮的攻击，在这轮攻击中，该组织舍弃了使用多年的dropper，完全重写了攻击诱饵dropper，此外还引入了白加黑技术对抗安全软件的检测和查杀。

与以往的攻击手段类似，依然以节假日祝福为主题诱饵进行鱼叉钓鱼攻击，最近抓获的攻击邮件主题为“Happy new year 2020”、“2020 New Year WishesFor You”等，欺骗用户下载并打开附件。通过附件中的scr文件执行之后释放以及下载后续攻击载荷。

该组织常利用节假日、朝鲜国庆等朝鲜重要时间节点来进行钓鱼活动，诱饵内容包括新年祝福、元宵祝福、朝鲜国庆祝福，以及重要新闻、海外人员联系录等等。被攻击的对象包括跟朝鲜相关的外交实体（如驻各地大使馆官员）、政府官员、人权组织、朝鲜海外居民、贸易往来人员等，受害国家包括中国、朝鲜、日本、尼泊尔、新加坡、俄罗斯、波兰、瑞士等。

TransparentTribe：针对印度外交官的攻击活动

披露时间：2020年2月21日

情报来源：

https://blog.yoroi.company/research/transparent-tribe-four-years-later/

 

相关信息：

Proofpoint研究人员于2016年2月首次发现了Transparent Tribe攻击活动，该行动在沙特阿拉伯和哈萨克斯坦的一些使馆针对印度外交官和军事人员进行了一系列间谍活动。该行动依赖于多个媒介，例如水坑网站和网络钓鱼电子邮件活动，这些电子邮件活动提供了被称为Crimson和Peppy的定制RAT。这些RAT能够提取信息，截屏并记录网络摄像头流。
近期Proofpoint发现一个标题为DSOP FUND（国防服务官员公积金）的Excel文件。Excel中包含真正的宏代码，执行之后会释放下阶段攻击载荷，包括一个vbs脚本，一个C＃脚本和一个Zip文件，Zip文件还能释放出四个PE文件。完成执行之后能在目标计算机上通过Lnk文件达到持久性攻击的目的。

RobbinHood勒索软件另辟渠道，通过驱动漏洞关闭杀毒软件

披露时间：2020年2月26日

情报来源：

https://mp.weixin.qq.com/s/4eeenMoQQYhpWEOo5X2I-Q

 

相关信息：

奇安信病毒响应中心在日常样本监控过程中发现了一款名为“RobbinHood”的勒索软件通过使用“另类”的方式关闭并删除杀软，经分析，在执行过程中会释放并加载带有漏洞的技嘉驱动程序，之后会对该驱动程序进行漏洞利用，关闭Windows DSE机制，一旦利用成功便会迅速加载没有签名的Rootkit，Rootkit主要功能为结束并删除指定的进程和杀软，上述操作完成后开始加密。
在以往的勒索软件中，Nemty勒索使用Taskkill来结束指定的进程和服务，Snatch勒索会进入安全模式来加密文件，Sodinokibi勒索会使用CVE-2018-8453内核提权漏洞来提升自己的权限结束相关进程和服务。

Remcos RAT利用COVID-19疫情传播

披露时间：2020年2月25日

情报来源：

https://blog.yoroi.company/research/new-cyber-attack-campaign-leverages-the-covid-19-infodemic/

 

相关信息：

Yoroi近期发现一个名为“ CoronaVirusSafetyMeasures_pdf ” 的可疑文件。该文件执行之后会释放一个VBS脚本和一个PE格式的可执行文件。VBS脚本用来启动可执行文件。通过注册表RunOnce来设置开机启动项，随后会收集用户的敏感信息并记录用户的键盘信息存储在名为“ logs.dat”的文件中，通信方式使用的为Remcos使用的用|cmd|作为数据分割。

ObliqueRAT：针对东南亚政府和外交目标定制的RAT

披露时间：2020年2月20日

情报来源：

https://blog.talosintelligence.com/2020/02/obliquerat-hits-victims-via-maldocs.html

 

相关信息：

Cisco Talos发现了一种名为ObliqueRAT的新型恶意软件，该恶意软件疑似针对东南亚地区政府和外交目标开发的定制恶意软件。并且还发现了ObliqueRAT与2019年12月发布的另一项攻击活动之间的重叠地方，该活动使用了CrimsonRAT类似的内容恶意文档和宏代码。
攻击者使用钓鱼邮件以及武器化的Office来投递RAT，攻击者会诱导受害者向Office中输入邮件中的密码，一旦密码输入之后就能执行文档中包含的恶意VB脚本。随后VBScript会在当前登录的用户下写入Lnk文件以达到开机启动的目的，并且还能够在执行任意命令，文件操作以及进程操作等功能。

针对80多家土耳其公司的攻击活动

披露时间：2020年2月17日

情报来源：

https://research.checkpoint.com/2020/the-turkish-rat-distributes-evolved-adwind-in-a-massive-ongoing-phishing-campaign/

 

相关信息：

Check Point研究人员正在追踪一个持续进行的垃圾邮件运动，该攻击活动针对80多家土耳其公司。初始攻击媒介以包含Office文件附件的网络钓鱼电子邮件开头。在下一阶段链中，将下载恶意的Jar文件。该文件被高度混淆，并带有多种规避技术，以避免被安全产品检测到。然后jar文件会释放Adwind RAT，该恶意软件被配置为窃取敏感信息并将其发送到攻击者的命令和控制服务器，同时获得对受害者计算机的远程访问权。
与该活动的早期版本相比，该恶意软件使用了几种新的反沙箱技术，会检查JVM的默认语言环境，检查机器的语言以及检查计算机的国家名称是否设置为土耳其语，如果不是土耳其语言则不会执行恶意行为。

LoadInfo针对日本组织的恶意软件

披露时间：2020年2月20日

情报来源：

https://blogs.jpcert.or.jp/ja/2020/02/LODEINFO.html

 

相关信息

JPCERT确认于2019年12月左右针对日本组织的定向攻击电子邮件。有针对性的攻击电子邮件中包含一个名为“ LODEINFO”的恶意Word文档，该文档试图感染新的恶意软件。
通过启用Word文档的宏在主机上释放LoadInfo文件并以Rundll32启动可执行文件。LoadInfo与服务器的通信是通过Http通信，数据通过AES加密之后再经过Base64编码，随后Post到服务器。接下来LoadInfo会从服务器请求控制命令，其后门功能包括执行PE文件，执行ShellCode，文件上传下载，结束进程，发送文件列表以及发送恶意软件版本信息的功能。

CVE-2020-0688：Microsoft Exchange远程代码执行漏洞

披露时间：2020年2月26日

情报来源：

https://cert.360.cn/warning/detail?id=26ac820dfe1b5f13c5a6ec3a5274d59a

 

相关信息：

2020年2月11日Microsoft发布的Microsoft Exchange Server中的远程代码执行漏洞（CVE-2020-0688）漏洞细节.
该漏洞是由于Exchange Control Panel(ECP)组件中使用了静态秘钥（validationKey和decryptionKey）所导致的。所有Microsoft Exchange Server在安装后的web.config文件中都拥有相同的validationKey和decryptionKey。这些密钥用于保证ViewState的安全性。而ViewState是ASP.NET Web应用以序列化格式存储在客户机上的服务端数据。客户端通过__VIEWSTATE请求参数将这些数据返回给服务器。经过身份验证的攻击者可以从身份验证的session中收集ViewStateUserKey，并在登录请求的原始响应中获得__VIEWSTATEGENERATOR。通过这两个值可以利用YSoSerial.net工具生成恶意的ViewState，从而在ECP中执行任意的.NET代码。由于ECP应用程序是以SYSTEM权限运行的，因而成功利用此漏洞的攻击者可以以SYSTEM身份执行任意代码，并完全控制目标Exchange服务器。
影响版本

Microsoft Exchange Server 2010 Service Pack3 Update Rollup 30

Microsoft Exchange Server 2013 CumulativeUpdate 23

Microsoft Exchange Server 2016 CumulativeUpdate 14

Microsoft Exchange Server 2016 CumulativeUpdate 15

Microsoft Exchange Server 2019 CumulativeUpdate 3

Microsoft Exchange Server 2019 CumulativeUpdate 4

CVE-2019-15126：Wi-Fi加密漏洞，影响超过10亿台设备

披露时间：2020年2月27日

情报来源：

https://blog.alyac.co.kr/2774

 

相关信息：

网络安全研究人员在Broadcom和Cypress制造的流行Wi-Fi芯片中发现了一个新的高风险硬件漏洞。该芯片似乎已在超过10亿个设备中使用，包括智能手机，平板电脑，笔记本电脑，路由器和IoT小家电。

名为“ Kr00k”的CVE-2019-15126漏洞，此漏洞可能允许远程攻击者近距离拦截和解密从易受攻击的设备无线发送的一些无线网络数据包。攻击者不必连接到受害者的无线网络，并且此漏洞适用于使用带有AES-CCMP加密的WPA2-Personal或WPA2-Enterprise协议的易受攻击的设备来保护网络流量。
