 Fox Kitten:针对全球多个地区的间谍攻击活动  

披露时间：2020年2月16日

情报来源： 

https://www.clearskysec.com/fox-kitten/

参考链接:

https://www.clearskysec.com/wp-content/uploads/2020/02/ClearSky-Fox-Kitten-Campaign.pdf

 

相关信息：

    在2019年最后一个季度,ClearSky发现了伊朗在过去三年中针对以色列和世界各地的数十家公司和组织进行攻击的间谍活动.攻击者成功地获得了来自全球IT，电信，石油和天然气，航空，政府和安全部门的众多公司和组织网络的访问权和持久的攻击立足点。除恶意软件外，该活动还包含整个基础设施，以确保长期控制和控制伊朗人选择的目标的能力。在ClearSky的分析中，ClearSky发现该战役的基础设施与伊朗进攻性组织APT34-OilRig的活动有中度重叠。该运动活动是通过使用各种攻击性工具进行的，其中大多数是基于开放源代码的，而有些是自行开发的。

 黑产控制药物研究机构邮箱搞钓鱼  

披露时间：2020年2月13日

情报来源： 

[https://mp.weixin.qq.com/s/T2FuoPMtpnVghX4BXG3yjQ](https://mp.weixin.qq.com/s?__biz=MzI2MDc2MDA4OA==&mid=2247490311&idx=1&sn=f53a621b683b5365df9ff1d4d0af5e8f&scene=21#wechat_redirect)

相关信息：

       而近日，红雨滴团队再次发现一起钓鱼攻击，控制正在抗击疫情研发药物的机构的邮箱来发钓鱼邮件,发件人为某药物研究所的邮箱，目前猜测该所邮箱被盗。

       点击邮件中的钓鱼域名，则会向目标展示一个钓鱼页面,在输入信息后，点击提交，则会跳转到另一个页面。有趣的是，钓鱼页面相当粗糙，”登陆地址”正确的写法应该是”登录地址”，下面的提示方案也打错了字，为保证”顺利生”，而漏掉了升级二字，因此可以初步判断，攻击者懂拼音，而不是直接使用谷歌翻译。从钓鱼域名的访问来看，这波攻击从2月5日开始，已经有了一定的影响面。

       红雨滴团队也发现了一条新的国内黑产钓鱼链：系统开发商提供域名、主机、管理系统，黑产攻击者使用这些信息，进行一次性攻击后删除证据，这样就会导致证据链短缺，难以进行下一步的追踪行动。

 恶意软件不忘“黑心”，继续利用疫情发国难财

[https://mp.weixin.qq.com/s/D23kyK20FXXwviZm0KA8Yw](https://mp.weixin.qq.com/s?__biz=MzI2MDc2MDA4OA==&mid=2247490413&idx=1&sn=8a21cc2f47444aa783399beac9511abc&scene=21#wechat_redirect)

 Gamaredon组织Pterodo样本分析  

披露时间：2020年2月17日

情报来源： 

https://blog.yoroi.company/research/cyberwarfare-a-deep-dive-into-the-latest-gamaredon-espionage-campaign/

相关信息：

       Gamaredon的以一个名为f.doc的Office文档作为攻击链的开始,样本使用乌克兰语言编写,混合了很多垃圾字符,目的是诱导用户点击启动文档.Office利用了模板注入的方法,当文档被点击之后会下载一个.dot的文档.

当下载的文档被打开之后会利用通过vbs脚本设置开机启动项,以及设置一些其他的注册表键值信息.还会从远程服务器中下载阶段攻击载荷,并强制重启计算机.此外还会释放并执行.NET编写的可执行程序.

 ViperSoftX:新的JavaScript恶意软件  

披露时间：2020年2月14日

情报来源：

https://www.fortinet.com/blog/threat-research/vipersoftx-new-javascript-threat.html

 

相关信息：

FortiGuard实验室检测并阻止了一种新的，高度混淆的恶意软件。这是一种基于JavaScript的远程访问特洛伊木马（RAT）和加密货币的窃取程序.

ViperSoftX  在执行其实际有效负载之前，先分解  8个代码混淆层。使用了3种不同类型的混淆技术：

AES解密:仅在第一层中使用。作者从广泛使用的CryptoJS  库中复制粘贴了实现AES算法的代码块 。每个样本都有一个不同的硬编码AES密钥。

转换Char数组:此方法通常也只在第三层执行一次，并且具有评估硬编码字符数组的简单功能。

UTF8解码:此方法是最经常发生的去混淆层。它包含最有可能从在线Web Toolkit 复制以执行UTF-8解码的代码段。

建立持久性后，ViperSoftX将循环查询C＆C服务器以获取要执行的命令,并且在执行每个命令后休眠3秒钟。ViperSoftX远程控制命令包括执行其他JS命令,远程CMD,下载和执行以及自更新和删除功能.

 Nemty v2.5借Phorpiex僵尸网络传播，可监视剪贴板劫持虚拟币交易  

披露时间：2020年2月13日

情报来源：

https://s.tencent.com/research/report/886.html

 

相关信息：

       近日，腾讯安全御见威胁情报中心发现Nemty勒索病毒最新变种依靠Phorpiex僵尸网络投递再度活跃。国内近期活跃Nemty均为2.5版本的勒索病毒,Nemty勒索病毒由恶意脚本代码执行后下载而来，恶意脚本会使用PowerShell或者Bitsadmin下载名为jp.exe的恶意勒索模块到temp目录执行.

由于Phorpiex具备了虚拟货币窃取（剪切板替换）功能，当受害者不慎感染了其下发的Nemty勒索病毒后，如果尝试在受勒索机器上缴纳赎金，则可能导致虚拟币转帐交易被劫持，从而使勒索赎金无法转帐到Nemty运营团伙处（被Phorpiex僵尸网络窃取），无法支付赎金，从而无法解密文件。

 CVE-2020-0618: 微软SQL Server Reporting Services远程代码执行漏洞  

披露时间：2020年2月16日

情报来源：

https://cert.360.cn/warning/detail?id=eb57a4ea32131f58ad40b6d92168a74c

 

相关信息：

       SQL Server Reporting Services 是依托于 SQL Server的一个附属组件。其作用是利用 SQL Server 中的数据，便捷的生成用户友好的图表。该服务默认是内部服务，默认开放在 localhost 的 80 端口。

该漏洞需要经过身份验证后，攻击者向 SQL Server 的报告服务(Reporting Services) 发送特制请求进行触发。攻击成功可获得SQL Server服务的对应控制权限。

影响版本:
