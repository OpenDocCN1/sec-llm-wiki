 疑似南亚地区新APT组织GroupA21相关攻击活动分析  

披露时间：2020年1月15日

情报来源：

https://x.threatbook.cn/nodev4/vb4/article?threatInfoID=2398

 

相关信息：

微步在线发现了一个至少自2017年开始活动，主要针对南亚地区各国开展网络间谍活动的新APT组织。该组织的攻击手法与印度背景的SideWinder和Bitter组织存在些许相似，但在攻击细节和所用木马方面存在本质的区别，为方便进行跟踪，微步在线内部将之命名为GroupA21。

该组织疑似具备印度背景，主要针对南亚地区的巴基斯坦、斯里兰卡、马尔代夫和孟加拉等国的政府、军事、外交、情报、原子能和高校等行业和机构开展网络间谍活动。

根据IOC和木马指纹关联溯源发现，该组织至少自2017年开始活跃。其攻击木马使用Python、C、C++、Go等进行开发，具备回传系统配置信息、Shell、获取目录、传输文件、发送邮件和远程文件执行等功能。

在鱼叉式网络钓鱼攻击中，该组织善利用时政和军事等目标相关信息制作钓鱼邮件和诱饵文档，使用伪装成PDF文档的SFX文件、伪装的LNK文件作为木马投递载体，早期也曾利用CVE-2017-11882漏洞传播木马。

  

2

 全球加密货币公司的梦魇——揭秘APT组织“危险密码”  

披露时间：2020年1月8日

情报来源：

https://x.threatbook.cn/nodev4/vb4/article?threatInfoID=2371

 

相关信息：

       近日微步在线威胁情报云捕获到多个具备相同特点的压缩木马文件，并关联发现幕后黑客的更多网络资产及攻击样本。由于诱饵文件以“每月业务报告”、“职位描述”、“项目风险简介”等话题，且内容均涉及加密货币，研判认为幕后存在一个专门攻击加密货币公司的APT团伙，微步在线威胁情报根据攻击手法将其命名为“危险密码”（DangerousPassword），具体情况包括：

“危险密码”发布的诱饵文件涉及中文、英文、日文、俄文等，域名资产数量过百，且攻击目标集中于加密货币公司，是一个资源丰富、目标明确的APT团伙。

“危险密码”至少于2018年3月开始活跃，主要通过钓鱼邮件投递恶意文件下载链接，诱导收件者从仿冒的谷歌、微软、亚马逊云服务器下载木马压缩文件。

压缩文件一般包含诱饵加密文档和伪装成密码文件的恶意快捷方式，用户启动后会下载后门脚本直接执行，同时展示文档密码迷惑用户。

恶意后门启动后监测主机是否存在“金山毒霸”、“360”等软杀进程，以判断绕过或是否驻留等后续操作。同时后门会将主机信息、运行进程等数据发送回C&C服务器，并持续发起请求以执行后续操作。

 “折纸”行动：针对南亚多国军政机构的网络攻击  

披露时间：2020年1月15日

情报来源：

[https://mp.weixin.qq.com/s/mFVoFpPFSJb88rpWMJScZg](https://mp.weixin.qq.com/s?__biz=MjM5MTA3Nzk4MQ==&mid=2650174342&idx=1&sn=f9946edb54b88f42d36ae9219d792a67&scene=21#wechat_redirect)

 

相关信息：

安天CERT捕获多批针对南亚多国军事、政府和教育等实体的攻击样本，且样本之间存在一定关联，攻击者带有明显窃密意图，受害者集中于巴基斯坦，少量分布在孟加拉、斯里兰卡和马尔代夫等南亚国家。根据当前观测数据，攻击者投递的诱饵文件形态丰富，诱饵的主题涉及军情事务、地缘争端、核武器、区域会议等重要话题，攻击者所使用的木马武器既有开源工具、也有自研工具，包括其中一种通过U盘摆渡机制，突破内网隔离以获取内网数据的木马。这一系列的攻击活动至少在2017年7月已经开始，迄今仍保持活跃。通过溯源分析，这些攻击样本来自被安天命名为“幼象”的组织，其手法和装备与“白象”组织有一定差异，同时安天判断该组织与友商命名为“响尾蛇”的攻击组织存在关联。木马载荷既有自研发的通过C++编写的窃密木马、Python语言编写的木马和Go语言编写的木马，也用公开的Empire渗透框架和Exploit Pack漏洞攻击平台。最早发现的攻击样本编译于2017年7月，最新的编译于2019年10月16日

 黑产团伙利用Apache Struts 2漏洞及SQL爆破控制服务器挖矿

披露时间：2020年1月14日

情报来源：

https://s.tencent.com/research/report/871.html

 

相关信息：

腾讯安全御见威胁情报中心监测到团伙利用Apache Struts 2远程命令执行漏洞（CVE-2017-5638）攻击windows服务器，从团伙使用的文件列表来看，主要通过爆破或漏洞利用进行攻击，且针对windows服务器，已控制服务器270台左右，被下发挖矿木马的服务器有44台，该团伙挖取门罗币已赚得3.5万元。

查看团伙HFS服务器文件列表，可以看到多个扫描爆破工具、漏洞利用工具、密码抓取工具、远程控制工具及端口转发工具。

根据钱包地址进行关联，可以关联到F5研究团队在去年3月公布的“CryptoSink”行动中批量的钱包一样，当时已经挖掘到70个门罗币，可见这次挖矿攻击活动仍然跟“CryptoSink”关系较大。

 安在公司“正版”监控软件被黑产利用  

披露时间：2020年1月14日

情报来源：

[https://mp.weixin.qq.com/s/xLfWKjqem09Z7tfrQIJUvw](https://mp.weixin.qq.com/s?__biz=MzI5Mzg5MDM3NQ==&mid=2247484774&idx=1&sn=59c26f799ee76748f2fc157ddc72931e&scene=21#wechat_redirect)

 

相关信息：

近日，奇安信病毒响应中心在日常跟踪黑产团伙过程中，发现了一个利用正规监控软件窃取用户信息，甚至监控聊天记录的黑客团伙，由于正规监控软件带有数字签名，杀软一般不会对其进行查杀，从而达到免杀的效果。

样本在执行过程中会在从远程服务器下载远控客户端安装程序，通过消息操作实现客户端自动化安装，安装成功后主进程则会连接远程服务器。可以实现屏幕监控、流量监控、屏幕录像、监控上网行为、软件管理、访问控制、文档备份、下发文件等复杂功能，同时其释放的驱动注册了进程回调来保护主进程不被结束。

 360安全中心披露新勒索MZRevenge  

披露时间：2020年1月3日

情报来源：

https://blog.360totalsecurity.com/en/new-ransomware-mzrevenge/

 

相关信息：

360安全中心拦截了一个新的勒索软件MZRevenge。该病毒使用AES-256-CBC +流加密方法。加密的文件将重命名以后缀.MZ173801结尾。

捕获的原始样本是用C＃编写的下载器Trojan。该功能非常简单，下载并执行MZRevenge病毒。MZRevenge用Delphi语言编写，并使用VMProtect保护。数据加密后会提示受害者支付300美元的赎金以恢复加密数据。

披露时间：2020年1月15日

情报来源：

https://www.fortinet.com/blog/threat-research/analysis-metamorfo-variant-targets-financial-organizations.html

 

相关信息：

       FortiGuard Labs最近从网络钓鱼电子邮件中捕获了可疑样本。经分析确定是Metamorfo恶意软件的新变种。电子邮件内容为葡萄牙语，为巴西的官方语言。电子邮件内容伪装成一条通知，要求受害者下载电子发票。下载的文件不是电子发票，而是MSI文件名“ XlsPlan\_Visualize.msi”的ZIP文件。     Msi文件会释放并执行VBS代码，并从远程服务器下载下阶段攻击载荷Metamorfo。

 SAIGON：Ursnifv3变体木马  

披露时间：2020年1月15日

情报来源：

https://www.fireeye.com/blog/threat-research/2020/01/saigon-mysterious-ursnif-fork.html

 

相关信息：

       FireEye研究人员发现基于Ursnif v3源代码修改的新变种SaiGon，但SAIGON的功能不是完全成熟的银行恶意软件，而是更通用的后门程序，可能是专门为有针对性的网络犯罪活动量身定制的。

SAIGON在受感染的计算机上以存储在注册表项中的Base64编码的shellcode blob的形式出现，该注册表项是使用PowerShell通过计划任务启动的。与其他Ursnif变体一样，该恶意软件的主要组件是DLL文件。该DLL具有一个导出的函数DllRegisterServer，这是一个未使用的空函数。通过DLL的入口点加载并初始化DLL时，将执行恶意软件的所有相关功能。

相关信息：

WIN10

Windows  Server 2016/2019
