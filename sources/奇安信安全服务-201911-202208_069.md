# 奇安信参加App专项整治行动宣贯会 App专项治理进入纵深推进阶段

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MzA0ODUwNw==&mid=2247485139&idx=2&sn=333937e29e443fb13eb34a26fae7dfc8&chksm=eb91e987dce660914159a6c861bc20ab5e483381dcc293fcd10651299159390ce25de7c5bb3e&scene=126&sessionid=1681401840#rd](http://mp.weixin.qq.com/s?__biz=MzI4MzA0ODUwNw==&mid=2247485139&idx=2&sn=333937e29e443fb13eb34a26fae7dfc8&chksm=eb91e987dce660914159a6c861bc20ab5e483381dcc293fcd10651299159390ce25de7c5bb3e&scene=126&sessionid=1681401840#rd)

  

  

近日，工业和信息化部在京召开“纵深推进APP侵害用户权益专项整治行动宣贯会”。会议强调，针对App用户权益的保护是人民群众幸福感的重要组成部分，全行业应坚决把群众利益放首位，严格落实企业主体责任。同时，将进一步加大常态化监督检查力度，技术与管理结合、凝聚产业力量，持续提升App技术检测能力，加强协同治理，推动社会共治。奇安信作为技术支撑单位全程参与了本次会议。

  

  

  

![](../Images/8cba303272c7d4fde25b61cf296daa1c.png)

  

  

**App隐私治理进入纵深推进阶段**

  

今年央视“315”晚会曝光了部分SDK窃取用户隐私的行为。7月22日，工信部发布【2020】164号文《关于开展纵深推进APP侵害用户权益专项整治行动的通知》。通知部署了2020年开展纵深推进APP侵害用户权益专项整治的行动，本次App专项整治行动力度大、对象广、要求严，涉及到App服务提供者、软件工具开发包（SDK）提供者、应用分发平台三类对象。

  

同日，四部委召开“2020年App违法违规收集使用个人信息专项治理工作启动会”，部署工作，进一步加大App整治力度，同样涉及到这三类整治对象，要求对App违法违规收集使用个人信息行为，予以约谈、警告、下架、罚款等处罚，形成有效震慑。

  

7月24日，工信部通报了2020年第三批侵害用户权益行为的App，58款未完成整改的App被点名通报，要求上述App在7月30日前完成整改。通报特别提到：部分移动应用分发平台管理主体责任缺位，对上架App审核把关不严，并已对相关企业进行了集中约谈。

  

中国信通院已初步建设全国App技术检测平台管理系统，到今年年底，系统自动化检测能力将在奇安信等技术支撑单位的协同下全面上线，年底计划完成40万款App的检测工作，实现App由静态监管转向动态监管、重点监管转向全面监管、分散监管转向集中监管的转变。

  

![](../Images/9f7873a5d51452814a64e24ec087c415.png)

  

可以说，随着会议的召开及一系列行动的部署，App专项治理进入纵深推进阶段，App侵害用户权益行为将得到更深力度的整治。

  

  

**App隐私违规问题顽疾何在**

  

根据信通院发布的《移动应用（App）数据安全与个人信息保护白皮书（2019 年）》报告，截至2019 年10 月，我国本土市场上监测到的App 在架数量为525 万款。众多的App中普遍存在安装索要授权的行为，正如广大用户所说，今生撒过最大的慌莫过于“我已阅读并同意用户协议”。

  

**那么移动应用App或者SDK在获取什么信息呢？**

  

**通讯录权限：**读取、修改、删除和备份通讯联系人（地址），读取、修改或者删除通话记录等，恶意程序据此可以获取您的重要联系人信息。**电话权限：**获取手机号、IMEI号、IMSI号码、ICCID号等，恶意程序据此可以获取您的基本标识。**短信权限：**读取、发送、写入或者删除短信或者彩信等，恶意程序据此可以获取您的机密信息。**影音权限：**使用设备摄像头、调用录音、通话录音等，恶意程序据此可以获取您个人敏感的照片、声纹和指纹等重要信息。**位置权限：**通过频繁访问GPS、WIFI等位置源，恶意程序据此可以获取您个人敏感位置信息以及其他位置信息。**其他权限：**读取上网记录、应用列表、日程记录、应用通知、传感器数据等，恶意程序据此可以形成您的上网行为等的全面描述。

  

**个人隐私信息的泄露主要有以下几种形式：**

  

1、小部分非法企业通过违规开发App或者SDK，利用某些管理漏洞实现App短期快速上线，收集海量个人信息数据进行非法营销。2、部分企业为达到其精准营销的目的，而超范围采集用户个人信息，以方便其进行相关产品和服务的精准推送。3、某些企业在开发App的过程中无意使用某些SDK或者因对相关法律法规不熟悉而出现超范围收集个人信息的行为。

  

App开发和经营者缺乏评估App个人信息安全产品的专业能力，尤其对第三方外包的开发的App以及集成的第三方SDK情况了解不足；各分发平台对其管理范围的App难以进行快速检查；监管机构投入的人力、物力不断增加。如何快速、高效的发现App中隐私合规问题已是行业面临的严峻问题。

  

  

**奇安信App隐私合规检测实践**

  

奇安信隐私合规检测方案依据《App违法违规收集使用个人信息行为认定方法》《GB/T 35273-2020 信息安全技术 个人信息安全规范》、工信部164号文等规定和标准，对各类App隐私安全合规评估，为用户提供从App开发到上市全流程的隐私检测服务。

  

**移动应用监测平台：**可以快速对全国范围内的App隐私合规情况进行监控与分析。

![](../Images/055ad80b3ededdb11e49bcd3559fba64.png)

  

重点解决监管部门人力、物力不足的情况进行隐私合规全局的梳理，从行业入手，立足全国，通过可编程接口设计对接各方数据，实现App全量数据的抓取、隐私合规分析和数据治理，全面服务各级监管部门。

  

**隐私卫士系统：**对安卓和IOS两大平台移动应用隐私合规检测与分析的系统，可以为各类移动应用进行全方位、快速、深度的隐私合规检测。

![](../Images/e39999b03561505df52fb3899fedc042.png)

  

面对企业产品开发设计的现状，隐私卫士可以深入到产品设计、开发、测试的各个环节，对雏形阶段的产品即可进行隐私合规检查，实现App全生命周期的隐私合规检测。

  

**隐私合规检测服务：**奇安信隐私合规检测服务可以为各类客户进行App隐私安全合规的深度评估，出具合规性评估报告，报告细化到每个条款的差距分析，指导App运营者进行整改，并可协助通过相关认证。

  

面对App合规检测中普遍存在的超范围收集个人信息、个人信息泄露、滥用个人信息、强制授权、过度索权的现象，通过对监管机构发布的各类隐私保护政策法规深入解读，奇安信新一代App隐私合规检测的专业化工具与服务，能够为各类企业提供全面的隐私合规检测解决方案，协助企业提高研发、测试和上市各环节中的隐私合规检测工作，助力隐私合规问题的切实解决。
