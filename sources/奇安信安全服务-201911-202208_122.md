# 挖矿木马问题较为突出 | 应急响应每周简报(第3期)

**概述**

*2020/03/02*

  

上周，奇安信网络安全应急响应中心共接到应急响应21次，共计574.14小时，覆盖13个省市，9个行业。其中，政府部门应急次数最多，累计应急5次。根据上周实际应急情况，奇安信网络安全应急响应中心发现，在政府部门相关的应急事件中，挖矿问题最为突出。

  

  

**事件分析**

  

  

**1、失陷区域**

  

从政企机构上周网络安全事件失陷区域看，61.9%为业务专网、38.1%为办公终端。由于内部员工安全意识不足，常导致业务专网中存在大量安全漏洞，如危险端口暴露在公网中、未及时安装安全补丁等，可以被轻易利用，所以业务专网遭受的攻击和威胁也是最多，最严重的。

  

![](../Images/4361c47e7e898394d7eab3af695aa5e3.png)

**2、事件影响**

  

从政企机构上周的统计来看， 28.6%的安全事件导致了系统/网络不可用、14.3%的安全事件导致了数据丢失、14.3%的安全事件导致了数据篡改、9.5%的安全事件导致了破坏性攻击、9.5%的安全事件导致了声誉影响、9.5%的安全事件导致了生产效率低下。从攻击现象统计看，攻击者对系统的攻击具备破坏性、针对性，严重影响了系统和业务的正常运行。

  

![](../Images/dcdc5533a6508450e81a64967e34716e.png)

  

**3、攻击目的**  

  

对上周网络安全事件中攻击者的目的进行了分析。其中，33.3%的安全事件属于黑产活动事件、28.6%的安全事件属于敲诈勒索事件、9.5%的安全事件属于内部违规事件、9.5%的安全事件属于窃取重要数据事件。由此可见，对于大部分攻击者而言，其进行攻击的主要原因是为获取暴利。

  

![](../Images/e52cd839618bb8eb906792bc6f3ca358.png)

  

**4、木马类型**

  

对上周政企机构遭受攻击的常见木马类型进行了统计，其中， GLobeImposter勒索软件占比为19%、挖矿木马占比为19%、一般木马占比为9.5%、其他勒索软件占比为28.6%。从以上数据可以看出，勒索病毒、挖矿木马仍为攻击者攻击政府机构、大中型企业的常见木马类型。

  

![](../Images/b9e9e20a2a8e8987b169ceaa1ca9bf68.png)

  

**5、自身弱点**

  

网络安全事件的发生，往往会暴露出相关政企机构内部存在的安全运营和管理问题。在上周所处置完成的21起网络安全事件中，弱口令问题最为显著。其中，47.6%的事件与弱口令有关、19%的事件与永恒之蓝有关、9.5%的事件与服务器漏洞有关、9.5%的事件与配置不当有关。。（其中，单起网络安全事件中，存在多个弱点的情况。）
