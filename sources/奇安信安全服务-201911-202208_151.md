# 年关将至-近期黑产团伙攻击事件分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4MzA0ODUwNw==&mid=2247483775&idx=1&sn=5762279fed6b26162c5f636cec907267&chksm=eb91ee2bdce6673d7c751e61ba442742955b5ee27fef24a72e37e104d8bb548e7de90ccf5b33&scene=126&sessionid=1681401871#rd](http://mp.weixin.qq.com/s?__biz=MzI4MzA0ODUwNw==&mid=2247483775&idx=1&sn=5762279fed6b26162c5f636cec907267&chksm=eb91ee2bdce6673d7c751e61ba442742955b5ee27fef24a72e37e104d8bb548e7de90ccf5b33&scene=126&sessionid=1681401871#rd)

**事件概述：**临近2020新年春节，勒索攻击事件数量又呈快速上涨趋势。从攻击类型来看除了早期通过爆破手法投递勒索攻击以外，有进一步演变以勒索、挖矿、远控三合一的攻击模式，而攻击手法从单纯的RDP爆破到现在的RDP爆破、Web攻击、持久化控制（MSF、CS）等几乎涵盖了所有的攻击面，黑产人员的技术提升及自动化攻击工具的完善也使得用户资产受威胁面进一步扩大。

  

类似攻击事件还可追溯到2019年初勒索团伙借助永恒之蓝下载器渠道投放CIOP勒索病毒并进行持久化控制。而本次以奇安信安全服务团队的某起应急事件的实践出发，通过观星应急响应分析系统，选取近期经典案例来分析黑产团伙的攻击手法。

**事件分析**

  

2019年12月至2020年1月初，观星实验室接到一线的应急响应支持，发现某用户机器感染了疑似SatanCryptor勒索攻击，且遭受了持续性攻击。SatanCryptor勒索最早出现在2017年，其演变了多个变种包括SatanCryptor Lucky、SatanCryptor Go以及近期出现的SatanCryptor 5ss5c。

  

现场根据被攻击的时间点，定位了某台业务机器，排查存在的可疑文件，看到类似如blue.fb、star.fb基本可以确认是永恒之蓝的攻击工具，除此之外也出现了5ss5c\_token的标志文件。

![](../Images/2c1dc1b16890576e6cd8e564804c6043.png)

在Windows下的Temp目录也发现了几个可疑文件，如Ssession早期是Satan勒索使用的标志文件，其中cl.bat是一个简单的清理脚本，其中audiodg.exe进程正在系统中运行。

![](../Images/9a691022d7c1e622dfccf3dacd5a19ff.png)

  

根据以前分析Satan勒索的经验，在C:\\Program Files\\Common Files\\System\\下发现了cpt.exe（勒索主体样本）和c.exe（传播样本）除此之外还有还发现了scanlog文件（扫描器记录的机器信息）及tmp文件。把观星主机采集器采集到的主机数据在应急响应分析系统中分析，发现的第一类威胁即powershell命令执行的可疑服务，其时间为2019年11月29日凌晨1点45分，其执行命令路径即CS的攻击payload。

![](../Images/fff3165f829aa81c193b672616a300a4.png)

  

类似的CS的payload还有一条，两条记录的时间及服务名称不同，一般为攻击者攻击执行两次或Spawn了新的会话，其回连CC为106.247.237.150:53。

![](../Images/4984be3b7f2a18c209862fa1de11b4b3.png)

  

除以上外同样发现了另外一条powershell服务，其恶意域名为hxxp://www.al1baba.club。

![](../Images/f99915f6ac325c8b40ddd9a48adc0f8d.png)

  

第二类威胁即发现了WMI可疑的命令执行驻留，该恶意域名hxxp://g-s.io曾有一段时间停止解析。

![](../Images/ae6311e67d69049ce8f091fe741f8ffd.png)

  

第三类威胁即进程链存在可疑的命令执行如g.exe即对应了WMI后门的执行后的结果

![](../Images/bfb7d867b86ba64f663fb1699232edda.png)

![](../Images/ecd53b03e46395761d63141effa838cc.png)

第四类是发现了可能存在RDP隧道或者转发的情况。  

![](../Images/fb0bc60482b5ce51e4948e5a6fddfbe3.png)

  

第五类则是威胁情报匹配的可疑文件，如永恒之蓝的漏洞攻击工具。

![](../Images/ac9669821588270e62fbbb4a43663223.png)

![](../Images/4aeba14f2d19a1728d427f4d8d0e2f16.png)

除以上发现的威胁情况，还发现了不同时间点有爆破攻击的行为。  

![](../Images/ce3945cfed9f1cb0abe303b2077b2787.png)

![](../Images/dcdd198106324b1c9fb274bead3b9a1c.png)

除系统数据外，在用户应用日志中发现了攻击者使用泛微e-cology OA漏洞执行命令的情况。  

![](../Images/576924b3139ee1935a039d1f8dc73b1f.png)

  

再深入挖掘其登录行为，可以看到攻击者发起攻击是从2019年11月27号开始逐渐开始到12月15日为第一阶段，第二阶段从2019年12月25日开始直到2020年1月12日以后。

![](../Images/d67da83c88c38dd096e38eacfc65a979.png)

![](../Images/7a4bf13955c9fb60f47e2d769c17db6e.png)

在网络连接中也有一条可疑连接，80端口是用户泛微OA的服务端口，有条外连的111.202.222.253地址。  

![](../Images/6b1138ee39e9d33d414e4d5d73d21644.png)

  

**根据以上信息并结合用户现场分析，梳理攻击线索如下：**

  

首先是时间最早的连接hxxp://www.al1baba.club恶意powershell服务，在奇安信威胁情报中心可以观察到其攻击有利用通过“泛微e-cology OA远程代码执行漏洞启动”的行为。

![](../Images/7714dab523d4d6aa7de96f3d3f79006c.png)

  

除此之外，在WMI启动项中发现的g-s.io的域名，其直接关联执行Windows目录下的g.exe，是一个自解压包，wslog\_tblog6，wslog\_tblog3即为64位和32位的xmrig挖矿程序，audiodg.exe为其调用程序，cl.bat是清理g.exe的脚本。

![](../Images/c09332ab4e29490cea741e659ba22491.png)

  

在其流程中会复制并重命名挖矿程序且检测任务管理器进程并关闭。

![](../Images/54fd3a2857f3a71ff8d5a62254a2e7c6.png)

  

可以看到挖矿信息37.59.43.136:80、37.59.44.193:80。

![](../Images/33b617e5773b5c61f14cec7a010a1b71.png)

  

而分析g-s.io发现，其DNS历史解析曾用IP与恶意域名hxxp://havefuntomorrow.com、hxxp://gjjqu.com有关，其关系的恶意程序也为挖矿相关。

![](../Images/9c2de96f96005a7ee4de0d657c6966c7.png)

![](../Images/8a9c5c56de9cd9f1823acfd5d00ff537.png)

而在temp下存在一个tomorrow.exe的恶意程序，分析该程序发现，其PDB路径中原始项目命名就为tomorrow.exe。  

![](../Images/6c2417eb47ca84fe7424fc68eb3098ea.png)

  

分析样本发现其主要执行C:\\Windows\\Temp\\tmp30下的e.exe文件，在应急分析系统中，利用USN日志我们可以看到其相关的文件记录。

![](../Images/53ddd4d051dcffb652e890138403aaaf.png)

![](../Images/d584db80ce673f26d7e522721e24a416.png)

![](../Images/02b672bf40bd9ac39425559d2f1f3b3b.png)

而在前面威胁检测中已经发现其是永恒之蓝的漏洞利用工具。  

![](../Images/dfa23947bcc3dbfb39ceac9268a5e059.png)

![](../Images/1bdfd49abce9d9be2853d8225fa2f79b.png)

由于该文件的创建时间已经到2020年1月，而创建访问hxxp://www.al1baba.club的powershell服务及WMI的访问在2019年9月，时间跨度较大，暂没发现有关联关系，其更可能与后续Satan勒索相关。而针对2019年11月29日发现的有关CS的powershell命令执行，在系统排查时发现其执行了8.bak恶意文件，分析该样本即为CC落地样本106.247.237.150。

![](../Images/9770e4b7e97ed31894d45530f755ea61.png)

  

原始样本与Satan壳相同，MPRESS压缩，其中判断了当前用户模式，及监视是否有杀软运行。

![](../Images/d56a574b9957ffd40a55d6620456daf2.png)

![](../Images/dee0a7195919b9e7dafd1ff5f5d21a08.png)

最终在内存加载执行ShellCode执行。  

![](../Images/8c654d0edc6e941608c3b9d6661c3776.png)

![](../Images/46a3a016f8aa6c9b6754da7efd13673f.png)

通过奇安信威胁情报也观察到该CC同挖矿相关。  

![](../Images/f504d7c05e45f483fb8f641710d03245.png)

  

在此过程中还发现了一个add.exe，是一个管理工具包括有账户提权、修改账户密码、进程管理、runas、远程连接、ip端口扫描、mssql连接、下载器功能。

![](../Images/0fc170bc110e6261170a6340de2ef995.png)

  

down.exe，即其下载传播模块的恶意程序，cc相关为39.100.124.206。

![](../Images/acfd689ceb72934dc798746eb86b1b1a.png)

  

此时投放的勒索主体cpt.exe其版本标志依旧为Satan\_Crypt互斥体。

![](../Images/21c09a40ce120fe9cd5a9016ccfcd9e6.png)

  

在此阶段应急时发现用户既没有安装任何杀软，也没有打相关漏洞补丁，且服务器管理密码相同，在处理完毕后提示用户需要进行必要的系统加固。而在2020年初又接到用户求助，发现用户再次遭受勒索攻击，即遭受了SatanCryptor 5ss5c攻击，但在分析过程中发现相关系统并没有下线，此次攻击还是利用了泛微e-cology OA漏洞执行，并在目录下发现冰蝎webshell。

![](../Images/bfedaac229782958744713f0c53511f6.png)

  

其相关CC为38.21.243.3，1234端口下的地址已无法访问。

![](../Images/ab9f729ebfa452a856a8d1ea4a4fa0e9.png)

  

该域名下的威胁情报显示其均为菠菜和色情产业相关。

![](../Images/faea890788a9f3bfaf6895cff61ec974.png)

![](../Images/a5de764fbe716e1ee532d95f90dc3cd4.png)

而其50050端口为CS端口，通过fofa数据也可以确认。  

![](../Images/69bcce0c65af2cbfd1f9b1e04eaa871b.png)

  

而在这次的样本中分析发现cpt.exe已更新到5SS5C变种，其编译时间在2020年1月12日，几乎与用户遭受攻击的时间重合。

![](../Images/93a49f75128c7a156bc6f10fa3ba02f8.png)

![](../Images/8cd145d751d84f9ea2b41ed88d154a23.png)

其创建的互斥量已改为5SS5C\_CRYPT。  

![](../Images/96904398395154625f69605342586297.png)

  

在ProgramData下判断5ss5c\_token是否存在（即勒索是否执行过），并创建5ss5c\_token文件。

![](../Images/c225484876db07bbd87ab5525fc5f9b3.png)

  

**而在其传播模块c.exe中可以发现其更新了攻击方式：**

  

1.利用MiMikatz抓取密码

![](../Images/4fe1b4ff7bbbc53b4be2f39e45cee7c4.png)

5.利用抓取的密码及弱口令尝试连接SQLServer并SQL Server xp\_cmdshell执行命令下发

![](../Images/ab0b953c0744c58a3cece2d857a571b0.png)
