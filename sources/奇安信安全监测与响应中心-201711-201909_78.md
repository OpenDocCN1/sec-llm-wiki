## 0×01 测试程序

  

Linux系统中执行命令主要依靠execve函数族，可以通过hook execve函数的方法监控命令执行，首先编写两个测试程序帮助寻找hook。

  

execute.c:

  

#include <stdio.h>

#include <stdlib.h>

#include <unistd.h>

 

int main**(**int argc**,**char**\***argv**\[\])**

**{**

    char**\***newargv**\[\]****\=****{****NULL****,**"hello"**,**"world"**,****NULL****};**

    char**\***newenviron**\[\]****\=****{****NULL****};**

    **if****(**argc **!=**2**)****{**

        fprintf**(**stderr**,**"Usage: %s<file-to-exec>\\n"**,** argv**\[**0**\]);**

        exit**(**EXIT\_FAILURE**);**

    **}**

    newargv**\[**0**\]****\=** argv**\[**1**\];**

    execve**(**argv**\[**1**\],** newargv**,** newenviron**);**

    **return**0**;**

**}**

myecho.c:

  

#include <stdio.h>

 

int main**(**int argc**,**char**\***argv**\[\])**

**{**

    int i**;**

    **for****(**i **\=**0**;** i **<** argc**;** i**++)**

        printf**(**"argv\[%d\]:%s\\n"**,** i**,** argv**\[**i**\]);**

    **return**0**;**

**}**

将myecho程序路径作为参数传递给execute程序，execute程序将会调用execve函数使用指定的参数执行myecho程序，而myecho程序将会打印出参数。

  

使用strace跟踪程序运行从而获得程序执行的细节

strace–o output.txt ./ execute ./myecho

首先看到在终端下执行命令是通过execve完成的，Google了程序执行时打开的几个文件后，发现/etc/ld.so.preload这个文件比较重要，可以用来劫持系统调用，并且找到了程序调用的libc库的位置，用IDA打开libc库并查看导出表，可以看到execve函数族还有另外几个相同功能的函数，在Hook的时候必须找到一个合适的Hook点避免遗漏。

确定了Hook点之后，就可以选择Hook方案了，这时有几个选择：

在应用层：

  

1、在ring3通过/etc/ld.so.preload劫持系统调用

2、二次开发glibc加入监控代码(据说某产品就是这么做监控的)

3、基于调试器思想通过ptrace()主动注入

 

在应用层做Hook的好处是不受内核版本影响，通用性较好，而且技术难度相对较低，但是缺点更明显，因为ring3层的Hook都是针对glibc库做的监控，只要直接陷入0x80中断，就可以绕过glibc库直接调用系统调用，比如近期分析的某挖矿木马：

  

![](../Images/905b4bcdcde9a497009a30609c00ca7f.png)

  

既然应用层的监控行不通，那就看看内核层的监控手段：

  

1、API Inline Hook

2、sys\_call\_table Hook

3、IDT Hook

4、利用LSM(Linux Security Module)

  

API Inline Hook以及IDT Hook操作难度较大，而且兼容性较差，利用LSM监控API虽然性能最好，但是必须编译进内核才能使用，不可以实时安装卸载，而sys\_call\_table的Hook相对易于操作，作为防御者也可以直接从” /boot/System.map-\`uname -r\` ”中直接获取sys\_call\_table地址，也可以利用LKM(loadable kernel module)技术实现实时安装卸载，所以最后选择在内核层Hook sys\_call\_table实现监控。

## 0×03 监控执行命令的进程以及对应的文件

  

1、如何获取到执行的命令

  

execve的第一个参数为被执行文件的文件名，第二个参数为参数的数组，

![](../Images/071c271d9dd1c7cdc56c5b64f47fcedf.png)

  

linux中执行的终端命令其实都是执行对应的文件，可以通过whereis命令来找到对应的文件，以很常用的ls为例：

![](../Images/caa58d3cae2d8321345d7a8301bd365c.png)

  

2、如何获取执行命令的进程路径

  

可以通过内核提供的current宏来获取当前进程的文件名，但是无法获取进程文件的完整路径，参考Linux内核源码后发现可以通过current宏获得当前进程pid，然后通过kern\_path以及d\_path获取进程文件完整路径。

![](../Images/ed8f3ad832e3cfd0cb6351483df989c9.png)
