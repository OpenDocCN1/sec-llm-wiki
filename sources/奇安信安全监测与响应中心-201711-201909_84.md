> **MyKings: 一个大规模多重僵尸网络**

  

MyKings 是一个由多个子僵尸网络构成的多重僵尸网络，2017 年 4 月底以来，该僵尸网络一直积极地扫描互联网上 1433 及其他多个端口，并在渗透进入受害者主机后传播包括 DDoS、Proxy、RAT、Miner 在内的多种不同用途的恶意代码。我们将其命名为 MyKings，原因之一来自该僵尸网络的一个主控域名 \*.mykings\[.\]pw。

  

统计 2017 年 5 月底前述被关闭的上联 URL 的访问来源 IP 数可知，独立来源 IP 总数 1,183,911 个，分布在遍布全球 198 个国家和地区。其中来源 IP 超过 100,000 的国家和地区有四个，分别是俄罗斯、印度、巴西和中国。

  

![](../Images/d9d547bcf7dd77dc45d20098628b9b82.png "undefined")

  

2018.1.17 开始，针对 1433 端口的扫描流量有明显的下降趋势，从我们对此 Botnet 的跟踪来看，此前支撑该 Botnet 的主要 C2 之一 67.229.144.218 停止服务。随后，2018.1.23 凌晨我们发现一个新的 C2 IP 上线： 67.229.99.82。另外，我们发现该团伙还在陆续更新 Botnet 后面其他的基础设施。获取该 Botnet 相关的主要样本详细分析请查看原文：

> # **区块链技术安全讨论**
> 
> ## 
> 
> # 

  

区块链技术是金融科技（Fintech）领域的一项重要技术创新。作为分布式记账（Distributed Ledger Technology，DLT）平台的核心技术，区块链被认为在金融、征信、物联网、经济贸易结算、资产管理等众多领域都拥有广泛的应用前景。区块链技术自身尚处于快速发展的初级阶段，现有区块链系统在设计和实现中利用了分布式系统、密码学、博弈论、网络协议等诸多学科的知识，为学习原理和实践应用都带来了不小的挑战。

  

![](../Images/4f7788022c0de25a791743b2e884faa5.png)

  

由于区块链技术的特性，在设计之初就想要从不同维度解决一部分安全问题：比如 Hash唯一性， 密码学安全性， 身份验证，去中心化的分布式设计和传输安全性。同时还要考虑数字货币的安全性和交易平台安全性。

  

虚拟币的火热，直接搅动着金融市场与科技市场，也面临着各种安全问题。现在各个国家也开始对区块链市场与虚拟币市场相继出台政策与治理方案，对交易所也开始纳入管控范围，作为虚拟币交易平台，是否有资质有能力保护在线虚拟货币的安全性成为一个值得考究的问题，虚拟币已经渐渐的从网络进入到现实世界中，然而这个过程的进步同样带来了很大的隐患，这也促使着政府企业以及个人对交易平台以及虚拟币本身更加的慎重选择与投入。（来源：安全客）

> # **2017年度安卓系统安全性生态环境研究**
> 
> # 
> 
> ## 

  

360 Alpha Team发布了《2017年度安卓系统安全性生态环境研究》，截止至2017年12月，所测设备中93.94%的Android手机存在安全漏洞，有6.06%的设备完全没有检测出漏洞，安全程度同比上升1.64%，这一数据刷新了国内安卓系统安全生态情况的最高纪录，同比2016年，手机安全程度呈上升趋势。

  

![](../Images/2d0be8a69d8675df5a3c865310110134.png "undefined")

  

安卓手机用户中，约有46.0%的用户会保持手机系统（特指安全补丁等级）版本与厂商所提供的最新版本保持一致，约有14.6%的用户的手机系统版本会保持滞后厂商最新版本1到3个月，接近9%的用户会滞后4到6个月，其余用户会滞后半年以上。其中保持手机系统更新的用户相较上个季度无明显差异，同比2016年，也无明显差异。

> # **指纹识别安全吗？触摸键摔裂随意解锁橘子皮也行**
> 
> # 
> 
> # 
> 
> # 
> 
> ## 
> 
> ## 
> 
> ## 
> 
> # 

  

近期，研究人员发现在指纹识别能任意解锁。破解指纹验证的关键在于指纹触摸键上的图案。在指纹识别触摸键贴上(胶布或指纹贴)，再涂抹导电介质，只要机主成功解锁开机几次后，别人便都可以随意开机。因为指纹传感器接收到的信息包含指纹贴上的导电涂层，并不完全是机主手指的指纹。而在进行指纹比对时，只要部分信息相同就能通过验证。因此经过处理，任意指纹都能够验证通过，甚至橘子皮也能解锁成功。

  

> ## **恶意 Chrome 插件影响超过五十万用户和全球业务**
> 
> ## 

  

2018年1月21日，国家信息安全漏洞共享平台（CNVD）接收了OAuth 2.0存在第三方帐号快捷登录授权劫持漏洞（CNVD-C-2018-06621）。综合利用上述漏洞，攻击者可通过登录受害者账号，获取存储在第三方移动应用上的敏感信息。由于OAuth广泛应用于微博等社交网络服务，漏洞一旦被黑客组织利用，可能导致用户隐私信息泄露。 CNVD对上述漏洞的综合评级为“中危”。

> ## **英特尔暂停发放CPU补丁， Linux之父怒批“Spectre补丁是彻底的垃圾”**
> 
> # 

  

英特尔周一表示用户应当停止在受影响的设备上部署Meltdown和Spectre漏洞补丁，因为目前发现了超出预期的重启问题以及其他不可预测的系统行为。由于英特尔还没有为CPU安全漏洞提供适当的修复，Linux Kernel 4.15版本的推出不得不推迟。这可能是让 Linus Torvalds 再次进入“骂人模式”的原因。

  

![](../Images/9dca460718cb649cae3d1e414e314a05.png)

  

安全漏洞爆出后，操作系统供应商都在进行漏洞的软件层面更新，而芯片厂商英特尔负责固件级别问题。 但目前看来，英特尔似乎没有做好自己的工作。（来源：FreeBuf）
