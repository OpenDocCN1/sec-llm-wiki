# 基于投票的热门域名排名——奇安信前沿研究在亚太区DNS学术论坛上分享

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4OTU4MjQ4Mg==&mid=2247485979&idx=1&sn=0cf7c93d1b7740859076a65cb0ac5252&chksm=cfe8ece6f89f65f050ef724201f97ad1e68c4eebde20a9591bea83b2485698e42638d202c437&scene=126&sessionid=1681373419#rd](http://mp.weixin.qq.com/s?__biz=Mzg4OTU4MjQ4Mg==&mid=2247485979&idx=1&sn=0cf7c93d1b7740859076a65cb0ac5252&chksm=cfe8ece6f89f65f050ef724201f97ad1e68c4eebde20a9591bea83b2485698e42638d202c437&scene=126&sessionid=1681373419#rd)

2022年3月30日，在亚太区DNS（域名系统）学术论坛上，奇安信技术研究院分享了关于DNS的前沿技术研究——“使用PDNS构建透明，稳定，不易被攻击的基于投票的域名顶级列表”。

  

该研究已被安全领域四大顶会USENIX Security 2022录用。该研究由佐治亚理工学院谢秦歌、奇安信技术研究院研究员汤舒俊、郑晓峰以及清华大学刘保君、段海新教授等合作完成。

  

域名排名列表是互联网测量、安全和隐私研究社区的关键资源。此前，已经有数百项的研究使用过这些列表。然而，现有的排名列表（如Alexa top 1M, Cisco Umbrella top 1M等）存在许多问题，包括列表数据源和构建方法缺乏透明度，波动性高，排名容易被操纵。尽管存在这些缺陷，但由于缺乏合适的替代品，这些排名列表今天仍然被广泛使用。

![](../Images/c3dc453725a5152821237a6f0237e655.png)

    **  图1 基于投票的域名排名**

奇安信技术研究院的研究员基于海量的PDNS（被动DNS）数据集，系统地探索了构建域名排名列表的方法，调查了不同的域名排名方法所存在的问题，开发了一种基于投票理论的域名排名算法。通过量化单个IP的域名偏好，得到局部的域名排名，再根据投票机制确定整体的域名排名。研究团队评估了基于投票理论的域名排名列表，在所使用的被动DNS流量数据集下证明它比现有的排名列表具有更好的稳定性和抗操纵性。更重要的是，本研究提供了一种通用、公开、透明的针对被动流量的流行度排名算法。  

  

ICANN（The Internet Corporation for Assigned Names and Numbers）是互联网名称与数字地址分配机构，负责在全球范围内对互联网唯一标识符系统及其安全稳定的运营进行协调。2022年亚太DNS论坛，由 ICANN 和 MYNIC BERHAD（即“.MY”的注册管理机构和注册服务机构）联合举办，主题为 “超越技术：DNS 的变革”，探讨技术主题，行业趋势、商业机会，以及监管、政策和技术发展对DNS行业的潜在影响等主题。
