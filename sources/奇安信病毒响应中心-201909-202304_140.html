概述

受近期比特币暴涨的影响，越来越多的用户涌入到了数字货币圈中，而对于潜藏在各大数字货币交流群中的灰黑产从业者来说，新用户的出现就约等于新“肉鸡”的上线。近日，奇安信病毒响应中心在日常灰黑产挖掘过程中发现多个数字货币交流群中均出现了木马文件，详细分析后，我们发现这是一个在Telegram活跃了多年的黑产家族，奇安信和友商曾多次对其进行披露，但这并没有让该团伙有一丝的收敛，反而是在不断扩大他们的传播途径。
基于奇安信大数据平台，我们发现已经有普通用户中招。恶意样本执行之后，会在内存中解密Farfli远控木马并在内存中反射加载，加载过程中无后续文件落地。为了防止威胁进一步扩散，奇安信病毒响应中心对此事件进行分析和披露。

加载器分析

Farfli是一种运行于Windows系统的木马程序，该恶意代码通过创建服务方式自启。受此恶意代码感染的计算机可以被用作DDoS攻击。
Farfli家族木马可实现对“肉鸡”设备进行文件管理、键盘记录、远程桌面控制、系统管理、视频查看、语音监听、远程定位等远程操纵的高威胁功能。该家族木马最早出现时间约在2007年到2008年间，并且作者将源代码通过某种途径开源于互联网，经过十几年的更新迭代，目前Farfli家族木马达到了“泛滥成灾”的态势。
以<老挝金山角再封11天.cmd>样本为例，原始样本由upx加壳，是一个MFC编写的加载器。样本运行之后，首先会尝试打开指定的注册表项以判断当前计算机的操作系统是否基于Intel 386平台，若不是则退出。


接着程序将会通过指令vpcext 7,0Bh检测虚拟机。


通过404EF0函数动态解密API地址。


循环解密Farfli并拷贝到新开辟的内存中。


获取指定导出函数的地址并调用该导出函数。

接着程序将通过sub_1000A048函数创建线程。

接下来程序将会再次对当前的运行环境进行一个判断，包括调用进程判断：判断自身是否是被rundll32.exe调起，如果是则查找并结束掉rundll32.exe进程。


此外，程序会根据预定义变量byte_100132B8和操作系统环境的不同，程序执行不同的操作，一共有五套处理逻辑：

  4. byte_100132B8 == 0

  5. byte_100132B8 == 其他值


无论执行哪套逻辑的代码， 程序都会调用sub_10008EA4函数与C2建立连接并通信。


Windows10系统代码分支

新线程则会将当前进程的路径写入到Run注册表键值中以实现开机自启动，注册表键名称为：Aguqaae.exe。

线程执行完之后，程序会调用网络请求函数与C2建立连接。


byte_100132B8 ==2

当 byte_100132B8的值等于2时（此样本逻辑为2），程序首先会尝试打开Rsdnrt khnxrsmi这个注册表键以判断是否存在该服务，若已经存在则通过StartServiceCtrlDispatcherA启动服务，若该注册表不存在，则会跳转到后面创建服务。


若不存在该注册表键值，程序则会将自身拷贝到C:\Program Files (x86)\Aguqaae.exe，并且将该文件设置为系统级隐藏文件。

byte_100132B8 ==1

关联分析

对本次捕获的其他样本进行分析，可知样本只是外层loader有所不同，加载的dll均为Farfli远控木马，这些样本请求C2相同：ssy.skt-one.com，只是创建的服务名有所不同。


在此样本中，程序关联的的C2是：ssy.skt-one.com。


基于奇安信ALPHA威胁分析平台，可以看到多个关联域名均已打上了对应的标签信息，其中每个域名在2021年就已经关联了数百个不同的样本，某些域名的单日访问次数就已破万，可谓是触目惊心。


总结

本次捕获的恶意样本所对应的家族是一个长期活跃在Telegram群聊中的网络犯罪团伙，该犯罪团伙有着较为完整的攻击流程和敏锐的嗅觉，能够很快加入到新用户较多的群聊中并投递多个话题相关的诱饵文件，成功率较高。目前只看到该家族在Telegram群里中活跃，暂未发现其他的传播途径。
奇安信病毒响应中心再次提醒广大用户，请勿在任何群聊中下载/运行陌生人发送的文件，不要接收任何陌生人私聊的文件，树立良好的安全意识，不要沦为攻击者牟利的工具。
天擎用户请及时更新病毒库以查杀此类恶意样本的最新变种。另外，企业用户可以建设态势感知，完善资产管理及持续监控能力，并积极引入威胁情报等产品，以提高多维度防御的能力。
