# 比特币暴涨，数字货币交流群木马激增

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5Mzg5MDM3NQ==&mid=2247487802&idx=1&sn=c3fd7b0f290786dc6c8d0b9c53332127&chksm=ec6a6112db1de804c4a1311149479ba0e11722d8a6102a4948c76ad4be1e9d67e67375fc633d&scene=126&sessionid=1681380788#rd](http://mp.weixin.qq.com/s?__biz=MzI5Mzg5MDM3NQ==&mid=2247487802&idx=1&sn=c3fd7b0f290786dc6c8d0b9c53332127&chksm=ec6a6112db1de804c4a1311149479ba0e11722d8a6102a4948c76ad4be1e9d67e67375fc633d&scene=126&sessionid=1681380788#rd)

**概述**  

受近期比特币暴涨的影响，越来越多的用户涌入到了数字货币圈中，而对于潜藏在各大数字货币交流群中的灰黑产从业者来说，新用户的出现就约等于新“肉鸡”的上线。近日，奇安信病毒响应中心在日常灰黑产挖掘过程中发现多个数字货币交流群中均出现了木马文件，详细分析后，我们发现这是一个在Telegram活跃了多年的黑产家族，奇安信和友商曾多次对其进行披露，但这并没有让该团伙有一丝的收敛，反而是在不断扩大他们的传播途径。基于奇安信大数据平台，我们发现已经有普通用户中招。恶意样本执行之后，会在内存中解密Farfli远控木马并在内存中反射加载，加载过程中无后续文件落地。为了防止威胁进一步扩散，奇安信病毒响应中心对此事件进行分析和披露。

**样本分析**

**加载器分析**

Farfli是一种运行于Windows系统的木马程序，该恶意代码通过创建服务方式自启。受此恶意代码感染的计算机可以被用作DDoS攻击。Farfli家族木马可实现对“肉鸡”设备进行文件管理、键盘记录、远程桌面控制、系统管理、视频查看、语音监听、远程定位等远程操纵的高威胁功能。该家族木马最早出现时间约在2007年到2008年间，并且作者将源代码通过某种途径开源于互联网，经过十几年的更新迭代，目前Farfli家族木马达到了“泛滥成灾”的态势。以<老挝金山角再封11天.cmd>样本为例，原始样本由upx加壳，是一个MFC编写的加载器。样本运行之后，首先会尝试打开指定的注册表项以判断当前计算机的操作系统是否基于Intel 386平台，若不是则退出。

![](../Images/e762767396eee1e711c3bad59ec3dc1a.png)

  

接着程序将会通过指令vpcext 7,0Bh检测虚拟机。

![](../Images/16491be165b6e06928f6eb39383c4fca.png)

  

通过404EF0函数动态解密API地址。

![](../Images/85303043447615b3c53997652ea1acd8.png)

  

循环解密Farfli并拷贝到新开辟的内存中。

![](../Images/60a5bbaa9477bfccea43ee9234a7f418.png)

  

获取指定导出函数的地址并调用该导出函数。

![](../Images/996bdab895b69e7685c8edbe5c9717be.png)

  

**Farfli远控分析**

该导出函数首先会获取用户计算机的GUID和操作系统版本信息。

![](../Images/515059e692a7e9033b9fea0bffa1f7b3.png)

  

接着程序将通过sub\_1000A048函数创建线程。

![](../Images/6cf384c6c36ba25eac6e624b05210016.png)

  

具体实现是通过\_beginthreadex创建传入进来的参数。

![](../Images/126428d58f067e54ff5cc9bc8b35176c.png)

  

创建的第一个线程会调用下载函数，在函数中程序会获取函数的参数，若参数是一个url地址，程序则下载该地址的文件保存到本地并加载执行。

![](../Images/0b72de1aa26c74f42f3363d2f3af4139.png)

  

接下来程序将会再次对当前的运行环境进行一个判断，包括调用进程判断：判断自身是否是被rundll32.exe调起，如果是则查找并结束掉rundll32.exe进程。

![](../Images/1f8a2f3f71307e9062ec10af381a37c1.png)

  

此外，程序会根据预定义变量byte\_100132B8和操作系统环境的不同，程序执行不同的操作，一共有五套处理逻辑：

1.  当前操作系统为Windows10
    
2.  byte\_100132B8 == 2
    
3.  byte\_100132B8 == 1
    
4.  byte\_100132B8 == 0
    
5.  byte\_100132B8 == 其他值
    

  

无论执行哪套逻辑的代码， 程序都会调用sub\_10008EA4函数与C2建立连接并通信。

![](../Images/1afab87eb63202ef78039014ad2c1134.png)

  

**Windows10系统代码分支**

操作系统判断：程序通过RtlGetNtVersionNumbers获取操作系统版本，若dwMajorVersion 等于10且dwMinorVersion等于0说明当前程序运行在windows10系统上，程序则会创建新线程执行。

![](../Images/59201e95d42726f629ac6b042173dca0.png)

  

新线程则会将当前进程的路径写入到Run注册表键值中以实现开机自启动，注册表键名称为：Aguqaae.exe。

![](../Images/eea0945ba22d4fb7e040df1afc7392f5.png)

线程执行完之后，程序会调用网络请求函数与C2建立连接。

  

**byte\_100132B8 ==2**

当 byte\_100132B8的值等于2时（此样本逻辑为2），程序首先会尝试打开Rsdnrt khnxrsmi这个注册表键以判断是否存在该服务，若已经存在则通过StartServiceCtrlDispatcherA启动服务，若该注册表不存在，则会跳转到后面创建服务。

![](../Images/f4370c006ac8d8343f6f97e36c7ca2dc.png)

  

若不存在该注册表键值，程序则会将自身拷贝到C:\\Program Files (x86)\\Aguqaae.exe，并且将该文件设置为系统级隐藏文件。

![](../Images/97a38f619a3d0007f891d20763daa3b4.png)

  

创建服务以实现自启动：

![](../Images/43a2628c461cf015687975d49b795e99.png)

服务启动后移除自身。

![](../Images/d306c2e34b9371e62c8a282212c63671.png)

  

接下来程序还会向注册表中写入两个值，分别是请求的模式和当前的运行时间，此处请求模式为默认，一切准备就绪， 程序则开始网络请求。

![](../Images/927e966296b274a205df07b51b1f1f03.png)

  

**byte\_100132B8 ==1**

如果配置的值为1，程序依旧是先配置好请求方式和运行时间，这里请求方式为默认。

![](../Images/823d72f55d57f1a78a3a1ddbaa21d5b7.png)

  

配置完成，程序会遍历进程查找当前系统是存在RavMonD.exe进程，若存在，则说明主机已经成功感染，则程序会创建一个线程将自身移动到指定位置并重新设置文件属性，若不存在该进程，程序则会将自身拷贝到C:\\Windows\\Aguqaae.exe并且将该路径写入到Run注册表键值中以实现开机自启动。

![](../Images/81bb04a4b29f67361865fff31fa7eec9.png)

  

最终循环调用网络请求函数：

![](../Images/0bf436e135e5c900ead340631c3ce50f.png)

  

**byte\_100132B8 ==0**

若预定义的值为0，程序在设置请求方式和markTime之后，会获取并生成当前计算机的GUID。

![](../Images/02afc93631c6b27dd7e4d393f8f22e23.png)

  

将自身移动到C:\\Program Files (x86)\\Common Files\\路径下并以生成的GUID重新命名：

![](../Images/739224a619d75c7bee1e3d0acb4f4f15.png)

  

最后调用网络请求线程。

![](../Images/7d4b235c8b8b2126d07e1134a626ac16.png)

  

**byte\_100132B8 == 其他值**

若配置的值不是0，1，2三个预定的值，程序则会直接创建线程以进行网络请求：

![](../Images/26e971db4fbe1d7e5e3b585feb045e1d.png)

  

**网络请求线程**

五个代码分支最终都会创建线程以实现网络请求，该线程首先会以<请求域名:端口:服务名>为互斥体名称创建互斥体防止重复感染。

![](../Images/09d5129fb9bacb0308a93219f11b1599.png)

  

互斥体创建之后，程序将会在Rsdnrt khnxrsmi注册表下，重新写入MarkTime的值。

![](../Images/c2a52bbfcb9f65388a1d2f744b4f6ac3.png)

  

接着尝试与C2：ssy.skt-one.com 建立连接：

![](../Images/062dc8a3ade429dfbba8931715f70276.png)

  

若成功连接到C2，程序则会新开一个线程执行10001b29函数用于接收服务器返回数据并执行后续操作。

![](../Images/84d4cc976296195d9d8b877b6e1f3978.png)

  

接收到服务器返回数据后，程序首先会对返回数据进行异或解密，接着判断返回值长度，根据长度不同执行不同的功能。

![](../Images/57a2d2b3154a0cb5cf64ded4e66a5ce4.png)

  

程序会获取本机的一些基本信息，包括操作系统版本、计算机用户名、当前样本版本等，根据C2的返回将数据传到服务器上。

![](../Images/650c41e2a7673734ae6f5e52884ff7dc.png)

  

上传数据时，程序首先会对数据进行简单的异或加密，然后循环进行上传。

![](../Images/478ffa342e31098ca478bc09b22f74d0.png)

  

**关联分析**

对本次捕获的其他样本进行分析，可知样本只是外层loader有所不同，加载的dll均为Farfli远控木马，这些样本请求C2相同：ssy.skt-one.com，只是创建的服务名有所不同。

![](../Images/7a82a47f98f687774042df7d3e628b36.png)

  

在此样本中，程序关联的的C2是：ssy.skt-one.com。

![](../Images/d08a5b15232958d0014fcc111b1d5d24.png)

  

基于奇安信ALPHA威胁分析平台，可以看到多个关联域名均已打上了对应的标签信息，其中每个域名在2021年就已经关联了数百个不同的样本，某些域名的单日访问次数就已破万，可谓是触目惊心。

![](../Images/d28cd1844394130748537a1f7998e829.png)

  

**总结**

本次捕获的恶意样本所对应的家族是一个长期活跃在Telegram群聊中的网络犯罪团伙，该犯罪团伙有着较为完整的攻击流程和敏锐的嗅觉，能够很快加入到新用户较多的群聊中并投递多个话题相关的诱饵文件，成功率较高。目前只看到该家族在Telegram群里中活跃，暂未发现其他的传播途径。奇安信病毒响应中心再次提醒广大用户，请勿在任何群聊中下载/运行陌生人发送的文件，不要接收任何陌生人私聊的文件，树立良好的安全意识，不要沦为攻击者牟利的工具。天擎用户请及时更新病毒库以查杀此类恶意样本的最新变种。另外，企业用户可以建设态势感知，完善资产管理及持续监控能力，并积极引入威胁情报等产品，以提高多维度防御的能力。
