# 遏制非法热点，为无线城市保驾护航

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247490534&idx=3&sn=6088f80c7ae19a2abb3e09e67c46ef4f&chksm=fb753de2cc02b4f4baa6666ad282b895963fabe78b8635051249b4155ed8da5870283863c38c&scene=126&sessionid=1681374073#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247490534&idx=3&sn=6088f80c7ae19a2abb3e09e67c46ef4f&chksm=fb753de2cc02b4f4baa6666ad282b895963fabe78b8635051249b4155ed8da5870283863c38c&scene=126&sessionid=1681374073#rd)

# 

2016年12月2日，上海新闻晨报披露了一则消息，提醒上海市民：目前在上海覆盖较广的免费城市无线WiFi——i-Shanghai，目前在很多区域存在冒充的WiFi热点。一旦使用甚至可能发生账号密码被盗，相关信息被窃取等危险。此消息一出，很多市民对这个惠民工程产生了不少恐慌和担忧。

![](../Images/8bd0ed851ad956d5b3bd68aff7cbeae1.png)

![](../Images/02cc3739ce3bd14402930c5e67346506.png)

据了解，上海最近又新开通了177处i-Shanghai免费上网场所。i-Shanghai免费上网场所增至1240处，覆盖了包括火车站、商圈、医院、办公楼聚集地、公园、体育场馆、文化广场等15大类人流最密集区域。

目前城市的信息化水平是城市竞争力、创新力、发展潜力的重要保障。当前大众创业、万众创新的热潮风起云涌，特别是结合“互联网+”的创新创业成为当下的热点，各地陆续建设了一批智慧型城市。

作为城市公共服务区域部分的无线WiFi是智慧城市建设的重要内容和信息基础设施。这种以畅通、便捷、智慧的基础设施支撑了信息惠民工程高速发展、促进信息消费，助推动态完整的数据分析决策，催生新的经济增长点，解决群众最为关注的民生领域等问题。提升了政府效能，促进了工业化、信息化、城镇化、农业现代化的同步发展。

然而，值得我们警惕的是，WiFi网络由于其传输介质的开放性，SSID广播的可随意修改，公众WiFi网络面临着巨大的钓鱼WiFi的安全风险。

根据中国公共WiFi热点安全报告，全中国近21%的公共WiFi热点存在安全隐患，由此引发的网银被盗、个人信 息泄露、网络诈骗等案例已成爆发性上涨趋势。

作为国内最大的网络安全公司，360人应秉承安全之本，对传统网络安全之外的这一全新领域安全加以重视，于2014年正式推出了基于WiFi的无线入侵防御系统-360天巡系统。

![](../Images/1b3bda6c4605cde16e2e56a9ff8d77b9.png)  

历经3年的市场磨练，360天巡系统已经发展到第三代，累计为银行、公安、税务、涉密企业、教育等众多行业提供了无线的安全入侵检测和无线安全防护得服务，得到了用户的一致认可和好评，并于2016年3月以1.58亿元成功中标东莞无线城市项目，该项目也是迄今为止国内首个以无线安全为主的无线城市项目。
