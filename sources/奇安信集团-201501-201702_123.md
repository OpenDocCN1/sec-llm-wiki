# 【敢于承诺勇于担当】深入解读360天擎“百万”敲诈先赔服务协议

敲诈者病毒肆虐横行，上半年攻击了我国58万终端（19.7%属于企业用户），但国内却没有任何一家安全厂商敢于承诺可以防范敲诈者病毒。但360企业安全不一样，我们敢于承诺，勇于担当！

  

**百万敲诈先赔，我们是认真的！**

![](../Images/ac1e6f7da07270af4bb027038067d957.png)  

自9月6日起，360企业安全面向所有政企用户独家推出针对敲诈者病毒的免费专属服务“360天擎敲诈先赔服务”，并做出郑重承诺：**只要政企用户开启了360天擎敲诈先赔功能，如果依然感染了敲诈者病毒，360企业安全将负责赔付赎金，为政企用户做出百万先赔保障。**

  

之所以敢于承诺百万敲诈先赔，源自于360企业安全对**360天擎对敲诈者病毒的实时追踪与快速防御响应能力的绝对自信**。事实上，自敲诈者病毒诞生之日起，360就对该病毒进行了深入的研究，并在百亿级别安全大数据分析的基础上，依托于免疫、QVM机器学习引擎和行为识别等方式，以及独家推出的“文档防护功能”，对敲诈者病毒进行全面的防御和拦截，**已经帮助政企用户抵挡住了敲诈者病毒的一轮又一轮攻击。**

  

关于360天擎敲诈先赔服务，几个关键点您不可不知：

（1）赔付前提：**不间断****开启360文档保护功能与360天擎敲诈先赔服务功能**。

（2）申请时效：遭受敲诈病毒勒索之日起的**72小时内**。

  

（3）赔付金额：服务期间，如果政企用户感染了敲诈者病毒，**每终端每次获赔上限为1万元人民币或3个比特币**，**每企业用户****累计获赔上限为100万元人民币或者 200个比特币**。
