# “安全创客汇”十强揭晓 10亿资金投向安全行业

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247490606&idx=1&sn=5e5cfcf05ba64da901fe9946e635b1a2&chksm=fb753a2acc02b33c666e3816bcf00befb5819d27f13adcf1f4de49bab96fd614492c653d8c97&scene=126&sessionid=1681374103#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247490606&idx=1&sn=5e5cfcf05ba64da901fe9946e635b1a2&chksm=fb753a2acc02b33c666e3816bcf00befb5819d27f13adcf1f4de49bab96fd614492c653d8c97&scene=126&sessionid=1681374103#rd)

国内首个聚焦安全的孵化器工程“安全创客汇”十强企业揭晓，白帽汇、南京安贤、芯盾时代等十家初创公司将会亮相2016互联网安全大会，现场演示最前沿的安全技术，接受来自硅谷安全创业教父弓峰敏、4大国际知名投资机构合伙人、大会评委的指导。

![](../Images/9d1c32081790a5f5b8ab9196a8bcc82f.png)  

“安全创客汇由”360互联网安全中心和新京报寻找中国创客联合主办，旨在公开选拔最具潜力的安全初创公司，鼓励更多的资金和人才进入到安全行业。大会收到近50家安全企业的创业计划书，从中甄选出10支最具创新性的初创安全公司。据主办方介绍，在这十支初创安全公司中，多数厂商以云安全和大数据安全为主。

**云计算、大数据安全受重视  
车联网安全初露锋芒**  

以芯盾时代为例，其致力于解决互联网环境下存在的身份欺诈、身份仿冒、身份劫持等问题，着重为银行、 证券、保险、政府、公共事业等单位提供基于业务的、大数据风控的身份认证反欺诈系统。  

南京安贤则是一家专注于云计算基础架构层的安全的企业，擅长以数据分析为核心采用创新的无代理安全技术，打造可视化安全运维产品。目前该产品已为十多家国内大型云计算厂商采用，主要解决虚拟化安全防护效率低下以及未知威胁的防护等问题。

![](../Images/b22d323aa7c81876649b4bb977e690c6.png)  
此外，当下火热的车联网安全也引起了安全企业的重视，这十家企业中的VisualThreat就是一家领先的车联网安全厂商，其不仅开发了全面的汽车防御系统，可抵挡外界对汽车的攻击，还能够帮助汽车厂商、供应商和用户在不改变现有产品架构的基础上实现汽车的智能化和安全化。

  

**抢占蓝海  
初创安全企业的机会与契机**  

随着云计算和大数据的发展，越来越多的数据和应用开始翱翔于云端。这也让越来越多的企业开始意识到，云与数据安全是非常紧迫与重要的问题。国内安全专业媒体咨询机构安全牛，为此次大赛推举了多家安全初创公司，安全牛主编李少鹏表示，今后一到两年的挑战将集中在云端及其聚合的数据资产中展开，安全行业需要不断地创新。  

硅谷安全创业教父、本次评选的评委之一弓峰敏先生表示：“无论是从企业管控，还是从云端管控，从用户安全需求来讲，我们有着很大的探索空间。尤其是在IOT和智能汽车这样的领域。”

![](../Images/271fde8e95f5be02fdef9bd37922c7a4.png)  
正因如此，越来越多的安全企业将目光瞄准了云、大数据安全。在这方面，初创安全企业拥有先天的优势：尽快冲入蓝海，把重点放在前沿技术上，迅速占领滩头阵地，为企业未来的发展打下了良好的基础。

  

**资本市场看好  
将有10亿热钱流入安全行业**  

2016互联网安全大会不仅为初创安全企业提供了展示自身实力的舞台，同时也为其后续的可持续发展做了深入的考量。在甄选过程中，硅谷安全创业教父弓峰敏、红杉资本中国基金合伙人郑庆生、红点创业投资基金全球主管合伙人袁文达、IDG资本合伙人牛奎光、执一资本创始合伙人陈文江也参与其中。因此，十家初创安全企业不仅能得到现场安全专家的指点，还有打动投资人的可能,入围的优质项目将有机会入围新京报寻找中国创客第二季，获得新京报全媒体阵容的关注，优胜者还将获得通往乌镇（世界互联网大会）的门票。

![](../Images/165025e61a2dd38f29bb4d20838024ce.png)

安全行业虽然是一个相对垂直的领域，但并不缺乏发展空间。据Gartner的数据显示，预计2014—2019年安全市场增速超过10%，同期，安全投资增长更快，增速超过30%，可以预见，未来3年安全市场将会迎来爆发式增长。此次活动投资方表示：未来，将会有数10亿人民币投向安全市场。这对立志投身于安全行业的企业来说，无疑是个好消息。

  

**“安全创客汇”十强企业  
（排名不分先后）**  

**![](../Images/00e4392ab325eb0b24bf52332fdfdfd5.png)  
**

**芯盾时代**

北京芯盾时代科技有限公司致力于解决互联网环境下存在的身份欺诈、身份仿冒、身份劫持等问题，着重为银行、证券、保险、政府、公共事业等单位提供基于业务的、大数据风控的身份认证反欺诈系统。

**天空卫士**

天空卫士在数据安全、WEB安全、邮件安全、移动安全和接入云安全等领域开展深入研究和研发，目前已完成多个产品，为组织有效应对APT攻击、钓鱼信息、内部数据窃取等威胁提供可靠保障。

**岂安科技**

岂安科技帮助企业解决互联网领域的业务风险，场景包括真假用户识别，账号欺诈/盗用、交易欺诈监控、恶意订单、补贴滥用、盗卡盗刷等等，并拥有一系列带自主知识产权的核心产品。

**凌晨**

凌晨网络科技专注于企业安全，以信息安全视角，联动安全运维环节，让用户在企业信息自主可控的情况下最大程度提升企业自身信息安全等级。

**亿盾互联**

北京亿盾互联科技有限公司致力于互联网金融，专注反钓鱼网站，为互联网机构提供专业的一站式反钓鱼网站安全解决方案，实现对钓鱼网站全面侦测、快速发现、快速关停和深度追踪。

**白帽汇**

白帽汇是一家专注于安全大数据、企业威胁情报，为企业提供尖端安全产品和服务的一家高科技互联网企业。

**南京安贤**

南京安贤目前拥有以数据分析为核心的可视化安全运维产品，采用创新的无代理安全技术，效率提升300%以上。

**Clearclouds（南京云利来）**

南京云利来致力于成为全球专业的网络可视化解决方案供应商，已推出全球领先的网络流量可视化方案，对内用于智能运维，对外进行安全预警，适用于用互联网提供服务的各行各业。

**安焦数据**

安焦数据专注于企业安全威胁管理与运营服务，坚持威胁数据合作与技术创新，为企业提供“多维度检测，快响应”的安全运营服务。

**VisualThreat**

VisualThreat是领先的车联网安全厂商，公司的汽车安全防御体系采用先进的防火墙和安全策略更新机制，最大限度阻断汽车攻击，同时领先的空中更新算法为车厂节省大量汽车更新的成本。
