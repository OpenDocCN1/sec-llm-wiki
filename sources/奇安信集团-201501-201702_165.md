# 无线电安全和全栈安全——从软件无线电说起

在互联网行业有句话：“Software is eating the world!”

  

这是网景公司的创始人马克.安德森(Marc Andreessen)说的，我想这句话不仅针对互联网公司，对整个工业界都是成立的。软件使得各行各业的研发过程变得越来越简单，成本越来越低，技术更新迭代的速度也越来越快。

  

我是学通信出身的，关注软件无线电（Software Defined Radio，SDR）很多年。软件无线电可以看做是通信系统的软件化。无线通信行业，有了SDR的进入，正在发生快速的变化。

  

SDR技术，从一开始就跟安全紧密相关。安全公司，以及政府的无线电监控部门，军方的实验室，都对此很有兴趣。最早应用SDR技术的使用者都是军方。民间Hacker也是SDR用户中很大的一个群体。目前SDR技术已经广泛的使用在各个频段，用于无线电信号监听，逆向分析，欺骗攻击，监控防御等等。我们UnicornTeam团队，在日常的安全研究工作中，也经常使用SDR工具。

  

太早之前的故事，咱们就不细说了。2000年以后，推动SDR技术的两大功臣，是GNU Radio/USRP这对搭档。

![](../Images/6166e470c48bf8799353dfa9d26514f8.png)  
Matt Ettus和USRP1

  

USRP是2004年由Matt Ettus开发的，公司就命名为Ettus Research。在USRP出现之前，SDR都是基于一些价格十几万人民币的PCI板卡。USRP一下子把SDR的门槛拉低到了几千元人民币。更有意思的是，这个公司的硬件是开源的，它的电路原理图、HDL代码和上位机代码都是开源的。于是国内一下子就出现了好几家复制USRP的公司，价格更便宜。2010年，Ettus公司被NI（National Instruments）收购，但仍然保持独立的品牌，并且继续保持开源的风格。USRP现在已经被广泛用在各种与无线通信相关的科研、教学、监控监测、军事和安全方面。并且USRP一直在持续的推出新产品。今年Ettus更是推出了一款体型小巧还自带电池的USRP E312，可以支持70M~6GHz这么宽的频率，上面带有一个主频866MHz的双核ARM。这样的硬件能力，可以做很多事情了。杨卿开玩笑跟我说，“Ettus这么搞下去，早晚会被恐怖分子拿来当枪一样武装”。

![](../Images/e332c7a72e694a137c5b0119c1044650.png)  
USRP E312

  

好搭档中的GNU Radio最早出现在2001年，2004年重写了整个项目，配合USRP，实现了一套完整的软硬平台。这对搭档从此书写了SDR的新历史，使SDR成为真正普及的工具。有意思的是，GNU Radio项目的主要开发者之一，Tom Rondeau，今年3月离开GNU Radio，加盟DARPA，美国国防部下属的国防高等研究计划署，也算进入了安全圈。

  

过去开发一个通信系统，一般会有硬件工程师和软件工程师两个队伍，各自做自己擅长的部分。但是SDR出现以后，使得习惯在PC上编程的工程师，也能开发底层的通信协议栈了。因此，SDR极大的“放大”了程序员的能力。打通了应用层和通信底层的联系。

  

2009年，利用USRP，OpenBTS（http://openbts.org/）这个项目第一次用SDR实现了一个真正能用的GSM基站。而且OpenBTS是开源的，使得每一个程序员只要有一个USRP，就可以搭建一个GSM小基站。这个OpenBTS项目，后来被利用为制造伪基站。当年，谁能想到，伪基站会泛滥成今天这个样子呢？

![](../Images/87c6f6f0171f13953dbcc5d42bf038a0.png)OpenBTS开源项目和伪基站设备  

  

后来，使用SDR来实现基站的尝试就一直没有停止过。2012年，著名的法国程序员Fabrice Bellard（http://www.bellard.org/），就是那个FFmpeg和QEMU项目的创始人。他以一人之力，开发出了基于USRP+CPU结构的完整的LTE基站的功能。当时，我所在的一个小团队也在试图开发LTE软基站。听到这个新闻的时候，我简直惊讶得不知道该怎么评论此事。在传统电信设备制造企业中，开发一个基站，至少需要好几个软硬件团队相互配合。毫不夸张的说，Fabrice一个人相当于一百个普通程序员的生产力。当一个软件系统的所有细节都装进一个人的脑子里时，你可以想象，可以进行多么高效的组织和优化。这就是可怕的全栈工程师！ 

![](../Images/2bc6525aaef06f0283ae0b7faa1778e7.png)

天才程序员Fabrice Bellard

  

韩国的黑客神童Lokihardt，以通杀IE、Safari和Chrome三大浏览器而闻名于世。“传说”他现在正式的工作是在三星公司做芯片安全。如果这是真的，那他就成为了可怕的全栈安全专家，从PC软件、操作系统、到手机操作系统、手机芯片协议栈，全栈打通！  

  

安全，在万物互联的今天，攻击面已经遍及各个层面。360也不仅仅只关注PC安全、APP安全，我们也已经深入到硬件和芯片层面。各种智能硬件团队的创立，和奇酷手机的加入，使得我们也能够深入到硬件内部，分析其中的安全问题，也使得我们有机会在芯片固件的层面去做防护，还可以有机会把固件层面和手机OS结合在一起做更智能的防护。Cross-layer将会是非常有优势的一种技能。

![](../Images/55f0d6cb7c85fc26da15f9491228ed16.png)  

  

也许现在360之中还没有哪位天才能把全栈装进一个人的大脑，但是我们有各方面的攻防人才。只要大家能高效合作沟通，也能够实现跨层优化的效果。并且每个专长的Hacker，如果有余力的话，都应该尝试学习了解其他领域的技术。
