# 《2015年中国高级持续性威胁（APT）研究报告》发布

继2015年5月发布海莲花报告之后，360天眼实验室于今日发布了《2015年中国高级持续性威胁（APT）研究报告》，揭示了针对我国的APT攻击技术演变趋势。根据报告，仅2015就已发现29个针对中国境内机构进行APT攻击的黑客组织，其中14个为360天眼实验室首先发现并监测到的APT组织，包括2015年5月发布的海莲花（OceanLotus）APT组织。

![](../Images/ff62f8642122b945cb8bee1c86fa1f93.png)  

我国教育科研、政府机构是APT攻击主要针对的领域。这些APT组织从中国教育科研、政府机构等领域窃取了大量敏感数据，对国家安全造成严重的危害。其他受到攻击的行业还包括能源、军事、工业与商业等。

![](../Images/c0c76c9754f0553c05378fe3167bc889.png)  

作为360天眼实验室发布的第二份APT报告，《2015年中国高级持续性威胁（APT）研究报告》显示国内APT攻击有如下特点与发展趋势：

  

**针对中国的APT攻击主要是低成本攻击**

报告显示，针对中国的APT攻击主要由低成本的攻击组成，但由于相关防御薄弱导致低成本攻击频频得手。研究人员发现，在针对中国的攻击中， APT组织更多选择1day或Nday等已知漏洞，这说明相关机构对已曝出的漏洞并未及时修补，安全意识较差，导致黑客利用已经公开的漏洞仍然可以成功。

![](../Images/01a032d7d33255a1a7f7c0951bbfcfbc.png)  

此外，鱼叉邮件攻击是APT攻击中使用最为频繁的攻击载体。针对中国的鱼叉邮件攻击主要是携带恶意二进制可执行程序，这也从侧面反应出中国相关机构的安全防御措施、以及人员的安全意识比较欠缺。

  

**APT****组织对安全厂商主动出击**

一般来说，在APT攻击行动中从初始攻击到横向移动，各个环节都存在大量对抗手法，其目的是保证攻击成功且不留痕迹。在具体的攻击中遇到防御措施，攻击者一般会选择放弃、等待、绕过或主动突破等方法，而这些基本都是针对具体目标环境中部署的防御措施。

  

但360天眼实验室的研究人员发现，2015年发现的APT-C-00组织将木马构造伪装为Acunetix Web Vulnerability Scanner（WVS）7的破解版，其针对的目标很有可能是网络安全从业人员、研究人员或者其他黑客组织。另外，2015年还曝光率针对卡巴基斯攻击的duqu2.0。卡巴斯基在对2016年安全趋势的预测报告 中也提出“针对安全厂商的攻击”。

![](../Images/e5bddfdbf5657447713f4c31c1bf7fd8.png)  

从各方面都可以看出，APT组织针对安全行业将会从被动隐匿过渡到主动出击。这是前所未有的趋势，值得安全厂商关注。

 

**Windows****不再是APT攻击主战场**

从360天眼实验室截获的APT攻击来看，在APT攻击面前，没有任何操作系统是真正安全的。但360天眼实验室研究人员发现，在2015年针对中国的APT攻击中，针对Android、MacOS X等非Windows系统的攻击逐越来越多。如智能手机等移动通信设备，天生有传统PC不具备的资源，如通话记录、短信信息、地理位置信息等。

![](../Images/66634747a41a2f6088f4cab504b47719.png)  

研究人员认为，Windows不在是APT攻击的主战场，相关攻击会从只针对Windows操作系统逐步过渡到针对如Linux、Android、Mac OS X和工业控制系统，相关攻击出现的频率和次数将会持续增高。这提醒国内用户需要及时进行防范。

 

**安全威胁越来越难“看见”**

研究人员发现，2015年，RAT（远程访问木马）攻击武器也出现了一些新趋势。其中包括RAT文件格式整体趋势是从PE(可执行文件)到非PE转变，文件形态也由实体文件逐步转化为无实体文件，这令攻击行为往往更加难以被发现。

 

除了RAT以外,初始攻击方式逐步发展为周期性攻击、事后恢复；C&C域名大量采用动态域名，非动态域名采用域名WHOIS信息保护，进一步依托可信网站、SNS、第三方云盘等传输指令、文件等这些手法都让防御设备和安全分析人员很难定位追踪。这些技术变化都给APT威胁的感知与发现增加了难度。

![](../Images/67f16ced3f0acaf651ddbfa5d09ab65c.png)  

360企业安全集团总裁吴云坤表示，在对抗APT等新威胁方面，360一直坚持开放、合作的态度。在国内，360希望与政府机构、目标行业和其他安全厂商加强合作；在国际上也会努力与境外机构厂商建立良好的沟通和合作。最近也开放了威胁情报基础数据查询服务，以帮助国内厂商和用户更好地进行安全分析。

  

360天眼实验室负责人韩永刚透露，2016年360天眼实验将会持续发布APT相关报告，报告全文可以在360威胁情报中心（TI.360.com）下载浏览。

\---------------------------

成立于2014年的360天眼实验室致力于利用大数据技术研究未知威胁。该实验室旗下的天眼系统(SkyEye System)也是全球首个基于大数据的未知威胁感知系统。从2014年至今，360天眼已发现了20多起APT事件，持续分析跟踪其中16起的活动情况。
