# 数据泄露成高管杀手，更多网络攻击还在路上

婚外情网站Ashley Madison母公司Avid Life Media CEO、“婚外情之王”Noel Biderman于近期离职，成为新一轮数据泄露事故受害者——他绝不是惟一因安全事件而离职的管理人员。此前，美国人事管理局负责人凯瑟琳·阿楚莱塔(Katherine Archuleta)因为高达200万美国雇员信息泄露而辞职。愈演愈烈的安全事件成为高管的杀手。![](../Images/cacd4d8b7a3136554fe0af5f22880d0e.png)很多高管本身并不直接负责IT安全事务，甚至对安全一无所知。不过在当下这个网络世界当中，IT安全已成为企业获得业务成功的必要基础，而一旦出现问题、责任也将由各个层级共同承担。一**数据泄露成高管杀手**除了上述的两位高管，近两年发生的安全事件还导致了美国零售巨头Target公司CEO Gregg Steinhafel辞职和索尼影业掌门人Amy Pascal辞职。![](../Images/12a79084fc175060d0d0e59baf13aaf0.png)近期，有媒体对近10年的安全事件进行了梳理，发现有至少15位机构高管因为数据泄露而黯然离职。  
即便如此，众多的安全事件并未让高管们惊醒，很多机构的高管秉持着得过且过的侥幸心理，认为自己不会成为黑客攻击的对象。但如果认真查阅过曾经遭受过黑客攻击的受害者，就会发现即使是技术实力最强的机构也承受不住恶意人士的轮番轰炸。2014年，美国联邦调查局局长James Comey曾经明确指出：“目前只有两类机构。一种已经受到黑客的网络攻击，另一种则还没意识到自身已经受到了的网络攻击。”  
随着越来越多高管因为安全问题而断送前程，强调优先考量安全议题就十分必要与迫切了，可能未必能防范事件的发生，但至少能够未雨绸缪，降低事件造成的损失和影响。  
二**更多攻击还在路上**今年发生的数据泄露事件令相关企业或机构损失惨重或名誉扫地，这也是高管们所担忧之处。但安全专家指出，与更多还在路上的安全攻击相比，即使是克莱斯勒召回140万汽车这类黑客攻击事件，都只不过是餐前开胃菜。![](../Images/c36b059c22541e145679fe1d82a53f88.png)惠普公司预计，在2020年前，美国将遭受到更强大的网络攻击，导致银行、证交所、发电站和通信设施瘫痪。企业目前对此毫无准备，联邦机构同样如此。安全专家指出，企业甚至都不知道如何应对针对自己的攻击，，而不必说针对其他机构的攻击了。惠普的调查显示，高达57%的企业高管在如何应对黑客入侵方面，根本没有接受过任何培训。高达70%的企业高管认为，自己所在企业只是部分理解了面临的安全风险。  
近年来，作为新兴网络攻击形式代表的高级持续威胁（APT）越演越烈，尤其是随着大量的网络安全威胁和0day漏洞被发现，成为APT攻击的重要工具和途径。  
高级持续威胁（APT）有哪些新趋势？如何防范从心脏滴血到贵宾犬等各种安全漏洞？恶意软件会对机构带来哪些影响？即将于9月29日-30日召开的2015中国互联网安全大会，特别设置了“APT与新威胁论坛”，对网络威胁的新趋势进行交流，并探讨应对之道。![](../Images/c1e4868d34051b19d6eb94c2dea9915d.png)我们虽不能完全阻止网络攻击的发生，但至少可以通过技术交流，降低网络攻击的影响和损失。![](../Images/1c634e22a47e3a4fe970d578eadf8487.png)长按二维码
