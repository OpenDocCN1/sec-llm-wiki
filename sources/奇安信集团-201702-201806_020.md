# 护航数字化转型 国内首个城市网络安全运营中心发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247490151&idx=1&sn=acf51d984571a72f256afe9ecb494916&chksm=fb753c63cc02b5757023d2e99b15c73ebf1a426e152f36199915d04db1afa9f3a20a8e3d46fd&scene=126&sessionid=1681373906#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247490151&idx=1&sn=acf51d984571a72f256afe9ecb494916&chksm=fb753c63cc02b5757023d2e99b15c73ebf1a426e152f36199915d04db1afa9f3a20a8e3d46fd&scene=126&sessionid=1681373906#rd)

5月27日，在2018中国国际大数据产业博览会上，360企业安全集团正式发布了360城市网络安全运营中心，这是国内首个体系化、可落地的城市级网络安全防护和管理体系。

今天云计算、物联网、大数据和人工智能等新技术引领的新一代数字化革命，正在深刻影响着城市的发展和运营，智慧城市、数字城市、无线城市的建设推动了新兴IT技术在城市应用的深化和普及，越来越多的业务、系统、服务和设施数字化，带来了城市惠民、兴业、善政能力和水平的提升。  
  
新技术的应用推动城市发展和运营进入数据化、连接化和智能化的同时，网络空间与现实世界的边界越来越模糊，网络空间的影响会直接投射到现实世界中，网络攻击、数据泄露、数据破坏等网络安全问题会直接造成人身安全、业务停止、生产中断、基础设施遭到破坏。  
  
2017年初，境外国家组织针对我国的APT攻击从沿海城市的大型能源央企分支窃取海洋经济与权益相关信息；2017年5月，永恒之蓝勒索病毒在全球爆发，我国多个城市银行ATM终端、加油站自助加油终端都因感染病毒无法正常运行；2018年2月，国内连续发生两起医疗网络安全事故，造成了医疗数据被强行加密、系统瘫痪和患者无法就医的后果。  
  

![](../Images/2b36e0d49587f9488049f11e43f56f7d.png)

  
360企业安全集团董事长齐向东认为，在当前网络空间安全威胁日益严峻的新形势下，城市需要构建“关口前移、防患于未然”的网络安全管理体系，保障智慧城市、数字城市和无线城市建设、运营和发展。  
  
360城市网络安全运营中心就是定位于城市总体网络安全，为数字化转型中的城市构建具备全天候、全方位感知和有效防护的安全体系。  
  
该中心是以城市业务为导向、以数据驱动为基础、以安全运营为手段、以态势感知为支撑、以安全人员为核心、以协同联动为特征的城市积极防御安全体系。在实现对城市关键基础设施，民生、企业和党政等核心业务应用，政务数据等进行全方位保护的同时，实现常态化的威胁发现和响应处置，实现防患于未然。  
  
360企业安全集团高级副总裁曲晓东在发布会上表示，一个城市的网络安全体系有四个关键点：1）同步规划、同步建设、同步运营，将安全管理和防护措施前移到数字城市的规划和建设的早期阶段；2）基于数据驱动的安全能力建设，在被动防御基础上提升到积极防御的检测和响应；3）构建以态势感知和威胁情报为支撑的协同联动防御体系；4）建立以人为核心的安全运营体系。360城市网络安全运营中心在以上认识和判断基础上，将公司新一代网络安全技术和方法论在城市网络安全的落地实践。  
  

![](../Images/d2b2edf5aed7a1744a9699e71097b045.png)

  
据介绍，目前360城市网络安全运营中心已经形成了政务云安全运营、工业互联网安全运营等十大成熟体系，已经开始在多个城市落地实施，并与这些城市合作不断探索和完善运营体系。
