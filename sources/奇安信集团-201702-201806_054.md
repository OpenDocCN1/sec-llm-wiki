# 确认过眼神，你是对的云安全管理平台

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247490177&idx=2&sn=668c6e392502b7f142298d0e12f00f31&chksm=fb753c85cc02b5937780968377c49908c0cc8f495f811f2a47561e53b362f011e93165888e4e&scene=126&sessionid=1681373921#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247490177&idx=2&sn=668c6e392502b7f142298d0e12f00f31&chksm=fb753c85cc02b5937780968377c49908c0cc8f495f811f2a47561e53b362f011e93165888e4e&scene=126&sessionid=1681373921#rd)

社会粉红猪小妹佩奇一家沉迷于电脑

佩奇和弟弟乔治喜欢上网玩游戏

猪妈妈喜欢网上看菜谱

猪爸爸只能孤单一人看电视

为了重返一家欢乐温馨的气氛

猪爸爸偷偷关掉电源才让他们回到正常生活状态

  

![](../Images/aaf03a9a4a93c8a947187fd978f4c2b1.png)

  

就这样仅仅是断个电源就让猪小妹娘仨不没有再沉迷于上网······

（可爱猪猪的世界超简单，有木有？？？）

有一次，佩奇家的电脑坏了

猪妈妈喊猪爸爸修电脑，

非常尽职尽责的猪爸爸坦言“我不是很会修电脑”

经历这些无能为力的状况后

猪爸爸郁闷的想“要是有个神器

能让我成功解决这些IT网络问题多好啊

  

![](../Images/7be1f8a88fe1a40a9e3ddefc8a2eb2a4.png)

  

我们知道猪爸爸非常爱逞强但实际上没有什么擅长

为了扭转猪爸爸是“猪队友”的形象

我们假设他在一家大型的能源企业上班

肩负重任的猪爸爸不仅要负责总公司的整体运维安全

还需要管理多个子公司的网络资源

  

可能在以前，公司有新的业务上线或者有子公司接入企业内

猪爸爸和团队需要花大量时间去做规划

准备对应的网络、计算存储等IT资源

如果要解决的网络问题很多

猪爸爸还要找多家厂商采购解决不同问题的设备

通过公司整体的招标采购流程

来来回回在采购部、网络部、安全部等多个部门周旋

同时后期安装、配置、调试的时间非常漫长

  

![](../Images/e00cafafd3efb89468aad50d82ffe296.png)

  

现在，我们将**360云安全管理平台**推荐给猪爸爸使用

“笨笨”的猪爸爸马上就华丽丽变得英明神武啦~

  

![](../Images/f7aa1672b524278140d36f7668ac5868.png)

**新的业务上线后**

**业务负责人根据他业务类型找猪爸爸申请相应的资源**

**比如防火墙，Web应用防火墙、虚拟化安全的资源等**

**猪爸爸只用轻轻松松在线对这个申请进行审核**

**审核通过后，这些资源就会在平台中自动创建好**

  

![](../Images/bc106c1ed8747fc4c72b236effe72e53.png)

  

一站式的服务快速帮助业务负责人提升了效率

同时也减轻了猪爸爸的工作量

猪爸爸可以早早下班回家陪佩奇和乔治跳泥坑啦~
