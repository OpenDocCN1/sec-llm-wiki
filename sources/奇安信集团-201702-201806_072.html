美国当地时间4月16日，全球最具影响力的网络安全行业会议RSAC2018在旧金山开幕，在同期举行的展览中，各大安全厂商都会展示自己最新的产品、技术，他们展台的Slogan也将集中展示这些安全厂商对于安全行业未来趋势的理解和判断。《安全内参》选取了现场14家厂商的Slogan，跟大家一起寻找安全的趋势和未来。



Check Point：Step up to 5th generation cyber security

迈向第五代网络安全。这家老牌安全厂商通过不断重新定义安全世代来实现自我革命。


IBM:Intelligent Orchestratio

安全智能编排。


Proofpoint:Protection starts with people

安全防护从人开始。与"人是安全的尺度"异曲同工。


赛门铁克:Securing the cloud Generation

维护云时代的安全


McAfee: Together is power

团结就是力量。强调产业协同的价值，这个Slogan有点中国味道。


PaloAlto：Security built for automation

安全为自动化而生。自动化PaloAlto已经谈了一段时间了。


360：Data-Driven Security

数据驱动安全。360推出数据驱动安全理念已经三年了，这是第一次在RSA上展出该技术理念。


ForcePoint: Human-Centric Cybersecurity

安全以人为中心。另类强调“人是安全的尺度”。


Ixia:Visibility is Security

可视即安全。看得见的安全，数据驱动安全的一个分支。


SailPoint: Identity is Security

身份即安全。最近几年身份安全又热了。


卡巴斯基: True Cybersecurity for Digital Transformation

为数字化转型构筑真正的安全。


英特尔: Building innovations with security at the Coreore

安全是科技创新的基石。


RSA: Business-Driven Security

业务驱动安全。RSA提出业务驱动安全也已经很长时间了。


F5：Think app security first

应用安全第一。


从Slogan来看，不同安全厂商对于网络安全的未来都有自己的判断。这些判断既有基于大方向的把握，比如安全防护从人开始、安全以人为中心、团结就是力量；有注重安全目标的，比如保护云时代安全、为数字化转型构筑真正的安全；也有注重方法论的，比如数据驱动安全、业务驱动安全、应用安全第一、安全因自动化而生。
