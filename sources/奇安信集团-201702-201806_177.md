# 警企共建“涉网违法犯罪研究中心”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247490293&idx=2&sn=560ab6303d8121d956d767588d4f614d&chksm=fb753cf1cc02b5e71bf3bd616ef2fa74d7178b5af209843984aa7a7324355d7cc521b1874899&scene=126&sessionid=1681373962#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247490293&idx=2&sn=560ab6303d8121d956d767588d4f614d&chksm=fb753cf1cc02b5e71bf3bd616ef2fa74d7178b5af209843984aa7a7324355d7cc521b1874899&scene=126&sessionid=1681373962#rd)

“ 

11月15日，合肥市公安局和360企业安全集团共建的“涉网违法犯罪研究中心“揭牌仪式在合肥市公安局举行。市公安局党委委员、副局长杨援军，360企业安全集团副总裁何新飞为研究中心揭牌。

”![](../Images/b3a6fa9da2da22c4ff1f4ffc6e5d1215.png)

  

合肥“涉网违法犯罪研究中心”，是360企业安全集团在国内与公安共建的首家针对涉网违法犯罪进行研究的专门机构。

  

![](../Images/cc61003aa202aaa0ca0fdabb1a429282.png)

![](../Images/361b05ece8078fbdbdde5201820cf9af.png)

  

当前我国涉网犯罪占全部刑事犯罪案件总数的三分之一，并以每年30%的速度增长，未来绝大多数犯罪都会涉网。360企业安全集团与合肥市公安局共建的全国第一家涉网违法犯罪研究中心，就是为了顺应国家“互联网+”发展形势，让信息网络技术与警务工作更好的融合发展，创新打击网络犯罪的新举措，打造一流的涉网违法犯罪研究型智库，深入研究网络黑灰产业链特点，建立有效的立体化防控处置机制，全面提升合肥网络安全综合防控体系建设能力和水平，进一步提升网络违法犯罪的预防及打击能力，不断提升群众安全感满意度。

  

![](../Images/3164ed10cf6c929d9969e73b51e408f7.png)

  

仪式现场，360企业安全集团副总裁何新飞说到，在党的十九大上，总书记提出了“人民对美好生活的向往是我们的奋斗目标”的要求。人民的美好生活不仅是现实社会中的衣食住行，也包括在网络空间的学习、交友、工作。网络空间不是虚拟的，它与我们的生活空间紧密相连，互为一体。生活是否美好取决于幸福感，而幸福感是要以安全作为前提和保障的。何新飞还表示，作为全球用户数最多、中国最大的互联网安全公司，保护网络的安全，为人民服务既是社会责任也是我们的使命。2017年5月国家发改委批复360企业安全集团筹建 “大数据协同安全技术国家工程实验室”，实验室下设多个研究中心。此次与合肥市公安局共建的“涉网违法犯罪研究中心”其目的就是充分利用国家工程实验室的科研成果与360企业安全集团的装备、技术来服务合肥人民，为合肥市人民美好与幸福的生活做好安全保障 。
