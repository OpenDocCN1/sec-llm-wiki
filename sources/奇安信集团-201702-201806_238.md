# 【ISC观感之六】校企协同，打通网安人才培养最后一公里

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247490339&idx=3&sn=36a7e6015687e25c1b8e7182850410f0&chksm=fb753d27cc02b4317681d98b9a47eed2deac04dbde1d588efb405eb42c56af310e64b8ba1b9a&scene=126&sessionid=1681373987#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247490339&idx=3&sn=36a7e6015687e25c1b8e7182850410f0&chksm=fb753d27cc02b4317681d98b9a47eed2deac04dbde1d588efb405eb42c56af310e64b8ba1b9a&scene=126&sessionid=1681373987#rd)

  

今年的中国互联网安全大会(ISC 2017)提出了一个颇有深意的观点：“万物皆变，人是安全的尺度”。其实，安全本质是人与人的对抗，在几十年的网络安全行业与黑产、灰产的对抗过程中，安全人员的作用从来就没有被忽视过，只是从来没有人旗帜鲜明地把人放在这么核心的位置上，把人在安全中的作用提到这样的高度——“人是安全的尺度”！

  

的确，安全问题的根源来自与人，解决安全问题的关键也在于人，但恰恰是安全人才这个安全运营体系中的核心要素，成为困扰许多政企机构和安全公司的心病。今年5月份，永恒之蓝勒索蠕虫病毒席卷全球，国内很多政企机构中招，从不少机构手忙脚乱的应对过程不难发现，即使是系统打补丁、安全设备变更配置这样最基础的安全运维工作，都缺少合适能力的人去完成。更有甚者，不少政企机构压根儿就没有专门的安全运维岗位和组织，遇到安全事件往往是IT运维部门的非安全专业人员处置。

  

本届ISC专门设立了安全人才培养及竞技实战论坛，邀请到全球多个国家安全行业专家，共同探讨网络安全人才培养话题。

  

美国原NICE网络教育计划主任、国家协调办公室副主任Ernest McDuffie、清华大学网络科学与网络空间研究院网络空间安全实验室主任段海新、美国加州大学河滨分校钱志云、北京航空航天大学计算机学院教授李舟军、四川大学网络空间安全学院教授陈兴蜀、i春秋网络安全教育平台创始人蔡晶晶等嘉宾围绕安全人才培养话题进行了颇具见解性的讨论和分享。

ISC安全人才培养及竞技实战论坛

  

国内的网络安全公司也同样面临安全人才短缺的现实状况，往往开出高薪，也很难招聘到合格的安全人才。据有关机构统计，当前国内的网络安全人才缺口高达60万！如何高效率地培养网络安全人才，特别是缺口巨大而需求旺盛的基础安全运维人才，成为制约网络安全行业发展的重要因素，也是整个安全行业必须面对、焏待解决的问题。

  

![](../Images/144d5284a30d538ea88813bd03761d6b.png)

  

谈到基础安全运维人才的培养，国内数量众多的普通高等院校和高职院校无疑是一个理想的人才培养基地。自2001年教育部批准开班信息安全专业以来，我国已有近百所高校开设信息安全类相关本科专业

  

2015年，国务院学位委员会、教育部联合发文《关于增设网络空间安全一级学科的通知》，旨在全面提升网络空间安全学科建设水平，也为网络安全人才的培养带来了机遇。这些高校每年都有大量毕业生进入就业市场，选择到政企机构或安全公司从事网络安全相关的工作。但是，从用人单位的反馈来看，我们的安全人才培养体系并不成功。大多用人单位反馈录用的应届毕业生存在几个问题：一是理论知识陈旧，在学校中接受的安全理论教育落后于网络安全技术发展的步伐；二是安全实战经验缺乏，实际动手能力差，往往要经过长达6个月到1年的岗位训练，才能达到岗位要求。这样的安全人才培养质量和效率对急需安全人才的政企机构和安全公司来说无疑是雪上加霜。可见，在现行培养机制下，网络安全人才培养的最后一公里并没有被打通。

  

![](../Images/144d5284a30d538ea88813bd03761d6b.png)

  

造成这种状况的根本原因在于高校的安全人才教育培养与现实的人才需求之间出现了脱节。我们知道，网络安全行业的技术发展非常迅速，新的技术理念和安全技术层出不穷，按照目前高校的课程体系设置的节奏来看，很难跟上这个步伐。另外，网络安全是一个非常注重实战经验的行业，而高校很难有条件接触到实际的安全场景。国内的网络安全企业，特别是一些优秀的安全企业，他们一直战斗在安全攻防的第一线，对新理念、新技术、新产品高度敏感，追赶的也非常及时，否则就无法为客户提供优质的产品和安全服务，无法真正解决客户的安全问题，企业的竞争力也就会很快衰退导致公司的消亡。所以，国内优秀的安全企业往往是新技术的倡导者和实践者，并且积累了丰富的网络安全实战经验。

  

![](../Images/74c4e9af02cedc4dc37454580d75a440.png)

  

因此，如果能够建立良好的校企协同安全人才培养机制，把优秀安全企业和高等院校双方优势资源加以整合，建立以人才市场需求为驱动，结合现实的网络安全技术与安全产品实践经验，联合打造安全人才教育培养体系，将学生的理论知识学习、素质和能力养成、安全实战经验培养这三个方面贯穿于教育的全过程，对学生采取课程理论学习和实践教学并重的方式，使学生不但能够掌握专业基础理论知识，还能掌握网络安全实践的方法和技能，培养学生独立分析和解决网络安全问题的能力，提高人才培养的质量和效率。

  

所以，我们应当鼓励普通高校和高职院校联合优秀的网络安全企业共同建设网络空间安全院系或专业。首先，在本科四年的基础理论课程体系中，充分听取安全企业的建议，加入并不断更新代表最前沿技术趋势的网络安全技术课程，让我们未来的安全人才不要输在起跑线上。其次，安全企业需要帮助院校建立符合市场需求的实验课程，采取“以场景为基础，以问题为导向”的教学方法，以典型政企网络信息系统的规划、部署、运维、管理为目标，基于广泛应用的安全产品如下一代防火墙、终端安全管理、高级威胁检测、日志审计、漏洞扫描、源代码检测、大数据安全、云安全、无线安全等设备和实验平台，针对实际应用场景，模拟政企机构日常网络安全运维工作遇到的典型问题，依托实际案例完成实验课程，提高学生的动手能力和实战经验。最后，双方可在本科教育的最后一年开启更加深入的协同模式，安全企业为学生提供实习基地，联合校方推出安全人才的任职资格评定与认证工作，为学生的就业提供更为便利的条件，等等。

  

![](../Images/144d5284a30d538ea88813bd03761d6b.png)

  

**通过这种资源互补的校企协同模式，一定能够打通网安人才培养的最后一公里，为国家和企业的网络安全发展不断输送优秀的人才。**
