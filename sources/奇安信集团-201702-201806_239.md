# 【ISC观感之一】来自ISC的20个安全智慧洞见：人是安全的尺度

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247490340&idx=1&sn=76fd4867f3cdcfd62a3693ecce948b7d&chksm=fb753d20cc02b436216c657917cd3320158020182aa47821fb9564ece2184833be1b72ad69df&scene=126&sessionid=1681373987#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247490340&idx=1&sn=76fd4867f3cdcfd62a3693ecce948b7d&chksm=fb753d20cc02b436216c657917cd3320158020182aa47821fb9564ece2184833be1b72ad69df&scene=126&sessionid=1681373987#rd)

9月13日，中国互联网安全大会（ISC 2017）落下帷幕，大会主题“万物皆变，人是安全尺度”得到了全球网络安全行业的广泛认同和共鸣，成为未来产业和行业发展的风向标。

 

即将开幕的网络安全周的主题“网络安全为人民，网络安全靠人民“，其核心也是人是安全的尺度，从人出发，挖掘全民网络安全生产力。

  

在为期3天的ISC 2017上，来自10个国家的249位安全产业智库和行业安全专家发表了212场主题演讲，历经五年发展，ISC已经成为一个真正的全球性网络安全行业交流合作平台，来自海内外的90多家网络安全机构与国内近4万网络安全从业者、行业网络安全管理者和运维者、政企机构信息化和网络安全负责人进行了有关网络安全智慧、思想、技术和方法的深入交流和探讨。

 

“受益匪浅，专家们带来的最新研究成果和前沿趋势分享，让我开拓了视野，增长了见识，与同行交流学到了很多的宝贵经验。” 刘鑫是一家央企的网络安全负责人，在参加完2天的会议后向记者表示：“今年大会的主题为人是安全的尺度，这是一个新思维，但确实定位到了网络安全的本源，我们在日常网络安全工作中，最大的问题就是人。”

 

在大会期间，行业相关领导、产业智库和行业专家的演讲中，也表达了对“人是安全的尺度”这一大会主题的赞同。以下节选了大会期间20位专家的精彩发言，从中可以了解到网络安全产业发展和行业应用的趋势和方向。

  

![](../Images/f87a5a6069aed862f206d01e7be856e0.png)

  

**1.中央网信办副主任杨小伟**

  

维护网络安全要坚持网络安全为人民，网络安全靠人民。网络安全事关国家安全，也事关广大人民群众在网络空间的安全和利益，要坚持以人民为中心的发展理念，无论是制定网络安全法律政策标准还是加强网络安全的管理，都要以维护老百姓的合法权益作为我们网络安全工作的根本出发点和落脚点。同时，要充分发挥人民群众在维护网络安全中的重要作用，让人民成为网络安全的参与者、建设者、受益者。

  

**2.工信部网络安全管理局赵志国局长**

  

这次大会的主题是“万物皆变，人是安全的尺度”，这个主题富有哲理，变与不变既相互对立，又相互转化，相互影响，两者辩证统一。当前，网络安全面临的风险和挑战正发生新的变化，作为新一轮科技革命和产业变革的关键力量，网络信息技术对推动社会进步及人类发展的作用日益凸显，网络安全威胁和风险也随之递增、扩散、增加。

  

**3.公安部网络安全保卫局郭启全总工程师**

  

今年6月1号《网络安全法》实施以后，我们按照法律的要求和规定，去实施我们的网络安全的战略、规划、目标、策略，全国网络警察、全国公安机关要依法进行执法，我们广大的用户要守法，用好这部法，按照法律去保护好我们国家的关键基础设施，开展网络安全工作。

  

**4.国家密码管理局商用密码办公室张平武主任**

  

网络安全关系国家安全、社会稳进和人民利益，网络安全的新态势、新需求、新发展，都需要密码发挥不可替代的重要作用。本次大会的主题是“万物皆变，人是安全的尺度”，保护人民的隐私，维护人民的权益，增进人民的福祉，是网络安全的重要目标。

  

![](../Images/11808b2997f05bbb32e5833757b9c22d.png)

  

**5.中国工程院邬贺铨院士**

  

在推进互联网与实体经济融合过程中，我们面临人才匮乏的挑战。我们缺乏大量既懂新技术、又懂传统产业的“复合型”人才，网络安全领域同样面临人才缺乏问题。

  

今年中国互联网安全的主题是“万物皆变，人是安全的尺度”，就是想体现当前数字化转型与互联网创新的新形势，同时呼吁我们的主管机构、产业界和用户，重视人才的培养，重视安全人才在应对网络攻击的作用。

  

![](../Images/59190e252d46900b7de48c7ef767d4a8.png)

  

**6.中国工程院方滨兴院士**

  

网络空间是一个人造的电磁空间，包涵载体、用户、数据和操作四个要素，数据账号是主体或者用户是主体，用户也好，账号也好，背后都是人。阿尔法狗不是人，但是阿尔法狗代表的是人，它完成的是人的意志，背后总是人。这个空间里面它的主体是用户，但背后是人。

  

**7.中国工程院倪光南院士**

  

网络安全人人有责，得有政府、每一个人、每一个单位，但是企业有特殊的责任。我想产业担当这个提的很好，因为我们大家记得习主席关于网络强国说了16个字，战略清晰，技术先进，产业领先，攻防兼备。没有一个强大的网络安全的产业的支撑，网络安全是空话，网络强国不可能建设起来。

  

**8.中国工程院沈昌祥院士**

  

安全可信只有科学的，才能符合需求。现在公布的《国家网络安全空间战略》，夯实网络安全是基础强调，加快安全网络产品应用。现在什么是网络安全问题，在座每个人回答都是不一样，我作为老同志是有责任，因为国家一极学科，我通过十几年努力申报成功，一级学科有深厚的科学技术基础理论。

**9.美国退役海军上将，美国前参谋长联席会议副主席William A. Owens**

  

在军事领域，越来越多的希望能够进一步打造网络攻防能力，能够在网络空间战争上更好的做好防护，美国在网络方面有很多的投入，很多最聪明的那些人也加入其中，在军事方面希望能够在网络战争当中处于主导作用。我们需要把这些整合起来，出于国家良好的意愿，以及为了人类整体的和平，我们需要找到方式来做。

  

**10.联合国毒品与犯罪问题办公室网络犯罪全球项目主管Neil  J·Walsh**

  

我们曾经合作过的国家里面，有几千个暂时未就业的IT从业人员，如果有这么多的从业人员他们的技巧非常高，但是自己却没有工作做的话，这里就有一个非常大的网络犯罪的风险，有些人可能想去使用自己的技巧，却没有用武之地，当然有可能就会犯罪。我们把它看成是一个非常基本的机会，来加强网络安全，加强在经济方面的繁荣。

**11.Evolution  Security  GmbH公司CEO Benjamin  Kunz  Mejri**

  

我自己是一个非常叛逆的人，但是我不属于黑帽，当我开始进入到这个行业的时候，我希望能够来通过教育的方式进到这个行业里面。问题在于在德国，我当时想进入这个行业的时候，我只有一些基本的学历。这种基本的学校毕业的学历是没有办法进入到这个行业。

  

**12.生物黑客   ACKspace创始人**

**Patrick Paumen**

  

黑客不光是指进行计算机系统的攻击，有时候可能对我们身体进行一个攻破。我的身体里已经有14个装置植入，有4个是在我的指尖上，还有在我手的其他位置，这都是一些感应系统，里面是没有电池的，所以我不需要把它从我身体里面取出来，它是可以永远植入的。

  

**13.360公司董事长&CEO周鸿祎**

  

大安全时代，人是网络安全最脆弱的因素，也是网络攻击中最薄弱的环节，同时人也是网络安全中最重要的因素，网络安全是科技劳动密集型行业，需要大量的专业技术人员的智力密集型服务。我们的政企单位不仅需要培养自己的网络安全队伍，还需要充分利用网络安全企业提供的专业化的安全服务。大安全时代，网络安全服务将成为大产业、新机会。

  

**14.360企业安全集团董事长齐向东**

  

在过去十二个月里，我们还发现，85%的网络安全事件，来自内部人的疏忽、大意和故意，人还是关键。所以，今年我们提出“万物皆变，人是安全的尺度”，也就是说，人，对网络安全起着决定性作用。

**15.Comae Technologies创始人Matt Suiche**

  

我们也不知道影子经纪人有多少文件、有多少数据，这是一个大的问题。因为在这种灰色地带，它到底是一个个人还是一个组织我们现在还不知道，这也是网络安全领域值得担忧的一个东西。

  

**16.ZDI负责人Brian Gorenc**

  

在这个空间里人们有道德，更关注如何给这个漏洞打补丁，以及它背后的一些科学原理。当然还有一些进入灰市，有些人发现漏洞找出来，从中建立一个利用链，提供到政府的供应商，或者是漏洞的代理人，或者灰市上，把它卖给这些政府。我们在白市当中希望能够影响到灰市，让他们进行漏洞利用可能性更小一些。

  

**17.360首席安全官谭晓生**

  

网络空间安全的人才培养会产业化，这里面就是一个挣钱的机会。我们的人才缺口变大了，说明我们的产业需求非常巨大，但是现在的培训方法还不行，没有办法能够跟上市场需求的速度。培养黑客、培养进攻者不是那么容易，培养漏洞挖掘的人不是那么容易，但是防御者是可以批量的进行培养的。  

  

**18.思科Talos项目技术负责人**

**Holger Unterbrink**

  

勒索软件背后的这一些人，他们都是普通的人，但是这些人完全不关心到底他们造成了怎样的一些后果。他们甚至会威胁一些医院，或者威胁到人们的生命，他们却毫不在乎，只要能挣钱就行。
