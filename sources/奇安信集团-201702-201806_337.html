【重大预警】微软曝光“震网三代”漏洞，360紧急提供修复和防护方案

原文：http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247490408&idx=1&sn=ac29fc324dde98e3d98af641ced708f4&chksm=fb753d6ccc02b47aa002e2ae83491752628e42708308f78cf9e3a324ae03177de379b43d611f&scene=126&sessionid=1681374017#rd

北京时间6月14日，本月的微软补丁发布，经过360安全专家研判确认以下两个漏洞需要引起高度重视，采取紧急处置措施： LNK文件远程代码执行漏洞（CVE-2017-8464）和Windows搜索远程命令执行漏洞（CVE-2017-8543）。

该漏洞是一个微软Windows系统处理LNK文件过程中发生的远程代码执行漏洞。当存在漏洞的电脑被插上存在漏洞文件的U盘时，不需要任何额外操作，漏洞攻击程序就可以借此完全控制用户的电脑系统。该漏洞也可能籍由用户访问网络共享、从互联网下载、拷贝文件等操作被触发和利用攻击。


该漏洞的成因与2010年“伊朗震网（Stuxnet）”事件中所使用的穿透核设施中隔离网络的Windows安全漏洞CVE-2010-2568非常相似。它可以很容易地被黑客利用并组装成用于攻击基础设施、存放关键资料的核心隔离系统等的网络武器。鉴于此漏洞与震网漏洞原理及威胁的高度相似性，我们将此漏洞命名为“震网三代”漏洞。


另一个Windows搜索远程代码执行漏洞（CVE-2017-8543），涉及Windows操作系统中Windows搜索服务（Windows Search Service：Windows中允许用户跨多个Windows服务和客户机搜索的功能）的一个远程代码执行问题。Search服务默认开启，使它与之前NSA永恒系列SMB漏洞几乎有相同的影响面。


这次微软也同时发布了针对Windows XP、Windows Server 2003等之前已经不再支持的老操作系统版本的对应补丁，甚至包括了上次Shadow Brokers公布的除永恒之蓝系列漏洞以外的其他几个未修补漏洞，这个补丁发布机制的修改也许是为了避免上月发生的WannaCry蠕虫勒索事件的重演。Window XP/2003的补丁更新可以在微软下载中心找到，但不会自动通过Windows推送。

目前微软已经针对所有受影响的操作系统提供了官方补丁，360安全监测与响应中心提醒用户尽快安装补丁修复系统漏洞。


LNK文件远程代码执行漏洞（CVE-2017-8464）微软官方补丁下载地址：

https://portal.msrc.microsoft.com/en-us/security-guidance/advisory/CVE-2017-8464


Windows搜索远程命令执行漏洞（CVE-2017-8543）微软官方补丁下载地址：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-8543


同时微软也针对Windows XP、Windows Server 2003等之前已经不再支持的老操作系统版本发布了补丁。微软官方补丁下载地址：

https://support.microsoft.com/en-us/help/4025687/microsoft-security-advisory-4025685-guidance-for-older-platforms


360企业安全为方便用户便捷安装，特推出了一键式修复工具


360企业安全集团天擎团队发布的“震网三代”漏洞补丁修复工具支持对LNK文件远程代码执行漏洞（CVE-2017-8464）和 Windows搜索远程命令执行漏洞（CVE-2017-8543）进行一键式检测与修复。


下载地址：http://b.360.cn/other/stuxnet3fixtool



360天擎产品处置建议


360天擎用户升级最新的漏洞补丁库（版本1.0.1.2832）即可扫描和修复微软6月份推送的包含CVE-2017-8464和CVE-2017-8543在内的多个漏洞。




360天擎已经支持对利用CVE-2017-8464漏洞的恶意lnk文件进行查杀和拦截，可以有效防御此漏洞的攻击。



360天眼产品处置建议


360天眼未知威胁感知系统的流量探针已经加入了针对LNK文件远程代码执行漏洞（CVE-2017-8464）及Windows Search远程命令执行漏洞（CVE-2017-8543）的检测。




请尽快升级到最新版本：3.0.0614.10474。


LNK文件远程代码执行漏洞（CVE-2017-8464）对应的规则编号：0x4a62。


Windows Search远程命令执行漏洞（CVE-2017-8543）对应规则编号：0x4a63。


规则升级方法：

系统配置->设备升级->规则升级，点击“本地升级”或“网络升级”。
