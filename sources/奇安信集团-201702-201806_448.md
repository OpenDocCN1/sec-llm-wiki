# 谭晓生：解决安全挑战需借助大厂的平台整合与集成能力

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247490472&idx=2&sn=5fcea7f2b3a890d75c88efedd985aec3&chksm=fb753daccc02b4ba052b9083a9b0a84c7b1b56416be0b8ea4ad36c8b73fae48e93b8817cb6d7&scene=126&sessionid=1681374048#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247490472&idx=2&sn=5fcea7f2b3a890d75c88efedd985aec3&chksm=fb753daccc02b4ba052b9083a9b0a84c7b1b56416be0b8ea4ad36c8b73fae48e93b8817cb6d7&scene=126&sessionid=1681374048#rd)

在3月28日的RSA分享会上，360公司首席安全官谭晓生认为，过去几年里，安全初创公司的创新并没有带来解决安全挑战的银弹。用户意识到，做好网络安全还要练好基本功。安全大厂在本次大会上凭借集成、整合等能力强势回归，预示着未来在安全产业中，解决安全挑战需要基于平台的集成与整合。

在今年RSA大会上，众多大厂有着比较亮眼的表现。IBM发布了与Watson人工智能系统结合的“认知SOC”、聊天机器人以及语音能力的安全助手。Palo Alto Networks作为下一代墙的标准定义者，发布了平台Platform2.0，聚焦在集成和自动化。

谭晓生认为，传统大厂商的话语权在明显上升。过去几年中，在互联网态势里，很多新兴公司说要颠覆创新，但安全领域里，从过去四年里看，颠覆创新的范围还比较小，反倒今年看到这些大厂，凭借着集成、整合等能力强势回归。

![](../Images/e405984dfaa7cb7f45c7c6d2bc5c9d73.png)

对于传统大厂的重新崛起，谭晓生认为背后代表的是安全产业环境的变化：重要性空前提升，安全创新并没有解决安全挑战。应对挑战需要借助大厂的平台能力进行整合与集成。

2013年，Mandiant发布APT1报告，让用户着实恐慌了一阵。传统安全产品、安全理念没有办法应对新兴威胁，面对这种新的“疾病”没有办法时，就要找各种各样的方法，就像当年非典期间，板蓝根卖得特别好，醋也脱销了。

过去几年里，创新公司推的东西，不管终端还是威胁情报，大家都想把它当作救命稻草，看是不是一招就灵。经过几年时间，发现这根稻草还是救不了命，还是要回归。回归到安全的基础——防各种漏洞、打补丁等基础工作。应对安全挑战需要大厂商的平台进行整合与集成。

集成、整合涉及非常繁杂的问题，确实不是小厂商能做得了的，往往需要大兵团作战。恰恰IBM这样的大厂对合作用户的应用比较了解，自身也有工程的能力，它过去卖产品、做项目的利润率又比较高，才可能会去做。平台厂商在这时的价值凸显是非常正常的。因为他们对用户的理解、资源整合能力、复杂工程应用能力非常强。比如，我们推OpenDXL标准，如果不是Intel Security (McAfee)等大厂商，新创立的厂商新提个标准、搞个平台，基本做不起来。 

对大厂崛起对产业的影响，谭晓生认为，未来市场会走向几个巨头+若干细分领域玩家的格局。未来一定是碎片化市场，因为客户的个性化需求就在那里。安全从业人员有自己的特点，很难想象有一个大的安全公司能管理好几万名黑客。它首先是碎片市场，会有若干个大巨头，是在其中起整合和提供复杂应用的支撑能力的公司。这种竞争态势也使得新技术普及速度加快。

因此，未来产业合作与协同更加深入。360这样的厂商也觉得很多事儿自己搞不定，也不可能很多人把安全防御链条上那么多产品都做了，即使做了也做不好。360可能充当集成者的角色，某些细分领域，别人的产品做好了我拿来用，在行业内分享利益可能是不得不走的一个方向。

对创新企业来说，则需要重新思考自己的定位。虽然我们看到的光明，从国家战略方面的重视（重要性），企业前景很光明，但我们大家需要认识到未来很长时间还是会是很艰难的道路。作为安全厂商要定位好，你是作为产业中的一环还是希望作为老大，作为一环是做哪些安全细分工作。

随着安全对业务的重要影响。目前IT大企业与互联网公司进入安全领域无可避免。华为这样的企业一定会进入到安全领域。所有大的互联网公司都会进入到安全领域，不管是刚开始为了解决自身的安全问题还是它本身就奔着做安全业务，一定会进入。解决自己的安全问题之后一定会想是不是扩展这个服务。现在腾讯、阿里做安全，滴滴出行也在建立相当强大的安全团队，互联网公司进入安全领域没有悬念。

据悉，今年9月12-13日，第五届中国互联网安全大会将会在京举办，届时将会有更加精彩的安全内容分享。
