# 【漏洞预警】IIS 6.0远程代码执行0day漏洞预警及修复建议

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247490472&idx=4&sn=924f1ee5bec43525d554293a7c22ec79&chksm=fb753daccc02b4ba453f8202fb2ec690a0acf9f3fe30e3dd6250b9b450ca1208aef98e09ea0e&scene=126&sessionid=1681374048#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247490472&idx=4&sn=924f1ee5bec43525d554293a7c22ec79&chksm=fb753daccc02b4ba453f8202fb2ec690a0acf9f3fe30e3dd6250b9b450ca1208aef98e09ea0e&scene=126&sessionid=1681374048#rd)

2017年3月28日，广东华南理工大学信息安全实验室公布了一个关于Windows 2003的IIS 6.0服务的高危安全漏洞（CVE-2017-7269），远程攻击者可以利用此漏洞在开启了WebDAV的IIS 6.0服务器上执行任意命令，从而完全控制受影响的系统。  

目前，针对 windows server 2003 可以稳定利用，对于此漏洞的POC利用代码已经被发布，极有可能被修改以后作为攻击工具，对网站安全构成非常高的现实威胁。据报告称，去年七月起就有攻击者开始利用此漏洞。

IIS是Internet Information Services的缩写，意为互联网信息服务，是一种国内使用非常广泛的Web应用服务系统，被大量的Web网站所使用。最初是Windows NT版本的可选包，随后内置在Windows 2000、Windows XP Professional和Windows Server 2003一起发行。

![](../Images/a3af89ea618dba5414cd502b2b104165.png)

  

**漏洞描述**

在Windows Server 2003的IIS6.0的WebDAV服务的ScStoragePathFromUrl函数存在缓存区溢出漏洞，攻击者通过一个以“If: <http://”开始的较长header头的PROPFIND请求执行任意代码。

WebDAV （Web-based Distributed Authoring and Versioning）是一种基于 HTTP 1.1协议的通信协议。它扩展了HTTP 1.1，在GET、POST、HEAD等几个HTTP标准方法以外添加了一些新的方法，使应用程序可对Web Server直接读写，并支持写文件锁定(Locking)及解锁(Unlock)，还可以支持文件的版本控制。

**风险评级：高危**

**威胁类型：远程命令执行**

**影响范围：**

目前经过研究人员验证后的受影响版本如下，其他版本正在紧急验证中。

Microsoft Windows Server 2003 R2 开启WebDAV服务的IIS6.0

  

* * *

**360企业安全发布修复建议**  

  

**检测方法**

**本地检测IIS 6.0 WebDAV是否开启**

打开“IIS管理器”(Internet Information Services) Manager

\---->“Web拓展服务”(Web service Extensions)；

在右侧边栏找到“WebDAV”；

若“状态”(status)值为: “允许”(Allowed)，则表明WebDAV处于开启状态

如下图：

![](../Images/2c3f17b3b0d5b7c7f0974b65a49730ef.png)

  

**远程检测**

对服务器发送OPTION请求：

1、先判断返回banner信息中IIS版本信息为：IIS 6.0

2、再判断HTTP返回方法中是否有PROPFIND方法

若1、2同时满足，则极有可能存在该漏洞。

\--------------------------------------------------------------------

使用NC发送http请求

H:\\>nc 192.168.222.145 80

OPTIONS / HTTP/1.1

Host:192.168.222.145

请求响应头如下：

HTTP/1.1 200 OK

Date: Tue, 28 Mar 2017 02:39:39 GMT

Server: Microsoft-IIS/6.0

X-Powered-By: ASP.NET

MS-Author-Via: DAV

Content-Length: 0

Accept-Ranges: none

DASL: <DAV:sql>

DAV: 1, 2

Public: OPTIONS, TRACE, GET, HEAD, DELETE, PUT, POST, COPY, MOVE, MKCOL, PROPFIND, PROPPATCH, LOCK, UNLOCK, SEARCH

Allow: OPTIONS, TRACE, GET, HEAD, COPY, PROPFIND, SEARCH, LOCK, UNLOCK

Cache-Control: private

\-----------------------------------------------------------------

当ALLOW中包含如上方法时，可以确定服务器开启了WebDAV。

如下图：

![](../Images/23852e5c063adca282fe26aca8d358b6.png)

  

**修复建议**

请您通过扫描检查相关业务系统是否在此漏洞的影响范围之内。  

如您的服务器版本为Windows Server 2003，IIS版本为6.0，且开放了WebDAV服务，建议暂时关闭WebDAV服务，并增加 waf 规则。

  

**修复方法**

本地关闭WebDAV 

步骤如下：

选中右侧边栏WebDAV“右键” ----->“禁止”（Prohibited）

如下图：

![](../Images/44b14acc3870a0772eaf9678c3b6e290.png)

关闭WebDAV后无需重启IIS，配置即可生效。

360天眼未知威胁感知系统的采集器已加入对利用此漏洞的攻击检测规则，可以精准地发现相关的攻击并判定是否攻击成功，鉴于微软已不再对Windows Server 2003提供支持，请及时按如上步骤关闭WebDAV。
