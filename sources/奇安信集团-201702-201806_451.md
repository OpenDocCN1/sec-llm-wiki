# 有一个地方，Pwn2Own上的精彩与豪气每天都在上演

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247490473&idx=2&sn=2dfa7598e1096883590a64a1f8fc2e4f&chksm=fb753dadcc02b4bb24b4799bcc314cd680f1cf862f6eb37b46e9e6f0b68420fe4c8863cc0ff3&scene=126&sessionid=1681374048#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247490473&idx=2&sn=2dfa7598e1096883590a64a1f8fc2e4f&chksm=fb753dadcc02b4bb24b4799bcc314cd680f1cf862f6eb37b46e9e6f0b68420fe4c8863cc0ff3&scene=126&sessionid=1681374048#rd)

Pwn2Own至今已经走过了10个年头， 这个由美国五角大楼网络安全服务商、惠普旗下TippingPoint的项目组ZDI（Zero Day Initiative）主办，谷歌、微软、苹果、Adobe等互联网和软件巨头都对比赛提供支持的世界黑客大赛已经成为了全世界最著名、奖金最丰厚的黑客盛会。

在Pwn2Own上，参赛者将对包括IE、Chrome、Safari、Firefox、Adobe Flash和AdobeReader等在内的最新产品进行攻击破解，如能够攻破上述广泛应用的产品，将获得ZDI提供的现金和非现金奖励，Google Project Zero也对本届比赛提供了额外奖励。而ZDI也会将产品漏洞反馈给相关厂商，帮助厂商进行修复。

在今年的Pwn2Own黑客大赛上，中国的黑客军团包揽了前三名，让众多网友不禁欢呼：厉害了！Word中国黑客！

![](../Images/a5d72f9320a478f8e85cb7bf8f763292.png)

  

不只是聚光灯下的那些黑客，其实我们的身边有许多白帽黑客，他们都有着不同的成长轨迹，但是都有一颗维护安全的心。每天都有着一场场不为人所瞩目的Pwn2Own比赛正在进行。在补天漏洞响应平台上就有3万多名白帽子，利用他们的安全技术帮助4000多家企业挖掘漏洞，漏洞经过企业的确认后，帮助企业提出修复建议，从而保障企业IT系统的安全。

在补天平台上，有公开面向社会征集漏洞并免费通知企业修复的公有SRC模式，旨在帮助企业发现漏洞，白帽子将漏洞提交到补天平台，补天平台发布漏洞招领公告，企业注册确认后即可领取漏洞详情。补天平台来支付白帽子奖金，这在一定程度上很好的帮助了企业发现问题，规避风险。

另外，在公有SRC的基础上，补天平台又逐渐形成了专属SRC模式，企业可以自助发布漏洞悬赏，召集有技术能力的白帽子帮助企业发现漏洞，审核确认，企业就可以对白帽子给予奖励。

2016年，补天平台还正式推出了众测服务，与Pwn2Own黑客大赛相似，众测平台会召集优秀的白帽子，集中时间并有针对性的对企业指定的IT资产进行模拟攻击，帮助企业发现潜在问题。区别于专属SRC模式，众测服务一方面参与众测的白帽子均是通过实名认证并签署保密协议，通过VPN安全接入，平台全程记录白帽子操作行为，保证测试过程安全可控，检测结束补天平台还会提供专业详实的修复方案，让企业及时修补漏洞排除隐患。

![](../Images/c3ae8a5f86cdf28154daa55cc31a1998.png)

补天平台已经成为中国最大的漏洞检测与响应平台，作为公益性的第三方平台，截止今年3月底，补天平台已经有注册白帽子3万多名，注册企业4千余家，共发现漏洞超20万个，发放奖金数达近900万元。

3月30日，补天将于深圳JW万豪酒店举办补天白帽大会，本次大会将秉承开放、协同的原则，广泛邀请国内外知名白帽子、技术精英、安全爱好者，与网络安全相关主管机构和知名企业和机构的CISO共同参与，共同解读当前网络安全形势和安全威胁，探讨漏洞响应与防范方案，同时交流和分享漏洞挖掘与安全攻防等前沿议题。
