# 奇安信荣获WISE 2019新商业引领者大奖

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247494477&idx=1&sn=3a9435e11cdb11fcfdccd598b2044f88&chksm=fb76cd49cc01445fbf86d30bc4c23745a4c90cef7481b0c26428601d0723844386172592c6e5&scene=126&sessionid=1681373763#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247494477&idx=1&sn=3a9435e11cdb11fcfdccd598b2044f88&chksm=fb76cd49cc01445fbf86d30bc4c23745a4c90cef7481b0c26428601d0723844386172592c6e5&scene=126&sessionid=1681373763#rd)

日前，由著名科技创投媒体36氪举办的“2019 WISE超级进化者大会”在京召开，会上奇安信集团荣获了“WISE 2019新商业引领者”大奖。

![](../Images/497b1a239f59d497f2eb92de0562d365.png)

  

36氪表示，消费互联网随着用户数量增长触顶而遭遇天花板，深耕用户差异化需求的下半场已经开赛；产业互联网则随着云计算、人工智能、智能传感等新技术的成熟和应用落地，迎来爆发期，带动To B服务市场的快速发展。在风口迭代的产业重塑期，我们希望回归企业的商业逻辑、核心竞争优势以及价值创造能力，寻找到那些勇于创新、引领行业制胜未来十年的超级进化者们！

  

事实上，早在2014年，奇安信集团董事长齐向东就已经预见To C将风光不再，他笃信To B风口即将到来，创办了奇安信。2016年，360美国退市回归，齐向东押上全部身家，将企业安全业务独立于360，专注To B安全领域。

  

今天，经过两年酝酿、三年发展，奇安信已成为网络安全行业的独角兽，截至目前，奇安信员工数已近6500人，2016~2018年三年公司营业收入年复合增长率非常高，是国内网络安全领域中成长最快的企业，也是中国人员规模最大的网络安全公司。这也与“WISE 2019 新商业引领者”要求创业公司有可持续增长的商业模式、持续引领行业进步、并且是行业头部公司的标准不谋而合。

  

目前，奇安信的业务已经覆盖大多数的中央政府部门、中央企业和大型银行，还在印度尼西亚、新加坡、加拿大、中国香港等国家和地区开展了安全业务，牵头承担十九大、两会、一带一路峰会、达沃斯论坛、APEC、G20等多项国家级重大网络安全保卫任务，进一步确立了中国网络安全领军者的地位。
