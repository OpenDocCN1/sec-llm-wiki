# 奇安信集团助力合肥市中级人民法院获得“2019全国政法智能化建设优秀创新案例”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247494426&idx=1&sn=1b44081222fd2b41d1e2d64ef1dee7d2&chksm=fb76cd1ecc01440865675479a4d5e6fea4a2a40fbdd16f759f80544b065a128c4b5af09d9ca4&scene=126&sessionid=1681373768#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247494426&idx=1&sn=1b44081222fd2b41d1e2d64ef1dee7d2&chksm=fb76cd1ecc01440865675479a4d5e6fea4a2a40fbdd16f759f80544b065a128c4b5af09d9ca4&scene=126&sessionid=1681373768#rd)

7月3日，由法制日报社主办的“2019全国政法智能化建设研讨会、全国政法智能化建设技术装备及成果展、首都公共安全防范建设应用成果展（简称：2019全国政法展）”在京举行。会议期间，大会组委会发布了“2019全国政法智能化建设创新案例征集活动”评审结果，基于奇安信集团的人民法院态势感知与安全运营平台解决方案，合肥市中级人民法院获得了“2019全国政法智能化建设优秀创新案例”。

图 展会现场  

  

据悉，合肥市中级人民法院成立于1958年，目前，合肥市中院下辖五区、四县、一个地级市共10个基层法院。下辖各法院系统存在网络复杂多样、设备种类繁多、信息资产不清晰等问题，需要对全市各法院的网络、业务系统等进行统一安全监管，利用多维检测手段，及时发现安全威胁，并进行快速处置，实现安全运营闭环，提升安全风险预警及安全事件响应能力。  

  

基于奇安信网神态势感知与安全运营平台，合肥市中级人民法院实现了全市法院系统网络安全态势集中展示、统一运维管理、安全事件追踪和响应、安全风险的预警和防护，对下辖各法院的各业务系统进行实时监管，准确掌握各级法院安全状态。同时建立了统一的威胁与风险预警处理中心，辅助决策，大幅提高安全运维效率。

  

据了解，除合肥市中级人民法院外，奇安信网神态势感知与安全运营平台目前还应用于全国几十个各级各类政法机构。该平台还在人社部、科技部、财政部、国土资源部、国家安监总局以及多省市政府电子政务中心，和中国移动、中国联通、中石油、中石化、国家能源集团、中国华电、中国电力建设集团、清华大学等单位机构成功实施运行，并得到了赛迪顾问颁发的“2018~2019中国安全管理平台市场占有率第一”证书。
