# IDC发布国内市场研究报告 奇安信终端安全市场份额位列榜首

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247494080&idx=1&sn=c2419077d8e5422c2bbf9f0410271343&chksm=fb76cfc4cc0146d2d4e7b685c1bde5fc91a5de48c1a0c5f6aab4982fcfaae7598a8045b33a55&scene=126&sessionid=1681373783#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247494080&idx=1&sn=c2419077d8e5422c2bbf9f0410271343&chksm=fb76cfc4cc0146d2d4e7b685c1bde5fc91a5de48c1a0c5f6aab4982fcfaae7598a8045b33a55&scene=126&sessionid=1681373783#rd)

日前，**IDC发布《2018年下半年中国IT安全软件市场跟踪报告》**，报告显示，2018年全年中国IT安全软件市场厂商整体收入9.49亿美元同比增长23.98%，到2023年将增长至22.9亿美元。**在中国终端安全软件市场，奇安信以22.9%的市场份额位列第一，同比增长67.8%。**

![](../Images/79bafaac64f17dd616ed6524aabff400.png)

  

近年来，奇安信终端安全产品的能力受到了业界和客户的广泛认可，已经成为中国政企客户**4000万终端**的信赖之选，在权威分析机构IDC、赛迪顾问的报告中都位列2018中国终端安全市场第一，还囊括了美国知名网络安全杂志CDM的前沿技术（Cutting Edge）等众多知名奖项。

  

奇安信天擎终端安全管理系统以功能一体化、平台一体化、数据一体化为设计理念，以安全防护为核心，以运维管控为重点，以可视化管理为支撑，以可靠服务为保障，为客户的终端安全防护提供了终端防病毒、入侵防御、补丁管理、安全准入、资产发现、身份认证等十六大基础安全能力，帮助政企客户构建了针对终端威胁的检测、响应和鉴定的高级威胁对抗能力，并大幅提升了客户在安全规划、战略分析和安全决策等终端安全治理能力。

  

特别的是，在勒索病毒肆虐的背景下，奇安信天擎还面向所有天擎政企客户推出敲诈先赔服务：如果客户在开启了奇安信天擎敲诈先赔功能后，仍然感染了勒索软件，奇安信将负责赔付赎金，为政企用户提供百万先赔保障。
