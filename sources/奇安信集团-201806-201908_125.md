# 吴云坤：新时代网络安全需要实战化安全运营能力

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247494057&idx=2&sn=437ef566d69d4a9354955f623be2c1e3&chksm=fb76cfadcc0146bbb1ed5120a6cd64dd94a221c839f83ffae1a41f1de800b13ca906895b5dcc&scene=126&sessionid=1681373783#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247494057&idx=2&sn=437ef566d69d4a9354955f623be2c1e3&chksm=fb76cfadcc0146bbb1ed5120a6cd64dd94a221c839f83ffae1a41f1de800b13ca906895b5dcc&scene=126&sessionid=1681373783#rd)

今日，2019补天白帽大会在上海召开，这是安全行业顶级攻防技术交流的盛会，也是顶尖攻防人才的聚会。奇安信集团总裁吴云坤在大会致辞时表示，“新时代网络安全防护需要以人为核心，建立实战化安全运营的能力。网络安全讲一百遍不如打一遍，新一代网络安全体系的目标是实现安全与信息化的全面覆盖、深度结合、有效检测、协同响应。”

  

![](../Images/dea7acc92af1c408726ec37f2c3b0caf.png)

图 奇安信集团总裁吴云坤

  

实战化运营能力的建立，需要先进的思想和体系，需要应用大数据、人工智能等新技术，更需要关注人在安全中的能力和价值。网络安全的本质是人与人之间的攻防对抗，再聪明的机器也不能取代人的作用。

 

吴云坤谈到，在过去四年与客户的共同实践中我们发现，无论是在态势感知、高级威胁检测这些的新技术场景下、还是安全运维、应急响应、实网攻防演习这些实战场景下，不仅需要更多的机器学习、深度学习等人工智能技术应用来提升效率，更需要安全运营、分析与响应、攻防渗透这样的实战型人才来提升整体安全能力，任何场景下网络安全的及时告警、快速响应都需要采用“人+机器”的方法，人起到关键性作用。

  

在网络安全人才整体短缺的大背景下，实战化安全人才无论是数量还是能力都严重匮乏，需要我们全社会联合起来，采用开放的思维、创新的手段，建立完善的生态体系。补天漏洞响应平台是我们专门针对攻防人才发现和培养的一种很好探索。

 

据了解，本届2019补天白帽大会吸引了国内外上千名网络安全顶尖攻防人才就漏洞技术、安全事件进行了研讨和分享，同时随着“补天五星计划”在大会上的发布，补天漏洞响应平台跻身全球三大漏洞平台之列，成为国内第一家全面覆盖全品类漏洞的第三方漏洞响应平台。
