# 不辱使命 奇安信圆满完成亚洲文明对话大会网络安全保障工作

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247494044&idx=1&sn=9c3deb1cf9daa31ecc354e429ed280ed&chksm=fb76cf98cc01468e2dfe5defae5c8a3e67a095cd2631b1e9964305e25aad2a55fb70955a42a2&scene=126&sessionid=1681373783#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247494044&idx=1&sn=9c3deb1cf9daa31ecc354e429ed280ed&chksm=fb76cf98cc01468e2dfe5defae5c8a3e67a095cd2631b1e9964305e25aad2a55fb70955a42a2&scene=126&sessionid=1681373783#rd)

亚洲文明对话大会于5月15日至22日在北京隆重举行，这是汇聚亚洲文明、凝聚亚洲共识的宽广平台，也是亚洲文化大交流、人民大联欢的人文盛事，是激发文化共鸣点、维护文明多样性的文明盛会。为了确保大会顺利举行，奇安信集团根据网络安全主管部门的工作部署，参与了亚洲文明对话大会的网络安全保障工作。  

![](../Images/37a33565b87a04c3908e24992ab0202f.png)

（图片来源于网络）

  

根据亚洲文明对话大会的安全保障需求，奇安信派出专家及工作人员组成重保团队，共计投入245人天，昼夜奋战1960小时，配合网络安全主管部门完成了远程安全检查、现场安全检查和安全值守工作。  

  

**远程安全检查工作**

5月初，奇安信配合对大会重点单位相关信息系统进行远程安全检查，协助重保单位提升业务系统整体安全性，降低了重点保障单位被网络攻击的风险。  

  

![](../Images/7c7da0a04ce4919b8e3e500182307b51.png)

  

**现场安全检查工作**

为确保重要信息系统的安全运行，奇安信在进行现场安全检查后，根据网络安全主管部门要求，对重点保障单位网络环境和重要信息系统进行了风险评估和安全测试，进一步提升了重保单位信息系统的安全防御能力。同时，在亚洲文明对话大会召开前夕，对北京市内部分大屏进行现场安全检查，重保团队连夜协调多名安全专家，配合相关人员支撑现场检查工作，顺利完成检查任务。  

  

![](../Images/961c6d2ad9795073a09f6a915bad6b6c.png)

  

**安全值守工作**

亚洲文明对话大会期间奇安信重保团队还参与了亚洲文明对话大会核心网站及重点单位的值守工作。现场值守阶段负责分析态势感知平台监测数据，保障业务系统的正常运行，并对重保系统进行每日巡检，处理突发事件；远程值守支撑阶段值守人员负责提供远程安全保障支撑，以应对紧急情况。在重保团队的安全保障下，亚洲文明对话大会期间无一起安全事件发生。  

  

![](../Images/fdaae64d1186378108a7ea6bf3bdc6b1.png)

（图片来源于网络）

**态势感知监测工作**

会议期间，奇安信协助提供了技术支撑平台，截至亚文会结束，共采集各类网络资产数据21万余条，并持续开展分析和研判工作。实现了公安部、市局、重保单位相关网络安全部门的联动响应，支撑了网络安全保卫工作。

  

**作为保卫国家网络安全的重要力量，奇安信多次积极参与国家重大活动期间的网络安全保卫工作并圆满完成任务，**得到了国家主管部门、各省市相关机构和重要行业、企业的高度认可和褒奖。截至目前，奇安信先后完成了春晚、两会、博鳌论坛、一带一路高峰论坛、达沃斯论坛、贵阳大数据博览会、香港回归20周年、全运会、金砖国家峰会、国际刑警大会、十九大、上合峰会、中非论坛、上海进博会、海军成立70周年活动、第二届一带一路高峰论坛、世园会、亚文会等国家级网络安全保卫任务，用自己的能力和行动捍卫着国家和企业的网络安全。
