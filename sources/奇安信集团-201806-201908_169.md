# 大数据系统中数据安全建设的三个目标

4月26日, 由公安部网络安全保卫局指导，中国（中关村）网络安全与信息化产业联盟、北京网络信息安全技术创新产业联盟、中国保密协会产业分会主办的以“共享数据价值·共担安全责任”为主题的第三届中国数据安全治理高峰论坛在北京举行。北京奇安信科技有限公司副总裁梁志勇受邀出席了此次论坛，并以“大数据系统中数据安全建设思考与实践”为主题做主旨演讲。

![](../Images/673d211bfe089f30344677b1a4748218.png)

梁志勇表示，当前在数字化转型的背景下，各个行业都在做大数据为核心的信息化建设；而大数据技术的应用，在给大家带来便利，提升生产力的同时，也改变了政务和业务的流程和环境，随之也带来了新的安全威胁和安全需求。

  

同时，针对大数据系统中数据面临的安全风险，梁志勇表示可以从两个视角来进行分析：

  

第一个视角是数据生命周期，数据时间维度的风险。一个数据集在不同时期，都有哪些风险？比如：数据采集阶段，可能有伪造的风险；数据存储阶段，存储介质可能被盗，导致泄露的风险；数据销毁阶段：数据未被安全删除，导致泄露风险等。

  

第二个视角是风险暴露面，数据空间维度的风险，数据会在哪些系统间流转，每个流转环节就是一个风险暴露面，都会存在潜在风险。例如：业务人员的违规使用；DBA等特权人员越权、违规操作数据存储系统；假冒应用服务访问数据服务；假冒数据服务访问平台服务；生产数据下载到测试环境未进行脱敏；传输链路被监听、嗅探，导致数据被篡改、窃取等。

  

基于以上风险分析，奇安信结合过去网络安全的成功经验，以及同行先行者的成功实践，提出了**数据安全的建设目标：以数据为中心，建设可见、可控、可管的能力，达到看得见，控得住，管得严。**

  

为什么要以数据为中心？众所周知的是传统的安全建设是以系统为中心，数据存储在系统中相对静止，把系统保护好数据就安全了；而在大数据系统中，数据是在多个系统和网络间流转的，即便是保护好了每个系统，也无法保证流转过程中的数据安全。所以必须要以数据为中心，不管是静态或是动态，全生命周期进行安全防护。

  

同时，还需要建设几个方面的能力：可见的能力，数据是保护对象，保护数据需要先看见数据；可控的能力，风险可控，大数据系统数据安全风险点比较多、比较散，对于不同的风险点都要有控制手段；可管的能力，数据安全运营能力，风险是动态的，安全需要持续不断的运营和调整。

  

数字经济时代，数据作为每个组织的重要资产在多个产品、系统、业务环节中频繁流转，利用数据创造价值的同时，如何妥当地保护数据资产、明确数据所有权，不仅关系到公民的隐私权利保护，也牵涉到中国信息化进程和一系列产业发展。
