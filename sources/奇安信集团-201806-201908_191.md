# 媒体聚焦：“绵阳模式”已成网络安全运营服务新引擎

**3月29日，网络安全人才培养和安全运营服务研讨会暨360企业安全集团绵阳基地一周年成果汇报会成功召开，**绵阳基地和“绵阳模式”引发了媒体的广泛关注，人民网、中新网、光明网等多家媒体及绵阳当地媒体都进行了跟踪报道，以下内容为人民网报道。

人民网成都3月29日电  今日，网络安全人才培养和安全运营服务研讨会暨360企业安全集团绵阳基地一周年成果汇报会成功召开。来自绵阳市委市政府、中国工程物理研究院培训中心、国网信息通信有限公司、上海电力、华中电力、辽宁联通、西南科技大学、电子科技大学成都学院等政府、高校以及相关行业的60多位专家领导齐聚绵阳，共议网络安全人才培养“绵阳模式”。

  

据了解，绵阳基地成立一年来，已累计招生1200多人，培养出的网络安全运营服务工程师已经服务于政府、教育、金融、能源等各个行业，覆盖了全国40多个城市，参与156个项目，为中国网络安全事业贡献力量。如今，“绵阳模式”已成为了网络安全人才培养的代名词。

**“绵阳模式”培养安全人才仅需3—5个月**

  

网络安全人才培养绵阳基地作为承载360企业安全集团“以人为核心的安全运营服务”战略主体，于2018年3月29日在中国（绵阳）科技城正式启动，是360企业安全集团包括安全运营服务总部、网络安全人才培养基地、网络空间安全军民融合创新中心绵阳分中心在内的三大战略之一，旨在为党政机构、军工保密和广大企事业单位提供网络安全运营服务和多层次的网络安全专业人才。

  

“在长期的网络安全实践中，我们充分认识到围绕数据、人、工具和运营管理的积极防御体系是未来安全体系发展的方向。人是安全的尺度、数据是安全的第一生产力。”360企业安全集团副总裁徐欢在研讨会现场表示，绵阳模式是360企业安全基于多年网络安全实践和人才培养、培训实践，多年对政企机构网络安全人才需求和行业发展趋势的把握基础上，对网络安全人才培养的一种模式探索

  

“突破网络安全人才短缺的困境，不仅实现网络安全人才的自给自足，也为社会贡献急缺的安全专业人才，为政府及广大企事业单位的网络安全保驾护航。”360企业安全副总裁、绵阳基地总经理程国章在绵阳基地一周年成果汇报中表示，绵阳模式所建立的“管、产、学、用”一体化的协同生态平台，让高校、企业、主管机构和用人单位，从选才、培养到使用的人才培养全生命周期的紧密协同。

  

在绵阳模式下，通过多层次人才培养和短期定制培训服务，经安全知识系统理论学习加导师指导下的实战训练，最快仅需3—5个月左右时间，便能培养出合格且较为优秀的网络安全专业人才。

  

绵阳基地首期学员赵亿凌也来到了研讨会现场。2017年，她考研失利加之未能找到理想的工作，便抱着试一试的想法来到绵阳基地学习。从网络操作系统基础知识到python语言及网络安全攻防技术系统性的理论教学，加上网络攻防的实战演练，让赵亿凌在短短的3个月时间里，就成长为网络安全运营的熟手，并以笔试第一名的成绩拿到了360企业安全的offer，如今不到一年的时间，就已独当一面，进驻上海市某客户现场，独立负责信息安全管理平台项目。

**绵阳基地，将成网络安全人才的摇篮**

  

“中国科技城绵阳将成为网络安全人才的摇篮。”在研讨会现场，绵阳市委常委罗宗志表示，绵阳基地将极大推动信息安全产业加快发展，助推国家军民融合发展战略深入实施。绵阳市委党校副校长刘仲平亦评价，网络安全人才培养业已形成了绵阳速度。

  

在去年绵阳召开的第六届中国（绵阳）科技城国际科技博览会上，360企业安全集团董事长齐向东就曾谈到，“未来，国家间的主战场一定会向网络空间转移，那么网络安全的人才，会像二战期间的核物理专家一样珍贵，谁拥有了他们，谁就拥有了取得胜利的钥匙。绵阳将成为生产这把钥匙的网络安全人才之都。”

  

![](../Images/7e0885529f5fe8d2c1f5f1676ad84ea4.png)

**“绵阳模式”将向全国复制推广**

  

“360企业安全集团绵阳基地与中国联通集团辽宁省通信有限公司开展了富有成效的合作。”辽宁联通产业互联网有限公司网络运维部经理张辰冬表示，合作不仅提升了辽宁联通信息安全水平，也为广大用户提供了更好的安全产品，同时为辽宁联通提供了专门的安全人才，降低了自身培训人才的成本。

  

网络安全人才培养“绵阳模式”中，除了政府、企业的参与外，高校是关键一环。“通过与360企业安全集团这样的网络安全领域的专家开展校企合作，学校和企业可以优势互补，资源共享。学校可以更好的发挥自身科研优势和人才优势。”来自重庆工程学院院长李生林在研讨会现场表示，目前重庆工程学院共有71多人参加了绵阳基地开展的网络安全特训营，有34人成功入职360企业安全集团。

  

在研讨会现场，与会专家、企业、高校代表等一致认为，网络安全人才短缺是一个全球性问题，我国网络安全行业“人才荒”形势更加严峻，而360企业安全在绵阳建立的人才培养基地，进一步完善了网络安全人才培训体系和机制，规模化的培养将有力填补网络安全行业的人才缺口，也为当前急缺的国家网络安全人才培养提供了可复制的“绵阳模式”。

据悉，“绵阳模式”是360企业安全基于多年网络安全实践和人才培养、培训实践、多年对政企机构网络安全人才需求和行业发展趋势的把握基础上，对网络安全人才培养的一种模式探索。经过一年的成功实践，摸索总结出来的网络安全人才培养经验和模式，已经成为网络安全运营服务的新引擎，不仅为360企业安全服务广大政企机构提供了人才保障，更为整个行业和社会补充网络安全人才的新鲜血液。

  

中国工程物理研究院培训中心规划处处长李建强认为，未来”绵阳模式”将成为引领网络安全行业发展新的人才驱动力。360企业安全集团副总裁、绵阳基地总经理程国章表示，“绵阳模式”将向全国进行复制推广，360企业安全亦将联合全国各地方政府、高校、政企机构和网络安全企业共建人才培养生态体系平台，作为保护国家安全，保护网络空间安全的主力军，也成为360企业安全集团引领中国网络安全行业以及走向世界的新的驱动力。
