# ISC互联网安全大会亮相RSAC2019 8月去中国参会成潮流

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247493191&idx=2&sn=b5c6dfc1e89e79f709cb0a4a9fab9ffc&chksm=fb76c043cc014955912874409f81541249f07bc66a43588fbcf15b3ce700ea8259832c0928e4&scene=126&sessionid=1681373809#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247493191&idx=2&sn=b5c6dfc1e89e79f709cb0a4a9fab9ffc&chksm=fb76c043cc014955912874409f81541249f07bc66a43588fbcf15b3ce700ea8259832c0928e4&scene=126&sessionid=1681373809#rd)

正在美国旧金山举办的RSAC 2019大会，吸引了诸多来自世界各地的顶级信息安全企业代表、各行业的 IT 决策者、资深安全专家以及学术界的领军人物，共同探讨安全产业发展趋势与前沿技术。

 

其中，由中国互联网协会、360互联网安全中心等共同主办的，被称为亚太地区网络安全风向标的ISC互联网安全大会，也亮相RSAC 2019，并展示了其对网络安全产业领袖的汇聚能力、对网络安全行业趋势的洞见能力，以及对网络安全技术新未来的精准把握能力，现场吸引了诸多信息安全机构代表和资深专家的关注，他们纷纷表达了参加ISC 2019互联网安全大会的意愿，8月去中国参会几成RSAC 2019大会现场的一股小潮流。

  

![](../Images/8795af79afef344f688c8b5bb1d18ec3.png)

*ISC的风采吸引了诸多参会者的目光*

  

“ISC大会上我们是否有机会就我们的技术进行交流呢？”阿拉兹费兹是美国一家专注于个人隐私保护和信息安全领域的创业公司负责人，在RSAC 2019大会上得知CSA云安全联盟与ISC互联网安全大会达成战略合作，并将其今年的国际云安全峰会落地在北京，与ISC互联网大会同场同期召开。原本准备参加国际云安全峰会的他，希望能同时参加ISC互联网安全大会并介绍自己公司的技术，并表示愿通过ISC互联网安全大会在亚太地区的影响力，让他们的技术能够得到亚太地区的同行和专家的认可，以便未来能够服务更多的亚太地区客户。

 

与阿拉兹费兹有同样计划的，还有印度孟加拉CSR大学网络安全学院的院长Makuf。在RSAC 2019大会上，他表示ISC 2019大会不仅自己会参加，同时还将带来他的合作伙伴一道参加，“我希望在ISC大会上遇见更多优秀的同行、聆听更多的真知灼见。”

 

作为亚太地区规格最高、规模最大、最具影响力的国际级安全盛会，ISC互联网安全大会自2013年创办以来，已成功举办了6届。目前已成为亚太地区网络安全行业的风向标，也是网络空间安全最新战略、产业最新发展方向、技术趋势和最新研究成果的发布平台，同时还是产业合作和行业应用实践的交流平台。“安全从0开始”、“万物皆变，人是安全的尺度”、“协同联动，共建安全+命运共同体”、“数据驱动安全”等大会历年主题无一例外成为当年的行业共识，引发全球网络安全产业的共鸣。

 

据了解，ISC 2019（第七届）互联网安全大会将于今年8月21日至23日在北京国家会议中心举行，届时将汇集全球网络安全顶级专家和智库、网络安全领导企业，共同推动全球网络安全领域的交流与合作。
