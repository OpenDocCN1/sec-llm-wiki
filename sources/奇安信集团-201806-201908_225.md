# RSAC 2019即将在美举行 “数据驱动安全”系列解决方案集中展示

美国当地时间3月4日—8日，汇集全球信息安全产业焦点的2019年RSAC信息安全大会将在美国旧金山召开。以360企业安全集团为代表的36家中国信息安全企业，将集体向全球展示网络安全中国力量。

  

创立于1991年的RSAC信息安全大会经历了20多年的发展，已成为网络安全行业最受关注的年度盛会，享有“全球顶级信息安全大会”的美誉。其每届大会都是当年最受关注的安全事件之一，也吸引了众多全球知名信息安全企业、行业决策者和资深专家学者前来参会，共同讨论网络安全的最新趋势，展示创新科技成果。

  

![](../Images/4af06be6cdb64ee47e2f70f2b270ae89.png)

  

今年RSAC 2019大会确立“Better”为主题，旨在数字化时代大背景下探索新的网络安全发展领域，致力于寻找更优质的安全厂商、产品及服务解决方案。在这一主题下，RSAC 2019大会讨论议题将涵盖新威胁、隐私监管、新兴技术等。

  

此次RSAC 2019大会，将有来自全球各国的736家安全机构参展，参展数量较去年增加了27.6%，今年有36家中国企业参展，较去年增长了38%，其中有12家中国企业以独立身份参展。

  

360企业安全集团作为中国企业级网络安全市场的领军者，将全面展示其基于“数据驱动安全”理念的威胁情报能力以及工业安全、大数据安全、云安全、新边界安全解决方案。**（本次大会360企业安全集团展位号：1061）**

  

![](../Images/af6b5c563b2174e56bea2ff074d2022f.png)

图 360企业安全集团展位位置及示意图

  

近些年，随着大数据、人工智能等技术的应用，360企业安全集团基于“数据驱动安全”的核心技术理念，积极探索并推动将云、大数据、人工智能等新兴技术应用于网络安全，构建起面向人工智能、大数据、云计算和万物互联时代的新网络安全防御体系，并利用全球领先的安全大数据资源和技术，开发出一系列“安全+互联网”的政企网络安全解决方案，成为“大数据协同安全技术”的领军者。

  

此外，被称为亚太网络安全风向标的ISC（Internet Security Conference）互联网安全大会将再次亮相RSAC 2019并举办一系列活动，邀请全球网络安全顶级专家智库及网络安全领导企业，参加今年8月在北京举办的ISC 2019互联网安全大会，推动全球网络安全领域的交流与合作。

  

敬请关注RSAC 2019的**1061**号360企业安全展位。
