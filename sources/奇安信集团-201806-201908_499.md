# 协助修复严重漏洞 施耐德电气官方致谢360企业安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247490133&idx=1&sn=55dc749f0c37bb6476dd9bf21e7abfd6&chksm=fb753c51cc02b547384c4f14c26be392e7a01fdbffe9b98318acd119d3e2582873c8b851a541&scene=126&sessionid=1681373901#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247490133&idx=1&sn=55dc749f0c37bb6476dd9bf21e7abfd6&chksm=fb753c51cc02b547384c4f14c26be392e7a01fdbffe9b98318acd119d3e2582873c8b851a541&scene=126&sessionid=1681373901#rd)

  
近日，全球知名工业企业施耐德电气发布安全更新，修复旗下产品U.motion builder由360安全监测与响应中心安全研究员发现的两个严重漏洞（CVE-2018-7784、CVE-2018-7785）。分别如下：  

   

*   CVE-2018-7784：程序对提交的数据过滤不严，导致输入的数据被当作代码执行。通过这个漏洞，攻击者可以在存在漏洞的机器上远程执行任意代码、泄露信息或者引发程序报错。
    
*   CVE-2018-7785：远程命令注入漏洞，攻击者可以在无需认证的情况下，于存在漏洞的主机执行任意远程命令。
    

  

两个漏洞的影响评分（CVSS v3.0）为最高级别的10分，发现时U.motion builder 所有版本都受影响，均可导致远程代码执行。

  

360安全监测与响应中心旗下A-TEAM研究员@bigric3 发现漏洞后，第一时间上报给施耐德电气，并协助其修复安全隐患。目前，施耐德电气已发布修复版本U.motion builder v1.3.4，相关用户请尽快更新至最新版。

U.motion 是一款楼宇自动化解决方案。U.motion Builder 工具能让用户为自己的 U.motion 设备创建项目。

  

360安全监测与响应中心成立于2016年，是属于360企业安全的安全应急响应平台，旨在第一时间内为客户提供漏洞或网络安全事件预警通告、相应处置建议、相关技术分析和360企业安全产品解决方案。在2017年的多起重大网络安全事件中（如WannaCry蠕虫爆发、“坏兔子”勒索病毒等），360安全监测与响应中心都为个人和企业提供了有效的解决方案和处置建议。

  

360安全响应中心旗下A-TEAM是一只高质量的技术研究团队，研究方向包括 Web 渗透、APT 攻防&对抗、前瞻性攻防工具预研等，从底层原理、协议层面进行严肃、有深度的技术研究，深入还原攻与防的技术本质。
