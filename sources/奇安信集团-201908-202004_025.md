# 对话齐向东：新基建浪潮，我们更要守住安全底线

新冠疫情暴发后，政企的数字化转型和以远程办公、远程医疗、远程教育为代表的数字生活成新常态，国家加大力度部署新基建，网络安全的重要性更加凸显。  
**国内最大的网络安全公司奇安信创始人、知名网络安全专家齐向东向业界呼吁，新基建和数字经济为行业带来巨大机遇，值此风口网络安全企业更应恪尽职守，协同守护社会安全的底线，实现高质量发展。**![](../Images/086b757721024b1dc46c388349b0c05b.png)

![](../Images/35299764fc396b3bf79affd95086bf71.png)

图 奇安信集团董事长齐向东在奇安信云年会上发出行业倡议

  

齐向东是在3月30日奇安信集团云年会上发出此番倡议的，他同时宣布，奇安信第一阶段“上规模”战略圆满达成，在新基建浪潮背景下将企业将进入“高质量发展”阶段。  
  
  
  
  
  

**护航新基建**

  
  
  
  
  
  

  

随着新冠肺炎疫情在全球蔓延，数字经济日渐红火，新基建需求爆发式增长，急需网络安全作为底层设计和保护。3月24日，在北京网络安全大会（BCS）携手全球信息安全大会(RSAC)举办的“全球首场网络安全行业万人云峰会”（后面简称万人云峰会）上，**Rain Capital创始人、被誉为“网络安全投资女王”的王晨曦**分享了她所看到的产业机会：“美国传统企业在疫情下，想实现几百员工远程办公都非常痛苦，因为缺乏零信任的网络安全体系支持，一开始就卡在身份验证关口。这必将提升企业对网络安全的认知和投入。”

  

站在产业全球风口上，**齐向东**指出，奇安信将用以“内生安全”为核心理念的全新网络安全框架来建立满足新基建保障需求的能力；同时在这个网络安全框架中发现机会、扩大规模、提升产业，引领网络安全进入全新发展阶段，撬动未来万亿大市场。

  

  

“网络安全行业大发展需要可信任的大公司”，**前美国国家安全委员会主管Glenn Gerstell**在万人云峰会上谈到全球新基建趋势时提到。

  

  
**奇安信在万人云峰会上发布的全新网络安全框架，正体现了大公司的能力和担当。**这个网络安全规划包括基础架构安全、纵深防御、积极防御、情报和反制不同阶段的安全能力，及其对应的产品、人、能力和服务，并将所有能力内生到信息化系统中，保证安全系统与业务系统深度融合、安全能力伴随业务变化日渐强壮、即使网络被攻破也能保证业务安全。其次，用系统工程的思路进行网络安全规划设计，实现安全融入IT战略和企业战略。框架包含十大工程五大任务，可以根据使用场景需求任意组合，适用于所有应用场景。**“我们就是要将产品和技术都实现‘乐高化’，分为基础件和特殊件，用标准化生产实现个性化定制，避免重复劳动，创造最大效益。”齐向东说。**

  

![](../Images/2d33ad4ce52f828a77b6717ba5ef890e.png)

图 奇安信发布面向新基建的新一代网络安全框架

  

除了对产品、技术、理念的持续升级，新基建浪潮下更需要企业在全球视野下加强交流与协作。无论是疫情期间的全球万人云峰会，还是每年8月举办的北京网络安全大会（BCS），都是奇安信搭建的全球顶级安全产业交流平台。通过各国网络安全政、产、学、研、用的定期碰撞，全球网络安全领域的中国模式越来越被世界接受。

  

  
  
  
  
  
  

**护航“疫战”**

  
  
  
  
  
  

  

**新冠疫情暴发后，很多企业挺身而出驰援灾区。一些黑客组织却对众多关键基础设施发起攻击，****网络空间成为“抗疫第二战场”。**  
3月16日，美国卫生与公众服务部网站遭受了数百万次攻击；3月9日，负责监督欧洲高压电力基础设施运行的组织ENTSO-E被黑客入侵；中国安全形势也不容乐观，疫情期间多家地市级医疗卫生机构的网站遭受DDoS攻击和大规模恶意扫描渗透。中国信息通信研究院发布的报告显示，黑客对医疗行业的暴力破解攻击达到了单日 80 万次的高峰。

  

奇安信在1月25日大年初一就发出“大疫当前，奇安信绝不袖手旁观”的号召，全员复工，成立了防控支援团。

  

**在安服、安运、交付、产品、CERT等核心部门人员4小时完成生产一线集结，加急生产防疫网络安全设备的同时，1663名奇安信人分别奔赴防控一线，将5000万元网络安全设备和服务，源源不断捐赠给包括火神山、雷神山在内的全国19个省市的100多家医院和疾控单位。**

  

“就算不眠不休，我们也必须用自身的专业能力，严守网络和医疗信息化系统的安全，让医生能够救助更多的病人。”参与火神山、雷神山医院建设的奇安信工程师李虎在日记中写到。

  

![](../Images/e52bb84858b0fe700e4d760c7004d862.png)

图 9小时，奇安信400万专业设备送抵武汉火神山医院。

  

**“作为网络安全领域国家队成员的奇安信既是战士，更是卫士。疫情病毒来势汹汹，正面阻击的同时，还得力保大后方企业安全、稳定的生产运营。”奇安信集团总裁吴云坤回忆起这个春节开始的忙碌时这样说。**  
1月25日起，奇安信全员以7X24小时免费网络安全服务支持千余家单位，开发应急协同指挥平台和疫情上报系统，义务协助近2000家单位的防控工作。防控后期，又将旗下移动办公平台蓝信赠送中小企业助力复工复产。  
**“在疫情彻底被控制之前，奇安信一切工作以疫情防控为第一优先，不计成本，不惜代价，竭尽所能！”齐向东说，而这也是奇安信成立至今始终坚守的企业社会责任。**

  

  
  
  
  
  
  

**护航冬奥会**

  
  
  
  
  
  

  

公司成立至今，奇安信人见证了无数个国家的重要时刻。  
近两年，承办及配合网络安全主管机构、部委和大型央企，奇安信开展了100余次实战型攻防演练，参与国家级重保活动70余次，全国两会、一带一路峰会、达沃斯论坛、APEC、G20、上合峰会、中非论坛、进博会等多项国家级网络安全保卫任务都由奇安信负责。在新中国成立70周年大庆安保活动中，奇安信是唯一一家负责天安门广场现场值守任务的安全厂商。由此，**奇安信被媒体称之为网络安全的“守夜人”。**

  

凭借雄厚的技术实力和丰富的重保经验，2019年底，奇安信入选为北京2022年冬奥会和冬残奥会官方网络安全和杀毒软件服务商，成为奥运历史上首个网络安全赞助企业。

  

![](../Images/38ee637ae46892e049bd6be57338391e.png)

图 北京市副市长、北京冬奥组委执行副主席张建东和奇安信集团董事长齐向东共同为北京2022年冬奥会和冬残奥会与奇安信组合标志揭幕

  

目前，奇安信冬奥会和冬残奥会网络安全运营中心已经成立，专家工作组已进驻北京冬奥组委。在完成场馆、设施网络安全梳理，以及与全球通信服务运营商对接后，奇安信将制定严密的网络安全方案。在冬奥会和冬残奥会举办期间，奇安信预计派出超过3000人规模的驻场专业技术人员，从系统设计、到人员服务全方位护航冬奥会和冬残奥会圆满举办。  
  
  
重任在肩的奇安信，加快了科创板上市步伐。2019年6月，证监会北京监管局官网发布公告，奇安信接受中信建投证券上市辅导，启动登陆科创板。9月，宣布完成了15亿元B+轮融资。今年2月，奇安信以快于行业平均的速度完成前三期IPO辅导。辅导机构中信建投称，将在下一阶段对奇安信有针对性地进行继续辅导，协助其尽快完全符合上市要求。  
“网络安全经历20的零散发展，市场缺少领头羊。在新基建大背景下，原本就高速发展的网络安全市场，将持续迎来更多新任务挑战。资本市场的认可，是奇安信实现高质量备战的坚强助力。”在介绍上市进程时**吴云坤**说。  
未来6年，作为国内最大的网络安全企业，奇安信将实现“上市”“护航奥运”“国际化”三部曲。**齐向东**表示，用责任和担当守护国家、企业和人民的网络安全，勇担产业领头企业责任，是奇安信的初心，也是使命。
