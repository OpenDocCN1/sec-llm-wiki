# 中国工程院院士邬贺铨将首次解读“新基建”下的网络安全

“新基建”浪潮扑面而来，与之密不可分的网络安全也成为焦点话题。**3月24日晚上19:00，**国内规模最大的网络安全公司奇安信集团将举行一场大咖云集的**“新基建”网络安全论坛。**  
届时，中国工程院院士、中国互联网协会理事长邬贺铨应邀出席本次论坛并发表主题演讲，通过云直播的方式，和交通、能源、电力等重点行业知名专家，以及奇安信副总裁韩永刚等一起，共同探讨“新基建”面临的网络安全挑战及应对之策。

  

![](../Images/1a0070cbbee8f0dbc67f63b8fce90c27.png)作为国内通信、互联网和信息化领域最有影响力的专家，不久前，邬贺铨接受媒体采访时表示，**“国家需要加大基础设施投资力度来对冲疫情对宏观经济的影响，以5G为代表的新一代信息基础设施将会是首选。”**  

  

邬贺铨认为，在疫情防控和复产复工中，5G等为代表的新基建已经“初露锋芒”。“基于5G进行医学影像传送的远程会诊与远程医疗在这次疫情中发挥了重要作用。例如5G空口毫秒级延迟让远程检查与手术的实施成为可能，外科医生利用5G可以将‘手臂’伸到千里之外”。而在复产复工潮中，5G实现物联网与人工智能的无缝融合，成为工业互联网的重要支撑，推动智能制造和柔性生产，不仅在制造环节而且在全产业链都有积极的作用。  
  
**对于新基建浪潮所衍生的网络安全挑战，邬贺铨表示，创新应用需要兼顾发展与安全，需要有法可依。**远程医疗、智能网联车、机器人和工业互联网的许多应用，超出了现有法律规范的内容，涉及到产业安全与人身安全。其中，数据的挖掘应用事关企业商业秘密与个人信息安全的保护，需要审慎把握并兼顾发展与安全。  
邬贺铨院士对安全的思考，和奇安信在网络安全领域的理论实践不谋而合。**奇安信集团董事长齐向东****表示，网络安全是新基建的基础。**“以前，网络安全是辅助性工程，但在新基建里是基础工程。新基建会进一步加快网络世界和物理世界的融合。这意味着两者的边界将基本消失，对网络的攻击就等于对物理世界的攻击，直接影响人民生活、社会稳定和国家安全。比如，5G远程手术遭遇网络攻击，可能会威胁到人们的生命安全；车联网遭受攻击，可能会直接造成车毁人亡。”  

![](../Images/e09111368b6feba2aaa44ddd80285f04.png)

  
然而，相对于对新基建34万亿投资的热捧，业内对网络安全的关注度和重视度还远远不够。**3月24日晚上19:00，邬贺铨将通过云直播的方式，在新型基础设施建设网络安全论坛，发表最新的真知灼见。****同时发表演讲的还包括中国交通通信信息中心党委委员及副主任林榕、全球能源互联网研究院副院长及教授级高工高昆仑、华北电力大学能源电力大数据研究院院长李建彬、奇安信副总裁韩永刚等。**
