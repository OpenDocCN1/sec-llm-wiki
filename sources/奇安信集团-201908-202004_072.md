# 奇安信荣获2019年度“金智奖”双料大奖

近日，在由信息安全与通信保密杂志社主办的2019年度“中国网络安全与信息产业金智奖”评选活动中，奇安信集团荣获“战疫特别贡献奖”，奇安信应急响应服务荣获“年度解决方案奖”。

  

  
![](../Images/1d0b791ce0f578bcf2b72500a5a62b30.png)  

  

  
![](../Images/b5958e6fcf9f0fb205d5173d0fb32c73.png)  
  
2020年春节以来，新冠肺炎疫情牵动着全国人民的心，为了应对日益严峻的疫情形势，奇安信第一时间发起了疫情防控总动员。1月25日，奇安信正式组建新冠肺炎疫情防控支援团，全面部署启动疫情防控支援工作，为疫情防控信息化系统免费提供7x24小时安全服务，并提供定制化安全防护产品。  
同时，奇安信启动了网络安全行业迄今为止最大规模的捐赠行动，承诺向全国范围内所有用于抗击本次新型冠状病毒疫情的相关单位，免费提供包括蓝信、终端杀毒（天擎）、SD-WAN、网站云监测（全球鹰）、网站云防护（安域）、SSL VPN、7x24小时远程支持服务和应急响应服务等8项产品和服务。据统计，奇安信和全国上百家医院和疾控等防控疫情一线单位密切沟通，累计达成产品和服务捐赠意向金额达5000万元。  
  
  
  
  
  
  
  
  

  

随着国内疫情防控形势逐渐向好，全国各地政企机构陆续复工，运用大数据分析技术对支撑疫情防控部署与精准施策，可有力支援国内生产企业顺利复工复产。但是，在利用大数据技术防控疫情过程中，面临各部门数据难以融合和个人隐私数据泄露两大大难点，如何快速排查高风险、潜在感染人员？各平台收集的个人信息会不会泄露？能否科学预测后续疫情发展态势进而科学施策？

  

针对上述问题，奇安信科技集团数据安全子公司云安宝基于方滨兴院士提出的隐私保护新技术理念：“数据不动程序动、数据可用不可见”，研发落地了隐私保护的疫情防控大数据安全融合分析平台-防水堡，可实时对接关键部门数据，建立跨部门密切配合、统一归口的疫情防控大数据共享机制，在保证各部门数据不流出、数据隐私安全的前提下，将多源数据进行数据对比碰撞与深度分析，形成实时、全面、精准的“疫情潜在风险人员库”，支持国内企业快速排查疫情风险人员，顺利复工复产。

  

另外，奇安信还针对医院、疾控等疫情防控相关机构，推出了免费的APP隐私安全远程快速检测服务。自2月5日首次发布免费检测服务以来，奇安信已经累积承接了涉及疫情防控的政府、公安、医疗，以及金融、保险、互联网等行业的125家机构、超过200+APP应用的隐私安全检测服务。

  

  

  
  

  

**在应急响应服务方面，奇安信应急响应服务致力于成为“网络安全120”，向政企客户提供的一站式威胁检测、溯源分析及响应处置服务。**奇安信通过构建“快递式”指挥平台，实现了综合指挥和统一调度，极大的提高了应急响应的整体指挥能力。

  

同时，为了标准化一线应急响应人员的分析能力和安全水平，奇安信将多年来一线应急响应专家日常遇到的事件分析的过程和方法融合进了应急响应工具箱，并完成了一线应急响应人员的全部配发，很好的提高一线应急响应人员的应急处置能力。

  

奇安信还拥有一支数百人的从事专业安全分析及响应的安全服务团队，汇聚了操作系统、数据库、WEB、逆向、漏洞挖掘、渗透等各个安全领域的精英，该团队成员的经验是奇安信威胁检测与响应服务深受客户信赖、雄踞行业领先地位有力保障，成为政企客户最信赖的应急支撑单位。

  

**截至目前，奇安信应急响应业务已覆盖全国31个省份，处置政企机构网络安全应急事件超过两千起，累计投入工时25000多个小时，为全国超过千家政企机构解决了网络安全问题。**

  

针对政企客户在应对突发网络安全事件经验和能力不足的问题，奇安信推出了应急响应训练营服务，将自身在一线积累的丰富应急响应实践经验面向广大政企机构进行网络安全培训和赋能，帮助政企机构的安全管理者、安全运营人员、工程师等不同层级的人群提高网络安全应急响应的能力和技术水平。
