# 奇安信向北京协和医学基金会捐赠价值230万元网络安全产品及服务

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247499271&idx=2&sn=52ff22638f873d8e04ad2c37af3b62c0&chksm=fb76d803cc015115afc41eb90e6f312ba224c92262fedf930f9a28ec55be6ca50ac1639d8bc8&scene=126&sessionid=1681373661#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247499271&idx=2&sn=52ff22638f873d8e04ad2c37af3b62c0&chksm=fb76d803cc015115afc41eb90e6f312ba224c92262fedf930f9a28ec55be6ca50ac1639d8bc8&scene=126&sessionid=1681373661#rd)

3月13日，国内最大的网络安全公司奇安信集团和北京协和医学基金会在京举行了捐赠仪式。奇安信通过北京协和医学基金会向北京协和医院定向捐赠价值230万元的专业网络安全产品和服务。北京协和医学基金会姜玉新理事长、段文利秘书长，奇安信集团总裁吴云坤、副总裁何新飞等领导出席了本次活动。

  

![](../Images/8f30e0eb1cce84ccfeee4b4cbf59c77a.png)

图 奇安信集团向北京协和医学基金会捐赠专业网络安全产品和服务仪式

  

  

  
  

  

“疫情是一场考验，也是一块试金石。优秀的企业在这场抗击疫情的工作中表现出了强烈的社会责任感和使命担当，由此赢得了社会公众的尊重和各界赞誉。”**北京协和医学基金会理事长姜玉新**在致辞中说。  

  

![](../Images/e7c6b9f90debf5281cd49405889139ea.png)

图 北京协和医学基金会姜玉新理事长在捐赠仪式上致辞

  

“疫情发生以来，奇安信第一时间主动提出技术支持和捐赠意向，为北京协和医院信息系统安全稳定的运行提供了强大保障。” 姜玉新理事长代表基金会致谢奇安信集团。

  

  
  

  

![](../Images/c76658b5eedc5bd9665e5637a0fd7d05.png) 图 奇安信集团总裁吴云坤介绍疫情期间双方的紧密协作

  

“疫情发生之后，北京协和医院勇担抗疫使命，冲在了抗击疫情的最前线，为守护人民群众的生命健康作出了重大贡献。”**奇安信集团总裁吴云坤表示，**“奇安信作为一家具有高度社会责任感的企业，以及北京协和医院长期以来的网络安全合作伙伴，我们竭尽所能，向北京协和医学基金会捐赠价值230万元的终端安全、威胁情报分析等产品及服务，为医院抗击疫情尽一份绵薄之力。”

  

  
  

  

![](../Images/b22ccb8463d322a75866acfc1c24441b.png)

图 奇安信集团副总裁何新飞介绍本次捐赠内容

  

  

据**奇安信集团副总裁、新冠防控疫情支援团负责人何新飞**介绍，这批捐赠的产品及服务，包括奇安信网神私有云杀毒管理系统（天擎）、网神终端安全管理系统（天擎）、安装实施服务、大数据威胁分析报告服务、威胁情报服务等。部署之后，不仅可帮助医院进一步加强常规安全防护，更可增强大数据研判和威胁情报分析能力，尽早向“关口前移”、防患于未然的目标迈进。  
![](../Images/f9a0638e99e9f7f172d4a68f7a8f0fbd.png)  

  

据悉，从1月25日即大年初一开始，奇安信就启动了网络安全行业迄今为止最大规模的捐赠行动。截至目前，奇安信已向全国19个省、市、自治区，100多家医院和疾控等疫情防控一线单位捐赠了专业设备和安全服务，累计达成产品和服务捐赠意向金额达5000万元。捐赠医院包括武汉火神山医院、雷神山医院，以及全国各地用于疫情防控的新建“小汤山”医院。  
  
  
**万众一心，没有翻不过的山；心手相牵，没有跨不过的坎。**奇安信凭借领先的专业技术水平、快速的应急响应能力，以及强烈的社会责任感，获得了200多家政企机构、医疗单位的肯定。2月以来，奇安信先后收到温州市第六人民医院、宜昌市第三人民医院、公安部科技信息化局、天津西青经济开发区管委会等数十封感谢信。  
正如**奇安信集团董事长齐向东**所说的，“在疫情彻底被控制之前，奇安信一切工作以疫情防控为第一优先，不计成本，不惜代价，竭尽所能！”
