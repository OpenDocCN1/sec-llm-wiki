# “驾御车联安全实验室”发布信息安全三大产品

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247499170&idx=2&sn=986d3b62d3fa357ac9b33bf915220e1e&chksm=fb76dba6cc0152b002ed6db149198ae2c1a0bd5c102e82410838c767965fa7280db509312089&scene=126&sessionid=1681373661#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247499170&idx=2&sn=986d3b62d3fa357ac9b33bf915220e1e&chksm=fb76dba6cc0152b002ed6db149198ae2c1a0bd5c102e82410838c767965fa7280db509312089&scene=126&sessionid=1681373661#rd)

为顺应新一轮科技革命和产业改革趋势，抓住产业智能化发展战略机遇，助力加快推进智能汽车创新发展，3月10日，驾御车联安全实验室召开线上产品发布会，发布了中电车联大数据云控基础平台、蓝海安全分析与预警平台和工业主机安全防护系统（车企版）三款产品，并公布了《稳健参数设计》团体标准在智能汽车创新发展中的应用。本次发布会发布的产品在疫情期间将为各类企业提供免费测试版试用。  

  

  
  
  
![](../Images/12b0ea77ea245aa83e6fe05338230929.png)  
  
  

  

中国电子信息产业集团总经理助理、中电工业互联网有限公司董事长朱立锋，中国电子信息产业集团规划科技部副主任白丽芳，北汽集团副总经理、北汽蓝谷信息技术有限公司董事长陈江，北汽集团有限公司战略与系统运营部部长、北汽蓝谷信息技术有限公司总经理李晓龙，北汽集团有限公司战略与系统运营部部长助理冯景姣，奇安信科技集团股份有限公司副总裁吕韬，奇安信科技集团股份有限公司副总裁左英男，驾御车联安全实验室专家吴新松出席云直播会议。  
当前，互联网、大数据、云计算等技术正快速发展，传统的汽车行业与信息通信技术不断产生融合。在信息化浪潮下，汽车行业边界和产业链价值加速重构，信息安全也成为产业变革、创新过程中不可忽视的重要环节，因此有必要构建一套智能网联汽车全生命周期的内生安全体系，要在智能网联汽车设计阶段、开发阶段、测评阶段、生产阶段、运营阶段都加入安全的因素，形成一个安全的闭环。  
会上，驾御车联实验室主任、奇安信集团副总裁左英男对此次发布的三款产品进行了详细介绍，并展示了《稳健参数设计》团体标准的应用案例情况。  
  
  
  
![](../Images/40d988cc32cb77b242670896f6cb7060.png)  
  
  

  

其中，中电车联大数据云控基础平台支持将大数据能力无缝融入现有车联网数据生态环境，并基于中国电子“PK体系”，通过对汽车零部件、整车信息化、用户数据等海量数据存储、分析、场景挖掘，旨在打造成中电汽车行业工业互联网安全大数据运营中心。  
  
蓝海安全分析与预警平台则是基于大数据安全分析，通过采集全网流量及日志数据，全文检索分析、异常行为检测和安全合规要求，支撑安全决策和应急响应。该平台结合数据建模、行为识别、关联分析、人工智能等方法，对海量异构的安全数据进行分析，以资产、威胁、脆弱性等维度进行安全态势分析。  

工业主机安全防护系统（车企版）是为车企专属定制的工业主机安全防护系统。该系统可以实现“多样式”主机兼容，支持低配硬件，兼容老旧系统，适配车企工业软件，并能在车企制造场景应用。此外，该系统还具备一体化防护能力、资产分析管理能力和集中运维管理能力，最终实现工业主机“装得上，防得住，查得清，管得了”。

  

此外，左英男还介绍了《稳健参数设计》团体标准在智能汽车创新发展中的应用。在智能汽车的安全性能方面，整车安全性和汽车零部件质量是息息相关的，通过《稳健参数设计》可以提升汽车行业零部件制造商的质量水平，通过零部件制造商质量水平的提高，最终确保智能汽车整体的安全性能。

  

驾御车联安全实验室是由北汽蓝谷信息技术有限公司、中电工业互联网有限公司和奇安信科技集团于去年11月联合成立。实验室将充分发挥三方在车联网、工业互联网和信息安全领域的各自优势，专注于车联网安全技术研究和安全攻防体系建设，共同开拓车联网安全市场。此次发布的三款产品和《稳健参数设计》团体标准的应用案例正是实验室的成果。

  

![](../Images/35063ea85da780bb3e0f73e97f424367.png)  
**北汽集团副总经理、北汽蓝谷信息董事长陈江**表示，驾御车联安全实验室在成立仅仅三个多月的时间就发布了多款产品，这主要得益于三方强强联合，实现了聚力赋能。在这几个月中，三方各自发挥了在车联网、工业互联网和信息安全领域的优势，快速组建了一支由各领域资深专家和技术骨干组成的核心研发团队，协同开发了多个车联网安全和传统信息安全领域的产品，激发出了全方位的创新活力。  

  

  

![](../Images/9063cf20774ef71e305c629e90debb88.png)  
**中国电子总经理助理、中电互联董事长朱立锋**指出，驾御车联安全实验室自去年11月成立以来，始终立足于建设汽车行业工业互联网安全大数据运营中心，开展汽车行业数字智能工厂建设和工业网络安全研究。今天发布的产品就是三家企业技术共享、合力协同将实验室研究成果产品化的成果。  

  

  

![](../Images/d84ad78985d147af6e0b0b781708811b.png)  
**奇安信集团副总裁吕韬**表示，随着5G网络和无人驾驶等技术的兴起，智能网联汽车成为汽车行业未来的发展主流趋势和方向。希望驾御车联安全实验室能够在三家企业的共同努力下，对中国车联网安全事业做出更大的贡献，进而更好地支撑产业管理和车企在车联网方面的技术进步。  
  
新一轮科技革命和产业变革方兴未艾，智能汽车已成为全球汽车产业发展的战略方向，成为汽车强国的战略选择。  
北汽蓝谷信息、中电互联、奇安信三方将继续以“驾御车联安全实验室”为平台，深耕车联网信息安全市场，打造车联网安全领域的最强共同体！
