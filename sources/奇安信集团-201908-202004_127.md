# 支持全国公安机关疫情防控 奇安信获公安部致信感谢

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247498811&idx=2&sn=e6e21727f4ba1263a570c4f986780159&chksm=fb76da3fcc015329aea0083f6df714eb16372c2287e816efe38c06edbb9c2fa2dbbc6ec8048e&scene=126&sessionid=1681373667#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247498811&idx=2&sn=e6e21727f4ba1263a570c4f986780159&chksm=fb76da3fcc015329aea0083f6df714eb16372c2287e816efe38c06edbb9c2fa2dbbc6ec8048e&scene=126&sessionid=1681373667#rd)

近日，因积极协助公安部科技信息化局疫情防控工作，为全国各地公安机关开展疫情核查工作提供有力支持，奇安信收到公安部科技信息化局的致信感谢。  
在感谢信中，公安部科技信息化局表示，奇安信在疫情防控工作中，组织精干力量，协助公安部研发开通基于公安网的新冠肺炎确认和疑似病例、密切接触人员数据查询服务，为各地公安机关开展疫情核查工作提供有力支持。  
同时，在服务部署过程中，奇安信8位工程师响应迅速，加班加点、紧急攻关，有力保障了服务的迅速上线，体现出了强烈的社会责任感和高超的专业水准。

![](../Images/4e56246b4ee80e7fe659dde8f5282508.png)

  

  
  
在协助公安机关疫情防控中，奇安信网闸产品线协助公安部现场开发出一套专有的服务调用接口，包括私有协议分析、内容过滤、关键字段检测、核查比对及数据摆渡等。  
仅用三天时间就成功实现了公安网对政务外网卫建委防疫数据的安全打通，为抗“疫”一线的公安民警提供了安全高效的应用服务。

  

  

加油

  

奇安信大数据与态势感知团队，依托天工大数据智能建模平台，搭建了20多个数据分析模型，处理了数以亿计条数据，并通过可视化技术，绘制出了精准的“疫情态势图”，为各地公安机关研判疫情态势、排查密切接触人员、控制传播途径，提供了精准的决策支撑。  

![](../Images/cf6b702f93b57561bce8f14041e7b86c.png)  

图 奇安信大数据与态势感知团队加班加点、连夜工作。

  

**疫情发生以来，奇安信积极支援疫情防控工作。**自1月25日紧急成立“新型冠状病毒感染的肺炎疫情防控支援团”至今，奇安信1200多名员工深入全国疫情防控一线，5000万专业设备捐赠并运抵到全国200家疫情防控单位，免费提供的7X24小时网络安全服务支持了近千家单位，蓝信应急协同与指挥平台和疫情上报系统免费协助近2000家组织防控疫情，并向中小企业赠送1000万远程签约及免费疫情上报系统助力复工复产。  
**奇安信集团董事长齐向东表示，“在疫情彻底被控制之前，奇安信一切工作以疫情防控为第一优先，不计成本，不惜代价，竭尽所能！”**
