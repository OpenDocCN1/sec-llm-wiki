# 2019年度新安全服务企业榜单出炉 奇安信荣膺榜首

1月21日，《互联网周刊》和eNet研究院联合发布了“2019年度新安全服务企业TOP50”，奇安信凭借在大数据与安全智能、终端安全防护、安全运营与应急响应等领域的综合实力，荣膺榜首。这也是继2019年10月份奇安信获得“2019企业网络安全服务TOP10”榜单第一名之后，再次斩获殊荣。

  

  

![](../Images/e07fb54e414a0fa49495b7e47fe57dfc.png)

  

《互联网周刊》指出，随着互联网技术及其应用的不断发展，网络安全的边界也在不断扩大和延伸。大数据技术发展的同时，用户隐私安全受到威胁，数据安全便应运而生；云计算的高速发展带动更多企业实现业务上云，但也使云空间的安全受到更多威胁，由此催生了云安全的发展；同时，5G网络本身目前还处于建设阶段，5G安全也缺乏更多的试验和实际应用，故而5G网络安全也面临着巨大的挑战。

  

网络及应用环境越来越复杂、安全挑战越来越严峻的同时，安全服务重要性正在日益凸显。过去政企安全防护理念相对滞后，客户对安全服务投入过低，导致中国安全服务水平远远低于世界平均水平，目前安全服务只占整个网络安全市场的13.8％，而欧美市场2019 年安全服务支出规模占比达到了64%，预计未来三年将是政企迅速补齐安服短板的三年。据中国信通院预计，2021年安全服务市场规模将达到183.5亿元,未来三年复合增长率为39％,2021年安全服务占网络安全市场结构占比有望超过20％。

  

作为国内规模最大的网络安全公司，奇安信在**大数据与安全智能、终端安全防护、安全运营与应急响应**等领域取得了众多创新成果，曾多次承担国家级的重大活动网络安全保障工作，创建了稳定可靠的**网络安全服务体系**，**包括全维度管控、全网络防护、全天候运行、全领域覆盖、全兵种协同、全线索闭环等。**

![](../Images/4740670864c7c6232351219f9a7c027b.png)

  

不久前，奇安信正式成为北京2022年冬奥会和冬残奥会官方网络安全服务和杀毒软件赞助商，这是奥运会史上第一次设立网络安全赞助商。这不仅体现了冬奥组委对网络安全的高度重视，更体现了奇安信网络安全服务的综合能力已领先于同行。奇安信董事长齐向东表示，公司正式成立北京冬奥会网络安全运营中心，并投入超过3000人的人力来做好冬奥会的网络安全服务工作，确保北京冬奥会期间网络运行“零事故”。

每一次国家级重大活动的网络安全保障，都缺少不了奇安信的身影。仅在2019年，奇安信就先后完成了春晚、全国两会、博鳌论坛、海军成立70周年、数博会、一带一路高峰论坛、夏季达沃斯、第七届军运会、上海进博会、新中国成立70周年、澳门回归20周年等国家级网络安全保卫任务，用自己的能力和行动捍卫着国家和企业的网络安全，并得到了各级主管们和重要行业、企业的高度认可。

  

在即将到来的春节，奇安信应急响应服务致力于成为“网络安全行业的120”， 以“用户利益第一”为原则，以“快速响应、力保恢复”为行动指南，24小时全天待命，严格把控服务规范和服务标准，为各行业政企单位提供全方位、全天候的应急响应服务，确保政企单位的安全。
