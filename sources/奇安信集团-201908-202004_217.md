# 金融业网络安全从业人员认定工程师CFSP第二期实训班在福建举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247497749&idx=4&sn=c77fa580970066bd164270df60733987&chksm=fb76de11cc015707818cd7e5dfe828a5c7a1a97e28d5258b0921b5dd3e294302fe36a0802f87&scene=126&sessionid=1681373687#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247497749&idx=4&sn=c77fa580970066bd164270df60733987&chksm=fb76de11cc015707818cd7e5dfe828a5c7a1a97e28d5258b0921b5dd3e294302fe36a0802f87&scene=126&sessionid=1681373687#rd)

近日，由中国金融电子化公司与奇安信集团联合主办的金融业网络安全从业人员认定工程师CFSP第二期实训班，在福建奇安信南平安全城市延平示范区举办。

实训班含9天线上培训和5天线下实训，采用场景实训为主的教学模式，以攻防兼备的知识体系为核心，从实战化的红队攻击技术、蓝队防御技术、应急演练等角度，培养学员的动手能力，积累实战经验。

  

![](../Images/1d6aec78bab45d1a221e7ae501bc3c90.png)

  
  

  

本次实训共有来自20家银行的55名学员参加了培训，这其中有一半学员来自农信农商体系，包括北京农商、浙江农信、广东农信、海南农信、贵州农信、内蒙古农信、新疆农信、黑龙江农信、湖南农信等。最终55名学员全部通过考评，获得了CFSP认定工程师证书。  

  

![](../Images/8d595076f20f41f41da185fd771945a4.png)  

  

![](../Images/9dafd3645b8a4b0999e88e4f94fcc62e.png)中国人民银行福州中支张燕副处长在开班仪式上发表了讲话，她提出，网络空间的竞争，归根结底是人才的竞争。面对复杂多变的网络安全形势，希望各位学员能在此次实训中多思考多交流，珍惜机会，学有所获。

  

  

![](../Images/e8c1ec4e30496e97b01b87ab18b95757.png)福建省网络与信息安全测评中心主任许哲君对参课学员进行了网络安全新形势下的关键信息基础设施保护和网络安全等级保护2.0的解读培训。许哲君表示，网络安全里人是最大的不安全因素，要加强安全意识教育，普及网络安全法、网络安全等级保护制度，才能从根本上降低不安全因素，真正减少网络安全犯罪。

  

![](../Images/8d595076f20f41f41da185fd771945a4.png)  

  

在5天高强度的学习中，55名学员分成了6个小组，经过激烈角逐，最终第六组“超越队”获得了优秀团队称号，7名学员分别获得了优秀组长、优秀学员和明星学员等称号。学员们纷纷表示，CFSP与传统的网络安全认证课程不同，更偏重实操，更贴近实际工作。

金融行业网络安全从业人员认定及实训体系（英文为Certified Financial Security Professional，简称“CFSP”），是业内首个根据金融行业特点专属打造的网络安全人才培养体系，紧跟国家政策及金融行业技术的走向，面向金融机构的高级管理人员、安全技术人员以及业务人员等量身打造的专业化课程。课程涵盖了金融业务安全意识教育、攻防实战、代码安全、安全运营、政策解读、合规管理等多个层面。

  

CFSP旨在为金融行业输送和培养新形势下的复合网络安全人才，并以推动金融行业安全人才队伍建设，助力金融机构夯实安全基础，创新金融科技为目标。下一期培训将在3月份海滨之城青岛开班，相关课程安排、课程内容、讲师、报名方式可点击**阅读原文**进行了解，欢迎金融业的同仁们踊跃报名。
