# 奇安信斩获2019关键信息基础设施安全两项大奖

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247497290&idx=3&sn=e5d80fe9ff1d0e66fcd5600724b3edd2&chksm=fb76d04ecc01595893d1a6f1f910688abe4ada532b5cc5cab16eea2f9f9c98d33040c82134c1&scene=126&sessionid=1681373697#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247497290&idx=3&sn=e5d80fe9ff1d0e66fcd5600724b3edd2&chksm=fb76d04ecc01595893d1a6f1f910688abe4ada532b5cc5cab16eea2f9f9c98d33040c82134c1&scene=126&sessionid=1681373697#rd)

12月26日，第二届金融关键信息基础设施保护论坛暨2019关键信息基础设施安全优秀产品、解决方案评选活动颁奖仪式在京召开。奇安信天眼新一代威胁感知系统、奇安信网络空间安全态势感知与应急指挥平台从多个解决方案中脱颖而出，分获2019关键信息基础设施安全优秀产品之技术创新奖“盘古奖”和2019关键信息基础设施安全优秀解决方案之最具潜力奖“龙门奖”。

![](../Images/178bd882a3271fa60d5388c5b5d9e9d7.png)![](../Images/c5d767fbd894e8190b2c620dfb8d6bc3.png)

  

此次关键信息基础设施安全优秀产品、解决方案评选活动是为了展示优秀国产自主网络安全产品和解决方案，为关键信息基础设施相关行业的网络安全建设提供产品、技术和产业支撑，并将出版《2019关键信息基础设施优秀网络安全产品和解决方案推荐手册》，持续推荐给关键信息基础设施行业用户。

  

  

  

奇安信天眼新一代威胁感知系统因2015年捕获了境外APT组织“海莲花”而知名，是新一代高级威胁检测发现产品，可为政企客户提供针对高级威胁的检测、响应、溯源整合解决方案。截至目前，采用天眼新一代威胁感知系统的政企客户超过1200家，遍及全国30多个省份和直辖市以及海外市场，在公检法、金融、政府部委、运营商、石油石化、电力、教育、医疗等行业都具有丰富的案例实践，帮助政企机构发现和处置超过百起APT攻击事件。

  

  

  

奇安信网络空间安全态势感知与应急指挥平台能够采集和利用来自云、网、端、边界、终端、应用、数据等层面的多源异构安全数据，基于深度学习、可视化分析等多种大数据智能分析方法,实现了针对不同时间、空间、行业和威胁类别等的多维度、全天候、全方位的网络安全威胁检测、监测和预警,形成了具备大数据安全协同联动能力的网络安全威胁态势感知和应急处置体系。截至2019年7月，奇安信已经为监管部门建立了超过70套大数据体系的态势感知平台，覆盖了大多数的千万级国家监管部门的网络安全态势感知系统。

  

  

在军运会、十九大、全国“两会”、G20峰会、中非合作论坛、博鳌论坛、“一带一路”高峰论坛、70周年国庆等一系列国家重大活动以及网络攻防演习期间，奇安信天眼和态势感知为网络安全保障提供了重要的技术支撑，协助安全专家累计监测攻击行为数十万次，发现漏洞利用行为上千起，有效协助政企机构对网络安全隐患进行加固防护，得到了国家有关部门的高度评价。

  

除本次获奖外，奇安信天眼和态势感知也曾多次获得各机构、协会以及第三方咨询机构的认可。

在2018年中国国际大数据产业博览会上，天眼新一代威胁感知系统（临检版）入选全球“黑科技”，获得领先科技成果奖；

在2019年数博上，奇安信“天眼+安服”安全运营服务和态势感知同时入围了领先科技成果奖；

在IDC发布的《IDCMarketScape:中国态势感知解决方案市场2019年厂商评估》和《2018中国威胁情报安全服务市场研究报告》中，奇安信态势感知均获得“领导者”称号。
