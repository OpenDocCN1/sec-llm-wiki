# 聚焦红队技术研究 奇安信A-TEAM首期实战安全攻防沙龙召开

12月17日，由奇安信集团主办的安全训练营——A-TEAM实战安全攻防沙龙在京召开。本次沙龙以 RedTeam 技术安全研究与实践为主题，受到了广大安全攻防从业人员以及爱好者的积极参与。为此，主办方在首批报名截止后，临时增加了30个名额，共计吸引到超过150名观众参与本次活动。

  

![](../Images/beaf4245120bace4941d3457725756fa.png)

  

活动现场，奇安信A-TEAM团队部分成员就打造Vscode RCE利用链、绕过EDR的保护进行LSA凭据提取、攻防体系技战法之看透组策略以及RDP登录日志等议题，分享了A-TEAM在日常攻防研究中的实战技巧，引起了与会嘉宾的激烈探讨。

  

![](../Images/1b05fdf75d9c9f0e9946ebedf3933791.png)![](../Images/3e51ac2484e00cf0ee47995fd99350d9.png)![](../Images/9b73519827b1be765d0cc47a15a4d738.png)![](../Images/0e1dcb32c9854adfef0f72c30c9007d5.png)

  

![](../Images/bab6657659cd4f9c0a308ae249baedbb.png)

奇安信A-TEAM 成立于 2016 年，是属于奇安信旗下的纯技术研究团队。该团队主要致力于 Web 渗透、APT 攻防以及前瞻性攻防工具预研，从底层原理、协议层面进行严肃、有深度的技术研究，深入还原攻与防的技术本质。

  

同时，A-TEAM也是奇安信CERT的支撑团队，曾多次率先提供Windows域、Exchange、Weblogic等重大安全问题的预警及可行的处置措施并获得官方致谢。在2019北京网络安全大会期间，A-TEAM团队首次亮相安全训练营活动。

![](../Images/7dcf37220e7c86cdec7958367e58d652.png)

  

![](../Images/48c480babc2258b64ac7b8e766af0f70.png)

图 奇安信A-TEAM成员与观众现场互动

  

  

**安全训练营**旨在为网络安全行业人员与中国顶级信息安全专家提供交流培训平台，针对不同受众人群，通过政策法规解读、行业趋势分析、安全能力提升、技术解密、案例分享、实战操作等形式对学员进行训练。目前安全训练营已经累计开发超过60门课程，培训了超过2000名学员。

  

**据主办方透露，A-TEAM实战安全攻防沙龙将会持续举办，**为参会观众分享最新的攻防理念和实战技巧。另外，在2020年8月25日~27日举办的2020北京网络安全大会上，A-TEAM还将亮相安全训练营大师班，赋能安全行业发展。
