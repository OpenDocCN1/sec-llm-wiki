# 齐向东连任中国网络空间安全协会副理事长

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247496820&idx=1&sn=ad03af91443ed7889a3593c160474072&chksm=fb76d270cc015b66b268a6d42c8570df3f9d4d1cdf5a3f1c85ca52f25de784ddb81af5219bd3&scene=126&sessionid=1681373707#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247496820&idx=1&sn=ad03af91443ed7889a3593c160474072&chksm=fb76d270cc015b66b268a6d42c8570df3f9d4d1cdf5a3f1c85ca52f25de784ddb81af5219bd3&scene=126&sessionid=1681373707#rd)

近日，中国网络空间安全协会（以下简称“协会”）第一届会员代表大会第三次会议及第一届理事会第四次会议在北京召开。中央网络安全和信息化领导小组办公室副主任刘烈宏、中国网络空间安全协会理事长王秀军等领导出席大会。在大会上，奇安信集团董事长齐向东再次当选协会副理事长，奇安信同时当选为协会副理事长单位。

  

  

早在2016年协会成立之初，齐向东就与中国工程院院士吴曼青、国防科技大学教授贾焰、中国科学院信息工程研究所所长孟丹、腾讯CEO马化腾等11人当选为副理事长。

  

![](../Images/62507d71f2c5a9a2fa74dce51ef881b5.png)![](../Images/6c3cd24abfb144cc50c41a34072e54f3.png)

  

中国网络空间安全协会是国内首个网络安全领域的全国性社会团体，由国内从事网络空间安全相关产业、教育、科研、应用的机构、企业及个人共同自愿结成的全国性、行业性、非营利性社会组织，旨在发挥桥梁纽带作用，组织和动员社会各方面力量参与中国网络空间安全建设，为会员服务、为行业服务、为国家战略服务，促进中国网络空间的安全和发展。

  

目前，我国正由网络大国向网络强国迈进。但随着云计算、大数据、人工智能等新技术、新应用快速发展，网络空间内涵和外延不断扩展，网络安全威胁持续上升。面对漏洞无处不在、不可避免的现状，以及内部威胁防不胜防的挑战，传统安全防护手段已经失效，网络安全已进化到“内生安全”时代。

  

而“内生安全”的概念，正是今年8月奇安信联合中国网络空间安全协会等相关单位共同主办的北京网络安全大会上，奇安信首次率先发布的理念。所谓内生安全，即要求信息系统的安全体系具有自我免疫、内外兼修、自我进化的三大特点，让信息化系统内不断生长出自适应、自主和自成长的安全能力。

  

  

齐向东把奇安信构建的内生安全体系总结成“一个中心，五张滤网”，其中“一个中心”指的是安全运营中心，“五张滤网”指的是网络、身份、应用、数据和行为五张滤网。而网络信息经过“一个中心，五张网”的层层过滤，将极大降低网络攻击的风险。

  

同样，齐向东认为企业增长也已从需求驱动转变为创新驱动，需要用内生安全实现内生增长。而奇安信正是通过技术创新，拿到内生增长的钥匙，创造了网络安全行业规模、估值和增速三座新高峰, 服务用户覆盖大多数的中央部委、央企、大型银行。

  

  

作为中国人员规模最大的网络安全公司，奇安信此次当选协会副理事长单位，未来将继续与协会各成员单位相互协作，共同维护国家网络安全，提升网络空间的治理水平和管理能力，切实做强网络安全产业生态、提升网络安全技术、做大网络安全产业规模，实现网络安全产业的集群突破发展；

另一方面，进一步加强自主创新，发挥行业领军企业带头作用，将奇安信以内生安全实现内生增长的经验，分享给更多的企业，为维护国家网络安全，实现网络强国战略贡献更大力量。
