# 植入14枚芯片、生物黑客再升级：重量大咖空降首届“补天杯”破解大赛

*挥挥手掌或手臂，就可打开公寓门锁、解锁汽车、开启电脑；手指自带磁性，可以提起钉子等轻量物体，堪比万磁王；不靠任何设备，仅靠身体就能运行安全软件和执行加密任务……*

  

 这些似乎在科幻电影中出现的情节，已经变成了现实。而具有这些“超能力”的主人，就是世界顶尖的荷兰生物黑客大神Patrick Paumen。

  

![](../Images/317c9e10ff77ca72d54cdfd3e7ab5b13.png)![](../Images/aea095c203ad9343bb922eb751509788.png)![](../Images/86e70580bbb1b7ae950ebc4ddee7355c.png)  

  

对于了解“生物黑客”的爱好者，几乎无人不知Patrick Paumen的大名。Patrick Paumen曾于2017年首度来华，被认为身具万磁王+钢铁侠+X教授的特异功能，堪称真正的现实版终结者。

  

11月27日，Patrick Paumen将再度来华，此次降临的地点为湖南省长沙市，他将应邀参加由奇安信集团承办的湖湘杯网络安全技能大赛系列活动之首届“补天杯”破解大赛，并担任大赛评委，同时在现场再秀绝技，展示植入14块芯片、再度升级后的生物黑客“超能力”。

  

![](../Images/a47df8619b73f63f6d90815abe69480f.png)![](../Images/cadbdb7b970d060cf2929607d992a7a6.png)

  

> 生物黑客英文为Biohacker，和我们理解传统意义上的黑客有所不同，他们是自己动手的生物学家、车库生物学家（garage biologist），目标是把生物技术带出实验室，打破常规实验室的限制，在不同环境下创新发展生物技术。生物黑客可借助纹身针、手术刀、注入装置、微型芯片或各种线路，便可为身体赋予联网能力，真正突破人类身体的极限。
> 
>   
> 
> 据悉，Facebook 创办人扎克伯格（Mark Zuckerberg）和 Tesla 创办人马斯克（Elon Musk）都是生物黑客的支持者，马斯克表示，“ 人类生物学和技术必须融合，才能让人类跟上技术进步。”今年7月，马斯克宣布由他创立的神经技术公司Neuralink发布了脑机接口系统，可实现人脑和机器间的连接，让人脑的意念可以被机器读取。马斯克这次发布的脑机接口系统的方法是通过激光开颅手术把特殊的芯片植入人类的大脑中，可以用无线方式和iPhone手机相连进行通讯。他还预计，该系统明年第二季开始人体实验，以实现帮助截肢、视障、听障等人群重获对世界感知的目的。
> 
>   

  

Patrick Paumen自2011年以来，一直在研究植入物的生物黑客，他在身体内植入9个感应芯片，5块磁铁，通过14枚“插件”，Patrick Paumen可与门禁系统、门锁、智能手机等各种电子设备交互，身兼万磁王、万能解锁手、意念操控术、人形计算机、超能零部件五大特殊能力，堪比现实版“终结者”。Partick Paumen在多个国家和国际媒体出版物中被重点采访，包括《华尔街日报》和德国关于半机械人的纪录片。

![](../Images/af176de8a43071fab7e2bd1ca53e1273.png)![](../Images/4e858b0c2089af5f602af7a6532dfbf6.png)

  

  
据透露，Patrick Paumen本次在“补天杯”破解大赛上表演的内容，预计与智能家居破解有关。随着物联网的普及，我们周围的家电设备如智能音箱、门锁、摄像头等都已经数字化、联网化，一旦被破解控制，会直接影响我们的实体空间世界。Patrick Paumen将通过生物黑客的技能表演，向公众更好普及安全的重要意义。同时，Patrick Paumen还将担任本次破解大赛的评委。  

![](../Images/002514635c8597ecfadd5909b185a063.png)

  
组委会介绍，湖湘杯网络安全技能大赛系列活动之首届“补天杯”破解大赛将在11月27日举行，致力于号召全国范围内的企业、高校、民间的极客、白帽黑客、专家对智能设备存在的漏洞及网络风险进行破解挑战，以比赛的方式发现智能设备存在的安全问题，引起政府、企业厂商对物联网安全的重视。为此，大赛设置了高达50万元的总奖金池，赛题包括智能交通安全、智能终端安全、能家居安全、智能制造安全等四个方向。  
  
![](../Images/1a4ce70077a9e7acebcdf4ba14e46b69.png)  
“补天杯”破解大赛由湖南省委网信办、湖南省工业和信息化厅、湖南省科学技术协会、长沙市人民政府、中国电子信息产业集团有限公司主办，长沙市委网信办、长沙市工业和信息局、湖南湘江新区管委会经济发展局、奇安信集团承办。补天漏洞响应平台承担了此次大赛的独家技术支持工作。
