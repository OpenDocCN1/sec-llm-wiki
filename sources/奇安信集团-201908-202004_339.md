# 2019“天府杯”自动漏洞挖掘与利用论坛召开 顶尖专家分享前沿观点

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247496288&idx=2&sn=e79ddc3464bf458b924e51980c41bae9&chksm=fb76d464cc015d72f599495c5d5194f68e2b35ebbdccaed932ad34f558ffd2e8f1abe58120ed&scene=126&sessionid=1681373712#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247496288&idx=2&sn=e79ddc3464bf458b924e51980c41bae9&chksm=fb76d464cc015d72f599495c5d5194f68e2b35ebbdccaed932ad34f558ffd2e8f1abe58120ed&scene=126&sessionid=1681373712#rd)

11月17日，由清华大学网络科学与网络空间研究院、奇安信集团主办的2019自动漏洞挖掘与利用论坛在成都西部博览城举行。  
自动漏洞挖掘与利用论坛是2019天府杯国际网络安全高峰论坛七大分论坛之一，论坛邀请了清华大学、武汉大学、中科院、阿里安全和奇安信的高级技术专家，围绕漏洞挖掘与利用技术，从学术与应用层面进行了深入的探讨。  
  
![](../Images/f11d7eeecf6133e685be8dada0345702.png)随着网络空间形势的急剧变化以及企业在数字化转型过程中的阵痛，企业漏洞管理的重要性和迫切性要求又一次摆在了企业安全管理者的案头。漏洞管理作为企业主动防御未知威胁的主要手段，成为了安全管理者不得不考虑的问题。因此以风险为中心，以业务影响为主要着眼点，以最大化发现未知威胁为目标，以最小化暴露窗口为使命的第三方安全平台也成为漏洞管理的重要工具。  
 例如，补天平台于2016年推出的补天众测服务已经累计为500多家政府、金融、运营商、互联网行业客户提供了优质的服务，收到了众多客户的表扬和青睐，并于2019年5月荣誉入选工信部网络安全技术应用试点示范项目，为安全企业中唯一入选者。  
 在今年初发布的五星计划，补天平台针对现阶段我国政企机构网络安全所面临的新风险，投入奖金数千万元，将漏洞响应范围升级化为IoT、工控、操作系统等五大方向，全面覆盖了新一代网络安全环境下的各种漏洞风险。  
 随着补天五星计划的推出和深入，发现和挖掘了一批具备特殊技能的白帽子，进一步巩固和发扬了安全众测模式在工业互联网、物联网等新兴领域的生命力和创造力。目前，已经有多家企业委托补天众测为其工业互联网平台、车联网平台及物联网平台提供安全众测服务，将白帽子能力赋能到企业，取得了较为明显的成果。  
  
另一方面，自动漏洞挖掘技术也是提高效率的另一种途径。此次“自动漏洞挖掘与利用论坛”从技术角度邀请了顶级专家，分别从不同主题、角度进行了分享，并与现场听众进行了深入交流互动。  
![](../Images/c209adc1ae563f33cddb669a3bddf4ee.png)清华大学副教授、清华大学&奇安信联合实验室副主任张超表示，只要是系统就一定会有没被发现的漏洞。代码是人写的，是人就会犯错误，这是不可避免的。人犯的错误就会变成程序的缺陷，这种缺陷一旦被黑客利用就是漏洞。面对数量庞大的漏洞，安全人员疲于应对，而自动漏洞挖掘技术可以批量分析目标，快速响应，也更为经济高效。

  

  
![](../Images/65b7c91006833e725a1637b7565d53a5.png)

清华大学&MEAC-LAB甘水滔博士就“GreyOne：数据流敏感的模糊测试”进行了主题演讲。当前主流的漏洞挖掘方法是模糊测试技术，其中以代码覆盖率为制导目标的进化算法最为有效。甘博士的工作提出了以数据流辅助的方案，可以高效地提升代码覆盖率，取得了非常好的效果，相关工作被网络与系统安全国际四大顶级会议之一USENIX Security 2020录用。

  

  
![](../Images/d1a877f4f6e6d6949bc00cba3fd8ea7e.png)

武汉大学国家网络安全学院副教授、博士生导师赵磊则分享了“混合式漏洞挖掘研究进展”，提出了以符号执行技术辅助模糊测试的方案，可以更快更高效地提升漏洞挖掘效果，相关工作发表在网络与系统安全国际四大顶级会议之一NDSS 2019中。  

  

  
![](../Images/6d042381b3f52f95a341fdfd97768534.png)

奇安信Codesafe Team高级工程师王俊杰讲解了“基于换子树的JS引擎智能反馈漏洞挖掘技术”，该方案在各大浏览器的JS引擎中发现了十余个0day漏洞，取得了非常好的实际效果。

  

  
![](../Images/b816b88abb4cd43daffe0547e0d5afbd.png)

阿里安全猎户座实验室&清华大学的裴中煜展示了“基于流量的自动化漏洞利用重现”。漏洞利用是实践中难度非常大的环节，也是区分安全人员个人能力的重要标志，当前漏洞利用主要依靠顶尖黑客完成。该报告分享了一种自动漏洞利用的方案，在给定攻击流量的情况下，可以快速自动生成一个攻击样本，对于蜜罐等环境自动捕获0day攻击有非常重要的作用。

  

  
![](../Images/8305407c5e07148b93ebbf958fe1f040.png)

中科院信工所王琰博士讲解了“Maze:自动堆风水技术”，该方案解决了自动漏洞利用中一个重要的问题——堆内存布局问题，实现自动堆风水，在实际CTF环境以及美国国防部自动攻防比赛CGC测试集中都取得了非常好的效果。

  

  

![](../Images/710599697851de4df5bcc497c29b2faa.png)

  

嘉宾专业的演讲内容与论坛良好的交流互动氛围获得了与会安全专家们的一致认可。  

2019天府国际网络安全高峰论坛以“数字赋能时代 天府护航安全”为主题，立足国内外网络安全产业发展最新态势，聚焦西南地区引领网络安全产业发展所面临的机遇和挑战。
