# 奇安信亮相成都“天府杯” 与天府新区达成战略合作

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247496266&idx=1&sn=791ece1ae01ebfca767eeecc73265ca0&chksm=fb76d44ecc015d58439801bbe670c1abd992477d8044613204f7cf70ac12569d39e69851ea6c&scene=126&sessionid=1681373712#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247496266&idx=1&sn=791ece1ae01ebfca767eeecc73265ca0&chksm=fb76d44ecc015d58439801bbe670c1abd992477d8044613204f7cf70ac12569d39e69851ea6c&scene=126&sessionid=1681373712#rd)

11月16日，“天府杯“2019国际网络安全大赛暨2019天府国际网络安全高峰论坛”在成都西部博览城举行。奇安信携内生安全系统、实战攻防演习平台等先进的产品和技术亮相“天府杯“，并与天府新区成都管委会达成战略合作，共同助力“天府杯”的持续成功举办。奇安信集团副总裁陈华平出席战略签约仪式并参与了高峰论坛圆桌讨论。

  

此次奇安信集团与四川天府新区成都管委会达成的战略合作主要包括，双方积极参与“天府杯”各项筹备工作，共同助力“天府杯”的持续成功举办，并以此为契机共同合力构筑天府新区网络安全产业生态圈，进一步助推国际国内网络安全交流与合作，实现网络安全领域优质资源共享。 

![](../Images/ddbc92fc21e616f0edba6d02ad0661ec.png)

  

  

![](../Images/36c2e6d3c8369fbaeae1b119092707c7.png)

“天府杯”2019国际网络安全大赛是以逐步打造属于中国自己的“Pwn2Own”为目标的专业大赛，近年来“天府杯”大赛影响力与日俱增。

  

今年，与“天府杯“2019国际网络安全大赛同期举行的还有2019天府国际网络安全高峰论坛。论坛以“数字赋能时代 天府护航安全”为主题，立足国内外网络安全产业发展最新态势，聚焦西南地区引领网络安全产业发展所面临的机遇和挑战。奇安信集团副总裁陈华平出席了高峰论坛，并参与了圆桌讨论。

![](../Images/43eedb77d6045cba88b9677d72a7f9a6.png)

  

  

圆桌讨论以5G安全和AI安全为主题。在圆桌对话上，陈华平表示，今年是我国5G商用元年，也是国家首次提出“智能+”战略年。5G不再仅仅是传统意义上的通信网络，它的定位是新型信息基础设施。5G商用建设将推动我国工业互联网、物联网等产业发展，在我国工业转型升级和智慧城市建设工作中发挥重要作用。 

  
![](../Images/6f3cded3cc285c7424fe0792acda6ce3.png)“5G商用加速了物联网、工业互联网等产业的发展，物联网和工业互联网等产业场景中的设备与系统、应用与安全将紧密结合，传统的“外挂式”安全体系中，业务与安全是两套独立的体系，难以满足新的安全需求，需要转变安全的防护思路。”陈华平表示，在新的防护思路中，我们认为，网络总会被突破，除了网络边界防护，还需要增加身份、应用、数据和行为这四张过滤网，同时，静态过滤的思路之上，更重要的是增加一个安全运营中心，把行为记录下来，进行感知和监控，甚至溯源。

  

陈华平表示，新的应用场景中，要想更好地解决安全问题，除了上面四张过滤网加一个安全运营中心外，还需要践行内生安全的思路，将安全与网络、应用、数据和行为融合，同时与业务相结合，形成关口前移，做到内生安全。

  

关于AI 对安全的影响，陈华平总结包含两个层面：AI技术自身安全问题和AI辅助安全能力两个方面。AI技术算法本身可能存在安全漏洞，并且AI训练的数据可能会被污染，这样攻击者就可以对使用AI技术的信息化系统发起攻击。AI辅助安全方面，总结起来至少有4个场景，通过AI做网络内容治理、AI对抗欺诈机器人、AI做威胁检测及AI提升安全运营能力。

  

  

![](../Images/a3c963540d20a13fca0c6494231cd6a0.png)除了比赛与高峰论坛，“天府杯”还为各家参会企业搭建展示企业成果、互动交流的平台。在奇安信的展台上，奇安信展示了内生安全系统、实战攻防演习平台、网络安全人才培养、代码安全解决方案。来到奇安信展台参观的观众络绎不绝。

  

  

![](../Images/eab6d0bfbcbf6c765bbc1dfcf76cce45.png)在奇安信的代码安全解决方案中，介绍了奇安信自主研发国内第一个商用源代码安全分析平台代码卫士，可检测1300多种源代码安全缺陷；自主研发国内第一个软件成分分析系统开源卫士，可识别4000万个开源软件版本，并提供全面精准的开源漏洞情报，为企业软件安全开发保驾护航。

  

![](../Images/bd87da3d8b9aa16f09b60c2cd091fa72.png)在今年的“天府杯”期间，组委会还特别针对互联网行业举办了专门人才招聘会，因此人才培养也成为了各方关注的焦点。在奇安信展台上，奇安信网络空间安全高层次人才培养模式也引起了强烈的关注。奇安信搭建了包括安全运营人才、研究开发人才、攻防对抗人才，覆盖网络安全全岗位的全领域网络空间安全人才培养体系。

  

奇安信的人才培养体系注重“理论+实践”，以方法论课程教学为载体，配套网络空间安全专业教材，实现人员学习生命周期的闭环管理。此外还为学员提供了基于场景化综合实践和基于行业需求的网络安全认证工程师体系。

  

目前，奇安信集团在北京、青岛、绵阳等地建设了安全人才培养基地，截止到2019年10月底，绵阳基地共培养19期学员，青岛基地共培养3期学员，总人数近2000人。

  

![](../Images/736e5599970caa22d1854245fb13fd26.png)在展览期间，奇安信集团高级研究员张飞凡还在现场发布并详细阐述了奇安信面向实战化的威胁检测和运营的新思路。张飞凡表示，面向实战化的威胁检测思路，主要基于实战化的攻击路径进行检测，根据数据源利用情报数据、检测引擎、沙箱技术进行检测输出精准事件。同时，基于机器学习的模型对用户的异常行为进行分析。

  

面向实战化的一体化安全运营的思路，主要围绕护网的核心工具产品，天眼、椒图、蜜罐、邮件，进行威胁运营的时间分析，输出精准的威胁事件，利用安全专家包括客户的安全团队、安服驻场专家、奇安信远程专家，建立安全运营中心，建立护网指挥中心、威胁检测与主动响应、事件响应机制。  
近年来，奇安信立足企业优势，先后为党的十九大、全国两会、庆祝中华人民共和国成立70周年大会等重大国事活动提供网络安全支撑保障，在刚刚结束的庆祝中华人民共和国成立70周年大会上，奇安信是唯一一家覆盖三大指挥部的安全公司。除此之外，奇安信还承接了11家国家级媒体单位现场值守任务和25家重要单位现场值守任务，业界排名第一。  
2019年，在面向实战化的威胁检测和运营的新思路指导下，奇安信服务了金融、央企、政府部委、传媒、运营商等150家行业客户及近200家二级单位。
