# 教育部下发开展ECSP培训通知 奇安信获授权11月开课培训

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247495747&idx=2&sn=133632f0dd55c7b314f0c719d9a7e8bb&chksm=fb76d647cc015f515e3d5788dcd7fff3a819a0d4a567eb9d1d971e264cd4a88c92f09a4bc75f&scene=126&sessionid=1681373727#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247495747&idx=2&sn=133632f0dd55c7b314f0c719d9a7e8bb&chksm=fb76d647cc015f515e3d5788dcd7fff3a819a0d4a567eb9d1d971e264cd4a88c92f09a4bc75f&scene=126&sessionid=1681373727#rd)

  

日前，教育部教育管理信息中心下发“关于开展‘教育系统网络安全保障专业人员(ECSP)’培训的通知“，将面向各级教育行政部门及其直属单位的信息化技术管理人员、各级各类学校的信息化技术管理人员和其他教育机构信息化技术管理人员，开展“教育系统网络安全保障专业人员(ECSP)”系列培训项目。

  

![](../Images/ce6429744234c312e624b20c70c15087.png)

  
据悉，此次培训是为了全面贯彻落实《网络安全法》和教育系统有关党委(党组)网络安全责任制考核要求，全面提升教育系统人员网络安全素养和岗位技能水平。

  

培训  

教育系统网络安全保障专业人员培训(Cyber Security Professional for Education Industry，即ECSP)，是由中国网络安全审查技术与认证中心(简称网安中心)与教育部教育管理信息中心为提升教育系统人员网络安全素养和专业技能水平，支撑保障教育信息化和网络安全持续健康发展，共同开发认定的专业岗位能力培训培养项目。

  

目前，根据教育系统网络安全岗位能力需求，ECSP证书初期设置为四类，分别为ECSP-T(专业技术人员)、ECSP-M(专业管理人员)、ECSP-I(高级应急人员)、ECSP-P(高级安全渗透与攻防人员)。ECSP培训采用线上线下结合方式开展教学，学员考试合格后，由中国网络安全审查技术与认证中心与教育部教育管理信息中心颁发相关证书。ECSP证书有效期为三年，获证学员每年需要完成至少8学时继续教育，三年后换发新证书。  
  
  
  
奇安信集团作为教育部教育管理信息中心首批授权的指定培训机构，将于11月在四川绵阳开展“ECSP-T专业管理人员“和“ECSP-M专业管理人员“首期培训班。  

*   **ECSP-T专业技术人员培训班**于10月14日~11月1日进行报名，线下培训将于11月6日~11月9日进行。
*   **ECSP-M专业管理人员培训班**于10月14日~11月8日进行报名，11月13日~11月16日 进行线下培训。
