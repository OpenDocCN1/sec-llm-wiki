# 奇安信与首都在线达成战略合作 共促云安技术融合

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247495069&idx=2&sn=e22f712e631ee3bce673f1239e8a4cfe&chksm=fb76cb99cc01428f0acfd7baf4929ba3280e73b196bfb68d81801a30045a425bdb00ba64d939&scene=126&sessionid=1681373743#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247495069&idx=2&sn=e22f712e631ee3bce673f1239e8a4cfe&chksm=fb76cb99cc01428f0acfd7baf4929ba3280e73b196bfb68d81801a30045a425bdb00ba64d939&scene=126&sessionid=1681373743#rd)

  

9月3日，奇安信科技集团股份有限公司（以下简称奇安信）与北京首都在线科技股份有限公司（以下简称首都在线）正式签署战略合作协议。双方优势互补，将在云计算及网络安全领域展开深度合作，共同拓展新的市场。首都在线董事长兼CEO曲宁、奇安信集团总裁吴云坤出席了签约仪式。  

  

![](../Images/24b0b46472b5e4b01967797bf13047a8.png)  
  
首都在线是中国较早进行云计算服务提供商，在分布式计算、并行计算、大数据、网络存储、虚拟化领域和其他相关领域具有丰富的经验。奇安信是中国最大的网络安全公司之一，专注于为政府、企业，教育、金融等机构和组织提供企业级网络安全技术、产品和服务，已覆盖大多数的中央政府部门、中央企业和大型银行。  

![](../Images/83a4a5e7fefa462b3f30da2559f02c10.png)

  

  

  

目前，双方已经在打造安全屋、安全云平台、共创安全场景3大业务层面开展了紧密合作，首都在线开放云平台资源，奇安信投入安全技术与能力，帮助首都在线提升公有云平台的安全防护能力，同时奇安信还提供全系列的安全产品为首都在线客户提供云上安全产品与服务。

  

另外，针对用户特定场景的安全需求，双方共同定制和开发新品类的安全产品，以满足客户不断更新的安全需求。

  
**首都在线董事长兼CEO曲宁表示，**在网络空间时代大国之间的博弈重点之一就是科技，而科技最核心的竞争力是信息，在信息里最前沿的是安全。首都在线的定位是一家通信公司，从互联网时代到网络空间时代，网络一直是稀缺资源，网络安全在这其中非常重要。我们很高兴能与奇安信达成战略合作，加强首都在线在网络安全方面的能力，与奇安信一起携手为客户提供专业的安全能力，让首云成为客户的首选品牌。**奇安信总裁吴云坤表示，**在数字化转型的大环境下，客户的需求在发生变化，信息化与安全的融合是未来的趋势，内生安全成为了客户信息化发展过程中的前提和保障。此次与首都在线达成了战略合作关系，一方面我们希望能将奇安信的安全能力赋能首云，让首云更安全，另一方面我们希望通过双方在产品和业务上的融合，进一步发现新的客户以及新的市场机会，为客户的信息化提供新的价值。

  

首都在线首席产品官兼研发中心总经理牛继宾、首席信息官兼运营官韩旭光、业务拓展部总监杨波、产品总监杨鑫，奇安信集团副总裁陈华平、防火墙与网闸公司总经理吴亚东、云安全公司总经理刘浩、智能安全网络事业部总经理王茜、销售助理总裁黄翔等双方相关业务线负责人共同出席了此次签约活动。
