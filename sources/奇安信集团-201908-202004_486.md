# 聚焦BCS 2019｜以安全保发展 5G时代呼唤安全建设升级

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247494953&idx=4&sn=7bed12dfe43420ccca41585fade38a9e&chksm=fb76cb2dcc01423b6211926d82685b1e7ff7169266826de6235ba5ccbd67e396981e9d358234&scene=126&sessionid=1681373748#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247494953&idx=4&sn=7bed12dfe43420ccca41585fade38a9e&chksm=fb76cb2dcc01423b6211926d82685b1e7ff7169266826de6235ba5ccbd67e396981e9d358234&scene=126&sessionid=1681373748#rd)

  

![](../Images/0515a628aeea31aa29481c749ca7d674.png)

  

5G网络的高速率、海量覆盖、极低时延等特性，让万物互联成为可能，与此同时，新形势下的安全问题也引起各界关注。8月22日，2019北京网络安全大会的5G发展与安全高峰论坛在国家会议中心正式召开。

本次论坛由中国信息通信研究院（以下简称“中国信通院”）主办，中国通信学会网络空间安全战略与法律委员会协办，中国信通院副院长王志勤、中国通信学会副秘书长宋彤出席并主持论坛，工信部网络安全管理局信息安全处处长姚志杰发表致辞，北京师范大学网络法治国际中心执行主任吴沈括、华为Hisec首席网络安全架构师殷浩等专家做主题演讲。

  

![](../Images/9811074226ed6354b8f7f765b3987d3a.png)中国信通院副院长王志勤以论坛主持人身份率先发表了自己的看法，“5G作为先进技术引入很多新型的网络架构，在5G发展的同时，5G的安全问题也成为世界各国关注的焦点。”

  

![](../Images/a5e68edfaf0595faacfa7f98080ef95b.png)  
工信部网络安全管理局信息安全处处长姚志杰也在致辞中表示，“5G实现了计算与通信的融合，基于大数据、人工智能的网络运维，减少人为差错，有利于提高网络安全水平。”  
![](../Images/01a2d96f182f314687562b0147e1f672.png)此外，中国信通院安全所副所长谢玮表示，“我们看到，5G网络安全的整体架构设计，试图去针对它新的特性，设计了一套内嵌式的安全加固体系，这是以前最大的不同，安全是自上而下的。“而数据司法也是如此。  
![](../Images/0e519b58137eadb2dff83e140100bd71.png)北京师范大学网络法治国际中心执行主任吴沈括强调，“有必要在新的技术环境当中，包括5G数据业务过程当中强调责任阻断机制的建设，对于单位而言，从横向的角度要求定岗定人，明确行为人主观认识与客观行为的边界，在纵向来看要求定岗定则，确定业务作业层级，确定单位法律责任。”  
![](../Images/dad3183af07684924ea2bc6c0ef168b5.png)  
而同为法律工作者的中国通信学会网络空间安全战略与法律委员会副主任敬云川针对法律保护制度的完善提出了专业的建议，首先要尽快启动并完成《个人信息保护法》立法程序，其次个人信息保护立法的核心问题要合理界定信息处理主体和信息主体之间的权利和义务关系，另外还要平衡市场与个人信息保护的关系，建立网络安全国际对话和交流平台，最后要制定5G时代安全与发展的国际公约。  
![](../Images/9ae9cf06a0b78adb12036e94847de4dd.png)华为Hisec首席网络安全架构师殷浩也发表了自己的看法，“5G网络环境当中，CT网络域需要进行引入IT化的安全运营管理能力，甚至是安全和运维流程的变革，才能更好的面对各类网络安全威胁。”  
![](../Images/767d68e732c1cca0df9e4adc3b6bd4ea.png)身为中国电力科学研究院有限公司信息通信研究所工程师的李志表示，与传统互联网相比，能源互联网不仅实现了人与人，人与物的互联，而且实现了人、物、能源终端之间的广泛互联，引发并满足更多的互动需求，创造出全新的价值。

  

![](../Images/e83000eafc9bade70a88f53bf9641a83.png)随着5G技术的不断成熟，由虚拟化所带来的安全挑战也不断增加。中国移动通信研究院网络技术研究所所长段晓东表示，软硬件的解耦，边缘计算方面的基础准备、技术体系的形成、生态体系的形成、总机交付能力，切片的运营、管理、调度，切片的质量如何达到精准的设计，切片的资源如何调配，切片端到端如何协同，这些都是虚拟化带来的前所未有的挑战。  
![](../Images/d0c6568cae5c44d4217224804e35542a.png)论坛的最后，奇安信集团高级安全研究总监乔思远指出，安全能力是一个一个作战的方法，可以像船上的导弹一样去应用，对5G来说实现这样的开放能力并不是一艘战舰就能够达到多样化需求的，需要所有5G相关的产业全部加入进来。  
![](../Images/066bc67d376e999077ca25b224437c84.png)在随后题为《推进5G网络建设，保障网络信息安全》的圆桌对话环节中，王志勤、中国电信集团公司科技创新部网络与信息安全领域业务督导王爱宝、段晓东、吴沈括、殷浩分别针对主题发表了各自的看法与观点。![](../Images/943145c80ffe6a893bd4cc87db2be7cd.png)![](../Images/add65bcbea93778e3e70dccf3506615b.png)

  

据悉，北京网络安全大会于8月21日至23日在国家会议中心举行，本届大会主题为“聚合应变，内生安全”，旨在通过打造世界级的网络安全产业交流平台，多位国际政要、顶级信息安全专家齐聚大会并发表演讲，此外还汇聚了上千位各行业IT决策者、学术界领军人物、优秀企业代表等，共同探讨网络安全的前瞻技术和产业发展趋势。
