# 让智慧能源更安全 北京网络安全大会聚焦智慧能源网络安全

能源是重要的基础产业，在国家战略中占有重要的基础性地位，而随着5G数字化、泛在物联网、人工智能和实体经济的深度融合，智慧能源也面临着日益严重的网络威胁。2019年8月21日，在国家会议中心举办的北京网络安全大会智慧能源网络安全高峰论坛上，众多行业专家就智慧能源面临的网络安全问题进行了深入的讨论。

  

  

![](../Images/84e8573bf98678a6e1b3eedf18aada28.png)![](../Images/e9dd8147f98a1152b87ba2c06915a98e.png) ![](../Images/a762583ca5eef91bef9585df469e2244.png)

BCS2019 智慧能源网络安全高峰论坛

  

本次会议由中国电机工程学会会士、中国电机工程学会电力信息化专业委员会副主任**刘建明**主持，多位行业专家参与，为解决智慧能源面临的网络安全问题，推动能源行业网络安全水平更上新台阶，与会专家结合自身企业现状，提出了众多见解与建议。

刘建明

![](../Images/229543c5645079fe720a2c45dff3ba30.png)  
中国能源研究会常务副理事长、国家能源局原副局长**史玉波**在致辞中表示，首先，要加强能源领域的网络和信息技术的创新研究和开发应用，确保我国关键技术设施制度化数字化充分利用，建设网络与信息安全的保障体系。  
其次，要解决好网络安全与智能化发展的关系。网络安全是智能化发展的前提，智能化发展同时也是安全的基础。网络安全和发展应同步推进，以安全保发展，以发展促安全。第三，构建网络安全技术体系，推动行业网络安全人才发展。建立符合我国国情且进一步较强可操作性的关键信息基础设施保护技术体系，有效的融合行业主管部门的要求和本行业自身的要求，打造关键基础信息基础设施领域专家团队，运行服务团队。

史玉波

![](../Images/4529ae25a4cd069a18f602ee011e99dc.png)  
中国华能集团首席信息师**朱卫列**指出，保障智慧能源网络安全要将安全与智能相结合。首先要重视安全问题，在大的框架下进行等级保护，并对数据进行安全加密。另一方面就是进行智能化，安全离不开智能化，只有将安全与智能相结合，才能达到更好的效果。

朱卫列

![](../Images/272f6c5de30a324a12a2cac681fa2589.png)  
国家电网公司大数据中心副主任**陈春霖**认为，随着泛在电力物联网建设，智慧能源面临的网络环境更加复杂，他提出，智慧能源网络安全可以从以下四个方面进行推进。  
一是打造全场景网络安全防护体系，制定专项提升行动计划。二是研究适应泛在物联的柔性认证技术，升级基础设施，建立公司一体化网络安全仿真验证环境。三是建立电力大数据安全实验室，联合内外部资源共同推进数据安全能力建设。四是打造全景感知，从全局视角提升数据安全威胁的识别和安全监测能力。

陈春霖

![](../Images/16278f1f970ed0f64ec0b25366d1d972.png)  
国家电投集团科技总监、科技与创新部主任**范霁红**则认为，现在的智慧能源系统基础是互联网。因此要更加关注网络的去中心化认证，大数据安全分析以及轻量化防护技术。

范霁红

![](../Images/d625a50b6c7e6ffb873082934866f8be.png)  
中国海洋石油集团有限公司信息化部副总经理**竹蔚文**称，保障智慧能源网络安全主要措施是完善标准制度，持续监督检查，提升动态防护能力，强化多层次纵深防御以及建设专业化网络安全队伍。

竹蔚文

![](../Images/41a819c401f2aff2193ab095bfcd59cb.png)  
奇安信集团副总裁**左英男**表示，要做好网络安全规划和体系建设，建立起统一的安全管理，将安全体系规划建设和新一代信息化系统深度融合，构建起安全的网络安全体系。

左英男

![](../Images/167f9f65999b425c6a5ef9246f525d05.png)  
  
 北京网络安全大会是由中国电子信息产业集团有限公司指导，中国互联网协会、中国网络空间安全协会、中国通信学会、中国友谊促进会和奇安信集团主办的安全行业盛会。此次大会将立足建设网络强国和加快推进数字经济转型发展，打造世界级的网络安全产业交流平台。
