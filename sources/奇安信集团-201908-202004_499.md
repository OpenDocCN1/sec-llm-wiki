# 聚焦BCS 2019｜第四届观潮论坛召开 数字世界需要新思维

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247494854&idx=3&sn=94f044337cc26f40b97a6c3fd06c870c&chksm=fb76cac2cc0143d4151b807108947ff54a992f27e0b9f1263414317cb336a982dbb5833235ce&scene=126&sessionid=1681373748#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247494854&idx=3&sn=94f044337cc26f40b97a6c3fd06c870c&chksm=fb76cac2cc0143d4151b807108947ff54a992f27e0b9f1263414317cb336a982dbb5833235ce&scene=126&sessionid=1681373748#rd)

“数字世界必须摒弃狭隘和过时的绝对控制和绝对安全论，向多边主义方向进行思维和规则的突破。”观潮论坛主席、国家创新与发展战略研究会副会长郝叶力8月21日下午在第四届观潮论坛上表示，面对网络安全的新技术和新形势，需要旋转思维、整体思维等新的思维，才能更好地解决网络安全问题，为“地球村”共筑和平稳定的压舱石。

![](../Images/f242326955b17d0228e09ff3860f9a60.png)

  

以“共话数字世界的游戏规则”为主题的第四届观潮网络空间论坛（以下简称“观潮论坛”），在2019北京网络安全大会（BCS 2019）期间召开。六国大咖跨洋聚首，围绕影响数字世界安全与发展的痛点、难点，数字世界的游戏规则等问题展开战略对话，以洞见数字技术的发展与控制、竞争与合作的新走势，共同探寻趋利避害、应对风险、建立规约的方法、路径与行为准则。

  

本届观潮论坛由观潮网络空间论坛副主席、国家创新与发展战略研究会副理事长、中国科学院大学经管学院教授吕本富主持。观潮论坛理事长、奇安信集团董事长齐向东，联合国经济和社会事务部公共机构和数字政府司司长朱巨望，美国前助理国防部长、前网络安全首席顾问、哈佛中心联合主任Eric Rosenbach等嘉宾出席并致辞。

  

**No.1**

**超越二元对立，数字世界需要新思维**

  

“数字世界，是实体经济和现实社会全面数字化升级，形成线上线下深度融合的新时空。数字世界具有三大特性：数据的流动性、资源的复用性、平台的赋能性。”郝叶力认为，数字世界能量呈几何级数增长，但严峻的困境和痛点也已显现：一是安全概念的过度泛化，可能导致数字世界冷战化、碎片化；二是新技术突飞猛进发展的不确定性，带给人类新威胁、新挑战。新技术发展的主导权成为竞争制高点。

 

郝叶力称，数字世界是个大棋局，需要遵循游戏规则，设定行为边界，才能成局而不破局。要想下好这盘棋，需要格局思维，把安全与发展、竞争与合作，这两个维度的关系放在一盘棋局中来考量。为此，她认为，面对网络安全的新技术和新形势，观察网络空间的“三视角”理论在过去多元思维和分层思维基础上，新增旋转思维和整体思维，从而更好地解决网络安全问题。

  

![](../Images/2ab1470d95270471fbfe7503c5aacd5a.png)

图 观潮论坛主席、国家创新与发展战略研究会副会长郝叶力

  

郝叶力解释称，旋转思维，即换位思考，网络空间中的国家、国际和国民，每个行为体都有需要尊重小三角，保护核心层，但也必须互相兼容大三角，拓展共享区。核心区尊重差异，共享区求同共治。而整体思维则是指，国家、国际和国民等各方共处三角形空间，内切圆形成了平衡的共同利益区，外接圆构成了广泛的数字世界疆域。

 

“一千人眼中可能会有一千个看问题的角度，但拥抱了多元、分层、旋转、整体思维，我们就拥有了超越二元对立的智慧，有了稳定的基石和解决问题的钥匙。以此为方法论，可在网络大潮中，开合作大局，利全球共治。”郝叶力为此提出了六大关键词，围绕竞争应是敬畏、互动、慎用代价，对于合作则应坚持信任、纠偏、正向构筑。

  

**No.2**

**六国大咖，共话数字世界的游戏规则**

  

观潮论坛坚持国际视角，欢迎全球学者“观网络大潮”。

 

本届观潮论坛吸引了美国前陆军少将、美国Palo Alto Networks公司首席安全官John Davis，美国信息产业机构政策总裁Christopher Millward，云安全联盟（CSA）首席执行官Jim Reavis，美国东西方研究所全球副总裁Bruce McConnell，美国卡内基国际和平基金会高级研究员Eli Levite，马来西亚网络安全董事会主席Azumi，荷兰莱顿大学副教授、海牙网络规范项目高级研究员Dennis Broeders，谷歌拼图董事总经理Scott Carpenter，英特尔全球安全战略计划高级总监Thomas Quillin、联合国裁军厅网络空间安全团队官员Ingmar Snabilie以及中国社会科学院教授、国家全球战略智库研究员丁奎松，阿里巴巴集团副总裁刘松，凤凰卫视评论员汤本，清华大学公共管理学院教授李晓东，中国网络空间安全协会副理事长杜跃进等中、美、马来西亚、荷兰等六国安全领域的顶级智库和行业代表参加。

  

![](../Images/5c0990f0dc1f00627ad1632e59780490.png)

  

针对当前数字世界的难点与痛点，美国前陆军少将、美国Palo Alto Networks公司首席安全官John Davis认为，当前网络攻击者利用自动化技术实施攻击和逃避检测，动态网络威胁领域面临新的挑战。他建议，防御者需要人工智能来抵抗攻击者，以便快速阻截攻击者、发现那些靠人工方式无法察觉的威胁、借助持续性分析避免人为出错，同时简化操作。

 

“在过去的十年中，企业和普通公民的网络安全意识以及对数据的日常依赖显著提高。但各国烟囱式的特定法规和标准阻碍着互操作性和创新。”美国信息产业机构政策总裁Christopher Millward呼吁，应通过国际标准加强数据隐私的互操作性，平衡隐私担忧与新兴和联网技术，加强国际间的沟通交流。 

  

![](../Images/48f0e9cbe7673b6d5b0a9c20042cb4a9.png)

  

荷兰莱顿大学副教授、海牙网络规范项目高级研究员Dennis Broeders建议，有必要制定和颁布一项国际性规范，规定各国必须保护互联网的公共核心（即其主要协议和基础设施，是一种全球性的公共商品）免受不正当干预。

 

除了六国专家外，今年观潮论坛同样迎来了联合国官员参会。

 

在观潮论坛现场，联合国经济和社会事务部公共机构和数字政府司司长朱巨望呼吁，在全球网络安全领域建立相互信任、协调有效的合作机制，将发展数字经济作为实现全球经济社会可持续发展的关键措施。

  

观潮论坛由国家创新与发展战略研究会、中国国际战略学会、奇安信集团共同发起，致力于打造我国网络空间领域重要战略智库，通过不断促进中国和国际社会的互动，为全球网络空间治理提供全新视角。

  

据观潮论坛相关负责人介绍，以后每届观潮论坛将在北京网络安全大会期间举办。北京网络安全大会由中国电子信息产业集团有限公司指导，中国互联网协会、中国网络空间安全协会、中国通信学会、中国友谊促进会和奇安信集团主办，旨在打造世界级的网络安全产业交流平台，推动全球范围内政、产、学、研、用各界在网络安全领域的交流与合作，共建全球网络空间命运共同体。
