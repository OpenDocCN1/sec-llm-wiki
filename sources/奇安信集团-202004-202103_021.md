# 上市刚过半年 奇安信入选科创50指数样本股

**金融界网2月26日消息 **2月26日，上交所公告，根据指数规则，上海证券交易所与中证指数有限公司决定于2021年3月15日起，对科创50等指数的样本进行调整，调入奇安信等5只股票。  

  

![](../Images/4268abcb69787a89aa7c94b9b9635136.png)  

  

**“科创50”指数**作为首条表征科创板市场的指数，是投资者观察科创板市场的重要参考，指数成交金额（量）显示为全部科创板证券的成交金额（量），可方便投资者观察科创板整体情况。

  

科创50指数的筛选可谓优中选优，具体评价标准结合了总市值以及日均成交量等资本市场核心指标。此前，上交所出台《关于修订上证综合指数编制方案的公告》指出，“科创50”指数总体呈现以下特征：

**一是**指数代表性充分。

**二是**行业特征鲜明，样本集中于新一代信息技术等战略新兴行业，凸显了科创板创新驱动的行业结构特征。

**三是**科创属性突出。样本公司平均研发支出占营业收入比例达13%。

  

按照指数调整规则，现阶段新股上市满6个月后可纳入样本空间。此次调入科创50指数样本股的奇安信，是网络安全龙头企业，于去年科创板开板一周年之际正式上市。换言之，刚过6个月即被调入科创50指数样本股，足见资本市场对奇安信的认可。

  

根据公开资料，在上市前，奇安信三年研发费用投入超过24亿，研发占营收比为41.54%。去年前三季度，奇安信研发投入高达8.71亿。也是凭借科创驱动和研发优势，近日，奇安信以中国有效发明专利数473件、全球发明专利数量1299件，位列“科创板225家上市企业有效发明专利排行榜”第五，领跑国内网络安全行业。  
在上市时，奇安信将57亿元全部投入网络安全新赛道。根据2月24日发布的2020年度业绩年报快报显示，奇安信新赛道产品在自有产品中营收占比由2019年的34.95%提升至42.65%，市场竞争力凸显。同时，根据赛迪、IDC数据等第三方机构数据，奇安信在终端安全、大数据智能安全检测与管控、安全管理平台、云安全和安全服务等新兴领域，均已做到行业第一。  
与此同时，年报快报还披露，奇安信2020年全年营收为41.64亿元，与上年同期相比增长了32.04%，规模继续稳居网络安全行业第一，其**2020年年初启动的“高质量发展”战略效果初显成效。**

  

东吴证券等多家券商研报认为，以等保 2.0 为核心的政策、以“云大物移工”为代表新安全、以“动态攻防”为代表的新产品将驱动网络安全需求持续增长，以及疫情影响安全支出将重回正常化，多重因素推动行业高速增长，奇安信作为网安行业的领军者，凭借在“新安全”领域优势，以及全面布局的主动防护网安体系，将迎来更大发展。
