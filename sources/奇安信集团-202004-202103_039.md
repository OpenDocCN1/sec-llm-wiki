**奇安信代码安全实验室研究员**为微软发现一个严重的DNS服务器远程代码执行漏洞 (CVE-2021-24078)，第一时间报告并协助其修复漏洞。

**该漏洞是首个由国内安全研究员发现并提交的蠕虫级漏洞，危害巨大，CVSS 评分为9.8分，堪比去年微软修复的类似漏洞 (CVE-2020-1350)。**

![](../Images/a1a8b04cccbd9ca89723e0847ce7e0a1.png)

漏洞概述

  

**CVE-2021-24078 —— Windows DNS Server 远程代码执行漏洞**

攻击者仅需向目标DNS服务器发送特制数据包，即可利用该漏洞在目标系统上以本地系统账户权限执行任意代码，且触发无需交互、无需身份认证且在 Windows DNS 默认配置下即可执行。

微软已发布修复方案，用户应尽快修复。
