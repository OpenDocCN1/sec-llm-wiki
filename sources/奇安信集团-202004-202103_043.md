# 《2020年人工智能优秀产品和应用解决方案》正式发布 奇安信监管类态势感知成功入选

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247520325&idx=2&sn=9196c098f74de22841d1ceb02939d398&chksm=fb76b641cc013f5722852b39e118577f73930f65d5d571da76b2aa3939e5605e292b897342b0&scene=126&sessionid=1681373530#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247520325&idx=2&sn=9196c098f74de22841d1ceb02939d398&chksm=fb76b641cc013f5722852b39e118577f73930f65d5d571da76b2aa3939e5605e292b897342b0&scene=126&sessionid=1681373530#rd)

2月8日，由国家工业信息安全发展研究中心(简称“中心”)人工智能所主办的“信息技术大讲堂·优秀案例篇”活动在线上召开。

  

活动期间，中心正式发布了**“2020年人工智能优秀产品和应用解决方案”**名单，**“奇安信网神网络空间安全态势感知与协调指挥系统”**(简称：奇安信监管类态势感知平台)在全国数百个参评项目中脱颖而出，成功入选。

  

  

![](../Images/2d3462c2eaa20534834b676f18b50ab8.png)

  

**奇安信集团副总裁李虎**在演讲中表示，网络空间是一个高度复杂、贯穿了虚拟世界和现实世界的复杂巨系统，要深刻的洞察、实时的感知、精准的应对、保卫其安全，就必须建立以安全大数据为支撑，集感知、管理、预防、控制、打击、反制能力为一体的防御体系。奇安信监管类态势感知平台就是这样的大数据体系。

  

李虎介绍，奇安信作为国内最早推出网络安全态势感知技术及平台的安全厂商,通过7+1能力体系，集业务能力、数据能力、技术能力、服务能力、安全能力、呈现能力、交付能力为一体，以平台化技术进行整合，建立知行合一、平战结合、攻防兼备、智能开放的网络安全治理平台，使其成为监管机构、行业主管部门治理、保护网络安全的核心抓手。

  

作为多个国家级重大活动网络安保的独家支撑平台，2020年，奇安信监管类态势感知参与了全国两会、世界互联网大会、国家网络安全宣传周、贵阳数博会等多个重大活动，并为数十次实战攻防演习活动，提供了网络安全监测与指挥保障。

  

![](../Images/d2036b09446410269631deb5fcba29b0.png)

  

**多家第三方机构的市场分析报告显示，奇安信在态势感知领域始终处于领先地位。**

*   2019年IDC发布的《中国态势感知解决方案市场 2019 年厂商评估》报告显示，奇安信在市场和收入、战略规划、创新技术、产品功能、客户满意度等多方面排名第一，获评中国态势感知解决方案领导者。
    
*   2020年3月数世咨询发布的《网络安全态势感知能力指南》显示，奇安信在技术创新力和市场执行力双第一。
    
*   在"安全牛"对外发布的《2020网络安全态势感知应用指南》报告中，奇安信集团入围年度代表性厂商，同时有5个行业代表性案例入选，在数量和覆盖领域等方面在所有入围厂商中位列第一。  
    

  

  
  

**信息技术大讲堂系列活动由国家工业信息安全发展研究中心人工智能所主办，邀请来自政府、行业、学界的精英代表共同探讨人工智能、大数据等行业前沿趋势，旨在进一步推动新型基础设施建设，加快新一代信息技术与实体经济的融合，提升社会大众对新一代信息技术的认知水平和应用能力。**
