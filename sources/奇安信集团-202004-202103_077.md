# 奇安信董事长齐向东谈职场：干网络安全要甘于寂寞

*“我们做技术，尤其是网络安全技术，往往需要能够甘于寂寞”奇安信集团董事长齐向东在1月15日播出的热门职场节目《职场是个技术活》上说，他最看重能够坚定干自己的事，‘’命长‘’的员工。*  

  

在这期节目上，齐向东对通过层层选拔出的3名奇安信实习生进行终极面试，并为通过考核的实习生现场发放入职offer。

  
![](../Images/277be245a278f8514f2bf965c118f12f.png)节目一开始，齐向东就表示**“今天至少要带走一位人才”**。  
面对清华博士、网络安全技术专业人才，职场“小马达”型人才，和跨专业的天赋型人才，齐总从价值观和企业认同感对实习生进行了提问面试。  
他表示，职场上有两句话，选择比努力重要，坚持比天赋重要。网络安全行业需要甘于寂寞，对工作岗位坚定的人，虽然很少有短期的光鲜亮点，但“命长”、走得更远，这三位实习生都是“命长”的优秀人才。而面对实习生们提出的薪资期望，齐总也大方表示“都OK”。

  

  
作为新一代网络安全领军者，奇安信专注于网络安全市场，为政府、企业用户提供新一代企业级网络安全产品和服务，网络安全作为高精尖产业，这个职业是名副其实的“技术活”。  

  

在《职场是个技术活》节目中，奇安信实习生就先后参与了U盘数据防泄漏、应急响应服务、网络安全周调研及执行方案汇报、民宿安居设计大赛、云展厅定制化方案等多个项目，接触了奇安信天眼新一代威胁感知系统（天眼）、奇安信终端安全管理系统（天擎）、雷尔可视化平台、云展厅管理系统等，体验了一线客服、用户交付、社会调研、定终端安全解决方案、进驻客户现场部署实施技术系统等多项工作内容，全方位深入了解奇安信的网络安全产品和创新的网络安全服务，同时也让大众对于网络安全有了更直观的感受。  

  

  
![](../Images/4a4c64e8440a8178ad1942a68c71054d.png)  

  

同时，奇安信作为北京2022年冬奥会官方网络安全服务和杀毒软件赞助商，实习生们还从安全场馆和安全可视化两个方向，参与了冬奥网络安全运行指挥系统建设方案课题。  
![](../Images/f64266ae28aa87f0a3c1d871c1e3cbc7.png)

  

**最终，**第一期首发实习生、从未被淘汰过的“小马达”型员工冯珮柔，凭借坚持、不懈、认真、做事扎实，成功获得了齐向东手中唯一的一张工卡，拿到offer。求贤若渴的齐总还当场给另外两位实习生发出了“同意录取”的手写offer，将三人一并收入麾下。

  

![](../Images/daefe6fe8c914a9620af30f760cf5664.png)

  
  

**奇安信从成立时起，就致力于“让网络更安全，让世界更美好”，齐向东也曾表示，“网络安全的本质是人与人之间的攻防对抗”。不管是网络资产管理、补丁管理，还是遇到攻击时调整外环境防护策略、入侵防护策略、终端策略，都需要专业的网络安全人才去分析和执行。对优秀人才的激励和凝聚，激发员工的积极性和创造性，都将在未来转化为奇安信未来发展的竞争优势。**
