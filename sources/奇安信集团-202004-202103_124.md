# 奇安信获“国家网络与信息安全信息通报机制”优秀技术支持单位

12月15日，由国家网络与信息安全信息通报中心主办的“国家网络与信息安全信息通报机制技术支持单位2020年度工作总结暨表彰会议”在京召开，奇安信荣获**“国家网络与信息安全信息通报机制”优秀技术支持单位**，并受到表彰。

![](../Images/1ccd7ae5ebcbae63f1f5e1ba241822ca.png)

  

公安部网络安全保卫局一级巡视员、副局长兼总工程师郭启全等领导出席了表彰会议，并对奇安信等25家优秀支持单位在2020年所做的工作表示肯定和赞许。他表示，希望支持单位进一步发挥榜样作用和表率作用，成为网络安全综合服务商，向世界一流企业发展。”

  

![](../Images/0aec70403840fb1e9cb7aeb8b0aa3a1f.png)

“奇安信作为迅速成长的大企业，起到了带头作用，同时也拉动技术创新，促进了产业的发展”郭启全对奇安信在国家网络与信息安全信息通报机制技术支持方面的工作表示肯定。

  

作为优秀企业代表，奇安信首席战略官刘勇在表彰会议上介绍了2020年奇安信在国家网络与信息安全信息通报机制技术支持方面开展的主要工作，包括重保支持、信息通报、情报服务、应急处置以及安全赋能。

  

在重保支持方面，奇安信2020年配合公安部及各地公安机关执行多次重保任务，如央视春晚、全国两会、北京服贸会、数字中国建设峰会、进博会、世界互联网大会等，确保重大活动无网络安全事故发生。

  

在情报服务方面，奇安信利用公司威胁情报能力，全面支撑了海莲花等APT组织的发现、分析工作。

  

  

在应急处置方面，奇安信全年响应处置了来自公安部及各地公安机关的数十件安全事件。目前奇安信应急响应服务已覆盖全国31个省市。

  

在安全赋能方面，奇安信先后主办、协办并参加天府杯、网鼎杯等网络安全大赛，配合网安局组织关基保护论坛、等保关保宣贯会等活动。

  

“公司将支撑工作上升为公司战略层面，从体制、机制、人员配备、资源组织到管理体系多方面形成完备的支撑体系，全力保证支撑工作。”刘勇表示，开展支撑工作，是国家站位和社会担当的体现，是网络安全企业应尽的责任和义务，也是政策引导和政府支持的成效，是促进产业集群竞争力提升的最佳路径。
