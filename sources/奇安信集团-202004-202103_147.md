# 打造网安产城融合生态园 奇安信与重庆网信办、璧山区达成战略合作

![](../Images/c38edcd2be518e4c39ac868d0f6d1c57.png)12月4日，奇安信集团与重庆市璧山区人民政府、重庆市委网信办签署战略合作协议，三方将携手共同打造“一带一路”的网络安全产城融合和网信人才生态园。![](../Images/5f90bc812d4f50f06b9387e6a4d0edf8.png)![](../Images/05d2668a23c3cfa6174e38b90e60b213.png)**重庆璧山区委书记蓝庆华、重庆市委网信办主任文天平、奇安信集团总裁吴云坤出席了签约仪式。重庆璧山区委常委、常务副区长张献强与重庆市委网信办副主任王茵、奇安信集团重庆区域总经理马培月等三方代表，就共同打造网络安全产城融合和网信人才生态园进行了签约。**  
![](../Images/87ee876466f4107faa2b85047bb7a969.png)

在签约仪式上，**重庆市璧山区区委书记蓝庆华**表示，近年来璧山区抢抓重庆建设国家数字经济创新发展试验区重大机遇，加快“数字产业化、产业数字化、数字化治理”，尤其是在网络安全领域，全区按照“安全即服务”的理念，在西南地区率先布局量子保密通信技术，积极谋划引入国科量子等一批龙头骨干企业，抢抓量子科技发展机遇，努力抢占网络安全市场新“蓝海”。

同时，他期待在三方的共同努力下，加快形成数字经济安全保障体系，实现网络信息安全与数字经济良性互动，推动高质量发展，将璧山打造成为面向“一带一路”全国领先的网络安全应用示范高地。

  

![](../Images/a7689fddfb3a937dd4c3ce617b58651b.png)

**重庆市委网信办主任文天平**表示，璧山区高度重视网络信息安全工作，在硬件、软件上已有大量投入，此次奇安信重点布局重庆落户璧山恰逢其时，三方携手合作，共同维护区域网络信息安全。

  

![](../Images/2df0fb13e8ddb9df1b6e4e3456f16c6c.png)

**奇安信集团总裁吴云坤**表示，璧山区产业基础雄厚，发展前景广阔。奇安信作为国内最大的网络安全公司之一，将充分利用集团自身在云计算、大数据、移动互联网、工业互联网、物联网、安全攻防等方面的突出优势，与璧山在网络安全基础设施、网络安全研究、网络安全技术创新、信息安全学院等相关领域展开全面合作，引导和扶持各类安全人才集聚璧山，共同打造服务成渝地区双城经济圈及面向“一带一路”的全国领先的网络安全产城融合和网信人才生态园，引领和带动西部地区网络安全产业新发展。

  

根据协议内容，未来三方以“坚持网络安全教育、技术、产业融合发展，形成人才培养、技术创新、产业发展的良性生态”为核心，在网络安全基础设施、网络安全服务产品开发、网络安全研究、国家级网络攻防实战演练靶场、网络安全人才和网信人才培养、区域整体网络安全技术能力提升、网络安全技术创新、信息安全学院、网络安全生态发展等相关领域展开全面合作。  
其中，西部城市网络安全运营中心将设立网络安全研究室，网络安全产品开发中心，立足璧山，面向重庆，服务成渝地区双城经济圈及“一带一路”沿线城市。重庆市网信人才培养基地则融入重庆全市干部培训计划，发挥在网信领域的培训优势，开展党政领导干部网络安全新技术、互联网思维等专题培训，着力提升互联网思维和防范化解网络风险的能力。  

而在人才培养方面，三方联合高校将在璧山区落户信息安全学院，结合奇安信安全技术研发能力与实战经验，结合本地高校的优质教学资源，培养信息安全科研和工程技术人才。

  

与此同时，三方将在璧山区建立国家级网络攻防实战演练靶场，开展网络安全攻防对抗演习，提高网络安全防护和对抗能力，培养和储备网络安全人才，提升网络安全创新能力，推动周边网络安全产业创新发展。

  

作为国内网络安全龙头企业，奇安信在今年7月22日科创板上市后，凭借三年复合增长率96%、年营收超31亿的规模，奇安信稳居网络安全行业龙头地位，被媒体誉为“网安一哥”。根据已披露的三季报显示，奇安信第三季度营业收入达8.63亿元，同比增长89.25%，继续领跑网络安全板块。公司前三季度营收为18.7亿，同比增长30.41%。同时奇安信在终端安全、安全管理平台、安全服务、云安全、终端安全软件等领域的市场份额中均排名第一。

  

  

  
  

**目前，奇安信网络安全服务已覆盖国内绝大多数政企机构，同时与多个政府机构展开战略合作，共同打造全面、开放、先进的网络安全产业新生态，为数字经济高质量发展保驾护航。重庆是奇安信重点布局的区域之一，目前已跟重庆广电、重庆经信委、重庆两江新区等展开战略合作，并在今年9月将工业互联网网络安全西部中心总部落户重庆两江新区。**
