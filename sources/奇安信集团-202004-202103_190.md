# 三大亮点抢先看！奇安信将亮相武汉5G+工业互联网大会

11月19日~21日，**“2020中国5G+工业互联网大会”**将在武汉举行。届时，国内网络安全的领军企业奇安信集团将携新一代网络安全框架、工业互联网攻防演示系统等亮相本次大会。  

  

同时，奇安信董事长齐向东，奇安信副总裁吴俣还将在大会期间发表主题演讲，就5G+工业互联网下的网络安全建设分享真知灼见。

  

![](../Images/94fd250793fe8218a8bd27389f7f140f.png)

  

# **亮点 1**

  

**大咖将分享重磅观点**

**论道工业互联网安全**

  

11月20日，大会将举行主论坛环节。当天下午，**奇安信董事长齐向东**将出席主论坛并发表主题演讲，主要探讨工业互联网在新时代下所面临的网络安全新挑战，以及奇安信在新形势之下提出的内生安全理念和安全框架落地。  
在前一天的“5G+互联网安全专题会议”环节，**奇安信副总裁吴俣**将分享《工业互联网应首选内生安全》的主题演讲，他将结合5G+工业互联网下的具体场景和需求，探讨安全风险，以及内生安全框架在工业互联网的具体落地和实践。  
  
![](../Images/ff5157f83d18c0a2409aa2d92b94c2b7.png)  

  

  

# **亮点 2**

  

****将展示面向政企的新一代网络安全框架****

  

作为北京冬奥会和冬残奥会的网络安全“守护者”、奥运史上首个网络安全赞助商，奇安信将用奥运标准进行安全规划建设，守护工业互联网安全。在本次展会上，**奇安信将展示新一代网络安全框架——政企网络安全防御全景模型。 **

  

奥运，是全球最受瞩目的体育赛事，也常常成为全球网络黑客的攻击目标。奇安信为北京冬奥专门打造了**“六全防护体系”：全维度管控、全网络防护、全天候运行、全领域覆盖、全兵种协同、全线索闭环，**确保北京冬奥会关键系统万无一失，“零事故”运行。奇安信将以高标准严要求的“奥运标准”，为工业互联网提供更可靠的安全防护体系。

  

  
![](../Images/ff5157f83d18c0a2409aa2d92b94c2b7.png)  

  

  

# **亮点 3**

  

**场景化的现场攻击演示**

**全面展示奇安信技术实力**

  

紧密结合本届大会主题，奇安信还将通过场景化的攻防演示，展现5G下的工业互联网安全生产风险。

  

![](../Images/f8dca8bd201cce8e398cdbc85b550413.png)

  

届时，奇安信将现场展示化工生产自动化控制系统攻防演示的全过程，包括发起攻击、发现安全威胁、显示攻击过程、可视化展示、安全防护等，让观众更直观感受到未加防护的工业系统所面临的巨大网络安全风险。

  

![](../Images/0ccfac981ef0ef661dfbf13899daa017.png)

  

此外，本次展会还会展示奇安信的工业互联网安全产品及解决方案，以及智能网联车的破解演示，全面展现奇安信攻防技术实力。  
  
  

**11月19日~21日，湖北省武汉市中国光谷科技会展中心B2-07奇安信展台，不见不散！**
