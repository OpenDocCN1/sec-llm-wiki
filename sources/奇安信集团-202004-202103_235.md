# 奇安信魏雨露荣获国务院国资委抗疫“先进个人”表彰

10月22日，由**国务院国资委组织的中央企业抗击新冠肺炎疫情表彰大会暨先进事迹报告会**在京隆重召开。**奇安信集团助理总裁、湖北分区总经理魏雨露**，因在抗击新冠肺炎疫情中做出的优异表现，被评为**“先进个人”**，并获得了国资委党委的隆重表彰。

  
  
![](../Images/69fca07d517ef51441ae7391e08695f0.png)

  

![](../Images/cf8364259305e833c77e1c71416c2968.png)

国资委党委在表彰中表示，新冠肺炎疫情发生以来，国资委和中央企业坚决贯彻落实党中央、国务院决策部署，主动担当、勇挑重担，分秒必争抢建专门医院、义无反顾参与医疗救治、不计代价转产医疗物资、全力以赴攻关医药研发、千方百计保障民生供应、有力有序推进复工复产，在这场惊心动魄的抗疫大战、艰苦卓绝的历史大考中，以实干实绩向党和人民交出了一份合格答卷，涌现出一大批先进典型，生动诠释了伟大抗疫精神，充分展现了关键时刻冲得上去、危难关头豁得出来的主力军风采。

  

![](../Images/6af8ffba7cbbc42794d7bf55821e4251.png)![](../Images/cf8364259305e833c77e1c71416c2968.png)

  

春节前后，湖北省武汉市等地区发生的新冠肺炎疫情，牵动着每个国人的心。作为奇安信科技集团湖北分区经理，魏雨露2020年1月22日从郑州出差回到武汉，计划当天回安徽陪父母过春节。随着疫情形势日益严峻，魏雨露毅然决定留守武汉。

1月25日即大年初一，奇安信紧急成立疫情防控支援团，武汉公司立即成立火神山抗疫小分队。**队长魏雨露临危受命，带领黄宝、张宇、朱波等9人小分队队员毅然决然选择“逆行”**，于1月29日进驻火神山医院，星夜援助火神山医院建设，承担整个火神山医院网络安全建设任务，用行动谱写了一曲动人的抗疫战歌。而这9位小分队队员，更被媒体誉为**“火神山九勇士”**，成为这场战疫中勇敢的“逆行者”。

  

![](../Images/94a1216abec0800575e0b4982a2146c9.png)

  

在这个特殊的团队中，有的家中孩子出生还不到10个月，有的此前与家人已经整年没有见过面。然而当得知火神山前线急需支援后，无一例外地当即决定立刻出发！他们只能通过手机，慰藉春节不能团聚的缺憾和家人的担忧。“我知道这次病毒的传染性有多强。我担心自己感染，担心影响家里人，家里有3岁小朋友，感觉很歉疚，这是心里话。”魏雨露事后回忆道。  
“我们仅用5天，就完成了火神山医院网络安全设备同步架设，圆满完成驰援火神山的任务！这是奇安信人的光荣！”在极其艰难和危险情况下，魏雨露带领小分队成员奋战8天7夜，分别完成火神山、雷神山所有网络安全设备安装调试工作，确保两山医院网络平稳运行。团队出色的表现获得了省市卫生部门以及新华社、人民日报等主流媒体的表扬与报道。   
除了援建火神山医院和雷神山医院外，魏雨露还带领团队免费独家支持湖北省市网信办，省市公安厅局监测全省几千上万个政府，企业互联网资产，并独家多次现场支撑武汉市卫健委大数据疫情直报系统安全服务工作等。  

幸得有你，山河无恙。中国之所以能率先取得抗疫胜利，经济领先全球复苏，离不开医疗、公安、解放军、交通等无数“平凡英雄”的无私付出。

**在网络安全这条看不见的战线上，奇安信还有魏雨露这样的1600多名“逆行者”，**他们第一时间深入疫情防控一线，向全国200多家疫情防控单位捐赠了数千万物资和专业服务，为抗击疫情的有序、高效开展等提供强大的安全保障。
