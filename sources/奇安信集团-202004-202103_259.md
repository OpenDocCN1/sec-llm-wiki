# 国际权威咨询机构最新报告：奇安信领跑国内安全托管服务市场

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247511544&idx=1&sn=49c14d171bc6470d1711d101c79675c3&chksm=fb768bfccc0102ea916fa3a4d4ae504e61174f620d934fa4d96ea5b0f5428533e5fb3299b3b1&scene=126&sessionid=1681373581#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247511544&idx=1&sn=49c14d171bc6470d1711d101c79675c3&chksm=fb768bfccc0102ea916fa3a4d4ae504e61174f620d934fa4d96ea5b0f5428533e5fb3299b3b1&scene=126&sessionid=1681373581#rd)

     近日，国际权威咨询机构**Forrester**发布了《Now Tech: Managed Security Services In Asia Pacific, Q4 2020》（Now Tech：2020亚太地区安全托管服务市场指南）报告。

**报告显示，奇安信**凭借基础安全运营服务、终端安全运营服务、安全运营中心运营服务、态势感知运营服务、全流量威胁分析服务等领先的安全托管服务（MSS）能力，**成为****国内规模最大的安全托管服务供应商**，与德勤、安永、Version、三星等全球知名MSS厂商同列中等规模供应商榜单，领跑国内MSS市场。![](../Images/d07ee2cfb43984f2755eb3dacd3dc550.png)

**Forrester一向以其严谨的评价体系著称，其发布的报告对全球网络安全服务采购方的具有重要参考意义。**本次报告详细分析了亚太地区主要供应商的差异和优势，并对采购方给出具体建议。

报告指出，安全托管服务供应商可以作为安全团队的延伸，能够帮助机构建设更加成熟网络安全能力体系，减轻全团队的工作压力，从而更加专注于主营业务。但在选择供应商之前，客户必须明确供应商所能提供的服务细节，并确保他们能够及时和完整交付。

报告针对威胁检测、事件响应、威胁情报、机器学习等26个细分指标，对亚太地区安全托管服务商进行了全面的评估和考量，奇安信在大多数指标的评测中均位居领先位置。

  

![](../Images/74f27b6ec3e714e47879b416f1b48fc7.png)  
据奇安信安全托管服务负责人介绍，奇安信已经具备了完善的网络安全产品体系和一支近千人的安全服务团队，覆盖终端安全、大数据安全分析、安全运营、应急响应等相关领域拥有领先的技术研发实力和强大技术力量，为安全托管服务提供了有力的支撑。可以一体化协同推进安全托管涉及的资产管理、威胁分析、漏洞验证、安全数据分析、溯源分析、事件协同处置等一系列持续的运营动作，找出安全体系的短板，为用户安全建设提供支撑，推动安全管控体系的全面提升，帮助用户科学地开展安全工作。  
**目前，奇安信已经为上百家来自政府、金融、能源与公共事业等行业的客户，提供了专业的安全托管服务。**
