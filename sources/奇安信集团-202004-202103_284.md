# 分享奥运故事·守护冬奥安全|北京冬奥宣讲团走进冬奥赞助商奇安信

**9月23日，北京冬奥会倒计时500天系列宣讲活动——北京冬奥宣讲团奇安信专场宣讲会在奇安信安全中心举行，来自不同行业的八位宣讲员从不同的视角，分享他们与冬奥的故事。**

  

![](../Images/fde9f5ff9a419b747a998654f16fa5ad.png)**北京冬奥委市场开发部副部长顾灏宁，市场开发部赞助商服务处副处长李超，新闻宣传部综合处干事陈博，市场开发部赞助商服务处干事谷秀，北京市委讲师团百姓宣讲处干部徐艳丽，随锐集团副总裁胡鹏出席了此次宣讲会。**

  

![](../Images/b8aa5a648fd4f166423898bcf15070a4.png)

图 北京2022冬奥委市场开发部副部长顾灏宁  

  

顾灏宁为此次宣讲会发表了致辞。顾灏宁表示，2022北京冬奥会的顺利举办需冬奥赞助企业大家庭的通力合作。奇安信作为新一代网络安全领军者、北京2022年冬奥会和冬残奥会官方网络安全服务和杀毒软件赞助商，值得被寄予更多期待。

随后，**北京冬奥组委新闻宣传部陈博**介绍北京冬奥会筹办工作进展情况。

  

在宣讲环节，八位宣讲员分别讲述了自己与奥运的故事。他们之中有为雪而生，为国而战的**自由式滑雪空中技巧世界冠军郭丹丹**，有让五星红旗在奥运赛场上高高飘扬的**第九届残奥会冠军刘玉坤**；

有等待着与冬奥相遇的**北京市朝阳区第三少儿业务体校高山滑雪运动员张丁月**和**北京市延庆区第二小学学生王凯文**；

还有6年走遍全球45座奥运城市，致力于传播奥林匹克精神的**奥林匹克文化推广人、国际奥委会文化与奥林匹克遗产委员会委员侯琨**。

  

  
  
![](../Images/d2de761e16c9782bc7d6ddcfe6053281.png)**他们平凡又不平凡的奥运经历，真挚又朴实的奥运情怀，让现场奇安信员工深受感动和鼓舞。**  
  
此外，**中国联通北京分公司冬奥办公室主任张嘉**和**北京北控京奥建设有限公司员工张丹丹**还分别介绍了他们为北京2022年冬奥会筹备工作做出的努力和经验。而作为北京2022年冬奥会和冬残奥会官方网络安全服务和杀毒软件赞助商，**奇安信一直致力于守护北京冬奥会的网络安全。**

  

在科技冬奥战略下，2022年北京冬奥会中，人工智能、物联网、5G、云计算、大数据等新技术大量应用，网络环境将更加开放，更追求数据集中与共享，IT环境将变得更加开放复杂。

  

北京冬奥会的IT和业务环境复杂程度、面临的安全威胁和安全挑战将远超任何企业，需要从信息化角度，用工程化思想，体系化规划建设网络安全体系。

  

**为此，奇安信面向科技冬奥的新一代网络安全框架体系。**在新一代企业网络安全框架指导下，奇安信将为北京冬奥会建立“全层面管控、全网络防护、全领域覆盖、全周期保障、全线索闭环、全兵种协同” 的“六全”网络安全保障框架体系，确保北京冬奥会关键系统万无一失，“零事故”运行。

  
![](../Images/e555a790a5ac302f673327780f45bde0.png)

图 宣讲团参观奇安信安全中心展厅

  

在此前BCS 2020峰会上，**奇安信集团董事长齐向东**接受媒体采访时表示，今年年初奇安信已开始着手执行高质量发展战略，计划用**6年时间实现“四化”——奥运化、乐高化、服务化、国际化。奥运化是其中重要一环。**

  

齐向东表示，每个奇安信人都应该学习奥运精神，勇于向世界先进水平挑战，体现出更快、更高、更强的精神。奥运精神还意味着竭尽所能，每天都比昨天的自己更好一点。齐向东认为，如果每个员工每天都比昨天的自己更好一点，奇安信就是世界上最好的公司。

  

筹办北京冬奥会、冬残奥会是中国的一件大事，是北京的一件大事，也是奇安信的一件大事。奇安信人已把奥运精神融入日常工作和事业发展中。  

办好北京冬奥会，是中国对国际奥林匹克大家庭的庄严承诺，是中国对国际奥林匹克运动作出的又一重要贡献，相信在社会各界的共同参与和积极努力下，2022年，北京联合张家口一定能举办一届精彩、非凡、卓越的奥运盛会！
