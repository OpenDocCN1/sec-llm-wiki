# 奇安信NGSOC荣获“2020年网络安全解决方案优秀奖”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247507096&idx=2&sn=0a4a6eb0099d1c31f1867d61aed05d96&chksm=fb76fa9ccc01738a63336412e5b0daafcc1fdcc4bd4cc46a18f6283a070d794b3e0577997b89&scene=126&sessionid=1681373591#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247507096&idx=2&sn=0a4a6eb0099d1c31f1867d61aed05d96&chksm=fb76fa9ccc01738a63336412e5b0daafcc1fdcc4bd4cc46a18f6283a070d794b3e0577997b89&scene=126&sessionid=1681373591#rd)

**9月15日，在由中国网络安全产业联盟（CCIA）举办的“2020年国家网络安全宣传周——网络安全产业创新发展论坛”期间，奇安信态势感知与安全运营解决方案（下文简称奇安信NGSOC解决方案）荣获“2020年网络安全解决方案优秀奖”。**

![](../Images/004c4a5e874575d39359a6ab16b5eb1c.png)

  

据悉， “2020年优秀网络安全解决方案和网络安全创新产品”评选活动自5月29日开始，历时近两个半月，经由CCIA专家委以及知名投资机构代表组成的风投专家组严格评审和把关，历经专家初审、网安用户在线投票、复审答辩等环节，综合专家打分和网安用户在线投票得分，最终奇安信NGSOC凭借实战化威胁检测、溯源分析和安全运营能力，从120多款产品和解决方案中脱颖而出，获此殊荣。

  

据奇安信NGSOC负责人介绍，攻防对抗的日趋加剧，为安全管理者和安全运营人员带来巨大挑战，政企机构对于实战化安全能力以及安全运营人员能力提升和持续的运营体系建设等需求不断增长，**主要表现为：**消除安全数据的信息孤岛，将威胁分析所需的各类数据进行统一采集、处理和存储；引入高性能的关联分析引擎和高置信度的威胁情报，提升高级威胁事件的检测能力；在日趋复杂庞大的目标网络中，实现安全事件溯源与调查；实现不同层级、不同时段的资产态、风险态、安全态、防护态和运营态的可视化；持续运营体系的建设需求，不断提升安全运营的效率和相关从业人员的安全技战术水平。  

  

对此，**奇安信NGSOC解决方案**针对安全管理者在摸家底、识风险、控态势方面的不足，以及安全运营人员在深度检测、持续监测、精准预警、趋势研判、追踪溯源、运营保障等方面能力要求，创新并突破了多源异构安全大数据高效采集与处理、大数据智能检测与高效分析、基于攻防博弈的威胁建模与APT挖掘分析、多元威胁情报生产与应用、基于积极防御的威胁精准预警和自动化响应、安全事件高效研判分析与追踪溯源、全方位立体化安全动态监测等系列核心关键技术，提出有效解决方案，帮助政企机构持续监测网络安全态势，实现从“被动防御”向“积极防御”的进阶，为安全管理者提供风险评估和应急响应的决策支撑，为安全运营人员提供威胁发现、调查分析及响应处置的安全运营工具。![](../Images/9a510a9af5c0d935e3f14fe63d0232d2.png)  
  
此前，赛迪顾问发布的《2019~2020年中国网络信息安全市场研究年度报告》显示，奇安信NGSOC在中国安全管理平台产品市场占有率达到23.9%，排名第一。IDC发布的《中国态势感知解决方案市场2019年厂商评估》显示，奇安信集团获评中国态势感知解决方案领导者。数世咨询发布的态势感知能力点阵图显示，奇安信态势感知在技术创新力和市场执行力双第一，处于市场领导者。
