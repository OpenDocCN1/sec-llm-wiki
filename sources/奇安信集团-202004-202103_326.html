浏览器新高度 奇安信发布87内核可信浏览器先锋版

9月3日，继7月率先升级浏览器Chromium 83内核之后，奇安信又一次领先业界，正式发布国内首款升级至Chromium 87内核的奇安信可信浏览器先锋版。

据悉，先锋版将率先适配信创平台，旨在为用户提供更加安全、可信、领先的政企业务承载平台。


图 奇安信可信浏览器先锋版欢迎页



2个月之内再度升级

奠定信创浏览器领先地位


据了解，7月8日奇安信可信浏览器升级83内核，是近年来国产浏览器与Chrome浏览器正式版首次实现内核版本同步。而这次奇安信可信浏览器先锋版升级至87内核，空前实现了国产浏览器与最前沿的Chrome Canary内核版本同步，在国产浏览器市场上前所未有，在全球浏览器市场上也可谓罕见。


尤其是两次内核升级仅相差不到2个月，其更新迭代堪称火箭速度。分析人士称，此次基于Chromium 87内核的先锋版上线，再次奠定了奇安信在信创浏览器的领先地位。


目前，奇安信可信浏览器先锋版已经率先在信创平台的麒麟商店上架，广大政企客户可到麒麟应用商店下载体验。


图 奇安信可信浏览器先锋版已上架麒麟商店


“近几年信创领域的发展可算是百花争放、百家齐鸣。但对于一直习惯使用Wintel平台的用户来说，信创平台的体验相对而言还是有很大差距。”奇安信可信浏览器田亮表示，“尤其是浏览器软件作为用户上网、办公的必备工具，在保证用户方便、快捷、安全的前提下，能够让用户在最快时间内体验最新的技术，是对各大主流浏览器厂商技术实力的考验。”

作为国内网络安全的领军企业，以及信创产业的坚定支持者，奇安信在业内率先推出了可信浏览器先锋版。田亮表示，“这款浏览器不仅率先采用了Chromium 87内核，同时率先适配信创平台，这样让政企用户在信创平台上，能用上超出Wintel平台的优质产品。这不仅是我们的能力体现，也是我们义不容辞的责任。”




率先升级最新安全内核

打造更可靠的业务承载平台  


作为用户上网和获取信息的入口，以及政企业务的承载平台，浏览器安全的重要性毋庸置疑。据介绍，业内大多数浏览器仍在使用78内核，从78内核到先锋版最新的87内核版本，Chromium一共修复了多达300多个安全性漏洞，从而大幅提升了浏览器内核安全性，降低利用漏洞入侵的各类风险。

同时，先锋版在很多安全细节方面进行了强化。新内核浏览器通过新增了地址栏隐藏完整URL功能，可以避免攻击者通过URL欺骗方式的网络钓鱼、社交工程和网络诈骗。而更加隐私友好的SameSite cookie功能，能够从源头上有效的阻止此种攻击的发生，显著增强了授权网站的安全性。

和旧版本相比，先锋版默认禁止iframe嵌套页面下载，以保证沙盒的安全性。同时先锋版支持TLS 1.2，弃用了存在弱点的TLS 1.0和1.1，从网站加密通信层面大幅增强了安全性。




增加更多功能创新

效率、兼容性一个都不能少


对于广大政企客户而言，浏览器是日常办公中最常用的工具和操作入口，几乎所有的在线办公业务都需要通过浏览器来完成，因此，安全、效率、兼容性、便利性等等，可谓一个不能少。

凭借Chromium 87内核的新特性，奇安信可信浏览器先锋版在功能创新、友好性、性能等用户体验方面，都明显优于之前内核版本。


  • 首先是标签功能得到增强。先锋版支持更强大的标签分组功能，可以为打开的多个标签页进行分组和命名，同时群组支持移动、折叠和展开。同时它还支持更灵活的标签页预览，鼠标悬停到标签上直接查看页面的缩略图预览，更方便的标签页查找体验。
  • 其次是新版本优化了文件拖拽打开方式。通过默认在新标签页面中打开拖拽进入浏览器窗口的文件，从而避免误操作造成编辑中未保存文件被覆盖的损失。
  • 第三是优化了多标签情况下的功耗情况。先锋版通过关闭闲置标签中不必要的JavaScript计时器和跟踪器，从而显著降低功耗。

由于越来越多的业务应用开发需要基于浏览器环境，因此先锋版强化了开发者的支持。例如它增加了大量 Web animations API 特性支持，如动画替换、获取设置关键帧等，使复杂的动画效果开发更容易。同时，先锋版还支持全新的AVIF图像格式，在Web Workers中支持ES modules，支持Content indexing API等。

在开发者工具方面，先锋版得到进一步增强。它使用新的 Issues 标签修复网站问题，帮助减少控制台的通知疲劳和混乱，并在Inspect 模式中提供更多的辅助信息，如键盘是否可聚焦等。此外，它还具有样式窗格更新功能，支持revert关键字，其中CSS rgb色彩定义支持空格分隔，而不仅仅是逗号；CSS媒体查询支持 Aspect Ratio 长宽比属性等等。




全力支持信创产业发展

做信创应用生态的探路先锋


当前，在国产化替代的大趋势下，信创产业进入高速发展期，奇安信可信浏览器在多个方面，为支持信创产业的发展贡献力量。

  • 首先，奇安信可信浏览器大力支持国密算法。目前已经预置了国密根证书、支持国密双向认证、国密算法自动识别、切换能力，并且独家支持国密标识。

  • 其次，奇安信可信浏览器大力支持信创生态建设。为了方便研发和适配信创应用，奇安信浏览器提供了开发者工具、应用适配性检测工具、Web应用开发规范、开发指南以及常见问题解答文档，帮助开发商、集成商以及客户来更快的完成产品研发和适配部署工作。而在今年8月的北京网络安全大会(BCS 2020)上,奇安信正式提出了基于浏览器建立信创应用生态的解决方案，推进信创应用生态的建设。


据悉，奇安信可信浏览器已经和国内主流的信创生态企业建立了全面深入合作，并在产品适配、方案融合、项目合作等方面开展了诸多落地案例，内容包含了芯片制造、操作系统、基础软件、应用软件、软硬件集成等信创全生态的多个领域。


目前，信创浏览器作为信创平台最重要的核心应用，已成为众多浏览器厂商的兵家必争之地。奇安信可信浏览器从今年4月2日推出之初，就迅速成为信创浏览器的引领者。其中，首个版本就面向信创全生态，全面兼容国产CPU硬件平台和操作系统，为政企用户、开发者、运维人员打造了一款安全、可信、全平台、一体化的政企业务承载平台。
7月8日，奇安信率先发布了基于全球最新Chromium 83内核的可信浏览器，让信创浏览器实现全球同步更新，达到国内领先、国际一流的水平。8月11日，当Chromium内核曝出CSP 0day漏洞后，奇安信浏览器团队第一时间启动漏洞应急响应机制，率先在24小时内完成漏洞修复，并免费为客户提供漏洞修复补丁。
而此次发布的首款基于87内核的信创专享先锋版，不仅巩固了奇安信可信浏览器在信创领域的引领者地位，更助力信创应用快速迈上新的台阶。
