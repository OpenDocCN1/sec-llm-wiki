# 奇安信代码卫士帮助微软修复严重漏洞 获官方致谢

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247500706&idx=2&sn=6a1041f9ed20d8359d8750db111cc43e&chksm=fb76e5a6cc016cb0cda77be17da23521aad9f467d7aedff474377b52b6d4b78c8bc1323416aa&scene=126&sessionid=1681373636#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247500706&idx=2&sn=6a1041f9ed20d8359d8750db111cc43e&chksm=fb76e5a6cc016cb0cda77be17da23521aad9f467d7aedff474377b52b6d4b78c8bc1323416aa&scene=126&sessionid=1681373636#rd)

近日，奇安信代码安全实验室研究员为微软发现一个“严重”级别的漏洞(CVE-2020-1153)，第一时间向微软报告并协助其修复漏洞。

  

北京时间2020年5月13日，微软官方发布了补丁更新公告以及致谢公告，公开致谢奇安信代码安全实验室研究人员并颁发奖金。

  
![](../Images/05a66ba182199937bf15259e66bdd754.png)

图 微软官方致谢  

  

据介绍，该漏洞名称为CVE-2020-1153 – 微软 Graphics Components 远程代码执行漏洞，属于“严重”级别。该漏洞是由微软 Graphics Components 不正确地处理内存对象造成的一个远程代码执行漏洞，成功利用该漏洞的攻击者，能够在目标系统上执行任意代码。  
目前，微软已解决这个漏洞问题，同时微软提醒用户，应尽快予以更新。![](../Images/3cd5713f2d2dfe44821577ab9777af20.png)  
  
就在近1个月之前，即4月15日，奇安信代码安全实验室因帮助微软发现了五个高危漏洞，获得微软官方致谢公告和颁发奖金。其中一个为“严重”级别（CVE-2020-0938），其余四个为“重要”级别CVE-2020-0957、CVE-2020-0958、CVE-2020-0993和CVE-2020-1005）。同一天，奇安信代码安全实验室还因帮助全球第二大软件巨头Oracle发现漏洞，获得后者的公开致谢。  
  

  

  

**▶奇安信代码安全实验室**是奇安信代码卫士的研究团队，专门从事源代码、二进制漏洞挖掘和分析，主要研究方向包括Windows / Linux / MacOS 操作系统、应用软件、开源软件、网络设备、IoT设备等。该实验室具有业内领先的漏洞挖掘和研究能力，持续支撑国家级漏洞平台的技术工作，多次向国家信息安全漏洞库（CNNVD）和国家信息安全漏洞共享平台（CNVD）报送原创通用型漏洞信息。截至目前，奇安信代码安全实验室帮助谷歌、微软、Cisco、Juniper、Adobe、苹果、VMware、阿里云、华为、施耐德等大型厂商的产品发现了100多个安全漏洞，并多次获得官方致谢和奖金。  
**▶奇安信代码卫士**团队推出的奇安信代码卫士支持Windows、Linux、Android、Apple iOS、IBM AIX等平台上的源代码安全分析，涵盖C、C++、Objective-C、C#、Java、Java(Android)、JavaScript、PHP、Swift、Go、Python、Cobol、TSQL、PL/SQL、JSP、ASPX、Node.js、Vue.js、React.js、HTML、XML等多种编程语言，可检测1300多种源代码安全缺陷。同时，奇安信代码卫士还支持国标“应用软件安全编程指南”、国军标GJB 8114-2013、国军标 GJB 5369-2005、通讯行业标准“联网软件安全编程规范”等相关规范或标准的合规检测。
