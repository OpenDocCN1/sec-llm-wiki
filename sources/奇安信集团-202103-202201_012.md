# 奇安信荣获2021中国电子“i+”创新创业大赛两项大奖

**12月29日，2021第五届中国电子“i+”创新创业大赛奖项揭晓。奇安信“PKS体系之漏洞攻击防护关键技术（天狗）的研发与应用”和“基于PKS的大数据环境零信任动态授信体系”两个项目，分获一等奖和三等奖。**

  

![](../Images/fd1cfebbc9c935b55e0073b264f8077a.png)

2021年，第五届中国电子“i+”创新创业大赛以“共建共享PKS生态 全面赋能数字化转型”为主题，并设置了海南（PKS生态）、武汉（网络安全创新大赛）和上海（金融数字化）分站赛。奇安信集团的两个项目在海南站、武汉站分别以“特殊贡献奖”和“一等奖”的优异成绩进入总决赛，并最终通过总决赛路演和导师提问等环节的激烈比拼，一举获得两大奖项。

  

PKS体系正在成为我国自主安全绿色计算信息系统的核心底座。奇安信作为新一代网络安全领军者，以安全人才和安全技术双向加持PKS体系，通过过程安全和本质安全的深度融合打造以国家安全为目标的新一代网络安全防护体系。![](../Images/feb27a576eba1f8b29323384f37f3eb2.png)

**由奇安信集团自主研发的新一代安全技术“天狗”，承担了打造PKS安全底座的重任。**“天狗”是基于内存指令调用序列的检测技术，在攻击发生时，能够在内存指令层进行安全检测，从而有效抵御0day漏洞攻击，对未知漏洞攻击具有极强的发现效果。依托“天狗”技术从根本上支撑了PKS体系应用生态对漏洞攻击发现的技术实现。

  

“天狗”具备完全自主的知识产权，已申请相关发明专利152项，已授权专利超30个，并已在各领域头部客户中进行了推广和应用，帮助相关政企机构及时发现高危安全事件。

  
![](../Images/a4353459f0456293432ea0f123655e3d.png)

**打造安全可信框架下的中国特色零信任实践。**经过近两年的技术研究和产品迭代研制，奇安信打造了国内一流、国际领先的基于PKS的零信任动态授信体系化产品，支持模块化构建零信任动态授信平台，结合基础架构和授信体系一体化运行，基于人工智能的信任评估模型训练技术，实施持续信任评估和动态访问控制，适用于多种大型应用场景，确保PKS内生安全体系管控能力在网络安全和业务安全的全面覆盖。

  

同时，由奇安信牵头发起的T/CIITA 117-2021《信息安全技术零信任参考架构》于近日正式发布，该标准在编制过程中亦充分结合了零信任在PKS技术体系中的实践应用，并将于2022年2月1日起正式实施。  
据悉，中国电子“i+”创新创业大赛自2017年推出以来，累计在北京、上海、重庆、深圳等地举办25场分赛和决赛，组织1200个项目参赛，评选出84个获奖项目。“i+”大赛自投和引入社会资本投资超5亿元，逐步完善固化形成了“赛事择优，资金孵化”的模式，已逐步成为具有全国影响力的双创大赛。
