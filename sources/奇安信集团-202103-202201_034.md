# PKS生态大会：奇安信携手20家企业共建安全大生态

12月24日，PKS安全先进计算2021生态大会“安全先进绿色计算+安全实践”生态专场在奇安信安全中心举办。在奇安信集团董事长齐向东以及50多家合作企业负责人的共同见证下，奇安信集团副总裁陈华平代表奇安信与20家企业进行战略合作签约，结成战略合作伙伴。

  

  
  
  
  
![](../Images/ffbb04822348e42c77f3660c65474c76.png)  

  

  

**此次签约分两轮进行**

  
  

  

  

首轮签约

![](../Images/9bfc2707fcc02f0f1c91648ecc1ded3f.png)![](../Images/65508772344cf19ae675842eccf23675.png)![](../Images/52c3c6f520d3f86a1ce2febedd2b4e44.png)

**首轮围绕PKS体系，保障底层构架的本质安全，**此轮签约的企业分别为：飞腾、麒麟软件、华控清交、派拉软件、芯盾时代、清软融安、联成科技、缔安科技、虎符网络、安御道合。  

  

![](../Images/924fe901daa4f9b48830ee9f80db273d.png)

  

  

二轮签约

![](../Images/9bfc2707fcc02f0f1c91648ecc1ded3f.png)![](../Images/cd85d3c9b0811c693acff46455ce09b1.png)![](../Images/52c3c6f520d3f86a1ce2febedd2b4e44.png)

**第二轮围绕行业应用场景，构建深度融合的行业安全解决方案，共同为数字经济发展保驾护航，**此轮签约的企业分别为：用友网络、澜起科技、网宿科技、二六三网络通信、大唐高鸿信安、致远互联、中电开发、思贝克集团、诺映科技、罗格科技。

  

2021年，奇安信已经与数百家行业、领域头部企业签属战略合作协议，共同推动行业信息化的安全解决方案开发和建设，服务于各行各业的客户。  
  
《网络安全产业高质量发展三年行动计划（2021-2023年）》明确提出了“生态培育”的发展目标。作为新一代网络安全领军者，**奇安信将定位生态的布局者、融合发展的推动者、业务创新的探索者，发布以“融合内生·共筑安全”为思想的“领航者计划”—— 3543策略：**坚持3个同步，输出5种能力，聚合4类伙伴，共建3大平台。链接1000家生态伙伴，落地100种场景解决方案，满足10000个项目需求，带动100亿产值。  

![](../Images/95b66ebd05277d455e345a08f8dc8b12.png)

  

  

奇安信（股票代码688561.SH）成立于2014年，是2022年冬奥会和冬残奥会网络安全服务与杀毒软件的官方赞助商。一直专注于网络空间安全市场，向政府、企业用户提供新一代企业级网络安全产品和服务，已发展成为国内领先的基于大数据、人工智能和安全运营技术的网络安全供应商，安全技术已应用于金融科技、智慧教育、智慧医疗等多个行业场景。
