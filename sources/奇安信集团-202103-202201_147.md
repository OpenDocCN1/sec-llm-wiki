# 再创升级记录！奇安信可信浏览器率先升级至Chromium97内核

追求交互、效率、安全等方面的领先体验，是广大政企用户选择浏览器的重要标准。10月19日，奇安信可信浏览器先锋版率先升级至Chromium97内核，再次实现了国产浏览器与业界最前沿Chromium内核的紧密同步。

新升级的可信浏览器不仅在性能、安全性等层面具有重量级更新，更持续深化开发者与信创生态支持工作，为政企用户提供极致流畅、安全可靠的使用体验。

  
  
  

  

![](../Images/a313ce0252102f07a65ac4cdbad97d77.png)

  

**产品力全面领先！面向政企用户和开发者多维升级**

  

  

此次可信浏览器升级至Chromium97内核，重点关注政企用户和开发者的使用体验，更新内容主要集中在功能体验、产品性能和安全性三个维度。值得一提的是，新版本更新了最新的V8引擎，大大提升脚本解析性能。同时，可信浏览器新版支持全新图形API，使得图形和多媒体内容方面性能提升25%，也为开发者提供了更多的图形接口。并通过限制子资源的私有网络请求以保护上下文，来加强浏览器的安全性。  
  
在功能及特性上，可信浏览器面向开发者新增网络编码器、虚拟键盘等多个API。其中，编解码器 API将更好地支持新兴应用程序，例如延迟敏感的游戏流、客户端效果或转码以及可填充媒体容器支持，而不会增加JavaScript或WebAssembly编解码器实现的网络和 CPU 成本，从而为开发者消除这些缺陷。  
而VirtualKeyboard接口具有控制何时显示或隐藏虚拟键盘的方法和属性，开发人员可以通过inputmode属性控制虚拟键盘的显示形状，但对虚拟键盘何时显示或隐藏的控制有限；新增的EyeDropper API，可用于构建自定义的颜色选择器；URLPattern API则提供操作系统支持，用于将URL与提供的模式相匹配。  
可信浏览器还更新了WebGPU性能，特别是 Direct3D 12、Metal 和 Vulkan，用于在图形处理单元 (GPU) 上执行渲染和计算操作。同时，它还公开了一个TaskController接口，可以动态取消任务并更改其优先级。  
此外，升级后的CSS性能可以保留3D和透视属性现在与规范对齐，并允许子元素参与父元素的3D场景，透视属性将透视变换应用于子元素。在JavaScript性能层面，新版本浏览器包含了V8 JavaScript 引擎的 9.4 版，能够显著提升脚本解析性能。

  

**升级速度再次刷新！坚实国内政企浏览器领军地位**

  

  

保持内核版本的稳定更新，是浏览器保证安全性、稳定性、性能、开发者等技术先进性的重要工作，也是衡量研发能力的重要指标。据了解，在过去一年左右的时间里，可信浏览器内核升级次数高达5次，平均3个月即有一次内核更新，本次内核更新时间距离上次仅间隔3个月，继续刷新着内核升级速度记录。正是凭借其稳定的内核升级速度，奇安信可信浏览器始终保持着国内政企浏览器赛道的技术领军地位。  
  
一直以来，奇安信可信浏览器以“多方兼容、统一管理、内生安全”为设计理念，提供针对业务系统的兼容能力，针对浏览器客户端的统一配置管理、统一行为管理和统一安全管理能力，为政企用户提供专业的业务承载平台。  
在信创领域，奇安信可信浏览器已与国内主流信创生态企业建立了深入合作，全面兼容各类CPU架构、国产操作系统以及打印机、邮件系统、OA系统等办公软硬件，全面支持信创生态，成为信创领域浏览器的首要选择。  
此外，奇安信可信浏览器已经被广泛应用于党政、金融、石油、电力、电信、交通、航空航天、医院、教育等行业，以及外交部、教育部、科技部、工业和信息化部等26个国家部委，成为千万终端的业务访问入口，并获得了用户的一致好评。

  

  
  
  

目前，麒麟应用商店已上架基于97内核的奇安信可信浏览器先锋版，供用户下载体验。
