# 50支院校战队云端对决 第五届“蓝帽杯”决赛圆满完赛

8月24日，第五届“蓝帽杯”全国大学生网络安全技能大赛决赛云端开赛，从半决赛四大赛区中突围的50支战队云端“会师”，在蓝信平台烽火台防作弊系统的监考下，经过6小时不间断比拼，顺利完成了比赛。

  

  
  
  
  
![](../Images/600bbe0d833dbf3fbd31857bfd4fafca.png)  

  

决赛采用CTF夺旗模式，参赛队伍通过互联网在线解题，题目分为 Web 漏洞与渗透(Web)，软件逆向 (Reverse Engineering)，二进制漏洞挖掘和利用(Pwn)，密码（Crypto）学与杂项（Misc）。每种类型的题有不同的分值，参赛队通过获得 flag 从而得到对应的分值，最终以各战队得分高低直接分出胜负。  
上午10时，比赛正式开始，选手们向10道赛题分头发起冲击。10:45，来自南京邮电大学的An4t0le战队率先解开crack point题目，顺利拿下“一血”；之后，又在13:03完成了另一道题目的破解；而北京邮电大学的ylly战队在整场比赛中拿到两个“一血”，天璇Merak战队更是完成了8道题目的破解，一举拿下高分。  
长达6小时的不间断比赛，绝对是体力与脑力的双重考验。新疆警察学院的S1gMa战队，在赛程过半时，成功破解Imagecheck题目，率先拿下Web题型的“一血”。截至14:18，北京航空航天大学的or4nge战队解开了第十题，本次决赛题目全部成功破解，而该题目的破解者文滔，在比赛开始79分钟时，就已完成abc题目的破解，一己之力拿下两个“一血”。

  

  
  
  
  
![](../Images/ec3f6e4598e6ddb03e8dbb2cf73d4f69.png)  
  

最终，中国人民公安大学的虎皮凤爪战队，新疆警察学院的S1gMa战队，北京邮电大学的天璇Merak、啥也不队、ylly3支战队，北京航空航天大学的or4nge战队，杭州电子科技大学的绝望的肉战队，中国人民公安大学、江苏科技大学、南京邮电大学联合战队nepnep，成都信息工程大学的曾某人队，浙江师范大学行知学院的DoK0wn战队，广州航海学院的G2mtu战队以及南京邮电大学的An4t0le战队，凭借优秀的表现名列前茅。在通过裁判组的统计和审核后，将公布最终排名和具体获奖情况。

  

  
  
  
  
![](../Images/64049678088186ba1a625e7b3d94892c.png)  

  

学生的出色表现离不开带队教师的辛勤指导。在蓝帽杯5周年之际，面向多年带队参赛的战队教师发起了“5周年MVP教师奖”评选。最终来自山东警察学院的张璇老师，来自江苏警官学院的刘家银老师，来自湖南警察学院的苏欣老师，来自铁道警察学院的孟彩霞老师，和来自南京森林警察学院的吴育宝老师获得了这一荣誉。

第五届“蓝帽杯”由公安部网络安全保卫局指导，中国人民公安大学、北京理工大学和奇安信科技集团股份有限公司联合主办。在报名阶段就吸引了全国各高校的1000支战队、2520名学生报名，并有200支战队进入全国四地同时开赛的半决赛，最终决选出50支战队挺进决赛，也是历届蓝帽杯大赛参赛人员规模最多的一次。
