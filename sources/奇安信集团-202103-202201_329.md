# 速度最高提升23%！奇安信可信浏览器率先更新至Chromium93内核

打开网页更快、运行应用更流畅……浏览器用户对速度的追求永无止境，内核的升级不会停止。为了让广大政企用户享受到极速、稳定的巅峰体验，**7月6日，奇安信可信浏览器先锋版再次升级，宣布率先更新至Chromium93内核。**

![](../Images/3126087547d3a931829a130351ac91d2.png)![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)  
  
![](../Images/257d24d39353419eed8ef10a5defe007.png)  
  
新版在浏览器功能、产品性能及安全能力等方面均有显著提升，正是凭借其升级速度和产品实力的领先优势，奇安信可信浏览器始终保持着国内政企浏览器赛道的领军地位。  

  

**浏览器速度最高提升23%**

**产品性能与安全性再进一阶**

  

  

从Chromium83内核到Chromium93内核，支撑每一次内核领先升级的，不仅是奇安信可信浏览器的技术实力，也是对产品及使用体验的不断打磨。  
  

**在浏览器性能层面，**新版内核优化了V8 JavaScript编译器，通过全新的Sparkplug编译器和short builtins调用机制，执行和优化 JavaScript 代码之间的空白，优化浏览器使用生成代码的过程，最大程度优化浏览器整体性能，最终为政企用户带来最高23%的速度提升。

与此同时，可信浏览器通过对全新AV1开源视频编码器的技术支持，大幅度减少了高清视频的资源占用。并增加了自动冻结闲置标签组功能，通过降低开启但未使用标签的CPU和内存资源使用量，以提升浏览器的性能、减少电量消耗。

  

**在安全层面，**此次新版内核更新了目前已知的安全补丁，其中包括影响范围较广、后果较为严重的引擎远程代码执行漏洞(CVE-2021-30551)的安全补丁，浏览器安全性保持领先。

  

此外，本次升级还带来了窗口重命名、记住窗口配置和支持桌面应用程序对剪贴板进行只读访问等诸多新功能。新版本浏览器将默认启用WebTransport网络传输协议框架和WebAssembly SIMD，在追求极致的产品性能与安全能力之余，为政企用户带来**更加高效**的使用体验。

****全平台兼容适配****

****可信浏览器助力信创工程持续落地****

  

  

浏览器作为政企业务的重要承载平台，是不可缺少的基础应用软件。此前，奇安信“金融行业信创过渡期终端安全建设方案”成功入选工信部“2020年度信息技术应用创新解决方案”，并获评单项创新奖。其中，奇安信可信浏览器为金融客户信创工程的持续落地提供了有效助力。  

  

![](../Images/bbcf45ac9d800a4f141863d01e27f446.png)

  

在该方案中，可信浏览器为客户提供了业务迁移时的Windows设备和国产化设备统一访问和一致体验，并为金融客户提供了信创过渡期间的业务适配解决方案。同时，借助奇安信可信浏览器的安全联动能力，客户还能获得业务系统文件上传下载安全扫描能力，避免恶意代码在业务内网扩散传播。  
  
在持续助力信创生态发展上，奇安信响应龙芯述求，与龙芯研发团队合作，第一时间完成了包括奇安信可信浏览器在内的多款奇安信产品与龙芯全新LoongArch指令集芯片 - 3A5000的兼容适配，并获得了龙芯架构兼容互认证书。此外，奇安信可信浏览器也与麒麟软件合作，率先完成与银河麒麟桌面操作系统（海思麒麟版）V10的兼容性测试，并获得了麒麟软件NeoCertify认证证书，不断深化信创平台兼容性。  
值得一提的是，继6月24日微软正式发布Windows11后，奇安信也第一时间基于该平台对可信浏览器进行了测试验证。经过验证，奇安信可信浏览器可完美兼容适配Windows11。

  

![](../Images/bf27c76c8f56e4f2fe5bce05d1ae2010.png)
