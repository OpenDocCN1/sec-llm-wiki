DNS劫持


Domain Name System Hijacking


先讲一个发生在网安图书馆中一则“偷梁换柱”的故事——

您好，我想找《新话网安》。

书的编码是5KL26，5层K区L架上的第26本书，你去找吧。

（满脸困惑）管理员这编码不对啊，5KL26是《旧话网安》，旁边5KL27才是《新话网安》。

诶，是谁这么坏把编码库的编码给我偷偷调换了！

作为一个普通人，书名我们大体记得住，但在图书馆如此庞大的书籍体量下，书的具体位置还是需要编码标注才更方便查找；此时图书管理员就是给小虎提供书籍编码，从书名到找到书的中间人。


同样，DNS（Domain Name System）域名系统作为“IP管理员”就起到了相似作用。相较一大串数字，我们更倾向于记代号，而计算机却喜欢用数字如IP地址来标注。当我们浏览网页时，DNS就帮助我们进行从域名到IP地址的转化。


但此时，如果DNS被人动了手脚，本来A网站的IP是A，B网站的IP是B，但你输入A网站域名后DNS却给你B的IP，你是不是就访问到别的网站去了？这便实现了偷梁换柱，也就是“DNS劫持”。

是不是不好懂？看图！

随着互联网的快速发展，DNS服务已经成为最重要的服务之一，保证DNS安全，对于创建稳定的互联网环境起着关键的作用。



美国头部信息服务公司NeuStar国际安理会于2021年初的一项调查中发现，在疫情更多人选择线上购物的情况下，超过3/4的安全专家预计DNS攻击将随之增加，且在对全球顶级电商和购物领域研究后发现，超过70％的拼写错误域名归第三方所有，其中至少有40%显示出恶意企图。
