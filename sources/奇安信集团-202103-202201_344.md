# “庆祝建党100周年 筑牢网络安全防线”—— 北京市保障房中心、奇安信集团主题党日联建

6月25日下午，北京市保障房中心信息中心与奇安信科技集团，在奇安信安全中心联袂组织了**“庆祝建党100周年 筑牢网络安全防线”**主题党日活动。

![](../Images/bc50b4e9c296b694c026e59a759d6df1.png)

  

  
  
![](../Images/0ece2d48ae58effdee19f7becf54912c.png)  
  

  

  
  
  
  
  
  
  

  

此次主题活动意在加强双方各岗位人员对网络安全新趋势及新挑战的认知，树立正确的网络安全观，加强信息基础设施网络安全防护，加强网络安全信息统筹机制、手段、平台建设，加强网络安全事件应急指挥能力建设，为保障房中心提供强有力的网络安全支撑。

  

  
  
![](../Images/cc95e2f282ee705ee951e1a68a85bed5.png)  
  

  

  
  
  
  
  
  
  

  

随着十四五规划、数字化转型和5G的高速发展，全球网络互联互通已逐步实现，网络安全问题也上升到国家高度，网络安全问题日益凸显。奇安信集团党委以“网络安全新形势下的思考”为核心，与北京市保障房中心党委进行了深入探讨，其作为北京市政府、国资委重点企业，对网络安全的重视程度要随着信息化发展不断提升。

  

![](../Images/e2bb1d687456ece70f361ee1b8a5483e.png)![](../Images/662e28d41b1312f3a6b899da340bff7b.png)  

  

  
  
  
  
  
  
  

  

此次“庆祝建党100周年 筑牢网络安全防线”活动还参观了奇安信应急响应中心和奇安信安全中心展厅，二十余名党员同志和业务骨干观摩了前沿网络安全技术和产品演示并听取了网络安全专家针对不同场景、各种未知网络威胁的分析讲解。参观人员在不时驻足观察、咨询交流、认真学习，直观认识到了包括工业互联网在内的网络空间安全的重要性。

  

![](../Images/a288d81ca768d11683a159c60930f8a6.png)![](../Images/227ba9633a2877007af960785ad9ab52.png)  

  

![](../Images/6943818fdb39dd36979d80d828fd3ee0.png)

通过本次参观，全体人员更加牢固明确了“网络生活共享、网络安全同担”的责任意识，携手并肩，共同维护网络安全，为营造清朗健康的网络安全环境贡献力量。
