# 开班啦！2021年信息安全专业暑期教师研修班开启报名

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247529056&idx=3&sn=c2e9ee5c7b31b39ff82b9c2d513fc5f2&chksm=fb765464cc01dd72a27b6a54ff58ffa321aa2f21897a746a60ef31ffa68ceb37860a932e3948&scene=126&sessionid=1681373480#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247529056&idx=3&sn=c2e9ee5c7b31b39ff82b9c2d513fc5f2&chksm=fb765464cc01dd72a27b6a54ff58ffa321aa2f21897a746a60ef31ffa68ceb37860a932e3948&scene=126&sessionid=1681373480#rd)

为落实《教育部关于学习宣传贯彻习近平总书记重要指示和全国职业教育大会精神的通知》，深化改革，进一步深化课程教材建设与教法改革，进一步细化“双师型”教师队伍建设举措。加强师资队伍建设，改革教师培养培训制度，构建职前职后一体化、校企双主体的教师培养培训体系，特举办此次** 2021 年信息安全专业暑期教师研修班**。

  

  

本次暑期教师研修班，由**重庆电子工程职业学院**联合**奇安信集团**制定了有针对性的网络安全师资研修计划，培训内容主要为“常见 Web 安全漏洞”的分析与实践，为教师提供网络安全产业知识、技能和经验，以培养和积累网络安全领域教学能力，为培养网络安全应用和技术型人才不断赋能。  

  

![](../Images/9ac7286cbaae1b4ca30c8a752a09c482.png)

本次培训将持续 5+2 天（**2 天体验世界技能大赛网络安全集训基地技能平台**），培训考核合格颁发师资培训课程结业证书和**中国通信工业协会教育分会“Web 安全工程师证书”**。请各位参加培训的老师填写报名回执表完成报名。
