# 一屏看百馆 一码听百年——“红色云展厅”在人民网上线

**人民网北京6月15日电** 今天上午，“红色云展厅”上线仪式在人民网举行。今年是中国共产党成立100周年。为讲好党的故事、革命的故事、根据地的故事、英雄和烈士的故事，**人民网、中国传媒大学、奇安信集团联合全国百家红色展馆、数十家省区市广播电视台**，共同推出“红色云展厅”公益展播活动。

![](../Images/6e68b975b3c8c8fa5c839249db2990be.png)

  

“红色云展厅”旨在通过5G、云技术将各地红色纪念馆、陈列馆、展示馆、博物馆等党建党史内容数字化，形成“红色资源库”，献礼建党百年。观众在人民网各渠道入口，可实现一屏看遍全国百家红色展馆；在展馆现场，可通过扫码收听专业讲解。

  

![](../Images/8d27f4592be7fd59c5c650a372430b63.png)

*中国传媒大学党委书记、校长廖祥忠(左)，人民网党委书记、董事长、总裁叶蓁蓁(中)，奇安信集团党委书记、董事长齐向东(右)共同宣布“红色云展厅”正式上线。人民网 马天翼摄*

  
  
  
  
  
  
  

  

“红色云展厅”是学习党史的新阵地、国际传播的新载体、内容科技的新形式、智慧党建的新应用。人民网充分发挥政治优势、传播优势和策划联动能力，积极推动内容科技与党建党史深度融合，为各类红色场馆提供内容数字化服务。围绕“红色云展厅”建设，人民日报社主管、依托人民网建设的“传播内容认知国家重点实验室”将提供基于人工智能的党史知识图谱技术支持，为我国相关领域科研工作提供关键数据支撑。人民网将在各地打造的“智慧党建体验中心”，既是传承红色基因的内容科技应用示范基地，也是“红色云展厅”线下空间的具体呈现。首个智慧党建体验中心，已经在北大科技园揭幕运行。  
  
  
  
  
  
  
  

  

**人民网党委书记、董事长、总裁叶蓁蓁**在致辞中表示，目前上线的是“红色云展厅”一期，欢迎更多红色展馆加入“红色云展厅”，欢迎更多兄弟媒体参与合作。

  

🎤

**中国传媒大学党委书记、校长廖祥忠**在讲话中指出，“红色云展厅”是利用现代科技建构可知、可感的中华整体精神家园的重要实践，是推动红色文化创造性转化和创新性发展的切实举措。中国传媒大学尝试运用现代视听技术、传播技术、云存储和云计算技术，深挖红色文化资源潜力，推动革命纪念馆的数字化转型，将各地红色资源汇聚至云端，形成可及时升级、可持续传播的“红色资源库”。

  

🎤

**奇安信集团党委书记、董事长齐向东**在致辞中表示，“红色云展厅”是党建与融媒体、云技术、云展厅技术与数字化深度融合一次创新尝试。“红色云展厅”将依托奇安信云媒资、云展厅技术，以公益性方式为有条件的线下红色展厅进行升级；还将分发、推送适配性更强、内容更为丰富的党史数字音频包、党史视频播放包、党史学习及党性教育音视频课等，增强展厅视听效果。

  

![](../Images/ebc9adea1e89b757c1c81ad05b0e957e.png)  
  
  
  
  
  
  

  

**“红色云展厅”项目，是内容科技运用于党建党史领域的最新案例。**在启动仪式上，人民网监事会主席、人民网研究院院长唐维红发布了年度报告《2020内容科技发展与前瞻》。报告记录了2020年内容科技新发展、产业新应用、认知新进展，梳理了内容科技在新闻媒体、社会管理与公共服务以及行业应用方面的15个典型案例，并对内容科技未来发展提出了五大展望。  
 **“红色云展厅”项目对全国31个省区市红色纪念馆、陈列馆、展示馆、博物馆等的红色资源进行了数字化加工、云上呈现。**山西综合广播、上海人民广播电台、江苏新闻广播、浙江之声、安徽之声、福建新闻广播、山东广播电视台、河南广播电视台、广东广播电视台、广西综合广播、四川广播电视台、贵州广播电视台综合广播、陕西新闻广播、陕视新闻、甘肃新闻综合广播、宁夏新闻广播、新疆广播电视台、青岛新闻综合广播、咸阳广播电视台、彬州融媒、华州融媒等多地广播电视台参与视频拍摄制作。在上线仪式上，全国各地的红色场馆发来祝福，共同庆祝项目上线，共贺党的百年华诞。在现场，来自香山革命纪念馆宣教员杨佳萍讲述了红色故事《大红灯笼照亮前行的路》。
