# 打造网安创投“四维”创新生态系统 2021安全创客汇报名开启

34家企业，超23亿融资额，过去五年进入安全创客汇前十名的50家企业受到了市场的高度认可，并在发展中实现了业务的大幅增长。

6月9日，2021安全创客汇召开第一次专家评审会，同时为评委会专家颁发聘书，开启了新一轮网络安全“千里马”的发掘，第六届安全创客汇参赛企业线上报名工作也同步开始。

![](../Images/a69aa54186689c17b148546ee2914da3.png)

  

  
![](../Images/b1173373bbe0eb26e860bd11dd4fdc9e.png)  

  

“企业发展‘始于创新，成于资本’，资本能为企业的创新发展提供肥沃的土壤。但目前我国的网络安全初创企业，仍然面临着融资难、生存难等挑战。”**奇安信集团董事长、BCS北京网络安全大会主席齐向东**在致辞中表示，网络安全行业面临着采购链条长、回款周期慢等特点，企业往往面临较大的资金压力，进而可能影响技术、产品和服务的创新。

但作为风口上的行业，中外多家研究机构已预测，未来十年，整个网络安全产业会保持25%以上的增长，网络安全产业将迎来发展高潮，网络安全市场将迎来万亿规模。

“奇安信坚持举办安全创客汇，就是希望在创新创业企业和专业投资机构间搭建起桥梁，让网络安全产业和优质资本形成良性互动，推动整个网络安全产业更上一层楼。”

  

  
  
![](../Images/82e11be9e410708bc088f73e7ee807b5.png)  
  

  

2021安全创客汇由北京网络安全大会、奇安信科技集团股份有限公司、奇安（北京）投资管理有限公司联合主办。自2016年创办以来，安全创客汇已挖掘和扶植了一批国内外优秀的安全初创企业，包括芯盾时代、天空卫士、威努特、众享比特、ClearClouds(美国)、HoloNet(美国)等明星初创公司，并从最初聚焦网络安全领域的专业创投平台，成长为涵盖创客明星赛、创客沙龙、创业培训等多主题、多活动、多服务的创新生态平台，成为网络安全领域创投平台的标杆及引领者。

  

  
  
![](../Images/63b6749d0c4d7c97e107a51a8b4d5858.png)  
  

  

目前，安全创客汇已经构建了面向政府、大企业、投资人、创业团队的“四维”创新生态系统，由独立创新到协同创新，打造一个能获取高价值信息及有效合作机会、实现资源全面对接、知识的高阶聚合、商业的高度互信的生态平台。

  

据悉，**本届安全创客汇新增了“返场”环节**：以往五届安全创客汇十强企业，可报名参与专家评委或议题分享环节；以往五届安全创客汇非十强企业，依照首次参加条件返场。

  

经过招募和百强资格赛、南北明星赛环节后，最终入围企业将于2021年北京网络安全大会(BCS2021)上举行的安全创客汇-明星赛决赛中，决出年度明星赛冠军企业。

  
  
  

【报名时间】

  
  

2021年6月9日~6月30日
