# 19所广西职业院校骨干教师获首期“奇安信1+X网络安全应急响应职业技能等级证书”

5月28日，为期5天的**“奇安信1+X网络安全应急响应职业技能等级证书”**师资培训研修班顺利结业，40名教师全部通过考核，获得“奇安信1+X职业技能等级培训教师”证书。

  

  
  

![](../Images/07e9f93f71114894b63ddc95ff8e1824.png)

  

  

本期“奇安信1+X网络安全应急响应职业技能等级证书”师资培训研修班，由南宁职业技术学院与北京电子科技职业学院主办，奇安信集团承办，来自南宁职业技术学院、柳州铁道职业技术学院、广西职业技术学院等19个广西职业院校单位，共计40名骨干教师人员参加培训。  

  

作为网络安全领军企业，奇安信也是目前同时在研究型人才培养、应用型人才培养、继续教育、特殊人才培养、国家安全意识教育提供完整解决方案的安全企业。

奇安信教育行业部负责人施洪春表示，在应用型人才培养领域，奇安信集团能够提供专业建设所需要的人才培养方案、教材、大纲、ppt、实验环境、师资培养等一整套教学资源；在产教融合上能够提供企业生态群，形成产、学、研、用的完整闭环。

  

  
  

![](../Images/18b55bba61be9f1a29de9b407f8bb482.png)

  

  

目前，奇安信已经与近百所高校建立了校企合作关系，其中与30多所学校进行了专业或者学院共建，输送一批优秀毕业生到了奇安信生态就业。2020年，奇安信工程师学院在北京电子科技职业学院成立，学院以网络信息安全方向的专门人才培养、网络安全认证培训中心和网络安全技术社会服务为主要抓手，全面推进校企合作、产教融合水平，促进教育链、人才链与产业链、创新链有机衔接。

  

  
  

![](../Images/bad78a52321639ccfa7a5a3ee8771ab2.png)

  

  

**北京电子科技职业学院电信工程学院副院长于京**表示，北京电子科技职业学院与奇安信集团是战略合作伙伴，此次研修班是1+X网络安全应急响应举办的第一次师资培训，希望通过培训架起友谊的桥梁，在人才培养的道路上共同发展。

  

🎤

**奇安信教育产品部负责人林雪纲**博士介绍，针对新时期的职业教育和产教融合特点，通过以奇安信集团为代表的行业岗位梳理分析，把握未来人才需求对应的学校专业培养目标、集团内部产教融合进行教学资源开发、以“虎符名师堂”为核心实施的各类教育服务交付赋能，奇安信有信心和高校一起实现“教育快一步”。

![](../Images/de02f71f90ef9d1b9322c47416bd2e14.png "读书分割线")  

作为国家职业教育制度建设的一项基本制度，**1+X证书制度**把学历证书与职业技能等级证书结合起来，体现了职业教育作为一种类型教育的重要特征，有利于推进产教融合、校企合作育人机制的不断丰富完善，是构建中国特色职业教育发展模式的一项重大制度创新。

  

2020年12月，教育部职业技术教育中心研究所公布了《1+X证书制度试点第四批职业教育培训评价组织和职业技能等级证书名单》，奇安信从602家申报单位中脱颖而出，获批为教育部1+X证书制度第四批职业教育培训评价组织，开展“网络安全应急响应”与“云安全运营服务”两个职业技能等级证书试点工作。
