# 国际权威咨询机构最新报告：奇安信零信任位列“GROWTH STAGE”榜单

日前，国际权威咨询机构Forrester发布《New Tech: Zero Trust Network Access, Q2 2021》（《New Tech:2021年第二季度零信任网络访问》）报告（以下简称《报告》）。《报告》概述了全球34家零信任厂商的发展前景，其中，**奇安信凭借领先的技术与产品实力，上榜 “GROWTH STAGE”零信任厂商榜单**。

  
  

**作为全球最具影响力的研究和咨询机构之一，Forrester**以其严谨的评价体系著称，为全球企业用户提供务实和具有前瞻性的建议。《报告》结合零信任的发展背景，从企业发展、员工发展和产品成熟度三个维度对厂商进行综合判定，并详细介绍了厂商的产品形态、重点行业及客户代表等信息。

  

**零信任**是2020年标志性的网络安全技术，在云计算、物联网、5G等各种新技术驱动下，企业业务上云颠覆了传统IT架构，尤其是在应对疫情的背景下，远程办公加速了网络安全边界瓦解，诸多安全挑战也随之而来。  

  

**《报告》认为，企业远程访问所面临的挑战有三**：

*   内网流量限制，即许多企业没有足够VPN带宽支持员工远程访问；

  

*   传统VPN许可失效；

  

*   远程办公人员缺少网络安全防护，这些挑战促使企业寻求更安全的解决方案，也就是零信任网络访问。

  

  

![](../Images/6943818fdb39dd36979d80d828fd3ee0.png)

自零信任理念提出以来，奇安信率先将其引入国内，并推出**零信任远程访问解决方案**，具备“以身份为基石、业务安全访问、持续信任评估、动态访问控制”四大关键能力，重点解决了边界易被攻破、全面网络开放、使用不稳定、扩容不平滑、管理不便捷等典型问题。

![](../Images/9d9d313f29fd893e3d25a10ddbe6bb86.png)**奇安信零信任远程访问解决方案**采用了最小化端口开放，并遵循动态最小权限原则，实现应用级细粒度的分级访问控制，能够有效收缩暴露面。在认证层面，奇安信基于数字身份边界，使用自适应多因子认证技术，并在基础上采用持续信任评估，根据风险等级调整访问权限，从而应对复杂的远程访问场景挑战。  

  

![](../Images/e489a44c0c18684d6bf86433a78fd831.png)  

一直以来，奇安信始终积极推进零信任落地与企业IT架构改革工作，凭借领先技术实力多次获得Gartner、数世咨询等国内外知名机构推荐。

前不久，奇安信零信任安全项目荣获我国智能科学技术最高奖“吴文俊人工智能科学技术奖” (企业技术创新工程项目)，得到了市场、业界的高度认可。

目前，奇安信零信任远程访问解决方案已经在部委、央企、金融等行业进行广泛应用，充分帮助构建组织“内生安全”能力，推动零信任理念在多个行业的实践落地。
