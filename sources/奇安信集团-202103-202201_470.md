# 第五届“蓝帽杯”大赛报名启动 实战化导向选拔顶尖网安人才

奥运标准选拔网络安全尖兵考核再次升级。第五届“蓝帽杯”全国大学生网络安全技能大赛于**4月7日**正式开启报名通道，并将于**4月29日“首都网络安全日”**举办初赛。

![](../Images/4614d0dec2ff5b2f35cd947b59ff5619.png)

  

据悉，本次比赛将在传统CTF赛制的基础上，加入电子取证、冬奥网络保障等实战安全场景，通过三方合作覆盖全国警院及高校，为公安系统选拔、输送更多网络安全实战型人才。

![](../Images/b2f6ed56a9885ac9aedbaf6ea142b13b.png)

  
  

****首次引入冬奥安保场景 实战锤炼精兵****

  
  

  

作为面向全国警院的高规格、强影响力的实战技能大赛，“蓝帽杯”被誉为未来网警的“奥运会”。四届以来，比赛规模、参赛队伍、选手数量逐年扩大，为公安系统培养、输送了大量顶尖人才，探索了网安人才培养的新模式。  
  
**第五届“蓝帽杯”**由公安部网络安全保卫局指导，中国公安大学、北京理工大学和奇安信科技集团股份有限公司联合主办。本次比赛将增加电子取证、冬奥网络安全保障场景，通过“以赛促学、以赛代练”的形式，并结合冬奥网络保障等实战化场景，让未来的网警人才提前接触一线业务、了解网络安全工作场景，提供实战能力。

  
  

****扩大“战区”吸纳英才 拓宽人才储备****

  
  

  

为容纳更多实战内容、覆盖更多参赛团队，第五届“蓝帽杯”将通过**初赛-半决赛-决赛**进行人才的逐层选拔：  
  

*   **初赛**采用国际上流行的CTF夺旗模式，于4月29日“首都网络安全日”举行，京津冀地区选手将于北京线下参赛，其他地区选手将于线上参赛，线上线下同步进行，并对比赛进行实时直播；
*   **线下半决赛，**首次拓展为北部、中西部、东部、南部四大赛区，覆盖更多警察院校及地方院校，并在比赛中加入电子取证、案件侦办等实际工作场景内容，以考核参赛队员的综合素质；
*   **线下决赛，**将采用AWD Plus（大规模攻防兼备赛）的竞赛模式，要求参赛战队兼任攻击和防御两种任务，综合考核参赛团队攻击、防御技术能力、即时策略。最终选拔出优胜战队，获得一等奖的战队遴选评定后可进入**第三届网鼎杯半决赛**，参与国家级高水平网络安全赛事。

  

  

  
  

**作为国内网络安全领军企业，奇安信积极履行社会责任，大力促进校企合作，推动网络安全人才培养，并与国内众多高校和单位展开合作，进行针对性的能力培训和提升。本次“蓝帽杯”，也将在继续与警察院校深入合作的同时，积极拓展地方院校的优秀网络安全人才，为国家网络安全行业储备更多人才。**
