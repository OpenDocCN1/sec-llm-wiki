# 奇安信打造国家首个网络安全领域原创技术策源地

**8月17日，奇安信集团打造网络安全领域原创技术策源地启动仪式，在BCS 2022大湾区网络安全峰会开幕式上举行。中国电子党组成员、副总经理陈锡明，奇安信集团董事长齐向东为“网络安全领域原创技术策源地”揭牌。**

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)

  

![](../Images/ff8de7fae76a550b6c5d131c97579621.png)

  
**奇安信集团与飞腾信息、麒麟软件、南网数字集团就共建网络安全领域原创技术策源地实验室进行签约。**  

![](../Images/70e2131e6279dc365dbd759806863289.png)

  
**在中国电子信息产业集团有限公司的指导下，奇安信科技集团股份有限公司将建设我国首个网络安全领域原创技术策源地。**网络安全领域原创技术策源地是基础性、紧迫性、前沿性、颠覆性的自主网络安全技术的研发源头，同时策源地是发挥新型举国体制优势、促进产学研用创新要素汇聚融合的组织平台，也是推动网络安全原创技术成果向涉及国计民生的重要行业推广应用的转化平台。  

奇安信集团首席战略官、副总裁刘勇在启动仪式发布了打造网络安全领域原创技术策源地的五大行动计划。

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)  

*   **一是技术攻关行动计划。**策源地第一阶段重点研发8大方向、45项技术。其中，基础性技术12项、紧迫性技术14项、前沿性技术18项、颠覆性技术1项，通过攻克一批网络安全领域的核心技术，构建自主的网络安全技术产品体系。

  

*   **二是开放创新行动计划。**策源地将采取开放研究、开放设施、联合创新等方式，向上下游企业、网络安全领域的科研院所，开放研究设施和研究数据，开展协同技术攻关，建设网络安全技术创新体系。

  

*   **三是产业培育行动计划。**策源地将进一步扩大大数据安全分析竞赛、安全创客汇的规模，积极对接国家科技计划成果路演行动，加强与各类创新基金的合作，加快建立完善技术转移服务体系。

  

*   **四是应用推广行动计划。**策源地将与有关行业和地方共同打造50个重大应用试点标杆项目，联合开展标准制定、安全增强、定制专用、行业服务等工作，积极推动自主安全技术融入新一代信息技术产品、应用和重点领域，着力打造需求牵引、原始创新、深度融合的生态合作体系。

  

*   **五是人才培养行动计划。**策源地将设立工程硕博士试点，建设产教融合基地，承担央企万人培训等工作，逐步形成培养复合型人才、高水平技术人才、实战专用人才的多层次培训体系。

  
![](../Images/7a54a2b08068b8912d290519c9879423.png)

网络安全领域原创技术策源地力争到2025年，实现参与国家科技项目超过15个，授权发明专利超过800个，参与制定国家和行业标准超过40个，建设自主研发平台15个。策源地将成为国家网络安全领域科技和产业的重要力量。
