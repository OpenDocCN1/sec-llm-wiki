# 龙江之约 奇安信将亮相2022世界5G大会

8月10日-12日，2022世界5G大会将在黑龙江哈尔滨召开。届时，全球5G领域的科学家、企业家和各界人士将深入探讨5G发展趋势，分享5G发展经验，共商5G发展大计。奇安信集团受邀出席，将参与主论坛、5G与工业振兴论坛、“龙江数字经济发展之约”座谈会、线下主题展等系列活动，并将与黑龙江省政府签约，共同推进北方区总部暨区域安全运营中心项目建设。

  

![](../Images/5ecbe0c960eeac0bffb841d5350b111c.png)

  

**大咖亮声，共话5G安全。**奇安信集团董事长齐向东将出席8月10日上午的开幕式及主论坛，发表《以“零事故”为目标 护航5G融入千行百业》的主题演讲；8月10日下午，齐向东还将作为企业代表，受邀参加“龙江数字经济发展之约”座谈会，与主管部委领导，全球一流专家学者、企业家深入探讨全球5G发展，以及黑龙江省数字经济突破方向与发展规划；奇安信工业互联网安全产品总监王弢将出席“5G与工业振兴论坛”，分享5G+工业互联网安全面临的挑战和解决方案。  
**冬奥网络安全中国方案全面展示。**在展览区（哈尔滨国际会展中心C09），奇安信将以“冬奥标准奇安信·网络安全零事故”为主题，通过中国模式、中国产品、中国架构、中国服务充分展现冬奥“零事故”成果经验，为5G时代下我国关键基础行业的网络安全保障及网络安全产业发展提供经验方案。  

![](../Images/299ccb3fba88ef06e811c81c6aa2dafa.png)

  

**深扎本地，积极推进龙江合作发展。**2022世界5G大会期间，黑龙江奇安信科技有限公司将正式揭牌。同时，为更好推进区域经济协同发展，促进黑龙江5G融合应用及数字经济发展进程，奇安信集团还将在大会期间，与黑龙江省政府签署战略合作协议。  
![](../Images/4dd878e20cab3a286ffe9ca5ca7dc85f.png)![](../Images/8344c545bcbbd73fa3f0ff946ccce124.png)

据悉，2022世界5G大会经国务院批准，由黑龙江省人民政府、国家发展改革委、科技部、工业和信息化部共同主办。大会围绕“筑5G生态，促共创共利”这一主题，设置“国际合作”“技术前瞻”“5G及数字产业”“5G+行业应用”等四大板块共14个分论坛/主题研讨会。作为全球首个5G领域的国际性盛会，自2019年在北京首次举办，奇安信已连续参与三届。
