# BCS2022| InForSec互联网基础设施安全论坛将于7月27日举办

*互联网基础设施是上层网络应用蓬勃发展的重要基石。近年来，随着地缘冲突的加剧，互联网的互联互通特性正面临着前所未有的严峻挑战，互联网基础设施的安全性成为备受关注的话题。*

  
  
  
  
![](../Images/b4c123cc149ee2d88b4dd2d3f936d427.png)![](../Images/629b6bfb721e938322dde5ccee609898.png)

  

7月27日，由InForSec网安国际主办，清华大学网络科学与网络空间研究院、网络空间安全治理研究基地与奇安信集团共同协办的2022北京网络安全大会（BCS2022）互联网基础设施安全论坛，邀请来自国际互联网治理领域权威组织ICANN、互联网技术标准组织IETF、清华大学、北京邮电大学、中国信通院以及大型运营商等业界专家学者，围绕“地缘冲突背景下互联网基础资源治理”主题展开交流讨论。

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)

  

![](../Images/a5de08bfe3e00a79307d2a9c30b78670.png)

  

清华大学网络研究院副院长、教授徐明伟将围绕“BGP路由系统”进行详细分享。针对当前国际范围内典型的BGP异常事件及冲突对抗进行系统分析，并介绍全球主要机构对BGP安全问题的最新关注和回应，还将探讨提升我国BGP安全的可能手段。  
公共技术标识符(Public Technical Identifiers, PTI)总裁、国际互联网号码分配机构(IANA)职能副总裁Kim Davies，以及ICANN亚太区总经理、公共技术标识符PTI董事罗嘉荣先生将围绕“域名系统的根区管理问题”进行共同分享。自2016年全球互联网域名管理组织IANA完成管理权移交以来，IANA的职能一直由PTI履行。演讲将通过分享IANA 职能部门的日常运营情况，PTI如何对其绩效负责并持续改进，讲解互联网域名解析中根区的管理逻辑，及其运行的机制。  
中国互联网络信息中心研究员，ICANN ccNSO理事姚健康将阐释他对互联网基础资源治理的几点基础认知，姚健康此前曾任国际互联网技术标准组织 IETF 互联网架构委员会（IAB）委员，他将结合其在国际互联网组织IETF和ICANN任职经验，主要介绍互联网基础资源治理的几点基础认知，这些基础认知可以作为互联网基础资源治理的基础和出发点，尝试回答当下全球互联网利益相关方都关心的问题：是谁控制了互联网？ICANN、IETF、IANA等国际互联网组织的理念是什么？  
清华大学博士后刘保君将从互联网信任体系的角度，谈互联网的治理问题。作为互联网关键信息基础设施之一，Web PKI为网络通信提供了机密性与完整性保障。刘保君将围绕“Web PKI证书信任体系安全性现状”进行分享，系统性梳理Web PKI证书信任体系所面临的潜在安全风险，并介绍历史上具有重要影响的典型安全事件；并结合前沿的学术研究成果，介绍终端可信根证书管理策略的安全缺陷与实际影响，并探索相应的防范措施以及最佳安全实践。  
基于近期两个国际热点事件背景，中国信息通信研究院政策与经济研究所副总工程师郭丰将分享“国际热点事件背景下ICANN动向观察”，分析ICANN社群讨论情况和ICANN组织及各方对事件的反应。  
  
  

**圆桌论坛环节将围绕“地缘冲突背景下的互联网基础资源治理”话题展开，北京邮电大学教授、前亚太互联网信息中心APNIC执委会委员马严担任主持，与论坛演讲嘉宾及清华大学李星教授、段海新教授、阿里云高级网络架构师宋林健等，进行深入的探讨。**
