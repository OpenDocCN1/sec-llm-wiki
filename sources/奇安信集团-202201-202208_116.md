# 人民日报：齐向东委员建议鼓励龙头企业培养创新人才

**人民日报**今日刊文发表《深入实施新时代强国战略——全国政协专题协商会发言摘编》，**北京市政协委员、奇安信集团董事长齐向东建议，鼓励龙头企业培养创新人才。**以下是发言全文：

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)  
  
  
  

  

**加快培养面向世界科技前沿**

**和国家重大需求的创新人才**

  

北京市政协委员、奇安信集团董事长

齐向东

  

各位领导、委员们，大家好！

  

**我的发言题目是“加快培养面向世界科技前沿和国家重大需求的创新人才”，具体谈三点建议。**  

*   **第一，**鼓励龙头企业针对“卡脖子”难题，通过承担国家重大前沿技术研发工程，培养创新技术人才。关键性的创新人才都是从重大工程中锻炼和培养出来的。比如，我国通过两弹一星工程，培养了数万名科技工作者。

  

重大前沿技术研发工程需要围绕龙头企业来开展。龙头企业中很多都是民营企业，在激烈的市场竞争中积累了资金、人才等优势。像奇安信集团，由于抓住了数字技术革命的机遇，大规模进行研发投入，仅8年时间，就成为龙头企业，不仅连续两年位列“中国网安产业竞争力50强”排行榜第一名，而且去年营收还跻身世界网安上市企业前十位置。利用承担北京冬奥网络安全保卫这个大工程，培养了一批网络安全顶尖创新人才。

  

但民营龙头企业承担重大前沿技术研发工程的积极性不高，因为周期长、投资大、风险高，研发费用按目前会计政策不能资本化，必须在年度内扣减利润，影响企业利润、股价和投资者利益。

  

**建议**出台具体政策，鼓励龙头企业投资重大技术研发工程：一是出台会计准则解释，对一些项目研发费用资本化运作，研发成功后由政府验收；二是给予专项资金补贴。

  

*   **第二，**打通企业和高校两个蓄才池，在国家重大需求领域，联合培养能解决复杂问题的卓越工程师。目前我国大多数硕博士毕业生实操能力不足，不符合产业能力要求。像网络安全专业，有潜力的学生多是逆向思维、兴趣驱动和不走寻常路，都是专才、怪才，毕业后他们很难读硕士、博士。

  

**建议**发挥企业的主导作用，校企联合培养卓越工程师：一是在工程硕博士的招生中，企业为主，把选人权交给企业，学校和企业各派一名导师；二是第一年的基础理论课，以高校为主，企业参与制定课程体系；三是第二年之后的专业培养，以企业为主，工程硕博生在企业导师的指导下，直接参与企业创新项目，项目周期一般2~5年，项目验收学生毕业。

  

*   **第三，**选取重点产业开展育才引才试点，国企民企一视同仁，打造更优的软环境。目前，我国人才在落户、住房等方面还存在不少困难。尤其是民营企业，能享受到的政策更少。

  

**建议**国家在对龙头企业的人才政策上一视同仁：一是给予民营企业和国有企业相同的人才落户比例；二是将人才评审权赋予龙头企业等市场主体；三是通过企业申请、政府补贴，吸引境外优秀人才回归。
