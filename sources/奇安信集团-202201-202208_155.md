# 同筑梦·共前行·一起向未来 | 2022重庆分区合作伙伴大会召开

2022重庆奇安信生态合作伙伴大会于7月8日在渝成功召开，会议围绕集团战略、渠道政策、2021重庆分区工作总结及2022工作计划目标等三大主题进行开展，旨在加强和重庆分区合作伙伴的紧密合作。

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)

  

奇安信集团副总裁何新飞、重庆分区总经理马培月、渠道负责人安雪涛、安服西南区总监谢继剑等出席并参与了全部会议，近100家合作伙伴参加本次会议。  

![](../Images/93db048bb8eea8225b8d82d069c82814.png)

  

## **奇安信集团副总裁何新飞**表示，数字重庆开启新篇章，需要高水平的网络安全能力保驾护航。奇安信集团是中国网络安全市场的领军者，作为在重庆网络安全市场规模最大、影响力最大的龙头企业，奇安信集团重庆公司专注于为重庆本地政企用户提供专业的网络安全产品和服务，并将持续以OSM运营销售模式、“七.一”行动、“三个一”工程等，赋能重庆市智造重镇、智慧名城建设。

  

奇安信集团重庆分区总经理马培月在《回首牛年 虎视未来 携手向前》中详细阐述了重庆分区的战略布局和规划，并寄望 2022年，奇安信集团重庆分区继续与各位合作伙伴同筑梦，共前行，一起向未来。  
针对2022年渠道政策和工作重点，奇安信集团重庆分区渠道负责人安雪涛进行了详细介绍，并对以往合作中做出杰出贡献的星级服务商、优秀合作伙伴进行了逐一颁奖。

  

![](../Images/2fe4239a81c04566344a6c7c33f046a3.png)

  
奇安信集团优秀合作伙伴代表重庆甲骨金文大数据有限公司董事长向博以《同筑梦 共前行 一起向未来》为题作了主题分享。

  

会上，重庆奇安信生态合作伙伴应急联盟正式成立。集团安服西南区总监谢继剑表示，应急联盟的成立将为重庆市网络安全保障工作提供更强有力的支撑，希望西南地区更多的生态合作伙伴能够加入联盟，共同为川渝应急保障赋能，助力构建完善的重庆市网络安全建设体系。

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)  

![](../Images/6344b8e0091f2812184a681854b7a87a.png)

  

重庆奇安信技术总监魏振国还在本次合作伙伴大会上进行了冬奥“零事故”保障经验分享。  
  
![](../Images/7a54a2b08068b8912d290519c9879423.png)

何新飞表示，渠道战略一直是奇安信集团核心战略，也是奇安信集团实现第二阶段高质量增长的核心战略，更是每一个营销人员的核心战略。后续奇安信集团也将以网络安全“零事故”为目标，持续贯彻渠道核心战略，和生态合作伙伴一起因地制宜打造适合重庆的三级网络安全指挥体系，促进多部门的协同联动，提升应急协调处置速度，为重庆的政企机构、关键信息基础设施提供一体化的网络安全保障。
