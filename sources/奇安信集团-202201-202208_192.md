# 奇安信与成都卫健委举办冬奥网络安全“零事故”经验分享会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247568621&idx=4&sn=3e18a8d31dc158b29233518bfedcb020&chksm=fb77eae9cc0063ff870b423fb5ef8636816627852fb733b7397a7625db8ba17089a0fb44ae6e&scene=126&sessionid=1681373333#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247568621&idx=4&sn=3e18a8d31dc158b29233518bfedcb020&chksm=fb77eae9cc0063ff870b423fb5ef8636816627852fb733b7397a7625db8ba17089a0fb44ae6e&scene=126&sessionid=1681373333#rd)

6月23日，奇安信与成都卫健委举办冬奥网络安全“零事故”经验线上分享会。四川天府新区社区治理和社事局、成都东部新区公共服务局、成都高新区教文卫健局，各区(市)县卫健局，成都大运会执委会医疗部，各委直属单位、委机关各处(室)，奇安信集团领导及相关专家团队共500人参加。

  

![](../Images/c0e914d6e5f4a0807cf95ec649e9adcc.png)

  

**成都市卫生健康委员会党组成员、副主任贾勇**表示，此次与奇安信的交流活动对于医疗战线的同志们了解网络安全风险、网络安全前沿知识，是一个宝贵的学习机会，有助于各单位相关负责人进一步强化网络安全意识，树立网络安全日常化、实战化的大局观。希望大家提高思想认识高度，在技术上不断精进，在人才上不断培养，在运行机制方面不断完善。  
随着互联网+医疗的快速发展，医疗行业网络安全风险也愈加凸显，医疗行业网络安全保障能力的提升刻不容缓。**奇安信集团高级副总裁曲晓东**表示，近几年，国内多个省份的医疗机构均受到不同程度的网络安全攻击。国家及行业主管机构对医疗行业网络安全工作愈加重视，相关政策法规不断出台，在数据安全、信创等方面不断明确要求和深化指导。奇安信自2020年起，就协助主管机构开展开展卫生健康网络安全攻防大赛，协助医疗单位强化安全工作人员能力水平。

  

![](../Images/7a28f994bfe5c4c25ad02ca1d479d476.png)

  

冬奥的实战化检验，让奇安信的综合实力再上新台阶，冬奥“零事故”经验也开始在医疗行业一些头部单位试点试行，探索应用。曲晓东表示，奇安信将以“零事故”为目标，将冬奥成功经验和成都卫生领域实际需求相结合，与成都卫健委加强合作。  
奇安信集团副总裁、奇安信冬奥网络安全“零事故”经验宣讲团副团长韩永刚，奇安信集团冬奥保障项目经理仝磊，奇安信涉网犯罪研究中心专家秘焰，就奇安信在北京冬奥网络安全保障过程中的整体规划、重点工程、重保研判等方面的成功经验及技术内容进行了介绍。

  

![](../Images/870093b8b0f1ef05e16b7315b92259a4.png)

据悉，奇安信冬奥网络安全“零事故”经验宣讲团成立于3月16日，并梳理了北京冬奥网络安全“零事故”经验，总结了由“中国模式”“中国服务”“中国产品”“中国架构”共同组成的网络安全“中国方案”。截至目前，宣讲团已面向金融、通信、水利、电力、医疗等重点关基行业举办了百余场经验分享会，旨在尽快为我国关键信息基础设施、重要活动的网络安全保障工作打造模范样本，并加快落地应用。
