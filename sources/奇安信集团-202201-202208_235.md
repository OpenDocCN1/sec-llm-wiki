# 奇安信公益基金会“眼明心安”项目启动 为西藏眼疾患儿点亮未来

6月6日，在第27个全国爱眼日之际，由北京白求恩公益基金会与北大医学（包括北京大学人民医院、北京大学第一医院、北京大学第三医院）眼科专业力量携手共同发起，北京奇安信公益基金会支持的“白求恩·眼明心安-西藏儿童盲及低视力诊疗能力提升项目”正式启动。

  

![](../Images/1ae429fb93b537b74d4d95388ab0afef.png)

  

项目启动会通过线上线下相结合的方式举行。西藏自治区卫生健康委党组书记、副主任谭相东，北京白求恩公益基金会理事长孙志伟，北京大学医学部副主任肖渊，北京大学人民医院眼科副主任、中华医学会儿科分会眼科学组组长梁建宏，西藏自治区人民医院党委副书记、常务副院长（援藏）、国家卫生健康委医政医管局行风建设处处长陈虎，西藏自治区人民医院副院长格桑罗布，北京奇安信公益基金会理事长尹乃潇，北京奇安信公益基金会秘书长齐子昕等各方代表及医学专家参与启动会。

![](../Images/f7851c245a660a7a51a44bd4d5e4d8fe.png) 

  

**北京白求恩公益基金会理事长孙志伟**在致辞中提到，在第27个全国爱眼日之际启动“白求恩·眼明心安”项目，是助力健康中国的一个具体行动。希望通过汇聚各方力量，提升西藏儿童盲及低视力诊疗能力，从首都北京到青藏高原，为西藏孩子们的心灵之窗带去光明的力量。

  

![](../Images/d063b18e55a4948506d06b3cba0bebd1.png)

  

![](../Images/f7851c245a660a7a51a44bd4d5e4d8fe.png)

  

**西藏自治区卫生健康委党组书记、副主任谭相东**在致辞中对本项目的启动给予了充分的肯定和期待。他指出：实施好“白求恩·眼明心安-西藏儿童盲及低视力诊疗能力提升项目”，是增进西藏各族群众特别是儿童健康福祉的迫切要求；是提升西藏眼科诊疗水平的迫切要求；是揭示西藏眼科疾病防治规律的迫切要求；是造福雪域高原的民生工程、民心工程、德政工程。我们有信心、有经验、有基础、有条件、有实力去完成好，只有这样才不愧对广大西藏眼科患儿的期待眼神。

  

![](../Images/eb2cbd74a01f7e011bffa7a0b035661a.png)

  

![](../Images/f7851c245a660a7a51a44bd4d5e4d8fe.png)

  

作为本次项目的重要支持方之一，**北京奇安信公益基金会理事长尹乃潇**表示，“眼明心安”项目是奇安信公益基金会2022年“心安助医”工程的重点项目。奇安信公益基金会将与北京白求恩公益基金会、北京大学医学部一道，重点解决西藏眼疾患儿面临的难题，希望切实帮助更多的孩子。

  

![](../Images/c779d95bfba03a21ae8ffcb7f4c32af7.png)

  

  

“ 

2022年1月，国家卫生健康委发布《“十四五”全国眼健康规划（2021—2025年）》要求，到2025年，儿童青少年眼健康整体水平不断提升；力争眼科医师总数超过5万名，每10万人口拥有眼科医师数超过3.6名。

” 

  

本项目牵头专家，**北京大学人民医院眼科副主任、中华医学会儿科分会眼科学组组长梁建宏教授**在发言中讲到，西藏受特殊的地域环境和自然条件影响，成为我国各类眼病的高发区。在西藏，失明或患有严重视力障碍的人口比例远超全国平均水平。尤其是医疗卫生资源分布不均，眼科专业医疗技术人员数量不足及医疗水平有待提高的问题仍然存在。

  

![](../Images/37de155173228d19b75ee5ead0fe29f1.png)

  

![](../Images/f7851c245a660a7a51a44bd4d5e4d8fe.png)

  

在此背景下，北京白求恩公益基金会、北京奇安信公益基金会、北京大学医学部三方联合发起“白求恩·眼明心安-西藏儿童盲及低视力诊疗能力提升项目”，希望结合北大医学多年来的医疗援藏实践经验和优势，共同助力完善西藏自治区防盲和眼健康服务体系建设，促进眼科专业人才培养，推动西藏自治区眼科医疗服务高质量发展，不断提高人民的眼健康水平。

  

**启动仪式上，“白求恩·眼明心安-西藏儿童盲及低视力诊疗能力提升项目”合作正式签约。**在项目实施过程中，北京白求恩公益基金会、北京奇安信公益基金会、北京大学人民医院将各司其职，整合资源，以实现“促进眼科专业人才培养，助推西藏自治区眼科医疗服务高质量发展，不断提高人民的眼健康水平”的目标。北京白求恩公益基金会秘书长樊燕荣向北京奇安信公益基金会秘书长齐子昕颁发纪念奖杯。

  

![](../Images/20dacbe54918a5767fbd03a3cbe3d98a.png)

  

![](../Images/f7851c245a660a7a51a44bd4d5e4d8fe.png)

  

自2021年10月成立以来，奇安信公益基金会经过多方深入调研，专门设立了“心安工程”，从“心安助医”、“心安助学”、“心安救灾”、“心安助农”四个领域入手，积极践行社会公益。

  

此前，奇安信公益基金会已向吉林大学、福州大学等七所高校分批捐赠了防疫物资，并响应首都统战援港工作、北京民营经济同心抗疫号召进行捐赠，为全国各地抗击新冠疫情、打赢防疫抗疫贡献攻坚力量。同时，“眼明心安”也将作为奇安信公益基金会2022年“心安助医”工程的重点项目，切实帮助西藏儿童眼健康筑起牢固屏障。
