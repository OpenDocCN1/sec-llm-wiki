# 《黑客帝国4》预言了下一代科技革命？后元宇宙时代，你准备好了吗

《黑客帝国4》在国内上映了，不得不说这次变化不小。墨菲斯不是原来的墨菲斯了，特工史密斯摇身一变成了尼奥在母体中的老板，突然冒出来的尼奥的心理咨询师其实是个大boss，连主角尼奥和崔妮蒂的脸上都增添了不少岁月痕迹。

  
![](../Images/ce51141cdc16368c48f9f829617802ce.png)图片来源于《黑客帝国4》  
**时代也在变化。**2003年《黑客帝国3》上映时，手机还是大哥大的样子，如今电脑已经从大头显示屏搭配巨型主机进化到现在超薄笔记本。这20年间，与黑客帝国系列题材相似的《西部世界》、《头号玩家》、《雪崩》等，已经把不断发展的先进科技演绎了一个遍。  
****黑客帝国**系列自面世以来，一直是极客们的终极乌托邦。《黑客帝国4》**的口碑虽然已难以与之前匹敌。但凭借20年前就在电影中疯狂输出先进科技，在极客们的心中黑客帝国系列的地位就难以撼动。连接母体与自由人的脑机接口、特工史密斯在母体中病毒式的演进复制、先知不断开后门。现在看来这些先进技术概念都已被大众熟知，甚至不少人在看了《黑客帝国4》之后直呼——**这不就是元宇宙吗！**  

**黑客帝国与元宇宙之间**

**只差“技术”这一层窗户纸？**

  

    Matrix&Metaverse

  
**《**黑客帝国4**》的上映恰逢元宇宙概念的大火，掀起了不小的热度。**黑客帝国系列中一直是在用脑机接口来连接人和虚拟世界，也就是所说的母体。而在现实中，科学一直在试图不断实现将人的意识反映虚拟现实之中，就此诞生了VR、AI等一系列技术。甚至不少网友说，人脑和电脑都是“脑”，连上就是“黑客帝国”！  
![](../Images/f74a65cf809a987f9d1a1017ad250356.png)图片来源于《黑客帝国1》  
**说到这里，不得不问一句，人类目前的技术距离实现“黑客帝国”般的元宇宙究竟还有多远？**对于元宇宙的定义一直以来可谓是众说纷纭，但其最重要的几大元素到目前为止公认的有：扩展现实、数字孪生、数字仿真、区块链、人工智能、云计算、大数据等，一同搭建出元宇宙世界内的经济系统、社交系统与身份系统。虽然元宇宙是一个全新的，平行于现实世界的数字世界。但人作为接入其中的使用者，目前为止元宇宙的搭建还是以人类社会为范本。黑客帝国中的人工智能已经相当高级，甚至已经作为一种新的生命形态与尼奥所在的人类社会产生了冲突。有不少人说，这根本的冲突在于硅基生命和碳基生命的冲突，在黑客帝国系列中也一直以此冲突为设想进行探讨。  
**但现实中，真正的人工智能技术远不是想象中的那么简单，也绝不是将神经元转化为电脑数据就能实现。**人工智能是一个综合性交叉学科，包含计算机、心理学、哲学、神经科学等等。到目前为止人类对于人工智能的研究都还处于刚刚入门的阶段。再进一步说，人类对于人工智能中最重要的神经科学的研究、如何理解人脑，也仍处于盲人摸象的阶段。  
![](../Images/4b0ca16a8b07611890028ccbca276612.png)  
在如此的进展下，目前人类与计算机的连接，也暂时只能通过VR设备将人的行动反映到虚拟世界中。而这些距离实现黑客帝国中采用脑机接口，直接将人的意识接入到虚拟现实之中来看，怕是还有很长的路要走。**在探索的路上，也并非毫无曙光。**特斯拉CEO马斯克旗下的脑芯片公司Neurallink曾在一只名为“帕格”的9岁猕猴大脑内，通过内置的Neurallink设备实现了用意念操控电子游戏。就在今日，其实验室宣布招募临床试验主任，准备兑现其“在人类身上进行临床试验”的承诺。  
![](../Images/8c273892ae3106b722f9a9bce7acaf2d.png)图片截取自Neurallink上传至油管的视频  
**马斯克一直以来都是元宇宙的坚实拥护者，但有些专家却对此并不持乐观态度。**美国匹兹堡大学神经生物学家安德鲁称，实验视频中实际猴子对其的控制性很基础，早在20年前就已经得到证明。以目前的神经科学发展程度及伦理角度来看，在脑中放入芯片就已饱受专家的质疑，更不用说若想要实现类似黑客帝国系列中的脑机接口，势必将要在人脑中置入一个物理设备的接口。  
**可见目前人类社会距离黑客帝国，甚至元宇宙之间的距离，都还将涉及医学、科技与伦理的多重挑战。**  

**何为现实？**

**你选红药丸还是蓝药丸**

  

    Matrix&Metaverse

  
黑客帝国系列中的红蓝药丸一直都是区分现实与虚假的关键。**若说黑客帝国中的脑机接口离现实还太远，而数字孪生、云计算、大数据等技术已相对成熟，已成为元宇宙未来发展的重点硬科技领域。**目前，国内不少互联网大厂都已开始了元宇宙的布局。其实在2021年初，在各大科技公司的推波助澜下，元宇宙就已经爆火，在2021年底Facebook宣布其正式改名为Meta时达到了高潮，科技圈内对于元宇宙的讨论达到了前所未有的热度。而与此同时，区块链货币价格飞涨、NFT爆火，互联网上甚至一度出现了“元宇宙房地产”的宣传。  
![](../Images/afb2a594aad5ffdf941753c21b481179.png)  
**一时间，乱象丛生。各种新型“红药丸”、“蓝药丸”充斥在元宇宙发展之中。**岁末年初，国内多个城市开始陆续表态布局元宇宙赛道，尤其以“长三角”地区为首。2021年11月，浙江省经信局就组织召开“元宇宙”产业发展座谈会；12月，《上海市电子信息产业发展“十四五”规划》出台，元宇宙首次被写入地方“十四五”产业规划；2022年1月，在北京“两会”上，布局元宇宙被多位委员提出。  
**美国一直以来通过科技霸主、经济霸主等优势地位收割着全世界。但近年来，我国科技的发展已逐渐呈现赶超美国的势头。**在此次元宇宙发展中，国家的快速反应、积极布局，剥除元宇宙乱象、确立元宇宙发展以科技发展为核心的一系列动作，想来也是国家科技强国的举措之一。  
2022年，新冠疫情仍在大规模肆虐。德尔塔、奥密克戎、德米克戎接二连三席卷全球，美国每天的确诊人数一次次攀升，甚至在严防死守的我国，有时都不得不面对病毒偷偷溜进国门的现实。试想一下，在大量线下活动因疫情转移到线上的今天，这时，如果元宇宙技术可以大量应用到教学、医疗、文旅、娱乐等等领域，那么**原本因疫情只能靠视频来呈现的各类行业，或将迎来新一波井喷式发展。**![](../Images/bd61d4eb7e17d53f3157794dc0775fca.png)  
目前大部分的远程教学依靠视频沟通软件，很多时候师生两端缺少了很多原本应有的沟通交流；远程文旅最多只能依靠视频来了解，不能达到文旅真正临其境、观其物、感其形的目的；远程医疗目前只能保证“望闻问”，如不能“切”，怕是诊断还是会受一定程度影响，更不用说有些需要手术的医疗问题。2018年，在我国5G技术的支持发展下，解放军总医院刘荣主任利用5G实现了远程操控无线钻孔机床，帮助一只试验猪进行了肝小叶切除手术。未来如果能够利用数字孪生技术提前演练，进而利用数字仿真技术远程操控，我国医师或许可以随时随地为远在非洲的患者进行手术。  
**握在手里的硬科技，才是现实。****比起爆炒的NFT和区块链货币，这类技术的发展将不仅仅是造福一方、甚至全人类的科技进步，也更是将我国先进科技推向世界，重置世界科技、产业，乃至经济格局的绝佳机遇。**  

**打工人尼奥被困母体，**

**你世界的安全谁来守护？**

  

    Matrix&Metaverse

  
在黑客帝国系列中，尼奥一直在与特工史密斯斗智斗勇斗法，第三部中尼奥和崔妮蒂撇开一切去到了机械城市01，牺牲自己守护了锡安。**人类的命运还要靠尼奥、崔妮蒂来守护。**  
![](../Images/a6d6e5781f4d394e7153219a322e6ca8.png)图片来源于《黑客帝国3》  
现实生活中，数字世界本就融入千家万户、世界各地，真实的“黑客”也在现实世界中横行，伴随着不少的虚拟世界的安全问题。**更何况随着元宇宙科技的发展，现实世界与虚拟世界的链接是否安全？人类与人工智能之间的关系又是否安全？而这些，又要由谁来守护？ ****有攻便有守，就像尼奥和史密斯是一个事物的一体两面，有危险的地方就一定会有人在守护。**说起这个， “黑客”一词其实可褒可贬，网络空间的安全其实一直都是由一群具有正义感的“黑客”守护。在1986年中国计算机学会计算机安全专业委员会正式成立之后，中国的网络安全行业逐渐成型。这一代成长起来的极客们，一直都视黑客帝国系列为启蒙，奇安信甚至取“锡安”为其四大研发平台之一命名。  
**目前世界的意识形态，已广泛存在于网络空间之中。**近年，美国已明确提出未来网络空间将成为除海、陆、空、太空外的第五战场，更是成立了专门的网络军来应对随时随地的网络攻击。**如此便不难理解，为何我国早在元宇宙如火如荼开战之前，就已经开始大力布局网络安全产业。**  
目前，我国各行各业都已经陆续将网络安全行业作为基础建设布局在数字化进程中。**一直以来以和平为著称的奥运会，也将网络安全纳入了安全考虑范畴之内。**北京冬奥组委在 “没有网络安全就没有国家安全”的手抄报发出之后的次年，便宣布了与网络安全头部企业奇安信的合作。2022北京冬奥也将是奥运会历史上第一届拥有专门的网络安全提供商的奥运会，具有划时代意义。随着元宇宙的发展，数字世界将是每一个人都无法避免接触的社会。到那时，何为真，何为假，眼前的人是尼奥还是史密斯，对于大多数来讲，将是比起选红蓝药丸还要难的题目。  
**那么网络安全行业中各位正义的“黑客”，未来或将成为守护国家安全，甚至人类社会安全的the One——“尼奥”。**  

**说到底，元宇宙爆火映射的是**

**人类社会亟待下一个科技革命的现状**

  

    Matrix&Metaverse

  
**历史的洪流从来都不曾停歇**，从第一次科技革命开始，大机器生产成为工业生产的主要方式，为西方技术先进于东方奠定了基础；第二次科技革命，进入电气化时代，资本主义完成了大量原始积累；第三次科技革命，二战后形成了资本主义的垄断，以西方为主的世界经济格局延续至今；第四次科技革命，产生了系统科学、计算机科学、纳米科学与生命科学等技术，我国在这些领域中国逐渐追赶；第五次科技革命，电子和信息技术普及并应用，随着互联网的快速发展，中国到目前已经站到了国际科学技术的前沿。  
**那么元宇宙，是否就是下一次科技革命的先演？****或许是。****回看每一次科技革命，都完成了一次生产力的进步，科学技术的飞升。如果元宇宙能够实现，从其中的各类技术的实践角度来讲，或许确实能够实现人类社会生产力的再一次提升。**![](../Images/94597bb5ee09e7240e65e644bab8f950.png)  
这时也就不难理解近年来为何国家一直强调“科技强国”的战略，而此次元宇宙乱象一出便快速布局，以科技发展为元宇宙定调的原因。**中国若能够抓住此次技术发展的机遇，扩展现实、数字孪生、区块链、人工智能、云计算、大数据技术势必将我国推向科技领导者的地位。**那个时候，距离黑客帝国仅一步之遥，未来社会将充分享受科技的便利。脑机接口接上便可以周游世界，甚至环游宇宙，更甚至可以穿越时空；或许医学足够发达，重症不复存在，或者是可以随意更换身体部件，又或者直接将自己的记忆传输到全新克隆人的大脑芯片内继续生活。  
**超越时空，超越生死。**这些或许都是未来科技能够带给人们一直想要追求的便利。但如果超越了时空，超越了生死，那么人类生活的意义是否又会随之改变，像黑客帝国系列中一次次发生的人类与机器人的对抗、人类被逼迫到世界的一角是否会真的变成现实。  
![](../Images/6edcdf058441dc5be1509db69515bbf3.png)图片来源于《黑客帝国1》  
**技术、社会、伦理……黑客帝国也许从一开始就想要为我们预言其中的一种可能性。红药丸还是蓝药丸？何为现实？是范式也可能是警示。****无论怎样，科技在发展，时代在变化，距离真正的元宇宙，我们也还有很长的路要走。**
