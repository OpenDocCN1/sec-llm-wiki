# “九大战略”重构渠道CBG业务发展，近200家代理商参加2023奇安信虎符问道系列行活动

**近日，鄂豫、苏沪、黑吉辽蒙等地区近200家代理商共赴奇安信集团参加“零事故大机会，安全携手奇安信”主题的2023奇安信虎符问道系列行活动**，奇安信集团副总裁、渠道CBG总经理何新飞，渠道CBG技术总体部总经理李宁等领导与来访的合作伙伴，共同分享2023年奇安信集团渠道业务新模式、新战略和渠道CBG业务新思路，探讨渠道市场新机遇和营销新策略。

虎符问道系列行会议现场，集团副总裁何新飞发言

**“以‘九大战略’重构渠道CBG业务发展”。**座谈会上，集团副总裁何新飞表示，奇安信集团成长和发展的每一步都有着各位伙伴的关注、支持、付出和贡献，奇安信的成功是各位合作伙伴共同努力的结果。2023年，渠道CBG坚持模式创新引领渠道业务高质量发展，从**“渠道CBG组织”独立运营发展、“江河数字化平台”建设运营、渠道方案推动与模式引领、渠道客户共享与推送商机、渠道业务发展考核导向、渠道网络安全竞争力提升、“虎符生态”市场推广、渠道战略发展顾问委员会设立以及渠道CBG组织保障等九大战略****，全面推进渠道CBG变革，为渠道业务高速发展提供强硬支撑。**

  
**在方案推动、模式引领方面，何新飞表示，奇安信通过分析市场竞争力，深刻了解产品特性、方案特色、模式引领，与合作伙伴共同打造教育“双安模式”运营中心、特勤运营中心模式、零事故“MSS”安全运营模式，以保障渠道业务的有效推进。**奇安信集团将积极发挥自身在网络安全领军企业的技术和产品优势，扎根渠道、融入渠道，与合作伙伴共享变革和发展成果，为渠道创造持续价值。![](../Images/547d3c6710b0ebc51d8c839e7e101064.png)

虎符问道系列行座谈会现场

在座谈会中，渠道管委会相关负责人围绕2023渠道CBG政策，零事故大机会，以“模式”创造网络安全新市场，奇安信生态合作伙伴“江河”平台等方面做了详细的介绍和讲解，为鄂豫、苏沪、黑吉辽蒙等地区近200家代理商实现核心价值共生，提供一套基于奇安信虎符生态的核心价值代理商体系，为中小企业客户实现核心价值再造，达成企业数字转型升级注入了安全的力量。

  
在交流研讨环节，鄂豫、苏沪、黑吉辽蒙等地区近200家代理商针对业务开展中存在的库存问题、跨区域调货配合、项目报备产生争议、质保期内售后服务、样机支撑、应急联盟评定、技术如何赋能以及分销的项目与产品如何区分等数十个问题和需求与渠道CBG管委会领导班子进行交流和探讨。![](../Images/54564139d28bd6675262d14d04d0ce7e.png)
