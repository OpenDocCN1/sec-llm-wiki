# 德胜门大讲堂|齐向东：发挥人的主体性 积极拥抱人工智能时代

最近，ChatGPT4.0、百度文心一言陆续发布，人工智能再次成为大众关注的焦点。AI如何影响生活和工作？如何改变人类社会？这场科技革命带来的安全问题又如何应对？**奇安信集团董事长齐向东在近日全国工商联举办的“德胜门大讲堂”上说，要发挥人的主体性，积极拥抱人工智能时代。**

以下是演讲全文：

![](../Images/046b345395c571a06dc4d469da4cb04f.png)党的二十大报告指出，要构建新一代信息技术、人工智能等一批新的增长引擎。人工智能已经成为国家重点战略，为实现中国式现代化提供创新动能。如何抓住人工智能机遇、让人工智能技术真正为我所用，是摆在我们面前的关键性问题。借这个机会，我想和大家分享三点看法。  

****一、人工智能是科技革命的核心技术。****

*最近，ChatGPT凭借学习能力快速“出圈”，标志着人工智能成为了当前科技革命的核心技术。*有人说它像个小学生，有人说它像个中学生，有人说像它像个大学生。在我看来，ChatGPT像是一个高智商的人，大脑的并行计算能力很强。我们知道，一个人把智商转化成创造力需要一个过程，哪怕是神童，也得需要十年时间，才能念完从小学到博士的全部课程。但AI不需要这么长时间，它可能一个月就能学会一个人这一生需要学习的东西。

  
![](../Images/69b2e87c93d898bcb35569e3b190f10f.png)这个成果让人工智能不是上了一个台阶，而是上了一个境界。![](../Images/47378bf0f2c0e3737f7410f704049208.png)第一，ChatGPT产生科学突破，让人工智能第一次具有逻辑能力。中科院教授吕本富认为，以前的人工智能只是对图像、语言进行识别，回答Yes和No的问题。这次有了逻辑推理能力，是革命性的，他说“中国人工智能专家之前一直在探索，在黑暗中摸索，没找到方法”。清华大学人工智能研究院的孙茂松院士认为，ChatGPT完全出乎行业学者的估计，完全没想到“它不是一个简单的产品，实际上是一个智能信息处理的通用基础设施。”中国工程院院士王坚认为，ChatGPT表面上是应用的发展，但本质上是背后的方法论发生翻天覆地的变化，是方法论趋向统一。

  
第二，ChatGPT是对人工智能产业的颠覆。以前人工智能最大的卡脖子问题，是不同行业的知识，要用不同的模型进行训练，永远也训练不完。ChatGPT用大模型通用训练，具备各专业的知识和逻辑，这是突破。清华大学刘嘉教授认为，ChatGPT训练素材几年包括了人类所有知识，如果互联网知识是1，它学了2/3。举个例子，维基百科有600万篇文章，只占它素材的千分之六。

  
第三，创新进入“高能创新”时代，“高能创新”需要“人才密度”。ChatGPT团队只有87人，几乎全是名校毕业，其中华人10%，清华本科背景的有3人。吕本富认为，未来创新不是大公司或国家组织能主导的，讲究人才密度。孙茂松院士也认为，我国人工智能平均水平是领先的，但顶尖能力和人才差距很大。

  
第四，ChatGPT的进阶速度，令人瞩目。在计算机时代，有摩尔定律，它的周期可能更短。据OpenAI统计，从2012年到2020年，人工智能模型训练消耗的算力增长了30万倍，平均每3.4个月翻一番，超过了摩尔定律的每18个月翻番的增速。

  
第五，人工智能将成为基础设施，极大推动经济发展。真正的人工智能是变成基础设施，像水电煤气等，它会对经济产生冲击，要有所准备。我们要积极拥抱人工智能，拒绝人工智能的帮助可能使自己落后。研究显示，到2025年，人工智能技术可能在全球范围内增加超过13万亿美元的经济价值。

  
第六，对经营和管理产生深远影响，改变产业竞争格局。人工智能可能会取代一些低智力的劳动岗位，比如低级别的程序员、通用文稿写手、通用文案策划等，一些靠低智力、大量人力优势的公司，可能难以维系，所以蓝海和红海可能要重新划分。吕本富认为，ChatGPT 的答案是全人类的最大公约数，来源于它能收集到的人类最大数据，所以创造力和想象力更加稀缺，以后每个企业的招聘标准将以这两个“力”为核心。

  
第七，AI不会完全取代人，人工智能和人类将是协同合作的关系。人工智能本质上是辅助人的，但它不会完全取代人，人工智能和人类将是协同合作的关系，因为再先进的科技，归根到底都是由人类研发、让人类使用的工具，人的主体性很难替代。孙茂松院士也认为，人工智能还是受人控制，虽然它做坏事的威力会很大，但背后还是因为人出了问题。

  

****二、人工智能为我们实现科技自立自强提供了大机遇，要发挥主力军和生力军作用。****

*只有科技自立自强，实现中国式现代化才有强劲的动力。*我们已经开启全面建设社会主义现代化国家新征程、向第二个百年奋斗目标进军，中国式现代化道路进入新阶段。抓住机遇，推进科技创新，实现科技自立自强，我国在国际竞争中才能立于不败之地，才能为实现中国式现代化提供强劲的动力。

  
*人工智能为我们加快实现科技自立自强提供了突破口。*习近平总书记强调：“人工智能是引领这一轮科技革命和产业变革的战略性技术，具有溢出带动性很强的‘头雁’效应。”

  
*占领人工智能核心技术的最高点，需要充分发挥“主力军”和“生力军”的作用。*科技自立自强包含两方面，一方面是在现行技术路线上自立，解决“卡脖子”难题，实现自主可控；另一方面是在未来新技术路线上自强，走自己的技术路线，创新引领前行。要想实现这两点，只靠少数精英企业、高端科研院所是做不到的，还需要更多力量参与进来。民营企业不仅是市场中最活跃的主体，而且是科技创新的重要力量。目前，随着“放管服”的持续推进，我国的营商环境得到了很大改善，企业办事变得容易了，各种门槛限制也放宽了。但是，我们的创新环境、金融环境还有待改善。

  
一方面，行业龙头企业是科技创新的“主力军”，资本市场对创新研发的包容度还需进一步扩大。龙头企业在激烈的市场竞争中积累了丰富的资金、人才等优势。但是，科技创新投入大、周期长、风险高，投资在眼下，收益在未来，体现在会计制度上，是在研发期间即时扣减利润，还是在成功之后有了收入再减本。我们知道，研发创新产品是成本费用，第一种情况，当年就减少利润，企业会受到股东和股民的反对，企业就没有创新积极性；第二种情况，不减少当年利润，而是在项目成功上市取得收入以后，按收入进度比例分摊成本费用，保证分摊之后增加毛利润，这样做到了在研发期不减利润，在投产期增加利润。企业就愿意为技术创新投资了。目前的会计准则支持第一种情况，不利于创新。所以，我们还需要进一步改善会计制度，让“卡脖子”项目的研发费用可以资本化，让龙头企业真正成为科技自立自强的主力军。

  
另一方面，“专精特新”企业作为科技创新的“生力军”，还面临“三难”困境：起步难、持续难、做强难。从研发到产品投入市场，周期长、原始资金需求量大，融资起步难；产品站稳脚跟后，需要扩大市场，市场和研发费用再次加大，如果没有再融资渠道则持续难；一些产业链涉及的关键技术点多，“卡脖子”难题多，持续研发投入可能长期亏损，如果资本市场包容度不够，则做强难。要针对性解除这“三难”问题，我们需要在融资方面给予更大的扶持，比如延长贷款还本时间、推动保险公司和银行合作定制开发“专精特新”专属信贷产品、设立专项投资基金等，让“专精特新”真正成为科技自立自强的生力军。

  

****三、网络安全是核心中的核心。****

我过去总说，“网络安全是数字时代的底板工程”，很多人对这句话没有实感。*人工智能兴起以后，网络安全会变得越来越重要，真切影响到生产安全、财产安全、生命安全，甚至国家安全。*

  
*人工智能让整个社会变成了一个大的基础设施，网络攻击的后果是不可估量的。*我刚刚提到，未来人工智能会变成水电煤气一样的基础设施，渗透到大众生活的每一个场景。它会加速企业产品和服务的智能化，共同连接到这个大的基础设施上。这样的一个基础设施连接着数以亿计的产品，如果被攻击，就像自来水被人下了毒，后果可想而知。当企业的生产业务系统都实现数字化，黑客攻击这些单位就能盗窃资产卖钱，更能以迫使停工停产而敲诈勒索、谋取赎金，因为有利可图，这样就会形成恶性循环。现在，因为网络攻击导致“断电”“断油”“断肉”“断播”的案例已经时有发生。未来，人工智能的广泛应用会加剧这种风险。

  
*人工智能还相当于给了普通人一本“武林秘籍”，让黑客的水平跃升，威胁国家安全。*现在，高水平的黑客只是一小部分，一般是具有国家背景的组织窃取他国的国家秘密、破坏重要基础设施。但人工智能技术能让黑客的水平跃升，因为它懂得更多的漏洞知识，懂得更多攻击方法，甚至能让不懂代码、不懂技术的普通人也成为黑客。这样一来，网络攻击强度更大、数量更多。俄乌网络战中已经为我们敲响了警钟，守不住网络安全严重影响社会稳定运行、甚至国家安全。

  
*所以，网络安全是未来社会核心中的核心*。我经常鼓励自己，网络安全最大的魅力，就在于要不断面对新问题。针对人工智能带来的网络安全挑战，有人认为，要用人工智能打败人工智能。但我认为，解决问题的核心是人。

  
*网络安全的本质是攻防两端人与人的较量，再先进的科技，都需要人来使用、人来控制、人来确保安全。*在北京冬奥网络安保中，我们对几乎所有可能做了预判，建立了三级态势感知系统，它能从数以千万计的攻击中，快速研判和拦截80%的攻击，剩下20%机器拿不准的，让高水平的人去做决定。通过“人+机器”的配合，我们成功研判、拦截了3.8亿次网络攻击，创造了冬奥网络安全的“零事故”纪录。

  
*现在，奇安信通过“两手抓”，积极布局智能时代。*一方面，我们正在训练专有的类ChatGPT安全大模型，未来可以用于安全产品开发、威胁检测、漏洞挖掘等多个方面。另一方面，在人才培养上，我们充分发挥“培养卓越工程师重点企业”的优势，在绵阳、武汉、青岛等地成立了虎符基地，目前培养了3600多名网安人才，输送到了金融、交通、能源等各个重点领域。

  
*人工智能的进化速度超乎人类的想象。我们需要持续奋斗，不断创新，尽一切努力跑在AI前面。*我也将带领奇安信加大创新力度，为网络强国、数字中国建设贡献网络安全力量！谢谢大家。
