# 奇安信参与国内首个数据交易链建设

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247587772&idx=3&sn=c0387249c409a49f19c2bebf756266ae&chksm=fb77b1b8cc0038ae49a788bf9505b903de753f837aeca59cd057e83e7f575ee301f261d50ce8&scene=126&sessionid=1681373227#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247587772&idx=3&sn=c0387249c409a49f19c2bebf756266ae&chksm=fb77b1b8cc0038ae49a788bf9505b903de753f837aeca59cd057e83e7f575ee301f261d50ce8&scene=126&sessionid=1681373227#rd)

近日，上海数据交易所宣布，将携手大数据流通与交易技术国家工程实验室正式启动国内首个数据交易链的建设工作，这也是国内数据流通交易领域的新一代基础设施建设项目。**奇安信集团等多家专业公司将与上海数据交易所、大数据流通与交易技术国家工程实验室一起，共同完成数据交易链本期建设工作。**

![](../Images/410b146feacc009aaafc897fc5cc61af.png)

位于浦东张江的上海数据交易所是上海市人民政府指导下组建的准公共服务机构，承担数据要素流通制度和规范探索创新、数据要素流通基础设施服务、数据产品登记和数据产品交易等职能。据介绍，数据交易链的建设工作的启动，进一步贯彻落实了《关于构建数据基础制度更好发挥数据要素作用的意见》，积极响应了《数字中国建设整体布局规划》。  
  
目前，上海数据交易所数据交易系统建立了登记、挂牌、交易、交付、清结算和凭证发放六大业务环节，通过建立数据交易链，利用区块链存证和智能合约等技术使这些业务环节更加安全、高效和透明。  
近期，大数据流通与交易技术国家工程实验室与上海数据交易所汇同国内主要区块链科技企业、行业研究单位、头部区块链应用和建设单位以及相关业内资深专家学者围绕基于区块链技术的数据要素安全流通建设方案进行了多次探索和深度交流，形成了建设数据产品全链路存证及未来跨链技术方面的共识。由此，大数据流通与交易技术国家工程实验室与上海数据交易所经与国内行业专家学者、主要区块链科技公司、专业交易系统建设企业以及数据安全科技企业等合作方就建设目标实施步骤等完成了策略规划和落地方案，并正式启动了数据交易链的首期建设工作。  

据悉，数据交易链本期建设工作由大数据流通与交易技术国家工程实验室与上海数据交易所联合上证所信息网络有限公司、上海数据发展科技有限责任公司、上海信息投资咨询有限公司、上海数字产业发展有限公司、**奇安信科技集团股份有限公司**等各方专业公司共同完成。

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)作为网络安全领军企业，奇安信很早就在数据安全领域进行全面产品布局，在咨询规划、客户需求响应及创新、产品体系布局、组织架构变革等方面全面发力，在数据安全赛道上牢牢占据着领头羊的地位。根据2月27日奇安信发布的2022年度业绩快报公告显示，公司实现营业总收入66.3亿元，较上年同期增长14.13%。其中公司数据安全产品收入增速超55%，大大超越行业平均增速。在工信部下属机构发布的数据安全服务前十企业名单中，奇安信集团成功入选并位列第一。IDC等机构发布的相关报告显示，在数据安全方面，奇安信市场份额领跑网络安全厂商。
