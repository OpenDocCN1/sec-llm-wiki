# 奇安信签约新一代人工智能开源开放平台 护航开源AI

![](../Images/a2a539e4517adc9d5e231fd2ec7b3dac.png)2月24日，在由鹏城实验室、新一代人工智能产业技术创新战略联盟（AITISA）主办的第四届OpenI/O启智开发者大会上，作为国家新一代人工智能开放创新平台的建设单位之一，奇安信与新一代人工智能开源开放平台——OpenI启智社区正式牵手。**奇安信****将****充分发挥“软件安全国家新一代人工智能开放创新平台”****在软件开发、软件应用、安全分析等方面的平台及技术优势，与启智社区共同打造我国人工智能开源生态新局面**。

![](../Images/9aebfa1bfa480878bfed303cee91cfe4.png)

2022年，奇安信获批建设[**“软件安全国家新一代人工智能开放创新平台”**](https://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247578144&idx=3&sn=96232779f23a19f118f0d2d61574b1b6&chksm=fb779424cc001d32f8a21e189eb44aed0f4c844567b6ec39a5b7edf5f1f6a820efe45e5e92e5&token=617432448&lang=zh_CN&scene=21#wechat_redirect)，正式跻身“人工智能国家队”。相关负责人介绍，平台的**目标是解决海量复杂软件的安全问题，持续研究基于人工智能快速发现软件安全问题的方法，以夯实我国数字经济的基础**。平台支持创新创业，带动行业内的企业和个人共同研究运用人工智能解决软件安全问题。  
  
截至2022年，奇安信拥有187项网络安全领域的人工智能相关专利，是目前拥有最多相关专利的网络安全企业。这些专利技术，将在软件安全国家新一代开放创新平台的建设过程中发挥重要作用。  
我国开源技术正处于蓬勃发展阶段，需要多方参与，共同推进开源生态安全平稳发展。此次合作，**奇安信将助力OpenI启智社区****为软件开发用户、软件应用用户及安全分析用户提供代码智能安全检测服务、风险智能判别及处置服务、安全智能分析算法的训练服务**。

  

据悉，**“新一代人工智能开源开放平台”**是国内首个人工智能开源平台，通过开源社区的形式，把国内人工智能研究力量、科研院所、企业组织起来，形成汇聚各种研发和产业力量的开源开放平台，共同促进人工智能开源生态建设，对于强化开源开放和政策引导，构建开放协同的人工智能科技创新体系具有重要意义。新一代人工智能开源开放平台与八个国家级新一代人工智能开放创新平台的集中签约，将引入国内人工智能各产业的坚实力量，共同为我国人工智能开源生态作出积极贡献。
