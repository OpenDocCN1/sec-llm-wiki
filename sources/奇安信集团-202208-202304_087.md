# 民营企业社会责任报告发布 齐向东入选优秀企业家

2月21日，全国工商联发布《中国民营企业社会责任报告（2022）》和《中国民营企业社会责任优秀案例（2022）》，**奇安信集团董事长齐向东入选优秀案例企业家。**

![](../Images/e6e2332d3afb060898c7faa8c7f62f8b.png)

据介绍，《中国民营企业社会责任报告（2022）》的数据来源于全国21112家民营企业参与的问卷调查和11个省市近百家民营企业的实地调研，对企业社会责任工作进行量化分析。  
《报告》指出，2021年，面对新型冠状病毒感染疫情反复冲击和复杂严峻的国内外形势等诸多风险挑战，我国民营企业深入贯彻新发展理念，主动融入新发展格局，以共同富裕为企业社会责任价值目标，对我国经济社会可持续发展发挥的作用日趋显著。  
作为中国网络安全领域的龙头企业，奇安信集团一直将国家与社会安全作为企业发展之本，树立了“让网络更安全，让世界更美好”的愿景。奇安信利用自身技术优势，参与并圆满完成多个国家重大活动的安全保障任务。同时，在抗击新冠疫情、推进数字化党建、践行社会公益等方面，奇安信始终以守护网络强国为责任，促进社会数字安全的公平与保障，履行守护美好生活的使命。  
企业家是领导企业攻坚克难的带头人，更是推动经济社会可持续发展的生力军。**作为奇安信集团的“掌舵人”，齐向东扎根网络安全行业数十年，提出了“数据驱动安全”“内生安全”“经营安全”“网络安全零事故目标”等先进理论，形成了系列安全产品和解决方案。带领奇安信圆满完成了北京冬奥会和冬残奥会网络安全保障任务。不仅创下了冬奥网络安全“零事故”的世界纪录，还打造了由“中国模式”“中国产品”“中国服务”“中国架构”组成的网络安全“中国方案”，并进一步面向金融、通信、医疗等重点行业落实基于“零事故”标准的产品、技术、服务和方案，提升关基行业网络安全能力建设。**  
目前，奇安信不仅在人员规模、收入规模和产品覆盖度上均位居行业第一，多年蝉联“中国网安产业竞争力50强”榜单第一名。自成立以来，奇安信在网络安全人才培养、乡村教育、健康医疗、乡村振兴等领域累计捐赠公益资金超过5500万元，累计捐赠网络安全产品超过2656万元，发动企业内外部志愿者超过9432人次，累计专业志愿服务时长超过9万人天。为包括冬奥会、二十大、建党百年、进博会等在内的近百场重大国家活动提供网络安全保障志愿服务，为全国超过31万所企业提供了免费的漏洞挖掘，开展各种社会网络安全公益宣传教育覆盖超过1700万人次，帮扶困难群众超过4万人次。![](../Images/5d8e6c69ce3abeb857e54b88f4e28633.png)奇安信已经将国家安全、行业进步、社会和谐融入自己的发展血液之中，正如齐向东所说，社会责任是企业的立身之本，创新是企业发展的第一动力。**“只有真诚回报社会、切实履行社会责任的企业家，才能真正得到社会认可，才是符合时代要求的企业家。”**
