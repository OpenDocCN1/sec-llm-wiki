# IE、Chrome、Edge浏览器接连“断供” 政企客户该如何应对？

2022年12月，Google、微软相继公告，2023年2月初即将正式发布的110版Google Chrome浏览器和微软Edge浏览器不再支持Windows 7/8/8.1操作系统。

  

这就意味着，两款主流浏览器将对Windows7等操作系统“断供”，Windows7等操作系统将无法再获得两款浏览器的安全更新。考虑到Chrome、Edge浏览器的漏洞发布及修复机制，企业存在较高的感染病毒和恶意软件的风险。

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)![](../Images/89edfb8893d7a2121579299a8218ad44.png)  

同时，企业还面临另一浏览器“断供”事件。早在2022年6月15日，微软就宣布正式停止对 IE的支持，官方将不再进行安全漏洞维护和相关补丁更新。但微软发现即便停止对IE的支持，用户依旧热情不减，继续使用IE浏览器进行业务访问。于是2022年10月份，微软再次提醒用户，将通过 2023 年 2 月14日的累积安全更新，在 Win10 中删除并永久禁用 IE 11。这意味着，此后用户将无法再通过技术手段重新激活并使用 IE 11。

  

此外，2022年10月25日，谷歌发布Chrome107版浏览器，终止支持所有平台上的NaCL、PNaCL以及PPAPI接口，由此导致依赖于此类插件技术的业务系统发生业务中断事件。

  

## 奇安信可信浏览器负责人田亮表示，“当前，浏览器已不单单是一款应用软件，它已成为企业办公的基础支撑平台，这一系列浏览器‘断供’事件给广大国内政企客户带来了一个重大提醒：针对个人用户的浏览器频繁停服以及技术断供，会给政企客户的正常办公带来巨大影响。浏览器‘断供’应该引起主管单位和相关企业足够重视，并及时采取应对策略，避免断供后导致的业务中断和数据安全等风险。”

![](../Images/59b16c7efe07b4a5f2c617feb18dcda2.png)  
奇安信可信浏览器是奇安信专门面向政企客户推出的安全可信的统一业务承载平台，它通过广泛的兼容适配、内生的安全特质、便捷的统一管理、流畅的应用体验，大幅提高整体办公效率，为业务高速发展保驾护航。  
针对浏览器技术断供问题，奇安信可信浏览器持续支持各款Windows操作系统（Windows XP - Windows11）和各类插件技术（ActiveX、PPAPI、NPAPI、NaCL、PNaCL、Native Messaging），保证业务访问的连续性。日前奇安信已发布基于最新Chromium110内核版本的可信浏览器产品，延续对各类操作系统平台和插件技术的长期支持。  
同时，奇安信可信浏览器集成双内核引擎，兼容IE6-11和Chrome内核，无缝支持各类新旧业务系统平滑访问。通过奇安信可信浏览器管理平台，管理员可统一控制浏览器客户端的内核访问策略，当浏览器客户端访问到指定系统时，便会根据策略要求自动进行内核切换，保障业务访问的流畅性。  
此外，奇安信可信浏览器具备统一升级部署、统一策略配置、统一安全管控能力。通过浏览器管理平台，运维人员可以对客户端进行统一升级管理，解决个人版浏览器不受控升级导致的业务访问中断风险；也可实现浏览器证书下发、插件下发、可信网站设置等统一管理功能，满足终端用户免配置，即开即用，流畅访问办公系统的办公体验。  
值得一提的是，随着信创政策推进，企业同时面临基于IE内核开发的业务系统无法快速完成信创迁移，业务系统无法在信创终端正常访问的问题。奇安信可信浏览器团队重磅打造的远程渲染解决方案可以保证用户在信创终端无缝访问原有基于IE内核开发的业务应用系统，帮助客户大幅缩短信创业务改造周期，解决政企用户在信创终端替换中业务系统改造周期长，投入大的难题。此方案已在银行、电力、运营商等领域上线应用。  
![](../Images/5ac0ec27d8091c0e270ae4eae0615642.png)  

基于奇安信浏览器远程渲染技术的《金融行业信创过渡期终端安全建设方案》已先后荣获工信部颁发的《2020年信息技术应用创新解决方案》、中关村可信计算产业联盟颁发的《2022年度首届安全可信优秀解决方案》。

目前，奇安信可信浏览器已经广泛应用于党政、金融、石油、电力、电信、交通、航空航天、医院、教育等行业，以及外交部、教育部、科技部、工业和信息化部等26个国家部委，成为千万终端的业务访问入口，并获得了广大用户的一致好评。
