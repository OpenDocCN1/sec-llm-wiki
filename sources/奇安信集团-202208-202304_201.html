国内首家！奇安信可信浏览器率先升级至Chromium110内核

2023年1月3日，奇安信正式推出了基于Chromium110内核的奇安信可信浏览器先锋版，成为国内首家升级至Chromium110内核的企业级浏览器供应商，再次实现了国产浏览器与业界最前沿Chromium内核的紧密同步。


相比于102内核，本次更新在浏览器功能、产品性能、资源占用及安全能力等方面均有显著提升，以更贴近用户应用场景为出发点，新增更多实用功能，为广大政企客户带来浏览器的极致体验。此次升级，再次巩固了奇安信可信浏览器在国内政企浏览器赛道的领军地位。


在功能优化方面，奇安信可信浏览器新版本具备了预渲染机制，可以显著加快页面加载速度、减少资源占用。与此同时，该机制可大幅加强数据安全和用户隐私保护力度，保障了安全性和易用性之间的平衡。另一方面，奇安信可信浏览器还支持在可用于解码 HEVC 的硬件（例如：GPU、媒体加速器等）平台上解码 HEVC 视频。

在开发者层面，新版奇安信可信浏览器新增多项实用API接口。新的 API 允许开发人员自定义网页上的搜索界面，尤其可以修改与搜索对应的内容被突出显示的方式。同时Web 应用会得到更好的支持，并且会提供更接近原生应用所提供的体验。他们的标题栏将能够整合某些界面元素，例如搜索栏，并进一步个性化。

在安全层面，此次新版内核更新了目前已知的安全补丁，修复了多个已知高危漏洞，为广大政企用户筑起业务访问的第一道安全防线。

奇安信可信浏览器相关负责人表示，保持内核版本的稳定更新，是浏览器保证安全性、稳定性、性能、开发者等技术先进性的重要工作，也是衡量研发能力的重要指标。奇安信可信浏览器正是凭借其稳定的内核升级速度，始终保持着国内政企浏览器赛道的技术领军地位。

一直以来，奇安信可信浏览器以“多方兼容、统一管理、内生安全”为设计理念，提供针对业务系统的兼容能力，针对浏览器客户端的统一配置管理、统一行为管理和统一安全管理能力，为政企用户提供专业的业务承载平台。

奇安信可信浏览器已经广泛应用于党政、金融、石油、电力、电信、交通、航空航天、医院、教育等行业，以及外交部、教育部、科技部、工业和信息化部等26个国家部委，成为千万终端的业务访问入口，并获得了广大用户的一致好评。

目前，已更新至Chromium110内核的奇安信可信浏览器先锋版已在麒麟应用商店上架，可供广大用户和开发者下载体验。
