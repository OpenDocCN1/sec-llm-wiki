# 奇安信与南京信息工程大学深化校企合作 共建网络安全英才班

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247580160&idx=2&sn=efec6b11f1c7c561b11b859ae5eee5a9&chksm=fb779c04cc0015121f3660b99d9a61713b98172a255e36f9673416bc1eeacf7a247563b369af&scene=126&sessionid=1681373257#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247580160&idx=2&sn=efec6b11f1c7c561b11b859ae5eee5a9&chksm=fb779c04cc0015121f3660b99d9a61713b98172a255e36f9673416bc1eeacf7a247563b369af&scene=126&sessionid=1681373257#rd)

近日，奇安信集团与南京信息工程大学举行共建网络安全英才班暨深化校企合作签约仪式。双方将共建“南信大—奇安信数字取证联合研究院”、“南信大—奇安信网络安全创新创业实验室”，开设奇安信网络安全英才班。同时，双方将共建“数字取证教育部工程研究中心”。

![](../Images/ea423f07a266d4db0eeedd0962f69829.png)

![](../Images/7a54a2b08068b8912d290519c9879423.png)

中国科学院院士王金龙，江苏省委网信办副主任王万军，江苏省公安厅网络安全保卫总队监控支队政委张久栋，南信大党委书记管兆勇，副校长韦忠平、陈海山，奇安信集团总裁吴云坤，副总裁韩争光、陈明，江苏总经理梁辉，南信大相关职能部门、学院负责人，导师代表，奇安信集团员工代表，计算机学院师生代表，奇安信英才班学生代表出席大会。大会由陈海山主持。

成立网络安全英才班是南信大在信息工程领域创新人才培养的又一重大举措。**中国科学院院士王金龙**表示，南信大信息工科实力强劲，近年来重点开展了信息工科拔尖人才培养模式的改革探索，在探索产教、科教双融合路径上取得了显著成效。他希望双方进一步深化合作，通过强强联合共建网络安全英才班，积极打造网络空间安全领域的校企合作典范，培养一批批优秀的网络空间安全人才，助力国家网络空间安全事业的发展。

![](../Images/b2157b11c94cbc4dde932c3e7621482d.png)

**江苏省委网信办副主任王万军**对此次合作表示祝贺。他表示，信息安全等相关专业的学生，是我省网络安全战线上未来的生力军，培养更多更好的专业人才尤为紧迫。南信大学科发展态势喜人，为社会培养了大批信息安全业务骨干。奇安信集团长期深耕网络空间安全市场，已发展成为国内领先的基于大数据人工智能和安全运营技术的网络安全供应商。期待双方在产教融合深度协同的道路上再谱新篇，在网络安全人才培养领域多结硕果。

![](../Images/5f9ce18416c14e7de75331b56312509e.png)

**南京信息工程大学党委书记管兆勇**表示，南信大一直积极探索分类多元的拔尖人才培养实践，重点开展信息工科拔尖人才培养模式的改革探索，着重发挥校企优势，探索产教、科教双融合的发展路径。希望通过本次深入合作，双方能够突破传统路径，充分发挥各自优势，整合优质教育、行业和产业资源，布局未来网安人才培养，为网络强国建设提供坚强人才保障，更好地服务国家网络空间安全战略。

![](../Images/6c6375ba14ba71c5c96cbb93556cce8e.png)

**奇安信总裁吴云坤**对南信大给予的信任和支持表示感谢，并就此次校企合作提出两点展望：一是立足高端人才培养，共同打造满足国家战略需求的网络安全人才培养平台，通过主办网络安全英才班，举办全国电子数据取证大赛等方式，持续培养高端网络安全人才；二是致力前沿技术攻关，联合进行数字取证等领域的先进技术研究及成果转化。希望通过双方的全面合作，能够为我国网络安全人才培养和网络安全前沿技术研究树立校企合作典范。

![](../Images/e7fe501dec87bfe74d17d369ba844d6d.png)

签约仪式上，“南信大—奇安信数字取证联合研究院”、“南信大—奇安信网络安全创新创业实验室”揭牌，奇安信网络安全英才班正式开班。管兆勇为奇安信网络英才班导师代表颁发聘书。奇安信集团副总裁韩争光作为英才班导师代表发言。

![](../Images/75d631f4b15e97dd3837e3c329d97e99.png)

韩争光表示，奇安信网络英才班的建设，将面向新工科未来必争的领域人才需求，以国家网络空间安全战略及产业需求重点产业链、核心信息技术集群需求为前提，共同开展数字取证新型人才的培养。奇安信也将提供导师、平台、实习、就业等机会，实现真正的学以致用，战训一体，为国家网络安全与数字取证领域培养真正的实战化人才。

![](../Images/fa9aab0bf5309c07aa1944949ed9aef5.png)

会后，双方进行了座谈，共同研讨网络空间安全学科的发展，并就双方相关合作事宜及奇安信网络英才班培养方面进行了深入交流探讨。

![](../Images/90fda5c728d6af1f3ca86899a3b08cc8.png)

![](../Images/45e2741bcf784f8b538af5a6a1b2125b.png)

据悉，网络安全英才班主要通过高考优录及全校考核相结合的方式组建而成，以培养满足国家网络空间安全战略及顶尖安全企业的人才需求为导向，面向数字取证、网络安全、司法鉴定等培养方向，双方共同完成全日制授课，通过扎实的理论和丰富的实训案例，有效推进专业人才培养。
