# 18家CA厂商！奇安信可信浏览器助力国密生态腾飞

**近日，山西省数字证书认证中心、四川省数字证书认证管理中心、卓望数码技术（深圳）有限公司、南京数字认证有限公司等4家CA厂商通过了“商用密码证书可信计划”联合认证。**

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)

**该项计划由奇安信可信浏览器联合麒麟、统信两大操作系统发布，自2021年8月发布至今，已累计超18家CA厂商通过该项认证，携手共同发展壮大国密数字证书体系，助力国密生态飞速发展！**  

作为网络业务访问的安全基石，数字证书的运用已日趋普遍，2020年1月1日我国《密码法》正式实施，国产自主的商用密码体系建设已步入快车道，同时，随着信创生态持续健全、技术环境日趋成熟，信创系统正加速应用，基于国产商用密码的数字证书将在信创领域得到更为广泛的运用。

  

当前，信创操作系统、浏览器预置国产商用密码数字证书进度仍然较慢，导致国产密码证书信任体系未被市场广泛接受，绝大多数业务系统、网站仍未采用我国CA机构签发的国产密码证书，信创环境下业务访问因此而缺失安全可信的信任基础。

  

为加速国产密码推广应用，推动基于国产密码数字证书的信创环境安全访问体系持续完善，奇安信可信浏览器联合麒麟、统信两大操作系统共同发起“商用密码证书可信计划”。本计划公开接受国密数字证书发布机构入根申请，经审核并认证通过为受信的数字证书，可被默认预置于奇安信可信浏览器及操作系统使用，并向受信数字证书发布机构颁发《商用密码根证书受信证明》。

  

**![](../Images/f1a84029c4876d2993a9b959d7a7474a.png)**

  

## 相关人士表示，“商用密码证书可信计划”发布后，奇安信持续运营并推动国内主流CA厂商加入，对国产密码证书的落地使用、普及推广起到巨大的推动作用，也对我国CA机构的繁荣运营提供了有力支撑。

除上述4家新通过联合认证的CA厂商外，另外通过的14家国内主流CA厂商包括：北京数字认证股份有限公司、上海市数字证书认证中心有限公司、数安时代科技股份有限公司、深圳市电子商务安全证书管理有限公司、中金金融认证中心有限公司、陕西省数字证书认证中心股份有限公司、吉林省安信电子认证服务有限公司、北京天威诚信电子商务服务有限公司、安徽省电子认证管理中心有限责任公司、贵州省电子证书有限公司、广东省电子商务认证有限公司、江苏省国信数字科技有限公司、亚数信息科技（上海）有限公司、福建省数字安全证书管理有限公司。  

  
![](../Images/6943818fdb39dd36979d80d828fd3ee0.png)

目前，奇安信可信浏览器已经广泛应用于党政、金融、石油、电力、电信、交通、航空航天、医院、教育等行业，以及外交部、教育部、科技部、工业和信息化部等26个国家部委，成为千万终端的业务访问入口，并获得了广大用户的一致好评。
