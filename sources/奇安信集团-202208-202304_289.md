# 招募令|香港警务处联合奇安信开展粤港澳（大湾区）网络攻防菁英培训

*由香港警务处及其下属网络安全及科技罪案调查科（CSTCB)主办，澳门司法警察局、香港CTF协会、奇安信协办的粤港澳（大湾区）“网络攻防菁英培训2022/23”，正在招募大湾区有志于在网络安全领域发展的青少年参赛。*

  
  
  
  
![](../Images/b4c123cc149ee2d88b4dd2d3f936d427.png)![](../Images/629b6bfb721e938322dde5ccee609898.png)  
“网络攻防菁英培训2022/23”是香港警务处下属网络安全及科技罪案调查科牵头举办的大型网络安全推广活动，目的旨在通过网上互动游戏及网络攻防比赛，提升粤港澳大湾区14至24岁青少年对网络安全的知识，推广网络安全“零信任”(Zero Trust) 的概念，加强大湾区人才及组织在网络安全领域的协作，并为有志投身网络安全的青少年提供“职业生涯规划”，发掘网络安全人才。  
“网络攻防菁英培训2022/23”即将进入活动宣传推广阶段，该活动分别在香港、澳门、广州三地举办，分别由香港警务处、澳门司法警察局、奇安信承办。**如果你是在大湾区的网络安全有志青年，欢迎前来报名：**
