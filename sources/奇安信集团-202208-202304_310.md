# 奇安信荣获“2021-2022中国互联网行业自律贡献和公益奖”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247578144&idx=6&sn=109817f0df2a743d7cc26c508ca28315&chksm=fb779424cc001d32737142ac5700a104f234c340c2e63d327ee658e0ffd9fa4af093be2558a3&scene=126&sessionid=1681373272#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247578144&idx=6&sn=109817f0df2a743d7cc26c508ca28315&chksm=fb779424cc001d32737142ac5700a104f234c340c2e63d327ee658e0ffd9fa4af093be2558a3&scene=126&sessionid=1681373272#rd)

11月17日，在2022中国互联网大会闭幕式上，中国互联网协会为在推动行业自律、履行社会责任、热心社会公益等方面表现突出的企业颁奖。继获得[“2018-2020年度中国互联网行业自律贡献和公益奖”](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247516361&idx=1&sn=daf3a01a660a8a30c12ba775cc5d903d&chksm=fb76a6cdcc012fdb42c19cb93461d8304721e86cd80bd5b4c76d15350360497b991c086f67ac&scene=21#wechat_redirect)后，奇安信蝉联“2021-2022年度中国互联网行业自律贡献和公益奖”。

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)  

![](../Images/1f8d739564bdd2391b18f7b95ba7f2bd.png)

据悉，本次“中国互联网行业自律贡献和公益奖”由中国互联网协会组织，旨在为表彰互联网从业单位在推动行业自律，净化网络环境，保护未成年人健康成长，积极履行社会责任，热心社会公益中所做出的努力和贡献，促进我国互联网行业健康和谐发展。

  

作为网络安全行业的领军企业，奇安信一直高度重视自律建设，积极投身社会公益，持续推动行业建设。

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)

*   **严格打造集团内部自律，做好安全表率。**奇安信一直高度重视集团内部安全管理及保密工作。通过不断完善各项安全和保密制度，并严格执行日常监察与管理，并在内部举办各种网络安全和保密教育讲座、培训和演习，增强公司员工的安全及保密意识和观念。
    

  

*   **做好行业“领头雁”，保障国家网络数据安全。**两年来，奇安信不仅为包括全国两会、建党100周年庆祝大会、服贸会、世界互联网大会乌镇峰会等在内的超过11场国家重大活动提供网络安全保障服务，并创下了北京冬奥会网络安全“零事故”的成绩。
    

  

2022年3月，奇安信组建了“零事故经验宣讲团”，总结冬奥网络安全成功经验，形成网络安全“中国方案”，面向金融、交通、民生、医疗、教育、水利、电力、工业制造等十余个行业的主管单位、政企机构、行业企业，1600余家单位、近6000人次分享了冬奥网络安全“零事故”的成功经验；冬奥网络安全保障指定号码95015在赛后永久服役，为全国各地政府、企业、相关机构提供冬奥标准的网络安全应急响应服务。

  

*   **积极创新，持续投身社会公益。**为更好履行企业社会责任，2021年，奇安信成立北京奇安信公益基金会，发起“心安工程”，从医疗健康、教育助学、灾害救助、扶农助农4个方向践行公益慈善。在疫情救助方面，奇安信不仅向香港、吉林、福建、北京、内蒙古等疫区捐赠防疫及生活物资；并号召组织志愿服务，累派出志愿者超过300人，协助核酸检测筛查超2万人。
    

  

2021年，奇安信还联合人民网、中国传媒大学发起“红色云展厅”，将各革命老区的革命博物馆、纪念馆等内容数字化，创新助力党建扶贫。在人民网微博、微信、党史学习教育官微等平台，“红色云展厅”陆续推出红色场馆文物背后的党史故事，全网总计访问量超过20亿，互动量超过50万次。  
![](../Images/6943818fdb39dd36979d80d828fd3ee0.png)

**奇安信集团董事长齐向东表示，集团将不断加大科技创新力度，积极做好行业自律和责任担当，为奋力开创互联网产业高质量发展贡献更大力量。**
