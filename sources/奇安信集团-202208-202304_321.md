# 打造城市下沉标杆 奇安国投500万中标湖北某市安全运营中心项目

近日，由奇安信集团和宜昌产投集团联合成立合资公司奇安国投中标湖北某县级市智慧城市采购项目（城运中心安全运维项目），项目总额超过500万。

该项目的落地，充分证明了奇安信在县市级建设城市安全运营中心的可行性，更突出了公司对城市安全运营布局的前瞻性和战略性，为将来在县级市等下沉市场开拓和推广，提供了高质量、可借鉴和复制的落地标杆。

![](../Images/47378bf0f2c0e3737f7410f704049208.png)

该县级市位于湖北省中部，近年来，该市深入推进政府数字化建设，不断创新智慧政务服务模式，坚持推进“一体化”的新型智慧城市之路，充分整合各部门现有信息网络资源，做好全市一盘棋，强力统筹建设该市的“部门小脑”。在此基础之上，该市相关领导意识到，需要尽快完善网络安全运营体系，为城市数字化转型保驾护航，在信息安全方向做“创新与创造”。

  

因此，该市政数局邀请了奇安信集团合资公司奇安国投进行安全运营方案的规划和设计，通过多方讨论、专家评审及领导汇报，最终认可了奇安国投的城市安全运营方案。该市也因此获得上级行政单位相关领导的多次肯定。

  

据悉，该项目涉及安全产品比较广泛，包括奇安信旗下态势感知与安全运营中心（NGSOC）、椒图、蜜罐、天擎、可信浏览器、智慧防火墙等产品，涵盖了态势感知、主机防护、攻击诱捕、终端安全、边界安全等领域，基于顶层视角和全局规划，解决了以往网络安全离散化、碎片化、单点化的突出问题，形成全域的安全防护体系建设。

  

作为该项目的中标主体，奇安国投是奇安信和宜昌产投集团成立的合资公司，从成立之初，就承担起建设城市安全运营中心的使命。相关负责人表示，目前城市安全运营中心在一、二线城市已经逐步开展，但在县级市尚处于探索阶段，该项目的落地，为县级市建设城市安全运营中心提供了很好的示范作用和借鉴意义，值得向其他县级单位广泛推广和复制。

  

据悉，早在2020年，奇安信就和长沙市政府合资成立了奇安星城公司，共同打造长沙网络安全运营中心。目前，奇安信正在长沙、广州、宜昌、宜宾、德阳和宿州等城市中，配合协助当地政府网信、数据资源管理等部门进行系统性的城市级网络安全规划与建设工作，并已经取得了阶段性成果。在2022BCS北京网络安全大会发布的“星城”城市网络安全运行平台2.0，未来将在北京和全国多个城市也将逐步落地。
