# 乌镇时间开启 奇安信亮相2022世界互联网大会

11月8日，2022年世界互联网大会“互联网之光”博览会在浙江乌镇开幕。奇安信集团携网络安全“中国方案”等重磅内容率先亮相，未来两天，还将深度参与主题论坛及多项特色活动。

![](../Images/47378bf0f2c0e3737f7410f704049208.png)

![](../Images/c24435b76741b62ca949018f99484c8a.png)

![](../Images/47530a5968d5dcc5f6fb5a91d471d231.png)

****乌镇亮声****

****共话网络安全前沿观点****

![](../Images/47530a5968d5dcc5f6fb5a91d471d231.png)

**奇安信集团总裁吴云坤**将应邀出席9日举办的“互联网企业家论坛”和“数字技术论坛”，围绕国际市场开拓，及数字技术创新发展相关主题进行分享，为维护全球网络空间安全贡献中国力量、分享中国经验。

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)

![](../Images/4394d5da18ce9eb90e80ad2daafcdc7a.png)

  

**奇安信集团首席战略官兼副总裁刘勇**将出席“网络安全技术发展与国际合作论坛”和“开源技术生态创新发展”论坛，围绕新形势下数据安全合规治理，及开源软件安全进行分享。

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)

![](../Images/ca81aa6282adcda7f568c4ffac92e5a9.png)

![](../Images/47530a5968d5dcc5f6fb5a91d471d231.png)

****参展、办赛****

****全面展示安全实力****

![](../Images/47530a5968d5dcc5f6fb5a91d471d231.png)

第四次亮相“互联网之光”博览会，奇安信集团携冬奥网络安全保障“零事故”实战检验的网络安全“中国方案”亮相。

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)

![](../Images/9a69c0ce6b4cd0469d2bbe58906b5128.png)

除展示冬奥网络安全保障过程中创新总结的“中国产品”“中国架构”“中国服务”“中国模式”外，奇安信还以多种形式展示PKS体系中的安全融合，全面展示立足打造信创安全产业新高度，引领安全产业的快速发展和担当国家信创安全品牌的形象。

  

![](../Images/8f5e4061116329f9e4cfe4a5d13d2ada.png)

  

作为大会专题活动之一，11月9日，**“之江杯”数据分析与治理大赛启动仪式暨专家研讨会**将在乌镇峰会期间举办，大赛由浙江省委网信办、浙江省大数据发展管理局、中国网络空间安全协会指导，中国电子信息产业集团有限公司、之江实验室、浙江省网络空间安全协会、杭州未来科技城（海创园）管理委员会主办，杭州电子科技大学、浙江大学嘉兴研究院、奇安信集团承办，将挖掘更多数据创新典型案例。

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)![](../Images/56ebff739175aa8c9864721dd87a83e0.png)

  

据悉，作为世界互联网大会国际组织成立后的首届年会，本次乌镇峰会以“共建网络世界 共创数字未来——携手构建网络空间命运共同体”为主题，邀请120余个国家和地区的近2000位代表，以线下或线上形式共同围绕大会主题展开交流，为网络空间命运共同体建设献智献策。
