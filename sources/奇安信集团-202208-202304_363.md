# 奇安信与上海交大达成战略合作 打造一流网安创新和产业应用平台

11月3日，奇安信集团与上海交通大学签约仪式在2022补天白帽大会上举行。双方将成立**“上海交通大学电子信息与电气工程学院-奇安信信息系统安全联合实验室”**（简称信息系统安全联合实验室），开展信息安全领域技术研究和应用基础研究工作，共同推进信息系统安全领域的技术创新与产业发展。

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)

![](../Images/1e6fbd74dcaefa95690a64cb4afcf79c.png)

**上海交通大学党委书记杨振斌、奇安信集团总裁吴云坤共同为信息系统安全联合实验室揭牌，上海交通大学网络空间安全学院院长谷大武、奇安信集团副总裁、奇安盘古CEO韩争光作为双方代表签署协议。**

  

![](../Images/c8de1a5bbbcf347a684f8beae81d187b.png)

网络空间的竞争，归根结底是人才的竞争。工信部近日印发的《关于加强和改进工业和信息化人才队伍建设的实施意见》中提出，发挥科技领军企业、部属高校、部属科研院所等作用，组织产学研协同攻关，在人才梯队配套、科研条件配套、管理机制配套方面给予特殊政策，加快关键核心技术突破。

  

![](../Images/321fc97e35824d23708429fe0915e971.png)“联合实验室将充分发挥顶尖院校和龙头企业的人才及技术优势，共同推进信息系统安全领域的技术创新与产业发展。”** 上海交通大学党委书记杨振斌**表示，将通过建立开放、高效的管理体制和运行机制，集聚与培养一批网络安全领域的顶尖人才，力争在网络安全基础理论、关键核心技术及产业应用等领域，取得一批国际先进水平的重大标志性成果。用共同眼光、共同坚持和共同责任，创造一流的科研成果，培养一流的创新人才。

  

![](../Images/a567b582461b02e0faf5c47beb57a5e6.png)**上海交通大学教授、联合实验室主任薛质**介绍，信息系统安全共建实验室将搭建联合研究平台，支持信息系统安全领域的基础研究和应用基础研究工作。围绕安全基础理论研究、软件分析和漏洞挖掘、网络安全监测和防范、网络攻防对抗演练、物联网安全性分析、数据隐私安全合规、联合教学实践等方向展开深入合作，并推进相关技术成果的落地应用。

上海交通大学电子信息与电气工程学院是全国高校规模最大的同类学院之一，师资力量雄厚，并始终瞄准国际前沿科技，对接国家重大需求，加强创新平台和团队建设，为国家重大战略需求和社会经济发展做出应有贡献。  

  

奇安信作为国内最大的网络安全公司之一，一直高度重视产学研合作，并以高层次高质量网络安全人才培养为目标，充分发挥网络产业实际工程引领作用，在全国形成一批具有示范性的高层次人才培养新模式。此前，奇安信已与清华大学网研院、中科院软件所、山东大学、中国海洋大学等科研院所及高校成立联合实验室及联合研究中心。

  
奇安信集团副总裁奇安盘古CEO韩争光表示：“联合实验室的成立，将基于交大电院的办学条件和特色，发挥奇安信在安全研究、产品技术、专家资源等方面的体系化能力，推进高水平校企联合专业建设和人才培养。”
