# 计算机安全专委会党的工作小组成立大会暨与奇安信集团联合党日活动成功举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247575745&idx=2&sn=c64739aeae06b7b9bcdc38f893314c50&chksm=fb778ec5cc0007d347451cb7329bae66ebb5220716466afe162c48ed870d3eec4db15ac7c1b1&scene=126&sessionid=1681373287#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247575745&idx=2&sn=c64739aeae06b7b9bcdc38f893314c50&chksm=fb778ec5cc0007d347451cb7329bae66ebb5220716466afe162c48ed870d3eec4db15ac7c1b1&scene=126&sessionid=1681373287#rd)

![](../Images/366e3938172309aabc4312c83bcd3515.png)

  

金秋送爽、丹桂飘香。**10月12日，中国计算机学会计算机安全专业委员会党的工作小组成立大会暨与奇安信集团联合党日活动在奇安信安全中心成功举办。**来自公安部、工信部、中国科学院、新华社、国家信息中心、航天科技集团、国家电网，以及国内网络安全头部企业代表参加本次活动。

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)

![](../Images/49930336661efe14a89e155d0324a551.png)

  

  
  
  
  

会议开始前，与会代表在奇安信集团党委书记齐向东的带领下，参观了奇安信集团荣誉展室，并了解集团党建情况。

  

会议由专委会副主任、中国科学院大学密码学院院长荆继武主持。首先，**专委会主任、公安部第一研究所副所长于锐**在致辞中指出：专委会党的工作小组的成立，是加强党对科技社团组织领导，扩大党的覆盖面和影响力的实际举措。从专委会工作角度，希望党的工作小组能够体现新时代新特点，突出政治功能，开拓创新，积极探索符合科技社团组织的活动形式和载体，发挥好功能性、监督性、创新性，让会员单位、委员充分理解和认识基层科技社团组织设立党的工作小组的目的和意义，积极地支持和参与工作小组各项工作和活动，真真正正把工作小组建设成为专委会内宣传党的立场，贯彻党的决定，团结动员党员群众，推动专委会工作创新发展的基层战斗堡垒。专委会也将全力支持党的工作小组的各项活动，完成好党的工作小组交办的各项任务。

  

![](../Images/6fcb6c5d54ad936cf1fd373df326b23c.png)

  

**奇安信集团党委书记、董事长齐向东**在致辞中指出：奇安信集团坚持发挥党建的领航作用，用高质量党建推动高质量发展。党的领导是信息安全事业的核心力量，党建是信息安全工作的活水源头。对于信息化领域的工作者来说，必须始终保持强大的战略定力，以党建为引领，把听党话、跟党走当成心里的一杆秤，把站稳政治立场、坚守政治底线当成做事的一把尺，以高度的使命感和责任感开展工作。奇安信也将继续强化党性修养，全力支持、配合专委会党的工作小组工作，推动党建优势进一步转化为发展优势。

  

![](../Images/f039019b8bedcc88d066cd176dce2b13.png)

  

随后，**专委会顾问委主任、公安部十一局原政委赵世强**宣读了计算机安全专业委员会党的工作小组成立决定：根据中共中央办公厅《关于加强社会组织党的建设工作的意见（试行）》《中国科协关于加强科技社团党建工作的若干意见》和中国科协学会党建工作精神，同意CCF计算机安全专业委员会组建党的工作小组的申请，并公布CCF计算机安全专业委员会党的工作小组的成员名单和分工。

  

![](../Images/211dde7593349b45a1eabffa0b6c9ac3.png)

  

根据决议，专委会副主任荆继武担任党的工作小组组长，专委会常务委员廖方宇担任副组长，专委会常务委员吴云坤、李雪莹、于晴担任委员。成员任期与CCF计算机安全专业委员会届期同步，CCF计算机安全专业委员会换届时党的工作小组应同步换届。  
随后，党的工作小组成员分别进行任职表态发言。**工作小组组长荆继武**表示，将带领党的工作小组支撑好专委会工作，做好联系群众的工作，积极团结会员企业，更好支撑专委会宣传党的政策。

  

![](../Images/7bf0276cea28f5358efd303e2ab760c7.png)

  
**工作小组副组长、中国科学院计算机网络信息中心原党委书记廖方宇**表示，将积极配合组长推进党的工作小组的各项工作，并与计算机学会、专委会一起探讨如何更好开展党建工作、服务党员、服务群众委员，更好地发挥出专委会特色。

  

![](../Images/3edf67e086f472b51b60347fca624921.png)

  

**工作小组成员、奇安信集团总裁吴云坤**表示，党的领导是网络安全和数据安全的重要和基础保障，不仅在顶层设计中发挥重要作用，也为网络安全和数据安全技术发展明确了方向。同时，要在党的工作小组领导下，提高政治站位、强化责任担当、坚持创新发展，打造领先的网络安全和数据安全技术和能力。

  

![](../Images/1f859034cd15ef058a58f0028529a2ef.png)

  
**工作小组成员、天融信科技集团董事长兼CEO李雪莹**表示，成立党的工作小组非常必要，将更好地发挥党建引领行业的作用，更好地促进专委会各项工作的开展，更好地保障国家网络安全建设工作。  
**工作小组成员、北京鼎普科技股份有限公司董事长于晴**表示，党的工作小组成立可以充分发挥党员先锋作用，为专委会发展做出更多支持和贡献，不断推动党建工作和网信安全工作紧密结合。  
在专题党课环节，**专委会荣誉主任、公安部第一研究所原所长严明**从计算机安全专业委员会的发展历程出发，详细讲解了我党对网络安全和信息化建设的一贯重视。他指出，上世纪八十年代起，我国开始对计算机安全广泛关注。中央也向公安部提出了关于相关安全和执法管理需求的研究要求。在中央和国家有关部门一系列举措的推动下，从上世纪末开始，我国的网信安全逐步进入快速发展阶段。

  

![](../Images/a8442633b0bbf7696f288dee8318dcd3.png)

  
  
1989年，中国计算机学会计算机安全专业委员会正式成立。作为中国计算机学会所属的计算机安全学学科和计算机安全保护、监察等应用领域的分支组织，安全专委会由我国计算机领域的党政军公检法和科研教育部门的专家、技术和管理人员组成。成员单位扩大到了公安、军队、机要、高校、科研机构和企业，以积极应对我国网络信息安全领域面临的各方面挑战。他强调，虽然目前关注网络与信息安全的学术机构越来越多，但都远不能适应我们国家网信安全科技交流的需要。专委会要积极适应国家和民族的需要，响应整个行业和学科的召唤，努力把网信安全的学术交流平台办好，打造成我国网信安全的高水平学术组织。  
  
与会代表也围绕党的工作小组成立意义、工作计划踊跃发言。大家纷纷表示，将认真学习，勇于担当，积极配合党的工作小组各项工作安排，提高自身能力和素质，积极履职尽责，在党的领导下，做好网络安全工作，形成新气象，实现新作为，取得新进步，实现新发展。  
  
![](../Images/8fc3782a436b5433b45be83f73eba40c.png)

会议结束时，与会代表集体合影，并共唱“没有共产党就没有新中国”，大会在铿锵的旋律中圆满结束。
