# 奇安信红色云展厅获评2021年“聚力首善共建文明”十佳优秀案例

近日，由首都精神文明建设委员会办公室组织的“2021年聚力首善 共建文明”主题活动优秀案例正式发布。由市委统战部推荐的**奇安信集团“红色云展厅”项目获评2021年“聚力首善共建文明”主题活动十佳优秀案例。**

![](../Images/ccc8cb85a2e6af1d89b1c1cdac6f6797.png)

  

**2021年，建党百年之际，奇安信集团联合人民网、中国传媒大学及全国百家红色展馆、数十家省市区广播电视台，共同推出“红色云展厅”。**通过5G、云技术，将百家红色场馆的党建党史、“四史”教育内容数字化，全景展示各地红色纪念馆、博物馆和学习教育基地中的珍贵红色文物，形成一座“云端”的红色展览馆，实现一屏看遍全国百家红色展馆，让更多人生动、准确地学习党史，从党史中汲取精神力量，探索建设新时代中国特色社会主义建设的新路径。

![](../Images/41d4d178e5efceffa02ab686f2ecd8a7.png)

**目前，全国已有237家展馆加入“红色云展厅”。在人民网微博、微信、党史学习教育官微等平台，“红色云展厅”陆续推出红色场馆文物背后的党史故事，全网总计访问量超过20亿，互动量超过50万次。**

  

今年以来，“红色云展厅”还走进校园。通过组织一次红色展馆网上参观、组织一次红色主题论坛、开展一次红色主题班团活动、上好一堂红色思政大课、开展一次红色主题征文、过好一次“红色传承”为主题的组织生活、举行一场红色校园跑、举办一场红色文艺演出、组织一次红色历史知识竞赛、产生一批红色文化研究成果等系列活动，讲好革命故事，传承红色基因，弘扬伟大建党精神。

  

  
  

奇安信集团党委书记、董事长齐向东表示，“红色云展厅”是党建与融媒体、云技术、云展厅技术与数字化深度融合一次创新尝试。未来，“红色云展厅”将继续以公益性方式，为线下红色展厅推送丰富的党史数字影音包，增强展播内容感染力和视听效果，打造更多党史教育新阵地，并确保网络安全，“党史不容篡改”。
