# 奇安信集团与华东石油工程达成战略合作 共同构筑石化油服网络安全体系

9月20日上午，奇安信集团与中石化华东石油工程有限公司（以下简称“华东石油工程”）达成战略合作协议。双方将在石化行业数字化转型过程中进行网络安全深度合作，包括整体网络安全建设规划、安全运营、前沿技术研究等方面。

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)

![](../Images/af6e28598267fb9d2bcd0f1cdf8e2230.png)  

本次战略合作协议由中石化华东石油工程有限公司副总经理李超、奇安信集团副总裁吕韬进行签署，中石化华东石油工程有限公司执行董事、党委书记粟开喜，奇安信集团总裁吴云坤作为见证。

## 根据协议，双方将在网络安全前沿技术研究，行业标准规范制定，网络安全专业人才培养，网络和信息系统安全防护产品应用，网络安全规划、咨询、实施、运营、维护和培训等安全服务方面进行交流合作，共同推进石化行业安全建设及研究。

签约仪式上，**中石化华东石油工程有限公司执行董事、党委书记粟开喜，奇安信集团总裁吴云坤**分别致辞，表达了双方对本次合作的期许和对未来的展望。在座谈交流会上，双方就网络安全前沿技术研究、整体安全建设规划、安全运营等方面达成合作意向。![](../Images/93e7b5384e4ea87d6cd70d45e3adf177.png)****粟开喜表示，****随着公司业务发展，在自动化、远程控制、数据等方面存在安全风险，需要加强安全防护措施、加强网络安全建设，从而进一步保障业务发展。奇安信集团是国内网络安全领军企业，希望通过此次战略合作，双方共同打造新的石化油服产业竞争力，推动油服体系网络安全创新发展。![](../Images/62f085cfcad1b6d5c8777f9bd8fe9dd8.png)****吴云坤表示，****华东石油工程目前发展是符合全球变革的趋势，数字化转型走的越快就越具备领先优势。奇安信将在与能源行业的合作过程中，通过业务与安全结合、信息化与网络安全并行，从而提供全面的、有效的、具备能源行业针对性的网络安全解决方案。奇安信集团将充分发挥网络安全领域技术优势，为华东石油工程提供更多支持，更好打造生态合作、提供专业解决方案、持续进行服务创新。做到使命必达、落地可靠。本次战略合作的达成将促进华东石油工程在石化油服体系的信息化安全建设，逐步促进石化油服的网络安全运营中心建设，从管理、技术、制度、流程、人员等多方面进行优化及改进。实现石化油服网络完全管理智能化、一体化，实现安全态势全感知、完全风险全预警、安全事件处置全流程。

![](../Images/f7851c245a660a7a51a44bd4d5e4d8fe.png)

  
**中石化华东石油工程有限公司**（以下简称“华东石油工程”）是中石化石油工程技术服务有限公司（股票代码：600871，以下简称“石化油服”）全资子公司。公司业务范围涵盖钻井、测录井、定向、固井、酸化压裂、地质导向、泵送射孔、油气增产、连续油管、信息环保及国际工程。形成了钻井、压裂、测录井、环保、地质工程一体化5大技术体系，包括超深井、页岩气井、火山岩油气井优快钻井技术、大位移海油陆采钻井技术、储气库井“一揽子”服务技术30余项优势技术。先后获得国家专利200多项，刷新4项中石化记录，多项成果获中石化、石化油服科技进步奖和专利奖。  
**中石化华东石油工程有限公司科技发展分公司**为中石化华东石油工程子公司，华东石油工程科技公司作为石化油服体系内专注于信息化产品研发及服务的高新技术企业，始终保持对新兴产业技术发展方向的跟踪，积极研发创新，定位于服务整个中石化工程板块的信息化建设，推动中石化工程板块的信息化加速发展。  

**奇安信集团**（股票代码688561.SH）作为新一代网络安全企业，一直专注于网络空间安全市场，为政府、大型央企用户提供新一代企业级网络安全产品和服务，并通过持续的技术、产品和服务创新，打造国家网络安全核心力量，为国家经济社会的数字化转型提供网络安全保障，为国家创新发展战略和科技创新保驾护航。2022年3月，奇安信作为北京冬奥会官方网络安全服务和杀毒软件赞助商，创下了“零事故”的世界纪录，并进一步总结了“零事故”的成功经验，形成了网络安全“中国方案”，重点面向关基领域企业和机关单位，提供实战化、可落地、可复制的网络安全技术方案，为我国关键信息基础设施、重要活动的网络安全保障工作打造模范样本。
