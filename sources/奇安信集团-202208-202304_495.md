# “关基条例一周年”专题研讨会成功举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDk0NTAwMw==&mid=2247573874&idx=1&sn=48bd286d0b14e69a9d002043d8a2a103&chksm=fb778776cc000e60f22090c3e64cb30aca5ad89d36942693abb394158788e9d12babb3698603&scene=126&sessionid=1681373303#rd](http://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247573874&idx=1&sn=48bd286d0b14e69a9d002043d8a2a103&chksm=fb778776cc000e60f22090c3e64cb30aca5ad89d36942693abb394158788e9d12babb3698603&scene=126&sessionid=1681373303#rd)

2021年9月1日《关键信息基础设施安全保护条例》正式实施，值此条例实施一周年之际，由《中国信息安全》杂志社与奇安信虎符智库联合主办的“关基条例一周年”研讨会今日在奇安信安全中心举行。多位**产、学、研领域一线**专家、研究学者、科技企业等专业人士参加，一同围绕关基安全保护工作推进的相关问题进行沟通与交流。

  
![](../Images/a2c856979a096f8f9fff1e8af5a2fe85.png)

  

![](../Images/9bf749d98528d7dd181681669317f8a9.png)

  

供应链安全是本次会议的热点问题之一，多位嘉宾认为实现自主可控将成为保障我国关键基础设施的重要着力点，针对这项议题，嘉宾就如何提升供应链安全能力，应对高端产品或组件的垄断与断供、组件投毒等问题进行了探讨。此外，与会嘉宾还围绕国内外关基政策、等保实施、中美竞合面临的关基挑战等议题进行了沟通与交流，并分享了条例实施后的实践经验与推进中遇到的问题与发现。  
本次研讨会由《中国信息安全》杂志社社长位华主持，中国科学院院士冯登国、网信办网安局供应链安全处杨皓、中国信息安全测评中心处长任望、中国电子标准化研究院网安中心技术咨询部主任孙彦、中国科学技术大学教授左晓栋、国家信息技术安全研究中心总师杨韬、中核集团科信部安全处处长钱勍、航天科工网信部处长赵龙波、国家工业信息安全发展研究中心检查评估所副所长孙军、中科院信工所网络安全防护技术北京市重点实验室总工刘玉岭、华北电力大学能源电力大数据研究院院长李建彬、奇安信集团解决方案中心副总经理黄凯等嘉宾出席研讨会。  
![](../Images/6943818fdb39dd36979d80d828fd3ee0.png)

2021年7月30日，国务院令第745号公布《关键信息基础设施安全保护条例》，2021年8月17日正式对外颁布，自2021年9月1日起施行。该条例的颁布标志着我国网络安全法律法规建设和安全保障工作进入到了一个新阶段。
