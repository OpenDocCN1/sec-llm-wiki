# 犇众信息助力移动安全联盟，共建移动安全生态

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MDA0MTYyMQ==&mid=2654402553&idx=1&sn=4ac39253f61c334d3bbdd30540feb433&chksm=f1ade903c6da6015ed171eab61920d1f916b6e65ee04c308dacf251570425ffa15d342f53f28&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2MDA0MTYyMQ==&mid=2654402553&idx=1&sn=4ac39253f61c334d3bbdd30540feb433&chksm=f1ade903c6da6015ed171eab61920d1f916b6e65ee04c308dacf251570425ffa15d342f53f28&scene=27#wechat_redirect)

2017年12月4日，在以“智能·互联”为主题的的“泰尔论坛2017”上，为应对日益严峻的移动安全环境，中国信息通信研究院携手360、华为、vivo等国内多家厂商，共同宣布成立“移动安全联盟”（Mobile Security Alliance，简称MSA）。

![](../Images/efd53de64d84aeb6f1025e34c8df4457.png)

移动安全联盟致力于搭建移动互联网安全的合作与促进平台，聚集信息通信界的中坚力量及相关机构，服务企业，支撑政府决策，推进移动互联网、移动设备安全发展，为实施《网络安全法》和推动“互联网+”发展提供必要支撑。

全球网络安全已经进入到 “大安全时代”。网络安全不再是孤立的数据泄露、病毒和木马，而是国家安全、社会安全、基础设施安全，城市安全、甚至人身安全。

近年来，移动互联网产业发展迅速，市面上涌现出各式各样的移动应用，在给用户带来便利的同时，也存在着种种安全隐患。移动互联网已经渗透到购物、WiFi、出行、社交这些与生活息息相关的方面，一旦存在漏洞，对于个人及社会的影响不可小觑。

![](../Images/93034b64bf8dc05e16cf5edbc19d4497.png)

移动安全联盟立足于当前移动安全环境现状，联合国内知名的移动终端厂商及移动安全厂商，对于当前频发的安全问题，提供技术支持和解决方案，有效应对移动端漏洞及恶意软件，开放、协作、共享，助力移动安全生态环境的建设。

**犇众信息作为国内移动安全厂商，长期致力于移动安全研究和专业的移动安全解决方案。作为移动安全联盟的成员单位，犇众信息将利用自己多年的移动安全研究成果，为广大移动安全用户保驾护航。**

目前，移动安全联盟共有会员单位33家，其中副理事长单位4家，理事单位12家，普通会员13家，观察员3家。理事长单位为中国信息通信研究院，副理事长单位分别为360、北京大学、华为、 vivo 等。

下一步，移动安全联盟将按照前期部署，稳步推动各工作组正式开展工作，着力于聚集产业生态各方力量，联合开展移动安全技术、标准和产业研究，共同探索移动安全的新模式和新机制，维护行业公平，推进技术、产业与应用研发，开展试点示范，广泛开展国际合作，形成全球化的合作平台，加快推动我国移动互联网产业健康快速发展。

**关于犇众**

上海犇众信息技术有限公司是以国际顶级安全团队盘古为核心的自主创新型企业，在操作系统安全性研究、程序自动化分析、漏洞挖掘与攻防等研究领域有雄厚基础。公司创立于2014年，致力于移动互联网安全技术研究和产品研发、为企业及个人用户提供专业的安全服务和解决方案。  

基于盘古团队的安全研究成果，公司在移动终端APP漏洞检测与风险评估，恶意APP检测与分析、移动设备取证、移动设备APT检测与对抗等领域开发了多款产品。

犇众信息是国家互联网应急中心 — CNCERT网络安全应急服务支撑单位，是中国信息安全测评中心 — CNNVD技术支撑单位。犇众信息凭借强劲的技术实力，逐渐得到客户及合作伙伴的认可。

公司以让每一台智能移动终端更安全为使命，基于丰富的系统攻防之道，铸造坚实的移动设备安全和数据隐私保障之盾。同时公司秉承技术分享理念，为促进信息安全社区的整体发展和技术提升积极贡献力量。
