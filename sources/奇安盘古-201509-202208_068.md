# “开放赋能·生态共赢”，犇众助力“企业安全联合实验室”，携手共建生态网络

2017年7月26日-27日，2017年网络安全生态峰会在北京国家会议中心隆重举办。“新安全·共担当”，本次会议以此为主题，着重探讨如何维护网络安全、建设生态网络环境，旨在推动中国互联网事业的安全发展。

  

![](../Images/79fb4d4d29f35dfa1c0b67c5b88fd70f.png)

  

  

携手并进，“企业安全联合实验室”守护企业安全

  

近年来，安全事件频发。6月28日，全球再次出现大规模网络攻击事件，新一轮超强电脑病毒正在向包括俄罗斯、英国、乌克兰等在内的欧洲多个国家迅速蔓延，有报告称包括俄罗斯最大的石油公司、乌克兰银行和一些跨国企业都已经感染了病毒。而仅仅在此前一个月，一款名为“WannaCry”的勒索病毒席卷全球，在短短一周时间里，上百个国家和地区受到影响，至少30万台电脑被病毒感染。

病毒的肆虐也影响到了我们的日常生活，很多中小型企业遭受到攻击和威胁。而中小型企业由于种种原因，不具备及时应对网络安全威胁的响应能力，容易成为黑灰产攻击的目标，这些威胁对于中小型企业来说是非常严重的隐患。

  

![](../Images/95e78f8edd431b7f9d83586d0d554300.png)

  

经过半年的发展，为了更好的帮助中小企业提供安全服务，解决安全问题，蚂蚁金服携手**中国国家信息安全漏洞库（CNNVD）**、专注于移动安全领域的**犇众信息**、国内领先的安全服务提供商**四叶草安全**；在攻击态势感知领域领军的**广州锦行**、拥有专业安全媒体“嘶吼”的**未来安全**、以及多次获得苹果、谷歌、三星等知名厂商公开致谢的**蚂蚁金服巴斯光年安全实验室（AFLSLab）**共同点亮了象征着“聚力融合·发展共赢”的启动装置，正式建立 “**企业安全联合实验室**”。

  

实验室将定期向社会发布各行业安全趋势报告，包括行业漏洞态势、最新高危漏洞预警、漏洞分类分级、漏洞深度分析和影响范围。并为企业提供全面的企业安全能力评估，包括系统风险、实时入侵监控、帮助企业了解自身安全能力，针对风险情况提供修复建议和安全整体解决方案。共同携手，守卫企业安全。

  

  

关于犇众

  

上海犇众信息技术有限公司是以国际顶级安全团队盘古为核心的自主创新型企业，在操作系统安全性研究、程序自动化分析、漏洞挖掘与攻防等研究领域有雄厚基础。公司创立于2014年，致力于移动互联网安全技术研究和产品研发、为企业及个人用户提供专业的安全服务和解决方案。

基于盘古团队的安全研究成果，公司在移动终端APP漏洞检测与风险评估，恶意APP检测与分析、移动设备取证、移动设备APT检测与对抗等领域开发了多款产品。

犇众信息是国家互联网应急中心 — CNCERT网络安全应急服务支撑单位，是中国信息安全测评中心 — CNNVD技术支撑单位。犇众信息凭借强劲的技术实力，逐渐得到客户及合作伙伴的认可。

公司以让每一台智能移动终端更安全为使命，基于丰富的系统攻防之道，铸造坚实的移动设备安全和数据隐私保障之盾。公司秉承技术分享理念，为促进信息安全社区的整体发展和技术提升积极贡献力量。
