# 盘古实验室助力“东华春秋杯”网络安全技能大赛，聚焦高校人才培养

11月21日,“东华春秋杯”2015年上海市大学生网络安全技能大赛总决赛在上海东华大学校园顺利收官。作为上海地区高校信息安全领域的重要赛事，本届“东华春秋杯”吸引了全国25个省市自治区、91所高校的200余支队伍参加，不仅覆盖了上海地区的几十所高校，还获得了国内20余所重点院校和香港地区高校的积极参与。经过前段时间为期8天的预赛阶段网络答题比拼，来自东华大学、西北工业大学、西安电子科技大学、上海交通大学、华东政法大学、复旦大学、江苏信息学院的十二支代表队进入了最终总决赛。

整个决赛过程中，参赛选手们表现出的扎实的理论功底与高超竞技水平给观摩大赛的嘉宾们留下了非常深刻的印象。东华大学邱高校长在接受采访时表示，“东华春秋杯”的成功举办，不仅为高校杰出的网络安全人才搭建了展现自身能力的舞台，更为上海地区乃至全国高校的网络安全人才培养积累了宝贵的经验。

**盘古实验室**将持续关注大学生网络安全技能大赛，并为高校学生提供更多的实习及实践机会。2016年盘古将把“**高校人才培养计划**”将列入实验室日常工作计划，从高校中寻找和培养更多更优秀的网络安全人才，为国家网络信息安全事业尽绵薄之力。
