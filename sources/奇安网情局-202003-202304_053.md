# 美国网络空间和数字政策巡回大使主张将威慑扩展到整个网络领域

美国务院首任网络空间和数字政策巡回大使纳撒尼尔·菲克10月6日出席国务院新闻发布会，就其新任职发表演讲并回答记者提问。

  

菲克表示，网络空间和数字政策局专注于整合和提升美国与合作伙伴和盟国的技术外交方法，并坚持利用技术来丰富生活和维护民主价值观的愿景；外交应成为美国所有事务的首要工具，而网络和数字政策将成为下一个外交前沿；网络和数字政策不是孤岛，而是贯穿美国外交政策各个方面的基础；网络和数字政策既是国务院工作的核心部分，也是各级外交官工具包中的核心工具。

  

菲克表示，将威慑扩展到网络领域的想法在美国外交政策的许多方面都很重要，包括俄乌战争；强大的威慑框架是北约联盟的一部分，威慑正在乌克兰以外地区发挥作用，这也是俄罗斯未在乌克兰境外使用网络手段进行大量横向升级的原因之一；进攻性网络能力和行动是美国的国家力量的重要工具；“历史不会重演，但会押韵”，核威慑所启示的部分原则同样适用于网络威慑，例如相称性、非战斗豁免以及国家整体力量等原则。

**美国务院首席副发言人韦丹·帕特尔：**大家下午好。

  

正如我所承诺的，今天我们有一位特别的客人。今天，我很高兴介绍网络空间和数字政策巡回大使纳撒尼尔·菲克，他几周前刚刚开始工作，并于本周早些时候在10月4日举行了宣誓就职仪式，正好赶上网络安全意识月。

  

去年，美国务卿布林肯制定了雄心勃勃的现代化议程，以帮助国务院在决定未来几十年的政策领域发挥领导作用。网络空间和数字政策位居榜首，这就是我们首位巡回大使的到来，领导我们的新网络空间和数字政策局。这是实现国务卿议程的关键里程碑。

  

菲克大使得到了参议院的一致认可，在公共和私营部门都拥有令人印象深刻且无可挑剔的领导记录，并且是网络空间和数字政策领域许多问题领域的专家。

  

我很高兴他来到这里。他将向你们发表一些意见，然后我们将回答几个问题，然后他必须继续全天开会。有请菲克大使。

  

**菲克大使：**谢谢。大家好。

  

我叫内特·菲克。我是领导网络空间和数字政策局的新任巡回大使。正如你所听到的，这是我任职的第一周。

  

我很高兴有机会领导国务院最新的局，领导一个专注于整合和提升美国与我们的合作伙伴和盟国的技术外交方法的机构，并坚持我们如何利用技术来丰富我们的生活和维护民主价值观的愿景。

  

我对此提出了一些个人的、发自内心的信念。大学毕业后，我在职业生涯的早期是一名海军陆战队员。“911”事件后，我在阿富汗服役，2003年在伊拉克服役，亲眼目睹了外交失败时的代价。因此，我再次坚信外交的内在价值。我认为外交应该是我们在所有事情上的首要工具。网络和数字政策是外交的下一个前沿。这不是孤岛；这不是一组仅限于任何一个局的问题；这是贯穿我们外交政策各个方面的基础。

  

布林肯国务卿和谢尔曼副国务卿已经明确表示，网络和数字政策不仅仅是一个局的工作，我们需要将理解数字政策作为国务院工作的核心部分，以及我们各级外交官工具包中的核心工具。

  

因此，为了取得成功，我们需要在公众中传达我们将要做什么，所以我很高兴有机会在我在这里的第四天开始与大家交谈。因此，我期待找到新的方法来突出我们如何推进这一使命，我将仅举一个我前10天的例子，来说明网络和数字问题已经如何影响美国外交工作。我宣誓就职，拿到护照，并登上飞往布加勒斯特的飞机，以便在上周国际电信联盟（ITU）秘书长选举前几天与我们的美国代表团一起工作。

  

国际电信联盟（ITU）是一个拥有157年历史的组织，负责制定管理电信诸多方面的标准，包括5G和光纤网络等。我们有一位非常强大的美国公民作为秘书长候选人，多琳·博格丹-马丁，她以压倒性优势战胜了她的俄罗斯对手：139票对25票，我认为这给了她——我们认为现在给了她强有力的授权开始她作为秘书长的四年任期。我知道她将完成一项非凡的工作，不仅因为她在国际电联拥有管理和领导经验，还因为她致力于连接未连接的人们、缩小数字鸿沟以及推进开放、可互操作的原则，为世界各地的人们提供安全、可靠的互联网。

  

因此，显然，从打击恶意网络活动和建立弹性，到促进对安全电信基础设施的投资，以及确保以促进人权的方式普遍访问互联网，还有很多工作要做。

因此，我很荣幸能与网络空间和数字政策局一支由经验丰富的外交人员组成的优秀团队合作。我期待与我的跨机构合作伙伴建立关系。我期待与我们在全球的合作伙伴和盟友合作。

  

就此，我很乐意回答几个问题。

✦

**韦丹·帕特尔：**好的。所以大使会回答几个问题。亚历克斯，你想开始吗？

  

**提问：**非常感谢大使。非常感谢你的到来。祝贺你的新工作。

  

**菲克大使：**谢谢。

  

**提问：**关于俄罗斯的几个问题。你如何评估俄罗斯网络报复的风险，从乌克兰到俄罗斯、克里姆林宫支持的团体攻击美国各州的最新例子？你对此有评估吗？在哪里会有回应？

  

**菲克大使：**是的。我想，几天后，我可能不得不将我的一些评论保持在原则层面。但我认为，将威慑扩展到网络领域的想法在美国外交政策的许多方面都很重要，包括俄乌战争。

  

我认为我们看到的整个北约联盟的目标统一程度令人鼓舞。网络威慑是其中的一部分。它是——在某种程度上它是有效的，对吧？我们还没有发现俄罗斯人在乌克兰境外使用网络手段进行大量横向升级。在乌克兰内部——早期有趣的成功案例之一是——与软件供应商在当地的公私合作伙伴关系的有效性，在某些情况下，数以亿计的系统部署在乌克兰，以及它们与美国政府间关于威胁情报共享以及向系统推出补丁等问题的反馈循环。

  

我在私营部门工作了很长时间，我不习惯看到它像现在这样顺利和快速地工作。所以我觉得我们至少在这方面正在学习。

  

**韦丹·帕特尔：**凯莉，你举手了吗？

  

**提问：**是的，只有两个问题。继续这一话题，你提到威慑在乌克兰正在发挥作用，当涉及到任何……

  

**菲克大使：**威慑正在乌克兰以外地区发挥作用。

  

**提问：**乌克兰以外。

  

**菲克大使：**威慑正在欧洲和整个北约联盟中发挥作用。

  

**提问：**好的。所以你认为这种威慑是我们没有发现俄罗斯在乌克兰开展更多进攻性网络行动的原因之一，还是你认为这只是代表他们就如何处理这场战争做出的决定？

  

**菲克大使：**凯莉，再次道歉，有点原则层面的问题，因为我还刚任职，我认为有一个强大的威慑框架是北约联盟的一部分，我认为这是，至少部分原因是，为什么在乌克兰以外未出现广泛的俄罗斯网络攻击。

  

在乌克兰内部，我认为实际上存在一定程度的恶意俄罗斯网络活动，至少他们已经尝试过。而且我认为它没有产生俄罗斯人希望的影响的原因之一是因为在乌克兰有所部署的软件供应商和硬件供应商之间正在发生这种紧密的反馈周期，以及它们与美国政府、乌克兰政府和北约的合作伙伴关系来传达这一点——以加速反馈周期。

  

**提问：**还有一个问题。当谈到美国的进攻性网络能力和行动时，你是否很高兴看到本届政府正在努力控制这些网络行动以及它们真正能够执行前在美国方面必须通过的检查水平，以便国务院能够更加深入了解？

  

**菲克大使：**我认为网络行动是国家力量的重要工具。我认为，在最初的几天里，现在进入有关该主题的任何细节都超出了我的范围。

  

**韦丹·帕特尔：**罗杰。

  

**提问：**谢谢大使，祝贺你。你领导的网络空间和数字政策局可以做什么——该局在让伊朗民众访问互联网方面可以发挥什么作用，或者该局可以与私营公司做些什么或任何让伊朗人访问互联网的事情？

  

**菲克大使：**我认为——我希望从全球倡导的角度来看，我们可以做很多事情来推进我们的信念，即互联网是——互联网访问，对可靠、安全信息的访问——是地球上每个人都应该拥有的东西。这是多琳·博格丹-马丁作为国际电联秘书长而奋斗的原则之一。我认为我们可以通过多种方式实现这一点，在我的领导下，我希望网络空间和数字政策局能够大力倡导这一点。

  

**韦丹·帕特尔：**然后是奈克。

  

**提问：**菲克大使，祝贺你。威慑如何发挥作用？我的意思是，我们知道核威慑是如何发挥作用的。我们——就像这个国家有这么多武器，而对手有这么多武器，等等。但在这种情况下，你会向他们展示什么——比如关闭对手的一些设施等等，以展示你的威慑能力？

  

**菲克大使：**我认为有一句古老的格言，“历史不会重演，但会押韵”。我认为我们在冷战过程中学到的关于核威慑的一切并不能完美地转化到这个领域，但它确实会押韵。一些原则保持不变。例如，归因存在独特的挑战。我们没有一系列卫星可以跟踪导弹发射羽流并能够实时确定它们来自哪里，对吧？这不是这个领域的工作方式。

  

当你谈论的是一次中继的网络攻击——由一个国家发起并在打击目标前通过其他六个国家的服务器中继，这将成为一个更具挑战性的问题。但同样，我认为在历史上为我们服务的一些原则将继续为我们服务：相称性原则；非战斗豁免原则；诸如声明可能不仅仅是网络报复的原则，是的，威慑——真正的威慑——需要调动我们国家力量的每一盎司——信息力量、经济力量、外交力量。所以……

  

**韦丹·帕特尔：**奈克，继续。

  

**提问：**谢谢。祝贺你，大使，感谢你的通报。随着美国——随着美国中期选举的临近，就针对中期选举的网络活动而言，你从俄罗斯、伊朗等国发现了什么？你是否发现其他国家或非国家行为者引起关注？谢谢你。

  

**菲克大使：**所以这对我来说将是一个非常近期的优先事项——与我们的跨机构合作伙伴合作，以维护我们的选举以及我们的盟友和合作伙伴的选举的安全——但我还没有足够的时间来谈论它。

  

**韦丹·帕特尔：**我认为大使有时间再问一个问题。是的，还有一个——艾比，继续。

  

**提问：**你对国务院自己系统的安全性有多大信心，你是否会努力改善这里的安全性？

  

**菲克大使：**所以我的妻子问我需要多少天才能让部门里的某个人要求我修理他们的打印机。（笑声）我猜答案是四天。我们的办公室不属于国务院的首席信息官或IT部门，因此我对国务院自身网络的安全性没有任何细粒度的认识。对不起。

  

**韦丹·帕特尔：**非常感谢大家，感谢大使加入我们。
