# 旗帜分明：黑客组织开始在俄乌冲突中“选边站队”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4ODQzMzk3MA==&mid=2247486291&idx=1&sn=7ca251771c111883cab0653ae01a07a5&chksm=ec3f390edb48b01806a72c098780b47c4cef0ed11c432ccb0510c2c3034ed621fdaf7c9e739a&scene=126&sessionid=1681277251#rd](http://mp.weixin.qq.com/s?__biz=MzI4ODQzMzk3MA==&mid=2247486291&idx=1&sn=7ca251771c111883cab0653ae01a07a5&chksm=ec3f390edb48b01806a72c098780b47c4cef0ed11c432ccb0510c2c3034ed621fdaf7c9e739a&scene=126&sessionid=1681277251#rd)

**编者按**

  

随着俄罗斯与乌克兰冲突升级，部分黑客组织已经开始在社交媒体发表立场声明，宣布其效忠所在。  

  

俄罗斯阵营方面，Conti勒索软件团伙声称将利用所有资源对针对俄罗斯实施网络攻击的敌方关键基础设施进行反击；白俄罗斯UNC1151团伙已经开始入侵乌克兰军事人员的电子邮件账户；“沙虫”（SandWorm）组织得到俄罗斯的支持，由俄罗斯国家资助的黑客组成；“红土匪”（The Red Bandits）组织声称，已劫持乌克兰警方行车记录仪，如乌克兰不按俄罗斯意愿行事，将升级对乌克兰的攻击，并将考虑在乌克兰散播勒索软件；CoomingProject组织声称，将协助俄罗斯政府应对网络攻击。

  

乌克兰阵营方面，“匿名者”（Anonymous）宣布正式与俄罗斯政府展开网络战，并声称已经发动攻击致“今日俄罗斯”网站下线；“幽灵安全”（Ghostsec）宣布支持乌克兰，该组织通常也被称为“匿名者”的一个分支。

  

黑客公告的“多米诺骨牌效应”已经促使乌克兰国防部向乌克兰向地下黑客社区发布信息，号召乌克兰黑客集结执行任务，以保护乌克兰关键基础设施免受网络攻击，并在网络间谍活动中对俄罗斯采取进攻性行动。安全专家分析称，所谓“网络爱国者”根据自己的意愿或在政府的指示下与所谓的敌人交战，是任何军事行动中不可避免的一部分；黑客组织的部分活动（如DDoS攻击）只会产生一定干扰作用，但其他活动可能会产生严重后果。

  

奇安网情局编译有关情况，供读者参考。

俄罗斯对乌克兰的行动在线上和线下都发生，将物理破坏与不断升级的数字战结合在一起。勒索软件团伙和其他黑客组织已经在社交媒体上宣布其效忠所在。

  

上述团体的许多声明都包括对关键政府基础设施的威胁。一些团体是国家资助的，而另一些是分散的，但所有团体都能够摧毁计算机系统和破坏机构。

  

勒索软件专家艾伦·利斯卡称，“现在，所谓的‘网络爱国者’将根据自己的意愿或在政府的指示下与所谓的敌人交战，这是任何军事行动中不可避免的一部分。其中一些活动，例如匿名发起DDoS攻击，只不过是小麻烦，但其他活动可能会产生真正的后果。例如，勒索软件组织的目标比他们现在所追击的要多，并且可能决定专注于攻击他们国家的敌人以制造真正的破坏。更有技能的团体可以产生更大的影响。”

  

艾伦·利斯卡警告称，“沙虫”（Sandworm）和UNC1151的能力和活动最令人担忧，应密切关注。

  

**支持乌克兰的一边**

  

**“匿名者”（Anonymous）**——与乌克兰联合并“正式与俄罗斯政府展开网络战”。该组织在推特上称，其攻击了俄罗斯国家控制的国际电视网络RT，并“已经关闭了#俄罗斯‘今日俄罗斯’（RT）新闻网站”。“匿名者”据称是一个去中心化的黑客组织，曾攻击过政府机构、公司和山达基教会。

  

“匿名者”2月24日发表推特称，“‘匿名者’集体正式与俄罗斯政府开展网络战#Anonymous #Ukraine。”

  

![](../Images/a6ec2f0f787b99d6957d8d0f9f7efc29.png)

  

**“幽灵安全”（Ghostsec）**——2月25日宣布他们对乌克兰的支持：“为了支持乌克兰人民，我们支持你们！”该组织也被称为“幽灵安全”，自认为是一个“义警”组织，最初成立的目的打击宣扬伊斯兰极端主义的“伊斯兰国”网站。Ghostsec通常也被称为“匿名者”的一个分支。

  

![](../Images/469fcdd8b3351d2ac557f403fe7c4754.png)

  

**支持俄罗斯的另一边**

  

**Conti勒索软件团伙**——全力支持俄罗斯——Emsisoft勒索软件专家布雷特·卡洛发表推文显示，Conti团伙扬言“如果有人决定组织针对俄罗斯的网络攻击或任何战争活动，我们将利用我们所有可能的资源对敌人的关键基础设施进行反击。”Conti勒索软件团伙非常先进，并以第一个将Log4Shell漏洞武器化并运营完整的攻击链而闻名。

  

![](../Images/cd85ed784118e085b09aaafd9fe39e0b.png)

  

**位于白俄罗斯明斯克UNC1151团伙**——支持俄罗斯。该黑客组织通常被认为是由白俄罗斯国家资助的，并且已经在努力入侵乌克兰军事人员的电子邮件账户。乌克兰官员称，该组织的成员是白俄罗斯国防部人员。

  

**“沙虫”（SandWorm）组织**——得到俄罗斯的支持。该组织以其最近的名为Cyclops Blinks的恶意软件而闻名，由俄罗斯国家资助的黑客组成。该恶意软件于2019年6月首次被部署，主要被检测到针对WatchGuard Firebox防火墙，但不排除也能够感染其他类型的网络设备。

  

**“红土匪”（The Red Bandits）组织**——支持俄罗斯。该组织2月22日发表推文称，“我们劫持了@ UkrainePolice 行车记录仪并一直在监视它们。如果乌克兰不按照#Russia 的意愿行事，我们将升级对乌克兰的攻击，以引发恐慌。我们还将考虑在# UkraineRussiaCrisis #RussiaUcraina #Ukraine 中散发#ransomeware。”该集体自认定为来自俄罗斯的网络犯罪集团，然而人们普遍推测其实际上是俄罗斯情报机构。

  

![](../Images/c85473e27832aa3ea0b616cb43afb991.png)

  

**CoomingProject组织**——支持俄罗斯。该黑客组织2月25日发表明宣布，“大家好，这是一条信息，如果有针对俄罗斯的网络攻击和行为，我们将帮助俄罗斯政府。”该团伙与2021年南非国家航天局的数据入侵和泄漏有关。

  

![](../Images/757ea52075f9461c7cb1db258775e43e.png)

  

黑客公告的多米诺骨牌效应促使乌克兰国防部向乌克兰地下黑客社区发布信息。该信息是号召性用语，鼓励乌克兰黑客集结执行任务，以保护乌克兰关键基础设施免受网络攻击，并在网络间谍活动中对俄罗斯采取进攻性行动。虽然是乌克兰国防部要求的，但该消息是由Cyber Unit Technologies的创始人叶戈尔·奥舍夫发布的，他为黑客社区的人员提供了申请。该消息还要求黑客和网络安全专家通过谷歌文档提交申请，列出他们的专长，例如恶意软件开发和专业参考。

  

叶戈尔·奥舍夫表示，志愿者将分为防御性和进攻性网络单位；防御单位将用于防御基础设施，例如发电厂和供水系统，其正在组织的进攻单位将帮助乌克兰军方针对入侵的俄罗斯军队开展数字间谍行动；乌克兰未来将建立网络军事力量；已有数百名申请成为志愿者，其将开始审查以确保他们中没有俄罗斯特工。
