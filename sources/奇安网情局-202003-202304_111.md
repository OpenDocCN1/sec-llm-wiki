# 美国防部长亲自观看美军网络部队进攻性网络行动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4ODQzMzk3MA==&mid=2247486172&idx=1&sn=e0ce341d2546d1993865aaa751f34d47&chksm=ec3f3881db48b197872e123b0d3fab4d7c98984aa9855d0c484b620d4a19effba47a084a14f7&scene=126&sessionid=1681277261#rd](http://mp.weixin.qq.com/s?__biz=MzI4ODQzMzk3MA==&mid=2247486172&idx=1&sn=e0ce341d2546d1993865aaa751f34d47&chksm=ec3f3881db48b197872e123b0d3fab4d7c98984aa9855d0c484b620d4a19effba47a084a14f7&scene=126&sessionid=1681277261#rd)

**编者按**

美国空军国民警卫队日前发布新闻称，美国网络司令部一支特遣部队于2021年2月至8月期间开展了首次进攻性网络行动。此次行动意义非凡，以至美国国防部长劳埃德·奥斯汀亲自出席并观看了行动。此次行动也是数字领域战争性质迅速演变以及进攻性网络行动未来重要性的另一个标志。

  

此次行动是一项“进攻性网络效应行动”，涉及美国防部信息网络的安全，但行动确切性质和目标仍然未知。开展此次行动的特遣部队由来自美国马里兰州空军国民警卫队第175网络作战大队、特拉华州空军国民警卫队第166网络作战中队、美国海军第63网络突击队、美国空军第341网络作战中队和空军预备役的人员组成。虽然美国网络司令部还开展了其他进攻性网络行动，但这是该特遣部队开展并承认的首次进攻性网络行动。

**美国网络司令部的一支特遣部队在美国防部长的注视下开展了首次进攻性行动。此次行动是数字领域战争性质迅速演变以及进攻性网络行动未来重要性的另一个标志。**

  

该特遣部队针对现实世界的网络威胁执行了所谓的“首次进攻性网络效应行动”。虽然行动的确切性质和目标仍然未知，但这次事件的意义足以让美国国防部长亲自出席观看行动。

  

**该行动由一支特遣部队在2021年2月至8月期间开展，特遣部队由来自马里兰州空军国民警卫队第175网络作战大队、特拉华州空军国民警卫队第166网络作战中队、美国海军第63网络突击队、美国空军第341网络作战中队和空军预备役的人员组成。**尽管美国空军国民警卫队1月4日刚宣布此消息，但该特遣部队在2021年2月至8月期间执行了这项行动。虽然美国网络司令部（USCYBERCOM）还开展了其他进攻性网络行动，但**这是该特遣部队开展并承认的首次进攻性网络行动。**

  

![](../Images/da968960477832147547ff885efc7747.png)

网络国家任务部队成员于2021年在马里兰州米德堡

参加训练和战备演习

  

关于特遣部队网络攻势所应对的具体威胁的详细信息很少，但美国空军第175网络空间作战中队作战主管科利·布拉德福德少校表示，进攻性网络行动涉及国防部信息网络的安全。

  

布拉德福德在美国空军国民警卫队发布的新闻稿中称，“我们的国家任务团队是特遣队部队成功开展进攻性网络效果行动的直接贡献者。当我们的特遣部队在这次动员期间执行首次进攻性网络效应行动时，终于看到了我们的劳动成果，这让我非常兴奋。”

  

**耐人寻味的是，美国防部长劳埃德·奥斯汀亲眼目睹了这次行动。布拉德福德少校称，“这是一个巨大的里程碑，所以他希望在前排座位亲眼目睹行动。”**

  

**美国网络司令部尚未发布有关此次行动目标的信息。**网络司令部去年回应的最大的公开威胁之一是俄罗斯主导的SolarWinds数据泄露事件，但目前尚不清楚此次进攻性行动是否与该事件有任何关系。无论情况如何，美国网络司令部在2021年底举行了一次直接响应SolarWinds事件的国际演习，并于2021年12月对国际勒索软件组织（例如对Colonial Pipeline攻击负责的组织）开展了进性攻行动。与此同时，俄罗斯的网络攻击一直在稳步增加，同时它最近在与乌克兰接壤的边境采取了咄咄逼人的军事姿态。

  

自2015年以来，美国国民警卫队一直在激活更多的网络作战部队，这是整个国防部对网络作战日益重视的一部分。这些单位的大部分任务是在发生紧急情况时向州和地方政府提供援助和情报，并积极开展演习以为此类突发事件做计划。空军上校蒂莫西·伦德曼称，“国民警卫队遍布所有50个州、3个领地和哥伦比亚特区。如果州和地方官员需要帮助，他们更有可能求助于他们认识的人。他们认识的人就是国民警卫队。”

  

![](../Images/30123f8a0912da37814915a978b278d5.png)

美国空军少尉罗伯特·科西斯，马里兰州国民警卫队网络联合特遣部队的一名作战人员，位于沃菲尔德空军国民警卫队基地第175联队

  

马里兰州空军国民警卫队的第175网络作战大队于2016年成立。第275作战支援中队指挥官凯文·乔治上校当时称“我们拥有执行网络任务的所有要素。由于我们独特的情况和支持机制，我们将能够执行防御、进攻和动能作战。”该大队成员在国防承包商和网络安全公司担任文职职位，这使国民警卫队能够利用这些成员在私营部门获得的专业知识。

  

虽然这可能是该特遣部队开展的首次进攻性网络行动，但这凸显了五角大楼对网络安全的日益重视。美国白宫2021年5月签署了一项行政命令，旨在加强整个情报界和国防部的网络防御，后来于2021年6月宣布将某些网络攻击提升到与恐怖袭击相同的优先级。虽然这些举措在本质上是防御性的，但网络司令部2021年9月曾发表声明，概述了进攻性网络能力对于“打击敌人和敌对对手活动”也是必要的。这些能力的确切性质仍然未知。

  

![](../Images/b26f60043c907e3ab1c838bc76f3f655.png)

第175网络空间作战大队人员在被称为“猎人巢穴”的作战楼层

监视网络攻击

  

正如最近世界各地的许多网络和勒索软件攻击所表明的那样，美国的大部分公用事业网络和其他关键基础设施仍然容易受到来自国家和非国家行为者的网络攻击。随着美国政府试图加强其应对这些迅速出现威胁的能力，五角大楼对防御和进攻网络能力的重视可能会继续增长。
