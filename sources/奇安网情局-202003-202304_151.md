# 美国防部使用Haystack解决方案确定精英网络人才

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4ODQzMzk3MA==&mid=2247485661&idx=1&sn=7331a27af055ac67fb880fd68b4cfcf4&chksm=ec3f3a80db48b3968f6000186461df92f32725da6ffddea6af05a739c9b41d98aa1321120505&scene=126&sessionid=1681277282#rd](http://mp.weixin.qq.com/s?__biz=MzI4ODQzMzk3MA==&mid=2247485661&idx=1&sn=7331a27af055ac67fb880fd68b4cfcf4&chksm=ec3f3a80db48b3968f6000186461df92f32725da6ffddea6af05a739c9b41d98aa1321120505&scene=126&sessionid=1681277282#rd)

编者按

美国马里兰大学使用Haystack Solutions公司的“网络资质和人才评估”（CATA）工具，对来自美国特种作战司令部、美国海军、西点军校和美国空军的数百名军方人员开展了压力下表现测试，快速、准确地识别候选人在关键网络安全角色方面的资质，包括批判性思维、方法和实践的详尽性、初始行为、实时效率和响应行为等。结果显示，CATA准确界定了美国空军信息技术基础（ITF）课程中97%的精英表现者，以84%准确率区分了高技能和未受训的美国空军网络人员，确定了与国防部参与者各种课程绩效指标相关的六个主要测试参与者集群，给出了代表候选人总资质的综合分数。

  

CATA的大部分核心是由马里兰大学共同开发的，而认知评估最初由国家安全局和美国海军第10舰队使用。CATA侧重于五个关键的大脑维度，包括批判性思维、刻意行动、实时行动、主动思维和反应性思维。CATA包括一系列测试，旨在在网络安全职业四个领域中衡量认知能力并了解天然资质，包括进攻性操作、防御性操作、分析和取证以及设计和开发。CATA的核心已被美国情报体系和国防部使用来创建一些表现最佳的网络团队。

美国马里兰大学（UMD）与美国海军（USN）、美国特种作战司令部（SOCOM）、西点军校和美国空军合作，使用Haystack Solutions的“网络资质和人才评估”（CATA）工具快速、准确地识别候选人在关键网络安全角色方面的资质，无论其母语或以前的IT/安全经验如何。

  

Haystack Solutions是网络安全资质评估的共同创建者，能够以惊人的精确度预测候选人的成功概率，该公司7月15日推出了“网络资质和人才评估”（CATA）工具。CATA是首个此类商业解决方案，其科学设计用于识别进入或提升网络安全技能个人的自然认知能力。到目前为止，此类评估（包括Haystack的核心产品）仅在以军事和联邦情报为重点的机构中可获取。

  

![](../Images/f7304ae42bd6e5b3971a9fe3678f478f.png)

  

美国退役海军中将简·泰伊曾表示，“作为第十舰队司令，我被迫需要识别和留住我们最优秀的人才。我想要用于网络的武装部队职业资质能力（ASVAB）标准评估。我认为，如果我们可以创建一个能力测量器，使我们的计算机网络运营人员与他们的最佳工作角色最佳地匹配，我们将通过将团队成员置于最适合他们的兴趣和能力的具有挑战性、令人满意的角色来提升人员保留率。马里兰大学正在研究类似的方法，我们利用了一些工作。”

  

简·泰伊补充称，“像CATA这样的工具可以通过提高保留率、降低再培训成本和提高任务效率来为我们的团队节省无数时间。”

  

马里兰大学对美国防部的测试结果：

  

在马里兰大学进行的研究中，来自美国特种作战司令部、美国海军、西点军校和美国空军的数百名国防部参与人员接受了压力下的表现测试，确定了与卓越网络安全相关的关键领域的资质，例如批判性思维、方法和实践的详尽性、初始行为、实时效率和响应行为。所有测试都最大限度地减少了语言偏见，并让参与者都具有竞争力，无论其母语、英语熟练程度或之前在IT和网络安全原则方面的经验如何。在国防部合作伙伴中，CATA测试准确地：

  

![](../Images/805f6f4d942c8ad31e488c038991dcec.png)

◾界定了美国空军信息技术基础（ITF）课程中97%的精英（课程平均90%或更高）表现者

  

◾以84%准确率区分了高技能和未受训的美国空军网络人员

  

◾确定了六个主要的测试参与者集群，这些集群与国防部参与者（例如美国特种作战司令部、美国海军、西点军校和美国空军）的各种课程绩效指标相关  

  

*   在四个关键学科中表现出色的人——他们成为网络课程中最成功的人。
    
      
    
*   在“认知需求”、“矩阵推理”和“动态系统控制”等CATA测试中得分高的批判性思想者。这些候选人也是表现最好的。
    
      
    
*   许多测试对象被确定为创造性思维者，他们在许多任务中得分较低，但在“认知需求”、“认知闭合需求”和“模式警惕”等关键领域表现出色，因此非常适合并被选为他们以前没有申请过的网络安全角色。
    
      
    

◾制定了综合分数（一个代表候选人总资质的数字）

![](../Images/119a7c7c96b4be695f4fcdf9db64144d.png)

  

Security Mindsets公司负责人查尔斯·科洛吉称，“寻找合适的候选人并确定哪些员工可以投资于额外培训是一项影响范围很广的艰难决定。正确的决定可以让组织安全状况得到整体改善，而错误的决定可能会削弱准备工作。Haystack的解决方案打开了认知能力的‘黑匣子’，可以帮助确定不仅拥有适当认证而且还具备成功所需能力的最佳候选人。通过这种方式，可以淘汰那些资质优秀但天生技能不适合特定任务的人。把事情做好是当务之急，而赌博的成本太高了，从延迟招聘和留任率低到错过警告标志等严重后果。”

  

CATA侧重于五个关键的大脑维度：批判性思维、刻意行动、实时行动、主动思维和反应性思维。它包括一系列测试，旨在在商业部门网络安全职业四个领域中衡量认知能力并了解天然资质：

  

*   进攻性操作：实时使用部分数据的主动性和创造性解决问题能力；
    

  

*   防御性操作：通过扫描和实时、部分数据检测异常，筛选干扰；
    
      
    
*   分析和取证：解释和协调大量经常发生冲突的数据；
    
      
    
*   设计/开发：将创造性问题解决方案化并构建模型程序以供执行的能力。
    

  

CATA的大部分核心是由马里兰大学共同开发的，而认知评估最初由国家安全局和美国网络司令部的前身第10舰队使用。

  

马里兰大学ARLIS中心认知安全和信息运营主任、Haystack公司CTO和技术共同发明人迈克尔·邦廷博士称，“CATA的核心已被美国情报体系和国防部使用来创建一些表现最佳的网络团队。很高兴看到它适用于商业领域，并在早期试验中帮助识别学校和大学中以前未开发但天生天才级的网络人才，他们现在获得了一些最负盛名的CTF奖项，并且以前没有考虑过网络安全职业。”

  

除了映射到网络安全领域外，评估报告还支持国家标准与技术研究所/国家网络安全教育计划工作角色框架，显示了通往自然适合更个人化的网络安全职业工作角色的路径。

  

Haystack Solutions首席执行官兼创始人、CATA联合开发者道格·布里顿称，“网络安全是一个日益复杂的领域，学习曲线漫长而艰巨。长期以来，商业部门一直需要深入了解网络安全候选人的问题解决、可视化和模式识别能力，这些是证书和学位所不一定能反映的品质。让我们面对现实吧，商业部门的网络安全挑战每天都在扩大和变得越来越复杂。识别具有天赋的人并确保他们接受最适合的职位培训的能力可以帮助商业部门更快、更有效地弥合人才缺口。CATA迎接了这一紧迫的挑战。”邦廷博士表示赞同称，“我们需要确定每个拥有网络战士认知指纹的人，并让他们参与战斗。”
