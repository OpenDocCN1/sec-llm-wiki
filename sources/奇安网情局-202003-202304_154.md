# 美军和日本陆上自卫队通过“东方盾牌”演习测试联合网络作战

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4ODQzMzk3MA==&mid=2247485617&idx=1&sn=86c924a45f97ef155ee007916c03a8c3&chksm=ec3f3aecdb48b3fa48eaaaf7a8b0a1c6d0e0f1e115220c132a57d76ae0eac3de65c74ec783e9&scene=126&sessionid=1681277282#rd](http://mp.weixin.qq.com/s?__biz=MzI4ODQzMzk3MA==&mid=2247485617&idx=1&sn=86c924a45f97ef155ee007916c03a8c3&chksm=ec3f3aecdb48b3fa48eaaaf7a8b0a1c6d0e0f1e115220c132a57d76ae0eac3de65c74ec783e9&scene=126&sessionid=1681277282#rd)

**编者按**

美国陆军和日本陆上自卫队近日举行“东方盾牌”年度演习，旨在测试安全威胁能力，并完善双边互操作性，同时表明美国支持该地区盟友安全利益的决心。来自美国防部、众议院、邮政局、海岸警卫队和国民警卫队的430多名人员参与了此次演习，演习的指挥控制由美军第40步兵师负责。此次演习还纳入了网络战和电子战内容，提供虚拟防御网络培训。网络保护团队在虚构设施中遭入侵网络上独立工作，目的是检测、识别、隔离和对抗其网络上的敌对存在。

  

关岛国民警卫队首次参加“东方盾牌”演习，其陆军和空军成员组成了该岛的6人小队远程参加了此次演习。该团队分为网络战和电子战部分，其中网络战方面着眼于使用本地网络对抗敌人等问题，而电子战方面则着眼于雷达干扰和电网。上述部分将根据情报向日本陆上自卫队同行提供网络和电子战建议，以帮助其阻止入侵威胁。

  

奇安网情局编译有关情况，供读者参考。

  

![](../Images/e8d1bf67181f4e0313cdf9ac14efae7a.png)

  

日本陆上自卫队和美国陆军之间每年都会举行“东方盾牌”演习，以测试一些安全威胁。2021年的演习活动纳入了电子战和网络战。演习的指挥和控制由总部位于加利福尼亚的美军第40步兵师负责。

  

关岛国民警卫队的陆军和空军成员组成了该岛的6人小队，远程参加了2021年“东方盾牌”演习。关岛国民警卫队表示，兰迪·恩吉尔梅库尔中士、肯·克拉克专业军士、艾弗里·蒂奎恩科专业军士、杰里米·穆诺兹专业军士和空军下士瑞安·马丁内斯在普拉明·拉比诺上尉的监督下在巴里加达的胡安·穆纳堡远程参加了此次演习。

  

一名中士、三名专业军士和一名空军下士在一个放着几台笔记本电脑房间内可能看起来不多。但在电子战和网络战领域，像这样的小团队可以发挥作用。该团队分为几个部分，电子战部分由恩吉尔梅库尔领导，网络部分由穆诺兹领导。作为美军第40步兵师的顾问，这两个部分均与日本陆上自卫队的同行定期举行在线会议。

  

![](../Images/deaeae89ac86f2fe3082bdf94a5814b5.png)

  

兰迪·恩吉尔梅库尔称，“对于今天的场景，模拟入侵正在发生。一旦蒂奎恩科军士在他的情报方面发现这是一次两栖和空降入侵；我们直接向日本陆上自卫队提供网络和电子战建议，以帮助他们阻止它。”

  

杰里米·穆诺兹表示，“我们可以查看他们当地的基础设施，并就如何利用它为我们提供优势提供建议。例如，恩吉尔梅库尔的团队着眼于雷达干扰和电网，而网络方面则着眼于使用本地网络对抗敌人等问题。”穆诺兹称,“我们只开展了几天，但它帮助我看到了更大规模的事物。我们也在学习更多关于领导力和决策的知识，我也了解了很多关于日本的情况。我认为像这样与我们的盟友保持良好关系很重要。”

  

这是关岛国民警卫队首次参加始于1985年的“东方盾牌”演习。该演习旨在完善日本陆上自卫队与美国陆军之间的双边互操作性，同时表明美国支持该地区盟友安全利益的决心。

  

美国防部新闻秘书约翰·柯比在6月的一次简报会上称，来自国防部、众议院、美国邮政局、海岸警卫队和国民警卫队的430多名参加者参与了“东方盾牌”演习。柯比表示，“该演习提供虚拟防御网络培训，网络保护团队在虚构设施中遭入侵网络上独立工作，目的是检测、识别、隔离和对抗其网络上的敌对存在。”
