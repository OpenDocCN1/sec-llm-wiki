# 美国智库：2021年要忘记的五种网络策略

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4ODQzMzk3MA==&mid=2247484938&idx=1&sn=9e2216d718875ab9e72e29ccd42afdec&chksm=ec3f3457db48bd41a7cc800b34212ed583a2bfa43730171ca4affa52c89fe86224f4b3ce99ca&scene=126&sessionid=1681277312#rd](http://mp.weixin.qq.com/s?__biz=MzI4ODQzMzk3MA==&mid=2247484938&idx=1&sn=9e2216d718875ab9e72e29ccd42afdec&chksm=ec3f3457db48bd41a7cc800b34212ed583a2bfa43730171ca4affa52c89fe86224f4b3ce99ca&scene=126&sessionid=1681277312#rd)

**编者按**

美国智库战略与国际研究中心高级副总裁兼战略技术项目主任詹姆斯·刘易斯近日撰文分析认为，当前由“稳定、升级、威慑、规范实施、透明”构成网络安全战略分析框架已经过时，国际社会需要新的概念和新的方法来重新考察网络安全问题。

  

文章称，美国对手视网络行动为改变国际力量格局的重要手段，不会放弃会破坏稳定的网络行动；升级可能是网络安全中最被高估的风险，相关国家谨慎控制其最危险的网络能力，并将网络行动嵌入其避免与西方直接军事冲突的更大战略中；威慑在网络领域却毫无效果，美国未能在网络空间有效威慑对手；由于各竞争大国之间不存在共同的风险意识，使得有关国家无意遵守规范；网络能力的透明并不具有威慑性，而且西方的单方面透明并不能提高网络空间稳定。

公众对网络安全的讨论很热烈。但是，有时这种讨论没有像人们所希望的那样被深思熟虑。分析的出发点不应该是来自冷战战略思维或显然不可能（现在，我们已经拥有超过25年的网络冲突经验）假设情景的人造品，而是可以观察到的事实。在观察和经验的指导下，如果我们从2021年的网络词汇中消除这五个可驳斥的概念，则可以改善分析和政策制定。

  

**一、稳定**

  

美国对手不希望稳定；他们希望改变。他们正在挑战现状。他们将寻求稳定视为维护西方利益，以维持以美国为首的西方占主导地位的现状。1945年后的国际秩序由于其重塑意图而在很大程度上受到侵蚀，他们将网络行动视为实现这一目标的宝贵工具。他们不会放弃我们认为会破坏稳定的行动，开展网络行动的风险也不会足以影响他们的行为。网络行动不会造成生存威胁，这一认识给予对手在网络领域开展恶意行为的自由，只要他们避免越过我们在国家实践中可以观察到的隐性的使用武力阈值，他们就认为没有风险。 

  

**二、升级**

  

升级可能是网络安全中最被高估的风险。各国通过建立信任措施、改善沟通渠道、互相发表声明以及无数二次对话，减少可能导致网络事件升级为暴力的误算风险。然而，在过去二十年的恶意网络行动中，从未发生过导致升级的事件。没有发生导致升级的网络事件的可能原因是，各国保持对其最危险的网络能力的谨慎控制，尊重隐性的使用武力阈值，并且网络行动已被嵌入其避免与西方直接军事冲突的更大战略中。

  

十年前，分析家推测，随着各国更多地使用进攻性网络行动，考虑到网络行动的隐秘性、归因难度（当时）以及潜在的意料后果和附带损害，可能会升级为更大、更具破坏性的冲突。虽然有一些意外后果和附带损害的事件，例如NotPetya，但这些事件并未导致冲突升级。现在，我们可以将误算和升级的最初假设视为不准确。

  

**三、威慑**

  

威慑在其设计领域中一如既往地有效，但在网络领域却毫无效果。俄罗斯未派遣军队入侵欧洲，但并没有阻止其利用腐败、有组织犯罪、影响力行动、间谍活动以及偶尔暗杀来促进其在欧洲的利益。相关国家可能已经研究了如何规避美国威慑，并且该研究指导了他们的网络行动和策略。我们并没有威慑我们在网络空间中的对手。也许有办法恢复对网络和其他新形式冲突的威慑力，但是美国现在所做的任何事情都行不通。威慑的隐含目标是稳定，而由于我们的对手不希望稳定，因此使它成为一种无效策略。

  

**四、规范“实施”**

  

规范未执行；它们被遵守。各国选择以规范为基础采取行动，如果愿意，各国可以通过法律或政策实施这些规范以指导国家行动。但是，实施并不能反映意图，并且它本身不是决定性的。显然有可能“做样子”实施规范，但并不遵守规范，从而使规范无用。遵守规范反映了意图和一国决策。

  

通过谈判和拟定联合国议定准则方面的直接经验，我们可以说，这些准则源于军备控制先例，并且是基于这样的假设，即各竞争大国之间存在共同的风险意识。后一种假设不再成立，而没有任何外部理促使敌对大国遵守规范，从而消除了其遵守规范的动机。

  

**五、透明**

  

一些国家，尤其是澳大利亚和美国，对拥有进攻性网络能力的方面的透明度越来越高。这种透明性还没有任何对手给予回报。透明性并不具威慑性，单方面透明也不能提高稳定性。即使是提高透明度的西方国家，也必须对他们的实际能力保持某种程度的不透明，从而保持其有效性。网络是一个由秘密和意外主导的领域。它不是那种“你能在‘五一’游行，让西方观察家拍照和计数”的事情。这些属性与透明性互不兼容，并给透明性创建了一个上限，任何合理国家都不会越界。民主国家中有国内政治上的必要性，因此必须对立法机关和公民保持网络能力的透明，但是透明性的国际助益是有限的，尤其是当对手不予回报且不受威慑时。

  

还有其他一些概念（网络和平、网络灾难）也没有得到审查，但是它们在制定政策时起的作用很小，大多数人已经意识到它们缺乏分析实用性。但是，上面列出的五个术语构成了对网络安全进行战略分析（以及进行谈判）的过时框架。当使用它们时，这表明我们应该对由此产生的建议保持怀疑。观察趋势并计算事件。他们朝着错误的方向前进。要改变这一点，我们需要新的概念和新的方法。
