# 美国将伊朗树立为新的网络干涉活动打击目标

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4ODQzMzk3MA==&mid=2247484805&idx=1&sn=889798eb72f7b2fdccc6d0cf817d917d&chksm=ec3f37d8db48bece36b7a325c603034e7f885bbbc22e4d36799001b579da83a21234bf35c6cd&scene=126&sessionid=1681277317#rd](http://mp.weixin.qq.com/s?__biz=MzI4ODQzMzk3MA==&mid=2247484805&idx=1&sn=889798eb72f7b2fdccc6d0cf817d917d&chksm=ec3f37d8db48bece36b7a325c603034e7f885bbbc22e4d36799001b579da83a21234bf35c6cd&scene=126&sessionid=1681277317#rd)

自2016年以来，美国加强了对大选网络安防工作，抵制外国虚假消息影响力运动是其中的重要组成部分。不同于以往主要将矛头指向俄罗斯，美国在此次大选过程中将伊朗树立为网络干涉活动的重点打击新目标。

  

美国土安全部9月发布报告，披露包含有关伊朗黑客使用的Web Shell的技术细节。同月，美司法部对3组伊朗黑客提起诉讼，美财政部宣布制裁伊朗APT39黑客组织。美国司法部10月7日宣布，美国已查封了92个伊朗伊斯兰革命卫队（IRGC）用于进行全球虚假宣传运动的域名。其中4个域名（newsstand7.com、usjournal.net、usjournal.us和twtoday.net）被伪装成真实新闻机构，但实际上由IRGC控制，并且针对美国开展亲伊朗宣传，目的是影响美国的国内和外交政策。

  

美国司法部11月4日再次发布新闻稿宣称，根据联邦调查局的调查，美国再次查封了IRGC的27个域名，上述域名中的4个域名（rpfront.com、ahtribune.com、awdnews.com和criticalstudies.org）以美国为目标受众，开展虚假信息影响力运行，企图暗中影响美国的政策和舆论。

美国已经查封了27个域名，这些域名被非法用于进一步开展全球秘密影响力运动。

  

如查封文件所述，所有27个域的使用均违反了针对伊朗政府和IRGC的美国制裁规定。其中四个域名自称是真实的新闻媒体，但实际上由IRGC控制，并以美国为目标受众，以暗中影响美国的政策和舆论，这违反了《外国代理人注册法》（FARA）。其余的对象是世界其他地区的受众。此前，美国还以同类原因查封了92个域名。

  

美国国家安全助理总检察长约翰·德默斯称，“上个月内，我们宣布没收了伊朗的武器、燃料和秘密影响基础设施，只要伊朗领导人试图通过国家资助恐怖主义和劫持人质破坏世界稳定，我们将继续执行美国制裁措施，并采取其他法律措施来对付它们。”

  

美国检察官安德森称，“今天的查封是打击伊朗在全球范围内虚假信息运动的又一重要步骤。这项工作将继续。我们不能允许伊朗对假消息的迷恋凌驾于我们对法治的承诺。”

  

联邦调查局（FBI）负责特工克雷格·费尔称，“联邦调查局正在积极调查任何有关外国影响和敌对国家非法传播虚假信息的证据。今天，我们查封了伊朗IRGC非法使用以操纵包括美国在内的其他国家的舆论的27个域名。由于我们与谷歌、脸谱和推特的持续合作，FBI得以中断了这次伊朗宣传运动，我们将继续寻求外国行为者在我们国家传播虚假信息的任何尝试。” 

  

2020年11月3日发布的查封令描述了27个被查封的域名是如何违反联邦法律运作的。IRGC对域名的控制违反了《国际紧急状态经济权力法》（IEEPA）和《伊朗交易和制裁条例》（ITSR），上述法律禁止美国人未经许可向伊朗政府提供服务。此外，美国发现，IRGC向包括真主党、哈马斯和塔利班在内的许多恐怖组织提供了物质支持。因此，美国财政部外国资产控制办公室（OFAC）将IRGC列入其特别指定国民名单，并施加了其他许可要求。如查封文件所述，这27个域名已在美国域名注册机构进行了注册，并使用了美国注册机构拥有的顶级域名。在使用域名并从美国提供商处获得服务之前，IRGC和伊朗政府都未从OFAC获得许可。 

  

此外，还根据FARA查封了27个域名中的四个域名：“rpfront.com”、“ahtribune.com”、“awdnews.com”和“criticalstudies.org”。FARA为外国委托人（包括外国政府及其代理机构）的代理人建立注册、报告和披露制度，以便美国政府和美国人民知悉企图影响美国舆论、政策和法律的信息来源和人员身份。 

  

FARA要求，除其他事项外，相关人员必须定期提交注册声明，其中包含有关其活动和从中获得收入的真实信息。披露所需信息使联邦政府和美国人民可以根据其作为外国代理人的职能评估这些人员的陈述和活动。在这里，这4个域名自称是独立新闻媒体，但实际上是由IRGC或代表IRGC运作的，对美国开展亲伊朗宣传，企图暗中影响美国人民以改变美国对伊朗和中东的政策。 

  

这些域名针对的是美国受众，没有按照FARA进行适当注册，也没有以明显的标签通知美国公众，这些域名的内容是代表外国负责人、IRGC和伊朗政府发布的。
