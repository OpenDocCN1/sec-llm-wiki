漏洞描述

近日，Spring Cloud Function 官方测试用例曝光了 Spring Cloud Function SPEL 表达式注入漏洞，可利用该漏洞通过注入 SPEL 表达式来触发远程命令执行。

目前，Spring Cloud Function 已被许多科技巨头采用，包括 AWS Lambda、Azure、Google Cloud Functions、Apache OpenWhisk，可能还有其他“无服务器”服务提供商。

该漏洞已被归类为 严重 ，CVSS 得分为 9.0（满分 10）。

漏洞影响范围

Spring Cloud Function 的某些版本特定配置（版本 3 <= 版本 <= 3.2.2）的动态路由

WAF方案修复

在WAF设备上，对于头部有这两个字段的HTTP请求进行拦截

  1. spring.cloud.function.routing-expression
  2. spring.cloud.function.definition

漏洞详情请看代码

https://github.com/spring-cloud/spring-cloud-function/commit/dc5128b80c6c04232a081458f637c81a64fa9b52

https://github.com/spring-cloud/spring-cloud-function/blob/dc5128b80c6c04232a081458f637c81a64fa9b52/spring-cloud-function-context/src/main/java/org/springframework/cloud/function/context/config/RoutingFunction.java

提醒

目前网上的分析都是集中在spring.cloud.function.routing-expression，

但从同一个代码分析,spring.cloud.function.definition也可能存在同样的漏洞。

而且spring.cloud.function.definition的代码存在更久。
