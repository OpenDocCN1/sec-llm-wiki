这篇文章介绍如何使用Vue生态的一系列工具从头创建一个手机web应用。这款虚拟的应用是一个新闻应用。

我们准备使用vuetify 2作为material设计组件和Vue Router来处理导航。代码是使用javascript来实现。

文章的代码请见https://github.com/JonUK/vuetify-mobile-app

创建工程

工程使用vue cli 3来创建，先安装它。

npm install -g @vue/cli

创建工程

vue create vuetify-mobile-app

vue cli会通过一些问题提示来指引创建新工程，选择vue 2.x就行了。

这时，vue cli会创建好工程和安装所有的npm依赖包。

在这里，可以尝试运行一下这个新应用。

cd vuetify-mobile-app
npm run serve

用浏览器打开http://localhost:8080/，可见到如下

安装vuetify

Vuetify是一个非常棒的组件框架，它允许我们通过将几个现有的组件组合在一起来创建一个外观很棒的应用程序。

把它作为一个插件安装

vue add vuetify

重新运行一下npm run serve，可以见到

同时也需要安装Material Design字体和图标

npm install --save material-design-icons-iconfont

然后在vuetify插件src/plugins/vuetify.ts导入

import 'material-design-icons-iconfont/dist/material-design-icons.css'

顶部工具栏组件

第一个要创建的组件是应用顶部显示的工具栏组件。

在目录src/components创建TopToolbar.vue

<template>
  <div>

    <v-navigation-drawer
      app
      fixed
      v-model="showMenu"

    >
      <v-list dense>
        <v-list-item @click="doNothing">
          <v-list-item-action>
            <v-icon>settings</v-icon>
          </v-list-item-action>
          <v-list-item-content>
            <v-list-item-title>Settings</v-list-item-title>
          </v-list-item-content>
        </v-list-item>
        <v-list-item @click="doNothing">
          <v-list-item-action>
            <v-icon>help</v-icon>
          </v-list-item-action>
          <v-list-item-content>
            <v-list-item-title>Help</v-list-item-title>
          </v-list-item-content>
        </v-list-item>
      </v-list>
    </v-navigation-drawer>

    <v-app-bar
      app
      fixed
      dark
      color="primary"
    >
      <v-app-bar-nav-icon @click.stop="toggleMenu"></v-app-bar-nav-icon>

      <v-toolbar-title>Vue News</v-toolbar-title>

    </v-app-bar>

  </div>
</template>

<script>
export default {
  data: function() {
    return {
      showMenu: false,
    }
  },
  methods: {
    toggleMenu() {
      this.showMenu = !this.showMenu
    },
    doNothing() {
    },
  },
}
</script>

这里封装了Vuetify工具栏v-app-bar和导航块v-navigation-drawer。“汉堡包菜单”形状图标控制着导航栏的显示，导航栏包括两项“Settings”和“Help",每项都有相应图标。

在代码里，定义一个布尔属性showMenu，也定义一个用于隐藏/显示导航栏的方法toggleMenu。

在这个模块里，属性app和fixed确保工具栏作为应用布局的一部分显示，而不是作为内容的一部分。

v-app-bar组件包含了一个color="primary"属性来设置工具栏颜色为vuetify主题基本色蓝色。

Vuetify使用一个字体文件来包含了所有Material Design图标，把图标名字放在<v-icon></v-icon>标签里，就可以显示一个图标了。

底部导航组件

主要的导航功能在底部导航组件实现。把主要导航功能放屏幕底部是非常适合手机用户使用单手和拇指来操作。

在src/components目录创建一个文件BottomNav.vue

<template>
  <v-bottom-navigation
    app
    fixed
    grow
    v-model="activeItem"
    color="primary"
  >
    <v-btn value="top" >
      <span>Top Stories</span>
      <v-icon>thumb_up</v-icon>
    </v-btn>

    <v-btn value="code" >
      <span>Code Examples</span>
      <v-icon>code</v-icon>
    </v-btn>

    <v-btn value="favorites">
      <span>Favorites</span>
      <v-icon>favorite</v-icon>
    </v-btn>
  </v-bottom-navigation>

</template>

<script>
export default {
    data: function() {
        return {
            activeItem: 'top',
        }
    }
} 
</script>

这里定义了三个菜单项Top Stories， Code Examples和Favourites。属性app和fixed标明了这个底部导航栏是应用布局的一部分。

到这里，整个应用还只是一个壳，接下来使用路由来实现导航。

创建应用外壳

上面已经创建了TopToolbar和BottomNav组件，现在把它们用于App.vue

<template>
  <v-app>

    <TopToolbar></TopToolbar>


    <BottomNav></BottomNav>

  </v-app>
</template>

<script>
import TopToolbar from './components/TopToolbar.vue';
import BottomNav from './components/BottomNav.vue';

export default {
  name: 'App',

  components: {
    TopToolbar,
    BottomNav,
  },

  data: () => ({
    //
  }),
};
</script>

访问一下网页，可以看到这两个新组件已经出现了。

注意：所有Vuetify组件都必须要包含在v-app组件里才能够正确渲染和工作

添加View组件

应用已经稍具雏形了，但是在用户通过底部导航栏选择相应功能时，却还没有任何内容显示。现在需要把内容添加上去。

在src/view创建三个组件TopStories.vue, CodeExamples.vue和MyFavorites.vue。

TopStories.vue：

<template>

  <v-container>
    <h1 class="headline">[[Top Stories]]</h1>
    Content is coming to this mobile app very soon!
  </v-container>

</template>

CodeExamples.vue:

<template>

  <v-container>
    <h1 class="headline">Code Examples</h1>
    Content is coming to this mobile app very soon!
  </v-container>

</template>

MyFavorites.vue:

<template>

  <v-container>
    <h1 class="headline">My Favorites</h1>
    Content is coming to this mobile app very soon!
  </v-container>

</template>

这一阶段不添加任何代码，所以可以忽略<script></script>标签

需要创建路由关联这三个文件，使得可以通过底部导航栏来访问。

在router目录下建立一个index.js

import Vue from 'vue'
import Router from 'vue-router'

import TopStories from '../views/TopStories.vue'
import CodeExamples from '../views/CodeExamples.vue'
import MyFavorites from '../views/MyFavorites.vue'

Vue.use(Router)

export default new Router({
    mode: 'history',
    base: process.env.BASE_URL,
    routes: [
        {
            path: '/',
            name: 'top-stories',
            component: TopStories,
        },
        {
            path: '/code-examples',
            name: 'code-examples',
            component: CodeExamples,
        },
        {
            path: '/my-favorites',
            name: 'my-favorites',
            component: MyFavorites,
        },
    ]
})

更新BottomNav组件，使得每个按钮都可以通过:to参数来引用相应的路由

<template>

  <v-bottom-navigation
    app
    fixed
    grow
    v-model="activeItem"
    color="primary"
  >
    <v-btn value="top" :to="{ path: '/'}">
      <span>Top Stories</span>
      <v-icon>thumb_up</v-icon>
    </v-btn>

    <v-btn value="code" :to="{ name: 'code-examples'}">
      <span>Code Examples</span>
      <v-icon>code</v-icon>
    </v-btn>

    <v-btn value="favorites" :to="{ name: 'my-favorites'}">
      <span>Favorites</span>
      <v-icon>favorite</v-icon>
    </v-btn>
  </v-bottom-navigation>

</template>

<script>
export default {
    data: function() {
        return {
            activeItem: 'top',
        }
    }
} 
</script>

在main.js里引入路由

import Vue from 'vue'
import router from './router/'
import App from './App.vue'
import vuetify from './plugins/vuetify'

Vue.config.productionTip = false

new Vue({
  router,
  vuetify,
  render: h => h(App)
}).$mount('#app')

<template>

应用已经具备初步交互了，可以通过底部按钮切换内容了。
