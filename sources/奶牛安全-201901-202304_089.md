## 创建工程

工程使用`vue cli 3`来创建，先安装它。

```

npm install -g @vue/cli
```

创建工程

```

vue create vuetify-mobile-app
```

`vue cli`会通过一些问题提示来指引创建新工程，选择`vue 2.x`就行了。

这时，`vue cli`会创建好工程和安装所有的`npm`依赖包。

在这里，可以尝试运行一下这个新应用。

```


cd vuetify-mobile-app
```

用浏览器打开http://localhost:8080/，可见到如下

![](../Images/79f9ae260d9f2ddc08b85e3d1fe90102.png)
