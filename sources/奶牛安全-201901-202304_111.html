这里需要解决用户身份丢失的问题，同时学习一些关于User命名空间的知识。

UID和GID映射

用户身份丢失的原因是，进入User命名空间时忽略了一些重要的配置。添加CLONE_NEWUSER标志并不足够让User命名空间准备就绪。为了适当设置命名空间，需要了解一下什么是UID和GID映射。

ID映射和它与命名空间的关系是一个大话题，本文无法覆盖那么多，只能针对那些用户身份相关的内容：

  • User命名空间提供UID和GID的隔离
  • 在任何时候，同一台宿主机可以有多个不同的User命名空间在使用
  • 每个Linux进程运行在这些User命名空间之一。
  • User命名空间允许同一个进程在不同两个User命名空间的UID不同。
  • UID/GID映射提供了一个在两个单独User命名空间映射ID的机制

下图是对上述内容的可视化

两个User命名空间1和2都有相应的UID和GID表。进程C在命名空间1以非root用户运行，可以创建一个在命名空间2以root用户运行的进程D。这里的关键是两个User命名空间的映射（由虚线表示）。

进程D只是在User命名空间2上下文有root权限。从User命名空间1来看，进程D还是以非root用户运行，也没有什么root的权限。

这种映射也是ns-process里缺失的，现在把它补上。

代码

ID映射可以通过设置cmd.SysProcAttr的字段UidMappings和GidMappings。两个字段的类型都是SysProcIDMap，可以在Go的syscall包。

type SysProcIDMap struct {
        ContainerID int // Container ID.
        HostID      int // Host ID.
        Size        int // Size.
}

ContainerID和HostID的含义是显然易见的，Size决定需要映射的ID的范围，它允许一次映射多个ID。

修改一下代码

// Git repo: https://github.com/teddyking/ns-process
// Git tag: 2.1
// Filename: ns_process.go
package main

import (
    "fmt"
    "os"
    "os/exec"
    "syscall"
)

func main() {
    cmd := exec.Command("/bin/sh")

    cmd.Stdin = os.Stdin
    cmd.Stdout = os.Stdout
    cmd.Stderr = os.Stderr

    cmd.Env = []string{"PS1=-[ns-process]- # "}

    cmd.SysProcAttr = &syscall.SysProcAttr{
            Cloneflags: syscall.CLONE_NEWNS |
            syscall.CLONE_NEWUTS |
            syscall.CLONE_NEWIPC |
            syscall.CLONE_NEWPID |
            syscall.CLONE_NEWNET |
            syscall.CLONE_NEWUSER,
            UidMappings: []syscall.SysProcIDMap{
                {
                    ContainerID: 0,
                    HostID:      os.Getuid(),
                    Size:        1,
                },
            },
            GidMappings: []syscall.SysProcIDMap{
                {
                    ContainerID: 0,
                    HostID:      os.Getgid(),
                    Size:        1,
                },
            },
    }

    if err := cmd.Run(); err != nil {
        fmt.Printf("Error running the /bin/sh command - %s\n", err)
        os.Exit(1)
    }
}

上面是一个单一的UID/GID映射，把ContainerID设为0,HostID设为当前用户的UID/GID，Size为1。这里的意思是把新User命名空间的ID为0（root）映射到执行ns-process命令的用户。
