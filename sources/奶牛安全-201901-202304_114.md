# 概述

一条恶意广告链指向`Fallout`利用工具，紧跟着疑似`Arkei`窃密软件的东西。进一步分析，虽然这个样本与`Arkei`有很多相似之处(包括网络事件)，但它实际上是一个较新的恶意软件`Vidar`。

![](../Images/20c0b1a31bd4f246d55df6f23aaade6c.png)

img

除了`Vidar`窃密能力外，还发现从`Vidar`的C2服务器获取的第二个恶意负载。感染时间线显示：受害者先感染`Vidar`，`Vidar`先尝试获取各种私密信息，最后再下载`GandCrab`勒索软件。

## 恶意广告链和`Fallout`利用工具

Torrent和流媒体视频网站带来了大量流量，它们的广告往往咄咄逼人且没有监管。恶意攻击者使用恶意广告域，根据这些站点访问者的地理位置和来源将其重定向到至少两个不同的攻击工具包(`Fallout EK`和`GrandSoft EK`)。

像`AZORult`这样的窃密软件是很受欢迎，但同样`Arkel/Vidar`也相当普遍。在这个例子里，`Vidar`是通过`Fallout`利用工具包推送的。

![](../Images/7a3270d7edbed863e191fde244430f76.png)

img

## `Vidar`

需要注意一点，`Vidar`是通过产品方式售卖，所以，它会由不同的组织在不同的活动分发。

![](../Images/ff1ae1545bf12997b62e3970c6206649.png)

img

`Vidar`的用户可以根据它的配置来定制它，指定他们感兴趣的数据。除了通常的信用卡号码和应用存储的密码，它还会抓取电子钱包的数据。

![](../Images/5fa4a69157b35e57c53c19c382744fc4.png)

img

一旦在系统运行，它会搜索配置指定的数据，然后把这些数据通过未加密的`HTTP POST`请求发到C2服务器。

这些数据会包括系统信息（规格，运行程序，安装软件）和机器的位置（IP，国家，城市和ISP），这些数据会存储在一个叫`information.txt`的文件，再和其它数据打包成一个`zip`包发送到C2服务器。

![](../Images/57db84f8b58de57eee41643b8cfc23f4.png)

img

## 作为GandCrab的加载器

`Vidar`也会通过它的C2服务器下载额外的恶意软件，这是它的加载特性，而且它可以通过在`Vidar`管理面板直接加入恶意软件`URL`来配置。然而，并不是所有`Vidar`都会下载额外的恶意软件。在这种情况，C2服务器只会回应一个OK，而不是一个URL。

```








HTTP/1.1 200 OK
```

在`Vidar`最初感染一分钟后，受害者的文件会被加密，它们的壁纸会显示`GandCrab` 5.04版本
