> 使用Windows快捷方式来做恶意文件，思路非常新颖。
> 
> 译自：http://cyberforensicator.com/2018/12/23/dissecting-cozy-bears-malicious-lnk-file/

通过武器化快捷方式文件来分发恶意软件的方式并不流行，但有时候却会出现。这类文件的一个很好的例子是火眼在2018.11描述的，它与APT29相关，也被称为**安乐熊**。

据信，安乐熊是一个俄罗斯黑客组织。更重要的是，它甚至与俄罗斯外国情报局和俄罗斯联邦安全局联系在一起。

要分析的快捷方式文件是在2018.11.14日发生的有针对性的网络钓鱼活动。网络钓鱼电子邮件包含一个指向ZIP存档`ds7001.zip`的链接。到目前为止，它已经有了相当高的检测率：

系统信息

集中在`powershell`命令的分析。从上面看，`$zk`变量的部分是`base64`编码。

> 请看`$fz`是使用了`FromBase64String`， 0x40就是64

使用`b64`工具对`$zk`解码。

首先，把编码过的数据复制到一个文本文件，然后从命令行运行`b64`

```

b64.exe -d base64_encoded.txt base64_decoded.txt
```

下面是`base64_decoded.txt`的内容

```

















$ptgt = 0x0005e2bf;
```

从上面看出，输出是从`ds7002.lnk`的`0x0005e2bf`位置开始读取到`0x000623b6`位置。使用一个16进制编辑器这里用(`Hex Editor Neo`)看一下这个快捷方式文件的`0x0005e2bf`的内容：

![](../Images/d77fe7f6d57aeb4b75b17daea57c7aff.png)

img

看上去又是`base64`编码的数据。再把这些数据拷贝出来，从`0x0005e2be`到`0x000623b6`，再使用 `b64`工具，可以得到如下代码：

```














function lylyvve(${ntnmbtq}, ${ayxlc}) { 
```

```
























































































































function abejxg($vuvmxt, $crjtjsm, $uuckzka, $syontem) {
```

浏览一下输出，会发现第一个函数`lylyvve`非常常用。可以使用这个函数，因此`PowerShell`将对输出的某些部分进行去模糊处理。复制这个函数并将其粘贴到`Windows PowerShell ISE`，然后按Enter键，就可以用它了。使用输出的以下部分：

```



$oufgke = 0x48bd8
```

看上去又是一些偏移量，看上面`0x48db8`和`0x5e2be`。聚焦到`lylyvve`，把上面代码粘贴到ISE，会得到`%TEMP%\ds7002.pdf`。所以这部分是投放`pdf`诱饵。由于知道偏移值和大小，开始解剖它。

继续用16进制编辑器打开，没有正常的pdf头部

![](../Images/7a809a5db7fea5b341be439d43f77950.png)

![](../Images/d42ef3f57d3305147e831cee30edfe86.png)

再看另外一部分

```



$oufgke = 0x0dd8
```

按照上面步骤来做，会得到文件`%LOCALAPPDATA%\cyzfc.dat`。再根据取这个文件0x0dd8和0x48bd8之间的数据。
