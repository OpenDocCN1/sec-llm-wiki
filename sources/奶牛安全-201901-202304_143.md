# 志怪小说：蜃楼风水

译自清朝李庆辰著《醉茶志怪》的《城南三则》  
县城南三里处，叫黑牛城，本来是旷野，每逢大雾天，就会出现城楼，垛墙敌楼一一具备，天一放晴就立马消失。  
有人说这是辽国的遗址，但没有考据。  
天津离海不远，应该是海市蜃楼之类。  
\--------------------------------------------------------------------  
有南方人过来天津等候官场空缺，精通风水学。  
一天，他望见南城有旺气冲天，如果把先人骨头葬在那里，应该可以官运亨通，于是他打算把先人骨头迁葬过来。  
迁葬的当晚，风雷大作，他们一行人打开先人的坟抬出棺材，就往旺穴去。  
他们挖开旺穴，把棺材放下去，填埋上泥土。  
泥土刚填完，闪电立马劈开墓穴。  
如此这般，棺材几乎被雷火烧焚，他们过于恐惧，只好作罢，把先人骨头迁回原址。  
译者注：这名南方人能够当官，从风水角度来看，也是先人阴宅风水好，何必要挪。何况，有不少旺气不一定是阴宅发出来，可能也是有精怪修仙发出，迁葬过去，只会帮精怪挡雷劫。擅自迁葬，容易惊扰死者，破坏之前风水灵气。  
\--------------------------------------------------------------------  
  
县中有人通过风水师找到一处旺穴，挖开泥土三尺后，见到地下有一层平砖。  
旁边有一个人阻止他说“砖一挖开，灵气就泄露了，这穴就不旺了”  
风水师极力主张挖开。  
一挖开，砖下都是清水，有一条蛇和一只蟹，缠绕在一起，一见人就立马走了。  
阻止的人大叹一声，走了。  
译者注：这个穴应该是很早之前有人改造过。因为砖肯定是人铺的。穴中有清水，说明有水源，有水就有生气。但只是水不行，所谓水不在深，有龙则灵。蛇是小龙，所以蛇是让穴的生气变成灵气。蟹，在水族是将军。就是小龙抬棺，蟹将军守卫。葬在这，肯定是官运亨通。改造这穴的人才是真正懂风水，那个风水师只是半桶水。而我呢，只是胡诌。
