# 志怪小说：妖精渡劫

摘自清朝李庆辰著《醉茶志怪》的《怪雨》  
  
1873年7月一个夜晚，暴风雷雨，运河中有舟，盐船几十艘，同时沉没。  
起初，天刚刚阴晦，船只纷纷靠岸，都用苇席遮挡，人都躲入船舱。  
一只船的苇席被风吹开，船夫出来，准备盖好它，一抬头看见对面波浪高如山，有蓝衣妇女站在浪头，用衣襟装着三四枚茄状物体，颜色深紫，在电光中，纤毫可见。  
船夫惊骇之下倒毙在船上，风狂雨骤，于是所有船只都遇难了。  
当时邻县有善人，用船只打捞遇溺尸体，见船夫尸体顺序而下，捞起发现尸体还没冷，过了半天后，船夫苏醒，他说起当时情形就这样。  
大概船夫因为一时闭气，水并没有进到腹中，才能够活下来。  
船夫看着河中浮尸船板，络绎不绝，不由痛心大哭。  
上岸处已经离沉船的地方，已经有百来里。  
善人资助船夫盘缠，让船夫得以回家。  
有人说妇人是鱼精，但没什么证据，但能够站在浪头上，肯定是精怪无疑。  
又有同县人去河南，船在黄河上，见到岸上站着不少人，互相指着某处看。  
同县人仔细看天边，有一处乌云，出现两只脚，一妇人拿着伞站在云端，露出半个身子，向东面飞驰。  
身后电闪雷鸣，紧追着她。  
当雷电即将追及，妇人就转身用雨伞格击，雷电立马退后。  
这样持续一会，雷电妇人都消失不见。  
一会，雨停天晴，云消雾散。  
当时正好中午，有人说是飞天夜叉。但夜叉偶尔会遇到，却没有过在云中显形给大家看到的事情，但又不知道是什么怪物。
