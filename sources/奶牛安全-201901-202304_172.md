# 志怪小说：宝木茵陈

摘自清朝李庆辰著《醉茶志怪》的《茵陈木》  
  
武清渔人在河里打鱼，拉网时发现有东西挂在网上很重，于是叫一村民一起拉网。  
网拉上来，得到一个物件，外面用锡浇灌，打破锡皮，有棵大木头，用黄绢包裹，上面写“永乐二年，臣某贡“，原来是茵陈木。  
两人争抢要木头，并互相殴打。  
县中官差倪某见到，说“这是上贡的御物，你们留着可能会给自己带来灾祸。”  
两人害怕极了，向倪某请教对策。  
倪某说“我家幸好有一块闲地，可以用来藏起来，送给你们千来钱，让我背这个灾祸吧。”  
两人拿了钱，欢呼雀跃而去。  
倪某用木头给父母做了两副棺材还有剩余，于是把剩余的偷偷珍藏起来。  
有懂行的说“木头一般是按十三件规格来运输，船翻落水，当时只捞到九件，其余没找到。现在倪某得到一件，还有三件，不知道落在谁的手里”
