基本操作

Python 是众所周知的解释型语言。但是在部署 Python 应用程序时，总是依赖于使用正确版本的库。Ansible / Docker 等工具以一种方式解决了这个问题。创建安装程序以另一种方式解决了问题。

PyInstaller 库可帮助您创建 Python 脚本的可执行（二进制）版本。我的python脚本名字叫recorder.py

  1. 确保 python3 开发库可用**（Linux 用户）**
sudo apt-get install python3-dev

  1. 安装PyInstaller库

    pip3 install pyinstaller

    Linux用户可能需要使用sudo

  2. 切换到包含Python脚本的目录，执行如下命令

    pyinstaller recorder.py --onefile 

  3. 检验一下效果

     ./recorder
     usage: recorder [-h] [-c CONFIG]

    antifraud monitor

    optional arguments:
      -h, --help            show this help message and exit
      -c CONFIG, --config CONFIG
                            specify config file

对于有参数的脚本

如果原来脚本是这样运行的

python recorder.py -c config.json

通过pyinstaller产生的执行文件，执行如下

./recorder -c config.json

对于通过virtualenv创建的工程

对于这种工程，pyinstaller创建的执行程序，在运行往往会出现这种提示

ImportError: No module named xxxx

那么通过pyinstaller生成时，要这样

pyinstaller recorder.py --onefile -p venv/lib/python3.9/site-packages/
