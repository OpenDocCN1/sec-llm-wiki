## 基本操作

Python 是众所周知的解释型语言。但是在部署 Python 应用程序时，总是依赖于使用正确版本的库。Ansible / Docker 等工具以一种方式解决了这个问题。创建安装程序以另一种方式解决了问题。

PyInstaller 库可帮助您创建 Python 脚本的可执行（二进制）版本。我的python脚本名字叫recorder.py

1.  确保 python3 开发库可用\*\*（Linux 用户）\*\*

```

sudo apt-get install python3-dev
```

2.  安装PyInstaller库
    
    ```
    
    pip3 install pyinstaller
    ```
    
    > Linux用户可能需要使用sudo
    
3.  切换到包含Python脚本的目录，执行如下命令
    
    ```
    
    pyinstaller recorder.py --onefile 
    ```
    
4.  检验一下效果
    
    ```
    
    
    
    
    
    
     ./recorder
    ```
    

## 对于有参数的脚本

如果原来脚本是这样运行的

```

python recorder.py -c config.json
```

通过`pyinstaller`产生的执行文件，执行如下

```

./recorder -c config.json
```

## 对于通过`virtualenv`创建的工程

对于这种工程，`pyinstaller`创建的执行程序，在运行往往会出现这种提示

```

ImportError: No module named xxxx
```

那么通过`pyinstaller`生成时，要这样

```

pyinstaller recorder.py --onefile -p venv/lib/python3.9/site-packages/
```

## 校验结果

检测生成的文件是正常二进制文件

```

(venv) buckxu@hidsserver:~/code/py2elf/dist$ file recorder 
```

确实是正常二进制文件

看是否加壳

```








































































(venv) buckxu@hidsserver:~/code/py2elf/dist$ readelf -S recorder 
```

有正常的`.text`, `.data`, `.rodata`，`.bss`段，多了一个`pydata`段，并没有加壳。

## 使用UPX对文件进行加壳

> 请到这https://github.com/upx/upx/releases/tag/v3.96 下载UPX，pyinstaller的`--upx-dir`选项无效

加壳

```

./upx -v -9 -k recorder 
```

检验

```






buckxu@hidsserver:~/code/upx-3.96-amd64_linux$ ./recorder
```

看看段信息

```




buckxu@hidsserver:~/code/upx-3.96-amd64_linux$ file recorder
```
