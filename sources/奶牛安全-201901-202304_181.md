# 志怪小说：女虎妖

摘自清朝李庆辰著《醉茶志怪》的《申仲权》  
  
申仲权，河北人，多次参加科举都没考上，生活过得非常落魄潦倒。  
申有表亲冉某，在东北一将军府里当文书，于是过去投奔。当他到达时，将军已经到其它地方任职，冉某也跟着去了。  
申非常郁闷打算再去寻找投奔，但身上钱财已经花光了，只好投奔挖参的同乡。  
同乡四五个人生活都很困苦，自己都无法糊口，只好给一把长铲他，叫他跟着一起挖参。申挨不了这种苦，大家也嫌他累赘，却不忍心赶走他。  
一天，大家入山挖参，申走不动了，在松树下稍息一下。一会儿，大家就不见踪影。  
申跑去寻找他们，到一处，山重水复，道路曲折，已经迷路了。  
这时候，太阳快下山了，风声四起，申打算寻找一个石洞，用来避虎豹豺狼。  
正在迟疑间，他看见一名女子，容貌姣丽，腰间系着白鹿皮裙，到溪边捧水喝。  
申走向前，解下腰间的瓢给女子。女子欣然接受，喝完，把它还给申。  
申向女子问路，女子说“这山中很少有人住，前面山峦密集的地方是我家。那边没有甘泉水，所以每次都到这边喝。然而，这里离大路非常远，你为什么跑到这里来？”  
申把缘由告诉她，希望她可以收留。女子不答应，转身就要走。  
申不断地哀求，甚至都哭出来了。女子只好带着他走。  
转过一个山坡，有一道小桥，小桥下芦苇杂生，一路上青蛙的鸣叫，蚯蚓的叫声，显得非常凄楚。  
又走了几里路，见到一大石桥，不知道有多长，石栏雕镂，宛若天成。  
大石桥尽头是一个山庄，有一石门向南。进去发现石室精致整洁，非常宽阔。  
女子带申仲权到一个房间说：“你暂且呆在这，我给你准备点吃的”，然后女子自己进去庄内。  
申看见房间的床和桌子，都是石做的。墙壁上，花纹就像画一样，花草树木，人与物体，均栩栩如生。  
正在参观时，门外一只老虎跑过，申战栗不敢乱动，趴在石床上。  
过了一会，女子进来，拿出一样像手臂大小的东西给他，红润鲜软，不知道叫什么名字。  
女子说：“吃一点就可以饱了，剩下的带回去卖了可以发财”，说完就走开了。  
申掰着吃，味道甘甜，一下就饱了，留下一半放在怀里。  
天开始亮了，女子过来，给他指出回家的路。  
申仲权一路拨草寻路，翻山越岭，终于走出山了，回头看出路，只见重峦叠嶂，根本无路可走。  
申满腹狐疑地回去，把怀中的物件给同乡看，原来是上好的人参，于是把它卖了，得了一百两黄金，整理好行李回乡下。
