python web框架tornado处理静态文件的探究

目标结构如下：

.
├── main.py
├── static
│   ├── index.html


1 directories, 3 files

static\index.html

<html>
    <head>
     <title>Hello</title>
    </head>
    <body>
     <h1>Hello world!</h1>
    </body>
</html>

main.py

import os
import tornado.web

urls =  [
    ( r'/()',  tornado.web.StaticFileHandler,  {"path": os.getcwd() + os.sep + "static", "default_filename": "index.html"} ), 
]

if __name__ == "__main__":
    app = tornado.web.Application( urls )
    app.listen(port=8888)
    tornado.ioloop.IOLoop.current().start()

r'/()'的()非常重要。一开始，是没有加上这个。结果变成了404.

上面的例子是基于tornado.web.StaticFileHandler

To serve a file like index.html automatically when a directory is requested, set static_handler_args=dict(default_filename="index.html") in your application settings, or add default_filename as an initializer argument for your StaticFileHandler.

使用 curl来请求一下

buckxu@kali:~$ curl 'http://127.0.0.1:8888'
<html>
    <head>
     <title>Hello</title>
    </head>
    <body>
     <h1>Hello world!</h1>
    </body>
</html>

如果要支持其它的html文件，就要把urls改成这样

urls =  [
    ( r'/(.*\.html)',  tornado.web.StaticFileHandler,  {"path": os.getcwd() + os.sep + "static", "default_filename": "index.html"} ), 
]
