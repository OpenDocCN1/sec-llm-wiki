由空闲内存的探究，可以得到空闲内存的数据结构大致如下：

struct _FREE_ENTRY
{

 struct _HEAP_ENTRY header;

 struct _LIST_ENTRY list;

};

由上面，可以得到判断一个地址addr(指代任何一个地址)是不是有效地址的方法：

  1. 用!heap –v得到所有的堆。再用!heap –hf addr看一下，addr是不是堆列出的堆块地址范围。如果不在的话，那么addr就是野指针。如果在，那么addr是不是某个堆块地址**+8**.如果不是，那么，那么addr可能是野指针，或者是被损坏了,或者指错位置了。
  2. 或者，把addr减去0x8得到BlockAddr(堆块地址)，用dt _HEAP_ENTRY BlockAddr看一下Size和PreviousSize.再用dt _HEAP_ENTRY BlockAddr-8*PreViousSize得出前一堆块的Size值，如果不和BlockAddr的PreviousSize相等，那么堆块有可能被损坏了，或者是野指针，或者指错位置。如果上一个堆块用同样的方法验证，是对的。那么，addr所在的堆块应该是损坏了，被上一堆块的数据覆盖了。如果addr和上一个堆块验证没问题的，但Size和下一堆块的PreviousSize不相等，那么，addr所在堆块的数据覆盖了下一个堆块。
  3. 当addr可以通过1，2两种方式的验证，那么它是一个有效地址。如果根据它的Size可以在FreeLists里面找到它，那么它就是一个有效的空闲堆块。
