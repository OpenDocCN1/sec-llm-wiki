*   **获取powershell默认编码**

```

$OutputEncoding
```

*   **改变powershell默认输出编码为UTF-8**

```

 $OutputEncoding = [Text.UTF8Encoding]::UTF8
```

*   **powershell文本转换成utf-8**

```



$Enc = [System.Text.Encoding]::UTF8
```

*   **powershell发送utf-8编码的数据**

```





$Headers = @{"Content-Type"="application/json;charset=utf-8"}
```
