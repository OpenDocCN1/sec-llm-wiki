在Windows下载了ElasticSearch 6.6.0，跑了点数据进去，发现ElasticSearch拒绝了数据。想看一下它的日志在哪？

在powershell看一下elasticsearch安装在哪里？

```

 Get-Process -Name elasticsearch|Select-Object -Property Path
```

结果如下：

```



Path                                                              
```

用powershell看一下`C:\Program Files\Elastic\Elasticsearch\6.6.0`下

```

Get-ChildItem -LiteralPath 'C:\Program Files\Elastic\Elasticsearch\6.6.0\' -Recurse
```

发现并没有配置目录

```

```

根据这篇文章Directory layout of .zip archive 在Powershell上看一下有没有ES相关的环境变量

```

 Get-ChildItem env:*|Where-Object Name -Match "ES_"
```

发现存在有ES配置文件目录。

```




Name                           Value                                                                                             
```

看一下`C:\ProgramData\Elastic\Elasticsearch\config`

```

Get-ChildItem $env:ES_PATH_CONF
```

结果

```











    目录: C:\ProgramData\Elastic\Elasticsearch\config
```
