2021年是辛丑年，值年太岁为`杨信将军`或`汤信`。`汤信`没找到记载，`杨信将军`可以找到三个：

1.  汉朝使节

```

杨信，辛丑太岁，汉时降生于陕地，名杨信。汉武帝元鼎时杨信出使匈奴。杨信刚直屈强，忠贞不二，不辱使命。单于见杨信一介儒生，素非贵臣，屡加刁难。单于欲召入，杨信节不离手，单于乃坐穹庐外见之。是时，武帝东拨胞溃貉、朝鲜为郡，西置酒泉郡阻断胡羌通道，并西通月氏、大夏，分裂匈奴之援国。杨信说单于欲和亲则以单于太子质汉。单于欲折其词，挫其气，乃以缯絮食物为和亲之首，终末果。后遣信归。
```

2.  五代麟州(在陕西)刺史，杨家将老爸

```

杨信是五代时麟州新秦县的地方豪强，以武力称雄于一方。后晋天福七年，河东步军都指挥使刘崇为麟州刺史时，杨信命长子杨业追随左右。
```

3.  明朝名将，西北长城

```



杨信（1422年1月24日－1478年1月10日），字文实，应天府六合县（今江苏省南京市六合区）人。镇北大将军杨洪之侄，明朝名将。
```

这三人都是**忠心，勤勉，有勇有谋略**，且都是在**西北**建功立业，守护国家边疆的英雄。故今年的**太岁位在西北**。

本命年犯太岁，是为**年冲**，就是属相是这一年。值年太岁最初也是，也是有人的感情的，只要投其所好即可。辛丑太岁在世都是铁骨铮铮的汉子，肯定是`重英雄惜英雄`，会庇护努力勤恳肯干有想法的人。

因此：

1.  在事业上，本命年的朋友今年应该忠心勤勉，做事应该肯于承担，奋勇向前，多思多学，改进做事方法。
    
2.  在财运上，太岁位在西北，做贸易的朋友应该多点关注一带一路方面，比如”中欧班列“。**如果有朋友真这样发财了，请回来打赏**。
    

## 符

回到符方面，当时朋友放了四个符，第一个符是这样

![](../Images/da10599d306dc5ad112fd16712d38ba6.png)

这个符呢，如果是庚子年（2020年）用的话，本来不犯太岁，不惹小人，太岁都会降祸（庚子年是鼠年）。再者，猫是邪灵，特别是黑猫。只要翻一下古代志怪小说，有不少因猫而尸变的记载。用这种猫符，只怕内鬼引外鬼，里应内合，不光犯太岁惹小人，还家嘈屋闭。这种猫符，还不如狗符呢。狗护主，在古代志怪小说里，有不少狗帮主人驱邪挡煞的记录

第二个符是这样的

![](../Images/6c20b2d460b91fa9919d54fda11b3e8f.png)

天师符，貌似好像可以。不过呢，天师符一般是用于镇宅驱邪作用，也就是说，已经出事了。但目前求符是防范于未然，是避凶择吉。且茅山术也曾经被心术不正的人用于作恶。这个符文不太懂，用不好，恐怕会引煞上身。

第三个符是这样的

![](../Images/6d16ac34a7fd5575494d003c1f74f994.png)

这个符是勅令符，是庚寅年用的，貌似改成年份，就符合要求了。但，符是道教的，经是佛教的，从上面的符文来看，又佛又星君的，和拿着KFC的优惠券要求KFC和金拱门都提供五星级服务，用这种符的人，不怕惹小人了。能够挑拨两大神灵系统的斗争，还怕什么小人。

第四个符是这样的

![](../Images/cf4f53e2c82e039a3de282162d82430b.png)

这个也是勅令符，从平时从庙里求的平安符样式一样。从符文内容来看，是一个和合符，从符文内容来看，都是阴阳调和，一团和气，且`”天合气收罡“`也预示着一团和谐从而蒸蒸日上，和大家希望的“家和万事兴”，“和气生财”的愿望契合。且行文的书写，笔走龙蛇，行云流水，一气呵成，也代表着”顺风顺水，毫无阻滞”。不过个人对符了解不多，这个符在符文内容更加改进，会好一些。
