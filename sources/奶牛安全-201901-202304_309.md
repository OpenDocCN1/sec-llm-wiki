# CISSP考试指南笔记：4.9 内联网和外联网

When a company uses web-based technologies that are only available inside its networks, it is using an **intranet**, a “private” network.

An **extranet** extends outside the bounds of the company’s network to enable two or more companies to share common information and resources.

Trading partners often use **electronic data interchange (EDI)**, which provides structure and organization to electronic documents, orders, invoices, purchase orders, and a data flow.

A **value-added network (VAN)** is an EDI infrastructure developed and maintained by a service bureau.
