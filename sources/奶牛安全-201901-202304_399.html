接着看这一段汇编

edx = cnt;

eax = argv

ecx = argv[cnt];

size_t len = strlen( argv[cnt] );

上面翻译的理由:

1.     ebp-4在前面已经是表示cnt

2.     ebp+0xc由于main函数的原型可知是argv

3.     由于char*是4个字节大小,所以eax+edx*4是argv[cnt]

4.     eax是返回值,那么ebp-8用来存放返回值,命名为len;

 

xuzhina_dump_c04!main函数就大致如下了:

终于,整个汇编都被翻译成C/C++代码了.而且标红加粗的那一行,就是程序coredump的那一行代码.

{

    for ( int cnt = 0; cnt < argc; cnt++ )

    {

       size_t len = strlen( argv[cnt] );

       if ( len == 0 )

       {

       }

       else if ( len == 1 )

       {

       }

       }

       {

           printf( “%s”, cnt );

       }
