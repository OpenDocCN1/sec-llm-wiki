在了解了上面指令之后,开始逆向上面的xuzhina\_dump\_c04!main函数,看一下它是怎样的实现.

 

知道有参数的main函数的原型是

int main( int argc, char\* argv\[\] );

首先从开始看这个函数的汇编,会先看到这几个跳转语句,如图标识:

![](../Images/36e4fd7c6d54df3f8ef9975b6e1c052b.png)

![](../Images/e231d3bd08424518e859bbf3e60ee6a0.png)

从上图,可以知道, ebp+8是argc, 而0x004010b6之后的指令已经是函数退出时操作了.可以知道0x00401018-0x0040101e处的汇编,翻译成C语句大致如下:

| if ( \*(ebp-4)  >=   argc ) return; |
| --- |

而

![](../Images/03a2ef9337aceba8dc087f14a12859c4.png)

表示 \*(ebp-4) +=1的意思.所以, 可以命名ebp-4指向的变量为cnt;

那么这一段指令

![](../Images/013870708097cb587b58cd3748ef5820.png)

就是表示这样的意义

| cnt++;if ( cnt >= argc ) return; |
| --- |

但由

![](../Images/7259818f0466762a019e6bc97b04e38c.png)

的程序是不会执行到cnt++;这一条语句,难道它是循环?搜索一下,看看哪一条指令跳到0040100f,可以找到这一条:

![](../Images/2b36e53da8c00a433297f4af736c883f.png)

由高地址跳转到低地址,和循环的意义一样.

xuzhina\_dump\_c04!main函数就大致如下了:

| int main( int argc, char\* argv\[\] ){for ( int cnt = 0; cnt < argc; cnt++ ){![](../Images/b1a7a91e690ae9d6798d2aa6cb053d77.png)}} |
| --- |

接着看这一段汇编

| ![](../Images/55ead4c76f4e83d4018cd9cb330797cd.png) || edx = cnt; |
| --- | --- |
| ![](../Images/b0b4cac955b366fe6b64eab590c6420c.png) || eax = argv |
| ![](../Images/1fb62e7c706c2dca0249b984de080467.png) || ecx = argv\[cnt\]; |
| ![](../Images/aef8a803477331422438e236c9eb80f6.png) || size\_t len = strlen( argv\[cnt\] ); |

上面翻译的理由:

1.     ebp-4在前面已经是表示cnt

2.     ebp+0xc由于main函数的原型可知是argv

3.     由于char\*是4个字节大小,所以eax+edx\*4是argv\[cnt\]

4.     eax是返回值,那么ebp-8用来存放返回值,命名为len;

 

xuzhina\_dump\_c04!main函数就大致如下了:

| int main( int argc, char\* argv\[\] ){for ( int cnt = 0; cnt <argc; cnt++ ){  size\_t len = strlen(  argv\[cnt\] );![](../Images/6860314d55d847040eceb90cb7dbcb69.png)    }} |
| --- |

现在需要把剩下的汇编翻译成C/C++代码.先看一下跳转语句:

![](../Images/7242935e26bc226e5188c539a10459a7.png)

从上面可以看到ebp-0xc是由ebp-8赋值的,也就是局部变量len.那么这一段汇编

| --- |

可以翻译成

| --- |

根据上面那段汇编的跳转地址,0x00401053,0x00401070, 0x0040108b, 0x0040109f及相应的汇编,可以把剩下的汇编翻译成这样

终于,整个汇编都被翻译成C/C++代码了.而且标红加粗的那一行,就是程序coredump的那一行代码.

| int main( int argc, char\* argv\[\] ){    for ( int cnt = 0; cnt < argc; cnt++ )    {       size\_t len = strlen( argv\[cnt\] );       if ( len == 0 )       {           printf( “%c”, argv\[cnt\]\[0\] );       }       else if ( len == 1 )       {           printf( “%s”, argv\[cnt+1\] );       }       else if ( len == 2 )       {           printf( “%d”, cnt );       }       else       {       **    printf( “%s”, cnt );**       }    }} |
| --- |
