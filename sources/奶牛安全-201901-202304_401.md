C/C++或者其它高级语言,函数或者子过程都会有三种结构:顺序结构,条件结构,循环结构.

实际上,这三种函数内执行结构就构成函数的骨和肉.由于顺序结构是很单调地往下执行,而条件结构和循环结构却不大一样,它们都是会根据条件来决定执行.所以,条件结构和循环结构是构成了函数的骨架,顺序结构可以说是函数的肉.

如果需要能够从某一个函数的汇编中找出对应哪一行代码出了问题,必须能够快速把函数的骨架找出来,也就是说,把循环结构和条件结构找出来.

在C/C++语言里,这两种结构的关键字是if, else, do, while, for之类.汇编也有表示同样作用的指令,如下表:

|

| --- | --- | --- |
| 条件跳转指令 || jmp || 无条件跳转 |
| JAE/JNB || 大于或等于跳转,用于无符号整数运算 |
| JA/JNBE || 不小于或不等于跳转,用于无符号整数运算 |
| JB/JNAE || 小于跳转,用于无符号整数运算 |
| JBE/JNA ||  小于或等于跳转,用于无符号整数运算 |
| JG/JNLE || 大于跳转,用于有符号整数运算 |
| JGE/JNL || 大于或等于跳转,用于有符号整数运算 |
| JL/JNGE  || 小于跳转,用于有符号整数运算 |
| JLE/JNG || 小于或等于跳转,用于有符号整数运算 |
| JE/JZ  || 等于跳转 |
| JNE/JNZ || 不等于跳转 |
| JC  || 有进位跳转 |

其实在实际程序中,很少会用loop,loope,loopne这些指令,因为它比较设置条件有限.往往是用条件跳转指令来实现的.在分析这个例子时,会看到的.

同时,函数的骨架除了由条件指令和循环指令,还可以由函数间调用来确定.为什么呢?可以想像一下,如果一个函数先后调用了a,b两个函数,而coredump是发生这个函数调用a,b之间的指令.那么完全可以确认coredump的代码行肯定是位于a,b的调用地方.而调用在汇编也是有相应的指令,见下表:
