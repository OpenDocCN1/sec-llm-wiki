在前面看过了一个vectorcoredump的例子,接触了vector的iterator,可以知道vector的iterator只有一个成员_M_current指向vector某一个元素.或许其它container类的iterator也是这样.

先看一个例子:

#include <vector>
void init( std::vector<int>& vec ){    for ( int i = 0; i < 0x10; i++ )    {        vec.push_back( i );    }}
int getSum( std::vector<int>& vec ){    std::vector<int>::iterator iter;    int result = 0;
    for ( iter = vec.begin(); iter != vec.end(); iter++ )    {        result += *iter;    }
    return result;}
int main(){    std::vector<int> vec;    init( vec );
    return getSum( vec );}
