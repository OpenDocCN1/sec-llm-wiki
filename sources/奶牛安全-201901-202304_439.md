而cnt在每次循环比较结束条件时，都会：

```

```

且cnt在循环比较结束条件时，都会

*   

```

```

可见，result函数的第二个参数是数组要遍历的个数。

再者，由于函数指针和它两个参数的获得只是最后一条指令不一样，且它们是以数组的元素为基地址的。可以推断它们是结构体。
