想用python免费调用一下某在线翻译的接口，即使直接copy一个现成的会话cookie，每次还是会收到503响应。

分析发现打开该翻译在线会加载一堆js，这些js会生成一些唯一的标识。实在没心情分析这些js的内容，考虑一下python + selenium是否会实现。

由于使用的是firefox，按照https://selenium-python.readthedocs.io/installation.html#downloading-python-bindings-for-selenium下载geckodriver，并在PATH环境变量包含的路径。如下图：

直接根据https://selenium-python.readthedocs.io/getting-started.html的例子修改，如下

from selenium import webdriverfrom selenium.webdriver.common.keys import Keysimport timeimport sys
if len( sys.argv ) < 2:    print( "supply a argument")    sys.exit(-1)
driver = webdriver.Firefox()driver.get("https://fanyi.unkown.com/")src = driver.find_element_by_xpath("//div[2]/div[2]/div/div[1]/div[1]/textarea")src.clear()src.send_keys(sys.argv[1])src.send_keys(Keys.RETURN)time.sleep(1)   #关键部分，用于等待后台返回翻译结果，否则下一行会抛异常dsts = driver.find_elements_by_xpath( "//div[2]/div[2]/div/div[2]/div[2]/span")for dst in dsts:    print( dst.text )time.sleep(5)driver.close()
