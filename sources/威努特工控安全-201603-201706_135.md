# “天公降才在此期，长风破浪会有时！” ——“信息安全铁人三项赛”华电+威努特战队启动仪式在华北电力大学盛大召开

2016年7月11日下午，“信息安全铁人三项赛”华电+威努特战队启动仪式在华北电力大学盛大召开。华北电力大学控制与计算机工程学院副书记谢桂庆、北京威努特技术有限公司总经理龙国东、北京西普阳光教育科技股份有限公司课程总监、大赛技术委员会委员刘春利以及华北电力大学100余名同学共同出席了此次会议。

 ![](../Images/ec94cdd826f9c1975b6ddf1d9f9cfc1a.png)  
  

谢桂庆副书记在致辞中首先为在场学生介绍了信息安全铁人三项赛的概况，并指出，2016年4月19日，习近平总书记在京主持召开网络安全和信息化工作座谈会并发表重要讲话强调：“要聚天下英才而用之，为网信事业发展提供有力人才支撑。网络空间的竞争，归根结底是人才竞争。引进人才力度要进一步加大，人才体制机制改革步子要进一步迈开。各级党委和政府要从心底里尊重知识、尊重人才，为人才发挥聪明才智创造良好条件。要不拘一格降人才，解放思想，慧眼识才，爱才惜才。”中央网信办网站2016年6月6日发布了《关于加强网络安全学科建设和人才培养的意见》（以下简称《意见》）。《意见》称，为加强网络安全学院学科专业建设和人才培养，经中央网络安全和信息化领导小组同意，提出以下八项意见：加快网络安全学科专业和院系建设，创新网络安全人才培养机制，加强网络安全教材建设，强化网络安全师资队伍建设，推动高等院校与行业企业合作育人、协同创新，加强网络安全从业人员在职培训，加强全民网络安全意识与技能培养,完善网络安全人才培养配套措施。

  

谢副书记认为，“信息安全铁人三项赛”的校企结合模式，完全符合习总书记的指示精神和网信办的指导意见，对企业、院校乃至参赛学生来说，可谓意义非凡。对于企业来说，与院校结对可以深入了解院校网安科研和学生实力，建立长效的校企合作模式、建立校企双方交流平台，促进信安行业交流、通过“学徒”模式的大赛，推广企业品牌，挖掘和培养人才，促进整个生态链的人才供应。对于院校来说，与企业合作对于建立校企连接渠道，解决企业资源进校难的问题有很大帮助、同时引入企业虚拟师资，促进学校课程体系及人才培养改革、借助用人单位和大赛力量，营造校内网安氛围，提升网安影响力、最终对接用人单位需求和产业最新技术，促进学校科研和专业培养方案。而对于院校学生来说，校企合作模式可以帮助在象牙塔中的学子走出校门，开拓视野，提前接触网安产业，了解网安一线技术和相关职业前景，而企业导师提供的“新学徒”的技术和职业指导，则可提前让学生们进行个性化的学习规划和职业发展。在新的竞赛环境下，通过校企结合，来批量培养、选拔优秀的信息安全人才，“信息安全铁人三项赛”就是能够真正实现“不拘一格降人才”的实战技能赛事。

接下来，刘春利委员为现场学生详细介绍了大赛具体内容、价值以及9月份即将开赛的华北地区赛事日程。他说，大赛分为“信息安全数据分析对抗赛”、“企业计算环境安全对抗赛”和“个人计算环境安全对抗赛”三大类，强调贴近实战，采用基于真实应用场景下的安全对抗来检验参赛学生的信息安全工程能力和攻防技术能力、展示企业实力。![](../Images/66426c8384511dffcd4edfa4aed986ab.png)

龙国东总经理上台后简要介绍了北京威努特技术有限公司的概况——威努特是一家专注于工业控制系统网络安全产品与解决方案研发的创新型公司，公司致力于为工业客户提供工控安全整体解决方案与服务。公司成立短短两年来，就已经成长为国内工控安全行业的领军企业，在行业内深受认可，是国家工控安全实验室理事单位，并成为2016年杭州G20峰会公安部网络安保单位。威努特自成立之初就与众多高校科研院所紧密合作，全力推进国家工控安全人才培养工作：

1、参与华北电力大学举办的国内第一届工控安全攻防比赛，并获得第三名

2、与上海第二工业大学共建《工控安全概论》创新课程，并建立工控安全实训平台  

3、与北方工业大学共建工控安全实训平台

4、与北京石油化工学院共建《石化行业信息安全攻防实验室》![](../Images/a1f0bbf1b252182f8c653a251357810c.png)

龙总强调，威努特与华电结对后，能够参赛战队提供很多服务，其中包括赛前五天的集中培训，包括企业IT环境介绍、企业网设计、工控安全攻防实践、网络协议分析、入侵防护实践和安全日志分析实践等，并且威努特安全试验室可以提供10名宝贵的实习机会，针对优秀毕业生可以优先录用。他的讲话获得在场学生的积极响应，会后已有数十名学生积极踊跃报名参赛。
