# 威努特应邀参加2015年《数字化油气田高峰论坛》

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTgyODU3NQ==&mid=2651060189&idx=1&sn=b3067f542066d0b745bcd2e315237541&chksm=80e1ed6db796647b79f474a35284ab4539ab5d9e4430c19cc37237790a61a29e033e76e655e2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNTgyODU3NQ==&mid=2651060189&idx=1&sn=b3067f542066d0b745bcd2e315237541&chksm=80e1ed6db796647b79f474a35284ab4539ab5d9e4430c19cc37237790a61a29e033e76e655e2&scene=27#wechat_redirect)

9月23日，由中国石油和石油化工设备工业协会主办的2015年《数字化油气田高峰论坛》在重庆隆重召开，北京威努特技术有限公司应邀参加。本次论坛邀请了中外知名企业和行业专家现场演讲，交流研讨国内外数字化油田的最新应用技术与实施方案，以推进我国油田数字化的应用水平。

![](../Images/88074dc57427bd7e81abda553b185232.png)  

  

威努特技术有限公司副总经理发表了题为《构筑网络安全“白环境”》的演讲，指出分析了石油石化行业工业系统网络面临众多网络安全问题及发展趋势。在此形势下，威努特提出了工控安全“白名单”解决方案。运用白名单的思想，通过对工控网络流量、工作站软件运行状态等进行监控，运用大数据技术收集并分析流量数据及工作站状态，建立工控系统及网络正常工作的安全模型，进而构筑工业控制系统的网络“安全白环境”。

  

  

此次受邀参会，为我公司进一步了解和掌握石油石化行业最新动态及先进技术提供了便利，同时也为我公司提供了展示最新产品的平台。威努特将继续坚守责任与使命，服务于广大石油石化行业用户，为用户的工业信息安全保驾护航！
