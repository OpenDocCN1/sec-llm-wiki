# 快讯：威努特全面参与工业互联网产业联盟工作组

工业互联网产业联盟自2016年2月1日正式成立以来就紧锣密鼓的开展工作组筹备会。 2016年4月7日，联盟工作组第一次全会在北京友谊宾馆召开，联盟秘书长余晓晖主持本次全会，工信部信息通信管理局、联盟理事长单位、副理事长单位、成员单位、相关单位代表及业界专家等88家单位280名代表出席了会议。为推动工业互联网产业创新，联盟分别设立了国际合作组、总体组、需求组、技术与标准组、产业发展组、安全组、试验平台组等七个小组，同时在联盟总体组下设边缘计算组、工业大数据组、知识产权组等三个特设组。

  

北京威努特技术有限公司作为领先工控安全厂商全程列参与会议，并在联盟安全组的各项工作中积极、全面地做出贡献。经过安全组全体成员单位协商推荐，威努特被安全组确定为“调研建立工业互联网信息安全漏洞公告系统的可行性”的牵头单位，并作为主要贡献单位全面参与需求工作组、标准起草工作组、工业控制安全工作组、工业云与大数据安全工作组所有4个专项工作组。威努特公司从工控安全专业视角为联盟出谋划策，助力“中国智造2025”。
