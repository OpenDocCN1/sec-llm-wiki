# 威努特正式加入上海工业控制系统信息安全技术服务联盟

2015年4月24日-25日，上海工业控制系统信息安全技术服务联盟(以下简称联盟)第二次理事会暨全员会议在上海工业自动化仪表研究院隆重召开！上海市信息安全测评中心、上海市计算机软件技术开发中心、上海工业自动化仪表研究院等40余家单位的领导和专家出席会议。威努特作为国内工控网络安全行业的新兴领军公司，会上作为本次大会唯三的新成员之一正式加入联盟！

    联盟于2014年10月31日正式成立，聚焦工控系统信息安全，打造国内一流、国际先进的技术服务平台。威努特作为国内工业网络安全行业的新兴领军公司，自成立以来，利用自身在信息安全和自动化的深厚技术积累，专注于产品和解决方案研发。威努特工控防火墙是国内唯一一家支持对OPC Classic, Modbus TCP, DNP3, IEC104, IEC61850 MMS,Profinet,SIEMENS S7等工业协议深度解析，并提供只读配置模板的工业防火墙；支持4个全千兆端口，采用无风扇高可靠设计设计，满足-40°C-70°C的工业级工作温度范围要求，平均无故障时间超过27年；一键式搞定工业协议安全防护。威努特可信工作站卫士是第一款采用“白名单主动防御”机制的主机防病毒软件，比肩美国Bit9、成功替代McAfee的国内创新型工控安全产品。威努特不但为企业提供专业的工控安全产品，而且能够提供工控信息安全咨询、安全培训和漏洞挖掘、攻防演练等全生命周期的安全服务。威努特加入上海工业控制系统信息安全技术服务联盟，必将和联盟的各家单位一起，为客户提供更加成熟完善的工控安全解决方案。
