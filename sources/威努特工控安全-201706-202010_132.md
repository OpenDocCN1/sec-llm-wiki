# 威努特荣膺 ISAGCA创始成员

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTgyODU3NQ==&mid=2651067840&idx=1&sn=841d5e07d43f1935a7c3e82204e98201&chksm=80e60f70b7918666c23d8707167bd82a81f94db14744717b99074d475dd8cb5aa386972a1a86&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNTgyODU3NQ==&mid=2651067840&idx=1&sn=841d5e07d43f1935a7c3e82204e98201&chksm=80e60f70b7918666c23d8707167bd82a81f94db14744717b99074d475dd8cb5aa386972a1a86&scene=27#wechat_redirect)

![](../Images/237ff58a8b5fe32028e5d43dad949e38.png)**近日，威努特作为中国工控安全领军企业，荣获国际自动化学会（ISA）权威认可，以亚太地区唯一创始成员的身份加入全球网络安全联盟(GCA)。**

![](../Images/5ff04ee67cf020ec38f54d50101cb0e9.png)

  
国际自动化学会（ISA）成立于1945年，其制定的 ISA/IEC 62443 标准被国际电工委员会采纳并得到联合国的认可。此次建立全球网络安全联盟（GCA）旨在提高全球制造业和关键基础设施及流程中的网络安全防范和意识，积极应对日益增长和新出现的网络威胁。  
![](../Images/72b7bbc80bf974c74232d684b954b60d.png)  
全球网络安全联盟（GCA）是权威公众号召力的国际性组织。其首批创始成员均是国际领先的跨国工业技术提供商，在技术和应用方面拥有深厚的专业知识。其中包括威努特、施耐德电气、罗克韦尔自动化、霍尼韦尔、江森自控以及Claroty等22家在专业技术和应用方面国际领先的最终用户企业、控制系统供应商、IT和OT基础设施提供商、系统集成商及网络安全提供商。未来，该联盟将与世界各地的政府机构、监管机构和利益相关方组织密切合作。**威努特作为亚太地区唯一一家以首批创始成员身份加入的安全企业，彰显了中国网络安全企业的国际影响力，标志着我国工控安全专业技术已达到国际领先水平。**近年来，网络攻击带来的安全隐患日益加剧，尤其越来越多针对工业控制系统的攻击不断更新升级。全球工业信息安全漏洞也呈现连年高发态势，工控设备漏洞广泛分布在能源、制造、商业设施、水务、市政等国家关键基础设施，关乎国计民生。而企业在检测和构建安全防护体系方面行动缓慢，不想影响现有的工控设备功能和运行环境。因此威努特始终积极推动与艾默生、施耐德、卡斯柯、GE新华、泰雷兹等全球主流设备厂商构建安全产业生态，提高其自动化设备的安全等级，为我国工控系统构建起第一道安全防线，助推我国工控网络安全行业发展。  
威努特自2014年创立以来，深耕工控安全领域，以自主研发的全系列工控安全产品为基础，经过多年的技术积累，反复的市场考察验证，打造了多行业解决方案，并已成功服务超过1000家用户，积累了宝贵的工控安全行业经验和丰富的技术成果。并且依托行业专业度和知名度，在全球也得到了充分的认可。2019年1月，威努特独立自主研发的工控漏洞挖掘平台 VHunter IVM全面通过了ISCI （ISA Security Compliance Institute 国际自动化协会安全合规学会）EDSA和SSA双重认证，成为**国内首款独立自研获得该认证的产品**。除此之外，威努特成功通过全球著名的研究机构IDC在公司规模、产品技术、行业客户、发展战略等全方位严格考察评估，成为**中国物联网（IoT）市场唯一入榜的工控安全企业。**  

![](../Images/664dbbf5e9de2eed4d79b332124a4ed0.png)

  

此次威努特入选ISAGCA全球网络安全联盟创始成员单位，是国际对威努特工控安全技术能力的再次高度认可，也是对中国工控安全技术能力的充分肯定。未来，威努特将不负众望，肩负起捍卫我国关键信息基础设施的责任，积极汲取国际领先的技术，学习国际先进的工控系统网络安全防护经验，不断提升自身技术水平，持续为我国建设网络强国贡献力量。

  
![](../Images/a65448be4beb31a423248b69e20f3af7.png)**威努特简介**![](../Images/a65448be4beb31a423248b69e20f3af7.png)

北京威努特技术有限公司（简称“威努特”），是国内工控网络安全领军企业，全球六家荣获国际自动化协会安全合规学会认证企业之一。

威努特作为国家高新技术企业，以创新的“白环境”整体解决方案为核心，自主研发了全系列工控网络安全专用产品，拥有42项发明专利、46项软件著作权、31项原创漏洞证明等核心知识产权。积极牵头和参与工控网络安全领域国家、行业标准制定，受邀出色完成新中国70周年庆典、中共十九大、两会等重大活动的网络安保任务，被授予“国家重大活动网络安保技术支持单位”，得到了中央网信办、公安部、工信部等国家政府部门的高度认可。迄今已成功为电力、轨道交通、石油石化、军工、烟草、市政、智能制造、冶金等国家重要行业1000多家工业企业提供了全面有效的安全保障。

威努特始终以“专注工控，捍卫安全”为使命，致力于为我国关键信息基础设施网络空间安全保驾护航！
