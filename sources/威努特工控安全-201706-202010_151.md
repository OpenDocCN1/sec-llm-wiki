# 案例精选 丨某水电厂生产控制系统信息安全监管与预警平台建设项目

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTgyODU3NQ==&mid=2651067138&idx=1&sn=d762d7363c09d10f51debae237a0db60&chksm=80e609b2b79180a439f2fdc7eb20715cade42158d8507fb9a628a3a221b159b82d2e91fd621d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNTgyODU3NQ==&mid=2651067138&idx=1&sn=d762d7363c09d10f51debae237a0db60&chksm=80e609b2b79180a439f2fdc7eb20715cade42158d8507fb9a628a3a221b159b82d2e91fd621d&scene=27#wechat_redirect)

![](../Images/237ff58a8b5fe32028e5d43dad949e38.png)

某水电厂是我国实施西部大开发战略的标志性工程和国家西电东送的骨干电源。水电站装机容量420万千瓦，保证出力185.4万千瓦，年保证发电量190亿千瓦时，是中国目前水电站单机容量最大的电站之一。  
随着信息化与工业化深度融合以及物联网的快速发展，面对越来越严峻的信息安全形势，2017年该水电厂为保障生产控制系统的信息安全，确保其安全稳定生产，满足国家相关监管机构对关键信息基础设施的安全提出明确要求，决定针对生产控制系统信息安全监管与预警平台建设进行招标。**经过多方面严格考核，最终威努特凭借专业的技术服务方案、可靠的工控安全产品和丰富的行业实施经验，在众多企业中脱颖而出，成功中标。**  

![](../Images/30736c99e4303a89753b93f31ea0954e.png)

  
1项目背景  
水电厂工业系统运行环境特殊，保障系统安全稳定运行是关键。解决方案不仅要应对汛期时工控系统超负荷工作，部署的安全设备还要具备宽温差、高湿差的性能。为了更好的保障项目实施，威努特成立的专家技术团队围绕国家政策法规对其紧急开展了现场检查和风险评估。该水电厂生产控制系统基本满足电力监控系统安防要求，生产控制大区与管理信息区已实现单向隔离，与南网总调、云南中调和澜沧江集控中心远动通道已实现纵向加密，但与《电力行业信息系统安全等级保护基本要求》还有诸多不相适应的地方，网络边界防护、监控大区病毒防护、安全审计、操作系统加固等还不完善，存在一定的信息安全风险，不利于电站长周期安全稳定运行。因此急需开展生产控制系统信息安全监管与预警平台建设，消除电厂不符合等级保护要求的缺陷，提高生产控制系统的安全等级保护水平。  
2项目方案

  

针对已发现的风险，威努特专家技术团队根据该水电厂集中控制系统情况，结合国家发改委、工信部、国家能源局对发电厂工控系统安全防护的具体要求，依托独创的“白环境” 纵深防御解决方案，根据系统在不同阶段的需求和业务特点，采用评估、管理、技术和持续运维的安全体系设计方法，帮助用户构建一套覆盖全面、重点突出、节约成本、持续运行的纵深安全防御体系，从网络边界安全、主机终端安全、流量行为安全和运维管理安全四个方面进行网络安全建设：  
◇ 部署工业防火墙对生产控制系统不同机组之间进行隔离防护。  
◇ 部署工控主机卫士对工程师站、操作员站、历史服务器等主机系统进行安全防护。  
◇ 部署工控安全监测与审计系统和入侵检测系统对电力生产控制系统内人员的操作行为、恶意攻击入侵行为等进行事前监控、事中记录、事后定位。   
◇ 部署安全运维管理系统实现账号统一管理、资源和权限统一分配、操作全程审计。  
◇ 部署统一安全管理平台对系统内的安全设备进行统一的监控，将设备日志统一收集起来，进行综合分析，提升运维效率。

3核心产品与技术服务

  

根据威努特为该水电厂定制的“白环境”工控安全解决方案，确保完成监控系统生产控制大区的安全风险监测、预警、审计、准入、运维堡垒机、主机加固及防护等安全防护系统的设计、安装、调试和投运工作，其中采用**威努特完全自主知识产权的****安全防护产品**完成安全建设内容主要包括如下几个方面：  
◇ 增设26台**工业防火墙**；◇ 增设4台**工控安全监测与审计系统**；◇ 增设2台**工控入侵检测系统**；◇ 增设2台**安全运维管理系统**；◇ 增设15套**主机安全加固防护系统**；◇ 增设1台**统一安全管理平台**；◇ 监控地面赫斯曼核心交换机更换；◇ 其它网络基础环境建设内容,包括：2面HP标准服务器机柜、2台地面及地下维护终端SUN X6-2L及线缆铺设（网线铺设等工作）施工等。  
该项目采用多款防护设备，对于保证系统的稳定性、及时性以及防护设备的使用寿命有着极其严格的要求。威努特纳入设计方案的相关技术及产品均通过严格的产品测试，拥有多项国家级资质、多项发明专利，并具有丰富的项目实践。同时，产品在现场验收后，威努特还提供为期两年的技术服务，保证对其水电厂提供紧急预案方案，调度相关资源保障正常运行。

本项目从方案设计到实施完成全程均受到威努特与电厂双方的高度重视，在项目实施过程中提前制订应急预案，充分考虑可能的风险，对在线生产环境零影响、施工过程零失误的前提下，保质保量的完成了实施任务，全面提高了水电厂工控网络的整体安全性，获得了客户一致好评，树立了行业标杆！

  
![](../Images/a65448be4beb31a423248b69e20f3af7.png)**威努特简介**![](../Images/a65448be4beb31a423248b69e20f3af7.png)

北京威努特技术有限公司（以下简称“威努特”），成立于2014年，公司规模200余人，是国内专注于工控安全领域的国家高新技术企业，全球六家荣获国际自动化协会安全合规学会认证企业之一。

威努特以率先独创的“白环境”整体解决方案为核心，研发了覆盖工控网络安全的5大类20款自主可控产品，拥有领先的核心技术及市场优势，成功为电力、轨道交通、烟草、石油石化、市政、智能制造、冶金及军工等国家重点行业五百余家客户提供了全面有效的安全保障，多次受邀为新中国70周年庆典中共十九大、两会、“一带一路”、G20等重大活动进行网络安保工作，广泛参与工控安全领域的国家和行业标准制定，得到了国家多个政府部门和客户的高度认可。

威努特始终以保护我国关键信息基础设施网络空间安全为己任，为建设网络强国添砖加瓦！
