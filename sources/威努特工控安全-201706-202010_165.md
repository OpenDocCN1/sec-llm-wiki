# 载誉而归丨 威努特国家网络安全宣传周荣获“双奖”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTgyODU3NQ==&mid=2651066825&idx=1&sn=a3a3065feab07399c82230316e0d25a0&chksm=80e60b79b791826f77af471f97364693af03dfdf150613c65a05454685bf08f9fee5ea0f4262&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNTgyODU3NQ==&mid=2651066825&idx=1&sn=a3a3065feab07399c82230316e0d25a0&chksm=80e60b79b791826f77af471f97364693af03dfdf150613c65a05454685bf08f9fee5ea0f4262&scene=27#wechat_redirect)

![](../Images/237ff58a8b5fe32028e5d43dad949e38.png)9月22日，2019年国家网络安全宣传周圆满落幕。安全周期间，在中国网络安全产业联盟参与承办的“网络安全标准与产业高峰论坛”上，**威努特凭借在工控安全领域丰富的项目实践经验和强大的产品研发能力，水电厂生产控制系统信息安全监管与预警平台建设方案荣获“2019年网络安全解决方案优秀奖”， 独立自主研发的工控漏洞挖掘平台（VHunter IVM）获“2019年网络安全创新产品优秀奖”两项大奖，载誉而归。**威努特技术服务部总监郭念文出席了“2019年优秀网络安全解决方案及网络安全创新产品"颁奖典礼。

![](../Images/40a2b800ba693ffc653518717e42c055.png)**水电厂生产控制系统信息安全监管与预警平台建设方案**  
本次荣获“2019年网络安全解决方案优秀奖”的“水电厂生产控制系统信息安全监管与预警平台建设方案”是基于该电厂业务的重要性及运维需求，以客户网络安全的总体框架为基础、以安全策略为指导，配备经验丰富的安全运维团队、借助专业的技术工具、依托成熟的服务管理体系，为客户提供完善的安全运维服务，帮助客户发现并处理日常安全问题、规范安全运维流程、促进安全管理制度落地。通过建立可信任网络“白环境”和“白名单”防护理念，以自主可控的核心技术投入，以完全符合工业现场的产品设计，为电厂构筑 “安全白环境”整体防护体系，保护电厂生产控制系统信息安全监管与预警平台系统设施的稳定运行，达到“只有可信任的设备，才能接入控制网络”、“只有可信任的消息，才能在网络上传输”、“只有可信任的软件，才允许被执行”的防护效果。该方案打破了传统“黑”的防护模式，打破工控安全信息孤岛，以更符合工业现场特性的防护手段，以“一个中心，三重防护”的防御体系，将传统的“被动防护”转化为“主动防御”。  

![](../Images/1b68ad7cbf208a92e6e09aa103bfd866.png)

  

![](../Images/40a2b800ba693ffc653518717e42c055.png)**工控漏洞挖掘平台（VHunter IVM）**  
威努特工控漏洞挖掘平台（VHunter IVM）是国内通过ISASecure CRT Test Tools认证的首款独立自研产品（全球仅六家），由威努特研发团队自主研发，具有100%知识产权的安全产品，支持超过50种通信协议（全面覆盖主流工控协议），截止目前已累计发现110个工控系统的高危漏洞。该产品用于工控网络未知漏洞发现和安全状况验证，采用智能Fuzzing技术，对工控设备（PLC、RTU等）、工控系统（DCS、SCADA等）进行漏洞挖掘、协议健壮性测试，清晰定位问题并给出修复建议，增强监管单位、测评机构的检测能力，提升工控设备厂商产品的安全性和竞争力。 

![](../Images/3d92730ee3fbf6fd49c3a0913b336a31.png)

  
据悉，本次评选活动旨在促进我国网络安全产业自主创新能力，推进产业结构化升级，为广大用户选择网络安全解决方案和网络安全产品提供参考依据。评选征集得到了众多企业的广泛关注和积极参与，共收到100余份申报材料。中国网络安全产业联盟根据回避原则邀请了网络安全行业知名专家对申报材料进行了初审和复评，并邀请风险投资机构代表对参加复评的网络安全创新产品进行了评审。 威努特能从众多参选厂商中脱颖而出，摘得双奖，是业界对威努特技术研发实力和自主创新能力的肯定。未来，威努特将继续努力，发挥自身专业技术和业务优势，为社会提供更多优质的网络安全产品及解决方案，为提升我国关键信息基础设施安全保障能力贡献力量。  
  
![](../Images/a65448be4beb31a423248b69e20f3af7.png)**威努特简介**![](../Images/a65448be4beb31a423248b69e20f3af7.png)

北京威努特技术有限公司（以下简称“威努特”），成立于2014年，是国内专注于工控安全领域的国家高新技术企业，全球仅六家荣获国际自动化协会安全合规学会安全认证的企业之一。

威努特以率先独创的“白环境”整体解决方案为核心，研发了覆盖工控网络安全的5大类20款自主可控产品，拥有领先的核心技术及市场优势，成功为电力、轨道交通、烟草、石油石化、市政、智能制造、冶金及军工等国家重点行业五百余家客户提供了全面有效的安全保障，多次受邀为中共十九大、两会、“一带一路”、G20等重大活动进行网络安保工作，广泛参与工控安全领域的国家和行业标准制定，得到了国家多个政府部门和客户的高度认可。

威努特始终以保护我国关键信息基础设施网络空间安全为己任，为建设网络强国添砖加瓦！
