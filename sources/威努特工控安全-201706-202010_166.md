# 威努特参与编写的《中国网络安全产业白皮书（2019年）》正式发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTgyODU3NQ==&mid=2651066825&idx=2&sn=b5fb7a6f45752bf44cdba43d13b86ba8&chksm=80e60b79b791826febbefef997e155c21bbdc54c71064295be4f4cd620b875ceb08dd8246da0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNTgyODU3NQ==&mid=2651066825&idx=2&sn=b5fb7a6f45752bf44cdba43d13b86ba8&chksm=80e60b79b791826febbefef997e155c21bbdc54c71064295be4f4cd620b875ceb08dd8246da0&scene=27#wechat_redirect)

9月18日，在2019国家网络安全宣传周上，中国信息通信研究院正式发布《中国网络安全产业白皮书（2019年）》。**威努特作为工控安全领域领军企业，参与了白皮书的编写工作。**

![](../Images/3dcbe2d1c55d5c716ee461d10032f60e.png)

![](../Images/41aa1abc635801d9d01839e812dbeeb1.png)

![](../Images/191a6ca92938ab573326eba3496bc9b9.png)

此次发布的白皮书是中国信息通信研究院第四次发布网络安全产业白皮书，延续了从规模结构、政府政策、企业发展、技术进展、人才培养等维度对国内外产业进展跟踪分析，同时结合热点趋势，重点对工业互联网安全、云安全、零信任安全、“人工智能+安全”、5G安全等五个领域进行了分析预测，最后对产业发展前景进行了展望，希望为关注网络安全产业发展的企业、政府机构以及相关单位提供参考和帮助。  
威努特深耕于工控安全领域，在联合编写过程中，提供了工控安全相关专业内容支撑。**威努特针对工业互联网安全、云安全、零信任安全、“人工智能+安全”、5G安全五个重点方向进行思考与探讨，并结合威努特工控安全产品与技术优势，分别在工业互联网安全和“人工智能+安全”领域，分享了威努特基于无损探测的工业互联网设备测绘实践和基于智能 Fuzzing 框架的工控漏洞挖掘实践。**此次参与编写《中国网络安全产业白皮书（2019年）》是对威努特在工控安全领域产品与技术的充分肯定。  
工控安全是国家网络安全的重要组成部分，是工业和信息化高质量发展的重要保障。威努特专注工控安全领域，凭借多年的技术沉淀与行业实践积累，自主研发了5大类20款安全产品，并广泛应用于电力、石油石化、轨道交通、烟草等工业领域重点项目，积累了丰富的行业经验。威努特将持续不断创新研发，深入用户业务需求，结合行业应用场景提供专业可靠的安全服务，积极带动国内工控安全行业持续发展，为我国网络安全建设保驾护航。

![](../Images/a65448be4beb31a423248b69e20f3af7.png)**威努特简介**![](../Images/a65448be4beb31a423248b69e20f3af7.png)

北京威努特技术有限公司（以下简称“威努特”），成立于2014年，是国内专注于工控安全领域的国家高新技术企业，全球仅六家荣获国际自动化协会安全合规学会安全认证的企业之一。

威努特以率先独创的“白环境”整体解决方案为核心，研发了覆盖工控网络安全的5大类20款自主可控产品，拥有领先的核心技术及市场优势，成功为电力、轨道交通、烟草、石油石化、市政、智能制造、冶金及军工等国家重点行业五百余家客户提供了全面有效的安全保障，多次受邀为中共十九大、两会、“一带一路”、G20等重大活动进行网络安保工作，广泛参与工控安全领域的国家和行业标准制定，得到了国家多个政府部门和客户的高度认可。

威努特始终以保护我国关键信息基础设施网络空间安全为己任，为建设网络强国添砖加瓦！
