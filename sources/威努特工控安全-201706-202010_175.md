# 威努特牵头国家标准项目，获全国信息安全标准化技术委员会立项

2019年8月21日，全国信息安全标准化技术委员会公布了2019年网络安全标准项目立项清单。由**北京威努特技术有限公司牵头，联合公安部第三研究所、中国网络安全审查技术与认证中心**等单位编制的《信息安全技术 工业控制系统主机安全防护系统安全技术要求和测试评价方法》标准，立项成为2019年网络安全研究标准。全国信息安全标准化技术委员会秘书处发布了相关公告，具体公告内容如下：

此次，威努特牵头制定的国家标准获得入选，是对威努特长期以来工作与技术能力的认可。威努特还将继续积极参与国家级、行业等工控安全标准和政策制定工作。在工业互联网安全形势日趋严峻的今天，为保护我国关键信息基础设施网络空间安全持续贡献力量。![](../Images/a65448be4beb31a423248b69e20f3af7.png)**威努特简介**![](../Images/a65448be4beb31a423248b69e20f3af7.png)

北京威努特技术有限公司（以下简称“威努特”），成立于2014年，是国内专注于工控安全领域的国家高新技术企业，全球仅六家荣获国际自动化协会安全合规学会安全认证的企业之一。

威努特以率先独创的“白环境”整体解决方案为核心，研发了覆盖工控网络安全的5大类20款自主可控产品，拥有领先的核心技术及市场优势，成功为电力、轨道交通、烟草、石油石化、市政、智能制造、冶金及军工等国家重点行业五百余家客户提供了全面有效的安全保障，多次受邀为中共十九大、两会、“一带一路”、G20等重大活动进行网络安保工作，广泛参与工控安全领域的国家和行业标准制定，得到了国家多个政府部门和客户的高度认可。

威努特始终以保护我国关键信息基础设施网络空间安全为己任，为建设网络强国添砖加瓦！
