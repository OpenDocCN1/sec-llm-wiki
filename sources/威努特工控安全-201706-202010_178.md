# 威努特推动工控安全新生态，ISC 2019圆满收官

8月20日，亚太地区规格高、规模大、影响力深远的第七届互联网安全大会（以下简称ISC2019）在北京雁栖湖国际会展中心圆满闭幕。威努特作为国内工控安全领军企业，已连续五届受邀深度参与。在持续两天的大会中，威努特与国内外顶级网络安全专家、国内知名优秀企业共同探讨了网络战时代下的安全解决之道，以及合力共建我国工控大生态，同筑工控大安全，为推动强化我国关键信息基础设施安全贡献力量。

  

威努特展区爆“红”

  

大会中，威努特展区重量级嘉宾纷至沓来。中国工程院院士邬贺铨、国家工业信息安全发展研究中心副主任何小龙、国内资深网络安全专家陆宝华、中国科学院信息工程研究所信息安全国家重点实验室教授吕述望等领导专家莅临指导交流，讲解人员向专家领导进行了深度的汇报及讲解。

工业互联网安全论坛

  

8月20日下午，威努特董事长兼CEO龙国东受邀出席了以“跨界融合、协同并进、构建工业互联网安全生态”为主题的ISC2019工业互联网安全论坛。  

![](../Images/ba55f3f590736e9efef8d273eead8650.png)

  
首先，国家工业信息安全发展研究中心副主任何小龙在致辞中指出，工业互联网是制造业发展面临深刻变革这一背景下提出来的，也是推动我国制造业数字化转型的一个现实的路径。当前，全球工业互联网正处在产业格局还没有确定的关键期，也是大规模运用、规模化扩张的一个窗口期。我们国家抓住这个机遇，基本应该说与发达国家是同步启动了工业互联网建设。在平台建设、产业应用、市场潜力等方面我们理解都不逊色于发达国家。但是在工业互联网安全保障能力这方面，我们是相对薄弱，也成为约束制约我们工业互联网迈向更高发展水平的一个主要的短板之一。工业互联网安全关系到经济的发展、社会的稳定，是咱们制造强国和网络强国战略的一个基石。其工作责任重大，任务也比较艰巨，需要我们各方面共同的参与、共同的努力。

  

随后，龙国东在圆桌论坛上就以下几方面与其他重磅嘉宾进行了深入讨论：

  

![](../Images/a9a211e1bb45b033e3c0776200bece7f.png)

  
**一、针对解析工控安全领域存在的强风险**

  

龙国东：工控安全和传统安全最大的不一样在于对真正发生危险或者是安全事故后的后果比信息安全更加严重。五年以来在400多个现场的统计数据来看，我们发现有安全设备的客户不超过10%，也就是说90%的客户没有任何的安全防护。我们在400个用户里统计出来的，接近50%以上的现场是有问题运行的。我们的CTO在之前大会上也说过这个数据，全球工业信息安全漏洞呈现连年高发态势，其中半数以上为高危漏洞，广泛分布在能源、制造、商业设施、水务、市政等关键领域，工控安全存在强风险并且是实实在在迫在眉睫需要解决的问题。**二、如何在工控安全新赛道高质量发展**

  

龙国东：说到新赛道，我们也是有数据支撑的。我平常很关注行业的数据，我们自己也会做市场的预测。前几年对工控安全分行业，分客户，分典型的投资来看做了一个统计。工控安全市场400-500亿的市场，我们在现场看到90%的现场是没有安全设备，基本都是新增市场。围绕新增市场，我觉得还是要分步解决问题，第一步是为90%以上没有做安全投入的企业把基础的安全建设做好。技术的安全建设主要是围绕合规的需求和客户自主真实需求，这是前五年甚至是未来五年的主旋律，因为有90%的用户还等着我们给他做相应的安全服务和安全建设。第二步，80%-90%的用户有了一定的安全建设以后，我们可以围绕着国家电网、工信部的态势感知的策略做整体的态势感知的体系建设。要打网络战先得知道自己有什么问题，有什么能力，甚至是安全态势是怎样的。因此第二阶段态势感知体系的建设是重点。第三阶段是攻防的阶段，既然已经有强大的安全基础，又掌握了安全态势，再配合一定的安全攻防的能力有可能打赢这场战争的，所以我认为工控安全是非常长期的事情，也是一步一步脚踏实地把每一个阶段做好才能进入到下一个阶段。

  

**三、如何结合企业特色，跨域联合构建工控安全共同体**

  

龙国东：每个企业都不可能把所有的事情做好，我们会看到现在国内安全创业公司非常多，可能超过500家以上。每家公司可能会聚焦在一两个点上去做他的拳头产品及核心竞争力，因此我们应该高质量携手共建工控安全大生态，可以在方案上进行很多的结合，更好的服务于客户，共同推进工业互联网安全产业的发展以及为我国建设网络强国尽自己最大的力量。

  

权威媒体专访

  

会后，龙国东在接受人民网专访以及出席安全牛、techweb、安全客、国际在线、中国电子报、中国教育电视台等十多家媒体的群访中继续强调指出，互联网的安全威胁渗透将进工业领域，网络攻击直达生产一线，对生产安全，甚至是国家基础设施安全都带来致命的影响。它更像是一个新的引爆点，因为它可预见性的改变了我们目前的生产、生活以及社会治理等方面的现状，而它到底会产生多深远的影响，目前还无法计算。威努特自2014年成立以来一直专注于工控安全，如何能更好的提升工业控制系统以及国家关键基础设施安全防护能力，在近几年的业务工作开展中，也是近几年威努特在工控网络安全布局的主要方向。

![](../Images/a65448be4beb31a423248b69e20f3af7.png)**威努特简介**![](../Images/a65448be4beb31a423248b69e20f3af7.png)

北京威努特技术有限公司（以下简称“威努特”），成立于2014年，是国内专注于工控安全领域的国家高新技术企业，全球仅六家荣获国际自动化协会安全合规学会安全认证的企业之一。

威努特以率先独创的“白环境”整体解决方案为核心，研发了覆盖工控网络安全的5大类20款自主可控产品，拥有领先的核心技术及市场优势，成功为电力、轨道交通、烟草、石油石化、市政、智能制造、冶金及军工等国家重点行业五百余家客户提供了全面有效的安全保障，多次受邀为中共十九大、两会、“一带一路”、G20等重大活动进行网络安保工作，广泛参与工控安全领域的国家和行业标准制定，得到了国家多个政府部门和客户的高度认可。

威努特始终以保护我国关键信息基础设施网络空间安全为己任，为建设网络强国添砖加瓦！
