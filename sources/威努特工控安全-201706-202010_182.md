# 威努特获选“青岛市工业信息安全综合服务联盟”首批成员单位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTgyODU3NQ==&mid=2651066516&idx=1&sn=d533d04a7e9e1471d54166f175486e43&chksm=80e60a24b7918332d6e8b73013829aa99ea428e7d3bedac098efcc66d5e410a58ab350c6aac7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNTgyODU3NQ==&mid=2651066516&idx=1&sn=d533d04a7e9e1471d54166f175486e43&chksm=80e60a24b7918332d6e8b73013829aa99ea428e7d3bedac098efcc66d5e410a58ab350c6aac7&scene=27#wechat_redirect)

![](../Images/237ff58a8b5fe32028e5d43dad949e38.png)  

7月26日，国家工业信息安全发展研究中心、工业信息安全产业发展联盟指导的“2019世界工业互联网产业大会工业信息安全高峰论坛”在青岛召开。青岛市工业和信息化局、国家工业信息安全发展研究中心等有关部门负责人、行业组织、高校及知名企业代表共计二百余人参加了本次大会，深入探讨工业信息安全产业结构、技术发展现状以及现存问题，畅言企业在工信安全发展方面的经验，共同推动信息安全产业持续发展。  

![](../Images/e7e7c562e8d5d8200237e47670506584.png)

  
论坛上，国家工业信息安全发展研究中心副主任何小龙、青岛市工业和信息化局副局长左锐共同为 “青岛市工业信息安全应急处置中心”揭牌，应急处置中心将为青岛市提供工业信息安全应急处置、监控预警、容灾备份体系建设等服务。  

![](../Images/41d84a946900e30355f6b61afee8a306.png)

  

同时，应急处置中心联合15家国内知名安全厂商正式成立“青岛市工业信息安全综合服务联盟”，威努特凭借在工业信息安全领域突出的技术研发实力和多年来的行业经验积累，获选成为该联盟的首批成员单位。  

![](../Images/53db777aa6fb102e75bb55f4564cdb12.png)

![](../Images/3f85ce2d9c2164d5e9c61725b7266f75.png)

威努特代表吕长坡（右5）接受联盟授牌

  

作为国内专注于工业安全防护领域的企业，威努特坚持以技术创新为基石，不断提升安全研发与事件响应能力，自主研发的安全管理类、防护检测类、检查评估类、态势感知类及教育实训类共5大类20款安全产品广泛应用于电力、石油石化、轨道交通、烟草等工业领域重点项目。本次入选成为青岛市工业信息安全综合服务联盟成员单位，既是荣誉，更是责任，今后，威努特将积极参与应急处置中心相关工作，为更多工业企业提供可靠服务，充分展示工控安全厂商的良好担当，为青岛信息安全体系建设持续助力。  
 ![](../Images/a65448be4beb31a423248b69e20f3af7.png)**威努特简介**![](../Images/a65448be4beb31a423248b69e20f3af7.png)

北京威努特技术有限公司（以下简称“威努特”），成立于2014年，是国内专注于工控安全领域的国家高新技术企业，全球仅六家荣获国际自动化协会安全合规学会安全认证的企业之一。

威努特以率先独创的“白环境”整体解决方案为核心，研发了覆盖工控网络安全的5大类20款自主可控产品，拥有领先的核心技术及市场优势，成功为电力、轨道交通、烟草、石油石化、市政、智能制造、冶金及军工等国家重点行业五百余家客户提供了全面有效的安全保障，多次受邀为中共十九大、两会、“一带一路”、G20等重大活动进行网络安保工作，广泛参与工控安全领域的国家和行业标准制定，得到了国家多个政府部门和客户的高度认可。

威努特始终以保护我国关键信息基础设施网络空间安全为己任，为建设网络强国添砖加瓦！
