# 人民网：威努特助力滨海中关村赋能协同创新

2019年4月14日，人民网发表了文章《滨海中关村：争做协同创新“赋能者”》**，威努特凭借在工控安全领域的实力及影响力，作为天津滨海中关村代表企业接受了采访。**  

  

**滨海之上绘新篇**

  

2016年11月22日，滨海—中关村科技园在此正式揭牌。今年1月17日，习近平总书记在京津冀考察时来到这里，他强调，自主创新是推动高质量发展、动能转换的迫切要求和重要支撑，必须创造条件、营造氛围，调动各方面创新积极性，让每一个有创新梦想的人都能专注创新，让每一份创新活力都能充分迸发。  

  

威努特是较早一批入驻天津滨海中关村的高新技术企业。为践行十九大会议精神，结合天津地区产业基础，依托天津滨海—中关村科技园的政策扶持，在天津滨海中关村科技园设立了专注工控网络安全子公司。

  

![](../Images/28715fc64f9124a808bb7169047578dd.png)

  

2018年1月26日，威努特天津办公楼落成剪彩，并成功召开京津冀协同发展论坛暨2018年威努特工控安全沙龙。论坛由国家计算机病毒应急处理中心指导，威努特联合天津市滨海中关村科技园管委会共同主办。公安部、工信部领导，各行业资深专家，各地区合作伙伴100余人出席会议，深入探讨了工控安全产业最新政策动态与技术发展，有力推进了京津冀区域经济一体化发展。

  

![](../Images/b509f32e68ef3b62afe5ab236d19e67f.png)  

  

**共建京津冀协同发展蓝图**

  

2017年9月12日，北京市党政代表团赴天津市学习考察。北京市委书记蔡奇，市委副书记、代市长陈吉宁，市政协主席吉林与天津市委书记李鸿忠，市委副书记、市长王东峰，市人大常委会主任肖怀远座谈。会后，北京市党政代表团来到滨海——中关村科技园实地考察，视察了天津威努特信息技术有限公司。蔡奇书记表示，工控安全关系国计民生，非常重要，威努特虽然是一家民营企业，但是发展方向很好，潜力巨大。希望威努特能够利用好京津两地的政策资源，抓住机遇，继续努力，不断创新、发展！

  

![](../Images/bd2f60f78f7b2993ebc1ba08271e15cf.png)

  

![](../Images/82a31ae4f9757eda89c341009f92fda6.png)

  

2017年12月7日，新华社天津发表题为《大潮澎湃帆飞扬——走进京津冀协同创新“新地标”》，文章中对威努特进行报道。  

  

2017年12月9日，在CCTV《新闻联播》的“【新时代 新气象 新作为】天津：做好新时代协同发展文章”中，对威努特进行了相关新闻报道，央视记者在了解威努特企业发展情况后，对威努特一系列工控安全产品及取得的成绩表示赞赏，并对威努特的未来寄予厚望。

  

![](../Images/644d1005d951d050d4508f8aa382933f.png)

  

![](../Images/117e1eb107ca88f92edf6b773fdcf949.png)

  

2019年1月17日，中共中央总书记、国家主席、中共军委主席习近平到天津滨海——中关村科技园进行调研考察。在园区内的协同创新展示中心，习近平总书记对近20家企业展示的高精尖科技产品，进行了视察。习近平总书记强调，自主创新是推动高质量发展、动能转换的迫切要求和重要支撑，必须创造条件、营造氛围，调动各方面创新积极性，让每一个有创新梦想的人都能专注创新，让每一份创新活力都能充分迸发。要深化科技园区体制机制创新，优化营商环境，吸引更多在京科技服务资源到园区投资或业务延伸，促进京津两市真正实现优势互补、强强联合。威努特作为工控安全领域领军企业应邀展示了公司核心产品与解决方案，接受习近平总书记的视察。

  

![](../Images/678dcde4d1ad84009ff3976f54810118.png)

  

初心不改，砥砺前行！威努特近几年的快速发展离不开各界的支持与帮助，威努特将持续助推京津冀协同一体化发展，引进人才、重点投入，强化我国工控网络安全领域防护能力。

![](../Images/e228325f2dcfa044d56d22fafb44196f.png)**威努特简介**![](../Images/e228325f2dcfa044d56d22fafb44196f.png)

威努特简介北京威努特技术有限公司（以下简称”威努特”），成立于2014年，是国内专注于工控安全领域的国家高新技术企业，全球仅六家荣获国际自动化协会安全合规学会安全认证的企业之一。

威努特以率先独创的“白环境”整体解决方案为核心，研发了覆盖工控网络安全的5大类20款自主可控产品，拥有领先的核心技术及市场优势，成功为电力、轨道交通、烟草、石油石化、市政、智能制造、冶金及军工等国家重点行业五百余家客户提供了全面有效的安全保障，多次受邀为中共十九大、两会、“一带一路”、G20等重大活动进行网络安保工作，广泛参与工控安全领域的国家和行业标准制定，得到了国家多个政府部门和客户的高度认可。

威努特始终以保护我国关键信息基础设施网络空间安全为己任，为“中国制造2025”保驾护航，为建设网络强国添砖加瓦！
