# 威努特工控安全评估检测专场渠道招募会顺利召开

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTgyODU3NQ==&mid=2651065496&idx=1&sn=a4e4601f03eb659eebedca290bec40a8&chksm=80e61628b7919f3e0e64d68e17d96e545d8dbb1d4724bae1484f4bc2236a6948eae487aaef49&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNTgyODU3NQ==&mid=2651065496&idx=1&sn=a4e4601f03eb659eebedca290bec40a8&chksm=80e61628b7919f3e0e64d68e17d96e545d8dbb1d4724bae1484f4bc2236a6948eae487aaef49&scene=27#wechat_redirect)

![](../Images/237ff58a8b5fe32028e5d43dad949e38.png)

3月29日，2019年威努特工控安全评估检测专场渠道招募会在北京顺利召开，本场招募会以贯彻落实《工业控制系统信息安全防护指南》和今年有望出台的《网络安全等级保护条例》为核心，重点为远道而来的行业渠道合作伙伴介绍了等级保护检查工作开展下威努特自主研发的工业互联网雷达、生产安全集中监测平台、工控等保检查工具箱、工控漏洞挖掘平台四款评估检测类产品以及渠道合作政策、典型案例及运作模式，为共同推动等保2.0下的工控安全检查评估工作新局面打下了良好基础。

![](../Images/aace87aa4587949b0cb20c76f104b5e3.png)

威努特技术服务部王鹏程以《等保2.0与工控系统信息安全政策》为主题就网络安全法中的重点条款、等级保护2.0标准体系、工业控制系统信息安全防护指南及行业标准进行了详细讲解，并重点指出，在等级保护2.0时代，相关部门将根据信息技术发展应用和网络安全态势，不断丰富制度内涵、拓展保护范围、完善监管措施，逐步健全网络安全等级保护制度政策、标准和支撑体系。

![](../Images/e0bdb704f1f3bc88671a47308e2a4691.png)技术服务部工程师王鹏程

威努特安全大数据产品线研发总监李飞从系统架构、产品价值、核心技术及产品部署等方面详细介绍了工业互联网雷达和生产安全集中监测平台。  

**威努特工业互联网雷达**是为政府监管部门、测评机构、科研院所、能源等大中型企事业单位提供工业互联网资产探测、漏洞预警与宏观安全形势展现等服务的技术平台，具有“网络空间资产在线检索”、“网络空间资产漏洞感知”、“一站式全服务”等多项功能，满足对工控设备、工控主机、工控网络的监测。其中“协议识别”、“设备指纹”、“漏洞感知”等多项核心技术填补国内相关技术空白，并达到国际相关行业技术首创。

**威努特生产安全集中监测平台**是对工业企业网络中硬件资产、安全产品及安全事件进行集中监测、智能化分析展示的软硬件一体化产品。借鉴 “一个中心、三重防护”的纵深防御模型，采用“一个中心、三重发现”的建设理念，可自动识别工控网的设备类型、设备厂商、设备型号，自动识别网络拓扑，提供全方位的资产可视化体验，并且智能分析海量安全设备日志，通过人工智能的知识图谱技术，将资产配置弱点、漏洞、威胁事件关联分析，自动发现攻击路径，结合等保2.0合规自评和自动化的合规评估技术，将合规评估量化分析，提供企业集团量化的健康指数。

![](../Images/d6b09ace4658f34f96ca06ba7e45c29f.png)安全大数据产品线研发总监李飞

威努特产品与解决方案部工程师张雄杰为渠道合作伙伴介绍了工控等保检查工具箱的检查流程、详细功能列表及应用场景，并直观展示了产品的外观构成和工作界面。

**工控系统等级保护检查工具箱**是集工业控制系统信息安全等级保护合规监管、测评、自查等功能于一体的移动便携式专用装备。按照《信息安全技术网络安全等级保护基本要求》、《工控系统安全等级保护检查工具技术规范》等权威标准，结合威努特攻防研究和风险评估项目经验，以及工业现场环境特点，对工控系统进行全面程序化检查，实现“定级、备案、测评、整改、安全自查和监督检查”的全流程管理，为企业自查、监管机构安全检查以及测评机构安全评估工作提供技术支撑。

![](../Images/3b1d3cd00568dbab257e33925b3d4242.png)产品与解决方案部工程师张雄杰

随后，产品与解决方案部工程师李之云为参会来宾介绍了工控漏洞挖掘平台 VHunter IVM，概括描述了漏洞挖掘的定义，具体讲解了漏洞挖掘平台的产品架构、主要功能及优势亮点。

**工控漏洞挖掘平台VHunter IVM**是全球第六个获ISASecure CRT Test Tools安全认证证书的国内首款独立自研产品，该产品采用智能Fuzzing技术，对工控设备（PLC、RTU等）、工控系统（DCS、SCADA等）进行漏洞挖掘、协议健壮性测试，清晰定位问题并给出修复建议，支持超过50种通信协议（全面覆盖主流工控协议），可为工业控制系统厂商、行业监管单位、测评机构以及行业用户提供工控设备安全性及协议健壮性评估。

![](../Images/327c5dae96188db4415a1677cea5f67b.png)产品与解决方案部工程师李之云

会议尾声，渠道业务部负责人刘旻分享了《威努特渠道合作政策》，对渠道体系基本架构、各渠道定位、渠道商认证考核、晋级机制及管理流程做了全面解读，同时，刘旻还向参会来宾展示了公司资质库和资源库。威努特具备业内领先的技术实力和服务实力，有绝对信心为渠道合作伙伴提供全方位的支持和保障。

![](../Images/b7b8aa82c81cb0e80eff3baa4ea539cc.png)渠道业务部负责人刘旻

会后，多位渠道合作伙伴表示这次会议内容丰富、收获很大，表达了强烈的合作意向，并亲临威努特公司参观交流，为进一步开展渠道合作奠定了坚实基础。无论是威努特还是行业渠道伙伴，都是本着诚信合作促双赢，携手共进谋发展的宗旨，为提高工控系统网络安全防护能力以及保护我国关键信息基础设施安全而不懈努力。

![](../Images/4ef6d4b098cd5983fd7921e0a83135d8.png)威努特简介![](../Images/4ef6d4b098cd5983fd7921e0a83135d8.png)

北京威努特技术有限公司（以下简称”威努特”），成立于2014年，是国内专注于工控安全领域的国家高新技术企业，全球仅六家荣获国际自动化协会安全合规学会安全认证的企业之一。

威努特以率先独创的“白环境”整体解决方案为核心，研发了覆盖工控网络安全的4大类20款自主可控产品，拥有领先的核心技术及市场优势，成功为电力、轨道交通、烟草、石油石化、市政、智能制造及军工等五百余家国家重点行业客户提供了全面有效的安全保障，多次受邀为中共十九大、两会、“一带一路”、G20等重大活动进行网络安保工作，广泛参与工控安全领域的国家和行业标准制定，得到了国家多个政府部门和客户的高度认可。

威努特始终以保护我国关键信息基础设施网络空间安全为己任，为“中国制造2025”保驾护航，为建设网络强国添砖加瓦！
