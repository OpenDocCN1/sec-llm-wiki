# 【合作共赢】威努特与汇志凌云缔结渠道战略合作伙伴关系

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTgyODU3NQ==&mid=2651065183&idx=1&sn=6234f84b5b973e270600412f03c49f62&chksm=80e611efb79198f993256dd9cab8420c98c8e50e0362a6d167294da38d73b6efc93603239ac8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNTgyODU3NQ==&mid=2651065183&idx=1&sn=6234f84b5b973e270600412f03c49f62&chksm=80e611efb79198f993256dd9cab8420c98c8e50e0362a6d167294da38d73b6efc93603239ac8&scene=27#wechat_redirect)

2019年3月5日，北京威努特技术有限公司（以下简称“威努特”）与北京汇志凌云数据技术有限责任公司（以下简称“汇志凌云”）达成渠道战略合作伙伴关系，并在北京举行了战略合作签约仪式。汇志凌云总经理董强、副总经理杨健、网络安全业务部总监武艳平、网络安全业务部产品经理李瑶以及威努特董事长兼创始人龙国东、副总经理陈晓慧、技术服务部总监郭念文、运营管理部总监赵艳等双方领导出席了本次签约暨授牌仪式。

  

![](../Images/81805e39d7c2c6761eedfec96c73aed1.png)

  

此次渠道战略合作的结盟，可以促使双方就销售渠道建设和未来行业业务的拓展，同时双方以整合资源达成共赢为目的，相互信任、相互支持、密切合作、共同发展为原则共享了市场资源，开启了两大企业的多层次强强联手、共进共赢的战略合作局面，这也将对工控网络安全行业的发展具有极其重要的推动作用。

  

![](../Images/e225b6e2148ccc648b4ac9b28aaaa7dd.png)

![](../Images/24bc005b4cb3db56a9ab1cadb4404874.png)

  

签约期间双方就渠道合作建设进行了深入的会谈，威努特董事长兼创始人龙国东表示，威努特已成立近五年，拥有最完善的产品和服务，在我国工控安全产业领域积累了丰富的项目实施经验。2019年是威努特的渠道年，汇志凌云是威努特正式签署的第一家渠道合作伙伴，此次与汇志凌云正式签约，是威努特开展渠道工作以来非常重要的一步，希望此次达成战略合作成为双方进一步合作的起点，在未来的合作中，一定能够秉持各自的优势，在渠道业务上拓展出一片新的天地。

  

汇志凌云总经理董强同时表示，十分看好此次合作，经过多方对比、客户案例考察，深深认同威努特专业的技术实力和完善的售后服务能力，最终选择威努特为渠道战略的长期合作伙伴。国内工控网络安全市场发展已日趋成熟，安全厂商和渠道商都需要寻找新的突破。作为威努特的战略合作伙伴，汇志凌云将依据对行业的丰富理解，深入行业需求，协助威努特进一步拓展国内市场，实现用户、安全厂商和渠道商的互利共赢！

  

**汇志凌云简介：**

汇志凌云隶属于TCL集团，目前已经在全国设立了华北、东北、西北、华东、华中、华南、西南七个大区，业务涵盖会议系统解决方案、视觉系统方案、信息安全&工控安全解决方案、智慧园区解决方案、楼宇自控、云安全和大数据解决方案等领域。

在上述各领域方向上，我们已经与DELL、绿盟、威努特、巴可、山石、利亚德、Extreme Networks、德特威勒、伊顿、威图、世图兹、永洪BI、阿里云等国内外知名厂商展开深入合作，并依据对行业的丰富理解，深入行业需求，整合各方面资源形成专业解决方案。

  

**威努特简介：**

威努特是国内专注于工控安全领域的高新技术企业，以研发工控安全产品为基础，打造多行业解决方案，提供培训、咨询、评估、建设及运维等全流程安全服务。威努特提出工业网络“白环境”理念，迄今已服务电力、轨道交通、石油、石化、市政、烟草、化工及军工等行业的五百余家客户，受邀保障G20峰会和“一带一路”国际合作高峰论坛。威努特致力于为客户构建安全可靠的工业网络环境，保障国家关键信息基础设施运行安全，为中国制造2025护航，为建设网络强国添砖加瓦！
