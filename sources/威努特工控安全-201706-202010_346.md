# 2018中国工业信息安全大会召开在即 威努特应邀分享“白名单技术在工控安全中的应用”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTgyODU3NQ==&mid=2651063221&idx=1&sn=36f1402feac504352d49dfce182e9dc1&chksm=80e61905b791901349d99df6fa196b3c096ebc49b1b76e78091974d7edf5db69197189defd5e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNTgyODU3NQ==&mid=2651063221&idx=1&sn=36f1402feac504352d49dfce182e9dc1&chksm=80e61905b791901349d99df6fa196b3c096ebc49b1b76e78091974d7edf5db69197189defd5e&scene=27#wechat_redirect)

      为贯彻落实党的十九大报告提出的“推动互联网、大数据、人工智能和实体经济深度融合”有关要求，推动落实《国务院关于深化“互联网+先进制造业”发展工业互联网的指导意见》，由工业和信息化部指导，国家工业信息安全发展研究中心和工业信息安全产业发展联盟主办的2018中国工业信息安全大会将于5月24—5月25日在北京世纪金源大饭店召开，此次大会主题为“筑工信安全建网络强国”，旨在为中国工业信息安全产业打造一个世界级交流分享平台。

![](../Images/907bf4ef9e685c4b57a0c7707100e4c4.png)

  

     威努特公司作为工控安全行业领军企业应邀出席本届大会，届时威努特CTO/联合创始人黄敏将在工业信息安全趋势分论坛上做“白名单技术在工控安全中的应用”的主题演讲，就目前传统信息安全广泛采用的黑名单技术为什么在工控网络中水土不服；白名单技术在工控网络中有什么优势；白名单技术是不是灵丹妙药，面临哪些挑战，以及未来发展的方向跟与会嘉宾进行深入探讨。

  

同时在此次工业信息大会案例展示区威努特也将展示工控安全行业优秀的实施案例。如在水电行业，威努特成功实施《小湾电厂生产控制系统信息安全监管与预警平台建设》项目，威努特的产品及服务得到了小湾电厂的高度认可。在客户现场通过现场网络结构、主机设备、系统软件、安全设备等运行情况进行安全调研和分析，识别系统资产和脆性性，确定了小湾水电站现场所存在的安全隐患和安全防护缺失项而为小湾电站打造的的可信任网络“白环境”，打造“一个中心，三重防护”的防御体系，将“被动防护”转化为“主动防御”。在满足合规性要求的同时，从网络、控制设备、主机、运维等多个层面提升了小湾电站生产控制网络的安全防护水平，为水电行业树立了新的标杆。

  

![](../Images/b8059fc1ff7f2561859f421a80eabc40.png "22222222222.jpg")

  
**小湾水电站发来的感谢信**![](../Images/54de8bba8ebbe4a048ad54a87bc83400.png "QQ锟斤拷图20180515163418.jpg")

小湾电站是实施西部大开发战略的标志性工程和国家西电东送的重点工程，工程以发电为主，兼有防洪、灌溉、拦沙及航运等综合利用效益。电站装机容量420万kW，设计多年平均发电量190亿kW•h，是中国目前水电站单机容量最大的电站之一。

  

威努特作为国内专注于工控安全领域的高新技术企业，同时也是最早提出工业网络安全"白环境"理念的安全厂商，迄今已服务电力、石油石化、轨道交通、智能制造、燃气、水务、军工、烟草、煤炭、化工、高校、科研机构等两百余家行业客户，落地项目和市场占有率在业内遥遥领先。威努特自成立以来，受邀参与"G20峰会"、"一带一路"国际合作高峰论坛"、2017年第十九次全国代表大会、2018年两会等重大活动的网络安全保障工作，威努特致力于为客户构建安全可靠的工业网络环境，为国家关键信息基础设施运行安全提供有力保障，为中国制造2025保驾护航，为建设工业网络安全强国添砖加瓦。
