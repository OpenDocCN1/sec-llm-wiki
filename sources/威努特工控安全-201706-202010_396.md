# 网络安全行业全景图（2018年1月）发布，威努特工控安全实力再获认可

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTgyODU3NQ==&mid=2651062661&idx=1&sn=475298a81f5df2a27045297d62e87617&chksm=80e61b35b79192231ef72c5908fd6d20b94c6ebbdaa1377672f52edb118dce568e1f21535469&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNTgyODU3NQ==&mid=2651062661&idx=1&sn=475298a81f5df2a27045297d62e87617&chksm=80e61b35b79192231ef72c5908fd6d20b94c6ebbdaa1377672f52edb118dce568e1f21535469&scene=27#wechat_redirect)

近日，企业级信息安全新媒体平台安全牛发布“网络安全行业全景图（2018年1月）”，此次发布的全景图共分为17大类安全领域，61个细分领域，包含200家安全企业和相关机构。威努特凭借在工控安全领域多行业的产品及技术应用、创新能力等多方面的专业表现，再次荣登业务安全大领域中工控安全细分领域行业榜首。

![](../Images/08184eeb8247ec82533da8cf6d8ed513.png)

自2016年9月全景图首次推出以来，作为工控安全行业领先者，威努特连续多届名列工控安全细分领域榜单。经过2017年快速稳健的发展，取得了多项的骄人成绩，此次名列工控安全细分领域行业榜首，充分证明威努特过硬的企业综合实力。

  

在刚刚过去的一年里，各类安全事件频发，工控安全行业迎来多方面的重大变革，政府相继出台《网络安全法》、《关于深化“互联网+先进制造业”发展工业互联网的指导意见》、《工业控制系统信息安全行动计划（2018-2020年）》等多项政策法规及管理制度，全面提升国家关键信息基础设施运行安全保障。自成立以来，威努特一直专注于工控安全领域。首次提出工业网络白环境理念，在电力、石油石化、轨道交通、市政、化工、烟草等多个行业打造标杆案例。落地项目及市场占有率遥遥领先，以实际行动有效保障国家关键信息基础设施运行安全。再一次入选网络安全行业全景图，是对威努特在工控安全领域综合实力的充分肯定，对用户的选择具有重要参考价值。未来，威努特将持续发力，保持行业视野领先、技术领先、创新能力领先的持续发展道路。为工控安全行业发展注入强劲动力，为中国制造2025护航，为建设网络强国添砖加瓦！

网络安全行业全景图（2018年1月）

  

网络安全行业全景图（2018年1月）于今日发布。本次发布的全景图，共分为17大安全领域，61个细分领域，包含约200家安全企业和相关机构。  

![](../Images/9bac5fea080b20d885ece23bc6fc02bd.png)

与去年相比，**在业务安全大领域中新增两个细分领域**“视频专网”与“办公系统/办公设备”；原技术设施安全中的细分领域**“上网行为管理”更名为**“上网行为管理/Web安全网关”。

![](../Images/a5394b3b0c52fb75508035255fe843b6.png)

据本期全景图统计，**企业业务占有率排名前三细的分领域分别是：防火墙／NGFW（21家），SOC／NGSOC（19家），评估加固／安全运维（19家）。**从此项数据中可以看出，传统安全领域仍是国内安全厂商的主要核心业务。

同时，我们也看到了一些新兴领域的出现。（注：因各别厂商业务较新并具有独特性，无法构成一个专属领域，所以分别在“酷厂商”领域中出现。）

  

**它们分别是：**

  

*   **瑞数信息——网页动态混淆**
    
*   **众享比特——区块链**
    
*   **八分量——可信+白名单**
    
*   **观数科技——Hadoop安全**
    
*   **默安科技——伪装+云安全**
    
*   **卫达安全——动态防御**
    
*   **太极风控——ERP安全**
    
*   **志翔科技——大数据安全**
    
*   **极验——机器验证**
    
*   **云安宝——云堡垒机**
    
*   **蔷薇灵动——微隔离**
    
*   **得意音通——声纹身份认证**
    

  

自2016年9月全景图首次推出以来，安全牛受到了安全相关各领域业内人士的关注，尤其是国内的安全厂商，纷纷积极地与安全牛取得联系并不断地进行沟通，以把全景图梳理的更加合理和准确。

  

全景图的定位是推荐在各个安全细分领域的优秀厂商，而非“企业黄页”或“企业大全”。我们将企业列入全景图某个细分领域的原则有二，一是**根据该产品在国内市场上的占比和销售规模**，二是**根据该产品是否非常具备特色和技术优势**。因此，尽管某安全企业有多条产品线，但可能并不会在相应领域全部露出。
