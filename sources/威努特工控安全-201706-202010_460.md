# 威努特入选《IDC创新者：中国物联网安全，2017》报告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTgyODU3NQ==&mid=2651061975&idx=1&sn=5d9edfb03edd3033add6b394a8f09daf&chksm=80e1e467b7966d714dd8c85a7ed1d50147dc98a309323c6b7c1f4b181f6b1bca6a5943440244&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNTgyODU3NQ==&mid=2651061975&idx=1&sn=5d9edfb03edd3033add6b394a8f09daf&chksm=80e1e467b7966d714dd8c85a7ed1d50147dc98a309323c6b7c1f4b181f6b1bca6a5943440244&scene=27#wechat_redirect)

北京，2017年10月11日——物联网（IoT）在全球已处于快速发展阶段，目前在各个行业得到了广泛的应用并为人类社会带来巨大便捷。但是，由于IoT产品缺乏足够的安全防护，对IoT产品的攻击和利用IoT产品对网络目标的攻击屡次发生。2016年10月21日攻击者制造的"Mirai"恶意软件通过弱口令漏洞控制大量IoT设备并构成庞大的僵尸网络，进而实现对Dynamic Network Service （Dyn）的大规模分布式拒绝服务（DDoS）攻击，直接造成美国互联网大规模瘫痪。

2017年6月1日正式生效的《网络安全法》特别强调了关键信息基础设施的运行安全，而能源、交通、水利等关键基础设施的工业控制环境无疑将是安全建设的重中之重。另外，在智慧城市、车联网、智能家居、智能楼宇、植入式医疗设备、摄像头等方方面面的IoT环境、产品中都需要IoT安全体系的保障。物联网安全建设刻不容缓。

IDC对全球物联网安全产品的分类主要包括设备和传感器安全、网络和边界安全、安全分析和支持基础设施、IoT物理设备自主安全及使能安全四个维度。为帮助初创企业，IDC搭载了相应活动平台并形成了扶持初创企业计划。同时可以为IT Buyer/投资资本提供相关资讯。

IDC创新者是特定领域的新兴IT技术供应商，他们的营收需要在1亿美元以下。这些供应商或是在市场中展示了开创性的商业模式，或是具有创新的技术能力，也可能两者兼而有之。

IDC表示，在中国市场目前有相当数量的新兴公司专注于IoT安全。这些IoT安全相关的公司致力于最大程度的解决IoT环境及产品的安全问题。IDC从公司规模、产品技术，到行业和客户，生态系统建设以及未来发展战略等方面对IoT安全领域的新兴公司进行了考察，最终选择了北京梆梆安全科技有限公司、北京方研矩行科技有限公司、北京杰思安全科技有限公司、北京威努特技术有限公司四家厂商成为IDC物联网安全创新者。《IDC创新者：中国物联网安全，2017》报告介绍了这四家公司的产品和客户案例，分析了其差异化特点以及需要面对的挑战，帮助IT购买者选择技术供应商时，发现最新的IT技术，并找到新产品的评估方法。

威努特公司自2014年9月成立以来，专注于工控安全，在工控安全产品研发上持续投入，不断创新，打造了多行业解决方案，为客户提供培训、咨询、评估、建设、运维等全流程安全服务，迄今已服务于电力、石油、石化、市政、烟草、化工、军工、轨道交通等行业的近百家客户。
