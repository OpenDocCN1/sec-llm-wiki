# 中秋遇国庆|威努特全体员工恭祝您双节快乐！

今年是国庆68周年，又恰逢传统中秋佳节。相信有很多朋友都早早的安排好各种度过双节假期的计划。“小威”是工控安全领域专家，这次也客串一把大家的“私人假期安全专家”。为大家奉上几条实用的假期安全建议，希望您拥有一个愉快、安全的双节假期。

  

![](../Images/f6fceb34add9dd2814c659e4d533ae11.png)

安全提示

一：注意出游安全

旅游有时会经过一些危险区域景点，如陡坡密林、悬崖蹊径、急流深洞等，在这些危险区域，要尽量结伴而行，千万不要独自冒险前往。

二：注意住宿安全

住酒店、旅馆时应先熟悉住宿环境，特别要熟悉酒店、旅馆的疏散逃生路线。

三：注意出行安全

国庆期间，街上游人较多，尤其是有文艺演出活动或者逛商场时，同学们要注意远离人员密集的场所，避免拥挤和踩踏事件的发生。

四：注意饮食安全

饮食要注意合理营养，切忌暴食暴饮。 饭后休息半小时再从事体育运动。 不买街头或小店“三无”食品，不吃腐败变质的食物，以免食物中毒，购买食品时应先检查生产日期、生产厂家、保质期等。

五：注意驾驶安全

驾驶机动车请自觉做到不超速、不超载、不超员、不疲劳驾驶、不酒后驾驶。

六：注意办公室安全

节日期间加班的朋友严禁将易燃、易爆物品带入工作场所；如发现电源线路及电器设备有异常或故障，应及时报告物业相关人员进行处理；严禁在公共办公场所内吸烟，以免引发火灾；最后一个离开办公区域时，要检查各种电源是否关闭，关好窗，锁好门。
