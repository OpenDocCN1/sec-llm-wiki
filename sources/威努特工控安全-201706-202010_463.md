# 工业控制系统安全防护的“黑”“白”之争

随着工业信息化的不断深入，工业化与信息化的融合趋势越来越明显。工业企业在享受互联网巨大便利的同时，也承受着随之而来的各类安全隐患，包括采用存在大量漏洞的通用协议，重要生产单元直接或间接与互联网相连等。  

在几年前，一个病毒需要数周或者数个月才能在工业控制系统网络中发现，而如今，一个病毒在数天甚至更短时间之内就可以在多个国家的工业控制系统中发现样本，勒索病毒就是典型的例子，而且病毒的变种速度之快也令人咋舌，从WannaCry到Petya再到NotPetya也仅仅用了不到3个月的时间。

威努特（小威）作为工业控制系统网络安全行业领先的安全服务供应商，结合目前工业控制系统的特点创新性提出了“白环境”的安全防护理念。

                   

![](../Images/ecf45b945aa2321d828620db6fa85eed.png)

            

“白环境”即采用白名单技术实现工业控制系统安全防护。白名单技术的宗旨是：

*   只有可信任的**设备**，才能接入控制网络。
    
*   只有可信任的**消息**，才能在网络上传输。
    
*   只有可信任的**软件**，才允许被执行。
    

确保任何未经授权的设备、消息及软件等都不允许运行在指定的受保护区域。

小威采用白名单技术实现工业控制系统安全防护的主要原因有以下几点：

（1）更适应工业企业生产业务。首先，从信息安全的三大属性可用性、完整性、机密性来说，工业企业最关注的是可用性，因为数据和系统可用是保证生产业务正常运行的前提。白名单技术采用白名单机制只允许自己信任的、正确的内容通过，不会对数据的可用性造成破坏，并保证了进入系统的数据是信任无害的，从而保障了工业生产网的可用性。再者从实时性考虑，工业生产网对某些变量的数据往往要求准确定时刷新，信号指令必须在确定时限内完成。这就要求在进行安全建设时，所选择的安全产品必须具备低延时，不能影响工业控制网络的实时响应速度。与“厚重”的黑名单机制相比，白名单技术采用轻量级白名单机制能够更好的满足工业生产网络的实时性要求。

（2）白名单机制不需要频繁升级。由于白名单技术是将已知的、信任的内容加入白名单，只要保证白名单的全面性和纯净性即可发挥良好作用。与需要定期更新、频繁把工控网络环境从“稳态”拖入“暂态”的黑名单技术相比，白名单技术拥有天生的优势。

（3）从工业控制网络的特点出发，只要工艺流程、业务数据固定下来，白名单就不会发生变化。即使有变化，只要我们把变化的内容添加到白名单，白名单机制依然能够很好的发挥其安全防护作用。这样一个良好的循坏，保障了安全机制和业务生产长期稳定共存，最终实现基于业务内生的安全。

小威选择白名单技术作为工业网络安全防护的主要手段有以上诸多的理由，那么不选择黑名单技术也自有其道理：

（1）黑名单技术是一种检测或防止已知恶意程序运行或进入非授权区域的方法，大多数防病毒程序就使用的黑名单技术来阻止已知威胁。但由于黑名单不能阻止未知攻击行为，并具有一定的滞后性，致使黑名单技术只能在传统信息化网络中发挥比较好的作用，当然前提是黑名单内容的准确性和完整性要非常高，而保证其准确性和完整性的唯一方法是要定期对其病毒库、特征库甚至系统自身进行升级，升级过程中由于不确定因素太多，可能导致断网、系统崩溃等。正是因为黑名单技术的这种固有不确定性，在工业控制系统安全防护中，黑名单技术显得力不从心。

（2）黑名单技术在使用过程中，基于特征库、漏洞库对系统文件等进行扫描，这个过程会耗费大量系统资源，会对工业控制系统的实时性造成严重影响。

（3）黑名单机制无法发现和阻止“O Day”漏洞的攻击，而白名单机制对于一切不信任、不确定的内容都阻止在网络和系统之外，包括“O Day”漏洞的攻击。因此，在这一点黑名单机制就逊色于白名单机制。

通过以上分析得出，在目前的工业控制网络，白名单技术可谓是工业控制系统安全防护建设工作中的不二选择。那么白名单技术应该如何应用于工业控制系统安全防护建设呢？下面，小威就从工业控制系统业务流程、业务数据分析入手，给大家一一道来。

![](../Images/d77c53ad284a4fe2cc15f3544b0eb205.png)

  

依据GB/T20720.1 《企业控制系统集成 第1部分:模型和术语》中的功能等级模型，将工业控制系统从下到上分为Level0~Level4五个层级，分别是Level0现场设备层、Level1现场控制层、Level2过程控制层、Level3生产管理层、 Level4企业资源层。

*   Level0现场设备层包括传感器和执行机构。传感器用来将各种不同的被测物理量（温度、压力、流量、电量等）转换为能被现场控制器接收的模拟量或开关量，执行机构用来对被控设备进行控制。
    
*   Level1现场控制层主要包括工业控制系统中的核心控制器，如PLC、DCS控制单元和RTU等。控制器直接与传感器、变送器、执行装置相连，实现对现场设备的实时监控并通过工业控制系统实现与过程控制层之间的信息交互；这一层主要实现对现场设备的自动控制。
    
*   Level2过程控制主要包括操作员、工程师站、HMI、SCADA等，主要负责对工程项目文件进行新建、编辑、修改和项目程序的下载、上载，以及生产设备的监控、操作，生产数据的实时采集、存储、报警、打印等，这一层的功能完全作用于level1过程控制层。
    
*   Level3生产管理层主要负责收集和维护与生产、存库、人力资源、原材料、备件和能源使用相关的数据。
    
*   Level4企业资源层主要包括订单管理、物料管理、过程管理、生产排程、品质控管、设备控管以及对整个生产过程进行优化管理等，这一层主要负责将企业生产所需核心业务的所有流程整合在一起，统一生产管理和调度执行。
    

Level0现场设备层通过Level1现场控制层和Level2过程控制层进行控制，Level3生产管理层收集并维护Level1现场控制层和Level2过程控制层的数据，Level4企业资源层则主要涉及生产数据的统一分析和管理，不涉及实时的生产数据。通过以上分析，我们的防护重点就落在了Level1现场控制层~Level3生产管理层。

![](../Images/8f4a4f7a635c325705a184015547fabe.png)

Level1现场控制层~Level2过程控制层运行的数据与生产相关，并且数据类型和业务流程只要确定下来，后期就基本稳定不变。因此，这一层的安全防护没有比采用白名单技术更适合的了。小威在这里常用到的产品包括工业防火墙、主机白名单系统、工控安全监测与审计系统等。

Level3生产管理层位于Level2过程控制层和Level4企业资源层的边界，主要收集和维护生产相关的数据，这些数据都是确定的数据。因此，在这一层小威也将采用白名单技术进行安全防护，常用到的产品包括主机加固系统、主机白名单系统、工业防火墙等。

综上所述，在目前相对还不是完全开放的工业控制网络中，“白环境”理念更适合工业控制网络环境，但在两化融合的大趋势下，未来工业控制网络完全开放与互联网联通的情况下，可以适时引入黑名单机制，通过以“白”为主，以“黑”为辅的防护方式来保障未来工业网络安全。
