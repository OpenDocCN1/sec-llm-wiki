# 喜讯|威努特CEO龙国东荣获2016年中关村创业之星殊荣

“大众创业，万众创新”。北京威努特技术有限公司在CEO龙国东先生的带领下，积极响应政府号召经过多年的不懈努力，终于将威努特打造成为工控安全领域具有自主创新能力的标杆企业。

2017年9月23日，为响应国务院“京津冀一体化”号召，助力创新驱动发展国家战略，实现优质资源的共有共享，推动京津冀协同发展，受河北省邢台市发改委邀请，由北京市科委、中关村管委会等政府部门指导，北京中关村高新技术企业协会和中关村创业投资和股权投资基金协会联合主办的“2016中关村双星汇”之“创业之星”颁奖典礼在邢台万峰大酒店隆重举行。经过评委专家客观、公正的评选，威努特CEO龙国东先生以其独特的视角和企业经营理念及科学人性化的经营管理能力，凭借近三年来的飞速增长，从数百家候选者中脱颖而出，一举荣获“2016中关村创业之星”殊荣。

![](../Images/6d3868f40aff7234d0c8bd29c1d3569b.png)

“中关村创业之星年度评选活动”是北京中关村地区最具权威性和公正力的大型公益性评选活动之一。该活动通过考量企业连续近三年的营收复合增长率、拥有的知识产权、企业创新能力、社会责任感等综合情况，秉承公平、公正、公开、公益相结合的“四公”原则，通过纸面评审和企业路演相结合的方式，经过专家数轮评议后，征询政府相关部门意见，并在网上公示后，最终评选出“2016中关村创业之星”上榜企业家38名。

![](../Images/99beaca5e3fb29290c9aeb0ac31a0e69.png)

据悉，中关村“双星汇”大型系列评选活动首次在邢台举办。旨在为邢台提供精准、多元化商务合作对接机会，进一步提升邢台市营商环境，促进经济发展。

在颁奖典礼仪式结束后，威努特CEO龙国东先生与中关村企业家代表们先后考察了5家邢台市重点企业，并对邢台的投资环境、高端产业发展进行了深入了解。

获评的“2016中关村创投之星”和“2016中关村创业之星”代表在发言中对邢台的发展环境给予了高度评价，并表示下一步将和邢台相关部门进行深入对接，寻找更多产业合作、转移的契机。![](../Images/9f8b692a35bfe84039143d3f670cc710.png)

威努特CEO参观邢台当地重点企业。

作为众多高新科技创新创业者中的佼佼者，威努特公司自2014年9月成立以来，专注于工控安全，在工控安全产品研发上持续投入，不断创新，打造了多行业解决方案，为客户提供培训、咨询、评估、建设、运维等全流程安全服务，迄今已服务于电力、石油、石化、市政、烟草、化工、军工、轨道交通等行业的近百家客户。

威努特公司致力于为客户构建安全可靠的工业网络环境，为国家关键信息基础设施运行安全提供保障，为中国制造2025保驾护航，为建设网络强国添砖加瓦！
