# 直击ISC2017 威努特：工控安全由我们来守护！

9月12日，亚太地区最大规模的安全会议——2017中国互联网安全大会(ISC2017)在北京国家会议中心盛大开幕。本次大会的主题为“万物皆变，人是安全的尺度”。 北京威努特技术有限公司作为国内工控安全行业的代表企业连续三年受邀出席大会，昭示自己的坚持：“工控安全由我们来守护！”

**新品发布——工业互联网雷达**

进入主会场新品发布区，一块巨大的屏幕迎面而来，上面展示的正式本次威努特最新发布的拳头产品——工业互联网雷达。

 

![](../Images/8fc9e91e9d93c8c79c9f396394f6a17b.png)

工业互联网雷达发布现场

目前，工业互联网安全现状非常严峻，公开的ICS漏洞数量逐年递增，截止2017年9月CNVD收录的工控漏洞数量达到1264个，公开安全事件数量近年来居高不下。美国非常重视关键信息基础设施安全，早在2012年美国国土安全部通过Project Shine项目搜索暴露在互联网上的关键信息基础设施，已经收集了全球范围内超过220万条数据，并确定其中7200个为美国关键信息基础设施。随着中国制造2025、互联网+、智慧城市政策推进，越来越多的关键信息基础设施接入互联网，对其有效监控，掌握网络安全态势信息符合国家安全战略，我国亟待建设相关监测能力。

工业互联网雷达是威努特在多年从事工控安全研究、实施和服务的基础上，洞察客户需求和行业趋势而研发的一款产品。工业互联网雷达是为政府、监管部门、能源等大中型企事业单位提供工业互联网资产探测、漏洞预警与宏观安全形势展现等服务的技术平台。该平台支持Siemens S7、Modbus、IEC 60870-5-104、DNP3等35种以上的工控协议指纹识别，支持工控设备无损漏洞探测，可实现全球工控设备信息和漏洞信息的隐匿探测及全局采集，同时准确定位工控设备。其搜索内容全、范围广、效率高，可支撑监管单位完成安全监测、检查、整改的闭环工作，对于评估工业控制系统的安全性，推动国家关键信息基础设施的网络安全保障工作具有极为重要的意义。

2017年8月中国信息通信研究院上线我司一套工业互联网雷达系统，用于开展接入互联网的工控系统普查工作。当前该系统运行良好，扫描速度快、定位准确，为客户掌握工控相关网络安全态势提供了有力保障。

**智慧城市工控安全攻防演练平台**

ISC联席主席、360企业安全集团董事长齐向东在开幕致辞特别提到基础设施安全的重要性：“今天我们面对APT攻击的时候，攻击的目标是毁掉一个基础设施，比如水厂、电厂等，或者盗窃一批关键数据。哪怕是只漏掉万分之一，损失都是不可承受的。”

金一南说过：“多数人因为看见而相信，只有少数人因为相信而看见。”安全行业面临此问题尤甚，如何让多数人看见安全威胁？威努特本次展出的“智慧城市工控安全攻防演练平台”就是一个很好的方法。智慧城市，安全先行。威努特凭借多年在工控安全领域的技术积累，打造了智慧城市工控安全攻防演练平台，将其全线工控安全产品和业界领先的工控安全“白环境”解决方案全景化、可视化直观呈现在公众面前。在该平台中，通过可视的形式，向观众展示了发电、电网、燃气、自来水和地铁遭受攻击给人民群众生活带来的灾难性后果，同时展示了通过威努特的安全产品和技术方案可以应对这些攻击，将风险降到最低。充分体现了人是安全的尺度这一主题。
