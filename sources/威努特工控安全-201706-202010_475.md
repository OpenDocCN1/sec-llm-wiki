# 2017网络安全周，威努特捍卫工控安全

响应国家号召的网络安全宣传周活动，即将于下周在全国各地先后开展。作为国内工控安全领域的标杆企业，威努特将应邀出席上海“2017年网络安全博览会暨网络安全成就展”，并携智慧城市工控安全攻防演练平台精彩亮相。展会将于9月16日至20日于国家会展中心（上海）举办，威努特位于F4展位，届时欢迎您的莅临指导。

![](../Images/dbd6a8d18795479f655b307a694b1a09.png)

智慧城市，安全先行。威努特智慧城市工控安全攻防演练平台通过全景式、可视化的手段，将全线工控安全产品和业界领先的工控安全“白环境”解决方案呈现在公众面前。在该平台中，通过直观形象的方式，向观众展示了发电、电网、燃气、自来水和地铁遭受攻击给人民群众生活带来的灾难性后果，同时更重要的是展示了通过威努特的安全产品和技术方案可以应对这些攻击，将风险降到最低。

本次展会上，威努特还将展示一款重磅产品——工业互联网雷达。工业互联网雷达是为政府、监管部门、能源等大中型企事业单位提供工业互联网资产探测、漏洞预警与宏观安全形势展现等服务的产品平台。该平台支持Siemens S7、Modbus、IEC 60870-5-104、DNP3等35种以上的工控协议指纹识别，支持工控设备无损漏洞探测，可实现全球工控设备信息和漏洞信息的隐匿探测及全局采集，同时准确定位工控设备。其搜索内容全、范围广、效率高，可支撑监管单位完成安全监测、检查、整改的闭环工作，对于评估工业控制系统的安全性，推动国家关键信息基础设施的网络安全保障工作具有极为重要的意义。2017年8月中国信息通信研究院上线一套威努特工业互联网雷达系统，用于开展接入互联网的工控系统普查工作，当前该系统运行良好。  

![](../Images/4ffec4c67ac48bcec1125df0bcf68016.png)

北京威努特技术有限公司是国内专注于工控安全领域的高新技术型企业。以研发工控安全产品为基础，打造多行业解决方案，提供培训、咨询、评估、建设、运维全流程安全服务。首次提出工业网络“白环境”理念，迄今已服务电力、石油、石化、市政、烟草、化工、军工、轨道交通等行业近百家客户，落地项目遥遥领先，市场占有率全国第一。受邀保障“G20峰会”和“一带一路”国际合作高峰论坛。

当前，建立维护网络安全的长效机制是当务之急。进入新世纪以来，科技水平日新月异，网络安全攻击也层出不穷，涉及众多国家关键基础设施的工控安全形式严峻。我们要紧跟时代发展的趋势，在创新中找思路、在发展中求突破，安全与发展并驾齐驱，才能使我国的网络真正安全，为我国两个一百年保驾护航。
