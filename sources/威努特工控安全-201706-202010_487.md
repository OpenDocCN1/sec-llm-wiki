# 威努特出席2017第二届信息安全服务年会并发表演讲

7月20日-21日，“网络安全法及关键信息基础设施保护培训会”和“2017第二届信息安全服务年会” 在北京万寿庄宾馆召开，本届会议由公安部第三研究所、国家网络与信息系统安全产品质量监督检验中心主办，100余名信息安全主管部门领导，行业信息化建设负责人，大型央企、信息安全领域的权威专家和学者，以及知名信息安全产品厂商、安全服务商等相关人士参加。威努特总经理龙国东受邀出席会议，并发表《工控信息安全产业发展探讨》的演讲。

 

![](../Images/bd80fdaa5f9b0e43e042dbb94b695bd8.png)

龙国东说，《网络安全法》规定关键信息基础设施的具体范围由国务院制定，《关键信息基础设施确定指南（试行）》中给出的重点行业包括：能源、金融、交通、水利、医疗卫生、环境保护、工业制造（原材料、装备、消费品、电子制造）、市政、电信与互联网、广播电视、政府部门，其中大多数均与工业控制系统相关，工控安全是关系国计民生的大事。 “风起青萍之末”，国内工控安全的起源可以追溯到2006年8月在中国工业设备网刊发的一篇文章《工控软件安全性的设计问题探讨》，比鼎鼎大名的震网事件还早了四年。2011年，工信部《关于加强工业控制系统信息安全管理的通知》（工信部协〔2011〕451号）中对重点领域工业控制系统信息安全要求做出了明确要求。

 

![](../Images/d34cfe6899428741f81ef29857e742f1.png)

2014年，可称为工控安全元年，那一年工业控制系统信息安全产业联盟（ICSISIA）在北京成立，推荐性国家标准GB/T30976.1～.2-2014《工业控制系统信息安全》正式发布，工业控制系统信息安全技术国家工程实验室在北京正式揭牌成立，当然，威努特也在那年成立。经过三年多的发展，现在国内工控安全市场已经处于高速增长导入期，产品层面开始从“产品线完善”转向“产品功能完善”；厂商层面从“布局圈地”转为“深耕产粮”，市场竞争加剧；行业层面行业应用依然高度集中，但应用领域不断扩大；用户层面信息安全意识明显提升，引导工作越来越有针对性；未来预期2017-2020年有望迎来爆发性增长。威努特从2015年销售额仅有几百万，迅速发展成为国内工控安全的领军品牌，今年的销售目标是超过5000万。

总体来说，工控安全无论从技术、市场还是监管层面，依然面临挑战与机遇并存的局面。下一步威努特将从以下几个方面开展行动：一是积极配合关键信息基础设施检查，做好技术检查队伍支撑；二是积极配合有关机构构建中国的工控安全准入机制，从源头做好；三是积极参与国家标准、行业标准及产品标准的制定；四是以重点行业（电力、轨道交通等）带动，辐射带动其他行业；五是与国家监管单位紧密配合，为国家工控安全产业的发展添砖加瓦！
