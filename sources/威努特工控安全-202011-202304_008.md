# 威努特工控安全监测与审计系统通过山西省工信厅工业互联网安全态势感知相关产品测试

# 根据《山西省工业和信息化厅关于征集工业互联网安全态势感知相关产品的通知》有关安排，山西省工业和信息化厅委托国家计算机网络与信息安全管理中心山西分中心对工业互联网安全态势感知相关应征产品（第二批）进行对接测试。近日，山西省工信厅发布公告，公布相关产品测试结果，**威努特工控安全监测与审计系统全面满足《省级工业互联网安全态势感知平台与企业侧对接规范》，顺利通过产品测试，可实现与省级态势感知平台对接。**

  
  
  
  

![](../Images/da84053e8d414f6813109970b85d9654.png)

根据《国务院关于深化“互联网+先进制造业”发展工业互联网的指导意见》中关于“推动安全技术手段建设，提升隐患排查、攻击发现等技术能力”的要求，工信部部署建设国家、省、企业三级协同的工业互联网安全监测与态势感知平台，这是加强国家工业互联网安全保障的一项重要工作。为充分发挥国家、省、企业三级平台协同处置网络安全事件的能力作用，全面提升网络安全监测感知等防护能力，山西省工信厅、省委网信办、省国资委联合开展国有企业、工业企业等对接省级工业互联网安全态势感知平台工作。省级平台的建设完成，将在发现和处置企业网络安全事件方面发挥重要作用，为企业的安全生产提供有力保障。

  

![](../Images/c05aff1ab96f81172930226d88ab9e01.png)

作为国内工控安全行业领军者，威努特始终以守护国家工业信息安全为己任，全力打造出全系列工控安全明星产品并在电力、轨道交通、石油石化、市政等国家重要行业得到有效应用。本次入围山西省工业互联网态势感知平台建设的威努特工控安全监测与审计系统，是专门针对工业控制网络的信息安全审计平台，产品采用旁路模式部署，可实现工业生产过程“零风险”。通过对工业控制协议的通信报文进行深度解析，能够实时检测针对工业协议的网络攻击、用户误操作、用户违规操作、非法设备接入以及蠕虫、病毒等恶意软件的传播并实时报警，同时详实记录一切网络通信行为，包括指令级的工业控制协议通信记录，为工业控制系统的安全事故调查提供有力依据。

工业互联网的发展是推进制造强国和网络强国的重要基础，做好网络安全工作成为企业生产和发展的重要前提。未来，威努特将充分响应国家号召，全力发挥自身技术优势和产品优势，为进一步提升山西省企业信息安全防护能力和水平，保障山西省企业网络安全和生产安全贡献力量！

![](../Images/f9d33686deb42ca315f98329dc4b5cf3.png)**威努特简介**![](../Images/f9d33686deb42ca315f98329dc4b5cf3.png)

北京威努特技术有限公司(简称:威努特)是国内工控安全行业领军者，是中国国有资本风险投资基金旗下企业。凭借卓越的技术创新能力成为全球六家荣获国际自动化协会ISASecure 认证企业之一和首批国家级专精特新“小巨人”企业。

威努特依托率先独创的工业网络“白环境”核心技术理念，以自主研发的全系列工控安全产品为基础，为电力、轨道交通、石油石化、市政、烟草、智能制造、军工等国家重要行业用户提供全生命周期纵深防御解决方案和专业化的安全服务，迄今已为国内及“一带一路”沿线国家的4000多家行业客户实现了业务安全合规运行。

作为中国工控安全国家队，威努特积极推动产业集群建设构建生态圈发展，牵头和参与工控安全领域国家、行业标准制定和重大活动网络安全保障工作，始终以保护我国关键信息基础设施网络空间安全为己任，致力成为建设网络强国的中坚力量!
