# 六大角度解析一款优秀的工业防火墙是怎样炼成的

**前言**

  
  
2019年9月，GB/T 37933-2019《信息安全技术 工业控制系统专用防火墙技术要求》正式发布，标志着工业网络选择防火墙产品具有唯一标准，也意味着从专业角度建议工业网络安全防护应采用工业控制系统专用防火墙产品。  
本文将**从研发理念、功能、性能、可靠性、可用性和环境适应性六大角度**，详细阐述一款优秀的工业防火墙，是如何炼就钢筋铁骨的一身本领，也让用户理解传统防火墙增加工业协议解析模块并不意味着就是真正的工业防火墙。  

**研发理念方面**

  
  
**工业控制系统专用防火墙，需要采用基于白环境的主动防御技术理念。**与传统IT防火墙和基于IT防火墙演变而来的工业防火墙不同，真正的工业防火墙是采用基于白环境的主动防御技术理念。**白环境技术的宗旨是：只有可信任的设备，才能接入控制网络；只有可信任的消息，才能在网络上传输。**而传统IT防火墙是采用基于黑名单的被动防御技术理念，在传统黑名单防御基础上增加工业协议解析模块，其系统本身主要能力还是黑名单，这是与基于白名单开发的工业防火墙最大的不同。实践证明，**采用白名单的主动防御技术，相比于传统基于黑名单的被动防御技术，更适用于工业控制系统。**  
白名单主动防御技术更适用于工控网络的主要原因有以下几点：  
**（1）更高的实时性。**与“厚重”的黑名单机制相比，白名单技术采用轻量级白名单机制，能够更好的满足工业生产网络的实时性要求。  
**（2）白名单机制不需要频繁升级特征库。**由于白名单技术是将已知的、信任的内容加入白名单，只要**工艺流程、业务数据固定下来，白名单就不会发生变化，生产业务系统也能稳定运行。**与需要定期更新特征库，频繁把工控网络环境从“稳定状态”拖入“不确定状态”的黑名单技术相比，白名单技术拥有天生的优势。  
**（3）白名单机制可以检测和防止未知威胁。**黑名单机制基于已有特征库来检测和防止威胁，无法发现和阻止未知威胁；而白名单机制对于一切不信任、不确定的内容都阻止在网络和系统之外，可以有效防止未知威胁。

**功能方面**

  
  
**工业控制系统专用防火墙，不止于工业协议的深度解析。**一直以来，用户主观认为工业防火墙的主要功能，就是对工业协议的深度解析，其实这种观点大错特错。  
工业控制系统的安全防护不同于传统安全防护，是有业务逻辑规律可循的。工业控制系统的安全防护，需要找寻一个“时机”，这个“时机”需要靠两种规范来进行约束，一种是工业控制系统环境规范，一种是生产业务行为规范。  
**工业控制系统环境规范**，这里并非指物理环境，而是工业生产运行环境，包括生产设备、设备操作系统、工业应用软件、工业通讯协议等，主要功能包括**工业资产识别、资产间会话关系、风险识别、漏洞利用防护、工业协议白名单**等。  
**生产业务行为规范**，是从指令周期、时序逻辑等角度对生产业务工艺行为逻辑进行规范，建立**基于指令周期和时序逻辑的业务工艺白名单。**针对逻辑性、时序性强的业务流程，允许客户轻度或无参与地定义工控协议合法工艺序列集、报文传输周期及时延容忍度，通过工艺业务在控制协议中体现的时序逻辑、周期、频率等特点建立的业务模型，能够**发现隐匿在合法指令中的异常工艺行为**，从而消除工控系统因序列攻击或用户的误操作产生的危害。  
目前主流的工业防火墙产品，几乎都是针对**工业控制系统环境**进行安全防护，属于**空间上的防护**，完全忽略了生产工艺行为异常对工业控制系统正常运行带来的危害。而**业务工艺白名单**属于**时间上的防护，只有从空间和时间两个角度建立起来的白名单约束，才是真正符合工业控制系统白环境的防护手段。**

**性能方面**

  
  
**工业控制系统专用防火墙，需要更低的传输时延。**工业控制系统对网络传输时延要求非常高，因此也要求工业防火墙具备更低的传输时延，要求小于90us；而传统IT网络则对传输时延不敏感，要求小于200us。

  

![](../Images/df364c3069c6f8bd08d9a0e6d66a7672.png)

图3 工业防火墙平均时延测试结果  

**可靠性方面**

  
  
**工业控制系统专用防火墙，需要故障开放设计。**工业防火墙应用在两个或更多的网络之间，会对通过它的网络报文进行分析，以判断是否有威胁存在，处理完成后再按照一定的规则将报文转发出去。如果工业防火墙设备出现故障，比如断电或程序挂死，那连接在工业防火墙上的所有网络也就彼此失去联系。  
**工业防火墙为适应工业控制系统对可用性的高要求，****按照“故障开放”原则进行设计，**即工业防火墙故障时需要保证网络畅通，所以**Bypass功能是工业防火墙的标配**；而IT防火墙按照“故障关闭”原则设计，即IT防火墙故障则断开内外网的网络连接，不适用于工业控制系统。  
**威努特工业防火墙最高配备88个继电器，全电口支持Bypass，最大程度上保障业务连续性；**传统墙或传统墙演变而来的工业墙，不支持或少数端口支持Bypass，对业务连续性要求不高，两种防火墙在硬件配置上差别巨大。

**可用性方面**

  
  
**工业控制系统专用防火墙，具备更丰富的接口类型。**现场众多工业控制系统设备并不像传统IT系统设备一样，具有标准的RJ45接口。工业控制系统设备的接口类型由于历史原因，具备多样性，如RS-232/422/485总线接口。对于此类设备的安全防护，传统IT系统防火墙或者沿用传统IT防火墙硬件的工业防火墙，是无法进行安全防护的。**专业的工业防火墙在硬件设计之初，就具备RS-232/422/485这样的总线接口，**可以对只有此类接口的设备进行安全防护。

**环境适应性方面**

  
  
**工业控制系统专用防火墙硬件，需要精工锻造的工业级品质。**在工业生产环境中，工业防火墙要求能够适应恶劣的工业现场环境。工业现场的环境比普通IT网络环境要恶劣，至少在**震动、湿气、温度、电磁干扰、盐雾、粉尘**上都要比普通IT网络环境恶劣。由于传统防火墙在设计之初，并不是从工业控制系统应用出发的。当它应用到工业现场，面对恶劣的工况，严重的线间干扰等，必然会引起其可靠性降低。专业的工业防火墙在设计的时候就考虑到工业现场的复杂情况，从而更加适应工业环境而发挥工业级防火墙的作用。  
接下来，让我们通过实际测试结果，检验下威努特工业防火墙在恶劣的工业现场环境中运行的表现。

**1、极端环境大考：严寒与高温中的坚韧**

GB/T 37933中规定了工业防火墙的工作温度要求，其中应用于工业现场的工业防火墙工作温度不低于-40~70℃，应用于一般环境的工业防火墙工作温度不低于-10~60℃。

**3、实测电磁兼容性：无惧强干扰**

在工业生产线上往往都部署有大量的电气设备，而这些设备在运转中产生出的强电磁噪声则会对现场网络设备的数据传输带来一系列的干扰，令整个通信网络性能下降，丢包现象频发。

实测后发现，**威努特工业防火墙在EMC 4级强度的测试条件下，依然可以稳定的正常运行，而且没有任何丢包、宕机或损坏情况发生，**完全可以应用在电力、轨交等对设备电磁兼容性防护要求较高的工业控制系统中。  

**4、无风扇全密闭设计**

各类粉尘一直是威胁电子设备正常运转及使用寿命的天然“杀手”，在复杂的工业环境中，不论是带有风扇的传统IT防火墙，还是机身遍布散热孔的普通工业防火墙，都将面临粉尘侵入而影响设备散热、加速元器件老化的威胁。  
为了提升设备的稳定性，**威努特工业防火墙采用无风扇设计，取消外壳上的散热孔构造，而改为采用一体成型的精钢外壳加上内部独特的散热设计，来帮助散热，已达到无风扇全密闭结构设计。**

综上，**工业控制系统与传统IT系统是完全不一样的系统，对工业工控系统的安全防护需要使用专业的工业防火墙产品。**优秀的工业防火墙应从现场使用环境、工业资产、工业应用、工业传输协议和生产业务等实际需求出发，从研发理念、功能、性能、可靠性、可用性和环境适应性六大角度来规范软硬件设计，而不是在传统IT防火墙的基础上增加软件功能。
