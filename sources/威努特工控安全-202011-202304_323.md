# 预告| 工业互联网安全讲坛第二期聚焦“漏洞”精彩开讲

国家工业信息安全发展研究中心联合工业信息安全产业发展联盟、北京工业互联网技术创新与产业发展联盟推出“工业互联网安全讲坛”品牌活动，面向新一代信息通信技术与工业经济深度融合产生的安全问题，聚焦工业互联网、（工业）物联网、“5G+工业互联网”等安全需求，分享战略标准、前沿技术、关键设备、创新应用等系列核心成果，争创产学研用一体化深度融合的权威性、引领性交流学习平台。  
  
第二期活动“工业互联网安全的战略资源——漏洞”将于**11月7日14：00**精彩开讲。**北京威努特技术有限公司联合创始人&首席技术官黄敏受邀分享《工业互联网设备漏洞挖掘关键技术及应用》，聚焦工业互联网漏洞挖掘分析，分享在工业互联网设备典型场景下的应用技术。**届时将为您带来一场学术与产业的学习交流盛宴，敬请期待！
