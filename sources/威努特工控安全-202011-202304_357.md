# 威努特承担首台（套）全国产智能监控系统网络安全建设

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTgyODU3NQ==&mid=2651078545&idx=1&sn=7f31b7bb1b0e9321adaf61c132e2b0cd&chksm=80e62521b791ac3704543b81a9996055fae40ebf679d64af1f98b2193e2dce0e531364daffe9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNTgyODU3NQ==&mid=2651078545&idx=1&sn=7f31b7bb1b0e9321adaf61c132e2b0cd&chksm=80e62521b791ac3704543b81a9996055fae40ebf679d64af1f98b2193e2dce0e531364daffe9&scene=27#wechat_redirect)

![](../Images/237ff58a8b5fe32028e5d43dad949e38.png)8月6日，华能小湾水电站智能监控系统投入运营，**我国首次**实现了 700 兆瓦级大型水电机组的**全国****产智能监控**，标志着我国高水头、大容量水力发电领域核心监控系统实现自主可控。同时，中国华能集团授予小湾水电站“700兆瓦水电机组全国产计算机监控系统首台（套）示范基地”称号。

计算机监控系统是水电站的“神经中枢”，是水电站核心控制系统，通过对水电站机组和辅助系统的智能控制，实现机组的自动启停、负荷及运行工况的智能调整，是保障电网安全稳定运行的重要基础。掌握水电计算机监控系统核心技术，并拥有完全自主知识产权，是保障国家能源安全的重要支撑。

  

小湾水电站是国家重点工程和实施西部大开发、“西电东送”战略的标志性工程，总装机容量420万千瓦，单机容量70万千瓦，年保证发电量190亿千瓦时，是澜沧江中下游河段的龙头电站。**威努特于2017年就承担了国家发改委《小湾水电厂生产控制系统信息安全监管与预警平台项目》**，其具备完全自主知识产权的工控安全解决方案帮助水电站实现了总体安全现状分析，并提供简便易用的回溯功能，为工业控制系统安全事故调查提供技术手段，全面提高了生产控制网络的整体安全性，得到了客户的高度认可。

  

**此次小湾水电站全国产化计算机监控系统改造项目，同时也引领了水电控制系统在信息安全、调节性能等方面的前沿发展。威努特在其再次承担了全国产智能监控网络安全建设重任。**威努特依托自主研发的国产化工控安全产品针对水电站生产控制大区进行合规补全及安全检测功能提升，除满足GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》、《电力监控系统安全防护总体方案》（36号文）等国家标准政策要求外，增强了未知威胁检测能力。项目于2021年4月顺利完成厂验环节，5月进场配合完成现场实施并进入试运行，于8月完成试运行并正式投产。威努特用专业的技术回馈客户的信任，再次赢得了客户的表扬与肯定。

  

![](../Images/9b1bb3ce297dda23c05b1a6a6a77f3cd.png)

  

中国自主可控国产化的路径既是历史的必然，也是时代的脉搏。小湾水电站全国产计算机监控系统的正式投运，对于提升水电控制信息安全和网络安全水平，实现水电站核心技术国产化替代具有重大作用。未来，威努特将继续积极支撑关键信息基础设施领域国产化替代，持续为工业企业用户提供自主可控的工控安全产品和创新的工控安全解决方案。![](../Images/a65448be4beb31a423248b69e20f3af7.png)**威努特简介**![](../Images/a65448be4beb31a423248b69e20f3af7.png)

  

北京威努特技术有限公司（简称：威努特）成立于2014年，专注于工控安全领域，以自主研发的全系列工控安全产品为基础，为电力、轨道交通、石油石化、市政、烟草、智能制造、军工等国家重要行业用户提供全生命周期纵深防御解决方案和专业化的安全服务。凭借持续的研发创新能力和丰富的实战经验入选全球六家荣获国际自动化协会ISASecure认证企业之一和亚太地区唯一全球网络安全联盟(GCA)创始成员。威努特秉承首创的工业网络“白环境” 技术理念，迄今为国内及“一带一路”沿线国家的2000多家客户实现了业务的安全合规运行，已成为最受客户信赖的工控安全领军企业。同时，作为中国工控安全国家队，积极推动产业集群建设构建生态圈发展，牵头和参与工控安全领域国家、行业标准制定和重大活动网络安全保障工作，致力于为国家关键信息基础设施保驾护航。

威努特始终以“专注工控，捍卫安全”为使命，致力于为我国关键信息基础设施网络空间安全保驾护航！
