# 威努特入选工信部《2021年网络安全产融创新发展报告》创新企业案例

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTgyODU3NQ==&mid=2651077986&idx=1&sn=2e9c824b483a5e51be9460c93d521dbf&chksm=80e627d2b791aec4fdac227bfa824b6081ea9c41e1c18ef442801cd78ca8c56791c065f72600&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNTgyODU3NQ==&mid=2651077986&idx=1&sn=2e9c824b483a5e51be9460c93d521dbf&chksm=80e627d2b791aec4fdac227bfa824b6081ea9c41e1c18ef442801cd78ca8c56791c065f72600&scene=27#wechat_redirect)

近日，工业和信息化部网络安全产业发展中心正式发布《2021年网络安全产融创新发展报告（上半年）》（以下简称《报告》）。**威努特作为工控安全领军企业，凭借领先的技术创新能力、不俗的市场表现和优秀的行业应用场景，成功入选《**报告**》第一批创新企业案例。** ![](../Images/c5a85138bef7e605981b0d7fd7e3191e.png)  

《报告》以2020年及2021年第一、二季度最新网络安全产融活动为基础，结合中外对比及企业调研，多角度总结分析了中国网络安全产融协同发展情况。通过调研200余家网络安全领域的创新企业，《报告》发现最近两年的市场热点主要集中在**工业互联网安全、**云安全、身份安全和数据安全四大领域。**工控安全、**云主机安全、云原生安全、开发安全、零信任架构、大数据交换、网络空间资产测绘、蜜罐诱捕、威胁检测与响应、网络靶场为十大创新技术热点。网络安全产业应用场景不断拓展，产品、服务与解决方案融合创新。 

  

![](../Images/1a32cef8aec7904e870b091d1fe0e150.png)

 

此次威努特入选《报告》的创新企业案例为**某电力企业监管与预警平台项目案例**：通过对企业工控系统的网络安全建设，最终实现生产控制系统网络安全从边界防护到纵深防御、从被动防护到主动防御、从单一设备防护到协同联动的能力提升，实现集控中心到下属电站生产控制系统常态化、体系化的网络安全态势感知，做到知己、知彼、知未来，构筑精准防护和联防联控的网络安全综合防控系统。**威努特作为国内唯一全面覆盖所有发电业务形态（风光水火核）及电力监控系统Ⅰ、Ⅱ、Ⅲ区所有业务系统的安全公司**，该项目是威努特打造的电力重要信息系统网络安全保障示范工程，在该集团业务范围内起到标杆示范作用。 威努特专注工控安全领域，自成立以来以来一直积极探索技术创新，自主研发了5大类30款工业网络安全产品，并已申报73项发明专利、71项软件著作权和76项原创漏洞证明等核心知识产权，为拓展业务方向积极进行技术储备。经过七年稳健运营，威努特已为国内及“一带一路”沿线国家的2000多家客户实现了业务的安全合规运行，在技术应用和安全服务方面积累了丰富的经验。威努特市场发展前景持续被业界一致看好，2021年初威努特顺利完成3亿元D轮战略融资。在两位央企股东的加持下，威努特正式成为中国工控安全“国家队”，同时进一步巩固了在工控安全领域独角兽的地位。  
此次入选《报告》第一批创新企业案例，是工业和信息化部网络安全产业发展中心对威努特创新能力及市场表现的充分认可，也是对威努特行业技术应用的充分肯定。未来，威努特将充分发挥自身优势，持续技术创新，持续为我国关键信息基础设施保驾护航。 ![](../Images/a65448be4beb31a423248b69e20f3af7.png)**威努特简介**![](../Images/a65448be4beb31a423248b69e20f3af7.png)

  

北京威努特技术有限公司（简称：威努特）成立于2014年，专注于工控安全领域，以自主研发的全系列工控安全产品为基础，为电力、轨道交通、石油石化、市政、烟草、智能制造、军工等国家重要行业用户提供全生命周期纵深防御解决方案和专业化的安全服务。凭借持续的研发创新能力和丰富的实战经验入选全球六家荣获国际自动化协会ISASecure认证企业之一和亚太地区唯一全球网络安全联盟(GCA)创始成员。  
威努特秉承首创的工业网络“白环境” 技术理念，迄今为国内及“一带一路”沿线国家的2000多家客户实现了业务的安全合规运行，已成为最受客户信赖的工控安全领军企业。同时，作为中国工控安全国家队，积极推动产业集群建设构建生态圈发展，牵头和参与工控安全领域国家、行业标准制定和重大活动网络安全保障工作，致力于为国家关键信息基础设施保驾护航。

  

威努特始终以“专注工控，捍卫安全”为使命，致力于为我国关键信息基础设施网络空间安全保驾护航！
