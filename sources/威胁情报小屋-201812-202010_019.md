概述

  

  

  

  

  

  

  

      

    FIN7是一个出于经济动机的威胁组织，自2015年中期以来，其主要针对美零售，餐饮和酒店业。

    网络攻击组织通常会采用钓鱼邮件，水坑攻击等方式作为切入口进行攻击，而近期Trustwave SpiderLabs的安全人员发现他们的几个客户遭受了一种特殊的物理攻击。

攻击者伪装成全球最大的家用电器和电子产品零售集团之一的Best Buy。向受害者邮寄了一封快递信件，信件中包含一个usb。声称其将会给老用户给予50美元的礼品，相关礼品清单在usb中，请通过usb查看。

    主要执行流程如下

1.  通过获取当前UTC毫秒来生成唯一ID
    
2.  检查脚本是否在文件夹％AppData％\\ Microsoft \\ Windows中，如果不是，则将其自身删除
    
3.  延迟执行2分钟
    
4.  生成包含以下信息的数据：
    

1.  组：f1（硬编码）
    
2.  rt：2（硬编码）
    
3.  secret：秘密哈希（硬编码）
    
4.  时间：120000
    
5.  uniq\_id：当前UTC毫秒
    
6.  id：MAC地址和主机名（使用WMI查询）
    

6.  URL对数据进行编码，并使用随机生成的密钥对数据进行XOR编码。
    
7.  将生成的XOR密钥附加到以“＆\_＆”分隔的编码数据
    
8.  形成一个包含参数的HTTP POST主体。
    

1.  kbaxmaconhuc = <编码数据+生成的XOR密钥>
    

10.  形成一个URL路径：
     

1.  https：// <命令和控制域> / <随机路径> / <随机文件> /？type = name
    

12.  使用以下HTTP请求标头将数据作为HTTP POST原始主体发送到命令和控制URL：
     

5.  用户代理：Mozilla / 5.0（Windows NT 6.1; Win64; x64; rv：69.0）Gecko / 20100101 Firefox / 50.0'
    
6.  内容类型：％application / x-www-form-urlencoded'
    

14.  命令和控制响应已编码的JScript代码
     
15.  使用eval（）解码并执行Jscript代码
     

如果C＆C服务器处于活动状态，它将以编码数据进行响应，如图9所示。编码数据包括一个XOR密钥以对其进行解码。数据和键用*“＆\_＆”*   或URL编码的“％26\_％26”定界。解码后的数据显示了将在受感染主机中执行的其他Jscript代码。

* * *

    根据多个社区安全人员反馈，此次攻击活动与臭名昭著的FIN7组织存在重叠

![](../Images/a37b69df8ba92f54244e26e382348dc7.png)

    这些类型的USB设备已广为人知，并被安全专业人员使用。它们也很便宜并且任何人都可以买到。意味着犯罪分子“在野外”使用这种技术只是时间问题。由于USB设备无处不在，使用并随处可见，因此有人认为它们无害且安全。一般人可能会对未知USB设备的内容感到非常好奇。常常会将未知的usb插到自己的设备，这一举措是存在安全风险的。本次攻击活动告诫我们，对于不信任来源的可移动设备要保持戒备，不能将其插入到自己的计算机直接使用。
