# 疑似APT34针对黎巴嫩的攻击活动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NDA1OTQxMA==&mid=2247484638&idx=1&sn=54c6bf04295a89249f5be388239c7f72&chksm=c0241223f7539b35c9dfe56fd677adb41bdbd98d8f900206cf6c739542dbb3b6b097f25bad57&scene=126&sessionid=1681278910#rd](http://mp.weixin.qq.com/s?__biz=Mzg5NDA1OTQxMA==&mid=2247484638&idx=1&sn=54c6bf04295a89249f5be388239c7f72&chksm=c0241223f7539b35c9dfe56fd677adb41bdbd98d8f900206cf6c739542dbb3b6b097f25bad57&scene=126&sessionid=1681278910#rd)

![](../Images/e987b5389f1659493b5a381f264fe5bd.png)概述

  

2018年11月，思科Talos的研究人员将针对黎巴嫩和阿联酋的攻击活动进行了跟踪和详细披露，并命名为“ *DNSEspionage** ”*活动。

在2019年4月，思科Talos发现了APT34（代号Helix Kitten或OilRig）与“ *DNSEspionage”*之间存在关联。Talos分析师发现了攻击者使用的基础架构中和常用TTP存在一些重叠之处。并命名了一个新的植入样本：Karkoff

来自Cybaze / Yoroi Zlab的专家发现了一个新样本，并认为这是Karkoff更新。可以证明APT34仍然处于活动状态，APT小组在技术，战术和程序上进行了一些更改，但目标依然是是黎巴嫩。

在此活动中，通信逻辑中的一些证据似乎表明该APT组织可能入侵了属于黎巴嫩的Microsoft Exchange Server

这种新的Karkoff与过去活动中涉及的Karkoff样本有一些相似之处，包括：

*   相似的宏结构
    
*   具有类似逻辑的.NET模块
    
*   利用Microsoft Exchange Server作为通信渠道
    

此外，新的Karkoff实现了新的侦察逻辑，以便将最终的有效负载荷分配到特定目标，收集系统信息，域名，主机名和操作系统。

![](../Images/e987b5389f1659493b5a381f264fe5bd.png)总结

* * *

APT34仍然很活跃，这次针对黎巴嫩的活动证明了这一点。Karkoff恶意软件的新版本表明，与APT34网络间谍组织继续改善其武器库。此活动所涉及的示例实现了新的侦察功能，它通过使用Microsoft Exchange协议实现了隐蔽且有效的C2通信渠道。
