# 海莲花攻击手法概述

1攻击入口

  

海莲花组织通常采用鱼叉邮件的方式进行投递，附上恶意附件或者恶意链接。

  

2攻击方法

  

伪装成文档的可执行文件

使用伪装成普通文档文件的可执行文件进行伪装，例如Word或PDF文档等，导致用户误将文档文件执行。他们将文件的图标更改为文档程序的图标，或者在“.exe”可执行文件扩展名之前添加文档文件扩展名，例如“.doc”或“.pdf”。这会导致用户将文件误认为是文档文件。这些可执行文件通常以电子邮件附件的形式进行压缩和传递。

![](../Images/51ec1d41b1a5a95df3efdced250c9979.png)

  

伪装成正常程序

  

将恶意软件文件名更改为普通程序的文件名，例如Web浏览器安装文件（Firefox，Chrome）或Adobe Flash Web浏览器插件安装文件。此外，恶意软件通过伪装成仅在目标国家使用的正常程序来分发。

![](../Images/252e65d67e0ef4d1a8c17850ef1369a5.png)

可执行文件名后加长空格

使用“文件名后空格”技术使可执行文件看起来像普通文档文件。在“.exe”扩展名之前插入文档文件扩展名，例如“.doc”，“。docx”，并在中间插入许多空格。根据文件名字段的大小，由于空间较长，长“.exe”扩展名将不可见，用户可能会将可执行文件误解为文档文件。

![](../Images/3a4ae357bdf1863f29af2af68e3e1a5d.png)

RAR文档中包含恶意软件

主要以压缩档案的形式传递恶意软件，使用的压缩格式包括RAR，ZIP，GZIP，主要使用RAR压缩格式

![](../Images/4232c0fabacd3625b9ec365163d33ed8.png)

SFX自解压

使用SFX（自解压存档）自动运行压缩文件的恶意软件。他们利用WinRAR程序生成SFX压缩文件的能力，生成SFX自解压文件运行恶意软件

![](../Images/fb4a6de19a23dc2f72fed85f6e85fdb7.png)

![](../Images/bbbe7becffd4ded641603cfb8855fa95.png)

HTA恶意软件

使用HTA传播恶意软件。HTA代表Microsoft HTML应用程序，并使用“.hta”扩展名。典型的HTA文件配置类似于HTML文件，但是使用单独的实用程序“mshta.exe”运行，而不是像Internet Explorer一样的Web浏览器。通过在“.hta”文件中包含VBScript来传播恶意软件，并且VBScript释放嵌入式的恶意软件或下载其他恶意软件来工作。这里的优点是，由于安全控制，VBScript在Web浏览器中具有有限的权限，当通过HTA文件执行VBScript时，这些安全控制被绕过。

![](../Images/9171593302686d4bdd73ecc09e022de5.png)

![](../Images/5b11ab1933089768039de3ba7ed25d75.png)

LNK快捷方式

使用快捷方式（“.lnk”）文件来传播恶意软件。通过伪装看起来像word文档文件的图标和扩展名传递给目标。这样的LNK文件可以执行命令。使用“mshta.exe”运行LNK文件的VBScript代码。LNK文件释放正常的文档迷惑受害者，且悄悄从远程服务器下载恶意代码执行

![](../Images/ef1a4df85eb3bcaf56a6db34036bed46.png)

使用云服务器下载恶意软件

使用亚马逊的AWS S3和Dropbox云存储服务下载恶意软件，该链接通过电子邮件发送。  

宏利用样本

文档的文件名设置为目标可能感兴趣的内容，并将文档附加到其电子邮件中。如果恶意宏未运行，受害者将不会被感染，因此文档正文包含一种社交工程技术，以诱导用户激活宏。

![](../Images/8e648d150d1db5dc94b80994093234de.png)

![](../Images/04519a7172ac3729c776238e0b1ecb99.png)

MIME宏

包含传统恶意宏的Word文档文件更容易被安全解决方案（如防病毒和反垃圾邮件过滤器）检测到。为了绕过它，海莲花也使用ActiveMime格式。ActiveMime是一种未记录的Microsoft文件格式，用于对Microsoft Office中的宏进行编码。当您将包含宏的Microsoft Office文档转换为“.mht（Microsoft Web Archive）”格式时，该宏将包含在ActiveMime格式的“.mht”文件中。这些转换后的宏可以绕过安全解决方案，因为只有通过分析ActiveMime格式才能检测到它们。

将已转换为“.mht”文件格式的恶意文档的扩展名更改为“.doc”扩展名，并将其附加到电子邮件并将其传递给目标。

![](../Images/03f99fd3447921ede063cc14c5c237e4.png)

cve-2017-0199

CVE-2017-0199漏洞是由于Microsoft Office程序无法正确处理OLE对象而发生的漏洞。可以通过MS Office处理URL Moniker对象时发生的漏洞从远程服务器下载并执行HTA（HTML应用程序）等恶意文件。

使用CVE-2017-0199漏洞向目标提供包含恶意OLE2link对象的RTF文档。OLE2link对象下载包含要运行的Powershell命令的VBScript HTA文件。

cve-2017-8570

CVE-2017-8570漏洞是由于Microsoft Office程序无法正确处理OLE对象而发生的漏洞。此漏洞存在于MS Office处理Composite Moniker对象的方式中，并且可以执行OLE包中包含的SCT（Windows脚本组件）脚本。

使用CVE-2017-8570漏洞传递包含恶意“.sct”文件的RTF文档，该文件会向目标生成恶意软件。

![](../Images/97fa22f9d2dc0fde1955a9a5cdeaaca5.png)

CVE-2017-11882

CVE-2017-11882漏洞是在MS Office程序的一个组件公式编辑器（EQNEDT32.EXE）无法正确处理某些对象时发生的漏洞。当MS Office处理内存中的某些对象时，它可以通过漏洞执行任意代码。

海莲花通过发送带有shellcode的恶意RTF文档进行攻击

![](../Images/891502b3d1889f5671ada3a5bb92d5d6.png)

![](../Images/09b94a2ffad74e2f1a0ef19646c23212.png)

CVE-2018-20250

CVE-2018-20250漏洞发生在UNACEV2.dll中，它包含在压缩程序WinRAR中。这是一个漏洞，可以通过在ACE压缩格式的处理中操作文件名字段来生成特定路径中的文件。这允许攻击者在可以在系统引导时自动执行文件的路径中创建可执行文件。

由于许多威胁行动者团体开始使用CVE-2018-20250漏洞，海莲花组也做了同样的事情。

![](../Images/c649d141126b522585cc2a7b6b5fb29c.png)

水坑攻击

  

海莲花通过攻击反对越南政府的关键人员和活动家访问过的网站,并且袭击了政府，外交，国防和研究领域的网站，包括柬埔寨，中国，老挝和菲律宾，并攻击了与东盟相关的网站。

当目标访问特定网站时，攻击者会分发伪装成Web浏览器程序或插件的恶意软件，或显示伪造的登录页面以收集凭据数据。他们还创建了类似于普通网站或在线服务的域名，并将恶意脚本插入虚假域名网站以收集有关其目标的信息。

  

DLL劫持

海莲花更喜欢“DLL Side-Loading”技术来执行他们的恶意软件。DLL侧加载技术也称为“DLL劫持”

在Windows操作系统中加载DLL时，搜索顺序如下：

![](../Images/efb323d2a38b2bbe00fa8da8d6501b70.png)

因为DLL文件与可执行文件位于相同的目录路径中，所以加载该DLL，因为它具有最高优先级的负载。SectorF01组将合法文件和恶意DLL文件一起分发，以便它们位于同一路径中。这将在执行普通文件时将恶意DLL加载到一起。

这将使它看起来好像是由合法程序加载的DLL文件，这可以绕过检测执行基于行为的检测的端点安全解决方案。

SectorF01组已经分发了MS Windows操作系统文件或带有DLL的流行程序来加载其恶意DLL文件。在某些情况下，着名的反病毒软件的合法文件也用于加载恶意DLL。

SectorF01组非常喜欢“DLL Side-Loading”技术，以至于他们滥用了许多合法的程序。我们想知道有多少正常程序被利用，所以我们总结了我们发现的所有正常程序。
