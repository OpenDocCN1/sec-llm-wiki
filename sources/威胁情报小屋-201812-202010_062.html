  MuddyWater是疑似来自伊朗的APT组织，专注于中东（伊拉克，沙特阿拉伯，巴林，约旦，土耳其和黎巴嫩）的政府和电信目标，以及附近地区的一些其他国家（阿塞拜疆，巴基斯坦和阿富汗）。


    MuddyWater于2017年首次亮相，并一直活跃，针对众多组织。第一阶段感染和图形诱饵已被多种来源描述，包括在我们之前的研究中：“ MuddyWater扩展操作 ”（https://securelist.com/muddywater/88059/）

    然而，MuddyWater最初感染后发生的事情的全面细节以前没有公开过。MuddyWater攻击者部署了各种工具和技术，这些工具和技术主要由团队自己在Python，C＃和PowerShell中开发，以实现攻击并完成受害者渗透和数据泄露。此类工具的示例包括C＃和Python中的多个下载/执行工具和RAT，SSH Python脚本，用于提取凭据，历史记录等的多个Python工具。

    此报告详细说明了此威胁演员在初次感染后对其目标使用的工具集合。它还详述了一旦在受害系统内部署了攻击工具（例如中文字符串，俄语字符串和假冒“RXR沙特阿拉伯”黑客组织）后用于转移调查的欺骗性技术。

5.1
工具集

    在我们对MuddyWater活动的研究中，我们能够识别出这个演员使用的一些工具和脚本，从而很好地理解了这个演员的能力。使用的大多数工具都是定制开发的，其他工具则基于公开通用工具改写。

这些工具包括：


  • Nihay - C＃下载并执行工具

  • LisfonService - C＃RAT

  • Client.py - Python RAT

  • Client-win.py - SSH Python脚本

  • Rc.py/Rc.exe - 基本Python RAT

  • VBScript和VBA文件

  • 第三方脚本（Muddy，Losi Boomber，Slaver反向隧道...）

  • 第二阶段PowerShell脚本

    大多数这些工具都是用Python或PowerShell编写的脚本。我们注意到MuddyWater将各种令人反感的Python脚本编译成可执行文件以便于移植，使用Py2Exe和PyInstaller完成此任务。这包括Python脚本，如“CrackMapExec”，“shootback”和“Lazagne”。

    我们还注意到使用“PS2EXE”将PowerShell脚本转换为可执行文件，原始PowerShell代码嵌入为Base64编码的字符串。在其他情况下，我们注意到使用PowerShell Reflective DLL注入来部署Metasploit Stageless Meterpreters的偏好。它们使用32位和64位版本。通常，Stageless Meterpreter具有“Ext_server_stdapi.x64.dll”，“Ext_server_extapi.x64.dll”和“Ext_server_espia.x64.dll”扩展名。

Nihay c# downloader

    名为“Nihay”的工具（根据其Pdb）是一个用C＃编写的基本“下载并执行”木马。它从硬编码的URL下载PowerShell单行（例如，https：// beepaste [。] io / view / raw / pPCMo1）并将其传递给“cmd.exe / c”执行


LisfonService c#RAT

    LisfonService是一个非常类似于我们在之前的出版物中分析过的PowerShell RAT的RAT。LisfonService从隐藏真实C2服务器的大量硬编码代理URL中随机选择一个URL。它收集有关其受害者的一些基本信息：用户名，域或工作组名称，计算机名称，计算机内部IP地址，操作系统版本，操作系统版本和公共IP地址。成功注册受害者后，会将受害者ID分配给受害者，并在以后用于从C2请求命令，例如执行PowerShell代码或导致蓝屏。

    在反编译的C＃代码中，有一个名为“str1”的引用变量，实际上并未使用。我们认为它是早期测试阶段的残余，它可能是代理URL后面的C2的IP地址。

当到达此URL时，它会返回攻击者可能留给研究人员的有趣聊天

Client.Py python rat

Client.Py是我们认为是由MuddyWater开发的Python 3.6 RAT。它使用PyInstaller作为已编译的Python可执行文件部署在受害计算机上。执行流程如下：

  1. 收集有关受害者计算机的基本信息：计算机名称，操作系统名称，操作系统版本和用户名。然后它将信息发送到C2服务器192.64.86 [。] 174：8980。

  2. 它支持多个命令，其中一些命令是通过创建临时.VBS文件并通过调用cscript.exe来运行它来执行的。支持的命令允许RAT实现基本的键盘记录功能，窃取Chrome中保存的密码，查杀任务管理器，远程命令执行以及在消息框中显示受害者的警报消息。

client_win.py ssh python脚本

这个PyInstaller编译的Python脚本利用Python paramiko插件创建到其C2的SSH连接。

  1. 在端口8085上连接到C2的硬编码IP地址（例如104.237.233 [。] 38），发送字符串“ip”。然后它应该以“ip1 :: ip2 :: ip3”的形式接收IP列表。

  2. 然后该脚本连接到相同的硬编码IP地址，发送字符串“pw”，以便以“pw1 \ npw2 \ npw3”的形式从C2获取密码列表。

  3. 最后，它尝试使用在步骤1中获取的每个IP上接收的每个密码来验证SSH会话的硬编码用户名列表（例如“cisco”，“root”，“admin”）。

rc.py/rc.exe python RAT

这个UPX打包的可执行文件是PyInstaller编译的Python脚本（rc.py）。脚本接收其C2的IP地址作为参数，在硬编码端口9095上连接到它。

这个基本的RAT支持受害者系统上的一些命令来收集密码和远程命令执行。

  • “杀”自我终止。

  • “cd”用于更改当前目录。

  • “dopass”用于从Chrome，IE，Mozilla，Opera和Outlook获取凭据。

  • “info”提取有关受害者计算机的基本信息：操作系统名称/版本，32位/ 64位，处理器名称，用户名，计算机名称，计算机FQDN，内部IP地址，MAC地址和公共IP地址。

  • “shell”从C2接收文件并将它们保存在“C：\ ProgramData”中

  • “exec”产生了由C2确定的新过程。

  • 否则，调用cmd.exe / c以生成由C2确定的新进程。输出始终发送到C2。

归属

在我们对这个演员活动的分析中，我们发现了多个OPSEC错误并分析了它所使用的一些分心技术。在OPSEC错误中，在一些样本或从C2服务器收集的工件中留下了多个PDB文件路径。

龙和熊猫

名为“LisfonService”的.Net RAT具有将“dragon”和“Panda”称为用户名的PDB文件路径。



熊猫和龙可能被故意用于误导研究人员可能是一个中国演员，或者它可能只是攻击者喜欢引用自己的方式。值得一提的是，在一些PowerShell RAT中，攻击者还将 “$ dragon_middle”变量名称用于C2代理URL数组。

冒充其他组织

在另一个PowerShell中样品（MD5：e684aa1c6e51f4696a836ecb6ff1e143，文件名：km.ps1），攻击者建立与C2服务器的连接时使用俄词语作为RC4密钥（78.129.139 134 []）


此外，IP 78.129.139 [。] 134也用作其他样本的C2。有趣的是，在访问C2时，它显示一个空白网页，其HTML源代码显示一个奇怪的HTML标记值，表明攻击者试图冒充一个名为RXR沙特阿拉伯的沙特黑客组织。


5.1
结论

近年来，MuddyWater攻击在目标和恶意软件功能方面不断扩大。攻击者似乎已经为他们的目标提供了相当完善的装备，使用相对简单且可消耗的工具来渗透受害者并渗透数据，主要使用基于Python和PowerShell的工具。这些工具似乎也允许他们灵活地适应和定制受害者的工具集。

这种持续不断调整和加强攻击的能力，适应不断变化的中东地缘政治局面，似乎使这个演员成为一个不断发展的坚实对手。我们希望它继续开发或获得额外的工具和能力，可能包括零日。
