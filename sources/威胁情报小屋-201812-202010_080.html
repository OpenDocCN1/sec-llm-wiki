dropper


    dropper用于将后门安装到受感染的系统中并建立其持久性

    


    dropper中的所有字符串以及后门都使用硬编码的RSA256密钥加密。有两种形式的加密字符串：RSA256加密字符串，以及自定义base64编码和RSA256加密字符串。

    使用setStartup（）方法之前，dropper首先检查它是否以root身份运行。GET_PROCESSPATH和GET_PROCESSNAME方法将解密应安装后门的硬编码路径和文件名。不同用户对应路径如下

processname: screenassistantd

  • 对于普通用户

确定路径后，利用Loader :: installLoader方法，读取硬编码的64位Mach-O可执行文件（魔术值0xFEEDFACF），写入确定好的路径文件中。

    

    当dropper安装后门时，它将其属性设置为“hidden”，并使用touch命令将文件日期和时间设置为随机值：touch -t YYMMDDMM“/ path / filename”> / dev / null。然后访问权限将更改为0x1ed = 755，相当于u = rwx，go = rx。


    之后，将在/ Library / LaunchDaemons /或〜/ Library / LaunchAgents /文件夹中创建持久性文件。 RunAtLoad键将命令launchd在操作系统启动时运行守护程序，而KeepAlive键将命令launchd以使进程无限期运行。 此持久性文件也设置为隐藏随机生成的文件日期和时间。


launchctl load /Library/LaunchDaemons/filename.plist> / dev / nul或launchctl load~ / Library / LaunchAgents / filename.plist> / dev / nul然后命令操作系统在登录时启动释放的后门文件。dropprt将在流程结束时删除自己。

    当加扰一个字节时，加扰器首先确定字节值是奇数还是偶数。 如果该值为奇数，则将该字节以及一个随机生成的字节添加到该数组。 在偶数值的情况下，首先添加随机生成的字节，然后添加字节。 在上面的情况中，第三个参数是'1'= 0x31，这是一个奇数。 这意味着它将字节'1'和一个随机生成的字节添加到最终的加扰数组中。

    当加扰字符串时，加扰器生成一个5字节长的序列。首先，它生成一个随机字节，然后是三个零字节，一个随机字节，最后是字符串长度的字节。假设我们想要争夺字符串'Mac OSX 10.12'。其长度为13 = 0x0d，两个随机字节为0xf3和0x92。最后的5字节序列看起来像F3 00 00 00 92 0D。然后用5字节序列对原始字符串进行异或。


  1. 加密

    加扰的字节序列被传递到Packet :: Packet类的构造函数，该类创建一个随机的AES256密钥并使用此密钥加密缓冲区。

  1. 编码加密密钥

        为了使C＆C服务器解密加密数据，随机生成的AES256密钥必须与加密数据一起包含在数据包中。但是，该键也会被操作XOR 0x13加扰，然后对每个字节应用ROL 6操作。
