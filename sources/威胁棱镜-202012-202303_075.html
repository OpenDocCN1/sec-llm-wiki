工作来源

2020 IEEE Symposium Series on Computational Intelligence (SSCI)

工作背景

Yara 是在安全领域中被广泛使用的工具，近年也出现了自动生成 Yara 规则的工具，例如 yarGen、yaraGenerator 和 yabin。Yara 规则的成功取决于生成的 Yara 规则的有效性，取决于规则中 IoC 字符串。手动生成 Yara 规则需要特定安全领域的高度专业技能，而使用工具自动生成 Yara 规则对使用者的要求相对要求较低。

Yara 规则通常由元数据、字符串和条件三部分组成：

字符串有三种类型：文本字符串、十六进制字符串和正则表达式字符串。

  • 文本字符串：常见带有修饰符，如 nocase、ASCII、wide 和 fullword

  • 十六进制字符串：常见带有通配符（wild-cards）、跳转（jumps）与替换（alternatives）

  • 正则表达式字符串：自从 2.0 版本引入

yarGen

yarGen 由 Florian Roth 利用 Python 开发，利用模糊正则表达式、朴素贝叶斯分类器和乱码检测等技术生成 Yara 规则。字符串的数量是预定义的，通常最多 20 个。可根据恶意软件类型生成两种类型的规则：

  • 基本规则：针对特定的恶意软件

  • 高级规则：针对一组恶意软件/家族

优点：

  • 可以基于操作码和字符串生成 Yara 规则

  • 支持使用 PE 模块

  • 可以与其他反病毒软件集成使用

  • 查询数据库减少误报

缺点：

  • 需要再处理才能提高有效性

  • 需要大量资源用于处理操作码或查询数据库

  • 生成速度缓慢

  • 高级规则可能会重复和冗余

  • 需要安装所有依赖和数据库

yaraGenerator

yaraGenerator 由 Chris Clark 利用 Python 开发，利用字符串优先级与代码重构技术生成 Yara 规则。它也提供了基于不同文件格式的 3 万个黑名单字符串，用于减少误报。

优点：

  • 可以针对特定文件格式生成规则

  • 支持 PE 模块

  • 利用黑名单数据库减少误报

缺点：

  • 需要再处理才能提高有效性

  • 随机选择的字符串可能并不是最合适的字符串

  • 不支持操作码

  • 已经不再更新

yabin

yabin 由 Alien Vault Open Threat Exchange (OTX) 利用 Python 开发，利用罕见函数生成 Yara 规则，例如 55 8B EC 在 Microsoft Visual Studio 编译的程序中指定函数的开始。从超过 100G 的恶意软件中提取的常见函数的白名单，用以减少误报。

优点：

  • 可根据代码重用进行聚类

  • 可扩展检索模式

  • 提供常见库函数白名单

缺点：

  • 需要再处理才能提高有效性

  • 不适用于特定文件格式

  • 只匹配函数，不匹配其他类型的字符串

  • 只能处理脱壳的可执行文件

  • 不是为处理 .NET\Java\Office 文档文件设计的

  • 为了测试而不是实际生产使用

工作设计

使用模糊哈希可以将文件分成几个块，每个块单独计算哈希再拼接起来，块大小、文件大小和所选哈希函数的输出大小都会影响模糊哈希的结果。主要分为几种类型：上下文触发分段哈希（CTPH）、统计不可能哈希（SIF）、基于块的哈希（BBH）和基于块的重建（BBR）。

如果发现命中的字符串较少，则不会被判定为匹配。大量增加字符串会增加命中率，但引入了计算复杂度和额外的性能开销。利用模糊哈希提供文件间相似度的对比，增强 Yara 的检测能力。

工作准备

准备了勒索软件和良性软件进行效能评估，恶意软件包括 WannaCry/WannaCryptor、Locky、Cerber 和 CryptoWall 四个家族的数千个样本。VirusTotal 上至少四十个引擎判断为恶意软件，且进行了手动验证确认剩下一千个样本，四个家族平分。

而良性软件包括 JAVA、MS OFFICE、Google Chrome、MySQL、R、NMAP、McAFee、MATLAB、Python 和 Snort 共计两千个样本。

工作思考

Yara 为安全分析人员提供了一种极为便捷的方式来编写自定义处理规则，跨平台且支持多种接口。但如果只是字符串来进行匹配，攻击者容易进行检测逃避，这会降低有效性。需要安全分析人员站在更高的维度对恶意样本提炼特征，进行匹配才能更好地进行检测发现。自动生成的规则效果可能并不尽如人意，但仍然可以作为简便方法减轻人工分析的负担。

几种工具的检测方法都有颇有启发性，作者本身使用 ssdeep 结合 Yara 进行提升反而好像十分刻意，感兴趣可以查看原文的参考文献进一步阅读其他分析结果。在性能和效果之间的权衡和取舍始终是核心问题，在不同的应用场景下也会有不同的取舍侧重，不能一刀切。
