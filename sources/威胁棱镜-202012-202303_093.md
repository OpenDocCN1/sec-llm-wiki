# 工作来源

17th China Annual Conference, CNCERT 2020  

## 工作背景

与 2018 年相比，2019 年超过 300 Gbps 的超大规模 DDoS 攻击增加了 200 多倍。活跃的僵尸网络家族也聚焦在物联网设备上，包括 Gafgyt 和 Mirai 在内都瞄准了海量的物联网设备。NSFOCUS 在 2019 年发现了 60 个 DDoS 攻击团伙，多达 15 个攻击团伙掌握的攻击资源超过 1000 个，最大的攻击团伙掌握 88000 个攻击资源。其中物联网设备所占比例最高可达 31%。本文根据僵尸网络的控制指令传播日志和威胁情报数据对 DDoS 攻击团伙进行分析。此前的研究包括《*DDoS attack gang analysis method based on network attack accompanying behavior*》、《*Network security situation analysis based on malicious code propagation log*》以及《*Detection of IP Gangs: Strategically Organized Bots*》等。现有的 DDoS 攻击团伙分析主要侧重于攻击资源、在海量数据中发现社区。基于攻击资源行为的团伙分析有两个缺点：

*   攻击行为数据的检测精度问题。DDoS 始终伴随着正常用户行为，而其中一些行为很难进行区分  
    
*   数据统一问题。基于攻击资源行为的团伙分析通常源于攻击资源的大规模行为相似和社区结构，对规模较小的缺乏关联证据

因此，为了发现 DDoS 攻击团伙，不仅有必要在行为级别执行聚类，还要将攻击资源的控制消息和相关样本/域名都结合在一起使用。

据此本文提出了基于复杂图的 DDoS 攻击团伙发现框架 DDoSAGD。实体和关系从僵尸网络控制消息和僵尸网络相关的威胁情报中提取，构建的基础异构图包含 DDoS 行为关系和情报关联关系。然后以 C&C 服务器作为关键实体，设置一系列元路径，并基于元路径相似性度来计算 C&C 服务器之间的相关性，建立 C&C 服务器之间的相似性关系。形成以 C&C 服务器为节点、以相似性为关系的同态图（Homomorphic Graph）。然后结合图挖掘来构建分层社区发现算法，该算法可以发现具有基于行为的相似性和基于证据相关性的攻击团伙。

## 工作基础

数据集包括 2018 年 1 月至 2019 年 12 月的僵尸网络控制消息日志。僵尸网络控制消息日志包含 C&C 服务器、僵尸网络家族、肉鸡列表、攻击目标信息和攻击时间。

数据集的准备包括数据导入、威胁情报关联和数据存储/计算：

*   数据导入：数据来自 CNCERT/CC 提供的数据集
*   威胁情报关联：从僵尸网络控制消息中提取网络实体，并从各种外部威胁情报来源和数据来源查询相关情报信息（包括相关域名和样本）
*   数据存储/计算：数据存储于 Hadoop、计算利用 Spark

数据集包含 5225 个 C&C 服务器对僵尸网络肉鸡的 3005888 条控制消息。僵尸网络控制消息的整体月度趋势如下图所示：

## 工作设计

DDoS 攻击团伙发现框架 DDoSAGD 主要包含三部分：构建异构图、相关性测量和社区发现。

### 构建异构图

一共涉及七类实体，事件实体是根据攻击目标和时间特征提取而来，根据经验判断时间范围通常不超过 24 小时。七类实体之间形成三种不同类型的关系：行为关系、关联关系和相关关系。

![](../Images/dda97975318b5056c873a216e168a058.png)

### 基于元路径的相似性判断

DDoS 攻击团伙发现主要是根据相关关系对关键实体进行聚类。具体来说，两个实体之间的相关关系是通过异构图中基于元路径相似计算的。下图列出了为 DDoS 攻击场景构建的异构图模型中的异构关系：包括行为关系和相关关系。

![](../Images/0778b5addf9df10e4bfac01a5119387f.png)

考虑到多跃点相似性，下图显示了 K 跃点的示例（橙色圆圈表示实体、绿色圆圈表示 1 跳实体、蓝色圆圈表示 2 跳实体、紫色圆圈表示 3 跳实体）。

![](../Images/63e55f9759b76855f27e8da679152674.png)

例如 C2-C2@SIM\[DOMAIN\] 表示基于关联域名的 C&C 服务器与其 2 跳实体之间的关联关系，而 C2-C2@SIM\[MD5\] 表示 C&C 服务器与其 3 跳实体之间的关联关系，该关系基于关联样本的相似性。最后，C2-C2@SIM\[PDB\] 表示 C&C 服务器与其 4 跳实体之间的关联关系。此关系基于两种类型的关联关系，即与 C&C 服务器关联的恶意样本和与样本关联的 PDB 路径。

![](../Images/f88a05649e06168643ceb98eba74997e.png)

根据相关关系，我们确定两个关键实体是否属于同一攻击团伙。如果与两个 C&C 服务器相关的实体数大于 n，或者 Jaccard 的相似性大于 t，即可判断是相关的。true 表示两个 C&C 服务器是相关的，而 false 表示无关。再利用关注机制聚合多维关联关系，因为计算 C&C 服务器之间的相似性时，不同类型的关联关系并不同等重要，需要配给权重。

![](../Images/36dcb45bd4e3435024104a1f2c85a533.png)

### 社区发现

相似判断的逻辑主要立足于：

*   基于行为的相似性：特定团伙中的攻击者在大规模攻击行为中应具有相似性，例如，在特定时间段肉鸡应由同一组 C&C 服务器控制、肉鸡或 C&C 服务器应参与同一组攻击事件
*   基于证据的相关性：基于证据的相关性是为了从具有高度可信的小规模关系中提取相关性。例如，在特定时间段中，两个 C&C 服务器都解析到相同的域名、两个 C&C 服务器具有来自相同恶意软件样本的网络连接或具有高度相似性的恶意软件样本

没有一种方法能够同时捕获大规模行为相似和小规模特征相似，故而分为三步进行处理。

![](../Images/9f5f3905122d562a2faa1bbf66bb54bd.png)

首先使用 Louvain 算法根据 C&C 服务器的行为相似发现团伙，将会得到一个社区发现结果。其次，通过强有力的证据将 C&C 服务器上运行 Connected Component 算法将图拆解为多个 Component 中，其中任何两个顶点都通过路径相互连接，并且这些顶点不连接到图中其他顶点。最后，合并重叠的 Louvain 社区和 Component 的结果。如果社区和 Component 具有相同的 C&C 顶点，将合并到一组中。

## 工作思考

随着万物互联时代的到来，僵尸网络也利用越来越多的网联设备发起更大规模的攻击。DDoS 攻击规模每年都会刷新记录，攻击者控制的肉鸡数量也在快速增长。DDoS 攻击团伙发现是站在更高的视角下对多种数据（控制信息、威胁情报等）进行深入挖掘而来，为 DDoS 攻击监测和演变分析提供了一个除家族外更大的数据视野。

与此同时，我们也必须看到：传统的僵尸网络 Mriai、Gafgyt 和新兴僵尸网络 Mozi、BigViktor 此消彼长，攻击者也在向高对抗转变，比如僵尸网络家族由传统中心式控制结构向 P2P 控制结构转变，加大了僵尸网络整体的隐蔽性和对抗性，提高了监测难度。随着数字货币价格一路走高，僵尸网络除了传统的 DDoS 攻击外也利用掌握的大量主机进行挖矿获益，有些还与勒索软件相互勾连，形成更为精细化的攻击链条。

由于网络犯罪所带来的威胁越来越大，安全公司与执法机构开始对一些较大规模的犯罪组织（如 Emotet、Trickbot 等）进行定点精准清除。攻击团伙的识别在未来也许可以配合跨国行动对犯罪组织进行铲除，或者关停控制服务器、摧毁控制网络，这也有利于营造风清气正的网络空间、筑牢网络安全防线。
