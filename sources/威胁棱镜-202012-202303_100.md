# 通过 ATT&CK 归因攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyMzE5ODExNQ==&mid=2247483693&idx=1&sn=08fb974c385ea1afd6c16d4ff5572f8d&chksm=c1e9f6e1f69e7ff73bafb39f297e9df44e02b9e4e43d6b66b6bd71f597b49ed8ebe1ff0ee062&scene=126&sessionid=1681278728#rd](http://mp.weixin.qq.com/s?__biz=MzkyMzE5ODExNQ==&mid=2247483693&idx=1&sn=08fb974c385ea1afd6c16d4ff5572f8d&chksm=c1e9f6e1f69e7ff73bafb39f297e9df44e02b9e4e43d6b66b6bd71f597b49ed8ebe1ff0ee062&scene=126&sessionid=1681278728#rd)

某公司的安全团队发现了恶意 C&C 流量后，邀请趋势科技的团队分析入侵行为。为调查研究提供了数量有限的设备和数据的访问权限，包括日志、硬盘和内存镜像。但由于缺乏 EDR、XDR 等解决方案，未能完整收集所有的样本和攻击数据，这限制了调查团队进行攻击分析。

**初步分析**

对日志的分析发现攻击者已经入侵了 62 台计算机（10 台服务器、13 台计算机植入了文件收集与数据泄露的恶意软件、22 台计算机植入了后门、其余计算机植入了其他工具与加载恶意软件使用的合法软件）。

![](../Images/173534dd7557d8e0287e9cedfd99a961.png)

攻击者可利用后门调用 cmd.exe 执行命令。而 ProcDump 和 Mimikatz 等工具用于获取用户帐户，还有网络扫描工具被用来查找其他目标机器。创建计划任务或使用 wmic process create 命令来远程删除可执行文件。在某些情况下，也会删除后门的副本。  

  

攻击者主要收集诸如 PDF 和 Microsoft Office 之类的文档文件。此外，根据这些恶意文件的时间戳和内网中扩散的程度，攻击可能已经隐藏了很多年。我们使用 MITER ATT&CK 分析发现的文件与工具，所有这些技术都与 APT32 匹配。

![](../Images/8826f52a5b8b90ae67d7e74d5a07e00e.png)

根据已有数据，观察到的技术项与 MITRE ATT&CK 中 APT 32 基本一致。但也发现了一些出入，有四种技术无法关联上。如果从这个角度看，该攻击与 APT 3 更为匹配，只有三种技术无法与 APT 3 关联上。

![](../Images/315d9c2a5956b678560be8d501f7da83.png)

**进一步分析**

考虑到有两个组织与观测到的技术匹配，需要进一步深入分析。分析团队选取了安装恶意软件最多的五台计算机，提取了磁盘映像和相关文件进行分析

**数据泄露工具**

分析发现了六种类型的数据泄露工具，每个都能独立运行。这些工具可以从各种位置收集所需文件，并将文件发送出去。

*   TSPY\_PILFERDOC.ZBGK。该工具收集文件并压缩到硬编码密码加密的 RAR 文件中，随后删除所有收集的文件
    
*   TSPY\_KARYAL.ZAGK。该工具将自己收集的文件或者其他工具收集的文件通过网络发送走，它会为每个文件创建一个线程发送文件。还会发送包括计算机名称与用户名在内的元数据，所有数据都异或加密
    
*   HKTL\_FILEDOWNLD。该工具下载指定的文件到本地
    
*   PowerShell 数据库工具。该工具查询 MySQL 数据库，将结果写入 CSV 文件中
    
*   HKTL\_FTPEXFIL。该工具将文件路径写入文本文件并复制到临时目录中，临时目录名基于系统日期。文件使用 7-ZIP 进行压缩，并使用简单的异或密钥加密。最后使用 FTP 发送出去
    
*   BKDR\_NULTUS.ZCGK。该工具位于启动文件夹中，而且很难进行逆向工程。该工具功能与 TSPY\_PILFERDOC.ZBGK 类似，而且编写方法明显不同，推测是攻击者使用的新工具
    

**后门**

后门包括横向移动和收集用户账户等功能，一共发现了六个后门。

**BKDR\_HANNOTOG**

该后门使用 cmd.exe 执行从远程网站接收的命令，执行结果从管道中读取后再加密发回去。但并不包含持久化功能，收到命令就创建在特定时间执行一次的计划任务。一共有三种变体：x86 可执行文件、反射加载资源中内嵌的 DLL 文件的 x64 版本以及硬编码 C&C 地址的 x86 版本。

![](../Images/e850201cdef14f1ff9a1bd01fecb4c21.png)

**TROJ\_SHELLLOAD**

该后门反射加载另一个二进制文件。使用管理员账户映射 IPC$ 共享，而且使用 wmic 进行远程执行。

![](../Images/94f98aae501628bc3575a008bbc1d8f8.png)

**TROJ\_QUASLOAD.ZBGK**

该后门用于加载和执行二进制文件（QUASAR 木马）。此外，还可以收集编译和压缩的文件。虽然 TROJ\_QUASLOAD.ZBGK 与 TROJ\_SHELLLOAD 用不同的语言编写，但二者在内存中加载二进制文件的方式是相似的。

![](../Images/c5e6837a48a5eaf786683582d1a904ee.png)

**Backdoor4**

该后门可以用作 Dropper，也可以删除和执行其他二进制文件。

![](../Images/badc018aa57a490a4476241f710a584a.png)

**Web shell**

该公司部署了 Apache 服务器，攻击者也针对性地部署了 Webshell。

![](../Images/04bdb655d557859911a0819f8adfc469.png)

**BKDR\_XRAT.ZCHB**

该后门为 .NET 开发的后门，作为服务安装进计算机。该后门不必加载二进制文件就能单独工作，而且使用的是 XRAT 的 2.0 版本。

![](../Images/735d4d44e33279d183684a1aeb25accc.png)

**其他工具**

*   TROJ\_CHINOXY.ZAGK。该工具会删除合法文件与恶意 DLL 文件，存在启动文件夹进行持久化
    
*   侧加载 DLL。
    
*   Procdump。用于转存 LSASS 的内存
    
*   Mimikatz。该工具经常与 Prodump 一同使用
    
*   HackTool.Win32.NBTScam.A。该工具用于打开共享

**更新技术项**

通过进一步的研究，发现了最初没有发现的技术和工具。

![](../Images/eb3e2fdcb5ff187f043f1acccedf8eb7.png)

这些后门的基本逻辑是类似的，但是编写和使用的方式却是不同的。

*   BKDR\_HANNOTOG 不具备持久化能力，但 TROJ\_SHELLLOAD 可以持久化
    
*   BKDR\_XRAT.ZCHB 与 TROJ\_QUASLOAD.ZBGK 是 .NET 写的，但 BKDR\_HANNOTOG 是 C 写的
    
*   TROJ\_SHELLLOAD 使用了 WMIC 而其他后门没有使用
    
*   使用管理员共享的方式各不相同

第二组的 TTP 与海莲花有关：

![](../Images/13f30af018b383f8363b798c626466b4.png)

**归因**

在已识别的四组工具链中，其中两个与 Lotus Blossom 和海莲花高度相关。入侵工具集 1 与简体中文有关联，入侵工具集 2 未能归因给任何组织。在其他所有入侵工具集中都存在海莲花常用的技术。

通过将检索到的恶意软件与已知的 APT 恶意软件进行比较，以及根据恶意软件之间的关系对恶意软件进行聚类，范围缩小到了两组嫌疑人。必须指出的是，没有任何一种技术是具有排他性的，任何组织都有可能在任何时间点使用。分析团队尽可能地通过痕迹与行事风格发现关联关系，但不排除受到 False Flag 的影响。

**结论**

在研究入侵事件时，调查团队应该从宏观角度看待整个环境中发生的问题。由于攻击可能跨多个二进制文件和设备进行传播，因此查找恶意软件之间的关系将使分析人员能够更好地了解攻击及其详细信息。查找这些关联，对提供网络中所发生情况以及任何可疑进程的可见性都将大有帮助。攻击者的许多工具都利用了公司的内部系统和软件（例如文档管理系统）以及 MySQL 后端数据库等。分析团队最后将这次攻击归因于这两个组织，想要了解调查的全部技术细节和分析，请下载研究报告。
