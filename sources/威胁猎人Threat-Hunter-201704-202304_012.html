再获认可！威胁猎人入选IDC 2022年中国API安全领域推荐厂商

近日，全球权威咨询机构IDC发布《中国API安全市场洞察，2022》(下称《报告》)，威胁猎人凭借API安全管控平台的突出表现，成功入选IDC2022年中国API安全领域推荐厂商。

《报告》针对2022年中国API安全市场进行了深度调研，挑选出具有代表性的API安全产品，为最终用户在产品选型时提供技术参考。



数字化浪潮席卷而来，企业业务涉及的 API 数量激增，API 作为应用程序、数据流动和使用的桥梁，关乎企业业务核心逻辑及数据安全，其承载的巨大数据商业价值被众多恶意攻击者所觊觎。


全球范围内由API攻击导致的数据安全事件层出不穷，也让越来越多的企业意识到，做好API安全是保障数据应用安全、业务安全，实现数字化创新与发展至关重要的一步。


然而，传统在Web应用安全网关等产品中的API防护功能无法实现对API资产的动态梳理及风险管理，难以应对日益复杂的API攻击，现阶段API架构的安全建设亟待加强。


IDC《报告》中指出，总体来看，最终用户面临的 API 安全防护困境主要集中在API 资产梳理不全面、不准确、开发过程中的API 测试能力较弱、安全配置错误、身份认证与权限管控失误、加密失败、运行过程中持续的检测监测难、API 安全意识薄弱等问题。


作为深耕业务安全多年的安全厂商，威胁猎人很早就关注API安全问题。


为更好地帮助企业应对API安全挑战，满足用户需求，威胁猎人推出以“情报”为基础构建业务风险基线的API安全管控平台，通过全自动化的API资产识别能力和高精准的API风险监测能力，帮助企业快速、有效发现、治理在数字化过程中存在的大量API风险问题，保障其在线业务健康发展。



向新而行，步履不停，威胁猎人一直致力于API安全领域的创新与发展。


2022年，威胁猎人凭借在API安全领域的优秀表现，实力入选IDC「API安全」技术推荐厂商、成为首批通过中国信通院API安全能力“先进级”认证的企业.....多项成果也充分证明了威胁猎人在API安全领域的研发及创新实力。


目前，威胁猎人「API安全管控平台」已陆续在银行、证券、保险、互联网、政务等行业落地实践，并得到了众多头部客户的一致认可。


未来，威胁猎人将在情报技术、API安全产品上不断创新，以覆盖更多场景、为用户提供标准化服务为方向，切实帮助用户解决更多安全问题。



2023年1月5日，永安在线进行品牌焕新，正式更名为“威胁猎人”（详见：成立6周年，威胁猎人焕新回归）。
