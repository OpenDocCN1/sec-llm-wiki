# 2022年，永安在线API安全能力步入3.0版本

数字化时代，通过API流通数据来创造价值成为企业创新发展的关键，然而由于API管控不当导致数据泄露、恶意攻击等事件接二连三发生，**Gartner等权威机构指出，API作为企业数字化转型的重要基础设施已逐渐成为攻击者的主要攻击目标。**面对更加多元化的安全需求，**如API资产自动化梳理、数据泄漏风险感知和溯源、数据出境合规、账号行为审计、营销反欺诈等**，永安在线在API安全管控平台的**产品功能、运营能力、应用场景**等方面投入了大量研发力量。在不断迭代与创新下，**永安在线API安全能力正式步入3.0大版本**：  

![](../Images/6771ccda5f592ef0c0a1c9ea4c21ebe6.png)

  

**四大核心能力升级**

![](../Images/104802efaa2ae811d08cf01dd9f16a5e.png)

**API资产识别**

为解决企业技术发展中存在的API多协议类型，永安在线3.0版本API资产识别引擎基于图模型专利技术以及永安在线每日数亿的情报数据能力，可支持**Restful、GraphQL、Soap、Dubbo、Xml-RPC、Json-RPC**等多种主流API协议的资产梳理；

同时，为解决攻击者**利用非自研的系统和组件的API风险**来进行攻击，**3.0版本支持130余种常用组件的识别**，如**SpringBoot Acuator、XXL-JOB**，能及时对组件关联API的有效梳理，保障API资产识别的有效性和全面性。

截至目前，API资产识别率可达**97.8%**。

![](../Images/582cefb0dd7098364f6f6f83ef1cc74e.png)

**敏感数据识别**

***1*****.****数据地图**

为了清晰、全面地感知数据资产在流转过程中的实际应用情况及可能存在的风险，3.0版本上线了“**数据地图**”功能，**从数据和站点的维度对敏感数据的分布与调用趋势进行可视化展示。**通过数据地图可以观测到**当前企业存在哪些涉敏数据及其聚集分布的站点情况，从而对自身流动数据资产分布有全面的认知**：![](../Images/4b8d7be8a61d3598b62665a6589cbc61.png)

***2.*****数据出境合规自审**

《数据出境安全评估办法》于2022年9月1日起正式实施，明确规定了四种需要企业向网信部门申报数据出境安全评估的情形，这就**要求企业对自身出境数据有全面、动态的管理**。为此，3.0版本上线了**“数据出境合规自查”**，模块能力对标以上《办法》要求，**支持对不同业务的境外涉敏请求流量进行审计与记录**，评估出境的数据资产是否存在出境风险；**即使业务分布在多个云上或不同数据中心，也可通过分布式部署方案实现全面的出境数据资产评估。**![](../Images/b5f92ef167212f8b9a41fc9629d0beca.png)

**API缺陷检测**

永安在线基于代理蜜罐最新的漏洞攻防情报分析发现，有大量API因存在涉敏信息未脱敏、返回敏感数据类型过多等缺陷而被攻击者利用以窃取敏感数据；也有不少攻击者利用非自研系统或第三方组件存在漏洞而发起攻击。

为此，3.0版本的API缺陷检测引擎**新增了多种敏感数据传输、组件配置类的缺陷检测规则**，包括关键涉敏数据未脱敏、返回敏感数据类型过多、Airflow未授权访问、Clickhouse未授权访问等。

至此，**支持检测的API缺陷类型达到64种**。![](../Images/092fa2b0c07c414e57e6867c9b09f7cf.png)

此外，3.0版本实现了**自动化缺陷修复状态判定**，实现缺陷闭环处理，提升安全运营效率。

![](../Images/69bdf015fde2c2714b9f290315a56c37.png)

**API风险感知**

基于永安在线的攻防情报研究，越来越多的攻击者在攻防对抗中通过动态IP、API的逻辑组合等方式，伪装成正常的流量请求，对API进行低频、慢速攻击，可绕过传统的风险检测规则和模型。

为此，3.0版本对API风险判定模型进行全面优化，结合永安在线情报监测到的攻击者使用资源，如IP、工具、账号、邮箱等风险情报，构建API访问安全基线，可及时、有效地感知**恶意注册、扫号攻击、撞库攻击、营销欺诈、数据爬取、短信轰炸、敏感API境外访问**等场景的API风险事件；尤其**能解决黑产利用海量小号、秒拨代理IP发起的低频、慢速、无特征的扫号撞库、数据爬取、营销欺诈行为**，识别准确率**不低于95%**。

![](../Images/aba4fa9efb1b81ccc5a6ed133dff6e22.png)

2022年，永安在线API安全管控平台已成功帮助多个客户发现并及时处置了薅羊毛、话费充值洗钱、数据恶意爬取的业务攻击。

  

**三大重要功能上线**

![](../Images/df150f95024c9527625469ce9c81c9f8.png)

**账号资产管理及风险识别**

随着企业内部流程数字化，数据的传输从原先基于文件共享到通过系统API来完成访问，如何做好员工的数据访问行为审计，**避免员工违规操作泄露数据或者“内鬼”通过API批量窃取数据，**是企业在数字化发展过程中信息安全建设的重要环节。

为此，3.0大版本上线了“**账号资产管理**”和“**账号风险识别**”功能，支持按照自定义或预定义模型从登录流量中提取账号信息、账号凭证等关键信息，**建立账号调用关系视图**，可支持在不同登录模式下提取账号资产，包含但不限于SSO统一登录模式、独立系统登录模式、混合登录模式等。

可从账号的终端型号、使用地点、使用时间、数据获取行为、访问行为、登录行为等多个维度进行UEBA分析，**支持9种账号风险类型的识别**，能有效帮助客户应对**账号共用、账号借用、账号盗用、内部人员数据访问等**各种类型的账号风险。

永安在线通过这一功能成功帮助某金融客户监测到**贷后外包人员违规获取敏感数据的风险**，帮助某互联网客户识别出了**VIP账号多人共用的业务风险**。

**IP资产管理及风险识别**

根据永安在线情报信息显示，有大量的API攻击都是攻击者利用低成本的代理IP实现的，攻击者通过大量的动态代理IP，伪装成正常的请求流量，低频攻击API接口。**如何能及时有效地应对IP风险是API攻击风险识别的重要环节**。

3.0大版本支持从流量中提取访问IP作为IP资产，并从攻击者使用的IP的行为特征、数据访问特征、地理位置特征、情报特征等维度进行关联分析，**支持11种IP风险类型、90+漏洞扫描行为特征以及60+漏洞扫描成功行为特征的识别，**能有效帮助客户应对各类IP风险。

永安在线通过这一功能，在2022年网络攻防演练中，帮助某政企客户第一时间**识别出Ueditor XSS注入攻击**，并协助其对攻击行为进行处理，避免了防守失分。

**溯源审计**

国家推出的多个网络安全法规明确要求企业要具备对安全事件的溯源能力。但当下很多企业针对API攻击造成的数据泄漏溯源缺乏统一、全面的日志记录，且溯源验证过程需跨部门、跨业务协同，成本高。

因此，3.0大版本上线**“溯源审计”**功能，可对全流量进行账号识别、涉敏数据识别，并提取关联账号、涉敏数据类型、原始数据等关键信息**以完善审计日志**，满足客户从账号调用、数据获取等不同维度的数据审计需求。

此外，可根据客户提供的多条涉敏原始数据样本，从账号、IP、时间、API等多个维度进行聚合分析，帮助客户**从账号异常行为及数据泄露情况还原整个攻击过程**，从而有针对性地进行事件处置。

  

**运营能力逐步提升**

为提升广大客户API安全运营效率，API安全管控平台3.0版本增加了**自定义配置、风险事件同步、联动处置等**功能：

***1.*****自定义配置**

平台支持涉敏数据自定义、缺陷引擎自定义、风险引擎自定义、资产分级分类自定义，客户可根据业务实际情况进行配置。![](../Images/df4b881e8d9e6b1f943450a01c446f87.png)

***2.*****安全事件同步**

平台支持通过kafka、syslog方式将安全事件同步给第三方SOC或者工单系统，真正将API安全纳入企业的日常安全运营管理工作。

***3.*****事件联动处置**

平台支持与第三方安全设备对接，对风险IP进行及时封堵拦截，且支持对封禁任务进行实时管理及信息同步，缩短处置时长。

  

**适配多种业务环境**

永安在线关注到有不少企业存在**混合云、多数据中心**等业务场景，有较大的流量以及较高的API每秒并发量，当下基于流量汇聚的方式难以实现实时、精准的风险判定。针对这部分企业的需求，3.0版本提供**“单一管理中心+多分析节点”的分布式部署方案**。企业可通过部署多个分析节点采集和解析业务流量，再传入管理中心（中心节点）进行分析与展示。由于各分析节点**采用基于情报的风险判定引擎**，可独立完成情报信息同步和更新，并直接根据情报信息完成风险判定，**不会因流量分布在多个节点而导致风险漏判或误判，风险判定更及时、更精准。**

![](../Images/673756071d7b3420edc88b9b62ade81e.png)

此外，**3.0版本支持多种数据源接入，旁路部署对业务零干扰**。从设备性能来看，单设备最大处理能力可达到**网络流量40Gbps**，**http请求20000qps**，能满足各种业务场景下的流量支撑。![](../Images/93b562db0fec9950f7f28e46722cde27.png)2022年，永安在线API安全管控平台已成功在**互联网、金融、政务、制造、医疗等**行业落地应用，并获得客户的高度认可：![](../Images/85faf1c48b377824c9c49814974c5c21.png)

未来，永安在线将持续通过技术创新和能力迭代，给客户带去更有效、更便捷的API安全管理体验，让客户在API安全建设之路上摆脱低效的投入，从而有更多的精力投入到业务创新。
