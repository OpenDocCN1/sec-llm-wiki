![](../Images/6098c18c027c1e77fc1958ed006137e2.png)3月31日，安全牛《中国网络安全行业全景图（第九版）》发布，**永安在线入选业务与应用安全细分领域，包括 API 安全、支付安全、欺诈检测和识别等均榜上有名。**

安全牛《中国网络安全行业全景图》基于对国内安全行业的调研和积累，对我国网络安全产业整体发展状况及细分领域代表性厂商进行展现，自2016年首次发布以来受到行业广泛关注。**此次入选《中国网络安全行业全景图》代表着业界对永安在线在 API 安全、业务反欺诈等领域的专业认可。**  

**作为长期专注于业务反欺诈和 API 数据安全解决方案输出的安全厂商**，永安在线始终紧跟趋势、关注客户需求，不断迭代和优化产品能力，力求为客户提供极致的安全体验。

2021年，在意识到 API 广泛应用及安全策略缺失对企业业务安全造成越发严重的影响，**永安在线基于过去在安全情报的技术和经验沉淀，于2021年底正式对外推出新一代 API 安全管控平台。**

  

**基于情报的新一代API安全管控平台**

**新一代 API 安全管控平台通过旁路镜像的方式提供 API 资产梳理、敏感数据管理、API 风险感知、API 安全缺陷评估等多方面能力**，帮助企业构建**可预防、可解释、可溯源**的 API 安全管理体系，让企业能够有效实现对 API 资产的全面盘点、防止敏感数据暴露、预防和发现阻断 API 遭受攻击、提升风险事件的响应速度以及数据合规自查。![](../Images/46b8eb3ce2883161651031d6a5a9271c.png)同时，**新一代 API 安全管控平台通过情报为业务建立 API 安全基线，可实现误判率低、可用性高、及时全面感知企业外部 API 风险，**并基于精准预警输出的攻击者 IOC 情报，支持联动 WAF 或风控系统等快速处置攻击风险，帮助企业实现更好的进行 API 风险识别及阻断。![](../Images/73484e275f81082dd97dc83b748ff269.png)**目前，新一代 API 安全管控平台已陆续在金融行业多家企业试点，并获得客户的一致认可。**未来，永安在线将继续发挥黑灰产情报能力和攻防技术优势，持续以技术创新为驱动，不断提升产品研发、服务能力及管理水平，全面保障企业每一个 API 的安全运行。
