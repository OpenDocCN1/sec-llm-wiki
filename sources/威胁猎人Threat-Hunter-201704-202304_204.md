# 「动态」反欺诈技术为企业护航增长！永安在线受邀出席2019年度企业圆桌会议

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NDY3NDUxNg==&mid=2247485430&idx=1&sn=0f7485cdf1e3ea94c1af937d18645ac7&chksm=eb1121cddc66a8db519267c1b026ca5f2129156a33bdf08471a5ec95f39d06b74059a6476b6b&scene=126&sessionid=1681278844#rd](http://mp.weixin.qq.com/s?__biz=MzI3NDY3NDUxNg==&mid=2247485430&idx=1&sn=0f7485cdf1e3ea94c1af937d18645ac7&chksm=eb1121cddc66a8db519267c1b026ca5f2129156a33bdf08471a5ec95f39d06b74059a6476b6b&scene=126&sessionid=1681278844#rd)

招商银行深圳分行携手真格基金举办的2019年度企业圆桌会议，于11月14日在深圳成功举办，**永安在线作为优秀的创新型安全企业，受邀出席本次圆桌会议。**   
![](../Images/3f4b83e7e29b3285b28512f5346c7a4b.png)

  

此次圆桌会议以**“真知灼见 ****招****赢未来”**为主题。深圳市基础设施投资基金董事长卢文彬就大湾区政策前沿，做了现场深度解读，分享了大湾区将打造为充满活力的世界级城市群、具有全球影响力的科技创新中心的目标定位。  
![](../Images/639fa709528e67366beb00d8b0a227a4.png)

  

深圳作为大湾区其中的全国性经济中心城市，以及国家创新城市，无论从经济消费、智能制造、技术创新等都充当桥头堡的角色。永安在线研发副总裁彭巍在现场的圆桌会议环节中，就安全领域方向做了自己的行业分享。  
![](../Images/d7aeb567d7ed0a68d63993ef1854c706.png)

  

**提问：**从你过往的从业经验来看，ToB大环境下，如何突破安全业务的线性增长？  
**永安在线：**ToB业务的增长手段相对ToC就比较有限。因为ToB业务都是付费的，获取客户基本就意味着销售转化。 其中包括两点，一是产品与客户需求之间的匹配程度，二是客户对业务的接受程度，就是ToB业务增长的核心问题。

  

而我们现在认为解决以上问题的重点，是在如何**“赢得企业客户信任”**。  
因为如果仅仅从产品层面来看，同类型的ToB厂商不会相差太多，只是使用体验或者功能上略有差异而已。这时候要想赢得客户信任，更重要的就是让客户感受到你对他的重视，而服务就是其中非常重要的手段之一。  
![](../Images/a5f5ebe573f4968f24a87d11759e57fe.png)  
**提问：**针对互联网数据的反欺诈与内容安全服务，黑灰产对抗领域需要不断地保持学习的敏感度，也需要高价值的人才，公司在这一方面的战略是什么样的？  
**永安在线：**巧合的是，今年10月份，也就是上个月，我们企业名称刚从原来的“威胁猎人”变更为目前大家看到的“永安在线“，与此同时，**公司对外的产品服务及****对内的人才管理全面升级。****“识别、赋能、培养”**是永安在线的人才建设中的3个关键词。从早期创始团队中，有来自猎豹移动和腾讯的已深耕安全领域多年的CEO老毕，以及曾荣获世界著名的黑客大赛Pwn2Own全球冠军的CTO邓欣。![](../Images/c86c13848899962eafe438d30b9bf861.png)毋庸置疑，黑灰产对抗领域的安全从业人员，是非常稀缺的，一是专业性要求较高，二是培养的成本也相对较大，因为业务安全风控经验的丰富，是需要在真实的对抗中一步步积累起来的，这里不仅需要具备专业的技能，同时需要对业务本身也有了解。永安在线从创始班子的搭建，便注重团队技术基础的夯实，确保从“地基”上，**充分具备安全领域的技术创新基因。**  
永安在线研发副总裁彭巍在圆桌会议同时表示，伴随着人口红利、流量红利逐渐消失的互联网下半场的到来，新形势下的安全问题也日趋严重、欺诈横行、套路并存，企业不可避免会误入欺诈的各种“坑”。  
**反欺诈没有一招制胜，构建完备的实时防御体系才是王道。**  
![](../Images/3165e444190e3a5fa234f5a9dc9aa0a4.png)

  

比如，我们推出的**行业首个秒拨IP识别技术**，可实时判定IP状态，采取打分机制，量化风险值，精准识别恶意动态IP，解决由此带来的爬虫、撞库、薅羊毛等风险行为。  
同时设立的**“鬼谷实验室”**，旨在通过主动挖掘黑产攻击最新情报、复现黑产作恶业务途径、反欺诈模型等的进行深入研究**，****针对性制定完备的评估、检测、防御和感知的安全体系，帮助客户识别欺诈风险，并形成企业全流程的安全闭环。**  
  
在未来，永安在线将以自身反欺诈的技术优势，帮忙更多的行业客户识别、规避及防御风险，致力于为客户企业的业务增长、健康发展保驾护航。
