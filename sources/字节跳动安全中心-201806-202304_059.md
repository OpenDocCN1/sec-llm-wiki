# 最后7天|东南大学、同济大学战队暂列字节安全AI挑战赛初赛榜首

8月8-9月8日，由字节跳动安全中心发起的第二届安全AI挑战赛初赛火热开赛中，本次大赛延续第一届的高质量题目，**聚焦图像识别和文本对抗**，组委会希望为学生提供真实的业务场景，深度参与企业工作中的安全风险和挑战，通过以赛代练的方式来验证在学校期间的AI算法模型的实战性和扩展性。

据统计，截止目前已累计有185所高校，500多战队参与其中，目前距离初赛结束还有1周的时间，感兴趣的同学们还可以通过官网进行组队报名，**9月8日结束前均可报名参赛呦，即刻报名，冲击最后的榜单！**

![](../Images/e62da8dc53df7407a6ac7c2c15b0ad24.png)

  

**真实业务场景 多元数据类型**

本次赛道一的题目为《低分辨率抖音号识别》，在本次题目中，组委会根据题目要求，筛选了大量的抖音公开无处罚可下载的抖音视频帧，之后在这些原始投稿图像上填写随机生成非真实用户的抖音号，希望**选手通过建立算法模型来识别这些低分辨率的图像中包含的抖音号**。目前排名前三的队伍「SEU\_309、Anya、rcoevian」分别来自：东南大学、上海交通大学、上海交通大学。

  

![](../Images/81a0a97cd0b0a1b97523ed9658f97a3a.png)

  

赛道二题目为《文本对抗训练攻击》，本次赛题设计的背景是对文字识别模式发起攻击，**题目提供了针对模型攻击的1000条公开测试数据，题目中的文案长度大都在20-40字左右，需要选手通过提交恶意样本，对特定AI模型进行攻击，使之产生误判**。目前排名前三的队伍「给个机会吧、给个机会、LLL」分别来自同济大学、浙江大学、上海交通大学。

  

![](../Images/4fd699b287fcc9503ace3be8079aa3ea.png)

同时，本次大赛继续为同学提供丰厚的奖励，以及字节跳动安全与风控团队的**直通终面的正式和实习OFFER**。

![](../Images/141f66fbeacd56dcd36f33def3448a93.png)

正如大赛官网所展示，本次大赛继续扩充产学研的结合，与20所高校形成合作，**希望与高校携手共同挖掘安全AI人才，促进行业的人才培养**。

  

![](../Images/23ad7fbc065b4a1c6af45f313ec05532.png)

  

图像识别、文本对抗的技术研发和企业治理工作会是一个长期的工作，组委会从办赛之初便希望，**通过字节跳动安全AI挑战赛为学生提供一个竞赛平台**，真实的业务场景，仿真的数据，借助大赛搭建高校学子、科研专业之间学习和交流的桥梁。
