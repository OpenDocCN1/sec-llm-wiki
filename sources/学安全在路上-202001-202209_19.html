场景

    已获得shell，但目标主机存在杀软，需要免杀工具进一步后渗透。

免杀思路

测试时间：2021-10-16
需要免杀的工具：刚好主机上的mimikatz.exe

1、修改文件hash

    保证exe能够正常使用的前提下，修改exe内容完成hash变更，简单逃避杀软的hash特征查杀。这个很简单，使用十六进制工具将exe最后以为修改就行了。
可能也能过一些杀软，但效果肯定不会特别好。不做测试了。

2、特征码免杀

    主要是不断的通过二分法，将需要免杀的程序分段。观察哪一段程序运行会触发杀软报毒，然后再修改相关的特征值，将文件再次编译打包，完成免杀。因为需要对特征码进行修改，所以需要对PE文件结构很熟悉，不然可能杀软是不报毒但是也用不了了。。。哈哈哈哈哈

        这里测试了mimikatz.exe 被火绒标记了13处特征值。。。。。


3、添加签名

    使用sigthief对exe的签名进行修改，将签名替换为正常文件的签名。可以免杀一些，但是里可能效果不太好

sigthief.py -i tcpview.exe -t x86_meterpreter_stager.exe -o /tmp/msftesting_tcpview.exe

4、增加/替换资源

    通过替换资源文件（例如换图标、修改声明）和捆绑正常文件的方式，去除工具中杀软识别的一些特征，达到“永久的”一次性免杀。（不太好改到特征值，所以还是和修改hash是一个原理）
    工具：resource_hacker
    未免杀的mimikatz.exe，会直接被360查杀

    使用resource_hacker替换工具中的资源文件并捆绑正常软件notepade++

    保存为mimikatz1.exe

    尝试去运行，360全程未报毒

暂时过不了火绒.......(第一次火绒比360难过...........)

5、添加壳

    常见的加壳工具例如upx、VMP已经被杀软盯得很紧了。所以要想通过加壳的方式绕过杀软需要使用一些比较小众的加壳工具。这里使用Shielden来加壳，工具还具备反调试、反沙箱的一些功能。
    将需要免杀的exe放入工具中，根据需要勾选选项即可。（注意要保证程序正常运行）

    测试360，最新版本

    因为测试使用的mimikatz.exe，已经被火绒标记了很多的特征码所以上面的方法对mimikatz.exe火绒的免杀可能不太有效，但是免杀普通的cs、msf木马应该是可以的。
    以上的方法可以照着全走一遍，可能效果会好一点。。。。。

    经过一系列操作：目前测试多次，暂时可以稳定免杀低版本df(win10  df 已测试、2019 server 的不行)、截止今天最新的360

最后

    以上的方法最终都是要在目标主机上留下文件的，并没有达到所我们想要的隐蔽性。所以最后还是使用之前提到的无文件落地的方法，直接省去了被杀软识别特征的环节。
