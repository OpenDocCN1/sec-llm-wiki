Domain Fronting（域前置），一种隐藏连接真实端点来规避互联网审查的技术。用于隐藏Metasploit、Cobalt Strike等远控软件服务端与木马受控端之间的流量通信；Amazon，Google，Cloudflare，腾讯云等众多厂商现已经关闭Domain Fronting服务。现在只能借助CDN服务进行隐藏Metasploit、Cobalt Strike服务端链接地址。

 

CND解析过程如下：

CDN技术如何区分，被控主机的请求是正常的网站服务，还是访问远控服务器。在设置CDN解析时会填写多个A记录的DNS解析，当被控主机请求不同的A记录时，CDN服务根据请求的A记录解析对应的资源。

 

以下使用Cobalt Strike和Cloudflare进行演示，环境准备：

VPS：搭建Cobalt Strike服务端

Cobalt Strike：远控软件

域名：国内注册需要备案，可选择国外购买

Cloudflare：CDN服务

 

1、VPS购买，国内外厂商很多，例如：阿里云，腾讯云，Amazon，Google，Vuitr等；购买不过多阐述。

2、Cobalt Strike搭建，将准备的Cobalt Strike上传到服务器，更改证书，端口启动服务即可。

3、域名注册，国内域名注册需要实名认证备案才能使用（VPS也需要实名认证），方便可选购国外厂商提供的域名服务（Freenom提供免费的域名），购买过程过于简单不过多阐述。

4、Cloudflare，注册Cloudflare账号即可。

 

设置CDN解析

登录Cloudflare，添加解析域名。

选择0元免费版本使用。

设置NS记录，登录域名服务商，将NS记录更改为Cloudflare提供NS记录；完成后等待10分钟左右刷新Cloudflare即可正常使用进行CDN配置。

设置解析记录，进行CDN解析；将SSL/TLS设置完全加密后，访问设置的A记录测试是否使用CDN解析。


生成证书，默认生成证书有效时间是15年，根据需求选择证书有效时间，将生成的公钥和私钥拷贝（原证书保存为server.pem，公钥保存为client.key）保存以备后面使用。

将生成的公钥和私钥生,打包p12格式证书，将p12证书生成store格式文件

opensslpkcs12 -export -in server.pem -inkey client.key -out ceshi.com.p12 -nameceshi.com -passout pass:"123456" （注意pass需要用引号包裹，ceshi.com需要替换成生成证书的域名）


keytool-importkeystore -deststorepass "123456" -destkeypass"123456" -destkeystore ceshi.com.store -srckeystore ceshi.com.p12-srcstoretype PKCS12 -srcstorepass "123456" -alias ceshi.com （注意pass需要用引号包裹，ceshi.com需要替换成生成证书的域名）


将生成的证书，放置到Cobalt Strike根目录；将teamserver中的keystore，keyStorePassword替换成上传的证书和证书密码。

配置Cobalt Strike C2 profile 文件，profile文件下载地址：https://github.com/xx0hcd/Malleable-C2-Profiles；选择合适的profile文件进行修改，将host头修改为Cloudflare加速的域名（get，post都需要修改）。

在profile中添加如下配置：

https-certificate {set keystore"keystore.store"; //证书所在的位置set password "1234565";//证书的密码} http-config {   set trust_x_forwarded_for "true";}

 使用c2lint 验证profile是否配置成果。

启动teamserver，./teamserver IP 密码profile

连接客户端，配置C2（注意开启VPS防火墙端口）

**注意：**免费版本的cloudflare支持解析少量的端口，具体端口如下

http：80、8080、8880、2052、2082、2086、2095

https：443、2053、2083、2087、2096、8443

选择设置监听的beacon，生成木马测试上线，成功上线。

使用Github 开源项目生成Profile文件，项目地址：https://github.com/FortyNorthSecurity/C2concealer

 安装使用：

  git clone https://github.com/FortyNorthSecurity/C2concealer  cd C2concealer  Chmod +x  ./install.sh

 C2concealer --variant 1 --hostname“ceshi.com”   //域名需要加引号,生成完成后使用c2lint检测；（使用C2concealer生成profile，需要配置listener时在profile中选择variant_1才行，不然可能会导致无法上线。）

  选择 3

  输入证书所在路径

  输入证书密码

配置监听，生成木马测试上线；

通过抓包看到通信中并没有服务端地址，受控端和服务器之间通信的IP也是CDN地址。

使用Powershell上线，需要在生成的时候需要勾选SSL头，否则无法上线(注意端口需要设置Cloudflare允许的端口)；成功上线。

中途遇到一些坑点：

 1、使用github项目C2 Profile需要增加两个Profile参数

 2、设置Listeners 选择http、https端口需要设置Cloudflare解析的端口

 3、使用C2concealer生成profile，cs使用过C2lint检测过profile，会与C2concealer产生冲突导致无法正常生成profile。
