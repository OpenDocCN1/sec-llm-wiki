# Cobalt Strike CDN隐藏

Domain Fronting（域前置），一种隐藏连接真实端点来规避互联网审查的技术。用于隐藏Metasploit、Cobalt Strike等远控软件服务端与木马受控端之间的流量通信；Amazon，Google，Cloudflare，腾讯云等众多厂商现已经关闭Domain Fronting服务。现在只能借助CDN服务进行隐藏Metasploit、Cobalt Strike服务端链接地址。

 

CND解析过程如下：

![](../Images/fe7fb6062c1334a661cafd9fda208d40.png)

CDN技术如何区分，被控主机的请求是正常的网站服务，还是访问远控服务器。在设置CDN解析时会填写多个A记录的DNS解析，当被控主机请求不同的A记录时，CDN服务根据请求的A记录解析对应的资源。

 

以下使用Cobalt Strike和Cloudflare进行演示，环境准备：

VPS：搭建Cobalt Strike服务端

Cobalt Strike：远控软件

域名：国内注册需要备案，可选择国外购买

Cloudflare：CDN服务

 

1、VPS购买，国内外厂商很多，例如：阿里云，腾讯云，Amazon，Google，Vuitr等；购买不过多阐述。

2、Cobalt Strike搭建，将准备的Cobalt Strike上传到服务器，更改证书，端口启动服务即可。

3、域名注册，国内域名注册需要实名认证备案才能使用（VPS也需要实名认证），方便可选购国外厂商提供的域名服务（Freenom提供免费的域名），购买过程过于简单不过多阐述。

4、Cloudflare，注册Cloudflare账号即可。

设置NS记录，登录域名服务商，将NS记录更改为Cloudflare提供NS记录；完成后等待10分钟左右刷新Cloudflare即可正常使用进行CDN配置。

中途遇到一些坑点：

 1、使用github项目C2 Profile需要增加两个Profile参数

 2、设置Listeners 选择http、https端口需要设置Cloudflare解析的端口

 3、使用C2concealer生成profile，cs使用过C2lint检测过profile，会与C2concealer产生冲突导致无法正常生成profile。
