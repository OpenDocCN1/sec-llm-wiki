重点函数介绍

*   
*

```
in_array()可以判断一个值是否在数组中,数组内匹配指定值mb_substr()从字符串内返回指定值（substr()只针对英文字符，如果需要分割中文字符则需要mb_substr()),左闭右开比如mb_substr(0,2)得到0,1位字符mb_strpos()返回某字符在数组中首次出现的位置
```

*   

