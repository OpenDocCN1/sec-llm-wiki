一、工具介绍

Nim 小众语言不易被检测

内存加密释放可执行文件体检小（相对于golang）

降低被杀毒软件检测到的风险

使用加密将文件“硬编码”为代码

能够自删除

应用场景：钓鱼投递伪装成正常文件的木马。

项目下载地址：

https://github.com/evilashz/NimFileBinder

二、安装nim环境

nim下载地址

https://nim-lang.org/



将得到的文件解压，然后再移动到自己选择的目录下（这个无所谓）：

复制bin目录下的路径：

D:\Tools\safetools\钓鱼攻击\nim-1.6.6_x64\nim-1.6.6

将该路径添加到环境变量的系统变量path中去

保存系统变量设置后，打开cmd命令窗口，输入nim

此时代表Nim安装成功

三、安装MinGW

MinGW是为Nim编译所必须的，MinGW主要是编译C、C++代码用的，在这里一共有两种方式：

  • 直接下载MinGW安装

  • 利用Nim自带的程序finish.exe安装

这里选择直接安装MinGW的方式

安装MinGW 在这里有下载链接地址

https://sourceforge.net/projects/mingw-w64/files/

下载最新版x64位版本：

64位系统建议选择x86_64-posix-sjlj32位系统建议选择i686-posix-sjlj

MingGW64 版本区别于各版本说明 https://www.pcyo.cn/linux/20181212/216.html

下载完成之后来到bin目录下，使用命令行检查当前的gcc版本：gcc.exe --version

然后就是和上面一样，设置系统环境变量：在控制面板\系统和安全\系统中，选择高级系统设置\高级\环境变量，设置环境变量

将MinGW添加到系统环境变量中去

完成之后，确认退出：在新的命令行中尝试输入gcc.exe --version

此时证明MinGW安装成功

四、编译

到NimFileBinder的src目录下调用cmd，输入一下命令进行编译

nim c --hints:off -d:release NimFileBender.nim


结果出错了，提示我们没有strfmt这个模块

那我们就下载这个模块并安装

nimble  install   注意如果前面的系统变量中有中文字符的话，这里安装也会出问题，所以一定要所有路径都是英文才可以

所有缺少的模块都可以在github上找到，都安装完成之后再次执行上面的编译命令，就会在当前目录下生成一个NimFileBender.exe的程序了

五、使用方法

可将免杀好的exe文件和想要捆绑的正常文件放在Nimfilebender.exe目录下。

并输入命令Nimfilebender.exe xx.exe xx.exe testkey即可将文件捆绑。

当前文件夹下会生成一个outfile.exe，这个就是捆绑后的文件

点击执行会按照正常文件的方式执行，但是后台会运行我们的木马
