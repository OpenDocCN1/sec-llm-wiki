先dump下dexheard文件

  

![](../Images/1bef5e9fcb19ca240a37a29b3e0130bc.png)

  

脚本：

  

staticmain(void)

  

{

  

autofp, begin, end, dexbyte;

  

fp= fopen("C:\\\\dump\_heard.dex", "wb");

  

begin= 0xBED8EC54;

  

end= 0xBED8EC54+0x70;

  

for( dexbyte = begin; dexbyte < end; dexbyte ++ )

  

fputc(Byte(dexbyte),fp);

  

}

  

因此程序逻辑清晰了：

  

**先获取到混淆的****dex****，然后根据偏移量，计算出起始点位置，然后再解密另一个****dex****文件头部和文件大小，然后拼接处再前面的****dex****的偏移量起始点处，这时候在赋上第一个文件大小****A7C14**
