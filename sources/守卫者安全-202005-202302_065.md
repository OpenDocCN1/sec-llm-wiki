网站首页显示如下

![](../Images/6c6d32a1c156c292a4801d1ba8f06459.png)

随便打开一个公告手工测试发现可能存在注入

`and 1=1`

![](../Images/e09e95dad8ad7f92f856147d06aa60db.png)

`and 1=2`

![](../Images/f7c1aa86657f7df6a07b34ef58164128.png)

随即用sqlmap进行测试

![](../Images/04adbb52eb4ff4833903f3a14aaac16b.png)

![](../Images/71335968f8f3c76ff5993d036ea53e22.png)

可以看到确实是存在注入的，并且使用的是sqlserver数据库。接着就是用跑出来的密码登录网站后台

![](../Images/057a68ef661d5784620bd6ef2982f73f.png)

后台首页显示如下

![](../Images/eb06cab3f08bfaf48127393441132627.png)

好像并没有什么多余的东西只能对公告进行修改或删除。随即点击修改发现可以能够上传文件

![](../Images/1c49c3e7cdc5214c2b97fe7506c60971.png)

经过测试这里可以直接上传aspx的木马，不过需要免杀的那种。上传成功只会会返回路径，显示如下

![](../Images/3737fd67a2185574ee39105b11455f96.png)

用菜刀进行连接

![](../Images/a53f67eabe30bd9d8571cfced1016bb6.png)

![](../Images/3acc8bcde9ff62710eb324355759a1fa.png)

接着首先看看当前是什么权限，结果发现就是一个iis用户的普通权限

![](../Images/155f5e53c665e85c2efe9d3e35a7c2ef.png)

所以接下来就开始了一系列失败的提权之路。什么烂土豆啊、ms17-010啊，反正疑似存在的都试了一遍都未成功。就在打算放弃这个站的时候，在网站根目录的某个文件夹下面发现了很多php文件

![](../Images/7a8b2d2e756542f630810611c43f61ee.png)

这就意味着服务器能够解析php啊，所以直接上传一个php大马进行访问

![](../Images/7b8bfd13c83d4d4eab4cd5c1c4e792fe.png)

最后在执行cmd命令中发现了惊喜

![](../Images/ffbdc12e88f52b9a3c61ccdadde427b0.png)

居然php是具有administrator权限的，这可真是柳暗花明啊。这下我的cobaltstrike就起作用了。

首先选择Attacks--Web Drive-by--scripted Web Delivery(S)

![](../Images/0714ee5ed14f1682f1883dc54329f003.png)

点击“开始”，成功的话就会弹出如下窗口

![](../Images/ef44c6f1a6dece267ed098f6f2c8dbc5.png)

*   

```

```

将生成的语句直接放到执行cmd命令的窗口中执行即可，执行完毕cs就能收到主机上线的提醒

![](../Images/20ddc894b21263ad387cd3092d080d34.png)

现在主机也上线了，权限也是administrator。那么接下来当然就是读取密码啦。

这里有两种方式，第一种就是转储Hash

![](../Images/7fcc47b2eac1a5420856467ecb33dd99.png)

![](../Images/fd5cec905b5859aeb874f3cf47a55f79.png)

通过这种方式能够得到目标主机的用户名和密码hash值，不过能不能解密出来就看运气了。这里的hash我就没有解出来

![](../Images/a75456a5e87525bbce286c4c7bdc5a7e.png)

第二种方式就是Run Mimikatz

![](../Images/2992b5e2037b8d62674f6011d4001683.png)

![](../Images/39425fb728ba02cbe91ffe04afcd3eb8.png)

可以看到账户密码已经是明文显示出来了。接着扫描一下目标主机开放的端口  

![](../Images/242e438f6b162f739566899505b125f9.png)

3389端口是方法的就很nice了，直接登录  

![](../Images/351a4c35878b5480463d2436dd063202.png)
