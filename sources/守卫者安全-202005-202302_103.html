       最近Burp suite工具更新了全新的版本(Burpsuite_pro_v2020.4)。从此版本开始，环境要求最低为Java 9，不再支持Java 8，在实际测试中 Java 8也确实不行，相信目前很多用户将受此更改的影响。

       在之前的版本中我们通常是从JAR文件直接启动Burp而不是使用提供的安装程序，但是在尝试启动新版本的JAR文件之前，需要确保本地环境是Java 9至13版本中的一种。

       针对此情况,下面将对此次实测安装使用新版Burp Suite的过程进行详细记录。

       下载安装文件（请在文末获取文件链接），下载成功解压之后可以看到其中包含如下文件

        直接启动主程序没有任何响应，所以我们需要更新java版本。点击当前文件夹下的jdk-13.0.2_windows-x64_bin.exe即可进行更新。

安装完成之后开始对系统的环境变量进行配置。


1、新建系统变量java_HOME,并将变量值切更改为jdk13的安装目录

C:\Program Files\Java\jdk-13.0.2


2、在Path系统变量中找到如下地址

 C:\Program Files (x86)\Common Files\Oracle\Java\javapath


然后打开此位置，并且删除其目录下的如下三个文件


3、在Path系统变量中新增一条地址

%java_Home%\bin

       完成这些配置之后就可以选择解压缩文件中的burp2020.4中文版.bat或burp2020.4英文版.bat（看个人习惯）
