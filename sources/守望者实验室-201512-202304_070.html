01

基本描述

  根据我们对一些典型安全事件的分析，部分木马采用了HTTPS协议进行加密传输，以防范流量监测系统发现其行为或传输的内容。针对此种攻击，可以通过被动流量分析，提取HTTPS加密通讯时所使用的证书信息， 也可以通过主动探测的方式获得，基于zmap 的应用层扫描器 zgrab可以探测获取目标的证书信息。

      根据获取的证书信息，借助威胁情报的恶意证书指纹、证书过期信息等，协助我们发现木马传输的隐蔽行为。

02

情报样例

  Feed威胁情报系统：https://feed.watcherlab.com中，专门提供了证书基本信息的查询、恶意SSL证书指纹库，并定期更新。

      平台支持通过证书的指纹等进行证书的基本信息查询。可展示数据主要字段：版本（version）、序列号（serial_number）、签名算法（signature_algorithm.name）、签名哈希算法（signature_algorithm.oid）、颁发者（issuer_dn）、使用者（subject_dn）、有效期开始时间（validity.start）等。

  恶意SSL证书指纹Hash（ssl_hash），主要提供具有恶意软件、恶意行为URL或者域名所使用的SSL证书指纹。

03

应用场景

● 首先搭建一个网站，并为其颁布SSL/TLS证书

● 证书信息

  访问测试网址，浏览器端获取到网址的证书，查看证书的序列号、SHA1指纹、证书是否过期等信息。

● Suricata规则

1# /root/rules-suricata/tls-test.rules
2# 检测SHA1：
3alert tls $EXTERNAL_NET any -> $HOME_NET any (msg:"This is KKW Certificate's SHA1....."; tls.fingerprint:"85:d8:84:76:8b:b9:9c:b4:13:5f:94:f8:52:b8:c2:79:50:b6:fe:07"; sid:810000012; rev:1;)
4# 检测序列号：
5alert tls $EXTERNAL_NET any -> $HOME_NET any (msg:"This is KKW Certificate's Serial..."; tls_cert_serial; content:"61:10:3c:b2:00:00:00:00:00:02"; sid:810000011; rev:1;)
6# 检测证书是否过期，未过期为true
7alert tls $EXTERNAL_NET any -> $HOME_NET any (msg:"The kkw Certificate is valid..."; tls_cert_valid; tls_cert_serial; content:"61:10:3c:b2:00:00:00:00:00:02"; sid:810000013; rev:1;)
8# 检测证书是否过期，过期为true
9alert tls $EXTERNAL_NET any -> $HOME_NET any (msg:"The kkw Certificate is expired..."; tls_cert_expired; tls_cert_serial; content:"61:10:3c:b2:00:00:00:00:00:02"; sid:810000014; rev:1;)

● 启动Suricata

命令

1suricata -c /etc/suricata/suricata.yaml -s tls-test.rules -i eth0

● 再次访问测试网址

在另一个终端查看日志信息

1tail -f /var/log/suricata/fast.log
