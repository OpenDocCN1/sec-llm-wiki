**    描述    **

     ioc-parser是一个从PDF的安全报告中提取威胁指标的工具，并且可以将IOC存储为csv、tsv、json、yara、netflow这五种格式。

**    使用方法    **

     通过帮助选项可以发现，使用方法都已经列的很详细了，如图：

![](../Images/38b682c97801a939ea35a2f3d44ddc2e.png)

几个比较重要的选项

\-i 输入文件的格式，有PDF、HTML、txt三种

\-o 输出格式，有五种格式，csv/tsv/json/yara/netflow

\-d 删除重复条目

\-l 指定PDF解析库，是pypdf2还是pdfminer

    可以直接对某个目录下的报告进行提取，如下：（以提取成csv格式为例）

![](../Images/1563c3c113bc3bb585565006276d222a.png)

结果导入到result.csv文件中，打开该文件，如下：

![](../Images/ed679213c00473589d26379c6874cb35.png)

通过相关语句控制，可以单独提取第三列和第四列，如下：

iocp -i pdf -o csv -d report | awk -F, '{printf "%s,%s\\n",$3,$4}' > result.csv

![](../Images/d01b4fd59d85043c1b9a829bce4e5461.png)

![](../Images/1257e11ec82e9ff12dda951fe61ded9b.png)

**    安装与配置   **

首先安装解析库

安装PDF解析库之一：

PyPDF2 - pip install pypdf2

pdfminer - pip install pdfminer

![](../Images/853e7fdfd3f2c0bbabe1e7bb4e5d68d2.png)

安装HTML解析支持：

BeautifulSoup - pip install beautifulsoup4

![](../Images/a524e54459cddadcdb2b9f42b4a2e0c1.png)

对于HTTP(S)的支持

requests - pip install requests

![](../Images/851d7152a51077a8611002995770ae25.png)

使用pip安装ioc\_parser

pip install ioc\_parser
