    简述    

      DNS是互联网和物联网（IOT）的“神经系统”，是连接网络的第一步动作，DNS系统是一个基于C/S结构的巨型分布式数据库系统，实现域名到IP地址的转换，DNS系统有着良好的系统性能，同时作为一个开放的系统，也存在着诸多的安全问题和隐患。

  其中，以恶意软件为例，恶意软件一般通过DNS实现命令与控制(Command and Control)信道、窃取数据和重定向流量等三个目的。除了恶意软件，还有很多网络攻击也离不开DNS，比如APT攻击、垃圾邮件、僵尸网络和挂马网站等，它们都在利用DNS伺机攻击企业的网络。
    Suricata默认规则   

     如上所述，DNS检测还是很重要的一点，Suricata默认规则文件中也包含一个检测DNS协议相关攻击的文件——emerging-dns.rules，该规则文件是由Emerging Threats提供，Emerging Threats是Suricata更新源之一，下面就解析一下emerging-dns.rules这个规则文件[1]。

    模拟实例   

● Sinkhole信息检测

  该检测是指当访问的域名为僵尸网络的时候，并不会让浏览器跳转到该页面，而是DNS服务器给出错误信息，从而防止访问特定域名。

分析一下第一条规则（代码区可以左右滑动）

alert udp $EXTERNAL_NET 53 -> $HOME_NET any (msg:"ET DNS Reply Sinkhole - sinkhole.cert.pl 148.81.111.111"; content:"|00 01 00 01|"; content:"|00 04 94 51 6f 6f|"; distance:4; within:6; classtype:trojan-activity; sid:2016413; rev:4; metadata:created_at 2013_02_14, updated_at 2013_02_14;)

（代码区可以左右滑动）

# 数据包流量方向 外部主机的53端口到本机的任何端口
$EXTERNAL_NET 53 -> $HOME_NET any
# |00 01 00 01|该16进制是DNS响应包的特征字段
content:"|00 01 00 01|";
# 威胁类别属于特洛伊木马活动（检测到网马）
classtype:trojan-activity;

● 检测可疑域名

  在emerging-dns.rules规则文件中提供了类似于下图中的检测域名的规则，规则提供方Emerging Threats认为这些域名为可疑域名，认为这些域名存在潜在的威胁流量。

以如下规则为例，分析一下该规则（代码区可以左右滑动）

alert udp $HOME_NET any -> $EXTERNAL_NET 53 (msg:"ET DNS DNS Query to a Suspicious *.vv.cc domain"; content:"|01 00 00 01 00 00 00 00 00 00|"; depth:10; offset:2; content:"|02|vv|02|cc|00|"; fast_pattern; nocase; distance:0; classtype:bad-unknown; sid:2012826; rev:1; metadata:created_at 2011_05_19, updated_at 2011_05_19;)

（代码区可以左右滑动）

# 告警信息  udp协议   检测本机任何端口到外部主机53端口流量  
alert udp $HOME_NET any -> $EXTERNAL_NET 53
# 检测到之后打印在日志里的信息
msg:"ET DNS DNS Query to a Suspicious *.vv.cc domain";
# 匹配字段信息，其中|01 00 00 01 00 00 00 00 00 00|是16进制DNS请求包有的特征字段，
# depth和offset分别代表匹配宽度和在开头的偏移量，
# fast_pattern表示有线匹配简单的字段，即|02|vv|02|cc|00|，
# nocase表示不区分大小写;distance:0表示在当前位置不偏移
content:"|01 00 00 01 00 00 00 00 00 00|"; depth:10; offset:2; content:"|02|vv|02|cc|00|"; fast_pattern; nocase; distance:0;
# classtype表示威胁类型，sid表示该规则的id号，
# rev表示该规则的版本号，metadata表示附加信息
classtype:bad-unknown; sid:2012826; rev:1; metadata:created_at 2011_05_19, updated_at 2011_05_19;

● 检测通常与恶意软件相关联的域名

  与检测可疑域名类似，Emerging Threats定义了一部分通常与恶意软件相关联的域名，如果在这方面有流量，也会打印日志。

分析其中第一条规则（代码区可以左右滑动）

alert dns $HOME_NET any -> any any (msg:"ET DNS Query for .su TLD (Soviet Union) Often Malware Related"; dns_query; content:".su"; nocase; isdataat:!1,relative; reference:url,www.abuse.ch/?p=3581; classtype:bad-unknown; sid:2014169; rev:2; metadata:created_at 2012_01_31, updated_at 2012_01_31;)

与可疑域名不同的是，增加了isdataat和reference两个字段。（代码区可以左右滑动）

# isdataat 表示在某偏移量位置是否有数据，
# relative表示从上次匹配的位置偏移，！表示取反。  
# reference表示该威胁的相关描述信息所在的链接地址。
isdataat:!1,relative; reference:url,www.abuse.ch/?p=3581;

请求包信息如图：

启动Suricata，访问www.12345.su，查看日志，如图：（代码区可以左右滑动）

# 启动Suricata
suricata -c /etc/suricata/suricata.yaml -i eth0
# 实时查看日志
tail -f /var/log/suricata/fast.log


    小结   

    Suricata还有很多默认规则，比如Current_Events Rules、DOS Rules、Attack-Response Rules等，后续会推出更多内容，关注公众号，获取更多资讯。

    注解    

    Suricata最新版本已经不会单独列出emerging-dns.rules，而是在使用suricata-update更新规则时，默认是将所有规则合并在一个规则文件中：/var/lib/suricata/rules/suricata.rules。如需分离，需要在更新源时添加--no-merge选项，eg: suricata-update --no-merge
