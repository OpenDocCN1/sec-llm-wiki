**Feed系统下载Suricata规则**

下载地址：https://feed.watcherlab.com/rules/

2

**简述**

在Centos6.9系统上搭建Suricata4.1.0环境，另外，Centos6.9需要用root用户权限

3

**安装EPEL包库**

yum install epel-release

4

**安装依赖**

yum -y install gcc libpcap-devel pcre-devel libyaml-devel file-devel zlib-devel jansson-devel nss-devel libcap-ng-devel libnet-devel tar make libnetfilter\_queue-devel lua-devel

![](../Images/eecc7b026e4e91edf2f1898927203a5e.png)

![](../Images/2f77be779628dd3f56f3b4acbf463b7a.png)

5

**下载Suricata4.1.0**

wget https://www.openinfosecfoundation.org/download/suricata-4.1.0.tar.gz

![](../Images/d69342db8c9472d0685a21445a274504.png)

tar xvf suricata-4.1.0.tar.gz

cd suricata-4.1.0

./configure --prefix=/usr --sysconfdir=/etc --localstatedir=/var --enable-nfqueue --enable-lua

![](../Images/d4b57039a3ed986f15a7feb523fc8663.png)

![](../Images/9fe2a49cf81da5c08e4d4f47fc026d9f.png)

6

**编译安装(在suricata-4.1.0目录下)**

make

make-install

ldconfig

7

**简单配置**

make install-conf  

将执行常规的“make install”，然后它将自动为您创建/设置所有必需的目录和suricata.yaml。

![](../Images/3f39f069ed38148d52e60e2bf2b8649b.png)

make install-rules

将执行常规的“make install”，然后它将自动下载并设置Suricata可用的Emerging Threats的最新规则集

![](../Images/1c95d2120d90b723ec8d15404776f4b6.png)

make install-full

将结合上面提到的所有内容（install-conf和install-rules） - 并为您提供准备运行（配置和设置）Suricata

![](../Images/8ba71357520f7be4cfa6da4a8b0ca22f.png)

  

8

**简单配置**

vim /etc/suricata/suricata.yaml

修改本网段的网段范围，同时将其他网段，改成any，因为可能会收到内网主机的攻击，所以EXTERNAL\_NET修改成any。

![](../Images/4206ef798989928e4dce1787fe3d4a4d.png)

9

**编写测试规则并执行**

![](../Images/5cba43c7bfcf321863138df074017e73.png)

alert http $HOME\_NET any -> $EXTERNAL\_NET any (msg:"this is a test...";content:"GET"; http\_method; content:"baidu";http\_host; sid:80000001;rev:1;)

运行suricata

suricata -c /etc/suricata/suricata.yaml -s /tmp/test.rules -i eth0

![](../Images/d3787e71319d17a4d934f4665cdb0a8d.png)

10

**监听日志**

在主机上访问www.baidu.com，查看日志变化
