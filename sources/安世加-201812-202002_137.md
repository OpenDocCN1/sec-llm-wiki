**1.运行说明**

  

  

目标:获取靶机Flag

靶机难度:中等

运行环境:攻击机Kali Linux 2019.4&&靶机XXE VMware 15.X

靶机XXE 下载地址：

https://download.vulnhub.com/xxe/XXE.zip

  

网络设置:VMware当中的NAT模式

  

![](../Images/bd5056678b6abed34ffb25205ac17528.png)

  

  

**2.风雨欲来**

  

  

我们把下载好的xxe靶机文件解压到我的D:\\ios镜像\\靶机\\xee

  

![](../Images/da4a6aa4e0392ed80450b9ac702cc0d2.png)

在该目录下创建一个xxe文件夹

![](../Images/e57c36f2687ea7146f5f161a7084a6f2.png)

然后打开xxe文件 类型为开放虚拟化格式程序

![](../Images/2e83f6385535b8967f8eb682226232c2.png)

  

存储路径就是我们在D:\\ios镜像\\靶机\\xee创建的xxe文件夹

  

点击导入后 我们就可以打开靶机了

  

![](../Images/51097ee34dad06d02c520605fbe52063.png)

  

打开后等待一段时间就这样了，我们不必去管它，也别关闭这个靶机。

接下来我们来看看我们的网络模式是否正确

  

![](../Images/ea48db959a6160fa4f77e271c5cc2855.png)

  

我们这里的VMnet8 是NAT模式啊

（打开虚拟网络编辑器：虚拟机的左上角 编辑 –->网络虚拟编辑器）

 接下来我们切换到我们的kali linux即可开启我们的练习了

![](../Images/bd5056678b6abed34ffb25205ac17528.png)

  

  

**3\. 长达两年半的练习**

  

  

这里我们可以用netdiscover工具或者nmap工具去扫描虚拟机下的网关

这里我就首选netdiscover了，因为你用nmap扫描还得知道自己的网关ip。相对而言是麻烦的！

  

![](../Images/d330c19b231d9c9e9fcff200589064c6.png)

因为我kali的ip从这里是可以看到的，所以很明确知道靶机地址是192.168.214.131

  

知道ip我们第一时间使用namp去扫描一下有什么东西

  

![](../Images/2f591581781bff31db48aeecabf8f89f.png)

  

不难知道靶机开放了80和5355这两个端口

![](../Images/f0820048f2fa2466542bb271a22261a8.png)![](../Images/7cfa5c013a4f5ce6b99644a2a7a38bef.png)

  

因为开放了80端口，我们直接访问ip看看吧

![](../Images/3eb74c59f7ce73ca2d2e05c3323e71ce.png)

得到了这么一个ubuntu的默认页面，几乎没有什么可以利用的价值

按照大佬们写的靶机渗透文章，这时候我们应该扫描一下靶机的目录

  

这里有两个工具推荐，一个是dirb(这个是kali自带的工具)还有一个是dirsearch（需要自己去github上面克隆到kali里面）

由于kali linux 2019.4是我今晚更新的 没啥脚本所以我们还是用dirb吧，不过我还是推荐大佬们去使用一下dirsearch，百度有很多教程！！！

  

![](../Images/d7a5f90c988bb33fecfdac18fdc0e1e4.png)

  

咦，居然存在robots.txt文件，必须去看一看

  

![](../Images/5fd0595994ec2c151bb3bd5e6604302a.png)

  

打开后发现有/admin.php 我们来打开看看

![](../Images/f9ff75947803ed29d45a845db470ae8f.png)

好的，是我不配。我们来看看这个xxe吧。

![](../Images/05462fc48b324e3408de770f937ca936.png)

  

我试过了弱口令，不存在。既然是xxe靶机，那么我们从xxe的思路来吧。

拔出我们的神器 burpsuite 配置代理（此处忽略）

  

我们随便输入内容，然后抓包

![](../Images/7b3bc12832d745c763a600aafea65d93.png)

  

二话不说，咱直接丢尽repeater 然后send看看回显什么内容

  

![](../Images/f1d281e4289fe9c7b2bdd99525c36d40.png)

  

我们直接用xxe的方式开始利用吧。

插入：

            <!DOCTYPE r \[

            <!ELEMENT r ANY >

            <!ENTITY admin SYSTEM "file:///etc/passwd">

             \]>

  

  

![](../Images/2001c343bc5773a0b83ba1b0b8d59e02.png)

  

      记得修改为<name>&admin;</name>

       既然有回显，那么我们就来利用这个思路看看刚才看不了的admin.php

  

![](../Images/01714f3d52bbc19bd6307469c69aaf8f.png)

  

放回结果是被base64加密了的内容，我们去百度查找在线工具然后解密看看

当然了，burpsuite也自带了解码工具，我们方便一些，直接使用现成的！

  

![](../Images/bec7334119eab181e6e067f0cb26afee.png)

  

可以知道一串被md5加密的密码，我们事不宜迟直接去解密吧。

![](../Images/51a1ef480d48170fd9b4c12a69643d1b.png)

可以得出密码是 amdin@123 但是我们拿去登录却一直登陆不进去

![](../Images/9c9dd28bd0ed4bec1a0391679de35f90.png)

  

怎么回事呢？？我疑惑了很久，于是对这个目录扫描了一下

不扫不知道，一扫就是惊喜

  

![](../Images/0de3fabf6733fa9d4cc05c845b1c0a94.png)

  

没想到在xxe目录下面还有一个admin.php文件

我想，密码应该是这个文件的吧。

  

![](../Images/a9df926d2485ef8c3e141e38a568f8f8.png)

  

成功登录了，显示了一个红色的Flag，点击发现是个跳转，但跳转的文件无法打开，我们再次用xxe的利用思路看看

  

![](../Images/5034709c6e36111ebb0a181753771b99.png)![](../Images/d64e01f0e8c5c0d556360cdb3ac9283d.png)

  

又是得到一串编码，我们去解码看看

  

![](../Images/a3de08a27d72ad8dd9f8513887bc7370.png)

  

再次得到一串flag，但这个flag是编码的，我们再解码看看 不难看出是个base32编码，因为burpsuite只能解码base64，我们去找在线平台解码吧

  

![](../Images/a31f89910a66d5044559ee062e8520e2.png)

  

这个靶机，我。。。，又是个base64编码。老套路，拿去burpsuite解码吧

  

![](../Images/d050df20b855842c8a452d4fd6fae81c.png)

  

这一次终于不是一个被编码的内容了，而是一个文件，我们用xxe漏洞利用方式来看看里面有什么内容吧！

  

![](../Images/568161bc2dbbde7d2be4dedd3e7feb5b.png)

  

又得到了一堆编码的东西，再去解码看看有什么吧。

  

![](../Images/bfb2a8946dada7f9a2f68297f83963fa.png)

  

这次解码的东西是什么鬼。。。。。。

找了很久，才从万能的度娘找到了，这是一个webshell，算是变形的吧！

  

接下来我们就把它保存在本地，然后打开环境运行看看

  

![](../Images/2b867985f86aa0f8b1120da3da948dd6.png)
