面对日益复杂的网络环境和层出不穷的网络攻击威胁，如何有效保护您的企业并获取所需的技能和经验。欢迎报名参加将于**2019年6月18****日**在上海举办的"**安全·御远而行暨2019云&网络安全峰会--网络靶场攻防实战演练**”。本次网络靶场将模拟最前沿的攻防环境和真实应用环境，帮忙企业通过一系列解决方案成功抵御现网中的各种攻击。

网络靶场将采用快节奏，高科技以及实战演练的方式来学习最新安全策略和技术。届时我们将携手技术合作伙伴CYBERBIT为您呈现最真实的网络攻防模拟环境。

**靶场演练场景介绍**

**09:00-12:00 - Apache Shutdown** （难度：中等）

在此场景中，模拟攻击者会攻击已知的公共 Apache web 服务器。

参加人员需要调查整个攻击的过程， 想办法通过相关安全工具来防止攻击的再次发生， 并最终为整个攻击过程进行画像。

**13:30-17:30 - Ransomware** （难度：高）

在此场景中， 模拟攻击者通过发送潜伏了勒索软件病毒的电子邮件进行攻击。 

参加人员需要调查整个攻击的过程， 想办法通过相关安全工具来防止攻击的再次发生， 并最终为整个攻击过程进行画像。

由于本次靶场演练活动需要用户动手实操， 请参与演练的客户自行随身携带笔记本电脑，基本要求如下：

CPU: i5或以上

内存: 8GB或以上

硬盘: 100GB 磁盘空余空间以上

网卡：Wifi 和有线网卡

操作系统：Windows7 SP1或以上

软件要求：OpenVPN(可参看下面的下载地址) 和 Mircrosoft RDP，浏览器IE11/Chrome/Firefox
