**海底捞包间内装摄像头引争议 **

**网友：侵犯隐私吗**

据央广网报道，日前，一则“海底捞在包间里安装摄像头”的消息，引发网友热议。**有媒体走访了海底捞多个门店包间，发现确实安装了摄像头**，对于安装摄像头是否会侵犯隐私网友各执一词。关于此事，海底捞曾公开回应称：

![](../Images/2a2fba3715d397bc2e9bf24856a26778.png)

  

为保障消费者用餐安全，各门店会结合门店特点安装监控设备，包括包间。同时，海底捞注重保护顾客隐私，公司对监控管理设有相关的制度、流程，同时通过技术手段强化管控，保障消费者权益。有记者进一步采访其安装摄像头的必要性时，截至发稿时，海底捞方面暂时没有回应。对于安装摄像头是否会侵犯隐私网友各执一词。不接受包间摄像头的网友认为：此举会泄露消费者隐私，毕竟选择包间就是为了能有一个私密空间，但是有摄像头会有一举一动被监视的感觉。也有网友认为：餐厅包间再私密也是公共场所，只要摄像头亮在明处，没有什么不能接受的。有律师解读，如果部分海底捞门店在未告知消费者的情况下，在包间安装摄像头，则涉嫌侵犯消费者的隐私。你怎么看？

**强化医疗隐私保护**

**让患者免于“裸奔之忧”**

![](../Images/26b2aa6dbd2f9115f25bf94426d7f340.png)

据媒体报道，2021年全国“两会”召开在即，民进中央将提交提案，**建议加强患者医疗数据的隐私保护和数据安全管理**。提案称，应加强访问者的权限控制和访问后的行为追溯，对访问行为实行实时监控，确保数据安全和患者隐私，并研究制定医疗数据安全相关条例，保障数据全生命周期安全。  

看病过程中，难言之隐被当众讲出，**或者检查身体被突然闯进诊室的其他患者撞见，无疑是件尴尬事**。而那些产妇和婴儿信息被倒手卖出，或敏感妇科疾病甚至艾滋病诊断结果被公示在医院的电子屏幕上等情况，则更让人难以接受——看一次病，相当于隐私裸奔一次，这让不少患者感到闹心。

不可否认，医疗数据是个富矿，互联网诊疗、远程会诊、AI医生、共享病历、检查结果互认等，都需要收集和交流医疗数据。医疗信息共享有利于降低医疗成本、提高医疗质量，但信息开发和隐私保护不能顾此失彼。

就当下看，医院信息化建设加速，电子处方、电子病历等新事物层出不穷，但有些规则和制度难以跟上进度，导致部分信息成为脱缰之马。此外，部分医院各自开发信息系统，信息互相不兼容，难以制定统一有效的信息保护措施。**而黑客盗取数据、勒索病毒入侵内网等，也会对患者的医疗隐私构成威胁。**

近年来，在数据安全和隐私保护方面，相关措施出台了不少。2016年6月，国务院办公厅下发**《关于促进和规范健康医疗大数据应用发展的指导意见》**，明 确要规范和推动健康医疗大数据融合共享、开放应用，妥善处理应用发展与保障安全的关系，有效保护个人隐私和信息安全。同年9月，**《电子病历与医院信息平台标准符合性测试规范》**发布，力求用测试与考评来推进医疗信息标准化建设。2020年10月，国家卫健委出台**《关于加强全民健康信息标准化体系建设的意见》**，在技术和管理等层面规范流程、统一标准。

但数据安全和隐私保护不能只有“粗线条”，细致的管理规范与行为约束有待出台。

医院信息系统如何建设，信息后台监管、防堵、纠错怎么实施，平台登录和信息修改发布权限如何限制、访问行为如何留痕和追溯，甚至病历怎么共享、处方怎么流转、远程会诊的信息如何传输等，这些工作细节都有待进一步明确。全国两会提案关注此议题，利于通过制度建设，化解这个民众普遍关注的问题。

**个人隐私的内容很多，但医疗信息由于涉及患者身体与疾病等隐私，比身份、财产、社会关系等其他个人信息更加敏感，泄露的杀伤力更大。**

医疗信息化建设的油门要下力猛踩，但信息安全的刹车也必须十分灵敏。这样才能更好地趋利避害，使患者既能享受医疗信息化带来的便利性，也能避免医疗隐私泄露带来的风险。

**谷歌建议用户立即升级 Chrome 88 最新版：修复重要安全漏洞**

对于谷歌浏览器（Google Chrome），相信很少有用户不知道，它可是**占据了市场上 60% 以上的份额**。此前微软基于 Chromium 的 Edge 浏览器超过了 Mozilla Firefox **浏览器排到了第二**，新的微软 Chromium 版本 Edge 浏览器升级非常迅速，对很多功能都能迅速地进行增加。

![](../Images/e9af0426e2e3c31889ce184eb2c38d0f.png)

  

而目前来讲，更新到谷歌浏览器 Chrome 的最新版本这件事是很重要的，因为在本周四谷歌在发布的 88.0.4324.150 版浏览器中**修复了一个漏洞**，并声称该漏洞正被**广泛利用**。要知道的是，这个更新现在正在 Windows、Mac 和 Linux 上进行推广。其中，谷歌并没有提供有关 CVE-2021-21148 漏洞的具体细节，“直到大多数用户更新了修复程序。”但有媒体指出，谷歌称该漏洞于 1 月 24 日被报告的日期，也就是距离谷歌威胁分析小组公开披露黑客活动的前一天，**黑客活动似乎仍依赖于 Chrome 中一个未修补的漏洞**。不管修补的是哪个 BUG，确保运行的是最新版本的 Chrome 都比平常任何时候更重要。虽然浏览器的更新过程基本上是自动的，但是你可以在 “About Google Chrome”菜单中加速更新。除了上述更新外，Chrome 88 还是很值得升级的，新版本浏览器在启动、响应速度上更快，同时 CPU 占用率大幅下降。比如，提供前进后退缓存等特性，号称启动速度快了 25%、载入页面速度快了 7%、CPU 占用减少了 5 倍、可增加额外 1.25 小时续航等。也就是说，Chrome 88 将大量节流后台标签中的 Java 定时器操作，以提高性能并减少 CPU 和 RAM 的使用。就谷歌浏览器功能，此前我们知道它有这些特性：该浏览器追求的是全方位的高速体验。它可以快速地从桌面上启动，并能迅速加载网页等。其窗口采用了清爽简洁的流线型设计。Chrome 浏览器通过一些功能为您提供更加安全的上网体验。比如内置的恶意软件和网上诱骗防护功能、自动更新等。**Chrome 能够让您控制自己的隐私信息，同时还能帮助保护您在网上共享的信息。**您可以通过各种各样的方法来自定义 Chrome 浏览器，从而享受独一无二的体验。无论是更改设置，还是从 Chrome 网上应用商店添加应用、扩展程序和主题背景 ......在 1 月，谷歌浏览器稳定版更新至 88.0.4324.96 版本时，新的谷歌浏览器改进了深色主题支持，停止了对 FTP 的支持，还需要注意的是，**该版本停止了对 Mac OS Yosemite 的支持。**而详细更新内容如下，改进深色主题支持，停止对 FTP 的支持，停止对 Mac OS Yosemite 的支持，结束对旧版浏览器附加组件的支持，减少请求许可干扰，优化适用于 Chrome OS 的浅色和深色模式，Tab Seach 可用，以及其他改进。目前，**谷歌 Chrome 不管是桌面端还是移动端都是占据主导地位的网络浏览器**，它已经是大多数手机和平板电脑的默认浏览器。由于 Chrome 大部分都是开源的，而 Android 上的其它大多数浏览器都使用这种开源基础，因此 Chrome 的绝大多数功能最终都会在其它应用中重复。根据调查统计机构 Netmarketshare 发布的消息显示，2020 年 4 月份全球浏览器份额排名第一的是谷歌 Chrome 浏览器，排名第二、第三的分别是微软 Chromium 版 Edge 浏览器和 Firefox 浏览器。具体情况则是：谷歌 Chrome 浏览器市场份额从 68.5%增长到了 69.18%，依旧稳居第一；微软 Chromium 版 Edge 浏览器市场份额从 7.59%增长到 7.76%；而 Firefox 浏览器，从 7.19%增长到 7.25%。现阶段，谷歌 Chrome 浏览器的市场统治地位达到了历史较高水平，距离 70%的市场份额仅一步之遥。另外，由于微软 Edge 浏览器是采用 Google 的 Blink 引擎，基于 Chromium 打造出来的，它与谷歌 Chrome 浏览器属于同源关系。整体来看，谷歌 Chrome 浏览器、微软 Chromium 版 Edge 浏览器、Firefox 浏览器在保持较大市场份额的基础上，在进一步挤压其他浏览器的生存空间。据了解，就智能手机而言，Android 手机可能有两种默认浏览器：三星互联网 (Samsung Internet)和谷歌 Chrome。三星互联网是基于 Chrome 的，但它有一个完全定制的界面，符合三星的一个用户界面设计语言。与 Chrome 相比，它的一些优势包括：跟踪保护、有限的附加组件选择，以及更易于在高配手机上使用的按钮布局。而在苹果手机上面，所有第三方浏览器都需要使用 Safari 浏览器渲染引擎，相比谷歌，则允许将任何 Web 浏览器引擎发布到 App 商店提供给安卓手机安装使用。
