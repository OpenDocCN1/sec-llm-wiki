招聘职位

安全工程师（2 位）

**薪水****面议**

![](../Images/d40ce9f4d4add42c91726d0274cf938b.png)

**岗位职责**

*   负责应用系统（web、app、小程序、公众号、sdk）的安全测试、提出修复建议或解决方案，并推动研发整改；
    

*   对违规数据泄漏及攻击场景进行溯源分析处置，对安全问题和事件进行跟踪、分析，快速定位问题和解决；
    

*   推进纵深防御体系建设，参与 SDL 流程在公司落地。
    

**岗位要求**

1、 良好的计算机基础，熟悉操作系统，网络基础原理，熟悉 TCP/IP、HTTP 等协议；

2、 对 WEB 应用和移动端应用安全攻击和防御有深刻理解，熟悉漏洞原理及发掘和利用方法；

3、 具备较好的逻辑分析能力，良好的沟通表达及协调能力；

4、在各类安全平台发布优秀安全文章、SRC 平台挖洞排名靠前、CTF 比赛取得名次、参与 hw 活动取得名次或提交 CVE 漏洞者优先考虑。
