# 面对AI时代的诸多全新挑战，百度安全始终致力整合各界力量，搭建演练平台，输出前沿经验。但安全能力的提升不仅需借助虚拟网络空间内的攻击与防守演练，更离不开真实场景下的实战测试，2019年“第一届百度大学生网络安全技能大赛”，也基于此背景举办，活动得到各大高校同学的鼎力支持，得以圆满完成！

#   

# 此外，**2020年“第二届百度大学生网络安全技能大赛”**即日起正式启动，大赛设立丰厚现金及额外奖励，欢迎各大高校同学踊跃报名参加。

  

**比赛规则**

本次比赛均为线上漏洞挖掘赛，参赛选手发现任何百度系安全漏洞及安全情报，提交至百度安全应急响应中心平台（https://bsrc.baidu.com），计算分值；总分由基础分值与额外加分两部分构成，基础分值为比赛所提交的漏洞及情报的评分（安全币）为分数（评分规则请参考百度安全应急响应中心评分规则），额外加分细则（均为团队分数）如下：

![](../Images/c3dc8248578e77bbcae5929a4ef37d4e.png)

  

**报名范围**

大赛采取高校团体组队参赛和非高校团体报名参赛的方式，团队须满足4-15名成员的条件。**高校团体：**全国全日制普通高校（含本科类院校、高职类院校等）均可组队报名参加。

  

**报名方式**

**高校团体报名：**以高校为单位，队长组成4人以上的团队，由1名队长带领参赛，高校按照比赛通知要求填写《百度大学生网络安全技能大赛高校团体/个人报名表》，并邮件提交至百度安全应急响应中心邮箱（security@baidu.com）。**在校学生个人报名：**以个人为单位，由主办方促成高校组为单位队伍，若所在高校参赛选手少于4人，则由主办方建议的方式组成高校联合战队（自愿），联合战队成员数12人封顶。个人报名按照比赛通知要求填写《百度大学生网络安全技能大赛高校团体/个人报名表》，并邮件提交至百度安全应急响应中心邮箱。

注：若不知道所在高校是否有参赛队伍，可与主办方取得联系咨询，若所在高校无参赛队可自荐成为队长。

  

**奖励设置**

除百度安全应急响应中心日常奖励外，设置优胜团队奖、优秀个人奖、校园大使推荐奖，比赛结束后，将现场为获奖人员和团队颁发以下奖项及奖金：高校团体设置**团队奖项****第一名至第五名**，合计五个；团队奖励即所有参赛队伍中总分前五名的队伍；学生个人设置**个人奖项第一名至第五名**，合计五个；

个人奖为所有参赛成员中，团队个人所获得的基础分值前五名，不涉及加分项；

校园大使设置**比赛推广第一名至第三名**，合计三个；校园大使第一名至第三名需推荐至少三个高校队伍参赛。
