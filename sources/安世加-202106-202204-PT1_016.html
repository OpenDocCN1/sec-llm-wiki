2022年3月25日，由安世加主办的第三十二期沙龙之企业网络安全在线上成功举办！本次沙龙共吸引了超过200位安全专家，安全负责人报名参加，沙龙围绕《安全运营》、《打造一站式测试平台，启动数字转型之旅》、《云原生网络安全》、《浅谈终端供应链安全及入侵对抗切入面》、《企业低成本自研安全平台实践》这些安全热点话题，通过嘉宾精彩的演讲，为与会者提供了更多可落地的实践与经验的分享。

Lee

企业：某餐饮公司

职位：Senior Security Manager

首位演讲嘉宾是来自某餐饮公司的Senior Security Manager Lee，从业10多年，就职甲、乙方多家公司，在信息安全建设、信息安全管理体系建设、网络系统安全集成、应用安全领域。近3年从事餐饮行业，之前都以金融、互联网行业。持有DPO、CISSP、ISO27001LA COBIT、PMPCCIE-RS、CCIE-SEC认证。他带来的演讲主题是《安全运营》。

主要内容包括：

一、安全大背景：介绍现在安全发展方向，安全背景

二、安全运营的切入：如何快速在企业中切入安全、快速建立安全运营思路

三、安全运营的阶段建设：

初期：标准、设备

中期：监控、响应

后期：自动化

四、餐饮特殊的安全关注：门店/工厂

五、未来的安全运营趋势：大数据、合规化、共享化

李晔

企业：HCL

职位：Secure DevOps专家

第二位演讲嘉宾是来自HCL的Secure DevOps专家 李晔，李晔拥有近30年IT从业经验，职业生涯与Secure DevOps的发展成熟不谋而合。涉足过软件全开发生命周期所有环节。在IBM工作过10多年，主要负责IBM Rational配置管理、自动化测试等相关产品的技术支持。他带来的演讲主题是《打造一站式测试平台，启动数字转型之旅》。

在敏捷开发的风潮之下，软件版本的迅速迭代无疑带给了测试人员巨大的压力。近来公布的个人信息保护法和数据安全法，让测试人员也意识到安全测试的重要性与严重性。如何打造一个兼顾单元和集成、功能和性能、动态Web应用漏扫、静态代码审计的自动化测试平台，已经是管理者优先要考虑的问题。

汪东

企业：极氪汽车

职位：网络安全负责人

第三位演讲嘉宾是来自极氪汽车的网络安全负责人 汪东。汪东有信息安全从业14年，及多年信息安全管理工作经验，在金融证券，制造行业的信息安全工作建设方面落地经验丰富，对于网络安全、数据安全、工控安全等领域有深刻理解，持有CISSP、CISP、CCIE等认证。他带来的分享主题是《云原生网络安全》。

云原生技术已成为驱动业务增长的重要引擎。逐渐在人工智能、大数据、边缘计算、 5G 等新兴领域崭露头角。伴随各行业上云的逐步深化，云原生化转型进程将进一步加速，而传统安全工具已无法满足云原生需求。


大纲：

1、云原生化的转变；

2、云原生安全体系；

3、云原生的防御：基础，集群，容器，代码。

傅偲珏

企业：货拉拉

职位：办公安全运营专家

第四位演讲嘉宾是来自货拉拉的办公安全运营专家 傅偲珏。某乙方应急支撑部门出身，具有丰富的一线入侵对抗、应急响应、HW攻防演练及APT对抗经历，擅长以最短路径解决入侵问题。现任货拉拉办公网对抗能力建设，自研EDR产品规划及规则运营。他带来的分享主题是《浅谈终端供应链安全及入侵对抗切入面》。

终端安全作为攻防双方的兵家必争之地，近期呈愈演愈烈趋势。前有MacOS Navicat投毒事件，终端软件供应链安全如何收敛？后有乌克兰政府 APT MBR擦除事件，办公安全如何保证？本次分享将由终端软件供应链安全为始，以red team最火权限维持技术——白加黑利用检测进行展开，探讨红蓝双方对抗形式演变，及甲方APT、办公网入侵对抗切入面。

汤青松

企业：趣加Fun Plus

职位：安全架构师

第五位演讲嘉宾是来自趣加Fun Plus的安全架构师 汤青松。汤青松是实体书《PHP WEB安全开发实战》作者，擅长企业安全建设，SDL安全建设。PHPCon 2020 第八届 PHP 开发者大会分享《PHP安全编码规范与审查》，NSC 2019第七届中国网络安全大会分享《PHP反序列化漏洞分析实践》，看雪2018 安全开发者峰会担任Web安全训练营 讲师，2017 看雪安全开发者峰会分享分享《浅析WEB安全编程》话题。他带来的分享主题是《企业低成本自研安全平台实践》。

企业安全工作大多围绕安全建设和合规化，对内部系统做渗透测试和内外部的威胁感知比较多。通常自研安全产品工作量大，对于小规模甲方安全团队来说有些耗费精力，因此大多是选择用开源和破解版；本议题主要分享在甲方低成本的自研安全工具，以达到事半功倍的效果，包括资产收集、漏洞扫描器、代码审计、批量验证等。

最后感谢本次赞助商HCL、感谢所有演讲嘉宾及参会者的支持与付出，同时感谢机械工业初版社华章分社的支持，希望大家能在沙龙中有更多的收获与得着。
