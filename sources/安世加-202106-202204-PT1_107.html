2022年1月14日，第三十期安世加沙龙之杭州站在杭州钱潮开元酒店成功举办！

本次沙龙共吸引了超过30位安全专家及安全从业人员参与。沙龙一起探讨分享了《网络安全攻防推演》、《零信任实践之TDNA网络接入》、《基于微隔离的数据中心零信任实践》、《企业安全建设实践》、《企业应用安全实践》、《水平越权漏洞检测的探索及实践》、《企业数据安全风险管控建设》等热点议题，旨在为行业提供更多的实践与经验的借鉴。



网络安全攻防推演

童将 / 安全总监 / 某支付公司

首位演讲嘉宾是来自某支付公司的安全总监 童将。他分享的主题是《网络安全攻防推演》。

本次演讲围绕企业自身的攻防演练实践进行，包括背景环境的介绍、实网攻防与渗透测试、风险评估的区别、攻防演练方法论等内容。

零信任实践之TDNA网络接入

吕刚超 / 安全顾问 / 联软科技

第二位演讲嘉宾是来自联软科技的安全顾问 吕刚超，他分享的主题是《零信任实践之TDNA网络接入》。

移动工作、业务云化大幅度提升了业务效率，但也使得企业网络边界越来越模糊，更多的个人设备参与到企业办公及流程当中，给网络信息安全带来了严重挑战，传统以边界安全为核心的防御体系成为了业务效率发展的制约因素。本次分享基于零信任的成熟应用，帮助企业逐步构建一套符合当前及未来业务发展的安全接入架构，以安全能力保障和促进企业的业务发展。

基于微隔离的数据中心零信任实践

王海峰 / 高级产品专家 / 蔷薇灵动

第三位演讲嘉宾是来自蔷薇灵动的高级安全专家 王海峰。他分享的主题是《基于微隔离的数据中心零信任实践》。

在全球抗击疫情及企业数字化转型的双重驱动下，零信任理念得以加速推广并落地。同时，数据中心内部的东西向流量始终是安全管控的薄弱环节，本议题将介绍如何通过微隔离对数据中心东西向流量实现基于身份的访问控制，从而实现数据中心零信任的落地。

企业安全建设实践

郭水平 / 安全经理 / 每日互动

第四位演讲嘉宾是来自每日互动的安全经理 郭水平。他分享的主题是《企业安全建设实践》。

本次演讲分为三部分，第一部分介绍了做好企业安全建设需要清晰掌握三个基本的知识点：背景、目标、业界方法论，确保正确的做事，最短路径、最小成本实现安全目标；第二部分介绍了每日互动安全体系产品框架级落地进展，细分的介绍了数据安全体系的实现方式及身份认证中心、数据交换平台等产品的建设情况；第三部分介绍了安全评价的维度等。

企业应用安全实践

黄龙 / 应用安全负责人 / 网易安全中心

第五位演讲嘉宾是来自网易安全中心的应用安全负责人 黄龙。他分享的主题是《企业应用安全实践》。

SDL是大家最为熟知的安全工作之一，也是应用安全的核心工作。本次分享主要和大家聊一聊在应用安全工作中的一些落地经验，包括从大家熟悉的SDL工作，到DevSecOps，再到红蓝对抗以及纵深防御体系建设相关的工作。同时也会和大家探讨一下从目标/方向以及更高一层的视角，如何去更好的实施应用安全工作，去提升团队的价值和工作效率等实际经验。

水平越权漏洞检测的探索及实践

朱浩文 / 高级安全工程师 / 蚂蚁集团

第六位演讲嘉宾是来自蚂蚁集团的高级安全工程师 朱浩文。他分享的主题是《水平越权漏洞检测的探索及实践》。

随着各家企业安全水位的提高，传统的常规漏洞可以被较好的收敛后，业务逻辑类漏洞的问题就显得比较突出。在业务逻辑类漏洞中水平越权漏洞的数量更是占据各家互联网企业其中的大头，为了改变这个现状，各企业的安全部门都做了大量的尝试。网商银行信息安全部将分享根据水平越权产生的特征进行该类漏洞检测与发现的一些探索和实践，此外也将分享其在应用业务类漏洞发现能力的建设思路。

企业数据安全风险管控建设

武天旭 / 安全专家 / 微医集团

第七位演讲嘉宾是来自微医集团的安全专家 武天旭。他分享的主题是《企业数据安全风险管控建设》。

数据安全是企业信息安全体系建设的重要组成部分，而对数据的风险管控则是数据安全建设中的重要一环，科学的风险管控方式不但要及时识别风险所在，还应能精准判断风险级别，同时对不同风险采取不同处置措施，从而助力提高数据安全的建设成效。
