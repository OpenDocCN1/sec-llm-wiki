# 技术干货 | CVE-2021-44228: Apache Log4j 远程代码执行严重漏洞利用在野 (Log4Shell)

流行的日志库Apache Log4j2 中的严重漏洞影响了全球的许多服务和应用程序，包括 Minecraft,Didi,Baidu,Twitter,Amazon,Tesla,Apple等众多国内外知名公司。攻击者已开始积极扫描并试图利用该漏洞。  

**![](../Images/229a5da41d140c20f22950562b3f6848.png)**

**背景**

12月9日，研究人员发布了Apache Log4j2 中一个严重漏洞的PoC利用代码，Apache Log4j2 是一个Java 日志库，被许多应用程序和服务使用，包括但不限于：

*   Apache Druid
    
*   Apache Flink
    
*   Apache Solr
    
*   Apache Spark
    
*   Apache Struts2
    
*   Apache Tomcat
    

该漏洞被研究人员称为 Log4Shell，起源于有报道称流行的视频游戏 Minecraft 的多个版本受此漏洞影响。

![](../Images/bc90a04a2f3364f308e62c411c712dac.png)

此外，Steam 和 Apple iCloud 等云服务也受到影响。该漏洞被认为非常严重，以至于 Cloudflare CEO 计划为所有客户提供保护。

![](../Images/f6d857c7bac53aa37e4d82e19b30dcab.png)

**![](../Images/229a5da41d140c20f22950562b3f6848.png)**

**分析**

**CVE-2021-44228 **(CNTA-2021-0032)是Apache Log4j2 中的远程代码执行 (RCE) 漏洞。未经身份验证的远程攻击者可以通过向运行有漏洞的 log4j 版本的服务器发送特制请求来利用此漏洞。精心设计的请求通过各种服务使用 Java 命名和目录接口 (JNDI) 注入，包括：

*   轻量级目录访问协议 (LDAP)
    
*   安全 LDAP (LDAPS)
    
*   远程方法调用 (RMI)
    
*   域名服务 (DNS)
    

如果易受攻击的服务器使用 log4j 来记录请求，则漏洞利用将通过上述服务之一从攻击者控制的服务器通过 JNDI 请求恶意负载。成功的利用可能会导致 RCE。

就 Minecraft 而言，用户可以通过 Minecraft 聊天发送特制消息来利用此漏洞。

![](../Images/df6be9d1fdb188346c3902a7c2bb2d6e.png)

GreyNoise 和 Bad Packets 都检测到使用Log4j 搜索服务器的大量扫描活动。

![](../Images/3b34ab3bcd1727318a6a2a3ca5501b26.png)

现在有报道称该漏洞正也被用于植入挖矿木马。

![](../Images/229a5da41d140c20f22950562b3f6848.png)

**解决方案**

虽然 Apache 在12月6日发布了一个候选版本来解决这个漏洞，但它并不完整。Apache 已于12月10日发布了 2.15.0正式版。

Log4j 2.15.0 需要Java 8，因此使用Java 7的企业需要先升级才能更新到 Log4j 的补丁版本。

Apache 建议，如果无法立即修补，可以采取三种缓解途径来阻止利用此漏洞的尝试：
