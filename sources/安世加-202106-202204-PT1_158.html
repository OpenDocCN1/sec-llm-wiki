第二十九期沙龙

2021年12月10日，第二十九期安世加沙龙之广州站在广州中心皇冠假日酒店成功举办！

本次沙龙共吸引了超过30位安全专家及安全从业人员参与。沙龙一起探讨分享了《企业SDL安全落地与实践经验》、《企业零信任安全架构实践》、《构建应用数据安全主动防御体系》、《基于社区的企业安全服务平台》、《邮件防线的攻防研究实践》、《供应链安全甲方互联网RASP应用实践》、《软件安全能力成熟度模型》等热点议题，旨在为行业提供更多的实践与经验的借鉴。

企业SDL安全落地与实践经验

潘陈粮 / 安全项目经理 / 东风日产

首位演讲嘉宾是来自东风日产的安全项目经理 潘陈粮。他分享的主题是《企业SDL安全落地与实践经验》。

本次主题主要介绍东风汽车SDL安全落地与实践的经验探索，内容包括SDL标准流程体系化的建立、SDL人员安全培训、安全需求与设计落地（主要包括安全功能设计与安全业务设计、安全架构设计）、企业威胁建模实施、自动化安全工具对接、SDL平台流程对接、自动化安全运营、知识库沉淀等。

企业零信任安全架构实践

廖敏超 / 资深安全顾问 / Palo Alto Networks

第二位演讲嘉宾是来自Palo Alto Networks的资深安全顾问 廖敏超，他分享的主题是《企业零信任安全架构实践》。

本次演讲主要分为三个部门，1、风险的不同角度理解, 讲述不同角度的安全风险理解与当前的安全状况；2、构建零信任的主要因素:讲述零信任实现所需重点因素；3.、最佳落地实践：讲述零信任的实现思路与最佳实践。

构建应用数据安全主动防御体系

郑泽文 / 高级安全顾问 / 瑞数信息

第三位演讲嘉宾是来自瑞数信息的高级安全顾问 郑泽文。他分享的主题是《构建应用数据安全主动防御体系》。

随着《数据安全法》和《个人信息保护法》的相继实施，企业数据在面临各类安全威胁的同时，更受到了来自监管合规的巨大压力。然而很多企业当前在数据安全治理，尤其是数据安全体系建设上仍不知从何做起，数据安全亟需破局。

《数据安全法》中对于数据处理的定义包括收集、存储、使用、加工、传输、提供、公开，其中提供和公开是首次被纳入到数据处理过程中，是数据安全目前关注的重点，也是当前企业数据安全工作中较为薄弱的环节。瑞数信息的数据安全解决方案定位于“应用数据安全主动防御”，旨在解决数据在传输、提供和公开三个过程中的数据安全风险。传输过程中的主要风险是数据明文传输和中间人攻击；提供环节主要面临的风险是API敏感信息泄露和API数据爬取；数据公开则主要应对非授权访问、非受控访问、撞库攻击和数据爬取风险。

基于社区的企业安全服务平台

曾垚 / 联合创始人 / 火线安全

第四位演讲嘉宾是来自火线安全的联合创始人 曾垚。他分享的主题是《基于社区的企业安全服务平台》。

线上漏洞频繁出现，内部安全资源不足，无法应对频繁的应用上线，逻辑漏洞覆盖困难，漏洞发现成本越来越高。火线安全将分享如何通过优质的社区资源，帮助企业打造可持续化的安全风险发现能力，降低安全风险发现成本，以及如何构建漏洞自动发现能力，在上线前彻底解决通用漏洞。

邮件防线的攻防研究实践

陈秋雨 / IT网络安全负责人 / 荣耀

第五位演讲嘉宾是来自荣耀的IT网络安全负责人 陈秋雨。他分享的主题是《邮件防线的攻防研究实践》。

今年第三季度全球因网络钓鱼引起的攻击事件超过26万起，几乎是去年同期的2倍，钓鱼邮件攻击不管在真实攻击还是红蓝演练中，始终是攻击方最喜欢、性价比最高的攻击方式，那么今年的钓鱼攻击有哪些新的特点呢？我们防守方应该怎样从事前、事中、事后有效地去防御和检测这种攻击呢？我会在议题中和大家分享我的实践，并和大家一起学习和探讨。

供应链安全甲方互联网RASP应用实践

廖翰晖 / 应用安全负责人 / 豌豆思维

第六位演讲嘉宾是来自豌豆思维的应用安全负责人 廖翰晖。他分享的主题是《供应链安全甲方互联网RASP应用实践》。

本次演讲类举拦截案例，以财务系统真实攻击拦截作为分享，通过对rasp防护实践分享沟通交流的经验，如何让业务部门和开发部门接受rasp对未知漏洞防御的心路历程。以shiro等反序列化漏洞的细节进行防御以及如何修改js抵御未知漏洞。结合实践经验以供应链安全的防护实现，达到对未知漏洞的防御思想。通过rasp的防御思维，展望rasp技术在供应链安全的思想。

软件安全能力成熟度模型

林伟壕 / 高级安全工程师 / 腾讯

第七位演讲嘉宾是来自腾讯的高级安全工程师 林伟壕。他分享的主题是《软件安全能力成熟度模型》。

本次分享围绕软件安全能力成熟度模型的价值、选型、具体实施以及实施后的经验总结展开，首先业界对这类模型的价值是存在争议的，但从大多数实践的情况来看，其价值值得肯定，其次，没有完美的模型，目前主流模型各有缺陷，根据具体实际情况微调足以指导应用安全体系建设，最后，实施过程中存在一些最佳实践可确保模型高效运转。
