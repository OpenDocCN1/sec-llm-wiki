**第二十八期沙龙**

**2021年9月10日**，第二十八期安世加沙龙之金融行业安全实践在**北京亮马河饭店**成功举办！

本次沙龙共吸引了**近40位**安全专家及安全从业人员参与。沙龙一起探讨分享了**《网络安全防御措施》**、**《Web安全在实战中技战法》**、**《众测服务的最新实践》**、**《安全实践之技盟安全交付平台》**、**《数据安全建设的取与舍》**、**《全球化下隐私管理合规实践》**、**《数字化时代银行信息安全实践与展望》**等热点议题，旨在为行业提供更多的实践与经验的借鉴。

**网络安全防御措施**

**薛辉 / 金融科技部信息安全负责人 / 中国人寿养老保险**

![](../Images/54dd09c81706fb71a3f5db39c9d2e654.png)

首位演讲嘉宾是来自**中国人寿养老保险金融科技部**的**信息安全负责人 薛辉**。她分享的主题是**《网络安全防御措施》**。他的分享主要包括四个方向：

1、信息安全体系建设目标；

2、攻防演习防御手段；

3、系统开发安全管控；

4、数据安全管控等。

**Web安全在实战中技战法**

**路笑凡 / 中国区技术顾问 / Imperva**

![](../Images/cdb2df909945674f236314fd7c11e189.png)

第二位演讲嘉宾是来自**Imperva**的**中国区技术顾问 路笑凡**，他分享的主题是**《Web安全在实战中技战法》**。

大数据时代，信息安全正在成为全球焦点话题。无论是个人信息、商业机密，还是应用程序开发中的API，信息与数据安全的保护至关重要，一旦遭到Web应用程序攻击，那么必然会导致数据与信息安全风险的爆发。Imperva 一直都见证着web应用安全的发展和变化，通过多年客户实际环境经验积累，讲解Web应用安全需要重点防护场景。

**众测服务的最新实践**

**邬迪 / 创始人 / 火线安全**

![](../Images/234328d4f4ebf3550ff18f988e6d6ddb.png)

第三位演讲嘉宾是来自**火线安全**的**创始人 邬迪**。他分享的主题是**《众测服务的最新实践》**。

“众测”作为一种新型的安全服务在2012年被首次推出，如今已成为很多企业开展安全测试工作的标配。在攻防新常态下，众测的服务和运营还有哪些可以探索和提升的空间？火线平台的负责人将与各位共同分享过去18个月的一些实践。

**安全实践之技盟安全交付平台**

**张宏明 / 高级技术顾问 / Gigamon**

![](../Images/19d99ba2d502fd2bc1c295abf5651bca.png)

第四位演讲嘉宾是来自**Gigamon**的**高级技术顾问 张宏明**。他分享的主题是**《安全实践之技盟安全交付平台》**。

专注于流量可视化平台建设，是安全产品发布平台的最佳实践，提供基于物理网络，虚拟化，容器、云平台等环境的流量采集解决方案，并且还可以为安全产品的串接部署提供可按需编排的解决方案，是一个为客户提供全面的基于流量可视与编排的整体解决方案提供商。通过技盟的安全发布平台能够让安全产品按需发布，弹性可扩展，不仅能帮助优化安全产品在采集流量、按需编排、弹性扩展安全资源池等方面的精细化运维，还能够帮助客户在安全扩展时确保预算可控、可持续。

**数据安全建设的取与舍**

**刘衍斐 / 安全总监 / 某金融公司**

![](../Images/5fe936660641c3feae46c09f8541ec25.png)

第五位演讲嘉宾是来自**某金融公司**的**安全总监 刘衍斐**。他分享的主题是**《数据安全建设的取与舍》**。

在数字化转型和数据安全强监管的背景下，围绕数据安全风险管控与合规建设中的挑战，从不同视角分享对数据安全建设的观点思考，探讨在企业中如何规划和有效落地数据安全，探索适用于金融企业的数据安全建设思路。

**全球化下隐私管理合规实践**

**张杰 / 安全总监 / 老虎证券**

![](../Images/f7a4251d7950281a15e4f7a2d024c91d.png)

第六位演讲嘉宾是来自**老虎证券**的**安全总监 张杰**。他分享的主题是**《全球化下隐私管理合规实践》**。

出海的跨国企业面临管理多国公民数据的业务场景。在当前各国隐私法陆续发布，世界进入隐私强监管时代，跨国企业如何高效安全合规的管理这些隐私信息成为了高风险的难题，需要安全和法务共同解决。

**数字化时代银行信息安全实践与展望**

**袁靖 / 数据安全负责人 / 中国民生银行**

![](../Images/c6263b9dca422eac2c077a31667d0a25.png)

第七位演讲嘉宾是来自**中国民生银行**的**数据****安全负责人 袁靖**。他分享的主题是**《数字化时代银行信息安全实践与展望》。**主要包含三个方向：

1、当前网络安全形势的变化；

2、网络攻防对抗下的防御体系建设；

3、网络安全工作下一步展望。

**小组讨论：金融行业安全实践方法论**

**张杰 / 安全总监 / 老虎证券**

**薛辉 / 金融科技部信息安全负责人 / 中国人寿养老保险**

**袁靖 / 数据安全负责人 / 中国民生银行**

![](../Images/6c9d48926d10fb7046f66aaa03bcf2db.png)

最后由来自**老虎证券**的**安全总监 张杰**、来自**中国人寿养老保险金融科技部**的**信息安全负责人 薛辉**、以及来自**中国民生银行**的**数据安全负责人 袁靖**的小组讨论环节。三位嘉宾就当前最新颁布的《数据安全法》，《个人信息保护法》及金融行业红蓝对抗等热点议题发表了各自的观点，为与会者提供了有力和实践借鉴。
