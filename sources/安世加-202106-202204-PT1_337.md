**招聘职位**

  

  

**安全工程师(蓝军对抗方向)  **

工作地点：⼴州/北京

岗位职责： 

1、参与系统安全测试与红蓝对抗； 

2、协助研发修复漏洞与应急响应； 

3、漏洞情报研究。 

任职要求： 

1、2022届本科及以上学历，计算机相关专业； 

2、熟练掌握常⻅的应⽤安全漏洞原理； 

3、了解系统安全机制及⽹络协议特点； 

4、至少掌握python/java/go/bash等⼀⻔语⾔；

5、有CTF比赛或SRC挖洞经验者优先。

  

![](../Images/49bc3dd42227612a0665ff05b3824c73.png)

  

  

**安全工程师(运营管理方向）**

工作地点：广州 

岗位职责： 

1、负责公司安全门户的运营，流程设计；2、负责公司SRC的运营：活动宣传,漏洞闭环推进等； 

3、负责企业内部安全标准化、合规与安全管理等。

  

任职要求： 

1、2022届本科及以上学历，计算机、⽹络、信息技术等专业优先； 

2、有基本的信息安全概念； 

3、具备较强的沟通能力； 

4、有UI设计经验者优先。

  

![](../Images/49bc3dd42227612a0665ff05b3824c73.png)

  

  

**安全工程师(安全开发方向）**

工作地点：广州/北京 

岗位职责： 

1、参与安全平台后端开发⼯作； 

2、参与安全检测模块开发，扫描器、⼊侵检测、流量监测等； 

3、参与安全开发⽣命周期研发和治理⼯作。

  

任职要求： 

1、熟悉spring mvc，spring boot，mybatis， mysql，redis 等框架与组件的使⽤和开发，能独⽴使⽤ java 开发后端应⽤，了解常⽤的设计模式、io、多线程等知识； 

2、熟悉shell、python 等⼀⻔脚本语⾔的开发，熟练使⽤ linux 系统命令； 

3、扎实的计算机基础知识，深⼊理解数据结构、算法、操作系统、密码学等知识，有强烈的求知欲，主动性强，有安全⽅向发展的职业规划。
