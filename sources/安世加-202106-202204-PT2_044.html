安世加走进平安


随着DT时代的到来，数据的地位越来越高，其流动也越发频繁，数据除了给企业的业务带来巨大的机遇之外，对企业的安全部门也提出了更高的挑战。

2021年6月10日，十三届全国人大常委会第二十九次会议通过了数据安全法，它确立了数据分类分级管理，数据安全审查，数据安全风险评估、监测预警和应急处置等基本制度。数据安全的重要性达到前所未有的高度。

为了提升行业的整体素质，助推安全生态圈的健康发展，安世加在7月16日，与众安全大咖一起携手走进平安，就数据安全实践这个热点话题，进行了一次深入的探讨与交流。

14:00-14:45 

王超 / 安全总监 / 爱奇艺

数据安全治理

来自爱奇艺的安全总监 王超是首位分享交流的嘉宾，王超负责爱奇艺的隐私合规、数据安全、网络攻防、应用安全、云原生和零信任等安全领域的技术创新和项目实施，获CISSP，CISA，ITIL等认证。

他分享的主题是《数据安全治理》。介绍了爱奇艺数据安全方面对外参与制定及试点国家行业标准的一系列工作，对内一站式安全合规管理工作，如何将APP隐私安全和业务线CICD发版流程集成。拆解数据安全在分级、分类、来源、存储的不同风险点，通过流程，技术等多种手段闭环收敛风险。

14:45-15:30 

刘琦 / 数据安全负责人 / 网商银行

大数据时代，数据与隐私安全实践探索

第二位嘉宾是来自网商银行的安全负责人 刘琦。刘琦负责数据安全能力建设与隐私安全；曾担任普华永道信息安全顾问。

他分享的主题是《大数据时代，数据与隐私安全实践探索》。大数据时代，数据与隐私安全的监管环境趋严、变化加速。满足监管条例与行业标准的前提下，如何平衡安全、体验与效率，是每个企业/安全团队均在探索的问题。在常见数据安全能力（分类分级，风险审计）的基础上，如何进阶到下一步，进行风险实时拦截，达到数据的默认安全。

15:30-16:00 

姜若芾 / 资深安全研究员 / 银河实验室

隐私合规快、准、稳（WON）！

第三位嘉宾是来自银河实验室的资深安全研究员 姜若芾。姜若芾专注移动安全领域的研究与相关工具的开发。移动应用监控系统”人马系统“GALAXY隐私合规检测系统负责人。

他分享的主题是《隐私合规快、准、稳（WON）！》。分享围绕银河实验室自研的隐私合规检测系统，如何快，准，稳地对移动应用进行隐私合规检测，工具常见问题处置。

16:00-16:15 

伍晨旭 / 安全工程师 / 平安健康互联网

好医生APP隐私合规SDK实践分享

第四位嘉宾是来自平安健康互联网的安全工程师 伍晨旭。

他分享的主题是《好医生APP隐私合规SDK实践分享》。分享从专业公司角度，使用实验室工具完善SDK安全管理流程，及时发现并消除第三方SDK潜在的隐私合规风险。

16:15-16:30 

邵宇宁 / 高级产品经理 / 集团信息安全平台部

SECRADOR前端敏感信息检测工具介绍

最后一位嘉宾是来自平安集团信息安全平台部的高级产品经理 邵宇宁。

她分享的主题是《SECRADOR前端敏感信息检测工具介绍》。安全部自研敏感信息检测小工具，帮助发现业务系统中获取/返回的敏感信息，提前发现风险。

除了主题分享，本次活动还设有Q&A问答环节，针对分享的主题，通过参加者自身企业的视角提出问题，使活动嘉宾之间有了更深度的学习与交流，可以说，本次以纯甲方视角出发，以数据安全实践为主题的平安行活动，为数据安全实践提供了良好学习与借鉴的机会。
