02 

Senior SOC Analys

POSITION SUMMARY STATEMENT:

The senior SOC Analyst will be responsible for conducting incident response operations according to documented procedures and industry best practices. Perform monitoring and data correlation to events of interest using multiple tools such as system event logs, SIEM, IPS/IDS logs, network traffic, anti-virus console and client end-point software to determine if incidents took place. Respond to security incident and investigation requests in line with established SIRT processes and procedures within defined service level targets. This position occasionally required to provide off hour support when situation arises and maybe assigned to weekend shifts. 


DETAILED RESPONSIBILITIES/DUTIES: 

  • Responsible for security incidents investigation. Track security incident investigations to resolution.

  • Analyze and assess security incidents and escalates to appropriate internal teams for additional assistance.

  • Perform periodic systems and tools health checks, ensuring security monitoring system are always at optimum level.

  • Actively investigate latest in security vulnerabilities, advisories, incidents, and penetration techniques and notify relevant teams when appropriate.

  • Perform tasks as identified in a security operations process manual and runbooks and any SOC related tasks assigned.

  • Act as incident coordinator with internal teams for security incident investigations when situation arises.

  • Should be familiar with handling and mitigating attacks related to viruses, spoofing, hoaxes, malware.

  • Should be familiar with emerging security threats and their attack vectors especially web application attacks.


Requirement:

  • Experience with one or more Security Information and Event Management (SIEM) solutions. (such as McAfee, LogLogic, Splunk, QRadar, ArcSight).

  • Understanding of common attacks (e.g. brute force, SYN flood, session hijack, smurf etc.) and their SIEM signatures.

  • Experience in leading security monitoring, Incident Response (IR), security tools configuration and remediation processes.

  • Strong knowledge and experience in security event analysis capability.

  • Excellent verbal and written English communication skills are most important for the role.

  • Understanding of network protocols (TCP/IP stack, SSL/TLS, IPSEC, SMTP/IMAP, FTP, HTTP etc.).

  • Understanding of operating system (Windows, Linux, iOS), web server, database and security devices (firewall/NIDS/NIPS) logs and log formats.

  • Experienced in security incident response and investigation, root cause analysis and troubleshooting and post incident reporting.

  • More than 1 years of technical experience in cyber security incident response or related area.

  • Accredited certification on incident handling (CEH, CHFI, GCIH, ECIH) or any other industry certification(s) a plus.
