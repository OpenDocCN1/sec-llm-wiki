**新零售及供应链安全**

  

**2021年6月25日**，第二十七期**安世加**沙龙之新零售及供应链安全在上海银星皇冠假日酒店成功举办！

本次沙龙共吸引了近**40位**安全专家及安全从业人员参与。沙龙一起探讨分享了**《企业云安全建设规划之路》**、**《多元化新零售业务安全防护—瑞数动态安全超融合解决方案》**、**《端到端业务加密环境下的可视化及安全服务链编排》**、**《AI安全的展望与分析》**、**《“双传统”物流安全成长分享》**、**《供应链安全》**等热点议题，旨在为行业提供更多的实践与经验的借鉴。

**企业云安全建设规划之路**

**沈珑 / 亚太及中国网络安全总监 / 某零售企业**

![](../Images/3f7df768e82d0dd7d9e6f444c5ff60fe.png)

首位演讲嘉宾是来自**某零售企业**的**亚太及中国网络安全总监 沈珑**。他分享的主题是**《企业云安全建设规划之路》**。他的分享主要包括三个方向，企业云安全挑战；如何建设完善的云安全管理之路；云安全关注的重点控制域。

**多元化新零售业务安全防护—瑞数动态安全超融合解决方案**

**吴剑刚 / 技术总监 / 瑞数信息**

![](../Images/8bd7978e9e81bbd84ee61dbce3c3a89b.png)

第二位演讲嘉宾是来自**瑞数信息**的**技术总监 吴剑刚**。他分享的主题是**《多元化新零售业务安全防护—瑞数动态安全超融合解决方案》**。

随着零售企业多元化业务的发展，业务接入渠道已覆盖Web、App、API、微信和小程序，各类漏洞探测，自动化、拟人化的Bots威胁兴起，给零售企业带来了新的业务风险，造成经济损失；在此瑞数将分享“动态、主动、高效、融合、智能的一站式动态安全超融合解决方案”，帮助零售企业有效解决应用安全和业务安全问题！

**端到端业务加密环境下的可视化及安全服务链编排**

**顾威 / 技术经理 / Gigamon**

![](../Images/3fb1894ad214c9ffedc2f21464208ef8.png)

第三位演讲嘉宾是来自**Gigamon**的**技术经理 顾威**。他分享的主题是**《端到端业务加密环境下的可视化及安全服务链编排》**。

1\. Inline 安全服务链编排: 针对安全节点的现状, 改变目前行业内安全设备糖葫芦串的部署架构, 降低安全设备部署的复杂性，解决IT信息孤岛的问题并加速安全技术方案的部署。

2\. 可视化基础网络建设: 旁路镜像流量的可视化网络建设, 帮助企业进行数字化转型, 提供跨物理、虚拟和云网络架构的流量完全可视化, 为安全、网络、业务部门提供海量数据的可视化流量网络基础。

**供应链安全**

**Greta Fan / CISO / 某零售集团**

![](../Images/18473d00c7a7c372012c573cdc70e4f3.png)

第四位演讲嘉宾是来自**某零售集团**的**CISO Greta Fan**。她分享的主题是**《供应链安全》**。

近年来针对供应链的攻击越来越多，供应链的安全风险也越来越受企业重视。针对零售行业，供应链的重要性毋庸置疑，同时在整个供应链的管理中必然面对各种各样的安全风险。本次演讲将结合实际，围绕零售行业面对的各种安全风险，进行分享和探讨。

**“双传统”物流安全成长分享**

**张天宇 / 安全技术负责人 / 安吉物流**

![](../Images/f113255dfbefe0f88983976202f6ca20.png)

第五位演讲嘉宾是来自**安吉物流**的**安全技术负责人 张天宇**。他分享的主题是**《“双传统”物流安全成长分享》**。

当传统国企和传统物流碰撞，会激发出怎样的安全火花，怎样在组织内部，从一个人的安全部提升到集团安全部，中间会遇到哪些不一样的困难，怎么去解决它。

**AI安全的展望与分析**

**马一烈 / CISO / 某奢侈品牌**

![](../Images/5a3ab834cbbb56ebdd79c1c6e4f667ef.png)

最后一个位演讲嘉宾是来自**某奢侈品牌**的**CISO 马一烈**。她分享的主题是**《AI安全的展望与分析》**。

她的分享主要分为四个方向安全未来三年的愿景；行业状况；企业新挑战；如何计划安全下一代。

**小组讨论：新零售的安全挑战与实践**

**马一烈 / CISO / 某奢侈品牌**

**李震 / CSO / 某新零售集团**

**任博博 / CISO / 大润发**

![](../Images/edb2fc53380d30a0f15684fa27dd0879.png)

最后一个环节是由来自**某奢侈品牌**的**CISO 马一烈**、来自**某新零售集团**的**CSO 李震**、来自**大润发**的**CISO 任博博**。随着《数据安全法》，《个人信息保护法》草案的相继出台，预示着国家对个人信息保护的监管越来越严格，对于新零售企业又会带来何种冲击呢？几位嘉宾就当下热门的数据安全法，APP合规，跨境数据治理等话题，以自身企业的视角发表了各自独特的观点，为与会者提供了有力和实践借鉴。
