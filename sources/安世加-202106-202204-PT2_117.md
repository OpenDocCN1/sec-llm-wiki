# 漏洞评估业务增长：你所不知道的Nessus

Nessus团队一直在开发各种高级评估功能，其中包括对新操作系统、可利用漏洞以及容器实例的洞察。

![](../Images/93a44699d063ef3eec5ae5d3354837b8.png)

当Renaud Deraison于1998年4月4日首次在 Bugtraq上发布Nessus时，后者还仅是一个内部测试版本。如今，Nessus诞生即将届满23年，其内部测试版本alpha漏洞扫描程序已成为世界上最为广泛运用的漏洞评估工具。

Nessus的持续增长现已成为业界奇迹。首次发布时，Nessus在Linux基础上编译，并且仅有50个插件。此后不到五年时间里，Nessus不仅将插件增加到1000 多个，还帮助推出了**Tenable**，**Tenable**平台开启了基于风险的企业漏洞管理新篇章。又过了五年，Nessus对操作系统的支持规模急剧扩大，插件数量超过28,000 个，Nessus下载量也超过500万。一代安全专业人员伴随与Nessus一起成长，他们中许多人对使用Nessus扫描漏洞的最初体验记忆犹新。

在过去十年中，Nessus持续增加各种新功能和改进性能。今天，Nessus可以在所有常见（以及一些不太常见）的Linux 发行版、FreeBSD、Apple macOS、Windows服务器和桌面操作系统上运行。它拥有的报告选项超出以往任何时期，并且具有强大的API、针对常见漏洞的预配置扫描模板以及约152,000个插件，涵盖61,000个通用漏洞披露 (CVE)。仅在2020 年一年，**Tenable Research**就发布了超过12,000 个插件，并更新了超过16,000个插件。我们不只是发布插件，我们还会根据获得的新信息不断改进插件。

Nessus

与这些庞大数字相比，更惊人的是这些数字背后不断创造奇迹的人们。一支由数十人组成的团队负责编写、测试、更新和部署我们的插件和审核文件。**Tenable**不只应对已公布的漏洞；我们还拥有一支零日研究团队，他们不断努力发现各种新漏洞。他们在 2019年披露了100个零日漏洞，在2020年披露了141个零日漏洞。 

![](../Images/224bc2b38f34fead62374d7014db43fd.png)![](../Images/693de4ef9c4fec92be62f1ca1d6c85c2.png)

  

**在过去一年中，Nessus开发出许多新功能，**

**同时持续推动漏洞评估的进步：**

**新增了对六个操作系统的支持以在本地运行Nessus，扩大了对Mac、Linux和Windows的总体覆盖：**

*   *SUSE Linux Enterprise Server 15*
    
*   *FreeBSD 12.x*
    
*   *Kali 2018、2019、2020*
    
*   *Unbuntu 20.04*
    

**六种新用户预定义报告，范围涵盖从操作系统检测到超过一年的顽固漏洞：**

*   **操作系统检测**—安全分析人员接收网络中各主要操作系统的摘要，帮助识别风险最大的系统。
    
*   **可利用的漏洞**—通过识别自然环境中已知的被利用漏洞，安全分析人员可集中进行补救工作，以更好地保护网络安全。
    
*   **不受支持的软件**—系统管理员接收供应商不再支持的软件的摘要，以帮助了解相关风险。
    
*   **已知帐户**—安全分析人员可以审查和识别其中存在用户帐户相关配置问题的系统，以防止漏洞在网络中横向扩散。
    
*   **存在漏洞的主机**—系统管理员可以查看25个最常见漏洞，以及与每个漏洞相关的IP地址列表。
    
*   **一年多以前的漏洞**—安全分析人员发现本地环境中一年以前存在的漏洞。  
    

**对扫描性能和模板的改进使Nessus的速度超出以往。**

**能够将Nessus部署为Docker镜像。客户可以将托管型 Nessus扫描程序或Nessus Professional实例部署为 Docker 镜像，以在容器上运行。**

**新增的备份和恢复功能使用户能够创建Nessus备份，并轻松快速地恢复。这可以是Nessus以前的备份，以便稍后在其他系统（即使是不同的操作系统）上恢复。**

**Tenable Research发布了超过28,000个Nessus 插件和更新，在CVE覆盖率、零日研究和漏洞管理方面均处于业界领先地位。**
