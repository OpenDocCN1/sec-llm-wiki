# 知名硅谷黑客当街被刺身亡！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2MTQwMzMxNA==&mid=2247531607&idx=1&sn=25d1b636380140f2944887565963dcef&chksm=fc7b788acb0cf19c5db38337efade0f659a3c1e4a83c5e1f4884d7344ba5cdaf64fee1f4e685&scene=126&sessionid=1681404128#rd](http://mp.weixin.qq.com/s?__biz=MzU2MTQwMzMxNA==&mid=2247531607&idx=1&sn=25d1b636380140f2944887565963dcef&chksm=fc7b788acb0cf19c5db38337efade0f659a3c1e4a83c5e1f4884d7344ba5cdaf64fee1f4e685&scene=126&sessionid=1681404128#rd)

  

一位年仅43岁的技术大牛/黑客，在美国旧金山遇刺身亡。

他叫鲍勃·李（Bob Lee）。

![](../Images/3d268839ac23ca2d2918bc1ae1e758e4.png)

他曾担任谷歌软件工程师，负责安卓系统核心API的开发，后创办了著名移动支付软件Cash App。

现在是加密货币初创公司MobileCoin的首席产品官。

此消息一出，就震惊美国科技圈，无数网友自发悼念。

![](../Images/14d48e6508469e9c7f9b7180f9e0bc99.png)

MobileCoin CTO称：

他所作贡献带来的影响力的持续时间，一定会比他在世的这短暂时日还要长。

与此同时，马斯克也注意到了这一消息，展开抨击并呼吁当地加紧对暴力犯罪的监管措施。

![](../Images/c770c720c00fe7f5ac7d302f28a50132.png)

**辅助安卓系统开发，创办Cash App**

据旧金山警局官方通告，他们于当地时间周二凌晨2点35分左右接到报警（具体遇袭时间不知）。

随后赶到现场，发现一名43岁的成年男性受害者身上有明显的刀伤。

警方召集了医务人员到现场，随后又将受害人送往当地医院，但最终还是因伤势过重而死亡。

截止到通告发布的时间（当地周二晚6点多），警方还未逮捕到任何嫌疑人，并希望有线索的市民第一时间提供信息协助破案。

![](../Images/62f89b5c43291f0f5e87afd15415a4b1.png)

就在转天，多家媒体援引未具名警方消息称，这位被刺身亡的受害者正是加密货币和数字支付初创公司MobileCoin的首席产品官鲍勃·李。

鲍勃于2021年11月正式加盟MobileCoin担任其首席产品官。

在此之前，他还是美国移动支付巨头Square（后为拥抱区块链技术更名为Block）的CTO，这是一家由推特前CEO杰克·多西（Jack Dorsey）联合创立的金融公司。

鲍勃在Square工作了四年多，在那里他还创办了该司旗下的转账支付软件Cash App（功能类似国内微信和支付宝）。

截至到2022年底，该App拥5100万月活跃用户。

时间再往前一些，鲍勃是谷歌的软件工程师，在那里辅助安卓系统的开发（任期五年）。

除了这些履历之外，他还是SpaceX、Clubhouse、Figma等企业的早期投资人。

截止目前，旧金山警局还未公布鲍勃被害一案的最新进展。

“科技界和旧金山的巨大损失”

鲍勃的消息在网上迅速传开，无数朋友、同事和网友表达了自己的悲痛心情。

鲍勃的现任雇主MobileCoin CTO，专门发了一篇悼文回顾他一生的贡献。

他称鲍勃是一位典型的创造者、领导者和完美的黑客。

从他在谷歌为安卓系统做出的巨大贡献，一直到加入Mobilecoin与他们合作，其影响力“肯定会远远超过他在这个世界上的短暂一生”。

他表示，鲍勃最初来到MobileCoin是作为一名早期投资者和顾问，他是商业隐私的坚定支持者。

他想要一个你我都可以自由交易不受掠夺性公司和罪犯窥探的世界。我们对他为我们所做的一切表示感激和谦卑。

![](../Images/2f887da905e9b05dbfbb901d8cb5238c.png)

Figma首席执行官Dylan Field发帖表示：

听到@crazybob（鲍勃绰号） 英年早逝的消息真是令人难过。我第一次见到他是在2006年夏天——他不在乎我只有14岁跟我谈论技术/极客编程。多年来我们一直保持联系，他是Figma的早期支持者。很难相信他已经走了。

YCombinator CEO陈嘉兴则称：

鲍勃的死对科技界和旧金山来说都是一场悲剧和巨大的损失。

并表示他遇害的地方到处都是摄像头，应该很快能知道真相。

![](../Images/1af64ff0eb89f5b9917a662821b4794a.png)

有网友称鲍勃很平易近人：

跟他就一些技术细节进行了很长时间的交谈之后，我才知道他居然就是我司的CTO。

![](../Images/c70de67e2a40a7764e70552185f1bfc9.png)

也有人表示自己曾参加过他的面试，但在所有面试官中只对他印象深刻，因为只有他提出的问题不是照本宣科。

![](../Images/83ce128cb4ca3115cce3f6fa6c11cd39.png)

R.I.P。
