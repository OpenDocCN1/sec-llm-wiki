# 关于对美光公司在华销售产品启动网络安全审查的公告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2MTQwMzMxNA==&mid=2247531577&idx=2&sn=b721f082a7832937e1faf97a4a300a9e&chksm=fc7b78e4cb0cf1f2a8ff51afd885fbf309b344845e8cd6b3ce0c992655be8dfcf68ed8053626&scene=126&sessionid=1681404129#rd](http://mp.weixin.qq.com/s?__biz=MzU2MTQwMzMxNA==&mid=2247531577&idx=2&sn=b721f082a7832937e1faf97a4a300a9e&chksm=fc7b78e4cb0cf1f2a8ff51afd885fbf309b344845e8cd6b3ce0c992655be8dfcf68ed8053626&scene=126&sessionid=1681404129#rd)

为保障关键信息基础设施供应链安全，防范产品问题隐患造成网络安全风险，维护国家安全，依据《中华人民共和国国家安全法》《中华人民共和国网络安全法》，网络安全审查办公室按照《网络安全审查办法》，对美光公司（Micron）在华销售的产品实施网络安全审查。　　特此公告。  
网络安全审查办公室2023年3月31日
