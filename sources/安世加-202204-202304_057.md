# 韩国拒绝苹果向海外传输高精度地图数据的要求

       韩国政府一位官员周一表示，韩国政府以安全问题为由，拒绝了美国科技巨头苹果(153.83, 2.80, 1.85%)提出的向海外传输韩国高精度地图数据的要求。

　　韩国国土交通部有关人士表示，苹果向国土交通部下属的国家地理信息研究所申请输出1比5000的韩国地图数据，但在2月16日被拒绝。

　　该官员表示：“这主要是出于安全问题，到目前为止，允许输出1：25 000比例尺的地图数据，但不允许输出精度更高的地图数据。”

　　此前，谷歌(95.58, 1.56, 1.66%)曾多次向韩国政府提出向海外发送地图数据的请求，但均遭到了拒绝。
