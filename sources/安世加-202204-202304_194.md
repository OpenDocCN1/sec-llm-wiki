# 马斯克将Twitter整个网络安全团队“连根拔起”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2MTQwMzMxNA==&mid=2247527921&idx=2&sn=3a068281db36b39f7cde5736fea82491&chksm=fc7b692ccb0ce03a038f770d9226ee760589facb65acc10493e55f77760a1c1fa35f863b98e1&scene=126&sessionid=1681404194#rd](http://mp.weixin.qq.com/s?__biz=MzU2MTQwMzMxNA==&mid=2247527921&idx=2&sn=3a068281db36b39f7cde5736fea82491&chksm=fc7b692ccb0ce03a038f770d9226ee760589facb65acc10493e55f77760a1c1fa35f863b98e1&scene=126&sessionid=1681404194#rd)

当地时间10月27日，沸沸扬扬的Twitter收购案已经落下帷幕，马斯克以440亿美元的价格买下推特，Twitter正式步入“马斯克时代”。  

在完成收购Twitter交易后仅几分钟，马斯克就解雇了Twitter现任的多名高管，包括首席执行官Parag Agrawal、首席财务官Ned Segal、总法律顾问Sean Edgett等，并宣布将成立一个包容多方观点的内容审核委员会。

![](../Images/f30476c4a14b368d83d02efd8f8f63de.png)

赶走了原高管，马斯克将裁员计划对准了推特的员工。据悉，马斯克将立马辞退至多 50% 的推特员工。其中包括Twitter网络安全团队，马斯克在没有发出任何通知的情况下突然宣布裁掉Twitter整个网络安全团队，这是继数据工程团队后，被马斯克“连根拔起”的第二个技术团队。  
Twitter暴露出的网络安全问题  
此前，Twitter前首席信息安全官Peiter Zatko曾在8月份的举报信中称Twitter的数字安全防御严重不足，员工中有外国间谍潜伏，而前首席执行官Agrawal要求Zatko在董事会上弱化安全问题，夸大安全防御工作成果。  
Zatko还提到，Twitter的访问管理混乱，所有工程师都可（以较高的权限）访问生产环境却没有日志信息记录其访问和操作，导致生产环境始终存在较高内部风险。而且Twitter工程师的个人设备如办公电脑也缺乏安全控制和监控，40%的设备连基本的安全防护标准都达不到。Twitter接下来面临网络威胁在未来的几周时间内，Twitter的安全性将会大大降低，新的安全团队又无法及时进行响应，由此黑客将会肆意攻击Twitter。甚至一些被裁撤的安全人员会充当黑客攻击的“辅助者”，进一步增加了黑客攻击出现的频率和实施的成功率。
