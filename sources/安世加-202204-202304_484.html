2022年4月22日，由安世加主办的第三十三期沙龙之数据安全在线上成功举办！本次沙龙共吸引了近300位安全专家，安全负责人报名参加。沙龙围绕《从能力到运营-数据安全深水区玩法》、《IBM Security 助力企业数据安全合规建设》、《Fortinet 全球网络安全趋势预测》、《制造业企业数据安全实践》、《数据安全治理那些事》、《数据安全治理能力建设及落地案例分享》这些安全热点话题，通过嘉宾精彩的演讲，为与会者提供了更多可落地的实践与经验的分享。

刘志诚

企业：乐信集团

职位：信息安全中心总监

首位演讲嘉宾是来自乐信集团信息安全中心的总监 刘志诚，刘总是中科院心理研究所管理心理学博士，印第安纳大学kelley商学院金融硕士（MF），香港理工大学软件理学与工商管理（MBA）双硕士。前中国移动电子认证中心（CMCA）负责人，OWASP广东区负责人。关注企业数字化过程中网络空间安全风险治理，对大数据、人工智能、区块链等新技术在金融风险治理领域的应用，以及新技术带来的技术风险治理方面拥有丰富的理论和相关经验。他带来的演讲主题是《从能力到运营——数据安全深水区玩法》。

谈到数据安全，从生命周期的治理，到身份、认证、鉴权、加密、脱敏、审计的能力建设，要么是和工程无关的理念，要么是预防，响应的单点能力，如何工程化了解业务场景的数据安全需求，实现数据的可见，可管，可控，可验证，希望我的讲述能给你一些启发。

袁笑鹏

企业：IBM

职位：大中华区资深安全架构师

第二位演讲嘉宾是来自IBM的大中华区资深安全架构师 袁笑鹏，袁总在电信、金融行业有十年以上工作经历，现任职IBM大中华区资深安全架构师，在数据安全、零信任、人工智能等领域有丰富的理论和实践经验。他带来的演讲主题是《IBM Security 助力企业数据安全合规建设》。

当前，数据已成为国家基础性战略资源和重要的生产要素。随着《数据安全法》和《个人信息保护法》的正式实施，行业企业建设数据安全体系的意愿不断增强。本次议题从合规的角度为企业数据安全的建设提供了方案和建议。

郑伟

企业：Fortinet

职位：亚太区产品营销经理

第三位演讲嘉宾是来自Fortinet的亚太区产品营销经理 郑伟。郑伟有二十多年的IT行业从业经验，涵盖网络安全、云安全和存储等领域。曾经在赛门铁克软件(Symantec)有限公司，阿卡迈(Akamai)信息技术有限公司，Computer Associates Technologies ，富士通(Fujitsu)等知名公司担任大中华区资深产品营销经理，大中华区市场总监等职务，主要负责产品及市场营销和业务等相关工作。他带来的分享主题是《Fortinet 全球网络安全趋势预测》。

全球网络安全领导者Fortinet的FortiGuard Labs 全球威胁情报响应与研究团队发布了《2022年全球网络安全趋势预测报告》。报告显示，2022年将是网络犯罪的高峰，勒索软件数量将显著增长，攻击者的数量也将达到空前的程度。同时，勒索软件攻击也将迅速蔓延至整个攻击面，勒索软件威胁将无处不在。

更具挑战的是，越来越多的企业组织机构转向现场和远程混合办公模式，并采用更多基于AI（人工智能）和ML（机器学习） 的技术，启用更多新的连接形式，还将更多关键业务应用和设备部署到云中，使得攻击面也随之扩大。

当前全球网络攻击的自动化和攻击速度均显著提升，更具破坏性、 不可预测性且更加持续的网络犯罪正快速演进。此外，伴随随时随地办公（WFA）及混合IT环境而来的不断扩大的攻击面，更是给了网络犯罪分子更多的可乘之机…….

肖寒

企业：某上市公司

职位：信息安全负责人

第四位演讲嘉宾是来自某上市公司的信息安全负责人 肖寒。肖总负责企业IT及信息安全的建设、运维和管理工作。十多年信息安全从业经验，多年甲方信息安全管理经验。对信息安全、安全大数据分析、项目管理、运维管理、数据治理、零信任等领域有深刻理解及丰富的落地经验。他带来的分享主题是《制造业企业数据安全实践》。

本次演讲围绕制造业企业数据安全实践展开，主要内容包括数据的分类与分级、数据的备份与恢复，包括了产品选型。

Hobby

企业：某科技公司

职位：信息安全负责人

第五位演讲嘉宾是来自某科技公司的信息安全负责人 Hobby。Hobby是国内某安全实验室创始人之一，持有CISP、Security+认证。丰富的互联网企业安全建设经验，参与主导数据安全治理项目的规划、建设、实施落地和优化等工作。专注于安全规划、安全建设、安全运营、攻防等方面。现就职于某科技公司，主要负责公司业务信息安全相关工作。他带来的分享主题是《数据安全治理那些事》。

国内外数据安全事件频发，数据安全相关法律相继出台，数据泄露风险和监管压力越来越大，数据安全治理开始被各司提上日程。本次分享主要和大家就在数据安全治理工作中可能存在的痛点、难点进行探讨和分享，包括但不限于寻找治理驱动和着手点、创建标准等。

苏振波

企业：OPPO

职位：高级数据与隐私安全专家

最后一位演讲嘉宾是来自OPPO的高级数据与隐私安全专家 苏振波。苏总负责OPPO公司互联网业务数据安全合规体系及数据安全能力体系的规划与建设，前腾讯数据安全解决方案负责人，主导过多个政务大数据、金融、大型互联网企业的数据安全顶层规划，在数据安全和个人隐私保护标准、产品、技术、应用方面拥有丰富的实践经验。他带来的分享主题是《数据安全治理能力建设及落地案例分享》。

主要分享包括：

1、企业面临的数据安全和隐私风险分析

2、探讨企业数据安全和隐私保护建设路径

3、数据安全关键技术

4、数据流转关键风险识别和应对方案

5、基于分级标签的细粒度管控实践

6、脱敏和个人信息去标识化实践
