# CCIA报告：增速放缓且集中度提升 未来数年网安行业竞争残酷

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMDQ4OTkyMg==&mid=2247484848&idx=1&sn=c6fecdf33caa33424b99a2ce19afda13&chksm=f9e8db1dce9f520baf45a6ce560910673dc255532eb3a09bc5b2a19a27d312ce15203599f4c2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUyMDQ4OTkyMg==&mid=2247484848&idx=1&sn=c6fecdf33caa33424b99a2ce19afda13&chksm=f9e8db1dce9f520baf45a6ce560910673dc255532eb3a09bc5b2a19a27d312ce15203599f4c2&scene=27#wechat_redirect)

中国网络安全产业联盟（下文简称CCIA）在12月14日发布了《中国网络安全产业分析报告（2020年）》（以下简称报告），其中在第二部分特别针对我国网络安全产业的规模、增速等进行了调研，并得出了部分数据。  
  
首先从增速方面看，数说安全及CCIA根据公开数据整理出来的内容，可以看出2019年我国的网络安全市场规模约为478亿元，这一数字虽然低于此前大多数机构所预估的数值，但考虑到该数据来源于对网络安全企业的实际调研并运用数学模型计算之后总结得出，相比之下具有较强的参考性。  

  

![](../Images/ff330049ad044589d4ae4206d648e6ca.png)

数说安全、CCIA的《中国网络安全产业分析报告（2020年）》

  

尽管该报告的市场规模数字可能是同类型报告中最低的，但在增速方面和大家的心里预期基本一致，同比增长达到了21.5%。由于2020年出现了很多利好，诸如2020年1月实施的《中华人民共和国密码法》、2020年6月1日实施的《网络安全审查办法》以及其他网络安全相关的法规、政策等不断出台，促进了网络安全行业市场规模的增长，但由于本年度疫情对社会的影响非常深，因此该报告也预计本年度的市场规模同比增速将会大幅低于20%，为15.6%。

  

另外，通过报告的预估增长数据看，在2022年（含）之前，整个网络安全行业的市场规模增速都不会重回20%上方，到2022年市场规模也不会突破800亿元。  

  
报告同时指出中国网络安全整体规模较小的局面仍未得到改变，根据Gartner公布的数据估算，我国的网络安全指出还不足IT支出的1%，而在全球来看这一数据是3.2%，由此可见仍有可观的增长空间，尤其是在新基建带动下，更多的传统行业、产业将会加速数字化转型，这一过程当中对网络安全的需求提升也是肉眼可见的，这一点也成为众多资本青睐国内网络安全领域的原因之一。  

  

![](../Images/a39461dbc4d44a8cf3bee02a7f1cf4d7.png)

数说安全、CCIA的《中国网络安全产业分析报告（2020年）》

  

在行业集中度方面，报告指出我国网络安全市场已经由竞争型转变为低集中寡占型，该判断源自于他们对当前网络安全行业分析结果——CR8为39.48%得出。  

  
这种分型是源于美国经济学家贝恩和日本通产省对产业集中度的划分标准，将产业市场结构分为两种，分别是寡占型和竞争型，其中寡占型细分可为五个级别，分别为极高寡占型（CR8 ≥ 70%）和低集中寡占型（40% ≤ CR8<70%）；竞争型则分为低集中竞争型（20% ≤ CR8<40%）和分散竞争型（CR8<20%）。  
  
尽管严谨一点看，当前中国网络安全行业集中度仍处在低集中竞争型之中，但确实如报告所言——“我国网络安全行业CR8基本达到了40%的水平”。  
  
CCIA在本次报告中提及的开展网络安全业务的公司数量方面已经达到了3589家（2020年上半年），如果再看报告分析中品牌的市场占有率情况来看，奇安信、启明星辰以及深信服的市占率均达到6%及以上，不足千分之一的三家企业占据了整个市场接近20%的份额，至少从这份数据以及其所反映的趋势看，在市场规模增速保持15%+，且规模总体不大的基数之下，未来绝大多数网络安全企业将会面临愈加残酷的竞争。
