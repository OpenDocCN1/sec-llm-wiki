# 7月30日 那个最黑客也最干货的MOSEC移动安全技术峰会就要来了！

2021年7月30日，由盘古团队和POC联合主办的第七届MOSEC移动安全技术峰会将于上海万达瑞华酒店举办。本届MOSEC将承袭前六届的传统，广邀业内优秀移动安全领域专家聚首上海，向世界分享最新安全研究成果。

  

MOSEC移动安全技术峰会始办于2015年，至今已经是第七个年头了。会议立足于高质量的安全技术，致力于分享移动安全领域前沿性的技术议题及发展趋势，以其高质量的干货议题在业内享以美誉，而MOSEC也已经成长为国内安全技术峰会的重要风向标。

  

  

**MOSEC：安全爱好者眼中地表最强的**移动**安全峰会**

  

近年来，随着国内信息安全热度的不断升温，一到每年的夏天，令人眼花缭乱的各大安全会议和安全沙龙会迅速在全国遍地开花，往往前脚这家安全公司刚刚举办完一场行业大会，后脚另外一家安全公司在同一个会场内继续再举办一场，甚至有时候还会出现两次安全大会举办时间撞车的情况。

  

在安全419曾经采访过的部分技术从业者眼中，很多安全会议商业气息浓厚，一些线下的沙龙活动也都是出于圈内社交的目的，从技术学习的角度来看意义并不大。那么，什么样的会议才是有价值和值得关注的呢？

  

知乎上有一个圆桌话题叫做：“有哪些值得关注的黑客会议？参加体验如何？”，其中有一条热门回答是，想要了解一场黑客大会是否值得参加，可以看看历届分享的议题是否干货，是否能让你学到东西。而在众多回答中，DEFCON China、KCon、XCon以及MOSEC都高票当选，获得了广大安全从业者们的极高评价。

  

对于那些喜欢研究手机系统的从业者们而言，MOSEC几乎代表了业内移动安全技术大会的最高水平。 

  

![](../Images/87e9282c29226f4d1ba580eddf146184.png)

  

  

**业内顶尖移动安全研究员齐聚上海**

  

在盘古团队看来，就一场技术会议来说，首先要做到的就是排除包括企业广告和产品广告在内的一切广告。因此，自从第一届起，MOSEC就不向赞助方承诺议题演讲的机会，这个传统也一直延续至今。所以MOSEC的全部内容只有一个，移动安全领域全球顶尖研究者的干货分享。

  

六年来，MOSEC平台总计发表了近百个前沿技术议题，邀请全球最顶尖的网络安全专家和白帽子黑客登台演讲，包括著名的苹果天才少年Luca Todesco、著名图书《MacOS and iOS Internals》的作者Jonathan Levin、Google Project Zero、360 Vulcan / Alpha Lab、腾讯科恩实验室/ 玄武实验室等全球著名安全团队成员。

  

盘古团队表示，因全球疫情尚未平息，今年一些原定的外籍嘉宾无法来到上海现场进行分享，因此分享嘉宾的阵容仍然将以来自盘古实验室、360 Alpha Lab、腾讯科恩实验室以及赛博昆仑为主，各位研究员们将带来自己的技术秀。

  

MOSEC的老朋友，来自北京赛博昆仑的“大宝”招啟汛也将再次登上MOSEC的舞台，为大家带来自己对于苹果PAC保护机制的安全研究成果。

  

![](../Images/5cf5fb1dcf9c9d1caba3c697add99303.png)

  

  

**BaiJiuCon——煮酒论英雄**

  

据了解，在MOSEC 2021上，MOSEC最为经典的BaiJiuCon环节也将继续延续，在BaiJiuCon环节中，只要你喝一杯白酒，就可以拿到5分钟的演讲时间，尽情展示自己的黑客绝技。

  

![](../Images/7c1dc6816dd67dd92deb681cdc107f44.png)![](../Images/102e24894e0eb5a3b24cf6344c20a864.png)

  

讲到这里，安全419已经对这次MOSEC上海之旅充满了期待，7月30日，上海万达瑞华酒店，想要前排摩拜各位大佬，学习最前沿的移动安全攻防姿势的话，大家就相约MOSEC现场见吧。

  

对了，鉴于MOSEC报名参会过于火热，很多小伙伴可能因为买不到票而无法前往现场，安全419 后续会带来更多第一手参会报道，保持关注哦~

  

  

**The End**

安全419编辑部于近期正式启动“2021年度网络安全细分领域厂商”调研工作，重点针对数据安全、工控安全、端点安全、移动安全、开发安全、云安全、密码、零信任八个领域展开，并在第四季度围绕调研成果发布系列选题内容。
