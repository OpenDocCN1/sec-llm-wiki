# 中国技术市场协会联合多机构开展NFT平台与产品评测标准研制工作

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMDQ4OTkyMg==&mid=2247492128&idx=4&sn=7d97f2beaddf37b030f8a5b30465ec8f&chksm=f9eb3c8dce9cb59baa14452f0fe7a5f8014584a5b294d6e464d1f7858721603c3d21bfc5e24b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUyMDQ4OTkyMg==&mid=2247492128&idx=4&sn=7d97f2beaddf37b030f8a5b30465ec8f&chksm=f9eb3c8dce9cb59baa14452f0fe7a5f8014584a5b294d6e464d1f7858721603c3d21bfc5e24b&scene=27#wechat_redirect)

安全419了解到，9月22日，科技部下属中国技术市场协会标准化工作委员会发布**《关于开展 NFT 平台与产品评测团体标准研制及成立起草工作组的通知》**，表示联合多家产学研机构成立工作组，共同开展《 NFT 平台与产品评测》团体标准研制、起草工作。

  

![](../Images/97d866941ea35cd21f824bb2367ed5c4.png)

  

NFT (非同质化权益证明)是基于区块链技术对知识产权、文化符号所有权的一种数字化表现形式，有利于知识产权保护、授权与交易。近年来，国内外 NFT 生态建设蓬勃发展，特别是在文学、美术、音乐、数字作品等领域得到了越来越多的应用。

  

但在 NFT 市场火热的同时，针对 NFT 平台和数字商品的标准却严重滞后，不同平台制作的 NFT 作品在安全性、兼容性、可扩展性以及合规等方面存在很大差异。加快相关标准研制已成为行业共识。  
  
根据《通知》，已确认参与《 NFT 平台与产品评测》标准起草单位(品牌)有：  
  

*   清华大学 x - lab 区块链实验室
    
*   清华大学经管学院区块链金融研究中心
    
*   中科院软件所区块链实验室
    
*   腾讯 QQ
    
*   蚂蚁金服集团研究院
    
*   火星区块链研究院
    
*   欧科云链研究院
    
*   杭州节点互信科技有限公司
    
*   Element
    
*   零幺宇宙
    
*   NFT 标准实验室
    
*   海文交 NFT 发展中心
    
*   北京知道创宇信息技术有限公司
    
*   厦门慢雾科技有限公司
    
*   北京微乎文化科技有限公司
    

  
同时，中国技术市场协会呼吁欢迎更多有志于推动 NFT 市场健康发展的机构共同参与起草，高水平完成标准编制工作。
