1.BCS 2022北京网络安全大会今日开幕


7月13日，2022年北京网络安全大会（BCS 2022）正式开幕。本届大会以“零事故之路”为主题，围绕全球网络空间安全、冬奥零事故经验、体育赛事信息化和网络安全等重大议题展开研讨。据介绍，本次大会首次采用“四地双会场动态召开”的创新模式，在北京、长沙、重庆和深圳等地采取线上线下融合的方式持续举行，会期长达一个月，举办包括冬奥零事故峰会、安全战略峰会、观潮网络空间论坛等多场活动，立足全球视野，分享中国经验。


2.VMware修补了11月披露的vCenter Server漏洞


在披露 vCenter Server 的 IWA（集成 Windows 身份验证）机制中的高严重性提权漏洞八个月后，VMware 终于发布了针对其中一个受影响版本的补丁。此漏洞（CVE-2021-22048）也影响 VMware 的 Cloud Foundation 混合云平台部署。攻击者利用此漏洞可将对vCenter Server的非管理访问权限提升到更高权限的组。虽然 该漏洞影响多个 vCenter Server 版本（即 6.5、6.7 和 7.0），但今天发布的补丁仅针对运行最新可用版本的服务器。


3.微软修复了数十个Azure Site Recovery权限提升错误


Microsoft 修复了 Azure 站点恢复套件中的 32 个漏洞，这些漏洞可能允许攻击者获得提升的权限或执行远程代码执行。在发布的一份通报中，微软指出SQL注入漏洞导致了大多数权限提升错误。还强调了由Tenable发现的DLL劫持漏洞引起的CVE-2022-33675漏洞。考虑到ASR在依赖不间断云应用程序和服务的企业环境中的使用范围，它可能成为网络入侵的关键弱点。


4.趋势科技发布基于云的加密货币挖掘攻击报告


据外媒报道，趋势科技的研究人员发布了一份报告，详细介绍了针对 GitHub Actions 和 Azure VM 的基于云的加密货币挖掘攻击及其背后的组织。黑客正试图破坏大量基于云的系统来挖掘加密货币，在资源消耗和成本方面对目标组织产生重大影响。专家指出，受矿工感染的基础设施的性能会降低，并可能导致企业在线服务中断，从而影响组织的声誉。


5.一项大规模的网络钓鱼活动使用（AiTM） 网络钓鱼站点攻击多个组织


Microsoft 观察到一项大规模的网络钓鱼活动，该活动使用中间对手 （AiTM） 网络钓鱼站点来窃取密码、劫持用户的登录会话，并绕过身份验证过程，即使受害者已启用 MFA。在网络钓鱼中，黑客在目标用户和用户希望访问的网站之间建立代理服务器，这是攻击者控制下的网络钓鱼网站。微软专家认为，自2021年9月以来，AiTM网络钓鱼活动已被用于针对10，000多个组织。


6.TikTok在意大利被警告违反GDPR后推迟欧洲隐私政策更新


广受欢迎的视频共享平台TikTok同意暂停一项有争议的隐私政策更新，该更新可能允许它根据用户在社交视频平台上的活动投放有针对性的广告。据报道，意大利数据保护机警告该公司，理由是违反了数据保护法。
