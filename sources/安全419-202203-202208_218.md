# 数字化转型从上云开始 便捷迁移与安全成企业核心考量

全行业通过数字化转型，将带动企业实现商业模式创新，营销、研发、采购、管理以及销售的全面数字化，推动企业在释放数字价值的同时也实现企业自身的做大做强。成功的数字化转型将从上云开始，与此同时，业务上云也带来新的问题：一方面是迁移上云过程过于复杂，企业需要解决环境变换问题，还要将迁移周期与迁移成本做到可控；另一方面则是企业上云也带来全新的网络安全问题，之前部署的部分安全设备大多失效，如何保障业务的连续性、数据安全亦是合规性考量。

  

![](../Images/2eca8bdfda95c1c352dbcab4280b6837.png)

  

当然，潮流不可逆，企业不能也不应因为存在上述问题而放弃数字化转型，因此如何克服以上问题才是值得思考的。带着这些问题，安全419与致力于自动化运维与数据保护综合服务商 CloudWonder 嘉云进行了交流，在交流的过程中，了解到他们基于 NaviClouDR 主动式数据保护系统所推出的解决方案，不仅具有可以支持多云深度融合，同时还依靠具创新力的技术实现了自动化云间迁转效能与容灾增值服务，很好地解决了客户以上问题。

  

**一键式Any to Any**

**嘉云NaviClouDR稳定可靠的多云异构迁移**

  

NaviClouDR 确切地说是一款以容灾应用为核心，加入大量主动式工作流的数据保护产品，其核心价值是保护客户业务系统连续性的容灾快速迁移恢复（通过快速迁移恢复的容灾能力，全面保障客户业务系统的连续性），而主动式工作流则带来了诸多自动化运维能力，其中多云迁移融合就是其中之一。

  

CloudWonder 嘉云指出，云迁移指的是企业将 IT 系统数据和应用迁移上云，包括从传统的物理环境迁移到云的虚拟环境，也包括从一朵云迁移到另一朵云。CloudWonder 嘉云在其容灾解决方案中选择了通用性更强的 Re-Host 路径，这也是云迁移中最常见的方法。

  

直接迁移，顾名思义，即在不改变应用程序运行环境的前提下将系统和数据迁移上云。这一方法的优势是对业务的影响最小，而且在应用到容灾恢复产品当中，更适合执行高速而又有效的事后恢复或云上迁移应用。这也是容灾产品所强调的那样，是由业务系统连续性提供最大支持决定。

  

![](../Images/bcc2d8bf97cd3a491d133d4c5551e5af.png)

  

我们回来看产品本身，嘉云的技术专家向安全419讲解道：系统在不同基础架构之间迁转时，最重要的是能够保证系统和应用在新的环境下都能稳定运行。面对这一场景，NaviClouDR所拥有的“Any to Any”和“to Any Cloud”两大基础能力让其可以轻松应对，使其解决方案具备智能识别来源和目标基础设施类型能力，并通过技术自动化地完成异构平台的系统转换，可帮助用户真正实现系统和数据在云上自由穿梭。

  

![](../Images/dc7cb2d8495e62194a7645923f6bad24.png)

  

Any to Any：由于 NaviClouDR 是一款具备多云 API 融合能力的容灾解决方案，其产品原生为云计算模式所构建，与云平台深度融合的同时兼顾传统数据中心场景，因而具备“Any to Any”能力，这意味着其目标端无论是数据中心，还是私有云、公有云都能够实现高效和标准化的容灾保护。

  

to Any Cloud：据了解，NaviClouDR目前已可以支持包括阿里云、腾讯云、AWS、Azure、VMWare、UCloud、ZStack、青云、GCP等各个主流云服务商，真正实现了对多云平台的兼容，可以更为充分的助力企业覆盖多云场景。

  

落地到具体应用上，意味着用户可以借助嘉云NaviClouDR 解决方案将原有业务往任何自己想要的方向去进行迁移，如数据中心到数据中心、数据中心到云、云到数据中心、云到云。

  

![](../Images/41ba00912edf121614fbc7eb8a321489.png)

  

耳听为虚，眼见为实，在相关技术人员向安全419演示整个迁移的过程中，我们看到的是一场真正的“一键迁移”——得益于自动化工作流的助力，令用户只需简单设置即可完成迁移工作，整个操作过程只需几十秒，迁移（恢复）过程受带宽影响较大，但用时仍以分钟计（180G双盘）。整个产品的优势在这里也有较为突出的体现，那就是大幅度减少人工操作，从而节省人力成本，同时也提升了运维生产力。

  

综上所述，NaviClouDR作为容灾产品解决方案，其灾难恢复过程也是一次完整的整机迁移过程，是以业务系统连续性、数据保护为基础的，在多云环境中提供快速再生的过程。应用选择权则在用户自己，相当于在具备以容灾为代表的网络安全底线能力的同时，可以为用户随时提供想要的上云迁移，或是云与云之间的迁移。

  

**实践案例 嘉云NaviClouDR协助客户**

**实现大规模Azure自动化迁移**

  

在交流的过程中，CloudWonder 嘉云还分享了他们的一项实践案例。

  

该案例的主角是一家总部位于我国香港的某集团公司，其业务遍布全球11个市场130多个城市。为拥抱数字化转型，基于对未来业务系统发展敏捷开发，快速、自由部署和扩展需求，同时有效控制对于传统 IT 架构投入成本，集团决定将IT业务系统全面迁移至微软 Azure。

  

由于原有部分业务被部署在 VMware 平台之上，加上多部门逾百套业务系统统一迁移，匹配的业务类型众多，因此对于迁移上云后的业务完整性以及业务之间逻辑关系的准确性都有极高要求。同时，迁移涉及的数据总量也不小，超过了 50TB。如何在有限的带宽条件下实现高效传输，并在既定时间内完成全部迁移工作，这对该集团的迁移团队提出了巨大挑战。

  

据了解，由于NaviClouDR 采用底层块复制技术进行数据传输，大幅提升了数据传输的效率并确保传输的稳定性，同时提供了压缩、加密等技术，确保数据安全性和最小化数据的传输要求。通过 API 接口与 Azure 平台实现联接，整个迁移过程实现完全自动化操作，在执行迁移命令后，无需任何人工部分的参与，从而大幅降低了迁移的人工和时间成本。

  

在决定迁移切换之前，NaviClouDR 提供的快速自动化验证测试功能，帮助用户有效保证迁移的一次性成功率，确保迁移计划得以合理规划并实施落地。另外，NaviClouDR 可在本地部署多个缓存节点，在不影响业务系统的前提下帮助该集团实现了 7\*24 小时的不间断数据同步。

  

最终，该迁移项目通过 NaviClouDR 提供的解决方案，得以保证该集团的IT业务系统在既定时间内，且业务完全未受影响的条件下完成了快速迁移，保障了集团未来的IT信息化发展。

  

**业务连续性是企业生命线**

**容灾解决方案将逐渐替代传统数据备份**

  

我们前面提及，NaviClouDR 本身是一套容灾解决方案，对于多云环境的迁移支持仅是其自动化工作流程之一，与此同时，该容灾解决方案还创新提出“主动侦测 自我恢复”，这八个字在容灾产品的应用体现也是其核心价值，即主动式数据保护。

  

![](../Images/734a4b255070afe4b9c09ae49a5c81a0.png)

  

主动式数据保护应用到容灾解决方案当中，其应用价值也会完全不同，因为在传统的意识当中，救灾往往是在发现问题之后才进行，但如果告警机制缺乏或者运维机制不完善，有可能导致备份数据被覆盖，造成无法挽回的后果。

  

CloudWonder 嘉云告诉我们，主动式容灾概念则通过智能的识别技术，第一时间侦测到主机业务故障发生的情况，并在业务恢复平台中，全自动实现自动容灾恢复，并通知用户。这将大幅降低传统被动式数据保护，复杂、耗时、易出错的弊端，为用户数据安全提供更智能化的保护手段。

  

以应对勒索攻击为例，该解决方案的主动式容灾一旦侦测到勒索病毒，即刻告知用户，且在灾难发生的时候自动地将灾备系统完成恢复并且就绪。

  

NaviClouDR 另一项重要能力是具备自动化演练，这也是对传统容灾产品在实战时经常遭到质疑的能力提升。CloudWonder 嘉云表示，将灾备演练常态化将从根本上改变传统灾备演练模式中只演不练弊端，实现常态化、自动化演练不仅能够让用户有机会发现，由于业务变化，环境变化所可能导致恢复流程失败的问题，还可以根据发现问题，提出改进建议，及时调整保障灾难恢复有效性。

  

所以，嘉云 NaviClouDR 解决方案完整的应用是以企业业务系统、数据提供容灾保护，并提供主动保护机制，在安全事件发生时，比如说网络攻击，或是人为因素造成的错误，同时容灾方案本身也对真正意义上的灾难事件提供良好保护，该方案可以第一时间帮您做迁移恢复，一系列的安全自动化能力全力保障了企业在线业务的连续性，以及核心数据的安全性，从而能让运维团队在威胁到来之前和之后更加从容应对。
