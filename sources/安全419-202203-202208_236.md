# 网安风向标 | RSAC2022创新沙盒大赛十强解读

RSAC2022创新沙盒大赛将于旧金山时间6月6日召开，作为“安全圈的奥斯卡”，大赛逐渐成为全球网络安全行业技术创新和投资的风向标，也因此每年都备受外界所瞩目。安全419关注到绿盟科技创新研究院近一段时间分别对RSAC2022十强初创公司作出解读，本篇为主要内容摘录。

  

![](../Images/93db468a3eb34d138892ac906cad0a04.png)

  

本次创新沙盒十强中共有4家云安全公司，但通过对2022年的云安全产品进行分析，发现这些公司的产品功能已很难用单一的传统云安全产品概念去覆盖。这些产品很难被归类为传统的云安全产品（CASB、CSPM、CIEM等），而是同时覆盖了云安全领域与其他安全技术领域的交集。一方面，这些产品为云环境中的接入方式与特有安全风险都提供了良好的兼容；另一方面，这些产品也针对某一些具体任务或具体场景提供了完善的安全能力。

  

RSAC2022除了云安全类公司入围数量上升之外，也出现了往年少有关注的领域，这可能归功于疫情在全球范围的持续影响，比如为远程办公提供支撑的浏览器安全。同时纵观今年的十强创新企业，其产品在设计上也存在更多的共性，比如更加积极的与安全生态上的兼容，从而辅助自动化响应等。

  

根据主要产品类别，创新沙盒十强公司可以被分为以下几类：

  

![](../Images/386faaa9a1090a000517ef4993cb6ecb.png)

  

**一、Araali Networks**

**云原生风险缓解**

  

Araali Networks是一家为云原生环境提供威胁管理解决方案的公司。Araali Networks提出了一种叫做Resilient-Patching弹性补丁的技术解决方案，可对威胁进行检测和拦截，从而建立完整的识别、保护、检测、响应和恢复的安全框架，实现了安全的闭环运营。

  

Araali Networks创办于2018年，总部位于美国加利福利亚州，并于2020年获得了种子轮投资。其创始人兼CEO Abhishek此前是Tetration Analytics的联合创始人/工程副总裁，在加入Tetration之前，他曾在Aruba、Cisco和Ericsson担任工程领导职务。

  

**二、Cado Security**

**云原生取证与响应**

  

Cado Security 是一家云原生网络取证和响应平台提供商。代表产品Cado Response将事件响应概念移植入云环境，并借此在云环境、容器环境以及无服务器环境下捕获详细数据，帮助安全团队以云速度进行调查并做出反应。

  

该公司于2020年4月成立，目前在英国和美国设有办事处，旨在为安全团队提供更智能、更快速的方式来调查和响应云中的网络安全事件。该公司成立不久便获得150万美元种子轮融资，2021年又获得1000万美元A轮融资。其首席执行官兼联合创始人James Campbell具有丰富的网络事件响应经验和国家情报工作背景。

  

**三、Lightspin**

**攻击者视角下的DevOps安全**

  

Lightspin是一家云安全初创公司，旨在提供针对云原生应用保护的解决方案。代表产品是一个基于图表的云原生应用程序保护平台 (CNAPP)，该平台可以识别、确定优先级并修复云堆栈中的攻击路径。同时还可以减少DevOps和安全团队保证云服务平台安全性所需要的时间、成本及资源。

  

该公司于2020年底在以色列特拉维夫成立。据介绍，其创始团队成员具有丰富的渗透测试经验，两位联合创始人曾在Cymotive共事，分别负责汽车云团队和云安全架构工作，也都对云计算领域的攻击技术有较深的了解。Lightspin在创立至今的两轮融资中共筹集了2000万美元资金。

  

**四、Neosec**

**面向API安全的SaaS化防护方案**

  

Neosec专注于API安全领域。公司主打基于AI驱动的API安全平台，其以SaaS化的形式部署于云中，自身设计支持可扩展，可集成，实现可持续的API发现、基于API的行为和上下文威胁分析、API威胁狩猎、自动化响应编排。

  

Neosec成立于2020年1月，总部位于以色列，其首席执行官兼创始人Giora Engel毕业于以色列希伯来大学，毕业后曾任职于以色列国防部，后于2011年创立了LightCyber公司，后被Palo Alto收购，Giora Engel曾在Palo Alto担任产品管理VP职位长达三年。

  

**五、Torq**

**无代码安全自动化**

  

Torq原名StackPulse，是一家致力于无代码-安全自动化运维的初创公司。代表产品无代码平台包含多个模块，如自动化威胁情报狩猎、自动化云安全态势修正、安全告警修复、钓鱼邮件响应、可疑用户的调查响应和应用安全模块等。

  

Torq于2020年在美国注册成立。公司由Ofer Smadari、Leonid Belkind和Eldad Livni三人共同创建，目前Torq已进行四轮融资，总金额达到7800万美元，其中A轮和B轮融资规模分别为2000和5000万美元。

  

**六、Dasera**

**全生命周期保护云上数据安全**

  

Dasera是一家是一家引领数据治理与运维的公司。代表产品数据安全平台从客户的基础设施、数据和访问用户获取上下文，并持续监控客户的数据和数据管理策略，帮助企业实施数据治理方案，从而为企业存储于云上的数据提供全生命周期的防护，实现敏感数据的安全使用。

  

Dasera公司于2019年在加利福尼亚州成立，该公司成立当年即获得300万美元融资，并于2021年再次获得600万美金种子轮融资。该公司CEO Ani Chaudhuri具有丰富的创业经验，创立的科技初创公司eCircle被Reliance收购，Opelin则先后被惠普和Whodini收购。

  

**七、Sevco Security**

**专注数据融合的资产管理平台**

  

Sevco Security是一家提供网络安全服务和产品的公司。代表产品资产管理平台，可通过集成现有资产管理平台的资产清单，对多源资产管理软件的数据融合，建立更全面的资产库，以识别企业网络中的脆弱资产，从而实时跟踪资产库中资产状态变化情况。

  

Sevco Security成立于2020年，总部位于得克萨斯州奥斯汀，初创团队主要来自Carbon Black（终端安全公司，2018年在纳斯达克上市）和Cylance（人工智能和网络安全公司，已被黑莓14亿美金收购）等成功创业团队。该公司于2020年和2021年完成了共计两轮融资，融资金额超过2000万美元。

  

**八、BastionZero**

**零信任基础设施访问服务**

  

BastionZero最初是一家区块链安全公司，受疫情影响业务中心转向了基础设施访问控制安全。代表产品BastionZero除了可提供对基础设施的零信任远程访问外，其独特的安全模型解决了传统零信任架构面临的单点攻陷问题。

  

BastionZero于2019年成立，由波士顿大学计算机科学系副教授Sharon Goldberg创立，注册地位为美国马萨诸塞州首府波士顿，Sharon Goldberg曾在IBM、Cisco和 Microsoft担任研究员。BastionZero在种子轮融资中获投600万美元。

  

**九、Cycode**

**软件供应链安全完整解决方案**

  

Cycode公司专注于软件供应链安全，开发了业界首个源代码控制、检测和响应平台。代表产品为一个具备DevOps工具安全、防代码篡改、硬编码机密监测、源代码泄露监测和基础设施安全的软件供应链安全解决方案平台。

  

Cycode成立于2019年，总部位于以色列特拉维夫，公司的首席执行官兼创始人为Lior Levy，他在网络安全攻防方面拥有十多年的经验，曾是以色列国防部的网络架构师兼安全研究员。Cycode于2021年11月完成了5600万美元的B轮融资。

  

**十、Talon Cyber Security**

**面向企业的安全浏览器**

  

Talon Cyber Security是为远程办公提供网络安全解决方案的提供商。Talon的主打产品是一款面向企业的安全浏览器TalonWork。产品宣称“通过提供全面的安全性、简单的部署和无摩擦的用户体验（UX）来保护企业工作环境。可以在任何地方工作，也支持在自带设备（BYOD）上工作，而无需进行严格的设备管理或复杂而昂贵的网络控制”。

  

Talon有两位已知的创始人，其中一位Ohad Bobrov同时也是Lacoon Mobile Security公司的创始人和CTO，而另一位Ofer Ben-Noon曾担任以色列网络情报单位8200部队的上尉，并且是两个以色列国防奖获奖项目的团队成员。Talon已经完成两轮总额4300万美元融资。
