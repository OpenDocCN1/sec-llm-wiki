**1、中安网星完成数千万Pre-A轮融资**

  

5月19日，身份威胁安全方案提供商中安网星宣布已于日前完成数千万Pre-A融资，本轮投资方为AA投资。至此，中安网星在近12个月内完成了三轮融资，已引入包括初心资本、微步在线等在行业内极具影响力的投资方。中安网星介绍，本轮融资资金将用于加速产品矩阵研发、加强团队建设、加大市场覆盖速率。

  

**2.公安部公布五类高发电信网络诈骗类型，"刷单"占榜首**

  

5月11日，公安部公布了五类高发电信网络诈骗案件，以进一步提升群众防骗防诈能力。公安部指出，刷单返利、虚假投资理财、虚假网络贷款、冒充客服、冒充公检法5种诈骗类型发案占比近80%，成为最为突出的5大高发类案，其中刷单返利类诈骗发案率最高，占发案总数的三分之一左右；虚假投资理财类诈骗涉案金额最大，占全部涉案资金的三分之一左右。

  

**3、****超过 380,000 台 Kubernetes API 暴露在互联网上**

  

非营利性网络安全组织Shadowserver近日称，在对互联网展开来的 Kubernetes API 服务器扫描探测过程中，发现大约 380,000 个允许某种形式的访问。其中，超过一半的暴露实例位于美国，其中许多也出现在西欧、东南亚和澳大利亚。Shadowserver表示，虽然这并不意味着这些服务器完全开放或容易受到攻击，但 Shadowserver 认为它们代表了“不必要的暴露的攻击面”。

  

**4、****微软警告针对加密钱包的“Cryware”信息窃取恶意软件**

  

微软警告称，针对联网加密货币钱包的新威胁“cryware”近期十分活跃，Cryware 是直接从非托管加密货币钱包（也称为热钱包）收集和窃取数据的信息窃取程序，此类攻击通过向对手控制的钱包进行欺诈性转移，导致虚拟货币不可逆转地被盗。

  

微软称，“因为热钱包与托管钱包不同，它存储在本地设备上，并且可以更轻松地访问执行交易所需的加密密钥，因此越来越多的威胁正以它们为目标。”  

  

**5、****Conti团伙声称将删除哥斯达黎加政府的解密密钥**

  

臭名昭著的 Conti 勒索软件团伙上个月对哥斯达黎加的行政系统发动了攻击，威胁要“推翻”该国的新政府。为了进一步增加压力，该网络犯罪集团已将其赎金要求提高到 2000 万美元，以换取用于解锁其系统的解密密钥。上周末， Conti 在其暗网网站中发出最后通牒，称将在一周内删除解密密钥，此举将使哥斯达黎加无法恢复对勒索软件加密文件的访问权限。
