# 亚马逊的安全基因Job Zero：比任何第一要务都更重要

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMDQ4OTkyMg==&mid=2247497671&idx=1&sn=3e95ac97b285fd7e9c950114f869bc7a&chksm=f9eb296ace9ca07cfcf03730ddf988895a7b333ed4c35a9500deb4ea0a33be0f268fe8b977ee&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUyMDQ4OTkyMg==&mid=2247497671&idx=1&sn=3e95ac97b285fd7e9c950114f869bc7a&chksm=f9eb296ace9ca07cfcf03730ddf988895a7b333ed4c35a9500deb4ea0a33be0f268fe8b977ee&scene=27#wechat_redirect)

亚马逊前不久发布2021年Q4财报显示，AWS业务在过去一年第四季度收入同比增长40%，仍然是增长最快的细分领域业务。与此同时，近期数个调研机构发布相关报告显示，亚马逊AWS业务在全球多个地区仍高居领导者地位。在全球领域，亚马逊AWS市场占有率已高达4层以上。

  

当全球进入中疫情时期，云作为承载数字化转型最重要的基础设施，市场正迎来高速增长。上云不再是趋势，已成为必然。在这一方面，亚太地区更成为全球用云高地，随着经济持续稳定发展，中国区市场亦是云厂商争抢的最大蛋糕。

  

![](../Images/052267ca45ae30b53d1d80e0170020dd.png)

  

为持续推进中国区市场业务，本周（3月24日）亚马逊云科技在京召开媒体见面会，安全419受邀在场见证了亚马逊AWS的安全合规战略。

  

**上云已成安全合规最佳捷径**

  

亚马逊云科技大中华区战略业务发展部总经理顾凡向媒体表示，安全合规已成为企业开展全球性业务的最大挑战。他指出，132个国家和地区制定了不同的数据保护和隐私相关的法律法规，企业需要为业务拓展全面评估各个地区的法律法规，开展全球性经营时正面临更大的压力。

  

据悉，亚马逊云科技为此建立了一系列措施，来帮助企业在全球各地区快速开展安全合规业务。AWS可为客户提供包括数百项安全、合规性和监管服务及功能，并支持近百项安全标准和合规性认证，且存储客户数据的全部AWS服务均具有加密数据的能力。

  

在中国市场，亚马逊云科技也在持续加大安全合规领域投入，安全合规基础设施和云服务相辅相成，并通过本地化合作模式落地实践，全方位帮助客户提升云中安全与合规，帮助中国企业在全球快速落地业务，以及国际企业来华开展业务。

  

此前，亚马逊云科技通过与光环新网和西云数据的紧密合作，在中国区域已推出50多项安全合规的服务和功能，现在，亚马逊云科技已宣布进一步升级与德勤中国的合作，由德勤中国推出安全运营中心服务，该运营中心将在亚马逊云科技上为客户提供云上端到端的安全监测及响应服务，提升企业云上安全。

  

**“Job Zero” 亚马逊的安全基因**

  

![](../Images/713c2cff133daab6ed534120105e89e5.png)

  

亚马逊总裁兼首席执行官Andy Jassy曾指出：安全是我们的Job Zero。意思是它比任何第一要务都更重要，其理解深度值得推崇。据了解，在“Job Zero”这一安全文化精髓之下，亚马逊从上至下建立了系统化的安全架构标准，每一名员工深度参与，并形成了自动化+创新的安全运营理念。

  

这也是亚马逊AWS将成为客户优选的信心源泉，其自身云基础设施的安全性已成为行业标杆。据消息称，对安全要求极高的纳斯达克将计划在2022年实现100%迁移到AWS，这也代表着对AWS安全性的高度认同。

  

在这一方面，除了云基础设施自身安全之外，企业还需要考量的是如何保障云上业务安全。据了解，亚马逊目前拥有280多项安全、合规服务及功能，涵盖威胁检测和事件响应、身份认证和访问控制、网络和基础设施安全、数据保护与隐私以及风险管控及合规五大领域。

  

在本次媒体见面会上，我国企业TCL分享了其全球化安全合规实践。据悉，TCL实业作为“中国智造”出海的代表性企业，其已将海外业务的多个重要核心系统部署在亚马逊AWS上，实现安全合规的全球部署，同时使用Amazon WAF、 Amazon GuardDuty、Amazon Security Hub等安全服务提升云端安全。
