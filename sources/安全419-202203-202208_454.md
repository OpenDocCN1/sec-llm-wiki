# 翻倍扩容 微软 Azure 中国新区官宣启动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMDQ4OTkyMg==&mid=2247497521&idx=3&sn=ef59f8dd593f879eaa24dd5535f676e3&chksm=f9eb299cce9ca08a464df53bdcfca38b9e1c40a1aa5d3eaa8c5874d8675742fca3e6b1fd29d5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUyMDQ4OTkyMg==&mid=2247497521&idx=3&sn=ef59f8dd593f879eaa24dd5535f676e3&chksm=f9eb299cce9ca08a464df53bdcfca38b9e1c40a1aa5d3eaa8c5874d8675742fca3e6b1fd29d5&scene=27#wechat_redirect)

2022年3月17日，微软召开线上发布会，正式官宣微软 Azure 中国新的数据中心——中国三区正式上线运营。安全419观察发现，随着 Azure 中国新区启动，微软 Azure 在我国云计算业务承载能力相比之前已得到两倍以上的扩容，从中可以看到微软对云计算业务增长最快、规模最大的中国区域市场的觊觎之心。

  

![](../Images/74801ecf5eed64a6f474952ea8defe27.png)

  

微软全球资深副总裁、微软大中华区董事长兼首席执行官候阳博士，在线上发布会致辞环节中宣布了 Azure 中国新的数据中心正式启动。他表示，数据中心是云计算的心脏和发动机，Azure 中国新区域的建设采用了业界领先的数据中心技术，计算效率和性能进一步得到了提升。Azure 中国三区启用之后，将作为微软创新云服务落地中国市场的桥头堡，服务和赋能更多客户的中国创新，为中国的数字化转型添砖加瓦，助力每一人、每一组织成就不凡。

  

据悉，微软 Azure 新数据中心除了采用 Dv5 和 Ev5 系列虚拟机，借此发布会，还首次发布了 Mv2 新一代大型虚拟机，Mv2 专门为企业海量数据、管理需求配置，从而对蓬勃发展的高性能计算产业提供支持。此外，多项云上应用也将被引入到国内市场，如 Azure Digital Twins（微软云上数字孪生平台）、Azure Arc（微软多云管理工具）等等。

数字化转型 战略与机遇并存

  

微软中国区总裁包嘉峰在发布会上强调了微软中国的云战略，三大方向分别是 go china、go global、lndustry，归纳总结分别是帮助跨国企业来华开展业务，帮助我国企业走出海外，利用微软云定制解决方案致力于各行各业成功的数字化转型。

  

安全419观察发现，微软 Azure 中国新的数据中心即是微软云计算全球战略长远规划的一部分，因为几乎同一时间，微软在印度市场同样启用了全新的数据中心，同时数据中心建设也需提前规划和审批。但从现在的时间结点来看，新的数据中心对于微软而言也将是一次难得的战略机遇。

  

如今中国社会方方面面正大力发展数字经济，企业正处于数字化转型重要时期，而处于顶端的云服务厂商在其中将扮演至关重要的角色。微软 Azure 由世纪互联运营，世纪互联集团高级副总裁、世纪互联蓝云 CEO 刘启航在启动会上就提到了这一点，从他的表述中可以看出，微软 Azure 也希望能从中国市场大机遇的广阔前景下，打造出优质的数字应用未来模板。

绕不开的安全、合规问题

  

企业将业务上云核心考量之一就是安全问题，而开展国际化业务，更要对遵守不同国家、地区的法律法规硬性合规要求。对此，此次线上发布会上来自微软大中华区、微软中国的多位高管、专家对此也作出了大量的介绍，安全419现整理如下：

  

1、中国三区新数据中心拥有可用性区域 Availbaility Zone 垮区灾备技术加持，针对特定计算和虚拟机服务，提供高达99.99%的 SLA 保证，来支持不同场景下关键业务系统的灾备冗余和稳定运行。

  

2、微软全球承诺会在2030年实现碳负排放，Azure 中国新区正是以此标准进行规划建立，并持续升级。未来，微软可持续发展云将以生态安全为考量，可持续发展为目标，将向全行业输出碳中和解决方案。

  

3、Azure 数据将存储在中国本地，中国新区将与微软全球运营的云服务物理隔离，在数据隐私保护方面，Azure 客户完全拥有并控制自己的业务和客户数据。

  

4、微软 Azure 拥有100+合规认证，并持续跟踪各各国家、地区的现有标准和规章，以及行业标准，评估潜在的新要求，并开发相应的控件。

  

5、由世纪互联运营的 Azure 云服务，不仅提供合规的本土云端服务，同时在数据及应用安全方面，微软安全产品融合了超过40种云安全服务，以身份和访问管理、威胁保护、统一终端管理、信息（数据）保护、云安全管理五大维度为云上用户护航安全。

  

6、微软网络防御运营中心8500名全职安全专业人员，以平均每日处理上万亿全球安全信号，持续跟踪攻击形式，研判技术漏洞，开展持续的 Azure 安全保障工作。

  

7、基于安全无极限认知，微软每年都会更新云计算时代安全战略架构，持续开展云计算安全前瞻性研究，持续保障云计算平台安全。

  

![](../Images/ccfcd76f502f94142763d381bfb6cd2e.png)

  

相关报告显示，目前，全球云计算市场微软 Azure 在多个区域占有率排名第二，在亚太市场，微软 Azure 排名阿里云之后，处于第三位，而我国云计算市场则几乎被阿里云、腾讯云、华为云、百度云等本土云计算厂商牢牢把控，但观察发现，亚马逊 AWS、微软 Azure 近期在国内也是动作频频，未来国内云计算市场在外来和尚面前，市场竞争定会越加激烈。
