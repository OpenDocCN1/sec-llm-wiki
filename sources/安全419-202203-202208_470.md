# 云计算市场竞争激烈 安全问题已成为核心建设考量

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMDQ4OTkyMg==&mid=2247497375&idx=2&sn=23aa23497c183e4eeef14f6e1e1c542d&chksm=f9eb2832ce9ca124553b551e748dc025aadcbb5af102d5f47494283720604a46eb7488eb2bd2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUyMDQ4OTkyMg==&mid=2247497375&idx=2&sn=23aa23497c183e4eeef14f6e1e1c542d&chksm=f9eb2832ce9ca124553b551e748dc025aadcbb5af102d5f47494283720604a46eb7488eb2bd2&scene=27#wechat_redirect)

致力于网络和电信行业提供市场情报和分析的调研机构 Synergy 近日发布相关报告，根据最新数据显示，亚马逊（AWS）、阿里巴巴和微软是亚太地区云计算市场的领导者。亚马逊在五个亚太地区中的四个处于领先地位，领先于区域其它竞争对手。微软现在在四个子区域中排名第二，在整个亚太地区排名第三。腾讯在整个亚太地区排名已经来到了第四位，高于谷歌，同时百度也在持续发力云计算业务。

  

![](../Images/ccfcd76f502f94142763d381bfb6cd2e.png)

  

从上图可以看到，阿里巴巴在中国仍然处于领导者地位，拥有强大的领先优势，并且在东亚其他地区、南亚和东南亚以及大洋洲也处于领先地位。阿里云在整个亚太地区的云计算业务也是高居第二位，仅次于亚马逊。

  

在中国云计算市场方面，除了阿里云之外，该份数据中依次的排名是，腾讯云、百度云、中国电信、华为云和中国联通。与之类似的情况也发生在日本，富士通在日本目前也占据优势地位；Naver 和 KT 在韩国同样占据重要地位；而 Telstra 则在澳大利亚市场处于优势地位。

  

报告还指出，亚太地区前20名云提供商还包括京东云、金山云、光环云等，这也预示着，在中国乃至整个亚太地区，未来云计算市场竞争也将越加白热化。

  

报告重点提及，来自云基础设施服务的亚太地区收入在去年第四季度达到近170亿美元，并且每年以超过40%的速度增长。公共 IaaS 是该地区最大的分支市场，其次是公共 PaaS 和托管私有云服务。

  

由于数据库和面向物联网的服务增长特别强劲，公共 PaaS 在该季度的增长率最高。亚太地区现在占全球市场的1/3，并且继续比北美或欧洲、中东和非洲市场增长得更快。尽管所有亚太地区的子区域都在强劲增长，但增长率最高的是南亚和东南亚，这在很大程度上要归功于印度。

  

但报告重点强调了一点，虽然印度市场增长更快，但中国仍然是迄今为止该地区最大的市场。

  

观察发现，前不久，微软在中国市场和印度市场均开放了全新的数据中心，预示着将进一步开辟两处的云计算业务，而对于微软 Azure 如何成为用户优先时，其相关人员解释了创新性和安全性两大方面因素，可见，云计算自身的安全性，越来越成为获客的先决标准和硬性条件之一。

  

亚马逊（AWS）也不断重视和加大在中国市场上云计算业务推广，近日，安全419就受到邀约，亚马逊将向媒体讲述其安全合规方面的优势。

  

谷歌近日则以54亿美元成功截胡微软，收购了安全企业 Mandiant，而后者被爆出将直接加入到谷歌的云计算部门。可见，各云企对安全本身的重视程度是如此之高。

  

来到中国，业内人士曾指出，以并购达成某种战略能力在国内还没有成为主要方向，而国内，如阿里、腾讯、华为等，均自身设立有独立的安全部门。同时强调产业生态上的合作来致力于安全能力的建设与提升。

  

以腾讯为例，腾讯调整组织架构拥抱产业互联网之后，以腾讯云为门面的腾讯云与智慧产业事业群被认为是决胜未来的关键，腾讯安全也被划分到该组织架构之下。这也意味着，腾讯安全庞大的技术安全团队核心职责未来将向“云端”靠拢，一方面将安全服务内置到云中，同时也为云服务本身提供全面防护。
