# 工业控制系统漏洞披露在过去四年中激增110%

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMDQ4OTkyMg==&mid=2247497198&idx=3&sn=107d0152affaa97bdbbe6a9a0bc4ff4a&chksm=f9eb2b43ce9ca255050bd1b35e8028a0459d0f6e1cd4f8dda9d796f05c2fe7a3634212f87817&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUyMDQ4OTkyMg==&mid=2247497198&idx=3&sn=107d0152affaa97bdbbe6a9a0bc4ff4a&chksm=f9eb2b43ce9ca255050bd1b35e8028a0459d0f6e1cd4f8dda9d796f05c2fe7a3634212f87817&scene=27#wechat_redirect)

  

根据 Claroty 发布的一项研究报告称，工业控制系统（ICS）漏洞披露在过去四年中增长了惊人的 110%，与前六个月相比，2021 年下半年增长了 25%。

ICS 漏洞披露增加

  

该报告还发现，ICS 漏洞正在从运营技术（OT） 扩展到扩展物联网（XIoT），到 2021 年 2 月，有 34% 的漏洞影响 IoT、IoMT 和 IT 资产。

  

“随着越来越多的网络物理系统相互连接，从互联网和云中访问这些网络需要防御者拥有及时、有用的漏洞信息来为风险决策提供信息。”Claroty 研究副总裁 Amir Preminger 表示。

  

他进一步补充说：“数字化转型的增加，加上融合的 ICS 和 IT 基础设施，使研究人员能够将他们的工作从 OT 扩展到 XIoT。过去一年备受瞩目的网络安全事件，例如 Tardigrade 恶意软件、Log4j 漏洞和对 NEW Cooperative 的勒索软件攻击，显示了这些网络的脆弱性，强调了安全研究社区合作发现和披露新漏洞的必要性。”

该报告的主要发现：

  

1、ICS 漏洞泄露在过去四年中增长了 110％，50％ 的漏洞是由网络安全公司的研究人员发现，他们的工作重点已转移到包括 IT 和 IoT 安全研究，安全环境将有所转变。

  

2、34％ 的漏洞披露了 IOT，IOMT 和 IT 资产，表明组织将在融合安全管理下合并 OT，IT 和 IoT。因此，资产所有者和运营商必须具备摸清旗下所有相关资产的能力，以便管理漏洞并减少其曝光率。

  

3、内部供应商研究披露的漏洞在过去四年中增长了 76％。这证明了漏洞研究的成熟行业和纪律，因为供应商正在为其产品的安全分配更多资源。

  

4、87％ 的漏洞是较低的复杂性，这意味着它们不需要特殊条件。在成功利用漏洞之前，70％ 不需要特殊权限，64％ 的漏洞不需要用户交互。

  

5、可以通过网络远程利用的漏洞占比为 63％，表明需要安全的远程访问解决方案，这些解决方案正由于新冠疫情大流行而加速。

  

6、影响最重的无疑是远程代码执行（53％），其次是拒绝服务漏洞（42％），绕过保护机制（37％），允许读取数据（33％） 。

  

7、缓解因漏洞带来的安全性建议依次是网络分割，其次是勒索，网络钓鱼和垃圾邮件保护和访问控制。
