微软在华新数据中心启用 云计算市场竞争加剧

据中国日报报道，微软位于我国华北的新数据中心已经建成并正式启用。报道称，该数据中心为迄今为止微软在中国市场拥有的最大的数据中心。这也代表着，微软在中国这个全球增长最快的公共云市场的云计算能力自2014年以来增长了12倍。预示着微软 Azure 中国区业务未来将有更广阔的承载空间。



中国经济受外界瞩目


微软中国总裁包嘉峰表示，新数据中心建成启用，将有助于公司更好地驾驭国家数字化发展的下一波浪潮。


观察发现，疫情以来，中国是世界范围内为数不多的仍保持经济高速增长的国家，这归咎于我国有效的疫情应对措施，同时也与处于十四五规划在内的数字中国战略快速发展密切相关。


报道称，目前微软中国云计算业务约40%来自于帮助跨国公司在中国设立数字化业务，包嘉峰进一步表示，该业务同比增长超过50%。


这表明跨国公司持续看好中国经济，正在积极参与我国的数字化建设，同时，中国模式对世界的影响也将越来越大。


同时，微软中国云计算业务另外40%的则正在帮助中国公司走向全球。


无处不在的安全性


微软 Azure 在新数据中心启用之后，国内云计算市场竞争将进一步加剧，阿里云、腾讯云、华为云等一众公有云厂商将迎来进一步挑战。包嘉峰接受采访时表示，除了全球化和技术创新，安全性和合规性将是微软 Azure 核心优势。


安全419观察到，微软目前正采用积极的方式来应对数字化当中的安全问题，以便让企业在全球都能使用微软 Azure 顺利地达到他们的商业目的。


在整体的安全性上，微软 Azure 采用了基础安全的做法，意为将安全控制集成到硬件和固件组件中，同时提供丰富的内置控件，奉行了简化安全宗旨。


其中数据安全合规是近年来的重点关注，开展全球化业务要求企业遵循各各国家、地区的法律，对此，微软 Azure 聘请了3500多名致力于数据安全和隐私保护的安全专家，以确保企业始终处于合规运营。


Azure DDoS 则为企业提供业务持续在线保护，2021年年末，微软就曾对外披露，针对亚洲一位未具名的 Azure 客户抵御了3.47Tbps的峰值吞吐量和3.4亿包每秒（pps）的包速率的 DDoS 攻击，攻击持续了15分钟，成为有史以来最大的 DDoS 攻击报告。


属于现在和未来的——数字孪生


在技术创新方面，在接受中国日报记者采访时包嘉峰表示，在全球第二大经济体加速数字化转型的背景下，微软正在优先考虑汽车、医疗保健、零售、制造和低碳发展的本地解决方案。例如，该公司正在将云服务 Azure Digital Twins 带到中国，希望为当地客户提供在云中创建物理对象的数字孪生以提高效率的能力。


Digital Twins，即数字孪生，该技术属于现在和未来。


微软对数字孪生的定义如下：


“Azure 数字孪生”是一项平台即服务（PaaS） 产品/服务，它能够创建基于整个环境的数字模型的孪生图，这些图可能是建筑物、工厂、农场、能源网络、铁路、体育场馆，甚至整个城市。这些数字模型可用于获取洞察力，以推动产品改进、运营优化、成本降低和客户体验突破。


Azure 数字孪生可用于设计数字孪生体系结构，该体系结构在更广泛的云解决方案中代表实际 IoT 设备，并连接到 IoT 中心设备孪生以发送和接收实时数据。


安全419观察发现，如今数字孪生已在我国取得了一定规模的应用，如我国举办的本届冬奥会就大量的使用了数字孪生技术，在具体的项目中，该技术的应用带来了高效管理与低碳环保等诸多优势。


未来，数字孪生将会广泛应用于不仅仅以智慧城市，新基建、工业互联网为代表的典型场景，数字孪生本身可视为元宇宙的基石，未来将会有更为广阔的应用空间，甚至是安全本身。
