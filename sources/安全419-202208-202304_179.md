# 安全419《2022年度策划》评选活动——年度十大优秀创业者名单公布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMDQ4OTkyMg==&mid=2247517233&idx=1&sn=40db3165f33a4b79640a032a8b9d69d9&chksm=f9eb5a9cce9cd38a96fbe3d8f447e01fed491c413c4c73427e73ef889b378d275c1c86bb15e9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUyMDQ4OTkyMg==&mid=2247517233&idx=1&sn=40db3165f33a4b79640a032a8b9d69d9&chksm=f9eb5a9cce9cd38a96fbe3d8f447e01fed491c413c4c73427e73ef889b378d275c1c86bb15e9&scene=27#wechat_redirect)

![](../Images/e6208fd75f4dd22bf5959378d54df978.png)

  

年度十大创业者评选活动是安全419《2022年度策划》中的重点之一，也是我们首次推出与人物相关的评选活动。

  

在网络空间环境日益复杂的当下，无论是外部攻击还是内部威胁都呈现出愈加诡谲的姿态，安全的挑战强度在迅速提升，合规与监管逐渐建立健全起来，也提出了愈加精准的安全要求。这些因素，都成为滋生创新的土壤，那些挺身而出的创业者们基于自身对安全形势的理解及思考探索、过往的技术积累，选择或开创了不同的方向，带领企业在创新之路上不断前行，并逐渐成为推动网络安全行业健康发展的中坚力量，整个行业也因此而百花齐放。

  

在刚刚过去的一年中，安全419编辑部接触了近百位我国优秀网络安全企业的创业者，在他们之中，既有那些在安全行业从业20余年的安全精英，也有那些年轻有为、锐气十足的安全新秀，他们对安全行业都充满着热情，锐意创新，关注落地。但不可否认，选择创业这条路本就是挑战，而选择在网络安全行业创业在我们看来更是挑战中的挑战，虽然网络安全行业在当前迎来黄金发展期已经成为业内共识，但整体市场规模偏低，数千家企业竞争其中，对创业者其实并不友好，但他们仍选择走上这条胜者王、败者寇的道路，单凭一腔热情远远不够，那么他们的背后到底是什么在支撑呢？

  

于是就在这一年，安全419编辑部决定推出一个全新的栏目——[**《创业者说》**](https://mp.weixin.qq.com/mp/appmsgalbum?action=getalbum&__biz=MzUyMDQ4OTkyMg==&scene=1&album_id=2415347037006266370&count=3#wechat_redirect)，以期挖掘他们背后那精彩纷呈的故事，展现带领各自的企业在发展的创新之路上一路披荆斩棘的创业精神，更是分享他们对网络安全行业创业的亲身感受和对行业的细微观察，希望通过他们对自己过往那段经历的阐述，能够让人们对于他们及他们的企业有更多维度的了解，同时也对网络安全这个行业拥有更多感性认知。该栏目自推出以来一直备受关注，这也给了我们巨大的动力，不仅坚持把它做下去，而且要越做越好，同时也让我们想到，为什么不用一个评选活动来做一个总结呢？这也是我们将年度十大创业者评选活动加入安全419《2022年度策划》系列活动中的动因之一。

  

在经过紧张、激烈甚至是纠结的内部评审过程后，我们最终取得了一致，十位企业创始人当选成为2022年度十大创业者，具体名单如下：

  

**PS**

  

本活动均不涉及排名，评选结果均以企业首字母排序。

  

**1**

**北京安普诺信息技术有限公司（悬镜安全）**

  

**创始人兼CEO 子芽**

  

  

![](../Images/db8f785b52187f91b8f620867c0193f4.png)

  

  

北京安普诺信息技术有限公司（品牌名称“悬镜安全”）创始人兼CEO子芽，拥有着10年以上前沿安全技术研究实践经验，并长期从事AI深度学习算法在持续威胁评估领域的研究，也是国内倡导DevSecOps理念的先行者，目前也是信息通信软件供应链安全社区首席专家。安全419初次接触子芽是在2021年年初，彼时他们还没有一个自己独立的办公室，但有着强大自信的他在接下来的1年多时间里，成功地带领悬镜安全成为中国开发安全乃至软件供应链安全的头部企业之一，这样的发展速度放在当时我们恐怕是很难想象的。除此之外，这一年多来他还创立了OpenSCA开源社区，以出品人的身份办了两届DSO敏捷安全大会，撰写了一本体系化讲解DevSecOps的新书——《DevSecOps敏捷安全》，而他和他的团队所提出的DevSecOps敏捷安全技术金字塔，也已从1.0更新到目前的3.0版本，对该领域未来的技术演进以及行业发展有着很强的参考价值。可以看到，无论是带领企业发展还是个人发展，子芽这一年多来的精彩表现有目共睹，极为突出。

  

  

**2**

**安芯网盾（北京）科技有限公司**

  

**创始人兼CEO 姜向前**

  

  

![](../Images/17979a2c8901ce7a22ed95daf2c7c5aa.png)

  

  

安芯网盾（北京）科技有限公司（以下简称“安芯网盾”）创始人兼CEO姜向前自大学毕业后就开始从事网络安全相关工作，在2009年与姚纪卫（安芯网盾创始人、现任CTO一职）联手创立了百锐信息安全实验室，那也是他的第一次创业，成为首批基于行为检测分析的恶意代码检测引擎开发商。十年之后的2019年，姜向前在创业之路上再次出发，选择以内存安全为方向，成立安芯网盾，次年就夺得了BCS安全创客汇的冠军。截至目前，作为国内首家提出“内存保护”概念的公司，安芯网盾所提供的新一代高级威胁实时防护端点安全解决方案已服务于众多行业客户，广受好评和肯定。作为一名创业者，哪怕经历过一些坎坷也从未放弃，20余年坚守网络安全行业，从现在看，这份坚持也得到了回报，相信我们也一定能看到他再接再厉，取得更高成就。

  

  

**3**

**北京华顺信安科技有限公司**

  

**创始人兼CEO 赵武**

  

  

![](../Images/2467c8b4fccbdae20985bfe34eea7d71.png)

  

  

北京华顺信安科技有限公司（以下简称“华顺信安”）创始人兼CEO赵武，是中国网络空间资产测绘领域的奠基人之一。值得一提的是，作为一名创业者，华顺信安其实是他打造的第二家企业。在此前创办诺赛科技期间，赵武独自研发出包括 Pangolin（穿山甲）、Jsky、iiscan 在内的多款知名安全软件，在国内外广受安全从业者追捧。成立华顺信安后，赵武带领团队创建了现国内最大的白帽生态社区-FOFA社区，并打造出多款网络空间安全测绘主流产品。在他的掌舵之下，华顺信安通过融合敏锐的网络安全威胁发现能力，形成了独有的网络空间资产安全生态。资本层面，华顺信安在2022年完成了数亿元人民币的C轮融资。正如他们自己所说的，“不忘初心，专注网络空间测绘，我们，一直在路上！”相信赵武在这一领域会走得更远。

  

  

**4**

**北京华云安信息技术有限公司**

  

**创始人兼CEO 沈传宝**

  

  

![](../Images/131db14c2884e8babc4cdc7692ac9eb3.png)

  

  

北京华云安信息技术有限公司（以下简称“华云安”）创始人兼CEO沈传宝的履历十分丰富，作为有着20年以上行业经验的安全老兵，他既有甲方的从业背景，又有着丰富的安全行业专业经历，也曾参与其他安全领域的创业项目，这丰厚的经验对他现在所掌舵的华云安而言，是无比宝贵的财富。在沈传宝的带领下，2019年7月才刚刚成立的华云安目前已经完成三轮融资。他秉承数据驱动、AI引领的理念，不断将攻防能力落地为可用的产品和方案，更是国内首批倡导攻击者视角构建完整攻击面管理体系者，目前华云安已发展成为我国攻击面管理领域的头部企业之一，被列入Gartner 2022中国网络安全技术成熟度曲线《Hype Cycle™ for Security in China, 2022》报告中攻击面管理、入侵和攻击模拟两大创新领域的代表厂商，不得不说，2022年的沈传宝真是收获满满，成绩斐然。

  

  

**5**

**北京数安行科技有限公司**

  

**创始人兼CEO 王文宇**

  

  

![](../Images/e3588e15784834ccc2370aee3ba1998a.png)

  

  

北京数安行科技有限公司（以下简称“数安行”）创始人兼CEO王文宇在数据安全行业有着20余年的从业经历，这意味着他也是这个行业中最懂数据安全那批人中的一位。在2020年创立数安行以来，一贯倡导并坚持DataSecOps数据运营安全理念，带领团队坚持走自主研发路线，创造性地推出以零信任为基础、人工智能为核心驱动的数据运营安全平台，在不改变网络架构、不改造业务的情况下，自动发现及识别数据运营过程中的数据安全风险，并执行自适应的防护策略，构建全场景数据运营安全风险分析及防护体系，对政务数据、个人隐私数据以及商业秘密数据进行有效保护，从而实现让数据安全地创造价值，行业价值显著。这一系列的成绩表明，王文宇对数据安全行业的观察、理解和判断都十分精准，不仅寻觅到适合自己的创业方向，更是以坚守初心和锐意创新的态度，稳扎稳打的作风，令数安行从0开始到现在在产品化、商业化等诸多方面都取得突破，交出一份亮眼的成绩单。

  

  

**6**

**北京微步在线科技有限公司**

  

**创始人兼CEO 薛锋**

  

  

![](../Images/fa5e2eb38ddc878c7a4717e28d3819e4.png)

  

  

北京微步在线科技有限公司（以下简称“微步在线”）创始人兼CEO薛锋曾在微软、亚马逊等国际顶尖科技企业担任要职，于2015年7月发起并成立了微步在线，并在不到3年的时间里，就让它成为了中国威胁情报领域的头部企业，多次入选全球网络安全500强，更是2017-2021年连续四次入选Gartner《全球威胁情报市场指南》，这一成绩迄今仍没有其他中国企业可以做到。在薛锋的带领下，微步在线的安全能力和业务范围逐渐从威胁情报拓展到全方位的威胁发现和响应，先后推出了一系列基于不同安全场景和需求的网络威胁检测响应产品。另外，薛锋在2022年做出了一个重要决定——在成立七周年之际正式宣布品牌全新升级。以“数字时代网络威胁应对专家”为新定位，并发布了新的品牌口号“让安全没有边界”，也成为2022年网络安全行业的大事件之一，更是让我们对踏入新领域的微步在线产生了诸多期待。

  

  

**7**

**成都无糖信息技术有限公司**

  

**董事长、CEO 张瑞冬**

  

  

![](../Images/d9d17ba64ea74cbfc88a10bac7dff7f0.png)

  

  

成都无糖信息技术有限公司（以下简称“无糖信息”）董事长、CEO张瑞冬是国内最有影响力的白帽子之一。13岁发现银行ATM机程序的逻辑漏洞，14岁就在黑客网站做管理员，中学毕业以后就开始从事网络安全工作，并成长为一位被安全圈熟知的技术大牛（Only\_guest），在WEB安全、漏洞挖掘、网络攻防等研究领域具备卓越的技术实力和丰富的实战经验。张瑞冬始终坚持科技创新是企业发展的根本动力，在2017年创立无糖信息后，主持并引领研发团队攻克多个关键核心技术，先后申请13项国内发明专利，拥有40项知识产权。在他的带领下，无糖信息以网络安全核心技术为基础，为各地公安机关提供网络犯罪案件协查和技术攻坚支持，旗下主要产品——猫头鹰电信网络诈骗预警平台，每月电信网络诈骗全国预警数据高达近1000万条，月累计发现识别各类诈骗网站7万余条。此外，他们已与300余家公安机关开展合作，每年为公安机关提供各类案件支撑服务500余起，这些成绩可以看出，张瑞冬所掌舵的无糖信息在该领域不仅具备技术水平领先的优势，更是为我国网络信息安全领域的发展和创新作出了积极的贡献。

  

  

**8**

**江苏易安联网络技术有限公司**

  

**创始人兼CEO 杨正权**

  

  

![](../Images/61051ed94df870adb597529710785f3b.png)

  

  

江苏易安联网络技术有限公司（以下简称“易安联”）创始人兼CEO杨正权，是一位在网络信息安全领域有着20余年经验的企业家。在他带领下，易安联历经过多年的发展，从早期的SSL VPN到CASB，再到现在的零信任，他始终坚持围绕着应用访问安全领域在深耕，在我们看来，这一点尤为难能可贵。自2017年5月确立并启动企业集团化战略以来，于2019年推出EnSDP整体解决方案，截止目前，易安联已成长为行业内领先的“零信任”解决方案提供商，围绕应用访问安全先后发布6款基于零信任架构的网络信息安全产品，为政府、金融、教育、运营商、能源等行业客户提供零信任安全解决方案。从早期创业到历经坎坷到最终守得云开见月明，老杨堪称网络安全行业中创业者的典范之一。

  

  

**9**

**深圳永安在线科技有限公司（威胁猎人）**

  

**创始人兼CEO 毕裕**

  

  

![](../Images/593185a482ef4703f87a6fb7c6872edc.png)

  

  

深圳永安在线科技有限公司（品牌名称“威胁猎人”）的创始人兼CEO毕裕在三十而立的年纪辞去了头部大厂的稳定工作，自立门户，不出几年已被业内人唤作“老毕”，能看得出他在网络安全这个“江湖”打响了自己的名号，当然，他还不老。自2017年创业至今已近六年的老毕，面对发展历程中的坎坷和诱惑，始终心无旁骛，和同样年轻的创业团队一起，坚持以情报为底层核心能力，并基于此打造了业务风险情报平台、API安全管控平台等服务和产品，目前无论是在产品能力还是在客户接受度方面都已经位居市场前列。他常说的一句话是将军赶路，不追野兔，威胁猎人能走到今天，应该说和老毕这一特质有着很大的关系，相信未来在基于情报这一底层能力基础之上，老毕和他的威胁猎人还能为我们带来更多惊喜。

  

  

**10**

**北京云科安信科技有限公司**

  

**CEO 金飞**

  

  

![](../Images/99365b54d9a18f65b8bef4f0674bf994.png)

  

  

北京云科安信科技有限公司（以下简称“云科安信”）CEO金飞有着20余年的IT从业经验，曾在哈工大任职10年，致力于国防安全服务，离开哈工大后，金飞曾担任HP（惠普）首席信息安全顾问、F5 Networks亚太安全解决方案架构师，从事防御工作长达10年，在防御体系构架和设计方面有着深厚的能力和实践经验沉淀。云科安信在他的带领下，通过自主研发，结合团队的实战攻防经验，陆续形成了可编程动态防御平台、攻击面管理（ASM）系统、WAF、动态应用加固、蜜罐等安全产品和解决方案，已成长为一家专注实战攻防的平台型企业，并将旗下已实战应用多年的工具、产品等进行升级和融合，打造出国内领先的攻击面管理平台——白泽。同时，金飞还积极倡导颇具创新性的“+运营商”模式，客户可以通过云端可扩展弹性资源和防御生态，实现不同维度技术的叠加和组合，从而较轻松地获得实战防御能力，同时，借助运营商营销渠道广泛的优势，更是可将服务带给更多有需求的客户。我们看到，在攻击面管理领域日趋激烈的市场竞争中，金飞给人的感觉颇为沉稳，在对商业模式的探索方面有着诸多创新思路，相信他和他的云科安信在未来能够拥有更广阔的发展空间。
