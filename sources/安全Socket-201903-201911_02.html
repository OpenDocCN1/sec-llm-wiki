一道墨者靶场的CTF题

N年前也这么刷过票来着...

打开界面如下

a2019离第一名差约300票


人工投一票，截数据包


放包，看报错信息，要是微信UA（User Agent用户代理）投票才有效

更换UA字段为微信的

Mozilla/5.0 (iPhone; CPU iPhone OS 8_0 like Mac OS X) AppleWebKit/600.1.4 (KHTML, like Gecko) Mobile/12A365 MicroMessenger/5.4.1 NetType/WIFI

成功投票

直接重放数据包发现


分析数据包，根据ip只能投一票

修改X-Forwarded-For:10.1.0.1,把C段D段作为爆破点

设置字典IP，两处均为1-20，20X20=400，足够第一名

随着爆破进行，票数不断上升

刷到第一名，得到key


修改id=?字段，可以给指定一个对象shua票



不过机器人刷检测很简单，目前都是通过建群——接单发单——截图领工资的形式人工投票，甚至还能控制时间隔间
