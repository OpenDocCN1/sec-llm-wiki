更换UA字段为微信的

Mozilla/5.0 (iPhone; CPU iPhone OS 8\_0 like Mac OS X) AppleWebKit/600.1.4 (KHTML, like Gecko) Mobile/12A365 MicroMessenger/5.4.1 NetType/WIFI

![](../Images/51b070b16f5af975c68466d6f4f25756.png)

  

分析数据包，根据ip只能投一票  

修改X-Forwarded-For:10.1.0.1,把C段D段作为爆破点

![](../Images/2e1094373b1e209e0b5d4930ec28720b.png)

设置字典IP，两处均为1-20，20X20=400，足够第一名

![](../Images/4669e885e287bc02a75b6622e5173274.png)
