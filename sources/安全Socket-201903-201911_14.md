### **二、****password.txt文件的存放路径问题：**

VC中调试运行需要该文件与源文件在同一个文件夹中；

OllyDbg中调试需要该文件与可执行文件在同一个文件夹中。

如果在指定文件夹中没有该文件，将导致异常发生

### **3.****MessageBoxA函数的入口地址**

在第三个小实验中，需要查找两个地址，buffer数组在栈区的起始地址，以及MessageBoxA函数的入口地址：前者通过动态调试观察栈区变化可以查到；查找MessageBoxA函数的入口地址，既可以使用Dependency Walker工具,也可以使用以下小程序获得：

 

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
#include <stdio.h>#include <windows.h>typedef void (*FuncPointer)(LPTSTR);  // 函数指针  int main(){       HINSTANCE LibHandle;    FuncPointer GetAddr;    // 加载成功后返回库模块的句柄    LibHandle = LoadLibrary("user32");      printf("user32 LibHandle = 0x%X\n", LibHandle);    // 返回动态链接库(DLL)中的输出库函数地址    GetAddr=(FuncPointer)GetProcAddress(LibHandle,"MessageBoxA");       printf("MessageBoxA = 0x%X\n", GetAddr);   //即实验中需要的库函数地址    return 0;}
```
