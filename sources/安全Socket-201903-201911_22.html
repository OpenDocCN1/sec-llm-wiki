0x05 利用sslstrip和ettercap进行基于ARP欺骗的密码嗅探

实验环境：攻击方：192.168.189.129，kali linux

          被攻击方：192.168.189.128，windows7

工具介绍：

sslstrip：sslstrip 也叫 https 降级攻击，攻击者拦截用户流量后，欺骗用户与攻击者进行 http 通信，攻击者与服务器保持正常通信 （http 或 https），从而获取用户信息。

Ettercap：ettercap有两种运行方式，UNIFIED和BRIDGED。UNIFIED的方式是以中间人方式嗅探，基本原理是同时欺骗主机A和B，将自己充当一个中间人的角色，数据在A和B之间传输时会通过C，C就可以对数据进行分析，从而完成嗅探。BRIDGED方式是在双网卡情况下，嗅探两块网卡之间的数据包。这里主要用它来进行流量嗅探。


实验步骤：

首先利用arpspoof对目标主机192.168.189.128进行arp欺骗，并开启流量转发，通过被欺骗主机的arp缓存表可以看到arp欺骗已经成功。


运行命令ettercap -T -q -i eth0监听流量，其中-T，文本模式显示，-q，安静模式，不显示嗅探数据


如果此时被攻击者进行https页面的登录，如登录163邮箱


点击登录，由于sslstrip的修改，浏览器会提示证书风险，建议不要继续访问

如果忽略警告，继续访问，则在攻击方就能嗅探到提交的用户名和密码

没有密码的wifi，慎连！

将WiFi连接设置为手动连接。这样能避免手机自动连上钓鱼WiFi的危险性。


在连接WiFi时，如果遇到名字相同或者相近的WiFi名称，要再三确认之后再连接。因为名称相近的WiFi很有可能是钓鱼WiFi。


在使用公共WiFi时，尽量避免进行网银等支付操作，避免在公共网络中泄露了自己的信用卡和银行卡信息。


慎用类似于“WIFI万能钥匙”的软件，表面上看能帮助用户“便捷”的连接网络，但是许多不法分子会对商家的路由器进行劫持，然后将一些弹窗广告发送到用户的手机中，还有一些甚至会盗取用户的隐私资料，甚至是网银密码。
