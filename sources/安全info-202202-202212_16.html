2、工具中使用多线程列表

# payload  ->  pass_list 结合  用户名字典进行确定# 使用线程列表ths_list = []with open(user_dic,'r') as f:    user_list = f.readlines()    for user in user_list:        for pass_line in pass_list:            payload = {'user':user.strip(),'pass':pass_line}            # print(payload)            ths_list.append(threading.Thread(target=scan,args=(payload,)))for th in ths_list:    th.start()
