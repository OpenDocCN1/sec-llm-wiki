# 证监会叫停部分基金券商小程序：出于“网络安全”考虑

1月13日，上线不到一周的基金公司小程序悄然出现变化。

  

21世纪经济记者注意到，包括“建信基金＋”、“广发基智理财”、“华夏基金通”、“银华赢在定投”等4个基金公司小程序已经暂停服务，若从小程序界面端直接搜索上述小程序号，则已经没有相关结果显示。  

  

![](../Images/1e48c49692f94aeb7a910893345aad36.png)

  

上述4家基金公司的小程序与南方基金旗下的“南方基金微理财”、嘉实基金旗下的“嘉实逐流英雄汇”、工银瑞信旗下的“工银基金优选“属于最早一批登陆微信小程序平台的基金公司小程序，均为1月9日上线。  

  

截至目前，“南方基金微理财”、“嘉实逐流英雄汇”、“工银基金优选”3个小程序号仍可以正常使用，为何其余4家公司的小程序号却都突然暂停服务？21世纪经济报道记者向其中一家暂停小程序号的基金公司进行了求证，对方回应称主要是由于收到了监管层的书面指导意见。

  

上述基金公司相关人士表示，“证监会的监管指导意见如下：一是暂停小程序内基金的交易、申赎、定投等交易功能，只能展示产品；二是开户只支持页面跳转的方式。主要是出于网络安全的考虑，请立即执行。”

  

从目前尚在使用的“南方基金微理财”和“嘉实逐流英雄汇”两个号来看，确实符合上述规定的条件范围之内。

  

以下是“南方基金微理财”的小程序界面截图，可以看到除了超级现金宝的充值和其它产品展示外，并无法实现其它交易功能：

  

![](../Images/309a5fc1324eeb40e90b32beba0fb490.png)![](../Images/422b000235d0b0a47368fa45f8c9b970.png)

  

而“嘉实逐流英雄汇”则更加中规中矩，主要连接虚拟理财，以下是其小程序界面截图：

  

![](../Images/ea19b33acde619006000bd9e4dd8a09c.png)![](../Images/21b2d820ef9d96b7b41ded2764d87551.png)

  

对比之前记者截图的其它几家公司小程序的界面截图来看，则普遍存在一些不跳转即可开户、一键定投等功能，正是此次监管层要求暂停的功能。

  

那么，对于被暂停的基金公司而言，后期是否会修改小程序重新上线这一问题，其中一家公司回应称“要看情况。”

  

该人士表示，“如果不让实现交易功能，而只是在页面展示产品的话，实际意义并不大。因为很少人会专门去搜这个小程序来看我们的产品展示。就好比你去一家专卖店只让你看产品而不能买产品，没有什么意义。”

  

另一家同样暂停小程序号的基金公司相关人士也向记者表示，“我们也是才收到通知，后期是否会进行修改重新上线还需要讨论，目前还没有确定。”

  

事实上，除了基金公司以外，券商的系列小程序号也出现了暂停服务的情况。

  

根据21世纪经济报道记者从多家券商求证到，今天下午监管层对券商小程序中凡是关于“开户”、“交易”功能全部叫停。

  

**其中一家上市券商互联网部人士告诉记者，“监管层要求先暂停，他们比较担心如果券商使用微信平台进行开户和交易的话，会涉及到客户资料和交易安全的问题，所以需要论证。等监管层论证完再决定是否要再上线。今天下午通知到机构了。”**

  

据其表示，若券商小程序只是做行情展示的话，倒不受此次窗口指导影响。
