# 无处不在的营销，如何接招

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzcwMTU1Ng==&mid=2649517272&idx=1&sn=5e9fa559befcd79da8444c6593e62611&chksm=8713cd03b06444158bd97a080a557df50c49faa48cbf52532d162b3cc3a7ee52b556e587be3b&scene=126&sessionid=1681368410#rd](http://mp.weixin.qq.com/s?__biz=MzA3MzcwMTU1Ng==&mid=2649517272&idx=1&sn=5e9fa559befcd79da8444c6593e62611&chksm=8713cd03b06444158bd97a080a557df50c49faa48cbf52532d162b3cc3a7ee52b556e587be3b&scene=126&sessionid=1681368410#rd)

遥记得2015年年底的时候对2016年寄语，希望新的一年越来越好。然而这越到年底，越是能看到各种大戏不断上演，其中反转不断皆让路人侧目大呼【还不过瘾呀，继续呀】...

  

从人们笃定的认为希拉里稳赢总统宝座到川普逆袭而上，从支付宝试水社交到负责人背锅道歉，从疯狂转发的【罗一笑，你给我站住】到【大家不要再转了，这是带血的营销】，这些迟一刻都理不清来龙去脉的事情，是对2016年的祭奠和对2017年的期冀...吗...？

  

  

![](../Images/2966c43bf576f3b698f52f678cd5fec5.png)  

  

营销一直都是一门学问，好多公司和企业都要求针对热点事件建立应激机制，不然老板很有可能敲着小黑板跟你咆哮：怎么这个热点没追上呢！怎么就发不出声音写不出观点！怎么人家都行你们就不行呢！要！你！何！用！

  

![](../Images/320302cf0835f41dc721585cc316310b.png)  

  

何为热点？焉知不是媒体的大量传播造成“热点事件”的形成。很多时候我们不能准确判断某个事件的真伪，看到声情并茂抑扬顿挫的抒情很容易深陷其中，在面对众筹面对捐款时觉得五块十块在个人能够承受的范围内便献出一份爱心，除了希望帮助到别人，也为了让自己心里好过一点。

  

人性真的有很多弱点，对弱势群体抱有同情之感也无可厚非，谁都希望当面对困境的是你自己时，别人也能伸手拉你一把，所以请各位“碰瓷”者手下留情，不要消费别人的善良来达到利欲熏心的目的，**把更多的机会留给那些真正需要帮助，却不会写文章的“罗一笑”吧**。

  

在这个看似日趋冷漠的时代，仍然有很多人对人性和社会抱有积极的态度，善良从来不是错，善中带有智慧才能让“善”变得更有意义。

这是一件有智慧的事  

  

在政府不断加大对云计算产业的扶持与引导，国内数据中心建设进入高峰期，数据中心市场加快增速的阶段，重复建设、高耗能、资源浪费等不稳定因素也日益明显。除此之外，BAT等互联网巨头从不同细分领域切入IAAS市场并获得一定的市场份额，致使中小IDC服务商在云业务领域受挫，同时，IT、房产、传统企业、投资基金等行业凭借自有资源向IDC市场延伸。更多的国际热线及经验丰富的数据中心、解决方案及技术供应商开始将目光锁定国内市场。正是在这样的背景下，**中国IDC产业年度大典**应运而生。

  

自2006年以来，中国IDC产业大典已经连续举办十一年，成为中国IDC的标志性活动。本届产业大典的【安全运维论坛】由**威客安全**承办，12月21日，众多大咖齐聚国家会议中心，除了充盈你智慧的头脑，还有不一样的现场体验。
