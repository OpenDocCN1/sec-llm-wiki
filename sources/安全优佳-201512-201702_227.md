# 特稿 | ISC 2016：永信至诚用竞赛推动时代安全感

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzcwMTU1Ng==&mid=2649516871&idx=2&sn=2632c82b2fbebc6c7e30cadf599b6388&chksm=8713ca9cb064438a06076e57c731b75ab71b8d61f429c86491c774ed32ea2323a019033a9e30&scene=126&sessionid=1681368425#rd](http://mp.weixin.qq.com/s?__biz=MzA3MzcwMTU1Ng==&mid=2649516871&idx=2&sn=2632c82b2fbebc6c7e30cadf599b6388&chksm=8713ca9cb064438a06076e57c731b75ab71b8d61f429c86491c774ed32ea2323a019033a9e30&scene=126&sessionid=1681368425#rd)

8月16-17日，以“协同联动，共建安全+命运共同体”为主题的2016第四届中国互联网安全大会（ISC 2016）在北京国家会议中心盛大举行，来自全球的70多家网络安全相关机构和企业，百位行业大咖和专家参加此次会议。会议现场多个分论坛与展览会将同步进行，其中安全技术人才竞技与培养论坛和由永信至诚出品的“i春秋星际训练营”特色展台成为本次大会的焦点。

  

![](../Images/16c3931eb7fd5e09334f9aef5b4d2f33.png)  

  

16日，各主题论坛展开了如火如荼的演讲与交流，北京永信至诚科技股份有限公司董事长、i春秋学院创始人蔡晶晶为所有与会嘉宾带来的《竞赛——获取信息时代的生存能力》主题分享引起了广泛关注。蔡晶晶结合自己十余年的网络安全从业经验，为大家分享了竞赛平台的研发理念以及发展方向。

  

他提到，未来竞赛平台应该更符合真实的环境，同时可以借助云技术以及大数据，让更多人通过更加科学的、合适的“姿势”参与到比赛中来，打破时空的阻碍与隔阂。同时随着人机交互技术的进步，竞赛过程将越来越直观，更加可视化、可感知，让信息安全技术竞技变得和打魔兽一样充满乐趣，值得围观。

  

![](../Images/9043f04c6d73d328fab56d39ea724d87.png)  

  

蔡晶晶在分享中也提出一个梦想，希望未来网络安全竞赛像奥林匹克一样瞩目，能够有明确的精神和主旨，有确定的发起机构、成员机构、章程，提供平台、赛题，给予参赛者足够的关注与认可，从而激励更多人对网络安全产生兴趣。用竞赛反演出来更深邃的精神、更精彩的故事、更专业的技术，共同推动这个时代安全感的进步。

  

![](../Images/83ae147ddf85abcd01d77d92d9d02ec7.png)  

  

大会同期，由永信至诚出品的“i春秋星际训练营”特色展台也吸引了大量观众的围观和互动，场面十分火爆。本次i春秋打造的“星际训练营”主题CTF体验活动，在大会伊始就聚集了大批对CTF竞赛和网络安全技术感兴趣的白帽黑客。值得一提的是，i春秋与熊猫TV跨界合作， i春秋美女黑客鸽子与熊猫TV女主播小白直播现场答题，在线观看人数近3000人。

  

![](../Images/93565275f584f3a30402eb464f7f2658.png)  
![](../Images/da869ee2e610d0c5b4d503de389041d3.png)  

  

另一方面，Geek Game CTF挑战赛再次降临ISC大会。本届Geek Game大赛采用国际流行的“CTF夺旗”赛制，采用e春秋竞赛平台作为比赛环境的技术支撑，来自全国多所高校和中学的8队精英选手一同在赛场中拼杀鏖战。最终，安赛战队凭借1550分的优异成绩摘取了本次比赛的桂冠，Avdir战队和天枢战队分获本届大赛的二三名。

  

e春秋网络安全实验室竞赛系统多年来受到很多比赛的青睐，其多维度、多角度的竞赛展示界面，有效帮助竞赛组织者实时、形象的了解比赛过程，同时也更好的吸引了大批的信息安全从业者与爱好者参与到网络安全竞赛活动中来，感受技术的魅力，激发学习的兴趣，培养扎实的实战能力。
