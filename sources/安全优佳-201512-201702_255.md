# 快讯 | SWIFT黑客再现 乌克兰银行被盗一千万美元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzcwMTU1Ng==&mid=2649516708&idx=2&sn=8f40d81edcdad197ee3cd8938a91375c&chksm=8713cb7fb0644269202519fb6bd9df4e743ec5914ac94ef20793321671ee9166ab2fbd502242&scene=126&sessionid=1681368435#rd](http://mp.weixin.qq.com/s?__biz=MzA3MzcwMTU1Ng==&mid=2649516708&idx=2&sn=8f40d81edcdad197ee3cd8938a91375c&chksm=8713cb7fb0644269202519fb6bd9df4e743ec5914ac94ef20793321671ee9166ab2fbd502242&scene=126&sessionid=1681368435#rd)

**国际信息系统审计协会（ISACA）的专家近日证实‘ SWIFT 黑客’再次现身，这一次他们再次通过 SWIFT 系统漏洞从一家乌克兰银行盗走了一千万美元（约6650万元人民币）。**  

![](../Images/56c314c3973c191f5c51ae5755afd126.png)  
通过 SWIFT 系统漏洞进行银行盗窃的事件又再一次发生，未知黑客从乌克兰银行盗走一千万美元。该消息由ISACA（全球公认的信息科技管治、监控、保安，以及标准合规的领导组织，会员遍布逾160个国家）在乌克兰基辅的分支机构传出，国际信息系统审计协会已经证实，本次欺诈行为还是通过SWIFT 国际银行系统，黑客已经将资金转移至世界各地的金融机构。

乌克兰银行雇佣了 ISACA 组织进行一起网络攻击的相关调查，但是就目前来看，已有多家银行遭到了攻击，损失达上千万美元。

> “目前，已经有数十家银行（主要位于乌克兰与俄罗斯）被攻击，黑客从这些银行中盗走了上千万美元，” ISACA 在一份新闻稿中说道。

ISACA 成员证实，他们正在进行的调查非常耗费时间。金融机构内部网络遭攻击与信息泄露的调查往往需要数月时间，他们需要收集大量的攻击数据。在侦查阶段，黑客们可以了解到银行的内部流程及管理规章，他们在此阶段收集的信息在随后被用来进行资金的欺诈性转移。

ISACA的专家称，网络犯罪分子通过公开的信息和工具从乌克兰银行窃取了上千万美元，由于相关的攻击信息无法进行同步，黑客有可能随后会攻击该国的其他金融机构。

“由于银行害怕事情会被公开，他们一般不会去共享类似的攻击信息，” ISACA 基辅的分支机构主管 Aleksey Yankovsky 说道。

就在一个月之前，菲律宾的一家银行也被 SWIFT 黑客攻击，并成为了第四家受害的银行。Symantec 的安全专家证实黑客使用的恶意工具中使用的共享代码来自 Lazarus 组织。

五月，媒体公布了 SWIFT 黑客攻击的第二家与第三家受害银行，SWIFT 黑客进行的首次攻击就是二月公开的从孟加拉国央行窃取了 8100 万美元。
