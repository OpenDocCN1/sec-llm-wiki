# 销售沙龙敲响破厂产烂货的丧钟！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzcwMTU1Ng==&mid=2649516676&idx=1&sn=63e9aedb4187f9a7dee590d57d114274&chksm=8713cb5fb06442495f70be2809f7113529d576a49e116757ff2c63fff23cf1fe1561d807455c&scene=126&sessionid=1681368435#rd](http://mp.weixin.qq.com/s?__biz=MzA3MzcwMTU1Ng==&mid=2649516676&idx=1&sn=63e9aedb4187f9a7dee590d57d114274&chksm=8713cb5fb06442495f70be2809f7113529d576a49e116757ff2c63fff23cf1fe1561d807455c&scene=126&sessionid=1681368435#rd)

对于出租车的吐槽已经到了人神共愤的地步，出租车的高价和高傲有恃无恐的态度，造就了快车产业的诞生，也顺道解决了黑车无法管理和统计的情况。这是一场像革命式的变革，一场用户更可以做公平和客观选择的变革。

  

![](../Images/16bc7b9f93e663f801ee19cb5812d362.png)  

  

而如今的信息安全市场也面临这样的革命，落后的厂商和销售之间的生产关系，制约了销售面对巨大市场开拓能力的发挥，甚至成为制约行业发展的最大痛点。有的企业产品种类单一，可能都聘不起全职销售。而曾经在某一家公司就职的销售，跳槽之后发现原来积累的产品经验并没有什么卵用了，这是很现实也很刺痛的一件事。

  

所以我们需要这样一场变革，让销售能够更容易的串货，更清楚容易的了解多家产品，不拘泥于自家产品也不拘泥于单一客户。这样，曾经一个有能力的销售才能服务十家客户，却也只能卖自己产品的情况，就会变成每一个销售都有可能服务十家以上客户，还能够卖出多家厂商的产品，只要你愿意这么干！

  

![](../Images/054bb9a7e75de3674b9b90cb0bd68848.png)  

  

安全产品的市场是有巨大潜力的，传统封建的固化销售模式和厂商关系，不再适合现在越来越公开和公平化的市场经济，只有打破这种禁锢，安全产品的市场才有成为蓝海的可能。公平的市场即将出现，美好的事物会在这样的共识下被推向极致，而腐朽的靠关系卖烂货的企业终归不是正途，在威客电商的大火烧过来的时候，就寿终正寝。  

  

而现在，我们终于有机会来为现在这种格局做一次破冰的尝试。

  

![](../Images/6aa2649f748334eb8857b260100295ba.png)
