# NSC2016：全球化的网络安全，信息化推动现代化

> “没有网络安全就没有国家安全，没有信息化就没有现代化”。

  

![](../Images/70d8262cedf73a216579877f01911e26.png)  

  

随着网络空间地位的日益提升，网络空间已成为各国家、地区间安全博弈的新战场。世界各国为确立在网络空间中的优势地位，不断加强网络空间攻击能力，国家级网络冲突爆发的风险不断增加。

  

在我国，随着“互联网+”、智能制造等新兴业态的快速发展，工业控制系统、智能技术应用、云计算、移动支付领域面临的网络安全风险进一步加大，黑客组织和网络恐怖组织等非国家行为体发起的网络安全攻击将持续增加，影响力和破坏性显著增强，更是给网络安全带来极为严峻的挑战。  

  

在此大背景下，已经成功举办了三届的中国网络安全大会即将拉开第四届的大幕！**赛可达实验室、国家计算机病毒应急处理中心、国家网络与信息系统安全产品质量监督检验中心、首都创新大联盟**将于2016年6月23日在国家会议中心，共同举办2016第四届中国网络安全大会。

  

**【大会亮点】**

**国际化：**来自美国、俄罗斯、韩国等众多国际大咖鼎力支持，引领全球信息产业发展趋势。

  

![](../Images/391daac429900d3e0f24f135064b3893.png)  

  

**平台化：**数以千计的参会者与您面对面沟通交流，为您解决实际问题，助您实现业务增长。

  

![](../Images/7a71bc1ddb48a215b0fef32ceea97992.png)  

  

**行业化：**金融、通信、电商等行业，70%以上行业用户最热衷的信息安全盛会。

  

![](../Images/1a582369f0466ceeda00e8bec68cd06b.png)  

  

大会日程  
 **【9:00-12:00】**

**主题峰会：**政府领导、国际知名专家、行业意见领袖等重磅嘉宾，将深度探讨行业最新、最热的话题。

**主持人：**陈钟——北京大学教授、北京大学网络与软件安全保障实验室主任

  

**【13:30-17:30】**

**分论坛1：云安全和电商安全**

汇聚顶尖互联网企业、云服务提供商、电商、网络安全厂商的安全大伽，聚焦云安全和电商安全面临的新威胁、新技术及相关的解决方案与实践案例，与现场观众进行深度交流。

**主持人：****邵国安**——国家信息中心安全管理处处长

  

**分论坛2：威胁情报实践与应用**  

威胁情报是目前网络安全行业的最热话题之一，是业界公认的解决安全新威胁的有利武器，正在从理论研究走向应用实践。该论坛将聚焦威胁情报的最新发展、应用场景及解决方案。

**主持人：****金湘宇**——威胁情报推进联盟发起人、星源壹号基金合伙人

  

**分论坛3：网络安全新技术与行业应用创新**

以“聚焦全球网络安全新技术，推动重点行业网络安全应用落地”为主旨。力邀政府、工业、金融、通信、电力、交通、能源等行业领域的CIO、CSO、专家和中外安全厂商，权威解析互联网+时代的网络安全核心技术在重点行业领域应用的成功案例及创新的安全理念。

**主持人：****徐东华**——国家机械工业经济管理研究院院长、国务院发展研究中心研究员

  

**分论坛4：大师讲堂**

知名网络安全专家和顶级白帽子将深度分享前沿性的技术研究和发展趋势。

**主持人：大潘 （潘廷柱）**——启明星辰首席战略官
