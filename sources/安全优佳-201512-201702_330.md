# 海淘的免税时代即将结束，你还打算靠代购致富吗

 改革开放以后留学浪潮涌现

生活条件越来越好的家庭

都想把孩子送出国感受一下别样的气息

  

如果你是一名留学生，深处大洋彼岸的资本主义国度，面对如此多的包包、化妆品、鞋子、奶粉，首先不要慌，下一秒，你的亲朋好友们可能会在微信上热切地咨询它们的价格并提出代购的要求了。

  

这种情况下靠代购来增加自己的零花收入，已经成为一种时尚的选择。

  

然而，父母们每年花几十万培养的快递小能手，凭代购赚钱过着滋润日子的时代或将渐行渐远。根据此前财政部、海关总署、国家税务总局发布的《关于跨境电子商务零售进口税收政策的通知》，自4月8日起，我国将实施跨境电子商务零售进口税收政策，并同步调整行邮税政策。

  

根据调整后的政策规定，跨境电子商务零售进口商品的单次交易限值为人民币2000元，个人年度交易限值为人民币2万元。在限值以内进口的商品，关税税率暂设为0%；取消进口环节增值税、消费税免征税额，暂按法定应纳税额的70%征收。超出限额的部分，均按照一般贸易方式全额征税。

  

![](../Images/c05fa54b0b6992d2a20018847a816894.png)代购兴起：在金融危机大背景下兴起

  

2008年，席卷全球的金融危机让越来越多的白领动起了抄底国外名牌商品的念头，一些代购商家的生意也随之火暴。除了在网上早已兴起的代购店、代购网站之外，专业的实体代购商店成为一个新的商机。

  

代购是代国内消费者向国外商家购买商品的服务。代购的商品以化妆品、饰品、服装、箱包等最为常见。与网络代购相比，专业的实体代购商店既可经营少量现货产品，也可按消费者的需要向国外商家订货。由于顾客可以亲眼看到一些样品，因此比网络代购更加直观，也更能取得消费者的信任。

  

![](../Images/c05fa54b0b6992d2a20018847a816894.png)海外代购形成的主要原因

  

由于国内外价格差异大，许多奢侈品由于关税、进口增值税等边境税形成巨额价格差，进口后在国内流通与销售环节还有大量的加价(特别是大型市场的门店费用)，代购们可以通过这一途径获取部分代购费用。

  

此外，销售商的价格歧视，许多奢侈品牌对于不同市场的定价是不同的，存在价格歧视，国内同样的商品可能会高于在其他国家的售价，国外市场上品质样式更好的商品的价格甚至还比中国市场定价低。这反映了一些商品在中国市场的价格弹性低，替代商品少，竞争不充分。

  

同时，“外国的月亮比中国圆”，“外国货”意味着质量保证与食品安全，发达国家对产品往往有更高的技术标准，特别是对药品和食品的标准与监管极为严格，假货或冒牌货就更少，从海外购买对于消费者来说比较放心。

  

随着我国经济的越来越发达，国人对外国品牌有着强烈的品牌崇拜，一些品牌在销售战略上也存在在不同市场进行分割销售的可能，即不同市场上销售的产品的款式、类型不同，一些国内追货族通过代购获得在中国没有销售的海外版产品。

  

不过，我国出台的相关规定对代购这个行业来说无疑是一大打击。海淘电商的发展使个人代购的利润空间越来越小，在税收新政实施的同时，海关检查趋严，个人代购必难翻身。
