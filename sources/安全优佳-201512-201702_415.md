# 安卓新型恶意程序：Mazar BOT 盗取用户银行账户并清除所有数据

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzcwMTU1Ng==&mid=401439191&idx=3&sn=535304041e4396c593910fe514bed069&chksm=0d12d80c3a65511abf22c1cb8d8fb33643141c3bc120d1018f84a21e9c95b6d3dd97c037750d&scene=126&sessionid=1681368471#rd](http://mp.weixin.qq.com/s?__biz=MzA3MzcwMTU1Ng==&mid=401439191&idx=3&sn=535304041e4396c593910fe514bed069&chksm=0d12d80c3a65511abf22c1cb8d8fb33643141c3bc120d1018f84a21e9c95b6d3dd97c037750d&scene=126&sessionid=1681368471#rd)

近日，这种新型安卓恶意程序兴风作浪，造成了使用者们的极大困扰。该恶意程序可以获取用户智能手机的 root 访问权限并且能够彻底地清除用户手机中存储的数据，它还可以窃取用户网上银行账号。

  

安全研究人员认为这种名为 Mazar BOT 的恶意程序包含许多隐藏功能，所以非常地危险。一旦被加载，可将用户智能设备变为黑客的僵尸网络。

Heimdal Security 的安全研究人员在分析一条发送给任意国家或地区的随机号码的 SMS 信息时发现了 Mazar BOT。

  

![](../Images/3eab52239c976a8c7cdf6177b2c59749.png)

  

**Mazar BOT 如何工作？**

除了像其他的 Android 恶意程序那样欺骗用户从第三方app商店中进行安装，Mazar BOT 还通过带有链接的钓鱼 SMS 或 MMS 信息引诱用户下载一个恶意的 APK 程序（Android 应用文件）。

  

一旦用户点击了该链接，其设备便会自动下载该 APK 文件，APK 文件运行时将会提示用户安装新的应用程序。

  

这个新的 Android app 有一个通用名称‘MMS Messaging’，即要求用户提供管理员级别权限的进程名。许多用户由于这个非常具有欺骗性的通用名而授予了该恶意应用 root 权限。

**为什么 Mazar BOT 如此令人厌恶？**

  

一旦该恶意程序获取了受害者设备的 root 访问权限， Mazar BOT 可以对受害人设备做出多种令人厌恶的事情，如：

```


1．引导设备持续重新启动

```

Mazar BOT 可通过 TOR 匿名浏览互联网

  

除了这些功能外，Mazar BOT 还能在用户的智能手机上下载一个合法的 TOR（洋葱路由器）Android app，然后在没有用户许可的情况下安装该 app。

  

通过 TOR app，该恶意软件还可以从 Tor 网络匿名访问互联网。

一旦该恶意程序在受害者手机上安装了 TOR，Mazar BOT 便会向一个的伊朗号码（9876543210）发送短信“Thank you”以及受害者手机的地理位置。

  

在一些情况下， Mazar BOT 也会安装一款名为 Polipo Proxy 的 Android app，在受害者设备上建立代理，允许该恶意程序作者监视受害者网络流量并进行中间人攻击。

  

谁是这个可怕的恶意软件的幕后推手呢？

  

Mazar BOT 被认为是由一个俄罗斯的网络犯罪团伙推广的。

  

得出这个结论的其中一个线索是：Mazar BOT 无法安装在俄罗斯的 Android 智能设备上，其源代码中的指令包括当遇到手机配置使用俄语时，停止该恶意程序的安装进程。

  

另一线索是：在俄罗斯有一项不成文规则是“如果网络犯罪分子不去俄罗斯，俄罗斯当局也不会追踪他。”并且，尚没有数据说明Mazar BOT 影响了俄罗斯的任何设备。

  

到现在为止，Mazar BOT 已经在许多俄罗斯地下（暗网）论坛上明码标价，这是有史以来首次监控到如此令人毛骨悚然的可进行主动攻击的代码被滥用的情形。
