# 谁说外资在撤离？苹果库克看好中国长期潜力

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzcwMTU1Ng==&mid=401321711&idx=1&sn=3c2b26cb1aee71d14cc801d32f326681&chksm=0d140f343a63862265d3a033e2779344d43e2d5f10ad778a2ca0c447f350eb27866270e3e7ea&scene=126&sessionid=1681368481#rd](http://mp.weixin.qq.com/s?__biz=MzA3MzcwMTU1Ng==&mid=401321711&idx=1&sn=3c2b26cb1aee71d14cc801d32f326681&chksm=0d140f343a63862265d3a033e2779344d43e2d5f10ad778a2ca0c447f350eb27866270e3e7ea&scene=126&sessionid=1681368481#rd)

苹果公司CEO蒂姆·库克近日表示：“对中国市场长期的潜力非常有信心，也相信这个市场能为我们带来很多大机会。我们保持投资计划不变。”

  

库克表示（上一财年第四财季）该区域季度营收同比增长14%，环比增长47%，以固定汇率计算的同比增幅则为17%。库克补充称，之所以取得这样的成绩“归功于（该区域）实现单季度最高的iPhone销量和App Store苹果应用商店创纪录的表现。”

  

库克在随后的公司电话会议上表示，苹果“对中国依旧非常乐观”且“不同意那些预测前景黯淡的说法。”

  

![](../Images/2c8887a285fcb58de61dad279331e02f.png)  

  

去年夏天，库克接受美国全国广播公司财经频道（CNBC）采访时表示：“7月和8月我们在中国持续实现强劲的业绩增长。”

  

在写于去年8月的文章中，库克表示：“由于中国的LTE渗透率非常低，而且最重要的是预计该国的中产阶级将在接下来几年里茁壮成长，因此我依旧相信中国在长期里意味着一个无与伦比的机会。”
