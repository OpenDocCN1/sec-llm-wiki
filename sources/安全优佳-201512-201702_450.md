# 瑞雪丰年时，爱在腊八节

16日晚，北京虽然轻飘雪花，却未留下任何痕迹。但是坐落在北京西北方位的延庆此时此刻，却是大雪纷飞，落地半尺有余。一群又一群的“互不相识的人”各自驱车，相聚于此。

![](../Images/5c250faae7fec4637e1c55f7c77d14be.png)  

17日早晨6点的延庆，天还未放亮，这群“互不相识的人”就开始赶往了润泽寺，大约两个小时后，相聚润泽寺的人越来越多。

![](../Images/1c69a765c444bb9f4ca241aa0260c991.png)  

![](../Images/fa88b1b72be927a4a6732bfb3893ac1a.png)  

众所周知，1月17日是中国的传统节日——腊八节，同时这一天也是释迦牟尼佛成道的日子。在新年伊始之际，由“互不相识的人”和教徒组成的六组车队，四十多辆汽车奔向位于永宁、旧县、香营以及千家店四个乡镇13个村庄，为那里的老人和需要帮助的人送上了腊八的温暖（米面，水果等），新年的祝福。![](../Images/6dc22858517d1cba714bfd19546ca136.png)

夕阳西下的景色，在落雪半尺的腊八节中格外贴心。这些“互不相识的人”关心的不是彼此来自何方，而是心存爱心才会走到一起。
