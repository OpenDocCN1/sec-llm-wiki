# 打击 IS，网络有责

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzcwMTU1Ng==&mid=401229904&idx=2&sn=3e27ed4bf318b50c3b81db503191bfee&chksm=0d15e98b3a62609d8f2b143e86707b551c6eafffe9c63222edb3aba888af5cc158f47d1b18d0&scene=126&sessionid=1681368491#rd](http://mp.weixin.qq.com/s?__biz=MzA3MzcwMTU1Ng==&mid=401229904&idx=2&sn=3e27ed4bf318b50c3b81db503191bfee&chksm=0d15e98b3a62609d8f2b143e86707b551c6eafffe9c63222edb3aba888af5cc158f47d1b18d0&scene=126&sessionid=1681368491#rd)

在美国最高反恐官员前往美国加州从公司（包括苹果、Facebook 和 Twitter）拉拢技术主管后，奥巴马政府承认了「复杂的宪法第一修正案议题」。

在上周五的一次秘密会议中，科技巨头们似乎都倾向于帮助美国政府打击伊斯兰国，该会议邀请到的是美国最高级反恐官员和硅谷一些公司的高管。这次科技大佬们（包括苹果、Facebook、Twitter 和 Microsoft 等）和白宫代表团的相聚向世界透露了一个信息，即科技公司愿意和政府一起合作。这也预示着，奥巴马政府似乎自己承认不能独自在网上打击恐怖分子。

据知情人士透露，高层官员们（包括美国国家安全局局长 Michael Rogers、白宫办公厅主任 Denis McDonough 和 FBI 局长 James Comey）似乎想知道如何发起社交活动来抵制 ISIS。在星期五早上会议之前发给技术高管和《卫报》的一份简报文件中透露了政府代表团（包括美国最高级间谍、国家情报局主任 James Clapper）的一个愿景。「我们非常希望和你们一起讨论如何处理日益增长的来自恐怖分子和其他恶意行为的威胁，包括加密技术。」该简报文件说，「有没有这种技术，可以使得恐怖分子更难使用网络来进行动员、促进行动或者实施行动？」

![](../Images/3022c55190110e88a14e8080cf81d759.png "3bfa359c78.png")

据知情人士透露，尽管最近也有很多关于公民自由、加密和监控等方面的抗议活动，但是技术高管似乎乐于接受这个消息。「说实话，对于今天的这些谈话，我感到非常诧异。」参会者 Matthew Prince 说。Matthew Prince 是 CloudFlare（一家总部位于旧金山的安全和网络公司）首席执行官。英特尔安全组组长 Christopher Young 也是与会者之一，他也认为这次谈话的气氛相当和谐。早先在华盛顿的时候，白宫新闻发言人 Josh Earnest 就曾透露，参加此次谈话的科技公司的负责人都有非常高涨的爱国情怀。

会议讨论的一个议题就是，Facebook 有一个系统，可以辨认哪些使用者有自杀倾向，从而帮助他们；这个系统经过改进以后，是否也可以用来辨认恐怖分子。

Facebook 社交网络首席运营官 Sheryl Sandberg 告诉政府官员目前 Facebook 如何帮助用户来识别哪些人可能具有自杀倾向。而参加会议的政府官员则对此非常感兴趣，他们想知道这样的系统是否也可以用于辨认恐怖分子，或者检测用户是否比较激进，从而对其言论拒绝引用。「该会议表明，在打击恐怖主义时，我们众志成城，团结一致，都在为实现这一目标而奋斗。」Facebook 新闻发言人说，「Facebook 对于恐怖主义或者恐怖宣传绝不姑息。」

除此之外，苹果首席执行官 Tim Cook 则告诉政府苹果公司需要公开表示支持高度加密。在去年一年，苹果公司遭遇了 FBI 的数次攻击，原因是 FBI 认为苹果销售的产品可以帮助犯罪分子进行秘密通讯。其他出席的科技公司包括 LinkedIn、DropBox、YouTube、Yahoo 和 PayPal。

这已经不是高级代表团首次造访硅谷，但是由美国高级反恐官员邀请科技公司负责人就反恐问题进行磋商则并不常见。没有哪位科技公司负责人想要被人们认为是支持恐怖主义的，但是政府的要求或许比看起来要复杂得多。理想情况下，奥巴马政府希望科技公司可以在社交网络和聊天应用程序上找到恐怖分子。这或许会涉及到将通讯网络和短信内容结合起来锁定恐怖分子的电话等信息。根据政府的设想，这些科技公司正在出于商业目的进行这方面的尝试。

然而，自从斯诺登在 2013 年将西方政府的秘密透露给《卫报》和其他媒体后，硅谷对于和政府之间的合作越来越谨慎。政府的这些要求也产生了相应的法律问题。根据目前的美国法律，科技公司仅仅在获得信息所有者授权的情况下才可以将涉及用户的具体信息进行分享，并且保证不会对用户产生危害。「要想获得这些信息其实并不容易。你要做的就是从别人的大脑中获取这些想法，然后确定这些是否会和一些暴力行为连接起来。」Andre McGregor 说。Andre McGregor 是前 FBI 恐怖主义调查员，现在是硅谷安全公司 Tanium 的安全负责人。目前一些公司可提供一些志愿协助服务，例如用户移除了和一个月前发生在 San Bernardino 的枪击事件的相关主页等这些信息可以被收集起来，但是他们究竟能走多远还未可知。

政府也意识到了可能出现的风险。在该简报中提出了这样的问题：如果任何恐怖内容检举系统独立于政府而存在，那么是否可以提高其生存能力。不仅如此，他们也面临着不同美国官方的竞争需求。政治家们已经开始呼吁科技公司们（例如希拉里 · 克林顿和唐纳德 · 特朗普）将恐怖分子剔除出网络，从而将这些活动扼杀在摇篮之中。不过科技公司们都认为这是不可能的。

其他的一些部门，例如 FBI 和 NSA 都希望美国公司可以重点关注恐怖分子的账户，并且让美国当局介入其中。「我们坚决反对让 ISIS 使用美国产品。」美国公民自由联盟首席技术专家和隐私倡导者 Christopher Soghoian 说。但是从网络中找出恐怖分子是美国政府的责任，让科技公司来完成这些很不现实。在会议结束之后，与会者都纷纷从侧门离开了大楼，其他人全部离开，没有人对会议内容做出任何评论。
