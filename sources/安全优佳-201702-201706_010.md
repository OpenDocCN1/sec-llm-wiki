# 网络安全缺口大 国内首款网络信息安全综合险面世

自5月份开始的比特币勒索病毒“WannaCry”，到目前为止已经入侵了150多个国家、近30万台电脑，并再次引爆了网络信息安全问题。6月1日起，《中华人民共和国网络安全法》正式实施。6月26日，众安保险与杭州安恒信息技术有限公司联合推出网络信息安全综合保险，这是国内首款网络信息安全综合保险。

![](../Images/ebb1f3962554866a0e870fc620acca3b.png)

随着互联网发展的持续深入，网络成为企业的基础设施的一部分，网络信息安全问题日趋重要。上海信息安全行业协会副秘书长王怀宾透露的一组数据显示，国内在网络安全信息建设方面缺口极大。他指出，2016年由于网络犯罪的经济损失是3万亿美金，最新的Gartner预测，预计在五年后这个数字将达到6万亿；中国网民每年的经济损失是916元（中国网民数量为9亿）；中国的防范网络犯罪的专业人才缺口是140万（目前仅3万）；中国有信息安全相关责任和义务的企业法人有5万家。

在这种背景下，保险企业开始瞄准这一市场空间。据众安保险方面介绍，这款网络信息安全综合保险主要针对政府、事业单位、机构、大型企业以及上云的中小企业，所保障的内容包括数字资产损失和数字资产安全责任两个板块（即被保险人自身损失和造成的第三方损失）。具体而言，主险保障包括有害程序事件、网络攻击事件、信息破坏事件等三大类共14个子类的风险事件。另外加收保费提供扩展保障，包括0day漏洞事件、扩展分布式拒绝服务攻击（DDOS攻击）事件。

从具体的保险方案来看，该产品客户被分成A类（政府、事业单位、机构以及大型企业）和B类（中小企业），每类客户有两种投保方案可供选择，保险期间为1年，最低保费为2万，最高保额为300万。

安恒信息副总裁冯旭杭对记21世纪经济报道者表示，由于国内目前并无同类保险产品可供对标，在该产品的设计和定价中，参考了国外相关产品，对客户的保障需求和价格承受心理进行了大量调研，同时根据网络信息安全大数据进行了相关的风险分析。
