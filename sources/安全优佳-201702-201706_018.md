# 警企协同打击网络犯罪 猎网平台三大举措守护网络安全

       近年来，我国网络诈骗案件频发，诈骗手法日趋复杂，已经成为社会毒瘤。6月20日，由北京市公安局网络安全保卫总队、相关省市公安机关和 360公司共同参与的“警企协同，打击网络犯罪——猎网平台发布2017网络诈骗数据报告暨十大案例通报”活动在京举行，来自全国200多家公安机关的代表共同出席会议。

       360公司首席安全官谭晓生表示：“猎网平台利用多方力量共同打击网络犯罪，是一个创新型的机制与模式，也成为了警企协作的典范。打击电信诈骗会是一个长期、高技术的斗争过程。今后360也将继续与各地公安部门深入合作，充分利用互联网技术打击网络犯罪，保障社会安全。”

![](../Images/e4a84950ef8b9809b55b15bf07d5cfde.png)

**成效显著  成警企协作典范**

为了全面有效打击网络犯罪，2015年5月，北京市公安局联合360互联网安全中心共同推出了全国首个警民联动的网络诈骗信息举报平台——猎网平台。平台集公安机关的刑侦优势与互联网企业的平台优势于一身，面向全国网民提供网络诈骗举报服务。举报不设金额地域限制，即使一元被骗，也能举报。猎网平台可以通过视频、音频、图片及文字等多种方式接受举报，从而全面收集犯罪分子信息，同时利用360的大数据分析能力，将举报线索进行串并，所有信息直接同步公安机关。

截至目前，猎网平台已与全国200多个地区的公安机关建立联系，协助侦破100多起重大网络诈骗犯罪案件，涉案金额为1.7亿元， 打掉了10余个组织严密、分工明确的大型诈骗团伙。

猎网平台同时也对广大网民积极进行网络安全教育，提高防骗意识。同时向网民公开黑名单，网民遇到不能判定的诈骗信息还可以咨询查证。自成立以来，平台还公开发布了各类电信网络诈骗研究报告30余份，拍摄各类反诈骗宣传片50余部。

在活动现场，猎网平台同步发布了《2017年上半年网络诈骗数据报告》，并通报了近期全国十大网络诈骗的典型案例，为各地公安和网民全面揭露今年各类流行诈骗手法和诈骗趋势。

**三大举措  向网络犯罪重拳出击**

为进一步全面打击网络诈骗犯罪，增强网民防骗意识，猎网平台宣布推出三大举措，从线上到线下全面封锁诈骗入口，从前期预防到后期赔付，尽力将网民损失降到最低。

在活动现场，猎网平台正式启动了“反诈骗宣传全国行”行动，联合全国200余家公安开展反诈骗宣传。活动期间，不仅通过微博、微信、猎网官网等线上渠道发布最新骗术及防骗提醒，同时每月也在学校、企业、社区等地开展防骗宣传活动。

同时，猎网平台已开通“猎网追踪”功能，向各地公安机关和网民全面开放检索功能，可以对可疑的手机号、网址、QQ号码进行查询，检索欺诈信息。截至目前，广东、浙江、福建、河南、河北、山东、内蒙古、辽宁、云南、重庆、贵州等地的网安部门已经接入猎网追踪接口。

此外，猎网平台还将接入“网购先赔”服务。用户在首页导航栏、举报页面及举报成功界面均可找到“先行赔付”的入口，在举报的同时可直接申请理赔。既减少了用户填写理赔信息的步骤，同时也给更多符合赔付标准的用户提供便利。

![](../Images/eab9f8fe960a53747aa11ac781040f1a.png)

在活动现场，辽宁省营口市公安局反诈骗中心、贵阳市公安局网络安全保卫支队、包头市公安局网络安全保卫支队、河南省公安厅网络安全保卫总队、徐州市公安局网络安全保卫支队、南宁市公安局网络安全保卫支队的代表还被授予了“猎网两周年优秀合作伙伴” 纪念牌。

两年来，猎网平台已经为打击网络诈骗探索出了一条警、企、民协同联动的有效新路。今后，随着全国各地对网络犯罪打击力度的持续加强，警企合作的不断深化，猎网平台也将发挥更加重要的作用，让网络犯罪分子无处藏身。
