为了应对下一代汽车系统开发的网络安全挑战，卡巴斯基实验室和AVL Software and Functions公司将通过合作和全面的合作伙伴关系，共同开发高级嵌入安全技术。

2017年6月1日，雷根斯堡——越来越多的车辆功能开始使用车辆和云端或同其它基础设施之间的通讯通道，例如远程诊断、远程信息处理和信息娱乐功能。这种汽车数据交换提供和很多技术机遇，但是这些通讯通道也很容易成为网络攻击的目标。另一方面，车辆被入侵的风险以及车辆的安全、隐私和财务价值被违反的风险也日益加大，迫切需要采取系统的、有组织的以及有效的技术手段来确保所有车辆功能得到保护。

卡巴斯基实验室首席战略官Alex Moiseev先生和AVL Software and Functions公司的总裁Georg Schwab博士于2017年6月1日在雷根斯堡签署了合作协议。协议内容包括以下：

· 合作开发一款软件解决方案，保证汽车组件之间以及汽车和外部联网基础设施之间进行无干扰的安全通讯

· 在嵌入汽车开发和最佳网络安全实践和技术之间打造一座桥梁

· 将安全产品同汽车组件开发捆绑，为汽车制造业推广综合的安全解决方案

· 为汽车安全行业建立培训和辅导组合服务

· 通过无缝和全面的产品组合来延伸业务，为未来的联网汽车和自主汽车提供安全和保障

其中一个重要的目标是打造一个可靠和灵活的软件平台，使汽车制造商能够使用与其制造计划相一致的硬件和附加软件组件，允许开发和实施安全通信单元（SCU或汽车网关），并将其应用到他们的汽车中。一旦开发成功，将通过安全相关的验证和验证方法测试概念验证SCU解决方案。这个全面的开发包不仅能够生成行业所需的技术交付成果，还将开发出通过设计使汽车软件安全的新概念。

卡巴斯基实验室将和技术合作伙伴AVL Software and Functions公司将于9月12-17日在法兰克福召开的移动世界新体验/ 2017法拉国际车展上演示这款安全通讯平台。

卡巴斯基实验室首席战略官Alex Moiseev评论说：“卡巴斯基实验室的汽车安全专家关注有关联网汽车安全和快速发展的网络安全攻击层面已经很多年。我们认为，要保护整个联网汽车生态系统的安全，唯一的方法是通过网络安全专家和汽车行业企业进行密切合作。我们同AVL Software and Functions 公司的合作，标志着我们在这次的旅途上迈出了重要的一步，从车载安全性开始，并扩展到车对车和基础设施通信。”

AVL Software and Functions 公司的总裁Georg Schwab表示：“AVL作为一家汽车厂商，了解汽车和其环境之间安全和可靠的通讯通道的重要性。为了全面了解安全解决方案的概念和实施，并成为汽车网络安全的领先合作伙伴，AVL专注于与经验丰富的网络安全公司卡巴斯基实验室的合作。”
