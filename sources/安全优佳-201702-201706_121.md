# 一、顽固的便利贴  

Sticky Toptes是 Windows 系统自带的电子便条，可以把它印在屏幕上，而且不会掉~

操作方法很简单：直接在搜索框输入【Sticky Notes】并选择即可。

这是一个放在你电脑桌面的小型便利贴，用于提醒自己一些事情很有帮助！

# 三、无密码自动登陆

首先点击开始按钮右侧的Cortana搜索框，输入字符串“netplwiz”回车。然后点击你的账户，取消“要使用本计算机，用户必须输入用户名和密码”前面的复选框，确定之后，Win10会要求你输入一遍密码以便验证。再次确定后，电脑就没有烦人的登录界面了。![](../Images/70755cef27009a5a25093723625d0c6c.png)

# 四、创建虚拟桌面

点击Cortana搜索栏旁边的“任务视图”按钮就可以进入该功能。此时点击右下角“新建桌面”（如下图）就可以创建多个虚拟桌面，或者点击屏幕中间的任务缩略图就可以切换前台任务。
