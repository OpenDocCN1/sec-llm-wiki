# 新报告显示感染WannaCry病毒重灾区是Win7

一些数据可以了解勒索病毒是如何进行攻击的，希望让更多的网民们关注网络安全和防止未来类似的网络攻击。近期来自卡巴斯基实验室的一份报告显示，这次勒索病毒攻击受影响的运行系统大部分都是 Windows 7 ，而 Windows XP 受攻击数目少到甚至可以“忽略不计”。这就推翻了之前人们所认为的 Windows 版本越低受攻击越严重的说法。

![](../Images/693bbe035ff9a238e6585cad8e68ecbb.png)![](../Images/103d6b8854539d35ee913468ab7b0bf7.png)

根据数据显示，此次攻击系统中 Windows 7 占受影响计算机总数的 98%，其中影响最大的是 64 位系统；而 Windows XP 和 2008 R2 Server 的感染率为0.1％ 和 1.5％，这些数字已经可以忽略不计了。

到目前为止，Windows 7 仍然是使用最普遍的 Windows 系统。根据相关统计显示，在全球范围内，Windows 7 的安装使用量大约是 Windows 10 的 4倍，而最新的 Windows 10 系统并不容易被勒索病毒攻击，因此该病毒会向 Windows 7 系统入手。另外，由于 WindowsXP 系统虽然过时而且缺乏补丁，理论上更容易遭到勒索病毒的攻击，但或许是使用人数较少的原因，其实 WindowsXP 对病毒的传播发挥的作用并不大。而卡巴斯基的数据也表明了，未打补丁的 XP 系统电脑在传播勒索病毒反倒没有起到太大的作用。

经过这次事件之后，微软的补丁政策饱受外界批评，但从另外一方面也提醒了用户，用户应该关注 Windows Update的例行下载补丁和安装安全更新。
