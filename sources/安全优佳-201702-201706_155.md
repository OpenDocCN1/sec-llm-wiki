# 微软透露：Win10 S不支持Linux子系统

Windows10S是一款十分优秀的系统，然而这个系统的用户中几乎不会有Linux的粉丝，微软透露，Linux子系统将不会在Win10 S上运行。

![](../Images/7c9702a8c096c8136cff2ef8874606e7.png)

这个声明非常奇怪，因为微软此前已经表示会将Linux子系统上架Windows应用商店，而Win10S是可以运行来自Windows应用商店的应用的。

Rich Turber在微软的博客中说，来自Windows应用商店的应用程序一定要满足特定条件才能在Win10 S上运行，就算一个应用程序来自Windows应用商店，这也不意味着它一定是安全的，有些来自Windows应用商店的应用程序不被允许在Win10 S上运行，包括所有的命令行应用程序、Shell和控制台。

Turner澄清说，Win10 S针对的是非技术类用户，比如教师、学生或者内容创作者，他们可以在微软构建的沙箱中完成他们的工作，因此，对于开发者和系统管理员来讲，Win10 S并不是适合他们的操作系统，因为这类人群的开发工具通常需要访问操作系统的底层，但是Turner表示，你可以在Win10 S上编写能在互联网或者IoT设备上运行的代码。

如果你是个开发者或系统管理员，既想使用CMD、Powershell或Linux子系统，又想使用新鲜出炉的Surface Laptop，那么只需花点银子把Win10 S升级到Win10 Pro，值得提醒的是，你可以在今年之内将Surface Laptop免费升级到Win10 Pro。
