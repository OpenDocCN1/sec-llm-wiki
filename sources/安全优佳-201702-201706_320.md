# Facebook利用图像对比软件阻止“色情报复”内容

       北京时间4月5日晚间消息，Facebook今日宣布，将推出一些新工具来方便用户举报所谓的“色情报复”内容，并自动阻止这些图片被再次共享。

　　“色情报复”内容是指伴侣分手后，在未经对方同意的前提下，在网络上分享对方的私密（情色）照片，旨在敲诈或羞辱对方。一般情况下，女性受害者的比例更大。

![](../Images/8ff40f965be3b422bbf432167e083c23.png)

　　在此之前，Facebook曾因为该问题而遭遇诉讼。2015年，Facebook正式宣布，禁止在网站上共享“色情报复”内容，同时鼓励用户举报。

　　Facebook今日又在一份声明中宣布，从本周三起，Facebook用户将会看到一个选项，可以把相关图片举报为“色情报复”内容。

　　此外，Facebook还将推出一个自动化程序，来阻止这些被禁止的图片被再次共享。Facebook称，该图像对比软件将把“色情报复”内容从Facebook网站，以及Instagram和Messenger服务中剔除。

　　同时，共享“色情报复”内容的帐号将被禁用。除此之外，一支训练有素的Facebook团队将对每一张被举报的图片进行审核。
