# 三星Tizen系统安全性遭批评：被指最烂代码

       4月6日上午消息，来自国外媒体gsmarena的消息称，三星公司自己研发的Tizen系统近日被安全业界人士狂批，甚至被称为“史上最烂的系统。”

　　为了减轻对Android的依赖，三星在2012年联手英特尔及两大Linux系统联盟，共同推出此操作系统，目前主要用于三星的电视机，智能手表和少量的手机上。

　　在星期一的卡巴斯基实验室安全分析师峰会上，研究人员Amihai Neiderman对外表示：这可能是我见过的最烂的代码，他们在能出错的地方都出错了，审核这些代码的人没有任何编码安全经验。![](../Images/e32c0860e27ac7771b608c13d9f739f9.png)目前Tizen系统主要用于三星的电视机与手表，智能手机并不多

  

　　安全研究人员称，三星Tizen操作系统当中存在40个零日漏洞（指被发现后立即被恶意利用的安全漏洞）。这些漏洞将允许攻击者远程攻击设备，或通过Tizen Store软件商店控制电视等设备。

　　三星尝试过推出Tizen系统的手机（Z系列），但是市场反应平淡，人们依然习惯Android的生态系统，目前，Tizen更多被用于三星的智能手表上。

　　Amihai Neiderman说他已经联系了三星，最初只得到邮件自动回复。在媒体报道之后，该公司表示将与Neiderman合作，消灭所有漏洞。
