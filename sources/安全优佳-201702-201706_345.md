# 世界上最安全硬币 不同角度将可分别看到数字1或英镑符号

世界上最安全硬币发布新版本。据悉，新的12边形1英镑硬币是1983年发行1镑面额硬币以来首度改款。新版硬币比旧款略大，但更薄、更轻，并有一道“全像型”(hologram-like)图案，从不同角度将可分别看到数字“1”或英镑符号。皇家铸币厂已制造约15万枚新币。虽然新币上市流通，但当地普及的特易购超市仍约有200间店的手推车还不能用新硬币。此外约15%的自动贩卖机、10%的停车计时器也都还不能用新硬币。

![](../Images/4247389384b9b2512e7d22dd4dad6753.png)

　　据外媒报道，拥有英格兰、苏格兰、威尔斯、北爱尔兰各自象征物的新版1英镑硬币，在英国启动脱欧程序前夕上市流通。这枚12边形的新硬币号称是“最安全、最难伪造”的硬币。

　　据悉，新的12边形1英镑硬币是1983年发行1镑面额硬币以来首度改款。新版硬币比旧款略大，但更薄、更轻，并有一道“全像型”(hologram-like)图案，从不同角度将可分别看到数字“1”或英镑符号。

　　报道称，新硬币一边是伊丽莎白二世女王肖像，而另一边则分别有象征英格兰的玫瑰、苏格兰的蓟、威尔斯的韭葱和北爱尔兰的酢浆草同置于皇冠内的图案。旧版1英镑硬币只能用到10月15日即告失效。

　　皇家铸币厂已制造约15万枚新币。虽然新币上市流通，但当地普及的特易购超市仍约有200间店的手推车还不能用新硬币。此外约15%的自动贩卖机、10%的停车计时器也都还不能用新硬币。
