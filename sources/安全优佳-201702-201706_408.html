       大多数人会倾向于认为黑客都是技术超群、聪明绝顶的天才。一般来说，黑客都是“精于算计和部署的”，所以应该不会有什么愚蠢的黑客。但是，403 Web Security的首席执行官Alan Wlasuk则认为事实上并不完全如此。他说，其实在黑客圈子里也有不少“蠢到哭”的黑客。不过他们也只是一时糊涂，并非真正的愚蠢。

虽然黑客是非常危险的，但是并非每个黑客都是Kevin Mitnick，有些行为不慎的黑客的犯傻行为真是令人大跌眼镜、啼笑皆非。接下来小编就为大家介绍史上最愚蠢的十大黑客行为，hold不住就捧腹大笑吧～～～

Michael Buen：找工作时有些事千万别做！

Michael Buen，WM97/Michael-B Word宏病毒的作者。Buen会在每月底的周五，在受到宏病毒感染的文档中打印出他自己的个人简历。随后受到病毒感染的计算机就会显示这样一段话：“警告：如果我在这个月月底之前没有得到一份稳定的工作，我将会发布另一款病毒，它将会删除主驱动器上的所有文件夹。”但是根据菲律宾最高法院所言，当时还没有适用的法律来起诉这位“蠢萌”的黑客。

 Eduard Lucian Mandru：电子邮件地址暴露行踪

美国政府用了好几年的功夫才将Eduard Lucian Mandru——这一攻破美国国防部计算机的黑客抓捕归案。然而帮助抓捕他的线索，却是他在攻击中所使用的电子邮件地址暴露在了网上求职站点上。这名黑客在2006年攻破了美国国防部并且一直逍遥法外，直到政府当局几年前从多个网上求职站点找到了这名黑客的电子邮件地址。

 医院审计系统抓住泄漏医疗数据的“内鬼”

很多医护人员尽管没有访问需求但还是可能会禁不住地去查看名人的病历。近年来，不断有名人病历数据外泄的事件发生，很多是受利益驱使而为之。不过随着法律的不断完善，现代的计算机审计系统将有助于规范医院行为准则。因此，医院管理者和执法机关、当事人律师可以更好的找出偷看病人信息的行为，并追究其相应责任。

KellyOsbornes的“诱惑”：将名人邮件转发至个人邮箱中

一名黑客入侵了Kelly Osbornes的电子邮件帐户，并设定将新邮件转发至个人账户中。该此次攻击活动中，黑客侵入了Kelly Osbornes的电子邮箱账户并读取了她保存的每一封邮件。但是将新邮件转发至的另一个账户却被证实属于黑客个人所有。403 Web Security的首席执行官Alan Wlasuk表示，“这无疑成为了追踪该黑客行为的最好线索。”

Samy Kamkar：车牌号引发的悲剧

黑客利用窃取的MySpace帐户，在网上张贴自己的个人照片和带有车牌号的汽车照片。Samy Kamkar是Samy蠕虫病毒的作者，该病毒曾经在2006年感染了超过100万MySpace帐户。他在博客上吹嘘自己的所作所为，并配上载有车牌背景的照片，根据车牌信息最终Samy被抓捕归案。

ShaheeMirza:“HACKED BY SHAHEE_MIRZA”

你可以想象一名黑客在攻击了政府网站后在上面公布了自己的真实名字吗？包括Shahee Mirza在内的一群黑客组织，攻击了一个孟加拉国政府军事网站，并嘲笑该政府机构低级的安全防护水平。Mirza在完成攻击后加了一句“我们不是犯罪分子”，还留下了一写有“HACKED BY SHAHEE_MIRZA”的横幅。403 Web Security的首席执行官Alan Wlasuk说道，“大家可以想象一下世界上最贫穷的国家之一的监狱会是什么样呢？”

Max Butler：Benevolent 蠕虫的“反噬”

一名黑客释放了一个能下载并修补BIND DNS服务器漏洞的蠕虫病毒。该蠕虫包含一个后门，攻击者能够对受到感染的计算机实现远程控制和访问。由Max Butler撰写和发布的这一蠕虫病毒，是一个Linux ADM蠕虫变种，攻击目标主要为BIND DNS服务器。此外，该蠕虫病毒还为Max Butler或任何其他黑客实现远程控制开启了后门。但是，Max Butler却声称从未打算使用这些后门。

用真实身份发动攻击

很多人可能根本没有意识到，黑客组织Anonymous使用“低轨道离子炮”（Low Orbit Ion Cannon）进行分布式拒绝服务攻击的时候，并没有屏蔽自身IP地址，这样一来使得自己的真实身份被暴露在外。这种攻击手段采用了一种开源的DoS攻击工具，允许用户组建僵尸网络发动分布式拒绝服务攻击。该工具本身并不会隐藏用户IP地址。Imperva的Noa BarYosef曾说过，“作为黑客的第一条法则就是，隐藏自己的真实身份”。

Daquan Mathis：注意微笑，摄像头正对着你！

一名男子利用窃取的iPhone手机给自己拍照，并将照片发送到他个人的电子邮件帐户中，从而使得警方更加顺利的找到了这名犯罪分子。在名为Sayaka Fukuda的用户发现自己的iPhone被偷后，她检查自己iPhone上的电子邮件帐户发现处于在线状态。而犯罪嫌疑人，Daquan Mathis用窃取的手机拍了张照并通过电子邮件发送至了个人电子邮箱账户中。警方正是根据这名男子发送邮件的线索，成功找到了失主的iPhone，并成功将该名男子逮捕归案。

愚蠢OR聪明？

黑客利用自动测速照相拍摄的图像，欺骗电脑将某些超速行驶的汽车不记录在案。通常情况下，自动测速照相会自动将汽车的速度和车牌号一并记录下来。照相机特征识别技术能将车牌号照片自动生成字符串，从而归并到汽车数据库中。该黑客将其车牌号改成了ZU 0666，然而通过车牌号本身很容易追查到黑客。
