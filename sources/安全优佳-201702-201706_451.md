# 手机自毁功能研发成功 竟解决了马化腾6年前的担忧

       现在的手机早已经成为我们生活中不可或缺的一部分，我们的沟通在手机、交友在手机、办公在手机、娱乐在手机，难怪有人说，一般的人摸得最多的一定不是他老婆的手，而是他亲爱的手机。

![](../Images/98b120f9f4d6a8242d98cebda11dd4ef.png)

       确实手机从最开始砖头到直板按键、翻盖、旋盖、上滑；屏幕从拇指般打小变成2寸屏、2.5寸屏、4寸屏，大屏化成了趋势和主流。应用从单纯的语音通话，变成了可以支持中文短信的发送，到可以支持彩信的接发，实现手机浏览纯文本的网页，收发邮件。附加功能从空白到内置了如贪吃蛇等游戏，到开始加入了照相机，延续到变成音乐手机，加入蓝牙功能，闹钟功能等等一系列的附加值。不得不说现在的手机能共越来越强大，越来越便捷了。

![](../Images/4a914b4abfdbaec648f48f20c64323af.png)

       但当智能手机越来越便捷的同时，它背后的隐患也开始显现。个人信息泄露、恶意软件、超级短信病毒、中奖短信、银行卡盗刷、偷跑流量等问题层出不穷，让人担忧，甚至恐惧。切实了解其中的弊端以及如何防范，成为当下每个智能手机用户都必须面临的课题。

**小马哥6年前神寓言竟成真**

       周日去朋友家玩的时候他告诉了我这样一件事，他说楼下的一家日用品店前几天抓到一个小偷，他把店里的支付二维码偷偷换成了自己的，由于店主的疏忽大意直到月底结款的时候才发现，但是据小偷交代，这一个月他通过这家店已经默默的在家收了13万了。

![](../Images/70eed4c2faa9c635cbe543b03035de09.png)

![](../Images/73c069ca92b6fcf9bca6e1577ca79d90.png)

       虽然这则新闻直到今天也尚未曝出，但可以看到在我们使用便捷的二维码支付的同时，也带来了很多直观的安全隐患。这不禁让我想起了马化腾在6年前在微博上曾经说过的一句话：安全和便捷总是相对矛盾的! 在那个正值腾讯微博使用的高峰期，这一句话引来了众多业内人士的评论，但大多人都秉承着随着科技的发展指纹、人脸识别等技术的升级，未来的互联网将更便捷、更安全。

       岁月如梭，6年的时间转瞬即逝，即便是现在各种类型的支付方式层出不穷，可如今的网络环境并没有比之前更安全。这正好验证了6年前小马哥的说的话，安全和便捷总是矛盾的。即便是随着科技的快速发展，这个定律也几乎无法打破，想要安全的同时还要便捷的解决办法几乎是不存在的。

**便捷与安全总是对矛盾体**

       据资料显示在去年《我国公众网络安全意识调查报告》显示我国约83%的网名存在网上支付的安全隐患，多账户使用同一密码的情况高达75.93%；随意连接公共免费WiFi的比例高达80.21%；支付时不仔细辨认支付页面网址真伪，在被调查者中占比接近35%。

![](../Images/caf9e1753879db6fcb34c685ac04b521.png)

       总有人说NFC的出现能解决便捷与安全问题，但事实并非如此，NFC的便捷性让我们的用户绑定银行卡购物、刷公交卡的时候无需密码和繁琐的流程，方便了很多，同样也让黑客窃取我们资料和信息方便了很多。只要黑客以标志性地标为名称开通免费热点，必然会吸引不少人连接，这样黑客就可以随意植入木马让很多人的信息外漏，甚至绑定的手机都有可能会成为黑客的取款机。

![](../Images/c7715fc6877865411115257a8582fd0a.png)

       同样现在极度流行的指纹支付同样能让黑客有可乘之机，目前不少黑客可以绕过指纹识别器解锁、支付，甚至他们还可以拷贝手机中用户的指纹，这将极大地威胁用户安全。指纹和密码不同，密码被盗可以换，而指纹被盗则更换难度很大。值得一提的是，指纹识别还因为受伤、温湿度等因素干扰影响，公安部的数据也显示大概3%左右的人指纹无法被很好识别。

![](../Images/f5bc3c4e45cd2d7b0a9d54a65c4dcb5b.png)

       人脸识别也是同样,面部识别是基于生物特征的识别方式，与指纹识别等传统的识别方式相比，具有实时、准确、高精度、易于使用、稳定性高、难仿冒、性价比高和非侵扰等特性。但不少电影中都给我们展示过，通过高科技乃至3D打印、全息投影等技术针对面部识别的固有规则，很容易采用针对性的方式，进行攻破，带来更可怕的安全隐患。而且一旦人脸识别大规模应用后，就和指纹支付一样，一旦被攻破，要想修改难度很大。

**手机自毁终于研发成功**

       可越是在这不安全，出现尴尬局面的时候，去催生出了一项手机自毁功能的研发。近日，由沙特阿拉伯阿卜杜拉国王科技大学研究人员开发出的一种新型聚合物就方便得多，不但可相容目前常见的大多数半导体，最快更可于10秒内完全自毁。

![](../Images/b3c203daa260aa86a9c8446dcbaca4a2.png)

       据研究员表示，这种自毁机制主要是建基于一种可膨胀的聚合物层，当加热到摄氏80度后，其体积便会迅速膨胀至原来的7倍，而触发过程只需由加热电极便可进行。据报只需释放出500至600mW电力，即可于10至15秒内膨胀并摧毁零件。由于整个过程只是透过张力去撕裂破坏零件，比起爆炸破坏会安全得多。

**自毁虽好 但安全成疑**

       这个自毁功能虽然完美的解决了安全性与便捷性不能同时存在的问题，但这次却带来了人身的安全问题。由于此原理是加热膨胀奖处理器摧毁，万一自己误操怎么办，万一伤到小偷怎么办。另外一旦手机有了这个装置，火车飞机就彻底上不去了。虽然官方声明手机自毁的同时不会超出指定的安全范围而伤及无辜。但仅仅伤到自己或者偷盗者都是一个很严重的问题。

![](../Images/137df31fc1d99ed55241fe6eb97186b9.png)

       不仅如此，一旦大规模的应用，未来的二手手机交易市场就面临着关门大吉的惨状，因为在国内完全有这样一群只要我卖出去拿到钱了，才不管你能不能使用，反正交易的时候没有任何问题。

       总之，不管到了什么时候，安全和便捷总是成反比的，要想享受安全的环境，先让自己“不方便”起来吧。或许这项技术的初衷是为了给人们提供一个更安全、更便捷的手机使用环境，不过在目前来看，它还不够令人完全信服。
