泰康保险集团信息安全2017年招聘需求


一、 信息安全专家 (方向: Web安全，移动安全)

岗位职责：

  • 1. 对公司网站、业务系统及移动应用进行安全评估测试（黑盒、白盒测试）

  • 2. 制定Web相关平台、系统的安全加固标准

  • 3. 制定Web和移动应用安全开发相关制度、规范及标准

  • 4. 协助完善公司的安全监控、扫描等平台功能和规则

 

技能要求：

  • 1. 深入掌握Web漏洞原理，可以独立分析和挖掘Web漏洞

  • 2.熟练使用各类安全、黑客工具，可根据需要扩展规则、添加模块

  • 3. 熟悉脚本语言，可以根据测试需求独立编写工具

  • 4. 熟悉各类Web应用、平台的搭建，了解加固重点

  • 5. 有责任心和职业道德，具备良好的团队合作沟通能力，对安全有兴趣和热情

 

人数：Web安全，移动安全方向各1人

待遇：15k--25k（面谈）

福利：七险二金、弹性工作、过节费、生日卡、加班费、年终奖、健身房、办公环境优越

 

二、 信息安全专家 (方向: 安全分析，逆向分析, 应急响应)

岗位职责：

  • 1. 根据对流量、日志等的分析，发现异常或攻击

  • 2. 负责安全事件监控、入侵检测及响应

  • 3. 负责建设基于开源软件的安全监控分析系统

  • 4. 负责漏洞分析研究，恶意程序分析

 

技能要求：

  • 1. 熟悉黑客攻击技术，安全漏洞原理

  • 2.熟悉流量分析，安全日志分析

  • 3. 有安全监控，入侵检测及响应，安全事件调查相关经验

  • 4. 有漏洞分析研究，恶意程序逆向分析相关经验（逆向分析）

  • 5. 有责任心和职业道德，具备良好的团队合作沟通能力，对安全有兴趣和热情

 

人数：安全分析，逆向分析,应急响应方向各1人

待遇：15k--30k（面谈）

福利：七险二金、弹性工作、过节费、生日卡、加班费、年终奖、健身房、办公环境优越

 

三、安全开发专家

岗位职责：

  • 1. 负责安全大数据分析平台的开发, 安全监控平台的功能扩展，关联分析开发

  • 2. 与开发团队配合，进行安全框架的开发工作

  • 3. 对开发团队的项目开发工作给予安全指导，根据项目中面临的具体安全风险给出解决方案

  • 4. 推动SDL工作落地

 

技能要求：

  • 1、有SDL方面的相关经验，对SDL工作有自己的理解。

  • 2、熟悉spring/myBatis开源框架，理解其设计思路，并有一定的个人见解；

  • 3、了解Tomcat等WEB应用服务器，有相关应用部署经验，能够熟练使用常见Linux命令；

  • 4、熟悉web领域面临的安全风险，对SQL、XSS、CSRF等漏洞的原理有深入的理解

  • 5、在企业安全体系的建设上有自己的理解

  • 6、熟悉以下至少两种开发语言：C、C++、java、php、python、等

  • 7、有责任心和职业道德，具备良好的团队合作沟通能力，对安全有兴趣和热情    

 

人数：2人

待遇：15k--30k（面谈）

福利：七险二金、弹性工作、过节费、生日卡、加班费、年终奖、健身房、办公环境优越

 

四、安全合规员

岗位职责：

  • 1。负责组织定期的信息安全风险评估、以及全集团范围内信息安全合规检查；

  • 2.审核泰康保险集团范围内相关信息安全策略、标准和流程的合规性并提出修改建议；

  • 3.配合集团内稽核监察部、内控合规部等部门组织的有关信息安全的内审与检查工作，配合外部监管机构与认证机构的合规检查工作；

  • 4.协助组织信息安全相关的培训与文化宣导；

  • 5.对信息安全事件进行记录、分析、汇报和总结，组织对重大信息安全事件的调查和后续跟进；

  • 6.负责信息安全管理过程中的文件归档管理。

 

任职资格：

  • 1.熟悉信息安全相关的国内外法律、法规、标准，特别是熟悉ISO27001，等保，云安全等规范标准；

  • 2.具有1-2年信息安全从业经验；

  • 3.掌握基础的IT技术；

  • 4.责任心强，具有较强的沟通协调能力，具有较高的快速学习能力。

  • 计划人员数量：1名

 

五、安全规划与设计员

岗位职责：

  • 1.参与制订和更新集团信息安全的整体规划、管理体系架构，以及实施过程中的监督；

  • 2.制订、更新泰康集团的信息安全管理制度、标准和管理流程，推动和监督安全管理制度和技术规范的执行；

  • 3.根据应用开发和数据的安全规定和指导方针，指导、监督应用开发中的安全技术手段和控制措施的符合性；

  • 4.根据加密标准和有关合规要求，指导、监督国产密码及加密技术在集团内的落实；

  • 5.维护集团信息安全应急预案，并定期组织对预案进行演练。

任职资格：

  • 1.精通ISO27001、ISO13335、ITIL、等保等业界安全管理标准及风险管理理论；

  • 2.熟悉与IT安全相关的法律、法规；

  • 3.熟悉开发生命周期安全管理以及加密技术有关理论，并具有一定的实践经验；

  • 4.具有较强的沟通、协调能力；

  • 5.有安全规划、制度建设等相关信息安全项目实施经验；

  • 6.5年以上的信息安全从业经验；

计划人员数量：1名
