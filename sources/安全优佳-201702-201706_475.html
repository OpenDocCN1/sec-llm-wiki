你或许没有听过 SHA，也可能不太了解什么是哈希算法，但这些听起来陌生的事物却与我们的日常生活息息相关。

       SHA（安全哈希算法的一种），可谓是网络安全的“防线”，它可以帮助我们验证文件的可靠性，避免病毒或恶意代码的“入侵”，在浏览器保护、代码库管理等等数字安全加密领域都起着举足轻重的作用。

近日，谷歌发布了一条爆炸性的新闻，称他们首次攻克了安全加密算法 SHA家族中的“ 老前辈” SHA-1 ，给这个曾经在密码学领域中流行的安全算法宣判了“死刑”。

这是谷歌联合荷兰 CWI 研究所，花费两年时间，进行超过 9 兆次运算（9,233,372,036,854,775,808）后才得出的突破性成果， 他们将其称为 SHAttered attack。新闻发布当天，研究人员还向大众展示了 SHAttered attack 的证据——两个文件颜色存在着明显的差异，但他们显示出的 SHA-1 哈希值却一模一样。

研究人员解释道，哈希值是由如 SHA-1 这类安全算法运算所得到的一串数字，就像是文件的“身份证号码”，每个文件都“持”自己独有的哈希值。哈希碰撞指的是来自两个不同文件的哈希值一致，是本不该出现的状况。但当哈希算法存在漏洞时，一个 有足够实力的攻击者 就能够制造出碰撞，也就是说攻击者可以向依靠哈希值来“验明身份”的系统植入错误文件，并进行恶意破坏。

其实早在 2005 年，SHA-1 诞生十年后，密码分析人员就已经发现 SHA-1 存在漏洞，有安全隐患。另外 2012 年时安全技术专家布鲁斯·施奈尔做出了预测，完成一次 SHA-1 哈希碰撞所需要的成本将逐渐降低，到了 2021 年可能只需要 4.3 万美元就能实现。同时他还暗示，2018 年将会出现具备伪造 SHA-1“身份凭证”能力的犯罪团伙出现。

虽然这种犯罪事件还未出现，但从 2014 年开始大部分网站已经抛弃了 SHA-1，选用 SHA 家族中的“后起之秀”SHA-2。与此同时，三大浏览器谷歌的 Chrome、微软的 Edge/IE 和火狐浏览器也相继宣布全面放弃 SHA-1，停止接受使用 SHA-1 证书的网站。

那么既然 SHA-1 已经犹如“弃子”，为什么谷歌还要花费这么大精力去破解它呢？上面提到的 9,233,372,036,854,775,808 次演算并非易事，是需要一个 CPU 运行 6500 年加上一个 GPU 运行 110 年才能完成的。难道说谷歌是太无聊了，或者说想炫耀炫耀他们系统的计算能力？

其实不然，这或许是谷歌“敦促”网站运维人员弃用 SHA-1 认证的一种表现。从 2014 年 10 月份开始，使用 SHA-1 认证的网站在 Chrome 上的分类标记已经从“存在小错误”的黄色小三角图标变成“禁止通行”的大红叉，而这次的 SHAttered attack 犹如给 SHA-1 最后补上重重一刀，对仍使用 SHA-1 认证的网站和代码库发出“最后通牒”。

而对于我们普通用户来说，这次加密技术的破解事件或许是一件好事。这表明随着技术的进步和计算机行业发展，整个网络系统的安全加密防线也在不断加强。不过还在使用 Windows XP 系统的用户就要小心了，因为 Windows XP 并不支持 SHA-2。
