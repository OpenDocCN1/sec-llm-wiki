# 苹果回应Face ID安全隐私问题 参议员大赞

很多政客都十分关心苹果的 iPhone X ，或者说他们更关心的是 Face ID 的隐私和安全问题。

![](../Images/16dd74028923fe27022000a739d0cf6b.png)

就在 iPhone X 发布后不久，美国参议员 AI Franken（隐私、技术和司法委员会成员）便向苹果 CEO 蒂姆·库克致信，他就 Face ID 的安全和隐私提出了几个问题。 AI Franken 要求苹果在 2017 年 10 月 13 日前进行回复，而苹果的美洲公共政策副总 Cynthia Hogan 这通过邮件及时对他说提出的问题进行了回应。

在邮件中，Cynthia Hogan 重点提到苹果最近公布的 Face ID 安全白皮书以及 Face ID 支持文档，其中她明确说明了苹果是如何保护用户隐私以及保持用户数据安全书所采取的措施。

让我们来看看 Cynthia Hogan 是如何回答参议员的问题的 。Franken 参议员的问题中有一个是关于 Face ID 是如何被训练的，苹果的回答如下：

“产品对不同种族的人的可及性对我们来说至关重要。而 Face ID 使用的是我们利用超过十亿张图像开发的面部匹配神经网络，这些图像包括了在参与者知情并同意下的情况下，研究和收集的 IR（红外）和深度影像。”

“我们会与来自世界各地的参与者进行合作，以获得一个有代表性的人群，这其中包括性别、年龄、种族和其他因素等等。我们还会根据需要去增加研究，为各种各样的用户提供了高度的准确性。此外，经过训练后的神经网络可以有效防止那些试图用照片或者面具解锁手机的做法。”

![](../Images/6540297154f6f6822aa0d11c6f40eecf.png)

在收到苹果的回复后，Franken 参议员今天发表声明，对苹果愿意提供关于 Face ID 的信息的做法表示赞赏。

Franken 说：“一直以来，我们都清楚并切实体验到了几年前仍难以想象的新技术和创新。尽管这些发展为我们的家庭、事业以及我们的经济带来很大帮助，但也带来了关于如何保护我认为是消费者面临的最紧迫的问题：隐私和安全。我很感谢苹果公司愿意与我的办公室就这些问题进行沟通，我很高兴看到该公司为解决消费者隐私和安全问题而采取的措施。”

“我会继续保持与苹果的联系，了解更多关于如何计划保护那些决定使用最新 iPhone 的面部识别技术的用户的数据安全。”

其实除了提供 Face ID 安全白皮书以及详细的支持文档，苹果还通过让高级工程主管 Creag Federighi 参加多次采访来向外界提供有关 Face ID 的信息，所以最近我们也看到 Creag Federighi 多次通过邮件来回应果粉们的问题，而且苹果也针对这些问题，做出了许多的承诺。

很快，iPhone X 就要正式上市了，届时，我们将能真正体验到 Face ID 是不是真的那么安全有效，只不过遗憾的是，一开始的时候，iPhone X 的供货量会很少，除了期待 Face ID 的到来以外，我们也祝愿大家都能抢到自己心仪的爱机。
