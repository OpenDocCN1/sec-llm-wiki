# 2017云栖大会：如何攻克万人Wi-Fi难题？

每当一场行业盛宴拉开帷幕，除了大会的内容干货必须要引人制胜外，会议环境的一些标配元素实际也不可或缺，比如现场过硬的Wi-Fi网络覆盖。因为对于越来越乐于分享的人们来说，在摩肩接踵的会议现场内无法流畅地使用大会Wi-Fi来刷朋友圈/微博等社交平台的话，那可是一件非常令人诟病的事情。

上行7.51Mbps的大会Wi-Fi：靠谱！

现在伴随2017年云栖大会的召开，来自世界各地的4万多名各界人士齐聚一堂，在共历一场科技创新盛宴的同时，也再次向大会主办方发出了一项高密无线接入的全新挑战。

![](../Images/4d4402ff437a8bbf51b5863297f3ba05.png)

2017年云栖大会

据悉，此次为期4天的云栖大会，议题涵盖了人工智能、大数据、新零售、多媒体、AR（增强现实技术）等20个前沿技术领域。参会者不仅能在主论坛与科技行业的大佬们“亲密”接触，还能深入参与由800多位演讲嘉宾分享的两场主论坛、20场峰会、120余场分论坛的“科技盛宴”，其中有55位全球知名的科学家作学术分享，可以说是精彩纷呈、干货满满。

以往在此类大型会议中，由于现场人数众多，会场的Wi-Fi经常形同虚设，连不上、打不开等囧状时有发生，想传照片、发视频俨然成为奢侈的需求。那么在本届云栖大会上呢？

经过记者在现场实际接入大会Wi-Fi网络（SSID：“The Computing Conference”）测试后发现，虽然面对万人无线接入的巨大压力，但现场的Wi-Fi体验却相当流畅。

下图是通过speedtest获得的会场Wi-Fi测试结果，可以看到无线网络的下行达6.02Mbps，上行更可达7.51Mbps，PING值仅为7ms，不仅能够满足参会者发朋友圈、刷微博，上传照片等需求，甚至能够确保视频流等大带宽应用的快速传输。

![](../Images/3fdf283841931d9b961b4c973f45b85c.png)

2017云栖大会现场Wi-Fi测试：下行6.02Mbps，上行达7.51Mbps

当然，几天下来的Wi-Fi体验不只有速率快速，信号覆盖也相当到位。记者在各个场馆内的不同地方踩点后发现，手机上的无线信号一直处于满格状态，而且由于整张无线网络支持无缝漫游，因此穿行在云栖大会上并未出现过掉线、重连等异常情况。

流畅高密无线网支撑者：锐捷！

如此顺畅的会场Wi-Fi，可并不多见，记者在提示海报上注意到了支撑本届云栖大会无线网络的供应商--锐捷网络（以下简称“锐捷”）的身影。据了解，实际上这已经是锐捷第三次为云栖大会Wi-Fi保驾护航了。

![](../Images/afd9f5f9fc0b2d56117c94e449fbc565.png)

锐捷网络为2017云栖大会提供现场Wi-Fi（见黄框，点击看大图）

虽然已经是老马识途，轻车熟路，但伴随逐年增加的参会人数，却让组网的难度系数一再刷新。根据其WIS π平台的统计数据显示，本届大会开始之初，仅10月11日一上午的接入峰值就达到3384个终端，峰值流量突破了800Mbps，传输数据总量高达844GB，相当于分享了20多万张的4MB照片。

锐捷网络WIS π平台对现场Wi-Fi网络的监测数据（点击看大图）

为了应对有限空间里短时间内大量终端的高并发率，以及克服AP间干扰，锐捷高密度会展无线解决方案再次用实力向云栖大会提交了一份出色答卷，来确保现场观众可以随意使用免费Wi-Fi分享精彩瞬间，为会议添彩。

4阶段攻克万人Wi-Fi难题：给力！

那么在新的挑战下，锐捷是如何攻克万人Wi-Fi的这一难题的呢？通过了解，记者发现锐捷可不仅是完成会场的Wi-Fi组网部署这么简单，实际上还专门针对本届大会制定了4个不同阶段的技术支持服务。

首先，在地勘阶段，通过对往届AP部署点位的梳理与分析，锐捷团队根据今年云栖大会更高密度的并发需求，对AP点位重新进行了优化及AP增补，将AP数量从500个增加到591个。

其次，在施工阶段，为了确保无线覆盖方案可以严格按照AP点位设计方案进行最佳部署，即使在国庆假期期间，锐捷工程师仍然专门连续8天加班加点，轮班指导监督施工队进行AP安装部署，为后续调试网优打下坚实基础。

![](../Images/0e4caf13f3452164da9144b6726ec797.png)![](../Images/11e2c27224a5a4245624857b014bb072.png)

锐捷无线AP在云栖大会上不同点位的部署

随后，面对时间紧任务重的调试阶段，为了确保最终的优化效果，现场保障团队依然加班加点进行专业调试，不仅利用wisπ对各个会场进行自动网优，更在此基础上逐个开展人工级别的精细网优，以确保大会开启后的流畅Wi-Fi体验。

最后，在现场保障阶段，根据各会议的重要性，还有6名一线售后+1名TAC（技术支持中心）+2名研发，进行分区域驻场保障，使用WISπ及WiFi魔盒进行实时用户体验监控，可快速响应异常事件，来为本届大会的Wi-Fi提供技术保障。

![](../Images/c753d406f7b57c640f5b63e3dc2e29c2.png)

锐捷网络保障团队在云栖大会现场提供技术支持

通过各个阶段的精心部署，2017云栖大会上的Wi-Fi网络再次经受住了万人Wi-Fi的现场挑战，并获得各界人士的一致称赞。然而你或许不知道的是，助力一年一度云栖大会搭建优质Wi-Fi网络的锐捷，还曾成功服务过腾讯全球合作伙伴万人大会、GITC全球互联网技术大会等众多大型活动。而这些仅仅是素有“扎根行业、深入场景”理念的锐捷稳居WLAN供应商前三名的又一佐证罢了。
