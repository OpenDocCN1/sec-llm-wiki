# 特斯拉CEO怒怼谷歌新品 公然漠视用户隐私

       谷歌2017年秋季新品发布会于北京时间2017年10月5日0点如期举行，这次发布会谷歌可谓是下了大力气，共发布8款硬件新品，其中包含手机、电脑、智能音箱等，另外还有一款Google Clips人工智能相机让人印象深刻，但是特斯拉CEO埃隆·马斯克却不认可这款产品。

谷歌Clips可以利用人工智能判断用户可能感兴趣的人脸，并在这些人脸出现时自动拍照。拍照时不会闪光，不需要通过语音启动摄像头，所以用户自己并不会知道何时会拍照。特斯拉CEO埃隆·马斯克表示，“他们甚至不屑于让自己‘看起来’很无辜。”他甚至指责谷歌公然漠视隐私。  

![](../Images/7eab584bacb20ad0f026b5d068b9e017.png)

目前谷歌方面并未对特斯拉CEO埃隆·马斯克的评论做出回应，但此前曾有谷歌的相关人员表示，“所有机器学习都在相机上运行，Clips也不会联网传输内容。与传统相机相同，除非你主动导出照片，否则所有内容都会一直保存在相机里。”

目前尚且未知谷歌Clips会不会像谷歌眼镜一样，面临涉嫌偷拍而遭受各种问题，感兴趣的小伙伴不妨关注一下。
