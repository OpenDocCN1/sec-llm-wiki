# 一句话告诉你，什么是“物联网”

现在科技高速发展，不断的改变着人们的生活。什么移动支付，滴滴打车，无人超市等等，真是日新月异、层出不穷。现在又在说“物联网”“云计算”“大数据”“人工智能”真是目不暇接，真是云里雾里。那到底什么是“物联网”？物联网对人们生活又有什么意义？  

![](../Images/bd67519941ef00c1b1f4a0764f32dfa4.png)

物联网其实，就是简单的一句话，就是物与物之间实现直接交流。为什么人们需要物与物之间直接交流呢？  

互联网时代，特别是移动互联网让人与人交流更加方便快捷充分。而在互联网时代，人与人之间的交流，其中有很大一部分是进行物与物交流。比如一家汽车制造厂，要生产10000辆小汽车。加备胎，共需要50000套轮胎，这时汽车厂采购就会跟轮胎厂销售进行交流。然后轮胎厂采购又要跟橡胶厂销售进行交流。这时如果橡胶厂不能提供满足50000套轮胎的橡胶，可能汽车厂就有麻烦。就生产不了10000台汽车。如果实现了物联网，就省去了人与人之间的交流。就是10000台汽车直接同时跟几个轮胎厂、跟橡胶厂、以及橡胶厂的上游供应商在物联网上进行直接交流。这样就能让生产的供应链更准确、更高效。让社会资源得到充分的利用。这种工业生产上下游物与物之间的直接对接交流，就是工业4.0.

在生活中，也是物与物进行交流。比如，你买了一套100平米的住房，接下来就是装修。现在，你是跟装饰公司，装饰城的商店，上网找材料，一个一个的慢慢的交流。以后，到了物联网时代，就是你用AR技术，直接编辑和添加你想要添加在现实场景中的AG虚拟物件，根据自己的喜好，自己设计。你在编辑和设计过程中，你的住房这个物，就同时在跟你需要的材料、家具、家电等进行交流，只要你确认。就能立即按云计算制定的程序进行装修添置家具。在装修过程中，大量的工作是由材料厂家签约的智能机器人完成。能够保质高效的完成各项工作。

你日常生活中也是物与物进行交流。比如你开空调，空调会给门窗同时下指令，门窗自动关上。甚至你家的冰箱里的食物，米桶里的米都可以跟物联网对接，会定期配送。也就是说，你可以将你生活中的每一件实物，都可以放到物联网上，这些实物跟万物交流，给生活带来便利。

![](../Images/83df7dba0e21619ca52118758ca5b102.png)

简单的讲，物联网就是万物相连。通过%5G、云计算、大数据、人工智能等高科技手段，让物与物直接、充分进行交流，来满足人们生活的需要。
