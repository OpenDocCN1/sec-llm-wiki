# 六年来首变！微信地球启动页换图“国产”

北京时间25日17时开始，17时开始，为庆祝“风云四号”正式交付用户投入使用，微信启动页开始“变脸”，由此前的JPG静态图换成了GIF动态图片，这也是微信6年来首次“换脸”。  

![](../Images/80248be4936bda6a8c476b344e9ef13c.png)

一对比我们不难看出，两张图片上地球显示的区域发生了变化~这可是微信运营6年来首次更换启动图。

腾讯科技表示，25日至28日期间，用户在微信启动时，可以欣赏到由“风云四号”从太空拍摄的最新气象云图。相关单位发布消息称，微信启动页面变化后，背景中的地球图片由非洲大陆上空视角，变为中国所在的东半球上空视角。画面从人类起源的非洲大陆逐渐过渡为华夏文明起源地。

媒体援引微信团队介绍称，原本微信启动页中选用的照片素材是NASA在全世界范围公开的第一张完整的地球照片，画面中所显示的是非洲大陆，名为“蓝色弹珠”，“这是人类第一次从太空中看到地球的全貌。”

关于选用这张照片作为素材的原因，微信团队透露称：“非洲大陆是人类的起源地，我们将非洲上空的云图作为启动页的背景图，也希望将‘起源’之意赋予启动页面。因为人类的出现，才有了沟通的存在和意义。而此次展示‘风云四号’拍摄画面，也是寓意从‘人类起源’到‘华夏文明’的历史发展，旨在向亿万微信用户展示华夏大地的河山风貌。”

在9月25日至9月28日期间，用户在微信启动时，可以欣赏到由我国新一代静止轨道气象卫星“风云四号”从太空拍摄的祖国全景。

风云四号综合技术性能国际领先，填补了三项国际空白。在轨测试期间，风云四号卫星对台风、沙尘、暴雨强对流灾害天气和蓝藻水华、大气灰霾环境生态问题进行了实时且有针对性的应用监测，为今年5月中国北方地区严重沙尘、6月华北特大暴雨、6月底至7月初南方持续降水以及“苗柏”“南玛都”台风的预警提供了有力支撑；还为“一带一路”国际合作高峰论坛、全运会重大活动发挥了气象保障作用。

前风云四号卫星已被世界气象组织纳入全球对地观测气象卫星序列，有望在年底具备试运行和服务能力，将为中国及亚太地区防灾减灾和经济社会发展提供支撑服务。
