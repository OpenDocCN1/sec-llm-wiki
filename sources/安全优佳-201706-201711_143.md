# 低级比高级安全？磁盘格式化要保护秘密

不管是重装系统还是新加硬盘，我们都会进行的操作是格式化硬盘。对于出错的SD卡和被恶意软件侵占的硬盘，也可以通过格式化来使其恢复使用。

![](../Images/06f6cf20698fdb7fa91fb15c42374284.png)

磁盘和数据都很重要

提到格式化可能很多朋友不以为意，无非就是借助软件将硬盘进行清空处理，windows自带的工具也可以快速对磁盘进行格式化，看起来也没有什么技术含量，其实不然，了解了不同的格式化在使用磁盘时可以更有效。

![](../Images/c23afa3d2a1dc03f0b293cb73d5fe9a6.png)

格式化磁盘也有技巧

顾名思义，格式化就是将磁盘初始化，也就是清空磁盘中的数据，我们在进行格式化的时候，系统或软件也会警告我们格式化会删除磁盘上的所有数据，不过不同的格式化方式会使得删除的数据可恢复性不同，下面我们就来聊聊磁盘格式化的小知识。

对磁盘进行格式化有两种方式，分别是低级格式化和高级格式化。其实这两种格式化的名称和我们对字面的理解不同，恰好是相反的。

![](../Images/763887fda482c7de7a2f11deb65d54f2.png)

高级格式化

高级格式化是根据一定的分区格式对磁盘进行标记，并生成引导区信息，初始化空间分配表，标注逻辑坏道等。高级格式化并不会删除磁盘中的数据，而是重新生成引导区信息使磁盘中的内容可以被覆盖掉，通俗地讲就是把目录删除掉了。

![](../Images/55a88f065e561bd160f1d50c0997dfe2.png)

低级格式化会清除磁盘中的内容（图片源自网易博客）

低级格式化则是将磁盘划分出柱面和磁道，再将磁道划分为若干个扇区，每个扇区又划分出标识部分ID、间隔区GAP和数据区等。和高级格式化不同，低级格式化会将整个磁盘覆写一遍，磁盘中的所有内容就不复存在了。

![](../Images/c3c866176d7f68a25cae8aa32a7122a0.png)

快速格式化其实是高级格式化的一种

在进行格式化的时候我们可以看到一个“快速格式化”的选项，这里的快速格式化就是高级格式化的一种，不同之处在于之从分区文件分配表中做删除标记，而扫描磁盘是否有损坏的扇区，在提高速度的时候牺牲了可靠性。

高级格式化和低级格式化的区别在于格式化的方式不同，对于用户来说最大的影响就是数据的可恢复性。高级格式化删除的数据可以借助软件进行恢复，而低级格式化删除的数据基本上是不可以恢复的。

![](../Images/58853d0bd7094ff24cc4eb2abf62c053.png)

遇到这种情况可以先格式化，后恢复数据（图片源自百度知道）

如果磁盘中有重要数据但是又不能物理损坏，就要进行低级格式化，很多电脑厂商会在回收电脑之后对硬盘进行低级格式化，还有些情况下会对磁盘进行多次低级格式化来保证数据完全不可恢复。

![](../Images/be23fba10ecde91cee8ee29f5b947c85.png)

使用软件可以看到磁盘使用信息

需要注意的是，由于低级格式化是将磁盘全部覆写一遍，因此对磁盘寿命会有影响，如果硬盘已经有了物理坏道，那么低级格式化会进一步损坏硬盘，所以这种情况下不适合低级格式化。

![](../Images/eaf380059e5c284fbdc17ea3d91ca8ea.png)

出现坏道的硬盘要避免低级格式化

其实，我们经常进行的格式化是高级格式化，而不是字面上的低级。在需要格式化没有损坏扇区的磁盘时可以优先选择快速格式化，正常格式化磁盘则可以选择高级格式化，低级格式化一般不使用。

了解了不同格式化的区别和应用，我们再为大家介绍一些使用磁盘时的小技巧。

机械硬盘在使用过程中要避免振动以免损伤盘片，如果需要挪动机箱应该先关闭电脑，移动硬盘也要做好防震措施，避免跌落和磕碰。

![](../Images/61565ed29ac552440ea7a65870054e85.png)

精密的机械硬盘需要做好防震措施

重要的文件要做好备份，有必要的时候要做云端备份和本地备份双重备份，并保护好密码，防止丢失的同时也要预防窃取。

![](../Images/fd3b8fb88fdf92062c7c6d161f6e71ec.png)

做好重要数据备份很重要（图片源自易百）

如果操作失误格式化了磁盘，或是已经格式化的磁盘中曾经有未备份的资料，可以通过数据还原来找回数据。很多软件的还原功能允许我们访问磁盘中已经删除的文件，不过要注意这样会损伤磁盘，要避免多次恢复数据。

![](../Images/0ff164161c7f266732bb532a912ef6a9.png)

数据恢复软件（图片源自软件E线）

有的朋友旧硬盘分区不合理，需要重新分区的时候可能还需要重装系统，其实这样不必。借助分区助手这样的软件可以将磁盘重新分区且不需要删除文件，这样既完成了分区容量的重新分配，又保存了重要数据。

![](../Images/d060e88d2b444848b6f99bdefee1dd55.png)

分区助手可以便捷更改硬盘分区（图片源自百度经验）

其实磁盘要比很多人想象的要坚强，只要保持良好的使用习惯，很多硬盘都能正常使用很长时间，我们在使用硬盘的时候还要注意做好基本的散热和防潮防震，选用硬盘和优盘也要注意选择有品牌和质量保障的产品，避免假冒伪劣。
