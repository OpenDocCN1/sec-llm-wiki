# 大公司钟爱Windows,程序员该抛弃Linux了？

Linux是当今最流行的操作系统之一，诞生于90年代，现有用户群已经遍及世界各个行业。Linux在我们的手机、汽车、冰箱设备中的应用无处不在，但在Linux成为运行桌面、服务器和嵌入式系统平台之前，它仍是最可靠、最安全的操作系统之一。

![](../Images/1cbf8e485b6e911c1ca8103c8da8da0f.png)

但是，最近有网友提出了这样一个疑问，既然Linux这么优秀，那我们到底该不该学习Linux呢?

这位网友叫做Per，他的大致经历是这样的——Per是一所欧洲大学的学生，课程主修嵌入式系统方面。但他经常听到许多关于Linux有趣的知识和信息，所以有时他非常渴望学习Linux。但Per也了解到，Linux在许多小公司普遍使用，而大公司却更加钟爱Windows等，这也是教育官方的政策。这样Per就开始疑惑，作为一个编程开发人员，如果以后想要更大的发展，到底该学习Linux还是Windows?

![](../Images/d9cba925a9f72a1cf83ffd5fd360c3e0.png)

其实对于学习的操作系统是Windows还是Linux都无关紧要，对所有的东西而言，学习本身就不是一件坏事，你学的东西也许不知道哪一天就排上了用场，中国有一句比较有诗意的话：“你的气质里藏着你走过的路,读过的书和爱过的人”。就像我是一名律师，现在正努力的学游泳。学会了游泳关键时刻就能救命，学习法律知识和游泳就好比学Windows与Linux，更何况相对于法律和游泳而言，Windows与Linux还有点关系呢。

![](../Images/610c58571bd78c25b284a44699e251be.png)

不要为了学习而学习，不要为了某种利益而学习，以一种技术为生的人，80%也都是源于自己对这个行业的热爱。
