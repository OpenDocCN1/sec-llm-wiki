# 美国全力封杀杀毒软件卡巴斯基：被百思买下架

据CNET报道称，美国一家领先的电子和软件连锁店百思买（Best Buy）不再为客户提供俄罗斯公司卡巴斯基实验室产品，目前连锁店网站上已没有该公司产品。

![](../Images/06459e6065cf4416d91c8c498bd60207.png)

美国联邦调查局对卡巴斯基进行了多次测试后，依然建议政府部门包括不少企业公司封杀这款软件，特别是能源部门，具体原因是，隐藏所谓的后门，可能危及信息安全。

卡巴斯基实验室新闻中心表示，已停止在美国百思买大型连锁店销售公司软件，并表示将继续通过自己的网站和其他零售商在美国销售这一软件。Verge引述卡巴斯基实验室声明称，对于整个事件与俄罗斯没有任何关系。（yoyo）
