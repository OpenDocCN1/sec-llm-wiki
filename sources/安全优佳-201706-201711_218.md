# 智能时代 软件赋能——2017中国软件技术大会

伴随着物联网、云计算、大数据、人工智能等智能技术日趋广泛的应用，软件的赋能价值日益凸显，同时软件的角色地位也在发生变化，软件技术的创新更是日新月异，2017中国软件技术大会将从白金讲堂及6个专题会场为参会嘉宾奉上一场豪华技术盛宴：

![](../Images/db71d3f0165fd93a855f7c3df325dd34.png)

由中国科学院软件研究所、中科软科技股份有限公司联合主办，北京中科凯亚科技有限公司协办的第15届中国软件技术大会将于2017年12月在北京· 国家会议中心隆重举行。

毋庸置疑，我们正在迈入智能时代，伴随着物联网、云计算、大数据、人工智能等智能技术日趋广泛的应用，软件的赋能价值日益凸显，同时软件的角色地位也在发生变化，软件技术的创新更是日新月异，2017中国软件技术大会将从白金讲堂及6个专题会场为参会嘉宾奉上一场豪华技术盛宴：

**专题一**

大数据&人工智能

**主题：**大数据实时计算、大数据前沿技术、大数据应用实践、深度学习、人工智能应用等

建立在大数据基础上的人工智能技术，正在深刻改变人类社会的未来，从基础理论研究、到关键共性技术研发、再到人工智能应用开发，软件作为核心载体，发挥着无可替代的作用。

**专题二**

云计算&云生态

**主题：**云计算技术、云架构、云安全、云应用等

云计算已经成为智能时代基础IT技术，并正在形成包括基础架构、计算技术、云安全、云应用在内的完整、健全的云生态。

**专题三**

移动开发与应用实践

**主题：**移动开发技术、用户体验、应用创新实践等

智能时代是移动互联时代的延伸，以用户体验为核心的移动软件开发和创新活动更趋活跃。

**专题四**

企业级服务和架构设计技术

**话题：**实时系统架构、分布式系统架构、企业级服务架构、微服务架构等

智能时代正在推动企业服务的转型和IT架构的升级，如何打造一个适应智能时代发展需要的企业级IT系统架构，支撑企业智能化业务的发展，尤为关键。

**专题五**

研发管理新思维

**话题：**产品设计思维、用户体验设计、测试技术、研发团队管理、自动化运维、性能优化等

智能时代用户和市场需求的变化，正在倒逼软件研发管理思维的创新，如何在软件开发中高效完成产品设计思维、用户体验设计、测试技术、研发团队管理、自动化运维、性能迭代优化等工作，成为我们的必修课。

**专题六**

金融科技创新与未来

**话题：**区块链、金融科技、保险科技、传统应用转型创新等

金融科技和保险科技，作为智能时代当前最具商业价值的应用场景，备受人们关注，如何更好地以创新的科技拥抱智能的未来，金融行业正在积极地思考和行动。

2017中国软件技术大会将邀请五十多位知名技术大咖、行业企业的技术专家、技术畅销书的作者、独立咨询师等就多个新兴前沿领域，深入解析最新技术热点，探讨软件的赋能价值，探讨软件技术的创新。
