# 多家主流手机厂商的Bootloaders中存在多个漏洞，华为也中招

来自加州大学圣巴巴拉分院的9名研究人员发现，5家主流芯片厂商的Android bootloader 组件存在多个漏洞，该漏洞可导致手机信任链在引导过程中被攻破，从而使设备遭受攻击。

![](../Images/a804c3dfb08f1fba4788e886cb64d20a.png)

通过BootStomp来分析bootloader

研究团队发现bootloader 闭源并缺乏代表的metadata（如程序头或调式符号），导致难以进行逆向分析和安全审计。 因此团队的大部分工作聚焦于开发名为BootStomp的新工具来帮助测试分析bootloader。

BootStomp工具的目标是自动识别使用攻击控制的且由Bootloader代码信任的，非易失性存储器的相关安全漏洞。具体来说就是研究人员将使用自己的系统作为自动系统，将bootloader作为输入，输出大量可提示安全漏洞存在的警报。然后人工分析这些警报，并快速确认高亮显示的功能是否构成了安全威胁。

发现6个新漏洞

通过使用 BootStomp 来寻找之前 bootloader 代码存在问题的区域并查看问题结果的方式，专家们确定了7个安全漏洞，6个新的和1个已知漏洞（CVE-2014-9798）。在6个新漏洞中，bootloader 供应商已经确认修复了5个。

“这些漏洞允许攻击者执行恶意代码，或持续的执行Dos攻击”，研究人员说。“我们的攻击还确认了2个bootloader漏洞，该漏洞让攻击者利用操作系统的root权限来解锁设备并破坏信任链”

4家供应商存在5个不同的bootloader：

华为/海思芯片集 \[华为 P8 ALE-L23\]

英伟达芯片集 \[Nexus 9\]

联发科芯片集 \[索尼 Xperia XA\]
