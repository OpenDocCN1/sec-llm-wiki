# 竟然能当路由器 优盘技巧解锁更多姿势

提到优盘，我们都知道是它非常方便的工具，技术的不断发展进步让优盘在容量增加的同时体积也在边小，也让优盘更加亲民易用。

![](../Images/f19039a030f57c5d5f4fcd49251cc745.png)

小巧的优盘让使用更方便

很多人都有一个或多个优盘，不管是拷电影还是传数据都非常方便，也有不少朋友把优盘挂在钥匙上或者随身携带，都是优盘常见的用法。

其实优盘很简单，在不同材质的外壳内部是PCB电路板，上面有主控芯片，贴片电阻、电容和闪存芯片，其中存储空间就是由闪存芯片提供的。

![](../Images/576e81e46801589fae6ff111503fd063.png)

优盘不只能传送文件

我们都知道优盘可以放置文件，不过优盘可不只是能传文件这么简单，借助一些工具和方法，可以让优盘具有更加强大的功能，不仅可以当做开机钥匙，还能变身路由器，甚至给电脑扩展内存，下面我们就为您介绍几个有逼格的优盘用法。

几年前还有很多用户用光盘安装系统，随着光驱和光盘的使用越来越少，使用优盘也更加方便，准备一个优盘当做系统盘可以在重装系统的时候提供不少便利。

![](../Images/3e6d8a06c159eac4302c934c6ed345d7.png)

制作启动盘会清除优盘中的文件需要做好备份

制作系统启动盘需要准备4G以上的优盘和系统镜像，将优盘连接电脑之后最好先备份好优盘内的重要资料，然后进行格式化，借助USB启动盘制作工具写入优盘即可。

![](../Images/a75878aab90513d9f35cdaedafa954c7.png)

Rufus免安装启动盘制作工具

![](../Images/ef2532efa8b843336671ed398ab20741.png)

Rufus免安装启动盘制作工具

这里我们以Rufus为例，在格式化之后把.iso格式的镜像写入到优盘中，注意这里要用软件进行写入，而不是把系统镜像放到优盘里。

![](../Images/b70c0f6fa64ab173586056d1a8157b5d.png)

制作完成的系统盘图标会不同

![](../Images/7bb22eecb4cd6c779df1c7cd05d565c5.png)

优盘启动需要在BIOS里设置

当使用优盘启动时，需要在系统自检时按Del键（不同的系统可能会采用F12等按键）进入BIOS设置，在高级设置中，将Boot sequence更换为USB-ZIP第一，按F10保存并退出之后重启就可以通过U盘安装系统了。

如果电脑的配置较低，在运行一些应用的时候可能会出现卡顿的情况，我们就可以借助Windows的ReadyBoost功能来让优盘给电脑加速。

ReadyBoost最早在Vista系统中推出，原理是利用闪存随机读写及碎片文件读写上的优势来提高系统性能，这一功能是为了帮助内存插槽不足或限于资金不能增加内存的用户，让他们的平台可以小幅度提升随机读写性能。

![](../Images/f534b628cc0ec7bcdd457489ee09130d.png)

ReadyBoost占用的空间将不可用于文件存储（图片源自百度百科）

如果优盘具备USB 3.0速度或者标注支持ReadyBoost，就可以用于这个功能。在将优盘连接至电脑后，在弹出的对话框中选择“加速我的系统”，或在优盘的属性界面ReadyBoost选项卡中可以找到ReadyBoost功能。

![](../Images/222af0585719867d62f1c493b22b8526.png)

在ReadyBoost选项卡中设置空间（图片源自百度百科）

用户在这里可以选择用于ReadyBoost的空间，这些空间就不可用于文件存储了。如果用户的电脑运行速度足够快，也是不启用ReadyBoost功能的。

![](../Images/ccfa31d4cbe42ae35d08bdb49bdcd283.png)

运行速度足够快的计算机未启用ReadyBoost

需要注意的是，ReadyBoost是用来升随机读写性能的，并不能替代内存工作，同时提升的性能也有限，如果想要大幅提升整机的性能表现，增加内存是更加直接的方法。

把优盘当做开机的钥匙原理其实很简单，就是开机时识别优盘中的特定内容，如果没有检测到指定文件就用系统的自动关机关闭系统。

![](../Images/ad00e28a40fc207b76db0f4633ad04d8.png)

编辑批处理文件

首先需要创建一个后缀名为.bat的批处理文件，用记事本将其内容编辑为以下内容，也可以将内容放在txt文档中然后重命名为.bat后缀的文件。

if not exist E:zol.zol shutdown -s -t10 -c "警告：未检测到开机钥匙，系统将自动关机！"

其中10是10秒自动关机，我们可以自行改变秒数，引号中的内容是提示信息，这里也可以进行自定义。

![](../Images/7a56926012975a72628b2059dc5dda10.png)

在本地组策略编辑器中找到启动脚本

接下来按Windows徽标键+R或者在开始中找到运行，输入gpedit.msc之后点击确定。

在弹出的本地组策略编辑器中，从路径：计算机配置-Windows设置-脚本，选择启动项（启动/关机），把刚才保存的.bat添加到脚本列表中。

![](../Images/070ab384d61879bd803f7a793942cd66.png)

在启动中添加脚本

最后，还要在钥匙盘中新建一个zol.zol文件，这里的文件可以命名为自己喜欢的名字，但是一定要和之前.bat文件中的名字一样，这样以后开机就需要这个优盘连接在电脑上才能进入系统了。

![](../Images/d77a18a91f197955332eb9694e06b187.png)

没有钥匙盘无法开机

如果优盘不慎丢失或开机时不在身边，可以通过PE进入系统，删除保存的.bat文件即可。

优盘当做路由器其实是利用DD-WRT系统的功能来实现，实质上这是一个第三方的路由器固件，因为功能比较强大，所以被广泛应用在无线路由器上，我们将其刷到优盘中，便可以实现路由器的功能了。

![](../Images/3f56d1f17f57d90b54901de058df2199.png)

在命令提示符窗口找到优盘（图片源自优盘量产网）

首先需要下载DD-WRT及写入工具physdiskwrite，然后按Windows徽标键+R，输入CMD打开命令提示符窗口，执行命令：“physdiskwrite.exe-udd-wrt\_public\_vga.image”，程序会自动检测当前系统中的硬盘及移动存储设备，并显示出所有存储设备的序号及相关参数。

![](../Images/24b6e5475ccb41922b7ab9ce7c1baaaa.png)

在优盘中写入软件（图片源自优盘量产网）

![](../Images/733e33fe78a948d5e5d7c3237853410b.png)

确认写入优盘（图片源自优盘量产网）

在这里输入优盘的序号，一般情况下是序号最大的一个，不确定的话可以先拔掉优盘看一下不同硬盘的序号，输入之后点y就可以写入优盘了。

![](../Images/6169d3b0bf8035f8ad86d63fb3990e46.png)

写入优盘完成（图片源自优盘量产网）

在连接完成之后，DD-WRT会自动检测网络环境和硬盘设备，并自动进行网络设置，开始提供路由服务。在浏览器地址栏输入192.168.1.1，路由器的默认用户名为root，密码为admin,在进入页面之后选择administrator，将Language Selection设置为 Chinese Simplified即可将语言切换为中文。

有时候我们需要在其他电脑上运行一些程序，而这些电脑又没有程序或是设置不同，还是需要有自己的电脑系统，这里我们就可以借助优盘来完成了。

将优盘做成随身系统就是把操作系统直接写入优盘中，当用户从优盘启动时就可以直接进行互联网访问。

![](../Images/1aa907e51f56f9f2106c8878bc2a76f9.png)

用软件写入系统镜像

我们以Windows to go为例，将系统镜像写入优盘，方便以后使用，因为优盘速度会影响读写速度，所以这里我们建议大家选择USB 3.0的优盘来保证制作时间和系统的使用体验。

![](../Images/a45e1de09d46686cf8e16911da9a9e8e.png)

用软件写入系统镜像

写入完成之后，重启电脑就可以对这个随身系统进行个性化设置，真正开启自己的操作系统之旅，真的很方便。首先在BIOS里选择优盘启动，就进入加载过程。

![](../Images/adbcfa6663116f0946cb626bc26734fa.png)

准备在BIOS界面设置优盘启动

只需要简单几步就可以将系统设置完毕，这一点特别适合经常出差旅游的用户。平常就将自己常用的软件、资料存放在这个随身系统之中，出去的时候就不用带电脑，只要将优盘插入电脑就可以继续完成文件更新，相当方便。

![](../Images/f90ac0876cfcbb707c023f9a474f79bc.png)

系统设置要准备好

这些优盘的小技巧介绍到这里，最后我们提醒大家，在选用优盘的时候要优先挑选有品牌保障的，购买渠道也要看好，避免假冒伪劣商品，优盘有价数据无价，不要贪小便宜吃大亏。在使用的时候也要注意优盘避免进水磕碰，合理的保护还是非常有必要的。
