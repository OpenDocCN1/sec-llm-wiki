# 用户量大敢任性 Facebook日关百万账户

Facebook是全球用户量最大的社交软件，而相应的，其内容中所存在的问题也是非常多的。在全球的20亿用户中，难免会有用户违反其相应的政策，发布一些不符合规定的文字或视频。而Facebook的回应手段也十分强硬，他们每天因违规关停的账号超过百万个。

![](../Images/ea245ad6466cd05beff328099689880b.png)

Facebook首席安全官亚历克斯·斯塔莫斯（Alex Stamos）表示，如果要处理海量的互动信息，制定一套规则然后执行下去却不出错，这是不可能的。为了清理平台上的垃圾信息、欺诈信息和仇恨言论，每天Facebook关闭100多万个帐户。

斯塔莫斯表示，决定删除某个帖子并不是一部分人做出的决定。当仇恨言论的数量越多，误报也就会越多，要抓到谈论的人也会更难，更容易出错。斯塔莫斯表示，在各地运营时Facebook必须遵守100多个国家的法律。因此每天关闭的帐户达到7位数或者8位数，一些行骗者一次会注册几千个帐户。会后他向CNBC确认说每天关闭的数量超过100万。

Facebook CEO扎克伯格之前曾说过，公司准备再招募3000名员工审校并删除攻击性内容。斯塔莫斯指出，公司的招募工作还在继续，追踪威胁因素的团队正在扩张。尽管如此，斯塔莫斯相信工作不能只靠人力来完成，正因如此Facebook才会用人工智能软件判断发表内容的用户是不是合法用户。

Facebook拥有庞大的用户数量，这是一种幸运，也是一份责任，如何传播正能量并且保持不受各种危险言论的侵扰，在技术和手段上都需要强大的支持。
