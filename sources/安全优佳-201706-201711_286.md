# 支付宝因抄袭向微信道歉，然后微信出现了大面积故障

近日，移动支付的两大死对头，发生了一件有趣的事：支付宝向微信致歉，表示在小程序上直接复制了微信的示例。

  

神奇的是，**这个道歉刚刚被广大网友熟知，下午就发生了微信大面积故障的事。**

网友表示：看来，支付宝的道歉有毒啊！微信承受不起。

![](../Images/d7b749a7c04c4c8afb0a5b558c011c10.png)

事情的起因是，某科技号大V偶然发现，进入公测的支付宝小程序代码中，竟然出现了微信小程序团队开发者的名字。

  

事件发生后，支付宝知乎的官方账号在当晚发布道歉信，及时承认了错误，向微信道歉，并表示该团队已修改了这一部分的代码，不会在其他领域重现。

![](../Images/99b9c1573b0748b4b00ddf60384cde59.png)

令支付宝没有想到的是，这个举动并没有引来谩骂，**网友反而表示：腾讯一直抄袭，支付宝也无须道歉。**

![](../Images/4f58c3e5bc6dbf1927159a189f8227aa.png)

就在支付宝的道歉刷爆自媒体的时候，今天下午三点多，微信突然出现大面积故障，禁止各大内容平台将链接分享到微信，其中包括自己的 App 腾讯新闻等，转账功能也无法使用。

![](../Images/34b65cd3ca8db9eff074fe3d26ee9799.png)

大量网友表示，扫码半天无法支付，差点以为账号被盗了。随后，微信官方作出回应，称受影响部分正在逐步恢复中。
