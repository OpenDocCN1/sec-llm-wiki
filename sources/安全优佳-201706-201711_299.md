# 没有网络安全，就没有国家安全

——清朗网络空间 不做沉默的大多数  

随着信息技术的发展，虚拟网络世界已成为人类的另一块栖息地。中国作为世界上最大的网络市场，拥有超过人口半数的网民。根据中国互联网络信息中心（CNNIC）最新发布的第40次《中国互联网络发展状况统计报告》，截至2017年6月，我国网民规模达到7.51亿，互联网普及率为54.3%。然而，随着网民数量的提高，网络安全也随之迎来更大的威胁。2013年6月“棱镜门”事件曝光，联系到此前美国发布国家赛博空间安全战略；2017年4月，比特币勒索病毒席卷全球，威胁到多国的电信、快递、教育乃至医疗行业。网络安全面临的威胁小至个人信息泄露、资金外流，大至构成生命威胁、危害国家安全。由此可见，网络安全已经上升到了国家战略高度，没有网络安全就没有国家安全。

我是一名青年，我的成长和生活都是伴随着互联网的发展而发展，是典型的互联网原住民。同时，我是一名人民警察，从警4年，曾在基层派出所、特警和公安宣传舆情部门工作，接触大量互联网引发的案例。我发现现实生活中，除了黑客病毒入侵这些可防可控的隐患之外，网络舆论危机已然成为新时代的一颗隐形炸弹。与传统媒体相比，网络舆论具有多元化、隐蔽性、突发性、裂变性等新特点，又由于网民主体庞大，内容监测困难，信息传播范围广等因素影响，网络舆论成为一股难以控制的政治软力量。网络舆论战场的安全是网络战场安全的重要组成部分。当代中国，是一个人人都有麦克风的时代，是一个人人都渴望表达并且渴望着不沉默的时代。现在的很多网民，宁鸣而死，不默而生，在任何时间、任何地点都不想保持沉默。于是，只要网上哪个事有热度，或者哪个图有热度，很多网民先不管三七二十一，先发表一番言论再说。一个个义愤填膺，一个个充满所谓的“正义”。于是网上出了一副很搞笑又很具讽刺意味的图：两只大怪物，一只代表人云亦云的网民，一只代表无良媒体，他们在听到远处传来声响，人云亦云的网民问，发生什么事了？无良媒体回答，我也不知道，先骂了再说！这就是现在网络舆论环境的怪现象。如此畸形的发展趋势既丑化了政府形象，也削弱了执法部门的公信力，尤其对于基层公安执法，我更有感觉和说服力。现在只要公安民警一采取强制措施，被处罚对象或者嫌疑人家属马上拿出手机，并高喊“警察打人啦”，让警察不敢正常执法或者心有余悸，我亲身经历过，嫌疑人自己倒地并且往民警脚上滚，一边大喊“快来看啊，这就是人民警察”。再例如峰会期间网络疯传的秋水山庄对比图，让杭州举办峰会成了众矢之的，事实上，黄色的只是防腐层，青灰色才是主色。“庆安枪击事件”、“北京雷洋案”、“青岛大虾事件”、“山东聊城于欢刺死辱母者案”等等，这个过程出现的谣言、恶搞等等，无不在伤害我们网民。

习近平总书记在中共中央政治局第三十六次集体学习时强调，要正确处理安全和发展，要不断提高对互联网规律的把握能力、对网络舆论的引导能力、对信息化发展的驾驭能力、对网络安全的保障能力，把网络强国建设不断推向前进。作为一名人民警察，在现实生活中我要与违法犯罪分子作斗争；在网络舆论战场上，我更是响应号召，打压歪风邪气，弘扬网络正能量。作为个体，我所能做的就是利用微博、微信等传播正能量，坚决不做沉默的大多数。一时的力量固然有限，但日积月累传递累积的力量却不容小觑。

为了改变网上的不实、诽谤与恶意抹黑，我结合公安工作在微博实名注册微博@文艺泽，目前粉丝4万，月阅读量1000万，已成为有较大影响力的金V。与好友@亮剑共同发起创设和维护的#网络好故事#话题，两年时间阅读量已经超过3500万。2014年，为主策划拍摄的微电影《舌尖上的彭埠派出所》，网络点击超1000万；2016年，微电影《一封特殊的家书》登上新华社首页，使警察正面形象得到极大扩散和宣传。很多网友看完微电影之后第一句话就是：原来警察是这么辛苦！这是我看过最感动的警察微电影！这些事让我深刻体会：我们的网络是呼唤正能量的，怎样把正能量广为传播是我们应该思考和切实践行的。

我清晰记得习总书记“没有网络安全就没有国家安全”的号召。近五年来，我在另一个虚拟无声的网络战场进行着无畏战斗！真心觉得清朗网络环境、保障网络安全特别辛苦，很多时候，不是靠物质来支撑，而是靠信念和精神。网络舆论是把双刃剑，需要加以正确的引导和管理，只有这样，才能让安全的网络环境为国家的雄伟发展奠定基础。因此，冲在网络舆论第一线，肩负习近平总书记治国理正思想的责任是我们亟待完成的使命。我相信在我们不懈的坚持与努力下，定能在网络大潮中立身潮头，引领潮头，使网络舆论成为推进国家治理体系和治理能力的现代化进程的显著力量，让网络安全成为捍卫国家安全的重要屏障。
