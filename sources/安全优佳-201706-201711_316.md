# “匿名者”宣布接管新纳粹网站The Daily Stormer

据外媒报道，在上周维吉尼亚州夏洛特维尔市白人至上主义者集会以及随后在周末发生的暴力事件发生之后，新纳粹网站The Daily Stormer公开诋毁在这起暴力冲突事件中遇难的32岁的希瑟·海尔(Heather Heyer），当时有人开车冲撞抗议者人群造成其死亡。

![](../Images/eb10dc40ce0432a03d8a787750941b1a.png)

据外媒报道，现在黑客组织“匿名者”宣布已经接管了这个网站，并且已经发誓要在24小时后完全关闭这个网站。The Daily Stormer域名托管平台 GoDaddy也宣布,他们通知The Daily Stormer有24个小时时间将域名转交由其他服务商托管，因该网站“违反了我们的服务条款”。
