# 提升教育行业网络安全能力，打造CISM-JY培训认证体系

目前，我国教育改革和发展正面临着前所未有的机遇和挑战。以教育信息化带动教育现代化，破解制约我国教育发展的难题，促进教育的创新与变革，是加快从教育大国向教育强国迈进的重大战略抉择。

随着信息技术在教育行业的广泛应用和深度融合，教育行业网络与信息安全关系着教育信息化的稳步推进和教育事业的改革发展，教育行业信息系统及网站遭到挂马、植入暗链、页面遭篡改、数据被窃取等恶意攻击事件时有发生，网络与信息安全面临巨大威胁。

教育行业约有教育机构50万所，教师1800万名，在校学生2.6亿人。教育行业网络安全呈现出机构多、人员多、系统多、数据多、关注度高、影响面广的特点，面临的网络安全问题之复杂、难度之大是任何行业都无法比拟的，对相关岗位人员的信息安全保障技术能力和综合素质提出更高的要求，全面提高具有网络和信息系统管理经验和专业技能的人员从事网络与信息安全管理工作，建立网络与信息安全管理专职队伍和技术支撑专业队伍，落实岗位责任和考核机制，制定网络与信息安全管理和技术人员的培训规划，开展面向全员的普及性培训，加强网络与信息管理和技术人员的专业培训，逐步实行网络与信息安全管理和技术人员持证上岗在教育行业已经迫在眉睫。

为进一步贯彻落实习近平总书记指示精神和国家有关部门要求，加强网络与信息安全人才培养力度，全面提升网络与信息安全管理人员的技能水平，中国信息安全测评中心通过与教育行业的深入交流与探讨，结合教育行业网络和信息安全的行业需求，针对教育行业建立了国家注册信息安全员CISM-JY教育行业知识体系框，开展国家注册信息安全员CISM-JY教育行业专业培训。

2017年7月28日，北京市朝阳区现代教育技术信息网络中心在中国信息安全测评中心指导下，组织开展了国内首批国家注册信息安全员CISM-JY认证培训，来自朝阳区教育系统各单位的信息安全人员、部分骨干网管教师及运维单位技术人员共计50余人参加培训。

中国信息安全测评中心李淼在谈到课程体系设立的目的时说到：国家注册信息安全员CISM-JY教育行业知识体系框架结合教育行业网络与信息安全管理和技术特点，增加面向教育行业的专业课程知识体系内容，设立CISM-JY认证培训类型，根据中国信息安全测评中心CISM-JY的认证注册要求，通过考试并符合认证要求的学员，将获得中国信息安全测评中心颁发国家注册信息安全员CISM-JY教育资质证书。

![](../Images/c7d6747239946fffac6852435797423e.png)

朝阳区现代教育技术信息网络中心安全负责人李全增谈到：随着网络安全法的实施，信息安全工作重要性的日益凸显，教育系统面临的信息安全的形势日益严峻，从网站到核心数据安全保障层面，对通过网络安全培训提升全区信息安全保障能力的需求日益提升，此次培训结合教育行业特点，针对性强，满足了教育行业对网络安全工作的需求，为教育行业培养网络安全人才开辟了一条新路。

参加培训的网管教师谈到：作为单位网络安全管理员不仅担负着校园网的防护任务，也担负着学校网络信息安全宣传教育工作。通过此次培训，系统的学习了相关网络安全基本政策和知识，提高了网络安全意识，培养了技术能力，对实际工作具有指导意义，取得认证不是目的，回去后一定结合所学知识，在单位宣传贯彻网络安全法，保障教育教学网络的绿色安全。

上海汇哲信息科技有限公司承担此次认证培训工作，该公司是中国信息安全测评中心CISM-JY授权培训机构。公司具备丰富的信息安全、IT治理、IT审计、IT服务管理、项目管理等领域培训与服务经验，在谈到下一步如何更好地开展教育行业认证培训时，公司负责人余剑表示将继续完善教育行业培训认证体系内容，将培训从单一课程向多元化发展，开展线上培训、实操培训，结合教育行业特点普及网络安全知识，加强网络安全意识宣贯，开展系列网络安全培训活动，努力打造教育行业培训品牌。
