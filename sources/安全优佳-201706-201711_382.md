# 这个黑客团队两次远程攻破特斯拉系统！

特斯拉新款电动汽车Model 3将在太平洋时间7月28日举行交付，首批有30辆，就在Model3交付前夕，黑客们又来“搞事情“了。科恩实验室在2017年世界黑客大会分享了对特斯拉无物理接触远程攻击的过程，最终实现在驻车模式和行驶模式下对特斯拉任意远程操控。

![](../Images/1f16f40defae2b8c2892ba43c863a2b4.png)

这是科恩实验室第二次实现远程攻破特斯拉的系统，根据腾讯科恩实验室博客的文章，此次安全研究有四大亮点：

1.  实现了和2016年一样的完整攻击效果，最终入侵特斯拉车电网络实现任意远程操控。
    
2.  本次研究中在特斯拉多个模块发现0Day，目前科恩实验室正在和特斯拉及相关厂商协商漏洞的国际CVE编号。
    
3.  特斯拉为了提升车辆安全性，在2016年9月增加了“代码签名”安全机制，对所有FOTA升级固件进行强制完整性校验，本次研究突破了该“代码签名”机制。
    
4.  本次研究展示中的“特斯拉灯光秀”效果，涉及对特斯拉多个ECU的远程协同操控，体现了科恩实验室对车电网络中各ECU模块的安全研究能力。
    

科恩实验室已经将发现的所有安全漏洞技术细节报告给特斯拉美国产品安全团队，特斯拉在7月初通过FOTA推送了新的系统固件，修复了漏洞。视频展示中攻击涉及到的是8.1以下的系统漏洞，目前全球范围内绝大部分特斯拉车辆升级到新的系统，提高了安全性。

新发布的特斯拉Model 3自然是不会存在上述漏洞的，不过只要联网，就没有攻不破的系统。

作为互联网汽车的代表，特斯拉成为黑客们热衷研究的对象，特斯拉对于安全问题也格外关注。特斯拉CEO马斯克表示，只要有人坐在车里，人就需要拥有对车辆的绝对控制权限。一旦汽车自行做出一些古怪的操作，乘客只需按下某个按钮，即可完成对车辆的控制，并切断车辆与云端服务器的连接。

另外特斯拉还针对重要的子系统进行了加密，防止黑客在入侵之后完全控制动力总成或制动系统。

科恩实验室证实了特斯拉车机用的是Linux系统，而底层ECU系统采用了硬实时RTOS（Real-Time OS）系统，两者都被攻破。通常车机的系统是比较容易入侵的，可以控制车机内容、雨刷、天窗操作等，但底层的油门、刹车和方向盘属于关键控制对象，难以北攻破。

有分析认为科恩实验室展示的攻击并没有完全取得控制权，而是通过控制转向的空气助力以及刹车助力，即便如此，在高速行驶中，依然是非常危险的。

特斯拉展示的自动驾驶以及智能化特性为其增添了吸引力，但也带来潜在的风险。即便特斯拉对于安全问题高度重视，但一般车主们的安全意识并不高。虽然及时更新系统能确保安全性，但对比今年Windows系统中大规模爆发的漏洞，用户主动修复往往并不及时。

另外科恩视频中的灯光秀则与此前网络热门的“特斯拉秀车灯PK奥迪”视频”相似，多个特斯拉远程协同操作也是非常有意思的研究。

对比国内的互联网汽车项目，阿里、百度都推出了车联网平台，而未来汽车与互联网的联系更加紧密，安全性的问题也需要得到多方的重视。
