区块链近年来被越炒越热，它的身影频繁出现在各大头条，一时间也成为投资者的关注点。你可能对区块链这个名词感到陌生，但是如果提到比特币，你肯定不会陌生。没错，比特币的交易过程中，就使用了区块链技术。百度百科对于区块链的定义是这样的：区块链是一串使用密码学方法相关联产生的数据块，每一个数据块中包含了一次比特币网络交易的信息，用于验证其信息的有效性（防伪）和生成下一个区块。

简单点来说，区块链是一个公共数据库。数据被存储在被称作 “块”的容器中，完成这一过程中，块将被添加到链上，该链包含了过去产生的数据。这些数据可以是任何类型，对于比特币或者其他一些数字货币来说，该数据就是一组交易。

区块链技术带来了新的，完全数字化的货币，如比特币，莱特币。它们不是由中央机构发行或管理的。比特币也诞生了以太坊这种新型分布式计算技术，它引入了有趣的概念，如智能合同。

首先，我们要定义块的结构：在块链中，每个块都存储有时间戳和可选的索引。在SnakeCoin中，我们将同时存储两者。并且为了帮助确保整个块链的完整性，每个块将具有自识别散列。每个块的散列将是块的索引、时间戳、数据以及前一个块的哈希散列的加密散列。这点和比特币相似，当然，数据可以是任何类型。块的代码如下：

> import hashlib as hasher
> 
> class Block:
> 
> def \_\_init\_\_(self, index, timestamp, data, previous\_hash):
> 
> self.index = index
> 
> self.timestamp = timestamp
> 
> self.data = data
> 
> self.previous\_hash = previous\_hash
> 
> self.hash = self.hash\_block()
> 
> def hash\_block(self):
> 
> sha = hasher.sha256()
> 
> sha.update(str(self.index) +
> 
> str(self.timestamp) +
> 
> str(self.data) +
> 
> str(self.previous\_hash))
> 
> return sha.hexdigest()

接下来，我们需要定义一个函数来生成链上的后续块。该函数将链中的前一个块作为参数，创建要生成的块的数据，并返回具有其相应数据的新块。 当新块添加了先前块中的哈希信息时，块链的完整性随着每个新块的加入而增加。 如果我们不这样做，第三方很容易通过改写之前的数据改变整个链条。 这个哈希链作为加密证明，确保了一旦块被添加到块链中，它就不能被替换或删除。
