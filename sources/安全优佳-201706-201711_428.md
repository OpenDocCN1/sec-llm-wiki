# 微信聊天记录被删除，不用第三方软件这样恢复最简单

微信一方面便利了我们的工作和生活，一方面也保存了我们很多聊天记录，比如领导下达的工作重要指令、对象发来的甜蜜情话……有时候微信聊天记录需要保存备份，有什么办法能实现吗？

![](../Images/c7d11fa1ae9c41ed380c1bc6a414fe9e.png)

我们知道，微信删除了对话框、退出重新登录、卸载都会让聊天记录消失。如果要找回聊天记录，需要下载第三方软件才能找回来。在这里，其实不需要靠第三方软件，微信就能保存备份聊天记录哦。

手机电脑同步备份法

在同一个网络状态下，我们分别登录手机微信和电脑微信， 打开登录电脑版微信，最左下方的的三杠处，点击打开“备份与恢复”；

![](../Images/88b72673cbcef28674a2441b173f5c99.png)

页面会弹出“备份聊天记录至电脑”和“恢复聊天记录至手机”，选择“备份聊天记录至电脑”即可；

![](../Images/99cd0381f9b3c70e4dfc50e2eb76c1c0.png)

这时候，要回到手机微信，根据手机提示点击“选择聊天记录”，页面进入到对话框选项中，比如教授要备份与老板的聊天记录，点击“老板”，选择教授与老板7月14日的聊天记录；

![](../Images/7821873b0d2acd7ab9acdc2311b15294.png)

进行上面的操作后，手机开始备份。消息不多的，备份很快，如下图所示聊天记录已经备份到电脑上了。

![](../Images/0a976f510e76a847067df18728f6a84d.png)

在手机微信聊天记录备份到电脑成功以后，怎么把微信聊天记录恢复到手机微信上？我们可以先在微信上把聊天记录删除；

![](../Images/75ae3af7602f0806b373797203707898.png)

再来到电脑打开“备份与恢复”，选择“恢复聊天记录至手机”就可以；

![](../Images/bc07f6a53180707eecd75c5a53ed21bc.png)

等恢复完成后，打开聊天记录，发现被删除的记录又回来了，以下就是教授备份教授发给老板的消息。

![](../Images/c09063ce99ffd4931060dfac05ac6cea.png)

手机电脑同步备份法，步骤相对繁琐局限，因为你在删除或者清理微信消息前需要在电脑上备份，而且需要确保手机和电脑连接的是同一个网络。这里教授再给大家安利一个只用手机微信就能备份聊天记录的办法。

邮件或笔记法

如果我们在一个微信群里聊天，重要消息很容易被覆盖，而身边又没有电脑，可以通过邮件和笔记本的办法来备份聊天记录。

首先，点开微信聊天栏，长按聊天记录并点击“更多”；

![](../Images/bddc6e150aaf11e5d92eca4e547887ea.png)

勾选需要复制的聊天记录，点击聊天框右下角的三点按钮，然后选择“邮件发送”；

![](../Images/5c28703970eff12b3aeb9a887965b7df.png)

选择“邮件发送”的时候，前提是微信绑定了邮箱。到这里，我们点击“邮件发送”，可以发送到自己的邮箱，发送完成后，邮箱内容展示有时间、聊天人以及聊天记录，非常直观。

![](../Images/2261fe50e6d6880759d97929e2f8430b.png)

通过发送邮件的办法来备份保存微信聊天记录，方法简单，而且可以有选择性的去备份，一些没有保存需要的表情和简单日常对话就可以不用备份保存了。

![](../Images/59a6213666f9f1f105d5c689a8f840d2.png)
