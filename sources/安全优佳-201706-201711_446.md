# 北京移动4G网络大瘫痪！这解释你信吗？

12日一早，多位北京网友反映，北京移动出现大面积网络故障，具体表现包括没有信号、呼叫失败，无法接入4G网络等等，其中东二环到东四环区域最严重。由于事发早高峰阶段，不少人的出行都受到严重影响。

对此，北京移动官方今天下午做出官方回应：7月12日早8点45分，北京通州区、朝阳区及东城区部分区域因4G网络升级，导致客户无法使用4G网络。经过紧急修复，至9点30分网络恢复正常。

北京移动还表示，将认真核查，深挖原因，完善升级流程和应急措施，避免类似事件的发生，全力为广大客户提供更加优质的通信服务。

北京移动还特意将此声明刊登在了《北京日报》上，位于第10版的右下角。
