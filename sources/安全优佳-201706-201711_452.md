# 无线路由器都可以用来窃听，科技时代我们还有隐私可言吗？

现在的我们，无时无刻都离不开手机和网络。路由器就成了我们日常生活中非常重要的东西。

![](../Images/922b0a1aac8828d08823b367fe4e5877.png)

可是你知道吗，路由器可以用来窃听！

![](../Images/66ed5bc66b7a9b40eee32692b654be9d.png)

即使不对无线信号承载的数据本身进行解密，无线信号也能泄露我们的隐私，攻击者还能够利用它来实现密码或者重要文件之类的窃取。是不是觉得整个过程听起来非常神奇呢！简直就是黑科技嘛！

![](../Images/87eb7d6d7d3db423a59c3e284fab1e9c.png)

路由器还可以用来监视人类活动情况。当一个人在WiFi信号满格的空间内移动时，信号与人们身体之间接触并发生改变，甚至可以通过别的方向反射给其他人。通过这个现象，研究人员就可以利用它对人进行定位，可以看到一个人手指在空气中写了什么，一个人走路的步伐，甚至是一个人在房间中嘴唇蠕动的情况。简直太不可思议了！

![](../Images/8edfeeca0f0a67f2d38d3cf21935e302.png)

在科技越来越发达的今天，连无线路由器都是窃听神器。如果被别有用心的人进行利用，我们的隐私还能被保证吗？
