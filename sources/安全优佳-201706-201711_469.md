# OWASP 2017亚洲峰会研讨会圆满结束

2017年 7月7日，由OWASP中国主办、SecZone承办的OWASP 2017亚洲峰会研讨会在深圳东方银座美爵酒店举行，本次研讨会共有四场，分别针对金融及其应用领域、高校人才培养以及安全软件开发流程等展开讨论，邀请了各领域的资深专家进行深度交流与经验分享，共同探讨面对挑战的解决方案。

上午进行的金融专场研讨会邀请了OWASP中国海外联系人、大型企业安全专家钟卫林女士作为主讲嘉宾，以“大型企业应用安全方案”为主题，针对银行、证券等金融行业展开了一场生动且信息量丰富的行业技术研讨会。钟卫林女士从规模、复杂度、效率、效用与治理五个维度概括了企业面对的挑战，引起了各参会者的共鸣，随后分别从人、技术、流程三个核心要素出发，提出了“文化、资源、管理”相互结合的综合性解决方案，并就其中的具体问题进行了深度分析与详细的讨论。

![](../Images/70923179fef05c118485d8c20d4d8e45.png)

普华永道风险管理资深专家陈绍良先生担任金融专场下午研讨会的主讲嘉宾。陈绍良先生以“金融云隐私保护的挑战和应对”为主题，从云隐私保护的挑战与应对的角度探讨了金融领域中的信息安全风险问题。陈绍良先生从如何界定隐私数据的定义与范围出发，首先与大家探讨了云隐私的现状与特点，他表示，如果用最通俗的语言来概括隐私，那便是“个人数据保护+信息自决权”。随后分析了金融类企业在云计算环境中的主要业务类型及隐私数据的分布，引出了云隐私的主要风险和应对之道。最后从“确认事件、组件处理团队、内部粉笔、对外处理、后续处理”等五个环节与参会人员共同探讨了隐私泄露事件的处理流程，将研讨会的气氛推向了高潮。

![](../Images/b043d91065708abb95ed6e5c142abac3.png)

而“高校网络安全人才培养”研讨会，则由OWASP中国广西区域负责人王厚奎副教授作为主讲嘉宾，与来自电子科技大学、深圳大学、北京大学以及其他参会代表一起，共同讨论了高校网络安全人才培养中的特征与行业需求，针对如何突破高校网络安全人才培养“苦与痛”的现状分享了自己的实践经验与思考，并重点介绍了南宁职业技术学院与OWASP中国联合培养实用性网络安全人才的收获和感悟。王厚奎副教授认为，OWASP中国提供的网络安全人才培养材料、工具和方法，极大的提高了本学院网络安全人才培养的效率、扩展了本学院网络安全人才培养的思路、开拓了本学院网络安全人才培养的眼界。

![](../Images/7595d1ec5eae32e96013c18859f87ed9.png)

在下午研讨会中，OWASP中国主席RIP进行了OWASP Secure Software Development Life Cycle Project (OWASP软件安全开发生命周期项目，简称“OWASP S-SDLC项目”)在全球范围内的正式发布。该项目是OWASP组织首个由OWASP中国团队独立发布并主导的研究项目，并且已经聚集了来自微软、惠普、思科、亚马逊、Google、华为等全球知名企业的顶级安全专家。RIP在发布会上表示，OWASP中国组织诚挚邀请全球安全专家的共同参与，为软件安全、业务安全的体系化研究和技术实施进行深入研究与探讨。
