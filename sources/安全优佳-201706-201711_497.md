# 伦敦警方仍有18000台计算机运行Windows XP操作系统

尽管 Windows XP 从 2014 年期就终结了官方支持，但这并不意味着英国伦敦警察厅就基于更新到全新的操作系统。实际上，据外媒报道，当地警方仍有至少 1.8 万台计算机运行着老旧的 Windows XP 操作系统，占总共 32751 台计算机中的大半。尽管伦敦市长 Sadiq Khan 表示升级至受支持 Windows 的计划正在进行中，但并未给出一个明确的“截止日期”。

![](../Images/bfe85bd87aa782c65fc01613e2b66246.png)

对于大都会警局来说，此举并不让人感到意外。因为他们原本是计划在 2016 年 3 月份将所有计算机都升级到 Windows 8、辅以由微软提供的定制支持。

然而即使是这种过度政策，也遇到了障碍。保守的伦敦议会治安与犯罪新闻发言人 Steve O'Connell 解释称：

> 警方希望在新的袭击（比如 WannaCry 和 Petya）发生前进行升级，因其对过时的 Windows 系统构成了巨大的威胁。
> 
> 警方正在努力升级其软件，但在当前状态下，就像一条鱼在鲨鱼池里有用。在我们看到另一起影响全国安全的网络攻击前，调动资源去设置一个升级时间是至关重要的。

当前伦敦警方仅有 8 台运行被认为是最安全的 Windows 10 操作系统的计算机，而 Windows 8.1 则会在 2023 年停止获得安全补丁。
