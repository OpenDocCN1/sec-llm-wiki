# 研究人员：Petya勒索病毒新建一个只读文件就可免疫

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzcwMTU1Ng==&mid=2649518514&idx=2&sn=6b83c3a6a1393919916c1b735dee120a&chksm=8713d069b064597f309a1eea8147cba7b561b7d647381e9131fa599ed71f481acbbc9425eb6c&scene=126&sessionid=1681368272#rd](http://mp.weixin.qq.com/s?__biz=MzA3MzcwMTU1Ng==&mid=2649518514&idx=2&sn=6b83c3a6a1393919916c1b735dee120a&chksm=8713d069b064597f309a1eea8147cba7b561b7d647381e9131fa599ed71f481acbbc9425eb6c&scene=126&sessionid=1681368272#rd)

![](../Images/7b9a8b472e6a52f19e74e49193f2a4a9.png)点击上方“安全优佳” 可以订阅哦！

继 WannaCry 之后，利用 NSA“永恒之蓝”漏洞的新型 Petya 勒索软件再次引爆了网络。 据悉，Petya 会锁定磁盘的 MFT 和 MBR 区，导致计算机无法启动。除非受害者付费解锁（但目前并不推荐这么做），否则无法恢复他们的系统。

![](../Images/de1c1723832adab050a26773f21cad6d.png)

早前肆虐互联网的 WannaCry 有个“自杀开关”，但 Petya 却只能通过“疫苗”来预防。

Petya 爆发后，研究人员们蜂拥而上对其进行分析，而 Serper 率先发现 NotPetya 会搜索一个本地文件，如果磁盘上已经存在，勒索软件就会退出加密。

没过多久，这一发现就得到了 PT Security、TrustedSec、以及 Emsisoft 等安全研究机构的证实。这意味着用户可以在 PC 上创建一个只读文件，即可封锁 NotPetya 勒索软件的执行。

下面是 NotPetya“疫苗”的注射流程：

![](../Images/fd3199fe0e3900a747bcff7769dc6cb3.png)

（1）首先，在 Windows 资源管理器中配置“显示文件扩展名”（文件夹选项 -> 查看 -> 隐藏文件和文件夹 -> 显示隐藏的文件、文件夹和驱动器）；

![](../Images/52973866eb738d848eb4890f94088b0d.png)

（2）其次，打开 C:Windows文件夹，选中记事本（notepad.exe）程序，复制/粘贴一个它的副本。

![](../Images/61e8a0e385f98e087a351ec932aeff7d.png)

（3）执行该操作时，系统可能需要你赋予管理员权限。

![](../Images/9398a7e7ec60691b63c76e925986d683.png)

（4）继续后，按 F2 将 notepad（副本）.exe重命名为perfc。

![](../Images/bbb8e2d709532b142dd1d250c50c7529.png)

（5）确认变更文件夹和后缀名的操作，继续后 右键选中该文件，点击属性。

![](../Images/2984d1d2efbe28632cf57f6763990792.png)

（6）在弹出的文件属性对话框中，将其设置为 只读。

![](../Images/1027da82422117148747ddfd61a5d31d.png)

（7）设置完成后，点击 应用。

完成上述操作后，你的计算机应该就可以免疫 NotPetya / SortaPetya / Petya 类勒索软件了。
