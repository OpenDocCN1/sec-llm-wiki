# iPhone X「人脸识别」有漏洞，苹果这份内部文件透露了真相

Face ID 是 iPhone X 上最大的亮点之一，然而从 iPhone X 发售以来，就有用户反馈 Face ID 导致 iPhone X 后置摄像头不可用的问题。

此前部分用户在 Reddit 上反馈 iPhone X 的 Face ID 和后置摄像头常常一起故障，一名用户指出后置像头除了全景、慢镜头和延时摄影外的功能都不可用，同时 Face ID 会弹出「Face ID 号码不可用」的提示。

![](../Images/91cd37a8336acd0d50372afb091d2818.png)

（图自：Los Angeles Times）

最近苹果在提供给 Apple Store 和授权服务商的内部文件中，给出了针对这种问题的维修建议，也间接透露了 Face ID 出现 Bug 的原因。

![](../Images/c23010afaf3d43f5e857c3a226fca0ca.png)

（Face ID 设置界面）

根据这份内部文件，当遇到 Face ID 导致的故障，苹果零售店和授权服务商的服务人员应该先对 iPhone X 的后置摄像头进行检测，必要时修复系统。如果这样依然不能解决问题，那就应该给客户更换新机，而不是对显示器进行维修。

来看看文件原文是怎么说的：

> 为了提供最佳的客户体验，如果客户报告他们的 iPhone X 存在 Face ID 问题，您可以通过后置摄像头修理解决问题。
> 
> 在客户的设备上运行 AST 2 以检查相机。如果诊断程序发现相机存在问题，请执行修复以查看问题是否已解决。如果问题未得到解决，请执行整个设备更换，而不是同一台设备的显示器修理。

其实去年更新的 iOS 11.2 也曾导致部分 iPhone X 的 Face ID 出现故障，不过这次问题可能不太一样。

![](../Images/ba50f676ba629a5787dc069a61e9bae1.png)

根据部分用户向Genius Bar 员工的咨询， Face ID 所用的 TrueDepth 摄像头和后置的长焦摄像头是相互连接的，因此 Face ID 的 Bug 和后置摄像头的故障似乎存在某种联系， 不过目前尚不清楚具体的原因。

![](../Images/726d16830d19e272a0d534740685261d.png)

除了这份被曝光的文件，苹果也还未就此事公开作出回应，以及公开发布任何相关维修计划。

此前 Face ID 的一些问题也曾让用户担忧，不过主要集中在安全和隐私方面。去年11 月一家越南安全公司 Bkav 称利用自制的 3D 面具成功破解了 iPhone X 的面容 ID，还有多家媒体测试了 Face ID 能否识别双胞胎，得出的结论也各有不同。

  

![](../Images/51981ba627a24b4a5a0d48366746abae.png)

  

为了打消用户的疑虑，苹果还专门发布一份「白皮书」来解释面部识别的技术安全问题，文件中指出「人群中随机抽取一个人，看着你的 iPhone X 就能使用 Face ID 解锁的可能性为百万分之一（Touch ID 这一概率为五万分之一）。」  

![](../Images/f87374e2255d889b35c3658b0a5b2f33.png)

不过比起极低概率的 Face ID 破解，Face ID 和后置摄影头双双不可用给用户带来的困扰会更大，不知道苹果是否也会发布相关的技术报告来解释这一故障。  

如果你是 iPhone X 用户，是否也出现过 Face ID 故障的情况呢？
