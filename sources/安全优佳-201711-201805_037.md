# 几种加密数字货币中发现拒绝支付漏洞，黑客可以花光你的币

一个学术团队在Zerocoin协议中发现了一个安全漏洞，同时在libzerocoin库中发现两个安全漏洞，这是基于Zerocoin协议生成实际加密货币的开发库。  

研究人员表示，他们发现这三个问题在不同程度上影响至少5个基于Zerocoin的加密货币，这五个加密货币是SmartCash、Zoin、Zcoin、Hexxcoin和PIVX。

来自萨尔大学和德国弗里德里希 - 亚历山大大学纽伦堡 - 埃朗根大学的四人团队已经将他们的研究成果发表在题为《Burning Zerocoins for Fun and for Profit》的研究论文中。

**拒绝支付漏洞**

研究人员称，Zerocoin协议受到拒绝支付问题的影响，允许攻击者停止受害者的正常交易，并在正常请求之前发出“支付”操作，结果攻击者的“支付”操作被执行而正常的交易被拒绝 - 这被标记为“双重支付”漏洞。

研究人员表示，该协议漏洞影响SmartCash、Zoin、Zcoin、Hexxcoin和PIVX。这五个中间的三个-PIVX、SmartCash和Hexxcoin在发现此问题后，在其各自的加密货币源代码中禁用了Zerocoin协议。

直接结果是，所有通过Zerocoin协议开发的山寨币使用户的钱包存在一个坑。

SmartCash团队告诉研究人员，他们打算向所有者退还未使用的币，而Hexxcoin和PIVX团队表示他们计划在问题解决后重新启用Zerocoin支持。

研究人员表示，Zoin和Zcoin在Zerocoin协议问题上仍然存在漏洞，并建议用户暂时不要去使用支付操作，直到他们发现的问题得到修复，一般要利用这个漏洞需要攻击者获得网络位置并拦截受害者的“支付”交易。

**两个libzerocoin漏洞**

除了协议本身的问题外，学者们还发现了两个影响libzerocoin的漏洞，一个是用于实现Zerocoin协议的C++库。

在这里，研究人员发现了一个允许攻击者生成新币的“inflation” 漏洞，以及库对交易的没有正确签名的漏洞。

这两个漏洞影响Zcoin、SmartCash、Zoin和Hexxcoin，但研究人员称，这些漏洞在初次报告后得到了修复。

**源于Zerocoin是一个老的协议**

所有这三个问题都不奇怪，因为Zerocoin协议和libzerocoin库已经死了多年。

Zerocoin协议已被Zerocash协议所取代，Zerocash协议现在被Zcash加密货币支持，并已将其纳入Zoin、Zcoin、SmartCash和Hexxacoin项目，而libzerocoin库已被放弃，其README文件中多年来一直都有大量安全警告。

学术团队建议，不要使用过时的技术，不要使用带有大量安全警告的开发库。
