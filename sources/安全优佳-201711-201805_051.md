# 苹果Touch ID 遭韩国企业控告侵犯专利权

苹果一直被多间公司控告侵犯其专利，而最新的一单，是用于iPhone、iPad 上为主机解锁以及电子支付使用的指纹辨识系统，原告者是一间韩国企业。

![](../Images/fed794d6a18e2af3bd4abb96937a8e4b.png)

根据韩国网媒《TheInvestor》报道，韩国流动网路相关的初创企业Firstface 入禀法院，控告苹果侵犯其结合Home 按键与指纹辨识系统，在用户解锁之后直接返回Home 画面的专利。Firstface 指在2011 年在韩国、日本与美国等多个国家都有申请专利。

Firstface 公司共同CEO Shim Young-tack 指出，「以用户指纹认证来打开智能手机画面的解决方案，在Jung Jae-lark（同公司另一名共同CEO）发明之前是没有人使用过的。」另外他指出当初曾联络苹果，探讨是否能进行某种形式的合作，但遭到拒绝。

韩国报章《BusinessKorea》指这间公司以往亦曾经同Samsung 等公司展开过专利权诉讼案件。另指出Firstface 亦持有脸部辨识解锁后直接返回Home 的专利，因此稍后该公司有可能因「Face ID」再次对苹果提出诉讼。
