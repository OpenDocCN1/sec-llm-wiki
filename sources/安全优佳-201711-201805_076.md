# 用手机摄像头就能进行3D混合现实社交？迈吉客获盛景集团数千万追加投资

3月28日，迈吉客科技（AppMagics）首次对外公开继A+轮完成后再获母基金盛景追投数千万。本次融资主要用于加速旗下混合现实产品的落地，以及自主研发的Magic Engine混合现实引擎的技术提升与优化。

迈吉客科技是一家专注于计算机视觉三维混合现实技术的公司，其开发的核心产品为Magic Engine魔法引擎。这款引擎可以利用摄像头捕捉人脸或人身整体的结构，通过算法分析表情和动作，赋予到虚拟形象上，以达成真人之间的虚拟形象社交。

这种虚拟社交模式可用于多个领域，截至目前，迈吉客合作伙伴覆盖社交/直播平台、智能设备厂商、广电影视传媒和动漫IP游戏等相关领域。

![](../Images/dfab896ab41a9f35e1c5a612e43b9512.png)

迈吉客创始人CEO伏英娜认为，人类想象力是发散性的，而传统视觉内容更偏重线性。例如，在互联网时代下的教育领域，催生出许多视频教育产品，但这样的教育方式只是改变了内容传播的途径。迈吉客的理念是将混合现实技术加入到教育的过程中，使一位现实中的老师脱离物理范畴成为虚拟形象，

在互联网教育领域，迈吉客的理念是将混合现实技术加入到教育的过程中，使一位现实中的老师脱离物理存在成为虚拟形象，寓教于乐地传播知识和跨时空互动。更加有趣的内容生产和传播方式，会提高教育本身的效率，提高学生对于知识的兴趣。除了教育领域，娱乐与社交之于混合现实现实也是一片蓝海。

迈吉客希望利用其自主开发的Magics Engine混合现实魔法引擎，将AI+CG与人结合，让虚拟人物的形象、性格不再是程序所赋予的，而是每个真实的人所“扮演”的，成为其进入数字世界的载体和化身。伏英娜表示，在美国微软工作期间，她便痴迷于如何打破传统的视觉方式并打破“次元壁”，于是2014年回国后创办了迈吉客科技，致力于融合虚拟和显示，创造技术驱动的实时混合现实内容生产和互动平台。

迈吉客团队创立初期主要在产品研发上进行投入。不同于苹果iPhone X基于深感摄像头技术开发出Animoji表情，迈吉客团队克服了目前绝大多数移动设备不具备深度感应能力的困难，利用算法使普通手机的前置摄像头也可以完成人脸表情识别，并赋予3D表情或人物使传统视频社交更加多元化。

降低混合现实社交化的消费门槛是迈吉客产品落地的基础和愿景，融资发布会开场，伏英娜就以二次元虚拟主持人娜娜的形象出现并表示，迈吉客未来将会通过Magic Engine引擎为每个人“穿”上二次元的形象，让互联网社交更有趣。

相关数据表明，2017年中国泛二次元用户达3亿人，市场规模达到了1500亿。迈吉客希望通过全新的混合现实场景，将传统的影视动画、CV、CG技术消费化，使更多互联网用户能够通过旗下的Magics Engine混合现实引擎，扩展自己的社交方式。

伏英娜告诉36氪，迈吉客希望利用沉淀IP价值的方式达成今年项目落地以及盈利的目标。此前，公司已与“泰迪”珍藏系列动漫IP展开合作，将混合现实产品通过卡通形象应用到内容生产和游戏直播中，同时也在寻求与其他大流量IP主播的合作。

目前，迈吉客的优势在于识别精度高、技术实现能力强，已有多家合作伙伴在产品中加入或使用迈吉客的Magics引擎和所定制的内容或虚拟人物，未来迈吉客还将以技术驱动的裂变方式与文娱、广告、教育等领域的公司展开深度合作。
