# WiFi万能匙存在重大安全隐患 强制共享你的密码！

智能手机和无线路由器的普及无疑方便了我们的生活，也使得我们的生活越来越离不开网络。近些年来一款可以直接 “破解” 国内各地的 WiFi 蹭网应用 —— WiFi 万能匙因此而受到热捧，他们都抱着贪小便宜的心理打算能够一直靠免费蹭网来解决自己的上网问题，但事实上，这种 “WiFi 万能匙” 都存在着重大的安全隐患。

![](../Images/bca5830313225e292d4fce70a8a417ad.png)

今天就有国家权威媒体直接点名批评，因为这款应用的泛滥导致了很多国家机关和金融机构的 WiFi 密码被盗，用户数据根本就连基本的安全保证都没有。

![](../Images/4d26e4e48a44edac0d7b2127019ed174.png)

那为什么 WiFi 万能匙这种流氓软件就能这么神地 “破解” 大部分无线网络呢？其实这款应用根本没有什么所谓的解密算法，纯粹是靠强制性地 “共享” 了你的 WiFi 密码。因为 WiFi 万能匙这类应用会默认把你连接过的 WiFi 密码上传到他们的服务器上，也就意味着在这些国家机关单位、重要金钩机构的工作人员里面只要有其中一个员工安装了 WiFi 万能匙，那么基本上这些不对外接入的 WiFi 网络都会被安装了 WiFi 万能匙的用户直接连上。家用 WiFi 也是一个道理，只要家里人任何一个人安装了这些软件，你们家的 WiFi 密码就等于写出来黏在大门上让人随便用一样。

![](../Images/ff42a14abcef6ef4ba39d6900eb7c732.png)

如果不想被强制分享你的 WiFi 密码？那就要到这个应用里面申请取消热点分享，但明明是自己家的 WiFi 想要取消分享还要让这个应用审核通过之后才能取消，可谓相当流氓。

很多人以为分享自己的网络没什么所谓，如果只是让自己的亲友上网当然没问题，但遇到一些别有用心的人、而你又没有更改路由器登录账号和密码的话，那么他大可以通过这个软件监控你的路由器，监控你在网络上的一举一动，甚至能看到你私密应用的密码。所以使用这款应用，会导致非常严重的个人信息安全危害。

如果想完全杜绝这种流氓应用，最好的方式就是从自己做起，坚决抵制这种流氓应用，不下载、不使用，之前安装过的也赶紧卸载，并更改一次自己的 WiFi 密码。

WiFi 万能匙这么流氓的应用，你还敢用吗？
