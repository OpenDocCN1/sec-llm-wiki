# 路由器暗藏间谍 被收集信息还变成肉鸡

黑客对于家中路由器的攻击事件，呈现越来越严重的态势。并且通过路由器可以控制家中的摄像头、手机等联网设备，还可以使这些设备变成黑客的肉鸡。卡巴斯基实验室的安全研究人员发现了一种复杂的网络威胁，这一威胁存在于中东和非洲的网络中，从2012年就开始存在，知道2018年2月份才被发现。

![](../Images/ef4be9700d2e786e7d5d257618e453b9.png)

**从路由器发起攻击越来越频繁**

该恶意软件被安全研究人员称之为“Slingshot”，通过攻击路由器并获取路由器的控制权，进一步控制连接路由器的其它设备。安全研究人员表示，“Slingshot”的许多攻击技术都是独一无二的。它能够隐蔽的收集被攻击者的桌面截屏、键盘数据、网络数据、密码、usb连接、剪贴板数据等。

![](../Images/8a64058f08ca3850a075baf78becf730.png)

**Slingshot主要攻击中东和非洲地区**

这样的“全能”表现让安全人员称，“Slingshot”是一个复杂的威胁，它使用了各种各样的工具盒技术，还拥有迄今为止最先进的内核模式模块。如此有威胁的恶意软件，竟然存在了6年多的时间，令人非常震惊。很多人都是通过路由器感染到此恶意软件，最初黑客是如何攻击路由器的目前还不得而知。

![](../Images/2ee3cc2e4ed8c4b703bdadb40ef7fccb.png)

**黑客无处不在**

截止到目前，安全研究人员对100名受害者进行了分析。发现这些被攻击者主要位于位于肯尼亚、也门、阿富汗、利比亚、刚果、约旦、土耳其、伊拉克、苏丹、索马里和坦桑尼亚。而且大多数的受害者都是个人，对于政府组织和机构的攻击目前出现在肯尼亚和也门地区。
