# 手机丢了 支付宝还登着怎么办？赶紧采取这3个方法，减少损失！

想必大家听过了那么多丢手机的事情，偶尔也会担心一下万一自己的手机突然丢了，那放支付宝/微信里的钱该怎么办呢？今天我们就先来说说支付宝里的钱在手机丢失时第一时间该如何操作。

![](../Images/92cbe8fde98f47afecab3971e432852b.png)

**1.挂失手机号码**

![](../Images/32c3d7dc370abaf80b7d8f35739f7246.png)

**2.用别的手机登录支付宝账号，**登录成功后可将余额转出到银行卡，接着将银行卡解绑，挂失账号或直接注销账号即可（步骤：我的-设置-安全中心）  

若无法登陆，则赶紧拨打支付宝客服电话，在客服的帮助下注销被盗账号。

![](../Images/d81be875792e435aa965c2f7d82a3cc6.png)

**3.修改淘宝密码，**现在支付宝和淘宝都是绑定着的，为了以防盗刷花呗账户余额之类的操作，原来的淘宝账号也需要另行重置密码。

![](../Images/81513b37d2ce4ca47147b65f1bd89155.png)

最后，希望大家不仅为手机设密码，支付宝里也最好开启指纹验证，APP密码，关闭小额免密支付等等操作，确保账户财产更加安全。

![](../Images/4011768daa5becfd1c35df2478d150bb.png)
