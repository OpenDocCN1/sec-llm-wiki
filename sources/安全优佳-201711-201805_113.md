**0x01 准备工作**

需要安装：Git Bash ，Python 3 

https://git-scm.com/download/win 

Git Bash 

https://www.python.org/downloads/windows/ 

Python 3

Windows 10 操作系统

首先需要安装Git bash和Python 3，其实Git bash 并不是必须的，安装Git bash是为了Git clone方便，不用下载Zip包。 

Python 3是必须要安装的。

**0x02 安装Kali Linux子系统**

首先使用管理员权限打开一个Powershell。 

![](../Images/9a42e8f020d60375ec2ac49118c56e11.png)

然后输入

![](../Images/8f091389f05ab10f8ce5340ceba8cec6.png)

Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux

![](../Images/8d2148fdd018d92d095f8c728fb3858c.png)

执行完后会提示，是否重启系统，默认是重启，我们直接回车重启即可。   

![](../Images/725f0fde035fcc01aab54c44207d4b44.png)

重启完后，打开一个CMD执行

![](../Images/8f091389f05ab10f8ce5340ceba8cec6.png)

lxrun /install

![](../Images/e8a801f2f4e9769406766d213abab53c.png)

直接输入y即可继续安装。   

![](../Images/57b60e3af32399f308ef3ac0178324fe.png)

然后会提示我们输入系统用户名，我们随意填写，我写的root。 

![](../Images/08683410f3e116ad4b684ecc5d6e7e4b.png)

然后打开Git Bash 下载WSL-Distribution-Switcher

![](../Images/8f091389f05ab10f8ce5340ceba8cec6.png)

git clone https://github.com/RoliSoft/WSL-Distribution-Switcher.git

![](../Images/a471eac58103cf434a4698eaa75f7eae.png)

或者是去下载Zip包。   

然后CD到WSL-Distribution-Switcher目录

![](../Images/8f091389f05ab10f8ce5340ceba8cec6.png)

cd WSL-Distribution-Switcher

执行  

![](../Images/8f091389f05ab10f8ce5340ceba8cec6.png)

python get-prebuilt.py kalilinux/kali-linux-docker

![](../Images/b2b4192c693639bcbbb29c5e481752c5.png)

来下载kali-linux-docker的系统文件。   

如果爆了ssl的错误。 

![](../Images/6a316d31e65c4826ed02ca149eecde88.png)

编辑get-prebuilt.py文件头部加入

![](../Images/8f091389f05ab10f8ce5340ceba8cec6.png)

1.import ssl

2.ssl.\_create\_default\_https\_context = ssl.\_create\_unverified\_context

这两行来忽略SSL错误。顺便检查一下网络是否遭到劫持。 

![](../Images/d0be065b04069b98beac280a24afcb8f.png)

![](../Images/d822b1c6a52919fa12549f60ff33dafe.png)

然后执行

![](../Images/8f091389f05ab10f8ce5340ceba8cec6.png)

python install.py rootfs\_kalilinux\_kali-linux-docker\_latest.tar.gz

来安装刚才下载的kali-linux-docker 

![](../Images/af049f234b51f5f8cfecb86ee2d93d75.png)

然后执行

![](../Images/8f091389f05ab10f8ce5340ceba8cec6.png)

lxrun /setdefaultuser root

![](../Images/cffec6bf21c760ad97eebcc933a7dec5.png)

执行完后关闭Git Bash，打开powershell，执行Bash。  

![](../Images/8f091389f05ab10f8ce5340ceba8cec6.png)

1.bash

2.export

然后就进入了我们的kali——Linux子系统，但是系统默认的DNS不对。我们需要修改他的DNS配置。 

我换为了114的DNS。 

可以使用vi来编辑配置文件，也可以echo一个到配置文件。

![](../Images/8f091389f05ab10f8ce5340ceba8cec6.png)

echo "nameserver 114.114.114.114" > /etc/resolv.conf

  

![](../Images/44b6f8ac1a3471d785ed7eec2798784d.png)

然后执行

![](../Images/8f091389f05ab10f8ce5340ceba8cec6.png)

1.apt-get update

2.apt-get dist-upgrade

![](../Images/068c6c4a8a1d370e17b784e645a6e784.png)

这个时候系统已经安装完毕了。   

![](../Images/33e43608220e806dffddd7644f42ab23.png)

但是很多工具都没有，如果我们需要完整的Kali的话，需要编辑apt源。 

改成这样

![](../Images/8f091389f05ab10f8ce5340ceba8cec6.png)

deb http://http.kali.org/kali kali-rolling main non-free contrib

然后

![](../Images/8f091389f05ab10f8ce5340ceba8cec6.png)

1.apt-get update

2.apt-get install kali-linux-full

即可安装完整的kali\_Linux
