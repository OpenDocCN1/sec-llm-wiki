# 魔高一尺 智能技术加持信用卡信息盗取更便捷

据美国科技网站Fox4kc报道称,黑客组织借助全新的智能技术在某种情况下甚至能够不碰你钱包就能盗取你信用卡的信息。

“那些人走到我的身后,在不知不觉中偷走了我的信用卡信息,这简直让我胆战心惊。”一起发生在密苏里州堪萨斯城信用卡欺诈案的受害者Frank Sereno说。周五,Sereno参观了位于72号街附近的QuikTrip后,被告知他的账户存在欺诈指控。Sereno说,“当我和骗子通电话时,他们干了这个事情。”![](../Images/9a25373273893f567e175ca0a90673c1.png)

有人攻破了Sereno的账户安全密码,并在加利福尼亚州的餐馆和商店消费购物。“不,这些消费都不是我做的,我还没有在堪萨斯城以外的地方用过我的卡。” Sereno对执法者说。

巧合的是,Sereno在网上也看到过类似的同样发生在堪萨斯城事件的报道。和Sereno一样,技术人员都没有在受害人正常刷卡消费的终端上找到信息盗取设备。这名技术人员认为,也许是有人使用了一种全新类型的信息盗取设备,偷走了受害者的信用卡信息。

“便携式信用卡信息回收器可以使用一种类似于我们在NFC设备上使用的技术,”位于堪萨斯城北部的安全设备公司的区域主管Ryan Mckeel说。“一些黑客实际上是在我们利用手机使用NFC技术时靠近我们,利用他们手中的设备够读取我们正常交易时产生的数据,以盗取绑定在一起的信用卡交易信息。”在实施犯罪的过程中,犯罪分子只需要离你几英寸远就可以读取相关数据,而根本不需要与你产生任何的身体接触。

Mckeel建议为保护自己的信息安全,应使用专业的屏蔽钱包。“与普通钱包相比,屏蔽钱包有一个金属层,可以防止无线通讯信号穿透你的钱包读取信用卡信息,”Mckeel说。“另一种简便的保护方法是在你的钱包里放一张锡纸,能起到一定的保护作用。”
