# 下载必须的模块文件  

前提：安装了Python并配置了环境变量

1\. 需要的模块

*   cx\_Oracle 用来连接数据库的
    
*   xlrd 用来打开execl文件，操纵execl文件的
    
*   xlwt
    

可以从网上下载

2\. 将下载到的压缩文件拷到Python的根目录下，并解压。

3\. 进入解压文件中，在图中的路径进入命令行

![](../Images/4a6d14bea013df7af527931a0ea2a664.png)

4\. 执行python setup.py install
