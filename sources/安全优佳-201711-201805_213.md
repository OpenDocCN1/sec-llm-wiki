# 英特尔已为90%的处理器推出安全更新固件

为了应对近期曝出的处理器底层安全漏洞，各大芯片厂商、系统提供商携手通过固件更新迅速弥补漏洞。

本周，英特尔宣布其已经为过去五年里发布的超过九成的不同型号处理器发布了相应固件更新，以应对可能因Meltdown和Spectre漏洞造成的用户数据泄露问题。同时英特尔表示，关于更新补丁带来的性能损耗并不像此前媒体报道的那样会达到30%之所，对于普通用户来说，安全更新补丁对整体性能的影响大概在0~2%左右，因此无需担心因更新固件而带来的性能损耗。

![](../Images/52dd73928432940da1e844fb59bc88a9.png)

本次安全漏洞最初由英特尔处理器曝出，但随后包括AMD、ARM、苹果等在内的厂商纷纷宣布自己处理器同样会受到漏洞的影响。进而使这一次漏洞事件上升为整个芯片行业的行业性事件。而近期，各大厂商已经开始通过各类固件更新来弥补漏洞。

此外，截至目前为止，全球范围内也并未有一个真正被利用漏洞而攻击的案例，因此对于这次的处理器底层漏洞事件，总体来说是芯片产业对抗硬件漏洞的一次胜利。
