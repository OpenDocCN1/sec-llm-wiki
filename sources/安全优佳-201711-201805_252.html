虽然这次漏洞大量电脑手机受到影响，但各个科技巨头修复起来效率还是很高的。

昨天有消息称，英特尔 CPU 存在严重的安全漏洞，而修复这些漏洞会有大幅降低 CPU 性能的隐患，那么采用了英特尔 CPU 的 Mac 产品会不会也受到影响呢？据外媒报道，苹果在去年12月份发布的 macOS 10.13.2 中，至少部分修正了英特尔芯片中的缺陷。

我们先来回顾一下这个漏洞事件，英特尔 CPU 在近日爆出巨大安全隐患，黑客能够通过该漏洞到 PC、Mac 的系统核心来获取用户数据。更加让人头疼的是，这个漏洞其实是可以修复的，但是代价却是补丁可能导致 PC 和 Mac 出现性能下降，下降幅度在 5%-30% 之间。所以在收到这一消息之后，不少媒体都开始测试相关机型，AppleInsider 就是其中之一。

根据开发人员 Alex Ionescu 的说法，苹果在12月6日发布的 macOS 10.13.2 中对大部分的内核安全漏洞进行了修复，在他的测试中，与运行 macOS High Sierra 10.13.1 的机型相比，运行 10.13.2 时系统性能没有明显下降，并且苹果还将在 10.13.3 版本中提供更多补丁软件。这一说法也得到了部分苹果内部人士的证实，他们表示，苹果能够迅速反应和他们过去10多年来部署的安全措施有关，但是这些措施也并不能100%堵上英特尔的这一漏洞，所以还需要更多后续补丁。

不过这件事情今天已经完全不限于在 Windows 和 Mac 阵营中发酵了，今天英特尔就此事发表了一个声明，他们表示 AMD 和 ARM 处理器其实也存在着同样的问题，这意味着几乎所有的 PC 和 Mac ，还有安卓手机或许都暴露在漏洞之下，而英特尔也正在与其他科技公司紧密合作，制定全行业解决方案来攻克问题。

截至本文发稿，Mac 在前文已经介绍了修复方案， 微软称 Windows 10 Beta 版本已经在去年底修复这一问题，今天更新的 KB4056892 正式版将强制用户更新，亚马逊表示而谷歌也表示他们已经修复了问题。考虑到不久之前才爆出过 Intel ME 全球范围的漏洞，现在又来一个，看来英特尔真得好好面壁思过了。
