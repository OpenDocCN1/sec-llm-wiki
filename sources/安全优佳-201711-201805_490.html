根据路透社的报道，美国公民自由联盟（ACLU）和民主与技术中心（CDT）今天对苹果在面部扫描方面如何“有效”地执行某些隐私规定提出了质疑。iPhone X 的面部识别能力再次被认为是隐私问题的核心。

具体而言，隐私保护组织担心的是，一些试图通过新智能手机的面部软件创建娱乐功能的开发者会从 iPhone X 上提取某些面部数据。用于解锁 iPhone X 的面部数据，或与“人脸识别”相关的数据被安全存储在设备本身，而不是存储在 iCloud 中。

不过，根据路透社公布的一份合同条款显示，苹果将允许开发者从用户的 iPhone 中提取特定的面部数据，“只要他们寻求客户的许可，而不是将数据卖给第三方”。这意味着，想要使用 iPhone X 前置摄像头的开发者可以获得一张用户面部的“粗略地图”，以及“超过 50 种面部表情的数据”。

开发者可以收集到的数据（可以存储在开发者自己的服务器上）据说可以帮助监控用户眨眼、微笑，甚至是扬起眉毛的频率。尽管这一数据无法解锁 iPhone X，但根据向安全研究人员发送的 Face ID 文件显示，开发者可以“相对容易”地获得部分用户面部数据，并将其添加到自己的服务器上，这导致了 ACLU 和 CDT 今天提出的新担忧。

ACLU 高级政策分析师杰伊·斯坦利表示，在解锁一部智能手机的背景下，围绕人脸识别的隐私问题“被夸大了”。斯坦利解释说，“真正的隐私问题与第三方开发者的访问有关。”在这种情况下，有关人脸识别的专家们也不担心“政府窥探”，而是更多地关注那些追踪用户的表情如何对他们的广告做出反应的营销人员和广告商。

苹果对使用面部数据进行广告和营销的开发者采取了严格的政策，但相关团体表示，他们担心该公司“无法控制应用开发者在离开 iPhone X 之后会做什么。”斯坦利表示，对于苹果来说，“困难的部分”将来自于必须找到并“捕捉”可能违反这些政策的应用。

目前 iPhone X 已经掌握在许多评测者手中，许多人都表示，在许多不同的情况下，Face ID 都能很好地工作。一些媒体已经开始尝试用大量的衣服、太阳眼镜和“双胞胎测试”来糊弄 Face ID，最后的结果是喜忧参半。为了突出用户的安全与隐私，苹果公司在 9 月份发布了一份深度安全白皮书，强调并解释了 Face ID 的一些功能。
