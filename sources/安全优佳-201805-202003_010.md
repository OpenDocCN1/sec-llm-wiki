# 360儿童安全座椅现身世界智能大会 开启儿童出行智能时代

5月19日，第三届世界智能大会在天津闭幕。国家领导人在发来的贺信中强调，把新一代人工智能作为推动科技跨越发展、产业优化升级、生产力整体跃升的驱动力量，努力实现高质量发展。

作为智能硬件领域最具影响力的大会，本届世界智能大会以 " 智能新时代：进展、策略和机遇 " 为主题，集合了 30 个以上主要国家和地区的知名企业家、专家学者，共同针对智能科技产业的发展探讨商机和未来。展会期间，全球领先的 OS 智能生态服务提供商 360OS 展示的IOT OS 智慧平台，及360智能安防产品是本次大会的一大亮点。在现场所设立的360专属展区内，360儿童安全座椅吸引了众多参会人员的目光。

360车联网总裁邓邱伟此前曾表示，"在所有的交通事故当中，儿童人群永远是最弱势的群体，我们得重点关注儿童在驾驶当中的安全。"360儿童安全座椅，一经发售便深得消费者的喜爱。它除了给孩子带来全方位的安全保障，还自带很多"智能"功能，给孩子更安心舒适的乘车体验。

![](../Images/911972fc29a39d89c75f957329ee6d5e.png)

360儿童安全座椅在设计上遵循力学的三角定律，稳固抗侧翻。硬件配置了ISOFIX接口、五点式安全带、F1赛车供应商的雄霸卡扣，高强度精钢骨架、记忆棉材料等。当车祸发生时能吸收并分散来自前方的撞击力，让孩子的身体被座椅安全的包覆住，从而达到更好的保护力。

![](../Images/0688d491fa589338e82c51ae374347d7.png)

360儿童安全座椅首次采用真车64KM/H的速度进行碰撞测试，并取得优异成绩。通过官方的汽车高强度碰撞测试可以看出，360儿童安全座椅通过了以≥64km/h汽车碰撞墙体的安全监测标准，在发生碰撞之后，360儿童安全座椅能够对孩子身体的重要部位起到很好的保护作用，避免发生严重的侧翻、甩飞、多次碰撞的情况。

![](../Images/2ba9952dfc78f4307834d671ae2fc5ca.png)

针对孩子不愿意乘坐安全座椅，体验感差等问题，360儿童安全座椅团队经过多次调研和修改设计，为产品加入很多智能功能。360首创儿童座椅通风系统，采用吸风模式，独有的透气循环系统可缓解孩子久坐湿热。家长还可通过灯光颜色判断座椅目前的温度，及时为孩子增减衣物。其自带的"哄娃神器"，座椅两侧内置立体声扬声器以及多处氛围灯让小朋友坐上去就不愿意下来。当孩子哭闹不停的时候，父母可以通过手机APP连接座椅自行播放小朋友喜欢的歌曲音频。

值得一提的是，在360专属展区内，360安全路由、360扫地机器人、360智能门锁、360儿童手表等产品也吸引现场大量嘉宾。360公司综合正利用人工智能、大数据、云计算、IoT智能感知、区块链等新技术推出的分布式智能安全系统及物联网产品，守护在智能时代的国家、国防、关键基础设施、社会、城市及个人的网络安全与物理安全。
