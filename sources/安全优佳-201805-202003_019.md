# 概述

很多时候我们想实现限制某个IP段登录数据库，比较常用的是用触发器来实现，这里大致介绍下。

* * *

# 触发器实现

```


create or replace trigger logon\_ip\_control
```

说明：该触发器对用户EPAY\_USER进行了IP限制（只允许'192.168.219.20','192.168.219.22'，如果需要设置IP段，用%或?代替即可，如'192.168.219.%‘）。

* * *

# 测试验证

1）从非允许IP地址登陆 （192.168.219.21），连接失败
