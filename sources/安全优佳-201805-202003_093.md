# 瑞星荣获中国反网络病毒联盟“2018年度杰出工作单位”

近日，2019年中国反网络病毒联盟（ANVA）年会在京召开，来自政府部门、重要信息系统单位、电信运营企业、互联网和安全企业等60多家单位的专家和代表参加会议，瑞星作为知名网络安全厂商受邀出席。瑞星公司已连续多年被认证为中国反网络病毒联盟成员单位，此次荣获中国反网络病毒联盟“2018年度杰出工作单位”称号。

![](../Images/2a74201a124ee24c3236b95f443465cb.png)图：瑞星荣获“2018年度杰出工作单位”称号

![](../Images/3604901ead79d90c89c75eb95b78d0c6.png)图：瑞星认证为中国反网络病毒联盟成员单位证书

ANVA联盟会上总结了2018年度工作情况。其中，联盟“网络安全威胁信息共享平台”全年接收包括瑞星公司在内40家成员单位共享的恶意程序样本15.9万个，计算机恶意程序样本6.2万个，移动恶意程序样本9.6万个，发布关于信息窃取、恶意扣费、锁屏勒索等高危移动恶意程序信息121篇，公布了15305款具有信息窃取行为、380款具有恶意扣费行为以及952款具有锁屏勒索行为的移动恶意程序。

会议公布了2018年新获准加入联盟的8家成员单位名单，并对在恶意程序信息共享、安全检测分析、应用商店下架等工作中表现突出的26家联盟成员单位进行了现场表彰。瑞星在2018年度恶意程序样本共享、计算机和移动应用程序安全检测等工作中表现突出，被授予“杰出工作单位”称号。

瑞星作为中国领先的网络安全厂商，一直专注于网络安全领域，坚持自主研发，拥有完整的自主知识产权，本次荣获“2018年度杰出工作单位”称号，再次证明了瑞星的技术实力与服务能力。未来，瑞星还将继续坚持履行自己作为网络安全企业的职责，为广大网民及国家网络安全贡献出自己的一份力量。
