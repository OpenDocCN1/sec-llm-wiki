# 中国联通去年移动服务收入1651亿元，手机用户月户均数据流量约6GB

![](../Images/b4ceb897d8394a23eea474e9d8da109d.png)

新京报消息，3月13日下午，中国联通在港交所发布了2018年财报。财报显示，2018年实现服务收入2637亿元，同比增长5.9%，公司权益持有者应占盈利达到人民币102亿元，同比增长458%。

财报提到，2018年面对提速降费和市场竞争压力，公司积极推动移动业务创新经营，在渠道佣金和手机补贴下降的情况下，移动业务实现高效增长。全年移动服务收入达到人民币1651亿元，同比增长5.5%。

2018年，联通手机上网总流量增长1.8倍，手机用户月户均数据流量达到约6GB；手机上网收入同比增长13.7%，达到人民币1048亿元。

# 网易考拉加拿大鹅遭立案，杭州市滨江市场监管局专人负责

![](../Images/0505fcd8d4674ae27ad81b71f02b15fe.png)

此前备受关注的“网易考拉加拿大鹅疑似售假”事件有了新进展，据《证券日报》最新消息，浙江省杭州市滨江市场监管局对消费者线女士对网易考拉的投诉已经正式立案。另据了解，滨江市场监管局还要求线女士将证据材料以书面的形式寄送到指定地址。

工作人员告诉记者，线姓消费者对网易考拉的注册主体杭州优卖网络科技有限公司的投诉进展目前由专人负责中。网易考拉方面则并未披露案件的进展情况。

此前多家媒体报道称，2018年12月18日，北京市民线女士在网易考拉花5500余元购买了一件加拿大鹅牌羽绒服。消费者将该羽绒服拍图并发邮件给加拿大鹅的官网，后被告知是假货。2019年1月8日，网易考拉声明称，经内部及加拿大鹅官方双重核查，确认平台所售加拿大鹅为正品。1月9日，又有消息爆出，加拿大鹅官方推翻了向网易考拉出具的正品鉴定。

# 腾讯企鹅号盗号事件发酵，QQ帐号拟二度上线注销功能

![](../Images/0ce29216235caec4588acfffeb1c3d9c.png)

近日，腾讯企鹅号被盗号一事引发关注，3月14日，《证券日报》发布消息称，腾讯方面计划在近日第二次启动上线QQ帐号注销功能。对于启动QQ账号注销功能，腾讯客服方面表示，QQ帐号注销功能近期将会在QQ7.9.9及以上版本实现。而目前的QQ停留在QQ7.9.8版本。

腾讯此举被认为是3月12日发生的腾讯企鹅号盗号事件的发酵影响，12日，有自媒体人发文称，自己的企鹅号被盗号，盗号方更改了企鹅号的创作领域和方向，并且获利颇多。此事件被曝光后，有消息传马化腾过问“露露事件”，内部反腐即将开始。对此，腾讯回应称，传言不属实，并表示已注意到企鹅号平台上的“做号集团”和洗稿问题，正在筹备推出“企鹅号原创专家委员会”，推动版权保护。

# 春雨医生官宣“莆田系”医院名单 北京24家“上榜”

# 瑞银：2月份iPhone中国市场需求同比下滑70%

瑞银（UBS）3月13日发布报告称，今年2月份，苹果iPhone手机在中国市场的需求同比下滑了近70%。

此外，研究机构Longbow Research近日也曾发布报告称，中国消费者对iPhone手机的兴趣越来越淡，因为在网络上搜索iPhone的人越来越少。

Longbow Research数据显示，今年2月份，消费者通过搜索引擎百度搜索iPhone的次数下滑了48%。而今年1月，该搜索量下滑了50%。事实上，这已经是连续第五个季度呈下滑趋势。

# 董明珠：格力员工不一定有股权，但可以确保都有房

![](../Images/3c96472d49ee81cd16fa0d493915dddc.png)

近日，格力电器董事长董明珠接受澎湃新闻采访，被问到：有搞股权激励的想法吗？董明珠表示：我觉得它不是唯一的方法，你不一定拥有股权，你这个企业就能搞好，我就让员工活得幸福开心，我觉得这就是最好。幸福开心有多种方式。

对于格力集团此前备受关注的加薪和员工分房问题，记者问道：格力电器9万员工，一人一套房9就得有9万套房。

董明珠回应：不一定要有9万套，因为我们好多都是夫妻俩，两人一套。我们只能对一个人分房，给两个人分房不是让他们离婚吗？对不对？这已经在实施当中，可以确保员工都有房。
