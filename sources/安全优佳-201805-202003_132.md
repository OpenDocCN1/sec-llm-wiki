# Windows 10现可以自动卸载导致系统故障的“问题更新”

如果您的Windows 10计算机在更新完成后遇到问题并且自动恢复尝试失败，系统现在将自动删除这些“问题更新”，这种更新在Windows的发展历程中并不在少数，因而微软经常要发布新的补丁去修补上一个补丁。在一个新的支持文档中，微软详细介绍了一个有趣的功能，其中Windows 10将自动删除已安装的更新以修复启动问题和其他阻止PC启动的错误引发关注。

几个小时前，该支持文档被悄悄发布，出于某些原因，微软阻止搜索引擎抓取或索引该页面。文档中，微软解释说Windows可能会自动安装更新，以确保您的设备安全和顺畅。但由于各种原因，包括软件和驱动程序兼容性问题，Windows更新容易出错和导致硬件错误，此外在某些情况下，Windows Update可能无法成功安装。

安装最新更新后，如果您的PC遇到启动失败并且自动恢复尝试失败，Windows可能会尝试通过卸载最近安装的更新来解决该故障。在这种情况下，用户可能会收到包含以下消息的通知：

> Windows Update已卸载
> 
> “我们删除了一些最近安装的更新，以便从启动失败中恢复设备”。

微软表示，Windows还将自动阻止有问题的更新在接下来的30天内自动安装。在这30天内，微软及其合作伙伴将调查失败并尝试解决问题。解决问题后，Windows将再次尝试安装更新。

用户仍然可以自由地重新安装更新，如果您认为不应删除更新，则可以手动重新安装先前卸载的驱动程序或质量更新。
