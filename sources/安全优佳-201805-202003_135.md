# Airbnb

Airbnb是增长黑客的例子。这是一个关于真正的骗子的故事，他们不介意弄脏手，创造了世界上最著名的旅行平台之一。

简而言之，最初的“床上用品和床上用品”模型已经成为一种传统，甚至连希尔顿酒店连锁店都可以羡慕。

![](../Images/b86adebe4796dfea4ff8936ceacbb325.png)

# Airbnb的增长黑客故事

Airbnb以许多东西而闻名，其中一个正在制作以选举为主题的早餐谷物，并在奥巴马/麦凯恩竞选期间在会议聚会上出售以筹集一些初始资本......这就是Hustle 101，但我们不要过分关注它。

他们最着名的“黑客”是他们改造 Craigslist 的方式。早在2010年，Airbnb 找到了一种破解巨型平台以利用 Craigslist 客户的方法。

他们建立了一个机器人，将人们在 Craigslist 上的公寓列表重定向到 Airbnb。

结果？激烈的牵引力=惊人的增长。

这样做算得上道德的吗？可能不是......但非常聪明？绝对！

# Udemy

Udemy是增长黑客案例研究的另一个例子。

Udemy在全球拥有超过30000多个教育视频和700万学生，是世界上最大的在线教育平台之一。

然而，他们的成功并没有立即成功，因为创业公司在成长阶段大挣扎。他们找不到教师上传视频，因此无法吸引学生观看。

# 那么，他们是如何克服这个障碍的呢？

简单地说，他们决定从 YouTube 上抓取成千上万的教育视频并将其托管在 Udemy 上。实际上与 AirBnB 的故事情况相似。

参观者被此吸引，促使教师开始在 Udemy 上传他们自己的视频。这就是他们的旅程如何变成成长黑客的成功故事。

![](../Images/bdfa5c30cbd87ae31279e3677deab84e.png)

# 这些增长黑客故事有什么共同之处？

1.  他们使用OPN：'其他人的网络'来发展。Udemy 使用YouTube，Airbnb 使用 Craigslist和 Dropbox，使用他们客户的个人网络。
    
2.  他们成功的比例代表了 80％ 的最佳实践和 20％ 的颠覆性。正如阿利斯泰尔·克罗尔（Alistair Croll）所言：“大多数重大成功都有一点点邪恶”。
    
3.  它们由具有技能的人员执行，大多数数字营销人员都没有这些技能：网络抓取，编码和快速实验。
