# 蔚来汽车高成本运营致亏损96.4亿，周三收跌逾21%

3月7日消息，发布财报后，蔚来汽车股价出现大跌，截至周三收盘，蔚来汽车报8.00美元，跌幅达21.26%，市值82.08亿美元。

蔚来汽车于美国东部时间3月5日盘后发布了其上市以来首份财报。据财报显示，2018年，蔚来汽车仍处于巨额亏损之中，且亏损幅度还在扩大。根据财报，2018年全年，蔚来总收入为49.5亿元人民币（7.2亿美元），净亏损为96.4亿元人民币（14.0亿美元），较2017年扩大92%。

# 苹果称三年内将在圣地亚哥招募1200人

![](../Images/67c29ac51e3520678f1619b13f4c60ae.png)

苹果公司周三宣布，未来三年将在圣地亚哥的一个办公室招聘1200名员工，试图在其目前的法律对手高通的地盘上扩大影响力。

苹果深度侵入高通腹地示威也证明了两家关系的紧张，此前，两家公司一直在进行一场跨国法律战。高通指控苹果侵犯了其专利，而苹果则指控高通在设备中使用其芯片的专利使用费过高。

据此前路透社的报道，苹果已将其调制解调器芯片工程团队从供应链部门转移到内部硬件技术部门，这表明苹果可能正在考虑将其过去从高通购买的芯片转向由自己研发生产。苹果最近停止使用高通制造的调制解调器，转而使用英特尔芯片。

圣地亚哥市长凯文-福克纳（Kevin Faulconer）在推特上表示支持苹果的扩张计划，他说“这将使当地的就业机会增加20%。”

# 熊猫直播被指破产清算，曾与虎牙、斗鱼、网易谈收购，负债超7亿

![](../Images/525a91d8b8ecc7ddbddf4aee264fdac2.png)

3月6日，AI财经社获悉熊猫直播正在进行破产清算，有内部员工向AI财经社透露，此前王思聪曾与多家直播平台商谈，想要将熊猫直播出售，但由于负债太多，最终对方放弃了收购。从去年年开始。2018年1月，熊猫直播就开始内部裁员，该员工表示，公司仅赔偿离职员工半个月的工资，低于同行业水平。

另据财联社报道，半年前，在熊猫直播和虎牙、斗鱼、网易谈收购时，其已负债7亿多元人民币，因高额负债，交易并没有结果。

# 沪江否认大裁员，第一大股东：支持沪江对接资本市场的各项举措

![](../Images/c60f1b4b9f63adf37c54cb9badfdc9bf.png)

距离上市仅一步之遥的沪江网校却传出对赌失败裁员超千人的消息。AI财经社就此向沪江网校方面核实，沪江网校方面回应称，关于“95%裁员”的谣言严重失实，上市正处于进行之中，对赌不存在。

一位在线教育行业内人士告诉AI财经社，裁员消息属实，但应该只是业务收缩。成立于2001年的沪江网，曾是中国最早的非营利英语学习BBS社区之一。过去18年时间，沪江网校三度传出上市消息，去年7月更是与新东方在线前后脚向香港证券交易所提交招股书，争夺“港股在线教育第一股”。

针对网传对赌消息以及裁员等负面问题，沪江第一大股东涌金方相关人员回应财联社记者称：沪江教育加速盈利，是全体董事及股东集体决策的成果，符合公司发展战略，涌金会全力支持沪江减亏增效，以及对接资本市场的各项举措。

# 高通：苹果前工程师对有争议专利毫无贡献

高通与苹果的专利战还在持续，据新浪科技援引美国科技媒体CNET报道称，在高通对苹果发起新一轮专利诉讼的第二天，高通针对苹果之前的说法进行了反驳。在本次诉讼中，双方争议的焦点是一个对智能手机系统快速启动相关的专利。

本周一，苹果表示该公司前工程师阿诸纳·希瓦（Arjuna Siva）是第一个提出这个想法的人，他提出这个创意的时间早于高通在2011年获得No. 8,838,949这一专利的时间。那时，苹果和高通两家公司提出了将这个调制解调器技术用在iPhone中的计划。

高通方面表示不认同，高通工程总监史蒂芬·海尼晨表示，希瓦与这个专利毫无关系。在这项专利中，海尼晨也是发明人之一，他表示希瓦在这项专利上“什么也没做”，对专利毫无贡献。

# 魅族Note9发布：李楠称非公模机，定制屏幕花800万元

魅族6日发布魅族Note9手机，售价1398元起，3月11日正式发售。魅族高级副总裁李楠表示，魅族Note9虽然是千元机，但却不是公模机，很多零部件进行了定制。据魅族方面透露，该产品的水滴屏定制花费800万元，而后置双摄中的黑白副摄定制，让成本新增了300万元。

魅族Note9此次将游戏和拍照作为主打卖点，打出了“吃鸡不卡，拍她更美”的宣传语。

# 外媒称三星电子考虑竞购恩智浦半导体，恩智浦盘后涨约10%

腾讯科技消息，据外媒报道，全球十大半导体公司之一的恩智浦或迎来新的竞买人，有消息称，三星电子考虑竞购恩智浦半导体。此前，2016年10月，高通首次向荷兰恩智浦发出收购要约，报价380亿美元，但恩智浦股坚持认为价格太低。高通在今年2月将将收购报价提高到440亿美元，得到了恩智浦的认可。

最终因为双方约定的交易期限即将到期，该项收购未得到中国监管部门的同意，高通于2018年7月26日晚间正式宣布，终止收购恩智浦。

三星有意收购恩智浦的消息曝光后，恩智浦半导体盘后涨约10%。

# 周鸿祎：都赚钱的时候分不出谁是企业家谁是生意人

![](../Images/76d42f16d9c71f066477863ff305860d.png)

近日，360集团董事长兼CEO周鸿祎谈到企业家精神，他认为，企业家精神的关键词之一是“信念”。“没有信念的企业家，可能他今年可以炒房子，明年可以炒股票，后年可能炒炒比特币，但这不是最终能够给中国经济带来推动的企业家精神。”

周鸿祎说，“企业家和生意人最大的一个差别，生意人是什么挣钱就干什么，到处找风口，但是企业家应该有自己的信念，虽然最终的结果企业家也会挣到钱，但是他们的信念一定是通过创造一个独一无二的产品和服务，然后给用户、社会、国家创造价值，通过自己的产品、服务能力改变世界。”
