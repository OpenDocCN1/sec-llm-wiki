# 前言

你知道现在为什么许多黑客都首先选择Python吗，因为快呀，具有许多强大的渗透测试工具和强大的库支持，开发又快又好，优点多多。

如果你喜欢漏洞研究，喜欢渗透测试，逆向工程等等，强烈建议学学Python这门“胶水语言”，它包含了大量的库和实用工具，非常实用，那本节就给大家介绍一些精华库和非常牛逼的工具。

分为以下这几种：

1.  WEB
    
2.  Fuzzing
    
3.  网络
    
4.  调试和逆向工程
    
5.  PDF
    

1.WEB

FunkLoad: Web 功能和负载测试

WSMap: 寻找 Web 服务器和发现文件

Requests: 优雅，简单，人性化的 HTTP 库

ProxMon: 处理代理日志和报告发现的问题

Ghost.py: Python 写的 WebKit Web 客户端

HTTPie: 人性化的类似 cURL 命令行的 HTTP 客户端

Twill: 从命令行界面浏览网页。支持自动化网络测试

Windmill: Web 测试工具帮助你轻松实现自动化调试 Web 应用

spynner: Python 写的 Web浏览模块支持 Javascript/AJAX

mitmproxy: 支持 SSL 的 HTTP 代理。可以在控制台接口实时检查和编辑网络流量

pathod/pathoc: 变态的 HTTP/S 守护进程，用于测试和折磨 HTTP 客户端

python-spidermonkey: 是 Mozilla JS 引擎在 Python 上的移植，允许调用 Javascript 脚本和函数

2.Fuzzing

untidy: 针对 XML 模糊测试工具

antiparser: 模糊测试和故障注入的 API

SMUDGE: 纯 Python 实现的网络协议模糊测试

Powerfuzzer: 高度自动化和可完全定制的 Web 模糊测试工具

Mistress: 基于预设模式，侦测实时文件格式和侦测畸形数据中的协议

Sulley: 一个模糊器开发和模糊测试的框架，由多个可扩展的构件组成的

fuzzer.py(feliam): 由 Felipe Andres Manzano 编写的简单模糊测试工具

Peach Fuzzing Platform: 可扩展的模糊测试框架(v2版本 是用 Python 语言编写的)

TAOF: (The Art of Fuzzing, 模糊的艺术)包含 ProxyFuzz, 一个中间人网络模糊测试工具

![](../Images/a896bb568a9bc8488bd756163bf2cfa8.png)

3.网络

SubBrute: 快速的子域名枚举工具

Knock Subdomain Scan: 通过字典枚举目标子域名

flowgrep: 通过正则表达式查找数据包中的 Payloads

libdnet: 低级网络路由，包括端口查看和以太网帧的转发

Dirtbags py-pcap: 无需 libpcap 库支持读取 pcap 文件

dpkt: 快速，轻量数据包创建和分析，面向基本的 TCP/IP 协议

Impacket: 伪造和解码网络数据包，支持高级协议如 NMB 和 SMB

Pytbull: 灵活的 IDS/IPS 测试框架（附带超过300个测试样例）

pypcap, Pcapy, pylibpcap: 几个不同 libpcap 捆绑的python库

pynids: libnids 封装提供网络嗅探，IP 包碎片重组，TCP 流重组和端口扫描侦查

Mallory: 可扩展的 TCP/UDP 中间人代理工具，可以实时修改非标准协议

Scapy, Scapy3k: 发送，嗅探，分析和伪造网络数据包。可用作交互式包处理程序或单独作为一个库。

4.调试和逆向工程

pefile: 读取并处理 PE 文件

pydasm: Python 封装的 libdasm

diStorm: AMD64 下的反汇编库

Androguard: 安卓应用程序的逆向分析工具

Immunity Debugger: 脚本 GUI 和命令行调试器

python-ptrace: Python 写的使用 ptrace 的调试器

PyDbgEng: Python 封装的微软 Windows 调试引擎

Paimei: 逆向工程框架，包含 PyDBG, PIDA,pGRAPH

PyBFD: GNU 二进制文件描述(BFD)库的 Python 接口

PyEMU: 全脚本实现的英特尔32位仿真器，用于恶意软件分析

uhooker: 截获 DLL 或内存中任意地址可执行文件的 API 调用

mona.py: Immunity Debugger 中的扩展，用于代替 pvefindaddr

vdb/vtrace: vtrace 是用 Python 实现的跨平台调试 API, vdb 是使用它的调试器

IDAPython: IDA pro 中的插件，集成 Python 编程语言，允许脚本在 IDA Pro 中执行

Capstone: 一个轻量级的多平台多架构支持的反汇编框架。支持包括ARM,ARM64,MIPS和x86/x64平台。

![](../Images/38368b49d444dfe0949b2c53aa7291a4.png)

5.PDF

PDFMiner: 从 PDF 文件中提取文本

python-poppler-qt4: Python 写的 Poppler PDF 库，支持 Qt4

Origapy: Ruby 工具 Origami 的 Python 接口，用于审查 PDF 文件

peepdf: Python 编写的PDF文件分析工具，可以帮助检测恶意的PDF文件

Opaf: 开放 PDF 分析框架，可以将 PDF 转化为 XML 树从而进行分析和修改。

pyPDF2: Python PDF 工具包包含：信息提取，拆分，合并，制作，加密和解密等等

Didier Stevens PDF tools: 分析，识别和创建 PDF 文件(包含PDFiD，pdf-parser，make-pdf 和 mPDF)

6.总结

当然还有许多许多的库和一些取证工具，什么关于Python黑客的书籍呀，等等一些强大的库和工具，我就不一一列举了，因为太多大家也不好消化，其实东西不在于多，在于你能不能记得，这样才能学到东西啊。
