# 罗永浩聊天宝团队被曝解散，200人团队只留二三十人或回锤子科技

![](../Images/3b95ed7a8e7ec7ca4419a8986d25eec9.png)

3月6日，据36氪报道，有消息称聊天宝团队已经宣布就地解散，原团队只保留二三十人或将流回锤子科技，而聊天宝团队的原人数约200人。

企查查数据显示，2019年2月，罗永浩先后退出天津云上漫步科技合伙企业(有限合伙)、天津云上畅游科技合伙企业(有限合伙)股东行列，实控人变为王威。据悉，聊天宝主体公司北京快如科技有限公司由成都快如科技有限公司100%持股，而成都快如科技由云上漫步和云上畅游两家公司控股。

# 蔚来CEO李斌证实：蔚来汽车确定取消嘉定建厂计划

![](../Images/a01eb8d85c109114aafabce33f627e61.png)

3月6日，蔚来汽车发布的最新财报显示，公司已与相关方达成一致，取消2017年签订的在上海嘉定建厂的计划。对此，李斌回应全天候科技，表示信息属实。此前消息显示，2018年2月，蔚来第二工厂正式完成选址，将落户在上海嘉定外冈镇，原计划今年2018年中旬动工，规划用地800亩左右。

财报显示，蔚来去年总营收49.512亿元（7.201亿美元）；净亏损为96.390亿元（约合14.019亿美元）；ES8全年总产量为12775辆，交付量为11348辆。

# 福布斯全球亿万富豪榜：贝佐斯仍是全球首富，马化腾排名20

![](../Images/9a18cbf1a6a4d89ed467132418bc4a52.png)

美国《福布斯》杂志3月5日公布的最新全球富豪榜显示，网上零售商亚马逊创办人贝佐斯蝉联全球首富，身家达到1310亿美元，较去年增加了190亿美元。虽然经历了婚变风波，贝佐斯可能面临将自身资产分一半给前妻的情况，但是贝佐斯依然稳坐全球首富位置。

紧随贝佐斯之后的是微软联合创办人比尔盖茨和股神巴菲特，比尔盖茨的身家为965亿美元，巴菲特身家为825亿美元。中国富豪中，腾讯创始人马化腾以388亿美元的身家跻身第20位。

# 趣头条四季度净亏损同比扩大629%超预期，盘后暴跌逾14%

趣头条发布第四季度财报，报告显示，趣头条Q4营收13.27亿元，同比增长426.1%，高于分析师预期的12.9亿元；净亏损3.98亿元，亏损同比扩大629%；四季度日活用户数3090万，同比增长224.2%；预计2019年第一季度净营收11-11.20亿元，分析师预期为12亿。财报发布后，趣头条盘后转跌，一度下跌超14%。

用户数据方面，第四季度平均月活跃用户达到9380万，同比增长286.0%，2018年净增6950万，平均日活跃用户达到3090万，同比增长224.2%%，2018年净增2140万。日人均使用时长同比增长96.3%至63分钟。

# 格力手机3上架官网，配置却是2018年上半年或之前的机型

![](../Images/87a29885d56fa4818393f373b3af77c2.png)

董明珠表示格力将跟上“5G和柔性屏的大趋势”后，格力最新一款的手机悄悄上架了。

据快科技消息，在没有任何宣传的情况下，格力手机3代上架格力官方商城，售价3600元，现货开售，已售出16台。

配置上，格力手机3采用了5.99英寸2160x1080分辨率的18：9全面屏，后置1200万+500万像素双摄（支持光学防抖），前置800万像素单摄，内存组合4+64GB，电池3160毫安时，机身厚度8mm。

格力手机3采用MSM8996SG，即骁龙821处理器，令人大跌眼镜。系统预装Android 7.1.2系统，支持双卡，不支持扩展卡

从配置与设计上看，这是一款2018年上半年或之前的机型。

# 天猫、苏宁、京东大幅下调iPhone XS系列售价，最高直降近2000元

![](../Images/e69a09498e0d8aadef7c01c71208c5b4.png)

3月5日，苏宁、京东和天猫都表示要大幅下调iPhone XS系列售价，苏宁的下调力度最高达1000元，京东最高降1700元，天猫最高直降2000元。

# 特斯拉称与海关重启Model 3清关程序：原标识不合规

![](../Images/b5f7bfc3a1ef4dd1c9ffd4e40173b5be.png)

路透社消息，特斯拉周二表示，中国海关已经接受了公司解决Model 3轿车清关问题的方案，无法清关主要是因Model 3轿车标识不合规。

特斯拉方面表示:“这次疏失是由于一些Model 3车辆上的铭牌打印错误所导致的。 我们已经与海关总署达成了整改方案，并正密切合作，争取尽快恢复车辆通关过程。 车辆经过审核合格通关后，我们将尽快把它们交付到客户手中。 这并不影响Model 3 在国内的销售。“

# 阿里集团增持阿里影业，持股比例升至50.92％，实现实质控制

3月5日晚间，阿里影业发布公告称，阿里集团对阿里影业的股权增持计划已完成交割，阿里影业正式成为阿里集团的附属子公司。

去年12月，阿里集团对外公布计划增持阿里影业，向其注资12.5亿港元，持股比例由49%提升至50.92%。交易完成后，阿里集团将对阿里影业实现实质控制，并在阿里影业董事会拥有一定的董事席位。
