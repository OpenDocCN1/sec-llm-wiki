# 京东宣布扩招：2019年新增岗位需求预计将达1.5万人

![](../Images/78a6ac8f65482eacbcc8fa67655d18eb.png)

2月25日晚消息，京东集团宣布，2019年的新增岗位需求预计将达1.5万人，其中京东物流将在2019年新增1万名员工，招聘对象以一线员工及基层管理者为主，零售子集团等板块的招聘方向将主要聚焦于提升用户体验等领域。 京东集团目前拥有零售、物流、数字科技三大核心业务。

而就在上周，京东刚刚证实将对10%的副总裁以上高管进行优化。京东集团董事局主席兼首席执行官刘强东在全员信中提到，京东正在向“小集团，大业务”转型，其总部将从管理型总部升级为战略型总部，而将运营职能下沉，给予业务板块更多的授权，充分发挥组织活力，让各个业务板块能够更有意愿、更有条件地去自主经营，实现更有质量的增长。

资料显示，截至2018年三季度末，京东集团拥有的全职员工数量超过17万人，仅技术研发团队人数就已达2万人。

# 作价4.48亿美元，凤凰新媒体拟出售一点资讯母公司32%股份

![](../Images/87ebf8e95a9103991c43b661f8b64cf0.png)

2月25日晚间，凤凰新媒体发布正式公告，宣布其就一点资讯的股权转让与投资人签订了合法的投资意向书。公告称，根据意向书中条款规定，凤凰新媒体将以4.48亿美元的价格，将其所持有的32%的一点资讯股份进行转让。以此价格估算，一点资讯的投前估值将达到14亿美金。

交易完成后，凤凰新媒体仍将持有5.63%的一点资讯股份。本次交易的交割需满足所有交割先决条件。

资料显示，凤凰新媒体曾参与了一点资讯早期的三轮投资，所投金额合计约为4450万美元。如今五年过去，凤凰新媒体收获了4.48亿美元的财务投资回报。

# 联想与联通签署5G协议，将推出系列化5G终端产品

![](../Images/23dae8ef3c5a824d22006b5b5e569982.png)

2月25日晚消息，联想方面称，联想手机正式与中国签订了5G终端战略合作协议，宣告发力5G终端，规划将推出系列化5G终端产品，包括5G手机、电脑、IoT等多样化产品和用户的解决方案。联想认为，其将第一批实现5G产品在国内市场的商用化。

联想方面表示，联想在5G领域早有布局，是全球最早从事5G技术研究与积累的企业之一，还通过收购摩托罗拉，在5G专利领域拥有了较强的积累。目前联想正将5G技术延伸到更多的终端产品中。

# 马斯克再惹新麻烦：发推文对生产做出“不准确”表述，恐被拘留

![](../Images/c62933b7a524a5d72127b9668ed6e054.png)

特斯拉公司掌门人马斯克又有了新麻烦。2月26日，美国证监会（SEC）称马斯克2月19日的推文对生产做出“不准确”表述。消息称，因为藐视此前签订的协议，美国证监会要求法官对马斯克进行拘留。

马斯克在推特网站上宣布，2019年特斯拉将会生产大约50万辆车，不过稍后马斯克修改了说法称，2019年特斯拉的电动车产销量大约为40万辆。

此前，马斯克因发布公开信宣布私有化，随后又宣布放弃，此举遭到SEC指控为涉嫌证券欺诈。经过协商，双方达成协议，马斯克同意在45天内辞去特斯拉董事长的职务，但将继续担任首席执行官一职。此后三年没有再次被推选为董事长的资格。同时，马斯克的推文也将受到监控。

# 马云：中国电影离奥斯卡不远了，电影不应该是靠钱堆砌起来的

![](../Images/02548086efe66050b5ce1f25fb9d66a7.png)

2月25日晚上，作为影片的联合出品方，阿里影业在北京举办了电影《绿皮书》的超前点映。

阿里巴巴集团董事局主席马云现身观影现场，他在映后分享表示：“说中国电影离奥斯卡远，其实也不远了。电影不应该是靠钱堆砌起来的，电影也未必一定要有一个惊天动地的故事。”

马云称，这部电影成本非常低，“《绿皮书》让我看到这个世界人性的温暖。里面也有很多经典的句子，给人们很多思考。我今天还和一个导演聊到，真的想拍出好的电影，一定要热爱电影，而不是看到电影带给人的名利。要看到电影带给社会的正面意义。希望阿里影业不仅仅是投资、引进这样的电影，未来能拍摄出更多这样的好电影。”
