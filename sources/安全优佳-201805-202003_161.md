# 华为发布5G折叠手机售价一万七，展开后屏幕达8英寸

![](../Images/494d70f52ff1ffae560fe1ee4231eacb.png)

2月24日，外界期待已久的华为折叠屏手机在巴塞罗那发布，这款手机的售价高达2299欧元。在打开状态下屏幕有8英寸，类似于平板电脑，折叠后正面6.6英寸。

余承东透露，他也意识到这款手机的售价高昂，但里面有太多尖端的技术，“我们尽量让工程师把价格降下来”。据悉，为了攻克屏幕铰链技术，华为工程师花费了三年时间，做到了折叠后没有缝隙。

同时这款手机也是华为首部5G手机，采用了双卡槽设计，4500毫安电池和55W快充。预计在今年6月份对外发售。

# 滴滴发节约资源通知：自2月25起减少餐补、健身房、下午茶等员工福利

![](../Images/a04b2a65cafb4187c21b3848bbb3d9d3.png)

日前，滴滴发起节约资源、减少浪费的通知，对茶水间饮品、下午茶、健身房、咖啡厅、员工餐补、生日礼物等均进行了相应的取消或下调。这些调整将从2月25日执行。

具体而言，全员夜宵及茶水间零食取消，茶水间日常茶品减少，增加零食售卖机品类；取消咖啡厅、员工餐厅补贴，部分单品价格小幅上调。此外，还将取消员工生日礼物，减少周年礼物品类；减少员工俱乐部经费；取消工位健身及外部合作健身房。

此前，滴滴宣布公司将做好过冬准备，将对非主业进行“关停并转”，对业务重组带来的岗位重叠和绩效不达标的员工进行减员，整体裁员比例占到全员的15%，涉及2000人左右。

# ofo再次被法院冻结145万元，已遭多起供应商起诉

![](../Images/083dd01d8abeaeb8f8b77d825743cbde.png)

ofo又一次因与供应商纠纷被法院冻结资金。2月23日，企查查数据显示，天津科林自行车有限公司与ofo关联公司北京拜克洛克科技有限公司买卖合同纠纷一审民事裁定书显示，法院冻结拜克洛克银行存款145万元或查封其他等额财产。

此前，2月20日，北京市第一中级人民法院也对天津飞鸽和ofo的买卖合同纠纷作出了判决，法院判决东峡大通付给天津飞鸽7271万元及违约金779万元。同时，法院在同日出具的民事裁定书显示，已经冻结或查封扣押ofo共计8082.75万元的银行存款和相应财产。

自2019年1月3日至今，共享单车品牌ofo运营主体东峡大通（北京）管理咨询有限公司新增43条被执行人信息，执行标的金额总计达2.2亿元。而ofo对目前退押金的进展仍没有作出回应。

# 传滴滴车服与大众联手成立合资公司

2月24日，据北京青年报报道，有消息称，大众汽车与滴滴在中国建立的合资公司已经落户上海嘉定。对此，滴滴方面暂未回复。

记者查询工商登记信息发现，上海桔众汽车科技有限公司已经于去年年底成立。该公司注册资本6400万，由大众汽车（中国）投资有限公司持股 40%，而另一方则为惠迪（天津）商务服务有限公司60%。公司法定代表人为杨峻，他同时也是北京小桔新能源汽车科技有限公司的法人代表。

此前，有消息称，大众汽车期望的目标是，提供约10万辆电动化或具备自动驾驶功能的产品与滴滴共同组建一个运营车队，并且为车队提供其管理经验。新合资公司不会涉及目前滴滴的现有业务，但会参与滴滴的全球化布局和服务。

# 暴风集团澄清：冯鑫依然是公司实控人，并未卸任法人

![](../Images/2ddd654db92506a5e9a323f07e59ec1d.png)

2月24日，暴风集团发布澄清公告称，冯鑫并未卸任上市公司暴风集团的法定代表人，且依然是上市公司的控股股东和实际控制人。

此前，2月22日，据天津市市场监督管理委员会官网显示，暴风集团已于2月21日发生法人代表变更，由冯鑫变更为姜自权，冯鑫依然担任董事长一职。

对于暴风集团来说，整个2018年是灰色的。暴风集团1月30日公布的2018年业绩预期显示，预计暴风集团2018年亏损约9.25亿元，主要原因是传统业务暴风影音营收下降，影响本期亏损1.7亿元；其他亏损为公司根据经营情况对主要资产的可收回金额预估进计提了相应资产减值损失。
