# 易到宣布司机提现再延迟：允许乘客付现金，公司没倒闭

![](../Images/8d2c3007c6a1bb6bfa59eb756629ca88.png)

2月22日消息，易到用车向平台司机推送了《关于车主延迟提现说明》。易到方面表示，原定于2月22日的提现承诺，将延期兑现。自韬蕴资本2017年6月接手易到以来，已经向易到提供了数十亿资金。

易到在声明中表示：“我们恳请大家给易到一些时间，为多方筹措资金，韬蕴资本一直在全力推进包括融资、出售资产以及推进乐视相关资产拍卖在内的筹资动作。韬蕴资本承诺所获得款项将优先用于易到车主提现，届时易到的提现和可持续发展问題将得到根本的解决。我们无意一一列举大股东其他资产，只恳请各位车主再给韬蕴资本、易到一些信任、时间，我们会兑现承诺。”

# 李国庆创书友会称目标三年创收10亿元，想再做一个到两个独角兽

![](../Images/1bc84eb9cc731485fa3a4a25d05fa239.png)

2月20日，李国庆以公开信的方式宣布离开当当，投入到新的创业项目“书友会”中去，用区块链的方式探索内容产业。李国庆的公关经理对AI财经社透露，李国庆离开当当后将担任CRYSTO公链生态旗下DAPP CEO。

宣布离职当当后，李国庆在接受媒体采访时表示：“我知道做娱乐可能（有）更大的市场，但那不是我熟悉的事儿，所以我就愿意做这这个细分领域，再做一个到两个独角兽。”

《证券日报》报道称，李国庆对于他所将要创办的书友会抱有良好的盈利预期。“书友会的现金流会非常好，盈利预期也非常好。”

“按照付年费的方式，不搞补贴制。”李国庆透露，“如果一定要说个目标，我觉得第一年这个会员费大概能收到1亿元；第二年3亿元；第三年10亿元”。

# 百度第四季度营收272亿元，净利润同比降50%

![](../Images/dac26df232f5650d0f2afbac053f5e13.png)

百度发布了截至12月31日的2018财年第四季度和全年未经审计财报。报告显示，百度第四季度总营收为人民币272亿元（约合39.6亿美元），与上年同期相比增长22%，不计入公司已经宣布的资产剥离交易的影响为同比增长28%；净利润为人民币21亿元（约合3.03亿美元），与上年同期相比下降50%。

财报显示，百度2018年全年总营收为人民币1023亿元（约合148.8亿美元），比上年同期增长28%；2018年归属百度的净利润为人民币276亿元（约合40.1亿美元），比上年同期增长51%。

# 联想第三财季同比扭亏，股价飙升12%至三年来最高

![](../Images/2f581b204480bdef9865b74369099c60.png)

联想集团21日公布截至2018年12月31日第三财季业绩，营收及净利润均好于预期。第三财季业绩报显示，其总营业额971亿元，为4年来最高水平；总体税前利润24.2亿元人民币，年比年提升133%，为创联想有史以来新高；去年同期联想还是净亏损近20亿元的状态，现今净利润达到16亿元。

据21世纪经济报道消息，2月21日开盘后，联想集团在半小时内便强势上涨近9%，随后持续在高位徘徊。截至当日收盘，联想集团报收6.67港元，涨幅达11.91%，盘中一度蹿至最高点6.73港元。这也是联想自2016年2月以来的最优股价表现。

# 京东回应奶茶店关闭：随市场环境变化做出调整

![](../Images/dd207bd9fd1b0c826b348da4abbca089.png)

2月21日，京东旗下的“JD+智能奶茶馆”被曝停止营业。据报道，“JD+智能奶茶馆”于2015年5月8日正式开业，地址位于北京中关村创业大街。当时，刘强东携章泽天一同出现在开业现场。二人合用一把剪刀为奶茶店剪彩，恩爱羡煞旁人。

对此，京东方面回应称，奶茶馆是承担创业孵化器的角色，随着市场环境的变化，创业孵化器的形式也发生了改变。

# 苹果App Store累计向欧洲开发者分成超250亿美元

![](../Images/b783d56b89497043e18fe264670a685e.png)

苹果公司负责Apple Music和国际内容的副总裁奥利弗·舒瑟(Oliver Schusser)周四宣布，苹果App Store应用商店已累计向欧洲开发者支付了逾250亿美元的分成。

据此前媒体消息称，苹果此前宣布，截至今年1月份，App Store总计向开发者支付了逾1200亿美元分成。这就意味着，其中大约20%流向了欧洲应用开发者。

舒瑟重申，Apple Music付费订户已达5000万。他同时宣布，苹果播客平台节目数量达到65万个，累计单集下载量和流媒体播放量超过500亿次。

# 小红书进行全面组织升级：原社区电商事业部升级为“品牌号”部门

2月21日，小红书创始人毛文超和瞿芳发布内部信，对组织架构进行升级，共涉及5个方面。

小红书全面组织升级包括：将原社区电商事业部升级为“品牌号”部门； 升级“福利社”部门，整合商品采销、仓储物流和客户服务的全流程职能；在技术端，聚合公司所有业务线的技术团队； 在职能端，设立平台部，整合市场营销、品牌公关、政府事务、合规、行政等职能部门；新设立CEO办公室。

# 苹果最早明年放弃英特尔处理器，转而用自己的ARM芯片

外媒Axios报道称，苹果开发人员和英特尔高管预计最早将在2020年放弃英特尔处理器，转而采用ARM芯片。

彭博社此前报道称，首款基于ARM的Mac电脑可能会在2020年问世。据称苹果公司计划在2021年让开发者开发出一款理论上可以与苹果所有硬件兼容的应用，包括iPhone和Mac。
