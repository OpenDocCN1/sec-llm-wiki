# 贾跃亭再减持348.53万股，乐视网提示暂停上市风险

2月20日消息，乐视网发布公告称，2月13日至19日，贾跃亭所持公司股份减少348.53万股。截至2月19日，贾跃亭所持股份较2018年6月30日累计减少8066.64万股，根据贾跃亭方面此前邮件回复，其被司法处置股票用于偿还债务。

乐视网方面表示，公司2018年度审计报告被出具无法表示意见，公司存在股票被暂停上市的风险。截止目前，2017年度审计报告中“无法表示意见”尚未完全消除。根据2018年全年业绩预告，归属于上市公司股东净利润预计为亏损，如经审计后公司2018年全年净资产为负，公司存在股票被暂停上市的风险。

# 联想第三财季营收140.4亿美元，高于市场预期

![](../Images/18c61529c05910963d61ca737efced23.png)

2月21日消息，联想集团今日发布2019财年第三季度财报：当季营收140.4亿美元，同比增长4.9%，市场预期为139亿美元；净利为2.33亿美元，市场预期为2.001亿美元，同比增长38.7%。

财报显示，联想集团第三财季毛利为20.5亿美元，同比增长17%。毛利率14.6%，同比增长1.1%，主要由于个人电脑和智能设备业务利润率得到稳健增长及其移动业务的产品组合得到改善致。

ofo新增数十条被执行人信息，8000万银行存款和财产被冻结扣押

![](../Images/259d138cd4c1cf36d391e2c330342b9a.png)

财联社消息，自2019年1月3日至今，共享单车品牌ofo运营主体东峡大通（北京）管理咨询有限公司新增43条被执行人信息，执行标的金额总计达2.2亿元。

另据搜狐财经“公司深读”消息，北京法院审判信息网公开消息显示， ofo与天津飞鸽的合同纠纷有了结果。

据了解，天津飞鸽和ofo的买卖合同纠纷案于2018年6月20日立案，截至2018年5月30日，ofo仍欠天津飞鸽7271.02万元货款及违约金778.95万元。

判决表示，ofo应于判决生效后十日内向天津飞鸽支付7271.02万元货款及违约金778.95万元。法院在同日出具的民事裁定书显示，已经冻结或查封扣押ofo共计8082.75万元的银行存款和相应财产。

# 分析师：中国消费者对苹果的渴望在转移到华为身上

![](../Images/f949e82ed9ae01860c7ef70d85191260.png)

新浪美股消息，汇丰认为，由于“超过价格点”，苹果公司iPhone在中国市场面临的需求问题“可能并非短期状况”。该行确认对苹果的持有评级，目标价为160美元。

# 网易第四季度净利润23.6亿元，同比增长25.58%

新浪科技2月21日消息，网易发布了该公司截至2018年12月31日的第四季度及全年未经审计财报。财报显示，网易第四季度净营收为人民币198.443亿元（约合28.862亿美元），同比上升35.8%；按非美国通用会计标准计算（non-GAAP），归属于网易股东的净利润为人民币23.596亿元（约合3.432亿美元），同比增长25.58%，稀释后的non-GAAP每股净收益为2.66美元。

根据雅虎财经汇总的数据，华尔街18位分析师平均预计，网易第四季度营收将达29.5亿美元。财报显示，网易第四季度净营收为28.862亿美元，略低于分析师预期。

# 美团辟谣“大众点评会消失”：会一直是个独立App

![](../Images/6770e801820d5e3b7327f85030027589.png)

2月20日晚间，据界面新闻报道，大众点评将被改名或被直接放弃。美团副总裁王慧文在内部会上称投资人要求美团DAU达到6000万；为提高DAU，美团旗下所有产品将整合进美团App中，包括大众点评的数据和流量。

对此，美团相关负责人向AI财经社回复，大众点评会一直是个独立app，不存在合并进美团app的可能性。

# 韬蕴资本回应“面临巨大财务困难”：公司经营正常，通知被过分解读

2月19日，韬蕴资本发布内部通知表示：自公司接手易到以来，耗费了大量精力与资金挽救易到，对公司整体业务与资金造成了不小的冲击，新一笔融资在短期内恐难到位，公司在财务上面临巨大的困难。

2月20日，韬蕴资本法务总监孙树明对《每日经济新闻》表示，“公司目前经营正常，通知被过分解读了。”针对通知中提到的为救易到，公司面临巨大财务困难，他说：“面临一点困难，没有那么严重。在资本市场寒冬下，更加聚焦主营业务，对非主营业务的优化和调整，再具体的安排不方便透露了。”
