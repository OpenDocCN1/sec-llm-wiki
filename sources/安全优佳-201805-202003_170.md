# 罗永浩聊天宝被曝出现bug，用户可兑换百万现金，回应：已关闭提现

![](../Images/23716f0c1d84945e15fdf7851e0d9de0.png)

2月19日，有用户爆料称，罗永浩的聊天宝App疑似出现bug，原来的金币能折现几十万元，并称已经有不少人提现成功。

19日晚间，聊天宝APP官方发布了《关于聊天宝 App“摇钱树”游戏临时关闭的声明》，声明中表示：聊天宝APP的“摇钱树”游戏出现问题，导致用户金币技术错误，超额发放给了部分用户，为及时修复此问题，当前已关闭“摇钱树”游戏功能及用户现金提现功能。待问题修复完成后，超额发放的金币数量将自动恢复为原有数量。

# 马斯克：到年底特斯拉将拥有全部无人驾驶汽车功能

![](../Images/c07bb994a670f5778b8ff0520c0bc805.png)

新浪科技消息，特斯拉CEO埃隆·马斯克（Elon Musk）预计，到年底该公司将可拥有运营无人驾驶汽车所需要的全部技术。

“我认为，今年我们将可实现功能完备——也就是实现完全的自动驾驶。”马斯克说道。“这就意味着，今年开始我们的车能在停车场找到你，接你上车，然后一路带你到目的地，期间无需任何干预。我要说，对这一点我很肯定，没有疑问。“

# 韬蕴资本:公司为挽救易到造成财务困难,暂停发绩效，员工在家办公

![](../Images/991d67ee9b53a6ac7248b24bddad7279.png)

据界面新闻报道，韬蕴资本发布通知称，公司接手易到以来，耗费大量资金挽救，给公司其他业务带来了不小的冲击，公司多次融资自救，但新融资恐难以在短期内到位，公司财务发生巨大困难，目前已无法支撑现有团队继续运营。

文件称，自通知发布之日起，各部门负责人安排员工在家办公，期间暂停绩效工资发放，只做基本生活保障，恢复上岗时间将另行通知。

# 阿里巴巴成中金第四大股东,持2.03亿股占总股份4.84%

![](../Images/e7079200b635e2bf09c7c81996fa32de.png)

阿里巴巴集团透露已于近日完成对中国国际金融股份有限公司（3908.HK，“中金公司”）的入股，持有中金公司港股约2.03亿股，占其港股的11.74%和总已发行股份的4.84%。

值得注意的是，2017年9月腾讯以每股13.8港元的价格认购了中金公司2.075亿股H股，合计耗资28.64亿港元。认购完成后腾讯持中金股4.95%，成中金第三大股东。彼时，腾讯入股中金的举措被视为与阿里金融业务的抗衡。一年多时间过去，阿里也顺利入股中金，成中金第四大股东。

阿里巴巴集团方面称，公司与中金有多年业务合作。通过本次入股能结合双方各自在金融、科技、数据等领域的专长，为客户提供更创新、更全面的产品及服务。

# 斗鱼北京分公司市场部大量裁员，办公室一半是空位

![](../Images/f21d8f0da30e411d444c1c08032ad508.png)

2月19下午，AI财经社接到爆料称斗鱼北京分公司市场部大量裁员，原办公地点优盛大厦七层已经人去楼空。接到爆料后，AI财经社赶到斗鱼北京办公室发现斗鱼所在的优盛大厦七层、十八层两层楼中，其中七层确实有大量员工空位，而技术部所在十八层也有空出了一个办公室。

根据斗鱼离职员工透露，此次裁员中，斗鱼市场部80%的员工已经离职，之前三十多人的团队目前仅剩七八人左右。年前，斗鱼就曾传出深圳分公司海外部门大量裁员的消息，但当时斗鱼称是正常的人员结构调整，而此次记者就裁员问题向斗鱼公关咨询后，对方表示”不予置评“。

# 特斯拉2018年在华销售额17.57亿美元，同比下降15.4%

北京时间2月9日消息，特斯拉向美国证券交易委员会提交的2018年年报显示，当年特斯拉实现营收共计214.6亿美元。中国作为特斯拉第二大消费市场，销售收入较2017年有所下降，2018年度中国地区的收入为17.57亿美元，同比下降15.4%。

特斯拉对于中国市场的重视程度非常高，自中建厂消息传出以来，特斯拉在中国市场的招聘也已经启动。今年1月，特斯拉方面公布了在在上海招聘的职位共有20个，且绝大部分是服务于临港的超级工厂。“我们接下来肯定要在中国招募很多人才。”一位特斯拉的内部人士表示。
