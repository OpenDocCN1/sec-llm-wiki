# 网络安全协同创新公益性--石景山在行动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzcwMTU1Ng==&mid=2649522821&idx=1&sn=2d068649dc148d37a29a2b11e50b7898&chksm=8713235eb064aa480df2fb83d6fca6f92a63e652b0ce7dfcb757205e00f54c14c70deb315173&scene=126&sessionid=1681368001#rd](http://mp.weixin.qq.com/s?__biz=MzA3MzcwMTU1Ng==&mid=2649522821&idx=1&sn=2d068649dc148d37a29a2b11e50b7898&chksm=8713235eb064aa480df2fb83d6fca6f92a63e652b0ce7dfcb757205e00f54c14c70deb315173&scene=126&sessionid=1681368001#rd)

2019年1月19日，由石景山区工商联海商会、北京新时代空间&猫妹咖啡承办的网络安全协同创新公益行活动在石景山举办。

![](../Images/6a1b2d17d6cc0d6085aea6b786ea639a.png)

新时代空间&猫妹咖啡总裁颜兵致辞

本次公益活动是由北大纵横管理咨询集团县域治理与发展研究院，中关村文创游戏产业发展联盟共同发起的。面对日益严峻、复杂多变的国际形势，在高科技迅猛发展的新时代，以网络安全为起点的网络安全协同创新体系势在必行，正成为新时代网络创新的里程碑。北京市石景山区定位为未来国家级绿色转型发展示范区，正大力引进与发展高端服务业，引领未来网络科技发展趋势的网络安全协同创新也将成为石景山区重点发展的领域，成为产业投资的新风口。这次公益活动举办得正合时宜，通过网络安全培训，提高企业和个人的网络安全意识，学习国家相关法律法规，加强防范措施，为促进全国网络安全事业开辟新途径。

![](../Images/3fac2f971802adb3758330b1f42a2bca.png)

北大纵横副总裁樊勇

![](../Images/173cb850c757e1f347d9bd0e7af8f1df.png)

北大纵横院长黄军

这次公益活动获得石景山区委统战部、石景山投资促进局、石景山公安分局的大力支持，owasp中国、中关村智城军民融合信息安全工程技术联盟、中关村文创游戏产业发展联盟、石景山区工商联海商会、新时代空间、全球中小企业联盟、瑞思创智教育扶贫工作部、威客中国、中招环能、嘉赛信息技术、大璞科技等30多家企业及相关组织代表、网络安全行业人士到场参加培训。

![](../Images/1f53d523f657bc18c9ea0fe279a82091.png)

现场参加公益活动的企业家和组织代表们  

这次公益活动包含两个环节，第一个环节主要是公益讲座培训，在石景山科技馆报告厅举行。威客安全高级专家詹鑫对当前企业和个人面临的网络安全隐患以动画地形式进行了深入浅出的讲解，并提出了具体的防范措施。石景山公安分局的资深网警马俊龙对新时代的网络安全的形势与政策进行解读，提升了在座企业家们对网络安全法、定级备案、等保测评相关知识的理解和认识。第二个环节是在猫妹咖啡举行的网络安全协同创新投资风口研讨会，研讨网络安全公益行活动的重大意义和网络安全协同创新投资的世纪机遇。

本次活动结束后，还计划于2019年在石景山区举办多场公益活动，培训1000名网络安全协同创新相关人员和100名公益讲师（大使）。讲座虽小，公益事大，重在参与。欢迎各界朋友积极参与网络安全协同创新的学习和研讨，争取成为公益讲师，一起推动网络安全协同创新，在以网络安全为新起点的新一代网络体系形成过程中，开拓我们共同的和个人的新空间。让网络安全公益行活动以石景山为起点，走向北京，走向京津冀，走向全国，走向中国东盟自由贸易区，走向一带一路。
