# 警方破获首例芯片卡“隔空盗刷”案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzcwMTU1Ng==&mid=2649522791&idx=1&sn=9f7767b9a67d060086a6c8a6e7ef1e33&chksm=871323bcb064aaaad7235b3aa00af6f23a055d493c7fe821dbc0c105d0276ca27db51b8ed9eb&scene=126&sessionid=1681368001#rd](http://mp.weixin.qq.com/s?__biz=MzA3MzcwMTU1Ng==&mid=2649522791&idx=1&sn=9f7767b9a67d060086a6c8a6e7ef1e33&chksm=871323bcb064aaaad7235b3aa00af6f23a055d493c7fe821dbc0c105d0276ca27db51b8ed9eb&scene=126&sessionid=1681368001#rd)

“卡还在，钱没了。”11月中旬以来，南沙区一派出所接连接到群众报案，称被人盗刷银行卡资金。

据这些事主反映，他们的银行卡都在自己手中，但是卡上的钱却不翼而飞了……

![](../Images/620e43741b35408d1f03ef196fb31bd9.png)

靠一靠，钱就到手，最近南沙警方就抓获了一个犯罪团伙，用的就是这种手法。

![](../Images/42605894b046ecbc7c577f4c45e7aec3.png)

“我们现在很多银联卡都换成芯片卡的，芯片卡都默认会开通免密支付，也就是闪付功能，小金额的消费不需要输密码或者签名，pos机感应到芯片卡的这个闪付功能，就会自动消费的了。”

所以这个犯罪团伙就是将一部设置好的pos机，装进一个比较薄的钱包里面，然后就寻找一些合适的下手对象。

![](../Images/da5ec6c160ed01405ca4a90b5595b997.png)

![](../Images/f872fec4138cd5bba428c0accbdc40d7.png)

找到合适的对象之后，就会靠过去感应一下。感应的距离，大概是5公分，因此一些女士的包包，或者男士贴身带的钱包，就很容易成为了他们下手的对象。

由于免密支付最高限额是1000元，所以每次嫌疑人都是设定999以下，专门选择到人流密集场所逛街，就这样走一圈“收获”也不少。

![](../Images/c0da47e1fdeaef0ec0a1ab8ff301d7ab.png)

11月中旬以来，南沙区公安分局鱼窝头派出所接连接到群众报案，称被人盗刷银行卡资金。据这些事主反映，他们的银行卡都在自己手中，但是卡上的钱却不翼而飞了。针对这一新型作案手法，警方高度重视，迅速开展侦查。

民警综合分析认为，犯罪嫌疑人在作案地点的选择上应该是以人流密集嘈杂地区为主，于是将目标锁定在大同市场正在举办的美食节，并对该区域进行重点布控。11月15日17时许，民警发现有两男一女，手持黑色提包在市场走来走去，却无购物行为，形迹十分可疑。其中一名男子手持黑色提包向一名群众靠近，而后又迅速撤至隐蔽位置拉开提包操作刷卡机。民警看准时机，迅速上前控制3名嫌疑人，当场缴获POS机2台及现金约8万元。

![](../Images/7df69f5f6baf891741b4d4bb69f0c5b9.png)

据嫌疑人交待，他们是利用芯片银行卡小额免密支付的功能，在人流量较大的公共区域相互掩护，用伪装过的POS机贴近事主钱包内的银行卡进行感应，以此盗刷他人卡内资金。

![](../Images/91efc3c679e4d4c230f5bc8a5b373591.png)

目前，犯罪嫌疑人曹某良（男，42岁）、汤某军（男，30岁）、汤某宏（女，39岁，均为湖南省衡阳市人）因涉嫌盗窃罪，已经被警方依法刑事拘留。案件仍在进一步侦办中。

**民警提醒：**

银行卡闪付免密免签：自2018年6月1日起，中国银联与各成员机构联合对“小额免密免签”功能进行优化，银联芯片借记卡、信用卡的小额免密免签单笔限额由300元提升至1000元，单卡单日累计消费金额不超过3000元。

![](../Images/53ccc4fbc276e912c856aea7d0276679.png)

芯片银行卡大多都具有小额免密闪付功能。使用此功能虽然方便快捷，但其支付原理存在一定的风险。民警提醒：由于免密支付是默认开通的，所以各位街坊可以根据自己的需要，打电话到银行关闭该项功能。

**什么是小额免密？**

当持卡人使用具有“闪付”功能的金融IC卡或支持“银联云闪付”的移动设备，在指定商户进行一定金额及以下的交易时，只需将卡片或移动设备靠近POS机等受理终端的“闪付”感应区，即可完成支付，支付过程中，持卡人不会被要求输入密码，也无需签名。

为了确保用卡环境的安全，各行对商户资质情况、终端类型等对不同商户实施分级管理，设置了小额免密免签累计交易笔数或限额参数，重点对自助售货机类商户连续多笔交易，连锁超市、商场类商户贴限额（单笔、单日累计）交易，以及连续多日累计大额小额免密交易等涉及可疑交易的商户进行监控，并向银联反馈商户风险调查结果及风险防控措施，确保用卡环境安全。
