# 世界首例基因编辑婴儿争议不断：122位科学家联名谴责，卫健委展开调查

![](../Images/969b05bfbd0a69e0c2ef59a5f4f2e223.png)

11月26日，南方科技大学副教授贺建奎宣布，一对名为露露和娜娜的基因编辑婴儿于11月在中国健康诞生。这对双胞胎的一个基因经过修改，使她们出生后即能天然抵抗艾滋病。这是世界首例免疫艾滋病的基因编辑婴儿。

这一消息立即引发各界广泛关注和质疑。南方科技大学发布声明表示，此项研究工作为贺建奎在校外开展，学校和生物系对此不知情，且贺建奎已停薪留职。深圳市医学伦理专家委员会表示已启动对该事件涉及伦理问题的调查。

我国122位科学家也对此发表联合的声明，称“此项技术早就可以做”，不做的原因是巨大的风险和伦理问题。声明表示，这项所谓研究的生物医学伦理审查形同虚设。此外，省卫健委已组织力量针对该事件展开调查。

# 乐视网拖欠前员工15万经济补偿，再被列为老赖

![](../Images/f07f8c00f1dc771567d1a2c739f06350.png)

11月26日有媒体爆出，因涉嫌前公关的一笔经济补偿案，乐视网于近日再次被列为失信被执行人。对此，乐视网回应称，将进行核查。据公开信息显示，此次劳务纠纷涉及对象崔欣爽为乐视集团前公关总监，于2017年11月从乐视离职，而后转至优信二手车集团担任公关总监。

此宗案件立案时间为2018年10月15日，发布时间为11月21日。据法律文书显示，乐视网于判决生效后七日内支付崔欣爽解除劳动关系经济补偿金150267元。如乐视网未按照判决指定的期间履行给付金钱义务，应按照规定，加倍支付延迟履行期间的债务利息。

而被执行人的履行情况为 “全部未履行”，且失信被执行人行为具体情形为“有履行能力而拒不履行生效法律文书确定义务”。这不是乐视网第一次被列为“老赖”。AI财经社在中国执行信息公开网上查询获悉，截至目前，乐视网信息技术（北京）股份有限公司共计21条执行信息记录。

# 诺基亚与OPPO达成授权协议，OPPO将可以使用其多项技术专利

![](../Images/75b1c4792931cf711f4df5cd92623107.png)

据IT之家报道，日前，诺基亚发布公告称，已经与OPPO签署多年的专利授权协议。协议内容大致是OPPO所获专利授权的类目，更为具体的授权内容、授权费用，诺基亚表示对外保密。

公开资料显示，诺基亚在移动通信领域仍然拥有上万项专利数量，大部分厂商与其不能在同一个量级。诺基亚的专利覆盖面也较为广泛，尽管诺基亚曾一度退出手机制造，但如今，凡是涉及手机研发制造的环节都难以绕开诺基亚所持有的专利。

目前，诺基亚已经拥有在5G、WiFi、石墨烯等领域的诸多专利，这些对于许多手机厂商来讲是未来重要的发展方向。

# 持续近十年， 苹果App Store涉嫌垄断案最终将启动美国最高法院听证

![](../Images/c3ca31164ee26ba7e596bea6df22b48e.png)

据外媒报道，苹果App Store涉嫌涉嫌垄断的案件最终将在美国最高法院法官面前展开辩论，这场争端已经持续了近十年。

iPhone用户认为，苹果App Store对应用销售收取30%的佣金，相当于价格欺诈，用户只能通过App Store购买应用，这是一种非法垄断，因此苹果需要向iPhone用户支付损害赔偿。而苹果公司则坚决否认这一点。

专家表示，如果法院允许iPhone用户提起诉讼，那么他们可能会要求苹果退还在四年内售出的每一款应用的一定比例，这可能会给这家科技巨头带来数亿美元的罚款。

# 美国通用汽车计划裁员14000人，并关闭七家工厂

![](../Images/2e4ea425f415cda0d85f15e27e975095.png)

日前，通用汽车周一早些时候发表声明称，公司将花费30-38亿美元用于裁员如果公司与工会未能就将更多生产任务分配给这些工厂达成协议，那么通用汽车可能在2019年底前关闭在美国的四家工厂以及在加拿大的一家工厂。另外两家在北美之外的工厂也将被关闭。

这一计划还包括放弃一些销售不佳的车型。通用汽车表示，通过这一系列计划，预计在2020年前将节省45亿美元成本、实现60亿美元现金流增长。对此，公司CEO博拉称，美国经济十分强劲，裁员只是因为汽车业出现变革，而公司之后的重心和投资将放在电动汽车的制造上。受此消息影响，通用汽车股价飙升。

# 知情人士：吉利起诉百度不是冲着百度，更不是冲着李彦宏

![](../Images/3ec37aac521a581c5daaac56aa3128df.png)

近日，北京海淀法院官网发布的一则浙江吉利控股集团汽车销售有限公司起诉北京百度网讯科技有限公司的案件快报，吉利汽车认为，百度公司作为百家号的开发者和经营者，未对用户“车有趣YOU”的不实文章予以审查即发布，导致吉利汽车的名誉受损，其行为已构成对吉利汽车名誉权的侵害，应承担相应的侵权责任。故将百度告上法庭。

一位知情人士向《每日经济新闻》记者解释了此次吉利起诉百度的原因，“吉利只是希望百度能加强百家号平台的监管，从而得到一个更好的媒体环境。”该人士表示，“这并不是冲着百度，更不是冲着李彦宏”。

吉利方面认为，作为自媒体平台的提供者，类似于百度百家号等平台方固然拥有对入驻自媒体的隐私保护义务，但是也有对企业商誉保护、对虚假恶意捏造信息进行审核处理的义务。

# 美国“洞察”号无人探测器成功登陆火星

![](../Images/5a9d8bc5cbb5defae4f33d492c062f2b.png)

北京时间11月27日凌晨3点54分，美国宇航局（NASA）“洞察”号探测器在火星软着陆成功，执行人类首次探究火星“内心深处”奥秘的任务。“洞察”号降落在火星表面后，通过与其同行的迷你卫星于15时许传回了火星的第一张照片。

据了解，“洞察”是首个研究火星内部的火星探测器，将帮助科学家勾勒出火星内部结构的演化历程。

今年5月5日，“洞察”号从位于美国加利福尼亚州中部的范登堡空军基地升空，经过205天的旅行，在外太空零下269℃，飞行了半年多，航行了4.84亿公里后，着陆火星。这个路程即便让宇宙中速度最快的光去跑，也要27分钟。
