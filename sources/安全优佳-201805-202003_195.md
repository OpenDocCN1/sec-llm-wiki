# 酷派发布公告：专利复审委裁定起诉小米侵权专利部分有效

![](../Images/cdfa7521f43864c44d20d48ae89f8101.png)

11月14日消息，酷派集团公告表示，公司附属公司就与小米通讯等被告之间的三项发明专利权纠纷向法院提起的诉讼，小米通讯此前就该专利权向国家知识产权局专利复审委员会提出专利权无效宣告请求，复审委员会在11月9日发出维持该专利权部分有效的决定书。公司认为，此决定书为公司日后案件审理中提供了有利证据支持。目前案件均已受理，尚未开庭。

今年5月，酷派公告称，公司接到附属公司宇龙科技（原告）通知，由于小米科技等公司（被告），在收到诉讼诉状后继续实施侵权行为，诉讼原告近日向深圳市中级人民法院提出申请，请求法院裁定诉讼被告立即停止侵犯专利权的行为，即停止销售和许诺销售红米Note 4X、小米6、小米Max2、小米Note3和小米5X共五款手机产品。

业内人称，士酷派目前的手机业务从市场角度上来说已经基本瘫痪。现在看来，专利似乎成为酷派盈利的一种方式。酷派CEO蒋超此前表示，“现在很多公司在盗用或者窃取我们核心的技术和专利，下一步我们会对一些相关公司进行专利诉讼。”

# 人人公司宣布将2000万美元代价出售人人社交网络全部资产

![](../Images/74d55cd3d2d63084058ae9f13128ce4f.png)

11月14日消息，人人公司在其网站发布信息称，宣布其子公司北京千橡网景科技发展有限公司已同意将其所从事业务中的人人网社交平台业务相关资产以2000万美元的现金对价出售予北京多牛互动传媒股份有限公司。

人人公司认为该项资产出售是对人人网社交平台业务的最可行的安排，也将会帮助人人公司步入下一个成长阶段。随着本次交易的完成，人人公司将专注于境内的二手车业务和以在美国运营的Trucker Path业务和SaaS业务为代表的境外业务。人人公司仍计划保持其纽交所上市公司的身份。

资料显示，人人网前身是成立于2005年12月的校内网，创办人是王兴、王慧文、赖斌强等几位大学生。2006年10月，校内网被千橡互动集团收购。同年底，校内网与千橡公司旗下的5Q完成合并。2009年8月4日，校内网改名为人人网；2011年5月4日，人人网正式挂牌纽交所上市。

# 银隆创始人魏银仓被指侵占公司利益超10亿，回应称已起诉董明珠

![](../Images/4e9fe7386f7ea2a17d1e830bf1c4e338.png)

11月13日，明银隆新能源发布声称，公司新一任董事会、监事会及公司管理层在履职过程中，发现原董事长魏银仓、原总裁孙国华涉嫌通过不法手段，侵占公司利益金额超过10亿，目前，公司已向珠海市中级人民法院提起民事诉讼、向珠海市公安局经侦支队报案。相关机构已正式受理。

据腾讯《一线》报道，魏银仓对此回应称，“已经起诉她（董明珠）了”。

2018年以来，快速扩张使银隆不断被曝出停产、停工、欠薪、被封、IPO叫停等负面新闻。

此前，银隆新能源各大园区电池订单减少、工厂停产的消息持续发酵。位于河北省武安新能源产业园的河北银隆率先传出订单下降导致产能过剩，部分生产线停工、员工被放假的消息。据此前报道显示，工厂减产、员工被放假的情况在银隆新能源的多地园区都有发生。

# 美团与上海汉涛签股权转让协议，登记股东变更为王兴、穆荣均

![](../Images/24bd4743f35f96d3d7dc5d03d2c69216.png)

11月13日晚，美团点评发布公告称，与上海汉涛签订股权转让协议。将上海汉涛的登记股东由现有登记持有人变更为公司执行董事王兴及穆荣均，现有登记持有人同意分别向王兴及穆荣均转让上海汉涛的95%及5%股权，总代价为人民币1800万元。

资料显示，上海汉涛信息咨询有限公司注册成立于2003年9月23日，旗下主要产品为本地生活消费平台大众点评网。2015年10月，大众点评网与美团网宣布合并。美团CEO王兴和大众点评CEO张涛将同时担任联席CEO和联席董事长，重大决策将在联席CEO和董事会层面完成。

此次股权转让协议生效前，大众点评网创始人张涛拥有上海汉涛29.19%的权益。

# 快递车辆起火，包裹损毁？菜鸟驿站回应：恶意造谣

# 滴滴公布调查结果：86%用户赞成司机可拒载独自醉酒乘客

![](../Images/0eebd482ddb110c9bcb8e73e6ca72dbc.png)

11月13日下午，滴滴出行发布了公众评议会第一期议题的用户反馈结果，第一期议题为“司机是否有权拒载独自醉酒的乘客”，滴滴公布的调查结果显示，共26.9万位网友参与了投票和评论，86%的人认为司机可以拒载独自醉酒的乘客，14%的人认为司机不能拒载。

绝大部分网友认为，醉酒乘客吐在车内需支付司机相应的洗车费与误工费。也有网友提出可与保险公司合作提供 “醉酒险”、“洗车险”供醉酒乘客购买。

此外，滴滴还公布了第二期公众评议会的议题——“网约车内是乘客的私人空间还是公共环境”，将邀请公众就能否在车内饮食、携带宠物打车、以及在确保信息安全的基础上能否接受在车内录音录像等问题展开讨论。

# iPhone市场需求低迷拖累富士康，三季度净利润低于预期

![](../Images/0d854a2a47ec601163fe616f4db69e0c.png)

11月13日晚间，富士康今日发布了2018年第三季度财报，净利润同比增长18.3%。

作为苹果公司和全球最大的电子产品代工厂商，富士康在截至9月底的第三季度净利润为248.8亿台币(约合8.0552亿美元)，同比增长18.3%。该结果低于分析师平均预期的282.6亿台币。

近几日，苹果公司多家零部件供应商发布盈利预警，主要与iPhone市场需求低迷有关。受此影响，富士康和苹果公司其他几家代工厂商股价今日均出现下滑。此外有报道称，苹果公司已经告知富士康等代工厂商，要求其暂停增加iPhone XR生产线的计划。知情人士称，富士康每天要少生产大约10万部iPhone XR，与最初的乐观预期低20%至25%。

# 传宝宝树IPO募资额减幅高达八成，招股区间为6.8至8.8港元

![](../Images/cc1881913f70bd4a4bed0554a62fc801.png)

11月14日，据港媒援引接近承销团的消息，母婴电商平台宝宝树IPO集资额由市场传闻的最多10亿美元，减至约2亿至3亿美元，减幅最高达八成。招股价预计在6.8港元至8.8港元。

宝宝树原计划于本月22日在港交所挂牌，11月13日，媒体报道称，宝宝树突然取消了原定在香港举行的上市记者会。对此？宝宝树在内部邮件中解释称，是由于技术问题。不过，并未公布新的举行时间，也没有回应上市是否会延期。而接近宝宝树的知情人士向AI财经社透露，“发布会是延迟不是取消，很快就会举行”。

资料显示，宝宝树成立于2007年，是业内最早一批挖掘母婴市场的电商平台。今年6月29日，宝宝树向港交所递交招股书，计划募集8亿美元。据招股书显示，从2015年至2017年累计亏损额高达21.31亿元。

彼时，业内知情人士透露，宝宝树估值区间为160亿－170亿港元。10月25日，宝宝树在港交所通过上市聆讯，计划于11月22日挂牌上市。
