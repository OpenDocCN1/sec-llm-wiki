# 双11正式收官，天猫、京东、苏宁交易额均创新高

![](../Images/142caf79b393b42d08059ce22ff06aba.png)

11月11日24点，2018双11正式收官，天猫、京东、苏宁等都公布了各自的战绩。

其中，2018年天猫双11全球狂欢节总交易额达到2135亿元人民币，较2017年的1682亿增长了26.9%。此外，据阿里披露的数据，天猫双11全天物流订单突破了10亿，也创造了新的纪录。

京东11.11全球好物节自11月1日00:00开始至11月11日24:00，累计下单金额超1598亿，创历史新高；苏宁官方宣布11.11期间全渠道订单量增长132%，小米今年则打通了线上线下，将线上7大平台与线下上千家门店一起奋战双11，最终新零售全渠道支付金额创下52.51亿元新纪录。

英国媒体《镜报》报道称，“双11”已经超过西方传统购物节日“黑色星期五”，成为全球最大的购物狂欢节。

# 传FF员工网上筹款自救，计划两周内筹款5万美元

![](../Images/0c41f2376f58560ae21c26cd62cf78b1.png)

据第一财经报道，日前有记者在众筹网站Go Fund Me上找到了法拉第未来发起的一项“Futurist Manufacturing Family Fund”的筹款。该项目已经发起9天，截至11月11日，获得了来自40人次超过2.1万美元的捐赠，项目计划两周内筹得款项5万美元。

据了解，Go Fund Me是美国最大众筹网站，类似于中国的“水滴筹”。根据网站上的公开信息，项目介绍称，由于法拉第未来的资金危机，公司采取了裁员和“停薪留职”的措施，该项筹款旨在帮助生产团队急需资金支持的员工。

捐款由法拉第未来工具和设备部门管理人员赫克特·帕迪拉发起。此前已经宣布离职的FF全球制造高级副总裁Dag Reckhorn向该项目完成了其承诺捐助的1万美元。Reckhorn分别在11月3日、4日和5日三天内捐赠了三笔4500美元、4500美元和1000美元的款项，并表示：“帮助真正需要帮助的员工。”

# 微信回应平台内容低俗、抄袭刷量等乱象：将进一步加强审核、清理违规信息

![](../Images/e49c934c1637fcc13fd7655842a2acdc.png)

11月10日，微信公众平台发表公告，针对低俗内容，针对网络谣言的传播，针对抄袭及侵权，针对“刷量刷粉”等乱象一一作出了回应。

公告称，一直以来，微信对损害内容生态、严重影响用户的阅读体验的行为严格治理。　接下来，微信将进一步加强内容及资质审核、清理违规信息，完善举报受理机制。

公告还披露了2018年来微信公众平台对不良内容的处理情况。其中封禁及处理发送色情暴力类内容的帐号38761个；封禁及处理发送低俗类内容的帐号115540个。同时，2018年至今，已辟谣文章10.5万篇，删除公众号谣言文章近10521篇；已处理涉及“抄袭”的投诉接近8万单，处理了涉嫌侵权的帐号5万个，处理涉嫌侵权的文章接近3万篇。

# 三星宣布：折叠手机已经在大规模量产，2019年上半年将全面入市

![](../Images/e37f11848b4e6aca1eeee10f7fd5dded.png)

三星公司近期近期动作频频，日前，三星突然宣布其折叠手机已经在大规模量产，2019年上半年将全面的进入市场。

据了解，该款折叠手机主屏幕是一块7.3英寸可折叠柔性屏，可当平板电脑使用，而折叠时，使用外屏幕。外屏幕是一块21：9的4.58英寸屏，跟普通智能手机一样，折叠后可放在口袋中。

业内人士认为，三星的这款折叠手机一旦面市，将对平板电脑带来一定程度冲击。也有分析人士表示：“从三星近期的动作来看，其在中国市场的手机策略已经非常明显。三星有意在原本薄弱的中端市场进行弥补，并借助运营商力量大规模发力超高端领域，同时三星还在为折叠手机、5G手机做深度布局。5G将成为未来两年中国手机市场的竞争格局的变量。”

# 国家邮政局：双11当天全国处理4.16亿快件，创历史新高

![](../Images/fcebd4df18d1fc61eb18d94184a9da3f.png)

国家邮政局数据显示，国家邮政局数据显示，11日当天全国主要电商企业全天共产生快递物流订单13.52亿件，同比增长25.12%；全天各邮政、快递企业共处理4.16亿件，同比增长25.68%。预计11月11日至16日期间，全行业处理邮件、快件业务量将超过18.7亿件。其中，11、12日两天将出现网络压力峰值，最高日处理量可能达日常处理量3倍以上。

据新京报报道援引北京市邮政管理局相关负责人观点称，北京已由快递输出城市转变为输入城市，今年前九个月，进京量比出京量多出1.3亿件，特别是中心城区的投递业务占比持续上升，占全市比重的71%。

此外，“双十一”期间，邮政及快递相关企业新增临时用工9625人，增配快件处理及临时存放场地19.2万平方米，新增或租赁快递车辆2450台。该负责人还称，“双十一”过后，“双十二”、圣诞节、元旦、春节等一系列节日，会使业务旺季持续96天。

# 苹果公司：部分iPhone X显示器可能会出现触摸问题，官方将免费更换

![](../Images/e1275594402487e283fa60784f55f2eb.png)

11月10日消息，苹果公司发布公告称，由于iPhone X显示屏模块上的某个组件可能会出现故障，部分iPhone X的显示屏可能会出现触控问题。触控问题的具体症状有：1. 显示屏或显示屏的一部分不响应或间歇响应触控操作；2. 即使没有进行触控操作，显示屏也会作出反应。

对此，苹果将会为符合条件的设备免费更换显示屏模块，之前因此问题产生的维修费用苹果也会退回给用户。

苹果还在公告中提到，此项维修计划将为受影响的iPhone X用户提供三年的保障措施。此外，苹果还表示部分13英寸MacBook Pro固态硬盘（SSD）设备也存在问题。

# 蘑菇街提交上市招股书，拟募资2亿美元，腾讯为第一大股东

11月10日，蘑菇街向美国证券交易委员会提交了招股说明书。文件显示，蘑菇街计划通过IPO交易筹资最多2亿美元，拟在纽约证券交易所上市。主承销商为摩根士丹利、瑞信和华兴资本。

资料显示，蘑菇街上线于2011年，2016年，蘑菇街与美丽说合并。截至2018年9月30日，蘑菇街平台上月度移动端活跃用户为6260万，主要为年龄在15至30岁之间的年轻女性；同期，平台上拥有超过48000名时尚达人，活跃着超过18000名时尚主播。

蘑菇街的收入主要由三大板块构成，分别是营销服务收入、佣金收入和其他收入。据招股书披露，2019财年上半年（2018年4月1日-2018年9月30日），蘑菇街营收为4.89亿元人民币，同比增长1.9%，净亏损3.03亿元，去年同期净亏损为4.28亿元。

此外，招股书还披露了主要股东的持股情况，腾讯为蘑菇街第一大股东，持股18%。
