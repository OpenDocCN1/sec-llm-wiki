# 最适合锻炼编码技能的10个最佳编程游戏！

一旦你知道本身要做甚么，编程就很诙谐，但达到这一点，可以或许是一次疾苦的经历。

这就是为甚么在上课、听讲座、看教程之间，你该当留出工夫玩一玩编程游戏。它们不只是诙谐的抓紧手段，还能让你切身实际，多么你会学得更快，记住更多常识。

Robocode

![](../Images/8dcfe277bfd3e9eb694ff3a5a066d02f.png)

Robocode是个复杂的编程游戏，在这个游戏中，你可以编写机械人坦克的代码，让坦克们彼此博弈。你要用Java、Scala、C#等编程措辞，编写人工智能法度典型，驱动机器人。

Robocode装配法度典型附带开辟状况，内置机械人编辑器和Java编译器。你写的是真实的代码！固然Robocode早在2000年就颁布发表了，但它仍然按期更新和保护，因为它是开源的。

Codingame

![](../Images/b90d7ff85d5cba3e4f47d7c85ff4d495.png)

Codingame是一款类似游戏的Web应用法度典型，经过过程编写真实代码来措置困难和挑衅。撑持超越25种编程措辞，包含Java、C#、Python、JavaScript、Lua、Go、Rust等。每个困难或挑衅都有一个主题，例如，编程炮塔击落邻近的飞艇，是不是是很诙谐？

Codecombat

![](../Images/f4fed53b6916121564ae4aba76a29ad6.png)

Codecombat也是一个用于像游戏的谜题挑衅类Web应用法度典型，只能经过过程编写代码来措置。不过Codengame更有文娱性，Codecombat有很强的教育意义，它有一个“教室版”，师长教员可以用来帮助师长教师进修编码。今朝有3种课程可供选择:计较机迷信、汇集开辟和游戏开辟。

Codewars

![](../Images/061b225f42f991ca2f69c386d707e285.png)

Codewars与其说是游戏，不如说是一种演习编码和措置算法挑衅的游戏化进修编制。措置结果后你可以获得必定点数，点数值取决于你的措置经营的效能。Codewars许可你查抄他人提交的措置经营，便当进修和自创。

Codehunt

![](../Images/0f6961a5f980f5b81415098a3c0735fe.png)

Codehunt是一种可以应用Java或C#来玩的游戏。它的目标是教你学会编程措辞的根基常识，从操练末尾，到轮回和字符串等主题，最后是排序、暗码和编程困难等挑衅。Codehunt的诙谐的地方在于，它没有通知你若何博得每项挑衅。

Vim Adventures

![](../Images/f78bbad1b5c929a0bbb5f758c5834b71.png)

Vim Adventures是一个诙谐的类似游戏的教程，用于进修若何应用Vim，这是一个功用极端弱小大年夜的文本编辑器，很多编程专家都爱好用。可是，它不随便学，这就是为甚么有多么的教程。当然Vim本身不是一种编程措辞，但节制Vim可以帮你更高效地编码。

TIS – 100

![](../Images/23678bf88de884ee991d9e52e1a5e96f.png)

TIS - 100是一款与众不合的视频游戏，它迫使你进修并应用摹拟的初级汇编代码来措置编程困难。这个游戏很难，它是开放式的，只需你没有怒到卸载它，就会发现它的价值。

Shenzhen I/O

![](../Images/957e738681bf0154a7e3856c39b4cbb5.png)

Shenzhen I/O 与TIS – 100同属一家任务室的作品，这是一款益智游戏，你的义务是创建简化版电路，并编写电路上运转的简化版汇编代码。与TIS – 100对比，Shenzhen I/O更随便学，更令人欢愉，不过也异常复杂。

Human Resource Machine

![](../Images/75f44001b8d1c5aa14b90a31bc867bfe.png)

在Human Resource Machine中，你要扮演一名办公室任务人员，经过过程将各类指令组合在一路来完成义务。从某种意义下去说，这款游戏恳求经过过程可视化编程来措置困难，乃至触及了逻辑流程和内存办理等概念——但以易于知道的、以办公室为主题的编制呈现。这是一个熬炼法度典型员大年夜大年夜脑的好游戏。

Screeps

![](../Images/805e7b28a44848b790f66e6484ce6be2.png)

Screeps是一款大年夜大年夜型多人在线计谋游戏，你要应用JavaScript来编码游戏中实体的行动，并为本身建立一个帝国。
