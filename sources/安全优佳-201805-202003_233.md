# 苹果要完全放弃英特尔采用ARM 真的吗？

据外媒报道，现在网上越来越多的人推测苹果即将在其Mac产品线中放弃使用英特尔芯片，而全面使用基于ARM的处理器。

![](../Images/d6006a6669c1135295506945eed189d5.png)

甚至有业内人士预测，苹果将在2020年或2021年全面放弃英特尔芯片转而购买ARM芯片。

![](../Images/b2276162acebb46de741fdf155e267ad.png)

ARM芯片

一些分析人士则表示，苹果公司如能实现这一目标，结果将非常有意义，因为将能够节省大量的成本。到时潜在的芯片供货瓶颈将不复存在，苹果亦可按照自己的意愿随意控制并升级硬件。

外媒Extreme Tech则认为，苹果考虑转芯片的另一个原因可能是英特尔在14nm和10nm制程路线演进方面遇到了困难。

然而英特尔未对此事给予任何评价。同时英特尔公司宣布已经开发了3D晶体管技术，该技术将会在消费级平板电脑和智能手机市场优于ARM。

不过，鉴于微软Windows 10已能在ARM上运行，虽然性能表现不如在英特尔上运行那么好，但随着ARM芯片变得更快、节能和更便宜，恐怕距离上述推测实现就不远了。
