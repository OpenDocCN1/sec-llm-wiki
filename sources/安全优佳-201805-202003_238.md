# 58同城虚假信息涉诈骗金额或超百万，每天投8亿广告费求转型

![](../Images/ab7cda3320a402fbc8a5208bab6d5604.png)

近日，58同城出现招聘虚假信息一事再度被媒体提及，据《投资者报》消息，58同城网站存在大量虚假信息，这些信息导致用户受骗，受骗者被骗金额从730元~1890元不等，涉嫌诈骗金额或超数百万。

58同城已经多次被曝光存在虚假信息，今年6月，58同城、赶集网因存在招聘陷阱，有5500余名被害人共计被诈骗上亿资金，甚至有人因此落入诈骗集团的陷阱。

对于存在虚假信息一事，58同城方面也多次表态回应，但是猖獗的虚假信息屡禁不止。

据投资者报报道，出于转型的目的考虑，58同城董事长兼CEO姚劲波曾表示：“我们将持续加强对新业务和主营业务的投入，以确保长期发展的领先优势，进一步抢占市场空间。”

公开数据显示，2018年上半年，58同城广告费耗资1535亿元，相当于每天花费8亿多的广告费。不知广告费的增加对于58同城而言是否能够真正达到转型的目标。

# 马蜂窝回应1800万“真实点评”全是抄袭：对涉嫌虚假点评帐号做清理

![](../Images/57b820bd0e9df3071f4c973b5d6f2420.png)

10月21日，一篇《独家|估值175亿的旅游独角兽，是一座僵尸和水军构成的鬼城？》刷屏网络。

这篇数据分析文章指出，成立于2006年、已获得4轮融资的马蜂窝旅游，2100万条点评中有1800万条是抄袭的。

10月22日，马蜂窝官方进行了声明。该声明表示，马蜂窝网站上有关本地服务的评论仅占总体数据的2.91%，虚假数据微乎其微。在马蜂窝上，核心数据为游记攻略，占比高达78.91%，谢谢游记攻略绝大部分是用户原创。因此自媒体文章存在误导倾向。

AI财经社此前联系到发布这篇文章的微信账号“小声比比”创始人梓泉，他告诉AI财经社，关于马蜂窝数据造假一事，是乎睿数据团队在4个月以前发现的，马蜂窝“数据的活跃曲线有很明显的爆发和消失”，它的用户增长曲线波动不太正常，搬运和抄袭的现象非常严重，而且非常拙劣。“我们已经把抄袭的标准定得非常严格，间或性抄袭是不算抄袭的。比如我把三条点评拼起来变成一条。”梓泉说。

梓泉高速AI财经社：我们不是说，抄袭了一个其他平台点评账号留言，就定性为抄袭。我们是把一个抄袭了150个不同的大众点评账号的马蜂窝账号定为抄袭的。为了避免用户有两个账号，在大众点评发，也在马蜂窝发。但是你如果与150个大众点评账号的内容都……可以认为你是有意的，是吧？

# 北京中介协会：针对个别企业续租涨价问题已展开调查，企业违反承诺续租涨价将被处理

![](../Images/c2ce55ec6be197b2af61430a35fe017b.png)

澎湃新闻消息，近日，有媒体报道了个别企业续租涨价问题，10月21日，北京市房地产中介协会表示，该协会已经开展调查，将按照协会章程对违反承诺的企业进行处理。

北京房地产中介行业协会香港负责人表示，到10月20日，10家公开承诺2个月内投放12万套（间）不涨租金房源的租赁服务企业，已累计投放房源133131套（间），完成公开承诺总量的1.1倍。

8月20日，北京房地产中介行业协会组织十家租赁企业公开承诺在2个月内投放12万套（间）不涨租金房源，到9月20日十家企业共投放房源69110套（间），时间过半，完成任务过半。相关负责人介绍，环比9月，北京住房租赁市场量、价继续回落，成交量环比下降约8%。

在租金方面，“自如”整租的租金环比下降5.5%，“相寓”租金环比下降4.3%，“蛋壳”租金环比下降0.1%。“各企业出租房屋的空置期均有拉长，收房日趋谨慎。”该负责人表示。

# 苹果租赁硅谷大型仓库：或为研发苹果汽车做准备

![](../Images/588a314e329deb216f893722d25cc181.png)

腾讯援引外媒消息，报道称苹果在硅谷米尔皮塔斯市租下了一个面积达31.4万平方英尺（约合2.9万平方米）的仓库，租期10年。有消息称，苹果此举是为了造车计划做准备。据了解，这块地的属性为“工业生产用地”，网传苹果租用这块地的租金为每平方英尺90美分（约合每平方米10美元）。

# 映客上市3个月股价跌46%，CFO：望投资者多点耐心信心

![](../Images/cc84ce192e9e430d3d5a7e29eab19343.png)

《证券日报》消息，统计数据发现，从港股市场来看，以映客为代表的科技股跌幅靠前。如果按上市首日收盘价计算，截至10月19日，映客的股价跌幅深至46.01%。

有业内人士指出，“映客股价持续走低，与当前直播行业整体表现不佳且用户流失严重、映客本身营收结构单一等原因有关。”

今年7月12日，映客在港交所正式挂牌，发行价为3.85港元/股，截至10月19日收盘，其股价为2.30港元/股，较上市首日收盘价跌幅已达46.01%。

10月10日，映客CFO李劲在第三届香港中资券商首席论坛上坦言，“市场中有一种观点认为直播过气了，我们的看法则完全不一样，借鉴视频网站行业的发展历史，对于直播行业，我们也希望投资者可以多点耐心和信心。”

# 三星将和NEC展开5G合作，或为抗衡中国厂商

![](../Images/f6f37416912fc73f52356f7f5c6aa58e.png)

IT之家援引《日本经济新闻》消息，三星电子已经与NEC就研发5G次世代无线通讯规格的基站达成了合作协议，内容涵盖产品开发、销售等方面。有消息称，三星此次与NEC的合作目标将产品拓展至美国，日本，中国等受限制的市场。

# 中国联通公布前三季度业绩预告：利润总额约105亿元

![](../Images/fc365ab8728233f38938d1876fd0d2bb.png)

新浪科技消息，中国联通今日发布2018年首三季度业绩预增公告。公告显示，在今年前三季度（2018年1月1日至2018年9月30日）中，公司利润总额预计约105.46亿元人民币，同比增长约95.9%；归属于上市公司股东的净利润预计约34.70亿元人民币，同比增长约164.5%。

公告表示，中国联通发生税前非经常性损失预计约29.22亿元人民币。扣除该项非经常性损益事项后，联通在2018年度首三季度利润总额预计约134.68亿元人民币，同比增长约106.8%，归属于上市公司股东的净利润预计约44.64亿元人民币，同比增长约179.9%。

# 区块链工程师平均年薪超15万美元，超AI专家

腾讯援引外媒消息，美国旧金山专门帮助客户招聘技术人员的公司Hired发布全球统计数据显示，区块链工程师的平均工资在15万到17.5万美元之间。Hired表示，这比普通软件工程师的平均年薪（13.5万美元）要高出很多。

拥有区块链专业技能的工程师薪水与专攻人工智能（AI）的开发人员相当，但比其他任何专业的工程职位都要高。到2017年底，Hired已经将区块链列为其服务榜单中，从那以后，该公司发现招聘区块链人才的职位需求增加了400%。Hired首席执行官梅胡尔·帕特尔(Mehul Patel)说：“对区块链人才的需求非常高。软件工程师已经处于极度短缺状态，而区块链领域这种情况更加严重，这就是为何他们薪水更高的原因。”
