长期以来，Github 一直就是储存源代码和进行分享的平台，如今，已被微软招致麾下的 Github 似乎正在打破自己的边界。

在 10 月 16 日的年度 GitHub Universe 大会上，Github 发布了一次重要的版本更新，推出了 GitHub Actions：允许使用者直接运行部分代码。

作为世界最大的源代码托管和分享平台，一直以来，开发者一般只在 GitHub 上进行简单都是上传、搜索和下载代码，而当我们需要测试 GitHub 上的一个项目时，则必须要下载到本地才能进行。

GitHub Actions 的推出将会改变这一情况，它提供给了开发者一种自动管理代码的工具，包括进行测试和其他技术支持。

GitHub 平台负责人 Sam Lambert 将此次更新称为“GitHub 史上最大的一次转变。”他将其比作是 IOS 中的 Shotcuts，只不过 GitHub Actions 的功能会更加灵活。Lambert 表示：“想象一下，所有开发人员在 github 平台上，可以快捷方便的通过一个触发动作，自动化其工作流程”

目前，包含了新功能的测试版已经放出，包含了450个预设的 action ，开发者也可自建新的 action ，或使用Docker 绑定现有程序在 GitHub 上运行。

测试版地址：https://github.com/features/actions

除了这一重量级更新，此次 GitHub Universe 大会还公布了 2018 年的 GitHub 年度报告。

报告显示，近三年来，Contributors 数量最多的六个国家在排名上没有发生变化，分别为美国、中国、印度、英国、德国和加拿大。同时，报告强调了亚洲是今年提交代码数量增长最快的地区，且在 2018 年的 9 月底，亚洲开源项目数量已超过其他任何地区。

图丨Contributors 地区排名：中国稳居第 2 （来源：GitHub）

在对开发者组织的统计中，可以看到微软以较大的优势稳居第一，而最近入股 GitLab 的谷歌则排名第二，这些较活跃的组织包括了公司、学校等多种组织。

图丨Contributors 组织排名（来源：GitHub）

对开源项目的统计中，微软推出的 vscode 依然坐稳头把交椅，react-native 和 tensorflow 继续稳居前三。

图丨开源项目数量排名（来源：GitHub）

报告指出，今年增长最快的开源项目更多地集中在机器学习、游戏、3D 打印、家庭自动化、科学编程和数据分析等领域。

在数百种语言中，JavaScript 依然是使用人数最多的语言，这一情况在不同的项目、组织和地区都保持了一致。在今年排名前十的语言中值得关注的是，TypeScript 在去年首次进去前 10 后，在今年再次跃进排到第 7 位。
