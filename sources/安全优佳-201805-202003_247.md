# 美国某购物网站遭黑客猛烈攻击，造成650万用户数据泄露

近日，美国在线时尚零售商SHEIN承认，国际知名黑客窃取了近650万客户的个人身份信息（PII）之后，该公司遭遇了严重的数据泄露。SHEIN总部位于德国北不伦瑞克，成立于2008年，已成为全球80多个国家最大的在线时装零售商之一。该网站最初旨在为女性生产“实惠”和时尚的时尚服装。

![](../Images/00f6288d8bafe4df4fe934461a352a2e.png)

SHEIN上周末透露，其服务器已成为今年6月开始的“协同犯罪网络攻击”的目标，并持续到8月22日，当时该公司终于意识到潜在的盗窃行为。此后不久，该公司扫描其服务器以删除所有可能的后门入口点，利用哪些黑客可能再次渗入服务器。SHEIN向客户保证，该网站现在可以安全访问。

![](../Images/3b4e0447128621eb2acf5780911d9160.png)

黑客窃取了超过640万的SHEIN客户数据，虽然有关此事件的详细信息很少，但在线零售商透露，恶意黑客设法窃取了在其网站上注册的642万客户的电子邮件地址和加密密码凭证。SHEIN负责人说“虽然攻击的全部范围将继续受到调查，但现在可以确认入侵者非法获取的个人信息包括访问公司网站的客户的电子邮件地址和加密密码凭证”。

![](../Images/b28c883a9ba9cb78e5a3a6ca166fd1c5.png)

然而，该公司表示，它通常不会在其系统上存储任何信用卡信息，并且目前没有证据表明其客户的任何信用卡信息都来自其系统。你受影响了吗？这是用户应该做的事情，在意识到这种潜在的盗窃行为后，SHEIN立即聘请了一家领先的国际法证网络安全公司和一家国际律师事务所，对这一违规事件进行彻底调查。该公司已经开始联系所有受影响的客户，并要求他们更改其在线商店帐户的密码，方法是单击SHEIN电子邮件通知中提供的链接或直接登录他们的SHEIN帐户以更改密码。
