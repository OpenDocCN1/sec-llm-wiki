# 软件更新需谨慎：「挖矿」恶意软件伪装成Flash更新

现在互联网非常的便捷，像是网购什么的，或者是足不出户就能赚钱等等，而网络安全也是重中之重。近日伪装成 Flash 更新程式的恶意软件向来变化多端。近日一家网络安全机构发现一种新的恶意软件，伪装成 Flash更新程序，而实际上就是加密货币的挖矿程序，占用电脑资源为黑客赚钱。

![](../Images/96a9a0d74a12bd55945b713bd6a2996e.png)

网络安全机构 Palo Alto Networks 发现，有个新的伪装成 Flash更新程序的恶意程序，8月份左右开始在网络上传播，这个程序内含 XMRig 挖矿程序，会暗中使用电脑资源来取得 Monero 加密货币。据称这款恶意软件虽然会触发 Windows 对未知来源软件安装的提示，不过由于伪装程度较高，更新程序的仿真度较高，不注意的玩友们很可能就会忽略提示继续安装恶意软件。

利用伪装的文件来暗中安装挖矿软件的情况在近几年变得流行，从电脑到手机都有发现相关的恶意软件，因此对未知来源的安装程序和文件都要特别小心注意，以免自己的电脑被黑客恶意使用。
