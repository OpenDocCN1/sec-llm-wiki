# 微软解释1809版Window10，为什么会删除个人文件

微软暂停了2018年10月Windows 10更新推送，因为它会删除了一些人的文件。如今，微软已经解决了这个问题并解释了为什么会产生这个Bug。

微软的John Cable在微软Windows博客上的帖子中所解释的那样 ，问题在于“已知文件夹重定向”功能。此功能允许你将 C： Users Name Downloads等已知文件夹移动到D： Downloads。你也可以移动其他文件夹包括桌面，文档，图片和视频。

在2018年4月更新之后，之前使用此功能的一些人发送报告说在原来的文件夹下会产生一个额外空副本文件夹。例如，在原始C： Users Name Downloads文件夹会出现一个空的Downloads-副本的文件夹。因此，为了解决这个问题，微软推出了可以删除那些旧的空文件夹的代码。

所以就存在一个问题：代码会删除这些文件夹，即使文件夹不是空的。因此，如果你将“下载”文件夹移动到D： Downloads但仍有一个包含文件的C： Users Name Downloads文件夹，则2018年10月更新的Win10会将原始文件夹以及其中的文件都删除了。

微软现在已经修复了这个问题，最新版本的Win10正在向Windows Insiders进行额外测试，然后再向Windows 10用户进行推送。
