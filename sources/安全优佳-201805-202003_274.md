# 西数My Cloud曝安全漏洞 攻击者可获得完整访问权限

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzcwMTU1Ng==&mid=2649522486&idx=3&sn=5c9f12e634210a89d7dc299f987575ba&chksm=871320edb064a9fb58f5597b80f58dadb564ae875af17ea2d5722ae602502314f4aef90a9ce1&scene=126&sessionid=1681368027#rd](http://mp.weixin.qq.com/s?__biz=MzA3MzcwMTU1Ng==&mid=2649522486&idx=3&sn=5c9f12e634210a89d7dc299f987575ba&chksm=871320edb064a9fb58f5597b80f58dadb564ae875af17ea2d5722ae602502314f4aef90a9ce1&scene=126&sessionid=1681368027#rd)

西部数据（Western Digital）广受欢迎的 My Cloud 系列网络附加存储（NAS）设备，近日曝出了一个严重的安全漏洞，导致攻击者可以完全访问设备里的内容。荷兰安全研究员 Remco Vermeulen 刚刚分享了有关该问题的“特权提升攻击报告”，另一位同行亦表示早已披露了其它攻击的详细信息，但西数迄今未给出固件更新。

![](../Images/896537a43b40f36b4e5fc420d3fea0d2.png)

Remco Vermeulen 指出：身份验证绕过漏洞允许攻击者在登录设备之前获得管理员权限，他们只需创建反向 shell，便可访问驱动器上的用户文件。

![](../Images/65bada9d3bff1952c58d25c53dfef987.png)

如果设备所有者已经启用了远程访问，那么在面向互联网（Internet）的远程连接上也存在此漏洞。

![](../Images/f33480b28d52af236dfc9459ca7f937b.png)

作为一款众所周知的 NAS 设备，西部数据的 My Cloud 系列屡次因安全问题而登上报端。漏洞利用者再次证实了这一事实，称其也向西数汇报了同样的漏洞，甚至纪录了整个过程。

![](../Images/c6beb7ab16023db654db42d82062cb62.png)

发稿前，西数工程师团队终于给出了回应，表示他们将在定期的固件更新中解决问题，并建议客户与支持团队取得联系。

WD My Cloud security flaw（via）

西数在博客文章中披露，许多使用 Dashboard Cloud Access 的设备仍然容易受到攻击，包括 My Cloud EX2、EX4、Mirror、PR2100、PR4100 等。
