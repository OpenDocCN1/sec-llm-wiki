# 针对美国断网战略威胁，中国加快布局下一代互联网工程，准备

自从智能手机出现以后，网络可以说是与现在人们离不开了，网上购物，网络游戏，微信等社交软件，紧紧围绕着人们的生活。

![](../Images/27436807a8da6cdcef75f4f70144b654.png)

我们现在使用的第4代互联网协议（IPv4）最多只能提供40亿个可用IP地址，当时美国掌握着互联网的话语权，北美占据了全球3/4的IP地址，我国虽然有近10亿网民，却只分配了3.38亿个IP地址，人均仅0.3个。

互联网协议IPv4第四版体系中，全球只有13台根服务器，其中10台在美国，除了1个为主根服务器，其余9个为辅根服务器；另外3个辅根服务器分别在英国、瑞典和日本。13个根域名服务器可以指挥Firefox或Internet Explorer这样的Web浏览器和电子邮件程序控制互联网通信，全球对美国互联网的依赖性非常大，美国通过控制根服务器而控制了整个互联网。

最近美国废除了网络中立规则，因为控制着全球的互联网服务器，针对这样的事情，就有人担忧表示，中国10亿网民正处于蓬勃发展时期，美国随时可以切断中国网络，这极大引起了人们的恐慌，虽然从理论上来讲，美国是能威胁到中国网络，但是事实上就对中国网络的威胁是十分有限的。

根服务器都是由美国的组织（如商业机构，研究所，大学）运营，并受ICANN管理，不过ICANN已经和美国签好协议，不能在直接干预其运营，所以除非美国使横手或者不怕那冗长的法律申请，基本上美国没太多控制权。那么中国只能分配到根域的镜像，事实上中国有能力研发一套根服务器的模拟镜像，以此来将"断网"所带来的负面影响。

![](../Images/f65c4a3a520f4e720834539b8f90de95.png)

可是互联网第四版网络协议中现在仅安排13个根服务器，难以再新增，中国没有根服务器，这与中国作为全球互联网用户数最多的国家的地位不符，也不利于对网络安全的自主可控。

现在中国正在加快部署基于IPv6的下一代互联网，积极参与全球下一代互联网体系建设。有专家表示，IPv6将为解决网络安全问题提供新思路，有助于实现我国走出互联网“无根”困局。

![](../Images/73216f394a736fe09db7c8036121e4c6.png)

互联网协议第六版也就是IPv6的规模部署加速。工信部信息通信发展司昨天下午召开IPv6规模部署及专项督查工作全国电视电话会议。根据中办、国办去年联合印发的行动计划，2018年我国IPv6活跃用户数要达到2亿。

我国大力发展下一代互联网，有助于提升国家信息安全和自主创新能力，充分发挥物联网、工业互联网、云计算、人工智能等技术飞速发展。
