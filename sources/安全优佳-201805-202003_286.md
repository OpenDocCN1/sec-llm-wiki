# 蔚来汽车股价大涨75.76%,市值119亿美元，成立至今未盈利

![](../Images/64ec67d4c84c5cca6dbd7a2c43af74e9.png)

蔚来汽车（纽交所证券代码：NIO）上市第二天股价大涨5.00美元，涨幅75.76%，报收于11.6美元，市值达119亿美元。该公司股价盘中最高至12.69美元，创上市新高。

蔚来汽车于美国当地时间9月12日正式在纽交所挂牌上市，开盘报价6.26美元，发行1.6亿股ADS。融资金额约为10亿美元，估值约为64亿美元。上市首日，蔚来汽车盘中曾一度破发，跌至5.35美元。

据蔚来汽车招股书显示，公司成立至今尚未实现盈利。截至2018年6月30日，蔚来汽车净亏损人民币33.255亿元（约合5.026亿美元）。

据了解，在首次公开募股之后，李斌共持有蔚来汽车148,689,253股股票，按照周四收盘价计算，李斌所持股票的市值已超过16.6亿美元。

# 拼多多股价暴涨30%创新高，高盛称其靠腾讯正处于极佳的位置

![](../Images/fcadd2378d316e70d56122a5a884297c.png)

中国电商公司拼多多（纳斯达克证券代码：PDD）周四股价暴涨30%，创出上市以来的新高。据腾讯科技援引外媒消息报道，拼多多此次股价出现大涨原因是受到投行高盛一份研报的影响，在研报中，高盛称拼多多是目前全球营收增速最快的互联网公司，并建议投资人买入拼多多股票。

腾讯科技援引外媒的报道显示，高盛分析师Piyush Mubayi在研报中称，拼多多凭借自家应用和大股东腾讯的社交网络，正处于极佳的位置，从中国电商市场的持续增长中受益。

拼多多上市至今股价出现多次大起大落，一个重要原因是其受到售假问题的舆论影响。

美国东部时间7月26日，拼多多在纳斯达克挂牌上市，上市后，拼多多屡受“假货”问题的质疑。此前据每日经济新闻的报道，拼多多IPO首日股价曾暴涨40%后，随后，因受到“山寨假货”的质疑，在5个交易日内股价累计下跌约27%，市值也曾一度蒸发50亿美元。

# 微信的捂脸表情的商标被抢注，腾讯：法定期限内提出异议申请

![](../Images/fbdfa25ce703b9569a074c3a30bcda70.png)

近日，微信的捂脸表情的商标被浙江义乌人金召平抢注一事引发热议，上游新闻消息显示，去年11月21日，浙江义乌大陈镇的金召平申请注册捂脸表情，该商标为25类，核定使用商品/服务项目包括：T恤衫；服装；衬衫；婴儿全套衣；鞋；帽；袜；手套（服装）；领带；围巾等。

国家商标局在8月13日发布了该商标的审定公告，异议期限为2018年8月14日至11月13日。

9月13日，腾讯公司回应上游新闻记者表示，微信日常小黄脸表情系列表情中捂脸表情由三四个设计师历时五个月所完成，“腾讯将在法定时限内对该商标提出异议申请。”

江苏圣典律师事务所吴庭祥律师接受采访时表示，“如果腾讯公司能够证明捂脸表情属于其公司员工的职务作品，可以就此提出异议，而且成功率会比较大。”

# 自如甲醛门发酵： 其委托第三方检测机构不具资质

![](../Images/609f02fff41d765ae8d49d4ee913baa5.png)

第一财经日报消息，自如“甲醛门”事件又有了新进展。近日，深圳市场监管部门检查发现，深圳自如公司委托的一家第三方空气检测机构不具有CMA（ChinaMetrologyAccreditation，中国计量认证）认证资质。

9月11日上午，深圳市市场稽查局执法人员会同深圳市计量质量检测研究院的技术专家，对给自如出具检测报告的斯凯希公司以及使用检测报告的自如公司，进行执法检查。经现场检查，发现斯凯希公司不具有CMA认证资质。

目前，深圳市市场稽查局已对斯凯希公司涉嫌无资质出具检测结论立案调查。同时，自如公司也被责令不得委托无资质机构检测空气质量，不得使用非正规检测数据误导消费者。

# 乐视网复牌首日跌停 贾跃亭股份减少遭问询

![](../Images/aedb5dae1a1ce1eb0a9e0dbbf1d292ac.png)

乐视网自9月6日开市起停牌核查，此前已出现连续五个交易日涨停的情况。9月13日，乐视网复牌后，开盘便近乎跌停，并于当日封跌停板，以3.74元/股收盘。

就在复牌前夜，深交所发出了今年以来对乐视网的第十份问询函，就乐视网半年报提出了包括关于公司经营情况、贾跃亭所持股份、乐融致新、公司债务情况等在内的一共六个方面18个问题。

深交所指出，截至2018年8月28日，乐视网控股股东贾跃亭持有102257.69万股股份，占总股本25.63%，其中101953.98万股已质押，已全部触及平仓线，但截至8月28日其所持股份较6月30日减少168.97万股。对此，深交所要求乐视网核实说明贾跃亭所持股份减少的原因，该部分股份是否被司法执行划转。

乐视网方面则对《证券日报》记者表示，对于深交所问询中提到的问题，公司会按规定进行披露。

# 华为辟谣将被国资收购：业务分拆、剥离部分业务的传闻也不属实

![](../Images/ac1298b6c631822dbb0a23870470f629.png)

近日，有传言称华为将被“国资收购”，针对此事，华为对第一财经记者做出否认。关于业务分拆、剥离部分业务的传闻，华为表示同样不属实。

华为官网显示，“华为成立于1987年，是一家由员工持有全部股份的民营企业，目前有18万员工，业务遍及170多个国家和地区。”其中，股东会是公司权力机构，对公司增资、利润分配、选举董事/监事等重大事项作出决策，由工会和任正非两名股东组成。

今年1月9日，搜狐财经报道称，华为控股的注册资本出现，新增注册资本约15亿元，增长比例约10%。本次注册资本变更后，任正非与华为工会委员会持股比例未有变化，仍为任正非持股1.01%、华为工会委员会持股98.99%。

# 小米上市后首次调整架构，重组十个业务部全向雷军汇报

9月13日消息，雷军发布内部信宣布对公司组织架构进行系统性调整。雷军表示，小米已经成为一家营收过千亿、员工近两万人的公众公司，为保障公司可持续的发展，必须把组织管理、战略规划放到头等位置。

这是小米进行上市后的首次组织架构调整，新设集团组织部和集团参谋部，进一步增强总部管理职能，并同时调整王川、刘德、洪峰和尚进等高管的工作分工。

这次组织调整更加趋向管理扁平化，重新组建了十个业务部，直接向CEO雷军汇报。而这些业务部门的总经理以80后的年轻人为主。

# 国产厂商CEO集体吐槽新iPhone：越来越平庸

# 腾讯花1.64亿港元回购股票，马化腾说大股东三年内不再卖

9月13日晚间消息，港交所公告显示，腾讯公司当日再次回购12.4万股股票，耗资3950万元，这也是腾讯连续在第4个交易日中回购股票。腾讯当日收盘报323.8港元，单日上涨4.99%，总市值3.08万亿港元。

此前，腾讯在9月7日回购2.27万股后，从10日到12日，又分别回购了12.4万股、12.6万股及12.5万股，这意味着在过去一周内，腾讯共耗资1.64亿港元进行5次股票回购。

今年腾讯曾在3月下旬经历大股东Naspers Limited减持1.9亿股、套现769亿港元，以及总载刘炽平以平均每股434.37港元价格减持100万股、套现约4亿港元，虽然董事会主席兼CEO马化腾曾在当月的IT领袖峰会上回应称，“大股东坚守了十多年，前几天才卖了一点点，还一直说三年之内不会再卖”，但之后腾讯股票依然一路下跌。

# 传iPhone X遭下架停产，苹果回应：怎可能停产？是给渠道商去卖

北京时间9月13日凌晨，苹果举行了新品发布会，一口气推出了三款新iPhone：iPhone Xs、iPhone Xs Max和iPhone XR。

不过，新iPhone发布后，AI财经社发现，可能为了断了各位等降价买iPhone X的念想，苹果官方网站已经下架了iPhone X。有网友猜测，iPhoneX可能即将停产。

对此，苹果方面回应表示，iPhone X都是给运营商和渠道商去卖，“已停产？怎么可能。”
