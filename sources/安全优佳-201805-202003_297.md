# 滴滴等完成整改前无限期停止顺风车服务

![](../Images/f228c5f5e03ba323a66817d570c1d424.png)

10日晚间，交通运输部办公厅、公安部办公厅联合印发关于进一步加强网络预约出租汽车(以下简称“网约车”)和私人小客车合乘(以下简称“顺风车”)安全管理的紧急通知。要求各地立即开展行业安全大检查，并严厉打击非法营运行为。根据两部门的要求，各地需对从事或申请从事网约车服务的驾驶员一律进行背景核查，确保网约车驾驶员符合条件，从即日起至年底前，加快清理网约车平台上不合规的车辆和驾驶员。

交通运输部将组织交通运输新业态协同监管部际联席会议成员单位对滴滴等网约车平台公司开展安全大检查。滴滴公司等平台公司要全面开展安全隐患自查和整改工作，在完成隐患整改前，无限期停止“顺风车”信息服务。

# 百度：如遇假冒、钓鱼欺诈等网站受到损失，不设上限进行“全额”先行保障

![](../Images/803265e15956b1c1c5e832de9af9832c.png)

9月10日，百度官方发文称，当网民使用百度搜索遭遇假冒、钓鱼欺诈等问题，只要提供相关证据，百度将不设上限进行“全额”先行保障。

近日，作家六六因使用百度搜索遭遇大量广告推广，六六本人发文进行了吐槽，此后，央视又曝光了有患者使用百度搜索“上海复旦大学附属医院”的时候，被百度搜索推荐的“复大医院”误导，患者就诊后病情并未见好。两件事情发生后，百度方面再次受到了来自舆论的拷问。

在10日的发文中，百度方面对于如何使用百度搜索品牌官网、公立医院进行了解释。在百度搜索品牌名称，如“华为”、“海尔”时，结果页会显示“官网”标志，代表该网站通过了百度的官方认证；此外，经过认证的官网会展现V标，点开后可查看企业档案。

# 苹果发布会或推更贵iPhone，售价或达1100美元

![](../Images/976765606f1162d0bf985b6b77316e26.png)

据《第一财经日报》消息，苹果新品发布会即将举行，有消息称此次苹果将一口气推出三款不同型号价位的iPhone新品，这三款iPhone将全部采用带有“刘海”的全面屏设计。

据业内媒体预测，三款新品可能分别是两款不同尺寸的OLED全屏机型（5.8英寸和6.5英寸，或取名iPhoneXs），其中5.8英寸的机型预计是现iPhoneX的升级版，6.5英寸的机型则是大屏版iPhoneX，另一款是配有6.1英寸LCD液晶屏的低端机型（或取名iPhoneXc）。

这几款机型的售价很可能高于此前分析师的预期。其中，旗舰机型iPhoneXs的售价或达到1100美元，比去年发布的iPhoneX售价再贵100美元。

苹果分析师郭明琪表示，这三款手机都将配有深度摄像头和面部识别功能。这也意味着人们开启手机将不再需要指纹识别功能。如果实现，那么使用长达11年的苹果Home键可能真的要退出历史舞台了。

# 腾讯将回购3900万港元股票，已是连续两日回购

![](../Images/e5d371a9ae4978e0165c45584158bbf0.png)

# 小米获得日本最大运营商DoCoMo电信专利授权

![](../Images/6f795250a79e9ede6d8e75ab3706b5af.png)

据外媒最新消息，小米日前和日本最大的移动通信运营商NTT DoCoMo公司就专利授权协议达成了一致。

据国外科技媒体MobileWorldLive报道，DoCoMo公司已经就一个全球性的专利授权协议和小米公司达成了一致，授权的专利涉及该公司持有的通信“标准必要专利”。

所谓的“标准必要专利”，指的是某些公司研发的专利技术被纳入了行业技术标准，比如全球的4G、5G技术标准中就包括了许多公司研发的专利。而根据国际惯例，标准必要专利的持有人，必须公平公开、以合理的费用向所有的企业提供这些专利授权。

对于此次的专利授权协议，小米公司支付了多少专利费，尚不得而知。

# 上海执法整治网约货运平台，货拉拉已对首批无双证司机封号

![](../Images/4fa21bcd6e652d9a9c9ca18a4c3071b5.png)

澎湃新闻消息，记者从上海市城管执法局获悉，今年8月初，上海市城管执法局牵头召集市交警总队、市交通执法总队联合约谈了“货拉拉”、“58速运”等网约货运平台负责人，要求平台就经营中存在的问题，依法依规限时整改。

9月10日上午，三部门执法人员至虹漕路421号货拉拉办公地以及江场西路299弄快狗打车办公地进行执法检查。目前，货拉拉已对确定无双证的第一批司机做封号处理。对于新加入平台的司机和车辆，货拉拉表示将严审身份证、驾驶证、行驶证、道路运输证、从业资格证，对五证不齐的不予准入。

# 网秦创始人林宇称遭董事长史文勇绑架，后者否认称将采取法律行动

9月10日，网秦创始人林宇在朋友圈晒出《立案告知书》照片，并发文称自己遭网秦董事长史文勇绑架，期间受到非人折磨，九死一生。截图显示立案时间为2018年8月1日，而林宇收到立案告知书的时间为2018年8月3日13时。

林宇发布的朋友圈显示：史文勇涉嫌重大刑事案件，即涉嫌从2016年11月到2017年底绑架我13个多月，期间我受到非人折磨，九死一生，我的家人也受到威胁恐吓。史文勇已逃离出境近一个月。

针对上述“绑架”事件，网秦董事长史文勇声明称与林宇声称的立案事宜无关，并表示自己在公司正常履职，史文勇还表示对林宇的做法将采取必要的法律行动予以回应。
