# 微信现“山寨版”：能自动抢红包显示全球定位，防止对方撤回信息

# 罗永浩：子弹短信挑战微信不现实，有人写600页材料举报其为黄色软件

![](../Images/4b82ed15b4aad36727cfa1e0b33f2754.png)

9月9日，罗永浩在参与直播过程中表示，希望子弹短信能够拿到20%的市场份额，而挑战微信也并不现实。

目前官方公布的数据显示，子弹短信目前下载量超过千万，激活用户700万。对于外界认为其可能会对微信造成挑战，罗永浩表示，挑战微信基本不可能，而子弹短信会针对特定的人群，比如对语音识别功能有需求的群体等。

此外，罗永浩给子弹短信的定位是，在通讯工具里拿到10%-20%的份额，可以做成几十亿甚至上百亿估值的公司。罗永浩还表示，之前子弹短信遭遇了一次垃圾信息的攻击，而他们正在完善反垃圾的机制，同时他还透露，已经有人写了600多页的材料举报子弹短信是一款黄色软件。

# 滴滴表示将录音直接加密上传，保存7天后自动删除

![](../Images/b3d240ac6caff2cda85c4c0a345b05e4.png)

据北京青年报消息，9月8日，滴滴上线车内录音服务功能，使用滴滴快车等服务前必须先授权录音安全保护功能，才可以正常叫车。

北青报记者打开滴滴App发现，在呼叫快车、专车、拼车等车辆时，会弹出“请授权录音安全保护”的提示，乘客只有在点击“同意并授权”后，才可以正常继续叫车，否则只得取消订单。

根据该提示，在乘客进行授权后，每次行程中车主端会开启录音；该录音主要用于差评或投诉时，可向平台申请核查录音，有据可依。滴滴表示，将严格保密录音，该录音直接加密上传，在保存7天后，将自动删除，如有纠纷，会适当延长保存时间。

# 央视曝光百度再现医疗推广事件，百度：误导网民就医选择深表歉意

![](../Images/a1f6098067765cf48d3ffc3f14e69ac9.png)

# 乐视电视公司疯狂打折：曾估值270亿 今拍卖起价18亿

每日经济新闻消息，乐视电视的经营主体为乐融致新电子科技（天津）有限公司（以下简称“乐融致新”），乐视控股拥有约18%股权，乐视网是其大股东。由于乐视控股的债务问题，上述18%股权被司法冻结并进入司法拍卖流程。

# 北京互联网法院来了：24小时不打烊 诉讼可在线上完成

9月9日上午，北京互联网法院正式揭牌成立。

据了解，该法院将集中管辖北京市辖区内应当由基层人民法院受理的第一审特定类型互联网案件，当事人不需要到法院，便可以实现起诉、调解、立案、送达、调解、庭审、宣判、执行等全部或部分诉讼环节的网络化办理。

值得注意是，虽然北京互联网法院虽然以“网上案件网上审理”为基本准则，但互联网法院并非采用“一刀切”的方式进行全部案件的网上审理。根据当事人申请或者案件审理需要，互联网法院可以决定在线下完成部分诉讼环节。
