# Cloud Foundry大调查：Java和JavaScript仍是企业的最爱！

IEEE Spectrum早前发布了学术界的程序语言偏好调查，而开源云端平台Cloud Foundry基金会也公布了企业爱用的程序语言排名，Java和JavaScript仍然稳居第一、第二名宝座，甚至有与第四名之后拉开距离的趋势，而学术界爱用的Python在企业界反而没有这么热门，使用比例甚至从2017年11月的30%，降到今年3月的25%。

![](../Images/0de2d9d2964b97c9bcfa004463caf47c.png)

Cloud Foundry对全球企业IT决策者（ITDM）所做的调查，在过去9个月中，无论是2017年11月或是2018年3月的研究，Java和JavaScript都是企业开发者最主要使用的两种语言，在今年3月有58%的IT决策者表示使用Java，前端与后端使用JavaScript的比例为57%。而另一家研究公司RedMonk在今年3月也公布了语言排名，Java和JavaScript也是位在排名最前面。两个调查都一再证明Java在企业界仍然非常强势，没有衰退的情况，Cloud Foundry提到，Java还活得很好。

企业应用开发语言排名：

![](../Images/7ca137db3a29d878460505736324154e.png)

第三名与第四名为C++和C#，第五名与第六名为Python和PHP。C++在过去9个月的表现也有微幅的成长从45%上升到46%，PHP表现持平维持在22%，C#和Python都往后衰退，C#从28%下降到了26%，而Python更从30%下降到了25%。企业对于新兴语言使用仍然较为保守，较新的语言像是Ruby或是Go都只有个位数的使用率。Cloud Foundry认为，除了Python之外，其他语言的使用率差异可以视为边际误差，而前三名语言上升，所有语言下降的现象，可能代表着较少受访者选择多重选项。

![](../Images/628308402e3648b8a646010e2e72887a.png)

由于现在许多开发环境都支持多程序语言，因此企业可以更弹性灵活的选择想要使用的语言，用适合的语言解决适合的问题，尤其是实践原生云端应用的大型企业，更能自由选择使用的语言，Cloud Foundry提到，这个现象之于企业的意义，代表大型企业不再受限只能聘雇特定语言的开发人员，虽然企业内团队会有惯用语言，但该团队也可能是由多语言开发能力的人员所组成，这样的生态扩展了企业可用人才的范围。

越来越多企业会以多语言或是多平台的策略，解决企业的需求，而云端开发的灵活性，让原本单一的开发方法，更走向灵活、可移植以及具有互通性的运算生态，Cloud Foundry表示，使用多开发语言是现在企业的新现象，无论是在开发、生产或是资本考察，多语言开发提高企业发展速度。

![](../Images/ebdb9a9c6ac516cf899a31c09af9f7d2.png)

虽然整个开发产业流行的语言存在一致性，但是其中仍然有些差异，特定语言会受地区或是公司规模而影响受欢迎程度。调查发现，企业规模越大，使用的开发语言就会越多，因此在大型企业中，一般来说都会使用到Python和C#这两种语言。

在北美，有三分之二的IT决策者使用JavaScript，Java则为58%，在亚洲Java为58%，接着是C++为52%，而欧洲排名则与全球的表现相当一致。私有云用户也与全球用户趋势相同，但Java和JavaScript的使用率相较其他开发语言有更大的差距，多云企业也大多数使用Java和JavaScript，Cloud Foundry认为，只要原生云端趋势继续发展，那Java和JavaScript在企业开发领域就会继续强势。
