# 拼多多售假风波后首发公开信：已关店1128家 下架商品近430万件

![](../Images/f14a53bb47949e239384b77f5e270f71.png)

8月22日晚间，电商平台拼多多发布的“双打行动”阶段性说明公开信。公开信中拼多多方面表示，受到社会舆情的关切之后，深刻认识到平台还存在对知识产权保护重视程度不够、履行平台主体责任能力有所缺失、平台内部治理不够规范等诸多问题，并迅速展开打击销售侵权和假冒产品的“双打”行动。

8月2日至8月9日期间，平台已强制关店1128家，下架商品近430万件，批量拦截疑似假冒商品链接超过45万条。根据清查进度，拼多多向长宁区市场监督管理局报送36家涉嫌违法商家信息，后续将根据清查结果继续向属地市场监管部门报送涉嫌违法商家信息。

拼多多在声明中表示，我们深知，存在于过去的问题不应该继续存在于未来，有担当的企业应该通过创造性地解决存量问题来寻求发展，和实现自身社会价值。

# 美团点评今日通过港交所聆讯，苹果、亚马逊等可能成为基石投资者

![](../Images/3f9d0e24b00c8c11be78a9c61e0e846f.png)

根据公众号“IPO早知道“消息，美团点评已于昨日获得港交所上市的口头许可，并将于今日正式通过港交所聆讯。美团点评将于明日正式启动PDIE（Pre-Deal Investor Education）和分析师路演，并于下周五确定基石投资者。

美团点评在前期的NDR（Non-Deal Roadshow）中，对基石投资者的选择非常苛刻，目前最有可能成为基石投资者的是Apple（苹果）、Amazon（亚马逊）、Microsoft（微软）、Blackrock（贝莱德）、Capital Research（资本研究）和Hillhouse（高瓴）。美团点评将于9月20日在港交所正式上市，估值区间为400亿～600亿美元。

# 雷军拿99亿薪酬超越刘强东刷新世界纪录，小米行政开支剧增44倍

![](../Images/6b4c33add349899f1d0fd234bef18e7a.png)

8月22日，小米发布截至2018年6月30日止6个月的中期业绩报告。

财报显示，小米收入452.36亿元，同比大涨68.3%，经调整利润21.17亿元，同比增长25.1%。此外，小米第二季度行政支出高达104.57亿元，同比暴增4469.6%。小米财报称，这主要是由于2018年第二季度一次性以股份为基础的薪酬为99亿元。

雷军的99亿人民币高薪刷新了记录，而此前，这个记录的保持者是京东创始人刘强东。

据了解，2014年京东上市前夕，京东董事会就决定，奖励创始人刘强东4%的公司股权，按当时的价格来算，刘强东手握的4%京东股权价值约6亿美元（约合人民币41亿元）。而此次雷军获得的99亿人民币，是刘强东当时获得奖励的2.4倍，刷新纪录！

# 高通宣布今年推出5G热点 明年推出针对5G手机的芯片

腾讯科技援引外媒报道，高通今日宣称，它正在为5G手机开发下一代“旗舰移动芯片”。该芯片将整合高通的Snapdragon X50调制解调器和尚未命名的7纳米芯片系统解决方案。

高通预计这个新的芯片将会“在2019年上半年”出现在高端智能手机中，因此它计划在“2018年底”推出的移动热点可能会使用其他不同的芯片组。

根据高通宣布的消息，虽然早期的5G热点将会使用Snapdragon 855芯片，但是5G智能手机将会采用它的尚未命名的新芯片。这很可能是因为工程设计方面的考量——电耗、热量和无线性能——促使高通及其大多数客户偏向于选择新的5G芯片。

# 拍拍贷二季度净赚6亿，活跃借款人320万，追加回购6千万美元股票

![](../Images/49bd6ecfb86a12e08734254ec2b3f413.png)

8月22日，中国金融科技公司拍拍贷（NYSE：PPDF）发布了其2018年第二季度未经审计的财务报告。

报告显示，拍拍贷2018年第二季度营收达10.48亿元，环比增长14.24%；净利润为6.08亿元，环比增长38.9%。活跃借款人320万人（其中新增借款人数近113万），比上季度的250万亦有所增加。

财报发布后，拍拍贷宣布扩大公司现有的股票回购计划，从回购6千万美元增加至1.2亿美元，回购期限亦延长至董事会批准之日起12个月。此外，拍拍贷还宣布任命邓凯为公司董事，并加入董事会下属的薪酬委员会。同时，原本代表最大机构股东红杉资本持有拍拍贷25.5%股份的沈南鹏将从公司董事会辞职。这两项人士变动即刻生效。

# 安全公司：黑客每60秒可盗走超100万美元资产

据英国《每日邮报》8月21日报道，黑客每隔60秒就可窃取100万美元。网络安全研究人员发现，每分钟有1861人成为网络攻击的受害者。仅2017年，网络犯罪造成全球经济亏损6000亿美元。黑客动机繁多，包括金钱利益、政治和间谍活动。

# 山寨平台售卖彩票致用户受骗，十二部委联合发文严禁网络售彩
