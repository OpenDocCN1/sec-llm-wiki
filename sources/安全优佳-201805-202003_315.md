# 新款iPhone或于9月14日接受预订，iPhone 9价格或在5000左右

![](../Images/72b34ff37838ec4af2274abc1f0e018f.png)

8月21日，据德国媒体援引当地两家运营商的消息称，2018年三款新iPhone的预订工作将从9月14日开始。据悉，9月12日苹果将举行秋季新品发布会。另外，三款新iPhone的上市日期定为9月21日。

根据之前媒体的报道，今年苹果推出的三款新iPhone，其中包括5.8英寸iPhone Xs、6.5英寸iPhone Xs Plus以及配备LCD屏幕的iPhone 9。

其中，两款iPhone Xs使用的是OLED显示屏，iPhone 9则用的是成本更低的OLED显示屏。三款新iPhone均搭载了由台积电制造的A12芯片，标配TrueDepth摄像头，也意味着三款新iPhone均支持Face ID面部识别功能。有传言称iPhone9是三款新机中价格最低的一款，或在5000元左右。

# 研究称5G智能手机将从2021年开始大规模出货

![](../Images/10029ed5f03b632c13d51fd6dbc23ce7.png)

北京时间8月21日消息，根据Digitimes Research预测，包括智能手机、CPE和WiFi设备在内的5G终端设备，于2019年开始在市场上开售后，直到2021年才会迎来大规模出货。

5G智能手机的出货量将占据2022年5G终端设备出货总量的97%以及全球智能手机出货量的18%。

8月13日，中国联通正式发布了＂5G NEXT＂计划。北京联通将率先开展面向商用的 5G 规模试验，计划到今年年底在北京建成 300 基站规模。

目前已经明确5G手机发布时间表的已经有不少了。三星方面会在2019年3月推出5G手机，华为在2019年6月推出5G手机，OPPO与vivo也铁定会在2019年推出5G手机。总之在2019年，我们是不会缺少5G手机进行选择的。

![](../Images/ada88108d55968009ed214b8a2c58ad7.png)

# 富士康在美国建厂拉高当地低价，房地产市场热度上升

![](../Images/884070ce15d3196f76652e5799968f64.png)

中国电子代工巨头富士康集团在美国威斯康星州投资建设液晶面板基地，项目已经动工。据外媒最新消息，富士康的到来激活了房地产市场，越来越多的开发商涌入，导致地价暴涨。

不久前，富士康集团举行了威斯康星州液晶面板基地的动工仪式，美国总统特朗普特意光临。这一项目总投资100亿美元，将创造3000个就业岗位。这也是富士康在美国布局的最大电子制造项目。

据威斯康星州密尔沃基（该州最大城市）媒体报道，富士康集团给当地房地产市场带来巨大推动。近日，来自加州的一家开发商在I-94高速公路和11号公路交口附近，购买了28英亩（相当于170亩）土地，一共支付245万美元。

# 流量降费目标超额完成，全国流量均价11.26元/GB 上半年已降价50%

近日，三大运营商都发布了2018年上半年财报。

综合三大运营商的财报，2018上半年，三家运营商用户共计使用手机流量共计271.58亿GB，同比增长212%，三大运营商流量收入总计3057.62亿元，同比增长12.88%。

以此计算，全国流量均价为11.26元/GB，此价格相比于2017年上半年的31.17元/GB降低了74%，相比于2017年底的21.68元/GB降低了48.16%。

如果继续以“流量单价”作为统计口径，2018年政府工作报告中提到的“移动网络流量资费年内至少降低30%”已提前、超额完成。

# 蚂蚁金服回应：从来没制定过上市时间表 不存在“上市推迟”一说

![](../Images/a1cb65bcb8760695b2c2cce2964ca101.png)

据外媒8月21日报道，蚂蚁金服IPO计划再次被推迟，蚂蚁金服在2019年底之前不太可能上市，还有知情人士表示，上市是“几年”以后的事情。

对此，蚂蚁金服公关总监彭美回应上证报记者时表示，蚂蚁金服从来没有制定过上市时间表，根本不存在推迟一说。

彭美表示，蚂蚁金服这些年一直在基于各种创新科技的研发，助力全球普通消费者和小微企业获得更加安全、便捷的普惠金融服务，从而获得更多平等的机会。“对于蚂蚁金服而言，上市是一个水到渠成的事情，但我们从来没有就上市制定过时间表，所以压根不存在推迟上市一说。目前市面上所有关于蚂蚁金服上市的传言都与事实不符。”

# 乐视控股称与乐视网达成40多亿偿债方案，贾跃亭兜底，股价涨停

8月17日，乐视网发布告称，与乐视非上市体系达成认定债务规模约67亿元。21日，乐视非上市体系（乐视控股）债务处理小组相关负责人在接受采访时表示，乐视控股已偿还了2.63亿元的债务，并与乐视网达成了40多亿元的偿债方案。“剩余的十几亿元本不应该由贾跃亭承担的公司债务，贾总承诺由他个人承担。” 该负责人表示。

受此消息影响，21日午后，乐视网(300104)直线涨停，封单超110万手，报2.29元，涨0.21元，总市值91.4亿元。

# 三星电子股价持续下跌 已较历史新高蒸发24%

![](../Images/70423593f8191f242d3b13c617721391.png)

据外媒报道，随着对半导体超级周期见顶的担忧日益加剧，三星电子的股价近期持续下跌。虽然该公司有望在今年交出有史以来最强劲的第三季度表现，但这对其股价似乎并没有什么影响。而市场专家对该公司前景的看法也参差不一。

一些业内人士称，在半导体超级周期结束后，三星电子的增长将会放缓。还有人则认为，该公司股价将触底反弹，因为所有的不利因素都已经反映到其股价之中。

截至周一，三星电子股价在韩国证券交易所报收于43850韩元，较上一交易日下滑0.57%。当天盘中，该股一度跌至43500韩元，创下52周新低。相较去年11月3日创下的57519韩元的历史新高，三星电子股价已经在不到一年的时间内下跌了24%。

# 哄抬房租、恶意克扣租金？北京开通打击"黑中介"举报热线

![](../Images/2ce6ba9cb5fd9100af4c6882c9d14575.png)

8月21日，北京市住房城乡建设委会同市公安局、市工商局、市非紧急救助服务中心等部门，依托北京市12345政府服务热线，开通打击“黑中介”投诉举报专线。群众发现中介机构存在无照经营、未备案；打隔断出租；哄抬房租、恶意克扣租金、押金；发布虚假广告、虚假房源信息；采取威胁、恐吓等暴力手段或采取堵锁眼、断水断电、辱骂骚扰、言语恐吓等软暴力行为驱逐承租人、强行收取各类费用等侵害群众利益行为的，均可以通过热线直接进行投诉举报。

北京市住建委相关负责人表示，各部门将依照职责对上述乱象予以坚决打击，对于违法违规行为一经发现予以严肃处理，对于违规中介依法予以高限处罚、注销备案、停业整顿直至吊销营业执照，对于涉及刑事犯罪的“黑中介”移送公安部门予以严惩。
