# 俄罗斯黑客称：美国正在研究UFO技术

UFO的披露就在眼前。2018年8月20日，俄罗斯黑客破译了来自五角大楼的秘密文件。据该俄罗斯黑客称：美国正在秘密研究UFO技术。近些年越来越多的人相信UFO是真的，并且几十年来一直被世界各国政府所研究。美国国防部副部长威廉林恩收到参议院多数党领袖的致函，其中哈里·里德给国防部副部长的信称五角大楼对UFOs的秘密计划进行了一系列奇异的未来技术的调查。与高级航空航天威胁识别程序（AATIP）调查有关的文件证实，他们秘密研究了将使美国人能够在未来几十年对其他国家实行更大的军事控制的技术。

![](../Images/a6fbe33411103d32ab2b028900c3468e.png)

这项主要致力于探索空中异常现象的“秘密”，该秘密在昨天被俄罗斯的黑客所曝光，其中内容主要讲述了一架F/a-18超级大黄蜂战斗机和一架椭圆形UFO之间的近距离接触。根据俄罗斯哦黑客的说法，F/a-18超级大黄蜂战斗机在飞行时速度非常快，在空中进行了令人难以置信的动作。这封信揭示了五角大楼在UFO研究和航空航天技术进步方面的生动细节。虽然这封信没有特别提到外星人，但它似乎证实了这位参议员被命令评估来自太空的“外来威胁”的程度。此外，信中还提到了极其复杂的概念，如量子力学、核科学、电磁学、反重力和热力学。

![](../Images/030fcecdf9da88664ea6327c3a8b2a8f.png)

里德参议员在这封信中警告说：“这些技术有可能被对手用于灾难性的后果。”这封信是现在拉斯维加斯网站获得的。事实上，在AATIP项目中研究的技术所取得的进展是如此敏感，以至于参议员建议国防部实行更严格的控制，并建立“SAP级别”的证书（加密访问程序），这意味着它的信息将被归类于最高机密之上。信中还提到，在确定几个高度敏感、非常规的航空航天相关发现方面取得了很大进展。最终，AATIP的结果不仅将有利于美国政府，而且我相信，它将以一种出乎意料的方式直接有利于国防部。

![](../Images/65bd695a1aea57ae4349e9b6ea245ea1.png)

获得的技术洞察力和能力将为美国提供比任何外来威胁都明显的优势，并使美国保持其世界领导地位。当然，怀疑者认为，信中提到的威胁最有可能是俄罗斯和中国等其他国家所制造的武器和太空发展。然而，似乎有明确的暗示，AATIP对UFO现象的研究帮助改善了美国的航天技术，UFO猎手和UFP学者认为，这种进步很可能是由于反向工程技术的应用。后者可以从去年前AATIP经理路易斯·伊莱桑多关于“外星人”五角大楼计划存在的秘密被解除后所做的声明中推断出来。

![](../Images/09cf28d34fc624dae7141ef1810a37a2.png)

在令人震惊的声明中，伊莱桑多声称“有令人信服的证据表明我们并不孤单”，并暗示美国政府可以使用多年来从外星飞船上找到的“超材料”，并在拉斯维加斯沙漠某处经过特别改装的设施中得到保护。这些令人震惊的事实表明，美国政府是多么认真地对待UFO这个问题。不管他们对UFO现象的真实性质有什么看法，这封信让我们深入了解了五角大楼感兴趣的原因，以及他们认为这些威胁和机遇可能是什么。然而《地铁》杂志发表的文章解释道：美国这份文件没有给出宇宙中是否真的存在外星人。但是在美国国防部，美国科学家放弃了UFO的术语，而代之以UAP（不明飞行物现象）作为其代替词，这既是为了重新组织辩论，也是为了模糊大众的视线。
