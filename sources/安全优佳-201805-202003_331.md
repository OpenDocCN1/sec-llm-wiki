# 《人民日报》官微支持遏制天价片酬，爱奇艺、优酷、腾讯视频等联合发声明

![](../Images/f0b1e7c8d731fd8f689f8c847de9e411.png)

继爱奇艺、优酷、腾讯视频三家视频网站联合六大制片公司发布联合声明，宣布共同抵制艺人“天价”片酬现象，共同抵制偷逃税、“阴阳合同”等违法行为后。由华谊兄弟牵头，横店400余家影视公司于8月12日亦联合发表声明。

12日晚间，《人民日报》发微博表示遏制天价片酬就是为了提高演技上限。

8月11日，首都广播电视节目制作业协会9家会长单位：海润影视、大唐辉煌、华谊兄弟、爱奇艺、完美影视、北京电视艺术中心、酷云互动、磨铁集团、金英马影视，代表协会联合发表《关于加强行业自律 遏制行业不正之风的倡议》。

8月12日，以华谊兄弟为会长单位，汇集了博纳影视、横店影视、乐视花儿影视、唐德影视、新丽传媒、印纪传媒、正午阳光等400余家影视企业的横店影视产业协会发表了《关于“加强行业自律、规范行业秩序、促进影视精品创作”的倡议》。

声明中指出将“规范行业秩序，抵制天价片酬。合理规划成本，严格落实《通知》规定，严控片酬比例，“每部电影、电视剧、网络视听节目全部演员、嘉宾的总片酬不得超过制作总成本的40%，主要演员片酬不得超过总片酬的70%”，确保创作成本和制作成本优先。”

# 滴滴司机曝外挂骗局 滴滴回应：一旦发现即封号

![](../Images/fe56409939b8d77e27069f8686f7d4b7.png)

日前，华商报报道了《有滴滴司机使用“外挂”让乘客费用翻倍》的新闻。对此，滴滴出行方面表示，如果乘客掌握司机使用“外挂”的证据，可向平台进行投诉，会严肃处理涉事司机，并返还乘客费用。另外，平台也时刻监控“外挂”作弊行为，一旦发现会对司机进行封号、罚款处理。

此消息，陕西保群律师事务所律师宋伟表示，从民事上讲，司机使用“外挂”骗取乘客车费属于交通运输合同纠纷，乘客通过司法途径追回。但如果一名司机多次通过“外挂”骗取乘客费用，并且这些乘客都向警方报警的话，达到一定金额警方会按刑事案件处理。

# 腾讯预计上半年利润增14.8-26.8%，股票虽下跌海外投行仍看好

![](../Images/69782effa96fdcab3dce46d9d4415e8a.png)

截至8月10日，今年以来，恒生指数累计下跌5.19%，腾讯控股年内累计下跌幅度达到8.67%。作为港股市场的“股王”，腾讯控股在一段时间里跑输大盘的情况是极少发生的。

自港股通开通以来，内地资金持续青睐腾讯控股。但在过去的四个月里，内地资金出现了较大金额撤出腾讯控股的情况，资金量达到了253亿港元。

今年3月份，腾讯控股的大股东（Naspers Limited）破天荒地减持了约769亿港元的股份。就在大股东减持之后，内地资金通过港股通也在减持腾讯。

据统计，今年4月13日至今，内地资金通过港股通持股腾讯控股的股份，从2.08亿股减少至1.43亿股，减持市值达到了253亿港元（根据统计区间均价进行估算）。

虽然面临了股价的缩水与投资者的减持，但众多海外大行还是比较看好腾讯控股。比如，高盛、瑞银、花旗、美银美林等投行均给予了腾讯控股“买入”评级，且目标价均在500港元之上。其中，麦格理更是给出了560港元的最高目标价。

# ofo否认青桔品牌替换小黄车：完全虚构

# 法拉第未来称FF91即将交付，回应EVelozcity对其财务状况指责

![](../Images/22760f81c155a57faa7bce25faae7176.png)

当地时间8月9日,由法拉第未来（Faraday Future）前CFO Stefan Krause创立的南加州电动汽车初创企业 EVelozcity向洛杉矶高等法院(Los Angeles County Superior Court)起诉法拉第未来大股东以及代理CEO贾跃亭，称其引诱并要求员工签署包含竞业禁止条款的雇佣协议，EVelozcity认为法拉第未来使用威胁和欺骗手段阻止其雇员自由寻找新的工作机会。

针对上述指控，法拉第未来回应称：“我们审阅了EVelozcity在加州地方法院递交的起诉状，认为这些主张毫无法律依据。法拉第未来严格遵守加州各项法律，尊重雇员的择业流动性。尽管EVelozcity在诉状中声称诉因是针对FF员工聘用协议的择业随意性问题，但却在诉状中花费了大量篇幅罗列与该诉因毫无关系的琐碎性的诉因的指控。由此可见，EVelozcity提起这一琐碎诉讼是看到法拉第未来在交付其第一款量产车——FF 91取得了进展，而蓄意骚扰和诋毁法拉第未来，法拉第未来满怀信心在这一诉讼中大获全胜。”

# 华为、vivo、OPPO被传“造电视” 或采取代工模式

![](../Images/d172a8da5617b2be7a828de8eff16017.png)

近日，有消息称，vivo、OPPO、华为等手机厂商正在评估调研电视市场，将有可能正式宣布进入电视市场。此消息一出，引发业界热议。

这几家手机厂商几乎占据手机市场七成以上份额，如若其集体进入电视领域，或将对手机和电视两个产业产生较大影响。

日前，vivo相关人士接受《证券日报》记者采访时，对此消息进行了否认。其表示：“这只是传言，公司内部并没有这样的消息。”对于公司是否可能进入电视领域，其称：“目前vivo还是会专注于手机业。”

不过，业内人士认为，几家主流手机企业进入电视领域是有可能的。“电视目前仍是用户获取资讯的第一个平台、第一入口。随着手机市场的逐渐饱和，厂商已经不满足于竞争激烈、利润空间趋近的手机市场，它们开始酝酿从手机端蔓延到电视端，蚕食电视市场份额，抢占客厅流量入口。”

# 特斯拉董事会本周与银行见面 马斯克已遭到两宗集体诉讼

![](../Images/bf20f50033cb9a9cccd41884d7c52ded.png)

腾讯科技引用外媒报道称，特斯拉董事会计划在本周与银行家见面，正式将特斯拉私有化提上议事日程。该报道还补充了证据，证明了很多特斯拉观察人士猜想到的事情：沙特主权财富基金PIF（它刚刚持有了大量特斯拉股票）可能就是私有化协议的资助者。

马斯克宣布将对特斯拉进行私有化收购以及退市的消息引发了行业和资本市场震动，据外媒最新消息，马斯克以及特斯拉公司已经为此遭到两宗集体诉讼。

据报道，原告Kalman Issacs在加州旧金山联邦地方法庭提交诉状，指控特斯拉公司和马斯克本人实施了一场阴谋，试图操纵特斯拉公司的股票价格，以此打击对特斯拉股票的做空人士。在另外一宗提交到旧金山联邦地方法庭的集体诉讼中，原告William Chamberlain表示，从8月7日到8月10日，马斯克在特斯拉公司私有化方面对投资人进行了严重误导，其中包括谎称投资者支持其私有化计划，另外自己获得了收购资金。

对于投资人的集体诉讼，特斯拉官方并未发表评论。

# NASA“帕克号”太阳探测器成功发射升空 开启七年飞行任务

![](../Images/7c20bb81b12904d518ff4a6d535ffef3.png)

美国东部时间8月12日凌晨3时31分（北京时间8月12日下午3点31分），美国宇航局（NASA）携带“帕克”号太阳探测器的德尔塔IV型重型火箭成功点火升空，“帕克”号探测器飞行7年后将抵达太阳的日冕层，这是人造航天器首次抵达恒星的大气层。

帕克太阳探测器预计于10月份抵达金星轨道，探测器将在11月初启动第一圈绕日飞行，最快于今年12月收到第一批对日探测信息，而第二圈飞行需要等到明年5月，随着绕行圈数增加，获得的数据也就更加准确完备。

这项探测任务预计结束时间为2025年6月，7年任务中，探测器将绕日飞行24圈，这是一项伟大的、令人难以置信的大胆旅程。

# P2P企业微贷网欲在美股上市，募资1亿美元，上半年净利润同比增14.6%

8月12日消息，国内车贷平台微贷网日前提交IPO招股书，申请在纽交所挂牌上市，股票代码为“WEI”，计划通过此次交易筹集最多1亿美元资金。

在招股说明书里，微贷网将自己定义为一家新兴成长公司。2011年7月成立于杭州，从事以汽车抵押借贷为主的P2P业务，还是中国首家创新汽车抵押模式的公司。

招股书显示，微贷网2018年上半年实现净利润3.07亿元，同比增长14.6%。
