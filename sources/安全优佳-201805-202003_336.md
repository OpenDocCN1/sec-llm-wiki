# 传腾讯欲30亿收购《绝地求生》开发商8.5%股份成第二大股东 腾讯回应不知情

![](../Images/aa916adc7629f398750eab1a8bea84f1.png)

根据外媒消息称，风投行业知情人士表示，腾讯同意收购在线游戏《Playerunknown's Battlegrounds(绝地求生:大逃杀)》开发商蓝洞约8.5%的股份，每股价值65万韩元，收购总额大约为5000亿韩元(约30亿人民币)。

# 摩拜女员工举报领导性骚扰，称多人受害，摩拜回应：被举报人已停职

![](../Images/ae1a60e2b5b9f4f1e075d7937eeef823.png)

在举报信中，该员工还称，同组受伤害最严重的女同事工作受到严重影响，已经被迫离职。

该员工在举报信中疑似喊话摩拜单车创始人胡玮炜，称：胡阿姨同为女性，一定理解我们的感受。

摩拜方面对此回应称，在接到该举报后高度重视此事，第一时间成立专项调查小组展开调查。目前被举报人已被停职并接受进一步调查。

# 余承东确认华为正在做智能音箱，人工智能将成华为发展重点

# 北京27家互金机构发联合声明：保证决不失联跑路

8月9日，北京市互联网金融行业协会官方微信号发布《北京市网贷行业共建社会信用体系联合声明》，并在声明中表示，保证决不失联跑路，并承诺对投资人负责，与投资人共同对逃废债行为人追究到底。

声明还表示，将充分运用金融科技手段，建立健全金融消费者KYC机制、风险提示、恶意逃废债黑名单等配套制度，强化恶意逃废债行为人的甄别。

# 中国移动CEO李跃：筹划旗下3至4家公司分拆上市

![](../Images/b787b4283fbe21994e4e1634d19a395a.png)

在中国移动9日举行的中期业绩发布会上，中国移动执行董事兼首席执行官李跃对外透露，目前正在筹划旗下3至4家公司分拆上市，但上市具体时间地点未定，中国移动香港也没有相关计划。

从具体业务来看，李跃表示会考虑选择已经独立运营、与大网业务关联较少、方便财务核算的公司。

中国移动公布上半年财报数据，上半年净利润656亿元人民币，同比增长4.7%。市场预期为634亿元人民币。营收3918亿元人民币，同比增长2.9%。其中，通信服务收入为人民币3561亿元，增长5.5%；EBITDA为人民币1459亿元，增长3.7%。

# 新iPhone和iPad发布前夕 苹果组件订单数量大幅攀升

据国外媒体报道，苹果主要供应商之一Lumentum Holdings今天公布了二季度财报，财报结果显示该公司增强现实和3D感应业务有大幅攀升。Lumentum Holdings是苹果VCSEL（垂直腔面发射激光器）的主要供应商，这个组件的作用就是为iPhone的前置摄像头提供Face ID和Animoji等功能。

Lumentum Holdings在财报中称，二季度业绩高于预期，其中AR与3D感应业务增长速度高于预期，主要是由于苹果增加了今年新iPhone的产量。

Lumentum Holdings是苹果最大的面部识别芯片技术供应商，目前占据了大约75%的市场份额。
