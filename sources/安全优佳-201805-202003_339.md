# DNF外挂员携300万跑路，逼迫去腾讯上班实属套路赔偿？！

众所周知，DNF在刚出来没多久的时候，便开始外挂横行！不过，随着腾讯技术部的升级，打击外挂的力度便开始增重了！就在近日，发生了一起DNF外挂事件！也就是铁马脚本制作组携款300万跑路的事情了！DNF外挂制作组被逼去腾讯上班！不去就追究刑事责任！你怎么看？

![](../Images/27c790d22397ad3f1d3d9be468d30cdf.png)

不过，目前，这名外挂制作者已经跑路，并非常嚣张的网上发声：已经跑路，源码已经交给腾讯了！

![](../Images/9ddb3d714256e2e2c272cc1a1a9680bd.png)

在这期间，腾讯已经派人打电话给这名外挂制作人，并表示让他去技术部上班，如果去了就不追究他刑事责任！然后，这人表示又跟腾讯商量半天，腾讯表示：不想上班也可以，将外挂源码交上来！不交的话就警察局见！最终，这名玩家妥协，将外挂源码交了上去，并携款300万跑路！

![](../Images/c6fec88c3f1d258a1261ca89bd1dc5a6.png)

对于这名外挂制作者放弃不去腾讯上班而跑路的行为来看，很多网友表示他做的是正确的！不然就算进去工作了，没有几年也挣不到300万，而且后期还有被腾讯安排的风险！
