# 联想宣称要全球第一个推出5G手机 采用高通最新芯片

![](../Images/4548e8c0823d16b07d46b01d4f846786.png)

据外媒报道，联想宣称它要成为全球第一家推出5G智能手机的公司，而且它的5G智能手机将采用目前尚未推出的高通芯片。

# 人民日报海外版评拼多多上市：低价是市场需求，低质是商家失责

![](../Images/0a4282a601c17f9720fe92a34c87906e.png)

8月3日消息，拼多多上市以来，围绕其涉嫌售假的风波引发舆论持续关注。3日，人民日报海外版发表评论称：对于所有市场主体而言，需要明确的是，低价产品不一定都是低质产品。低价是市场需求，低质是商家失责，售卖假货则是违法行为。不管是拼产品，还是拼市场，拼到最后，一定是拼质量。

拼多多创始人黄峥在此前接受采访时曾表示：“我们当前主要是在满足用户多实惠的阶段，就是同样的东西在这里更便宜，或者总体性价比更高，这个还是最主要的。”

北京时间8月3日凌晨美股收盘后，拼多多最新收盘价为19.66美元，总市值为217.79亿美元，较市值最高时的305亿美元相比，拼多多市值已蒸发约60亿美元。

8月2日消息显示，由于来售假风波，拼多多让投资者蒙受了不少损失，已经有六家美国律师事务所宣布代表投资者们展开对拼多多的集体诉讼。

# 腾讯微信提醒：警惕“官方授权”“政府扶持”等小程序开发骗局

![](../Images/60993006d353f51be22c0533f5e86d3a.png)

今年6月，微信安全风控中心配合河源紫金警方捣毁了一个冒用小程序官方授权名义的小程序诈骗团伙。该诈骗团伙自去年6月份以来，就打着“腾讯公司子公司”和“小程序服务中心”的名号，邀请商家参加“小程序推介会”。为了让商家信以为真，该诈骗团伙捏造了“广东省现代移动互联网研究院”，并制造该“研究院”是工信部门下属权威机构的假象。

对此类事件，腾讯微信团队表示，将持续关注同类事件，一旦发现有涉嫌侵权、冒用官方名义的团伙，将启动法律程序，追究其法律责任。腾讯微信团队同时也提醒商户在与第三方公司合作开发小程序时，注意辨别第三方公司信息的真实性及可靠性。

# “拼多多”销售盗版图书 出版社称将追究其法律责任

![](../Images/fd06cafb2e9c7ea9e8a50415d2a7c3ae.png)

中国青年报消息，近日，人民文学出版社在“拼多多”购物平台上发现大量侵犯人民文学出版社权益的盗版图书，包括《红星照耀中国》《长征》《抗日战争》、“哈利·波特”系列、《围城》以及古典名著《红楼梦》《三国演义》《西游记》等，以《红星照耀中国》《长征》和“哈利波特”系列为甚，数目之巨、流传之广、影响之恶劣令人震惊。人文社表示，将通过法律手段追究“拼多多”购物平台销售盗版图书的责任。

在“拼多多”购物平台上出售的上述人文社图书均为盗版，绝大多数售价低于正版图书定价的五折，甚至很多低于三折，远低于人文社发行的最低折扣。

# 上海警方连夜通报：聚财猫等44起P2P暴雷案件已立案侦查

8月2日晚间，上海市公安局多个分局通报了近期辖区内涉嫌非法吸收公众存款、集资诈骗的案件，均涉及各类互联网金融点对点借贷平台（P2P平台）。

具体来看，上海市公安局下辖的浦东、松江、杨浦、长宁、黄浦、静安、闵行、奉贤、虹口、普陀等10个分局共通报了44起案件。根据通报，44起案件基本上是相关公司通过设立线下门店及线上理财平台，在全国范围内向社会不特定公众非法吸收公众存款，在产生巨大资金缺口后，导致无法兑付投资人本息。上海公安机关已对各案件立案侦查，犯罪嫌疑人也多被依法采取刑事拘留措施，相关案件正在进一步调查中。
