# 苹果股价涨超5%，市值逼近1万亿美元

![](../Images/ff0e9320e473357c31031b4ec9e425dc.png)

美国东时间8月1日，美国股市开盘，苹果股价一路狂飙突进，涨幅超过5%，市值逼近万亿美元大关。截至收盘，苹果股价报201.5美元，涨幅为5.89%，总市值达9904亿美元。

万亿美元是个什么概念呢？美国GDP是19万亿美元，相当于19个苹果公司的市值！

苹果股价从2016年底开启了一路狂飙模式。最近1个月市值一直徘徊在9000亿美元上下。苹果在7月31日收盘后发布了第三季度财报，这成为市值突破万亿大关的推手。财报显示，即使处于全年最淡季，苹果营收仍实现17%的同比增长，利润更是同比增长32%，两项指标均高于市场预期。

iPhone仍然是苹果业绩的支柱。尽管iPhone销售数量仅同比增长1%，但由于均价提升，收入仍同比增长20%。除了iPhone之外，苹果服务性收入，也在该季实现31%的同比增长。服务性收入被看做是苹果为来持续盈利的重要指标。

# 拼多多股价暴跌超17%，跌破19美元的IPO定价，市值蒸发666亿元

![](../Images/884e62783fa69c26defc311666c78321.png)

北京时间8月1日晚间，拼多多跌破19美元的IPO定价，当前跌幅超17%。此前，拼多多售假问题受到中国市场监管总局密切关注，并接受上海市区工商和市场监督部门约谈。

7月27日，拼多多正式登陆纳斯达克，开盘价26.5美元，较19美元的发行价上涨39.47%。截至当日收盘，拼多多股价上涨7.8美元，报26.8美元，较发行价上涨41.05%。按收盘价计算，拼多多市值达到305.31亿美元。

按拼多多上市首日305.31亿美元的市值计算，破发的拼多多市值为207.3亿美元，市值已经蒸发98亿美元，约合人民币666亿元。

# FF91完成整车进度40% 贾跃亭承诺年底交车难度不小

![](../Images/6a5ce029090e8f704b49378f29db6e0e.png)

不久前，恒大集团斥巨资入股贾跃亭的法拉第未来Faraday Future。近日，FF高调宣称，第一辆豪华电动汽车FF91的白车身（BiW）已正式完工并已成功开始整车装配，首批FF91交付预计将于今年12月份开始到2019年中期完成。

# 特斯拉二季度营收40.02亿美元，净亏损7.43亿美元

![](../Images/e2ed4163719428e5e6340d2935d963e6.png)

美国电动车厂商特斯拉公布了2018财年第二季度财报。财报显示，特斯拉第二季度营收为40.02亿美元，较去年同期的27.90亿美元增长43%；净亏损为7.43亿美元，较去年同期的净亏损4.01亿美元扩大；归属于普通股股东的净亏损为7.18亿美元，较去年同期的3.36亿美元扩大。

特斯拉汽车称，在Model 3车型产量已达每周5000辆的形势下，该公司未来将重点致力于进一步提高产量，预计第三季度Model 3车型产量可达5万辆到5.5万辆，环比增长75%到92%。

# 华大基因：湖南案例孕妇不是漏检 不存在赔偿的说法

![](../Images/6a7f98c97627e48b642dca77c048d658.png)

# “滴滴外卖”起诉“站长之家”索赔203万，称被其文章严重损害名誉

8月1日，据北京市海淀区法院网站消息，滴滴外卖将“站长之家”诉至法院。2018年4月19日，“站长之家”网站发表了文章《滴滴外卖在无锡迅速“降温”日订单量下降超过50%》，文章中提及“滴滴外卖订单暴跌50%”、“滴滴服务体验存在一定的问题”等内容，滴滴外卖认为该文章无论是标题还是正文均存在多处侵权内容，文章中统计的数据缺乏基本事实依据，内容严重失实。同时，该文章已被大量用户浏览，传播范围极其广泛，严重损害了原告的名誉。

“滴滴外卖”运营商北京再造科技有限公司以名誉权侵权纠纷为由将“站长之家”网站的运营主体厦门享联科技股份有限公司诉至法院，要求“站长之家”删除侵权内容、赔礼道歉、赔偿损失及合理费用共计203万余元。日前，海淀法院受理了此案。此案正在进一步审理中。
