# 拼多多售假问题发酵股价跌超10%，央视点名：上市了，能管住假货吗？

![](../Images/68bbe98b08e87e0c2ae2c7eec514c240.png)

拼多多上市以来，售假问题持续引发风波。股价方面，周一盘中，拼多多股价一度跌逾10%，最低探至21.88美元。

与此同时，央视网也针对拼多多涉嫌售假一事发表评论。

央视网消息，7月28日，有媒体刊文报道拼多多平台上出现的小米视界、三星视听、VDVD手机、创维云视听、雅利阿道夫等多款涉嫌侵犯相关品牌权益的产品，涉及手机、电视、日化等多个品类。

央视网评论称：拼多多成功登陆美股纳斯达克的消息吸引了不少人的目光。但与此同时，拼多多也饱受争议。其中就包括平台上存在卖假货问题，有人质疑道：“就算拼多多上市了，能管住假货吗？”价廉或许未必能物美，但摈弃假冒、山寨是应有的底线，正因此，我们希望拼多多能够切实履行平台责任。事实上，无论是对于内容生产的互联网平台还是对于电商平台，管好自己地盘上的事，已经成为互联网行业发展的共识。从长远看，还没有哪一家希望走远的公司，能绕开这“必修的一课”。

# B站发公告：下架整顿时间持续到8月末 该公司股价盘初跌8%

![](../Images/57b8d99377cea7bf4620b7373fd1ca33.png)

7月30日周一晚间，哔哩哔哩动画（B站）公告称，APP下架整顿时间从7月26日持续到8月25日，临时下架不会对现有用户造成影响。

公告还称，该公司拟与有关部门充分合作，并将进一步完善其内容监控程序和相关政策。公司还计划对其平台上的内容进行全面审查，并加倍内容监控人员的人数。该公司希望能够快速实施所需的审查措施，尽快从应用商店恢复APP下载。

公告过后，B站美股盘前跌近4%，盘初跌8%。

7月26日下午，B站APP在多家应用商店遭到下架。25日，B站公告称，近日国家多部门约谈B站并做出处罚和整改的要求。

# 苏宁易购发半年报：净利润59.97亿元 同比增长近2000%

![](../Images/b5ced6b4854cb8b8f159b57a424f6a57.png)

7月30日晚间，苏宁易购（002024.sz）公布了半年报业绩快报。业绩快报显示，苏宁易购上半年，实现营业收入1107.86亿元，同比增长32.29%。归属于上市公司股东的净利润59.97亿元，同比增长 1957.38%。

其中值得注意的是，报告期内苏宁易购基于整体发展战略安排，出售了部分阿里巴巴股份，在扣除初始购股本金以及股份发行有关成本及相关直接费用后，净利润约人民币56.01亿元。

这也就意味着，若不考虑出售阿里巴巴股份出售带来的利润影响，公司实现归属于上市公司股东的净利润约为3.96亿元，同比增长35.85%。

整体来看，2018年上半年，苏宁易购商品销售规模为1,513.19亿元，同比增长44.63%，其中中国大陆地区实现商品销售规模同比增长44.61%。

# 传秒拍被永久下架？官方否认：正在积极整改

![](../Images/2f47bb424cbbc7688eb9f069d35fd148.png)

近日，有报道称一下科技旗下视频应用“秒拍”被永久下架，对此，秒拍内部人士回应称，并未收到相关部门关于APP永久下架的通知，目前“正在整改”，还没有接到通知，因此才不得上架。该内部人士强调，相关处理结果以国家网信办公告为准。

7月26日，网信办发布公告，联合六部门对哔哩哔哩、秒拍等16家短视频网站进行联合约谈并要求整改。

7月27日，秒拍发布了《正视问题全面落实整改公告》，称完全接受处罚，强化内容机制和编审监管，建立黑名单制度，对发布违法违规内容的创作者一律永久封停。

# 港媒：中国铁塔香港IPO获8.4亿港元的孖展认购

《香港经济日报》综合6家券商数据报道称，中国铁塔首次公开募股(IPO)获得8.4亿港元的孖展（英文为Margin，即保证金的意思，实际上就是香港对杠杆式交易制度的称呼，又称保证金交易）认购，相当于面向散户发行规模34亿港元的25%；该新股将于周二中午截止认购。

原定于7月下旬在港交所IPO的中国铁塔，近期延期，预计在8月8日在香港正式IPO，其有望成为港交所H股上市，规模最大的IPO。

此次中国铁塔上市的一大看点就是引入了阵容豪华的基石投资者。据招股书显示，中国铁塔已获10家基石投资者认购，累计投资金额14.235亿美元，约占上市后已发行H股的18%。阿里巴巴旗下淘宝中国认购1亿美元。

# 特斯拉探索在欧洲建造“超级工厂”

![](../Images/0c89d1ef366fcde1ca9bccfe502ce64a.png)

据华尔街日报消息，特斯拉的国际扩张势头正在增强，德国和荷兰的有关部门正与该公司展开谈判，以建造其在欧洲的首个“超级工厂”。参与谈判的官员称，谈判处于初期阶段。

此前特斯拉CEO马斯克上月暗示，特斯拉可能会在年底前宣布在欧洲设立一家工厂，随后他在上月的一篇推文中表示，德国是领先选择。

参与谈判的官员表示，本月宣布计划在中国建设首个海外工厂的这家硅谷汽车制造商，已与德国两个州进行了初步讨论，这些州竞相计划在欧洲设立一个所谓的千兆工厂，生产电动汽车及其电池。该官员还表示，谈判仍处于初期阶段，可能无法达成协议。

一位荷兰政府官员表示，特斯拉还讨论了在荷兰建造该工厂的选项。

# 乐天百货回应“撤出中国内地”：有商讨对策，尚无具体方案

![](../Images/5fceb3bf61163f815d09e451b0a12d86.png)

针对有关乐天百货将撤出中国内地市场的消息，乐天中国方面做出回应。

7月30日，乐天中国方面回应称，公司在“商讨相应的对策”，但“目前还没有确认任何具体的方案”。

7月30日，韩国《朝鲜日报》消息称，继今年5月出售其在华超市业务后，乐天集团旗下高端百货连锁乐天百货计划出售其在中国内地的门店。韩国媒体提到，乐天无法继续承担中国百货越来越高的运营成本。

对此，乐天中国公关负责人向澎湃新闻回应称，“在中国的零售市场因为网购等新业态的冲击，市场竞争激烈，我们有商讨相应的对策。但目前还没有确认任何具体的方案。”
