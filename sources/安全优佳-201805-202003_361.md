# 传ofo和滴滴谈判接近尾声，联合创始人：近期还有新融资进账

![](../Images/cb2ba7b7d5d7eccc8bacbcee710e293e.png)

7月29日，ofo又有新消息，有知情人士表示，ofo被滴滴收购的谈判已经接近尾声，滴滴还在不断降价，每谈一次价格就要折损一次，对此消息，ofo联合创始人于信回复称：“不存在的事”。

此外，于信称，ofo在近期还将有一笔新的融资进账。新的融资确实已经在计划内，“应该不会等太久”。此前有消息称ofo想通过拿到阿里的融资洗掉滴滴的控制权，对此，于信否认称，“我们从没有过这样的想法和打算”，他称，“滴滴是ofo的重要股东，阿里巴巴也是我们的重要股东，所有股东对我们都很重要”。

# 港媒：中银香港、京东金融可能与腾讯联手申请香港虚拟银行牌照

![](../Images/f152f74b7e9caef459e4858bcab7f554.png)

# 消息称美团又逼商家二选一，美团表示系合同过期服务商

![](../Images/9116b1d27a28a1e9fdc796bc3ca7cecc.png)

近日，有消息称美团已于7月16日陆续关闭银盒宝成、辰森等服务商的服务接口，这批被关闭的服务商大多与其他外卖APP有着深度合作。

银盒宝成CEO崔巍巍表示，公司并没有提前收到美团方面的通知，而是从商户处得知这一情况。

美团称，美团点评餐饮开放平台对服务商进行整体梳理后，对合同过期的服务商关闭了接口。其中，辰森和银盒宝成两家均为合同过期。

# 乐视起诉易到致司机提现账户被冻结 易到整体负债由20余亿元飙升至近50亿元

![](../Images/de507946253b92dad18b729087c29fd4.png)

7月27日，网约车平台易到再次发布通知称，平台用于车主提现的账户于7月20日被法院诉前保全冻结，对车主正常提现造成影响。

一周前，易到发布公告称，韬蕴资本入主后发现易到整体负债由乐视承诺的20余亿元飙升至近50亿元。

易到工作人员表示，乐视在主导易到期间，通过易到大量采购乐视系电视、手机等硬件产品。经查，此类交易数额巨大，交易商品多用于易到彼时的大额充返馈赠，并非易到市场硬性需要，属不正常关联交易，这为易到带来了巨大债务。

在韬蕴资本接手易到后，乐视一直试图通过该关联交易干扰易到正常运营，也因此影响到广大车主正常提现。

# 大众点评回应小红书侵权投诉：已全部下线封号

![](../Images/ff157a4436b979687a37249e45f45fa1.png)

7月29日消息，近期小红书官方微博及其部分内容作者投诉称大众点评上出现大量未经授权的小红书账户及内容。

对此，大众点评回应称接到投诉后高度重视并立即采取相关技术措施，在7月27日第一时间完成所有内容排查与全部清理下线。

经调查，该事件发生是因为大众点评新上线试运营的推荐栏目在未经授权的情况下对相关内容进行了违规转载。

7月28日下午，小红书官微发布声明，指责大众点评大量抄袭小红书用户的内容。据小红书估计，抄袭的数量在百万条量级。

小红书方面称，根据《中华人民共和国著作权法》第四十七条及《民法通则》第九十九条的规定，大众点评的行为严重侵犯了小红书及小红书用户的合法权益。小红书会对大众点评追责到底，帮助用户维权。

# 乐天玛特之后，乐天百货拟撤出中国内地市场

![](../Images/502a19eeb82af8f4234a6303a6b95307.png)

继韩国大型零售商乐天玛特谋划逐步撤出中国内地市场后，该事件再有进展——乐天集团旗下高端百货连锁乐天百货（LOTTE DEPARTMENT STORE）也计划出售其在中国内地市场的门店，可能逐步撤出中国内地市场。

一位韩国流通行业的知情人士向第一财经记者独家透露，因受到在中国内地市场业务亏损的影响，乐天着手评估乐天百货在中国内地市场撤出的可行性。这也就意味着，继易买得之后，又一家韩国零售连锁很有可能将告别中国内地市场。

# CNBC：恩智浦CEO称本来值得考虑延长高通收购案的最后期限

![](../Images/d17827e16632df632dc8e3e2ed876b89.png)

据彭博援引CNBC报道，恩智浦CEO Rick Clemmer表示，原本至少值得考虑把高通收购案7月25日的最后期限延长。Clemmer称：“由于中国商务部必须到10月15日的第三阶段给出答案，至少值得考虑延长”。当被问及如果中国同意，是否有机会重启交易时，他说：“我不这么认为。现阶段的重点是我们未来几年，如何在自己的道路上创造更多的价值。”

7月26日，高通宣布其间接全资子公司Qualcomm River Holdings B.V.终止对恩智浦半导体的收购，立即生效。按照收购协议条款规定，Qualcomm River Holdings将于2018年7月26日向恩智浦支付20亿美元收购终止费用。
