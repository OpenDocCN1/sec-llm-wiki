# 微信QQ聊天记录将成为举证有效证据

近日，广东自由贸易区南沙片区人民法院出台《互联网电子数据证据举证、认证规程》。

规程参考已经颁布施行的电子签名法以及尚在审议过程中的“电子商务法”，结合实践中出现较多的证据类型，将互联网电子数据证据限定为短信、电子邮件、QQ、微信、支付宝或其他具备通讯、支付功能的互联网软件所产生的，能够有形的表现所载内容并可以随时调取查用的数据信息。

法院在采信微信相关的证据时,由于微信并未强制进行实名认证,但根据当事人提供的对方微信号、绑定的手机号码以及聊天中透露的相关信息内容,法官可以结合日常生活经验,综合相关信息,适用高度盖然性原则分析认定微信使用者的身份。对于微信聊天记录的真实性问题,则可以通过双方各自所持有的微信聊天记录,对比分析是否存在删除篡改关键内容的情况,据此作出事实认定。

# 中消协征集华帝“退全款”活动相关投诉，华帝发声：退款工作已开展

针对华帝用户退全款遇阻，7月19日，中国消费者协会（下称“中消协”）发布公告称，华帝公司推出“法国队夺冠，华帝退全款”的营销活动，现法国队已经夺冠，但据消费者反映和媒体报道，华帝公司未能依约定兑现承诺，现公开征集投诉。消费者可以在中国消费者协会官网下载《消费者投诉登记表》，按照表格要求完整填写相关信息，将投诉材料发送到中消协指定邮箱。

7月18日，中消协在官方微博回应“法国队夺冠，华帝退全款”称，希望华帝切实履行承诺，按照售前约定和承诺，切实做好每一位消费者的退款工作。

20日，华帝公司官方微博发声：目前消费者退款工作已在紧张有序的开展。我司将恪守诚信原则，严格按照售前约定及承诺，切实地做好每一位消费者的退款工作。

# 超级高铁公司HTT将在贵州建中国首条超级高铁

19日，铜仁市与美国超级高铁公司在贵阳市举行“真空管道超级高铁研发产业园项目”签约仪式，标志着超级高铁项目落户贵州铜仁迈出了坚实的一步。据了解，这是美国超级高铁公司与中国签署的第一份超级高铁建设协议。

根据协议，铜仁市政府与HTT公司将分别以1:1的出资比例在铜仁市成立合资公司，共建“真空管道超级高铁研发产业园”项目。

据悉，与美国超级高铁公司合作建设真空管道超级高铁产业园项目，有利于推进铜仁市实体经济和交通旅游融合发展，提升铜仁知名度和影响力，促进铜仁经济社会加快发展。

# 高德、百度、腾讯手机地图齐回应：取消没必要的用户隐私获取

手机联系人、发送短信、获取通讯录……在被上海市消保委曝光后，百度、高德、腾讯三家手机地图类App，决定取消这些与地图应用无关的个人隐私信息获取。

针对评测中发现的问题，高德地图、百度地图、腾讯地图在18日发布会上作出了积极回应，并在7月19日提交了书面反馈。

高德地图表示：正紧急对相关权限申请进行下线处理，7月20日会发布新版。在旧版产品中出现的，涉及部分用户的获取手机联系人等权限申请，在新版本产品中会全部取消。

百度地图表示：将在后续的版本中去除短信分享的功能，从而不再获取发送短信的权限。

腾讯地图表示：已在安卓版本中停止获取通讯录权限，iOS将在后续的新版本中删除该权限。

# 滴滴与软银成立合资公司 进军日本出租车打车市场

7月19日，滴滴出行宣布与软银公司（“软银”）成立合资公司，即将在日本为本地居民和游客提供出租车打车服务和智能交通解决方案。

滴滴出行总裁柳青表示：“滴滴相信人工智能技术上的创新能为出租车行业和公共交通产业带来新的发展。我们期待着与交通界伙伴展开广泛的合作, 为日本和亚洲的智慧城市建设做出贡献。”

官方数据显示，滴滴出行为超过5.5亿用户提供包括出租车、私家车到共享单车和外卖的多种按需服务。滴滴也是全球最大的出租车线上叫车平台，服务超过200万出租车司机。

# 外媒报道称ofo关闭在美多数业务 ofo暂未回应

据华尔街日报报道，ofo计划关闭其多数美国业务。对此，ofo方面并未给出回应。

该报道称，ofo将裁减美国的绝大多数员工，并撤回到少数几个大城市，但目前尚不清楚哪些城市将受到影响。外媒还表示，ofo在美国的员工总数约100人左右，截至6月份，ofo在美国投放了超过四万辆自行车。

近期，ofo对海外市场集中了集中调整。7月初，ofo宣布停止在以色列和中东地区的业务运营，表示其将转而深耕新加坡、美国、法国等规模大、增长迅速的重点市场。不过随后，又有外媒相继曝出，ofo将推出澳大利亚与德国市场。

# 新能源车补助政策调整，中央与市级补助不超汽车售价60%

19日，北京市财政局发布消息称，市级新能源车补助政策将有调整，中央与市级补助上限为汽车售价的60%，其中地方补助按中央补贴的50%安排。

为推广新能源汽车应用，市财政局、市科委、市经信委两年前曾发布市级补助政策。今年，财政部等四部委印发《关于调整完善新能源汽车推广应用财政补贴政策的通知》。据此，市财政局等三部门结合北京实际情况，研究制定了市级新能源汽车推广应用补助政策，对相关补助条款进行调整完善。

北京市新能源汽车补助的对象是消费者，消费者应获得的补助资金由新能源汽车生产企业或销售机构先行垫付。汽车生产企业或销售机构申请中央和北京市财政补助总额最高不超过车辆销售价格的60%。

根据国家四部委“地方财政补贴不得超过中央财政单车补贴额的50%”规定，北京市按照中央与地方1：0.5比例安排对新能源汽车（纯电动汽车、燃料电池汽车）的市级补助。

# 高通CEO：如果收购恩智浦失败 进行进行股票回购提振股价

据外媒报道，高通首席执行官史蒂夫-莫伦科夫（Steve Mollenkopf）日前在接受《纽约时报》采访时表示，如果高通收购恩智浦的交易无法获得中国政府批准，该公司将计划回购200亿美元至300亿美元的公司股票，以提振公司股价。

在2014年出任高通首席执行官的莫伦科夫表示，即便是没有恩智浦，高通也依旧能够繁荣发展，“因为高通拥有卓越的技术线路图。无论与恩智浦的交易有什么样的结果，该线路图都将是有价值的。”

该线路图的核心就是5G。莫伦科夫预测，5G将带领高通超越智能手机领域。他补充说，自签订收购恩智浦的协议以来，高通通过向汽车销售更多芯片，在业务多元化方面取得了进展。目前，高通来自汽车行业的芯片订单已达到40亿美元。
