# 中兴解禁3日，三大运营商火速送来5亿元订单

7月16日和17日两天，三大运营商分别公布了一批通讯设备中标候选人名单，中兴均有涉及。获得解禁之后的中兴通讯，近日接连收获国内三大运营商的大额订单，业务迅速回归正轨。

7月15日，中兴通讯发布公告称，根据BIS于2018年7月13日（美国时间）发布的命令，BIS已终止2018年4月15日拒绝令，并将中兴通讯从《禁止出口人员清单》中移除，上述事项自拒绝令解除令发布之日起生效。

解禁第二天，中国移动就发布公告显示，2018年GPON设备（新建部分）集中采购（标段二、标段三）的中标候选人名单中，标段二部分，中兴通讯为第一中标候选人，中标份额不低于70%，投标报价4.87亿元（不含税）。

17日，中国联通也公示，将对2017-2018年中国联通高端交换机扩容项目（中兴部分）进行单一来源采购，采购内容为主控板卡、10GE板卡、百兆/千兆光板卡等。

同样是在17日，中国电信公示的2017年CN2网络扩容工程——接入交换机——中标候选人中，中兴也成为第一中标候选人。据披露，中兴投标报价为256.84万元。

# 人民日报、央视评“华帝退款”：霸王条款，可能要“凉凉”

19日，人民日报和央视都对近期备受关注的“世界杯法国队夺冠，华帝退全款”一事进行了点评。

人民日报评论微博写道：（华帝）一些经销商称，买的时候光有小票没签协议就不能退。这也是霸王条款了。要知道，如果没有后续服务和诚信做支撑，营销堆出来的热度峰值，也可能马上“凉凉”。

央视财经也表示，“华帝退款”事件中，线上的消费者，“退款”变成了“退购物卡”。线下的消费者，除了发票之外，店铺还要求消费者提供在活动期间签署的选择“夺冠退全款”优惠的活动协议。在实体商店退款碰壁的消费者却纷纷反映，在购买之时并没有听说有此项退款活动协议。业内人士表示，对于商家的失信，消费者可以依法维护自己的正当权益。

# 欧盟给谷歌开43亿欧元天价罚单，谷歌不服将提起上诉

7月18日，彭博报道援引内部人士消息称，谷歌因安卓系统问题面临43亿欧元欧盟罚款，创欧盟史上最大罚单，目前，谷歌已对此处罚结果提起了上诉。

谷歌CEO桑德·皮查也在谷歌官网发文抗议，他认为欧盟委员会针对Android及其商业模式的罚单定忽略了Android手机与iOS手机竞争的事实。也忽略了Android为成千上万的手机制造商和移动网络运营商提供了多少选择，正是这些手机制造商和移动运营商在生产并销售Android设备。此外，世界各地有数百万的企业依靠开发Android应用为生；数十亿的消费者使用着廉价的安卓手机。

此前，有报道称，欧盟反垄断机构欧盟委员会表示，美国科技巨头不公平的移动设备战略强化了其在搜索市场的主导地位。欧盟委员会可因此向谷歌征收年营收的10%作为罚款，这相当于111亿美元。欧盟委员会还可能会要求谷歌不得把Android 与Chrome浏览器和其他服务捆绑在一起。

# 百度外卖代理商维权索赔4.6亿元，百度回应：已尽最大努力提供帮助

近日来自全国各地的百度外卖代理商聚集在百度总部进行维权，16日到现场的人数已达100人以上，据悉还有100多家代理商仍然在路上。

百度代理商指责百度对代理商采取过河拆桥政策: 不承认代理商的存在 、不承认代理商高达10亿元的投入；由饿了么来接管百度代理商打下的市场数据和市场份额，卸磨杀驴。

百度代理商集体诉讼的标的是4.6亿元人民币。

对此，百度方面回应称，百度集团是百度外卖投资方之一，不参与日常运营，相关地方合作商与百度外卖之间的代理关系及具体的运营策略，与百度集团无直接关系，百度方面已尽最大努力提供帮助。

# 乐融大厦揭牌仪式取消：或因乐视控股方静坐抗议

7月18日，乐视网董事长、乐融集团CEO刘淑青当日正式发布乐融品牌，并举行乐融大厦揭牌仪式。但在品牌发布过程中，刘淑青表示，因受到乐视控股方阻碍，揭牌仪式取消。

当发布会结束，相关阻碍人员已经离去。

随后，腾讯《一线》向乐融集团内部员工了解到，今年上午早间，确有自称乐视控股财务人员的人士带领4-5人来到乐融大厦楼下静坐，抗议大楼改名。

知情人士称，乐视控股方面对其阻碍，或因此前乐视网与乐视控股在债务切割方面的纠纷。

# 影响市容！深圳交委喊话酷骑单车，限其10日内把车全部回收清走

7月18日，深圳市交通运输委员会等部门发布关于加强酷骑（北京）科技有限公司（以下简称“酷骑单车”）遗留车辆清理处置的通告。

公告称，酷骑单车在国家企业信用信息公示系统已被列入经营异常名录，酷骑单车长期滞留公共空间，且已不能提供相应服务，给城市管理和交通安全带来较大负面影响。为维护市容环境和道路公共秩序，保障城市交通安全有序运行，要求酷骑公司10日内，将滞留在深圳市的自行车全部回收，或书面明确交由政府相关部门处理。
