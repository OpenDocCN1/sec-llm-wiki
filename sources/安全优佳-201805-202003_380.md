# FF汉福德工厂获临时办公许可，贾跃亭：要创造共享的智能出行生态

近日，贾跃亭的FF位于加州汉福德的工厂获得临时办公许可牌照（TCO, Temporary Certificate of Occupancy）。

FF方面表示，获得TCO是近期公司一系列里程碑事件的重要一环，为在2018年底交付公司首辆电动车FF91奠定了基础。

FF创始人兼全球首席执行官贾跃亭表示，“对于汉福德政府官员致力于帮助FF完成FF91生产交付的努力印象深刻，我们不仅要在新的工厂破土动工，而是要打破传统工业与互联网、IT、新能源和汽车的边界，创造共享的智能出行生态。”

7月13日，恒大董事局主席许家印等人到美国对FF视察，在公布的消息中显示，FF董事长已经由贾跃亭变成了夏海钧，许家印视察FF贾跃亭全程陪同。

# 世界杯期间华帝股份大赚 退款后仍入袋近4亿元

7月16日，在法国队夺冠的同时，华帝股份官方微博宣布：“庆祝法国队夺冠，华帝退全款启动！董事长再次签字！”

此前，根据华帝股份在今年世界杯期间启动的营销方案，若法国国家足球队2018年在俄罗斯世界杯足球赛中夺冠，则对在2018年6月1日0时至2018年7月3日22时期间，凡购买华帝股份指定产品并参与“夺冠退全款”活动的消费者，华帝将按所购指定产品的发票金额退款。

根据7月5日华帝股份发布的关于营销活动情况的公告显示，此次退款活动华帝股份以及经销商需要承担的费用总计低于7900万元。

受此利好消息影响，华帝股份股价自7月5日开始就不断上涨，截至7月16日，公司股价在8个交易日内，累计上涨了13.03%。

据华帝股份发布的关于营销活动情况的公告显示，经初步统计，世界杯期间，华帝股份总计销售收入10亿元左右，按照2017年公司销售毛利率45.47%来计算的话，其营业利润为4.55亿元左右。减去需要退款的7900万元，仍有3.76亿元左右的营业利润。

# 拼多多获腾讯、红杉资本各增持2.5亿美元，最高拟融资18.7亿美元

# 中兴复活3日获3.77亿主力资金流入，供应链和工程交付部门最忙

7月15日晚，中兴通讯公告称，美国商务部工业安全局（BIS）已终止2018年4月15日拒绝令，并将中兴通讯从《禁止出口人员清单》中移除。

长达三个月的“中兴通讯”拒绝令风波，终于在中兴通讯管理层大换血、设立独立特别合规协调员、支付14亿美元民事罚款等“替代和解协议”内容达成后基本平息，中兴通讯也火速恢复正常经营。

中兴通讯内部人士透露，中兴全面恢复运营后，之前所有订单按优先级排序开始正常发货。为全力追赶进度，中兴通讯供应链和工程交付部门最为忙碌。

7月16日，中兴通讯AH股大幅拉升，wind数据显示，当日中兴通讯A股吸引了3.77亿元主力资金流入，机构净买卖9789.44万元，净买入金额占当日成交额比例达3.11%。

# 港交所行政总裁李小加：内地拒小米入港股通是小算盘 将与证监会商榷

# 乐视大厦更名乐融大厦：已被乐视控股质押给乐融致新

乐视网方面向腾讯《一线》确认，乐视大厦已在近日更名为“乐融大厦”。早在今年4月，乐视网旗下电视运营公司乐视致新已更名为乐融致新。

据了解，即便乐视大厦股权目前仍归属乐视非上市体系归属乐视控股，该大厦的所有权目前归属于北京宏城鑫泰置业有限公司，该由乐视控股100%持股，且被乐视控股质押给重庆乐视商业保理有限公司，出质金额为5000万。

重庆乐视商业保理有限公司是乐视投资管理(北京)有限公司100%控股的子公司，后者又是乐融致新的全资子公司。

这也意味着，目前乐融大厦虽然并未归属乐融致新，但已被其所有方乐视控股质押给乐融致新。

# 滴滴预计分拆车服业务，为IPO计划铺路

据《财经》消息，滴滴将分拆其车服业务，这次分拆是为滴滴的上市计划做准备。

关于这次分拆，滴滴车服准备以约30亿美元的投前估值，融资10-15亿美元。软银是意向投资者之一。不过最终方案尚未完全敲定。

滴滴于2018年4月16日宣布成立汽车服务平台（简称：车服）。汽车服务平台隶属于滴滴快捷事业群，整合了原汽车后市场、运力中心、海浪（租车业务）和优步等多个部门人员，整合后下设业务包括——加油、维保、汽车开放平台和分时租赁。该部门由快捷出行事业群副总经理陈熙（Kevin）担任负责人。

据当时的内部信显示，滴滴汽车服务平台年化交易额超过370亿元人民币，覆盖城市200多个、合作伙伴和渠道商5000多家。2018年，其年化交易额的目标是900亿元人民币。

# 饿了么、百度外卖上线视频巡查系统 实时监管餐馆后厨

7月16日，饿了么及百度外卖宣布双方在43座城市的商户成立明厨亮灶联盟，平台在APP上开通明厨亮灶专区，给予联盟商家以流量支持。同时，平台将借助后厨摄像头，启用可自动识别后厨食安违规现象的智能视频巡查工作站，全天候保障后厨食品安全。

据介绍，饿了么于2016年初首次提出明厨亮灶项目，旨在通过商户后厨的直播摄像头，在饿了么APP上实时展现后厨洗净、切配、烹饪等过程，让广大用户透明消费、放心消费。截至目前，项目已覆盖北京、上海、广州、深圳、成都等43个城市，参与商户超过5000家，每天触达用户达百万。

# 苹果对iPhone X期望过高 导致零部件大量库存
