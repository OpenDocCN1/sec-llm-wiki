# 高通：三星、华为仍用高通芯片 代表我们做得好

近日，高通全球副总裁沈劲再次回应了手机芯片竞争激烈的问题。他表示，华为、三星都自产芯片，但高通芯片如果做得比较好，他们还是会继续使用。

被问及关于目前三星、华为自产手机芯片的状况时，沈劲表示，这个情形是一直存在的。三星自己有芯片exynos，也会用高通芯片。华为有自己的芯片，也部分采用高通芯片。

“我们也没什么可选择的，就是努力把芯片做得最好。 如果我们的芯片，确实比友商做得好，我相信他还是会使用。 我们专注做芯片，道理上来讲，应该能够推出最好的。”沈劲说。

# 百度等三平台再遭约谈：竞价推广致维修企业诚信缺失

上海市消保委第二次就空调维修“套路”约谈58同城、百度、360三平台。

此前，市消保委将空调遥控器设为乱码，从11家网络平台找11家维修企业上门维修空调，结果9家虚构电脑板故障、缺少制冷剂等毛病，骗取维修费。

市消保委于7月2日曝光这一体察结果后，7月9日，各平台依约回应，都将此定为个案。

7月11日，市消保委再次约谈58同城、百度、360三家体察中问题突出平台。澎湃新闻记者在约谈现场发现，针对维修商不诚信等问题，平台已开始排查，部分平台已下架所有推广，不过，平台对上线维修商核实仍不给力。

市消保委副秘书长唐健盛告诉记者，在此次空调维修体察中，消保委发现，平台靠流量卖钱，不法维修企业为收回买流量的费用，再去欺骗消费者，而正常的维修企业因为买不起流量，失去客单，加之平台审核不严，这个市场最终出现“劣币驱逐良币”现象。

# 富士康在硅谷成立AI公司

据国外媒体报道，富士康近期在加州硅谷成立了一家新公司，专注于研发工厂领域的人工智能技术。

该计划的出台，正处于全球智能手机销售放缓的背景下，同时工人要求提高工资待遇，还有不断变化的劳动力市场，富士康所处的制造业开始面临越来越严峻的挑战。

郭台铭表示，新公司计划聘请超过100名工程师和人工智能深度学习技术专家。

目前富士康在美国已经建造了一家投资超过100亿美元的工厂，为当地提供了数百个工作机会，并且获得了当地政府的免税政策优惠。

# 特斯拉上海工厂投资或达百亿美元 规划年产量为目前全球产量5倍

7月10日，特斯拉公司（Tesla）与上海临港管委会、临港集团共同签署了纯电动车项目投资协议。特斯拉公司将在临港地区独资建设集研发、制造、销售等功能于一体的特斯拉超级工厂（Gigafactory 3），该项目规划年生产50万辆纯电动整车，事实上，这一数字相当于目前特斯拉全球总产量的5倍。

有业内人士对《证券日报》记者称，筹建年产能25万辆纯电动车总装厂的投资总额就高达25亿美元至50亿美元，特斯拉上海工厂整体投资或超过百亿美元级别。

# 小米在美国取得另类成绩：成最大共享滑板车供应商

据外媒最新消息，小米在一个美国另类的市场获得了巨大成功，该公司已经成为美国最大的电动滑板车供应商。

和中国街头的共享单车类似，在过去半年时间里，共享电动滑板车在美国城市风靡一时，Bird等多家公司争先恐后在多个城市投放滑板车，给消费者带来出行便利，也给地方政府带来了监管麻烦。

据美国科技媒体Quartz报道，许多人不知道的是，小米中国已经成为美国主导的电动滑板车代工企业，由小米供货、然后贴上美国公司商标的电动车大量出现在街头。

共享电动滑板车领域的“独角兽”公司Bird已经投放了大量小米供应的滑板车。据报道，该公司五月份可能和小米签署了采购协议，采购价值数千万美元的电动滑板车。

# 广东警方破获比特币网络赌球大案 流水资金超百亿

广东省公安厅11日晚通报称，该省茂名警方近日破获一个利用比特币进行网络赌球的特大案件，流水资金超百亿元。

此次收网行动打掉20余个涉案团伙，抓获540余名犯罪嫌疑人，捣毁70余个赌博APP和网站，关停250余个网络社交平台聊天群，冻结2.6亿余元涉案资金，扣押一批服务器、电脑、手机、银行卡等涉案物品。

警方专案组侦查发现，这一网络赌博平台服务器搭建在境外，是集传统网络赌博、暗网技术、区块链虚拟货币交易和聊天工具推广运营于一体的赌球集团。这一赌博平台上线运营8个多月，就发展两级代理8000余人、会员33万人，涉及多个国家和地区。由于平台充值只接受虚拟货币，一般会员不会操作，因此派生出很多输赢交易内部对冲群，代理资金流水超百亿元。

# 摩拜开展旧车回收工作，计划回收至少10万辆旧车

7月11日，摩拜单车方面宣布，在上海正式开展旧车回收工作，计划回收至少10万辆旧车，同时不少于5万辆新款摩拜单车将与市民见面。

新款摩拜单车采用橙白相间的线条配色，在摩拜内部将其称为“三文鱼车”。车身强度超欧盟标准50%，而整车仅重15.5千克。

对于确认报废的回收车辆，摩拜单车将统一回库返厂后，交由再生行业专业的合作伙伴为摩拜单车提供单车生命周期结束后的回收拆解及无害化处理等专业化服务，实现废旧车辆100%回收。
