# 小米今日上市，超过200名员工来港鸣锣 挤爆港交所

7月9日早上7点刚过，港交所后门就排起了长队。腾讯《一线》现场获悉，仅小米员工据说就超过200人，再加上小米集团从内地带来的庞大媒体观光团以及嘉宾等，此次参加小米挂牌仪式的人数预计超过700人。

# 华为：不会成为美国制裁目标 今年仍购买美国芯片

据国外媒体报道，华为一位联席主席胡厚崑对法国媒体《星期日周报》(LeJournal Du Dimanche)表示，华为自己不会成为美国制裁目标，今年它仍然会购买美国芯片。

胡厚崑表示“十年前，我们就建立了一个系统来控制我们的出口，这已经变得非常有效。我们的政策是严格执行欧洲、联合国和美国提出的所有法律法规。”

目前，华为是全球最大电信网络设备制造商，也是全球第三大智能手机制造商。

近日，欧洲电信巨头Altice葡萄牙分公司将与中国企业华为在5G网络方面展开合作，双方这一合作的目标是让葡萄牙在开发和推出5G网络方面领先于欧洲其他地区。

# 微信客户转错账遭对方拉黑，腾讯：保护隐私对所有用户负责

据中国之声《新闻纵横》报道，不小心微信转账转错人，对方收了钱不还，甚至还删好友、拉黑。近日，广东黄先生微信转账8万元转错人的事情，引起社会广泛讨论。腾讯公关部相关人员表示，已和那名用户联系并进行沟通，正在配合警方一起解决此问题。

对于微信转错账问题是否可以要求腾讯提供对方信息，腾讯集团市场与公关部相关人员向记者表示，由于涉及用户隐私，微信方面无法向转账人提供收款人的任何信息。

腾讯公关的相关人员强调，保护用户隐私是互联网公司的底线。他们要对所有用户负责，只要司法机关要求微信官方协助，他们肯定义不容辞，但如果是个人需要，不能突破底线。

# 腾讯宣布已向港交所提交有关腾讯音乐分拆建议，估值在290亿至310亿美元之间

8日，腾讯控股发布公告称，公司已根据第15项应用指引，向港交所提交有关其在线音乐娱乐业务通过经注册的公开发售在美国的认可证券交易所独立上市的方式拟进行分拆的建议。这意味着，腾讯音乐将在美上市，目前其估值在290亿至310亿美元之间。

2016年，QQ音乐与中国音乐集团和评委腾讯音乐娱乐集团，实现了QQ音乐、酷我音乐和酷狗音乐的曲库合并，目前腾讯音乐独家代理了包括环球、索尼、杰威尔、YG娱乐、华纳等音乐版权。

# 法拉第FF91高速测试：250千米/小时的速度跑三分钟没问题

据外媒消息，法拉第FF91在俄亥俄州东自由区的交通研究中心进行了车辆的高速测试。

在三天的测试过程中，法拉第用了一辆代号为“熊猫特快”的测试车，该车采用黑白双色涂装。它在测试赛道上跑得飞快，在155英里/小时（约合250千米/小时）的速度上保持了三分钟。

“熊猫特快”在测试中共三次跑到155英里/小时，而在这之间，该车还在75英里/小时（约合120千米/小时）的速度上巡航了两分钟。跑完测试圈这辆车只花了不到15分钟，不过这已经吸掉了它三分之一的电量。

# 特斯拉全系车型上调售价，Model X最高涨价25万

由于国内对美国的整车进口关税在7月6日的12：01起开始由15%上调至40%。因此，特斯拉在其官网上公布了目前在国内售卖的两款车型Model S和Model X的最新售价调整。

特斯拉官网显示，目前国内在售的Model S、Mode X车型，售价已经全线上调。以Model X最低配的75D为例，售价由之前的77.56万元，上涨至92.72万元，涨幅达15.16万元。而Model X P100D车型则达到了夸张的25.66万。

# 无人驾驶公司景驰陷舆论漩涡：被诉、人事内斗分家

无人驾驶公司景驰科技“高管伪造签名质押股权事件”上演大反转。7月8日，针对景驰科技前法人代表潘思宁日前发布的“CFO等人伪造签名质押股权”的说法，景驰科技发布官方声明，称前北京景骐信息技术有限公司法人代表、执行董事潘思宁所述不实，且已被公司股东会罢免。

此前，景驰科技因创始人被诉、内斗分家等人事风波多次陷入舆论漩涡。

7月7日，潘思宁通过个人公众号发布消息，“景驰科技CFO吕庆等人未经潘思宁本人同意，将潘思宁的股权进行质押，”。

就此，景驰科技7月8日官方回应：“北京景骐信息技术有限公司股东会已经按照法律和公司章程的规定罢免了潘某法定代表人和执行董事的职务。”

# 传明年新能源汽车补贴再减三成，中汽协：未收到通知

7月6日，有外媒报道，“明年中国电动汽车的财政补贴将在2018年的基础上再减三成”。该媒体援引知情人士的话称，中国正在考虑明年进一步削减电动汽车补贴计划，因政府希望以此敦促汽车制造商依靠技术创新，而不是财政补贴来开发新能源汽车。

对此，《每日经济新闻》记者第一时间进行了多方求证，均被告知没收到此通知。全国乘用车市场信息联席会秘书长崔东树在接受记者采访称，他不了解这一信息，但上述知情人透露的‘明年电动汽车补贴标准下降以及针对车辆的续驶里程提高补贴’，均属合理范围。”

中国汽车工业协会秘书长助理许海东也表示，截至目前，协会方面还没收到任何有关2019年新能源汽车补贴标准的消息。
