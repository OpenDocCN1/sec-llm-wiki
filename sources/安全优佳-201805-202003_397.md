# 中国移动将在2020年前实现3G退网

在MWCS2018上海移动大会上，三大运营商宣布了将在2020年实现5G。现在最新消息，中国移动发布的《5G中端产品指引》明确，将在2020年前实现3G退网。

中国移动发布的《5G终端产品指引》报告提出，今年9月采购测试终端、连接型CPE，并需要厂商在11月交付。

5G网络确认将在2020年正式商用，意味着将在2020年到来之前，实现执行3G网络全部退网，彻底终结移动3G。

# 中兴通讯：确认获美商务部暂时部分解禁 有效期 一个月

中兴通讯7月6日早间公告确认获美商务部暂时部分解禁：公司和深圳市中兴康讯电子有限公司于7月2日收到BIS出口商服务办公室发送的在《美国出口管理条例》第764.3(a)(2)条下的有限授权。本授权自签发之日起生效，有效期截至2018年8月1日。本授权允许公司继续运营现有网络和设备；为现有手机提供支持；网络安全研究与漏洞披露；有限资金转移。

美国东部时间7月2日，美国商务部发布公告，暂时、部分解除对中兴通讯公司的出口禁售令。

公告称：从公告发布之日起至8月1日，在有限条件下解除对中兴通讯公司的出口禁令。美国商务部公共事务总监丽贝卡·格洛弗在接受CGTN记者问询时表示，对中兴通讯的7年禁售令并未正式取消。这份公告的授权对象是已经与中兴通讯开展业务的公司，期限是一个月。

7月5日消息，中兴通讯将任命电信云与核心网络产品线总裁徐子阳为中兴通讯新首席执行官。

徐子阳此前为中心通讯德国公司前首席执行官。与此同时，中兴通讯无线研究院院长，中兴通讯副CTO王喜瑜将出任新CTO。

上周，中兴通讯完成了新一届董事会的提名。8名新董事会成员分别是：李自学、诸为民、方榕、蔡曼莉、吴君栋、李步青、鲍毓明、顾军营。

# 美国芯片公司在华被禁售，美光公司：收到专利诉讼案判决的初步禁制令

腾讯科技引用外媒消息报道，美光科技5日宣布收到了来自中国福建省福州市中级人民法院的判决，针对联华电子和福建晋华集成电路有限公司起诉美光专利侵权一案对美光进行了初步销售禁令。

该初步禁令要求美光中国子公司停止制造、销售或进口包括动态随机存取存储器和NAND闪存类共26种产品。据悉，此次受影响的产品占美光年收入大约1%。根据美光预计，该禁令对公司的营收会造成1%的负面影响。同时美光表示，将遵守福州市中级人民法院这一判决。

今年1月，联华电子与晋华集成电路有限公司针对美光旗下中国子公司提起专利侵权诉讼。该诉讼认为美光部分DRAM模块和固态硬盘产品侵犯了联合电子与晋华在中国的专利。

# 小米否认涉足国外金融产品：不会向加密货币发行新股

近来，有国外加密货币公司宣称，可以帮助投资人用加密货币投资购买小米股票。不过这一说法很快遭到了小米公司的否认。

据BTManager等国外媒体报道，最近，位于塞浦路斯的加密货币公司“黑月”提供了一个投资产品，相当于小米股票的加密货币版本。投资人可以使用各种加密货币来购买，比如比特币、ETH、LTC等。另外为了防止大规模短期炒作，这家公司还面向投资人推出了“加密货币版”小米股票的交易锁定期，即在挂牌交易93天之内不得交易。

小米公司官方已经否认和上述公司有任何关系，小米表示不了解上述黑月公司的情况，另外，小米当前的工作中也不包括发行所谓的股票代币。

# 美团在京招司机，要求30岁以下不胖不抽烟，否认为美团打车进京招聘

7月5日，AI财经社独家获悉，美团正在北京招聘司机，提出三大硬性要求，必须来自特种部队，驾驶技术要好，并且不抽烟。还有五大任职要求，来自特种部队，年龄在30岁以下，熟悉北京路况，身材没有发福，并且没有在互联网行业工作过。

对于所招的司机，美团开出的条件相对优渥，成功应聘者可成为正式员工，具有浮动年终奖，公司提供五险一金加补充医疗以及住宿。

有分析人士认为，美团此举是在低调为美团打车进军北京布局。

对于招聘司机是否意味着即将开启第三城进入北京，AI财经社向美团求证，对方承认公司确实在招聘司机，但否认是在为美团打车招聘，也没有透露具体会招聘多少名司机以及司机的用途，只是强调美团很多部门都有可能需要司机。

# 传美团打车月亏损3.3亿元 官方回应不属实

7月5日消息，蓝鲸TMT报道称，据一位接近美团的投资人透露，美团打车每月亏损5000万美金（约合人民币3.3亿），以维持南京、上海的市场份额。对此，美团方面回应称“消息并不属实”。

腾讯《一线》此前曾报道，美团打车单均补贴为20元左右，当时美团方面未对此回应。去年底，美团打车宣布其日订单量突破10万单，若按照此数字计算，当时美团打车在南京一天的补贴达到200万元。

美团最近递交的IPO招股书显示，新业务及其他分部的销售成本由2016年的2.594亿元人民币增加325.1%至2017年的11亿元人民币，主要由于美团于2017年推出试点网约车服务，令网约车司机成本由2016年的零元增加至2017年的2.933亿元。

# 网约车近期频现打车难，滴滴建议乘客提前规划出行方式或拼车出行

7月5日，进入七月以来网约车叫车难的现象再次出现，有不少用户反应遇到了半小时没司机接单、非高峰时段也要排位等候的情况。

对于近期打车难现象，滴滴方面回应称，近日平台收到很多用户反映由于供需失衡，北京部分地区高峰期打车成功率下降，等待时间变长，我们深感抱歉，在此也提醒广大用户尽可能提前规划出行方式，更多通过预约或拼车出行，成功率会相对高一点。其他网约车平台暂未回复。

《北京市查处非法客运若干规定》7月起开始实施，严厉打击克隆出租车、“黑巡游车”、“黑网约车”、“黑旅游车”、“黑长途车”等非法运营行为。

# 苹果放弃未来在iPhone上使用英特尔5G基带芯片

腾讯科技引用外媒报道消息称，英特尔未来不会再向苹果的iPhone智能手机提供基带芯片了。英特尔确认，公司已经停止开发部分原本计划使用在苹果iPhone上的5G通信基带芯片。

据悉，苹果已经向英特尔发出通知，决定不在未来的iPhone上使用来自于英特尔的调制解调器，而此消息已经得到了英特尔内部人士的证实。英特尔这一决定将会影响苹果在2020年推出的iPhone智能手机，而明年的iPhone不会受到影响。

# 摩拜宣布将在全国实行无条件免押，2亿用户受益

7月5日，摩拜单车对外宣布，将在全国进行无条件免押，摩拜2亿用户均可享受。

今年5月初，摩拜先开放了首批合肥、东莞、杭州等6座二线城市，6月份又宣布百个二线城市免押，6月底进一步新增19座城市无门槛免押金。

摩拜单车副总裁李彧岑表示，摩拜通过数据调查发现，每个月都有200万用户频繁充、退押金，因此其从今年开始逐步尝试免押，截止今年6月，已经实现了1.05亿用户免押，并且增加了1500万新注册用户。

同时，摩拜单车方面还宣布，摩拜单车正式接入美团APP，拥有其独立入口。
