# 中国移动希望为美国和其他国家提供国际电话业务遭拒绝

环球时报消息，美国国家电信和信息管理局（NTIA）当地时间2日发表声明，以“国家安全”为由，建议美国联邦通信委员会（FCC）拒绝中国移动2011年提交的在美国市场提供国际电话业务的申请。

NTIA隶属于美国商务部，该部门7月2日发表的新闻稿称：中国移动2011年向FCC申请电信业务214牌照，希望为美国和其他国家提供国际电话业务，不涉及美国国内移动服务。中国移动按照国际牌照流程，请求美国政府行政部门就该申请是否符合美国公众利益发表意见。

新闻稿引述美国商务部助理部长大卫·雷德尔的意见称，在与中国移动进行大量接触后，“对国家安全和执法的担忧无法消除”。

# 华为在东莞拿下10宗住宅用地，还建了学校和医院

关于“华为搬迁至东莞”的消息，从本月1日起，就持续在发酵。华为方面回复称，“搬迁属于正常业务布局，并不是华为‘外迁’。华为在东莞松山湖基地建设已有一段时间，深莞两地早已安排正常通勤用车，华为松山湖南方工厂已在正常运转之中，这些均为正常业务布局。”

南都记者梳理华为在东莞松山湖的“拿地”矩阵发现：自2015年以来，华为凭大股东的身份，以东莞绿苑实业投资有限公司的名字，通过招拍挂市场，拿下共10宗限价住宅用地。占地面积合计约55.66万㎡，规定最高售价不能超过9500元/㎡。

东莞市国土局相关负责人公开回应称，这些招拍挂的地块的销售对象不限于华为员工，将由松山湖管委会统筹安排。

调查发现，华为在当地还投资和主办了民办国际化学校，提供从幼儿园、小学、初中到高中贯通15年的全学段国际品质教育。

还建有康华医院·华为门诊部，由康华医院携手华为打造，为华为乃至整个松山湖科技产业园区的基础医疗服务提供保障。

# 腾讯再次回应微信支付SDK存漏洞：实际影响范围不大，完全可控

此前，有报道称，微信支付官方SDK存在严重漏洞。之后，腾讯回应称已修复。

4日晚间，腾讯进一步回复称，该漏洞为常见漏洞，只要在程序接收到XML数据进行解析之前，调用相关的函数关闭XML语言的上述特性即可有效防范和解决。目前已经启动商户的安全提示，提示商户主动排查其自建系统是否存在该漏洞，并给出修复指引进行协助。腾讯还表示，此次问题服务器端SDK的实际影响范围不大，完全可控。

# 起底沃克理财：30多万人疯买的“虚拟币”实为传销，涉案总金额50亿元

近日，福建泉州市公安局通报了“沃克理财”案情况，据通报显示，这起传销案形成高达309层的传销网络，涉案总金额50亿元。此前，沃克理财火爆时需排队一个月才能买上其所发行的虚拟货币，短短一年内就吸引会员35万人。

沃克生活信息科技有限公司宣称是一家“互联网＋”投资公司，其经营的沃克理财号称集互联网金融理财优点于一身。如今，在互联网上仍然可以找到其宣传信息：“45天投资翻倍，一年可获得十倍收益”“只要有闲钱，躺着也能赚钱”。

今年年初，晋江市法院对这起案件作出一审判决，主要犯罪嫌疑人王良妙犯组织、领导传销活动罪，被依法判处有期徒刑13年，其余30名犯罪嫌疑人分别被判处1年至7年不等的有期徒刑。

# 广州打捞共享单车：河里捞出摩拜ofo超三千辆

4日，摩拜公司宣布为期半个月的广州河涌大作战即打捞共享单车行动结束，共捞起1178辆共享单车，61%为摩拜。

而另一共享单车ofo小黄车从今年4月份就着手在河涌打捞工作，截至目前，ofo共打捞近2000辆共享单车。

至于会不会用新车来置换这些被扔在水里的破损车辆，摩拜和ofo方面均表示不会。ofo方面表示，报废流程比较长，还要把报废的车牌号上交审核。目前主要是做减量工作，因此不会再投放新车。

# ofo App 上线小游戏，设置购买月卡入口，称不计划通过游戏盈利

7月4日，ofo APP近日上线了小游戏功能，被外界猜测似乎要通过游戏增加收入实现盈利。ofo方面回应称，小游戏的主要用途是为增强用户粘性，没有计划通过游戏盈利。

根据APP显示，在“我的”一栏，ofo上线了一款名为“天使的蛋生beta”的养成类游戏，ofo称该功能目前处于测试阶段，主要为增强用户粘性，没有通过游戏实现盈利的计划。

但是，AI财经社使用发现，该养成类游戏中依然设置了购买月卡的入口。

商业化是当下ofo的重要目标。目前，ofo的看看一栏中，除了常规广告之外，还上线了多个信贷品牌和P2P公司的广告。

有业内人士分析，P2P一个用户的价格通常会远高于普通线上用户的获取价格。因此，包括此前ofo用户退押金被诱导绑定玖富万卡均被视为ofo商业化过于着急的表现。
