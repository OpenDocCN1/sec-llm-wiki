# 央视点名：腾讯QQ群成滋生犯罪的温床，腾讯回应：对涉事账号永久封停

6月29日，央视新闻客户端发布《法治在线》调查《谋划绑架、招运毒马仔、诱导赌博…警惕QQ群贴吧变成滋生犯罪的温床》，展示一些网络平台以戒赌为名，却成为诱赌诱贷，乃至滋生违法犯罪的温床。新闻发布后，在网络引发热议。

7月1日，腾讯方面表示：感谢央视新闻针对网络平台不良及违法信息的监督和提示。QQ安全团队一直持续打击包括暴力、赌博等在内的各类违法违规行为。对涉事的QQ群及账号，一经核实，永久封停，绝不姑息。情节严重者，还将被提交至司法机关。

# 用户爆料使用百度手机输入法被后台录音，百度回应：为了加快语音启动速度

36氪消息，有微博用户爆料，用户在vivo NEX上使用百度输入法在打开手机自带的浏览器进行搜索的时候，在无任何操作的情况下，手机顶部显示“百度输入法正在录音”，并且会提示用户是否要禁止它。百度输入法官方微博回应称，只需要关闭智能场景语音功能后就可以消除该问题。

# 华为2700名员工搬至东莞，为员工提供3万套房，任正非：华为总部永远不离开深圳

7月1日，华为公司正式搬迁，40辆8吨货车，共60车次，搬迁车辆将往返深圳和东莞松山湖，搬家货车会有一个华为标识，“华为搬迁专用车辆”。

而7月2日，将有2700人从深圳到东莞松山湖溪流坡村上班。

华为内部人士表示，这次搬迁，除了研发团队外，还包括一些其他部门人员。

网传消息显示，华为在东莞会提供3万套员工住房，有华为员工对记者证实：“网传消息基本属实，但是能买房的员工要常驻松山湖，而且这类房子在5年后也不能像普通商品房那样随便卖，如果在华为工作不到5年，离职时需要将房子退回华为。”

在外界看来，华为近年来屡屡传出搬迁消息，或许和成本有关。

此前华为创始人任正非在接受媒体采访时谈到深圳：深圳房地产太多了，没有大块的工业用地了。大家知道大工业的发展，每一个公司都需要一定的空间发展。

那么，华为部分员工的搬迁，是否意味着是华为“去深圳化”的一部分呢？

答案是否定的。在去年上半年的一次座谈会上，任正非明确表示，华为的总部永远不会离开深圳。

# 央视曝光共享单车常扣费，ofo回应：确实存在，但比例不超过2%

7月1日下午，ofo就近日ofo小黄车“为开锁扣费”、“报修先扣费”等异常扣费问题作出回应，称经自查发现，ofo在48小时(系统研判时间)内的“报修后错误扣费返还率”超过90%，但在剩余近10%的“未返还”案例中，除去虚假报修案例外，确有“正常报修扣费未获返还”的个别情况存在，比例不超过2%，同时也在进行新流程的灰度测试。

7月1日，央视新闻频道《每周质量报告》关注了共享单车行业的“异常扣费”情况,其中涉及ofo小黄车“未开锁扣费”、“报修先扣费”等问题。

# 余额宝总规模达1.8万亿元，首超“四大行”个人活期存款

7月1日，中国基金报发布消息称，经过自家的统计，余额宝对接的6只货币基金2018年6月底合计规模达到了18602亿元，比2017年年底的天弘余额宝单只货币基金15798亿元，增加了2800多亿元。

同时这也是余额宝对接的6只货币基金规模首次超过“四大行”的个人活期存款业务，据悉中国银行在2017年的个人活期存款为余额为17986亿元。

# 腾讯宣布：《QQ宠物》正式停运，结束13年运营史

7月1日消息，腾讯近日宣布，将于2018年9月15日正式停止《QQ宠物》和《乐斗Ⅱ》的运营。

具体安排上，2018年07月05日，停止游戏充值和新用户注册；

2018年09月15日，正式停止游戏运营，关闭游戏服务器，停止官方渠道游戏客户端下载，玩家无法登陆游戏；

2018年09月30日，游戏官网、论坛、专属客服关闭。

游戏服务器关闭后，游戏内的所有帐号数据及角色资料等信息将被全部清空。

公开资料显示，《QQ宠物》是2005年腾讯推出的一款虚拟社区养成游戏。由腾讯互娱旗下魔方工作室开发。2005年6月，《QQ宠物》公测，至今，已持续运营13年。

# 苹果市值冲关万亿美元遭重挫 分析称市值被低估，还有潜力

近期苹果的冲关遭到了挫折，市值重新跌到了9100亿美元左右。不过外媒分析指出，苹果市值目前仍然被低估，未来还有增长的潜力。

腾讯科技通过雅虎财经美股行情数据看到，六月初，苹果股价曾经达到大约194美元的历史高位，距离一万亿美元的市值只剩下很小的距离。

# 6月份P2P网贷融资额34.8亿元 52家平台出现问题

7月1日，网贷之家发布《P2P网贷行业2018年6月月报》。

数据显示，截至今年6月底， P2P网贷行业历史累计成交量达到了73341.87亿元。今年6月份，P2P网贷行业的成交量为1757.23亿元。

本月网贷行业发生6例融资事件，总融资金额高达34.8亿元（美元兑人民汇率按照6.5：1计算）。

截至今年6月底，P2P网贷行业正常运营平台数量下降至1842家。据不完全统计，6月份停业及问题平台数量为66家，其中问题平台52家（提现困难49家、跑路3家），停业平台14家。

截至2018年6月底，累计停业及问题平台达到4334家，P2P网贷行业累计平台数量达到6176家（含停业及问题平台）。
