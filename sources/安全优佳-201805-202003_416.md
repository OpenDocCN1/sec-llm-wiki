# 恒大称FF91已满足全面量产条件 对赌协议确保许家印稳赚不赔

FF91何时量产，成为恒大投资FF后，舆论关注的焦点。恒大作为投资方与FF原股东签订了对赌协议，如果FF91不能按时量产，那么FF的控制权将全面转移到恒大手中。

对此，恒大方面表示，FF91完全满足了全面量产的条件。FF汉福德工厂现已全面开展大型生产线设备调试工作，计划2018年年底完成整体量产准备。

恒大方面也指出，FF广州南沙研发生产基地2019年底到2020年初会实现投产，首期计划年产能10万台。

有业内人士指出，恒大签下的对赌协议，基本上算是保障了公司的利益。“如果FF91按时量产，那么20亿美元的投资，肯定是稳赚不赔；如果对方违约，那么恒大就会拿过来自己做，造车的前期投入非常大，20亿美元买FF技术并不亏，加之恒大自身的资金，完全可以将FF救活”。

# 券商提醒小米认购风险 投资者以限价形式下单

6月25日至6月27日，小米集团赴港上市招股。

21世纪经济报道采访中，有港股新股基金经理透露“由于此前几只新经济股票在上市股价表现并不理想，客户认购热情不高，我们就限价在18港元下了些单。据了解，很多机构都是以限价的方式认购，小米最终定价可能不会在中上限。”

过往散户哄抢新经济股的盛况这次却并未发生，小米正式启动招股后连续两日市场反应冷淡。

据港媒报道，6月25日，11家香港本地券商共录得仅74.72亿港元的孖展认购额，以在香港公开发售集资额23.98亿港元计算，超额认购仅2.12倍。6月26日，10家本地券商则累计录得59.44亿港元的孖展认购，超额认购1.48倍，远远落后于市场预期。

# 快手：封禁12个涉庆阳女孩跳楼遭网络直播事件账号

近日，甘肃庆阳李某某跳楼一事备受关注，现场有群众在围观女生跳楼时拍摄短视频上传至快手平台，此举引发大量争议。

对此，26日晚上，快手方面回应记者称，根据他们的调查，在李某某坠楼事件中，有3个账号发布了3条违规视频，有9个账号发布了17条不当言论，目前这12个账号已经被永久封禁，视频和评论也做了处理；没有通过直播功能进行直播的情况。

快手表示，事件发生后，已经加大了对视频内容的审核，目前从技术手段上来说，已经可以对直播的声音和画面进行监控，如果出现不当内容，可以进行中断。

# 苹果三星7年世纪大战和解告终，三星曾赔付苹果3.99亿

外媒消息，美国加州北区地方法院最新文件显示，苹果和三星日前就持续了数年之久的专利纠纷达成和解，但文件中没有披露和解条款的具体内容。

苹果和三星对此事都没有进一步回应。

这份和解协议结束了苹果自2011年以来针对三星发起的一场专利战，苹果指控三星“盲目地”抄袭了iPhone的设计，侵犯了苹果专利。今年5月份，美国陪审团裁决三星向苹果赔偿苹果5.39亿美元。

三星此前曾向苹果赔付了3.99亿美元，以补偿其专利侵权行为。如果判决得到支持，三星还需要向苹果支付近1.4亿美元的额外费用。

# 二手车电商优信赴美IPO 上市首日股价逆市涨逾7% 去年亏损近17亿人民币

当大家都在关注小米、美团点评上市消息的时候，另一家中国互联网公司优信二手车悄悄的在美国上市了。

6月28日，中国二手车电商平台优信集团周三正式在纳斯达克IPO（首次公开招股）上市，当日美国股市全线下跌，但优信逆市涨逾7%。

然而，尽管股价抢眼，在经营成绩上，优信成立至今7年，仍然处于亏损中。

“还没有盈利，运营现金流仍然是负数，未来一段时间可能还会保持这样的状态。”优信在招股书中提示。

招股书披露的数据显示，优信2016年的净亏损为13.929亿元人民币，2017年净亏损达到27.478亿元人民币（约合4.205亿美元），亏损同比扩大近一倍。2018年第一季度，优信的净亏损为8.394亿元人民币（约合1.335亿美元），而其去年同期为5.108亿元人民币。即使不按照美国通用会计准则，2016年度、2017年度以及2018年第一季，优信调整后的净亏损仍旧为10.50亿元、16.96亿元、4.78亿元。

# 花椒直播与六间房宣布重组，新公司估值超85亿元，360仍是掌控位置

6月27日晚，宋城演艺发布公告，公司全资子公司六间房拟与密境和风（花椒直播运营主体）进行重组，原六间房创始人兼首席执行官刘岩将出任新集团CEO。

密境和风的全体股东拟以密境和风的100%股权，认购六间房新增注册资本，六间房整体估值34亿元，密境和风整体估值51亿元，间与密境和风重组后的六房将不再作为公司的并表子公司。

工商资料显示，奇虎360为密境和风控股股东，持有其45.17%股份。此次交易完成后，花椒全体股东占重组后主体60%股权，宋城演艺和战略股东合计占重组后主体40%股权。奇虎360仍将在新集团内处于掌控位置。

# 美图宣布将进军芯片领域 推自研MT-AI图像处理芯片

27日消息，美图公司正式宣布下一步将进军芯片领域，推出自研的MT-AI图像处理芯片。美图表示，公司当前在手机影像处理技术上的探索，遇到了硬件的性能掣肘。现有的手机硬件无法及时地支持某些需要庞大的计算量的尖端影像技术，比如夜景相机的降噪处理。为此，美图在云处理的软件解决方案之外，积极寻求硬件上的突破。
