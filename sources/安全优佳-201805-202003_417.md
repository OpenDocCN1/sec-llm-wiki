# 2025年这20种职业会被机器人替代，里面有你现在所从事的工作吗？

59年前，约翰·麦卡锡等几位科学家达特茅斯会议上，脑洞大开了一个对人类意识和思维过程模拟的领域，并赋予这个领域一个名字人工智能，简称AI。从此人类点亮了新时代 ，从手机系统到3D打印，从谷歌眼镜到全息投影都需要运用到人工智能。

![](../Images/5c6765456fcb9e7e58b0cd7806fdf585.png)

人工智能也在以远超我们想象的速度发展。穷苦大众还没享受到iphone的洋气，siri就已经从智能助手变成了 段子手。短短几年，人机交互，无人驾驶、虚拟现实、增强现实等等智能设备的扎堆出现，智能机器人频频亮相。

![](../Images/eb3461c6f86f163e8490962c7ec1e5c8.png)

2014年，全球首款表现人类情感的机器人，它可以通过摄像头捕捉人的面部表情来分析出人的喜好。首台云识别冰箱Chiq问世，不仅可以根据用户的喜好推荐食谱，并且可以自己上网购买，足不出户，就把菜买回来了。借助人工智能，给我们的生活带来了很多便利，但是我们也面对他带来的威胁。

![](../Images/86bb41cf96ab6aea473257b9599c3407.png)

埃隆·马斯克说：借助人工智能，我们将召唤出恶魔，而且圣水和魔法阵都搞不定它。霍金预言：技术的发展速度要远快于生物的进化速度，迟早技术将产生自我意识，并取代人类。霍金还预言：如果要在这个迟早上加一个期限，这个期限大概是100年以内。

![](../Images/c17e19b28a6001ac5b9ab3cabfc1588a.png)

但是，取代来的太快就像龙卷风，就在这一秒，人工智能也在以简单粗暴的方式取代人类，因为和你抢工作的已经不是人类而是机器人。2011年，应用于医疗领域的沃森，已经收录了肿瘤学研究领域的42种医学期刊，60多万条的医疗证据和150万分患者记录和200万页文本资料，只要几秒钟就能为医生提供相对应的治疗方案，2014年微软code大会上，skype translator通过识别不同用户的口音和说话方式即可实现两个母语不同点的两个人的无障碍交流。2015年，腾讯dreamwirter机器人发布的8月CPI资料新闻，从抓取资料到撰稿发布，仅耗时一分钟。

![](../Images/98f9e550be3f1a2f02e8819be78c17ae.png)

人工智能已经将触手伸向各个领域，代替人类完成各种工作。业内人士预测，如今50%的职业都在会2025年消失。牛津大学还分别列出了20种可能被替代的工作。例如：消防员、拆弹人员、出租车司机、快递员、酒店前台接待、销售人员、纹身师、客服、收银员、操作工、网络编辑、放射科大夫、银行大堂经理、笔译和口译人员、速记师、保安、讲解员、上菜服务员、采购员、财务等。

![](../Images/14b84002faa5c5effafb5c5258409d8f.png)

你永远也猜不到下一秒谁的工作在消失，孙正义预测，到了2040年，全世界机器人的数量将超越人类的数量，达到100亿个。人工智能呢个的迅速发展，对此你有什么看法？对于2025年被替代的职业中有你吗？
