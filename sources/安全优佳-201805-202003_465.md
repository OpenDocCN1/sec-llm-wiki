# 加拿大两大银行遭网络黑客袭击 数万信息或被盗

据美国“侨报网”5月29日报道，加拿大蒙特利尔银行(BMO)和帝国商业银行(CIBC)28日表示，网络黑客可能窃取了两家银行数万名客户的数据信息，这可能也是该国金融机构第一次遭受重大攻击。

据英国路透社报道，加拿大蒙特利尔银行(BMO)28日表示，网络犯罪分子已与他们联系，声称已窃取了该银行有限数量的客户个人和财务信息。该银行表示，它认为这起网络袭击来自国外，而导致客户数据被盗的网络风险已被清除，同时，正在与相关部门合作对事件局势进行评估。

同时，加拿大放贷商业银行加拿大帝国商业银行也表示，网络黑客也联系了他们，并声称已窃取了该银行4万名客户的个人电子账户信息。该银行指出，目前尚未确认任何网络信息泄露事件，并正在认真调查此次黑客敲诈，其主要银行部门的客户没有受到影响。

两家银行都表示，他们正在联系客户，并建议客户监控他们的账户并报告任何可疑活动。加拿大六大银行一直在与加拿大银行合作，以加强对网络攻击的防御。加拿大银行5月初也表示，一些网络袭击可能是无法避免的，但它有恢复机制来尽量减低损失。

据报道，网络攻击正在变得越来越普遍。2017年，信贷监控公司Erimax表示，在网络攻击中，美国大约有超过1.46亿的用户名字和出生日期失窃，失窃的美国社会保障号码超过1.45亿个，失窃地址9900万个，此外，还有20.9万支付卡号码和截止日期被盗。
