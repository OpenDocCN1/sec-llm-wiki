# 再见李华：

1.下载附件，解压发现是一张图片，

![](../Images/5b31d80a4dbc6dea138610d264343df6.png)

2.用winhex打开图片，发现key.txt文件，

![](../Images/8b25c7f456d24cc75d7f7109a26a9754.png)

3.将图片后缀改为zip，如图，

![](../Images/4c484122df11e2a7ba3561c69223016a.png)

4.题目描述中没有特殊字符，是说明密码没有特殊字符，而不少于1000个字，这个1000是8的二进制，所以密码是9位或9位以上，最后署名，意思是密码中后面5位数是Lihua，最后用Advanced ZIP Password Recovery\_4.0进行破解。最后密码为15CCLiHua，得到flag，

```
Stay hungry, Stay foolish.


```
