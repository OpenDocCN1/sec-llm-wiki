# 黑客再入侵美有线电视网络公司 要求支付数百万美元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247483995&idx=3&sn=994b575302802b6e8b7b35748ba3268a&chksm=ebf9457bdc8ecc6d48362f19078a2b5d0f51638a886c8f1556c214f5e29d8720fab915c3349c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247483995&idx=3&sn=994b575302802b6e8b7b35748ba3268a&chksm=ebf9457bdc8ecc6d48362f19078a2b5d0f51638a886c8f1556c214f5e29d8720fab915c3349c&scene=27#wechat_redirect)

据美媒报道，入侵美国著名有线电视网络媒体公司HBO频道电脑系统的黑客7日在网上公布了更多的被盗内容，并要求HBO公司支付数百万美元的赎金，以防止黑客发布更多的被盗信息。

  

![](../Images/bb5c0d263a20156891364d8b462ad9c7.png)

  

以“史密斯先生”为名的黑客们泄露了HBO频道的奇幻史诗电视剧《权力的游戏》的部分脚本，以及一名公司高层主管的电子邮件。  

  

黑客们还上传了一段视频，要求HBO首席执行官理查德 普列普勒(Richard Plepler)支付价值600万美元的在线货币比特币，否则就会泄露更多资料。

  

在最新的泄漏之后，HBO重申它不相信公司的整个邮件系统都被侵入，但表示将继续调查黑客入侵事件。该公司之前承认有些“专有信息”被盗。

  

据悉，许多被盗的HBO内部文件都有“机密”的标记，其中有法律和人事档案。 人事档案中有参加电视剧演出的影视明星的电话号码和电邮地址。

  

7月初，黑客声称从HBO电脑系统中窃取了1.5TB信息，并发布了电视剧《权力的游戏》中的一集剧本大纲，以及HBO电视剧《好球天团》(Ballers)、《巴里》(Barry)和《104室》(Room 104)的部分剧集。

  

到目前为止，与黑客声称拥有的信息量相比，黑客所泄露的信息是有限的，但他们要求HBO在3天内付款，否则就要面对可能是好莱坞历史上最严重的黑客入侵。
