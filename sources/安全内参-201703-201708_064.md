# 富国银行发错电子邮件 导致5万客户信息遭到泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247483886&idx=4&sn=ab624db230d04e4a0a3dde6305dc07e3&chksm=ebf946cedc8ecfd86331def734d60cb8970a1a5469b95c91d59c8e69aa49bd691498a5064f16&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247483886&idx=4&sn=ab624db230d04e4a0a3dde6305dc07e3&chksm=ebf946cedc8ecfd86331def734d60cb8970a1a5469b95c91d59c8e69aa49bd691498a5064f16&scene=27#wechat_redirect)

7月24日早间消息，由于信息安全措施不力和黑客攻击事件，过去几年许多大企业都丢失过敏感的数据。近期，富国银行意外地向一名前理财顾问发送了1.4GB包含5万名高净值客户信息的数据。

  

![](../Images/4c9c00e1b27c66002dd06d778a4fe9ea.png)

  

这名前理财顾问加里·辛德布兰德（Gary Sinderbrand）正在对富国银行一名员工提起诽谤诉讼。他原本会收到与本案相关的电子邮件和其他文件，然而富国银行却将数万客户的机密信息，包括姓名、财务信息，以及社会安全号码发给了他。报道称，受影响客户的投资资产达到数百亿美元。

  

更糟糕的是，辛德布兰德的律师收到的这些数据并没有附以保密协议，或是由法官签署的保护令。这意味着，没有任何法律约束，可以阻止辛德布兰德发布这些信息。而如果他这样做，那么富国银行将承担责任。

  

发送这些文件的律师表示，这个错误来自于外部供应商。供应商应当过滤所有文件，只将与本案相关的文件发送给辛德布兰德。富国银行要求辛德布兰德退回这些数据，不过他的律师表示，辛德布兰德将确保这些信息安全，同时“评估自己的法律权利和责任”。
