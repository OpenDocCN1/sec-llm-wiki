# NSA征集提案:拨款550万美元培养政府网络安全人才

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247483835&idx=2&sn=af07e01877230df690d6963b3f14187f&chksm=ebf9469bdc8ecf8dc0df9cfbabb8eaa87e06ad860cbb885ee49e8946c3a548ac59f39cd0a213&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247483835&idx=2&sn=af07e01877230df690d6963b3f14187f&chksm=ebf9469bdc8ecf8dc0df9cfbabb8eaa87e06ad860cbb885ee49e8946c3a548ac59f39cd0a213&scene=27#wechat_redirect)

7月17日讯 美国国家安全局（NSA）正在征集网络安全核心课程开发拨款提案，拨款550万美元投入新计划，培养联邦网络安全人才。

  

![](../Images/8d19a504aa0aab683366a9ca66b67aa7.png)

  

NSA在项目描述中提到，拨款将用于教学大纲、课程资料、动手实验室、实验室、以及其它专注计算机网络、网络威胁与漏洞、风险管理、以及相关国家与国际法律法规的网络培训资料。  

  

前总统奥巴马推出的《网络安全国家行动计划》要求的教育工具将提供给大学、学院或其它教育机构。

  

NSA表示，拨款提案审查人员正在审查深度与广度。

  

项目描述显示，将先前的提案促成完整课程或实验室的资金介于10万美元-60万美元之间（约为人民币68万到408万）。当前这一轮提案于去年12月23日到期。
