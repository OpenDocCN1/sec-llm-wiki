# 美国四大移动运营商联手开发下一代身份认证产品

在涉及到个人安全时，双因素身份验证目前被认为是保持帐户和设备安全的最佳方式之一。

但是，像大多数安全措施一样，它还可以改进得更好。这就是为什么在去年9月，互为竞争对手的AT＆T、Verizon、Sprint和T-Mobile联合起来，创建移动身份验证工作组的原因。

该工作组的目标是为用户设备开发下一代多因素身份验证解决方案，在2018年世界移动通信大会上，官方宣布新的解决方案将发生在未来几周内试验测试，并可能在今年年底推出。

这个解决方案如何工作？移动身份验证工作组表示，它将由运营商的网络提供支持，在用户同意后向经授权应用提供密码验证的电话号码和个人资料数据。验证环节中其它因素也会被考虑，包括IP地址、SIM卡属性、电话账户类型等。

当然，机器学习、高级分析等技术也会运用，机器学习将有助于评估风险并学习用户行为模式。 

工作组表示，它将在今年晚些时候为感兴趣的应用提供商推出一个网站。
