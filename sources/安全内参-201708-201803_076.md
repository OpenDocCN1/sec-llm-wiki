# 美国军方将虚拟现实技术用于网络战实战演练

美国军队正在其网络司令部进行各种类型的训练，包括为其“网络士兵”创设虚拟教室。

日前，美国军队举行的第二届“行业日”（Industry Day）活动，目的是听取私企的想法，公开寻找一起开发持续网络训练(PCTE)的合作商。  

在佛罗里达州奥兰多市举行的“行业日”告诉我们美国军队未来要怎样培训网络新兵。作为在军队网络攻防操作中越来越有影响力的军事部门，最近网络司令部被要求提升统一作战指挥。  

两年前，美国军队模拟、训练和仪器使用项目执行办公室（PEO STRI）首次批准PCTE的时候，它就被描述为“一个可以让网络任务部队（CMF）在模拟网络环境中训练的平台，该平台可重点关注应用整合，促成自动化，从而支持多个同时训练任务。”   

RFI认为，有DoD联合参与的PCTE将是一片光明。其互操作性通用训练满足了所有的培训类型，从个人，到团队，再到军队的培训，TTP开发，以及任务预演。  

周二，CyberScoop测试了Raytheon开发的一个PCTE样本，此样本利用虚拟现实软件和硬件提供了一个模糊定义的互联式“任务预演”平台，而这也是军队需要的平台。一位新闻发言人称，样本使用HTC Vive 耳机，且可以根据需要接入其他硬件，包括鼠标或键盘。  

该样本主要用于展示见习学员在模拟战场如何发现切断无人机和其他交通工具之间通讯的DDoS攻击，并进行修复。

Raytheon情报，信息和服务（IIS）投标经理Howard Miller透露，这种虚拟训练环境的定制程度极高，目的是训练学员应对不同的情况或是远程协作任务。  

除训练外，该PCTE样本似乎还为指挥者们提供了一个虚拟规划区，供他们起草和调整战略。在耳机里，用户可以查看数据以及主流网络安全软件加载的其他情报，包括类似Norse Attack Map（http://map.norsecorp.com/#/）的地图。  

政府网络解决方案主任Bill Leigher称，该计划的目的是让军队领导和士兵更容易认识到他们如何在部署网络的同时抵御攻击。这就是网络战模拟器，如果购买此产品，将是这类产品第一次用于军事用途。他说：“我们在自身经验的基础上对此进行了概念化，但还未让所有的需求都清晰明了。”  

Leigher和Miller解释称，未来美国网络司令部将会扩大培训规模，其培训地点不仅会在美国还会出现在附近的美军基地，而PCTE将成为其组成部分。  

与PCTE类似，培训地点在不断发展中。Raytheon还没有签订网络业务方面的有效合同，但有计划参加未来的“行业日”活动。  

首个PCTE行业日于2016年11月举行。自那时起，该计划就吸引了许多国防承包商的眼球，包括Mantech，Raytheon和Lockheed Martin。   

PCTE的发展可能成为军队给承包商确定培训任务的风向标；这些承包商将面对不断变化的任务，而不是效力NSA（美国国家安全局，负责收集通信情报）的黑客。  

Leigher认为，联合任务的指挥官们将面临挑战，他们需要思考如何让网络适应任务。而新变化将推动战术，技术和过程的改进。这将有助于开发出应对不同情况的标准。
