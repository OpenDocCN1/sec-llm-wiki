# 美国民主党首次雇请CSO，为2018年中选举护航

美国民主党全国委员会（DNC）已经任命Bob Lord为其新任CSO，这位Yahoo前CISO将负责DNC的网络安全事务直至2018年中期选举。

  

DNC表示，Lord将与该组织的内部安全团队合作，还会支持民主党在各地的组织，包括更新其信息安全战略等。DNC于上周四发布此人事任命声明。

  

DNC主席Tom Perez称：“我有信心，Bob的技术和勤奋将有助于我们对抗目前普遍存在的网络攻击以及入侵。”“防御是任何对垒形式中不可缺少的部分，Bob加入DNC，我感到很开心。” 

  

DNC此前从未聘请过CSO。但由于在2016年美国大选期间，民主党的多项政治活动都遭到俄罗斯黑客的渗透，使选民认为该党派与俄政府为伍，所以此次人事任命是符合实际需要的。

  

Lord受雇DNC之前都是就职于大型科技公司，包括Twitter、Rapid7、Red Hat和America Online。

  

DNC的CTO Raffi Krikorian曾与Lord共事于Twitter，他很看重这位Yahoo前CISO应对国家级黑客攻击的经验。 

  

Lord去Yahoo之前，Yahoo刚遭受两次数据泄露，数以百万计的用户账户被入侵。这两次安全事故的余波未平，Lord便开始负责Yahoo的安全事务。虽未经历两次事故，但他自委任之时就被要求修复这两次安全事故带来的损害，并重建Yahoo的核心安全架构。

  

去年有调查者称，Yahoo在2014年的一次数据泄露是由俄罗斯的情报人员与雇佣的黑客合作完成。
