# 深度：俄罗斯为什么要建自己的互联网？它能成功吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247485000&idx=1&sn=31f4a3a322fce1b6ce2539a327f2eb92&chksm=ebf94168dc8ec87e486d0bc8533ee1477da136f8fbf3a9c101af1e59388cf9a05a348265b4da&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247485000&idx=1&sn=31f4a3a322fce1b6ce2539a327f2eb92&chksm=ebf94168dc8ec87e486d0bc8533ee1477da136f8fbf3a9c101af1e59388cf9a05a348265b4da&scene=27#wechat_redirect)

去年11月，有消息称俄罗斯总统普京批准了一项计划，即2018年8月1日前要打造俄罗斯独立的互联网，该新闻由俄罗斯媒体“今日俄罗斯”（RT）率先报道。而金砖五国将使用这个独立的互联网，并用它抵御“潜在的外部影响”，克里姆林宫新闻发言人Dmitry Peskov告诉RT。   

![](../Images/17bf348a606b8042de59e39b54165b1e.png)

“我们都知道全球网络的主要管理者是谁，”Peskov说。“而由于这样的网络具有不确定性，所以我们不得不思考如何才能确保国家安全。”

国际互联网的主要管理者ICANN遵循加州法律，而这一点或许会干扰俄罗斯对网络的使用，那么问题来了：俄罗斯能不能打造专属于自己的互联网呢？

“答案是肯定的，”ICANN CTO David Conrad说。互联网协议是公开的，互联网由多个内网连接而成，所以重新建一个多个内网连接而成的互联网是完全可能的。 

假设俄罗斯想这么做，就需要复制目前管理互联网数据传输的硬件和软件。这就涉及安装计算机服务器，复制已有数据库，更新安全性能以及对现有技术进行重新配置——其实，就是需要自己的DNS，这是现有互联网不可或缺的技术，因为需要借它把域名翻译成计算机能读懂的数字，且这些数字组成了域的IP地址。

要建造一个独立的互联网，俄罗斯需要三个主要组件。第一个是命名空间，这是一个根据树形等级机制，组织网络传输的结构，此处的数据传输即指对IP地址的询问和响应。第二个是根服务器（以及一个根域数据库），该服务器是由多个电脑组成的网络，它最先对互联网查询做出响应，并将这些查询导向下级域名服务器。第三，他们还需要重新配置原有域名解析器，即由ISP网络运营商管理的电脑，它们主要用于获得最终结果的查询，解析器还会把响应结果保存在内存中以便下次能快速访问。

“互联网名人堂”入选者Farsight Security CEO Paul Vixie认为，管理一个DNS所需的技术投入不是什么难题，因为通用的单板计算机价格并不昂贵。

难就难在如何让用户买账。即便俄罗斯可以说服自己国家的民众使用独立的互联网，也不一定能说服其他国家的人。Conrad表示，任何在俄罗斯之外，想要使用俄罗斯独立互联网的人，公司或政府都需要重新配置自己的电话，电脑或其他设备才能实现网络适配，更不用说它们的路由和DNS解析器。

Vixie表示，联网设备不能在使用俄罗斯独立互联网的同时，还使用ICANN管理的互联网，也不能随意在二者之间进行切换。没有什么软件既能识别普通互联网的网址，又能识别俄罗斯独立互联网上的网址。

Vixie称，一旦使用俄罗斯独立互联网，用户将只能访问该适配该互联网的网站。而普通互联网则可以让用户看到所有在ICANN注册的网站。但是，俄罗斯总不会希望用户看乌克兰的网站。在俄罗斯独立互联网中极有可能直接在根服务器中取消乌克兰的国家代码顶级域名.ua，这样就彻底找不到乌克兰的信息了。

但相同境况会发生在俄罗斯的顶级域名.ru上吗？据RT透露，2014年，俄罗斯通讯部就做过一次模拟测试，想看看自己备用的互联网是否支持网页操作，俄罗斯对普通互联网的访问是否被掐断。他们也担心ICANN会把.ru的域名从普通互联网上清除。

Vixie认为，这种情况发生的代价太大。“这恐将会是互联网历史上的大事件，”“它不仅会影响俄罗斯，还会让很多国家不信任ICANN。”

至于我们通用的互联网，信任是非常重要的。每个网络运营商以及每个互联网设备程序员都相信，当手机或电脑向DNS服务器发出询问时，会得到可靠且准确的响应。否则，就是互联网出了故障。

为了加强国家之间的信任和合作，ICANN在2016年10月进行了重组，致力做一个独立的非政府组织。其管理架构脱离美国，转变成了基于志愿者的，多股东管理组织，力求让执行董事会所遵循的规章制度在最大程度上对所有互联网社区负责。

各国派了代表在ICANN政府顾问委员会（GAC），他们会向ICANN的执行董事会提出建议，并由董事会决定是否采纳这些建议。更重要的是，没有哪个国家可以对ICANN施加压力，迫使其实施不好的举措。

Conrad认为，ICANN会不通过顶级域名管理者就移除顶级域名的可能性不大。因为这样做的后果会损坏其信誉，也可能导致管理架构出现排他性重组。所以俄罗斯不用担心这个问题。

美国对外关系委员会数字与网络空间政策项目总监，《The Hacked World Order》一书的作者Adam Segal认为，俄罗斯的声明似乎是一种政治声明。

俄罗斯，中国和其他国家在过去的几年总是抱怨互联网的管控问题。作为GAC的成员，他们有建议权。但是他们不能对IETF的决议行使否决权。IETF是网络设计者，运营商和研究人员组成的一个独立性国际组织，负责监督互联网架构及其运行。

Segal还表示，俄罗斯和中国对发展中国家的影响力也是需要考虑的因素。这些发展中国家也要考虑到底是效仿美国和欧洲互联网自下而上的自由信息模式，还是要效仿中国和俄罗斯的自上而下的严格系统呢？全球对于自由信息流的判定是有争议的。

与此同时，俄罗斯正通过其他方式加强对互联网的控制。俄正推行一项计划，迫使外国公司如LinkedIn把俄罗斯本国公民的信息保存在俄罗斯的服务器上。这一计划对美国公司的影响还有待观察。
