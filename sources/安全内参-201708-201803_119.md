# 用户被改号软件骗钱后起诉运营商，法院：运营商需担责

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247484923&idx=4&sn=aee533de136a76bbc089a063fd706dea&chksm=ebf942dbdc8ecbcd2fdec70cf0cfcea0d29923d025030a1a8b11c098ca83be2ac1b16bdfc7d7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247484923&idx=4&sn=aee533de136a76bbc089a063fd706dea&chksm=ebf942dbdc8ecbcd2fdec70cf0cfcea0d29923d025030a1a8b11c098ca83be2ac1b16bdfc7d7&scene=27#wechat_redirect)

11月19日，深圳市福田区法院就杨某诉中国移X公司深圳分公司财产损害赔偿纠纷一案作出一审判决，判决被告赔偿原告杨某损失88578.4元，驳回原告杨某的其他诉讼请求。

**原被告双方均存过错 法院判决各自承担相应责任**

法院经审理认为，被告（即中国移X公司深圳分公司）存在过错行为，与原告杨某的财产损失之间存在一定的因果关系。

首先，经过调查，证实中国移X公司深圳分公司提供给杨某的来电显示075595555、02162588800等电话号码并不准确、真实，根据《中华人民共和国电信条例》第五条规定，电信业务经营者应当为电信用户提供迅速、准确、安全、方便和价格合理的电信服务。

准确、真实地显示来电号码，是双方订立合同时对来电显示服务质量标准要求的应有之义，也是杨某作为普通消费者对该项服务的合理期待。

被告中国移X公司深圳分公司主张作为被叫端电信运营商在现有技术和规范下无法识别主叫号码的真伪，仅是将主叫端运营商传送的主叫号码向用户传送，不能保证来电显示的电话号码的真实性。

那么根据《消费者权益保护法》第八条，中国移X公司深圳分公司应在杨某开通来电显示服务业务时以明确的方式告知原告这一事实，并以合理方式提示用户可能存在的风险，提示原告对来电显示内容进行辨别，避免危及人身、财产安全，原告杨某基于对来电显示电话号码的准确、真实性的合理期待，形成对中国移X公司深圳分公司提供来电显示服务内容的信赖，进而被他人诈骗导致财产受到财产损害，对此，被告中国移X公司深圳分公司具有一定过错。 

其次，从中国移X公司深圳分公司提供的手机号码138\*\*\*\*\*自身安全性能来讲，提供给原告杨某使用的涉案手机号码多次被其他号码055163800696、055182339813设置为呼叫转移的接收号码。

被告（中国移X公司深圳分公司）作为该号码提供者，在未取得原告杨某同意的情况下，允许他人将原告使用的手机号码设置为呼叫转移的接收号码；中国移X公司深圳分公司主张其当时并不能识别涉案手机号码被设置了呼叫转移，但中国移X公司深圳分公司作为手机号码提供者，却对自己提供的手机号码被设置了呼叫转移不知情，导致用户所使用的手机号码可能随时被他人设置呼叫转移，存在重大的安全隐患，中国移X公司深圳分公司对此也未向作为用户的原告进行告知和提示。杨某在不知情的情况下，依据被告中国移X公司深圳分公司提供并不客观、全面、真实的来电显示信息做出了错误的判断，导致其被诈骗造成巨大的经济损失，被告中国移X公司深圳分公司对此亦存在一定过错。

最后，从目前日益猖獗的电信诈骗现状来看，要求电信运营商需要承担更高的社会责任和义务，中国移X公司深圳分公司应与其他电信营运商协商合理安排互联互通业务，积极协调、沟通、及时弥补信息传输过程中存在漏洞，提高服务技术，改善服务态度，提高服务质量，来保证用户的人身、财产的安全。被告中国移X公司深圳分公司未有证据证明其履行了上述社会责任和义务。

原告杨某作为接受过高等教育且具有完全民事行为能力人，应对自己的人身、财产安全尽到足够审慎注意的义务，然而在本案中，杨某仅仅是通过电话交流就轻信他人，向他人透漏银行账号、密码等重要的财产信息；对一般的骗术伎俩缺乏辨别、识别能力，对自己的财产安全未尽到足够、合理的注意义务。

综上，法院结合本案的实际情况、双方当事人的过错程度以及造成损失的原因力大小等各方面的因素，酌定被告中国移X公司深圳分公司对原告杨某的损失承担20％赔偿责任，故被告中国移X公司深圳分公司应赔偿杨某财产损失88578.4元（442892×20%），杨某的利息请求没有事实和法律依据，对杨某过高部分的诉讼请求法院不予支持。

目前案件尚在上诉期，判决仍未生效。
