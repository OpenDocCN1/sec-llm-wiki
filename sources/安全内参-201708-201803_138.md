# 以安全之名，美国18位议员联名告状叫停华为与AT&T合作

腾讯《一线》 郭晓峰 1月9日报道

美国时间1月8日下午，美国权威媒体《华尔街日报》援引知情人士消息称，美国运营商AT＆T已经撤销了销售华为手机的计划，具体原因尚不详。对此消息，AT＆T和华为官方并未发表评论。

据了解，华为原本将在明天开幕的拉斯维加斯CES展上宣布与AT&T达成协议，正式在美国运营商渠道销售智能手机。在临近宣布的时刻发生这一幕，很多人始料未及。

随后，腾讯《一线》第一时间从接近此次合作的知情人士获悉，合作是被临时取消的，原因很可能是AT＆T迫于美国政府的“压力”。

《华尔街日报》在文中称，华为是全球最大的电信设备商，而2012年的一份美国国会报告对华为设备的安全性表示担忧。华为当时否认相关指控，并表示该报告存在政治动机。

事实上，以安全担忧为借口，美国政府过去几年对华为等中国企业一直大门紧闭，这也一定程度上影响了华为其他产品的布局，业界深知这背后复杂的政治博弈。

在此次华为与AT&T洽谈合作期间，这样的“阻力”一直存在。

早在去年12月，腾讯《一线》独家曝光了此事，进一步确认了双方合作细节。在当时，引起美国媒体及一些政客的广泛关注。甚至有外界称，美国政府正在给AT&T施加“压力”。

今日，腾讯《一线》又独家获得一份“美国18名国会议员联名致信联邦通信委员会（FCC）主席艾吉特·帕伊（Ajit Pai）”的邮件，其中主要内容是，要求FCC对华为与美国运营商的合作展开调查。

![](../Images/9132c32d02ac970ec384ac439f15ec4b.png)

在这封邮件中，再次提到2012年时美国国会发出的、在美国市场对华为设备的禁令。

“我们需要记住2012年HPSCI报告中的建议，即“美国应当以怀疑的态度去评估中国电信业公司在美国电信市场的持续渗透”，“美国政府系统不应当加入华为或中兴的设备，包括设备元件”，“政府承包商应当在各自系统中排除中兴或华为的设备”。因此我们要求知道，FCC雇员目前是否被允许在政府事务中使用华为的产品，以及如果美国电信运营商与华为合作，这样的规定是否会调整。”

![](../Images/c285b210ce77e181954cbeaaf320981d.png)

这封邮件同时也被抄送给美国司法部长杰夫·赛森斯（Jeff Sessions）等人。由于美国的“政治滤镜”很强大，所以，这非常有可能是导致AT&T与华为合作被“临时取消”的根本原因。

根据IDC的数据显示，去年华为约占10%的全球智能手机市场，仅次于三星和苹果。华为消费者业务CEO余承东曾向外界透露，华为计划在一到两年超越苹果。显然，要实现这一赶超，华为必须返回美国智能手机市场。

华为去年曾在亚马逊、百思买等渠道销售过手机产品，但比起掌控美国市场80%以上手机销售的运营商渠道相比微乎其微。

在美国高端机型方面，三星、苹果iPhone始终保持着70%以上的市场份额，这也造成两个品牌在面对运营商的时候总是高高在上。相反，美国运营商的地位江河日下，而种种迹象也表明，三星、苹果往后可能会更加不可一世。

从全球智能手机行业发展来看，现在的美国市场需要一个有能力抗衡苹果、三星的搅局者。而华为目前是最佳的选择。

与此同时，一旦华为进入美国智能市场，对另一家美国巨头企业也产生了一定“威胁”。据了解，此次与AT&T合作的华为手机并没有采取高通的芯片，而是自家的麒麟芯片。

美国高通公司是目前手机芯片市场的霸主，来自中国市场的收入占其整体收入近一半。华为近几年的高端智能手机产品并没有采取高通的芯片。

坊间有传闻称，由于没有采用高通的芯片，这家美国公司向政府提出了“保护措施”。而之所以在美国销售的华为手机必须使用高通公司的芯片，除了专利保护之外，同样是美国出于对安全的考量。

目前，还不清楚华为与AT&T的合作何时恢复。但任何一家中国高科技企业进入美国市场已不仅仅是一场行业竞争行为，开放、平等的态度将决定一切命运。
