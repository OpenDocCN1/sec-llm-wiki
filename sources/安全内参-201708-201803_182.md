# 由科技巨头和投资大佬主导的5个智慧城市项目

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247484736&idx=3&sn=5ba550671638a45cb04554586ebee01d&chksm=ebf94260dc8ecb767f543528eae32241ab0b2d96a23654f4e9e05c4f23bc556539d58ad8cb96&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247484736&idx=3&sn=5ba550671638a45cb04554586ebee01d&chksm=ebf94260dc8ecb767f543528eae32241ab0b2d96a23654f4e9e05c4f23bc556539d58ad8cb96&scene=27#wechat_redirect)

目前，在全球，智慧城市建设处于一个概念到逐步落地的过程，而科技巨头与投资大佬是这一新浪潮重要的参与者。  

从谷歌、比尔·盖茨、特斯拉，到Y Combinator、彼得·蒂尔，以及国内的百度、阿里巴巴、腾讯，也都不会在这一浪潮中缺席。

![](../Images/0e3e2bf920d30fec8824f220caaaf67f.png)

Edouard Leon Cortes油画作品

那么，为何科技巨头和投资大佬都如此热衷于智慧城市建设？原因主要在于：智慧城市为科技巨头的前沿技术提供了庞大的练兵场与商业机会，也为投资机构及其创业公司提供了更大的回报渠道。

当然，他们自身积累的对于技术应用的敏感性，以及对于未来城市的前瞻性思考，也是不可多得的，而且应该在城市发展中得到应用和验证的。

以下是几个典型的由科技巨头、投资大佬主导的智慧城市项目。从操作模式来看，这些项目几乎都采用了一种要么“大规模新建”、要么“小范围测试”的模式。

另外一个值得关注的特征是：不管是谷歌在加拿大、彼得·蒂尔在大溪地，还是特斯拉在澳大利亚的项目，都表明这些机构在海外有力的业务拓展，以及当地对智慧城市项目的欢迎。这对国内的相关厂商也是值得借鉴的经验。

  

**1.谷歌与多伦多高科技社区**

  

人行道实验室（Sidewalk Labs）是谷歌母公司Alphabet旗下的城市发展组织。

2012年，人行道实验室开始在纽约推出无线网络中心，将旧式的城市付费电话转变为免费的、技术先进的接入点，接入点包含了视频通话和快速无线上网功能。在接下来的几年中，7500个这样的接入点将安装到整个纽约城。此外，实验室还为纽约开发了新的交通规划工具。

2017年10月，人行道实验室宣布，计划与开发商Waterfront Toronto就一处位于多伦多湖畔的800英亩的黄金地段进行合作，建设一个名为Quayside的高科技社区。

![](../Images/2338bf242bb77b06ee816dea030123f7.png)

Waterfront Toronto将Quayside描述为“既是一个新兴技术、材料，以及应对新挑战的试验台，也是能复制应用于世界各地城市的先进解决方案”。

而其中最令人兴奋的描述是：“我们有机会从根本上重新定义城市生活。”

该项目将以一笔5000万美元的投资为开端，测试智慧城市技术，并暗示未来社区将会实现零排放，而且1/5的住宅单元都会设计为可负担住宅。

可以想象，谷歌和谷歌地图的大量数据、以及无人驾驶等最新技术，将在该项目中派上用场，并发挥协同效应。

  

**2.比尔·盖茨与沙漠都市**

  

比尔·盖茨近期宣布，他承诺为亚利桑那州凤凰城的智慧城市项目投资8000万美元，该项目将与房地产投资集团Belmont Partners合作进行（注：比尔·盖茨的Cascade投资公司是Belmont Partners的实际控制方）。  

该公司将项目描述为一个“前瞻性社区，通讯和基础设施扎实，有能力支撑起尖端科技。与此同时，项目将围绕高速数字网络、数据中心、新型制造技术与分销模式、无人驾驶车辆与自动化物流中心进行设计。”

![](../Images/a8f0c02ed3ab871f32361563d0d48f9e.png)

不同于人行道实验室在多伦多的项目，这座城市可以说是“平地起高楼”，将在沙漠中现有的24,800英亩的空旷土地上建造起来。

Belmont Partners的发言人Grady Gammage认为，这给了该公司一个独特的优势：“从零开始构想未来的基础设施，比改造一个已存在的城市架构要容易得多，高效得多。”

最终，这个目前称为Belmont的城市将包含8万个家庭，3800英亩的工业、办公与零售空间，另外留出470英亩土地，为公共学校的建设做准备。

  

**3.特斯拉与“特斯拉城”**

  

近日，南澳大利亚燃煤电厂跳闸，而特斯拉在南澳新建的世界最大锂离子电池几乎在瞬间向国家电网输送了100兆瓦电力，解决了当地用电高峰期的“燃眉之急”。这一新闻迅速引发了人们对特斯拉储能系统的关注。

其实，就在澳大利亚墨尔本的城郊，特斯拉正在打造的YarraBend社区项目也在如火如荼的进行。

![](../Images/ba108f9a4d1f9d5491b6051ca90378f3.png)

在一定程度上，这里更像是特斯拉产品的样板间，因为这里的2500套住宅都将安装该公司的屋顶太阳能和Powerwall电池储能系统，而社区也配备了电动汽车充电站和节能照明设施。

该项目的目标是成为澳洲最永续发展的社区，绿色、环保是该社区的发展主题，而Tesla的可持续技术能使建筑物以更加智能和绿色的能源系统来运行。

据开发商Glenvill介绍，该社区的居民将减少80%的废物排放和43%的水资源消耗。

可以说，这个社区就是一座“特斯拉城”，也是一个小规模的未来城市化的样本。

  

**4.Y Combinator与“新城市”计划**

  

作为全球最成功的创业加速器之一，Y Combinator有着将技术理念转化为诸如Dropbox这样的知名公司的经验，而如果说Y Combinator可以成为城市创新的孵化器，也不足为奇。

2016年7月，Y Combinator提出了一项名为新城市（New Cities）计划的研究项目。

![](../Images/c5a82455ff4d67fd8f556f8c901c8afe.png)

公司合伙人Adora Cheung在其博客中指出，目前全世界有很多人都未发挥其自身潜力，其中很大的原因，在于许多城市并无法为居民提供足够的机会与生活条件。

为此，Adora Cheung希望未来的新型城市应该首先解决住房价格问题，同时充分发挥科技在城市中的作用，包括自动驾驶、高速交通、多元化设计、公共空间利用、城市绩效评估、居民互动，以及解决法规的复杂性等问题。

Adora Cheung还表示：“我们的目标是在现存的法律约束下，设计出最好的城市。”，并特别强调，Y Combinator对“高科技迷的疯狂自由主义乌托邦”的想法并无兴趣，表现出其对该项目的务实态度。

从Y Combinator孵化和投资的大量高科技公司来看，相信这种生态系统能够为该计划的研究与实施提供助力，而如果项目能得到实际落地，也为这些公司提供了非常好的用武之地。

  

**5.彼得·蒂尔与漂浮城市**

  

目前，非盈利机构海洋家园研究所（Seasteading Institute）正启动在法属波里尼西亚的漂浮城市项目。该项目由硅谷著名投资人彼得·蒂尔提供支持。  

该项目提出了非常具有感染力的目标：“海上家园：漂浮国度将如何恢复环境、改善穷人境况、治愈疾病并从政治家那里解放人性。”

![](../Images/afea6b7f6af598086231614d048bb6e8.png)

据报道，该组织计划到2020年，将12个漂浮岛结构投入运行。虽然到目前为止，这些计划还并不一定包括其它高科技装备，然而这一概念确实在很大程度上推动了一些先进理念，包括生态屋顶、椰子纤维建筑和可循环使用的材料。  

为推动项目进行，项目方组建了一家创业公司Blue Frontiers，来负责浮动岛屿的设计与建设。该项目还创建了开放式平台，以吸引全球法律、商业、工程、建筑、科学和艺术各领域人士的参与。

2017年，项目已经与当地政府签署关于大溪地相关保护水域“浮动岛屿”的“特殊政府框架”。
