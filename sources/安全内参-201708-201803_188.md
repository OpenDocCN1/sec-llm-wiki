# Opera 加入了屏蔽挖矿脚本的功能

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247484724&idx=5&sn=c25dd2742a4c3446e9a9cbd7f01080bb&chksm=ebf94214dc8ecb0265f9b1c14bd8be3e3ab3d0929899940d2895436658450b119f3493eab03d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247484724&idx=5&sn=c25dd2742a4c3446e9a9cbd7f01080bb&chksm=ebf94214dc8ecb0265f9b1c14bd8be3e3ab3d0929899940d2895436658450b119f3493eab03d&scene=27#wechat_redirect)

Opera 成为第一个内置挖矿脚本屏蔽功能的浏览器。数字加密货币的火热推动了挖矿的流行，越来越多的网站尝试悄悄利用访问者的 CPU 去挖掘数字货币，导致用户的 CPU 满负荷运行，风扇狂转。 Opera 刚刚发布了 Opera 50 beta RC，加入了叫 NoCoin 的功能，在启用了 NoCoin（默认已经勾选，该功能位于设置-基本-拦截广告-推荐列表） 后，浏览器访问嵌入了挖矿脚本的网站时会像屏蔽广告那样屏蔽挖矿脚本。
