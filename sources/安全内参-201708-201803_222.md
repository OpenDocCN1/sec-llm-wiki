# 信通院总工程师余晓晖：未来3年ICT十大趋势（附PPT全文）

2017年12月14日，由中国信息通信研究院举办的2018年ICT深度观察大型报告会暨白皮书发布会在北京万寿宾馆隆重召开，与业界分享我院在ICT产业、5G、工业互联网、区块链等热点领域的研究成果，发布2018-2020信息通信业十大趋势，以及一系列白皮书。

  

会上，中国信息通信研究院总工程师余晓晖发表了题为《迈向2020，驱动变革的技术》的主题演讲，发布了信息通信业（ICT）十大趋势（2018-2020）。

![](../Images/0ae545a2d3d92c65f60432f359242e60.png)

“2018-2020信息通信业十大趋势”分别是：

1.中国引领，驱动5G加快迈入快车道；

2.跨越拐点，开启万物互联新世界；

3.边缘到云，重构网络计算新体系；

4.算法为王，激发人工智能新变革；

5.创新前行，拓展工业互联网发展新格局；

6.AI为先，重塑智能终端发展新范式；

7.突破瓶颈，筑成虚拟现实产业全生态；

8.两极分化，探索区块链发展多路径；

9.数字转型，激发数字经济新动能；

10.以人为本，塑造智慧社会新形态。
