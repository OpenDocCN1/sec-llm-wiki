# 查获3亿多条公民信息、光取证耗用了18个T的硬盘，这批“黑客”被嘉善警方抓了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247484580&idx=5&sn=0c393ca5e9fc5ded9a953fb606fc1d7e&chksm=ebf94384dc8eca928fc15e079d4286a4f5ce584ccd5fa0ed52905b269512fb0c30757e921ae2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247484580&idx=5&sn=0c393ca5e9fc5ded9a953fb606fc1d7e&chksm=ebf94384dc8eca928fc15e079d4286a4f5ce584ccd5fa0ed52905b269512fb0c30757e921ae2&scene=27#wechat_redirect)

当你被推销电话、垃圾短信精准锁定时，是不是会感到很奇怪，甚至有一丝不安，为什么他们对你的情况了如指掌？近年来，违法犯罪分子利用网络非法获取并买卖公民个人信息，既严重侵害人民群众切身利益，又催生出其他类型的犯罪。

  

今年5月底，嘉善县公安局在工作中发现，有大量第三方支付平台账号在浙江嘉善某IP段出现异常登录情况。该案迅速引起了省市县三级公安机关领导的高度重视，在浙江网警总队和嘉兴网警支队的指导下，嘉善县公安局网警大队立即抽调精干警力组成“6·06”专案组，对该案立案侦查。

  

![](../Images/b8b3d62a7819138bca72cd43e7f930e1.png)

网络配图

  

经过两个多月的侦查取证工作，嘉善警方发现暂住在姚庄镇的卢某与其妻子黎某长期在互联网上伙同他人，利用黑客手段大量盗取他人第三方支付平台账号，后通过QQ进行销售谋取非法利益。7月份，嘉善网警对卢某和黎某开展抓捕，并掌握到以卢某为核心的12人犯罪团伙，涉及下游侵犯公民信息犯罪成员170多名后，专案组成员先后赶赴辽宁、四川、福建、湖南、湖北等地对整个犯罪团体的重点成员实施抓捕。截至目前，嘉善警方已对卢某、黎某、郑某、任某等26名主要犯罪嫌疑人采取了强制措施，其中12名团伙核心成员已被依法执行逮捕，扣押电脑50余部、手机50余部及移动硬盘、U盘30多个，查获了3亿多条公民个人信息。

  

![](../Images/3ac7229f5aa0c351b0cd638a39b90a4c.png)

网络配图

  

“卢某等人的作案手法相当娴熟，通常先通过社工库网站及盗号团伙购买邮箱账号、公民信息等数据，然后利用平台接口的漏洞和非常规通道获取第三方支付平台用户信息，最后通过申诉、找回密码等方式盗取他人第三方支付平台账号，继而进行销售谋取非法利益。”嘉善县公安局网警大队副大队长朱刚介绍。

  

具体来说，该犯罪团伙分为三个层级，第一层为公民个人信息提供者，提供海量的特定条件的公民个人信息，比如包含了至少姓名、身份证号码、手机号码的公民个人信息条目，靠出售这些数据牟利。第二层为黑客群体，先向第一层级购买数据，接着通过人工申诉等方法进一步加强对撞库成功的第三方支付平台账号的掌控能力，比如重置账号的支付密码、更换绑定账号的手机号码等，最后将上述账号销售牟利。第三层则是以诈骗为主的犯罪团伙，主要购买黑客团伙“加工”好的第三方支付平台账号实施进一步的违法犯罪活动，比如将第三方支付平台账号主要作为诈骗后的洗钱工具，或者利用账号发送大量诈骗信息。

  

数以亿计的数据分析、10多本厚厚的案卷、遍布全国10余个省市的二十余名主要的团伙成员……半年多来，专案组成员终于把这根硬骨头啃了下来。“在整个案件的侦破过程中，除了各地公安的大力协助外，百度内容安全中心也给予了我们全程的技术支持，单单取证，就帮我们完成了近18个T容量的信息数据固定。”朱刚说。

  

![](../Images/59255f90e791fe0b9a424c22dfea618e.png)

  

1986年出生的“黑客”郑某是辽宁葫芦岛人，他还是一个瘾君子，自称吸毒是为了攻克黑客技术上的难题；1995年出生的任某家住四川达州山区，家里连宽带都没有，他却自学成才，借助一部手机上网，编写了很多黑客小工具；卢某和黎某一开始仅仅是帮助别人刷单赚点外快，慢慢接触到转卖账号可以获取较大利润，就拜郑某为师，潜心钻研技术……

  

“公民个人信息被不法分子窃取后，严重损害了人民群众的合法权益，滋生了电信网络诈骗、敲诈勒索等下游犯罪，社会危害严重，群众反映强烈。”朱刚说，公安机关将与相关部门密切配合协作，对涉嫌销售、传播公民个人信息的网店、网络账号、通讯联络号码等开展清理整治工作，净化网络环境，不给违法犯罪留下可乘之机。

  

同时，提醒广大群众要提高个人信息保护意识和能力，可通过设置密码、多重密码、动态密码等增加信息窃取难度，保护个人重要关键信息。此外，大家要谨慎使用个人信息，不随便扔弃个人信息资料，避免个人信息被意外泄露。如发现侵犯公民个人信息案件线索可向公安机关举报。
