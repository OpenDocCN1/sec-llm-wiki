# 《数字政府白皮书——AI时代的数字政府发展指引》详解

近日，在“2017互联网+智慧中国年会”——数字政府与互联网+政务服务论坛上，国脉研究院副院长金婧发表了在数字政府领域的研究成果《数字政府白皮书——AI时代的数字政府发展指引》报告，以下为详情（实录系根据现场速记和录音整理，未经本人审核）。

  

**↓以下为实录及PPT全文↓**

  

  

  

![](../Images/40a7d89bd185fe776c7278c76e782082.png)

  

金婧：今天我的主题是《AI时代的数字政府发展指引》。最近大家一直在谈论数字政府，那么数字化概念对大家来说已经不陌生了。从1998年美国前副总统艾伯特·戈尔提出“数字地球”的概念之后，数字国家、数字城市、数字社区等概念都出来了，世界各国将数字治理提升为国家治理，乃至全球治理的战略层面。

  

![](../Images/d211f18fc669a66009bf91fa8284057f.png)

  

通过这样一组数据，我们也可以看到近几年在人工智能、共享经济、公益方面出现了很多值得关注的变化。生产关系和社会关系实际上也在经历着数字化洗礼、网络化重塑和分权化再造，这种情况下我们政府治理模式也进入了新的历史阶段。

  

![](../Images/5d3d09383c9681f2f0cbea20b586646e.png)

  

  

国脉对于数字政府相关研究主要是从基本内涵与表现特征、发展模式与实践案例、评价体系和未来展望这三方面展开的。今天时间有限我就其中观点和要点与大家分享。

  

**一、基本内涵与表现特征**

  

**▊信息社会具有一体化、社会联动性高、复杂不确定性的特征，这种背景下需要从三个维度来理解数字政府：**

  

![](../Images/b3fd0ecca5231b21d7d36900133f81fe.png)

  

**○数字政府是一种不断演进的政府形态**

  

在不同的技术条件、需求阶段、社会响应趋势下，其所表现出来的特色、价值和影响等均不一样，本质上，数字政府是在web2.0技术、移动互联网和人工智能不同技术的作用下，不同服务模式的驱动与用户需求的倒逼下，逐渐生成的政府新形态。

  

**○数字政府是一种数据驱动的组织范式**

  

本质是数据驱动，无论是治理精细化、服务个性化，其背后是对数据价值的挖掘与运营，作为数据驱动的组织，数据作为一种资产、能源和组织灵魂与依归，电子政府、网络政府、智能政府等都是不同的数据价值爆发阶段对数字政府的再定义。

  

**○数字政府是一种社会创新的开源平台**

  

数字政府的终极模式是公民社会的成熟与自组织，主动参与政府事务并分担责任贡献力量解决问题，类似于Appstore的应用市场模式将出现，政府以开源平台模式呈现自身能力与资源，为社会创新力量提供二次创新与开发的基础资源。

  

![](../Images/fcfb3fefa462887014012f8e655d2e79.png)

  

通过数字政府演进路线图可以直观看到以2013年大数据为基点，所有应用、设备、需求都出现爆发式增长和转变，数字化形态也从信息数字化到业务数字化再到组织数字化转变，正在形成一种以数据治理为核心的模式。

  

![](../Images/6ddb5e10e1f220ed1b362068bc793271.png)

  

如果对数字政府进行分解和再定义，我们可以把它分为电子政府1.0、网络政府2.0和智能政府3.0三个阶段。我们现在可能已经迈入智能政府3.0的阶段，在这个阶段当中我们正在从表层走向里层、从外部走向内部，关键核心是数据治理和数据资产化。很多国家、省市已经开始在数据治理和数据资产化部署相应行动。

  

**二、发展模式与实践案例**

  

从十八大以来咱们国家以“放管服”为抓手，逐步推进政府体制改革，削减行政审批事项，目前多数省级政府行政审批事项减少50%，有的省高达70%，全国各类循环证明减少了800余项。近期出台了几个文件，《政务信息资源共享管理暂行办法》、《政务信息系统整合共享实施方案》、《政务信息资源目录编制指南》、《关于开展政务信息系统整合共享应用试点的通知》等等，都在强调从政府治理的底层架构入手，以政务信息资源目录编制为抓手，推进政务信息资源的整合、共享和开放。  

  

**▊1.国内现状**

  

![](../Images/14fa0957be6c28bace462784bac3fb7c.png)

  

很多省也是以简政放权、放管结合、优化服务为抓手，真正希望达到让公众少跑腿、好办事、不添堵这个目标，同时解决政府的条块分割、烟囱林立、信息孤岛的问题。

  

**○浙江：****用数据开放驱动数字政府创新**

  

![](../Images/eae96bae42d10894bbddd6c9f74abae6.png)

  

浙江省“最多跑一次”案例背后实际上是数据共享和流程优化在发挥着巨大作用。浙江省依托综合受理专用平台、电子证照库平台、信息共享平台、电子监察平台四大平台为“最多跑一次”改革提供了全方位技术支撑。他们在个人综合库、法人综合库、信息库、电子证照库方面的归集工作基本完成，省市县三个层面的在线办事量均超过50%。

  

**○贵州：****“云平台”强化政府数据资源整合、共享、开放**

  

![](../Images/1075b6761fb7654ddc45da3328e13565.png)

  

贵州省建立了推进政府数据资源整合、共享、开放和利用的云上贵州平台，打破政府各部门信息孤岛，实现了政府数据信息的融汇和应用。云上贵州现在已经成为贵州省金名片。今年《贵州省数字经济规划》出台之后，大数据发展管理局又梳理出大数据发展的十大重点工程（产业培育、项目裂变、融合升级、数据融通、数字政府、数据扶贫、基础设施攻坚、安全铁壁、万千人才、首选实验田）。

  

**○广东：**“统筹、联动、协同、通办”推动数字治理

  

![](../Images/2540899a2ba1895aba3d0b166e057942.png)

  

广东省着力构建“管运分离”的“数字政府”建设管理新体制，建成省级统筹、整体联动、部门协同、一网通办的“互联网+政府服务”体系。今年《广东“数字政府”改革建设方案》也已经通过了省政府常务会议，相信在这个方案出台之后，广东省在政治体制改革这方面会做出很多大胆和创新的选择。

  

**▊2.国际观察**

  

![](../Images/73cd017f5fedeee5b3011e3222999676.png)

  

利用信息化或者数字化的手段来推动社会经济和政府治理的发展，已经成为全球的治理大潮。**通过美国的开放政府计划、英国的政府数字化战略以及加拿大开放政府草案可以提炼出几个共同点：****一是**数字领袖/CIO与第三方合作，**二是**建立统一的数字服务标准和通用技术平台，**三是**服务的改造和重新设计以简化流程和访问要求，**四是**信息透明度、开放政府数据、公众参与。

  

**○英国：****政府即平台**

  

![](../Images/e74d7af171fcd1b7ee8117f7d2235cce.png)

  

英国提出建设以平台为基础的政府，实际上最根本的就是要建立跨部门模式来提供公共服务。对“政府即平台”理念的执行，英国内阁办公室和各部门协商，牵头制定和提供一系列的通用跨政府部门技术平台，范围覆盖数据开放、数据洞察、身份认证、支付、云服务、事务办理等。注重数字素养的提升，英国政府非常注重各部门领导人的数字素养，通过培训和人才招聘来提升各部门团队的数字素养。注重第三方力量的参与，为鼓励更多第三方力量参与到数字政府战略的落地中，英国政府将开放合作的理念践行在各个环节中。例如，积极开放API，将企业和第三方的平台成为政府网站的延伸和扩展。

  

**○特朗普时代的美国政府****数字化转型**

  

![](../Images/e15fe09c822aba601f58c0e2e2cf83dd.png)

  

**美国在政府数字化转型当中强调了几个点：****第一**是让公众能随时随地通过任何设备方便、快捷获取政府的高质量服务，**第二**个是政府要适应数字化的发展进程，能够经济、安全、有效的地管理数据应用和资产，**第三**是强调社会创新与对创新工具的采购。

  

除了对物联网、安全标准、云计算、自动化数据分析的使用，美国也是积极培养一个鼓励创新和前瞻性思维的环境，也要求利用私营部门创新想法和实践来推动政府改革与治理。

  

**三、评价体系和未来展望**

  

**▊1.AI时代全球数字政府聚焦的三大任务**

  

![](../Images/0d0090ef9d8ec70a204b9cf9c1a2c682.png)

  

除了美国和英国，实际上还有很多国家，包括新加坡、韩国、日本、加拿大等国家，针对数字政府的建设也开展了许多行动。**总体来看全球数字政府聚焦三大任务：**

  

**○第一，发展数字经济，**反哺数字政府发展生态的内生动力。数字经济和数字政府是依存关系，数字经济发展会有效地推动数字政府的建设，而数字政府的发展速度也将影响数字经济的节奏。

  

**○第二，推动数据共享与开放，**互联网政务乘数效应的关键策略。我们一直讲的数据共享和开放实际上是发挥互联网政务乘数效应的关键策略。

  

**○第三，提升数字素养，**持续推进数字政府发展的重要软实力。数字政府不仅仅要改变现有工作方式，更重要的是要重塑公共服务价值与观念。

  

**▊2.国外评价体系分析**

  

![](../Images/6c46806e310d20d73f2067bea0cce5fe.png)

  

国际上包括经社部、早稻田大学等机构都对数字政府建设的绩效和效果进行过相应的评估。今年早稻田大学发布的2017年国际数字政府评估排名相关指标，其中像新加坡、美国、韩国、日本都是名列前茅，咱们国家是第44名，在60多个国家当中处于中下游水准，所以说目前我们国家数字政府的发展还是比较缓慢，但是基于雄厚的基础条件，还有很大的上升空间。

  

通过这样一套指标体系可以看到，针对数字政府评估从基础设施、服务应用到相关的保障措施都是一个考核要点。

  

**▊3.国脉评价体系分析**

  

![](../Images/ef84de3e79e4f2fcde3e561ee671c5de.png)

  

在国脉看来，数字政府评价指标是可以从政府治理精细度、公共服务体验度、数据共享与开放价值度、制度规范包容度以及数字基础设施感知度这五方面进行细化的。

  

**▊4.数字政府未来四种形态**

  

![](../Images/5a3676875c1bcf665b033555b63818a9.png)

  

从现在以及未来相当长一段时间内，我们可以展望数字政府将呈现出**平台政府、数据政府、云端政府以及开源政府四种形态：**

  

**○平台政府，**强调的是整体政府和协同政府，那么在平台政府当中，部门与部门之间、层级与层级之间，地域与地域之间的政务数据边界将被打破，公众可以像享受商务服务一样享受政务服务。

  

**○数据政府，**包括三条数据流，分别是部门之间横向数据流，不同层级之间的纵向数据流，以及政府与公众和企业产生的数据流，通过三条数据流交融与交汇，通过一个一个数据库连通实现更大范围地数据共享。

  

**○云端政府，**顾名思义就是支撑我们实现政务信息资源的优化配置。

  

**○开源政府，**实际上是大众创新模式的崛起，在这个概念当中我们所要关注的是社会巨大的创新价值挖掘。

  

**▊5.未来展望**

![](../Images/22302dfaff2e0113a2eef6fe6597e751.png)

**●****在新技术的影响下，数字政府还有几个值得关注的点：**

  

**○第一，**VR/AR与公共服务体验革命。数字政府建设仅仅是一个起点，运营才是关键。在解决政务数据共享和服务准确性之后，在线体验的成熟度将成为决定政府口碑的重要准绳，而大批企业也将由政务服务平台建设者转向政务服务产品的设计者。

  

**○第二，**区块链与透明政府。区块链将催生透明政府的到来，区块链技术的应用在身份认证、土地确权、法律判决等领域将产生至关重要的影响，作为一个公共账本，用户或组织无法抹去痕迹，这在推进政务信息资源共享与廉洁政府建设中有着重要作用。

  

**○第三，**人工智能与定制型政府。在人工智能的影响下，以后每一个用户的每项需求都可以被量身定制，这将对服务平台、服务设计者与法律产生巨大挑战，围绕用户需求，人工智能或许并不能完全有把握在相关法律范畴内对用户的服务请求提供满意答案。

  

**○第四，**社交直播与数字民生。社交直播的盛行将对政府机构的反应与决策速度与效率，以及舆论应对能力提出严重挑战。社交直播无疑也是数字民主的重要推动力，公民在线参与的频繁与影响力的提升，将有效促进政府在信息公开、回应关切等方面能力与水平的提升。

  

实际上，政府数字化转型不会一夜之间完成，长远来看收益最大、付出代价最多可能都集中在短期。所以说相信通过制定相应的政策措施，通过建立开放平台，通过社会第三方力量参与，能够形成一个长久和持续的政府治理体系。
