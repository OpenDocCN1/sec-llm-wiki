# IPv6商用，这次是否“狼真的来了”？

今天（11月26日）晚上七点十分左右，我正在家里享受着难得的双休的最后一个晚上，一边刷碗，一边听着一岁八个月的奇奇在客厅中咿咿呀呀的说着某个星球的语言，气氛温馨而祥和，突然，作为BGM的新闻联播中传出了这个消息：

  

中共中央办公厅、国务院办公厅印发了《推进互联网协议第六版（IPv6）规模部署行动计划》，并发出通知，要求各地区各部门结合实际认真贯彻落实。行动计划旨在加快推进基于互联网协议第六版（IPv6）的下一代互联网规模部署，促进互联网演进升级和健康创新发展。

  

这么高调的宣布推进IPv6建设，我第一个反应是——伟大的XXX已经能搞定IPv6了？

  

IPv6是计算机网络行业的一个宏大设计，它不仅极大扩充了IP地址资源，还针对IPv4网络中的已知问题做了很多颠覆性的设计（例如路由表、IP地址分配方式、安全特性等），以期提供给整个人类一个更安全、更高效的计算机网络。

  

由于Internet发展的不平衡，有限的IPv4地址并不是按照人口来分配的，西方发达国家特别是美国由于显著的先发优势，占有了绝大多数的地址段。而占据全世界人口大多数的发展中国家，能分到的IP地址数量十分有限。特别是中国，信息基础设置发展的速度非常快，IPv4公网地址很久以前就面临枯竭。因此中国应该是最有意愿推动网络升级的。

  

然而，作为网络层基础协议的IP协议，并不是那么容易升级的。所有的终端、交换机、路由器都要支持才行，这涉及到巨大的投资，并且不可能同一时刻完成替换。幸好出现了NAT，能够把私网地址映射为公网地址，极大缓解了公网地址的消耗。同时，IPv6的安全特性，会使我国有关部门的业务需求受到极大挑战，管理机构也没有足够的动力去推动技术升级。所以IPv6的概念每次都是炒作一段时间之后就冷下来。

  

我之前在设备商工作，2006年刚进公司时，一个特性在IPv4上实现之后，需要立刻在IPv6上实现，后来几年甚至要求在项目设计之初就考虑V4、V6双栈，那个时候每年运营商集采时也都会测IPv6的性能。然而几年之后，每次大家都是“只听楼梯响未见人下来”，IPv6的商用被一次次的延后，真的有些“狼来了”的感觉，所幸公司就不强制要求双栈特性一致了。

  

到了今年，情况似乎发生了变化。移动互联网的蓬勃发展使所有人都养成了时刻在线的习惯，5G的商用计划也已明确，而5G最显著的应用就是IoT——万物互联。

  

IoT时代来临之后，会有不计其数的设备需要连接到网络中，这是再靠NAT已经很难满足要求了——一个局域网内就可能有数以十万计的设备要同时接入Internet，公网IP的65535个端口都不够分配了。再不启用IPv6，网络管理将会变得十分复杂。因此，升级基础协议将是一个不得不做的决定。前文提到的《行动计划》中的阶段计划，有明显的对5G的指向性。

  

另一方面，大家对隐私越来越重视，https正在加速替换http，即使不升级IPv6，网络中的明文传播的内容也会越来越少。原来因为强制IPsec而导致的监管困境，逐渐成为了两种协议栈面临的共同困难。因而这一点反而不再成为升级IPv6的障碍。近几年随着大数据、机器学习的快速普及，针对流量模型的研究也发展迅速，监管的手段更加多样化了，即使是对加密传输的报文，也能在不破解内容的情况下获取一些信息，无论IPv4还是IPv6都一样，升级也就更无所谓了。  

  

IPv6针对IPv4的一个重要改进就是地址分配方式：

![](../Images/e0b50b10e8c814198eb22904f998a976.png)

运营商在地址分配上的话语权比IPv4更大，而且可以为每个设备分配一个唯一的地址，溯源比IPv4方便的多。这一特性，也是有关部门很需要的。

  

最后，IPv6的概念经过20年的发展、普及，绝大多数操作系统、网络设备都已经支持，而且还有各种过渡技术（例如NATPT、DSLite、6in4隧道、4in6隧道等等）能够为平滑过渡提供保障，技术上遗留的问题已经不多了。

  

总之，升级IPv6不再是纸上谈兵，大部分技术已经准备好，整个行业都在等着一个合适的时机，然后启动轰轰烈的的升级过程。那么现在这个时机到了么？也许到了，但是你准备好了么？

  

虽然基础架构已经能支持双栈，但是上层业务并不能天然支持IPv6场景。在IPv6环境中，很多原有业务的逻辑都会受到挑战，同时也会创造出很多新的应用，就像移动互联网之于传统互联网一样。我们的网络资产普查如何遍历整个IPv6地址空间？编码中存储IP地址用的什么数据结构？每个设备都有公网IP之后，企业的安全策略如何调整？

  

既然在新闻联播中公布了明确的时间表，说明有关部门的决心很大，我们作为行业中的人，都应该想想应该做些什么了。或许这次，狼真的来了。
