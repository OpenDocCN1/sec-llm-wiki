# 韩国网络托管公司Nayana再遭勒索病毒攻击，此次留有“讨价还价”的余地

什么是IDC？IDC，Internet Data Center，也就是我们所称的“互联网数据中心”。它为互联网内容提供商（ICP）、企业、媒体和各类网站提供大规模、高质量、安全可靠的专业化服务器托管、空间租用、网络批发带宽以及ASP、EC等业务。

以此我们可以看出，IDC在整个互联网服务链条中所起到的作用是何其重要。一旦这个环节出了问题，也就意味着整个互联网服务链条将被中断。

担心总不是多余的，在今年6月份韩国IDC旗下的一家网络托管公司Nayana遭遇了勒索软件攻击，其153台Linux服务器被攻陷。最终，该公司同意向攻击者支付价值100万美元（约合683万人民币）的比特币才获得了“救赎”。

不过，Nayana似乎并没有在付出高额经济代价之后吸取教训。没有修补漏洞或使用弱密码的Linux服务器再次成为了勒索软件的攻击目标。

Nayana在本月8日宣布，9台托管于Nayana的服务器受到了勒索软件的攻击。攻击者并没有注明详细的赎金数额，但留下了联系方式。这和6月份的攻击很相似，攻击者似乎给了Nayana一个“讨价还价”的余地。

![](../Images/2995810a412bb1137c6947b08b65f2f8.png "韩国网络托管公司Nayana再遭勒索病毒攻击，此次留有“讨价还价”的余地-E安全")

韩国互联网安全局（KISA，Korea Internet & Security Agency）的一位代表说：“此次事件中使用的勒索软件与6月份的事件中使用的勒索软件不同，它仅针对的Linux系统文件进行加密。”

“Linux服务器的安全系统创建起来非常复杂，它不像Windows服务器，只需安装一些补丁即可。” Hauri CERT的Choi Sang-myung部门负责人表示，“这个勒索软件似乎只是针对韩国服务器，因为在以前的勒索软件报道中，并没有它的身影。”

一位安全专家说：“Nayana是由韩国IDC运营的，韩国IDC有必要为一家曾遭受过攻击的公司再次成为受害者而负责。”
