# 韩国LG服务中心遭遇勒索软件攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247484061&idx=5&sn=246e9e84124e3361292e38fe52517cd0&chksm=ebf945bddc8eccab2414059ddcde93e1c5af3631e44e26af25f828a8109064539e2f2b521900&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247484061&idx=5&sn=246e9e84124e3361292e38fe52517cd0&chksm=ebf945bddc8eccab2414059ddcde93e1c5af3631e44e26af25f828a8109064539e2f2b521900&scene=27#wechat_redirect)

韩国安全机构上周三表示，韩国科技巨头LG电子的服务中心遭到勒索软件攻击，攻击者使用的恶意代码与WannaCry勒索软件相似。

![](../Images/2ba1fd76b1393209d58b0ab545d2a228.png "韩国LG服务中心遭遇勒索软件攻击-E安全")

LG表示，某些服务中心的自助服务终端机遭到勒索软件攻击。上周一早上，遭遇攻击的自助服务终端机出现访问故障，LG停止使用设备后向韩国网络安全局(Korea Internet and Security Agency)通报了事件。

LG电子发言人表示，故障是勒索软件造成的，LG第一时间关闭了服务中心网络，所幸没有造成损失。该公司称已更新这些设备的安全系统，自助服务终端机上周也已恢复正常运作。

韩国网络安全局官员表示，这些自助服务终端机可能遭遇了WannaCry勒索软件攻击，因为他们在LG自助服务终端机中发现的恶意代码样本与WannaCry勒索软件相同。至于攻击的确切原因，还有待进一步调查。

安全专家敦促组织机构确保更新系统。Malwarebytes的恶意软件情报研究员乔维·尤玛威表示，任何国家都可能遭受勒索软件攻击，目前仍有蠕虫不断地扫描互联网寻找易受攻击的主机。WannaCry从未真正离去，其变种或仍在兴风作浪。
