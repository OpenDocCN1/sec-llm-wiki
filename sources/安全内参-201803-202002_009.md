# 奇安投资王鹏飞：危机总与机会并存，创业者要谨慎决策

2020年新春，中国遭遇了新型冠状病毒疫情，为了防控疫情很多企业延迟开工，餐饮等行业客流量的骤减也让大量中小企业面临生存挑战。对于网络安全行业，疫情会对2020年中国网络安全行业产生什么影响？为此“安全创客汇”联合《安全内参》发起了系列人物访谈报道，分别采访了投资人、创业者、行业专家、甲方企业等，从不同的角度来解读此次疫情对网络安全行业，对创业者的影响。

  

《安全内参》采访了奇安投资CEO王鹏飞，就网络安全行业2020年发展态势及创业者的发展前景发表了相关观点和建议。

  

![](../Images/f74028314809cb4c3db57b57555327aa.png)

*王鹏飞：**奇安投资创始合伙人*  

  

王鹏飞认为，总体来看疫情对网络安全影响有限。因为网络安全行业的需求来自两方面：一是政府预算和采购，二是企业信息化建设自身的采购需求。围绕政府相关行业的需求不会因为疫情有太多影响，在此次疫情期间，也有很多疾控单位对网络安全保障有着强烈的需求。

  

企业自身需求是市场化的需求，必然受到企业自身的经营情况和财务影响，在此次疫情期间，远程办公突然火爆，办公业务的互联网化提高了产业互联网的渗透率，而互联网化本身也会带来更多的信息安全需求。总体来看，疫情对网络安全影响有限。

  

对于创业者，王鹏飞也给出了建议。他表示，网络安全行业的企业有一个通性，就是高应收账款，但是低现金流。在这样的商业模式特点下，现金流的压力一直是企业发展的掣肘。在面临冲击时候，创业者一定要把握好自身现金流管理。具体而言，控制支出主要就是研发费用的收缩，但这也有可能弱化了核心竞争力。

  

不过，王鹏飞也提到，所有的危机都是与机会并存的，在疫情的冲击下，也会带来局部需求的增长和部分产品技术的淘汰，例如现在火热的远程在线办公协助平台，不过这时候就考验创业者的判断力了，网络安全从业者要谨慎把握业务方向。

  

创客访谈是安全创客汇在2020年新装启航推出的系列报道，旨在为网络安全领域的创业者、投资人及相关人员提供一个沟通交流的平台，打造一个能获取高价值信息及有效合作机会、实现资源全面对接、知识的高阶聚合、商业的高度互信的生态平台。除了创客访谈，安全创客汇还有创客沙龙，创业培训、年度明星赛等系列活动。
