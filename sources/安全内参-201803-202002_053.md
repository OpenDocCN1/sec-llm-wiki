# 俄罗斯《主权互联网法》正式生效：可与全球互联网断开

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247486673&idx=1&sn=0effb6a2fe30cf30e14bd9e98382cc47&chksm=ebf94bf1dc8ec2e76cdec90e366cc880d0815e8d084ab279edb95aa0eb1462294bad26ac823b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247486673&idx=1&sn=0effb6a2fe30cf30e14bd9e98382cc47&chksm=ebf94bf1dc8ec2e76cdec90e366cc880d0815e8d084ab279edb95aa0eb1462294bad26ac823b&scene=27#wechat_redirect)

*   俄罗斯的“主权互联网”法律于上周五生效。  
    
*   该法律加强了莫斯科方面对该国互联网基础设施的控制，目的在于为俄罗斯提供一种使其网络与世界其他地方断开连接的方式。
    
*   专家们怀疑这种举措在技术上是否可行。
    

![](../Images/c9aac9a0aa9a481f8460a432f25ab1c6.png)

*2019年10月3日俄罗斯莫斯科：反对派集会的参与者在莫斯科市中心抗议政府加强对俄罗斯互联网的控制。*

俄罗斯互联网之前被称为在线铁幕。

上周五，一项颇有争议的法律生效，该法律使俄罗斯能够将其互联网与世界其他地方断开来，这让批评人士为之担忧：他们担心该措施会强化在线审查。

克里姆林宫称，已由普京总统于今年5月签署的“主权互联网”法律是一项安全措施，那样万一出现紧急情况或诸如网络攻击之类的外国威胁，可以保护俄罗斯。该法律将让莫斯科方面得以通过让互联网流量经由政府控制的基础设施路由来传输，并创建一套国家域名系统，以加强对该国互联网的控制。

从理论上来讲，该措施将让俄罗斯得以运营本国的内部网络，该网络可以独立于互联网的其余部分来运转。

专家们怀疑这种举措在技术上是否可行，并称该法律是俄罗斯政府试图对在线信息进行审查的一项举措。

普林斯顿大学信息技术政策中心的Sergey Sanovich在接受CNBC采访时说：“为了能够以一种有利于俄罗斯的方式来管理信息流，他们就必须事先部署落实一套系统。”

今年早些时候，成千上万的抗议者走上街头抗议俄罗斯的这项措施，而人权倡导者警告该法律对言论自由和媒体构成了威胁。

人权观察组织（Human Rights Watch）周四在一篇博文中说：“‘主权互联网’法律旨在为大规模监视提供法律依据，并使政府能够有效地执行现有的在线立法，该立法破坏了言论自由权和隐私权。”

普京还采取了另外一系列措施来遏制在线自由，比如禁止加密消息传送服务Telegram，但事实证明，其中许多举措并没有取得成功。

Sanovich说：“俄罗斯政府的目的是能够阻止他们不希望看到的内容，又不损害整个网络。”

俄罗斯允许其互联网在过去的三十年间自由发展。据互联网协会主席兼首席执行官Andrew Sullivan声称，断开全球网络连接非常棘手。
