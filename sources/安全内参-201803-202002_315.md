# 《网络安全法》正式实施一周年观察报告

去年6月1日，《网络安全法》正式实施，我国的网络安全领域从此进入法制化阶段。一年来，随着各种相关配套法规制度陆续出台，各地各行业通过各种行动和措施推进《网络安全法》的落地，《网络安全法》效应已经初步显现。
