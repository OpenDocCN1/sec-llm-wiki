# 伊朗机场电子显示屏遭黑客劫持，播放政治抗议宣言近一小时

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247485825&idx=5&sn=4b41316583c2ab777ee92ab2b7fcdf0c&chksm=ebf94ea1dc8ec7b75e45413975864c0b6f5b1b4045d18cac441f07978b4b0d7a5c3d85513fd5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247485825&idx=5&sn=4b41316583c2ab777ee92ab2b7fcdf0c&chksm=ebf94ea1dc8ec7b75e45413975864c0b6f5b1b4045d18cac441f07978b4b0d7a5c3d85513fd5&scene=27#wechat_redirect)

在上周四（5月24日），位于伊朗东北部马什哈德市的机场遭到一群不明身份黑客的袭击。机场电子显示屏遭到黑客劫持，并向伊朗政府发出抗议宣言。

据法尔达电台（Radio Farda）报道，黑客在机场出入口的电子显示屏上留下了一些图像，显示了一份抗议伊朗政府在中东地区军事存在的声明。

声明以波斯语呈现，指责伊朗伊斯兰革命卫队（Islamic Revolutionary Guard Corps，IRGC）在黎巴嫩、叙利亚和加沙浪费伊朗人的生命和财政资源。

这个自称Tapandegan（Palpitaters）的黑客组织表示支持伊朗法尔斯省Kazeroon县居民的抗议活动，而这场抗议活动已经持续了长达数月的时间。

![](../Images/e3e84f3be720eb43e8295a2285e161cc.png)

报道指出，该组织之所以能够劫持电子显示屏并发布图像来源于他们成功侵入了马什哈德机场民用航空部负责人Mohsen Eidizadeh的电子邮箱。另外，该组织还鼓动乘客拍摄电子显示屏画面并使用标签“Protests\_alloverthecountry（抗议遍布全国各地）”通过社交媒体平台进行发布。

根据法尔达电台的调查结果来看，数以百计的伊朗人通过Twitter上发布了电子显示屏的照片。由于伊朗境内的Twitter用户担心政府会对此次事件进行镇压，发帖人大都使用了虚构的用户名称，如“Dr Zhivago（日瓦戈医生）” 和 “Godless（无神论者）”。

法尔达电台指出，马什哈德是2017年12月28日大规模反政府示威活动开始的城市，并且已经蔓延到100多个其他伊朗城市。它也是伊朗的第二大城市，第八任什叶派伊玛目神殿所在的宗教城市，地方当局和神职人员都是最坚定的强硬派之一。
