# 英国首次发动网络战：对伊斯兰国家组织实施“大规模网络攻击行动”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247485561&idx=1&sn=c5b84825b70f538ec9a00e94fa509ec4&chksm=ebf94f59dc8ec64f7f7e1d5db56a6ab025b3bd79a8be955b279d4d3e8f3cbd7f70897141f18b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247485561&idx=1&sn=c5b84825b70f538ec9a00e94fa509ec4&chksm=ebf94f59dc8ec64f7f7e1d5db56a6ab025b3bd79a8be955b279d4d3e8f3cbd7f70897141f18b&scene=27#wechat_redirect)

英国情报机构政府通讯总部（简称GCHQ）负责人披露称，英国已经对伊斯兰国家组织（Islamic State group）实施“大规模攻击性网络行动”（major offensive cyber-campaign）。

军情五处特工Jeremy Fleming表示，此次行动旨在阻止对方的协调攻击活动，同时压制其网络宣传能力。

这是英国有史以来第一次以军事行动的方式系统性打压敌对方的网络活动。

![](../Images/79f510cf0f2e2f6eb6a7d3f7482b6b7d.png)

Fleming先生以GCHQ主任的身份，通过公开演讲发布了上述消息。

他在本届于曼彻斯特召开的Cyber UK大会上表示，“这些行动带来了广泛的成果。”

“2017年，伊斯兰国家势力开始发现其几乎无法通过网络传播仇恨情绪、利用正常渠道发布言论或者散布其出版物。”

Fleming先生指出，大部分网络行动“太过敏感，因此无法具体讨论”，但可以肯定的是这些行动扰乱了伊斯兰国家组织的在线活动，甚至对其设备及网络造成了严重破坏。

他同时补充称，“这轮行动也揭示出我们该如何发动有针对性且具备实效的网络攻击。”

不过Fleming先生同时强调，与IS的斗争还远没有结束，因为该组织正继续“密谋在英国发动进一步恐怖袭击”，同时找到了新的“无监管空间作为自身运营基础”。

**“模糊界限”**

Felming先生亦就所谓“不可接受的网络行为”对俄罗斯提出批评，表示这将成为英国及其盟友所面对的“日益增长的威胁”。

他回顾了去年发生在乌克兰的NotPetya勒索软件攻击事件。虽然英国与美国随后表示，这一轮攻击事件背后由俄罗斯军方负责支持，但莫斯科政府否认了这一说法。

Fleming先生表示，“他们并没有遵守同样的规则。他们正在模糊犯罪活动与国家活动之间的界限。”

他还提到在索尔兹伯里对Sergei与Yulia Skripal使用神经毒素的作法“严重且令人震惊”，这表明了“俄罗斯的鲁莽态度”。

英国方面指出，俄罗斯政府应对此次攻击“负责”，不过俄方否认与此事存在关联。

Fleming先生称，“来自英国及国际社会的强烈反应，表明克里姆林宫确实应对上述非法行动承担后果。而且我们对于俄罗斯的了解也在持续加深。”

在演讲结束之后，英国国家网络安全中心首席执行官Ciaran Martin在采访中提到，Notpetya案同样是俄罗斯方面鲁莽行动的体现。

在被问及此次攻击性网络行动公告是否是在向俄罗斯方面发出隐性警告时，Martin表示有时候最好的防守就是防守——而非进攻。

Fleming先生进一步解释了GCHQ的其它几项发展目标，包括追踪那些通过暗网发布儿童性虐待图片的用户。

他指出，网络的出现为攻击者及防御者建立起新的对抗平台。这将带来“巨大”挑战，但强大且拥有合法性作为依托的GCHQ完全能够解决这一切。

本周三，Fleming先生宣布新的GCHQ总部将于曼彻斯特启动，并希望能够吸引到“熟悉技术的新鲜血液”的加入。
