重磅！中央网信领导小组改为委员会，强化管理职责


中央网络安全和信息化领导小组改为委员会，负责相关领域重大工作的顶层设计、总体布局、统筹协调、整体推进、督促落实。为维护国家网络空间安全和利益，将国家计算机网络与信息安全管理中心由工业和信息化部管理调整为由中央网络安全和信息化委员会办公室管理。


网络安全法实施8个月全国执法盘点：新浪微博、腾讯被处最高罚款


目前各地已公开的执法案例共30例左右，涉及关键信息基础设施的网络运营者、直接负责的主管人员、网络产品或服务提供者等责任主体。现有的处罚对象主要集中于网络运营者这一核心责任主体。


新加坡《网络安全法2018》法案正式通过（附解读）


2018年2月5日，新加坡议会通过了《网络安全法2018》（Cybersecurity Act 2018）。该法是落实新加坡网络安全战略（Cybersecurity Strategy）的重要举措，旨在建立关键信息基础设施所有者的监管框架、网络安全信共享机制、网络安全事件的响应和预防机制、网络安全服务许可机制，为新加坡提供一个综合、统一的网络安全法。


英国政府强化物联网监管：智能设备寿命结束前网络防护措施必须一直有效


为了应对日益严峻的网络安全形势，英国政府将出台一揽子计划，其中包括要求制造商为电视、玩具，音响等“智能”电子设备安装内置严密的网络安全保护机制，该机制必须保证在这些设备的寿命结束之前一直有效。


欧盟希望过滤上传到互联的所有代码，或成开发者噩梦


欧盟一项提案要求所有平台检查上传的内容有无侵犯版权，旨在让盗版者更难共享内容和媒体，然而可能会使软件的成本更高昂。GitHub表示，自动过滤代码对于独立程序员和大企业程序员来说都是毁灭性的。面临的问题可能包括：误报/漏报、丢失依赖项、许可证混淆以及不必要的负担阻碍创新。

漏洞预警


国家漏洞库CNNVD：关于思科多个漏洞情况的通报


成功利用上述漏洞的攻击者，可以对使用了IOS以及IOS XE系统的思科设备发送恶意的数据包，最终实现拒绝服务或远程代码执行，完全控制设备等。所有支持Smart Install client特性的IOS以及IOS XE设备都可能受漏洞影响。目前，思科官方已对该漏洞进行了修复，受影响的用户请尽快对系统更新进行防护。


CNCERT：Drupal core远程代码执行漏洞安全公告

英特尔再爆处理器漏洞：BranchScope侧信道攻击


四所美国大学的研究人员发现了一种新型的侧信道攻击，它可利用现代处理器中的推测执行功能从用户 CPU 中恢复数据。虽然推测执行这个 CPU 功能曾在今年年初被指遭 Meltdown 和 Spectre 漏洞利用，但研究人员指出，由于这次它攻击的是推测执行进程中的一个新分区，因此不同于之前的缺陷。
