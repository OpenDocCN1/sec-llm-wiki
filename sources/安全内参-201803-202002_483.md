# 中国军团缺席，全球黑客大赛Pwn2Own前途黯淡

为期两天的Pwn2Own 2018于上周六结束，微软Edge、苹果Safari，以及火狐浏览器和甲骨文 Oracle VirtualBox 被攻破，研究人员总共拿到26.7万美元的奖金，远不足本次由微软、VMware和ZDI提供的奖金池——200万美元。同样，也远不及前几届拿走的奖金。2017年83.3万，2016年46万，和2015年的55.25万美元。

  

缺少了中国军团的Pwn2Own，这项经典黑客大赛的前途黯淡呀！
