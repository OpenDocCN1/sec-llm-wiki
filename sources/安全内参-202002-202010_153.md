# 佳能遭到Maze勒索软件攻击，据传10TB数据被盗

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247489696&idx=3&sn=9515a96e4eaf2b4eb1b79ca7d3906c74&chksm=ebf95f80dc8ed696cec1cbaca74e686566f53029429b96f5564577e27f17aa3502ff3015d653&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247489696&idx=3&sn=9515a96e4eaf2b4eb1b79ca7d3906c74&chksm=ebf95f80dc8ed696cec1cbaca74e686566f53029429b96f5564577e27f17aa3502ff3015d653&scene=27#wechat_redirect)

Maze勒索软件，史上最跳的勒索软件，专门针对大型公司进行勒索攻击，此前已经有多个大型案例，同时黑鸟也对该软件功能和勒索的方式进行过描述，详情：[Maze勒索软件](http://mp.weixin.qq.com/s?__biz=MzAxOTM1MDQ1NA==&mid=2451180951&idx=1&sn=4fc49f1894e818d374eabc5159c55009&chksm=8c26fb4ebb517258c293984c52d8237b092fdbfc04ecc41c5628e4188d795f538d93a4baf1a3&scene=21#wechat_redirect)

  

而近日，著名数码摄像机厂商佳能(Canon)被曝遭受勒索攻击，影响了许多服务，包括佳能的电子邮件，微软团队，美国网站以及其他内部应用程序。

![](../Images/05a33cba89c14505c1ae8cc156546fd3.png)

![](../Images/aec5c490fb0c515950b5cd022cdc80a8.png)

  

据外媒报道称，**佳能image.canon云照片和视频存储服务**的可疑中断，导致其免费10GB存储功能的用户丢失数据。

![](../Images/99aa1aec3dd370dedf7c7636b56f56d8.png)

  

服务于2020年7月30日停机，直到8月4日服务回复，目前访问已经恢复。

![](../Images/9b5728017906762c97c911adb801df49.png)

  

由BleepingComputer消息称，佳能的消息来源人士共享了一张全公司范围的通知的图像，该通知的标题为“** IT服务中心发来的消息**”，该通知于今天上午6点左右从佳能IT部门发送。该通知指出，佳能正在经历“影响多个应用程序，团队，电子邮件和其他系统的广泛传播的系统问题，目前可能不可用”。  

![](../Images/4bb8f86059e3eeb4f98e351b6e1eda7b.png)

目前，黑鸟访问了一下佳能美国总部的官网，显示正在维护，使用了一招传统艺能，图片镇压网站。

  

![](../Images/b5398e2df7af4db48a5abfc82452e894.png)

  

同时bleepingcomputer还发布了受影响的网站列表  

```


www.canonusa.comwww.canondv.com
佳能内部被攻击的勒索信截图![](../Images/45ca2e0b19ce724bea39a74b843cce56.png)BleepingComputer联系勒索软件运营商，Maze告诉他们的攻击是今天早上进行的，当时他们偷了**“10 TB数据，私有数据库等”**作为对佳能的攻击的一部分。
Maze拒绝透露有关攻击的任何进一步信息，包括赎金数额，数据被盗证据以及加密设备的数量。但其透露，image.canon的服务中断与勒索软件攻击无关。

```

截止发文为止，黑鸟还未能看见Maze勒索软件团伙上架佳能的数据。
