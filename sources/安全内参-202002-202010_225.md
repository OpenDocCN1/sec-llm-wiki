# 疑网络攻击致核设施起火，伊朗威胁将予以报复

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247488761&idx=2&sn=5c4fc87c268f1fa5d3d3497e94f64b5c&chksm=ebf953d9dc8edacf1d5131a5140ab403806dd3b4297bdd08c42401f683b6f53220677479bc07&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247488761&idx=2&sn=5c4fc87c268f1fa5d3d3497e94f64b5c&chksm=ebf953d9dc8edacf1d5131a5140ab403806dd3b4297bdd08c42401f683b6f53220677479bc07&scene=27#wechat_redirect)

新华社7月4日消息，就伊朗纳坦兹核设施2日起火，伊朗官员说，如果证实火灾由网络攻击引发，伊朗将予以报复。

  

纳坦兹核设施铀浓缩活动受到国际原子能机构监督。这一联合国机构3日说，火灾不影响监督继续。

  

纳坦兹核设施位于伊朗中部伊斯法罕省沙漠地区，大部分建筑位于地下，可生产浓缩铀。伊朗原子能组织2日发布一张照片，显示这处设施地上一层建筑部分屋顶和墙体被烧，一扇门摇摇欲坠，表明屋内可能发生过爆炸。

  

伊朗官方3日说，起火原因已经确定，“出于安全考虑”将在日后合适时机公布。

  

三名不愿公开姓名的伊朗官员告诉路透社记者，他们相信火灾由一次网络袭击引发，没有给出证据。其中一名官员说，这次袭击以一个离心机装配间为目标，伊朗的敌人曾经发动类似袭击。

  

纳坦兹核设施2010年遭“震网”蠕虫病毒袭击，这一病毒据信由美国和以色列研发。

  

伊朗民防组织主管吴拉姆-礼萨·贾拉利2日晚些时候告诉伊朗国家电视台：“回应网络袭击是国家防御权的一部分。如果证实我国遭受网络袭击，我们将予以回应。”

  

伊朗伊斯兰共和国通讯社2日暗示，火灾可能关联敌方蓄意破坏。报道说：“到目前为止，伊朗一直试图阻止危机加深，避免形成不可预测的局面。敌对国家，尤其是以色列和美国，越过伊朗伊斯兰共和国的红线，意味着（伊朗的）战略……应该修改。”

  

记者就伊朗核设施起火提问以色列总理本雅明·内塔尼亚胡，他回答：“显而易见，我们进不去那里。”

  

国际原子能机构3日说，纳坦兹核设施起火场所没有放置核原料，起火时没有国际原子能机构人员在场。

  

“国际原子能机构与伊朗相关部门保持联系，确认火灾不会影响对（伊朗铀浓缩）安全防护的验证活动，预期验证将继续。”

  

路透社以网络安全研究人员为消息源报道，现在断定起火缘于网络袭击“为时尚早”。

  

美国2018年退出伊朗核问题全面协议后，伊朗分阶段中止履行协议部分条款，包括突破低丰度浓缩铀存量、浓缩铀丰度以及启动IR-4型离心机和IR-6型离心机。
