# 一个功能强大到让Mirai相形见绌的物联网僵尸网络？

4月8日，安全研究人员声称，一个新发现的僵尸网络是有史以来最先进的物联网平台之一，它专门攻击家用路由器、录像机及其他联网设备。它有一系列高级功能，包括能够将恶意流量伪装成良性流量、保持持续隐匿以及感染运行在至少12种不同CPU上的设备。

 

防病毒软件提供商Bitdefender的研究人员表示，“这个名为dark\_nexus的新物联网僵尸网络拥有大量新的功能特性，让我们见过的大多数物联网僵尸网络和恶意软件相形见绌。”在Bitdefender跟踪的三个月期间，dark\_nexus前后更新了30个版本，其开发人员在稳步添加更多的功能特性。

**01**

![](../Images/790d07a02715f69801c4a792d40bbb36.png)

**威力强大得多**

  

该恶意软件已感染了至少1372款设备，其中包括录像机、热成像仪以及由Dasan、Zhone、Dlink和华硕等厂商制造的家庭小型办公室路由器。研究人员预计，随着dark\_nexus的开发继续下去，更多款式的设备会受到影响。

  

研究人员在一份报告中写道，相比其他物联网僵尸网络时，我们分析后确定，虽然dark\_nexus重用了Qbot和Mirai的一些代码，但核心模块基本上是原创的。它可能与已知的物联网僵尸网络存在一些相同的功能，但其开发一些模块的方式使其功能要强大得多。

  

该僵尸网络通过猜测常见的管理员密码和利用安全漏洞的双重手法来进行传播。增加受感染设备数量的另一个功能是，它能够攻击在种类广泛的CPU上运行的系统，这些系统包括：

  

•arm：ELF 32位LSB可执行文件，ARM，版本1（ARM），静态链接，已剥离

•arm5：ELF 32位LSB可执行文件，ARM，版本1（ARM），静态链接，已剥离

•arm6：ELF 32位LSB可执行文件，ARM，EABI4版本1（GNU/Linux），静态链接，已剥离

•arm7：ELF 32位LSB可执行文件，ARM，EABI4版本1（GNU/Linux），静态链接，已剥离

•mpsl：ELF 32位LSB可执行文件，MIPS，MIPS-I版本1（SYSV），静态链接，已剥离

•mips：ELF 32位MSB可执行文件，MIPS，MIPS-I版本1（SYSV），静态链接，已剥离

•i586：ELF 32位LSB可执行文件，英特尔，80386版本1（GNU/Linux），静态链接，已剥离

•x86：ELF 64位LSB可执行文件，x86-64，版本1（SYSV），静态链接，已剥离

•spc：ELF 32位MSB可执行文件，SPARC，版本1（SYSV），静态链接，已剥离

•m68k：ELF 32位MSB可执行文件，摩托罗拉m68k，68020，版本1（SYSV），静态链接，已剥离

•ppc：ELF 32位MSB可执行文件，PowerPC或思科4500，版本1（GNU / Linux），静态链接，已剥离

•arc：？

•sh4：ELF 32位LSB可执行文件，Renesas SH，版本1（SYSV），静态链接，已剥离

rce：

  

Bitdefender的报告称，尽管dark\_nexus传播模块含有针对ARC和摩托罗拉RCE架构的代码，但到目前为止，研究人员仍无法找出针对这些架构编译的恶意软件样本。

  

dark\_nexus僵尸网络的主要攻击目的是执行分布式拒绝服务（DDoS）攻击，通过向众多网站及其他在线服务发送潮水般的垃圾流量，从而使它们不堪重负、最终宕机。为了使攻击更有效，恶意软件采用了一种机制，可以让恶意流量貌似是Web浏览器发送的良性数据。

  

**02**

![](../Images/790d07a02715f69801c4a792d40bbb36.png)

**谁是希腊太阳神？**

  

dark\_nexus的早期版本含有字符串“@greek.helios”。该字符串还出现在了2018年版的“hoho”中，这是Marai恶意软件的变体。hoho和dark\_nexus都含有Mirai和Qbot代码。Bitdefender的研究人员很快发现，“greek helios”是销售物联网僵尸网络恶意软件和DDoS服务的知名网上用户所使用的名称。一个名为greek helios的用户开设的Youtube频道收录了宣传恶意软件和所提供服务的几段视频。此人在物联网恶意软件技能方面似乎颇有经验，已到了开发这个新的dark\_nexus僵尸网络的水平。

  

4月8日的报告称，一段视频显示了一计算机桌面上有IP地址的快捷方式，该地址最早曾在去年12月出现在Bitdefender的蜜罐日志中，是一台dark\_nexus C/C服务器的地址。诸如此类的线索让研究人员怀疑这个人是dark\_nexus的幕后主使。

  

dark\_nexus通过两个模块，使用Telnet登录信息填充（使用一份预定义的登录信息列表）和漏洞来攻击设备。该僵尸网络的早期版本钻了一些安全漏洞的空子，比如Linear eMerge E3系列中高危的命令注入漏洞CVE-2019-7256和Netgear DGN1000路由器中未经身份验证的远程代码执行漏洞。

  

dark\_nexus还借用了Qbot和臭名昭著的Mirai僵尸网络以前使用的代码和进程，后者在2016年发起了Dyn DDos攻击。比如说，其启动代码的行为与Qbot相似，会阻止几个信号，并将其自己与终端脱离开来。另外，与Mirai相似，dark\_nexus绑定到固定端口（7630），从而确保该僵尸程序的单个实例可以在设备上运行。

  

与TheMoon、Gwmndy和Omg僵尸网络等僵尸网的另一个相似之处是，研究人员在dark\_nexus的一些版本中发现了socks5代理，它们可能用于租用访问资源的权限。

**03**

![](../Images/790d07a02715f69801c4a792d40bbb36.png)

**另辟蹊径的僵尸网络**

研究人员认为，dark\_nexus组件系列是僵尸网络另辟蹊径的一个标志。这些模块经常更新，三个月内发现了30个新版本。

  

dark\_nexus自带能够逃避检测、持续隐匿的策略。该僵尸网络采用发动DDoS攻击的手法，比如说，将流量作为浏览器生成的无害流量隐藏起来，帮助绕过检测。一旦感染了设备，该僵尸程序还企图冒充是BusyBox（借/bin/ busybox之名）来伪装自己，BusyBox是一款流行的软件套件，可以在单单一个可执行文件中提供多个Unix实用程序。

  

dark\_nexus还随带用于删除被感染设备上的重新启动权限的命令，从而达到持续隐匿的目的。这些命令试图通过停止cron服务（用于计划任务），并删除可用于重新启动设备的可执行文件的权限，以防止设备重新启动。

  

研究人员称，该僵尸网络还使用一种独特的技术确保自己在被感染设备享有“最高地位”：“dark\_nexus的独特之处在于，它使用基于权重和阈值的评分体系来评估哪些进程可能构成风险。这需要维护被列入白名单的进程列表……终止超过可疑阈值的其他所有进程。”

  

该僵尸网络使用的其他功能包括一个调试模块可维护设备的适当功能和可靠性。另外，僵尸网络的有效载荷经过定制，可攻击12种不同的CPU架构，因而它所得攻击的设备类型和数量来得更广泛。

  

研究人员基于蜜罐日志的数据估计，自2019年12月被首次发现以来，该僵尸网络已经危害了全球至少1372款设备。相比之下，Mirai在2016年11月肆虐最严重时期感染了逾600000个物联网设备。

  

目前dark\_nexus感染在中国最为常见，已检测到653个节点被感染。其余四个受感染较严重的四个国家是韩国（261个）、泰国（172个）、巴西（151个）和俄罗斯（148个）。美国检测到68个节点被感染。
