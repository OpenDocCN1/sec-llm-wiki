# 社交平台Gab遭黑客攻击，70GB数据泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247496110&idx=4&sn=19a3a26ccc8bac552678f5eefbdc76ce&chksm=ebfab68edc8d3f986ddd6045761aad22d28c598522676aa753f0b436bf3771d475f2e556bfc6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247496110&idx=4&sn=19a3a26ccc8bac552678f5eefbdc76ce&chksm=ebfab68edc8d3f986ddd6045761aad22d28c598522676aa753f0b436bf3771d475f2e556bfc6&scene=27#wechat_redirect)

![](../Images/ce2c3340f07b581b78a22e78a2bb71bb.png)

  

1月6日，推特、脸书和YouTube等社交平台都暂时冻结了特朗普的账户或删除了部分内容，于是特朗普转战社交平台“Gab”。与此同时，大量用户也涌向该平台。

  

Gab是一个支持言论自由、个人自由和在线信息自由流动的社交网络平台。反对非法内容和煽动暴力，但允许除色情内容以外的所有合法言论。用户可以创建自定义过滤器，以确定他们希望接收的内容，它允许使用者发表最多300个字元的讯息。因其自由言论政策，正在受到越来越多用户的青睐。

  

不过近日该平台遭到了黑客攻击。黑客利用 SQL 注入漏洞从后台数据库中窃取了大约 70GB 用户数据，包含该网站的 4000 多万条帖子。

  

泄露的数据包括 1.5 万名 Gab 用户的公共、私人互动，并用户详细的个人资料、哈希密码和组别的纯文本密码。

  

![](../Images/2e23d9d487817fd1bcd8180bead5b452.png)

  

在泄漏的用户中，包括前美国总统特朗普、MyPillow 首席执行官迈克-林德尔，国会女议员马乔里-泰勒-格林和 Infowars 主持人亚历克斯-琼斯等知名人士的账户。不过，该公司否认自己遭遇了数据泄露，并向 Gab 用户保证，他们的密码没有被泄露。

  

爆料网站DDoSecrets称一名自称为JaXpArO的黑客把Gab外泄数据交给了自己，他们已经将这些数据汇编成了一个名为 GabLeaks 的东西，打算将其提供给选定的记者、社会科学家和研究人员进行进一步分析。
