# 臭名昭著的勒索软件组织Maze宣布“正式关闭”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247492494&idx=3&sn=d213a61ec9dae5081baaf77b4aa8c026&chksm=ebfaa4aedc8d2db806f01414eda6163c17ddee52958b6539d86233ff7ff09426530e03673cbb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247492494&idx=3&sn=d213a61ec9dae5081baaf77b4aa8c026&chksm=ebfaa4aedc8d2db806f01414eda6163c17ddee52958b6539d86233ff7ff09426530e03673cbb&scene=27#wechat_redirect)

Maze 是最活跃、最臭名昭著的数据窃取勒索软件组织之一，不过现在它宣布“正式关闭”。据了解，这一消息上周就发布了。

  

![](../Images/c8a16afd72e7ed807b01ba7b9ed1412a.png)

  

该网络犯罪团伙宣布，他们将不再泄露受其勒索软件感染的新公司的数据。

  

在过去一年中，该组织已针对大量目标公司发起了攻击，包括信息技术咨询及业务流程提供商 Cognizant、网络安全保险公司 Chubb、制药巨头 ExecuPharm、特斯拉和SpaceX的零件供应商 Visser 和国防承包商 Kimchuk。

  

![](../Images/a454b651fb8327521c827071795f28c3.png)

  

通常情况下，勒索软件会对硬盘数据进行加密，用户只有交付赎金之后才能解锁。而 Maze 的做法更加激进，它们会首先泄漏受害者的部分数据，并威胁他们如果不支付赎金就公开这些数据。它很快成为勒索软件组织的首选策略，勒索软件组织通常在黑暗的网络上建立网站，以在受害者拒绝付款时泄露其窃取的文件。

  

Maze最初使用漏洞攻击工具包和垃圾邮件活动来感染受害者，但后来开始使用已知的安全漏洞专门针对大型公司。Maze 随后使用易受攻击的虚拟专用网（VPN）和远程桌面（RDP）服务器对受害者的网络发动有针对性的攻击。

  

![](../Images/bd45d80a94d24aa68ed7554b5316d2fe.png)  

  

昨天，迷宫运营商在他们的网站上发布了一份新闻稿，标题为“该项目已关闭”，警告说任何其他勒索软件如果滥用其品牌，都将被视为骗局。

  

“我们从未有过合作伙伴或继任者。我们的专家不与任何其他软件一起工作。没有人，也永远不会在我们的新闻网站上招待新的合作伙伴。企业联盟从来就不存在。”
