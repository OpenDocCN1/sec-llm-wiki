# 东京奥运会赛事正酣，日本诈骗网站也扎堆出现

参考消息网萨马兰奇体育频道7月28日报道 共同社网站近日报道称，日本早稻田大学信息安全专业教授森达哉等专家，在26日表示，目前，**已出现1753个与东京奥运会和残奥会官方网站相类似的域名，其中148个可能被以盗取个人信息等为目的的恶意虚假网站所使用**。报道称，已发现有东京奥运门票购票者及志愿者的ID和密码[在网络上泄露](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247498464&idx=1&sn=6a6fbc80fce2f326d09387f277b3421b&chksm=ebfabdc0dc8d34d6aad3e77a758f3b65cf24000f5b4e27194ca4f1b6e9104e5183e635509f61&scene=21#wechat_redirect)。有观点认为，这些信息的泄露并不是源于针对东京奥组委的网络攻击，而是被虚假网站盗取。东京奥组委已呼吁日本民众提高警惕。

![](../Images/2409ad0bc6acdd913fe5fa3cd4582671.png)

据与森达哉共同研究这一课题的研究生河冈谅介绍，他们所进行的调查搜集了截至举办开幕式的23日，在网络上出现的含有“Tokyo”“2020”“Olympic”等多个可能被误认为官方网站的域名数。在搜集到的1753个域名中，可能有一大半是为了通过增加浏览人数而增加广告费所制作的网页，但**有148个域名很可能是浏览后会感染电脑病毒或被盗走个人信息的虚假网站**。在2019年5月进行的调查中，类似域名有956个，其中虚假网站有22个。今年以来，含有“ticket”等单词的类似域名明显增多。森达哉指出：“虚假网站大多因举报而在短时间内被删除，但新的虚假网站仍在持续增加。”据信息安全公司Cybereason透露，已确认有通过假装成倒卖门票和发布视频的网站来盗取个人信息的“钓鱼”网站。东京奥组委称：“**已经预想到恶意虚假网站的增加。希望大家仔细确认是否为官网**。”
