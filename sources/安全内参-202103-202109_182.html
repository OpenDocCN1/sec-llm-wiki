以色列起家的端点安全公司SentinelOne刚刚在纽交所成功上市


2020年全年融资金额29亿美元刚创下纪录，以色列网络安全行业在2021年的表现更为强劲，前六个月就筹得34亿美元，其中7家公司晋升独角兽；


6月30日，端点安全公司SentinelOne成功上市，以90亿美元估值募资12亿美元，这被认为是网络安全史上规模最大的IPO。


以色列国家网络局（INCD）表示，今年上半年，以色列网络安全公司总共融资50笔筹得34亿美元，其中7家成功跻身独角兽行列，即市值超过10亿美元的私营公司。
更重要的是，面对2020年刚刚创下纪录的全年29亿美元融资数额，以色列网安行业在2021年的表现更为强劲，前六个月即筹得34亿美元。数据还显示，上半年以色列企业的融资数额已经占据全球网安公司融资总量的41%。
从数据来看，全球超过三分之一网安独角兽企业来自以色列，在30-33家独角兽公司中占得13席。
2021年上半年，共有18家以色列网络安全公司被收购，总交易金额达22亿美元。
与此同时，诞生于以色列的端点安全厂商SentinelOne上周三成功上市，以90亿美元的初始估值，成功筹集到12亿美元，这被认为是网络安全史上估值规模最高的IPO。
以色列国家网络局经济与增长主任Roi Yarom表示，可观的投资数字“表明以色列在网络安全领域继续处于全球领先地位。”面对去年突然爆发并席卷全球的新冠疫情、特别是众多行业受到隔离政策的严重影响，网络安全行业反而逆势而起、蓬勃发展。众多企业及员工选择居家办公、全球业务快速转往线上，而黑客威胁的升温则让网络安全成为刚需中的刚需。
Yarom在电话采访中解释道，“我们观察到国内网安行业正在走向成熟，并在全球网络安全市场上占据更大份额。”他强调，网安行业可以说是以色列国家经济的增长引擎，同时也将提高以色列对于未来网络安全攻击的抵御能力。
数据显示，Cato Networks、Forter、Aqua Security、Cyberreason、Wiz、Axonius、BigID、Snyk、Orca Security、Riskified、Claroty、Transmit Security以及OwnBackup均为位于以色列或创立于以色列的独角兽网安企业。作为曾经的独角兽俱乐部成员，上文提到的SentinelOne公司决意迈出在纽约证券交易所上市的步伐。
但在Yarom看来，以色列网络安全行业也面临着一定挑战，首先就是人才严重短缺——这已经成为限制网安行业发展的“玻璃天花板”。“我们正努力培养新的人才，并增加女性从业者的数量。”
此外，更重要的是保证这些企业能够在发展过程中始终保持对于以色列本土的积极带动作用。“网安公司开始在纳斯达克发行股票，这当然值得庆祝。但我希望他们能继续把研发中心保留在以色列，我们也将认真维护好这种合作关系，保证以色列的经济发展能够持续受益于网安行业的迅猛增长。期待他们能够保持住以色列企业这一基本属性。”
SentinelOne公司在IPO中的巨大成功，证明了该公司拥有巨大的发展潜力以及投资者表现出的浓厚兴趣与坚定信心。
除SentinelOne公司之外，还有其他六家先后登陆美国股市的位于以色列或创立于以色列的网安厂商，其中包括市值约160亿美元的Check Point Software Technologies Ltd以及估值约52亿美元的CyberArk Software Ltd。
