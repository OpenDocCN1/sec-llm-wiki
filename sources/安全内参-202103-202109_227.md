# 北约计划于2026年正式出版《塔林手册3.0》

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247498026&idx=4&sn=d376c84964ba78c7d3259033db0f1518&chksm=ebfabe0adc8d371c1ebda476a5d5179eb43e166267c475c92e2ee7c483b53f67f211b9a33a9c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247498026&idx=4&sn=d376c84964ba78c7d3259033db0f1518&chksm=ebfabe0adc8d371c1ebda476a5d5179eb43e166267c475c92e2ee7c483b53f67f211b9a33a9c&scene=27#wechat_redirect)

  

**编者按**

  

北约正在资助开展《塔林手册3.0》撰写项目，并计划于2026年正式出版。《塔林手册3.0》是2017年推出的《塔林手册2.0》的更新版，旨在将近年来各国处理黑客行为方式的变化纳入其中。《塔林手册》的目标本质上是观察相关国家涉网络空间言行，并将似乎达成的共识整理成文。手册撰写人员希望设定更清晰的网络空间界限，并减少黑客竞赛升级和动荡的机会，尤其是在世界网络强国之间。

  

《塔林手册3.0》将继续由美国海军战争学院法学教授迈克尔·施密特担任主编，其他两位起草人为来自爱沙尼亚和英国的网络法专家莉丝·维胡尔和马尔科·米兰诺维奇。来自不同国家的20名网络专家组成的小组将对手册草稿进行审查和修订，并发送给数十个国家政府的律师咨询意见。施密特称，“如果我们不仅可以澄清哪些规则适用于网络空间，还可以澄清它们如何适用，那么我们就会拒止可能利用这种不确定性为自己谋利的对手。”

  

奇安网情局编译有关情况，供读者参考。

国际顶尖法律专家们正在开始一项为期五年的项目，以确定国际网络冲突的界限。其结果将是北约资助文件的第三版，即《适用于网络行动的国际法塔林手册》。该手册不具有法律约束力，但美国和其他地方的政府律师在争论哪些攻击性黑客行为在法律上是可以辩护的以及何时适合进行报复时越来越多地求诸该手册。

  

这将是2017年以来的第一次更新，作者们旨在将各国如何对待黑客行为的巨大变化纳入其中，这是由一系列重大攻击引起的，包括俄罗斯干预2016年美国大选以及威胁经济安全和公共安全的犯罪勒索软件攻击。

  

**作者们希望他们的工作可以设定更清晰的界限，并减少黑客竞赛升级和动荡的机会——尤其是在拥有最先进网络技能的国家之间，例如美国、俄罗斯和中国。**

  

《塔林手册》项目主管兼美国海军战争学院法学教授迈克尔·施密特表示，“我并不天真。我知道法律将被触犯......但至少有游戏规则会增加一些稳定性。”

  

![](../Images/4361e232d5e8aeed92d3e97e2d3b9e59.png)

  

**随着手册的发展，网络冲突变得越来越危险且造成的损失也日益严重。**但是，网络空间有一些道路规则和国家不应跨越的红线的想法已经获得了很多支持。**在施密特和他的同事于2009年开始编写第一卷手册前，网络空间被广泛认为是一个无法无天的“狂野西部”，在这里“力量即正义”。**到2017年第二卷出版时，专家们普遍同意，国际法存在于网络空间中，就像在陆地和海上一样——即使各国和专家在细节上争论不休。

  

随着作者们开始编写第三版（将于2026年出版），拜登政府正在推动制定更严格的黑客规则。在日内瓦与俄罗斯总统普京会面后，拜登总统呼吁达成一项广泛的协议，该协议将申明管道、机场和供水系统等关键基础设施应免遭网络攻击。他威胁说，如果俄罗斯不遵守协议，他将在网络空间和其他地方进行反击。拜登还威胁如果俄罗斯不控制在其领土上活动的犯罪黑客将产生后果，包括在Colonial Pipeline和肉类加工商JBS锁定计算机并用以勒索赎金的组织。

  

克里姆林宫在测试全球黑客规范方面有着悠久的历史。但它的黑客往往不会公然违反广泛制定的规则。施密特称，因此，如果美国及其盟国能够更准确地说明他们认为界限在哪里划定以及越过这些界限将产生什么后果，这可能会导致俄罗斯的黑客攻击不那么咄咄逼人。**《塔林手册》的目标本质上是观察这些国家的言行，并将似乎达成的共识整理成文。**

  

施密特称，“俄罗斯人发现了那个灰色地带，这就是他们运作的地方。因此，**如果我们不仅可以澄清哪些规则适用于网络空间，还可以澄清它们如何适用，那么我们就会拒止可能利用这种不确定性为自己谋利的对手。”**例如，没有证据表明俄罗斯黑客在2016年大选期间改变了选票，大多数国际法律专家认为这显然违反了国际法。相反，他们发起了社交媒体影响力行动，并发布了希拉里·克林顿竞选活动中令人尴尬的黑客信息——这在当时并没有明确违反任何既定的网络规则。施密特称，“我知道很多人说有些国家根本不遵守国际法。他们不在乎。我还没有见过那些国家。”

  

施密特正在与两名同事一起编写手册的初稿。他们是分别来自爱沙尼亚和英国的网络法专家莉丝·维胡尔（Liis Vihul）和马尔科·米兰诺维奇（Marko Milanovic）。然后，该手册将由来自不同国家的20名网络专家组成的小组进行审查和修订。该小组还将把该草案发送给数十个不同国家政府的律师，以便在他们定稿之前提出意见。

  

该手册以爱沙尼亚首都塔林命名，这也是北约合作网络防御卓越中心的所在地。塔林是2007年网络攻击的首批全国受害者之一。在攻击期间，普遍认为与俄罗斯政府有关联的黑客用大量的网络流量淹没了爱沙尼亚议会、银行、报纸和广播公司，以至这些机构无法运作。此次攻击由爱沙尼亚政府拆除了苏联时代的战争纪念碑所引发。自袭击事件发生以来，爱沙尼亚已成为网络防御和政策的领导者。
