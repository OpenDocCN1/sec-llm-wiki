# 第九届全球云计算大会·中国站成功举办 (附回看)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247497996&idx=4&sn=dd96c9aab6bc730c61c175edd9ec290b&chksm=ebfabe2cdc8d373ae2314e679b2a4460157938710b394e33e553907a681b9e2acfd13bd5eae8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247497996&idx=4&sn=dd96c9aab6bc730c61c175edd9ec290b&chksm=ebfabe2cdc8d373ae2314e679b2a4460157938710b394e33e553907a681b9e2acfd13bd5eae8&scene=27#wechat_redirect)

  

6月18日，由**宁波市人民政府**指导、全球最大展会机构**Informa Markets**主办，英富曼企业管理（上海）有限公司及宁波雅卓展览服务有限公司共同承办的**第九届全球云计算大会·中国站**(Cloud Connect China 2021)在宁波泛太平洋大酒店圆满落幕。

  

为期三天的大会，包括首日下午的“**第三届云联世界30位领导人闭门会议**”，以及后两日的**两大主论坛**、**四场分论坛**及**技术展示区域**，两日大会共计吸引**近700位参会者**、**逾1500人次**、**近40位演讲嘉宾**、**逾20家参展企业**，和**近30家媒体**共同参与。

  

![](../Images/28e90e7989a38aaa12aa9e47b6c76b96.png)

现场共吸引近700位参会者、逾1500人次、近40位演讲嘉宾、逾20家参展企业，和近30家媒体共同参与。

  

  

本届大会以“**新技术赋能双循环发展**”为主题，通过深入探讨**AIoT工业趋势应用**，**物流与制造业新技术融合**，聚焦分析数字化平台，助力企业转型；同时聚焦**云计算先进技术**，探讨未来技术路线发展与变革；新增设**云计算人才培养分论坛**，以求进一步探索适应行业需求与新技术演进的高端人才培育。今年大会共邀请到**国家发展改革委员会国际合作中心副主任刘建兴博士**，**德勤咨询首席云战略官、全球十大云计算影响力人物David Linthicum**等近40位海内外行业大咖和学术领袖，分别来自产业界领先的技术公司、知名院校及第三方中立机构，包括：德勤咨询、SAP、谷歌云、华为、F5 Networks、中通快递、中软国际、华胜天成、深信服科技、朝亚、九州云、紫光云、腾云互联等，出席两大主论坛、四场分论坛，带来精彩主题演讲！

  

![](../Images/8b41de2694d08188011d9527c77cfeea.png)![](../Images/8ae0f45315770a9bc99a855ff5579038.png)![](../Images/14f6e27738669fe0912dfc36a004ef71.png)![](../Images/168a438042358e5798b09a8d2d3f72a3.png)

分别为：国家发展改革委员会国际合作中心副主任刘建兴博士（左上）；德勤咨询首席云战略官、全球十大云计算影响力人物David Linthicum（左下）；SAP全球副总裁、大中华区办事处总经理Andreas Hube（右上）；印孚瑟斯技术（中国）有限公司助理副总裁、中国交付和运营负责人Rajnish Sharma（右下）

  

  

  

除了硬核海内外嘉宾及大会内容，17日下午亦公布大会每年核心活动“**云鼎奖**”（Top Cloud Connect Awards）的最终得奖名单。第八届“云鼎奖”共计收到**162家企业**投递的**309个奖项**。最终共颁出**7大奖项逾40个荣誉奖杯**，表彰2020-2021年度对中国云计算产业做出突出贡献和具有创新精神的集体、个人和产品。
