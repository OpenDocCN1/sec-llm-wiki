# 支付赎金后，80%的企业遭受第二次勒索软件攻击

Cybereason周三发布的一项调查显示，选择支付勒索软件赎金的企业中，**80%会再次遭遇勒索软件攻击，其中46%的攻击来自相同的攻击者。**而支付赎金以重新访问其系统的企业中，46%表示他们的数据部分或全部已损坏。该研究由Censuswide进行，对全球七个市场的1,263名安全专业人士进行了调查，其中包括新加坡、德国、法国、美国和英国的受访者。  

  

在全球范围内，51%的受访者表示在支付赎金后完整解密了数据，3%的受访者表示他们没有重新获得对任何加密数据的访问权限。该报告的一个案例显示，一个特定组织支付了数百万美元的勒索软件金额，却在两周内成为同一攻击者第二次攻击的目标。

  

在新加坡，90%的受访者在支付了第一次赎金后经历了第二次勒索软件攻击，只有28%的人重新获得了对损坏数据的访问权限。约73%的人承认他们因攻击而损失了收入，而全球平均水平为66%，40%的人认为他们的品牌或声誉受到不利影响，而全球这一比例为53%。

  

支付勒索软件的新加坡组织中，约有37%支付了14万美元至140万美元，5%支付了超过140万美元的赎金。另有13%的受访者承认由于袭击后的经济损失而不得不裁员，而20%的受访者被迫关闭。

  

在全球范围内，调查发现81%的受访者高度关注勒索软件攻击带来的风险，73%的受访者表示他们已制定政策或计划专门管理勒索软件攻击。

  

根据Cybersecurity Ventures的数据，到2031年，勒索软件攻击预计在全球范围内造成2650亿美元的损失，每隔几秒钟就会有一次攻击影响企业和消费者。今年，此类攻击的成本估计为200亿美元，是2015年的57倍。

  

Check Point Research周三还透露，过去两个月，全球勒索软件攻击的平均数量增加了20%，过去六个月增加了41%，过去一年增加了93%。

  

安全供应商表示，在新加坡，此类攻击在过去几个月中增长了40%，在过去半年中增长了99%，在过去一年中增长了147%。他补充说，拉丁美洲和欧洲的勒索软件攻击峰值是自2021年初以来的最高峰值，分别为62%和59%。

  

Veritas去年11月的一项调查显示，在成为此类攻击的受害者后，78%的新加坡企业和88%的澳大利亚企业已全部或部分支付赎金。此外，新加坡有45%的人需要5到10天的时间才能从勒索软件攻击中完全恢复，而印度为11%，中国为35%。
