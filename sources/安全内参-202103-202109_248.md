# 美国银行CEO：我们每年的网络安全支出超过10亿美元

**在过去的一年里，一系列超大型网络攻击袭击了美国政府和私营公司的网络，这导致政府和公司都在重新评估和更新他们的网络防御系统。**

  
美国银行（Bank of America）首席执行官布莱恩·莫伊尼汉（Brian Moynihan）周一表示，该公司已**将其网络安全支出提高到每年10亿美元以上**。莫伊尼汉在CNBC的 "Squawk Box "节目中说："我在11年前成为首席执行官，**\[每年\]大概花了3到4亿美元，现在已经超过了10亿美元。**"他补充说：“我们周围的机构，其他机构和同行，花费的金额相当，我们的合作方也花了同等的金额。”“换句话说，我们让提供服务的第三方以同样的方式保护我们，因此，有很多钱被花在这上面，我认为我们行业做得很好的一件事就是共同合作。”在过去的一年里，一系列超大型网络攻击袭击了美国联邦政府和私营公司的网络。最近的两起事件发生在Colonial Pipeline（美国最大的燃料管道运营商）和JBS（世界最大的肉类包装公司）身上。这导致企业和政府重新评估和更新他们的网络安全防御系统，因为这些攻击已经成为经济损失的来源。上个月，拜登总统签署了一项行政命令，旨在加强美国的网络安全防御。据NBC新闻报道，拜登政府正在采取行动，将勒索软件攻击视为国家安全威胁。然而，私营部门也有责任做好自己的工作。国家安全副顾问安妮·纽伯格在本月早些时候的一封公开信中呼吁企业领导人加强他们的技术防御。纽伯格写道：“私营部门也有保护自己免受这些威胁的重要责任。”在这次范围广泛的采访中，莫伊尼汉还说，随着经济的持续开放，消费者的消费更加自由。他还说，美国有6万名员工已经通知银行他们的Covid-19疫苗接种情况，并开始返回办公室。
