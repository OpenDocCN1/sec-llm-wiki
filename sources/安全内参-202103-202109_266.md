# 美国联邦调查局利用虚假加密手机实施全球“钓鱼执法”行动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247497828&idx=2&sn=1352bd59bb194d9e9940d42592f616a9&chksm=ebfabf44dc8d365224281fc97706226508d3e60ddfc45be37bcb274b2b213ff84f206a48a05a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247497828&idx=2&sn=1352bd59bb194d9e9940d42592f616a9&chksm=ebfabf44dc8d365224281fc97706226508d3e60ddfc45be37bcb274b2b213ff84f206a48a05a&scene=27#wechat_redirect)

使用ANØN加密手机的全球犯罪分子以为自己使用的是可助其躲避各国执法部门抓捕的最新加密通信手段，而实际上他们早已落入了美国联邦调查局精心布置的陷阱当中——无论是组织毒品贩运和洗钱，还是策划买凶杀人，犯罪分子通过ANØN加密手机向其同伙发出的每一条信息，都成为联邦调查局及其国际执法合作伙伴立即掌握的证据。

  

这个代号为“特洛伊盾牌（TROJAN SHIELD）”的联合执法行动于2018年启动，共有十八个国家超过九千名执法人员参与。该行动有两个主要目标：一是利用ANØN加密手机所收集的犯罪证据，彻底摧毁跨国犯罪组织；二是在全球犯罪地下社群中散布“加密手机等秘密通信手段不可靠”的印象。

  

联邦调查局及其国际执法合作伙伴实施“特洛伊盾牌”行动的灵感，源于加拿大加密手机提供商Phantom Secure案——该公司将黑莓手机改造为极为安全的加密消息工具，以至于美国及其西方盟友的执法部门无法监听破解由其发送的信息。由于该公司首席执行官文森特.拉姆斯（Vincent Ramos）拒绝接受美国和加拿大执法部门在其产品中植入后门的要求，自行制作一个用于诱捕全球犯罪分子的“加密手机网络”，也便开始成为联邦调查局及其国际执法合作伙伴解决“无法监听破解犯罪分子手机通信”这个问题的首要选项。

  

最终联邦调查局牵头成立了一个名为ANØN的“加密手机提供商”，作为其伪装——并在ANØN网站上宣称其提供的加密手机使用强大的点对点加密技术，“能够完全规避各国执法部门的监听”，并以“仅有经现有用户推荐介绍的新用户方可购买使用”作为卖点。实施过程中的官方流程、保障和技术障碍，则主要由联邦调查局和澳大利亚联邦警方在反复沟通中解决。之后，联邦调查局和澳大利亚、新西兰的卧底探员们不断向国际犯罪地下社群兜售ANØN加密手机。最终在两年的时间里，联邦调查局及其国际执法合作伙伴成功地将ANØN加密手机推销给了全球近万名犯罪分子，而澳大利亚“用户”最多，超过1500名。

  

联邦调查局及其国际执法合作伙伴的收网行动，已于本周二首先在新西兰、澳大利亚和欧洲启动，目前已有数百名嫌疑人被逮捕。仅在澳大利亚，执法部门就已抓捕224名嫌疑人，阻止21次谋杀企图，摧毁六个非法实验室，并缴获超过4500万美元的现金。澳大利亚联邦警察局长瑞斯.科尔肖（Reece Kershaw）指出，“特洛伊盾牌”行动以及全球犯罪分子对ANØN加密手机的盲目信任，为执法部门提供了一个看到“前所未有的犯罪规模”的宝贵机会。

  

美国司法部、联邦调查局等方面暂未披露其抓捕情况，相关细节预计将于美国时间周二在圣迭戈的一场发布会上公布。
