# 数据安全要火？2021年RSAC创新沙盒大赛10强名单出炉

受全球疫情的影响，全球网络安全顶级大会RSA Conference 2021不出所料的改为了线上大会，于2021年5月17日—20日召开。

  

今日（4月15日）官网上发布了备受瞩目的Innovation Sandbox（沙盒）大赛的Finallist。创新沙盒这个说法有一些拗口难懂，本质上其实就是**全球网络安全领域的创业大赛**。作为全球网络安全行业创新风向标，从业者将其视为“安全圈的奥斯卡”，因此每年的创新沙盒大赛都备受瞩目。  

  

在[前几年RSAC的创新沙盒入围分析中](http://mp.weixin.qq.com/s?__biz=MzkzMDE5MDI5Mg==&mid=2247488844&idx=1&sn=38e2ea1b062f9b4bece759d63db0da0f&chksm=c27f53f7f508dae1be77720ea7a376721d5b0596bfe5c45931950df506f97f32b9cfd6d065e8&scene=21#wechat_redirect)我们说过，**创新沙盒比的不是技术，而是商业。**在这个比赛中，进入决赛名单的10家企业技术方向有显著差异，不同领域的企业在一起竞争是很难从技术角度进行比较的，更多的是商业逻辑的比较。

  

那么今年入选沙盒决赛的十家企业都是谁呢？我们为大家详细总结出了这10家企业的基本信息与产品亮点。
