# 红十字国际委员会遭遇高级网络攻击

红十字国际委员会（ICRC）本周四宣布遭遇高级网络攻击，泄露了超过50万人的个人和机密数据，这些数据来自全球至少60个红十字会和红新月会组织。

  

红十字国际委员会表示，暴露的信息属于高度脆弱的群体，包括因冲突而离散的家庭。  

  

“对失踪人员数据的攻击使家庭的痛苦更加难以忍受。”红十字国际委员会总干事罗伯特马尔迪尼说：“我们都对这些人道信息成为攻击目标并泄露感到震惊和困惑。这种网络攻击使弱势群体，那些需要人道主义服务的人，面临更大的风险。”

  

国际人权组织和非营利组织是网络攻击者的热门目标。联合国在去年9月证实，其基础设施曾在2021年初遭到攻击者入侵。红十字会一直强烈呼吁停止针对医疗机构的网络攻击。

  

Mardini敦促攻击者“做正确的事”，“不要分享、出售、泄露或以其他方式使用这些数据”。目前没有迹象表明数据已在线共享。

  

由于这次攻击，红十字国际委员会暂时关闭了其“重建家庭联系”项目，该项目旨在帮助因冲突、灾难或移民而离散的家庭团聚。据新闻稿称，该项目每天可平均帮助12个失踪人口与家人团聚，红十字会正在“尽快确定解决方法以继续开展这项重要工作”。

  

据悉，红十字会的数据是从一家瑞士科技公司泄露的，该公司与红十字国际委员会签订了数据存储合同，目前还没有发现任何嫌疑人。
