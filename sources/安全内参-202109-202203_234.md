# Grafana任意文件读取0day漏洞安全风险通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247500512&idx=2&sn=a9f7e1b16c0f60bfe14adb47ac43b482&chksm=ebfa85c0dc8d0cd602e4708e7aad785f4f140db62e15bb6ac5ce1bec3bb574ed6c6c8c634eb7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247500512&idx=2&sn=a9f7e1b16c0f60bfe14adb47ac43b482&chksm=ebfa85c0dc8d0cd602e4708e7aad785f4f140db62e15bb6ac5ce1bec3bb574ed6c6c8c634eb7&scene=27#wechat_redirect)

  
  

**风险通告**

  
  

近日，奇安信CERT监测到 Grafana 未授权任意文件读取 0day 漏洞信息在互联网上公开。经验证，未经身份验证的远程攻击者可利用此漏洞读取服务器上的任意文件。鉴于此漏洞目前处于0day状态，建议客户尽快采取措施防护此漏洞。

漏洞描述

Grafana是一个跨平台、开源的数据可视化网络应用程序平台。用户配置连接的数据源之后，Grafana可以在网络浏览器里显示数据图表和警告。该软件的企业版本提供更多的扩展功能，扩展功能通过插件的形式提供，终端用户可以自定义自己的数据面板界面以及数据请求方式。  

 

近日，奇安信CERT监测到 Grafana 未授权任意文件读取 0day 漏洞信息在互联网上公开。经验证，未经身份验证的远程攻击者可利用此漏洞读取服务器上的任意文件。

风险等级

奇安信 CERT风险评级为：高危风险等级：蓝色（一般事件）  
  

影响范围

处置建议

此漏洞目前处于0day状态，客户可采用奇安信产品解决方案来防护此漏洞；或关注厂商官网等待Grafana安全版本发布：https://grafana.com/
