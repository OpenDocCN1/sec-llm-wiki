# 特斯拉全球宕机：500名车主被锁门外5小时，马斯克发推道歉

近日，500名特斯拉车主在网上抱怨，他们在APP上收到错误提示「故障代码500」，因此无法打开车门或启动汽车。

  

特斯拉「断网」，数百车主被锁车外？？？

 

关建是关在门外长达5个小时...

 

外媒称，近日，数十名特斯拉车主在网上抱怨，他们在APP上收到错误提示「故障代码500」，因此无法打开车门或启动汽车。

 

![](../Images/b26c9a4b4e50275fad87337979a2aa83.png)

 

据称，来自美国、加拿大的车主率先报告这一问题，欧洲和亚洲的车主也发现了类似状况。

 

![](../Images/a3b0be8bbf5a467a5b85b49ce861ad85.png)

 

美国印第安纳州的特斯拉车主扎卡里·基弗（Zachary Kiefer）表示，特斯拉应用服务中断时，他开车离家约一小时。

 

他大约一个月前丢了车钥匙，还把手机换成了新手机，所以此次服务中断让他被困在车外好几个小时，只能打电话叫拖车。幸运的是，在拖车到达之前，特斯拉APP又开始工作了。

 

![](../Images/370ebcffaacec4a212ab37e56bb35246.png)

 

基弗说，特斯拉的客户服务似乎没有特别大的帮助，「我很失望，他们似乎一点也不在乎」。

 

据网络状况监控网站DownDetector的数据显示，在美东时间19日16时40分左右，约500名用户报告该问题，而到当日21时20分左右，仍有60份问题报告。

 

![](../Images/500335540900b80ab9060610a37f9277.png)

 

# 

服务器down，马斯克道歉

  

11月20号，有用户在马斯克的推特下留言说，他们在韩国首尔通过iOS应用程序连接特斯拉Model 3时遇到了表示「服务器错误的500代码」，并认为这可能会造成全球范围的故障。

 

很快，特斯拉首席执行官埃隆·马斯克告诉这位来自韩国的车主，他正在检查这个问题。

 

![](../Images/47b145023867bc766e28d02b8d5a4b13.png)

 

马斯克随后表示，他们意外增加了网络流量冗余。

 

他向用户道歉，并保证将采取措施确保此类事件不再发生。

 

![](../Images/6c28b95536e7563bde748078a8d349a6.png)

 

特斯拉手机APP允许车主使用手机作为钥匙来解锁和启动特斯拉的车辆。

 

据了解，很多车主习惯用手机上的特斯拉APP打开车门，启动发动机。不过特斯拉也给每位车主配备了实体NFC钥匙卡，提前做好相关设置后，手机APP也可以在没有网络服务的情况下启动汽车。

 

![](../Images/b7055a0bd26d1d0ae738b5c94fe8a07a.png)

 

不过，很多车主出门都没有带钥匙卡的习惯，经常用手机APP解锁。

 

然而，一旦APP或车联网出现故障，锁车外的事故非常有可能发生，这次全球数百名特斯拉车主遭遇的就是这一尴尬场景。

 

特斯拉的APP近年来宕机次数不算少。

 

2020年5月份，国内大量车主反映特斯拉APP大规模宕机，导致手机无法与车联动，手机钥匙失灵，导致无法获取车辆信息，车内仪表盘、中控屏无法点亮。很多车主都处于「盲目驾驶」状态。

 

此外，2020年9月的时候，特斯拉面向客户的服务器和内部系统也经历过数小时的宕机。

 

针对特斯拉「断网」导致多名车主被锁在车外一事，360集团董事长周鸿祎在微博上发帖称，此次，车主打不开车门的影响可能不大，但如果遭黑客组织网络攻击，就可能威胁行车安全、人身安全。据统计，2020年，将近1/3的汽车网络攻击事件是通过云端服务器发起的。

  

网友：自由是相对的

  

一位网友客观评论道，大家平时用的最多的，是配对好以后通过手机蓝牙开锁。这种方式是没有问题的。而备用方式，是特斯拉标配的智能卡，这种方式也是没有问题的。

 

出问题的，是通过特斯拉手机App开锁。手机App和车之间没有直接的联系，必须通过服务器中转。只有用户手机蓝牙没有和汽车绑定过，又忘记携带智能卡的情况下，才会出现问题。

 

![](../Images/8c63060901bd8fa084f12cbd50d9f8a6.png)

 

![](../Images/597f20a6bac72d7e63a7d2b96cc929fe.png)

 

国内一位网友表示自己也遇到了这样的问题，「怪不得昨天打不开门了，我还以为是我手机蓝牙没连上。不过手机套里就是卡片钥匙，没啥影响。」

 

![](../Images/130946d703656a45c3787d65ef79be20.png)

 

还有网友调侃道，「用网络限制了你的自由，不是安全而是后门，自由是相对的。」

 

![](../Images/a8aa3134e9ca75f20fc69c4573eb58f6.png)
