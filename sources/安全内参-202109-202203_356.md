# 真相扑朔迷离：伊朗加油站网络攻击事件元凶追踪

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247499975&idx=3&sn=1610642bf668c246b9c8e1b7d9850a7f&chksm=ebfa87e7dc8d0ef192566b2250c48468a82de6c8741d29a7c5b1b2844e48f9d7ad64b283892e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247499975&idx=3&sn=1610642bf668c246b9c8e1b7d9850a7f&chksm=ebfa87e7dc8d0ef192566b2250c48468a82de6c8741d29a7c5b1b2844e48f9d7ad64b283892e&scene=27#wechat_redirect)

**据以色列时报当地时间10月27日12点50分（北京时间17:50）的更新报道,一名伊朗官员将26日导致全国加油站瘫痪的网络攻击归咎于外国，因为当局表示该问题正在得到解决，石油供应正在全国范围内恢复。当地时间27日早上，80%的加油站恢复供应油品。伊朗总统也表态称事件是某个外国所为，但拒绝透露这个国家的名字。这仅仅是可能性之一。另有媒体报道称，有未具备的组织在Telegram上声称对攻击负责，但缺乏任何证据。最后一种可能是反伊朗当局的组织所为。**  

![](../Images/21c0baf8189d4d9422520a9b35d7e506.png)

（**2021年10月26日，在伊朗首都德黑兰，汽车和摩托车在加油站排队加油，全国范围内的汽油分销系统遭到破坏。(Atta KENARE /法新社)）**这次攻击损坏了伊朗人免费或以补贴价格使用当局发行的数字卡加满油箱的IT系统，导致加油排长队和人们的沮丧，因为驾驶者在没有燃料的情况下陷入更加困难的境地。  
  
一名伊朗高级官员27日表示，网络攻击影响了伊朗伊斯兰共和国的所有4,300 个加油站。但据国营的伊朗伊斯兰共和国通讯社报道，到27日早上，伊朗80%的加油站已重新开始销售燃料，这位官员说。  

**伊朗国家石油产品分销公司发言人法特梅·卡希**27日告诉官方的 IRNA通讯社，在连接到该系统的 4,300个伊朗加油站中，只有 220 个已重新连接。

  

然而，她补充说，“近3,000 个加油站可以离线分配燃料，但以公开价格”——消费者在用完每月补贴燃料后必须支付的费用。

  

**综合各方媒体的报道，此次网络攻击造成加油站大规模关闭的重大影响事件，真正的幕后元凶到底是谁？大概有三种可能！**  

  
可能性之一：未具备的攻击组织所为？  
周二晚些时候，一个此前从未听说过的组织在消息应用Telegram上发布消息，声称对此次网络攻击负责。它没有提供任何证据证明它实施了袭击。  
可能性之二：某个外国政府所为？  
伊朗总统易卜拉欣·赖西27日表示，网络攻击旨在“通过制造混乱和破坏来激怒人们”。赖西拒绝指责谁对事件负责，但补充说：**“网络战领域应该认真做好准备，相关机构不应该让敌人追随他们的关键目标，给人们的生活趋势制造麻烦。”**国家电视台随后播放了总统访问德黑兰中部一个加油站的画面。  

![](../Images/0cc066436adaf89e09551ffdaa7610cc.png)

  
**伊朗最高网络空间委员会的高级官员Abolhassan Firoozabadi告诉国家广播公司IRIB，这次袭击显然是由外国实施的，尽管现在说出嫌疑人的名字还为时过早。在IRNA的评论中，他还将这次袭击与7月份针对伊朗铁路系统的另一起袭击联系起来。**  
Firouzabadi 说：“与之前针对铁路系统的袭击一样，这次袭击有可能是从国外进行的。”（编者注：*这种表述很难不让人不把它与以色列联系越来。*）  
伊朗国家电视台称，**伊朗最高国家安全委员**会早些时候证实，燃料供应中断是由网络攻击造成的。“正在调查攻击的细节及其来源，”国家电视台补充说，但没有提供更多细节。  

![](../Images/1d514dd93d572fca6d4a61a7aab03d61.png)

**（2021年10月26日，星期二，在伊朗德黑兰的一个加油站，一名工人靠在已经关闭的加油泵上。(美联社照片)）**  
据伊朗塔斯尼姆新闻媒体报道，**伊朗议会能源委员会主席**Fereidoon Hassanvand 表示，加油站遭到“有针对性的”袭击。  
  
该国**石油部长Javad Owji**告诉IRIB，当局预计所有加油站将在27日下午重新上线。他补充说，专家们正在努力强化加油卡的安全性。  
可能性之三：反伊朗组织所为？  
**前电信部副部长阿米尔·纳兹米(Amir Nazemy)早些时候在Twitter上写道，“加油站系统的基础设施是一个独立网络，这种通信方式不在互联网上。”这引发了一个问题，即是否有伊朗境内能够进入该系统的人发起了网络攻击，或者以其他方式促成了网络攻击。**  
这次网络攻击与几个月前的另一次攻击有相似之处，该攻击似乎直接挑战了伊朗最高领袖阿亚图拉·阿里·哈梅内伊，因为该国经济在美国制裁下陷入困境。由于美国和伊朗尚未共同重新加入德黑兰与世界大国的破烂核协议，这些经济问题正在恶化。  

26日，在加油站关闭事件发生后，保守的法尔斯通讯社将事故与反对者联系起来，这是在汽油价格上涨引发的致命抗议两周年之前。法尔斯报道说，在 2019 年11 月15日周年纪念日之前，“反革命媒体开展的一场运动”“加强了网络攻击的可能性”。

  

也有神权政治人士认为，反伊朗力量发动了一场袭击，可能是为了在全国范围内针对汽油价格的抗议活动遭到致命镇压两周年之际煽动伊朗。

  

两年前的那个日子，燃油价格突然上涨的消息引发了全国数十个地方的抗议活动。这是伊朗十年来最强烈的公众异议爆发。

  

2019年，伊朗约100个城镇因汽油价格上涨举行了数天的大规模抗议活动。安全部队逮捕了数千人，国际特赦组织认为有304人在政府的镇压中被杀。周二的网络攻击与2019年汽油抗议活动发生在波斯日历上的同一个月。
