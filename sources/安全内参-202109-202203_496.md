# 大量论文在百度文库售卖，原作者姓名学号全泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247499201&idx=3&sn=fa3cb92a515c1089922d5017abf44bde&chksm=ebfabae1dc8d33f7735af081d3ee7b3ebca591c382525d2fc6e30f8019e94f8107bdf24a8ca2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247499201&idx=3&sn=fa3cb92a515c1089922d5017abf44bde&chksm=ebfabae1dc8d33f7735af081d3ee7b3ebca591c382525d2fc6e30f8019e94f8107bdf24a8ca2&scene=27#wechat_redirect)

通过百度文库搜索并下载各种资料，已成为很多人获取知识的便利途径。2020年3月，百度文库上线了**“知识店铺”**功能，用户开通后可以**出售自己的原创文档，视频、音频、图书等形式的虚拟知识类产品**，变现盈利。

  

然而，在百度文库所谓“知识变现”的美好口号背后，却**暗藏着严重的版权问题**。记者连日来调查发现，百度文库知识店铺上传的付费内容里，**有大量未经版权认证，甚至明显侵权的内容**。更有甚者，有高校学生的论文被挂在知识店铺里明码出售，而**自己却毫不知情**。

  

百度文库从2009年创立起，就深陷在版权纠纷的漩涡中。然而直到今天，这个“全球最大中文文档分享平台”依然在“互联网避风港”下掩饰自身的版权漏洞，从侵权内容中获利的同时，在服务协议中将自身责任撇清一边。

  

![](../Images/3943f05913dbc8fb8ffad8450572b76d.png)

百度文库知识店铺。

  

//

**毕业论文被批发出售**

**姓名、学号全被泄露**

//

  

“我们学院200多篇论文，全部被泄露了。”

  

卢小姐已经从广东科技学院毕业一年，据她讲述，她是在去年6月完成了毕业论文，去年1月左右完成的论文答辩。

  

最近，在一次与其他学院同学的聊天中，她偶然得知了百度文库上一家名为“学姐帮帮忙”的知识店铺。令她惊讶的是，**自己班上同学的论文材料和答辩ppt居然被放在店铺里公开售卖，价格从两元到十几元不等，对于论文被上传同学们均表示“不知情”。**

  

![](../Images/84002e0ad98a49a5b0d297662e2a7414.png)

百度文库中名为“学姐帮帮忙”的知识店铺。

  

据卢小姐统计，一共有电子商务、市场营销、工商管理三个专业的学生论文被泄露，**总数200多篇**。其中电子商务专业的论文上传于今年5月14日，市场营销专业和工商管理专业的论文上传于今年的6月19日。

  

对于论文泄露的原因，卢小姐和同学猜测可能是在查重阶段发生的。令同学们感到愤怒的是，**在网店销售的论文还有着广东科技学院学生的班级学号和个人真实姓名等信息，均未做模糊处理。**

  

卢小姐向客服举报了该店铺涉嫌侵权，却发现要求提供原作者的相关身份信息，由于该店铺并未有售卖卢小姐的论文，因而投诉无法受理。不过在投诉后不久，卢小姐发现“学姐帮帮忙”已经无法搜索到。过了几天后，该店铺又重新上线，但涉嫌侵权的论文已全部下架。

  

![](../Images/c1ac5f55a4dd2bf05f099f92796bbf98.png)

百度文库中名为“学姐帮帮忙”的知识店铺。

  

但是记者仍能在该店铺里找到大量版权不清晰的内容，比如在一个售价为46元的《新媒体文案写作》教案里，明确写着“2018级新媒体运营创新班”等带有明显所属意味的字眼，而记者并没有在该商品上找到相关版权声明或标识。记者向客服举报该内容涉嫌侵犯版权，系统显示需要版权所有者提供相关证明才能受理。

  

而记者在百度文库上搜索“教案”“课件”等关键词时发现，很多知识店铺出售的文档、ppt里都清楚写有某学校教师的姓名或某学生的班级、学号，**但却无从证明这些店铺是否拥有这些内容的版权。**

  

![](../Images/6bfae536ba17eca867a722816503c8a0.png)

百度文库中名为“学姐帮帮忙”的知识店铺。

  

//

**平台抽成50%**

**侵权后果却让用户担全责**

//

  

记者查询发现，涉事的店铺属于百度文库的**“墨斗鱼平台”**管理。据官网介绍，其是由百度推出的，面对全体知识内容创作者、知识服务提供者的交易平台， 旨在通过墨斗鱼平台，快速形成个人品牌闭环，使知识供需双方高效对接，完成用户沉淀，实现知识变现。

  

注册一个知识店铺需要哪些步骤？根据官网的指引，记者尝试用百度账号开通知识店铺，只需要提供个人实名信息，以及店铺名称、logo等信息，系统就显示将在三个工作日内回复是否通过注册。

  

低廉的注册门槛，却难以掩盖内容创作者与平台方之间地位的不对等。一名百度文库用户称，**开通知识店铺需要强制开通并绑定百家号，**而没有开通知识店铺的用户，甚至无法在后台查看自己以前上传在文库里的内容。

  

此外根据服务协议，百度墨斗鱼平台对用户收益抽成比例高达50%，剩下的收益还需扣除所得税。而用户提现打款的流程也极为漫长，每月的5日至24日申请提现，却要到下个月的最后一周才能收到款项。**如果用户的账户余额不足100元的话，则无法提现，被平台白白占有收益。**

  

![](../Images/b9f120c30fb27e16aa9a1d5e30d97b11.png)知识店铺服务协议中关于用户收益的条款。

  

尽管百度文库通过用户上传付费内容，赚取了大量收益。然而对于用户上传的内容可能涉嫌侵权的情形，平台却在条款中将自身责任摘得很干净。记者在百度文库上搜索到的《百度文库知识店铺服务协议》（下面简称《协议》）中，**明确表示用户需要保证上传的内容没有侵犯任何第三方的合法权益，如百度被第三方主张权利而产生任何纠纷、仲裁、诉讼，或遭到国家相关部门处理，将由用户出面解决，承担全部法律责任并使百度免责。**此外，《协议》还写明如果用户无法提供数字作品权属证明，百度将收回在平台售卖数字作品的收益。

  

这份《协议》也被挂在百度文库上有偿分享，用户需要充值VIP才能下载该文档。

  

![](../Images/d64d6c64beded692470b9d269d87c286.png)知识店铺服务协议中关于第三方侵权的条款。

  

//

**侵权的避风港？**

**争议中赚钱的百度文库**

//

  

2009年，作为百度文库前身的百度知道“文档分享平台”正式上线。从问世开始，百度文库就陷入了各种版权纠纷中。

  

由于百度文库收录了大量未经作者授权的文学作品，2011年3月15日，**贾平凹、韩寒等50位作家公开发布《中国作家声讨百度书》，指责百度文库“偷走了我们的作品，偷走了我们的权利，偷走了我们的财物”。**对此，百度曾经回应称将删除文库内未获授权的作品，并对遭侵权的作家表示歉意。

  

![](../Images/0b6a825345d9d2384bd24036607b9c20.png)部分网友对知识店铺的评论。

  

记者查询到，除了作家韩寒曾以侵犯著作权起诉百度文库外，2013年，中国青年出版社中青文传媒公司指控百度在未经授权许可的情况下，通过“百度文库”网站在线提供其旗下三本书籍的电子版本，为此向百度索赔损失1818.65万余元。

  

即使是深陷版权纠纷，也没有阻止百度文库十多年来朝着付费化模式一路狂奔。从早期宣传的“内容免费下载”，到推出VIP会员才可下载的“付费文档”，到如今推出知识店铺引导用户上传付费内容并从中抽成盈利。如今百度文库的首页界面上，已经很少能见到完全免费的内容。

  

尽管近年来侵犯作家、出版社著作权的诉讼纠纷已较少发生，**百度文库中的很多内容仍游走在侵权的边缘。**在百度文库自己发布的《2020年侵权大数据》中，也承认模板范文以及计划、汇报、解决方案等内容依旧是侵权的多发区域。尽管百度文库为受侵权人提供了版权认证和侵权申诉途径，但却始终声称从中盈利的平台方“没有责任”，也没有有效手段阻止用户上传侵权内容。

  

而为百度文库在版权纠纷中提供“护身符”的，正是所谓的“互联网避风港原则”：在2006年7月1日正式实施的 《信息网络传播权保护条例》其中有规定，网络存储及搜索提供商在接到权利人申请通知后，断开侵权的相关链接，即可不承担赔偿责任。

  

曾代理过互联网平台侵权案诉讼的上海中联（广州）律师事务所高级合伙人严翔律师认为，“互联网避风港”原则如今已经被一些互联网平台滥用了，“如果平台没有尽到相应的平台义务，而且从平台用户的侵权行为中获利，那么就应该承担相应的责任。”此外，根据民法典中的“红旗原则”：如果侵犯信息网络传播权的事实是显而易见的，网络服务商就不能视而不见，或以不知道侵权的理由来推脱责任。
