# Cobalt Strike远程代码执行漏洞安全风险通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247506096&idx=3&sn=1812de6520cd5991b0883c7d1b78c479&chksm=ebfa9f90dc8d1686e888c2786849fb8f133cc861ad4f84a8c41898c10dea2cc008cdb7df2730&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247506096&idx=3&sn=1812de6520cd5991b0883c7d1b78c479&chksm=ebfa9f90dc8d1686e888c2786849fb8f133cc861ad4f84a8c41898c10dea2cc008cdb7df2730&scene=27#wechat_redirect)

近日，奇安信CERT监测到 Cobalt Strike 远程代码执行漏洞 ，当攻击者可访问 Beacon 的监听器时，可以在连接Beacon的listener时使用错误的用户名，触发XSS，造成远程代码执行。**鉴于这些漏洞影响范围极大，建议客户尽快做好自查及防护。**
