# 净网行动：乌克兰国家安全局查处2个“机器人农场”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247505840&idx=2&sn=3a06e213c3a3922fd0ebaca298bc8ba3&chksm=ebfa9090dc8d1986d9b889b936901d61358e1dd357ebb197558306fdf47bc251001a020e9cbf&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247505840&idx=2&sn=3a06e213c3a3922fd0ebaca298bc8ba3&chksm=ebfa9090dc8d1986d9b889b936901d61358e1dd357ebb197558306fdf47bc251001a020e9cbf&scene=27#wechat_redirect)

**编者按**

  

乌克兰国家安全局（SSU）9月3日发布消息称，SSU的网络部门已经关闭了在基辅地区和敖德萨运营的2个“机器人农场”。上述“机器人农场”控制了近7000个账户的“机器人军队”，并在网络上传播破坏性内容，旨在：诋毁乌克兰国防军和国家领导；为俄罗斯的军事行动辩护；破坏乌克兰的社会和政治局势。

  

据悉，5个本地人员创建和管理了上述2个“机器人农场”，利用计算机、服务器、调制解调器、手机、SIM卡以及特殊软件等创建虚假机器人账户，并通过出租或出售机器人账户来获利，其客户来自俄罗斯。相关机器人农场在乌克兰信息空间宣传了破坏性和挑衅性材料，包括声称来自前线的虚假信息和假新闻。

  

奇安网情局编译有关情况，供读者参考。

  

  

![](../Images/2ff8f5c143a8d7a7de5f2aba0284d812.png)

  

乌克兰国家安全局（SSU）网络部门已经关闭了另外2个在基辅地区和敖德萨的“机器人农场”。近7000个账户的“机器人军队”被用来传播破坏性内容，旨在：

  

● 诋毁乌克兰国防军和国家领导；

  

● 为俄罗斯的武装行动辩护；

  

● 破坏乌克兰的社会和政治局势。

  

**在基辅地区：**

  

根据调查，目前居住在基辅地区的1名24岁的扎波罗热地区本地人员创建并管理了一个拥有5000个账户的“机器人农场”。

  

为保密起见，他通过俄罗斯电子邮件服务和俄罗斯和白俄罗斯移动运营商的虚拟号码注册了虚假账户。在某些情况下，他使用伪造的乌克兰公民文件进行验证。

  

该组织者将“现成”机器人出租或出售给感兴趣的各方，并接受银行卡付款。

  

据确定，他的“客户”包括政党公关部门的代表和俄罗斯公民，他们在乌克兰信息空间宣传破坏性和挑衅性材料。

  

  

![](../Images/8db29ebe3aca703754faaf520a4861ed.png)

*（SSU没收“机器人农场”的设备）*

  

乌克兰执法部门在该管理员家中进行了搜查，并没收了带有非法活动证据的计算机设备和特殊软件。

  

**在敖德萨地区：**

  

该机器人农场由4个当地人组织。

  

他们的主要活动是在社交网络和聊天软件中创建和推广账户。该团伙利用机器人在该地区散布恐慌，例如，通过传播来自前线的虚假信息和假新闻。

  

根据调查结果，SSU确定该团伙的“客户”来自俄罗斯。

  

![](../Images/39ea052de676b5d02f5d65ccd49bb6d0.png)

*（SSU没收“机器人农场”设备）*

  

在对嫌疑人家中进行搜查时，执法部门发现并查获：

  

● 计算机设备、4台服务器、250多个USB调制解调器和有非法活动证据的手机；

  

● 供“客户”支付钱款的银行卡；

  

● 400多张移动运营商的SIM卡。

  

![](../Images/e1b2cabb4d40c01281833367c8e2885b.png)

  

![](../Images/f41d188709ba3ad5cf78e2ba926c78e9.png)

  

查获的物品已送交检查。调查正在进行中。

  

相关行动是由SSU与国家警察部门在敖德萨和基辅地区检察官办公室的程序监督下进行的。
