# Linux Kernel openvswitch模块权限提升漏洞安全风险通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NDY2MDMwMw==&mid=2247505840&idx=4&sn=5485f918ad3ab5d7f0e18730bda448c6&chksm=ebfa9090dc8d19868d6c4cd2b9e6fed029ad21b8a05d502fbde4b06fa6f2c0d43c4469befccb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247505840&idx=4&sn=5485f918ad3ab5d7f0e18730bda448c6&chksm=ebfa9090dc8d19868d6c4cd2b9e6fed029ad21b8a05d502fbde4b06fa6f2c0d43c4469befccb&scene=27#wechat_redirect)

近日，奇安信CERT监测到 Linux Kernel openvswitch 模块权限提升漏洞 EXP 在互联网上公开，漏洞编号为CVE-2022-2639。在处理大量actions的情况下，Linux Kernel openvswitch 模块存在越界写入漏洞。本地经过身份认证的攻击者可利用此漏洞提升至ROOT权限。**奇安信CERT已复现此漏洞，经测试，此EXP稳定有效。****鉴于此漏洞影响范围极大，建议客户尽快做好自查及防护。**
