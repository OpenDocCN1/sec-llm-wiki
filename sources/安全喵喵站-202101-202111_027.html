“创始人IP打造”是这些年流行的“营销套路”。


起初我也认为很有道理，特别是对于产品很难说清楚又急需打开市场却没预算的企业，想要有故事，还能自发传播，好像就只能宣传创始人自己了。


于是，我常常跟一些技术出身的CEO大佬们苦口婆心地说“您多多见媒体，对品牌有大大的好处”。


他们大多数都沉默不语，或者直接摆手“不行不行，我口才不行，也不想高调…”


“不说可以在自媒体写啊，写技术观点，创业初衷...” 


逼急了的CEO一般是开个公众号坚持写几篇或者不得不接受几次媒体采访后，就一溜烟地忙着跑客户，见投资人了。那些不听的，强迫也没用。


转头一想，忙了大半天，科技类企业创始人真正有个人品牌的10个手指头都数得过来，我们这么做到底是To 市场或客户还是To VC呢？是否要像知识网红一样必须有个人IP呢？


好像也不是，仔细分析会发现这仅仅是实现“锦上添花”而不是“雪中送炭”。


我们来说说。


1. 

个人品牌/个人 IP 是什么


查阅了很多国外的文章，对于个人品牌(Personal Brand)有清晰的解释，但对于个人IP说得比较少。


先来说说个人品牌。


根据品牌的定义，我们可以简单的理解成：别人提起你会有联想到你的事业，或者提起某领域的企业领袖就能想到你（是赛道的品类王），那么你就是有品牌的。


谈起Elon Musk，有人会觉得他是个疯子，但又是能够创造新世界的人，更会想到科技感十足的特斯拉汽车；提起最能让公司起死回生的CEO，你可能会想起带领大象跳舞的IBM 前CEO郭士纳…


这两类中，前者是企业创始人，他们用梦想、使命为企业代言。国内的雷军、柳传志、任正非等… 都是小米、联想、华为品牌中最重要的资产之一。


第二类是职业经理人，行业精英，拥有卓越的领导力，带领企业不断创新突破。他们虽然不是创立企业的功臣，但是一样成就了传奇，比如微软的纳德拉，国内格力电器的董明珠… 


这两类人我们都尊称他们-企业家。


再来说说个人IP，这个词在国内非常火。个人IP（intellectual property ) 可以简单理解为个人在线上的品牌资产，可以通过不同方式变现，形成交易闭环。


各种网红、自媒体KOL、直播主播被认为是有个人IP的，以内容为产品的企业创始人也说自己是有IP的。


但个人IP和个人品牌有啥区别，我也没找到准确答案。也许IP更是互联网时代打造偶像的方式？或者IP可以带来持续的收益？


不过，企业家们常常有独特的个人魅力，他们不仅仅是一个icon，更是业界领袖，自然也为企业带来了不可估量的价值。这个程度上讲，无论是品牌或者IP都一样。


2. 

个人IP不是硬凹“人设”


但不得不说的是，这些人之所以卓尔不群，要不是真天赋异禀，要不就是坚韧、智慧、勤勉、专业…并不是靠品牌部门或者公关公司设计出来的。


可现在大家提起IP，必谈“人设”。这听起来是一个刻意而虚伪的词汇。


要知道，“硬凹人设”的下一句常常是“翻车”或“崩塌”。


对于企业CEO更是一样，按照设定的剧本表演一定很别扭。


每个人身上都有独特的闪光点，作为能够有勇气创业或者真正成为企业家的人，身上一定有很多让人敬佩和尊敬的特质。


关键的是让别人能看到这些与众不同。


比如我熟悉的一位CEO是物联网行业技术专家，拥有不少发明专利，但在科技圈并不一定会让别人记住，毕竟牛人太多了。


但如果我告诉你他还是资深油画藏家、会西班牙语，你是不是会对他印象深刻？


更能联想到这么文艺又懂技术的人不但对产品要求高，更加在UI、用户体验都精益求精。


实际上确实是。


因此，如果适当地宣传他的个人爱好，会让客户对他的事业有更全面的认识，对于品牌形象的打造大有好处。


因此打造个人品牌是挖掘“与众不同”而不是“编故事”。是让人看到丰富的、有血有肉真实的人，更是呈现价值观，为人处事的态度。


不是虚假炒作，更不是去拍一些形象照、参加一些评奖、在视频平台上讲课就马上能拥有的。起码在科技圈行不通。


但并不是每个CEO都需要一开始就广泛地传播与宣传自己。上面说的那位CEO就认为时机并没到，想企业发展更好的时候再让更多人了解他。


我也非常欣赏Facebook COO 桑德伯格的观点：


“人类非常复杂，而且容易犯错。一旦创造了一个"完美"的个人品牌，就很可能为了支撑这种形象而肩负重压。我没有品牌形象，但是我有自己的价值观，如果你能够去做一些事，帮助我们的世界向你所希望的方向前进，这才是更具有价值的地方。”


3. 

不同发展阶段CEO品牌的重要性不同


在企业不同的发展阶段，对于创始人个人品牌的需求以及打造方式也不同。比如：


（1）初创期：需要


如果能让对大家更多的了解真实的创业故事，过往的工作经历背景，会让客户、投资人更全面的了解企业，产生信任。


有的CEO是连续创业者或者本身就是行业大拿，早就有了口碑和声誉，没有产品的时候可能投资人就在后面跟着。


对他们而言个人品牌更多意义上是吸引志同道合的人加入，大家一起共创事业。可以适当的通过一些专业社群、自媒体等发表自己的专业见解。


（2）发展期：不太需要


CEO在这个阶段会非常忙，大多会把精力放在搞定灯塔客户以及内部管理上。这个阶段企业的品牌塑造以产品和服务为主，强调带给客户的价值。


（3）成熟期：很需要


企业有了一定的知名度，需要进一步扩大在市场、行业上的影响力，也需要在员工中建立强的雇主品牌。CEO这个阶段可以渐渐从具体事务抽身，对外作为企业代言人，发表专业观点，对内成为精神领袖，强调使命与价值观，推广企业文化。

 

这些仅仅是一般情况，或者说理想的情况。实际上CEO不太愿意或者不接受打造个人品牌的原因大多有这些：


  • 对未来心里也没有底，万一失败了呢？牛皮吹大可不好

  • 认为个人品牌就是要高调做人，这不符合自己的性格，另外说多了竞争对手会不会搞事？

  • 对媒体不感冒，也担心他们乱写

  • 自媒体没时间弄，本来也不擅长写或者拍视频

  • 客户都是圈子里的人，也不太需要去宣传自己，做好产品就行

  • 想宣传也不知道从何说起，没经验

…


以上这些如果没想好，那真的还不如先放放。不一定非要成为科技圈明星才能把事业干好。


另外企业和个人的品牌都是长期的承诺与投入，如果开始都这么难，坚持下去的可能性并不大。如果做不好，反而会起到反作用。


换另外一个思路是打造团队的IP ，不是一个人而是一个组合。


比如创始人团队具有非常强的多样性，优势互补，年轻又有朝气，这对企业的品牌形象一样加分。


4. 

不可忽视的品牌公关意识


但不去打造个人品牌并不是说就和媒体绝缘，更不是不去配合市场部门做品牌公关活动。


现在的媒体环境越来越复杂，除了传统的渠道，更是有各种社交媒体、自媒体可以发声。


但途径多，成本低了，说错话的风险高了。


企业高管团队如果要和媒体合作，必须经过专业的媒体培训，哪些话可以说，哪些话不能说要实际演练多次。


比如不能在各种渠道发布未经公司统一规定的财务数据，比如不能直接攻击竞争对手、未经许可擅自不能在各种媒体使用客户形象以及案例… 这些对自己的专业形象不利，更会让企业惹祸上身。


除此之外，无论是面对面采访，还是电话、视频等形式，提前准备非常重要。


建议在采访前先拿到问题提纲，认真回答并反复练习，“临场发挥”或“随遇而安”只会让自己在面对可能的刁难、尖锐、无礼的各种问题时措手不及。


如果有正式的露面采访机会形象上也要做准备，不能穿短裤拖鞋，整个人看起来神清气爽别人…这是基本的礼仪，与互联网风尚无关。


另外，假如遇到危机事件，创始人要勇敢的站出来及时澄清与解释，亲自处理并及时通报也是基本的公关原则。


因此，CEO拥有品牌公关的常识比打造个人形象还重要。


最后再来重申一下我的观点：创始人个人品牌打造要看时机，也不一定是必须，根据企业实际情况以及创始人个人意愿来综合衡量。


一旦决定要做，那么就要做好长期时间与精力投入的准备。


个人品牌不是一天两天形成，更不是一次炒作，一次出镜就OK了。真实真诚最重要，虚假的人设迟早也会露馅。


持续用业绩和行动说话，展现最真实的自己，个人品牌也会自然而然的到来。
