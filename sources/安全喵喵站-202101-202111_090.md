# 安全行业「权威资质」搜索指南·上篇

营销老司机们都知道，在招投标过程中，**资质不仅是加分项，有时甚至是参与投标的入场券**。一些成熟的安全大厂，每年在资质这一块会投入数百万元的费用和大量人力资源去运营完善，提升整体竞争力。  

  

资质并不是一成不变，随着行业的发展，也一直与时俱进，不断更新迭代。面对招标书上那一长串林林种种的资质要求时，营销老司机也难免遇到盲点，刚入行的萌新更是一脸懵。**这些资质到底都是些啥？业内都有哪些厂商拿了？在哪儿能查到？**

![](../Images/37b3e35c6869e609b1d5879922047617.png)

  

为此，喵酱将为大家汇总业内常见的权威资质，并一一梳理对应的查询入口。

  

![](../Images/70c6f55a9cacc274056d3fc7df8d5785.png)

  

本篇，我们一起看看**公安部网络安全保卫局、中国网络安全审查技术与认证中心、国家互联网应急中心CNCERT、**国家**保密科技测评中心**这几个机构颁发的资质。

  

来，跟着喵酱走，保证不迷路～

  

**公安部网络安全保卫局**  
![](../Images/ee150294a91cbd70fd7486f618b6b32f.png)  

**销售许可证**

  

*   **证书介绍**

根据《计算机信息系统安全专用产品检测和销售许可证管理办法》，中华人民共和国境内的安全专用产品进入市场销售, 实行销售许可证制度。安全专用产品的生产者在其产品进入市场销售之前, 必须申领《计算机信息系统安全专用产品销售许可证》；根据《计算机病毒防治管理办法》，任何单位和个人销售、附赠的计算机病毒防治产品，应当具有计算机信息系统安全专用产品销售许可证，并贴有‘销售许可’标记。  

*   **查询入口**

https://ispl.mps.gov.cn/ispl/jsp/common/ProductList\_Public.jsp  
  
**中国网络安全审查技术与认证中心**  
![](../Images/0637b58d21acff1a911b00c889e27b75.png)  

**网络关键设备和网络安全专用产品安全认证**

  

*   **证书介绍**

依据《网络安全法》第二十三条的规定，对网络关键设备和网络安全专用产品依据国家标准强制性要求开展安全认证。  

*   **查询入口**

https://p.isccc.gov.cn/CertSearch.aspx?ptype=1  

**国家信息安全产品认证**

  

*   **证书介绍**

获得国家信息安全产品认证证书的产品表明其符合相应的信息安全规范和标准要求。  

*   **查询入口**

https://p.isccc.gov.cn/CertSearch.aspx?ptype=2  

**IT产品信息安全认证**

  

*   **证书介绍**

依据信息技术安全评估准则和相关技术要求，对IT产品的安全性进行评价，旨在保护用户信息安全，维护用户利益。生产企业的IT产品获得信息安全认证证书，表明该产品符合相应的标准和技术要求。  

*   **查询入口**

https://p.isccc.gov.cn/CertSearch.aspx?ptype=3  

**风险评估服务**

  

*   **证书介绍**

风险评估服务提供方的服务能力主要从以下四个方面体现：基本资格、服务管理能力、服务技术能力和服务过程能力；服务人员的能力主要从掌握的知识、风险评估服务的经验等综合评定。对服务提供方的背景审查主要指客户投诉、违法违纪行为等；服务人员的背景审查主要指行业主管部门或使用单位对从事风险评估服务的人员进行必要的审查。资质级别分为一级、二级、三级共三个级别，其中一级最高，三级最低。  

*   **查询入口**

http://cx.cnca.cn/CertECloud/result/skipResultList?certItemOne=C&currentPosition=%E6%9C%8D%E5%8A%A1%E8%AE%A4%E8%AF%81  

**信息安全应急处理服务**

  

*   **证书介绍**

对应急处理服务提供方的基本资格、管理能力、技术能力和应急处理服务过程能力等方面进行评价。信息安全应急处理服务资质级别是衡量服务提供方应急处理服务资格和能力的尺度，应急处理服务资质分为三级，其中一级最高，三级最低。  

*   **查询入口**

http://cx.cnca.cn/CertECloud/result/skipResultList?certItemOne=C&currentPosition=%E6%9C%8D%E5%8A%A1%E8%AE%A4%E8%AF%81

*   **证书介绍**

**信息系统灾难备份与恢复服务**

  

*   **证书介绍**

将信息系统的数据、数据处理系统、网络系统、基础设施、专业技术支持能力和运行管理能力进行备份，并在灾难发生时，将信息系统从灾难造成的故障或瘫痪状态恢复到可正常运行状态，将其支持的业务功能从灾难造成的不正常状态恢复到可接受状态，而设计和提供的活动。信息系统灾难备份与恢复服务资质级别是衡量服务提供者服务能力的尺度。资质级别分为一级、二级、三级共三个级别，其中一级最高，三级最低。  

*   **查询入口**

http://cx.cnca.cn/CertECloud/result/skipResultList?certItemOne=C&currentPosition=%E6%9C%8D%E5%8A%A1%E8%AE%A4%E8%AF%81

**国家互联网应急中心CNCERT**  

![](../Images/1003b1c397adeb449da58db2bb45d7bf.png)

  

**CNCERT网络安全应急服务支撑单位**

  

*   **证书介绍**

为发掘网络安全领域优秀技术力量，推动完善我国互联网网络安全应急体系，CNCERT于2004年启动“CNCERT网络安全应急服务支撑单位”遴选工作。支撑单位每两年一个遴选周期（届满到期后所有单位重新参加新一轮遴选），实行总量控制、开放竞争、考核评估、动态调整。支撑单位类别分为国家级、省级、重点技术领域，其中重点技术领域根据工作需要设置。  

*   **查询入口**

https://www.cert.org.cn/publish/main/32/index.html  
  
**国家****保密科技测评中心**  

![](../Images/3f360d530d89b970e8583473e876d385.png)

  

**涉密信息系统产品检测**

  

*   **证书介绍**

测评中心对用于涉密信息系统的安全保密产品进行检测，通过检测的产品经国家保密局审核批准后，向申请单位颁发《涉密信息系统产品检测证书》，并列入国家保密局批准的在涉密信息系统中使用的产品目录。  

*   **查询入口**

http://www.nsstec.org.cn/cpjc/zscx/index.shtml
