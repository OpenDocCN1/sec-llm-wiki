# 2B or Not 2B？从微软和华为的不同动态，看云电脑的未来

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkzNjE5NjQ4Mw==&mid=2247504674&idx=1&sn=c692fa1fcc595c769b170fa97a0b5b28&chksm=c2a0f3cef5d77ad89c3ae93de611d1242e478d864021d1b498f0b7d88e5229d81a07e80bc9c1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkzNjE5NjQ4Mw==&mid=2247504674&idx=1&sn=c692fa1fcc595c769b170fa97a0b5b28&chksm=c2a0f3cef5d77ad89c3ae93de611d1242e478d864021d1b498f0b7d88e5229d81a07e80bc9c1&scene=27#wechat_redirect)

近期业界有两则新闻，引起热议。一个是**7月14日微软发布了Windows 365 Cloud PC，云电脑成为核心战略业务。**  
![](../Images/1069d23b3a328a2e605480fac57c4c8e.png)[微软发布 Windows 365，开创全新计算类别](https://mp.weixin.qq.com/s?__biz=MzA3MTA0ODYyOA==&mid=2651282034&idx=1&sn=28dded29feead0a3ee36443415910448&scene=21#wechat_redirect)  
紧接着是**7月15日，华为云电脑团队发布公告称，因业务发展策略调整，“华为云电脑”将于北京时间2021年8月15日23点59分停止服务和运营****，数据将被永久删除。**![](../Images/d61a20d0b8a5cbb3656dc8eca4f240b2.png)[华为云电脑将于8月16日停止服务，数据将被永久删除](https://mp.weixin.qq.com/s?__biz=MzU4NDcyMjM0Nw==&mid=2247501035&idx=1&sn=d769338fa358d6fca03d6ec6d12826a4&scene=21#wechat_redirect)  
  
为什么Microsoft把Azure Desktop升级成Windows 365 Cloud PC，而华为云却把云电脑业务关停呢？**我们的看法是：云电脑是天然的企业服务，Manageability是核心，所以这事只有Microsoft能做，别家都搞不起来。**  
终端设备的性能和价格已经在合理区间，云电脑对一般个人用户意义不大，对特定商业用户是成本换便利性，真正的市场是企业。传统VDI/桌面云的购买和使用成本并不比分散的台式机低，用户使用体验也和个人终端电脑有差距，这些年“桌面云” 在企业市场广泛发展的根本原因还是安全，确切地说是集中管理和数据安全。  
与传统VDI/云桌面相比，云电脑/云桌面进一步降低了硬件部署和维护成本，让使用更灵活，这些好处是显而易见的。但是，从VDI/桌面云到云电脑/云桌面，业务模式从私有云变成了公有云，企业对资源和数据的掌控变得不完整，而用户访问更加便利和随意，使得安全更难以保障。因此，要想把云电脑在企业市场做起来，用户身份管理（以及基于身份管理的访问管理）是基础，对云上终端（及用户在终端上的行为）的掌控是不可或缺的核心能力。Microsoft拥有长期积累下的系统管理能力，核心是域管理和终端管理。除了Azure AD，从Azure Desktop到Windows 365 Cloud PC的一个基础和支柱是Windows Endpoint Manager。  
**至于其他厂商，目前来看，在基本能力上都是根本缺失的。**所以华为云电脑业务关停，阿里云无影大概也没戏；AWS Workplace一时半会儿应该也做不起来，不过Amazon做事情线放得长，还有AppStream等探索，没准哪天打通“任督二脉”也未可知。  
整个云电脑的业务和生态只是传统PC的延伸——Microsoft是PC时代无可挑战的霸主，在良好的Azure基础上云电脑自然也脱不出其掌控。在可以预见的将来，Cloud PC整体可能是会被Microsoft独吞的万亿甚至十万亿规模的市场，而由于公有云基础架构业务的特殊性，国内云厂商如果能补足基本能力，应该还是有些机会的。  
**当然了，云电脑（Cloud PC）仍然是终端。**随着云的进一步深入发展，终端本身并不是不可挑战的，而一旦传统终端从逻辑上被打破，关于云电脑的一切讨论都将不复存在， Microsoft命运终结的时代也就到来了。
