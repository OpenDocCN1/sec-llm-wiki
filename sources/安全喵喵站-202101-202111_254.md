# 20家网安企业IPO申报情况汇总

**概要**  
  
本期航行资本盘点了网安企业上市进展情况，目前监测到20家企业在申报中/终止。  
**申报进程**：2家已通过审核、1家在受理中、9家辅导中、3家终止、4家撤回、1家通过精选层辅导验收。  
**申报板块**：16家申报科创板、1家申报主板、1家申报新三板精选层、2家未披露。
