# 「身份编排」新趋势，Strata完成B轮融资2600万美元｜喵站快讯

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkzNjE5NjQ4Mw==&mid=2247529561&idx=1&sn=3e768521e2e02c3bb1130ac9bfce185f&chksm=97d091665fd83f6bc976846e914b8252fc13352da992c7fb5d71386457369275746016593450&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkzNjE5NjQ4Mw==&mid=2247529561&idx=1&sn=3e768521e2e02c3bb1130ac9bfce185f&chksm=97d091665fd83f6bc976846e914b8252fc13352da992c7fb5d71386457369275746016593450&scene=27#wechat_redirect)

![](../Images/94f101423437c6531d3ef79c6ba63495.png)

  

**2023年1月25日，定位于「身份编排Identity Orchestration」的创新厂商Strata宣布完成2600万美元的B轮融资，由Telstra Ventures领投。新一轮融资将用于扩展其Maverics平台，跟进快速兴起的下一代多云身份管理的步伐，并加速GTM市场推广计划。**

  

![](../Images/c20e96776aaa57029837a85562bb57c5.png)

  

Strata的Maverics Identity Orchestration平台将一个组织中所有的身份管理服务——包括本地和云基础设施——抽象到一个集成的身份结构中（类似于 Gartner所称的网络安全网格或CSMA），该结构支持身份编排和用户流，使不兼容的身份系统能够无缝协同工作。

  

Maverics的身份编排是运行时用户流，可以从登录、多因素、授权、属性和其他身份服务对用户会话进行编排，通过对用户的身份旅程管理来保障运行时体验，通过登录和注册步骤以及通过用户和安全流程链接用户体验，从而提供跨应用程序的安全和无缝衔接的整体用户体验。

  

![](../Images/f8c176669b2b91ec52b5f2e0129b62cf.png)

  

**Strata解决了现有身份系统无法解决的一个新问题，即将企业使用的多种身份和安全解决方案集成到一个身份结构中。**Strata使企业的身份操作具有连续性和弹性，从而可以在比如Okta出现故障时，从Okta切换到Microsoft。**凭借这一理念，Strata成功入选了2021 RSA创新沙盒十强**，同届的明星厂商还包括WABBI、Satori、Abnormal Security、Apiiro、Axis Security、Cape Privacy、Deduce、Open Raven、WIZ。

  

![](../Images/8ecaa8661e0a17a16a7ee60392f030f9.png)

  

**2022年Strata的ARR增长了380%以上，**客户包括财富500强，涉及金融服务、零售、制造、咨询、技术和电信等等多个行业，并与各州和地方政府展开合作。**Strata 宣称，大多数客户在初次购买后的一年内将他们的实施增加了一倍或四倍，而且从未失去过客户。**

  

「身份编排」理念的兴起

  

**「身份编排Identity Orchestration」是IAM领域中的一个新细分市场，**这个市场正在以每年14%的速度增长，到2030年市场空间将达到$36B。经过过去几年的发展，身份编排已迅速成为加速现代化和管理由多种云服务和多供应商身份蔓延带来的巨大挑战的最重要工具之一。

  

大型企业一直在稳步采用多云基础设施，随着多云的出现，新旧技术平台之间出现了新的身份和安全孤岛。向多个云的迁移正在推动向多个身份系统的迁移，**这些企业现在需要一种方法使这些多个身份系统共存，因为整合通常不是一种选择。**

  

![](../Images/58e26a7590c1649f003b1688200ba325.png)

  

**Gartner将这类新兴的身份编排方案命名为Journey-Time Orchestration旅程编排。在Gartner看来，在未来，公司要么编排，要么被编排，**编排类解决方案可在用户与应用程序交互时实时改进数字用户旅程的风险管理。大多数组织会管理许多身份与确认、欺诈检测工具、访问管理等邻近功能，编排解决方案会集成供应商管理，简化旅程中每个事件的风险评估，并提升用户体验UX。

  

![](../Images/5971656e641caac536b12fd5fb480e04.png)

  

**保护数字用户旅程的完整性是数字化转型的关键。**使用编排解决方案可以消除管理多个供应商集成的操作复杂性，提高数字用户旅程中风险管理的效率，并帮助组织管理安全和用户体验之间的微妙平衡。**在提高用户体验的同时提高安全性，是大多数企业的梦想。**

  

![](../Images/20ea7d3a5bb97a26f7710d0bd2056c50.png)

  

「身份编排」和身份安全在国内的发展

  

**随着多云和复杂架构的发展，身份安全的整合复杂度需求，也越来越被国内用户所关注，身份安全也同样是近几年国内安全发展的热点，**部分国内明星厂商已经前瞻性布局，也是为众多资本所看好的一个未来赛道方向。

**派拉软件身份安全产品总监陈庆健表示**，身份编排技术的核心思想是将不同的身份验证方式和身份数据整合在一起，为用户提供更加安全和便捷的身份验证和管理体验。相比于传统的单一身份验证方式，身份编排技术可以更好地保护用户的隐私，并且可以应对日益复杂的身份验证场景。并且，多云架构下的身份验证和管理是一项非常复杂的任务，因为多个云平台之间存在不同的身份验证和授权机制，而不同的云平台也可能涉及到不同的身份验证标准和协议。身份编排技术通过集成不同的身份验证和授权系统，将不同的身份信息进行映射和转换，可以帮助企业在多云环境下实现一种更加智能、安全、可靠的身份验证和管理体系。

  

在当前数字化时代，身份编排技术可以为各个领域提供更加安全、高效和方便的身份验证和管理体验，其应用前景非常广泛。例如在金融领域，身份编排技术可以有效地防范诈骗和欺诈行为，提高交易的安全性和效率；在电商领域，身份编排技术可以帮助企业更好地识别和管理用户，提高用户的购物体验和满意度；在医疗领域，身份编排技术可以帮助医疗机构更好地管理和保护患者的健康信息。作为国内最早从事身份治理的专业厂商，派拉软件依托零信任安全框架，构建零信任身份安全产品体系，成功落地了大量实际案例，极大的提高安全性。

  

**竹云科技副总裁戴立伟认为，**身份编排是身份管理与访问控制发展过程中，以用户体验旅程为导向，并通过拖拉拽无代码组件为形式的身份管理能力体系。身份编排可以快速编织用户获取、用户同步、登录认证、风险控制、日志查询等能力，实现组织内身份体系快速部署与测试，满足多身份供应源、多云身份体系、多认证能力汇聚、事前风险预警等现代身份管理要求，促进组织业务快速发展。竹云统一身份管理与访问控制平台，从早年认证编排开始，逐渐构建全面的身份编排能力，并在众多国家部委、省市区数字政府、大型央国企以及外资企业获得最佳实践，赋能组织数字化转型。
