# 网安厂商是时候拥有一个「自己的」安全媒体了｜一种观点

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkzNjE5NjQ4Mw==&mid=2247526323&idx=1&sn=d9bc53b7c0c982aecf36dbf23192910c&chksm=c2a0475ff5d7ce49ce15baf11d92f69e2b585a7a1db5517693b13d86681c1e8ec8d361171867&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkzNjE5NjQ4Mw==&mid=2247526323&idx=1&sn=d9bc53b7c0c982aecf36dbf23192910c&chksm=c2a0475ff5d7ce49ce15baf11d92f69e2b585a7a1db5517693b13d86681c1e8ec8d361171867&scene=27#wechat_redirect)

![](../Images/2e4293f44989739a4aa9bac91f4d4801.png)![](../Images/851b5e6bbb9fb2e16d24af23506f5672.png)  
自从Elon Musk买下Twitter，全世界的媒体们就无法停止关注另一个媒体的命运。抛开Musk扑朔的初心和莫测的手法不谈，这场并购显然补齐甚至放大了其影响力版图。  
**这不是第一次科技巨头并购媒体了。**OpenView Capital的两位合伙人对近几年硅谷的媒体并购记录做了整理，发现软件公司（尤其是PLG类的独角兽）对并购或自建媒体平台尤为钟爱，果然是「软件正在吞噬世界」。  
![](../Images/8817aaf028e364ffa8db7a0c6fa42183.png)**独角兽们的媒体并购举动背后，是一种怎样的思考？**HubSpot的联创兼CTO Dharmesh Shah曾发Twitter写道：**下一代的软件公司将内嵌一家媒体公司。**道出了其并购的真意。  
  
![](../Images/ecfb1ae3cec5cbb519989fddfe0f3d3b.png)  
**诚如芒格所言，要到有鱼的地方去钓鱼，科技公司拥有「自己的」的媒体平台，好处很多。**由于身份角色不同，媒体平台往往具备以低成本吸引大量粉丝的身份和能力，而粉丝社区一般是软件厂商PLG 战略的天然加速器，尤其是粉丝群体有聚焦或细分画像的媒体，甚至可以针对性的帮助产品搜集反馈并加速迭代。  
CBInsights在JP Morgan出手并购了两个媒体之后，也开始关注这一现象并分析认为：**与其租用（媒体的）观众，公司开始意识到拥有他们的观众并直接触达可以降低 CAC（Customer Acquisition Cost用户获取成本）并增加 LTV（Life Time Value用户终身价值）。**![](../Images/72dbbb7a0b136c8dd7f38e9b7bdf7f3d.png)  
**「自己的」媒体平台，可以通过并购而来，也可以尝试团队自建。**所谓术业有专攻，打造一个活跃的媒体平台，比想象中要难得多，对于高估值的科技独角兽而言，并购媒体往往比自建要更有效率，而且成本更低。媒体平台本身的估值PS倍数一般都不高，对于独角兽的估值和资本放大系数而言，并购媒体对其整体资产占比影响极低，需要注意的反而是后续的运营如何维持，包括内容的打磨输出，也包括核心人员的稳定。  
**那么，网安行业也会并购专业安全媒体吗？**或许是因为网安技术的碎片化，即便是硅谷的网安巨头，直接并购安全媒体的也并不多见，大多依然是选择与多个专业安全媒体平台展开合作。部分安全厂商会自建一个媒体平台，比如威胁情报公司RecordedFuture自建了The Record平台，Sophos也建立了一个naked security平台。  
![](../Images/1b87f020d992af9240e702fbbef29982.png)  
![](../Images/de856d0de88b2cc0247e2994da3c8ff1.png)**视角转回国内。**2022年初时，繁星创投、红华资本、 航行资本、斯元商业咨询四机构曾发布过一份面向国内市场的[**「网安创业生态图·Explorer Map for Cyber Security Startups」**](http://mp.weixin.qq.com/s?__biz=MzkzNjE5NjQ4Mw==&mid=2247519222&idx=1&sn=8652e987144bcf55ce318bac12f67d8f&chksm=c2a0ab1af5d7220c72eb283a57381a49c2c92ccb3a0f5bd1df1e7898cd1216cfa96550421f63&scene=21#wechat_redirect)，将网安行业进行了生态解构，媒体便是生态中不可或缺的一环。  
  
**![](../Images/d1770795785b69c28f5b5e09c0b3e639.png)**  
目前国内的安全媒体生态中，有监管下属的机构，有独立的第三方自媒体平台，有行业KOL的个人自留地，也能看到一些国内的网络安全厂商，在尝试建立「自己的」媒体平台所作出的努力。感兴趣的朋友，可以关注下不同媒体平台的公司主体和股权结构，其中还会发现许多网安上市公司的身影。  
**但网安厂商对媒体价值的认知，依然原始。**Peter Thiel七年前就在《从0到1》中写到：**把公司推销给媒体是推销给其他人的必要前提。出于本能，技术精英不相信媒体，常常犯忽视媒体的错误。**国内厂商大多依然把媒体看作一个单向的喇叭而不是一个与市场双向沟通的通道，也很少体系化设计自身品牌和个性化的产品传播战略，手段不清目的不明，效果自然惨不忍睹。  
**网安的技术碎片化和用户精力的极度分散，也使得当前的网安媒体平台市场出现马太效应，**新的平台难以冒头，用户也懒得再去新的地方吸收信息。**而伴随着[分析机构偶像化的破灭](http://mp.weixin.qq.com/s?__biz=MzkzNjE5NjQ4Mw==&mid=2247525636&idx=1&sn=9a816c27ebbb3dcae102b30782277087&chksm=c2a045e8f5d7ccfe081e7e5dd3b894ada2110c27aa861f8f77f46797d3bd3c5b465ee4fd3305&scene=21#wechat_redirect)，更注定了当前是一个霰弹散射式的传播时代，不再有最响亮的喇叭，众声喧哗才是最有效的传播策略。**![](../Images/ebdf1acdfeaff29c6fd08fee6b4a8ff6.png)**网安厂商是时候拥有一个「自己的」安全媒体了。**不是所有公司都能有Musk这种天生的代言人，在赛道数百、玩家过千的国内网安市场中，**想想你公司的名字，已经有多久没有被人提及了？**媒体传播，对于网安厂商而言，已经不是要不要做、何时要做的问题，而是当下该怎么做的问题。**如何在众多的网安媒体中，找到和自己业务契合的伙伴，成为「自己人」，是网安厂商需要认真面对的问题。****为了喝口牛奶，未必一定要买头奶牛回家，也可以试着认领一头。但无论采用何种方式，都要记得持续饮用，才能健康成长。**
