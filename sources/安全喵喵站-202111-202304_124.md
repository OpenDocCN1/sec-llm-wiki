# Fortra（原HelpSystems），一个被忽视的网安巨头

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkzNjE5NjQ4Mw==&mid=2247525805&idx=1&sn=ff7bca77d4debf7b6bd22202c08d4ca7&chksm=c2a04541f5d7cc576f5bf40853b70134c71ae80c7f5bcf63ca1404d84b85f38426937dcfd774&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkzNjE5NjQ4Mw==&mid=2247525805&idx=1&sn=ff7bca77d4debf7b6bd22202c08d4ca7&chksm=c2a04541f5d7cc576f5bf40853b70134c71ae80c7f5bcf63ca1404d84b85f38426937dcfd774&scene=27#wechat_redirect)

**Cobalt Strike，PhishLabs，Digital Guardian，Beyond Security，这些耳熟能详的、独立赛道上的专业明星厂商，你知道他们都隶属于同一个母公司吗？**今天就来为大家介绍一下这个被忽视了的网安巨头**「Fortra」**。

  

![](../Images/10d8958f2166544e03915516bf2f76d6.png)

  

**Fortra原名为HelpSystems，在今年11月2日正式更名。**更名后的Fortra将聚焦安全和防御，以凸显公司帮助客户简化网络安全复杂性的决心。Fortra目前有3000多名员工，在18个国家设有办事处，拥有30000多名全球客户。Fortra首席执行官Kate Boleth表示：“网络安全行业一直在变化，我们也随之发展。希望客户将我们视为他们的网络安全盟友，相伴同行。”

  

![](../Images/13b87195ce77c54d3afd75827229d322.png)

  

**Fortra旗下拥有20+安全产品线，**包括Alert Logic、Beyond Security 、Digital Guardian、Cobalt Strike、Tripwire、Digital Defense、Terranova Security、Agari、PhishLabs、Core Security、GoAnywhere、Titus以及其他知名软件和服务提供商。**由于之前很多产品都是以独立品牌面向用户提供单独的专业技术方案，因此母公司的存在感并不强。**更名后，Fortra将重点转向网络安全和自动化，建立了一流的产品组合，具备数据安全、基础设施保护和MSS方面的关键能力。

  

据机构披露，Fortra的英文域名Fortra.com是今年6月28日以17,500美元买下的。

  

![](../Images/f0c15f1f770e1e39c70274a31158965b.png)

  

**Fortra的前身HelpSystems成立于1982年**，1989年开始进军智能自动化领域，为当时正快速增长的IBM AS/400用户群体提供消息管理方案。2005年创始人退休后，将公司出售给私募股权机构Summit Partners，开启了商业并购的进程。2010年，随着安全成为IT团队的首要任务，HelpSystems开始关注网络安全并构建其产品组合，收购数据安全及身份治理IGA等领域的技术领导者，并持续并购完善其产品组合，直至2022年，更名为Fortra。目前Fortra可以为客户提供包括数据安全、基础设施保护、威胁研究和情报，以及管理服务在内的一流安全和自动化解决方案。

  

![](../Images/30b39561c36f5ede21f982a55aedc728.png)

  

**目前，Fortra由HGGC所持有。**HGGC是一家专注于Middle‐Market的私募机构，累计资本超过68亿美元，自2007年以来，已完成500项投资组合和交易，企业总价值超过680亿美元，于2018年2月通过资本重组获得HelpSystems的控股权，传闻称交易金额超过12亿美元。
