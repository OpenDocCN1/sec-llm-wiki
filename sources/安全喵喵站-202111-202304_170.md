# 安芯网盾亮相全球最大科技展GITEX GLOBAL 2022，正式加入华为云丝绸之路技术生态伙伴

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkzNjE5NjQ4Mw==&mid=2247524446&idx=2&sn=87b5cabbd3ac8916adc20e35b11f3a76&chksm=c2a040b2f5d7c9a46a5715e8db5c9e219e40e8b806e4e41eeeee07e076d417cfe5560358dd8b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkzNjE5NjQ4Mw==&mid=2247524446&idx=2&sn=87b5cabbd3ac8916adc20e35b11f3a76&chksm=c2a040b2f5d7c9a46a5715e8db5c9e219e40e8b806e4e41eeeee07e076d417cfe5560358dd8b&scene=27#wechat_redirect)

10月10日-14日，全球最大的科技展Gitex Global 2022在迪拜世贸中心（DWTC）举行，安芯网盾作为唯一一家来自中国安全公司亮相GITEX展会。据了解，**安芯网盾作为内存安全的开拓者和领军者，此次在展会上展示了拳头产品内存保护系统（MDPS）和多个安全解决方案，为海外客户提供国际领先的网络安全产品和解决方案。 **  
  
GITEX始创于1980年，目前已发展成为全球最大、最成功的计算机、通信及消费性电子产品展。本届GITEX有来自全球各地的5000+参展商，吸引来自170个国家和地区的超过10万名各界人士参观。重点展示了人工智能、网络安全、元宇宙、WEB3.0、区块链、6G通信、云计算、金融科技和大数据领域应用。   
![](../Images/7f1b37ad4f6e8161efebdac2837fcd12.png)（图1：GITEX官网展示安芯网盾介绍页面）  
同时，安芯网盾受邀参与了Gitex Global 2022华为云计算峰会Huawei Cloud TechWave Summit MEA 。在峰会现场，安芯网盾正式加入华为云丝绸之路技术生态伙伴身份（Technologies Along Silk Road Alliance），将共同为丝绸之路技术生态赋能，为更广泛的海外客户群体提供安全解决方案。   
![](../Images/f4cd9e81638e800f986495fe32e72dac.png)（图2：安芯网盾正式加入华为云Technologies Along Silk Road Alliance）  
安芯网盾一直与华为也保持着紧密的生态合作。2019年9月加入华为云沃土初创生态扶持计划首批最高计划伙伴，2020年6月安芯网盾核心产品内存保护系统获得华为Stack8.0（鲲鹏）、鲲鹏云服务完成兼容性认证。一直以来，双方的技术专家多次就端点安全保护技术和实践展开交流和探讨。自2020年以来，安芯网盾也与华为一起为海外客户持续提供安全解决方案，并受到客户的一致好评。  
![](../Images/5124d53aacc1ffd8afc9bd3e523c8b9d.png)（图3：参观者在安芯网盾展台咨询）  
在展会期间，安芯网盾吸引了众多前来展会的参观者前来咨询。随着新技术的不断涌现，云业务应用的不断扩张，IT业务系统的复杂度越来越多样化。对于企业来讲，当服务器的数量不断增长、业务越复杂时，则会面临越来越多的安全挑战。安芯网盾在端点安全能力方面具有如下优势：  

能够和新型的高级威胁进行对抗。当前无论是主机环境、云环境或终端环境在内存防护层面均处于“裸漏”状态，基于内存的新型攻击手段层出不穷，包括无文件攻击、内存马攻击、缓冲区溢出攻击、ROP攻击等，而这些攻击最终都会在内存中“展现”和执行，内存是所有威胁的汇聚点，理论上守护住内存和CPU就能防御所有的威胁。通过内存保护技术可以有效应对各类威胁的发生。 

  

**可以实现真正的运行时安全保障能力**

内存安全保护是在CPU和内存指令集这个层面去做防御，可以在第一时间对威胁进行发现和检测，是实时的运行时保护，对网络攻击可以0秒响应。基于日志和流量来分析攻击过程中产生的蛛丝马迹，难以保障程序运行时安全，内存保护通过实时检测、实时响应和内存上下文关联分析等技术来构建程序运行时安全保障能力。  

 

**兼容性更强，系统资源占用更少**

内存保护产品基于内存、CPU这个层级做保护，使它的兼容性更强。因为在应用层上的防护需要做大量的适配工作，而防护越往下通用性越好，稳定性越强。   

  

**自身环境更安全，病毒无法感知**

内存保护基于硬件虚拟化技术的应用，可充分利用CPU本身的隔离机制，不容易被反检测机制发现，从而保障自身核心模块的安全能力。同时在应用层具备防篡改、认证校验、防杀保护能力。   

  
**安芯网盾推出的内存安全细分领域的主打产品内存保护系统，在系统层、内存层、应用层立体防护的主机全栈保护，为客户提供基于内存保护的一体化端点安全解决方案，填补了国内在内存安全实时检测与防御的空白，为用户提供实时的高级威胁防护能力。**  
自2019年4月成立以来，安芯网盾一直保持着超高速的发展态势，致力于内存保护技术的应用研究和创新，积累了深厚的技术能力和丰富的实践经验，已在内存安全领域取得诸多开创性成就和突破，获得了业界和客户的高度赞誉。
