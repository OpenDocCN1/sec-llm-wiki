# 智能汽车信息安全隐形冠军，「云驰未来」战略引入中电基金

近日**智能****汽车信息安全企业「云驰未来」**于近期完成新一轮**战略融资，由中电基金领投，老股东中关村前沿基金和金沙江创投跟投****，累计实现过亿融资规模****。**据悉，本轮融资主要用于汽车安全产品的技术研发和持续迭代，以及团队建设和市场拓展等方面，**航行资本提供财务顾问服务**。

「云驰未来」成立于2020年，是一家专注于自动驾驶与车联网安全领域的技术、产品与解决方案提供商。**面向自动驾驶企业及OEM****主机厂****，****提供“软硬结合、车云一体”的智能****汽车全生命周期信息安全解决方案，帮助客户建立符合法规和标准（UNECE/WP.29和ISO/SAE 21434等）要求的全生命周期信息安全管理体系，并提供产品、技术****、服务和****方案****的****落地****实施****。**

云驰未来创始人兼CEO曾剑隽原信息安全公司九州云腾CEO（被阿里收购后担任钉钉副总裁），原WatchGuard大中华区CTO。核心团队来自东软、百度、阿里、东风汽车、大唐移动等，兼具信息安全、汽车E/E架构、自动驾驶与硬件工程等能力，目前团队快速发展至超过百人规模，先后分别在北京、大连、武汉、上海、深圳等建立研发中心和分支机构。

当前智能汽车的渗透率正在不断上升，中国智能网联车出货量2020-2024年复合增长率达63.8%，远超同期全球的预期增长率14.5%。**随着汽车智能网联化进程加快，网络攻击威胁加速向车端、车联网平台蔓延，亟需加强智能网联汽车、V2X 通信网络、车联网服务平台、车联网应用程序、数据保护等****汽车信息****安全建设。**

曾剑隽向36氪表示，尽管跟传统互联网相比，当前暂时汽车受到的攻击量级还不大，同时攻击成本和难度也相对更高，但汽车安全被攻击带来后果更严峻。**除了****关系****驾驶员和乘客的人身安全，更涉及到道路行人和社会公共安全问题，同时系统级的车联网安全风险带来****的****破坏性后果****更****是灾难级的。**

“随着汽车产业在智能化网联化方向深入发展，未来汽车已逐步成为车轮上的数据中心，车载软硬件配备也变得更加复杂。今天的汽车有多达几十上百个车载控制器和大约1亿行代码，支撑自动驾驶、网联通信、人机交互等各类新兴功能的实现。与此同时，高度复杂的汽车电子电气系统、 通信网络和软件配备也为针对车辆和道路基础设施的网络攻击创造了大量的机会，带来大量的汽车安全问题。”曾剑隽说道。

**在汽车****信息****安全领域，云驰未来****重点****做了两件事：第一，为智能汽车搭建****单车可靠合规****的安全防护****系统****；第二****，基于AI和机器学习技术****构****建****车****云****一体的云端实时孪生动态****安全防护****和监测平台****。**

![](../Images/a6488392271e567353e62739d42cbce3.png)

  

 为此，「云驰未来」推出了**车联网安全中间件产品**，与车辆EEA架构和相关业务深度集成，深入ECU/DCU为各个车内的域控系统（如ADAS、座舱域、动力域、底盘域等）提供安全能力，具体包括数据加密、认证鉴权、攻击防护、入侵检测、安全审计等功能，可灵活部署于车身系统及各种车载电子控制器中，帮助实现车内基于AI算法和数据驱动的分布式安全架构。

除车联网安全中间件之外，云驰未来推出了**多款车载安全网关硬件产品**，包括智能汽车安全网关D2000和下一代智能汽车5G安全网络域控制器 L3000，可满足不同车身网络架构对高可靠网联通信、网络与数据安全的不同需求，通过构建可信安全体系架构，阻止外部入侵、防止非法控车、保护数据安全和隐私数据，全面保障车载网络安全。

在合规咨询和技术工具方面，**「****云驰未来****」****研发了高度自动化****的****车辆信息安全威胁分析与风险评估的TARA工具——****i****nTARA**，可以由此建立信息安全需求及资产库，完成整车安全方案，构建包括整车密钥/证书部署管理、车云认证、OTA升级安全、远程诊断安全、车内安全通信等防护体系。

在单车纵深防御安全体系基础上，云驰未来还构建了**云端的安全运营中心——****云驰****智云VSOC**，可提供云、管、端协同的车云一体信息安全能力，基于侵入式和非侵入式两种方案，构建车辆安全的实时数字孪生平台，提供态势感知、应急处理、威胁预警等安全运营能力，以及车队管理、资产管理、流量管理、安全OTA管理等业务服务能力，实现汽车网络信息安全可见、可管、可控、可信。

曾剑隽表示，目前**「****云驰未来****」****近一半的业务都来自于L4自动驾驶****的商业场景落地**，**已****覆盖****百度****Apollo****、京东****物流****、图森未来、文远知行、阿里小蛮驴、滴滴等****业界头部的****自动驾驶公司。**

这些业务实践和技术积累为云驰未来进入主机厂产线打下了坚实的基础。目前，**云驰已经陆续接到了传统车企的量产车型项目，成为宝马、东风、金龙、福田等多家****主机厂的信息安全供应商****。**据悉，云驰未来去年已实现数千万级营收。

2021年8月12日，工业和信息化部发布《关于加强智能网联汽车生产企业及产品准入管理的意见》，提出加强数据和网络安全管理、规范软件在线升级和加强产品管理等要求。其中在加强数据和网络安全管理的部分，强调企业需要具备保障汽车电子电气系统、组件和功能免受网络威胁的技术措施，具备汽车网络安全风险监测、网络安全缺陷和漏洞等发现和处置技术条件，确保车辆及其功能处于被保护的状态，保障车辆安全运行等具体要求。

**曾剑隽表示，随着国内智能网联车辆渗透率的进一步攀升，汽车行业相关****的****整车信息安全****政策法规、****技术要求和管理标准也已经在****落地的****路上****，特别是国家整车信息安全强标预计明年7月份正式发布，****汽车****信息****安全行业将迎来****快速发展的窗口期****，这也是云驰未来的机会所在。**

航行资本表示，智能网联汽车飞速发展，技术、政策和事件正在共同驱动汽车信息安全市场发生变革性颠覆。
