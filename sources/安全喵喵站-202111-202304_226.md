**01 ****资本市场动态**![](../Images/53899b1ea4092ab86aa1516b76a2685f.png)**融资信息**（按国内外/金额排序）  
       

  

**1. 安般科技：宣布获得超1亿元的A轮融资**  

投资方为硅港资本和上海东方证券创新投资有限公司联合领投，名川资本和中南资本跟投。

**主要业务（模糊测试）：**

安般科技是一家企业安全服务商，为企业设计的人工智能模糊测试的提供者和开发者。该公司的模糊识别技术可以识别应用程序和系统中的漏洞，为客户提供定制的网络安全解决方案。

  

**2. 薮猫科技：宣布获得A轮融资，金额暂未披露**  

投资方为源码资本领投，红华繁星网安天使基金及老股东云九资本跟投。

**主要业务（数据安全）：**

薮猫科技依托专业安全团队的硬核技术，创新研发青骓 DDR、飒露紫 ADR 等系列威胁检测与响应（DR）产品，打造「终端 x 流量」全链路、纵深防护体系。青骓 DDR（Data Detection and Response）是基于智能内容识别引擎、驱动级的终端应用事件监控、泄密风险检测等技术而打造的终端数据检测与响应产品。而飒露紫 ADR（API Detection and Response），作为 API 安全检测与响应产品，是基于高性能流量采集引擎及多维检测策略，对业务应用流量，进行动态画像和全场景式流量清洗，从而发现 API 攻击事件、业务风险及行为异常等安全问题。

  

**3. TXOne Networks：宣布获得7000万美元的B轮融资**

投资方为TGVest Capital领投，联发科、塔雅创投、中银资本国际、JAFCO亚洲、玉石创投、辛普乐科技、KAiA资本、群创创投、Ash Tower有限公司和CHT证券跟投。

**主要业务（中国台湾 · 物联网安全）：**

旨在保护用户免受网络攻击的网络安全解决方案提供商。该公司为工业物联网环境开发工业控制系统(ICS)，包括智能制造、智能城市和智能能源，使行业能够保护其系统免受网络威胁。

  

**4\. ThreatX：宣布获得3000万美元的B轮投资**

投资方为Harbert Growth Partners领投，Vistara Growth、.406 Ventures、Grotech Ventures、Access Venture Partners和其他未披露的投资者跟投。

**主要业务（美 · 抗DDoS）：**

开发基于云的web应用程序和应用程序编程接口(API)保护(WAAP++)平台，旨在提供保护、bot管理和分布式拒绝服务(DDoS)缓解。该公司的平台提供网络安全产品和服务，有助于全面管理和通信功能，同时利用云优化的基础设施，使黑客远离网络，使商业组织能够打击恶意事件和有效管理风险。

  

****5. SynSaber：宣布获得1300万美元的A轮融资****  

投资方为SYN Ventures领投，Rally Ventures和Cyber Mentor Fund跟投。  

**主要业务（美 · 威胁检测）：**

开发网络安全应用程序，用于感知网络威胁和安全漏洞。该公司的应用程序提供了一个易于部署的可视化界面，以及一个可伸缩的安全数据收集和检测栈，从位于现有服务器上的一个小容器到专门为该任务构建的硬件，使企业和组织能够检测威胁并从根本上减轻它们。

  

**6. dWallet Labs：宣布获得500万美元的种子融资**

投资方为Amplify Partners和其他12家投资者。

**主要业务（以色列 · 零信任）：**

一家网络安全公司的运营商，打算专注于区块链技术。该公司致力于在Odsy网络的基础上构建零信任的访问控制方案，通过添加一个完全分散的动态和有状态访问控制层，使公司能够改变数字资产的存储、使用、访问和连接到现实世界的方式。

**IPO & 并购**（8.15-8.21）  
       

  

**1\. Darktrace（英 · 安全自动化）：该公司将被Thoma Bravo收购，金额未披露**

**主要业务（英 · 安全自动化）：**

Darktrace旨在网络安全领域大规模部署AI。它是自主学习AI的先驱，也是自主响应技术的前沿。Darktrace的平台使用机器学习和AI算法来消除各种数字领域的网络威胁，包括云和网络、物联网和工业控制系统。从地理上看，它的大部分收入来自美国和加拿大，在英国也有业务。![](../Images/55cdfdc0b29dab1177392c55dd8337c9.png)  
  
**募资事件**（8.15-8.21)  
       

  

**1\. 上海普陀区：拟设立20亿网络安全基金**

**主要投向：**

普陀区政府公布了《普陀区加快发展网络安全产业实施意见》作为专项扶持政策推动园区建设。政府牵头引导社会资本发起成立不低于20亿元的网络安全产业基金，产融结合加速推动产业发展壮大。![](../Images/1c07f6f7fb16f3433f8eb8cdc86cb376.png)

![](../Images/53899b1ea4092ab86aa1516b76a2685f.png)**行业动向**（8.15\-8.21）  
       

  

**1.**** 飞天诚信**自主研发的**智能POS终端F210**通过中国银联支付终端安全认证检测，正式获得《中国银联支付终端设备安全认证》证书。  
**2\. **中国网络安全产业联盟（CCIA）公布了经由第三方评测机构检测，符合《实践指南》标准的 Windows 7 操作系统安全加固防护产品目录（第1批，共2款），**安天智甲终端防御系统**入选。  
**3\. **工业和信息化部密码应用研究中心开展了首届全国商用密码应用优秀案例征集活动，**卫士通“数字政府（政务云）平台密码应用”**成功入选首届全国商用密码应用优秀案例。  
**4\. **在2022（第七届）全国民航‘互联网+’智慧机场建设发展高峰会中，作为本届大会的技术支持单位，**启明星辰**应邀出席并荣获“5G互联网+智慧机场最佳创新方案”奖。  
  
**5\. **工信部公示2022年大数据产业发展试点示范项目名单，**美亚柏科控股子公司美亚亿安、奇安信**等25家厂商项目成功入选。  
**6.** **安恒云-天池云安全管理平台**再次完成升级，致力于向用户提供完善、灵活、易用的云安全体验。  
**7\. **广东省人民政府主办的“粤盾-2022”广东省数字政府网络安全实战攻防演练活动在广州闭幕。**绿盟科技**荣获二等奖；**中孚信息**荣获优秀攻击队伍三等奖；**任子行**荣获优秀白帽子团队奖第一名。  
**8\. 奇安信集团**与**数字广东公司**签署战略合作协议，正式达成战略合作。  
  
**9\. 格尔软件**与**银联商务**在上海签署战略合作框架协议。  
**10\. 亚信安全信舷防毒墙AISEDGE**全面升级。全新一代防毒墙通过集成“梦蝶+怒狮+魔龙”三大自研引擎，基于文件检测、DPI流量特征检测、威胁情报等优势能力，实现“边界勒索治理”和“边界挖矿治理”。  
**11\. **由工业和信息化部密码应用研究中心组织开展的“首届全国商用密码应用优秀案例征集”获奖名单公布。**腾讯云、卫士通、安恒信息、数字认证等15家厂商**的申报案例入选。  
**12\. 深信服**桌面云aDesk发布5.5.3新版本。![](../Images/55cdfdc0b29dab1177392c55dd8337c9.png)

  

**政策动向**（8.15\-8.21）  
         
中宣部举行“中国这十年”系列主题新闻发布会，**中央网信办副主任、国家网信办副主任、新闻发言人牛一兵**表示，掌控网络意识形态主导权，就是守护国家的主权和政权。全国网信系统把网络意识形态工作作为意识形态工作的重中之重，加强党对网络意识形态工作的全面领导，切实增强履职尽责的责任感使命感紧迫感，严格落实网络意识形态工作责任制，有力维护意识形态安全和政治安全。  
**中央网信办网络安全协调局局长孙蔚敏**在新时代网络强国建设成发布会上表示，将指导督促滴滴公司切实做好相应整改工作，消除安全风险隐患。  
**全国信息安全标准化技术委员会**发布《关于下达2022年第二批网络安全推荐性国家标准计划的通知》。  
**上海市通信管理局**发布了关于通信网络安全防护管理情况的通报（2022年7月）。常游网络科技、零动数码科技等6家单位存在未落实通信网络安全防护管理责任被通报。  
在黑客大会 DEF CON 上与记者 Kim Zetter 的对话中，**白宫国家网络主管 Chris Inglis** 发言：网络安全的前进方向是防御、明确的角色和责任以及对弹性和稳健性的投资。  
**越南政府**发布法令，要求外国科技公司将用户数据存储在越南本土，同时要求这些公司在当地设办事处。这项法令将于2022年10月1日开始生效。![](../Images/55cdfdc0b29dab1177392c55dd8337c9.png)
