薮猫科技完成A轮融资，源码领投，成立1年融资上亿元

原文：http://mp.weixin.qq.com/s?__biz=MzkzNjE5NjQ4Mw==&mid=2247522727&idx=1&sn=3f19c5ad57e461e74b16a8c4e7a77008&chksm=c2a0b94bf5d7305df362211c90aeea061d3d9b3757bed4fc2d0d8f98d6f88678fd790f3a54e6&scene=27#wechat_redirect

近日，数据安全领域的创新型企业薮猫科技正式宣布完成 A 轮融资。本轮融资由源码资本领投，红华繁星网安天使基金及老股东云九资本跟投。至此，加上三一集团、深涧资本等老股东在内，公司已累计获得上亿元融资。本轮融资将用于加大公司在研发创新、人才建设和市场拓展的投入，持续深耕数据安全领域的技术与实践，为企业提供下一代数据安全解决方案。



随着数字经济的快速发展，数据的战略价值已经得到了个人、机构、企业乃至国家的重视。然而战略的重视，也意味着风险性的提高，所以在近些年我们经常能够看到数据作为企业、国家的重要资产，一边在创造价值，一边却不断发生大规模的数据泄露事件，给全社会造成了巨大的损失。因此，我们坚信数据安全是数字经济发展不可或缺的环节。


作为网络安全 & 数据安全领域的创新型企业，薮猫科技成立于 2021 年中。在过去一年的时间里，薮猫科技聚焦下一代数据安全场景，潜心探索，获得了众多突破性进展。



薮猫科技依托专业安全团队的硬核技术，创新研发青骓 DDR、飒露紫 ADR 等系列威胁检测与响应（DR）产品，打造「终端 x 流量」全链路、纵深防护体系。


青骓 DDR（Data Detection and Response）是基于智能内容识别引擎、驱动级的终端应用事件监控、泄密风险检测等技术而打造的终端数据检测与响应产品。而飒露紫 ADR（API Detection and Response），作为 API 安全检测与响应产品，是基于高性能流量采集引擎及多维检测策略，对业务应用流量，进行动态画像和全场景式流量清洗，从而发现 API 攻击事件、业务风险及行为异常等安全问题。


同时，结合渗透测试、安全审计、数据咨询等专业服务，薮猫科技为企业提供全方位的下一代数据安全解决方案，目前已在金融、新经济、政府、运营商、制造、电商互联网、能源等多行业得以应用与落地。


截至目前，总融资金额累计上亿，这对创立刚满一年的薮猫科技来说，无疑是资本市场对公司实力与发展前景的莫大认可与肯定。
