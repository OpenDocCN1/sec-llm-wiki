为助力企业安全负责人、渠道合作伙伴和安全从业者及时了解网安行业的新兴赛道及前沿产品，在项目产品选型时，高效检索细分赛道和代表性厂商，斯元商业咨询基于网安最新技术动态及长期行业调研数据，推出了**「Emerging Technology Vendor Index · 网安新兴赛道厂商速查指南」报告**（以下简称「速查指南」），并持续更新迭代。此前，斯元商业咨询已正式发布[**「速查指南」第3版**](http://mp.weixin.qq.com/s?__biz=MzkzNjE5NjQ4Mw==&mid=2247519969&idx=1&sn=2461aee354e1c9829f9f857b9a4081e0&chksm=c2a0ae0df5d7271bf41e3f36e2aa979f0dd2b8a2cdb1f182ac537cb4a209516b430a95e47b6b&scene=21#wechat_redirect)。

  

第3版「速查指南」共发布127个新兴产品赛道，国内外厂商收录1000+，是迄今国内网络安全行业发展和赛道分析收录最全的机构报告。

  

![](../Images/afe908d1aa4dfd62f7bf41d1d5ae9899.png)

  

**基于目前网安技术与产品最新的发展动态，斯元商业咨询现面向国内安全厂商正式启动第4版调研工作。****本轮调研在第3版的127个新兴产品赛道基础上，新增17个产品赛道，同时，大幅度优化删减了300+技术赛道聚焦不足的国内厂商，新增收录200+国际创新技术厂商，也进一步提升厂商收录的技术要求。**

  

**新增产品赛道概览**

1.IT供应商风险管理  IT Vendor Risk Management2.身份目录即服务  Directory as a Service3.基于风险的身份验证  Risk-Based Authentication4.身份威胁检测和响应  Identity Threat Detection and Response5.Kubernetes安全配置管理  Kubernetes Security Posture Management6.数据安全即服务  Data Security as a Service7.数据安全配置管理  Data Security Posture Management8.格式保留加密  Format-Preserving Encryption9.应用防护/加固  Application Shielding10.安全众测平台  Crowdsourced Software Security Testing Platforms11.关键业务应用安全  Business-Critical Application Security12.自带PC办公安全  BYOPC Security13.主机入侵检测系统  Host-based Intrusion Detection System14.IP情报  IP Intelligence15.第三方风险管理  Third-party Risk Management16.内部（人员）风险管理  Insider Risk Management17.网络安全测试与保障  Cybersecurity Test & Assurance
