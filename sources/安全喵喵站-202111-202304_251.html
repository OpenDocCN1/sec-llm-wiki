全球科技竞争格局正加速重构，技术竞争与经济博弈，导致了断供风险的客观存在。如何构建安全可控的网络安全科技供应链，是中国众多关键基础设施企业亟需思考的问题。


在过去数十年的科技发展中，国内甲方企业已高度嵌入全球供应链体系。根据斯元商业咨询发布的「网络安全科技供应链报告：厂商成分分析及国产化替代指南 · Cyber Security Technology Supply Chain Report: Vendor Composition Analysis and Localization-Substitution Guide」，当前约有125家国际网安厂商在国内开展业务，涉及91个技术产品类型。




在国家政策支持及IT技术加速创新的双重驱动下，国内网安行业日新月异，新兴赛道不断涌现，技术快速推陈出新，不仅与国际安全技术发展同步接轨，也更能准确理解国内的安全发展态势、监管要求和安全需求，为客户提供更契合实际业务场景的产品和本地化支持。


哪些国货值得买？喵酱将持续选取热门赛道，为大家推荐得到客户和行业认可的国产化臻选厂商。本篇为大家介绍的是“数据安全”赛道，一起来看看观安信息的数据库安全审计系统吧。






国货臻选


赛道名称：数据安全 Data Security

国产化臻选：观安信息

国际厂商：Imperva


这是一款怎样的产品？

观安观智数据库安全审计系统是一款集数据库活动实时监测与安全分析为一体的新一代数据库审计产品。它在充分吸收传统数据库审计系统优势的基础上，结合大数据安全技术，提供了海量的审计日志存储和高性能的日志检索能力，可针对业务环境下的数据库操作行为进行细粒度审计，当出现数据库高危操作和非法入侵行为时，能够及时告警。为降低企业数据资产损失，满足合规要求，提供强有力的安全保障。


对标国际厂商，差异化优势如何体现？

Imperva成立于 2002 年，是网络安全解决方案的专业提供商，能够在云端和本地对业务关键数据和应用程序提供保护，拥有稳定的发展和成功历史。


在数据库安全方面，Imperva 提供完整全面的数据库审计日志供审计人员使用，针对未授权的访问和恶意攻击进行实时警告和阻拦，内置可自定义的各种报告和分析工具。同时具有丰富的数据库安全功能和专业的数据库安全支持团队进行定期的数据库安全信息更新，评估工具以及数据库用户权限管理。


相较于Imperva厂商，观安信息的解决方案更具弹性，能够快速响应市场需求。在数据库安全防护方面具备精准度和更加广泛的安全覆盖，适应国内市场需求及法律法规和相关行业标准，为客户提供最优的个性化解决方案。


（1）全面支持信创环境部署和协议解析

在数据库协议上，系统除了支持关系型、非关系型、大数据组件等多种类型的数据库；还支持南大通用、人大金仓、神州通用、达梦、Tidb、Oceanbase主流国产数据库。

在运行环境上，除了主流的Centos，还支持中标麒麟、银河麒麟、统信等国产操作系统，适配了兆芯、飞腾、鲲鹏、申威等处理器平台，并取得互认证书。



（2）分布式日志存储和检索

系统采用大数据存储系统，支持大容量实时检索性能，支持水平扩展分布式节点。系统可通过各种条件自由组合的形式进行日志检索。在海量日志记录中，检索效率每秒可以达到千万级。如：在一亿条审计日志中，检索一条SQL语句最多不超过10s。在高性能检索引擎的加持下，可帮助安全管理员做出精准响应，进行有效的追溯和定责。


（3）成熟的上云方案

基于云市场（公有云、私有云）市场的环境特性，开发了更适合云环境的版本。能够对接云控制台，实现云市场用户的自主购买、自主创建审计实例、自主启停审计服务、自动化部署功能。目前支持通过K8S或OpenStack实现镜像化自动部署。


请谈谈现阶段国产化取得的进展

“十四五”规划和2035年远景目标中，科技创新、自主创新等创新驱动发展战略被提升到前所未有的高度，“加快推进国产自主可控替代计划，构建安全可靠的信息技术体系”成为业界共识。新一代的国产化安全能力要从自主、可控两个方面来共同推进。

目前，观安信息已与统信、麒麟等主流国产操作系统以及飞腾、鲲鹏、兆芯等国产CPU完成兼容性认证。


目前在哪些行业得到应用？

运营商行业、金融行业、能源行业、政务行业







关于观安信息


观安信息是一家提供大数据+泛安全产品与服务的高新技术企业。公司聚焦数据安全、网络空间安全、5G安全、人工智能安全、工业互联网安全及公共安全等核心方向，为运营商、政府、金融、电力、公安、医疗等行业用户提供全面的信息安全解决方案。被认定为国家重大活动网络安全保卫技术支持单位、工信部专精特新“小巨人”企业、5G创新企业、上海市高新技术企业。
