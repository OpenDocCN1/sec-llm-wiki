**国货臻选**

  

**赛道名称：**工控靶场 Cyber Range for ICS/OT Security

**国货臻选：**木链科技

**国际厂商：**Cyberbit

  

**这是一款怎样的产品？**

工控网络安全靶场是木链科技自主研发的集“仿真、实训、竞赛、演练、科研”为一体的，面向企业、政府、高校、关键信息基础设施单位等客户推出的工控安全孪生演兵场，可帮助用户解决无法在真实环境中对复杂大规模异构网络和用户进行逼真模拟测试以及风险评估等问题。

  

工控网络安全靶场通过虚拟化、虚实结合组网等技术，能够低成本、高效率地仿真出接近真实的工控网络环境和企业网络环境，同时还具备可视化拓扑组网引擎，丰富的靶标资源，开放的第三方接入支撑，多样化的赛事支持，定制化的教学课程，创新性的高阶安全工具等功能。

  

用户可依托工控网络安全靶场进行网络体系规划验证、人才教学培训、能力测试评估、安全攻防演练、安全赛事承建、产品研发试验、产品安全性测试、前沿技术评估等任务。

![](../Images/134e442b36f3e860e2fe6bd926131a4b.png)

  

**对标国际厂商，差异化优势如何体现？**

Cyberbit成立于2015年，是全球领先的网络靶场训练与仿真平台提供商，其目标是利用尖端的网络安全技术来满足政府和军事组织的严格要求。

  

Cyberbit网络靶场提供了一个集成的产品组合，用于管理从检测到遏制，从IT、OT到IoT攻击面的整个事件响应过程，并可用于在超现实仿真环境中训练安全人员。其Cyberbit Cloud Range平台创造复刻客户SOC的沉浸式环境，可以准确模拟客户网络拓扑、安全攻击以及正常和恶意流量，并通过独特方式结合高级模拟技术、全面实训功能满足各种实训课程需求。

  

相比于Cyberbit厂商，木链科技的工业互联网安全属性更强，并且以工控靶场平台为基座，能帮助客户解决转型升级过程中遇到的复杂安全问题。

  

首先，木链科技工控靶场聚焦工控网络安全结合传统网络安全，行业属性突出。靶场通过搭建多样化高仿真环境，构建复杂攻防剧本，复现经典漏洞场景，采集全方位攻防数据，评估多维度能力指标等，可应用于教学培训、攻防演练、安全竞赛、产品测试等场景，满足用户基本诉求。此外，靶场还可针对军工、电力能源、钢铁、智能制造等细分行业用户的个性化诉求提供专业定制化开发服务，保障用户能够构建充分满足其需求的测试环境。

  

其次，木链科技工控靶场构建了专业的、高并发的、高可靠的底层平台和架构，可满足用户大规模应用需求。同时，靶场还具备高开放性和灵活性，强自主性和拓展性等特点，可不断融合云计算、数字孪生、固件分析等新型技术，亦可逐步实现跨平台、跨地域的各类资源互联互通共享。在完善靶场生态的同时，能更好满足用户逐渐成长和多元的建设需求，提升用户对靶场的使用效能和体验感。

  

其三，木链科技自建星期五安全研究团队，在协议解析、漏洞挖掘、固件分析、仿真技术等方向深入研究，并将其成果赋能于靶标构建、场景搭建、案例复现、赛题设置、课程培训、数据采集等重要环节，持续提升靶场价值。同时木链科技配以专业安全服务团队，针对不同客户不同层次的安全能力和需求“量体裁衣”，提供覆盖全业务流程和生命周期的顾问式服务，帮助企业实现安全投入的正向产出，真正激发业务生产价值。

  

最后，木链科技工控靶场实现了国产化适配，支持统信、麒麟等主流国产操作系统，并集合了木链科技全系自研产品，如工控安全审计平台、工控安全防火墙、工业安全综合管理平台等，构建起自主可控的木链工控网络生态。

  

**请谈谈现阶段国产化取得的进展。**

木链科技认为新一代的国产化安全能力要从自主、可控两个方面来共同推进。自主是实现核心技术、关键零部件、各类软件的自研、自造。可控则是实现信息安全的重要目标。

  

完善的生态链是国产化战略进程、国产化产品应用、国产化难点攻克的有效推手，这就需要产业链上下游共同努力并历经市场的不断检验。木链科技工控网络安全靶场已与统信、银河麒麟等主流国产操作系统完成兼容性认证。而海光、飞腾、华为等生态合作联盟中也均能找到木链科技的身影。

  

**目前在哪些行业得到应用？**

国防军工、电力能源、教育科研
