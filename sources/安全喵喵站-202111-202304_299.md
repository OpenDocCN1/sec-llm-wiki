![](../Images/470fb8d3fbe71484de5edf25288435b8.png)

  

「网络安全科技供应链报告：厂商成分分析及国产化替代指南」（Cyber Security Technology Supply Chain Report : Vendor Composition Analysis and Localization-Substitution Guide）调研体验版为斯元商业咨询基于网安行业最新技术动态及长期行业调研数据，对当前在国内有业务落地、产品/方案已被国内企事业单位采购使用的全球及中国港澳台地区的主流网络安全科技供应链厂商进行的系统梳理，**助力国内广大关键基础设施及企事业单位的合规监管、安全、运营、采购等相关部门负责人及时了解供应链厂商基本成分信息与技术产品组成，以及国产化替代可选项，为合规梳理、安全体系建设和技术选型等环节提供决策支撑。**

  

本报告属于斯元商业咨询Cyber Security Billboard系列报告之一。
