01 资本市场动态
融资信息（按国内外/金额排序）

       


1. 双湃智安：宣布完成数千万Pre-A轮融资

本轮融资由创东方领投。

主要业务（工业互联网安全）：

双湃智安是一家工业互联网安全服务商，致力于保护数字化转型时代下工业资产、运营和人员免受网络安全威胁，凭借超过15年的网络安全和工业领域专业知识和应用经验，将成熟的网络安全技术和工业技术结合起来，最大限度地提高生产力、可靠性和安全性。


2. 边界无限：宣布完成超千万元级别天使轮融资

本轮融资投资方为初心资本。

主要业务（RASP）：

边界无限BoundaryX是一家提供全链路云安全防护产品和顶级的攻防体系建设的网络安全企业，旗下的全栈式云安全防护系统靖云甲·RASP可以细粒度构建应用资产，提供资产关联能力，有效防御未知漏洞威胁，全方位保护应用安全。它采用独特采样决策架构，保障应用安全“快准稳”。此外，基于云原生场景进行的顶层设计，使得靖云甲·RASP可以完美契合云上安全需求，支持容器化和K8S部署，轻松解决业务爆发式增长、实例突增带来的安全防护同步问题。


3. Semperis：宣布筹集了超过2亿美元的C轮融资

由 KKR 领投，十一个风险投资公司、Paladin Capital Group 参投、Atrium Health 战略基金、Tech Pioneers Fund 以及包括 Insight Partners 在内的现有投资者。

主要业务（美 · 身份安全）：

Semperis 确保关键企业目录服务的完整性和可用性，并将恢复时间缩短 90%。Semperis 的专利技术专为保护混合 Active Directory 环境而构建，可保护超过 5000 万个身份免受网络攻击、数据泄露和操作错误的影响。世界领先的组织信任 Semperis 发现目录漏洞，拦截正在进行的网络攻击，并从勒索软件和其他数据完整性紧急情况中快速恢复。Semperis 总部位于新泽西州霍博肯，在国际上开展业务，其研发团队分布在美国、加拿大和以色列。


4. Tidelift：宣布已筹集2700万美元C轮融资

由Dorilton Ventures 领投。

主要业务（美 · 开源供应链安全）：

Tidelift 的开源管理解决方案 Tidelift 订阅为企业提供了一种工具来创建、跟踪和管理已批准的开源组件目录，从而避免在其环境中使用不安全的组件。Tidelift 作为市场解决方案的关键区别之一是该组织与开源项目维护者的合作伙伴关系。


5. Autocrypt：宣布在B轮融资中筹集了2550万美元

投资方为Korea Asset Investment Securities、Ulmus Investment、BSK Investment、Shinhan Venture Investments、JB Asset Management、STIC Ventures、Pathfinder H 和 Hyundai Venture Investment。

主要业务（韩 · 车载系统安全）：

该公司的车载系统安全解决方案中添加了 Security Analyzer 和 Security Fuzzer。Security Analyzer 是一个基于 SBOM 的软件漏洞分析平台，在整个生命周期保护车辆软件，而 Security Fuzzer 通过智能模糊测试有效地检测软件缺陷。这两种工具对于当今日益面向软件的 E/E 架构来说都是必不可少的。


6. Code Ocean：宣布获得1650万美元B轮融资

投资方为Battery Ventures和微软风险投资基金M12共同领投。

主要业务（美 · 云计算平台）：

Code Ocean是一个美国云领域计算平台，成立于2016年，所开发的数字实验室为计算科学家提供了一个安全的空间，以便在客户的私有云中自动化、复制、共享和研究，并保证跨学科研究的完全可重复性。该平台能够为从事生物学、生物制药、化学、基因组学和计算科学新兴领域(如人工智能驱动的药物研发)的研究人员提供帮助。


7. Nisos：宣布获得1500万美元的B轮融资

由全球网络投资者Paladin Capital Group以及现有投资者Columbia Capital和 Skylab Capital 领投。

主要业务（美 · 威胁情报）：

Nisos的服务使安全、情报和信任与安全团队能够利用为其需求量身定制的世界级情报能力。Nisos将强大的数据收集与对对抗性思维方式的深刻理解相结合，提供更智能的防御和更有效的应对高级网络攻击、虚假信息和数字平台滥用的响应。


8. ShardSecure：宣布获得1100万美元的A轮融资

本轮融资由 Grotech Ventures 领投，Gula Tech Adventures 和 KPMG LLP 以及现有投资者 Tom Noonan、EPIC Ventures 和 Industrifonden 参投。

主要业务（美 · 云安全）：

ShardSecure 由联合创始人兼首席执行官 Bob Lam 领导，是 Microshard 技术的发明者，该技术可减轻云中的数据安全和隐私风险。Microshard 流程用于粉碎、混合和分发数据，使数据变得难以理解，对攻击者没有任何价值，从而降低了数据泄露的风险。Microshard 技术的主要创新之一是它的自我修复数据，它可以逆转未经授权的数据删除和对静止数据的篡改（包括勒索软件）。虚拟集群支持集群内和多个集群之间的高可用性和故障转移功能，以帮助确保关键的静态数据保持安全和可用。ShardSecure 还通过将 Microshard 数据分发到多个客户提供的存储位置的方法以及类似 RAID-5 的能力来重新创建受存储服务中断影响的数据，从而支持业务连续性。这种方法可以防止数据丢失的风险，并允许业务运营在中断期间继续不受影响。


9. MazeBolt Technologies：获得1000万美元的现有股东股权融资

投资方暂未披露。

主要业务（以色列 · 抗DDoS）：

该公司的技术支持将 DDoS 缓解从需要被动手动恢复转变为几乎完美的自动缓解任何面向 Web 的网络的所有 DDoS 攻击，无论其使用的 DDoS 缓解平台如何。


10. Red Access：获得600万美元的种子轮投资

投资方由 Elron Ventures 和 11-11 Ventures 领投。

主要业务（以色列 · 安全浏览）：

Red Access承诺为企业客户提供“保护跨任何浏览器、应用程序和设备的每个网络会话”的技术。随着平台的公开可用性，Red Access 正在走出阴影，无需安装任何端点代理或修改工作习惯即可提供针对威胁的保护。Red Access 表示，其平台可全面覆盖和控制最新的文件、身份和数据驱动的攻击——包括网络钓鱼和勒索软件。


11. LimaCharlie：宣布获得545万美元的种子融资
本轮融资由 Susa Ventures 领投，施乐创投、CoFound Partners、Long Journey Ventures、Sands Capital、StoneMill Ventures 以及现有投资者 Lytical Ventures 参投。
主要业务（美 · 基础设施安全）：
LimaCharlie 成立于 2018 年，以大规模构建的方式按需提供安全工具和基础设施，API 优先。LimaCharlie 允许任何安全团队（无论规模或预算）开始使用强大的工具和基础架构，从而使安全基础架构的访问民主化。LimaCharlie 使组织能够检测和响应威胁、自动化流程、减少他们使用的供应商数量，并使其安全运营面向未来。该公司与 MSSP、DFIR 公司和企业的 100 多个安全工程团队建立了关系，包括 Carta、Snap Inc.、Soteria 和 Chainalysis。

12. XONA：宣布获得720万美元A轮融资
由DataTribe Opportunities Fund牵头，TFX Capital和个人投资者参与其中。
主要业务（美 · 身份安全）：
XONA 成立于 2017 年，XONA 支持专为运营技术 (OT) 和其他关键基础设施系统构建的无摩擦用户访问。XONA 专有的协议和零信任架构可以在几分钟内完成配置，立即消除常见的攻击媒介，同时为授权用户提供从任何位置或设备对操作技术的无缝和安全控制。凭借集成的 MFA、用户到资产访问控制、用户会话分析和自动视频录制，XONA 是连接网络物理世界的单一安全门户，使关键操作能够在任何地方以完全的信任进行。

13. ORNA：宣布获得1,065,000美元的种子轮超额认购
投资方为WGG Capital Canada 领投。
主要业务（加拿大 · SOAR）：
ORNA由经验丰富的业内人士Logan Wolfe、Jana Krioukov和Martyn Gill创立并领导，是一个人工智能驱动的安全编排、自动化和响应 (SOAR) 平台，适用于检测网络攻击并使用人工智能指导响应、报告、通过创新的实时协作环境进行合规和预防工作。

14. Cribl：宣布完成D轮融资
由Tiger Global Management领投，Cribl的总融资额达到4亿美元。
主要业务（美 · 数据安全）：

Cribl 大约一半的业务都在安全领域，该公司的数据路由功能使客户能够更轻松地将数据加载到他们的安全信息和事件管理 (SIEM) 以及用户和实体行为分析 (UEBA) 中，工具。Cribl 可以通过消除噪音、浪费和对他们来说不是特别感兴趣的数据来帮助安全客户控制成本。

2. VMware Inc：被博通以610亿美元收购

主要业务（美 · 云基础架构和移动商务解决方案）：

VMware总部位于美国加州，是全球云基础架构和移动商务解决方案厂商，提供基于VMware的解决方案，企业通过数据中心改造和公有云整合业务，借助企业安全转型维系客户信任，实现任意云端和设备上运行、管理、连接及保护任意应用。

02 网安行业动态
行业动向（5.22-5.29）

       


1. 默安科技子公司火线云科技推出业内首个集成AI蓝军的SaaS XDR安全平台，助力广大政企用户全面提升安全事件的检测和响应能力，构建智能化的安全运营体系。

2. 纬德信息获得广州市黄埔区2021年度瞪羚企业和瞪羚培育企业认定。

3. 中国软件评测中心组织的数据安全产业专家委员会正式成立，深信服成为首批数据安全产业专家委员会成员单位。

4. 卫士通“盛趣游戏个人信息安全合规服务项目”入选2022年首批数据安全产业典型应用案例。

5. 天融信、安恒信息、三六零、启明星辰等16家厂商荣获CNNVD 2021年度优秀技术支撑单位称号。安恒信息、启明星辰等6家厂商获得CNNVD 2021年度特殊贡献奖。

6. 天融信科技集团顺利通过了通信行业“系统集成领域”、“运维服务领域”企业信用等级评价，获得AAA级评级认定。

7. 安恒信息发布新版安恒云。

8. IDC发布了《IDC Innovators: 中国DevSecOps技术，2022》报告，悬镜安全被评选为IDC中国DevSecOps技术创新者。

9. IDC正式发布《中国政务云云安全市场分析》报告，数字认证、卫士通、吉大正元等入选专业安全厂商名单。

10. 数字认证顺利通过软件开发能力成熟度认证CMMI 5评估，并获得权威机构颁发的CMMI 5级证书。

11. 亚信安全信磐堡垒机AISIFORTV4.0.3正式发布，并新增主机防绕行、安全网盘、零信任远程运维三大应用场景，资产帐号管理等七项功能特性。

12. 迪普科技正式加入麒麟软件生态圈，将共同打造自主创新的安全防护产品，推动国产化网信产业生态建设，为用户提供更具价值的安全创新解决方案。

13. 绿盟科技推出城轨云网络安全解决方案，旨在打造“一个中心支撑下的三重保障体系”。


政策动向（5.22-5.29）

证监会机构部下发的《机构监管情况通报》中，将近期发生的多起信息系统安全事件案例作为重点进行了专门通报。

最高人民法院发布《最高人民法院关于加强区块链司法应用的意见》。

中共中央办公厅、国务院办公厅印发了《关于推进实施国家文化数字化战略的意见》。
