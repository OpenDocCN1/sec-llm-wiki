# 融资发布｜物盾安全完成数千万元Pre-A轮融资

2022年5月，**上海物盾信息科技有限公司**（以下简称：物盾安全）成功完成Pre-A轮数千万元的融资，本轮融资由**奇安投资领投，老股东源渡创投跟投**。

  

![](../Images/d0204fc06974223b7a5799fd848030cd.png)

  

IDC数据显示，2021年中国网络安全相关支出有望达到102.6亿美元。预计到2025年，中国网络安全支出规模将达214.6亿美元。在2021-2025的五年预测期内，中国网络安全相关支出将以20.5%的年复合增长率增长，增速位列全球第一。以能源、制造、公共事业等行业为代表的物联网基建改造催生出了大量的物联网安全需求，在合规与业务的双重驱动下，全球物联网安全市场发展迅猛，相应的，中国的产业侧物联网安全市场未来发展也将呈现对应的高速增长趋势。

  

  

物联网对于制造业、能源等行业的改造正在快速发生着，越来越多的物联设备接入、4G/5G等无线通讯技术的引入以及边缘计算都在快速改造当前的网络架构。传统的“网络分区、边界防护、监测审计、主机防护”安全防护理念显然已经无法适用“泛在物联网”网络边界日渐模糊的场景。

  

  

物盾安全以智能电力物联网安全为入口，聚焦**物联网边缘侧安全**领域，以**零信任**为核心理念，致力于解决“**物联网+边缘计算**”场景下的安全问题。以**物安盾零信任安全防护管理系统**为核心产品，通过边缘计算本体防护、南向终端管控、北向可信接入以及云边协同安全管理，实现工业互联网中“**最后一公里**”的安全通讯。

  

  

![](../Images/8d62d21d3a342a3eb7c30516354bfed7.png)

**物安盾零信任安全架构图**

  

截至目前，物盾安全以**在行业内领先而成熟的解决方案和产品**，与公安部、国家电网、南方电网、上海地铁等合作伙伴持续开展了多项边缘侧物联网安全关键技术研究。物盾安全通过渠道销售、生态联盟等多种方式，以开放、合作、共赢的理念与众多行业的优质伙伴建立合作关系，不断丰富应用场景，拓展市场渠道，已**连续几年营收翻倍**，成为行业内的领先者，也因此广泛获得了行业客户及投资者的关注和支持。

  

本轮融资过后，物盾安全将继续扩大对**研发、运营以及市场销售团队**的投入，加大**物安盾安全防护系统**建设，加快**产品方案**的优化与升级，又快又稳地实现运营管理的优化和业务规模的**持续高速增长！**

  

**物盾安全 CEO汤晓冬  表示：**

非常感谢投资方对物盾安全未来发展方向的认可，尤其是在疫情这一特殊时期，此次融资也进一步帮助坚定了公司及团队对未来发展的信心。物盾安全从成立之初一直致力于物联网安全产品的研发，特别是针对高度场景化的边缘计算安全解决方案是我们的长远发展战略。网络安全的目的是服务业务需求，赋能业务发展，我们将继续围绕着客户业务纬度进行产品研发并提供整体解决方案。此次融资，除了在研发方面加大投入之外也会加强市场方面的投入，扩大产品优势的同时形成行业及区域的布局和覆盖。

  

**奇安投资 投资VP周竞驰  表示：**

物联网的应用前景十分广阔，近几年以来正在深刻改造着既有的网络架构。对于整个网络安全行业而言，物联网安全无疑是未来有确定性的新兴场景方向。我们认为，物盾安全团队针对各类垂直场景，提出了成熟可复制且具有前瞻性的物联网安全解决方案，是这一方向具备先发优势的物联网安全厂商。期待物盾安全持续研发投入，成为我国物联网安全发展的中坚力量。

  

**源渡创投 卢飞  表示：**

近几年物联网行业飞速发展，具有计算能力的边缘节点大量增加，通过物联网的数据量几何级数的上升，物联网安全成为物联网行业发展的关键环节。物盾安全团队拥有先进的物联网安全技术，深耕于众多垂直行业，积累了大量行业经验，并由此打造出了诸多理念先进、稳定可靠物联网安全产品。源渡创投作为物盾安全连续两轮投资人，看好物联网安全方向的前景，也将持续支持物盾安全成为引领行业发展的优秀企业。
