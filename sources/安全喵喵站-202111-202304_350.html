产品整体概述

靖安科技「旌旗」是一个智能指挥操作系统，集情报、指挥、行动于一体，用于连接指挥中心与现场行动小组，致力于实现对行动指挥过程的全要素数字化与智能化，帮助用户全面了解复杂的现场态势，更高效地做出决策。从产品定位上，旌旗对标 Anduril 的 Lattice 平台和 Palantir 的 Gotham 平台。

旌旗通过将现场数据转化为信息，将信息转化为决策，再将决策转化为战术及战略行动，构建从感知到决策再到行动的完整链路，从而帮助指挥人员快速洞察现场，高效精准决策，掌控行动进程。

全域现场感知

旌旗能够对行动现场数以万计的各种类型各种领域的传感器毫秒级即时接入。同时，旌旗融合了数字地图、卫星遥感、倾斜摄影高精模型等，并支持从各类数据基础设施中数据集成，并进行时空融合，并最终在同一个 UI 里，将复杂的现场传感器与各类数据源自动解析成智能的通用操作界面。


设备接入：旌旗依托于底层自研核心引擎「牍术」，是一个全结构 AI 编排计算引擎。借助于牍术的强大的接入能力，旌旗能够并发接入近百万级几乎市面上所有类型的感知设备，无论是监控摄像头、雷达设备、无线电侦测装置、环境传感器等固定设施，还是智能眼镜、执法记录仪、智能头盔等智能单兵作战装备，或者是无人机、四足机器人、无人船、无人潜艇等智能自主装备等等。同时，旌旗兼容 GB/T 28181、GA/T 1400、RTSP、RTMP 等各类常见的公有协议和私有协议，极大简化了设备接入过程，用户只需简单配置，即可批量完成接入。

时空融合：旌旗底层融合了数字地图、卫星遥感、数字高程模型、倾斜摄影高精模型、BIM/CIM 模型、激光点云模型等。同时，旌旗支持从各类数据库、数据仓库、数据湖等数据基础设施中批式或流式进行数据集成，如 POI 数据、告警数据、事件数据等。统一进行时空校准，在同一个 UI 里将复杂的现场传感器和数据源自动解析成智能的通用操作界面，让用户真正意义做到全域现场感知。

网络通信：旌旗支持各类通信手段用于连接指挥中心与行动现场，包括 4G/5G、WIFI、有线连接、MESH 自组网、无线电通信、卫星应急通信等。对于通信受干扰的现场环境，旌旗能够智能切换通信方式与通信链路。同时，受益于重写了许多底层传输协议与传输机制，旌旗在极端弱网情况下（网络通信丢包80%的情况），依旧能稳定流畅传输各类现场数据，同时延迟保持在500毫秒以内。

实时决策智能

在高风险的行动动态环境中，仅仅是看到现场是不够的，必须要能快速高效地做出决策。旌旗采用传感器融合、计算机视觉、边缘计算、深度学习等技术来检测、跟踪和分类每一个对象，帮助指挥员更好地洞察现场。同时，利用运筹优化、强化学习等决策智能技术实时生成行动预案、最优资源分配与调度，给指挥员提供建议与决策支持，简化了决策过程的复杂性。

智能预案：通过对历史行动数据的积累与学习，旌旗能够在每次行动过程中智能生成行动预案。行动甘特图呈现预案的关键过程节点，清晰展示各节点的预案内容、前后依赖关系、预估时间等信息。结合系统提供的现场态势，即时给到指挥人员推荐任务指令与可调度资源。同时，提供可编排的操作方式实时更新预案、调整顺序、标注进程等，帮助指挥中心做出全面、有效和及时的决策。

目标追踪：基于多传感器数据融合，旌旗能有效在全频谱的范围内对目标进行持续跟踪。通过对视频数据、雷达探测数据、无线电侦测数据、遥感数据、定位数据等进行融合计算，旌旗能够实时检测、跟踪和分类每一个对象，无论是人、车、船、飞机、无人机、非机动车，或者是其他目标对象等。

全面布控：旌旗支持在现场范围之内，实时下发布控任务，第一时间对布控对象进行触网预警。对于超出固定传感设备「视距」范围的情况，行动人员单兵装备、车载视频等作为移动布控可以起到补充作用。同时，旌旗可调度无人机、四足机器人等搭载可见光、热成像、激光雷达等载荷对目标区域进行广域自主搜索与持续跟踪。

敌我识别：旌旗通过无线电侦测数据以及我方无人机信号特征，可进行无人机的敌我识别。同时，结合摄像头数据、热成像数据、RTK 定位数据、无线电侦测数据、无人机遥感视频等，利用 Re-ID 算法与精准测距算法，能精确刻画在行动现场我方行动人员与目标对象位置信息。

资源调度：根据事发地点、事件等级、行动预案、路网情况等进行综合分析，结合运筹优化，旌旗能够对行动小组、机器资源、计算资源等进行最优资源调度与分配，自动编队最优推荐的行动人员与机器资源形成协同力量，规划行动路线，同步下发并实时动态更新策略。

动态合围：结合目标对象最后出现时间、最后出现地点、交通工具、道路路网等进行综合研判，利用运筹优化与强化学习等决策智能算法，自动设置包围卡点，形成动态包围圈，下发行动人员前往设卡。

综合指挥控制

旌旗可以在几秒钟之内将决策转化为行动，快速作用于现场，能够对全域、分布式地理位置和极限干扰的通信环境中对行动人员以及无人装备进行实时指挥和控制，让无人机、四足机器人、无人船等无人设备能自主完成任务或对行动人员进行任务协作。旌旗大大简化了多域操作，能够让一名操作人员在一个 UI 上即可支撑复杂的行动。

行动人员指挥控制：通过接入行动人员智能单兵装备，旌旗可实时掌握行动人员位置信息，并可按需进行语音通信、双向通话以及指令下达。通过单兵装备，旌旗可第一时间采集第一现场图片、视频、音频等数据。

无人机指挥控制：旌旗可在指挥中心侧远程「超视距」控制无人机的起飞、降落、返程、飞行状态、挂载载荷等，无需飞手在现场进行额外操作。搭载旌旗内置的自动控制算法，无人机可实现自主导航、自主执行任务、自主返航充电、自主避障并自适应空域环境。在平时，可配置无人机进行航点任务、例行巡检、日常巡逻任务等。在战时，可下发目标对象信息以及要搜索的区域，无人机可自动前往现场开始搜寻目标，并持续保持追踪。同时，也可对行动现场进行应急建模，二维建模、三维倾斜摄影建模、激光建模，支持边飞边建。


机器狗指挥控制：旌旗可在指挥中心侧远程「超视距」控制机器狗的起步、停止、返程、运动、载荷等，并可切换行走、跑动等运动模式，具备视频回传、定位回传等功能，搭载旌旗内置的自动控制算法，机器狗可实现点云地图构建、环境感知、自主导航、智能避障、上下楼梯、巡点任务执行等能力。同时，搭载360度双光谱高清云台，可在复杂而又危险的行动环境中为指挥中心提供无死角360度全域现场视角。


其余设备指挥控制：除了无人机、机器狗，旌旗还支持对无人船、无人潜艇、油动无人机、轮式机器人等各类常见装备的指挥与控制。同时，也支持云台、球机、转台、喊话器、喷网器等各类 PTZ 控制和载荷控制。所有可控制装备均可采用用算法自动控制，或通过同一套摇杆进行人工干预与人工控制。

旌旗应用场景

旌旗适用于一切行动指挥，以及所有跟事件处置相关的场景。结合「望楼」智能哨兵感知平台，以及「牍术」全结构 AI 编排计算引擎，可应用在各类不同场景，包括但不局限于公共安全、峰会安保、应急管理（应急处置、消防、灾害救援、公共卫生防控）、基础设施（工业园区、机场、油田、电站、地铁等）、边防海防、森林防火等。
