**今日，由繁星创投、红华资本、航行资本、斯元商业咨询四机构联合出品的「网安创业生态图·Explorer Map for Cyber Security Startups」2022首版正式发布，**全新视角呈现网络安全行业的生态格局，为网安行业创业者提供一个商业成长的探索图鉴。

  

![](../Images/22aeab4942663516b5469bdddd0bf3b1.png)

  

近年来，在国家政策支持及IT技术加速创新的双重驱动下，中国网络安全行业迎来极大的发展机遇，新兴安全赛道不断涌现，产业热度持续升温，规模日益扩大。根据工信部发布的《网络安全产业高质量发展三年行动计划(2021-2023年)》，到2023年，网络安全产业规模超过2500亿元，年复合增长率超过15%。在如此高速发展的网络安全行业大环境下，创业景象同样是百花齐放，据统计，2021年网络安全行业创业融资逾150笔，总金额超过150亿元，遍布数十个技术赛道。

  

为协助创业者及时抓住时代红利，加快成长步伐，繁星创投，红华资本，航行资本，斯元商业咨询四机构经过深入调研，依据过往3年的行业生态活动数据，联合制作了「网安创业生态图·Explorer Map for Cyber Security Startups」。「网安创业生态图」以第三方专业视角，将网安行业从**投资机构、并购方、媒体及协会、FA财务顾问、加速器、总代理、猎头**等几个维度进行了生态解构，详细展示了不同维度下的活跃机构及代表性机构介绍。
