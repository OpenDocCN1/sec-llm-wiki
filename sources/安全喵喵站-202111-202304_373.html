赛道方向：固件安全 Firmware Security
关注厂商：赛博堡垒Hardened Vault
国际厂商：Purism, Privatecore，ReFirm Labs
喵酱点评：安全的基石，从固件开始
赛博堡垒是一家专注于开放体系基础架构的安全公司，提供来自硬件，固件，Linux内核和安全通信协议的全栈开源基础架构安全方案。赛博堡垒提供一系列的重要组件作为“搭积木“式的安全防御体系，Linux主机类安全基线扩展、Linux 0day/Nday防护技术、具有下一代固件安全的可信/机密计算以及密码朋克社区认可的密码工程最佳实践，为客户提供构建自己的"赛博堡垒"所需要的积木。









赛道方向：客户身份和访问管理 CIAM
关注厂商：无胁科技WuThreat
国际厂商：OKTA, Janrain(Akamai)
喵酱点评：做好客户访问管理，提升数字化用户体验
无胁科技专注于业务安全、身份认证、漏洞情报、安全运营安全，有效利用 AI、安全智能、威胁情报技术开发了一系列具有创新、智能的安全产品与服 务。无胁科技团队在业务安全、威胁情报、攻防渗透、内网横向、机器学 习、APT对抗、黑灰产对抗领域拥有15年以上的经验，是一支年轻化的具有 资深经验、实战化的团队!









赛道方向：API安全 API Threat Protection
关注厂商：喜数信息
国际厂商：Salt Security
喵酱点评：如果我们的语言是API
上海喜数信息科技有限公司成立于2018年，公司总部位于上海，设有广州、武汉、长沙等分支机构，业务涉及API安全、数据安全、安全管理、安全服务。以“专注信息化安全，服务生产力提高”为定位，奉守“稳持发展、内富员工、外服社会”的经营原则，以“专业、创新、利他、家公司”作为文化，通过优质的产品、丰富的行业经验、完善的服务体系，竭力为用户提供专业、可靠的产品与服务。









赛道方向：身份即服务 IDaaS 
关注厂商：派拉软件
国际厂商：OKTA
喵酱点评：零信任时代，身份就是一切
派拉软件致力于为企业单位和政府机构提供专业的一体化零信任身份安全产品和服务。作为国内零信任身份安全的领导者，派拉软件率先将软件定义边界、持续自适应、微隔离等信息安全前沿技术导入身份管理产品的研发与实践中，为各个行业客户提供专业的一体化零信任身份安全解决方案，覆盖内部员工身份治理（2E）、外部合作伙伴身份治理（2P）、C端客户身份治理（2C）、API身份治（2API）、loT身份治理（2loT）、云身份治理、特权身份管理。









赛道方向：蜜罐/欺骗诱捕 Honeypot/Deception
关注厂商：长亭科技
国际厂商：TrapX, Attivo, Illusive,
喵酱点评：理论上无限扩容的商业产品完美形态
长亭科技是国内顶尖的网络信息安全公司，专注为企业级用户提供专业的网络信息安全解决方案。创新发布基于人工智能语义分析的下一代Web应用防火墙，颠覆了传统依赖规则防护的工作原理，为企业用户带来更智能、更简单、更省心的安全产品及服务。
