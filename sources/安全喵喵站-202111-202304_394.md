近日，喵站正式发布了[「Cyber Security Billboard·网安新兴赛道及厂商速查指南」（2022）第1版](http://mp.weixin.qq.com/s?__biz=MzkzNjE5NjQ4Mw==&mid=2247518032&idx=1&sn=61833a483baf201235dd364ace8f75f8&chksm=c2a0a7bcf5d72eaaa564acddbabd1f55d89ac5adb78f096f76099c3f37f6032d66308f84834e&scene=21#wechat_redirect)，共包含99个新兴产品赛道，收录420+国内厂商，350+家国际厂商，得到了业内的积极反响与认可。  
![](../Images/291848ea9c8e2e9521372ae6732ec9db.png)![](../Images/5ce0f12751069d2e38e5d14acca7485f.png)  
「Cyber Security Billboard」并非年度型单次总结报告，而是随着业内赛道和厂商更新情况，1年多次不定期动态更新迭代，为企业安全负责人、渠道合作伙伴和安全从业者提供最实时准确的信息查询检索。  
**基于目前网安技术与产品最新的发展动态，喵站现面向国内安全厂商启动第2版调研工作。**本轮调研在第1版「速查指南」99个新兴产品赛道基础上，**新增17个赛道**：  

1.  5G安全  5G Network Security
2.  内容拆解与重建  Content Disarm and Reconstruction
3.  客户身份和访问管理  Customer Identify and Access Manager
4.  云基础设施授权管理  Cloud Infrastructure Entitlement Management
5.  数据安全治理 Data Security Governance
6.  员工身份和访问管理  Employee Identify and Access Manager
7.  固件安全 Firmware Security
8.  基于硬件的安全  Hardware-Based Security
9.  移动威胁防御 Mobile Threat Defense
10.  隐私影响评估 Privacy Impact Assessments
11.  隐私管理工具  Privacy Management Tools
12.  SDK安全 Software Development Kit Security
13.  安全的即时通信  Secure Instant Communications
14.  安全服务边缘  Security Service Edge
15.  统一终端安全  Unified Endpoint Security
16.  漏洞情报  Vulnerability Intelligence
17.  人工智能安全  AI Security

  
**期待大家积极参与新增赛道的调研反馈，如有现有赛道收录、赛道移除及创建新的赛道分类等需求，也可以一起同步反馈。**厂商反馈经审核通过后，将收录至第二版中。第二版预计于3月底发布。
