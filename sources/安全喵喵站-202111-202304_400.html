网安行业🔥🔥🔥

根据喵站不完全统计数据，仅2021年就有144笔创业融资，技术和产品创新层出不穷，新兴赛道和产品形态日新月异。


为助力企业安全负责人、渠道合作伙伴和安全从业者及时了解网安行业的新兴赛道及前沿产品，在项目产品选型时，高效检索细分赛道和代表性厂商，喵站年初启动了「Cyber Security Billboard·网安新兴赛道及厂商速查指南」，并面向国内安全厂商进行正式版的首次调研，共同完善信息。


本次调研得到了国内近500家厂商的积极参与与反馈，经梳理整合，现正式发布「Cyber Security Billboard·网安新兴赛道及厂商速查指南」（2022年）第1版。



  • 定位：网安新兴赛道及厂商速查

  • 内容：赛道中英文名称，国内厂商、国际厂商索引

  • 受众：企业安全负责人、渠道合作伙伴、安全营销人群、投资机构、行业咨询分析机构，及其他网络安全行业从业者


核心要点

第一版共发布99个新兴产品赛道，收录420+国内厂商，350+家国际厂商。每个赛道均独立页面展示，厂商名字以文字形式呈现，便于使用者快速检索定位、分析者按图索骥。

感谢所有网安业内人士对「Cyber Security Billboard·网安新兴赛道及厂商速查指南」调研工作的积极参与及大力支持，欢迎大家为我们提出更多宝贵的优化建议。


特别说明：「Cyber Security Billboard·网安新兴赛道及厂商速查指南」并非年度型总结报告，而是会根据赛道和厂商更新情况，1年多次不定期动态更新迭代，为行业渠道合作伙伴和最终用户提供最实时准确的便捷可查询信息。


调研工作长期持续进行中，如厂商有赛道收录、移除及创建新赛道分类等需求，请随时扫描小程序二维码或点击链接填写厂商调研反馈表。厂商反馈经审核通过后，将定期更新至速查指南中。反馈更新将体现在第二版中，预计于3月发布，敬请持续关注喵站，随时获取更新版。
