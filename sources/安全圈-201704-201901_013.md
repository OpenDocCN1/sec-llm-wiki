# 包含51个安全更新！Microsoft 2019年1月补丁来了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651960848&idx=3&sn=1a113204811f5f10c95231278b5671e2&chksm=f36c9a50c41b13462235d4510d3a7da1a5fb5470490cf6edc05ed00526f9ef6e0fca0c438dbb&scene=126&sessionid=1681311946#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651960848&idx=3&sn=1a113204811f5f10c95231278b5671e2&chksm=f36c9a50c41b13462235d4510d3a7da1a5fb5470490cf6edc05ed00526f9ef6e0fca0c438dbb&scene=126&sessionid=1681311946#rd)

近日，微软2019年1月的补丁发布，这是它2019年第一次更新！本月的安全更新中包含重要更新，因此请务必尽快安装所有可用更新以保护您的计算机的安全。

  

随着1月安全更新的发布，微软已经修复了51个漏洞，包括Adobe Flash Player和服务堆栈更新（SSU），其中7个被标记为严重。

  

**2019年1月更新的有趣漏洞**

  

**DHCP漏洞 **

  

Microsoft Windows企业安全团队的Mitch Adair发现了一个漏洞（CVE-2019-0547），该漏洞可允许攻击者向客户端发送特制的DHCP响应，以便在客户端上执行任意代码执行。

  

“当攻击者向客户端发送特制的DHCP响应时，Windows DHCP客户端中存在内存损坏漏洞。成功利用此漏洞的攻击者可以在客户端计算机上运行任意代码。要利用此漏洞，攻击者可以向客户端发送特制的DHCP响应。“

  

**两个可以在主机上执行代码的Windows Hyper-V漏洞**

  

这次发布的补丁中包括修复Hyper-V中的两个漏洞（CVE-2019-0550  和CVE-2019-0551）的安全更新，这些漏洞可能允许guest 虚拟机上的恶意软件在主机操作系统上执行代码。

  

“为了利用此漏洞，攻击者可以在客户操作系统上运行可能导致Hyper-V主机操作系统执行任意代码的特制应用程序。”

  

对于使用Hyper-V分析恶意软件样本的研究人员来说，这尤其可怕。

  

**Skype for Android版本可以绕过锁定屏幕**

  

Skype for Android（CVE-2019-0622）中的漏洞已修复，可能允许对Android设备进行物理访问的攻击者绕过锁定屏幕。

  

这将使他们能够访问受害者的个人信息。

  

**Jet Database Engine RCE漏洞已公开披露**

  

据微软称，Jet数据库引擎RCE漏洞（CVE-2019-0579）已被公开披露，但尚不知道它有没有被人利用。

  

根据ACROS安全公司首席执行官Mitja Kolsek和0patch的联合创始人的说法，这可能是Zero Day Initiative公开披露的漏洞，但微软的安全更新不完整。在发现不完美的更新后，Kolsek的团队发布了一个微型补丁来纠正它。

  

![](../Images/6290ca67d167af85c60237887f982bb2.png)

  

**2019年1月补丁本周二更新中修复了严重漏洞**

  

此次补丁修复了Microsoft产品中的7个严重安全漏洞。这些漏洞是最危险的，因为它们可能允许远程攻击者在易受攻击的计算机上执行命令，且基本上可以完全控制它。

  

在7个关键漏洞中，有3个用于Chakra脚本引擎，我们在这些写入中常见，2个用于Windows Hyper-V，一个用于Windows DHCP客户端和Microsoft Edge。

  

**CVE-2019-0539 - Chakra脚本引擎内存损坏漏洞**

  

Chakra脚本引擎处理Microsoft Edge内存中对象的方式中存在一个远程执行代码漏洞。此漏洞也可以通过Microsoft Edge通过特制的网站或广告来利用。

  

**CVE-2019-0547 - Windows DHCP客户端远程执行代码漏洞**

  

如上所述，此漏洞允许攻击者将特制的DHCP响应发送回客户端以执行任意代码执行。

  

**CVE-2019-0550 - Windows Hyper-V远程执行代码漏洞**

  

当主机服务器上的Windows Hyper-V无法正确验证来宾操作系统上经过身份验证的用户的输入时，存在远程执行代码漏洞。要利用此漏洞，攻击者可以在客户机操作系统上运行可能导致Hyper-V主机操作系统执行任意代码的特制应用程序。

  

成功利用此漏洞的攻击者可以在主机操作系统上执行任意代码。

  

**CVE-2019-0551 - Windows Hyper-V远程执行代码漏洞**

  

当主机服务器上的Windows Hyper-V无法正确验证来宾操作系统上经过身份验证的用户的输入时，存在远程执行代码漏洞。要利用此漏洞，攻击者可以在客户机操作系统上运行可能导致Hyper-V主机操作系统执行任意代码的特制应用程序。

  

成功利用此漏洞的攻击者可以在主机操作系统上执行任意代码。

  

**CVE-2019-0565 - Microsoft Edge内存损坏漏洞**

  

当Microsoft Edge不正确地访问内存中的对象时，存在远程执行代码漏洞。该漏洞可能以一种使攻击者能够在当前用户的上下文中执行任意代码的方式来破坏内存。成功利用此漏洞的攻击者可以获得与当前用户相同的用户权限。如果当前用户使用管理用户权限登录，则攻击者可以控制受影响的系统。然后攻击者可以安装程序，查看，更改或删除数据， 并创建具有完全用户权限的新帐户。

  

攻击者可能拥有一个旨在通过Microsoft Edge利用此漏洞的特制网站，然后诱使用户查看该网站。攻击者还可以通过添加可能利用此漏洞的特制内容来利用受感染的网站和接受或托管用户提供的内容或广告的网站。

  

**CVE-2019-0567 - Chakra脚本引擎内存损坏漏洞**

  

Chakra脚本引擎处理Microsoft Edge内存中对象的方式中存在一个远程执行代码漏洞。此漏洞也可以通过Microsoft Edge通过特制的网站或广告来利用。

  

**CVE-2019-0568 - Chakra脚本引擎内存损坏漏洞**

  

Chakra脚本引擎处理Microsoft Edge内存中对象的方式中存在一个远程执行代码漏洞。此漏洞也可以通过Microsoft Edge通过特制的网站或广告来利用。
