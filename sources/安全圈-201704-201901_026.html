系统工程师（网络运维方向）   薪资面议  

学历：本科以上  经验：3年及以上 地点：上海


职位描述


【职位要求】


1. 系统监控经验；

2. Devops工具：ELK/Zabbix/Prometheus chef/ansible....；

3. 有一定的代码能力（Python/Java/Shell）；

4. Linux经验。


【学历要求】


本科以上（硬性要求）985/211优先。

英语四级以上。


【行业经验】


有产品安全/实验室测试环境 工作经验。可以是在客户端工作，也可以是在咨询端工作。


数据工程师  薪资面议   

学历：本科以上  经验：3年及以上   地点：上海


职位描述

 

【职位描述】


1、熟练使用Python, Bash, SQL等工具，对大规模数据进行整理、清洗、评估等工作；

2、接入与整合第三方平台API数据源，爬取并处理网页数据，进行页面内容抽取等；

3、在指导下开发与维护大规模数据流水线。


【职位需求】



1、熟练掌握C/C++、Java或Go语言；

2、能熟练使用Python、Bash等脚本语言进行数据处理；

3、有Spark、Hadoop等分布式处理系统的使用经验者优先；熟练使用SQL者优先；

4、CS/EE专业本科或以上学历；

5、对数据有敏感性，对数据质量有高标准、严要求，热衷为用户提供最好的产品使用体验；

6、学习能力强，敢于接受挑战，乐于学习新的系统与技术，具有良好的沟通合作能力、认真负责，勇于承担责任，有较好的英文读写能力。


UI自动化  薪资面议   

学历：本科以上  经验：3年及以上   地点：上海


职位描述

 

【职位描述】


与其他工程师和测试人员合作创建测试计划与用例实现自动化测试，用例总结记录问题，并与团队沟通分析遇到的问题，并给出可能原因在产品开发过程中，与其他成员紧密合作跟踪问题来提升产品质量。


【职位要求】



1、掌握常用测试方法，并具备丰富的自动化测试经验；

2、了解UI自动化测试 熟悉并充分掌握一种脚本语言 Python, Ruby, JavaScript 等；

3、有在常见测试框架平台中更新创建自动化测试用例的经历善于总结，记录及诊断问题 母语为中文，并有较好的英文读写能力。 掌握多种汉语方言优先； 

4、工作认真负责，有较好的学习和沟通能力；

5、有苹果平台 iOS/Mac OS/Watch OS 相关经验者优先，有创建与维护自动化测试框架平台经验者优先，有语音/语言类产品经验者优先。




员工福利：周末双休，社保公积金足额缴纳，外派，节假日福利，节假日正常休
