# 新技术支持骗局使Chrome浏览器使用100％的CPU

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651960524&idx=5&sn=d14bcce3751a1e946ae37b378bab8ad1&chksm=f36c988cc41b119a5a0d98a3d22e21686dd98a913207df6aafbf62b0eb2264ae921afdbe513d&scene=126&sessionid=1681311955#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651960524&idx=5&sn=d14bcce3751a1e946ae37b378bab8ad1&chksm=f36c988cc41b119a5a0d98a3d22e21686dd98a913207df6aafbf62b0eb2264ae921afdbe513d&scene=126&sessionid=1681311955#rd)

![](../Images/dbffd8856c1f977ae196cdba16d2087b.png)

  

已经发现了一种新的技术支持骗局，它使用JavaScript创建一个循环，最终导致谷歌浏览器耗尽计算机上的所有CPU资源并冻结浏览器。

  

Google Chrome错误报告中报告了这种新的技术支持诈骗变体，该报告指出，一旦用户访问该页面，CPU利用率很快就会达到100％。这使得无法关闭选项卡，浏览器或正确使用计算机，直到Chrome进程被终止。

  

![](../Images/fde8e6c4530b301a3d005570fd864f9b.png)

**Google Bug报告**

  

访问列出的网址时，您将被带到一个技术支持骗局页面，其标题为“重要信息”。此页面假装是Windows错误标题“Internet Security Alert！代码：055BCCAC9FEC”，表明您的计算机已被感染，您应该拨打所列支持号码以获取帮助。

  

![](../Images/2feb68410557a9e74a26e0dbb8e6ac04.png)

  

此页面包含的JavaScript将导致浏览器重复转到#URL，然后返回按钮转到浏览器历史记录中的上一页，然后转到前进按钮返回原始页面。

  

![](../Images/0c0576801d797faa2eea710190d749de.png)

**Javascript显示循环**

  

此循环使浏览器利用计算机的所有CPU资源，如下面的Chrome任务管理器中所示。

  

![](../Images/d8ed3341e416a589399abc343f1a589c.png)

**技术支持诈骗的CPU利用率**

  

这种高CPU利用率最终会导致浏览器冻结，而您的计算机几乎无法使用。此时，关闭浏览器的唯一方法是使用Windows任务管理器等工具关闭有问题的Chrome.exe进程。 

  

问题是，在关闭流程后打开Chrome后，它会提示您打开以前打开的页面。这将导致技术支持骗局页面重新打开，这会再次导致浏览器/计算机出现问题。

  

![](../Images/361779070a0d8f108add2abe5472f56f.png)

**重新打开Chrome**

  

因此，当受技术支持骗局影响并终止浏览器进程时，请确保您不允许Chrome或任何浏览器恢复以前打开的页面。否则你会回到你开始的地方。

  

在BleepingComputer的测试中，同样的技术支持骗局不会影响Firefox。使用Firefox，您只需关闭选项卡和浏览器即可摆脱此技术支持诈骗。
