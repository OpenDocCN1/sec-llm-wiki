发现了Windows零日漏洞的研究员，被微软封了GitHub 账号

12月20 日，在Twitter上一个名为SandboxEscaper的安全研究员发布了针对微软Windows操作系统的新零日漏洞的POC漏洞利用。



这个新公开的Windows零日漏洞可以利用微软广告组件，允许攻击者读取目标Windows计算机上的任意文件。


如果用户使用普通帐户登录，则攻击者可以成功获得相同的权限。如果管理员登录，则攻击者可以完全控制整个系统。


该漏洞利用名为MsiAdvertiseProduct的微软广告组件，在调用该组件的函数安装程序时，会导致任意文件被复制，而攻击者利用这枚漏洞可以读取系统所有文件。


据了解，这是SandboxEscape在过去几个月中第三次发现Windows零日漏洞。


第一个是在8月底发布的，该漏洞是一个“本地权限提升”问题，允许攻击者将恶意代码的访问权限从有限的USER提升到全访问SYSTEM帐户。



第二个是在10月底发布的，它也是一个权限提升漏洞。该漏洞影响Microsoft数据共享（dssvc.dll）服务，允许攻击者删除普通用户无法与之交互的文件。


|  发布第三次漏洞之后


虽然SandboxEscape发现并公布了漏洞，但在SandboxEscape发布第三个漏洞后，微软以违反用户协议封禁了该研究人员的 GitHub 账号。


|  微软已发布补丁，修复IE浏览器零日漏洞

 

目前，微软已发布了所有受支持Windows版本的最新安全更新，主要用于修复IE浏览器远程执行代码漏洞。


厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/en-us/security-guidance/advisory/CVE-2018-8653


以下素材来自CNNVD，是对该漏洞的描述：


漏洞名称：Microsoft Internet Explorer 脚本引擎安全漏洞


漏洞编号：CNNVD-201812-806（CVE-2018-8653）


漏洞详情：Microsoft Internet Explorer（IE）是美国微软（Microsoft）公司开发的一款Web浏览器，是Windows操作系统附带的默认浏览器。


Microsoft IE 9、10和11的脚本引擎中对内存对象的处理方式存在远程代码执行漏洞。远程攻击者可利用该漏洞在当前用户的上下文中执行任意代码，损坏内存。以下系统版本受到影响：Microsoft Windows Server 2012（Internet Explorer 10）；Windows 10版本1703，Windows 10版本1803，Windows 10版本1809，Windows 10版本1709，Windows 10，Windows 10版本1607，Windows Server 2019，Windows Server 2016，Windows 7 SP1，Windows 8.1，Windows RT 8.1，Windows Server 2008 R2 SP1，Windows Server 2012 R2（Internet Explorer 11）；Windows Server 2008 SP2 （Internet Explorer 9）。
