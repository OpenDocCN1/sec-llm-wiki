# 美国航空航天局一服务器被黑客攻击 员工信息或遭泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651960442&idx=2&sn=66f7a4d0759cb9a261d7d5754c533317&chksm=f36c983ac41b112c055176f74f30aadb2f26b315e59915f9ce646d93e53fcbf9bc155858c770&scene=126&sessionid=1681311955#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651960442&idx=2&sn=66f7a4d0759cb9a261d7d5754c533317&chksm=f36c983ac41b112c055176f74f30aadb2f26b315e59915f9ce646d93e53fcbf9bc155858c770&scene=126&sessionid=1681311955#rd)

![](../Images/dbffd8856c1f977ae196cdba16d2087b.png)

  

周二，NASA员工收到了一份令人不安的电子邮件。

  

该机构的人力资源部门发出的消息显示，黑客可能在最近几个月内攻击了NASA的服务器，且在此过程中访问了员工的个人身份信息，包括他们的社会安全号码。

  

更令人不安的是，这已经不是第一次了 。

  

![](../Images/2434f94a3abf2d04a1521a31a7efdf95.png)

  

10月23日，入侵者就曾访问过存储着当前和前NASA人员信息（包括社会安全号码）的服务器。  

  

美国宇航局首席人力资本官鲍勃吉布斯说，虽然美国宇航局知道服务器确实被访问过，但他们还不知道入侵者盗走了哪些信息。

  

该机构称没有任何迹象表明NASA的各项任务受到了黑客影响，但现在它已经传达给所有员工，让他们知道某些信息已经暴露给黑客。NASA表示，在发现这些事件后，NASA网络安全人员立即采取行动保护服务器及其中包含的数据。美国宇航局及其联邦网络安全合作伙伴正在继续检查服务器，以确定潜在数据泄漏的范围，并识别可能受影响的个人。

  

NASA表示，调查需要时间，但强调它现在已成为NASA目前最重要的优先事项。NASA表示，将为所有员工提供额外服务，包括身份保护服务。

  

但是NASA没有详细说明服务器是如何被破坏的，以及事件背后的黑客组织名称。

  

以下是原文：

  

**全机构与员工的沟通**

  

2018年10月23日，美国国家航空航天局(NASA)网络安全人员开始调查个人身份信息(PII)存储在美国国家航空航天局服务器上的一个可能的漏洞。经过初步分析，美国国家航空航天局(NASA)确定，其中一台服务器上的信息可能遭到了泄露，其中包含美国国家航空航天局现任和前任雇员的社会保险号和其他PII数据。

  

在发现这些事件后，NASA的网络安全人员立即采取行动保护服务器和其中包含的数据。NASA及其联邦网络安全合作伙伴正在继续检查这些服务器，以确定潜在数据泄漏的范围，并确定潜在受影响的个人。这个过程需要时间。正在进行的调查是机构的一项最高优先事项，高级领导积极参与。美国宇航局不认为任何机构的任务受到了网络事件的危害。

  

无论你的信息是否被泄露，这条信息都将被发送给所有NASA员工以引起他们的注意。那些从2006年7月到2018年10月在NASA工作、与NASA分离或在各中心之间调动的公务员可能受到了影响。一旦确认，NASA将向PII受影响的过去和现在的员工提供具体的后续信息，包括提供身份保护服务和相关资源。

  

我们的整个领导团队都非常重视个人信息的保护。信息安全仍然是NASA的首要任务。NASA正在继续努力保护所有服务器的安全，并正在审查其流程和程序，以确保整个机构都在遵循最新的安全实践。
