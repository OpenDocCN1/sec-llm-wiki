# “Donald” 光荣上榜2018年最烂密码榜单

又到了每年发布年度最差密码榜单的时间，当然123456和password这种密码绝对不会缺席榜首，人们从来就不会从错误中学到什么。今年的名单的最大亮点在于包含了常见的人物，美国总统“唐纳德”今年首次亮相，名列23位。

  

排名来自SplashData，这是一家名为SplashID的密码管理软件公司。 SplashData分析了在互联网上泄露的500多万个密码，发现人们仍在使用容易猜到的密码。

  

![](../Images/4c0e7fadd642a89800152d6e2ec28af7.png)

  

SplashData首席执行官摩根·萨兰称，人们继续将自己置于风险之中，尽管有频繁的消息揭露人们的密码和身份信息正在被不断泄露的当下，人们依然在做他们不应该做的事情，比如使用他们自己的名字或名人名字（比如美国总统）作为可预测的密码。

  

“Donald”位于名单中的另外两位新人之间，“aa123456”和“password1”也是新上榜的两个自作聪明的变种密码。
