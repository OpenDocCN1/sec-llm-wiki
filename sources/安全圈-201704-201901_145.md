# 支付宝回应短信红包：非官方发送，已严厉打击

近日，有用户反映收到了邀请领取支付宝红包的短信，这类短信中会提供给用户一串数字，称打开支付宝，输入相应数字搜索就可以领取红包。

  

**支付宝安全中心回应称：**

**1、这些短信并非支付宝官方发送**

**2、发送红包短信的手机号码并非来自支付宝**

**3、领红包页面开放了投诉通道**
