网友为什么发出这样的感叹呢？

  

今天，一篇关于机器人“卧底”GitHub数月，查找错误并编写和提交修复补丁，并且有多个补丁成功通过被采纳的消息，引起网友讨论。

  

![](../Images/2dbd3b7d8baafb6f12d70c22acdc2c02.png)

  

据了解，这名为“Repairnator”的机器人，是由KTH 瑞典皇家理工学院的软件技术教授 Martin Monperrus 及其朋友构建的机器人，**它目前已被证实可以发现错误并编写高质量补丁**。

  

> 据悉，该团队将 Repairnator 伪装成了一个名为 LucEsape 的 GitHub 用户，他们给 Luc 上传头像并填写个人资料，看起来就像是一位渴望在 GitHub 上做贡献的初级开发者。他们共进行了两轮测试。
> 
>   
> 
> 第一轮是在2017年2月到12月，Repairnator 在 14188 个 GitHub 项目的修复列表上运行并扫描错误，期间 Repairnator 总共分析了超过 11500 个失败的构建，其中有 3000 多个能被重现。然后，Repairnator 生成了针对其中 15 个问题的补丁，遗憾的是由于补丁质量低、花费时间过长等问题，这些补丁均未被接受。
> 
>   
> 
> 第二轮测试是在2018年1月至6月，该团队没有具体说明他们对 Repairnator 做了哪些改进，但 Repairnator 在1月12日成功编写出了第一个被人类开发者接受的补丁。在之后的6个月里，Repairnator 陆续又有 5 个补丁被采纳。

  

这位Martin Monperrus教授表示，“这是自动修复程序研究中的里程碑，**它拥有和人类开发者竞争的潜力**。”

  

![](../Images/7563e734d6468ed4129786fb68170189.png)

  

厉害了，机器人！

  

我们创造机器人的初衷是为了帮助人类，而且，在劳动过程中的一些突发情况，还是需要人来解决的。

  

> 与精密的机器相比，绝大多数人或许是笨拙、愚蠢的，但维系人类社会的是爱与同情，而不是纯粹的智力。无论何时，机器和科技都要为高贵的人服务，奉行人本主义，而不是相反。

  

对于这位能自动编写补丁的机器人，有的网友忧心可能会工作不保，有的网友就很轻松了，甚至表示想看现实版“机器人互战”
