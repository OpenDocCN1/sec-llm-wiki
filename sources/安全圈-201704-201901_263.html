微软Azure云服务宣布Dynamics 365将落地中国

原文：http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651959179&idx=1&sn=c6b2e4a615a2a07435f67f7e08c46be3&chksm=f36c83cbc41b0add2be2d3c7c274f5aa4b9731d378c561fda1f71c875f7c5c3031e35e8b2def&scene=126&sessionid=1681311979#rd


今天微软在Microsoft Tech Summit2018上正式宣布Dynamics 365计划于2019年春落地中国。



据悉，这是微软首次公开其智能云Azure、Office 365、Dynamics 365齐聚中国，共同在中国市场与本土云计算公司展开竞争。


实际上，多年来，由本土公司世纪互联运营的Microsoft Azure与Office 365在中国市场超预期的健康发展，也开创了国际云服务在华合法合规运营的成功先例。



微软公司资深副总裁、大中华区董事长兼首席执行官柯睿杰(Alain Crozier)表示：


Dynamics 365在明年春李落地中国，让微软智能云“三驾马车”为国内企业注入更多创新能力。


作为此次大会的重头戏Dynamics 365，我们就先来详细了解一下


Dynamics 365是植根云端的新一代智能企业应用平台，全面整合了CRM客户关系管理和ERP企业资源计划的众多功能，能以按需构建的应用模块管理不同行业企业对于市场、销售、服务、运营、财务、人才等业务流程的智能化管理。


Dynamics 365可以提供现代化的细分功能模块。可为企业业务的快速创新注入人工智能(AI)、商业智能(BI)、混合现实(MR)、社交及移动应用。


Dynamics 365还可通过加入第三方应用进行扩展，进而构建出新型解决方案，不断因应业务的发展变化。


再来看看Microsoft Azure


据业内人士分析，四年来，微软智能云Azure已服务超过11万家企业用户，客户满意度高达95%，且随着中国数字化转型的不断深入，微软在华的各项投入也在不断加码，今年Azure在中国运营规模实现了3倍扩容，目前已在中国总共有4个高等级数据中心。


然而，再厉害的“云”也敌不过大自然的云：微软公司的Azure公共云被真正的云搞垮了



微软表示，位于得克萨斯州的美国中南部数据中心遭到了雷电风暴，结果散热系统出现了故障，迫使该公司关闭了许多服务器和系统，以防遭到更严重的损坏。


散热系统是现代数据中心的一个重要组成部分，因为散热系统是消除在一个封闭的地方紧密堆叠在一起的成千上万台服务器产生的高温所必不可少的。简而言之，如果这个系统出了故障，所有系统都将随之停运。


微软表示，这起故障已影响了许多Azure云服务，包括Visual Studio Team服务。停运的其他服务包括Azure Active Directory身份管理服务和基于云的生产力套件Office 365。


Constellation研究公司的首席分析师兼副总裁霍尔格•米勒（Holger Mueller）就此事表示，“这次事件深刻地提醒人们，即使对于像微软这等规模的IaaS提供商来说，要保持数据中心正常运行有多难。”


对于微软云Azure，也有人拿它与亚马逊云服务作比较。在今年7月，据华尔街日报报道：


高盛发布的报告显示，大型公司将更多工作转至云端，在亚马逊旗下云计算服务Amazon Web Services的支出最多，不过微软的云服务Azure正在扩大阵地。报告显示，当被问及目前正在使用的基础架构即服务(简称IaaS)公有云供应商时，有56%的大型上市公司CIO回答是AWS，回答是Azure的比例为49%。


其实，我国已经有很多做得很好的云。


在今年9月份，天下数据《国内十大云服务器商排名 各有什么优势呢？》中提到，国内十大云服务商公司排名，位列前三的分别是阿里云、腾讯云和百度云。


今年，易观《中国云服务企业创新发展专题研究报告》对2017年国内云服务市场整体表现进行评估。百度云市场营收跻身国内前三甲，增长速度和技术前瞻性均达到业内第一水平。同样，在今年ForresterQ3季度的报告中，百度云因市场营收和市场占有率的大幅攀升而闯入国际视野，强势登陆Forrester“优异表现者”象限，被评为国内顶尖AI与IoT服务供应商，ABC能力获全球认可。


曾经有人提到过，亚马逊AWS等外资企业入华，对于本土公司是极大的威胁。但百度云计算事业部总经理刘炀表示，云计算除了是产品技术的竞争，也是生态的竞争，而本土化公司跟国内消费者更近，能够更好地解决客户的业务需求。


未来各方在云上的竞争，将更加激烈。相信，各方面世的产品，也会越来越好。
