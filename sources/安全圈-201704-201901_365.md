# 无耻！这些人绝了中国码农在硅谷的路！！！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651958393&idx=1&sn=07c02ecdeac1def407de7ddca3a99ba6&chksm=f36c8039c41b092f095ae6e7c88147bd8286f364e762a496c1f811ee904607f5ca493ee1e975&scene=126&sessionid=1681311991#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651958393&idx=1&sn=07c02ecdeac1def407de7ddca3a99ba6&chksm=f36c8039c41b092f095ae6e7c88147bd8286f364e762a496c1f811ee904607f5ca493ee1e975&scene=126&sessionid=1681311991#rd)

在中国，去阿里巴巴和腾讯这样的大公司上班是很多人梦寐以求的事，而在国外，谷歌、Facebook、亚马逊这些公司更是全世界码农的梦想，但要想到这些大公司上班可不是一件容易的事。  

  

最近有网友发帖爆料：**Facebook 竟然还有面试枪手，面试通过一次性收费1.5万美金**。

  

![](../Images/ca0dd147be0dc8fe7390777d56f6098a.png)

  

此帖子一出立马引发网友激烈讨论：

  

![](../Images/eb79f7f0e81a57399d7aba0bc26e9f6e.png)

  

有网友评论爆料，印度那边更为夸张，甚至电面招人替代的都有 。

  

![](../Images/0c02d85b3be6ebd1f7d4eb2320336fd0.png)

  

  

还有网友调侃说：为什么这种入职以后不会被发现呢？因为面试造火箭，工作拧螺丝。

  

![](../Images/b4065b12e4f37d7c6e24275fda355abc.png)

  

也有网友表示早就知道这种现象存在，见怪不怪了。

  

![](../Images/0c02d85b3be6ebd1f7d4eb2320336fd0.png)

![](../Images/cd2ba59289ffc2f81369c8bfd631b018.png)  

  

看了聊天截图，我的第一反应就是不公平，对其他面试者来说都不公平，我们都有过面试大公司前疯狂刷题的经历，有过花很长时间精心准备面试的经历，这个过程非常辛苦，但是别人却通过花钱，找代面轻轻松松通过了。

  

  

Facebook的面试是在线做题加上电话面试，重点是在线做题是有题库的，而这些枪手花了大量的时间将题库题目做完就可以接代面，对于很多枪手来说真是“一次学习，终身赚钱”。

  

对于找代面的人进入Facebook来说，想要转正还要通过最后一道关卡。就是转正之前的最后一轮面对面面试，想要浑水摸鱼可是非常不容易，就算你侥幸过关成为了正式员工，发现你工作能力不行，马上就让你收拾行李走人。

  

![](../Images/1eadc521f8daf98e154fd18b928c339e.png)

  

但同样面试造假搁在谷歌这里就比较难，谷歌对员工是很宽容的，只要你通过面试，就算你后面工作能力不是很突出，谷歌也会给你安排一个适合的岗位，所以，也有人戏称进去“谷歌”就像去养老一样。就因为进去后相对轻松，所以谷歌对面试把控很是严格，并且谷歌的面试题没有什么标准答案，面试官采用一问一答的模式，根据不同的回答筛选出不同的候选者。

  

![](../Images/baf9d2d32d6d17eb47a127d9b28b7e2b.png)

但就算是这样，也无法阻挡这帮枪手赚钱的道路，于是就出现了可以代面谷歌全职的枪手，更可怕的是他们还团队配合操作，会用丰富的经验帮你通过电话面试，然后在关键的真正面试的时候竟然和谷歌内部招聘人员勾结说你**“腿断了，没办法来面试**”。纳尼？“**腿断了**？”没错，就是腿断了，然后就会进行第三次电话面试直到顺利拿到offer。这么牛X的操作，小编也是第一次听说。  

  

![](../Images/7321e0b7ff25e42d0921a0d9bd9969de.png)

  

但无论是哪家公司，这些枪手为了赚钱什么都能做的出来，歪理是一套一套的，说不定就把一些热爱IT事业的小哥哥给唬住了，万一相信了，作弊被发现开除了，那就是一辈子职业生涯的污点，不仅如此，连你的人品都会打上一个大大的问号，还有什么好的工作机会呢？作弊造假不但对个人产生严重的影响，更有可能造成国外大企业对华人印象恶劣，从而减少给华人工作机会。

  

就说前段时间，GitHub 简历造假的事被曝了出来，造假之人被生生打脸。不管如何，真的假不了，假的也真不了。与其绞尽脑汁去造假进入这些大公司，还不如提高自已的技术专业能力，专业能力到了，就是“梦想照进现实”的时候了。

  

废话不多说，下面就是小编献上的干货，希望程序员小哥哥们要扎扎实实，一步一个脚印才会走得更远哦。
