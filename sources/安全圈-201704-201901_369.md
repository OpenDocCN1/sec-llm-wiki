# 这个间谍软件在全球45个国家进行大规模监视

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651958335&idx=4&sn=63ee4efb847d3772190f2b2eceacadb1&chksm=f36c807fc41b09697b0ffdacb58142a0c9354cc03ab09a3eb326de17592f32613e0038a760f3&scene=126&sessionid=1681311991#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651958335&idx=4&sn=63ee4efb847d3772190f2b2eceacadb1&chksm=f36c807fc41b09697b0ffdacb58142a0c9354cc03ab09a3eb326de17592f32613e0038a760f3&scene=126&sessionid=1681311991#rd)

新的研究表明，以色列的NSO集团使用强大的基于移动的Pegasus间谍软件在**全球45个国家**进行大规模监视。  

  

NSO集团在以色列开展业务，向政府和私人实体生产和销售名为**Pegasus**的手机间谍软件，以执行大规模的监控操作，以便从目标受害者处获取敏感信息。

  

飞马间谍软件以前的操作在2016年8月对阿联酋活动家艾哈迈德·曼苏尔启动，它包含了**零日漏洞苹果iPhone与间谍软件针对他的iPhone 6到他的间谍活动电话**一起。

  

NSO集团基本上作为一家  “网络战争”公司运营，将Pegasus间谍软件作为**“合法拦截”**软件出售给政府机构和私营公司。

  

研究人员认为，**至少有10名Pegasus运营商**似乎积极参与了45个国家的监控行动。

  

Pegasus间谍软件是最复杂和最强大的间谍软件之一，**可以在Android和iPhone中执行各种恶意活动**，例如**窃取私人数据，包括密码，联系人列表，日历事件，短信和来自流行的移动消息应用程序的实时语音呼叫**。

  

![](../Images/14d482896c87c3721d18d1470727c9c3.png)

  

截至目前，研究人员发现了**36个不同的Pegasus系统**，每个系统可能由一个单独的操作员运行，并且他们怀疑Pegasus感染与36个Pegasus操作员中的33个相关，并且他们监视45个跟随国家。

**研究人员开发了一种名为Athena的新技术，发现1,091个IP地址与指纹相匹配，并且有1,014个域名指向NSO集团。**

  

后来，通过对匹配域名进行全球DNS缓存探测研究，确定了受监视的国家，这有助于找出每个运营商在哪些国家进行间谍活动。

  

根据citizen实验室的研究，为了监控目标，Pegasus的政府运营商必须说服目标点击特制的漏洞利用链接，点击该链接后，可以提供一系列零日攻击，以渗透手机上的安全功能。在用户不知情或未经许可的情况下安装Pegasus。

  

在成功利用电话后，它开始通过命令和控制服务器与操作员通信，以便接收进一步的操作命令。

  

通过HTTPS请求与Pegasus间谍软件建立通信，它要求运营商注册和维护域名。

  

**过去利用链接的域名模仿移动提供商，在线服务，银行和政府服务。**

  

运营商可能拥有他们在其发送的漏洞利用链接中使用的多个域名，并且还有几个用于C＆C的域名。域名通常解析为由NSO Group或运营商租用的基于云的虚拟专用服务器（我们称之为前端服务器）。研究人员说。

  

在这种情况下，NSO集团拒绝了citizen实验室的调查结果并说：“实验室的最新报告存在多处问题。最重要的是，国家统计局被指控经营的国家名单简直不准确。“

  

“国家统计局并未在所列的许多国家开展业务。该产品仅被许可在我们的商业道德框架批准的国家/地区运营，并且该产品不会在经批准的国家/地区之外运营“
