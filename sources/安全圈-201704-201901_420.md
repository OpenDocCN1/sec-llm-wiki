# 国内 GitHub 被爆造假，你的“造假”简历有多硬？

目前市面上很多程序速成班，更多教给你的是一些应试技巧，教会你如何包装自己，这种包装，已逐渐延伸到了Github。  

  

大家都知道，Github作为全球最大的开源社区，GitHub 对于程序员群体而言像是空气般重要的存在，从代码托管、项目管理到面试加成，可以说贯穿了程序员的职场生涯。

  

对于互联网公司 HR 来说，通过查询一名候选人的 GitHub 主页，能够进一步了解候选人的开源贡献、技术热情和编程习惯，从而为公司招聘到最好的开发人选提供参考。

  

![](../Images/484142c47097b37c693ac51d49b2c4f5.png)

  

然而，并不是每个程序员都有能力拿得出亮点较多的项目的，为了早日找到理（gao）想（xin）的工作，于是就有了Github代刷业务。早在几个月前，就传出有培训机构可以代刷Github，代出简历的服务。甚至有人莫名其妙就收到了推广的邮件。

  

![](../Images/5c2e260b3733ecd2e4cd1874981031ed.png)

![](../Images/3b41cffb05266ebafb43280b32feda34.png)

  

有一篇《中国内地 GitHub 造假呈指数级增长，其背后是……》的文章便将 GitHub造假事件推上了风口浪尖。

  

![](../Images/0f08e4825944c7a39faa4feb20edc152.png)

来自 知乎@非著名程序员  

  

文章叙述了 GitHub 如何在国内「变味」，部分国内用户通过中介对个人的 GitHub 主页进行「包装」，达到谋取高薪工作等目的。「包装」的方式包括刷赞、刷 follow、刷 fork等。其中最让人感到惊讶的是，就连需要项目方首肯才能进行操作的pull request，中介也有办法通过人脉关系搞定。

  

![](../Images/bb2f1880c94afa7a0c2797974e71628e.png)

  

后来的结果是什么？

  

结果就是很多公司不要培训出来的人，宁愿错过一千也不肯放过一个，因为包装的太好，见招拆招太熟练，招到公司里来，不知道究竟能不能胜任工作，万一关键时候出了岔子...为了保险起见，就一并拒绝了。是培训出来的人不好吗？不是，而是一旦选错，成本太高。

  

另外如果你的简历够硬，没被发现作假，那么你可能是幸运的，但万一有一天真的被发现了，就涉及到你这个人的诚信问题，公司会用一个没有诚信的人吗?

  

![](../Images/6dfb4427962aa5177d5caa74adca40b0.png)

  

网友是这样评论的：

  

![](../Images/c718f281f1074f79e5aa274368812a57.png)

![](../Images/69a360fb8e4662295138c622585d5ebb.png)

![](../Images/ffd01dcdb6dd66ec6ae62ce5dfdc97ff.png)

  

技术本就是纯粹的，老实人好好写简历没有人用，反而被一些写的花里胡哨的人给抢去了岗位面试资格。如果越来越多这样个人出现，那么你还如何区分好项目？坏项目？你看到的东西到底值得借鉴还是误人子弟？  

  

为什么不可以踏踏实实学习？只要你有技术，锻炼多了，工资自然就涨了。好看的简历顶多在筛选简历的过程加分，职业之路要走得长远，最终拼的，仍然是技术实力以及你的诚信。
