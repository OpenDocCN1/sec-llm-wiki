# 华住旗下汉庭、桔子等5亿条酒店开房记录疑被泄露！连你的身份证号都有...

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651957890&idx=1&sn=c4f62ba693efc6d735526815d5235b4f&chksm=f36c86c2c41b0fd4827971037908f227291dbd39756e155579b160be21f33ad6a1f46e0132d3&scene=126&sessionid=1681311999#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651957890&idx=1&sn=c4f62ba693efc6d735526815d5235b4f&chksm=f36c86c2c41b0fd4827971037908f227291dbd39756e155579b160be21f33ad6a1f46e0132d3&scene=126&sessionid=1681311999#rd)

今天早上6点整，中文暗网论坛发布一封华住旗下酒店开房数据的帖子，曝出**华住旗下所有酒店数据——包括汉庭酒店、美爵、禧玥、漫心、诺富特、美居、CitiGo、桔子、全季、星程、宜必思、怡莱、海友等多家酒店都在内——遭脱库，共泄露数亿条信息。**

  

开价8btc，并且**发出部分测试数据**。本次数据泄露疑是开发人员将数据库配置文件上传至github导致，也有人说是root太简单。但目前官方无任何说明。

  

![](../Images/bd1fc30cc10773a91ec16ad9569bcab7.png)

  

帖子显示，售卖的数据分为三个部分：

  

**一部分为华住官网注册资料**，包括姓名、手机号、邮箱、身份证号、登录密码等，共 53 G，大约 1.23 亿条记录；

  

**一部分为酒店入住登记身份信息**，包括姓名、身份证号、家庭住址、生日、内部 ID 号，共 22.3 G，约 1.3 亿人身份证信息；

  

**还有一部分为酒店开房记录**，包括内部 id 号，同房间关联号、姓名、卡号、手机号、邮箱、入住时间、离开时间、酒店 id 号、房间号、消费金额等，共 66.2 G，约 2.4 亿条记录。

  

![](../Images/bb66dc691db8c2a79e9e7bcb56e31c70.png)

  

该贴还称，上述数据脱库时间为8月14日，**每部分数据都提供 10000 条测试数据。**所有数据打包售卖 8 比特币，按照当天汇率约约合 37 万人民币。

  

![](../Images/d33ed16287304a34d36b17f1bd47bce4.png)

  

 2013 年，汉庭等酒店就曾出现过数据泄露，当时是因为酒店所使用的 WiFi 管理和认证管理系统存在漏洞，数据传输过程并未加密，导致数据泄漏。此次事件，是不是也因为管理的漏洞呢？

  

**据业内人士测试显示，此次华住遭脱库信息，多个可测试信息显示该数据为新数据，且可信度较高。若此次数据泄露事件属实，该事件或成国内近几年最严重的信息数据事件。**

**密码可以改，但是有些信息是一辈子都改不了的。这个后果很严重。再者，如果这些数据真的是明文保存，那么企业是不是应该注意一下安全方面了！**
