# **绝地求生勒索软件：通过玩游戏解锁文件**

  

最近，研究人员发现一款新的勒索软件，名为绝地求生勒索软件。软件的创新不在于牛X的感染途径，而是解密方式。

  

![](../Images/6434b4c1d6718c672298e069455ee045.png)

  

MalwareHunterTeam发现，当PUBG勒索软件启动时，会加密用户桌面上的用户文件和文件夹，并附上.PUBG扩展名。完成文件加密后，它将显示一个屏幕，提供两种可用于解密加密文件的方法。

  

第一种方法是在程序中输入“s2acxx56a2sae5fjh5k2gb5s2e”代码并单击恢复按钮。不过勒索软件还会通过监视一个“TslGame”的进程来检查你是否玩过绝地求生。

  

![](../Images/388af255609865f3fb76818b0e1724db.png)

  

如果用户玩游戏，勒索软件就会检测到进程，勒索软件将自动解密受害者的文件。勒索软件只会查找进程名称，不检查其他信息以确认游戏，所以只要把个可执行文件改名成TslGame就可以解密文件。

  

![](../Images/5ae91cd306a5f3939c554315039a666a.png)

  

这已经不是第一个搞笑勒索软件了，这类的勒索软件会让用户玩游戏来解密。2017年，MalwareHunterTeam还发现了另一款勒索软件RensenWare，要让感染者们在TH12游戏中获得2千万分，才能恢复你的文件。

# **代刷软件超半数意在“勒索” 360手机卫士建议用户不要使用**

  

近日，360烽火实验室联合360互联网安全中心发布了《勒索软件“假面”系列-代刷软件》(以下简称《报告》)。

![](../Images/7ef9680c8cb314082371e1a50ca5342e.png)

报告显示，代刷主战场已逐渐由Web平台向移动代刷软件转移，仅2017年一年新增的代刷软件就超过了15万个，是2015年总量的35.6倍，由此可见代刷软件增长之势极为迅猛。

  

同时，在360烽火实验室捕获的代刷软件中，有超半数是恶意勒索软件，这些软件对用户的财产和个人信息安全有着极大威胁。

# **YouTube黑客破坏并清除大量流行音乐视频**  

  

YouTube上正在发生一些可疑的事情。看起来谷歌的子公司遭到了黑客的袭击，因为一些流行的音乐视频已经遭到了破坏或者突然消失了。事实上，该平台上观看次数最多的视频--Louis Fonsi和Daddy Yankeee的Despacito 在YouTube上暂时无法观看。

![](../Images/cb564d5f1651b8d896e1057d8347084f.png)

目前尚不清楚攻击的来源是什么，但大多数受影响的视频都是从Vevo帐户上传的。根据The Verge的一份报告，其他受影响的视频包括Chris Brown，Shakira，Selena Gomez，Katy Perry和Taylor Swift的歌曲。大多数这些剪辑已经被编辑以去除损坏的内容。

  

其中一名参与攻击的黑客说，他们使用脚本来篡改视频。与此同时，他黑客组织的另一名成员威胁要取消美国宇航局的YouTube频道，以及有争议的保罗兄弟洛根和杰克频道。

# **谷歌申请新专利，利用区块链技术保护用户数据安全**

  

据了解，谷歌计划借助区块链记录签名信息，再用签名验证存放在数据库中的数据，从而了解数据是否遭到修改，以及被修改的时间。为此，谷歌将开发一种“查封日志”，概念类似于贴在物品上面的封条。

![](../Images/5f9e6f7027e78db7ada51ed9af08d364.png)

根据专利描述，谷歌会使用两种区块链，其中一个负责在总账户标记签名，另一个用于保存验证信息。此外，还需要一个额外验证的电子设备，该设备可以分别辨认出当前区块和下一个区块的签名，并将一个新的区块添加到目标链中，后者的签名基于前两个签名生成。

  

下一个区块和目标区块可使用分布式存储实现，或者基于不同的数据架构创建。在新的区块中，可以包含一个或多个日志，类型既可以是机器日志、性能日志、操作日志，也可以是分户总账条目、授权信息等。

  

# **黑客非法侵入计算机系统 1毛钱“购”100元加油卡**

数月前，一家汽车服务公司向武汉网警报案称，该公司通过网站举办加油卡促销活动期间，资金流出现异常——网上明明售出数十万余元的加油卡，资金却没有通过网上支付平台正常收回，差额巨大，他们怀疑有人在网上做了手脚。

  

![](../Images/4d4b1b2b3dd9ee1ae4c9d2112d4c6109.png)

  

不久后警方将嫌疑人抓获。原来，他们在互联网上下载了抓包工具，以修改付款金额数据包的方式多次作案，共骗得价值50余万元的加油卡，并通过打折优惠的形式销售套现，获利10余万元。
