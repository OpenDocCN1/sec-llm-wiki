# 美国默弗里斯伯勒市水务局遭伊朗黑客入侵：网站关闭

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651962783&idx=1&sn=aebdbb60b3f89d220fa36ee34575cbc8&chksm=f36c91dfc41b18c906a8ea46149ab66101b14bbd3488d9f1dde221507d9169d1791729cc41bd&scene=126&sessionid=1681311886#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651962783&idx=1&sn=aebdbb60b3f89d220fa36ee34575cbc8&chksm=f36c91dfc41b18c906a8ea46149ab66101b14bbd3488d9f1dde221507d9169d1791729cc41bd&scene=126&sessionid=1681311886#rd)

![](../Images/52811614dab8f45330932d19a7eec439.png)

  
美国田纳西州默弗里斯伯勒市的供水和污水处理部门的支付网站遭到黑客入侵。当用户尝试从水务部门网站访问其LINK帐户时，会显示被黑网站。受感染的网页显示了伊朗国旗和Guy Fawkes面具的图像。图片下方的消息称“被伊朗黑客黑客攻击”和“被Mamad警告黑客攻击”，“我们总是离你很近，我们知道你的身份”。

  

![](../Images/a9af1916d999ddf7ec0b3cb01ef56577.png)

  

在此之后，该部门立即关闭了网站并启动了内部评估，以确认黑客的来源和攻击程度。评估确认了攻击仅限于在线的门户网站页面，且没有客户信息遭受攻击。默弗里斯伯勒的公共信息官Mike Browning表示，黑客与城市水务部门账单支付的在线访问是隔离的，该支付网站有两个不同的接入点。黑客通过旧的脚本获得了访问在线门户的权限。  
目前由于网站关闭，客户无法在线支付账单。该市IT部门正在努力恢复网页并加强安全措施。
