# 微软收购数据隐私和治理服务商BlueTalon

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651962681&idx=5&sn=058f0343c65b2b94afcf2d497eed63ed&chksm=f36c9179c41b186f94b5e47f97a669bd55a3ecbacc1a483e385dc26029924452f8b2fd435d51&scene=126&sessionid=1681311890#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651962681&idx=5&sn=058f0343c65b2b94afcf2d497eed63ed&chksm=f36c9179c41b186f94b5e47f97a669bd55a3ecbacc1a483e385dc26029924452f8b2fd435d51&scene=126&sessionid=1681311890#rd)

![](../Images/52811614dab8f45330932d19a7eec439.png)

  

周一，微软宣布收购 BlueTalon，这是一家数据隐私和治理服务提供商，致力于帮助企业制定员工访问数据的政策。然后，BlueTalon 会跨越大多数流行的数据环境执行这些政策，并且还会提供对政策和访问权限进行审计的工具。  

![](../Images/b8a00837ad9b58a3ed1b096a36237c23.png)

  
微软和 BlueTalon 均未披露这笔收购交易的财务细节。Crunchbase 的数据显示，在被收购之前，BlueTalon 已经融到了 2740 万美元的资金，其投资者包括 Bloomberg Beta、Maverick Ventures、Signia Venture Partners 以及斯坦福大学旗下的 StartX 基金。  
“通过收购 BlueTalon 获得的知识产权和人才将在大数据、安全和治理之上为我们带来独特的专业知识。” 微软 Azure Data 的全球资深副总裁罗翰·库马尔（Rohan Kumar）写道，“此次收购将增强我们向各个行业企业赋能以进行数字化转型的能力，同时确保通过 Azure 规模化的集中数据治理来实现数据的正确使用。”  

![](../Images/083ac482d93d15188b4e34cad90ad383.png)

  
并不让人感到意外的是，BlueTalon 团队将加入 Azure 数据治理部门，他们将在那里致力于提升微软在数据隐私和治理方面的能力。当然，微软已经提供了适用于 Azure 的数据访问和治理控制工具。不过，随着几乎所有企业都在变得更加以数据为中心，对能够跨系统运行的中心化访问控制的需求只会变得更加强烈，而新的数据隐私法律会给这个过程增加难度。  
“当我们开始探索与各家超大规模云计算服务提供商进行合作以此来更好地服务于客户时，微软给我们留下了深刻的印象。”BlueTalon 首席执行官埃里克·蒂勒纽斯（Eric Tilenius）在周一的公告中表示（他显然熟谙创业者出售公司的那一套措辞），“Azure Data 团队在数据治理方面具有独特的思考和远见。我们认为，他们在使命和文化方面跟我们非常契合。因此，当微软邀请我们加入他们时，我们抓住了这个机会。”
