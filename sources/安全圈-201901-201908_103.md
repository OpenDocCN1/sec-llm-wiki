# 美国超过60所大学受到ERP漏洞的影响

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651962541&idx=4&sn=027596eb705c50bf8fe05f5579d5971b&chksm=f36c90edc41b19fb77218854d9d006b10c0ae9caa1c7e1c584beff999f9c4a93aa9f4cf0fc2c&scene=126&sessionid=1681311894#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651962541&idx=4&sn=027596eb705c50bf8fe05f5579d5971b&chksm=f36c90edc41b19fb77218854d9d006b10c0ae9caa1c7e1c584beff999f9c4a93aa9f4cf0fc2c&scene=126&sessionid=1681311894#rd)

![](../Images/52811614dab8f45330932d19a7eec439.png)

  

据美国教育部称，黑客利用流行的ERP软件中的漏洞，攻击了数十所美国高校。

  

![](../Images/07594034de1e575d6857dc5c10697253.png)

  

政府上周在一次警报中透露了该活动，并解释了Ellucian Banner Web Tailor版本8.8.3，8.8.4和8.9以及Banner Enterprise Identity Services版本8.3，8.3.1，8.32和8.4都存在问题。

  

前者是Ellucian Banner ERP平台的一个模块，允许组织定制他们的Web应用程序。而后者用于管理用户帐户。

  

所讨论的漏洞名为CVE-2019-8978，是一个“不当身份验证”缺陷，其CVSS 3.0分数为8.1（高），可允许攻击者远程访问用户帐户。

  

一家NIST咨询公司指出，“此漏洞允许远程攻击者通过重复请求初始Banner Web Tailor主页，并将IDMSESSID cookie设置为受害者的UDCID来窃取受害者的会话（并导致拒绝服务）。在此情况下测试的是机构ID。在受害者登录尝试期间，攻击者可以利用竞争条件，并将发出针对该受害者的SESSID。”

  

教育部门现已确定62家受此漏洞影响的大学，并称发现网络犯罪分子主动扫描了尚未修补的组织。

  

官方通告声明，“受害机构已经表明，攻击者利用该漏洞，然后利用Banner系统的招生或入学部分中的脚本创建了多个学生帐户。”  

  

据报道，犯罪分子在24小时内至少创建了600个虚假或欺诈性学生账户，活动持续数天，创建了数千个虚假学生账户。其中一些账户似乎立即被用于了犯罪活动。”

  

虽然该通知警告称，由于Banner“影响或影响学术管理的各个方面”，但该漏洞可能会使财务援助数据面临风险，目前还不清楚到底发生了什么样的犯罪活动。
