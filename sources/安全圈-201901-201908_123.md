# 美国电网疑似遭伊朗网络攻击，纽约大规模停电一片混乱！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651962435&idx=1&sn=91423fc3387426cffe9dfc6c650e1198&chksm=f36c9003c41b1915993ef7504aaf9d23eeaff3f8eb28ebeb80a9b256bff122563b7cc86e01ce&scene=126&sessionid=1681311894#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651962435&idx=1&sn=91423fc3387426cffe9dfc6c650e1198&chksm=f36c9003c41b1915993ef7504aaf9d23eeaff3f8eb28ebeb80a9b256bff122563b7cc86e01ce&scene=126&sessionid=1681311894#rd)

![](../Images/52811614dab8f45330932d19a7eec439.png)

上周六晚，纽约的停电事故导致整个曼哈顿地区没有电力供应; 有趣的是，事件发生当天是1977年发生的大规模停电周年纪念日，这使得整个城市没有电力，交通严重，所有的工作，学术和家庭活动，网络安全专家报告等都受到严重影响。

  

![](../Images/4afce445b3ba78dfbb9e6e32ba53a343.png)一片漆黑的纽约

  

纽约电力供应商公司之一Con Edison提到，事件发生在周六下午16:47，这是由变压器故障引起的。地方当局提到，事故原因将会在调查结束后公布，电力供应将在午夜左右完全恢复。

  

![](../Images/1f7c09843c3932b45600968599ffe39d.png)

停电后市民志愿指挥交通  

  

停电还导致四个纽约地铁站（哥伦布圆环，洛克菲勒中心，哈德逊码头和第五大道）关闭; 据网络安全专家称，列车运营商不得不手动操作一些机制，将乘客到带到最近的车站。

  

![](../Images/48a07143c634a7c230c971903c540323.png)

停电后的地铁站

  

由于停电，出行的路人只能打开手机里的电筒照亮回家的路，大型住宅楼里的居民         不得不走楼梯，曼哈顿陷入了一片混乱。  

  

![](../Images/6c5078a25f8c38206339a5e9a8667a2b.png)停电造成混乱

  

虽然没有负责当局和公司并没有给出事件的确切原因，但谣言并未停歇。根据国际网络安全研究所（IICS）的网络安全专家的说法，这一事件（和类似的事件）与美国政府和伊朗之间已开始的网络战存在联系。

  

最近，伊朗当局声称已经拆除了一个由中情局运营的间谍网络，该网络曾多次逮捕国际间谍，负责中东的情报工作。此外，众所周知，政府资助的黑客团体极具破坏力，据报道黑客攻击活动针对其他政府的电网事件频发，这些电网能够使用复杂的恶意软件变体大规模地破坏能源供应。

 

对于伊朗的主动攻击，俄罗斯认为合理合法，拍手称赞！因美军最先在6月21日，伊朗击落美军无人机后，宣布对伊朗进行信息战攻击。
