# **考生切勿用搜索引擎搜索填报志愿网页？百度刚回应了**

# 

6月26日下午消息，此前山西省招生考试管理中心日前发布提醒，考生在网上填报志愿时，切记不要使用搜索引擎来搜索网上填报志愿系统网页，否则可能误入其他网站。

  

![](../Images/2992a17f7ededca9c36009537e786973.png)

  

对此，百度今日在微博上发布声明称，从2013年开始，百度就启动了对考试招生院官网的保护，将各地招生院官网在搜索结果进行显著位置展示，并为官网免费提供“官网”标识认证。

  

此前，据新华社报道，山西省招生考试管理中心日前发布提醒表示，考生在网上填报志愿时，切记不要使用搜索引擎来搜索网上填报志愿系统网页，否则可能误入其他网站，使自己填报的志愿信息无效，并造成考生密码等个人信息泄露的不良后果。

  

对此，百度今日在微博上回应称，从2013年开始，百度就启动了对考试招生院官网的保护，将各地招生院官网在搜索结果进行显著位置展示，并为官网免费提供“官网”标识认证。

  

在声明中，百度还以“山西招生考试网”为例，表明百度已经为“山西招生考试网”免费提供“官网”标识认证。

  

值得注意的是，百度董事长兼CEO李彦宏的故乡，正是山西省。

  

![](../Images/80a24a8c8088f0c0d61142aa9c54bea4.png)

  

在声明中，百度表示，针对省市级别的高考志愿相关检索需求，百度也会在结果页面进行风险提示。

  

此外，百度表示，针对历年来虚假野鸡大学诱骗考生、非法招生的情况，近年来，百度也在根据国家权威机构公布的信息，持续排查和更新“野鸡大学名录”，方便考生和家长甄别。新一批鸡大学名单将于明日对外公布。
