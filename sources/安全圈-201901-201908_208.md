# **安卓手机现“先天”病毒**

# 

The Verge网站援引谷歌专家的话报道称，黑客掌握了在智能手机激活前在生产阶段就向安卓系统植入病毒的方法。

  

![](../Images/937739000fcde508cdd3938b9f993c55.png)

安卓手机现恶意广告病毒

  

这里指的是Triada系列危险程序，用于在手机上投放广告和发送垃圾邮件。而且专家发现，更新后的这种安卓木马可以预先设定。这种攻击是通过帮助生产商改进功能或提供成品的第三方软件供应商进行，对其服务设置诸多限制。感染特点暂未披露。

  

消息称，这种攻击方式也可在软件更新时进行，因为它们也是由第三方供应商开发。

  

具体有哪些智能手机生产商遭到了Triada病毒攻击，消息没有具体指明。但已经确定的是，2017年中国Leagoo和Nomu手机曾发现这种恶意软件的变种。
