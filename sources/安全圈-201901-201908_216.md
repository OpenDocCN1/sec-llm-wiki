# **防止个人数据上传隐私泄露，完全阻止某应用程序访问网络**

![](../Images/70a72a3189e6d783d74a2639e4eecb7a.png)

# 

# 在我们平时使用Windows时，一些应用程序会在后台偷偷访问Internet，或偷走流量，占用宽带速率，或在用户不知道的情况下将用户数据传回到它的服务器。造成隐私泄露，那么，当我们不得不使用某个程序，而又不希望它偷偷访问网络时，该如何全面阻止它上网呢？其实，不借助第三方工具，仅用Windows即可实现阻止。（也可以用于一些破解过软件，阻止其访问官方服务器去验证是否正版、是否激活。你懂的^\_^）  

  

我们可以使用Windows 防火墙来阻止已安装的任何应用程序访问Internet。

  

以Windows 10演示为例。win+Q 出现搜索框，然后输入“防火墙”，在最佳匹配结果中单击“高级安全Windows防火墙”

![](../Images/2f0e7b08533354f7522d998a4d3787f8.png)

  

在“高级安全Windows防火墙设置”窗口中，选择左侧窗口的“入站规则”，然后点击右侧窗格中的“新建规则”，如下图

  

![](../Images/65d26ba799171e95c80a4c52e0e1fe3c.png)

  

接着将规则类型选择为“程序”，单击“下一步”。

  

![](../Images/516193c4e1d4d8de2b23d721cb117c52.png)

  

接下来的窗口中，选择“此程序路径”并单击其后的“浏览”按钮，选择要阻止的应用程序的EXE主文件，

  

![](../Images/267338a0656584696224e15317081e9a.png)

例如，我们阻止QQ

![](../Images/afda39157a2011fdfb091e739d345800.png)

  

点击“下一步”。在下一个窗口中选择操作类型为“阻止连接”，点击下一步

  

![](../Images/d83c9a7c8af2be500a716fd192ae43e0.png)

  

最后选择应用该规则的场合（默认有3种场合，分别为域、专用、公用）。因为我们要完全阻止该程序连网，因此这里要将3个选项全部选中。

  

![](../Images/aa249a39429e3ff91165cb0336e36172.png)

  

点击下一步，然后可为规则指定一个名称，

  

![](../Images/1e156113e5ed84f4508ca6281acca6e2.png)

  

可根据自己喜好命名或者添加描述，单击“完成”按钮保存它。保存规则后，

  

![](../Images/403314a33a52687bd7314552bc357329.png)

  

双击规则可获得规则的详细信息。

  

![](../Images/f62f1d8d6e050825852b749d4fb4907c.png)

  

左侧“出站规则”中重复以上操作，此时阻止应用程序出入站规则已经发挥作用。如果被封锁的应用程序尝试访问Internet，将显示错误信息。例如QQ

  

![](../Images/bb1a6e7f692df49bb16dc0508cf4b991.png)

  

如果要解除对应用程序的网络封锁，只需删除上述制定的出入站规则即可。

  

![](../Images/c1d0282e731aa2698e0b47879de8513c.png)

![](../Images/aba9fda0fa5eae476b5b1bd22da86706.png)
