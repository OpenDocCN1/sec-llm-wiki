# 把挤回去的牙膏吸出来：恢复因漏洞补丁而降低的性能

# 

在之前的文章中实锤了！Intel打补丁性能大降我们报道了英特尔处理器因为补丁的缘故会降低性能的消息，而微软近期推出的Win10最新累积性更新中有一项采用“Retpoline”技术的升级补丁方案用于恢复被吃掉的性能。

  

Windows 10 1903版中已经默认部署了Retpoline技术，而1809版的用户如果想要恢复性能的话需要手动启用Retpoline，需要在注册表编辑器中进行更改。

# 

![](../Images/60134fd73b19e2c62e927484a7315979.png)

想要找回被吃掉的性能，必须是win10 1809以上版本

![](../Images/7956bb19ba6d6daf41dfbbcb1fadff85.png)

1、开始菜单输入“regedit“，打开注册表编辑器（以管理员身份打开）；

  

2、点击顶部地址栏，粘贴以下内容：“计算机HKEY\_LOCAL\_MACHINESYSTEMCurrentControlSetControlSession ManagerMemory Management“；

![](../Images/fabe94a9ed62214c3400cb6a2592e34f.png)

  

![](../Images/f59c9bc597fdd1bb24522238ab036bf6.png)

进入注册表编辑器

3、双击“FeatureSettingsOverride”和“FeatureSettingsOverrideMask”两个键值，进入十进制编辑模式，将数值修改为“1024”；

  

![](../Images/e8d830b56082b9fc1bf8790b058368b4.png)

最后重启电脑就可以了！
