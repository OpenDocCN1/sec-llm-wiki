你的电脑会不会突然莫名其妙的增加一些软件

  

或者某些数据被删除了

  

有时候突然就像失控了一样

如果有上述问题出现

  

那么你的电脑可能就**存在漏洞**啦！

  

![](../Images/a443e6762cfd3e3809de3653904acf0e.png)

(图片来自网络）  

  

北京时间5月15日，微软发布了针对远程桌面服务（以前称为终端服务）的关键远程执行代码漏洞CVE-2019-0708的**修复****补丁**。该漏洞影响了某些旧版Windows用户们！

  

**快看看你的电脑版本受影响了吗？**

  

![](../Images/90a73a263ab1867a1d3afe568eb77211.png)

  

  

(图片来自网络）

  

这种漏洞属于预身份验证且无需用户交互，因此可以通过网络蠕虫方式被利用，与2017年爆发的WannaCry恶意软件的传播方式类似。

  

也就是说无需身份认证

  

且无需用户干预的情况下

  

即可被远程执行任意代码

  

如安装应用程序，查看、更改或删除数据

  

创建完全访问权限的新账户等

  

一旦有黑客利用该漏洞

  

可能会出现蠕虫病毒大规模爆发

  

影响与危害**极大**！

  

**解决方案**

01

目前，微软已经发布针对该漏洞的补丁，请受影响的操作系统用户及时更新。

  

资源：

Links to downloads for Windows 7, Windows 2008 R2, and Windows 2008

  

Links to downloads for Windows 2003 and Windows XP  

  

Simon Pope, Director of Incident Response, Microsoft Security Response Center (MSRC)

  

  

补丁地址：

https://support.microsoft.com/zh-cn/help/4500705/customer-guidance-for-cve-2019-0708 

  

  

02

无法及时更新补丁的用户，请尽量关闭远程桌面服务，避免主机被直接暴露在互联网上。

  

受影响的用户们可以赶紧行动起来了

  

**及时更新补丁**

  

以防受到该漏洞影响！
