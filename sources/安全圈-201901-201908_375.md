# 预测了所有天气，却预测不到飞来的黑锅

**文 | 谢幺谢幺**

  

大家好，我是谢幺。

前两天网上发生了一件事让我挺生气，今天和大家说说。

  

2月23号那天，Twitter 上有人发了一条推文，号称曝光**墨迹天气APP上传用户 WiFi 账号**。

  

或许是因为用了诸如**“流氓”**、**“隐私跟踪画像”**、**“疯狂”**之类的扎眼词，消息传回国内社交媒体，像一颗鱼雷扔进水塘，BooM!Shalaka。。。

  

![](../Images/75d540947b92297ae41f22ba364ce09e.png)

  

最近两年隐私话题在国内很火，大家神经都蹦得紧，网友的键盘早已饥渴难耐，墨迹天气算是“赶上了时候”：

  

![](../Images/28dd5a1366573da007edc7171f37bc3e.png)![](../Images/17a83d3d6d2bd92bd5b3330ce3937596.png)  

  

喷着喷着，还有人开起了地图炮：

  

![](../Images/d4250947c764ec4d86b76a54835cb4ce.png)

  

更脏的话我就不放出来了，大家自行脑补。总之，墨迹天气很快粘满了网友们扔的臭鸡蛋。

  

**但令我****生气的，并不是墨迹天气，而是这些扔鸡蛋的网友们。**  

  

  

  

**Let's Rock !**  

  

  

其实墨迹天气的事情出了之后，我就挺纳闷：

最近国内“隐私保护“的舆论这么火热，前阵子某大型互联网公司刚被推上浪尖，墨迹天气怎么会傻到顶风作案？不太对。  

  

我就托朋友找到他们公司的一位内部知情人士小张，打算问问情况。  

  

小张的回复是：

  

首先，墨迹天气收集的不是 WiFi 密码，而是公共环境的 WiFi 名称，所以不属于侵犯和泄露**个人隐私**；

其次，这些使用这些信息是用来提升用户体验的，不拿去售卖；

最关键，隐私条款里都写了。

  

![](../Images/1b8da0911191c8428e7c9b82bbd1a332.png)

  

为了验证他的说法，我下载了个墨迹天气APP，发现隐私条款里面确实有写：

  

（截取自墨迹天气APP）![](../Images/7aee181547de4e9efe25e3ea6d09311b.png)

  

但网友们似乎不买账。

  

网友甲就说了：**“这么长的隐私条款，谁看啊？不都点一下就过去了。”**

  

对这个观点我部分认同。大家普遍习惯不看隐私条款，这是事实。但隐私条款严格意义上毕竟相当于一份合同，按规则办事总没错，该看的还是得看，没有习惯就从现在开始养成习惯，否则哪天把自己卖了都不知道。

  

网友乙也发话了：

![](../Images/b538d7fbfa35999b44f19621c34a3931.png)

  

评论区还流传着一个阴谋论：墨迹天气把用户的 WiFi 账号信息卖给第三方大数据营销公司，追踪人们的行踪，做精准营销。

  

我向小张核实，他的原话是：

  

![](../Images/810b56fb4e6e7010eb36e5ca55846e6a.png)

  

言下之意，即便从纯粹的商业角度上来看，买卖数据风险大收益，还不如做他们做正当生意。  

  

可是，一家靠做天气预报的公司能有赚钱？我决定扒一扒墨迹天气。

  

在证监会的官网，我扒到一份招股书，这家公司居然几年前就开始筹备上市了…………

  

![](../Images/1c619686f82a55ab97cb85eef0f4853c.png)

  

一看吓一跳，这家“做天气预报”的公司居然2013年就开始盈利，2017年的营收有3.1亿，净利润有6253万。

  

（截取自墨迹天气的公开招股书）

![](../Images/cd75828d7384666d60e18b5ad0c48df1.png)

  

光做天气预报能挣这么多钱？

我撑着眼皮翻完了两百多页的披露更新信息和一百多页的网络信息……

  

给大家概括总结一下他们的商业模式：

  

先说C端，也就是针对APP用户，他们提供准确的天气预报。

  

一般的天气预报信息都从气象局获取，数据大体上没问题，但不是特别特别精准，于是他们在气象局的基础上叠加了一套预测模型，比如根据过往十几年的天气数据，经过运算，给出一个相对精准的结果。

  

（招股书里摘出的个别核心技术）

![](../Images/54777fb6c2e1078d1b5710399e82150e.png)

  

建立口碑之后，再通过APP里的互联网广告、信息流、会员等方式来挣钱。

  

在B端，也就是企业服务市场，他们尝试做**气象商业化**，把气象数据定制打包给各行各业的企业，为他们节约成本。

  

有新闻报道，目前现在市面上所有的外卖平台，像饿了么、美团外卖、点我达……用的都是墨迹天气的气象数据，主要用来做骑手运力的调配，商家备货等等，（雨天和晴天叫外卖的人数和运送效率都会变化）、还有骑手的绩效考核等等（冒雨送外卖工资给高一些）。

  

![](../Images/5d5c954bb537c46cf2170f1fc9a618cd.png)

  

除了外卖平台，他们还服务电力、物流、航空等行业……这些也占墨迹天气收入的相当一部分。（怎么越说越像是给他们打广告了……）总而言之，这家公司的收入主要靠广告和企业气象信息服务，没有线索表明他们买卖用户数据之类的。

  

但这还是没能解决我的疑惑：

  

![](../Images/1341194ac6306b5bbb581214f2a9e945.png)

  

他的答案是：用来提升用户体验。

  

他说，报告天气、空气指数等等需要结合用户的位置来做。要不然**“北京局部地区有雨”**，你根本不知道“局部”到底指的是朝阳区还是海淀区。

  

墨迹天气利用 WiFi 信息配合其他功能做一个大致的位置判断，根据位置来提供气象服务。

  

![](../Images/f3b680cb3f483e23cd8bd5166bd17ba5.png)

  

**可是，定位的工作难道不应该是用 GPS 来做吗？怎么就轮到 WiFi 了？**

  

他说：“你有没有过这样的经历，打开某个定位APP时，弹出一个提示，让你打开 WiFi 以提高定位精准度？”

我：“好像确实有过。”

  

（iOS和安卓确实都有）

![](../Images/57622d1ff53c298085b6884c96168cbe.png)

  

接着，他又给我科普了一段关于定位的姿势，这里给大家复述一下。

  

以往，大家都认为手机定位主要依靠GPS，实际上，定位的方法有很多种。

  

速度最快也最普遍的，其实是 GSM 信号定位。它的门槛最低，只要手机有信号就能定位。

  

我们出门旅游时，经常在半路上收到类似 **“花果山福地，水帘洞洞天，XXX市旅游局欢迎您”**之类的短信，其实就是基于手机信号获取的位置。

  

原理很简单。我们生活在一个充满基站和信号的环境，它们的分布就像是蜂窝格子一样，所以又叫蜂窝网络。

  

最简单的位置判断方法是：**你的信号在某个基站的“射程”里，那你的地理位置肯定也站在这个蜂窝格子里。**

  

（图片源自百度百科）

![](../Images/a5d18d4ebaa2a403bbe21443c96f6a6c.png)

  

稍微复杂一丢丢，如果你周围有三个基站，只要计算一下每个基站信号到你手机的传播时间，就能用“三点定位法”估出一个较准的位置。

  

你周围基站更多，定位就更准。

  

![](../Images/8840a331c5105b10d5b4536dacb5e743.png)

  

总之，GSM 可以用来定位。

  

那 WiFi 又是怎么定位的呢？道理和基站定位类似。

  

你能搜到某个热点，那你肯定在路由器附近。（不管连不连这个 WiFi，只要手机能搜到信号就行）

  

你的手机能判断每个 WiFi 的信号强度，所以只要你身边出现三台 WiFi 路由器，就能通过三角定位原理来确定坐标。

  

周围的 WiFi 热点越多就越准确。

  

![](../Images/5105fa277e521c591a15db53e4e85fcc.png)

  

  

为什么需要用 WiFi 来定位？因为GPS 定位虽准，但缺点很明显。

  
首先是启动速度慢，冷启动一般接收信号就十几秒到一两分钟；其次是信号功率非常低，对接收要求比较高，天线对天空之间不能有遮挡物，需要在室外或者窗边用，站在封闭的屋内用导航，多半会提示你**“当前GPS信号弱”**。

  

所以通常我们刚出门，站在小区楼下打开定位，定位信息一开始多半是由 GSM  和 WiFi 提供的，得等好一会儿才能收到 GPS 的准确定位信息。

  

除此之外，还有蓝牙定位、磁场定位、IP定位等等，它们各有各的优缺点和使用场景…………

  

**扯远了，总之，WiFi 信息是用来定位的。**

  

你去翻了翻高德地图和百度地图等主流地图的隐私条款，其实都涉及 WiFi 数据：

  

（高德地图）

![](../Images/171069476ab3b17dae497db25dc542ba.png)

  

（百度地图）

![](../Images/ef199fcc93fbe0b1b847d827e24d3092.png)

  

可能有人还要问了：**“会不会只有国内软件才这样？”**

  

我下了个谷歌地图，发现外国的月亮并没有更圆，谷歌地图连蓝牙信息和传感器数据都拿了。

  

![](../Images/c115053b7ac0b248d1a67bebad06b3b4.png)

  

再看看苹果，也需要这些权限。并且苹果也还会为你多考虑一步：在拨打紧急电话时，无论你是否开启定位服务，都给你定位。

  

（苹果的隐私条款）

![](../Images/d523d56d0faa3103c1e13fe4a2b3198f.png)

  

到这一步，瓜就吃完了。

  

倘若墨迹天气真的侵犯了隐私，被唾沫淹死也不足惜。但照目前的情况看来，它只是做了一件谷歌、苹果都会做的事情而已，并且初心是想帮大家更好地预测天气。

  

事实上，就在事情发生的第二天，最开始说曝光这事的人又发了一条推文，讲 google 在“信息拼接”这件事上比更厉害。

  

![](../Images/eff04b424d7356d1fb2b764035a65191.png)

  

但是似乎并没有人关心这一条了，国内的观众们依然把炮火瞄着墨迹天气。

  

对于隐私、流氓软件行为，最近人们都很关注也很谨慎，一朝被蛇咬十年怕井绳，大家都怕了。于是人们不希望放过任何一个作恶者，一有风吹草动便群起而攻之。

  

这当然没错，但请不要杀红了眼。

  

隐私泄露当然可怕，但更可怕的是人们失去判断力，无脑跟风，错伤了那些想要好好干的人。

  

有人说，国内的 APP 公司全是流氓，国外的 APP 都很正常。我更愿意承认，国内的 APP 创业者有流氓的，也有不流氓的，国外同样。正如世上的人有好也有坏，自媒体不全是编瞎话赚流量的，广东人并不都爱吃福建人。

  

滥杀的正义并非正义。不放过每个作恶者，也不要冤枉任何一个好人，这才有可能解决问题。
