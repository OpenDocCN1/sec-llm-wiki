上海蓝道信息技术有限公司


【公司介绍】


上海蓝道信息技术有限公司成立十余载，业务范围涵盖代理销售、技术支持和咨询服务等领域。我们始终坚持以提供成熟稳定的存储系统、数据管理产品和网络安全系统以及与之相关的技术支持服务为企业目标，以帮助客户提高核心竞争力为己任，秉承“真诚、沟通、勤勉、高效”的企业精神，专注于技术优势与产品优势的整合，致力于成为业界领先的数据安全、网络安全、系统安全产品和解决方案的供应商和技术服务提供商。 


【招聘职位】


高级网络安全工程师  15k-20k/月

本科及以上/3年及以上/上海

 

【职位要求】


1. 计算机相关专业，本科以上学历，3年以上IT工作经验； 

2. 具有网络安全方面的方案，实施，故障排除等经验；

3. 熟悉各厂家网络安全产品配置，管理；

4. 熟悉网络安全基本技术和主要的安全协议；

5. 掌握网络安全风险的分析以及评估；

6. 掌握网络安全新技术发展趋势；

7. 具有CCNA，CCNP者优先考虑。


【工作职责】


1. 具备良好的团队合作精神，乐观向上，勇于接受挑战，不怕困难，工作努力；

2. 熟悉网络安全方面知识，如防火墙，上网行为管理，负载均衡，VPN等;

3. 熟悉各品牌网络设备的配置，调优，故障排除;

4. 协助公司销售人员与客户建立良好的合作关系，善于协调和解决公司的各类技术问题。



高级备份工程师   15k-20k/月

本科及以上/3~5年/上海

 

【职位要求】


1.计算机相关专业，本科以上学历，5年以上IT工作经验；

2. 具有主流备份系统的运维管理，安装部署经验；

3. 精通主流操作系统（RedHat，Windows）； 

4. 精通至少一种主流备份软件（Commvault，NBU，NetWorker等）；

5. 熟悉至少一种主流存储 (NetApp, DELLEMC等 )；

6. 精通磁带库或者虚拟磁带库方面知识；

7. 具有主流数据库、虚拟化工作经验者优先；

8. 年龄25-40。


【工作职责】


1. 具备良好的团队合作精神，乐观向上，勇于接受挑战，不怕困难，工作努力；

2. 备份系统专家；

3. 具备丰富的备份系统部署安装，运维经验；

4. 协助公司销售人员与客户建立良好的合作关系，善于协调和解决公司的各类技术问题。


实习生3k-5k/月

大专及以上/无经验/上海

 

【职位要求】


1. 专业方向上并无特别要求。最好是对IT服务行业有兴趣; 

2. 能以开放、主动的心态迎接工作中的各种挑战;

3. 具备良好的团队合作精神。 


【工作职责】


1. 实习生岗位为希望增加社会实践经验的大学生提供学习、积累工作经验的良好机会;

2. 提供销售、技术、行政、财务等助理岗位;

3. 实习期间表现良好的应届毕业生有机会转正为正式员工;

4. 实习岗位既能提供接触社会，积累经验的机会，也能提供和蓝道信息共同发展的机会。 



福利待遇：五险一金、双休、年假、每年一次国内/外旅游
