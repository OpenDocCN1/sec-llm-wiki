# RedHat 移除 MongoDB

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651960967&idx=5&sn=60118d79ec643a4808b491680e65c525&chksm=f36c9ac7c41b13d174365924c2153a2532d8ab46f4f51a601eee8d560c60453681c50328f500&scene=126&sessionid=1681311942#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651960967&idx=5&sn=60118d79ec643a4808b491680e65c525&chksm=f36c9ac7c41b13d174365924c2153a2532d8ab46f4f51a601eee8d560c60453681c50328f500&scene=126&sessionid=1681311942#rd)

![](../Images/4ceeea45bc569fc45f7a8ec0a8cd2813.png)

  

去年十月，MongoDB 宣布其开源许可证从 GNU AGPLv3 切换到 Server Side Public License (SSPL)，希望从软件即服务或云计算业务上获取收入。但更改许可证正导致Debian Linux 也已经从它的发行版中删除了 MongoDB。

  

前几天 AWS 推出 DocumentDB，以替换原有基于 MongoDB 源码的产品，被视为是对 MongoDB 的一大反击，而这两天英国卫报也完全弃用 MongoDB，最新消息是开源大佬红帽宣布从 Red Hat Enterprise Linux（RHEL）8 中删除 MongoDB。

  

![](../Images/98da982ecda249dc1e393885809b0d55.png)

  

在最新的 8.0 Beta Release Note 中，RHEL 明确表示因为 MongoDB 使用了 SSPL 协议，所以将不会在 8.0 系统中提供该数据库。

  

开源厂商修改协议的做法本身无可厚非，但是像 MongoDB 这样被各方都视为“不法”则属于头一回，随着开源不断被重视，各方利益冲突在所难免，接下来会怎么发展？
