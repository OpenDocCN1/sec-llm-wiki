2020年 Linux设备或将爆炸式增长

2020 年即将到来，Linux 在接下来又会有怎样的发展？Omg Ubuntu 网站的作者 Joey Sneddon 给出了关于 Linux 和开源的五个预测：


Linux 设备将呈爆炸式增长


明年我们将看到大量新的 Linux 硬件上市，这并不是一个疯狂的猜测。


Sneddon 想知道我们最终是否可以用上不基于 Intel/Nvidia 组合的 Linux 笔记本电脑？他表示自己目前在 AMD 硬件上运行 Ubuntu，体验非常棒。

新的一年将由 Pine64 和即将推出的 PinePhone 打头阵。


这款售价 149 美元的 Linux 手机价格实惠，运行带有主流 Linux 内核支持的开源软件。而且，它背后的公司不会止步于此。定于 2020 年上市的还有价格为 79 美元的 PineTab Linux 平板电脑和价格为 25 美元的 PineTime 智能手表，它们不是基于 Linux 的，但确实都可以运行开源软件。


如果 Pine64 明年发布更多的硬件，无论是新产品还是改进产品，都不会令人惊讶，而是意料之中。



Focal 成为焦点



Ubuntu 19.10 发布后，被用户们投票为“十年来最好的 Ubuntu 版本”。接下来，预计于 2020 年 4 月发布的 Ubuntu 20.04 LTS 将成为最重大的版本之一，尤其是对于那些从 Ubuntu 18.04 LTS 升级的人来说。数以千万计的 Ubuntu 用户使用 LTS 版本，这意味着 LTS 更新非常重要。


虽然以前的 LTS 版本仍可用，但它或许并非最佳。在过去的两年中，仅 GNOME Shell 所做的性能改进就非常可观。Sneddon 认为，Ubuntu 20.04 LTS 将在之后脱颖而出。



WSL 将有更大改进



曾经在 Windows 的 Ubuntu 上曾经被称为 Bash 的 WSL （ Windows Linux 子系统）算是今年的重大新闻之一，这在一定程度上要归功于 WSL2 的巨大改进。


Canonical 希望明年 WSL 在 Ubuntu 上更加流行。该公司不仅成为了微软首届 WSL 会议的赞助商，而且还在积极雇用更多的开发人员、投入更多的资源来进行这项工作。


去年的这个时候，应当很少有人想到 Linux 将像现在一样成为微软开发战略不可或缺的一部分。随着开发人员社区不断突破技术能力的界限，预计在 2020 年，WSL 将出现更多意想不到的飞跃。



GNOME 操作系统出现


这个大胆的预测听起来有点疯狂，但在 Sneddon 看来，这是有道理的。

他对 GNOME 的印象是，GNOME 设计团队对如何使用 GNOME Shell 桌面的愿景与 GNOME Shell 桌面实际被使用的方式不一致，尤其是下游发行版。


围绕第三方 GTK 主题、替代样式表、不同图标等的影响的一些“担忧”让人想知道，至少在简单化的世界中，按预期使用 GNOME OS 是否会有所帮助。KDE Neon 的成功证明，人们渴望以“期望的”方式进行一流的呈现。



轻量级、重量级


低端设备性能的提高将成为明年大多数主要 Linux 发行版中的主要趋势。


GNOME 3.34 带来了明显的性能提升。在 Ubuntu 开发人员的帮助下，这项工作将在即将于明年发布的 GNOME 3.36 和 GNOME 3.38 版本中继续进行。


此外，KDE Plasma 已经证明了自己在低功耗 ARM 笔记本电脑（例如 PineBook Pro）上的可行性。而且，由于 Raspberry Pi 4 现在也能够带来“桌面”风格的体验，因此发行版在此特定领域也有很多机遇。


再加上 Alpine Linux 提供桌面支持的早期阶段，以及对更轻量的 Linux 发行版（如 Peppermint OS、Zorin OS Lite 和 elementary OS）的兴趣日益浓厚，Sneddon 认为自己对低性能启动的预测是带有必然性的。


除了以上几点预测内容，Sneddon 也表达了自己对接下来的愿景，分别是希望延长 Linux 电池寿命、更多出色的本机 Linux 应用，以及适用于 Ubuntu 的更好的 App Store。


在新的一年里，你对 Linux 和开源又有什么想法和期待呢？
