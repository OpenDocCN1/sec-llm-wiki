# 今后Windows 10新功能有望独立于系统 以更快分发

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651965035&idx=3&sn=394893b06d3d3ab891d396769278c16b&chksm=f36cea2bc41b633dc3df1d4b9436b7c4b9f3512dd4fcb2fc80ac6b49121e4e2f17f361c933fc&scene=126&sessionid=1681311837#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651965035&idx=3&sn=394893b06d3d3ab891d396769278c16b&chksm=f36cea2bc41b633dc3df1d4b9436b7c4b9f3512dd4fcb2fc80ac6b49121e4e2f17f361c933fc&scene=126&sessionid=1681311837#rd)

![](../Images/010dbe333e8005ccf96e3219ae27adbc.png)

  

在面向全球用户推进Windows 10 November 2019 功能更新的同时，微软已经将开发重心放在即将于明年春季上线的Windows 10 Version 2004上。**根据最新报道称，微软似乎正计划以更智能的方式来推动Windows 10新功能和重要改进的引入。**

# 

  

![](../Images/40d3ed18ffb590f3894a228bc2b020df.png)

  

在日前宣布**Fast通道的Windows 10版本更新不再受到功能更新的束缚**，今后最新版本表明微软团队在开发上的最新状态。而现在又有证据表明微软计划剥离Windows Core OS和Shell Experience，从而实现更快速的功能更新和改进。

  

![](../Images/cefea1318bfe89ba921a48baca00982b.png)

  

![](../Images/81be7c98abff1bce5ea7a9c7c6f82b26.png)

  

在Windows 10 Version 2004最新预览版设置应用中的“关于”部分，以及Microsoft Store上已经出现了Windows Feature Experience Pack这款新应用。熟悉该开发的人士认为，Microsoft可以使用它独立于常规更新将Windows 10的新功能和改进推送到Windows 10。换句话说，**Windows 10的某些功能可以单独下载，而不是通过单个主要操作系统更新来提供**。

  

![](../Images/4820a1fa24ddd77854043ac018c7a847.png)

  

![](../Images/1e25fb57c2f22d6252fd63580016a13b.png)

  

尽管“ Windows Feature Experience Pack”目前无法执行任何操作，但将Windows 10拆分以进行更快的更新无疑是正确的发展方向，能够让Windows 10X和Windows Core OS家族生态更加完满。

  

另一个泄漏表明，微软正在重组Windows和Azure中的团队，以加快Windows 10的开发。这家技术巨头可能将团队分为CoreOS团队和Shell Experience，因此更新和改进可以更快地推向消费者。
