微软Edge插件网站上线(beta)：带搜索功能及162个扩展

据外媒报道，微软Edge Insider插件(Add-ones)网站不再局限于Insider，现在，微软Edge插件网站（Beta版）正式上线。用户将可以它的搜索功能查找自己想要的扩展，新增的40个扩展使得扩展总数超过了160个。


尽管Chromium Edge允许用户安装Chrome网络商店的插件，但微软仍然保留了一个专门的插件商店。直到昨天，该商店提供的插件数量还只有123个，包括广告拦截器、密码管理器、OneNote Web clipper等等。


微软Edge插件商店（Beta版）


通过对扩展商店的重新设计，微软重组了附加组件部分并 将广告拦截器和密码管理器中的扩展转移到生产力部分，另外还为购物和社交提供了大量新扩展。


现在，微软将Edge插件分为以下几类：

Accessbility

Blogging（博客）

Developer Tools （开发者工具）

Entertainment（娱乐）

News& Weather（新闻&天气）

Photos（照片）

Productivity（生产力）

Search Tools（搜索工具）

Shopping（购物）

Social（社交）





Micrsoft宣布Edge插件网站的稳定版发布日期为2020年1月15日。
