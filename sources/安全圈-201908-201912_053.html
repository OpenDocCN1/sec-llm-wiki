开源办公套件LibreOffice 6.3.4发布 带来大量修复和改进

原文：http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651964905&idx=4&sn=eb0b487d9209dba2747ab160041fe485&chksm=f36ce9a9c41b60bf3e21488e05b7581b16816119255e9d58b0c44e9a6e824fde36cb06b314dc&scene=126&sessionid=1681311842#rd


Document Foundation 已发布了适用于Windows，Linux 和 Mac 的 LibreOffice 的新版本，即 LibreOffice 6.3.4。这是 LibreOffice 6.3 系列的第四个次要版本，而此次更新则主要是“针对技术爱好者和超级用户”。


事实上，LibreOffice 6.3.4 在错误修复和改进方面是一个重要的版本，其包括了 120 多个错误修复和对文档兼容性的改进。据悉，LibreOffice 6.3.4 的稳定版本包括先前在 RC1 和 RC2 版本中引入的所有改进，包括从模板创建新文档时从所有宏中删除签名的错误修复，以及在使用 DOCX 文件时 Writer 表中的合并单元不正确格式。


同时，该版本还解决了许多崩溃问题，其中包括在重新打开的文档中剪切文本框时 LibreOffice 应用程序意外关闭的状况。TDF 表示，它还解决了使用查找和替换功能时导致 LibreOffice Calc 挂起的问题。


此外，对于 Windows 用户而言，一个显着的变化就是，其需要安装 Windows 7 或更高版本。也就是说，LibreOffice 6.3.4 不能安装在 Windows XP 或 Windows Vista 上。
