# 20家Web托管商突然关闭 只给客户两天时间下载数据？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651964818&idx=2&sn=325e21ab4fd74b4cce586a2ad55b0de5&chksm=f36ce9d2c41b60c4bae3ca6929b59906c55a10951f55841ad20a3fe89eff713bcff39fad0d24&scene=126&sessionid=1681311846#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651964818&idx=2&sn=325e21ab4fd74b4cce586a2ad55b0de5&chksm=f36ce9d2c41b60c4bae3ca6929b59906c55a10951f55841ad20a3fe89eff713bcff39fad0d24&scene=126&sessionid=1681311846#rd)

![](../Images/53cb3792038be38d83be203427063201.png)

  

至少 20 家 Web 托管服务商在上周末突然通知客户，宣布将在周一关闭，只给客户两天时间从服务器下载数据。所有服务商提供的都是提供廉价的 VPS 服务，所有网站都有着相似的页面结构，使用相同的邮件模板通知客户。  

![](../Images/a8c7020ef9d71bd2201d60c25f3c144f.png)

种种迹象显示它们可能是同一个实体运营的，一些客户认为这是某种“退出骗局”，认为这些 VPS 服务商背后的公司携款跑路了。业内人士称这是 Web 托管行业低端市场的常见现象。
