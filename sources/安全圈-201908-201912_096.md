# 恶意 Python 库被发现会窃取 SSH 和 GPG 密钥

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651964731&idx=4&sn=bf5221898fe49c178b67b0b69dddc852&chksm=f36ce97bc41b606dffc69f3b808b22ba97b2e1401996e6e32b79466149210b42c3136eb4191a&scene=126&sessionid=1681311846#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651964731&idx=4&sn=bf5221898fe49c178b67b0b69dddc852&chksm=f36ce97bc41b606dffc69f3b808b22ba97b2e1401996e6e32b79466149210b42c3136eb4191a&scene=126&sessionid=1681311846#rd)

![](../Images/53cb3792038be38d83be203427063201.png)

  

Python 安全团队从  PyPI (Python Package Index) 移除了两个被发现会窃取 SSH 和 GPG 密钥的恶意 Python 库。两个库都由同一名开发者创建，利用名字相似的方法去模仿已知的流行库的：python3-dateutil 试图模仿流行的 dateutil 库，jeIlyfish 模仿 jellyfish 库。

  

![](../Images/24a1789ed7469affc8f96a75be19dfeb.png)

  

德国开发者 Lukas Martini 上周日发现了这两个恶意库，在通知安全团队之后它们被立即移除。

  

![](../Images/bb6e207652482737dd13bfbee20d386f.png)Martini 称，恶意代码只存在于 jeIlyfish 中，python3-dateutil 本身不包含恶意代码，但它会导入  jeIlyfish 库。

  

dateutil 开发团队成员 Paul Ganssle 分析后认为，恶意代码是尝试从用户计算机上窃取 SSH 和 GPG 密钥，然后发送到一个 IP 地址。
