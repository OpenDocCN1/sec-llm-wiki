# 交易所被“黑”，炒币者遭遇爆仓，亏损赔不赔？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651964644&idx=3&sn=ea29fc12b5a4eb6e81c0bae08a849163&chksm=f36ce8a4c41b61b2066db9f8d2a43cd303968a63de485ae4946f704ff7137640d675e0aad3eb&scene=126&sessionid=1681311846#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651964644&idx=3&sn=ea29fc12b5a4eb6e81c0bae08a849163&chksm=f36ce8a4c41b61b2066db9f8d2a43cd303968a63de485ae4946f704ff7137640d675e0aad3eb&scene=126&sessionid=1681311846#rd)

比特币、莱特币，自一诞生就吸引了无数人的眼光。近年来，伴随着比特币的暴涨，投资者、交易所、币圈自媒体以及各种不明身份的基金会、项目方纷纷涌入，构造了币圈新“生态”。

  

在虚拟货币交易的所有环节中，交易所上承项目方，下接各路韭菜，可谓是产业链的核心枢纽，特别是顶级虚拟货币交易所。而交易所一旦被黑客攻击，受到威胁的就是广大投资者“钱包”。

  

日前，中国裁判文书网就公布了这样一起案例。一名炒币者在一家虚拟货币交易所进行交易，交易所遭遇黑客攻击，其被宕机、插针、爆仓，亏损49.2个比特币和3136个莱特币。而被告的交易所称虚拟货币合约是网络游戏，不是期货；黑客攻击是不可抗力，是可以免责的。

  

![](../Images/6082130b454c5835842d3b2e28edabf3.png)

  

**交易所被黑客攻击，投资者遭遇爆仓**

  

近期，北京市海淀区人民法院公布了韦某与北京乐酷达网络科技有限公司侵权责任纠纷一审民事判决书。

  

判决书内容显示，原告韦某诉被告北京乐酷达网络科技有限公司（以下简称“乐酷达公司”）侵权责任纠纷一案，北京市海淀区人民法院于2016年5月6日立案后，公开开庭进行了审理。

  

根据法院认定事实，乐酷达公司系手机应用软件“okcoin比特币”的开发者，通过该手机应用软件可以登录www.okcoin.com（okcoin国际站网址）及www.okcoin.cn（okcoin中国站网址）。

  

据悉，2015年7月10日，莱特币市价大跌，7月13日比特币大跌，okcoin平台称被黑客攻击而瘫痪，黑客恶意操纵价格，客户无法上线进行操作，导致大量客户爆仓蒙受重大损失。两次黑客攻击造成的网站停机事件，平台数据异常。

  

据韦某所言，其无法上平台进行操作，在平台上的莱特币和比特币没有能够操作止损，损失了57.9个比特币和3136个莱特币，经与okcoin公司交涉，okcoin公司赔偿其15%的损失，赔偿了他8.7个比特币、1个充电宝和1个月的交易手续费，剩余的49.2个比特币和3136个莱特币okcoin公司以自身也受黑客攻击受损失为由拒绝赔偿。

  

在本案中，原告韦某向北京市海淀区人民法院提出诉讼请求：判令乐酷达公司赔偿其2015年7月10日、2015年7月13日在okcoin公司平台交易因服务器被黑客攻击而受损失的49.2个比特币和3136个莱特币。

  

而韦某向法院提交其账户交易信息截图，合约账单显示，2015年7月10日17时29分49秒，其账户LTC0925合约被强平，LTC合约张数-9.771，LTC权益-3136.0919179；2015年7月13日15时21分09秒，其账户BTC0925合约被强平，BTC合约张数为-1.898，BTC权益-57.957086。

  

韦某还指控，乐酷达公司涉嫌非法经营期货，并操纵市场诈骗客户。因乐酷达公司涉嫌非法经营期货，且安全技术水平低下，经常出现网络瘫痪情况，擅自非法修改网站后台数据，使其放在平台上的财产遭受巨大损失，故诉至法院，请求赔偿其全部损失。

  

![](../Images/28aea9f6ea235a1b896e7435368f419b.png)

  

**交易所：****比特币合约是一种“网络游戏”**

  

对于韦某指控的非法经营期货，乐酷达称，其与诉争网站均未从事比特币期货交易，也不符合期货交易的法律特征，实际上是比特币的网络游戏。其也没有修改K线图和人为操纵价格的行为。

  

乐酷达表示，该网络游戏与期货交易的主要区别是期货交易以保证金进行合约买卖，其经营的是用比特币进行比特币合约买卖，用莱特币进行莱特币合约买卖，合约是期货交易中的概念，该合约是用保证金购买的，但比特币和莱特币是网络虚拟商品，根本不是保证金。之所以称比特币和莱特币交易是网络游戏，是因为这种交易只是借鉴了期货交易的概念，但实际上只是一种游戏。

  

其次，乐酷达公司辩称，韦某的损失即使客观存在，其计算方式也是错误的。韦某的损失是黑客攻击造成的，而在网站的服务条款中约定黑客攻击是不可抗力，是可以免责的。

  

再次，被告乐酷达公司辩称，诉争www.okcoin.com网站（即国际站）是由总部在香港的OKEXFINTECH公司负责运营，无论该网站发生什么样的法律责任，都与乐酷达公司无关。

  

此外，乐酷达公司还表示，诉争网站在其首页显著位置有明确提示“本网站服务于非中国区客户，中国区客户请到中国站去”，中国站网址为www.okcoin.cn，通过www.okcoin.com的页面也能够进入中国站。诉争网站与用户签订的用户协议明确约定中国区用户不得登录诉争网站国际站，否则后果自负，用户协议的约定和网站国际站的提示都禁止中国区客户使用诉争网站国际站进行交易，韦某对此是明知的。故即使韦某有损失，也应自行承担。

  

法院认为，乐酷达公司称其已将www.okcoin.com网站移交香港公司运营、其并非该网站的运营方，但未提交充分证据证明，且乐酷达公司系www.okcoin.com网站在工业和信息化部备案的主办单位，通过乐酷达公司开发的okcoin手机应用软件及乐酷达公司官方网站均可登录www.okcoin.com网站，www.okcoin.cn网站亦发布信息为www.okcoin.com进行宣传，在发生黑客攻击后，www.okcoin.cn网站同时对攻击情况进行了说明。

  

综合上述情况，法院认为，韦某在比特币合约和莱特币合约交易过程中，乐酷达公司参与为韦某提供服务，双方形成合同关系。在交易过程中，乐酷达公司提供的服务存在瑕疵，致使攻击时宕机，韦某无法及时交易产生比特币和莱特币损失，该损失系双方合同标的物的损失，应在合同纠纷范围内予以解决。

  

但经法院释明，韦某坚持以侵权责任纠纷提起本案诉讼，该主张无事实及法律依据，法院不予支持。驳回韦某的全部诉讼请求。

  

**原告：****已按合同纠纷起诉**

  

案件没有就此结束，紧接着北京市第一中级人民法院发布了韦某与北京乐酷达网络科技有限公司侵权责任纠纷二审民事裁定书。裁定书显示，韦某不服一审判决，进行了上诉，但后又撤回上诉申请，表示经慎重考虑，服从一审判决结果，自愿依法申请撤回就本案上诉。

  

上诉又撤回是怎么回事，案件是否到此结束？带着疑问，每日经济新闻（微信号：nbdnews）记者采访了当事人韦某。

  

韦某说，2014年底，他从网上看到消息，接触到比特币，就开始在虚拟货币平台上交易，主要在一家名为OKCoin的平台上交易。当时平台上的比特币合约，不叫合约，叫做期货。

  

他先后投了二三十万，有赚有赔，但做期货后，赔得多、赚得少。当时的期货平台“服务器很不稳，经常宕机、被黑客攻击”。

  

“我告他们的那次是比较严重的问题，完全登录不了，无法平仓。我跟他们交涉，他们说赔15%（7月13日比特币爆仓量的15%）。”韦某说道，“我一直在申诉，通过电话、投诉信等手段，找公安、证监会等行政部门维权，后来我就通过法律的途径维护自己的权利。”

  

韦某向记者展示了2015年7月10日莱特币大跌，OKCoin平台宕机时，他跟OKCoin交涉的截图。

  

![](../Images/efa7b016de12c127eac33430a0603ea1.png)

韦某与OKCoin交涉截图（受访者供图，点击可看大图）

  

关于什么是插针，韦某向记者举例。譬如2015年11月10日，OKCoin被人操纵恶意做空，平台上的莱特币从35.75元，瞬间跌到0.01元，就像一根长针，暴跌99.97%，价格接近于零。但随后马上再恢复原价，在如此暴跌情况下，任何做多的合约都将被击穿爆仓。

  

![](../Images/e1613411c9f115a39b3b7adc4747765d.png)

okcoin莱特币暴跌时K线截图（受访者供图）

  

但在OKCoin随后展示的K线图中，在2015年11月10日的这张图中，莱特币最高价格35.75元，最低价格18.42元，没有0.01元的价格。

  

![](../Images/86da03f18967e442350ed5cbb8715bd3.png)

okoin平台修复后的K线截图（受访者供图）

  

关于下一步的准备，韦某说：“现在撤诉了，第一次以侵权起诉，现在按合同纠纷起诉了，已经起诉了。诉讼请求还是全额赔偿我2015年7月10号、13号的损失。”

  

“因为目前注册在境外、面向中国境内的所有虚拟货币交易所都在中国金融监管机构的监管之外，这就意味着他们所有的数据是否暗箱操作，是否存在内幕交易，是否存在市场操纵，以及其他的任何违法违规的行为，中国的监管机构都难以进行实时监管。因此，交易者在通过上述虚拟货币交易所交易的时候，资金可能会遭受极大的损失或者面临洗钱、犯罪等相关的负面冲击。”
