# 濮阳公安摧毁一侵犯公民个人信息团伙

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651964443&idx=2&sn=215b110fa5749c559798439bf32bade4&chksm=f36ce85bc41b614d38d4f44ac01290a5280494e5d46221cec58afe3c97b1cf1fa1bef8268793&scene=126&sessionid=1681311850#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651964443&idx=2&sn=215b110fa5749c559798439bf32bade4&chksm=f36ce85bc41b614d38d4f44ac01290a5280494e5d46221cec58afe3c97b1cf1fa1bef8268793&scene=126&sessionid=1681311850#rd)

![](../Images/53cb3792038be38d83be203427063201.png)

  

“您的新房需要装修吗？我们保证质优价廉！”“您需要购买新房吗？价格优惠，不可错过”……近日，河南省濮阳市公安局大庆分局打掉一个侵犯公民个人信息团伙，犯罪嫌疑人张宗某等3人因**涉嫌侵犯公民个人信息罪，已被警方依法采取强制措施。**

![](../Images/37d5a15aaf9c167ef63826792b5d0faa.png)

  

“在这个高度信息化的时代，个人信息成为不法分子眼中的商品，侵犯公民个人信息违法犯罪活动日渐猖獗，个人信息安全不断受到挑战。”据大庆分局相关负责人介绍，民警在办理某案件调取证据时，发现一笔记本电脑里存有大量公民个人信息，经粗略统计，数量达数万条。民警感到案情重大，迅速将相关案情上报。

  

**后经查实，该电脑非法储存的公民信息有3万余条。**

  

涉案的笔记本电脑所有人为张宗某，系某装修公司经理。张宗某供述说，这些公民信息是其通过购买、交换等方式收集到的。民警根据查获到的线索，将出售给张宗某公民个人信息的犯罪嫌疑人张铁某和石某抓获归案。

  

经查，张铁某为某售楼部工作人员，其利用工作便利，将获取到的买房人的姓名、联系方式、家庭住址等信息，出售给张宗某。石某为另外一装饰公司的业务员，自2016年起，其通过与其他装修公司、建材商、新建小区售楼部工作人员、小区保安队长等拉关系，多次购买或互换小区业主信息，并将获取到的业主信息出售给张宗某。

  

民警在调查中发现，涉案的张宗某、张铁某和石某利用获取的公民信息，联系、拓展自己公司的业务，并通过非法购买、交换的方式，相互获取更多的公民信息，致使大量的公民信息在其业务领域内不断流转。
