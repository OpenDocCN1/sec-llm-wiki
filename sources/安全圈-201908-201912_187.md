# 游戏“作弊”也犯法！江苏宿迁警方破获一起特大外挂案件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651964330&idx=2&sn=b8dc8dbdcc67a86468bd1d0f8f53de22&chksm=f36cefeac41b66fc517d729f4266c09b3e46f8eed3b35bc0ea27b82c43e459292f815f4d572f&scene=126&sessionid=1681311854#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651964330&idx=2&sn=b8dc8dbdcc67a86468bd1d0f8f53de22&chksm=f36cefeac41b66fc517d729f4266c09b3e46f8eed3b35bc0ea27b82c43e459292f815f4d572f&scene=126&sessionid=1681311854#rd)

![](../Images/53cb3792038be38d83be203427063201.png)

  

随着网络游戏市场的火爆，与之相关的网络犯罪案件呈现上升趋势，对网络游戏产业的健康发展产生了严重的影响，也损害了游戏软件运营商和玩家的合法权益。

  

近日，**江苏宿迁警方破获了一起利用游戏外挂程序非法牟利的重大案件，成功抓获犯罪嫌疑人33名，查明涉案资金500余万元，有效净化了网络环境。**

  

![](../Images/5008bedb133dec7ac7916fa665d526a8.png)

  

在“净网2019”专项行动中，今年9月初，江苏省宿迁市公安局宿城分局网安大队接到某游戏公司报案，称有人针对其**公司开发的一款热门网络游戏制作了多款游戏外挂软件，并在网上进行销售。**该游戏外挂软件严重损害了广大玩家的利益，影响了游戏的正常运营。

  

经过对该线索的深挖和缜密侦查，宿城警方逐步确定了外挂团伙的组织架构，掌握了外挂制作者、总代理和销售者等人员的相关信息。10月份，宿城警方雷霆出击，展开集中收网行动，将涉案作者、一级代理、二级代理共33名犯罪嫌疑人悉数抓捕归案，**当场查获电脑、手机、U盘等一系列作案工具。**

  

**警方介绍，该犯罪团伙从事的是一条专门针对热门游戏的网络黑色产业链，**具有“作者——全国总代——销售代理”等多种角色，人数众多、规模庞大、分工明确。**他们编写“财神”、“一条”等10余款外挂程序，通过月卡、周卡的形式加密打包**，并以QQ群为推广载体在网络上进行销售。

　　

目前，33名犯罪嫌疑人均已被采取刑事强制措施，案件正在进一步侦办之中。
