每年一到11 月份，蓝蓝就觉得有些硝烟弥漫啊。


2009年11月11日天猫举办了一次网络促销活动，虽然当时参与的商家数量和促销力度有限，但营业额远超预想的效果。在初尝甜头后，于是11月11日成为天猫举办大规模促销活动的固定日期。双十一已成为中国电子商务行业的年度盛事，并且逐渐影响到国际电子商务行业。


 


如今，双十一购物狂欢节已经走过了10个年头，每年提前几个月，电商平台就开始双十一促销活动的预热，以吸引顾客们在自己的平台上挥金。


其中，天猫每年的预热活动最能引人注意，从去年双十一的战队 PK ，到618的“合猫猫”再到今年的店铺盖楼，天猫的双十一每年都能引起不小的社交浪潮，无论是收益性还是游益性，这样的活动都使很多人加入其中！


领喵币-盖楼


相信在这半个月的时间里，关注这场盛典的人们对此应该早已熟悉，这里还是给大家简单介绍一下“喵币”和“盖楼”（最近不少人为了这个，可谓是废寝忘食啊）。


首先打开“某宝”首页，点击“双十一合伙人”这个按钮，之后就可以开始以「领喵币→升级喵铺→做任务→领喵币」形式的循环战斗了。等到喵铺升级到 5 级以后，就可以邀请好友组队盖楼，5 人为一队，最终经过长达十几天的艰苦奋战，坚持到低的人可以参与瓜分 20 亿红包。

今年，拼多多也汇入了这场厮杀中（现金提现），这些推广类促销对于那些对“11.11”、“6.18”毫不敏感的人来说，这样的社交轰炸，无疑是一场噩梦啊~

 


这时，假如有一个自动采币机，那岂不是美哉？最近，GitHub上就有大神开发了一个自动逛双十一会场领喵币的脚本，不用自己动手就可以领各种喵币。


大神自动脚本


首先，开发者构建了一个可以自动逛双十一会场的脚本，能让双十一的粉丝们轻松完成各种领币任务，解放双手再也不是梦！整个自动化脚本都是基于 Auto.js Pro 的无障碍服务（Android 7.0 以上的系统都能使用）。


蓝蓝科普：

Auto.js 是一种 JavaScript 自动化软件，总体上它可以实现自动操作模块，例如控件操作、触摸模拟、按键模拟等，也可以实现其它设备、应用、界面等模块的自动化。


直观理解上，Auto.js 有点类似于用 Python 爬数据的 selenium 库。我们可以将其理解为安卓设备上的「按键精灵」。


它将领喵币的过程写成脚本，因此也就可以自动完成领币各种任务了。



目前该项目直接提供了 APK 安装包，我们也可以将脚本代码复制到手机端，并使用 Auto.js 运行。蓝蓝自己也试用了这个项目，通过安装 APK，我们确实可以尝试自动领喵币。


但是这个脚本只能帮助逛会场来领取喵币哦，签到和盖楼等 PK 作战活动，还是得亲自披挂上阵。


测试


在安装 完APK 后，下面的步骤可能稍微有些繁琐，但是想想那些“不劳而获”的喵币，这都不是问题！话不多说，让我们一起来看看吧！


最重要的部分就是就是配置「无障碍服务」与开启悬浮窗权限。其中在 APK 页面点击加载悬浮窗就会自动转到无障碍服务页面，需要确保开启了「淘宝领喵币」的无障碍权限。开启这两种权限后，在淘宝「领喵币中心」点击悬浮窗的开始，就能看到手机自动完成一系列任务，并愉快地领喵币啦。


开发者也很贴心的展示了 APP 内的使用注释，在完成设置后，基本上操作还是很简单的。



GitHub是一个面向开源及私有软件项目的托管平台，每当国内出现各种大型活动，总会有开发者在 GitHub 开源一些很有意思的解决方案。从 12306 抢票到自动领喵币，开发者们在各种节日里也离不开 GitHub。
