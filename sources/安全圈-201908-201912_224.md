# 非法获取1000余万贷款用户信息，江西警方抓获12人

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651964202&idx=3&sn=b9b851dd8e90ef9633bf55a99a298de2&chksm=f36cef6ac41b667cac08caef8a41c275123f13a915562fbbaf16e504232083999ac3eb6fa0d0&scene=126&sessionid=1681311858#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651964202&idx=3&sn=b9b851dd8e90ef9633bf55a99a298de2&chksm=f36cef6ac41b667cac08caef8a41c275123f13a915562fbbaf16e504232083999ac3eb6fa0d0&scene=126&sessionid=1681311858#rd)

**![](../Images/53cb3792038be38d83be203427063201.png)**

记者6日从江西省公安厅获悉，该省重拳出击开展“净网2019”专项行动，目前共立案侦破网络犯罪刑事案件957起，抓获犯罪嫌疑人1686人。其中，“**山西晟盾信息科技有限公司**侵犯公民个人信息案”等重点案件被公安部挂牌督办。

  

![](../Images/f08d5045ffe2740e498aa9bbca179a0b.png)

  

据介绍，今年9月，赣州市公安局组织网安、特警等部门40余名警力远赴1600多公里外的山西省太原市，**对在全国范围内为网络套路贷犯罪提供软件技术支持、非法获取海量公民个人信息的山西晟盾信息科技有限公司开展统一收网行动**，抓获包括主犯毛某在内犯罪嫌疑人12名。

  

警方查获该公司服务器60台及公民个人信息数亿条，斩断一个涉及江西、河北、浙江等20余省市的特大侵犯公民个人信息犯罪利益链条。

  

经查，山西晟盾信息科技有限公司开发大数据风控系统软件后，在全国范围内大肆销售网贷APP软件，并借“授权查询”之名，与多家第三方大数据公司合作，非法获取1000余万名贷款用户公民个人信息，再向下游网贷公司收取数据查询费用，非法获利数千万元。

  

目前，案件仍在审理之中。
