# iOS上的ProtonMail应用现已完全开源

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651964128&idx=2&sn=fc9540c5117d60b481d1cd982fce253a&chksm=f36ceea0c41b67b61dab66eda5125d662f7e64fb4db579b01c73fd2bdc63ea189106b8cd1dc8&scene=126&sessionid=1681311862#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651964128&idx=2&sn=fc9540c5117d60b481d1cd982fce253a&chksm=f36ceea0c41b67b61dab66eda5125d662f7e64fb4db579b01c73fd2bdc63ea189106b8cd1dc8&scene=126&sessionid=1681311862#rd)

![](../Images/53cb3792038be38d83be203427063201.png)

  

Proton Technologies AG宣布其iOS上的ProtonMail应用现已完全开源，源代码现已在GitHub上提供。公司给出了应用程序开源的理由，相信“透明与社区的力量，并为所有人建立一个更加私密和安全的未来。”该应用程序的开源是在由安全公司SEC Consult对软件进行安全审核之后进行的。

  

Proton Technologies AG表示，通过开放源代码可以增强其用户的信任，用户可以看到应用程序的功能，甚至可以在不信任分发的二进制文件的情况下使用源代码构建自己的应用程序版本。

  

![](../Images/53a8fe49e51191d169902e4b9dc366b1.png)

  

在评论该应用程序的开源时，Proton说：

  

“开发人员可以自由地实施和建立在我们记录和发布的产品的方法，我们相信，当开发人员共同解决现实世界中的隐私挑战时，每个人都会受益，我们希望代码的发布将带来更安全，更强大的iOS应用。”

  

在发布源代码的同时，该公司还记录了iOS安全模型，该模型可以帮助公众审查该应用中发现的一些更难以理解的代码。

  

在源代码已开放的情况下，如果您希望通过ProtonMail错误赏金计划赚钱，可以直接查看错误代码。另外，如果您是Swift编程语言的新手，并且正尝试为iOS创建应用程序，那么回顾现有程序并查看它们的工作方式是提高编码技能的好方法。
