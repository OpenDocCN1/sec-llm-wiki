# 小心！这21个年轻人，盗走了全国500多万人的个人信息

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651963970&idx=1&sn=903bad5afe0356813bacdb1a7649c216&chksm=f36cee02c41b6714620d50a15d7c832de3f299d47c838e6f4088d201877ec549753da032c164&scene=126&sessionid=1681311862#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651963970&idx=1&sn=903bad5afe0356813bacdb1a7649c216&chksm=f36cee02c41b6714620d50a15d7c832de3f299d47c838e6f4088d201877ec549753da032c164&scene=126&sessionid=1681311862#rd)

![](../Images/53cb3792038be38d83be203427063201.png)

  

日前，宿迁市沭阳县警方在“净网2019”专项行动中，**破获一起涉及全国数百万人的侵犯公民个人信息案件**，共抓获犯罪**嫌疑人44人**，成功摧毁**犯罪团伙8个**，非法获取、买卖公民**个人信息约310万条**，**涉案金额达500余万元**。

  

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_1042219618674343937](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_1042219618674343937)

  

今年2月初，沭阳县公安局网安大队接群众举报：2018年11月份以来，广东省某贷款公司依托自建的网贷产品，**大肆在网络上收集公民个人信息**（包含身份信息、联系方式、通话记录、手持身份证照片等），然后再**明码标价卖给他人****进行非法牟利**。

  

被害人张某称，之前在宿迁宿豫的五叉路口的一个小贷公司借过钱，当时就留下了手机号码，之后每天都有几十个电话打来。

  

以受害人张某的报警线索为切入点，民警多方调查发现，这些广告信息的发送方都是经过"伪装"的，采用的是虚拟身份。调查起来有一定的难度。

  

![](../Images/483191bee7e4783a9916ae68924b526e.png)

  

通过经过三个多月的努力，警方最终锁定了这个犯罪团伙。他们的成员分布在安徽、福建抚州、泉州、漳州等地。今年7月，警方分批抓捕了21名犯罪嫌疑人。

  

原来，今年3月，嫌疑人陈某某等人成立了熊猫金融团队，通过一款名为**"号码魔方****"**的软件，来破解用户信息，侵犯公民个人信息。熊猫金融团以公司形式运行，有上级的股东、工作人员，有专门的财务人员，以及发展下线的广告宣传人员。

  

![](../Images/a4ffd29a1d04abb24190445ad1d8226b.png)

  

专案组在充分掌握该犯罪团伙的组织架构、作案手法后，**调集70余名警力**分赴广东、福建、河南、浙江、上海等10余个省市开展抓捕工作，共抓获犯罪**嫌疑人44人**，现已**采取刑事强制措施43人**，扣押**电脑41台**，**手机59部**，**涉案金额达500余万元**。

  

目前，案件还在进一步审理中。
