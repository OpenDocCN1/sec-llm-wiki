# SUSE 放弃 OpenStack 业务

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651963706&idx=4&sn=4266f9336cb90d32efccd687be36d1ff&chksm=f36ced7ac41b646cf597fdf126b3d45587a09953fa2852ca2bc4349836652c7465c544635d17&scene=126&sessionid=1681311870#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651963706&idx=4&sn=4266f9336cb90d32efccd687be36d1ff&chksm=f36ced7ac41b646cf597fdf126b3d45587a09953fa2852ca2bc4349836652c7465c544635d17&scene=126&sessionid=1681311870#rd)

![](../Images/53cb3792038be38d83be203427063201.png)

  

长期以来支持OpenStack基础设施即服务云计划的SUSE现退出OpenStack云行业。多年来，欧洲Linux和开源公司SUSE一直是OpenStack基础设施即服务云计划的拥护者之一，如今不再是这样。SUSE已决定停止生产新版本，并停止销售SUSE OpenStack云。  

  

  

![](../Images/7c6208733744c762a0cf7a6065d9bd46.png)

  

这离发布SUSE OpenStack Cloud 9才过去了几个月的时间。该产品基于OpenStack Rocky版本和SUSE Linux Enterprise Server（SLES）12 SP4。它也是第一个集成HPE的Helion OpenStack的版本。SUSE在三年前收购了HPE的云资产。

  

**为什么突然转变？**

  
SUSE声称：“SUSE致力于我们在应用程序交付市场及机会方面的战略性投入，并加大投入，以便顺应行业的技术趋势，最重要的是满足客户需求。因此，SUSE会更加致力于基于Kubernetes的应用程序交付产品：SUSE Cloud应用程序平台和SUSE CaaS平台。”SUSE还暗示，“将来会收购技术。”  
SUSE主管公司发展和战略联盟的总裁Michael Miller在一封电子邮件中说：“SUSE致力于我们在应用程序交付市场及机会方面的战略性投入，并加大投入，以便顺应行业的技术趋势，最重要的是满足客户需求。这些调整将让SUSE得以更有效地将资源投入于我们的客户需求、战略方向和市场机会。这个额外的焦点将推动SUSE继续迅猛发展，成为一家高瞻远瞩的、独立的开源公司，在成长和创新方面有着令人激动的目标。”  
至于SUSE的现有OpenStack客户，“我们正与所有受影响的客户和合作伙伴紧密合作，在他们过渡到替代产品的过程中在剩余的订购期限内提供支持。”  
SUSE会继续致力于企业Linux服务器产品：SUSE Linux Enterprise Server（SLES）和基于Ceph的软件定义存储解决方案SUSE Enterprise Storage。  
就在SUSE作出此举前两个月，公司刚换了首席执行官（CEO）。SAP的前首席运营官Melissa Di Donato在7月被任命为SUSE的CEO。Di Donato受命进一步促进SUSE的增长和扩展。不过她没有透露如何着手开展这方面工作的任何细节。Di Donato认为，由于这一举措，SUSE需要更加关注基于Kubernetes的混合云。  

**OpenStack基金会采取了务实的态度**

  
OpenStack基金会的首席运营官Mark Collier在电子邮件中说：“OpenStack发行版市场逐渐出现了一群得到高度支持、被广泛采用的核心玩家，就跟Linux及其他大规模开源项目方面出现的情况一样。所有公司都会不时调整战略优先事项，对于继续致力于为私有云中的容器、虚拟机和裸机提供开源基础设施产品的那些发行版提供商而言，OpenStack是市场的首选。”  
Collier并不认为SUSE离开OpenStack生态系统是表明OpenStack面临麻烦的迹象：  
“展望2022年，像451 Research这样的市场研究公司预计OpenStack和Kubernetes这个新兴的合并市场的产值有望超过110亿美元，其中77亿美元来自OpenStack。随着整个开源云市场继续朝着收入八位数及更高的方向前进——大部分集中在OpenStack产品和服务上，很显然，发行版的自然合并不会对采用产生任何影响。”
