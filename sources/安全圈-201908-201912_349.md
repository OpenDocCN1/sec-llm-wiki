# 你还在玩私服？别助纣为虐了！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651963622&idx=2&sn=7cee23c965ee974c5057bf5cf38d8cfa&chksm=f36ceca6c41b65b0df1e47b25e9050e5cac9f00a3f5ebdb672d798f7913b1cd36321d6e45140&scene=126&sessionid=1681311870#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651963622&idx=2&sn=7cee23c965ee974c5057bf5cf38d8cfa&chksm=f36ceca6c41b65b0df1e47b25e9050e5cac9f00a3f5ebdb672d798f7913b1cd36321d6e45140&scene=126&sessionid=1681311870#rd)

今天我们来聊聊游戏。

  

我们都知道一款手游从零开发往往成本都在几百万元，一二十个人的技术团队才可以担得起重任。因为游戏用户的粘性，成瘾性是非常大的，所以产品成功了，游戏相对应的收入也是非常可观的。风靡全球男女老少的腾讯旗下的**王者荣耀2018年约赚220亿RMB。**

  

![](../Images/77e936a1c7e64824e08dc451133c84b3.png)

  

游戏产业兴旺的同时，游戏背后的黑色产业，也远远超出了大家的想象。**这不但包括你有所耳闻的游戏工作室、代练、盗号、贩卖游戏道具，甚至还包括贩卖游戏本身。**今天蓝蓝就来讲一下，**私服，未经研发商团队允许，私自搭建服务器并且运营收费的游戏，就是盗版网游。游戏私服，这个非常暴利的产业链。**

  

在游戏私服的利益链中，不论是网站经营者，还是运营商、广告代理商，发布商、搜索引擎的代理商，均是一本万利。私服不受地域限制，只要有网络信号，就可全天候向全球玩家出售自己的产品，其实开设私服运营并不难， 就拿传奇举例，游戏的源代码很好买，一个人或者一个团队不需要很多技术就可以架设自己的私服。

  

有多暴利。有人给蓝蓝算过一笔账，如果一个私服可支持1.2万名玩家同时在线，一般可注册玩家4-5W名，如果每个玩家包月费20元，一个私服一月可净收近100万元。如果同时多架设几个私服，一年轻松上千万……上千万……千万。

  

![](../Images/85a3a3b4c98bf00acf88a44ca86f0dd5.png)

  

  

私服的暴利，总有人愿意铤而走险。

湖南首例侵犯网游著作权案告破 嫌犯开**“私服”获利613万**

近日，湖南衡阳市公安局蒸湘分局成功破获了湖南省首例侵犯网络游戏著作权案。衡阳市公安局蒸湘分局经过5个多月的侦查，辗转北京、广东等地，对这起涉案金额613万元的侵犯网络游戏著作权案，实现了全链条打击，6名犯罪嫌疑人被逮捕。

  

![](../Images/862827174f46ded03252b8480543befa.png)

警方查获的赃物。

  

案件线索来源于2018年底，蒸湘分局多次接到辖区内某公司报案：一款名叫“xx女儿国”的网络游戏冒充“xx轮回”正版网络游戏在网上推广，造成正版网络游戏玩家大量流失，严重侵犯该款游戏的计算机软件著作权。

  

接到报案后，蒸湘分局网安大队迅速开展初查，发现有人通过非法途径，获取了受害公司的游戏源代码，组织技术人员开发游戏管理平台后，将该私服交由北京某公司上线运营，并由该公司通过其他下游渠道商进行游戏宣传推广，**该游戏私服充值涉案金额达613万元。****正版游戏价格不菲，一套普通装备就需要2000多元，游戏玩家多为收入较高群体。而“xx女儿国”游戏门槛较低，一套装备仅需要几十元，吸引了不少青少年沉迷其中。**

  

![](../Images/1516c0b03386a08fe62f1f8b22e2d53b.png)

涉案嫌疑人。

  

6月30日，专案组民警实施收网行动。在北京警方的大力配合下，专案组兵分三路抓获涉案人员12名，当场缴获作案用电脑、手机若干，将私服架设人员张某、吴某及运营私服的北京某公司徐某、赵某、王某等带回衡阳依法刑事拘留。7月25日，民警抓获该私服主要渠道商广州某公司负责人梁某。至此，该案主要犯罪嫌疑人全部落网。

  

在大量证据面前，6名犯罪嫌疑人均对“xx女儿国”侵犯“xx轮回”网络游戏著作权并从中牟取巨额非法利益的犯罪事实供认不讳。经查，该款私服游戏上线仅仅7个月，注册玩家就超过12万人，获利613万元。

  

私服产业如今已经在国内形成庞大的产业链，规模预计已经达到千亿级别。**如今市面上不但存在大量的传奇私服、奇迹私服、诛仙、征途、神魔大陆、甚至还有玩家熟知的魔兽世界的私服，其它私服蓝蓝就不一一列举了，有兴趣的小伙伴可以下方留言评论大家讨论一下如今都有哪些私服。**

  

蓝蓝温馨提示：计算机软件著作权受法律保护，未经著作权人许可，以营利为目的，复制、发行他人的计算机软件，均属于违法行为。切勿为贪一己私利，触碰法律底线，最终等来的将是刑罚的制裁。
