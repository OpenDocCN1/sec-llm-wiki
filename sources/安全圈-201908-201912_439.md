# 团伙制作销售游戏外挂被警方抓获，竟都是00后！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651963197&idx=2&sn=f77c376978c4249526e5fd9325f605c7&chksm=f36c937dc41b1a6bc3c9f003a01778cf09f5d13a4fd291ea3119d8177167274fbaced6ab3a71&scene=126&sessionid=1681311878#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651963197&idx=2&sn=f77c376978c4249526e5fd9325f605c7&chksm=f36c937dc41b1a6bc3c9f003a01778cf09f5d13a4fd291ea3119d8177167274fbaced6ab3a71&scene=126&sessionid=1681311878#rd)

不少游戏玩家都有过这样的体验：激战正酣时，突然自己莫名其妙被人“淘汰”，或者自己躲在房间一动不动，对手却对自己行踪了如指掌……原因可能是有玩家使用了游戏外挂。  
9月3日，湖北襄阳市保康县公安局3日通报，该局在“净网2019”专项行动中，远赴黑龙江、湖南、广东、河北、浙江等地，一举捣毁3个制作销售游戏外挂的团伙，抓获开发制作和持有游戏《和平精英》外挂的犯罪嫌疑人3名，以及游戏外挂的代理销售人员6名。  
  
今年5月，军事竞赛体验手游《和平精英》正式公测，襄阳保康籍的小赵(化名)是该游戏的粉丝，可玩了没多久，他发现自己的技术越来越“差”，而且经常还没看到对方就被对方淘汰。小赵怀疑对方使用了游戏外挂，遂向保康县公安局网安大队举报。  
经过对该线索的深挖和缜密侦查，警方逐步确定外挂团伙的组织架构，掌握了外挂制作者、总代理和销售者等人员相关信息。  
  
7月初，保康警方展开收网行动，将涉案作者、一级代理、卡盟负责人、二级代理共9名犯罪嫌疑人一举抓获归案。  
保康县警方介绍，这三款游戏外挂名称分别为SK2、毒蛇、马日地，均针对《和平精英》游戏设计。外挂开发者将外挂卡密交于一级代理商对外销售，一级代理然后发展下线销售，各级下线通过聊天工具或者卡盟进行销售。3款外挂的主要开发人员和持有人均为“00”后，其中两名还是学生。  
  
![](../Images/93d5879e98fc37c49072908a6df94aa3.png)警方抓获的犯罪嫌疑人。保康公安供图  
警方介绍，湖南男子陈某，高中辍学，是《和平精英》的玩家。今年4月份，他自己编译了一款能在该游戏中实现自动瞄准等多个功能的外挂程序，取名SK2。4月中旬，陈某找到有销售外挂经验的游戏好友“九哥”魏某商量，他负责外挂程序的开发和更新，“九哥”作为一级代理商对外销售。陈某以每张卡密1元的价格批发给九哥（1天使用费用），“九哥”以每张卡密获利0.5元至0.7元批发给下线。  
　　陈某开发外挂程序功能齐全，而且每四五天更新一次，程序运行非常稳定，深受一些玩家青睐，最高峰时一天七八千人在线使用，卡密价格高达15元/日。  
　　除了SK2，陈某还开发了一款该游戏的外挂程序“炸弹”，发布到网上供游戏玩家免费试用，还未来得及收费。  
　　另一个“毒蛇”外挂程序的作者王某是个学生，编写程序后由一级代理何某负责销售。何某再将外挂发包给下线施某等人利用其卡盟网站销售。  
　　此外，赵某在网上购买《和平精英》“除草“外挂程序，取名为“马日地”，之后将外挂程序出售给魏某、周某、张某等人，魏某、周某、张某再通过聊天群、卡盟出售给玩家。  
自今年4月该游戏推出以来，三款外挂程序出售多达22万余人次，涉案金额高达300余万元人民币。  
目前，9名犯罪嫌疑人因涉嫌提供侵入、非法控制计算机信息系统工具罪被公安机关采取刑事强制措施，案件正在进一步办理中。
