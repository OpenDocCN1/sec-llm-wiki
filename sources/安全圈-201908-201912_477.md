# 英国网络安全机构督促开发者淘汰 Python 2

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651963044&idx=4&sn=d8f94b7b952c132ae936b72a8964b6c7&chksm=f36c92e4c41b1bf2478196c8f7d6ac727fe68f09d8c406c942887ab0c0087c8cc71afc9e82a3&scene=126&sessionid=1681311882#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651963044&idx=4&sn=d8f94b7b952c132ae936b72a8964b6c7&chksm=f36c92e4c41b1bf2478196c8f7d6ac727fe68f09d8c406c942887ab0c0087c8cc71afc9e82a3&scene=126&sessionid=1681311882#rd)

![](../Images/52811614dab8f45330932d19a7eec439.png)

  

Python 2.x 即将终止支持，英国国家网络安全中心（NCSC）督促开发者尽快淘汰 Python 2.x 迁移到 Python 3.x。Python 2.x 将于 2020 年 1 月 1 日终止支持，Python 核心开发者之后不再提供 bug 修正和安全更新。

  

![](../Images/cd53dbb7b1ed7a8be5e264a310003c92.png)

  

NCSC 警告如果继续使用 Python 2.x 开发的模块，将会面临安全风险，因为漏洞总会出现，而新的漏洞不会再有人修正。

  

NCSC 称，如果你维护了一个其他人依赖的库，你可能会阻止其他人更新到 Python 3。如果你无法将代码升级到 Python 3，一个选择是付费给商业公司继续支持 Python 2。NCSC 以勒索软件 WannaCry 举例说明使用不再支持的软件会发生什么。
