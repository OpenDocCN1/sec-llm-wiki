# 黑客入侵新加坡网课丧心病狂发色情图片，教育部立即叫停Zoom

新加坡的学校在周三因冠状病毒疫情导致学校停课后，纷纷改用视频会议类的应用程序进行家庭式学习。

岂料，Zoom平台的安全系统其实不是那么安全......

  

不少Zoom的账号出现在暗网，许多信息如电邮、密码、会议ID通通都被暴露，最可怕的是，竟有黑客入侵网络课程，向学生展示色情图片！

  

有位家长社交平台脸书上控诉遇到了这样的问题。她表示，自己13岁女儿在使用Zoom平台进行网上学习时，有两名黑客男子突然入侵网络课程，向学生展示色情图片，甚至要求学生露出胸部。事发太突然，老师立即暂停课程。

  

![](../Images/974eba01ce2245f439ab3ccee1836d1b.png)

图片来源：Facebook  
**针对此事，新加坡教育部表示：所有学校将暂停使用Zoom平台上课！此事也正在调查中，并会在必要时报警。**![](../Images/ecb9f8b4273fdfe19da1cca57d4c19d5.png)  
对此，新加坡教育部教育技术司司长Aaron Loh表示：“这一事件非常严重，教育部目前正在调查这两起违规事件，如有必要，将向警方报案。作为预防措施，我们的教师将暂停使用Zoom，直到这些安全问题得到解决。”  
他还表示，在视频会议App中部署的安全功能，如使用安全签到方式、不大面积分享会议链接等，都会告知老师们使用。为了避免“zoom bombing”的捣乱事件再次发生，Zoom最近宣布将默认开启会议“等待室”功能，以方便网络会议举办人鉴别与会者。  
在应用内部被爆出多个安全漏洞后，因为COVID-19爆红的Zoom一直面临舆论压力。该公司首席执行官Eric Yuan后来宣布，Zoom正在执行90天的功能开发冻结令，以修复目前该服务的安全问题，也就是说在此之前这一会议软件不会发布任何新功能。
