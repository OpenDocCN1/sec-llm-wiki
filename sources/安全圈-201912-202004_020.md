# Windows 10资源管理器功能更新 轻松查看Linux子系统文件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651966902&idx=4&sn=1b568c919b29ec4facdbe4cb9a8def92&chksm=f36ce1f6c41b68e05520bf8207c67a62633095df55a7e8ab09e40668748143fda24a170fe60a&scene=126&sessionid=1681311797#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651966902&idx=4&sn=1b568c919b29ec4facdbe4cb9a8def92&chksm=f36ce1f6c41b68e05520bf8207c67a62633095df55a7e8ab09e40668748143fda24a170fe60a&scene=126&sessionid=1681311797#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)  

微软刚刚向开启了快速更新（Fast Ring）通道的 Insider 测试者们推送了 Windows 10 build 19603 编译版本，主要引入了面向 Linux 子系统的文件资源管理器集成。**如果你已经在设备上安装了 WSL，便可在更新后看到一个新的 Linux 驱动器，以便用户正常浏览文件。**

  

![](../Images/9bdd439e234114262b4de8f1fd333ffa.png)

  
实际上，早在 2019 年春季发布的 1903 版本中，Windows 10 就已经支持访问 WSL 中的 Linux 文件。  
不过鉴于资源管理器仍是用户首选的文件查看器，我们对于 build 19603 的集成改进还是感到相当欣慰的。  

![](../Images/a31c2ded905d836042a8390bac74296f.png)

  
微软在更新日志中写到：现在，你可以直接从左侧导航窗格里轻松访问 Linux 子系统里的文件。  
需要指出的是，面向 Insider 测试者的 19603 内部编译版本，算是 Wnidows 10 2004 的抢先预览。如果一切顺利，其有望在下月正式与我们见面。
