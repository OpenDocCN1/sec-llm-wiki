# 2020年Windows 10路线图：重头戏是Windows 10X

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651966844&idx=2&sn=c430ef21814c35839ad3ee587b9dfbd3&chksm=f36ce13cc41b682a5629baeddef56231c47ece9cd2ebb1e381b96596fb73c10be2580fb3bef6&scene=126&sessionid=1681311801#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651966844&idx=2&sn=c430ef21814c35839ad3ee587b9dfbd3&chksm=f36ce13cc41b682a5629baeddef56231c47ece9cd2ebb1e381b96596fb73c10be2580fb3bef6&scene=126&sessionid=1681311801#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)  
2020年的Windows 10系统更新路线图已基本明晰，目前20H1的开发工作已经结束，现阶段主要精力会放在BUG修复和后台优化方面。而下半年上线的20H2将采取和19H2相同的策略，可以视为超大版的累积更新。而今年最大的看点就是随Surface Neo登场的Windows 10X系统。  
**Windows 10 Version 2004（20H1）**同Windows 10 November 2019功能更新（1909）不同，Windows 10 Version 2004带来了很多重磅新功能，具体可以浏览本站此前发过的文章。  
![](../Images/b9347c96837de120158cf8a62e340269.png)  
目前微软主要精力放在如何让Windows 10 Version 2004更稳定和流畅方面，有望在下个月发布。即将到来的20H1功能更新将着重于实质性的改进和质量提升，包括对现有功能的改进，如 "Reset this PC"等。  
![](../Images/395e705da9332aa7c600fb0c8f3a76ba.png)  
截至目前的最新预览版中，Windows 10 Version 2004更新包括性能提升、新的Cortana体验、WSL 2、更新后的平板电脑体验、新的可选更新页面、驱动程序兼容性提升、降低CPU和磁盘使用率、新的应用图标、任务管理器中的两个新功能等等。  
**Windows 10 20H2**  
在20H1发布之后，20H2将不再注重新功能的引入，而是对20H1进行全面的修改优化。目前20H2分支版本主要集中在质量的提升方面，但也会提供一些比较小的新功能。  
从最近的Build版本中，有几个潜在的功能很耐人寻味。例如，Windows搜索正在获得一种新的算法，当你不主动使用PC时，它将允许它启动索引过程。  
![](../Images/a5b9b8001e2c362e5a3a7f5b34a1cccc.png)  
在这次更新中，我们还将看到各种UI元素的一些小调整。临时测试版构建版也进一步暗示了今年或明年会有什么东西出现。例如，微软已经开始着手开发新的音量控制任务栏功能、现代磁盘管理工具和控制面板移除计划。  
**Windows 10X**  
2020年的重头戏自然是随Surface Neo登场的Windows 10X系统，目前微软内部正在积极测试新系统。  
Windows 10X 中你首先会注意到的变化就是全新的开始菜单。它不再包含 Windows 8/10 以及 Windows Phone 上常见的动态磁贴，而且具备更简洁的外观设计。![](../Images/5c8920de2c3c514793cdf4072c98296f.png)  
Windows 10X 的开始菜单包含已固定的应用程序，以及近期文档列表。整个外观看上去更像是目前的任务启动器，用户能够搜索应用程序，文档甚至网络内容，这也支持基本的语音输入。不过在 Windows 10X 的设置中并没有发现 Cortana 的相关设置。
