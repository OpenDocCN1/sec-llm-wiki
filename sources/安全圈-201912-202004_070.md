# System76 推出 Linux 键盘

“我们即将发布的 Pop!\_OS 20.04 版本中的自动平铺功能可以与该键盘配合使用，并且我认为人们会对此做出真正的回应，因为这将是一种全新的体验。”  
![](../Images/c8c1cb9ba1234bcdfe7adc7d255b3c5e.png)  
在外观设计上，此款键盘并没有很惊艳的地方。但 System76 方面表示，Linux 键盘将提供更加舒适的输入体验。例如，键盘将没有数字键盘。如 System76 所说，没有数字键盘，鼠标就可以更加靠近用户。因此，用户在将该键盘搭配鼠标使用时，手部操作需要消耗的精力也会更少。  
Richell 也表示，此款键盘并不会改变用户的使用习惯。“不必一定感觉有所不同，您可以将其插入并像其他键盘一样使用。但是，您的手将减轻压力，因为您无需使用小指，而可以使用拇指来进行常见的击键和组合键。另外，像 Backspace 这样的键也依旧可以很轻松的找到。”  
预计该键盘将在今年夏季投入使用，但进一步的细节（如价格）还尚未公开，更多信息将在发布日期之前浮出水面。
