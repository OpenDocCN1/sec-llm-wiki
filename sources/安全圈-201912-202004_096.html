历史回顾：微软当年如何让IE成为Mac OS X默认浏览器的？

原文：http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651966646&idx=3&sn=7ee99e4ad4ae5fd70ccac7397d9d4504&chksm=f36ce0f6c41b69e0c110a96964df0b704a722275089545f2e75bf29aae3528cb748024d418f8&scene=126&sessionid=1681311805#rd

在几年前宣布向软件服务转型后，微软已不再拘泥于在自家平台上打败竞争对手。于是在苹果和谷歌的生态系统中，我们也可以无障碍地体验微软提供的应用与服务。但是在多年以前，微软与苹果的关系、以及粉丝和用户群体之间，还是显得有些敌对。于是当 IE 成为 Mac OS X 默认浏览器的消息宣布后，现场几乎是一片哗然。


一切始于 1997 年在波士顿举办的苹果 MacWorld 大会，当时史蒂夫·乔布斯（Steve Jobs）出人意料地宣布了这一消息，然后比尔·盖茨（Bill Gates）亲自上台讨论了微软产品登陆 Mac OS X 的计划。

本届大会上，双方宣布达成了合作伙伴关系，以便微软软件能够在 Mac OS X 上得到相当大的扩展 —— 第一件事，就是让 IE 成为 Macintosh 的默认浏览器。
幕后真相是，由于遭遇了财务上的困境、以及股价的低迷，担任临时首席执行官的乔布斯和苹果公司，确实需要财大气粗的微软的救助。

乔布斯向观众解释称：“经过审视，我们认为将 IE 设置为 Macintosh 上的默认浏览器是一个不错的选择。当然用户还可使用其它浏览器，并更改默认设置”。

同时作为五年合作的一部分，软件巨头还向苹果 Mac OS X 用户提供了 Microsoft Office 生产力套件的专用版本。


当然，这么做的前提是，微软需要向用过提供 1.5 亿美元的投资，以避免该公司遭遇财务上的崩溃。

最终微软以市价购买了相应金额、但无投票权的苹果股票，同时承诺至少三年内不会抛售。这意味着当该公司业务恢复健康运营、且股价有上涨时，微软也将获益于此。

同时微软与苹果的专利纠纷也告一段落，双方获得了所有专利的完整交叉许可。毋庸置疑的是，作为世界上最大的软件公司，微软成为了这笔交易的最大赢家。

早在 1996 年，IE 2 就已登陆 Macintosh 平台。但在 1998 年的 MacWorld 大会上宣布 Mac OS 8.1 的时候，IE  又成为了苹果系统的默认浏览器。

一些人可能感到疑惑，当时命名已经有了更新的 4.0 版本，为何 Mac 上的还停留在 3.01 版本？

官方解释称：那是因为当苹果完成 Mac OS 8.1 的时候，IE 的最新版本尚未最终敲定。


自那时起，微软向 Mac OS X 平台移植软件的工作变得愈加努力，并在较长一段时间内都提供了 IE 浏览器的更新（2000 年 1 月的 IE 5.0，以及 2001 年 9 月的 IE 5.1）。

双方的合作关系，结束于 2003 年。当时苹果发布了 Mac OS X 10.3 Panther，且预装了自家的 Safari 浏览器。

微软最终于 2005 年放弃了 IE for Mac，并于次年永久取消了下载链接。之后尝试下载的 Mac 用户，将被告知使用 Apple Safari 。
