# Windows 10最佳杀软测试结果出炉：Windows Defender表现优异

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651966646&idx=5&sn=47cf3161ee763d00ef500bc8df5abccf&chksm=f36ce0f6c41b69e0c77c215f31be9a067b42f4711c59dc0a56201b098f525ab3eb44c62e2d9c&scene=126&sessionid=1681311805#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651966646&idx=5&sn=47cf3161ee763d00ef500bc8df5abccf&chksm=f36ce0f6c41b69e0c77c215f31be9a067b42f4711c59dc0a56201b098f525ab3eb44c62e2d9c&scene=126&sessionid=1681311805#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)  
疫情期间，越来越多的人被迫在家远程办公的同时，网络罪犯也忙于攻破各种设备。**德国研究公司AV-TEST在今年1月至2月期间做了一系列新的测试，确定了适合Windows系统的最佳病毒防护产品。**  
![](../Images/61bed7ab0504f4032cd7a54da57fd65f.png)![](../Images/9d7622c5ec07578424592acc9920d9ef.png)  
和以往相同，他们测试了每款病毒防护产品的保护、查杀能力以及可用性，每个栏目最高分为6分。其中五款产品获得了满分18分的好成绩，分别为  

> ● Avira Antivirus Pro● F-Secure SAFE● Kaspersky Internet Security● NortonLifeLock Norton 360● VIPRE Security AdvancedSecurity

  
另外还有五款病毒防护软件获得了17.5分的好成绩，表现同样非常优秀，分别为  

> ● BullGuard Internet Security● G DATA Internet Security● K7 Computing TotalSecurity● Microsoft Defender● Trend Micro Internet Security

  
Windows Defender是预装在Windows 10系统中的防病毒产品，获得了和世界领先的第三方安全厂商几乎相同的分数。Windows Defender的保护得分为5.5分，性能得分为6分，可用性得分为6分，最终得分为17.5分。  
这次表现最差的奖项是PC Matic，这是一款仅获得3分保护和3.5分可用性的安全产品。测试过程中的总得分为6分。总体来说，如果您正在寻找一流的恶意软件防护，那么不妨使用微软官方提供的Windows Defender，它已经提供非常优秀的性能保护。
