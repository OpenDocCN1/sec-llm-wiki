# Windows 10 2004将迎来新版Linux子系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651966493&idx=2&sn=a9c1c501e058b46a9daac3825bb8a02e&chksm=f36ce05dc41b694b414383b317ed5d8bb63302238d9ea21eb145ed5f989962b27551add63031&scene=126&sessionid=1681311809#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651966493&idx=2&sn=a9c1c501e058b46a9daac3825bb8a02e&chksm=f36ce05dc41b694b414383b317ed5d8bb63302238d9ea21eb145ed5f989962b27551add63031&scene=126&sessionid=1681311809#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

曾经有一段时间，微软对 Linux 的态度并不友好。但随着企业战略的全面转型，该公司已经积极投身相关应用与服务的开发。甚至在 Windows 10 操作系统层面，都有专门的 Linux 子系统。**最新消息是，作为开发者与 IT 经理们必不可少的一款趁手工具，微软已经完成了新版 Linux 子系统的开发（简称 WSL2），并将随 Windows 10 2004 一起提供。**

![](../Images/ef4acc0eb99479e4d3a2e85835c584ea.png)

资料图（来自：Microsoft）

  

目前 WSL2 已经向 Windows 10 20H1（Version 2004）的慢速更新（Slow Ring）通道推送，最终版本还要再等待一段时间。

  

已经加入 Insider 项目的测试者，将能够通过 Windows Update 获取这一更新。不过目前的交付方式尚未实现，因此感兴趣的朋友仍需手动安装 WSL2 。

  

> 微软在今日的一篇博客文章中表示：我们的最终目标，是实现无缝化的体验。即无需用户的考虑，即可让 Windows Linux 子系统的内核保持在最新状态”。
> 
> 默认情况下，相关事宜将完全交由 Windows 来处理，就像在系统上执行常规的更新那样，且涵盖 Windows 10 初始版本、2004、以及最新的 Insider 内部预览。

  

目前用户暂时需要手动安装 Linux 内核，未来几个月还会收到后续更新，引入自动安装和服务功能。

  

微软将确保通过这样的动态模型，为 WSL2 初始常规发行版本中的所有用户提供服务，并不会将老版本系统用户晾在一旁。

  

> 显然，该公司希望吸取旧版 Edge 浏览器的教训，不再将太多需要频繁更新的功能与系统捆绑升级。
> 
> 正如新版 Edge 浏览器那样，WSL2 将能够独立于操作系统而实现更新，意味着该模块的创新可与 Windows 10 的大版本更新脱钩。
