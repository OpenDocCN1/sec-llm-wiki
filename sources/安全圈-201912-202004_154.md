# Windows 10X文件管理器上手：框架已搭好 功能待完善

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651966471&idx=4&sn=b43caae2fb32dfd3a6934afc6bec296e&chksm=f36ce047c41b6951cce2795703cf1020c5129ab28aef15a5f9b4324ccd51fa95406f674fbd5f&scene=126&sessionid=1681311809#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651966471&idx=4&sn=b43caae2fb32dfd3a6934afc6bec296e&chksm=f36ce047c41b6951cce2795703cf1020c5129ab28aef15a5f9b4324ccd51fa95406f674fbd5f&scene=126&sessionid=1681311809#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

本周早些时候，微软发布了Windows 10X Emulator的第二个系统镜像，并带来了全新的文件管理器体验。昨日我们分享了如何在Windows 10系统上安装该文件管理器的技巧后，现在外媒再次分享了有关新功能的屏幕截图。

  

![](../Images/4f2edd18405cdfd8d49a71f06b3c3dc9.png)![](../Images/0319255f2e830d7aafd134b98d5cad10.png)![](../Images/959fb2d4f7e088ac6060fcdcb3acc1e6.png)

  

目前这是文件管理器的首个Beta版本，因此和目前Windows 10系统中的文件管理器相比还显得非常简陋，但整体框架已经搭建完成。打开该应用，你首先注意到的就是现代化设计，整体用户界面体验要比当前版本好很多。

  

![](../Images/7870dc52f455768fdfdd6a535c70f0b1.png)

  

此外，微软还改进了新版文件管理器的过渡动画，UX交互体验更优秀。不过新版在功能方面还存在较大缺失，但相信一旦丰富和完善起来会比当前版本更强大。
