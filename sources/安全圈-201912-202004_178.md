# 由于冠状病毒问题而取消或推迟的安全会议列表

由于新型冠状病毒COVID-19在世界的各地的蔓延，已经有许多技术会议和贸易展览取消、推迟或改为虚拟会议，现在许多网络安全会议也面临着同样的命运。

  

以前一些网络安全专业人员由于时间、差旅或健康等问题，无法参见一些他们喜欢的安全会议，但现在对他们来说可能是个好消息，他们可以从家、公司或者任何舒适的场所参加一些安全会议了。

  

下面是一些即将召开的会议信息及状态，包含取消、推迟或改为网络形式的会议。未列出的会议预计会按计划进行。

  

**Wild West Hacking Fest **\-  -3月10日至3月13日，圣地亚哥-当前状态：虚拟。

  

**Women in Cybersecurity**  -3月12日至3月14日，奥罗拉（科罗拉多州）-当前状态：已取消。

  

**ICS West (trade show)** -拉斯维加斯3月17日至3月20日-当前状态：推迟到7月，新日期待定。 

  

**Pwn2Own CanSecWest (hacking contest)**\-温哥华3月18日至3月20日-当前状态：可以选择远程参与。参加Pwn2Own黑客大赛的黑客可以参加，他们也可以要求组织者代表他们执行攻击。

  

**InsomniHack**\- 3月19日至3月20日，日内瓦-当前状态：推迟到6月4日至6月5日。

  

**Black Hat Asia** -新加坡3月31日至4月3日-当前状态：推迟至9月29日-10月2日。

  

**BSidesCharm**\- 4月4日至4月5日，巴尔的摩-当前状态：执行调整后的规则。远程发言人可以选择使用视频会议，而不必到现场参加会议。

  

**Kaspersky's Security Analyst Summit** -4月6日至4月9日，巴塞罗那-当前状态：推迟至9月，确切日期待公布。

  

**DEF CON China**\-北京 4月17日至4月19日-当前状态：已推迟，新日期尚未公布。

  

**Area41 **\-6月11日至6月12日，苏黎世-当前状态：推迟到明年2021年6月。

  

另外已经被取消的知名科技会议包括**移动网络大会、Facebook的F8开发者大会、谷歌的I/O开发者大会、IBM的Think 2020、Zoho的Zoholics和SXSW。**选择虚拟化的会议包括**Microsoft的WSL会议，NVIDIA的GTC，Adobe峰会，Atlassia峰会和Google Cloud Next**。
