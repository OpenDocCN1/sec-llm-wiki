# 已将近2个月：Windows 7用户仍没太大动力升级

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651966366&idx=4&sn=293919600a0de8ffe45c4309a81bbc0c&chksm=f36ce7dec41b6ec8931add701d69eba68a9fc86decdb5fcd26b644ca2bb4b7f404363d024148&scene=126&sessionid=1681311813#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651966366&idx=4&sn=293919600a0de8ffe45c4309a81bbc0c&chksm=f36ce7dec41b6ec8931add701d69eba68a9fc86decdb5fcd26b644ca2bb4b7f404363d024148&scene=126&sessionid=1681311813#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

Windows 7系统已经停止支持，微软已经不再为该系统提供安全更新，并鼓励和敦促用户尽快升级到Windows 10系统中。**尽管微软已经使用全屏通知等方式提醒用户升级，但Windows 7仍然是微软第二常用的桌面操作系统。**

![](../Images/7a8a669b2cbe341429ee447d57fff169.png)

  

自Windows 7支持终止已经过去了两个月，但事情几乎没有改变。根据NetMarketShare公布的最新2月数据，Windows 7仅占台式机市场的25.20％，而Windows 10占PC的57.39％。这些Windows 7拥趸依然没有升级新系统的打算。

  

Windows 7核心用户不愿意在短期内升级到Windows 10，并且未来几个月市场份额可能不会发生重大变化。
