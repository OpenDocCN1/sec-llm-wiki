# 微软警告Windows 10 Bug或阻止驱动程序更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651966350&idx=4&sn=3e725ae055ad6c5b2a8fc473ea176371&chksm=f36ce7cec41b6ed8ba199e072beec6db1d9b579b8bf383154ce34e5b18e72fb7812f21245b04&scene=126&sessionid=1681311813#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651966350&idx=4&sn=3e725ae055ad6c5b2a8fc473ea176371&chksm=f36ce7cec41b6ed8ba199e072beec6db1d9b579b8bf383154ce34e5b18e72fb7812f21245b04&scene=126&sessionid=1681311813#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

Windows Update 为包括 Windows 10 操作系统在内的微软产品提供了便捷的安全维护与软件升级服务，**然而新曝光的一个 bug，可能导致系统无法顺利安装驱动程序更新。**通常情况下，通过 Windows Update 发布的驱动程序是经过品质认证、可良好地在客户设备上使用的，但这并不代表该通道总能推送最新的修复更新。

  

![](../Images/5cc4690e02d55e72ab7c2ac7c76f8bcd.png)

资料图（来自：Microsoft）

  

某些情况下，用户更需要使用自定义的驱动程序，而不是 Windows Update 提供的版本。为此，Windows 10 也允许用户在其设备上手动安装设备驱动程序。

  

遗憾的是，尽管驱动安装功能可正常运行，但近日已被微软证实的一个 bug，却可能阻止用户的部署。

> 微软表示，‘内存完整性’设置可能阻止驱动程序的加载，并在安装时导致潜在的意外行为。
> 
> 有鉴于此，该公司警告称 —— 如您选择继续使用设备、但又无法搞定驱动程序相关的问题，即有可能发现某些支持的功能不再起效，后果的轻重程度也不尽相同。

据悉，该问题影响 Windows 10 的各大版本。想要临时避免这方面的尴尬，可尝试关闭 Windows 安全应用程序中的有关设置项。

> （1）点击‘开始’菜单，转到‘设置’；
> 
> （2）单击‘更新和安全’，打开‘Windows 安全中心’；
> 
> （3）在‘安全中心’中找到‘设备安全性’；
> 
> （4）在‘内核隔离’项目下，关闭‘内存完整性’功能；
> 
> （5）如需设置生效，轻重新引导系统。

此外，微软还建议用户通过 Windows Update 或制造商网站等地方搜寻其它驱动程序。

> 在相关新闻中，该公司最近推出了新的 WIndows 10 可选更新体验，允许用户选择切实取药的驱动程序更新。
> 
> 比如用户可以忽略打印机、鼠标、键盘、图形、存储和非安全补丁程序的特定更新。
