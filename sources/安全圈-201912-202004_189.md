# 15.1万微软员工已升至稳定版 新Edge已做好企业部署的准备

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651966338&idx=5&sn=ec04358ebce56a136b6451b07c37b9d5&chksm=f36ce7c2c41b6ed4f78d81e4be9f025dd270f836284ab477095299a3ae2df2c28d578402bac2&scene=126&sessionid=1681311813#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651966338&idx=5&sn=ec04358ebce56a136b6451b07c37b9d5&chksm=f36ce7c2c41b6ed4f78d81e4be9f025dd270f836284ab477095299a3ae2df2c28d578402bac2&scene=126&sessionid=1681311813#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

微软已经向公司所有15.1万名员工推出基于Chromium的稳定版Edge浏览器。根据Microsoft IT Showcase官方博文，在新版Edge浏览器开发阶段邀请10万名微软员工提供反馈，并以此观察新浏览器是否已经准备好满足企业客户的需求。

  

![](../Images/39a95133996dd9452fce1465a93a9526.png)

  

负责Microsoft Edge的首席项目经理Steve Rugh表示，基于Chromium的新版Edge中有很多企业级IT管理员喜欢的东西。博文中写道：“与其通过另一款浏览器来寻找打破Web局面的方式，我们更倾向于在开源的Chromium项目之上构建和改进。现在我们浏览器的易用性大大提升。

  

新Edge浏览器依然是微软的门面，也欢迎更多人更轻松的走进来。它具有和扩展程序和网站的最佳兼容性；它为最新的渲染功能和现代Web应用程序提供了强大的支持；并且在所有受支持的平台上提供强大开发人员工具。”

  

新版Microsoft Edge为企业用户引入了包括Application Guard和SmartScreen的诸多新功能。 Application Guard使用单独的容器打开Microsoft Edge，以防止黑客试图访问您的Windows设备和/或操作系统，而SmartScreen可帮助保护Windows PC免受恶意软件和网络钓鱼攻击。
