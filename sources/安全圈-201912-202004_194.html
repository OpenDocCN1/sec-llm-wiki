Chrome浏览器终于可以并排查看两页PDF文档了

原文：http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651966318&idx=5&sn=35f802c0f7cf67cebb723644127595b2&chksm=f36ce72ec41b6e3816aa1b892a12e39ee8335ae389ec7cb5fc3b019525dfda71145add8dcc7c&scene=126&sessionid=1681311813#rd


在 Adobe 流行的 PDF 阅读器和经典版 Microsoft Edge 浏览器中，我们都是可以在窗口或缩放比例合适的情况下，以并排两页的方式来查看 PDF 文档。然而在 Google Chrome 和基于 Chromium 内核的新版 Edge 浏览器中，这项功能却迟迟未能实现。好消息是，在最速更新的 Canary 通道上，谷歌已经加入了这项改进。


经典版 Edge 浏览器中的 PDF 两页视图


对于习惯了纸质书、或拥有大屏显示器的用户来说，双页模式有望节省大量的阅读时间。


目前谷歌正努力为 Windows、Mac、Linux 和 Chrome OS 的 PDF 查看器添加并排视图改进，经典版 Microsoft Edge 的用户可在工具栏选项中激活。


点击“页面视图”，选择“两页”图标或按下 F8 功能键，然后使用鼠标滚轮来水平翻转页面。


在 Adobe Acrobat 阅读器中，体验略有不同。你需要点击“视图 -> 页面显示”，然后选择“两页视图”，并可正常滚动翻页。


Chrome Canary 中的 PDF 双页视图


其实早在 2010 年，就有人向 Chrome 开发团队请求，希望为原生 PDF 查看器加入双页模式。


Chromium 团队从去年开始着手这项工作，目前已在 Canary 通道的 Chrome 82 中添加了一个功能标记，相信正式版也将很快引入。


需要指出的是，Chrome 自带的 PDF 阅读器，其实基于开源的 PDFium 引擎，当前已支持页面自适应缩放、打印和旋转调节功能。


最后，在 Google Chrome 发展的同时，新版 Microsoft Edge 等第三方浏览器亦有望很快跟进。
