# Windows Core OS 相关信息再遭“泄露”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651966278&idx=4&sn=ea58710e3fed31b8e89de2e4edb63bac&chksm=f36ce706c41b6e10374ca50f3f874bb0af6795fc9c004707e14f122ea9f3bc2c81ff3109c9e2&scene=126&sessionid=1681311813#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651966278&idx=4&sn=ea58710e3fed31b8e89de2e4edb63bac&chksm=f36ce706c41b6e10374ca50f3f874bb0af6795fc9c004707e14f122ea9f3bc2c81ff3109c9e2&scene=126&sessionid=1681311813#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

微软 Windows Core OS（WCOS）计划的相关消息又双叒叕遭到了泄露。据近日发布在 LinkedIn 上的职位信息显示，微软正在开发基于 Windows Core OS 的“创新技术”，用于混合现实设备。

  

![](../Images/edb9c4c14846df8b832a508939c373af.png)

  

“我们正在寻找经验丰富的工程师来帮助实现令人兴奋的全新混合现实方案。混合现实合成团队正在研究与混合现实与 Windows Core OS 集成相关的创新技术，并启用新设备和功能以使您的应用程序在现实中工作。您将不断面临复杂的问题和挑战，并且将不得不基于遥测和用户反馈做出决策。您将使用从内核组件一直到应用程序框架和 Windows Shell 的代码。强大、性能、无退化、高质量代码将始终是最重要的指标。”

  

此外，据 Windows Latest 消息称，Microsoft Store 中最近还被发现了一个基于 Windows Core OS 的 GameCore 测试游戏。根据报告，GameCore 将允许开发人员构建可在任何地方运行的游戏，包括 Windows 和 Xbox。

  

![](../Images/65c686b2fe667252b93a8dc5b0119ac5.png)

  

事实上，一直以来微软都未曾公开谈论过 Windows Core OS，基本上有关此新平台的所有信息都来自于泄漏。今年 1 月，开源中国就曾写过一篇有关微软工程师简历“泄露” Windows Core OS 信息的报道，并对其以往被披露过的消息进行了大致梳理。
