# 微软披露重新设计的Windows 10开始菜单

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651966278&idx=3&sn=fa75db88d11f8e8d9be01e9da6957c10&chksm=f36ce706c41b6e108b0341f111d1c90bca934e4a14c50bcf7ef9b45c95610df540b18cc89e0a&scene=126&sessionid=1681311813#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651966278&idx=3&sn=fa75db88d11f8e8d9be01e9da6957c10&chksm=f36ce706c41b6e108b0341f111d1c90bca934e4a14c50bcf7ef9b45c95610df540b18cc89e0a&scene=126&sessionid=1681311813#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

**最近有报道称，微软将从 Windows 10 的“开始”菜单中剔除动态瓷贴（Live Tiles）。****而最新披露的概念设计，似乎已经证实了这一点。**

  

由图可知，新的“开始”菜单具有基于图块的静态图标、采用了更进一步的 Fluent 设计风格。当然，只要用户依然喜欢，动态瓷贴就不会很快消失。

  

![](../Images/d0bff803095ce9f4751c49d4d82bbf5f.png)

  

在 Windows Insider 播客中，微软展示了 Windows 10“开始”菜单的内部概念，可知其换成了基于图标（而非实时信息）的图块。

  

新设计能够为用户带来统一的体验，与 Windows 自定义设置更加一致。不过为了消除大家的顾虑，该公司称动态瓷贴并不会被完全删除，有需要的用户仍可启用它们。

  

举个例子，“开始”菜单可与深浅色主题保持一致，而且新瓷贴有了背景色和圆角。至于新设计能否在 Windows 10 2004 中出现，目前看来不大可能。

  

微软称设计团队正在“探索”新“开始”菜单的布局，目前该项目仍在进行中，意味着短期内不会与大家建模。
