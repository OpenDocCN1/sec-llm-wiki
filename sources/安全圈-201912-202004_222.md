# Windows 10 2004将带来文件资源管理器的重大改进

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651966165&idx=2&sn=b85188828ffd665287987a93970b14a4&chksm=f36ce695c41b6f836b0afe2fc27c8fe27ce2526e1afb0aebe2a1b7c095af541cfc1e9cb3ab1d&scene=126&sessionid=1681311813#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651966165&idx=2&sn=b85188828ffd665287987a93970b14a4&chksm=f36ce695c41b6f836b0afe2fc27c8fe27ce2526e1afb0aebe2a1b7c095af541cfc1e9cb3ab1d&scene=126&sessionid=1681311813#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

**外媒报道称，微软已计划在 Windows 10 2004 中引入针对文件资源管理器的重大改进，尤其是转向了由 Windows 搜索来驱动。**首先，当用户在 File Explorer 的搜索框中输入内容时，将可看到一个下拉列表，其中包含了建议的文件。

  

![](../Images/212e19d49d4cb820e4a7ab84a8eda7e9.png)

Windows 10 2004 平板模式

  

改进后的搜索框，可以通过直接点击来启动。如果你想打开文件的位置，也只需右键点击该条目，参考弹出的新选项。

  

![](../Images/a9c156cc1036f134e02617ede69d5c32.png)

新版还整合了 OneDrive 云盘与传统的本地索引搜索结果

  

如需借助命令、或更深入地研究未编入索引的位置，则仍可按回车键并使用传统的搜索结果呈现方式，以填充满当前的视图。

  

![](../Images/e2ff5a153dc1223432054e8817bc7694.png)

  

据悉，定于今年上半年正式推送的 Windows 10 2004，将是一个包含诸多新功能和改进、以及 bug 修复的重大系统更新。更多内容，还请翻阅官方更新日志。
