# 批量成人内容泄漏流传：被质疑遭到黑客攻击

**据美国新闻聚合平台Buzzfeed报道：社交媒体平台OnlyFans可能遭到黑客攻击，有大量成人内容流出。**

  

OnlyFans是英国的社交媒体平台，受到网红，色情演员和性工作者的欢迎。

  

![](../Images/cd578af83297a4fc0fe3a3c773f2e4bb.png)

截图自Buzzfeed

  

OnlyFans数TB的成人内容，包括色情图片和视频，从星期四开始流传。根据Twitter用户的说法，通过Mega云存储站点共享的泄漏内容可能有1.5到4 TB。  

  

![](../Images/840afd682beb379e05945ed8a5f168f7.png)

  

泄漏消息传开后，OnlyFans否认其平台发生了任何恶意事件。

  

对此，OnlyFans营销主管Steve Pymm表示，网站并没有遭到黑客攻击。他们调查了整个网站被黑的说法，没有发现任何违攻击系统的证据，而且泄露的文件似乎是从包括其他社交媒体应用程序在内的多个来源策划的。

  

先注意到内容泄露的是Scottish 记者Vonny LeClerc，他报道称社交媒体上流传着包含约1.5 TB被盗内容的超大云存储文件。她说，泄露的文件杂乱无章，内容分散在几个不同的文件夹里。

  

OnlyFans发言人没有回答有关该公司是否已采取措施阻止Mega链接扩散的后续问题。

  

泄漏被整理为一个目录，其内容按首次上传到OnlyFans的日期列出，并由表演者在网站上使用的名称列出。 根据Mega上的链接，泄漏的对象包括TikTok明星，Instagram模特和业余色情明星，所有这些人都使用OnlyFans通过制作成人内容赚钱。

  

尽管OnlyFans泄漏并不少见，但从未有像周四那样大而广泛的泄漏。Reddit和Telegram上有一些社区专门致力于破解表演者的帐户并在未经他们同意的情况下共享内容。这些视频中有许多最终都进入了各种管站点。

  

上周六，在类似的活动中，OnlyFans泄密事件同样大，但有所不同。

  

同时，这并不是成人演员和性工作者的内容和个人信息的第一次大泄漏。据报道，色情网站SextPanther也在今年早些时候公开了用户的信息，包括家庭住址，出生日期和生物特征数据。而且，根据电子前沿基金会的技术专家戴利·巴内特（Daly Barnett）的说法，其他为性工作者服务的网站（如PussyCash和iWantClips）最近也有漏洞。
