# Brave浏览器推出404时光机器 可检索消失网页的历史存档

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651966104&idx=3&sn=8b0a495c74d5f134c48a571d486e17b8&chksm=f36ce6d8c41b6fce7d8cb6d18850e7ce42b7c88591bd3193d7713049b27da78d46dc211b5165&scene=126&sessionid=1681311817#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651966104&idx=3&sn=8b0a495c74d5f134c48a571d486e17b8&chksm=f36ce6d8c41b6fce7d8cb6d18850e7ce42b7c88591bd3193d7713049b27da78d46dc211b5165&scene=126&sessionid=1681311817#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

网上冲浪的时候，难免会遇到一些网页显示 404 错误。该代码表示特定的页面不存在，但无法分辨其从一开始就不存在、还是曾经短暂地出现过。**好消息是，由 Mozilla 前 CEO Brendan Rich 打造的 Brave 浏览器，已经整合了一项神奇的技能 **—— 在 404 界面上，查找已消失网页在互联网档案馆中的历史存档。

  

![](../Images/f50dc0fb29fb5e15dd189d023ddbbe8c.png)

  

尽管听起来像是时光机器，但这项技能的背后原理并不复杂。只是在浏览器遇到 404 报错的时候，Brave 可允许一键加载存档页面。

  

有趣的是，除了 404 错误，Brave 浏览器还可涵盖 408、410、451、500、502、503、504、509、520、521、523、524、525 和 526 等错误。

  

过去 23 年里，Wayback Machine 已存档 9000 亿个 URL 和 4000 亿个网页，且每天都会增加上亿个存档URL，因此一键拯救的成功率还是相当高的。
