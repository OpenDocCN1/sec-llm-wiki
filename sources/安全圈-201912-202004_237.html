尽管Windows 10 Version 2004（20H1）的RTM版本--Build 19041已经于去年12月发布，但需要数月的打磨等待今年春季的时候再发布。今天微软在Insider下载页面放出了Build 19041的ISO镜像，同时被列为Fast和Slow通道版本。



Windows 10 Build 19041.1主要调整和改进


Quick Search功能向国际用户开放

上月，微软宣布了全新的Quick Searches功能，能够帮助用户更快、更轻松的找到网页答案和结果。此前该功能仅限于美国英语用户，现在微软宣布扩展支持简体中文等其他语种， 包括

澳大利亚：英文

加拿大：英文和法文

中国：中文（简体）

法国：法文

德国：德语

印度：英语

意大利：义大利文

日本：日语

墨西哥：西班牙语

西班牙：西班牙文

英国：英文

美国：英语

使用Quick Searches可以快速找到关于天气、热门新闻、历史上的今天、最新电影、偶尔出现的季节性主题或有趣的测验的信息。根据您所处的市场，您会看到其中两个到四个选项。

想要使用Quick Searches功能，只需要点击任务栏上的搜索框或者按下Win键+S打开Search Home。只需键入以输入搜索内容，即可快速轻松地获取所需的信息。

注意：这是服务器端的更改，目前正在推广中，将在受支持的市场中从版本1809到20H1的版本向用户显示。

PC端的常规改进

● 此版本不再显示桌面右下角的版本水印。但这并不意味着微软已经完成了

● 已经修复在尝试安装最新的版本时，安装程序回滚并返回错误代码0xc1900101。在某些情况下，更新在后续尝试中成功完成。如果遇到问题，请确保在“反馈中心”中提交反馈。

● 修复了在尝试登录设备上的辅助帐户时可能导致崩溃的问题

● 修复了某些Office应用程序中使用日语IME时，可能导致使用重新转换时候选窗口不出现的问题。

● 修复了如果在打开“公共文件对话框”后保持闲置状态，则可能导致win32应用程序出现CPU使用率意外增加的问题。



已知的问题

●  由于某些Insider Preview版本和某些BattlEye反作弊软件版本在操作系统中的调整，BattlEye和Microsoft发现了不兼容问题。为了保护可能在其PC上安装了这些版本的内部人员，Microsoft已对这些设备应用了兼容性保留，以防止受到影响的Windows Insider Preview版本。有关详细信息，请参见本文。

●  Microsoft在调查安装新版本时有关更新过程暂停较长时间的报告。

●  微软正在调查有关某些外部USB 3.0驱动器在连接后未响应Start Code 10的报告。

●  Microsoft已收到有关Optimize Drives应用程序的报告，错误地报告了优化并未在SSD设备上运行的情况。
