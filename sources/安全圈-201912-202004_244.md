# 联想产品总监吐槽Windows 10奇葩Bug：i5-1035G1“最高负载”0.99GHz.

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651966061&idx=3&sn=421b3314e7501ce440c0e9072e2e81fc&chksm=f36ce62dc41b6f3b20e72e90c0a331e90c0d6026fcbae9a3bfe2f6994f81f5b51a3c6f77e92c&scene=126&sessionid=1681311817#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651966061&idx=3&sn=421b3314e7501ce440c0e9072e2e81fc&chksm=f36ce62dc41b6f3b20e72e90c0a331e90c0d6026fcbae9a3bfe2f6994f81f5b51a3c6f77e92c&scene=126&sessionid=1681311817#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

虽然微软一直在提供更新，但Windows 10仍然存在一些Bug。2月23日消息，联想集团产品总监、联想平板电脑事业部高级产品经理林林发现并吐槽Win10的CPU频率显示Bug：对于10nm Icelake的i5-1035G1（YOGA S740，小新Air14 2020，还有一些其他厂商的用这颗CPU的机器也是同样）。

  

**无论实际CPU跑在什么负载多高的频率上，****Windows****的任务管理器总是一直显示0.99GHz。**

  

如下图，系统的各种性能均正常，无论是游戏还是办公，但是在Win10的任务管理器中CPU一直显示0.99G，其他的软件如CPU-Z，HWinfo，Aida64等均能显示CPU实际是跑在3.3GHz的频率上。**Win10就是这么奇葩，但性能完全完全不受任何影响，只是显示有问题。**

  

![](../Images/0749fa9e949efc6a57fd6c1df9c33e4a.png)

  

此前，微软曾面向快速通道的Insider会员推送过版本号Build 19569.1000的Windows 10新预览版，修复了OneDrive不工作和高CPU占用；部分三方虚拟机不识别SCSI驱动器而出现C1900191报错；开始菜单无法稳定使用；部分用户遭遇“SYSTEMTHREAD EXCEPTION NOT HANDLED”报错的绿屏等诸多问题。此番的CPU频率显示Bug目前看来还有待解决。
