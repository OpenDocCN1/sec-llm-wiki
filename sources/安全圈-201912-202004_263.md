# Windows Update体验再升级：更好处理驱动兼容性冲突

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651965975&idx=3&sn=1d37bb678a255b60473addea8527dc74&chksm=f36ce657c41b6f4114833b49200620b5cecec746ba1dd1148b85b266aa3b8129ef0a83eacac2&scene=126&sessionid=1681311817#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651965975&idx=3&sn=1d37bb678a255b60473addea8527dc74&chksm=f36ce657c41b6f4114833b49200620b5cecec746ba1dd1148b85b266aa3b8129ef0a83eacac2&scene=126&sessionid=1681311817#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

在前天放出的官方博文中，微软宣布将改善Windows 10系统中的Windows Update整体更新体验。尽管微软表示一直在努力寻找正确更新Windows的方法，但是几乎每次Windows 10 更新都有用户报告各种问题。

  

![](../Images/cacb130688994bb4795ca274307b2e95.png)

![](../Images/ab0de98f974e9cbcedb63cdf2c051773.png)

  

在2019年，就因为强制进行功能更新而遭到用户的广泛诟病，为此微软决定施行新的更新策略，以便于用户对系统更新有更多的掌控力。在博文中微软表示，Windows 10能够更好的处理驱动程序兼容性冲突，能够为你的处理器，键盘，鼠标，图形和其他设备安装合适的驱动程序。

  

微软表示，驱动程序制造商能够更轻松地发布驱动程序，并能够让微软更及时的发现驱动程序问题，并在将驱动更新发送给用户之前解决这些问题。微软还在积极调整Windows Update设置页面，包括全新的“可选更新”区域。Windows Update仍将自动安装许多硬件驱动程序更新，不过新的额外更新并不会自动安装，而是会出现在可选更新页面中。

  

使用此新功能，客户和企业可以了解Windows更新中的内容（驱动程序，非安全更新和其他修补程序），以便他们可以决定是否以及如何进行准备。其他改进也将使其合作伙伴轻松地将用户定向到正确的驱动程序。

  

根据Microsoft的说法，新体验将在今天晚些时候向消费者推出，而这些调整会在北美时间2月19日下午5点正式生效。，Microsoft计划允许硬件合作伙伴在特定Windows 10版本与PC上的驱动程序兼容性冲突时阻止功能更新。换句话说，硬件合作伙伴如果知道驱动程序存在问题，便可以请求更新阻止。
