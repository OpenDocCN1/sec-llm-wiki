# Face ID遭遇Bug 导致iPhone解锁后出现鬼影键盘

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651965975&idx=2&sn=7e4898544a68442cac7294c04af1e806&chksm=f36ce657c41b6f41a9f8fb03c6ab823471d08bdd8323725455d62f78c1b76ca577487af81347&scene=126&sessionid=1681311817#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651965975&idx=2&sn=7e4898544a68442cac7294c04af1e806&chksm=f36ce657c41b6f41a9f8fb03c6ab823471d08bdd8323725455d62f78c1b76ca577487af81347&scene=126&sessionid=1681311817#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

尽管无法从手头的 iOS 设备上重现网友描述的 Face ID 故障，**但从 Reddit 网友分享的帖子来看，iOS 12 和 iOS 13 均有可能在通过面容 ID 解锁后，遇到类似的“鬼影键盘”。**通过分析网友们的爆料，可知问题集中在带有字母数字密码的 iPhone 用户群体中 —— 尤其在面部识别系统无法立即检测到已注册面容的情况下。

  

![](../Images/e57cbf9df0423d1265fbd9e924abbc31.png)

（图自：Apple，via Softpedia）

  

某 Reddit 网友评论称，想要重现这一 bug，只需在解锁 iPhone 前挡住 Face ID 传感器。

于是在触发 Face ID 并解锁 iPhone 之后，点击主屏的下半部分，就会触发无背景的“鬼影键盘”。

  

![](../Images/d138e8173a8e8d42439bcf0eb1361ba9.png)

  

这表明键盘控件仍在后台运行，但屏幕上已经不可见。目前已知受影响的设备包括 iPhone X 和 iPhone XS，系统版本从 iOS 12 往上都有人汇报。

  

人们已经向苹果汇报了这个“鬼影键盘”bug，然而在运行多个 iOS 版本的 iPhone 11 Pro 设备上，我们并没有顺利地重现这一故障。

  

![](../Images/32a64b7549fe58b4a794d7789c57883c.png)

  

尴尬的是，据向苹果（以及安全漏洞赏金项目）上报该问题的 Reddit 网友所述，他只得到了很敷衍的答复：

> —— 很抱歉，这并不涉及安全方面的问题，我们已于几个月前完全无视了他。

失望之余，这位网友决定奋起一搏：

> 即便我对该 bug 的修复失去了全部希望，但至少可以让问题广为传播，或许这样还有机会倒逼苹果修复这个 bug 。
