# NCA：使用Kali Linux等软件的孩子可能成为黑客

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651965892&idx=1&sn=516402fbce2aad057086c78f9082b6c7&chksm=f36ce584c41b6c929a8c33fba53a04d55b3ba3c8421591b3080b5454da06fd09199fd666d7b0&scene=126&sessionid=1681311821#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651965892&idx=1&sn=516402fbce2aad057086c78f9082b6c7&chksm=f36ce584c41b6c929a8c33fba53a04d55b3ba3c8421591b3080b5454da06fd09199fd666d7b0&scene=126&sessionid=1681311821#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

由西米德兰地区打击有组织犯罪部门（WMROCU）制作、印有英国国家犯罪局（NCA）徽标的宣传海报发出警告，**使用Tor浏览器、Kali Linux Discover发行版本和Metasploit等软件的儿童极有可能成为下一代黑客。**

  

![](../Images/ae8a3f607be55ef36f0ebddcbd1f344f.png)

  

这张警示海报是由推特用户G\_IW上传发布的，在警告内容中写道：“如果你看到孩子正在使用这些软件，或者认为孩子存在黑客破解行为，请告知我们，我们可以提供合理的建议，并引导孩子树立正确的价值观。”

  

这张宣传海报认为TOR Browser, virtual machines, Kali Linux, WiFi Pineapple, Discord和Metasploit等软件可以用于不良目的。其中Kali Linux是专门用于渗透测试的发行版本，幕后团队赞同这张海报的做法。

  

Kali Linux的开发者在推特上表示：“必须承认这样做很好，在他们人生开端时树立了正确的价值观。我们都知道教育孩子最简单的方式就是告诉他们，什么应该做，什么不应该做，那么这些罗列的软件清单就是他们不应该碰的。”

  

![](../Images/ba7d2508b83f7bce0fcb6ad1104bd3fc.png)

  

尽管这张海报上印有英国国家犯罪局（NCA）的徽标，但是NCA回应称和这张海报没有任何关系。NCA表示：“NCA没有参与这张海报的生产或分发。有很多适合技术娴熟儿童使用的工具，其中有部分可以同时用于合法/不合法的目的，所以家长和孩子知道如何安全使用这些工具才是至关重要的。”
