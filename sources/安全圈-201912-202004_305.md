# NASA"立扫把挑战"引爆社交媒体

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651965813&idx=5&sn=8803c45c4b323f01dac3ef401bef6d6c&chksm=f36ce535c41b6c230c4da44b6bbda759cca19856fda7dcae195824a6afd24a52793f00d79f4f&scene=126&sessionid=1681311821#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651965813&idx=5&sn=8803c45c4b323f01dac3ef401bef6d6c&chksm=f36ce535c41b6c230c4da44b6bbda759cca19856fda7dcae195824a6afd24a52793f00d79f4f&scene=126&sessionid=1681311821#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

据外媒CNET报道，这两天所谓的NASA"立扫把挑战"突然刷爆网络，社交媒体用户正在分享看似没有任何支撑的普通家庭扫把立起来的照片和视频。而这一挑战似乎始于一条推文，该推文声称“NASA说因为地球引力的作用，今天是唯一可以让‘立扫把’伎俩奏效的一天……我最初不相信，但是天哪！”

  

![](../Images/7607fe0c0d40836bd6352261f48fb4d1.png)

  

不过NASA随后澄清，该机构此前从未说过这样的话。在周二NASA官方推特帐户发布的9秒视频中，宇航员Alvin Drew和科学家Sarah Noble对“立扫把挑战”作出回应，表明这只是简单的地心引力，每天都可立起扫把。

  

![](../Images/91503dde79de089f18174f40903c172f.png)

“你昨天进行了立扫把挑战吗？”Noble问道。“事实证明，您今天可以再做一次。” Drew回应道：“这只是物理学问题。”

  

![](../Images/9559ab0e4ecdac21e5ff40e49f09ce3f.png)

  

肯尼迪航天中心游客中心的推特账号警告说：“不要进行立扫把挑战。实际上，它的重心很低，可以使扫帚在今天和任何一天保持其刷毛的平衡。”  
尽管如此，Twitter用户似乎并没有理会NASA的澄清推文。不止昨天，每天扫把都可以立起来。国内网友也是纷纷效仿，立扫把、菜刀、鸡蛋... ...  
人民日报也发文澄清：立扫把与引力大小无关！
