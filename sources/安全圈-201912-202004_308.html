Windows 7用户遭遇无法关机的bug 这里有临时解决方案

2020 年 1 月 14 日，微软如约向 Windows 7 用户推送了“最后的更新”。然而上月的“星期二补丁”，带来了将桌面壁纸变成一片黑的 bug 。在遭到大量用户的吐槽反馈之后，微软承诺在对此问题予以修复，然后在 1 月 31 日发布了相关补丁。尴尬的是，随后又有 Windows 7 用户遭遇了无法关闭 PC 的头疼问题。


（图自：Microsoft，via Neowin）



ZDNet 援引称，该问题会阻止用户关闭 PC，并附上了一条“您无权关闭此计算机”的报错消息。


庆幸的是，尽管软件巨头尚未意识到这个问题，动手能力强的人们，已经想到了一些临时的解决方案。



Windows Central 援引 Reddit 网友 dinil007 的话称，我们可以尝试对组策略进行一番调整。

（1）打开‘运行’窗口，输入‘Gpedit.msc’并执行；

（2）转到 计算机设置 -> Windows 设置 -> 安全设置 -> 本地策略 -> 安全选项；

（3）双击 用户帐户控制 -> 以管理员模式运行；

（4）打开命令提示符（cmd），输入‘gpupdate / force’并执行；

（5）* 为实施更改，必须强制重启一下系统；

（6）* 可按 Winkey + R，输入‘shutdown -r’并运行。

需要注意的是，上述操作仅对运行 Windows 7 专业版、旗舰版、企业版的用户可用（家庭版和其它版本需另寻它法）。



The Windows Club 给出了另一种解决方案，涉及对注册表编辑器的一些修改：

Windows 7 家庭版用户可以按下‘CTRL + ALT + DEL’组合键，并使用右下角的电源选项来尝试关闭 PC 。

或者按下‘Windows + L’组合键，从当前账户下注销，然后通过电源选项来关闭或重启 PC 。

最后，虽然已经有不少用户在微软官方支持论坛等渠道提交过反馈，但鉴于 Windows 7 已经终止了面向普通消费市场的技术支持，我们对微软能否在本月的“补丁星期二”推出后续补丁感到好奇。
