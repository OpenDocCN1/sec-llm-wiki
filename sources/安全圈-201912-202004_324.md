# Windows 10设置应用的顶栏又回来了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651965739&idx=2&sn=44aa29dd4fcedea0e3a6629176eba0f8&chksm=f36ce56bc41b6c7d874e0ed0d816350263f55bdc2b507493f82875ccec8102e8bcf592dd64c9&scene=126&sessionid=1681311825#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651965739&idx=2&sn=44aa29dd4fcedea0e3a6629176eba0f8&chksm=f36ce56bc41b6c7d874e0ed0d816350263f55bdc2b507493f82875ccec8102e8bcf592dd64c9&scene=126&sessionid=1681311825#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

在早前面向 Insider 测试者的快速更新（Fast Ring）编译版本中，微软曾将 Windows 10 设置应用的顶栏给取消。**没想到的是，HTNovo 报道称，现在它竟然又在 Windows 10 1909 更新中回来了。**据悉，设置应用顶栏旨在提供一些基本信息、以及方便用户快速访问某些功能。

  

![](../Images/73e6f38dd15d630db0ef2eefcfea6d4d.png)

（题图 via MSPU）

  

此前有不少用户抱怨设置应用的顶栏“造成了空间上的无谓浪费”、提供的信息也没什么用。

不过现在看来，微软还是觉得顶栏能够方便用户快捷操作，比如登录和管理 Microsoft 帐户，从而改善 Windows 和微软产品的使用体验。

  

用户可借此轻松查看系统状态、何时有可用的更新，另有一些用户建议微软提供设置应用顶栏的定制功能。

  

虽然微软尚未发布这样的公告，但我们还是可以小小地期盼一下。
