# iCloud.com更新：支持Android/iOS原生移动浏览器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651965674&idx=4&sn=e8d9a9e2fc6531a5ea77c8fe93355b84&chksm=f36ce4aac41b6dbc5992f1939e488b028e9aab8520b146a81fb7cd128a1c740efa71a30686be&scene=126&sessionid=1681311825#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651965674&idx=4&sn=e8d9a9e2fc6531a5ea77c8fe93355b84&chksm=f36ce4aac41b6dbc5992f1939e488b028e9aab8520b146a81fb7cd128a1c740efa71a30686be&scene=126&sessionid=1681311825#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

随着近日的更新，iCloud.com 现在终于可以在 Android / iOS 设备上，通过对移动界面更加友好的原生浏览器来访问大量功能，比如“查找我的 iPhone”。尽管苹果没有大张旗鼓地宣布这一喜讯，但还是值得我们庆祝一下的。此外，用户可以通过移动 Web 界面访问 iCloud.com 的照片、便笺、提醒等功能，而无需切换到桌面站点。

  

![](../Images/dd6483868c27f985fe1d7a5a83f1963e.png)

  

推出初期，用户可能会遇到一些 bug 。随着时间的推移，苹果可以听取用户提交的反馈，并及时作出修复。展望未来，苹果还可能会推出扩展的 iCloud 服务，比如联系人和日历的访问。  
Newslanded 指出，Android 移动版 Chrome 浏览器无法创建新的便笺。此外 Apple Insider 提到，要在移动 Web 版 iCloud 上查看提醒，用户必须先在 iOS 或 iPadOS 上创建提醒列表。  
好消息是，包括查找 iPhone 在内的其它功能，目前都可如预期运行。用户还可访问账户设置，查看剩余的 iCloud 存储空间，并提供 Apple ID、语言和格式的外部链接。  
对于只有一部 Android 备用机，偶尔需要通过 iCloud.com 来定位 iPhone 的用户来说，这确实是一次值得庆祝的更新。
