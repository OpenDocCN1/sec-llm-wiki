# 63项性能测试证实 Linux系统比Windows 10快了15%

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651965674&idx=2&sn=f013c208d0c1f55a480f1e6826751b2a&chksm=f36ce4aac41b6dbc25772e350514e066dccb38f6b39a53d590a5b7958b9a987e159890361a2e&scene=126&sessionid=1681311825#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651965674&idx=2&sn=f013c208d0c1f55a480f1e6826751b2a&chksm=f36ce4aac41b6dbc25772e350514e066dccb38f6b39a53d590a5b7958b9a987e159890361a2e&scene=126&sessionid=1681311825#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

全球最受欢迎的OS操作系统是什么？大家第一个想到的恐怕是Windows，最新的Win10安装量超过10亿了，但是如果把安卓也算作Linux系统的分支，那么Linux才是使用最广泛的系统，而且Linux系统的性能比Win10还要好——没错，就是这样。

  

著名Linux测试网站Phoronix创始人及Phoronix Test Suite开发者Michael Larabel日前亲自动手做了一个Linux vs Win10的测试，他使用售价只有199美元的笔记本——Motile M141对比了Linux发行版Ubuntu 20.04版与Win10的性能，后者使用的是AMD的锐龙3 3200U处理器、4GB内存及120GB SSD，算是很低端的配置了。

  

![](../Images/bb5a148f4339cd5624afcf2a6cbcd8c0.png)

  

Phoronix Test Suite的测试内容很多，涉及网页、Java、文件压缩、图像、音频、视频、数据库等等各种测试，不一一搬运测试数据了，只看结果。

  

![](../Images/87bb4a0732848ca7e4b2c2ab0b9b2e9e.png)

  

从测试看看，在63项性能测试中，60%的情况下Ubuntu 20.04都是领先的，也就是说Linux系统的性能更好。平均下来，这款199美元的廉价笔记本上，Linux系统的性能领先了15%之多，在Web开发、PHP编程上速度则要快得多。

  

当然了，Linux系统的性能领先Windows系统早就不是新闻了，对极客来说Linux折腾起来很好玩，但是对大部分普通人来说，Linux相比Windows系统在使用习惯及生态系统上还是有缺陷的，这不是15%性能可以弥补的。
