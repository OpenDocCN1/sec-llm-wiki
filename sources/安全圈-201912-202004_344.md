# Windows 10 Core OS或引入重新设计的通知系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651965659&idx=3&sn=398a78a52817966360336556498550bf&chksm=f36ce49bc41b6d8d77f42182af03c7211447ab3910d19e7aaa0528485bc62977a6091a13f415&scene=126&sessionid=1681311825#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651965659&idx=3&sn=398a78a52817966360336556498550bf&chksm=f36ce49bc41b6d8d77f42182af03c7211447ab3910d19e7aaa0528485bc62977a6091a13f415&scene=126&sessionid=1681311825#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

尽管距离 Surface Neo 的发布还有十多个月的时间，有关 Windows Core OS 的传闻，仍然会不时地冒出来。本周，外媒在 LinkedIn 上有了新发现，表明 Windows Core OS 的通知系统，有望获得可访问性方面的改进。具体说来是，微软计划在“通知设置”页面上引入“上下文”功能，以简化 Windows Core OS 上的通知管理。

  

![](../Images/01387a51d07c5053ae7794e3a3010ec6.png)

  

这项发现再次证实了微软正在为 Windows Core OS 项目做出积极贡献，但大量细节仍然缺失。  
先前有泄露的文档指出，重新设计的“行动中心”（Action Center），将为用户提供清晰、一致的设置访问路径。  
基于此，微软计划提供一种更加简便的方法来修改“快速设置”，同时显示设备的各项信息，比如电池状态、屏幕亮度、音量级别等。  
此外根据另一人的资料，微软可能正在为下一代 Windows 10 X（基于 Windows Core OS）带来包括 UI 适配、讲述人、以及放大镜等功能在内的诸多改进。  

![](../Images/1291749f87649ce496f1905baa3a112c.png)

  
此前，微软已经在 Hololens 2 和 Surface Hub 2X 设备上展示过 Windows Core OS，但这家软件巨头从未公开谈论过这款操作系统、更别提模块化操作系统的计划了。  
在去年的 Surface 发布会上，微软继续保持着对 Windows Core OS 细节的关注，同时 Geekbench 也泄露了有关 Windows Core System（来自微软虚拟机）的部分信息。  
最后，该公司或于今年的开发者大会上（Build 2020），披露有关 Windows Core OS 和 Windows 10 X 的更多细节。
