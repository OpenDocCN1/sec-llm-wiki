# AV-Test公布最新一期面向家庭用户的最佳Windows反病毒软件名单

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651965576&idx=2&sn=bd9dea268cabc06e554c60f9f41b1bfc&chksm=f36ce4c8c41b6dde05531aebfa9fa6004d0c7ed75415af236247d6d92ede9a4d20b1e5eb8c4b&scene=126&sessionid=1681311825#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651965576&idx=2&sn=bd9dea268cabc06e554c60f9f41b1bfc&chksm=f36ce4c8c41b6dde05531aebfa9fa6004d0c7ed75415af236247d6d92ede9a4d20b1e5eb8c4b&scene=126&sessionid=1681311825#rd)

越来越多人认为防病毒产品是无用的软件，因为操作系统中的自我防护现在已经相当完善，但是也有相当一部分人认为独立反病毒软件依然是有必要购买的，它们可以很好地让计算机远离网络威胁。选择正确的防病毒软件并不是一件容易的事情，而这正是防病毒测试的重点。AV-TEST的专家在11月和12月进行的最新防病毒测试表明，有三种产品在三项测试中几乎都表现完美后。

  

BullGuard Internet Security，Kaspersky Internet Security和NortonLifeLock Norton Security这三款应用在测试的满分18分中拿下了完整的18分，无论是保护、性能和可用性测试均得到6分。

  

虽然只有3款产品得分高得有些令人惊讶，但是还有许多其他产品的性能几乎完美无缺，并获得了17.5分。其中包括Avast Free Antivirus，微软的Windows Defender，VIPRE Security AdvancedSecurity和Avira Antivirus Pro。

  

微软的Windows Defender预装在Windows 8.1和Windows 10上，在测试过程中再次给人留下了深刻的印象，因为它的性能与领先的第三方安全厂商所提供的性能相当甚至更好。 Windows Defender在保护方面获得6分，在性能方面获得5.5分，在可用性方面获得6分。

  

在新一轮测试中表现最差的是Protected.net Total AV，在获得4分保护，4分性能和6分可用性之后，其得分几乎未达到14分。
