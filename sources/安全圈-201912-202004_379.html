Windows 10 Version 2004新功能盘点：Cortana大改 系统重装更轻松了

目前掌握的线索表明Windows 10 Version 2004功能更新已经完成，在接下来的几个月中微软将会进行打磨，努力修复各种BUG、优化后台性能和稳定性，预估会在今年4/5月和大家正式见面。


相比较Windows 10 November 2019（Version 1909）功能更新，Windows 10 Version 2004带来了诸多新的功能，接下来让我们来盘点下即将引入的新功能。



Cortana重大调整


去年11月，微软重磅宣布其语音助手Cortana（中文名：微软小娜）战略性收缩，将在2020年1月31日退出iOS和Android平台，但美国市场将较晚执行这一举措，目前仅在中国、英国、德国、澳大利亚、加拿大、墨西哥、西班牙、印度等8个国家执行。尽管微软计划从Microsoft Launcher中删除Cortana，但是公司仍然计划在Windows 10的下个功能更新中对Cortana进行改进，极大地改善对话体验。



在即将到来的Windows 10 20H1功能更新中，Cortana将会和系统搜索功能剥离，作为独立应用程序获得后续更新。Cortana可以像其他应用程序一样，通过Microsoft Store来更新Cortana应用程序。


这就意味着它会和其他Windows 10应用一样，获得应用标题栏，并能够在桌面任意拖动窗口至任意位置，也能调节窗口大小，以及最大化和最小化处理。


Cortana的新设计使您可以通过文本和语音与数字助理进行交互。 它带有新的语音和语言模型-使其比以往更快。


Cortana还允许用户打开应用程序，管理您的提醒，管理Microsoft To-Do，警报，并且还可以与传统的“ Hey Cortana”功能一起使用。


最后，Cortana允许您在亮屏和暗屏模式之间切换。 如上所述，Cortana将由Windows Store应用程序管理，因此您可以期望在未来几个月内会有更多改进。


重新安装PC更轻松了


微软负责恢复的项目经理亚伦·洛特（Aaron Lower）在Windows Insider网络广播中表示，“重置此PC功能”使其“几乎就像您第一次打开PC一样”。 如果您要出售或赠送PC，则可以擦除文件，甚至擦除驱动器，以使数据无法恢复 。 如果您遇到PC问题，或者只是想要一个干净的Windows系统，您将获得全新的Windows操作系统。



重置PC时，您可以选择保留个人文件还是将其从PC中删除。 无论哪种方式，Windows都会删除已安装的程序并为您提供全新的操作系统。


要重置PC，请转到“设置”>“更新和安全性”>“恢复”，或在“高级启动选项”菜单中选择“疑难解答”>“重置此PC”选项。 如果您在启动PC时遇到问题，则打开此菜单，但是也可以在单击Windows“开始”菜单或登录屏幕中的“重新启动”选项的同时，按住Shift键来打开它。



Windows将在后台收集所需的文件，并基本上创建一个新的Windows安装。 如果您愿意，它将把您的个人文件以及硬件驱动程序和预安装的应用程序迁移到新系统。


Windows Subsystem for Linux 2


WSL 2 做了架构的巨大变更，使用了虚拟化技术，并仍在努力改进网络支持。由于 WSL 2 现在运行在虚拟机中，因此你从 Windows 访问 Linux 网络应用程序需要使用该 VM 的 IP 地址，反之亦然，你需要 Windows 主机的 IP 地址才能从 Linux 中访问 Windows 网络应用程序。


WSL 2 的目标是尽可能使用 localhost 访问网络应用程序！可以在文档中找到有关如何执行此操作的完整详细信息和步骤。要了解有关用户体验更改的更多信息，请参阅文档：WSL 1 和 WSL 2 之间的用户体验变化。


优化搜索功能


此前，微软已在 2019 年 5 月更新中引入了增强的搜索模式，以便用户更快、更好地体验这项功能。启用之后，你可以借此快速地在 PC 上的任何位置检索文件。



在操作系统的早期版本中，Windows Search 索引包含了文档、下载、图片和桌面。要启用增强搜索模式，请打开“设置 -> 搜索 Windows -> 增强（推荐）”。


如此一来，Windows 10 就能够让系统搜索功能覆盖到整个 PC 了。需要注意的是，这项更改可能导致 CPU 和磁盘占用率过高，从而影响 Windows 的总体性能。


在 Windows 10 的下一个重大更新中，微软使用了一种新的算法，能够检测到 CPU 的高占用率，并适时确定系统的高峰使用时间。


该算法将调整索引程序并进行相应管理，以确保减少磁盘使用量和活动，从而缓解系统性能问题。


任务管理器


Windows 10任务管理器新增了两项新功能，它能够显示PC的磁盘类型--固态硬盘还是机械硬盘。另一项功能就是监控你的GPU温度，如果你使用的是独立显卡，那么就会在任务管理器的性能标签页中看到GPU温度。



磁盘清理


在Windows 10 Version 2004中，磁盘清理工具中不再显示“下载”文件夹。Windows 10 November 2019（Version 1909）功能更新以及此前版本，磁盘清理工具下依然显示“下载”文件夹（默认情况下不会选中）。



在Windows 10十月更新（Version 1809）中，微软在磁盘清理工具中引入了“下载”文件夹， 因此用户在运行磁盘清理工具的时候需要注意该选项是否被勾选，以避免文件被误删。


为避免用户意外选择文件夹，软件巨头最初在Windows 10 version 1903中添加了一条警告，提示信息显示：“这些是你私人下载文件夹中的文件，如果你想要删除所有内容可以选中这个选项。这并不跟随Storage Sense设置”。


恢复关机时所用应用



当用户启动PC并登陆的时候，Windows 10可以自动恢复关机时候所使用应用程序。在此版本中，“设置”应用中提供了一个新选项，可以更轻松地禁用该行为。


您会在“设置”>“帐户”>“登录选项”中找到禁用该功能的新选项。 启动Windows 10时，Google Chrome和Spotify等应用程序不会自动打开。
