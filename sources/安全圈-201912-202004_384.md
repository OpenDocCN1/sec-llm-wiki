# 跑分网站显示Google Pixel 4已跑上Android 11

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651965478&idx=4&sn=1b1edda738b56c802b36e03d393490fc&chksm=f36ce466c41b6d706a24995d901b851a758b9f6b5a57bb0e01af6320429b1847cc3d348a328e&scene=126&sessionid=1681311829#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651965478&idx=4&sn=1b1edda738b56c802b36e03d393490fc&chksm=f36ce466c41b6d706a24995d901b851a758b9f6b5a57bb0e01af6320429b1847cc3d348a328e&scene=126&sessionid=1681311829#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

尽管还有相当一部分用户尚未升级Android 10（Q），谷歌已经马不停蹄地开始测试Android R（Android 11）了。在知名基准测试软件GeekBench 5上，**一款Pixel 4“亲儿子”手机被发现已运行Android 11系统**，外界猜测是谷歌内部员工不小心将测试阶段的ROM泄露。

  

![](../Images/986397751ef32b60a8fe783da0ea3bee.png)

  

关于Android 11目前所知并不多，媒体仅仅是从一些开源代码分析，Android 11预计会加入以下新特性，比如移除最大4GB视频文件的限制、允许三方软件调用通话录制API、数字ID本地存储（如驾照等）、更优秀的低功耗模式等。

  

通常情况下，谷歌会在每年4、5月份公布新Android的开发者预览，9月份转正。另外，说到Pixel，关于Pixel 4a/4a XL的传言也是甚嚣尘上，感兴趣的安卓极客们可以继续关注。
