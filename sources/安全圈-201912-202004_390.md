# 新版Edge浏览器将引入Windows 10上的Fluent Design风格

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651965446&idx=2&sn=732c395cb0467d729246ab1cf44f8afb&chksm=f36ce446c41b6d50200b38102da2491880a90a54f11f0a0ce9b8037edf89688ac7e26cac9178&scene=126&sessionid=1681311829#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651965446&idx=2&sn=732c395cb0467d729246ab1cf44f8afb&chksm=f36ce446c41b6d50200b38102da2491880a90a54f11f0a0ce9b8037edf89688ac7e26cac9178&scene=126&sessionid=1681311829#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

**经过大约一年的 Beta 测试，微软终于发布了适用于 Windows 10 / 7 和 macOS 的 Chromium Edge 浏览器。**

  

其采用了与 Google Chrome 相同的 Web 引擎，但在此基础上开发了许多专属的功能。从外观上来看，新版 Microsoft Edge 确实有着新颖时尚的风采，但与 Windows 10 上的流畅设计（Fluent Design）有些不搭调。

  

当微软在 2018 年末宣布 Chromium Edge 项目时，该公司承诺将保持经典版 Edge 浏览器的外观和风格不变。但在开发了多个功能之后，Fluent Design 似乎已经成为了微软的首要目标之一。

  

软件巨头悄悄透露，其正在调查用户对 Fluent Design 和圆角动画的反馈。未来几个月里，该公司计划重点关注以下领域：

  

![](../Images/cbcacabc4b1d0519ab3274e58878d97f.png)

  

Edge 团队称：“我们一直同设计师紧密合作，以使其外观风格与 Fluent Design 保持一致，并符合我们的可用性和可访问性标准”。

  

目前 Chromium Edge 中的 Fluent Design 实施仍处于早期阶段，甚至无法与经典版 Edge 接近。鉴于微软仍在考虑意见反馈，新变化可能要到 2020 下半年才会引入。

  

该公司近日透露，新版 Edge 将于今年晚些时候，开始向所有 Windows 10 用户推送。至于计划中的 Linux 版本，微软尚未透露确切的启动时间。
