# iOS 13.3.1 Beta版中引入了禁用U1超宽带芯片的开关

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651965446&idx=4&sn=0d91ad0fe78172a67ed5124b9d85625b&chksm=f36ce446c41b6d50f2463b895dbcf4f85a0a4fcfeac3ad8cccfeb7cc82ee625042b591adae42&scene=126&sessionid=1681311829#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651965446&idx=4&sn=0d91ad0fe78172a67ed5124b9d85625b&chksm=f36ce446c41b6d50f2463b895dbcf4f85a0a4fcfeac3ad8cccfeb7cc82ee625042b591adae42&scene=126&sessionid=1681311829#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

**Twitter 网友 Brandon Butch 在本月早些时候发布的 iOS 13.3.1 的第二个 Beta 版本中发现，苹果为其引入了一个禁用设备上的 U1 超宽带芯片的开关。**

  

有需要的用户，可在“设置 -> 隐私 -> 定位服务 -> 系统服务 -> 网络和无线”中找到该选项。需要注意的是，禁用之后，蓝牙、Wi-Fi 和超宽带的性能将受到影响。

  

![](../Images/2193083ac263871f8dc35cfc80d322b4.png)

  

此前，有人发现即便禁用了位置服务，iPhone 11、11 Pro 和 Pro Max 仍会继续追踪用户的位置。于是在 Beta 测试版中，苹果添加了这项功能开关。

  

该公司称，这是超宽带的预期行为，旨在让 iPhone 的运行负荷设计要求。应国际监管法规的要求，苹果需要在某些特定位置禁用 U1 芯片。

  

通过位置服务、并结合 iOS 软件，设备可智能判断是否应在某些地区禁用超宽带技术。该公司当时承诺添加一个切换按钮，以完全禁用 U1 芯片，现在它终于在 iOS 13.3.1 上向所有人发布了。

  

苹果强调，超宽带技术的合规性、以及位置数据的使用和管理，都完全是在用户设备上完成的，期间不会收集用户的任何隐私信息。
