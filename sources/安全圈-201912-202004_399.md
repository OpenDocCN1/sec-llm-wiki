# 四大浏览器性能横评：基于Chromium的Edge要比Chrome更优秀

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651965420&idx=2&sn=e01e8f76a7a69dbd08550d8393fd9888&chksm=f36cebacc41b62ba1d32a742e16588fc0610a193ff35b91e5498df1d53cddf6796a53963e3ed&scene=126&sessionid=1681311829#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651965420&idx=2&sn=e01e8f76a7a69dbd08550d8393fd9888&chksm=f36cebacc41b62ba1d32a742e16588fc0610a193ff35b91e5498df1d53cddf6796a53963e3ed&scene=126&sessionid=1681311829#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

毋庸置疑，Chrome是浏览器市场的“一哥”，占据将近67%的市场份额。而紧随其后的Firefox、IE浏览器和Edge占有率分别为9％，7.4％和5.6％，始终无法造成直接的威胁。不过基于Chromium的Edge浏览器有望给Chrome带来一些压力，今天正式版已经面向macOS、Windows和Android平台发布。

![](../Images/050edbe1c981ce6442474f21bd2893f4.png)

那么，基于Chromium的新版Edge能够给Chrome带来多大的压力？近日外媒VentureBeats进行了一场浏览器跑分测试，对Chrome、Firefox、新版Edge和Brave四款浏览器进行了专业的测试。

  

测试平台是Surface Laptop（英特尔酷睿i5-7200U，8GB的内存和256GB的固态硬盘），并划分了100GB的空间重新安装了64位的Windows 10专业版系统。所有四款浏览器均为最新版本，包括 Chrome 79, Firefox 72, Edge 79和Brave 1.2，每款浏览器进行所有8个测试项目，每个项目均进行多次测试取平均值，最终成绩结果如下：

  

> SunSpider: Edge wins!
> 
> Octane: Chrome wins!
> 
> Kraken: Firefox wins!
> 
> JetStream: Edge wins!
> 
> MotionMark: Edge wins!
> 
> Speedometer: Edge wins!
> 
> Basemark: Brave wins!
> 
> WebXPRT: Firefox wins!

可以看到在所有8项测试中，基于Chromium的Edge浏览器获得了4个冠军，而Chrome浏览器只有1个冠军，Firefox有2个冠军，Brave浏览器有1个冠军。至于这样的成绩能否吸引更多的用户使用新版Edge，这还有待时间的考验。
