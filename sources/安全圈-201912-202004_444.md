# Windows 10X仍不成熟 新版开始菜单界面曝光

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651965263&idx=3&sn=79e0aaeddc46be9f91ec4832ecb580a7&chksm=f36ceb0fc41b621923fa94222437da843324bc29d71cf91a60bf3a8dcff892cb5f73b9d817aa&scene=126&sessionid=1681311833#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651965263&idx=3&sn=79e0aaeddc46be9f91ec4832ecb580a7&chksm=f36ceb0fc41b621923fa94222437da843324bc29d71cf91a60bf3a8dcff892cb5f73b9d817aa&scene=126&sessionid=1681311833#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

Windows 10X可以认为是微软对桌面操作系统的“全新表达”，并将于2020年面向消费者推出。不过根据联想透露的信息，该操作系统目前仍不成熟，需要更多的时间进行调整和打磨。联想表示旗下的首款可折叠双屏设备ThinkPad X1 Fold将会在今年年中时候推出，但上市之初依然会搭载Windows 10系统，待微软完善之后再推出Windows 10X系统。

  

![](../Images/f7e9c5eb9cf346da46656a39b508ebff.png)

  
此外在联想的公告中，外媒Windows Latest还发现了一个有趣的信息。根据渲染图展示的细节，Windows 10X在设备展开的时候会在中间启动开始菜单或者Launcher。而面向传统笔记本的Windows 10X系统，在唤醒设备之后可能会跳出开始菜单。

  

![](../Images/5f6af4468d5011163435b6ff6cdb6981.png)

  

除了重新设计的“开始”菜单外，Windows 10 X还带有对任务栏的更改以及新的通知中心，您可以在其中快速启用或禁用Wi-Fi，蓝牙或蜂窝数据。此外，有传言称Windows 10 X带有现代的文件资源管理器，新的锁屏体验，对Windows Update的重大改进以及对容器中传统桌面应用程序的支持。

  

![](../Images/6661160716f5f295d08da1a7393d6386.png)
