# 2019年 Windows 10彻底坐稳了“桌面第一操作系统”宝座

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651965224&idx=3&sn=4e72863654df5d49c2b28d815d37fb60&chksm=f36ceb68c41b627e0ce95428a1f27e989942ea2f0c85b0b19b101bda29a4936eb60a51b76b57&scene=126&sessionid=1681311833#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651965224&idx=3&sn=4e72863654df5d49c2b28d815d37fb60&chksm=f36ceb68c41b627e0ce95428a1f27e989942ea2f0c85b0b19b101bda29a4936eb60a51b76b57&scene=126&sessionid=1681311833#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

  

在刚刚过去的2019年中，Windows 10终于坐稳了“桌面第一操作系统”的宝座。根据市场分析公司NetMarketShare提供的统计数据，在过去的2019年中虽然偶尔出现一些小问题，但Windows 10系统呈现稳定上升的趋势。

  

![](../Images/558bd903b1a773bd0a4d815a2ede6b43.png)

  

在2019年年初，Windows 10的市场份额为40.90%，并且在去年二月下降至40.3%。不过它在11月达到了54.30％的市场份额，并在2020年结束之前以54.62％的成绩交出了一份满意的答卷。

  

而另一方面由于受到将于2020年1月14日停止支持的影响，在过去一年中Windows 7系统的市场份额在不断减少。在去年年初全球还有37.19的设备运行该系统，而在12月的统计报告中显示只有26.64%。距寿命终止只有不到两周的时间，Windows 7的市场份额很可能会继续下降。

  

其余操作系统都紧随其后，对Windows 10的统治地位没有构成威胁。例如，Windows 8.1仅在全球3.63％的系统上运行，而macOS 10.14的市场份额为3.50％。在刚刚过去的2019年，属于此消彼长的状态中，可以说是Windows 10称霸桌面系统的元年。
