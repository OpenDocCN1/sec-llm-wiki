Windows 10 version 2004新功能多，预计明年春季发布

Windows 10版本2004更新预计将于2020年春季发布，与2019年11月更新（它更像是Service Pack）不同，Windows 10 2004旨在带来Windows早期版本中未发现的新功能和增强功能。



对于希望体验Windows 10 2004（也称为20H1）和各种新功能的用户，可以加入Windows Insider程序并安装。



Windows 10 2004中的更新

1
可选的更新体验


从Windows 10 20H1开始，您不再需要访问设备管理器来管理驱动程序，并且不会自动安装新的设备驱动程序。

相反，新驱动程序将被检测为“ 可选更新 ”，并将在“查看可选更新”屏幕下列出，并选择安装。

可以在“设置” >“ 更新和安全性” >“ Windows更新” >“ 查看可选更新”下找到此新页面。



2
任务管理器得到升级

Windows 10的任务管理器具有两个新功能-第一个功能是可以查看磁盘类型，第二个功能可以监视图形卡的温度。



Windows Search降低了磁盘和处理器的利用率


过去，许多用户会禁用Windows搜索所使用的Windows索引器功能，因为它占用了过多的CPU或导致大量磁盘使用。


为了防止这种情况的发生，Windows 10将使用一种新算法来检测磁盘使用率和高活动性，并且如果检测到该算法，则会降低Windows Indexer的速度。



“基于此，我们将引入一种算法，该算法可检测磁盘的高使用率和高活动性，从而可以更好地识别高峰使用时间并相应地管理索引器。我们还为开发人员进行了更改，以防止搜索某些存储库和项目文件夹以提高磁盘使用率。”



3

Windows 10 2004新功能

无密码体验


Microsoft正在为Microsoft帐户引入无密码登录，以加强设备登录。这使Microsoft帐户可以使用“现代多因素身份验证”（例如Windows Hello，指纹和PIN）代替密码。


新的Cortana体验


Windows 10提供了一个全新的Cortana体验，它具有一个全新的基于聊天的用户界面，使用户能够键入与数字助理交互的内容。



更新后的Cortana支持深色和浅色主题、Bing答案、助手对话、还可以打开应用程序、设置提醒、警报和计时器。该公司放弃了笑话和其他以消费者为中心的功能。


  • Microsoft为“ Hey Cortana”查询创建了一个不太麻烦的屏幕。

  • 引入了新的语音和语言模型。

  • 显着提高了性能。


重新设计的网络状态页面


Microsoft已修改“设置”中的“网络和Internet”着陆页。它提供了有关网络的更多信息，因此您可以轻松了解设备的连接性。



新的“网络”页面在“状态”页面上显示所有可用的连接接口，用户也可以在此页面上查看数据使用情况。


Windows Search的改进


Windows 10 2004对Windows搜索进行了改进，包括：


  • 改进了“应用程序和设置”搜索的拼写校正。Microsoft正在对Windows Search的内置拼写检查器的工作方式进行重大更改，因此用户可以找到所需的确切文件；

  • Windows搜索将智能地理解和纠正小错误，例如“ powerpiont”和“ exce”；

  • Windows搜索现在在“related”行下显示提示，以改善最佳匹配结果。
