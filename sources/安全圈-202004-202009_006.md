# 【安全圈】Windows XP源代码被曝泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651973226&idx=3&sn=c1b019a621c00b9e985cc6ee3e7fc2f5&chksm=f36cca2ac41b433c08056b5ff93a63a75bd7f68e2857f1a2cc041c07e3de39cb480ca7ef5365&scene=126&sessionid=1681311733#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651973226&idx=3&sn=c1b019a621c00b9e985cc6ee3e7fc2f5&chksm=f36cca2ac41b433c08056b5ff93a63a75bd7f68e2857f1a2cc041c07e3de39cb480ca7ef5365&scene=126&sessionid=1681311733#rd)

![](../Images/f84fa37c419728c61eeae312ac680d8b.png)

昨天，疑似匿名组织放出Windows XP源代码，从压缩包打包时间看，为2020年6月6日。

![](../Images/ba674e1339d614831665eb27a8e09614.png)

最开始是推特上看到有人发出这个消息，百万网盘和迅雷大军迅速出动。

![](../Images/d4bf4a82f56c67e7ad346cc6af0d8f5c.png)

  

不过最开始流传的网盘资源都是2~3g的所谓Windows XP源码，直到一个种子文件的出现才真正揭露了这次泄露事件的全貌。

![](../Images/9a3035134460886e1303bb3233191a56.png)

可以看到这次全部的泄露内容远不止Windows XP源码，不过其中重量级的确实当属XP源码。黑客声称这是他收集两个月得来的资料，包含Windows XP及Windows Server 2003的源码，也包括DOS、NT、2000等部分此前泄露过的源码。并且表示，这是第一次正式公布。

此源代码的真实性有待确认，不过有兴趣的朋友还是可以下载来深入研究Windows。
