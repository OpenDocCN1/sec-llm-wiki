# 【安全圈】美国将华为云等37家公司列入贸易管制“黑名单”：进一步限制其使用美国技术

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651971821&idx=1&sn=4cf20c973b0d7fd70aaaaba360665b81&chksm=f36cccadc41b45bb788c03bfc55c13b629f108dd0518d1482603f53d1e2cc6cd74edb67fa58f&scene=126&sessionid=1681311749#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651971821&idx=1&sn=4cf20c973b0d7fd70aaaaba360665b81&chksm=f36cccadc41b45bb788c03bfc55c13b629f108dd0518d1482603f53d1e2cc6cd74edb67fa58f&scene=126&sessionid=1681311749#rd)

![](../Images/f84fa37c419728c61eeae312ac680d8b.png)

在美国国务院官网发布的声明中，蓬佩奥称，“国务院强烈支持商务部今天扩大其外国直接产品规则，这将阻止华为通过‘替代芯片生产’与‘使用从美国获得的工具生产芯片’来规避美国法律。”![](../Images/33a3058f2f98417fca2973305e7252e0.png)“实体清单”被认为是美国出口管制的“黑名单”，被列入的实体需要获得美商务部颁发的许可证，才能购买美国技术。美国企业可以申请向这些被列入名单的公司出售产品，但美国政府会抱着拒绝的态度审视此类申请。此外，美国工业和安全局（BIS）还在实体名单上另外增加了华为旗下的38家分公司，实体名单要求受《出口管理条例》（EAR）约束的所有产品都需要申请许可证，并修改了华为实体名单上的现有四项。BIS还规定凡是涉及受商务部出口控制管辖范围约束的产品的任何交易都需要申请许可证，比如华为（或实体名单上的其他实体）充当采购方、中间方或最终用户的情况下。这些措施立即生效，阻止华为企图规避美国出口管制条例，以获取使用美国技术开发或生产的电子部件。2020年5月，BIS修改了长期以来的外国产直接产品（FDP）规则，针对华为获取属于某些美国软件和技术直接产品的半导体这一行为。今天的修正案通过对以下交易进行控制来进一步完善FDP规则：

*   1）美国软件或技术是外国产商品的基础，该外国产商品将被添加到或将用于“生产”或“开发”实体名单上任何华为实体生产、购买或订购的任何“零件”、“组件”或“设备”；
    
*   2）当实体名单上的任何华为实体是这类交易的当事方，比如“采购方”、“中间收货人”、“最终收货人”或“最终用户”。
    

该修正案进一步限制华为获取使用美国软件或技术开发或生产的外国产芯片，其程度与同类的美国芯片一样严格。美国商务部长Wilbur Ross表示：“华为及其外国分公司已加大了努力，以获得使用美国的软件和技术开发或生产的先进半导体。由于我们限制了其获取美国技术，华为及其分公司通过与第三方合作，以这种方式利用美国技术。这种多管齐下的行动表明了我们继续致力于阻止华为这么做的能力。”以下遍布21个国家或地区的38家新的华为分公司已被添加到实体名单上，BIS 称华为会以其他方式力求利用这些分公司来规避实体名单实施的限制。英文版：Huawei Cloud Computing Technology; Huawei Cloud Beijing; Huawei Cloud Dalian; Huawei Cloud Guangzhou; Huawei Cloud Guiyang; Huawei Cloud Hong Kong; Huawei Cloud Shanghai; Huawei Cloud Shenzhen; Huawei OpenLab Suzhou; Wulanchabu Huawei Cloud Computing Technology; Huawei Cloud Argentina; Huawei Cloud Brazil; Huawei Cloud Chile; Huawei OpenLab Cairo; Huawei Cloud France; Huawei OpenLab Paris; Huawei Cloud Berlin; Huawei OpenLab Munich; Huawei Technologies Dusseldorf GmbH; Huawei OpenLab Delhi; Toga Networks; Huawei Cloud Mexico; Huawei OpenLab Mexico City; Huawei Technologies Morocco; Huawei Cloud Netherlands; Huawei Cloud Peru; Huawei Cloud Russia; Huawei OpenLab Moscow; Huawei Cloud Singapore; Huawei OpenLab Singapore; Huawei Cloud South Africa; Huawei OpenLab Johannesburg; Huawei Cloud Switzerland; Huawei Cloud Thailand; Huawei OpenLab Bangkok; Huawei OpenLab Istanbul; Huawei OpenLab Dubai; and Huawei Technologies R&D UK
