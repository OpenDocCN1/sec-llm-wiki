# 【安全圈】以色列挫败朝鲜黑客的重大网络攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651971684&idx=4&sn=006c66a529ede262f22179f1738e0ec1&chksm=f36ccc24c41b45321ba0b4c6a69937427da10ea446a12046d686d51d2ff72323f87941081509&scene=126&sessionid=1681311753#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651971684&idx=4&sn=006c66a529ede262f22179f1738e0ec1&chksm=f36ccc24c41b45321ba0b4c6a69937427da10ea446a12046d686d51d2ff72323f87941081509&scene=126&sessionid=1681311753#rd)

![](../Images/f84fa37c419728c61eeae312ac680d8b.png)

以色列国防部阻止了一组名为“拉撒路集团”的网络罪犯的攻击，该组织“得到外国的支持”。

国防部周三宣布，一群自称为“ Lazarus Group”的恶意黑客对以色列国防工业进行了大规模的网络攻击。

以色列国防部安全局发表的一份声明解释说：“该小组的成员使用了各种黑客手段，包括'社会工程'和冒名顶替。”

黑客的战术之一是在名为LinkedIn的社交网络上的“虚假个人资料”，在高科技领域的专业人士中很受欢迎。”

“在调查此案之后，已经发现未遂的网络攻击是由一个名为'Lazarus'的国际网络组织进行的，该组织得到了外国的支持，”安全局解释说。

据许多网络安全专家称，拉撒路集团与朝鲜有联系。

![](../Images/18ccdb739adf1c579eccc00e930fa48d.png)

声明继续说：“攻击者冒充人事部门的经理，首席执行官和主要官员以及国际公司的代表，并与以色列主要国防工业的雇员联系，目的是展开讨论并为他们提供各种工作机会，” 。

这一系列攻击是实时侦听的，并由国防部国防安全局局长负责的技术部门阻止了它们的踪迹。

该局解释说：“攻击者试图破坏这些员工的计算机，使其网络渗透并收集敏感的安全信息。” “攻击者还试图利用几家公司的官方网站来入侵他们的系统。”

这些攻击是在造成任何损害之前捕获的，据报道“没有对任何网络造成损害或破坏”。

安全局正在调查未遂事件。除了对索尼等主要公司的安全漏洞外，拉扎鲁斯集团还被认为是几起重大盗窃案的罪魁祸首。
