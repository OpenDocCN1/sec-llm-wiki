# 【安全圈】苹果成为钓鱼攻击最受模仿的品牌

COVID-19大流行刺激了欺骗偏好的改变，以及基于电子邮件的攻击激增。

谷歌和亚马逊在2020年第二季度（第二季度）超过了苹果，因为该品牌最受攻击者欺骗，以诱使人们因网络钓鱼攻击而堕落。一项新的研究表明，排行榜的变化很可能是由于与COVID-19大流行有关的活动。

从2020年第一季度到第二季度，虽然所谓的网络钓鱼攻击数量保持稳定，但威胁行为者认为人们最可能信任的公司或他们将最关注其页面的公司的位置发生了重大变化根据Check Point Research的第二季度品牌网络钓鱼报告，可能会点击。

品牌网络钓鱼是一种攻击，攻击者通过在攻击中使用相似的域或URL来模仿已知品牌的官方网站，在某些情况下还包括与实际公司的原始网站相似或相同的模仿网页。在外观和感觉上。

威胁情报部门Check Point经理洛特·芬克尔斯滕（Lotem Finkelsteen）指出，在第二季度，攻击者还开始更多地将电子邮件用作此类攻击的媒介，这可能是受COVID-19大流行期间在家工作时依赖虚拟通信的人数启发的。给Threatpost的电子邮件。

他说：“由于我们所有人都被迫在家工作，因此收件箱是黑客的主要攻击手段。” “在打开电子邮件文档之前，我想的不是三遍，而是三遍，特别是如果据称是来自Google或Amazon的文档。”

攻击者通过电子邮件或短信发送恶意链接和欺骗性链接，然后通过Web重定向或欺诈性移动应用程序将潜在的受害者引导到欺骗页面，在该页面中他们试图窃取凭据，个人信息或拦截付款。

科技公司是攻击者利用此类攻击的第一产业，其次是银行和社交网络。在2020年第一季度，苹果公司在诱骗网络钓鱼的受害者方面是科技领域攻击者中最受欢迎的品牌。

然而，在第二季度，谷歌与亚马逊并列首位-每个品牌在Check Point遥测中使用了13％的攻击-其次是WhatsApp和Facebook（9％），微软（7％）和Outlook（3％） ，根据报告。

苹果公司跌至第7位，与Netflix，华为和PayPal分享了这一荣誉，在网络钓鱼攻击中有2％代表了这些荣誉。

第二季度末包括COVID-19危机的初期，世界上许多国家/地区都在执行在家d订单，这可能解释了攻击者偏好的变化。随着人们被限制在家中并寻求有关冠状病毒的信息，作为顶级搜索引擎的Google将会比平时更受欢迎。

自从大流行开始以来，由于许多商店在第二季度初关门或营业时间有限，使用亚马逊购买商品进行送货，这也自大流行开始以来就出现了大幅增长，也引起了对该品牌的更多兴趣。的确，研究人员看到了最近进行的两次网络钓鱼活动，目的是在亚马逊包裹交付通知的幌子下提升凭证和其他个人信息。

如前所述，第二季度还发现用于攻击的特定向量发生了变化。通常，网络是品牌网络钓鱼攻击的主要渠道，其中61％源自此。然而，研究人员说，电子邮件在第一季度排名第三，在第二季度以24％的攻击率上升到第二位，而移动在15％的攻击率下降到第三位。

根据Check Point的说法，在大流行期间，除了有如此多的人在家里工作时依赖电子邮件外，随着一些限制的缓解，企业也开始在第二季度末重新开放，这也增加了电子邮件流量作为一种攻击手段。6月发生的一次网络钓鱼活动利用了这一优势以及COVID-19后工作环境的现实状况，其目的是向返回工作场所的员工发送冠状病毒培训资源。相反，电子邮件发送了恶意链接。

在网络攻击中使用率最高的前两位是Google和Amazon，位居第二，其次是WhatsApp。毫不奇怪，Microsoft和Outlook在基于电子邮件的攻击中分别排名第一和第二，其次是Unicredit。报告称，Facebook，WhatsApp和PayPal是第二季度基于移动的网络钓鱼攻击的领导者。该公司表示，几乎有15％的网络钓鱼攻击源于移动设备。

网络钓鱼的努力没有丝毫放松的迹象。6月下旬，Check Point研究人员目睹了一个欺诈性网站，该网站试图模仿苹果云服务iCloud的登录页面。其目的是尝试相应地窃取iCloud登录凭据，网络钓鱼URL列在域account-icloud \[。\] com下。该域于6月下旬首次启动。
