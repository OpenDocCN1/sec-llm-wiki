# 【安全圈】索尼向黑客悬赏PS4漏洞，奖赏高达提供5万美元

索尼PlayStation 4具有新的芽赏金计划。日本公司已经宣布，谁管理的道德黑客发现严重的安全漏洞中的PlayStation 4和PlayStation网络就可以得到奖赏高达$ 50,000个（略低于 ₹ 38十万）。该公司已与安全平台HackerOne配对，以使该漏洞赏金计划成为可能。

![](../Images/d50a8b6f35db8f0a2406b4ed37b39ced.png)

索尼在本周的一份声明中说：“我们邀请安全研究界，游戏玩家和其他任何人来测试PlayStation 4和PlayStation Network的安全性。”在PS4中发现漏洞可以使黑客赚取50,000美元，而能够在PlayStation网络中发现漏洞的用户则可以赚取3,000美元。索尼将向第一位报告了以前未报告的漏洞的黑客悬赏。“到目前为止，我们一直在与一些研究人员私下运行我们的漏洞赏金计划，”索尼告知。索尼互动娱乐（SIE）软件工程高级总监Geoff Norton表示：“我很高兴宣布我们已经启动了公共PlayStation Bug赏金计划，因为我们产品的安全性是为我们的社区创造出色体验的基本组成部分。）。安全平台HackerOne上的黑客通过漏洞赏金成功赚取了总计1亿美元，该公司声称与去年的赏金相比增长了85.6％。Covid-19还增加了总赏金17.5％。到目前为止，全球社区中的道德黑客已成功地在2,000个赏金计划中揭露了1,700,000个漏洞。公布赏金计划有助于改变组织对安全问题的解决方案。据索尼称，奖励“漏洞的严重程度以及报告的质量有所不同”，仅对未公开的迹象有效。此外，公司未提及的硬件不参与该程序，其中包括PlayStation Vita，PlayStation 3，PlayStation 2，PSP和PlayStation 1。在HackerOne计划的官方网站上，根据“声誉”对参与者进行排名。前五名保证在主页上排名，而其他则在专用部分列出。尽管看起来很新，但索尼的Bug Bounty已经活跃了大约6个月。但是，到目前为止，只有一部分研究人员和专业人士参加。这次，该公司向整个社区敞开了大门。根据以往的索尼发生漏洞的损失来看，无论您在何处玩游戏，确保您的信息在线安全始终很重要，因为用户发现自己的信息已被黑客入侵并不罕见。如果您购买了大量的数字游戏并将信用卡信息保存到PlayStation Network帐户中，则这一点尤其重要 ，因为这可能意味着您的卡，电子邮件地址和其他个人信息可能最终落入一个陌生人的手中，并成为在发生数据泄露或黑客入侵时对您不利。前些年，任天堂就成为此类攻击的受害者，潜在的16,000多个帐户受到了攻击。对于那些关心自己如何在其他平台（例如）上进行帐户结算的人，
