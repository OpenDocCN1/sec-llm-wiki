# 【安全圈】微软向已终止支持的Win 7系统推送补丁，只为给用户安装新Edge

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651969408&idx=3&sn=34394d1f8b871c8a945b8e66e7fa0905&chksm=f36cfbc0c41b72d604d0e3f72c7bb7af93c1868074952cfb5408dfd6f2156bbf23808f4f7466&scene=126&sessionid=1681311773#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651969408&idx=3&sn=34394d1f8b871c8a945b8e66e7fa0905&chksm=f36cfbc0c41b72d604d0e3f72c7bb7af93c1868074952cfb5408dfd6f2156bbf23808f4f7466&scene=126&sessionid=1681311773#rd)

![](../Images/f84fa37c419728c61eeae312ac680d8b.png)

据MSPoweruser报道，微软周二开始向Windows 10用户推出基于Chromium的新Edge，同时微软也借此机会将新浏览器面向不受支持的Windows 7操作系统推送。

![](../Images/00059b44a704c86554136ba81a667fee.png)

WindowsArea报告说，KB4567409是Microsoft数月来首次向不受支持的Windows 7推送的更新。IT之家了解到，KB4567409也称为“ Windows 7 SP1和Windows 8.1的新Microsoft Edge更新：2020年6月17日”，适用于Windows 7上的非企业用户，并包括以下质量改进：• 新的Microsoft Edge将固定在任务栏上，并向桌面添加快捷方式。• 新的Microsoft Edge将不会取代Internet Explorer。• 此更新不会更改默认浏览器有趣的是，尽管Win 7操作系统自今年1月以来未见任何更新，不过用户在安装更新补丁后，浏览器将自动更新。WindowsArea指出，与Windows 10不同，如果Windows 7用户不喜欢新的基于Chromium的Edge可以忽略此更新。
