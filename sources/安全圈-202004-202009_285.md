# 【安全圈】Adobe回应终止Flash：继续支持大陆地区发行维护

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651969357&idx=2&sn=bfcd8e0ab4253a57eb3e603295186b0f&chksm=f36cfb0dc41b721b47a21d0b7b042e96721629cefcd8e7859c184997ed524e41179b414af6d1&scene=126&sessionid=1681311773#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651969357&idx=2&sn=bfcd8e0ab4253a57eb3e603295186b0f&chksm=f36cfb0dc41b721b47a21d0b7b042e96721629cefcd8e7859c184997ed524e41179b414af6d1&scene=126&sessionid=1681311773#rd)

![](../Images/f84fa37c419728c61eeae312ac680d8b.png)

  

虽然Flash退出历史舞台已经是不争的事实，但Adobe还是明确了其寿终正寝的日期。目前，Adobe公司宣布：2020年12月31日，今年的最后一天，将是其旗下产品Flash Player生命终结之日，也就是 End-Of-Life Date。同时，Adobe将会删除所有的Flash Player下载页面，而基于Flash的内容也将会在 Adobe Flash Player中被阻止运行。那今后Flash我们还能用吗？尤其是Flash存量巨大中国市场，影响又有几何？

![](../Images/20298611021aaf9a2480fa2333b0f8f6.png)

  
事实上，早在2019年10月，Adobe官方就曾明确表示，为了支持中国大陆地区市场特有的发行渠道、用户习惯，以及为数众多的企业、开发者和游戏社区，Adobe将在2020年后继续与重庆重橙网络科技有限公司 重橙网络合作并支持其在中国大陆地区对Flash Player的独家发行与维护。当时，Adobe大中华区高级董事总经理黄耀辉表示，Adobe非常高兴能继续在中国大陆地区与重橙网络进行独家合作。本次合作也进一步体现了Adobe对于中国市场的承诺，并致力于确保中国客户能够继续使用全新的、安全的Adobe Flash Player。

![](../Images/75ac6a5299f4f230e091cfaf4767f96a.png)

  
昨日，Adobe官微重申，如此前宣布，重橙网络是Adobe Flash Player在中国大陆地区的官方独家发行合作伙伴。为支持中国大陆地区市场特有的发行渠道、用户习惯和企业、开发者和游戏社区，Adobe将在2020年后继续与重橙网络合作并支持其在中国大陆地区对Flash Player的独家发行与维护。该合作仅限中国大陆地区。目前，中国大陆地区依然可以通过https://www.flash.cn/下载Flash Player。官网显示，最近的更新时间为2020年6月9日。

![](../Images/b833ac890fc89c8a9f9ae36d6d0b3d7b.png)

  
系统要求为：Windows：32 位和 64 位（除非另外说明）：Windows XP SP3（32 位）、Windows Vista（32 位）、Windows 7、Windows 8.1. 和 Windows 10最新版Microsoft Internet Explorer、Microsoft Edge、Mozilla Firefox、Google Chrome 和 OperaMac OS：Mac OS X 10.10 版或更高版本最新版本的 Safari、Mozilla Firefox、Google Chrome 和 OperaLinux：适用于 NPAPI 和 PPAPI 的 TAR.GZ、RPM 包最新版本的 Firefox 或 Google Chrome
