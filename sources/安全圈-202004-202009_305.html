【安全圈】微软Win 10更新又双叒叕出Bug

据Windowslatest报道，微软发布的2020年6月Windows 10累积更新已导致某些用户出现打印问题和其他错误，有用户报告称他们在更新完系统后启动诸如Microsoft Office之类的应用程序时会收到“ Windows找不到[* .exe]”的提示。

IT之家了解到，有用户已在Microsoft论坛上报告了此错误，该错误据称是由Windows 10 KB4560960（版本1909）和Windows 10 KB4557957（版本2004）累积更新引起的。值得注意的是，Avast最近发布的一个更新中包含一个类似的错误，该错误会阻止应用程序运行并显示以下错误消息：
“Windows无法找到“ C：\ Program Files（x86）\ Microsoft Office \ root \ Office16 \ EXCEL.EXE”。请确保您键入正确的名称，然后再试一次。”
微软方面确认这是Windows 10更新的“已知问题”，用户可以通过调整注册表项来修复它。
解决“请确保您正确键入名称，然后重试”问题步骤如下：
打开Windows注册表（regedit）。
在注册表编辑器中，导航到以下路径：
Computer\HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution文件夹
重命名不起作用的应用程序的文件夹。例如，将“ Chrome.exe”重命名为“ BackupChrome.exe”。
重新启动计算机。
根据报告显示，Windows 10累积更新和Avast更新都破坏了部分的应用程序。用户也可以选择直接卸载Windows 10累积更新KB4560960，而Avast用户需要将该程序更新到最新版本以解决相关问题。
