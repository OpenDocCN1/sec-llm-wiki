# 【安全圈】蓝巨人IBM Cloud出现全球性宕机，目前已经修复

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651969052&idx=2&sn=454fb910e9902d00b4c933ec4714e17e&chksm=f36cfa5cc41b734a87cd8ab9aecf3d2553d2940af4c2ea49ea928306822d60507ea7c806df4c&scene=126&sessionid=1681311777#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651969052&idx=2&sn=454fb910e9902d00b4c933ec4714e17e&chksm=f36cfa5cc41b734a87cd8ab9aecf3d2553d2940af4c2ea49ea928306822d60507ea7c806df4c&scene=126&sessionid=1681311777#rd)

![](../Images/f84fa37c419728c61eeae312ac680d8b.png)

IBM Cloud 今天遭遇了重大宕机故障，平台上托管的多项服务也因此中断，其中就包括知名科技新闻聚合网站 Techmeme。本次宕机事件从太平洋时间6月9日下午2点30分左右开始，并快速蔓延至全球。

![](../Images/5fe2792fbf32d0c4006e696a07c7b3c2.png)

![](../Images/c753922541297d83ba4ef05c809a5515.png)

![](../Images/96519ef3fe58375e379266a5eafbbdcd.png)

目前 IBM 自家的状态页面已经无法加载，并返回了一个内部服务器错误，目前尚不清楚本次宕机事件的受影响范围，也不清楚是什么原因所导致的。

![](../Images/1771a2814223f764b6597026e5db6e21.png)

在宕机事件发生之后，IBM Cloud 官方推特并没有更新推文，不过外媒发现了一个托管在第三方服务器上的IBM Aspera 的状态页面，这似乎证实了这很可能是一个全球性的网络问题。

更新：IBM Cloud 官方推特在1小时前发布推文，表示本次宕机事件已经得到全面修复。
