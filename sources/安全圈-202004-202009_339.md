# 【安全圈】苹果奖励发现ID验证漏洞者十万美金，但还有很多尚未解决

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651968494&idx=2&sn=6b8a2580726078de724314992c4477b0&chksm=f36cffaec41b76b859e2ef7c67d9e58264f1fe7199991842d466908de82d2a958774dfab174b&scene=126&sessionid=1681311781#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651968494&idx=2&sn=6b8a2580726078de724314992c4477b0&chksm=f36cffaec41b76b859e2ef7c67d9e58264f1fe7199991842d466908de82d2a958774dfab174b&scene=126&sessionid=1681311781#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)

“赏金猎人”计划公布了最新消息。即一位印度的漏洞研究人员发现了影响使用Apple登录系统中的一项重大漏洞，在向苹果安全团队作出报告后，官方紧急修复了该漏洞并奖励了这位研究人员十万美金。

![](../Images/5242ba0fdafdbd202fd1ca8d02a31865.png)

根据了解，这个漏洞能够帮助远在千里外的攻击者绕过用户的身份验证，接管用户使用的Apple登录选项，并注册第三方服务与应用程序上的账户，可以说是非常危险了。  
去年，苹果公司启动了苹果ID登录第三方的保护隐私机制，这一机制可以让用户使用苹果ID注册一些第三方的应用程序，并且没有必要再透露电子邮件地址，**简单的来说就是苹果ID注册第三方应用化繁为简了。 **

![](../Images/cd37f6136bae8ed3c6f0c430c6b10b24.png)

研究人员称，他发现这个漏洞存在于Apple启动过程与苹果服务器的认证过程中，对于不知情的用户，**在服务器上通过使用Apple登录进行身份验证时，会生成一个JW令牌，这个令牌里就包含着确实用户登录的机密信息，**而这正是此次漏洞的罪魁祸首。**![](../Images/0a318c2879f09213fe154a4e03989c82.png)**研究人员表示，他发现了可以向这一有着机密信息的令牌请求来自Apple的任何电子邮件ID，且实用公共的钥匙验证取得令牌签名后就能直接登录。这就代表着攻击者可以获取任何邮箱ID访问我们的账户。**这一漏洞严重到什么地步呢？简单地来说就是它有很大的几率导致我们的账户直接被骇客接管。****![](../Images/41175d8a4eafb840a095ea6efb7186d3.png)**文章来源：bilibili**猜你喜欢  ****[**【安全圈】8种流行的安全工具，你还有补充吗？**](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651968394&idx=1&sn=a057a4bd1b4ee3617fdc691a4a251ae9&chksm=f36cffcac41b76dce5ce87fe03bb1bad7da553eed5851bd79cb4bc847bbf894c1a049ca0dc5c&scene=21#wechat_redirect)**[**【安全圈】发现 26 个 USB 漏洞：Linux 18个 Windows 4 个**](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651968327&idx=1&sn=c6328609dcb8775e3b65fce40521cc7c&chksm=f36cff07c41b7611282d9ca2652dc43e994c8fbdbd8fa1d97d35fc6c1dfa8ef98f63e75bd671&scene=21#wechat_redirect)**[【安全圈】孟晚舟命运28日凌晨2时揭晓引渡美国案将有关键裁决](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651968299&idx=1&sn=028f2412bbbcd2ae1392792cc4275e3d&chksm=f36cff6bc41b767d3e430e7c465023e67cb7fe3e876a18d1e0f9a5b9ae5b21097d9d361cd91f&scene=21#wechat_redirect)**
