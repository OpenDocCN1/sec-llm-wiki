# 【安全圈】孟晚舟命运28日凌晨2时揭晓引渡美国案将有关键裁决

加拿大2018年底应美国要求逮捕华为财务长孟晚舟，加拿大卑诗省法院预定当地27日11时（中国时间28日凌晨2时）宣布孟晚舟能否引渡美国的判决。

美国指控孟晚舟涉嫌银行和电汇诈欺，指她2013年在香港向汇丰银行简报时，隐瞒华为和子公司星通（Skycom）的关系，误导汇丰为华为与伊朗的非法交易提供服务，导致汇丰面临违反美方对伊朗制裁措施的风险。

![](../Images/3b2d863d7fcabadc82fd7eb083f78c2a.png)

▲ 裁决前数天，孟晚舟引渡案明裁决前孟与团队法院前举胜利手势合照。（加拿大CBC图片）**孟晚舟引渡案周三迎关键裁决杜鲁多：无需就结果道歉或解释**

杜鲁多周二（26日）接受访问时称，加拿大拥有真正独立的司法系统的好处是，不需为其做出的决定道歉或解释，强调对司法系统的独立性有信心，会继续遵守并捍卫。

杜鲁多又透露，加拿大人一直与中美就当前问题进行对话。他说，继续就孟晚舟案、两名被中国拘留的加拿大公民的问题上，与美国和中国进行外交接触。

**如果认定**孟晚舟**在两国都违法，才符合引渡美国受审的条件**

加拿大法官将裁决孟晚舟的行为是否在美国和加拿大都构成犯罪，如果认定在两国都违法，孟晚舟才符合引渡美国受审的条件；相反，孟晚舟涉及的案情如非美加都属犯法，她便要获释。

即使法院在28日凌晨的判决中，指孟晚舟应引渡到美国，孟仍可上诉，预料官司会一路打到最高法院。若孟晚舟最后败诉，是否真的引渡要由加拿大司法部长决定。

**就算判处孟败诉她仍可上诉**

孟晚舟的律师辩称，美国对伊朗实施经济制裁，但加拿大并未对伊朗实施经济制裁，因此，孟晚舟未触犯加拿大法律。

正如前述，如果法官认定孟晚舟未触犯加拿大法律，可驳回本案，孟晚舟可恢复自由。

孟晚舟2018年12月被捕后以加币1000万元交保，软禁在温哥华的豪宅。

加拿大媒体25日报道，孟晚舟日前在卑诗省最高法院门外，笑容满面竖起大拇指与华为副总裁等多名亲友合照，时机耐人寻味。
