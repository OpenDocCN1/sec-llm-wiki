# 【安全圈】多种DNS解析程序被发现漏洞 允许攻击者发动拒绝服务攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651968086&idx=2&sn=0b55cb0546da28f8c8bc42828179e53a&chksm=f36cfe16c41b7700663c73cca074c9198488a612fa3e504fe9727a0be9fab2b4657a3b7bcaff&scene=126&sessionid=1681311785#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651968086&idx=2&sn=0b55cb0546da28f8c8bc42828179e53a&chksm=f36cfe16c41b7700663c73cca074c9198488a612fa3e504fe9727a0be9fab2b4657a3b7bcaff&scene=126&sessionid=1681311785#rd)

**![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)**

DNS 解析程序不能向“名字”发送域名查询，因此解析器首先需要获得权威 DNS 服务器的 IPv4 或 IPv6 地址，之后才能继续查询域名。NXNSAttack 就是基于这一原理，攻击者发送的委托包含了假的权威服务器名字，指向受害者的 DNS 服务器，迫使解析程序对受害者的 DNS 服务器生成查询。一次查询会被放大数十次乃至数百次，对受害者服务器发动了拒绝服务攻击。

  

![](../Images/f73a01df59213a013d6e76e9395a6162.png)

众多 DNS 软件都受到影响，其中包括 ISC BIND (CVE-2020-8616)、NLnet labs Unbound (CVE-2020-12662)、PowerDNS (CVE-2020-10995)、 CZ.NIC Knot Resolver (CVE-2020-12667)、Cloudflare、Google、Amazon、Microsoft、Oracle(DYN)、Verisign、IBM Quad9 和 ICANN。
