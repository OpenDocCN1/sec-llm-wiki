PowerShell


不久前 PowerShell 被放入 Kali Linux 的网络存储库中，这意味着，如果要用 Powershell，必须通过以下方式一次性安装该软件包：


kali@kali:~$ sudo apt install -y powershell

不过现在 PowerShell 被放入了主要元软件包之一：kali-linux-large。这意味着，如果选择在系统设置过程中安装此元软件包，或者直接启动并运行这一安装程序（sudo apt install -y kali-linux-large），那就可以直接使用 PowerShell 了（用pwsh）。


软件包


此片包含可能的最新软件包，主要有：GNOME 3.36、Joplin、Nextnet、Python 3.8 与 SpiderFoot，其中由于某些工具的需要，暂时还重新添加了 python2-pip，不过这只是临时措施，官方还是建议工具开发者移植到 Python3。
