# 你们曾经下过哪些影片，都被这个站记下了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651967169&idx=1&sn=276fbb6d04094c6def011dbf3d7da515&chksm=f36ce281c41b6b979515837e705dfa46612ee9f058c43ee20c436b8165aced1f176ce7af0e6b&scene=126&sessionid=1681311793#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651967169&idx=1&sn=276fbb6d04094c6def011dbf3d7da515&chksm=f36ce281c41b6b979515837e705dfa46612ee9f058c43ee20c436b8165aced1f176ce7af0e6b&scene=126&sessionid=1681311793#rd)

![](../Images/8d9fcadf195cd509555aa3264a196e64.png)  
BT 下载估计每个小伙伴都在用，长期关心的问题无非就是怎么样让速度快一些，再快一些。  
但很少会有人去关心，使用 BT 下载的内容会不会被别人发现。  
你每天通过 BT 都下载了什么东西，可能你自己都不记得，但是有一个网站却把这些记录地清清楚楚。  
https://iknowwhatyoudownload.com/  
没错，中文名字就是： **我知道你下载了什么 。**  
老司机们，是不是有点害怕了，来，我给你介绍完这网站，你会更害怕。  
  
**通过 IP 地址查询下载历史**  
你只要打开这个网站，首页就会默认显示出你的 IP 地址，以及通过这个 IP 地址你近期下载过那些东西。  
同时也列出了你附近的一批 IP 地址。  
  
![](../Images/312e89eacd73f0ffbf66f9fdf8e62203.png)  
嗯，我有一位朋友，这就是他的下载记录。  
能看到自己的还不算什么，它还能看到你邻居们都下载了什么，这就刺激了。  
随便点开附近的一个 IP 地址，看看他的下载记录有啥。  
在第一页发现它看的有动画也有电影，还有阅兵式，嗯，挺好的。  
  
![](../Images/e78429703ba1ac81819031efeb019202.png)  
不过当我往下翻，果然发现了老司机出没的痕迹。  
具体名字，我就不方便介绍了，大部分都得打上马赛克。  
![](../Images/b1abd75e67cdc8d39a396ee8ce7a249a.png)  
可以看到，显示的这些下载数据非常详细，包括开始时间、结束时间、内容种类、名称、文件大小。  
这还不算什么，还有一位邻居的下载列表才是叹为观止：  
![](../Images/e185ea45820c558255acd686caa6856c.png)  
这位老司机大多数都是在下载电影进行极限挑战，然后晚上好挑战极限。![](../Images/89b6e085ab85253dcf7a7a18fdaf5a17.png)  
相信不少小伙伴这时就有想法了，既然数据这么详细，是不是也提供种子下载呢？  
当然并不是，这里只是记录你下载过那些种子，以及种子的具体信息，至于种子从哪里下载，可不归它管。  
![](../Images/ba9840dad5fa99005e872a9754c77d0e.png)  
通过这个，你就能发现你附近的邻居有多少是老司机，我翻看这个网站的时候忍不住会有一种奇妙的感觉，感觉自己不是一个人在战斗，从窗口往外看，说不定那家亮着灯的书房里就有你的战友。  
这还不是最骚的操作，这个网站还提供了一个特别腹黑的功能，可以看到任意一个人的下载记录。  
比如你想知道朋友的 BT 下载历史，只要知道他电脑的 IP 地址，然后在网站上方搜索框输入，就可以出现他的下载历史了。  
看到这里，老司机们是不是有点瑟瑟发抖了。你们一定会说：我死都不会告诉别人的 IP 地址。  
没关系，不需要知道你的 IP 地址照样也能办到。  
**跟踪下载**  
点击跟踪下载，在输入框随意输入一个网址，然后点击转变。  
![](../Images/666b03318fbc11e2d4e696c57456fa49.png)  
这时原本输入的网址会变成另外一个看着“人畜无害”的网址，把这个新网址发给你的朋友并且让他点击。  
![](../Images/91a04a622a9b5c5f708b17602d2189c6.png)  
当他打开网址之后，他看到的还是原本正常的网页。  
但是在你的页面下方就会出现朋友最近下载过的电影。  
嗯，还好，我的这位朋友比较清心寡欲，下载的并不是小姐姐，而是电影《小妇人》。  
![](../Images/cea914f79a66711d690420e878709b34.png)  
这样即使不知道你朋友的电脑 IP 地址也能知道他最近的下载历史。  
所以说，那些来历不明的链接真的不要随便点开，不然连底裤都被扒的一干二净。  
我知道你可能会有点犯怵，这个网站是怎么知道自己的 BT 种子下载情况的呢？有没有办法不让别人发现呢？  
很遗憾，这个真没有，因为这是由 BT 下载的原理决定的。  
  
大家都知道 BT 下载是点对点的下载方式，你要下载一个文件，就必须通过 tracker 服务器找到有多少人正在和你下载同一个文件，所以 tracker 服务器必须知道下载这个文件的人各自的 IP 地址，才能够让你们建立起下载连接。  
有心的同学就会发现，其实在使用 BT 客户端下载的时候，就能发现这些 IP 地址：  
![](../Images/690ca61c3373599a68311ebc68b5d092.png)  
所以这些信息只要你用 BT 下载，它就不可能不被记录。  
而这个网站也自曝了收集的方式，他们就是通过解析 torrent 网站和侦听 DHT（种子网站的分布式哈希表）网络两种方式来收集的。  
所以不必担心会有什么隐私泄露之类的，网站只是把这些半公开的信息汇集出来而已，也仅限于你使用 BT 的下载记录。  
不过不得不说，这个网站的开发者多多少少还是有那么一些恶趣味的，不然也不会有伪装网址跟踪下载记录这种骚操作。  
**下载历史统计**  
既然无法清除个人下载记录，索性来看看世界人民都在下载什么东西吧。  
  
在这里不仅可以通过 IP 地址查到国内网民的下载历史，可以看到世界各国人民的，而且也已经做好了统计，妥妥的老司机大数据啊。  
**中国每日统计下载历史统计**  
先看下咱们中国人都喜欢下载啥，这里你可以选择任意日期查看。  
  
比如说 4 月 21 日这一天，中国每百万人口里有 621 人进行了 BT 下载，大概有 50.3% 的网络用户，每天有 0.12％ 的用户在使用 BT 下载。  
![](../Images/6f2c563c8497c62d2d64510494840272.png)  
  
再来看看具体都下载了什么，在这个下载榜单中，提供了总榜、电影、XXX（不可描述的资源）以及软件、游戏、音乐等分类榜单。  
注意，饼图蓝色部分就是 XXX 资源，69% 的流量都在下载不可描述的资源，老司机们辛苦了。  
当然点击进去还会有相应的详细信息，但是依旧不提供种子下载的。  
除了热门 XXX 不适合展示外，这里统计了中国人下载最多的 12 部电影以及 12 部剧集。  
![](../Images/b0656144834f07c1d4982e879f6ce888.png)  
很意外，夺得榜首的这部《365 天》，在豆瓣上的中文译名叫做《黑帮大佬和我的 365 日》这部片子居然没听过，回头找来看看。  
剧集自然是以美剧为主了，国产剧一般都在线看了。  
![](../Images/74ca05f66957b7e312e115c2643887f6.png)  
  
其实从某种意义上来说，这个榜单才是最有说服力的，比起什么猫眼、豆瓣的榜单来说，这可是没有添加任何水分的真实榜单，什么才是最受欢迎的电影，到这里看看就知道了。
