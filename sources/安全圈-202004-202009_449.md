# Windows Terminal Preview v0.11 发布：新的字体和主题

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651967102&idx=5&sn=19fdcc7670cd4484d898de1889b0bc07&chksm=f36ce23ec41b6b28b216bb5eb1d7ed051e27f77b3d1c15c8bc895d161d690cf4b064b761888e&scene=126&sessionid=1681311793#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651967102&idx=5&sn=19fdcc7670cd4484d898de1889b0bc07&chksm=f36ce23ec41b6b28b216bb5eb1d7ed051e27f77b3d1c15c8bc895d161d690cf4b064b761888e&scene=126&sessionid=1681311793#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)  
微软发布了 Windows Terminal Preview 0.11 版本，这是 1.0 版本发行之前的最后一个主要更新，从现在开始之间的版本将是该版本的修订版。新版还有一些其他更新内容和 bug 修复，详情见发布公告：  
https://devblogs.microsoft.com/commandline/Windows\-terminal-preview-v0-11-release/  
![](../Images/cd77c79fca3aae853284beaae9051c13.png)  
**本土化 **  
这是第一个支持非英语 UI 语言的 Windows Terminal 版本，功能仍在完善中。  
**设置更新 **新版本对设置进行了一些更改，建议用户将设置文件移出文件夹，并让终端自动生成一个新文件。然后便可以将设置复制回来。  
**Settings.json**  
profiles.json 文件已重命名为 settings.json。如果已经安装了终端，文件名会自动更新。  
**Cascadia Code **  
Cascadia Code 已成为所有配置文件的默认字体。如果要更改字体，可以将 fontFace 属性添加到配置文件。  
**Tango 配色方案**  
新版本带来了两个新的主题：Tango Dark 和 Tango Light。
