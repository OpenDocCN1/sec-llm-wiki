# 网友设计的“Windows 20”：这才是该有的样子

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651967049&idx=2&sn=a408486b8fa9374948b31c47f3ab21e7&chksm=f36ce209c41b6b1f563fe874e5625ea5964f3b93b7471a66668d00f890266084f054db8fe6a4&scene=126&sessionid=1681311793#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651967049&idx=2&sn=a408486b8fa9374948b31c47f3ab21e7&chksm=f36ce209c41b6b1f563fe874e5625ea5964f3b93b7471a66668d00f890266084f054db8fe6a4&scene=126&sessionid=1681311793#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)  
Windows 10被吐槽的地方很多，无论UI界面设计还是功能特性，都有很多完全可以做得更好的地方，也不断有网友给微软献计献策，打造自己心目中的概念设计。  
但是，Avdan的概念设计达到了空前的高度(点击看视频)，**他对Windows 10的各个角落都进行了重塑。**  
**包括任务栏、开始菜单、资源管理器、设置、平板模式、动作中心、暗夜模式、搜索、动态壁纸等等，并将其命名为“Windows 20”。**  

![](../Images/b10dd5aa87014ab428ec248758ddd42f.png)

![](../Images/eeb5089f630bbe068834c3fa8ff6edb3.png)

![](../Images/d83708c29d0e188c446d9a09f141adb5.png)

![](../Images/40ce33e93809e23bd4dbd4ad55aefc74.png)

  
Windows 10的任务栏也支持很多定制，但是Advan加入了更多、更灵活的选项，尤其是**任务栏图标可以选择居中、居左等不同位置，图标支持悬停变色，甚至开始菜单图标都可以隐藏，还有深色、浅色等不同显示模式。**  

![](../Images/103abc173f6de6cd1c31908f10cb26b1.png)

![](../Images/1b9fa55f7c6bd8c5e1f37c9d493fb5f0.png)

  
开始菜单中，主要调整了**动态磁贴，光标悬停会弹出上下文菜单**，类似手机上长按图标的效果，不同程序的选项也不一样，比如PowerPoint会弹出新建、打开、最近、分享，Outlook则会弹出新邮件、新事件、查看日历。  

![](../Images/ec72f248bbeb9ab638903419246755d7.png)

![](../Images/ec654d3c95c29e349ef369919c1129a5.png)

  
**资源管理器整个界面都做了翻新，布局更加合理、养眼，而且加入了呼唤多少年的多标签浏览模式。**  

![](../Images/c5c2ffc0a66b384f34d8b0ec35201d3d.png)

![](../Images/b047b1ab807aaf1459147737d40ac3af.png)

![](../Images/d516cd2d5fde532aaa7e5686552192af.png)

  
设置程序，一方面加入了账户、OneDrive云盘、收录机、Windows更新等信息状态，**另一方面彻底摒弃了传统的控制面板，将所有选项都集中在一起**，非常方便。  

![](../Images/2601b1ba447ee77fde1a4aab054f6d1e.png)

  
平板模式下加入了类似iOS的底部提示栏，上滑即可呼出程序图标。  

![](../Images/d4b7125bb9f51a67ec49dff2d5f14224.png)

![](../Images/59117f9b9ca2e04b2f51e8e9bba5cae7.png)

![](../Images/9b64f42b9635c0f9d6acad297768fe9e.png)

![](../Images/b200c7e1cbf06d7f92db5c8fea046396.png)

  
动作中心重新梳理了通知和快速设定，不但调节亮度、音量，开关Wi-Fi、蓝牙等更加方便，**还特别加入了色彩模式**，可选明亮、暗夜、更暗三种模式，支持按时间自动切换，状态栏、开始菜单等的显示也会自动随之变化。  

![](../Images/adcb38a0cd5a6a49e40dfad06e19f318.png)

  
搜索是Windows一直做得很差劲的地方，重新设计后可以按照不同类别搜索，结果显示也更加合理。  

![](../Images/26c7228b1e2f8491e6165b5cde7aab3b.png)

![](../Images/10599adef43a3a5201258e9be958550d.png)

![](../Images/d9657f8d1f0481dabbda8857cbf7249f.png)

  
**动态壁纸也有了**，会根据时间切换不同的壁纸，比如白天的蓝天、夜晚的星空等。Windows 10如果变成这样，谁会不爱呢？  

![](../Images/c68007d6c56a181f01164247a88b82d7.png)
