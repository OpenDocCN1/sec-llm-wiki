# Ubuntu 20.04 LTS 已上架 Windows 10 应用商店

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651967034&idx=3&sn=cb3a93bd7d090deb35d8a5e8e9d6dd0c&chksm=f36ce27ac41b6b6cf4566b697e2ac9eadc1847fe0ee2bd77f02cd341504ec8a8aa459f3066c5&scene=126&sessionid=1681311793#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651967034&idx=3&sn=cb3a93bd7d090deb35d8a5e8e9d6dd0c&chksm=f36ce27ac41b6b6cf4566b697e2ac9eadc1847fe0ee2bd77f02cd341504ec8a8aa459f3066c5&scene=126&sessionid=1681311793#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)  
Ubuntu 20.04 LTS 正式版仍未发布，不过，在 Windows 10 应用商店中已经可以下载 Ubuntu 20.04 LTS on Windows。根据应用商店中的页面介绍，Windows 上的 Ubuntu 20.04 允许使用 Ubuntu Terminal 并运行 Ubuntu 命令行实用程序，包括 bash、ssh、git、apt 等。  
它要求 Windows 10 版本 16215.0 或更高版本，支持 ARM64 和 x64 体系结构。要注意的是，该程序在 Windows 10 S 上不受支持。  
![](../Images/87b8c0a4266343abf8cf66f11cddcc04.png)  
启用 WSL 后，在命令行提示符（cmd.exe）上输入 “ubuntu2004”，或在“开始”菜单中单击 Ubuntu 磁贴即可启用 Windows 上的 Ubuntu 20.04。也可以直接用 PowerShell 提示符执行以上步骤：  

```
Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

如果已安装 Ubuntu，在 Ubuntu 终端中运行 do-release-upgrade 便可升级到新版本。  

![](../Images/750bee8992ab1d35a56252bab418b4d1.png)

  
上周开源中国曾报道，WSL 1 在运行 Ubuntu 20.04 LTS 时将会出现问题，建议 WSL 1 用户暂时不要升级到 Ubuntu 20.04，或是换到 WSL 2 来运行。  
Ubuntu 20.04 LTS 于本月初发布了最终 Beta 版本，稳定版预计会在 4 月 23 日释出。
