# Intel官方严正声明：有人篡改处理器骗保

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651967034&idx=4&sn=6993e28cbe62b3096a979a5973189e18&chksm=f36ce27ac41b6b6cd39de5b9a7d3664d90565710aa36b6435189aa92864be17d67c5648ef0db&scene=126&sessionid=1681311793#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651967034&idx=4&sn=6993e28cbe62b3096a979a5973189e18&chksm=f36ce27ac41b6b6cd39de5b9a7d3664d90565710aa36b6435189aa92864be17d67c5648ef0db&scene=126&sessionid=1681311793#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)  
4月17日，Intel客户支持官微发布严正声明称，**近期以来，有部分商家或个人将经过篡改的英特尔台式机处理器提交给我公司，并申请保修、更换服务。**对此，英特尔（中国）有限公司（以下简称“我公司”）声明如下：  
我公司仅对处在保修期之内且有英特尔原始标识的处理器提供售后服务。经我公司鉴别、确认，上述处理器的原始频率标识和其他原始标识均被移除，且该标识被替换为虚假商标和/或错误的产品信息。故上述处理器应被视为经过篡改的处理器，不符合我公司的有限质保条款与政策。

  

我公司重申，经过故意篡改的处理器，无法享受法律以及我公司的质保条款与政策规定的维修、更换或退款的售后服务。敬请广大消费者通过英特尔授权的合法分销商购买英特尔盒装正品，或致电英特尔服务热线（座机：800 820 1100，手机：400 920 2200）以获取分销商列表。对于实施制假、售假行为，或者以明知或故意的方式，使用被篡改的英特尔处理器（如去除核心Die组件的处理器）要求我公司提供保修、更换等售后服务，以骗取非法利益的单位及个人，我公司保留追究一切法律责任的权利，并将在必要时通过向公安机关报案等合法手段，保护我公司的合法权益。      ![](../Images/de859a25728924bb179cb7ced4bfee42.png)（图中处理器，为我公司收到的经过篡改的英特尔台式机处理器）
