# “这辈子不可能打工男子”出狱了 司法所将对其重点关注

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651967021&idx=2&sn=119587fce6b151c9488cdd1c1af567a4&chksm=f36ce26dc41b6b7b81c84d48efdcd8e6e2814195a4842dddaa1a513de9e1c04b9724a7e9d196&scene=126&sessionid=1681311793#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651967021&idx=2&sn=119587fce6b151c9488cdd1c1af567a4&chksm=f36ce26dc41b6b7b81c84d48efdcd8e6e2814195a4842dddaa1a513de9e1c04b9724a7e9d196&scene=126&sessionid=1681311793#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)  
“打工是不可能打工的，这辈子不可能打工的，就只能靠偷维持生活这样子，看守所里面的老哥各个都是人才，感觉回到这里就像回家了一样...”相信各位长期网上冲浪的伙伴们对这段话一定不陌生，早年，一位周姓男子在多次偷电动车的电瓶之后被抓，在看守所接受采访的时候说出了这一段著名的话，并一跃成为了特殊的“网红”。  

![](../Images/d7c029783e2fbfe573999f6e152beceb.png)

![](../Images/4060d0ac3e2495d275d104a2cb7732f5.png)

  
有才的网友们为其创作了各种大量的衍生段子，将其改编成了各种版本，称之为“窃·格瓦拉”，甚至还有网友为其创作了一首单曲，他的著名台词，配上著名网络音乐唱作人约瑟翰·庞麦郎的《我的滑板鞋》，别说，还真的挺好听的。  

![](../Images/6d7c6a5af8b2ebfedfce78473f241894.png)

  
除了各种段子之外，他也成了B站鬼畜区的常见素材，并在表情包界经久不衰。  

![](../Images/dfaa4e9c96bb39a8742407215d7512d4.png)

  
而在最近，这位几年前的“网红”迎来了他的第四次出狱，2012年，他第三次因为偷窃罪进看守所，在看守所受采访时留下这段名言，出狱后他继续犯事，2015年第四次进监狱被判处了4年6个月有期徒刑，从2015年10月19日起到2020年4月18日止，也就是说今天就是“窃·格瓦拉”刑满释放的日子。  

![](../Images/fe0c82b4694522fe6fea68a26c000a4f.png)

  
据知情人介绍，他和家里人早已断了联系，柳州市司法所也表示在他出狱后也会对他进行重点关注，在法律框架之下对其进行法律教育，防止其再次犯罪，同时柳州监狱也表示近期刑满释放人员将在监内提前进行14天隔离。  

![](../Images/fa55145b18f069d4fc2a0ea26fbc1339.png)

  
对于“窃·格瓦拉”刑满释放，网友们开始各种调侃，有网友直接安排了电影《今瓶没》，上映日期就是今天他出狱的日子。  

![](../Images/6a9a432b137c7695a145f891476a0e63.png)

  
**还有网友为其赋诗一首：**  

![](../Images/b7fd3583c5c730feef7c5597253533d6.png)

  
并有人总结了他的传奇经历，著成一段“名人简历”。  

![](../Images/276f5cbba1062c1e0a34bd119a207960.png)

  
至于某网友所说，“在出狱这样的日子要抽取一位幸运观众走路回家”这样的事情，小编还是觉得不要发生比较好。  
其实也有人替他想过，如果他出狱了，按照他以往的经历，好好包装一番，可能是个不错的喜剧演员，其实这样的事情已经有过先例，此前著名的另外一位“看守所网红”大力哥就曾经成功的客串了某网络节目中的部分片段，并深刻反思了自己年轻时期曾经犯下的错，教育了自己的“孩子”不洗澡就会被抓走。  

![](../Images/074e9542eacd8c320d3371e6c64120f0.png)

![](../Images/b52346193519beb78389aa3c59ed23c4.png)

![](../Images/9b489c9a8b8d43df89bc4ee163d7bc38.png)

  
其实犯错不可怕，可怕的是不知悔改，也希望“窃·格瓦拉”放弃偷电瓶养自己，老老实实的找个本分工作，就像大力哥在节目中说的那样“人呐，老老实实安安分分才是真”。
