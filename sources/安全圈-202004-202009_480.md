# BT种子站海盗湾遭杀软报毒拦截：宕机一个月刚恢复

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651967011&idx=4&sn=2c9c9d32bcf4f1d75817282e8846d45d&chksm=f36ce263c41b6b75dbee1af3948cc25eab70d6956067d64a42c79ab1651801186282b7d0d5d0&scene=126&sessionid=1681311797#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651967011&idx=4&sn=2c9c9d32bcf4f1d75817282e8846d45d&chksm=f36ce263c41b6b75dbee1af3948cc25eab70d6956067d64a42c79ab1651801186282b7d0d5d0&scene=126&sessionid=1681311797#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)  
**宕机了近一个月后，知名BT种子站点“海盗湾（The Pirate Bay）”日前重新回归，不再“猥琐”于暗网偷生。**然而，令人大跌眼镜的是，大量安装了MalwareBytes杀软的用户反映称，访问网站时弹出木马报毒提示，从而出现页面整个空白的问题。  

![](../Images/424bff888ef0fe4da208ff3596a65c34.png)

  
对此，MalwareBytes背后的WebProtection实验室负责人Andres Ortiz解释称，海盗湾网站的种子列表依赖apibay.org返回的数据呈现，但是杀软机构发现，apibay.org中存在一些恶意的挖矿代码。  

![](../Images/9cad0d6acd3c84cbb2fdd266d956f59f.png)

  
海盗湾再次修改后，MalwareBytes现在确认，这些挖矿代码已被移除，它们将很快部署软件更新，确保用户正常访问。  
不过，坦率来说，海盗湾作为正版组织中的眼中钉，时不时就会出现访问异常，在“踢屁股（kickass）”、ExtraTorrent消失后，它还能坚持多久。
