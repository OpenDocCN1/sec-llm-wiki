# 两男子用黑客手段攻击交易平台，刑拘！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651967011&idx=1&sn=9cd1d7f349417de4d62d2fad4c98c810&chksm=f36ce263c41b6b75610d6fed69845021d2be482602dc389a47d7792ae687f25072b96734cb03&scene=126&sessionid=1681311797#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651967011&idx=1&sn=9cd1d7f349417de4d62d2fad4c98c810&chksm=f36ce263c41b6b75610d6fed69845021d2be482602dc389a47d7792ae687f25072b96734cb03&scene=126&sessionid=1681311797#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)  
4月13日，茂名市化州公安网警开展“净网2020”专项行动再传捷报，其联手上海网警抓获2名涉嫌计算机犯罪的“黑客”。这是继4月初接连抓获3名涉嫌网络诈骗犯罪嫌疑人以来的又一战果。  
今年4月上旬，化州市公安局接到茂名市公安局网警支队转来的一条案件线索：有2名化州籍的嫌疑人，涉嫌上海警方侦办的一宗计算机“黑客”犯罪案件。  
化州市公安局网监大队对此高度重视，迅速组织办案民警循线摸查，很快锁定了2名嫌疑人的社会关系及藏身处所。  
4月13日，上海黄浦网安支队联合化州市公安局网监大队和杨梅派出所组成的抓捕组，展开抓捕行动。  
当天下午，办案民警在杨梅镇某出租屋，成功抓获涉案嫌疑人陈某健、林某其，现场缴获**作案手机3部、计算机硬盘4个**。  
经审讯，落网的陈某健（男，31岁）、林某其（男，31岁，均系化州市杨梅镇人）对其犯罪事实供认不讳。  

![](../Images/02ee29caf2447e4078dabbf30a8fa450.png)

两名嫌疑人背景警方控制  
据其交代，**今年年初，陈某健和林某其利用“黑客”手段，攻击“某某交易平台”，导致该平台无法正常运行。他们通过修改后台程序等手段，从中非法谋取该交易平台的钱财达数万元。**  
目前，落网的嫌疑人陈某健和林某其，因涉嫌破坏计算机信息系统犯罪，已被上海公安机关刑拘。
