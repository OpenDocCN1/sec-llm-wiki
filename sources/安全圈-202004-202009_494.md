# 本月累积更新已放出：该给Windows 10打补丁了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651966967&idx=3&sn=08ce15f1f3f22e951043ddbb8683b2d8&chksm=f36ce1b7c41b68a1d8802cb86b2768bd61023b4472aba987dd8511ce651549a88262b2c888e6&scene=126&sessionid=1681311797#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651966967&idx=3&sn=08ce15f1f3f22e951043ddbb8683b2d8&chksm=f36ce1b7c41b68a1d8802cb86b2768bd61023b4472aba987dd8511ce651549a88262b2c888e6&scene=126&sessionid=1681311797#rd)

![](../Images/ebb7cb2ba50c6975654c8b26c7aa8a46.png)  
在本月的补丁星期二活动日上，微软发布了新的Windows 10累积更新，并且照常将重点放在安全性能改进上。**这些累积更新还包括其他非安全错误修复程序，建议用户尽快安装它们。**![](../Images/5ed77afc2622e2cf06fee6383c522136.png)  
**Windows 10设备现在可以使用以下累积更新：**

> Windows 10 version 1507 — KB4550930 (OS Build 10240.18545)Windows 10 version 1607 — KB4550929 (OS Build 14393.3630)Windows 10 version 1703 — KB4550939 (OS Build 15063.2346)Windows 10 version 1709 — KB4550927 (OS Build 16299.1806)Windows 10 version 1803 — KB4550922 (OS Build 17134.1425)Windows 10 version 1809 — KB4549949 (OS Build 17763.1158)Windows 10 version 1903/1909 — KB4549951 (OS Builds 18362.778 and 18363.778)

  
对于Windows 10版本1903，新的累积更新KB4549951将操作系统的内部版本号增加到18362.778，对于Windows 10版本1909，将操作系统内部版本号增加到18363.778。  
除了星期二补丁程序中发布的典型安全改进功能之外，此累积更新还包含已解决的Microsoft Office产品漏洞。因此，如果您使用的是Office生产套件，则此累积更新应会阻止任何潜在的漏洞利用，这意味着强烈建议您尽快安装此更新。  
此外，此更新还包括用于存储和管理文件的修复程序，还进行了进一步更改以提高Windows执行基本操作时的安全性。
