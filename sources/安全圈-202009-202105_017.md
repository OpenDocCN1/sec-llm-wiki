# 【安全圈】苹果 AirTag 首次被破解 可进行任何入侵操作！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651980940&idx=3&sn=24c13dcc3a0def56c4ec29d71eac19b2&chksm=f36f28ccc418a1da423539e16113f097655eb7604afee7c52f2e70bcc1112a9c5b98e6bef3c3&scene=126&sessionid=1681311669#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651980940&idx=3&sn=24c13dcc3a0def56c4ec29d71eac19b2&chksm=f36f28ccc418a1da423539e16113f097655eb7604afee7c52f2e70bcc1112a9c5b98e6bef3c3&scene=126&sessionid=1681311669#rd)

![](../Images/564ee02b17d744c7dc30ff12f394bbe3.png)

有安全研究人员表示已破解苹果刚刚发布的 AirTag，并演示了修改 " 丢失模式 " 的 NFC URL 过程。此过程相当于对 AirTag 完成越狱，黑客可以肆意进行想要的操作。

  

![](../Images/ef8e049c80df39d6088ca907cefe2b23.png)

  

德国安全研究人员 Stack Smashing 今天发推说，他能够 " 入侵 AirTag 的微控制器 " 并修改了 AirTag 的固件，并放出了一个修改 NFC URL 的演示视频。

  

苹果目前尚未回应，但此前已有白帽发现过这一漏洞，苹果或可尽快制定应对措施。
