# 【安全圈】黑客称已从美国警方电脑窃取敏感信息：不给赎金就曝光线人

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651980644&idx=2&sn=d5b2b47e26155ce61986fcc131ef8d46&chksm=f36f2f24c418a6328be744c65b5576d0a1026f65736544eacb00853df1d72e987c387586e13e&scene=126&sessionid=1681311669#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651980644&idx=2&sn=d5b2b47e26155ce61986fcc131ef8d46&chksm=f36f2f24c418a6328be744c65b5576d0a1026f65736544eacb00853df1d72e987c387586e13e&scene=126&sessionid=1681311669#rd)

![](../Images/ebb2e4b8b1a3bd83cb43cdd29ec2562c.png)

据《纽约邮报》27 日报道，有黑客声称，他们已经从华盛顿特区警方的电脑中窃取了有关线人的敏感信息，并威胁称，除非获得赎金，否则将把这些信息提供给犯罪团伙。

  

美国华盛顿特区警察局在周一证实，" 意识到我们的服务器上有未经授权的访问 "，并 " 已让联邦调查局进行全面调查 "。

  

![](../Images/4dbacdc3e248347b69eb1c40f0d83af7.png)

  

一个名为 "Babuk" 的新型勒索软件组织声称对此事负责，该组织在暗网上发帖称，已经窃取了超过 250GB 的数据。屏幕截图显示，这个黑客组织至少拥有来自四台电脑的数据，其中包括情报报告、犯罪团伙冲突情况、监狱人口普查和其他警方管理文件。  

  

据报道，该组织给美国华盛顿特区警方三天时间与他们取得联系，否则 " 我们将开始与犯罪团伙取得联系，以曝光线人 "。赎金数额没有具体说明，但没有迹象表明警方的行动已经受到影响。

  

![](../Images/a4f978286fa99e9f0d84059f869be8b0.png)

  

网络安全公司 Emsisoft 威胁分析师布雷特 · 卡洛向美联社表示，今年到目前为止，美国有 26 个政府机构受到勒索软件的攻击，网络犯罪分子公布了从其中 16 个机构窃取的网络数据。

  

《福布斯》杂志称，今年才出现的 "Babuk" 组织被认为与针对休斯敦火箭队发起勒索软件攻击的黑客来自同一组织。美国国土安全部部长亚历杭德罗 · 马约卡斯 ( Alejandro Mayorkas ) 上个月表示，打击这些犯罪组织已成为国土安全部的首要任务。
