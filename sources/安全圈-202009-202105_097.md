# 【安全圈】安卓手机收集用户数据量是苹果收集的20倍

3月31日，爱尔兰都柏林一所大学的计算机科学教授最近进行了一项研究，发现安卓手机收集的用户数据是同类iPhone的20倍。

  

![](../Images/2a694e25341acce5302aa99502575a85.png)

  

研究员兼学院计算机系统主席道格·莱思(Doug Leith)称，iOS和安卓系统都在不断收集数据并将其分别发送回苹果和谷歌。这一行为从将SIM卡插入智能手机开始，包含硬件和应用程序的交互等。

  

该项研究的测试条件是，将手机恢复出厂设置后进行测试，首次启动，在手机处于空闲状态时插入或拔出SIM卡，查看设置，启用或禁用位置，以及用户登录到自带应用商店时首次收集的数据。

  

测试的两款手机是运行Android 10系统的Google Pixel 2手机，以及一台运行iOS 13.6.1的未知型号iPhone，为了监视网络连接，iPhone已经越狱。

  

研究人员表示，最大的差异是收集信息的数据量。测试中，Android在启动时向谷歌发送了大约1MB的数据，而iOS则向苹果发送了大约42KB的数据。

  

当手机处于空闲状态时Android每12小时发送另外1MB的数据，而iOS则为 52KB。根据这一数据量，预计在美国谷歌估计每12小时就会从其所有用户中获取1.3TB的数据，而苹果在同一时期会收到约5.8GB的数据。
