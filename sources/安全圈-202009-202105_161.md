# 【安全圈】西山居旗下逍遥网遭攻击致数据泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651978825&idx=3&sn=2ad3ddd88fe3bf43ed69825ae1765c0a&chksm=f36cd009c41b591f23ed92b36cad8cc62bf0832eaeda6dd60a2500db0e65fbdaa5d49492696f&scene=126&sessionid=1681311689#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651978825&idx=3&sn=2ad3ddd88fe3bf43ed69825ae1765c0a&chksm=f36cd009c41b591f23ed92b36cad8cc62bf0832eaeda6dd60a2500db0e65fbdaa5d49492696f&scene=126&sessionid=1681311689#rd)

![](../Images/cda61c05c06dc4f5a105ea1815def691.png)

根据西山居官方的消息，逍遥网遭黑客非法攻击，导致部分用户账号和加密后的非明文密码等信息外泄。官方建议第一时间修改安全等级偏低的短位密码。

  

![](../Images/4b57922400fd8528dc04f8597ab4dde3.png)

  

官方表示，2020年冬天以来，西山居旗下所属产品遭到了频繁的黑客攻击，包括大流量的DDoS攻击、撞库甚至试图直接入侵数据库。本次黑客攻击虽然不能获得明文密码，但可能用算力暴力破解短位密码。官方建议这部分用户一时间修改安全等级偏低的短位密码，请按照指引完成操作；如在其他平台使用了相同的账户及密码，也建议您对其密码进行修改。

  

![](../Images/cd355e1dcd07dae3bbadcb5662cba790.png)

  

逍遥网已经第一时间开展技术排查，并联合第三方网络安全团队成立专项专家组，目前已经协调机房和相关的服务供应商提升防护等级，并对相关业务采用了更高强度的加密算法对数据的存储和传输进行防护。
