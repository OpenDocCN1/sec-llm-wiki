# 【安全圈】微软指称俄罗斯是国家支持的黑客攻击的主要源头

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651973465&idx=1&sn=066a1b52d127af28d7048fcee1ac6dfd&chksm=f36ccb19c41b420fb9e00beeef2df2a793004364ca39ac71cfec2464dcc1e815a3a84662e91d&scene=126&sessionid=1681311733#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651973465&idx=1&sn=066a1b52d127af28d7048fcee1ac6dfd&chksm=f36ccb19c41b420fb9e00beeef2df2a793004364ca39ac71cfec2464dcc1e815a3a84662e91d&scene=126&sessionid=1681311733#rd)

![](../Images/f84fa37c419728c61eeae312ac680d8b.png)

**微软公布了一些统计数据，揭示了高知名度用户所面临的黑客攻击规模。微软透露，在过去两年中，已经有13000次关于国家支持的针对微软用户的黑客攻击企图的警报。其中超过一半（52%）来自俄罗斯，25%来自伊朗。**俄罗斯黑客的目标从奥运会举办到多个国家的选举，以及非营利组织、专业服务和高等教育相关的账户。

微软表示，在对俄罗斯运动员进行兴奋剂调查的情况下，与俄罗斯有关的黑客还试图闯入三大洲的16个体育和反兴奋剂组织的账户。

伊朗黑客更专注于政治，他们攻击了至少241个与美国总统竞选、现任和前任美国官员、政治记者和居住在海外的知名伊朗人相关的微软账户。

![](../Images/3d0a1bc4abba985d4b5408e288e8833d.png)

还有国家 "试图获取与即将举行的美国总统大选相关组织的情报"，但也对美国和亚洲的医疗研究机构进行了攻击。

作为 "捍卫民主"计划的一部分，微软为现有微软Office 365产品的用户提供免费的网络安全保护，包括监测国家支持的潜在黑客的潜在行为企图。
