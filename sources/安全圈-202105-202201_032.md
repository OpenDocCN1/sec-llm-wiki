# 【安全圈】流水高达10亿余元！陕西延安警方侦破一起特大网络赌博案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651990965&idx=1&sn=157628d49a1c4ca91d94ad3dfb8edec0&chksm=f36f07f5c4188ee3d5c78c93f9c1d9eb1fd7c87ae7e8cd90e761a6c099f7b45bd441111e68f2&scene=126&sessionid=1681311604#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651990965&idx=1&sn=157628d49a1c4ca91d94ad3dfb8edec0&chksm=f36f07f5c4188ee3d5c78c93f9c1d9eb1fd7c87ae7e8cd90e761a6c099f7b45bd441111e68f2&scene=126&sessionid=1681311604#rd)

![](../Images/8c409ab4578f89a4c605dc8411256e6b.png)

**关键词**

网络赌博  

  

2020年10月份以来，延安市公安局多个县分局先后多次接到报警，称其在同一个微信群以猜红包尾数的方式参与赌博，输掉数量不等的钱财。基于这一情况，市局指定安塞分局对该案展开侦查。

  

![](../Images/757d8a368cf40addba1a09a67a949374.png)

  

接到指令后，安塞分局立即成立由安塞区人民政府副区长、延安市公安局党委委员、安塞分局党委书记、局长吕宁同志为组长，分局党委委员、副局长石磊同志为副组长，治安大队大队长尚武岐及治安、网安部门精干力量为成员的专案组，着手实施前期侦查摸排工作，并于11月23日予以立案。

  

![](../Images/4fbe40f9ea6c1f6186ebd26a26372051.png)

  

一年来，专案组累计调取电子数据三十余万条、查询银行账户九百余个、分析交易流水二百余万条，并通过一系列技侦措施，使案件侦破工作终于迎来了重大进展。随后，专案组又奔赴广州、深圳、潮州、汕头等地，经过连续九天认真细致的调查摸排，一个以王某东为首，涉及全国多个省市的特大网络赌博体系终于清晰地浮出水面，抓捕时机亦随之成熟。

  

![](../Images/f2cf187bae157e6ab32885da73370b87.png)

  

2021年11月21日，遵照袁家富副市长指示，由市局党委委员、副局长曹林安同志和安塞区人民政府副区长、市局党委委员、安塞分局党委书记、局长吕宁同志带队，在安塞区委、区政府的大力支持下，抽调市局技侦、网安等相关部门7名同志和分局101名民警组成抓捕行动队，分12个小组分别赶赴广东、浙江、江西、福建、河南、广西、上海6省1市实施收网。到达任务地之后，各小组立即进入工作状态，在当地公安机关的大力配合和支持下很快摸清了嫌疑人的具体方位。11月26日上午，随着指挥部的一声令下，各小组同时行动，不到一小时便将涉案犯罪嫌疑人全部抓获。

  

![](../Images/1e734452a1acf5aae98bb1e21c7d3c0f.png)

  

全部嫌疑人押解回塞后，分局又专门组建了以郭金亮副局长为组长，刑事科学技术室教导员蔺怀勋为副组长的案件审讯组，全面负责对嫌疑人的审讯和后期办理工作。最终查明：该网络赌博案件整体呈“工”字形结构，主要分为群组织成员、“拉手”和参赌人员。涉赌APP包括微信（企业微信）、聊呗、城信、街店四种，赌博方式统称为“快乐十分”，赔率从最低一倍至最高七十五倍不等，赌注为100元至50000元不等，整个案件涉案赌资流水高达10亿余元。

  

![](../Images/3f886bf35ad6c6afcf99ebf555731de2.png)![](../Images/c845b4852e0f37b9885ae032cf16bb24.png)

  

目前，该案共冻结账户200余个，冻结资金400余万元，现场查获赌资20余万元，查扣作案手机百余部，抓获犯罪嫌疑人15人，除2名被取保候审外，其余13名嫌疑人已被安塞区人民检察院批准逮捕。

  

![](../Images/db362a5e6cbe1982edddc0f40e4bbba1.png)

  

值得一提的是，此案全程无第三方社会力量技术支持，完全由公安机关独立侦办，这在延安市公安机关尚属首次。此案的成功侦破，无疑为全市公安机关今后进一步打击类似新型网络违法犯罪积累了宝贵经验。
