# 【安全圈】冻结涉案资金9600余万！吉林市警方破获部督跨境网络赌博案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651990140&idx=1&sn=6bbbf62339b3998b7735242afce87839&chksm=f36f043cc4188d2ab63639b4988fec296c577a08f93aa17024fc661024e790dc61ef84a24086&scene=126&sessionid=1681311608#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651990140&idx=1&sn=6bbbf62339b3998b7735242afce87839&chksm=f36f043cc4188d2ab63639b4988fec296c577a08f93aa17024fc661024e790dc61ef84a24086&scene=126&sessionid=1681311608#rd)

**关键词**

网络赌博

  

经过长达一年的连续奋战，吉林市公安局昌邑分局全盘部署出动警力1000余人次，全线追踪、全链条打击，成功破获一起公安部重点督办的跨境赌博案件，截至11月20日，打掉犯罪窝点团伙5个，抓获犯罪嫌疑人295名，涉案资金流水32.88亿元人民币，冻结涉案资金9600余万元，扣押3500余万元，查获、封停开发运营网络赌博APP10个。

  

![](../Images/5cdf1b354f367e604a29c463c86390a7.png)

  

2020年8月份，昌邑公安分局全面梳理摸排跨境赌博案件线索时，发现多个非法直播平台存在网络赌博行为，并立即抽调各警种精干警力，合成作战，全力开展调查工作。

  

![](../Images/acd87f920dd8619611b18fe4cf7dd5d2.png)

  

通过深入侦查，专案组获取嫌疑人朱某某、韩某某、杜某等人为网络赌博直播平台的代理人，朱某某系该非法直播平台的家族长，在吉林市租赁多个固定窝点，拉拢雇用网络主播，通过组织“赌播”、“黄播”等非法活动进行盈利，韩某某、杜某负责技术、后台以及联系购买转移资金的银行卡等行为。该团伙系有组织的通过跨境服务器架设多个非法涉黄、涉赌APP直播平台的犯罪集团，通过一款聊天软件吸纳下级代理人员，并在这些直播平台上给他们开通一至多个直播间权限，建立直播场所，拉拢雇用涉黄、涉赌主播开展网上直播，网上招赌人数超过30万人。平台依靠非法软件进行管理及统计账目、获取利润。2021年8月20日，该案件被公安部列为重点督办案件。

  

![](../Images/f1cf62f2acd137e619a1ac1964fb8dcc.png)![](../Images/40faded06319861dde7316537cbc7a39.png)

  

根据初步查明的线索，2020年9月以来，昌邑分局组织警力，先后奔赴辽宁、北京、河北等10个省、直辖市、自治区开展抓捕工作，成功打掉涉黄涉赌非法直播平台团伙5个，抓获朱某某等犯罪嫌疑人295名。

  

目前，犯罪嫌疑人朱某某、韩某某、杜某等225名犯罪嫌疑人已被起诉，70人待起诉，该案件还在进一步工作中。
