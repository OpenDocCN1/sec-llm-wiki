# 【安全圈】“血洗”200亿元！周末虚拟货币再现“闪崩”

**关键词**

虚拟货币  

  

上个周末，并不安宁，虚拟货币再遭血洗。4号、5号两天时间内，包括大饼、以太、币an币、狗狗等各类币种均遭断崖式下跌。都渴望牛的持续走高，可曾想，利空不断，其实细品，这种结果影响因素其实很多，除了本身性质原因，更多的是受外界以及部分乱搞的影响。

  

![](../Images/fbb16280d6bea95fc1e34cecac5c23b1.png)

  

**虚拟币再现断崖式下跌**

虚拟货币的暴涨暴跌，对于行业内来说已经是家常便饭了，但这样的断崖式下挫，也引发了不少骚动。对于此次闪崩原因，有媒体报道称是主要受到新毒株奥密克戎蔓延影响，继而引发焦虑和悲观情绪，再加上欧美多国通胀创新高以及各国不断传出的金融机构监管案例等，直接或间接推动了虚拟货币集体闪崩。

  

也有一些机构分析称，市场杠杆过度或是虚拟币闪崩的重要因素。据权威跟踪数据显示，在大饼大跌不到一个小时内就触发了近6亿美元未平仓大饼期货头寸强平。而且一个多月以来，大饼未平仓期货合约一直保持在36.5万手以上，这种未平仓合约长期保持高位是不常见的，可能表明市场杠杆程度过高。

  

事实上，自两个月前大饼创出历史新高以来，后续价格整体走低。也有声音称，近几日下跌的因素比较多，但主要是美联储货币政策趋于紧缩，他们也放弃了“暂时性通胀”的说法，承认了通胀具备持续性，从而表明未来可能转向紧缩，美元紧缩对于虚拟货币的世界货币信仰是一个打击。

  

更有一些声音表示由此更不看好虚拟货币，说“这也再次说明虚拟货币存在高波动性，没有信用支撑，没有资产担保，属于私人铸币，其高波动性可能意味着投资将出现巨大风险，消费者要规避此类高波动资产。”

  

仍有投机者试图险中求贵

  

可能大多数人想不到的是，虚拟货币价格大涨大跌前后，是大部分币圈投机者瞄准的“入场最佳时机”。

  

相信有不少朋友都是这样，每次遇到行业大涨或大跌的时候，感觉都是入场机会。因为价格大幅下跌后，就觉得后续会有回升的机会，这个时候就会选择买进或者开多。

  

说实在的，这种多空投机游戏风险极高，每一次开单对我们普通人来说，都是刀尖舔血的刺激挑战。就拿简单的一次杠杆合约开单来说，在发现一些币大行情急速下挫的时候，开多操作，本来以为“利空出尽、坐等回弹”，但没想到的是，价格仍在继续下挫，也许就短短的几分钟，就可以把你的本金一波带走了。

  

这种合约交易又称期货交易，是一种将交易品远期交易的模式。一是既能做多又能做空，可双向获利；二是可以加杠杆，以小博大。通过合约交易及交易所推出的上百甚至上千倍杠杆，让本就波动巨大的币市也变得更加危险疯狂。

  

这时候可能有人会比较困惑，不是不让炒币交易吗？怎么还能开杠杆合约？说到此，投机币民的疯狂操作，其实离不开一些机构的“推波助澜”。事实上，币圈的投机者除了险中求贵的币民外，还有给币民造梦的交易所和其他币圈机构们。

  

目前，币圈市场乱象层出不穷。除了币民层面，有不少人通过百度贴吧、Telegram的方式交流炒币，甚至有个人用户注册机构参与交易外，在机构层面，尽管有头部交易所官宣停止大陆地区新用户注册，但仍有部分对国内用户开放甚至顶风拉新。

  

近几日，发现有不少币圈交易所的业务人员在拉人头，在社群中宣传高比例返佣，邀请好友注册交易炒币；甚至还有交易所人员号称可“手把手”教学新手翻墙注册账号，诱导新手开户甚至进行杠杆交易。

  

“币圈目前有很多大量拉人头的传销行为、诈骗行为，甚至会包装成培训班或投资群的名义出现，投资者需要关注此类风险，处理财产的时候要有防骗意识。” 虚拟货币存在着各种问题和风险，相关监管也将持续保持高压态势，建议从事相关活动的机构和人员应杜绝侥幸心理，明确认识到这种行为与政策风向不符，尽早停止虚拟货币违法活动。

  

挖矿、交易等监管不断升级

  

事实上，不管是关于虚拟货币挖矿还是交易，近期监管都在持续升级中。

  

今年9月，多部门就曾发布通知明确虚拟货币相关业务活动属于非法金融活动，同时构建对虚拟货币的全链条监管，并强调开展法定货币与虚拟货币兑换业务、虚拟货币之间的兑换业务、作为中央对手方买卖虚拟货币、为虚拟货币交易提供信息中介和定价服务等非法金融活动，一律严格禁止，坚决依法取缔。

  

业内预计，后续监管还将加强对涉虚拟货币交易的账户和资金的监测，相关账户封堵工作将进一步升级。

  

由于虚拟货币的去中心化和加密特性，监管难度很大，所以，要加强对普通投资人的风险教育。
