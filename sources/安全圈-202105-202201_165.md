# 【安全圈】安徽省铜陵市警方破获一起跨境网络赌博案 涉案金额高达4千万！

　　近日，铜陵市公安局铜官分局杨家山派出所经过5个月的缜密侦查、强力攻坚，辗转3000余公里，在市局网安、技侦、刑侦等警种的支持下成功破获了“铜都棋牌”特大跨境网络赌博案，抓获犯罪嫌疑人13人，查明涉案赌资4千万元，涉赌银行账户800余个，冻结违法资金3百万元，扣押作案手机26部，电脑2台。

  

![](../Images/90964eb88c5f96e4fc88013937ae21f2.png)

　　

今年2月26日，杨家山派出所民警在工作中发现线索：有人通过一款名为“铜都棋牌”的APP进行网上赌博，参赌人员众多，涉案资金巨大。

  

　　掌握线索后，杨家山派出所高度重视，安排民警迅速核实相关线索并开展前期侦查。

  

　　经查发现“铜都棋牌”APP为铜陵市乐享天成网络科技有限公司开发的APP平台，公司运营者为王某、王某某，其APP内有“跑的快”、“铜陵麻将”、“比鸡”等赌博项目。

  

　　公司通过在全国范围发展代理商，由代理商招揽赌客赌博赌客进入APP后，公司及代理商会以“上下分”、“微信、支付宝”转账、“亲友圈”等形式向玩家进行抽成，从中渔利。

  

　　鉴于案情重大，铜陵市公安局抽调精干警力成立专案组，全力协助铜官分局侦办此案。

  

　　经过专案组民警近4个多月的艰苦侦查、循线摸排和强力攻坚，成功掌握了“铜都棋牌”管理层主要犯罪嫌疑人和技术团队，各级代理商等犯罪嫌疑人的身份信息以及犯罪事实，抓捕时机已成熟。

  

　　6月17日晚19时许，铜陵市公安局组织50余名警力，分10个抓捕组连夜将“铜都棋牌”管理层主要犯罪嫌疑人王某、王某某、莫某等3人抓捕归案；同时赶赴芜湖市、池州市将一、二级代理商吴某某、童某等6人抓捕归案。

  

![](../Images/15b9c4caee0048ecb9f5ab2f5e8e8a87.png)

　　

在抓获主犯和一、二级代理商后，专案组马不停蹄组织警力远赴深圳市将“铜都棋牌”技术团队主要犯罪嫌疑人杨某、张某某、吴某、孟某某抓捕归案。

  

![](../Images/fee3eb3dd77b74f6c474a8d17607ab54.png)

　　

经查，2018年4月至2021年2月期间，王某、王某某、莫某等3人通过成立铜陵乐享天成网络科技有限公司开发“铜都棋牌”APP软件，通过“跑的快”、“铜陵麻将”、“比鸡”APP软件进行跨境网络赌博，发展“铜都棋牌”代理商10余名，在全国范围内招揽参赌人员达1000余人，技术团队参与制作同类网络赌博APP达100余个，王某等人从中抽成，涉案赌资流水达4千万元。

  

　　目前，犯罪嫌疑人王某、莫某2人已被执行逮捕，王某某等11名犯罪嫌疑人已被依法移送起诉，案件正在进一步办理中。
