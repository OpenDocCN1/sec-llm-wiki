# 【安全圈】江苏省无锡市警方破获特大侵犯公民信息案，数据高达54亿多条！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651987610&idx=1&sn=913315aff6833a30654a96179661cea8&chksm=f36f32dac418bbccf9597707d1515df296485fd493ea02b55d56bdc99cd9aba5bb36f56b5b76&scene=126&sessionid=1681311625#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651987610&idx=1&sn=913315aff6833a30654a96179661cea8&chksm=f36f32dac418bbccf9597707d1515df296485fd493ea02b55d56bdc99cd9aba5bb36f56b5b76&scene=126&sessionid=1681311625#rd)

![](../Images/36e78ebc5b4bd92a9172b1575d9fde99.png)

**关键词**

“社工库”  

  

近日，江苏省无锡市警方成功破获了一起侵犯公民个人信息案，犯罪嫌疑人非法获取各类公民信息，数据累计高达54亿多条，并通过非法网络平台以查询、出售等方式牟利。

  

![](../Images/528c2e908368ed728027ecfffa5e1aaf.png)

  

今年3月份，无锡网警部门在网上巡查时发现，一名卖家利用非法网络平台，为他人查询某大型社交网络账号关联的手机号码等个人信息数据，并将查询信息以每条1000美元（约合人民币6384元）的价格出售。

  

![](../Images/8d9ca448941a360e9250fe5a5a191146.png)

  

江苏无锡市公安局锡山分局网安大队民警 陆朋：我们发现在贵州遵义有一家网络公司可能与该案有关，该网络公司的法人何某具有一定黑客技术，深入侦查发现他自己组建了一个社工库。

  

![](../Images/27d4726b1bad37a90ddfe733ba10987b.png)

  

所谓社工库就是黑客们将泄露的用户数据整合分析、集中归档的一个地方。何某通过搭建具备查询功能的数据库，并利用非法网络平台提供查询公民个人信息的服务以此获利。经过侦查，无锡警方于近日成功抓获何某、熊某等人，现场查扣涉案服务器6台、电脑2台，以及非法获取的各类公民个人信息54亿余条，目前该案还在进一步侦办中。

  

![](../Images/31ae0251348c316ef02cac99e301d65d.png)

  

江苏省无锡市公安局锡山分局网安大队民警 陆朋：它的信息，迄今为止应该是国内我们查获的最大单体量的一个公民个人信息社工库。
