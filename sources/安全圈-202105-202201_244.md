# 【安全圈】备份好搜狗浏览器个人数据文件，官方通告！搜狗浏览器论坛将在10月18日停止服务

9月18日，据媒体报道，搜狗浏览器论坛管理员近日发布了搜狗浏览器论坛离线公告。

  

通知显示，搜狗浏览器论坛将于2021年10月18日停止服务。请在此之前登录论坛，复制并保存所需内容。谢谢你的陪伴。不便之处请谅解。

  

官方表示，如果您在使用中遇到相关问题或需要帮助，请点击浏览器右上角的“菜单”-“帮助”-“问题反馈”进行在线反馈。我们会尽快与您联系并帮助您解决问题。

  

7月13日，国家市场监督管理局无条件批准腾讯控股有限公司收购搜狗股权，该股权将成为腾讯的间接全资子公司。

  

据界面消息，腾讯最早将于8月完成搜狗整合。搜狗的大部分业务将并入腾讯PCG，搜狗的主要团队将并入腾讯的看点。

  

此外，据报道，搜狗现任首席执行官王小川将来可能离职，选择自己创业。腾讯集团副总裁兼腾讯负责人殷宇将接任。
