# 【安全圈】江苏省南通市公安局破获一起通过违禁呼叫设备连接境外互联网，联合境外犯罪分子以虚拟货币结算方式非法获利案件

**关键词**

为境外犯罪分子提供境外协助

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_2049885014556753924](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_2049885014556753924)

  

一伙人经常拖着一个行李箱进出小区，行为诡异！

  

今年8月，南通海安市公安局接群众报警

  

一查果然有问题！

  

“接到报警说，这伙人鬼鬼祟祟的在草丛里躲着，不知道在干些什么。公安民警对这个情况进行了初期的侦查，发现事情不简单。”南通海安市公安局刑警大队反诈中心民警何祯祺介绍了这一情况。

  

![](../Images/f60354f4549e89ade38ed8ed73728662.png)

  

民警方调查发现，该团伙在草地上放置了一组设备，包括大功率移动电源、路由器、发射天线和一个已被相关部门列为违禁管制物品的呼叫设备。

  

![](../Images/cd2df122974a5f59748df5df32786272.png)

  

这群人等设备安置好后便离开现场，过一段时间后又返回现场将设备收走。

  

![](../Images/d61d505c8860c2e53089aad2347520bb.png)

“通过这个设备，他们批量地朝设备范围内的老百姓拨打电话，通过架设的这个路由器，跟境外的互联网进行连接，做一个中转的作用，可以同时向外同时拨打48个电话。”民警何祯祺说。

  

9月11日，海安市公安局刑警大队一举将该团伙4名成员全部抓获。

  

![](../Images/037650eb766953f5b41851f70807d4bf.png)

  

经查，2021年8月份以来，泰州姜堰籍男子张某某从奚某某处购得这套呼叫设备后，多次伙同周某某、翟某某窜至江苏省多市架设该设备，为境外诈骗犯罪分子实施诈骗提供呼叫协助，并以某虚拟货币结算酬劳，非法获利10万多元。

  

![](../Images/118f0e89eb24000f4ae110de92322ae7.png)

  

目前，4名犯罪嫌疑人已被依法刑拘，案件还在进一步深挖办理中。

  

警方提醒：在日常生活中如果遇到类似的人员、设备或者异常的行为，要及时向公安机关反映。
