# 【安全圈】黑龙江省牡丹江市警方仅用六天抓获信息网络犯罪嫌疑人

**关键词**

信息网络犯罪

近日，牡丹江市公安局爱民分局刑警大队仅用6天就抓获6名犯罪嫌疑人。据悉，他们涉嫌帮助信息网络犯罪活动，涉案74.5万元。

![](../Images/9e0cef247d9c2f16974e25c2ae9c4eaa.png)

  

犯罪嫌疑人被押解回牡丹江

  

　　2021年8月25日16时许，牡丹江市公安局爱民分局刑警大队接到受害人赵某的报警电话称，自己从今年8月2日起在一个名叫“长江量化精灵”的APP上购买股票，截至8月23日已先后通过手机银行向对方账户存入74.5万元用于购买股票，现已无法登录该APP，且无法与运营方取得联系。

  

  

　　爱民分局刑事侦查大队接警后，立即对报警人赵某的资金流去向展开研判，经过3个昼夜的工作，锁定了犯罪嫌疑人的身份。8月29日，爱民分局副局长牛刚、刑事侦查大队副队长历成带队赶往宁夏回族自治区银川市开展侦查，经过连续摸排和蹲守，于8月31日分别在银川市和中卫市将涉嫌帮助信息网络犯罪活动罪的慕某等6人抓获归案。

  

  

　　9月2日22时许，爱民分局刑警大队办案组成功将6名犯罪嫌疑人押解回牡丹江。目前，案件正在进一步办理中。
