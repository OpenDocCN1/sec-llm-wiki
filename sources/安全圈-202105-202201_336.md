# 【安全圈】义乌警方破获特大境外网络侵权案件，犯罪团伙靠非法广告以及打赏获利

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651984608&idx=4&sn=34f618a8101e449a5a2d103040835da6&chksm=f36f3ea0c418b7b60f95aefe736607b79f4f897c9664b78e74882979b153c23c054cbe16f9f6&scene=126&sessionid=1681311645#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651984608&idx=4&sn=34f618a8101e449a5a2d103040835da6&chksm=f36f3ea0c418b7b60f95aefe736607b79f4f897c9664b78e74882979b153c23c054cbe16f9f6&scene=126&sessionid=1681311645#rd)

**关键词**

网络犯罪  

8月3日，经过义乌警方2个多月的缜密侦查，成功侦破一起侵犯著作权案，抓获2名犯罪嫌疑人，查获侵权影视作品18万余部，涉案金额超百万元。

![](../Images/9076c30cee92192d2f4fac6951518ef0.png)

     5月29日，义乌市公安局食药环大队接到国内某知名电影公司报案，称有一家网站在未获得他们授权的情况下，擅自在其经营的网站上发布数万部侵权影视作品，并以此牟利。此举涉嫌侵犯著作权，义乌市公安局食药环大队立即联合网警等多部门展开调查。

    通过对域名的分析，警方发现犯罪嫌疑人将网站服务器架设在境外，而实际运营则位于国内，该网站通过开通打赏以及植入非法广告等方式牟取利益。经过侦查，警方锁定了犯罪嫌疑人何与冯某。

    8月3日上午，义乌警方在广东佛山和江西南昌两地同时收网，成功抓获了嫌疑人何某、冯某。到案后，二人对自己的犯罪事实供认不讳。

![](../Images/5df8635ab11c459288ae0d5f68b130ce.png)

   据嫌疑人冯某交代，他从多年前就接触了解到电影网站的搭建、发布盗版影视作品方面的东西，觉得有利可图，于是从2019年起自己租用境外服务器陆续搭建了17个影视网站，通过盗版各大正版影视资源，放在其经营的网站供人观看，从而收取广告费和用户打赏盈利。久而久之，冯某的影视网站积累了一定的流量和人气。

![](../Images/29c3654763395f803500a21e404ae7aa.png)

   今年年初，嫌疑人何某在一个网络论坛与冯某相识，何某看中冯某的影视网站资源多，流量大，想要从冯某手上买域名，为自己建立的影视网站“狗带网”提供影视资源、引流。于是两人通过论坛达成交易，冯某以42万的价格将域名卖给了何某。

目前，何某与冯某因涉嫌侵犯著作权罪，已被义乌警方依法采取刑事强制措施，该案件还在进一步侦查过程中。

义乌警方呼吁广大市民，在日常生活中支持正版，拒绝盗版，不要为盗版产业提供滋生的土壤。
