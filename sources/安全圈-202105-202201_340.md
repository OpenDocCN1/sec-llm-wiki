# 【安全圈】小米MIX 4资料遭提前泄露！消息称处理结果已确定：赔偿100万

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651984517&idx=1&sn=41e398ecbdbda9ab3bdd63edb78e9260&chksm=f36f3ec5c418b7d30e268945c31309d707659673e44d6581ce52900074fed0adff1dadf8c4d1&scene=126&sessionid=1681311645#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651984517&idx=1&sn=41e398ecbdbda9ab3bdd63edb78e9260&chksm=f36f3ec5c418b7d30e268945c31309d707659673e44d6581ce52900074fed0adff1dadf8c4d1&scene=126&sessionid=1681311645#rd)

**关键词**

资料泄露

![](../Images/cbcfbf3819f0acb434ddf6051a689eea.png)

今晚（8月10日）19:30，雷军将举办2021年度演讲，并且将发布多款重磅新品，其中包括时隔三年首次回归的小米MIX 4和小米平板5。

  

这次小米在发布会之前的保密工作一直非常严谨，虽然时不时就有配置信息传出，但是相关的外观设计直到近两天官方公布之后，才彻底曝光。

  

但天有不测风云，昨天网络上突然传出一份小米MIX 4的详细评测指南文件，其中详细介绍了该机的各种配置和亮点，外观也被曝光的一览无余，足足有29页的PPT资料。

  

按照以往的行业惯例，评测指南和评测机一般都会签署保密协议，而泄密情况一旦出现，泄密的一方将会被追究法律责任，并且还要承担巨额赔偿，此次MIX 4对于小米来说意义非凡，自然将进行严肃处理。

  

根据今天下午一些博主的消息，内部已经发布了此次泄密处理决定，其中指出2021年8月9日，自媒体"科技九洲君”工作人员将新品评测指南误发至微信群，造成新品信息泄露至各大媒体，被大规模传播。

  

根据《小米集团信息泄密处罚暂行办法》和《保密协议》并综合考虑泄密影响，对自媒体"科技九洲君”工作室做出罚款100万人民币的处罚。

  

据日前相关消息透露，此次泄露原因其实始于微信的置顶机制，自媒体"科技九洲君”工作室的员工在向另一位员工转发资料时，失误将文件发送至被新消息顶上来的粉丝群，造成了信息泄露。

  

虽然此次泄密属于意外事件，但是终究是在该工作室出现的问题，被处以罚款也在情理之中。
