# 【安全圈】电商老板转行开卡业务员，疯狂盗取公民“人脸信息”被宁波警方抓获

**关键词**

**网络犯罪、猫池**

家住海曙的邓先生前段时间经历了一场由普通人到诈骗嫌疑人又到受害人的三重身份转变，而这一波三折的身份变化都是在邓先生毫不知情的情况下发生的。

  

到底怎么回事？

这一切还要从邓先生

一张无辜被“盗”的脸说起

↓↓↓

  

今年2月，手机卡办理专员小谢和小俞敲开了邓先生家的门，他们向邓先生热情介绍了新卡套餐，面对“无限流量”“充值返现”“超低月租费”等优惠力度，邓先生一下子就动了心，随后在专员小谢“手把手”贴心帮助下，**很快用自己的身份证，刷脸办好了新卡。**让邓先生没想到的是，这次送上门的“大馅饼”**竟然成了“大陷阱”。**

  

今年4月，海曙公安在办理一起电信诈骗案时，查到一涉案APP的客服号码为邓先生所有，经过查证，邓先生的嫌疑很快就被洗清了，但是这个号码确实是**2个月前通过身份证和人脸识别两个“关卡”后成功绑定在邓先生名下的，**照理来说这张手机卡就是邓先生在知情的情况下由本人办理的。

  

此路不通，办案民警立刻换了思路。很快，当时给邓先生办卡的专员谢某和俞某进入到了民警的视线。

  

5月12日，在掌握充分的证据后，民警在北仑某暂住房内成功将谢某和俞某抓获，**当场查获1000多张手机卡和7台猫池设备。**

![](../Images/52d1de2f4f1d511cea1b6a87445bffbc.png)

**▲当场抓获犯罪嫌疑人**

据了解，谢某原本是一名电商老板，无意间在一些微信群、QQ群中，发现了一群“买号”“卖号”“养号”的特殊群体，他们通过售卖自己或他人手机号，或者售卖用手机号注册的美团、抖音、陌陌等APP软件的新账号，其中不乏涉及网络犯罪的黑灰产类APP软件。

  

谢某看到他们的“利润”如此之大，不由动起了歪心思，他通过仔细观察和认真“学习”，很快掌握了技巧，**尝试着用自己和店员俞某的手机号承接微信群和QQ群的这类业务并成功获利。**

  

尝到了“甜头”的他很快不满于现状，干脆关了自己的电商店，**把“兼职”干成了“职业”。**

![](../Images/3e5215330df9f69c833a3f7a4c2ec984.png)

**▲盗刷过来的手机卡**

今年2月，自以为掌握了“财富密码”的谢某拉着俞某一起注册成为了联通、移动的开卡业务员，正式上门为客户推销开卡。

  

他们“热情而贴心”的服务加优惠力度极大的手机新卡业务吸引了不少像邓先生一样的人办卡，**而猫腻就出在他们在给他人办卡的时候，****他们通常在客户办卡时利用“刷脸”不成功要求刷第二次，****再通过第二次的“刷脸”成功“盗取”客户的脸部信息办理第二张手机卡，**就这样，谢某和俞某拥有了海量的手机卡。

![](../Images/d2f5018dff04cc3e35fca47b96f3148f.png)

**▲猫池设备**

随后，谢某用相关软件管理记录开户手机卡的信息，再将卡都“养”在猫池设备上，群收、群发短信，获取验证码，均用于各类APP软件的新账号注册，然后**通过网络中间商“售卖”账号，**并不管账号的用途。看着自己的收益慢慢增长，**短短2个多月，他们就办卡1000多张，并通过“卖卡”获利了近7万元。**

  

目前，谢某和俞某因涉嫌帮助信息网络犯罪案被海曙警方采取刑事强制措施。

  

而针对手机SIM卡“泛滥”衍生出的“黑灰色产业”犯罪暴露出的监管不严等问题，海曙公安已主动联合工信、检察院等职能部门，**加大对买卖手机SIM卡及关联账号等新型网络犯罪打击力度，重点严惩身份证卖家、实名卡卖家、“养卡”人等犯罪群体。**
