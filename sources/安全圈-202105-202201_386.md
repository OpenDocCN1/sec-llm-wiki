# 【安全圈】更新导致Chromebook用户被拦在登录界面之外 谷歌正在修复

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651983089&idx=2&sn=7359de75dd7b1ad73457d4e1018ddf48&chksm=f36f20b1c418a9a76fc04025f12360624ea490d4c2b184b5784a45893bc366510854b8be85d4&scene=126&sessionid=1681311649#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651983089&idx=2&sn=7359de75dd7b1ad73457d4e1018ddf48&chksm=f36f20b1c418a9a76fc04025f12360624ea490d4c2b184b5784a45893bc366510854b8be85d4&scene=126&sessionid=1681311649#rd)

![](../Images/965e45d9906d0b6f55c3bc89d5becfa7.png)

尽管及时部署最新发布的软件更新，有助于设备获得最佳的功能与安全体验。但在某些特殊情况下，它反而会造成一些额外的风险 —— 尤其当操作系统或 Web 浏览器等关键软件本身就带有重大 Bug 时。比如昨日，许多 Chrome OS 都在向谷歌抱怨，在升级到 91.0.4472.165 版本后，他们就遭遇了无法顺利登录的困扰。

![](../Images/95739cb21a66f7e673da674ac3592742.png)

截图(来自：Google)

外媒指出，尽管 91.0.4472.165 其实并不是一个重要版本，但它还是被推送给了许多无辜的 Chrome OS 设备用户。

这个看似无害的更新，让不幸中招的用户陷入了无法重新重录的困扰。

目前谷歌已经留意到了用户投诉，并且从服务器端撤下了 91.0.4472.165 版本，以避免损害的进一步扩大。

与此同时，这家搜索巨头正在积极制作修复版更新，以消除先前引入的故障。

![](../Images/464126d48fcd4cb23321db228312a7f9.png)

尴尬的是，对于那些已经中招的 Chrome OS 设备用户来说，目前仍缺乏足够良好的拯救措施。

尽管可以对 Chromebook 进行强力重置，但这会清除设备上的所有本地数据。

此外就算能够回滚到 Chrome OS 操作系统的较早版本，许多用户也不知道该如何用 USB 驱动器来执行恢复操作。

![](../Images/d5ce3a930879563a3f72edce3dc04146.png)

如果数据很是重要，目前这些用户也只能耐心等待谷歌推出修复更新。

然后让 Chromebook 保持在登录前的界面，等待 Chrome OS 完成更新的下载和安装，然后重新启动。

等不及的话，亦可尝试以访客模式登录，以手动执行更新的安装。
