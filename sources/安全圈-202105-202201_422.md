# 【安全圈】卡巴斯基：IcedID 网银木马新变种正在疯狂传播

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651982398&idx=2&sn=3bb120d00071566c8616864f806fa156&chksm=f36f267ec418af6880e85db786342ccb36ebb85e919e696e790b42b32db38effa5ae6dcba4bf&scene=126&sessionid=1681311657#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651982398&idx=2&sn=3bb120d00071566c8616864f806fa156&chksm=f36f267ec418af6880e85db786342ccb36ebb85e919e696e790b42b32db38effa5ae6dcba4bf&scene=126&sessionid=1681311657#rd)

![](../Images/76ef669ee2143bafc1397bf548b896c8.png)

卡巴斯基研究人员称，一款 IcedID 网银木马的新变种正在迅速传播，检测峰值甚至达到了每日 100 个。截止 2021 年 3 月，其在德国（8.58%）、意大利（10.73%）、印度（11.59%）和美国（10.73%）等地区的传播力最为显著。与旧版木马相比，新变种利用了修改过的英文下载器，其中包含了经过压缩的 ZIP 格式恶意软件。

  

![](../Images/479f52f1c2b203cb5f9788807d0e04ed.png)  

至于 IcedID 的感染过程，主要分成下载器和本体两个部分。前者将用户信息发送到服务器端，以供恶意软件本体使用。在将自身映射到内存后，后者会将恶意软件进一步渗透到受害者的系统中。

  

此外该木马还可启动其它恶意操作，比如允许威胁行为者绕过双因素身份验证（2FA）或运行恶意动态链接库（DLL）的 Web 注入。这两种方法，都允许下载和执行渗透到系统身处的其它恶意模块。

  

![](../Images/d2a3864ae3e2e2fae5d5d815d5ade00a.png)  

IcedID 攻击的地理位置分布

  

包括下载电子邮件收集器、Web 注入模块、密码抓取器、以及 hVNC 远程控制模块等组件，以执行 Web 注入、流量拦截、系统接管、以及密码窃取。

  

至于 QBot 和 IcedID 的区别，主要是新变种变得能够利用 x86-64 CPU 架构、从服务器端移除了假配置、且核心也略有改动，因为作者决定不将 shellcode 交换为包含一些加载程序数据的常规 PE 文件。
