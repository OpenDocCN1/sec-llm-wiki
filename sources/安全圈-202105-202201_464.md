# 【安全圈】FBI称攻击者利用Mega.nz发起勒索攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651981784&idx=3&sn=881597378142da56434bfe515e9fca14&chksm=f36f2b98c418a28e3ce1e2f97d889bedc570ceba8b8de206018fa3848bd329c92e1eb657e65c&scene=126&sessionid=1681311661#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651981784&idx=3&sn=881597378142da56434bfe515e9fca14&chksm=f36f2b98c418a28e3ce1e2f97d889bedc570ceba8b8de206018fa3848bd329c92e1eb657e65c&scene=126&sessionid=1681311661#rd)

![](../Images/60acb2d414df3370fb3041805b6ed8a1.png)

据外媒，联邦调查局FBI表示网络攻击者通过网站或直接在受害者的电脑上安装客户端应用程序，将偷来的材料上传到Mega.nz，对此Mega公司表示，没有办法阻止黑客利用合法的软件，因为他们完全控制了他们所入侵的系统。再有，除非执法部门或黑客组织举报，否则也不可能知道其2.2亿账户持有人的加密文件上保存了什么。

  

![](../Images/b8ce9a91bce818656d962fa22e8957ec.png)  

  

根据Mega2020年的透明度报告，即使文件是加密的，Mega也能获得用户的注册数据和IP地址。如果得到当局的书面确认，Mega可以在非常有限的情况下露用户信息和数据。根据该报告，Mega在2019-2020年收到了8份法院命令，并提供了被报告参与海外严重犯罪活动的账户信息。

![](../Images/fb0bcd6a4f28b0fd14384ccc7e91af66.png)  

此前有新闻表示，2021年第一季度，网络犯罪分子利用Office 365、Azure、OneDrive、SharePoint等服务发送了超过5200万条恶意信息，受疫情影响，在企业加速推进云端迁移的过程中，犯罪分子将钓鱼电子邮件隐藏到微软和Google的各项服务中，来达到窃取用户数据、勒索用户等目的。
