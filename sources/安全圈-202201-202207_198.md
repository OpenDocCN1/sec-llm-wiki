# 【安全圈】测试发现输入虚假账户可以绕过Win11登录限制

**关键词**

账号破解  

  

从Win10系统开始，微软就有意淘汰系统的本地账号，引导用户使用微软账号登陆Win系统，在Win11系统上当然也是如此，而且越来越严格，之前家庭版限制本地账号，现在Win11专业版也同样限制了。

  

更进一步，从日前的Windows 11 22H2 22616版本开始，如果你想安装新系统，只能使用微软账号，否则无法进行。

  

![](../Images/13f86c3a3d01253a9a6978149c4b0980.png)

  

对于微软的强制措施，网友们当然很不服气，网上有不少破解方法绕过这个限制，不过还有个最简单的方式可以糊弄下微软，那就是输入假的电子邮件（格式一定要正确）和密码，之后微软会提示报错，多次几次之后微软就会允许选择本地模式进入系统。

  

经过多个网站及网友的验证后，这个方法确实可以用，也比网上的那些修改方法更简单，不用断网，不过从这个过程来看，这应该是微软故意留下来的，不然很难解释为啥会有这么简单的漏洞。

  

微软何时会彻底封杀这些方式还不得而知，不过他们力推微软在线账号的态度应该是没跑了，毕竟这有助于提高用户活跃度，其实对个人用户来说也有不少好处，比如同步设置之类的。
