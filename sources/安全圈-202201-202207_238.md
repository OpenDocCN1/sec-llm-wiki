# 【安全圈】安卓木马VajraSpy伪装成聊天软件，瞄准巴基斯坦军方

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651997729&idx=4&sn=a4a834c441f82c3bfb3b3480543ce4c3&chksm=f36f6a61c418e37706fde0e151ca465e2ee3bfe1e93c1082ae0eed7a2d3381dce7defd5724e6&scene=126&sessionid=1681311572#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651997729&idx=4&sn=a4a834c441f82c3bfb3b3480543ce4c3&chksm=f36f6a61c418e37706fde0e151ca465e2ee3bfe1e93c1082ae0eed7a2d3381dce7defd5724e6&scene=126&sessionid=1681311572#rd)

![](../Images/028f511a415ee292bf475ca1cdd8b951.png)

**关键词**

木马程序  

  

VajraSpy 是一个安卓远控木马，使用指定的谷歌云存储服务来存储窃取的数据。研究人员发现，APT-Q-43 组织使用 VajraSpy 木马伪装成名为 Crazy Talk的聊天应用程序，攻击巴基斯坦军方人员。  

解压缩 CrazyTalk.apk样本可以发现多个 classes.dex，多个 classes.dex文件使用 Multidex 进行加载。

  

![](../Images/d4b3333d71399de1e78b4a7830b619cc.png)

  

该木马使用 Firebase 云存储服务来存储从失陷设备上收集的数据。  
应用的入口点为 classes2.dex 的 MainActivity，其中的 onCreate()函数确认应用程序拥有“Notification Access”和“Accessibility Service”的权限，并收集 Firebase Cloud Messaging（FCM）的 Token。

  

![](../Images/58cfb52c0acef5343d9c4d99217ee763.png)

  

恶意软件模拟一个聊天应用程序要请求的权限：

  

![](../Images/1ab48f10681a134f71c2d62470f04777.png)

  

恶意软件初始化 Firebase 存储服务：

  

![](../Images/54c86055f0b214f0be5f6a6dc9fb6f23.png)

  

在 FirebaseStorage 初始化后，应用程序通过启动 StorageReference 来收集受害者的个人信息：

  

![](../Images/84de4b62e25c0bd98df7f5040902a2ec.png)

  

     如上所示，putBytes()函数通过 StorageReference对象将数据上传到 Firebase 存储服务。

  

     除了上传的 contacts.json 文件，恶意软件还会收集其他用户数据，如短信、通话记录、WhatsApp（包括企业帐户）消息、 Signal 应用程序消息、设备详细信息、受害者设备的应用程序列表等。

  

![](../Images/d899c341ba4f50102709e3aaa57badb8.png)

  

     WhatsApp、WhatsAppBusiness 或 Signal 的消息会暂时存储在 SQLite DB 的指定数据表中，然后将其上传到指定的 Firebase 云存储服务。

  

![](../Images/1d8b0d891e6ffca7af4a3d6b528d8b3e.png)![](../Images/c168409e8665f28b8296ac6184ab23bf.png)![](../Images/c9d5d496a8b864b0052bf9cbd45bf522.png)

  

**总结**

  

     最近，安卓恶意软件势头正盛，各种不同的恶意软件都在快速攀升。攻击者也在积极利用各种能够利用的手段（如云存储服务等），将攻击过程隐蔽化、合法化。
