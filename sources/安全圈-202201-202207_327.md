# 【安全圈】入侵公司后台盗刷5万余元！三亚民警千里追逃“黑客”

**关键词**

黑客  

  

法网恢恢、疏而不漏。3月30日，国际旅游岛商报记者从海南省公安厅海岸警察总队第四支队获悉，三亚市公安局红沙海岸派出所经缜密侦查，成功破获一起利用互联网盗刷资金案，抓获犯罪嫌疑人1名，追回被盗资金56000余元。

  

3月10日，某公司负责人华先生将一面印有“破案返赃为企业挽损 一心为民护航自贸港”字样的锦旗送到红沙海岸派出所民警手中，以表达感激之情。回想起案发时的情景，华先生至今仍心有余悸……

  

2021年8月19日，

华先生焦急地来到

红沙海岸派出所报警称，

其公司账户被人盗刷资金56000余元。

接警后，民警立即展开调查。

据华先生介绍，

当天上午上班时，

他发现公司账户资金

被盗刷了56000余元，

且资金转入了一个陌生的银行账号。

经深入调查，

民警发现这是一起典型的

网络入侵他人公司后台服务器，

盗刷账户资金的案件。

  

![](../Images/fb40676ccc99456f47f1d604bdb49cc9.png)

  

了解情况后，派出所立即成立专案组全力侦办该案件，但由于网络犯罪具有很大的隐蔽性和复杂性等特点，使得案件在较长一段时间里难以取得突破性进展。今年2月初，专案组在三亚市公安局吉阳分局的大力支持下，经进一步侦查，最终锁定了远在广东的犯罪嫌疑人陈某（男，28岁）。

  

由于犯罪嫌疑人陈某长期居住在广东，而此时正是当地疫情防控关键时期，民警无法在短时间内前往广东实施抓捕。本着人性化执法的思路，民警决定先联系嫌疑人陈某，规劝其主动投案自首，争取宽大处理。通过动之以情、晓之以理的法理规劝，犯罪嫌疑人陈某最终认识到自己的违法犯罪行为，并于2月28日从广州来到三亚红沙海岸派出所投案自首。

  

经审讯，犯罪嫌疑人陈某对通过网络入侵他人公司后台服务器盗刷资金的违法犯罪事实供认不讳。目前，陈某已被公安机关依法刑事拘留，案件正在进一步侦办中。

  

据悉，犯罪嫌疑人陈某是一名电脑编程程序员，其掌握到某些关于破解网络账户的相关技术后，出于好奇心和贪念，便利用受害人公司“练练手”。在盗刷成功后，陈某惶惶不可终日，却又抱着侥幸的心理，直至接到民警劝其投案自首的电话后，陈某才意识到事情的严重性，并在自首前将盗刷的资金如数返回受害人公司账户。

  

民警提醒：广大群众遇到网络攻击或遭遇网络诈骗时，要及时报警求助，保存好相关证据，并积极配合公安机关开展案件调查。
