# 【安全圈】拜登签署“数字美元”行政命令 对加密货币意味着什么？

**关键词**

数字美元、加密货币

彭博社3月17日发文称，俄乌冲突导致俄罗斯央行可能选择货币“加密化”来保护他们的资产。此前，美欧就在考虑对加密货币实施制裁，以防止俄罗斯使用加密货币绕过对其部分银行实施的SWIFT制裁。

  

当地时间3月9日，美国总统拜登签署一项行政命令，要求政府机构仔细研究加密货币激增可能带来的风险，并考虑创建“数字美元”的可能性。行政命令签署后，比特币价格持续下挫至38000美元左右，而后反弹。

  

全球加密货币监管趋严，叠加俄乌局势背景下，数字资产存在哪些潜在的风险和机遇？科技金融作家兼CNBC金融顾问理查德•图林（Richard Turrin）告诉《每日经济新闻》记者，数字资产的投资风险很大，因为它们的价格波动很大，一些基于加密货币的庞氏骗局也在近年来层出不穷。

  

“数字资产风险与机遇并存。你可能会赔钱，但同时诸如数字人民币这样的数字资产也蕴藏着机会，它能够让社会进行更高效、更快捷、更低成本的数字化支付。”图林说道。

  

![](../Images/0ac246523788480026460d8ea20b448d.png)理查德•图林 图片来源：受访者供图

  

**“数字美元”意味着什么？**

《每日经济新闻》记者查阅白宫官网的行政命令情况说明书发现，美国对于数字货币的研究目的之一是应对国家安全风险和提高国际协调能力。

  

在俄乌局势升级的情况下，很多人都在关注比特币在帮助俄罗斯逃避制裁方面的可能性。据彭博社推测，俄罗斯拥有16.5万亿卢布的加密货币，约合2140亿美元，占全球持有量的12%。

  

乌克兰也在呼吁人们捐赠加密货币，并发布了比特币和以太币等代币的数字钱包地址。据区块链分析公司Elliptic，乌克兰扩大了接受捐赠的加密货币种类范围，截至3月17日，筹集了价值超过6300万美元的加密货币资金。

  

那么，俄罗斯能否通过加密货币规避美欧的经济制裁？图林告诉每经记者，加密货币并不能真正有意义地帮助乌克兰或者俄罗斯。“据我们所知，加密货币在乌克兰和俄罗斯的交易虽然在增加，但加密货币市场很小，不足以对任何一方产生重大影响。”

  

如果白宫发行“数字美元”，将会对全球加密货币市场产生什么影响？

  

图林表示，如果美国政府创建一个数字美元，对加密货币市场的影响很小。原因在于，目前很多人热衷于像比特币或者以太坊这样的加密货币，但并不喜欢也不相信美元。所以，对于喜欢加密货币的人来说，数字美元如果诞生，并不会让这些人出售自己的加密货币。

  

另外，图林预测，美国一旦推出数字美元，人们将更加适应数字化的货币，并且可能会有一些人决定在加密货币市场里进行投资或工作。

  

“如果华盛顿明天就推出数字美元，它对比特币的追随者来说影响很小，不会促使这些人出售他们的比特币或其他加密货币，至少他们不会立即这么做。如果你再等几年，很有可能一些已经拥有数字美元或类似数字货币的人，想尝试比特币等加密货币。”图林说道。

  

**中央银行数字货币VS加密货币 哪个更值得投资？**

  

《每日经济新闻》记者注意到，据英为财情，截至2022年3月17日，加密货币市值约1.83万亿美元。有关调查表明，大约16%的成年美国人（约4000万人）投资、交易或使用过加密货币。

  

图林对未来加密货币的发展持乐观态度。在采访中，他向每经记者介绍了比特币、以太币等加密货币外，另外两种风险相对较小的数字资产：稳定币（Stable Coin）和各国央行发行的数字货币，如数字人民币。稳定币的价值基于美元或欧元。

  

但他表示，如果投资者并不了解稳定币的发行者是否诚实可信，那稳定币也有一定风险。“数字人民币一类央行发行的数字货币显然是最安全的。”100多个国家和地区正在探索或试行中央银行数字货币 (CBDC)，这是一种国家主权货币的数字形式。

  

“加密货币市场很可能会更繁荣，但如果你准备持有稳定币或者数字美元，显然，持有数字美元是个更好的选择。所以，在未来一些稳定币可能会失去一些用户。”他补充道。
