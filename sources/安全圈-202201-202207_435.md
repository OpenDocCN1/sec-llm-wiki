# 【安全圈】微软Win11不再支持WEP等Wi-Fi加密协议

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651992905&idx=4&sn=d87bf1daf97f6f819e00fde516bd7626&chksm=f36f1f09c418961f7d300cbd6c5621d4c2b42212628539a86391911161670cafaeac29f678a4&scene=126&sessionid=1681311592#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651992905&idx=4&sn=d87bf1daf97f6f819e00fde516bd7626&chksm=f36f1f09c418961f7d300cbd6c5621d4c2b42212628539a86391911161670cafaeac29f678a4&scene=126&sessionid=1681311592#rd)

**关键词**

微软、Windows11  

  

芯研所2月17日消息，微软发布 Win11 预览版更新，开始放弃 Wi-Fi 中的 WEP 和 TKIP 加密协议。WEP 和 TKIP 都是 Wi-Fi 安全协议，前者问世于 2002 年，全称是有线等效加密，后者问世于 2013 年，全称是临时密钥完整协议。

  

![](../Images/5b7d56bd2a4c2dfad3323bcb40f0cd05.png)

  

由于时间久远，这两个加密协议的安全漏洞较多，早就被黑客研究透了，容易被攻击，所以微软从 Win11 Build 22557 版本开始放弃支持这两种加密的 Wi-Fi，如果用户还在使用这种两种方式连接 Wi-Fi，Win11 会弹窗提醒用户升级路由器及加密协议。

  

考虑到安全问题，如果用户的路由比较旧，只支持 WEP 和 TKIP 加密协议，那么也是时候淘汰了。对于较新的路由器，这个改变影响不大，这几年推出的路由器普遍支持到了 WPA2 甚至 WPA3 加密协议，安全性更高，也是新路由的默认加密协议。
