# 【安全圈】虚拟货币涉案价值约5000万，数百人牵扯其中！安徽池州警方出动了……！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2651991812&idx=1&sn=9b01baac544abe3ab8702e42c3ed9666&chksm=f36f0344c4188a52a066e5ac68cbdc6ed0335b865294b5ba290ece056804bf4d3d41755b561e&scene=126&sessionid=1681311600#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651991812&idx=1&sn=9b01baac544abe3ab8702e42c3ed9666&chksm=f36f0344c4188a52a066e5ac68cbdc6ed0335b865294b5ba290ece056804bf4d3d41755b561e&scene=126&sessionid=1681311600#rd)

**关键词**

虚拟货币  

  

反传销网1月23日发布：为扎实推进“守护平安-砺剑行动”，把破案的“句号”划在追赃挽损之后，2022年1月14日，池州警方在前期冻结部分涉案资产后，依法冻结涉嫌虚拟货币投资诈骗的600万虚拟资产，全力为受害人挽回损失。

  

近日，池州市公安局、该局贵池分局两级网警部门联动，经缜密侦查，数月攻坚，破获利用区块链技术非法获取计算机系统虚拟货币数据案，涉案价值约5000万元人民币，抓获李某、刘某、宋某等8名犯罪嫌疑人，成功摧毁了一个利用“后门”私自提取他人虚拟货币，并利用区块链虚拟货币交易平台进行销赃的犯罪团伙。

  

货币被转，牵出大案。2021年6月，王某用手机上网时发现某款数字钱包首页上新发布了一个项目，觉得有利可图，便投资了价值约59万元人民币的虚拟货币。次日凌晨发现自己质押的虚拟币全部被项目方转走，另外还卷走了其他投资者质押的近800万美元数字资产，并关闭了网站访问，失联跑路。据初步统计，该项目投资人（受害人）数百人，涉案价值约5000万人民币。

  

多警联动，合成攻坚。该案涉案金额巨大，涉及人数众多，群众损失惨重，在虚拟货币投资币圈内引起极大震动。接报案后，池州市公安局、贵池分局领导高度重视，要求市局网安支队、分局网警大队立即开展侦查，迎难而上，快侦快破。为彻底查清犯罪事实，有效惩治犯罪,在案件侦查过程中，贵池分局及时商请贵池区人民检察院提前介入，从捕、诉角度给予取证指引。

  

抽丝剥茧，寻踪觅迹。经专案组民警研判分析发现，此案是一起典型的利用区块链技术非法获取虚拟货币案件，犯罪嫌疑人精心策划、分工明确，项目方在取得安全公司的审计报告后，真实上线代码与通过审计代码不一致，实际上部署了含有“后门”的合约代码。正是通过这一后门程序，项目方可以不经投资者同意提走他们的质押资产，后跨链转入“匿名池”进行洗币。经网警对链上资金、信息流、网络流进行研判分析和网上作战，广东李某、四川宋某、湖南叶某等八人参与的犯罪团伙逐渐浮出水面。

  

![](../Images/8493ef6fdda28c48d2ee845973a168aa.png)

  

飞赴三省，围捕收网。经缜密侦查、综合研判确定抓捕条件已经成熟。贵池分局组织24名警力克服疫情期间异地抓捕重重困难，兵分三路，分赴广东东莞、四川成都、湖南衡阳等地开展抓捕，在当地警方的支持下，顺利将八名犯罪嫌疑人全部抓捕到案，依法查封、扣押嫌疑人利用赃款全款购买的价值千万别墅、百万豪车等涉案资产。经审讯，犯罪嫌疑人对参与实施该犯罪的事实供认不讳。

  

![](../Images/a8ac8af20962c8206783346c6867e33b.png)![](../Images/ef27760eadaf7223790bf6d9906bacd1.png)

  

2021年12月24日，犯罪嫌疑人李某、刘某、叶某、宋某、苏某等人因涉嫌非法获取计算机系统数据罪被贵池区人民检察院依法批准逮捕。2022年1月14日，池州市公安局贵池分局通过链上资金分析查询，冻结了价值600万虚拟资产。

  

目前，案件侦办、追赃挽损等工作正在进一步开展中。
