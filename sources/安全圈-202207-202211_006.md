# 【安全圈】马斯克危害国家安全？拜登：他与其他国家的关系值得关注

**关键词**

马斯克  

![](../Images/5cf0df51e65cf0678eb5bfeb7ae5d983.png)

北京时间11月10日消息，美国总统拜登周三表示，他认为推特新老板埃隆·马斯克(Elon Musk)与其他国家的关系值得关注。

  

拜登周三在新闻发布会上被问及，他是否认为马斯克对国家安全构成威胁，以及他在一家沙特企业集团的帮助下收购推特是否应该受到美国政府的调查。

  

“我认为，马斯克与其他国家的合作或者技术关系值得关注，”拜登表示，“不管他是否做了什么不合适的事，我并不是在暗示这个。我的意思是，他们值得关注。”

  

上月有报道称，美国正讨论对马斯克的一些投资项目进行国家安全审查。不过，白宫随后予以否认，表示这一报道“不属实”。马斯克收购推特引发了人们的担忧，担心特斯拉等他的其他公司可能因此被施压。马斯克是世界首富，除推特外还担任特斯拉和火箭公司SpaceX的CEO。
