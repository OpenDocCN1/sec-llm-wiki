# 【安全圈】突发！深夜全线大跌，24小时37万人爆仓！84亿元蒸发

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2652023756&idx=2&sn=6f5e58c1699db597a69aa4623be845a2&chksm=f36f878cc4180e9ace2abad2c2791b44a59466d7db39e8aa6847ac18876e7bc7172ff0f31363&scene=126&sessionid=1681311504#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2652023756&idx=2&sn=6f5e58c1699db597a69aa4623be845a2&chksm=f36f878cc4180e9ace2abad2c2791b44a59466d7db39e8aa6847ac18876e7bc7172ff0f31363&scene=126&sessionid=1681311504#rd)

**关键词**

加密货币  

美东时间周二早盘，随着Sam Bankman-Fried（简称SBF）的加密货币交易所FTX发行的数字货币FTX Token跌至2021年2月以来的最低水平，由于对SBF对冲基金Alameda Research的财务日益担忧，比特币面临抛售压力。

  

据CoinDesk数据，当地时间11月8日，比特币过去24小时下跌9.9%，最低跌至17484.2美元/枚。截至发稿，比特币有所回升，价格为18545.34美元/枚。以太币过去24小时下跌15.76%，现报1318.66美元/枚。币安币过去24小时下跌3.23%，现报327.76美元/枚。

![](../Images/48f00c2799a311c1eaa151218c0e979c.png)

**币安有意全面收购FTX**

11月2日，加密货币网站CoinDesk公布了一份Alameda Research的资产负债表细节。报告显示，该公司资产总额为146亿美元，负债约80亿美元，其中包括价值74亿美元的贷款。而公司资产中，FTT（FTX的原生加密代币）为其最大单一资产，约持有1.4亿枚，FTT相关资产为58亿美元，占其净资产的88%。

  

报道强调，该公司的账面上有超过58亿美元的FTT，但FTT的流通供给只有43.6亿美元左右。

  

该消息迅速引发加密市场对FTX流动性的担忧，该交易所随即遭遇大规模提款。FTT在周二跳水逾80%，最低至4.3美元。根据CryptoQuant的数据，由于FTX的提款量增加，其稳定币储备在周一跌至年度低点，过去两周减少了90%以上。

  

11月6日，赵长鹏在推特上发文表示，担心FTT会发生Luna那样瞬间崩溃的状况，未来几个月内将抛售账面上所有的FTT。Alameda Research随后回应称，如果币安要抛售FTT，其愿意花22美元/枚的价格购买这些被卖出的代币。

![](../Images/86493bf273d99a8940eb6966f07cc45f.png)

但对于FTX是否真的能拿出足够的钱回购代币，不少人都表示怀疑。

  

重重压力之下，FTX最终选择“卖身”来缓解流动性。

FTX创始人兼首席执行官Sam Bankman-Fried 8日在推特上表示，该交易所已与币安达成“战略交易”，正在进行尽职调查。

  

币安联合创始人兼首席执行长赵长鹏同日表示，FTX出现了严重的流动性紧缩，为保护用户，币安与FTX签署了无约束意向书，有意全面收购FTX，帮助其解决流动性问题。

  

**“币圈马斯克”百亿美元资产蒸发**

与Coinbase、币安等交易所类似，FTX也是近几年加密货币狂野浪潮中逐渐走到浪尖的佼佼者。公司创始人Sam Bankman-Fried生于1992年3月6日。在2017年投身币圈前，SBF在华尔街的简街资本（Jane Street）工作。凭借对金融衍生品的熟悉，他通过设立加密量化交易公司Alameda Research开始在币圈淘金，并在2019年成立FTX交易所。

  

与其他去中心化交易平台不同的是，FTX除了居间撮合交易外，还提供一系列复杂金融衍生品。几年之内，这家初创公司就成为了加密货币市场最大的几家交易所之一。福布斯曾经在2021年推出过一个“加密货币行业11大富豪”的特辑，SBF以45亿美元的身家位列第二，仅次于Coinbase的创始人布莱恩·阿姆斯特朗，被称为“币圈马斯克”。

  

在最近一轮加密货币价值腰斩的过程中，大量资金的奔踏出逃引发许多交易所接连出现流动性危机，FTX也通过一系列的兼并和借款获得“币圈央妈”以及币圈最后借款人的称号。

  

据华尔街见闻，根据数据统计，在周二收购前，SBF持有FTX53%的股份，价值约62亿美元，同时持有的对冲基金公司Alameda Research, 为他的个人财富贡献约74亿美元。SBF的总资产约为156亿美元。

据彭博的假设，在SBF寻求币安收购后，所有FTX投资者都将因币安的收购而消失，FTX和Alameda的估值将瞬间跌至1美元，也就是说现在SBF的总资产约为10亿美元，周二一天蒸发了94%。

  

而就在今年1月，包括软银愿景基金（Softbank Vision Fund）在内的3只基金以对FTX320亿美元的估值，投资了4亿美元。
