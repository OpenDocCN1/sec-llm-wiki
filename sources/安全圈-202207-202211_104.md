# 【安全圈】微软忙于修复阻塞性Bug，Win11 Dev渠道更新被迫停更

**关键词**

Windows  

对于大部分持续关注Win11更新的用户来说，每次更新后稀奇古怪的各类Bug已经是见怪不怪的事情了。

![](../Images/4f0ca8be138c2382fd8ac961b53e3e90.png)

但与每次更新都不会缺席的Bug相比，微软因为Bug而暂停更新的情况相当罕见。

  

近日，微软工程团队的Jason Howard指出，由于团队在忙于处理新版本系统中出现的阻塞性Bug”，原定一周一更的Win11 Dev更新将在下周缺席。

![](../Images/7a971252d1f03784dbdc9ea020e6e06e.png)

目前，微软Windows Insider官方已经确认了这一消息。

![](../Images/371ea8925c9f2586fbb37b4d92eeaba6.png)

不过，微软官方和Jason Howard目前都没有透露关于这一Bug的具体信息，因此我们并不能了解到究竟是什么恶性Bug会导致微软不惜暂停版本更新。

  

从现阶段微软放出的信息来看，Win11下一步的更新将围绕开始菜单的优化与小组件功能的完善展开，如果Bug能够顺利解决，我们应该很快就能迎来这两个功能的更新。
