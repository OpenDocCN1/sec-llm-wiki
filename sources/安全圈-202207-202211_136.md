# 【安全圈】数量将近Edge 3倍！Chrome成2022年漏洞最多的浏览器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2652020143&idx=3&sn=a691d3eda9e3cd68dd7dcad72a050991&chksm=f36fb1efc41838f90af49429203bfed139ebb8e6c60663bd1f5d2b72046e41dc0489ce635efb&scene=126&sessionid=1681311512#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2652020143&idx=3&sn=a691d3eda9e3cd68dd7dcad72a050991&chksm=f36fb1efc41838f90af49429203bfed139ebb8e6c60663bd1f5d2b72046e41dc0489ce635efb&scene=126&sessionid=1681311512#rd)

![](../Images/517c738daf5005211641e0b7c6557ea6.png)

**关键词**

Chrome  

据快科技网站消息，近日，Atlas的一项研究报告统计了2022年截至目前为止，各大浏览器记录的漏洞数量，Chrome以近乎于“碾压”的数量成为漏洞最多的浏览器。

  

根据统计数据，截至目前，Chrome在2022年已经记录了303个漏洞，其中甚至有部分漏洞是在10月刚刚出现并被记录的。

  

相比之下，排名第二名的Firefox只有117个漏洞，而位列第三，并一样采用Chromium内的Edge更是只有103个漏洞。

  

![](../Images/4524f6194f9e892561241efa117e475e.png)

  

如果将视线拉远，不止看2022年的数据的话，Chrome的漏洞数量也一样名列前茅，达到了整整3159个，相比之下，Firefox有2361个漏洞，Edge由于比较“年轻”更是只有806个漏洞。

  

![](../Images/fcdc4885d9bd829803903de78e0d2c8f.png)

  

当然，Chrome被记录的漏洞数量多，也并不能直接说明它的安全性不佳，反而能够说明它不太可能存在长期未被发现并处理的“祖传漏洞”，不会存在过于严重的安全问题。
