# 【安全圈】男子自学编程制作黑客软件，通过小红书等平台售卖获利超百万！

**关键词**

黑客入侵  

根据信息新观察报道，合肥市公安局庐阳分局从网络社交平台入手，斩断一个非法侵入某社交平台抓取用户数据、清洗分类提供给下游违法犯罪团伙的利益链条，成功抓获黑客软件原作者、引流代理商等。

  
  

![](../Images/f041e7052d35300990254bbafd91fa07.png)

  

据悉，了解相关案情后，庐阳分局迅速对售卖某社交平台爬虫软件昵称为“111”的嫌疑人虚拟身份开展分析研判，最终确定犯罪嫌疑人真实身份为范某兵。

  

该人活跃于多个售卖某社交平台数据的黑灰产群内，并交流相关代码编写问题。

  

深入研判后发现，该人系黑客软件的原作者，市面上类似功能的程序均为对其软件二次开发而成。

  

据范某兵供述，他自2019年自学编程及逆向破解等黑客技术，先后制作一系列针对某社交平台、快手、小红书软件非法获取数据的黑客软件，出售获利110余万元。

  

通过对网站数据库深挖、手机取证数据、资金交易记录进行碰撞比对，警方又确定购买用户40人，其中长期合作二级代理14人，购买年卡用户26人。

  

专案组立即组织警力赴江西、广东、山东、湖北对重点代理进行收网，抓获曹某、魏某、赵某、仇某晖、邹某、周某，采取强制措施7人。

  

并核实范某兵下线通过黑客程序将某社交平台用户信息分类抓取，整理转手至下游从事违法行为的犯罪过程。
