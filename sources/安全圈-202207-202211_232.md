# 专家曝光特斯拉拥有可疑代码，区别对待不同碰撞测试机构

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2652017594&idx=1&sn=d95291c77c6cec2e3dc0fefa92b27270&chksm=f36fbffac41836ecc32880f00829b80a37c3079cdcddda02d31f8a7e4f9b4e24afdedac3e3bd&scene=126&sessionid=1681311524#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2652017594&idx=1&sn=d95291c77c6cec2e3dc0fefa92b27270&chksm=f36fbffac41836ecc32880f00829b80a37c3079cdcddda02d31f8a7e4f9b4e24afdedac3e3bd&scene=126&sessionid=1681311524#rd)

![](../Images/78a636907b72ed4a9a5d13af8c3de99c.png)

**关键词**

特斯拉

根据IT之家的消息，特斯拉汽车在安全碰撞测试中的表现一直以来都十分优秀，已经通过了全世界知名碰撞测试机构的测验，上周 Euro NCAP 公布的数据显示，特斯拉车型获得了最高分。

2022 Tesla Model Y (MIG) 的 Euro NCAP 测试结果：

成人保护 - 97%

儿童保护 - 87%

弱势道路保护 - 82%

安全辅助 - 98%

  

![](../Images/a10998a38d79b152a9c2e2e1a4620353.png)

  

现在，白帽黑客兼特斯拉软件专家“绿神”@Greentheonly 发推称，他从特斯拉的代码中发现了一些不一样的东西表明特斯拉正在针对中国、欧盟、韩国的测试机构提供不同的软件版本进行测试，包括与 ANCAP（澳大利亚新车安全评鉴规程）、I-VISTA（中汽研中国智能汽车指数）、Euro-NCAP (欧盟新车认证程序 / 中心) 、Korea NCAP（韩国新车碰撞测试）等车辆测试中心相关的代码。

  

![](../Images/a1d2374a8224d1ef8486fbdf51533ba1.png)

  

他也提到，这里的代码更改仅与 ADAS 高级辅助驾驶系统有关，与碰撞测试无关。

  

根据这位白帽黑客的说法，“现在有了能够识别不同 ADAS 测试协议的 Autopilot 代码”，他自信地表示“可以说他们正在运行非量产车型的代码”。

对于 Euro NCAP 来说，这听起来可能有点麻烦，毕竟他们刚刚赞扬了特斯拉 Model Y 在此类测试中的完美表现。

  

特斯拉官方至今没有做出解释。有网友猜测是为了避免自动刹车而影响碰撞测试，有网友怀疑是特斯拉不想要机构测试时产出的碰撞数据，也有用户猜测是为了作弊，并可能在专项测试中调整设置，以便取得更好的成绩，但他回怼了数十名粉丝的想法，目前还没有统一的答案。

  

据 Drive，目前 ANCAP 的官方人员表示，他们已经知道这件事情，并将对此展开调查。

  

IT之家了解到，特斯拉经常会吹捧其车辆的安全性，称它们是有史以来最安全的。虽然有些人可能会怀疑马斯克的说法，但全球碰撞测试机构的数据已经证明特斯拉的车型确实非常安全，尤其是新款 Model 3 和 Model Y，毕竟不可能所有测试机构同时出错，但此次“代码门”必然会引起用户质疑，也希望特斯拉方面能尽快给出一个说法。
