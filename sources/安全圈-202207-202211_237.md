# 【安全圈】欧洲历史上最严重的一次DDoS攻击，中国香港也受到影响

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2652017510&idx=3&sn=abae70c30695a74d3c5ec2f1ad6f90f6&chksm=f36fbf26c4183630d15326b24ca852f7da4e13d44678292eb8edaf83a0e902631ef4095e8283&scene=126&sessionid=1681311524#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2652017510&idx=3&sn=abae70c30695a74d3c5ec2f1ad6f90f6&chksm=f36fbf26c4183630d15326b24ca852f7da4e13d44678292eb8edaf83a0e902631ef4095e8283&scene=126&sessionid=1681311524#rd)

**关键词**

DDoS攻击

  

Akamai 表示本次攻击是欧洲历史上最严重的一次攻击，不仅峰值攻击流量达到了 704.8 Mpps，而且攻击范围也远超以往，主要目标地点是中国香港、伦敦和东京。

  

分布式拒绝服务攻击 (DDoS) 通常使用多个“僵尸”或机器人系统，利用多个唯一 IP 地址或机器（通常来自感染恶意软件的数千台主机）。来攻击目标系统的带宽或资源。Akamai 说，新的攻击似乎来自同一威胁参与者，它“无情地轰炸”了同一家东欧公司，该公司在 7 月遭受了 659.6 Mpps 的攻击。

  

![](../Images/577adaf85966b905562aae3eb08b5429.png)

  
  
新的乱码互联网流量比之前的记录保持攻击高出 7%。攻击者针对位于欧洲和北美‍的六个不同的数据中心。在 201 次不同的累积攻击中，用作机器人的唯一 IP 数量也从 512 个增加到 1,813 个。

  

Akamai 表示“攻击者的指挥和控制系统在激活多目的地攻击方面没有任何延迟”，在短短 60 秒内，每分钟活动的 IP 从 100 个增加到 1,813 个。此次袭击的主要目标地点是中国香港、伦敦和东京。
