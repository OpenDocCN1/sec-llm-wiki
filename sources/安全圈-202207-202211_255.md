# 【安全圈】索尼PS5服务器崩溃：所有游戏都进不去

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2652016897&idx=4&sn=a995c4c3dc7930e857995ffb67f27169&chksm=f36fbd41c4183457fc8d6349540c3292cc1cc759c9b465f7be5a743743c3b2d4328654523a56&scene=126&sessionid=1681311524#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2652016897&idx=4&sn=a995c4c3dc7930e857995ffb67f27169&chksm=f36fbd41c4183457fc8d6349540c3292cc1cc759c9b465f7be5a743743c3b2d4328654523a56&scene=126&sessionid=1681311524#rd)

![](../Images/52e85c833f5ae73f436e0d33b8aaf062.png)

**关键词**

索尼  

根据环球tech消息，10日中午开始，大量网友在微博、贴吧等平台反映，自己的索尼PS5无法进入游戏，疑似服务器崩了。几乎所有人都会弹出提示称：“无法使用此内容，无法连接到服务器以确认授权”。

  

甚至不少网友都是在游玩中突然提示，然后就无法继续游戏了，即便是本地存在的游戏也不行，所有游戏全部瘫痪。

  

截止发稿前，还是有大量玩家反馈此问题，但索尼官方还未做出任何回复。

  

![](../Images/2a1a8b86d57ad3756c7fb435b4d9aa85.png)

  

这一波预计会对索尼PS5的口碑造成不小的影响，毕竟前不久他们还进行了官方涨价，已经备受玩家吐槽。

  

![](../Images/343372278adf40eb71bcc5c40217631d.png)

  

目前索尼国内的各大官方电商都已经调价完成，全系上涨400元，入门的数字版售价为3499元，光驱版售价为4299元。

  

据官方文件显示，此次调价针对欧洲、中东和非洲、亚太地区和拉丁美洲地区以及加拿大的部分市场推行，美国不会涨价。
