# 【安全圈】微软承认 Win11 存在用户无法登录的 Bug，现已修复

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2652016421&idx=3&sn=78f858f1f8fe5de4d0e39db110e65dba&chksm=f36fa365c4182a735235d6a623a99e1481f34d2ee53704715e21e8f23c31d8a455da0d05c886&scene=126&sessionid=1681311528#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2652016421&idx=3&sn=78f858f1f8fe5de4d0e39db110e65dba&chksm=f36fa365c4182a735235d6a623a99e1481f34d2ee53704715e21e8f23c31d8a455da0d05c886&scene=126&sessionid=1681311528#rd)

**关键词**

Windows11  

根据网站IT之家 9月9日消息，微软确认了 Windows 11 一个漏洞，可能会导致用户在更新系统并添加新的 Microsoft 帐户用户后，可能无法在第一次重启或注销后登录。

  

![](../Images/a25fc769223c96c014e528e71fffb044.png)

  

据微软称，这是由 KB5016691 更新引起的一个 Bug。IT之家了解到，该更新最初于 2022 年 8 月 25 日推出。目前微软已迅速解决这个问题，并更新了问题报告。

  

在Windows中安装此更新并添加新的 Microsoft 帐户用户后，可能无法在第一次重启或注销后短暂登录。此问题仅影响新添加的 Microsoft 帐户用户，并且仅影响首次登录。

  

此问题仅影响添加 Microsoft 帐户后的设备。它不会影响 Active Directory 域用户帐户或 Azure Active Directory 帐户。

  

如果遇到此问题，它会在短暂的时间后自动解决。需要等待锁屏再次出现，应该能够按预期登录。

  

此问题是使用已知问题回滚 (KIR) 解决的。

  

请注意，解析可能需要长达 24 小时才能自动传播到使用者设备和非托管业务设备。重启 Windows 设备可能有助于更快地将解析应用到设备。对于已安装受影响更新并遇到此问题的企业托管设备，可以通过安装和配置特殊组策略来解决此问题。

  

可以在计算机配置-> 管理模板 -> KB5016691 220722\_051525 已知问题回滚 -> Windows 11 (原始版本) 中找到特殊组策略。

  

组策略使用组策略名称下载：

下载 Windows 11 版本 21H2 - KB5016691 220722\_051525 已知问题回滚

重要事项 安装并配置 Windows 版本的组策略以解决此问题。

  

为了解决这一问题，微软宣布将进行“已知问题回滚”(Known Issue Rollback) ，该功能将恢复到之前推出的 Windows 补丁版本。微软还建议重启你的机器，以修正当前版本分辨率。

  

对于企业管理的设备来说，你需要通过 KIR 组策略来解决这个问题。根据上面微软提供的链接下载，然后按照组策略即可。
