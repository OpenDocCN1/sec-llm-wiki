# 【安全圈】亚马逊云科技推出Amazon GuardDuty 恶意软件检测新功能

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2652016140&idx=4&sn=2246667ee15d0e42def24e8aa184e651&chksm=f36fa24cc4182b5a834380cb5d2a8527c1206bb529319ecab6111ab23a13182c7d61f969829b&scene=126&sessionid=1681311528#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2652016140&idx=4&sn=2246667ee15d0e42def24e8aa184e651&chksm=f36fa24cc4182b5a834380cb5d2a8527c1206bb529319ecab6111ab23a13182c7d61f969829b&scene=126&sessionid=1681311528#rd)

**关键词**

亚马逊云科技  

全球TMT消息，亚马逊云科技进一步扩展 Amazon GuardDuty 的威胁检测范围，新增恶意软件检测功能帮助客户检测运行在其云环境中的恶意软件。该功能开启后，当 Amazon GuardDuty 检测到客户 Amazon EC2 实例或运行在其 Amazon EC2 实例上的容器工作负载有异常时，就会启动针对恶意软件的扫描。

  

在启用 Amazon GuardDuty 恶意软件检测功能的情况下，当 Amazon GuardDuty 检测到工作负载有异常时，会为相关的 Amazon Elastic Block Store ( Amazon EBS ) 卷建立快照，并分析这些快照，此过程不会影响客户云中相关资源的性能。Amazon GuardDuty 创建的快照在扫描结束后会自动删除，同时客户可以自行选择保留包含恶意软件的相关快照。
