# 【安全圈】百日行动｜涉案资金9600万！合肥警方捣毁一特大“帮信”犯罪团伙

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2652009196&idx=1&sn=2894a79ab3ceeefeceb7259f12c43d61&chksm=f36f5eacc418d7ba460c87c3101096eba3b14dcb3a3024f467d2d4613b068bf56945ab9d6e1b&scene=126&sessionid=1681311540#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2652009196&idx=1&sn=2894a79ab3ceeefeceb7259f12c43d61&chksm=f36f5eacc418d7ba460c87c3101096eba3b14dcb3a3024f467d2d4613b068bf56945ab9d6e1b&scene=126&sessionid=1681311540#rd)

**关键词**

百日行动  

  

经过缜密研判、调查，在夏季治安打击整治“百日行动”工作中，合肥市公安局庐阳分局打掉一涉嫌“帮信”（帮助信息网络犯罪活动）的犯罪团伙，抓获涉案人员18人，涉案资金达9600万元。

  

“帮信罪”即帮助信息网络犯罪活动罪。《中华人民共和国刑法修正案(九)》增设了“帮助信息网络犯罪活动罪”，作为刑法第287条之二，其中规定：明知他人利用信息网络实施犯罪，为其犯罪提供互联网接入、服务器托管、网络存储、通讯传输等技术支持，或者提供广告推广、支付结算等帮助，情节严重的，处3年以下有期徒刑或者拘役，并处或者单处罚金。

  

2022年6月，庐阳分局责任区刑警二队在核查一条网络赌博线索时，发现一张银行卡的持有人涉嫌从事违法犯罪活动，且该银行卡内的资金与境外存在频繁流动，交易金额巨大，可能涉嫌为转移网络赌博资金提供帮助。

  

民警立即围绕线索展开调查，在相关部门协助下，共梳理出可疑银行账户200余个。经过对该团伙的组织架构和人员构成进行缜密研判分析，民警最终锁定该团伙的主要犯罪嫌疑人为秦某等人。掌握了大量证据后，7月26日，庐阳分局抽调警力组成抓捕组赴外地将该团伙一举打掉。

  

![](../Images/8535b8110245d147024f28476273ade6.png)

  

经查，2021年9月以来，该团伙主要嫌疑人秦某、韦某某为获取非法利益，联系境外人员，为境外赌博团伙非法转移网络赌博资金，并为此在多地寻找“卡农”从事网络赌博“跑分”，为了扩大非法收益，团伙中的嫌疑人甚至会鼓动、拉拢亲戚朋友帮助其转移网络赌博资金。

  

![](../Images/43e5d95a7e1ca173decbae7ebc2a409f.png)  
![](../Images/b01cbdf7947a033574f114e261982b02.png)

  

经查，该团伙持有的涉案银行卡共计50余张，转移涉案资金9600余万元。目前，公安机关已对秦某等18名犯罪嫌疑人依法采取强制措施，案件仍在进一步深挖中。
