# 【安全圈】意税务局今遭黑客攻击:5天内不交赎金就公布数据!

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2652008654&idx=2&sn=a33512d8a3481c2f444d3283ad34c313&chksm=f36f5c8ec418d5984b96d22415fb75b55141814fa1c34ae09b9f8a813a4df82797c3f38d7dbd&scene=126&sessionid=1681311540#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2652008654&idx=2&sn=a33512d8a3481c2f444d3283ad34c313&chksm=f36f5c8ec418d5984b96d22415fb75b55141814fa1c34ae09b9f8a813a4df82797c3f38d7dbd&scene=126&sessionid=1681311540#rd)

![](../Images/2c6fe467a92020fca0ae82280cb372bb.png)

**关键词**

LockBit、网络泄密

今天上午（25日），黑客组织LockBit宣布从意大利税务局窃取了数据并索要赎金。据意媒消息，意税务局约78GB数据恐已被窃取。  

  

意大利《晚邮报》消息，LockBit组织今天上午在网上发布了相关声明，要求意税务局必须在5天内支付赎金。该组织威胁称，若逾期不付，就将公布他们盗取到的全部文件，包括财务报告和合同等。

![](../Images/a70c4697a4a1b07edd23c8110a13dd28.png)

  

意大利税务局随后要求负责网络安全的Sogei公司展开检查，并确认黑客此番攻击究竟致使哪些信息“被泄露”了。

  

最新消息称，正在调查此案的意大利邮政通讯技术警员和IT专家通过分析LockBit组织黑客发布的一系列攻击截图和可能被盗的数据类型，推测黑客有可能是通过入侵一名用户的资料展开数据盗窃的，而并不是直接入侵了税务局。

  

![](../Images/93a7e64e08100535cd846272e2eedeb3.png)

  

据报道，LockBit组织是一群在全球范围内通过“勒索软件”进行攻击的黑客。另据资料，LockBit这种“加密病毒”主要针对的是企业和政府组织，而非个人。

网络安全平台Swascan首席执行官Pierguido Iezzi指出，该黑客组织极其活跃，今年4-6月已进行了逾200次黑客攻击，是公共和私营企业信息安全的巨大隐患。
