# 【安全圈】巨逼真Youtube广告让用户真假难辨最终导向技术支持诈骗

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2652007776&idx=3&sn=ddf3b1ac70685aab52a505f73a8b7196&chksm=f36f4120c418c8362558d0d72d32fa369c9def26075f365c71b452d25c5188dbc9926052b31d&scene=126&sessionid=1681311540#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2652007776&idx=3&sn=ddf3b1ac70685aab52a505f73a8b7196&chksm=f36f4120c418c8362558d0d72d32fa369c9def26075f365c71b452d25c5188dbc9926052b31d&scene=126&sessionid=1681311540#rd)

**关键词**

YouTube

一个看起来很逼真的 Google 搜索 YouTube 广告正在将访问者重定向到技术支持骗局，这些骗局假装是来自 Windows Defender 的安全警报。

  

今天，网络安全公司 Malwarebytes 披露，他们发现了一个滥用 Google 广告的“重大”恶意广告活动。

  

搜索“YouTube”相关关键字时，搜索结果中显示的第一个广告标题为“YouTube - 最佳 YouTube 视频”或“YouTube.com - YouTube - 为您提供的最佳 YouTube 视频”。

  

  

查看广告，没有任何可疑之处，因为它包含正确的 youtube.com URL，并且还在广告下方显示了其他广告元素，如下所示。

  

![](../Images/122253a41636bc181b926951e91c0975.png)

Google 搜索结果中的虚假 YouTube 广告

来源：BleepingComputer

  

但是，单击广告不会将您带到 YouTube，而是将您带到伪装成来自 Windows Defender 的安全警报的技术支持骗局。

  

根据 BleepingComputer 进行的测试，技术支持诈骗位于 URL http://matkir\[.\]ml和http://159.223.199\[.\]181/上，并警告访问者“Windows 因可疑活动而被阻止”并且 Windows Defender 检测到名为“Ads.financetrack(2).dll”的特洛伊间谍软件。

  

![](../Images/559f16cce20b3bfe29cc379dbde962bb.png)

谷歌 Youtube 广告显示的技术支持骗局

来源：BleepingComputer

  

对于那些使用 VPN 的人来说，好消息是诈骗网站会检查您是否正在运行 VPN，如果是，则将用户重定向到合法的 YouTube 网站。

  

当我们拨打诈骗网站上列出的号码时，我们连接到一个海外呼叫中心，“技术支持”提示我们在我们的设备上下载并安装 TeamViewer。

  

虽然我们不允许继续安装，但他们可能会使用 TeamViewer 控制我们的计算机来“修复”错误。

  

在大多数情况下，诈骗者会以某种方式锁定您的计算机或告诉您您的计算机已被感染并且您需要购买支持许可证。无论哪种方式都会导致昂贵的支持合同，对受害者没有任何好处。

  

Malwarebytes 的一条推文表明，此时恶意广告活动仍在 Google 搜索上运行。

  

这种恶意广告活动之所以如此可怕，是因为它表明威胁行为者可以制作冒充公司的广告来分发恶意软件、网络钓鱼页面或其他类型的攻击。

  

BleepingComputer 已就有关广告的问题与 Google 取得联系，但目前尚未收到回复。
