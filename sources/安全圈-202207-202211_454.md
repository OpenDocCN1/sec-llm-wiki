# 【安全圈】男子自学编程开发外挂非法获利196万余元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2652007776&idx=2&sn=8f3c06bb1d70672a2ba64bef533af1be&chksm=f36f4120c418c836fb1142e32fa353baef603e7504022c59acbcad29419bc60b452a6ee718d0&scene=126&sessionid=1681311540#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2652007776&idx=2&sn=8f3c06bb1d70672a2ba64bef533af1be&chksm=f36f4120c418c836fb1142e32fa353baef603e7504022c59acbcad29419bc60b452a6ee718d0&scene=126&sessionid=1681311540#rd)

**关键词**

外挂  

玩网络游戏想换皮肤，却不想花钱？仅高中学历的技术男周明（化名）联合朋友陈勇（化名）通过开发网游换肤App为某网络公司推广软件获利190万余元。近日，江苏省扬中市检察院以涉嫌入侵计算机信息系统程序罪，依法对周明、陈勇提起公诉。经法院一审判决，周明被判处有期徒刑三年，缓刑五年，并处罚金人民币二十万元；陈勇被判处有期徒刑二年，缓刑三年，并处罚金人民币二万元。

  

![](../Images/7ae0c9b8c0aade62eaab191b50041d76.png)

高中文化自学编程制作

  

1995年出生周明虽然只有高中文化，但却对计算机编程十分感兴趣，自学了C++、E语言编程。2015年3月，当时还是学生的周明痴迷网络游戏，一次游戏中，无意间听见队友谈到一款火爆的换肤“外挂”。

  

正常情况下，绝大部分游戏角色的皮肤效果只能通过游戏活动或充值购买的方式获取，周明朋友推荐的这款“外挂”App却可以直接免费解锁角色皮肤。

  

此时，由于网游公司加大了对第三方插件的打击力度，这些用于换肤的插件越来越难找到。精通网络编程的周明便利用特长自己开发了一个换肤插件供玩家免费下载使用。

  

邀请好友“技术支持”

周明将这款换肤插件搭载在自己开发的换肤网站上后，很快就成了游戏圈“爆款”，每日的下载量惊人。2019年3月，某网络科技公司找到周明，希望在周明的网站上搭载他们公司的下载器，游戏玩家在安装换肤插件的同时捆绑下载数款该公司软件。完成软件推广业务后，该公司根据安装次数结算推广费用，每次0.1元左右。

  

此后，由于周明的换肤插件下载次数过多被游戏公司的安全方案检测到并被其反作弊系统屏蔽。于是周明想到了高中同学陈勇，陈勇是一家网络公司的技术员，科班出身的他很快就看出了其中的“门道”。陈勇告诉周明反作弊系统的检测流程，指导并提供一段代码加入到周明源码中，可以帮助换肤软件绕过检测被游戏玩家继续下载使用。

  

游戏玩家发现后举报

2021年10月，游戏玩家王先生下载并安装了周明的换肤软件，他发现在下载免费插件的同时捆绑下载了很多推广软件，遂通过平台报警。经网络游戏公司后台上报数据统计，直至案发周明的换肤软件影响客户端的日活跃数最高超50万，这意味着该软件至少非法控制了50万个该网游账号。

  

2022年5月23日，扬中市检察院依法对周明、陈勇提起公诉。经审查，2019年3月至2021年1月，周明通过换肤插件程序为某网络公司推广APP软件获利196万余元，分给陈勇10.3万元。经鉴定，该换肤程序属于破坏性程序。2022年7月1日，法院公开开庭审理该案，并作出前述一审判决。
