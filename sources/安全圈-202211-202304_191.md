# 【安全圈】CISA 发布 ESXiArgs-Recover 脚本，可修复 VMware ESXi 勒索软件攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2652030380&idx=2&sn=aa9394cdceb42d2cc86e7a3baeac9213&chksm=f36fe9ecc41860fadbd7be0456e8597e28e43f37f2afb42a5e0d528124af715704e8d3f2780c&scene=126&sessionid=1681311468#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2652030380&idx=2&sn=aa9394cdceb42d2cc86e7a3baeac9213&chksm=f36fe9ecc41860fadbd7be0456e8597e28e43f37f2afb42a5e0d528124af715704e8d3f2780c&scene=126&sessionid=1681311468#rd)

**关键词**

勒索软件

  

意大利国家网络安全局（ACN）于上周日发布警告，已经有黑客利用 VMware ESXi 服务器漏洞，对全球数千台服务器发起勒索软件攻击，并警告组织采取行动保护其系统。

![](../Images/8f046a9342dcf0020c6853f5b6f2f8a6.png)

**美国网络安全和基础设施安全局（CISA）近日发布了 "ESXiArgs-Recover" 脚本，来帮助受影响的用户抵御 ESXiArgs 攻击。**CISA 表示该脚本是根据勒索软件入侵期间未成功加密的虚拟磁盘，重建虚拟机元数据编译的。

CISA 脚本相关说明如下：

ESXiArgs-Recover 工具用于帮助组织恢复受 ESXiArgs 勒索软件攻击影响的虚拟机。

CISA 知道一些组织已报告在不支付赎金的情况下成功恢复了文件。CISA 基于 Enes Sonmez 和 Ahmet Aykac 等公开可用的资源编译了该工具。该工具的工作原理是从未被恶意软件加密的虚拟磁盘中重建虚拟机元数据
