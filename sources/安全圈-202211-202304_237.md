# 【安全圈】泄露 3.5 万用户数据后，微软 GitHub 项目打赏功能不再支持 PayPal 付款

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzE4NDU1OQ==&mid=2652029987&idx=3&sn=240bc4f8e1340188198a63f845f93f63&chksm=f36fe863c41861754858277a34285deb47b13a209c41fa2c37bb1df8e9ea4e285b5ae97931dd&scene=126&sessionid=1681311476#rd](http://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2652029987&idx=3&sn=240bc4f8e1340188198a63f845f93f63&chksm=f36fe863c41861754858277a34285deb47b13a209c41fa2c37bb1df8e9ea4e285b5ae97931dd&scene=126&sessionid=1681311476#rd)

微软 GitHub 官方博客近日发表简短声明，宣布从 2023 年 2 月 23 日起，GitHub Sponsors 项目打赏功能将不再支持 PayPal 支付方式。

赞助人将无法再通过 PayPal 打赏开发者或组织，GitHub 建议赞助人更新支付方式，使用信用卡或借记卡。GitHub 官方对此没有给出更多解释。

![](../Images/08d0fcb4c1907270cd72bfd4eca8a1ed.png "泄露 3.5 万用户数据后，微软 GitHub 项目打赏功能不再支持 PayPal 付款")

此外，使用 PayPal 打赏过开发者的用户将收到提醒邮件。

![](../Images/04adcca1d4734b67ef21b7da3c263f78.png "泄露 3.5 万用户数据后，微软 GitHub 项目打赏功能不再支持 PayPal 付款")

微软 GitHub 和 PayPal 双方都没有就这一事件给出回应，Hacker News 的网友爆料称，合作破裂可能是由于存在安全问题，或者两家公司的谈判破裂了，比如 PayPal 抽成费用可能太高了，或者“可能是 PayPal 虚拟货币洗钱问题”。

IT之家此前报道，PayPal 于 2023 年 1 月 18 日透露，该公司在 2022 年 12 月受到网络攻击，泄露了 34942 条用户个人信息。
