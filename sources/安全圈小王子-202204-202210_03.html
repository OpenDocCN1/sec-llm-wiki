数据迁移

使用过程中可能会遇到机器换新、卸载重装，然后awvs上有一堆扫描数据需要保留。

Awvs 将其所有数据存储在如下目录

Windows：C:\ProgramData\Acunetix

Linux：/home/acunetix/.acunetix

MacOS：/Applications/Acunetix.app/Contents/Resources

我们可以在卸载或搬迁前备份上述文件夹，在新安装前放置于新机器下（目录一致），然后直接运行安装程序，安装时程序会默认读取文件夹中的配置和记录，所有设置和数据都将保留。

重置主用户名和密码

Windows

  1. 从“开始”菜单启动 Acunetix 管理密码工具：

或者运行：

C:\Program Files (x86)\Acunetix\core\ChangePassword.exe
  1. 输入新的电子邮件地址、新密码，并确认新密码，然后单击“确定” 按钮。

Linux

  1. 输入以下命令：
sudo /home/acunetix/.acunetix/change_credentials.sh
  1. 输入新的电子邮件地址、新密码，并确认新密码。
prince@kali:~$ sudo /home/acunetix/.acunetix/change_credentials.sh
Master user found: olduser@example.com
Email (leave empty for using olduser@example.com): newuser@example.com
Using master user newuser@example.com
Password:
Password again:
prince@kali:~$

MacOS

  1. 在终端窗口中，运行以下命令：
sudo /Applications/Acunetix.app/Contents/MacOS/ChangeMasterPassword
  1. 输入新的电子邮件地址、新密码，并确认新密码。
prince@sec-Mac ~ % sudo /Applications/Acunetix.app/Contents/MacOS/ChangeMasterPassword
Password:
Configure the master user
    Email: newuser@example.com
    Password:
    Password again:
Updating

prince@sec-Mac ~ %
