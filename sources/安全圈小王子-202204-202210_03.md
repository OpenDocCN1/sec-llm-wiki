## 数据迁移

使用过程中可能会遇到机器换新、卸载重装，然后awvs上有一堆扫描数据需要保留。

Awvs 将其所有数据存储在如下目录

```


Windows：C:\ProgramData\Acunetix
```

我们可以在卸载或搬迁前备份上述文件夹，在新安装前放置于新机器下（目录一致），然后直接运行安装程序，安装时程序会默认读取文件夹中的配置和记录，所有设置和数据都将保留。

## 重置主用户名和密码

### Windows

1.  从“开始”菜单启动 Acunetix 管理密码工具：

![](../Images/451da0ed61296ee852dfaebb4b2124ae.png)

或者运行：

```

C:\Program Files (x86)\Acunetix\core\ChangePassword.exe
```

2.  输入新的电子邮件地址、新密码，并确认新密码，然后单击“*确定”* 按钮。

![](../Images/a24d97c49d772234eafa93481fca2151.png)![](../Images/40bfe6b1f2196bb90d05adf4af472fc1.png)

### Linux

1.  输入以下命令：

```

sudo /home/acunetix/.acunetix/change_credentials.sh
```

2.  输入新的电子邮件地址、新密码，并确认新密码。

```


prince@kali:~$ sudo /home/acunetix/.acunetix/change_credentials.shfor

 using olduser@example.com): newuser@example.com
```

### MacOS

1.  在终端窗口中，运行以下命令：

```

sudo /Applications/Acunetix.app/Contents/MacOS/ChangeMasterPassword
```

2.  输入新的电子邮件地址、新密码，并确认新密码。

```


prince@sec-Mac ~ % sudo /Applications/Acunetix.app/Contents/MacOS/ChangeMasterPassword
```
