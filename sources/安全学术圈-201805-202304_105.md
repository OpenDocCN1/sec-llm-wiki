# 2022年上海市计算机软件评测重点实验室开放课题

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5MTM5MTQ2MA==&mid=2247487368&idx=1&sn=0943aaab7144aa1b43900211aa0900f3&chksm=fe2ef003c95979152995ef9bd18dbad3f2b01a710ff9e08d8f73e29bb498fa6962819751b573&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU5MTM5MTQ2MA==&mid=2247487368&idx=1&sn=0943aaab7144aa1b43900211aa0900f3&chksm=fe2ef003c95979152995ef9bd18dbad3f2b01a710ff9e08d8f73e29bb498fa6962819751b573&scene=27#wechat_redirect)

上海市计算机软件评测重点实验室（以下简称“重点实验室”）是上海市科学技术委员会设立的重点实验室，依托单位是上海计算机软件技术开发中心。作为全国最早的第三方专业测评机构之一，重点实验室具有三十余年的丰富行业经验，专业从事计算机软件工程、软件质量、信息安全等级保护测评、软件测试与评估、网络监测技术的研究，提供故障定位与性能调优服务，为信息系统提供全过程的质量保证专业服务，具有国家级信息软件测评服务业标准化试点单位、国家涉密信息系统甲级资质证书，有多名政府特贴、上海市技术带头人、上海市青联委员、ISO/IEC国际标准化组织中国专家代表、上海市三八红旗手、研究员、高级工程师在内的中青相结合的研发队伍。

重点实验室注重软件工程学、软件开发方法、软件使用与构件技术、软件质量保证、软件度量学、软件法律等方面的研究，以及人工智能、大数据、云计算、网络空间安全等领域的技术跟踪。重点实验室承担了多个国家科技攻关项目、国家八六三项目、上海市重点攻关项目及国家科委、电子部项目，多次获得上海市科技进步奖。牵头制定了多项软件工程国际标准、国家标准以及行业标准，其中GB/T 25000.10、GB/T 25000.51等国家标准被测评专业机构所广泛使用。

重点实验室拥有自动化测试工具、白盒分析工具、安全测评工具、渗透测试工具等各类科研工具设备价值达5000万元，独立研制信息系统试验平台、网络空间安全试验平台。具有CNAS实验室认可、CNAS检验机构认可、ISO/IEC 20000 IT服务管理体系认证、全国信息安全等级保护测评机构、信息安全风险评估资质、信息安全服务资质认证、CMA检验检测机构资质认定、GB/T 19001质量体系认证和ISO/IEC 27001信息安全管理体系认证。近三年完成各类测评项目超万项。

为了营造实验室创新、求实、开放交流的学术氛围，更好的促进软件测试与质量的新技术研究，设置了重点实验室开放课题基金。该基金用于资助围绕实验室研究方向、创新性强的软件测试与质量、人工智能、大数据、云计算、网络攻防、数据安全相关领域的基础研究或应用基础研究课题。重点实验室诚挚邀请软件行业相关领域的研究人员踊跃申请开放课题基金项目。

#### 资助领域

本开放课题所资助范围涉及软件测试、大数据、云计算、人工智能、网络攻防、数据安全等方向。

#### 申报条件

1.  凡具有博士学位或高级技术职称（含副高级职称）的国内上述专业科技工作者（不包括本实验室专职研究人员）均可作为第一申请人提出申请。不具有高级技术职称或博士学位的申请者，须由两名具有高级职称的同行专家推荐。
    
2.  申请人应在相关领域有相当的技术积累，且有稳定的科研队伍支持项目执行。
    
3.  申请项目应具有创新的学术思想，解决的科学问题要明确，研究路线或技术方案可行，研究重点突出，考核目标明确。
    
4.  目前已经承担了实验室开放课题并且未通过验收的课题负责人不在本次申报范围。
    

#### 资助方向

1.  软件测试方法研究，包括但不限于基于需求的测试覆盖率度量，缺陷预测和故障定位方法，自动化接口测试方法，微服务架构的性能测试，人工智能应用的形式化验证。
    
2.  大数据或云计算中的测试技术，包括但不限于大数据系统基准测试、大数据系统测试调优、大数据数据质量评估技术、数据湖或数据中台技术、云环境中的软件测试技术等。
    
3.  人工智能深度安全技术研究，包括但不限于人脸对抗攻击与防御（如防止照片、面具、3D模型攻击等）、自动驾驶系统对抗攻击与防御（基于物理环境的攻击、基于虚拟仿真环境的攻击）、虚假内容验证识别等。
    
4.  网络攻防方向研究，包括但不限于网络和软件异常检测，小样本、加密网络攻击表征及检测，多模态恶意软件检测，对抗样本生成与检测，漏洞检测、挖掘、利用与验证技术等。
    
5.  数据安全方向研究，包括但不限于数据生命周期安全风险分析、安全服务体系、安全标准及测评体系，基于数据分析的识别技术，访问控制技术和安全处理技术，面向保护隐私的多方安全计算、差分隐私、联邦学习等。
    

#### 资助强度与研究年限

上述开放课题的资助强度为每项4万元，研究年限原则上不得超过2年。

#### 申请要求（程序）

1.  本开放课题申请指南公开发布。凡符合要求、有意申请的自然人均可填写附件中的《开放课题申请书》，按照要求认真填写后申请。
    
2.  申请人按申请书规定的格式，认真、如实填写《开放课题申请书》。申请人所在单位或学术主管部门应签署意见，单位领导在申请书上签字并加盖单位公章。
    
3.  所有申请均须报送电子版申请书和纸质版申请书原件1份，电子版申请书和纸质申请书的内容必须一致。难以电子化的附件材料随纸质申请书一并报送。所有书面文件请采用A4纸双面印和普通纸质材料做封面；不采用胶圈、文件夹等带有突出棱边的装订。
    
4.  评审将按照“依靠专家、发扬民主、公平公正、择优支持”的原则，由实验室学术委员会对申请者提交的申请书进行评审，确定资助项目和金额，并通知获得资助的申请人。
    
5.  项目评审通过之后，项目责任人应全面负责项目的实施，并指定1名项目接口人，定期（每月一次）向本实验室汇报项目的执行和进展情况。如果项目不能如期完成或负责人发生出国/调离，无法按计划实施项目，实验室有权中止经费支持。
    
6.  课题考核指标：（1）以第一作者双方署名单位完成在核心期刊或学术会议公开发表学术论文5篇以上，其中4篇以上应为EI或者SCI检索；（2）课题技术报告及结题报告各一份；（3）培养研究生3名。
    
7.  由本实验室资助的开放课题所发表的论文、论著、研究报告、资料、鉴定证书以及申报成果时，研究成果及知识产权为本实验室和研究者所在单位共有，所发表的论文或其他技术文件中，论文第一作者单位须为重点实验室（单位排序不限，署名形式如：XXX1,2  2上海市计算机软件评测重点实验室或2 Shanghai Key Laboratory of Computer Software Evaluating and Testing）。课题研究过程中培养的研究生需在毕业论文中体现重点实验室（企业导师、致谢等形式）。
    
8.  本年度开放课题的申请起始日期为2022年2月25日，截止日期为2022年3月11日。
    
9.  本年度通知立项的最晚通知时间为2022年3月18日。
