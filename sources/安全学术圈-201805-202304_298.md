# 期刊透视：CCF C类 IET Information Security

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5MTM5MTQ2MA==&mid=2247485051&idx=1&sn=a6f546f3f89322739b20e13acb778f94&chksm=fe2ef9f0c95970e666b7a4dc4c4e2379a02ea1f6e045a105ea29ae528385af6a5d62c0317b64&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU5MTM5MTQ2MA==&mid=2247485051&idx=1&sn=a6f546f3f89322739b20e13acb778f94&chksm=fe2ef9f0c95970e666b7a4dc4c4e2379a02ea1f6e045a105ea29ae528385af6a5d62c0317b64&scene=27#wechat_redirect)

IET Information Security的前身为IEE Proceedings - Information Security，由IET于2007年更为现名出版，是信息安全领域享有较好声誉的期刊，主要发表信息安全、密码学领域的原创性研究成果，是中国密码学会推荐的B类期刊，同时也是CCF推荐的网络与信息安全领域的C类期刊。发文量、IF与分区  
▌近11年发文量

期刊于2007年更为现名，2007～2013年为季刊，从2014年更为双月刊；近11年的发文量如下图所示，期刊发文量小，且各年发文量的差距不大。2020年，1～4期共刊文48篇，估计2020年发文量与2019年相差不大。

![](../Images/6d2287d78120db37b0d9e700f7a4df69.png)

▌近9年IF

期刊近9年的IF如下图所示，期刊近年的IF在1附近波动。IET旗下期刊的共同特点是IF较低，但都是老牌期刊。

![](../Images/cf2878ed3cbf94b221b1d1c5d2c44071.png)

▌JCR分区

根据2020发布的期刊引证报告，此刊的JCR分区情况如下图所示，同2018年分区完全一致，但期刊在各学科的排名稍有不同：

*   在“计算机：信息系统”学科，此刊从2018年的131/155（排名/期刊总数）下降到2019年的133位；
    
*   在“计算机：理论方法”学科，从2018年的71/105（排名/期刊总数）下降到2019年的73位。
    

![](../Images/8b28a1deac40f439dfc40095cb05646b.png)

▌中科院分区

根据中科院分区基础版（13个大类学科）、升级版（18个大类学科），刊物均为4区期刊，升级版仅将大类学科更为“计算机科学”，其他信息未发生变化。

![](../Images/464832c5392769abb94888ca65252287.png)

国别与机构统计  
▌国别统计

针对期刊2018、2019年度所刊的论文（140篇），统计作者所属的国别信息，如下图所示。中国、伊朗、印度分别发文63篇、18篇、16篇。

![](../Images/94b51e34720e7f47e1555a3af8774df4.png)

▌机构统计

针对期刊2018、2019年度所刊的论文（140篇），统计作者所属单位，如下图所示。中科院、西电、台湾的逢甲大学分别发文16篇、5篇、3篇；国外发文较多的机构为伊朗科技大学，发文仅3篇。

![](../Images/d73a64020a2938810dac2602c2593f4e.png)

自引情况  

期刊近年来的自引情况如下图所示，2012年的自引率较高，达到21.03%，其后各年的自引率较低。

![](../Images/2dea3354a008a99b3f66a771ff9e024d.png)

审稿周期统计  

从期刊最新发表的论文中随机抽取29篇论文，统计所有论文的录用周期。

▌一审周期

统计所有论文的一审周期，如下图所示，其中最短时间为6天，最长周期为477天。基于平均数、中位数得到的一审统计时间分别为222、192天。综合两种方法，一审平均周期为207天时间。

![](../Images/b513e74364bcbc64198749ee450f0f4c.png)

基于所有论文的一审周期，拟合论文的一审周期概率分布图，如下图所示，可以看到，约65%的论文在250天内完成一审返修。

![](../Images/1816a7502d591ba52660935c4b0b102e.png)

▌二审周期

统计所有论文的二审周期，如下图所示，其中最短时间为11天，最长周期为266天。基于平均数、中位数得到的二审统计时间分别为71、40天。综合两种方法，二审平均周期为56天时间。

![](../Images/a2b4fd7b7db42bfac63e8c7b1c14500a.png)
