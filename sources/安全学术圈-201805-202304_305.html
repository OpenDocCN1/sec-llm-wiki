0-引言

黑客可能会利用应用协议（DNS, HTTP, MQTT）的漏洞和数据库直接交互。

这篇论文主要focus在入侵检测技术，特别是针对物联网网络中使用的DNS，HTTP和MQTT协议的僵尸网络攻击。基于对潜在属性的分析，本文生成了新的统计流特征，并基于三个模型（决策树，朴素贝叶斯，人工神经网络）生成了AdaBoost模型，来验证这些特征的效果，并对恶意事件进行检测。

数据集：UNSW-NB15 ， NIMS botnet datasets 和模拟的IoT传感器数据

实验结果表明，利用相关性和相关系数测度，所提出的特征具有正常和恶意活动的潜在特征。此外，与框架中包括的每个分类技术和其他三个最新技术相比，AdaBoost的实验结果具有更高的检测率和更低的误报率。

1-介绍

IoT服务通过TCP/IP模型中的网络协议（DNS，HTTP，MQTT）来运作。

网络系统被分为四层。每一层由不同的协议组成，并和其他网络中的对应物进行交流。在部署IoT服务时，我们需要将中间件工具（例如Node-Red）连接到物理设备（例如温度和光传感器），然后将这些传感器生成的数据通过 TCP / IP传输到IoT中心。其中：

  • MQTT协议：为硬件性能低下的远程设备（e.g. 传感器）以及网络状况糟糕的情况下而设计的发布/订阅型消息协议，通过TCP运行，用于将中间件的数据发送和接收到IoT中心。

  • DNS协议是连接到Internet或网络的分层分布式系统，用于将domain映射到IP地址。

  • HTTP协议交换富文本信息，使用请求-响应机制，并依赖于C/S架构。客户端向服务器提交HTTP请求消息，然后服务器向客户端返回响应消息，提供诸如HTML文件的资源。

攻击者通常会利用这些协议里存在的漏洞或限制来攻击IoT设备。e.g. polymorphic code(多态代码), DNS spooﬁng（DNS欺骗）, DNS cache poisoning（DNS缓存中毒）, denial of service (DoS), distributed DoS (DDoS), exploits and URL interpretation（URL钓鱼）.

为了抵御IoT面临的网络攻击，这篇论文提出了一个基于AdaBoost集成学习算法的NIDS系统，基于统计流特征来识别恶意僵尸网络行为。


通过对多个应用协议抽取网络流特征，来构造模型做检验。源头数据抽取自UNSW-NB15 ， NIMS botnet datasets 和IoT AWS hub上的网络流量，通过Bro-IDS tool和一个新的抽取模块来捕获流量并抽取特征

本文主要贡献：

  1. 基于mqtt, dns, http 的基础流量对特征进行抽取，对IoT带宽要求较低（特征采集复杂度低）

  2. 新的数据源头：源头数据抽取自UNSW-NB15 ， NIMS botnet datasets 和IoT AWS hub（温度传感器，光传感器，湿度传感器）上的网络流量

  3. adaboost组合模型

2-Background and related work

2.1-NIDS技术

一个典型的NIDS包含以下四个步骤：

  1. 数据源

  2. 数据预处理：去掉无效的特征，生成能有效识别合法行为和非法行为的特征

  3. 分类模型

  4. 应急响应：运营人员对告警进行运营


NIDS技术主要分为三类：

  1. 误用模型（从黑的出发）：高准确率，低误报率，不能识别0day

  2. 异常模型（从白的出发）：能识别0day，不用投大量人力在规则维护上，可移植性好，重点在分类模型部分很难非常有效。

  3. 混合模型（误用 + 异常）


当前已有很多研究者通过集成方法来提高NIDS的效果，根据经验来看，所有的hybrid/ensemble 技术的效果都比单个模型的效果好。

2.2-TCP/IP协议下的NIDS和IoT技术

NIDS使用到的网络特征，通常可以被划分为以下四类：

  • source and destination port numbers-based features

    • 抽取工具：Coral-Reef and Netﬂow tools.

    • 这些特征几乎无效，因为它们仅从当代网络环境中高度不可信赖的数据包报头中获取简单信息，以识别在动态变化网络下的攻击。

  • payload-based features

    • 捕获已知应用的重要信息，能够帮助找出恶意行为，高准确率。

    • 端口与端口之间，流量信息相互独立

    • 更新不同攻击类型的流量特征很麻烦

    • 从高网络流量率中捕获它们也很困难

  • behavior-based features

    • hosts之间的交互信息

    • host自己的行为模式

  • ﬂow-based features

    • 基础的流信息：src ip，dst ip ,ports, 协议

    • 基础的统计信息：到达时间，包大小

如果利用好了第三、四类特征，会达到较高的准确率。即behavior-base features和flow-based features

3.3 特征类型

  • flow-based features ：从原始信息包中抽取出来的

    • src-dst ip, ports

    • 协议类型

    • 数据长度

    • header信息

    • transactional features：根据packet的session time做时间划窗，实现实时检测

  • service-base features:

    • http和dns协议的基础信息

    • DNS features：DNS请求的回复字段和域名，统计信息包括query和answer属性的平均值

    • HTTP features：http的请求和响应，操作码，method字段、url字段的长度和平均值

实验表明，统计特征可以定义具有合法和恶意实例模式的协议的基本信息。这是因为统计特性可以通过删除泛洪攻击(如DoS和DDoS[24])时出现的冗余观察信息来聚合流量。这些类型的攻击会发送大量的流来中断受损主机的资源。此外，transactional 特征可以帮助NIDS区分正常活动和异常活动之间的潜在差异，因为它们包含关于多个属性的信息，例如每个特定时间的源/目标ip和端口，并且不能使用现有的流导出器生成它们。这些特性可以在运行真正的NIDS时轻松创建;因此，如果决策引擎设计正确，它们可以帮助设计可靠的NIDS。

4-模型

集成学习的框架

  1. feature set

  2. 特征选择：用cc选出最不相关的特征

  3. 用组合方法来分类

4.1-特征选择方法

直接用cc计算，然后选取最不相关的N个特征。

cc的值分布在[-1, +1]之间

  • 如果越靠近+1，表明两个特征越正相关

  • 如果越靠近 -1，表明两个特征越负相关

  • 如果越靠近0，表明两个特征越不相关

 

4.2-组合分类模型

正常流量和恶意流量的区别较小。选择这三个基础分类器的原因是每个分类器都有不同的核函数，如概率（NB）, 权重（ANN），特征（DT），因此把它们集成到一起，能弥补各自的不足，获得更好的分类效果。

用adaboost的原因：

这使我们可以在训练阶段通过重新分配权重来优化结果。基础学习器错误分类的每个样本在下一轮训练阶段将获得更高的权重。Adaboost的关键是在训练阶段频繁利用基础学习器来更改形式，从而为选定的迭代次数创建一系列基础学习器。

5.2-评价指标

  • True positives（TP，真正） : 预测为攻击，实际为攻击

  • True negatives（TN，真负）：预测为正常，实际为正常

  • False positives（FP，假正）: 预测为攻击，实际为正常

  • False negatives（FN，假负）：预测为正常，实际为攻击
