随着科技的飞速发展，用户数据变得无处不在。大数据时代无论是金融授信风控或在线营销等都离不开数据。数据共享日益重要，但数据安全难以得到有效保障，出现了数据泄露和滥用等诸多问题。近年来，随着欧盟《通用数据保护条例》（GDPR）和其他国家法律的生效，用户隐私和数据安全问题受到了广泛关注，被提到了一个新的高度。因此，如何在满足数据隐私和法规遵从性要求的同时，打通数据孤岛，构建更好的人工智能系统，对传统的机器学习范式提出了巨大挑战。不同领域的学者以及工业界的研究人员从不同的角度提出了应对上述挑战的多种思路，以提高人工智能系统的隐私和安全性。借此我们期望把来自不同背景和领域的研究人员连接起来，交流学科领域研究以及工业实践的进展。

CCS是计算机安全和隐私领域国际顶级会议。蚂蚁在CCS 2020举办本次研讨会，期望提供更多的机会来连接CCS社区和机器学习社区的研究人员。本次研讨会旨在为来自不同背景和领域的研究人员提供一个论坛，共同讨论隐私保护机器学习技术的最新学术进展，以及从实际应用/部署中汲取的宝贵经验教训。此次隐私保护机器实践学习研讨会（ Privacy Preserving Machine Learning in Practice, PPMLP）包括但不限于以下技术和应用：

•Secure multi-party computation techniques (e.g., secret sharing and garbled circuit)  

•Homomorphic encryption techniques•Trusted execution environment (TEE) based approaches•Centralized and decentralized protocols for learning on encrypted data•Differential privacy•Privacy-preserving machine learning methods (e.g., privacy-preserving LR, privacy-preserving neural networks)•Collaborative learning / federated learning•(Privacy-preserving) transfer learning•Multi-party secure fraud detection•Privacy-preserving recommendation•Privacy-preserving marketing/retailing•Privacy-preserving crowdsourcing/mobile crowdsourcin
