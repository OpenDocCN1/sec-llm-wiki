# 安全研究实验室巡礼——新泽西州立罗格斯大学安全实验室

本周的安全研究实验室巡礼带大家走进美国新泽西州Rutgers大学安全实验室。该实验室由马仕青（https://www.cs.rutgers.edu/~sm2283/） 助理教授（博导）领导。马仕青博士是 NDSS 2016 和 USENIX Security 2017 最佳论文奖获得者，实验室致力于软件和系统安全，人工智能安全和程序分析与验证方向，包括对 Linux 内核的增强，软件模糊测试，深度神经网路的攻击防御和验证，基于 LLVM 等工具的程序分析和验证等。

  

当前实验室的主要研究方向包括：

*   Attack provenance system
    

*   Building provenance aware OS and applications in various environment (OS, Cloud)
    
*   Building infrastructure to support provenance analysis
    
*   Provenance analysis using DNN and program analysis
    

*   IoT/CPS security
    

*   IoT/CPS system testing and enhancement via program analysis
    
*   IoT/CPS system verification
    

*   AI security
    

*   Backdoor attacks and defenses
    
*   Adversarial example attacks and defenses
    
*   DeepFake attacks and defenses
    

*   Software security
    

*   Cross software stack isolation
    
*   Compiler based fuzzing and de-fuzzing techniques
