   PLDI会议全称为“ACM SIGPLAN conference on Programming Language Design and Implementation”，是程序语言和编译技术领域顶级的会议，创办于1979年，每年一届。其论文范围包括语言设计、语言实现、程序分析、编程模型和程序逻辑等围绕程序设计语言的理论和技术。

    PLDI 2020是CCF A类，截稿于2019年11月22日，会议时间为2020年6月15日，会议地点：英国伦敦。


   PLDI最有影响力论文奖项是依据论文10年内的影响力进行评选的，因此获奖论文发表时间早于获奖时间10年。下面我们来盘点一下近20年（2000年-2019年）的PLDI最有影响力论文。

    其中，15年最有影响力论文《Pin: building customized program analysis tools with dynamic instrumentation》引用次数和下载次数均居首位，17年最有影响力论文《Valgrind: a framework for heavyweight dynamic binary instrumentation》和13年最具影响力论文《The nesC language: A holistic approach to networked embedded systems》仅居其后。
