    好奇什么样的会议论文最“吸粉”吗？今天为大家统计的是**1981年至2019年**期间计算机安全领域顶级会议发表的论文在谷歌学术(Google Scholar）引用次数Top 100的优质论文。下面我们一起来看看！  

![](../Images/a25b54d16cd38d243be47a06444d66f8.png)

哪家顶会的论文受欢迎？

    统计数据显示，Top 100分别来自ACM Conference on Computer and Communications Security (**CCS**)、Annual Computer Security Applications Conference (**ACSAC**)、European Symposium on Research in Computer Security (**ESORICS**)、IEEE Computer Security Foundations Symposium (**CSF**)、IEEE European Symposium on Security and Privacy (**Euro ****S&P)**、IEEE Symposium on Security and Privacy (**S&P)**、International Symposium on Research in Attacks, Intrusions and Defenses (**RAID**)、Network and Distributed System Security Symposium (**NDSS**)、USENIX Security Symposium等9个会议。

    其中，CCS占比最多，共**37**篇论文入围TOP100；S&P紧随其后，共30篇论文入围。排行榜首位是Mihir Bellare 和 Phillip Rogaway于1993年在CCS上的《Random Oracles are Practical: A Paradigm for Designing Efficient Protocols》，引用次数为5132次。

那些年发表的论文

    引用次数TOP 100的论文中，最早的发表于1982年，是Joseph A. Goguen 和 José Meseguer发表在IEEE Symposium on Security and Privacy（S&P）上发表的《Security Policies and Security Models》，1981年至2019年期间被引用了2549次，排名第九。最新的发表于2017年，也是S&P收录的，Nicholas Carlini 和 David A. Wagner的《Towards Evaluating the Robustness of Neural Networks》，引用次数1564次，排名34。2002年发表的论文最受欢迎，有11篇论文入围TOP100。
