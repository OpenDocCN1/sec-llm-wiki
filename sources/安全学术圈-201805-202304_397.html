关于成员推理攻击（Membership Inference Attack）可行性的早期演示有很多关于敌手的假设，例如使用多个所谓的影子模型（shadow model），了解目标模型结构知识， 使用与目标模型的训练数据分布相同的数据集等。本文放宽了所有这些关键假设表明这类攻击以低成本而广泛适用，从而构成比先前想象的更严重的风险。通过对这一新出现和发展中的威胁进行最全面的研究，这些数据表明了所提出的攻击跨领域（across domains）的可行性。此外本文还提出有效的防御机制以抵御这类更广泛的成员推理攻击，保持机器学习模型的高实用水平。

一、研究现状

Shokri等人提出了针对机器学习模型的第一次成员推理攻击。这种攻击背后的想法是使用多个机器学习模型(每个预测一个类）称为攻击模型，用于对目标模型的输出，即后验概率（posterior probabilities)进行成员推理。假设目标模型是一个黑盒API，Shokri等人建议构造多个影子模型，以模拟目标模型的行为，并导出训练攻击模型所需的数据，即后验和真实（ground truth）的成员情况。

Shokri等人提出了两个主要假设。首先，攻击者需要建立多个阴影模型，每个模型与目标模型具有相同的结构。这已经实现了-通过使用相同的机器学习即种服务(MLaaS)来训练目标模型来构建影子模型。第二，用于训练阴影模型的数据集来自与目标模型的训练数据相同的分布，这一假设适用于大多数攻击的评估。作者进一步提出了人工合成数据来放宽这一假设。然而出于效率原因，这种方法只能适用于包含二分特性的数据集。

这两个假设要求相当高，大大减少了成员关系推断攻击ML模型的范围。在本文中将逐步放宽这些假设，以表明更广泛适用的攻击场景是可能的。调查表明，实际上在ML中的成员推理可以比先前考虑的使用的假设更少—从而更容易地执行。为了纠正这种情况进一步提出了两种有效的防御机制。

二、准备工作

本文利用8个不同的数据集进行实验。其中6个数据集与Shokri等人使用的数据相同，即MNIST、CIFAR-10、CIFAR-100、Location、Purchase、Adult。按照相同的程序对所有这些数据集进行预处理。

此外，本文利用另外两个数据集，即News和Face，用于评估。

News。News数据集(20个新闻组)是用于文本分类和聚类的最常见的数据集之一。该数据集由20，000个新闻组文档组成，这些文档被分类为20个类。属于每个类的数据点数非常相似，即数据集具有均衡的类分布。首先通过移除头、页脚和引号来预处理News数据集文件。然后从原始文档中构建tf-idf矩阵。

Face。Face数据集由大约13，000张从网络上爬出的人脸图像组成。它是从1，680名参与者中收集的，每个参与者至少有 数据集中的两个不同的图像。在评估中只考虑超过40张图片的人，即19个类别。对于面部识别来说，Face数据集具有挑战性因为图像是从网络上获取而不是在实验室等受控环境下进行的。同样值得注意的是，这个数据集是不平衡的。

三、面向模型无关的成员推理攻击-敌手1

（towards model independent membership inference attacks，adversary 1）

（1）概述

对于第一个对手，假设他的数据集来自与目标模型的训练数据相同的分布。在这里集中于放松对影子模型设计的假设。第一个简化即使用一个阴影模型而不是多个。然后提出了第二个简化方案，这使得对手从对目标模型结构的了解中解脱出来。

（2）一个影子模型（One Shadow Model）

敌手的训练方法可分为影子模型训练、攻击模型训练和成员推理三个阶段。对手在攻击中只使用一个影子模型和一个攻击模型，而Shokri等人的方法采用多个阴影模型和多个攻击模型(每个类一个)。特别是，由于每个影子模型都是通过MLaaS建立的，这种策略将大大降低她的成员推理攻击的成本。

为了训练影子模型假设敌手有一个数据集，该数据集来自与目标模型的训练数据相同的分布。进一步假设阴影模型使用相同的ML算法并且具有与目标模型相同的超参数。要在实践中实现这一点，敌手可以依赖构建目标模型的同一个MLaaS提供者，也可以执行模型提取来逼近目标模型。在本节的后面将展示这个假设也可以放松。

上图描述了第一个敌手的表现。一般来说，与以前的工作相比本文的有一个非常相似的成员推理。例如，对CIFAR-100数据集的攻击在精确率（precision）和召回率（recall）方面达到0.95，而Shokri等人的攻击具有0.95精确率和0.94的召回率。同样有趣的是本文的攻击既适用于平衡数据集(如CIFAR-10)，也适用于不平衡数据集(如Face)。

（3）目标模型结构（Target Model Structure）

上述攻击的一个假设是，敌手知道目标模型的算法和超参数，并以同样的方式实现他的影子模型。接下来展示如何放松这一假设。首先关注目标模型的超参数（hyperparameter），然后是使用的分类器类型。

为了在不了解目标模型的情况下对攻击进行改进，要构造一组ML模型，每个模型都有不同的分类算法，并将它们合并为一个影子模型。每一个ML模型都被称为次影子模型（sub-shadow model）。这可以实现因为分类器的类型是有限的。这种攻击也称为组合攻击（combining attack），可以学习不同分类器的行为，因此可以假设有一个次影子模型，它使用与目标模型相同的分类器进行训练。

在Purchase-100数据集上进行了一个本地实验以评估这一攻击。采用三种流行的ML分类器，即多层感知器、随机森林(1，000棵树)和逻辑回归作为次影子模型。Purchase-100数据集的目标模型是一个多层感知器。为了进行更完整的比较，进一步构建了另外两个目标模型分别基于随机森林模型和逻辑回归模型，并使用相同的算法建立单一影子模型。上表列出了结果，当目标模型为多层感知器和逻辑回归时，组合攻击具有相似的性能。同时，当目标模型是随机森林时攻击性能相对较差。

总之，组合攻击可以使攻击者从目标模型中解脱出来，从而进一步扩大了成员推理攻击的范围。

四、面向向独立于数据的成员推理攻击-敌手2

（towards data independent membership inference attacks，adversary 2）

（1）概述

对于这个敌手，假设他没有来自目标模型训练数据相同分布的数据。另外，敌手不知道目标模型的结构。这在很大程度上降低了敌手的攻击能力。这是一个比前一个更现实的攻击场景。在此设置中，本文提出了一个用于成员推理的数据传输攻击（data transferring attack）。在这种情况下，Shokri等人建议多次查询目标模型，生成合成数据以训练影子模型。然而这种方法只能在数据集具有二分类特征的情况下应用，相反本文的方法可以应用于攻击任何类型数据的ML模型。

（2）数据传输攻击

具体来说接受用不同的数据集训练单个影子模型。这意味着此处的影子模型不是用来模拟目标模型的行为，而是只用于捕获机器学习训练集中数据点的成员状态。数据传输攻击的主要优点是敌手不需要查询目标模型以生成合成数据，这意味着数据传输攻击效率更高，成本更低，也更难被MLaaS供应商检测到。

数据传输攻击的主要优点之一在于它的适用性。Shokri等人提出的合成数据生成策略不能应用于任意类型的数据集，而只能是具有二分特征的。即使是二分特征数据集，单个合成数据点也需要对目标模型进行156次查询。考虑到ML模型和MLaaS的按查询付费业务模型所需的大量数据集，这是非常昂贵的。此外，向MLaaS API发送大量查询将警告服务器，这甚至可能不允许对手完成其合成数据生成过程。而数据传输攻击没有上述任何限制。

x轴表示被攻击的数据集，即目标模型被训练的数据集，y轴表示 用于训练影子模型的数据集。与图对角线上列出攻击结果的第一个敌手相比，第二个敌手在多个情况下获得了相似的性能。例如，使用Face数据集攻击CIFAR-100数据集，无论是精确率还是召回率，结果都是0.95，而对于第一个敌手，对应的结果也是0.95。在一些情况下甚至观察到比第一个敌手的性能提高。例如，使用Purchase-10数据集攻击News数据集可以达到0.93的精确率和0.92的召回率，而敌手1的为0.88和0.86。更有趣的是，在许多情况下，来自不同领域的数据集可以有效地相互攻击，例如，News数据集和CIFAR-100数据集。

五、独立于模型和数据的不经训练的成员推理攻击-敌手3

（1）概述

（model and data independent membership inference attack without training，adversary 3）此敌手不使用任何影子模型，即攻击仅依赖于目标模型在使用目标数据点进行查询时获得的结果，根本不需要任何训练流程。实验表明目标模型的后验统计量，如最大值和熵，可以很好地区分成员数据点和非成员数据点。为了进行具体的成员推理，本文提出了一种阈值选择（Threshold Choosing）方法。实验表明这种简单的攻击仍然可以实现对多个数据集的有效推理。

（2）阈值选择

攻击者可以根据他的需求选择成员推理的阈值，如果他更多地关注推理的精确率(召回率)，那么可以选择一个相对较高(低)的阈值。

本文提供了一种选择阈值的通用方法。具体而言接受目标数据点的特征空间中生成一个随机点样本。对于图像数据集，包括CIFAR -10，CIFAR-100，MNIST和Face，生成随机图像，其中每个像素的值是从均匀分布中提取的。对于具有二分特征的数据集，包括Location数据集和Purchase数据集，根据无偏硬币翻转（unbiased coin flip）为每个特征生成0和1。

（3）结果

上图比较了三次攻击的性能，即精确率（a）和召回率（b）。特别展示了数据传输攻击(敌手2)的最佳性能。正如看到的，前两个敌手在大多数数据集中实现了非常相似的性能。另一方面，第三个敌手在最小的假设下的表现只是稍微差一点(特别是在精确率方面)。这些结果清楚地证明了成员推理攻击是非常广泛地适用的，因此相应的风险比先前显示的要严重得多。

六、防御

（1）丢弃（dropout）

完全连通的神经网络包含大量的参数，容易发生过拟合。基于经验证明，丢弃是减少过度拟合的一种非常有效的方法。在一个完全连通的神经网络模型中，通过在每次训练迭代中随机删除一个固定的边缘比例(丢失率)来执行该算法。本文对目标模型的输入层和隐藏层都应用了丢弃法。本文把默认的丢弃率设为0.5。

更有效的丢弃会导致过度拟合情况更大减少，从而更好地抵御成员推理攻击。这些结果支持Shokri等人的论点。过拟合是成员隐私风险和目标模型性能的共同敌人。无论过高或过低的丢弃率都会导致目标模型的低性能。这意味着当丢弃率处于中间时，目标模型的准确性最强。总之，0.5丢弃率是这种防御技术的合适选择。

（2）模型堆叠（stacking）

丢弃法是有效的，但只能在目标模型为神经网络的情况下应用。为了绕过这一限制提出第二个防御技术，即模型堆叠，它无关你使用的分类器模型种类。集成学习是一种ML范式，它不是使用单个ML模型，而是组合多个ML模型来构建最终模型。结合这些ML模型有不同的方法例如bagging或boosting。本文专注于以分层方式堆叠模型。下图显示了模型堆叠的示例体系结构：
