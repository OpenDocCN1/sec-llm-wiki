年度计算机安全应用大会（Annual Computer Security Applications Conference, ACSAC）作为CCF B类。ACSAC最早是1985年开始的航天计算机安全应用会议（Aerospace Computer Security Applications Conference），在若干年前改为现在名称。该会议的目标是探索计算机安全的应用技术，涵盖硬件、软件工具和技术，以及系统实现和应用的范例。ACSAC 2018年共收到**299**篇论文，录取**60**篇论文，录用率为20.1%。录用论文作者有来自于清华大学、复旦大学、中科院、南京大学、华中科大等多所高校，工业界包含了IBM、Facebook、腾讯等公司，小编将录用论文标题列举如下：
