# 软件架构国家重点实验室2018年开放课题

**一、背景说明**

软件架构国家重点实验室（东软集团）2009年经国家批准筹建，2015年通过国家验收并正式对外开放。实验室贯彻“开放、流动、联合、竞争”的方针，为促进我国软件学术界学术水平的提高和软件产业的技术进步而不断地开拓创新。

本实验室定位于应用基础研究，以国家战略需求和产业发展为导向，聚焦于竞争前新兴共性技术与方法的监控、辨识与及时导入，**以软件架构体系、共性技术与平台以及方法与工具为方向，以解决大型软件组织的创新和生产效率提升问题为己任**，研究方向及内容从实践中来，到实践中去。联合高校与科研院所，推动技术交流与合作；汇集优秀人才形成开放式研发基地，打造产学研用相结合的共赢生态；推动成果转化，发展合作伙伴，带动国产软件行业发展。

为了促进软件架领域中新理论、新思想、新技术、新平台和新方法及其相关标准的发展，加强国内外学术思想与人才的交流，促进学科交叉研究，实验室特设立开放课题基金项目，资助科研人员来实验室从事研究工作。开放课题在实验室研究方向框架内设立和实施，分为两类：**应用基础类研究****课题**和**创新合作研究课题**。应用基础研究类开放课题支持国内外高水平研究人员对实验室当前关心的重点研究课题开展前沿性、探索性的研究工作，课题资助额度为3万元；创新合作研究课题旨在实验室与其他高校、科研机构及企业/应用单位建立更紧密的合作关系，促进实验室研究成果的提升、转化与应用，课题资助额度不低于20万元。实验室热忱欢迎国内外科研工作者、博士后和博士积极申请符合本指南科研方向的科研项目。实验室将参照国家自然科学基金项目的评审办法，对项目进行科学、公正的评审，择优立项。

**二、项目指南**

**研究方向1：** 智能互联时代企业应用的软件架构体系与方法

**背景**：在移动互联网时代之后，智能互联网和智能互联应用被认为是下一代IT的基本支撑和特征，它是以物联网技术为基础，以平台型智能硬件为载体，按照约定的通信协议和数据交互标准，结合云计算与大数据应用，在智能终端、人、云端服务之间，进行信息采集、处理、分析、应用的智能化网络，具有高速移动、大数据分析和挖掘、智能感应与应用的综合能力，能够向传统行业渗透融合，提升传统行业的服务能力,连接百行百业，进行线上线下跨界全营销。在智能互联网时代，在结构、业务、商业模式、基本理念上都发生了重大变化。

**应用基础类研究课题，具体名称自拟。**

**选题方向与范围：**

1.  软件架构模式的智能化识别、建模与资产化
    
2.  智能互联时代的软件架构演化与关键支撑
    
3.  网态服务架构的理论与支撑关键技术
    
4.  智能化软件开发与运维关键技术与方法体系
    

**考核指标：**完成选题方向的领域分析与研究报告，获得实验室认可；完成和发表高质量学术论文（最低要求：SCI论文1篇或EI论文2篇以上，领域研究报告1篇，双方需联合发表论文）。

**研究课题2：**空间轨迹计算平台关键技术

**背景：**空间轨迹计算技术综合了IoT终端、边际计算、空间数据库、移动计算、数据挖掘、机器学习等技术，已经为社会提供了前所未有的丰富信息用以来研究和了解移动对象，并被应用于智慧城市、智能交通、地理信息等业务领域。它的深入研究涉及到计算机科学、生物学、社会学、地理学和气候学等多学科和领域。在能够产生空间轨迹数据的设备不断增多、空间大数据不断丰富、场景应用模式共性日益丰满的情况下，研究和提供新的计算技术和平台，用于处理、检索和发展空间轨迹数据并挖掘和探索数据更为广泛的应用价值。

**创新合作类研究课题，具体名称自拟。**

**选题方向与范围：**

1.  时空轨迹应用场景及其计算支撑平台
    
2.  面向多源异构时空大数据的感知、存储与计算融合的分布式系统架构技术
    
3.  时空特征数据的深层次建模方法与技术
    
4.  多源异构时空轨迹大数据融合的隐私保护与质量控制技术
    

**考核指标：**在该领域提出自主创新的理论、方法模型或者应用效果卓著的工具、技术；完成提交高质量学术论文（最低要求：SCI论文1篇或EI论文2篇以上，领域研究报告1篇，双方需联合发表论文）、国家发明专利、软件著作权等知识产权成果。

**研究课题3：医疗健康领域****智能化关键技术与应用**

**背景：**健康数据的爆炸式增长、全球共同面临的人口与费用挑战、人工智能在其他领域的成功案例、医疗机构数字化的经验与能力积累、公众积极参与自身健康的意愿提升等因素共同促成了AI技术在医疗领域应用的热潮。人工智能应用于医疗的主要动机是降低医疗成本、获得更好治疗手段并提高治疗的质量。在健康和医疗看护的不同阶段，AI技术可引入和应用的不同机会、场景与模式有着不同的特点和要求，同时除了技术性的因素外，隐私保护、法律合规和社会心理等方面也需考虑在内。

**创新合作类研究课题，具体名称自拟。**

**选题方向与范围：**

1.  医疗知识图谱的构建与应用
    
2.  多源异构健康和医疗大数据的融合技术
    
3.  诊疗诊断数据文本发现与挖掘
    
4.  特定病症的机器自动识别与筛查建模与分析技术
    
5.  面向医疗智能应用的感知、学习、存储与计算融合的分布式系统架构研究
    

**考核指标：**在该领域提出自主创新的理论、方法模型或者应用效果卓著的工具、技术。完成提交高质量学术论文（最低要求：SCI论文1篇或EI论文2篇以上，领域研究报告1篇，双方需联合发表论文）、国家发明专利、软件著作权等知识产权成果。

**研究课题4：分布式信任体系的行业应用关键技术研究**

**研究内容：**分布式信任体系作为一项重要的新兴趋势技术，其核心价值在于变革现有的集中化信任体系，通过分布式的信息存储、协商和决策机制为现有的电子交易乃至在未来的人机物融合的计算环境中为价值转移实现提供支撑，这一方向将深刻影响物联网、企业电子商务和产业生态层应用的应用场景和业务协作模式。

**创新合作类研究课题，具体名称自拟。**

**选题方向与范围：**

1.  分布式信任数据存证平台的架构与关键技术研究
    
2.  基于共识合约的数字资产交易自动化平台架构与关键技术研究
    
3.  基于分布式信任体系的供应链软件架构与平台的研究
    
4.  面向SQL接口、高效协议算法及跨域互信分布式协同信任通用平台架构与技术研究
    

**考核指标：**在该领域提出自主创新的理论、方法模型或者应用效果卓著的工具、技术。完成提交高质量学术论文（最低要求：SCI论文1篇或EI论文2篇以上，领域研究报告1篇，双方需联合发表论文）、国家发明专利、软件著作权等知识产权成果。
