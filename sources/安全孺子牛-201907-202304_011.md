#### **6.查找JMP ESP地址**

安装mona插件，把mona.py并存放在Immunity Debugger插件目录即可，并重启软件

```
https://github.com/corelan/mona
```

![](../Images/1b24cd0e5cf0c1c7cd56ff028d9e9839.png)

使用` !mona module`找到有效的 dll/模块

![](../Images/46c7ef36639e3cccb2f77b5fd1bdc256.png)

寻找 JMP ESP 指令的有效操作码

```

msf-nasm\_shell
```

![](../Images/2a13b581ef9a5e11af0bbcc9c0b88756.png)

使用 Mona 搜索JMP ESP指令地址查找到一个跳转指针

```
!mona find -s "\\xff\\xe4 -m "brainpan.exe"
```

![](../Images/43fc0339e9876f627f5231fa444c6e00.png)

选择字段内容为0x311712f3，在x86架构里，读取地址是由低到高的，所以是f3121731。用新找到的 JMP ESP 指令地址替换用于EIP寄存器的B字符，并添加 400 个C字符，用作 shellcode 的占位符。
