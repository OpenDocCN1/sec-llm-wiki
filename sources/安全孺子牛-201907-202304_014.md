## 1、信息收集

### **1.1通过arp-scan检测主机IP地址**

```
arp-scan 192.168.207.0/24
```

![](../Images/36cd05a9ff91118045f280a36ff2b148.png)

### **1.2 通过nmap进行端口扫描**

```
nmap -A -sS -sV -v -p- 192.168.207.146
```

查看开放22、80、139、445端口

![](../Images/133726d1c9c446f0fd8363e7dca2d6bf.png)

## **2、渗透测试**

### **2.1 WEB渗透**

#### **1.爆破信息泄露**

访问站点首页为Apache的默认页面

![](../Images/709c96f0af82dc1292e23a83768b581e.png)

通过dirb进行目录扫描，发现存在tiki目录

```
dirb http://192.168.207.146
```

![](../Images/fb6727a1ccd18b51c8a21d11def790f0.png)

访问以后发现是tiki的安装成功页面，未发现有用信息

![](../Images/e4a3195bfd185a297817331c217e2c8e.png)

#### **2.SMB检测**

通过前面的nmap扫描发现存在smb服务，针对smb进行扫描发现存在Notes目录

```
smbmap -H 192.168.207.146
```

![](../Images/dab993879c374f9d10669195624abb92.png)

连接Notes目录，查看存在mail.txt文件并下载

```

smbclient  //192.168.207.146/Notes
```

![](../Images/301b3df2ca15effce6cf3277258f0b21.png)

查看mail.txt文件发现账号和密码，账号为silky，密码为51lky571k1

![](../Images/f68f28bda4bd4d94f048799e73596f07.png)

#### **3.历史漏洞CVE**

通过获取到的账号和密码登录后台以后，在Last Change中查看有编辑的记录

![](../Images/210607e0b42476cb3c509584a8ec23f9.png)

查看编辑记录提示存在一个CVE编号

![](../Images/ceb722537d790c7bab84b7562c77f40b.png)

选择编辑，查看有提示历史编辑草稿，点击历史编辑

![](../Images/a980c2c1b8f5c14dbcbe64362409f602.png)

查看历史编辑中提示CVE编号为CVE-2020-159\*\*

![](../Images/62ea2466164be096045d40f6cd92a105.png)

通过谷歌搜索发现CVE编号为：CVE-2020-15906

![](../Images/38f35824ed50c654ecfa463f6ba7206d.png)

#### **4.漏洞利用**

使用漏洞利用脚本，提示admin管理员密码已经被删除

```

cp /usr/share/exploitdb/exploits/php/webapps/48927.py ./
```

![](../Images/3d835543fe341e5d688e62e459b48571.png)

使用账号admin和随意密码进行登录，并使用burpsuite进行抓包，删除密码字段的值

![](../Images/4c6b1e03c140e891b27b6ad6a58e249a.png)

删除后内容如下，并点击Forward放行

![](../Images/520c077b50af52dde0a7c1135fdc2fe9.png)

已经获取到admin管理员权限

![](../Images/5a7c3e05b7a593c8e39f8513eede1d42.png)

在历史编辑中，有一个证书信息内容

![](../Images/88e28f3fb02e7d16bd19af88435a2361.png)

打开以后提示有账号和密码信息`silky:Agy8Y7SPJNXQzqA`

![](../Images/585dbb81adf002c62f26562e8a7059ed.png)
