```

```

```
nmap -A -sS -sV -v -p- 192.168.207.132
```

## **2、渗透测试**

### **2.1 WEB站点测试**

#### **1.使用dirb进行目录扫描**

```
dirb http://192.168.207.133
```

    发现站点存在PHPmyadmin站点和weblog站点，怀疑站点为WordPress

![](../Images/3df26085f326b1e87abf4275072661c9.png)

#### **2.访问站点测试**

    发现站点跳转到一个域名中，需要做域名绑定

![](../Images/885651124268cfd686112cdb59254058.png)

![](../Images/404f21ecea6b6db70c54816189d1677c.png)

#### **3.第一个flag**

    访问站点后查看网站源代码获取到第一个flag

![](../Images/8bc6b9e9b088213fa250482480848c04.png)

#### **4.使用wpscan进行扫描**

```
wpscan --url "http://derpnstink.local/weblog" -eu -eap -eat
```

    未发现有用信息

![](../Images/5e5481b0266d03f3cfc8b2d774c65645.png)

    使用admin作为账号和密码发现登录成功

![](../Images/9625b4189cf18259ae6e76779356400e.png)

#### **5.使用MSF进行连接**

```


use exploit/unix/webapp/wp\_slideshowgallery\_upload
```

![](../Images/bb011af8d27eac826e6c31124d73f527.png)

    查看WordPress配置文件,获取到数据库账号和密码信息

```

cd /var/www/html/weblog
```

![](../Images/844f70be32fa7a766352ba2ac51bca91.png)

#### **6.尝试登录PHPmyadmin**

    登录后在WordPress数据库中wp\_users表发现有2个用户账号

![](../Images/b689f35c83fda3324363dd8229cedf2f.png)

    复制密码并保存到txt文档中，使用John进行爆破测试

```
john pass.txt --wordlist=/usr/share/wordlists/rockyou.txt
```

    爆破到密码为：`wedgie57`

![](../Images/8c0df535a1609eca7edaedd35ea129ec.png)

#### **7.第二个flag**

    使用unclestinky账号登录成功后，获取到第二个flag信息

![](../Images/9350d78f923ecf727049c65fa8df6093.png)

#### **1.查看系统用户信息**

```
python -c 'import pty; pty.spawn("/bin/bash")'
```

![](../Images/06c01f815715dfdff85d711aa83457ce.png)

#### **2.第三个flag**

![](../Images/7038771162d395d21cc6bd876d8c4ff5.png)
