# 1、简介

Cron词来自Crontab，存在于/etc 目录中。Cron任务用于通过在服务器上的特定日期和时间执行命令来调度任务。最常用于系统管理员作业，例如备份或清理 /tmp/目录等。

# 2、Cron语法配置

可以参考网上在线编写计划任务：https://tool.lu/crontab/

![](../Images/18f3273a5a83325c88ccc92677891d18.png)

示例：在 crontab 中，每隔1小时自动打印一次 apache 错误日志

```
1 0 \* \* \* printf "" > /var/log/apache/error\_log
```

#### 1.添加账号

```

```

```

```

## 3.4、计划任务文件覆盖

#### 1.在home目录创建文件

```


cd /home
```

![](../Images/e47bb8417cfb6b00b8f86c8f986becac.png)

