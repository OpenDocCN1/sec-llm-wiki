## 1、Snort三层路由IPS模式

![](../Images/ffd394ef98d9f793f0e35297534b1149.png)

### 1.1 网络部署

#### 1.配置网卡为固定模式

```
sudo vim /etc/netplan/00-installer-config.yaml
```

```


\# This is the network config written by 'subiquity'
```

#### 2.开启端口转发功能

```

echo 1 >/proc/sys/net/ipv4/ip\_forward
```

#### 3.攻击机添加路由

```
route add -net 192.168.32.0/24 gw 192.168.207.128
```

![](../Images/c0dcb5a6ed60491b13459fd3e4e49cf2.png)

#### 4.服务器添加路由

```
sudo route add -net 192.168.207.0/24 gw 192.168.32.128
```

网络已经配置完毕，攻击机会经过snort进行流量转发

![](../Images/89d06f8860f77b849de7ba6285628532.png)

#### 5.配置iptables

```

sudo iptables -I FORWARD -j NFQUEUE --queue-num=4
```

或者

```

sudo iptables -I FORWARD -i ens32 -o ens33 -j NFQUEUE --queue-num=4
```

### 1.2 功能测试

#### 1.创建本地规则

```
vim /usr/local/etc/rules/local.rules
```

```
alert icmp any any -> $HOME\_NET any (msg:"ICMP test detected"; sid:10000001; rev:001; classtype:icmp-event;)
```

#### 2.编辑snort.lua

```
vim /usr/local/etc/snort/snort.lua
```

设置HOME\_NET地址为内网主机地址段

![](../Images/28069c5c9d3d371542727d7c3a0fdfe2.png)

#### 3.启动IPS内联

```
snort -c /usr/local/etc/snort/snort.lua -i ens32:ens33 -Q -R /usr/local/etc/rules/local.rules --daq-dir /usr/local/lib/daq --daq afpacket --daq-var fanout\_type=hash -A alert\_fast
```

![](../Images/26343634ed8d898d983a6c572e55493d.png)

### 1.3 规则防护测试

#### 1.SSH流量检测

```
vim /usr/local/etc/rules/local.rules
```

```

alert tcp $EXTERNAL\_NET any -> $HOME\_NET 22 (msg:"检测到SSH流量";
```

#### 2.使用Kali通过SSH访问

```
ssh msfadmin@192.168.32.10
```

发现检测到告警事件

![](../Images/04d8c94ff58072f78397d6b03ef2bcc7.png)

#### 3.丢弃Telnet流量

```

drop tcp $EXTERNAL\_NET any -> $HOME\_NET 23 (msg:"丢弃到Telnet流量";
```

可以检测流量告警，但是不会执行丢弃

![](../Images/5f4548337ee8c3142b970718e130e41e.png)

注：Snort3中配置IPS inline模式后可以检测攻击，但是不能转发流量。

## 2、漏洞检测规则

### 1、vsftpd\_234\_backdoor

#### 1.简介

开发者在 2.3.4 的 vsftpd 中植入了一个后门，该后门的使用方式如下：

在 21 端口，使用随机用户名（末尾以 :) 笑脸结尾，使用随机密码在 TCP 流上进行 FTP 协议的认证，之后关闭连接。再新建一个 TCP 流，连接服务端的 6200 端口，此时服务端会将 /bin/sh 绑定到 6200 端口，即可进行命令执行。

#### 2.利用方法

```


use exploit/unix/ftp/vsftpd\_234\_backdoor
```

![](../Images/dba966bda3f94d695195739a881bdb28.png)

#### 3.检测规则

```

alert tcp $EXTERNAL\_NET any -> $HOME\_NET 21 (msg:"VSFTPD 后门利用攻击检测";
```

再次使用MSF进行攻击测试，检测告警事件如下

![](../Images/0387f79dbcd465d2c7801a6f0e0f5e3e.png)

### 2、Nmap Xmas扫描

#### 1\. 简介

Xmas扫描探测目标时，同時送 FIN, PSH, URG 至目标主机

#### 2.利用方法

```
nmap –sX -p80,8081 192.168.32.10
```

![](../Images/e1981bda45d8a6669322f112aa61f4a4.png)

#### 3.检测规则

```

alert tcp $EXTERNAL\_NET any -> $HOME\_NET any (msg:"Nmap Xmas扫描检测";
```

已成功检测到扫描

![](../Images/615c578b573d7be498144c2c6b647ddd.png)

### 3、检测FTP爆破

#### 1.简介

如果1分钟4次登录不成功即可认为爆破行为

#### 2.测试方法

```
hydra -l user -w 10 -P /usr/share/wordlists/rockyou.txt -f 192.168.32.10 ftp
```

![](../Images/e0b137472514ef092bf519552ee13396.png)

#### 3.检测规则

```


alert tcp $EXTERNAL\_NET any -> $HOME\_NET 21 (msg:"检测到FTP爆破";
```

可以看到检测到FTP爆破攻击

![](../Images/89b185cb5d9c4fb6b6debca8de239e32.png)
