1、挑战说明


我们最近从客户那里收到了这个内存转储。有人在他不在时访问了他的系统，他发现正在访问一些相当奇怪的文件。找到这些文件，它们可能很有用。我引用他的确切陈述，

    • ✅名字不可读。它们由字母和数字组成，但我无法弄清楚它到底是什么。

    • ✅此外，他注意到他最喜欢的应用程序每次运行时都会崩溃。是病毒吗？

注意1：此挑战由 3 个标志组成。如果您认为第二个标志是结束，它不是！:P

注意2 : 挑战时有一个小错误。如果您发现任何包含字符串“ L4B_3_D0n3 !! ”的字符串，请将其更改为“ L4B_5_D0n3 !! ”然后继续。

注意 3：只有当您拥有阶段 1 标志时，您才会获得阶段 2 标志

2、Flag1

2.1 获取镜像版本

vol.py -f MemoryDump_Lab5.raw imageinfo

2.2 查看浏览器信息

vol.py -f MemoryDump_Lab5.raw --profile=Win7SP1x64 iehistory

发现有多个文件

2.3 查找文件分析

vol.py -f MemoryDump_Lab5.raw --profile=Win7SP1x64 filescan > 1.txt
grep 'SW1wb3J0YW50.rar' 1.txt

只有SW1wb3J0YW50.rar存在

2.4 导出文件查看

vol.py -f MemoryDump_Lab5.raw --profile=Win7SP1x64 dumpfiles -Q 0x000000003eed56f0 -D /tmp

存在压缩密码

2.5 查看进程信息

vol.py -f MemoryDump_Lab5.raw --profile=Win7SP1x64 pstree

查看存在记事本和压缩包

2.6 查看进程文件输出

vol.py -f MemoryDump_Lab5.raw --profile=Win7SP1x64 cmdline -p 2744,2924

已经提取出该文件

2.7 通过截图插件分析

vol.py -f MemoryDump_Lab5.raw --profile=Win7SP1x64 screenshot -D /tmp

2.8 通过图片分析查看

其他图片都是空的，只有session_1.WinSta0.Default.png可以看到，并显示一串字符

ZmxhZ3shIV93M0xMX2QwbjNfU3Q0ZzMtMV8wZl9MNEJfM19EMG4zXyEhfQ

2.9 通过base64转换获取到flag

echo "ZmxhZ3shIV93M0xMX2QwbjNfU3Q0ZzMtMV8wZl9MNEJfM19EMG4zXyEhfQ" | base64 -d

flag值为：flag{!!_w3LL_d0n3_St4g3-1_0f_L4B_3_D0n3_!!}

3、Flag2

3.1 打开获取到的RAR文件

根据作者提示需要把密码修改为：flag{!!_w3LL_d0n3_St4g3-1_0f_L4B_5_D0n3_!!}，通过获取到的第一个flag作为密码打开压缩包，获取到第二个Flag值为：flag{W1th_th1s_$taGe_2_1s_c0mPL3T3_!!}

4、Flag3

4.1 在查看进程中可疑文件

查看发现2个文件名称相同，但是大写的NOTEPAD.EXE进程

4.2 分析2个文件

查看2个文件执行的路径，默认notepad.exe是在C:\Windows\system32

vol.py -f MemoryDump_Lab5.raw --profile=Win7SP1x64 cmdline -p 2724
vol.py -f MemoryDump_Lab5.raw --profile=Win7SP1x64 cmdline -p 2744

4.3 提取进程文件

vol.py -f MemoryDump_Lab5.raw --profile=Win7SP1x64 procdump -p 2724 -D /tmp

4.4 使用IDA打开文件

提取字段内容，获取到flag值为：bi0s{M3m_l4B5_OVeR_!}
