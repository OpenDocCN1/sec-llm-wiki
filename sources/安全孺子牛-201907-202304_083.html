1、挑战说明


一个恶意脚本加密了我系统上的一条非常机密的信息。你能帮我恢复信息吗？

注 1：此挑战仅由 1 个Flag组成,Flag分成两部分。

注意2：您需要Flag的前半部分才能获得第二部分 您将需要这个额外的工具来解决挑战，sudo apt install steghide

2、Flag前半段

2.1 查看镜像版本

vol.py -f MemoryDump_Lab3.raw imageinfo

2.2查看进程信息

vol.py -f MemoryDump_Lab3.raw --profile=Win7SP1x86 pslist

查看有notepad.exe记事本

2.3 查看notepad输出结果

vol.py -f MemoryDump_Lab3.raw --profile=Win7SP1x86 cmdline -p 3736,3432

2.4 查找文件

vol.py -f MemoryDump_Lab3.raw --profile=Win7SP1x86 filescan > san.txt
grep evilscript.py san.txt
grep vip.txt san.txt

2.5 导出文件

vol.py -f MemoryDump_Lab3.raw --profile=Win7SP1x86 dumpfiles -Q 0x000000003de1b5f0 -D /tmp
vol.py -f MemoryDump_Lab3.raw --profile=Win7SP1x86 dumpfiles -Q 0x000000003e727e50 -D /tmp

2.6 重命名文件

mv file.None.0x83e52420.dat vip.txt
mv file.None.0xbc2b6af0.dat evilscript.py

查看有2个文件，一个是txt，一个是py脚本

2.7 查看python文件内容

1.接收vip.txt文件传入，并使用xor进行3次编码，并把编码后进行base63编码

使用CyberChef可以快速解密，获取到前半段为：inctf{0n3_h4lf

3、Flag后半段

1.分析题意

题目要求安装steghide，发现Steghide 是一个隐写术程序。并支持图片和音频

2.基于文件类型进行查找

vol.py -f MemoryDump_Lab3.raw --profile=Win7SP1x86 filescan | grep jpeg

3.导出文件

vol.py -f MemoryDump_Lab3.raw --profile=Win7SP1x86 dumpfiles -Q 0x0000000004f34148 -D /tmp

4.使用隐写术解析图片

steghide  extract -sf

解压密码为上半部分的flag，为：inctf{0n3_h4lf

5.查看文件内容

cat secret\ text

获取到密码为：_1s_n0t_3n0ugh}，最终flag值为：inctf{0n3_h4lf_1s_n0t_3n0ugh}
