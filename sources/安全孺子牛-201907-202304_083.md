## 1、挑战说明

  

一个恶意脚本加密了我系统上的一条非常机密的信息。你能帮我恢复信息吗？

**注 1：此挑战仅由 1 个Flag组成,Flag分成两部分。**

**注意2：您需要Flag的前半部分才能获得第二部分** 您将需要这个额外的工具来解决挑战，`sudo apt install steghide`

## 2、Flag前半段

### 2.1 查看镜像版本

```
vol.py -f MemoryDump\_Lab3.raw imageinfo
```

![](../Images/b07af79acef7f237812bfa22072f4ec4.png)

### 2.2查看进程信息

```
vol.py -f MemoryDump\_Lab3.raw --profile=Win7SP1x86 pslist
```

查看有notepad.exe记事本

![](../Images/e49344e54b7f5af1cb00f8ae20a9f417.png)

### 2.3 查看notepad输出结果

```
vol.py -f MemoryDump\_Lab3.raw --profile=Win7SP1x86 cmdline -p 3736,3432
```

![](../Images/2382b3e64a610985f762c981259bc142.png)

### 2.4 查找文件

```


vol.py -f MemoryDump\_Lab3.raw --profile=Win7SP1x86 filescan > san.txt
```

![](../Images/c50517f910dbfe837008232884a1db6b.png)

### 2.5 导出文件

```

vol.py -f MemoryDump\_Lab3.raw --profile=Win7SP1x86 dumpfiles -Q 0x000000003de1b5f0 -D /tmp
```

![](../Images/9c60330381a71754a2cc449bd3f3442b.png)

### 2.6 重命名文件

```

mv file.None.0x83e52420.dat vip.txt
```

查看有2个文件，一个是txt，一个是py脚本

![](../Images/6065803d52d2e6a42f46c269354c47c6.png)

### 2.7 查看python文件内容

1.接收vip.txt文件传入，并使用xor进行3次编码，并把编码后进行base63编码

使用CyberChef可以快速解密，获取到前半段为：`inctf{0n3_h4lf`

![](../Images/e054f03482a34d70cf9a39c57583fa10.png)

## 3、Flag后半段

### 1.分析题意

题目要求安装steghide，发现Steghide 是一个隐写术程序。并支持图片和音频

![](../Images/b5216f6deed9430a687fcbddf02c2ff8.png)

### 2.基于文件类型进行查找

```
vol.py -f MemoryDump\_Lab3.raw --profile=Win7SP1x86 filescan | grep jpeg
```

![](../Images/e669ce329abcef217d29104a09dcc87b.png)

### 3.导出文件

```
vol.py -f MemoryDump\_Lab3.raw --profile=Win7SP1x86 dumpfiles -Q 0x0000000004f34148 -D /tmp
```

![](../Images/8a7596deb0fcdf5867ca4b570fec9eb0.png)

### 4.使用隐写术解析图片

```
steghide  extract -sf
```

解压密码为上半部分的flag，为：`inctf{0n3_h4lf`

![](../Images/646b7b38eb36fd62617907daa7e317f4.png)

### 5.查看文件内容

```
cat secret\\ text
```

获取到密码为：`_1s_n0t_3n0ugh}`，最终flag值为：`inctf{0n3_h4lf_1s_n0t_3n0ugh}`

![](../Images/fdf4d110c12f6dc265640fdfc509a0bf.png)
