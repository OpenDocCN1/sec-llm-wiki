1、挑战说明


我们公司的一位客户由于未知错误而失去了对其系统的访问权限。据推测，他是一位非常受欢迎的“环保”活动家。作为调查的一部分，他告诉我们他的应用程序是浏览器，他的密码管理器等。我们希望你能深入这个内存转储并找到他的重要资料并将其归还给我们。

2、Flag1

2.1 查看镜像版本

vol.py -f MemoryDump_Lab2.raw imageinfo

猜测镜像为：Win7SP1x64

2.2 查看CMD命令

1.查看CMD执行命令

vol.py -f MemoryDump_Lab2.raw --profile=Win7SP1x64 cmdscan

发现有一个conhost.exe，PID为2068

2.查看CMD执行结果

vol.py -f MemoryDump_Lab2.raw --profile=Win7SP1x64 consoles

没有发现有用信息

2.3查看进程的环境变量

vol.py -f MemoryDump_Lab2.raw --profile=Win7SP1x64 envars -p 2068

查看存在NEW_TMP变量中值为：ZmxhZ3t3M2xjMG0zX1QwXyRUNGczXyFfT2ZfTDRCXzJ9

2.4 通过base64解码

echo "ZmxhZ3t3M2xjMG0zX1QwXyRUNGczXyFfT2ZfTDRCXzJ9" | base64 -d

获取到flag值为：flag{w3lc0m3_T0_$T4g3_!_Of_L4B_2}

3、Flag2

3.1 查看浏览器记录

vol.py -f MemoryDump_Lab2.raw --profile=Win7SP1x64 iehistory

查看访问有：Important.rar、SW1wb3J0YW50.rar、stAg3_5.txt、Password.png、Hidden.kdbx相关文件

3.2 查看password.png

1.通过查找发现Password.png

vol.py -f MemoryDump_Lab2.raw --profile=Win7SP1x64 filescan | grep Password.png

2.导出Password.png

vol.py -f MemoryDump_Lab2.raw --profile=Win7SP1x64 dumpfiles -Q 0x000000003fce1c70 -D /tmp

3.查看图片内容

发现提示密码：P4SSw0rd_123

3.3 查看Hidden.kdbx

1.通过查找发现Hidden.kdbx

vol.py -f MemoryDump_Lab2.raw --profile=Win7SP1x64 filescan | grep Hidden.kdbx

2.导出文件

vol.py -f MemoryDump_Lab2.raw --profile=Win7SP1x64 dumpfiles -Q 0x000000003fb112a0 -D /tmp

3.打开文件提示有密码

4.打开文件

使用图片提示的密码打开后获取到Flag,Flag值为：flag{w0w_th1s_1s_Th3_SeC0nD_ST4g3_!!}

4、Flag3

4.1 批量查找文件

vol.py -f MemoryDump_Lab2.raw --profile=Win7SP1x64 filescan > file.txt

4.2 搜素浏览器历史记录位置

grep '\\Chrome\\User Data\\Default\\History' file.txt

4.3 导出浏览器历史记录

vol.py -f MemoryDump_Lab2.raw --profile=Win7SP1x64 dumpfiles -Q 0x000000003fcfb1d0 -D /tmp

4.4 使用DB Browser (SQLite)浏览数据

History 文件是一个 SQLite 数据库，我们可以使用 sqlite3 命令行工具或 GUI 应用程序（例如DB Browser for SQLite）来探索它
