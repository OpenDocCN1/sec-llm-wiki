## 1、挑战说明

  

我们公司的一位客户由于未知错误而失去了对其系统的访问权限。据推测，他是一位非常受欢迎的“环保”活动家。作为调查的一部分，他告诉我们他的应用程序是浏览器，他的密码管理器等。我们希望你能深入这个内存转储并找到他的重要资料并将其归还给我们。

## 2、Flag1

### 2.1 查看镜像版本

```
vol.py -f MemoryDump\_Lab2.raw imageinfo
```

猜测镜像为：`Win7SP1x64`

![](../Images/5d0568e94de5489aa4de7ce0294c89a8.png)

### 2.2 查看CMD命令

#### 1.查看CMD执行命令

```
vol.py -f MemoryDump\_Lab2.raw --profile=Win7SP1x64 cmdscan
```

发现有一个conhost.exe，PID为2068

![](../Images/b50e39c9e739ea1b3ec26a6432afe7df.png)

#### 2.查看CMD执行结果

```
vol.py -f MemoryDump\_Lab2.raw --profile=Win7SP1x64 consoles
```

没有发现有用信息

![](../Images/f0116febd147edff90a0dd638f1afbda.png)

### 2.3查看进程的环境变量

```
vol.py -f MemoryDump\_Lab2.raw --profile=Win7SP1x64 envars -p 2068
```

查看存在NEW\_TMP变量中值为：`ZmxhZ3t3M2xjMG0zX1QwXyRUNGczXyFfT2ZfTDRCXzJ9`

![](../Images/24e43b01f847d778ef9d441eaa583869.png)

### 2.4 通过base64解码

```
echo "ZmxhZ3t3M2xjMG0zX1QwXyRUNGczXyFfT2ZfTDRCXzJ9" | base64 -d
```

获取到flag值为：`flag{w3lc0m3_T0_$T4g3_!_Of_L4B_2}`

![](../Images/d5dcc1caa5e55511a416b36227a44f90.png)
