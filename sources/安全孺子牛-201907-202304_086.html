1、挑战说明

我姐姐的电脑坏了。我们非常幸运地恢复了这个内存转储。你的工作是从系统中获取她所有的重要文件。根据我们的记忆，我们突然看到一个黑色的窗口弹出，上面有一些正在执行的东西。崩溃发生时，她正试图画一些东西。

存在三个flag

2、Flag1

2.1获取操作系统版本

python vol.py -f ../test/MemoryDump_Lab1.raw imageinfo

操作系统版本为：Win7SP1x64

2.2 查看cmd命令

python vol.py -f ../test/MemoryDump_Lab1.raw --profile=Win7SP1x64 cmdscan

2.3 查看cmd输出

python vol.py -f ../test/MemoryDump_Lab1.raw --profile=Win7SP1x64 consoles

查看执行命令为：St4G3$1，结果为：ZmxhZ3t0aDFzXzFzX3RoM18xc3Rfc3Q0ZzMhIX0=

2.4 通过base64解码

echo "ZmxhZ3t0aDFzXzFzX3RoM18xc3Rfc3Q0ZzMhIX0=" | base64 -d

获取到flag值为：flag{th1s_1s_th3_1st_st4g3!!}

2.5 使用mimikatz获取密码

python vol.py -f ../test/MemoryDump_Lab1.raw --profile=Win7SP1x64 mimikatz

3、Flag2

3.1 分析进程信息

python vol.py -f ../test/MemoryDump_Lab1.raw --profile=Win7SP1x64 pslist

查看mspaint.exe是window自带的画图工具

3.2 转存储文件

python vol.py -f ../test/MemoryDump_Lab1.raw --profile=Win7SP1x64 memdump -p 2424 -D /tmp

基于mspaint.exe的进程为2424转存储文件

3.3 提取图片

1.把提取到的文件保存为data格式

mv 2424.dmp 2424.data

2.使用gimp打开文件

gimp 2424.data

3.设置图片类型为RGB Alpha

将宽度和高度都设置得更高

4.调整偏移量

需要慢慢减少或增加宽度，直到它变得更清晰

5.调整查看详细

微调后，我们可以简单地点击确定图片已经清晰

6.旋转图片180度

获取到flag值为：flag{Good_BoY_good_girl}

4、Flag3

4.1 获取cmdline

python vol.py -f ../test/MemoryDump_Lab1.raw --profile=Win7SP1x64 cmdline

查看有rar压缩，存在important.rar。

4.2 查找文件

python vol.py -f ../test/MemoryDump_Lab1.raw --profile=Win7SP1x64 filescan | grep "Important"

文件存储在alissa用户目录中

4.3 导出文件

python vol.py -f ../test/MemoryDump_Lab1.raw --profile=Win7SP1x64 dumpfiles -Q 0x000000003fb48bc0 -D /tmp

4.4 打开压缩包

1.显示解压密码为Alissa的NTLM HASH

并且密码需要大写

2.使用hashdump获取HASH

python vol.py -f ../test/MemoryDump_Lab1.raw --profile=Win7SP1x64 hashdump

获取到Alissa的HASH为：f4ff64c8baac57d22f22edc681055ba6，转变为大写：F4FF64C8BAAC57D22F22EDC681055BA6

4.5 获取flag3

flag值为：flag{w3ll_3rd_stage_was_easy}
