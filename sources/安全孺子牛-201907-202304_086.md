## 1、挑战说明

我姐姐的电脑坏了。我们非常幸运地恢复了这个内存转储。你的工作是从系统中获取她所有的重要文件。根据我们的记忆，我们突然看到一个黑色的窗口弹出，上面有一些正在执行的东西。崩溃发生时，她正试图画一些东西。

存在三个flag

## 2、Flag1

### 2.1获取操作系统版本

```
python vol.py -f ../test/MemoryDump\_Lab1.raw imageinfo
```

操作系统版本为：`Win7SP1x64`

![](../Images/eab09b667102a1467411feb02d24ec0c.png)

### 2.2 查看cmd命令

```
python vol.py -f ../test/MemoryDump\_Lab1.raw --profile=Win7SP1x64 cmdscan
```

![](../Images/f5c3a2eebd9d6809ce52bea76cbd807b.png)

### 2.3 查看cmd输出

```
python vol.py -f ../test/MemoryDump\_Lab1.raw --profile=Win7SP1x64 consoles
```

查看执行命令为：`St4G3$1`，结果为：`ZmxhZ3t0aDFzXzFzX3RoM18xc3Rfc3Q0ZzMhIX0=`

![](../Images/834a6e9a1b720f12ea9ccc46876dfb85.png)

### 2.4 通过base64解码

```
echo "ZmxhZ3t0aDFzXzFzX3RoM18xc3Rfc3Q0ZzMhIX0=" | base64 -d
```

获取到flag值为：`flag{th1s_1s_th3_1st_st4g3!!}`

![](../Images/ffe6256328e745f47fca915f3b9ebce3.png)

### 2.5 使用mimikatz获取密码

```
python vol.py -f ../test/MemoryDump\_Lab1.raw --profile=Win7SP1x64 mimikatz
```

![](../Images/ea054314a1ebf09834bc4449a13fa91b.png)

## 3、Flag2

### 3.1 分析进程信息

```
python vol.py -f ../test/MemoryDump\_Lab1.raw --profile=Win7SP1x64 pslist
```

查看mspaint.exe是window自带的画图工具

![](../Images/05c6870f6f15f337495e0ec1d488f07d.png)

### 3.2 转存储文件

```
python vol.py -f ../test/MemoryDump\_Lab1.raw --profile=Win7SP1x64 memdump -p 2424 -D /tmp
```

基于mspaint.exe的进程为2424转存储文件

![](../Images/7d883e07b1094f20e7bdef06ee5363bf.png)

### 3.3 提取图片

#### 1.把提取到的文件保存为data格式

```
mv 2424.dmp 2424.data
```

![](../Images/1239f6885b131ff5201309d945458ed8.png)

#### 2.使用gimp打开文件

```
gimp 2424.data
```

![](../Images/2db996d115d69a489736a97d61d852fe.png)

#### 3.设置图片类型为RGB Alpha

将宽度和高度都设置得更高

![](../Images/424945ee411866e4d874bbc4e271ba3f.png)

#### 4.调整偏移量

需要慢慢减少或增加宽度，直到它变得更清晰

![](../Images/bfd379888a41ac6deeda4f9cdf1f0c85.png)

#### 5.调整查看详细

微调后，我们可以简单地点击确定图片已经清晰

![](../Images/169906cfc55d876b80fba5f0a784b257.png)

#### 6.旋转图片180度

获取到flag值为：`flag{Good_BoY_good_girl}`

![](../Images/16aba3191ffc8e7af6514a3d1bda6273.png)

## 4、Flag3

### 4.1 获取cmdline

```
python vol.py -f ../test/MemoryDump\_Lab1.raw --profile=Win7SP1x64 cmdline
```

查看有rar压缩，存在important.rar。

![](../Images/70f53a2d752d9e8e1fdb157ef42891cb.png)

### 4.2 查找文件

```
python vol.py -f ../test/MemoryDump\_Lab1.raw --profile=Win7SP1x64 filescan | grep "Important"
```

文件存储在alissa用户目录中

![](../Images/34550359bbdfce1213c2e32d2c44b0e2.png)

### 4.3 导出文件

```
python vol.py -f ../test/MemoryDump\_Lab1.raw --profile=Win7SP1x64 dumpfiles -Q 0x000000003fb48bc0 -D /tmp
```

![](../Images/a53ea4d5aabf79e075dd4fc6576b24de.png)

### 4.4 打开压缩包

#### 1.显示解压密码为Alissa的NTLM HASH

**并且密码需要大写**

![](../Images/7d9c7933a8d029cb86e3653ee2c51453.png)

#### 2.使用hashdump获取HASH

```
python vol.py -f ../test/MemoryDump\_Lab1.raw --profile=Win7SP1x64 hashdump
```

获取到Alissa的HASH为：`f4ff64c8baac57d22f22edc681055ba6`，转变为大写：`F4FF64C8BAAC57D22F22EDC681055BA6`

![](../Images/3a84fbd5ce3ae2b7707f6bcbe6f08a69.png)

### 4.5 获取flag3
