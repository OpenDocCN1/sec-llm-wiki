## 1、挑战说明

  

约翰在编写任何程序时使用了太多变量。有一天，他给了我一个内存转储，并让我找出他在转储时在做什么。你能帮我弄清楚吗？

## 2、操作步骤

### **2.1获取操作系统版本**

#### 1.可以使用imageinfo获取

```
python vol.py -f ../test/Challenge.raw imageinfo
```

猜测版本为：`Win7SP1x86`

![](../Images/d9c1801d4c265183315fc08d931ba45d.png)

#### 2.也可以通过kdbgscan

```
python vol.py -f ../test/Challenge.raw kdbgscan
```

![](../Images/8c02e6524a07d8e73272e400fefa1bae.png)

### 2.2 查看正在运行进程

```
python vol.py -f ../test/Challenge.raw --profile=Win7SP1x86 pslist
```

先看一下cmd.exe，因为它非常简单地转储命令行参数.

![](../Images/52eecd2f36a4fb67f44fa9ece31c3ec2.png)

### 2.3 查看正在运行命令

```
volatility -f Challenge.raw --profile=Win7SP1x86 cmdscan
```

在当前CMD命令行中执行为：`C:\Python27\python.exe C:\Users\hello\Desktop\demon.py.txt`

![](../Images/57c1e8fa8e2385635170659444b8fbdd.png)

### **2.4 查看执行命令结果**

#### 1.查看命令行输出结果

```
python vol.py -f ../test/Challenge.raw --profile=Win7SP1x86 consoles
```

发现除了执行python命令，还在执行转存储操作。同时查看一段16进制字符串为：`335d366f5d6031767631707f`

![](../Images/c2c6304399b6890e1b71d8d69564aa16.png)

#### 2.解析编码

需要使用Python2进行解析，解析完毕后显示乱码

```

a = "335d366f5d6031767631707f".decode("hex")
```

![](../Images/fe9f7c0b64059ceff0bff77509be49d7.png)

### **2.5 查看环境变量**

#### 1.基于CMD的PID进行查看

```
python vol.py -f ../test/Challenge.raw --profile=Win7SP1x86 envars | grep 2096
```

查看有XOR和密码相关

![](../Images/582d232f5a754573afd2128a5d50d273.png)

#### 2.基于异或解密

```


a = "335d366f5d6031767631707f".decode("hex")
```

查看相似值为：`1_4m_b3tt3r}`

![](../Images/8303c0d662587a1107e672f685984f91.png)

### **2.6 获取账号HASH**

#### 1.使用hashdump获取密码

```
python vol.py -f ../test/Challenge.raw --profile=Win7SP1x86 hashdump
```

![](../Images/f37aad26fc58f54a68890af183046ec0.png)

#### 2.使用mimikatz获取密码

```
python vol.py -f ../test/Challenge.raw --profile=Win7SP1x86 mimikatz
```

![](../Images/a22c2331c23c9f5261296a1eca9d9678.png)

### **2.7组合获取flag**

最终flag值为：`flag{you_are_good_but1_4m_b3tt3r}`
