12、Level11-Level12

1.题目要求

下一级的密码存储在文件data.txt 中，其中所有小写 (az) 和大写 (AZ) 字母都被旋转了 13 个位置

2.登录账户

3.rot13解码脚本

#coding:utf-8
 
import string
 
def decoder(crypt_str,shift):
    crypt_list = list(crypt_str)
    plain_str = ""
    num = int(shift)
    for ch in crypt_list:
        ch = ord(ch)
        if ord('a') <= ch and ch <= ord('z'):
            ch = ch + num
            if ch > ord('z'):
                ch -= 26
        if ord('A') <= ch and ch <= ord('Z'):
            ch = ch +num
            if ch > ord('Z'):
                ch -= 26
        a=chr(ch)
        plain_str += a
 
    print(plain_str)
 
crypt_str = raw_input("Crypto_text:")
print "!------decode------!"
shift=13
decoder(crypt_str,shift)

4.使用rot13解码

python rot13.py

获取到密码：5Te8Y4drgCRfCx8ugdwuEX8KFC6k2EUu

17、Level16-Level17

1.题目要求

可以通过将当前级别的密码提交到本地主机上 31000 到 32000 范围内的端口来检索下一级的凭据。首先找出这些端口中的哪些端口有服务器在监听它们。然后找出哪些说 SSL，哪些不说。只有一台服务器会提供下一个凭据，其他服务器只会将您发送给它的任何内容发回给您。

2.登录账户

3.使用nmap进行探测

nmap -sV localhost -p31000-32000

查看存在SSL的端口有2个，分别是31518和31790

4.使用SSL进行连接

openssl s_client -connect localhost:31790

获取到私钥文件

5.导出私钥

保存私钥文件为key.txt

mkdir /tmp/bandits
openssl rsa -inform PEM -in key.txt -outform PEM -out key.pem
ssh -i key.pem bandit17@localhost

6.查看密码文件

cat /etc/bandit_pass/bandit17

获取到密码为：xLYVMN9WE5zQ5vHacb0sZEVqbrp7nBTn

21、Level20-Level21

1.题目要求

主目录中有一个 setuid 二进制文件，它执行以下操作：它在您指定为命令行参数的端口上连接到 localhost。然后它从连接中读取一行文本，并将其与上一级 (bandit20) 中的密码进行比较。如果密码正确，它将传送下一级（bandit21）的密码。

2.登录账户

3.新开终端创建连接

echo GbKksEFF4yrVs6il55v6gwY5aVje5f0j | nc localhost -l -p 32000

4.使用工具进行连接

./suconnect 32000

5.查看获取到密码
