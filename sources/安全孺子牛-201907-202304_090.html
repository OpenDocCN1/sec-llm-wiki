简介

    Bandit是针对绝对初学者的靶场，从 0 级开始，并尝试“击败”或“完成”它。完成一个级别会获得有关如何开始下一个级别的信息。

地址：https://overthewire.org/wargames/bandit/

端口：2220

1、Level0-Level1

1.题目要求

下一级的密码存储在主目录中名为readme的文件 中。使用此密码通过 SSH 登录到 bandit1。每当您找到某个关卡的密码时，请使用 SSH（在端口 2220 上）登录该关卡并继续游戏。

2.使用SSH登录

cat readme

获取到密码：boJ9jbbUNNfktd78OOpsqOltutMc3MY1

2、Level1-Level2

1.题目要求

下一级的密码存储在主目录下名为-的文件中

2.登录账户

使用账号bandit1，密码上面获取到的进行登录

3.查看-文件

如果通过普通方法访问，会提示报错

4.通过使用cat进行访问

cat < -

cat 'spaces in this filename'

6、Level5-Level6

1.题目要求

下一级的密码存储在inhere目录下的某个文件中，并具有以下所有属性：

    • 人类可读

    • 1033 字节大小

    • 不可执行

2.登录账户

3.目录文件太多，通过find进行查找

find . -type f -size 1033c
# -type   查找类型
# -size   大小
# c       byte方式
cat ./maybehere07/.file2

获取到密码：DXjZPULLxYr17uwoI01bNLQbtFemEgo7

7、Level6-Level7

1.题目要求

下一级的密码存储在服务器的某个位置，并具有以下所有属性：

    • 用户bandit7拥有

    • 由组bandit6拥有

    • 33 字节大小

2.登录账号

3.查找本地文件

find / -type f -size 33c -user bandit7 -group bandit6 2>/dev/null

4.查看密码

cat /var/lib/dpkg/info/bandit7.password

获取到密码：HKBPTKQnIay4Fw76bEy8PVxKEDQRKTzs
