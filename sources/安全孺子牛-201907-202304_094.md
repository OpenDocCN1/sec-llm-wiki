# 1、CTF-福莱格殿下

## 1.1 查看镜像信息

```
vol.py -f zy.raw imageinfo
```

镜像大致为：WinXPSP2x86

![](../Images/72d7d0d5722aa2dc74d5f76d4004cf69.png)

## 1.2 查看进程列表

```
vol.py -f zy.raw --profile=WinXPSP2x86 pslist
```

![](../Images/ea00a183fdb91321ed9b76621c89b079.png)

## 1.3 查看浏览器记录

```
vol.py -f zy.raw --profile=WinXPSP2x86 iehistory
```

查看有flag.jpg和hint.txt

![](../Images/ad5fc1830ff267dce3968b52772fd41d.png)

## 1.4 查找本地文件

```

vol.py -f zy.raw --profile=WinXPSP2x86 filescan | grep hint
```

![](../Images/305990dea1e7c947f3e22e1477be78cc.png)

## 1.5 提取文件

```
vol.py -f zy.raw --profile=WinXPSP2x86 dumpfiles -Q 0x0000000002456028 -D ./
```

![](../Images/26511fd34ceb0a993d53096ee16c5d8f.png)

## 1.6 查看文件

提示在fl4g存在flag

![](../Images/cf7f41eb0edb02927948c7ddae0cd7c9.png)

## 1.7 查找fl4g文件

```
vol.py -f zy.raw --profile=WinXPSP2x86 filescan | grep fl4g
```

![](../Images/48d1132eded860a21a03a2d71da9fdd6.png)

## 1.8 导出文件

```
vol.py -f zy.raw --profile=WinXPSP2x86 dumpfiles -Q 0x0000000002052028 -D ./
```

![](../Images/de9b78264ac126a73054c96c9dedb5c2.png)

## 1.9 查看文件类型

```

mv file.None.0x81c751a0.dat fl4g.zip
```

![](../Images/b4fb666f8dd25b086d4b85452174ff66.png)

![](../Images/31eb60ef1092bcdaa517ddd900f8b0dc.png)

![](../Images/c9acbe11cb14e0f7d1a3976d047e0aef.png)

## 1.10 图片分析

使用Stegsolve进行图片分析，先用StegSlove打开flag.png，然后点击Analyse->Image Combiner打开flag.jpg，进行异或会得到二维码

```
http://www.caesum.com/handbook/Stegsolve.jar
```

![](../Images/ff31970859aaea4faa65553937a1de27.png)

## 1.11 二维码识别

```
https://cli.im/deqr
```

![](../Images/ed01b8f48bac71b02216c1407927ea65.png)

# 2、CTF-very-ez-dump

## 2.1 查看镜像系统版本

```
vol.py -f mem.raw imageinfo
```

镜像版本可能为：`Win7SP1x64`

![](../Images/96073bb2a246156f88c124a3cd1de6c1.png)

## 2.2 查看进程

```
vol.py -f mem.raw --profile=Win7SP1x64 pslist
```

![](../Images/e0535257043235336429a416645dead9.png)

## 2.3 查看网络连接

```
vol.py -f mem.raw --profile=Win7SP1x64 netscan
```

![](../Images/32ace65f133402926b38dd56589f17f3.png)

## 2.4 查看历史命令

```
vol.py -f mem.raw --profile=Win7SP1x64 cmdscan

查看创建用户：`mumuzi`，密码：`(ljmmz)ovo`

![](../Images/e8170cf4f593954111a3f9d2ab840d47.png)

## 2.5 使用文件搜索

```
vol.py -f mem.raw --profile=Win7SP1x64 filescan |grep flag
```

![](../Images/61d123472251665bfb3762450d3b2783.png)

## 2.6 dump文件

```
vol.py -f mem.raw --profile=Win7SP1x64 dumpfiles -Q 0x000000003e4b2070 -D ./

![](../Images/c4e58b992652ff3f6f33ace2d393fa6c.png)

使用密码`(ljmmz)ovo`解压压缩包

# 3、陇剑杯-内存分析

## 3.1 分析镜像系统版本

```
vol.py -f Target.vmem imageinfo
```

![](../Images/33119b775a96fa4bcde67609d701c47f.png)

## 3.2 查看主机密码

```
vol.py -f Target.vmem --profile=Win7SP1x64 mimikatz
```

![](../Images/eb8a3c67f553d56cd70b6b4e78b14ca9.png)

或者使用lsadump获取hash

```
vol.py -f Target.vmem --profile=Win7SP1x64 lsadump
```

![](../Images/3aeb234cd0620b1c02d971525cda4ab3.png)

## 3.3 虚拟机存在手机备份

```
vol.py -f Target.vmem --profile=Win7SP1x64 filescan | grep HUAWEI
```

![](../Images/cf3436dcade8264b6b273ba9460611b6.png)

## 3.4 导出手机备份文件

```
vol.py -f Target.vmem --profile=Win7SP1x64 dumpfiles -Q 0x000000007d8c7d10 -n --dump-dir=./
```

![](../Images/6073006f6e5ce83c51828ab1096a9856.png)

## 3.5 修改导出文件为EXE

文件为自解压，在图片目录中发现加密文件

![](../Images/a3f7def3e0513b1bac96629bc92b0c2a.png)

## 3.6 解密文件

把解压后的文件夹全部拷贝到目录中，并执行

```
python3 kobackupdec.py -vvv W31C0M3\_T0\_THiS\_34SY\_F0R3NSiCX "/opt/test/HUAWEI" /opt/aaa
```

![](../Images/c33e55e675d08e12567fc9a56e3fdd92.png)

## 3.7 下载压缩后文件

```
cd /opt/aaa/storage/MediaTar/images
```

![](../Images/e997f355298c2d592599bde11350632f.png)
