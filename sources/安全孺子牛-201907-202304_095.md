# 1、部署安装

## 1.安装Volatility

### 1.安装标准包

#### 1.下载地址

```
https://www.volatilityfoundation.org/releases
```

![](../Images/a0176251cb63d89ad843c5fdba0cd269.png)

#### 2.配置安装目录

```


unzip -d /usr/local/volatility volatility\_2.6\_lin64\_standalone.zip
```

![](../Images/4322a37a104784a881f66f71455c9d31.png)

#### 3.配置环境变量

配置完毕后需要重新退出登录即可

```


vim /etc/profile
```

![](../Images/9fefa0a5aa02adb03738e282ba71de05.png)

### 2.Centos安装

#### 1.使用git进行克隆

```

git clone https://github.com/volatilityfoundation/volatility
```

#### 2.安装依赖包

```
yum install python-devel gcc cmake
```

#### 3.安装Python2依赖

```


wget https://bootstrap.pypa.io/pip/2.7/get-pip.py
```

#### 4.安装软件

```
python setup.py install
```

![](../Images/85a7994f3a5cbe30504e211bf6e97eb5.png)

#### 5.安装mimikatz插件

```


git clone https://github.com/ruokeqx/tool-for-CTF.git
```

![](../Images/d702707f031e52b1547e24fea57eefb5.png)

# 2、测试实例

## 1.获取admin密码

```
内存镜像下载地址：https://www.aliyundrive.com/s/oyD9Pyk9us9
```

### 1.获取镜像版本信息

```
vol.py -f worldskills3.vmem --profile=Win7SP1x64 imageinfo
```

![](../Images/b5d05cf231f9c2327dca39bc37cbf19a.png)

### 2.获取SAM信息

```
vol.py -f worldskills3.vmem --profile=Win7SP1x64 hashdump
```

![](../Images/6748139f15aece5cc3a48f19697abec7.png)

### 3.使用lasdump获取信息

查看到flag信息

```
vol.py -f worldskills3.vmem --profile=Win7SP1x64 lsadump
```

![](../Images/3f77296a3a315c9e8db3e8eef4623e64.png)

### 4.使用mimikatz获取密码

```
vol.py -f worldskills3.vmem --profile=Win7SP1x64 mimikatz
```

![](../Images/80fc2da26a070428f1fde1a832f703bf.png)

## 2.获取IP和主机名

### 1.通过使用netscan查询IP地址

```
vol.py -f worldskills3.vmem --profile=Win7SP1x64 netscan
```

获取IP地址为：192.168.85.129

![](../Images/f18254ac6f54d571c73bd33cd7d3dc6c.png)

### 2.查询注册表信息

```
vol.py -f worldskills3.vmem --profile=Win7SP1x64 hivelist
```

![](../Images/4e38c462494792d5bf096c041c3ca9c6.png)

### 3.查询键名

通过hivedump查询对应键名,该速度非常慢，需要等待。

```
vol.py -f worldskills3.vmem --profile=Win7SP1x64 hivedump -o 0xfffff8a000024010 | grep ComputerName
```

![](../Images/79a090e78ac1a21ef48c78df8519f28f.png)

### 4.查询主机名

```
vol.py -f worldskills3.vmem --profile=Win7SP1x64 printkey -K "ControlSet001\\Control\\ComputerName\\ComputerName"
```

![](../Images/bb537ed49e2c0ecb31d8b74eb9417bdd.png)

## 3.获取桌面上的flag.txt文件内容

### 1.使用filescan扫描文件

```
vol.py -f worldskills3.vmem --profile=Win7SP1x64 filescan | grep "flag.txt"
```

![](../Images/07e2b8bc216a95fb5c4dd95ce3bc9bb7.png)

### 2.爆破文件内容

```

vol.py -f worldskills3.vmem --profile=Win7SP1x64 dumpfiles -Q 0x000000007f1b6c10 --dump-dir=./
```

![](../Images/e9cac290d4ddc22e83ee9f14bba0c911.png)

## 4.查看服务器挖矿地址

### 1.查看网络连接

```
vol.py -f worldskills3.vmem --profile=Win7SP1x64 netscan | grep ESTABLISHED
```

查看已经建立链接的地址为：54.36.109.161，进程ID为：2588

![](../Images/32bc3fd07941ff7de6965530b944ee62.png)

### 2.查看挖矿服务

```
vol.py -f worldskills3.vmem --profile=Win7SP1x64 pslist | grep 2588
```

查看挖矿服务为svchost.exe，查看父进程为3036

![](../Images/9428ab9f0caeef846824f1bb719ca279.png)

### 3.查看挖矿服务的父进程

```
vol.py -f worldskills3.vmem --profile=Win7SP1x64 svcscan
```

![](../Images/07060c6b12ed5c35260ad49f1f7f8bbb.png)

### 4.查看父进程信息

```
vol.py -f worldskills3.vmem --profile=Win7SP1x64 pslist | grep 3036
```

![](../Images/cf5107136c86ac8410e3c5c9167a5066.png)

### 5.病毒自我删除时执行的命令

```
vol.py -f worldskills3.vmem --profile=Win7SP1x64 memdump -p 3036 --dump-dir=./
```

提取PID为3036的进程进行导出

![](../Images/83c0c50d8dffef3c1235a76850284aab.png)

### 6.提权文件

使用hexeditor 对dump文件以16进制方式查看

```
hexeditor /opt/test/3036.dmp
```

![](../Images/5c9a44048664141eff2cfb0a93c930c6.png)
