1、Linux应急响应靶机-kdevtmpfsi挖矿病毒

1、事件背景

某天监控服务器，发现CPU飙到100%。

2、分析步骤

1、查看进程ID信息

查看进程ID为1507，软件名称为：kdevtmpfsi

2、查看进程信息

根据进程ID查看文件在/tmp目录中

3、关闭进程并删除恶意文件

kill -9 1507 && rm -rf /tmp/kdevtmpfsi

4、查看进程是否异常

发现该文件又被重新启动

查看计划任务，有一个异常的计划任务

crontab -l

5、删除计划任务和关闭恶意进程

crontab -r
crontab -l

kill -9 1915 && rm -rf /tmp/kdevtmpfsi

6、再次查看异常文件

恶意文件又重新启动

ps -aux | grep kdevtmpfsi

7、查看守护进程

systemctl status 1990

发现有异常进程文件kinsinga.sh

8、查看异常脚本信息

ps -aux | grep kinsinga

查找恶意文件路径

find / -name "kinsinga.sh"

9、关闭守护进程和恶意文件

kill -9 1491   # 关闭守护进程
kill -9 1990   # 关闭恶意进程
rm -rf /root/kinsinga.sh
rm -rf /tmp/kdevtmpfsi

3、事后检查

1、检查是否有残余文件

find / -name "*kdevtmpfsi*"

2、查看Linux登录日志

# RedHeat和Centos日志
/var/log/secure

# Ubuntu和Debian日志
/var/log/auth.log

3、检查计划任务

crontab -l
#或者
vim /var/spool/cron/root
