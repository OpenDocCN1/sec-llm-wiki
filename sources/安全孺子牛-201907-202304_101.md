## 1、事件背景

某天监控服务器，发现CPU飙到100%。

![](../Images/9fe3751d6181fdd796941c7e5e4477e9.png)

## 2、分析步骤

### 1、查看进程ID信息

查看进程ID为`1507`，软件名称为：kdevtmpfsi

![](../Images/36979af16ffd71ddb1b1d1a9113cab80.png)

### 2、查看进程信息

根据进程ID查看文件在/tmp目录中

![](../Images/9649b03b99d8f16b29fbd92fa37e7a72.png)

![](../Images/9bb17788a5904d16a893d1ce1148f613.png)

### 3、关闭进程并删除恶意文件

```
kill -9 1507 && rm -rf /tmp/kdevtmpfsi
```

![](../Images/90a415b08216dcba552bd5f593dc056c.png)

### 4、查看进程是否异常

发现该文件又被重新启动

![](../Images/3ee4c6c3ac51d5cf7e506911e91a9b3f.png)

查看计划任务，有一个异常的计划任务

```
crontab -l
```

![](../Images/8aab103c4e2ccf35869095e8525a5b03.png)

### 5、删除计划任务和关闭恶意进程

```

crontab -r
```

![](../Images/ead835836a5490f951634b46aa150c00.png)

```
kill -9 1915 && rm -rf /tmp/kdevtmpfsi
```

![](../Images/fd0ee028086ebf696bdfac0578be3764.png)

### 6、再次查看异常文件

恶意文件又重新启动

```
ps -aux | grep kdevtmpfsi
```

![](../Images/cef778d335c427ded63ef3c04a38c4a8.png)

### 7、查看守护进程

```
systemctl status 1990
```

发现有异常进程文件kinsinga.sh

![](../Images/da6c101edf819b642ad0697b5c3baff8.png)

### 8、查看异常脚本信息

```
ps -aux | grep kinsinga
```

![](../Images/b7cb5452ecda920c6e58e490843be77e.png)

查找恶意文件路径

```
find / -name "kinsinga.sh"
```

![](../Images/13a32019316ec428b4791f32412ecd25.png)

### 9、关闭守护进程和恶意文件

```


kill -9 1491   # 关闭守护进程
```

![](../Images/c0f6f4ce393ad191052f8ac9e11745b2.png)
