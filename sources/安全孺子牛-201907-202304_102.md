## 1、应急概述

根据网络流量分析，发现主机有异常连接，需要进入主机进行查看分析

## 2、分析步骤

### 2.1 网络分析

#### 1.查看网络连接信息

```

```


## 3、攻击路径分析

### 1.文件权限分析

根据文件权限为root账号，怀疑账号为通过SSH弱口令或者爆破进入

![](../Images/7ec0eceb12db6a0932bdefaf74d826fe.png)

### 2.root登录日志分析

#### 1.查看SSH登录日志

```

cd /var/log/
```

![](../Images/af9dcef2ba866840616e7d6d4bbe07e9.png)

#### 2.统计登录日志

```
grep -o "Failed password" /var/log/secure\* |uniq -c
```

在secure-20200601中有76条登录失败记录，在secure-20210420中有1716条登录失败记录，结合1.sh与2.sh文件的日期，猜测是在20211020日被暴力破解的

![](../Images/da48644b345a5e9dc96cefedd0fd1479.png)

#### 3.查看爆破的第一行和最后一行

```


\# 查看第一行
```

查看爆破时间主要在`20210420 03:28:39-03:43:24`

![](../Images/4dfdde1fb450a37a9ae2c3da36b449aa.png)

#### 4.查看哪些IP地址进行爆破

```
grep "Failed password" /var/log/secure-20210420|grep -E -o "(25\[0-5\]|2\[0-4\]\[0-9\]|\[01\]?\[0-9\]\[0-9\]?)\\.(25\[0-5\]|2\[0-4\]\[0-9\]|\[01\]?\[0-9\]\[0-9\]?)\\.(25\[0-5\]|2\[0-4\]\[0-9\]|\[01\]?\[0-9\]\[0-9\]?)\\.(25\[0-5\]|2\[0-4\]\[0-9\]|\[01\]?\[0-9\]\[0-9\]?)"|uniq -c
```

其中发现爆破IP地址主要为`192.168.184.1`和`192.168.184.146`

![](../Images/7fe8bb1a4c17b764b6466a5374d28101.png)

#### 5.查询被爆破的用户名称

```
grep "Failed password" /var/log/secure-20210420|perl -e 'while($\_=<>){ /for(.\*?) from/; print "$1\\n";}'|uniq -c|sort -nr
```

被爆破的用户均为root账号

![](../Images/72e97d37b7d468d81f0a990ec50089ed.png)

#### 6.查询登录成功的用户

```
grep "Accepted " /var/log/secure-20210420 | awk '{print $11}' | sort | uniq -c | sort -nr | more
```

查看爆破登录成功用户有`192.168.184.1`和`192.168.184.146`

![](../Images/f2bec8d50fded37d6d6162753c133a4d.png)

#### 7.查看登录成功的时间

```
grep "Accepted " /var/log/secure-20210420 | awk '{print $1,$2,$3,$9,$11}'
```

![](../Images/eb52208e506da0a4d605d90d7949668e.png)

### 3.总结分析

*   ✅爆破时间：`20210420 03:28:39-03:43:24`
    
*   ✅爆破账号：`root`
    
*   ✅爆破IP地址：`192.168.184.1`和`192.168.184.146`
    

### 4.修复方法

修改root账号为强口令，限制登录频率
