1、以root身份运行

1.1 Cento8安装

cd /etc/yum.repos.d/wget https://download.opensuse.org/repositories/security:zeek/CentOS_8/security:zeek.repoyum install zeek -y

1.2 Centos7安装
cd /etc/yum.repos.d/wget https://download.opensuse.org/repositories/security:zeek/CentOS_7/security:zeek.repoyum install zeek -y

2、测试数据包
2.1 将ZEEK添加到PATH，以root身份创建/etc/profile.d/zeek.sh
vim /etc/profile.d/zeek.sh

pathmunge /opt/zeek/bin/

退出账号并重新登陆
2.2 编辑配置
vim /opt/zeek/share/zeek/site/local.zeek# 添加如下配置@load frameworks/files/extract-all-files
    
在local.bro中设置新的提取默认限制。默认值为25Mb
# 设置文件提取最大单元redef FileExtract::default_limit = 1000000000;
    
4、文件提取
4.1 提取方式
执行完毕后会在当前目录生成多个log和文件提取的
zeek -Cr 111.pcapng frameworks/files/extract-all-files-C  忽略check-sum文件校验-r  指定pacp文件# frameworks/files/extract-all-files    加载文件提取
4.2 查看文件提取信息
more files.log | zeek-cut tx_hosts rx_hosts source analyzers mime_type filename extracted

4.3 提取到的文件
file extract-1604389868.005594-HTTP-F0MioUzt9zcRGQqqa

5、提取http文件
5.1 提取文件
执行完毕后，会在本地目录生成
zeek -Cr example-01.pcap frameworks/files/extract-all-files

5.2 查看文件提取信息
提取文件的信息如下
more files.log | zeek-cut tx_hosts rx_hosts source analyzers mime_type filename extracted
数据包提取的文件包含txt文件、word格式文件和exe可执行文件
5.3 查看提取的文件详情
提取到的文件存放在本地目前的extract_files中，与files.log中文件名相对应
5.4 使用file查看文件信息
6、提取http网页
6.1 提取http网页
zeek -Cr example-02.pcap frameworks/files/extract-all-files
more files.log | zeek-cut tx_hosts rx_hosts source analyzers mime_type filename extracted | grep HTTP

6.2 HTTP页面提取后无法查看
由于http页面存在调用关系，提取后文件名称已经修改，无法查看网页详情
tree extract_files | grep HTTP

10、测试下载一个图片文件提取
10.1 开启本地抓包
tcpdump -i eth0 -w /root/1.pcap

10.2 本地下载一个格式为jpg的图片
wget http://192.168.207.135/aaa.jpg

10.3 使用ZEEK进行提取
zeek -Cr 1.pcap frameworks/files/extract-all-files

10.4 查看文件属性
file extract-1604396151.322058-HTTP-FSMMF72MpBpN8QCO05more extract-1604396151.322058-HTTP-FSMMF72MpBpN8QCO05

more files.log | zeek-cut ts tx_hosts rx_hosts source  mime_type  extracted

10.5 打印小脚本
#!/bin/bashtime=`more files.log | zeek-cut ts`thost=`more files.log | zeek-cut tx_hosts`rhost=`more files.log | zeek-cut rx_hosts`protocol=`more files.log | zeek-cut source`filetype=`more files.log | zeek-cut mime_type`filename=`more files.log | zeek-cut extracted`echo "时间：$time"echo "服务器：$thost"echo "客户端：$rhost"echo "协议：$protocol"echo "文件类型：$filetype"echo "文件名称：$filename"
