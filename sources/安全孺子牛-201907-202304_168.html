1、漏洞扫描

漏洞扫描将使您能够快速扫描目标IP范围以查找已知漏洞，从而使渗透测试人员可以快速了解可能值得进行的攻击。

如果使用得当，这对笔测试仪来说是一笔巨大的财富，但并非没有缺点。众所周知，漏洞扫描具有很高的误报率和误报率。

2、SMB扫描

一个常见的情况是拥有有效的用户名和密码组合，并且想知道您还可以在哪里使用它。这是SMB登录检查扫描程序非常有用的地方，因为它将连接到一系列主机，并确定用户名/密码组合是否可以访问目标。

use auxiliary/scanner/smb/smb_loginset rhosts 192.168.127.133set SMBUser victimset SMBPass s3cr3tset threads 50run

3、VNC认证

VNC身份验证无扫描程序是Metasploit的辅助模块。该工具将搜索一系列IP地址，以查找正在运行未配置密码的VNC服务器的目标。值得每位精干的管理员在允许入站连接之前先设置一个密码，但是您永远不知道什么时候可能会碰到一次幸运的休息，并且成功的笔测不会遗漏任何东西

use auxiliary/scanner/vnc/vnc_none_authset rhosts 192.168.127.0/24set threads 50run

4、WMAP扫描

WMAP是功能丰富的Web应用程序漏洞扫描程序，最初是通过名为SQLMap的工具创建的。该工具与Metasploit集成在一起，使我们能够从Metasploit框架内进行Web应用程序扫描

4.1 加载WMAP

load wmap

4.2 查看wmap帮助

help wmap

4.3 添加站点

wmap_sites -a http://192.168.127.133wmap_sites -l

4.4 设置扫描站点

wmap_targets -d 0或者wmap_targets -t http://192.168.127.133

4.5 扫描站点

wmap_run -h

使用-t开关来列出将用于扫描远程系统的模块

# 显示扫描模块wmap_run -t

4.6 开始进行扫描

wmap_run -e

4.7 查看扫描结果

wmap_vulns -l
