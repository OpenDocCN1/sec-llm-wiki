1、Msfconsole简介

msfconsole可能是最常用的接口使用Metasploit框架（MSF）。它提供了“多合一”集中式控制台，使您可以高效地访问MSF中几乎所有可用的选项。MSFconsole乍一看似乎令人生畏，但是一旦您了解了命令的语法，您就会了解使用此接口的强大功能。

优点：

    • ✅访问Metasploit中大多数功能的唯一受支持的方法。

    • ✅提供框架的基于控制台的界面

    • ✅包含最多的功能，也是最稳定的MSF界面

    • ✅全面的readline支持，制表符和命令完成

    • ✅可以在msfconsole中执行外部命令

3、Msfconsole核心命令

3.1 back 返回命令

完成特定模块的使用后，或者如果无意中选择了错误的模块，则可以使用back命令以移出当前上下文。就像在商用路由器中一样，您可以从其他模块中切换模块。提醒一下，变量只有在全局设置时才会保留。

3.2 banner信息

显示随机选择的banner信息

3.3 check 验证命令

可以检查目标是否易受特定漏洞利用，而不是实际利用它

3.4 connect 连接命令

msfconsole中内置了一个微型Netcat克隆，它支持SSL，代理，数据透视和文件传输。通过发出带有IP地址和端口号的connect命令，您可以像使用Netcat或Telnet一样从msfconsole连接到远程主机。

connect 192.168.207.135 4444

 

3.5 edit 编辑命令

edit命令将使用$VISUAL或$EDITOR编辑当前模块。默认情况下，这将在Vim中打开当前模块。

3.6 exit 退出

使用exit直接退出msfconsole

    

3.7 grep 过滤参数

grep命令类似于Linux grep。它与另一个msfconsole命令的输出中的给定模式匹配。以下是搜索来自搜索包含字符串" oracle"的模块，并使用grep匹配包含字符串" http"的输出的示例。

grep http search oracle

3.8 info 详情信息

info命令将提供有关特定模块的详细信息，包括所有选项，目标和其他信息。使用某些模块之前，请务必先阅读该模块的说明，因为某些说明可能会产生不良影响。

info命令还提供以下信息：

    • ✅作者和许可信息

    • ✅漏洞参考（例如：CVE，BID等）

    • ✅模块可能具有的任何有效负载限制

msf5 > use exploit/windows/smb/ms09_050_smb2_negotiate_func_indexmsf5 exploit(windows/smb/ms09_050_smb2_negotiate_func_index) > info exploit/windows/smb/ms09_050_smb2_negotiate_func_index

3.9 irb ruby解释器

运行irb命令将使您进入实时Ruby解释器外壳，您可以在其中发布命令并即时创建Metasploit脚本。此功能对于理解框架的内部结构也非常有用。

irbputs "Hello, metasploit!"

3.10 jobs 任务管理

jobs是在后台运行的模块。jobs命令提供了列出和终止这些作业的功能。

3.11 kill 结束运行的jobs

当提供job的ID时，kill命令将终止所有正在运行的job。

msf exploit(ms10_002_aurora) > kill 0Stopping job: 0...[*] Server stopped.

3.12 load 加载

load命令从Metasploit的插件目录加载插件。参数在shell上作为key=val传递

3.13 LOADPATH 加载第三方模块路径

loadpath命令将加载第三部分模块树的路径，这样你可以在你的零日漏洞，编码器，有效载荷等点的Metasploit

loadpath /usr/share/metasploit-framework/modules/

3.14 unload 卸载模块

unload命令将卸载以前加载的插件，并删除所有扩展命令

unload pcap_log
3.15 resource 加载批处理

resource命令运行可以通过msfconsole加载的资源（批处理）文件

比如一些攻击，如Karmetasploit，使用资源文件来运行一组命令在karma.rc文件中创建的攻击

批处理文件可以大大加快测试和开发时间，并允许用户自动执行许多任务。除了从msfconsole中加载批处理文件之外，还可以在启动时使用-r标志来传递它们。下面的简单示例创建一个批处理文件，以在启动时显示Metasploit版本号。

3.16 route 路由模式

Metasploit中的route命令允许您通过会话或“ comm”路由套接字，从而提供基本的透视功能。要添加路由，请传递目标子网和网络掩码，后跟会话（通信）号。

3.17 search 搜索

msfconsole包括广泛的基于正则表达式的搜索功能。如果您对要查找的内容有大致了解，则可以通过搜索进行搜索。在下面的输出中，正在搜索MS公告ms08_067。搜索功能将在模块名称，描述，参考等中找到此字符串。

search ms08_067

3.17.1 name 名称搜索

要使用描述性名称进行搜索，请使用name关键字。

search name:mysql

3.17.2 platform  平台搜索

您可以使用平台将搜索范围缩小到影响特定平台的模块。

search platform:aix

3.17.3 type 类型搜索

使用类型可以按模块类型进行过滤，例如辅助，漏洞利用等。

search type:post

3.17.4 author 作者搜索

使用author关键字搜索可让您按喜爱的作者搜索模块。

search author:dookie

3.17.5 多条件搜索

可以将多个关键字组合在一起以进一步缩小返回结果的范围。

search cve:2011 author:jduck platform:linux

3.18 sessions 会话

session命令允许您列出，与生成的会话进行交互并杀死生成的会话。这些会话可以是shell，Meterpreter会话，VNC等。


-l 选项要列出任何活动的会话

session -l

使用-i 参数然后加上会话的ID号，便可以与给定的会话进行交互。

sessions -i 1
3.19 set 配置参数

set命令允许您为正在使用的当前模块配置Framework选项和参数。

Metasploit还允许您设置要在运行时使用的编码器。当您不确定哪种有效负载编码方法适用于给定漏洞利用时，这在漏洞利用开发中特别有用。

3.20 unset 取消设置

与set命令相反的是设置的。unset删除先前用set配置的参数。您可以使用全部取消设置来删除所有分配的变量。

3.21 setg 设置全局变量

为了节省大量的输入时间，可以在msfconsole中设置全局变量。您可以使用setg命令执行此操作。设置完这些之后，您可以根据需要在许多漏洞利用程序和辅助模块中使用它们。您还可以保存它们，以备下次启动msfconsole时使用。但是，陷阱是忘记保存全局变量，因此在运行或利用之前请务必检查您的选项。相反，您可以使用unsetg命令取消设置全局变量。在下面的示例中，变量以大写字母（即LHOST）输入，但是Metasploit不区分大小写，因此没有必要这样做。

 setg RHOSTS 192.168.1.0/24

设置完不同的变量后，您可以运行save命令来保存当前的环境和设置。保存您的设置后，它们将在启动时自动加载，从而使您不必再次设置所有内容。

save

3.22 show 查看

可以使用许多show命令，但最经常使用的命令是show assistant，show exploit，showpayload，show encoder和show nops。

3.22.1 show auxiliary  查看辅助模块

执行显示辅助将显示Metasploit中所有可用辅助模块的列表。如前所述，辅助模块包括扫描器，拒绝服务模块，模糊测试等。

show auxiliary

3.22.2 show exploits 查看攻击模块

运行show exploits以获取框架中包含的所有利用程序的列表。

show exploits

3.22.3 show payloads 查看攻击载荷

运行显示有效载荷将显示Metasploit中可用的所有平台的所有不同有效载荷。

show payloads

3.22.4 show encoders 查看编码模块

正在运行的显示编码器将显示MSF中可用的编码器列表。

show encoders

3.22.5 show nops 查看nops生成器

使用show nops命令将显示Metasploit必须提供的NOP生成器。

show nops

3.23 漏洞模块查看参数

3.23.1 show payloads 查看模块对应的攻击载荷

当处于特定漏洞利用的环境中时，使用show只会显示与该特定漏洞利用兼容的有效负载。例如，如果是Windows漏洞利用，则不会显示Linux有效负载。

exploit(windows/smb/ms08_067_netapi) > show payloads

3.23.2 show options 查看配置选项

如果选择了特定模块，则可以发出show options命令以显示该特定模块可用和/或必需的设置。

exploit(windows/smb/ms08_067_netapi) > show options

3.23.3 show targets 查看支持目标

如果不确定操作系统是否容易受到特定漏洞利用，在漏洞利用模块的中运行show target命令，以查看支持哪些目标。

exploit(windows/smb/ms08_067_netapi) > show targets

3.23.4 show advanced 查看高级选项

如果希望进一步微调漏洞利用程序，可以通过运行show advanced查看更多高级选项。

exploit(windows/smb/ms08_067_netapi) > show advanced
