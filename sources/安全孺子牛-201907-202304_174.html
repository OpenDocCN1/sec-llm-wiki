1、简介

Metasploit是目前世界上领先的渗透测试工具，也是信息安全与渗透测试领域最大的开源项目之一。它彻底改变了我们执行安全测试的方式。

Metasploit之所以流行，是因为它可以执行广泛的安全测试任务，从而简化渗透测试的工作。Metasploit适用于所有流行的操作系统，主要以Kali Linux为主。因为Kali Linux预装了Metasploit框架和运行在框架上的其他第三方工具。

2、Metasploit文件系统

在Kali Linux中，metasploit-framework软件包中提供了Metasploit，并将其安装在/usr/share/metasploit-framework目录中

2.1 data目录

data目录包含Metasploit用于存储某些漏洞利用，单词列表，图像等所需的二进制文件的可编辑文件

2.2 documentation

顾名思义，文档目录包含该框架的可用文档。

2.3 lib

lib目录包含框架代码库的"内容"

2.4 modules

在modules目录中，您可以找到用于漏洞利用，辅助和后期模块，有效负载，编码器和nop生成器的实际MSF模块。

2.5 plugins

Metasploit包含许多插件

2.6 scripts

脚本目录包含Meterpreter和其他脚本

2.7 tools

工具目录具有各种有用的命令行实用程序。

3、渗透测试模块

所有Metasploit模块都组织在单独的目录中。它将在两个位置中进行查找

第一个是主模块存储在/usr/share/metasploit-framework/modules/下，第二个是存储自定义模块的位置，位于主目录下~/.msf4/modules/。

3.1 Exploits 漏洞利用模块

利用系统漏洞进行攻击的行为，此模块对应每一个具体漏洞的攻击方法（包括主动、被动方式）

3.2 Auxiliary 辅助模块

执行信息收集、枚举、指纹探测、嗅探、扫描等功能的辅助模块

3.3 Payloads 攻击载荷

成功执行exploit之后，真正在目标系统执行的代码或指令，包括shellcode或系统命令

其中在payloads模块下包括三个目录

3.3.1 stagers模块

目标系统内存有限时，先传输一个较小的payload用于建立连接

3.3.2 stages模块

利用stager建立的连接下载后续的payload

3.3.3 singles模块

包含所有的payload

3.4 Encoders 加密模块

对payload进行加密，躲避AV检查的模块

3.5 Nops 稳定性模块

Nops可以使攻击尝试中的有效载荷大小保持一致

3.6 Post 后渗透攻击模块

主要支持在渗透攻击取得目标系统远程控制权之后，在受控系统中进行各种各样的后渗透攻击动作，比如获取敏感信息，进一步括展，实施跳板攻击等

3.7 Evasion 免杀模块

从MSF 5.0以后新增加AV免杀模块，目前仅支持Windows平台

3.8 加载其他模块

Metasploit可以选择在运行时或已启动msfconsole之后加载模块。

3.8.1 启动加载模块

运行msfconsole时传递-m选项以在运行时加载其他模块：

msfconsole -m ~/secret-modules/

3.8.2 运行系统后加载模块

如果需要使用msfconsole加载其他模块，请使用loadpath命令

loadpath /usr/share/metasploit-framework/modules/
