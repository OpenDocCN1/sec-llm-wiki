1、TOP查看

    登录查看之后执行TOP命令发现有一个进程非常可疑，进程名为HT8sUu71，

    发现该进程CPU使用率为438%，严重影响业务，查看该进程执行的目录显示文件在/tmp中

2、系统排查

2.1 开机启动

    Linux木马一般会写在定时任务和开机启动中，查看开机启动，查看/etc/rc.local中，没有启动文件

more /etc/rc.local

2.2 定时任务

crontab -l

2.3 清除定时任务

crontab -e

    删除里面的文件，显示没有权限，由于登录用户为root账号，初步判断为加chattr权限了

lsattr /var/spool/cron/root

2.4 取消chattr禁止修改权限

    取消权限的同时，并清空定时任务，同时加上chattr进行继续写入脚本

chattr -i /var/spool/cron/root && echo "" > /var/spool/cron/root  && chattr +i /var/spool/cron/root
2.5 杀死进程

     杀死可疑进程，并删除执行文件

kill -9 21537 && rm -rf /tmp/HT8sUy

rm -rf /usr/bin/rbftfa3 && rm -rf usr/libexec/rbftfa3 && rm -rf && rm - rf /usr/local/bin/rbftfa3 && rm -rf /tmp/rbftfa3

    重启操作系统即可
