1、简介


    SSLH接受指定端口上的连接，并根据对远程客户端发送的第一个数据包进行的测试进一步转发它们。

    实现了针对HTTP，TLS / SSL（包括SNI和ALPN），SSH，OpenVPN，tinc，XMPP的探针，并且可以识别可以使用正则表达式测试的任何其他协议。

    典型的用例是允许在端口443上提供多种服务（例如，从公司防火墙内部连接到SSH，几乎从不阻止端口443），同时仍在该端口上提供HTTPS。

    SSLH 具有成熟守护程序所期望的一切：特权和功能下降，inetd支持，systemd支持，透明代理，chroot，日志记录，IPv4和IPv6，基于fork和基于select的模型等等。


2、部署安装


2.1 Debian、Ubuntu和衍生系统上
sudo apt-get install sslh
2.2 在RHEL、CentOS上，你需要添加EPEL存储库，然后安装SSLH
sudo yum install epel-releasesudo yum install sslh
