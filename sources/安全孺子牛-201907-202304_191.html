1、简介


ProxyTunnel是一个程序，它通过标准HTTPS代理将stdin和stdout连接到网络上某个服务器。我们主要使用它来通过HTTP（S）代理建立SSH会话隧道，从而使我们能够完成许多没有ProxyTunnel不可能完成的工作。


  • 通过标准的HTTP/HTTPS代理创建隧道

  • 通过HTTP Connect方法封装信息

  • 适用于内网使用代理并且防火墙只允许代理服务器上网的情景

  • 无法创建DNS隧道和ICMP隧道情况


2、客户端部署


客户端使用Centos7进行测试

2.1 安装proxytunnel软件包
yum -y install asciidoc openssl-devel xmltogit clone https://github.com/proxytunnel/proxytunnel.gitcd proxytunnel/make && make install
2.2 安装Squid
yum -y install squid
2.3 修改squid配置
vim /etc/squid/squid.conf  http_port 192.168.1.2:3128  http_access allow !Safe_ports  http_access allow CONNECT !SSL_ports  http_access allow all
2.4 启动squid服务
systemctl start squid

3、服务器端部署


服务器端使用kali进行测试


3.1 安装squid服务器端
sudo apt-get install squid
3.2 配置squid服务器
vim /etc/squid/squid.conf  http_port 192.168.207.134:3128  http_access allow !Safe_ports  http_access allow CONNECT !SSL_ports  http_access allow all
