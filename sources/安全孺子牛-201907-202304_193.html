1、简介


    icmptunnel是一个将IP流量封装到ICMP echo请求和回复（ping）包中的隧道工具，是在允许ping的网络中进行拓展、绕过防火墙的一种半隐蔽方式。虽然ICMP echo流量在网络边界通常会被过滤，但这种方法仍然可能对从企业内网出连到互联网的技术有一定帮助。


    虽然一些现有工具已经实现了这一技术，但在穿透状态防火墙和NAT方面，icmptunnel提供了一个更可靠的协议和机制。


2、服务器端部署


2.1 配置部署
git clone https://github.com/jamesbarlow/icmptunnel.gitcd icmptunnel/make
2.2 禁用icmp请求和应答
echo 1 > /proc/sys/net/ipv4/icmp_echo_ignore_all
2.3 启动服务器端
sudo ./icmptunnel -s
2.4 新开一个终端配置一个隧道接口
sudo /sbin/ifconfig tun0 10.0.0.1 netmask 255.255.255.0


3、客户端部署


3.1 配置部署
git clone https://github.com/jamesbarlow/icmptunnel.gitcd icmptunnel/make
3.2 禁用icmp请求和应答
echo 1 > /proc/sys/net/ipv4/icmp_echo_ignore_all
3.3 启动客户端
sudo ./icmptunnel 192.168.207.134
3.4 新开一个终端创建一个隧道
sudo /sbin/ifconfig tun0 10.0.0.2 netmask 255.255.255.0

4、服务器连接

客户端和服务器已经建立一个隧道，直接可以访问服务器地址。
