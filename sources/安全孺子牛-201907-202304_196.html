1、简介


    iodine基于C语言开发，分为服务端程序 iodined 和客户端程序 iodine，kali系统已内置。

  • 支持EDNS、base32，base64，base128等多种编码规范，性能更优

  • 支持多平台：Linux、BSD、Mac OS、Windows

  • 最大支持16个并发连接

  • 强制密码支持

  • 支持同网段隧道IP

  • 支持多种DNS记录类型

  • 丰富的隧道质量检测措施


    1.1 支持类型

    • ✅A

    • ✅TXT

    • ✅CNAME

    • ✅MX

    • ✅NULL

    • ✅SRV

    • ✅PRIVATE


      1.2 转发模式

      • ✅直连模式：客户端直接向指定IP的恶意DNS服务器发起DNS解析请求

      • ✅中继模式：像我们平时上网一样，DNS解析先经过互联网的迭代解析，最后指向我们的恶意DNS服务器。相比直连，速度较慢，但是更安全


      2、iodine服务器端

          本文中使用kali作为服务器端，默认已经安装服务器端为iodined、客户端为iodine


      2.1 开启iodine服务器端
      sudo iodined -P 123456 -f -c 10.0.0.1 ns.test.com
      -P          #认证密码-f        #前台显示，运行后一直在命令行等待-c        #指定创建一个虚拟网卡，不能与本地网络冲突-D          #指定调试级别，-DD指第二级，‘D’随等级增加

      3、iodine客户端

      3.1 文件下载
      https://github.com/yarrick/iodine/archive/master.zipyum -y install zlib-devel
      3.2 安装
      unzip master.zipcd iodine-master/make && make install

      3.3 开启iodine客户端

      iodine -f -P 123456 ns.test.com -r
      -f         #前端展示-P         #指定密码-r         #采用DNS中继模式传输数据-M         #指定上行主机名大小-m         #调节最大下行分片大小-T         #指定所使用的DNS请求类型，可选有NULL,PRIVATE,TXT,SRV,MX,CNAME,A-O         #指定数据编码规范-L         #是否使用懒惰模式，默认开启-I         #指定请求间的时间间隔
