1、简介


  • C/S ( dns2tcpc / dns2tcpd ) 结构

  • 通过TXT记录加密传输数据（A记录长度有限制）

  • 隧道建立后保持连接

  • 默认记录生存时间TTL值为3秒


    1.1 支持类型

    • ✅ TXT


    2、配置dns2tcp服务器端

        在本次测试中使用的是kali作为dns2tcp服务器端，默认自带不需要安装


    2.1 修改配置文件
    sudo vim /etc/dns2tcpd.conf
    listen = 0.0.0.0     #修改监听地址port = 53user = nobodychroot = /tmpkey = pass123domain = ns.test.com    #NS解析对应的域名resources = ssh:192.168.207.134:22,http:192.168.207.134:8080,socks:192.168.207.134:4444  #地址修改为服务器IP,socket端口为任意，这里为4444
    2.2 启动服务
    sudo dns2tcpd -F -d 1 -f /etc/dns2tcpd.conf
    – F      #前台展示– d      #debug level 1-3– f      #指定配置文件


    3、配置dns2tcp客户端

    3.1 软件下载
    https://pan.baidu.com/s/14SIxdiIWHKZDUz6lgn_Zag     提取码：t1rw
    3.2 编译安装
    unzip dns2tcp-master.zipcd dns2tcp-master/./configuremake && make install
    3.3 连接测试
    dns2tcpc -c -k pass123 -d 1  -l 7002 -r ssh  -z   ns.test.com
    -c    # 启用压缩-k    # 指定密码-d    # debug_level-l    # 绑定本地端口-r    # 远端资源-z    # 域名
