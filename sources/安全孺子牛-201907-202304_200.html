1、简介

    在上篇文章中介绍如何部署Modsecurity，但是在实际环境中，业务出现问题排查Modsecurity需要登录系统，去检索日志系统。本文中介绍如何使用Logstash针对Modsecurity日志进行收集。


2、配置modsecurity日志

# 创建Modsecurity日志目录mkdir -p /var/log/modsecurity/chmod 775 /var/log/modsecurityvim /usr/local/nginx/conf/modsecurity.conf

# 开启日志记录，并以Json格式输出SecAuditEngine OnSecAuditLogRelevantStatus "^(?:5|4(?!04))"SecAuditLogParts ABIJDEFHZSecAuditLogType SerialSecAuditLog /var/log/modsecurity/modsec_audit.logSecAuditLogFormat JSON

3、安装logstash

yum install java-1.8.0-openjdk.x86_64 -yyum install logstash -y
