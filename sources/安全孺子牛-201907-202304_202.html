1、简介


    nmap-vulners和vulscan这两个脚本旨在通过为特定服务（如SSH，RDP，SMB等）生成相关的CVE信息来增强Nmap的版本检测，默认没有该脚本，需要自行下载。


2、nmap-vulners


2.1 下载

下载到nmap的默认脚本文件夹中，不需要进行额外的配置

cd /usr/share/nmap/scripts/git clone https://github.com/vulnersCom/nmap-vulners.git

2.2 扫描测试

nmap --script nmap-vulners -sV 192.168.11.131


3、vulscan


3.1 下载

下载到nmap的默认脚本文件夹中

cd /usr/share/nmap/scripts/git clone https://github.com/scipag/vulscan.git


3.2 配置

    由于vulscan是利用预先存放在本地的配置文件来检索CVE漏洞信息，因此需要对vulscan进行简单的配置。这些配置文件放置在vulscan文件夹的根目录下，vulscan支持多个漏洞数据库配置，完整配置文件如下：

scipvuldb.csvcve.csvosvdb.csvsecurityfocus.csvsecuritytracker.csvxforce.csvexpliotdb.csvopenvas.csv

    为了确保这些配置已经更新至最新的数据，可以通过vulscan/utilities/updater/目录中的脚本updateFiles.sh对配置数据进行更新。

cd /usr/share/nmap/scripts/vulscan/utilities/updater/sh updateFiles.sh


3.3 扫描测试

    vulscan脚本的开发者会时常更新scipvuldb.csv这个数据配置文件，因此查询这个数据配置输出的结果是最新最全的

nmap --script vulscan --script-args vulscandb=scipvuldb.csv -sV 192.168.11.131


4、组合扫描

    可以同时使用两个脚本进行组合扫描测试

nmap --script nmap-vulners,vulscan --script-args vulscandb=scipvuldb.csv -sV 192.168.11.131
