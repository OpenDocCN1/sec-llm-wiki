1、简介


    ElastAlert是一个简单的框架，用于从Elasticsearch中的数据中检测异常，尖峰或其他感兴趣的模式的警报。通过将Elasticsearch与两种类型的组件（规则类型和警报）结合使用。定期查询Elasticsearch，并将数据传递到规则类型，该规则类型确定何时找到匹配项。发生匹配时，将为该警报提供一个或多个警报，这些警报将根据匹配采取行动。

    Github：https://github.com/Yelp/elastalert

    官方文档：https://elastalert.readthedocs.io/en/latest/


2、告警类型


    ElastAlert包含几种具有常见监视范例的规则类型：


  •  blacklist类型 ：

        黑名单规则将检查黑名单中的某个字段，如果它在黑名单中则匹配。

  • whitelist类型 ：

       与黑名单类似，此规则将某个字段与白名单进行比较，如果列表中不包含该字词，则匹配。

  • change类型 ：

        此规则将监视某个字段，并在该字段更改时进行匹配，该领域必须相对于最后一个事件发生相同的变化。

  • frequency类型 ：

        当给定时间范围内至少有一定数量的事件时，此规则匹配。这可以按照每个query_key来计数

  • spike类型 ：

        当某个时间段内的事件量比上一个时间段的spike_height时间大或小时，这个规则是匹配的。它使用两个滑动窗口来比较事件的当前和参考频率。我们将这两个窗口称为“参考”和“当前”。

  • flatline类型：

        当一个时间段内的事件总数低于一个给定的阈值时，匹配规则。

  • cardinality类型 ：

        当一个时间范围内的特定字段的唯一值的总数高于或低于阈值时，该规则匹配

  • percentage match类型 ：

        当计算窗口内的匹配桶中的文档的百分比高于或低于阈值时，此规则匹配。计算窗口默认为buffer_time。

5、配置elastalert告警


    5.1 下载配置文件

git clone https://github.com/Yelp/elastalert.git && cd elastalertmkdir -p /etc/elastalert/rulescp config.yaml.example /etc/elastalert/config.yaml

    5.2 编辑配置文件

vim /etc/elastalert/config.yaml
#elastalert规则存放目录rules_folder: /etc/elastalert/rules#elastalert进行查询的时间周期，可以周、日、时、分、秒run_every:  #minutes: 1  seconds：30  #hours：1    #days：1    #weeks：1    #查询时间范围，默认是15分钟buffer_time:  minutes: 15    #ES的ip地址es_host: 192.168.1.10
#ES的连接端口es_port: 9200     #这个是elastalert 在es里边写的indexwriteback_index: elastalert_status    #如果alert当时没有发出去重试多久之后放弃发送alert_time_limit:  days: 2

7、配置systemd开机启动


     7.1 配置systemd

cat > /etc/systemd/system/elastalertd.service <<EOF[Unit]Description=elastalertdAfter=elasticsearch.service
[Service]Type=simpleUser=rootGroup=rootWorkingDirectory=/etc/elastalertExecStart=/usr/local/bin/elastalert --config /etc/elastalert/config.yamlEnvironment=PATH=/bin:/usr/bin:/usr/local/bin
[Install]WantedBy=multi-user.targetEOF

     7.2 启动服务并设置开机自启

systemctl daemon-reloadsystemctl enable elastalertd.servicesystemctl start elastalertd.servicesystemctl status elastalertd.service
