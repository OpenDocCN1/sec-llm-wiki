1、elasticsearch简介


    Elasticsearch是天生支持集群的，他不需要依赖其他的服务发现和注册的组件，如zookeeper这些，因为他内置了一个名字叫ZenDiscovery的模块，是elasticsearch自己实现的一套用于节点发现和选主等功能的组件，所以elasticsearch做起集群来非常简单，不需要太多额外的配置和安装额外的第三方组件。

3、安装部署elasticsearch

    

  • 下载elasticsearch

wget https://artifacts.elastic.co/downloads/elasticsearch/elasticsearch-7.6.1-x86_64.rpm

  • 安装elasticsearch

rpm -Uvh elasticsearch-7.6.1-x86_64.rpm

  • 调整elasticsearch的JVM参数，官方建议JVM为物理内存的50%

vim /etc/elasticsearch/jvm.options

‍

  • 配置elasticsearch集群参数，cluster名称必须保持一致，node名称不一样

vim /etc/elasticsearch/elasticsearch.yml

  • 设置本机监听地址和端口

  • 设置集群发现、master节点、最少集群状态

  • 以此类推，三台全部都需要配置，由于测试环境可以关闭主机防火墙，线上环境建议放行9200和9300端口，由于elasticsearch目前没有做安全认证，不建议开放到互联网上。

systemctl stop firewalldsystemctl status firewalld

  • 每个节点启动elasticsearch，并查看启动状态

systemctl start elasticsearch.service systemctl enable elasticsearch.servicesystemctl status elasticsearch.service


4、查看elasticsearch集群状态

    

  • 调用elasticsearch的API接口查看集群状态，状态显示green，节点数量为3，目前集群状态正常

curl -XGET http://192.168.207.12:9200/_cluster/health?pretty
