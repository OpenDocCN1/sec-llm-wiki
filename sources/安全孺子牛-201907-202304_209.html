1、Curator简介


    Curator最早被称为clearESindices.py。它的唯一功能是删除索引，

而后重命名：logstash_index_cleaner.py。它在logstash存储库下作用：过期日志清理。此后不久，原作者加入Elastic，它成为了Elasticsearch Curator，Git地址：https://github.com/elastic/curator。目前最新版本为5.8


2、Curator功能


  • 从别名添加或删除索引（或两者都删除！）

  • 更改分片路由分配

  • 关闭索引

  • 创建索引

  • 删除索引

  • 删除快照

  • 开放封闭指数

  • 打开被关闭的索

  • 重新索引，包括来自远程集群的索引

  • 更改索引每个分片的副本数

  • 累积指数

  • 拍摄索引快照（备份）

  • 恢复快照

3、安装Curator

    

  • 安装pip

curl https://bootstrap.pypa.io/get-pip.py -o get-pip.pypython get-pip.py

   

  • 安装elasticsearch-curator

rpm --import https://packages.elastic.co/GPG-KEY-elasticsearch

cat > /etc/yum.repos.d/curator.repo << EOF[curator-5]name=CentOS/RHEL 7 repository for Elasticsearch Curator 5.x packagesbaseurl=https://packages.elastic.co/curator/5/centos/7gpgcheck=1gpgkey=https://packages.elastic.co/GPG-KEY-elasticsearchenabled=1EOF
yum install elasticsearch-curator -y

    

4、配置Curator


  •  默认配置文件在~/.curator/curator.yml,基本配置为空，需要指定ES的IP地址、端口是否需要启用用户名密码认证。

vim /root/.curator/curator.yml
---  # Remember, leave a key empty if there is no value.  None will be a string,# not a Python "NoneType"client:  hosts:    - 192.168.100.10   //指定ES的IP地址  port: 9200           //指定ES的端口  url_prefix:  use_ssl: False  certificate:  client_cert:  client_key:  ssl_no_validate: False  http_auth: elastic:xmhKHHkujYq2cuDo9BLE    //如果没有开启认证保持为空  timeout: 30  master_only: Falselogging:  loglevel: INFO  logfile:  logformat: default  blacklist: ['elasticsearch', 'urllib3']

  • 配置文件为例

vim /root/.curator/deletelog.yml

---# Remember, leave a key empty if there is no value.  None will be a string,# not a Python "NoneType"## Also remember that all examples have 'disable_action' set to True.  If you# want to use this action as a template, be sure to set this to False after# copying it.actions:  1:    action: delete_indices    description: >-      Delete indices older than 5 days (based on index name), for logstash-      prefixed indices. Ignore the error if the filter does not result in an      actionable list of indices (ignore_empty_list) and exit cleanly.    options:      ignore_empty_list: True      disable_action: False    filters:    - filtertype: pattern      kind: prefix      value: dns-               //以删除文件为例    - filtertype: age      source: name      direction: older      timestring: '%Y.%m.%d'      unit: days      unit_count: 5            //删除5天前的索引

  • 配置定时删除任务

0 0 * * * /usr/bin/curator ---config /root/.curator/curator.yml /root/.curator/deletelog.yml
