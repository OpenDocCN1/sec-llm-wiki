1、本文中使用为中文界面，可能会出现中文乱码的情况

2、默认SSH服务是关闭，开启SSH服务并开机启动，输入kali用户密码

systemctl start sshsystemctl enable ssh

3、查看虚拟机IP地址

sudo ifconfig

4、使用xshell类似的ssh工具连接，配置更新源

sudo vim /etc/apt/sources.list

5、添加阿里源

deb http://mirrors.aliyun.com/kali kali-rolling main non-free contribdeb-src http://mirrors.aliyun.com/kali kali-rolling main non-free contrib

6、进行系统更新

sudo apt-get update && sudo apt-get upgrade

7、安装中文字体包，并重启后就不会显示乱码的现象

sudo apt-get install ttf-wqy-microhei ttf-wqy-zenhei xfonts-intl-chinesereboot

8、Metasploit进行查询时，会调用postgresql加快查询速度。开启postgresql服务，配置开机启动。

sudo systemctl start postgresqlsudo systemctl enable postgresql

9、初始metasploit数据库连接

sudo msfdb init

10、进入metasploit查看数据库连接信息，显示已经连接到数据msf了

msfconsole> db_status

至此Kali Linux基本环境配置完毕
