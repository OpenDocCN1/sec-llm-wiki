# Kali Linux 2020.1a 基本安装部署

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MDI0NTM2Nw==&mid=2247483708&idx=1&sn=b98ee48f04ee78ef73ef6bcf82c48bb6&chksm=ea6dd324dd1a5a32725ebb2cd68b45e1adf970c1ce7580114232b11619ce8858c0a4316748f1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2MDI0NTM2Nw==&mid=2247483708&idx=1&sn=b98ee48f04ee78ef73ef6bcf82c48bb6&chksm=ea6dd324dd1a5a32725ebb2cd68b45e1adf970c1ce7580114232b11619ce8858c0a4316748f1&scene=27#wechat_redirect)

Kali Linux在2020年3月进行升级，如果您已经在运行2020.1，则无需重新安装。2020.1a版本仅适用于无法成功安装2020.1的用户。  

    更新功能如下：

*   默认为非 root
    
*   Kali Single 安装程序镜像
    
*   Kali NetHunter Rootless
    
*   主题和 kali-undercover 的改进
    
*   新工具
