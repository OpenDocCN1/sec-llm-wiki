# ELK7.2单节点安装部署教程-elasticsearch7.2安装

1、软件安装平台：

    Centos7  

  

2、ELK安装版本：7.2  

1.      elasticsearch7.2  
    
2.      kibana7.2  
    
3.      logstash.72
    

  

3、软件安装，首先需要去官网进行软件包下载，这里以Centos使用RPM进行安装，由于新版本的elasticsearch的RPM已经集成JDK1.9，直接RPM安装既可

    #  rpm -Uvh elasticsearch-7.2.0-x86\_64.rpm

![](../Images/8204ea7ec8347b777070974aa2714d80.png)

    #  systemctl daemon-reload  

    #  systemctl enable elasticsearch.service

    #   systemctl start elasticsearch.service

 4、软件开启以后，默认监听9200和9300,9200作为对我提供服务的接口，9300为elasticsearch集群的监听端口  

    通过netstat -antup查看已经开启9200和9300端口，默认监听在127.0.0.1的环回口

![](../Images/a4ca8fe271a52e697d7f2f63f3107f17.png)

  

5、使用curl验证运行是否正常

    #  curl http://127.0.0.1:9200/\_cluster/health?pretty&level=indices

![](../Images/20f80bb81fae28a8637b9a9d43c9a7ab.png)

  

6、kibana安装配置  

    #  rpm -Uvh kibana-7.2.0-x86\_64.rpm

![](../Images/be7bf3e591c66bf87cb2e8c673343926.png)

    #  systemctl enable kibana

    默认kibana监听在127.0.0.1网络接口，编辑kibana配置文件  

    #  vim /etc/kibana/kibana.yml

         server.host: "0.0.0.0"               //修改serve.host为0.0.0.0

         elasticsearch.hosts: \["http://localhost:9200"\]         //取消该段注释

         i18n.locale: "zh-CN"                 //取消注释，修改为zh-CN中文支持

    #  systemctl start kibana  

    查看监听端口为5601，不建议在公网上面放开所有，目前仅在测试环境部署，后面会介绍使用ELK的X-PACK功能，做用户名密码认证

![](../Images/686069668ce67ba35f3cfc46319b250c.png)

7、验证kibana的连通性，

      验证地址：http://IP:5601

      注：测试环境中，关闭firewalld,  

             #  systemctl stop firewalld  

![](../Images/abc4bede3687b91bbfb75c7c3f412f08.png)
