# 勒索蠕虫来袭 知道创宇严阵以待 避免持续入侵扩散

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMDc5NzYwNQ==&mid=2652403312&idx=1&sn=6dd36fcd3ac80700418498fa46125088&chksm=80a6013ab7d1882cb60f623057b585cff606bf48e435114d5d49a3d6d81743a6edc7e12eabbf&scene=126&sessionid=1681368857#rd](http://mp.weixin.qq.com/s?__biz=MzAxMDc5NzYwNQ==&mid=2652403312&idx=1&sn=6dd36fcd3ac80700418498fa46125088&chksm=80a6013ab7d1882cb60f623057b585cff606bf48e435114d5d49a3d6d81743a6edc7e12eabbf&scene=126&sessionid=1681368857#rd)

2017年5月12日晚些时候，据知道创宇威胁情报检测中心发现，不明黑客组织通过精心改良日前新一轮曝光的NSA网络攻击工具，在网上不断扩散一种新型蠕虫勒索病毒，不幸中招的用户需向勒索方支付300美金，目前国内多处高校网络和企业内网感染了这一新型蠕虫勒索病毒。据最新威胁情报显示，对于这一新型蠕虫勒索病毒，也开始有越来越多的后续不法黑客组织加入阵营，不排除存在其它勒索方式。

![](../Images/b1022babbb12c0016a7ebce2105ef0cf.png)

▲恶意程序勒索界面

据知道创宇404安全实验室分析确认，这一新型蠕虫勒索病毒正是利用了4月14日影子经纪人曝光的美国国家安全局使用的网络攻击工具，不明黑客组织利用改良后的SMB远程命令执行工具实施感染。虽然微软已经推出相关修复补丁（MS17-101），但仍有大量主机特别是内网主机并未完成补丁升级，造成了这些新型蠕虫勒索病毒的不断扩散。

MS17-010 SMB 远程命令执行漏洞全球影响及修复与自检

![](../Images/74dad79bc7010795fa392613bcf1597c.png)

▲MS17-010 SMB 远程命令执行漏洞全球影响（4月26日探测结果）

早些时候，知道创宇404安全实验室利用ZoomEye网络空间搜索引擎就已经给出全球对于最新MS17系列远程命令执行漏洞和Doublepulsar 后门全球探测报告（https://www.zoomeye.org/lab/ms17-010），报告对攻击程序主要染指的445端口做了全球系统扫描探测，对接下来可能出现的攻击做了系统的预判，并给出了相应的检测与修复方案，显然这仍未得到足够多的安全重视。

**检测与修复方案**

检测方案:

1\. 本地检测：通过Github项目doublepulsar-detection-script检测Doublepulsar后门是否被植入。

2\. 在线检测：通过访问Seebug照妖镜即可在线检测Eternalblue Windows SMB远程代码执行漏洞以及是否被植入Doublepulsar后门

**修复方案**

微软已经就相关漏洞发布MS17-010安全公告。请及时将系统更新到最新版。

**照妖镜在线检测**

![](../Images/6bdc0041f1a7fdc76c71e843e982360c.png)

▲Seebug已针对Web主机开放在线检测工具

目前用户Web服务端可通过知道创宇所运营的Seebug漏洞社区提供的照妖镜功能检测是否存在SMB远程代码执行漏洞，以迅速更新微软早先发布的MS17-010安全补丁。

“云图”威胁感知系统提供快速发现能力

对于运行的内外网主机，可以使用知道创宇“云图”威胁感知系统对入侵勒索蠕虫病毒做出系统捕获及进一步分析工作。

云图系统采用机器学习及全面沙箱分析与入侵指标（IOC）确认技术，通过BDE行为检测引擎及SDE规则检测引擎实时分析网络流量，可深度监控链接所有可疑活动。

Zoomeye网络空间雷达系统已集成主动威胁识别方法

![](../Images/7209d6182e3f01227cce9fb15079ad77.png)

![](../Images/93f782fe5f2f1064e14834c4ec2c449c.png)▲利用Zoomeye网络空间雷达系统可实施全网脆弱性检测，定位此次漏洞威胁影响面

  

同时，知道创宇推出的Zoomeye网络空间雷达系统早于4月下旬便已集成了相关的检测脚本，也可以利用这一先进工具完成校园、企业内网的全面资产威胁普查，以便协助监管单位完成进一步的安全升级工作，避免这一新型勒索蠕虫病毒的进一步传播。
