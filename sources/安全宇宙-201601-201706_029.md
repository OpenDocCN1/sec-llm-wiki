# 知道创宇锅涛：如何解决网络暗黑世界的运维之殇

2017年4月8日，由51CTO&DBAplus技术沙龙 共同举办的“大话运维保障之道沙龙” 在北京举行。大话运维保障之道系列技术沙龙，以目前最火热的互联网技术和运维体系为核心，本期更是以《大话运维保障之道——大中型企业运维保障和DevOps实践之路》为主题，汇集了互联网运维方面的资深专家分享交流，沙龙现场火爆参会人员多达200人。**知道创宇云安全作为唯一一家云安全厂商获邀参加本次沙龙，充分表明了运维业界对知道创宇安全技术攻坚能力的高度认可。知道创宇高级安全顾问锅涛在研讨会上发表了《网络暗黑世界之业务系统异常解惑》的演讲。**

  

![](../Images/393b5e6762199b47901f6a0499b43495.png)

  

锅涛在演讲中提到：“随着互联网+的发展，越来越多企业互联网化，而随之带来的是运维工作的加重，但对运维而言最痛的事情无疑是事件报警接踵而来，告警短信、告警邮件、故障电话数不胜数。对于如此之多的安全事件，通常企业用了很多硬件设备，做了层层防御仍不见效。”

  

![](../Images/e5dfd9a4165e307a8a990b73b91e9f43.png)

  

锅涛表示：“企业做了层层防御而不见效其实是有原因的。互联网技术在发展，目前的DDoS攻击已不再是简单的大流量攻击，网络层包括SYN-flood、ACK-flood、UDP-flood、ICMP-flood；应用层包括CC、DNS-flood、慢速连接攻击、DoS攻击；业务层常见的则是如刷体验金、刷优惠券、刷返利金、刷红包、刷短信网关等类CC攻击。而攻击方式有：混合型、反射型、流量放大型、脉冲型、链路泛洪等。**最近，新型的DDoS攻击—网络空间暗黑DDoS攻击出现，它之所以称之为暗黑DDoS攻击，是因为这类攻击真正的威胁并非来自 DDoS攻击本身，而是通过DDoS攻击的形式窃取核心数据信息。**”

  

![](../Images/b8a82f2c0c2533cc060062eeb191c029.png)

  

锅涛还向与会人员分析了“**传统安全防护的短板“，网络边界失效、基于已知特征被动防护、防护能力远远跟不上高维攻击，是目前主要的三大短板，而知道创宇Cyberspace网络新战场未来防御模式，它包含了全球监测、大数据分析、威胁情报和云防御。**知道创宇云安全具备自我学习能力，通过对攻击数据的学习，形成动态的防御体系，黑客输入的攻击数据越多，自我学习动态防御的能力就越高。可以通过对访问会话、相关数据和历史数据的关联分析构建恶意黑库和黑客指纹库。目前，恶意黑库累积超过10亿条。利用恶意黑库可以迅速定位攻击源，实施精准拦截！

  

![](../Images/c16c3ccc4437bef5f1a9114c6aceaf56.png)

  

知道创宇云安全防御平台，能够为网站建立起一道难以逾越的安全屏障，并实施高效智能的云端防御，加之“三位一体”的防御体系，使黑客望而却步，同时也让企业在添加策略的时候不再繁琐，保障企业业务连续性，同时为企业塑造安全“轻”运维模式。
