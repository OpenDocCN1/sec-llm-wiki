# 第六届中国公益节 知道创宇获“2016年度公益践行奖”

2017年1月10-11日，第六届中国公益节于北京富力万丽酒店举行，公益节设立于2011年，是首个由大众媒体联袂发起的以“公益”命名的节日。旨在弘扬公益精神，倡导公益行为，搭建多方深度对话、合作沟通的平台。如今，公益节已经成为推动公益事业发展的重要载体。六年来，公益节始终作为公益行为的见证者与公益精神的传播者，始终致力于传递向上向善的力量，让更多人建立起关注和参与公益的态度，以促成“全民公益”的实现。知道创宇受邀参加本届公益节活动，并获得了“2016年度公益践行奖”，极大的肯定了知道创宇在公益方面做出的贡献。  

 ![](../Images/d9ccdd8ed7696bebe4ec672cc02337e0.png)

  

知道创宇是一家成立有10年的网络安全公司。在最新的FIT互联网安全报告中显示，知道创宇已经一跃而成中国云WAF市场占有率最高的网络安全公司。公司创立之初，就立足于“互联网的安全必须做在攻击者的前面，才能从根本上对威胁产生最大的防护能力。“

  

![](../Images/f8b9aa074b7d529631371ca0000ef6b7.png)

  

知道创宇新业务部总监周梦琪代表知道创宇领奖，在获奖感言上，她说道：“什么才是中国网民的实际困难和需求？网络上充斥着的黄赌毒、坑蒙拐骗偷，才是对网民造成最大安全隐患的源头。这已经不完全是技术范畴的安全，而是社会化安全的范畴。在这样的背景下，知道创宇开辟了一个全新的领域——网络安全的社会化治理。网络安全的社会化治理，光是靠某一些机构，或者某一些企业来完成，基本上都无法实现，我们只有团结一切可团结的力量，才能为网民提供真正安全又放心的网络环境。基于这样的想法，在2012年9月，知道创宇联合腾讯、百度、金山共同创立了‘安全联盟’。它的主要任务是，团结越来越多的互联网厂商、硬件厂商、运营商等，建立业内统一安全标准、跨平台统一行动，以达到打击跨平台网络欺诈等关乎网民直接利益的网络黑产行为。”

  

![](../Images/e5e23e4a0d4dbb49415ee655f82da7b9.png)

  

知道创宇的口号是“侠之大者，为国为民”。周梦琪在发言中提到：“基于为国为民的公司理念，知道创宇建立了全方位的网站安全保障体系，不仅能够为政府及企业提供一流的网络安全解决方案，近几年也在不断加大力度打击电信网络诈骗。作为一家有社会责任感的企业，知道创宇在这些年的发展过程中也不断地主动履行社会责任、关注公益事业。”

  

![](../Images/ff449d648d7872870399397f7f1faa18.png)

  

“我们连续两年参加了由新浪发起的‘暖冬行动’公益计划，身体力行的进行募集御寒衣物及其他生活物资，让山区的贫困孩子能度过一个温暖的冬天。2015年11月21日，我们与新浪亲自为达州宣汉县双河口小学的孩子们送去了棉衣、棉被等爱心物资。2016年11月30日，我们与新浪经历了整整2天的长途跋涉，最终把爱心物资安全送达甘孜巴塘县茶洛乡中心小学学生手中。”周梦琪讲到。

  

随着互联网+时代的到来，新的思维与技术带来的变革，为社会创新提供了特殊条件，也对公益行为带来影响。知道创宇的公益行动永不会停止。作为互联网+的技术型企业，知道创宇今后还将继续支持这样的公益活动，在实际行动中回馈社会，践行自己的责任。
