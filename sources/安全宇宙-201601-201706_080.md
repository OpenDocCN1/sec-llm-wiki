# 【走进企业】第二十九期：微贷网携手知道创宇打造更安全的互联网汽车金融信息服务平台

12月8日，知道创宇云安全“走进企业”活动再次开启新篇章，走进了素有“中国互联网金融车贷平台先河”之称的微贷网。知道创宇云安全资深安全顾问锅涛现场介绍分享了许多信息安全相关的宝贵经验，也与微贷网的多名员工一同就互联网时代下的风险与挑战话题进行了深入交流探讨，现场气氛高涨，精彩纷呈。

![](../Images/30aa135eed1866c6a25175a5f29f989c.png)

  

微贷网于2011年上线运营，融合“互联网+金融+汽车”，以互联网为主要渠道，为借款人与出借人实现直接借贷提供信息搜集、信息公布、资信评估、信息交互、借贷撮合等服务，致力于打造一个规范、安全、透明、诚信的互联网金融服务平台。微贷网以锐意进取、开拓创新的企业精神，围绕产品、风控、服务、行业自律四大体系，建立标准化模式，并建立投资人监督委员会，推动行业朝着规范有序的方向发展。

  

  
![](../Images/115731fc17345f1be305811c6f9ad399.png)

  

据微贷网的负责人介绍，在缩短金融时空距离的同时，微贷网建立了专业、成熟、严谨的风控体系。2016年微贷网通过招标，与厦门银行签定直连模式资金存管合作协议，严格按照《网络借贷信息中介机构业务活动管理暂行办法》和《网络借贷资金存管业务指引（征求意见稿）》的要求规定，来进行技术、制度等方面的对接，着力打造合规、安全的中国互联网汽车金融信息服务平台。网络攻击日益严重的今日，微贷网特别邀请知道创宇资深安全顾问郭涛和大家共同交流讨论。

  

锅涛从事信息安全多年，拥有丰富的国际安全产品经验，对Web应用安全、恶意代码分析、下一代防火墙等安全解决方案很有经验，已为中国邮政储蓄银行、中国民生银行、国美在线等公司提供安全咨询服务。锅涛表示：“在‘互联网+’的时代下，随着互联网与各个行业深度融合，网络安全和信息安全正在成为公司、行业乃至国家层面上非常重要的话题。近年来，工业控制系统、智能技术应用、云计算、移动支付领域面临的网络安全风险进一步加大，黑客组织和网络恐怖组织等非国家行为体发起的网络安全攻击也在持续增加，影响力和破坏性显著增强，我国网络安全形势也更加严峻。黑客的攻击手段纷繁复杂，其中主流的有DDoS攻击、流量攻击、CC攻击、SQL注入、篡改、远程代码执行、远程溢出、嵌入恶意代码等，当中以DDoS攻击跃居首位。”

  

![](../Images/c054d563258c3c7334259dc7085f4ca0.png)  

  

接下来，锅涛为大家详细刨析了暗黑的DDoS攻击，并介绍了知道创宇云安全旗下与金融行业发展最息息相关的产品——抗D保。抗D保是知道创宇云安全推出的专业防御大流量DDoS攻击的产品。锅涛表示：“在这种目前的大环境大背景下，选择一款可靠有效的抵御DDoS攻击的产品尤为重要。知道创宇云安全的核心产品“抗D保”就拥有7X24小时的快速应急响应机制，自动触发、实时防护，无需用户干预即可全面应对攻击。此外，抗D保拥有30余个高防机房和DDoS清洗中心，全网2T（ 2017年将扩展至10T）抗D宽带，可应对超大规模攻击。知道创宇的核心成员均为技术专家出身，拥有多年以上网络维护和网络安全经验，以及网络安全方面多项国际高水平认证。从研发、运营到市场推广一路走过来，服务质量一直受到对业务连续性和可用性有较高要求的诸多考验，但抗D保在几次重大突发攻击事件中都很好的展现出了能力，在市场上拥有良好的用户口碑。”  

  

![](../Images/dc1af9c74da93a09a5daf39796481368.png)

  

在培训的最后，微贷网的负责人表示：“多年来风雨兼程，微贷网所有的努力都是为了担当起客户日益升级的投资需求和财富目标，为客户在安全的前提下创造价值是微贷网的初衷与不变追求。互联网金融已经从过去的野蛮生长年代，来到了规范化和优胜略汰的新纪元，只有真正重视业务安全性的企业，和重视用户数据的企业才可能赢得用户的信任。”
