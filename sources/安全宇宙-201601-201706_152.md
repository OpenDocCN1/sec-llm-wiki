# 中国“征信＋”高峰论坛 知道创宇发布业务反欺诈服务「浑天」

6月30日－7月1日，2016中国“征信＋”应用发展高峰论坛在深圳举行，会议以“重构信用价值、激发创新力量”为主题展开演讲讨论。此次活动受到了深圳互联网金融协会、广东互联网金融协会的大力支持。本次大会大咖云集、思想交融，为征信市场的有序发展提供了交流学习、信息共享的平台，推动解决P2P网贷行业平台运营过程中的安全与风险问题，共同探索互联网大数据时代的征信应用于实践，帮助实现行业间的合作共赢。**国内领军云安全厂商知道创宇携新产品「业务反欺诈服务—浑天」出席本次盛会，知道创宇大数据安全负责人潘少华发表主题演讲《知道创宇浑天反欺诈分享》。**

  

![](../Images/4e8619c896db8b2b84118220e5ccc696.png)  

  

浑天——浑象，天象之变；浑仪，测天之器。

  

潘少华首先向与会者解释了“浑天”的来历。“古之圣人仰观天文，俯察地理，中通人事，考星辰之变化而推人命之休咎，运用以数定象，因数明象的独特象数思维模式，以此建构了一套时空合一，三才一体，万物同构的生命数理信息模型，此乃千古不传之谜——浑天。浑天说分为“浑象”、“浑仪”。浑象，天象之变；浑仪，测天之器。浑天说不只是一种宇宙学说，而且是一种观测和测量天体视运动的计算体系，与现代的球面天文学一脉同源。”  

  

![](../Images/e48ffa6166c52e64827ce86e5f011ea1.png)  

  

知道创宇对多年积累的安全大数据进行深度挖掘，并精细剖析行业中易产生欺诈行为的业务场景，使用独有的拓扑数据分析、多维画像关联与在线学习两个大数据模型，创造性地构建出知道创宇业务反欺诈服务，以“浑天”之名，为业务安全提供全方位保护。

  

浑天智慧 安全磐石

知道创宇自主研发大数据风控技术，通过知道创宇的“创宇盾、抗D宝、安全联盟”等云安全产品的长期运行，采集了千万级的黑产数据；通过对互联网黑市的渗透，掌握百万级的被黑产利用的高危帐号信息；整合了百万级的欺诈信息，亿级的地理位置、设备数据，千万级的恶意IP；通过第三方数据的挖掘，掌握了亿级的征信数据、支付数据，十亿级的运营商脱敏数据，百万级的公安数据。

  

潘少华在演讲中表示：“知道创宇是公安部、工信部、央行、国务院、高法、国税的技术支撑单位。浑天的数据来源为公开来源、自有数据和第三方数据，数据就好比浑天的血液，而知道创宇最大的优势就是能保证这些数据都是可以在持续的更新，支撑产品不断的强大，旨在为信贷理财、电商O2O、运营商等行业，量身订做业务反欺诈行业解决方案，实时监控主要业务节点异常，防止业务欺诈行为发生，为行业业务安全保驾护航。”

 

![](../Images/dce11605672d3cbea94cdd6faad7e0e0.png)  

  

“8年来，知道创宇始终坚持在一线与网络黑客黑产进行对抗，在黑客攻击、网络欺诈方面有着丰富的实战经验。在云安全领域，我们已为500余家网贷企业提供安全防护服务。**这几年，网贷企业的风控环节中，虚假信息欺诈已成为重灾区，为了增加平台安全性，净化网贷环境，一些P2P平台积极尝试引入第三方服务商的数据和技术，强化风控体系建设。**浑天上线后，势必为平台上的网贷企业提供更完善、全面的风控服务。” 潘少华讲到。

  

潘少华称，提升反欺诈能力已经成为信贷理财、电商O2O、运营商等行业迫在眉睫的需要，他向与会者展示了，浑天依托强大的技术研发能力与行业领先的风控理念， 推出的以下服务：

**1.1 注册保护**

提供虚假信息与恶意软件脚本识别等服务保护注册安全。  

**1.2 登录保护**

通过拖库撞库识别、登录环境检测、异常用户行为识别等技术保护登录安全。

**1.3 活动防刷**

利用环境检测、黑库匹配识别等技术防止活动被刷。

**1.4 业务反欺诈**

知道创宇·浑天为信贷理财、电商O2O、运营商等行业，量身订做业务反欺诈行业解决方案，实时监控主要业务节点异常，防止业务欺诈行为发生，为行业业务安全保驾护航。

  

浑天产品优势明显，知道创宇多年来专注于安全行业，积累了数十亿条恶意黑数据；通过独有的拓扑数据分析、多维画像关联与在线学习两个大数据分析模型，风险识别准确率高于95％；高于99.99%的可用性、毫秒级响应时间、每秒万级并发量，保障业务顺利进行；从接入测试到正式部署使用，皆由经验丰富的行业业务安全专家全程提供支撑，并提供7\*24小时全天候售后响应支持。

  

浑天期待更多的具备远见卓识的企业加入到“浑天反欺诈风控阵营”。潘少华表示：“**风控技术一直被看做是网站的隐性门槛，也是线上平台能够正常运营的核心与保障。**在国内征信体系尚不完善的背景下，浑天旨在为企业建立风控的第一道防线‘反欺诈’，助力企业建立科学、完善的风控体系，促进企业及整个行业的健康发展。”
