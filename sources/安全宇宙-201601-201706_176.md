# 云端之上的数据和隐私如何保护？

云端时代，信息安全和隐私保护成为云上企业最关注的话题。近年来，愈来愈多的网络攻击和黑客暴行频现，互联网上的数据、隐私已经成为黑客觊觎的“生财之物”。近年，网络安全事件更是频频占据新闻头条，其中不乏涉猎政府、企业和个人的数据信息泄露。

  

**问题的根本在于：**1

企业及个人对数据信息的保护意识和安全意识不够；

2

企业对自己平台的安全状况不了解，不能第一时间确定出企业平台所存在的安全风险；

3

个人识别真实可靠网站的能力不够，不能快速有效的在网络中选出企业的真实网站，被钓鱼的风险极高。

  

  

![](../Images/820ad99f3e0d210d96d91c412951a28c.png)  

  

目前，黑客攻击企业最常见的类型有以下几种：

  

1  阻断用户访问

  

**这种攻击通常发生在大型网站和热门网站，造成“阻断用户访问”最普遍的攻击手法则是DDoS和CC攻击****（DDoS和CC攻击是以耗尽网站的服务器性能和带宽为目的，阻止其他用户访问的攻击方式）**。DDoS和CC攻击的技术含量较低，并且此类黑产的产业链已经极为成熟，即使是技术不高的人，只要花钱购买肉鸡，从网上下载工具就可以发起攻击。2015年7月，著名的比特币交易平台OKCoin中国站和国际站均遭受到了大规模DDoS和CC攻击，导致部分用户短时间内不能访问。**针对这种情况，最快最有效的方法就是足够大的带宽储备，让你的带宽足够大，这样就无法达到DDoS的目的。**

  

![](../Images/0f6599c616944458bc061872eb68215e.png)  

  

2  将域名劫持到恶意网站

  

“域名劫持”也是企业用户经常遇到的一种攻击方式，通常表现为“网民输入一个网站的网址，打开的却是另一个网站”。2013年6月，大众点评遇到的就是典型的“域名劫持”，由于大众点评网的域名服务商新网网站程序存在漏洞，导致黑客可以修改任意新网注册域名的IP指向，使北京地区用户访问大众点评网域名时会被跳转到天猫的促销页面，此次攻击持续时间长达十几个小时，造成的损失无法估量。这种现象可以分为以下几种情况：

  

a

黑客通过病毒修改了用户客户端电脑的HOST列表，使一个正确的域名对应了错误的IP地址；

b

用户所在的局域网，比如小区宽带、校园网、公司局域网等被ARP病毒感染，病毒劫持了局域网内的HTTP请求；

c

网站所在的服务器机房遇到了ARP攻击；

d

黑客通过技术手段，篡改了域名注册商管理的服务器。

  

前三种情况仅影响部分用户，第四种情况影响的是所有用户，危害最大。

  

3  在网站中植入病毒和木马

  

攻击企业网站，并在服务器上植入恶意代码，是另一种应用广泛的黑客攻击形式。2015年反病毒实验室新发现的电脑病毒数为1.45亿个，较2014年增加了5%。病毒感染量达48.26亿次，流氓软件感染量达3.70亿次，盗号木马感染量达0.80亿次。病毒破坏性增强，难以防范。

  

![](../Images/7145a36e2167847b5e9894fc9219df6b.png)  

  

4  商业机密外泄

  

随着市场竞争的日益激烈，有的企业会雇佣黑客获取竞争对手的数据，从而在市场竞争中占据先机。也不乏有些互联网公司由于对网络安全的重视程度不够，核心服务器暴露于互联网外网，从而导致企业数据外泄。例如，有些学校的毕业证查询系统被黑客攻击，黑客可以肆意修改毕业生记录，进而收取钱财等。

 

![](../Images/84ba84db2a4a6bbaf11b6a240fe448ee.png)
