# 知道创宇成广州互联网金融协会首批会员单位

近年来，P2P网贷、第三方支付、众筹、互联网小贷公司等互联网金融各细分行业极具创新活力和增长潜力，受到国家高度重视。2014政府工作报告明确提出“要促进互联网金融健康发展”。广州互联网金融协会于2015年4月10日正式成立，致力于促进互联网金融行业互联互通、相互交融、规范有序发展。

  

**2016年4月**

知道创宇成为广州互联网金融协会的首批会员单位，这是知道创宇云安全自去年起，深耕长江以南区域以来，广东各大互联网金融企业对知道创宇云安全安全工作肯定的证明。知道创宇云安全在为互联网金融企业建起坚固围墙的同时，已然得到了行业协会、行业企业的高度认可。**截止目前，知道创宇云安全已服务了近300家互联网金融企业。**

  

![](../Images/dfa049079ae4ea7a6d0f7b0586ee1267.png)  

  

目前协会成员有95家，共15类会员类型，范围涵盖了主要互联网金融业态，包括P2P网络借贷平台、众筹平台、第三方支付、互联网小贷公司、科技公司等基础会员，还包括创新较好、能与基础会员开展业务互动的银行、保险、证券、广州股交中心、广州仲裁委、联合信任时间戳、征信公司、行业门户网站和评级机构、上市顾问、中介机构、研究机构、专家学者等，是国内会员类型最多的互联网金融行业协会，形成了互联、互通、互助的大互联网金融生态圈。

 

![](../Images/618dbd42322a14329e4fedf2d9b02674.png)  

  

知道创宇作为广州互联网金融协会中的网络安全公司，为广州互联网金融协会中的成员单位保驾护航。截止到2016年，全国共有3500+家P2P平台，平均注册资本2468万元，在互联网金融爆发的同时，安全问题也逐渐显现。**在互联网金融业中常见的安全问题有：数据泄漏并进行黑市交易；账户信息泄漏，客户资金不翼而飞；互联网金融企业遭遇黑客敲诈勒索；羊毛党肆意薅羊毛等等。****知道创宇云安全提供一站式网站解决方案，保障网站可用性不受侵害。**

  

![](../Images/2f93532463cb9bfa95e343e52f2f861e.png)  

  

**知道创宇云安全防御平台包含“加速乐、创宇盾、抗D保”三大云安全产品以及“品牌宝”认证服务产品。**加速乐主要进行CDN内容分发服务，创宇盾拥有全面的防护能力，抗D宝则主要负责防DDoS、CC攻击等防黑业务。同时，知道创宇云安全三大安全产品具备自我学习能力，通过对攻击数据的学习，形成动态的防御体系，黑客输入的攻击数据越多，自我学习动态防御的能力就越高，为互联网金融平台的Web系统提供全面安全加速防护服务。**其次，再辅以品牌宝，为互联网金融企业提供企业商业转化，建立P2P企业的良性信誉。**

  

![](../Images/9cd0a577c4fcc177e4c19b8411d74753.png)  

  

为了更好的服务互联网企业，知道创宇云安全［走进企业］第二期正式启动。作为知道创宇云公益项目之一，［走进企业］旨在为企业提供免费的安全培训专项活动。第二期的活动将围绕互联网金融和电商网站开展，知道创宇云安全的资深安全专家将会结合8年的安全从业经验为您的企业进行最专业的免费安全培训，针对各企业量身打造独有的安全解决方案。未来，知道创宇云安全将继续深耕互联网金融领域，力保各平台稳健、茁壮发展。
