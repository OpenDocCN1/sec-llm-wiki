# 知道创宇云安全亮相WOT峰会 打造现代化安全“轻”运维

今日（4月14日），由51CTO主办的WOT大会之“互联网运维与开发者峰会”在京召开。作为上半年度最万众瞩目的运维技术盛会，涵盖了各领域运维核心技术，国内外优秀互联网企业运维专家超过1000人到场交流互动。知道创宇作为国内优秀的互联网安全公司获邀参与此次盛会。**知道创宇云安全高级安全顾问锅涛在“运维安全”论坛上发表了《云安全助力“轻”安全运维》的主题演讲，深入分析了如何利用云安全技术将传统运维转化为高效率、低成本的现代“轻”运维。**

 ![](../Images/65f1c5520f6652b211e32bfc76ef9c64.png)  

  

锅涛在演讲中提到：“在传统运维中，陈旧的架构需要花费大量时间来获取我们所需要的数据，从而迫使我们在效率和数据之间进行选择；其次，复杂的产品部署方式及管理方式使得安全运维成本飞涨。然而，在各个企业进行独立运维的时候，往往某个单一事件本身并不能提供足够多的上下文信息，以识别现在愈来愈高级的威胁。运维不仅仅在技术层面有着重要的价值，在业务层面也有着首屈一指的价值。然而，现阶段安全运维依旧停留在分析日志的层面，等到安全事件发生后，再人工对日志记录进行调查，统计事件发生的频率、搜索事件、追踪溯源。”

 

“现在摆在企业面前的运维情况是，网站面对黑客攻击时，你依旧是孤军奋战，处于被动状态。黑客的攻击入口多种多样，手段变幻莫测，加之在线业务系统层出不穷的安全漏洞隐患，凭一己之力完全不能有效解决。”锅涛如是说。

  

![](../Images/0b04fc8c8e65c5038604532167c8b95b.png)  

  

 对处于黑客行为猖獗的大数据云时代中的企业来说，传统的运维方式固然不可抛弃，但安全运维迫在眉睫。锅涛在演讲中对“如何利用云技术助力运维”做了详细的解读：“**知道创宇云安全平台每天对86万+网站进行安全监控，拥有33万＋个黑客的指纹信息，对数千万次真实攻击进行实时统计，对过亿条日志进行分析。**通过知道创宇云安全平台上的海量数据，知道创宇云安全团队研发了‘协同防御’机制，该机制不再是简单的定位攻击源IP，它可以通过对访问会话、相关数据和历史数据的关联分析，将其组合起来、计算概率，再为每个攻击源打上标记，然后利用关联分析后的数据构建恶意黑库和黑客指纹库。”

 

“知道创宇云安全防御平台深度学习智能技术对抗复杂多变的黑客攻击，其防御体系每一秒都在自动根据黑客攻击行为调整防护策略。知道创宇云安全不再仅仅是简单的数据堆积，而是具备了自我学习的能力，目前云平台已经学习了几千万种不同的攻击方式，直接智能转化为防御方式。”

   

知道创宇云安全不断提高自我学习的能力，通过对攻击数据进行学习，就形成动态的防御体系，黑客输入的攻击数据越多，自我学习动态防御的能力就越高。**知道创宇云安全实验室，专注捕获、分析、挖掘、模拟黑客攻击手段；知道创宇云安全检测平台，主要监控全球站点的安全状态，具备强大的态势感知能力；知道创宇云安全防御平台，则为网站建立起了一道难以逾越的安全屏障，24小时实施高效智能的云端防御。**知道创宇云安全“三位一体”的防御体系，为企业筑起坚固的“防御城墙”，同时也简化了企业的添加策略，为企业彻底塑造了一个安全的“轻”运维模式。
