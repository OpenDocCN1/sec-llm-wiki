# 如何利用人工智能进行网络安全防御？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMDc5NzYwNQ==&mid=404837016&idx=1&sn=9ac179ee7cae6d5cc0c35f0c9fec4f06&chksm=069f25d231e8acc447ded714f6fd13d3e3339fcfa1ce3f02a30d43d6375c316865d6c76d0b7e&scene=126&sessionid=1681368922#rd](http://mp.weixin.qq.com/s?__biz=MzAxMDc5NzYwNQ==&mid=404837016&idx=1&sn=9ac179ee7cae6d5cc0c35f0c9fec4f06&chksm=069f25d231e8acc447ded714f6fd13d3e3339fcfa1ce3f02a30d43d6375c316865d6c76d0b7e&scene=126&sessionid=1681368922#rd)

为了帮助行业及时了解高新技术的应用，防范技术风险，2016年4月8日，由中国基金业协会、中国保险资产管理业协会和另类投资者协会(AIMA)共同举办的“人工智能在资管行业的应用及网络安全研讨会” 在京举行。500多参会人员为中国基金业协会、中国保险资产管理业协会各会员单位高管、部门负责人及相关业务人员。知道创宇云安全作为唯一安全厂商获邀参加本次研讨会，充分表明了资管业内对知道创宇安全技术攻坚能力的高度认可。**知道创宇高级安全顾问锅涛在研讨会上发表了《人工智能在信息安全领域的应用与突破》的演讲。**

  

![](../Images/9fdcc12bbb7b1d75f252a002b84e8fd1.png)  

  

近日，围棋世界冠军李世石对决谷歌人工智能“阿尔法围棋”，引发了社会各界对人工智能的关注与热评。国家《十三五规划纲要草案》首次出现了“人工智能”一词。“人工智能即将创造巨额财富，成为引领发展的第一动力”已成为当季行业最热门话题。从蒸汽机革命、能源革命、信息革命，再到新一轮的“革命”，人工智能的发展或将成为改变世界的起点。“互联网+大数据+人工智能”将颠覆资管行业的原有运作模式，人工智能将会应用到投研、交易及客户服务等诸多环节，在给行业带来超高效率的同时也会带来许多潜在风险，信息技术及网络安全也成为了人工智能应用中亟待解决的问题。

  

锅涛在演讲中提到：“人机大战表明了人工智能的进步，与此同时，知道创宇云安全防御平台深度学习智能技术对抗复杂多变的黑客攻击，知道创宇云安全防御体系每一秒都在自动根据黑客攻击调整防护策略。**利用人工智能，知道创宇云安全不再是简单的数据堆积，而是具备自我学习的能力，目前云平台已经学习了几千万种不同的攻击方式，可以智能转化为防御方式。**”

  

![](../Images/58655e23254deb0d800a8c93543c1903.png)  

  

锅涛向与会人员展示“人工智能在知道创宇云安全平台上的应用”，知道创宇云安全具备自我学习能力，通过对攻击数据的学习，形成动态的防御体系，黑客输入的攻击数据越多，自我学习动态防御的能力就越高。人工智能的使用在知道创宇云安全平台上已经有非常大的突破，可以通过对访问会话、相关数据和历史数据的关联分析构建恶意黑库和黑客指纹库。目前，恶意黑库累积超过10亿条。利用恶意黑库可以做什么？迅速定位攻击源，实施精准拦截！

  

锅涛还表示：“人工智能将是未来发展趋势，但数据安全是先决条件。人们离人工智能时代越来越近，但是这样的研究同样伴随安全问题的产生，这将是我们未来担忧的重点。预防人工智能带来的数据安全风险，主动防护将成为工作的重中之重。对于人工智能，我们希望它为社会带来更多的便捷，而对于随之而来的安全风险，我们应该采用最好的解决办法去应对。比如，与以知道创宇云安全为首的专业防御平台合作。知道创宇云安全也立志为人工智能安全发展保驾护航。”
