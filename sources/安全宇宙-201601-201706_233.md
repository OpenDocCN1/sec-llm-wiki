# 调查：60%中小型企业受到网络攻击六个月后倒闭

国内某知名网络安全研究机构日前发布《2015年最新网络犯罪损失报告》中指出，国内企业每年因为受到网络黑客攻击，平均遭受了大约 1270 万元的损失。报告中研究的对象公司，平均需要 170 天的时间才能察觉出遭到了网络攻击，再需要平均31 天的时间来修复造成的损失。这意味着，大部分的公司从遭到网络攻击到完成补丁修复的时间，长达半年之久。但是，这大半年时间，被黑的网站会产生什么恶劣的影响：  

  

**1\. 网站降权**

搜索引擎一旦检测到网站被挂马，就可能对网站进行降权性惩罚，严重的甚至被K掉。尤其是使用百度统计等相关百度系工具的网站更是会被察觉异常而受到惩罚。即便是没有被百度发觉，大流量的攻击也会影响蜘蛛顺利抓取网站。

  

**2\. 信誉下降**

网络攻击会导致网站数据泄漏、信息被盗、财产受损，严重损害网站信誉带。这种卑鄙的手段，已经被归属为网络违法行为。然而仍有许多不法分子受利益驱使，逆流而上。SQL注入属于比较常见的攻击，专门破坏和攻击数据服务器，会把网站上的网页替换掉或修改网站网页，让网站受损。有一些网站发生过的用户名和密码被盗取，也是攻击所致。  

  

**3\. 风险提示**

网站被黑客攻击、挂马、出现敏感词，会在搜索引擎出现网站安全风险提示，被拦截无法进入。对于辛辛苦苦的网站运营来说，做站几个月终于有权重了，不幸的是，被百度提示安全风险，拦截进入网站的行为，对于SEO来说，不利于网站优化，同时浪费了不少的推广费。  

          

          从调查上还可以看出，目前只有四分之一的中小企业主认为自己处于网络攻击危险风险当中，但是，只有2%的企业把黑客攻击防御置于优先地位。许多人错误地认为只有像苹果这样的大公司才更容易受到黑客攻击，其实不然，仅2015年，只要具备在线交易功能的网站，无一幸免，均遭受过黑客的恶意访问。知道创宇云安全高级安全顾问王利伟表示：“中国中小企业有近5000万家，在互联网转型浪潮中，这些企业才是真正处于风险浪潮中，他们才是不法黑客的首要目标。”

  

调查显示，那些被忽略、没有成功拦截的网络攻击，会让60%的中小企业在六个月内倒闭。所以，以互联网金融、网游、O2O、电商为首的在线交易平台，一旦遭遇DDoS致网络中断，轻则商誉受损，重则永远关门。

SO

中小型企业更应以完善网络安全建设和客户隐私维护为重点，重视大数据环境下的网络安全问题，以及加强对基于大数据网络安全技术的研究，强化机制体系建设，营造业内安全、稳定的发展环境。作为大宗商品、虚拟交易行业中的第三方交易平台，可以根据自身网站安全建设需求接入第三方软件服务，通过安全性评测、应用安全评测、监测预警和风险评估等等，加强平台的可靠性，建立健全大数据安全保障体系。
