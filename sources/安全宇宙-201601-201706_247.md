# 互联网金融迎强监管时代 P2P平台如何实现稳健发展

日前，中央政法工作会议在北京召开，会议特别强调要对互联网金融领域存在的问题进行专项整治。中央政法委书记孟建柱表示，金融安全事关经济安全和社会稳定的全局。当前，一些网络借贷平台存在较大风险，要配合有关部门进行整改，推动对民间融资借贷活动的规范和监管，提高风险发现、预警能力。

  

在刚刚过去的2015年，互联网金融发展迅猛，其中P2P网贷增长速度更是惊人，但随之暴露出的问题也层出不穷。据网贷之家发布的统计数据，2015年网贷行业累计平台数量达到3858家，其中问题平台达1263家。这些问题平台，或经营不善、或非法集资、或遭黑客攻击、或被不法份子仿冒进行诈骗……给投资人带来损失的同时，也给行业发展造成极为不良的影响。

  

在政法部门宣布将开展互联网金融领域专项整治后，正式版的网贷监管细则也呼之欲出。也就是说，经过了长达8年“无监管、无规则、无门槛”的野蛮生长局面之后， P2P平台将正式进入一个强监管时代。在这个“风口”阶段，P2P应如何完善平台建设、防范风险、趋利避害，实现健康平稳发展呢？

  

1增强风控能力 规范资金管理

“风控”一直是P2P平台的核心问题。企业想要增强风控能力，必须利用互联网技术对风控逻辑、征信技术等方面进行进一步创新，如运用大数据构建模型的方法对借款人进行风险控制和风险提示等。

  

此外，在监管细则正式出台前，企业应严格规范资金管理，通过第三方合作托管用户资金、第三方担保交易的方式给投资者提供一个安全、可靠的投资理财平台。

  

2拥抱云安全  保障线上业务系统安全性

 P2P网站由于直接牵涉投资者的资金、个人信息、银行账户等敏感信息，其危险系数比一般网站高得多。近年来由于黑客攻击导致系统瘫痪、数据被恶意篡改、资金被盗取的事件时有发生。企业在做平台网站建设时务必要重视安全问题，通过加密连接、二次验证、防火墙等技术手段保证平台安全。同时，还应当提高技术人员安全意识、规范系统开发建设、建立完整完善的开发运营规范制度。

其次，为了做好安全防控，解决线上业务系统的一系列问题，企业可选择与优质的云平台服务商进行合作，建立健全Web体系。“知道创宇云安全”整合知道创宇公司旗下4大核心产品：抗D保、创宇盾、加速乐、品牌宝，可为互联网金融企业制定Web专属解决方案，提供一站式网站服务。不论是恶意流量清洗、Web业务系统放入侵，还是CDN网页访问加速，网站可信验证等，都可通过“知道创宇云安全”解决。日前，“知道创宇云安全”还推出了\[走进企业\]公益项目，该项目将免费对互联网金融企业进行管理层意识培训、技术人员专业培训、全员安全意识培训。

  

3进行网站验证 彰显企业资质

近年来，由于资金监管缺失，信息不透明等状况，使得部分平台借机诈骗敛财，携款款跑路事件频频发生，以P2P网贷为噱头的钓鱼网站也层出不穷。数据显示，2015年平均每月新增195家P2P钓鱼网站，P2P平台可谓是遭遇了极大的信任危机。为了保障投资者免受侵害，重塑与客户间的信任感，建议企业可进行网站验证，对外彰显企业资质与合法性，展示网站真实性。

  

目前，通过知道创宇云安全旗下 “品牌宝”验证的网站总数就已突破50万，品牌宝是安全联盟唯一指定的验证审核服务平台，该验证将对申请网站进行身份、经营内容、经营资质、网站安全性评估等百余项核验，合格后将对优质网站颁发安全联盟验证标识，并提供数十个品牌展示平台，与非法欺诈、钓鱼P2P网站划清界线，提升网站公信力。

  

2016年，合法合规将会是互联网金融的主旋律，随着监管的不断加码，只有规范资金存管、增强风险管理、注重平台安全的互联网金融企业才能脱颖而出。在这个过程中，知道创宇云安全希望能为互联网金融企业提供最优质的Web解决方案，助其稳健快速发展。
