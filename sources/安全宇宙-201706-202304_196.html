三、Frida安装



坑点：cydia安装frida为最新版本，在使用frida-ps -U时出现报错

第一步：在Cydia中添加源 https://build.frida.re


第二步，在github中搜索相关版本frida


第三步，使用scp拷贝到/private/var/mobile/Media/


第四步：dpkg -i frida_12.11.12_iphoneos-arm.deb

在cydia中点击frida下面就会是相关版本的frida

并测试frida在运行中


第五步：使用frida-ps -U查看


Frida-trace



frida-trace：-U 表示USB连接

-f 表示启动某个进程（后面跟着应用的bundleId）spwan方式启动

-m 对Object-C的方法进行追踪（你也可以叫Hook），后面可以跟各种模糊匹配等等

-i 对C函数进行追踪

-x：排除某个C函数

-X：排除某个objective-c方法

-I：包含某个模块


例子：

frida-trace -U -f com.apalonapps.vpnapp -m "[ FreeTrial]"

USB链接启动bundleID为com.apalonapps.vpnapp的app，hook所有Ocject-C包含FreeTrial

关键字的方法


-m "*[APNSubscriptionsManager *]" Hook Object类APNSubscriptionsManager下的

所有方法


跟踪导出函数

Frida-trace -U -I libxml2.2.dylib -I “MM*”

跟踪偏移地址

Frida-trace -U -f xxxxapp -a Aweme\!2a65ccc

对Aweme模块中偏移地址为0x2a65ccc的函数进行跟踪


跟踪调用栈

log('\tBacktrace:\n\t' + Thread.backtrace(this.context,Backtracer.ACCURATE).map(DebugSymbol.fromAddress).join('\n\t'))
