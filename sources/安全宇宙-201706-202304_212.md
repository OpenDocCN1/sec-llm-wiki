Servlet生命周期

  

Servlet被创建：

  

默认情况下第一次访问该Servlet时，Servlet即被创建

  

可修改配置文件，当服务器被启动时创建Servlet，<**load-on-startup**\>值为正数时

  

public void init(ServletConfig servletConfig) throws ServletException

Servlet提供服务：每次访问Servlet即被调用

  

public void service(ServletRequest servletRequest, ServletResponse servletResponse)

  

Servlet被销毁：服务器被正常关闭时Servlet被销毁

  

public void destroy()

### **HttpServlet请求转发**

1、步骤

通过request对象获取请求转发器对象，RequestDispatcher  request.getRequestDispatcher()

使用RequestDispatcher对象来进行转发，forward(request,response);

  

2、特点：

浏览器地址栏不发生变化

只能转发到当前服务器的内部资源中

转发只请求一次服务器（服务器内部进行跳转）

request.getRequestDispatcher("/demo2").forward(request,response);

  

3、共享数据

域对象：一个有作用范围的对象，可以在改范围内共享数据

request域：代表一次请求的范围，一般用于一次请求请求多个资源中共享数据（如请求转发）

方法：

void setAttribute(String name,Object obj)：存储数据到request域中

Object getAttribute(String name)：通过键获取值

void removeAttribute(String name)：通过键一处键值对

**JavaBean讲解**

  

JavaBean就是一个类，类中的成员变量对应着数据库中的信息，作为中间载体

1、javaBean对类的要求：

类必须被public修饰

必须提供空参的构造器

成员变量必须使用private修饰

提供公共setter和getter方法

  

2、封装数据

  

3、概念

成员变量

属性：setter和getter方法截取后的产物

    属性不是成员变量，这个关系非常类似于python的反射机制

   例如getUsername()-->Username-->username

  

4、方法：

setproperty(object,key,value)；设置属性，与python的反射机制相类似

getperproty(object,key)：获取属性值
