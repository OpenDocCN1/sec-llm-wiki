# **《Fastjson 反序列化漏洞史》**

👇

![](../Images/8588aff94042024976448dbd0f24c13f.png)

**扫码阅读全文**  

  
Fastjson 是阿里巴巴的开源JSON解析库，它采用一种“假定有序快速匹配”的算法，是号称Java中最快的Json库。Fastjson接口简单易用，已经被广泛使用在缓存序列化、协议交互、Web输出、Android客户端等多种应用场景。但在去年HW时期曾爆出Fastjson的0day漏洞。该漏洞危害大，影响面广，Fastjson在1.2.48版本以下，无需Autotype开启，攻击者即可通过精心构造的请求包在使用Fastjson的服务器上进行远程代码执行。  
针对这一现象，知道创宇404实验室总结整理出了Fastjson关键性的更新和漏洞时间线，梳理成了漏洞史，并对一些比较经典的漏洞进行测试及修复说明，来帮助大家查漏补缺，理解Fastjson一些漏洞原理和修复的方法，丰富相关知识，而且，**所有文中所提到的漏洞exp已经集成到了Seebug HW神器。**
