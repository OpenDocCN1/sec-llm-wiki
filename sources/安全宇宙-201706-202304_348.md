# 小姐姐手机被偷后发朋友圈，结果…

事情的经过是这样的

前些天上午，我正在开心的刷朋友圈

看到了我们公司的HR小姐姐悲伤地宣布

她的手机被偷了

  

![](../Images/01e4072cca805b8bf60e56243ed37f69.png)

  

  
作为吃瓜同事我也没太在意继续愉快的刷朋友圈直到晚上小姐姐又更新了一条朋友圈  

![](../Images/68f363f28aaaf706560e07660ff03632.png)

  

不对啊  

瓜再这么吃下去

小姐姐的Apple账号密码  

就要被小偷拿到手了...

  
  
用苹果的小伙伴们都知道“查找我的iPhone”![](../Images/7ab923e56c4b8f67839a0f81a872e17a.png)苹果的查找APP  
iCloud账号登陆进去后就可以看到自己所有设备的位置信息所以小姐姐在手机被偷后一定是第一时间标记丢失！抹掉信息！开启找到通知！一键三连

![](../Images/61484a86b7776a273bd019cc20bf2125.png)

  
第一，保护了她的信息安全！第二，小偷登陆她的手机就会有通知！第三，手机即使找不回来也不能让小偷用上！  
小偷没有iCloud密码因为苹果的安全机制拿到手机最多只能拆掉当零件卖小姐姐也能最大程度减少自己的损失（主要是心理上的，不让小偷得逞）  
  
让我们回到上面小姐姐的朋友圈

![](../Images/4cebd3e5eea8bb9501bd5425cf6ae7a4.png)

  

这个看似逼真“官方”的短信其实是**小偷发来的钓鱼网站**  
不得不说，这群小偷对心理学很了解我甚至怀疑他们是搞营销出身的知道手机掉了，寻机心切用文案刺激小姐姐点击钓鱼链接  
“您丢失的iPhone正在**刷机**”  
“OMG！居然在刷机了！我要进去看看位置然后报警抓住他们！”  
如果小姐姐没有立马上当他们还会继续轰炸  
![](../Images/60268cd5111a1c294d67f325abc95b01.png)先是**刷机**然后**整机更换**再被发现**伪造暂扣**收到短信的小姐姐可能已经脑补了一场宫廷大戏吧  
在这步步紧逼下小姐姐能忍住不去点钓鱼地址然后输入自己的 Apple ID 和 密码吗？  
![](../Images/a4c22b55dd3468a506161bca7ee3cedc.png)逼真的钓鱼网站页面（已经被我举报了）  
想到这里，我就不敢再继续本吃瓜同事要阻止这样的事情发生！  

![](../Images/517131dfff4ca7d2b41e475800a546a0.png)

  
除了我之外  
还有很多热心的吃瓜同事  
有找我们的404实验室去炸站的（误![](../Images/9ced60688638244cf1e0ddf7b36c736c.png)  
有分析解答的![](../Images/4bfbe5dedabb4abef1881777e795900a.png)  
有热心送防骗秘籍的![](../Images/66e3556801dc750e2e669b45eb25b79e.png)  
上面炸站的小伙伴还说：![](../Images/160fa596e50de17575e27c95461bdbbc.png)  
  

所以最后小姐姐没有点！

以前不幸点过的小伙伴

记得要去改一下你的Apple ID密码！

现在大家的Apple ID基本都绑定了支付宝

不要被小偷恶意刷费了！

![](../Images/d25701ce33f6605afbab951a66436ba7.png)

  
  

**温馨提示**  

掉手机后

**不要点击任何短信/邮件发来的任何链接**

不管它说你的手机是被刷机了

还是被拆解了

还是上天了

统统不要管

  

最保险的做法还是

去其他苹果设备上登陆相同的iCloud

然后在“查找”App里查看

或者直接登陆iCloud官网
