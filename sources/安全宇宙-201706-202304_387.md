# 知道创宇助力工业工控互联网安全发展

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMDc5NzYwNQ==&mid=2652404627&idx=1&sn=d2b66a1363e4931b301f093ca86fd01e&chksm=80a60cd9b7d185cff49f97b62dff1dc292dcb51a597a5471466e57d57bfb09d572e6fdb57444&scene=126&sessionid=1681368795#rd](http://mp.weixin.qq.com/s?__biz=MzAxMDc5NzYwNQ==&mid=2652404627&idx=1&sn=d2b66a1363e4931b301f093ca86fd01e&chksm=80a60cd9b7d185cff49f97b62dff1dc292dcb51a597a5471466e57d57bfb09d572e6fdb57444&scene=126&sessionid=1681368795#rd)

8月22日下午，由知道创宇KCSC主办的川渝高校工控工业互联网安全沙龙活动在成都腾讯大厦顺利开展。

  

此次活动是基于国内外工控及工业互联网安全的行业背景、发展趋势、人才需求、人才培养等现状，从各界及不同研究领域角度一起探讨工控及工业互联网安全发展的相关问题，为工控及工业互联网安全与院校网络空间安全人才培养相结合的方案进行沟通交流。本次活动聚集了多个院校的老师，共同探讨高校工控工业互联网安全的发展方向。

  

![](../Images/0b59e468ba4935fc635b3e093028d5a8.png)  
在会议开始，成都信息工程大学，网络空间安全学院张仕斌书记发表了关于产业、教育针对工业互联网发展，安全人才的培养体系，以及如何培养工业互联网人才的相关致辞。

  

知道创宇资深安全专家王志威首先分析了当下工控互联网安全面临的机遇和挑战。近几年来川渝经济发展迅猛，信息安全和工控自动化领域人员转换市场相对空白，人才市场缺乏。对于监管部门来说，需求量不大，而信息安全和工控自动化领域人员转换缺少研究和实战经验。同时王志威副院长也表明了工控工业互联网安全技术应该围绕云计算、Web、虚拟化等十大安全课程来加强学习，并介绍了知道创宇K学院是如何培养实验型人才的，随后提出了实验型人才培养系统化解决方案。

  

随后各院校老师结合院校情况发表了看法。重庆邮电大学网络空间安全与信息法学院程克非老师表明医疗行业开发人员是以功能为主，没有考虑安全开发。司法学院培养的学生不够理想、不能跨行业、要做提升和尝试。

  

![](../Images/f882774ef083b00caff355774689ff85.png)  
西南石油大学计算机科学学院张晓均老师根据“学校在针对石油行业工控安全建设思路，工控实验室建设计划”相关内容发表讲话，学校应该建设网络安全实验室和竞赛平台，为院校内的学生提供实践的平台。

  

电子科技大学电子科学与工程学院张徐亮老师结合学院情况对工控互联网理解进行分享，表明关键技术的自主可控是大势所趋、专业人才培养任重道远、AI的发展势在必行。

  

![](../Images/357e81174fe25135e248fe7808b9aadb.png)  
成都工业职业技术学院信息工程学院陈颜老师表明学院未来会参加工控安全方面的比赛，希望企业可以有应用型的课程，并希望学生可以在产品实施和安全运维方向就业。

  

成都信息工程大学网络空间安全学院万国根教授在会议中讲到工控就业难度大，院系缺乏实训平台，设计课程体系要有工业控制模型，实验场景难找。

  

最后，各院校老师表明愿意一起见证工控互联网的发展，不断培养实践性人才，在实践中汲取经验，各行业要完善人才培养体系，从而取得人才、高校的双重发展。在会议中知道创宇和高校老师一起探讨了网络安全的发展趋势、高校工业工控互联网人才培养的方案，并进一步推动了高校向网络安全行业输送人才。知道创宇也希望通过这次沙龙会议为工业工控互联网安全人才的培养贡献一份力量。
