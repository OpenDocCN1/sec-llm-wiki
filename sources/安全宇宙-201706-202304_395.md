# 等级保护2.0工作推进指南

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMDc5NzYwNQ==&mid=2652404419&idx=1&sn=49fe4dfd20a505a06b282d9b8644d67f&chksm=80a60d89b7d1849f9668037d04725a0cef134c5f0965b36756a11f2619da6f18924f79fc1912&scene=126&sessionid=1681368800#rd](http://mp.weixin.qq.com/s?__biz=MzAxMDc5NzYwNQ==&mid=2652404419&idx=1&sn=49fe4dfd20a505a06b282d9b8644d67f&chksm=80a60d89b7d1849f9668037d04725a0cef134c5f0965b36756a11f2619da6f18924f79fc1912&scene=126&sessionid=1681368800#rd)

自等级保护2.0核心标准发布后时间已过去了两个月，在等保2.0正式开始实施（2019.12.1）之前的这段时间里，等护工作具体应该如何推进？今日在北京举行的2019金科创新·金融行业等保2.0研讨会中，来自知道创宇的解决方案专家就在现场为大家解读了该问题。

  

![](../Images/425e48a600feeb84a6b667bf3596e831.png)

  

今年的首批护网行动刚刚结束，回首整个护网的过程，里面的很多内容与等保2.0是共通的。如：风险评估、安全加固、实战演练和应急响应等。

  

在我们梳理等保2.0时发现，与以往不同的是2.0里提出了集中管控的要求。集中管控，顾名思义“集中”IT资产等来进行统一的配置来实现高效管理，并做到安全可控。具体内容参考下图。

 

![](../Images/a5a4667d06304d2beed1a2f6484b8c9d.png)

集中管控主要内容  

 

虽有新的概念提出，但等保2.0标准依然采用“一个中心、三重防护” 的理念，从等保1.0标准被动防御的安全体系向事前预防、事中响应、事后审计的动态保障体系转变。

  

对于持续监测、威胁情报、快速响应类的要求提出了具体的落地措施。因此我们也从主动防御、风险评估、未知威胁捕获等方面提出我们的等级保护2.0解决方案。

**积极（主动）防御**

**创宇盾 **X **抗D保**

创宇盾背后有着知道创宇十余年与黑客进行对抗所获取的海量黑客行为大数据作为支撑，依靠掌握的全球数十万黑客的指纹信息和攻击手段，建立了有效的防御规则。

  

并且背后有着上百人的安全专家团队实时对全国云防御平台数据进行分析，不断优化云防御规则库和分发虚拟补丁程序，做到及时有效防御国际最新的攻击手段。利用大数据的力量，创宇盾可以识别出正常访问或者是非法访问，对于非法访问，将进行有效封锁。 

  

 

![](../Images/ae452affd0e180d634b541651629833a.png)创宇盾是怎么保证网站不被黑客攻破？

  

抗D保的总防御能力超4T，可以抵御所有类型的DDoS威胁；在处理CC攻击方面，基于自主研发的高效CC攻击拦截引擎（Anti-CC引擎），及祝融防护引擎，我能根据访问者的URL、频率、行为等访问特征，迅速识别出CC攻击并进行拦截，在大规模CC攻击时可以避免源站资源耗尽，保证网站的正常访问。  

 

**风险评估**

风险评估可以帮助企业系统分析资产所面临的威胁，及其存在的脆弱性，评估安全事件一旦发生可能造成的危害程度。并提出有针对性的抵御威胁的防护对策、整改措施，为防范和化解风险提供科学依据。

 

![](../Images/1f457b7012fef8f44ab857fc7f5d31f3.png)

风险评估模型  

 

**具体内容如下：**

1.对资产进行识别 ，并对资产的价值进行赋值 ; 

2.对威胁进行识别 ，描述威胁的属性 ，并对威胁出现的频率赋值 ; 

3.对脆弱性进行识别 ，并对具体资产的脆弱性的严重程度赋值 ; 

4.根据威胁及威胁利用脆弱性的难易程度判断安全事件发生的可能性 ;

5.根据脆弱性的严重程度及安全事件所作用的资产的价值计算安全事件造成的损失 ; 

6.根据安全事件发生的可能性以及安全事件出现后的损失 ，计算安全事件一旦发生对组织的影响，即风险值。

 

 

**未知威胁捕获**

未知威胁捕获其实就是蜜罐的思想。在通过在攻击者必经之路上构造陷阱，混淆其攻击目标，实时告警黑客和内鬼的内网入侵行为，将其诱骗隔离以延缓攻击，并帮助用户追踪溯源、阻断攻击和安全加固，从而保护企业核心信息资产安全。

 

![](../Images/f4aa71348467d21db3b53020ed64668d.png)

威胁感知系统

  

**知道创宇猎风（威胁感知系统）工作原理 ：**  

1.多场景部署：在办公网络区域及云端网络区域旁路部署埋点，模拟企业的多种真实业务及主机；

2.威胁报警：黑客入侵后，蜜罐可以作为下一层防御，捕获威胁，并第一时间向用户发起报警；

3.欺骗防护：与此同时，猎风从黑客视角，在黑客必经路径上设计陷阱，对攻击者进行诱骗，隔离攻击，保护用户数字资产，争取响应时间；

4.攻击溯源：对捕获的攻击进行全要素、细粒度的记录，协助客户溯源威胁来源、反制攻击；

5.应急响应：在发现入侵者后，猎风提供单次的 VIP 远程或现场的事件应急响应服务，帮助用户尽快解除威胁；

6.威胁感知报告：提供多维度的威胁分析报表，帮助用户直观了解自身网络中存在的薄弱环节。

 

**知道创宇整体等保解决方案架构：**

 

![](../Images/6b1678576d8e6a0e376bf806feb20cf3.png)

等保解决方案架构  

  

简单概括一下关于践行等保2.0 的主要内容：首先以身份为基础，构建网络安全信任体系；其次以攻防为视角，全方位提升主动防御能力；然后以联动为策略，提升网络安全事件响应能力；接着以运维为关键，加强统一集中管控平台的建设；最后从实战出发，建设自适应的安全体系。

  

![](../Images/3f8b5024e5173f7c97f6897ab5436718.png)

  

知道创宇作为连续多年参与护网的安全公司，在行动中获得了多方认可。结合我们这些年经验来看，企业不仅仅要依照等保2.0规范来做等保，同时也可以结合在护网中的实际经验，将业务系统安全再提升一层。
