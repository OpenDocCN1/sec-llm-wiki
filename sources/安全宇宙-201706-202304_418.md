# 知道创宇赵威：区块链大事记

2019年1月26日，由成都市大数据协会专委会主办的“数聚成都 链动世界”在成都举行。2018年中国区块链创业活跃度城市排名中成都居于西南区第一、全国第六。此次大会借助论坛活动，深入挖掘、评选、报道成都区块链落地的优秀应用。 知道创宇作为国内较早成立并专注于云安全的厂商获邀参加本次活动，充分表明了区块链业界对知道创宇安全技术攻坚能力的高度认可。知道创宇解决方案部高级安全顾问赵威在大会上发表了《区块链大事记》的演讲。

  

赵威在演讲中提到：“2018年被称为区块链的元年，同时也是区块链黑客的元年。为什么这么说呢？因为，2018年初区块链项目井喷式增长，各项目方都在宣传自己的项目，形势一片大好，所有与金钱相关的行业总是那么受关注，黑客也不例外，所以各种各样的安全事件接踵而至，造成的经济损失高达22亿美元。”

区块链大事记

  

**一、BeautyChain 智能合约漏洞**

2018年4月23日，有安全研究人员发现在BeautyChain的智能合约中发现了漏洞，并利用该漏洞获得了巨额的BEC代币。导致市场上海量BEC被抛售，价值直接归零。未检查整数下溢，转账后余额将会变为一个极大的数。

![](../Images/6cfd11da64af87d3d6d9b617069ce805.png)

**二、硬钱包事件**

2018年7月底McAfee公布了一款安全性极高“万夫莫开”的比特币硬件钱包——Bitfi。并宣称Bitfi钱包真的是世界上第一个不可攻破的设备，任何可以破解它的人都可获得10万美元的赏金。但不幸的是，安全研究人员只花了不到一周时间就攻破了Bitfi。利用一个简单的USB漏洞就可以提权获取敏感信息。

![](../Images/7bbe4bb0d873afe7db19fcaa0d4ad131.png)

**三、Fomo3D安全事件**

Fomo3D第一轮大奖于北京时间8月22日下午14点48分揭晓。 钱包地址尾号为5的获奖者获得了价值2200万元人民币（10,469以太坊）的大奖。而从钱包交易历史来看，该获奖人仅仅付出了6000元人民币左右的成本（2.7个以太坊）。为什么会出现这种情况呢？那是因为交易发起者定义gas limit，如果交易消耗的gas总值超过gas limit，该交易就会失败，而大部分交易，会在交易失败时回滚。为了让交易不回滚，攻击者还使用了一个特殊的指令assert()。

![](../Images/ea95bd2c8960e5f503d9bbf09b3a5ce3.png)

  

赵威在分析完区块链行业发生的这些大事记后，分享了一些针对性的解决方案。知道创宇区块链安全解决方案包含：

1、公链安全，从数据层、网络层、共识层、激励层、合约层、应用层面临着各种各样的安全问题；

2、钱包安全（硬件钱包安全、软件钱包安全）；

![](../Images/2e55729c54ef199bc43236e6ed4377a8.png)

3、造成智能合约安全问题频发的四个原因：

a、位于上层应用，出现安全问题概率大

b、语言发展时间短，语言本身不够完善

c、开发人员经验少，不熟悉语言特性

d、目前没有智能合约代码审核标准

4、交易所安全，包括web安全（黑客入侵、网站钓鱼、薅羊毛等），及可用性保障（DDoS攻击的防护）；

5、Dapp安全。

  

随着区块链技术的发展及其应用场景的逐步成熟，行业应用的复杂度越来越高。知道创宇深耕区块链技术安全，旨在为运用区块链技术的行业提供安全保障，加强行业的健壮性，同时构建一个安全的区块链生态。
