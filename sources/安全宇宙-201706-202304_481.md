# 知道创宇CEO赵伟荣获“云鼎奖—2016-2017年度中国最具影响力人物奖”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMDc5NzYwNQ==&mid=2652403548&idx=1&sn=1bb8d7a068db3e518b7a0520ac4e9033&chksm=80a60016b7d189005b5c9d5eac8a0427a8c1e134a223f765e83bfbcf6bac40c4bd7996102862&scene=126&sessionid=1681368841#rd](http://mp.weixin.qq.com/s?__biz=MzAxMDc5NzYwNQ==&mid=2652403548&idx=1&sn=1bb8d7a068db3e518b7a0520ac4e9033&chksm=80a60016b7d189005b5c9d5eac8a0427a8c1e134a223f765e83bfbcf6bac40c4bd7996102862&scene=126&sessionid=1681368841#rd)

2017年9月6-7日，2017第五届全球云计算大会·中国站在上海举办，知道创宇云CEO赵伟荣获“云鼎奖—2016-2017年度中国最具影响力人物奖”的殊荣。作为每年全球云计算大会·中国站（Cloud Connect China）的核心活动，“云鼎奖”（Top Cloud Connect Awards）旨在表彰年度对中国云计算做出突出贡献和具有创新精神的集体、个人和产品，进而促进云计算在中国健康、快速、有序发展，并助推中国企业走向世界舞台。获得云计算行业中的年度中国最具影响力人物奖，这意味着赵伟及其创立的知道创宇在云计算领域受到了最广泛的认可。

  

![](../Images/2d49b86061c99ad1f23e25d4f2b77e16.png)

  

**个人简介：**

赵伟，知道创宇公司创始人CEO，上榜福布斯中美3030创业者，他创办的知道创宇在2015年获得中国用户最多的互联网企业，腾讯第二次6亿元投资，目前公司估值30亿，员工突破800人规模。赵伟在网络安全行业内以其独到的观点与价值观一直处于引领地位，知道创宇的安全产品也同样在行业内具有引领行业的创新力。他第二届世界互联网大会上发表过主旨演讲，同时还获得了首届全国十大“最美消费维权人物”。

  

近年来，赵伟对云计算产业做出了突出贡献，引领了国内云计算在安全领域里的大力发展，知道创宇成立初期，在赵伟的带领下就对未来安全做足了思考，并确定了以云监测、云防御作为公司主要战略发展方向。在起初硬件产品当家的安全市场，这一战略并不被广泛看好，直到十年后的今天，信息的高速发展使得以云的方式解决安全问题被广泛接受和高度认可，也有越来越多的安全企业开始转战云安全。而赵伟在过去的十年里无疑是国内云安全的领军人物，随后的市场发展也佐证了知道创宇十年前的前瞻性眼光。

  

![](../Images/c794925d59f99695f4c60114ef1bdf57.png)

  

知道创宇经过十年发展，已成行业龙头企业，旗下云监测、云防御平台共服务90余万用户，为国内安全市场技术发展及格局均做出了卓越贡献。目前，中国SaaS市场用户还是集中在中小型企业，但企业用户对于SaaS的接受度是在加强的。为什么这么说呢？因为企业用户是有云端拓展的计划或者规划的，大多传统企业也在积极部署云端系统，将业务迁至云上。与此同时在云端迁移的过程中难免会面临网络安全问题，知道创宇深耕网络安全领域的解决办法。

  

![](../Images/8f5a2f4c79c9d84f4ea62e624912c0c3.png)

  

目前企业常见的安全问题以这些为主：数据被泄漏并在黑市进行交易；账户信息泄漏导致客户资金被窃；部分金融企业遭遇黑客敲诈勒索；羊毛党肆意薅羊毛等。造成如上诸多安全问题的原因主要在于互联网金融平台漏洞频发，但是平台安全技术出现短板，无法凭借一己之力解决问题。

  

作为一家网络安全企业，知道创宇深知所要肩负的责任和义务，一方面，我们积极参与国家网络安全建设，多次参加国家重大活动网络安全保障工作，同时我们还保护了近百万个企业商业网站，利用我们的云防御技术，为国家和人民提供了坚实的信息安全防护保障。此外，知道创宇为本次十九大的网络安全提供了安全防护方案，拟将旗下云安全产品线核心产品-创宇盾和创宇监控组成联合方案，免费给全国各级政府网站和企事业单位网站提供安全防护服务和安全监控服务。

  

![](../Images/3229f39831182a471fa782bdda0da5ce.png)

  

知道创宇云安全防御平台包含“加速乐、创宇盾、抗D保、品牌宝”四大产品，其中加速乐、创宇盾、抗D保为知道创宇三大云安全产品，可为企业Web提供全面安全加速防护能力；辅以品牌宝认证，可提供企业商业转化，建立企业的良性信誉。
