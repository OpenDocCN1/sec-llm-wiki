# 终于降临：360安全卫士登陆中标麒麟操作系统

自棱镜门和XP停服事件后，国内信息市场对于国产操作系统的关注程度就高居不下。但长期以来，国产操作系统上应用软件的缺乏和硬件兼容性不佳等问题一直制约其在中国市场更大范围推广。中标软件先后与多家国内外知名软硬件企业合作，推出了大量基于国产操作系统的应用软件和兼容硬件产品。

近期，国内最大的互联网企业之一奇虎360科技有限公司（以下简称360）与中标软件合作，推出了基于中标麒麟操作系统的360安全卫士专版，一举解决了国产操作系统下图形化安全防护产品缺乏的问题。

360安全卫士是一款为Windows系统提供全方位安全保护的软件，因其功能强大、用户体验优秀等特性而广受用户好评。现在，360安全卫士Linux版本发布，它继承了Windows版本众多的优良特性，支持查杀木马、系统清理和软件管理等强大功能，这将极大的提升中标麒麟操作系统的安全性和易用性，促进国产操作系统的普及。

广大中标麒麟系统用户可直接通过360专页下载安装。

http://chinaossafe.360.cn/

当前版本已经更新至：3.0.0.68

特色功能：全盘病毒木马扫描、系统优化加速、一键清理系统垃圾、对钓鱼网站进行网盾防护。
