# 苹果系统超越windows成为2014年漏洞最多操作系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5ODA0NDE2MA==&mid=202964775&idx=5&sn=168745dfcee41078bbdc93bf0eae7d29&chksm=197bcf482e0c465e9012e95cf3c930c0cf320e27cb4040e1dec16ea87107892142a01b9cd5ad&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5ODA0NDE2MA==&mid=202964775&idx=5&sn=168745dfcee41078bbdc93bf0eae7d29&chksm=197bcf482e0c465e9012e95cf3c930c0cf320e27cb4040e1dec16ea87107892142a01b9cd5ad&scene=27#wechat_redirect)

苹果的操作系统被认为是最安全的操作系统,不论是针对桌面终端的Mac OS X还是针对iPhone等手持设备的Ios。但不管你信不信，苹果系统是2014年一年中最脆弱的操作系统。

漏洞最多操作系统：

一直以来人们人为Windows是最不安全的操作系统，它最容易被黑客攻陷，原因是历史上windows爆出过大量的安全漏洞，然后根据国外安全机构2014年的统计结果显示，windows操作系统跌出了存在漏洞最多操作系统前3名的行列，前三名的操作系统分别是：

* * *

Apple’s Mac OS X

Apple iOS

Linux kernel

* * *

根据数据显示，存在漏洞最多的操作系统，分别在2014年被曝光了如下数量的漏洞：

* * *

Apple’s Mac OS X -发布漏洞**147**个，其中高危漏洞**64**

Apple’s iOS -发布漏洞127个，其中高危漏洞**32**

Linux Kernel -发布漏洞**119**个，其中高危漏洞**24**
