# 谷歌曾向FBI提交维基解密员工资料 隐瞒近三年

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5ODA0NDE2MA==&mid=202484738&idx=2&sn=1fe06c1c5e305b481204591f43ee2973&chksm=19729c6d2e05157b542781b8538a00ec1de5299b070d6818ce18021d91e48bf1ae1041d60cea&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5ODA0NDE2MA==&mid=202484738&idx=2&sn=1fe06c1c5e305b481204591f43ee2973&chksm=19729c6d2e05157b542781b8538a00ec1de5299b070d6818ce18021d91e48bf1ae1041d60cea&scene=27#wechat_redirect)

![](../Images/097d9dd1eaad742955045b58eb64dbf0.png)

维基解密网站日前给谷歌公司执行总裁埃里克·施密特发出信件，抗议该公司在上个月才告知己方，谷歌曾在2012年3月按照一名联邦法官签署的秘密搜查令指 示，向美国政府提交了维基解密三名工作人员的邮件和其他电子数据。维基解密在信中表示，谷歌公司用两年半时间才告知其用户这件事令人感到“震惊和不安”， 这潜在地剥夺了用户保护自己的“隐私、结盟和免于非法搜查”等权利的能力。

![](../Images/de64eaf0aa7ce339e6855a8f1d6cfad2.png)

据报道，这封信由维基解密纽约公司的律师迈克尔·拉特纳撰写，他要求谷歌公司列出所有提供给美国联邦调查局（FBI）的资料，并要求其回答是否对搜查令提出过质疑，以及是否收到过提供更多信息的要求。
