# FBI局长称：索尼黑客无法隐藏自己的IP地址，朝鲜就是幕后凶手

詹姆斯·科米在一年一度的国际会议上的网络安全（ICCS）在纽约发表了主题演讲，在Fordham大学，并透露了一些调查的细节上索尼黑客事件。

詹姆斯·科米表示：在2014年11月发生索尼影视娱乐公司遭受黑客攻击事件，黑客未能通过代理方式成功隐藏自己的IP地址，我们有证据表明，攻击来自朝鲜。

**攻击者并未能合理的隐藏自己的真实IP**

他 说，和平的守护者（GOP），声称对索尼的攻击，黑客通过代理方式发送威胁、攻击邮件、及网络言论。试图通过这种方式来隐藏自己的真实IP来逃避追捕。但 是某些情况下他们会忘记使用代理、又或者代理服务器故障导致他们的真实IP暴露出来了。因此我们可以看到这些攻击IP来自朝鲜。

不过目前还不清楚詹姆斯·科米所说的电子邮件和网上的帖子具体指哪些，但是这些帖子都是黑客通过匿名方式在网上公布的，并且和平的守护者（GOP）也并未声称对这些信息负责

FBI非常有信心能够找到索尼攻击事件的元凶  

在2014年12月24日情报中显示，FBI称平的守护者（GOP）还通过Pastebin发布了针对CNN的威胁消息。  

大卫·加勒特：FBI在事件调查过程中一直未能得到进展，直到GOP在Pastebin上发布了针对CNN的威胁消息。

在ICCS，联邦调查局局长表示，如果未能很好的处理这次事件，未来可能还会有更多的攻击发生，这也表明了FBI对此事的态度。

虽然针对这次攻击到底是谁发起的，又有了更多的疑云，但是FBI坚信，此次攻击的背后是朝鲜在幕后操控
