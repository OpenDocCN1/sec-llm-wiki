在本文中我将分享一些bash脚本命令和正则表达式在密码破解我找到有用的。大多数时候,我们发现裂纹通过共享哈希表贴网站Pastebin(最受欢迎的。)手工分离散列值是一个耗费时间的过程,因此我们将使用正则表达式来让我们的生活更轻松!

提取md5哈希
1
# egrep -oE '(^|[^a-fA-F0-9])[a-fA-F0-9]{32}(1|$)' *.txt | egrep -o '[a-fA-F0-9]{32}' > md5-hashes.txt


另一种方式可以用sed

1
# sed -rn 's/.*[^a-fA-F0-9]([a-fA-F0-9]{32})[^a-fA-F0-9].*/1/p' *.txt > md5-hashes


注意:上面的正则表达式可以用于SHA1,SHA256和其他新鲜的散列用十六进制表示。你唯一要做的就是改变“{ 32 }”为你想要的hash-type对应的长度。


提取有效MySQL-Old哈希

1
# grep -e "[0-7][0-9a-f]{7}[0-7][0-9a-f]{7}" *.txt > mysql-old-hashes.txt


提取blowfish 哈希

1
# grep -e "$2a$8$(.){75}" *.txt > blowfish-hashes.txt

提取 Joomla 哈希

1
# egrep -o "([0-9a-zA-Z]{32}):(w{16,32})" *.txt > joomla.txt


提取 VBulletin hashes

1
# egrep -o "([0-9a-zA-Z]{32}):(S{3,32})" *.txt > vbulletin.txt


提取 phpBB3-MD5

1
# egrep -o '$H$S{31}' *.txt > phpBB3-md5.txt


提取 Wordpress-MD5

1
# egrep -o '$P$S{31}' *.txt > wordpress-md5.txt

提取 Drupal 7

1
# egrep -o '$S$S{52}' *.txt > drupal-7.txt


提取 old Unix-md5

1
# egrep -o '$1$w{8}S{22}' *.txt > md5-unix-old.txt


提取 md5-apr1

1
# egrep -o '$apr1$w{8}S{22}' *.txt > md5-apr1.txt


提取 sha512crypt, SHA512(Unix)

1
# egrep -o '$6$w{8}S{86}' *.txt > sha512crypt.txt


提取 e-mails from text files

1
# grep -E -o "[a-zA-Z0-9.#?$*_-]+@[a-zA-Z0-9.#?$*_-]+.[a-zA-Z0-9.-]+" *.txt > e-mails.txt


从TXT文本提取 网页 URL

1
# grep http | grep -shoP 'http.*?[" >]' *.txt > http-urls.txt



提取HTTPS、FTP和其他URL格式使用

1
# grep -E '(((https|ftp|gopher)|mailto)[.:][^ >" ]*|www.[-a-z0-9.]+)[^ .,; >">):]' *.txt > urls.txt

注意:如果grep返回“Binary file (standard input) matches”使用以下方法

1
# tr '[00-1113-37177-377]' '.' < *.log | grep -E "Your_Regex"


或者

1
# cat -v *.log | egrep -o "Your_Regex"


提取浮点数


1
# grep -E -o "^[-+]?[0-9]*.?[0-9]+([eE][-+]?[0-9]+)?$" *.txt > floats.txt

提取 ISBN 号码

1
# egrep -a -o "ISBN(?:-1[03])?:? (?=[0-9X]{10}$|(?=(?:[0-9]+[- ]){3})[- 0-9X]{13}$|97[89][0-9]{10}$|(?=(?:[0-9]+[- ]){4})[- 0-9]{17}$)(?:97[89][- ]?)?[0-9]{1,5}[- ]?[0-9]+[- ]?[0-9]+[- ]?[0-9X]" *.txt > isbn.txt


WordList Manipulation
用sed移除空字符

1
# sed -i 's/ //g' file.txt OR # egrep -v "^[[:space:]]*$" file.txt


Remove the last space character with sed

1
# sed -i s/.$// file.txt


按单词的长度排序

1
# awk '{print length, $0}' rockyou.txt | sort -n | cut -d " " -f2- > rockyou_length-list.txt

Convert uppercase to lowercase and the opposite

1
2
# tr [A-Z] [a-z] < file.txt > lower-case.txt
# tr [a-z] [A-Z] < file.txt > upper-case.txt


用sed删除空白行

1
# sed -i '/^$/d' List.txt


用sed删除自定义字符

1
# sed -i "s/'//" file.txt


用sed删除一个字符串

1
# echo 'This is a foo test' | sed -e 's/<foo>//g'


用tr替换字符

1
# tr '@' '#' < emails.txt OR # sed 's/@/#' file.txt


Print specific columns with awk

1
2
3
# awk -F "," '{print $3}' infile.csv > outfile.csv
OR
# cut -d "," -f 3 infile.csv > outfile.csv


Note: if you want to isolate all columns after column 3 use

1
# cut -d "," -f 3- infile.csv > outfile.csv
