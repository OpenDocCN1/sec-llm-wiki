# MSN在线服务存在XSS漏洞 允许加载本地程序

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5ODA0NDE2MA==&mid=201861797&idx=3&sn=3abb5d85017379249ca9cae0acc35f51&chksm=196b1aca2e1c93dcc492cb940dd74791eb30e44c02d2ec70c17511034ff463591328f51c6517&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5ODA0NDE2MA==&mid=201861797&idx=3&sn=3abb5d85017379249ca9cae0acc35f51&chksm=196b1aca2e1c93dcc492cb940dd74791eb30e44c02d2ec70c17511034ff463591328f51c6517&scene=27#wechat_redirect)

研究人员在微软的MSN在线服务上发现一个XSS漏洞，允许通过URI（统一资源标识符）处理器注入命令的方式安装本地软件。开发人员利用Web浏览器调用本地程序执行某些任务，通过一个要求计算机上特定程序的URI完成。

Nicholas Lemonias发现了这个XSS漏洞，他表示他使用了一种特殊方式绕过会阻止通过网站实施XSS攻击的过滤机制。这种方法是JavaScript String fromCharCode()方法，将Unicode值转化为字符。目标程序会通过鼠标点击某些页面元素如MSN视频列表来实现。这样他能够滥用一个被信任的URI如 “mailto,” “callto,” “irc” 或者 “skype” 来加载程序。例如他开启了一个Outlook电子邮件客户端窗口，其中收件人、主题及信息部分已经填写完成。在Skype的例子中，程序被启动并拨出一个电话。

当通过URI启动程序时，web浏览器通常会为用户提供重复预期动作的可能性而不必通知用户。这个步骤非常重要，因为在未经用户统一的情况下，如果一个已安装的应用程序被启动，用户不会得到通知。

Lemonias表示，这可能引发恶意行为，如在用户不知情的情况下发送电子邮件，但他未给出可以证明这种可能性的验证。同时他也没有给出验证说明MSN的访客可能会通过XSS攻击被重新定向至一个不同的网站。由于MSN是一个可信任网站，攻击者通过访问恶意地址的浏览者实现恶意目标更为容易。Lemonias指出，还有一种可能性是引发DoS攻击。而Outlook或者其他电子邮件客户端并非唯一受影响的程序。

Lemonias将研究成果通知了微软，现在微软在更新中已经移除了这个安全风险。
