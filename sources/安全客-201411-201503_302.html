简介


Cisco RV 系列今日爆出多个漏洞，攻击者可以使用这些漏洞创建任意文件，执行任意命令和CSRF攻击。


受影响版本：

- Cisco RV120W Wireless-N VPN Firewall running固件< 1.0.5.9

- Cisco RV180 VPN Router 和 Cisco RV180W Wireless-N Multifunction VPN Router 固件< 1.0.4.14

- Cisco RV220W Wireless Network Security Firewall 全版本


1.不安全的文件上传处理


管理页面使用LUA脚本创建。安全人员在cookie中发现一个TeamF1Login值使用不当。这个cookie值被用来作为路径的名称来存储上传后的文件。而这个cookie值没有验证。从而导致攻击者可以创建任意文件。

注意：


-Web服务器(thttpd)使用root启动

-存在的文件将会被覆盖

-这个漏洞可以被未登录用户利用


/pfrm2.0/share/lua/5.1/cgilua/post.lua:


2.诊断工具命令注入


管理页面存在多个网络诊断工具，例如PING。在表单中输入特殊字符会导致如下错误信息：

Invalid IP Address/Domain name:Domain/WAN (Internet) must contain only alphanumeric letters, '.' and '-'.


可以看出检查不是在服务器端。直接向服务器发送请求可以导致任意命令执行（root权限）。要访问诊断工具需要登录。


/pfrm2.0/var/www/diagnostics.htm


3.GET 请求可以绕过Referer检查


当一个POST请求发送到应用时，程序会检查Referer头部。如果Referer头部为空或者是一个外部链接，则会显示一个(401 Unauthorized)错误信息。但是程序没有检查GET请求。程序使用Referer检查来防御CSRF攻击。下面URL可以添加一个管理用户：

https://192.168.2.1/platform.cgi?thispage=diagnosticsAP.htm&button.ping.diagDisplayAP=Ping&ping.ip=-h+
2%3e%2fdev%2fnull%3b%2fpfrm2.0%2fbin%2fsqlite3+%2ftmp%2fsystem.db+%22INSERT+INTO+%5c%22users%5c%22+VALUES%28%5c%22
