# Neutrino僵尸网络生成器内部结构分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5ODA0NDE2MA==&mid=207009174&idx=2&sn=472b8b79aec749eecaf9d098eb32e3db&chksm=193585f92e420cef09e78a0a03681e93d6fb2a3101c8385e0ca4e3fa04a68618f51deb3cc82e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5ODA0NDE2MA==&mid=207009174&idx=2&sn=472b8b79aec749eecaf9d098eb32e3db&chksm=193585f92e420cef09e78a0a03681e93d6fb2a3101c8385e0ca4e3fa04a68618f51deb3cc82e&scene=27#wechat_redirect)

 这是在网络犯罪的形式出售他们的产品包中最常见的做法,包括:  

一段恶意payload ——用于感染恶意软件的前端用户  

一个C&C panel ——一个恶意软件的后端,通常设计为一个web应用程序  

一个Builder——用于包装的有效载荷和嵌入在它的信息,特别是对特定的分销商的利益(C&C地址,一些配置等)  

这种包装是在黑市上销售的商业产品。然而,它的产品不时地泄漏到主流媒体。它给研究人员一个宝贵的机会,能够仔细看看所使用的技术。  

最近,我发现了一个泄露包里泄露了微型僵尸网络的建设者信息。虽然它不是最新版,但它仍然提供了很多有用的信息,可以帮助分析现在最新的样本分布。

**防守技术  
**

payload 还包含各种防御功能。  

除了众所周知的检查——比如isDebuggerPresent,我们能找到一些的东西——更高级的或者只是很奇怪(像对字符串检查用户名:“麦芽”、“tequilaboomboom”,“沙箱”,“病毒”、“恶意软件”)。

全套解释如下:  

调试器:  

IsDebuggerPresent  

远程调试器:  

pDebuggerPresent CheckRemoteDebuggerPresent(GetCurrentProcess())  

检查wine下运行:  

GetProcAddress(GetModuleHandleW(“kernel32.dll”)、“wine\_get\_unix\_file\_name”)  

检查列入黑名单的子字符串(忽略大小写):  

用户名:  

GetUserNameW vs {“MALTEST“, “TEQUILABOOMBOOM“, “SANDBOX“, “VIRUS“,”MALWARE“}  

当前模块名称:  

GetModuleNameW vs {“SAMPLE“, “VIRUS“, “SANDBOX” }   

BIOS版本:“HARDWARE\\Description\\System“, value “SystemBiosVersion” against: {“VBOX“, “QEMU“, “BOCHS“}   

BIOS版本:“HARDWARE\\Description\\System“, value “VideoBiosVersion” against: “VIRTUALBOX“  

SCSI:“HARDWARE\\DEVICEMAP\\Scsi\\Scsi Port 0\\Scsi Bus 0\\Target Id“, value “Identifier“), against {“VMWARE“, “VBOX“, “QEMU“}  

检查的存在:

VMWareTools :SOFTWARE\\VMware, Inc.\\VMware Tools

VBoxGuestAdditions: SOFTWARE\\Oracle\\VirtualBox Guest Additions

**结论**

恶意软件分析师通常只要处理一块拼图的下面的恶意payloads。分析一个完整的包,有助于看到的更多。

这也给了一个很好的概述如何协调分析恶意软件的行为。正如我们所看到的,犯罪分子提供了一个非常简单的方法来引导自己的恶意C&C。它并不需要先进的技术。我们生活的时代是恶意软件是一种武器提供给群众,这就是为什么每个人都有一个坚实的和分层的保护是如此重要。
