# duqu使用的是被盗的富士康（Foxconn）证书

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5ODA0NDE2MA==&mid=205701794&idx=3&sn=c8dbeadf0cef6e766f06a20874d8db6f&chksm=1921f2cd2e567bdb6f6a7a71b311347f284292d44e62ca4f1d06bb75b334aebec4e75db30dbb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5ODA0NDE2MA==&mid=205701794&idx=3&sn=c8dbeadf0cef6e766f06a20874d8db6f&chksm=1921f2cd2e567bdb6f6a7a71b311347f284292d44e62ca4f1d06bb75b334aebec4e75db30dbb&scene=27#wechat_redirect)

攻击者的目标是窃取硬件制造商数字凭证。

利用数字证书全球最大的电子产品制造商富士康（Foxconn）被盗。

俄罗斯安全公司卡巴斯基实验室表示,其研究人员发现Duqu 2.0恶意软件通过使用一个合法的数字证书从台湾的富士康（Foxconn）重定向流量。

富士康（Foxconn）的客户包括许多世界上最大的电子供应商,包括苹果、黑莓、谷歌、华为和微软等。

卡巴斯基透露其在上周的一份报告中的初步结果，三个欧洲酒店P5 + 1会谈涉及伊朗和六个世界大国,其他目标所使用的设备中均含有该病毒。

数字证书是网络上的计算机进行身份验证和加密流量合法的凭据。他们作为电子商务的基础和其他主要在网上交易自动化识别凭据。

安全专家表示，近年来,网络间谍已开始利用偷来的数字证书来诱骗机器运行来自其他电脑的恶意软件,在互联网上完成升级对公司业务链构成严重威胁

**有针对性的攻击**

世界六大国包括美国、俄罗斯、中国、英国、法国和德国在内的P5 + 1集团一直在与伊朗谈判限制伊朗核项目发展。

洛桑自去年以来一直断断续续与伊朗进行一系列的谈判与伊朗达成全面核协议已在日内瓦蒙特勒,慕尼黑和维也纳等多处举行。

卡巴斯基和赛门铁克安全公司的安全专家均表示之前发现的Duqu间谍软件由以色列的编程人员开发。

以色列,强烈反对大国对其宿敌伊朗的外交开放,并且否认研发过任何的恶意软件。

赛门铁克和卡巴斯基的病毒分析师表示Duqu与Stuxnet之间有技术重叠,Stuxnet是在2009-2009美国以色列破坏伊朗核计划摧毁了铀浓缩离心机的一款破坏性间谍程序。

卡巴斯基在出版于2010年一份报告中表示,窃取数字证书的间谍软件利用包括JMicron技术和瑞昱半导在内的两个主要台湾企业。

卡巴斯基在本周的总结报告中表示，“利用Duqu的攻击者是唯一获得这些证书的人。”

卡巴斯基表示,已通知富士康数字证书被窃取。富士康没有立即发表回复,但是它已采取措施确保其系统的安全性。

上周,卡巴斯基表示在2011年Duqu 2.0版本已经基于早期的Duqu开发。

据说Duqu 2.0利用了三个未修复的漏洞感染计算机,微软随即修复了这三个可以被利用的漏洞，但剩下的攻击几乎没有痕迹。

卡巴斯基本身就是Duqu 2.0恶意软件的受害者。在2015年初安全厂商发现其内部系统遭受Duqu 2.0恶意软件的持续威胁。
