# CVE-2015-1701本地特权提升利用工具

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5ODA0NDE2MA==&mid=204689412&idx=2&sn=5512c9c0eb2e1ad39f7ae4e5327c7a02&chksm=1950606b2e27e97df1fa44a9d153ec50bcb0ec294fd47c913036d18ef1ae961ece40b1bfb087&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5ODA0NDE2MA==&mid=204689412&idx=2&sn=5512c9c0eb2e1ad39f7ae4e5327c7a02&chksm=1950606b2e27e97df1fa44a9d153ec50bcb0ec294fd47c913036d18ef1ae961ece40b1bfb087&scene=27#wechat_redirect)

在微软5月份的补丁日里，包括了一个内核特权提升漏洞，如果攻击者在本地登录并可以在内核模式下运行任意代码，最严重的漏洞可能允许特权提升。攻击者可随后安装程序；查看、更改或删除数据；或者创建拥有完全用户权限的新帐户。

受影响的操作系统版本

Windows Server 2003

Windows Vista

Windows Server 2008

Windows 7

Windows Server 2008 R2

Windows 8 和 Windows 8.1

Windows Server 2012 和 Windows Server 2012 R2

Windows RT 和 Windows RT 8.1

相关公告

https://technet.microsoft.com/library/security/MS15-051

据了解，该漏洞是Fireeye在分析APT28的行动中发现的。

随后有人在github上给出了利用程序和源代码。

提示：该工具可能带有攻击性，仅供安全研究与教学之用，风险自负!
