# 狂刷优惠券5000万-7000万！苏宁易购一起逻辑支付漏洞导致重大乌龙事件

北京时间4月6日一位不愿意透露姓名的知情人向小编爆料，今日凌晨一淘网网友发帖称苏宁优惠券100-50，但是使用门槛仅需要满0.1元即可，帖子迅速被转载到各大网赚论坛，好友间利用QQ奔走相告。当然我们的程序员们都没闲着，大神们一宿没睡开始用软件刷单。有人甚至狂刷1.7万单。截至发稿前有网友粗略估算若苏宁按订单发货至少损失千万。纷纷有网友猜测又是一起“零时工”事件吗？以下为大神们熬夜刷单截图。

![](../Images/35bee6c0f13f7417755b510380924045.png)

今天已经有部分一线城市网友晒出自己用券买的东西，从图片中不难看出：刷单的人明知道系统漏洞还去刷，捡便宜是人之天性，便宜没捡反过来骂街，这就是道德问题。

![](../Images/9f7b460f6ed9262cc5d9b48c09764f1b.png)

一早上班发现群里谈论买东西，小编心想怎么突然这么多人买东西，毕竟没活动。就去问QQ群的小伙伴，一问才发现错过了很多精彩。一个知情网友向小编爆料说：有人狂刷1.7万单。甚至有苏宁员工爆料此次可能是由于优惠券BUG所致。

另据一名网友爆料：苏宁南京总部紧急召开高层会议，商讨对策。预测本次事件损失在5000W-7000W。

![](../Images/96f144a5def2ab659384bb206500583f.png)

网友观望苏宁易购能否按订单发货?

与以往很多网站标错价格不同的是：苏宁并非标错价格，而因误把优惠券门槛标错造成的众多网友疯狂抢购商品。以下是网友抢到的商品，但苏宁方面并未发货，知情网友通过苏宁方面了解到：苏宁目前已经紧急招来会议商讨对策。

![](../Images/ab26dd052f67e7182758c1791351813a.png)

![](../Images/2cd36b739f9bd0735d6dae2b7414c660.png)

当然也有理智的网友以亲身经历劝大家刷了没用。毕竟内裤也会被要回去。好吧，小编凌乱了。

![](../Images/fae2650350bbd96dc1c8373db881b5e4.png)

苏宁客服对是否发货出现两种声音：按照订单发货与订单或被取消

此次抢购成功的网友对小编说：我们还在观望苏宁怎么处理呢，早上问说是会被取消，后来我下午向苏宁易购方面咨询又说可能会发货。我也不知道会不会发。不过我倒是无所谓了，反正没开钱。苏宁能否正确处理好此次危机，是否能化危机为转机呢？

![](../Images/e4e0e6e265c4a6055e76d49208f68a55.png)

![](../Images/d0424021e2c6ace19bd14e8e1f71ad80.png)

截至发稿前，苏宁易购方面并未就此事发表任何形式的声明。此前网上已经出现过很多加因为误操作的情况，但是并未出现涉及如此巨大的数额。众多网络观察者都在看着苏宁此次对“优惠券”的处理意见。期待苏宁能化解此次危机。
