# GMail根证书过期，百万邮件客户端无法接收GMAIL邮件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5ODA0NDE2MA==&mid=203786526&idx=2&sn=dd35dba92062bc105d4e0a7750b1e4af&chksm=1946b9712e313067889b4a1ed0d5040c28e9ed35cd68d4ebe22f6e31da6bdb8cc05dc507a0b9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5ODA0NDE2MA==&mid=203786526&idx=2&sn=dd35dba92062bc105d4e0a7750b1e4af&chksm=1946b9712e313067889b4a1ed0d5040c28e9ed35cd68d4ebe22f6e31da6bdb8cc05dc507a0b9&scene=27#wechat_redirect)

周六上午，Google根证书过期，导致数百万用户的邮件客户端无法使用。Google的证书颁发机构（Google Internet Authority G2）颁发的证书被用来解决SMTP的问题，上午11点55分，证书过期引起了许多电子邮件客户端停止接收Gmail邮件。这个问题影响了大部分在PC端和移动端使用Gmail的用户，但是Web即网页端没有收到影响。

Google在公司App的状态更新页面中报告说，Google已经在周六下午的1点21分警告了工程师们Gmail出现了问题。在之后的一些状态更新中，公司发言人指出：”受影响的用户仍可以连接到自己的Gmail账户，但是只能看到错误消息或者其他一些以外行为。并且smtp.gmail.com显示为一个无效证书。”

![](../Images/67f55de4cc9dd33897f28cf02c1128bd.png "t01d26ac37c7579a6ed.jpg")

Google证书颁发机构的根证书是由GeoTrust授权颁发的。截至到周六下午4点，证书已经更新，有效期至2016年12月。
