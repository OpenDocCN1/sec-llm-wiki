# 特斯拉带来无人驾驶技术——同时给大众带来了网络安全问题

上周，特斯拉公司开创了汽车工业的又一领先项目：立即启动。公司将提供通过互联网直接升级的业务。

据华尔街日报3月19日的报道，特斯拉CEO Elon Musk说，“我们认为这种更新与更新我们的手机或电脑是一样的”。

特斯拉上周公布，汽车远程更新并不是对于未来的惟一一次尝试。这个话题的关注声音远远大于特斯拉汽车将会在今年夏天实现的新的“无人驾驶”能力（当然是通过无线下载）。纽约时报报道说，一旦您的车辆得到升级，那么在主要公路上，你可以打开“自动驾驶”。

特斯拉进一步破坏了传统汽车行业的消费规则——消费者直接升级，从而不需要通过商家来购买服务。这对消费者的方便是显而易见的，每个人对于无人驾驶技术变得触手可及都显得很兴奋。但是，这有什么坏处吗？

根据dujour，网络安全版，美国国会正在评估一个不是很愉快的事情，攻击者能够破解你的车的复杂的计算机系统的潜力。去年，Sen Senator Edward Markey(D-MA)致信20家汽车厂商询问他们的汽车依赖的无线计算机技术，反过来，咨询他们的系统的脆弱性。二月，他发布了公司的答复，他们并不完全放心。

根据Wired,Sen.Markey的发现，现在“几乎100%”的汽车售卖通过无线连接，可能会接入到“敏感或隐私系统”。最近的exposé在60分钟内组合了这些发 现，DARPA黑客证明了他有能力攻击进入丰田普瑞斯的系统，使汽车刹车或加速——这样你可以更好的理解SenMarkey所表达的。

厂家模棱两可的回应了议员关于他们的产品的网络安全的询问。有些人说他们加密信息，如驾驶历史和物理位置，而另一些人承认，他们不使用加密。一些公司说他们接受了关于车辆网络安全的第三方检测，而更多公司则承认没有进行检测。

特斯拉是三分之一没有回应Sen Markey问题的公司之一。相关的消费者有理由担忧吗？毕竟，去年，中国黑客公布了他们破解特斯拉的成功，尽管他们只是有限的解锁车门和打开天窗。

特斯拉公司一直三缄其口，但Musk曾表示，他将致力于安全。他最近出席了一个技术会议，并表示“公司关注的关键点是….保护…自己的硬件软件安全，免收外部的恶意攻击”

我们希望如此。一个不合理的自我驱动软件，当然，这是一个比中国黑客发现的系统问题更严重的问题。并且不回应Sen Markey的询问也许会马上开始一个自我检测吧。
