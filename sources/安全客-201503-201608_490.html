一个芬兰人建立一个简单的邮箱帐号，就能接收微软证书

一个芬兰IT专家只要通过向微软系统的在线服务提交一个请求就能够获取到一个HTTPS证书。

只需要一个邮件地址就能欺骗并获取到浏览器信任的科摩多SSL证书。

这是一名在芬兰从事IT经理在今年一月份发现的，只需要在微软的在线电子邮件中创建多个别名就能做到，他跟我们说：“我当时并不知道能否创建一个与管理员相似的电子邮件来达到获取到证书，因为觉得好玩，我决定试一试。”

几个月后，他创建了一个别名为hostmaster@live.fi的邮件帐号。他决定用创建好的这个帐号去获取到可信任的SSL证书。

令他吃惊的是，科莫多无任何验证地回转给了他HTTPS证书。

获取到浏览器信任的HTTPS证书能帮助他创建一个看起来很像真正的HTTPS网站并以此欺骗用户，达到窃取用户数据的目的。

他告诉我们他就此事已经在一月份联系了微软与芬兰通信管理机构，但是却没有得到任何一方答复。

上周二的时候，他收到了微软发来的感谢信。微软已经封了他的那个测试邮件帐号，使得他完全不能使用Lumia手机以及登录到XBox帐号。

在两个月后的今天，微软发出声明说他的发现已经得到严肃认真的处理。微软官方也告诉我们，他们准备联系发现这个问题的IT经理。

在星期一的时候，微软去掉了那个有问题的证书。在Windows 8.x, RT and Server 2012 系统版本中，可信任的证书已经能够自动升级。而Windows Vista, 7, Server 2009 and Server 2008 R2需要单独的手动升级。

微软指出，其他公司也应该确保针对如admin,administrator,postmaster,hostmaster,webmaster等管理员地址帐号向外开放而出现的问题。
