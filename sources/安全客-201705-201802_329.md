**Xshell**是一款十分强大的安全终端模拟软件，可以在Windows界面下用来访问远端不同系统下的服务器，从而比较好的达到远程控制终端的目的。互联网工作者可以通过网络远程连接管理服务器，享受其创新性的设计和特色，使得用户可以在复杂的网络环境中享受他们的工作。Xshell在互联网领域使用广泛，是大多数程序员及运维人员优选的远程管理工具之一。

  

近日，Xshell远程终端工具被爆出多个版本存在后门，恶意攻击者利用该后门可以收集到用户名密码等主机敏感信息，并将之传回攻击者的机器，导致服务器信息泄露，进一步可致使整个服务器被攻击。

  

如果这些后门没有被及时修复，服务器会面临严重的威胁。此次威胁根据严重程度和影响访问，在应急响应事件方面，定级为II级(重大网络与信息安全事件)。

  

本次受影响的版本：

**Xmanager Enterprise 5.0、Build 1232、Xmanager 5.0、Build 1045、Xshell 5.0、Build 1322、Xftp 5.0、Build 1218、Xlpd 5.0、Build 1220**

  

目前最新版本为Xshell 5 Build 1326，官方已经修复了该问题。

  

i春秋为您的安全做应急响应，复现真实场景，教您检测是否存在后门并进行应急修复。

**Xshell后门事件**

**▼▼▼**

Xshell是一款十分强大的免费终端模拟软件，它支持SSH、SFTP、TELNET、RLOGIN和SERIAL等功能，被广泛地用于服务器运维和管理。

  

而本月Xshell却被曝出存在有后门程序，无疑是安全圈的一个大新闻。

**Xshell后门个人应急响应**

**▼▼▼**

  

本地自检第一个方法是判断当前系统安装的版本是否为存在后门的版本，目前官网已经确定的版本有以下这些：Xmanager Enterprise 5.0 Build 1232、Xmanager 5.0 Build 1045、Xshell 5.0 Build 1322、Xftp 5.0 Build 1218、Xlpd 5.0 Build 1220。如果本地中匹配有上述的版本则存在后门。
