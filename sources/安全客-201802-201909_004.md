
从上面可以看出 rdi 就是 传入的 `char *buf` 的地址，首先会把他和最大的 case比较，这里是 5, 超过则跳出去，没有就根据 jump table 来执行每个 case从汇编代码可以看到，`[rdi]` 做了两次的检查一次在`cmp DWORD PTR [rdi],0x5` 比较最大值一次在 `mov eax,DWORD PTR [rdi]` 再一次取rdi 的值作为 jump table 的索引本来这里没有什么问题，但是如果`do_something(char *buf)` 传入的指针 buf的内容可以被并发修改，那么就可能会出现问题假如 cmp 之后 buf 的内容被改变了，那么 取到 eax 里面的就可能是其他的值，也就是我们说的 double fetch 了，于是就可以构造 jump table 的数组越界，最终可以利用`jmp rax` jump any wheregnote 也是根据这个特点做的设计，我们接下来看看题目
