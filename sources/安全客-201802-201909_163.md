# 2019第四届SSC安全峰会：安全客成为合作媒体

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5ODA0NDE2MA==&mid=2649718529&idx=3&sn=41406d4ac9a22526118a35ea5a3c8a54&chksm=888c4f6ebffbc6781736ab9d972cb5bb46b45bc7295b5b00aa0f0554f3ef5d935889056e9ee2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5ODA0NDE2MA==&mid=2649718529&idx=3&sn=41406d4ac9a22526118a35ea5a3c8a54&chksm=888c4f6ebffbc6781736ab9d972cb5bb46b45bc7295b5b00aa0f0554f3ef5d935889056e9ee2&scene=27#wechat_redirect)

第四届SSC安全峰会将于2019年8月初在古城西安举行，安全客与峰会承办方四叶草安全达成合作协议，成为2019年SSC安全峰会的官方合作媒体。将对峰会进行会前、会中、会后全程跟踪报道。

  

SSC安全峰会于2016年创办于西安，每年举办一届，迄今为止已成功举办了三届，得到了行业充分认可和社会各届广泛关注，成为我国中西部最具盛名，影响力最大，知名度最高的网络安全峰会，进一步推动了陕西及整个西北地区的信息安全产业发展，为网络安全强国建设贡献力量。

  

相比以往，2019年第四届SSC安全峰会融合政企合作、技术交流、技术创新、成果展示、资源对接、产学研用为一体，规模将更大、规格将更高、影响力将更广。旨在与全球硬科技创新大会、全球程序员节一并，成为西安“硬科技+信息技术+安全人才”的综合性会议。本次峰会有四大主题活动：对话长安、创客长安、科技长安、极客长安。

![](../Images/1900aad7a1e20f5ace12b904ecd0a8b0.png)

安全客是一个为广大安全爱好者和安全从业人员提供权威信息发布的漏洞信息、最新的安全资讯、最全的安全知识及精彩的安全活动的极具影响力的一站式安全平台。此次与安全客的良好合作将进一步扩大2018第三届SSC安全峰会的影响力和覆盖面，共同推动中西部网络安全事业的发展。

 

SSC安全峰会

  

  

**会议介绍：**

CloverSec Security Conference（简称：SSC），致力于打造为国内顶尖的网络安全峰会，旨在搭建“开放、共享、创新”的网络安全协同互促平台，推动国家网络安全事业整体发展，助力网络强国建设。

**往届回顾：**

2016年，第一届SSC安全峰会以“安全·传继”为主题，通过传承黑客精神，弘扬网络安全正能量，为安全行业的网络安全爱好者提供未来的发展方向。

2017年，第二届SSC安全峰会以“联动创新 智御未来”为主题，凝聚全国优秀的网络安全企业，汇聚全国网络安全专家、行业大咖、网络安全爱好者、高校学生共同聚焦“网络安全”。

2018年第三届SSC安全峰会以“智御安全•洞鉴未来”为主题，与业界大咖一起探讨安全新方向，探究安全新理念，共创安全新未来。
