# CVE-2020-0796：疑似微软SMBv3协议“蠕虫级”漏洞事件初步跟进说明

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5ODA0NDE2MA==&mid=2649721070&idx=2&sn=daf0fab51f33a053156f8889f2009f20&chksm=888cb881bffb3197eb71a8df350d38635c7a806dd5a453ceb9618ad6cd0068c20a3ae3ccf238&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5ODA0NDE2MA==&mid=2649721070&idx=2&sn=daf0fab51f33a053156f8889f2009f20&chksm=888cb881bffb3197eb71a8df350d38635c7a806dd5a453ceb9618ad6cd0068c20a3ae3ccf238&scene=27#wechat_redirect)

**0x01 事件描述**

2020年3月11日，360-CERT监测到有海外厂家发布安全规则通告，通告中描述了一处微软SMBv3协议的内存破坏漏洞，编号CVE-2020-0796，并表示该漏洞无需授权验证即可被远程利用，可能形成蠕虫级漏洞。  

鉴于微软官方并没有对编号 CVE-2020-0796 的漏洞进行描述，暂时不能确定该漏洞是否存在，360-CERT建议用户保持关注该漏洞事件的发展。

公告中描述如下\[见参考链接1\]：

```


漏洞是因为操作系统在处理SMBv3协议中的压缩数据包时存在错误处理。

**影响版本**

Windows 10 Version 1903 for 32-bit Systems

```

  

**0x02 时间线**

2020-03-11 某厂家发布规则更新，疑似SMBv3严重漏洞

2020-03-11 360-CERT 跟进并发布改漏洞初步跟进说明
