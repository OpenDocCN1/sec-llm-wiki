公司简介

火币集团是全球领先的数字资产金融服务商，以“让金融更高效，让财富更自由”为使命，秉承“用户至上”的服务理念，致力于为全球用户提供安全、专业、诚信、优质的服务。

熟练掌握常见WEB安全漏洞原理、利用方式以及对解决方案有较深入理解；
熟悉各种攻击方法，能独立研究发现新的漏洞；
熟悉 Java / Python 其中一项，可以将重复性的工作转换成自动或半自动化脚本实现；
对工作有热情，耐心、责任心强，具备较好的沟通能力和团队协作意识；
有各大SRC排名靠前者 / 移动安全经验 / SDL经验 / 个人技术博客 / 安全产品开发 / Java代码审计经验优先。
