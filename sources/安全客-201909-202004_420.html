这里插一句，Ghidra 转换高级代码能力比 IDA 的 Hex-Rays Decompiler 插件要差一些，比如 Ghidra 转换的这段代码：

还有对多个逻辑的判断，IDA 翻译出来是：
if (a && b){...}

Ghidra 翻译出来却是：
if (a) {  if(b) {  }}

而多层 if 嵌套阅读起来会经常迷路。总之 Ghidra 翻译的代码只有反复阅读后才知道是干嘛的，在理解这类代码上我花了好几个小时。
