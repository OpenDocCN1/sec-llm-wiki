# 放假之前EvaRichter勒索病毒来袭

![](../Images/6867c3e0d8507516d527ed19b059c07b.png) 目前勒索病毒仍然是全球最大的威胁，最近一年针对企业的勒索病毒攻击越来越多，大部分勒索病毒是无法解密的，并且不断有新型的勒索病毒出现，各企业一定要保持高度的重视，马上放假了，一款新型勒索病毒来袭……近日国外某独立恶意软件安全研究人员曝光了一个新型的勒索病毒，如下所示：

![](../Images/6aafbaccf802b1f4d76e1d462e3d93ce.png)

然后有人回复说是EvaRichter勒索病毒，并给出了id-ransomware博客地址，如下所示：  
![](../Images/c6a476570a553a7728f597bddd0c6970.png)这款勒索病毒之所以勾起我的兴趣，主要是它与之前的GandCrab、Sodinokibi、GermanWiper、NEMTY等勒索有某些类似之处，都将桌面壁纸修改成蓝色了，笔者通过MD5在app.any.run上找到了相应的样本，如下：

![](../Images/89fee660d6d377ddd4968f8153a0ec46.png)

样本被人在24号上传到了VT上，依据上传的时间判断可能就是国外那个独立恶意软件研究员上传的，从app.any.run上下载样本，图标使用了类似微信的图标，如下所示：  

![](../Images/411429f834c73a78f538e8fcce7613c2.png)

运行之后，加密的文件后缀为随机文件，如下所示：  

![](../Images/62bed86e7d2856cecec2ebe1b53d8881.png)

![](../Images/012ae43454aa2eb24652a17dac996c64.png)

![](../Images/980ca3ae174dd019951dded8fff71d62.png)

![](../Images/c8a282f352be008d789198acbd69c4f8.png)

黑客的BTC钱包地址：14Biqrf2fryuGNDrMDPchPCQeEjzZkqaLi，勒索赎金七天之内为：0.1521163 BTC，如下所示：  

![](../Images/96ea89eb50202d2c8895dcdb28a2ef8d.png)

此勒索病毒同样采用了高强度的代码混淆技术，简单的反调试技术，核心的勒索病毒代码被多层封装起来了，通过动态调试，解密出外壳的封装代码，如下所示：

![](../Images/52a1d4bd82fd20dc127a232decad6ce3.png)

![](../Images/2672ccad7f9b5f0e16acfcd7410dd7d4.png)

![](../Images/4118e4e647d83a8501a97c0a85e3a1c3.png)

从勒索病毒的核心代码，我发现这款勒索病毒与之前我分析过的一款新型的勒索病毒GermanWiper创建的互斥变量一模一样，都是HSDFSD-HFSD-3241-91E7-ASDGSDGHH，GermanWiper勒索病毒的核心代码同样是使用Delphi语言编写的，于是我将两款勒索病毒的核心Payload代码进行对比，如下所示：  

![](../Images/764f0ddc538d71434ccb2e6bc9e495c9.png)

代码相似度也高达82%，所以我觉得这款勒索病毒应该是GermanWiper最新变种，国外安全研究人员又取了一个名字叫：EvaRichter勒索病毒，还是按国外安全研究人员的名字命名吧
