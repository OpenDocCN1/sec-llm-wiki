公司简介



广东博智林机器人有限公司（简称“博智林机器人”）作为碧桂园集团的全资子公司，成立于2018年7月，是以机器人本体及其核心零部件、相关的机器人核心技术，智能机器人系统的研发、智造、运营为业务内容的科技型公司。

顺德机器人谷将引进全球顶尖机器人专家及研发人员，形成引领世界先进机器人技术的研发团队，为推进新一代智能机器人可持续发展提供重要支撑与技术储备，成为我国智能机器人产业发展的新引擎。

截止2020年8月，博智林机器人团队规模近7000人，硕士以上人才占比超过30％，博士在研发人员中占比超过10％，未来5年还将引进上万名全球顶级机器人专家及研究人员。博智林已陆续递交有效专利申请2400余项，获得授权600余项，在研发产品超过40种，近30款建筑机器人已进入工地现场测试。

招聘详情









应用安全工程师（SDL）

职位描述：

1. 参与和推进公司SDL管理体系建设，SDL制度、流程、标准的制定，推动SDL最佳实践；

2. 参与产品安全需求、安全设计、安全编码、安全测试等安全基线库的制定，推动落地实施；

3. 协助推广SDL的应用，并提供SDL流程体系相关培训；

4. SDL流程体系的需求收集与挖掘、方案设计等，持续推动SDL运营工作。

岗位要求：

1. 主导或参与过SDL、DevSecOps体系的建设；

2. 熟悉常见的安全开发基础模型，如SDL，SAMM、BSIMM等；

3. 熟悉多种安全标准，包括但不限于ISO27001，PCI-DSS，等保2.0等，熟练安全开发要求；

4. 熟悉web应用安全，对常见代码安全漏洞原理、危害、利用方式及修复方法有较深入理解；

4. 有良好的文档编写、宣传策划以及跨部门沟通、推动项目落地的能力。

加分项：

有一定的安全开发背景







代码审计工程师

职位描述：

1. 参与代码安全审计流程和方案的制定，并推动落地实施；

2. 协助制定安全编码规范，提供代码安全开发、代码漏洞修复等技术支持；

3. 使用代码安全审计工具开展代码审计工作；

4. 定制代码安全审计扫描策略，持续改进运营好代码审计服务。

岗位要求：

1. 熟练Java、php、python 一种或多种编程语言；

2. 1年及以上代码审计经验；

3. 熟练使用代码审计工具，如Checkmarx、Fortify、360代码卫士、cobra等；

4. 熟悉常见的安全漏洞及修复方法，具有分析研究安全漏洞的能力。
