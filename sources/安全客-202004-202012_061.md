公司简介

```

美团的使命是“帮大家吃得更好，生活更好”。作为中国领先的生活服务电子商务平台，公司拥有美团、大众点评、美团外卖等消费者熟知的App，服务涵盖餐饮、外卖、打车、共享单车、酒店旅游、电影、休闲娱乐等200多个品类，业务覆盖全国2800个县区市。截至2020年6月30日止十二个月，美团年度交易用户总数达4.6亿，平台活跃商户总数达630万。


```

工作地点

  

**北京朝阳区望京东路4号恒电大厦**

招聘详情

**01**

安全蓝军专家

职位描述：

```


1\. 负责集团内部安全能力的对抗验证，持续评估与反馈安全水位。以情报驱动沉淀技战术体系。
```

岗位要求：

```


1\. 熟练掌握The Cyber Kill Chain各环节关键技术、工具使用和思路。
```

  

**02**

业务蓝军专家

职位描述：

```


1\. 负责集团业务安全的对抗演练，收集并分析业务情报。持续发现并完善攻击场景，沉淀攻击手法。
```

岗位要求：

```


1\. 熟练掌握业务对抗所需的攻防能力（前端逆向、移动端逆向、模拟人机等），良好的业务理解及技术抽象能力。
```
