公司简介
悬镜安全，由北京大学白帽黑客团队“XMIRROR”发起创立，致力以AI技术赋能信安全，致力于DevSecOps软件供应链持续威胁一体化检测防御。核心的DevSecOps智适应威胁管理解决方案包括以深度学习技术为核心的威胁建模、威胁发现、威胁模拟、检测响应等多个维度的自主创新产品及实战攻防对抗为特色的政企安全服务，为金融、电信、政务、能源、教育等行业用户提供创新灵活的智适应安全管家解决方案。
 
工作地点
北京市海淀区中关村软件园(软件园三号路) 一期23号楼202室

招聘详情

01



软件测试工程师
职位描述：
1.能独立开展软件测试工作，合理分配工作任务，并控制测试进度和质量；
2.参与需求的分析评审，负责测试用例的规划，编写和审查；
3.报告测试进度和结果，并对测试中的问题进行分析，提出有建设性的改进化意见；
4.负责自动化测试和性能测试的规划和执行；

岗位要求：
1、本科及以上学历，有一定的开发或测试工作经验；
2、掌握至少一种脚本开发语言（如 perl， python， shell 等），具有一定开发能力；
3、熟悉自动化测试和性能测试相关技术，并有钻研兴趣；
4、熟悉测试理论、流程及规范，掌握常用的软件测试工具 loadrunner、 jmeter、 VuGen 等得使用；
5.具有良好的团队合作精神和沟通协调能力，积极主动，善于解决问题；

02



市场运营
岗位职责：
1.负责公司对外合作推广及项目合作拓展，获取潜在客户资源并进行管理维护；
2.负责公司市场活动策划及执行；
3.制定企业品牌宣传推广方案及活动组织。负责媒体专访、宣传文案撰写等；
4.负责媒体公号的运营，协助其他部门制定企业新产品的开发、推广方案。
 
岗位要求：
1.市场营销、管理类、广告类等相关专业本科及以上学历（能力优秀者，可不限学历）；
2.对数据敏感，有较强的数据分析与挖掘能力；
3.具备一定的销售技巧、渠道拓展能力、谈判能力；
4.有高度责任心，自我驱动能力、执行力强；
5.具有良好的团队协作能力和跨部门沟通能力。

03



安全服务工程师
职位描述：
1.对授权目标系统进行安全渗透测试；
2.负责客户的重保、应急响应等工作；
3.新型攻防技术探索研究；
4.将部分渗透能力自动化，平台化。
 
岗位要求：
1.精通各种渗透测试手法，能独立完成渗透测试工作，具备大型渗透项目能力；
2.熟悉各类高级渗透手法，思路开阔；
3.至少精通一门脚本编程语言；
4.对各类操作系统、应用程序、网络环境特性及弱点有较深入的理解；
5.具备良好的沟通、协调、分析能力者优先。

04



产品经理
岗位职责：

  1. 负责云安全相关产品的竞品分析、需求设计，版本管控等工作；

  2. 负责产品的定位分析、功能设计、产品线规划等；

  3. 跟踪并定期收集用户反馈，持续改进产品；

  4. 负责产品开发过程中的协调、进度质量跟踪和管理；

  5. 编写产品使用手册等相关文档；

  6. 负责用户的技术交流，产品介绍和方案宣讲；

  7. 行业安全解决方案规划、设计、编写；负责对用户及销售的培训工作；

 
任职要求：

  1. 本科及以上学历，计算机相关专业，2年以上产品工作经验；

  2. 能独立承担功能模块的需求制定；

  3. 熟悉主流信息安全产品（如漏扫、IPS、HIDS等）优先考虑；

  4. 有信息安全及开发相关工作经验者优先。

05



开发工程师(Go 方向）
岗位职责：

  1. 负责安全检测产品的设计、开发；

  2. 负责代码维护及性能优化；

  3. 解决产品测试和使用中出现的问题。

 
岗位要求：

  1. 熟悉 GO 语言开发及相关技术栈；

  2. 具备扎实的 C/C++基础， 熟悉 TCP/IP 协议、熟悉多进程、多线程编程；

  3. 熟悉 Shell、Perl、Python 等至少一种脚本语言；

  4. 熟悉 Linux 操作系统原理及常用工具；

  5. 良好的沟通能力，优秀的程序编写风格，独立思考的能力和习惯；

  6. 有信息安全相关经验者优先；

  7. 本科及以上学历，计算机相关专业。

06



开发工程师Python
岗位职责：

  1. 负责新爆漏洞和通用型漏洞的POC分析和研发；

  2. 负责相关安全功能研发；

  3. 负责对新型安全技术的研究和分析；

  4. 负责对产品的安全功能测试和优化。


岗位要求：

  1. 精通Python语言，至少1年以上Python研发经验；

  2. 熟悉 Shell、Perl、Java等至少一种脚本语言；

  3. 熟悉通用漏洞形成、发现及修复原理（比如 SQL、XSS、CSRF、SSRF、RCE反序列化等）；

  4. 熟悉Linux操作系统原理及常用工具；

  5. 具备良好的沟通能力，优秀的程序编写风格，独立思考的能力和习惯；

  6. 有信息安全相关经验者优先；

  7. 本科及以上学历，计算机相关专业。
