招聘详情

\>\>\>\>

隐私保护技术研究员

  
  
  
  
  
  
**职位描述：**

```
1、基于隐私保护、安全多方计算、联邦学习等前沿技术，设计并研发相应数据安全解决方案； 2、对隐私保护、安全多方计算、联邦学习等领域进行前瞻性技术预研，持续进行技术创新。
```

**岗位要求：**

```
1\. 计算机科学与技术、网络空间安全、信息与通信工程、数学与系统科学或相关专业硕士及以上学位； 2\. 熟悉数据安全行业发展现状，特别是联邦学习、多方安全计算的研究与落地进展； 3. 掌握一种或多种高级密码学、安全计算或隐私保护技术，如差分隐私、通用安全多方计算、专用安全多方计算、全同态加密、函数加密、零知识证明、可信执行环境； 4. 了解常用机器学习算法，如 XGBoost、LR 等； 5. 熟悉一个或多个常见的 ML/DL 开源工具库，如 Tensorflow、PyTorch 等。
```

  

\>\>\>\>

安全能力研发工程师

  
  
  
  
  
  
**职位描述：**

```
1、负责安全产品的二次研发及自研安全产品的研发及运营工作；
```

**岗位要求：**

```
1、全日制本科及以上学历；2、一年及以上研发相关工作经验；3、熟悉java及常用java framework技术栈或C/C++或Go技术栈，至少熟悉bash,python 中的一门脚本语言；熟悉Linux平台的应用产品研发，熟悉linux操作系统; 4、能够独立完成模块设计、开发和单测等产品研发工作；5、具有网络、云计算及分布式计算，大数据处理等方面研发经验者优先考虑；6、熟悉IDS/IPS、防火墙、WAF、Web安全、安全大数据、主机安全、机器学习、数据和行为安全等领域并有相关经验者优先; 7、具有良好的团队协作意识，较强的责任心，工作富有激情，勇于挑战。
```
