# 只是冰山一角：从Rite Aid案例揭秘面部识别系统的应用和滥用

**前言**

根据Rite Aid公司一份关于面部识别程序的秘密报告显示，仅仅禁止政府滥用该技术还远远不够。 

**面部识别技术的广泛应用**

路透社本周公布的一项调查显示，Rite Aid商店已经面向200家商店的顾客推广使用了面部识别软件。据路透社报道，这些用于面部识别的摄像机在8年的时间内陆续被投放到市场，它们通常被安装在低收入地区，主要是黑人和拉丁裔地区。而这些摄像机还经常会对有色人种进行误判。例如，在2016年，一名男子在Rite Aid购物期间，向美国加利福尼亚州的公共事务部提出了投诉，该投诉与面部识别系统的种族特征分析算法相关。路透社的这篇报道，描述了使用一种具有攻击性且具有缺陷的技术的黑暗画面，这项技术正在暗中被开发、测试和实施，然后悄悄地在美国的数百个地点被客户使用。在美国，并不仅仅是Rite Aid在暗中开展面部识别。沃尔玛已经在1000多家商店中使用了面部识别，澳大利亚的7-11便利店在700多家商店中使用面部识别，肯德基和麦当劳也已经在中国和日本测试了该技术。我们认为，在美国的众多企业之中，可能还会有更多家企业在使用面部识别技术，其中涉及到用于实时跟踪人员的算法。例如，面部识别技术巨头NEC去年曾向OneZero表示，他们不会向美国政府出售实时面部识别技术，但确实已经将该技术提供给位于美国的私人客户使用。该企业没有透露具体的客户信息。 

**立法对抗技术滥用**

在如何防范这项技术不断扩散的这一方面，美国远远落后。在旧金山、奥克兰和波士顿等城市，激进派反对政府使用面部识别，并取得了艰难的胜利。纽约可能会在学校禁止使用面部识别。但是，这样的法规并不能阻止沃尔玛和Rite Aid等公司使用这一技术。在伊利诺伊州，设立了严格的隐私权法律，禁止收集面部识别数据。但除了伊利诺伊州之外的其他州，几乎都可以在未经本人同意，或本人不知情的情况下，可以存储、使用和出售人们的面部信息。表面上，Rite Aid仅持有数百万人经过商店的数据，但该公司如何对这些信息进行处理，完全取决于他们的想象力。尽管目前并没有证据表明，但我们完全可以想象，Rite Aid可以提供将入店行窃人员的黑名单出售给其他商店的业务。俄勒冈州波特兰市是唯一提议禁止私人使用面部识别的城市，这意味着类似于Rite Aid这样的项目是非法的。科技巨头亚马逊正在持续反对这一举措。其他科技巨头也希望能够积极参与到面部识别的立法上来，他们纷纷对新法律提出建议，而这样的建议会为私有企业持续开展面部识别留下很大的缓和空间。例如，微软的一名员工同时也是华盛顿州的参议员，他撰写了华盛顿州关于规范面部识别技术的提案。正如我们所预料的，在他所撰写的提案中，很好地保护了微软的业务前景。禁止政府使用面部识别功能，这样的措施可以有效防止科幻反乌托邦的场景。但是，如果同时不去禁止私人使用该技术，那么只是将政府监视人们的可能性转变为公司监视人们，其中的透明度和监督力度会变得更少。
