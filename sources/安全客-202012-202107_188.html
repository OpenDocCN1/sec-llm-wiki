公司简介

深圳市网安计算机安全检测技术有限公司，成立于2001年6月，是国家高新企业，也是一家专门从事网络安全服务的第三方安全公司，服务项目包括网络安全等级保护测评、商用密码应用安全性评估、ISO27001体系建设咨询、信息系统审计、ICP评测、APP个人信息安全合规评估、信息安全风险评估、一体化创新智能安全防护平台等，迄今为止所服务的政府、金融、医疗、教育、企业单位已超过1000家。

深圳网安检测公司作为中关村信息安全测评联盟的副理事长单位，凭借优异的业绩及过硬的技术服务底蕴，连续多年获得全国等保测评机构先进单位称号。同时，网安检测公司已连续多年通过中国合格评定国家认可委员会(CNAS)的检测机构认可评审，标志着网安检测公司在安全检测服务领域获得国家认可并处于领先地位。

2018年，网安检测公司正式列入第一批27家商用密码应用安全性测评机构试点单位目录，2019年8月，网安检测公司获准扩大试点范围，面向社会开展密码应用安全性评估。

 

公司地点

招聘详情

渗透测试工程师

工作城市

深圳、广州

岗位职责

1. 针对授权指定站点进行按需渗透测试，包括但不限于Web系统、客户端、移动端等应用，能够独立输出安全测试报告并协助提供修复漏洞建议。

2. 针对网络攻击及安全事件进行跟踪，提供应急响应支撑并能独立处置应急响应事件。

3. 密切关注信息安全技术发展的发展趋势，跟踪互联网发布的安全漏洞、补丁信息和信息安全事件。

4. 完成上级领导交办的其他工作事项。

岗位要求

1. 1年以上的渗透测试经验，计算机相关专业，技术优秀者可放宽专业；

2. 熟悉常见WEB和移动端安全漏洞原理和利用方式，能对发现的安全风险提供修复方案；

3. 熟悉网络网络协议、Linux/Unix操作系统、Oracle2/mssql数据库；对主流操作系统和网络应用的漏洞和弱点有深入了解和研究；

4. 熟练掌握各类测试工具，能编写安全工具者优先；

5. 熟悉应急响应工作流程，能够独立完成渗透测试方案、测试报告；

6. 具有良好的职业素养、沟通能力及团队合作能力；

7. 具有较强的责任心、较强的语言表达能力和沟通能力，为人诚恳，积极好学。

解决方案专家

工作城市

深圳

职位描述

1. 根据网络安全相关合规要求、各行业技术规范，完成整体安全合规服务解决方案体系规划和设计；

2. 负责公司相关安全服务的售前技术支持工作；详细分析客户的业务需求，结合公司的服务，为客户提供合适的解决方案；

3. 负责合规服务成功案例整理和推广，标准化行业解决方案编制和推广；

4. 负责内部营销团队培训赋能工作。

岗位要求

1. 具备高水平的规划和解决方案能力，能够为用户独立完成业务规划及整体解决方案设计；

2. 对网络安全行业技术规范具有较深理解，熟悉行业客户需求及关注点；

3. 熟悉使用各类工具（文档编写、产品设计、功能PPT等），具备较好的审美能力以及较强文档撰写能力；

4. 善于分析、总结和归纳，出色的沟通表达、演讲能力，思维逻辑清晰，能够承担压力，工作主动性高，有很强的责任心。
