公司简介



美团的使命是“帮大家吃得更好，生活更好”。作为中国领先的生活服务电子商务平台，公司拥有美团、大众点评、美团外卖等消费者熟知的App，服务涵盖餐饮、外卖、打车、共享单车、酒店旅游、电影、休闲娱乐等200多个品类，业务覆盖全国2800个县区市。截至2020年6月30日止十二个月，美团年度交易用户总数达4.6亿，平台活跃商户总数达630万。

2018年9月20日，美团点评（股票代码：3690.HK）正式在港交所挂牌上市。截至2020年9月14日，市值超过1700亿美元，位列中国上市互联网公司第3名，全球第8名。

当前，美团战略聚焦 Food +Platform，正以“吃”为核心，建设生活服务业从需求侧到供给侧的多层次科技服务平台。与此同时，美团正着力将自己建设成为一家社会企业，希望通过和党政部门、高校及研究院所、主流媒体、公益组织、生态伙伴等的深入合作，构建智慧城市，共创美好生活。

Web前端开发工程师

工作城市

北京、上海

职位描述

在这里，你将负责网站和手机终端的交互界面实现的工作，为我们的用户呈现优秀的界面交互体验；

在这里，你还将参与客户端架构工程体系的建设，通过各种技术优化、组件化、自动构建，线上运维等领域的先进技术提高运营质量和开发效率，支撑业务的快速稳定发展！

你可以和设计师、产品策划一起，实现炫酷的网页效果，在关键时刻尽情展现自己在美术和设计方面被隐藏的天赋；

你可以和后端、SRE、质量工程师，PM，设计师们一起，不断优化，达到业界领先的性能和用户体验，帮大家“Eat better, live better”；

你可以！只要你来这里。

岗位要求

1.热爱前端（移动端）开发，对使用自己代码直接服务亿万用户着迷；或者是技术极客，对写出完美代码有执着者；

2.有前端领域开发经验，能独立完成基础的前端开发工作；

3.熟悉 W3C 标准与 ES 规范，熟悉 Web 语义化和相关前端技术；

4.熟悉至少一种 JavaScript 前端框架或者具有小型专项 JavaScript 框架的开发经验；或具有 Node 项目开发经验；

5.掌握至少一门其他开发语言（如C/C++/Go/Rust/Java/Python/Ruby/Dart 等），并有一定的实践经验。

数据开发工程师

工作城市

北京、上海

职位描述

美团拥有本地生活服务行业最全、涵盖吃喝玩乐住行的全链条大数据，公司非常注重数据价值，数据是美团的核心资产，同时也是下一代新能源，数据的高效管理和价值挖掘是各公司业务发展的基础和保障，公司的核心经营决策、百万外卖小哥的调度、广告、搜索、推荐等用户产品的正常运转等都离不开数据，数据就像血液一样渗透到美团的方方面面。在本岗位上，你将参与：

1.数据仓库的建设、组织和管理，沉淀数据资产；

2.数据建设过程的各项工具研发，如数据安全、数据质量、数据开发的工具链等；

3.数据应用的研发，如商业智能、挖掘、分析报告、数据可视化等；

4.其他服务于业务各环节的数据运营工作；

加入我们，参与建设、引领本地生活服务行业的大数据发展潮流，一起努力，通过数据帮大家吃得更好，生活更好。

岗位要求

1.计算机、信息技术相关专业本科以上学历，对数据技术感兴趣；

2.熟练掌握至少一种编程语言（包括但不限于Python、Java、C++等），熟练掌握算法数据结构，有编程实践经验；

3.掌握数据库基本原理和知识，熟练使用SQL。







计算机视觉工程师

工作城市

上海

职位描述

1.负责通用视觉识别能力的构建，包括文字识别，人脸和人体分析，图像和视频理解，增强现实等；

2.负责视觉技术在美团全场景的落地，包括但不限于线上信息流的内容审核、身份认证、门店数字化、视觉交互等。

岗位要求

1.熟练掌握模式识别和图像处理领域的基础理论和方法，在一个或多个领域有深入研究：OCR、人脸识别、大规模图像分类与检索、物体识别、视频结构化分析等；

2.在机器学习和深度学习方面具备扎实的理论基础和工程能力，熟悉TensorFlow、Caffe、MXNet等主流框架；

3.优秀的分析和解决问题的能力，项目推动力和团队协作能力。

风控运营

工作城市

北京

职位描述

如果你对以下任意一个方向感兴趣，欢迎网申这个岗位：

1.基于审核标准SOP，可独立执行作弊案件调查工作，维护平台交易秩序；对接内部产品团队，定期针对误伤案件提出策略优化需求；可适当执行基础数据分析相关工作；负责部门内部的公众号运营编辑和维护工作；良好的沟通能力、出色的执行力、有责任心、富有团队精神；

2.负责反洗钱法律法规的解读、传达；负责与反洗钱政策研究、行业组织的日常工作联系，落实政策和要求；负责反洗钱各类报告的撰写、报表填写及上报；根据客户的身份、行为与交易等信息，进行综合判断客户是否存在洗钱风险；对反洗钱系统各项功能的优化与迭代提出需求，并且推动需求落地；完成公司交办的其它工作事项。

岗位要求

我们期待你：

1.本科以上学历，法律、金融、经济、管理等相关专业优先；

2.逻辑性强，具有敏锐的洞察力和分析能力，熟练使用办公软件, 会数据分析工具等是加分项；

3.具备优良的写作能力、语言表达能力、数据分析能力、逻辑推理能力及自主学习能力；

4.思路清晰，细致主动，责任心强，具有较好的团队合作意识和组织协调能力；

5.富有团队合作精神，有较强的学习自驱力和成长意愿。具有较强的应变能力与沟通能力。
