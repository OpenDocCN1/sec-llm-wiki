公司简介

京东是一家以技术为成长驱动的公司，从成立伊始，就投入大量资源开发完善可靠、能够不断升级、以应用服务为核心的自有技术平台，从而驱动电商、金融、物流等各类业务的成长。未来，京东将更加重视技术的战略地位，发展云计算、大数据、智慧物流、人工智能、AR/VR、智能硬件等最新技术，以推动京东实现快速、可持续增长。

未来十二年，京东集团将坚定地朝着技术转型，用技术将第一个十二年建立的所有商业模式进行改造，打造一个包括智能商业、智能金融、智能物流在内的全球领先的智能商业体。

 

工作地点

北京市朝阳区北辰中路北辰世纪中心A座

 

招聘详情






风控大数据策略开发工程师

职位描述：

1. 负责开发高并发、低延迟、可扩展的广告反作弊实时数据流处理系统。

2. 负责海量数据分析，设计和实现稳定和高性能的计算模型和离线系统。

3. 负责广告风控领域的数据分析、挖掘和建模，深入挖掘作弊情况，为业务提供决策支持。

4. 加入团队，不断探索和创新，解决业务问题。

岗位要求：

1. 计算机、数学及相关专业，本科以上学历，具有2年以上大数据开发工作经验。

2. 熟练掌握c++/java/scala/python等至少一门编程语言，熟悉linux环境下编程，具备扎实的程序设计理论和工程实践能力。

3. 熟悉redis、kafka等开源工具，spark、flink、storm、hive等一种或几种大数据框架，对其原理、源码有一定研究者优先。

4. 具备很强的学习能力，解决问题能力，良好的沟通合作精神。

加分项：

1. 熟悉各类作弊场景的动机手段，能够针对性的制定反作弊算法、特征和模型。

2. 有跨行业反作弊经验，比如电商、O2O、信息流、金融等风控领域。

3. 有机器学习和深度学习等相关算法经验。







广告风控算法

职位描述：

1，负责京东在线营销广告的反作弊系统、基于大数据和智能算法的各类反欺诈工作

2，研发数据挖掘、机器学习、深度学习、无监督学习等反作弊技术

3，研发流式计算、离线分布式计算、图计算等技术

3，加入团队，不断探索和创新，解决业务问题

岗位要求：

1. 计算机、数学及相关专业，硕士/博士学历，3年以上算法经验，上不封顶

2. 熟悉各类作弊场景的动机手段，能够针对性的制定反作弊算法、特征和模型

3. 熟悉数据挖掘、统计学习、深度学习等相关的算法，有能力建立模型解决各类反欺诈问题，熟悉至少一种机器学习平台

4. 熟悉scala, c/c++，python等语言，有分布式数据处理经验，熟悉spark分布式系统，有良好的编程风格

5. 很强的学习能力，科研能力，良好的沟通合作精神

6. 有跨行业反作弊经验，比如电商、O2O、信息流等领域经验的优先







广告风控产品经理

职位描述：

1. 对京东广告反作弊进行整体规划，设计从作弊发现到特征提取、处理的流程和逻辑，并推动反作弊项目落地和后续维护；

2. 梳理和发现业务风险点，主动跟进并和研发制定解决方案；

2. 通过迭代作弊发现机制、数据指标监控、作弊处理流程，制定和优化反作弊策略，降低人力和时间成本，提升作弊处理效率；

3. 了解内外部竞价广告商业场景和核心需求，根据其他产品线的需求或外部市场变化，及时作出反馈和处理；

4. 同算法、技术、测试、标注等同学配合，并进行跨部门沟通协作，协调各方资源，确保体系稳步发展。

岗位要求：

1. 本科及以上学历，计算机、统计学等理工科专业背景优先；

2. 有反作弊、反垃圾、商业策略、风控策略等相关工作经验两年及以上，了解反作弊产品、行动策略、效果评估方法优先，有互联网行业反作弊风控经验优先；

3. 踏实可靠，积极主动，具有强烈的责任心、钻研精神和沟通协作能力；

4. 具备良好的逻辑思维能力，对解决挑战性问题充满热情，善于解决和分析问题；

5. 掌握数据挖掘基础知识，熟练使用数据分析工具优先，如Excel、SQL、Python、R等。







大数据架构工程师

职位描述：

1. 负责开发高并发、低延迟、可扩展的广告反作弊实时数据流处理系统

2. 负责离线反作弊处理系统的开发、维护和性能调优

3. 根据新的反作弊业务场景和需求，完成系统架构的设计和开发

4. 加入团队，不断探索和创新，解决业务问题

岗位要求：

1. 计算机、数学及相关专业，本科以上学历，具有2年以上大数据开发工作经验，上不封顶

2. 熟练掌握c++/java/scala/python等至少一门编程语言，熟悉linux环境下编程，具备扎实的程序设计理论和工程实践能力

3. 熟悉redis、kafka等开源工具，spark、flink、storm、hive等一种或几种大数据框架，对其原理、源码有一定研究者优先。

4. 有特征计算，流式计算，广告数据流架构经验者优先

5. 有跨行业反作弊经验，比如电商、O2O、信息流等领域经验的优先

6. 具备很强的学习能力，解决问题能力，良好的沟通合作精神
