公司简介

青藤云安全（简称“青藤”）成立于2014年，是中国主机自适应安全开创者、云原生安全领军企业。自成立以来，青藤以“为新技术提供新安全”为使命，专注于自主研发，不断提高核心技术创新能力，致力于成为一家富有社会责任感、为用户持续创造价值的世界级安全公司。
凭借强大的技术研发能力，充分运用云计算、大数据、AI等技术，青藤采用自适应安全架构，陆续推出青藤万相·主机自适应安全平台、青藤蜂巢·云原生安全平台、青藤猎鹰·威胁狩猎平台、青藤雷火·AI-Webshell检测系统以及专业的安全服务，形成了完整的安全产品矩阵，为客户打造集“预测、防御、监控和响应”于一体的安全闭环，以智能、集成和联动的方式应对各类攻击。
截至目前，青藤已帮助来自政府、金融、运营商、工业互联网、交通、电商、零售、医疗、互联网等行业的1000+大型客户，600万+台核心服务器提供稳定、高效的安全防护。

招聘详情

漏洞研究员


工作城市
北京
职位描述
1. 负责漏洞挖掘、研究工作，可输出有价值的研究成果。
2. 跟踪国内外漏洞信息，输出检测POC、利用脚本等。
3. 参与完善红队体系，包括但不限于自动化漏洞挖掘、武器库储备等。
岗位要求
1. 具有较多攻防项目经验，熟悉各个攻击流程
2. 熟悉常见Web漏洞利用方式以及漏洞原理
3. 熟练掌握代码审计技能，精通一种或熟练掌握多种编程语言，如Java、PHP、Golang、Python、.Net 等
4. 较好的的沟通能力、学习能力、抗压能力；
加分项
1. 有独立挖掘CVE、CNVD、CNNVD漏洞经验者。
2. 有丰富代码审计、漏洞挖掘经验者。
3. 独立挖掘过OA、服务器、中间件漏洞者。

攻防研究员


工作城市
北京
职位描述
1. 研究攻防对抗技术与技巧，对内产品赋能，对外输出研究成果；
2. 跟踪国内外安全动态、攻防技术；
3. 参与完善红队体系，包括攻击链、工程化工具等；
4. 参与红队评估、攻防对抗等项目；
5. 通过WEB或钓鱼，在攻防对抗项目中对目标进行快速内网突破；
岗位要求
1. 对攻防技术抱有热情；
2. 有较好的自我驱动能力；
3. 熟悉常见web漏洞原理，有较为丰富的漏洞利用经验；
4. 熟悉多种钓鱼技巧，有独特的钓鱼思路及手法；
5. 有一定的内网渗透、域渗透经验；
加分项
1. 掌握 Python / Java / Golang / C++ 等一种或多种编程语言，可开发较为复杂的工具；
2. 有红队经验；
3. 有漏洞挖掘经验；
4. 有SRC经验；
5. 有一定的文档、报告编写能力；
6. 有较好的的沟通能力、学习能力、抗压能力
