公司简介  

蚂蚁集团是移动支付平台支付宝的母公司，也是全球领先的金融科技开放平台，致力于以科技推动包括金融服务业在内的全球现代服务业的数字化升级，携手合作伙伴为消费者和小微企业提供普惠、绿色、可持续的服务，为世界带来微小而美好的改变。

  

  
  
  
  
工作城市  

深圳、杭州

  

  
  
  
  
招聘详情  
高级基础安全工程师/专家  
**0****1**

**职位描述**

1、负责蚂蚁集团国际事业群的安全技术体系建设和运营工作。

 2、负责蚂蚁集团国际事业群基础安全能力建设，包括但不限于防火墙、WAF、HIDS、漏洞扫描、资产指纹、蜜罐、安全基线、SOC等工作。

**0****2****岗位要求：**1、具有5年以上企业基础安全领域相关工作经验，有公有云安全建设及运营经验。2、熟练掌握常见公有云安全产品及解决方案，具备公有云API调用开发等技能。3、熟悉安全运营中心(SOC)的整体框架，对相关解决方案有深入了解和实践，有参与建设或运营经验。4、熟练掌握Java或Go语言等，具备数据化分析问题能力，有运营或开发安全系统经验者优先。5、熟悉金融类业务场景安全问题及解决方案和落地经验者优先。高级应用安全工程师/专家  
**01****职位描述：**

```

1、负责蚂蚁集团国际事业群的安全技术体系建设和运营工作。
```

**02****岗位要求：**

```


1、具有5年以上企业的的应用安全领域相关工作经验，有互联网公司SDL落地经验。
```

高级数据安全工程师/专家

```


1、负责蚂蚁集团国际事业群数据安全及个人隐私保护安全技术体系建设及运营工作。
```

**0****2****岗位要求：**

```


1、5年以上企业内数据安全、个人信息保护、安全运营等领域工作经验。
```
