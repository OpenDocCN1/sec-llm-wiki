公司介绍

```


美团的使命是“帮大家吃得更好，生活更好”。作为中国领先的生活服务电子商务平台，公司拥有美团、大众点评、美团外卖等消费者熟知的App，服务涵盖餐饮、外卖、打车、共享单车、酒店旅游、电影、休闲娱乐等200多个品类，业务覆盖全国2800个县区市。截至2020年6月30日止十二个月，美团年度交易用户总数达4.6亿，平台活跃商户总数达630万。活。
```

  

  
工作城市北京、上海

  

  
招聘详情**#流量安全算法工程师**  
**01****职位描述**

```
1.根据各类爬虫特点，应用机器学习&深度学习技术，针对海量信息，解决业务痛点,保障业务健康发展；
2.基于各类行为数据、业务数据、设备指纹数据等，通过算法有效赋能，有效刻画用户/商户/设备的风险服务；
```

**02****岗位要求**1.良好的数据结构和算法基础，熟练掌握C/C++/Python/Java/Shell等编程语言 ；

2.熟悉常用的机器学习算法、深度学习相关技术，对算法原理、实现、优化有较深入了解，3年以上相关工作经验 ，有异常点检测相关经验尤佳 ；

3.业务理解能力强，对数据有较高敏感度，逻辑思维能力强，有较强的独立思考能力 ；

4.正直诚信，具备与网络黑产持续斗争的韧性。

**#应用安全专家**  
**01****职位描述**1\. 负责美团应用的安全开发生命周期（SDLC），包括安全测试、威胁建模、产品架构设计；2\. 熟悉主流应用框架的风险点和安全方案，根据业务需要提供支持；3\. 输出及维护统一的安全解决方案，并能够推动方案的落地。**0****2****岗位要求**1\. 3年以上互联网行业产品安全建设经验；2\. 熟悉Java/Node.js 至少一门语言，能够独自完成源码审计工作，并熟悉Spring系列及Node主流框架的风险和安全实践；3\. 对可信计算、认证、鉴权、加密、攻击缓解措施、纵深防御等在软件安全设计领域落地有独到理解；4\. 英文阅读能力较好。**#原生安全架构师**  
**01****职位描述**1、负责美团基础架构安全能力建设，包括提供业界最佳实践方案、架构安全、原生安全能力建设；2、熟悉运维、开发流程中所需要的基础服务及安全防护；3、以结果为导向，推动安全方案落地。**0****2****岗位要求**1.5年以上安全行业从业经验；2.熟悉大型互联网公司的运维体系、开发体系，尤其是对K8s、微服务、PKI体系有深入了解；3.无障碍阅读英文文档。**#基础安全项目交付专家**  
**01****职位描述**1.负责美团基础安全项目管理体系的建设；2.对BG/BU级项目管控针对目标、进度、风险、ROI进行分析洞察，对组织决策和技术管理提供改进建议，并对全流程持续优化，为团队提供流程、工具、方法等支持；3.能够独立负责跨BG/BU范围的项目管理，从项目初期规划制定到后期收尾负责完整的项目生命周期管控，对项目进行立项、排期、风险识别、质量管理，解决过程中出现的各种问题，保证项目目标的达成；4.负责临时紧急项目的承接和执行，以及应对解决方案的成功实践及沉淀，不断迭代并复制推广，通过日常工作发现流程机制的问题，推动部门内部进行完善；5.负责对产品技术同学进行项目管理方法和意识的培训，提高部门整体的项目管理水平。**0****2**岗位要求1.本科以上学历，计算机、网络空间安全相关专业毕业；2.3-5年安全产品研发管理或项目管理经验，能够独立应对大型跨团队研发管理及项目集管理的工作；3.具备丰富流程管理及改进实践经验，能够因地制宜，在实际工作中灵活运用；4.具有较强的团队合作意识，工作积极主动、对细节有要求，具备优秀的沟通协调能力，责任心强，自驱力强，有较强的抗压能力和良好的职业道德；5.具备PMP或其他项目管理职业资质认证。
