# 特朗普卸任前启动五角大楼秘密计划背后的迷雾

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5ODA0NDE2MA==&mid=2649752328&idx=1&sn=7724e4d5fa0a71e46900762699de16ed&chksm=88933367bfe4ba7161c3f27873f60a1ad9c812a1fa64eedb6b9075f36060b628ced26d21f8b9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5ODA0NDE2MA==&mid=2649752328&idx=1&sn=7724e4d5fa0a71e46900762699de16ed&chksm=88933367bfe4ba7161c3f27873f60a1ad9c812a1fa64eedb6b9075f36060b628ced26d21f8b9&scene=27#wechat_redirect)

**事出反常必有妖，但有妖不一定是坏事。**

![](../Images/740b3e6b68e1f37d2edd3bc024fff7fc.png)

在数十年没有使用大量互联网后，五角大楼在特朗普卸任前一天，将数百万台计算机地址的控制权交给了一家不知名公司，用以发现可能的网络漏洞和威胁。早不交晚不交，卡着卸任时候交，很难不让人怀疑这背后暗藏猫腻。  

 

**0****1****旧事完结引争议**  
  

年初，唐纳德·特朗普（Donald Trump）总统卸任前几分钟，将大规模的互联网管理权委托给了佛罗里达州一家不起眼的公司——全球资源系统公司（Global Resource Systems）。而在前不久，美国国防部又重新拿回了1.75亿个IP地址的控制权，让特朗普卸任时的管理权移交画上一个暂时的句点。

管理权交接后，这项曾经时间节点十分不寻常的事件，开始面临全方位的审查。有人士分析称，这项计划更像是一场规模巨大，且充满政治色彩的联邦权力交接。全球资源系统公司（Global Resource Systems）在其最鼎盛的时期，控制了互联网上近6%的IPv4地址。如此之多的IP地址虽一直未被使用，但在五角大楼的控制下已有几十年。如果在市场上公开销售的话，可能价值会有数十亿美元。

![](../Images/b286effe2c8a5f4b5f15393f7e9b1c7d.png)

更神秘的是，根据公司注册记录显示，全球资源系统公司（Global Resource Systems）当时只有几个月的历史，该公司于2020年9月正式成立，而且没有公开报道过的联邦政府合同，没有明显正式对外的官方网站，在佛罗里达州也没有所谓真正的办公地点实体。而在接受了美国国防部的IP地址后，这家公司管理的互联网空间比中国电信、AT&T、或Comcast都还要多。

  

**0****2****IP地址移交or隐秘计划？**  
  

上周，五角大楼方面发布了一项技术公告，正式对外公布称他们将重新拿回1.75亿个IP地址的控制权，并会将流量定向到他们自己的服务器。在接受采访时，五角大楼方面表示，该IP地址移交计划实际是一项网络安全措施，旨在检测未被识别的漏洞，并防范未经授权使用国防部IP地址空间的恶意行为。这些IP地址从未被出售过或出租给这家公司，只是由这家公司控制试验项目而已。

这个项目则是由五角大楼一个名为“国防数字服务部”的精英单位创建的，该单位直接向国防部长报告，主要负责为部队解决突发事件以及开展试点工作。

![](../Images/88c09725fd32efdebf88d535b3a615c8.png)

美国国防部发言人拉塞尔·戈梅尔（Russell Goemaere）在《华盛顿邮报》的一份声明中表示：“国防数字服务部制定了一项计划，即启动网络安全试点，然后将该计划的控制权移交给了国防部合作伙伴。国防数字服务部的这一试点计划允许国防部重新回到传统的操作模式上，并引入更加成熟的网络安全流程，以保持整个DODIN的一致性。除此之外，还将允许他们对IP地址空间进行更加可控的管理，并确保国防部拥有维持和提高DODIN弹性所需的作战机动空间。”

![](../Images/79a07589822ae139e952686d817b590b.png)

对于为何会在特朗普卸任前几分钟移交，美国国防部发言人拉塞尔·戈梅尔（Russell Goemaere）给出了这样的解释，试点计划选择在如此不同寻常的时间节点启动（该计划于就职典礼当天上午11:57，即拜登总统就职前三分钟开始移交IP地址控制权），跟时间和联邦政权移交方面并无任何关联。该工作计划于2020年秋季开始实施，并于2021年1月中旬启动，而且当时所需的基础设施全部都已到位。而这一计划的启动，可以帮助我们更好地识别潜在的漏洞，评估和缓解潜在的网络威胁。

  

**0****3****写在最后**  
  

相比于媒体政界的众说纷纭，网络专家却对这一事件给出了不一样的评价。称全球资源系统公司（Global Resource Systems）接手后，将能够识别大规模攻击，进而更好地制定系统保护策略。

简单来说，这就是让专业的人做专业的事。美国政府通过与第三方公司合作，不仅达到了网络监控、收集国外情报的目的，同时还加强了自身的安全系统防御，何乐而不为呢。
