# ISCx安全客直击：RSAC 2022专题报道——零信任

随着RSAC沙盒大赛落幕，盛夏的温度被推向顶点。ISC联合安全客，为安全圈送来一丝清凉，在热烈的讨论中、激烈的交锋下，引导冷静的思考、输出尖锐的观点。本期云端专题讨论的主题是：零信任。它作为新安全时代最被期待的架构，为众多安全研究者追捧、实验、分析。RSAC 2022除了零信任议题外，还单独为它配置了合作分会场，其重要性可见一斑。我们邀请到数世咨询首席战略分析师靳慧超、易安联创始人杨正权、美创科技首席技术官周杰、360政企安全云安全产品规划总监梅宗林四位大佬，一起探索RSAC与零信任的秘密，展望安全的未来。   
![](../Images/a153dbee2fa00be214c55e41d5910dcd.png){零信任核心观点直击抢先看}

1.  RSAC创新沙盒的**零信任**热度走向巅峰，接下来何去何从。
    
2.  策略引擎在NIST零信任架构标准中的新角色：策略引擎，策略管理器，策略执行点和策略信息点。
    
3.  展开看零信任框架的基石——**身份治理**：谁可以访问什么谁应该访问什么以及如何正确的使用这些权限。
    
4.  传统物理边界转变为动态虚拟边界下零信任如何保证**跨边界的访问和数据**安全。
    
5.  零信任在RSAC讨论的**使用场景**：企业与分支机构、员工远程接入公司内网、访问互联网资源等中的**应用**。
    
6.  零信任在中国的**落地**与相关解决方案的**实践**。
