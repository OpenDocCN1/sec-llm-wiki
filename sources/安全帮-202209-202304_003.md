# 蓝队护网应急响应流程

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkzNjQwOTc4MQ==&mid=2247487767&idx=1&sn=a24104e54b5f2637b5f4af6796b449db&chksm=c29e7ecdf5e9f7db913a6495e80904e2deffd408af31c10fc28a6cfdddca9c6591f6778e07b4&scene=126&sessionid=1681311757#rd](http://mp.weixin.qq.com/s?__biz=MzkzNjQwOTc4MQ==&mid=2247487767&idx=1&sn=a24104e54b5f2637b5f4af6796b449db&chksm=c29e7ecdf5e9f7db913a6495e80904e2deffd408af31c10fc28a6cfdddca9c6591f6778e07b4&scene=126&sessionid=1681311757#rd)

当企业发生黑客入侵、系统崩溃或其它影响业务正常运行的安全事件时，急需第一时间进行处理，使企业的网络信息系统在最短时间内恢复正常工作，进一步查找入侵来源，还原入侵事故过程，同时给出解决方案与防范措施，为企业挽回或减少经济损失。

**常见的应急响应事件分类**：

Web 入侵：网页挂马、主页篡改、Webshell

系统入侵：病毒木马、勒索软件、远控后门

网络攻击：DDOS 攻击、DNS 劫持、ARP 欺骗

**应急响应流程**

收集信息：收集客户信息和中毒主机信息，包括样本

判断类型：判断是否是安全事件，何种安全事件，勒索、挖矿、断网、DoS 等等

抑制范围：隔离使受害⾯不继续扩⼤

深入分析：日志分析、进程分析、启动项分析、样本分析方便后期溯源

清理处置：杀掉进程，删除文件，打补丁，删除异常系统服务，清除后门账号防止事件扩大，处理完毕后恢复生产

产出报告：整理并输出完整的安全事件报告

**Windows应急排查思路**

  1.账号安全排查，主要检查隐藏账户

2.  显示文件隐藏文件/扩展名
    
3.  检查启动项：是否有可疑的开机启动项
    

4.  可疑进程分析
    

5.  检查历史痕迹
    
6.  检查正在运行的服务
    
7.  打补丁
    

8.  恶意程序的发现与停止/删除：高级病毒
    

   9.后门查杀

  10.日志分析
