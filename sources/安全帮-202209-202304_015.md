# 01 GNS3模拟器

![](../Images/3b62a4aea00927f82c585d04958e1752.png)

GNS3是一款具有图形化界面可以运行在多平台（包括Windows,Linux, and MacOS等）的网络虚拟软件。

GNS3稳定高效，使用简单，能够有效模拟思科路由的绝大部分的内容，交换机的部分功能，抓包分析啥的随手都能用。

GNS3软件支持虚拟机和物理机两种模式，我们建议使用虚拟机模式，因此在安装软件前，要确保你的电脑上安装了虚拟机软件，推荐使用VMware软件。

  

# 02 eNSP模拟器

![](../Images/5f3a30be72b78887685cf70af8f0ad29.png)

eNSP是一款由华为提供的免费的、可扩展的、图形化操作的网络仿真工具平台。通过ensp可进行扩展的、图形化的操作进行网络仿真能够更好地学习华为网络技术。

eNSP主要针对网络路由器、交换机进行软件仿真，支持大型网络模拟，让用户在没有真实设备的情况下，使用模拟器也能制作网络拓扑并进行实验。

# 03 Cisco Packet Tracer模拟器

![](../Images/a536affebe3bf35fe116bd9a6820f0f1.png)

Packet Tracer是思科对应是一个功能强大的网络仿真程序，它是为网络课程的初学者提供辅助教学的实验模拟器。使用者可以在该模拟器中搭建各种网络拓扑，实现基本的网络配置。

这一模拟器支持很多设备，包括防火墙、无线等。每种设备都提供了很多种型号的设备，对于没见过真实设备的人，这个还是有一些帮助的，起码在以后的设备选型的时候可以有所准备。

  

# 04 HCL模拟器

新华三模拟器是由新华三集团推出的一款十分好用的界面图形化全真网络设备模拟软件，这款软件可以帮助网络工程相关行业的用户进行虚拟组网、配置、调试等操作。

Win10/Win7操作系统，建议安装HCL V3.0.1，使用自带virtual box 6.0.14，当前模拟器暂不支持Win10 21H1系统。

![](../Images/40944ca9240be26a1dbd96685e0c204c.png)

  

HCL集成了virtualbox，可以做模拟器与真实设备直接相连的实验。并且可以自己DIY设备，这个功能是Packet Tracer和eNSP这两个模拟器所没有的。

  

# 05 EVE模拟器

![](../Images/e19effe88ef1abf28e1202f027de2662.png)

很多时候，学网络的人用的都是上述几个模拟器，但是这几个模拟器都有各自的缺陷。

比如，华为的eNSP使用模拟设备，采用的是在Oracle VM VirtualBox上运行相关镜像，当网络拓扑搭建较大，就十分考验电脑的性能。

EVE模拟器则可以模拟很多设备：思科、Juniper、F5、aruba、思杰等。

EVE已经不仅可以模拟网络设备，也可以运行一切虚拟机。理论上，只要能将虚拟机的虚拟磁盘格式转换为qcow2都可以在EVE-NG上运行。所以，EVE-NG可以算得上是仿真虚拟环境。
