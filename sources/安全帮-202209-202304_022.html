VMware/文件/新建虚拟机


选择“典型”安装，下一步


设置虚拟机名称，安装路径，下一步


设置磁盘大小，下一步


自定义硬件





点击完成启动安装


回车继续安装，选择语言，点 continue 继续安装


选择系统安装的目标磁盘




点击 ROOT PASSWORD 设置 root 账号的密码


这里我们输入 root 作为密码


4位密码过于简单会有提示，不用管，再次点击 done


等待安装完成


点 reboot，重启完成安装



输入用户名 root，密码 root，进入系统



开启网络



vi /etc/sysconfig/network-scripts/ifcfg-ens33


按下 i 键，进入编辑状态，把 ONBOOT=no 改成 ONBOOT=yes 开启网卡


按下esc键，输入“:wq” 回车，保存退出编辑
然后执行 reboot 重启系统，使上述配置起效

至此，已完成安装。

网卡配置说明

最后附上网卡配置说明。

DEVICE=ens33                        # 网卡的设备名称
NAME=ens33                          # 网卡设备的别名
TYPE=Ethernet                        #网络类型：Ethernet以太网
BOOTPROTO=none                #引导协议：static静态、dhcp动态获取、none不指定（可能出现问题）
DEFROUTE=yes                      #启动默认路由
IPV4_FAILURE_FATAL=no    #不启用IPV4错误检测功能
IPV6INIT=yes                           #启用IPV6协议
IPV6_AUTOCONF=yes            #自动配置IPV6地址
IPV6_DEFROUTE=yes                    #启用IPV6默认路由
IPV6_FAILURE_FATAL=no            #不启用IPV6错误检测功能
UUID=sjdfga-asfd-asdf-asdf-f82b     #网卡设备的UUID唯一标识号
ONBOOT=yes                           #开机自动启动网卡
DNS=114.114.114.114               #DNS域名解析服务器的IP地址 可以多设置一个DNS1
IPADDR=192.168.1.22              #网卡的IP地址（你想要设置的固定IP，如果是dhcp可以不填写）
PREFIX=24                                #子网前缀长度
GATEWAY=192.168.1.1            #默认网关IP地址
IPV6_PEERDNS=yes
IPV6_PEERROUTES=yes
NETMASK=255.255.255.0        #子网掩码，不需要修改；

解决 VMware 桥接网络无法获取 IP 的问题

有时会遇到桥接网络下 CentOS 无法获取 IP 的问题，这是可以通过指定网络适配器来解决，具体如下。

以管理员运行 VMware，点击 编辑，虚拟网络编辑器：


把自动改成本机的网络适配器，保存即可。


然后进入 CentOS，运行 ip addr 查看 IP：
