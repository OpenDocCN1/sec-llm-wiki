# 解决 VMware 桥接网络无法获取 IP 的问题

有时会遇到桥接网络下 CentOS 无法获取 IP 的问题，这是可以通过指定网络适配器来解决，具体如下。

以管理员运行 VMware，点击 编辑，虚拟网络编辑器：

![](../Images/8b1d4878e859c8ffdf71ca6970c73dc2.png)

  

把自动改成本机的网络适配器，保存即可。

![](../Images/03d3910fe73f605558d230666c1c5e60.png)

  

然后进入 CentOS，运行 ip addr 查看 IP：

![](../Images/0b5fba811afe1c1db073b63514fcb8da.png)
