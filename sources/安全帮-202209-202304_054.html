前言

当公司服务器发生黑客入侵、系统崩溃或者其他影响了业务运行的安全事件的时候，就需要第一时间进行排查并处理，并且寻找解决方案与实施，减少损失。

以下内容为平时工作中使用到的，仅作为记录进行分享。

1. 入侵排查思路

1.1账号安全。

用户信息文件

cat /etc/passwd

root:x:0:0:root:/root:/bin/bash

用户名：密码：用户ID：组ID：用户说明：家目录：登陆之后的 shell

排查影子文件

cat /etc/shadow

root:$6$5jagQ0e8EV8YWeC9Xy/::0:99999:7:::

用户名：加密密码：密码最后一次修改日期：两次密码的修改时间间隔：密码有效期：密码修改到期到的警告天数：密码过期之后的宽限天数：账号失效时间：保留

其他信息

w 查看系统信息，用户的某一时刻的行为

[root@localhost ~]# w

14:47:59 up 96 days, 22:32, 1 user, load average: 0.00, 0.01, 0.05

USER TTY FROM LOGIN@ IDLE JCPU PCPU WHAT

root pts/1 0.0.0.0 14:36 7.00s 0.02s 0.01s w

who 当前登录用户 tty 本地登陆 pts远程登陆

[root@localhost ~]# who

root pts/1 2022-12-21 14:36

uptime 查看用户登陆了多久，多少用户，负载情况

[root@localhost ~]# uptime

14:45:50 up 96 days, 22:30, 1 user, load average: 0.00, 0.01, 0.05

1.2排查帐号信息

查看其他帐号是否存在sudo权限。

more /etc/sudoers | grep -v "^#\|^$" | grep "ALL=(ALL)"

查看是否还有其他特权用户。

awk -F: '$3==0{print $1}' /etc/passwd

1.3排查历史命令

登陆root用户

历史记录命令history

查看其他用户的历史记录命令
/home/username/.bash_history

修改历史命令行数

修改/etc/profile 增加HISTSIZE=10000

source /etc/profile即可

1.4 使用PS命令查看进程

ps -aux |grep pid

1.5 查看定时任务

crontab -l 列出用户的详细内容

重点关注以下目录中是否存在恶意脚本

more /var/spool/cron/*

more /etc/crontab

more /etc/cron.d/*

more /etc/cron.daily/*

more /etc/cron.hourly/*

more /etc/cron.monthly/*

more /etc/cron.weekly/

more /etc/anacrontab

more /var/spool/anacron/*

1.6检查临时目录下的文件

查看目录下的隐藏文件和隐藏的文件夹

利用find命令查找1天内访问过的文件

find /opt -iname "*" -atime 1 -type filename

1.7排查系统日志

日志默认放在/var/log下，查看日志配置more /etc/rsyslog.conf

/var/log/cron 记录了系统定时任务相关的日志

/var/log/cups 记录打印信息的日志

/var/log/dmesg 记录了系统在开机时内核自检的信息，也可以使用dmesg命令直接查看内核自检信息

/var/log/mailog 记录邮件信息

/var/log/message 记录系统重要信息的日志。这个日志文件中会记录Linux系统的绝大多数重要信息，如果系统出现问题时，首先要检查的就应该是这个日志文件

/var/log/btmp 记录错误登录日志，这个文件是二进制文件，不能直接vi查看，而要使用lastb命令查看

/var/log/lastlog 记录系统中所有用户最后一次登录时间的日志，这个文件是二进制文件，不能直接vi，而要使用lastlog命令查看

/var/log/wtmp 永久记录所有用户的登录、注销信息，同时记录系统的启动、重启、关机事件。同样这个文件也是一个二进制文件，不能直接vi，而需要使用last命令来查看

/var/log/utmp 记录当前已经登录的用户信息，这个文件会随着用户的登录和注销不断变化，只记录当前登录用户的信息。同样这个文件不能直接vi，而要使用w,who,users等命令来查询

/var/log/secure 记录验证和授权方面的信息，只要涉及账号和密码的程序都会记录，比如SSH登录，su切换用户，sudo授权，甚至添加用户和修改用户密码都会记录在这个日志文件中

一些简单的排查登陆小命令

1查看哪些IP地址成功登陆服务器

grep "Accepted " /var/log/secure | awk '{print $11}' | sort | uniq -c | sort -nr | more

2 哪些IP在尝试登陆服务器

grep "Failed password for root" /var/log/secure | awk '{print $11}' | sort | uniq -c | sort -nr | more
