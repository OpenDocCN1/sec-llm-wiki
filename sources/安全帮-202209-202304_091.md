# HTTP服务器利用

前提条件：管理员 且 BypassUAC

下载便携版，打开

设置中取消显示托盘图标

![](../Images/347038dea7550f3f908b4b1ffb9506db.png)![](../Images/5abb3d2ce1321d134403e3cb919d52fe.png)![](../Images/b32170227b946fdd552437ebb5ca1e4a.png)

选择应用，保存，得到配置文件

![](../Images/065f5289d0755471fcf91f4ece9e9298.png)

将便携版与配置文件上传到目标

然后安装 Client 服务

```
everything.exe 
```

![](../Images/ab8d6abf66013e067b8b6e8b47fc83e5.png)

这样就在目标机器上开启了http服务，可以搜索、下载

![](../Images/576d4d8d58400e24d22c21a846d14bc2.png)

```
shell powershell "wget 'http://127.0.0.1:25005/?search=ceshi&offset=1'| Select -ExpandProperty Content"
```

![](../Images/ead2520f8a2f6d4773a71a0bc497db2a.png)

卸载服务：

```
everything.exe 
```

优点:搜索方便、http服务

缺点:

1.需要把端口转出来，或者自己写个工具请求本地http服务去搜索，使用powershell的wget或者curl之类的也行。

2.因为安装了自启动服务，所以部分杀软或者管理软件会提示开机自启动。

# 使用ES命令行控制

PS：一定要使用1.5版本

条件：管理员权限 + bypass UAC

上传everything1.5 版本，上传配置文件，这里就不需要http服务了，只需要隐藏图标即可，上传es.exe。

后台启动：

```
shell everything64
```

搜索：

```
shell es -instance 
```

# 高级语法

## 内容搜索

内容搜索比较费时间，最好只限定某目录、可限定格式

```
shell es -instance 
```

![](../Images/1b0959f778b4757a959b63ea2afe7e1e.png)

## 横向搜索共享

使用everything1.5

在everything1.5配置文件中存在folders参数，该参数可添加UNC路径

![](../Images/2320ac1534cdc170d3cd92b0d5e156de.png)

使用该参数可添加内网的共享地址，然后everything 会在启动时自动索引已经添加的内网共享。

对映到UI中修改的配置：

![](../Images/80312187edb89c863d481e69f4df21ce.png)

添加排除文件提高效率：

![](../Images/8e0fdfe4a2373ded0d05d4c18623b851.png)

将配置文件、everything64.exe、es.exe 上传到目标服务器

使用es的命令退出当前的everything实例（如果之前有运行的话）：

```
shell es -instance 1.5a -
```

重新后台启动everything

```
shell everything64
```

注意：因为everything会自动进行SMB认证，所以需要注意一下token。

![](../Images/a4989cc624f427c67d6daff235c6bacf.png)

Everything 比较适合机器多的情况下根据关机字检索重要文件，但如果添加的目标文件夹太多，建立索引的时间也会变长。
