### **检查Kubelet（只读端口）信息暴露情况**

当kubelet 只读端口暴露时，攻击者可以从 API 中检索信息。这会暴露集群配置元素，例如 pod 名称、内部文件的位置和其他配置。这不是关键信息，但仍不应暴露在互联网上。

例如，远程攻击者可以通过访问以下 URL 来滥用它：

http://<external-IP>:10255/pods
