渗透术语：

Penetration Test : 简称Pen-test，对服务或网站渗透测试。这是一个常用术语，通常与 Bug Bounty hunting 或 Black Hat hacking 一起使用。

渗透测试：常见测试

本地网络渗透测试（识别网络、系统、主机和网络设备中的漏洞）
Web 应用程序渗透测试（搜索网站和 Web 应用程序中的漏洞，通常需要某种形式的人工审查）
移动应用程序渗透测试（通常在软件初始发布之前识别弱点）
无线网络渗透测试（易被利用的漏洞）
社会工程（黑客攻击/网络钓鱼类型的方法）
DDOS测试（分布式拒绝服务/过载服务）
