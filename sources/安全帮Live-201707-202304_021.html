在 lyncdiscover.microsoft.com 域上进行 FUZZ，发现了几个 403 禁止访问页面。
检查后得出的结论是，当我清除所有header值时，服务器对Host做出反应。
提示1：
将 HTTP 协议版本更改为 1.0。
而且我没有在 header 中设置任何值。
提示 2：
如果服务器和任何其他安全机制未以正确的方式配置，我们就不会将 Host 放在 header 中。
