介绍

序列化是将某些对象转换为可以恢复的数据格式的过程。
反序列化是从某种格式获取结构化数据，并将其重建为对象。如今用于序列化数据的最流行的数据格式是 JSON。
反序列化漏洞是一种在反序列化您发送的数据的过程中能够注入代码并在受害机器中执行的漏洞，最典型的是在使用 Node JS 的应用程序中，但在这种情况下是在 JSON 中。
