介绍  

在渗透测试过程中找到严重的漏洞可能需要数周或数月的时间，因此拥有一些可供您使用的好工具会非常有帮助。他们通过定位软件、网络应用程序、网站、硬件和基础设施中的弱点和漏洞。这里有 6个我用来寻找漏洞的好工具 →

## WebHeckScanner

该工具将一堆不同的脚本集成到一个自动化的Bash文件中。WebHeckScanner是开源存储库与各种功能的组合，它利用SQLmap、Nuclei、Nikto等。我用它找到了大量高质量的漏洞

Wfuzz

Wfuzz 是Python编写的 工具，用于暴力破解 Web 应用程序。例如目录和脚本、POST 和 GET 参数检查（用于注入）、一般模糊测试和大量其他用途。这里有几个很棒的功能 →

*   能够检查多个注入点
*   非常擅长暴力破解参数
*   自动/人为的请求延迟

*   

```

```

IronWASP

这个开源网络应用程序安全扫描器是一个很棒的工具，而且可以免费使用。对于开源工具来说，它的功能非常强大，包括出色的GUI和适用于所有技能水平的实用功能。以下是使用此工具后我最喜欢的“优点”→

*   用于自动化目的的登录序列记录
*   多种报告格式（有助于提高可读性）
*   易于使用 + 适合初学者的出色 GUI

*   

```

```

## Wapiti

Wapiti是一个命令行界面工具，可帮助漏洞猎手审核 Web 应用程序的安全性。它通过黑盒扫描来抓取 Web 应用程序，搜索任何可能注入恶意脚本的参数或代码。当 Wapiti 类似于模糊器时——它会找到一个表单列表、表单输入和URL，注入有效的payloads检查脚本漏洞。主要功能如下

*   服务器端请求伪造（SSRF）、跨站脚本（XSS）、暴力破解漏洞扫描
    
*   许多用于暴力破解网站表单和后端目录的功能
    
*   如果您知道 CLI（命令行界面）中的一些命令，则 POST、HTTP 和 GET 攻击工具具有相当简单的界面。
    

*   

```

```

## DNS-Discovery

## DNS-Discovery是适用于所有技能水平的漏洞赏金猎人的绝佳工具，尤其是因为它是开源的。该工具是一个多线程（速度更快、性能更高）的子域暴力破解器，它利用了单词列表。它将来自单词列表的字符串与域连接起来，以搜索高价值的公开子域。这是该工具的链接，以及有关子域枚举的更多信息 →

  

*

## Vulnerability Lab

列表中的下一个工具“vulnerability Lab”本身并不是一个工具，但它作为一种资源却非常强大。该网站披露了许多高价值漏洞，并创建了一个供黑客（特别是漏洞赏金猎人）使用的惊人数据库。这是一个针对各种漏洞提供研究、评估和漏洞赏金的项目。一些最有用的方面 →

*   许多不同类别的 Web 应用程序漏洞
*   初学者错误猎人的第一个很好的资源
*   了解所有流行的赏金和漏洞的有用场所
