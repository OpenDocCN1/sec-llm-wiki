## 1. **What is A****ggressor Script?**

  Aggressor Script是Cobalt Strike的内置脚本语言，可以很方便的拓展Cobalt Strike的功能，官方资料位于：https://www.cobaltstrike.com/aggressor-script/index.html  Aggressor Script是基于Sleep Script语言进行开发的。

## 2. **How to Study Sleep Script**

在进行脚本开发前先把环境准备好.1.下载sleep.jar 2.安装java环境。Sleep文件下载地址:http://sleep.dashnine.org/download.html在编译sleep语言的时候会用到这个Sleep.jar文件.

简单的Hello.sl 实例代码:

```
println("Hello World");
```

How to run Hello.sl ??????     

用java运行Hello.sl格式：

  

```
java -jar sleep.jar hello.sl
```

以上是sleep简单的实例,下面介绍一些简单语法

**Stip1 基础语法介绍:**

对于字符串 整型等直接通过 $ 定义，例如

  

```
$a = 1; $a = “lol”;
```

  

对于数组需要 @ ，例如

  

```
$a = @(1, 2, 3, "four");
```

  

**Stip2 声明方法介绍:**

声明方法用sub，例如声明一个secbang方法

*

