### **0x01 使用含有已知漏洞的组件**

### **MurphySec Code Scan**

  

这里我向大家强烈推荐一款墨菲安全团队开发的IDEA插件——**MurphySec Code Scan。**该插件让开发者在 IDE 中即可检测代码依赖的安全问题，轻松识别代码中使用了哪些存在安全缺陷的开源组件，通过准确的修复方案和一键修复功能，快速解决安全问题。

因为封装成了IDEA的插件，所以使用起来是非常友好的。首先来到插件市场，搜索**MurphySec，**下边这个就是

  

![](../Images/36bfef30c20988f9f1e58bab470edfb6.png)

  

安装完毕后，点击MurphySec->快速认证->输入令牌->认证身份->确定，配置完毕后，点击左边的开始按钮即可  

  

![](../Images/72cffd097e77e02658bed5e569e0f076.png)

  

可以看到扫描结果还是很详细的

  

![](../Images/69ec9ccd97d752e4bdf57518f400ea42.png)

  

同时也支持Web控制台查看（https://www.murphysec.com/control/project）
