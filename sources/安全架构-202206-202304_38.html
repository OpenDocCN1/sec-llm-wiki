前言


目前对企业来说对抗勒索软件的入侵还是非常重要的，大多数勒索软件受害者都没有做好应对勒索软件入侵的准备，即使向勒索者支付一定的赎金，也面临丢失关键数据情况，同时遭受诸如收入损失、客户愤怒和品牌声誉受损等业务后果。

下面罗列下降低勒索软件入侵的一些方案和安全策略。

 


系统更新


勒索软件攻击，例如臭名昭著的 2017 年 WannaCry 爆发，经常利用可以通过安装最新的操作系统和应用程序补丁、更新和安全版本来关闭的软件漏洞。

所以可以依赖 Microsoft Windows 的组织应定期查看Microsoft 安全公告，以了解 Windows 的最新安全更新，及时安装更新到系统最新的安全补丁。

 


定期备份


定期进行全映像备份是防御勒索软件攻击中保障业务和数据的重要措施。定期备份关键文件，最好同时备份到公司场所和安全的云存储，这将消除降低勒索软件攻击的影响。

企业可能会丢失备份后生成的一些数据和文件，但每个人都可以快速恢复工作而无需支付勒索的赎金。

 


安装更新防病毒软件


 

端点防病毒 (AV) 产品，它可有效防御各种常见的恶意软件攻击。企业应谨慎选择反病毒产品并启用其特征数据库保证能自动更新最新病毒库。

 


启动内置反勒索软件功能


 

鉴于许多新的勒索软件变体可以逃避 AV 防御，在企业中还应部署具有内置反勒索软件功能的现代数据保护软件，例如带有 Active Protection 的 Acronis Backup。这项创新技术使用行为启发式和机器学习来自动检测和终止勒索软件攻击；然后它会自动恢复在检测到攻击之前损坏的所有文件。

 


关闭企业电子邮件系统中漏洞


 

通过电子邮件的管理员可以为所有用户进行一些简单的配置更改，这将使潜在的勒索软件攻击更加明显——例如，默认情况下使文件扩展名（如 Adobe Reader 文档的 .pdf）可见。这将使用户更容易识别潜在的恶意，例如试图伪装成无害的 Microsoft Word 文档 (.docx) 的可执行 JavaScript 文件（文件扩展名为 .js）。考虑默认情况下对所有电子邮件附件进行全公司范围的 AV 扫描。

 


培训提高员工安全意识


 

使用从 Facebook 和 LinkedIn 等来源收集的个人信息精心制作的网络钓鱼电子邮件是一种常见的勒索软件攻击媒介。通过组织一定的培训，提高员工对来自他们不明确知道和信任的来源的电子邮件持怀疑态度。让员工意识到点击电子邮件链接和打开电子邮件附件的风险，从而降低建设企业因员工安全意识不够而让企业遭受勒索病毒的入侵。

 


分割业务网络


 

许多勒索软件变体可以从最初受感染的机器传播到网络上的其他服务器和PC电脑。通过访问控制列表、专用 VLAN 和上下文感知安全分段等技术细分的业务 LAN，使这种传播更加困难。把控网络传播而降低勒索软件对入侵的影响面。

 


管理权限把控


 

在企业中加强对业务中的管理员权限的管控，授予用户的账户或应用程序的权限级别越高，如果其凭据被泄露，危害的可能性就越大。默认情况下授予基本用户权限，并且不愿意通过用户的账户控制授予提升的应用程序权限级别。

 


保持业务最新安全功能


 

Microsoft Office 等流行的商业应用程序现在包括许多“默认拒绝”安全功能，例如，禁用 Word 或 Excel 附件中的宏执行。在全公司范围内设置这些默认值，以关闭更多勒索软件常用的攻击媒介。

 


禁用从非正常文件夹下启动程序


 

许多勒索软件变种试图从某些系统级文件夹中执行，以伪装成标准的 Windows 进程。在 Windows 安装中创建特定规则以防止文件从 AppData和LocalAppData文件夹启动程序这些目录文件夹中启动执行，以降低安全风险。
