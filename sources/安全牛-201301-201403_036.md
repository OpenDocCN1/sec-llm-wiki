# 删除管理员权限可屏蔽96%的 Windows 漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=200056697&idx=1&sn=fce108e7ea8c4944d159a08a18a6d7db&chksm=28fc2faa1f8ba6bcf91c25c61859339803fe29016538f8d385c541f2c20dafd83c68f2ce9660&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=200056697&idx=1&sn=fce108e7ea8c4944d159a08a18a6d7db&chksm=28fc2faa1f8ba6bcf91c25c61859339803fe29016538f8d385c541f2c20dafd83c68f2ce9660&scene=27#wechat_redirect)

根据权限管理软件公司Avecto日前发表的“Patch Tuesday”月度补丁报告指出，删除员工计算机上的管理员权限可以避免微软软件中已经发现的92%的严重漏洞。

 

Avecto的报告显示，删除管理员权限还可以规避Windows系统96%的高危漏洞、91%的微软Office重要漏洞以及100%的IE漏洞。

 

恶意软件一旦获取管理员权限将在本机和本地网络造成严重损失，包括随意安装新软件、更改系统设置。

 

Avecto联合创始人Paul Kenyon表示：“太让人震惊了，竟然有这么多的漏洞能够通过简单地删除管理员权限解决。管理员权限的危害很早就被提出，但是大量接受调查的企业依然不完全了解有多少系统管理员用户。缺乏可视性和可控性使得企业面临大量安全威胁。“

 

Paul最后表示，报告给出的都是针对已知漏洞的数据，但网络犯罪分子还经常利用厂商未知的漏洞，对此类攻击的防护是非常困难的，但是显然移除管理员权限也将是减少未知漏洞威胁最简单有效的做法。
