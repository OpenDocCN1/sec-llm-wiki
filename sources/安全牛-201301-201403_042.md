# 首款符合FIDO标准产品亮相，瞄准移动安全“痛点”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=200050630&idx=2&sn=367032a46060249a5fb062ce1f6a8d7d&chksm=28fc37151f8bbe03490b8b79cf1ebeffcb9bcb95ea19654d4c8934ec22b06d47335dca836d42&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=200050630&idx=2&sn=367032a46060249a5fb062ce1f6a8d7d&chksm=28fc37151f8bbe03490b8b79cf1ebeffcb9bcb95ea19654d4c8934ec22b06d47335dca836d42&scene=27#wechat_redirect)

近日FIDO联盟的动作频频，发布技术标准规范后不久，联盟核心企业Nok Nok又向外界展示了首款符合FIDO标准的产品。

 

FIDO（线上快速身份认证联盟）近日发布了FIDO快速认证标准技术规范，Nok Nok Labs公司本周也透露了基于该技术规范的首款产品——NLL S3 认证套件。

 

S3套件包括一个多因子认证服务器（MFAS）和为移动客户端准备的多因子认证客户端（MFAC）。MFAS负责实现基于FIDO免密码认证方法(基于统一认证协议)，而MFAC使端点设备能够充分利用自带的硬件的安全功能。

 

据Nok Nok首席执行官Phillip Dunkelberger介绍：企业对在移动设备上部署FIDO认证技术的兴趣远远大过台式机和笔记本，移动安全现在时企业IT经理的痛点。

 

Dunkelberger预测2014年第二、三季度市场上将会出现FIDO标准产品。移动电商和支付系统企业将有可能成为首批用户，医疗和保险业客户紧随其后。

 

FIDO目前已经拥有超过100个企业会员，包括Nok Nok Labs、Google、BlackBerry、ARM、英特尔、PayPal、Lenovo和MasterCard。微软和EMC旗下的RSA是最近加入FIDO联盟的两个重量级厂商。
