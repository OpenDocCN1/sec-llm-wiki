# 安全警报： 泄露文档显示NSA监控维基解密网站及访客

**安全牛点评：如果你认为斯诺登泄密事件已经到了该收尾的时候，那么你错了。斯诺登文档依然在持续泄露中，由于英国卫报、德国镜报等媒体掌握的斯诺登泄露的NSA秘密文档数量过于庞大，按照目前的泄露速度，媒体还可以报道四十年！**

 

近日，在查阅斯诺登泄密文档后，新闻网站Intercept爆料称NSA和英国情报机构GCHQ不但监控维基解密和海盗湾网站，还监控这些网站的访客，该监视项目代号为ANTICRISISGIRL（题图）。喜欢去这两个网站猎奇的读者要小心了，记得用Tor哟。

 

泄密文档显示GCHQ会收集上述两个网站的访客的IP地址，以及来路搜索关键词，GCHQ使用了NSA开发的威力巨大的X-Keyscore监控系统，可以从骨干网监听数据。海盗湾及其用户都在NSA的潜在打击名单上，即使用户是美国人。

 

面对NSA的重点监控，维基解密创始人朱利安阿桑奇发表声明指出：

 

维基解密强烈谴责NSA不计后果无法无天的（监控）行为。我们请求奥巴马政府委派专员调查NSA对包括维基解密在内的新闻媒体的犯罪行为。
