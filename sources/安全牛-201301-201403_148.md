# 小字报： 美联邦贸调查Facebook新隐私政策

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5Njc3NjM4MA==&appmsgid=10000611&itemidx=1&sign=0502e0f0e1fa32cefc03d7f7a33630e7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5Njc3NjM4MA==&appmsgid=10000611&itemidx=1&sign=0502e0f0e1fa32cefc03d7f7a33630e7&scene=27#wechat_redirect)

美国联邦贸易委员会已经对Facebook的新隐私政策，以确认其在两周前调整的公司政策是否侵犯了用户的隐私权。

 

8月29日，Facebook宣布对公司的隐私政策进行调整。新政策称用户在注册Facebook账户的同时就赋予了Facebook使用其个人数据的权利。而此前的政策明确规定用户有权不允许Facebook将自己的姓名和照片用于营销活动。此外，Facebook将利用人脸识别技术，把用户头像纳入面部识别数据库以提升“圈人建议”功能。

 

这一举动引来不少非议，虽然Facebook声称公司最近修改隐私政策的举动只是为了提高公司行为的透明度，但是隐私保护组织称此举也削弱了用户的隐私权。反对者认为Facebook此举违反了2011年庭审的相关判决。该判决中要求Facebook必须先获得用户首肯之后才能推翻之前的隐私策略，并且Facebook必须明确向用户解释个人数据的应用范围。

 

周三下午，联邦贸易委员会发言人彼得卡普兰(PeterKaplan)表示，在获悉Facebook修改隐私政策之后，委员会已经与Facebook取得了联系。委员会就此与Facebook进行了讨论，这也是监督Facebook执行法庭命令的常规做法的一部分。不过他并未透露双方会谈的具体内容。

 

而Facebook发言人朱迪·塞思(Jodi Seth)则在一份电子邮件声明中表示，该公司并未违反法院判决：“我们对隐私策略的更新并未给Facebook任何额外的权力来将用户的信息用于广告，新的策略反而是为了进一步阐明和解释我们现有的职能。我们非常重视这一点，对于完全遵守了和FTC之间的协议很有自信。”
