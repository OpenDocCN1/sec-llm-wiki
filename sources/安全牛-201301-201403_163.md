# 小字报： 同病相怜？黑客攻击目标由Windows转向Android

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5Njc3NjM4MA==&appmsgid=10000570&itemidx=1&sign=0708501577ee30fe1358ce4c02b91221&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5Njc3NjM4MA==&appmsgid=10000570&itemidx=1&sign=0708501577ee30fe1358ce4c02b91221&scene=27#wechat_redirect)

作为移动领域中的大佬， Android在移动市场上已占有将近80%的份额，相当于PC电脑市场上的Windows，占有绝对领导地位。但有意思的是，Android也正日益成为黑客热衷于攻击的目标，黑客们攻击Android的方法也类似于Windows恶意程序。

 

Windows 和Android恶意程序的不同在于，后者演变的速度要快得多，因为犯罪分子已从攻击PC电脑中的过程中积累了丰富的经验。

 

迄今为止，Android恶意程序开发的巅峰之作要数Backdoor.AndroidOS.Obad.a。它的功能包括打开下载文件的后门，窃取手机及其应用程序信息，向收费号码发送短信，以及通过蓝牙传播恶意程序。

 

而且，Obad木马在使用加密或软件编码隐匿技术方面也达到了新的高度。此外，它还利用了Android三个以前不为人知的漏洞。研究者称，该木马看起来更像是Windows恶意程序，而不是典型的Android程序。

 

随着其他传播方式的发展，移动恶意程序的感染率有望提高。现在，黑客通常会利用含有恶意网站链接的垃圾邮件来传播病毒，垃圾邮件的数量有望会增加。很多带有漏洞攻击工具BlackHole Exploit Kit的网站，可在用户通过Android设备访问该网站时，将恶意程序下载到他们的手机中。

 

另一个恼人的发展趋势就是设置后门的移动恶意程序。尽管大多数智能手机感染的是向付费号码发送短信的木马，但越来越多的移动恶意程序拥有命令和控制服务器的后门。
