# 小百科：无线路由安全之禁用DHCP功能

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5Njc3NjM4MA==&appmsgid=10000514&itemidx=2&sign=44d11d116c9ceb14b1dfcb1892d8837c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5Njc3NjM4MA==&appmsgid=10000514&itemidx=2&sign=44d11d116c9ceb14b1dfcb1892d8837c&scene=27#wechat_redirect)

DHCP是Dynamic Host Configuration Protocol(动态主机分配协议)缩写，主要功能就是帮助用户随机分配IP地址，省去了用户手动设置IP地址、子网掩码以及其他所需要的TCP/IP参数的麻烦。这本来是方便用户的功能，但却被很多别有用心的人利用。

 

一般的路由器DHCP功能是默认开启的，这样所有在信号范围内的无线设备都能自动分配到IP地址，这就留下了极大的安全隐患。攻击者可以通过分配的IP地址轻易得到很多你的路由器的相关信息，所以禁用DHCP功能非常必要。
