# 小字报：赛门铁克发布最新版本诺顿手机安全软件

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5Njc3NjM4MA==&appmsgid=10000450&itemidx=1&sign=02822dab3102b456f9ded410aad7c750&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5Njc3NjM4MA==&appmsgid=10000450&itemidx=1&sign=02822dab3102b456f9ded410aad7c750&scene=27#wechat_redirect)

近日，赛门铁克发布了最新版本的诺顿手机安全软件（Norton Mobile Security），致力于为安卓系统的智能手机、平板电脑以及iPhone、iPad提供更为强大而有效的保护。全新的诺顿手机安全软件重点发展保护安卓地址隐私的能力，这也是广大消费者关注度迅速增长的领域，推出了全新的强大的智能技术--诺顿手机洞察技术（Norton Mobile Insight）。全新的诺顿手机洞察技术将显示那些使用户信息处于风险的手机应用程序。全新的诺顿手机安全系统通过“尖叫”报警装置提升了iPhone、iPad的防盗能力，使用户可以快速地找到丢失的移动设备。

  

对于移动设备用户而言，管理个人信息是最主要的关注点。事实上，百分之五十七的用户选择卸载或拒绝安装应用程序以保护自己的个人信息。为了解决这一问题，除了检测安全风险，诺顿手机安全软件还会检索相关风险程序的属性特征。例如，当一款移动应用程序将输出类似联系方式、照片或通话记录等用户信息时，诺顿手机安全软件会将此程序标记并告知用户。因为用户对于他们的数据是否被收集、使用或分享并无概念，故很难有效的管理个人信息。诺顿手机安全软件能够使用户明确应用程序是应该删除还是保留，从而有效地保护个人信息。

  

“隐私问题无论对于用户还是开发者而言都是复杂且不断变化的，”赛门铁克公司高级总监兼产品经理Con Mallon如是说，“截至目前，移动程序的扫描还停留在最表面的层次，相关可操作的信息还不能有效回馈给用户。有了这个最新版本，我们可以采用动态和静态相结合的独特组合方式，为程序隐私和信息泄露提供一个前所未有的展现形式。有了这些信息，用户可以真正做到自行决定是否要保留任何一个应用程序。”

  

随着手机、平板电脑等移动设备及网络技术应用的迅猛发展，移动设备网络安全对于广大消费者也愈发重要。赛门铁克公司近日发布了一项针对“当代粉丝（Modern Fan）”的全球调研，结果显示在人们参加演唱会、体育赛事活动和节庆活动的过程中，移动设备已经占据了核心地位。但是，随着智能手机等移动设备功能的逐步扩展，相关安全威胁也不断增大。赛门铁克公司对最新版本的诺顿手机安全软件充满自信，认为其能很好地帮助人们应对安全威胁。
