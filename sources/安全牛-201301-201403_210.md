# 周末讨论回顾：如何抹除网络上的痕迹？

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5Njc3NjM4MA==&appmsgid=10000435&itemidx=2&sign=6d747e9cd45a832f29f6ccd09356433a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5Njc3NjM4MA==&appmsgid=10000435&itemidx=2&sign=6d747e9cd45a832f29f6ccd09356433a&scene=27#wechat_redirect)

 

对于上周五有关如何抹除网络痕迹的话题，其之于我们普通网民，重要性的确算得上是日益提高。我们先看一下大家对此有什么看法（篇幅所限，只能摘录部分回复）。

 

long Joe：

如果不能注销，那就进行修改，填一些假的信息就行了。

 

图森破：

微博是最好注销的，发一些作死的东西，然后就达到目的了。

 

亚明：

忘了看到谁的一句话，意思是国内网站用户的信息包括用户名密码都成了管理员的私人财产了，即便注销还一个劲的往用户邮箱里发信息诱惑再次使用。知乎上也有人回答这个问题。我觉得真要在互联网上抹掉痕太难了，不太可能。只能尽最大可能地删除所有能删除的资料，删不掉的就改成假的，网站密码也换掉，预防泄漏后被登录其他网站。最后在搜索引擎里搜索自己，把搜出来自己能删掉的都删掉……然而很多是无法抹掉的，比如你在学校的信息，依然在学校网站上，姓名、学号……

 

MichaelWang：

想要完全抹去估计是不可能的，只能尽量做到不留痕，那么就避免泄露隐私，多用代理，当然选择信誉比较好的网站。不过棱镜之后估计信誉什么的都是浮云了吧。

 

Mr.ET：

抹掉之前的信息就好像在互联网上重新做人一样，不是不可能的事情，但是你可以想象一下，确实很困难。各种各样交织的互联网上充满了信息存储的借点。传统的简单信息可以潜移默化的注销减少，但是在操作的过程中切勿引入新的关联，另外对于已存在的固有信息，比如银行的个人信息暂时通过个人的手段无法得到缓解，随着个人、企业对信息安全的重视，对数据的监管加强，慢慢的可以得到缓解。总的来说可以重新管理自我的网络身份，做好分类分级处理，新增数据不会关联泄露会是一个重点考虑点。

 

N  30：

我认为可以把这些真实的信息修改为虚假信息，这样就可以避免，然后在长期的不登陆，我想这些社交网站应该会把你的账号给注销掉。

 

正如以上朋友所描述的那样，在中国目前的网络大环境下，很难彻底删除自己在网络上的痕迹，只能尽量删除敏感信息，删不掉就改成假的。或者在一开始注册网络账号时就注意选用大众化的ID，一搜索就是海量的信息，倒是可以起到大隐隐于市的作用；注销社交账号，可以在删除或修改资料的前提下，发些类似广告、政治等敏感内容的消息，有的网站就会将之封号。当然，上面Mr.ET提出的分类分级处理网络ID的方法很不错，这不只是于此，很多涉及个人信息的方面都可以运用分类分级的处理办法。
