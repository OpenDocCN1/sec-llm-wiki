Linux惊现“毁灭级”漏洞 可被利用攻击一切连网设备

安全牛消息：Red Hat 安全团队在 Linux 中广泛使用的 Bash shell 中发现了一个“毁灭级”安全漏洞。该漏洞被称作“BashBug”或“Shellshock”，这是继“心脏滴血”漏洞之后，又一个危险级别为“毁灭级”的漏洞。安全人员表示，“心脏滴血”能够允许黑客监控用户电脑，但不会取得控制权。而Bash只需要剪切和粘贴一行代码，即可控制用户电话。

Bash是一款在很多Unix电脑中用于控制命令提示符的软件，当用户正常访问，该漏洞允许攻击者的代码像在 shell 中一样执行。而且，极为严重的是该漏洞已经在 Linux 中存在很久，所以要全部修补有漏洞的机器，几乎不可能完成。

美国应急响应机构US-CERT发出警告称，这一漏洞可能影响基于Unix的操作系统，包括Linux和Mac OS X。Red Hat 和 Fedora 已经发布了针对该漏洞的修补程序，但苹果公司尚未发布修补程序。

漏洞修复：

SCANV网站安全中心建议用户和管理员立即升级系统，更新Bash！


红帽系列linux可通过更新 bash 并重启系统来解决这个问题：

# yum update bash

或者：

# yum update bash-4.1.2-15.el6_5.1

此举只是更新了 bash 包，还需要重启系统才能生效。


Ubuntu 用户可以通过如下命令打补丁，无需重启：

apt-get update

apt-get install bash
