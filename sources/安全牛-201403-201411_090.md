# 如何在全球范围追踪一个手机用户

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=200896203&idx=1&sn=1d07ade1425f7c4ca68b14284df816d4&chksm=28e9de181f9e570ee0bf74df2d2a2e864a207e201de20737376d65a1f5ac8ff06b4ef69c92fb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=200896203&idx=1&sn=1d07ade1425f7c4ca68b14284df816d4&chksm=28e9de181f9e570ee0bf74df2d2a2e864a207e201de20737376d65a1f5ac8ff06b4ef69c92fb&scene=27#wechat_redirect)

我们生活在一个被政府和企业大规模监控的时代，随着监控技术的爆发，我们越来越担心自己的个人隐私。按照企业给执法部门和情报部门的解决方案来看，监控工具似乎只能由政府来使用。但现实非常令人失望，监控工具往往轻易的落入其他机构或个人的手中。

  

监控设备的生产商把他们的产品卖给全世界各地的政府，这些产品利用手机基站的网络收集用户信息并提交给情报部门。无论你在哪里，国内还是国外，你的精确位置或你的行踪都能够被定位，定位器就是我们放进口袋里的手机。

**7****号信令**

 

监控技术得以如此强大的原因在于目前使用的通信协议网络太容易被利用。全球大部分运营商都使用7号信令(SS7, signaling System Number 7)协议的网络，包括打电话、发短信和上网。该协议允许运营商通过手机基站收集用户的地理位置信息并彼此分享，因此无论用户身处哪个国家，都能被手机运营商找到。而监控设备厂商现在也可以访问SS7，因此他们的客户能够足不出户的得到某人的位置，误差不超过几十米，即使在偏远地区也不会超过几英里。

![](../Images/e3e6d7ecd9c558347e5e51217bb06f09.png)

SS7起源于上世纪六十年代开发的SS6，当时只有几家大型运营商控制着全球的电话流量而现在成千上万家企业使用SS7系统为几十亿部手机和其他移动设备提供服务。所有这些公司都可以访问SS7网络，并彼此之间发送查询需求，共享信息，包括那些监控生产设备的厂商，从而造成整个网络更加容易被利用。

  

在过去几年中，已经有几十个国家租用或购买了这种监控技术。而且还有一些销售SS7跟踪系统的公司向用户宣传，把他们的系统与IMSI或StingRays这种执法部门使用的移动电话监听工具匹配。

![](../Images/19da210b4805f99abae8651f31a312d9.png)

StingRays是一种常见的监听工具，可以让执行部门模拟手机基站并跟踪该基站用户的位置，有时甚至可以拦截通话和网络流量，发送虚假短信，安装恶意软件并实施精准定位。

**安全牛注：**本文的重点并不在于手机网络可以跟踪你在全世界的位置，而在于任何别有用心的个人都能做到这一点，比如黑客和网络罪犯。
