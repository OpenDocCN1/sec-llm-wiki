想在20秒钟之内绕过防火墙和程序白名单，并拿到远程桌面吗？


渗透测试人员或黑客有时在使用命令控制台时会碰到防火墙的阻止，白帽子通常到此为止，但某些人这个时候就可以把这款名为Hikit的工具包拿出来了。


Hikit可以建立新的网络接口，捕获发到合法服务器的流量。如果后门通讯在流量中被检测到，数据流就会以不同的方式处理。在硬件防火墙这个级别，通讯流量被允许通过，因为它与合法流量一样，使用相同的TCP端口。这样攻击者得以绕过硬件防火墙，而渗透测试人员则被阻挡。这就是白帽子与黑客的区别，当然这个区别必需弥补，其也正是“绕过硬件防火墙”(hwfwbypass)工具的产生理念。


拥有系统管理员权限的攻击者，可以在硬件防火墙上把后门端口设置成正常的通讯端口，比如22、80、443等。但首先攻击者必需侵入服务器，然后才能对防火墙进行设置。没有进入服务器之前，这个工具毫无用武之地。


hwfwbypass的源码已可以从网上下载，实际上它是一个网络过滤的内核驱动程序。安装此工具需要管理员权限，该工具已经带有数字签名。（关注“信息安全知识”，回复“hwfw”获得下载地址）


使用hwfwbypass的四步：


1. 把恶意软件上传到远程桌面服务器上；
2. 修改APPLocker策略以执行任意代码；
3. 提升到管理员权限；
4. 使用hwfwbypass绕过硬件防火墙。


使用hwfwbypass的好处有四点：


1. 该驱动使用Windows支持的网络过滤器，这样它的功能以后也可以正常运行
2. 它是有效签名的驱动程序
3. 任何后门通讯都可以通过这个工作实现，比如Netcat，Meterpreter TCP
4. 服务器端无需额外的工具，客户端需要有Netcat


Hwfwbypass适用于windows server 2012和windows 8，但如果在服务器与攻击者之间存在网络地址转换(NAT)，则无法使用该工具。
