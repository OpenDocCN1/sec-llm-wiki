# 【牛闻牛事】打击恶意软件是一场永无休止的战争

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=200660142&idx=1&sn=dfc5d1c3717d5e19b7bad7ab5222c785&chksm=28e5647d1f92ed6b301cc41b4778a3d69fd4748840ac6916de97b6a11bddae18563255284cc8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=200660142&idx=1&sn=dfc5d1c3717d5e19b7bad7ab5222c785&chksm=28e5647d1f92ed6b301cc41b4778a3d69fd4748840ac6916de97b6a11bddae18563255284cc8&scene=27#wechat_redirect)

*编者按：尽管全世界的企业与机构在应对恶意攻击上已经付出了繁重的努力和巨额的成本，但这场已经延续几十年的斗争依然在继续，而且看不到尽头……*

据SANS技术研究所的主管约翰·派斯克托尔估计，目前大约有5%的信息系统预算用于安全保障。网络犯罪，包括内部人员和外部窃贼的恶意攻击，给美国的企业带来年均1160万美元的成本支出，去年十月份惠普赞助Ponemon研究所做的一份安全报告中的调查结果。报告显示，安全成本支出增幅达23%，上一年这一数字为890万美元。  
  
为什么说反恶意攻击是一场没有尽头的战争，安全专家们一般从军事和生态这两种理论上解释。持军事观点的人认为漏洞防护最终不过是一场道高一尺魔高一丈的竞争，而从生态环境的观点来看，这并不是一场战争，它没有胜者和输者，它只是猎物和捕食者之间永恒的生物循环链，其意义不在于胜利，而在于平衡。  
  
内华达州亨德森市EnclaveForensics的研究主管大卫·霍尔泽同意从军事的观点来看待这场战争。“我们基本上是在兜圈子，只有在我们的防御被击败后，才去改善我们的防护。大多数软件仍然充满了漏洞，但厂商通常不会修补它，除非被公开披露。编程人员没有经过安全方面的培训，说谁代码“'写得好”，意思就是支出在“预算内”。  
  
安全顾问莱尼·泽尔茨尔选择从生态平衡的角度来解释。“攻击者利用防护者，反之亦然。这是循环的一部分。如果攻击很容易，证明攻击方的投入一定很大。如果我们挡住了100%的攻击，那我们可能在防护上支出了太多的成本。实际上这是一种平衡状态，而且这种状态会一直持续。但满足于目前的状态是危险的，因为我们必须不断付出努力以保持平衡。”  
  
为什么要不断的付出努力才能保护平衡?金融领域的发展提供一个很好的例子。趋势科技最近的一份报告指出，最近一段时期对网上银行的攻击已经达到十年来的最高水平。  
  
尽管如此，专家们一致认为防护方面的进步还是有的，虽然只是保持了平衡而已。  
  
**好的一面**  
  
好消息是“就目前所知，还没有我们无法防范的恶意软件。”反恶意软件厂商卡巴斯基实验室的研究员罗尔·绍温伯格如是说。  
  
美国海军研究生院教授及安全顾问威廉·休·穆雷表示：“我们再也看不到三，四年前那样的大规模恶意软件的传播了。”  
  
通过采访安全厂商迈克菲、AVG和卡巴斯基实验室的的分析师和高管，以下四种主要手段是得以与恶意软件抗衡的关键：

  

“**病毒特征检测起到重要作用，包括识别恶意代码。**”  
  
“**行为监控。通过采用这种技术，你可以发现恶意软件在计算机中的活动，或是确定一个可疑文件是否会响应虚拟诱饵。**”  
  
“**黑名单。这是一种机制，以列表的形式列出不良网站和文件清单，以阻止访问。**”  
  
“**白名单。其实质上是相反的黑名单，通过这种方法，只允许用户访问已知的无害的网站和文件，不在名单上的站点或和文件被拒绝访问。**”  
  
这四种手段即有人支持也有人反对，而所有质疑这篇文章的反恶意软件厂商表示，他们把这四种手段结合起来使用。  
  
其他的防御手段包括防止入侵的防火墙(Windows甚至把它做成操作系统的一部分)，还有周期性的发布补丁来应对漏洞。

有人提出这样一个疑问，厂商手中是否有更先进的手段，而不为人知?有些人觉得，反恶意软件厂商把更好的防御手段隐藏起来，不到关键时刻不会使用。

  

厂商否认这一说法。反恶意软件厂商AVGTechnologies的高管托尼·安斯库姆说“这是一场天天都在进行着的战斗，我们的秘密武器每天都在使用。”事实上，如果厂商有办法可以制止所有的病毒的话，他们可不会保留。“赛门铁克的发言人凯文·海利一语道破：“留着以后用的想法是愚蠢的，这是一个极具竞争力的优势，因为可以销售出更多的软件。”  
  
不管怎样，现在的情况是，反恶意软件厂商可以在两小时内对一个利用“零日漏洞”的恶意程序作出回应，尽管复杂的恶意软件可能需要后续跟进，海利表示。  
  
与此同时，使软件更不容易被病毒利用的工作也一直在继续。微软可信赖计算的部门主管蒂姆·瑞因斯声称，微软已经改进了开发人员使用的代码库，以去除错误和漏洞。  
　 　因此，他指出，像含有堆栈错误这样漏洞的软件，在2006年有43%被利用，但现在已经降到7%。他还引用了2011年由分析人员丹·卡明斯基等人进行的一项研究结果，研究显示微软办公软件Office2003中含有126个可利用的漏洞，但在Office2010中只有7个。  
  
多年来给用户提供安全相关的软件补丁下载这一工作，也起到了相当大的作用。莱因斯引用微软在线恶意软件删除工具的统计数据：没有受到更新服务保护的系统感染病毒的比率是有更新服务系统的5.5倍。  
  
截至到2012年12月，没有更新保护的系统，每1000台设备有12.2台被感染，而有更新服务的系统是2台。因而，全球的平均水平是每1,000台有6感染病毒或恶意软件。  
  
从另一方面来看，感染还在发生，尽管感染率似乎已达到平衡状态。  
  
**目前的两大类主要攻击形式**  
  
Verizon公司ICSA实验室及安全测试公司的首席安全研究员罗杰·汤普森表示，可以把今天最常见的感染分为两类：APT(高级持续性威胁)和AFT(另一种疯狂的木马)。  
  
新型APT样本一个月左右出现一次，其针对特定目标，由资源丰富、能力强大和足够耐心的组织所开发。汤普森表示，典型的例子是2010年的Stuxnet(震网)病毒，其目标是伊朗核研究实验室的离心机，病毒通过加快其转速以摧毁它。  
  
“每个APT都是不同的，很可怕。”汤普森说。  
  
至于AFT，自我复制的恶意软件已经不再是首选的感染途径，攻击者更愿意发动“挂马式攻击”。这种攻击的方法是，诱骗受害者访问受到感染的网站。但仍然不要对蠕虫和传统病毒掉以轻心，这些恶意软件仍然潜伏在互联网上，未受保护的计算机仍然可以在短时间内被轻易感染。

安全人员同意，新型木马的样本很容易从网上获得，只要你愿意付出精力去寻找并下载，每天都可收集到成千上万的木马样本。许多样本都是过去长期流行的木马，只是被重新编译过，成为那些木马的变种。有些恶意网站会重新编译恶意软件的文件头，打造木马的唯一性，以提高挂马攻击的效率。虽然攻击计算机的方法就那几种，但却可能有超过上千种的木马。  
  
最初的感染通常是下载其他组件的自我引导行为，可以给攻击者返回受感染主机的情况，然后攻击者可以决定如何利用受害人的机器。  
  
通常情况下，一个内部系统受到感染并被攻击者蓄意劫持，如果这个系统的所有者是家小企业，攻击者目的是窃取银行凭证。但如果受攻击者是一家大型企业，那么这种攻击很可能就是工业间谍行为了。  
  
虽然反恶意软件厂商已经采取多种方法防范恶意软件，但恶意软件的编写者也在使用各种办法来躲避查杀。例如，有的恶意软件不会在诱使病毒发作的虚拟机中触发，除非它判断目前的环境不是虚拟机。  
  
同时，攻击者已经形成了自己的经济圈，彼此有着不同的分工合作。安全顾问泽尔茨尔说：“有些人擅长编写，另一些专攻感染。还有些人善于营销，如发送垃圾邮件，或者发动分布式拒绝服务攻击，或是盗窃数据。”  
  
“你可以偷窃账户的软件，然后再雇人把账户中的钱转成现金。”穆雷补充道。  
  
**XP、安卓是新战场**  
  
许多安全专家虽然认识到攻与防是一个平衡问题，但同时他们也预见到未来新增的危险。WindowsXP由于将来不再受到更新支持而无法使用，而安卓系统的智能手机很可能是恶意软件眼中的肥肉。  
  
就WindowsVista而言，它已不再受到微软的主流支持。但微软宣布，该公司将继续发布Vista的安全更新到2017年4月。  
  
WindowsXP是2001年的发布，至今仍在广泛使用。但2014年4月后，微软将停止发布它的安全性更新，而继续发行Windows7和Windows8的安全更新。于是恶意软件的编写者会将每一个安全更新进行反向工程，以找出更新解决的漏洞何在。

  

“然后，他们将找出的漏洞用于测试XP，看是否存在同样的漏洞。如果漏洞存在，他们就会编写攻击代码以利用。因为XP永远不会再更新，因此对于恶意软件编写者来说，这些漏洞都是‘零日漏洞’。如果在些系统上运行那些远程恶意代码，反病毒厂商就很难为这些系统提供保护，情况会变得越来越糟，最终XP操作系统将无法取得人们的信任。”莱因表示。  
  
“人们应该放弃XP，开发XP的时代已经与今天大不相同。它没有缓冲策略，极其容易遭到攻击。”绍温伯格补充说。  
  
智能手机操作系统安卓，销售非常火爆，根据Gartner的统计数据，今年第三季度已经超越了苹果的IOS，因此已为黑客的主力目标。  
  
安全人员从安卓的发展上看到与早期Windows市场的发展有许多相似之处。硬件厂商为他们的产品采用第三方操作系统，没有任何一方关注安全。另外，随着Android市场的发展，电信运营商又是一个复杂的因素。  
  
“安卓不像苹果，苹果可以在一天之内把它的安全补丁更新到全世界的苹果手机上。而安卓，厂商制作的补丁必须与通讯运营商一起接受认证才能下发部署。即使手机得到安全更新也是几个月之后的事情了，而这对于笔记本电脑来说是无法接受的。”绍温伯格表示。  
  
“安卓现在的情况与几年前的Windows一样，缺乏保护。”SANS技术研究所研究部主管约翰内斯·乌尔里希补充道。  
  
**希望?**  
  
返回到生态圈的比喻。有时一个小行星的撞击会把物种灭绝，而且，事实上，操作系统的更新换代也可以短时间的让恶意软件灭绝。  
  
例如，Windows95通过安全模式让程序无法被另一个程序覆盖，灭绝了MS-DOS的恶意软件。MicrosoftOffice2000添加了需要用户许可才能运行宏的功能，从而灭绝了基于Office1995的宏病毒。2004年WindowsXP的ServicePack2，默认启动Windows防火墙则消灭了另一代的恶意软件。  
  
“但目前却看不到有可以灭绝如今木马的可能。”汤普森说。  
  
即使有这样的奇迹，攻击者还可以借助别的方法，如电子邮件、电话，或其他非技术性的攻击方法，这些方法通常被称为“社会工程”。  
  
“社会工程的成功率惊人!”黑山信息安全的网络渗透测试工程师约翰·斯特兰德如是说。  
  
他们会冒充工作人员打电话，建议用户下载感染病毒的软件。或用一些通知性的电子邮件，诱使用户点击受感染的链接，斯特兰德解释说。  
  
再有就是以软件兼容性为由，告诉用户需要禁用系统的安全防护软件。绍温伯格说：“我不认为，存在需要禁用安全保护才能保证兼容性的任何合法的软件。但是，的确有一些软件要求用户在安装过程中禁用安全防护程序，因此导致用户认为这是一种正常现象，结果被恶意软件感染。”  
  
即使对用户进行培训，以防止这种手段。但那些面带微笑拿着笔记本，戴着假徽章的“工作人员”可能会出现在前台说，他们需要检查服务器机房。而他们总是会被允许进入。  
  
除此之外，在各种恶意网站上总会有大量的企业网络的登录口令出售，因为人们会在第三方网站用使用其办公邮件和密码注册，而这些网站后来被入侵。斯德兰德补充说。  
  
**坚持**  
  
“好消息是，大多数恶意软件相对而言比较容易防御，如果你使用最新的防病毒软件，运行防火墙，按时获取安全更新和使用强密码的话，这些方法可以阻止目前流行的主要攻击形式，并可能延续好几年。”瑞因斯如是说。  
  
“我大约10年前告诉人们的防护办法，现在我还是要告诉他们。配备良好的安全软件，及时更新系统，并具备相关常识，不要点击有疑问的链接。”  
  
最后，派斯克托尔建议用公众健康(而不是军事或生态)领域与恶意软件做比喻。“我们已经学会了洗手，并把污水池与饮用水保持一定的距离。但我们仍然会得感冒，我们仍然会得流行病。但如果我们迅速做出反应，就可以减少受害者的数量。”
