# 动态：Twitter收购安全密码创业公司Mitro

小型密码安全创业公司Mitro上周四宣布，该公司已经被Twitter收购，他们的团队将加盟Twitter，帮助其改善地理定位能力。

 

总部位于纽约的Mitro由谷歌前工程师创办，他们通过官方网站宣布这一消息时并未披露财务条款。Twitter发言人拒绝对此置评。

 

Mitro的密码管理器可以与浏览器配合使用，帮助用户分享账号。该公司表示，这款产品将成为一个开源项目，而他们的团队则会转而帮助Twitter开发地理定位项目。

 

通过加强地理定位技术，Twitter可以帮助规模较小的广告主更好地定位当地消费者。Twitter 2009年曾经收购了Mixer Labs，后者的地理标签技术已经可以在用户发送的Twitter消息上添加地理标签。

 

Mitro注册时的名称是Lectorius，该公司创办于2012年，他们之前通过谷歌风投和Matrix Partners获得了120万美元种子投资
