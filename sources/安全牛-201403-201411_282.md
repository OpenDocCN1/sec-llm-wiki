# 美媒：IBM和联想交易引发美国“安全担忧”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=200496318&idx=2&sn=46deb6a1b010ae3b0092961a38e1d9be&chksm=28e3e46d1f946d7b5252934f16951fceb03fb15256ff05a56b09618a192c819f07ee14684df3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=200496318&idx=2&sn=46deb6a1b010ae3b0092961a38e1d9be&chksm=28e3e46d1f946d7b5252934f16951fceb03fb15256ff05a56b09618a192c819f07ee14684df3&scene=27#wechat_redirect)

联想和IBM表示，x86服务器是其他美国公司生产的低端技术，同时现在大部分服务器，包括IBM的服务器，都是中国生产的，包含中国的零部件。联想还表示，它的产品是可信、安全的，其发展目标也都是商业性的。

 

据彭博新闻(Bloomberg News)早前报道，为了争取更多时间，IBM和联想5月重新递交了交易申请。

 

知情人士称，两家公司主要力图打消CFIUS对服务器维护方面的担忧。他们说，在把服务器业务出售给联想后，IBM还将在较长时间内代表联想继续提供服务器的维护服务。

 

但是CFIUS担心，在IBM的服务器服务合同到期后，那么维护这一块就有可能落入联想之手，他们担心这可能导致服务器更容易被中国特工入侵。维护服务可能涉及远程更新软件、技术人员维修硬件等许多内容。

 

一位知情人士说，联想提出，对维护服务的处理办法可以仿照2005年的个人电脑业务交易。IBM当时同意在出售个人电脑业务后的五年内继续对产品提供维护服务，之后这项合同又续签了几次。

 

联想的发言人说，这项交易正在取得进展，并将在年底前达成。IBM的发言人说，两家公司都对审查过程表示支持，并期望得出正面的结果。

 

一名知情人士说，一个可能的结果是，美国政府或将停止购买IBM的x86服务器。

 

IBM负责政府项目的副总裁帕迪拉(Christopher Padilla)今年1月份时说，IBM的x86业务总规模为47亿美元，政府业务只占其中相对很小的一部分。他没有提及哪些部门使用这些服务器。

 

CFIUS的发言人说，美国财政部不对具体的CFIUS审核案例发表意见。CFIUS是受财政部领导的一个机构。

 

Dealogic的数据显示，这项拟议的收购案可能成为中国企业在美国科技业进行的最大一宗收购交易，而此时此刻，北京与华盛顿之间的紧张局势正在不断升级。近年来，美国不断批评中国，称中国涉嫌对美国企业和联邦政府的电脑实施了攻击。与此同时，中国也对美国的做法表示担忧，因为前国家安全局(National Security Agency)承包商员工斯诺登(EdwardSnowden)披露的文件显示，美国的一项计算机间谍行动曾侵入中国的许多计算机。
