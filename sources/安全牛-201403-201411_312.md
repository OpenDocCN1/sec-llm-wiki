# 世界杯官网遭受DDoS攻击下线

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=200461730&idx=1&sn=ef20101198c7a08062b2a86b12497590&chksm=28e27d711f95f467238c0bee44b1b7df68ea58473b70f826a0a1c600a6ab82d92d900df03e9f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=200461730&idx=1&sn=ef20101198c7a08062b2a86b12497590&chksm=28e27d711f95f467238c0bee44b1b7df68ea58473b70f826a0a1c600a6ab82d92d900df03e9f&scene=27#wechat_redirect)

**安全牛点评：2014巴西世界杯可能是30年代以来最令人不安的一届世界杯，除去巴西本国人民的大规模抗议外，早在世界杯开幕之前的二月份，黑客“匿名”组织就曾威胁要对世界杯赞助商发起攻击，这些黑客没有食言，在周四的世界杯开幕式之前，各种与世界杯网站相关的网站遭到了分布式DDoS攻击。**

 

据悉，世界杯官方网站已经停摆了一天多的时间，而主办州的网站也不同程度遭遇攻击。黑客团体Anomymous已经宣称对这些攻击事件负责。

 

该黑客组织已经发布了一份名册，里面有60多个已经被拿下的网站，而且这些网站截止发稿时，仍然限于瘫痪中，包括音像巨头环球音乐的巴西分站。

 

这些黑客把支持巴西政府和这届世界杯的社会名人也列为攻击目标。许多表演者，如Caetano Veloso，Mariana Ayar和Filipe Catto的个人网站都被反对FIFA的信息所替代或是瘫痪。

 

上个月，巴西外联部的内部通信系统就被黑过，这次事件可能造成了一些机密信息的泄露。

 

即便如此，Anonymous并没有对这次攻击事件声称有直接联系，该组织在YouTube上发布了一段视频替自己辩解，并同时表达了对世界杯的不满。

 

今年二月，黑客称他们正准备在世界杯期间，对FIFA及其赞助商的网站展开一系列攻击，包括DDoS攻击以及篡改网站信息和盗窃数据。

 

Anonymous发誓要继续发动网络攻击，而且在其Twitter上将主题标签定期发布更新为“#OpHackingCup and#OpWorldCup”的反世界杯标语。
