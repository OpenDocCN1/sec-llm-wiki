# WiFi热点可令iOS8变砖｜OS X漏洞并未修补成功｜iOS8.4被越狱

就在这两天，苹果接连被曝安全问题。先是1500个iOS应用存在“HTTPS-crippling”漏洞，然后是SSL漏洞可令iOS8设备崩溃，接着安全人员指出已存在严重漏洞6个月之久的OS X其补丁程序可被轻易绕过，最后是iOS8.4被越狱。

  

**WiFi热点可令iOS8变砖**

  

黑客可利用WifiGate漏洞强制iOS设备接入虚假WiFi热点。无线运营商都在iOS设备中预装了程序，自动连接到特定网络，没有任何办法可阻止手机的自动连接。之后利用iOS中的SSL漏洞，可令大部分连接到互联网的应用在试图与服务器建立安全连接时出现崩溃，甚至还会导致iOS 8设备无限重启。

  

**OS X漏洞并未修补成功**

  

去年十月份安全牛报道过的，OS X Yosemite中的“Rootpipe”漏洞可以使黑客获取最高root权限，任意安装程序，甚至格式化硬盘。在本月初苹果推出补丁更新后，安全人员竟然发现这个漏洞还可以被利用，只需“一个新颖的但非常容易的办法”，就可以令本地用户重新利用这个漏洞。  

  

**iOS8.4被越狱**

  

几天前，德国安全专家、iOS越狱开发者，绰号“树人”的Stefan Esser发布了iOS 8.4 Beta的越狱视频。“树人”表示他并没有发布iOS 8.4越狱工具的打算，演示视频是为了证明他手中有漏洞。据了解，用以越狱iOS 8.4 Beta的漏洞并不算“新”，“树人”称这个漏洞在iOS的代码下会永远存在。
