# 美国缉毒署已收集国际电话记录数十年 比NSA还要早

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=204220396&idx=2&sn=fd59e3e2d4ed892e77f6ba9403bf6e7d&chksm=2f3c973f184b1e29849534d043a2bed7570f8864f57f02f6e562e8ba685352d746847d4de34b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=204220396&idx=2&sn=fd59e3e2d4ed892e77f6ba9403bf6e7d&chksm=2f3c973f184b1e29849534d043a2bed7570f8864f57f02f6e562e8ba685352d746847d4de34b&scene=27#wechat_redirect)

外媒《今日美国》报道，美国司法部及其下属执法部门缉毒署自从1992年以来，就开始收集美国公司拨打的国外长途电话。

  

![](../Images/cbf2997e8c209ee01758fa87693b6e82.png)  

  

这是司法部与缉毒署进行的一个联合秘密计划，收集从美国拨打到国外116个与贩毒有关国家的“实际上是所有的电话”记录，目的是打击贩毒。但只是收集电话记录，并没有记录电话内容。此消息是一名缉毒署官员在联邦法庭作证时披露的，目前细节尚未公布。

  

斯诺登之前披露过，美国国家安全局以打击恐怖分子之名，从电信公司收集电话元数据。但缉毒署的这个秘密计划比国家安全局更早。

  

一些电信公司并不情愿交出如此大量的电话记录，但缉毒署手握司法部的行政传票，允许其收集与毒品调查有关的材料，电信公司只好屈服。

  

为了保持计划的秘密性，缉毒署并未使用这些信息作为呈堂证据，以发起诉讼或是申请搜索令。只是作为消息提供给执行毒品调查任务的缉毒探员。

  

那些与毒品有关的国家随着时间不断变化，但加拿大、墨西哥、中美洲及南美洲是重点。

  

该项秘密计划于2013年9月，斯诺登事件爆发之后被叫停。

  

《今日美国》引用缉毒署前任及现任官员的消息，直到现在，缉毒署每天都会给电信公司发送传票，要求与毒品交易有关的嫌疑对象的电话记录，有时一天之内要求的电话号码达上千个之多。

  

缉毒署并未立即对此消息发表评论，但一位缉毒署的发言人对《今日美国》表示，“不再从美国的服务提供商那里收集大规模的电话元数据。”
