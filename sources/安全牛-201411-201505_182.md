# Windows 10可刷脸登录

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=203710994&idx=2&sn=2d6b8fca4272f7533d7b273a6afc6665&chksm=2f34d2c118435bd7f5c3f1bdeaee06b0e6c370607b8089d33ad183218c1714d15b7035110c5a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=203710994&idx=2&sn=2d6b8fca4272f7533d7b273a6afc6665&chksm=2f34d2c118435bd7f5c3f1bdeaee06b0e6c370607b8089d33ad183218c1714d15b7035110c5a&scene=27#wechat_redirect)

Windows 10的新功能可以通过识别人脸、指纹和虹膜实现系统登录、打开软件、查看数据和访问网站，这种新功能称为Windows Hello。

  

![](../Images/4fd42574d31b41e5976b87ec050cba08.png)  

  

微软表示，面部和虹膜识别需要在系统中安装红外摄像头以区分不同的用户，甚至在各种光线条件下也可做到成功识别。Windows Hello支持像英特尔3D摄像F200这样的设备，并支持现行的指纹阅读器。

  

> “这是一个政府、国防、金融、医疗和其他有关机构都能够使用的，一个加强整体安全性的解决方案。”－－微软操作系统小组 乔·贝尔福尔

  

Windows Hello令用户无需在不同的设备间传输口令，也就是说服务器上将不再储存密码，用户再也没有记忆密码的烦恼。

  

据悉，Windows 10将于今年下半年上市。
