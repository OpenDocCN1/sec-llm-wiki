# 眼见未必为实 DARPA欲上图像篡改项目

在白宫记者协会年度晚宴上，白宫展示了一张搞笑照片，照片上，巴拉克•奥巴马总统配上他妻子的新刘海。

  

![](../Images/a808f4f2e312fae977cece4f4381a0d4.png)  

  

现在对任何一个人来说，改变一个图片都不是难事，因此这也可能是个麻烦。

  

美国国防高级研究计划局（DARPA）的调查员希望高层能成立一个项目，称为Media Forensics或者MediFor，建立一个以计算机运算为基础的平台，并通过该平台检测图像处理，以此来解决这一问题。

  

“目前所使用的司法鉴定工具缺乏稳定性，可扩展性，而且只有某些媒体的地址可以被验证。缺乏一个终端到终端的平台，去执行完整化，自动化的司法鉴定分析。虽然在商业部门有一些应用程序的图像处理检测系统，但是仅仅局限于对是否是原始资源文件 或者是否是直接从图像设备上获取做出一个判定。因此，媒体身份的验证通常需要使用各种特殊方法，而且往往是艺术多于科学。并且这种判定很大程度上依赖于他们自己的背景和经验。”

  

DARPA指出，许多图片的修改都是无伤大雅的，仅仅是为了好玩或获取艺术价值。但是有些内容却是出于不好的目的，比如一些鼓吹或误导公众的行为。对于分析师或系统而言，决定图像或视频是否要使用之前，必须要了解图像都做过什么样的处理。

  

DARPA表示，它希望可以MediFor程序可以平衡这个操作领域的现状。“通过开发自动评定图像或视频的完整性技术，目前只有利于图像处理人员。”

  

该程序将把这些技术整合在一个视觉媒体的取证平台上，对于给定的图像或视频，将自动进行检测操作，并向分析师和决策者提供具体信息，包括不同操作的表现形式，如何进行操作，以及相关重要性，以便于他们根据图像和视频的价值做出决定。

  

DARPA指出，MediFor平台也将会发现不同视觉媒体集合的交互关系，并将此作为另一种确认图像/视频真实性的手段。

  

该机构指出，MediFor程序采用了图像和视频模型，该模型完整的包括了三个重要元素：

  

数字的完整性指标：像素或图像或视频有什么不一致吗？具有像素级别的功能，可以质疑数字技术的完整性，如边缘不连续，像素模糊，或者存在重复图像区域。有这样的例子吗？有对元数据或对人造假象的建议操作吗？

  

物理完整性指标：有图像或视频是违反物理定律的吗？3D场景包含的阴影，反射，和/或运动学（视频）是否与真实情况不一致?

  

语义的完整性指标：对于数字或物理分析，或者对于分析对象相关的任何假设，有其他信息来源可以证实或反驳它们吗？使用外部知识判断时间、日期、位置是错误的，或者在一组对象内，数字与物理特征存在不一致，有这样的证据吗？在试图发现一个对象可能被重新改造时，有什么证据可以表明一个对象与它宣称的并不相符。
