# 夺旗赛选手能替代专业渗透测试人员吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=208004797&idx=2&sn=e566e30059eaee417513c4e21f2918a8&chksm=2f75566e1802df784b6088ba3fad7e5ddedee107dd05e8a4c469654e8378ba63cfcd3d863373&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=208004797&idx=2&sn=e566e30059eaee417513c4e21f2918a8&chksm=2f75566e1802df784b6088ba3fad7e5ddedee107dd05e8a4c469654e8378ba63cfcd3d863373&scene=27#wechat_redirect)

好几个在不同公司当首席信息安全官的朋友都问过我：我在评估申请内部IT安全审计员或类似职位的简历时会不会对参加过夺旗赛（CTF）的经历另眼相看。这个复杂的问题也是每次我在挑人填补我们渗透测试员空缺的时候会问自己的问题。

  

![](../Images/7b4b29fee5549f28b5f38ed17c6b9ab6.png)  

  

国际信息系统审计协会（ISACA）的《网络安全态势：2015启示》报告称：**72.33%的受访者认为今日安全专业人士最大的技术空白是理解该产业的能力**。该调查中另一个有趣的事实是，绝大多数受访者发现**只有不到25%的应聘者胜任网络安全职位**。这些数字凸显出寻求信息安全职位的人和现代产业之间的巨大差距。另一个类似的差距存在于夺旗赛和专业渗透测试之间。

  

与我还在当学生的时候不同，现在人们可以很容易地找到各种各样的夺旗赛活动，从最简单的任务到复杂逆向和加密挑战都有。然而，很多夺旗赛是由安全爱好者组织的，而他们的主要受众也只是学生或者想在不违犯法律的情况下一试自身攻击技术的新丁。即使是与不同安全大会同时举行的著名夺旗赛，很多参赛选手也是学生或刚刚开始从事第一份信息安全工作的职场新鲜人。更不幸的是，由年轻天才选手组成的杰出团队往往由于无力承担高额的差旅费和入场费而无法参赛。这也是为什么在线夺旗赛越来越流行的原因。大大小小的安全公司组织或赞助夺旗赛以获取媒体关注，顺带招募最棒的选手。让我们来看看夺旗赛经验可能会对选手的习惯、技术能力和网络安全事业产生怎样的影响吧。

  

周末的时候，我喜欢看一些有关夺旗赛的报道，尤其是那些涉及网站安全的挑战。然而，我发现它们极少有针对专业渗透测试员每天面对的现实商业案例场景的。我显然忽略了复杂加解密挑战、汽车系统破解、电话窃用、黑掉自助取款机和非安全相关挑战等夺旗赛组织者设置来吸引粉丝的项目。但即使是剩下的部分也与日常现实相去甚远。因此，夺旗赛与渗透测试的实际差距到底是什么？夺旗赛又会对现实产业有什么影响呢？

  

大部分夺旗赛的首要问题就是，它们只关注单一结果（旗）而不是全面连续的安全测试。我见过很多由夺旗赛选手施行的渗透测试，他们仅仅是利用一个漏洞来推动其他所有漏洞利用测试。呈上来的报告充斥无关紧要的信息，比如web应用程序源代码、通过暴力破解FTP密码或利用任意文件上传漏洞获取到的数据库等。同时，web服务中很简单的SQL注入漏洞在报告中甚至提都没提，因为渗透测试员觉得通过从服务器获取所有机密信息‘夺到旗’已经足够震撼到客户了。实际上，很少有客户会为这种服务付费，因为从商业的角度出发，这种内容的价值极低（如果有的话）。

  

第二个问题就是，夺旗赛大多不能提供与真实商业环境相近的技术基础设施。夺旗赛失去攻破特意留有漏洞的不安全系统，而渗透测试是检测由专业网络安全团队努力保证安全的复杂系统。夺旗赛中的思维方式和渗透测试的思考方向完全迥异。处于‘渗透测试模式’中时，你将很难解决哪怕最简单的夺旗任务，反之亦然：在夺旗赛中你通常会顺着任务创建者的思考逻辑去寻找直接或间接线索，而在渗透测试中你需要理清整套业务逻辑，拥有全局网络安全视野，还要了解你客户的安全战略。

  

接下来你可能遇到的问题是安全测试员在选择攻击方法和技术时的责任问题。在夺旗赛中，如果你意外或故意让系统崩溃而使得其他人无法继续进行比赛，会有怎样的后果呢？最坏的结果，也不过是你的团队被罚掉几分。但在渗透测试中，这种鲁莽行为可能会导致你的客户损失千百万美元。同样的问题也存在于一些引发现实中野蛮驾车行为的赛车比赛中。

  

测试范围也非常重要：安全研究咨询公司 High-Tech Bridge的几乎每个渗透测试中，我们都在测试范围和边界上有着特殊的业务需求。渗透测试是面向过程的，而夺旗赛是面向结果的。出于各种业务和操作性原因，客户通常会意识到他们IT基础设施的某些组成部分是有漏洞的，而他们还没准备好承担将系统脆弱的事实公之于众。于是，他们聘用我们来检测其中安全部分的抗攻击力，而同时对脆弱部分进行漏洞修复或迁移。对渗透测试而言，明确要测试什么和怎样测试是非常重要的，否则你将可能只会激怒你的客户。我见过几起职业夺旗玩家在渗透测试时因为习惯于将整个过程当作‘无限制’比赛而无法控制其行为的案例。尽管他们一举攻破测试系统获取了最高权限，其客户却怒到准备起诉他们攻击了不该攻击的系统。

  

Yan Borboën，普华永道瑞士合伙人，理科硕士，信息系统审计师，风险和信息系统控制师，分享了他对于夺旗的观点：“随着全球网络攻击的增多，公司企业需要聘用经过良好培训的员工。夺旗赛是人们训练和展示自身行动力的绝佳竞技舞台。

  

在普华永道，我们举办像瑞士网络风暴安全挑战赛那样的安全竞赛，因为这明显是发现和招募天才的机会。然而，技术能力只是渗透测试的一个方面，它们能应对日常攻击，但不能提供对复杂持续性攻击的防护。

  

为向客户提供真正的价值，我们宁愿推荐以情报为导引的安全测试（例如：CREST STAR），这种测试集成了威胁情报和渗透测试，可以精准复制针对包含人员、流程和技术的整个组织的针对性攻击的完整场景。”

  

因此，招聘新团队成员时，我绝对更倾向于招有经验的渗透测试员而非夺旗赛冠军。不过，在其他条件相当的情况下，有夺旗赛经验无疑是个不错的砝码。夺旗赛有助于发展并完善独立技术能力和漏洞利用技巧。夺旗赛选手还能为团队带来某些有用的见解，以及其他成员可能不会有的从另一个角度想问题的视野。

  

但即便如此，我们应该牢记：夺旗赛只是玩玩，而渗透测试是工作。别把两者搞混了。
