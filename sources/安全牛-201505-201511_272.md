# 黑客入侵新闻专线获利1亿美元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=207453949&idx=2&sn=6789596d02b7166522df1f9c5d4207ee&chksm=2f4dce2e183a473821550dec94306d42aed124b1da3f3511fb209c3e1b13ddebb8c5b0ee9747&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=207453949&idx=2&sn=6789596d02b7166522df1f9c5d4207ee&chksm=2f4dce2e183a473821550dec94306d42aed124b1da3f3511fb209c3e1b13ddebb8c5b0ee9747&scene=27#wechat_redirect)

美国证券交易委员会（SEC）对一个黑客团伙提交指控，该团伙通过入侵新闻专线服务，在企业公开营收信息之前得到消息，并据此在长达5年多的时间里获利1亿美元。

  

![](../Images/35d1d4c6cd694924edb77f4ddd6fe005.png)  

  

全球新闻专线服务机构Business Wire周二表示，正在与政府有关部门合作调查一起网络入侵事件。在该起事件中，攻击者访问了其非公开的市场动向信息平台。

SEC主席玛丽·怀特表示：“这种国际性的计划在黑客事件中是前所未有的，无论是它涉及到的交易人员还是证券的交易数目，还是它获得的巨大利益。这些黑客和交易人员被指控，他们利用盗取的非公开信息获取非法利益达1亿美元之巨。今天，我们曝光了他们的欺诈计划并冻结他们的资产。”

  

这个团伙的首领有两人，特奇诺夫和莱利曼科。二人使用网站来传送盗来的数据给交易人员，这些人员分别位于俄罗斯、乌克兰、马耳他、塞浦路斯、法国和美国的三个州，乔治亚、纽约和宾西法尼亚。

  

特奇诺夫和莱利曼科通过视频向交易人员展示非法访问信息平台获取信息的能力，以招募世界各地的交易人员加入到他们的组织。例如，2013年5月1日，黑客与交易人员预先得知某上市公司准备在新闻专线公布将其营收下调的信息，在该公司将消息发送给新闻专线10分钟之后，利用20多分钟的空档做空该上市公司的股票并卖出差价合约（CFD），从而获利51万美元。而这时，该公司的消息才公开发布，股价也随之下跌。

  

SEC执行部主管安德鲁·赛瑞斯涅表示：“这是我们所见过的最错宗复杂的网络入侵和交易人员勾结在一起的事件，涉及全球几十个机构和人员。我们使用了创新性的分析工具来发现可疑的交易模式。”

  

该案共有32人被控违反联邦反欺诈法及SEC相关条例。

  

安全牛评

此次事件并非第一起黑客利用财务信息在股票市场上获利的实例。2014年12月，火眼发布了一个对名为“FIN4”黑客组织的分析报告。该组织专门盗取C级高管的内部信息，用于在股票市场上获利。火眼发现，FIN4从2013年起就多次发动了对100多家企业的攻击，这些企业要么是上市公司，要么是为这些公司提供咨询的顾问公司，如投资银行服务机构或法律事务所。
