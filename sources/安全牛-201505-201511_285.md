# DEFCON | 谭晓生： 国外黑客自由度更大

在本次黑帽和DEFCON上，奇虎360可谓表现不俗，多人在Black Hat和DEFCON做了演讲。展现了中国黑客们的风采。会后，安全牛记者对此次带队来参加黑帽和DEFCON的奇虎360副总裁谭晓生进行了简短的专访。

  

![](../Images/46708f6479b8b573ad2e6091dfca852a.png)  

  

安全牛（安）：谭总，首先祝贺奇虎360在这次黑帽和DEFCON上的精彩表现。这次黑帽和DEFCON, 你也接触了不少国外的安全从业人员，听了不少演讲，您感觉我们中国的黑客和国外黑客对比的话，有哪些不同？

  

谭晓生（谭）：我感觉最大的不同，在于国外黑客的自由度更大，比如这次表演Hack 吉普切诺基的Charlie Miller和Chris Valasek，就完全是以个人形式来讲演的，两个人甚至都不在一个城市，就能够协同一起完成这个研究。其实在对汽车的安全研究方面，我们的团队原来是走在前面的，现在看来，他们又走到了我们的前面了。另外一个不同是，我这次遇到一些在学术机构里从事安全研究的学者，我感觉他们的研究内容和方向相当的超前，这一点我们国内的安全研究相对比较着重于短期的目标以及容易一窝蜂扎到热门领域去。

  

安：说到黑客研究的自由度，我刚才和杨卿他们的独角兽团队进行的采访，我感觉他们的自由度还是蛮大的。

  

谭：这一点上，我们高层是有共识的。我们认为，安全研究应该给他们更大的自由度，如果束缚太死了就缺乏创造力了。所以我们主要看重的是中长期，着重把人培养起来。

  

安：这一点是不是跟360高层主要以技术出身为主，对技术的理解和重视程度更高有关。

  

谭：也许有一定关系。我们在技术研发的中长期投入方面是比较坚持的。 我们觉得研究不能急功近利，不能想着研究成果就一定要立即拿来赚钱。把人才培养起来才是我们真正的目标。

  

安：好的，谢谢谭总百忙中接收我们的采访，祝你们明年带来更加精彩的演示。

  

谭：谢谢，也祝安全牛越办越好。
