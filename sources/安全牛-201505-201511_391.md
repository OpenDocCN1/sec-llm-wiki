# 扎克伯格的又一件疯狂事 利用激光搭建互联网

脸书联合创始人扎克伯格在本周二的线上问答活动中，预言了一些未来将要发生的疯狂的事情。这些事情包括：  

  

> 心灵感应技术，即人类之间的交谈通过心灵而不是嘴巴
> 
>   
> 把数据从天空传送到地球的激光束  
>   
> 
> 人工智能和虚拟现实的发展

  

周四，扎克伯格在网上贴出一些来自脸书“连接实验室”的技术证明图片。  
  

为了帮助全世界各地的人们，脸书的Internet.org计划正在测试一种通过激光搭建互联网的方法。

  

![](../Images/361bcd4b5a3ceacce2ad862ef49f9bdf.png)  
互联网的未来－－激光束技术  
  

激光束实际上是不可见的，但为了说明起见，图片经过了处理。

  

扎克伯格表示，连接实验室已经研制出一种激光束技术，能够从天空把数据传输到地面。他计划使用无人机和带有激光的卫星把互联网信号传送到世界各地。如果这个计划在未来成功实施，它将“极大的增加远距离传送数据的速度”。但激光束的工作原理，扎克伯格没有提供进一步的解释。
