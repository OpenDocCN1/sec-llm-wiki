# 安全狗宣布完成B轮融资 累计融资近5000万人民币

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=206409263&idx=2&sn=eb4fcbcf1618460d82e56aed68e5cbeb&chksm=2f5d3efc182ab7eaf518fcb0ae54fd9406179986b77fbe97bb56258cf61e43047b9e9d6a27fb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=206409263&idx=2&sn=eb4fcbcf1618460d82e56aed68e5cbeb&chksm=2f5d3efc182ab7eaf518fcb0ae54fd9406179986b77fbe97bb56258cf61e43047b9e9d6a27fb&scene=27#wechat_redirect)

近日，专注于解决服务器、云主机系统以及虚拟化应用安全问题互联网安全服务品牌安全狗宣布今年完成了B轮融资，累计融资近5000万人民币。  
  
B轮由华软投资领投，A轮投资方IDG进行跟投。IDG资本副总裁牛奎光和华软投资合伙人陈晖对安全狗的云安全服务模式均表示非常看好，他们认为，在互联网安全状况日趋严峻的当下，安全狗结合云计算架构将能够更好的为企业用户提供安全服务。

  

安全狗负责人厦门服云信息科技有限公司CEO陈奋表示，本轮融资除用于团队建设和市场推广外，将继续发力打造产品，让用户可以通过安全狗的SaaS服务模式实现在云计算环境下更多的安全运维场景。

陈奋

  
从2015年初至今，国内包括网易、陌陌、支付宝、携程在内的知名互联网企业都遭遇了较大规模网络安全事故，中小型互联网企业所遇到的网络安全问题更是不计其数。 针对当前网络安全现状，安全狗•服云提出了全新的的安全服务理念“云安全新运维”并在不久前举行的第七届中国云计算大会上正式发布。“云安全”是安全发展的主流趋势，安全狗•服云将在这一主流趋势下提供全面的安全防护功能，解决用户各种外部攻击和入侵问题，帮助用户把风险降到最低。同时，安全狗还将通过跟云计算产商进行全面合作，为用户在新的IT架构下建立更好的运维管理体系，而这正是其所提出的“新运维”。

  

与欧美国家相比，我国的云安全防护市场还处于起步阶段，属于朝阳产业，高精尖的人才缺少成为整个行业面对的问题。  

  

据介绍，安全狗主要面向网站、服务器以及基于云端的监控提供专业的云安全服务。尽管目前安全狗每日能够成功拦截千万余次的网络攻击，但在安全防护技术等方面还有很大的提升空间。
