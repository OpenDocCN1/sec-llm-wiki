# 黑客攻击雇佣价码大公开

远程木马5到10美元；  

黑客教学20至40美元；

入侵谷歌、微软或雅虎邮箱129美元；

入侵俄罗斯社交媒体账户194美元；

入侵网站盗取数据350美元；

DDoS攻击5$/小时、200$/星期、1000$/月；

有效的银行账户登录凭证最高可达数万美元……

  

戴尔安全工作室最近发布的一份俄罗斯地下黑客市场的报告，披露了诸多黑客攻击手法的雇佣价格。从软件售卖到黑客教学，再到银行卡盗窃、DDoS攻击等各种网络攻击服务，应有尽有。

  

![](../Images/f4f26855cdbab78c94f6c4be388080b3.png)  

黑客服务

  

![](../Images/4b5a6966df357da398d0c56975f60070.png)  

信用卡服务

  

除了个人邮箱以外，地下黑客市场还提供入侵企业邮箱账户的服务，价格高达500美元。有趣的是，黑客还提供客户支持，不收预付金，并承诺最快时间完成任务（依据入侵目标的复杂性），而且还保证完全的隐蔽性，“目标都不会注意到自己被黑”。

  

![](../Images/e46fc4a1e6fdcfd65edc01a5be53a518.png)  

邮箱和社交媒体账户  

  

著名恶意软件工具包“垂钓者”(Angler)售价100至135美元，而勒索软件“Crypters”大幅上涨到90至440美元。信用卡数据的价格连续三年持续增长，其中美国维萨和万事达垫底，只有7美元，二者在日本和亚洲的金卡则卖到80美元，英国和欧洲是60美元。

  

![](../Images/894647e42dd926c0ad645a878e5f6b57.png)  

工具

  

银行账户登录证书则依据账户余额售出，不同的地区售价也不同。比如美国的银行账户，在40美元（余额1000美元）至500美元（余额1.5万美元）之间，欧盟的银行账户售价400美元，澳大利亚的最高在2250（余额2.2万）至3800美元（余额6.25万）之间。

  
![](../Images/9315dd03bfe83474bde5ea42efc4667e.png)  

在线账户

  

售价最高的要属高质量的已确认无误的银行账户，一个7万至15万美元余额的账户，黑客要收余额的6%，即4200至9000美元。

  

航空公司和酒店旅馆的积分也在售卖之列，150万积分的美国航空公司账户售价450美元，大型国际酒店100万积分的账户价值200美元。

  

另一件值得关注的事情，俄罗斯地下黑客市场还出售“完整的企业档案”，价格从547美元至822美元不等。这些文档的内容包括公司的各种银行账号，登录口令、身份令牌等。
