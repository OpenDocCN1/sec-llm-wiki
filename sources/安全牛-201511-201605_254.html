全球安全行业融资收购简报(2016年1月)

13日，Web安全公司 Shape Security 宣布D轮融资2500万美元，加上2012年A轮的600万、2013年B轮的2000万和2014年C轮的4000万，目前总融资额已达9100万美元。该公司表示，此轮融资主要用于加快其产品“防尸墙”（Botwall Service）的部署，特别是在中国进一步扩展的计划。


14日消息，2015年RSA大会伊始，雷神和Websense分别出资19亿和6亿美元共同成立Raytheon|Websense，时隔九个月之后，正式成立名为Forcepoint的新公司。主营三类业务，解决内部威胁、基于云的对office 365的保护、大规模分布式下一代网络安全。




20日，FireEye宣布完成收购威胁情报公司 iSIGHT Partners，收购总额达2.75亿美元。


21日，设备安全公司 ForeScout Technologies 宣布，在新一轮融资7600万美元之后，该公司估值已达10亿美元。


21日，恶意软件防护商 Malwarebytes 宣布B轮融资5000万美元，入资方为Fidelity。这家2008年由芝加哥少年 Marcin Kleczynski 创立的公司，直到2014年才A轮融资3000万美元。


28日消息，防电话欺诈厂商 Pindrop Security 在C轮融资7500万美元，总融资额已达1.22亿。此轮融资将用于公司的快速发展以及开发新的防电话欺诈技术。
