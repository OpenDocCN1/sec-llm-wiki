# 安全绝不是“差不多就行”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=401749306&idx=1&sn=abe334493908fa9c901578745be32f67&chksm=34e285e903950cff116a846713b39da53503b0625a7c294e88252db1e1daf4f4ed55e8459337&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=401749306&idx=1&sn=abe334493908fa9c901578745be32f67&chksm=34e285e903950cff116a846713b39da53503b0625a7c294e88252db1e1daf4f4ed55e8459337&scene=27#wechat_redirect)

安全运营和事件响应是个策略性、整体性且需要缜密分析的活儿。我们都没生活在理想国，所有的运营，尤其是安全运营是非常困难的，而改进也从来都不是件容易的事。

  

![](../Images/06b3326be7cad9bbce7de063c2f8955b.png)  

  

我们知道，采取策略性、整体性、分析性的方法可以帮助机构获得极大的改善，而且几乎每家机构都还有很多可供改进的余地。但很多从事安全运营或管理的人却常常有如下几种想法：

  

> *   “我觉得80%的解决方案就够了”
>     
>       
>     
> *   “我既没时间也没资源去策略性地评估和改进我的安全程序”
>     
>       
>     
> *   “我选价格最低的方案”
>     

  

**80%解决方案**

  

80%的解决方案是可以接受的么？在展开讨论之前，可以先看看以下几个例子，它们有助于理解"80%"的真实含义：

  

*   每天4小时48分钟喝不安全的饮用水
    
      
    
*   每天断电4小时48分钟
    
      
    
*   路上飞驰的汽车中每5辆就有1辆没有刹车
    
      
    
*   每5架飞机中就有1架不进行日常安全检查
    
      
    
*   每5个说明性例子中就有1个不知所云
    

  

这种例子可以举上成千上万，放到网络安全的语境下，这些例子说明了一个道理：时间和资源限制总会存在，但如果我们一开始就瞄着80%解决方案去，那我们最终很可能倒在20%的窘境上。因此，尽管困难重重，只要涉及风险规避，我们的目标就必须是那个正确的解决方案。

  

就拿砍价做个例子吧。

  

标价5块实价3块的商品，你肯定不会一来就说“我出3块”。正常流程应该是你先从出价1块开始，跟卖家来回拉锯，最终达成合理交易价格。

  

从某种角度来说，安全运营跟砍价也没什么不同。面对风险，我们要先划分各阶段目标和优先级；我们要找到合适的人员、过程和技术来达成所有这些目标，最终恰当地解决风险。当然，妥协、挑战和挫折是避免不了的，但那并不意味着我们从一开始就奔着“差不多就行”的目标去。我们必须总是瞄着根本的需求，只要方向正确，你会惊叹于实际达成的目标。

  

**没时间弄策略**

  

我们知道，大量的工作总是让人疲于应付，要花很长时间、耗费很多精力来检查安全程序是否落实是非常困难的。但是，也不得不承认，有时候公司企业还真是花费大量时间在做一些没什么附加值的事情。这就是个恶性循环：越忙于找出为什么自己如此忙乱，就越找不到自己为何如此忙乱的原因。

  

不过，就算很难，停下来缓口气儿的时间还是非常必要的。是的，短期内可能会从日常工作中抽调出一些资源。但长期来看，如果做法正确，采取策略性、整体性、分析性的安全方法会使得这些资源的使用效率最大化，让公司企业更快更有效地改善他们的安全态势。

  

**想想总成本**

  

有经验的销售人员会知道，“我选择最低要价方案”这句话往往会成为“我选择最低前期成本方案”。实际上，考虑解决方案花费的时候，应该考虑的是总花费，而不仅仅是前期成本和每年维护费用那么简单。

  

而且，技术本身并不是一种解决方案。解决方案需要人员、过程和技术的正确组合。这三个基本元素单独采用不能解决问题。而总花费的计算方式也略复杂，有时候还具有误导性。

  

解决方案总花费包括一些有形支出，比如：

  

*   不动产（机架空间）
    
      
    
*   操作和维护解决方案的人力资源
    
      
    
*   使用解决方案的人力资源
    
      
    
*   电力
    
      
    
*   解决方案的技术成本
    
      
    
*   开发和跟进解决方案过程的人力资源
    
      
    
*   培训
    

  

列表不长，但足以让各位看官对有形支出有个概念。但无形支出又是什么意思呢？且往下看：

  

*   在现有环境中引入额外的复杂性所需的附加人员、过程和技术
    
      
    
*   筛除不良解决方案产生的噪音所需的额外人力资源
    
      
    
*   与需要预期外关注的解决方案相关的额外运营和维护费用
    
      
    
*   漏报，检测能力不足或信噪比过低导致的经济损失
    
      
    
*   补足非最优解决方案欠缺功能所需的附加解决方案
    

  

看吧，只看前期支出是有多么误导人。计算总拥有成本十分复杂，但只要算对了，对公司的益处将是巨大的。只有真正理解了总体成本，才能为公司选择一个正确的解决方案。

  

很明显，每家公司都有各自的限制，但那并不意味着我们就只能选个“差不多”的解决方案。相反，公司企业应该总是瞄着适合自己的战略目标，最能有效改进其安全态势的解决方案而去。

  

当然，做到这一点肯定不容易，但并不是说连试一试都不行。“差不多就行”的真正代价是我们所承担不起的。
