# ProPublica：暗网竟然也有自己的新闻媒体

所谓的暗网一直被认为是罪犯和毒贩的天堂，但它正在缓慢的演变成互联网隐私保护的一面镜子。如今，暗网又多了一个杰出的新成员：一个非盈利性的新闻机构ProPublica。

  

![](../Images/74e4a78e378a3b927b0619aabd2abfae.png)  

  

上周三，ProPublica宣布成为首个基于Tor网络提供“隐藏服务”的网站。ProPublica 指出，此举可以为网站阅读者提供最好的隐私保护。与只隐藏网站访问内容的SSL加密链接不同，Tor隐藏服务可以确保访问者不被窃听，哪怕窃听者是互联网服务提供商。

  

麦克·提加斯（Mike Tigas）来自 ProPublica ，也是此次发行的 Tor 版本的开发人员，他表示：“每个人都应当有决定自己留下什么元数据的权利。我们不希望其他人知道进来这里是为了读取什么。”

  

当然，有隐私需求的客户也可以通过 Tor 浏览器访问 ProPublica 的网页，达到相同的匿名效果。然而，提加斯指出，使用这种方式的读者可能会遭遇恶意出口节点。出口节点指的是帮助用户连接到目标站点的志愿代理。如果追求匿名性的用户连接到 ProPublica 的非 SSL 加密部分，恶意出口节点有可能获取用户的访问内容。即使是访问 SSL 加密的页面，出口节点也能识别出用户正在访问 ProPublica。xiangdu相对而言，访问 ProPublica 的暗网版本时就不会遇到这种问题。

  

对 ProPublica 的大多数读者而言，这听上去无疑像妄想症驱动的多此一举。提加斯去年开始考虑开发这项功能，当时，ProPublica 正在编写一份关于某国在线审查的报告，他们希望某国读者能够安全地看到这份报告。就像其它新闻网站一样，ProPublica 也使用 SecureDrop 服务器接收匿名线报，这是 Tor 的另一项匿名服务。提加斯表示，他希望这个新开发的暗网版本能够让透露线报者在访问有关文章时获得尽可能多的安全性。目前还不确定读者对这一暗网版本的看法，因为 ProPublica 还没有决定在哪里进行推广。这次发布让 ProPublica 成为了暗网上的第一家大型媒体，但并不是第一家媒体。暗网媒体 Deep Dot Web 很早之前就开始给有相关需求的读者提供匿名服务了。

  

Tor 匿名服务可以隐藏网站本身的 IP ，进而隐藏网站管理层的身份。丝路网和一些儿童色情网站都使用了这些技术。ProPublica 此举并非业内首次。2014年末，Facebook 启动了自家的 Tor 匿名服务。尽管 Facebook 仍旧可以知晓访问者的身份，但这项服务可以让用户对窃听者免疫。卫报、2014年2月才创刊的 The Intercept、纽约客等媒体都有基于暗网的匿名线报服务，有点像危机解密。许多应用也在开始使用 Tor 匿名服务，比如匿名聊天服务 Ricochet 和文件分享服务 Onionshare。

  

提加斯说，他希望匿名服务能够为其它想要保护用户隐私的媒体作出例子，也许还能提高暗网有争议的名声。“就个人而言，我希望其他人能够了解到，匿名服务并不只有非法网站才会使用。ProPublica 和 SecureDrop 这些例子能够表明，使用这些技术的人不只是罪犯。”
