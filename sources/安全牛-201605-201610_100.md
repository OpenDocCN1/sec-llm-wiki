# 惠普88亿美元并购 Micro Focus 前做了这样一些事

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651068662&idx=2&sn=e81011a52daadb82f1a756ca9bc1e537&chksm=bd14a8258a6321332874558486cfc716a3f4bc26ae632178ef945e28767e34c7ef22ba104ee8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651068662&idx=2&sn=e81011a52daadb82f1a756ca9bc1e537&chksm=bd14a8258a6321332874558486cfc716a3f4bc26ae632178ef945e28767e34c7ef22ba104ee8&scene=27#wechat_redirect)

惠普企业(HPE)更新了其ArcSight、Fortify和SecureData技术，添加了新的功能，并进行了集成整合。

  

![](../Images/7781ea470254294bc09ea8f223b9b979.png)  

  

惠普88亿美元分离其软件资产并合并 Micro Focus 的交易中，其中的一个核心元素就是一串长长的安全技术列表，包括了Fortify、ArcSight、Atalla和 Voltage Security。交易结束前，HPE仍将管理和更新其安全软件组合，并用其 HPE Protect 大会发布新的更新。

  

HPE安全市场营销副总裁钱德拉·伦根表示：“发布包括了整体产品可用性，不受分离合并消息的影响。我们依然有着全面的产品管道，对坚持路线图和践行对客户的承诺保持热情。”

  

诸多声明中包括了一项HPE源自 Voltage Security 的SecureData加密技术与Atalla的**硬件安全模块(HSM)**的集成。HPE的SecureData已经集成了其他HSM，但客户现在可以通过单一厂商实现端到端数据保护策略了。在伦根看来，通过一家厂商(HPE)提供安全软件策略和HSM，可以让公司企业更容易地配置和实施安全策略。另外，单一厂商解决方案也更易于合规，以及确保整个数据生命周期不留安全漏洞。

  

在本次集成前，客户需要与单独的HSM供应商合作以保护他们的主密钥。现在，HPE SecureData和 HPE Atalla HSM 可以无缝集成，客户就能通过加密密钥的集中配置和管理，实现更为紧密黏合的数据安全。

  

9月14号的声明中，还包括有ArcSight数据平台(ADP) 2.0 的发布。该平台提供新的事件代理功能。ArcSight是惠普在2010年以15亿美元购得，给惠普带来了安全信息和事件管理(SIEM)平台能力。新的事件代理为**任意数据源和目的地址之间提供了开放连接和互动**，规模高达每秒100万事件。该事件代理还具备帮助结构化和丰富数据的逻辑，对多用例非常有用，比如实时关联和深度分析。

  

ADP 2.0 事件代理背后的核心技术，来自于开源阿帕奇卡夫卡项目。但不仅仅是卡夫卡项目的复制品，这个开源项目只是 ADP 2.0 事件代理的组件之一。

    

Protect大会上，HPE还发布了新的 Fortify Ecosystem (Fortify生态系统)和 Fortify on Demand (FoD：按需Fortify)**持续应用监视服务**。HP在2010年收购了Fortify，并自此一直持续扩展其静态和动态代码分析功能。

  

 HPE Fortify Ecosystem 建立在开放API基础上，让开发人员可以更容易地将安全测试和监视集成进开发运维过程中。

 

而且， HPE Fortify Ecosystem 已与微软、Docker、Chef等20多个开发者平台集成了。

  

HPE还在扩展FoD软件即服务(SaaS)代码扫描平台，为这个平台添加新的持续监视功能。

  

持续应用监视服务扩展了FoD的应用环境扫描功能，可纳入安全团队不知道或没归类的应用，让这些应用可以无缝接受FoD服务的检测。
