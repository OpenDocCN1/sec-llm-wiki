# 国内首款基于云架构的万兆DLP即将在钓鱼台国宾馆发布

随着大数据、深层内容分析技术的实用化，通过大数据进行行为和内容深度分析来检测和阻止新的安全威胁已经成为业界最新的研发方向之一。  

  

![](../Images/0a657f6d74b4e15ff4df79d58fca2269.png)  

  

大数据安全解析（BDSA）和统一内容安全技术（UCS），一直都是国外企业安全解决网络威胁的“杀手锏”。虽然国内的相关厂商已经不下十家，但由于过高的技术壁垒和技术封锁，这块信息安全领域的细分市场一直被国外厂商垄断。

  

为了实现信息技术自主可控的顶层设计要求，安全牛之前报道过的北京天空卫士网络安全技术有限公司通过不懈努力，成功攻克了统一内容安全技术（UCS）的重重壁垒，率先推出了基于UCS技术和云架构的全新数据防泄漏（DLP）系列产品，堪称填补国内信息安全技术领域的一个空白。

  

据天空卫士相关人员介绍，他们的DLP产品不仅在功能上达到了国际领先水平，在性能上更是遥遥领先。如，为了满足大型企业内外网络边界超过千兆实时流量的数据资产安全检查和管理需求，天空卫士推出万兆DLP，是大型企业进行数据防泄漏部署提升ROI、降低总体成本的最佳方案。

  

另悉，天空卫士将于2016年8月25日在北京钓鱼台国宾馆举行盛大发布会。届时将会推出全球第一款基于UCS技术的万兆数据泄露防护（DLP）产品和中国第一个纯云架构的数据泄露防护（DLP）解决方案。

  

**关于DLP**

  

数据防泄漏（DLP，Data Loss Prevention）技术，以集中策略为基础，采用深层内容分析，对静态、传输中及使用中的数据进行识别、监控、保护的解决方案，确保核心数据“丢不了”。

  

DLP技术重点是内容深层分析（包括指纹技术、机器自学习、光学字符信息分析等）。一般来说传统的数据安全产品都普遍拥有成熟的加解密系统和较简单的内容判定技术，包括关键字、字典、以及正则表达，但这并不是真正的DLP。和传统的加解密技术相比，DLP能真正做到人员行为可视化、策略部署一体化、条令规范可落地、安全事件可追溯。

  

DLP的核心目的是智能地管理和保护企业内部的海量的机密及关键数据。斯诺登泄密事件以后，西方的政府和企业开始大规模部署DLP技术，以防止内部泄密和外部APT攻击。
