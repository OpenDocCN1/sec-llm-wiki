# 牛妹杂记：探班ISC安全训练营

2016中国互联网安全大会（ISC2016）终于进入了最后一天的倒计时阶段。作为亚太地区信息安全领域最专业，最具规模的年度盛会序曲，“安全训练营”备受瞩目。  

  

![](../Images/8d09590776fbe43e92f760c77415ba9a.png)  

  

今年安全牛仍作为360的合作媒体，友情支持ISC大会，开通了特价票的购票渠道及安全训练营1折票秒杀活动，火爆程度不言而喻。据购票信息来看，欲参会的小伙伴也是来自全国的四面八方，就连安全牛客服的朋友圈也常常ISC大会门票刷屏。这么火爆，这么大的影响力，ISC大会究竟有多牛？安全训练营上万的票价究竟贵在哪？牛妹带着好奇心和牛仔们的种种疑问，来到了安全训练营现场一探究竟。  
  
一大早赶到360训练营现场，发现会场内异常安静，一路没有看到学员的身影，以为自己走错了。一打听才知道，原来8:30课程开始，还不到8点学员们就都已经进教室开始准备了…早就听说安全训练营的讲师都是安全界的顶级大神，而且今年的导师阵容比前两届更加震撼，31位导师带来了14节精选课程。盘古团队、独角兽团队、长亭科技、国测团队等，与现在奥运会相呼应，我想这应该算是我们安全界的梦之队了。  

  

![](../Images/0cabe45dbc0f29c692efa9f7ca3d33ee.png)  

  

安全训练营的每节课大概都需要3-4个小时，每一个教室的学员人数不超过20人。这也是安全训练营坚持的一个理念：对学员有针对性，手把手辅导，实效性强。据业内人士透露，其实每一届的安全训练营，还有一个非常重要的目的，就是希望能从参加安全训练营的学员中招收到自己的“门徒”，能和自己心中的大神并肩作战，我想应该是很多安全爱好者的愿望吧。  
  
课程结束午餐时间，正巧遇到几位刚结束课程的学员。简单和他们聊了聊。  
  
第一位是在我们安全牛秒杀到票的学员。据他说，一直都留意安全训练营，但是由于门票超出预算，领导一直审批不下来。正巧，遇到了安全牛的秒杀活动，就召集了全公司的人一起来秒杀，终于秒杀到了两个课程，一个是《360CERT课程》，一个是《无线电攻防大揭秘课程》，特别遗憾的是没有秒杀到《攻防硬件设计与企业安全分析》，他说：“这次课程的干货确实很多，课程的前半段还是比较能听懂，后半段听着就有点吃力了，可能是因为和自己的专业不是相关的缘故，如果明年安全牛再有秒杀活动，一定还要参加”。  
  
第二位是一位来自中科院的美女研究生，刚听完《如何在渗透测试中攻无不克》课程。她说：“感觉这节课受益匪浅，老师讲的特别到位，尤其有一节课老师还在课后发给每个学员一个Hackid，觉得很有意思。而且都是我们课程中很难接触到的东西，而且老师讲的也很系统很精炼，能让我们在学习和研究中少走不少弯路。”  
  
最后还碰到了一位来自云南的初中生，为了安全训练营，他合妈妈特地坐了三个多小时的飞机从云南赶过来。而且还是买的全价票。阿姨和我说：“这个孩子一直特别喜欢搞计算机这些东西，开始我们比较反对，总觉得耽误学习。但是看他参加一些比赛还能拿到名次，觉得挺了不起的。孩子对这些真是特别喜欢，每天晚上不睡觉的鼓捣，看他这么喜欢就支持他了。”

  

![](../Images/794cb42cdee9ccd205a17f3668bbf351.png)  

  

是的，其实有很多小白帽，也许他们并不是一个专科的学生，也并非是一个安全行业的技术人员，他可能就是一个在校的初中生，一位开出租车的司机，一个卖手机的店员，一个小区的保安。他们白天在自己的学校，工作岗位努力学习工作。也许深夜他们就在自学计算机，抱着电脑找漏洞，写代码。网络安全需要这样的人，我们也需要培养这样有天赋有热情的白帽们。怎样给他们一个平台，怎样让他们实现自我的价值。我想360正在寻找他们的路上。  
  
训练营结束后，简单和长亭科技的创始人杨坤聊了聊，因为牛妹属于技术盲，开始挺纠结，不知道和这些技术大牛从何聊起，但是杨坤的一席话，打破了我的疑虑。他说：“其实安全并不复杂，安全就在我们生活中，比如家里智能的烤箱，空调，电插板，摄像头..看似很简单生活家电，但是一旦出现了漏洞，可能就会出现一场火灾，或者一个隐私的泄露等等，其实这些漏洞就是那些制造商对安全的意识淡薄。但是慢慢的国家开始越来越重视，今年315上，也说到，一个产品的安全问题也就是产品的质量问题，我们有必要去给自己维权。我们现在在做的，就是怎么让生活中的智能硬件安全起来，让那些生产商把安全重视起来。”  
  
安全训练营的一天结束了。那些在我脑子中的疑问，也一道一道的解开了。这么贵的课程有人听吗？这些安全技术离我好遥远？我可以关心雾霾，有必要关心什么智能硬件吗？ 安全训练营的票贵，因为它是这些安全导师工作几年甚至几十年的工作经验和精华，也许一堂课就可以让你豁然开朗，也许一堂课就可以让在找漏洞的道路上得到重金奖赏。安全技术其实不遥远，除非你不用手机，除非你不上网，除非你不用某宝。我们一直在关心着我们生活的环境，但是一直忘记那些隐藏在生活中的导火线，那就是网络安全环境，也许一个用户注册就可以毁灭你生活。  
  
很欣慰的，看到越来越多人都投身于网络安全中。也希望未来，我们在安全课堂在遇见的时候，你可以从讲座下走上讲台。我想这才是安全训练营的真正目的。
