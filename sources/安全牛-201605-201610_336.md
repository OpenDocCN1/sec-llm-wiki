# 移动安全身份认证厂商及产品盘点

据统计，网络犯罪每年给全球带来高达4450亿美元的经济损失，日益复杂并向不同行业渗透，全球信息安全开支2014年710亿美元，2015年达1000亿美元。

  

我国网络诈骗黑色产业链规模超过1100亿元，从业人员160万人，2015年网民因为垃圾信息、诈骗信息和个人信息泄露等原因，导致损失约 805 亿元，七成左右的网民个人身份信息和个人网上活动信息均遭到泄露。  

  

![](../Images/05d27f9bd8cc10c88fe95409d90f33bc.png)  

  

身份认证安全已成为安全市场的新引爆点。央视2016年4月份集中报道了《5分钟网上买到上千银行卡信息几乎全部正确》、《起底“电信诈骗术”之“验证码”骗局》等节目，不法分子通过地下黑色产业链，盗取用户银行卡信息，拦截用户验证码短信，进而盗取用户钱财、盗刷用户银行卡。节目收视率很高，分析深刻、严谨缜密、触目惊心！

  

这一系列事件对整个金融行业和信息安全产业带来了很大震动，波及银行、第三方支付、证券、P2P金融及互联网公司，在社会上造成了恶劣影响。

  

下面我们就一起来盘点下2016年主流的**移动安全身份认证**类产品。根据应用场景的不同，我们将按照基础安全类，统一身份管理类，大数据风控类进行独立对比。

  

从安全技术的划分上看，目前用于金融交易的主流移动安全身份认证类产品主要有三个细分领域。  

  

**一、 基础安全类**

  

安全认证类产品主要解决注册、登录、支付交易、营销活动等各个认证环节的身份欺诈问题，又可细分为设备指纹、安全沙箱、安全认证、实名检测四个细分领域。

  

**二、 统一身份管理类**

  

使用一套登录体系，通过统一、免密、安全的方式，方便进行用户身份统一管理，且用户无需记密码，灵活方便、安全可靠。

  

**三、 大数据风控类**

  

大数据风控从实现方式上可以分为两类，分别是针对设备行为的风控和针对用户行为的风控。
