# 全球网络安全解决方案的三颗超级新星

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651066800&idx=3&sn=18127699ff34d60030b509024ba12f5f&chksm=bd14a1638a6328753c8b7ca35f8c7bf253601adfce354d3baf281d9b16cab54799bd913bc768&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651066800&idx=3&sn=18127699ff34d60030b509024ba12f5f&chksm=bd14a1638a6328753c8b7ca35f8c7bf253601adfce354d3baf281d9b16cab54799bd913bc768&scene=27#wechat_redirect)

**三强争霸**

  

![](../Images/bb77ab3d3ce6a18269788efc5590b0ca.png)  

  

安全市场逐渐升温，随着**SecureWorks**、**Optiv Security **和** Trustwave **之类的公司争夺市场份额，市场内大型解决方案提供商之间的竞争氛围愈加浓烈。最近几个月，这3家公司做出了一系列并购动作，像SecureWorks本月就启动了首次公开募股(IPO)。在一份关于此次IPO的报告中，市场研究公司科技商业研究的首席分析师简·赖特，从收益、安全运营中心数量、员工等方面，分析了这几家竞争对手是怎样在市场上圈地的。

  

**总量对比**

  

![](../Images/bb371fcc5af78bc8c8a80ae1dace3b2e.png)  

  

目前，Optiv Security 是三者中最大的，2015年财报收益20亿美元左右。SecureWorks第二大，其刚提交的S-1报表显示，2016财年报告收入3.395亿美元。Trustwave当前还是属于新加坡电信有限公司(Singel)的私营公司，最近一次财务公开是在2014年，当时年收益2.16亿美元。

  

**壮大之路**  

  

![](../Images/b3084bdb5989ce7ddc68768f16690c18.png)  

  

SecureWorks最近在扩张之路上迈出了一大步，本月首次公开募股，正式进驻公开市场。2011年，通过并购，SecureWorks成为戴尔及其母公司 Denali Holding 的全资子公司。Trustwave也是一家私营公司，2015年8月被电信巨头新加坡电信有限公司收购。Optiv Security 则走了不同路线，去年夏天合并了Accuvant和 FishNet Secrity，成为独立的安全解决方案提供商势力。研究报告里，赖特将这些举动归因于在托管安全服务市场上拼杀需要大量资源的结果。

  

**托管安全服务**

  

![](../Images/a1de9acf2b3fe83d46741b288b15e5c7.png)  

  

这3家安全玩家中，Optiv Security的托管安全服务份额最大，拥有5000客户，2015年收益达3亿美元。SecureWorks紧随其后，从4200客户手中获得了2.62亿美元的收益。Trustwave的2015托管安全服务收益为2.25亿美元，客户数3000。赖特指出，在高级安全服务(如威胁发现和修复)的驱动下，托管安全服务的需求正在上升。

  

**安全运营中心数量**

  

![](../Images/d3d6bd90cd1dcdf9048df85b678a4900.png)  

  

SecureWorks在美国有3个安全运营中心(SOC)，在欧洲、中东和非洲(EMEA)有1个，亚太地区(APAC)有1个。Trustwave与之相同。 Optiv Security只在美国有3个SOC。报告指出，说到SOC数量，这3家安全解决方案提供商在HPE和IBM面前根本不够看，两大巨头随便哪家都有双倍于SecureWorks和Trustwave的SOC数量。

  

**主要合作伙伴**

  

![](../Images/29f72b9444bf5ed48b7642f3922afcd2.png)  

  

SecureWorks的主要合作品牌包括：Check Point、思科、Cylance、戴尔、飞塔、HPE、IBM、英特尔、Juniper Networks、Palo Alto Networks和趋势科技。Optiv Security 的是：Carbon Black、Check Point、F5、火眼、HPE、英特尔、Juniper Networks、Palo Alto Networks、Proofpoint、SailPoint和趋势科技。最后，Trustwave，合作伙伴有：阿卡迈、思科、飞塔、Juniper Networks和Palo Alto Networks。能够支持更多的厂商品牌可能有助于像SecureWorks这样的公司在与合作品牌少的公司（如Trustwave）竞争时占据优势。

  

**去向何方**

  

![](../Images/21fbf988f347a988bcb492328e47ac9f.png)  

  

如今SecureWorks已上市，筹资1.12亿美元，宣称将投入运营资本和其他一般企业用途，可能包括增长计划、新的解决方案和其他投资。Optiv Security 一位高管日前则宣称，在4月收购了ID和访问管理咨询公司Adavancive后，将进一步并购更多公司。还有传言说Optiv正在评估IPO可能性，或许就在2016年下半年。Trustwave在去年8月收购案之时就宣称，计划投入托管安全服务的全球性扩张。
