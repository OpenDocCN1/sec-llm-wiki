# CA计划6.14亿美元收购安全测试公司Veracode

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651070846&idx=2&sn=6e5dbbd3af879bf1199f2dfafe8b4035&chksm=bd1491ad8a6318bb14ac0e7a912e8525f493d6727a5e3a767f077faa36528102db3bfcd88bb7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651070846&idx=2&sn=6e5dbbd3af879bf1199f2dfafe8b4035&chksm=bd1491ad8a6318bb14ac0e7a912e8525f493d6727a5e3a767f077faa36528102db3bfcd88bb7&scene=27#wechat_redirect)

CA Technologies 将以6.14亿美元收购应用安全测试公司Veracode，希望以此拓展其开发和测试产品，更好地为企业和应用开发者服务。该收购案预期将于今年第二季度完成。

  

![](../Images/c64cfe9705915e3f307424062c4a451a.png)

  
Veracode的办公地点设在伯灵顿、马萨诸塞和伦敦，是一家雇员超过500人的私营跨国公司。该公司客户有大有小，约在1400家左右。Veracode提供软件即服务(SaaS)平台，专注于帮助开发者从一开始就提升所开发应用的安全性。  
  
CA总裁兼首席产品官阿依曼·萨义德在博客中说道：“将安全嵌入到软件开发生命周期，并使其成为持续投放过程中自动化的一部分，意味着开发人员可以专注码代码，不用受到人工碎片化安全方法的干扰。”  
  
采用安全应用测试，在开发过程早期发现并缓解风险，是Veracode技术的特点。CA收购Veracode的目的，就是想用该技术促进公司开发运维投资组合。Veracode预期可将CA的“迈向市场策略”推向中型企业客户，而CA也将帮助Veracode延伸全球触角，触及更大型企业客户。  
  
去年12月，CA称其签署了收购维也纳业务自动化软件公司 Automic Holding 的最终协议。开源应用性能持续测试提供商BlazeMeter，分析公司 Mobile System 7，同样在去年被CA收购。CA公司之前曾名为冠群电脑( Computer Associates )。
