# 2017 RSA 大会上最为抢眼的13款安全产品

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651070667&idx=1&sn=86e6ed58d4742876d917a9412344bf2c&chksm=bd1490188a63190ee310936242ebded9914e7368ca11782327d7b75daf8d76bc12dff2324c78&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651070667&idx=1&sn=86e6ed58d4742876d917a9412344bf2c&chksm=bd1490188a63190ee310936242ebded9914e7368ca11782327d7b75daf8d76bc12dff2324c78&scene=27#wechat_redirect)

长期以来，一年一度的RSA大会，一直是安全厂商发布和展示新产品新服务的最主要展台之一。2017年的RSA大会也不例外。2月13至17日，大批厂商云集旧金山，沿袭之前的趋势，揭开各自新产品的面纱。

  

![](../Images/31175d7628f8ad2156f40b9c2e383ac9.png)

  

如RSA的身份验证与安全数据分析工具  SecureID Access 的重大更新，Qualys公司新发布的监视终端可疑活动的攻击指标(IOC)服务，以及记录和集中跟踪文件修改的文件完整性监视(FIM)服务，以及安全评级公司SecurityScorecard发布的免费服务 Malware Grader等。

  

以上这些，仅仅是 2017 RSA 大会上发布的众多新产品中的一小部分。下面就为大家带来本次大会上全新亮相的13种安全新技术。

  

**1\. RSA发布业务驱动安全策略(Business Driven Security)**

  

![](../Images/1327719c2806a07e54dd283c77553540.png)

  

RSA，纳入戴尔技术旗下之后，用其同名大会发布了业务驱动安全策略，包括旨在为安全提供业务上下文的新 SecurID Access 技术。

  

**2\. Qualys展示IOC服务**

  

![](../Images/4c16f228e7bf2c93af61fbd494b121bb.png)

  

本次大会上，Qualys发布了许多新产品，包括监视终端活动以检测可疑行为的IOC服务，以及记录和集中追踪文件改变的新文件完整性监视(FIM)服务。

  

**3\. SecurityScorecard揭开 Malware Grader 面纱**

  

![](../Images/cab0ee4ebe233852da25fe2ff2496120.png)

  

安全评分公司SecurityScorecard在RSA大会上发布了其免费恶意软件分级服务 Malware Grader。该公司宣称，这一工具提供简单的 A – F 分级功能，标示公司预防、检测和修复恶意软件相关事件的能力。

  

**4\. CrowdStrike改善Falcon平台**

  

![](../Images/7b9dc985c9bea3c6ac8e05f35052bc10.png)

  

RSA大会上，CrowdStrike发布了其Falcon平台的新功能，其中包括帮助公司查找未受管资产的发现功能。

  

**5\. Bufferzone 5.0 发布**

  

![](../Images/a4e1096000a5eaec7a34e9283ed66381.png)

  

Bufferzone旗舰安全平台5.0版本发布，包含新的Bufferzone护照(Bufferzone Passport)功能，为公司提供限制互联网访问受保护浏览器的能力。

  

**6\. Bay Dynamics 推出应用风险技术**

  

![](../Images/756b2d300ed07e080165615f6efc7e90.png)

  

Bay Dynamics 揭开了其 Risk Fabric 新功能的面纱，帮助企业量化特定威胁和漏洞相关风险的经济价值。

  

**7\. Corero提供 100 Gbps DDoS 缓解技术**

  

![](../Images/3ed8e6b064596056265a320adea1745e.png)

  

Corero在今年的RSA大会上推出了新的DDoS技术，包括支持 100G 以太网连接的新SmartWall网络威胁防御1100(NTD1100)。

  

**8\. 云安全联盟定义安全边界**

  

![](../Images/129c34250ebb344ebf222a950458cec7.png)

  

云安全联盟(CSA)在RSA大会上宣布了数项工作，包括对保护分布式网络的安全定义边界(SDP)的新研究。另外，CSA还发布了STARWatch软件即服务(SaaS)应用，帮助公司管理和维护厂商审查及评估过程的完整性。

  

**9\. Gemalto改进加密工具组合**

  

![](../Images/cd2766361b92fcfc0add953f2dfc6819.png)

  

Gemalto展示了其 SafeNet Luna HSM 7 硬件安全模块，及其 100 Gbps SafeNet 高速加密机，帮助公司快速扩展加密性能。

  

**10\. 惠普为大数据添加安全**

  

![](../Images/17b2c9f26b456aa7d137f524c4bdea75.png)

  

惠普企业揭开Hadoop和IoT安全工具SecureData，保护敏感信息不受侵害，同时，其 ArcSight Investigate 也进入到贝塔版，帮助安全研究人员查找隐藏威胁。

  

**11\. Preempt扩展行为防火墙**

  

![](../Images/1e0eddd7047ab817cedd755b7a9974cc.png)

  

Preempt发布了新的上下文数据源，旨在提升公司行为防火墙的安全。“有了Preempt的新数据及实现集成，我们的行为防火墙就能专注于更深层次的上下文数据；这对警醒和响应今日威胁是十分关键的。”Preempt共同创始人兼CEO阿基特·桑切蒂说。

  

**12\. 赛门铁克强化云安全平台**

  

![](../Images/e38c485fbbba56c261c2ed995e57a718.png)

  

赛门铁克的云安全平台又添更强功能，包括数据丢失保护(DLP)、云恶意软件分析和 AWS Web 应用防火墙。

  

**13\. TrapX改进欺诈平台**

  

![](../Images/5a1088010a3f8134b41d770bad219351.png)

  

TrapX Security 发布了其 DeceptionGrid 6.0 平台，提供新的“陷阱”诱使攻击者以为自己攻击的是完整的操作系统。“DeceptionGrid 6.0 还能暴露攻击者的技术，让公司企业得以捕获他们的技术，收集详细的鉴证信息，用正确的工具有效对抗攻击，尽快恢复到正常运营。”TrapX首席执行官格雷格·恩里克斯在声明中说道。
