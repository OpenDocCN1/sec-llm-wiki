# 利用声波和激光笔干掉无人机

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651070322&idx=2&sn=a1f72ace1447814dd96d6bb57e1f4ce7&chksm=bd14afa18a6326b7b467fa6d6b8777a3f3e60f8d431ce20fe87a3aab8f6127935f97552d9203&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651070322&idx=2&sn=a1f72ace1447814dd96d6bb57e1f4ce7&chksm=bd14afa18a6326b7b467fa6d6b8777a3f3e60f8d431ce20fe87a3aab8f6127935f97552d9203&scene=27#wechat_redirect)

黑传感器不像黑操作系统和固件那么流行，但简单的物理黑客行动的结果，确实非常可观的。

  

Enigma 2017 大会上，韩国先进科技学院(KAIST)信息安全研究生院的金龙大教授，展示了怎样用简单的激光笔或扬声器黑掉主/被动传感器——设置到正确的频率上就行。

  

![](../Images/f63dcb386141ca0312a9dd691f6f1683.png)

金龙大(Yongdae Kim)  

  

被动传感器，比如陀螺仪和磁强计，仅仅简单地测量周围环境并回报而已。主动传感器，比如雷达和声呐，则发出信号，然后测量返回的信号。两种传感器都能被黑，而且方法颇为简单。

  

就拿现成的无人机上用的陀螺仪来说吧。这玩意儿使用惯性测量单元跟踪三个轴上的重力变化。但很多材料都有一个可令自身振动的共振频率，比如用海豚音震碎酒杯什么的，只需找出那个频率就OK。

  

金教授及其团队在他们测试过的15款商用无人机的7款中，都发现了机上搭载的陀螺仪的共振频率，包括STMicro和InvenSense公司的硬件产品。这些频率在人类发声与不可发声频段之间，但都在干扰无人机致其坠毁上被证明十分有效。

  

金教授及其助手在台上展示时，一台商用四轴无人机在正确频率的声波指向下坠落了。虽然想让攻击起效你就得离无人机近些，但若放大输出功率，更远一点的距离也不是不可以。

  

不过，金教授也承认，限制条件也是存在的。如果陀螺仪防护罩比较坚固，干扰难度就会大很多。而且，声音太大引来的麻烦会不会大过弄下无人机的好处，你还得权衡权衡。

  

在主动传感器方面，金教授展示了滴注药品的主动医疗传感器是怎么被镭射笔给黑掉的。通过用镭射光照射控制液滴流的传感器，它测量滴注进病人身体的液滴的功能就失效了。

  

在测试中，该传感器可被控制输注2倍药量，或者减少45%的药量。更糟的是，做到这一点的物理距离只与镭射光束有关，所以，只要镭射光有通路可以指向传感器，该方法就能奏效。

  

幸亏其封阻方法也十分简单——用遮蔽胶条把设备上透明部分覆盖起来就行了。但总的来说，广泛使用的传感器这么容易就能被黑，还是十分令人担心的。

  

而且，问题只会变得更糟。传感器如今越来越多地被附到各种各样的设备中。金教授的团队目前正在检查自动驾驶汽车依赖的各种传感器，希望能保证我们生命安全吧。
