# CES 2017大会上新登场的7种IoT安全产品技术

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651070202&idx=1&sn=48821ec918403addf54246b242e5ad6a&chksm=bd14ae298a63273fda5b8834609fd5d4a82a820343eeb980d131154b66485b43cb246d47be66&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651070202&idx=1&sn=48821ec918403addf54246b242e5ad6a&chksm=bd14ae298a63273fda5b8834609fd5d4a82a820343eeb980d131154b66485b43cb246d47be66&scene=27#wechat_redirect)

拉斯维加斯每年的消费电子展(CES)都是包括安全在内的最新技术大展台，2017年1月5号到8号的这次也不例外。

  

![](../Images/6ec08fc11e980c3052b88088ad2f8381.png)  

  

最近几年，CES的一大主题都与联网消费设备有关，也就是通常所说的物联网设备(IoT)。IoT设备带来了新的安全风险，而新设备新技术新软件也纷纷出台，帮助保护IoT设备不受新兴安全威胁侵扰。

  

CES 2017 上，保护家庭安全的新设备和防护联网设备安全的新技术，都得到了充分的展示。其中，Ring公司出品的安全探照灯，将联网摄像头作为动作感知户外灯具的一部分。为防护不安全IoT设备，包括赛门铁克、迈克菲和Bitdefender在内的多家厂商，都发布了保护消费网络安全的新技术。Kensington和Yubico的新安全身份验证产品，也是改善用户访问安全的一大关键主题。下列7种安全产品，就是本年度CES展上发布的安全类翘楚。

  

**1\. 诺顿 Core WiFi路由器包含自动更新**

  

![](../Images/19cafe97b88488cb4d47893613162e54.png)  

  

赛门铁克的消费安全部门在CES上发布了新Core家庭安全路由器。该外形独特的设备，实际上就上内置了保护所有相连IoT设备安全的消费级WiFi路由器。该设备能提供自动更新，并进行安全评分，帮助衡量家庭网络安全。

  

**2\. Bitdefender Box 安全装置保护消费者网络**

  

![](../Images/3ed43b7a2c44c71c139e677daca2c4be.png)  

  

Bitdefender Box 是集成消费安全装置，包含有网络访问控制、入侵防御系统(IPS)和数据保护功能。Bitdefender消费解决方案副总裁奚普里安·伊斯特雷特称：“我们的联网设备数量有了大幅增长，对黑客攻击的暴露面也是如此。如今正是重新思考我们网络安全做法的时候，免得行动太晚，教训太惨烈。”

  

**3\. Synaptics为移动设备提供多因子生物特征**

  

![](../Images/be8d705e3be06f9fdb71f38de05740e5.png)  

  

Synaptics的移动设备新多因子生物特征融合引擎在 CES 2017 亮相。该生物特征引擎可被制造商嵌入到移动设备中，结合了面部识别和指纹验证，提供安全访问功能。用户需要根据环境条件选择是用面部还是指纹识别进行身份验证。

  

**4\. Arris网关集成迈克菲安全家庭平台**

  

![](../Images/601ca3873b89019cf56a5e6f53efe763.png)  

  

家庭网关厂商Arris在展会上发布了一款新安全家庭网关设备，集成了英特尔安全的迈克菲安全家庭平台。迈克菲技术为联网设备和家长控制提供安全防护。

  

**5\. Kensington VeriMark 指纹密钥支持2个标准**

  

![](../Images/2b7a9a6b529334354327f81ecad4f5db.png)  

  

Kensington发布新VeriMark指纹密钥，为安全上网提供生物特征设备。该密钥支持 Windows Hello 和线上快速身份验证(FIDO)通用第二因子身份验证(U2F)标准。

  

**6\. Yubico推出 YubiKey 4C 安全密钥**

  

![](../Images/ff67d59cc1cbc801e48d1df850a2713b.png)  

  

Kensington不是CES上唯一一家展示新安全密钥技术的厂商，Yubico也发布了其新 YubiKey 4C ——据称是全球第一款多协议 USB-C 身份验证设备。

  

**7\. Ring Floodlight Cam 连入IoT**

  

![](../Images/316bbd537eb4f250497174395638bc9f.png)  

  

运动感知探照灯不是什么新鲜事物，但将它们连入互联网呢？CES 2017 上发布的 Ring Floodlight Cam 提供的就是这样的前景。该设备是融合1080p云摄像头，带WiFi联网功能的户外探照灯。以前的运动传感器灯无法知道是什么东西触发了摄像，现在，摄像头就能给用户展现到底镜头前发生的是什么了。
