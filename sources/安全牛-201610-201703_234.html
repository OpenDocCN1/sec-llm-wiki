360企业安全集团-网康科技

(工作地点：北京)


一、高级Linux C/C++开发工程师


职位描述：


1. 作为主要开发人员致力于开发和设计网康领先的互联网应用技术产品；

2. 应用C/C++语言和设计模式构建高性能、可扩展、稳健的产品；

3. 可独立完成完整功能模块的设计实现；

4. 主要负责ICG产品用户管理相关模块设计及开发工作；

5. 负责初级员工技术指导和培训。


任职要求：


1. 计算机科学或相关专业领域的本科及以上学历，5年以上开发经验；

2. 对Linux 系统有深入了解，精通Linux/Unix下的C/C++ 开发；

3. 精通Linux 应用系统开发,Linux 网络开发；

4. 精通shell脚本，熟悉数据库操作；

5. 精通进程间通信，多线程编程；

6. 熟悉HTTP、HTTPS者优先。


二、自动化测试工程师（上网行为管理产品线）


职位职责：


1. 自动化测试技术lead，负责产品线自动化测试改进，提升自动化本身效率和覆盖率；

2. 负责持续集成测试改进，保证项目中自动化测试执行准确高效；

3. 负责测试团队内自动化技术培训，提升组员自动化测试开发技能；


任职要求：


1. 计算机、通信、电子工程等相关专业毕业，本科毕业3年以上，硕士毕业2年以上相关工作经验；

2. 2年以上自动化测试、自动化框架开发维护经验，精通shell、tcl、python等语言脚本编写；

3. 熟悉web自动化测试，有网络设备产品工作经验，熟悉Linux系统及网络的管理配置；

4. 有较强的逻辑分析能力和学习能力，具备较强的总结能力 ；

5. 热爱软件测试工作，可以胜任重复性工作，工作细致认真，有耐心 ；

6. 有独立工作的能力，同时具有团队合作的精神，有较强的责任感和进取精神。


三、高级开发工程师（应用内容引擎）


工作职责：


1. 致力于设计并开发领先的互联网应用安全网关产品；

2. 设计并维护的内容安全引擎架构，提升其性能、稳定性和可扩展性；

3. 负责初级员工技术指导和培训。


任职要求：


1. 计算机科学或相关专业领域的本科及以上学历，本科4年以上工作经验，硕士学历2年以上开发工作经验；

2. 具有丰富的Linux环境下C或C++编程经验，熟悉多进程多线程和高性能编程模型，并有相关架构的开发经验；

3. 熟悉TCP/IP等网络协议，掌握常见的HTTP、SMTP、FTP等应用层协议以及主流的互联网应用协议，比如：webmail；

4. 有AV、DLP或审计类引擎开发经验；

5. 具有很好的团队协作能力与沟通协调能力；

6. 对工作富有激情，对技术执着，追求卓越品质，能够适应高强度工作。


四、测试工程师（上网行为管理产品线）


岗位职责：


1. 根据产品功能需求，设计并执行测试用例，快速发现产品问题；

2. 反馈、跟踪产品bug并及时验证；

3. 根据测试过程和结果，给出测试结果评估，输出测试报告及其他相关文档；

4. 根据测试用例，编写对应的自动化脚本，执行自动化测试用例并分析。


任职要求：


1. 计算机及相关专业本科以上学历；

2. 熟悉Linux，能熟练使用Linux的常用命令；

3. 熟悉测试理论，计算机网络与数据库知识；

4. 工作细心、责任感强，良好的沟通表达能力和团队协作精神；

5. 熟悉网络安全领域知识、python或tcl语言者优先；

6. 有自动化测试经验者优先。


五、数据分析师


岗位职责：


负责cloud产品 数据分析业务，包括数据提取、业务建模、数据回测验证等。


任职要求：


1. 理科背景，数学/统计学相关的专业；

2. 对数据敏感，思维严谨，良好的沟通及表达能力、逻辑分析能力和数据呈现能力；

3. 有python编程经验尤佳。


六、PHP开发工程师


岗位职责：


1. 参与营销云平台网站的产品设计、接触到产品由设计到研发的全过程；

2. 侧重整体页面结构的构建、样式展现层的优化；

3. 负责界面在主流浏览器中的兼容性调整以及性能优化。


任职要求：


1. 本科及以上学历，计算机相关专业，3年以上web网站相关开发经验；

2. 熟练掌握LAMP架构下的网站编程，熟练掌握PHP、JS、HTML等开发技术；

3. 具备前端优化、数据库开发能力者优先，熟练掌握CSS和浏览器兼容问题优先；

4. 良好的代码规范，强烈的进取心，团队合作意识；

5. 有页面制作能力的可以加分。


七、测试支持工程师（下一代防火墙产品线）


岗位职责：


1. 响应前端故障支持，解决用户问题；

2. 整理用户问题，转化为产品改进点；

3. 调研友商设备，给出功能改进建议和报告；

4. 问题补丁或定制版本测试。


任职要求：


1. 熟悉市场主流防火墙产品，能够了解基本功能的实现原理；

2. 具有较强的解决问题的能力，能独立分析网络故障，并找出问题原因，提供解决方案；

3. 熟悉网络知识，快速配置Cisco、华为等主流设备，理解网络二、三层转发原理，例如：ip/mac学习机制、vlan/trunk/stp的工作原理、ospf/rip的工作机制；

4. 具备较强的责任心，能承受一定压力。


八、性能测试工程师（下一代防火墙产品线）


岗位职责：


1. 根据防火墙的功能定义和设计文档，编写性能测试用例，进行性能测试；

2. 深度掌握防火墙关键系统模块之间的相互关系和影响，能进行针对性测试设计和执行；

3. 根据测试过程给出测试结果评估，输出性能测试报告。


任职要求：


1. 熟悉解防火墙等网关类产品的使用场景；

2. 理解交换、路由的原理，以及数据包转发机制；

3. 掌握Linux，能熟练使用Linux的常用命令，包括命令的常用参数使用；

4. 掌握自动化测试方法，使用过tcl或python；

5. 掌握包速率、吞吐等标准指标，能熟练使用BPS，ixia测试仪。


九、功能测试工程师（下一代防火墙产品线）


岗位职责：


1. 根据防火墙的功能定义和设计文档，编写功能测试用例，进行功能测试；

2. 深度掌握防火墙关键功能模块之间的相互关系和影响，能进行针对性测试设计和执行；

3. 根据测试过程给出测试结果评估，输出测试报告。


任职要求：


1. 统招全日制本科及以上学历，5年以上相关工作经验；

2. 熟悉解防火墙等网关类产品的使用场景；

3. 理解交换、路由的原理，以及数据包转发机制；

4. 掌握Linux，能熟练使用Linux的常用命令，包括命令的常用参数使用；

5. 掌握自动化测试方法，使用过tcl或python。
