# 旧金山市政交通局被勒索软件攻击 导致乘客免费乘车

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651069523&idx=2&sn=16a73eabab258528ccf41577dd9819e7&chksm=bd14ac808a63259660091fe6c66a738292439ddab762e66a18e9f3ef622e6ae1b118ad073042&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651069523&idx=2&sn=16a73eabab258528ccf41577dd9819e7&chksm=bd14ac808a63259660091fe6c66a738292439ddab762e66a18e9f3ef622e6ae1b118ad073042&scene=27#wechat_redirect)

收费终端的屏幕上显示：“你们被黑了，所有的数据已被加密。”

  

![](../Images/87860dcc7875b285db94c4a4c38023c8.png)  
  

本周25日到26日，旧金山的乘客可以免费搭乘城市轻轨，因为该市市政交通系统的收费终端系统被勒索软件“搞定”，攻击者勒索100比特币，约价值7.3万美元的赎金。黑客声称控制了8656收费终端中的2112台。

  

被黑之后，为了正常出行，旧金山市政交通局(MUNI)在25日26日两天把闸机打开，允许乘客免费乘车。MUNI的交通系统包括轻轨、城市大巴和该城市著名的电缆车。

  

勒索软件这两年明显呈上升趋势，但为之付费的受害者并不多。今年8月份 Check Point 的一份报告显示，只有0.3%的受害者交付了赎金。

  

昨天（28号）MUNI的交通系统已恢复正常，但目前并不清楚MUNI官方是支付了赎金还是通过备份将系统恢复。但后者存在被勒索软件再次感染的风险。
