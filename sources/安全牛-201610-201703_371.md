# 安全专家呼吁希拉里要求重新计票

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651069491&idx=4&sn=eb7b32abbca84535f0b28859187dd994&chksm=bd14ace08a6325f61d76f1dc760a4f6a78423d610c3c6163f78e46be1b623ba5d19575dd5b0c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651069491&idx=4&sn=eb7b32abbca84535f0b28859187dd994&chksm=bd14ace08a6325f61d76f1dc760a4f6a78423d610c3c6163f78e46be1b623ba5d19575dd5b0c&scene=27#wechat_redirect)

电子投票机不过是我们周围具有严重漏洞的产品之一，3个摇摆州的投票结果应被复核，且新数据可能颠覆竞选结果。一组投票安全专家和选举律师这么告诉希拉里。

  

![](../Images/101003a6177e0fabeda0d92c9bd4fd74.png)  

  

宾夕法尼亚、威斯康辛和密歇根州的初始计票显示希拉里以1.2%或更小的差距落败，但该小组告诉希拉里的竞选团队：投票结果明显存疑。

  

截至目前，该小组尚未抛出投票违规的切实证据，但正计划发布一份报告。一篇新闻报道指出，特朗普在威斯康辛州的险胜，在使用电子投票机的郡和使用纸质选票的郡存在巨大差别。不过，该小组尚未证实该问题。

  

密歇根州使用纸质选票，威斯康辛和宾夕法尼亚州则是电子和纸质都用，虽然投票安全专家长期以来都在批评电子投票机的安全堪忧。

  

如果重新计票发现希拉里在这3个州都胜出，那她就将在总统选举团(由各州选举人选出的538名选举人组成的选举团履行选举总统和副总统职责)中收获46票，并赢下总统宝座。这情形出现的可能很小，但对俄罗斯黑客活动和选举前不准确投票的担忧，会引发对结果的质疑——密歇根大学计算机科学教授阿列克斯·海德尔曼说。

  

海德尔曼就是呼吁希拉里竞选团队要求重新计票的小组成员之一，23号在Medium.com上发文称：“我觉得最有可能的解释就是，投票出了系统性问题，而不是竞选被黑了。但查清是否有黑客攻击修改结果的唯一方式，就是深入调查可用的物理证据——纸质选票和关键州的投票机。”

  

要求重新计票的截止日期，在威斯康辛是25号，宾夕法尼亚是28号，密歇根是30号。“然而不幸的是，除非这些州的候选人现在就行动起来，在接下来的几天里申请重新计票，否则将不会有人来检查这些证据。”

  

一些安全专家曾说过，更好的选后审计是改善电子投票安全性的一种途径。

  

重新计票应增强选民信心。“检查这些州的物理证据，即便发现没什么疏漏，都将有助于消除怀疑，给选民对选举结果准确性的合理置信。同时，也将设立纸质选票常规检查的先例，为将来的选举提供重要的网络攻击遏阻力。”

  

一名安全专家称对选举违规的指控是“有警示作用的”。呼吁希拉里申请重新计票的小组还计划在28号发布一份详细的报告。目前尚无投票计算机被黑的切实证据。即将到来的报告，让每个人都周末都备受煎熬，担心他们的数据呈现或未呈现出的东西。

  

不过，美国确实需要修复投票安全问题，打印机应被加装到更多的电子投票机上。11月里，15个州都在用没有打印机的电子投票机，根本没有留下可供审计投票机内部结果的证据。
