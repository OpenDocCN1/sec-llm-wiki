# 这名少年黑客出售DDoS服务获利38.5万美元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651069296&idx=2&sn=34eae251e87d645be45b50c68f9a4701&chksm=bd14aba38a6322b594b17cde63f928759513fe0241bb588d9ae4d3f3a7728d0922632d192ccb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651069296&idx=2&sn=34eae251e87d645be45b50c68f9a4701&chksm=bd14aba38a6322b594b17cde63f928759513fe0241bb588d9ae4d3f3a7728d0922632d192ccb&scene=27#wechat_redirect)

英国赫特福德郡19岁青年日前承认，提供分布式拒绝服务攻击即服务(DDoSaaS)的 Titanium Stresser ，是他在运营。此类服务通常自我标榜为良性合法压力测试工具，但往往被用作廉价有效的网站攻击工具。

  

![](../Images/cfe61acc2dd2538f9b083298bf703a66.png)  

  

检方称，亚当·玛德通过租赁他在15岁时创建的服务，获利超过38.5万美元，帮助网络罪犯发起了170万起网络攻击。他在伦敦中央刑事法院上承认犯下了《计算机滥用法》中的两项罪行，以及一项针对洗钱的指控，判刑将在12月份进行。

  

贝德福德郡警方在通告中称，玛德的 Titanium Stresser 服务现在虽已停止运营，但曾租赁给犯罪分子进行过成千上万次DDoS攻击。玛德被控在2013年12月到2015年3月间针对181个目标发起过594次DDoS攻击。

  

![](../Images/c632e4e7a8a353669cf1b371afcb1ec7.png)  

  

他的平台在此类服务中知名度甚高，甚至提供免费的60秒DDoS攻击。玛德的平台本有可能成为著名黑客团伙蜥蜴小队所用租赁DDoS工具 Lizard Stresser 的基础。蜥蜴小队以2014年圣诞季搞摊 Xbox Live 和PlayStation网络而闻名。

  

警方之所以能锁定玛德，得归功于他保存DDoS攻击日志的习惯。东部地区特别行动队网络犯罪科探长马丁·皮特斯称，玛德错用了他的天赋，该案件十分令人遗憾。

  

“亚当·玛德的案子令人感到可惜，因为这名年轻人明明很有才华，却将这份天赋用在了侵害他人利益谋私上。”

  

“ 必须声明，我们并不是想要罪犯化年轻人，只是想给这些技术套上一些保护带，防止它们演变成犯罪工具。

  

皮特斯探长称，由于DDoS客户遍及全球，调查过程十分复杂。
