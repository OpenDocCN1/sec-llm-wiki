# 世界首个量子通信网络年底建成 安全性尚遭置疑

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651069236&idx=2&sn=734f435634abbccf3135357376f65e41&chksm=bd14abe78a6322f101a265a414ab9e8e6c1ef8521a43b1c15f4ffa0b5daac9159eb9c3886c0f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651069236&idx=2&sn=734f435634abbccf3135357376f65e41&chksm=bd14abe78a6322f101a265a414ab9e8e6c1ef8521a43b1c15f4ffa0b5daac9159eb9c3886c0f&scene=27#wechat_redirect)

2000公里的网络以提供安全量子密钥分发的基础——中国即将在下月完成首个专用量子加密光纤网络

  

![](../Images/4f4b5372c0baf3c150c7b7bb43598665.png)  

  

中国在4个主要城市之间打造“量子”网络，提供政府间安全通信，防止被外国情报机构窃听。

  

连通首都**北京**和沿海城市**上海**的光纤由32个可信节点组成，将在今年年底完工。该2000公里长的网络将途径中国东部的**济南**和**合肥**两大城市。该项目由中国科学技术大学的研究人员主导。

  

网络主要功能是交换安全通信的量子密钥，尽管网络中在节点处存在潜在漏洞——量子密钥须被转换为标准信息以解密或路由。这一世界**首个量子网络的建设**，与中国研究长距离量子密钥分发的专用卫星的发射同时进行。

  

英国量子通信中心主任蒂姆·斯皮勒称，因为是用单光子状态加密信息，量子密钥分发受限于距离。通过光纤或空气传播，光子会被吸收或散射掉。因此，**长距离的量子密钥分发需要量子纠缠支持**。据电气与电子工程师协会(IEEE)的定义，量子纠缠是“能关联物理距离很远的光子间状态，并可在光子间交换的一种属性。”

  

该半研究半实用性质的网络建设，适逢量子计算兴起的时节，研究所和大学中的某些研究开始迁移到谷歌和D-Wave之类的科技公司。英国政府也在量子计算中投入了大量资金。

  

不过，有些研究人员也称，量子加密还有一系列的缺陷有待解决。
