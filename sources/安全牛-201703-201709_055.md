# 启明星辰企业战略：独立运营、互联与智能

> “以客户需求为中心，做最受信赖的安全服务提供商”是启明星辰的企业理念之一。

  

![](../Images/2bb410950d6a9148e05eb57e4ec8dd86.png)

  

昨日，网络安全领军企业启明星辰在京召开企业战略说明会。**启明星辰CEO严望佳**在致辞中表示，启明星辰的业务模式正在发生变化，重点要放在独立运营、互联与智能化。

  

这些工作从去年开始做准备，今年已经逐渐在全国很多省市布局实施。如在当地与云、大数据、供应商加强合作，投入建设网络安全独立运营中心，并嵌入互联与智能的能力，从而为客户提供更多增值服务。

![](../Images/2ff9ac1e0169c7737c1eaa49ca6c63b8.png)

在产品交付方面，启明星辰会进一步扩大渠道、扩大概念，提高市场占有率。在用户方面，高度重视电力、税务、电信、金融等等重点行业的客户需求，对接私有云或行业云的产品服务。在运维方面，启明星辰将把智慧城市、政务云、大数据等安全运维工作放入安全运营中心。

![](../Images/ce83ec274c511ad019560ccadebdc90b.png)

  

启明星辰在未来几年的发展中，公司整个的组织结构和战略发展将围绕这三个重点工作进行。  

  

信息安全这个产业变化很快，云计算、大数据、物联网、移动互联网等等。启明星辰认为**安全既有独立性，又与这些新的场景和应用融合，是一个既融合又独立的概念。**

  

未来，启明星辰还将组建网络空间信息安全大学，在全国范围进行网络安全运营中心的布局和建设的同时，把网络安全当地人才的培养作为重点工作。

  

在前两天举行的互联网安全领袖峰会上，国内许多安全上市公司的高管都在强调战略定位的重要性。大家认为，成就业界领军企业，需要至少经历9次以上的重大战略决策不失误。**启明星辰发展成为目前国内第一大安全公司，最关键的原因之一就是其****战略定位准确的能力。**

  

**企业愿景：**

  

*   中国最具主导地位的企业级网络安全供应商
    
*   提供具有国际竞争力的自主创新安全产品和最佳实践服务
    
*   帮助客户全面提升其IT基础设施的安全性和生产效能
    
*   打造可控的安全生态体系
    
*   稳步迈入国际网络安全领导企业行列

启明星辰的企业战略说明，反映出传统网络安全厂商的转型大势。工控安全、大数据、云计算、机器学习、态势感知、数据安全，通过技术产品和业务模式的不断创新，以迎合未来趋势，是启明星辰的永远战略目标。
