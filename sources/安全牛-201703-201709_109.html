True Key 是如何干掉密码的

所有密码管理器的一个常见陷阱，就是你必须记住一个主密码。如果忘记了，你就准备失去其他所有密码吧。



True Key 则为主密码记忆这一负担提供了替代选项——用特定于用户的某些特征来登录该App。取决于你所用的设备，这些特征可以是指纹、人脸，或者另一台设备。如果想获得更强的安全，你也可以组合使用多种身份验证措施。


一旦创建了账户和主密码，并安装了浏览器插件，True Key 将以方便有效的欢迎向导，带你快速上手。向导旅程从展示几十个流行网站图标开始。挑一个点进去，向导会告诉你：你需要做的仅仅是登录，True Key 会捕捉你的凭证并存储到保险库里。再次访问该网站，True Key 会自动帮你登录的。


你的登录账户在 True Key 中可以展示成定制启动面板上的按钮


True Key 能检测到你的新账户创建动作，并弹框显示密码生成器。默认情况下，它会产生一个16字符的强密码——不嫌麻烦的话你也可以用足30个字符。


可以从定制启动面板登录你所有账户，账户可按图标或列表方式呈现。还可以从顶部的菜单栏访问电子钱包，当然，你也可以输入住址、驾照、信用卡、会员卡、护照、社会安全号等个人信息，并以不同颜色分类标记。不过，这仅仅作为安全存储而已，因为这些数据不会被用于自动填写网页表单。该菜单还包含“安全记事本(Secure Notes)”选项卡，可以存储自由格式的文本数据并做标记。


True Key 需要人脸、指纹或主密码，结合至少一种其他身份验证因子（比如可信/第二设备），来证实用户身份。用户可以选择是用基础（双因子）还是高级（三因子）保护，还可以在个人资料设置中选择用哪些验证因子。其他安全设置，比如自动登出等待时间，主密码遗忘重置等，也可以略作调整。


True Key 的电子钱包功能，可供存储用户住址、驾照、信用卡、会员卡、护照、社会安全号等个人信息，并以不同颜色分类标记。


True Key 可在所有设备上免费下载使用。免费版登录凭证存储上限为15个，若想多存，需要升级到Premium计划，每年付费20美元便可享有无限数量的密码存储服务。


底线


得益于对多因子身份验证的强调，True Key 在密码保护方面领先其他所有密码管理器。然而，它缺乏某些高级却又基础的功能，比如一键密码修改、安全密码共享和自动表单填充。如果仅仅想不费心记忆密码，True Key 价廉物美。但想要更强壮的密码管理，还是付出更高的代价找别的管理工具吧。
