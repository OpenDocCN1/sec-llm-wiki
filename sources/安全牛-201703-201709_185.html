一、市场推广经理


工作职责：


1. 搜集行业市场信息及行业动态，分类、管理、维护客户信息；

2. 了解信息安全行业及运营商行业特点，并根据市场及客户需求整合制作销售策划方案；

3. 配合运营商事业部进行市场活动的策划，制定营销策划活动的组织、执行、协调、执行过程监控. 后期宣传推广、活动总结等活动；

4. 挖掘新的市场推广活动，协助保证销售目标的达成及公司整体品牌能力的提升。


任职资格：


1. 本科以上学历，信息安全、市场营销、通信工程、计算机应用等相关专业背景；

2. 3年以上行业市场营销、或者信息安全行业售前经验；

3. 具备良好的行业、市场环境分析能力和较强的整合营销策划及提案能力；

4. 有良好的沟通能力，能够承受一定的工作压力，具有良好的职业素质及团队合作精神。


二、市场洞察经理


工作职责：


1.  为公司收集、整理、分析行业领域内政策、法规、市场、产品等相关数据；

2.  制定行业数据分析的计划，并确保按时有效的执行；

3.  行业数据分析的计划应侧重在了解行业现状及发展动态，为各部门日常业务运行提供有效的数据报告。


任职资格：


1.  本科及以上学历，数学、统计、情报分析、经济学、信息管理等专业；

2.  3年以上市场调研公司主管、行销相关经验；

3.  对于现象有深入分析探讨的能力；

4.  具有敏锐的市场洞察力，能适时观察并发现市场变化；

5.  系统逻辑思考分析能力佳，具有敏锐的数字能力，资料解读判断能力强；

6.  有良好的沟通能力，能够承受一定的工作压力，具有良好的职业素质及团队合作精神。


三、项目管理经理


工作职责：


1.项目的收集整理以及根据要求组织项目的评审答辩；

2.项目评审结束后的合同签订、以及中期、后期的跟踪和管理工作；

3.按时编制执行情况的月度总结。


任职资格：


1.较强的细致、有条理以及沟通协调能力；

2.有项目管理经验者优先；

3.有信息安全或计算机技术背景。


四、云计算安全产品经理


工作职责：


1. 挖掘客户的业务挑战与安全需求，跟踪国内外的安全技术动态，规划设计企业级云计算安全解决方案；

2. 跟踪云计算相关技术趋势，参与云计算安全架构建设；

3. 跟踪云计算安全技术发展趋势，安全标准及政策，并开展相关工作； 

4. 承担业务创新与开拓职责，进行解决方案的营销与推广。


任职资格：


1. 计算机及相关专业本科或硕士毕业，信息安全、计算机、软件等相关专业毕业；

2. 深度了解云计算基本架构和原理，熟悉VMware、OpenStack、Xen等当前主流云平台和虚拟化技术；

3. 深度了解云计算安全各主流方案，熟悉云平台以及云租户的不同安全防护需求，参与云计算安全项目优先；

4. 深入了解数据库、存储、网络协议及SDN等相关技术；

5. 深入了解评估类、防护类、响应类、检测类各安全产品技术原理与实现，有安全产品管理或研发经验优先，包括防火墙、IDS、WAF、漏洞扫描等；

6. 思维逻辑清晰，具有良好的沟通. 语言及书面表达能力，同时具备较强的学习能力；

7. 英语阅读良好；

8. 具备产品管理经验及实际安全服务或重大行业安全咨询项目经验者优先。


五、研发工程师


工作职责：


1. 负责对线上服务平台的开发和维护；

2. 负责通过线上服务框架对数据路由分发；

3. 负责构建海量数据存储/检索平台。


任职资格：


1. 1-3年Linux下的开发经验；

2. 熟悉C/C++；

3. 熟悉Shell，Python等脚本语言，有golang经验加分；

4. 熟悉TCP/IP，熟悉网络服务程序开发，对高并发、海量处理、负载均衡、容错等有深入的理解（重要）；

5. 熟悉Memcache，Redis原理，并能熟练运用；

6. 能够和团队高效沟通合作。


加分项：


有开源项目经验优先考虑；

有golang语言经验优先考虑。


六、产品支持工程师


工作职责：


1. 作为安全攻防和安全产品专家，为客户及分支安全工程师提供技术支援；

2. 深入理解产品原理，跟踪、分析最新安全漏洞和安全事件，并为内部用户提供相应培训；

3. 作为工程和客户代表，协同产品研发团队共同提升产品质量；

4. 参与重大产品测试或售前交流工作，为重要项目或在关键时刻提供现场支持。


任职资格：


1. 熟悉TCP/IP，熟悉网络交换原理和各类路由协议，如：BGP/OSPF/ISIS、策略路由，以及二层交换转发；

2. 熟练掌握网络交换、路由产品的使用、配置方法，熟练掌握复杂网络问题处理的各种手段；

3. 熟悉Linux、Windows系统常见命令，能够熟练使用各系统平台下常见应用；

4. 具有丰富的大型网络项目实施、排错经验，具有CCNP/CCIE证书，或具备相当的技术能力的优先考虑；

5. 对网络安全攻防有一定了解，如WEB攻防以及抗拒绝服务攻击等。


七、解决方案工程师


工作职责：


1. 作为安全产品专家，为客户及区域安全工程师提供基于安全平台产品或虚拟化安全产品的trouble shooting；

2. 深入理解产品原理，分析产品的应用场景，并为内部用户提供相应培训；

3. 作为工程和客户代表，协同产品研发团队共同提升产品质量；

4. 参与重大产品测试或售前交流工作，为重要项目或在关键时刻提供现场支持。


任职资格：


1. 具有丰富的soc项目实施、排错经验，或具备相当的技术能力；

2. 熟悉Linux. Windows系统常见命令，能够熟练使用各系统平台下常见应用；

3. 思维逻辑清晰，具有良好的沟通、语言及书面表达能力，同时具备较强的学习能力；

4. 了解信息安全方面的知识，熟悉网络安全攻防方面技术能力的优先考虑；

5. 了解TCP/IP，熟悉网络交换原理和各类路由协议的优先考虑；

6. 了解Hadoop，Spark，Hive等分布式大数据技术的优先考虑。


八、项目经理


工作职责：


1. 负责平台类项目的跟踪和推进；

2. 监控全国平台类项目的风险和里程碑；

3. 运用数据来监控和分析项目的进度、风险、质量和资源；

4. 同现场实施工程师和项目经理保持密切的沟通，了解当地项目进展和问题，寻找推动交付完成的解决方案；

5. 同研发保持沟通，推动定制化项目的完成和验收。


任职资格：


1.本科及以上学历，4年以上工作经验，2年以上项目管理经验，3个以上大型IT类项目交付经验；

2.掌握现场项目实施的管理知识，能熟练使用常用的项目管理工具，具有较强的分析能力和项目管理能力；

3.具有优秀的沟通协调和解决问题能力. 良好的团队合作意识和抗压能力；

4.熟悉Linux系统和主流数据库。


九、安全服务顾问


工作职责：


1. 负责支持分支重点咨询服务项目的售前和售后工作； 

2. 负责提炼成功咨询服务项目成果，开发规范化工程服务包； 

3. 负责分支纵向咨询专业人员培养； 

4. 参与外部客户培训； 

5. 公司总部其它部门要求支持或配合事宜。


任职资格：


1. 理解信息安全保障体系架构； 

2. 熟悉信息安全风险管理过程；

3. 熟悉各类安全技术及安全管理控制措施； 

4. 熟悉国家及行业信息安全监管标准及规范内容，如ISMS. 等级保护等。


工作地点：北京
