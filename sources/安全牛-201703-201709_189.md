# (ISC)²亚太区信息安全峰会召开（附：信息安全领袖成就奖完整名单）

全球最大的网络、信息、软件与基础设施安全认证非营利组织(ISC)²主办的**第十二届亚太信息安全峰会**2017 (ISC)² Security Congress APAC 于2017年7月初在香港成功举办。

  

![](../Images/389ccc62626b855355ee789b319c8575.png)

  

会议以**“未来行业的领袖”**为主题，来自全球各国政府、学术及行业300余位安全大咖云集，从全视角、多方位研讨全球热点网络安全问题。**研讨内容涵盖关键国家基础设施、新型技术与网络信息安全、云安全、安全合规与风险治理、职业发展等多个主题。**

  

由(ISC)²在2007年发起的亚太区信息安全领袖成就表彰计划 (Asia-Pacific ISLA)颁奖典礼成为大会的焦点，**亚太区信息安全领袖成就表彰计划** (Asia-Pacific ISLA)是(ISC)²联合(ISC)²亚洲顾问委员会开展的一年一度的奖项评选活动，旨在表彰展现出卓越领导力和取得杰出成就的亚太区信息安全专业人才和管理人才。

  

![](../Images/b100b8fb87fc2859210ebe4483fb4730.png)

  

据了解，参加ISLA 表彰计划评选的被提名人不限所获得的专业认证种类，面向以下四类信息安全从业者征集提名：**高级信息安全专业人员、信息安全教育工作者、信息安全项目管理类专业人员、信息安全从业人员。**并由来自政府、行业的信息安全专家评审委员会评选最终获奖者，全程公正透明。在本次获奖的24位组织和个人中，来自中国大陆的获奖者占有2席。

  

其中，来自**安点科技**的**CEO****许鑫**先生，获得 (ISC)²授予的**亚太区信息安全领袖成就（高级信息安全专业人员）奖**，以奖励许鑫先生及其带领的安点科技研究团队在工业控制网络安全技术研究中的重要贡献与成果。许鑫先生也成为获得亚太区信息安全领袖成就奖的唯一一位来自中国内地的信息安全企业CEO。

  

![](../Images/682795b1326b3a5c676f0dce96a04c4e.png)

安点科技CEO 许鑫（左一）、(ISC)²CEO David P Shearer（左二）

  

**获奖理由：**

  

“

 

十年工业控制系统网络安全技术研究工作，在核、电力、石油化工拥有多项研究成果，是工业信息安全领域最具创新力企业领导者。许鑫先生以强大的领导力带领安点科技团队攻坚克难，守护国家关键基础设施网络信息安全。
