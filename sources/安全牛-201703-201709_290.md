# 2017年5月份融资的10家安全公司

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651071889&idx=1&sn=63a1a1981bf3eb74c9927a370c0949a0&chksm=bd1495428a631c545c2b6b48914914696ae5dce6f842d918ef881341a4a8d0ecb3b2d432abf1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651071889&idx=1&sn=63a1a1981bf3eb74c9927a370c0949a0&chksm=bd1495428a631c545c2b6b48914914696ae5dce6f842d918ef881341a4a8d0ecb3b2d432abf1&scene=27#wechat_redirect)

上月的WannaCry将公众视线再一次拉向网络安全，网络攻击事件的层出不穷，令防御技术需求不断水涨船高。2017年5月，多家网络安全厂商发起新一轮融资，加大技术研发、产品完善和市场推广力度。

  

众多大笔融资包含了两个1亿美元级融资轮，其一是**CrowdStrike**用来发展其技术的，另一个是**Tanium**用以回馈员工和私募股东的。物联网依然是网络安全投资热门领域，Mocana的嵌入式安全技术获得1100万美元融资，Karamba的汽车网络安全技术卷走1200万美元。

  

**1\. RedLock**

  

![](../Images/fee2969bcd1810a852fb75af27ad0ee1.png)

  

RedLock的主要平台叫做 Cloud 360，为公共云基础设施提供安全。

  

**2\. Signal Sciences**

  

![](../Images/2ca47b269877394f129bfc3c8e525b8f.png)

  

Signal Sciences 于2014年成立，2015年公开发布其首个平台。今年5月9日，该公司宣布B轮融资筹集1500万美元。该公司的目标，是从其创始人从事领域汲取经验教训，打造能防御现实世界威胁的安全平台。

  

**3\. Vera**

  

![](../Images/0ac426be0fd8951b11622c986f871ab4.png)

  

数据安全厂商Vera同样在5月9号宣布新一轮融资，1500万美元的战略性投资。Vera自我定位在以数据为中心的安全厂商上，目标是帮助企业处理监管合规事务。

  

**4\. Attivo**

  

![](../Images/dc2675a934b0ae44fde372aa430387d8.png)

  

欺骗技术厂商Attivo在5月10号结束其1500万美元的B轮融资，主要用于满足客户需求和全球扩张需要。

  

**5\. Karamba**

  

![](../Images/aaeb687d72cfa55bc14b0a699eebfbd3.png)

  

5月16日，汽车安全厂商 Karamba Security 宣布1200万美元B轮融资。Karamba的使命，是辅助保护联网汽车和自治汽车。

  

**6\. Mocana**

  

![](../Images/a6438897abe44c6b741f3a4a92e58cde.png)

  

同样是在5月16日，物联网安全厂商Mocana宣布1100万美元融资轮，期待进一步提升其将安全集成进嵌入式IoT设备的能力。

  

**7\. CrowdStrike**

  

![](../Images/bcb3ec1b95b0c88e8589b916a6b5018c.png)

  

5月17日，安全厂商CrowdStrike宣布了1亿美元的D轮融资。该轮融资紧随一系列高调安全事件之后，包括了CrowdStrike被征召去处理的DNC数据泄露事件。

  

**8\. Aporeto**

  

![](../Images/47d85df4c1633f2e53704de522b8f61d.png)

  

容器安全厂商Aporeto在5月18日宣布了1120万美元的A轮融资，用以帮助公司改善其商业和开源容器，以及Kubernetes容器集群管理系统的安全性。

  

**9\. Tanium**

  

![](../Images/6fbc4e137221fffc5e1c3c65c1ff4caa.png)

  

下一代安全厂商Tanium在5月25日宣布了1亿美元融资轮。CEO奥莱恩·欣达维解释称，新融资轮不用来扩大业务运营，而是为了回馈现有持股者和公司雇员，包括共同创始人大卫·欣达维(奥莱恩的父亲)，给他们一个持股兑现的机会。

  

**10\. CounterTack**

  

![](../Images/5c4475b1d922e7979dbb30def90e4b1e.png)

  

5月30日，CounterTack宣布了2000万美元的D轮融资，用以提振该公司终端威胁平台的开发。
