# 利用这四个字符 任何网站都可以崩溃浏览者的 Windows 7/8

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651071812&idx=2&sn=be10cd5853387af4b9a5102cf4e91825&chksm=bd1495978a631c8164f307d7402a4c121794806328f8a9510c8636788c93401c5955b6979b06&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651071812&idx=2&sn=be10cd5853387af4b9a5102cf4e91825&chksm=bd1495978a631c8164f307d7402a4c121794806328f8a9510c8636788c93401c5955b6979b06&scene=27#wechat_redirect)

> 俄语网站Habrhabr.ru最近公布了一个bug，仅通过浏览网站即可触发。Windows 7/8/Vista均受影响，而对Windows 10则无害。

  

![](../Images/09959d6dd1046cd154ac16a5fe954165.png)

  

任何网站只需使用“$MFT”这个四个字符作为其图片目录的名称，即可令网站浏览者的计算机崩溃。原理是，这四个字符，Windows只认可其存在于特殊元数据文件中。如果在目录名见到这四个字符，计算机就会逐渐变慢直至最终挂起。这时，唯一的办法就是重启计算机。某些情况下，甚至还会触发蓝屏死机。

  

对于一个网站来说，图片文件通常存储在类似于“website.com/images/”这样的目录中。可能这也是为什么直到现在才有人发现这个bug，毕竟谁会想到使用“$MFT”这种字符给目录命名呢？

  

对于浏览者来说，除了禁止装载有问题网站的图片以外，别无他法。微软尚未对此bug做出回应，但可能会推出相应的补丁。但这只能是针对 Windows 7/8，Vista用户则没有此幸运，因为这个操作系统早已被微软宣布放弃支持了。
