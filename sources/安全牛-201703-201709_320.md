# 9国家级+51省级 60家安全公司入选第七届CNCERT应急服务单位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651071798&idx=4&sn=3a22bacb2cfffedfafcb723731bd26e0&chksm=bd1495e58a631cf3dfe0b0d7bbb5504b0c9a94b78d7350d73e1a8209eaa78e99a748e1ef90a4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651071798&idx=4&sn=3a22bacb2cfffedfafcb723731bd26e0&chksm=bd1495e58a631cf3dfe0b0d7bbb5504b0c9a94b78d7350d73e1a8209eaa78e99a748e1ef90a4&scene=27#wechat_redirect)

近日刚刚结束的“2017中国网络安全年会”上，举行了第七届CNCERT网络安全应急服务支撑单位的授牌仪式。  

  

本次应急服务单位共有100余家企业申请，最终获批60家。其中，绿盟、深信服、安天、安恒、启明星辰、东软、网神、天融信、恒安嘉新等9家安全厂商，入选**国家级支撑单位。**

  

![](../Images/87a3e7e6fb417e4fd41db9e68c570eb8.png)

去年的9家国家级支撑单位，分别是绿盟、奇虎、安天、安恒、东软、启明星辰、天融信、恒安嘉新和中国电信集成。

  

今年的变化有三：一是奇虎换成了旗下全资公司网神入选国家级支撑单位，二是深信服新进国家级，三是中国电信集成入选了省级支撑单位。

  

**省级单位**共51家，详见下图。
