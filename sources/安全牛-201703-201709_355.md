# 防火墙先锋 Check Point 进军汽车数据防护领域

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651071672&idx=2&sn=be63459aafe1533044886e89405b8533&chksm=bd14946b8a631d7d05ce8e0d5e1d69f41a679d25bc30826c60147a32c7205aa97401a3047259&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651071672&idx=2&sn=be63459aafe1533044886e89405b8533&chksm=bd14946b8a631d7d05ce8e0d5e1d69f41a679d25bc30826c60147a32c7205aa97401a3047259&scene=27#wechat_redirect)

Check Point 软件技术有限公司，是世界第二大网络安全提供商。如今，随着自动驾驶技术和联网车辆的安全需求上升，这家以色列网络安全公司在全球汽车市场上的销售预期也水涨船高。

  

**Check Point 将领导包括Argus网络安全有限公司和Valens半导体有限公司在内的工作组，设立车辆电子架构安全标准。**如果该工作组取得的成果最终被汽车制造商和供应商采纳，Check Point 在该行业的触角就将超出现有的云-车通信范围，探索更加深入。

![](../Images/5460c0e435aa994278daa52940f96324.png)

谈到 Check Point 在汽车行业的迈进，彭博社分析师曼迪普·辛格说：“每家网络安全公司都关注这一块，但都没取得多少进展。这是个非常大的用户场景，但技术仍处于萌芽时期。”

  

**技术联盟**

  

该工作组属于**HDBaseT标准联盟**。HDBaseT联盟是主推Valens发明的信号传输技术的一个贸易组织，其主要优势在于能将视频等富数据内容仅用一根线缆就传遍车内网络，既轻且省。通用汽车公司是该联盟董事会成员，戴姆勒公司去年称其将在信息娱乐系统、高级辅助驾驶和通信系统中采用HDBaseT。

  

**汽车越来越像电脑，都有千百万行代码和多个互联网连接，被黑的可能性也随之倍增。**2015年，汽车被黑风险受到广泛关注，安全研究员证明了他们可以黑掉Jeep汽车，夺取车辆的控制权。这导致了菲亚特克莱斯勒召回140万辆汽车，是为第一起因网络安全威胁而引发的正式安全行动。

  

Jeep召回事件带动了对现有车辆适用安全软件的需求。Check Point 期望能帮助描绘下一代车辆的安全蓝图。

  

Check Point 商业开发副总裁康托尔说：“随后，我们将能提供在车载基础设施上运行的产品，但第一个阶段，应该是进行安全设计。”

  

**膨胀的市场**

  

汽车网络安全市场现今价值不到1亿美元，但IHS Markit估测，到2023年，该数字将增至7.59亿美金。

  

**该行业的增长潜力驱动了很多行业的公司加入竞争。**去年被三星电子以80亿美元收购的美国哈曼国际工业集团，就是汽车网络安全领域最大的玩家。黑莓公司的QNX汽车软件已经在超过6000万辆汽车上运行，但该公司仍在尝试提供新的网络安全防护层，争取在汽车网络安全行业占得一席之地。

  

戴姆勒和德尔福汽车零部件公司也是HDBaseT联盟成员。虽然通用公司也在联盟董事之列，却仍在评估该技术。德尔福本月早些时候表示，持有Valens少量股份。
