# 网络安全监督机构发现大型跨国网络攻击APT10

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651071237&idx=2&sn=95c6314e3333394236fabd228833d9ab&chksm=bd1493d68a631ac05882fa48b792adf63e86b19247455a465874fafcb3f26589e645b19578f3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651071237&idx=2&sn=95c6314e3333394236fabd228833d9ab&chksm=bd1493d68a631ac05882fa48b792adf63e86b19247455a465874fafcb3f26589e645b19578f3&scene=27#wechat_redirect)

4月5日，对美国、日本、瑞典和其他欧洲国家公司通过IT服务商发起的大型网络攻击被曝光。

  

![](../Images/9cfcf942e43b062e90a97c623b0f27a6.png)

  

该网络攻击由英国国家网络安全中心、普华永道和 BAE System 网络安全公司的合作发现。该攻击至少从2016年5月，甚至可能早在2014年起，就试图获取托管服务商客户内部网络的访问权限。

  

该攻击源自**APT1**0，被命名为“**Cloud Hoppe****r**” 。瑞典民事应急机构在声明中称其准确规模尚未可知，但据信涉及海量数据。该机构没有说明此网络攻击是否仍在进行。

  

![](../Images/bdf5c5fc9cdc020b43f978b32b3075b4.png)

  

“

 

瑞典的高度数字化，以及大量服务外包给托管服务商的事实，意味着多家瑞典公司在该攻击的影响下会处于巨大的安全风险中。

  

该机构称，这些攻击背后的黑客使用了大量资源来锁定其目标，并发送高端网络钓鱼邮件来感染计算机。  

  

据称，瑞典IP地址也被用于协同入侵和取回被盗数据，APT10的攻击尤其针对IT、通信、医疗保健、能源和研究机构等目标。
