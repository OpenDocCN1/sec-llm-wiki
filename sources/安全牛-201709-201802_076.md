# 谷歌母公司成立独立安全公司 脸书、亚马逊、思科纷纷收购初创企业

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651075694&idx=2&sn=124207049d18cd4f8f6e49c4873c6d38&chksm=bd1484bd8a630dabe26d02ba9b61b5c24cd5dff755ad75c6f918b98e7a519ad36fa53608de1c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651075694&idx=2&sn=124207049d18cd4f8f6e49c4873c6d38&chksm=bd1484bd8a630dabe26d02ba9b61b5c24cd5dff755ad75c6f918b98e7a519ad36fa53608de1c&scene=27#wechat_redirect)

**谷歌母公司Alphabet****周四宣布成立独立安全公司****Chronicle**。Chronicle源自于谷歌的X计划，通过分析大量数据为安全团队提供“可能的漏洞”信息。公司业务分为两部分，一是网络安全情报和分析平台，二是2012年收购的恶意软件情报平台VirusTotal的原有业务。  

  

![](../Images/3dabd0e20c59c3d9a023720db16cce68.png)

  

**脸书最近完成对身份认证初创公司Confirm的收购。**后者在收购前已经研发出可整合到司机驾照和其他政府ID的API和SDK，可轻松的实现安全认证，并积累了750家机构的客户，2016年1月种子轮融资400万美元。

  

本周二，**威胁捕捉初创公司Sqrrl宣布亚马逊对其收购工作已经完成，并加入AWS家族。**Sqrrl是由美国国家安全局孵化的安全公司，其7名核心成员中有6名曾在美国国家安全局工作。该公司于2012年成立，至今为止已融资2800万美元，专注于大数据分析以发现安全威胁。

  

本周三，**思科宣布拟收购服务器安全初创公司Skyport。**后者2015年B轮融资3000万美元，2016年C轮融资3000万美元，总融资额约6700万美元。

  

除了上述的收购案例之外，本周二**，Sumo Logic 宣布完成事件响应与安全调查公司FactorChain。**

  

2018年伊始，安全领域的整合趋势明显。
