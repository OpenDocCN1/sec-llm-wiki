# 软件定义安全：天融信国内首家获得VMWare Ready认证

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651075083&idx=2&sn=08259218520fabf51cfbf33392870a5c&chksm=bd1482d88a630bcea7cd09310cd4365b13bbea8a67f2e61366a7942a9c54aa0b3a0cb90ccbf8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651075083&idx=2&sn=08259218520fabf51cfbf33392870a5c&chksm=bd1482d88a630bcea7cd09310cd4365b13bbea8a67f2e61366a7942a9c54aa0b3a0cb90ccbf8&scene=27#wechat_redirect)

继12月15日天融信宣布软件定义安全解决方案正式发布后，围绕“安全云化·随需应变”为主题的天融信软件定义安全解决方案媒体沟通会议于今日召开

  

![](../Images/6e4c475d6ee58673044c678d8c439eb3.png)

  

此次会议上，天融信全面诠释了**软件定义安全**（SDSec）解决方案在云时代的价值、使命与愿景，并与各家专业媒体围绕产品技术、市场等方面展开充分交流与互动。天融信CEO于海波博士、VMware大中华区渠道及业务拓展总经理王冰峰先生等出席此次会议并发表重要讲话。

  

天融信CEO于海波博士表示：“天融信作为中国领先的网络安全、大数据与安全云服务提供商，在云安全领域经过多年的技术积累目前已拥有完整的软件定义安全解决方案。而VMware是全球虚拟化解决方案的领导者，在虚拟化领域拥有最为广泛的用户基础，这次合作是云安全与虚拟化领域的强强联合，未来我们将共同努力，开展更加深入的技术合作与市场开拓，致力于为用户提供高品质云安全产品与服务，打造开放的云安全生态圈”。

  

![](../Images/e7a47a4c81b4f498976816d1e3a9db84.png)

天融信CEO于海波博士

  

天融信于2016年正式成为VMware的合作伙伴，其软件定义安全（SDSec）解决方案中的核心产品TopVSP-vDFW凭借丰富的高级安全防护特性与性能优势，获得了VMware Ready认证。VMware Ready是VMware为既有合作伙伴创建的产品而提供的最高级别认证。VMware技术联盟合作伙伴成员可以开发符合VMware标准的产品并提交进行测试和认证，符合VMwareReady要求的产品将显示VMware Ready徽标。

  

VMware大中华区渠道及业务拓展总经理王冰峰表示：“作为全球云基础架构和移动商务解决方案的领导厂商，VMware Ready™项目为当前合作伙伴所开发的产品和解决方案提供顶级支持，而VMware Ready身份可以帮助客户树立信心，并为业界领导者们创造更多云端合作的机会。VMware通过携手天融信这样的领先企业，帮助本地客户提升安全性能和业务灵活性，加速转型”。

  

![](../Images/51d5bc10153dbd45be19de0d3694a862.png)

VMware大中华区渠道及业务拓展总经理王冰峰先生

  

从中国第一台自主知识产权防火墙产品研制成功，到成为国内首家通过VMware Ready认证的安全厂商；从传统的网络安全边界防护纵深到云内虚拟化动态边界安全防护，天融信再一次弥补了国内虚拟化网络安全防护产品的空白，这标志着天融信完成了从传统环境下的网络与信息安全能力向云环境中综合安全服务能力的完美升级。

  

![](../Images/c4089c047479462c6bec87b670bbc289.png)

天融信云安全产品线副总经理李玮先生

  

此次天融信携手VMware召开此次天融信软件定义安全SDSec解决方案媒体沟通会议，向业界宣告一套全新云安全整体防护解决方案的伟大诞生。未来，天融信还将继续与VMware展开深度合作，以创新的产品技术、卓越的产品品质成为云时代网络安全的捍卫者。
