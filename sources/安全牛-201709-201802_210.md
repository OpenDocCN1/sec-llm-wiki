# 黑客使尽浑身解数修改监狱记录 只想让好友提前出狱

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651074867&idx=2&sn=367e85ce908d08e6de544c18f93a1bbc&chksm=bd1481e08a6308f6c28e67ab0eced76ba0338e4137e86506cd3d9f824117337e9f98bddc7132&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651074867&idx=2&sn=367e85ce908d08e6de544c18f93a1bbc&chksm=bd1481e08a6308f6c28e67ab0eced76ba0338e4137e86506cd3d9f824117337e9f98bddc7132&scene=27#wechat_redirect)

一位来自密歇根安阿伯市的黑客入侵了Washtenaw县监狱的计算机系统，他更改了服役数据来让朋友提前出狱。事与愿违的是，监狱工作人员及时发现并制止了这起事件。

  

![](../Images/d5ffffd405ab2fbdad81c8d3ebb137af.png)

  

这名黑客名为**Konrads Voits**，并于上周在联邦法庭认罪，他坦言自己通过一个复杂的计划入侵了监狱等电脑，该过程用到了恶意软件、钓鱼和社会工程技术。在修改数据的过程里，Voits也承认自己曾用电话诱骗监狱工作人员恶意软件，并盗取了多名县监狱员工的个人信息。

  

![](../Images/9c326847f2bc79566a10ad620b4909d8.png)

Konrads Voits

  

根据法庭文件，Voits也以Daniel Greene对名字注册假网站ewashtenavv.org来实行网络钓鱼诈骗，该县的官方网站是ewashtenaw.org，Volts使用使用“vv”取代“w”来混淆视线。

  

幸运的是，他的第一个针对县监狱员工的骗局失败了，所以他开始给他们打电话，声称自己是县监狱的IT部门经理。然后他让几个员工访问网站，下载并安装一个.exe文件来升级县监狱系统。

  

Voits最终得到了大量个人信息，其中包括超过名1600工作人员的账户密码、用于监控和跟踪监狱里的囚犯的XJail系统密码，,他用XJail提前了一个囚犯的获释日期。

  

整个犯罪过程发生在2017年1月24日至3月10日之间。政府花费了超过23万美元来赶在数据被曝光之前进行弥补。Volts认罪后将面临25万美元的罚款和十年刑期。他也愿意放弃用于攻击的个人财产，包括不明数量的比特币、手机和笔记本电脑。

  

然而，Volts并不是第一次给执法部门惹事，他曾在2015年向美国联邦调查局举报了虚假的炸弹威胁。Volts和自己的狱友兄弟也算是“A friend in need is a friend in deed”。
