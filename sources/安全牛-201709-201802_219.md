# AWS猛然成为网络安全领域重量级新势力 正式进军万亿美元市场

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651074829&idx=2&sn=4f4830bd68fd9fea22eafca615a0b344&chksm=bd1481de8a6308c8f187b18933104666dc4b992c1fd52b89e829d91a6eb6e2c0891afa15c299&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651074829&idx=2&sn=4f4830bd68fd9fea22eafca615a0b344&chksm=bd1481de8a6308c8f187b18933104666dc4b992c1fd52b89e829d91a6eb6e2c0891afa15c299&scene=27#wechat_redirect)

随着**Amazon GuardDuty**的发布，以及通用电气(GE)之类大企业对该服务的使用，AWS已成为网络安全领域一大力量。

  

![](../Images/f569100ada3e6560f26af5ccc51d76ca.png)

  

网络安全市场快速增长，未来五年预计全球网络安全开支将达1万亿美元。这意味着将会出现很多新的市场进入者。风险投资涌向网络初创公司的同时，主流科技品牌也在向该领域奋勇迈进。

  

随着GuardDuty的亮相，AWS成为网络安全界新进大牌。虽然AWS已经向其客户提供了一个安全平台和相关服务，该新产品还是触动了这个充斥着类似解决方案的市场。

  

![](../Images/076e5df449446963fe6cdfbf621b7bf4.png)

GuardDuty工作原理  

  

AWS  GuardDuty发布会上真正吸引眼球的，是大企业客户的快速采纳，包括GE、Netflix、FINRA和Autodesk。

  

重点很明显：AWS在财富500强、全球2000强公司和数十家大型企业的CISO面前赢得了一席之地。鉴于AWS云平台的规模，以及将IT基础设施部署其上的广大客户，AWS有可能在网络安全领域打下一片天地。

  

AWS新闻发布中，AWS首席信息安全官史蒂芬·施密特称：“客户常常跟我们说，帮他们保持安全最好的方式，就是交给他们更智能的工具，让他们可以更容易地搞定安全。”

  

“

 

我们把Amazon GuardDuty设计得非常简单且便宜，每位AWS客户，无论其安全专业知识水平如何，也不用管当前正在使用何种安全服务，都可以轻松选择GuardDuty。Amazon GuardDuty可智能识别其他安全产品很难检测的威胁，扩展起来也十分方便，能满足任何公司的需求，无论是有2个AWS账户还是有2000多个账户。

  

**GE一天之内就让Amazon GuardDuty部署运行起来了**

  

数家大型企业对GuardDuty服务反应迅速，大加赞赏。

  

AWS媒体发布中，GE副总裁兼全球首席信息及产品安全官纳斯林·雷扎伊说：“安全，是GE首要大事，根植在我们的公司文化中。GE在AWS运行有数千个应用。在我们全球AWS足迹上部署Amazon GuardDuty只需要几个小时，部署上就能增强我们威胁检测的能力。”

  

想想看，全世界最大IT商之一仅仅在1天之内就将GuardDuty全球部署。

  

超过50%的网络攻击都是针对小公司发起的（往往毫无防御），AWS对员工数少于250名的公司同样有吸引力。
