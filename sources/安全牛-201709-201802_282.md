# 且看10岁的孩子解锁他妈妈的iPhone X

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651074427&idx=2&sn=87f9c0b4a786f9585aacc2cdadd09571&chksm=bd149fa88a6316bee8c7807403d4a1bf6876ee1d8bcb92c02d26f4c43ee8f58c8733354ef29d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651074427&idx=2&sn=87f9c0b4a786f9585aacc2cdadd09571&chksm=bd149fa88a6316bee8c7807403d4a1bf6876ee1d8bcb92c02d26f4c43ee8f58c8733354ef29d&scene=27#wechat_redirect)

破解苹果手机的面部识别系统并非易事，当然如果你是一名“特殊”的黑客则另当别论。**不要误会，这里的“特殊”指的是你长得非常像你的父母。**

  

![](../Images/d18541469aedc8a6d5a6ea98555a0fcc.png)

  

这位十岁的黑客是一名五年级的学生，当时他的母亲刚买了一台iPhone X并使用了Face ID。结果，他拿起手机看了一眼，就“自然”的解锁了屏幕。吓的他母亲赶紧把手机夺过来，删掉手机中之前与孩子父亲的短信对话，因为里面有不想让孩子看到的大人之间的对话。

  

📹 [https://v.qq.com/iframe/preview.html?vid=w0505swjx8d&width=500&height=375&auto=0](https://v.qq.com/iframe/preview.html?vid=w0505swjx8d&width=500&height=375&auto=0)

  

Face ID是苹果公司引以为傲的面部识别技术，不知有多少黑客高手想破解都无功而返。即使昨天公开的消息称，几名越南黑客利用3D打印技术成功破解，过程也是非常困难的，需要当事人的面部数字扫描，然后再用硅有机树脂、塑制品等3D打印材料和化妆术才能搞定。

  

实际上，令苹果最头疼的就是相貌接近的家庭成员，比如双胞胎，甚至是异卵胞胎。而现在，子女也是一个大问题了。

  

令人疑惑不解的是，那名孩子只能解开母亲的手机，却对父亲的iPhone X无能为力。但实际上，据旁人说孩子长的更像父亲。

  

![](../Images/eb33473a4b3b8297e05f709f2a142cba.png)

瞧这一家子

  

妈妈后来又重置了几次Face ID，有的时候孩子无法解锁，有的时候可以，但后来似乎手机AI试图学习孩子的面部特征，以便让解锁更容易。

  

苹果的官方网站上这样写道：“统计学可能性有所不同，从双胞胎到长得比较像的兄弟子妹，再到13岁以下的儿童，因为，他们（指后者）的独一无二的面部特征还没有充分长成。如果你对此有所担心，建议使用口令来认证。”

  

其实不仅是子女，Face ID 被家人破解的例子还有不少，包括异卵胞胎，兄弟子妹，甚至还有一对年龄差异较大的同父异母（或同母异父）兄弟（见下面的视频）。
