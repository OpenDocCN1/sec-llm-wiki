# 长亭科技发布两款新品 B轮获经纬中国亿级融资

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651078128&idx=1&sn=28d181928be07cd1117ce48f1d1410fd&chksm=bd148d238a6304355ae44731e97a85bf8c48a918cd07335e63b501422f41f42ec632f3ddadea&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651078128&idx=1&sn=28d181928be07cd1117ce48f1d1410fd&chksm=bd148d238a6304355ae44731e97a85bf8c48a918cd07335e63b501422f41f42ec632f3ddadea&scene=27#wechat_redirect)

13日，以技术创新见长的网络安全公司长亭科技召开新品及融资发布会，宣布B轮获经纬中国亿级融资，并正式发布扫描器产品洞鉴（X-Ray）及云服务器安全产品牧云（CloudWalker），针对企业级市场的应用安全塔防体系形成。

  

长亭科技联合创始人兼CEO陈宇森现场公布：本次发布的新品牧云（CloudWalker）服务器安全平台将于9月底正式开源，作为国内第一家软件产品开源的网络安全公司，欢迎更多力量共同致力提升云时代基础安全水平。

  

创始人团队源自于清华蓝莲花CTF战队，是一支一流的网络安全竞赛战队，几乎包揽国内所有各大赛事的冠军，并是首支入围国际黑客大会 DefCon CTF 决赛的中国战队，迄今保持全球第二的最佳战绩。

  

陈宇森表示，基于优秀的人才去提供“智能、自动化、高效的安全产品和整体安全解决方案”是长亭的技术发展理念。而中国的网络安全市场增长很快，出现新的大型安全公司为大概率事件，长亭则为此而努力。他还表示，本次的融资将主要用于产品研发和市场扩张。

  

目前，长亭科技的产品线主要覆盖企业应用安全的攻、防、查、抓四大核心环节：

  

1.  攻-高可用性、低误报率的扫描器；
    
      
    
2.  防-基于智能语义分析的WAF，可高度自定义，支持轻量级的集群；
    
      
    
3.  查-云主机安全，从服务器内部观察网络环境的安全视角，基于Agent的深度服务器工作负载安全平台。
    
      
    
4.  抓-内网威胁感知，基于高级蜜罐技术，做伪装欺骗、事件记录和威胁分析；
    

  

同时，长亭科技升级服务线至渗透测试、代码审计、基线检查、应急响应四方面覆盖软件工程全生命周期。

  

目前的客户主要集中在金融与互联网，未来可能突破新能源和政企领域

安全牛评

  

长亭的技术切入点是颠覆传统基于规则的“语义分析”技术，核心人员均具备扎实计算机功底和高级攻防能力的CTF战队成员。在商业上，长亭较为快速的完成了落地、商业化、产品化等企业发展过程，下一步则面临着所有初创企业都要面临的“规模化”。创始人的全面性，协调、应变能力和战略头脑，以及核心团队的产品化和适应能力，将是长亭科技“规模化”发展的重要基础支撑。
