焦点


1. 最安全WiFi协议到来！WiFi联盟发布新一代WPA3安全标准，将分为个人模式以及企业模式两种部署。


2. 安全牛发布《中国网络安全企业50强》(2018年上半年)。2017年度，所有被调查对象（约210余家）网络安全业务收入总额为298.9269亿元。



时政


1. 近日，美国Applied Insight和DV United公司宣布获得美国陆军网络司令部价值650万美元的五年期合同，以加强美国陆军网络司令部的反情报工作，包括管理并维护“用户活动监控计划（UAM）”。这项合同将借助大数据分布防范内部威胁。



2. 本周，网络安全标准论坛在京召开。公安部官网发布《网络安全等级保护条例（征求意见稿）》，开始为期一个月的意见征求。同时，物联网将被纳入等保2.0。


3. 前NSA承包商员工因向媒体泄露俄罗斯干涉美国大选的机密信息，将面临63个月的牢狱之灾。

4. 欧盟网络部队成立，已有法国在内的七个国家加入阵营。

（http://t.cn/RrpnGhJ）


5. 英国国家医疗服务体系在过去三年中总共下线超过 1,300小时，其中超过一半的下线事件是由于网络安全问题。

（http://t.cn/RrjT6mG）


6. 英国政府发布“最低网络安全标准（Minimum Cyber Security Standard, MCSS）”，制定公共部门的网络安全底线。

（http://t.cn/RrjukHr）


行业


1. 2018 Gartner安全与风险管理峰会召开，关注安全管理者需要注意的问题：本源很重要，DevOps行之有效，安全需要融入体验。



2. 德国研究者发布论文，发布了一种新的方式，不仅仅能通过打印的内容找到相关打印机，更能发现打印的始作俑者。

（http://t.cn/RrpnIaM）


3. 数据泄露调查平台“Have I Been Pwned”（HIBP）将嵌入火狐以及1Password。用户可以通过工具Firefox Monitor来查找自己的密码是否遭到泄露。

（http://t.cn/RraF0G2）


厂商


1. 近日，绿盟科技发布面向企业的下一代安全运营服务——绿盟可管理的威胁检测与响应服务，为企业提供集安全威胁检测设备、安全威胁分析平台及安全专家服务于一体的安全运营服务。


2．数据保护公司BigID近日获得B轮融资3,000万美元。BigID致力于帮助企业保护数据以及进行数据合规。BigID运用智能身份以及机器学习，帮助企业保护数据以及进行合规——尤其是欧盟近日发布的GDPR。

（http://t.cn/RrCEDEX）



3. EDR（端点检测与响应）厂商杰思安全接受绿盟2,000万元的战略投资。绿盟科技与杰思安全将在云计算、虚拟化、威胁情报等多个技术领域展开合作。


4. 安全性平级公司BitSight近日获得D轮融资6,000万美元。BitSight的SaaS安全评级平台帮助全球1,200名客户管理第三方风险、安全性能表现、提供安全保险政策以及提供并购服务。

（http://t.cn/RrjmtLn）

2. 研究人员近日发现英特尔超线程漏洞，然而英特尔表示将不会对此发布任何补丁。
