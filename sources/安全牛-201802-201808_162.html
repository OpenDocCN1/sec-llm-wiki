赛门铁克：业界首款Web隔离云网络安全解决方案

6月11日，世界顶级网络安全公司赛门铁克发布其云世代网络安全( Network Security for the Cloud Generation )解决方案新功能，旨在全方位保护企业设备，无论员工是出差还是旅行，是通过企业网络、云、移动设备还是传统终端办公。



作为赛门铁克集成网络防御平台( Integrated Cyber Defense Platform )的组成部分，本次功能增强包括：


  • 行业首款Web隔离技术集成进赛门铁克Web安全服务(WSS)中，让上网冲浪不再惧零日恶意软件或高级威胁。


  • WSS纳入赛门铁克终端防护(SEP)及SEP移动( SEP Mobile )，形成全面的网络到终端防护，可将Web流量重定向到WSS应用网络安全策略，进而无需再设单独的代理来管理流量。


  • 软件定义云连接器( SD-Cloud Connector )令客户能将软件定义广域网(SD-WAN)技术的性能及可靠性融入赛门铁克WSS，以简单易行的高性能方法将分散各地的办事处通过赛门铁克领先世界的云安全服务连接起来。


赛门铁克WSS是包含了Web安全网关(SWG)、Web隔离( Web Isolation )、恶意软件检查引擎、沙箱、数据丢失防护(DLP)和云访问安全代理(CASB)，并集成了多因子身份验证的单服务产品。新功能为公司企业提供了全面易用的云网络安全服务，可保护关键业务信息，令云应用和Web使用安全而合规。



随着公司企业纷纷采用 Office 365 之类的云应用，随着员工越来越多地远程登录这些App，新的安全与合规风险浮现在公司企业面前。赛门铁克的云世代网络安全解决方案( Network Security for the Cloud Generation )为公司企业提供了全面的防护，可满足日益丰富的企业IT运营需求，保护现代企业环境——包括基于云的服务和物理及虚拟设备。


赛门铁克总裁兼首席运营官(COO)麦克·费( Mike Fey )称：“Web隔离( Web Isolation )是帮助客户解决针对雇员网页浏览器的新型高级威胁的重要创新，在防护恶意软件和网络钓鱼攻击的同时不会发生过度拦截现象或妨碍生产效率。我们WSS中新增的这些功能，让我们在单服务产品中囊括了市场上最全面的云威胁防范功能，能全方位保护用户及数据，帮助客户应对云世代安全挑战。”


往590万户家庭和公司输送天然气的SGN配气公司，使用赛门铁克WSS保护其分散各地的全体员工。SGN首席信息安全官称：“这一行中，安全是至关重要的。随着员工移动性增加，员工办公室设备和家中设备的安全防护工作也变得越来越困难。而有了赛门铁克的WSS，我们能够对所有用户实施公司的合规策略，无论用户身处何方，用什么设备办公；既支持了生产，又保护员工不受新兴威胁的侵扰。”


企业战略集团(ESG)的高级首席分析师乔恩·奥尔茨克( Jon Oltsik )称：“往现有网络技术栈中集成更新更好安全功能的工作并不容易，其复杂性和各项开销令公司企业苦不堪言。而太多员工远程办公或分公司遍布世界各地的现状，又更加加重了这种技术升级的挑战。赛门铁克基于云的WSS，能以全面的威胁防范、信息安全及云应用控制功能，帮助解决这些困难与挑战。新的Web隔离、终端集成和软件定义云连接器功能，为很多公司企业带来了很有价值的额外安全加成与工作简化收益。”


作为赛门铁克集成网络防御平台的组成部分，云世代网络安全解决方案可在终端等多个层次上无缝重定向网页流量，融合来自全球最大民用威胁情报网络的信息，帮助企业实施统一的安全策略合规。


目前，赛门铁克云世代网络安全解决方案已向客户推出；SEP Mobile 将在今年第三季度推出。
