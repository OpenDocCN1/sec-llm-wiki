# 牛道消息｜吸毒黑客也可参军、医院被轰炸、30亿美元

**\>> **美国政府正在考虑为了吸引安全人才加入军队而降低入伍标准。**由于军队内技术人才缺乏，尤其是计算机人才缺乏，已有人提出草案希望降低对性别和年龄的限制。**

  

![](../Images/270bc8b6b3b47198a730f25ff5e7ad5d.png)

  

其实早在2014年，时任FBI局长的Comey就放言FBI应该宽松药物政策来雇佣那些吸大麻的黑客人员。然而，SANS认为这种少量的稀缺人才一旦大量加入军队会对民间企业带来不利。为此，英国和美国都已经开展各种计划，目的不只在于培训人才，更重要的是想发现那些自身对计算机和信息安全有天赋的人。  

  

**\>> **英国的外科医生David Nott认为，**由于自己的电脑被黑客攻击，使得对方获取了叙利亚某医院的精确定位，从而该医院被战斗机实行了轰炸。**Nott医生通过Skype和WhatsApp软件给叙利亚医院的医生进行远程手术指导。该事件被英国的BBC新闻于2016年9月报道，而该医院于2016年10月3日遭到直接轰炸。尽管这次黑客攻击是否真实未有定论，但计算机被成功攻击，定位数据确实有可能被窃取。

  

**\>> **Gartner指出，全球企业今年将在物联网安全上花费15亿美元，而到2021年，这个费用将高达30亿美元。物联网作为新生技术，其本身有着大量的安全缺陷：从设计上就缺乏安全保护、无法及时在线更新补丁。

  

安全供应商Avira通过2017年的报告指出，仅美国地区连接的1.27亿物联网设备中就有0.25亿设备有安全漏洞——而漏洞类型尚只有45个。

**Gartner认为，****物联网安全需要同时依赖服务与工具。**

  

Gartner预测，2018年，企业将在物联网安全服务上花费总共15亿美元中的9.46亿美元，而在2021年，这个费用将高达21亿美元。

  

物联网设备安全工具则是另一个投入领域。2018年，在物联网**终端安全**上将花费3.7亿美元，在物联网**网关安全**上将花费1.86亿美元，而到2021年，这两个数字将分别达到6.3亿美元与4.15亿美元。
