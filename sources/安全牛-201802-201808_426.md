# 剑桥大学：俄罗斯攻击电网可导致成千上万人死亡

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651076337&idx=1&sn=b5a5b0004887e0c7e886470c8679f4d2&chksm=bd1486228a630f34be756bb83c3f091f57d4a97d1dde1b4ab71686d64259b4318407052077d8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651076337&idx=1&sn=b5a5b0004887e0c7e886470c8679f4d2&chksm=bd1486228a630f34be756bb83c3f091f57d4a97d1dde1b4ab71686d64259b4318407052077d8&scene=27#wechat_redirect)

**要点：**  

  

> *   俄罗斯有能力切断英国电网；
>     
> *   断电可致英国发生暴动和趁火打劫现象，届时将会出现成千上万的死亡；
>     
> *   现代生活太过依赖电力，断电是巨大的灾难；
>     
> *   周日和周一的气温骤降可能会令天然气需求骤增；
>     
> *   天然气储量可能大幅下降，英国需要俄罗斯的天然气。
>     

  

现代生活如此依赖电力，以致安全机构警告称：一旦电网被断，国家距离无政府状态也就几顿饭的时间。如果英国政府的控制力被网络攻击搞瘫，英国街头将出现骚乱和趁火打劫的现象，成千上万人会因此丧生。

  

![](../Images/38cb6038f50ed021df1ca3832f3e50a3.png)

  

剑桥大学学者认为，如果俄罗斯对英国发动网络攻击或切断天然气供应，英国就会面临上述风险。灾难性网络攻击与极端天气、太阳风暴、恐怖袭击一样，都是会让国家陷入混乱的巨大威胁。

  

剑桥大学存在性风险研究中心的研究人员表示，如果遭遇灾难性的网络攻击，法律和秩序将在几天内开始崩塌。这是相当真实的风险，任何时候都可能发生，有可能是明天，有可能在你正享用下午茶的时候，而英国人大多忽略了这种风险。

  

供水和污水依靠电力，油泵也需要，而通信中断意味着政府无法通告公众。电力基础设施安全委员会顾问认为，21世纪的社会完全依赖电力，这太可悲了。现代社会就像复杂的拼图，一旦撬动其中一两块，整个社会都会崩塌，人们的生活逐渐陷入停滞。

  

国家电网也认同这种观点，称“稳定可靠的能源供应我们最重要的工作”。**除了俄罗斯或其他国家发起的网络攻击，电力设施面临的风险还包括极端天气、电磁脉冲武器、对变电站的恐怖袭击，以及太阳风暴。**

  

英国国防部长加文·威廉姆森上个月称，俄罗斯一直在监视英国的能源基础设施，如果俄罗斯选择破坏这些能源基础设施，英国会出现无数死伤。3月中下旬的寒潮会让英国和欧洲燃气需求骤增，也让英国不得不祈求俄罗斯的天然气供应不要断供。

  

标准普尔普氏能源资讯分析师报告称，因为供应商库存已经或快要耗尽，欧洲诸国可能只剩下依靠俄罗斯这一途径。春寒以及英国储气设施关闭之后，整个欧洲的天然气储备都达到了历史新低。
