“牛道消息”播报员 晓凡


>> 为期两天的2018 Pwn2Own于上周六结束，微软Edge、苹果Safari，以及火狐浏览器和骨文 Oracle VirtualBox 被攻破，研究人员总共拿到26.7万美元的奖金，远不足本次由微软、VMware和ZDI提供的奖金池——200万美元。同样，也远不及前几届拿走的奖金。2017年83.3万，2016年46万，和2015年的55.25万美元。缺少了中国军团的Pwn2Own，这项经典黑客大赛的前途黯淡呀！


>> 特朗普政府一年来，获得了对克姆林宫持软弱态度的名声，哪怕后者入侵美国大选、在社交网络上用水军影响舆论等行为已经逐渐清晰。但最近事态有所变化。上周四，美国财政部宣布一项新的制裁，针对俄罗斯公民、官员和机构，共19个人和五个组织，包括互联网研究局ISA和俄罗斯军事情报机构GRU。前者在社交网络上控制舆论，后者则应为入侵总统大选系统和NotPetya恶意软件的爆发负责。



>> 一种可供警方和政府使用的苹果手机破解工具——GrayKey（灰钥匙），引起隐私保护人士的担心。该工具可破解iPhone的锁屏密码进入手机。目前以两种形式提供：互联网模式1.5万美元，300次的使用限制；线下模式3万美元，无使用限制。GrayKey是一个内部包含着一对光缆连接器的小盒子， 插到iPhone上之后，两小时到三天（看密码的长度）的时间，便可解锁手机，获得手机上的内容和数据。
