# 真观奖：百位市场总监选出中国网络安全十大影响力品牌

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651080892&idx=1&sn=9bda6263a2b2959b6d0140c858e9323f&chksm=bd14f86f8a6371796b8e1c5d8d22fecc263b9aac5a1baf740c4082ad9bde123ca9160ed76827&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651080892&idx=1&sn=9bda6263a2b2959b6d0140c858e9323f&chksm=bd14f86f8a6371796b8e1c5d8d22fecc263b9aac5a1baf740c4082ad9bde123ca9160ed76827&scene=27#wechat_redirect)

“2018年度中国网络安全十大影响力品牌：真观奖”（TVA, True Views Award）评选活动，今日落下帷幕。

 

![](../Images/0741e38c425539bf56a4aa86ce9668fe.png)

  

**本次评选活动有四大特性：公益；公平；真实；专业**。安全牛邀请了一百多家公司的安全市场总监，或负责相关事务的高管。不管企业具备多大的规模，仅限一人投票。而且采用了实名入群、群内远程投票+现场投票的机制，保证了每家企业只有一人具备投票权，无法拉票、防止水军、杜绝刷票的种种投票弊端。  

 

众所周知，一个企业的品牌影响力，最重要的策划和推广者就是负责企业品牌的市场人员。如同奥斯卡奖，是由演员、导演、电影学院教授等专业电影人投票，而不是观众。将投票人的身份限制为专业人员并且实名，从而保证评选结果的严肃性和专业性。更为重要的是，本次活动为公益性活动，活动组织者不从中赚取任何经济利益。

 

本次活动的创意，缘于业内各种评奖活动的种种弊端。买奖成为行规，拉票成为标准，刷票成为潜规则。种种弊端，模糊了大家的眼睛，影响正常的判断，最终导致“劣币驱逐良币”的现象一再上演。而对于非常自信的公司，也会存在一个“自已眼中的自己，和别人眼中的自己”的主观与客观差异的问题。安全牛试图通过这样一个公益性活动，为真正有影响力的品牌正名，呼吁业界的“清流之风”。

  

最后，特别感谢参加此次投票活动的市场人员、高管、专家和媒体老师，因为在评选结果出来之前，没人知道自家企业是否能获奖，只是因为看重此次活动的精神意义，才选择在百忙之中牺牲个人或工作时间进行长达数个小时的关注和投票，并且以实名支持。感谢你们！  

 

经过100多位网络安全企业的市场总监、高管，互联网公司和业内的安全专家，和绝大部分安全知名媒体人的现场投票和远程投票，结果如下：
