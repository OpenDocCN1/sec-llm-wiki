CISP大数据安全、云安全专业培训正式开班

昨日，安恒信息联合中国信息安全测评中心（简称“国测”）宣布，注册大数据安全分析师（CISP Big Data Security Analyst，简称CISP-BDSA）和注册云安全工程师（CISP Cloud Security Engineer，简称CISP-CSE）认证培训班在北京正式开班。

 


在2018年中国信息安全从业人员现场调查中，职业教育已经取代自我学习成为信息安全人才能力成长的首选方式。据统计目前CISP已经成为国内知名度最高、最受认可的信息安全从业人员的资质认证之一。

 

中国信息安全测评中心自2002年正式推出信息安全培训资质以来，经过15年的培训运营形成了三个体系：系统的培训知识体系、面向全国的授权培训体系、多样化的培训专业方向体系。安恒目前是CISP-BDSA、CISP-CSE培训的授权运营机构。

 

随着基础设施发生巨大转变，安全问题也更加成为制约大数据平台，云计算平台落地主要问题，对于专业信息安全人才渴求在云平台大数据规划过程，也体现的非常明显。为了满足我国在云计算、大数据发展过程中的特点，通过一种社会普遍认可的安全认证体系，成为当下急需。


 

杭州安恒信息技术股份有限公司 首席安全官 刘志乐表示“大数据安全，云计算已经成为信息安全发展趋势，云技术已经成为网络安全新高度。如何在繁多的大数据中精确地发现、解决、指导工作，是企业信息安全注册工程师急需培养的素质及能力。安恒凭借多年的行业经验及技术积累与国家测评中心成熟的认证体系相结合，推出了国内第一批专业系统化的安全培训”

 

面对未来网络安全的碎片化，攻击威胁的多样性，各企业的信息安全从业人员如何能准确的了解企业安全风险，精确判断所采购安全服务及产品的适用性，这需要信息安全从业者不仅要宏观管理，还需要纵深学习，真正的做到企业信息安全的保护中心。

 

安恒本次开班注册大数据安全分析师和注册云安全工程师，以及即将开班的工控安全工程师，仅是信息安全领域中的一小部分，据安全牛网络安全行业全景图2018上半年显示，安全行业可以细分到64个细分领域，每一细分领域中的领先安全厂商都具备丰富行业经验累积及技术优势。技术的传播及升级需要安全厂商担负起传道授业的职责，更需要国家机构的大力支持和规范制定。国家的重视和需求爆发式的增长，使得各安全细分领域的认证培训，成为未来发展的主要方向。



文尾介绍：

 

安恒将信息安全从业人员的认证细分到工业控制系统安全、云安全和大数据安全等新兴安全领域，在业界尚属首次，也是对业界热点安全人才需求的及时回应。从四年前成立安恒信息网络空间安全学院，到与国内十所顶级高校联合建设实训基地，再到目前推出网络安全的认证培训体系。安恒信息始终在身体力行地探索国内网络安全人才培养体系的建设。

 

注册大数据安全分析师（CISP-BDSA）

 

CISP-BDSA是对我国大数据安全分析人员进行资质评定的重要形式之一。持证人员掌握涵盖大数据概述和分析过程、数据分析算法原理和示例、大数据系统工程实现、大数据安全分析常见案例、大数据系统安全法律法规等知识内容，具备大数据安全分析理论基础和实践能力，可从事大数据安全分析、安全管理等工作。

 

注册云安全工程师（CISP-CSE）

 

CISP-CSE是对我国云计算安全技术人员进行资质评定的重要形式之一。持证人员掌握云计算体系架构及关键技术、云计算安全威胁与需求分析、云计算安全技术、云计算安全防护应用、云计算安全管理、云安全政策法规与标准规范等知识内容，具备从事云计算安全规划和系统运维等安全工作的技能，可从事云计算安全设计、服务、运维、安全管理等工作。
