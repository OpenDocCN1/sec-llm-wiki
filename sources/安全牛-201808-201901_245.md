# 如何在50秒内盗走一辆特斯拉

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651080045&idx=2&sn=0dd4c44fdad5e8c2b2566ac495cd8c3b&chksm=bd14f5be8a637ca837eb08340182c9192d3600352265f1625d802879858f1c1ca2562a44f28c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651080045&idx=2&sn=0dd4c44fdad5e8c2b2566ac495cd8c3b&chksm=bd14f5be8a637ca837eb08340182c9192d3600352265f1625d802879858f1c1ca2562a44f28c&scene=27#wechat_redirect)

敬告特斯拉车主：如果你尚未开启 PIN to Drive 安全功能，就只能期望贴出拍下窃贼快速盗走特斯拉 Modle S 的监控录像能敦促相关方面帮你找回爱车了。

  

📹 [https://v.qq.com/iframe/preview.html?width=500&height=375&auto=0&vid=o0766n9kidb](https://v.qq.com/iframe/preview.html?width=500&height=375&auto=0&vid=o0766n9kidb)

  

被盗特斯拉 Model S 车主名叫安东尼·肯尼迪( Antony Kennedy )，拿到了记录下爱车被劫过程的监控录像。其中一名罪犯似乎用平板电脑在他位于英格兰埃塞克斯的家附近捕捉车钥匙的信号。另一名罪犯则拿着手机蹲守在车门旁。该接力攻击只花了50秒就成功诱骗“聪明”的特斯拉 Model S 误以为车主就拿着车钥匙站在车门旁，然后打开了车门。

  

事实上，这俩高科技窃贼花在研究如何拔下充电电缆上的时间比实施接力攻击盗得汽车还长。

  

肯尼迪称，他贴出这段视频是要打脸特斯拉论坛上那些不相信他车是以这种方式被盗的人。

  

车被盗后，他第一个电话不是打给警局，而是呼叫了特斯拉客服，希望该公司能帮他找回自己的爱车。因为应用了GPS跟踪技术，特斯拉据称在2016年找回了所有被盗车辆。但在此案中，特斯拉连那辆 Model S 的边都摸不着。Kennedy表示，特斯拉什么都做不了，那辆车就是掉线了，或许是SIM卡被拔掉或者被屏蔽了(使用eSIM而不是实体SIM卡可能是个更好的选择)。

  

2小时后他联系了埃塞克斯警方，交出了他的监控录像和他从Facebook上找到的另一个人也被这俩偷车贼侵害的信息。肯尼迪对警察甚至都没回电话感到十分着急。他认为自己的特斯拉现在没准儿已经在运往欧洲的集装箱里了。

  

与在肯尼迪案中的表现不同，警方实际上介入了NBA密尔沃基雄鹿队副总裁阿列克斯·拉丝里( Alex Lasry )在雄鹿队主场揭幕战当天弄丢他特斯拉 Model X 的案件。 密尔沃基警方表示，窃贼“不知如何”拿到了钥匙，但鉴于拉丝里对该案未置一词，目前尚不清楚窃贼到底是黑掉了车钥匙还是拿到了车钥匙。无论如何，警方追缉之后，雄鹿队副总裁被盗的特斯拉最终是找回来了。

  

黑客2秒克隆特斯拉 Model S 遥控钥匙的新闻热炒一波之后，特斯拉提醒媒体：我们早就发布过 PIN to Drive 功能。即便窃贼成功打开了特斯拉车门，不在中心控制台触摸屏上输入PIN码，车也是开不走的。肯尼迪也承认，他确实没设置  PIN to Drive 功能。

  

“

 

马斯克先生，我的特斯拉今天早晨被盗了，偷车贼不过是用一台平板和一部手机扩展了我放在屋后的车钥匙信号覆盖范围。我知道我应该启用PIN访问功能。但我希望偷车贼能不能别这么简单就禁用了远程访问。我现在既不能追踪也冻结不了我的车了。

  

如果你的车有免钥匙进入功能，而你又没有信号屏蔽袋，那不妨走回老一套，将钥匙放冰箱里，那可是个大号的法拉第电磁屏蔽笼，不会让任何一丝丝信号进出的。
