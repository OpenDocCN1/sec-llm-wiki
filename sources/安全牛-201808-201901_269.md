# IBM发布一系列安全、AI及云项目

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651079915&idx=3&sn=0de07bcf0a8995bfb063bdf405b59270&chksm=bd14f4388a637d2e82b22ae63b0e001e4c304d6d75e7bd0c18b0d9eb2840a441e6d5cb5acd98&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651079915&idx=3&sn=0de07bcf0a8995bfb063bdf405b59270&chksm=bd14f4388a637d2e82b22ae63b0e001e4c304d6d75e7bd0c18b0d9eb2840a441e6d5cb5acd98&scene=27#wechat_redirect)

为鼓励涌现更多开放平台，进一步巩固其作为开放提供商的形象定位，IBM本月发布了其新的安全连接( Security Connect )、多云管理器( MultiCloud Manager )和 AI OpenScale 平台，囊括安全、云及人工智能(AI)领域。

  

![](../Images/401f5b52725ed160190362fa7aa3b47b.png)

  

IBM AI OpenScale 是一个可使公司企业在IBM云上使用多个AI框架的新平台，兼容TensorFlow、AWS SageMaker、AzureML及其他AI框架。另外，AI OpenScale 还有个用AI构建新AI模型的系统。IBM MultiCloud Manager 则是为帮助公司企业跨多个云提供商自动化及管理工作负载的新服务。最后，IBM Security Connect 则提供基于云的平台来集成多个安全工具。

  

IBM Security Connect 总监 Jason Corbin 称：

  

“

 

IBM Security Connect 将是我们用以交付新云产品和完善现有IBM安全产品组合的核心云平台。不仅如此，IBM Security Connect 还对合作伙伴及客户开放，可以连接他们的数据存储仓库，甚至打造能访问联合分析和跨IBM及第三方安全产品搜索数据的集成应用。

  

Corbin称，IBM Security Connect 是个社区平台，公司企业可在其上开发应用，利用平台自带的服务进行搜索和分析。它还有后端数据集成，以预构建的实时连接器连接多个数据源。

  

发布会上，Corbin表示已有16家公司致力于开放数据流或开发适用IBM Security Connect 的应用及解决方案。IBM Security Connect 平台不需要QRader或其他任意IBM产品，可以接入任何安全信息与事件管理系统(SIEM)，比如Splunk、迈克菲和 ELK Stack。

  

IBM Security Connect 就是为了让应用能仅需接入该平台便可与其他任意应用集成。该设计目的可通过数据共享和能自动添加上下文的通用共享服务实现。

  

IBM还做了个目录，可以将多个应用归集为一个解决方案，以及为工作流中的用户推荐其他应用或功能。举个例子，当威胁研究人员调查某个漏洞时，IBM可以将自身多个漏洞服务甚或合作伙伴加以集成，比如Qualys或Tenable。IBM可以建议使用 Security Connect 用户界面中出现的功能，用户无需再转向其他市场便可立即使用这些功能。

  

Security Connect 的核心技术之一是  STIX-Shifter 工程。STIX意为结构化威胁信息表达( Structured Threat Information eXpression )，是用于安全共享威胁信息的一种协议。

  

STIX-Shifter能保持从所有 IBM Security 产品和各第三方产品中收到的数据的一致性。通过提供同一个通用API的通用服务，IBM如今可以跨任意数据源查询数据，无论数据源是产品还是存储仓库，并收获同样的数据投入分析和搜索中。

  

**MultiCloud Manager**

  

Security Connect 是开放IBM云以驱动多种安全服务，IBM MultiCloud Manger 服务器则是要开放IBM以外的云，用以支持多云管理。

  

IBM MultiCloud Manger 运行在基于Kubernetes的 IBM Cloud Private 平台上。其目标是令公司企业能够在 IBM Cloud、AWS和微软Azure上执行云工作负载。

  

IBM MultiCloud Manager 采用开源方法跨云管理数据和应用，令公司企业能够扩展其多个云投资，完全释放出云的商业价值。公司企业也因此而超越租用计算能力的生产力经济，发展到完全利用云来开发新商业过程和进入新市场的阶段。

  

**AI OpenScale**

  

**AI面临的难题之一，是公司企业可能被锁定到某个特定的模型或平台上**。IBM 推出 AI OpenScale 的目的就是要通过令Watson、TensorFlow、Keras、SparkML。Seldon、AWS SageMaker、AzureML和其他框架协同运行，而让AI更加开放。

  

AI OpenScale 还有另一种效果：令AI模型能以多种不同格式输出，提供某种形式上的AI兼容性。

  

对 AI OpenScale 来说，AI的出品商、构建方式和运行位置都不重要，AI OpenScale 可以让它们统统可信且透明，还能切实检测AI的偏好问题，在运行时自动修正偏好。

  

除了接受已有的AI模型，IBM还推出了名为 NeuNetS 的AI自动化引擎。该引擎名是个缩略词，完整形式是 Neural Network Synthesis，意为神经网络综合体，可自动为用户构建AI模型。

  

输入一个数据集，NeuNetS就能为用户定制一个神经网络出来。这就是AI构建AI，因为IBM的算法会学习怎样设计神经网络。
