1. 安全活动  ISC 2018

ISC2018大会本周于北京召开，这已经是ISC第六届大会。本次大会包括了多场大型现场活动，60多家支持单位，80多家参展商，30多个主题论坛和270余项议题，以及前所未有的观众数量，多项参会指标突破历史记录。

 

2. 周鸿祎  安全大脑

在ISC 2018大会上，周鸿袆、齐向东、吴云坤三名大咖分享了关于安全大脑、360发展以及智慧城市三个方面的看法与观点。

 

3. 安全活动  CSS 2018

8月27日，第四届互联网安全领袖峰会（CSS2018）在京举行。峰会的主题是“安全强驱动 数字新生态”，探讨了企业在如今的合规、数字转型等压力下的网络安全策略。

 


4. 安全活动  CSS 2018

8月28日，第四届CSS互联网安全领袖峰会第二日，AE50（网络安全产学研协同育人联席会）成立。致力于将学校与企业合作，培养国内安全人才。

 

5. VPN  融资并购

VPN厂商AnchorFree融资2.95亿美元，总融资额接近3.58亿美元。AnchorFree为客户的移动设备提供企业级的隐私和安全保护，防御身份信息泄露、不安全公共Wi-Fi、钓鱼和恶意软件等攻击行为。

6. 国家安全  法律法规

 美国众议院于9月5日通过一项两党法案《2018网络威慑与响应法案》，旨在阻止和制裁未来国家支持的针对美国的网络攻击，以保护美国的政治、经济和关键基础设施免受侵害。


7. 政务安全  病毒

2018年9月3日，360安全卫士接到自然资源部、省国土资源厅紧急通知，山东多地不动产登记系统遭到病毒入侵，目前已波及山东10个市，不动产登记系统因此无法正常使用，山东多地发布暂停受理不动产业务登记的通告。


8. 安全竞赛 法律法规

中央网信办发布《关于规范促进网络安全赛事的通知》，旨在提升企业，高校与各地方网络安全赛事的专业水准以及确保赛事带来的安全与教育效应；并对赛事和会议的冠名做了规定。

 


9. 在线反欺诈  刷量  

2018年8月24日，国内首例因视频网站（爱奇艺）“刷量”而引发的不正当竞争案件在上海市徐汇区人民法院公开开庭审理，并对该案进行一审判决；视频刷量者被判不正当竞争 ，通过共同实施技术手段针对特定视频制造不下9.5亿余次的虚假访问，损害视频网站公司以及消费者的合法权益，爱奇艺视频网站获赔50万元。


 

10. 漏洞补丁  Wireshark

网络协议分析神器Wireshark暴露严重漏洞，可能会被攻击者利用产生系统崩溃。Wireshark团队已经承认并且修复了这些漏洞。Wireshark 的用户应将其软件版本更新到版本 2.6.3、2.4.9、2.2.17 或更高版本，以保护自己免受漏洞利用的风险。

 

11. 漏洞补丁  传真机

CheckPoint研究发现：攻击者可以利用传真机漏洞渗透进入企业内网。

 

12. 黑客攻击

安徽90后“黑客”为出名自学黑客技术后，入侵137台电脑，获取公民信息近一万条；被判有期徒刑3年，缓刑5年。

 

13. 内部威胁  今日头条

前今日头条员工跳槽后在技术后台留下后门，利用技术手段复活并倒卖废弃账号非法牟利两百余万元。
