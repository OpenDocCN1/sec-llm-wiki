2019全球加密趋势：61%的机构头疼加密密钥管理

nCipher Security 《2019全球加密趋势》报告指出，加密技术的部署工作仍是近半数公司企业的 “重大挑战”，61%的公司企业非常头疼加密密钥管理。



但更头疼的是，54%的受访公司企业都认为员工失误很大程度上是敏感数据泄露最有可能的原因，超过黑客威胁(30%)和内鬼(21%)。


难在哪里？


首先，69%的受访者将数据发现列为执行数据加密策略的最大挑战。


加密趋势报告：德国人干得漂亮


德国的企业加密策略覆盖面最广(67%)，排第二的是美国(65%)，英国受访者中有半数称自家公司具备加密策略。


随着需加密的数据越来越多，近2/3的受访者部署了6个以上的产品进行数据加密，73%的受访者认为策略实施是加密解决方案最为重要的功能。


nCipher Security 的报告中写道：


“

云数据保护要求继续成为数据加密的驱动力，公共云和私有云加密用例增长超过2018年水平，公司企业越来越重视跨内部环境和云端的解决方案。


nCipher Security 是一家英国公司，最近刚从Thales公司剥离，并在Thales与Gemalto合并前卖给了美国的 Entrust Datacard。


半数企业内部运营硬件安全模块


nCipher Security 提供安全存储加密密钥的硬件安全模块(HSM)，称HSM用例年同比增长率从2018年的41%增至47%，创历史新高，表明具更高信任水平的抗篡改环境市场变得更加广阔。


随着公共云提供商代表客户大力推进HSM管理，报告发现37%的受访者租用云提供商的HSM。但大多数仍在企业内部维护自己的HSM。


密钥管理是英国企业一个特别的痛点，法国受这个问题的影响最小。


调查数据显示，法国受密钥管理问题影响最小的主要原因是他们似乎不缺这方面专业人才。


“

在 ‘专业人才缺乏’ 作为密钥管理痛点主要原因的比率上，法国(31%)仅为全球平均比率(62%)的一半，是受访14个国家/地区中最低的。还有其他一些指标，比如使用的加密产品种类较少，以及大数据加密和IoT加密之类密钥管理技术尚不成熟的用例也相对较少。这些因素都能减轻密钥管理之痛。


但技术人才缺乏还是密钥管理痛点的最直接因素。


加密什么？


支付相关的数据和金融记录是最有可能被加密的。对14个国家/地区5,856人所做的调查显示，加密可能性最低的是医疗健康相关信息。
