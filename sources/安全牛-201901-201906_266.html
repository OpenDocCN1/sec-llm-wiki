CCSP云安全专家认证是什么？


两家国际顶尖的安全组织,云安全联盟Cloud Security Alliance与 (ISC)²，在2015年合作开发了一项全新的国际云安全从业人员认证，即CCSP  Certified Cloud Security Professional，(ISC)²注册云安全专家认证。


CCSP 建立在(ISC)²的CISSP信息安全专家认证和 CSA 的CCSK云安全教育计划之上，融合了更深层次的信息安全与云计算实践经验知识，反映最新和全面的云计算环境防护与优化最佳实践，可验证那些日常工作涉及云安全架构、设计、运营和服务编排的专业人士的实用技能知识。



CCSP 认证考试概述



CCSP认证考试涵盖CBK六个知识域内容和权重如下所示：


  1. 知识域1：架构概念和设计要求

  2. 知识域2：云数据安全

  3. 知识域3：云平台和基础架构安全

  4. 知识域4：云应用安全

  5. 知识域5：（云服务商及云数据中心）运营

  6. 知识域6：法律与合规

 

（ISC）2规定申请CCSP认证的资格和要求如下：


  1. 累积至少五年全职带薪的IT从业经验，其中三年必须工作在信息安全领域，并在CCSP考试的六个知识域之一具有一年工作经验；

  2. 获得云安全联盟的CCSK证书，可取代CCSP考试六个知识域之一的一年经验；

  3. 获得CISSP证书，可取代CCSP认证申请对工作经验的要求。



考试方式：


Ø 考试类型：125道单选题，（含拖图）

Ø 考试语言：英文（无中文可选）

Ø 考试时间：240分钟

Ø 考试中心：Pearson VUE Testing Center  

Ø 及格分数：700（满分1000分）



获得CCSP认证对于个人的益处



  1. 不仅可以展示国际公认的高级云安全专业知识，更能体现解决云环境安全问题的实践经验与能力；

  2. 提升专业知识可信度和竞争力，成为炙手可热的国际云安全专业人才，在同行中脱颖而出；

  3. 证实个人对于云安全行业的持续承诺，当前和未来均能理解和应用最佳安全实践于云环境；

  4. 成为 (ISC)²组织一分子，可获得宝贵的职业发展资源，如广结优质人脉、持续教育；
