# 两款免费工控安全工具发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651082874&idx=3&sn=372667803b81172e9151cb5c66e5d3f6&chksm=bd14e0a98a6369bfc30506027172856ee8b15b739a3317ce12a2e23b08baf39c2c9e44889543&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651082874&idx=3&sn=372667803b81172e9151cb5c66e5d3f6&chksm=bd14e0a98a6369bfc30506027172856ee8b15b739a3317ce12a2e23b08baf39c2c9e44889543&scene=27#wechat_redirect)

工业网络安全公司 Dragos Inc. 发布两款免费工业控制系统(ICS)资产发现工具。这两款工具名为Cyberlens和Integrity，之前是需要付费的商业软件。

  

![](../Images/2be9617e3596ef0a037f490b127525ee.png)

  

两款工具功能强大，可提供工业资产识别、ICS网络及数据流虚拟化，以及对 ModbusTCP、DNP3、EthernetIP、BacNet 和 OPC UA 等ICS产品的基本深度包检测功能。

  

Dragos Inc.于本周并购了行业对手NexDefense，并购金额未公开，但组合了两家公司开发的工具，推出了本次免费工具发布。  

  

如今，Dragos平台上更强大的商业功能已取代了这两款工具。

  

**工业网络安全：免费工具对小公司很有用**

  

3月18日发布的博客文章中，Dragos称：大多数企业级软件对小公司和市民而言太过昂贵，即便是基础版也负担不起。收购NexDefense并免费释出CyberLens和Integrity两款ICS网络安全工具，可帮助相关行业执行基本的资产发现任务。

  

“

对很多公司企业和市民来说，这些工具是他们开始保护自身环境的有力帮手。NexDefense Integrity如今变身免费社区版工具，提供安全、持续的被动ICS网络及资产发现。

  

Integrity最初于2012年由爱达荷国家实验室(INL)开发，当时名为“Sophia”，后来定名Integrity。该工具曾杀入RSA大会创新沙箱决赛，被《网络防御杂志》评为最佳网络安全解决方案，受到广泛认可。

  

CyberLens是Dragos创始人 Justin Cavinee、Jon Lavender 和 Robert Lee 还受雇于美国国防部时，获准在业余时间开发的一款被动ICS资产识别和可视化工具。

  

“

Integrity的技术放入Dragos平台没有任何意义，Dragos技术的资产识别和威胁检测功能已经远远超越了Integrity，但很多ICS社区成员永远入手不了专业付费产品。
