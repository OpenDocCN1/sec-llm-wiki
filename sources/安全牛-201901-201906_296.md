# 雷克萨斯、丰田、福特和保时捷无钥匙汽车系统安全性糟糕

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651082836&idx=1&sn=5cbe6347bd9702c4e2288f19e85b2b77&chksm=bd14e0878a63699104f59c729ce99fbb60adc46e3d35420d022f8dc18eb9aa32bf3a62be865f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651082836&idx=1&sn=5cbe6347bd9702c4e2288f19e85b2b77&chksm=bd14e0878a63699104f59c729ce99fbb60adc46e3d35420d022f8dc18eb9aa32bf3a62be865f&scene=27#wechat_redirect)

Thatham研究团队的专家认为，捷豹，奥迪，梅赛德斯和路虎具有“优越”的安全性。

  

![](../Images/08d88b32d99a1abc48cccff201117c77.png)

 

经过Thatcham Research的专家测试，雷克萨斯、丰田、福特和保时捷汽车的无钥匙汽车安全系统被贴上了“差”的标签。铃木吉姆尼的安全性如此糟糕，以至于给Thatcham给出的评定为“不可接受”。

 

安全性差的车辆，容易受到中继攻击，小偷可以利用无线设备激活汽车的远程中央锁定键，然后打开车门，将汽车开走。

 

Thatcham的最新研究结果是基于对十一款新车辆测试，为了对汽车安全提供更好的指导，该公司推出了新的评级系统。传统上，关于汽车安全人们关注的是安全系统，而不是汽车。

 

该团队评估的11款车型中，有6款被评为“差”。其中价值1.5万英镑的铃木吉姆尼排名垫底，安全级别为“不可接受”。吉姆尼是测试车辆中最便宜的车，可以选择是否配备无钥匙启动。然而，即使是一些昂贵，豪华的汽车也未能通过Thatcham的测试。

 

安全性差的汽车包括福特蒙迪欧(起价21495英镑)、现代Nexo(起价69,495英镑——这不是打字错误)、起亚ProCeed(售价23,835英镑)、雷克萨斯UX(售价29,900英镑)、保时捷Macan(售价46,344英镑)和丰田花冠(售价21,300英镑)。

 

虽然铃木吉姆尼排名垫底，但它的无钥匙启动是一个可选项，买家可以选择不配备该功能。然而，Thatcham发现它的安全性“**严重违反了所有标准**”，并且没有满足消费者有权期待的“基本安全特性”。

 

不过，有四辆车达到了“优秀”的安全等级。它们分别是奥迪e-tron、捷豹XE、路虎Evoque和梅赛德斯B级。

  

![](../Images/d6ca18351d4f98f6549073a625e70a57.png)

  

他们优秀的安全等级是公司对近年来发布的研究结果进行积极响应的结果，这些研究对无钥匙进入和启动系统的安全漏洞进行了警告，并采取一些措施减少受到中继攻击的风险。

 

Thatcham首席技术官Richard Billyeald 警告道：市场上出现了太多汽车在几秒内就从车道上被偷走的例子。现在，根据新的Thatcham研究安全评级进行评估，**任意具有易受攻击的无钥匙进入/启动系统的车辆，都将必然无法达到最佳评级**。

 

“

自20世纪90年代初，车辆犯罪达到顶峰以来，安全措施已经取得了很大的进步。但是，当犯罪分子可以利用数字设备绕过这些安全措施时，多年积累的安全措施将没有任何价值。遗憾的是，如果他们的无钥匙进入/启动系统不容易受到中继攻击的影响，大多数被评为‘差’的汽车至少会获得‘良好’评级。

  

Thatcham Research对汽车安全系统进行测试和评级，其研究结果会被英国保险业使用。该公司目前对汽车的安全性进行了评级，而不仅仅是第三方警报和防盗系统。评定结果有5个等级，分别为：“优秀”，“良好”，“一般”;“差”和“不可接受”。Thatcham的测试和评级几乎肯定会影响保险费率。

 

针对汽车无钥匙系统的中继攻击并不是什么新鲜事，但最近汽车盗窃案件的增加突显了这一威胁。
