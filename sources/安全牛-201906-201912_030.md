# 警方查抄装载黑客工具的监视车

今年早些时候，这位以色列车主展示了如何利用自己监视车上的黑客工具来黑掉任意智能手机。

  

若说有什么事是能危害到网络安全专家的，那必须是炫耀。当然，每个人都有炫耀的权利，但行使这项权利却有可能让你惹上麻烦——即便你是黑客大牛凯文·米特尼克 (Kevin Mitnick)。

  

身为监视公司 Circles Technologies 共同创始人的以色列情报专家 Tal Dilian，最近就因为炫耀了自己装载 900 万美元监视设备的厢型车而官司缠身。

  

据美联社报道，塞浦路斯警方顺手查抄了该车，开始调查此车是否用于监视他人而侵犯隐私权。车主本人也受到了盘问，但目前尚未得出任何结论。

  

该车的功能包括随时随地黑进任意加密级别的智能手机，正如 Tal 此前向《福布斯》展示的一样。而正是这一炫耀行为最终引起了塞浦路斯警方的注意。

  

Tal 迫使模拟目标的华为手机连接其 WiFi 集线器，以此黑进目标设备，悄悄安装上监视软件。过程中无需受害者任何互动操作。在车里，受害者手机上的 WhatsApp 消息发出几秒后，Dilian 面前的监视器上出现了同样的消息。

  

然而，该车有趣而充满争议的部分却并非上文描述的那些。Tal 宣称，该车上的工具可用于监视社会危险分子，比如恐怖分子；但真相却是，这些工具也可用来针对法律界人士，比如记者、政客和社会活动家。

  

事实上，伊斯坦布尔沙特领事馆卡舒齐谋杀案就非常有可能通过名为 Pegasus 的 iPhone 间谍软件实施。但这不过一起事件，且不同于 Tal 的监视车，为什么他要接受调查呢？无风不起浪。Pegasus 是 NSO Group 出品的程序，该公司于 2014 年与 Tal 的公司合并，即使 Tal 矢口否认参与了该起事件，二者之间的联系也是真实存在的。

  

无论如何，目前调查结果未出，不知道会对 Tal 现在的公司 Intellexa 产生什么影响。此类技术已经带来实际伤害的事实早已不是秘密，但到底是谁的责任却仍有待商榷。是提供这些技术的公司？还是向这些公司购买技术的政府？

  

因此，这仍是一个有待解决的问题，且在解决之前此类事件还会持续发生，毕竟这一行业的名声真算不上好。
