黑客最爱：Kali增添重要新功能

Kali Linux（主要被各色帽子黑客用于渗透测试、网络安全评估和其他安全探索的 Linux 发行版）有了全新工具集。



Kali Linux 2019.4 是 2019 年最终版本。该黑客最爱工具为用户呈现几个相当重要的新特性。下面我们就列举几个。


Kali Linux 2019.4 新特性


1. 再见 Gnome，你好 Xfce


该最新迭代用 Xfce 替换了其主要桌面环境 Gnome，尽管用户喜欢的话可以保留一个略有变动的 Gnome。


但正如 Kali Linux 在 11 月 27 日的博客中声明的：Gnome 对于大多数 Kali 用户而言太过臃肿，很多用户只想要一个能同时运行多个终端窗口的窗口管理器，以及一个 Web 浏览器。


新的 Xfce 用户界面 (UI) 是可运行于各层级 Kali 安装上的轻量级 UI。其功用在于无需变动即可处理普通用户的各种需求。该界面采用大众熟悉的标准 UI 概念以确保毫无学习曲线。且其现代 UI 元素充分运用屏幕空间，外观十分精美。


该团队还创建了名为 “Kali Undercover”（Kali 卧底）的 Kali 主题，乍看之下很像 Windows。


2. 走安卓路的 Kali（某种程度上……）


名为 NetHunter Kex 的新功能使用户可在 HDMI 输出上连接安卓设备，还可使用蓝牙键盘和鼠标，在安卓智能手机上获得 “完整无删减的 Kali 桌面”。


Kali Linux 团队称：只要手机性能够强大，这就好像一台恰好能装进口袋的全功能便携式 ARM 台式机。您以此进行安全评估的潜在利用方式很多。


3. BTRFS


Kali Linux 文档中新增将 BTRFS 用作根文件系统的内容，赋予用户在升级后回滚文件系统的能力。


BTRFS 是个写入时复制 (CoW) 的文件系统，旨在解决 Linux 文件系统中缺乏缓冲、快照、校验和及集成多设备跨越的问题。各大公司均对其代码库有所贡献，包括 Facebook、Red Hat、Oracle SUSE 等。


“

在虚拟机里尝试新东西的时候，往往会做个快照，万一问题时可以简单回滚到已知良好状态。但在裸机上运行 Kali 就没那么容易做到这一点了。你要么超级小心谨慎，要么一旦出问题就陷入无尽的手动清理中。但有了 BTRFS，即便在裸机安装上都可享有同样的快照功能！


4. Powershell



团队还标出了直接在 Kali 上执行 PowerShell 脚本的功能，尽管该功能似乎去年 6 月就已引入。


PowerShell 是跨平台自动化与配置工具，优化处理结构化数据（如JSON、CSV、XML 等）、REST API 和对象模型，包含一个命令行 shell、一个关联脚本语言和一个处理 cmdlet 的框架。


Kali 官方 git 库已于 2019 年 6 月置于 GitLab 上。
