【快讯】趋势科技7000万美元收购云安全公司Cloud Conformity

原文：http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651086397&idx=2&sn=04979d1285e9e1abed8b5cab64c73ba2&chksm=bd14eeee8a6367f83eb6fb79396efdffdf974701c9b3f56668bbf0d296a35591fa861471fa4e&scene=27#wechat_redirect

本周一，趋势科技宣布以 7000 万美元收购云安全公司 Cloud Conformity。



Cloud Conformity 2015 年成立于澳大利亚，致力于云安全态势管理 (CSPM)，为使用亚马逊 AWS、微软 Azure 和谷歌云的组织提供云安全、治理和合规解决方案。Cloud Conformity 预计年收入约在 1600 万美元。本次收购后，趋势科技将保有 Cloud Conformity 的研发和工程师团队，以及超过 100 位客户。


趋势科技首席执行官 Eva Chen 表示，趋势科技多年来一直致力于为云构建整体的安全性。Cloud Conformity 作为 2019 年度 AWS 技术合作伙伴，他们的产品和方案可以完美地补充趋势科技现有的产品组合，并可以立即为客户提供价值。通过收购 Cloud Conformity，趋势科技希望可以扩展其云安全服务类型，特别是基础设施配置错误的检查，并帮助客户确保遵守 PCI DSS、GDPR、HIPAA 等监管标准。
