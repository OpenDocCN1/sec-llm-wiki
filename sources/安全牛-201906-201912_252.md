**从“PK”体系到“PKS”体系**

  

**“PK” 体系**是中国电子主导构建的绿色、开放、共享的技术架构和生态体系。“P” 代表（Phytium）飞腾处理器，是中国电子自主设计兼容 ARM V8 指令集的处理器芯片产品，支持云计算、移动、多核、虚拟化、低功耗、富生态，“K” 代表（Kylin）麒麟操作系统，支持云计算、虚拟化、大数据等先进应用并与飞腾 CPU 深度适配。PK 体系的技术及市场优势主要体现在以下两方面：

  

1\. PK 体系，由中国电子聚合国内产学研领域 400 多家核心企业，共同开展关键技术攻关和公共技术服务，形成丰富的办公和事务处理类应用生态体系。

  

2\. PK 体系目前已可在国家核心领域和部分行业实现对 Wintel 体系的替代，未来随着招标对象的下沉和行业应用场景的打开，优势将被放大，市场份额有望进一步扩大。

  

基于 “PK” 体系的核心优势，本次产业生态大会中又特别提出了 “PKS” 体系，是在 “PK” 体系的原架构基础上加注了 “S” 的安全能力，主要体现在两方面 “可信计算” 和 “网络安全”。

  

1\. 可信计算，中国电子提出业界领先的 “可信计算3.0”，从芯片底层基础硬件做起，实现 CPU 内置可信计算，建立计算和安全防护并存的 CPU 双体系结构，打造基于可信计算的“主动免疫”模式，同时可信计算 3.0 经济性大大提高，可以有效利用 CPU 计算资源的冗余进行扩展，也可以在多核处理器内部实现可信节点。

  

2\. 网络安全，本年 5 月中国电子 37 亿元战略入股奇安信，这意味着奇安信将安全技术与安全人才双向加持中国电子网络安全能力。

  

奇安信集团总裁吴云坤在如何保障 “PKS” 体系安全的问题上谈到**在内生安全中，如何将过程安全和本质安全相结合**的关键点：

  

第一，过程安全是在“防漏洞”，本质安全是在 “堵后门”。PK 体系就是本质安全，在操作系统和 CPU 的最底层将安全能力放进去，同时与应用系统结合。

  

第二，基于 PK 体系来构建的一个强大的防护体系和整体解决方案。

  

第三，安全运行，通过人、技术、数据的相结合保证系统的安全，并能够及时的输出安全保障，如应急响应和处置能力。

  

**中国电子网络安全三大战略**

  

针对网络安全领域存在的芯片 “后门”、网络 “漏洞”、国外 “断供” 等问题，中国电子坚定推进本质安全、过程安全、产业安全三大战略，相应推进三大类型核心技术研发：

  

**1\. “关后门”：****突破基础和通用技术，保障本质安全**

  

中国电子重点布局发展 CPU 芯片，摒弃 “弯道跟随” 的旧模式，创造 “换道超车” 的新模式，通过自主创新和开放创新相结合，研发设计兼容 ARM 指令集的飞腾系列 CPU，成功实现与国际先进水平相当的高性能。

  

**2\. ****“堵漏洞”：发展非对称和杀手锏技术，保障过程安全**

  

中国电子创新实施 “白细胞计划”，以 “主动防御” 代替  “被动防御”， 有效抵御各类未知病毒，利用未知漏洞的攻击，可以智能感知系统运行中存在的安全问题，实现态势感知。

  

**3\. “防断供”：布局前沿和颠覆性技术，保障产业安全**

  

中国电子积极围绕人工智能芯片和新一代存储器技术，在上海布局相关重大产业项目，努力提升我国工业控制核心器件的供应能力。

  

**共建“PK生态村”**

  

中国电子联合国内自主创新产业力量，共同启动 PK 体系生态联盟筹备工作，在海南建设全国首个 “PK生态村”， 为 PK 体系生态联盟提供成熟的孵化平台与发展载体，努力把海南打造成为网络安全产业的战略新高地。
