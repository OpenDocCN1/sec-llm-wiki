# CIO调查：2020下半年IT支出最高优先级是网络安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651091740&idx=2&sn=20d517a3d9af5b84fe83f67c9e646940&chksm=bd14c3cf8a634ad902505754f708f155d424221c669b3d22f2cfcb6cbf18cfe65ae113c2ef17&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651091740&idx=2&sn=20d517a3d9af5b84fe83f67c9e646940&chksm=bd14c3cf8a634ad902505754f708f155d424221c669b3d22f2cfcb6cbf18cfe65ae113c2ef17&scene=27#wechat_redirect)

根据日立（Hitachi）ID近日发布的企业首席信息官（CIO）调查，2020年下半年最高IT支出优先级是网络安全。其中身份和访问管理（IAM）、端点安全和安全意识培训是安全支出的三个重点。

  

  

![](../Images/22a683c00c05069f869e2f0f0ee87b7f.png)

  

这项调查的重点是在冠状病毒大流行之后IT支出的变化，该调查表明，**网络安全是IT领导者在今年余下时间的首要任务**，而接受调查的人中有一半正在增加预算以实现其目标。

  

新冠病毒颠覆了大多数企业的2020年计划，自今年年初以来，有70％的CIO报告其长期优先事项已经发生了变化。现在，有89％的人表示他们专注于网络安全，而82％的人则致力于远程支持。

  

他们的目标反映了这些新的优先事项：86％的CIO表示，他们的目标是提高整个环境的安全标准，而80％的人则希望其技术堆栈对于远程和本地用户更加灵活。此外，75％的CIO表示他们希望保持其IT基础架构和工具堆栈的最新状态。

  

  

**CIO们预计2020年安全预算会增加**

  

尽管一半的受访CIO表示IT预算紧张，总体预计支出不会增加，但另一半的CIO则表示2020年的预算有望增加，以匹配（疫情导致的）IT需求变化。约33％的人预计会增加5％，13％的人预计会增加5-10％，而9％的人预计会增加10％以上。  

  

为了达成网络安全和远程办公支持的IT目标，有**43％的CIO在IAM上进行了投资，超过了排名第二的端点安全（34％）和排名第三的安全意识培训（17％）。**

  

“优先考虑IAM是有道理的。首席信息官已经意识到，大多数黑客不会破坏大门，他们会优先开启已经弄到钥匙的大门，”日立ID首席执行官Kevin Nix说。

  

“不良行为者一直专注于被盗凭证，网络钓鱼攻击和社会工程，特别是新冠疫情大流行迫使如此多的员工远程工作。我们发现正在寻找IAM解决方案的公司存在需求上的紧迫性。**去年，企业可能计划在一两年内采用IAM。现在，他们下个季度就需要它。**”

  

![](../Images/40f627c6340e1b504c4c26cb9e159b1a.png)

  

  

**其他发现**

  

·67％的CIO表示他们更愿意投资于新兴技术。  

  

·在拥有500-1000名员工的公司中，有88％的受访CIO计划投资新兴技术，这是所有规模类别中最多的。在拥有5,000至10,000名员工的公司中，只有45％的CIO计划投资新兴技术，是所有类别中最低的。

  

·87％的CIO会考虑2020年出现的新兴安全技术，而71％的人会考虑新兴的AI和机器学习技术。
