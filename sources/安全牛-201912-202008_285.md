# 调查：新冠疫情如何冲击美国互联网

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651088704&idx=3&sn=eb16d74d1c35d66bc77c4d4e178c220a&chksm=bd14d7938a635e85b7c364cc066f45ffc60afd3a2e111a2910ec49fe2d67f37a242fc20b8fae&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651088704&idx=3&sn=eb16d74d1c35d66bc77c4d4e178c220a&chksm=bd14d7938a635e85b7c364cc066f45ffc60afd3a2e111a2910ec49fe2d67f37a242fc20b8fae&scene=27#wechat_redirect)

根据网络提供商和网络情报公司的数据，受新冠疫情居家令和远程办公影响，美国互联网带宽消耗和潜在的安全漏洞已经显著增加。 

  

根据机器学习网络运营服务提供商Kentik的数据，自从年初以来，随着员工转向远程工作，美国公共互联网流量增长了50%，其中视频会议的增长最大，达到500％。 

  

![](../Images/ed351495c222f35c270c6b5bb13fce20.png)

美国互联网目的地流量指数

  

![](../Images/c224da82800c85ec33e3de0b4619399f.png)

美国视频会议目的地流量指数

  

Kentik首席执行官Avi Freedman指出，总的来说美国的网络提供商已经很好地解决了带宽消耗高峰的问题。 

  

Freedman说：

  

在宽带和传输网络上，今年的首次高峰是通过现有网络容量的过度配置来解决的。这使许多网络进入了加速增长的模式，这也意味着频繁的'微中断'，但并没有导致许多大规模或持续的中断。

  

但是，有迹象表明，面对突发的大规模远程办公很多公司并未做好准备，这使他们的基础架构处于劣势。   

  

使用端口扫描服务Shodan从3月底开始收集的数据表明，在过去的一个月中，暴露公开远程桌面协议（RDP）的系统数量有所增加，这种增加趋势已经持续了两年。

  

![](../Images/5030e86d164abd6a0707c861f2553042.png)

  

同时，根据SANS Institute的数据，3月期间，对最常见的RDP端口的互联网扫描数量激增了40％。

  

  

**家庭互联网流量高峰提前**

  

美国最大的住宅互联网网络运营商Peak Movement Comcast的峰值互联网流量增长了32％（某些市场为60％），而移动数据使用量则增长了24％。此外，通常晚上9点是整个住宅市场的高峰下载时间，但现在这个峰值提前到了7点半，这可能是因为居家办公与居家娱乐之间省去了通勤时间。更有趣的是，尽管确切时间有所不同，但高峰上传时间已从晚上9点更改为工作时间。  

  

自3月1日以来，Comcast的数据显示虚拟专用网（VPN）流量增长了40％，视频会议流量增长了212％。不过Comcast表示这些波动都在其网络能力范围内。

  

  

**远程工作导致“裸奔”台式机开始大幅增长**

  

为了保持业务发展和员工的正常运转，许多公司将台式机暴露于Internet以进行直接连接。RDP是实现此目的的常见但不安全的协议。  

  

从1月到2月，扫描服务Shodan看到暴露的RDP端口（标准3389和备用3388）都有所增加。

  

根据SANS Institute的数据，更多的攻击者也将重点放在协议上。该小组发现RDP来源数量增加了大约40％。

  

SANS技术研究所所长Johannes Ullrich表示：攻击者期望找到更多易受攻击的RDP服务器，因此它们正在扫描更多内容。

  

  

**带宽资源的“贫富不均”**

  

远程办公还暴露了美国城乡社区宽带接入的不平等现象。根据美国《消费者报告》，近四分之一的家庭没有宽带连接，超过400万学童受影响。  

  

总体而言，网络提供商认为，未来保障网络稳定没有问题，但是高速互联网覆盖不均的问题依然存在。

  

Freedman指出：

  

新冠病毒并非人人平等，我们已经看到财富和收入差异的影响，网络接入也是如此，虽然已经联网的用户无需担心，但是考虑到网络覆盖的不均，我们有理由开始担心秋季的远程教育。目前已经有社区在组织开放Wi-Fi，因为对于农村地区以及更多的城市社区来说，宽带的接入质量欠佳。
