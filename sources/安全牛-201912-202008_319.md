# 全球抗疫的数字防线：国际电信联盟推出信息共享平台

国际电信联盟（ITU）启动了一个新的信息共享平台——全球网络弹性平台（Global Network Resiliency Platform ），旨在冠状病毒危机期间帮助保护全球电信网络。

  

全球网络弹性平台将提供资源，帮助政府和私营部门提升网络弹性，同时帮助电信基础设施应对疫情产生的需求波动。

  

国际电联秘书长赵厚麟在3月23日的一份声明中说：

  

电信网络对我们的健康和安全，以及保持我们的经济和社会运转从来没有像今天在新冠肺炎危机期间那样重要。因此，我已指示我的团队立即利用国际电联现有的监管和政策制定者平台来帮助各国和行业应对全球网络日益增加的压力。

  

该平台将为决策者，监管机构和行业利益相关者提供“最佳实践和举措”，以确保网络和电信服务在危机期间尽可能正常地运行。  

  

赵厚麟表示，全球网络弹性平台一开始主要提供信息源服务，后继将逐步提供交互性功能。

  

  

**全球分享**

  

作为致力于加强全球信息和通信技术（ICT）基础设施的联合国机构，国际电联呼吁在以下领域参与制定或实施政策、监管措施的任何人分享他们的发现：  

  

·应急准备

·宽带可用性，可负担性和可访问性

·服务质量和经验

·消费者保护

·通用服务策略

  

  

全球网络弹性平台上已有的功能包括巴基斯坦电信管理局使用智能手机技术跟踪新冠肺炎患者的项目，以及VEON决定将10个国家/地区的所有紧急医疗保健和外交事务热线和网站的费率归零。

  

赵厚麟表示，这些资源“将使那些仍有时间的国家有机会学习其他疫区正在做的事情”。

  

  

**保护家庭网络**

  

围绕远程办公爆炸式增长的安全问题，国际电联的全球网络弹性平台已与互联网协会有关远程办公安全指南关联。  

  

目前，全球约有9亿人处于隔离状态，越来越多的公民正在依靠国内电信网络进行远程办公，与亲人保持联系，及时了解最新的政府建议并自娱自乐。

  

医生们也正在转向远程会诊，小学生转向在线学习资源，餐馆转向在线订单交付，这进一步加剧了信息通信技术基础设施的紧张。

  

上周，特朗普政府宣布已请求联邦机构提供紧急资金，其中包括电话会议、虚拟专用网（VPN）和网络安全升级的准备金。

  

当然，冠状病毒大流行不仅引起了网络安全的担忧，网络负载也不堪重负：根据网络服务公司Ookla的数据，互联网速度在全球许多受影响的国家都已下降。

  

作为响应，Apple、Netflix、YouTube、Facebook和Instagram自愿降低了视频流质量，以节省带宽。

  

同时，据报道，在英国通过移动和固定电话网络拨打的电话数量激增，影响了通话质量，造成掉线甚至断网。

  

现在大多数国家都报道了新冠病毒感染，国际电联秘书长敦促世界各国领导人“不要忘记世界上那些仍无法访问互联网的人”。
