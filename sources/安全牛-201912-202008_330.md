# 远程办公席卷全球，VPN用量翻番

随着全球新冠疫情的蔓延，社交疏离（隔离）成为常态，全球用户对VPN的兴趣激增，自今年年初以来，一些商业VPN提供商的用户和流量翻了一番。

  

  

自今年年初以来，与VPN相关的Google关键词查询的搜索量增长了六至十倍。VPN服务的一家提供商NordVPN表示，其平均日用户数量增长了165。与其他VPN提供商（例如Atlas VPN）相比，流经其网络的数据量也有了大幅度增长，意大利用户对该提供商网络的使用增加了一倍以上。

  

Atlas VPN首席运营官Rachel Welch说：

  

到目前为止，这种激增并未给网络增加负担。

  

对于许多工作人员，尤其是演出工作人员和自由职业者来说，VPN服务是最安全的在线工作方式。在许多国家，VPN的使用与冠状病毒病例的增加保持同步增长趋势。Atlas VPN表示，过去一周来，在中国以外受新冠病毒打击最严重的七个国家（意大利、伊朗、韩国、西班牙、德国、法国和美国），流量增长了9％至112％。  

  

根据企业软件公司Citrix进行的一项调查，在过去，美国只有约三分之一的知识工作者采用远程办公，但新冠病毒的大流行开始刺激远程办公人数的快速增长。根据Netskope的最新报告，过去两周美国远程办公人数增长了15%。

  

值得注意的是，虽然VPN是远程办公最重要的安全保障之一，但是VPN的安全性往往会被夸大而忽视了其他方面的安全问题。对于公司而言，最重要的问题是员工的设备在连接到内部网络之前是否已受到保护（端点安全）以及服务本身的安全性。此外VPN本身的安全性问题也值得关注。Pulse Secure VPN设备的缺陷导致去年有几家公司遭到勒索软件攻击。此外，NordVPN也发生过用户账户数据泄露。  

  

漏洞程序提供商HackerOne的信息技术主管Aaron Zander表示：

  

尽管修补和保护企业信息基础架构很重要，但企业还需要集中精力对员工进行安全使用VPN的教育。
