# 不可破解？F-Secure发布U盘安全计算机

**安全牛点评**

在安全牛之前的报道“可信开源计算是条死胡同”一文中，我们了解到构建基于开源的可信硬件和可信计算机并非易事。尤其是在这个零信任的年代，开源软件代码安全、供应链安全日趋复杂化，即使是开源硬件，也并不意味着其安全性的可视性，而且可信硬件验证的难度随着软硬件系统的复杂化而成几何级数上升。但是随着自主可控和零信任的安全需求不断膨胀，业界并未停止对开源可信硬件的追求。安全公司F-Secure的这个U盘计算机，其实现方法也许能给我们新的启发和灵感。

  

近日，F-Secure的硬件安全专家宣布开发了一个USB大小的安全计算机，号称“不可破解”。

 

这个U盘安全计算机全称为“USB armory Mk II”，是世界上最小的计算机之一。它从头开始封装安全性，并且适用于各种应用程序和计算任务，包括加密货币钱包、安全身份验证和硬件安全模块。

 

F-Secure在新闻稿中提到：

  

F-Secure Foundry的团队设计了该设备，以应对硬件开始与固件重叠时遇到的安全问题。该设备实现了软件、固件和硬件之间的最新编排，同时以最小的外形尺寸提供了多种安全功能和高计算能力。

\_

  

作为一个主打安全性的迷你计算机，F-Secure给MK II的定位是用于安全性至关重要的高风险用途，例如用作冷钱包。

 

MKII基于开放源代码生态系统，这意味着该平台可以根据用户需求进行二次开发。因此，如果您想使用的功能USB armoryMk II不提供，你也可以自动动手开发。

 

F-Secure的硬件安全主管Andrea Barisani补充说：

  

我们通常为客户提供安全审查和安全工程服务，这使我们既是技术突破者，又是技术制造商。这使我们能够在咨询实践中提供最先进的安全性。USB armory MKII的硬件和软件实现清楚地证明了这一点……我们对提高嵌入式计算安全性状态的系统和方法的不断研究，推动了U盘安全计算机的发展，这反过来又使我们能够为客户构建各种安全系统。
