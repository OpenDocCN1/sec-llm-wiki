# AV-TEST 发布 2019 最佳 Android 安全软件榜单

AV-TEST 近日评测了市场上常见的 21 款 Android 安全软件，发现各产品的恶意软件平均实时检出率达到 97.2%，对过去四周新发现的 Android 恶意软件的实时检出率达到 97.5%。  

  

![](../Images/56e613faab06e29221582efbaaa2d5f4.png)

  

AV-TEST 根据各产品的防护能力、性能和可用性三大评测指标得分给出了 2019 年最佳 Android 安全软件 TOP11 榜单：

  

  

![](../Images/1faf2313e3e752c9a749121af07e3314.png)

  

  

 1 

****安天移动反病毒引擎(AVL)**2.7**

**点评：**各项评测的表现都很强势，但功能略微单薄，例如只能拦截未知号码电话。

  

  

 2 

**Avira Antuivirus Security 6.0**

**点评：**防护性能并非百分百完美，恶意软件实时检出率达到99.6%，但是Avira在性能评测中一骑绝尘，而且没有误报。

  

  

 3 

**Bitdefender Mobile Security 3.3**

**点评：**防护性能一流，恶意软件实时检出率达到 100%，而且过去四周新恶意软件的检出率也达到 100%。可用性方面，Bitdefender Mobile Security 不会额外消耗电池电量或者拖慢系统速度，安装使用官网应用商店下载的 APP 时也从未误报。此外 Bitdefender 移动安全还提供防盗功能，可以远程锁定擦除和定位设备。

  

  

4

**猎豹安全大师(Cheetah Security Master)5.0**

**点评：**防护性能同样达到100%的实时检出率，性能测试也是满级通过，没有误报。此外还整合了防丢、应用控制、VPN和WiFi安全顾问和安全浏览功能。

  

  

 5 

**G Data Internet Security 26.6**

**点评：**相比这个类别的顶级产品，G Data Internet Security 26.6的功能更为丰富：远程锁定擦除定位、电话拦截、消息过滤、安全浏览、父母控制应有尽有。

  

  

 6 

**卡巴斯基网络安全(Kaspersky Internet Security)11.32**

**点评：**虽然在防护和性能两项测试中满分通过，但是卡巴斯基安全软件的功能并不算太丰富。

  

  

 7 

**McAfee Mobile Security Version5.3**

**点评：**恶意软件检出率接近满分 (99.9%)，功能丰富，防丢失、电话拦截、安全浏览、防钓鱼、父母控制等功能都有，而且支持将个人信息存入 SD 卡或者云端。唯一遗憾的是不支持电话拦截。

  

  

 8 

**诺顿移动安全(Norton Mobile Security)4.7**

**点评：**各项评测的表现都很强势，但功能略微单薄，例如只能拦截未知号码电话。

  

  

 9 

**NoxSecurity Antivirus Clean Virus， Booster1.3**

**点评：**AV-TEST榜单的新人，但首次亮相就出手不凡。防护能力和性能都是满分，而且不会拖慢系统速度，附加功能也很丰富，包括应用控制、电话拦截、安全浏览和WiFi顾问。

  

  

10

**Sophos Intercept X for Mobile 9.5**

**点评：**表现接近完美，恶意软件检出率达到99.9%。提供的功能也很丰富，但遗憾的是没有VPN电话拦截和个人数据备份到SD卡。

  

  

11

**趋势科技移动安全(Trend Micro Mobile Security)11.0**

**点评：**防护性能接近完美（99.9%）功能也很丰富，但是缺少了个人数据备份和VPN。
