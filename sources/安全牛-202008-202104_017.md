**政策法规 ****《安徽省大数据发展条例》**

  

[

《安徽省大数据发展条例》（以下简称《条例》）近日获得通过，并将于5月1日起施行。对于社会普遍关注的数据盗用、泄露等问题，《条例》明确要求实行大数据安全责任制，并清晰界定大数据安全的各方责任主体和责任范围，为数据信息加上“保险锁”。

](https://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664140690&idx=3&sn=ea2b54f63aa91784001d6801b5d3ed9e&scene=21#wechat_redirect "https://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664140690&idx=3&sn=ea2b54f63aa91784001d6801b5d3ed9e&scene=21#wechat_redirect")

**漏洞补丁 ****GitLab**

  

[

2021年3月31日，GitLab官方发布了任意文件读取的风险通告。漏洞等级：严重。攻击者可以导入特定文件来读取服务器上的任意文件。GitLab官方建议受影响的用户升级到最新版本。

**网络攻击 jQuery Migrate插件**

  

[

安全研究人员近日发现，假冒的jQuery Migrate插件通过在其中包含的混淆代码来加载恶意软件从而注入了数十家网站。这些被加载的文件被命名为jquery-migrate.js和jquery-migrate.min.js，这两个文件是用于加载恶意软件的。截至目前，有超过720万个网站都在使用jQuery Migrate插件。

](https://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651979756&idx=3&sn=ec7f530a3cc68b8c8150b83fda7d4b78&scene=21#wechat_redirect "https://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651979756&idx=3&sn=ec7f530a3cc68b8c8150b83fda7d4b78&scene=21#wechat_redirect")

**网络攻击 澳大利亚九号电视台**

  

[

疑似国家支持的黑客团伙发动猛烈攻击，导致澳大利亚九号电视台（Nine Network）停播超24个小时。这也成为澳大利亚有史以来最大规模的媒体事故。尽管部分节目已经开始复播，但九号电视台的新闻与时事频道仍处于攻击后的瘫痪状态。

](https://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247496668&idx=1&sn=43e16a6a2a481daf4b4766111ee81ac9&scene=21#wechat_redirect "https://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247496668&idx=1&sn=43e16a6a2a481daf4b4766111ee81ac9&scene=21#wechat_redirect")

  

**数据泄露 MobiKwik**

  

[

3月30日，印度移动支付服务商MobiKwik可能已被黑客入侵，近350万客户的KYC(实名身份验证)信息遭泄露。尽管MobiKwik否认了该黑客入侵事件，但其他消息似乎已经证实了这一事实，因为已经有人在暗网论坛上列出了8.2TB的KYC数据，售价1.5比特币(BTC)。

](https://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651979723&idx=1&sn=fbb11356b83eaed9ae7c191b81267c76&scene=21#wechat_redirect "https://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651979723&idx=1&sn=fbb11356b83eaed9ae7c191b81267c76&scene=21#wechat_redirect")

**数据泄露 ****谷歌、苹果**

  

[

近日研究员发现，尽管苹果的iOS和谷歌的Android设备用户选择了拒绝，但两个平台仍然在悄悄传送遥测数据。名为“手机隐私：测量iOS和Android发送给苹果和谷歌的数据”的研究还发现，与苹果从iOS收集的数据量相比，谷歌从其Android Pixel手机用户那里采集的数据最多高出20倍。

](https://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651101074&idx=3&sn=de4cda4f9f3331af7ec8aabef7c8c658&scene=21#wechat_redirect "https://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651101074&idx=3&sn=de4cda4f9f3331af7ec8aabef7c8c658&scene=21#wechat_redirect")

  

**数据泄露 Facebook**

  

[

日前在一家黑客论坛上，有人免费发布了5.33亿脸书用户的个人隐私信息，包括用户的电话号码、脸书登录ID、姓名全称、家庭住址、出生日期、个人简历，以及电子邮件地址等。被公布的这些个人隐私信息数据涉及来自106个国家的5.33亿脸书用户，其中包括3200万美国用户、1100万英国用户和600万印度用户。

](https://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247496717&idx=1&sn=e2973c64690154ea4a2834d49c9e8e87&scene=21#wechat_redirect "https://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247496717&idx=1&sn=e2973c64690154ea4a2834d49c9e8e87&scene=21#wechat_redirect")

[

在最近的一次更新中，臭名昭著的Cl0p勒索软件组织声称可以访问据称属于美国六所顶尖大学的学生和教职员工的财务文件和护照信息。泄露的记录包括截图，这些截图显示了联邦税收文件、要求减免学费的文书工作、护理委员会的申请、护照和税收摘要文件。
