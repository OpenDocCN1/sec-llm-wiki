# 特斯拉全自动驾驶系统是拿公众生命做测试？

在特斯拉等电动汽车厂商的误导性宣传下，大众对“全自动驾驶”的实现已经过于乐观，认为全自动驾驶已经非常接近现实。但事实上这是一个可怕的误解，其代价可能是城市街道上市民的生命。

  

近日特斯拉开始向部分车主推送全自动驾驶系统FSD8.2Beta测试版。油管AI频道@AI Addict在奥克兰街头对该系统的表现进行了实测，结果是灾难性的。

  

特斯拉自动驾驶系统犯下了几乎所有可以想到的驾驶错误，违反了能违法的所有交通法规，离开人工干预几乎步步惊心，随时都有可能酿成车祸！

  

在@AI Addict发布的13分钟视频里，更新到FSD Beta 8.2测试版本的Model 3在奥克兰街头就像个没头苍蝇，自主驾驶的视频很快就从“令人尴尬的错误”转变为“极度危险，可能有害的驾驶”：

  

视频：https://www.youtube.com/watch?v=antLneVlxcs

  

压线行驶、转弯后逆行、转弯路段直行险些撞上栏杆，压实线违法变道、无法顺利通过十字路口、在禁止右转的红灯右转、在空旷路面突然刹停、在右侧车辆有优先路权的交叉路口突然加速通过险些撞上一辆凯美瑞...

  

测试显示，**特斯拉“全自动驾驶系统”FSD根本不具备在市区道路上自主安全行驶的能力，**人类驾驶员稍有疏忽自动驾驶系统就可能犯下无可挽回的严重错误。AI Addict指出特斯拉自主驾驶系统的早期采用者会在城市街道上进行不受控制的测试，而行人、骑自行车的人和其他驾驶员则不知道他们是实验的一部分。**如果这些特斯拉司机中的一个“手滑”或者“脚滑”，后果可能是致命的。**

  

简而言之，特斯拉将极度脑残的“全自动驾驶系统”推送给用户，事实上是**怂恿这些用户在城市公共道路上以城市街道公众的生命作为赌注进行测试，**帮助这个世界上最有价值的汽车制造商获取测试数据改进系统，而特斯拉所需支付的成本基本上为零。
