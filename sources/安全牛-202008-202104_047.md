**行业动态 北京 ****中国网络社会组织联合会在线教育专委会成立**

  

[

3月16日下午，中国网络社会组织联合会在线教育专业委员会成立大会在京召开。据悉，在线教育专业委员会是联合会第三个分支机构，首批成员单位共58家，由联合会在线教育领域会员单位组成，致力于团结在线教育领域社会组织、互联网企业、专家学者，搭建交流平台，凝聚社会共识，加强行业自律，更好地汇聚业界学界资源和力量，助推在线教育健康发展。

**漏洞补丁 ****Chrome**

  

[

近日，谷歌发布chrome浏览器89.0.4389.90版本，新版本Chrome浏览器中包含了5个安全补丁，其中3个比较危险的漏洞分别是CVE-2021-21191、CVE-2021-21192和CVE-2021-21193。研究人员还发现了CVE-2021-21193 0 day漏洞的在野利用，这是谷歌本月内第二次发布这样的补丁。

](https://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247517652&idx=2&sn=f9cbf95ec72ee3092c543f1214bbc8e7&scene=21#wechat_redirect "https://mp.weixin.qq.com/s?__biz=MzI0MDY1MDU4MQ==&mid=2247517652&idx=2&sn=f9cbf95ec72ee3092c543f1214bbc8e7&scene=21#wechat_redirect")

**网络攻击 宏碁**

  

[

计算机巨头宏碁近日遭到了REvil勒索软件攻击，威胁分子索要迄今为止数额最大的赎金：5000万美元（约3.25亿人民币）。勒索软件团伙在其数据泄露网站上宣布，他们成功闯入了宏碁的系统，并发了涉嫌盗取文件的几个图片，以证明所言非虚。从这些泄露的图片可以看出，这些文件包括财务电子表格、银行结余和银行往来邮件。

](https://mp.weixin.qq.com/s?__biz=MzI4OTc4MzI5OA==&mid=2247534947&idx=2&sn=c28ff45112ae35acdb41700e0e845e5d&scene=21#wechat_redirect "https://mp.weixin.qq.com/s?__biz=MzI4OTc4MzI5OA==&mid=2247534947&idx=2&sn=c28ff45112ae35acdb41700e0e845e5d&scene=21#wechat_redirect")

**网络攻击 摩森康胜**

  

[

多家外媒报道，啤酒巨头摩森康胜上周发生“网络安全事件”。其啤酒生产业务被扰乱。摩森康胜表示，黑客攻击已使其系统离线，公司的部分业务被延误和中断，包括啤酒厂的运营、生产和发货。摩森康胜遭到网络攻击后，受影响的IT系统被关闭，员工被告知不要碰计算机。并且，为了修复控制工业系统的计算机，公司还关闭了一些生产系统。

](https://mp.weixin.qq.com/s?__biz=MzA3Mzk4MDUwNw==&mid=2652885716&idx=1&sn=f1dec2d58eb427d5dc14c453c395afe3&scene=21#wechat_redirect "https://mp.weixin.qq.com/s?__biz=MzA3Mzk4MDUwNw==&mid=2652885716&idx=1&sn=f1dec2d58eb427d5dc14c453c395afe3&scene=21#wechat_redirect")
