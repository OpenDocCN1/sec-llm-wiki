融资并购 Okta

  

[

领先的独立身份提供商Okta近日宣布已达成了最终协议，以股票形式收购Auth0这个面向应用软件团队的领先身份平台，交易价值约65亿美元。Okta和Auth0共同支持一系列广泛的身份使用场景，这起收购将加快两家公司的共同愿景：使每个人都能安全地使用任何技术，从而塑造互联网身份的未来。

**漏洞补丁 ****Chrome**

  

[

3月2日，谷歌发布了Chrome浏览器第二个零日漏洞的修复程序，称该漏洞正被积极利用。当天，谷歌发布了Windows、Mac和Linux版Chrome安全更新v89.0.4389.72，修复了 47 个漏洞，其中包括正被利用零日漏洞。

**网络攻击 Perl.com域名**

  

[

最近发生了Perl.com域名劫持事件，该域名指向了一个与恶意软件活动相关的站点。从攻击到恢复，过程可谓一波多折。Brian Foy表示，黑客在去年9月发动攻击后，直到三个月后才开始一系列的域名转移行动，主要是为了避免攻击活动被立即发现，且几经倒手更换注册商，使得域名恢复变得更加困难。

](https://mp.weixin.qq.com/s?__biz=MzA5ODA0NDE2MA==&mid=2649740830&idx=1&sn=1d7800431d4365d2d7896f903deada0b&scene=21#wechat_redirect "https://mp.weixin.qq.com/s?__biz=MzA5ODA0NDE2MA==&mid=2649740830&idx=1&sn=1d7800431d4365d2d7896f903deada0b&scene=21#wechat_redirect")

  

**数据泄露 印度核酸检测数据**

  

[

近日，印度西孟加拉邦卫生福利部被曝800万核酸检测结果报告泄露。。研究人员发现网站在实现上存在问题，会导致在特定州进行核酸检测的人员的测试结果泄露。报告中含有姓名、年龄、婚姻状况、检测时间、居住地址等敏感个人信息。这里的特定州指的就是印度西孟加拉邦。

](https://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651978786&idx=2&sn=3d67c821546524ea1efde8b0c3f68e48&scene=21#wechat_redirect "https://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2651978786&idx=2&sn=3d67c821546524ea1efde8b0c3f68e48&scene=21#wechat_redirect")

  

**数据泄露 SITA**

  

[

全球航空公司的通信和IT供应商SITA已遭到破坏，从而损害了存储在该公司美国服务器上的乘客数据，该公司称之为“高度复杂的攻击”。受影响的服务器在亚特兰大，并且属于SITA乘客服务系统（SITA PSS）。
