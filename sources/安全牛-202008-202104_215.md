# 安全牛第八版《中国网络安全行业全景图》调研启动

随着物联网、5G、新基建、工业互联网、大数据的快速发展，网络安全领域业务碎片、复杂多样化的特征越发明显。为了帮助甲方用户、安全厂商以及投资机构等行业从业人员更好地了解产业全景特征，安全牛通过长期与安全厂商、安全行业资深顾问专家的交流、调研及分析，于2016年在业界首先推出《中国网络安全行业全景图》（以下简称“全景图”）报告研究，目前已延续7版，受到行业广泛关注与认可。

  

面对已经到来的“大安全”与“大变革”时代，为了对国产网络安全厂商及其产品能力有更加真实、全面、客观的展现，帮助甲方用户更好选型网络安全产品，安全牛即日起正式启动第八版全景图调研工作，并将于2021年2月择机发布。

  

为了使全景图及相关报告能更真实地代表中国网络安全市场的现状与未来趋势，且对用户（甲方）、资本、企业、从业人员更具参考价值。安全牛分析师团队在第七版全景图报告基础上，对技术领域分类进行了优化和定义，并对调研流程做了进一步规范，相关说明如下：

  

1.  经过安全牛分析师团队调研，对第7版全景图一级分类进行了优化，将原“应用安全”、“业务安全”分类合并成“业务与应用安全”，将原“智能安全”分类拆分收录，将原“安全管理”分类调整为“安全管理与运营”分类，增设“支撑安全技术与体系”分类。详细分类请见“第八版全景图企业申报信息表”；
    
2.  全景图收录基于企业自主申报，企业需按要求填写全景图申报信息表，在2021年1月15日前邮件提交至：bd@aqniu.com。
    
3.  对于平台类网络安全产品，仅限基于产品核心能力提交不超过三项细分领域申报;
    
4.  全景图报告是为了全面展现我国网络行业整体状况，收录时不会涉及细分领域中各企业的排名或比较，企业展现位置与实际产品能力无直接关联性；
    
5.  本次调研将加强对云安全、大数据、区块链、智能安全等新安全技术领域的研究和收录，对相关领域中具有独特技术能力和发展潜力的初创公司给予重点关注，根据细分领域所处的技术发展阶段不同，差异化制定收录标准；
    
6.  安全牛《中国网络安全行业全景图》调研不涉及任何费用，如遇提及费用情况请随时举报，24小时举报电话：18311333376。
    
7.  本次全景图调研将广泛听取社会各界的意见和建议，请将您的宝贵意见和建议发送至邮箱：bd@aqniu.com
