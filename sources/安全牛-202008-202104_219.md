# 获国有企业结构调整基金入股，安天完成累计总额8亿元B轮融资

近日，安天科技集团股份有限公司(以下简称为“安天”)获得中国国有企业结构调整基金2亿元投资。在今年8月时安天本轮融资已到位金额为6亿元，如今安天B轮融资已全部完成，累计融资金额达8亿元，航行资本担任了全程独家财务顾问。

  

安天在2000年以“安天实验室”模式起步，2010年开始商业化转型，是国内专注威胁检测对抗领域的企业。从市场端看，当前随着信息化程度不断提升，从个体黑客、网络犯罪集团到背景复杂的攻击组织都更加活跃，0day漏洞屡屡曝光，勒索病毒泛滥传播，窃密事件时有发生，APT攻击更是难以防御。用户需要更有效的产品、服务和解决方案。

  

安天的产品布局包括流量威胁监测响应、高级威胁沙箱分析、蜜罐和欺骗式防御、主机系统和云安全、零信任接入等，同时安天为客户提供态势感知平台、资产安全运维平台、网络靶场等解决方案级产品。安天提供的反病毒引擎和下一代反病毒服务为华为、小米等手机厂商提供安全防护。

  

在整体客户端，当前全球已有近百家安全企业、IT企业选择安天科技作为检测能力合作伙伴，其威胁检测引擎和安全中间件已为全球超八十万台网络设备和网络安全设备、超过二十亿部手机智能终端设备提供了原生融合的安全能力。战略客户包括军队、军工、海关总署、中国民航、华能电力等关键信息基础设施行业客户。

  

安天正逐渐加快产业行业布局，以全栈技术赋能，与更多金融、政企、移动互联网、工业网络、物联网、关键基础领域客户达成战略合作。
