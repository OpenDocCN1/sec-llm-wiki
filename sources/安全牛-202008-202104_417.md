# Windows XP源代码公开泄漏

据Bleepingcomputer报道，Windows XP SP1和其他版本的操作系统的源代码9月26日在线泄漏。

  

泄密者声称过去两个月一直在编译泄漏的Microsoft源代码的集合。然后，这个43GB的收藏9月26日在4chan论坛上以Torrent种子文件形式发布。

  

![](../Images/1ecc46ba1bc7d359f514fa6395325f43.png)

Torrent种子文件中的泄漏内容目录  来源：Dey

  

种子文件中包括所谓的Windows XP和Windows Server 2003源代码，以及甚至更旧版本的操作系统。  

  

泄露的内容包括：

  

**·**MS DOS 3.30

**·**MS DOS 6.0

**·**Windows 2000

**·**Windows CE 3

**·**Windows CE 4

**·**Windows CE 5

**·**Windows Embedded 7

**·**Windows Embedded CE

**·**Windows NT 3.5

**·**Windows NT 4

  

种子文件还包含一个媒体文件夹，包含一组与比尔·盖茨有关的阴谋论视频。

  

除了torrent种子文件之外，泄密者还在线分发了一个较小的2.9GB的7zip文件，仅包含Windows XP和Windows Server 2003的源代码。

  

该泄漏者指出，Windows XP源代码已经在黑客之间私下传递了多年，但直到9月26日才公开发布。

  

BleepingComputer表示已经看到了源代码，但是无法确认它是否是Windows XP或Windows Server 2003的实际源代码。

  

这不是Microsoft操作系统源代码第一次被发布到网上。

  

Windows 10内部开发的源代码曾于2017年在网上泄露，而就在最近，微软私有GitHub存储库被黑客入侵，私有项目也泄露了。

  

截至发稿，对媒体关于Windows XP源代码泄露是否属实的质询，微软的回复是：“正在调查此事”。

  

**Windows XP源码泄露是否需要引起安全方面的关注？**

  

尽管Windows XP大约是20年前发布的，但是如果现代版本的Windows中还有仍在使用的代码，则此泄漏可能是潜在的安全风险。  

  

虽然攻击者可以对Windows进行逆向工程来查找漏洞，但是通过获得源代码，可以更轻松地详细了解Windows操作系统的内部工作原理。

  

如果在Windows XP源代码中发现可利用的bug，并且该代码仍在Windows 10中使用，则威胁执行者可以利用现代版本的操作系统中的bug。
