**国内**

  

**1、《中华人民共和国反电信网络诈骗法（草案）》公布**

  

据中国人大网消息，第十三届全国人大常委会第三十一次会议对《中华人民共和国反电信网络诈骗法（草案）》进行了审议。该草案面向社会公众征求意见，截止日期为2021年11月21日。

  

**详情点击：**

[重磅|《中华人民共和国反电信网络诈骗法（草案）》公布](https://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664149938&idx=1&sn=ca8c7a02d79bf6a0a0d1dc6027974e1b&scene=21#wechat_redirect)

  

**2、工信部公布第2批网络关键设备安全检测结果**  

  

日前，工信部根据《中华人民共和国网络安全法》《关于发布承担网络关键设备和网络安全专用产品安全认证和安全检测任务机构名录（第一批）的公告》，将由具备资格的机构按照《网络关键设备安全通用要求》（GB40050-2021）强制性国家标准，经安全检测符合要求的网络关键设备（第2批）予以公布。

  

**详情点击：**

[工信部公布第2批网络关键设备安全检测结果](https://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664149938&idx=3&sn=c12f7199437d02ee6489f45874022b8e&scene=21#wechat_redirect)

  

**3、工信部：尽快发布实施APP个人信息保护管理规定**  

  

10月19日，在国务院新闻办举行的前三季度工业和信息化发展情况新闻发布会上，工业和信息化部新闻发言人、信息通信管理局局长赵志国表示，为贯彻落实《个人信息保护法》，将会同相关部门，尽快发布实施《移动互联网应用程序个人信息保护管理规定》。

  

**详情点击：**

[工信部：尽快发布实施APP个人信息保护管理规定](https://mp.weixin.qq.com/s?__biz=MjM5MzMzNjU4MQ==&mid=2709970606&idx=3&sn=e4cf84c962785eb710cdaf3da894f513&scene=21#wechat_redirect)

  

**4、全国信安标委征求《信息安全技术 汽车采集数据的安全要求》国家标准（征求意见稿）意见**  

  

近日，全国信息安全标准化技术委员会归口的《信息安全技术 汽车采集数据的安全要求》国家标准已形成标准征求意见稿。该征求意见稿标准相关材料已发布在信安标委网站，如有意见或建议可于2021年12月18日24:00前反馈秘书处。

  

**详情点击：**

[全国信安标委征求《信息安全技术 汽车采集数据的安全要求》国家标准（征求意见稿）意见](https://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664149739&idx=3&sn=f6f2ee4d12846ab502017124a6b421cf&scene=21#wechat_redirect)

  

**5、国家网信办部署推进“清朗·互联网用户账号运营乱象专项整治行动”**  

  

为切实解决账号运营存在的突出问题，国家互联网信息办公室于10月18日召开“清朗·互联网用户账号运营乱象专项整治行动”全国视频工作会议，对相关工作进行专题部署。

  

**详情点击：**

[国家网信办部署推进“清朗·互联网用户账号运营乱象专项整治行动”](https://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664149644&idx=3&sn=a61b0663e24f4f28801339892f79d903&scene=21#wechat_redirect)

  

**6、身份云平台Authing完成2300万美元A轮融资**  

  

10月24日，身份云平台Authing宣布完成 2300万美元A轮融资。本轮融资由老虎环球基金领投，鼎晖VGC（创新与成长基金）、声网 Agora、老股东GGV纪源资本和奇绩创坛跟投，跃为资本担任独家财务顾问。

**7、赛宁网安再获2亿国有资本注资**

**国外**

  

**1、Oracle发布多个安全漏洞的预警**  

  

2021年10月19日，Oracle官方发布了多个安全漏洞的公告，包括Oracle Essbase 安全漏洞（CNNVD-202110-1470、CVE-2021-35652）、Oracle WebLogic Server 输入验证错误漏洞（CNNVD-202110-1400、CVE-2021-35617）等137个漏洞。

  

**详情点击：**

[CNNVD | 关于Oracle多个安全漏洞的预警](https://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664149866&idx=3&sn=24d1bfaa216591743d77243dd7025bd5&scene=21#wechat_redirect)

  

**2、微软发布关于 Surface Pro 3 TPM 绕过漏洞的安全公告**  

  

近日，微软发布了关于安全特性绕过漏洞 (CVE-2021-42299) 的安全公告。该漏洞影响Surface Pro 3平板电脑，可使威胁行动者在企业环境中引入恶意设备。

  

**详情点击：**

[微软发布关于Surface Pro 3 TPM绕过漏洞的安全公告](https://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247508450&idx=1&sn=c989fedda1b877fdcbafeebdd2efaa99&scene=21#wechat_redirect)

  

**3、开源软件Cachet被曝RCE漏洞**  

  

研究人员指出，开源的状态页面系统Cachet中存在多个安全漏洞，可导致攻击者执行任意代码并窃取敏感数据。

  

**详情点击：**

[开源软件 Cachet 被曝RCE漏洞](https://mp.weixin.qq.com/s?__biz=MzI2NTg4OTc5Nw==&mid=2247508394&idx=1&sn=e7f3bcfa2f01dbaa7136cf210e54890c&scene=21#wechat_redirect)

  

**4、谷歌推出针对安卓企业版漏洞赏金计划，奖金高达25万美元**  

  

近期，谷歌推出安卓企业版漏洞赏金计划，用来奖励安卓企业版本在 Pixel设备上的运行漏洞，最高奖励金额达25万美元。

**5、TCG宣布成立供应链安全工作组**  

  

近期，TCG（Trusted Computing Group，可信计算组织）宣布成立一个专注于供应链安全的新工作组，致力于制定供应链安全标准指南。该小组由微软、英特尔和高盛的代表领导，主要有两个目标：确保设备是正品、帮助企业组织在受到网络攻击后恢复。
