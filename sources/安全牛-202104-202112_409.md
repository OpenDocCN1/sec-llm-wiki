# Google紧急发布Chrome浏览器崩溃修复更新

本周末，Google紧急发布了Google Chrome浏览器更新，修复了自上周四以来导致全球范围内Windows 10和Linux上的Chrome浏览器崩溃的问题。  

  

上星期四，许多Windows 10用户突然发现 Google Chrome扩展程序和选项卡崩溃了，如下图所示。后来得知，Linux用户也受到此问题的影响。

  

![](../Images/7d72625377439f42e3515d66950c0942.png)

  

除了扩展程序崩溃之外，用户还发现无法访问浏览器的设置、扩展程序页面（灰屏）。

  

Google周日紧急发布了一个小更新来解决此崩溃问题。

  

受影响的Windows设备用户可按照下列步骤操作：

  

*   退出所有打开的Chrome窗口；
    
*   重新打开Chrome（问题仍然存在）；
    
*   保持Chrome打开约5分钟；
    
*   5分钟后，退出Chrome，然后重新启动Chrome，更新完成，问题应得到解决。
    

  

对于受影响的Linux设备，请执行以下步骤：

  

*   导航到包含Chrome用户个人资料的目录；
    
*   .config/google-chrome/；
    
*   删除\[Chrome user profile\]\\的内容 Origin Trials subdirectory；
    
*   该目录应包含“1.0.0.7”目录；
    
*   删除\[Chrome user profile\]\\Local State file；
    
*   启动Chrome，该Chrome应该会按预期加载。
    

  

尽管Google尚未正式说明导致崩溃的原因，但根据上述修复流程，似乎是由Origin Trial实验导致的崩溃被推送给了部分Google Chrome浏览器用户。
