# 谷歌FLoC广告追踪技术遭多家浏览器厂商抵制

上个月，Google宣布将“杀死”Chrome浏览器中的第三方Cookie，取而代之以新的基于联邦学习的网站广告隐私功能——FLoC。

  

FLoC旨在取代广告网络和分析平台用来在网络上跟踪用户的第三方Cookie，后者是整个互联网广告技术的基石之一，但长期以来面对侵犯隐私的指控。

  

但是，Google提出的用FLoC替换第三方跟踪Cookie的建议并未受到所有人的欢迎。

  

FLoC受到电子前沿基金会（EFF）的批评，而Vivaldi和Brave等浏览器厂商则完全拒绝了FLoC，这些厂商认为FLoC作为一种隐私保护技术存在争议。

  

**FLoC用“同类群组”替代Cookie的跟踪**

  

本周，浏览器厂商Vivaldi宣布他们不会在产品中支持Google FLoC。

  

FLoC的目标是用所谓的“同类群组”代替第三方Cookie和localStorage之类的跟踪技术。

  

与服务器（或广告网络）在web上跟踪用户并记录其浏览历史记录相反，FLoC将这一责任移交给了用户的个人Web浏览器。

  

也就是说，每个被选为FLoC试用版的Google Chrome浏览器实例都将与最能代表其近期网络浏览活动的特定“群组”或组合在一起。

  

在本地存储的成千上万具有相同浏览历史记录（属于同一“群组”）的浏览器将分配一个共享的“群组”标识符，该标识符将在请求时与站点共享。

  

正如Google解释的那样：

  

“FLoC不会与Google或任何人分享您的浏览历史记录。这不同于第三方Cookie，后者允许公司在不同站点上分别关注您（跨站点和应用追踪）。”

  

Google在博客中解释说：“FLoC可以在您的设备上运行，而不会共享您的浏览历史记录。重要的是，广告生态系统中的每个人，包括Google自己的广告产品，都将具有相同的FLoC访问权限。”

  

简而言之，这意味着，如果您对技术站点感兴趣（记录在网络浏览器的历史记录中，一千个其他用户也是如此），您的浏览器和另外一千个浏览器将被添加到一个访问技术站点的浏览器群组中，所有这些浏览器都将由一个共享标识符表示。

  

在该示例中，这与广告提供者对单个用户的浏览习惯具有可见性相反，广告提供者的可见性仅限于对技术广告可能感兴趣的浏览器列表（而无法定位到个人）。

  

此外，Google指出，**Chrome不会针对被认为敏感的主题（例如主要包含医疗、政治或宗教内容的网站）创建FLoC组。**

  

Google还将允许网站选择不使用FLoC。这意味着，在生成同类群组数据时，网络浏览器将不包含对拒绝FLoC网站的访问。

  

不希望加入FLoC的网站运营者可以通过向访问者发出以下HTTP请求标头来阻止它：

  

*Permissions-Policy：interest-cohort=（）*

  

**Vivaldi、Brave、DuckDuckGo拒绝FLoC**

  

但是，Vivaldi和Brave等网络浏览器的制造商显然并不愿意接受FLoC。  

  

“在Vivaldi，我们捍卫用户的隐私权。我们不以任何方式变相批准跟踪和分析。我们当然也不会允许我们的产品建立本地跟踪配置文件，”维瓦尔第首席执行官兼首席执行官乔恩·冯·特兹纳（Jon von Tetzchner）说。

  

“对我们来说，‘隐私’一词意味着实际的隐私。我们不会将其反过来。我们甚至都不会观察您如何使用我们的产品。我们的隐私政策简单明了；我们不想追踪您，von Tetzchner在本周发布的博客文章中进一步指出。

  

**Vivaldi认为Google的FLoC实际上是打着隐私保护的旗号侵犯隐私。**

  

许多人也赞同Vivaldi的看法，包括Brave Web浏览器、DuckDuckGo和电子前沿基金会（EFF）。

  

Brave将FLoC称为“朝错误的方向迈出了一步”，并认为FLoC以“对隐私友好”的幌子侵害用户隐私。

  

注重隐私的搜索引擎DuckDuckGo的制造商也对Google强迫没有明确意愿的用户使用FLoC表示失望。

脚本将检查是否设置了 document.interestCohort（）属性。如已设置则意味着您的Web浏览器已经被FLoC分配了标签。  

  

DuckDuckGo已发布了Privacy Essentials Chrome扩展程序，用户可以安装该扩展程序以阻止其Chrome浏览器上的FLoC。

  

Google表示，目前，FLoC有望在澳大利亚、巴西、加拿大、印度、印度尼西亚、日本、墨西哥、新西兰、菲律宾和美国的“一小部分用户”中推出。
