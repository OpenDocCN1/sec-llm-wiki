# 《企业零信任安全应用与建设实践指南》报告调研启动

云计算和大数据时代，网络安全边界逐渐模糊，内外部威胁愈演愈烈，传统的边界安全防御模式难以应对，零信任安全理念与架构应运而生。

  

零信任安全并非一套独立的系统，相比传统的边界防护和流量检测，覆盖范围更大，与基础通信网络和设施在耦合性方面也更密切，这使得其落地实施难度比传统安全解决方案更复杂。作为一种新的网络安全架构，在面对数字化转型的安全建设中还存在更多挑战。

  

为了更好推动零信任安全理念的落地应用，深入了解零信任安全在产品化过程中的发展状况和特点，探索分析其在行业应用、落地实践中的建设挑战与应对方法。安全牛联合**天融信、深信服、派拉软件、芯盾时代、九州云腾、吉大正元、格尔软件、易安联、缔盟云、绎云科技**十家国内零信任安全领域代表性厂商，联合发起《企业零信任安全应用与建设实践指南报告》（以下简称“报告”）。即日起，报告调研工作正式启动。

  

  

**01**

**报告重点**

  

1.  依托安全牛读者受众、会员体系、安全牛课堂学员群等专业行业资源，进行多维度的零信任应用需求与发展现况调研，全面呈现国内零信任落地应用的现状，并分析零信任技术发展对传统安全产业的影响；
    
      
    
2.  研究零信任的应用能力进阶模型，给出匹配零信任落地的技术发展路线图；
    
      
    
3.  以独立第三方研究视角，梳理总结零信任落地建设的可行性分析和建设指南；
    
      
    
4.  总结梳理零信任安全领域的产业生态及代表性厂商能力特点研究；
    
      
    
5.  基于10个真实落地的零信任安全应用案例，研究零信任技术发展趋势和最佳实践经验。
    

  

  

**02**

**研究方法**

  

**问卷调研：**

了解当前用户对零信任产品的认知与应用情况。

**用户访谈：**

了解用户对零信任产品应用的需求、顾虑、定位与建议，并进行总结提炼。

**厂商调研：**

邀请并调研国内零信任安全领域有较成熟产品和应用特点的代表性厂商，了解其在零信任安全方面的技术理念、方案能力、建设实践、技术优势和发展趋势等。

**案例研究：**

通过剖析真实零信任应用案例，对零信任的建设理念、实施步骤、主要挑战及应对方法进行研究。

**文献检索：**  

收集并阅读国内外研究论文、文献综述、科技报告、国家标准等专业期刊，总结零信任建设实践的政策要求和技术观点。

  

  

**03**

**报告提纲**

  

*   国外零信任技术应用与发展
    
*   我国零信任实践及应用现状分析
    
*   零信任应用技术矩阵
    
*   零信任应用实践分析
    
*   十大零信任案例研究
    
*   未来发展与应用趋势
    

  

  

**04**

**问卷调查**

  

为了进一步了解目前企业用户对于零信任产品的应用需求，全面了解零信任落地实践的难点和解决方案，本次报告将面向甲方企业用户和相关零信任安全厂商展开问卷调查活动，可点击**阅读原文**或扫描二维码参与。报告发布后，我们将会为有效参与完成的受访者提供纸质版《企业零信任安全应用与建设实践指南》报告一份。
