# 物盾安全完成数千万元Pre-A轮融资

日前，**上海物盾信息科技有限公司**（以下简称：物盾安全）宣布完成Pre-A轮数千万元的融资，本轮融资由**奇安投资领投，老股东源渡创投跟投**。

  

据介绍，物盾安全以智能电力物联网安全为入口，聚焦物联网边缘侧安全领域，以零信任为核心理念，致力于解决“物联网+边缘计算”场景下的安全问题。目前，物盾安全以物安盾零信任安全防护管理系统为核心产品，通过边缘计算本体防护、南向终端管控、北向可信接入以及云边协同安全管理，可帮助企业实现工业互联网中“最后一公里”的安全通讯。

  

![](../Images/8d62d21d3a342a3eb7c30516354bfed7.png)

安盾零信任安全架构图

  

物盾安全表示，本轮融资后，公司将继续扩大对研发、运营以及市场销售团队的投入，加大物安盾安全防护系统建设，加快产品方案的优化与升级，又快又稳地实现运营管理的优化和业务规模的持续较快增长。

**物盾安全 CEO汤晓冬 表示：**

非常感谢投资方对物盾安全未来发展方向的认可，尤其是在疫情这一特殊时期，此次融资也进一步帮助坚定了公司及团队对未来发展的信心。物盾安全从成立之初一直致力于物联网安全产品的研发，特别是针对高度场景化的边缘计算安全解决方案是我们的长远发展战略。网络安全的目的是服务业务需求，赋能业务发展，我们将继续围绕着客户业务纬度进行产品研发并提供整体解决方案。此次融资，除了在研发方面加大投入之外也会加强市场方面的投入，扩大产品优势的同时形成行业及区域的布局和覆盖。

  

**奇安投资 投资VP周竞驰  表示：**

物联网的应用前景十分广阔，近几年以来正在深刻改造着既有的网络架构。对于整个网络安全行业而言，物联网安全无疑是未来有确定性的新兴场景方向。我们认为，物盾安全团队针对各类垂直场景，提出了成熟可复制且具有前瞻性的物联网安全解决方案，是这一方向具备先发优势的物联网安全厂商。期待物盾安全持续研发投入，成为我国物联网安全发展的中坚力量。

  

**源渡创投 卢飞  表示：**

近几年物联网行业飞速发展，具有计算能力的边缘节点大量增加，通过物联网的数据量几何级数的上升，物联网安全成为物联网行业发展的关键环节。物盾安全团队拥有先进的物联网安全技术，深耕于众多垂直行业，积累了大量行业经验，并由此打造出了诸多理念先进、稳定可靠物联网安全产品。源渡创投作为物盾安全连续两轮投资人，看好物联网安全方向的前景，也将持续支持物盾安全成为行业中较快发展的创新企业。
