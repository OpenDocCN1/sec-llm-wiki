# 第九届“首都网络安全日”拉开帷幕

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651112750&idx=1&sn=8f8cc66fe1c831d108cb8cea67f9188c&chksm=bd1475fd8a63fceb796330272b9a540e34c9779942795d49a503663f57e918adc22d57621762&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651112750&idx=1&sn=8f8cc66fe1c831d108cb8cea67f9188c&chksm=bd1475fd8a63fceb796330272b9a540e34c9779942795d49a503663f57e918adc22d57621762&scene=27#wechat_redirect)

NETWORK SECURITY

**共筑网络安全防线 ****守护网络清朗空间 **

  

4月27日，由北京市人民政府主办，北京市公安局联合北京市互联网信息办公室共同承办的第九届“首都网络安全日”系列活动正式启动。本次活动通过专题直播、产业研讨、线上答题等多种形式，进一步提升社会网络安全意识，增强群众网络安全防护能力，共筑清朗网络空间。

![](../Images/674537e51e20c9907c3f07559d777c86.png)

  

![](../Images/3c9e914f21ec0e5cdfebc2bdd47531b7.png)

第九届首都网络安全日

  

**寓教于乐普及知识**

**提升安全防护意识**

**![](../Images/e0b4a8b58752ad520209a5306cdf09d8.png)**

  

　　本次活动推出“净网2022”网络安全知识有奖问答和《上网安全手册》，对常见的邮件安全、密码安全、设备安全，以及电信网络诈骗安全防范等内容进行宣传普及，携手广大群众共同打造网络安全的铜墙铁壁。此外，还特别制作“网络安全青警说”系列直播，邀请市公安局青年民警代表和相关行业专家，就广大网民在购物、求职、出行等应用场景下的安全问题进行交流分享，系列直播节目将在“首都网警”微博、快手号等各视频直播网站播出。

  

  

**搭建行业交流平台**

**助力数字经济发展**

**![](../Images/e0b4a8b58752ad520209a5306cdf09d8.png)**

  

　　为充分发挥首都网络安全行业“领头雁”作用，活动将举办“网络无边、安全有界”线上技术交流研讨活动，邀请院士、行业专家、企业代表参加活动，围绕关键信息基础设施防护、数据安全、供应链安全等业内话题、创新技术及行业政策等内容展开探讨，为行业内部提供优质交流渠道，为新形势下的网安建设之路献言献策，全力促进首都数字经济创新发展。

  

  

**做强网上正面宣传**

**凝聚网络正能量**

**![](../Images/e0b4a8b58752ad520209a5306cdf09d8.png)**

　　

　　活动期间，“小岗位大英雄”主题征集活动将在线上同步举办。在新华网的大力支持下，通过开设访谈专栏，围绕新时代互联网安全领域从业人员中的正能量榜样，讲述他们的典型事迹和家国情怀，进一步增进社会各界对互联网安全行业的信任与支持，激发从业人员的荣誉感和归属感，呼吁广大网友积极弘扬向上向善的网络文化，共同营造清朗的网络环境。
