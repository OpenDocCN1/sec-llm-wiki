# BCS2022全球议题征集正式开启

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651112432&idx=3&sn=fc6ea68a9508a13204f741d647f03445&chksm=bd1473238a63fa350582e2f360a3709dc99c4dce3413fae7cf3fec49638eb6991d49db68e461&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651112432&idx=3&sn=fc6ea68a9508a13204f741d647f03445&chksm=bd1473238a63fa350582e2f360a3709dc99c4dce3413fae7cf3fec49638eb6991d49db68e461&scene=27#wechat_redirect)

日前，2022北京网络安全大会（简称“BCS2022”）组委会正式面向全球网络安全技术专家公开征集大会议题，议题方向涵盖关键基础设施安全、安全规划与建设、数据安全、特权访问安全、数据跨境、数据生命周期安全、5G安全、云安全、供应链安全、开源安全等众多领域，优质议题提供者有机会公开发表技术研究成果、与全球网安大咖同台交流！

![](../Images/4a8363d58161e0fca37de5165cae3636.png)

**征集议题范围**  

  

关键基础设施安全、安全规划与建设、数据安全、特权访问安全、数据跨境、数据生命周期安全、5G安全、云安全、供应链安全、开源安全、区块链安全、工业互联网安全、物联网安全、车联网安全、人工智能安全、移动安全、远程办公安全、威胁情报、攻防对抗、零信任、商用密码、身份安全、应用加密、隐私计算、代码安全、安全运营、DevSecOps、SD-WAN、SOAR（安全编排与自动化响应）、态势感知、SOC、MSS、SASE安全访问服务边缘、隐私保护、网络犯罪打击治理、NDR、XDR、蜜罐、沙箱、指令调用序列检测、攻击面管理等。

  

\*议题包括以上方向，但不限于此。

  

**投稿人权益**

  

如议题被选中，将获得以下权益：  
1.现场主题演讲机会，公开发表研究成果

2.与全球专家学者零距离交流

3.可申请收录于《网络安全的40个智慧洞见（2022版）》，入选后获得1000元稿费（并可开具论文录用通知）

4.有机会受邀成为专家进入北京网络安全大会专家顾问委员会

5.大会全程VIP礼遇（含BCS尊享票及周边）

  

**征集截止时间**

  

2022年5月10日

  

**投稿形式**

  

1.投稿人需在5月10日之前提交议题征集表及演讲PPT。

2.若要投稿到《网络安全的40个智慧洞见（2022）》，需按照大会组委会要求按时提交不少于3000字的论文。

  

**投稿流程**

1\. 登录BCS北京网络安全大会官网https://bcs.qianxin.com/ ，进入全球议题征集专页，下载申请表格。

2.将符合标准的表格、PPT、论文发至BCS-topic@qianxin.com  

\*请将文件名改为：姓名+议题名。

  

**投稿人注意事项**

  

1.为保证会议的前瞻性，所提交议题内容须未在其他论坛或媒体演讲和发表过。

2.如议题通过审核，组委会将在2022年5月10日前通过电话/电子邮件通知。由于提交议题众多，未通过审核的议题，组委会无法一一通知。如对审核结果有疑问，请联系议题审核组（BCS-topic@qianxin.com）。

  

\*最终解释权归活动组委会所有

  

关于北京网络安全大会

  

北京网络安全大会（简称“BCS”），由中国电子信息产业集团有限公司、中国互联网协会、中国网络空间安全协会、中国密码学会、全国工商联大数据运维(网络安全)委员会、中国通信学会、中国友谊促进会、奇安信集团共同主办。以“全球网络安全、倾听北京声音”为立意，坚持“专业高端、开放多元、产业融合、创新引领”，代表了中国网络安全高水平和前沿声音，是立足北京、辐射全球的优秀产业交流合作平台，是首都北京重要的战略窗口与科技名片。

  

自2019年以来，BCS已成功举办三届。2022北京网络安全大会（BCS2022）将于5月24日-26日在北京•国家会议中心举办，大会特设冬奥日、产业日、技术日三大主题日，共展开3场国际峰会、40多场分论坛及第七届观潮网络空间论坛、第七届安全创客汇、第六届“蓝帽杯”全国大学生网络安全技能大赛等特色品牌活动。
