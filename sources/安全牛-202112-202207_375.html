格创东智


工业互联网公司格创东智科技有限公司（简称“格创东智”）2018年创立，以“格物智，创兴邦”命名，蕴含格创东智和它的战略孵化者TCL以科技创新实现制造强国的初心。2020年获得投资机构云锋基金亿元级A轮融资。

岗位详情


● 信息安全工程师1


公司官网：https://www.getech.cn

招聘地点：深圳、广州

截止时间：2022年5月31日

招聘邮箱：chenxiang37@tcl.com


岗位职责：

1、主导信息安全技术架构规划和设计；

2、根据公司管理及业务需求，制定技术研究与应用方案；

3、主导信息安全技术可行性分析与产品选型，进行产品对比、技术验证、技术成果论证，风险预防与控制；

4、主导问题真因分析与解决、识别并改善系统运维风险。


岗位要求：

1、5-10年信息安全岗位工作经验，本科或以上学历，计算机、通讯、网络相关专业优先；

2、精通信息安全基础理论知识，信息安全政策与标准；

3、精通主流的安全技术，如防病毒、网络安全、主机安全、应用安全、密码技术等；

4、熟悉主流操作系统、数据库、网络与应用系统的工作原理，全面掌握常见的安全漏洞及利用技术；

5、熟悉防火墙、IDS等安全设备；

6、熟悉网络安全审计的各种技术手段及软件使用，熟悉利用包分析软件检查网络问题；

7、熟悉网络及应用系统的常见安全漏洞与隐患，能够利用已有工具进行识别和评估。

● DBA


公司官网：https://www.getech.cn

招聘地点：宜兴

截止时间：2022年5月31日

招聘邮箱：weifeng1.wang@getech.cn


岗位职责：

1）负责大中型项目、产品的数据库运维；

2）负责制定较大数据库的存储架构，备份及恢复策略；

3）指导和协助团队内其他成员，数据库编辑相关的规范和方法；

4）负责已有项目的数据库性能调优；

5）完成公司安排的其他数据库相关工作和任务。


任职资格：

1）本科及以上学历，计算机，信息化相关专业，3年以上DBA经验；

2）精通Oracle/SQL数据库；

3）能熟练进行SQL查询优化，有大数据处理经验；

4）精通Oracle的各种部署、备份、恢复机制和方法，能根据业务实际制定相应的方案；

5）熟练使用Windows Server 2012/Unix/Linux操作系统，熟悉常用shell工具；

6）持有相关资格证书优先，如OCP，MCSE，RHCE。


● 服务器运维工程师


公司官网：https://www.getech.cn

招聘地点：内蒙

截止时间：2022年5月31日

招聘邮箱：weifeng1.wang@getech.cn


工作职责：

1）负责公司IT硬件、网络设备、服务器的运维管理；

2）负责公司服务器的监控、备份及恢复；

3）负责公司服务器的容灾管理；

4）负责公司邮箱系统的运维。


任职资格：

1）本科及以上学历，计算机，信息化相关专业，3年以上服务器运维经验；

2）熟练使用Windows Server 2012/Unix/Linux操作系统，熟悉常用shell工具；

3）熟悉服务器虚拟技术：VM、hyper-v、KVM；

4）熟悉zabbix监控；

5）持有相关资格证书优先，如VCP，MCSE，RHCE。
