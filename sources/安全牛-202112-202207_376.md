随着IT人才缺口不断扩大，全球企业也在竭尽所能地吸引顶尖技术人才。据Robert Half Technology发布的《2022年IT薪资报告》所示，科技行业的招聘人数正在增加，大有超越疫情前水平的趋势。在受访者中，52%的企业表示，他们计划在来年增加新职位；80%的企业表示，他们公司的营业额在过去一年有所增加。在此背景下，热门技能领域的适配人才将抢占先机，以填补今年最急需的职位缺口，而与网络信息安全相关的职位，将受到企业特别关注。

•  25分位：新手，仍在学习相关技能；

**▶ 云计算架构师**

  

网络/云计算架构师负责规划、设计、部署、管理和升级组织的网络和云项目及应用程序。除了网络、编程和安全技能外，网络/云架构师通常还需要对多个操作系统有深入的了解。企业应该寻找对云服务（如Amazon Web Services）有深入了解的人才，并且具备ITSM、网络、I&O、治理、自动化和供应商管理方面的经验。

  

必备技能和经验：

•  了解最先进的云技术和架构原则；

•  多年网络和云技术经验；

•  具有扩展云应用程序的经验；

•  了解云系统的成本、性能和架构；

•  协作和沟通技巧。

  

**▶ 网络安全分析师**

  

随着组织越来越关注企业隐私和安全，网络安全分析师的需求量将进一步扩大。这些IT专业人员负责设计和实施IT安全系统和解决方案，以确保公司的网络受到保护。企业聘请的人才需要能够有效监控复杂计算机网络的安全漏洞，并预测任何潜在的安全风险。此类候选人通常拥有计算机科学学士学位，有些人还可能拥有信息系统方面的MBA学位。该角色需要强大的技术和分析技能，以了解IT要求和目标，并设计、分析和实施IT安全系统。

  

必备技能和经验：

•  具备安装、升级、测试、分析和管理安全系统的经验；

•  具备渗透测试和技术经验；

•  网络漏洞知识；

•  具备补丁管理、防火墙、防病毒、入侵检测和防御系统（IDPS）的经验；

•  良好的沟通和书面技能，以提供适当的文档。

  

**▶ 计算机和信息系统管理员**

  

计算机和信息系统管理员负责监督企业的信息技术目标。这些IT专业人员的任务是分析组织的技术需求，并向高管推荐升级或新技术，负责监督计算机硬件和软件的规划、实施和维护。此外，在管理组织中IT专业人员的同时，他们还有望掌握公司的IT安全和预算。该职位的候选人通常拥有计算机或信息科学学士学位，并具有相关工作经验。

  

必备技能和经验：

•  具备数据库管理系统软件、ERP软件、Web平台开发软件及相关工具的经验；

•  硬件、软件、工程和数学知识；

•  了解业务管理原则、一般业务运作；

•  客户服务、沟通和管理技能。

  

**▶ 软件开发工程师**

  

软件开发人员负责设计、开发、安装、测试和维护软件系统。这项工作需要编码、设计和构建应用程序、网站或移动应用程序，使用多种编程语言，如C#、C++、HTML、Java、Microsoft .NET 和SQL Server。开发人员需要能够了解客户需求，并能够为改进Web、软件和移动应用程序提供建议，以确保它们满足用户需求。

  

必备技能和经验：

•  了解多种编程语言；

•  分析和技术能力；

•  沟通能力强；

•  计算机科学学士学位；

•  具有认证、训练营和先前工作经验的两年制副学士学位。

  

**▶ 计算机程序员**

  

计算机程序员的任务是编写代码，以帮助开发或改进软件应用程序和软件解决方案。该角色通常专注于管理各种操作系统、设计和更新软件以及编写或更新源代码。计算机程序员经常与软件开发人员密切合作，为组织创建程序、软件和服务。

  

必备技能和经验：

•  强大的编码能力；

•  编码、测试、故障排除、分析、维护和开发程序的能力；

•  了解多种编程语言；

•  跨多个系统实施计算机程序的经验；

•  强大的时间和项目管理能力。

  

**▶ Web开发人员**

  

Web开发人员负责开发符合业务需求的基于Web的应用程序。强大的Web开发人员可以编写应用程序并编写脚本，构建和优化安全网页，维护多个Web应用程序，与利益相关者进行有效沟通，并执行定期站点审核和定期维护。

  

企业需要聘请具有组织所需技能的Web开发人员，因为在Web开发的范畴内存在大量的技能和经验集。通常情况下，企业聘请的人才需要具备使用WordPress、AWS、MYSQL、JavaScript、Ruby、CSS和其他流行框架和编程语言的经验。

  

必备技能和经验：

•  强大的编码技能和多种编程语言知识；

•  强大的沟通技巧，以收集客户需求并与之密切合作；

•  前端和后端编码技能；

•  能够管理各种环境中的部署，包括云。

  

**▶ 系统分析师**

  

系统分析师主要通过分析组织中的IT系统来帮助解决业务问题。他们负责调查问题，并以有效且具有成本效益的方式解决它们。系统分析师需要测试程序和数据库，以确保它们有效地工作，而且他们需要运行安全审计并创建和维护组织系统中的文档。企业寻找的候选人需要能够进行创造性思考，并具有很强的沟通和解决问题的能力。

  

必备技能和经验：

•  CS，IT，工程或IS学士学位；

•  分析和解决问题的能力；

•  数据分析和编程技能；

•  具有业务和技术分析以及项目管理经验。

  

**▶ 数据库管理员和架构师**

  

数据库管理员和架构师主要负责构建和维护用于管理数据库的软件，并确保数据可供需要的人轻松访问。架构师通常专注于设计和构建数据库，而管理员则专注于数据库系统的日常操作。这些角色确实存在很多交叉——管理员和架构师的任务是确保服务器保持高效和可操作性，同时监督数据安全、实施、复制、备份、存储、访问和分区。企业聘请的人才不仅需要设计、构建和监控服务器，而且还能够优化性能并在紧急情况下随时待命。

  

必备技能和经验：

•  CS学士学位或数据库管理副学士学位；

•  IT工作或数据库管理背景；

•  Oracle、Linux和SQL技能；

•  数据分析、管理和报告技能。

 

**▶ 网络和计算机管理员**

  

网络和计算机管理员负责处理企业中计算机网络的日常操作。这些IT专业人员通常拥有计算机科学学士学位，并且应该熟悉LAN/WAN协议、软件和硬件。该职位需要花费大量时间进行故障排除，且通常需要随时待命，以防出现紧急情况或故障。

  

必备技能和经验：

•  故障排除和沟通技巧；

•  分析和诊断技能；

•  愿意在下班后随叫随到；

•  专业认证。

  

**▶ 帮助台技术支持人员**

  

对于面向客户的企业而言，帮助台是企业高效运营的重要组成部分。作为客户服务和故障排除的第一道防线，帮助台的技术支持人员需要具备工作所需的技术和软技能。Robert Half Technology将帮助台技术人员的角色分为三级，因为工作描述和要求可能因业务而异。

  

必备技能和经验：

•  I层：入门级职位，需要两年左右的经验、技术学校的副学士学位或课程；

•  II层：需要两-四年相关工作经验、学士学位；

•  III层：四年或以上帮助台设置经验、相关领域的学士学位和专业证书。
