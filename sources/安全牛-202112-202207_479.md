# 八成金融高管对现有身份认证技术不满

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651108137&idx=3&sn=a436614a3f27bf3963adaeef2d27ba12&chksm=bd1403fa8a638aec38a129f8cb37487526d8dd4cea01cffe1cfd1b34f4dab4aca6169774c663&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651108137&idx=3&sn=a436614a3f27bf3963adaeef2d27ba12&chksm=bd1403fa8a638aec38a129f8cb37487526d8dd4cea01cffe1cfd1b34f4dab4aca6169774c663&scene=27#wechat_redirect)

根据生物特征认证提供商authID.ai最近发布的一项行业调查，80% 的金融科技决策者对与传统身份认证选项相关的风险表示中度到高度的担忧；75%的高管还对一次性密码（OTP）和基于知识的身份验证（KBA）表示至少中等程度的担忧。  

  

由于传统 IT 安全工具有可被利用的漏洞，包括网络犯罪分子获取 SMS PIN 码或使用易于猜测的安全提示进行欺诈性帐户接管。因此，高管们对这些工具表现出担忧，但只有 22% 的受访者表示正在使用替代系统，例如面部生物识别身份验证；84% 的受访者预计明年将增加对 IT 安全的投资；70% 的受访者很有可能或在一定程度上考虑明年将面部识别身份验证作为 OTP/KBA问题的替代方案。

  

这些发现反映出企业安全解决方案（包括生物识别技术）的新兴趋势，因为企业希望更好地保护客户数据并改善其在数字（通常是基于云的）交易中的体验。鉴于 88% 的受访者表示他们熟悉面部生物识别技术（也称为“面部匹配”），这种安全解决方案很有可能在金融机构的身份认证交易、个人消费技术等方面发挥越来越大的作用。
