深圳昂楷科技有限公司


     深圳昂楷科技有限公司是领先的数据安全治理产品及解决方案专业研发企业，从公司成立伊始，就聚焦于数据安全领域。已经为医疗、政府、公检法司、电信运营商、电力、石化、互联网、先进制造等多个行业的3000多家客户提供了数据安全解决方案。产品解决方案广泛适用于大数据、云计算、云原生、人工智能、工业控制、物联网、智慧应用、IDC等应用场景，形成了完整的结构化SQL及NoSQL数据安全解决方案体系，涵盖DCAP、DAP、DSP等领域。产品解决方案及服务有：数据安全综合治理平台、数据资产梳理系统、数据分类分级、数据库审计、数据库防火墙、数据脱敏、数据库漏扫、数据库状态监控、数据水印、集中管理平台和数据安全风险评估、数据库渗透测试服务等，构建了数据资产运营、行为模型运营、安全风险运营和安全策略运营四维形成运营度量“五位一体”的数据安全运营体系，为客户提供全方位的数据安全治理服务。


     公司秉承“为客户创造价值是公司唯一存在理由”的经营方针，狠抓“踏踏实实做人，扎扎实实做产品”的服务理念，以“不做关系型产品”为座右铭，以IPD流程为经营服务理念的落地保障；始终坚持自主研发、大力投入研发，以市场需求为导向，在数字化的浪潮里，走在行业的前沿。

岗位详情


● 区域销售总监/办事处主任


招聘地点：北京、济南、重庆


岗位要求：

1. 大专及以上学历，计算机、通信、市场营销或相关专业，从事信息安全及相关行业工作5年以上；

2. 熟悉所在区域或行业的基本情况，有明确的拓展思路和规划；

3. 具备通信、信息安全等相关销售管理经验者优先；

4. 有政府、医疗、金融、运营商、能源行业资源者优先；

5. 负责区域办事处团队的搭建、管理，带领团队完成销售目标和任务。


● 销售总监


招聘地点：北京、上海、石家庄、广州


岗位要求：

1. 大专及以上学历，计算机、通信、市场营销或相关专业毕业，从事信息安全及相关行业工作5年以上；

2. 熟悉所在区域或行业的基本情况，有明确的拓展思路和规划；

3. 对所在区域的IT公司很熟悉，特别是对行业性的公司有很深的了解；

4. 有丰富的政府、金融、医疗、能源、运营商等行业资源者优先；

5. 具备挖掘和解决客户痛点及项目运作和商务关系处理能力；

6. 具备一定的团队管理经验。


● 大客户总监


招聘地点：北京


岗位要求：

1. 大专及以上学历，计算机、通信、市场营销或相关专业毕业，从事相关安全行业工作5-6年以上；

2. 对所在区域的IT公司很熟悉、特别是对行业性的公司有很深的了解；

3. 有丰富的政府、金融、能源、公安、运营商、国央企等其中之一行业资源者优先；

4. 具备挖掘和解决客户痛点及项目运作和商务关系处理能力。


● 销售经理


招聘地点：全国


岗位要求：

1. 大专及以上学历，2-5年左右销售经验；

2. 从事过网络信息安全行业或系统集成项目管理及网络安全设备区域分销者优先；

3. 有医疗/政府/公安/金融等行业资源者优先；

4. 有开拓新客户、挖掘和解决客户痛点的能力；

5. 具备项目运作和商务关系处理能力，有品牌推广意识、具备良好的职业操守。


● 解决方案专家


招聘地点：深圳


岗位职责：

1. 负责对重要客户、公司合作伙伴进行技术交流以及解决方案的开发与运营；

2. 协助销售团队推动项目管理，支撑产品的落地，输出更符合客户需求的方案；

3. 研究数据安全行业的发展方向，开发行业解决方案；

4. 协调部门资源、分享行业经验、更新销售工具包及提高团队交付质量。


岗位要求：

1. 本科及以上学历，计算机、网络、信息等相关专业；

2. 熟悉网络安全、数据治理等技术领域，有数据安全领域工作的优先；

3. 有扎实的文案功底，较强的理解和总结能力，沟通表达能力，良好的责任心；

4. 接受不定期的出差。


● 售前专家/工程师


招聘地点：深圳、北京、广州、武汉、杭州、上海、成都


岗位职责:

1. 负责项目售前交流、产品演示、试用测试、招投标等项目的售前阶段工作；

2. 针对客户的需求及业务系统的架构，提供合理的需求分析以及对应的解决方案输出；

3. 负责项目的前期客户环境的调研分析、产品版本对应、参数识别判断；

4. 负责对内外赋能，包括对外合作伙伴，对内销售部以及新人培训等相关工作；

5. 负责信息的收集，改进产品质量。


岗位要求:

1. 专科及以上学历，计算机、网络或信息安全等相关行业；

2. 具备营销材料编写、产品宣讲、市场调研和分析能力；

3. 熟悉网络基础，有相关的工程实施经验更佳；

4. 优先考虑的条件：具有安全行业从业经验，具备CISSP、CISP、CCNP、CISA、COBIT等相关的认证；熟悉防火墙、IPS、WAF等业内主流产品。
