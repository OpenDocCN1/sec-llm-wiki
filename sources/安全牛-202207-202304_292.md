# 北京市通信管理局通报20款问题APP

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651119698&idx=2&sn=e18c4e385e406b821b581ad1b56ce22e&chksm=bd1450818a63d99775fc95d50ee1e5f3bd13a35dfaa3db983eb1484cfdc95c3ba846a465db0e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651119698&idx=2&sn=e18c4e385e406b821b581ad1b56ce22e&chksm=bd1450818a63d99775fc95d50ee1e5f3bd13a35dfaa3db983eb1484cfdc95c3ba846a465db0e&scene=27#wechat_redirect)

依据《网络安全法》《数据安全法》《个人信息保护法》《网络产品安全漏洞管理规定》等法律法规，北京市通信管理局组织开展北京地区APP技术检测工作。  

  

现将存在侵害用户权益和安全隐患等问题的20款APP通报如下（详见附件），请有关APP运营企业立即整改，并于11月15日前提交整改报告。逾期不整改或整改不到位的，我局将依法依规予以处置。
