# 产业观察丨派拉软件研究发布《银行零信任安全白皮书》

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651118934&idx=3&sn=86077e7c04d7c362439b68bec7906b68&chksm=bd146d858a63e49380e8a3ae08f2b28764ec78d22d4f0806d0a308b120141359411fe1675d4e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651118934&idx=3&sn=86077e7c04d7c362439b68bec7906b68&chksm=bd146d858a63e49380e8a3ae08f2b28764ec78d22d4f0806d0a308b120141359411fe1675d4e&scene=27#wechat_redirect)

日前，派拉软件发展研究院发布《银行零信任安全白皮书》，旨在指引利用零信任安全技术的优势，加快推进并完善银行数字化业务安全的建设与发展。

  

白皮书研究人员表示：银行机构在业务数字化转型中，需要严格落实法律法规，将监管要求与风险管理等流程和机制充分整合到现有安全管理策略中。为了更好地解决信息安全风险问题，组织需要构建银行零信任安全架构，把身份安全、终端安全、网络安全、API安全包含进去，在满足业务需求的前提下提供一体化的安全保障。

  

![](../Images/129ccb3f954f2cf1c431f46a8a1b5e96.png)

  

据介绍，本白皮书共五个章节，从银行业信息化发展的环境背景着手，对其面临的安全挑战进行思考，提出银行零信任安全框架及业务场景的实现路径，并进一步对安全合规与隐私保护进行分析。同时，结合网络安全发展趋势，对银行业零信任安全的发展进行剖析，可以为银行组织数字化转型安全发展与建设提供参考。
