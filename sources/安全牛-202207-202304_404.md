# 美国商务部出台芯片法案实施细则，“安全合规”成为优先考虑因素！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njc3NjM4MA==&mid=2651118471&idx=2&sn=760522ea5ff551c12f5bd380f8496783&chksm=bd146b548a63e24251a3768ffcd88bf857a2c648b257de5134db59aab0fb4db7f07c042b7208&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651118471&idx=2&sn=760522ea5ff551c12f5bd380f8496783&chksm=bd146b548a63e24251a3768ffcd88bf857a2c648b257de5134db59aab0fb4db7f07c042b7208&scene=27#wechat_redirect)

据《纽约时报》报道，美国商务部日前正式出台了芯片法案实施细节，对美国总统拜登上个月签署的500亿美元CHIPS芯片法案的具体实施工作进行指导。细则内容显示，CHIPS激励计划将优先考虑遵守信息安全、数据跟踪和验证标准和指导方针的项目，并在进一步开发和采用此类标准方面进行推广。

  

根据实施细则内容显示，美国商务部对潜在申请机构提供了明确的建议，并确定了评估申请的准则，具体标准包括：

  

1.  **扩大规模并吸引私人资本：**CHIPS激励计划将鼓励吸引相关供应商和劳动力投资的大规模投资。
    
      
    
2.  **利用合作建立半导体生态系统：**CHIPS激励计划将鼓励行业利益相关者、投资者、客户、设计师和供应商以及国际公司之间的合作。
    
      
    
3.  **建立加强区域和地方产业集群：**CHIPS激励计划会优先考虑包括州和地方一揽子激励计划在内的项目，这些项目旨在最大限度地提高区域和地方竞争力，投资于周边社区，优先考虑广泛的经济收益。
    
      
    
4.  **建立安全的半导体供应链：**CHIPS激励计划将优先考虑遵守信息安全、数据跟踪和验证标准和指导方针的项目，并在进一步开发和采用此类标准方面进行合作。
    
      
    
5.  **优先满足美国本土劳动力需求：**CHIPS激励计划将优先考虑美国本土劳动力解决方案，创造更多有报酬的培训和体验性学徒工作机会岗位，优先考虑创造性的招聘策略，并根据其获得的技能雇用工人。
    
      
    
6.  **为企业提供可共享的商业机会：**CHIPS激励计划将优先考虑积极努力确保小企业、少数民族所有、退伍军人所有和妇女所有的企业以及农村地区的企业从CHIPS计划创造的机会中受益的项目。
    
      
    
7.  **提供财务审核计划：**申请人需要提供详细的具体项目和公司级财务数据，以确保激励基金在保护纳税人资金的同时满足项目的经济和国家安全目标。
    

  

CHIPS芯片法案自颁布起就备受争议，尽管其宣称旨在提升美科技和芯片业的竞争力，但却对美国本土芯片产业提供巨额的补贴，推行差异化的产业扶持政策，包含了多条限制有关企业在我国正常投资与经贸活动，以及中美正常科技合作的条款，将对全球半导体供应链造成扭曲，对国际贸易造成扰乱。我国政府及有关部门对此表示坚决反对，中国贸促会、中国国际商会等组织均已正式发布声明，反对美国相关法案不当干预和限制全球工商界经贸与投资合作。
