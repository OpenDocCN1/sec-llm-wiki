# 微软发布2014年8月安全补丁 安全狗提醒及时更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2NDM4MQ==&mid=200419391&idx=3&sn=7a4296617c491d72f630b085bfc5a94c&chksm=28f509cd1f8280db0edc9981332edee22d34daaae2a20f907c1383b9a3161c2bb15b5952d2d8&scene=126&sessionid=1681368542#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTc2NDM4MQ==&mid=200419391&idx=3&sn=7a4296617c491d72f630b085bfc5a94c&chksm=28f509cd1f8280db0edc9981332edee22d34daaae2a20f907c1383b9a3161c2bb15b5952d2d8&scene=126&sessionid=1681368542#rd)

北京时间8月13日凌晨，微软公司如期发布了8月份安全更新，本次更新涉及9个公告号，累计修复了37枚漏洞。其中一枚IE累积功能更新补丁修复了26个可能导致内存溢出的漏洞，而且均标记为严重安全级别、易受攻击。  
  
本次受影响的产品涉及Windows、OneNote 2007、SQL Server 2008及以上、SharePoint Server 2013、Windows Media Center TV Pack以及桌面Windows平台。  
  
目前服务器安全狗也已同步升级补丁库，建议用户尽快更新补丁，避免遭遇黑客攻击。

![](../Images/4c034abb531bcb18712555c14a8cd23c.png)

微软8月安全补丁简要如下：  
  
**MS14-051：Internet Explorer积存信息安全更新**  
  
此安全更新可解决Internet Explorer中一项公开揭露的信息安全风险，以及25项未公开报告的信息安全风险。其中最严重的信息安全风险，可能在使用者以Internet Explorer检视蓄意制作的网页时允许远程执行程序代码。成功利用这些信息安全风险的攻击者可以取得与目前使用者相同的用户权力。系统上帐户用户权力较低的客户，其受影响的程度比拥有系统管理权限的客户要小。  
  
**MS14-043：Windows Media Center中的漏洞可能允许远程执行程序代码**  
  
此安全更新可解决Microsoft Windows中一项未公开报告的信息安全风险。如果使用者开启蓄意制作、可呼叫Windows Media Center资源的Microsoft Office档案，此信息安全风险可能会允许远程执行程序代码。成功利用此信息安全风险的攻击者可以取得与目前使用者相同的用户权力。系统上帐户用户权力较低的客户，其受影响的程度比拥有系统管理权限的客户要小。  
  
**MS14-045：内核模式驱动程序中的漏洞可能会允许特权提升**  
  
这个安全更新可解决Microsoft Windows中三项未公开报告的漏洞。如果攻击者登入系统并执行蓄意制作的应用程序，则最严重的漏洞可能会允许特权提升。攻击者必须拥有有效的登入认证，并能够登入本机，才能利用这些漏洞。  
  
**MS14-049：Windows Installer服务中的漏洞可能会允许特权提升**  
  
此安全更新可解决Microsoft Windows中一项未公开揭露的漏洞。如果攻击者执行蓄意制作的应用程序，尝试修复先前安装的应用程序，则此漏洞可能会允许特权提升。攻击者必须拥有有效的登入认证，并能够登入本机，才能利用这项漏洞。  
  
**MS14-047：LRPC中的漏洞可能会允许信息安全功能略过**  
  
此安全更新可解决Microsoft Windows中一项未公开报告的漏洞。如果攻击者利用此信息安全风险搭配另一个会利用ASLR略过来执行任意程序代码的信息安全风险(例如远程执行程序代码信息安全风险)，此漏洞可能会允许信息安全功能略过。  
  
MS14-044：SQL Server中的漏洞可能会允许提高权限  
  
这个安全性更新可解决Microsoft SQL Server中两项未公开报告的漏洞(一个是在SQL Server Master Data Services中，另一个则在SQL Server关系数据库管理系统中)。这些漏洞较严重者除了影响SQL Server Master Data Services之外，同时如果使用者浏览了蓄意制作的网站，而该网站在使用者的Internet Explorer实例中放入客户端脚本，这时就可能允许提高权限。无论如何，攻击者无法强迫使用者检视受攻击者控制的内容，而是引诱使用者自行前往。一般的做法是设法让用户点选电子邮件讯息或Instant Messenger中通往攻击者网站的连结，或设法让他们开启经由电子邮件传送的附件。  
  
MS14-046：.NET Framework中的漏洞可能会允许信息安全功能略过  
  
这个安全更新可解决Microsoft .NET Framework中一项未公开报告的漏洞。如果用户造访蓄意制作的网站，此漏洞可能会允许信息安全功能略过。在网页浏览攻击的案例中，成功利用此漏洞的攻击者可以略过地址空间随机加载(ASLR)安全性功能，而此功能可协助保护用户免于广泛类别的信息安全风险侵扰。略过安全性功能本身不会允许执行任意程序代码。但是，攻击者利用此ASLR略过信息安全风险时，可能会搭配另一个利用ASLR略过来执行任意程序代码的信息安全风险(例如远程执行程序代码信息安全风险)。  
  
MS14-048：OneNote中的漏洞可能会允许远程执行程序代码  
  
此安全更新可解决Microsoft OneNote中一项未公开报告的漏洞。如果在受影响版本的Microsoft OneNote中开启蓄意制作的档案，此漏洞可能会允许远程执行程序代码。成功利用此信息安全风险的攻击者可以取得与目前使用者相同的用户权力。系统上帐户用户权力较低的客户，其受影响的程度比拥有系统管理权限的客户要小。  
  
MS14-050：在Microsoft SharePoint Server中的漏洞可能会允许特权提升  
  
这个安全更新可解决Microsoft .SharePoint Server中一项未公开报告的漏洞。成功利用此漏洞且通过验证的攻击者，可在目前SharePoint网站上，以使用者的权限层级利用蓄意制作的应用程序来执行任意JavaScript  
  
更多信息，可参考2014年8月微软安全公告摘要：https://technet.microsoft.com/library/security/ms14-aug
