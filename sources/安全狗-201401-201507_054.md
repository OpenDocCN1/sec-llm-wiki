# 安全狗·服云web端V3.3.1版上线啦！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2NDM4MQ==&mid=208010499&idx=2&sn=a2c4fad7abba84be67427e186efbde8f&chksm=2f62dcf1181555e754caed33e5b971916609a998d83ff65ede01995a6745e390ea3c6d4cf4da&scene=126&sessionid=1681368471#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTc2NDM4MQ==&mid=208010499&idx=2&sn=a2c4fad7abba84be67427e186efbde8f&chksm=2f62dcf1181555e754caed33e5b971916609a998d83ff65ede01995a6745e390ea3c6d4cf4da&scene=126&sessionid=1681368471#rd)

随着六一儿童节安全狗·服云新版官网的上线，6月3号，经过一个多月产品规划、研发测试后，服云web端V3.3.1版也更新上线啦。

  

此次上线的安全狗·服云web端新版主要针对安全防护等功能进行优化，具体包括以下几点：

  

1.新增网站安全防护linux-nginx版的设置功能；

  

2.在windows服务器安全防护的文件及目录保护中增加规则设置功能；

  

![](../Images/3bf55ae8d0162ced310bca240f8cdcbe.png)  

（备注：为保障用户账号安全，用户在点击规则设置的时候将会跳出一个验证框，需用户进行手机验证。）

  

3.在安全防护功能中，跟进软件安装情况补充软件未安装引导说明；

  

4.安全防护功能界面优化，调整界面自适应、增加选中状态等；

  

5.优化告警中心导出功能。

  

![](../Images/81ab1de3a0b93d5f31e08a15cb3f28a0.png)  

  

随着服云新官网的上线以及版本的不断升级优化，“云安全 新运维”开始正式成为安全狗·服云的新思路，并将不断加大力度去利用这个思路来开发更有利于保障服务器以及网站安全的新技术，为用户提供更高效的网络安全。

  

**“安全狗”是个啥？**

**安全狗**， 知名互联网安全品牌，领先的云安全与解决方案提供商。安全狗首创的云+端的云安全管理平台（SAAS模式）为用户解决公有云、私有云和混合云环境中可能遇到的安全及管理问题；提供了包含自动化系统风险识别和加固、系统级的安全防护（防黑/防入侵/抗攻击）、云监控（安全监控/性能监控/日志监控）、云管理（多公有管理/混合云管理）以及基于大数据架构的安全事件分析等功能。
