# 【获奖通知】安全狗微信送大白活动获奖名单公布啦

﻿亲，安全狗**4月27日****\-28日**举办的线上活动顺利结束了，我们根据活动规则，按照微信信息回复的先后顺序，排出了本次活动的前**60名**获奖名单，获奖用户将获得由安全狗寄出的大白公仔一个。另外，没有获得本次活动奖品的粉丝也别灰心，之后我们还将陆续举办更具诱惑力的活动，请大家继续关注支持哦。

  

由于获奖名单较多，这里就只截一部分名单，没有出现在本条微信的其他获奖粉丝我们将逐一回复，请大家注意查收。

  

**注**：获奖粉丝需在**4月30号前**将姓名、接收地址以及电话号码在安全狗官方微信上直接回复，我们将在5月4号统一寄出奖品。如果在4月30号前还没看到您的回复，我们将视您为自动放弃本次活动奖品。
