漏洞预警：Samba 4.x.x全版本存在命令执行漏洞

原文：http://mp.weixin.qq.com/s?__biz=MjM5NTc2NDM4MQ==&mid=200365349&idx=2&sn=96b4bfc706a34d4e76b8cf75a672e805&chksm=28f674d71f81fdc18e8dc985ae1bdbef127f354644966b6792e4bf067598a6cc0c100a48cc26&scene=126&sessionid=1681368547#rd

近日，Samba 4.0.0到4.1.10版本的nmbd(the NetBIOS name services daemon)被发现存在远程命令执行漏洞。CVE编号为CVE-2014-3560。

目前官方已经发布最新补丁，提醒各位用户朋友们及时关注并进行处理。地址：http://www.samba.org/samba/history/security.html

何为Samba，它是种用来让UNIX系列的操作系统与微软Windows操作系统的SMB/CIFS（Server Message Block/Common Internet File System）网络协议做链接的自由软件。第三版不仅可访问及分享SMB的文件夹及打印机，本身还可以集成入Windows Server的域名，扮演为域名控制站（Domain Controller）以及加入Active Directory成员。简而言之，此软件在Windows与UNIX系列OS之间搭起一座桥梁，让两者的资源可互通有无。（@FreeBuf）
