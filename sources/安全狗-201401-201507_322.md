本期主要安全内容回顾：

  

**中国肉鸡最多？Q1 中国IP 攻击流量达41% 高居榜首**

  

根据Akamai公司近日发布的《2014年第一季互联网发展状况报告》来自中国IP地址的攻击流量占据榜首，高达41%，远远高于第二名的美国(11%)。但IP地址确定的攻击来源国未必是攻击者所在的居住地，这意味着中国可能存在数量惊人的“肉鸡”。

  

Akamai 2014年第一季度观测194个国家或地区的攻击流量显示：来自中国IP地址的攻击流量占据榜首，但占比从2013年第一季度的43%轻微下降至41%。来自美国IP地址的攻击流量也从19%下降至11%，居第二位。印尼则从5.7%轻微上升至6.8%，居第三位。总体而言，攻击集中程度较2013年第四季度有显著下降。

  

**多重身份认证保护数据存取安全日渐普遍**

  

全球领先的数据保护供应商Safenet 最新研究报告指出，鉴于数据保护风险的增加、以及用户对跨设备的无缝对接和安全存取数据的需求，促使了身份认证解决方案获得了广泛的应用。在2014年全球身份认证调查中，超过三分之一的机构正在使用多重身份认证(Multi-factorAuthentication) ，让数据存取可在多个设备和多个位置无缝安全地进行。

  

调查结果显示，越来越多企业正采用多重身份认证，并应用于更广泛的工作模式中。该调查结果与近期的451 Research 报告1 相近，揭示了数据访问控制和身份认证是当前各企业IT 部门的难题及优先考虑的事项。外来恶意入侵者2013年造成了57%的数据外泄2，多重身份认证可降低非授权用户存取敏感数据的风险，却同时能让授权员工在需要时不受时间和空间的限制而灵活的存取企业数据。

  

**小评**：互联网的高速发展使得数据量日益巨增，安全问题由为重要，新技术的普及势在必行。

  

**卡巴斯基新技术企业机密文件的安全首选**

  

近日，卡巴斯基实验室枝繁叶茂的专利家族中又新增了一项技术。据了解，这项技术由美国专利技术局颁发，可以检测出企业IT 架构中的潜在威胁。更重要的是，使用这项技术不会泄露企业的机密信息。目前，这项专利技术已应用于Kaspersky Endpoint Security 8.0 for Windows 以及Kaspersky Endpoint Data Protection Edition (Endpoint 10)中。

  

 对于研发这项新技术的重要意义，卡巴斯基实验室全球紧急响应团队负责人，同时也是该专利技术的作者之一Alexey Polyakov 表示：“从事敏感数据的公司往往沦为其隐私的受害者，因为他们为了保护宝贵信息免遭泄露而将其置于其他威胁之中。但是恶意软件会感染所有文件，不论其是否为机密文件。而发送极小部分的受感染文件用以确认通常是十分安全的。这样可以使卡巴斯基实验室的技术检测出威胁，并且无需获取机密资源就能找出适当的解决方案。”

  

**小评：**新技术带来的是新的市场和新的机遇，同时也为用户提供更好的安全保护。

  

**高级网络攻击行为使得采取主动防御成为必要**

  

从叙利亚电子军团(Syrian Electronic Army)入侵《纽约时报》网站，到针对主要数据中间商进行的、把数以百万计用户置于风险境地的长期黑客行为，网络攻击者在窃取敏感信息和造成重大服务中断方面正变得越来越复杂、且有效。窃取我们的个人信息和知识产权的网络攻击行为每天都在发生。针对企业的民族国家攻击日益将我们的工作与经济置于危险之中。

  

虽然使主动防御成为防御常态仍有大量工作要完成，但我们却不能再继续等下去了，因为这样做的潜在成本太过高昂。维持现状只会给我们带来挫折感，并让攻击者持续坐收渔利。从现在开始，我们应共同合作构建壁垒，并实施积极防御。

  

**小评：**主动出击比被动防御更能有效的抵抗各种攻击，虽然前期需要大量的工作量去部署，但收获的效果将会更加让人满意，相信这会成为以后的发展趋势。

  

**微软调整安全通知服务不会停止发送补丁邮件**

  

北京时间7月2日消息，据国外媒体报道，关于软件的漏洞和安全问题，微软宣布将不会停止提前发送周二补丁日的提示邮件。据报道，微软此次宣布了对“补丁提示”邮件的改变，即信息会由原定的当地时间6月27日被发出改变至7月1日发出，在昨天晚上微软向用户发送一封邮件中表示，原定6月27日发出提示邮件的计划在经过考虑后被放弃了，并且微软此前的安全通知服务也将进行调整。微软也向媒体证实了这次事件。

  

微软表示:自7月1日开始，微软就“暂停安全通知发送”这一事件宣布了以下事项:安全公告高级提示，安全公告摘要，新的安全公告和警告，安全警告和公告的主要和次要的修改。

  

据悉，微软此次计划的改变，主要是因为加拿大政府和亚洲某些国家对微软相关产品和服务进行了严格的法律限制。

  

**小评：**树大招风，谁叫你是垄断呢。微软的一举一动都被亿万双眼睛盯着吧。

  

**PHP5.6 被发现存在堆溢出漏洞**

  

这个漏洞，应该不是Stefan Esser发现的，应该是Stefan Esser看到了github上的commit才随藤摸瓜找到了这个漏洞，看来关注更新的确是一个好习惯啊。 

  

漏洞存在于DNS TXT 记录解析这个功能之中。Stefan Esser 在github 的一个代码提交中发现了这个漏洞。当PHP 程序运行dns\_get\_record()的时候，恶意的服务器或者是进行中间人攻击的黑客可以利用这个漏洞执行任意代码。产生漏洞的代码存在于ext/standard/dns.c，可以看到代码之中加入了针对于长度的判断。

  

while (ll < dlen) { n = cp\[ll\]; + if ((ll + n) >= dlen) { + // Invalid chunk length,

truncate + n = dlen - (ll + 1); + } memcpy(tp + ll , cp + ll + 1, n);

add\_next\_index\_stringl(entries, cp + ll + 1, n, 1); ll = ll + n + 1;

  

Red Hat bug 也收录了这个漏洞，但也没有给出具体细节。

  

**小评：**漏洞总是被某些细心的用户发现，就好像是一个足不出户的大家闺秀一样，等待着被人欣赏、被人发挖。
