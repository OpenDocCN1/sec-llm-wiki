# 网站安全狗（IIS）V3.1增强版 新增定时网马扫描功能

    日前，网站安全狗IIS版推出V3.1增强版，旨在提升用户体验，帮助用户更好的进行服务器、网站安全防御。目前，用户可到官方网站http://www.safedog.cn 下载覆盖安装，尚不支持在线安装。

    **网站安全狗V3.1增强版全部新增内容如下**：

    1、新增定时网马扫描功能

    2、新增“服云”（服务器安全管理云平台）快速绑定

    安全狗﹒服云是服务器安全管理云平台，结合现有的服务器安全狗、网站安全狗、云备份等相关免费产品，为广大用户提供包括服务器系统资源监控、可用性监控、服务器重启、重要服务远程操作、安全狗软件远程管理、网页防篡改、网站监控、告警中心、云备份等在内的一系列服务器安全管理云服务。

    安全狗服云批量化、一站式、支持移动应用的管理方式，为广大IDC、企业、中小站长的服务器、网站安全管理提供了有效手段，极大减轻服务器、网站日常管理工作，有效降低因安全问题、管理问题等各种原因所导致的损失。用安全狗﹒服云，用户随时随地都可以轻松了解所有服务器安全状况。

    3、优化网页木马、挂马、黑链查杀算法，提高查杀效率

    4、解决网马扫描过程因文件过多导致界面崩溃问题

    5、细化攻击类型划分，实现防护日志内容优化
