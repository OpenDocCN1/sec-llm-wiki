# 新互联网时代下 如何为企业上一道“信息安全锁”？

**安全狗**，领先的云安全服务与解决方案提供商

  

3月29日，针对新互联网时代下信息安全风险对企业的威胁，安全狗携手美亚柏科以及厦门市上市公司企业协会在厦门共同举办《新互联网时代下企业信息安全管控研讨会》，探讨互联网+时代下企业的信息安全。此次与会者均来自上市企业的负责人、首席安全官以及企业信息安全负责人等。

 

![](../Images/f37b41f311820583f79427f921d38c11.png)  
   

上午，在厦门上市公司企业协会秘书长以及美亚柏科总经理申强的精彩致辞后，为增进沟通与交流，美亚柏科企业电子取证事业部副总经理陆平、首席技术专家徐志强，安全狗创始人陈奋以及安全狗首席安全架构师程长高等分别从不同角度分享了大型企业在信息安全防护方面的成功经验。

 

**新时代的企业安全 重在防患于未然**

![](../Images/b37f9294531acb00359e448f31684d6e.png)

近年来，网络安全事件频发，企业及用户纷纷投注更多的心力去维护自身的网络安全。针对此，安全狗CEO陈奋认为，相对于各种防范措施，防范于未然，扼杀安全隐患才是最有效的办法。

  

![](../Images/8bd33cae90abca54e8fdfd62833448bd.png)  
 

为什么这么说呢？陈奋回顾了2014年11月索尼影业的一次灾难性的攻击事件，令人困惑的是，如此一个全球性的大企业，竟未将防火墙和100多台设备的安全监测工作交给外部的合作安全团队，而只是让公司内部的一支团队负责。

 

从这个索尼事件中可以得出，企业想要更好地保障信息安全，就应继续以超前防范网络攻击者为目标，建立更为先进的安全管理平台。传统硬件防火墙显然已经无法适用云时代安全需求，对此，安全狗建立基于持续监控和分析的大数据安全分析平台，来加强安全防御能力和安全管理能力，从以漏洞规则为中心的防御模型向以持续威胁分析为中心的防御模型演进。

  

为抵御日益精妙的攻击手段，安全狗服云基于云端构建的信息安全体系通过网络层、应用层以及系统层层层防护，从IaaS安全管理系统、虚拟机主机安全防护、主动安全扫描、设计攻击陷阱、采用第三方威胁情报服务、专业安全团队全天候运维等方法入手，在多维度设立防范措施，保证用户信息的绝对安全。

**软件定义防御 数据驱动安全**

![](../Images/b37f9294531acb00359e448f31684d6e.png)

在互联网+的时代，几乎所有的细分领域都能在云端找到机会。对创业者、开发者而言，如何才能将业务安全地搬到云上，网络安全如何应对？在本次的研讨会上，安全狗首席安全架构师程长高就如何在云端构建安全体系进行了演讲。

  

 

![](../Images/58a462b9cebfd90351a98e64fd9ec77b.png)  
 

攻击威胁已然成为一种常态，面对越来越复杂的攻击手段，企业如何在价格昂贵、建设周期长以及培养专业人员的困境中寻求突破？安全狗构建“端+云+服务”的一站式云安全SAAS服务，基于数据驱动的云安全管理平台，让企业的安全管理变得“主动、可视、可防、可知、可管”。通过风险管理，第一时间发现安全问题；通过威胁分析，看清问题全貌，识别入侵，追溯源头；通过智能多重安全防护策略，确保做出快速应对和安全防护调整。再加上云端安全管理及监控帮助开展主动防御，寻找潜在攻击者、分析和评估威胁，并在威胁破坏企业的关键资产之前将其解除。

 

**企业安全那些事 上市公司有话说**  

![](../Images/b37f9294531acb00359e448f31684d6e.png)

安全狗CEO陈奋以及架构师程长高带来的案例引起了前来参加研讨会的各大上市公司的共鸣，同时他们也对安全狗带来的企业信息安全解决方案产生了十分浓厚的兴趣，当场对两位演讲者发起了一轮又一轮的“围攻”，纷纷提出了各自领域上的安全困惑。

  

 

![](../Images/844355b1f04f885ef19dc1a528b2a72d.png)  
 

有企业提出，在阿里云上购买云主机后，该如何使用安全狗？就该问题，安全狗陈奋作出了回答：安全狗与国内外主流的云厂商如AWS、阿里云、腾讯云、UCloud、金山云等云计算厂商已经建立了非常深度的合作伙伴关系。安全狗多重安全能力输出给云计算合作伙伴，用户在云计算厂商平台可以通过部署安全狗镜像来启用安全狗的服务，通过安全狗•服云平台可快速的为各大云计算平台的用户提供安全防御、安全管理、应急响应为一体的云安全SAAS服务。除此之外，电商、金融等行业还分别针对各自领域的信息安全提出了一些技术方面的问题。

 

“没有网络安全就没有国家安全，没有信息化就没有现代化”，网络安全、有序发展的重要性已经成为互联网发展战略顶层设计的指引。企业信息安全已经被提升到一个前所未有的新高度。安全是发展的保障，发展是安全的目的，只有两者之间相辅相成，才能促进各行各业的繁荣与进步。
