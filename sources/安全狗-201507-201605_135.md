# 英媒：挪威首次明确指责“中国黑客”窃取军事机密

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2NDM4MQ==&mid=401898990&idx=2&sn=11610c8e4fa237fb85e9aa0bef2993fc&chksm=34f35c1c0384d50ae0ff1659de32d75c8f9ad1275d816fe17be6e3dc4be5b3fd954e0269d6a7&scene=126&sessionid=1681368375#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTc2NDM4MQ==&mid=401898990&idx=2&sn=11610c8e4fa237fb85e9aa0bef2993fc&chksm=34f35c1c0384d50ae0ff1659de32d75c8f9ad1275d816fe17be6e3dc4be5b3fd954e0269d6a7&scene=126&sessionid=1681368375#rd)

2月29日报道 英媒称，挪威情报局局长莫滕·哈加·伦德公开指责中国在该国参与网络间谍活动，表示中国的黑客从挪威公司窃取的机密情报目前正用于中国的军事技术中。

  

![](../Images/20d950505820e3b2393d62ee3a6a46b7.png)  

据英国《安全计算机》月刊网站2月26日报道，伦德没有披露相关公司的名称和被窃技术的情况。  
  
据认为这是这个北约成员国的政府首次明确指责中国。  
  
据挪威广播公司24日报道，伦德在参加挪威防务部门的年度威胁评估时说，俄罗斯和中国的情报机构都对挪威构成了数字威胁。  
  
他还强调，来自这两个国家的威胁不仅涉及挪威公司，而且也是一种全球性挑战。  
  
报道称，美国“蓝色外套”系统公司欧洲、中东和非洲地区安全策略主管罗伯特·阿兰耶洛维奇在接受《安全计算机》月刊网站采访时说，有人也许认为，挪威不大可能成为目标，因为该国距离中国非常遥远，而且比较小，但对网络间谍活动而言，挪威可以被视为有价值的目标，因为该国战略位置重要，而且是石油生产国。  
  
此外，挪威在全球防务工业中扮演着非常重要的角色，其拥有的与武器有关的知识产权极有价值，更主要是因为挪威是北约成员国。  
  
此外北约秘书长延斯·斯托尔滕贝格也是挪威人。  
  
报道称，“蓝色外套”系统公司设在奥斯陆的研究团队首席安全研究员斯诺雷·法格兰证实了挪威政府的上述说法，并解释说，其团队观察到的黑客的活动概况与伦德谈到的相关活动相一致。  
  
其中包括所谓的大量间接证据，涉及时区、确定IP地址的地理位置、源代码、使用的语言（包括所用机器使用的语言）和恶意软件的类型等，不一而足。所有这些均指向中国。  
  
法格兰说：“被推定为来自中国的黑客已经活跃了相当长的一段时间，这些黑客仍在从事大量威胁活动。我们看到，各国都面临来自全球的高威胁活动。就在今天，我还一直在分析针对日本的活动。他们使用的方法似乎与人们可以预料的所谓中国的黑客所使用的方法一致。要确定这个空间的活动来自政府确实很难，在中国尤其如此，因为有地下组织同情政府的政策，所以存在一个可能受到政府驱使或支持的灰色区域，但不知道程度有多大。”  
  
他说：“毫无疑问，这里的目标会使与政府有关的利益集团产生极大兴趣，但也可能是私人在试图获得他们希望出售的情报。”  
  
报道称，阿兰耶洛维奇还表示，就得到政府支持的黑客而言，需要指出的还有“实施网络攻击时使用的一些先进手段，例如开发非常先进的恶意软件、投入的时间和资源等。所有这些表明，很有可能并不是某个小孩正在地下室里这样做”。
