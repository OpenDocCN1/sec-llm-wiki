# 清华网站疑遭攻击：IS黑客被指篡改页面

点击黑客篡改后的页面附带的超链接，会跳转至某社交网的页面，并显示页面设有浏览权限，无法显示。

  

![](../Images/ea2e691c9ee1dab90f5f9ceb7073b6b8.png)  

  

法制晚报讯 据清华大学清新时报消息，昨晚10时许，清华大学教学门户遭受黑客攻击。目前，清华大学教学门户网站正在维修，无法进入网页。

  

据清华大学清新时报称，清华大学教学网站遭黑客攻击后，部分页面点击后伴随音乐，内容为阿拉伯伊斯兰教经文，并且点击黑客页面附带的超链接处，跳转至国外某社交网络页面后，会出现设有浏览权限的页面，正常情况下无法显示。

  

清华追寻到该黑客社交网络账号为“IsIamic State Media”，但其目前尚未承认对此次黑客攻击事件负责。目前，清华大学还不能反向追踪到该黑客组织。据悉，清华大学信息化技术中心正在查找具体的原因。

  

清华大学本科生龙思宇告诉记者，此次被黑的网站仅限于存放公告的网站，被黑网站仅为清华众多子站中的一或两个，包括清华主页在内的其它站点均未受到影响，攻击后的页面基本相同，站点数量较小且分布无规律，受攻击的站点与学生信息无关，基本可以排除学生内部为篡改成绩的可能。

  

记者根据黑客所留账号“Don-2”，可搜索到被此侵入过的更多网站，其中有一家汽车物流公司官网。

  

据相关媒体报道称，“don soufiane”账号为独狼黑客，曾入侵过世界多个国家和地区网站，也攻击过部分私人账号。

  

截至记者发稿前，清华大学尚未对此做出回应。（网络）
