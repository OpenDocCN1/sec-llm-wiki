# Think in Cloud2015 安全狗与UCloud共赴变革之旅

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2NDM4MQ==&mid=401083958&idx=1&sn=9ca97b717da9290502d6191ca0448aaa&chksm=34ef2fc40398a6d20fc458bdf511774d6c620a8c7e4ea0d2b7b5455f07362c628b41983c2530&scene=126&sessionid=1681368395#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTc2NDM4MQ==&mid=401083958&idx=1&sn=9ca97b717da9290502d6191ca0448aaa&chksm=34ef2fc40398a6d20fc458bdf511774d6c620a8c7e4ea0d2b7b5455f07362c628b41983c2530&scene=126&sessionid=1681368395#rd)

备受瞩目的Think in Cloud 2015大会今日在上海虹桥天地演艺中心举行，数百名各行业精英领袖齐聚一堂共同聚焦数据时代下企业如何寻“机”而变。在本次大会上，知名互联网安全品牌安全狗作为UCloud合作伙伴在现场与各行业数百名精英领袖，聚焦行业变化，探讨创新变革，聚变企业生态，见证豹变之路。

  

![](../Images/fc1ffe940fb314436e2d142c8d3d08e5.png)  

  

U市场是UCloud于2015年8月推出的战略合作伙伴计划，定位于中立的第三方云服务市场，一端链接20000多个互联网企业和创业团队的巨大市场需求，另一端汇集国内各大云服务商的多样化产品，力求打造云端应用的一站式平台。作为领先的云安全服务与解决方案提供商，安全狗是首批进入企业级服务聚合平台U市场的合作伙伴。

  

![](../Images/8ac0f06aaea0a05f2380044c14ff2002.png)  

在聚集U市场合作伙伴的采访环节中，安全狗市场总监朱一帆代表安全狗回答了媒体采访的几个问题。安全狗CMO在接受采访时表示，安全狗与UCloud拥有大批共同的用户群，双方合作可以为这批用户打造更具有针对性的一站式云应用和服务生态。同时，安全狗“变革性”的解决方案和UCloud对外的开放性则是双方合作的主要原因。

  

作为本次大会的主要环节，安全狗与其他U市场合作伙伴们一起参加了主办方特别设置的启动仪式，见证了U市场“改变的力量”。通过启动仪式，安全狗同UCloud正式缔结合作关系，并与其他U市场合作伙伴们一起为企业打造一站式的云服务平台，同时也为双方接下来更深层次的合作带来保障。

  

![](../Images/4539a1f6f048f6710d18caff64620abf.png)  

安全狗与UCloud的合作是打造企业云生态的典型代表。早前，安全狗为企业提供的服务主要是安全镜像服务。该镜像环境通过自身强大的网站与服务器安全防护功能，可以对服务器操作系统进行全面的加固和调优，可实现与UCloud云主机的无缝接入，同时还集成了IIS、MySQL、PHP环境，可以帮助企业用户快速搭建数据库及网站环境。  
  
本次大会的主题为“汇聚改变的力量”，“变”是这个风起云涌的时代不变的主题。安全狗作为创新型企业的先驱，从一开始便寻求“变革”，力求在这跌宕起伏的互联网世界中扎根成长。此番助力Ucloud也是从“改变”角度出发，从安全方面全面解决云时代下的安全问题，帮助初创企业创新成长，一起创造改变的力量。
