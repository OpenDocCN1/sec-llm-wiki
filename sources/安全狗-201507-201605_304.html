破掉别人的Wi-Fi密码、套走账号、利用漏洞测试网络绝对能让人成就感爆棚。想变身黑客爽一把吗？你得先弄台便携黑客站，并熟悉下Kali Linux和树莓派（树莓派）。不会没有关系，我来教你！




这篇文章是Lifehacker邪恶周项目的一部分，这一星期我们会教你们使坏。不过任何邪恶都是相对的，如果我们能熟悉它们，就能更好地战胜邪恶。


工欲善其事，必先利其器，开始之前，先来介绍下我们的工具吧。首先登场的是Kali Linux，它是基于Debian的Linux发行版，在数字取证和渗透测试有较大的优势。你可以在你的笔记本上安装该系统，然后就可以用它破解周边的Wi-Fi，套取账号或者测试蓝牙漏洞了。不过如果你是个遵纪守法的人，可别做的太过，因为利用该系统黑进别人受保护的网络是触犯法律的，而且罪过还不小，很有可能会因为违反计算机安全法案遭到起诉。所以，要想一试身手就拿自家的网络来吧。


另外我们还需要一块树莓派开发板，它是一款针对电脑业余爱好者、教师、小学生以及小型企业等用户的迷你电脑，预装Linux系统，体积仅信用卡大小，搭载ARM架构处理器，运算性能和智能手机相仿。如果能将它和Kali Linux结合起来，就可以得到一台超便携的网络测试机。本文我们将告诉你如何在这台小电脑上运行Kali，这样你就不用在你的电脑上面做测试了。


所需设备

一台树莓派（最好是Model B+或者2）

一块电池组（只要能输出5V电压并带有USB接口就行）

一张WiFi无线网卡

一张8G的SD卡

一块能与树莓派配套使用的触摸屏（如果你不在乎便携性，还可以选用官方的7英寸触摸屏）

一个保护套（随身携带的时候还是带个套吧）

一套键盘鼠标（无线且便携的最优）

一部电脑（用于给树莓派安装Kali）




第一步：在树莓派上安装Kali

在成为“黑客”之前，你得先将触摸屏连上树莓派并为其安装Kali Linux。其实也没那么困难，跟安装其他操作系统差不多，下面是我们总结好的精简版本，列位看官请上眼：

怎样在Windows下将Kali安装到SD卡上

  1. 首先，下载Kali Linux 树莓派 TFT镜像文件，然后解压其中img后缀的文档。如果你用的不是触摸屏，请下载普通版的树莓派专用Kali Linux。

  2. 下载名为Win32DiskImager的压缩包并解压其中exe后缀的软件。

  3. 将SD卡插入你的PC中（记得用读卡器）。

  4. 双击打开Win32DiskImager.exe，如果你用的是WIN7或WIN8，则需要点击鼠标右键并选择“以管理员身份运行”。

  5. 如果该软件无法自动侦测到你的SD卡，你就要在右上角的下拉菜单中找到SD卡并手动选择它。

  6. 在软件的图像文件部分点击小文件夹的图标，找到你刚刚下载的Raspbian .img文件。

  7. 点击“写入”按键，Win32DiskImager就会帮你完成其它步骤。安装过程结束后，你就可以拔出SD卡然后将其插入树莓派了。


怎样在OS X下将Kali安装到SD卡上

  1. 首先，下载Kali Linux 树莓派 TFT image文件，然后解压其中img后缀的文档。如果你用的不是触摸屏，请下载普通版的树莓派专用Kali Linux。

  2. 下载RPi-sd card builder（可要挑好对应的版本哈），然后解压该软件。

  3. 将SD卡插入你的Mac中（记得用读卡器）。

  4. 打开RPi-sd card builder，软件会立即要求你选择一张树莓的照片，请选择之前下载好的img后缀的文件。

  5. 如果该软件询问你是否插入了SD卡，点“继续”就行，随后就会跳出SD卡选项。如果你只插入了一张，选项就只有一个，如果你的Mac里有好几张，可别选错了要用的卡，然后输入你的管理员密码。

  6. 随后电脑会问你是否已经拔出了SD卡，因为该软件安装系统时需要卸载SD卡。这时你要确保SD卡不再出现在Mac的Finder中，可别直接从USB接口拔掉读卡器。搞定这一切之后，点击“继续”按钮。

  7. 接着RPi-sd card builder会安全弹出你的SD卡，这时你就可以将其插入树莓派了。


第二步：连接屏幕




别看树莓派体积很小，它也有连接触摸屏的通用输入、输出接口。只要在角落里找到这些接口并连上触摸屏就好，随后你就可以进入树莓派了。


第三步：连接好各部分组件，然后开机

连接好屏幕之后，就可以插入WiFi适配器和键盘了，最后，为树莓派接好电池组就OK了。

启动过程可能会有点慢，有的用户可能还会遇到白屏问题，不过请耐心等待，登陆界面肯定会出来的。


第四步：登陆并启用你的WiFi无线网卡

登陆后启用WiFI无线网卡就可以使用Kali Linux内置的一系列工具了。树莓派会自动识别你的无线网卡，你只要登陆自己的网络就行。登陆后最重要的是打开Kali Linux的图形用户界面并保证各个组件正常运行：

  1. 你会在树莓派的命令行上看到用户名和密码，这时，输入用户名root和密码toor。用户名和密码后面可以修改。

  2. 输入startx，然后点击回车来启动Kali的图形界面，这个过程耗时可能会比较长，请耐心等待。

  3. 进入图形界面后你就可以正常使用触摸屏和键盘了。现在请点击dock栏中的终端图标来启动命令行。

  4. 想要设置你的无线网卡，只需要在命令行中输入nano /etc/network/interfaces载入配置文件就好。

  5. 将下列代码加入你刚刚打开的文本文档来替代你原有的网络信息：


iface wlan0 inet dhcp
wpa-ssid “你的用户名”
wpa-psk “你的网络密码”


搞定这一切之后，点击Ctrl+X进行保存并退出，这时你的无线网卡就可以正常工作了（记得要重启一下）。


第五步：修改密码

  1. 不过在你的“黑客行动”开始之前，请先修改设备的根密码，因为若别人也看了这篇文章，就很容易控制你的设备。修改密码过程如下：

  2. 在命令行中输入passwd并按下回车键。

  3. 输入你的新密码，记得要输两次哦。

  4. 你的OpenSSH服务器数值一开始都是默认的，所以最好重新配置一下，只需键入dpkg-reconfigure openssh-server并按下回车键就好。

到此为止，你的便携系统就搭建完毕了。


便携黑客站都能做什么？

这个问题要靠你自己解答了。你可以借助触摸屏畅游树莓派，还可以在Kali Linux上跑任何你喜欢的程序。如果你有点丈二和尚摸不找头脑，我们为你准备了些许线索：

  • 设置SSH以便远程连接你的树莓派

  • 学习一些有关命令行的基础知识

  • 尝试着破解Wi-Fi密码，创建虚假网络，或者窥探其它设备的通信

  • 监控处于同一网络中的所有设备

  • 学习Kali Linux

现在，你可以随心所欲了，不过可别触犯了法律。
