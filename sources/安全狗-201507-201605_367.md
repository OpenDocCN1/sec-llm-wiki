# 网站安全狗Apache 3.5版本发布 新增网站后台防护功能

**9月24日，网站安全狗发布Windows Apache 3.5版本，本次版本更新主要新增网站后台防护功能以及整合网马引擎、防护升级等内容。**

**具体更新内容：**

1、新增网站后台防护功能；

  

![](../Images/776ee352bc652dd1ae17d88193b25ba7.png)  

  

2、CC攻击防护功能新增路径白名单；

  

![](../Images/36addac29acca1cc30e3d89ff80fca7e.png)  

  

3、整合最新网马查杀引擎和升级中心;

4、优化网站漏洞防护功能，支持针对不同协议头字段设置规则；

5、解决特殊情况下上传防护功能绕过问题；

6、解决特定环境下，可能存在的挂马漏扫问题；

7、修复最新SQL注入绕过漏洞；

  

**目前安全狗官网已经提供下载（http://www.safedog.cn/website\_safedog.html）各位用户朋友们可根据需求进行下载安装。在使用过程中有任何疑问/问题，也欢迎向我们反馈。**

  

**网站安全狗**

网站安全狗是一款服务器安全防护软件，是为IDC运营商、虚拟主机服务商、企业主机、服务器管理者等用户提供服务器安全防范的实用系统，是集网站内容安全防护、网站资源保护及网站流量保护功能为一体的服务器工具。
