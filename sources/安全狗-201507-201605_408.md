# 来2015网络安全（中国）论坛现场和安全狗一起“摇一摇”

2015网络安全（中国）论坛于近日在上海绿地会议中心举行，安全狗作为国内知名安全厂商，出席了本次论坛，并设展位B4与现场参与人员进行交流，为更好地应对网络和信息安全新挑战，交流最新的安全技术与解决方案提供思路。

  

另外，为了与现场参会人员更好的进行互动，安全狗展位设置了名为“越摇越安全”的精彩活动。众多参加活动的人一起“摇一摇”两颗大色子，使得现场气氛十分活跃，参与者众多。
