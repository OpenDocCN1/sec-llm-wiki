# 【漏洞预警】 Jenkins 任意文件读取漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2NDM4MQ==&mid=2650810406&idx=1&sn=0d09b07bf29c2d86d3ff82597851e015&chksm=bd0709d48a7080c2cef9d3091c43cf1e4d0dabfce5fe9951cfe042efe51ac5c31b716872513d&scene=126&sessionid=1681368188#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTc2NDM4MQ==&mid=2650810406&idx=1&sn=0d09b07bf29c2d86d3ff82597851e015&chksm=bd0709d48a7080c2cef9d3091c43cf1e4d0dabfce5fe9951cfe042efe51ac5c31b716872513d&scene=126&sessionid=1681368188#rd)

Jenkins在2018年7月18日对高危漏洞CVE-2018-1999002这一“任意文件读取漏洞”进行了公告，Jenkins所使用的 Stapler Web 框架存在任意文件读取漏洞。攻击者可以在远程且未经授权的情况下，通过构造恶意的 HTTP 请求发往 Jenkins Web 服务端，从请求响应中直接获取攻击者指定读取的文件内容，如图所示。

  

![](../Images/45ab1f35cb3bb055209558dff094278e.png)

  

另外，在很多时候，Jenkins 的部分凭证和其内用户的帐号密码相同，获取到凭证信息后也可以直接登录 Jenkins 进行命令执行操作等。

  

安全狗攻防实验室第一时间关注了事件进展。根据最新的研究分析，我们总结出了一些防护建议，敬请用户知晓。

  
**漏洞相关信息**

![](../Images/300aa9a58d71eefbd01a7501af8541de.png)

  

**处置建议**

虽然该漏洞的危害较大，**但不必太过于担心**，因为在默认安装 Jenkins 时，匿名用户并不具备“可读权限”，并且此漏洞在 Linux 上被利用的可能性较小。  

  

以下为推荐的修复方案

**1、厂商修复方案**将Jenkins Weekly升级到2.133版  
将Jenkins LTS升级到2.121.2版  
(注：在运用厂商修复方案进行修复前，请将资料备份，并进行充分测试。)  

**2、安全狗攻防实验室推荐解决方案**  
在Jenkins管理员后台的“全局安全配置”中，将“匿名用户”的可读权限去掉，如图所示。  

![](../Images/68976f49faa78152c03f36926666b205.png)

  
  

  

我们将持续关注漏洞相关的信息，如果发现新的变动，将及时告知用户。
