# 为小哥哥们打call！这张荣誉证书就是发给他们的

↑ 点击上方“安全狗”关注我们

  

作为国内一线的云安全厂商，我们日常活跃在各个重大会议活动的网络安保工作中，比如G20、厦门金砖峰会等等，而在前不久结束的“数字中国建设峰会”中，我们同样参与了网络安全保障工作，这不，我们收到了由峰会网络安全保卫工作组颁发的荣誉证书！

  

![](../Images/d4d8874958a32a4eb8b9f0877a411cf3.png)

  

作为保障峰会期间网络稳定安全运行的重要力量之一，安全狗的工作人员全程参与了峰会包括场馆内各类信息系统的安全保障工作，除了安全服务外，大数据云安全产品也用于了保障工作，获得了好评。值得一提的是，本次安全保障工作所使用的啸天大数据态势感知平台同样在现场进行了展示，受到诸多观众的关注。

  

安全狗的啸天态势感知平台的画面出现在大屏幕上后，引来了不少观众的驻足。上面代表攻击的点在地图上不停穿梭，无比形象地勾勒了网络安全的现状，观众纷纷掏出手机拍照。

  

![](../Images/f70fe2887793bf510dadd4f16f2c7edc.png)

  

这是安全狗去年在金砖峰会网络安保中部署过的态势感知平台，汇集了所有的安全数据，为安全决策提供了坚实的依据。

  

![](../Images/b20c2d4bfd87fa441e8363e91f5cf7c9.png)

  

安全狗研发的啸天态势感知平台可以汇聚收集到的全部攻击数据，全面展示安全态势，实现对风险的可视和预测，为安全决策提供可靠的依据和手段。在去年的金砖峰会上，安全狗的云安全产品也用于了网络安全保障工作中。  

  

![](../Images/51e04266984dd54575985bf07a3b12a7.png)

  

为我们参与数字中国建设峰会网络安全保障工作的小哥哥们打call！

  

**![](../Images/ba2df1eb6cabe835e380ee2bd0978a7b.png)**

**（可惜他们没有一起拍个照片）**

  

无论是G20峰会，还是厦门金砖峰会，抑或是本次数字中国建设峰会，安全狗提供的云安全产品都经受住了实战考验，没有发生攻击成功的事件，参加安全保障工作的全体工作人员也发挥了极高的技术水准和职业精神。我们将继续深耕云安全领域，不断提升技术水平，为用户提供高水准的云安全服务，帮助用户在网络攻防中掌握主动权！
