# 【漏洞预警】Linux内核存在远程DOS/远程代码执行漏洞

**CVE-ID**

CVE-2017-8890

CVE-2017-9075

CVE-2017-9076

CVE-2017-9077

  

**漏洞类型**

远程DOS/远程代码执行

  

**危害等级**

高危

  

**影响版本**

可影响几乎所有Linux kernel 2.5.69 ~Linux kernel 4.11的内核版本、对应的发行版本以及相关国产系统

  

![](../Images/feb2daae4df3b5df937e3f8cd889cea0.png)

  

**漏洞危害**

可导致远程 DOS，且在符合一定利用条件下可导致 RCE，包括传输层的TCP、DCCP、SCTP以及网络层的IPv4和IPv6协议均受影响。实际上该漏洞在 Linux 4.11-rc8 版本中已经被启明星辰ADLab发现，且后来的Linux 4.11 stable版同样存在此问题。经研究这些漏洞在 Linux 内核中至少已经潜伏了11年之久，影响极为深远。

  

**补丁状态**

官方已经发布了修复该问题的补丁，可通过升级Linux内核修复“Phoenix Talon”相关漏洞，或使用 Grsecurity/PaX 对内核加固。
