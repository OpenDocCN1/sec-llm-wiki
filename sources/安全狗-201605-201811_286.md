# 【告警】Fastjson远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2NDM4MQ==&mid=2650807944&idx=2&sn=d1f8c9fbbda8dddc27629d07b0991d72&chksm=bd073f7a8a70b66c8bf6eefe1d83415cc765e4fe5ac456227b946c00c0b6a23c22ee577a2a4e&scene=126&sessionid=1681368279#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTc2NDM4MQ==&mid=2650807944&idx=2&sn=d1f8c9fbbda8dddc27629d07b0991d72&chksm=bd073f7a8a70b66c8bf6eefe1d83415cc765e4fe5ac456227b946c00c0b6a23c22ee577a2a4e&scene=126&sessionid=1681368279#rd)

**漏洞名：**Fastjson远程代码执行漏洞  

**影响版本：**< fastjson 1.2.24  
**漏洞描述：**fastjson 是一个性能很好的 Java 语言实现的 JSON 解析器和生成器，来自阿里巴巴的工程师开发。fastjson在1.2.24以及之前版本存在代码执行漏洞，当用户提交一个精心构造的恶意的序列化数据到服务器端时，fastjson在反序列化时存在漏洞，可导致远程任意代码执行漏洞。 

![](../Images/bc7ce6c6536a461262e331cba5bc46cb.png)

**修复方案：**目前厂商已经发布了升级补丁以修复这个安全问题，请到厂商的主页下载：（https://github.com/alibaba/fastjson/)
