**“阿里云经典网络安全隐患”**无疑是最近几天安全圈子的热点。  

**@左耳朵耗子**撰写了一篇名为**《科普一下公有云网络》**的文章，表达了其对“经典网络”安全性的担忧，质疑**阿里云“经典网络”**存在安全隐患，并呼吁大家尽快使用“VPC”。

很快，**@安全\_云舒**也很快撰文回复，称阿里云是**默认不同租户内网不通**的，**用户自行修改了配置**才可能会导致这种情形的产生。

（关于这件事，不知道的小伙伴可以在网上搜一下，狗哥这里就不展开叙述了。）

![](../Images/78c5418b4112dabb027024b63f2580a6.png)

那么问题来了，**对于小白用户而言**，怎么知道自己的配置对不对呢？

不用担心，**安全狗服云平台可以提供检测服务**！

**凡是阿里云的用户**，只要登录**安全狗的服云平台**  

（链接在此：fuyun.safedog.cn/serverCenter/index.html）

输入在阿里云上使用的**Access Key ID 和 Access Key Secret**  

（登录阿里云即可获取，方法见下图，链接在此:ak-console.aliyun.com/index#/accesskey）

即可检测**安全组配置合理与否**！

![](../Images/e2b8df7d6c6bdc6bcc323ac598793854.png)

凡是存在安全隐患的，我们都将会进行告警。

使用方法：

1、登录服云帐号，点击**告警设置**，选择左侧的**配置缺陷检测，**输入****Access Key ID **和**Access Key Secret；****

![](../Images/ba3a9baf3a3713e3d3abf0de6ded4239.png)

2、再点击**安全管理，**即可在下方看到告警的相关信息了！

![](../Images/8a10725323078a7590c79d9a6742348e.png)

**安全没有小事**，再小的隐患我们也会全力排查！
