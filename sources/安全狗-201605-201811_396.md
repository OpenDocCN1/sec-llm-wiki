# 共建云安全生态 安全狗受邀参加2016HCC华为全联接大会

今日为期三天的华为全联接大会( HUAWEI CONNECT 2016 ) 在上海盛大开幕。 该大会作为华为历史上规模最大的面向 ICT 行业的全球生态大会， 整合了原有的 HCC ( 华为云计算大会 )、 HNC ( 华为网络大会 )、 HDC ( 华为开发者大会 )，同时还有超过15000名业界精英齐聚上海， 共谋行业发展，探讨如何共建全联接世界、加速行业数字化转型之道。 

  

![](../Images/795480ed4ff82a29eaa6aef8cf05bd79.png)  

  

安全狗作为华为云合作伙伴，受邀参加此次大会。作为领先的云安全服务与解决方案提供商，安全狗凭借大数据优势以及创新性云安全技术与华为云先进的云计算技术相结合，充分发挥双方各自的能力，优势协同，打造自主可控、安全可信的云安全服务，为企业用户构建安全新生态，保障用户的业务系统安全稳定可靠运营。

  

![](../Images/be9ab8871d03071b5fed24fa369ba149.png)

  
![](../Images/798848aac846505e21ef1628492b492a.png)  

安全狗展台

 

**安全狗与华为云实现合作共赢   携手共建云生态 **

  

在现场，安全狗为参会者展示包括服务器安全狗、基于数据驱动的云安全管理平台等最新云安全产品及服务。其实早在去年的时候，安全狗在本次大会展示的产品中就有多个产品已经上架华为企业云应用超市。

  

![](../Images/e2841d4ffef3b3d44fddee113cf95021.png)  

  

服务器安全狗具有集服务器安全防护和安全管理于一体的优势，而与华为云合作打造的服务器安全狗(Windows版)-华为云专用版通过在内在逻辑与进程调优，使其更好地与华为云主机实现无缝接入。集用户安全防护和管理为一体，支持Windows全系列操作系统，基于内核级安全防护，采用NDIS中间层驱动模式，实现从驱动层直接屏蔽攻击，最大程度地保护用户主机系统安全。

 

“云安全”是当前网络信息安全发展的主流趋势，安全狗在这一主流趋势下提供全面的安全防护产品与方案，为用户解决公有云、私有云和混合云环境中可能遇到各种安全及管理问题，帮助用户把风险降到最低。

 

今天是大会的第一天，9月2号，安全狗作为华为云应用超市使用量最高的安全产品，还将接受采访，面向世界展示安全狗的核心产品及服务。

  

![](../Images/33daa97cc0701375ea87134f5570f505.png)  

![](../Images/2e7481473cdede8afc1f2856697e61ad.png)  

本次大会为期3天，内容将主要涉及云计算、SDN、物联网、大数据4大技术领域，并以此为基础开展6大主题峰会，话题覆盖金融、能源、交通、医疗、电力、政府等9大垂直行业。与此同时，34场媒体圆桌讨论和近百场媒体对话也将同步开展。更为值得一提的是，整个大会将吸引全球120多个国家的400余位行业领袖将参与发言和讨论，同步上演800多场专题演讲以及部署1000余个互动平台。
