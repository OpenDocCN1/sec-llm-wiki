# 打造安全云 保障云安全 安全狗正式加入CSA云安全联盟

7月5日，领先的云安全服务与解决方案提供商**安全狗**正式获批加入全球“云安全联盟”（Cloud Security Alliance，CSA），成为中国企业会员。安全狗CEO陈奋在深圳接受CSA大中华区主席李雨航教授颁发的证书后，双方还就云安全服务方面做了进一步的交流与探讨。

  

![](../Images/03254d025e30ca6ee6d28091a421375b.png)  

  

云安全联盟代表着云安全领域的高水准，具有广泛的国际影响力。陈奋表示：**“安全狗加入云安全联盟，将加强与云计算厂商的交流合作，为客户带来更安全、更优质的云服务。”**

**![](../Images/7f4a1a9b885943a815241065de637900.png)  
**

  

随着互联网云计算的快速发展，各大企业都陆续选择基于云计算平台的应用软件来降低成本、提高效率。然而，数据在云端的安全问题一直困扰着企业，随着云应用的持续普及，云安全的受关注度也与日俱增。由此，CSA便应运而生，其成立的目的是为了在云计算环境下提供最佳的安全方案。

  

![](../Images/aec99bf51f67a3c6a3d273eaf1d5fe4a.png)  

  

作为领先的云安全服务与解决方案提供商，安全狗深受业内人士以及用户的认可。在云安全方面，安全狗依托云端技术和大数据安全分析能力，基于“云+端+服务”一体化saas服务模式为电商、金融、游戏、教育、政府机关等行业客户提供最具核心竞争力的安全产品、服务及解决方案。截至2016年3月，安全狗云安全服务平台已经为客户保护超过200万台（云）服务器及100万个网站，日均拦截超过近亿次的攻击，已成为国内该领域用户量最大的云安全服务平台。

 

在云化IT基础架构下，安全狗提出“软件定义防御 数据驱动安全”的全新理念，即以可视化方式快速搭建多层次联动纵深防御体系，并通过基于持续监控和分析的大数据安全分析平台来加强安全防御能力，实时展示威胁风险，全面保障用户数据安全。

 

CSA是一个门槛较高的联盟，安全狗作为云安全联盟的中国企业会员，将在云计算环境下“打造安全云，保障云安全”，为用户提供最佳的安全方案。同时还将携手国际云安全联盟成员，一起推动行业级云安全标准在中国的建立和推广。
