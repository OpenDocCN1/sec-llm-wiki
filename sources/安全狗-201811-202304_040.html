12月21日，ISC2022数字安全创新能力百强暨数字安全技术创新论坛在北京成功举办。


作为国内云原生安全领导厂商，安全狗也受邀出席此次活动。





厦门服云信息科技有限公司（品牌名：安全狗）成立于2013年，致力于提供云安全领域相关产品、服务及解决方案，是国内最早引入云工作负载安全（CWPP）概念，首家推出云主机安全SaaS产品、成功构建云工作负载安全&云原生安全产品线、能灵活适配各种混合云环境的安全厂商。



作为数字安全届的“奥斯卡”，ISC 2022数字安全创新能力百强评选联合赛迪顾问、数说安全、数世安全、安在、安全419等行业权威机构、媒体，携手安全厂商、专家学者、技术从业者、投资客户等创新先驱，致力于深度挖掘数字安全未来的技术方向，遴选年度热点领域的创新产品和应用，洞察引领行业风向的发展趋势，推动中国数字安全发展与时代共进，助力实现国家安全体系和能力现代化的战略布局。



据悉，本次评选已经集聚十大年度热点领域的200余家参选企业、600余个安全创新产品及解决方案。安全狗云甲·云原生容器安全管理系统、云眼·新一代（云）主机入侵监测及安全管理系统依托综合全面的安全能力以及“身经百战”的安全服务实践，从600余个产品及解决方案中脱颖而出，分别获得云原生安全领域和威胁检测和响应领域的数字安全创新能力百强。



云原生安全
云甲·云原生容器安全管理系统



云甲














安全狗云原生容器安全解决方案（Cloud-Native Container Security Solution）结合Gartner提出的CNAPP（Cloud Native Application Protection Platform）概念，采用主机安全Agent和安全容器相结合的技术，既落地了“安全左移”的概念，又能对云原生容器做全面保护，同时能灵活地跟容器编排体系相结合，是云原生安全最佳实践。


在整个云原生容器安全生命周期中，方案采用自动检测、自动分析、自动处理的方式来防御整个容器生命周期中所遇到的安全威胁、做好云原生网络安全隔离。在防护技术上使用智能检测、机器学习与威胁预测等先进的方法来确保容器化基础设施及容器内应用安全。







值得关注的是，除了此次获得ISC的认可外，云甲还获得信通院云（原生）安全产品检验证书，并入选了Gartner2021 CWPP市场指南、云原生应用保护平台创新洞见、中国安全技术成熟度曲线等多份报告。云甲的云原生安全能力备受国际和国内权威机构认可。


云工作负载安全
云眼·新一代（云）主机入侵监测及安全管理系统



云眼














云眼采用Gartner提出的CWPP理念，提出了以工作负载为中心，以自动化、细粒度资产采集为基础，提供多种风险排查和漏洞发现手段，依托反杀伤链和实时入侵检测响应能力支撑企业安全防护二道防线，解决现代混合云、多云数据中心基础架构中服务器工作负载的安全需求，最终达到对已知威胁的自动响应以及对潜在威胁的检测识别。







作为安全狗旗下的核心产品之一，云眼也入选了Gartner、IDC、CSA等国际权威机构以及国内众多第三方咨询机构的报告中。在历年来的攻防实战演练、重保场景，云眼也展示出强大的安全防护能力。


延续去年“双百”荣誉的获得，此次安全狗核心产品又获“双百”认可，是业界对安全狗产品创新能力的高度认可，也侧面表现了安全狗在云原生安全&云工作负载安全领域的生态影响力深远。未来，安全狗也将依托自身多年的安全技术基础，持续整合&优化自身的安全能力与水平，打造容纳云安全SaaS、云原生安全、数据安全、云上云下等多维度安全能力于一体的安全生态池，保护用户信息安全，助力企业用户数字经济转型，为我国的网络安全全面发展做贡献。
