# 出类拔萃！安全狗云原生安全能力守护中国联通安全发展

**10月14日**，中国联通数字科技有限公司（以下简称“联通数科”）发布了**联通智慧安全终端卫士二期-主机容器终端安全组件招募**结果公示。

  

作为**国内云原生安全领导厂商**，**安全狗**经过层层审核与筛选，最终**入围供应商名录**。

  

  
  
  

安全狗是中国云原生安全（CNAPP）的领导者，作为国内首家云主机安全SaaS产品提供商，安全狗拥有长期的技术积淀和丰富的实战经验，是国内网络安全行业中具备最完整的云工作负载安全（CWPP）产品能力，能灵活适配各种混合云环境的安全厂商。

  

  

![](../Images/52964b3363a6d785e022d2c64adb0e54.png)

  

随着云计算技术的蓬勃发展，传统上云实践中的应用升级缓慢、架构臃肿、无法快速迭代等“痛点”日益明显，因此，具备快速开发和部署特点的云原生技术能有效解决用户难题，成为赋能业务创新的重要推动力，并已经应用到企业核心业务。然而，云原生技术在创造效益的同时，其在云原生应用开发、发布、部署、运行的整个生命周期中，也涉及到云、集群、容器和代码等不同层级的安全问题，对用户整体安全建设提出更高的防护要求。

  

目前在以云主机、容器、微服务等为代表的云原生技术架构场景下，传统云安全解决方案不够完善，会在业务高峰期对正常业务运行的效率和速度产生影响，且无法防护新型的高级攻击威胁以及缺乏企业级东西向云原生流量访问控制技术。除此之外，云原生架构还面临着容器化基础设施、容器化部署带来的内外部安全风险。

  

  
  
  
**安全狗云原生安全保护平台**  
  
  

**安全狗云原生安全保护平台**覆盖了宿主机安全、容器安全、网络微隔离和云原生态势感知全栈需求，通过**一站式平台**，可实现有效防护新型云原生攻击威胁、东西向网络流量完整可视化与访问控制、统一安全基座赋能应用安全等目标，从整体上帮助用户提升云原生场景下安全防护水平和科学应对网络安全威胁的能力。安全狗推出的云原生安全保护平台在为用户提供更好的云原生效能的同时，也助力用户更好地利用云原生技术优势。

值得关注的是，除了此次入围供应商名录，安全狗的**云原生安全防护产品**还多次入选**Gartner**的《Market Guide for Cloud Workload Protection Platforms》, 《Innovation Insight for Cloud-Native Application Protection Platforms》等多份权威报告，获得**信通院**颁布的云（原生）安全产品检验证书，此外还作为**参编单位**深度参与了《云原生应用保护平台（CNAPP）能力要求》的编写，整体云原生安全能力备受国内外权威机构认可。

  

此次入围联通智慧安全终端卫士供应商名录，不仅是用户市场对安全狗云原生安全防护实力的认可，更是对安全狗未来继续整合自身安全生态影响力、不断加强云原生安全综合能力的驱策。未来，安全狗将结合国家发展政策以及国内外技术发展趋势，继续扩大和巩固自身在国内云安全行业的领先优势，以市场需求为导向，坚持自主创新，驱动旗下包括云原生安全产品在内的产品矩阵快速提升，积极发挥生态优势，为包括中国联通在内的广大用户创造更大的安全价值，为我国的数字经济转型贡献延绵不断的云原生安全力量！
