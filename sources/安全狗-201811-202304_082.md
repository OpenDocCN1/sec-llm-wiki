# 连续上榜！安全狗入选《CCSIP 2022中国网络安全产业全景图》多个细项

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2NDM4MQ==&mid=2650832785&idx=2&sn=283c6f1e4a3c9964dadbdc24975d7101&chksm=bd075e638a70d775d7c0d8462a3e63550152bc45a47637c9166e79f74630a323ea069cf56e19&scene=126&sessionid=1681367987#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTc2NDM4MQ==&mid=2650832785&idx=2&sn=283c6f1e4a3c9964dadbdc24975d7101&chksm=bd075e638a70d775d7c0d8462a3e63550152bc45a47637c9166e79f74630a323ea069cf56e19&scene=126&sessionid=1681367987#rd)

**7月21日**，国内安全行业门户FreeBuf旗下FreeBuf咨询正式发布《CCSIP 2022中国网络安全产业全景图》（第四版）。

  

作为**国内云安全CWPP领导厂商**，**安全狗**也凭借综合且全面的产品和能力入选多个领域。

  

  
  
  

安全狗成立于2013年，自成立以来就致力于提供云安全领域相关产品、服务及解决方案，是国内最早引入云工作负载安全（CWPP）概念，并成功构建相应产品线的专业云安全厂商。

  
   
**调研详情**  
  

1、问卷调查    

Freebuf咨询通过问卷调查的形式获取企业的安全产品以及相应的资质信息，作为基础参考信息。

  

2、权威参考  

参考国内外网络安全领域的各类奖项、Gartner魔力象限以及专业机构发布的权威报告等，积累国内安全厂商和安全产品补充信息的数据库。

  

3、TTSP智库专家参与分析  

由FreeBuf咨询顾问、市场分析师、TTSP智库专家组成的专业评审团队，对安全厂商进行归类与评审。

  
  
  
  

  

依托综合且全面的云安全产品和服务，**安全狗此次入选了防护大类**里的网络隔离\-网闸、网页防篡改、WAF、Web应用扫描与监控、RASP、云运用安全、云WAF、云抗DDoS、云主机安全、云原生安全（容器安全）；网络基础安全大类里的抗DDoS、主机防病毒；持续改进大类里的渗透测试、攻防演练、风险评估；检测大类里的主机安全/EDR；响应大类里的SOC、SIEM等。

**云工作负载安全/云原生安全解决方案**  
  

安全狗云工作负载及云原生安全解决方案是国内首家全面符合CWPP落地的产品方案。整体解决方案基于融合架构下的云工作负载解决思路，构建资产管理、漏洞补丁、东西向流量隔离、云原生安全的“N合一”解决方案，完成国产化操作系统适配，完美赋能云原生安全，能够为云工作负载提供全面保护。

**攻防演练服务**  
  

Red Team测试是一个全范围、多层次、多重混合的模拟攻击。由安全狗专业的安全团队来完成，在客户授权的前提下，以攻击者的角度出发，采用攻击者的思维方式对相关真实线上环境进行攻击测试，并尝试发现不同角度存在的安全漏洞和安全风险，皆在衡量整个用户所属资产存在的安全风险，最终目的是帮忙用户保持竞争力，同时确保其相关利益。

**啸天安全大数据及态势感知平台**  
  

安全狗啸天安全大数据分析及态势感知平台是融合大数据分析技术、可视化技术、威胁情报技术于一体，为企业构建的新一代安全平台。啸天可实现 IT 资产和安全事件数字化、全局数据采集、持续关联分析和大数据模型分析，通过数据关联整合安全事件与 IT 资产，为安全应用提供大数据自动化分析能力支撑。

  
  
  
  

  

值得关注的是，除了荣登此次的《CCSIP 2022中国网络安全产业全景图》，在不久前，安全狗旗下的众多安全产品矩阵和安全服务也先后入选嘶吼发布的《嘶吼2022网络安全产业图谱》、信通院公布的“数据安全推进计划”名单、安在发布的《安在新榜·2022中国网络安全产品用户调查报告》、信通院发布的《可信业务与应用安全全景视图（2022）》等等报告，整体安全实力水平深受权威专业机构认可。

  

此次安全狗获得多方面的认可，是市场和用户对安全狗的高度认可以及未来继续努力的驱策。未来，安全狗也将依托自身多年的安全技术基础，持续整合&优化自身的安全能力与水平，打造容纳云安全SaaS、云原生安全、数据安全、云上云下等多维度安全能力于一体的安全生态池，实时为用户信息安全、企业数字经济转型、国家网络安全发展做贡献。
