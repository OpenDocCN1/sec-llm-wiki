# 守护数据安全|安全狗入选信通院“数据安全推进计划”名单

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2NDM4MQ==&mid=2650831938&idx=1&sn=1a781af74143f1d7d55596d31421fd36&chksm=bd075db08a70d4a6326dab760184eacf78d75d9d1f8c27c24b4f9a4897ef8850b508de7c7a4a&scene=126&sessionid=1681367987#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTc2NDM4MQ==&mid=2650831938&idx=1&sn=1a781af74143f1d7d55596d31421fd36&chksm=bd075db08a70d4a6326dab760184eacf78d75d9d1f8c27c24b4f9a4897ef8850b508de7c7a4a&scene=126&sessionid=1681367987#rd)

**7月5日**，中国信息通信研究院（以下简称“中国信通院”）公布了第五批“数据安全推进计划”（Data Security Initiative，以下简称“DSI”）入选企业名单。（点击下方“阅读原文”查看）

  

作为**国内云安全CWPP领导厂商**，****安全狗****从众多企业单位中脱颖而出，入选并成为成员单位。

  

  
  
  

安全狗成立于2013年，自成立以来就致力于提供云安全领域相关产品、服务及解决方案，是国内最早引入云工作负载安全（CWPP）概念，并成功构建相应产品线的专业云安全厂商。

  
 

DSI是一个公益性合作项目，将依托大数据协同安全技术国家工程实验室、中国通信标准化协会大数据技术标准推进委员会、中国互联网协会数据治理工作委员会开展具体工作，致力于打造健康规范的数据安全生态体系，帮助企业了解监管要求，全方位提升企业数据安全能力。其主要工作内容包括：（1）搭建交流平台，最新政策法规解读；（2）开展数据安全方法论和技术体系研究；（3）建立健全数据安全标准体系；（4）依托标准打造数据安全咨询与评估评测解决方案；（5）开展数据安全人才培训。

  

作为数据领域的基础性法律同时也是国家安全领域的一部重要法律，《数据安全法》于去年6月份被表决通过，并于去年9月开始施行至今。其备受国家和社会关注的深层原因与当前国家新兴技术和经济发展互相融合、在数字经济转型的过程中强调深挖数据生产价值等分不开关系。DSI的发起与壮大，有利于建立健全数据安全建设，推动并促进《数据安全法》的落实。

  

一直以来，安全狗围绕****CWPP****概念打造的云安全&云原生安全系列产品矩阵，融合了**云原生安全、零信任、数据安全**等多重安全技术在内，能有效地提供数据安全、等保合规、重保服务、网络安全纵深防护。

在****数据安全领域****里，安全狗凭借自身对云安全、数据安全领域的行业敏感嗅觉以及市场洞悉，安全狗在自身多年的安全技术实力和数据安全治理经验基础上，结合了数据安全成熟度模型DSMM、Gartner数据保护方法论等国际主流安全模型，提出了****以数据为中心****的安全建设思路和解决方案，形成了****数据安全治理解决方案****，即，以数据资产为核心构建数据安全防护体系，协助企业用户在数字化转型；持续风评、不断调整 ；制定全生命周期安全策略；摸清数据家底；实时监测、智能分析、智能控制；落实管理与技术过程中满足合规要求。

  

在****数据安全治理、数据安全评估、数据安全整改****等三个阶段中，安全狗可以提供相应的安全服务。

 ![](../Images/d39391cbb7186b9c78075f7aded974e6.png)

  

值得关注的是，除了此次数据安全治理能力受到****信通院****肯定外，安全狗还入选了信通院发布的《可信业务与应用安全全景视图（2022）》多个模块、《云原生产品目录》、成为首批“网络安全能力评价工作组”成员单位、获得“2022守卫者计划——安全运营专题优秀案例”荣誉等等。****从安全产品技术实力到安全服务能力都深受信通院的认可****。

  

此次入选信通院“数据安全推进计划”名单，不仅是信通院对安全狗数据安全治理能力的认可，更是对安全狗持续且稳定地输出安全能力、护航用户数据安全的驱策。

  

未来，安全狗也将依托自身多年的安全技术基础，持续整合&优化自身的安全能力与水平，打造容纳云安全SaaS、云原生安全、数据安全、云上云下等多维度安全能力于一体的安全生态池，实时为用户信息安全、企业数字经济转型、国家网络安全发展做贡献。
