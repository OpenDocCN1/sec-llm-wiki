# 备受推荐！安全狗入选Gartner云安全&安全运营中国市场供应商双名单

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2NDM4MQ==&mid=2650829669&idx=1&sn=9f65dac45a35e5721fe192a0a770aa27&chksm=bd0752978a70db8127d262590fa46ee8205dc73c13d21e1a7563e664af871e99d84129683675&scene=126&sessionid=1681368007#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTc2NDM4MQ==&mid=2650829669&idx=1&sn=9f65dac45a35e5721fe192a0a770aa27&chksm=bd0752978a70db8127d262590fa46ee8205dc73c13d21e1a7563e664af871e99d84129683675&scene=126&sessionid=1681368007#rd)

近期，国际权威咨询机构**Gartner**基于市场研究和对中国安全产品供应商的调查做了评估并发布**《Toolkit:Vendor Identification for Cloud Security, Data Security, IAM and Security Operation in China》**。

  

作为**国内云安全CWPP领导厂商**，安全狗依托旗下产品突出能力也入选**云安全**、**安全运营**供应商名单，安全实力倍受Gartner和用户市场认可。  

  

  
  
  

安全狗成立于2013年，自成立以来就致力于提供云安全领域相关产品、服务及解决方案，是国内最早引入云工作负载安全（CWPP）概念，并成功构建相应产品线的专业云安全厂商。

  
  

随着5G、云计算、大数据中心、人工智能等多项新技术快速发展，外加国家政策的扶持，社会的发展向**数字经济**进一步倾斜。传统产业和新兴产业纷纷选择上云，以便更好地进行数字化转型。然而，企业上云后，依靠硬件架构堆砌的传统安全防护方式已不再符合当下边界逐渐模糊的虚拟化环境。无独有偶，互联网、互联网+的企业业务发展速度越来越快，系统更新频繁，企业内部人员对日益增多的核心资产失去控制。同时，随着**云原生、微隔离、无服务器化**等新技术与概念的引入与普及，企业**云安全管理**面临的挑战越来越高，对企业安全运维人员水平的要求也不断提高。

  

面对当前经济生产力的发展与网络安全技术之间的融合和互相依赖程度不断提高，各行各业的企业用户亟需具备梳理并管控每天不断新增的资产，将安全盲区降到最低；同时也要实时强化自身的安全分析与管控、自动化线上应急响应等系列的**态势感知能力**。

  

面对种种云上安全情况，用户亟需能分别提供云工作负载安全、容器安全、微隔离安全、态势感知等众多能力的**云安全管理平台**和**安全运营产品**。

  

凭借契合Gartner对云安全平台能力、安全运营能力等定义的特点以及实际的实施效果，安全狗旗下的**云工作负载安全（CWPP）解决方案**和**啸天态势感知平台**在此次Gartner报告供应商列表中被推荐。

  

**◆◆****云工作负载安全解决方案****◆◆**  

> 依托安全行业里领先的专业技术团队优势，安全狗打造并推出的云工作负载安全（CWPP）解决方案具有国内CWPP公司中最完整的云端负载安全产品能力，能**灵活适配各种混合云环境**。

  

安全狗云工作负载安全解决方案是基于CWPP理念，并根据实际的安全场景，结合近几年概念的演进和大量的安全实践，涵盖了主机安全、容器安全、微隔离、补丁管理等安全需求产品矩阵在内的解决方案。

  

值得关注的是，该解决方案下的三款产品不仅在此次**Gartner的云安全供应商列表**中得到展现，在去年也全线入围**Gartner 2021 CWPP市场指南**报告，并且**容器全生命周期产品·云甲**还入选**云安生技术成熟度曲线**等多份技术报告。

**◆◆****啸天态势感知平台****◆◆**  

> **安全狗啸天态势感知平台**由安全大数据中台、纵深联动响应与自动化编排引擎、云工作负载保护平台（CWPP）探针、网络流量分析（NTA）探针和日志探针组成，具备**集采集、监测、溯源、响应和预防于一体的新一代网络安全智能分析与联动处置平台**。

此产品不仅受到Gartner的推荐，还入选了入选IDC MarketScape态势感知报告，并获得信通院网络攻击溯源能力评测认证，安全实力十分突出。

  

从安全狗系列云安全核心产品&解决方案到安全运营产品相继入选Gartner系列报告来看，安全狗多年来扎根于云安全赛道的成果有了质的飞跃。这也是安全狗始终践行“守护数字世界 助力网络强国”理念、将用户安全需求放首位等初衷所得的成果。

  

安全狗将不忘初心，持续关注国内外先进安全技术，不断巩固自身的云安全生态影响力，提高安全运营能力的输出。通过改善和优化公司的技术研发体系、服务支撑体系，同时紧密跟踪国际、国内技术发展趋势和市场需求动向，力求创新成长，以更加优质的研发成果和安全能力为广大用户创造更大的价值，护航其数字经济转型发展，为我国的网络强国事业添砖加瓦。
