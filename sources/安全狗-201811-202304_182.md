# 重保一线|安全狗出色完成第二十一届中国国际投资贸易洽谈会重保任务

**9月11日**，以“新发展格局下国际投资新机遇”为主题的第二十一届中国国际投资贸易洽谈会（下面简称“厦洽会”）在厦门圆满落幕。

  

作为**国内云安全CWPP领导厂商**，安全狗也受到邀请，以网络安全保护支撑单位的身份参与此次活动。

  

![](../Images/c2edbbc9332502aae0b20ef902c55f62.png)

  

  

据悉，作为**全球规模最大的投资性展览会**，在为期4天的厦洽会中，进行了50余场活动，近100个国家和地区、800多个经贸团组、5000多家企业线上线下参展参会，参展人数高达5万多人，协议总投资额达3920亿元人民币。这把坐落于厦门的“金钥匙”再次受到世界投资界的关注。

  

面对这场聚集世界各地重要客商，具有为多边投资合作打开更多机会、促进国际投资资源流动意义的高规格展览会，为其提供**全程的网络安全监测与防护也显得必要且重要**。值得关注的是，由于参展人数众多，且参展人员中具有多位重要国家领导和国际嘉宾，并且此次厦洽会也是国内外媒体关注的焦点等等，都向此次的网络安全保护工作提出更加严苛的要求。

  

为了全面、安全、无纰漏地开展此次的网络安全保护工作，福建省、厦门市等多个重要部门连续多次召开会议，就如何做好此次安保工作进行研讨与工作部署。安全狗作为**网络安全保护的支撑单位**,也**高度重视**此次任务。在接到任务后，安全狗第一时间组织多次的内部讨论，依托**自身拳头产品和特色服务**，结合以往多场国家级重要网络安保活动经验，制定了此次展览会专属安保方案，按“**保前准备、保中严防、保后总结**”原则展开部署工作，并于**9月1日至9月11日开展11\*24小时全天候的网络安保现场值守**，确保网络安全工作万无一失。

  

  
  
  

安全狗成立于2013年，自成立以来就致力于提供云安全领域相关产品、服务及解决方案，是国内最早引入云工作负载安全（CWPP）概念，并成功构建相应产品线的专业云安全厂商。

  
 

实际上，此次网络安保任务并非安全狗与厦洽会的“初识”。作为厦门市本地网络安保实力突出的安全厂商，安全狗凭借在2017年厦门金砖会晤期间杰出的安保能力获授“安保突出贡献单位称号”荣誉。在2019年，安全狗接到厦洽会相关部门抛过来的“橄榄枝”，今年更是**第三次接到委托**。

  

一直以来，安全狗**围绕CWPP概念**，不断吸收国内外先进安全技术，精进自身的产品解决方案和安全服务能力，同时也紧跟国内《数据安全法》、《个人信息保护法》等系列法律法规，分析用户们千变万化的安全需求，旗下**云主机安全产品云眼**[（点此查看）](http://mp.weixin.qq.com/s?__biz=MjM5NTc2NDM4MQ==&mid=2650825747&idx=1&sn=c4de6af955fb2778f28041587106741a&chksm=bd0745e18a70ccf79be879f96924461837bc0cc39edd302590f3aea04572227bcc42eb0b056b&scene=21#wechat_redirect)、**容器云原生安全产品云甲**[（点此查看）](http://mp.weixin.qq.com/s?__biz=MjM5NTc2NDM4MQ==&mid=2650826042&idx=1&sn=de3df697657db7833a5800958486384b&chksm=bd0744c88a70cddecd2ceca61d1a7a1e183ef40aa5536c7792f0d74238720d260dc173dd2049&scene=21#wechat_redirect)、**微隔离产品云隙**[（点此查看）](http://mp.weixin.qq.com/s?__biz=MjM5NTc2NDM4MQ==&mid=2650825798&idx=1&sn=6ba7b6f08034bc90a2c3974570c1e408&chksm=bd0745b48a70cca2d92e431c98a6cfa123c688c6f0a22306af6ed4f02371bace7251fc3aad0c&scene=21#wechat_redirect)等纷纷**推陈出新**，功能迭代。升级后，云甲的安全能力可覆盖开发、部署、运行时等阶段的全生命周期安全，部署方式包括了平行容器方式/Agent插件双模式，具备了资产全面可视化、镜像威胁及时阻断、运行时异常检测等功能，更好地守护云原生应用安全；云眼则加入内存马检测技术、可支持进程行为监控功能、蜜罐诱捕功能等，有效防御新型网络攻击行为；云隙新增了策略自动生成功能、可快速生成隔离策略、流量跟踪专利技术的应用优化了工作负载流量采集、适配容器环境，业务访问控制更精细等功能。**一系列拳头产品的除旧布新让安全狗的整体防护能力更上一层楼。**

  

![](../Images/3e07a318a3d11af92fa510ac335c372d.png)

  

此次重保期间，安全狗依托旗下**新一代（云）主机入侵监测及安全管理系统云眼**、**啸天流量分析系统**、**新一代网站应用防御系统云御**、**新一代网页防篡改系统云固**、**啸天安全大数据及态势感知平台等系列产品**，为厦洽会官网提供了一站式的重保服务，从网络层面、服务器层面、数据层面构建了全方面的安全防护体系，突出的用户监测发现、安全防护和应急处置能力，有效地遏制了非法恶意攻击、破坏、泄密等安全威胁事件的发生，在国家层面上，更是降低了因安全威胁因素而导致的政治负面事件的发生概率，有效维护了我国在国际政治舞台上的名誉与声望。

此次安全狗收到网络安全保护任务的委托，不仅是对安全狗安全实力的一种认可，更是一种激励。未来，安全狗将坚守“守护数字世界 助力网络强国”的使命，牢记社会责任，不断改善和优化公司的技术研发体系、产品生产体系、服务支撑体系和管理流程；持续地提升自身安全技术水平，加强安全服务能力输出，为国家网络安全体系的健康与稳定发展保驾护航，向外界展示我国更好的形象。
