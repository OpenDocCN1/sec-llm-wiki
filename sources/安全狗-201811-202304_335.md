# 2020年度网络安全十大市场热点

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2NDM4MQ==&mid=2650812691&idx=2&sn=fc855c98e96b49aff53e45e85cc37760&chksm=bd0710e18a7099f7e15e3308ef73e08c1e17edb08d1b1d66fef8cf2d8ddc88d3cdf0b7111386&scene=126&sessionid=1681368097#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTc2NDM4MQ==&mid=2650812691&idx=2&sn=fc855c98e96b49aff53e45e85cc37760&chksm=bd0710e18a7099f7e15e3308ef73e08c1e17edb08d1b1d66fef8cf2d8ddc88d3cdf0b7111386&scene=126&sessionid=1681368097#rd)

基于长期的经验积累与持续的技术与产业调研工作，数世咨询即日起推出各种维度的年度观察，为监管、用户、厂商、资本以及相关研究人员提供参考。

![](../Images/abe14eb334c72cc18d57446bdf4b5678.png)

根据数世咨询目前的不完全统计，2019年中国网络安全市场的规模约在550亿左右，年复合增长率有望超过25%。通过与业界沟通，结合去年的调研数据，预计2020年的市场热点为以下十种方向：

**1**  

**信创安全**

  

**所属领域：**行业环境

**分类级别：**一级

![](../Images/e022301bcc17bca56d426bc02bd31dee.png)

**成 熟 度 ：**发展市场

**代表厂商：**卫士通、中孚信息、深信服、奇安信、启明星辰、天融信、360、北信源、任子行

  

![](../Images/fa38785ef655d8c36fa385210faddf75.png)数世点评：国产化替代近几年内至少是数千亿的规模，按10%的安全占比来说就是数百亿。

  

  

**2**  

**云主机安全**

  

**所属领域：**计算环境

**分类级别：**三级

![](../Images/b8ca4ebe24e1b683964b5ff9f2ae55d6.png)

**成 熟 度 ：**发展市场

**代表厂商：**青藤云安全、安全狗、云锁、杰思安全、阿里云、腾讯云、志翔科技

  

![](../Images/fa38785ef655d8c36fa385210faddf75.png)数世点评：“云管端”的安全架构决定了云主机安全的重要性，近两年来呈现出快速增长的趋势。

  

  

**3**  

EDR

  

**所属领域：**计算对象

**分类级别：**二级

![](../Images/30fcada9acb1e6c6e609a6cea19fb81e.png)

**成 熟 度 ：**新兴市场

**代表厂商：**奇安信、安恒信息、亚信安全、深信服、网思科平

  

![](../Images/fa38785ef655d8c36fa385210faddf75.png)数世点评：过去EDR发展的束缚正在打破，机器学习的普及、用户意识的转变和产品体系的联动，相比过去均有了明显改观。

  

  

**4**  

**开发安全**

  

**所属领域：**业务对象

**分类级别：**一级

![](../Images/3ec7e0198bcb5bb44724ed3e5ce74eb8.png)

**成 熟 度 ：**发展市场

**代表厂商：**悬镜、开源网安、默安科技、孝道科技、思客云、国舜股份、梆梆安全、爱加密 、深信达

  

![](../Images/fa38785ef655d8c36fa385210faddf75.png)

数世点评：出现已经近二十年的技术，现在才开始焕发青春，安全的前移和体系化建设正在取得共识，我们在补课。

  

**5**  

**SD-WAN**

  

**所属领域：**访问控制

**分类级别：**二级

![](../Images/cb3104435616360be4d1e88de6893471.png)

**成 熟 度 ：**新兴市场

**代表厂商：**深信服、信达网安、上元信安、华为、新华三、中兴通讯

  

![](../Images/fa38785ef655d8c36fa385210faddf75.png)数世点评：从流量优化，到流量为主安全为辅，再到流量与安全并重。云的普及，SD-WAN一定会前景巨大，下一个便是CASB。

  

  

**6**  

** IAM**

  

**所属领域：**访问控制

**分类级别：**二级

![](../Images/b878ac44cec9618a941fd566afc61060.png)

**成 熟 度 ：**发展市场

**代表厂商：**亚信安全、竹云、派拉软件、芯盾时代、九州云腾、泰岳安全、安讯奔

  

![](../Images/fa38785ef655d8c36fa385210faddf75.png)数世点评：国内IT环境导致IAM进入国内时就水土不服，堡垒机、4A都是中国特色的变形，如今随着国内IT普及程度的提高，IAM携零信任大潮强势回归。

  

  

**7**  

**网络资产发现**

  

**所属领域：**通用技术

**分类级别：**二级

![](../Images/519250d388e882728c9ed3ed960f4bca.png)

**成 熟 度 ：**发展市场

**代表厂商：**盛邦安全、华顺信安、知道创宇、安恒信息、绿盟科技、魔方安全

  

![](../Images/fa38785ef655d8c36fa385210faddf75.png)数世点评：不清楚保护对象，何谈安全保护？资产发现与管理是网络安全的基石，我们继续补课。

  

  

**8**  

**蜜罐诱捕**

  

**所属领域：**通用技术

**分类级别：**二级

![](../Images/7ade70b492178f0f9a9a3b2d395ae8e0.png)

**成 熟 度 ：**新兴市场

**代表厂商：**默安科技、锦行科技、智信安全、元支点、长亭科技、经纬信安、观安信息、永信至诚

  

![](../Images/fa38785ef655d8c36fa385210faddf75.png)数世点评：主动防御时代，兼具信息收集、伪装欺骗、引诱捕捉等功能于一体的技术，实网攻防的新宠。

  

  

**9**  

**威胁情报**

  

**所属领域：**通用技术

**分类级别：**二级

![](../Images/067c7e91842a4e1ac604bec2b70dd7a0.png)

**成 熟 度 ：**新兴市场

**代表厂商：**奇安信、天际友盟、微步在线、绿盟科技、亚信安全、安恒信息、360

  

![](../Images/fa38785ef655d8c36fa385210faddf75.png)数世点评：这是一个特殊的热点，其以单品形式存在的市场规模始终没有形成，但已经无处不在，安全体系必备。

  

  

**10**  

**态势感知**

  

**所属领域：**综合框架

**分类级别：**一级

![](../Images/c10ea0c81e8a84d28c93d2f188e84846.png)

**成 熟 度 ：**发展市场

**代表厂商：**奇安信、安恒信息、PCSA、华为安全、启明星辰、绿盟科技、亚信安全、观安信息、深信服、瀚思科技

  

![](../Images/fa38785ef655d8c36fa385210faddf75.png)数世点评：集大成者，国之重器。预计明年将步入成熟市场阶段。

  

*注：数咨询将市场成熟度划分为四个阶段，概念市场、新兴市场、发展市场、成熟市场：*

*   **概念市场：**已提出新技术的概念和原理，但具体的框架和方案需要摸索。
    
*   **新兴市场：**出现较为成型的框架和方案，并形成少量的收入，但多数用户尚在观望，需要进一步的市场实践，以丰富功能和验证效果。
    
*   **发展市场：**该技术已有较为成熟的产品及典型案例，市场开始进入快速增长期。
    
*   **成熟市场：**已得到业界普遍认可，市场进入稳定期。
