# 介绍

Triton 是一款动态二进制分析框架，它支持符号执行和污点分析，同时提供了 `pintools` 的 `python` 接口，我们可以使用 `python` 来使用 `pintools` 的功能。 `Triton` 支持的架构有 `x86`, `x64`, `AArch64`.
