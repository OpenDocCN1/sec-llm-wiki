## $$导致的变量覆盖问题

**$$介绍**

$$这种写法称为可变变量

一个可变变量获取了一个普通变量的值作为这个可变变量的变量名。

  

```
<?php
\= "hello"
;echo "$a";          //输出hello
\="world"
;echo "$a";          //输出hello
echo "$$a";         //输出word
echo "$a ${$a}";    //输出hello world
echo "$a $hello";   //输出hello world
?\>

```

**漏洞产生**

使用 foreach 来遍历数组中的值，然后再将获取到的数组键名作为变量，数组中的键值作为变量的值。因此就产生了变量覆盖漏洞。

例如

  

```
<?php
foreach ($\_GET as $key \=>
 $value) {\=

 $value;echo
 $a;?\>

```

get 得到的数据 key 和key和value, 关键第 3 行,ParseError: KaTeX parse error: Expected '}', got 'EOF' at end of input: {key} 用 get 传进来的 key 做为新的变量, 将 get 传进来的key做为新的变量,将get传进来的value 赋值给它。

get ?a=1 第 3 行会解析为 $a=1。就造成了变量覆盖。

## extract()函数使用不当

extract()函数从数组中将变量导入到当前的符号表。该函数使用数组键名作为变量名，使用数组键值作为变量值。针对数组中的每个元素，将在当前符号表中创建对应的一个变量。

`extract(array &$array, int $flags = EXTR_OVERWRITE, string $prefix = ""): int`

第一个参数是必须的，会不会导致变量覆盖漏洞由第二个参数决定，该函数有三种情况会覆盖已有变量。

例如

  

```
<?php
\= 1;    //原变量值为1
\= array('a' \=> '3'
);extract($b);    //经过extract()函数对$b处理后
echo $a;    //输出结果为3
?\>

```

又例如

  

```
<?php
\= "0"
;extract
($\_GET);if ($a \== 1
) {echo "Hacked!"
;else
 {echo "Hello!"

;?\>

```

?a=1 就可以覆盖 a


## parse\_str()函数使用不当

`parse_str(string $string, array &$result): void`

如果未设置 array 参数，由该函数设置的变量将覆盖已存在的同名变量。

php.ini 文件中的 magic\_quotes\_gpc 设置影响该函数的输出。如果已启用，那么在 parse\_str() 解析之前，变量会被 addslashes() 转换。

parse\_str 函数的作用就是解析字符串并注册成变量，在注册变量之前不会验证当前变量是否存在，所以直接覆盖掉已有变量

例如

  

```
<?php
\= 1;                  //原变量值为1
parse\_str('a=2');   //经过parse\_str()函数后注册变量$a，重新赋值
print\_r($a);          //输出结果为2
?\>

```

PHP在处理哈希字符串时，会利用”!=”或”==”来对哈希值进行比较，它把每一个以”0E”开头的哈希值都解释为0，所以如果两个不同的密码经过哈希以后，其哈希值都是以”0E”开头的，那么PHP将会认为他们相同，都是0。

## register\_globals全局变量覆盖

> 注：register\_globals 已自 PHP 5.3.0 起废弃并将自 PHP 5.4.0 起移除。

php.ini 中有一项为 register\_globals，即注册全局变量，当 register\_globals=On 时，传递过来的值会被直接的注册为全局变量直接使用，而 register\_globals=Off 时，我们需要到特定的数组里去得到它。

当register\_globals=On，变量未被初始化且能够用户所控制时，就会存在变量覆盖漏洞：

  

```
<?php
echo "Register\_globals: " . (int)ini\_get("register\_globals") . "<br/>"

;if
 ($a) {echo "Hacked!"

;?\>

```

通过 GET 和 POST 方式输入变量 a 的值都可以覆盖 a

从 cookie 里也可以
