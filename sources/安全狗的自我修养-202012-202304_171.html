研究人员正在调查伊朗COBALT MIRAGE攻击威胁组织，至少自2020年6月以来一直在运营。COBALT MIRAGE与伊朗人有关钴错觉威胁组，主要使用持久性网络钓鱼活动来获取初始访问权限。这两个团体有可能共享贸易和访问。据报道，蜃楼活性的钴元素为含磷的和隧道视界.

根据从 Secureworks 事件响应和公开报告中获得的情报，CTU™ 研究人员确定了两个不同的 COBALT MIRAGE 入侵集群（在图 1 中标记为集群 A 和集群 B）。在组 A 中，威胁参与者使用BitLocker和磁盘加密器为了经济利益而进行机会主义勒索软件攻击。集群B专注于有针对性的入侵，以获取访问权限和收集情报，但其中一些活动已经尝试了勒索软件。

图 1.COBALT MIRAGE活性簇。（资料来源：Secureworks）

COBALT MIRAGE已经显示出对攻击以色列，美国，欧洲和澳大利亚组织的偏好。威胁参与者通过扫描和利用活动获得初始访问权限。2021 年，COBALT MIRAGE 扫描了端口 4443、8443 和 10443，以查找易受 Fortinet FortiOS 漏洞攻击的设备。CVE-2018-13379,CVE-2020-12812和CVE-2019-5591.从2021年9月下旬开始，该组织针对Microsoft Exchange服务器进行了广泛的扫描和利用活动。威胁行为者利用了ProxyShell漏洞 （CVE-2021-34473,CVE-2021-34523和CVE-2021-31207） 以部署快速反向代理客户端 （FRPC） 并启用对易受攻击系统的远程访问。

2021年11月，美国网络安全和基础设施安全局（CISA）发布了一份公告（AA21-321A）与CTU研究人员归因于COBALT MIRAGE的活动有关。该公告没有命名特定团体，而是指代“伊朗政府赞助的APT团体”。

2022年1月，COBALT MIRAGE使用通过ProxyShell利用获得的访问权限（可能在2021年底进行）进入美国慈善组织的网络。1 月 6 日，威胁参与者创建并访问了一个名为 aspx_okqmeibjplh.aspx 的 Web shell。此文件名的格式与 COBALT MIRAGE 勒索软件操作关联的既定模式匹配：aspx_[a-z]{13}\.aspx。攻击者发起的对 Web shell 的 HTTP 请求使用了名为 python-requests/2.23.0 的用户代理，指示使用利用 Python 的脚本请求图书馆。Python 引用可能是由于威胁参与者在其初始攻击中使用基于 Python 的概念验证 ProxyShell 漏洞，以及在入侵期间可能使用其他脚本命令。

在威胁参与者通过Web shell获得访问权限后，在Web服务器上丢弃了三个文件：Wininet.xml，Wininet.bat和dllhost.exe。CTU对Wininet.xml的分析显示，它被用于创建一个启动C：\Windows\Wininet.bat的计划任务。当 Wininet.bat 启动时，它将执行 C：\Windows\dllhost.exe（请参阅图 2）。

图 2.显示 dllhost.exe执行的进程树。（资料来源：Secureworks）

Dllhost.exe是一个自定义的Go二进制文件，它引用与快速反向代理（FRP），表示二进制文件至少部分基于此工具。FRP通常由COBALT MIRAGE部署。但是，dllhost.exe还包括来自其他项目的代码，并且其行为与典型的 FRPC 二进制文件不同。

当威胁参与者在受感染的 Exchange 服务器上执行 dllhost.exe时，二进制文件将作为子进程执行三个命令（请参阅图 3）。这些进程收集有关主机的基本信息，并建立到定义的命令和控制 （C2） 服务器的隧道。同一 PowerShell 命令有两个版本。一个版本使用较旧的 PowerShell 二进制文件名。另一个使用在PowerShell Core 6.0中实现的pwsh.exe文件名，该文件名于2018年1月发布。

图 3.由 dllhost.exe 执行的命令。（资料来源：Secureworks）

Dllhost.exe使用 'tcp443 .毫秒更新 。us' 和 'kcp53 .毫秒更新 。us's 子域用于命令和控制。包含协议（tcp，kcp）和端口号（443，53）是COBALT MIRAGE子域名的一种模式。这个二进制文件也从 http：//148 分发。251 .71 .182/update_win。2021年12月，CTU研究人员观察到COBALT MIRAGE实验Log4j漏洞利用托管在 148 。251 .71 .182.

威胁参与者在 dllhost 执行其命令后不久执行本地安全机构服务器服务 （LSASS） 转储.exe。LSASS 是一个 Windows 进程，用于存储经过身份验证的用户的本地用户名和密码。威胁参与者可以通过暴力破解新技术 LAN 管理器 （NTLM） 哈希或提取以纯文本形式存储的密码，使用这些数据来派生有效的凭据。

CTU研究人员对这些攻击的观察和分析与第三方一致报告CTU研究人员归因于COBALT MIRAGE的其他活性。这些报告描述了ProxyShell用于部署与这些攻击相同的时间段内具有相同文件名的Web shell和文件。

部署 dllhost.exe 三天后，威胁参与者使用远程桌面协议 （RDP） 和内置用户帐户 （DefaultAccount） 登录到受感染的 Exchange 服务器（请参阅图 4）。这是第一次从DefaultAccount登录到服务器，可能表明威胁参与者的开始手动键盘活动。然后，威胁参与者试图通过再次转储LSASS进程来提取本地缓存的密码。他们使用文件名 netscanold.exe通过 SoftPerfect Network Scanner 工具枚举了环境。

图 4.COBALT MIRAGE行动在2022年1月入侵。（资料来源：Secureworks）

威胁参与者横向移动并使用 BitLocker 加密了三个用户工作站，使受感染组织的员工无法访问它们。由于缺少日志记录和取证工件，因此在此环境中用于触发 BitLocker 的方法尚不清楚。但是，其他 COBALT MIRAGE 勒索软件攻击使用脚本（参见图 5）来自动执行攻击。

图 5.COBALT MIRAGE用于激活BitLocker的勒索软件攻击脚本。（资料来源：Secureworks）

此脚本执行以下操作：

  • 将 'mail=' 变量设置为定义的联系人电子邮件地址

  • 启用终端服务（在 Windows Server 2008 之后重命名为远程桌面服务）

  • 创建防火墙规则以启用对主机的 RDP 访问

  • 启动终端服务

  • 启动 BitLocker 磁盘加密

  • 定义赎金消息

  • 添加与 BitLocker 相关的多个注册表项，并创建一条消息，显示赎金消息和联系人电子邮件地址

  • 使用密码_AS_@1394在受感染的系统上创建“MSSQL”用户帐户，并将其添加到管理员和远程桌面用户组中


威胁参与者以一种不寻常的策略完成了攻击，即向本地打印机发送赎金票据。该说明包括一个联系人电子邮件地址和Telegram帐户，用于讨论解密和恢复（参见图6）。此方法建议使用一个小操作，该操作依赖于手动过程将受害者映射到用于锁定其数据的加密密钥。截至本出版物，CTU研究人员还不知道COBALT MIRAGE泄漏点。虽然有些与伊朗有关攻击针对2020年和2021年的中东组织似乎使用勒索软件来制造恐惧和破坏，COBALT MIRAGE攻击的受害者研究表明，这些威胁行为者专注于经济利益。

图 6.2022年1月钴幻影赎金票据。（资料来源：Secureworks）

2022年3月，CTU研究人员根据使用DefaultUser用户帐户，将FRPC部署到受害者网络以及使用与COBALT MIRAGE相关模式匹配的基础设施，将入侵美国地方政府网络归因于COBALT MIRAGE。但是，勒索软件未在攻击中使用。此活动是群集 B 的一部分。

对COBALT MIRAGE攻击的分析具有挑战性，因为不相关的威胁行为者通常还使用相同的漏洞（例如，ProxyShell，Log4Shell).这些威胁参与者中的许多使用相同的公开可用概念验证代码，并可能多次访问同一环境，从而丢弃冗余的Web shell。隐矿者感染通常与钴幻影活动一起观察到，但它们可能已被另一组部署。

2022 年 3 月参与的初始访问媒介尚不清楚，但威胁参与者可能利用了 Log4j 漏洞（CVE-2021-44228,CVE-2021-45046） 在受害者的 VMware Horizon 基础架构上。在2022年初，CTU研究人员观察到多个威胁行为者利用VMware Horizon上的Log4j漏洞来部署加密矿工。COBALT MIRAGE的最初开采可能早在2022年1月下旬就已经发生。获得访问权限后，COBALT MIRAGE 使用 DefaultAccount 用户通过 RDP 在环境中横向移动。

大多数入侵活动在3月中旬持续了四天。有一次，威胁行为者使用受害者环境中的系统进行Google搜索“免费上传文件”，然后访问文件邮件 。com， ufile .io， mega .nz，并且易于上传。io.日志指示其中一个或多个站点可能已用于从环境中泄露数据。威胁参与者还使用easyupload将几个文件（例如，23.zip，pxy.zip，pxy.rar）下载到受感染的系统上。io 和 ufile .io 文件共享服务。

23.zip文件不可用于分析，但 pxy.zip包含一组文件，用于通过 FRPC 建立到攻击者控制的服务器的持久远程隧道（参见图 7）。威胁参与者部署的 FRPC 二进制文件的哈希值与 2021 年 11 月 CISA 公告中列出的二进制哈希值相同。与集群B中使用的其他COBALT MIRAGE域类似，此事件中的C2域（my-logford . ml）已在Freenom注册商处注册。集群 A 中的域通常向 Porkbun 注册。

图 7.pxy.zip中文件的内容和执行流。（资料来源：Secureworks）

Pxy.rar包含与pxy相同的文件.zip还包括wmiexec.exe，这是基于Python的编译版本。wmiexec.pyImpacket工具。威胁参与者获得了对受害者环境中多个帐户的访问权限，并将pxy.zip下载到多个主机以提供冗余访问。当COBALT MIRAGE参与者在场时，Ngrok隧道工具也部署在环境中，但目前尚不清楚他们是否部署了该工具或是否由另一个威胁组织部署。伊朗威胁组织，如狐狸手套钴过去曾使用此工具，但没有迹象表明COBALT FOXGLOVE参与了这种入侵。

威胁行为者下载了一个网络扫描仪来枚举环境，执行Google搜索“软完美网络扫描仪便携式”，并从mega下载netscan_portable_v621.zip。新西兰。威胁参与者执行了多次扫描，并根据扫描系统的 IP 地址创建结果文件名。威胁参与者将网络扫描和其他工具输出上传到 ufile 。io.

在检测到并中断 2022 年 3 月的入侵后，没有观察到其他恶意活动。CTU研究人员没有直接观察到与集群B相关的勒索软件攻击，但有证据表明这些威胁行为者可能正在尝试勒索软件。文件 （rsf.exe）于2021年12月29日从伊朗上传到VirusTotal分析服务，似乎是对勒索软件的未完成尝试。它包含一个 PDB 字符串，该字符串具有不寻常的用户名 （C：\Users\pugna\），该字符串也在PowerLessCLR远程访问特洛伊木马 （RAT）。这个RAT已经托管在162上。55 .137 .20 COBALT MIRAGE使用的 IP 地址。CTU研究人员还观察到COBALT MIRAGE基础设施托管与HiddenTear open-source ransomware family but have not observed the ransomware being deployed to targets.

一月和三月的事件代表了COBALT MIRAGE进行的不同风格的攻击。虽然威胁行为者在初步获得广泛目标方面似乎取得了相当程度的成功，但它们利用这种机会获得经济利益或收集情报的能力似乎有限。至少，COBALT MIRAGE能够使用公开可用的加密工具进行勒索软件操作和大规模扫描和利用活动来危害组织，从而造成持续的威胁。CTU研究人员建议组织优先修补面向互联网的系统上的高严重性和高度公开的漏洞，实施多因素身份验证，并监控COBALT MIRAGE使用的工具和文件共享服务。

为了减少这种恶意软件的暴露，CTU研究人员建议组织使用可用的控件来审查和限制访问，使用表1中列出的指标。请注意，可以重新分配 IP 地址。域和 IP 地址可能包含恶意内容，因此在浏览器中打开它们之前请考虑风险。
