自2021年8月以来，思科Talos观察到Bitter APT组织正在进行恶意活动，该活动似乎针对孟加拉国的用户，这与攻击者通常的受害者有所不同。作为其中的一部分，有一个基于Apost Talos的新木马称为“ZxxZ”，除其他功能外，还包括远程文件执行功能。根据此广告系列中的C2服务器与Bitter之前广告系列的相似性，我们以适度的信心评估此广告系列由Bitter APT组运营。

### 摘要

思科 Talos 发现了自 2021 年 8 月以来由我们认为是 Bitter APT 集团运营的持续活动。这场运动是针对南亚政府实体的参与者的典型例子。

该运动针对孟加拉国政府的一个精英单位，提供一份主题诱饵文件，声称与受害者组织的常规业务任务有关。诱饵文件是发送给孟加拉国警察快速行动营部队（RAB）高级官员的鱼叉式网络钓鱼电子邮件。这些电子邮件包含恶意的RTF文档或Microsoft Excel电子表格，这些电子表格被武器化以利用已知漏洞。一旦受害者打开maldoc，公式编辑器应用程序将自动启动以运行包含shellcode的嵌入对象，以利用CVE-2017-11882，CVE-2018-0798和CVE-2018-0802（全部在Microsoft Office中）描述的已知漏洞，然后从托管服务器下载木马并在受害者的计算机上运行它。该特洛伊木马伪装成 Windows 安全更新服务，并允许恶意执行者执行远程执行代码，通过安装其他工具为其他活动打开大门。在这场战役中，特洛伊木马会自行运行，但攻击者的武器库中还有其他RAT和下载器。

这种监视活动可以允许威胁行为者访问组织的机密信息，并使他们的处理者比竞争对手更具优势，无论他们是否是国家赞助的。

### 痛苦的威胁行为者

Bitter，也被称为T-APT-17，是一个可疑的南亚威胁行为者。自2013年以来，他们一直活跃于中国，巴基斯坦和沙特阿拉伯的能源，工程和政府部门。在他们最近的竞选活动中，他们已将目标扩展到孟加拉国政府实体。

苦涩主要是出于间谍活动。攻击者通常通过HTTP将恶意软件从其托管服务器下载到受感染的端点上，并使用DNS与命令和控制建立联系。Bitter以利用受害者环境中的已知漏洞而闻名。例如，在2021年，安全研究人员发现对手正在利用零日漏洞CVE-2021-28310，这是微软桌面管理器中的一个安全漏洞。众所周知，Bitter同时针对移动和桌面平台。他们的武器库主要包含Bitter RAT，Artra downloader，SlideRAT和AndroRAT。

### 感染链

感染链从鱼叉式网络钓鱼电子邮件和恶意 RTF 文档或 Excel 电子表格附件开始。当受害者打开附件时，它会启动Microsoft公式编辑器应用程序以OLE对象的形式执行公式，并连接到托管服务器以下载并运行有效负载。

![](../Images/2b5054797dc0308f9acec40750598289.png)

*恶意 RTF 感染链摘要。*

  

在恶意Excel电子表格的情况下，当受害者打开文件时，它会启动Microsoft公式编辑器应用程序以执行嵌入的公式对象，并启动任务计划程序以配置两个计划任务。其中一个计划任务将特洛伊木马“ZxxZ”下载到公共用户的帐户空间中，而另一个任务运行“ZxxZ”。

![](../Images/672ac9c45a2f4a4b47257dd1ca619b83.png)

*恶意 Excel 感染链摘要。*

  

  

有效负载作为受害者计算机上的 Windows 安全更新服务运行，并与 C2 建立通信，以远程下载和执行受害者环境中的文件。

### RTF 文档

恶意 RTF 文档被武器化，以利用堆栈溢出漏洞 CVE-2017-11882，该漏洞允许在运行易受攻击版本的 Microsoft Office 的受害者计算机上执行任意代码。我们之前的博客概述了这种特殊的漏洞如何在受害者的环境中工作。

![](../Images/5262475c93ea9bad85d26fb6dea8c986.png)

*恶意 RTF 文档示例。*

  

RTF 文档嵌入了一个 OLE 对象，其类名为“等式 3.0”。它包含外壳代码作为使用 Microsoft 公式编辑器创建的公式。

![](../Images/dabb89ec3c6f4e0674eda8a7abd56497.png)

*嵌入式微软方程式对象。*

  

当受害者使用Microsoft Word打开RTF文件时，它会调用公式编辑器应用程序并执行包含面向返回编程（ROP）小工具的公式。ROP 以加密格式加载并执行位于恶意主机末尾的 shell 代码，该格式连接到恶意主机 olmajhnservice\[。\]com 并从 URL hxxp\[：\]//olmajhnservice\[.\] 下载有效负载。/nxl/nx.有效负载下载到由 shellcode 创建的文件夹“C：\\$Utf”中，并作为进程在受害者的计算机上运行。

### 有效负载

有效负载是在 Visual C++ 中编译的 32 位 Windows 可执行文件，时间戳为 2021 年 9 月 10 日。我们将木马命名为“ZxxZ”，基于有效负载在向C2发送信息时使用的分隔符的名称。此特洛伊木马是下载并执行远程文件的下载程序。在此广告系列中，可执行文件的文件名为“Update.exe”，“ntfsc.exe”或“nx”。它们要么被下载，要么被放入受害者的“本地应用程序数据”文件夹中，并作为具有中等完整性的 Windows 安全更新运行，以提升标准用户的权限。

执行组件使用常用编码技术对 WinMain 函数中的字符串进行模糊处理，以对静态分析工具隐藏其行为。

  

![](../Images/57f812ef9617a13328f76bb0fd96fb24.png)

### C2 通信

对于C2通信，首先，特洛伊木马会发送受害者的计算机名称，用户名，分隔符“ZxxZ”和从注册表中提取的Windows版本。服务器使用格式为<id><user>：“<程序名称”>的数据进行响应。

接下来，恶意软件请求程序数据。服务器发回可移植可执行文件的数据，有效地匹配模式：<零字节或更多字节>ZxxZ<PE数据减去MZ>。然后，它将该文件保存到 %LOCALAPPDATA%\\Debug\\<程序名称>.exe并尝试执行它。

![](../Images/7cd397b6e14b6ca1e9c80fe24b26af12.png)

*请求已发送到 C2。*

  

如果下载成功，服务器将使用操作码 DN-S 发回请求，如果失败，操作码RN\_E其响应中。根据我们的分析，opdoce DN-S表示“下载成功”，RN\_E代表运行错误。如果失败，恶意软件会尝试下载程序数据225次，之后，它将启动并退出。

### 结论

各组织应警惕已知在其所在地区进行针对性攻击的高度积极的威胁行为者。威胁行为者通常以智能技术出现，以实现其对抗目标，我们在这场战役中看到了这样的尝试，在他们的武器库中增加了一种新的变体。

在当前的这场运动中，在破坏受害者的机器并植入具有远程文件执行功能的木马ZxxZ后，攻击者可以部署并运行其武器库中的其他工具以实现其恶意目标。

组织应制定分层防御策略，并在其端点防御解决方案中实施最新的检测规则和行为保护 - 不仅具有技术控制，而且组织应具有成熟的事件响应计划，并简化组织的安全状况，以保护其环境免受最新威胁。
