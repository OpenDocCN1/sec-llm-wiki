一般信息：

与乌克兰国家银行 (CSIRT-NBU) 密切合作的乌克兰计算机紧急事件响应政府团队 CERT-UA 已采取措施调查 DDoS 攻击，攻击者将恶意 JavaScript 代码 (BrownFlood) 置于其结构中。被入侵网站（主要是在 WordPress 下）的网页和文件，导致这些网站访问者的计算机计算资源被用于生成异常数量的攻击对象请求，其 URL 是在恶意 JavaScript 中静态定义的. 代码。
