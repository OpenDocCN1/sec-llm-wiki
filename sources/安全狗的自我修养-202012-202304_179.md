# 使用恶意 JavaScript 代码 BrownFlood 的 DDoS 攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwOTE5MDY5NA==&mid=2247484955&idx=4&sn=5b860cc48c233468404ccaac5050888c&chksm=c13f3552f648bc44fcefa58e447513290920be93518607845ed7c8b048e97c392050378b376e&scene=126&sessionid=1681665600#rd](http://mp.weixin.qq.com/s?__biz=MzkwOTE5MDY5NA==&mid=2247484955&idx=4&sn=5b860cc48c233468404ccaac5050888c&chksm=c13f3552f648bc44fcefa58e447513290920be93518607845ed7c8b048e97c392050378b376e&scene=126&sessionid=1681665600#rd)

一般信息：

与乌克兰国家银行 (CSIRT-NBU) 密切合作的乌克兰计算机紧急事件响应政府团队 CERT-UA 已采取措施调查 DDoS 攻击，攻击者将恶意 JavaScript 代码 (BrownFlood) 置于其结构中。被入侵网站（主要是在 WordPress 下）的网页和文件，导致这些网站访问者的计算机计算资源被用于生成异常数量的攻击对象请求，其 URL 是在恶意 JavaScript 中静态定义的. 代码。

上述恶意 JavaScript 代码可以放置在网站主要文件（HTML、JavaScript 等）的结构中，包括 base64 编码形式。图 1-3 显示了相关示例。

要在 Web 服务器的日志文件中检测与上述类似的异常活动，您应该注意响应代码为 404 的事件，如果它们异常，请将它们与 HTTP 标头“Referer”的值相关联，其中将包含发起请求的 Web 资源的地址（图 4）。基于 BrownFlood 的测试版本，URI 由 Math.random () 函数形成，看起来与图 2 中所示的相似。此模板也可用于使用正则表达式进行搜索，但是，攻击者可以随时更改此功能。

有关包含 BrownFlood 代码的被入侵网站的详尽列表，请参阅“入侵指标”部分。Yara 检测此恶意软件的规则列在“威胁检测工具”部分。

CERT-UA 已采取措施告知对网站所有者以及相关域名注册商和托管服务提供商的威胁。

活动由 UAC-0101 跟踪。

  

妥协指标：

```


hxxp://cmtheodor\[.\]be
```

  

建议：

1\. 采取措施检测和删除恶意 JavaScript 代码。

2\. 为网站内容管理系统（CMS）提供最新和最新的支持。

3\. 限制访问网站管理页面。
