Loader分析

下载样本发现是一个 .net的程序

CVE-2022-26809.exe: PE32 executable (console) Intel 80386 Mono/.Net assembly, for MS Windows

用dnspy加载起来，看一下，外围的程序仅仅是一个loader，在内部解密了一个模块，然后用executingAssembly.LoadModule加载起来。

动态调试一下，把里面的模块dump出来，接下来开始分析模块。

模块分析

模块内部主要有三个函数，但是这个模块没有入口点，不能当做exe直接执行，所以我找了一个 .net 的laoder来加载这个模块。

模块加载器用的是 : https://github.com/hexfati/SharpDllLoader

但是这里需要一些修改，对 .net 程序不熟悉，这里非常感谢 @404师傅的指导，这个加载器要修改一下才能使用。

要不然没办法获取函数，另外向模块函数传参的地方也需要修改一下，不再细说了。

接下来看一下模块的代码，此模块运行时首先探测了一下提供的ip和port能否联通。

  2. 2. 传入参数之后，会判断参数指定的ip和端口是否可以连通

  3. 3. 会判断自身目录下是否存在文件 shellcode.bin
