顶会作者亲临！暑期学校讲师顶级研究成果一览

你是否想要在国际最顶级的学术会议上发表高水平的研究论文？你是否想了解构思新颖的idea、撰写高质量paper并最终获得审稿人青睐的秘笈？2021年第六届Let's GoSSIP软件安全暑期学校的讲师团中，有来自学术界的6名顶级研究人员和4位超新星青年研究人员，他们在最近两年的国际顶级学术会议（包括安全研究的四大安全顶会IEEE S&P、USEINX Security、CCS和NDSS，程序、系统等领域的顶级会议ISSTA、PLDI、OSDI、ICDCS）上发表了多篇高质量的研究成果，并将在暑期学校和大家进行零距离分享，下面我们来看看各位讲师的最新成果吧！


苏亭  华东师范大学

教授，博导，就职于华东师范大学软件工程学院，研究成果获得了Google教授研究奖、三项ACM SIGSOFT杰出论文奖（ICSE 2018、ASE 2018/2019）等。主要研究方向为软件工程、程序语言和软件安全，在PLDI、OOPSLA、ICSE、FSE、ASE、ISSTA、TSE等国际顶级会议和期刊上发表论文30余篇，担任ICSE、OOPSLA等国际顶级会议的PC成员。设计研发的App自动化测试工具已为腾讯、字节、谷歌等拥有亿级用户数量的软件产品发现了不少真实软件错误；工控软件的自动化单元测试工具SmartRocket Unit已服务于国内十余家大型企业的软件生产部门。其研究工作受到了中国/瑞士国家自然基金委、Google、ByteDance等公司资助。

苏亭老师最新的研究成果包括发表在ISSTA 2021会议上的研究论文Understanding and Finding System Setting-Related Defects in Android Apps，这篇论文介绍的代码缺陷测试技术在微信、腾讯邮箱、抖音等超过10亿日活用户数的Android应用上发现了新的bug！



汤战勇  西北大学

教授，博士生导师，主要研究方向为软件与系统安全。主持多项国家级课题，近年来在CCS、NDSS、PLDI、MOBICOM、INFOCOM、UBICOMP、SenSys和以及TIFS、TOPS、TON上发表多项相关研究成果，其中获CCS'18和SenSys'19最佳论文提名，部分研究被英国《泰晤士报》、美国《福布斯》以及国内主流媒体广泛报道，并在蚂蚁、华为、腾讯等企业落地应用。2018年获陕西省科学技术二等奖，2019年获ACM China 新星奖（西安）。

汤战勇老师最新的研究成果包括发表在PLDI 2021会议上的研究论文Automated Conformance Testing for JavaScript Engines via Deep Compiler Fuzzing，该论文提出的Deep Compiler Fuzzing技术，在JavaScript引擎上报告了158个bug，其中115个已被开发者确认并修复，同时该研究成果在 https://github.com/NWU-NISL-Fuzzing/COMFORT 上开源。


张锋巍  南方科技大学

副教授，研究员，博导。在加入南科大之前，他是美国韦恩州立大学计算机系助理教授（2015-2019）。他于2015年获得美国乔治梅森大学计算机专业的博士学位。主要研究领域是系统安全，包括可信执行、硬件辅助安全、恶意软件透明分析，以及可否认加密。

张锋巍老师最新的研究成果包括发表在IEEE S&P 2021会议上的研究论文Happer: Unpacking Android Apps via a Hardware-Assisted Approach，这篇论文首次利用ARM处理器硬件特性来支持高度透明的Android应用脱壳，实现了极佳的代码恢复效果~


夏虞斌  上海交通大学

作为2015全国“挑战杯”特等奖指导老师，夏虞斌教授是Let's GoSSIP 软件安全暑期学校自创办之初就从未缺席的金牌讲师。他每年都会为我们带来操作系统、系统虚拟化与系统结构领域在系统安全能力增强上的最新研究进展和应用介绍。夏虞斌教授的主要研究方向为操作系统隔离。获教育部技术发明一等奖，上海市技术发明一等奖，上海市学术带头人。在OSDI、EuroSys、USENIX ATC、FAST、ISCA、ASPLOS等国际会议发表/录用多篇论文，并担任包括OSDI等一系列国际会议的程序委员会委员。领导团队开发的安全操作系统T6获2015年第十四届“挑战杯”特等奖，实际部署设备数量过亿；基于RISC-V平台研发的安全操作系统“蓬莱”已开源。

夏虞斌老师的最新代表性研究成果是发表在在OSDI 2021会议上的研究论文Scalable Memory Protection in the PENGLAI Enclave，该论文介绍了IPADS实验室在2019年设计并开源的TEE安全系统蓬莱（Penglai-Enclave https://penglai-enclave.systems/）如何实施可扩展的内存安全防护，其性能指标非常亮眼！


赵磊  武汉大学

武汉大学网络安全学院教授，博士生导师，长期从事软件及系统安全方向研究，尤其是二进制程序的安全分析、软件漏洞的自动化挖掘、漏洞利用生成等关键技术及工具的研发。

赵磊老师的代表性研究成果是发表在CCS 2020会议上的研究论文PatchScope: Memory Object Centric Patch Diffing，该论文对安全补丁的代码改动进行了大规模研究，总结了安全补丁的模式，进而提出了一种基于内存对象访问序列的动态补丁差异分析技术。这种方法不仅可以精确定位补丁差异，还可以提供丰富的补丁上下文信息，进一步帮助安全分析人员了解补丁的细节，定位漏洞的根本原因，并可以识别引入漏洞的补丁。


白家驹  清华大学

清华大学计算机系助理研究员，2013年本科毕业于西安电子科技大学，2018年博士毕业于清华大学，并获得清华大学优秀博士学位论文奖。2018至2020年在清华大学从事博士后研究工作。其研究方向为系统软件可靠性、操作系统和程序分析，具体利用动态分析和静态分析技术来自动检测系统软件的缺陷。在操作系统和系统安全会议和期刊上已发表20余篇学术论文，包括ACM TOCS、ACM ASPLOS、USENIX ATC和USENIX Security等顶级会议和期刊。其研究团队所设计的程序分析工具，在主流操作系统（包括Linux、FreeBSD和Zephyr等）中发现了数千个真实缺陷，并在华为、蚂蚁金服和腾讯等公司中得到实际部署和使用，在缺陷检测方面效果良好。

白家驹老师的最新研究成果包括发表在USENIX Security 2021会议上的研究论文Static Detection of Unsafe DMA Accesses in Device Drivers，该论文设计实现了名为SADA的检测工具，检测Linux设备驱动中不安全DMA访问的问题。作者使用5.6版本的Linux代码对SADA进行了实验评估，并且发现了284处不安全DMA访问。其中121处可以触发buffer overflow，36处可以触发非法指针访问进而造成任意内存读写。



在今年暑期学校的特别环节——Youth Day中，我们更是邀请到了4位发表过顶级学术会议论文的年轻人，分享他们的研究经验，他们是：


李嘉奇  浙江大学

浙江大学网络空间安全专业三年级博士，曾参加2018及2019届Gossip暑期学校。目前主要的研究方向是数据隐私保护、数据库系统安全。李嘉奇博士的代表性研究成果是ICDCS 2020会议的最佳论文 HybrIDX: New Hybrid Index for Volume-hiding Range Queries in Data Outsourcing Services


宗珮媛  中科院信工所

中国科学院信息工程研究所陈恺研究员团队博士生，主要研究智能化技术与模糊测试技术结合的漏洞检测与利用技术，针对创新性漏洞检测与利用方法发表在USENIX Security、ACM CCS等安全领域顶级会议上。宗佩媛博士的代表性研究成果是USENIX Security 2020会议的论文FuzzGuard: Filtering out Unreachable Inputs in Directed Grey-box Fuzzing through Deep Learning


杜天宇  浙江大学

浙江大学计算机学院网络空间安全专业博士研究生，师从纪守领研究员，主要研究方向为人工智能安全，在国际会议与期刊上发表论文十余篇，包括USENIX Security、CCS、NDSS等。杜天宇博士的代表性研究成果是CCS 2021会议的论文Cert-RNN: Towards Certifying the Robustness of Recurrent Neural Networks 


南雨宏  普渡大学

南雨宏博士2018年毕业于复旦大学计算机科学技术学院，师从杨珉教授。目前为普渡大学（Purdue University）计算机系博士后研究员，并即将于今年9月以“百人计划”副教授身份加入中山大学软件工程学院。南雨宏博士的主要研究方向为系统软件安全及隐私保护。南雨宏博士的最新研究成果包括NDSS 2021会议的论文On the Insecurity of SMS One-Time Password Messages against Local Attackers in Modern Mobile Devices
