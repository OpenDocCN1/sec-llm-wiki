今天要为大家送上的是——当当当——先卖一个关子，让我们来看关于软件巨人Microsoft的新闻：

  

微软股价本周二上涨 1.1%，市值首次突破了 2 万亿美元，与苹果一起成为唯二两家市值达到两万亿美元的企业之一。微软是在 2019 年 4 月 25 日市值突破 1 万亿美元，仅仅两年之后它的市值就翻了一倍。苹果的情况类似，它也是在两年内市值翻一番，2020 年 8 月突破 2 万亿美元。微软的云计算业务是该公司的最大亮点，2020 年智能云业务占到了微软总收入的 33.8%，收入增长 24%

  

下面是针对这条新闻的一项选择题，问题是，微软公司为何能在本周突破两万亿美元市值大关，请大家选择正确答案：

  

**选项A：**微软正式宣布了它下一代操作系统 Windows 11。它与 Windows 10 的关系更像是新瓶旧酒。Windows 11 最大的变化是它的用户界面，包括新的开始菜单，更新了开始按钮，新 UI 与已经取消的 Windows 10X 相似，任务栏默认在底部中心位置显示。开始按钮抛弃了从 Windows 8 起引入的动态磁贴。微软称，Windows updates 将更小更有效率，它将在后台工作。Windows 11 还直接整合了 Microsoft Teams 和 Xbox Game Pass。

  

**选项B：**微软在宣布 Windows 11 时透露它能运行 Android 应用。Windows Developer Platform 企业副总裁 Kevin Gallo 公开了这一功能背后的技术细节：Windows Subsystem for Android。它的作用类似 Windows Subsystem for Linux (WSL)，在 Android 应用模型和 Windows 应用模型之间提供一个代理原生应用，将有一个虚拟机提供对 Android Open Source Project (AOSP)的兼容。

  

**选项C：**微软开始推送 Windows 10 21H1。Windows 10 用户现在可以在 Windows 更新中直接看到 Windows 10 21H1 的手动下载，微软还没有开始通过自动更新直接推送给用户。Windows 10 21H1 的主要变化包括：使用外部摄像头作为 Windows Hello 的默认设备；改进了 Microsoft Defender 应用程序防护，使文档能够更快地打开，同时还可以检查可能存在的安全问题；改进了对远程工作的支持，等等。

  

**选项D：**以上选项均不正确

  

正确答案当然是D！软件巨人之所以能够突破2万亿美元的市值大关，据G.O.S.S.I.P的可靠八卦，是因为这么一则小道消息——**2021年7月28日，在上海闵行区紫竹高新科技园，由紫竹两大巨无霸——上海交通大学和微软携手为大家送上一场盛大的安全研究学术活动！**这场活动将云集诸多工业界和学术界的大咖，为热爱软件与系统安全的你送上久违的安全学术盛宴！
