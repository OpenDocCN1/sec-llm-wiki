# 安全研究实验室巡礼——滑铁卢大学徐萌课题组

这周我们为大家介绍一位将在今年九月在加拿大滑铁卢大学出道的徐萌老师（博导）研究组~

  

![](../Images/81bc7902d6e9450a6202111e9440fe0d.png)

徐萌博士于2020年毕业于佐治亚理工大学计算机系，师从Taesoo Kim，并即将于今年9月作为助理教授入职加拿大滑铁卢大学（University of Waterloo)。徐萌博士的主要研究方向为系统和软件安全，致力于用高质量的研究解决实际的安全问题。具体研究内容包括但不限于：漏洞挖掘，面向安全的编程语言，程序分析，以及新兴硬件安全特性。以下是一些计划中的研究项目：

*   **静态程序分析**
    

*   High-fidelity program symbolization: 解决路径爆炸，循环，以及symbolic 内存访问的问题
    
*   Threading-aware memory-modeling: 解决多线程内存访问的建模问题
    

*   **动态程序分析**
    

*   Multi-dimensional fuzzing: 解决分布式系统fuzzing的多个难点
    
*   Semantic-aware harness generation: 解决生成高质量的seed input的问题
    

*   **新兴硬件安全/安全应用**
    

*   Resource-safe programming: 解决TEE编程的难点，提高TEE程序的正确性
    
*   Security holes of formally-verified software: 探索形式化验证之后软件可能存留的安全漏洞
    

*   **防御机制**
    

*   Security via multi-layer diversity: 探索在多个层次提高多样性对系统和软件安全的作用
    
*   Equi-semantic transformation and patching: 探索如何以更安全更智能的方式自动重构代码
    

除此之外，也非常欢迎学生提出自己感兴趣的科研项目去一起挖掘，一起思考，一起开发~

徐萌博士目前gap year就职于Facebook，是新一代智能合约语言Move的开发团队成员之一，致力于Move语言的编译器，虚拟机，以及形式化验证工具的开发和维护。作为新一代的编程语言，Move已经不满足于仅仅保证内存安全。我们一直在探索如何在语言层面保证（特定的）逻辑安全漏洞不会出现，同时配以形式化验证来尽可能消除其他的逻辑漏洞。Move语言的应用也会是徐萌博士课题组在滑铁卢大学的研究方向之一。

Move项目主页：https://developers.diem.com/main/docs/move-overview

徐萌在博士期间发表十余篇信息安全和系统方向顶会论文（IEEE SP, CCS, USENIX Security, SOSP, ATC)，同时也积极参与工业界的合作（例如与Google syzkaller integrate的file system fuzzing，在Microsoft实习时发表的IoT dominance概念，以及现在对Move语言的贡献等）。对于计算机安全的研究领域来说，与工业界的联系不仅是创造和扩大影响力的方式，更有可能孕育启迪新的研究方向。将来有合适的机会也会积极推荐学生去工业界实习。
