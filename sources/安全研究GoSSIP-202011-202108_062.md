火热的欧洲杯很快就要开始了，趁着足球赛的间隙，我们赶紧来读论文。今天为大家送上一篇发表在ISSTA 2021会议上关于Android应用的native代码中的虚拟化加固方案的反保护研究论文：

![](../Images/6bc8bc2a7c635f7e464588056aa6b309.png)

  

2021年我们介绍过桌面平台上更好的代码脱壳工具API-Xray（G.O.S.S.I.P 学术论文推荐 2020-04-23）和移动平台针对Android应用字节码更好的代码脱壳工具Happer（IEEE S&P 2021 参会小记---5月26日论文报告），今天介绍的Parema工具专门针对的是Android平台上native代码中的虚拟化加固保护。相信大家对虚拟化加固保护并不陌生，诸如VMProtect等保护早已在Windows平台上广泛部署，G.O.S.S.I.P在2017年的ISC会议上曾经发表过一篇对抗此类保护的论文（Nightingale: Translating Embedded VM Code in x86 Binary Executables）

  

![](../Images/111216c3393b35b74be10567f0332d76.png)

  

![](../Images/a9f36f0ca29f371a885f964b2e56f567.png)

  

对于Android平台，此类代码保护方兴未艾。尽管大家对这类VM保护技术的认知已经比较完善，但是专门针对Android native代码的反保护工具乏善可陈，因此作者设计了Parema工具，用来解决此类问题。特别地，Parema工具引入了一些机器学习技术来改变传统工作纯粹依靠启发式或者程序分析所遇到的困境。

  

![](../Images/f74da8c2c237408549b75108aca1a8ed.png)

  

当然，传统研究中使用的基于符号执行的分析仍然会被用在这类场合：  

![](../Images/12610c6f546d2bcc42faed0310e5e2e0.png)
