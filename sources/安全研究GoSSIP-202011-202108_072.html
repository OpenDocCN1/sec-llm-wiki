安全研究实验室巡礼——乔治梅森大学的Sun Security Lab

五月的最后一周，我们为大家介绍由孙琨老师创立并领导的美国乔治梅森大学的Sun Security Lab。



孙琨老师（个人主页：https://csis.gmu.edu/ksun/）目前是乔治梅森大学信息科学与技术系的副教授，同时还担任安全信息系统中心副主任。孙老师在南开大学计算机系获得学士和硕士学位后，赴北卡罗来纳州立大学计算机系继续深造，并获得博士学位。在加入乔治梅森大学前，他曾在威廉玛丽学院担任助理教授，智能自动化公司高级研究员，贝尔实验室研究员，在工业界和学术界有超过15年的研究工作经验。至今他有超百篇研究论文发表在国际知名的计算机安全会议和期刊上，如IEEE S&P，CCS，USENIX Security, NDSS，RAID，EuroS&P，DSN，ACSAC，AsiaCCS，TDSC，TIFS等，其中包括了两篇获得了所参加会议最佳论文奖的论文。



实验室的研究方向主要包括：


  • 可信性计算：通过将硬件层面的安全拓展（ARM TrustZone、Intel SGX等）与软件层面的隔离方法结合，来设计出可信计算系统，用以保护X86（AsiaCCS 2021, S&P 2015）和ARM（CCS 2020, ACSAC 2020, S&P 2016）处理器上的代码和数据安全。

  • 软件安全：采用机器学习的方法区分安全补丁与非安全补丁，用以实现优先应用安全补丁来降低0-day/N-day攻击 (DSN 2019)的目的。我们将此方法应用于GitHub开源项目的commit上，识别出近8K个“秘密”安全补丁，从而建立了一个大规模的安全补丁数据库 （DSN 2021）。该数据库可用于漏洞/补丁检测、补丁生成等进一步研究。

  • 人工智能安全：使用信号处理技术，研究声音的幅频特性并产生与扬声器对应的逆滤波器，寻找可能的针对智能语音识别系统的回放攻击方式，并设计增强的防御措施 （CCS 2020）。我们同时将利用声音的物理特性，增强无人汽车情景下的智能语音系统的安全（RAID 2020）。

  • 动态目标防御：通过将系统隐藏在持续变化的虚拟环境和使用具有高度欺骗性的蜜罐提供虚假信息来保护系统安全（INFOCOM 2016, DIMVA 2017）。

  • 网络安全：和清华大学合作，研究传统TCP/IP协议中潜藏的安全问题(CCS 2020)，以及新兴的软件定义网络面临的攻击（NDSS 2020, USENIX Security 2019）。



Sun Security Lab所在的乔治梅森大学安全信息系统中心（CSIS）成立于1990年，是美国大学第一个安全学术中心。作为公认的美国顶尖的国家研究和学术安全中心之一，CSIS在学术教育和信息安全研究领域一直处于世界领先地位。

乔治梅森大学位于弗吉尼亚州的费尔法克斯(Fairfax)，该地区及附近地区常年居全美家庭收入榜前列，治安环境极好；毗邻美国首府Washington D.C.，交通便捷，环境优美，潮汐湖畔的樱花节世界闻名。随着亚马逊的第二总部在学校周边的建立，乔治梅森大学计算机学院的排名在未来10年会迎来显著提高。学校附近生活便利，亚超、中餐、韩餐、日餐云集，例如由前国宴大厨张鹏亮主理的Mama Chang餐馆，远近闻名，也是实验室日常聚餐场所🤓。

Sun Security Lab的同学有大量的实习机会，包括Facebook, NEC Lab, Samsung, Cisco Lab, Baidu USA等。实验室长期招收具有本科或硕士计算机及相关专业背景的博士生，并提供全额奖学金，也招收具有计算机专业博士学位的博士后。同时，实验室也欢迎国内有兴趣的访问学者和学生与实验室交流合作~有兴趣的同学或者同行，欢迎发信咨询:  ksun3@gmu.edu
