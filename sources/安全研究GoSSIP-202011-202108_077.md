一年一度的安全学术研究的顶级盛会——IEEE Symposium on Security and Privacy（IEEE S&P, aka. Oakland）即将于北京时间5月24日也就是今天深夜拉开帷幕啦。由于疫情一波未平，一波又起，今年的会议同样选择在线上召开。会议从5月24日开始持续到5月26日（在线会议为PDT时间），目前参会人员已超过1100人。  

与今年二月份我们为大家送上的[NDSS 2021 参会小记](https://mp.weixin.qq.com/s?__biz=Mzg5ODUxMzg0Ng==&mid=2247484849&idx=1&sn=a573b6c827304dd1ffe3765d2ab2bb4d&scene=21#wechat_redirect)一样，本周G.O.S.S.I.P仍然会在线参加会议，并将在接下来几天的学术论文推荐栏目中，为大家带来今年S&P的论文精彩摘录。由于会议时间与北京时间有15个小时的时差，我们的参会小记会在每日会议结束的晚上准时推送给大家。更全面的会议论文内容，请大家关注会议官网 https://www.ieee-security.org/TC/SP2021/program.html 。

今晚即将进行的第一日议程包含Software Security, Mobile Security, IoT Security and Privacy以及Adversarial Machine Learning等安全研究热点session，千万不要错过！在之前的G.O.S.S.I.P学术论文推送中，我们已经给大家推荐过其中的部分文章，先来回顾一下吧：

[【G.O.S.S.I.P 学术论文推荐 2020-09-24】When Function Signature Recovery Meets Compiler Optimization](https://mp.weixin.qq.com/s?__biz=MzA5MzQ1MDI2MA==&mid=2456042444&idx=1&sn=b6f49f9cab3f84378df4f2828b4d6e83&scene=21#wechat_redirect)

> 这篇论文讨论了编译器代码优化对反汇编分析过程中函数签名（function signature）的识别产生的（正面与负面并存）的影响。现有一些工作（如TypeArmor）会在二进制代码上对函数的调用约定（call convention）进行分析并生成函数签名，为caller和callee寻找配对关系。为了研究编译器优化对基于函数签名的识别工作的影响，作者详细分析了编译器存在的8类对函数签名的改变，其中包括对使用stack还是使用register来进行参数传递的识别的影响，对特定寄存器的使用的误判。

[【G.O.S.S.I.P 学术论文推荐 2021-02-02】DIANE: Identifying Fuzzing Triggers in Apps to Generate Under-constrained Inputs for IoT Devices](https://mp.weixin.qq.com/s?__biz=Mzg5ODUxMzg0Ng==&mid=2247484646&idx=1&sn=e5d8f1188f7a14d2ee4487c7ec333b39&scene=21#wechat_redirect)

> 本文作者针对这种应用端验证代码约束的问题提出并设计了一种新的IoT Fuzzing工具——DIANE，该工具能够分析得到IoT设备配套应用中的fuzzing triggers函数，并以此来生成有效的模糊输入（不受验证代码的约束），从而大大的提高fuzzing的效率。

其他的精彩内容我们会在明晚与大家分享，明天一定要记得关注哦！
