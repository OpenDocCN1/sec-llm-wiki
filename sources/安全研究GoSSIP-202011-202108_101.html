2018年CCS会议上，我们在binary code analysis这个session上有幸结识了好几位杰出的华人研究人员，其中一位是专注于Windows平台代码脱壳研究的程斌林老师。时隔三年，程老师和合作者又为我们带来了代码脱壳研究新作，今天我们就为大家介绍这篇USENIX Security 2021的论文：

在这篇论文中，作者利用了处理器的硬件特性，设计了一款名为API-Xray的脱壳工具，这款工具的核心竞争力是基于BTS和NX bit等硬件辅助特性支持的Hardware-Assisted API Micro Execution。其核心目标是实现更为通用且能够对抗恶意代码的import table（IAT）重建，从而帮助分析人员实现对加壳代码更为全面的理解



API-Xray工具的详细工作流程图如下所示，其信息搜集跨越了处理器、内核和用户态三层，在各个层面上获取需要的信息，并通过对已有的加壳保护技术的总结，判断哪些信息标志了API调用。同时，作者引入的一种轻量级执行技术——API Micro Execution，只针对trampline code释放API调用信息进行执行，从而获取相关的API信息进而恢复调用表。
