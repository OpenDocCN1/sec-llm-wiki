即将迎来NDSS 2021的线上会议了，今天给大家推荐来自NDSS 2021的一篇研究Apple Mach port安全的论文“POP and PUSH”，作者是来自阿里巴巴猎户座安全实验室的三位著名的研究人员、浙江大学的周亚金老师和清华大学的张超老师。

这篇文章研究的对象是iOS、macOS这类基于XNU的操作系统。针对XNU kernel的传统攻击通常同时需要信息泄露和控制流劫持这两类漏洞，即先借助信息泄漏漏洞来解决KASLR，然后借助控制流劫持漏洞去执行ROP gadget。然而，由于PAC的部署，控制流劫持变得很困难。于是也就有了本文总结的(Mach) Port Object-Oriented Programming (POP)攻击。


首先大致介绍一下Mach port。它表示系统资源、服务或功能，是XNU中进程间通信的一种方式。用户空间的进程可以通过IPC机制，向Mach port发送消息，来请求一些敏感的服务。具体来说，内核空间的Mach port由指向ipc_port对象的指针表示，其handler在用户空间以Mach port name来表示。由于这类Mach port对象在内核中是被无条件信任的，因此借助Mach Port的攻击能够进一步获取内核内存的控制权，也就是本文总结的POP攻击，如图2所示。

这类攻击之前已经在iOS jailbreak中使用了，本文则是先对这类攻击进行了系统的归纳。首先，其条件是存在能用于破坏内核对象的内存破坏漏洞，然后借助图3中的这几个攻击原语一步步提升：

  1. Querying Primitive (QP)：用于打破基于随机化的保护策略，例如random_free_to_zone引入的freelist的随机化。借助QP原语（需要多重），能够借助错误返回值等有限的信息来找到corrupted port对应的handler。

  2. Kernel Memory Read Primitive (RP)：用于获取内核内存读取能力。该原语基于对类型完整性的不充分检查来滥用破坏的端口对象。

  3. Kernel Memory Write Primitive (WP)：依赖RP获得的内核信息，WP原语能够利用伪造的ipc_port对象来修改内核内存。

  4. Privileged Purpose Primitives (PPP)：XNU向特权端口提供了一些强力的系统调用，PPP原语就是获取权限向这些特权端口发送消息来得到这些强力的系统调用。

  5. 其他攻击原语：作者文章中讨论了任意代码执行原语ACEP。与之前的QP，RP，WP和PPP不同，ACEP着眼于破坏函数指针。

借助这五种原语，就能构建POP攻击链。作者文中以用于iOS 10.2越狱的Yalu Exploit为例子进行了POP攻击的具体说明。虽然总结了方法论作为指南，但是实际应用中显然是困难的，这些原语的条件还是较为苛刻的，需要依赖原语的积累。

总结了POP后，作者提出了Port Ultra-SHield (PUSH) 作为防护，如图7所示。由三部分组成：

  1. POP primitive searcher：根据之前归纳的模型从XNU源码与kernel cache中查找潜在的POP原语；

  2. PUSH policy generator：为Mach port对象采用对应策略从而在特定的Mach系统调用前后保护其完整性；

  4. PUSH checker：用于部署PUSH policy generator，相当于kernel extension。

在评估中，作者对表2的一系列漏洞进行了测试，涵盖了macOS 10.12-10.15和iOS 10-13。

其表现用插桩点IPs来表征，作者对IP的数量和具体内容做了分析，并通过case study进行了具体说明。除此之外，也对性能开销进行了测试，只有约2%的额外开销。测试的设备数量相当多，在阿里的40000多台macOS设备上部署了PUSH，结果显示确实能有效防御公开的18个exploit和一个0day exploit，也得到了苹果的致谢。

最后总结几句：这篇文章的研究思路是比较讨巧的，既有攻击也有防御，其攻击（POP）并非首创，而是归纳了过去的一类exploit，比较系统地总结了一套方法论与模型，然后对应这个方法论进行了防御（PUSH）的设计，这种防御的论证和实验也是难点。这类文章的内容非常充实，很值得去精读学习，包括其引用的文献资料，都可以作为进一步学习的材料。当然纸上得来终觉浅，还是得硬着头皮去实操，去积累原语。
