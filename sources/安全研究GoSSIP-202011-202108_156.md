每日学术论文推荐又回归了！亲爱的读者朋友们，我们想死你们啦~

  

今天我们带大家去看一篇曾经在G.O.S.S.I.P学习、目前在普渡大学读博的张倬同学（https://www.cs.purdue.edu/homes/zhan3299/）的一作论文，发表在2021年的IEEE S&P会议上

  

![](../Images/470baa12d993b131dbfe163b30847d0c.png)

  

在这篇论文中，作者定下了一个小目标，挑战主流的反编译工具如IDA、Ghidra和Angr等，实现更好的变量和数据结构分析恢复（针对stripped binary code）。为了实现这一目标，作者沿袭了他们组在ICSE 2019年提出的Probabilistic Disassembly，在本文中再次提出了一种新型 probabilistic variable & data structure 恢复技术，让我们来看看这项技术的特色何在。

  

![](../Images/c1f9944ef3faaba7171c2d4cc9eba033.png)

  

作者首先用gzip里面的一段代码作为实例，总结了主流反编译工具的分析结果。可以看到，同原始代码对比，IDA、Ghidra和Angr都偏差很大，只有几个学术系统如TIE、REWARDS和Howard的结果还不错。而作者自己设计的Osprey系统能够更好地还原相关的数据结构

  

![](../Images/413e80ab42f8f86b675a41fe9c7fcb8f.png)

  

Osprey系统通过扩展张倬本人在OOPSLA 2019上提出的BDA系统（BDA: Practical Dependence Analysis for Binary Executables by Unbiased Whole-Program Path Sampling and Per-Path Abstract Interpretation），深入分析了memory access patterns, data-ﬂow through register and memory, points-to, heap usage等程序行为，然后利用这些行为特征来给变量和数据结构的多种可能反编译结果赋予概率权重，选择概率最高的项作为最终反编译结果，效果十分理想！

  

![](../Images/d867d76b57f678ef503baf568350e457.png)
