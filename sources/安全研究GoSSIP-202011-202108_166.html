今天推荐的论文是发表在NDSS 2021的"Favocado:Fuzzing the Binding Code of JavaScript Engines Using Semantically Correct TestCases"。

 

JavaScript是由JS引擎解释的动态高级编程语言，它不具备一些必须的底层函数，如内存管理和文件读取。为了使用这些函数，JS运行时系统（Runtime system）在JS引擎中囊括了绑定代码（binding code）部分，该部分能够在具有底层函数功能的原生代码和JS之间创建必要的数据类型。绑定代码必须以严格的安全原则执行翻译过程，以避免原生代码存在的问题被引入到JS中。

 


作者认为，现有的JS Fuzzer面临的挑战有二：第一，测试用例必须是语义上正确的；第二，模糊测试的输入空间要精简。为了解决这些挑战，作者设计了Favocado方法。

如图所示。首先，Favocado对接口定义语言（Interface Definition Language，IDL）和API引用进行了语义上的解析。


接下来，Favocado生成了一个带有绑定代码语义信息的JS文件（测试用例生成器），并使用这个JS文件对目标JS运行时系统进行模糊测试。在这一过程中，测试用例生成器首先会在预定义语句中随机选择JS语句格式（如下图），包括定义对象、调用方法、为属性赋值等语句。接着，测试用例生成器利用上一步收集的语义信息和上下文信息来完成这个语句。该过程可以在一定程度上解决上面提到的挑战一，防止了运行时意外的错误。

 

此外，为了处理较大的输入空间问题（挑战二），Favocado对输入空间进行了划分，以提高模糊测试的有效性。具体来说，作者注意到了JS绑定层的一个特性，即DOM对象之间相互隔离，于是作者将整个输入空间划分为多个等价类，而Favocado仅需要在等价类中进行的模糊测试。


最后，作者验证了Favocado的有效性，实验结果表明，Favocado的性能优于最先进的DOM fuzzer。作者使用Favocado对四个JavaScript运行时系统（Adobe Acrobat Reader、Foxit PDF Reader、Chromium和WebKit）进行了模糊测试，并发现了61个以前未知的bug。其中33个漏洞是安全漏洞。
