# G.O.S.S.I.P 学术论文推荐 2021-01-15

今天给大家推荐的是来自USENIX Security 2020的一篇关于SGX Enclave安全性的论文—— "TEEREX: Discovery and Exploitation of Memory Corruption Vulnerabilities in SGX Enclaves"。

![](../Images/c7aad087476c6e920efc9363b54fc441.png)

在这篇论文中，作者为我们展示了SGX Enclave的潜在攻击面，并设计了一个基于符号执行的自动化分析工具TEEREX，用于检测SGX Enclave二进制程序中Host与Enclave接口的潜在漏洞。

  

现有的针对SGX攻击的研究工作都默认假设攻击者已经有Enclave里的内存破坏漏洞，从而可以劫持Enclave的控制流。然而，这类漏洞是否存在还是有待研究的一个问题。本文作者通过逆向一些公开Enclave程序，发现很多Enclave中的问题都存在于Host Application和Enclave的边界中，如图1所示。

![](../Images/e0aadfba3e6ca73676a9bd575ecb471d.png)

  

由此，作者设计了TEEREX，其主要架构如图3所示。TEEREX主要检测三类漏洞：控制流劫持、任意地址写、空指针解引用，主要包含以下几个组件：

*   Preprocessor：识别符号执行无法处理的函数或指令，并收集所有的ECALL信息。
    
*   TEEREX Symbolic Execution
    

*   Enclave Loader：初始化符号执行ECALLD环境，替换一些通用函数和特殊指令为Python模拟代码。
    
*   Symbolic Explorer：基于Angr符号执行框架。不同ECALL可以独立分别分析，因此可以在不同的机器上同时进行。
    
*   Vulnerability Detection：主要分析内存访问指令以及跳转指令。
    
*   Pointer Tracking：处理指针情况。
    

*   漏洞报告：包括漏洞类型、二进制程序中的位置、攻击者可控输入中影响到被控指针的数据位置、到达漏洞指令的执行路径。
    

*   利用漏洞报告信息，分析者可以快速构建PoC程序。
    

![](../Images/e781a5117127d1551af7b079324bc531.png)

  

利用TEEREX，作者对一些公开的Enclave二进制程序进行了分析，发现了其中许多Enclave存在内存破坏问题，包括由Intel、百度、WolfSSL开发的Enclave以及流行的笔记本品牌所用的生物指纹识别软件等。

![](../Images/61acc674d8a47e3063a5307e2bbb8678.png)

  

通过对检测结果的分析，作者总结了五类开发时很容易出现的漏洞，包括Passing Data-Structures with Pointers、Returning pointers to enclave memory、Pointers to Overlapping Memory、NULL-Pointer Dereferences和Time-of-Check Time-of-Use。

![](../Images/df6dd873a326408e383ccd36fe56cfba.png)

  

此外，作者使用三个enclave（Intel GMP示例Enclave、Rust SGX SDK's tlsclient，WolfSSL的示例Enclave）对TEEREX进行了性能测试，结果如图9所示。测试实验总共分析了73个ECALL，平均分析每个ECALL用了8.8GB的内存。其中，40%的ECALL在10秒内分析完成，52%的ECALL可以分析完成，8%的ECALL分析超出条件限制（时间、内存）。

![](../Images/54990da77dbf116c1b5895d6a7cf983d.png)

  
最后，作者还检查了TEEREX的检测结果是否存在误报。通过编写PoC进行验证，作者确认了TEEREX在三个enclave（Intel GMP示例Enclave、Rust SGX SDK's tlsclient，WolfSSL的示例Enclave）中发现的149个问题都是确实存在的。
