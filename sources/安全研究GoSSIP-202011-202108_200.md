在2020年的小尾巴🙈，我们将为大家带来澳大利亚昆士兰大学[马思奇](https://mp.weixin.qq.com/s?__biz=MzA5MzQ1MDI2MA==&mid=2456041695&idx=1&sn=026d3e8d87f751915d0e56fbaecb2014&chksm=87cd21a4b0baa8b2fe85a85fd27d73ca73c009397a3226ecbb832f597ce6f586baaa827932e6&scene=21#wechat_redirect)研究组的招生广告~

  

![](../Images/9a2c03dd232ec4cac82c9cce5d531d8c.png)

  

马思奇博士（个人主页：https://siqima.me/）于2020年加入昆士兰大学信息技术与电子工程学院任助理教授。马老师致力于利用软件工程的技术方法进行软件的安全性分析和防御，从而对真实软件设计和实现进行漏洞检测与分析。同时确定漏洞的类型和造成原因。马老师在安全学术顶级会议和期刊发表的论文中包含了对各类软件系统的分析，其中包括，移动应用，物联网，无人机，大数据预测模型，并且在这些软件系统中检测到authentication bug, memory corruption, cryptographic misuses, OTP misuses, input validation bug等。针对于现有已检测的漏洞，马老师团队利用软件工程领域的软件分析方法 （e.g., control flow analysis, data flow analysis）对当前漏洞实现进行代码检测。通过学习现有bug 代码的生成模式来给出对应的修复方案，同时利用机器学习的方法对此类修复方案进行模式学习来实现自动化漏洞的修复（e.g., CDRep, VuRLE）。

地点：Australia, St Lucia

  

指导老师：Professor Ryan Ko, Dr Guangdong Bai, Dr Naipeng Dong, Dr Siqi Ma

  

相关课题：

随着远程控制技术（remote management of operational technology）与漏洞挖掘研究的不断发展与不断更新，电子设备存在越来越多的潜在威胁，例如密码学算法的误用，认证协议的不完善等。所以马老师团队更倾向于设计自动化工具来协助开发者和工程师进行软件的安全性检测。为了完成该自动化工具，会用到一系列的安全性分析技术来对软件和系统的代码和网络协议进行分析，常用的技术包括program analysis，formal analysis，quantitate analysis。

  

四个相关的研究方向：

*   Analysis of blockchain and smart contracts
    
*   Analysis of IoT
    
*   Deep learning for symbolic execution
    
*   Analysis of mobile apps and systems.
