今天给大家推荐的论文是发表在Usenix Security 2021的《HAWatcher: Semantics-Aware Anomaly Detection for Appified Smart Homes》。

由于IoT设备与物理环境紧密联系，因此智能家居中的任何异常（攻击或故障）都可能会造成严重后果。现有的检测方法大多利用数据挖掘技术，具有较高的误报率，并且会丢失大量程序和设备的信息，缺乏对于IoT应用环境的实际考量。因此，本文作者提出了一种适用于智能家居的语义感知异常检测系统——HAWatcher（Home Automation Watcher）。


首先，作者对现实世界中智能家居的设备故障和攻击进行了调研，主要包含以下几类异常：

  • IoT Device Malfuctions

    • 故障事件：例如不正常的传感器的值

    • Ghost命令：IoT设备之间的关联指令

    • 事件丢失/延迟

    • 命令无效：设备无法执行IoT平台的指令

  • Attacks on IoT Devices

    • 伪造事件

    • 伪造命令

    • 事件拦截

    • 命令拦截

    • 受损设备

HAWatcher的目标是能够检测上述的故障和事件，该系统基于事件日志和语义，根据语义信息生成关联并使用事件日志对其进行验证。


HAWatcher主要包含四个模块：

  • Semantic Analysis

    • 语义分析模块会从应用程序及其配置文件中提取语义，并将语义转换为关联性，表示为trigger(T)-condition(C)-action(A)。

  • Correlation Mining

    • 这一步是挖掘用户行为和设备物理事件之间的相关性。作者提出了一种基于语义的高精度挖掘方法，包括事件日志预处理、假设相关性生成以及假设检验三个部分。

  • Correlation Refining

    • 作者将从应用程序中提取的关联性与上一步挖掘出的关联结合起来，并进一步提炼细化。

  • Anomaly Detection

    • 作者设计了一个Shadow Execution Engine，该引擎基于获取的关联性来模拟智能家居的正常行为。运行期间，如果设备的真实状态和模拟状态不一致，则被报告为异常。


作者在四个真实世界测试平台上评估了HAWatcher，针对62个不同的异常案例进行了测试。结果表明，HAWatcher具有较高的准确率和较低的误报率。
