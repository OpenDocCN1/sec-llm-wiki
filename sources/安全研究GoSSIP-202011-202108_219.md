# G.O.S.S.I.P 学术论文推荐 2020-12-03

今日推荐的论文是发表在S&P 2021上的《Black Widow: Blackbox Data-driven Web Scanning》，作者针对当下Web应用程序的黑盒漏洞扫描技术进行了改进。

![](../Images/375bdc92cf773f3ffe593842fbc999fd.png)

首先，作者总结了当下Web应用程序漏洞扫描技术面临的三个挑战。

*   第一，导航建模（NavigationModeling）——扫描程序需要对Web应用程序可能出现的所有状态，以及状态之间的连接、依赖关系进行建模。如图一，扫描程序必须能够对链接，表单，事件及它们之间的交互关系进行建模。
    
*   第二，遍历（Traversing）——要识别状态间的依赖关系，就需要对Web应用程序中复杂工作流程进行遍历。如图一，经过遍历后，可以观测到正常链接导航、表格提交和事件交互结合在一起的工作流。
    
*   第三，内部状态依赖（Inter-state Dependencies）——扫描器能够跟踪到状态之间细微的依赖关系，这里作者特指的是如何准确地检查出用户输入对Web应用程序的影响。如图一，admin.php#users页面中的操作可能会影响view\_users.php的状态转换。因此，在检测表单中的XSS攻击时，扫描程序在admin.php#users页面注入的有效载荷后，应该前往view\_users.php页面检测是否发生了变化。
    

![](../Images/3e1ad6e55a248a910f85d2cf2321dc99.png)

随后，作者介绍了他们对Web应用程序的扫描方法。

1.  导航建模。模型是在扫描应用程序的过程中创建的，扫描程序会提取已注册的JS事件，记录下JS事件触发时JS程序的内部状态变化或页面变化。在这一过程中，作者会为应用程序生成一张有标记的有向图，节点是应用程序的状态，边是使得状态改变的事件。
    
2.  遍历。扫描程序使用广度优先算法，按照添加进图中的顺序选择出一些边出来。这一步可以帮助扫描程序在深入了解应用程序的特定组件之前，对其有一个概观。在该阶段中，作者特别关注了表单提交过程，由于该过程通常涉及到用户执行一些具有特定步骤的操作，为了识别出这些操作，作者使用了对工作流进行建模的方法。
    
3.  内部状态依赖。该过程是为了发现用户的输入给应用程序状态带来的影响。作者使用了端到端的动态污点追踪技术，即输入特定的字符，并跟踪该字符出现的位置。
    
4.  动态XSS漏洞扫描。在该过程中，作者使用了细粒度的动态检测机制，即对每个XSS有效载荷进行特定的编号，由此可以避免误报的发生。
    

  

作者将Black Widow与其他7个扫描工具对10个Web应用程序进行了对比分析，结果表明Black Widow可以提高63%-280%的代码覆盖率，并在零误报的前提下发现了更多的XSS漏洞。
