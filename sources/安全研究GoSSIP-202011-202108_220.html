今日推荐的论文是来自波士顿大学的发表在USENIX SEC 2021上的《Saphire: Sandboxing PHP Applications with Tailored System Call Allowlists》，作者针对Web应用程序上的任意代码执行（Remote code execution，RCE）设计了一套防御框架。

现如今，任意代码执行（Arbitrary code-executions，ACE）是对于Web应用程序最为危险的漏洞之一，它允许攻击者完全控制运行中的应用程序。该漏洞如此危险的原因在于，应用程序在设计时没有遵循最小权限原则（Principle of least privilege，PoLP），攻击者能够在攻击时仅被操作系统的访问控制机制所约束。因此，在本文中，作者介绍了一种抽象感知技术，该技术可以将PoLP作用于解释型应用程序。

该框架由三个部分（阶段）组成：第1步，分析解释器暴露给应用程序的API，识别出API可以触发的系统调用集合；第2步，标识给定程序使用的API函数，并为程序创建系统调用的配置文件（Allowlists）；第3步，每当解释器执行该程序时，强制执行第2步创建的配置文件。

以上述框架为原型，作者针对PHP解释器设计了Saphire。如图2所示，Saphire分为以下三个阶段：

  • 通过构建解释器及其所包含的库的静态调用图，Saphire将解释器内置的PHP函数映射为系统调用，同时，Saphire补充了解释器在执行测试套件时执行的系统调用，以防止静态分析遗漏的间接函数调用。

  • 其次，Saphire识别了每个Web应用程序脚本的依赖，并确定解释器在运行脚本时调用的内置PHP函数。Saphire使用php-parser将每个脚本解析为其抽象语法树（AST），扫描了该语法树以查找PHP函数或方法的调用。参考第一步，Saphire利用扫描到的内置函数集合，生成为系统调用配置文件（Allowlists）。

  • 最后，Saphire使用seccomp工具将步骤2得到的Allowlists应用于Web应用程序，以达到将解释程序放在沙箱里执行的目的。

在实验评估过程中，作者对21种已知的易受攻击的Web应用程序和插件进行了评估。结果表明Saphire能够成功地阻止RCE的攻击，且开销较小。
