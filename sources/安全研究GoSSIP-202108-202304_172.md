# 安全研究实验室巡礼——宾夕法尼亚州立大学贾进元研究组

2022年下半年的第一篇安全实验室巡礼为大家介绍的是将于2023年夏天加入宾夕法尼亚州立大学的贾进元研究组~~![](../Images/586d616974481f0b6e2aad6bd160baea.png)贾老师于2016年获得中国科学技术大学（USTC）电子信息工程学士学位，于2022年在杜克大学（Duke University）师从[Prof. Neil Zhenqiang Gong](http://mp.weixin.qq.com/s?__biz=Mzg5ODUxMzg0Ng==&mid=2247483984&idx=1&sn=d037d6f6619d4a61f3912622eed16281&chksm=c0602c89f717a59f786100c3c16392ce55a5b6f7919edb105f951f5bdebcf070ced388b5cde5&scene=21#wechat_redirect)取得电气和计算机工程博士学位。贾老师目前在伊利诺伊大学厄巴纳-香槟分校（UIUC）师从Prof. Bo Li从事博士后研究员工作。他的主要研究方向为**机器学习、可信人工智能**。相关成果发表在顶级机器学习、信息安全和数据挖掘会议，如 NeurIPS、ICLR、CVPR、IEEE S&P、USENIX Security、CCS、NDSS、WWW和KDD。个人网页：https://jinyuan-jia.github.io谷歌学术页面：https://scholar.google.com/citations?user=iyg4ytkAAAAJ&hl=en![](../Images/ef7d17a0bce8c5beaf52bc62dbb1a961.png)宾夕法尼亚州立大学计算机usnews排名第34， csranking排名第27，计算机安全方向csranking排名第9。学校主校区位于宾夕法尼亚州State College, 是一个典型的大学城。关于学校生活，其最具优势的是：

*   治安非常好，非常安全，绝大多数人口都是大学相关人员。
*   生活成本低，生活便利有许多中超和中餐馆。学校日常有校车服务覆盖整个大学城，即使没车也能日常通勤。
*   交通便利，开车15分钟可以到达机场（可直飞纽约、费城、芝加哥等城市），开车2.5小时可以到匹兹堡，3小时可以到费城，3.5小时到华盛顿DC，4小时到纽约。

1.  对科研充满热情
2.  对机器学习和可信人工智能感兴趣
3.  比较强的编程能力
4.  拥有以下任何学科的背景：计算机、电子工程、安全、自动化、统计、数学、物理等
5.  之前有过研究经历或者托福口语达到23分是加分项（不做硬性要求）
