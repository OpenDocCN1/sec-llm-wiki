今天为大家推荐的论文是来自宾西法尼亚州立大学Ting Wang老师Alps Lab投稿的关于神经网络后门攻击与防御的工作TrojanZoo: Towards Unified, Holistic, and Practical Evaluation of Neural Backdoors，该工作已经发表于EuroS&P 2022。

背景介绍
后门攻击和防御在图像识别领域已经有很多相关工作（如BadNet与Neural Cleanse），但对于研究人员来说，他们缺少一个类似于Adversarial Attack里CleverHans的统一架构来评估不同攻击与防御的性能。所以在之前的工作中，科研人员往往耗费大量精力来复现基准方法。在这个工作中，作者囊括了8种后门攻击与14种防御，定义有6种攻击评估指标与10种防御评估指标，并提供出在5种常用数据集（CIFAR10，CIFAR100，GTSRB与ImageNet与VGGFace2）上所有交叉情况的性能评估结果。基于此平台，作者还深入讨论了许多后门研究中的常见疑问，这些疑问基于后门领域整体而需要多种方法实验结果支持，是之前的论文无法涉及的。篇幅原因本文只介绍基础的攻击防御性能评估结果。

后门攻击与防御的性能评估
下面展示主要的攻击与防御实验结果，更多细节请参阅论文。
  • 攻击实验结果
    作者在不同大小和透明度的后门上评估了8种攻击方法，结果显示后门越大，透明度越低，攻击成功率就越高。这与自然直觉相吻合。在8种攻击方法中，Latent Backdoor与IMC表现较好。

  • 防御实验结果
    之前的表格将防御划分为四类：Input Reformation，Input Filtering，Model Sanitization与Model Inspection。其中Input Reformation和Model Sanitization共用一套测量指标，以下展示主要的实验结果。
    a. Input Reformation与Model Sanitization
  实验结果显示Manifold Projection（即MagNet），Fine Pruning与Adversarial Retraining对大部分攻击有较好的表现。


    b. Input Filtering

    实验结果显示STRIP仅对Latent Backdoor与IMC有效，可能的解释是这两个攻击足够强进而导致了后门在混合图片中对分类概率的支配作用。

    c. Model Inspection
    实验结果显示Neural Cleanse，TABOR与ABS表现较好。他们的作用机理类似，都是通过在被污染的模型上优化搜索各个类的potential trigger来发现其中的outlier。


写在最后
在论文发表后，TrojanZoo又添加了2个clean label（Invisible Poison与Refool）、1个dynamic（Input Aware Dynamic）攻击方法与1个过滤训练数据的防御方法（Activation Clustering）。已有的方法大部分在与原论文作者交流后再次重写，所以实际运行结果可能与论文结果有所出入。
