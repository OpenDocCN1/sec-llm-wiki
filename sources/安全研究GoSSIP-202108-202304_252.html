在这个骄阳似火的周一，我们为大家推荐的论文是来自南洋理工大学 Cyber Security Lab与中科院信工所孟国柱老师联合投稿的关于深度学习神经网络在常见软工场景中应用的工作Learning Program Semantics with Code Representations: An Empirical Study，该工作已经被SANER 2022 录用。



如今深度学习技术被广泛地应用到不同的软工场景 （例如软件漏洞检测，软件功能描述，代码补全）。这些应用的本质是借助于深度神经网络学习代码的语义信息从而理解代码行为。相比于自然语言，程序代码是一种高度抽象的数据，它包含了不同的表征方式 （例如抽象语法树 AST， 程序控制流图 CFG， 数据依赖图DDG），不同程序表征往往体现程序不同维度的语义信息， 但目前业界仍然缺乏一个系统化研究来度量程序表征方式对模型学习语义信息的影响。进一步而言，针对于不同的应用场景，存在不同的代码表征方式。相关的研究需要进行深入地探讨与分析。

作者针对于上述问题，首次系统地调研了程序的四种常见表征方式（Feature-based, Sequence-based, Tree-based 和Graph-based）在常见软工场景代码功能分类（program classification），漏洞检测（vulnerability detection）和克隆检测（clone detection）三个任务学习程序语义的能力。针对于不同表征，作者利用不同模型学习程序语义，调研框架如图1所示。

为了获取程序的Tree-based和Graph-based表征方式，作者利用Joern对代码片段进行解析，从而获取程序的抽象语法树（abstract syntax tree）和代码属性图（code property graph）如图2所示：


图2


其中代码属性图（CPG）整合了抽象语法树AST，控制流图CFG，控制依赖图CDG和数据依赖图DDG用以表征程序的不同结构化信息。

作者进一步提出三个研究问题：

  • 在上述任务上比较不同的表征方式，从而确定哪种方式性能最佳？

  • 针对Tree-based和Graph-based表征，节点的类型信息和文本信息对于上述分类任务的影响。

  • 由于一个程序可以解析出不同的结构（如抽象语法树AST，控制流图CFG，控制依赖图CDG和数据依赖图DDG），针对Graph-based表征，哪种结构能够在这三个任务上达到最好的表现？

为了回答第一个问题，作者比较了四种表征方式在不同模型上的性能，实验结果如表1下：


表1


作者发现Graph-based 表征相对于其他三种表征方式能够更好地学习程序语义，相反Feature-based 表征方式在这三个任务上性能最差，作者归功于人工定制的特征不能覆盖程序的所有特征并且采用的传统机器学习算法特征只有有限的学习能力。作者通过第一个问题，回答了Graph-based表征方式能够很好地学习程序语义，进而探索第二个问题。对于图中节点的不同信息，节点类型和节点文本对于上述分类任务的影响，实验结果如表2所示：


表2



作者发现相对于节点类型信息，节点的文本信息对于模型的影响更大，但是当拼接节点类型和节点文本信息通过一个全连接神经网络（即Hybrid），模型的性能达到最优。第三个研究问题是针对于Graph-based表征方式的不同类型子图，作者尝试回答不同子图的影响对于Gated Graph Neural Network（GGNN）的影响，实验结果如表3所示：


表3


作者发现不同任务依赖task-specific语义以实现模型最优，例如在漏洞识别任务上，DDG比较于其他子图，有更好的识别准确率（Acc），作者归因于数据集中包含更多数据依赖类型的漏洞如buffer overflow等，但一般来说利用CPG学习程序语义能在不同任务上达到一个理想的性能。
