澳大利亚新南威尔士大学SATLab（G.O.S.S.I.P 澳大利亚分部）计划在2022至2023年招收多名博士生从事软件系统安全方向的研究。



SATLab由马思奇博士创立并领导，李卷孺博士与普渡大学的Elisa Bertino教授联合指导的，致力于打造多元化的、国际一流的软件系统安全实验室。实验室的主要研究方向为，利用软件工程的技术方法进行软件的安全性分析和防御，从而对真实软件设计和实现进行漏洞检测与分析，相关的研究成果已经以论文的形式多次发表在IEEE S&P、ICSE、TDSC、ACSAC等多个安全领域与软工领域的顶会上，并获得软工领域著名旗舰会议SANER 2020最佳论文奖。



SATLab近期研究成果：

  • Goshawk: Hunting Memory Corruptions via Structure-Aware and Object-Centric Memory Operation Synopsis @IEEE S&P 2022 

  • Annotating, Tracking, and Protecting Cryptographic Secrets with CryptoMPK @IEEE S&P 2022 

  • Control Parameters Considered Harmful: Detecting Range Specification Bugs in Drone Configuration Modules via Learning-Guided Search @ICSE 2022 

  • Fine with ``1234''? An Analysis of SMS One-Time Password Randomness in Android Apps @ICSE 2022 

  • SparrowHawk: Memory Safety Flaw Detection via Data-Driven Source Code Annotation @Inscrypt 2021 

  • Orchestration or Automation: Authentication Flaw Detection in Android Apps @TDSC 2020  


SATLab坐落于美丽优雅的澳大利亚首府堪培拉，隶属于澳大利亚新南威尔士大学。新南威尔士大学是一所享誉世界的顶尖公立研究型大学，为澳大利亚八校联盟，环太平洋大学联盟，国际的几大学联盟和英联邦大学协会成员。新南威尔士大学在最新QS世界大学排名中位列第43名，在U.S.News世界大学排名位列第41位。

招生信息！

你需要具备：

  • 要求本科就读于985/211大学，计算机/软件/电子工程/网络空间安全及相关专业毕业的本科生及硕士生，均分85分以上（若有国际知名会议/期刊论文发表，可适当放宽均分要求）

  • 雅思成绩6.5，单科不低于6分

  • 有一定的软件设计和代码分析能力


加入SATLab后你将享受的待遇：

  • 为了支持学生充分专注于学术研究，SATLab将为学生提供全额奖学金（每年35,000澳元），根据学生的表现，可额外获得5000-10000澳元补贴，免税！还免学费！

  • 优良的学习、工作、科研环境

  • 世界级的学术合作
