# G.O.S.S.I.P 阅读推荐 2022-04-07

上海也许从来没有哪个4月像现在一样，充满了无数渴望去上班的人。为了清零而不计成本的隔离，只能让我们从阅读中汲取能量。今天我想为你介绍一个很有趣的blog——CJ Ting's Blog (https://cjting.me/)，里面的文章都不难读懂，技术上也并无特别艰深之处，字里行间充满了青年计算机人蓬勃向上的朝气，非常适合在心情低落的时候阅读！

  

![](../Images/05b425de20e02fd28ccf4bc5d85d19e4.png)

  

我们要为大家推荐博客里面的三篇文章，第一篇是博主2020年底发布的博文《编写一个最小的 64 位 Hello World》 (https://cjting.me/2020/12/10/tiny-x64-helloworld/)。尽管很多书籍和文章都介绍过如何只用最少的字节写出各个平台的可执行文件，在这篇博文中，博主聚焦于文件尺寸是如何被占用（以及应该如何精简），深入浅出为初学者介绍了可执行文件的结构  

  

![](../Images/d7b2e3af4500cec1901240623d647ae7.png)

第二篇博文是《用 C 实现一个 CHIP-8 模拟器》(https://cjting.me/2020/06/07/chip8-emulator/)，这篇文章有趣之处在于，实现模拟器并非为了什么考试或者大作业，而是为了GBA游戏，这种乐趣驱动coding的做法实在令人欢喜

  

![](../Images/d56c40017e606eb8cd90c1e4d64bdf16.png)

  

最后一篇博文是《CS107e: 树莓派，ARM 和操作系统》(https://cjting.me/2020/09/11/cs107e-review/)，非常喜欢博主在里面说的一段话：“从上大学开始，我就对底层十分感兴趣，事实上我对所有事物最本质的原理都很感兴趣”，这种探究精神，也是我们做科研必备的品质啊！

  

![](../Images/2f6a25bfdefbacc1d5d313d3ff61367e.png)

  

欢迎大家去八卦一下这位有趣的博主，如果有什么发现请记得给我们留言哦
