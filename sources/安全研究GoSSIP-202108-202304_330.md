# G.O.S.S.I.P 阅读推荐 2022-03-29

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5ODUxMzg0Ng==&mid=2247489287&idx=1&sn=4d9f5a996232b7ad20185cd0e7babf32&chksm=c06039def717b0c8be84582fff2ae001e947df1ee7276cb5c3d8484dfcc86c0d56bfdb4a10cc&scene=126&sessionid=1681404185#rd](http://mp.weixin.qq.com/s?__biz=Mzg5ODUxMzg0Ng==&mid=2247489287&idx=1&sn=4d9f5a996232b7ad20185cd0e7babf32&chksm=c06039def717b0c8be84582fff2ae001e947df1ee7276cb5c3d8484dfcc86c0d56bfdb4a10cc&scene=126&sessionid=1681404185#rd)

今天给大家推荐的是来自IEEE S&P 2022的一篇论文——“Automated Attack Synthesis by Extracting Finite State Machines from Protocol Specification Documents”。本文作者关注自动化从文档提取协议有限状态机（FSM）的技术，提出了一种数据驱动的方式从RFC文档中提取有限状态机，并能够用于攻击合成。

![](../Images/d84906a82b0396f80d7effdecde4e721.png)

自动攻击发现技术通常需要协议以有限状态机的形式表示，但很多协议通常仅用文本描述，将其提取为一个有限状态机是十分耗时且极容易出错的。尽管已有的一些研究使用基于NLP的方式来实现信息提取和语义分析，但是这些方法需要对文本预先标记，而标记足够多的协议文本来支持可靠的NLP分析是一个成本高且十分困难的过程。

![](../Images/5dacd3089687c044f2531f3125916bcd.png)

本文作者以RFC作为协议描述的代表性格式，提出了一种组合的方法来从RFC文档提取特定协议有限状态机。该方法主要包含三步：

（1）Technical Language Embedding.  
作者首先利用相关文档（技术论坛、博客、研究论文和规范文档等）来学习技术语言的分布式单词表示，即嵌入模型。作者收集了ietf.org和rfc-editor.org全套文档，利用BERT无监督模型来完成此过程，数据集包括8858个文档和大约4.75亿个单词。

![](../Images/6e146856162fbb87892cce9f5fe0027c.png)

（2）Zero-Shot Protocol Extraction.  
在学习了相关表示之后，作者进一步利用模型从RFC中提取有关有限状态机的信息。为此，作者定义了一个语法来描述网络协议通用有限状态机的高层次抽象（如图2所示），这种抽象能够利用不同的协议来学习提取这些信息。即使相关文档的底层结构、有限状态机的描述方式及变量、事件和状态在不同协议之间有所不同，也无需重新训练。该过程输出中间表示。

![](../Images/65ff5cc2c013490b25c3227d0016b269.png)

（3）Protocol State Machine Extraction.  
最后，作者利用一组启发式方法来从中间表示提取实现相关协议的实际有限状态机。

作者对该方法的有限状态机提取以及攻击合成效果进行评估。

*   Information Extraction Evaluation
    

*   作者使用了六种不同协议（BGPv4、DCCP、LTP、PPTP、SCTP和TCP）来进行测试：对五个协议进行训练，对剩下一个进行测试；比对的有限状态机是从专家知识、RFC及相关文献中衍生出来的有限状态机。
    
*   结果表明，该方法能够正确提取部分的有限状态机；图2所示的抽象语法可以捕获足够多的信息来重构有限状态机的重要部分；该方法具有足够的通用性，可应用于各种协议。

*   Attacker Synthesis Evaluation
    

*   作者利用KORG，使用本文方法提取的有限状态机对TCP和DCCP连接的建立和销毁攻击合成进行测试。结果表明，提取的有限状态机能够成功生成几个已确认的攻击者。
