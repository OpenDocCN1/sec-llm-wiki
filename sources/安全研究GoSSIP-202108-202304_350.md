# G.O.S.S.I.P 学术论文推荐 2022-03-03 利用智能手机GPU窃取用户机密信息

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5ODUxMzg0Ng==&mid=2247488956&idx=1&sn=2bbb59c4a737233dee46aa8a7dfcc614&chksm=c0603b65f717b273bdd63d0e3b8e88f2be712ce59ecb5562d793fd36da737d66c9c7c3a61616&scene=126&sessionid=1681404195#rd](http://mp.weixin.qq.com/s?__biz=Mzg5ODUxMzg0Ng==&mid=2247488956&idx=1&sn=2bbb59c4a737233dee46aa8a7dfcc614&chksm=c0603b65f717b273bdd63d0e3b8e88f2be712ce59ecb5562d793fd36da737d66c9c7c3a61616&scene=126&sessionid=1681404195#rd)

我们来关注一下计算机系统结构顶会ASPLOS 2022上的最新研究成果，在安全研究的相关session中，今天为大家介绍的是一篇侧信道安全攻击研究论文，介绍了如何利用智能手机的GPU作为side channel来窃取用户机密（credentials）

![](../Images/c5c6ff6b9bc1636b0ee3dfcfb2ad0a56.png)

这篇论文在写作上非常友好，特别是给出了大量的示意图，让初级读者都能迅速理解相关攻击的核心，同时技术细节非常翔实，而且作者还提供了完整的Artifacts，读者完全可以重现相关攻击！那么让我们带大家来快速浏览一下论文的主要内容。

![](../Images/1544bc950c2288a59aaf355953a5e815.png)

作者在他们提出的攻击中利用的一些前提包括：1）用户在使用手机输入法点击特定字符时，会高亮显示该字符（如上图所示），这会产生特殊的GPU渲染模式；2）GPU本身使用了全局共享的performance counter（GPU PC），产生了side channel；3）攻击者在Android系统上可以通过普通权限的app访问系统的`ioctl` system call，读取GPU 设备文件相关信息，推测出GPU PC中的内容。

![](../Images/dea68b0fd1eb5e171700f06b2d4baeb0.png)

作者本文主要关注的是高通的Adreno GPU，里面包含三类GPU PC，而作者注意到键盘点击会对这些GPU PC的值产生特殊的改变（上图），利用预先的训练（下图的offline phase），攻击者完全可以先把每个字符点击的模式学习到手，然后在具体攻击中（下图的online phase）根据匹配的模式来推测用户的输入！

![](../Images/737d56fe2f3488ab1ae8db0e93e5809e.png)

如下图所示，各种不同的字符输入会产生可区分的模式，特别地，在系统存在图像渲染噪声（比如正在输入时系统弹出相关消息通知等事件）的情况下，区分度依然还是令人满意的。

![](../Images/eadfa0214546e1d41c5463ce34dc3fb9.png)

![](../Images/cbb4205d6a5dc5b634f1178315f75d25.png)

作者在论文中还很贴心地给出了如何攻击的保姆教程，包括介绍了GPU设备文件的具体信息、给出如何利用`ioctl`去读取信息的代码等

![](../Images/fb2919d872451352d575960e8f43d692.png)

![](../Images/c63dfedb2c6a07895d6ca61f53ecb958.png)

实验评估不再赘述，最后作者还讨论了如何防御此类攻击，首先最简单的方法是关掉输入法输入的时候的字符动态上浮提示，但是这个还不能完全根除相关隐患，对于Android系统而言，同时也应该为GPU设备文件的访问加上更为严格的访问控制，防止一些恶意应用随意读取数据并开展隐蔽的侧信道攻击。

有兴趣的读者可以访问 https://doi.org/10.5281/zenodo.5733423 获取相关材料，并可在Google Pixel 5 GD1YQ unlocked手机上复现相关攻击
