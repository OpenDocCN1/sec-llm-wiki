# G.O.S.S.I.P 学术论文推荐 2022-02-23 GNN Model Stealing

大家好，今天给大家推荐的是一篇来自Norton Research Group，CISPA Helmholtz Center for Information Security和INRIA联合投稿的关于图神经网络的模型窃取攻击的文章--"**Model Stealing Attacks Against Inductive Graph Neural Networks**"，目前该工作已被IEEE S&P 2022录用。

![](../Images/09afd11a2147bc4c88b000e60059beeb.png)

图结构数据在日常生活当中被广泛应用。比如社交网络，分子式，知识图谱等等。收集图结构数据并且训练模型往往需要耗费大量的人力物力。

近年来，为了更好地处理图结构数据，研究人员提出了一种新型的神经网络--图神经网络 Graph Neural Networks（GNNs）。GNN在很多图相关任务上取得了优异的表现并且被广泛应用于各个领域,如社交网络，推荐系统，生物医疗等等。然而，使用GNN模型所造成的安全隐私风险还有待研究。

  

![](../Images/4d58dbfb6539b88e040cbb7dadb798b8.png)

在本文中，作者主要关注节点分类任务 （node classification task），并提出了第一个针对Inductive GNN的模型窃取攻击（model stealing attack）。

  

具体说来，给定一个black-box 的图神经网络模型（target model）， 攻击者会利用一个查询图（query graph）作为输入来 query target model, 并获得其对应的responses。随后，攻击者会利用query graph以及对应的responses来构建一个surrogate model，其目的是复制target model的功能性（functionailty），换而言之，一个好的surrogate model会很好地模仿target model的行为，并且在目标任务上有着相似的表现。

  

对于查询图，作者考虑了两种情况，即查询图包含图的拓扑结构 （Type I attack） 或者查询图缺失图的拓扑结构 (Type II attack)。对于第二种情况，作者会首先对图的拓扑结构进行学习，再使用其query target model。

  

对于target model可能的responses，作者考虑了三种类型：节点分类预测的概率分布（posterior probability），节点的表示向量（embedding），以及节点的t-SNE降维坐标（t-SNE projection）。

  

![](../Images/8cb7c8ee9803c04213ab9ffd887140af.png)

针对不同的组合， 作者将不同的攻击进行了分类。如上图所示。从上往下攻击的难度依次提升。

  

![](../Images/84df52dc112946bdfa61655751f13973.png)

  

作者在不同数据集和不同模型上针对不同的responses进行了攻击（Type I attack），实验结果表明，攻击者构建的surrogate model能够达到近似target model的表现（如上图所示）。

  

![](../Images/5ac2b8f5a269ab5eaafa5101230820d5.png)

同时，作者发现，surrogate model学习到的embedding和target model十分相近，并且都能较好地区分不同类别的节点。

  

![](../Images/be19e973a41a48f61aa50b97a2ee10cb.png)

  

对于需要重建图结构的Type II attack，作者也对其进行了评估。结果表明，Type-II attack所构建的surrogate model同样拥有不俗的表现。

  

![](../Images/667222bdef08a5a0ea053e3f301aedce.png)

作者对不同的图结构重构方法进行了对比，并且发现采用IDGL进行图结构重构的表现优于kNN和Random方法。

  

![](../Images/5f106a6cba6b76ddfd4062b876244703.png)

为了进一步表明攻击的有效性，作者尝试利用更少的节点组成query graph进行攻击，如上图所示，实验结果表明，即使只利用3%的节点构建query graph（原始的query graph利用了30%的节点），本文提出的攻击依然有着很好的表现。

  

![](../Images/3b44358c888871ac95d5357ae25e6f2d.png)

最后，作者尝试了对response加噪声作为防御方式，并且发现该防御不能很好地抵抗针对GNN的model stealing attacks，这也说明未来需要更好的防御手段来抵抗此类攻击。
