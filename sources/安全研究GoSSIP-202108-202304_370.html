当当当！寒假状态解除！学术论文推荐又回到了正常的状态啦~今天我们为大家介绍一篇来自NDSS 2022的论文，这篇论文关注了在Linux Kernel中存在的一类特殊gadget——transient execution gadget，看到这个名字大家都应该很清楚，这篇论文探讨的还是CPU瞬态执行漏洞（meltdown、spectre等）相关的安全问题，接下来让我们深入阅读

来自著名的VUSec研究团队的研究人员和ETH Zurich的合作者一起，设计开发了名为KASPER的分析工具，去深入搜索内核中的transient execution gadget。大家可能要问，相关的问题2018年开始就已经有人深入研究了，这北京冬奥会都已经开幕了，KASPER有什么新特点吗？善解人意的作者首先专门做了一个“你问我答”页面，上面回答了很多疑问，这个形式非常值得我们学习：https://www.vusec.net/projects/kasper/

作者对前人的工作进行了细致的分析后，很有底气地提出自己的分析建模方法，具体地，
(1) 使用 speculative emulation 对 transient execution 进行建模；
(2) 开发了一系列 vulnerability detector 来建模不同的软硬件漏洞；
(3) 利用动态污点分析技术追踪所关注的软硬件漏洞在体系结构层面和微架构层面的不同影响；
(4) 使用 fuzzing 来对攻击者的可能覆盖能力进行建模

针对每个步骤和组件的具体技术实现在论文中有详细描述，这里不再展开。我们接下来关注一下实现细节。KASPER在LLVM工具链的基础上加入了三个组件：Kernel Speculative Emulation Unit (KSPECEM)，Kernel DataFlow Sanitizer (KDFSAN) 和 Taint Manager (TMANAGER), 同时还改造了syzkaller来进行kernel fuzzing
