# G.O.S.S.I.P 学术论文推荐 2022-01-07 SAILFISH

今天给大家推荐一篇来自S&P 2022会议上的论文——SAILFISH: Vetting Smart Contract State-Inconsistency Bugs in Seconds。这篇文章提出了检测以太坊智能合约一致性漏洞的工具——SAILFISH，并通过实验证明该工具在效率和准确度上比SECURIFY, MYTHRIL, OYENTE, SEREUM 和 VANDAL5个工具更突出。SAILFISH工具也在对89853个真实以太坊智能合约的分析中，发现了47个0-day漏洞。

  

![](../Images/c6d4e4845f11ec57618cb55921cb4ee0.png)

  

SAILFISH工具的执行流程如下所示，将一个智能合约输入后，该工具将根据合约建立一个存储依赖图(Storage Dependency Graph, SGD)，近似出存储读写操作。然后利用轻量级静态分析工具——SLITHER，根据给定的Query查询信息初步判断合约是否存在漏洞，若存在则产生一个反例状态子图。然后使用Refiner修改器做进一步判断。

  

在Refiner修改器的实现上，论文的作者利用ROSETTE符号执行工具进行符号分析，判断反例状态子图的可行性，并提出了value summary analysis分析框架，减少了误报的出现。

在与其他5个工具的比较中，SAILFISH以全能的结果遥遥领先于其余工具。

  

![](../Images/9de329ef9596e4a59c663213c345c960.png)

  

最后，论文的作者选取了89853个智能合约作为数据集（从共91921份的原始合约中去掉Solidity版本小于0.3.x的部分）进行实验评估，以能否识别出重入攻击和交易顺序依赖(TOD)攻击为指标，对各个工具的准确度进行分析（包括识别漏洞数量和误报漏报数量比较）。从结果中看出，SAILFISH工具在准确度上有较大的优势。

  

![](../Images/77ed9cda9c3fbabeca8a558e3820ab4b.png)

![](../Images/793e84f24d5515163e41f68a142b09b9.png)

  

论文的作者进一步按照数据集合约的行数多少分为4个数据集，对工具在4个数据集中的分析效率进行比较。结果表明，SAILFISH在Small数据集中领先于所有其他工具，在Medium和Large中仅稍慢于VANDAL工具，在综合效率上与VANDAL几乎持平的同时远超其他工具。其中Small表示代码行数范围为\[0行, 500行)的合约, Medium为\[500行, 1000行)的合约, Large为\[1000行, ∞)的合约, Full表示所有的合约。
