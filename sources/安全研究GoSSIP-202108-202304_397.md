# G.O.S.S.I.P 学术论文推荐 2021-12-29 The Many-faced God

2021年的倒数第三天给大家带来的是复旦大学周喆研究组，与[加利福尼亚大学尔湾分校李洲研究组](http://mp.weixin.qq.com/s?__biz=MzA5MzQ1MDI2MA==&mid=2456040870&idx=1&sn=d95659831b914eb344d0c265a45a698a&chksm=87cd2cddb0baa5cb650fc66139ccc63355035cc852172a75b4a6cd9c3d8b290648150574f9bf&scene=21#wechat_redirect)，共同投稿的发表在ASCAS2021的工作***The Many-faced God: Attacking Face Verification System with Embedding and Image Recovery***。

  

![](../Images/a8a82440f6eef685c0892893386f7f3e.png)

  

现如今，人脸识别作为AI领域落地最好的算法之一，在我们的生活中已经随处可见。尤其在安防领域，已经非常成熟，很多重要的安全审查关口（图1），都有此类算法的身影。但是，关于人脸识别算法的隐私问题，一直较为严重，很多研究工作针对这一问题展开（例如：Model Inversion Attacks, Membership Inference Attacks等）。

  

![](../Images/f1f4a10b988b9a5e7efb6ad2b196692a.png)

图1，中国出入境管理局

  

此类人脸识别算法，大都会用到“Embedding”的技术思想，例如FaceNet—将人脸图像映射到欧几里得空间，即一个128维（维度大小可调）的向量，并储存在数据库中。如图1，用户使用机器进行人脸判别时，算法会将当前用户照片映射为同一大小的“Embedding”向量。然后，基于欧几里得距离（或Cosine距离），与数据库储存“Embedding”进行相似度验证。

  

如今，人脸识别在现实应用中，已具备了极高的准确率。但本文作者发现，“Embedding”的存在，将会严重泄漏用户的肖像隐私。在本文工作中，作者利用Generative Adversarial Network技术，搭建er-GAN，将储存在机器中的“Embedding”，高还原度恢复为其对应的人脸图片。

  

![](../Images/87a9f01e2f24ecea58b49f739adad83b.png)

图2，人脸还原效果

  

图2选自测试集中连续的，五个不同人脸数据。第一行为victim原始图片（现实中，出于隐私保护，不会直接储存在数据库），第二行为作者利用er-GAN，针对其”Embedding“向量，所还原得到的**视觉结果**。由此可见，即使victim没有将的面部信息，储存在任何地方，仍然可能会被泄漏。

  

![](../Images/14a24e3dca11168e8fb3c444f5079f22.png)

图3，攻击流程

  

除了人脸信息的泄漏，更严重的是人脸检测系统，几乎会被本文攻击**完全绕过**。如图3所示，作者将还原的人脸图片，输入到检测系统，会有超过95%的准确率，被判别为victim本人。这将对安防工作，带来极大的安全隐患。

  

在现实攻击场景中，作者利用已知信息可以推测并获取“Embedding”。例如图1应用中，若输入victim对应号码（如 ID Number），机器将返回当前照片与该号码对应“Embedding”的距离。以128维向量为例，如果用不同照片，访问系统128次，即可精确求解出victim面部照片，所对应的“Embedding”。同时，在SVD（Singular Value Decomposition）的帮助下。33次访问（即33个方程组），所解得的近似“Embedding”，足以让本文er-GAN还原出的图像，绕过人脸检测系统，极大的提升了**攻击的可行性**。
