# G.O.S.S.I.P 学术论文推荐 2021-12-21 Westworld

今天给大家推荐的是来自ACSAC 2021的一篇论文 —— "Westworld: Fuzzing-Assisted Remote Dynamic Symbolic Execution of Smart Apps on IoT Cloud Platforms"。作者针对云平台上物联网应用的安全性，提出了一个系统Westworld，该系统能够实现对在云平台（SmartThings）上运行的物联网应用进行远程符号执行。

![](../Images/a689e6be20e84ed3375821564a9af8b3.png)

目前，在SmartThings等物联网云平台上，对应用的审查和测试是一个耗时耗力的过程（如图1和图2所示），开发人员需要手动填写配置和输入来提交测试请求，请求触发事件执行后，开发人员需要读取日志来寻找bug。尽管目前已经有了很多基于符号执行的方法来对应用进行自动测试，但由于平台API的闭源性（如图3所示，sysAPI代码不可用），要将现有技术应用到物联网云平台上仍存在着挑战，很难实现精确性和完整性。

![](../Images/2141ee47cafaa24143bfe00dc4144c23.png)

![](../Images/b43826c248db65cfe1ab91e97931e66a.png)

![](../Images/e1257b6ccfd6b803291846b651f88cfb.png)

本文作者提出了一种fuzzing-assisted remote dynamic symbolic execution的方法，能够对部署在云平台上的应用实现远程动态符号执行（DSE），并且利用模糊测试来辅助DSE。Westworld主要架构如图5所示，给定一个smart app，Westworld生成两类插桩app：1）PC-collection app插桩代码来实现通过远程DSE采集符号路径条件（PC）；2）seg-fuzzing app通过选择性代码片段模糊来辅助远程DSE，以实现高效处理平台API。

具体来说，Westworld主要分为三部分：

**(1) Path-Condition Collection: **利用平台提供的代码检测和已有服务（日志和消息传递）来收集路径信息。

*   识别入口方法：smart app没有主函数，而是通过订阅事件来声明入口点，每个订阅包含一个设备名称、设备事件以及事件处理程序（图4第9行）。Westworld通过分析所有的事件订阅来找到事件处理程序作为入口点。
    
*   识别符号输入：包含用户输入和环境变量。
    

*   用户输入：smart app通常需要用户输入（应用配置）来定制应用，该过程通过关键词的输入来实现（图4第2-5行）。
    
*   环境变量：smart app需要与外部交互来检索环境数据，作者识别存储环境数据的变量，并将其设置为符号输入。环境变量分为设备状态、位置、状态以及事件四类。
    

*   用于收集路径信息的插桩：如图6所示，Westworld利用应用AST来查找不同类型的插桩语句，记录变量值、符号变量以及符号路径条件。对于平台API（闭源），将返回值设置为临时符号变量TSV，之后通过选择性代码模糊来处理，确定其余符号输入的关系。
    

![](../Images/fdeba9ecc33b9ffcfda723b4b48c08a2.png)

![](../Images/c473a547d3b77d0bfb14e79734d7f8de.png)

**(2) Selective Code-Segment Fuzzing: **Westworld实现了选择性代码片段模糊来辅助远程DSE处理平台API调用。

如图7(a)所示，x是环境变量，sysAPI是平台API，O为TSV且依赖于x（influential symbolic inputs, ISI），由此Westworld通过确定代码段并创建seg-fuzzing app，即在代码段周围插入for循环来实现迭代，以学习ISI与TSV的关系，来实现对路径约束的求解。

![](../Images/01119ca800a2e0e98717a91849f3107d.png)

**(3) Remote Path Exploration: **路径分析用于根据符号路径条件来识别TSV，并且结合符号路径条件和代码片段模糊来生成新的测试用例以实现路径探索。本文作者提出了两种路径探索方法：original generational search和boosted generational search。

![](../Images/03c58172fa3d1f2f4744ae2cb62569f1.png)

作者针对SmartThings实现了Westworld系统，并从可行性、完整性、准确性、效率以及bug发现的有效性对其进行了评估，结果表明Westworld在路径探索和bug发现是有效的。
