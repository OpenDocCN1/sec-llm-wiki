# G.O.S.S.I.P 学术论文推荐 2021-12-20 argXtract

作为每年最后一个召开的知名安全会议，ACSAC上也有很多有意思的研究论文。今天我们为大家推荐的是来自ACSAC 2021上一篇基于ARM逆向技术的深入探索、对IoT设备中存在的错误配置进行自动化静态分析的研究论文

![](../Images/b6e25f73579bac5e756a25ed0debf92c.png)

作者针对ARM平台上stripped binaries中的分析难题开展了针对性研究，以期解决后续自动化分析和发现错误配置的问题。必须指出，作者研究的问题并不算非常新颖，在x86时代，对stripped binary code的代表性研究论文包括2005年的Practical Analysis of Stripped Binary Code和2011年的Binary code is not easy，而本文大部分的篇幅也是类似此前的研究工作，在讨论分析ARM平台上stripped binary code可能遇到的问题：

![](../Images/2340b4bcdc126dc64b3ed7608ced85e3.png)

针对Cortex-M指令集的二进制代码（固件），作者设计了名为`argXtract`的自动化分析工具，该工具实现了“更好”的Cortex-M指令集二进制代码分析能力，并基于此，专门针对安全相关的关键函数调用（security-relevant Calls Of Interest）提取调用参数，分析其中和设备配置相关的内容，最后找到可能引起安全问题的那些不正确配置

其实对于大部分同类工作，针对二进制代码的分析无非也就是如何更为准确地定位函数边界，以及如何区分数据/代码等经典问题：

![](../Images/1ecff217b97264c429a0578d1b9f0f16.png)

至于最后如何识别关键的函数调用以及如何提取参数，作者写得很简单，基本上一笔带过。文章比较有意思的是实验部分的case studies，作者针对三类不同的IoT设备开展了分析：

![](../Images/6b00c61885a749bbfb94c2c545bd3eb1.png)

![](../Images/aac9f33ce4e159b61b65d44e7d26a4e6.png)
