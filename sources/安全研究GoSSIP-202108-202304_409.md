今天给大家推荐的是来自CCS 2021的一篇摄像头安全的论文——"The Invisible Shadow: How Security Cameras Leak Private Activities"。

![](../Images/8ec14c254449b3961fa6d32b791c5b4d.png)

目前大多数的智能安防摄像头都具备夜视模式，该模式利用红外IR来捕获有遮挡物或昏暗场景下的物体。如图1所示，红外光能够穿过薄的不透明的材料，当用户停留在摄像头和窗户之间，红外光可以将用户的阴影投射在窗帘上。尽管用肉眼看不到这些阴影，但在某些情况下可以被攻击者捕获，本文所针对的就是这一类红外阴影攻击（IRSA）。

![](../Images/be3d94b559d3447d2bda70e3e750bfd3.png)

目前IRSA的实施存在两个挑战：1）红外阴影会受到环境因素的干扰，难以识别阴影轮廓；2）阴影变形使攻击者很难推断受害者的活动。

![](../Images/7c584d9373a929a2f56077dc6cc47cc8.png)

因此，作者提出了一个方案能够有效的实施IRSA，主要包含两个步骤：  

（1）捕获红外视频，并将其作为DeShaNet的输入来提取阴影关键点：DeShaNet包含了一个阴影关键点的检测模型，使得即使在阴影变形的情况下，也能够恢复2D阴影关键点。  

*   A-LSTM and scene feature fusion module：用于提取场景参数（环境因素）特征，从而适应场景变化。
    
*   Trajectory aware module：引入向量坐标，利用运动的连续性来推断阴影关键点，提高阴影变形情况下检测的稳定性。
    
*   Condition attention module：用于提高动态情况下的检测鲁棒性。  
    

![](../Images/8ce1fcdd70f31a45f74a0a582c7fb4d4.png)

（2）利用场景构造器（scene constructor）将2D阴影关键点映射到3D骨架，3D骨架可以用来提取用户信息，例如活动和身份。

*   Scene parameter estimators：在虚拟的3D环境中建模
    

*   IR Source Parameter Estimator (IRSPE)：通过阴影失真来判断红外距离和角度
    
*   Limb length estimator (LLE)：肢体长度估计
    
*   Curtain deformation estimator (CDE)：减少因为窗帘变形造成的阴影变形所导致的检测误差  
    

*   Shadow simulator：模拟阴影，用于推导3D虚拟骨骼。  
    

![](../Images/3c97786113bdc9893ab466ee1c868fa9.png)

作者在一个真实的室内场景收集了40组IRSA数据来训练系统，并对系统中的组件分别进行了评估。

![](../Images/31d3290f47f68205de4587680667f576.png)

这篇文章提出了一个比较有趣的攻击，利用红外光的一些特性来实现对用户的活动进行“透视”。文章中还涉及了关于攻击方案的技术细节和评估实验，感兴趣的小伙伴可以查阅原文。
