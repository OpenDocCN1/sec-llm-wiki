# G.O.S.S.I.P 学术论文推荐 2021-11-23

今天给大家推荐的是来自USENIX Security 2022的一篇论文——"Lumos: Identifying and Localizing Diverse Hidden IoT Devices in an Unfamiliar Environment"，作者设计了一个系统——Lumos，用于帮助用户识别和定位到一个陌生环境中隐藏的物联网设备。

![](../Images/ea78f05eaf77271f62b42e7064753abb.png)

在一个陌生的环境中（如Airbnb或酒店房间里），攻击者可能会放置一些隐藏的物联网设备来监视用户，这里作者主要关注WiFi连接的设备，这些设备可能会传递与用户隐私相关的数据给攻击者。本文的主要工作是设计实现了Lumos系统，该系统运行在用户设备（手机、电脑）上，嗅探加密的无线（802.11）数据包并对这些数据包进行检查和指纹识别，最终定位到隐藏的设备。

![](../Images/036f11320c467d0445c1996696fd7c1b.png)

![](../Images/5c47191ca0279f88bf1a16adefa4da3b.png)

Lumos主要分为以下三个模块：  

（1）Device Fingerprinting Module

该模块通过特征集和数据包属性来提取每类设备的有效特征。

*   从802.11无线数据包中自动提取相关设备特征属性。Lumos首先收集所有可能的802.11数据包，然后提取所有属性，最后去除不同设备上具有相同值且不携带任何有用信息的属性。经过该过程，作者从125个属性中筛选出52个属性。
    
*   使用one-vs-rest分类器训练模型。  
    

（2）Data Collection Module

Lumos通过捕获到足够多的数据包来识别设备类型。实际中，物联网设备可能连接在不同网络中，分布在2.4GHz与5GHz之间的30个信道上。作者提出了一种device-aware channel sensing方法，通过学习每个设备的流量模式来确定何时以及多长时间来监测每个无线信道。  

![](../Images/b84892b47bfc86835f99bd7e430aa2b9.png)

（3）Localization Module

为了定位识别出的物联网设备，Lumos将数据包的信号强度与手机中的VIO (Visual Inertial Odometry) 技术结合在一起，在用户移动过程中，利用稀疏测量方法（sparse RSSI sampling）来定位到设备。

作者在两类移动设备上实现了Lumos应用，并使用9类物联网设备进行测试识别，测试设备被部署在4个不同的环境中。测试结果如下：

*   对于每个环境，Lumos运行30分钟（27分钟无线嗅探和3分钟的移动），最终Lumos的设备识别准确率为95%-98%（如表3），定位精度中值约为1.5m，能够有效的识别以及定位到设备。
    

![](../Images/846320df0b737cc6fe897173645fe1fe.png)

![](../Images/bf4e0077c6e5ce1754686eed7e102110.png)

![](../Images/570d021381c9388bd6a250a948c1b361.png)

*   对于设备识别，Lumos在检测摄像头达到了非常高的精度，但在检测智能灯泡上精度较低，作者认为这可能是由于摄像头具有较高的数据传输速率，且传输的数据格式唯一（图像或视频），因此容易构造指纹来进行识别。
    

![](../Images/b838f9abe30f10c308b62288a83dc2dd.png)

*   对于信道扫描，作者将Lumos算法与random, round robin以及SpecInsight算法进行比较，结果表明Lumos能够在15分钟内发现92%的设备，在40分钟内发现100%的设备，大大优于其他算法。
    

![](../Images/f445bac22c43ff1e57d60b333322b1af.png)

*   对于设备定位，作者评估了用户移动速度、设备位置以及移动时间对于设备定位精度的影响。结果表明，用户移动速度较快时，接收到的数据包在空间上更稀疏，但是由于设备数据传输速率高于步行速度，因此移动速度对于设备定位精度没有较大影响；设备在房间的位置会影响定位精度，作者认为这是由于用户移动时与设备的距离有关；移动时间越长，能够提供更多的样本，对于数据传输速率低的设备（智能灯泡）的影响越显著。
