在这个愉快的周一为大家推荐的是一篇来自德国亥姆霍兹信息安全中心（CISPA Helmholtz Center for Information Security) 张阳研究组投稿的，和弗吉尼亚大学王天豪研究组合作的，关于 Machine Unlearning 系统中隐私泄漏的文章When Machine Unlearning Jeopardizes Privacy，目前该工作已被CCS 2021录用。

随着人们对个人隐私的日渐重视，许多国家和地区出台了众多消费者数据隐私保护法规，来保障消费者对于个人数据在商业活动中使用的各项权利，如知情权，被遗忘权，数据可携带权，隐私保护保证等等。例如，欧盟在 2018 年出台了 GDPR (General Data Protection Regulation)，美国加利福尼亚州颁布了 CCPA (California Consumer Privacy Act)，以及加拿大颁布的 PIPEDA (Personal Information Protection and Electronic Documents Act) 等。在众多权利中，被遗忘权备受关注。一方面，消费者有权力要求撤回商业活动中被用到的个人数据以保护个人隐私；另一方面，企业需要耗费大量的精力财力来保障该权利的高效执行以避免不必要的诉讼纠纷。

当前的商业活动中机器学习模型被广泛应用，而高质量的机器学习模型往往都离不开大量数据的支撑。因此近两年来有越来越多的学者研究在机器学习模型中如何保证用户的被遗忘权，该技术被称作 Machine Unlearning （有些学者把它翻译成中文“机器遗忘" 😊 )。被遗忘权一方面要求所有被撤回的数据不能出现在机器学习模型的训练数据集中；另一方面，机器学习模型自身也应该保证删除原来数据的各种遗留影响。在众多方法中，最合规的方法就是直接删除模型训练数据集中所有要求被撤回的数据，将模型从头训练一遍。

虽然各种 machine unlearning 技术的设计初衷是保护用户的隐私，但是它们真的能像期望中那样真正保护用户隐私吗？本文作者对此给出了否定的答案。作者通过设计针对 machine unlearning 系统的成员推断攻击，发现这种试图为用户提供隐私保护的方法反而增加了成员推断攻击的风险，导致了用户更多的隐私泄露，进而呼吁研究者们在今后设计 machine unlearning系统时需要更多关注这种额外的隐私泄露风险。

攻击方法

当数据拥有者要求撤回数据后，数据使用者（或模型提供者）依法删除了数据并合规训练了新的模型（unlearned model）。然而，攻击者可以在本地保存目标样本 (target sample) 在多个版本模型中的预测值，并通过比较任意两个模型预测值的微小差异，来推测该目标样本是否曾经在原模型 (original model) 中出现过。另一种判断目标样本是否出现在原模型的方法是直接针对原模型发动传统的成员推断攻击，作者通过大量的实验验证和真实场景模拟发现，利用两个模型预测值的差异能取得比直接发动传统成员推断攻击好得多的攻击效果。这直接说明了删除目标样本将更容易泄露目标样本隐私，也验证了machine unlearning 在某种程度上来说起到了隐私保护的反作用。值得注意的是，即使模型具有较小的过拟合程度，传统的成员推断攻击无法正常工作时，本文提出的攻击方法仍然可以取得较好的攻击效果。具体来说，攻击者需要在本地训练一些影子模型，并通过多种方法融合两个模型的预测值来构建攻击特征，最后用融合的攻击特征和影子模型标签训练攻击模型。

攻击效果评估

为了系统地评估 machine unlearning 引入的额外隐私泄露，作者使用三种指标评估了隐私泄漏程度。作者在 五个数据集和七种目标模型上分别评估了额外隐私泄露程度。实验结果表明，在不同的数据集和目标模型上，本文提出攻击都取得了比传统成员推断攻击更好的攻击效果。

为了进一步探究不同攻击特征融合方法的有效性，作者评估了针对两个具有代表性的数据集和目标模型的过拟合程度以及对应的攻击效果。实验结果表明，复杂的Resnet50模型具有相对较大的过拟合程度，排序级联（sorted concatenate）的特征提取方法更能够全面反应两个模型的差异，该方法在四种攻击模型结构上均取得了较好的攻击效果。简单的模型如逻辑回归（LR）等具有较小的过拟合程度，计算两个后验概率向量的欧式距离更能反映出数据点删除引起的模型变化，因此具有较好的攻击效果。

为了放松对攻击者本地数据的假设，作者评估了本地影子模型结构和本地数据分布与目标模型不同时的攻击性能。实验表明，即使攻击者没有同分布的数据或者不了解目标模型的结构，针对 machine unlaerning 的成员推断攻击依然有效。

此外，作者也评估了针对最近提出的基于分块训练再整合最终输出的machine unlearning方法–SISA (Shard Isolation Slice Aggregate)的攻击效果。可以观测到，虽然基于 SISA 模型的攻击效果不如基于retrain-from-scratch模型好，但额外的隐私泄露依然存在。

在实际应用生活中，machine unlearning 系统可能存在于多种场景中。为此，作者系统地研究了不用场景下的攻击效果：

  1. 攻击者无法精确得知在获得的两个版本模型中间隔了多少次重新训练。

  2. 在进行 machine unlearning 时，目标模型并不是收到一个删点请求就被重新训练一次，而是等待一批删点请求到来后一次删除并被重新训练。

  3. 在重新训练目标模型时，不但有数据样本删除同时也有新的数据样本加入目标模型的训练数据集中，即在线学习（online learning）场景中的机器遗忘（machine unlearning）。

结果表明，随着模型变动增大，原来单个数据样本对模型的影响越来越小，会造成攻击效果越来越差。但如果两个模型中间间隔少于10次重新训练，每批删除点额数据样本少于原始数据的千分之五，或者删点的同时新增的点数不超过千分之五，攻击效果依然较为明显。

与此同时，作者发现了一个有趣的现象，即删掉原始模型的部分训练数据，会使得同时存在于原始模型和遗忘模型的数据样本的隐私泄露程度少量增加。

防御方法

最后，作者提出了四种针对本文攻击的防御方式：

  1. 模型只返回后验概率向量 (posterior) 数值最高的 k 位。实验结果表明该方法并不能很好的抵御本文攻击；

  2. 模型只返回预测标签。实验结果表明该方法虽然可以有效抵御攻击，但实际应用场景受限;

  3. 使用差分隐私（Differential Privacy）在每次目标模型训练期间对梯度进行加噪。实验结果显示该方法可有效抵御本文提出的攻击。需要注意的是该方法要求系统设计者细心调节隐私预算来权衡模型精度和隐私保护程度；

  4. 使用 Temperature Scaling 方法训练 target model，该方法可通过调节模型的信心程度而实现降低攻击效果，但要求target model 需要有可调节temperature的层结构，如softMax层。
