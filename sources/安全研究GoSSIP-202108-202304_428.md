# G.O.S.S.I.P 学术论文推荐 2021-11-19

今天给大家推荐一篇CCS 2021安全会议上与IoT fuzz相关的工作——Snipuzz: Black-box Fuzzing of IoT Firmware via Message Snippet Inference。

  
论文作者考虑到IoT设备难以获取固件，并且其数据传输通常没有统一标准格式，使得相关的fuzz工具不能得到IoT设备的内部执行信息，并且基于语法的fuzz策略也无法使用。因此论文作者提出了一个基于语义信息片段推断的黑盒fuzz工具——Snipuzz，在很大程度上提高了IoT fuzz工具的时间和空间效率。Snipuzz不需要任何诸如逆向分析的前期准备，其在20个真实IoT设备中发现了5个0day漏洞，其中3个是目前其他工具所不能找到的。

  

![](../Images/813128c2929c884d2a4d14740c1b8e67.png)

  

Snipuzz工具引入了基于信息片段推断的变异(Mutation)策略，这也让该工具在与IoT设备fuzz相关的工作中脱颖而出。其基本工作流程如下所示：

  

![](../Images/b1542f9a84075c37dcdf5426f73fe1ed.png)

  

IoT设备可以看成是一个对输入数据格式有严格要求的程序，因此基于字节的变异策略所构造的输入可能大部分是无效的；基于语法的变异策略没有相应的IoT设备文档用作参考(或者各个IoT设备的文档规定形式过于多样)也同样不可行。

  

基于语义片段推断的变异策略就能够很好的解决这些问题，正所谓最好的语法使用指导就来自于IoT设备本身。

  

Snipuzz工具使用了分层架构算法来进行语义片段的识别。其针对一个输入信息，通过修改此信息的某些字节来得到新的输出，然后利用算法逐步进行分类、合并等操作，最终得出输入信息中的语义片段划分。有了这样的片段划分之后，输入序列的推测空间将被大大降低，fuzz工具的效率进而就提高。

  

![](../Images/733c0677a85145adcc1f192c0a101fbd.png)

  

然后论文的作者从漏洞识别和执行效率两个方面对工具进行了评估。

  

在漏洞识别上，在对20个IoT设备经过24小时的检测后，Snipuzz工具成功找到了5个IoT设备中共13个程序崩溃点，其效果远好于目前前沿的相关工具（除了IoTFUZZER工具，其他的一个崩溃点都没有找到）。

  

![](../Images/e87e263c59909c9495002e3cb23df9cf.png)

  

在执行效率上，论文的作者将Snipuzz工具与其他7个工具进行对比，测试10分钟内发现分类数量的个数。在全部的20个设备的运行结果中，Snipuzz在19个设备中都表现最佳。
