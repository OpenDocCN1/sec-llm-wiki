今天为大家推荐的论文是来自山东大学任昭春研究组与CISPA张阳研究组共同投稿的，目前已经发表在CCS 2021上的工作Membership Inference Attacks Against Recommender Systems。

现如今推荐系统作为如今最热门的网络应用之一，其被应用于各种各样的场景，例如在线购物，视频分享等。推荐系统的成功极大程度地依赖于大规模的用户数据。在很多情况下，这些数据包含了个体的敏感信息，例如购物习惯、社交关系和位置信息等。新近，许多研究表明，以机器学习分类器为代表的机器学习模型很容易受到成员推断攻击，从而导致隐私泄露。然而，推荐系统中用户的隐私遭受如何威胁尚未被完全研究。

在作者的研究中，开展了第一个从成员推断角度探究推荐系统中隐私风险的工作。与先前针对机器学习分类器的成员推断攻击相比，该工作主要面临两个不同：首先，我们的攻击目标是判断一个用户的数据是否被应用于某个目标模型。这表明了我们的攻击是在用户层面，而先前的攻击是针对数据样本层面。从更高一层出发的成员推断有一个更广阔的视角，进而可以带来对推荐系统中隐私风险的深入理解。其次，从攻击者角度来看，只有目标推荐模型中商品的排行榜是可用的，而非后验概率。

图1展现了一个推荐系统。即使推荐系统在决策前已经计算出了后验概率，用户（包括攻击者）也只能观察到推荐的物品列表。这个设定在现实世界中是很普遍的，例如在Amazon和Netflix提供的服务中。因为，暴露越少信息，越能保护推荐服务提供商的知识产权。相反，在先前针对机器学习分类器的成员推荐攻击中，用来进行决策的后验概率能够被攻击者获得。

在该研究中，攻击者的目标是对推荐系统进行成员推断攻击，推断目标用户的数据是否用来训练该目标推荐系统。成功的攻击可以带来严重的安全和隐私问题。具体来说，当一个推荐系统是训练在人们某些敏感信息数据上时（例如健康状况），知道用户的数据被用于推荐系统的训练就会直接泄露用户的隐私信息。此外，成员推断可以让攻击者获得目标推荐系统的训练数据。由于收集高质量的数据通常会付出巨大的成本，推荐系统的知识产权会因此遭到侵害。从另一个角度来看，用户同样可以使用成员推断作为审计工具来判断自己的隐私信息是否遭受侵害。

为了在仅知道用户相关物品的情况下（对后验概率一无所知），在推荐系统上进行用户层面的成员推断攻击，作者提出了一个新的攻击流程。首先，作者将物品投影到特征空间来获得物品的特征向量。然后，用户是被其历史行为与被推断的喜好之间的相近程度所表示。（在本文中，用“interactions”表示用户交互过的物品，用“recommendations”表示用户被推荐的物品。）最后使用用户的特征向量进行成员推断。如图2所示，整个方法分为三个部分：Labeled Data Generation，Attack Model Establishment，和 Parameter Optimization。

  • Labeled Data Generation：为了表示物品特征，通过分解一个user-item矩阵，可以获得一个物品矩阵。对攻击者来说，由于只有目标推荐系统的黑盒权限，一个影子模型被建立来生成有标签的数据以训练攻击模型。接着，用户的interactions和recommendations被相应的特征所表示。之后，计算每个用户的interactions和recommendations的中心向量，并用两个中心向量的距离表示相应的用户。最后，每个用户会被打上一个1或者0的标签，表明其成员状态。

  • Attack Model Establishment：作者建立了一个有两个隐藏层的多层感知机作为攻击模型来推断成员状态。每一个隐藏层跟着一个ReLU激活层。softmax函数用在输出层来预测成员状态的后验概率。

  • Parameter Optimization：如图2所示，在生成完有标签的数据以及建立完攻击模型后，攻击者对攻击模型的参数进行优化。在推断阶段，目标用户的特征按照有标签数据生成的相同步骤产生。随后，训练好的攻击模型推断目标用户的成员状态。


接下来，作者通过不同假设情境下的实验，验证了攻击的有效性：

  • 首先，作者假设攻击者知道目标推荐系统的推荐算法和训练数据的分布。在这种情况下，攻击的效果是非常好的，这主要源于两个方面：

  1. 由于推荐系统对成员和非成员使用不同的推荐方法，成员和非成员分别紧密地聚合在一起，这就导致了类间距离大于类内距离。

  2. 由于攻击者可以获得关于目标推荐系统的最多知识，其可以建立一个影子模型非常理想地模拟目标推荐系统的行为。

  • 接着，作者假设攻击者只能获得目标推荐系统的训练数据的分布。攻击如预料般有所下降，但性能仍然理想。并且作者发现，针对ml-1m数据集的攻击所表现的性能高于针对其他数据集的攻击。通过分析得知，这个结果是由ml-1m数据集生成的user-item矩阵是最稠密的导致的。简言之，攻击模型可以从更稠密的矩阵中获取更丰富的信息，从而产生了性能的优越性。

  • 最后，作者假设攻击者对目标推荐系统的推荐算法和训练数据的分布都不知情。即使如此，在很多情况下，攻击仍能产生不错的攻击表现。有趣的是，作者发现在少数情况下，攻击者知道更少关于目标推荐系统的信息，反而可以产生更好的攻击表现。

    • 在攻击性能的评测后，为了进一步验证攻击模型的有效性，作者研究了多个影响攻击模型的因素，并进行了相关的实验分析。不仅如此，作者还从“数据集”、“模型结构”以及“用户特征分布”等更高层面的角度讨论了其对成员推断攻击的影响。

    在文章的最后，作者提出了一种防御机制，名为“Popularity Randomization”。其主要思想是，在保证推荐系统的推荐性能的前提下，增加给用户推荐物品的随机性，以增大其墒，使得用户特征的类间和类内距离的差异更小。
