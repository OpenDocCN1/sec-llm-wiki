双十一你是买买买，还是守护中国男足的（渺茫）出线希望？还是来读论文吧！今天给大家推荐的是来自CCS 2021的一篇关于Android模拟器（Android emulator）安全性分析的文章——Android on PC: On the Security of End-user Android Emulators

  

![](../Images/56cb96771380e52eb355c419a2bb53dc.png)

  

在这篇文章中，作者们对6款典型的面向终端用户的安卓模拟器展开了研究，设计了5种攻击方案并进行了测试验证。作者将Android模拟器分为了两大类：面向开发者的模拟器（developer-oriented emulator）和面向终端用户的模拟器（end-user emulator）。前者主要用于程序开发和自动化测试的过程中，典型的例子包括Android Studio集成的Google官方模拟器和Genymotion模拟器；后者主要用于增强用户体验，尤其是游戏玩家的体验。本文主要关注后者，因为作者认为这类模拟器中更容易包含用户的敏感信息，例如游戏登录凭据、Google Play凭据、游戏相关的社交网络凭据等。作者针对以下六款典型的end-user emulator进行了研究：

  

![](../Images/18497e2c8a6f21c93003bd4a11d1d58e.png)

  

这六款模拟器的底层虚拟机（underlying Virtual Machine）都是基于VirtualBox实现的。首先，作者对模拟器的架构进行了研究。虽然六款模拟器的开发者都没有公开设计细节，但是作者通过逆向分析和阅读VirtualBox文档等公开文档，分析并总结出了模拟器架构的抽象模型，如下图所示：

![](../Images/8a6446d3a14b635e9456bd3bd345d689.png)

  

其中，PC主机与Android虚拟机之间的host-guest communication channel是造成本文中安全性问题的根源。模拟器没有为这一通信信道提供充分的保护。在本文所研究的六款安卓模拟器中，这种communication channel包括TCP/UDP、Virtual Device、VirtualBox (VB) Configurations 和 Shared Folders。

  

![](../Images/8db42b04b5dbfc723a1f83fa9a0b8bb6.png)

  

结合6款模拟器的UI，作者总结了安卓模拟器的主要功能，并认为其中有6个功能与安全性高度相关：

  

![](../Images/5d15687199557b3cdd82bfe2cc2737e0.png)

  

通过固件对比、VirtualBox配置文件检查、日志检查、网络和资源使用情况监控、静态分析、动态重放和注入测试等方法，作者设计并验证了5种针对安卓模拟器的攻击方案。这些攻击针对模拟器的用户输入、APP安装、导航栏管理、ADB等不同功能，包括：

*   Keylogger：窃取用户键盘输入
    
*   Input Injection：伪造用户键盘输入事件/触屏事件
    
*   Tab Session Hijacking：劫持导航栏对应的打开APP行为
    
*   Installation Hijacking：劫持APP安装过程
    
*   Shell/ADB Abusing：借助守护进程（daemon）获取root权限
