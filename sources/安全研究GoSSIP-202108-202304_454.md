今天给大家推荐的是来自USENIX Security 2022的一篇关于汽车诊断协议（vehicle diagnostics protocols）逆向分析的论文

  

![](../Images/7f29a645de98382fe0884be38ff8761c.png)

  

汽车诊断协议是为汽车诊断工具所设计的。汽车诊断工具在被连接到汽车之后，可以借助汽车诊断协议，来读取汽车的传感器值或控制汽车的ECU（Electronic Control Units），从而让汽车维修人员能获取汽车确切的故障信息，并进行相应的诊断测试。在这篇文章中，作者们设计并实现了一个自动逆向分析汽车诊断协议的系统DP-Reverser。利用该系统，作者们对两种非开源汽车诊断协议KWP 2000和UDS进行了逆向分析。

  

文章中，作者将常见的汽车诊断工具分为了三类：（1）**专业手持诊断设备**，可以直接被连接到车辆上；（2）**专业诊断软件**，通常被安装到笔记本电脑上，而笔记本电脑会被连接到车辆上；（3）**远程信息处理APP**，通常被安装到手机上，而手机通过WIFI或蓝牙等无线信道连接到诊断设备上，诊断设备被插入到车辆的相应接口上。三类工具示例图如下所示：

![](../Images/851b86890db634f6effa56226962eaa3.png)

  

所有三类诊断工具和汽车的连接，都使用了汽车诊断协议。目前使用最广泛的汽车诊断协议有三个：OBD-II、KWP 2000和UDS。其中，OBD-II协议的设计文档已被公开，因此作者未对其进行分析。作者以KWP 2000协议为例，说明汽车诊断协议的形式：在KWP 2000协议中，诊断工具对汽车可以进行输入输出控制（input output control），也可以进行ESV值（被表示为ECU信号值形式）读取（read data）。这些过程中，诊断工具将向ECU发送请求消息（Request Message），如果请求消息被成功执行，ECU将向诊断工具发送积极响应消息（Positive Response Message）。相关消息的格式如下：

![](../Images/1b9fcefa0c4572814c644f0c5299b848.png)

  

![](../Images/e45edbaefcd6e0c5692babfcaa690ddf.png)

  

假设诊断工具需要获取汽车的发动机转速，可以进行“read data”，向发动机发送Request“21 07”，其中0x21是Service Id，0x07是Local Id。而后，诊断工具会收到发动机的Positive Response，该Positive Response包含的ECU信号值是“01 F1 10”，其中0x01代表公式（formula）类型，对应的公式为X0 \* X1 / 5。由于X0的值为0xF1（即241），X1的值为0x10（即16），因此真正的ESV值为771.2 / min（即241 \* 16 / 5）。

  

以KWP 2000协议为例，作者所要逆向分析的对象包括：

（1）Local Id的值及其含义；

（2）Control Option的值及其含义；

（3）用于获取ESV值的公式。

为了实现上述目标，作者设计了DP-Reverser自动化系统：

![](../Images/51dfbb29c24abf169281b0b1401bd3ba.png)

  

其中：

*   Data Collection模块：主要包括虚线框内的部分。其中，诊断工具被连接到汽车；Robotic Clicker用于点击诊断工具的屏幕；Camera a和Camera b采集分别诊断工具的UI视频和屏幕截图，并将其发送给笔记本电脑；笔记本电脑分析截图，据此生成控制脚本以控制Robotic Clicker。
    
*   Diagnostic Frames Analysis模块：用于采集诊断工具和车辆之间 交互的CAN帧。
    
*   Screenshot Analysis模块：用于接收诊断工具的UI视频并提取UI中显示的文本。
    
*   Request Message Analysis模块：用于分析各字段的含义。
    
*   Response Message Analysis模块：用于分析公式。
    

  

作者针对18辆汽车和4款诊断工具（其中LAUNCH X431和AUTEL 919为专业手持诊断设备，VCDS和Techstream为专业诊断软件）进行了实验：

  

  

![](../Images/4acb6dd33b656155dcf10b5170ec84ff.png)

实验中，作者对18辆汽车中的446个ESV值进行了逆向分析还原。这446个ESV值中，290个ESV中包含公式，156个不含公式。根据已有的对KWP 2000和UDS的分析结果以及实际操作验证的结果，DP-Reverser的整体还原准确率达到了98.3%。相关结果如下表所示：

  

![](../Images/38a5046392b0bed461ee27c07da878d6.png)

特别地，对搜集到的160款远程信息处理APP，作者进行了相关实验，发现其中只有三款包含了针对UDS和KWP 2000协议的ESV公式处理能力，和诊断仪相比，APP的处理能力相对就弱很多（也许是为了防止逆向分析？）
