# G.O.S.S.I.P 学术论文推荐2021-10-12

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5ODUxMzg0Ng==&mid=2247487408&idx=1&sn=09692e3fd30a9303311281bad3c84740&chksm=c0602169f717a87f3ba91d4cc934fa88453bac7294f7537b3ded7575c5722945cf3de36172ce&scene=126&sessionid=1681404253#rd](http://mp.weixin.qq.com/s?__biz=Mzg5ODUxMzg0Ng==&mid=2247487408&idx=1&sn=09692e3fd30a9303311281bad3c84740&chksm=c0602169f717a87f3ba91d4cc934fa88453bac7294f7537b3ded7575c5722945cf3de36172ce&scene=126&sessionid=1681404253#rd)

在2021年的ESORICS安全会议上，有一篇分析iPhone所用的 Apple Remote Invocation (ARI) 接口的研究论文，作者通过逆向分析iOS上的相关代码，还原了ARI接口的相关详细信息并为该通讯协议开发了一个wireshark插件ARIstoteles！

  

![](../Images/de720cbd1298bec9668f17242e5cae1c.png)

在这篇论文中，研究人员关注了iPhone设备的基带（baseband）安全并从ARI接口入手，尝试通过相关通讯协议来实现对基带芯片的操作。作者为了实现相关控制，逆向了iOS中的ARI parsing libraries，之后不仅为协议开发了相关的wireshark解析插件，还针对ARI接口进行了fuzzing测试，发现了诸多crash~

  

![](../Images/4c7612152c836b7c57f32ac4bf1c72aa.png)

  

关于ARI的相关信息，在网络上其实没有特别多的资料，只有本文的通讯作者Jiska Classen（来自Darmstadt 理工大学Secure Mobile Networking Lab即SEEMOO）在Hardwear.io Security Trainings and Conference USA 2021 （相关资料参见https://hardwear.io/usa-2021/presentation/Jiska-USA-2021.pdf）上的相关介绍。本文作者首先在论文中介绍了iOS 12-14中的基带数据包解析流程

  

![](../Images/6b35badea75403c84cddf32845cc97cc.png)

  

然后详细还原了ARI相关协议！
