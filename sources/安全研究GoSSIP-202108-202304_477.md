# G.O.S.S.I.P 学术论文推荐 2021-09-17

之前我们给大家推荐过一系列的蓝牙安全论文，包括蓝牙冒充攻击BIAS、蓝牙降级攻击以及针对蓝牙配对方法混淆攻击（Method Confusion Attack）等。今天我们要为大家推荐一篇发表在NDSS 2021上的针对蓝牙口令输入模式安全性分析的论文——"The Bluetooth CYBORG: Analysis of the Full Human-Machine Passkey Entry AKE Protocol"。  

![](../Images/0c7f4940adacfecab621b3d5cc99ba6e.png)

蓝牙口令输入模式（Passkey Entry）是一种有用户参与的蓝牙设备认证方式，通常情况下，用户通过将一方设备上显示的口令输入到另一台设备中，来辅助完成设备双方的认证，设备双方之后也会根据输入的口令以及其他信息来协商计算共享密钥DHKey以及后续的会话密钥LK。其中根据口令的生成方式可以分为三类：发起设备生成口令（PE-IG）、响应设备生成口令（PE-RG）以及用户生成口令（PE-UG）。

![](../Images/d67f65f63c13ccdb0120457f31599486.png)

由于目前针对蓝牙的研究大多针对Device-to-Device (DtD)信道的安全性展开，本文作者提出了一个更为全面的威胁模型CYBORG来评估蓝牙Authenticated Key Exchange (AKE)协议，尤其关注攻击者对于User-to-Device (UtD)信道的威胁，即Passkey Entry模式（包含UtD信道）。

为此，作者首先提出了四个针对UtD信道的攻击向量，包括从发起设备到用户、从响应设备到用户、从用户到发起设备、从用户到响应设备。以此为基础，将攻击者的能力、不同攻击向量结合，来实现一个较为全面的分析模型。

![](../Images/a227661232c8bbdc9c0eb50cdbfcbb99.png)

之后，作者提出了一系列公式、符号来形式化表示CYBORG模型，包括参与者模型（会话、设备、用户等）、攻击者模型（通信信道、攻击者请求等）以及实验设置。此外，作者还在原有蓝牙Passkey Entry协议的基础上进行改进，重新提出了两种PE协议改进的方式，并将改进后的协议也作为安全评估的对象。其中，两种改进方式包括：  

*   Secure Hash Modification (SHM)
    

*   利用所有设备生成的nonces来构造Na和Nb，防止猜测攻击
    
*   将设备角色包含在Na和Nb的构造中，防止角色互换攻击
    
*   将IOCap包含在Ea和Eb的计算中，实现IOCap的认证  
    

*   Dual Passkey Entry (DPE)
    

*   每台设备均生成passkey，然后与用户共享并输入到另一台设备上，要求每台设备都要拥有显示和输入功能
    

![](../Images/1fe1a876b7f3f05d9cb14551bc2b436b.png)

最后，作者利用之前提出的形式化分析模型，来对三类PE协议以及两种改进的PE协议变种进行评估，结果表明所有三类原有PE协议均无法在CYBORG模型下提供安全性，而对协议的轻微改进能够提供更强的安全保证。
