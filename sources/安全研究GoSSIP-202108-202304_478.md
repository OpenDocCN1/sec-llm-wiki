# G.O.S.S.I.P 学术论文推荐 2021-09-16

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5ODUxMzg0Ng==&mid=2247487237&idx=1&sn=2aeb354cb50b98e56175ae4a13da9eb7&chksm=c06021dcf717a8ca7580d6d71b323037240820a0c9ebe467677dfc46a52a83983c345601dc9f&scene=126&sessionid=1681404263#rd](http://mp.weixin.qq.com/s?__biz=Mzg5ODUxMzg0Ng==&mid=2247487237&idx=1&sn=2aeb354cb50b98e56175ae4a13da9eb7&chksm=c06021dcf717a8ca7580d6d71b323037240820a0c9ebe467677dfc46a52a83983c345601dc9f&scene=126&sessionid=1681404263#rd)

早在2011年，G.O.S.S.I.P就在二进制代码的密码算法识别领域开展了研究，在2018年我们又在CCS上发表论文介绍了和算法无关的crypto key定位识别系统K-Hunt，今天我们要为大家推荐本研究领域的最新研究成果——发表在USENIX Security 2021上的论文Where’s Crypto：

![](../Images/4004876504435ad1df8ef246661f9b6e.png)

  

这篇论文设计并实现了一个自动识别二进制代码中密码原语并对其自动分类的工具——*Where’s Crypto*，主要的设计目标是打破已有工具局限（只能识别已知密码原语，且依赖于启发式方法选取待分析的代码段）。现有的一些密码算法识别工具在分析广泛存在于嵌入式系统中的未公开专有密码算法（proprietary cipher）时尤其会遇到困难，而 *Where’s Crypto *可用于分析现实固件中的密码算法种类，分析过程不依赖于固件所在的执行平台，将密码原语的识别范围进一步扩展，支持未知密码原语的识别，并能对其进行分类。

  

作者考虑到大部分经典的密码算法都可以囊括在已经建立起的原语类中，在论文中基于已有工作给出了下图的分类模式，并主要关注对称密码原语部分和无密钥密码原语部分：

![](../Images/3d462e8e639a47a2a15ddc125651417d.png)

  

为了解决先前工作的不足，作者通过构建DFG（数据流图）来刻画某个算法原语操作和数据流之间的关系。因而界定一个未知密码算法类别的问题，就可以转换成DFG子图同构的问题。与此同时，为了避免因代码实现和编译器因素导致的细微差异性，本文还在DFG子图同构分析前做了标准化处理。

![](../Images/d9c77fd7092ecd7f65cf21f7f2e0a42e.png)

  

作者分别选取了4个测试数据集来展示此工具的有效性。

*   1）与之前相关工作（Lestringant等人的工作）相同的数据集。可见在不同编译器和编译参数下，此工具均能成功识别：
    

![](../Images/72fc529583bb89358a1e1c8164ac7a31.png)  
  

*   2）选取OpenWRT 19.07.2版本中包含密码算法的库进行分析。*Where’s Crypto* 在较短的时间内正确识别了绝大部分的算法，准确性较高：
    

![](../Images/f66303f830bf6a0d38f60d871eaeb593.png)

*   3）作者选取一些公开的密码算法及嵌入式系统固件作为数据集进行测试。*Where’s Crypto *的表现依然可观：
    

![](../Images/fb332ab4fdbc1812deb97d101479b50f.png)

  

![](../Images/b0353d81ea2553c162bd0bc140292396.png)

  

作者（以IDA插件的形式）提供了 *Where’s Crypto *供大家测试，感兴趣的读者可以试试！
