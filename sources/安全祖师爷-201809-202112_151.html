Mac用户

作为一名资深Mac用户，我肯定得先研究Mac版本的破解。
首先，我们来到Chrome扩展管理页面，找到它的ID

ID


URL:chrome://extensions/?id=djmoeoifnlhjolebkehmpaocfnipknbh
我们使用sudo find / -name djmoeoifnlhjolebkehmpaocfnipknbh找到本地扩展的安装路径

搜索结果


找到以后，我们在Finder里面使用快捷性Command+Shift+G,输入找到的路径+2.2.4_0/theme/js
记得一定要在后面加上2.2.4_0/theme/js

JS

然后我们直接编辑hackbar-panel.js即可
修改false为true

true


新建一个页面调用hackbar，我们点一下那个Save就行了（其实不点也行了，点了就消失了）

破解完成


Win用户

C:\Users\你的用户名\AppData\Local\Google\Chrome\User Data\Default\Extensions\djmoeoifnlhjolebkehmpaocfnipknbh\2.2.4_0\theme\js


同样修改js文件相同的位置即可
