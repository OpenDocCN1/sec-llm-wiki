#### Mac用户

作为一名资深Mac用户，我肯定得先研究Mac版本的破解。  
首先，我们来到Chrome扩展管理页面，找到它的ID  

![](../Images/36c53e5b52c5298c5db3c3d9f7dbd4b7.png)

ID

  
URL:`chrome://extensions/?id=djmoeoifnlhjolebkehmpaocfnipknbh`  
我们使用`sudo find / -name djmoeoifnlhjolebkehmpaocfnipknbh`找到本地扩展的安装路径  

![](../Images/178dc5dfb88f718c4c599319e66fee0d.png)

搜索结果

  
找到以后，我们在Finder里面使用快捷性Command+Shift+G,输入找到的路径+`2.2.4_0/theme/js`  
记得一定要在后面加上`2.2.4_0/theme/js`  

![](../Images/c69449a80ecbf9161d45a2b20e797dbb.png)

JS

然后我们直接编辑hackbar-panel.js即可  
修改false为true  

![](../Images/d9efcb3660bf95ce886be45e7d372bcd.png)

true

  
新建一个页面调用hackbar，我们点一下那个Save就行了（其实不点也行了，点了就消失了）  

![](../Images/bb8aa0baedb9d3c46fd02307c46f576d.png)

破解完成
