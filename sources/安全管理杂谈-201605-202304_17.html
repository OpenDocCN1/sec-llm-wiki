在《管子·法法》中说到“求必欲得，禁必欲止，令必欲行。”说的是国家有要求的一定要做到，国家要禁止的一定要杜绝，国家颁布的法令一定要实行。
法律遵从（Compliance），也可以称为监管合规，是指企业的经营管理活动应符合法律法规、监管规定、行业准则和国际法规的要求。如果企业及员工出现不合规行为，可能会引发法律责任、受到相关处罚、造成经济或声誉损失以及其他负面影响的可能性，如：APP下架、业务关停、罚款、判刑等，给法人及企业带来不可估量的重大损失。
 所以务必遵纪守法，应当以国家法律及所在地法律法规、相关监管部门的要求，作为企业经营和安全建设的准则，行使相应的权利及履行相应的义务。

监管合规管理

企业需要进行有效的监管合规管理，应建立相应的组织和流程开展工作，以有效防控政治合规风险为目的，积极配合监管部门要求。
监管合规组织应由信息安全管理委员会专家组、法务部、人力资源部、政府关系部以及安全部门组成。其中安委会专家组，负责整体监管风险的评估及处理，以及相应工作的协调；法务部，负责相应法律法规及标准的解读；政府关系部，负责与政府监管部门进行沟通协调，并对内传达监管要求及对外发声，是企业对外的口舌；人力资源部，负责人员的教育培训；安全部门，负责具体执行监管合规的相应工作，如检查整改、安全措施更新等。
监管合规工作流程应包括政令接受与传达、风险识别与处理、教育培训、专项检查与整改、上报等阶段。

简单说明：

  1. 政令接收与传达：指政府关系部门接收到监管部门要求，并向监管合规组织传达。

  2. 风险分析与处理：专家组根据监管要求进行风险分析，给出相应的整改建议，并协调相关人员进行安全措施的处理及更新。

  3. 教育培训：对相应安全措施及制度文件进行培训，提高员工的安全意识。

  4. 专项检查与整改：安全部门配合监管外部检查，并根据检查结果协调整改。

  5. 上报：政府关系部门向监管部门上报并汇报结果。

相关法律法规：

网络安全法

为了保障网络安全，维护网络空间主权和国家安全、社会公共利益，保护公民、法人和其他组织的合法权益，促进经济社会信息化健康发展，国家出台《中华人民共和国网络安全法》。于2016年11月7日第十二届全国人民代表大会常务委员会第二十四次会议通过，并于2017年６月１日起正式施行，是国家信息安全宪法级法律。
网络安全法有对于网络运营者（企业）相关规定，如违反将按照相关条款进行处罚。要求企业遵守法律法规，尊重社会公德，遵守商业道德的相关条款：

  1. 履行网络安全保护义务，接受政府和社会的监督。

  2. 按照网络安全等级保护制度的要求，保障网络免受干扰、破坏、防止数据泄露。

  3. 签订协议或确认提供服务，应该要求用户实名制。

  4. 建立健全用户信息保护制度，严禁泄露。

  5. 建立网络信息安全投诉、举报制度，并及时处理。

  6. 为公安机关、国家安全机关依法维护国家安全和侦查犯罪的活动提供支持和协助。

  7. 配合网信等部门的监督检查。

  8. 制定应急预案，及时处置风险。发生危害后，采取补救措施，并向主管部门报告。

案例及处罚示例：

  1. 网安部门检查时发现，北京某互联网企业网络安全主体责任落实不到位，未按法律要求加强对网站所发布信息的管理，导致运营的APP被不法分子发布淫秽视频。2020年4月，北京市公安局海淀分局根据《中华人民共和国网络安全法》第四十七条、第六十八条之规定，给予该企业行政罚款十万元的处罚。

  2. 网安部门检查时发现，北京某互联网企业网络安全主体责任落实不到位，未按法律要求加强对网站所发布信息的管理，导致网站存在违法信息。2020年3月，北京市公安局海淀分局根据《中华人民共和国网络安全法》第四十七条、第六十八条之规定，给予该企业行政罚款十万元的处罚。

  3. 接公安部通报线索，“浴血XX”游戏中部分用户ID存在违法有害内容。经查，苏州某游戏企业在运营手机游戏“浴血XX”期间疏于管理，百余个游戏用户ID存在违法有害内容，造成恶劣影响，情节严重。2020年1月，苏州警方依据《中华人民共和国网络安全法》第47条、第68条规定，对该游戏企业予以罚款10万元。

  4. 常州警方在侦办一起侵犯公民个人信息案中，发现常州市某二手车商在经营过程中收集大量车辆信息（包含车主详细信息、车辆抵押状态、违章情况等）。但该企业内部管理混乱，没有采取必要的保护措施，保障其收集、存储的车辆信息安全，致使信息泄漏。警方同时还发现，该商行为便于核查二手车车况信息，曾在网上购买少量公民个人信息。2020年1月，常州警方依据《中华人民共和国网络安全法》第42条、第44条、第64条规定，对该企业予以罚款3万元，并收缴、销毁涉案个人信息。

网络安全等级保护标准

网络安全等级保护是国家对信息系统及网络按照重要性等级进行不同等级要求的保护工作，2007年出台的《信息安全等级保护管理办法》是等保1.0阶段，2017年6月1日，《中华人民共和国网络安全法》的正式实施，等级保护2.0时代正式来临。
网络安全法明确“国家实行网络安全等级保护制度。”（第21条）、“国家对一旦遭到破坏、丧失功能或者数据泄露，可能严重危害国家安全、国计民生、公共利益的关键信息基础设施，在网络安全等级保护制度的基础上，实行重点保护。”（第31条）。上述要求为网络安全等级保护赋予了新的含义，重新调整和修订的等级保护2.0标准体系，配合网络安全法的实施和落地，指导用户按照网络安全等级保护制度的新要求，履行网络安全保护义务的意义重大。
等保2.0包括安全通用要求和安全扩展要求，各方面更加突出可信计算技术的应用，形成“一个中心，三重防护”的防御体系。等保2.0是基于《中华人民共和国网络安全法》制定，针对共性安全保护需求提出安全通用要求，针对云计算、物联网、移动互联、工业控制和大数据等新技术、新应用领域的个性安全保护需求提出安全扩展要求，形成新的网络安全等级保护基本要求标准。
等级保护2.0共有8个控制措施分类，分别为技术部分（物理和环境安全、网络和通信安全、设备和计算安全、应用和数据安全）和管理部分（安全策略和管理制度、安全管理机构和人员、安全建设管理、安全运维管理）。

网络安全等级保护分级：

  1.  第一级（自主保护级），等级保护对象受到破坏后，会对公民、法人和其他组织的合法权益造成损害，但不损害国家安全、社会秩序和公共利益。

  2.  第二级（指导保护级），等级保护对象受到破坏后，会对公民、法人和其他组织的合法权益产生严重损害，或者对社会秩序和公共利益造成损害，但不损害国家安全。

  3. 第三级（监督保护级），等级保护对象受到破坏后，会对公民、法人和其他组织的合法权益产生特别严重损害，或者对社会秩序和公共利益造成严重损害，或者对国家安全造成损害。

  4. 第四级（强制保护级），等级保护对象受到破坏后，会对社会秩序和公共利益造成特别严重损害，或者对国家安全造成严重损害。

  5.  第五级（专控保护级），等级保护对象受到破坏后，会对国家安全造成特别严重损害。

其中最常见的是第二级和第三级，且二级及以上的定级对象需要落实等级保护工作，其中第二级有147个要求项，第三级有230个要求项。

等保工作主要分为定级、备案、建设和整改、等级测评和监督检查五个步骤：

  1. 定级阶段，应建立一个专项工作小组，完成相应的定级准备工作，并确认拟定级业务系统的业务及技术等相应负责人。确认定级对象，根据《网络安全等级保护定级指南》初步确认对象等级，准备相应材料，组织专家评审，并由主管单位审核。

  2. 备案阶段，准备《定级报告》、《备案表》、《系统拓扑图》、《系统安全实施方案》、《安全组织架构》等相关材料，到当地公安机关网安部门进行备案，由网安部门审核，并下发备案证明。

  3. 安全建设及整改阶段，根据《网络安全等级保护基本要求》中对应等级的要求为标准，开展自评估，对定级对象当前不满足要求的进行建设整改。

  4. 等级测评阶段，委托具备测评资质的测评机构（全国网络安全等级测评与检测评估机构目录）对定级对象进行等级测评，形成正式的测评报告，其中二级系统两年一次测评，三级系统一年一次测评。

  5. 监督检查阶段，向当地公安机关网安部门提交测评报告，并配合完成对网络安全等级保护实施情况的检查工作。

案例及处罚示例：

  1.  重庆市某科技发展有限企业自2017年6月1日后，在提供互联网数据中心服务时，存在未依法留存用户登录相关网络日志的违法行为，根据《网络安全法》第二十一条、第五十九条之规定，决定给予该企业警告处罚，并责令限期十五日内进行整改。

  2. 2020年2月，南京某研究院、无锡某图书馆因安全责任意识淡薄、网络安全等级保护制度落实不到位、管理制度和技术防护措施严重缺失，导致网站遭受攻击破坏。处罚措施：南京、无锡警方依据《网络安全法》第二十一条、第五十九条规定，对上述单位分别予以五万元罚款，对相关责任人予以五千元、两万元不等罚款，同时责令限期整改安全隐患，落实网络安全等级保护制度。

  3. 网安部门检查时发现，北京市朝阳区某建设企业财务报表管理系统未采取防范计算机病毒和网络攻击、网络侵入等危害网络安全行为的技术措施，导致被黑客攻击并植入了非法信息，且无法对黑客进行追踪溯源。2020年6月，北京市公安局朝阳分局根据《中华人民共和国网络安全法》第二十一条、第五十九条之规定，给予该建设企业罚款十万元的行政处罚。给予企业安全负责人罚款五万元的行政处罚。

Sarbanes-Oxley法案的404条款

2001年11月下旬美国最大的能源企业安然，因财务造假被美国证券交易委员会（SEC）罚款5亿美元，股价崩盘，走上破产之路。首席执行官弗里·斯基林被判刑24年，罚款4500万美元，首席财务官安德鲁·费斯托被判10年监禁加2380万美元罚金。
2002年6月美国第二大长途电话和互联网数据传输企业世通，在内部审计时发现了38.52亿美金数额的财务造假，美国证券交易委员会（SEC）介入调查，股价暴跌，2002年7月，世通宣布破产。首席执行官埃伯尼·埃博斯被判25年监狱，首席财务官斯科特·沙利文被判5年监狱，并没收全部财产。
针对安然、世通等企业的财务欺诈事件，美国国会出台了《2002年公众企业会计改革和投资者保护法案》，该法案涉及到会计职业监管、企业治理、证劵市场监督等多方面改革，要求在美国上市的企业都必须遵守，该法案由美国众议院金融服务委员会主席奥克斯利和参议院银行委员会主席萨班斯联合提出，又被称作《2002年萨班斯—奥克斯利法案》Sarbanes Oxley（2002）Regulations，萨班斯法案是对美股上市企业影响最广泛的法律之一，该法案旨在保护在美国证券交易所开展股票交易的企业股东，并加大对这些企业决策人的可查力度。
SOX404即为Sarbanes-Oxley法案的404条款，关于内部控制的管理评估内容。法案明确了管理层对与财务报表及与其相关的内部控制制度的有效性的责任，并要求管理层对此发表书面声明。旨在通过加大控制力度来加重上市企业决策人的责任。美国政府已强制性地要求所有公开交易企业必须于2005年底满足本部分的要求，与财务报告一起提供内部控制的年度管理报告 （CEO和CFO必须签署书面声明），这之中包括：

  1. 记录控制设计效力测试的结果，对企业建立和维持足够的财务报告内部控制负有责任。

  2. 披露任何主要缺陷。

  3. 获取外部审计企业审核以证明相关报告。

    根据SOX法案规定，企业高管须对财务报告的真实性负责，提供不实财务报告将获10年或20年的刑事责任，对故意进行证劵欺诈的犯罪最高可判处25年入狱；对犯有欺诈罪的个人和企业的罚金最高分别可达500万美元和2500万美元等。

数据与个人隐私保护相关法律

《中华人民共和国数据安全法》是为了规范数据处理活动，保障数据安全，促进数据开发利用，保护个人、组织的合法权益，维护国家主权、安全和发展利益而制定的法律。全文共七章五十五条，构建全生命周期的数据安全理念，从数据安全与发展、数据安全制度、政务数据安全与开放等多个角度对数据安全保护的义务和相应法律责任进行规定。2021年6月10日，第十三届全国人民代表大会常务委员会第二十九次会议通过《中华人民共和国数据安全法》，自2021年9月1日起施行。
《中华人民共和国个人信息保护法》是为了保护个人信息权限，规范个人信息处理活动，促进个人信息合理利用的法律。全文共八章七十三条，实现对个人信息的保护，从个人信息处理规划、个人信息跨境提供的规则、个人在个人信息处理活动的权利以及个人信息处理者的义务等多方面对个人信息全生命周期进行保护以及相应的法律责任进行了规定。2021年8月20日由十三届全国人大常委会第三十次会议表决通过《中华人民共和国个人信息保护法》，自2021年11月1日起施行。
《最高人民法院、最高人民检察院关于办理侵犯公民个人信息刑事案件适用法律若干问题的解释》，于2017年3月20日由最高人民法院审判委员会第1712次会议、2017年4月26日由最高人民检察院第十二届检察委员会第63次会议通过，2017年6月1日起施行。为依法惩治侵犯公民个人信息犯罪活动，保护公民个人信息安全和合法权益。
随着《网络安全法》、《数据安全法》、《个人信息保护法》的出台，其它部委的相继出台各类隐私合规相应法律，同时也加大了对侵害个人信息的打击力度，开展多次专项整治行动，未来几年个人信息保护及隐私将成为企业信息安全负责人需密切关切的方面。
在现行法律GB/T 35273-2020《信息安全技术个人信息安全规范》中规定：个人信息包括姓名、出生日期、身份证件号码、个人生物识别信息、住址、通信通讯联系方式、通信记录和内容、账号密码、财产信息、征信信息、行踪轨迹、住宿信息、健康生理信息、交易信息等。
《网络安全审查办法》则是为了确保关键信息基础设施供应链安全，维护国家安全，依据《中华人民共和国国家安全法》《中华人民共和国网络安全法》《中华人民共和国数据安全法》制定，由国家互联网信息办公室、国家发展和改革委员会、工业和信息化部、公安部、国家安全部、财政部、商务部、中国人民银行、国家市场监督管理总局、国家广播电视总局、国家保密局、国家密码管理局于2020年4月13日印发，自2020年6月1日起实施。并于2021年7月10日国家互联网信息办公室发布关于《网络安全审查办法（修订草案征求意见稿）》公开征求意见的通知，自2022年2月15日正式施行，要求掌握超过100万用户个人信息的运营者赴国外上市，必须向网络安全审查办公室申报网络安全审查。
与此同时，其它国家也在积极开展个人信息保护相应的法规，如欧盟的《通用数据保护条例（General Data Protection Regulation，GDPR）》，它是欧盟议会和欧盟理事会在2016年4月通过，在2018年5月开始强制实施的规定。英国尽管退出了欧盟，但是制定的《UK's Data Protection Act 2018》就是英国版本的GDPR，其它大洲与国家也在积极出台各自的GDPR。
该条例将影响适用于GDPR的企业收集和管理其客户及雇员个人数据的方式。根据GDPR，任何在欧盟设立机构的企业或者向欧盟境内提供产品和服务的企业在处理欧盟数据主体的个人数据时都应当遵从该要求。

欧盟GDPR将涉及以下一种或一种以上类别的个人信息视为敏感数据：

  1. 种族或民族出身
  2. 政治观点
  3. 宗教/哲学信仰
  4. 工会成员身份
  5. 涉及健康、性生活或性取向的数据
  6. 基因数据
  7. 经处理可识别特定个人的生物识别数据
规定企业在收集用户的个人信息之前，必须以简洁、透明且易懂的形式，清晰和平白的语言向用户说明：

  1. 将收集用户的哪些信息。

  2. 收集到的信息将如何进行存储。

  3. 存储的信息会如何使用。

  4. 以及企业的联系方式。

GDPR 的处罚力度也非常高，高到足够引起所有的企业重视，每次违反条例最高罚金可达2000万欧元或者其全球营业额的4%，以高者为准。
GDPR在2020年实施公布的高额罚款和/或影响较大的经典案例，主要如下：

  1. 2020年1月意大利数据保护机构（Garante）向电信运营商TIM开出2780万欧元的罚单。除了罚款外，Garante还对TIM实施了20项纠正措施，包括禁令和命令。特别值得一提的是，Garante禁止TIM出于营销目的，使用那些在呼叫中心联系时拒绝接听营销电话的用户、黑名单中的用户以及没有同意接听的非客户的数据。

  2. 2020年4月荷兰某组织要求员工必须扫描登记指纹用于考勤打卡，且该组织未遵照透明原则向员工提供法律要求的关于数据处理行为的信息，劳动合同和员工手册中未包含任何关于使用指纹数据的说明，且保留离职员工的指纹信息，违反GDPR第5条、第9条、第12条、第13条，因而被荷兰数据保护局处以725000欧元的罚款。

  3. 2020年6月法国行政法最高法院已驳回谷歌去年因未向其用户说明如何处理个人信息而必须支付5700万美元罚款的申诉。该法院确认了数据监管机构（CNIL）先前的调查结果，即谷歌并未向安卓用户提供“足够清晰”的信息提醒，这就意味着，谷歌没有获得将用户数据用于目标广告的合法性同意。考虑到谷歌违规的严重性和持续性，5700万美元的罚款数额是有理有据的。

  4. 2020年10月英国信息委员办公室（ICO）表示，万豪国际“未能按照GDPR的要求，采取适当的技术或组织措施，保护其系统上正在处理的个人数据，被处于1840万英镑（约合2380万美元）罚款。最终罚款比ICO最初计划的9920万英镑有所减少。ICO表示，“作为监管过程的一部分，ICO考虑了万豪的陈述、万豪为减轻事件影响所采取的措施，以及疫情对其业务的经济影响，然后才制定了最终的处罚”。

  5. 2020年12月法国CNIL限制委员会对亚马逊欧洲企业（Amazon Europe Core，一家设立在卢森堡，负责亚马逊集团下欧洲网站amazon.fr运营的企业）处以3500万欧元的罚款。原因是该企业在未经用户的事先同意及未提供充分信息的情况下，通过azmazon.fr网页在用户电脑中放置用于广告目的的cookies。

小结

希望通过此文让朋友们知道，企业在经营管理中可能会受到的各类监管要求，如网安法、等保、数安法、个保法、GDPR还有各类专项检查等，建议积极配合监管要求，并根据当地的法律法规、业界标准、行业最佳实践以及企业业务特点，更好的设计和实施安全策略，让业务合规合法合理，给客户提供保障，使业务持续经营。
