# 聊聊如何做内部邮件的安全

说到公司内部的邮件安全，没错，是公司IT部门的责任，它属于办公网安全的一部分；除少部分的公司邮箱是使用大厂的企邮产品之外，大多数公司都是自建的企业邮箱，邮箱做为公司内外部沟通的重要手段，重要程度不言而喻，随着而来的就是安全风险也越来越突出，比如电信诈骗，钓鱼攻击，勒索病毒等，一旦被黑客利用，将给公司带来巨大损失，这时候IT部门就会拉着安全部门一起背锅，所以需要引起高度重视和警惕；

 

**那么如何搞一个安全的邮件系统？**

**需要先知道邮件系统底细**

邮件系统管理员是谁，在哪部署，用户登陆方式是什么，邮件数据存了几份都在哪，网络拓扑是什么样，使用什么服务器，什么存储，具体什么配置，在关键环节是否有监控，是否考虑到冗余，是否有应急预案，是否做过演练等 ... 

**确认防护要求**

*   边界防控，最好部署防火墙、邮件网关等相应设备；
    
*   网络隔离，并制定ACL，只允许邮件管理员的网段进行管理；
    
*   管理系统的帐号认证，使用多因子认证进行防抵赖；
    
*   部署防病毒软件，对邮件附件进行查杀，防止病毒木马的传播；
    
*   部署反泄密系统，用以发现内部用户有意无意的泄密行为；
    

**做好日常运营**

*   密码策略，如强制用户90天更换一次密码，密码复杂度限制等
    
*   备份策略，如每周全量，每日增量，每月异地等
    
*   监控策略，对业务接口，服务器，以及网络进行监控，如异常通知管理员及安全部门等；
    
*   部署内网蜜罐，诱捕可能的攻击行为；
    
*   对邮件系统网络进行周期性扫描，并进行网络分析，发现异常及时处理
    
*   加强员工的安全意识教育，针对钓鱼，社会工程学等；
    

 

**给邮箱用户的建议**

1.  把工作邮箱与私人邮件分开，并定期更改密码；
    
2.  邮件密码与社交网站的密码不要相同；
    
3.  阅读来历不明的邮件，不要点击链接；
    
4.  安装杀毒软件，对邮件附件进行扫描；  
    
5.  发送重要材料要加密；
    
6.  重要资料勤备份；
