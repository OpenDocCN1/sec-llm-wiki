# #乱谈网络空间安全#

以前说网络安全（network security），当时是为了保障网络不受到有意无意的攻击，主要是保证网络通畅（可用性），实现网络通信的持续运行；后来说信息安全(information security)，将以前的网络安全扩展到更多的领域，在信息流（生成，保管，传递，销毁）各个过程中安全特性（可用性，完整性，保密性）在技术方面以及管理方面的采取必要的措施，实现业务的持续运营；现在说网络空间安全(cyber security),则是在以上的基础上，实现在公司提供的网络空间上的用户在真实世界中的人身，财产的安全；  

国家层面就不说了，现在普便认为网络空间是继陆、海、空、天后的第五疆域，公司配合国家完成国家网络空间安全战略部署就结了；

主要是公司的网络空间，即是公司的产品所建立的虚拟空间，就是一个世界，我们不仅要考虑每一个id就是一个生命，他们的虚拟资产就是他们的财富，有可能是用户在除了现实世界外的人生意义，还得考虑空间对用户在现实世界中的影响；

安全部门针对用户在虚拟空间的行为，确定其在现实世界的行为意义，建立安全规则从而做到更好的为用户服务，降低安全风险，提高安全等级，保障公司网络空间安全才是安全部门最终目标，安全部门的路真是特么的任重而路远啊；

就说到这吧，结束；
