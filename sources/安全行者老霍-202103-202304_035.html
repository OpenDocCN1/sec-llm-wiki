写在前面：防火墙是网络安全产品最早和最成熟的产品之一了，近年由于各种新的网络安全概念和产品频出，大家对防火墙的关注少了很多，似乎这是一个落后的概念了，实际上，它仍在不断发展，还是最有效的网络安全产品。这个文档主要让大家看看当前主流的防火墙厂家和防火墙技术的发展方向。


2022年1月17日  ID G00740373


       网络防火墙是关键的网络安全控制，他们不断发展，覆盖更多的用户场景，如公有云、防火墙即服务、和分布式边缘安全。安全和风险管理（SRM）领先者必须根据他们组织的使用情况，评估网络防火墙的能力。


概述


关键发现

  • 防火墙厂商正在扩大他们的产品种类，但这些新产品还没有紧密集成到他们的平台中。新产品经常要求多个管理控制台及多个主机代理软件，有时在组件之间缺少深度集成。

  • 当转向在家办公，防火墙厂商使用他们强有力的云安全策略，提供基于云的安全服务，越来越让客户满意。

  • 云优先企业，更喜欢支持集成管理云原生防火墙的厂商。

  • 随着向混合工作方式转移，终端用户发现本地防火墙价值降低，从已有的厂商中寻找混合云安全厂商。

推荐

       对基础设施安全负有责任的安全和风险（SRM）领先者，评估防火墙厂商时应该：

  • 基于组织的业务需求来比较厂商产品，而不是只关注单一厂商，要考察手边多个可用选择。例如，以数据中心为主、有很多分支机构的组织，也许会发现，同时具有最好的数据中心防火墙和防火墙即服务的厂商，会最大化组织的整体价值。

  • 在集中管理和集成的基础上，进行深度评测。

  • 如果组织的主要目标是缓解云中的安全功能，关注防火墙即服务厂商，云访问安全代理和云负载保护平台。

战略计划假设


       到2025年，30%的分布式分支机构防火墙将转向防火墙即服务，而2021年不到10%。

       到2025年底，最终用户在网络防火墙上的支出中，35%将来自单一供应商通过企业许可协议交付的大型安全协议，高于2021年的不到10%。


你需要知道

       防火墙厂商目前关注改善高级威胁检测和响应能力、物联网（IoT）安全、和公有云集成，勒索软件检测和响应。作为对客户越来越多在家办公的回应，厂商关心成熟的防火墙即服务功能，提供更灵活和地址无关的网络安全控制。防火墙市场最近已经发生几个主要收购，特别在公有云行业，包括防火墙即服务、安全软件定义WAN、（SD-WAN）和基于身份的隔离，也称之为微隔离。一些提供这些功能的厂商正在被防火墙厂商收购。网络防火墙厂商正在扩充他们的产品组合，满足组织的需求，在单一厂商产品中整合他们的解决方案。


厂商


阿里巴巴云

       阿里巴巴云提供公有云防火墙，叫作阿里巴巴云防火墙，只为阿里巴巴云客户提供防火墙即服务和基于身份的隔离。阿里巴巴云安全中心实现防火墙和其他产品集中管理。而且，最新版的阿里巴巴云防火墙有自己的统一管理。除了防火墙，阿里巴巴云有多个安全产品，例如分布式拒绝服务（DDOS）缓解、Web应用防火墙、数据保护和加密、托管安全服务。

       最近的更新已经引入网络服务和多个网络安全有关功能。亮点包括云安全访问访问（CSAS），具有应用访问控制、URL控制、零信任访问（ZTNA）内网访问控制和日志功能，容器防火墙和虚拟补丁。

       相比其他基础设施即服务（IaaS）的安全厂商，阿里巴巴云得分更好，由于其支持更多的第三方云，及其出色的统一管理功能。然而，虽然阿里巴巴云在高级安全功能（高级威胁检测和响应）方面优于其他IaaS厂商，但在这个领域，作为一个整体，位于市场的底部。


Amazon Web Service

       Amazon Web Service是全球公共云提供商。给其公有云客户提供许多网络安全控制，包括Amazon 虚拟私有云（VPC）安全组合Amazon 虚拟私有云网络访问控制名单。本文评测的产品是Amazon 网络防火墙，2020年11月发布。AWS 防火墙管理器统一管理所有Amazon Web Service 防火墙相关的产品，包括它的Web应用防火墙和DNS防火墙。

       在去年，AWS已经扩展其AWS网络防火墙到所有23个区域。

       因为其地理覆盖能力和按需扩展防火墙功能，AWS在扩展性方面得分很高。特别在基础设施保护方面，由于易于使用而碾压很多厂商。但在其他方面，AWS得分很低，如应用控制、入侵检测和高级威胁检测。虽然AWS防火墙提供和AWS平台无缝集成，没有提供保护其他云环境的网络防火墙功能。


Barracuda（梭子鱼）

       Barracuda主要使用CloudGen 防火墙产品线，对分支办公室和公有云提供保护。也通过安全防问服务边缘（SASE）产品CloudGen WAN提供防火墙即服务。防火墙控制中心是集中防火墙管理器，Firewall Insights 报告工具。

       最近的更新包括物联网（IOT）、运维技术（OT）和云安全功能。亮点包括集成零信任网络及增加CloudGen WAN的安全功能。Barracuda也宣布和Crosser达成合作关系，管理OT环境的防火墙配置变更。

       Barracuda适合分支办公室和基础设施及服务防火墙场景。和防火墙市场其他竞争者相比，它的方案和原生AWS及Microsoft Azure 控制集成地非常好。但Barracuda还没有提供容器防火墙或物理隔离。

       Barracuda没有提供基于云的防火墙集中管理器，这使它在管理易用性方面得分较低。


Cato Network

       Cato Network 通过Cato SASE Cloud产品提供防火墙即服务。虽然有一个硬件的Cato Socket ，实现SD-WAN，这个组件要求Cato 云组件。没有独立的防火墙或虚拟设备防火墙。Cato Management Application管理Cato 所有的产品。

       最近的更新集中在打造安全访问服务边缘（SASE）功能。零信任也能够以无代理的形式提供，增加了用户受众，除了SD-WAN，还可以得到Cato SASE Cloud的保护。

       Cato 只对分支办公室和漫游用户提供防火墙即服务、零信任和SD-WAN。然而厂商缺少数据中心和高带宽企业边界环境所需要的硬件。

       Cato 提供无差异化的URL过滤功能，但缺少客户端应用的细粒度控制及数据防泄漏功能。


Check Point Software Technologies

       Check Point提供整体的安全产品系列，使用量子这个品牌，如最近发布的Maestro Hyperscale 产品线。Check Point 也提供虚拟设备和云安全产品，使用CLoudGuard 品牌，加上防火墙即服务产品，使用Harmony品牌，用于Check Point 安全访问服务边缘（SASE）方案。Check Point 提供本地（Quantum Security Managerment）和云的集中管理和监控产品。

       过去的12个月，发布了新的Maestro 硬件和容器防火墙。软件功能包括自治威胁阻止，配置更容易，传输层安全支持检测假冒服务器名称标识（SNI），和多个在管理和监控控制台上的改善。

       Check Point 的硬件防火墙得分很高，特别是企业边界和数据中心用户场景。       Check Point 在高级威胁阻止和防火墙统一管理方面得分也很高。

       Check Point 不提供从本地或云数据防泄漏工具导入策略，也不支持SaaS应用中数据令牌化和解密。厂商没有提供原生SD-WAN，而是使用合作伙伴的产品。因此，Check Point 在分支办公室方面得分不高。

       虽然许多防火墙厂商扩展云安全使用场景，Check Point 缺少一个基于代理软件的根据身份进行隔离的产品，开发容器防火墙方面也有些落后。


Cisco

       Cisco 提供多条防火墙产品线，包括Cisco Secure Firewall（以前的Firepower）、Cisco Secure Workload（以前的Tetration）、Meraki MX系列。此外，Cisco 提供Umbrella Secure Internet Gateway（SIG）实现防火墙即服务，工业防火墙（Secure Firewall Industrial Security Application系列）。Cisco Secure Firewall Management Center（管理本地设备）和Cisco Defense Orchestrator （基于云）是Cisco的集中管理产品。

       在本次关键能力报告的评测时期，Cisco发布了六个Firepower Threat Defense（FTD）虚拟设备，一个容器防火墙和Cisco Managed Remote Access，托管VPN方案。其他重要的更新是多云管理和集成Secure Workload 和Secure Firewall的控制。

       Cisco多种防火墙产品，帮助它在某些特定用户场景，打分很高。然而，多样性也影响了Cisco的易用性评分。

       因为Cisco 提供集成的SD-WAN，特别是通过Meraki 产品线，能够支持多个协议，对于高级网络，打分很高。

       Cisco 的 入侵检测阻止（IPS）和高级威胁检测功能，包含在所有的防火墙产品中，帮助它在企业用户中得分很高。然而，由于在七层流量的应用控制粒度较低，相比别的竞争者，得分不高。


Forcepoint

       Forcepoint防火墙设备内置SD-WAN功能。Forcepoint有好几个虚拟设备型号。除了网络防火墙，Forcepoint还有数据防泄漏（DLP）、云访问安全代理（CASB）、安全Web 网关（SWG，Secure Web Gateway）产品线。

       在测评时期，Forcepoint发布了几个新的防火墙型号，特别是N60和N120WL低端产品。其他更新包括改善的SD-WAN性能，实现更快的SD-WAN边缘连接，进一步改善和AWS及Azure集成，额外的IPS引擎，和Snort配合，实现开源特征功能。

       Forcepoint防火墙主要适合分支办公室场景，客户在寻找成熟的威胁阻止功能。                                     

        Forcepoint 提供和AWS及Azure的公共云防火墙成熟集成。尽管其强大的安全Web网关功能，Forcepoint还没有提供防火墙即服务，或基于云的集中管理。


Fortinet

       Fortinet的FortiGate 防火墙产品线适合所有的防火墙部署场景。FortiGate也有适合AWS、Microsoft Azure、Google Cloud Platform（GCP）、VMware Cloud、Oracle Cloud Infrastructure（OCI）、IBM Cloud、阿里云等公有云平台。在收购了OPAQ之后，Fortinet 最近发布了FortiGate 防火墙即服务，并命名为FortiSASE。FortiManager和FortiGate Cloud 是Fortinet的集中管理产品。FortiAnalyzer和FortiCloud是集中报告工具。除了防火墙，Fortinet 有很宽的产品线，如端点检测和响应（EDR），Web应用防火墙/Web 应用和API保护（WAF/WAAP）、网络访问控制（NAC）、欺骗、身份和访问管理（IAM）。所有这些功能集成到FortiGate，由同一个管理系统控制。

       最近的发布包括安全运营中心（SOC）即服务、SASE和零信任产品。Fortinet 也提高了URL过滤和高级威胁检测功能。此外，在Fabric Management Center中集成了网络运营中心和安全运营中心。

       由于差异化的硬件方法，Fortinet 非常容易扩展，在分支防火墙产品集成高级SD-WAN功能。Fortinet 的产品矩阵由于易用性得到很高评分。然而，Fortinet 还没有集成基于身份的隔离产品，防火墙即服务还没有完全集成到FortiSASE，提供了两个还不成熟的防火墙即服务产品。


H3C

       H3C提供全系列的防火墙产品，名字是SecPath，适用小、中、大规模环境。SecPath 也提供虚拟设备。H3C 的防火墙即服务叫作SeerEngine-DC。有三个集中管理方案：iMC Security Service Manager、SecCenter Security Management Platform、SecCenter Cybersecurity Sitouational Awareness Platform。

       H3C 持续大力在安全和检测能力上投资。最近增加了欺骗、用户行为分析、网络杀伤链一致的工作流、资产风险评估。增量改善包括web和DNS检测，标记非法内容和弱口令。

       相比其他本地竞争厂商，H3C的防火墙即服务产品有很好的云支持功能，在分支企业中得分较高。H3C 的应用控制评价很好。在公有云支持方面得分不高，缺乏对主要的IaaS支持。


山石（Hillstone Network）

       山石提供多条防火墙产品线，满足不同用户需求。硬件防火墙分为A系列 NGFW、E系列NGFW、T系列NGFW、T系列NGFW、X系列数据NGFW。山石还有CloudEdge 虚拟防火墙、CloudHive 基于身份隔离、托管CloudPanno 防火墙即服务、容器化CloudArmour防火墙Hillstone Security Management（HSM）平台是及防火墙管理平台，Hillstone CloudView是基于云的安全管理系统。山石也提供专门的iSource XDR平台。除了防火墙，山石有很宽的产品线，包括网络安全、云安全和安全运营产品线。

       最近的更新包括一个新的防火墙产品线，云数据库湖和云威胁分析平台。此外，山石在策略编排和IP 声誉数据库方面做了功能提高。

       山石高级报告工具，如HAS，帮助它评分稍高，山石也支持一些全球公有云，帮助它在云支持场景方面，得到高分。

       但山石缺乏直接的防火墙即服务产品。CloudPano是一个托管防火墙即服务，由托管安全服务提供商来提供，由于这点，山石在分布式企业方面得分不高。


华为（Huawei）

       华为针对不同的用户，提供不同的防火墙产品。USG和Eudemon是其硬件防火墙产品线。华为云防火墙适用虚拟和云防火墙场景。华为有不同的集中管理产品，eSight、iMaster NCE、SecoManager。Hisec LogAuditor是集中报告工具。

最近的更新提高了华为高级检测和SD-WAN功能。亮点包括使用高端USG防火墙模块改善的硬件性能，华为云防火墙功能提高。

       华为防火墙的企业边界和数据中心的高处理能力场景中的高性价比为其赢得了高分。但在云安全方面得分不高，只要因为只支持华为云，不支持AWS和Azure等公有云。

       华为也缺少防火墙即服务，降低了在分支办公方面的得分。华为还需要提高防火墙的应用控制，在中国之外提供覆盖更多的应用。


Juniper

       Juniper 防火墙产品是SRX系列的下一代防火墙，可以作为硬件设备、虚拟设备（vSRX）、容器（cSRX）提供。vSRX可以安装客户自己的虚拟机或运行在AWS、Microsoft Azure、GCP、IBM Cloud Platform、OCI。除了防火墙，Juniper 提供安全信息和事件管理（SIEM）、DDoS缓解和威胁情报（TI）。

       最近的新产品包括对高级威胁检测功能的提高，IoT安全，工业控制系统（ICS）和SCADA环境的合作。

       Juniper 的Security Director 管理平台因其集中管理和易用性得分很高，提高了对中小企业和数据中心用户的适用性。容器化防火墙和全球公有云支持提高了云安全支持的得分。然而，Juniper 缺少高级数据防泄漏，降低了整体应用控制得分。


Microsoft

       Microsoft Azure 防火墙产品有两个分类：标准版和增强版。可以通过Azure Firewall Manager集中管理，使用Azure Monitor和Azure Sentinel集中监控。

       最近微软发布Firewall增强版，在网络规则中，增加了完整域名（fully qualified domain name，FQDN）过滤；应用规则中，增加传输层安全（TLS） 解密。

       微软增加了一些新的安全改善，许多功能可能会提高整体安全态势。微软的防火墙即服务产品在Azure环境中很容易实施，在用户中集中管理部分得分很高。然而，微软缺少应用控制，高级入侵阻止和检测，也不支持多云环境。


Palo Alto Networks

       Palo Alto Networks 对不同的客户提供不同的防火墙产品：硬件防火墙（PA 系列）、虚拟防火墙（VM 系列）、防火墙即服务（Prisma Access）、容器化防火墙（CN 系列）、基于身份隔离（Prisma Cloud）。防火墙集中管理是Panorama，可以作为硬件和虚拟设备提供。除了防火墙，Palo Alto Networks 提供端点安全、云安全和安全运营产品。

       最近的更新包括一些防火墙功能的提高。亮点包括新的产品分类，有IoT安全，企业DLP，SaaS安全和高级URL过滤。其他关键功能包括IoT安全、IPS、和DNS的更新。

       Palo Alto Networks 在高级威胁检测方面得分很高，因为其威胁研究的质量和大量使用Wildfire的用户。厂商提供成熟的防火墙即服务，覆盖很多地区，DLP和SD-WAN功能在分支办公室的使用，都增加了它的分数。Palo Alto Networks 的云防火墙产品支持大多数的云平台，专门的身份隔离和容器防火墙在云防火墙场景得分很高。

       然而，Palo Alto Networks 在集中管理方面得分很低，因为其当前只提供基于云的集中防火墙管理，叫Prisma Access。Prisma Cloud不安装插件，无法被Panorama管理。

       虽然Palo Alto Networks 已经通过最近发布的硬件，改善了它的性价比，在这方面仍然得到低分。这是由于其高的整体拥有成本（TCO），是其成为市场上最贵的防火墙产品。


深信服（Sangfor）

       深信服提供多种产品，满足从小到大的各种环境需求。下一代应用防火墙（NGFA）也可作为虚拟设备提供。深信服的防火墙即服务产品是Cloud Fortress Access，Sangfor Access是SASE方案。Sangfor CWPP是容器防火墙和身份隔离产品。Sangfor Central Manager 是本地集中管理方案，Sangfor Platform-X是基于云的集中管理产品。

       最近的产品更新集中在更深的安全能力上，包括针对欺骗和用户实体行为分析（UEBA）功能。Sangfor也提高了其威胁检测能力。

       相比本地的竞争者，Sangfor不只是一个面向7层的应用安全厂商，在大多数安全领域，得分都很高。防火墙即服务产品在本地和全球都很有影响。容器化防火墙提高了其云安全排名。然而，深信服缺少集中管理控制和云安全可视化，及软件定义网络环境，降低了集中管理得分。


SonicWall

       SonicWall 有三个硬件防火墙产品线，包括TZ、NSa、NSsp系列，虚拟防火墙产品线，NSv系列。NSv系列能安装在客户自己的虚拟机或AWS和Microsoft Azure上。Network Security Manager 是SonicWall 集中管理和报告工具。除了防火墙，SonicWall 还有集成的EDR、SEZG、零信任、VPN、云访问安全代理（CASB），沙盒技术，无线AP和交换机。

       最近的更新包括集中管理、规则优化、SD-WAN工作流简化分支办公室上线。SonicWall 完整了整合Gen 7的防火墙产品线。厂商发布集中管理，可管理SonicWall 交换机、AP和SonicWall 下一代端点。

       SonicWall 内置SD-WAN，和QOS功能，帮助它在高级网络方面得分较高。也有一个完整的防火墙即服务产品。然而，SonicWall 在大多数重要共有云中，除了AWS，缺少认证，影响了公有云支持排名。


Sophos

       Sophos 防火墙产品线包括Sophos Firewall(前XG)。Sophos 对当前的中小客户，也继续支持SG UTM 产品线。提供云安全态势管理（CSPM；Cloud Optix）和集中管理门户（Sophos Central）。InterceptX是其端点和服务器保护（包括云负载）品牌名称。Sophos 也提供其他安全产品线，如端点安全、电子邮件安全，和托管检测和响应服务。

       最近的更新包括硬件的变化（XGS系列和SD-RED）。Sophos 持续改善和IaaS平台的基础及集中管理和监控门户。其他功能包括VPN性能和高可用性提高，重新定义的TLS认证管理。

       Sophos为防火墙和端点层，提供单一管理和威胁关联门户，有助于提高易用性排名。然而，Sophos缺少云交付的防火墙即服务，在这个领域得到低分。Sophos不提供基于身份的隔离或容器防火墙，影响了其公有云支持的打分。


Versa Networks

       Versa网络的主要防火墙产品是防火墙即服务产品，来自其SASE产品线。作为一个成熟的网络厂商，Versa 在它Versa Secure SD-WAN设备中，也提供本地防火墙。Versa Concerto 是公司集中管理和报告门户。

       最近的更新包括加入云访问安全代理（CASB）、数据防泄漏、高级威胁检测（ATP）、Versa SASE产品提供主机信息概述服务。

       Versa 的能力是提供较低的每用户成本基础上，提供较小延时。多租户防火墙及服务门户帮助得到高分。Versa不提供云环境中Kubernetes 标签或态势管理功能，降低了公有云支持部分的得分。


WatchGuard

       WatchGuard提供防火墙满足中小企业和分支办公室的场景。防火墙产品线的品牌名称是WatchGuard Firebox。WatchGuard 也为AWS、Azure和虚拟化环境提供虚拟防火墙。WatchGuard Cloud和WatchGuard System Manager（本地/虚拟环境）是厂商防火墙集中管理平台。WatchGuard Cloud Visibility 和Dimension 是集中报告工具。

       最近更新包括SD-WAN 和VPN的本地及云管理，直接集成到AuthPoint 和端点产品，移动VPN 的端点完整性强制。

       WatchGuard的威胁检测无缝集成到大量的第三方端点保护产品，明显影响WatchGuard 的易用性评分。然而，WatchGuard只支持AWS和Microsoft Azure公有云。没有任何公有云认证，降低了公有云支持打分。
