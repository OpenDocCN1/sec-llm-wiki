写在前面：本文包括两个报告，都是Cybersecurity Insider发布的，但合作厂商不一样，一个是Resecurity，一个是Bitclass，由于大部分内容比较简单，就只列出两文中涉及的技术部分。安全产品很多，厂商根据信息世界的不同风险，提出各自的解决方案。从这两个报告可以看出，勒索软件和恶意软件还是最严重的威胁，因为他们的影响对象是业务系统和数据，也从侧面说明了端点安全的重要性。

持续加剧的威胁严重性  

  

        恶意软件和勒索软件是重大的威胁，能严重地伤害业务。大约60%的网络安全专业人员认为恶意软件和勒索软件对他们的业务是极端威胁。

![](../Images/8ab1625337fbd0ea2d2d3069b74595b2.png)

最危险的威胁  

  

        我们询问网络安全专业人员最关心哪种类型的攻击？有组织犯罪（77%）位居首位，其次是机会主义黑客（67%），最后是国家资助黑客（50%）。鱼叉式钓鱼邮件是最危险的恶意软件攻击类型，紧接其后的是域名欺骗（45%），中间人攻击（43%）。

![](../Images/9e5b16fb3a570ac7667198d441b2a8b8.png)

![](../Images/808dfbb7037e20bfa43681e5b572c397.png)  

攻击响应对策  

  

        我们询问网络安全专业人士，他们的组织在检测到勒索软件攻击之后，如何响应。攻击被检测到以后，最常见的响应是隔离并关闭受感染系统和账户，阻止最初攻击手段的同时，从备份中恢复加密文件。

![](../Images/73689b934f7a7203f268a07c0ef9451d.png)

  

有效方案  

  

        网络安全专业人士认为，持续检查数据和恢复（86%）作为对成功攻击最有效的方案。威胁情报也是有效的阻止方式（77%）。

![](../Images/06c5527ef057f1c1b995e2fcafd1bc37.png)

  

服务器级别的恶意软件防护  

  

        当问到在服务器级别的恶意软件防护方案中最重要的功能，76%的安全专家推崇自动化更新和扫描，其次是启发式分析（67%）。

![](../Images/05ab8b30f7d1cb0aa6888f90ab97d066.png)

        Resecurityt提供情报、风险管理和安全功能。使命是帮助企业、国家安全、立法机构打击网络威胁，不管他们有多复杂。

        Resecurity 专注于情报驱动的解决方案。公司投资于大数据、人工智能、数据科学。在网络犯罪、APT活动、威胁发起者的复杂调查带来独特投资价值。  

       Resecurity 的大部分工作是研发。公司研究最新的技术和网络罪犯及国家资助的攻击者的技巧，分析大量数据来改善产品。  

      公司的目标是为任何规模的组织实现网络安全革命，让他们更安全。在Resecurity，保护他们的客户是公司的承诺和激情。

勒索软件已经变成最危险威胁  

  

        今天，勒索软件位居组织担心之首。大多数网络专家（55%）甚至认为恶意软件和勒索软件是一个“极端”威胁。这个威胁不会很快消失。在接下来12月内，75%的受访者相信恶意软件和勒索软件将变成组织更大的威胁。

![](../Images/0c0182d841f11f944ed939c607c19725.png)

勒索软件攻击形式  

  

        网络罪犯持续使用经典的社交工程技术，包括钓鱼电子邮件（61%），电子邮件附件（47%），用户访问恶意网站（39%）使他们勒索软件攻击代码进入组织。

![](../Images/fd09f0e2ba3a2435d55dc2aae8482cb1.png)

检测恶意软件  

  

        为了检测潜在勒索软件威胁，IT和安全团队主要依靠端点工具（82%）。

![](../Images/ec3ad92e8af57f3d6c63d5e3282ef6c9.png)

  

勒索软件响应

  

        为应对勒索软件攻击，组织采用隔离方法（77%），或者主动关闭系统（56%）阻止正在进行的攻击。

![](../Images/66300c3ff424374498f0f53c8cb84232.png)

  

       

阻止勒索软件攻击  

  

        我们询问组织，他们现在如何防范勒索软件攻击，超过一半（55%）的受访者备份关键文件和数据，三分之一（29%）实施了零信任架构。

![](../Images/6722d6d849040f7ff31f1968752a5e50.png)

  

![](../Images/c8040f58a408c46f18ca7520cbc9e2d4.png)

        Bitglass，Forcepoint 子公司，提供行业内唯一真正集成的云原生安全服务边缘（Secure Service Edge，SSE）平台，当组织转移到云时，保护对信息的访问和使用。公司把最好的云访问安全代理（Cloud Access Security Broker，CASB）,安全Web 网关（Secure Web Gateway，SWG），零信任网络访问（Zero Trust Network Access，ZTNA），云安全态势管理（Cloud Security Posture Management，CSPM）结合到一起，并加上数据防泄漏（Data Loss Prevention，DLP）功能，帮助组织在访问Web、云、私有数据中心时通过单一控制台定义和管理，实现统一的安全策略。

        Bitglass 安全服务边缘（SSE）平台补充了Forcepoint数据优先的安全访问f服务边缘（Secure Access Service Edge，SASE）架构，极大地简化了客户在任何地点和任何设备上，实现安全和有效地访问、保护及使用数据。
