# AWVS批量添加目标并同时联动Xray

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NDUxMTI2NA==&mid=2247485003&idx=1&sn=585b548baff9da81eeebe71e4f290fe1&chksm=a687e68491f06f92f1a0ed1856ae82bbb526e4f94f80fa3174a76478ce8b499f64564b69cac1&scene=126&sessionid=1681663449#rd](http://mp.weixin.qq.com/s?__biz=MjM5NDUxMTI2NA==&mid=2247485003&idx=1&sn=585b548baff9da81eeebe71e4f290fe1&chksm=a687e68491f06f92f1a0ed1856ae82bbb526e4f94f80fa3174a76478ce8b499f64564b69cac1&scene=126&sessionid=1681663449#rd)

     闲着无聊，之前一直想看看能不能awvs批量添加的同时并联动到xray。于是今天就拿了之前网上下载的awvs批量添加的脚本改了改（感谢这位老哥的脚本）；

  

    然后划水的同时就改好了！！！  

    给大家演示下怎么玩！！  

    首先我先用aipang1.py采集一个目标的旁站  

    python3 aipang1.py

![](../Images/391c2d09dfdfd51422bc26afd6bd024d.png)

    假设这个站是有旁站采集到了很多目标，会在脚本的目录生成一个ok.txt，采集都放这里了  

![](../Images/23d5b13a52b5363b36618635f6a26413.png)

假设这是我们的目标！

  

然后打开awvsxray.py，先把本机的awvs账号密码修改好，在678行

![](../Images/3063a9cdfa8ffcd5a1d8c7253921ebae.png)

  

同时也可以修改你的xray端口和awvs的ua，在53行，这里我配备了百度爬虫的ua；

![](../Images/8b171b234658574874c78a5d1b7e7b19.png)

  

    然后打开xray监听，

.\\xray\_windows\_amd64.exe webscan --listen 127.0.0.1:7777 --html-output awvs.html

我这里监听的127.0.0.1:7777

![](../Images/1390405bb0420f1e8268d51e019efca8.png)

  

然后运行 python3 awvsxray.py -x ./ok.txt

![](../Images/b15d81efad01af75545822ca59c42165.png)

  

    然后就跑上了

![](../Images/a1bd3e605975883073dd890cc2775ac3.png)![](../Images/dffac154452ff03a8ac64afcf9514eea.png)![](../Images/e3bc228d5d48905b39d20820da333c73.png)  
  
脚本下载链接：https://github.com/Xiaoke-aas/PythonTools  
  

  

如果不需要联动，只awvs批量添加，就python3 awvsxray.py -f ./目标txt  ！！！！

  

脚本是修改大佬之前awvs批量上传的脚本，不是本人开发！！
