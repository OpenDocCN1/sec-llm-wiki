Dirsearch--目录扫描工具

dirsearch是一个基于python的命令行工具，用于进行web目录扫描。其中包括网站中的目录、备份文件、编辑器、后台等敏感目录。Dirseach的多线程和递归扫描功能很好用。

001-安装配置

该工具可以在任何操作系统上运行，Windows/Mac直接下载脚本即可使用（注意该工具依赖python3环境）。这里演示kali系统下的安装：https://github.com/maurosoria/dirsearch

apt-get update#更新所有存储库git clone https://github.com/maurosoria/dirsearch#安装

＃python3 dirsearch.py

 


#转到bin目录，并使用ln -s  命令创建一个符号链接，将其命名为“dirsearch”。创建符号链接后，在任何目录中键入dirsearch即可执行该工具

ln -s ln -s〜/ dirsearch / dirsearch.py dirsearch

 

002-常用扫描参数

-h    #查看工具参数

 


-u  #指定扫描目标网站URL

-e  #指定扫描目标的脚本类型

-e|–extensions asp,php    #指定扫描多种后缀

＃dirsearch -u http://xxx.com -e php

 

-x    #排除指定HTTP的状态

如下图。上面扫描到的403状态文件已经没有了。

＃dirsearch -u http://xxx.com  -e php -x 403

-w    #指定字典文件

kali中默认字典路径:/usr/share/wordlists/

 

-r    # 对目标网站进行递归扫描

＃dirsearch -u http://xxx.com -e php -x 403,301,302 -r


-R   #将递归级别设置为更深的值,如：

dirsearch -u http://xxx.com -e php -x 403,301,302 -r -R 3

 


Nmap--端口扫描之王

下载地址：https://nmap.org/download.html；简单安装即可使用。

namp主要用于扫描网络设备开放的网络连接端口情况。 Nmap参数繁多，日常渗透通常使用不到那么多，根据什么时候要用什么时候再百度原则。以下针对常用的命令进行列举：

-A ：全面扫描-T4：指定扫描过程使用的时序，总有6个级别（0-5），级别越高，扫描速度越快，但也容易被防火墙或IDS检测并屏蔽掉，在网络通讯状况较好的情况下推荐使用T4-oA test.xml:  将扫描结果生成 test.xml 文件，中断后结果也可保存-oG test.txt:  将扫描结果生成 test.txt 文件-sn : 只进行主机发现，不进行端口扫描-O : 指定Nmap进行服务器操作系统版本扫描-sV: 指定让Nmap进行端口对应服务信息扫描-p <port ranges>: 扫描指定的端口 ，：-p 1-65565/-p-全端口扫描-Pn   不进行ping扫描。服务器禁ping时可以使用-sP   用ping扫描判断主机是否存活，只有主机存活，nmap才会继续扫描-iL 1.txt : 批量扫描1.txt中的目标地址-v    在扫描过程中显示扫描的细节，从而让用户了解当前的扫描状态-F    快速模式，仅扫描TOP 100的端口


常用组合：

nmap 192.168.1.0/24 -excludefile 1.txt  #扫描除给定文件中的地址以外的其他地址nmap -sV -v -p- -oA 1.xml -iL 1.txt#扫描1.txt中的IP保存在1.xml

推荐一个nmap扫描xml转xls的小脚本，很好用。如果有大量资产需要进行端口信息收集并整理时可使用 ：

下载地址：https://github.com/mrschyte/nmap-converter

 


Hydra--万能爆破神器

Hydra多种服务的账号和密码进行爆破，包括Web登录、数据库、SSH、FTP等服务，支持各种操作系统安装，其中Kali Linux中自带Hydra。

windows版本下载地址：https://github.com/maaaaz/thc-hydra-windows

 

使用公式：

Hydra –L 用户名文件路径 –P 密码文件路径 -t 线程 –vV 详细显示 –o 指定生成文件路径 –f 找到密码就停止 –e ns 空密码和指定密码试探 ip service 爆破服务


-h#查看工具命令详解-l <登录>：小写，指定破解的用户，对特定用户破解-L <文件>：大写，指定用户名字典-p <PASS>：小写，指定密码破解，少用，一般是采用密码字典-P <文件>：大写，指定密码字典-e <ns>：可选选项，n：空密码试探，s：使用指定用户和密码试探-o <文件>：指定结果输出文件-f：在使用-M参数以后，找到第一对登录名或者密码的时候中止破解-t <任务>：同时运行的线程数，默认为16-w <TIME>：设置最大超时的时间，单位秒，默认为30s-v / -V：显示详细过程


hydra -L user.txt -P passwd.txt -o ssh.txt -vV  1.1.1.1 ssh    hydra -L user.txt -P passwd.txt -o ftp.txt -t 5 -vV 1.1.1.1 ftphydra  -L user.txt -P passwd.txt -V 1.1.1.1 rdphydra -P password.txt redis://1.1.1.1:redis端口号hydra.exe -l sa -P pass.txt 1.1.1.1 mssqlhydra.exe -L user.txt -P pass.txt 1.1.1.1 mysql
