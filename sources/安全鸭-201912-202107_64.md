##      原理

1.  此漏洞涉及到部分Windows10和Windows7系统。在开机状态下连续按下5次shift键，弹出下图中的提示，说明存在此漏洞。可以破解系统密码。![](../Images/cea1b16db2a90492ffc3f6f4e04b95e1.png)
    
    *   
    
    ```
    `c:\windows\system32\sethc.exe`
    ```
    
    在未进入系统时，可以通过该漏洞篡改系统文件名。连续按5下SHIFT键运行，并且此时应用程序会以WINDOWS的最高权限－SYSTEM权限运行sethc.exe，这里我们将sethc.exe替换成cmd.exe，从而达到破解Windows开机密码的目的。
    
2.    
    **漏洞利用过程**1.重启Windows系统，在出现windows启动界面图标时强制关机：****![](../Images/f2bd3f46946458f444d814a0843832e2.png)****2.再次启动Windows系统，出现如图所示界面。我们选择“启动修复(推荐)”。
3.  备注：如果没有出现该界面，应该是上一步重启的时机不对。手速和时机都很重要
4.  ![](../Images/adb3ee67f31546ac976b768736c03f8e.png)

  
    3.出现系统还原提示，点击取消![](../Images/88291d9932214354b327f3fa61230912.png)  
4.等待一段时间后，出现启动修复框，点击查看问题详细信息。  
![](../Images/bda4fca98c71ab68125668be6579278e.png)  
5.点击图中url:X:\\windows\\system32\\zh-CN\\erofflps.txt。![](../Images/722e7b2a290ae476eaf1e94a3f793bcb.png)  
6.在该文件下依次点击：文件》打开》![](../Images/5b173e5535feb64dec7de1cbe17b5fc5.png)  
  
7.找到目录：c:/windows/system32，文件类型框选择所有文件![](../Images/c2793ded7c6ade5c1df1dccbc6e0d32b.png)  
8.在c:/windows/system32/文件夹目录下将sethc重命名为test。将cmd重命名为sethc。完成后关闭命令框。重启windows系统。![](../Images/1654a9755120337cf200ced3a7ff4a98.png)9.系统启动后在锁屏界面连续按下五次shift键，弹出cmd命令框。
