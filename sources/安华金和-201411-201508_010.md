# 安华金和CEO笑谈安全行业创业

创业型公司或者发展型公司都会犯错，关键是在犯错时企业经营者的态度会是怎样的，没有企业在创业发展过程中是一帆风顺的。前期犯错使我们早点经受这种煎熬，经历了这样的煎熬后，现在的很多事，用时下流行的一句话说“那都不叫事”。

安华金和专注于数据库安全，6年成长历程，让这家技术型初创企业开始在市场上频繁崭露头角。以四款成熟型数据库安全产品占据市场，数据库漏扫，数据库防火墙，数据库加密和数据库审计。覆盖了数据库事前、事中、事后的三层防御。最近，安华金和数据安全产品上云的方向上发力，同时发布了一款名为DBHacker的数据库漏洞验证工具，让用户直观感受数据库安全风险问题。

谈及创业过程，公司创始人兼CEO刘晓韬怀有一颗乐观的心回忆当初，每个人在创业中都有不同的诉求，这些诉求有些还是相冲突的，冲突时怎么办，能不能合理的摆正自己的心态和位置，这都很重要。安华金和创业时，曾经一度号称“创业十联盟”，现在最后剩下3人，走了7个。创业当中，大家在认识上、心态上能否达成一致时需要面对的一些很重要的东西。 

![](../Images/af038ba09500a05c226182e9528c3d47.png)  

当记者问到，能否给现在进入安全行业的创客们，提出一些建议，刘总这样答道：“我不是以一位成功创业者的身份提出建议，而是为避免让大家过早的死掉有感而发：

一是团队，团队来讲，不是所有人都适合做安全行业的创业，我觉得安全行业的创业更适合一些技术型出身的人来进行。当然创业团队里有销售市场型的人员加入进来更好一些，会在市场需求方向上给予好的建议。但一定得是技术性人员做主导。因为这是以技术为基础的行业，而不是以商业模式为主导的行业。

二是方向，不能过度选择市场已经大热的产品。创业一定要找出一些新的行业突破点，哪怕是一些细分市场上，这一块可能现在没显现，但未来比较有前景的。现在谁要再去做防火墙，IPS、IDS，虽然市场空间很大，但格局已经很清晰的，已经被大厂拿走了。这两年真正能发展起来的新厂，往往是在新的市场上还没有被一些新的成熟的厂商瓜分掉。

安华金和做数据库安全，也规避掉了大厂的方向。现在还有一些在做手机安全的，这都是一些传统厂商已经形成了很固化的格局分割的状况。所以选择宁可选新，不要选看起来市场空间很大，但已经是很成熟的市场。

三是节奏。我们往往看toC的企业一下子融几千万，上亿，人员规模一下子从几人、几十人、几百人、上千人、上万人迅速的膨胀，因为2C本来市场单量就很大，而且是资本催熟型的发展模式，它需要的是迅速的扩大，有品牌，迅速的加深客户黏度。本质上安全行业需要的节奏更为平缓，而且市场发展的利润增长率也不会很过度，一年10倍的增长，可能性不大。一年能做到100%增长，速度算相当不错的。所以做安全行业得静下心来，好好思考行业本质是什么，技术本质是什么，打算用什么样的节奏去发展，目前在安全行业成功的企业基本上都有10年以上的历史，10年以下的成功历史非常少。安全行业不要跟toC市场拼速度、拼节奏，要静下心，要扎得下马步慢慢前进才行。这就是我对安全行业创业者的建议。

成功的企业各有各的成功之道，随着企业向前发展，适度转变自己的思维，逐步找适合自己企业的节奏感，在大众创业，万众创新的新时代，安华金和期待自己以及各位创客们，距离成功更近一步。
