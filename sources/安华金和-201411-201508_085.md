# 揭秘美国国安局（NSA）“天网计划”

The Intercept披露，美国国安局（NSA）一项名为“天网（SkyNet）”的计划可以基于个人所处位置、拨打电话的地点、时间及去往相关地方的频率分析和寻找恐怖主义分子。

此外，天网还拥有基于行为的数据追踪分析能力，例如手机是否只接听电话、目标经常更改SIM卡或设备，手机是否离开网格或者经常关闭。  

ps：天网(Skynet)是电影《终结者》里一个人类于20世纪后期创造的以计算机为基础的人工智能防御系统，最初是研究用于军事的发展，后自我意识觉醒，视全人类为威胁，发动了审判日。Cyberdyne Systems公司在电影里是天网的制造者。

联合合作项目

The Intercept报道称，NSA的天网计划依赖“地理空间、地理时间、生活模式以及旅行分析对大规模的DNR（拨叫号码识别）数据进行分析，以识别出可疑活动。

天网计划似乎来源于五个云研究组织的共同努力，其中主要包括三个NSA旗下组织——信号情报局、研究局、及技术局。该计划的合作伙伴包括麻省理工学院林肯实验室以及哈佛大学。而来自TMAC（旅行和流动分析中心）的团队也参与了天网计划。

另一份名为《天网：基于机器学习的情报检测》的文档指出，NSA使用来自巴基斯坦GSM（全球移动通信系统）运营商的5500多万手机通话记录的元数据来测试系统。

记者被误判为恐怖分子

天网计划的目标是找出与基地组织及塔利班相关的人员。然而，其中一名满足天网对于恐怖分子组织（基地组织及穆斯林兄弟会）成员所有识别指标的人员居然是一名非常受人尊敬的记者Ahmad Muaffaq Zaidan。这名记者是伊斯兰堡半岛电视台的领导人。

作为记者，Zaidan有着一个广泛的通讯录网络，允许他采访多名包括本拉登在内的基地组织领导人。被天网系统“误判”为恐怖分子让他非常愤慨：

```
“通过通讯薄、通话记录日志或来源就声称我自己或其他记者与任何组织有关是对事实的荒谬曲解，也完全是对记者行业的侵犯。”
```
