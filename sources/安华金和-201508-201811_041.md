在DB-Engines刚刚发布的“2018年7 月全球数据库排名”榜单上，前三依然是 Oracle、MySQL 和 Microsoft SQL Server 。 尽管较去年同月和2018年6月走势有所下滑，但Oracle的榜首地位始终没能被撼动。  

![](../Images/89dd23d1faddb76cec70bc6def11ce6e.png)

 那么，今天我们就站在数据库安全的视角切入，来全方位认知这个用户群体庞大，始终保持市场占有率和覆盖面领先的品牌。  

  

**Oracle 数据库经历了几十年的演进，无数个版本更新和漏洞修复，但它的几个关键组件仍然最容易受到攻击，且一旦被攻破就会对数据库造成不可弥补的伤害，同时带来巨大的损失。**

  

为了让广大Oracle用户对这些漏洞以及针对这些漏洞的防护手段有更加深入的了解，安华金和数据库攻防实验室数据库攻防专家刘思成特别录制了《Oracle数据库防护》系列课程。

  

本课程会给出Oracle最基本的安装配置；对Oracle各个组件进行详细漏洞分析；针对性地给出防护建议。系列课程具体覆盖Oracle的TNS漏洞与防护、XBD漏洞与防护、PL/SQL漏洞与防护、SQL注入漏洞与防护等专题课程。  
  

详细课程目录如下：

Oracle数据库的安装与配置

Oracle数据库的组成与易被攻击组件

Oracle数据库TNS漏洞与防护

Oracle数据库XBD漏洞与防护

Oracle数据库PL/SQL漏洞与防护

SQL注入漏洞威胁与防护建议

SQL注入分类及防护建议

  

**想要进阶成一名资深的DBA，马上进入公开课，开启这场干货满满的学习之旅。**

安华金和数据库攻防实验室（DBSec Labs）于2010年11月成立，是我国一支独立的、持久的针对数据库安全漏洞、数据库攻击技术模拟和数据库安全防护技术进行研究的专业队伍。

01

**DBSec Labs研究职责**

*   对数据库安全漏洞进行研究，是DBSec Labs的首要职责
    
*   黑客数据库入侵手段研究
    
*   数据库防护手段研究
    

  

02

**DBSec Labs部分成果**

截止2017年10月，安华金和攻防实验室向IBM、达梦、Gbase等数据库厂商提交并获认证的数据库漏洞共13个，其中包括1个超高危漏洞、3个高危漏洞，及9个中高危漏洞。
