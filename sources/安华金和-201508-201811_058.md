# 高考在即，教育行业全面开展业务系统与数据安全检查

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MTQwNTQxMg==&mid=2650777001&idx=1&sn=137d869998362a30b50a2d13d41a8394&chksm=87251fa2b05296b4a82ee37b3201c731cde849ed42fc03ee69a0cd6c08cf0f530e99e67eb4df&scene=126&sessionid=1681266657#rd](http://mp.weixin.qq.com/s?__biz=MzA3MTQwNTQxMg==&mid=2650777001&idx=1&sn=137d869998362a30b50a2d13d41a8394&chksm=87251fa2b05296b4a82ee37b3201c731cde849ed42fc03ee69a0cd6c08cf0f530e99e67eb4df&scene=126&sessionid=1681266657#rd)

2018年高考在即，教育部会同国家教育统一考试工作部际联席会议成员单位，分赴部分省份开展高考安全督查。在各地自查的基础上，督查组将针对涉及考试安全的重要环节进行抽查。

此次检查的一块重点内容就是网络信息安全：检查计算机系统和数据安全防护以及其他相关安全保障措施落实情况，严防考生信息泄露。那么，相关单位如何应对这次检查呢？

 

1、防护措施

要有一定的计算机系统及数据安全方面的防护措施。比如：

*   重要应用及数据的访问控制、入侵防御
    
*   数据库审计
    
*   数据及时备份
    

 

2、安全管理制度与技术措施

对能够接触到考生信息的各个环节要严加防范，通过安全管理制度及安全技术措施进行加强保护，防止考试信息的泄露，防止“徐玉玉”式的悲剧发生。防止数据泄露的安全技术措施有：强身份验证，如双因素认证、数据操作防护及审计、数据操作权限最小化管理及数据加密。当然也要通过一些数据库防火墙等其他技术措施防止数据被黑客入侵非法获取。

 

3、合规性

随着《网络安全法》正式颁布实施一年时间，有关进一步加强等保建设等法规与战略也相继出台，需要及时做好合规性工作，比如等级保护工作等政策性要求的工作，这些工作都是国家法律法规或者行业主管单位要求必须开展的工作，做好这类工作，才能打个良好的基础。

 

4、安全检测

专业的安全检测服务是必要的。最好请专业的第三方机构通过技术手段去提前对自己的重要信息系统进行安全扫描、渗透测试，及时发现现有系统存在的安全隐患，如高危漏洞、系统安全功能缺陷、防护策略不当等问题，并做出及时修复，防止相关潜在风险被黑客利用导致数据被窃取。目前安华金和的数据库漏扫系统成功接入等保2.0标准测评专用工具。可以帮助测评机构对被测评企业、组织完成数据库的安全风险评估并提供修复应对意见。

 

5、应急响应

驻场运维及应急响应工作是最后一道防线。道高一尺魔高一丈，我们不能保证绝对的安全，但是我们要做到安全可控，我们要做好最坏的打算。万一现场发生黑客攻击破坏等网络安全事件，要怎么办？这时候就需要及时发现网络攻击破坏行为，并最快地控制住网络安全事件的影响范围，查明原因，消除威胁，及时对应用进行恢复，将网络安全事件带来的负面影响降到最低。安全运维这块也可以通过数据库运维等技术做好内部的运维管控工作，防止内部人员违规操作带来的安全风险。

以上几点仅供参考，并非标准答案，还要视自身实际情况加以灵活运用。

一直以来，以教育部为中心的教育行业信息化建设较之其他行业，相对领先。与此同时，教育部对信息安全建设足够重视，目前已经在数据安全保障建设方面做了大量工作。安华金和作为专业的数据安全厂商，凭借在数据库安全领域的深厚积累和高质量产品，已经成为教育部信息化安全建设项目的得力合作伙伴。后续我们会分享客户案例，供更多用户参考。
