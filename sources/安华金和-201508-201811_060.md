# 安华金和漏扫工具接入等保2.0标准测评专用工具

等级保护进入2.0时代，新增云计算安全、移动互联安全、物联网安全、工业控制安全相关的标准要求。近日，为了规范开展新标准测评工作，对接即将发布的等保2.0测评标准，中关村信息安全测评联盟发布“等级保护测评作业工具”（又名“测评能手”）。目前，工具最重要的模块之一“漏洞审计”已经完成与专业漏扫产品的对接适配。

  

安华金和数据库漏洞扫描系统DBScan目前已经成功接入，将为等保测评工作提供专业的数据库安全检测支撑。

  

![](../Images/32d90b6db5223fd49064e9934f20cc90.png)

  

“漏洞审计”是当前等级保护测评报告的重要组成部分，用于描述测评机构在渗透测试过程中发现的高危风险问题。“漏洞审计”模块是基于开放的标准XML格式，扫描工具厂商需要根据此格式生成XML，与测评能手兼容对接，此外还需要支持诸如NESSUS、APPDetective等国外工具CSV文件的导入，具备完善的安全漏洞库，从而提升测评机构实施渗透测试的技术能力和工作效率，满足等级测评实际需求。

  

2017年6月1日实施的《网络安全法》第三十八条明确规定:“**关键信息基础设施的运营者应当自行或者委托网络安全服务机构对其网络的安全性和可能存在的风险每年至少进行一次检测评估**”。这要求不仅测评机构需要定期对企业和组织的信息化系统进行安全测评，大量的关键信息系统基础设施的运营者或者网络安全服务机构都需要时常使用测评工具自查，确保即使发现系统中的高风险漏洞和安全配置缺陷。

  

截至2018年5月，全国等级保护测评机构推荐目录中的167家测评机构已广泛使用等级保护测评作业工具开展等级测评，工具的使用带来的绝不仅是效率的提升，这些结构化、痕迹化的数据更是今后开展大数据分析的基础。

  

**等级保护1.0时代，安华金和数据库漏扫系统DBScan已经是等保检查工具箱的数据库安全测评专用工具。迈入****等保标准全面升级的****等级保护2.0时代，安华金和的数据库漏扫系统DBScan再次入选，**并将继续发挥产品优势，协助测评机构完成对企业和组织的安全测评，帮助被检测机构（广大关键信息系统基础设施运营者或者网络安全服务机构）发现数据库中的弱安全配置、风险代码、弱口令，对已知漏洞进行分析和模拟渗透攻击，有效暴露当前数据库系统的安全问题，并对数据库安全状况的持续监控，从而完成数据库安全风险评估。

  

安华金和数据库漏扫系统DBScan之所以持续入选成为等保测评专用工具，是因为产品具备突出优势：

*   数据库类型支持全面，能够支持七种国际主流数据库和三种国产数据库的安全检测。
    

3）数据库安全检查技术先进

*   支持多种数据库自动化检查技术和网络数据库发现技术，不仅提供数据库服务器发现，还提供数据库实例发现，实现多种DBMS的密码生成技术，提供1万多个口令爆破库，实现快速的弱口令检查方法。

5）自身安全性高

*   管理员、操作员、审计员三权分立；使用只读权限账户即可扫描；检测报告中数据库连接信息、口令等加密存储。
