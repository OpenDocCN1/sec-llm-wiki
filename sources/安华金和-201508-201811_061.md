# GDPR来了，年收入4%的天价罚单如何避免？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MTQwNTQxMg==&mid=2650776992&idx=1&sn=4c2c02a8ea8a1bac0835c685331d50e7&chksm=87251fabb05296bd2e0bde0f3e645d7f43da47e020295e1a1dfb6579800b40d8caca70131fa7&scene=126&sessionid=1681266657#rd](http://mp.weixin.qq.com/s?__biz=MzA3MTQwNTQxMg==&mid=2650776992&idx=1&sn=4c2c02a8ea8a1bac0835c685331d50e7&chksm=87251fabb05296bd2e0bde0f3e645d7f43da47e020295e1a1dfb6579800b40d8caca70131fa7&scene=126&sessionid=1681266657#rd)

  

![](../Images/42c71af28a4588a8ace33a92fa8a5cc8.png)**GDPR来了**《通用数据保护条例》General Data Protection Regulation被称之为“史上最严的隐私条例”，该法案将于明日正式生效，核心目标是对自然人个人数据进行保护。此为目前全球最先进的隐私保护法规，触犯可能会导致高达企业年收入4%的罚款。在如此令人难以置信的高额罚款之下，违反GDPR的后果将让大多数公司无法承受。

  

![](../Images/b4aec58c2fcb5ee1ef47de44bd0a6bd2.png)

  

![](../Images/42c71af28a4588a8ace33a92fa8a5cc8.png)**和你有关吗？**

GDPR是欧盟的主要数据治理规则，适用于所有使用欧盟相关数据的公司，所有自认为或即将成为全球性公司的企业主都难以逾越该法案。事实上，无论公司总部在哪儿，无论数据存储和处理地点在哪儿，只要与身处欧盟的人做生意，或者监视欧盟公民的行为，就必须遵从GDPR。进一步讲：如果你收集欧盟公民的数据，你就受到GDPR的管辖。除非你的公司非常严格地排除了欧盟国家业务，否则终将面对GDPR合规问题。由此可见，该GDPR适用的范围十分广泛。

  

GDPR不仅涉及在欧洲有实体的公司，还涉及其它在欧洲有收入的公司及其规范的行为：从数据收集、数据存储、数据处理、数据跨境传输（向欧盟境外的传输）等各个环节都做出系统规范。其中，数据跨境传输可能对于跨国企业的影响最为明显。

  

  

![](../Images/42c71af28a4588a8ace33a92fa8a5cc8.png)**企业准备好了吗？**

据某调查显示，**真正满足条例合规要求的企业只有2%，**这一比例差距之大，表明大多数企业对条例应对准备存在一定的误解。令有一项调查结果显示，**高达96%的公司承认她们并不理解GDPR的规定****。**可见，无论是让绝大多数企业、组织了解GDPR的各项规定，还是根据这些规定来进行企业自我评估、改进，继而满足条例合规要求，接下来都将是一项长期艰巨而事关重大的事情。

  

作为一家致力于数据安全使用的厂商，安华金和从去年已开始持续关注GDPR法案的合规要求，并结合自身专业予以解读，接下来，请跟随我们持续关注这个话题，通过多种形式快速了解、学习、应对GDPR：

遵循以下几大步骤，让你有条不紊的迎接GDPR：

**1、评估你的情况**

比如，以5个GDPR成熟度级别为标准进行自我评估：

*    您还没有开始解决一个特定的要求(1级)。
    
*   您已采取了最低限度的措施来解决1个要求(2级)。
    
*   您已经确定了必要的流程(3级)。
    
*   您一直在测量和控制这些流程(4级)。
    
*   您不断评估和改进这些流程(5级)。
    

**2、设计你的流程**

**3、改变你的做法**

**4、运作你的计划**

**5、符合GDPR必要要求**

  

比如，具体到如何对现状加以评估，如何对流程加以设计，如果改变做法和运作何种计划，从而符合GDPR必要要求，作为数据安全企业，安华金和将基于自身专注的领域给出应对建议。
