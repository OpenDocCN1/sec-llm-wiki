# SQL Server最佳安全配置指导手册

目前，Microsoft\_SQL\_Server数据库由于其高可靠性和易用性而成为世界上知名数据库之一，它被广泛使用在各个行业。像大多数产品一样，Microsoft\_SQL\_Server安装极其简单。通常，在安装这种产品时安全性不是主要的考虑因素。然而，正是这种“漫不经心”，可能会招致较大的安全隐患。

为了提前应对安装环节留下的潜在安全隐患，解决广大Microsoft\_SQL\_Server数据库用户常遇到的安全配置问题，安华金和攻防实验室安全专家基于对数据库安全配置的深入研究，编写了《Microsoft\_SQL\_Server最佳安全配置指导手册》，希望能够帮助用户快速进行Microsoft\_SQL\_Server数据库部署的同时，完成Microsoft\_SQL\_Server的安全配置，从而帮助用户抵御大多数常用形式的黑客攻击行为。  

![](../Images/0fdbb1136ecf7c47e71c7bd7578df8ce.png)

该指导手册选取现今最流行的Microsoft\_SQL\_Server\_2016版作为安全配置演示对象。所有安全配置项都会向大家展示检测方式和修补方法，以帮助Microsoft\_SQL\_Server用户快速判断是否存在配置问题，并采取必要的工具和手段进行修补。

  

**Microsoft\_SQL\_Server数据库的安全配置项涵盖了以下五大类：**

1、安装和升级的安全配置

2、数据库基础组件安全配置

3、身份验证与授权安全配置

4、审计和日志安全配置

5、加密安全配置

作为国内首款等保专用数据库风险等级评估检测工具，安华金和的数据库漏洞扫描系统是一款检测项达到4000+的数据库安全检测产品，可完成对以上全部安全配置项的检测和提供专业的修复建议；再辅以《Microsoft\_SQL\_Server最佳安全配置指导手册》给出的修复方法，帮助用户做好数据库安全风险评估，更好地提升数据库的安全状况。
