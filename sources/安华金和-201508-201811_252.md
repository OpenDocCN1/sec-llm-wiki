# 安华金和参加阿里云先知白帽大会——安全的渴望在云端

由阿里云云盾先知主办的先知白帽大会上周在京圆满结束，这是一场汇聚安全行业大咖，凝聚公益之心，集结技术干货，表达安全与信任渴望的暖心盛宴。安华金和作为阿里云战略合作伙伴受邀参会。

![](../Images/7d757acce8dd4c682a2acaed8b6977cb.png)

作为一家技术型驱动的数据安全企业，我们对这场大会若干议题的理念深以为然，比如提到安全意识，现场专家说：“安全意识是贯穿在信息安全建设的整个过程，意识的养成和重要程度一点不比管理和技术低，在做信息安全意识培训宣贯所秉承的理念是，将信息安全融入企业文化。”而这个观点，可以说和安华金和企业文化的使命“**让数据使用更安全**”不谋而合。

![](../Images/88d7c956fd553acfe270b0bf86330960.png)

谈到云上安全服务，现场也有观点认为：“云的好处在于把一些安全服务基础化，技术上讲更像是在更安全的框架上做开发，大公司把在安全方面的实践和经验转化成产品和服务，来弥补中小企业人才和成本上导致的安全空白。”安华金和顺应云计算发展的时代趋势，基于专业深厚的数据库安全领域的先进技术和实践经验，将长期的技术积累向云端数据安全防护领域转化，全面启动**云数据库安全业务**。

![](../Images/92ba35da712b4ddcd124f70f0da42889.png)

落实到地，现场我们就展示了三款云数据库安全产品——**云数据库审计系统、云数据库安全运维系统和云数据库加密系统（MySQL TDE）**。这三个产品因其突出的价值点吸引了不少关注度。技术创新永不止息，安全业务绝不松懈，云上数据安全防护更是云服务领域的重头戏。
