# 云市场持续发酵 安华金和成为阿里云安全潜力新星

“这是最好的时代，也是最坏的时代”。

  

虽然说2016年是资本的寒冬，但是我们互联网行业也一样在高速发展。根据艾瑞咨询最新数据显示，2016年中国企业云服务市场规模达到520亿，同比增长31.9%。2016年，阿里云总计融资额超过15亿人民币，其中在阿里巴巴在云数据安全市场的战略合作伙伴——安华金和获得5000万人民币融资，**安华金和也是阿里巴巴在云数据安全领域的唯一战略伙伴**。

  

2016，这一年，我们被“大数据”、“云计算”、“物联网”、“人工智能”等亮眼的名词包围着；这一年，数据安全问题事件，全球频发；这一年，企业上云的步伐越来越快；这一年，安华金和两款新品入驻阿里云市场，继云数据库扫描**（DBScan-EnCloud）**后，安华金和云数据库审计**（DBAudit-EnCloud）**、云数据库加密**(DBCipher-EnCloud)**上市，作为独立专业的第三方云数据安全厂商，为阿里云用户提供数据安全防护。

  

企业服务的应用，在DT时代的演进中渐渐趋向专业化和透明化。作为云端的产品与服务也会趋于专业化和透明化。针对企业数据上云的的趋势，作为专业的数据库安全专家——安华金和，意识到云市场有广阔的空间和市场，并将多年来对于数据库安全技术的积累，转化为云上实实在在的安全产品，真正实践安华金和“让数据使用更安全”的心愿。

  

这一切，需要一个良好的合作伙伴和生态链接。安华金和通过接入阿里云平台，与阿里云技术团队不断磨合和沟通，安华金和在阿里云实现了完全适配，快捷交付的产品部署。对客户而言，云市场的软件具有“直观、便捷、安全”的特点，对用户而言，意味着更加便利的用户体验、更高效的采购流程、更可靠的服务保障；对服务商来说，入驻云市场意味着与阿里云产品深度整合、更广域的销售通路（线上230万用户、20个行业以及4000多家渠道），更快的交付模式、更高效的单位产出。

  

安华金和创始人兼CEO刘晓韬——

DT时代，海量数据共享的同时也带来了数据安全的新挑战。安华金和从成立的第一天就以“让数据使用更安全”为己任，2016年安华金和同阿里云达成战略合作伙伴关系，同年进驻阿里云市场，向云数据安全的步伐又向前推进了一步。

  

自登陆阿里云市场以来，安华金和在云市场客户的转化率也超过了**80%**，对企业形象打造和产品链部署都产生了极大的促进。专注于数据安全，让企业“上云不再犹豫，数据使用自由而安全”，安华金和也将在云市场建立自己新的产品生态链。
