# 一场保险监管机构与数据安全厂商的跨界联姻 ——热烈祝贺中国保信项目成功验收

中国保信——以服务行业发展、支持保险监管、保护保险消费、辅助社会治理为使命，建设和运营安全高效的保险业数据信息共享和对外交互平台。中国保信坚持“信息凝聚行业理论 数据改变保险生态”的企业价值观，以“信息枢纽、数据基地、产业平台”为企业发展愿景，是整个保险行业的“信息数据聚集地”。由此可见，信息数据安全对于中国保信而言，重要性可见一斑。

  

跨界联姻

经历了4月份的调研分析、6月份的测试、8月份的公开招标，安华金和凭借着专业的数据库安全防护技术和出色的产品测试表现，在国内众多家实力不容小觑的数据安全厂商中脱颖而出，获得保监会下属的保险行业监管机构——中国保险信息技术管理有限责任公司（简称：中国保信）青睐。今年9月份，一场保险监管机构与数据库安全厂商的跨界联姻顺利达成，喜结良缘。在经历了一个季度的亲密磨合后，这场姻缘在12月12日——亲亲节这么热火的节日里成功验收。

安全现状

目前，中国保信已经建成和正在规划建设机动车辆保险、农业保险、健康保险、保险中介平台和保单登记等平台，其中车险平台基本实现了全国范围内机动车辆保险数据信息的汇集利用和交互共享，可在车险保费定价、车船税联网征收、代位求偿、反欺诈等方面发挥重要作用。中国保信车险平台，数据信息涉及的范围之广、规模之巨，足以引发企业对平台数据安全的高度重视。在车险平台建立之初、数据安全防护体系尚未搭建起来，数据库访问行为监管缺位，开发人员、测试人员等第三方外包人员甚至直接可以在数据库里获取到大量真实数据，数据泄露存在巨大风险。

  

匹配需求

为了加强自身平台信息安全、强化数据库安全监管、满足等级保护要求，中国保信引入安华金和的数据库防火墙产品对其车险镜像库加以安全防护。将数据库防火墙与车险镜像库串联，有效应对开发环境和测试环境下的数据安全威胁，防止数据泄露隐患，解决数据库访问行为无监管的弊端，同时又能满足等级保护要求。

  

价值体现

中国保信想要实现“成为服务不可或缺、安全值得信赖、品牌普遍认可的保险业基础设施建设者、信息服务提供者和数据生态营造者”的企业战略目标，需要以信息数据安全为基本保障，做好数据安全防护，可以帮助中国保信树立其行业监管的稳固地位，提升其行业信赖度和品牌认可度。

  

继续前行

与中国保信项目的成功联姻，是安华金和助力保险行业数据安全的重要实践，为安华金和拓延金融领域辟出更宽阔的道路，也为安华金和服务企业级客户树立了典范和标杆。安华金和将凭借着对各行各业数据安全防护的不断探索，以高价值产品成就用户数据安全，以专业服务，为用户数据安全保驾护航。
