# 安华金和与F5达成合作 安全自主可控大势不可逆转

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MTQwNTQxMg==&mid=2650774009&idx=1&sn=42930101f1d8c7ec2998d856599a3e31&chksm=872523f2b052aae42c2afa121fd4e59ffd7f06f7ff13bffe324d0d36bb833b63ee5384dd838e&scene=126&sessionid=1681266764#rd](http://mp.weixin.qq.com/s?__biz=MzA3MTQwNTQxMg==&mid=2650774009&idx=1&sn=42930101f1d8c7ec2998d856599a3e31&chksm=872523f2b052aae42c2afa121fd4e59ffd7f06f7ff13bffe324d0d36bb833b63ee5384dd838e&scene=126&sessionid=1681266764#rd)

**5月24日、26日两天，F5 AGILITY2016中国用户及合作伙伴大会，分别在北京、上海两地举行，安华金和与vmware、亚马逊、华为、听云、arista、亚信安全一起，面向广大用户及核心合作伙伴展开云上畅想。本次大会，安华金和与F5合作推出应用安全集成解决方案，并针对云安全方向的合作展开单独对话探讨。**

  

继棱镜门和光大乌龙指之后，国家对于信息安全的重视程度极具提升，信息系统与设备的安全性受到了空前关注，牵涉国家利益和商业信息的各行业数据库存储系统，很大程度上还是由国外厂商主导如Oracle的数据库，IBM的DB2，国家信息安全战略推进正在加速，信息技术领域逐渐国产化将成为明确趋势。F5作为美国原生企业，在中国市场的开拓中，特别是安全领域的战略转型中，无疑需要遵循本土化策略，提高自身市场适应度，为中国用户提供安全、可控的整体解决方案。与安华金和达成合作，F5主要基于应用安全管理产品(ASM)与安华金和数据库防火墙结合，从应用端到数据库端为各行业用户提供整体安全解决方案。

值得一提的是，F5此前在数据库安全领域与Oracle全球合作伙伴进行方案整合。这次安华金和取代Oracle，成为F5安全方向的本土合作伙伴联盟成员，足见安全自主可控大势不可逆转。

中国数据库市场中，Oracle占据60%的市场份额，金融、运营商、政府等重要行业大多使用Oracle数据库系统，使用Oracle数据库防火墙产品，相当于用自己的矛攻自己的盾，一旦提供商在系统中植入后门程序，无论从企业利益或是国家安全层面，核心数据安全存在巨大隐患。中国市场不可小觑，F5为实现本地化安全联盟合作，完美替代Oracle，安华金和成为不二之选，安华金和作为安全产业中唯一一家专注于数据库安全的领导品牌，也是国内最早将数据库防火墙(DBFirewall)推出市场的企业，从产品本身的成熟度和行业高端应用来看，历经国家人口库、国家发改委、国家开发银行、四川移动等大型数据库安全防护项目的检验，数据库防火墙技术优势及性能体验，堪称完美。

从技术路线来看，我们知道，数据库自身的补丁升级意味着系统重启，这对于用户关键业务系统来说，无法接受。安华金和为用户提供虚拟补丁功能，在数据库外的网络层创建了一个安全层，避免补丁升级带来的业务停顿，同时完成对主要数据库漏洞的防控，这是Oracle防火墙无法具备的。同时，相比Oracle数据库防火墙的应用程序SQL白名单机制，安华金和数据库防火墙主要基于对SQL语句精确解析，根据SQL注入的特征进行精准描述，以完成对SQL注入行为的检测和阻断。

由于不同用户的访问需求，安华金和数据库防火墙同时适用多个业务场景，应用服务器与数据库服务器之间的应用侧场景、维护人员与数据库服务器之间的维护侧场景，以及可能出现的双重场景混合情况。这也是Oracle防火墙不具备的。

从数据库防火墙对业务性能支撑的考量，产品应对万级数据库访问并发时，不影响数据库正常运行性能；并且安华金和数据库防火墙可以做到30000条/s的SQL语句压力下的安全防护。

安华金和是一家立足国内市场的本土数据库安全企业，除了产品成熟易用外，对于本地企业的技术服务支撑，安华金和提供7\*8小时应急响应，本地化的售后及研发团队为产品运行提供更具实效的有力保障。

**信息安全已提升至国家战略高度，安全可控成为首要条件。各行业核心数据均存储在数据库系统中，数据库安全的重要性不言而喻。本次F5与安华金和的战略合作，只是国际巨头进军安全市场拥抱本土合作伙伴的一个典型案例。未来，将会有越来  
越多的国际IT巨头不得不思考，如何与国内安全企业联合，共同符合国家政策导向的去适应国内信息安全市场发展。**
