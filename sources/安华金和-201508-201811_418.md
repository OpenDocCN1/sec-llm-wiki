# 年薪百万的DBA有哪些逆天技巧？

DBA高手就像扁鹊三兄弟一样：  
1.真正的高手是大哥从不让你犯病或身体不适；  
2.次等高手是二哥在您身体开始犯病或即将防病的前奏就治疗好；  
3.三等高手是扁鹊等你病入膏肓能起死回生  
对应而言一个资深DBA或者高手就要具备上面的能力，最佳的是大哥模式不过三等高手受多数企业的喜欢，见效特别明显  

**做到以下七点，年薪百万向你招手**  
1.懂主流开发或者曾经有丰富的开发经验，对各种语言多数了解，至少知道各自的优缺点及操作数据库可能会碰到的常见问题，也即要规避啥；  
2.对各类业务场景的业务知识要非常熟悉，可能使用的应用架构要非常熟悉；  
3.对普通和常用的运维架构要非常熟悉，硬件常识一定要掌握，操作系统及高可用等软件要熟知；  
4.对数据库软件产品的各类异常或称BUG要非常清楚，以及建立自己挑选软件版本及硬件平台的知识库；  
5.对数据库的架构设计及存储结构设计要非常熟悉，设计好表之后从不用担心研发人员写的SQL有问题，创建的索引有问题；  
6.从不抱有侥幸的心态，总是有未雨绸缪的心态和严谨度；  
7.拥有“无为而治”的技术理念；
