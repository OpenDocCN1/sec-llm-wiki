# 微信朋友圈“帮投票”？小心有毒

不少网友最近收到不少“帮宝宝投票”的信息，有人怀疑，这到底是真的还是假的？近日，记者从网络安全专家处获悉，一些木马病毒APP下载的网址常常被伪装成投票链接，收到此类信息的网友一定要小心，这里有可能是病毒，不要轻易点击。

![](../Images/0de53068f2fa31e5770de272020b7401.png)

朋友圈“求投票”链接暗藏木马

**微信投票最常见？要当心**

据 专家介绍，随着微信应用的普及，此类木马病毒经常改头换面进入微信朋友圈，用户稍不留意就会“中招”，这些带木马病毒APP一旦安装成功，手机中和支付相 关的短信就会被其偷偷转移走，不仅是短信验证码，连银行的消费通知用户也可能无法收到。因为无法接收短信，有的用户一直被蒙在鼓里，发生了上百笔诈骗交易 都浑然不觉。

目前，“帮宝宝投票”在微信朋友圈较为常见，有用户看到熟悉的朋友在其朋友圈上发此类信息，点击了网址链接，下载了里面的“微投票”软件，该病毒就在下载时传播出去，自动把“请求帮宝宝投票”的信息发送到通讯录的联系人上，并窃取用户信息。

**建议：手机别存储敏感信息**

手 机安全专家认为，拉票短信、违章查询、孩子成绩单、你的照片、你的订单、聚会相册等都成为近期诈骗短信传播木马病毒的重要手段，一旦手机用户点击这些链 接，就存在隐私泄露的风险。同时，如果手机中以短信，照片等形式存储了支付账号、密码、身份证号等信息，极有可能也被木马病毒一并窃取。他建议，手机用户 妥善保管好敏感信息，更不要在陌生网站填写支付信息，并安装安全软件进行防护。

**微信要包月收费？是假的**

近 期有不少人投入到微商销售中，广州的罗女士前天打算申请一个微信号作专门销售的账户，在申请过程中看到一个“微信多账号”的应用，下载后发现该应用提示 “支付包月后可以正常使用”，心存疑惑的罗女士随即向腾讯方面求证。微信团队表示，从未推出多账户管理应用以及需要收费的微信账户，该应用极有可能是木马 程序，建议罗女士到腾讯官方网站下载相关应用。

**建议：账号异常联系微信官方**

腾讯支付风控专家张平告诉记者，避免个人信息泄露是移动支付安全的关键。用户在使用微信支付及QQ钱包等支付工具时，一旦出现账户异常，应第一时间与腾讯风控团队联系，避免财产损失。
