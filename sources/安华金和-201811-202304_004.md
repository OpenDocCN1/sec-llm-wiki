# 安华金和荣获中国计算机行业协会数据安全专业委员会“优秀成员单位”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MTQwNTQxMg==&mid=2650784259&idx=1&sn=50f41fa84a4dbd96c27a41403b38e50c&chksm=87257808b052f11e159cc80c7f2f73aa846d1bf78aff3d09e263d64b29ddf5cded75f8410669&scene=126&sessionid=1681266377#rd](http://mp.weixin.qq.com/s?__biz=MzA3MTQwNTQxMg==&mid=2650784259&idx=1&sn=50f41fa84a4dbd96c27a41403b38e50c&chksm=87257808b052f11e159cc80c7f2f73aa846d1bf78aff3d09e263d64b29ddf5cded75f8410669&scene=126&sessionid=1681266377#rd)

近日，中国计算机行业协会数据安全专业委员会（以下简称“数专委”）工作组年度工作会议在京顺利召开。作为数专委成员单位，安华金和2022年积极参与数专委各项工作，**被授予“优秀成员单位”称号，并收获数专委感谢信**。

![](../Images/da999eca00578af25bbcdd9edcb86e19.png)

![](../Images/1e400728bb0709b3868ff994976d0809.png)

2022年是数据安全产业发展的奠基之年，为有序推动我国数据安全产业发展，在工业和信息化部网络安全管理局的指导下，在中国电子信息产业发展研究院的支持下，中国软件评测中心（工业和信息化部软件与集成电路促进中心）牵头发起成立中国计算机行业协会数据安全专业委员会，旨在凝聚产业多方力量共同构建数据安全产业生态，推动产业创新，做大产业规模，共享能力资源，夯实数据安全产业基础，护航数字经济高质量发展。

  //  

凭借在数据安全领域长期积累的技术和经验优势，安华金和积极承办并参与数专委沙龙活动，数据安全大赛、案例征集等各项产业活动，斩获2022年首届数据安全大赛“数据安全产品能力—数据识别”金奖、“先进技术应用案例”等多项荣誉称号。

作为首批加入数专委数据安全产业能力评价工作组、数据安全产业标准工作组和数据安全产业研究工作组的成员单位，安华金和将持续在产业研究、产业标准、人才培养、能力评价、成果转化等方向全力支撑各工作组的工作开展，分享自身在数据安全产业领域的经验，助力产业技术创新和生态建设，与数专委共同推进数据安全产业的高质量发展。
