# 数据安全“星选厂商”！安华金和荣列《CCSIP 2022 中国网络安全行业全景册》

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MTQwNTQxMg==&mid=2650783969&idx=1&sn=9c71c8a5dfa4e271b51bdf4848603552&chksm=87257aeab052f3fcf30767aef2ccf15cf2ec779eadf8fee8aca457a05f42e7b288a002d40256&scene=126&sessionid=1681266453#rd](http://mp.weixin.qq.com/s?__biz=MzA3MTQwNTQxMg==&mid=2650783969&idx=1&sn=9c71c8a5dfa4e271b51bdf4848603552&chksm=87257aeab052f3fcf30767aef2ccf15cf2ec779eadf8fee8aca457a05f42e7b288a002d40256&scene=126&sessionid=1681266453#rd)

![](../Images/d9e893ac25d50fb8b621bbfeeda90527.png)

2月1日，国内安全行业门户FreeBuf正式发布**《CCSIP（China Cyber Security Panorama）2022 中国网络安全行业全景册（第五版）》**。**安华金和入选9大类别22项细分领域，并荣列数据安全“星选厂商”。**

![](../Images/172239926c1ace5942620d81dc9e9f7c.png)

《CCSIP2022中国网络安全行业全景册（第五版）》 仍以PDR网络安全模型为基础，并参考IPDRR安全框架和P2DR2模型，在基础的Protection(防护)、Detection（检测）、Response（响应）三层逻辑上优化出第4层，即“持续改进”，形成“防护——检测——响应——持续改进”的安全闭环。在核心模型之外，另增加了网络基础安全与业务场景2个大类，构建完整的企业网络安全建设链，以此作为CCSIP全景册的顶层设计逻辑。

![](../Images/2eee0ab246ce29ea953ced9e3de1ad52.png)

此次的入选，安华金和保持了自身的赛道优势，并充分体现在数据安全领域丰富的产品体系、过硬的技术实力与专业的安全服务能力。

  

  

**入选领域一览**

**数据安全：**数据安全治理（解决方案）、数据库安全、数据脱敏、勒索软件防护、数据安全管控（平台型）、API安全  

**云安全：**云应用安全、云原生安全、云访问安全  

**应用防护：**Web 应用扫描与监控  

**内容安全：**恶意内容检测、舆情检测

**安全开发：**安全开发流程管控

**漏洞检测与管理：**漏洞检测、漏洞管理  

**安全情报：**漏洞情报  

**事件管理&响应：**风险及脆弱性管理  

**安全服务：**安全咨询与培训教育、渗透测试、风险评估、攻防演练、等保评测/咨询

连续多次入选《CCSIP中国网络安全产业全景图》，是业内机构与客户对安华金和技术、产品与服务的高度认可。目前，安华金和不仅打造出全栈式的产品和服务，还通过行业深耕和场景定制，推出了一系列贴近客户场景的解决方案，**总付费用户已达3000+家，被保护数据库累计1000000+**，用户遍及金融、医疗、政务、教育、能源、企业、运营商等各大行业。

  

  

  

  

在新形势、新机遇下，安华金和将继续立足数据安全领域，发挥技术优势，担负企业责任，紧跟时代发展脉搏，力争为广大行业客户提供更多更好的数据安全产品和解决方案，全力推进我国数据安全产业高质量发展！
