# 安华金和助力徽商银行获评2022（第二届）“金信通”金融科技创新应用卓越案例

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MTQwNTQxMg==&mid=2650783646&idx=1&sn=a6daff6d1b12ddd74f5c5f54fe205c94&chksm=87250595b0528c83c293d75724d0322dbb0368a83c79d42d73389984dc038e520b0b87730cd6&scene=126&sessionid=1681266461#rd](http://mp.weixin.qq.com/s?__biz=MzA3MTQwNTQxMg==&mid=2650783646&idx=1&sn=a6daff6d1b12ddd74f5c5f54fe205c94&chksm=87250595b0528c83c293d75724d0322dbb0368a83c79d42d73389984dc038e520b0b87730cd6&scene=126&sessionid=1681266461#rd)

![](../Images/4fa63f1783a7ea0f12d371b0ba3d1a59.png)11月17日，由中国信息通信研究院与苏州市金融科技协会联合举办的第五届中国金融科技产业峰会暨第四届中新（苏州）数字金融应用博览会在苏州国际博览中心开幕。会上，正式公布2022（第二届）“金信通”金融科技创新应用案例征集活动的评选结果，**北京安华金和科技有限公司联合徽商银行股份有限公司上报的《徽商银行敏感数据识别及安全评估》案例，****获评2022（第二届）“金信通”金融科技创新应用卓越案例。**

  

![](../Images/a2b6973534845df7803580bed512a025.png)  

本次案例征集活动旨在进一步推动金融科技高质量发展，健全适应数字经济发展的现代金融体系，汇集行业内典型的金融科技创新应用案例，形成一批可复制、可推广的金融科技样板项目，为政府、监管部门、金融机构和科技企业提供重要参考素材，推动我国金融科技生态健康发展。

  

徽商银行是全国首家由城市商业银行、城市信用社联合重组成立的区域性股份制商业银行，作为安徽省地方的金融主力军，在助力区域经济实现高质量发展中起到了关键作用。

  

基于对金融行业数据安全规范及法律法规的深刻理解，安华金和助力徽商银行基于《金融数据安全 数据安全评估规范》（征求意见稿）及法律法规，摸索了一套评估实践方法，对徽商银行全行数据安全现状进行评估，评估以个人金融信息安全为核心、抽取多个行内典型业务系统，从管理及技术为抓手，基于评估实践，围绕数据的全生命周期，全面厘清行内数据安全现状。  
以**急用现行、满足合规、动态管控、持续运营**的理念，安华金和助力徽商银行围绕“**管理、技术、运营**”三个体系相辅相成的建设思路并结合行内实际情况，基于可操作、可执行原则，对未来三年数据安全体系建设进行规划，完善制度并推动落地，按场景设立了常态化数据安全评估体系，整体提高了数据安全防护能力和数据安全管理能力，从根本上保障了数据资产安全。

![](../Images/03a81bfc573ab0d9ce5ecebcbac8b082.png)

**创新亮点**

**1）数据安全评估体系建立：**  

通过结合现状，建立了一套落地可行的数据安全评估体系，通过评估、整改、优化，不断完善和提升数据安全管理能力；并结合业务部门情况，梳理自查清单，满足业务部门自查需要。

**2）敏感数据、重要数据的识别分类及管控落地：**

通过本次实践，建设了敏感数据识别及分类分级工具、操作方法，实现了行内常态化分类分级制度体系完善；并依据现状完善了行内数据安全规章制度、实施细则，并配套完善技术工具推广、落实管控措施。

**3）数据安全体系化建设规划：**

当前商业银行数据安全建设主要集中在单一的防护手段，只能满足单点场景的安全需求，很难形成全面的能力。通过本次数据安全评估工作，基于数据安全长远考虑，安华金和为徽商银行体系化地规划数据安全建设路线，使其逐步构建一体化的数据安全能力从而面对复杂的安全形势。

![](../Images/17e27630a04f545ad95880944637db87.png)

**应用落地**

针对目前数据安全管控落地难的痛点，本次项目建立的数据安全规划体系，充分结合现状，细化管控方向，重点**以落地为目标**。

通过本次敏感数据识别及安全评估项目，徽商银行厘清了行内数据安全现状，识别了行内敏感数据，完善了行内管理制度与管控手段，并对行内未来五年的数据安全建设进行路线规划，明确数据安全建设目标与发展方向。数据安全工作任重而道远，徽商银行将通过持续优化数据安全策略、推动数据安全规范要求与业务相结合，实现“**从制度指导与策略制定，到事件识别与风险处置，再回归到优化改进制度及策略**”的运营闭环。

![](../Images/1513e233dbddabe53acb6466ca516173.png)

本次案例评选历经五个月，通过网络投票、专家初评、线上答辩等环节，遴选出百余个案例，中国信通院将精选案例集结成《“金信通”金融科技创新应用案例集2022》，旨在展示金融机构对前沿科技的应用经验、数字化转型成果、金融服务提质增效等进展与创新经验，并助力形成一批可复制、可推广的金融科技样板项目，为政府、监管部门、金融机构和科技企业提供参考素材，推动我国金融科技生态健康发展。    

![](../Images/970787a02db7a84ffa30c3d0109783d6.png)

  

  

      此次入选“金信通”金融科技创新应用卓越案例，是**金融行业对安华金和产品、技术和服务实力的认可及肯定**。未来，我们期待在陪伴金融业数字化转型的道路上，持续与更多的合作伙伴携手，提供高质量的数据安全产品与服务，**护航众多金融客户共赴数“智”未来。**
