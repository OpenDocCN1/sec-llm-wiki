# 案例解析 | 河北电信数据安全治理实践

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MTQwNTQxMg==&mid=2650781025&idx=1&sn=4e5ddb26b2512cbd21dc2804dfe412d0&chksm=87250f6ab052867c610cf2ffdd8d71e0d2ec9a382b711621a5f9480cb81b85a29295dc2ac291&scene=126&sessionid=1681266522#rd](http://mp.weixin.qq.com/s?__biz=MzA3MTQwNTQxMg==&mid=2650781025&idx=1&sn=4e5ddb26b2512cbd21dc2804dfe412d0&chksm=87250f6ab052867c610cf2ffdd8d71e0d2ec9a382b711621a5f9480cb81b85a29295dc2ac291&scene=126&sessionid=1681266522#rd)

![](../Images/fc06f559c3c249475fe80f1935799f04.png)

  
2019年12月，中国电信集团发布《关于印发 IT 安全能力建设与运营实施要求的通知》，**要求各省按照《IT 安全能力建设规范》，从资产管理能力、安全接入能力、安全防护能力、数据安全能力、安全分析能力及安全运营管理能力共六个方面进行安全能力建设**，并选取广东、江苏、安徽、广西、江西、河北六省作为数据安全能力专项试点省，探索数据安全与业务需求的平衡点，形成最佳实践方案。

  

伴随用户量级与业务规模的持续提升，河北电信已有越来越多的关键业务系统运行在数据库平台之上，而数据库本身在可靠性、安全性方面的功能不足，使得各应用系统数据库中存在敏感数据防窃取、防篡改等数据安全问题，愈发得到集团领导及管理层的高度关注与重视。**本案例中，将着重介绍河北电信在数据安全管理、安全分析等层面对IT系统数据库的安全审计能力建设实践经验与解决思路。**

  

需求分析

  

**1**

**集团合规性要求**

近年来，中国电信集团陆续出台数据安全能力建设规范、要求、通知等文件，旗下各地方省市公司、机构遵照开展相关建设工作：

  

《中国电信 2020-2022 年 IT 系统和数据安全规划》

  

《IT安全能力建设规范》

  

《IT安全能力建设与运营实施要求》

  

《关于印发 IT 安全能力建设与运营实施要求的通知》

  

《关于印发 2020-2022 年中国电信 IT 系统和数据安全规划和 IT 安全能力建设规范（试行）的通知》

  

上述文件中要求，各省需进行资产动态管理定级，建立统一接入系统，全面加强终端、网络、数据库安全防护，以及后期的安全运营与动态化管理，并通过信息共享与安全联动，实现集团与省公司的相关联防、联控工作。

  

**2**

**业务侧常规要求**

河北电信IT系统目前有上百套数据，需**通过部署数据库审计产品，实现对数据库操作的细粒度监测**，并在数据库遭受风险行为时进行告警、阻断和回溯。

  

需全面落实数据库安全防护措施，基于动态分析访问行为与静态分析访问数据相结合的主动防御机制，实现数据库的访问行为权限控制、恶意或危险操作告警，并对可疑行为的审计等，从而更好满足集团与工信部安全合规要求。

  

需从数据库兼容性、审计策略、日志查询与告警、统计报表、状态审计、部署方式、部署方式、系统管理等多维度进行功能性指标论证。

  

建设目标

河北电信遵循中国电信集团相关要求，着手搭建数据安全治理平台整体框架，**全面提升包括数据安全基础、数据安全防护、数据安全展示及数据生命周期安全在内的各项能力水平。**

  

![](../Images/b2ef6ba8a5bc037f349b96c17a7fbe24.png)

  

在数据发现、存储、传输、共享与使用等过程中，对数据资产实现自动分类分级和智能梳理；对数据资产分布状况及安全态势进行可视化呈现；同时，采用数据加密、数据脱敏、数据审计、数据水印等产品、技术措施，为保障数据安全提供全面、有力的支撑。

  

解决方案

**1**

**数据库审计架构**  

![](../Images/559dc1d7bc6578fee358d8a44cb78155.png)

  

如上图所示，通过在省市两个数据中心分别部署安华金和数据库安全审计产品，将其以镜像方式部署在核心交换机侧，监控BOSS、CRM、OSS、计费、财务等系统的操作流程，对违规操作和风险事件进行告警，从而为河北电信相关业务提供准确、及时的监控与告警能力。两个数据中心采用广域网负载形式，同时提供对外业务访问服务；当其中一个数据中心出现故障时，将由另一个数据中心继续提供对外业务访问服务；两个数据中心均可访问本地数据库审计系统和对端数据库审计系统，进行审计日志的查询。

  

**2**

**业务系统监控审计**

（1）BOSS系统业务运营支撑系统，通常包括计费及结算系统、营业与账务系统、客户服务系统、决策支持系统四个部分。

  

（2）CRM系统客户关系管理系统，以客户为中心，基于客户完整生命周期的发生、发展过程，实现以客户为中心的信息整合。

  

（3）OSS系统业务开展及运营支撑平台，是电信运营商的一体化、信息资源共享支持系统，主要由网络管理、系统管理、计费、营业、账务及客户服务等部分组成。

  

（4）计费系统支撑运营及客户管理的计费系统，承载着重要的资金流转业务。

  

（5）账务系统支撑更为复杂的周期性费用计算、账务及优惠、外部账单导入、调账等业务。

客户价值

  

**1**

**全量业务审计**

数据库安全审计系统适配电信复杂的网络部署要求，通过SQL行为和业务用户的准确关联分析，将数据库访问行为有效定位到具体业务工作人员，同时基于风险、语句、会话、客户端、应用端、响应时长、应答结果等形成数据库的全量行为记录，从而进行有效的追溯和定责。

  

**2**

**实时风险告警**

数据库安全审计系统提供了数据库风险告警能力，对于外部发起的数据库漏洞攻击、恶意SQL注入、非法业务登录、高危SQL操作及过量数据下载等风险行为，系统可基于灵活的策略配置与风险规则提供包括短信、邮件、SNMP、Syslog、企业微信等多种方式的实时告警。

  

**3**

**数据安全最小化原则**

面对众多复杂的电信业务系统，数据库安全审计系统针对访问源、访问方式、访问目标、访问内容等层面进行了有效的管控，阻断了恶意尝试登录数据库或访问权限外内容等风险行为，以最小化的访问方式大大提升了电信内部数据系统的安全水平。同时，**针对关键敏感数据的安全防护要求满足了标准特性：**

  

  

（1）访问控制性实现了最小化授权原则，同时要求对重要信息资源设置敏感标记，以防止恶意下载数据、删除数据等。

  

（2）安全审计性实现了对用户行为、安全事件等全面、准确的记录。

  

**4**

**丰富的合规统计报表**

数据库安全审计系统提供了丰富的报表功能，包括风险综合分析报表、综合现状报表等。客户通过查看统计报表的总结分析，能够更好的了解某一段时间内系统数据访问的运行状况。同时，为客户在日常决策与工作汇报时，提供了准确、便捷、直观的依据。
