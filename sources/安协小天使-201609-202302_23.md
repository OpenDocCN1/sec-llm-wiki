　　在 11 月 6 日，协会第三次同时也是最后一次 C 语言培训在冬天到临前结束了(\*｀▽´\*)这次 Mezone 学长带大家讲了关于：C 语言“基础知识”、结构体 struct 的注意事项、指针的“高级”应用、位运算、堆栈的基本知识等等，为大家的 C 语言学习进行了扫尾。

　　同样有主讲人 Mezone 学长列的大纲，感觉培训没听明白的小朋友可以结合大纲和 ppt 和搜索引擎自己再多研究一会噢(ﾉ)\`ω´(ヾ) 

*   了解 bit 与 byte ，进而了解内存空间
    
*   int 变量在内存中的存储方式
    
*   区分 struct 的几种定义方法
    
*   掌握内存对齐的规则
    
*   了解 union 的用法
    
*   区分字符串与字符
    
*   区分二维数组、二级指针
    
*   学会基本的位运算：与、或、取反、位移
    
*   学会使用异或加密
    
*   明白短路现象
    
*   知道 sizeof 在编译期间计算
    
*   初步了解堆、栈
    
*   认识 cdecl 、fastcall 两种调用约定，明白 fastcall 更快的原因
