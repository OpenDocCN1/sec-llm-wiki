  主讲人 Tinmix



　　接下来 Tinmix 学长对 C 语言展开了介绍。以下邀请了 Tinmix 学长做了个大纲:

  • C 语言的特性

  • C 语言对于以后学习和安全方面的帮助

  • 学习 C 语言的方法要善用搜索引擎，要有不怕困难的精神，多查多看多问

  • 区分 IDE 和编辑器的概念，以及编译器是什么

  • 强调 main 函数返回值在普通约定下是 int ，不要写成 void

  • 说明函数的作用，推荐利用函数将程序解耦，便于 review 和调试，介绍函数（函数声明 函数体 函数入参表 函数返回值 函数定义 等）

  • 简单复习一下二进制位的存储（补码和反码），列举常见类型的宽度，强调同一个数据不同的理解方式会产生不同的值，并简单介绍地址的概念

  • 引入指针，强调指针是地址的抽象概念，指针类型可以相当于为计算机理解数据的方式或约定

  • 指针加减运算

  • 引入 const 关键字，强调它有定义常量和保护参数的作用，建议在代码中多多使用

  • 引入指针常量和常量指针的概念，展示它们的特性和不同，同时说明判断规则和可变指针与不可变指针的安全兼容性

　　不知道大家有没有理解呢>_<学习路漫漫，而打好基础是重要的一步。还是那句话：勿在浮沙筑高台。
