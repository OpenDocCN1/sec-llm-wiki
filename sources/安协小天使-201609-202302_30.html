　　八月过去，即将迎来的是九月开学季，对于许多新生的疑问，我们也给出一些解答:




　　协会历年以来一直推荐先系统学习一遍 C 语言，这是因为：



  • 首先 C 语言是一种高级语言，同时它又非常接近底层。C 的编译器是目前世界上能生成最接近汇编效率的编译器，学习 C 语言可以了解到很多现代编程语言的特性，同时又能对硬件机制产生一定概念。

  • C 语言中并没有对内存操作进行高级封装，这意味着开发者需要自行处理数据在内存中的传递，同时也意味着学习者能学习到大量数据与内存的细节，这对以后更高级更抽象语言的理解会很有帮助。

  • 一般来说，一个合格的 Programmer 需要由内而外地了解程序世界的前世今生，C 就是这样一个契机，虽然它门槛比较高，但也是一个好的平台，能够帮助你更好地进入计算机这个领域。But of course，初学者应该更多关注语言本身而不是它带来的其它什么意义。所以我们也会更推荐 Web 初学者去看 HTML 或者 php，对于更注重算法而不是程序实现的小伙伴可以先学习脚本语言（如 Python）甚至 MATLAB。


　　因此，倘若你因 OI 等契机在步入大学校门之前已经熟悉 C++ 的基本语法，关于“是否还需要再系统地学习一遍 C 语言？”这个问题，相信现在你已有了答案。








　　关于 CTF 与安全的关系：


  • CTF 本质上是将现实中的场景简化抽象后的黑客游戏，避免了实战中可能出现的风险与复杂的现实环境，客观上降低了入门安全的门槛；学习安全的过程中，CTF 是一种高效学习的途径，能快速使你掌握一定的安全能力；CTF 中的知识点具有很高的时效性，因此也是了解最新安全知识的一大途径。


  • 但是，CTF 根本上只是学习安全的手段。CTF 可以检验学习的成果，了解自身的不足，享受与队友们齐心协力夺得的奖金与荣誉，但这只能是个精彩的开端。当你离开校园，真正步入安全行业时，通过 CTF 学到的安全能力才是唯一有意义的部分。


  • 近年来，浮躁的风气逐渐开始侵染 CTF 圈，希望大家不要因此迷失了初心，弄混了目的与手段。
