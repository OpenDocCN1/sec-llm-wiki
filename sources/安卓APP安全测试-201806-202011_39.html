序言


前几天收到微信消息说我这个公众号要过期了，才想到这是两年前想着要写一些关于安卓APP安全测试的东西的。拖延症要不得。

先做个自我介绍：我呢甲方安全人员一枚，14年的时候在菊花厂做过一年多的安卓APP安全测试，后面到某电商做安全，就很少接触安卓了。最近又到了绿厂做安全，趁着这个契机打算捡起来安卓安全测试。

在这个公众号里面，我将分享一些安卓APP安全测试的方法和经验，内容也是由浅入深，希望能够帮到有缘人。

今天我们先把环境搭建起来。


一、操作系统

 

Windows+ Linux（Vmware中安装），也可以是Windows + mac。

 

二、java环境


安装 JDK1.8，版本不需要太高，太高后续有些工具会运行不起来。

推荐下载：地址http://www.oracle.com/technetwork/java/javase/downloads/java-archive-javase8-2177648.html  选择  Java SE Development Kit 8u111。具体配置可参考《WIN10如何安装JDK并设置环境变量》（https://jingyan.baidu.com/article/64d05a024b327ade55f73b8a.html）。


三、安装开发工具


安卓开发主流是使用 Android Studio了，下载地址 https://developer.android.com/studio/。

安装好后，打开 File-->Settings，在 Android SDK标签中，按照如下方框勾选下载对应版本的 SDK，并记住箭头所指的Android SDK Location。




在环境变量里面，添加如下红框中的值（注意把路径改成你自己的）。



在命令行里面输入 adb，如果有输出就说明设置正确了。




四、安装模拟器

 

Android SDK默认是带模拟器的，缺点是慢，所以建议安装mumu模拟器。下载地址： http://mumu.163.com。

安装完成之后，运行起来。然后执行 adb connect 127.0.0.1:7555 来连接模拟器。



执行 adb shell 命令，如下说明已经成功连接到模拟器的shell了。

文本编辑器建议安装 notepad++，其他检测分析工具会在后续的具体安全测试中安装。
