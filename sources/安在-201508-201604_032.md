# 抄袭了，错了，我们道歉！

就在昨天，安在又删帖了，大家发现，好好的一篇文章刚发出来不久，一个大红戳就给盖上了。

  

热心粉丝纷纷问询，怎么了？  

  

以前也有发帖后删帖的情况，但多是一些几乎所有媒体都会面临的运营问题。

  

但这次，对安在来说，有点不一样。

  

事件缘起于昨天推送的《一图读懂GitHub信息泄露》。发出不久，便在微信朋友圈、微信群、微信公号留言、微博里发现许多质疑的声音，赶紧查看，这才知晓，该文有大段文字直接引自他人文章却无任何声明。

  

毋庸置疑，我们涉嫌抄袭，我们能做的，就是赶紧删帖，并在今天，向文字原作者及公众道歉。  

  

![](../Images/908d8617a9e35e78517aae7fb44086ee.png)

  

首先，我们必须承认，这篇原本应该属于原创投稿的专栏文章，以无声明前提下整段文字“援引”他人而无可辩驳地说明，这就是抄袭！原文作者——携程安全平台，以及原作者投稿媒体——Freebuf，我们想说，由于我们对来稿审核不严，由于我们的疏忽，给你们造成烦扰，我们深表歉意。  

  

其次，我们也要对一直关心爱护安在的读者朋友们致歉，尽管此类抄袭事件在当下浮躁社会世情中屡见不鲜，甚至很多人都见惯不怪了，但对于一贯秉持公正、内涵、专业和道德的安在，以及关注安在的读者朋友们来说，作假一定是我们的“零容忍”行为！而这次，这样的事情，我们也清醒地认识到，我们做的还很不够。

  

再有，针对此次抄袭事件，除了撤稿之外，安在将暂停“图说安全”专栏，我们不想让抄袭行为有任何缓释之机，对抄袭作者，或许也是最好的一次警示。  

  

最后，我们想再次强调，安在是一个致力于将信息安全意识与知识向大众传播，并力图以独到的视野报道及服务于行业的专业新媒体，我们非常注重内容的原创性，以及原创基础上的大众性、话题性、专业性和趣味性。借此次事件，我们重申立场，并向所有关注信息安全的朋友们正式公布我们新的内容奖励计划。

  

安在征稿之内容奖励计划分为两部分：

  

1.  专栏作家：适用原创作者协议（年度版）+内容奖励  
    
2.  自由投稿：适用原创作者协议（单次版）+内容奖励  
    

  

原创作者协议概要：

1.  文章必须为原创！  
    
2.  内容以大众性、话题性、专业性、趣味性为特色
    
3.  文章不可一稿多投
    
4.  单文章最高可奖励**5000元**。
