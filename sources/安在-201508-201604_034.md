# 阿尔法狗虐了李世石，中国黑客11秒灭它亲兄弟

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532023&idx=1&sn=1c957d8d4b10c1325b8551cce4a71ad0&chksm=febc1737c9cb9e2189548a4d598e8fa13dd963db0713af45c8edbc0e9435bd7dcec2aaa05af2&scene=126&sessionid=1681310823#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532023&idx=1&sn=1c957d8d4b10c1325b8551cce4a71ad0&chksm=febc1737c9cb9e2189548a4d598e8fa13dd963db0713af45c8edbc0e9435bd7dcec2aaa05af2&scene=126&sessionid=1681310823#rd)

李世石和AlphaGo的世纪大战刚刚尘埃落定，AlphaGo的完胜让人类的智能遭受了严峻挑战。但与此同时，大洋彼岸的另一场人机大战中，一群来自中国的白帽子却为人类大大争了一口气，来自中国的各支队伍捷报频传，更是一举击败了AlphaGo的亲兄弟——在加拿大温哥华举办的世界黑客大赛Pwn2Own上，360Vulcan Team用时11秒攻破了本届赛事难度最大的谷歌Chrome浏览器，成功获得系统最高权限。这是中国安全团队在Pwn2Own历史上首次成功攻破Chrome。此外，360Vulcan Team还攻破了基于Edge浏览器的Adobe Flash Player，同样获得系统最高权限，再获80000美元全额奖金和13分满分成绩。

 

**Pwn2Own是什么？**

对于普通人来说，Pwn2Own是个陌生的名词，但在全世界黑客的眼中，这场比赛无疑是安全界的“武林大会”。

  

![](../Images/57057ba56213bde7dbdad7a27ab2ccd1.png)

  

Pwn2Own大赛是目前世界上知名度最高、历史最悠久，同时也是难度系数地最高、最“高精尖”的黑客挑战比赛，参赛选手皆是对应领域排名Top5以内的高手。在长达八年的赛程历史中，多位世界顶尖的黑客，如Mac黑客大神、在高速上远程逼停Jeep的查理米勒、率先破解iPhone、PS3的天才神童Geohotz，“黑客军火商”VUPEN等，都在这项赛事上崭露头角。毫不夸张地说，Pwn2Own就是黑客界的”华山论剑“。

  

从去年开始，Pwn2Own比赛难度大幅度提升，今年更是到了令人望而却步的程度：所有北美、欧洲和俄罗斯黑客团队都迫于难度而放弃了比赛。曾经多次赢得Pwn2own、Pwnium（谷歌举办的类似比赛）冠军的天才黑客Geohotzgeng在审时度势后，更是决定退出黑客界，转而加入更有“钱途”的人工智能领域。

也有一些高手并未参赛，而是以其他形式加入战局：上届双料冠军Nicolas是大赛的熟面孔了，今年他加入了微软，以”保护者“的身份亮相大赛。作为一个资深的攻击者，他表示，这种感觉非常诡异。不知道当他看着本届比赛的选手们攻城略地时，会不会发出“江山代有才人出，长江后浪推前浪”的感慨？

  

![](../Images/66b9cba68d5844c7df2e38ffea4b8b44.png)

  

而作为Google安全防御技术的集大成者，Chrome不仅是本次大赛中的难度巅峰，也是有史以来难度最高的挑战项目。除了汇聚全球顶尖黑客的“黑客天团”Google Project Zero以外，谷歌近期还公布使用了超过4000台服务器，以深度挖掘技术对Chrome进行长期漏洞测试，降低漏洞被外界发现的概率，计算能力完全不亚于AlphaGo，说是“亲兄弟”也不为过。

  

同时， Chrome拥有全球唯一能够锁定Windows内核攻击面的沙箱系统，沙箱一旦上锁，攻击代码对外部资源的访问权限将全部丧失，其极高的安全性让Chrome成为历届大赛中高手们面临的终极挑战。最新版Chrome的安全系数相比往年更是有着飞跃提升，更极大地增加了攻破Chrome的难度。可以说，这场挑战的难度丝毫不亚于李世石的“世纪大战”。

 

**360Vulcanteam是谁?**

那么，啃下Chrome这块硬骨头的360Vulcan团队，又是什么来头？

  

360Vulcanteam是一支专注于软件漏洞挖掘、发现和防御的安全团队，团队成员都是实力极强的软件黑客，其中三名成员在微软全球top 100安全大神名单中榜上有名。

 

2015年，360安全团队为谷歌、微软、苹果和Adobe因提交了上百个漏洞获得公开致谢，仅次于Google Project Zero。

 

强悍的技术实力造就了360Vulcan team优秀的战绩：在2015年的Pwn2Own中，360Vulcan Team斩获微软全副武装的IE11“独角兽”级别奖项，在此之前，还从未有任何一支亚洲团队在Pwn2Own大赛上攻破IE。今年的比赛上，他们再度在中国安全行业历史上书就了浓墨重彩的一笔。

  

360Vulcanteam负责人MJ说，与谷歌的机器大军正面对抗，旨在“让每个人上网都变得更安全“，这也是整个团队不懈奋斗的目标，“Live Long and PWN“，秉持着这样一条座右铭，他们一直在努力。

 ![](../Images/5e84b1704dcd9fec636f0f33a4e492e8.png)  

  

下面，安在带你认识一下360Vulcan team的小伙子们：

  

**团队主要成员介绍**：

  

**MJ**

真名郑文彬，360Vulcan团队负责人，360首席工程师，反木马专家，曾经发现微软Windows “DirectShow视频开发包”漏洞、并被微软官方公开致谢，有“驱动神童”之称，号称**国内内核安全第一人**。

 

**龚广**

360手机卫士安全研究员，致力于挖掘安卓系统漏洞，去年他因发现安卓系统漏洞收到谷歌5次致谢，因为多次收到谷歌的赏金激励，他被同事称为安卓系统的“赏金猎人”。   

  

在2015年东京举办的Mobile Pwn20wn 大赛上，龚广攻破了谷歌NEXUS手机，此举使他直接获得cansecwest2016的演讲邀请，他也是该会议最早确定的议题演讲人:《只用一个漏洞攻破NEXUS》。

 

**古河**

是360安全研究团队360Vulcan的核心成员。他拥有超过6年的信息安全从业经历,研究方向包括漏洞挖掘分析和Exploit开发。同时他已在多个 安全会议上发表过演讲,如SyScan、Xcon、SyScan360等。

  

古河和团队一起参加了2015年的Pwn2Own大赛上，用时17秒攻破了号称史上最难的IE浏览器。

 

鉴于此次大赛上360Vulcan team的优秀表现，老板齐向东大手一挥，同意奖金double，刚刚挑战了技术高峰的小伙子们，此刻又面临一个严峻的新问题：170万奖金怎么花？目前他们正在线征集解决方案，看来这件大喜事，也够小伙子们头疼好几天了。

 

![](../Images/fe65c39fd402fe8fca0d97530a856e15.png)  
   

今年的大赛被人戏称为“新的乒乓球运动”，原因是比赛几乎被亚洲团队包揽，而来自中国的队伍表现尤为亮眼：360Vulcan Team11秒攻破了谷歌Chrome浏览器，腾讯安全联队5秒攻破苹果Safari浏览器并获得root权限、3秒攻破Flash插件实现系统级访问……而除了国内团队，由传奇的韩国神童Lokihardt带领的队伍同样不可小觑: 去年，他在Pwn2own上完胜全部浏览器，夺得22万美元最高奖金，也在另一世界黑客比赛Defcon CTF中击败有了不败称号的美国强队PPP。目前，他们已经攻克了Safari，正在向着全胜的目标前进。

 ![](../Images/d64bcd04f67003708a61b8c458063b62.png)

  

历年来，我们中国军团发现了许多价值巨大的漏洞，在”网络军火商“眼中，挑出其中一个漏洞就可获利数万美元，但白帽子们选择了维护互联网安全环境而非个人的利益。攻破Chrome并不是360Vulcan team征程的终点，我们衷心地希望，有更多的白帽子为互联网安全添砖加瓦，让互联网实现真正的自由、开放、安全；我们也希望，在世界互联网安全的舞台上，能够出现越来越多的”中国身影“。
