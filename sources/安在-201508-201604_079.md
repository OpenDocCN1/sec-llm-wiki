# 【团队】信息安全界有个360，360里有双“天眼”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247531991&idx=1&sn=53c082f289cc6bb78d7a7bf2b2d0a233&chksm=febc1717c9cb9e01ff685832324d66ed61800c21f891c0b577d137f3047572e000a74a70992d&scene=126&sessionid=1681310826#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247531991&idx=1&sn=53c082f289cc6bb78d7a7bf2b2d0a233&chksm=febc1717c9cb9e01ff685832324d66ed61800c21f891c0b577d137f3047572e000a74a70992d&scene=126&sessionid=1681310826#rd)

如果说在互联网的蛮荒时代，黑客之间的较量是侠客之间的决斗，那么今天的互联网，安全攻防已经升级成了战争。侠客间决斗比的是武艺，而两军对垒，则更依赖对战略和全局的掌控。擂台属于武人，沙场则属于智者：他们时刻注视着敌人的动向，审慎地分析着敌人的意图。他们，就是战场上的眼睛。而在所有这些炯炯的神色与目光中，有一双时刻高悬于网络“天际”，能够洞察网络深处的“天眼”。  
  
![](../Images/308383f7f07f47c83aab6be3f188fc68.png)  
1黑云压城，天眼初开  

“天眼”实验室成立于2014年1月。

  

彼时，一朵名为APT(Advanced Persistent Threat，高级持续性威胁)的阴云已经悄然笼罩在信息安全的堡垒上空。

  

不同于传统的安全威胁，APT的可怕之处在于，它会针对特定的目标展开持久的攻击。攻击者会针对用户环境进行长期的研究跟踪，尝试不同的攻击方式，寻找可利用的漏洞得到进入的机会，开发针对受害者特定环境和防御体系的特种木马。有的攻击周期长达几个月、甚至数年时间，2010年震惊世界的“震网病毒”，相关的工具代码可以追溯到2005年；而在“天眼”所监控的多个针对中国的攻击活动中，最长的潜伏期甚至长达八年。

  

针对性极强的定向入侵，能够巧妙地绕开传统基于规则的传统防护产品的检测；而长时间的持续攻击，更是让被动防御体系疲于招架。传统的安全产品如同武林中的侠客，习惯于“打擂台”的攻防模式：一刀一剑，有来有往，见招拆招。而APT攻击就像是一张巨大严密的阴谋网，任你武艺再高强，一旦陷入其中，也难以施展开拳脚。

最令人担心的是，APT攻击的目标往往是政治和高价值经济目标，目的是窃密或导致巨大破坏，大机构如Google、SONY都曾成为受害者。发生在俄罗斯的APT攻击Anunak 行动攻破了超过50家俄罗斯银行和5个支付系统，直接窃取了超过2500万美元。而发生在韩国的Dark Seoul攻击造成了大约8亿美元的经济损失，在攻击的最后破坏阶段，数千台ATM、POS机受到了影响。

自“棱镜事件”以来，显示中国事实上是APT攻击的主要受害国。如何检测并应对APT攻击，一时间成为信息安全业界的热门话题。就是在这种背景下，“天眼”适时成立，对于国内信息安全行业来说，无疑是一场及时雨。

作为360旗下专门利用大数据安全分析技术研究发现和回溯APT攻击的技术团队，天眼实验室（SkyEye Labs）从成立至今的短短两年时间里，已经在行业内崭露头角：到2015年11月底，360威胁情报中心监测到的针对中国发动APT攻击的境内外黑客组织累计29个，其中包括专门攻击中国海事部门的黑客组织“海莲花”，这是中国企业首次曝光境外高级持续攻击组织，报告一发布即引起国内外的强烈反响。另据“天眼”实验室最新发布的《2015年中国高级持续性威胁(APT)研究报告》，2015年,发生在中国的APT攻击遍及31个省级行政区，影响电脑超过万台。北京、广东成为重灾区，教育科研、政府机构是APT攻击的重点关注领域，同时，针对商业、金融领域的攻击也开始增加。

在茫茫丛林中，并不是任何猎手都能猎获狡猾的狐狸，而如此短时间里，“天眼”获得如此丰硕的“成果”，直叫业界刮目相看。

在2016年的Freebuf 互联网安全创新大会上，360天眼威胁感知系统获得了唯一的WitAwards年度安全产品奖。

“天眼”初开，成绩斐然。

  

![](../Images/1832f906b464176d04ade251a0742641.png)  
2未知攻，焉知防  

“APT攻击的目标通常是具备高价值信息资产的组织机构，结合复杂多变的攻击手段以及社会工程方法，这使得传统安全体系无法有效处理。海量的传统威胁事件也会掩盖这些攻击的踪迹，使真正分析线索被淹没。同时，大部分安全厂商还停留在传统安全的视野，对于相关事件的分析还局限于单点样本分析的层次，无法上升到事件的高度以及挖掘背后的攻击团伙。再加上APT攻击者本身较高的综合能力，这使得APT攻击很难被检测和防御。而我们要做的，就是对大量的异常线索进行分析，从中还原出整个攻击的全貌，事件的源头，到活动的现状，攻击手法发生了哪些演变。像一个侦探一样，抽丝剥茧，最终把攻击源揪出来。”

基于对对手的深入了解，“天眼”自然有着自己的“锦囊妙计”。

“APT攻击者是普遍具有较高的技术水平，是专业的有知识有资源有组织的黑客，攻击的布局、时机、手段，都是在对目标的防护体系、组织架构等进行研究后精心设计的，根据目标特点确定攻击计划。比如目标防护标能力不强时，只需要简单的鱼叉邮件配合伪装的可执行文件就可以拿下。而面对强防护目标，多种方法的结合，以及0 day漏洞的使用，则攻击成本会非常高昂，没有强大的资源支持是无法办到的。这些变化都是人决定的。”

“我们看到的APT组织利用的攻击方法，不一定用到0day漏洞，但肯定是通过某种手段绕过现有的查杀体系的。现有的病毒防御体系存在缝隙，只要研究的比较透，再加上一定的资源支持，完全有可能绕过。而天眼的方法之一，是以自动化处理体系作为筛选机制，把不重要的、已知的恶意行为标定出来，筛选出那些已经绕过了现有防护体系的部分，然后再结合攻防专家的经验进行分析以发现特别的线索。”

“网络安全的攻防博弈，最终对抗的还是人。

当“天眼”实验室的研究员提到这些“锦囊妙计”时，神采奕奕得仿若“天眼”在真实展现。

对于APT防御与传统防御之间的比较和联动，研究员如此说：“我们最近在跟踪的攻击反映出了传统防御体系存在的弱点：其他公司同样看到了恶意样本出现，但只是简单地杀掉，就宣告结束了。而天眼经过分析后发现，攻击已经持续了很多年，而且真正的变种甚至达到了上千种，各种资源都有被利用，要了解这次攻击的来龙去脉，就要分析它的多种类型的样本了解其演进过程，从中总结背后的团伙的手法及变化。只注意到某一个局部，无法看到全貌，这是重大缺失。当然，传统方法也有其价值，多年来形成的自动化机制为高级分析提供了坚实技术支持和数据准备，其基础安全能力是整个体系的重要组成部分。”

对于一支以技术见长的团队来说，再没有什么能比将集体智慧用于“运筹帷幄”更让人兴奋的事情了。

《孙子兵法》有云：“知己知彼，百战不殆。”在360的安全体系中，同样也有这样一句话：“未知攻，焉知防”。消极的防御已经无法应对复杂多变的APT攻击，主动出击才是克敌制胜的关键，“天眼”的一众高手们，无疑已经深谙此道。

  

  
![](../Images/d78d824623c437ae70a87b5cfddf0fb8.png)  
3天时、地利、人和  

在信息安全界，“天眼”宛若“卧龙”之存在：临敌应变，动合事机；攻守之势，了然于胸。不过，即便是抱大器孕大才的诸葛亮，没有合适的时机和充足的条件，也只能躬耕于南阳，无从施展抱负。“天眼”能有今天的光景，天时、地利、人和，缺一不可。

“天眼”创立之际，APT攻击正势如野火，Google、RSA、Comodo无不深受其害。“天眼”占尽天时，而360为这份天时所提供的舞台，则是绝佳的地利之便。

“天眼实验室核心成员不到五十人，主要专注于恶意代码分析、攻防技术跟踪、数据挖掘、机器学习、可视化分析等几个领域。但在实际工作中，还是要靠公司其他多个团队的资源。尤其像专注高级威胁研究的360追日团队，以及360的各类基础数据，包括在杀毒、威胁情报、漏洞研究、搜索等方面的优势，在APT攻击研究方面都为我们提供了有力的支持。”

“我们需要搜集更多的数据，往往是几十亿级别的，需要基础设施的搭建和数据层面的整合，不是单靠一个团队可以完成的。比如一个查询请求，背后是几百亿乃至上千亿的数据，需要几乎实时的结果响应，对工程能力要求很高。而360的搜索和大数据基础就使得事情相对容易了。同时，APT检测不是简单的样本分析，需要关联多个维度的数据。360恶意样本库拥有的95亿样本，每天新增的900多万，近年网络研究院的成立也使360补足了网络层面的基础数据，再加上多年做病毒查杀、网站安全防护以及全球最大的补天的漏洞库所累积各类数据，为我们的综合分析提供了也许是360才能拥有的自成体系的数据基础。”

天时地利兼备的“天眼”，还拥有着最重要的一个条件：人和。有人说，人对了，一切就都对了，这句话放在“天眼”身上，称得上是一句至理名言。

提到团队的凝聚力，“天眼”实验室负责人韩永刚稍作思考，说：“我们团队的凝聚力，还是在于技术吧。”

由于APT攻击绕过了传统的防御手段，一般的规则在这里便不再适用。对于“天眼”来说，敌人会使用什么样的套路他们大致知道，但如何分析应对有各种可挖掘的方案，这对于他们来说无疑是不小的挑战。然而，“天眼”的团队成员却一个个摩拳擦掌，乐在其中。

“我们喜欢有挑战的事情，没有成型的套路，我们自己挖出来，这样挺有乐趣的。”

这样的挖掘对大多数人来说，是充满艰难和挫败的，很多时候，绞尽脑汁尝试的方向，很有可能徒劳无功，这样的试错不在少数。能够胜任这项工作的人，必须具备对技术的无限热爱和超人的耐心。而“天眼”正是这样的一支队伍。“凝聚力在技术”，此言不虚。

这样的一群人在360，得其天时地利，正可谓如鱼得水。“公司的整体氛围是开放轻松的，这就意味着你所感兴趣的技术点都可以去尝试。有一些技术点可能并不是你最专业的方向，但都可以去学习研究。很多预研，在日后都可能会发挥巨大的作用。即使一些尝试并没有最终形成成果，但能够充分尝试，在攻防方面也是很有助益的。”

作为一个团队，“天眼”的成员们并不像那些个性十足且特立独行的白帽子们，他们并不会过多展示自己的个人生活。在提及技术之外的话题时，他们更多是以沉默和笑容来回应。可是，一旦聊到和技术相关的问题，他们立刻两眼放光且妙语连珠起来。

“我们团队小伙子们也会用技术做一些好玩的事，比如用机器学习做一个画风模仿的东西，你可以学习任意画家的风格，然后再套到其他任何一张图片上。”

“听起来很不错呀，如果把这个推广出去，一定大受欢迎。没想过好好利用一下吗？”终于逮着一个技术性的艺术话题，可天眼的成员相互看了看，然后笑了：“还真没有，我们做这个，就是好玩。”

这真的是一群对技术爱到痴狂以至于深入骨髓的人了。

不过，若不是团队有这样一种对技术的热爱，又怎会有今天的“天眼”？

未可知的是，就是这样一双洞察一切的“眼睛”，得天时、地利、人和，还会给我们展示出多少网络世界的未知和深邃？而可以肯定的是，无论有多少未知和深邃，有此“天眼”，不至于网络世界过于暗黑，不至于魔高一尺道难一丈。

祝愿“天眼”神启，若正义之剑高擎。
