“访谈”，是安在新媒体栏目之一，旨在通过与中国信息安全影响力人物的直接对话，揭示产业发展历程和动向趋势，描绘中国信息安全之全景视图。



虽蛰伏内地，四叶草安全却有着难得的聚焦、扎实和坚持，凭借多年的技术积淀和服务经验，做出的东西都很接地气。关于四叶草安全的产品以及未来，马坤自然是有很多话要说，且看耀疆访谈为您一一呈现。



张耀疆：先介绍一下四叶草安全的产品吧？

马坤：目前主要产品是BugScan，是一个分布式的扫描平台。同时还有一个开放式的漏洞感知平台BugFeel。另外就是我们的研究部门，CloverSec实验室。这三块构成了四叶草安全的主体。

BugScan的开发早在2011年底就开始了，经过多次迭代，2015年初正式对外发布的。

作为一个面向安全爱好者的免费的漏洞扫描平台，BugScan采用分布式架构，扫描器核心与插件使用 python 编写，不依赖于第三方库，在任何可以安装 python 的设备上，如 mac、Windows、linux 等都可以一条命令建立扫描节点。扫描插件相对完备，从弱口令到SQL注入、xss、主流 cms漏洞、常用软件漏洞和系统漏洞，都有，甚至现在也包含了很多工控系统的漏洞检测。

关于插件这块，我们用众筹思想建立了Q.bugscan.net，实际上是个圈子，吸引有一定编程基础、且有能力分析漏洞的安全爱好者，大家可以编写扫描器插件，上线一个月，插件就从 90 个增加到了340 个。

BugFeel是一个漏洞感知平台，目标是自动感知用户的“痛点”，让用户先于黑客发现自身弱点。架构上采用 python 双引擎，可以实现无需值守的自动检测、定制化应用追踪、以及应用级 0day 预警。

张耀疆：据我了解，四叶草安全起步时主要做的是安全服务，那怎么想到要开发产品的？

马坤：注册公司的时候我就想过安全即服务这一理念，但是当时客户都以为服务就是“堆人”，对服务的概念没有很好的理解，我就一直在思考另一种模式。

接触的客户多了，我发现因为客户类型很多，环境不尽相同，加上派出去做服务的人的水平也不同，我就思考是否可以出一些流程化的产品，提高相似服务的效率，比如遇到常规问题可以自动解决，或者像内网扫描的时候可以避免重复的过程。后来，我们就逐渐开发出一些可以批量解决服务问题的小工具。

总体上，我觉得服务的概念，不应该只是上人，提供工具也是一种。

就是基于这样的考虑，逐渐就衍生出我们的三块主要业务。这三年来，我们在安全服务、渗透测试、代码审计方面做了上千个项目，平均下来每天一个，正是这样的积累，才让我们把一些接地气的想法固化在同样接地气的产品上。



张耀疆：很多圈里人对四叶草安全的认知，似乎都和BugScan有关，能多说几句吗？

马坤：BugScan早期并没有开放，一直是自己人用，然后不停改版，到2015年才开放了，没想到效果非常好。作为一款真正的分布式扫描器，在我们实际应用中认为它是符合市场需要的。

既然开放了，BugScan就一定会是免费的，基于社区化运营的，我们鼓励大家来写插件。实际上它给很多白帽子提供了方便，是他们做众测的一个得力工具。

我们看安全的发展，从早期买设备做防御，到让人来做服务，再到众测，一直都在进步。但现在众测有个问题，就是用户不信任，不愿意暴露漏洞给黑客，这是人之常情。我们做了社区，很多人来写插件，用户自己就可以给自己的产品做检查，其实就是一种信任的保障。

分布式扫描我们做得很早，很多东西已经比较成熟了，比如开放框架权限，基于SaaS模式的插件提交，像填空一样简单，还有社区成员在写插件上可以互相参考、学习，我们是正真开放的平台。

当然，为了避免被恶意使用，我们会在扫描的目标选择上有所控制，实际上就是个白名单，把国内金融等领域的主要网站域名都列上，禁止访问，防止有人利用扫描平台做坏事。

张耀疆：写插件的是个什么群体？

马坤：有学生，有BAT的，很多都是爱好者。其实这个群体很有限，因为要求很高，要会编程，又要对漏洞有研究。众测平台上白帽子很多，很多白帽子都是利用网上公开的方法，相对要简单一些。而我们这个群体就很小了，注册白帽子有七千多，提交过插件的过了五千，但真正达到要求通过审核的不到八百。

张耀疆：用户有哪些？有商业化应用吗？

马坤：据我们长期观察，使用平台的人群主要是两部分，一个是安全公司，毕竟我们是分布式的，速度非常快；还有就是给平台提交漏洞的，可以用这个方法来刷分。

我们产品的优势在于非常及时，一爆漏洞，当天就有插件出来。毕竟是社会化协作的方式，动员社会力量一起做，后续能量很大。当然，分布式扫描产品本身在细节上有很多技术难点，比如怎样让分布式节点和产品匹配？速度效率和准确度如何平衡？都要比传统扫描器复杂许多。

对BugScan，我们的态度是为爱好者而生，不打算商业化。



张耀疆：商业化是准备在BugFeel产品上？

马坤：公司要生存，一定要考虑商业化运营的产品。目前我们正准备推出一款漏洞感知平台，叫感洞BugFeel。它会调用BugScan的引擎，可以达到一分钟内对七八万台服务器进行测试，根据节点来做插件分发。这也是我们积累了很多年的核心技术。

现在我们BugFeel的第二轮测试已经完成了,其实已经可以和客户签合同直接部署了。

目前在扫描这块，国际上分布式做的并不多。做安全的第一步是发现问题，大多数还是已知漏洞，这里面就有一个时间差的问题——用户与黑客发现漏洞的时间差，时间差越短也就越安全。但是，安全人员不会天天盯着，那我们就帮他们去找。采用分布式的方案，可以真正做到与黑客同步，这才是做这款产品的意义所在。

我一直认为，好的东西一定是很轻便的，好安装好使用。不过，很多传统厂商这方面比较欠缺，缺少同时懂渗透又很懂编程的人，一般都是懂渗透的人告诉做产品的人，这样出来的东西往往会偏离了最初设想。所以我就让我们的人都去一线做安全服务，去了解用户，让他们接地气，这样出来的感觉就会不一样，他们知道用户的痛点。

张耀疆：有没有竞争对手？

马坤：当然有了，很多竞争对手都在模仿我们，这没什么，也说明我们是先进的，竞争也可以促进互相进步嘛。

但有一点不好，就是流行的东西都一窝蜂，像漏洞感知，国内很多根本没基础的，也叫喊着做漏洞感知，其实什么也没做，还是老一套。

我这人性格里不喜欢模仿别人，要做就做创新。不到万不得已，我们一定是走自己的路。

张耀疆：之前一段时间里你们一直在苦熬，那四叶草现在发展的怎样？

马坤：最近项目比较多了，目前最赚钱的还是安全服务部门。

总体上是三块，我们的服务部门是负责盈利的，产品部门是未来，攻防实验室定位是对外发声，相当于是PR了。

目前公司四十多号人，规模会逐渐变大，但我们一直在做减法，专注做自己擅长的事情。



张耀疆：拿到投资后钱怎么花？

马坤：做安全真的太苦了，拿了钱肯定整个经营上会比之前宽裕很多。我们花钱的能力还是很强的，比如现在推出的“百万计划”，一方面奖励优秀员工比亚迪“秦”，还会奖励平台白帽子，设立了一百万到四百万的奖金，就想着怎么把这些钱花得让做安全的人感到受到鼓舞。

其实还有更长远的打算，我一直在想，等我有钱了，我就投资一些安全团队，我是经过的，知道他们真的非常苦，都是在为自己的爱好而拼命。

张耀疆：说实话，你们一直在西安，还是有点吃亏的，有没有考虑去北上广？

马坤：我们不会去北上广，就是扎根西安，这里不会太浮躁。我觉得互联网安全是不分地域的，所以我们强调人才本地化的重要性，慢慢这些人留住了，别人挖都挖不走，这对我来说是一种欣慰。人才流动少，来了就站住了，这是我们四叶草安全的一大特色。

张耀疆：未来有什么战略上的打算？

马坤：也谈不上战略吧，就是一些想法。

首先是希望部门能够协调得更好，让服务和产品继续发光发亮。很多安全公司不愿意养服务人员，更情愿养销售，但服务又必不可少，那就需要通过其他途径，我们平台就是一个很好的选择。同时要做好产品的商业化。另外，也有个长远的打算，想让小伙子们去国际赛场上亮亮相，在更大的领域发出声音，同时让产品去国际舞台展示。社区化这块还会继续坚持。我们的激励机制（“百万计划”）对写插件已经有明显的效果了，现在社区里有十几号人没日没夜在写，写路由、工控、摄像头、安全设备的漏洞插件。商业化的插件则是我们自己写，社区里提交的插件都是可以共享的。

此外，我曾赌气说要让西安人都知道我们，但现在这点还没做到，继续努力吧。

张耀疆：感觉你做安全完全是凭着一腔热爱？

马坤：是啊，就是因为喜欢，你想想，安全很难赚钱，如果是为了赚钱，干嘛做这个？为了做安全公司，我把过去积累的都扔掉了，完全是因为自己喜欢。既然不考虑短时间盈利，那就还是把事情做好吧。回想过去，曾经有过很多选择，我都没有动心，比如拿暴雪的源码，你说算不算诱惑？当然是了，但我并没有动摇，既然那时候都很坚决，后来也就更不会为一点小的利益而纠结了。


张耀疆：最后问一下，你喝酒到底有多猛？

马坤：说实话，以前还真不喝酒，都是开公司之后才开始喝酒的。但我有个习惯，就是不怎么与客户喝酒，而只和朋友喝，和兄弟喝，和团队喝。

我酒量其实一般，就是胆子够大。在我看来，喝酒一方面是真性情，也可以提升公司的凝聚力，大家在一块儿，虽然比较艰苦，工资不高，但是氛围好。所以我非常珍惜团队，记得大家的好，知道感恩。另外，也是觉得搞安全的太辛苦，和志同道合的朋友一起喝喝酒，相互诉诉苦吐吐槽，也是一种宣泄。
