1.为何外国科技公司喜欢通过“合资”抢滩中国？  
“13亿人口，近7亿网民”。  
国内网民数量相当于全球网民总数的24%左右，这就是当下中国互联网市场的“底气”，你可以不来，但是，错过了可能就是你的损失。  
“合资、合作、独资”，原本是外国公司进入中国可选的三种模式，但当前，合资越来越成为外国科技公司重新布局中国市场的最优选择。首先，“合资”模式能最大发挥国内合作伙伴优势。其次，“合资”模式能绕开部分监管进入特定市场。最后，“合资”模式或可实现外国公司利益最大化。  
伴随惠普、思科、微软、谷歌等重新调整中国市场布局策略，可能会引发更多外国科技公司效仿和借鉴，选择此种方式进入中国市场。事实上，在“互联网专车”领域，作为新一代外国科技公司代表，Uber已经开始这么做了。  
文/百度百家

3.Windows中国定制版，透露出中国与微软哪些考虑？  
对于微软而言，通过适应中国制度的产品改造，赢得更为广阔的中国市场，更加有助于在未来改变微软在互联网时代的地位。  
在这届世界互联网大会上，中国电科与微软宣布成立合资公司，共同研发基于Windows的操作系统，面向中国政府和企业提供定制版的Windows操作系统。  
对中国操作系统而言，重构一套基于Windows基础上的操作系统并非痴人说梦，同样也避免了开发一套操作系统而无应用软件的尴尬局面。对于微软而言，通过适应中国制度的产品改造，赢得更为广阔的中国市场，更加有助于在未来改变微软在互联网时代的地位。  
文/钛媒体![](../Images/33f2980eac86abb64a3ce43498963186.png)

就自主可控操作系统而言，从民族主义到改良主义，不能不说是稍有进步，但是，这种不分市场一概而论的中国特色，是否真的能够终成气候，现在还是要打个问号的。有些领域如军工机要也包括政府要害部门，不走“资本主义”绝对必须，但对广大通用型市场来说，“在Windows基础上开发具有中国特色的操作系统”，总觉得有点怪怪的哦

4.InterApp：可窃取周围任意手机数据的系统  
近日，有一个公司称他们开发了一个情报系统，可以窃取所有智能手机用户的数据。  
  
以色列Rayzone组织开发了一个叫做InterApp的系统，可以窃取任何手机用户的隐私信息，但条件是手机要在系统附近。被搜集的信息包括用户邮件地址和密码、联系人列表、Dropbox、手机操作系统、照片、上网历史记录、地理位置等等。  
最令人不安的是，该系统并不需要攻击手机，只要用户手机连上WiFi就行了。

5.英国政府开源了其大规模监控软件  
英国的监听机构国家通信情报局（GCHQ） 在 GitHub 上开源了其第一个项目，这是一个用 Java 编写的名为 Gaffer的海量图数据库。政府部门开源这并不值得惊奇，但令人吃惊的却是其开源的是一个用于监听民众的大规模监控软件。  
这一举动在黑客社区引发了大量的反思和讨论，他们争论它是否该用还是不用。  
一些人称赞了政府部门的这一举动，这使得社区也可以使用这些技术和基于它们进行开发；而另外一些人则建议拒绝掉这个项目，以维持计算机科学的正直性，因为它来自一个不道德的部门。

6.Juniper ScreenOS后门是谁做的？  
12/17Juniper公司发布安全公告，宣称在内部代码审计中发现了ScreenOS的两个后门已经被修补，需要用户升级防火墙。  
这两个后门是在源代码中植入的，谁这么有本事？是什么动机呢？  
从技术上分析，这么Low的做法不是NSA的水准。从非技术因素上分析，美国有官员告诉CNN，是外国势力所为，美国的情报机构没有做，最可疑的中国和俄罗斯。安全圈子的怀疑又加上了UK甚至以色列。Juniper在公告中说后门是在“internal code review”过程中发现的，这个也值得怀疑。另据说ScreenOS的研发是在中国做的，有没有可能是内部码农被收买？无间道总是最精彩的故事。
