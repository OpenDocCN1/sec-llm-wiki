# 启航今“安在”，耀疆有话说

“安在”是什么？耀疆是哪位？  
  

都不重要，重要的是你能看到此文。若看到了，你自然知道，若看不到，恰又是“安在”向往耀疆欲说。  
  

![](../Images/ec919d3fb798ade892d21a6b2ab62e20.png)  

去年初，我赶趟儿开了个人微信公号（可乐圈），起初是想逼自己码字儿练摊儿，可这一练就一发不可收，三天两头不吐不快不写不休。不过，毕竟是自娱自乐，没推广少显摆，粉丝量挤牙膏般一点点增长。  
  

凑场子看热闹的倒也罢了，可总觉得还缺点什么。  
  

作为一名信息安全“老兵”，在过去两年里，眼见互联网风起云涌颠覆频现，为免自闭，自然就多了与各界的交流，包括业内一线大咖。潘柱廷、方兴、季昕华、吴鲁家、谈剑峰、金湘宇、欧阳梅雯，都曾叱咤风云，言谈举止间满是阅历和故事。这种交流多了，逐渐意识到，中国信息安全产业，不正是在他们的见证、参与和引领下一点点发展起来的吗？可他们的话语权，又何曾有过最通畅最直接的表达渠道呢？传统以合规驱动的信息安全市场，基本上被权威如院士们所指点，官场说官话，学术说虚话，自上而下的沉闷风气，又怎能适应当前自下而上的云涌波澜？  
  

人人都可自媒体，信息安全需要新媒体，四处散落着的点点烁烁，都是思想、理念、观点和创新，该是汇聚成辉交相绽放的时候了。  
  

新媒体，是的，“安在”正是新媒体。  
  

可是，“安在”到底是怎样的新媒体？说实话，很长一段时间里，我都在思考这个问题。信息安全新媒体并不鲜见，前有安全牛、Freebuf、易安在线，都做得不错，那“安在”，有何不同？  
  

“安在”不是即时资讯，我们不想做简单的信息搬运工。“安在”不是技术展台，挖漏爆黑不是我们专长。“安在”也不是社会活动和资源对接平台，我们没有也不依赖于任何背景。  
  

信息安全作为一项产业，对其发展的认知，基本上可以从事件、技术、标准和人物这四个维度展开。每一次热点事件爆发，都会助燃一番信息安全热议；每一次技术演进，都会推动信息安全建设向前；每一次标准和法规的出台，都会以合规之力驱动产业发展；而每一个人，无论是信息安全事业的启蒙者，还是亲历者、见证者或者开拓者、实践者，都在这二十年风雨激荡中留下过不可磨灭的鲜明个性和浓墨重彩。

  

我认识他们，我想了解他们，我想让更多的人认识并了解他们。  
  

聚焦人物，关注热点，互动交流，传播服务，“安在”要做最有内涵的信息安全新媒体。比如现在，我们即将推出的“中国信息安全人物图谱”，约访典型人物，深度专题报道，线上线下互动。在攻防世界和杂色江湖，也许他们曾身披神秘外衣，但你会看到，他们其实个性鲜明各具风骨，都是有内涵有故事的人。  
  

一花一世界，一人一乾坤。信息安全前世今生，也许都在他们身上了。  
  

好了，到这里，你也许大致对“安在”有所印象了，那耀疆呢？我是何人？为何“安在”？  
  

前文书说，我是信息安全一名“老兵”，不谈职业身份，现在想做一名“安在”的开拓者和传播者。首先，作为信息安全圈内人，与大咖对话，至少不会陷入“专业恐慌”；其次，从事信息安全专业咨询（安言咨询）十多年，相比技术从业，又是圈内的“圈外人”，中立客观，进退有方；再有，我奉情怀，与人交流即在这性情相通；还有，我善讲能写，具备基本的媒体素养；最后，很重要的一点，我颜值尚可，与人面对不至讨嫌。兴趣所在，抑或使命使然？都有，所以，我在“安在”。  
  

有专业而不晦涩，有趣味而不庸俗，有态度而不做作，有内涵而不虚骄。  
  

快来关注！  
  

启航今“安在”，耀疆有话说。
