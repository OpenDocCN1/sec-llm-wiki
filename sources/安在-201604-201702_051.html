黑客礼物大作战：十款推荐礼物包TA心花怒放

一般偏感性的人都容易用小礼物被哄开心，比如从路边摘一朵花送给姑娘，她会开心好几天。但对一些偏理性的人，就很难用一个简单的礼物打动他了。以写代码为职业的黑客是偏理性的人群的典型代表，一般的礼物很难打动他们。下面这个笑话很形象的描绘了他们：

 

一个黑客骑着一个很漂亮的自行车到了公司，另一个黑客看到了他，问到，

 

“你是从哪搞到的这么漂亮的车的？”

 

骑车的黑客说：“我刚从那边过来，有一个漂亮的姑娘骑着这个车过来，并停在我跟前，把衣服全脱了，然后对我说：‘你想要什么都可以’”。

 

另一个黑客马上说到，“你绝对做了一个正确的选择，因为那姑娘的衣服你一定穿不了”。

 

不过，世上无难事，只要送对了礼物，黑客那颗坚冰的新还是可以融化的。下面列举的这几种礼物对于IT业外的人来说，也许根本不感兴趣，但对于黑客来说，却是非常有吸引力的，因为他们将运用这份礼物在新的一年当中实现更多探索与突破。下面就让我们看看都是些什么礼物吧：

 

1. 匿名工具：Onion Pi

 


 

作为目前最具人气的“万金油”匿名工具，Tor in a box是一款即插即用的设备，可以保证大家匿名在线。虽然绝大多数的此类产品都是打着“匿名”的旗号，但实际上毫无作用，甚至让大家的隐私与安全面临风险。但我们可以花上69.95美元为黑客好友送出一份“Onion Pi”。

 

2. Attribution Dice

  

在Attribution Dice（20美元）的帮助下，任何人都能够瞬间成为一位身手不凡的安全顾问，时刻抢在各类头条前面了解国际形势！每次发生安全违规事件时，黑客们都会发现各大媒体及相关企业仍然在不断以过时的口吻、陈旧的思路、古老的审视方式进行公布。

 

现在形势有了变化，有了Attribution Dice这款利器后，我们再也用不着关注什么新闻头条，只需轻轻地摇动这几个虚拟骰子，最近发生的安全事件就会自动呈现，是不是非常炫酷!

 

3. 21 Bitcoin Computer

 

 

毫无疑问，钱永远是最受欢迎的礼物！但是如果你觉得直接甩票子太俗，不妨试试接下来这款礼物——21 Bitcoin Computer。21 Bitcoin Computer适合用于购买并销售数字化商品及服务。大家可以利用它创建比特币支付API，建立自己的个人数字产品商店，以付款方式雇佣他人分享各位的在线内容，或者在这里分享您的游戏心得。

 

虽然价格不菲(395美元)而且存在一定争议，但它确实是一款拥有巨大潜力的玩具，而且21公司也决定在近期内推出面向该设备的开源软件包，一起期待吧。

 

4. Gentleman的Bogota开锁工具与练习工具套装

 

 

传统观念认为，所有的黑客都应该拥有娴熟的“开锁”技巧——无论是虚拟安全锁还是物理机械锁。但是他们真的都能做到吗？未必见得，所以接下来为大家推荐Gentleman出品的Bogota开锁工具包（34.95美元）。

 

这些轻量级小工具能够被轻松藏在我们的领口、帽子、外套、马甲、衣角或者其它任何你想放置的位置。如果各位的黑客朋友希望认真学习“开锁”技巧或者锻炼自己的动手能力，还可以为其送上一套练习工具套装。

 

5. Inverse Path USB Armory

 

 

每位黑客都应该拥有一款USB Armory作为新年礼物。Inverse Path USB Armory（售价130美元）从表面上看只是一款小小的U盘，但其本身却是一套完整的便携式计算机(采用800 MHz ARM处理器与512 MB内存)，Inverse Path USB Armory的设计目的是作为个人安全应用的便携式平台，而且突出的实际效果也使其被誉为“安全设备中的瑞士军刀”。

 

6. Hack-A-Day礼品卡

 

 

作为黑客文化的基石，Hack-A-Day拥有一套种类齐全的货物储备，同时发售礼品卡以方便买家从中购买自己喜爱的商品。在这里我们能够找到Bukito便携式3D打印机（售价899.97美元），人气极高的Facedancer21与Gootfet42，名为Lightblue Bean的低功耗蓝牙Arduino单片机以及袖珍开源机械手臂Mearm等。

 

7. 电影《黑客》20周年蓝光版

 

 

攻击地球！ 1995年上映的计算机朋克电影《黑客》至今已经过了20周年生日，而这部经典之作如今也推出了特别蓝光版，是不是特别期待呢？

 

据悉，此次《黑客》20周年蓝光版中附带长达1小时的制作纪录片，内容包含大量与电影相关的视频与音频资料，以及Matthew Lillard、Fisher Stevens以及Penn Jillette专访内容。另外，黑客技术顾问Nicholas Jarecki与Emmanuel Goldstein、导演Iain Softley以及其他众多参与影片制作与风格设计的工作人员也将一同现身。真的非常值得拥有，不是吗?

 

8. 黑客最期待的助眠利器：Re-Timer

 


除了每天变着法的研究计算机系统外，黑客们还需要与自己的生理系统对抗，其中最困难的就是如何调整睡眠周期与对抗困倦感？别担心，接下来这款利器一定可以帮到你——Re-Timer(299美元)。

 

这款极具未来感的眼镜加上工具套装能够帮助调节昼夜节律，并抑制人体褪黑激素的生成(也就是让我们的身体产生疲劳感和困倦感的因素)。

 

基于25年研发外加3年的全球市场实践，目前Re-Timer已经拥有了属于自己的一套时差计算应用程序，同时其Sleep App for Fitbit还能够根据实际睡眠规律制定出适合使用者的定制化运作模式。

 

9. USB Rubber Ducky Deluxe & LAN Turtle

 


作为黑客、渗透测试人员以及IT专业人员的最爱，USB Rubber Ducky Deluxe（售价42.99美元）是一款跨平台（支持Windows、Mac、Linux以及Android）测试与实验的设备，它能够以键盘的形式被系统识别，所以可以预见其中包含着多少可能性了吧。

 

而与之相配套的正是另一款礼物——LAN Turtle（售价50美元），这款隐形式系统管理员与网络渗透工具能够通过其简单的图形shell实现远程访问、网络信息收集以及中间人监控（所有的应用都能够在其USB以太网适配器下实现）。

 

10. TechShop礼品券


 

对于黑客来说，如何学习和提升是非常重要的课题，而TechShop礼品券这时就能发挥作用了。作为一家集制造、原型设计工作室、黑客空间与学习中心为一身的体系，TechShop提供总值超过100万美元的专业设备与软件，提供全面的技术指导与专家团队，确保您享受整个安全、充实而又极具价值的流程体验。

 

目前TechShop在亚利桑那州、加利福尼亚州、密歇根州、密苏里州、宾夕法尼亚州、德克萨斯州以及弗吉尼亚州/华盛顿特区设有分支机构（某些州拥有多套现场设施）。未来其还计划逐步进军圣路易斯与法国巴黎。
