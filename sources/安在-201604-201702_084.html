纪录片是以真实生活为创作素材，以真人真事为表现对象，并对其进行艺术的加工与展现的，以展现真实为本质，并用真实引发人们思考的电影或电视艺术形式。

——所谓“纪录片”

 

 

有人说纪录片就是窥视他人的生活，角色互换，体验生活在别处的感觉，也许不对，纪录片让你知道世界并不是你所想象的样子，无论震惊触动，还是无动于衷，都是你“受力”之后的表现。

 

每个人都不是全知全能的上帝，地球圆圆球面世界，有你不知道的人，在你不知道的土地上，跟你笼罩着一样的太阳，却应对着不一样的生存或死亡，上升或落幕，也许纪录片是通向人间生活的一个管道。来吧，看几部网络安全纪录片，一起领略你所不知道的互联网世界。

 

1. 网络战威胁 （Cyberwar Threat）——美国2015年上映

 

 

导演: 詹姆斯·班福德 / Chris Schmidt；
主演: 詹姆斯·班福德 / Eric Chien / James Comey / Shane Harris ；

片长：53分钟；

 

该纪录片详细介绍了网络战的现状，并警告我们现在已经进入了新的由国家力量支持的网络战争的军备竞赛之中。目前，每个人都理所应当地认为各个国家都拥有国家级网络武器，它们正在变得更加高端复杂，从监听侦查行为向破坏行为发展。

曝光美国情报机构如何致力于国家级的网络战争,除了花费数十亿美元采集和分析世界大部分国家的电子通信,还涉及网络战争、远程控制、植入性病毒、黑客攻击与反攻击等。斯诺登公布的文件当然是本片的重要资料来源,众多网络安全领域的专家为大家答疑解惑,抽丝剥茧。

 

影片介绍了有史以来最出名的网络武器——震网 Stuxnet 蠕虫病毒。从“ABC 武器”—原子(Atomic)武器、生物(Biological)武器和化学(Chemical)武器,到今天新的“D 武器”—数字(Digital)武器,而几乎没有任何国际公约或者监管机构可以监控这些“D 武器”的使用。

 

本片揭示了在愈演愈烈的网络攻击面前,任何个人和国家都无法幸免于难的令人不寒而栗的客观现实。  

 

2. 深网：比特币和丝绸之路未透露的故事——美国2015年上映;

 （Deep Web：The Untold Story of BitCoin and Silk Road）

 

 

导演: 亚历克斯·温特；
主演: Gavin Andresen / Andy Greenberg ；

片长：90分钟；

 

在《Deep Web》中，导演Alex Winter 提到了丝路的群体精神、偏自由主义的政治倾向，以及 “丝路”创始人Ross Ulbricht关于丝路使得毒品交易更安全的言论，不过，他并不想给出一个明确的结论。

 

Winters 说，“变化来的如此快速，如此激烈，因此，这也带来了许多的恐惧和误解，丝路落入了我们面临的最具争议的三个领域：虚拟空间、毒品战争以及一种不受监管的货币影响下的财务市场。但最终，它只是一个黑暗网络中的社群。看到它被如此对待，我的感觉是，人们构建了神话，然后，他们攻击了神话。”

 

通过《Deep Web》，Alex Winter 想要解构的一个神话是：穿着连帽衫的孤独黑客。

 

他说，“总是有些穿连帽衫的不法之徒，没有朋友，完全孤独，马基雅维利信徒或者有着反社会的观点。现实情况并非如此，当面对技术变革的时候，我们总是会带着一种恶意的想法。

 

我们在恶意丑化这一代人，而这是了不起的一代人。这些人被丑化之后，普通公民很难表示说，我想翻到围栏的另一边，那里生活着一群‘怪人，我们需要更好的隐私工具。我们需要更好的加密手段。我们需要走进黑暗的能力。有一种想法是，如果你没有可隐藏的东西，你就无需恐惧。这种想法是非常有破坏性的。”

 

3. 第四公民 （Citizenfour）——美国、德国、英国2014年上映；

 

 

导演: 劳拉·珀特阿斯
主演: 爱德华·斯诺登 / 朱利安·阿桑奇 /

片长：114分钟；

 

《第四公民》将能高度还原“棱镜门”事件始末，为观众真实揭秘身处漩涡中心的爱德华·斯诺登。
　　

纪录片导演柏翠丝本人也是“棱镜门”事件的核心人物，正是在她和《卫报》记者格仑·格林沃德的协助下，斯诺登才得以将美国国家安全局的监控丑闻公之于众。而柏翠丝与格林沃德也因此荣获普利策奖。

 

片名“第四公民”（citizen four）正是斯诺登早期与柏翠丝邮件沟通时使用的匿名代号。2013年6月，当柏翠丝第一次飞往香港与斯诺登见面的时候，她随身携带的摄像机也真实记录了当时的场景。《第四公民》将能高度还原“棱镜门”事件始末，为观众真实揭秘身处漩涡中心的爱德华·斯诺登。

 

4. 零日／零日网络战 （Zero Days）——美国2016年上映;

 

 

导演: 亚历克斯·吉布尼
主演: 乔安妮·塔克 / 马哈茂德·艾哈迈迪内贾德 / 乔治·W· 布什；

片长：116分钟；

 

一个全新型态的网路超级病毒，突然遍布全世界的电脑，一开始无伤大雅不受重视，直到随着时间累积，许多基础建设的系统都一一被攻击掌控，比过往任何一种病毒复杂几十倍，甚至可能全面瘫痪人们的生活。

 

随着深入调查，揭露这个超级病毒Stuxnet，背后竟是美国与伊朗战争行动的阴谋，伊朗核武危机无法以政治手段解决，美国便对伊朗的网路展开攻击。无法回头的网路攻击逐渐失控，人们生活中各式控制系统都备受威胁，包括发电、交通、通讯、ATM、医院都将不堪一击，网路安全问题全球都可能遭到入侵，下一次的世界大战危机似乎也一触即发。

 

5. 黑客军团故事（We Are Legion: The Story of the Hacktivists）——英国2013年上映；

 

 

导演: Brian Knappenberger;

主演: Anonymous组织;

片长：60分钟；

 

《黑客军团故事》讲述的是世上最着名的黑客集团——匿名者。

 

占领华尔街、反全球化运动袭卷全球，在伦敦的示威者纷纷带上有着一双细眼、山羊胡与诡异微笑的现代版盖伊．福克斯「V怪客」(V for Vendetta)的面具，维基解密的发起人亚桑奇莅临演说也戴了「V面具」，更引起示威者纷纷效尤，使得「V面具」俨然成为此波全球抗议示威中最独特的文化现象。

 

导演布莱恩‧ 耐本伯格(Brian Knappenberger)《骇客军团故事》完整纪录这波方兴未艾、结合网路与现实的公民运动。

                                  

《We Are Legion》组织由一群网络上的匿名者(Anonymous) 组成，成员来自网路世界的各个角落，他们在网路上以电子邮件、木马程式攻击企业、政府网站，在现实中更戴起V怪客面具发动占领华尔街、反核游行、反全球化等抗争，充满创意而活泼的文化现象不仅表现出民众对抗企业、政府的怒火，更将网路世代的公民意见化为实际的行动参与。

7. 互联网之子 （The Internet’s Own Boy）——美国2014年上映；

 

 

导演: 布莱恩·耐本伯格;

主演: 亚伦·斯沃茨 / 蒂姆·伯纳斯-李 / 科利·多克托罗 ;

片长：104分钟；

 

Aaron Swartz，1986年生，3岁开始玩电脑、13岁参与构建RSS、15岁参与构建互联网知识共享标准、17岁读斯坦福大学、18岁辍学并与人创立Reddit网站、19岁卖掉Reddit的股份成为百万富翁，之后这样的一个计算机天才放弃了继续在IT产业里发大财，走上了为信息自由而战的公益事业道路，最终因为严重挑战了有关版权方的利益引来入狱30年、罚金100万美金的刑事指控，2013年自杀身亡。

 

《互联网之子》由Brian Knappenberger 执导。该纪录片用凝重和悲凉的视角来回顾Swartz的一生，从童年到公众生活。纪录片汇集包括Swartz本人在内的多个采访，他的成就和参与的战争，以及导致他自杀的极具争议的起诉。虽然小编不太认同Aaron关于信息自由和版权的观点，但着实为这样一个敢于为自己的理想而战的英雄感动，强烈推荐这个纪录片！

 

8. 我们窃取秘密：维基解密的故事 （We Steal Secrets: The Story of WikiLeaks）——美国2013年上映；

 

 

导演: 亚历克斯·吉布尼;

主演: 朱利安·阿桑奇 / 阿德里安·拉莫 / 布拉德利·曼宁 ;

片长：130分钟；

 

《我们窃取秘密》围绕阿桑奇创办的黑客集团，详述了朱利安·阿桑奇（Julian Assange）维基解密网站（WikiLeaks）的诞生，这个网站助长了美国有史以来最大的安全缺口。影片描述了这一神秘网站的兴衰，其中穿插着美国陆军士兵布拉德利·曼宁（Bradley Manning）泄密事件，这个令人不安的高智商士兵从美国军事和外交服务器上下载了几十万个文档。

 

该纪录片用全方位角度解析主题，从1980年的运动开始，详细描述该组织数十年来收集来自全世界的信息的背景和历史。影片中还出现对阿桑奇 和曼宁的采访，揭示这个组织远不是人们表面看到的这么简单。

10. 世界黑客大会DEF CON （DEF CON：The Documentary）——美国2013年上映；

 

 

导演: Jason Scott Sadofsky;

主演: Dead Addict / Ryan Clarke / Chris Darbro ;

片长：110分钟；

 

DEF CON名称源自军事上的“战备状态（Defense Condition）”的缩写，作为一个会议的名称，“Con”也可解读为“Conference（会议）”。此外，很多DEF CON小组的早期成员都是盗打电话破解者，他们喜欢的“DEF”也是电话键盘数字“3”上面印着的字母。

 

DEF CON由绰号为“Dark Tangent（黑暗切线）”的黑客Jeff Moss创办，是世界上最知名的“黑客大会”。 DEF CON每年在美国内华达州的拉斯维加斯举行，第一届DEF CON在1993年6月举办，因此它也是最古老的网络安全会议之一。

 

该纪录片通过全面的视角，为大家详细的记录了DEF CON大会为期4天的各项会议、事件以及与会人员，并涵盖了DEF CON大会成功的历史进程和独特经验。

14. 鲶鱼  （Catfish）——美国2010年上映；

 

 

导演: Henry Joost / Ariel Schulman；
主演: Melody C. Roscher / Ariel Schulman / Yaniv Schulman ；

片长：87分钟；

 

在线约会、网友见面对今天的我们来说已经见怪不怪、习以为常，在五年前还不是这样。这部由新人导演亨利·乔斯特携手艾瑞儿·舒勒曼执导的一鸣惊人之作《鲶鱼》，以纪录片的形式，呈现出了一段交织在爱情与家庭伦理间的生活启示录。

15. 比特币的崛起  （The Rise and Rise of Bitcoin）——美国2014年上映；

 

 

导演: Nicholas Mross；
主演: Gavin Andresen / Brian Armstrong / Margaux Avedisian ；

片长：96分钟；

 

回头去看过去几年发生在比特币身上的事，仍然难以相信它是真的。

 

这么一个由至今匿名的人用纯数学逻辑创造出来的、基于互联网的虚拟货币体系居然在已有金融体系和物理世界上搅起那么大的风波。它的价格曾经攀升到 1 比特币兑换 600 多美金，如今也保持在 250 美金左右的价格。

 

这部纪录片记录了当比特币还停留在 Nerd 圈子时，一位坚定的比特币信仰者和他的哥哥记录比特币在接下来几年如过山车一样的疯狂经历。也许你当时关注过关于比特币的新闻，仍然，这部纪录片提供的视角很独特。

 

它不仅近距离拍摄了跟比特币有关的关键人物，还以一个 Nerd 和另一个 Nerd 聊天的方式作了很精彩的采访。看完后你不仅对比特币有新的认识，更重要的是你感觉自己与这群 Nerd 有了联系——他们是真正理想主义的一群人，从本质去思考问题，不局限在既有规则，对事物抱有信仰，并有能力（编程和互联网）去实现它——你会深切地感受到 Nerd 正在改变世界这个事实。

18. 《互联网时代》——中国2014年上映；

 

 

导演: 孙曾田 / 石强 / 高宏明 / 彭辉 / 赵曦 / 郭威；

主演: 蒂姆·伯纳斯-李；

片长：10集，单集50分钟；

 

《互联网时代》是中国第一部、也是全球电视机构第一次全面、系统、深入、客观解析互联网的大型纪录片，全片以互联网对人类社会的改变为基点，从历史出发，以国际化视野和面对未来的前瞻思考，深入探寻互联网时代的本质，思考这场变革对经济、政治、社会、人性等各方面的深远影响。该作品旨在引导全社会更准确、全面地认识和理解互联网，更深刻地思考互联网，有准备地迎接一个新时代的到来。

 

电影好看，因为你总是可以看到自己想要，却无法企及的生活；但是，记录片也同样有意义。可能潜意识里我们都觉得纪录片的主题就必须沉重，都必须经历生死，都必须疼痛黑暗。

 

其实纪录片和电影最大的区别就是：纪录片看过一次之后，就能记得特别深刻，补的是眼界和震撼。而电影补的是情感和情绪，所以容易遗忘。其实，纪录片的魅力可是一点都不输给其他类型的影视作品哦，只要你用心体会！
