# 洋葱吴洪声：“奶罩”哥如何罩住账号安全？|新锐

在安全圈，1985年生的吴洪声算是少年成名。20岁时，吴洪声凭着兴趣开发了DNSPod，后者不仅成了很多网站的基础设施。还在他26岁时被腾讯斥资4000万元收入囊中。

 

背靠腾讯的资源，吴洪声却在30岁时重新启程，启动了新的创业项目“洋葱”。这一次，他试图为公众和企业提供一款好用的密码和权限管理工具。 

![](../Images/e722bd3303dff533d941e55c80b097a9.png)

 

“洋葱”能否成为一门好生意？对已经成功过，却依然年轻的吴洪声来说，这是个他愿意去挑战的问题。

 

**明星极客的二次创业**

 

吴洪声眼瞅着是一位壮士，但他的昵称却叫“奶罩”，简单粗暴，挥发着荷尔蒙的味道。问起这个昵称的起源，他告诉我们一个古老的典故：他当年的QQ名是两个圆（^●\_●^），被好事者调侃：这很像“奶罩”嘛。

 

“奶罩就奶罩！”吴洪声最后也笑纳了这个外号，干脆将那两个圆干掉，直接改成了“奶罩”两个大字。

 

不过，在与他几个小时的交流中，这样的黑色幽默并未出现过。和2015年的照片相比，如今的吴洪声要清瘦一些，在交谈中经常流露出沉思乃至忧郁的神情。对于一个创业者来说，这种神情十分常见。

 

吴洪声不是一个爱热闹的人。在采访的前不久，吴洪声刚刚将他们公司从华丽的望京SOHO搬到了不远处的一栋商住两用楼，尽管无法用办公地给人带来高大上的错觉，但价格便宜了一大截，对大家的办公效率也并无影响。他甚至在认真考虑，是否还要继续留在北京，而是试一试迁往上海或杭州。

 

当下的创业经历，可能是吴洪声平生最具挑战性的岁月。年少成名的他，之前的人生可用一帆风顺来形容。尽管家境一般，但这个来自湛江的小青年早在读中专时，就靠着做站长成了高收入群体。在那个小镇公务员月薪也不过千元的年代，吴洪声站长平均月入2万元。几年奋斗，就给家里买了套房子。

 

之后，吴洪声前往北京，在一家在线广告公司做技术员。正是在那里，他自己“捣腾”出了DNSPod，这成为他确定江湖地位的代表作。

 

![](../Images/204bdf4f6e1edc500a84c5569f28274e.png)

 

在“校长”谭晓生的呼唤下，已经觉得网站的工作缺乏挑战性的吴洪声又进入了Myspace。作为一个懂技术的BD，吴洪声算是国内最早引入“开放平台”模式的先驱，也因此大大拓展了人脉。但可惜的是，随着MySpace的没落，这个“开放平台”的先驱成了先烈。

 

此后，吴洪声决定重操旧业——把DNSPod做精、做细。他希望在保持原有开放免费的同时，通过VIP服务获取收益。从这个角度来说，吴洪声的第一次创业可谓顺风顺水，从开业第一天起，这个只有一个人的创业团队就开始盈利。

 

吴洪声并不追求客单价，他认为：“不需要多，只要有几千个付费用户，你就会活得非常好。”而DNSPod显然是一个能够为他提供足够客户基数的产品。

 

2011年，腾讯投入4000万元收购了DNSPod。吴洪声也因此成为腾讯的一员。3年后，他决定离开腾讯，再一次创业。

 

回顾吴洪声并不漫长的职业生涯，不难发现他是个颇爱折腾的人——靠着自己的折腾和技术，他研发了DNSPod；靠着“折腾”来的人脉，他，先后遇到了曹政、谭晓生此类的伯乐，并且在职业经历中横跨了技术与商业；靠着“折腾”的心，他不愿意做没有挑战性的事情，“啥玩意做到没挑战性了，就算赚钱也不做”。

 

对这样一个人来说，二次创业可谓水到渠成。

 

**从DNSPod到洋葱，逻辑一脉相承**

 

吴洪声为什么会“突然”去做一个叫“洋葱”的密码及身份管理工具？对于吴洪声自己来说，这个决策顺理成章。

 

![](../Images/a08324650242041899b7bd297efa19b1.png)

 

“做DNSPod的那段时间，是我和黑客打交道最多的时候。当初直接攻击网站服务器已经越来越难，所以黑客就转而攻击域名。后来，我们的防范水平也在不断提高，域名攻击也越来越难了，于是黑客就转而攻击账号。”

 

吴洪声举例，如果一个域名管理员不小心犯了低级错误，很没有安全意识地设置了强度过弱的管理员账号密码，那么这个域名的账号密码一旦被盗，域名也就不攻自破了。此前，CSDN上的用户信息泄露，有不法分子拿着CSDN的库来DNSPod撞库，结果成功率极高。

 

这也让吴洪声意识到，账号体系已经成为安全的薄弱环节，而场上并没有很好的解决方案。

 

吴洪声认为，撞库之所以容易成功，是因为人类记忆不同账号、密码的困难。面对越来越多的互联网服务，每个人都可能会上百次地注册账号、设置密码，尽管有一小部分谨慎的人会设置截然不同的账号密码并记录在册，但绝大部分人仍然习惯于使用同一个账号和密码。此前，为了解决这一问题，国外有类似的应用软件，能够自动生成密码并本地存储，来帮助用户解决海量账户的问题。但吴洪声想得更多，他希望洋葱实现更多功能。

 

**从账号安全开始拓展**

 

尽管密码管理是个痛点，但很难说这可以称之为“刚需”。如果仅以此为切入点，做出一款超级APP，恐怕还是一件很困难的事情，而且，后续的变现与盈利渠道并不清晰。

 

吴洪声意识到，他需要切入企业级市场，才能获得成功。而要打准企业级市场的痛点，企业内部繁杂的权限体系就成为他最好的切入点。

 

即使对一家百来人的小企业来说，在劳动力流动频密、人员分工细化的当下，如何管理每个员工的权限，也不是一个小问题。一个新员工加入企业后，从WiFi密码、VPN到门禁、内网账号等在内的所有身份权限，都会成为其融入新公司的重要组成部分。以往，HR的一封邮件或者一张小纸条会记载这些信息，但问题也随之发生：如果员工离职了，怎么办？这些账号要么覆水难收，带来安全隐患，要么就必须一个个手动注销，不但费时费力，而且容易出错。在一些大型互联网公司，员工的入职、离职甚至需要在一个专门的办事大厅中进行，一圈流程跑下来，实在费时费力。

 

![](../Images/11c93a570e64f4372380e2bbbd810d5b.png)

 

洋葱想要解决的，就是企业权限管理的一键式操作。在他的演示中，他轻松地利用“洋葱”，为一个新员工一次性开通了所需的全部账号，并自定义了这个员工在每一处的权限；在该员工被设为“离职”后，他则可以一键注销其所有的账号与权限。

 

当然，这个商业模式也面临两大挑战。最大的挑战是信任问题，因为权限和账号密码都是一个人和机构最宝贵的数据资产，但是如今全部放在“洋葱”一个篮子里，这样是否安全？

 

对此，吴洪声的回答是，这些账号密码信息都在本地进行私钥加密的，在上传的过程中还有二次加密，所以从技术上上保证了其安全性。

 

另一位资深安全人士也告诉记者，还可以通过商业模式的设计，比如相关数据信息进行第三方托管，避免堡垒从“洋葱”内部被攻破。

 

另一个挑战就是第三方应用的授权。“洋葱”如果想要尽可能便捷，就需要和尽可能多的主流第三方应用进行合作，以便可以直接从洋葱跳转到其他应用上。这一方面的商务合作并不容易进行，洋葱必须拿出足够的理由，说服其他应用参与合作。目前，“钉钉”等第三方应用已经陆续接入“洋葱”，而吴洪声仍在与更多应用接洽。

 

![](../Images/a688f4eae3aa0e2c729da14bb66017ed.png)

 

总而言之，吴洪声正在试图让安全与便捷这两件天生冲突之事，在某种意义上达成和解与共存。这并不简单，但值得一试。吴洪声亦相信，“洋葱”有机会成为他的下一个DNSPod——毕竟，他只有31岁，还有很多可能性值得探索。
