每天，我们都在改变世界，但是绝大多数人是没有那么多时间来让这种改变产生意义的。而且改变从来都不会立竿见影，这是一个漫长的、循序渐进的、让人精疲力尽的过程。并不是每个人都能承受如此的。

——《黑客军团》

 

 

看完上期安利的黑客电影后，很多人留言大呼不过瘾，强烈要求小编补上黑客电视剧方面的资源。想想也是，闲暇时刻约上自己的技术小伙伴，准备几包辣条，一起看部精彩的黑客题材电视剧，是多么有基情的一件事情。

   

有求必应的小编也是绞（no）尽（zuo）脑（no）汁（die），凭靠不那么牢固的记忆和娴熟的搜索技能，搜刮到这些淋漓尽致展现黑客气质的电视剧，是多么不容易，来吧，看完后记得给个好评哈。

 

黑客题材电视剧

 

1. 美国出品

 

1）黑客军团 （Mr. Robot）——2015—2016年共2季；

 

导演: 涅尔斯·阿登·欧普勒夫；

主演: 拉米·马雷克 / 克里斯蒂安·史莱特 / 迈克尔·吉尔 / 卡莉·查肯 / 波茜娅·道布尔戴；

集数: 第一季10集；第二季12集；

 

《Mr.Robot》是一部由UniversalCable Productions制作的心理惊悚电视剧。本剧主角为艾略特·奥尔德森，是一位有社交恐惧症的年轻程序员，白天是网络安全工程师，晚上则化身为小心谨慎的黑客。有一天，艾略特遇见了一位地下黑客组织的首领Mr.Robot，并被招募为其中的一员。但当艾略特被指使要摧毁自己的雇主公司时，忠义难两全，他陷入了进退两难的境地：受个人信仰的迫使，他不断挣扎和抗拒这样一下可以拿下他雇主的机会；同时，他又坚信这样一个跨国集团在不断操纵和毁坏这个世界。

 

该部影片的内容真实性很高，剧中所使用的黑客技术（黑客工具和破解方法）都能在现实生活中找到，比如入侵核电设备，各种软硬件结合入侵等。所以很能引起现实生活中黑客和白帽子们的共鸣。

 

不过有一点想要吐槽的是，这些黑客题材的影视作品总爱将黑客塑造成具有心理疾病的人，但是事实上我认识的“大牛黑客”都是精神蛮正常的好嘛！

 

2）天蝎 （Scorpion）——2014—2015年共2季；

 

 

导演: 林诣彬；
主演: Elyes Gabel / 凯瑟琳·麦菲 / 艾迪·凯伊·托马斯 ；

集数：第一季22集；第二季24集；

 

《天蝎》是由美国CBS电视台根据真实故事改编的一部快节奏的、惊险刺激的悬疑剧集。讲述的是一个高深莫测的计算机专家和一群同样具备天才头脑的国际计算机黑客共同组建全球防御网络，抵抗来自现代社会的复杂威胁。

 

据悉，该故事主人公的原型是绰号为蝎子的超级黑客Walter O'Brien，他早年依靠黑客技术成名，后来成为蝎子计算机服务公司的首席执行官，为全球各地的客户提供信息服务。据称他是人类有史以来智商最高的人之一。他相当于现实生活中的X博士——他招募并训练来自世界各地的天才，统一指挥他们为挽救生命和解决难题而战。他们所面临的问题既包括赌场保安这种小问题，也包括无人战机发动攻击这种关乎国与国关系的大问题。

 

3）奔腾年代 （Halt and Catch Fire）——2014—2016年共3季；

 

 

导演: 胡安·何塞·坎帕内利亚 / 拉尔沙·康达基 ；
主演: 李·佩斯 / 斯科特·麦克纳里 / 麦肯兹·戴维斯 / 凯瑞·碧许 ；

集数：第一季10集；第二季10集；第三季10集；

 

《奔腾年代（Halt and catch fire）》是AMC电视台在2014年发行的一部原创新剧，故事背景为二十世纪八十年代初的美国硅谷，其时个人电脑正处于萌芽阶段，IBM公司刚刚推出旗下第一款主打产品并垄断市场。

 

“Halt and catch fire”是一个早期电脑指令，执行后使计算机进入竞争状态。创新与探索，挑战与机遇，自负与贪婪，乔·麦克米伦，将引领这家不起眼的小公司，成为奔腾年代的新领头羊。《奔腾年代》第三季中深入研究了早期网络中存在的一些固有的安全问题，以及当代黑客的起源。

 

4）疑犯追踪 （Person of Interest）——2011—2016年共5季；

 

 

导演: 大卫·塞梅尔 / 理查德·J·刘易斯  等；
主演: 迈克尔·爱默生 / 吉姆·卡维泽 / 塔拉吉·P·汉森 / 安妮·帕里西；

集数：第一季23集；第二季22集；第三季23集；第四季22集；第五季13季；

 

《疑犯追踪》是美国CBS电视台制作的一部犯罪系列电视剧，讲述的是一位被误以为已经死去的CIA特工与一位神秘亿万富翁联合起来，运用一套程序进行“法外执法”。

 

《疑犯追踪》的主人公是一位经过特殊培训的CIA特工，但因为某些原因被误以为去世然后沦落为流浪汉，但幸运的是，他被一个神秘的亿万富翁发现了。这位神秘的亿万富翁开发了一种可识别罪犯犯罪意识的程序，通过该程序，他们能识别出有可能进行暴力犯罪的罪犯，从而在犯罪发生前加以制止。

 

5）网络末日战 （Cybergeddon）——2012年

 

 

导演: Diego Velasco；
主演: Missy Peregrym / Olivier Martinez / Sarah Lian；

集数：9集
片长: 8-10分钟；

 

故事讲述了探员Chloe Jocelyn与拍档Frank Parker，调查一系列看似互无关联的网路入侵案件，必须在关键时刻，彻底打击由Gustov Dobreff为首的国际性网路犯罪组织，因为只要有连接网路的地方，每个人都有可能受害。 这部描述网路犯罪、情节紧凑的微影集分成9集，一集约8—10分钟。

 

6）网络犯罪调查：网络（CSI:Cyber）——2015年共2季；

 

 

导演: Eagle Egilsson；
主演: 帕特丽夏·阿奎特 / 托里·德维托 / 吉尔·贝罗斯 ；

集数：第一季13集；第二季18集；

 

作为CSI系列的衍生剧《CSI:Cyber》已经不是15年前靠传统调查手法出名的CSI了，而是属于科技时代的CSI。原本冗长的剧集将随着这部新的衍生剧进入新的领域，关注网络犯罪领域。电脑黑客、身份窃贼、网络敲诈和垃圾邮件等都会在剧中出现并受到法律制裁。当然，调查团队也是焕然一新，由帕特丽夏-阿奎特、詹姆斯-范德比克、彼得-迈克尼科尔、Bow Wow和卢克-贝里组成。

 

7）IT狂人 （The IT Crowd）——2006—2010年共4季

 

 

导演: Charles Linehan / Ben Fuller
主演: 克里斯·奥多德 / 凯瑟琳·帕金森；

集数：第一季6集；第二季6集；第三季6集；第四季6集；

 

去大公司面试成功的Jen（凯瑟琳·帕金森 Katherine Parkinson 饰）以为自己中了头彩，结果却被分配到了地下层的IT部门。部门里只有2个人，Moss（理查德·艾欧阿德 Richard Ayoade 饰）和Roy（克里斯·奥多德 Chris O'Dowd 饰），2个电脑方面的专家，生活常识类的怪人。对电脑一窍不通的Jen强装出一副精通的样子，惹出了不少笑话。

 

作为英国电影和电视艺术学院奖（BAFTA）得主，喜剧片《IT狂人》第四季2010年携主演Moss，Roy和Jen强势回归。剧中三人依然在地下室为Douglas落后管理下的Reyholm公司IT部门工作。

 

8）尼基塔 （Nikita ）——2010年共4季；

 

 

制作人：丹尼·卡农

导演：Nick Copus;

主演：Maggie Q、琳德西·冯塞卡、夏恩·韦斯特、亚伦·斯坦福；

集数：第一季22集；第二季23集；第三季22集；第四季6集；

 

在一个极其神秘的反恐怖组织的严格训练下，尼基塔在两年后已是一个身手不凡的特工人员。组织派她去暗杀一名恐怖分子，尼基塔却因没杀过人而下不了手。后来在又一次执行任务中，尼基塔为了救她的教官迈克尔打死了一名在暗处偷袭的恐怖分子，从而揭开了她一次次执行危险任务的序幕。她和迈克尔这一对师徒常常一道出生入死，默契配合，战胜一个又一个困难，从而完成了一次又一次的艰巨任务……

 

9）甜心陷阱（Eye Candy）——2015年；

 

 

导演: Catherine Hardwicke
主演: Victoria Justice / Casey Jon Deidrick / Harvey Guillen ；

集数：10集；

 

本剧根据同名小说改编。故事描述女科技天才、超级黑客Lindy创办了一个博客，专门揭露各种黑暗的真相——从恐怖袭击阴谋到连环杀手嫌疑人，无所不包。Lindy至今没有男友，于是她的室友劝说她在网上相亲。许多人对Lindy表示了兴趣，但她怀疑其中一个神秘的追求者可能是一直在骚扰她的网络跟踪者，随时会对她发动致命攻击。她在网络警察部门工作的朋友发现了曼哈顿一个连环杀手的踪迹，所有的证据都显示他就是Lindy的这个约会对象。Lindy决定与这群网警（绝顶黑客）一起侦破这起谋杀案，同时以她自己的方式来匡扶正义。

 

10. 暗网 （Dark Net）——2016年

 

 

导演：Mati Kochavi；

集数：8集，单集片长28分钟；

 

你所熟知的互联网是互联互通的，你所不知道的是，即便如此，你能访问到的互联网数据也不到其总数的0.1%，那么网络背后到底有什么？《暗网第一季》系列将为大家揭露你所不知道的世界。

 

韩国出品

 

1）幽灵（Phantom）——2012年

 

 

导演: 金亨植；
主演: 苏志燮 / 李沇熹 / 严基俊 / 崔丹尼尔；

集数：20集，单集片长64分钟；

 

电视剧《幽灵》讲述的是网络搜捕队在揭开不为人知的另一个网络世界即隐藏在高尖端技术中的人类秘密时，搜捕队员们所经历的悲欢和活跃表演，充满悬念和构想。在剧中苏志燮饰演的金宇炫作为警察高层干部的独生子，以第一名的优异成绩入学并毕业成为警察。通过天生的集中力和责任感，成为参与整顿警察厅网络搜捕队组织体系的核心人物。

 

虽然本人不喜欢棒子，但是棒子很多东西还是值得我们学习的，这部剧不管从内容、剧情到演员的颜值、演技都很赞。

 

当然里面涉及到了大量的黑客知识：渗透、破解、木马远控、硬件安全、智能汽车安全、ddos攻击、数据保护与擦除，还有大量的黑客工具：nmap、kali linux、Encase等等。

 

日本出品

 

1）血色星期一 （Bloody Monday）——2008—2010年共2季

 

 

导演: 平野俊一；
主演: 三浦春马 / 吉濑美智子 / 片濑那奈 / 芦名星 / 藤井美菜；

集数：第一季11集；第二季9集；

 

恐怖分子在一间教堂里散播病毒，导致俄罗斯东部一座城市完全消失。同样的噩运即将降临日本，日本警视厅严阵以待，并请18岁的天才黑客高木藤丸（三浦春马 Haruma Miura 饰）协助参与其中。藤丸的父亲也是警察，原本负责这起案件，后因卷入误杀事件而被通缉。恐怖组织的折原麻弥（吉濑美智子 Michiko Kichise 饰）以生物老师的身份进入到藤丸所在的高中，并监视着藤丸。

 

为了保护妹妹小遥生命安全，藤丸不得已答应了恐怖组织的要求盗取发电厂管理员密码给对方。在百货公司里，致命的bloody—x病毒怀疑被小丑散播，警视厅出动所有人力，为求保住东京市，差点让所有人命丧当地。幸好藤丸及时发现病毒是假的，虚惊一场。但当所有人都暂时放下心来时，恐怖组织已经开始踏出真正的第一步……

 

新加坡出品

 

1）力克千年虫 （The Millennium Bug）——2000年

 

 

导演: 陈健仪；
主演: 郑惠玉 / 赖兴祥 / 陈汉玮；

集数: 21；

 

二十年前，一位名叫奥法的8岁儿童神奇地闯入美国联邦政府电脑系统，引起联邦政府惊恐，联邦调查局如临大敌，全体出动，终将此案破获，奥法因此被尘封记忆，并判21岁前不得接触电脑。

二十年后，又有一名十几岁的少年受电脑黑客传授侵入航空公司电脑网络，扰乱导航系统，使班机在飞行时，无故撞向高压电柱。电脑黑客又在动画软件中插入经伪装的暴力画面，在催眠的作用下，利用潜意识控制人的思维，毒害青少年，以致发生校园中学生杀人和自轰事件。

 

黑客高手“千禧资讯科技”公司，不断研制一代又一代的电脑病毒，侵入网络，造成危害后，又堂而皇之地派人上门“解毒”，牟取暴利；更有甚者，他们侵入中森银行电脑系统，致使储户帐目丢失或款额改变，市民人心惶惶，争相提款，造成暴力事件；新千年来临之际，他们妄图利用“千年虫”，破坏全球电脑，引起恐慌，从而达到统治全球网络的野心……

 

中国出品

 

1）《防火墙5788》——2008年

 

 

导演: 何念；
编剧: 宁财神；
主演: 夏雨 / 姚晨 / 郭京飞 / 钱芳 / 王磊；

集数：30集，单集片长52分钟；

 

青梅竹马的舒蓉与贝志诚遭遇了前所未有的事业挫折，他们即将上市的舒诚公司屡遭背后黑手暗算。舒蓉的办公室被人闯了空门，对方直冲上市计划而来，虽然没有得手，却暴露出公司内部已有间谍。寻找深藏不漏的内奸，应付接踵而至的突发事件，加快公司的上市步伐，舒蓉和贝志诚忙得不可开交。

 

然而事情的头绪却越理越多，更加令人费解。在公司上市的紧要关头，贝志诚突然莫名其妙的发了水灾，电线短路。一个重要的程序必须在这天完成交给客户，贝志诚只好抱着未完成的硬盘四处寻找网吧。路上，贝志诚无意中遇到了来京投奔好友的宋玉秀，贝志诚好心载了玉秀一程，却不想玉秀下车后，贝的硬盘数据丢失了嫌疑落在了玉秀遗落的箱子上，贝志诚怀疑玉秀的身份与黑客有关，与舒蓉一同进行追查。

 

2）《非常24小时》——2004年

 

 

导演: 尤小刚；
主演: 胡兵 / 邬倩倩 / 刘冠翔 / 石小群 / 陈一娜；

集数：24集，单集片长40分钟；

 

除夕之夜，某市嘉年华晚会热闹非凡。陶李和孟梦两个网络少年偶然破解了密码程序进入卫星授时系统，使零点迎新焰火莫名其妙提前了三分钟！随之造成电网配电系统波动、大面积停电，供燃中心的毒气泄漏也在危及着居民安全，民航导航系统混乱，旅客随时都有生命危险，网络少年又神秘失踪，核电站传来预警险情……

 

就在这紧急关头，核电站机密文件失窃，引起丁院士心脏病发！他忽然想起，只有前女婿孟少杰(市突发事件应急处理中心副主任、排险专家)接触过自己的电脑，出于强烈的责任感，他将怀疑向国家突发事件应急中心负责人王常泰紧急作了报告。EMC网络组长夏末受命监视男友孟少杰，其内心极感矛盾，更使孟少杰痛苦万分，压力空前却有口难辩。偏巧这时，女儿孟梦失踪，前妻丁琳又突然回国，顿使已经分身乏术的孟少杰陷入内外交困境地……

 

3）《谍战深海》——2012年

 

 

导演: 王雁；
主演: 王志文 / 刘佳 / 姚刚 / 秦子越 / 墨阳 /；

集数：35集，单集片长40分钟；

 

海昌是我国新兴沿海城市，也是境外间谍组织关注的重点，随着国安局一名侦察员的意外失踪，拉开了一场反谍大战，李厅长（巫刚 饰）责成武梅（刘佳 饰）组成专案组进行调查。一艘渔船在我“探索一号”科考船附近意外打捞起一只奇形怪状的“水母”，深海研究院的总工程师岳诚（李进荣 饰）率众专家对其展开了攻关。

 

境外间谍头目彼得森命令海昌潜伏特务王维韬（王志文 饰）不惜一切代价夺回隐藏在“水母”中的核心机密。经过一番斗智斗勇，狡诈的王维韬最终落入法网，但武梅却发现了隐藏在表面案伴背后更大的阴谋，敌人已将多枚水母投放到我国海域，以窃取我海洋信息，武梅认识到，更大的对手即将出现......

 

4）《密战》——2009年

 

 

导演: 穆德远；
主演: 刘佳 / 王策 / 祖峰 / 侯耀华 / 李幼斌；

集数：30集，单集片长52分钟；

 

刘志军（王策 饰）是国安局的侦察队长，在一次谍战行动中，发现敌方要携我卫星方案出境，他伙同保密局武梅（刘佳 饰）处长负责侦破。几天后，潜伏在322所的方瑶（宋茶茶 饰）被抓，就在“银孤”（周里京 饰）端倪将现之机，方瑶被杀手“蝴蝶”（祖峰 饰）杀害，侦察陷入僵局。

 

该剧取材于当代，与传统电视剧如《潜伏》、《绝密1949》等多数基于中国解放前后比较原始的反特、泄密与反泄密题材完全不同，《密战》中运用了当前主流的技术和设备。不论是服务器、笔记本电脑、移动硬盘等大众普及用品，还是相当专业的微波发射中继器、手机窃听器、安防监控系统解读器，都是泄密和窃密的重要途径。

 

看完了节奏紧凑的黑客电影以及细节满满的黑客电视剧，是不是没有找到适合萌萌哒的你的那盘菜呢？别着急，接下来就为大家安利三部黑客题材的动画——《攻壳机动队2：无罪》、《黑客帝国动画版》和《黑客狙击手》。

 

1. 《攻壳机动队2：无罪》——日本2004年上映

 

 

导演：押井守；

集数：最新剧场版更新至2015年；

 

《攻壳机动队》（Ghost In The Shell）是由士郎正宗于1989年4月22日开始在讲谈社青年漫画刊物《周刊Young Magazine》海贼版连载的漫画。该片是《攻壳机动队》的第二部电影动画，故事发生在前作的三年之后，主人公不再是草薙素子，而是她的同事巴特，不过，由于草薙的记忆植于巴特的大脑中，所以她亦以一种特殊的方式不时在本片中登场。    

 

攻壳机动队描述一个未来科技高度发达，人类已经完全可以是电子人了，只保留人类大脑，少佐作为这样的一个义体人，身体素质非常强，思维也相当灵活开阔，充满智慧。在电影《黑客帝国》系列已经成为全球性话题的时候，更早的同主题日本动画片《攻壳机动队》却没有获得与之同等的知名度，但实际上沃卓斯基兄弟自己都承认“黑客”系列的灵感来自于这个系列的漫画。

 

2. 《黑客帝国动画版》——美国2003年上映

 

 

导演：沃卓斯基兄弟，安迪·琼斯，川尻善昭；

集数：最新剧场版更新至2015年；

 

《黑客帝国动画版》由9段以《黑客帝国》系列电影世界观为基础生发出的短片组成，各篇的角度与风格各异，制作班底汇聚了日本、美国、韩国三地的动画精英。《机器复兴》讲述了MATRIX的历史。机器人不堪人类恶劣对待，终于反抗并将人类化为能源。

 

《少年故事》讲述一名少年突然收到来自网络的召唤，而大批黑衣人开始对他展开围捕。《虚拟程序》展示了一对男女在虚拟训练程序中的片断。《世界纪录》描写一位短跑运动员在接近突破人类极限时终被系统牢牢控制。《超越极限》叙述因为系统错误，平静的街区中出现了一片超常区域。《侦探故事》描写一位侦探被步步引领着试图摆脱系统的桎梏。《矩阵化》讲述一只机器人被人类捕获并驯化的故事。《终极战役》记录了一艘飞船毁灭的经过。

 

作为与黑客相关的动画片，它不仅拥有想象力外壳，还拥有坚硬的理论核心。作为矩阵世界观的有趣延伸，这部动画值得珍藏！

 

3. 《黑客狙击手》 ——中国大陆2005年上映

 

 

导演：赵俊葆，杨苗；

集数：26集

 

《黑客狙击手》描写的是未来世界人类科研工作又有了新的突破，邪恶分子却要窃取这些科研成果以实现他们控制世界的目的，由于他们的阴谋破坏而引发了一系列网络危机。故事中有三位机智的少年，他们是M中学电子活动小组的三大电脑高手，他们挺身而出，与邪恶展开一系列机智的斗争。本片融合了侦探、科幻、友谊、亲情等多种科幻题材的元素。

 

作为一部难得的国产动画片，虽然槽点满满，但回想当时2005年计算机都还处于普及的萌芽阶段，能想到制作这样一个题材的动画片已实属不易，所以我们还是以包容的心态去观看吧～～～
