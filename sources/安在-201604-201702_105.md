# 打造CISP持续教育平台，为信息时代的安全感续航

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532259&idx=2&sn=33b7c77820ac3b542ce07fa0d5d615e3&chksm=febc1423c9cb9d35e2e94c384655ce5c7661985312e8d88233608da06bbafeeee054965c8555&scene=126&sessionid=1681310795#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532259&idx=2&sn=33b7c77820ac3b542ce07fa0d5d615e3&chksm=febc1423c9cb9d35e2e94c384655ce5c7661985312e8d88233608da06bbafeeee054965c8555&scene=126&sessionid=1681310795#rd)

# 10月27日，由中国信息安全测评中心推出的注册信息安全专业人员（以下简称“CISP”）持续教育平台正式上线。CISP培训获得国内信息安全领域广泛认可，截止目前累计为国家培养了数万名持证人员，其中很多人都已经成为国内知名安全专家，为信息安全的发展奠定了坚实基础。自2002年开展CISP培训以来,首次推出持续教育平台，持证人员可在该平台上学习相关课程或参加线下网络安全活动换取积分，进行证书维持。据悉，中国信息安全测评中心经过精心筛选和多方考虑，选择与北京永信至诚科技股份有限公司旗下公司出品的i春秋学院（www.ichunqiu.com）合作， i春秋利用其丰富的课程资源和独创的教育生态率先打造完成CISP持续教育平台，是国内第一家CISP持续教育平台。   

![](../Images/c1e112963aeaa886b91f46dabf689b88.png)  

中国信息安全测评中心负责人表示：“打造CISP持续教育平台，将CISP/CISM持证人员的继续教育与续证维持工作相结合，旨在规范CISP/CISM持证人员持续教育管理，为广大持证人员提供持续学习信息安全知识、参与信息安全活动的平台。i春秋是国内领先的网络安全在线教育平台，他们持续不断的更新课程，覆盖全网信息安全知识，可以为持证人员提供一个打破时空限制的学习信息安全知识、磨炼技艺、提高实战技能的良好环境。” i春秋自2015年6月9日上线以来，共有250余门常规课程上线，共计更新近2000节课程，并配套200余个实验环境，由来自50多家信息安全机构的180多名专家讲师亲自授课，保障了30多万信息安全爱好者的学习与交流，是国内最大最专业的信息安全在线教育平台。CISP持续教育平台不仅涵盖i春秋所有课程，还针对CISP持证人员不同的工作、学习需求，设置了热点安全事件解读、前沿研究、安全实践、安全理论四个课程板块，为CISP持证人员结合本职工作不断学习新知识、新技术提供有力的保障。

![](../Images/6dc068ac295551fe139a7f7ca3b80b80.png)  

  

随着科技的飞速发展，技术的更新迭代周期也越来越短，面对层出不穷的信息安全事件和巨大的网络安全人才缺口，持续不断的更新知识和技能对于信息安全从业者来说尤为重要。信息安全从业人员只有通过不断的继续教育培训，才能在掌握前沿专业知识与时俱进的同时，不断延伸和拓展自己的职业生涯之路。中国信息安全测评中心与i春秋打造的CISP持续教育平台不仅给持证者提供一个持续、方便、系统、丰富的学习环境，也为CISP获证人员未来的职业提升提供了重要途径。
