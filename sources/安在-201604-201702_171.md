# 危险！美国133支网络部队严阵以待 | 威观世界

这两天美国国防部24日发布消息，美军网络司令部下属的133支“国家网络任务部队”已经全部具备初步作战能力。

美军133支网络部队包括13支国家任务部队、68支网络保护部队、27支作战部队与25支支持部队，现有5000人，其中近一半部队已经具备全面作战能力，并计划到2018把网络部队扩军至近6200人，届时这些部队都将拥有全面作战能力。  

美国高调公布这一消息非同小可，这标志着美国这个世界警察已经准备好衍生大手向网络领域覆盖，相信不久之后，美国网络警察的形象也会呼之欲出。当然，美国网络部队由来已久，在现在这个时间点发布消息有其原因的，原因主要有三点。

**1.安抚美国民众受伤的心**

上周美国爆发了有史以来最大面积的断网事件，半个美国的网民受到影响，主流网站全部无法访问，对美国民众造成较大的心理影响，原本美国民众虽然一直自嘲，但打心底里觉得互联网是属于美国的自家财产，虽然各国黑客经常骚扰，但论网络技术底蕴和实力还是美国首屈一指的，美国网民通常有骄傲感，不想这次居然遭受这样类似恐怖袭击似的打击，对民众来说，其优越感心理造成较大影响，失落感配合国内恶化的经济形式，容易导致内部动荡。美军这时发布消息，为的是告诉民众，之前受这样的气，是因为我们没有准备好，看，我们网军也成立了，以后再也不会让大家受气了，并且所有攻击事件以后我们就有能力追查到底了，将一定把肇事者抓出来军法处置。

**2.向敌对势力宣战**

另外，美国宣布网军健全也是向敌对势力宣战，宣战对象包括恐怖组织ISIS，ISIS在去年就成立了网军开展网络恐怖主义战，通过网络传播极端主义，导致了多起美国境内的恶性事件。今年年初，美军网络司令部司令罗杰斯曾表示，美军网络部队对极端组织“伊斯兰国”发起攻击，使该组织难以从其位于伊拉克和叙利亚的基地对美国及美国的盟友策划或实施攻击。

![](../Images/4290cc51924ac2146e5769325bcacaef.png)  

此外，宣战对象也包括俄罗斯，近阶段美国网络安全事件频发，处处闪现着敌对势力的影子，上周半个美国断网，据传策划攻击的“new world hacker”组织成员大部分就来自俄罗斯；希拉里邮件的泄露直接影响了美国大选的走向，矛头也指向俄罗斯；美国安全局的“网络武器库”被盗，更是俄罗斯人在黑市上贩卖。更有甚者，美国和俄罗斯在中东的角力，战场上俄罗斯黑客也让美国吃了不少亏，土耳其倒戈美国就是俄罗斯黑客情报战的成果。因此，美国政府借此机会正式向俄罗斯宣战，未来可能将对俄罗斯发起网络反击，深层次的含义可能是为未来利用互联网核心端优势对俄罗斯进行不道德的非对称攻击埋下伏笔。

**3.向国际社会进行威慑**

网络空间已是各国显见的新主权领域，世界各国都希望在网络空间中彰显影响力，但美国一直推广其“网络无国界”的理念，核心含义其实是“网络没有国界，因为所有网络都是美国的”，因此才有了监听全世界的棱镜计划，网军作战能力的发布，预示着美国未来将计划行使网络霸权，通过航空母舰控制人类物理世界的物流通道，通过网络部队控制人类虚拟世界信息流通道，是美国的国家战略，并以此向国际社会进行威慑。向挑战其霸权者彰显实力。

虽然偷偷摸摸搞网军是世界各国心照不宣的事，但美国公布网军作战能力一事将网络部队台面化，对国际社会是个危险信号，这势必造成世界各国在网络空间领域的军备竞赛，网络空间也将不再那么自由、安宁。
