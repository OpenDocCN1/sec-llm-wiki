# 干翻了特斯拉的神奇小子Geohot终于要来了【极棒】

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532207&idx=1&sn=60d55f6c3414a12923a2fc428bd04212&chksm=febc146fc9cb9d7960c83d285b88ccf04b6127da93e10273c283e76f90f1b133f175e1f47630&scene=126&sessionid=1681310801#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532207&idx=1&sn=60d55f6c3414a12923a2fc428bd04212&chksm=febc146fc9cb9d7960c83d285b88ccf04b6127da93e10273c283e76f90f1b133f175e1f47630&scene=126&sessionid=1681310801#rd)

  

神奇小子是谁？他桀骜不逊、极具冒险精神，并且经常语出惊人。史上最传奇的黑客之一，苹果，索尼，Tesla与他的恩怨可以写3本自传了。他的传奇经历，充分诠释了“一路开挂”的含义。“天生的黑客”5岁就能写出电脑程序,世界上第一个破解 iPhone 系统的人，第一个破解 PS3 系统的人，第一个自制无人自动驾驶汽车的人，这位永远赶超时代技术潮流的天才黑客就是人们熟知的Geohot。

在短暂告别破解之路的几年时间，Geohot潜心于人工智能领域，终于在今年的硅谷科技大会TechCrunch上，Geohot公布了其开发的自动驾驶系统Comma One，并邀请彭博社的记者一起上路“惊心动魄”了一圈。

几个月做出无人驾驶系统还不罢休，还要再大会上向“前辈们”开嘴炮，这引得同行们的口诛笔伐。

但再猛烈的口水，也挡不住这位黑客的主角光环。

![](../Images/781bdaa922f93dfaf0053dbe5511ce68.png)  

  

**闯入自动驾驶领域的不速之客**

其实我们此次的主角，神奇小子“Geohot”在2015年就与特斯拉CEO伊隆·马斯克（Elon Musk）打赌自己可以造出价格低廉、技术可靠的自动驾驶方案，超越特斯拉的辅助驾驶技术合作伙伴Mobileye。于是，Geohot开启了他的“创造”之旅。

接下来几个月的时间，这个神奇小子兑现了他的诺言——黑客行事从来都是“能动手绝对不动口”。他在自家车库里改装出来的自动驾驶系统，包括6个普通摄像头一个位于仪表盘中央的屏幕和一个有自学能力的人工智能算法相机控制软件。传统自动驾驶技术的原理是，为汽车设置各种规则，告诉汽车如何开车。而Geohot的开发的方案则是，通过2个位于后视镜，1个位于车尾，左右两侧各一个的摄像头及车顶上大视角的鱼眼相机，捕捉汽车行进时的状况，并借助人工智能的深度学习能力，让系统自动做出判断。“我带着它出门开了10几个小时，让它观察我这10几个小时的行为，然后让它跟着我学。”

令人瞠目结舌的是，Geohot开发的自动驾驶系统只需要999美元！

Iphone7（256G）=自动驾驶系统？ What！！！

并且这套方案适用于任何车型。

不仅如此，Geohot还将长达7个小时的自动驾驶数据、模型和论文全部公布在网上，以帮助自动驾驶爱好者研究。

加州理工学院博士侯晓迪说: “这个自动驾驶解决方案最大局限是只能应付见过的输入类型，如果在实际过程的情况和训练数据差距太远，超过模型不变性所能容忍的上限，就很容易出现问题。”

![](../Images/af2beaae248f306c3a85b7ab54fce57b.png)  

人工智能研究负责人Yann Lecun评价说：“训练基础的卷积网络做车道线保持，这并没有什么难度，难度在于可靠性。他所做的事情或许很酷，但并不是特别具有创新性。”

这就是可爱的Geohot，一个研究人工智能驾驶的黑客。

![](../Images/24502cf67915ee0b562e6dd312a50a3a.png)  

  

**Geohot与GeekPwn（极棒）的火花四溅何方？**

据了解，Geohot此次来到中国·上海，是为了参加10月24日举办的GeekPwn（极棒）2016上海站，黑客大赛。GeekPwn今年的上海站和硅谷站将创新地涉及众多黑客大赛从未有过的内容和玩法，如人工智能Pwn和机器人特工这样新颖的比赛形式，就成为了今年的重点。但对Geohot此行的具体流程，并没有得到主办方——Keen公司的任何消息。这也给顶礼膜拜的粉丝们留下了许多悬念：

放炮力挺特斯拉，挑战Mobileye？

![](../Images/66b865ca99f4b000e7ca772b94c87b2f.png)  

随着近期Tesla和Mobileye近期的合作终止，和公开表态，Geohot也旗帜鲜明的站起队来，大神的嘴炮火力可谓不俗：“Mobileye的商业模式就是和立法者同流合污，来降低没安装Mobileye芯片的汽车安全评级。或许是特斯拉太有创新精神，吓到了Mobileye，所以他们干脆放弃，不再创新。”这…Very Geohot！

对“前辈”的不屑显然为Geohot树敌不少，“ Comma one的技术无法观察到车两侧和后方的信息，甚至可能连变道都做不了。而且Comma One的安装位置是在后视镜上，车主很可能会来不及切换到手动模式。” Facebook人工智能研究负责人Yann Lecun对GeoHot的端到端无人驾驶解决方案也曾经评价为“既不创新，也不可靠。”。

恃才傲物一向是Geohot的性格，面对“权威”对其“不靠谱”的评价，Geohot是否会现场演示他的Comma One， 或者干脆“秒杀”掉Mobileye，向人们证明“权威们”也不过如此？

  

  

**把自己研发的Comma One自动驾驶系统交由选手破解？**

另一个猜测是，面对质疑，Geohot秉承其“No Zuo No Live”的黑客精神，将自己开发的自动驾驶系统交由选手破解，发现漏洞并改良方案——自GeekPwn2014年创办以来，一直向智能软硬件厂商提供相应的漏洞报告，以协助厂商升级系统，提高产品安全性。正如Geohot所说的：“金钱唾手可得，我想拥有权利，不是凌驾于别人之上的权利，而是凌驾于自然和科技命运之上的权利，我只想知道事物的运作规律。”或许，在GeekPwn2016的现场，我们能看到一个真正的黑客对技术的追求和对黑客文化的践行。

目前，有太多“？”，但不需要着急，因为距离10月24日已经屈指可数，相信黑客界传奇人物Geohot第一次公开的中国之行将会给我们带来一个大大的“！”。这位“神奇小子”将在GeekPwn的现场怎样大放异彩？我们可以拭目以待！

  

  

作为全球首个关注智能生活的黑客大赛，GeekPwn（极棒）2016上海嘉年华将于10月24日举办。6月20日，极棒正式启动选手招募，除了一贯最高标准的项目奖金，主办方KEEN还为选手增设了四个特别奖项：全场“最大脑洞奖”、全场“最霸技术奖”、全场“最酷展示奖”、单项附加“脑洞奖”，以鼓励脑洞大开的极客天才。  
  
与此同时，在10月24日极棒三周年之际，主办方还将颁出三年最佳团队、最佳选手等大奖。
