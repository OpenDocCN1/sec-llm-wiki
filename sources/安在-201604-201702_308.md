# 【极棒】赵汗青：八九点钟的太阳，照在他的身上

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532147&idx=1&sn=e29fc37fa64ab10c898d3b338e535694&chksm=febc14b3c9cb9da5bb230510ceb7c474a376415b769593654f6fa90df49fac43cdc86ae21df0&scene=126&sessionid=1681310808#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532147&idx=1&sn=e29fc37fa64ab10c898d3b338e535694&chksm=febc14b3c9cb9da5bb230510ceb7c474a376415b769593654f6fa90df49fac43cdc86ae21df0&scene=126&sessionid=1681310808#rd)

  

  

在今年5月12日的“极棒”比赛中，赵汗青是最高奖金获得者之一。见到他之前，我就知道他年纪不大，但万万没想到的是，这哥们还在念大三。

  

我们的专访在我大呼小叫的惊叹中开始。赵汗青向我示意他做好准备了，甚至对我说，“就随便聊聊，不要紧张。”感觉上，倒像是他在引导这场访谈一般。脸蛋干干净净的他，说话做事已颇有几分成熟气度。

  

  
**“在比赛台上的表演也许只要几秒，但我们的付出却是几天几夜”**

  

这次比赛，赵汗青在极棒澳门站比赛捧得了42万元的最高奖金。奖金背后，他的团队所付出的努力着实不小。赵汗青说，前一天晚上他与队友杨坤分头研究到后半夜，自己实在困得不行，稍稍躺了一下就睡着了。反倒是年纪更长的杨坤还在继续攻关：“杨博士真的比我们年轻人还要精力旺盛。”  
  
一个个不眠之夜，可能是整个团队获得最终胜利的必修课。信息安全比赛的现场视觉效果往往狂拽酷炫，在观众眼中，几秒钟的时间里找到系统的漏洞，就是比赛的全部。但事实上，备战往往从赛前的几周就开始了，整个团队分头研究、准备，就如奥运选手一般——赛场上那几分钟甚至几秒钟的精彩表演，背后是无数次的艰苦训练。  

  

![](../Images/6f21bc225763bd0bfb91ab50404978c1.png)  

  

虽然还很年轻，但赵汗青的比赛经验很丰富，也获过不少奖。对于各类比赛，他有明显的好恶——他享受整个团队的密切团结、攻坚克难；相反的，有些比赛在考题的设计上脱离实际情况，可说是“为比赛设计漏洞”，让他深感无聊。  
  
谈及自己的获奖记录，赵汗青有点腼腆：“其实同学们对这个（奖）的关注度不是那么高。”  

  

  
**“我觉得我可以做好”**  

  

  
在长亭科技，小青在安全研究组工作。他喜欢自己的工作，也很喜欢这个团队：“本来是准备大三多选几门重考刷刷分数的，但因为（单位）是长亭，所以我又取消了选课，过来实习。”  
  
长亭科技的办公地位于768附近一栋小楼的二层，几乎每处布置都体现出这是一家年轻的公司——前台上摆放的除了奖杯奖状，还有各种手办；右转进门的走廊上挂着团队成员们的搞怪照片：有的照片中一人分饰两角，自己和自己执剑PK；有的照片中主角有了超能力，在空中打坐；有的照片一人发射冲击波另一人中招，虽然后期处理可谓“五毛钱特效”，但别有一番意趣。  

  

![](../Images/be569c694a75460665ad2375dad40d80.png)  

![](../Images/4d98e55f0006a4ed46c76e01672e032c.png)  

  

对一群常年端坐在电脑前的员工来说，长亭科技办公地的布置可谓贴心——每个员工都有的人体工程学座椅、休息区摆满的零食、电子琴体重秤哑铃等小装备，以及一条喜欢摇尾巴的小狗。  
  
作为安全研究组的实习生，尽管赵汗青颇为了解公司的业务流程，但被问及公司新上市的产品时，他抱歉地表示并不知道太多细节，“安全研究组的工作和产品并不是简单粗暴地联系在一起的。”  
  
赵汗青认为，漏洞研究是一种类似“宇宙漫游”型的工作，不断在前进中解决问题，而非按部就班地完成工作，让他极有热情。“漏洞研究是一个需要灵感的事情，就像砸向牛顿的那个苹果。”他以一种近似“布道”的语气神态告诉我。  
  
他的样子让我想起那些爱聊魔兽世界或者世界杯的男生，坚实的“信仰”让他很容易进入自己的世界中。  
  
“你确实可以做到技术很强，可你做的一直是技术相关的工作。以后如果要转管理岗，人与人之间的沟通是很复杂的，协作团队的不确定因素非常多。你怎么办呢？”作为“过来人”，我忍不住问。  
  
“我应该可以做好。如果遇到问题，我应该可以学习解决。”真是信心十足的答案。

  

  
**在研究室里读本科**

  

  
对不少人来说，大学本科的四年，可能是一生中最轻松惬意的时光。那是在高考重压之下憋足了劲之后，一口长长的喘息。很多高三老师甚至常说：“考上大学，随便你怎么玩”，作为对学生的激励。  
  
对赵汗青而言，他的大学生涯毫不轻松——他的本科，是在硕士研究生的实验室里上的。他亦向我们分享了他的求学经验。  
  
从大一下半学期开始，他就自己跑去找研究生导师，并毛遂自荐进入了研究生的实验室。在实验室，他完全按照研究生的方法做学术科研，甚至争取到了自己的座位。“学弟学妹们真的可以试一下，现在很多学校都有实验室了，可以这样尝试。”在实验室的学习，并没有耽误赵汗青的成绩，还让他结交了不少前辈，在生活与科研上都给予他不少指点。  

  

![](../Images/4ecff8b107a1bb762a937a743ee3a9c7.png)  

  

赵汗青选择把大部分时间放在实验室，也得到了父母的支持。这对70后父母给了儿子相当的尊重和空间。“大部分事情我自己都能做主，我爸妈不太干涉我。”赵汗青说。  
  
聊到未来，是继续念书、留学还是工作？赵汗青说自己还没想好。但是，所有的选择都会由他自己来做：“我有了自己的想法就会去做，有点倔，我可能是一个比较自我的人。”  

  

  
**“他们都说我们是修电脑的”**

  

  

对赵汗青而言，小小年纪就找到自己喜欢的行业并且取得不错的成绩，可谓人生一大幸事。茫茫人海中，很多人迷迷糊糊填志愿，匆匆忙忙找工作，年近不惑才突然发现，自己不知道想做什么。  
  
“你是因为喜欢所以报了这个专业吗？”我问。  
  
“其实本来我家里人想让我学医的，我也觉得学医挺好。”赵汗青回答。不过，他最终选择了信息安全，并且取得了颇为卓越的成绩。尽管如此，有时候他也会羡慕文科生，“他们好像都生活得诗情画意”；而在他看来，别人眼中对自己专业的印象大概是：“他们都说我们是修电脑的。”  

  

![](../Images/f6c12672c5a403ef789f42b3f7eddd9b.png)  

  

尽管老成，但少年仍是少年。每当我例行问起一些“有什么兴趣爱好”之类的问题，赵汗青都像答考卷一样思量再三再做回答，眼神真挚，仿佛是面对无法交白卷的问题，必须给出个完整答复一样。对兴趣爱好的问题，他明显地卡顿了一下，皱着眉头好一阵思索之后，才仿佛在头顶亮起一盏小灯泡，露出一口整齐的白牙，笑逐颜开道：“我喜欢出去吃东西。”  
  
“喜欢找美食馆子吗？”我问。  
  
“也不是，就是如果有人喊我出去吃饭我一定会去。但如果自己一个人的话，也不会想着出去。”  
  
秉承着烟台人皮肤好的特点，个子瘦高的赵汗青头发乌黑、声线温和低沉，在格子衬衫里呈现出一副干净阳光的样子。在公司里，他说起话来条理清晰，在其他人高谈阔论的时候安静倾听、礼貌得体。公司的同事有调侃小青长得像李宇春的，也有说长得像李易峰的。  
  
在学校里，赵汗青经常会在公开场合进行演讲，他对自己的表达能力很有信心；深夜，他是个在微博上写情话的少年，毫无套路，坦诚得有点笨，就像是每个少年都曾有过的样子。  
  
在每一个时代中，20岁的年轻人都有一些共同的特征，热情满满，胸怀梦想，他们总是比上一个五年的人有更多的自我主见和自我意识。而这一代95后表现出的变化之大，令人惊奇却在意料之中——技术的进步让移动互联网进入了每个小学生的书包，每个孩子都能方便获取海量的信息。这早就不是暑假去新华书店看《十万个为什么》的年代，年轻的一代学会了在网上搜索答案——无论是关于作业还是关于人生。  
  
这意味着，这代人能接触更广阔的世界，找到自己的兴趣所在，锚定人生坐标；同时，更具天赋的人也能得到遴选，在最适合的社会分工上发挥力量。赵汗青就是一个好的例子。

  

![](../Images/791f880d0bfe32159880b764e421d74f.png)  

  

作为一个95后，赵汗青很典型，又很不典型——也许，典型的95后，特征就是“不典型”。  
  
腾讯曾通过统计QQ空间的大数据得出结论：“95后真正的需求是获得独立、关注和认同感，力求在虚拟空间中实现个人价值。他们期待安全独立的社交环境，可以打破教条，畅所欲言，与兴趣相投的人尽情互动。”  
  
在当年的“夏雪”“刘星”早已长成今日的“邱莹莹”“余罪”的今天，整个时代的舞台都开始为95后让出他们应该拥有的空间。在人们对于“95后该是什么样”的讨论甚嚣尘上之时，他们已经甩开了评论，与兴趣相投的人，自信前行。  
  
这也许才是最值得其他人羡慕的吧。
