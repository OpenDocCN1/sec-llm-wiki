# 黑客？此刻他只是无助的父亲，五岁儿子身患两癌，帮帮他！

编者按  

关于秦波孩子生病遭难以及业界热情助援的事情，这两天热播热传。作为个人的我，以及作为领域媒体的安在，自然也在关注共情之列。  
  
27日一早，安在发布了一篇报道文章《黑客？此刻他只是无助的父亲，五岁儿子身患两癌，帮帮他！》，很可惜，发布后不到半个小时，我们就删掉了。  
  
从26日中午我们开始决定做此专题报道，一是想向大众澄清事实（毕竟牵涉募捐，热情若无事实支撑，信任会打折扣），二是想以媒体之微薄之力，倡议更大范围的援助。策划、采访、搜集并整理资料、反复斟酌讨论基调和细节、成文、审订、润笔，乃至于不断推敲标题，安在团队一直忙到凌晨两点，大家饱含热情积极协作，我们唯希望，能在久已封闭隔阂的安全圈，打开一扇协力共助的风气之门，俗话说即正能量。  
  
作为媒体，我们也知道一篇稿子突然的撤掉意味着什么，猜测，质疑，总少不了，从事后微信后台以及微信群和私人通信中的各方反馈来看，大家都表示很诧异。说实话，我个人对微信公众帐号每天只能发一次、无法后台修订的限制很有意见，往往会让媒体经营者非常被动，因为稍微前期一个疏忽或者意外，无奈删帖都会让心血付诸东流。但从另一方面来讲，这也要求我们媒体经营者要仔细再仔细，用心再用心，要确保每一篇拿出来的文章，都是经得起各方评议和时间考验的。  
  
而这次，问题就在于，我们并没有做到让所有相关方都达成一致。或者这么说，当我们认为我们是在采信各方陈述之后集结成文，应该代表的是媒体自身立场时，却不可避免地有之前未能认识充分的相干方需要更周到的协调。  
  
简单来说，本文中间有些图片含有个人信息，可能引发潜在的信息链风险，部分措辞也不够准确。在媒体看来似乎没什么不妥，但从个人来讲，细节决定对错。  
  
不怪别人，责任在我。  
  
做此文字澄清，不是想推脱，唯一心里过意不去，就是觉得我的伙伴们辛苦之下还是难免这样的结果，另外引发大家关切和猜疑，我心怀歉疚。  
  
媒体是要紧紧抓住“话题”，媒体是要注重传播，媒体是要吸引眼球，但大家都知道，安在不在普通娱乐八卦没有底线的媒体之列。  
  
安在以信息安全为立足，关注人物，讲述故事，培育文化，传播正能量。安在虽弱小，但我们有专注、内涵和认真的态度。  
  
按正常情况，原文经再次仔细修订后，今天重新发布，请见谅安在的“重复性”叨扰。  
  
值此，我们唯一希望的，是秦波的孩子——也是我们安全圈的孩子，能康复并平安！也恳请大家持续关注并给予力所能及的帮助！  
  
谢谢。

  

张耀疆  

  

  

  

对秦波来说，一切都像是一场噩梦。

  

![](../Images/152e0c3bf7c6611372c942488153c32c.png)  

  

外号“大波子”的秦波在安全圈里颇有名声——曾经在绿盟科技，离开后一直在知道创宇至今，担任湖南分公司的总经理。作为安全领域的老兵，秦波是web安全领域公认的“牛人”，在WAF方面极有建树。

  

一切看上去那么美好：人到中年，儿女双全，事业有成。但一切都因为一纸诊断书而改变——2014年，秦波年仅4岁的幼子秦智宏罹患白血病，病情严重，医院一度开出了病危通知书。

  

![](../Images/33344856feccb0c8155b8c49e7639753.png)  

  

秦波的tumblr页面名为“缘定今生”，介绍是“记录我儿战胜病魔过程”。这个博客曾经载满了他对信息安全技术的见解和记录，但从一年多以前的一条记录开始，所有的内容都与孩子努力与病魔搏斗的过程有关：“周一接到孩子妈给我的电话和短信，孩子病危，白血病！”

  

博客详细记录了孩子每一次的治疗，每一点滴的恢复，和秦波身为人父的心疼、担心与恐惧。在42页的记录后，更新停止在了今年春节。照片上的孩子气色不错，似乎正在恢复中。但又一个噩耗传来：今年，孩子被确诊患上了皮肤癌——用医生的话来说，“同时患上这两种疾病的几率以百亿分之一计”。病痛、化疗、皮肤溃烂，对一个不到5岁的孩子来说，这一切太过残忍。

  

![](../Images/60230917c01d3f7c510a09203fcd284e.png)  

  

“目前现主治医生表示同时患两种癌症的几率是百亿分之几，也查阅了大量国内外资料，给我的建议是两方案：1、按照白血病T系复发的方式来治疗，加大化疗，并观察皮肤是否有所好转，如果好则开始做骨髓移植；2、去北京上海广州等一线城市，找靠谱医院和专家来定制医疗方案”秦波说。

  

对于需要的帮助，秦波表示：“首先，是需要能结合这两种病急性淋巴白血病T系（中危）和非霍奇金T细胞淋巴瘤（分型为主γδT细胞淋巴瘤）同时考虑的治疗方案，因为目前对哪一种病的治疗都可能会对另一种造成干扰破坏。由于只有专业人士才能作出判断，我想要能把这个信息有效传递给相关的专家；其次一旦确定病情和治疗方案后，我希望在短期内立即办理入院。”

  

![](../Images/501839748be2fcb4907c9f36c0c0d7cf.png)

  

秦波是一个传统意义上的“技术男”。在知道创宇，同事们对他的第一印象就是“技术很牛逼”。出身普通家庭，秦波凭借着对技术的热爱和钻研，为家人努力创造美好的生活，但这一切在疾病面前显得不堪一击。从2014年至今，秦波为了治疗孩子的病，已经花费了超过50万元的巨额医药费。而根据医生的保守估计，接下来的治疗还要花费百万元之多。

  

对于秦波而言，命运的骰子在他面前掷出了残忍的随机数。不幸中的幸运是，他身处一个充满温情的安全圈。

  

![](../Images/6ede081350b57ef7eb1e4185383d655a.png)

  

7月26日凌晨1：23，秦波发出《为我儿求助治疗方案，同时患有白血病和皮肤癌》一文，详细地陈述了他儿子的病情和求医经历。了解秦波的人知道，这个汉子真的扛不住了。

    

同日下午17点左右，名为Bernice.fu的用户在“轻松筹”平台上发布“救助5岁白血病与皮肤癌孩童”，在该项目的抬头，轻松筹还特意注明，“您的支持行为属于对受助人的主动赠与，该行为符合国家现行法律法规规定”。

 

经安在采访了解，Bernice.fu为秦波曾在绿盟的同事，现安华金和付蓉洁。同为曾经绿盟人的她，与各位热心的“绿离子”一起快速成立了秦波救助小组，以响应来自大家的发来的信息、帮助。付蓉洁申请联络开通的网络众筹通道，将信息与圈中好友及社会公示，希望有医疗资源者与其尽快对接。

  

![](../Images/efc15b518c93c117fbd848f42bbb20e9.png)  

  

与此同时，UCloud的季昕华、启明星辰的孙小美、滴滴出行的吴树鹏、零日信息的黄荣等信息安全圈的知名人士，纷纷在朋友圈上发布、佐证了相关信息，并组织募捐活动。TombKeeper也特意向安在发来信息确认事件的真实性。黄荣的朋友圈显示，在“轻松筹”发布这一消息后的50分钟里，网站总请求数超过470万次。

  

![](../Images/a45d172f23c58acb8d33aca6f829dfb1.png)

  

7月26日晚上22：36，秦波在朋友圈中说，“5小时超过二十万善款，感谢绿离子和所有的朋友们，医院也基本确定了，明天下午到北京儿童医院，感觉从未有过的力量”。

  

绿离子是绿盟离职员工对自己的称呼。秦波动情地表示：“昨晚（25日晚）好友谢斌在里面一提，就瞬间爆发了惊人的凝聚力。医疗方案和众筹全部在他们的专业分工下迅速完成，以至于我瞠目结舌和感怀至深，真的没想到这么强的行动能力，感恩绿离子，感恩我的老东家绿盟，感觉这颗心都深深扎在了那片土地上。”

  

秦波所在的知道创宇公司也采取了行动。7月27日下午，安在获悉，知道创宇已经成立了信息救助小组，并将知道创宇的募捐筹款统一记录、整理后提现到专门的银行卡上，由公司领导层亲自转交秦波。“老大们特别关注，想办法从钱到资源尽力帮助，要亲自去探望宝贝和大波哥。”相关负责人士介绍。

  

7月27日下午15时左右，安在和秦波取得了联系，此时他刚刚达北京。“情况不妙，段主任表示这个情况少见而且床位紧张，需要优先第一次发病的患者。”秦波说。

  

  

![](../Images/8050a542c1441edd7a9f5f45ede3a33f.png)  
  

截至7月28日11:55，“轻松筹”筹集善款突破61万元。同日，秦波已经带着孩子从湖南来到北京儿研所就诊。

  

![](../Images/6e68e3ce941e3d8f0c97577384c02e94.png)  

  

**也许，未来还会有更多的挑战在等着这个家庭。安在希望，通过一些力所能及的帮助，让孩子康复的希望更多一点、离幸福更近一分。安在与你同在，关注与共情，捐助与携手，安全圈需要善念、行动和力量！**
