# 【访谈】在无线电上跳舞，杨卿和他的“独角兽”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532124&idx=2&sn=db5d97eb2666c90ac6bf32457e8862ab&chksm=febc149cc9cb9d8af01670100a5934f9fd1ba0dafea4cc4db924f3003cef10d3fdc33685d49a&scene=126&sessionid=1681310811#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532124&idx=2&sn=db5d97eb2666c90ac6bf32457e8862ab&chksm=febc149cc9cb9d8af01670100a5934f9fd1ba0dafea4cc4db924f3003cef10d3fdc33685d49a&scene=126&sessionid=1681310811#rd)

  

WiFi、公交卡、汽车钥匙、门禁克隆……杨卿和他的独角兽团队所研究的领域，和人们的日常生活息息相关。无线电安全，这个前几年还是“冷门”的新事物，如今随着企业和公众意识的加强，显得越来越重要。

  

杨卿举了一个简单的例子：许多时钟源都是GPS，黑客完全可以制造一个设备，放在华尔街的电线杆上，扰乱世界金融中心的交易时间——这种攻击会像蝴蝶风暴一样引发不可预测的灾难。也正因为此，他们团队从不公布漏洞代码。

在这样的现状中，向更多人普及无线电安全的知识，几乎成为杨卿的使命。我们和他聊天时也发现，杨卿思维活跃，妙语连珠，即使是谈到严肃的技术问题时也深入浅出，即使外行人都觉得特别有趣。

  

今天，这位业内的“黑客男神”就会来讲一讲，无线电安全究竟是怎么回事。

  

![](../Images/06225a223c578c417111d932675f3d7f.png)  

  

![](../Images/b11e8cfb61199494d8d43498d5d616d5.png)

Q先谢谢你送我的书（《无线电安全攻防大揭秘》）啊，倍感荣幸。A我最近在练签字呢，以前一直都是用电脑，字基本是废了，都是虫子爬似的（笑）。

  

Q我之前在朋友圈晒了一下书，结果很多不相关的人都来留言了，哇，帅哥！A一直也不靠脸，这些标签不知道谁贴的。

  

Q说起你的研究领域，好像之前并不常见，比较冷门？A无线电安全是我们起的，很难形容，以前说是无线安全，但是现在一说无线就是移动端，APP，我们是无线通讯安全，最后一想，干脆叫无线电。这个词对网络安全界来说很新鲜，以前都是网络、主机、系统。

  

  

Q你现在的团队叫独角兽，这个名字挺特别的，介绍一下团队？A

独角兽现在有28个人，黄琳在法国做移动通信挺成功的，来这边是为了能够学更多新东西。团队里的成员做安全时间都不短了，最长的有七八年了吧。

  

独角兽这个名字是怎么来的呢？因为我个人是动漫迷，那时候有一个独角兽高达，寓意是可能性之兽，就是无限可能的意思。我是搞无线的，无线也是无限可能。然后就是，独角兽比较好看的神兽。

  

Q 那么现在选择了这个方向以后，你有没有长期的规划？A在这个领域比较发散，漏洞一旦被发现，就会影响所有的东西，而且这些漏洞可能都是需要很长时间才能修复的，成就感比破解一台智能家居，甚至一辆智能汽车要高。而且这个领域也没有人做，我也会从容一些，没有同行的竞争之类的，算是偏门领域。  
月亮水瓶座的人可能不喜欢做别人做过的事情，我只走别人没走过的路。

  

  

Q但是这个领域相对冷门，并且很难一下子被市场消化，在转化方面你怎么考虑呢？A

做一个模板真的很难么如果是研究成果转化的话，我们会申请安全防护专利，放在儿童卫士或者奇酷手机上，这都是技术的输出。无线方面，因为有充足的安全攻防经验，就做了一个企业安全产品天巡，所以转化上面还好。

  

但还是新生事物，在WiFi安全上吃过亏被外界暴露出来的事件并不多，结合最近的新闻看，富士康等一些大公司在这上面还是有痛点的，他们深有体会，但是跟其他企业做安全交流的时候发现，他们还没部署到这方面的防御。我们认为这是未来很重要的一点，天巡一开始设计是用来保护360自己无线网络安全的，后来才开始产品化，目前天巡也已经卖了几家了。

  

![](../Images/643c0bfb1100cd44cdf600ec777b42f4.png)  

Q现在的反馈怎样？A目前有这样一个问题，需要工作人员去展示这里面的风险，他们才知道原来是这样。企业没有意识到，自己搭的WiFi热点会被无线渗透。公共场所WiFi钓鱼的问题，国外也是两年前就意识到了，咱们是2015年315晚会之后，媒体才隔三差五地说。对公众来说来说认知还是不够的，我们现在希望尽量把攻防技术转化成2C的形态。

  

  

Q能聚拢这么多人挺不容易，毕竟做无线安全门槛挺高的。A一个是基础知识，逆向啊信号解密啊。另外是设备，一开始设备确实贵，现在一两千的设备也出来了，淘宝都可以买到了。

  

  

Q听你这么一说，似乎门槛没那么高了。A

很多无线安全的东西其实离不开那几个攻击形式。其实在有线网络层他们也会用这些攻击思路，而在无线信号通信层的话阻力会更少。因为各类无线通信协议设计之初，更多考虑的是可靠性，而没有考虑到可信性。在生活中有很多这样的例子。

  

有一次我坐国航，飞机晚点没事干，国航飞机上有WiFi，没有连到互联网，但是有内网，内网会也有很多设备。我猜有很多内部服务器，就进去试了一下，打开管理界面，发现很多数据都是实时可以改的，当时带的笔记本没有太多攻击程序，否则做个溢出之类的都是可以的。

  

WiFi是企业安全的短板。其实很多利用WiFi的基础设施都是有短板的，因为做这些的研发人员是标准的工程人员，很少有安全人员介入。安全人员的思维和传统研发人员是完全背道而驰的，攻击者用的方法太多了，研发人员考虑到的防护点，黑客从来不会考虑。不过现在要好很多了，很多产品人员在设计时候已经加入更多安全上的考量了。

  

  

Q也就是说，问题早就存在，只是没人关注？A对，很多看起来貌似新的领域，其实问题还要古老，只不过大家没有关注，比如无线电安全、WiFi，包括硬件级的，比如GPS。公共基础设施都有很多的监测传感器，比如水利系统就有水位监测传感器，使用GPS授时，那我用GPS欺骗改个时间，改成1670年或者1970年，系统可能就会因为设计时没考虑到这种异常数据，导致程序崩溃、甚至系统瘫痪等问题。GPS欺骗刚发现的时候很多人都来问说能做成小型的设备，比如叫车软件司机可以欺骗自己的订单路径，再黑的可能想把这个技术卖给第三世界国家作为军用技术，这种便宜东西也许能卖个几百万。

  

  

Q说到这，你怎么看待这个研究的未来？A

未来希望让更多的人、企业都意识到GPS不安全了。在美国讲之前，我们报给了国家做内参，目前来说也只能这样，告诉大家说这个有问题了，对整个行业也有帮助。我相信问题出来后，很多GPS模块设计都会改进。如果不提出问题，就永远不会改进，那么问题可能永远不会得到快速解决。

  

很多人其实意识不到这个问题的严重性，其实位置欺骗还好，比如开车把你导航到另一个地方，时间欺骗更可怕。很多时钟源都是GPS。他通过电波表去对时，其实可以篡改。刚研究出来时，朋友说，你这个要是改了，做一个小型的设备，去华尔街往电线杆上一贴，所有交易时间都被你搞乱了。

  

不过我们的代码是不公布的。代码一公布，人家就会转化为能获利的东西，并且很多设备目前并不能抵抗，我认为这样做是现阶段对这种漏洞被恶意利用的一种保护，也对依赖GPS系统的各种机器与人的安全负责。

  

![](../Images/09ad70a3238a269b40831b52844fe556.png)  

Q怎么看待无线电安全的前景？A

很多人做安全看重职业上的，比如web安全，好找工作，不在公司的话还可以做黑产.而无线稍微苦点，花钱也多点。我希望更多的人能够重视无线电安全，包括出的这本书，之前一直想写，国际上没有专注于企业无线电技术的著作，我们写出来了，对我来说很有成就感。

  

但其实我写不多，团队成员写了不少，我只是把他们每个人的能力融合一下最大化，当时很放心地交给黄琳了，心想她肯定能完成。倒是我自己拖了将近两个月，拖延症严重点（笑）。

  

我希望最终能扭转一个错误印象，不要认为这个领域没希望没钱赚，我去年和今年都是优秀员工，团队今年也是优秀团队，在大家看过来，一个非主流安全方向的攻防团队也能做到这种程度，成就感和荣誉感是很强的。团队成员在公司内外，甚至在食堂吃饭时候被别人提起，都感到倍儿有面子。

  

  

Q平时你是什么样的？A我平常挺宅的，在咖啡厅刷刷微博微信，看看美剧、电影，吃的时候更多，撸串、火锅，其他娱乐真没有了。也过了玩游戏的年纪了。

  

  

Q不是吧？在大家眼里你很阳光啊。A不阳光，挺阴郁的，或者说，闷骚。我不是特别爱演讲什么的，讲完就跑，人家都留下吃饭什么的我都跑，可能是慢热吧，第一次见一般都挺尴尬，寒暄应酬我都不会，标准的做技术的性格。  

  

  

  

Q到目前为止，遇到的压力最大的情况是什么样的？A压力最大的就是DEFCON，对着一千多个外国人演讲。我英语不好，还有拖延症，本来打算提前一个月准备一下，后来拖着拖着时间就剩一周了，最后开始前两个小时我才看PPT，还问黄琳，这个单词怎么念？

  

  

Q那互动环节怎么办？不怕说不好吗？A互动有黄琳啊。说不好？即便我说不好还有黄琳哪（笑）。
