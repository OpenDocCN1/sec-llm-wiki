# 前日杭州，天空绝美纯白，因为，阿里ASRC2016大会盛开

本月13日，14个安全团队、17个SRC齐聚阿里光明顶共庆ASRC2016白帽大会。此次大会由阿里安全副总裁 杜跃进，阿里威胁情报体系负责人方兴，ASRC主要工作负责人清漫，PKAV 安全团队技术负责人二哥做主题演讲。此次大会突出介绍了阿里安全的新变化，将会向着阿里安全生态圈的方向建设，并逐步进行国际化的运作。

**杜跃进：安全业务的未来会不断融合 阿里安全正建设安全生态圈**

 

作为目前全球最大的电子商务平台之一，阿里的淘宝平台正完成着不可思议的任务。“在2015年的双十一期间，阿里的淘宝平台每秒产生14万笔交易，每秒完成8万笔支付，远远超过VISA实验室支付系统的理论峰值数据（每秒3万笔）。”杜总如是说。

  

![](../Images/e6c40c4438587b9df52cd4551528e83e.png)  
 

整个阿里集团有4万5千多人，分布到全国后也未必有多大的影响，但是全国依靠阿里平台及周边就业的人数已经达到1000多万。随着今年来互联网对人们生活的影响越来越深，这些技术也带来了新的安全挑战。安全业务的未来会发展成一整个”大安全”，以互联网为平台的商务业务平台进行不同领域的融合。所以阿里安全在2016年，希望用生态合作的方式进行安全建设，并且帮助阿里安全生态圈中的伙伴进行更好的发展。

 

同时，杜总也将对ASRC的期望归纳成琅琅上口的16字总结：

 

“扩大（覆盖）领域（从漏洞到所有威胁）、扩大（内部）影响（从漏洞收集入口到内外安全桥梁）、扩大团队（更多的人做更多的事）、扩大合作（更多的资源互助互利）”

 

**方兴： 互联网威胁情报收集工作需要多家企业联合收集**

  

![](../Images/fd2c8794f4d19f483b3c798d3b4e87f5.png)  
 

方兴，flashsky，阿里花名闪空，阿里情报威胁体系负责人（[【人物】侠客方兴](http://mp.weixin.qq.com/s?__biz=MzIzMTAzNzUxMQ==&mid=211227234&idx=1&sn=cee2bafead0ce0bf861dd14e53876630&scene=21#wechat_redirect)；[【访谈】方兴：信息安全需要“核威慑”](http://mp.weixin.qq.com/s?__biz=MzIzMTAzNzUxMQ==&mid=211227234&idx=2&sn=a7a0ca4dcc3fa3eafc0e13893ffbc256&scene=21#wechat_redirect)；）。时隔一年，再一次见到闪空只有一句话可说，好萌。他的演讲朴实无华，简单直接。伴随着互联网发展的黑产技术也在突飞猛进，基于各大互联网公司的攻击与诈骗也往往有着跨公司产品的产业链分布特点。例如，将淘宝上的消费者骗到QQ上进行支付诈骗，将京东的客户骗到淘宝上进行诈骗。这样一来，每家公司看到的内容往往只是事实的一部分碎片，无法对黑产进行完整的溯源。所以，闪空呼吁古道热肠的白帽子们，为国家社会的正常秩序稳定，打击网络犯罪，放弃公司之间的偏见壁垒，形成一个情报共享联盟。

 

阿里威胁情报机构会针对黑产资产、黑产工具、受害人群、专职人群等内容，设立情报奖励体系。

 

**清漫：2016 ASRC打造阿里生态安全 走向国际**

  

![](../Images/96a3fd3674ffac247a052cfa37062607.png)  
 

2013年10月成立至今，已确认收到千余白帽子提交有效漏洞，100多个威胁情报，并已有200余白帽子经过支付宝实名认证。2016年ASRC的工作重点将围绕着“漏洞+威胁情报”展开，不但会加强自身的安全建设，并且会帮助阿里系的子公司以及合资与合作伙伴进行众测建设，同时会进行国际化尝试。时至今日，《阿里威胁情报收集计划》已经发布2.0版本(行业首份标准)，以促进威胁情报缩短响应时间，推出SRC沙龙“雷锋会”进行xSRC平台之间的工作成果分享。

 

先知计划：是一款针对阿里云用户产品的众测平台，付款快速的特点，以补贴白帽子的方式对阿里云用户完全免费。

 

**PKAV二哥：目前漏洞等级评定对web漏洞的危险严重低估**

  

![](../Images/cbc582ae0ff4cf368a0216a27759d699.png)  
 

PKAV是四川无声公司的双螺旋安全实验室的安全团队，一直活跃在当地安全领域。此次大会获得了ASRC最佳合作团队奖。作为一个典型的安全技术员，二哥的演讲一点也不枯燥乏味，相反整场演讲中笑声不断，事例丰富而又详实，并且其中不乏尖锐独到的新鲜观点。

 ![](../Images/a440d74d10b61129edb976127fb88db9.png)  

由于互联网公司规模越来越大，产品线越来越多，造成了新的安全问题与前所未有的复杂度。“目前漏洞等级评定对web 漏洞的危险严重低估”、“互联网公司的发展，导致安全问题在互联网企业之间的模糊”、“安全问题是一个动态的过程”。

 

**圆桌讨论：甲方、乙方与白帽子的关系变化**

![](../Images/ce7e8124981c19fbee356a817d38d65b.png)  
 

主持人：贤唐

 

圆桌参与讨论人：301（原乌云众测产品负责人）、老马哥哥（原ASRC负责人）、孙维伯（绿盟资深安全研究员）、清漫（现ASRC负责人）、加菲猫（BSRC负责人）、121（发哥，CubeSec负责人）

 

贤唐：乌云使众测模式真正兴起。

301：乌云的真正价值在解决了企业与白帽子之间的信任问题，而不在于金钱上的多少。

老马哥哥：白帽子真正价值难以直接表达给甲方。

孙维伯：乙方为甲方的安全建设提供战略方案，有更多的经验与行业背景；白帽子为甲方解决更为具体场景的实际问题。

清漫：2014、2015年白帽子提交漏洞数占全年发现漏洞总数的50%以上。希望白帽子能提交更高质量的漏洞。

加菲猫：BSRC白帽子提交的漏洞占比也非常高。
