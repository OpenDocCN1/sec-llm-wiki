# 【白帽】强大也是一种习惯，MJ和360VulCan小记

前阵子出过一件大事，代表人类的李世石被代表机器的AlphaGo击败了。  
前阵子信息安全圈也出过一个事，AlphaGo的“亲兄弟”没撑住，被某人类代表给收拾了，而且收拾得干脆利落，前后不过11秒。  
当然，AlphaGo的“亲兄弟”并不会下围棋，它只能在网上搜罗信息资讯，它就是被Google精心打造并重甲防护的Chrome浏览器。别小看这个浏览器， Google可是动用了超过4000台服务器对其做长期持续漏洞测试的，单从计算能力来看，Chrome并不亚于AlphaGo，所谓一龙生九子九子各不同，Chrome的安全强度，在安全圈一直是有口皆碑的。  
就是这么个得到重重防护的厉害家伙，在不久前刚结束的Pwn2Own大赛上，被一支来自中国的团队成功突破，历时仅11秒，算是给我们人类出了口“恶气”。这支团队就是360VulCan。  
作为信息安全新媒体，安在怎能错过第一时间的“八卦”？趁着360Vulcan转战新加坡SyScan大会，安在跟踪追击，第一时间“踩”了360VulCan的领队——业界大名鼎鼎的郑文彬。  
MJ其人

  

![](../Images/afbec70220034c01ca0a7551321abc82.png)

  
郑文彬网上ID是MJ，是360首席工程师、反木马专家及360Vulcan团队负责人。作为微软Windows “DirectShow视频开发包”漏洞的发现者，MJ曾被微软官方公开致谢，并有国内内核第一人、“驱动神童”之美称。  
“目前在360，我负责管理的有十多个团队，分别做不同方向的研究。”开门见山的MJ语速平缓，声调沉稳而踏实，给人一种很“靠得住”的感觉。  
MJ于2006年加入360，几乎是和360一起成长起来的。  
以杀毒起步的360，当年也曾走过步履蹒跚的阶段。2008年，360推出第一版杀毒软件，“那个版本其实并不成熟，收到的负面反馈不少”，情急之下，老周临时抽调一批核心技术人员，组成“杀毒突击组”，希望能够扭转局面，MJ就在其中。  
“要知道，那时候360规模还不大，一个产品成败可能就决定了未来的发展。”杀毒突击组临危受命，奋战一个月以改善杀毒软件，“那段时间，常常是24小时在公司里，用户评价有一点点问题，我们就立即去修正和改进。”  
艰苦奋战终有成效，突击组没有辜负老周期望，新推出的360杀毒软件一举扭转局面，收到了良好的反馈。正是基于那段时间的成果，360杀毒以及安全卫士，为360后来快速成为国内知名安全厂商而奠定了基础。在这中间，MJ无疑立下了汗马功劳。  
作为一名典型的技术工程师，360同样成就了MJ。伴随着360一路走来，MJ从能力强悍的单兵，到能影响一方的首席工程师，再到现如今的领导角色，MJ也步步为营几经蜕变。当然，就像很多技术人员并不乐于脱离一线从事管理一样，当公司首次任命MJ为团队领导时，MJ是很犹豫的。  
也许这就是几乎所有技术人员的潜在心理：技术和管理截然不同，技术钻研需要执着和专注，胜在在某个方向不断精进和深耕之后的豁然开朗和心理满足；而管理，则强调沟通与协调，重在与人打交道。对技术人员来说，若要转向管理，往往顾虑两点：一是担心自己不能胜任；二是对“疏远”了技术后的依依不舍。“能够孜孜不倦钻研技术的，通常都是非常喜欢，我也是这样，所以，要让我偏离了自己喜欢的道路，多少会觉得不大舒服。”MJ如是说。  
就在几乎没人说服MJ的情况下，齐向东亲自出马了。  
“齐总是个很有说服力的人。他对我讲，他有一系列的计划，由我来领导团队在安全技术上做更深入的开拓和创新，这不仅仅是个人的事情，也是公司战略的需要。”与其说老齐是在说服MJ，不如说老齐是在向MJ展示一个宏图，如此一番，MJ不是被说服了，而是被真的打动了。  
事实证明，无论老齐还是MJ，对于当初的选择都是无比正确的。  
转型做了管理者后,MJ发现其实并没有想象中那么困难。“毕竟还是由纯技术人员构成的team，大家一起的交流，更多还是技术，加上环境又没什么变化，对我来说基本上没有所谓的适应期。”当然，骨灰级技术爱好者无论什么时候都不会忘了钻研技术，哪怕时间相对稀缺。“技术人员习惯的节奏是三到四个小时集中出活，但转型做管理后就不能奢望这样了，需要做些改变。”MJ的方法是，把自己的研究分割到碎片时间里去。“2015年，我在韩国演讲，主题是微软Windows 10的多个安全漏洞和攻破最新的Edge浏览器的0day漏洞，这些相关的漏洞，都是在碎片时间里发现并积累起来的。”  
从技术到管理，MJ一步步平稳进阶，经他手带出来的团队也个个出色，这其中就包括360VulCan。  
360VulCan其事  
![](../Images/274a2d760941c8a8eeb0f1236202c5ae.png)  
提到360VulCan，MJ语带兴奋，且透着一股子自豪。  
“Pwn2Own历史悠久，已经有七、八年时间了。能在那里展示自己，是全球安全界精英共同的心愿。2011年的时候，我就曾想带队参与，可惜没有成行，等到15年，终于能够真正参与，而且努力还最终得偿所愿，心里当然是很激动的。”  
首次参赛，初出茅庐的360VulCan颇多紧张：“当时已经在去往温哥华的飞机上了，我们还在调试，毕竟是第一次，担心做出来的东西不稳定。”好在结果还不错，既“见了世面”，又展示了自己的实力。及至2016年的本届比赛，虽然难度大大提高，360VulCan已不再有任何忐忑，而是踌躇满志了。  
“这次比赛难度提升了不少，也增加了很多限制。比如时间上，以前是三十分钟内可以无限重试，现在则变成了十五分钟，只允许重试三次。”  
如此严苛的条件，360VulCan自然是严阵以待，“其实也挺紧张的，担心墨菲定律会作怪，比如说即使方方面面都想到了，可能比赛时还会出现一些意外。我们有一个程序员，在配置时输入一个指令，好几次都输不对，手抖得厉害。不过，到了第二场，情况就好多了。”  
最终，他们成功了，他们在11秒内，让AlphaGo的“亲兄弟”——Chrome浏览器俯首就擒。  
提及360VulCan的优势，MJ说贵于实力的均衡。我们知道，通常安全圈人才可分为“江湖派”和“学院派”，前者拥有丰富的实战经验和极佳的攻防意识，而后者胜在扎实的学术研究和技术功底，问题在于，对很多组织来说，这两派往往各居其一实难两全。而在360，确切说在360VulCan，两者同时存在且水乳交融。“‘学院派’即使前期并没有接触过漏洞挖掘，但由于技术功底扎实，上手非常快，最重要是他们有很好的思维方式和研究方法，后劲会非常足。而‘江湖派’则可以在前期提出好的更具落地性的想法，起到开拓者的作用。对于团队，二者都不可或缺。”提到自己的团队，MJ自然有着最到位的评价。“其实二者是相互参照并殊途同归的，‘江湖派’在公司里一方面能持续磨练技术，同时也能补充系统研究的方法，而‘学院派’因为有足够的基础，多了漏洞挖掘的实践，后面会发展得更全面。”  
就是这样一支强悍的团队，名字却是临时起意凑出来的。  
其实在正式参赛之前，还没有360VulCan这个队名。MJ笑着解释其中原委：“Vulcan这个名字是我随便起的，灵感来源于《星际迷航》里一个科技最发达、也是最理性的同名的种族，在我看来，我们就该是这样一群人。当时已经上飞机了，再不向组委会报名字人家就不收了。灵机一动，我就说，那就360VulCan吧，大家没什么意见，然后就那么定了。”  
在古罗马，Vulcan是火神。他的相貌并不出众，但却心灵手巧，能锻造出各式各样精妙而锋利的武器，众神手中的武器，一大半是他打造的。也许在潜意识里，MJ就一直希望并努力去锻造出像火神一样的团队——低调而内敛，技艺高超，智慧超群。  
还在路上  
当360这艘巨舰乘风破浪时，舰队里的每一个成员都豪情万丈。  
让MJ感到欣慰的是，已经取得了不错战绩的360VulCan并未停步，相反，他们正以更大的热情奋步前行。  
在3月23日举行的亚洲地区信息安全领域技术发展风向标——SyScan360大会上，组委会同期举办了Pwn0rama亚太手机安全挑战赛，360军团再次上演拿手好戏：360手机卫士安全研究员龚广开赛首日就攻破了Google最新版本的Nexus6p手机，全程用时不到8秒。要知道，此次Pwn0rama亚太手机安全挑战赛无论规模还是难度，都远超上届的东京挑战赛，破解10款时下最流行手机的悬赏金额更是高达50万美元，堪称手机安全领域全球最高规格的黑客破解赛事。  
其实一切并非偶然。论技术实力，龚广早已业界闻名。2015年11月，在日本东京举办的PacSec太平洋安全大会上，龚广在两分钟内破解了Nexus 6，成为全球破解N6第一人。而今年的Pwn2Own大赛上，正是龚广助力360 VulCan，成功破解Chrome，完成了这项“不可能”的任务。  
MJ看在眼里乐在心中，当一个团队的强大成为习惯，那对它最好的嘉奖，就是让他一如既往并更加全面地强大下去。  
“接下来我有个心愿，就是让我的团队不仅仅在技术上，也要在生活上均衡发展，这才能保证我们团队持久的战斗力和坚韧的耐受力。”当我们以为MJ只会讲技术时，他却来了个180度的大转弯。“我们团队的成员都是专注于技术的人，这也有点‘副作用’，有几次我想叫上大家一起玩，可似乎大家都提不起兴趣。其实，人生不能仅技术，技术之外也有很多乐趣，偶尔唱唱歌，搞点小情调，这样才叫生活嘛。”  
说到这里，MJ似乎心里已经有了“使坏”的招儿，竟至忍不住笑出了声来。
