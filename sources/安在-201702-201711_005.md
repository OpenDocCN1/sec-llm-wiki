**会员融资快报**

  

  

▌ **火绒完成1500万元Pre-A轮融资 进军企业终端安全市场**

  

10月10日上午消息，北京火绒网络科技有限公司宣布近日已完成Pre-A轮融资。老牌安全厂商北京天融信公司向其注资1500万元人民币，并签署了战略合作协议。火绒将利用其技术优势，帮助天融信打造终端安全产品，完善其下一代网络安全架构体系，携手进军企业终端安全市场。

  

![](../Images/869409bdc3bc1e5250f554127e1ee3d1.png)

火绒安全CEO刘刚

火绒成立于2011年，长期专注于终端安全领域，潜心研发引擎等底层技术，构建完成EDR（终端、检测和响应）运营体系，逐渐开始领跑终端安全领域。火绒安全2012年发布的“火绒安全软件”是一款免费个人电脑安全软件。来自火绒的数据显示，该软件已积累了数百万用户，即将推出自己的企业级产品“火绒企业安全软件1.0版”。

  

**会员企业动态**

  

▌**瀚思科技荣膺“2017中国最具投资价值企业50强”**

  

2017年10月26日，由清科集团、投资界、新芽联合举办2017 Venture 50的颁奖典礼，汇聚近百位知名创客及投资大佬到场，解读尖端技术、分享前瞻商业、展示摩登产品，与所有伙伴一同“爆料”创业 ，喊出创业最强音！  

  

历时1个月，来自中国最活跃的100+顶级风险投资机构的投资大佬们公平公正的评审，万众期待的2017 Venture 50“风云榜”企业名单出炉！瀚思科技（HanSight）从三千多家参选企业中脱颖而出，入选“中国最具投资价值企业50强”，排名第20，为安全行业唯一入选企业！

  

![](../Images/273238f502297dee924d2f43f141297a.png)

  

2017年，创新创业浪潮持续洗涤中华大地，在无数奇妙创意与商业灵思的碰撞之下，中国涌现出大批的优质企业和创新项目。从“少有人做的事”，到“全民创业”，Venture 50陪伴创业者们跋涉了十二年，作为国内首家投资维度的企业评选，关注高成长企业，被誉为“行业投资风向标”。

  

![](../Images/a6b3901988b65a0b3c00dd4ec828599b.png)

  

瀚思科技（HanSight）成立于2014年，2017年7月完成B轮融资1亿元，由国科嘉和、IDG资本领投，南京高科等继续跟投，开创安全行业初创企业融资历史新高。

  

▌**微步在线入选全球网络安全500强**

![](../Images/68097d30fd18161f6d542297701665c6.png)

  

日前，全球领先的网络安全市场研究公司Cybersecurity Ventures发布了最新的全球网络安全企业500强（The Cybersecurity 500）名单，共有9家中国企业上榜，其中微步在线（ThreatBook）凭借着在威胁情报领域的领军产品、技术实力和“安全智能、情报驱动”的行业理念跻身九家上榜企业之中，是唯一一家专注威胁情报领域的公司，也是唯一一家成立仅2年左右的企业。同时入选的中国企业还有安天、绿盟、安恒、360等。

 

Cybersecurity Ventures每季度发布一次全球网络安全企业500强名单，这份名单包括了当今全球最具创新性力的安全企业。在评选这份名单时，Cybersecurity Ventures并非按照收入规模或团队规模对公司进行排名，而是根据公司所处细分行业、帮客户解决的问题、客户群体、CISO和决策者的反馈、评测机构反馈、咨询顾问反馈、公司增长、风险投资情况、产品评价、等等，从热门情况和创新力来进行综合评判，汇聚了全球领先的网络安全技术和服务公司。

  

▌ **全球最前沿安全技术公司评选 长亭科技上榜**

  

全球顶尖网络安全媒体Cyber Defense Magazine发布了2017年度的“前沿网络安全技术领袖公司50强榜单”。其中，来自中国的长亭科技成功入选，据悉这也是该榜单自诞生以来首度出现汉字图标。Cyber Defense Magazine创始人Gary S. Miliefsky给予了长亭科技极高的评价称：“长亭科技在下一代Web应用防火墙技术的创新，值得业内认真考量”（原话：Chaitin Tech Safeline is an innovative Web Application Firewall worthy of serious consideration）。  

  

![](../Images/529bfa327ce3576e18541881921ef077.png)

  

▌**天空卫士斩获自主可控最佳创新奖**

  

10月12日，全国抗恶劣环境计算机第二十七届学术年会在杭州召开。天空卫士凭借业界首款结合大数据分析和人工智能的新一代大数据安全技术（BDSA），受主办方特别推荐并经过大会专家组严格评审，一举荣获2017年度自主可控最佳创新奖，同时也是本次获奖的唯一家数据安全企业。

  

![](../Images/456142e80764011aae1aa996ecf80758.png)

  

2017年度自主可控最佳创新奖获奖词—— 天空卫士数据防泄漏解决方案，以国内最大的内容安全研发团队做后盾，在深层内容解析的基础上，充分应用大数据和机器学习等先进技术，不仅进一步缩小了国产新一代信息安全技术与国外的差距，更有效提升了我国数据安全领域的自主可控能力。

  

作为国产内容安全领域的领导企业，天空卫士一直在“打破技术垄断，共创英雄事业”的旗帜下，以实现高品质、自主可控的内容安全作为企业使命。随着DBSA技术的推出，天空卫士将定位于引领新一代大数据安全技术的发展。针对企业在数据安全保护方面不断发展的新需求，天空卫士将以《网络安全法》监管要求为依据，深入分析我国用户实际应用特点，量身打造包含网络、终端、云环境等复杂形态的企业整体数据安全解决方案，帮助用户有效规避数据泄露事件发生，保护我国企业核心数据资产的安全。

▌****极棒嘉年华（上海站）****

  

![](../Images/5a9880dc691ffb16222d17fa86980e19.png)

  

自开赛以来，极棒始终走在技术的前沿。  

  

2014 年，“没有规则”的极棒大赛横空出世；2015 年，设置了指纹专场、 SSL/TLS 协议安全专场等，挑战互联网安全的基石；2016 年，我们率先聚焦人工智能安全问题，“GAN 之父” Ian Goodfellow 等人在硅谷分会场分享了“欺骗人工智能的现实应用”，在嘉年华上海站上选手更是完成了能够窃取物理隔离环境中机密的“机器特工”。。。。。。

  

2017 年，极棒继续探索人工智能的安全问题，保留“无所不 PWN” 的报名规则和比赛形式，增设专项“人工智能安全挑战赛”，欢迎更多人工智能相关领域的安全研究者积极参与。

我们再次向打破思维枷锁的极客们发出邀请，让你们的才智翱游于科技之海。

▌****QCon上海站****

 

QCon是由InfoQ主办的全球顶级技术盛会，每年在伦敦、北京、东京、纽约、圣保罗、上海、旧金山召开。自2007年3月份首次举办以来，已经有超万名高级技术人员参加过QCon大会。QCon内容源于实践并面向社区，演讲嘉宾依据热点话题，面向5年以上工作经验的技术团队负责人、架构师、工程总监、高级开发人员分享技术创新和最佳实践。

▌**安创汇“走进饿了么”活动圆满举办**

 

![](../Images/0d21120468f7b56c969fd95e3f127c2e.png)

 

这是一次跨界合作的成功尝试，以互联网公司角度出发，讨论行业目前所面临的安全需求、问题等，与各界同行共同探讨行业面临的共性问题及亟待解决的安全需求，交流互联网安全的技术发展与当下最新、最热的技术话题，为行业未来安全发展开拓思路。

  

![](../Images/19d34e91121735eb71de823c90f03d92.png)

  

安在新媒体创始人张耀疆为活动开场致辞。对饿了么对此次活动的大力支持表示感谢，也对于此次活动的成功举办十分期待。对于未来更多的“走进名企”系列，表示了更多的期许与愿望，安全圈在日渐壮大，安创汇致力于帮甲乙双方制造更多的机会互动与交流，从而产生更多的合作机会。希望此系列的活动能真正的帮到大家的发展。

  
![](../Images/e6993e75f493d32a9a23b87f7966a17b.png)

饿了么安全总监王彬做为活动主办方同样进行了开场致辞。首先，肯定了这次安在与饿了么的合作，并表明了对本次安全技术交流互动的期待。安全发展迅猛，有必要走进企业，一同深度交流、相互学习，同时促进发展。
