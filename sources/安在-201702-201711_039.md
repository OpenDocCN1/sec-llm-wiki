# 他高中辍学，搞瘫MySpace，被抓后三年禁止上网，却被安全专家们视为英雄

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532592&idx=1&sn=0b801f4ea31124bf90624f2f8afdf24e&chksm=febc2af0c9cba3e683ce4b235218b62289dee40c07ac49546184d7c3a15a1788cb697dc5bb0a&scene=126&sessionid=1681310760#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532592&idx=1&sn=0b801f4ea31124bf90624f2f8afdf24e&chksm=febc2af0c9cba3e683ce4b235218b62289dee40c07ac49546184d7c3a15a1788cb697dc5bb0a&scene=126&sessionid=1681310760#rd)

![](../Images/ed4b4ffd32706c236e6e6faa8583b7b7.png)

  

2005年，萨米（SamyKamkar）19岁，不过是位高中都没有毕业，名不见经传的的小黑客。

  

但是在2005年10月4日的午夜时分，他放出了著名的 “萨米蠕虫病毒”，这或许是有史以来传播速度最快的电脑病毒，它的出现彻底改变了网络安全领域。

  

![](../Images/724cd706a4e278668f349f9fa8c5b194.png)

  

平时的萨米是一个害羞而不善言辞的少年，他从未想过成为英雄，他甚至不想和陌生人打交道。

  

**然而，由于几行巧妙的代码，一天不到，他就成为了 “英雄”，并在当时最热门的在线社交网络 MySpace 上成为了一百多万人的 “好友”。 **

  

萨米16岁从高中辍学，17岁创立了Fonality 软件科技公司，他说创建这个公司的初衷“想让那些搞计算机技术的朋友刮目看”。

  

事发的一周前，MySpace 刚开放允许用户自由地通过 HTML 代码等方式来自制个人主页，结果有的人做得五彩缤纷，也有人常常把主页弄得让人不忍直视。

  

而萨米立即意识到他其实可以对这个页面为所欲为。 不过 MySpace 上并非所有地方都可以自己设计。

  

例如，用户只允许上传12张图片。于是，萨米开始运用黑客技术，做一些网站本来不允许用户做的事，他很快便找到了可以上传13张图片的方法。 

  

在感情状态方面，用户的选择也不多，只有一个下拉菜单提供一些标准选项：已婚，未婚，恋爱中。萨米当时和自己的女朋友正如胶似漆，他希望能选 “热恋中”。

  

在黑入 MySpace 后台上折腾一番后，他如愿以偿了。做完这些后，萨米立即意识到，他其实可以做点更加疯狂的事。

  

![](../Images/a93fea0691053179da85c36b934ca6cd.png)

**萨米·卡姆卡尔在洛杉矶家中的电脑上工作。**  

  

接下来的一周，萨米写了一个病毒脚本，并且对其他用户都不可见，这个脚本不仅会强迫所有访问了他个人页面的人把他加为好友，还会在访客的个人页面的 “我的英雄”分类下加上一句话：“萨米才是我最大的英雄”。

  

**萨米发现，如果脚本只感染他个人主页的访客，传播范围十分有限，于是他将脚本设定为“感染”后，将自身复制到访客的个人资料里。 **

  

就在那一刻，他已创造了一种自主传播的蠕虫。病毒完成后，他以为一个月内可能会有100或200个好友，有人投诉的话，就把病毒删了。没什么大不了。

  

第二天早上，他发现收到了200个好友请求。他开始懵逼了，因为病毒的传播速度比他预想的要快。一个小时后，好友请求数量翻了一倍，接着不断成指数倍增。

  

萨米说，他那个时候甚至给 MySpace 发了封匿名邮件，提醒他们有蠕虫病毒，并提供了解决办法，但没有收到回信。直到今天，他也不清楚到底有没有人看到了那封邮件。  

  

下午1点30分，他已积累了超过2500名好友和6000多个好友请求。当晚他就发表了一篇博客，把事情的来龙去脉说了一遍。他写道：“情况已经失控。太多人给我发私信说我的名字为什么会出现在他们的“英雄”名单上，他们已经举报了我。

  

大家生气的原因，显然是因为他们将我从好友名单中删除后，只要浏览其它人甚至是自己的主页，就会马上被重复感染，他们无法避免我的存在。” 

  

他补充道：“只能祈祷没人起诉我。” 几小时后，萨米吃完饭回到家，他已经收到将近一百万个好友请求了。他在博客中写道：“说真的，我已经火了！” 

  

![](../Images/3c7e0b1ac3c3543fca2bfd049a5c9c1e.png)

**2005年10月5日，萨米的 MySpace 个人主页屏幕截图。**

  

好友请求超过一百万后，MySpace 公司让网站下线了，他们想弄明白究竟发生了什么事，如何清除病毒。 

  

萨米当时觉得很惊慌，但那个时候他早已无能为力了，从他释放了蠕虫的那一刻就已经太晚了。大约两小时后网站重新上线，他的个人主页被删掉了。

  

事件几个月后，库那（Kunal Anand）出任 Myspace 安全主管，他说萨米蠕虫爆发的时候，公司几乎没有安全团队，对此事件完全束手无策。所有人都没见过像萨米蠕虫病毒这样的东西。库那认为，这是安全行业的重大转折点。

  

然而白帽安全公司（WhiteHat Security）创始人、网络安全专家杰瑞米（JeremiahGrossman）认为，萨米蠕虫是“行业中所有专家都在等待的一次机遇”。

  

萨米的蠕虫病毒尽管传播速度快，但本质上并无害处，只不过是给他加了好友，然后在受感染者的个人主页中添加几个字罢了。

  

可是如果萨米心术不正，或者病毒作者有更邪恶的目的，它完全可能会被用作盗取别人的账户或者其他更加邪恶的事情。如杰瑞米所说，萨米 “完全有能力为所欲为”。 

  

萨米使用的技术被称为 “跨站脚本攻击”，现在早已被人熟知，经常被缩写为 XSS，其原理是攻击者在网站中插入恶意代码，并欺骗网站和用户的浏览器去执行这个代码。

  

那时人们严重低估了这个漏洞。每个网站都有这种漏洞，但没人真的去展示我们到底可以利用它来做些什么，但萨米做到了。

  

萨米蠕虫出现时，80%至90%的网站都容易受到类似的攻击。这件事得到了巨大的关注，开放式 Web 应用程序安全项目（OWASP）甚至还组织开发了一个应用程序编程接口，让网站能允许用户在个人页面使用代码的同时不受 XSS 的威胁，他们将其称为 “反萨米项目”（AntiSamy Project）。 

  

2015年，白帽安全公司收集的数据显示，仅有47%的网站可能存在这种漏洞。如果不是萨米的蠕虫病毒吸引了人们的关注，或许现在这仍然会是一个更为广泛的问题。 

  

这些年来，尽管网站和浏览器都加强了针对跨站脚本攻击的安全防护力度，但仍发生了几次较为著名的病毒攻击。

  

**例如2013年几位雅虎用户的电子邮件帐户由于类似的漏洞被盗取； 2014年，黑客则在 Tweet 桌面版上找到了一个 XSS 漏洞，可以在用户登录时强制弹出恼人的提示框； 2015年，也是由于 XSS 漏洞，一条简单的评论就可能影响 WordPress 博客。 **

  

尽管萨米的意图是无害的，还发表了博客解释他的所作所为，但是，他最终仍旧逃不开法律的制裁。他释放病毒的六个月后，美国特工处和洛杉矶警察局电子犯罪特遣队（Electronic Crimes Task Force of the LAPD）带着搜查令搜查了他的公寓和办公室。

  

政府当局没收了他的笔记本电脑、三台台式电脑和硬盘之类的所有电子设备。洛杉矶地方检察官根据加州刑法起诉他涉嫌计算机犯罪，特别是通过病毒感染电脑系统。  

  

萨米后来回忆道**：“我当时很害怕，我连高中文凭都没有，所以真的很担心他们会再也不让我碰电脑。电脑算是我仅有的东西了。”**

  

最后法庭上，他认罪伏法，被判三年缓刑，期间不能碰电脑更不允许上网。只被允许只能使用一台在当局注册了的电脑，而且不能上网。  

  

然而，缓刑可以让他继续在自己的公司担任管理职务，甚至还受邀去各种会议和演讲中谈谈他的蠕虫病毒。

  

2007年他在 OWASP & WASC 应用程序安全会议上遇到了杰瑞米，杰瑞米与朋友穿着印有 “萨米是我的英雄” 字样的T恤出席了此次会议，以此来声援萨米。

  

![](../Images/72d2bfd1df3679403e0926e9679b24ae.png)

  

有趣的是，由于萨米对应用安全领域造成的非凡影响，使得他去参加各种安全的会议和活动时甚至都不用花钱了。他曾对别人开玩笑说：“我觉得10年内我们在这类会场见面时，我都不用花钱给自己买饮料。” 

  

2008年，萨米结束了缓刑。他做的第一件事是冲到苹果专营店去买了一台笔记本电脑。接着他去最近的星巴克，打开电脑上网。

  
远离网络三年后，他都不知道该上什么了。于是他花十分钟访问了几个网站，然后去拜访了一些朋友的主页。 

  

萨米说，在萨米蠕虫事件前他 “十分内向且害羞”，因此 “三年不碰电脑其实对我这种电脑宅来说是件好事，让我可以做其他事情。” 

  

不过萨米一回到网上，就想出了一堆运用黑客技术的新点子和新技术。2010年他在拉斯维加斯著名黑客大会 DEF CON 上第一次发表讲话时展示了其中一些内容。

  

![](../Images/5f750958d6c9e4addf1fee39c863d07a.png)

**萨米在2010年BlactHat大会上的发言。**  

  

从此之后他就离开了公司，成为独立黑客，他先后揭露了谷歌、苹果和微软是如何跟踪他们的客户、创造了能自动劫持无人机以及开汽车锁和车库门的设备，而且全部都是以提醒公司注意安全问题、保护客户的名义进行的。

  

他惊人的成就以及能让黑客技术和信息安全变得通俗易懂的天赋让他成为了安全圈家喻户晓的人物。然而，假如现在能够使时光倒流，萨米说他 “可能不会放出蠕虫了。”萨米蠕虫的出现大大提升了人们对网络安全的重视，所以在某种程度上说，他是一个英雄。
