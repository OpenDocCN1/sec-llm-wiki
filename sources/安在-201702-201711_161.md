# 侯浩俊：安全是一场持久战

“做安全这件事情，不见得要比谁跑的快，但一定要比谁走的久。”这是ADLab的侯浩俊在接受安在的采访的时候说出的话，同时也是他在安全行业这几年得出的对自己的忠告，发人深省。

 

侯浩俊，启明星辰ADLab副总监。电子科技大学硕士，毕业之后进入启明星辰 ADLab（积极防御实验室）工作至今，目前主要负责 ADLab 的漏洞研究团队。

  

一．**ADLAB与****Phoenix Talon**

  

侯浩俊告诉**安在（anzer\_sh）**：2017年5月9日，启明星辰ADLab发现Linux内核存在远程漏洞“Phoenix Talon”（取凤凰爪四趾之意），其包含4个漏洞（CVE编号：CVE-2017-8890、CVE-2017-9075、CVE-2017-9076、CVE-2017-9077），经研究这些漏洞在Linux内核中潜伏了至少11年之久，影响的版本基本上涵盖了所有的版本，从老到新影响面非常广。  

 

**什么是****Phoenix Talon****？**

 

Linux存在着若干不同的发行版本，比如Redhat、Centos、Ubuntu、Suse等，包括很多国产化操作系统也使用了Linux内核。Linux凭借其开源和安全性的优势，常被用作网站、游戏、应用服务器的操作系统，除此之外Linux可以运行在多种硬件平台上，比如X86服务器、台式计算机、网络设备、平板电脑、机顶盒、游戏机等。

 

“Phoenix Talon”漏洞可被攻击者利用来发起远程DOS攻击，且在符合一定利用条件的情况下可导致远程代码执行，包括传输层的TCP、DCCP、SCTP以及网络层的IPv4和IPv6协议均受影响。如攻击者利用该漏洞发起攻击可导致部署Linux操作系统的网站服务器、应用服务器、中间服务器宕机或被控制！

 

“Phoenix Talon”中以CVE-2017-8890最为严重，该漏洞一举拿下了Linux内核漏洞两个评分标准的史上最高分：CVSS V2评分达到满分10.0，CVSS V3评分是历史最高分9.8，由此可见该漏洞的危害程度！

 

**ADLab是如何让发现该漏洞的？**

侯浩俊告诉**安在（anzer\_sh）**：ADLab日常的工作方向包括漏洞研究、渗透测试、恶意样本分析、源代码审计、威胁情报等，研究领域覆盖传统桌面与服务器操作系统及主流应用、web安全、移动平台、工控安全、车联网和物联网等。因此ADLab有很多团队，每个团队都有自己确定的研究领域，长期对该领域相关技术进行研究、跟进以及引领。“Phoenix Talon”则是侯浩俊所在的漏洞研究团队发现的。

 

侯浩俊这么解读他们的日常工作。“ADLab是个技术研究队伍，大家在兴趣驱动的基础上聚到了一起，不只为一份工作，更为能一起做些自己感兴趣的事情。因为安全研究/技术的范畴很广，且从某个方向往下又有很多细分领域，团队内部在自己的细分研究领域上往往是很少的几个人有的时候甚至是一个人在深耕，所以必须是这种内驱式的兴趣才能“孤独”快乐的坚持下来。“

 

**安在（anzer\_sh）**了解到：ADLab从发现（2017年5月9日）到申请编号，到最后（2017年6月16日）文章发出来，这中间等了一个多月之久。为什么等了这么久？侯浩俊解释道：一方面在等各个发行版本都PATCH完，另一方面他们也在测试该漏洞的受影响范围同时测试公司产品的受影响情况并积极修复，之后他们才来做对外发布这件事，这是一种负责任的态度。

 

我们有理由相信，对于ADLab这样一个团队来说，以后会有若干个不同领域的“Phoenix Talon“出现。

  

二．**ADLab，一个“老牌”的新团队**

  

![](../Images/ae82f62de5c2124d24e2c03d468de948.png)

  

真正好的研究人员一定是既自信又谦卑的，那么一个好的团队应该有的状态又是怎么样的呢？通过与侯浩俊的交谈中，我们发现ADLab给了我们最好的呈现。

  

ADLab非常强调个人在团队里以及个人与团队的关系，个人的成长跟团队本身有非常大关系。对外，团队任何个人的行为都会依托于团队，因为团队始终是一个整体的存在而非个体。对内，团队强化个人贡献差异的平衡和良性竞争，因为团队始终是由一个个独一无二的个人构成。ADLab既鼓励个人更强调整体和“团战“。

 

说到启明星辰，与之相对应的标签便会有：沉静，低调。

 

启明星辰一直非常低调存在于在安全圈里面，在一些外界的宣传曝光上我们基本上很难见到他的身影。但是即使是这样，他仍旧是安全圈里面不可忽视的老牌劲旅。而对于这两个字：老牌。“很多人一见到老牌会觉得比较固守传统，然后很容易把它往缺乏创新没有朝气的方向去引。但是老牌看上去老，其实它内里面有很多新的东西，因为大多数时候你在外面看到的和身处其中体验的东西是完全不一样的，老并不意味着out了，老意味着有其底蕴的东西在内里，换句话说，老牌表示你得有自己的故事，自己的体会，历久才能弥新。”

 

俗话说，酒香不怕巷子深。侯浩俊开玩笑的跟安在说到：虽说酒香不怕巷子深，但身处现在这个时代，酒香还是需要通过努力使其飘出巷子，这样才会让更多的人闻香品酒。

 

而在ADLab中却没有谁是一战成名的，都需要有一个漫长的积累过程。

 

侯浩俊随口说到自己刚进公司的感受：刚开始进入启明星辰，在ADLab一直呆到现在，说实话我一开始真的是觉得这个公司缺乏能点燃自己东西，因为那时候刚毕业热血的我总是希望什么都是热火朝天的。

 

但是经过这几年工作，侯浩俊才慢慢体会到持久才是王道。

 

热情与热爱还是差的比较远的。热情可能维持的是一时，但对于ADLab三代研究员十几年的坚守来说，光有热情是远远不够的，这其中需要太多东西来坚持，最重要的是秉持将安全视为终身事业并为之奋斗的这份热爱。

  

**三．技术是把双刃剑**

  

在当今这个流量眼球时代，掌握技术是把双刃剑，一念之差带来的效果和影响，其区别之大也是我们所不能估量的。

 

侯浩俊向安在介绍：ADLab这几年一直坚持的一个非常严格的甄选人才原则：我们在筛选Lab成员的时候，无论你技术到什么程度，只要你沾过一点点的黑或者说可能沾过，一律不会考虑。

 

有一年他们招了一个人，当时觉得其他方面都挺好。但是他提出了一个要求：工作之余的漏洞可以卖。团队毫不犹豫地拒绝了他。“安全这个行业比较特殊，你卖了第一个肯定会卖第二个，这个东西是没法控制的。”

 

技术一直是把双刃剑，掌握技术的人便是使用这把双刃剑的人。如何使用，取决于个人，但是对于ADLab来说，会永远把这把剑往积极方面去利用，这一点是不容许有丝毫偏差的。

 

你觉不觉得现在的圈子比原来要浮躁的多？安在结合现今安全圈的特点给侯浩俊抛出了这么一个问题。

 

”其实我更愿意用喧嚣来形容，因为浮躁的是我们自己心里的状态，而现今的安全圈相较之前来说已经处于喧嚣的状态。“侯浩俊很认真的回答说。

 

对于做安全的人来讲，大局观很重要，一定不能把安全做“窄”。一直以来安全大都是作为产品或业务的“附属品”，随着他们的改变而变化，但是若想把安全作为终身的事业去追求，可能需要跳出这种怪圈，时刻保持对整个行业的生态和发展动向的关注，未雨绸缪地进行一些探索。不能沉醉于安全表面的喧嚣热闹，失掉安全纯粹的内心。浮躁的是你，但喧嚣不属于安全。

  

四．**安全是场持久战**

  

![](../Images/5a7652398925a1f76a8e7dc537b42b53.png)

  

安全不是一蹴而就的，而是一场持久战，做安全的人亦需要这样的恒心。

 

侯浩俊告诉我们：你要有一颗能够坚守的心，以及形成一套沉淀的机制。

 

对于ADLab的未来，侯浩俊发出这样的期望：三年内想做的是影响力，我们要走出去，因为我们之前对外的发声不多，以前对外大都是以技术文章的形式，很少走出去讲我们的研究成果以及我们在研究过程中的一些思考。三年之后，我们希望ADLab能够做一些安全研究方面的原型出来以解决一些特定领域的安全问题。

 

持久安全，不忘初心。技术一般被认为是寂寞的代名词，耐得住寂寞，方能悟出真正的技术。说出来可能大多人会觉得矫情，但侯浩俊告诉**安在（anzer\_sh）**：这是他们的真实想法和初衷。“真正做技术的人，更多是为了技术本身的追求，而名利并非我们的最终目标。“

 

整个访谈下来，不得不说，安在真的有被ADLab所秉持的匠人精神所打动。言之于口，感知于心，一直以为感同身受是个悖论，通过ADLab，方知只是未到感知处。

 

启明星辰ADLab，因为热爱，所以坚持。
