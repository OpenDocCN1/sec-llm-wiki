# 我们已经生活在《攻壳机动队》里的未来吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532492&idx=1&sn=1e09a296c31770643b3a344a7b812dec&chksm=febc150cc9cb9c1a626acffe620cf75c1c2209e5ecbdaa55f88540eea3d711f8fbeb352a6c0f&scene=126&sessionid=1681310769#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532492&idx=1&sn=1e09a296c31770643b3a344a7b812dec&chksm=febc150cc9cb9c1a626acffe620cf75c1c2209e5ecbdaa55f88540eea3d711f8fbeb352a6c0f&scene=126&sessionid=1681310769#rd)

《攻壳机动队》为我们作了绝佳的未来预演，自由意志还将决定一切吗？人心之异变也是一种妖怪，那一具又一具没有灵魂的躯壳可是我们？

  

![](../Images/18c100c2fc3ba5153403382aed0baee7.png) 

《攻壳机动队2017》剧照

 

冲着 Scarlett Johansson 与北野武的超强卡司，极其华丽的未来城市特效画面，由 Rupert Sanders 执导的《攻壳机动队2017》火爆大银幕，它是经典动画重新翻拍的真人版，虽然剧情部分稍有改动，但画面上几乎是神还原，这也是影迷们高度期待的吸睛重点，观赏本片之余，或许你需要一些背景知识来帮助理解这部电影非看不可的理由，以及1995年《攻壳机动队》Ghost in the Shell 剧场版为何在影迷们心中被誉为 SF 神作，迄今无人超越。

 

《攻壳机动队》是在描述2030年左右，全身义体化以及电子脑普及的未来时代，日本特种部队“公安九课”是专门打击新型态犯罪的镇暴警察，他们侦察的案件极为复杂难办，称之为重案组一点也不为过。身为少佐的草薙素子是首位实验成功的全身义体生化人，她的搭档巴特探员则是身体局部改装为义体的生化人，两人都是冷血无情的终极兵器，便于执行罪犯的猎捕行动。

 

  

**黑色，颠覆与**** Cyberpunk**

押井守版本的《攻壳机动队》Ghost in the Shell 是一部充满哲学意涵的科幻动画。它是根据日本漫画家士郎正宗于1989年首次连载的cyberpunk漫画改编，这部漫画当中所描绘的全新世界观几乎颠覆了人类过往以来对于“生命”的看法。

 

![](../Images/ffdccf654f1e412e9d1a27f4e1f0674b.png)

  

片头一开始女主角站在高层大楼的天台往下方俯瞰，在获取情报后决心只身攻坚，运用热光学迷彩让身体完全透明融入城市背景之中的画面令人印象相当深刻。接着还有几幕场景是为了追踪生化人骇客九世（原作为傀儡师）潜入城市狭小巷弄内，另外黑市交易与色情特种行业，这些场景都弥漫着一股幽暗的黑色电影元素，像在废墟寻找幸存者那样，被社会体制排除在外的边缘人，他们也有自己的一套生存法则。

 

原本隷属于公安九课探员的女主角为了追捕恶意操纵生化机器人的骇客罪犯来到这些龙蛇杂处的地盘，却意外发现自己的身世很可能藏着不为人知的秘密，而这一切都是坂华机械企业的阴谋，让人感觉身处于未来的高科技社会有种不安全感，来自于是否我们的政府和企业始终隐瞒了事实的真相，而我们只是商业考量下被愚民政策统治的傀儡，失去了选择的自由意志，变成了一具又一具没有灵魂的躯壳。

 

押井守版本的《攻壳机动队》Ghost in the Shell 是一部充满哲学意涵的科幻动画。它是根据日本漫画家士郎正宗于1989年首次连载的cyberpunk 漫画改编，这部漫画当中所描绘的全新世界观几乎颠覆了人类过往以来对于“生命”的看法；也为即将来临的人机介面新科技，进行预言式的心理铺垫；也影响了当年的华卓斯基兄弟（现在是变性后的华卓斯基姐妹）导演的《骇客任务》三部曲，让观影者对于虚拟网路世界产生了不同与以往的视角。

 

传统的科幻小说向来忽略科技高速发展带来的不良副作用，而 cyberpunk 的出现作为一种自我修正与补足科技发展造成的生态失衡，针对所谓的“科技伦理”起了一定的警醒作用。

 

![](../Images/78d8d9bfd68909b5968df2767b41ff94.png)

  

Cyberpunk 原本是科幻小说的分支，故事情节主要围绕着电脑骇客与人工智能在面对大型企业之间的矛盾而展开，背景通常设定在近未来的反乌托邦（anti-utopia）地球，带着颓废感并且令人恐惧的假想社会里。主角必须为了正义放手一搏，勇于挑战无良企业所代表的巨大体制，相关电影包括《银翼杀手》（Blade Runner）、《机器战警》（RoboCop）、《骇客任务》（The Matrix）、《机器公敌》（I, Robot）皆属经典之作。传统的科幻小说向来忽略科技高速发展带来的不良副作用，而 cyberpunk 的出现作为一种自我修正与补足科技发展造成的生态失衡，针对所谓的“科技伦理”起了一定的警醒作用。

 

  

**香港，死忠科幻迷朝圣地** 

  

原作漫画里的“新滨市”是以香港作为未来城市的构想蓝图。繁华的街市，五颜六色的广告看板与霓虹灯，传统菜市场、肉贩和茶餐厅，肮脏颓废的防火巷，生存要求极低的笼民……这些印象构筑了混杂着各色人种，社会失序的无国界感，带有神秘诡谲的绝望氛围，被当地居民视为落后的有机建筑与传统市集，看在创作者的眼中却是科幻电影的绝佳素材。

 

![](../Images/29dbef1358a325844f06ce19dd06d55d.png)

  

这种背景的设定原初，根源于已消逝的九龙城寨给一般人的既定印象，那是全世界有史以来人口高度密集的住宅群（根据1988年的统计在不到1.6平方公里有将近五万居民住在这里），充斥着各种地下活动帮派组织、黑市交易，而且环境异常地杂乱无序，人们却视若无睹的活着，在混乱之中却带着生猛的活力。这几乎已成为反乌托邦世界的一种缩影，而香港也理所当然成为未来城市的一种象征和隐喻，这与中环一带的高层建筑群形成强烈的对比与矛盾，让城市地景有着丰富的层次表现更增添故事的戏剧张力，对于死忠的科幻迷而言，香港已然成为粉丝必访的朝圣之地。

 

  

**生化改造与平安时代的妖怪** 

  

而押井守版本的攻壳，让**安在（anzer\_sh）**留下无法抹灭的印象主要是由川井宪次作曲，押井守亲自填词（仿自日本神道教中巫女祭祀用的古谣词）由西田和枝社唱出震撼人心的灵魂之声＜傀儡谣＞。歌词很简单，只有几句而已，却道尽了全片的神髓所在，不得不承认在川井宪次的配乐加持下，使得这部动画作品一举提升到充满灵性的境界。

 

整首歌词翻译如下“若吾起舞时，丽人亦沉醉；若吾起舞时，皓月亦鸣响，神降合婚夜，破晓虎鸫啼。远神惠赐。”究竟内容是什么意思呢？旨在祝福草薙素子（全身义体生化改造人）与傀儡师（一支拥有自我思想的AI程式）之间的结合，将产生了新的生命体。歌词最后一句也提到“虎鸫”的啼叫，意谓“异变的前兆”。生命的演化系谱可能因为生化改造和人工智能而全面改写，我很喜欢这段歌词，有一种说不出的神秘气息和安定人心的力量。

 

歌词中出现的“虎鸫”是日本平安时代盛传的一种合体妖怪，汉字写成“夜鸟”（合为一字）音同努威，是一种叫声极为悲怆的鸟，也被当作召魂鸟，如果有人灵魂出窍回不来的时候，就可以利用“虎鸫”的力量，把飘流在外四散的魂魄给召唤回来。

 

![](../Images/d9123350c78a4fe8597b3109c198f26b.png)

  

这样的时代在攻壳机动队的世界观里，早已是理所当然的存在，不容怀疑的现实，开发这样的新产品当然有风险，但对于医学上的治疗也是有前瞻性的益处，不能否认科技就是这样一体两面的东西，水能载舟，亦能覆舟，端看使用者的心态来决定。

 

  

**人脑连接互联网成真？** 

  

在传统日本的泛灵思想下，万物皆有灵，就连电脑、手机等3C消费产品和网路程式、生化机器人也是有灵魂的，所以这些人造零件组成的义体生化人以及人工智能的程式当然也可以视为有灵魂的物种，或是发生突变的妖怪，端看人们如何定义它的存在。

 

而身为义体生化人的素子，她并不想成为企业主所定义的商品或是武器，她也有自主的思想甚至情感。她希望自己是人，而不是冷冰冰的机器，所以她会做梦，会出现现实不存在的幻觉，会有记忆错置的画面，会有记忆的残存印象，这些足以证明她也是个有灵魂的生命体。所以《攻壳机动队2017》影片中的骇客九世才会对她说：“那些人（指的是执行义体人实验计划的科学家以及企业本身）并不是赋予妳生命，而是夺去妳原本所拥有的生命。”这句话成为全片破案关键所在。

 

![](../Images/790f28d61d69a6739a190311798d855a.png)

 

无巧不成书，真人版电影上映前夕，目前最具影响力的创业家Elon Musk刚好要成立一家新创公司名为“神经连结”Neuralink，以此宣告人脑与电脑融合的人机介面时代来临。这种神经纤网技术可以透过微型电极芯片，未来可植入人脑与电脑连结思想。这项科技将改变过去以来对于记忆、学习甚至梦境具现的可能性。

 

如果人脑直接与互联网相连，可供参考的大数据资料库会有怎样猛爆性的发展，实在让人既期待又忧虑。而这样的时代在攻壳机动队的世界观里，早已是理所当然的存在，不容怀疑的现实，开发这样的新产品当然有风险，但对于医学上的治疗也是有前瞻性的益处。不能否认科技就是这样一体两面的东西，水能载舟，亦能覆舟，端看使用者的心态来决定。

  

 

**押井守是预言大师？** 

  

士郎正宗所描绘的未来世界，其实更接近东方的哲学思想。比方说庄周梦蝶，如真似幻；或是庄周才是梦里的人物，而做梦的是蝴蝶。**安在（anzer\_sh）**想到科幻小说大师菲利浦‧狄克的小说《银翼杀手》原名为《生化人梦见电子羊》 Do Androids Dream of Electric Sheep？意思如出一辙。

 

又比方说，佛家所谓的万般皆空，如露亦如电，应作如是观。在虚拟与现实混同的未来世界里，真实将不复存在，不管是躯壳（Shell）或是灵魂（Ghost）都可以复制、再生，上传或下载，或进行不同载具或介面的移转。这时候，是不是真实已经不再重要，电影里的扩增实境，那些华丽无比的街景和立体成像广告，就如同镜花水月般迷惑人心，却感到虚无荒凉。那真的是人们想要的未来吗？

 

拥有自我意识的超脑（人工智能）则以一种无处不在，无远弗届，无所不能的姿态，侵入网路所构筑的宇宙，可以渗透进入特定个体，撷取资料或窜改记忆。

  

1995押井守的版本，透过更为具像化的动画，为我们勾勒出更为细致写实的未来场景，而现今的科技证明了世界正逐步朝向影片预言的方向发展，惊人的精准度让人不得不佩服创作者的睿智洞见。2004年押井守又推出剧场版续集《攻壳机动队2：Innocence》，同样获得影迷们的一致好评。剧中穿插了所谓“人形哲学观”可谓迄今以来最完整的机器人论述，也就是说，如果你了解押井守如何诠释 Ghost in the Shell 的世界，等于也了解了人类在创造机器人的所有逻辑思维以及“有机生命体”的新进化论。

 

![](../Images/c319b02ccddf1eceb3677d5d25cfce87.png)

  

仔细想想，除了旧约圣经＜创世纪＞篇章，没有人真正参与过造人的过程，但从生化人改造换装的电影开场，观众仿佛也共同参与了造人的过程。这个新生命体的演化阶段，恰好让人类用一种后设的角度去思考人类的存在与创造生命所历经的思维演变；而拥有自我意识的超脑（人工智能）则以一种无处不在，无远弗届，无所不能的姿态，侵入网路所构筑的宇宙，可以渗透进入特定个体，撷取资料或窜改记忆，这不就是傀儡师在做的事吗？

 

这时候，是不是真实已经不再重要，电影里的扩增实境，那些华丽无比的街景和立体成像广告，就如同镜花水月般迷惑人心，却感到虚无荒凉。那真的是人们想要的未来吗？

 

  

**记忆做不到的，行动可以** 

  

假使连意识／灵魂都被夺去，剩下可活动的躯壳又有什么意义呢？原本只是没有灵魂的躯壳，一旦注入有意识的电脑程式，仿佛从迷茫之中觉醒过来，这样的自由意志实在令人骇怕，又有无法预期的惊喜。在这样的设定下发展的攻壳剧情，从冰冷的机械里灌注入情感和灵魂，倒让人觉得像是解放心灵的一则未来启示录。

 

虽然主题是生化改造人和机械人，骨子里又说中了人们的内心世界，我们仰赖着工作和金钱维系的最低限度生活，不也是资本主义操纵下的人偶吗？如果没有了梦想，没有了活着的意义和目标，那不就是傀儡般的人生？如今又有方便的网路，每个人都在街角和地铁，无时无刻不在滑手机，我们被这样的数位生活制约了，是该想想如何逃离网路成瘾的控制了。

 

科技的未来，人心的未来，到头来都是同一件事。

 

《攻壳机动队》为我们作了绝佳的未来预演，而自由意志将决定一切。

 

《攻壳机动队》为观众重新定义了生命存在的价值，就像影片中复述的那句话“紧抓着记忆，不会赋予你人格，是行动告诉你是什么样的人。”**安在（anzer\_sh）**觉得这是很振奋人心的一句话，我们必须从过往的记忆中解放出来，用我们的行动去创造一个理想的未来，无论是义体生化人也好，电子脑也好，或是两者合体的新型态生命体也好，或许妖怪一直都存在人世间，只是形态随着时代演进而有所变化而已，人心之异变也是一种妖怪，选择成妖还是成魔，只在一念之间。
