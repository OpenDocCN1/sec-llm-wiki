# 缺码农吗？去监狱里找一个吧！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532457&idx=2&sn=8c5424ab35ed7bca51c8027890efd429&chksm=febc1569c9cb9c7fa86e479a558f0b3b0c960206f287640f4c34daee3e64ce441f96bade3720&scene=126&sessionid=1681310774#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532457&idx=2&sn=8c5424ab35ed7bca51c8027890efd429&chksm=febc1569c9cb9c7fa86e479a558f0b3b0c960206f287640f4c34daee3e64ce441f96bade3720&scene=126&sessionid=1681310774#rd)

您的公司缺码农吗？**安在（ID：AnZer\_SH）**给你推荐一个不可思议的地方——监狱！没错，就是你以为的那种监狱，可又有别于你以为的那种监狱！

  
![](../Images/852574ae39f52f545db7a6741c256869.png)**监狱里的“救赎训练营”**

  

在加州，除了有遍地开花的创业公司和投资机构外，还有一所古老的监狱身居角落——圣昆廷州立监狱（San Quentin State Prison）。如果你看过电影《肖申克的救赎》，一定会记得终于刑满出狱后无法被雇佣，最终无奈留下“BROOKS WAS HERE”上吊自杀的老布。The Last Mile项目就在试图帮助这些服刑人员，开拓一个全新的未来。

 

“The Last Mile” 公益计划是由旧金山风险投资家Chris Redlitz和妻子Beverly Parenti共同发起的，它是圣昆廷州立监狱的“技术孵化器”。旨在教授囚犯们计算机编程技术和创业精神，使他们能够在出狱后顺利凭借自身技能找到一份工作，降低再犯罪率。

 

在一个房间内，有18个学生正在收集每周四次的技能学习资料，他们希望某天离开监狱后通过编程能够获得六位数薪水。房间里有一个打印机，有四排课桌和翻新的电脑，穿着蓝色衣服男孩坐在那儿看着投影仪的屏幕。讲话的人是他们的导师，正在教他们从一个远程位置访问谷歌。课程的重点是学习HTML、CSS、JavaScript。

 

![](../Images/a4a1b1105e758128041a154a04e4aaa1.png)

 

通过“The Last Mile”项目，他们不仅能够学到丰富的编程知识，还有类似导师角色的人（如LinkedIn、Quora 等工程师）来分享一些和创业相关的事情，如创业灵感、BP撰写、演讲技巧以及商业模式等。此外，他们还可以使用社交网络（主要是博客和Twitter）来试水自己的想法。对于服刑人员来说，能够通过这些形式与外界进行沟通交流，并得到一定的反馈，是非常鼓舞的一件事。

 

培训结束后，还会有一个“监狱演示日”（Demo Day），将这些“CEO”聚集在一起，每人可以讲述自己的创业细节，并将这些展示给投资者们。有人想成立食物分配的初创公司，把过剩的农产品有效送入贫困社区，也有人希望解决低收入区域的肥胖问题。

 

在参与项目的人员信息，**安在（ID：AnZer\_SH）**注意到一个人，Heracio Harts，他因过失杀人在这里服刑八年。对于这个项目，他认为：这个项目改变他们的是耐心和意志，还有一种不服输的态度。在参与过程中可能会遇到那些会让普通人崩溃的事，但同时也让参与者学会耐心和专注。

 

当然，美好的东西从来都不是能够轻易获得的！该计划具有非常明显的竞争性和紧张感。参与这项计划需要经过一个申请程序，囚犯需要讲述自己过去的经历，以及对未来工作的野心和对生活的态度。随后从数百名囚犯中筛选出十几名来，向硅谷的企业家们学习商务知识。而参与学习的囚犯每周需要上4天课，每天8小时，完成全部课程需要6个月的时间。

 

联合发起人Chris Redlitz说，“在加州，我们为监狱投入的费用已经高于高等教育的投入，每名囚犯每年的平均投入成本为45000美元，所以当很多人离开圣昆汀时，我们已经投入了上千万美元。但是我们没有理由不给圣昆汀监狱的囚犯们一个机会——他们中有很多聪明异常的人，将来很有可能成为出色的编程人员，为什么我们不把就业机会留给他们呢？”

 

![](../Images/7e933093f9dd3b16f3a921a15a214a21.png)

 

![](../Images/852574ae39f52f545db7a6741c256869.png)**洗心革面的人在等待一个机会**

  

参与编程学习的人员在课程结束后，Chris Redlitz还计划与Prison Industry Authority合作，让监狱里的编程高手在愿意雇佣这些“重生”人的企业里获得真正的编程工作。就像烘培蛋糕、制造家具一样，也给懂程序的前受刑者，一个机会！

 

不过，学员们在监狱里学习编程还面临着一个巨大的障碍——监狱内禁止上网。对此，来自Google程序教学组织的Hack Reactor开始使用Google Hangouts远距教学来教导囚犯们编写程序，但这是监狱内唯一许可的对外连线。

 

对于很多入狱多年的人而言，The Last Mile让他们第一次与现代科技实现了接轨。

 

![](../Images/ff2b3a734499dbe72aae18870bbd402a.png)

 

一名叫Aly Tamboura的学员表示，正是The Last Mile给了他适应社会和市场需求的技能，让他成为现代化的一员。他说，“我因为袭击被判刑14年8个月，在我进监狱服刑之前，我有一个翻盖手机——Nextel，不过它实在不是什么特别智能的东西。”

 

对于智能手机出现前就已经入狱的人来说，电脑几乎是闻所未闻的存在。所以，对于他们而言，学习HTML课程的同时，他们还需要学习如何使用鼠标。由此可见，为期6个月的学习和教学任务将是何等繁重。

 

而他们选择培训的目的无外乎两个方面：一是在监狱里可以赚取收益；二是出狱后也可以顺利找到工作，收获光明的未来。名叫Larry Hinston的学员称，“出狱后成为一名计算机程序员是我的目标。The Last Mile使我重拾自信，并利用这些技能寻找创业机会，它给了我希望和坚持不懈的动力。”

 

因为他们始终坚信：即使曾经误入歧途，但是只要他们付出努力，就有机会挣脱牢笼，迎接光明的未来。

 

![](../Images/d8e92f4e6741313247c5630bb4c319ed.png)

 

![](../Images/852574ae39f52f545db7a6741c256869.png)**The Last Mile****传奇毕业生的故事**

  

Kenyatta Leal拥有一项别人可望不可及的能力：让硅谷高管中的精英们登门造访的能力。这实在令**安在（ID：AnZer\_SH）**惊讶不已。

 

但是，据安在收集到的信息显示：跟大多数应用开发人员不一样的是，他没有麻省理工学院或者斯坦福大学的学位，他是从圣昆廷监狱毕业的——他就是世界上第一个监狱孵化基地“The Last Mile”的第一名毕业生。

 ![](../Images/edda5e69b0dd8c6990000ae7ea82f6a0.png)

  

Leal在1994年因犯重罪和非法持有枪支被判无期徒刑，关进了加州最古老的男子监狱——圣昆廷监狱。本以为前途无“亮”的Leal却在2011年得到了一条出路——The Last Mile提供的编程课程。

 

参与这项计划需要经过一个申请程序，囚犯需要讲述自己过去的经历，对未来工作的野心和对生活的态度。200 位囚犯中，Leal同其他 13 名囚犯被筛选出来，向硅谷的企业家们学习商务知识。值得一提的是，说唱歌手MC Hammer担任了他的导师。

 

在培训过程中，这些筛选出来的学员每星期都需要与企业家和社区领导进行两次会面和若干反馈课。这些企业家和社区领导被这些囚犯称为“The Shark Tank”。

 

而这些被称之为“雇员”的囚犯则使用旧金山编程学校Hack Reactor研发的特殊编码指令学习编程。

 

每隔四周，他们还要争取获得“每月明星雇员”的称号。六个月课程结束后的“展示日”上，他们还需要向潜在投资者阐述自己的创业理念，争取获取创业基金。

 

Leal在狱中开发了一款名为“沙发土豆”（Coach Potato）的梦幻橄榄球实况转播软件，成为了班里的明星学员，并获得了工商管理学学位。2013年，Leal假释出狱，并通过自身努力找到了一份教授网络服务课程的工作。而在本职工作外，他还一直在尝试说服更多投资者来支持这种前所未有的罪犯改造方法。

  

后来，Leal在接受记者采访时说道：“能够在监狱中学习编程真的非常幸运。入狱后，我完全失去了自我，混沌度日，直到我了解到了网络。我的家人开始用智能手机联系我，我对网络知识的渴望也越来越多，我开始好奇什么是推特，什么是谷歌。虽然身陷囹圄，但我们需要一个机会重新来过。”

  

与Leal一样，Chris Schuhmacher（因朋友从其公寓偷走一箱大麻将朋友刺死而被判无期徒刑）也是The Last Mile项目中的一名明星学员。他在狱中完成了佩丁大学专科课程，且开发了一款健身应用。

 

另一名毕业生Horatio Herts正向匹兹堡向州议员提出名为“健康心脏基金会”的商业计划。该基金会专注于帮助超重的美国人恢复原来的身材。

 

还有一名叫James Houston的学员创立了一套向贫困的城市孩子教授科技知识的课程。

 

Leal表示：监狱里犯人有创业精神，但是用错了地方。如果你在监狱里重新开始，你将能在监狱外重新生活。我曾经感觉我被排斥在一切之外，需要一个方法重新开始。

 

![](../Images/852574ae39f52f545db7a6741c256869.png)**意义非凡的伟大事业**

  

据**安在（ID：AnZer\_SH）**了解，加州囚犯出狱后在一年内的重犯率是67.5%，是美国各州中最高的。而每个囚犯每年平均要消耗5万美元成本。The Last Mile创始人和教学团队坚信，随着项目的进行，即使将重犯几率每年减少5%，他们也是在慢慢的拯救整个加州。

 

除了降低犯罪率外，该项目还帮助众多“重生／救赎者”找到了合适的出路，避免《肖申克的救赎》中老布的悲剧重演。因为，与中国一样，美国的就业市场也十分紧张，而雇主们对计算机知识也有了更高的要求。如果没有接受该项目的重塑，这些从来没有见过电脑的刑满释放人员将无缘跟科技相关的工作。

 

不知道中国何时会出现这种造福深远的公益项目？如果出现，你愿意给他们一次救赎的机会吗？
