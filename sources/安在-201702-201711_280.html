什么是腾讯安全探索论坛（TSec）？


它聚焦云安全、移动安全、物联网安全以及人工智能等多领域安全技术的高质量技术论坛，是中国互联网安全领袖峰会 CSS2017（Cyber Security Summit 2017）的重要组成部分，也是本届CSS最具技术含量与亮点的论坛。

 关于 CSS 您还可以了解更多

中国互联网安全领袖峰会（Cyber Security Summit，简称“CSS”是由腾讯公司、中国电子技术标准化研究院等企事业单位共同创办，得到了国家网信办、工信部、公安部等国家部门的大力支持和指导。


峰会始终致力于聚合互联网产业领域与网络安全行业的力量，共筑“互联网产业安全交流与合作平台”，共建“互联网安全新生态”，进而推进产业快速、稳定创新，为国民经济的升级转型和蓬勃发展做出贡献。


中国互联网安全领袖峰会于 2015 年首届举办以来，两年来共吸引来自互联网金融、智能汽车、物联网、智能硬件等多个热门产业领域的顶尖参与企业 500 余家，是全球规模最大、价值最高的互联网产业安全交流与合作盛会。


CSS2017 将延续“安全新秩序、连接新机遇”主题，围绕金融安全、数据与云安全、人工智能、安全新技术趋势、安全法制与伦理、智能制造与基础设施安全等议题展开。
