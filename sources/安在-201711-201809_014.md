# ISC大会周鸿祎：为百分之一的可能尽百分之百的努力

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532885&idx=2&sn=2d27320ee1c18c81df0f4af1ad4e5b21&chksm=febc2b95c9cba283bc10130a6e2f10da15edcd74fe1ec1e3e456b324e429ec194f2368e361d8&scene=126&sessionid=1681310730#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532885&idx=2&sn=2d27320ee1c18c81df0f4af1ad4e5b21&chksm=febc2b95c9cba283bc10130a6e2f10da15edcd74fe1ec1e3e456b324e429ec194f2368e361d8&scene=126&sessionid=1681310730#rd)

2018年9月4日， **ISC互联网安全大会**（原“中国互联网安全大会”）在北京国家会议中心隆重开幕。

![](../Images/ff8092871bd87fc8eade42dd0c1012d2.png)2018 ISC互联网安全大会  

在嘉宾致辞阶段，有着“红衣教主”之称的360创始人、董事长&CEO周鸿祎也发表演讲，果不其然，上身依旧是穿着一件红色的T恤，不愧是“红衣教主”。周鸿祎素有“段子手”的称号，每次一出场便是焦点。

果然，周鸿祎会上说，360将推出辣椒水，为广大女性同胞保驾护航，并表示，“辣椒水一喷，立马让对方丧失一切行动能力。”至于什么时候推出辣椒水尚未确定。  

![](../Images/ba17d4ccc2c8645675f6e97439abf630.png)360创始人、董事长&CEO周鸿祎

在安全方面，周鸿祎表示，安全保护的对象不仅仅是几亿台电脑和十几亿的手机，还有大量联网的智能安全设备、智能汽车。随着技术的发展，安全已经成为一个整体，是一个多层次的结构；也许某一个网站被突破，最终却造成大面积的网络安全问题，而安全防御却依旧停留在局部，各自为战。

当下网络安全的危害，已经扩展到国家安全、政治安全、国防安全、关键基础设施安全、社会安全、金融安全、个人安全以至于人身安全。网络安全从信息安全时代进入了大安全时代。对此，360提出“安全大脑”的概念。“大安全时代，网络安全需要一个整体的作战思维，需要一个全局的观察，从技术上来说，就是‘安全大脑’。”

简单来说，所谓360“安全大脑”，是通过数以亿计的传感器持续采集最全最新的安全大数据。然后把这些浩如烟海的数据源源不断地传输到安全大脑的云端，进行存储和计算，并利用大数据和人工智能技术实现对网络威胁的自动化、智能化响应和处置。

会后采访中，周鸿祎表示，一个病毒可以潜伏数年，而想要从浩如烟海的数据中寻找蛛丝马迹的信息，必须依靠有着人工智能和大数据分析技术的安全大脑，从细微处发现潜在的安全威胁。

周鸿祎说，只要有百分之一的可能，我们就要尽百分一百的努力；因为对于出事情的那百分之一的人而言，那就是百分之百的灾难。

360企业安全集团董事长、互联网安全大会联席主席齐向东在演讲中表示，网络安全行业一定会诞生巨头公司。

![](../Images/38614af82090eb1f9cc8f441e3e7cdc1.png)360企业安全集团董事长、互联网安全大会联席主席齐向东

近段时间以来，一系列网络安全事件表明，企业防护系统、隔离网和最强安全部门的防护都失灵了，这说明，随着信息化架构的巨变，安全技术已经落伍。演讲中，齐向东围绕理念、技术、方法和体系总结了网络安全的四个“新”，即新战力、新战具、新战法和新战术。

一是提升新战力，用数据驱动安全大脑，用安全大脑驱动安全构建多级网络安全监测平台，形成新体系；二是研究新战具，以数据安全为主要场景，依托安全大脑，发展第三代“查行为”的网络安全新技术；三是锤炼新战法，围绕“人是安全的尺度”，形成人+安全大脑协同运营的新方法；四是磨炼新战术，建立高位、中位和低位的“三位能力”立体联动的一体化管理体系。

当前，世界各国都高度重视网络安全，不论是从国家安全、发展战略和法制法规的强制性要求还是从技术革命本身来看，网络安全产业都具备了发展的高动能。以人工智能、大数据、物联网等新技术为代表的第四次工业革命，正催生出巨大生产力，网络将被彻底打开，传统边界属性改变，传统的IT安全架构已经跟不上时代发展，我们需要重新审视新时代、新形势下的安全产业。

从历史上看，**每一次工业革命爆发之后，都带来了长周期的高速增长，现在第四次工业革命刚刚起步，风口行业至少将保持几十年的高速增长。因此，未来一定是创新爆炸的时代，谁能抓住机会，谁就能成为行业巨头。**

ISC互联网安全大会是在中央网信办、工业和信息化部、公安部、国家密码管理局的指导下，由中国互联网协会、中国网络空间安全协会、中国密码学会、中国友谊促进会、360互联网安全中心共同主办的世界级网络安全会议。

自2013年首次举办至今已成功举办五届，成为亚太地区规格最高、规模最大、影响力最为深远的安全盛会。会议现场，来自全球的顶级安全战略智库、安全行业领袖、学术专家、高科技企业领袖、全球知名黑客等将齐聚一堂，从战略、产业和技术创新角度，全面深入探讨数字化转型时代的网络安全挑战与应对。

如今，ISC互联网安全大会已经成为行业的风向标。
