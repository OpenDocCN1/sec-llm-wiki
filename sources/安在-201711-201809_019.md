陈勤伟的网名是“勤大树”。2014年11月，“勤大树”从传统银行离开，选择加入上海首家民营银行。那时正好是银行的筹备期，核心系统和数据中心都还在建设中，安全体系更是一片空白，没有人员、没有制度流程、没有系统设备，绝对的一张白纸、“三无”状态。

  

![](../Images/a032b432d0fe6400fc643824357a0eb1.png)

  

从2014年加入民营银行到去年第一个三年战略规划结束，“勤大树”在这三年的时间里组建了银行的安全团队，完成了传统银行等级保护制度、数据中心的安全基线以及行内安全标准的搭建，把从物理安全、网络安全到数据安全、应用安全这一系列传统银行的安全体系逐步规范落地。

  

同时，为应对银行互联网业务的同步发展，在借鉴同业最佳实践搭建传统银行安全体系的同时，创新性的探索建立了具有鲜明特色的“十八罗汉”移动安全体系建设，在移动端上率先整合了较为领先的 “一机一密”、人脸识别、智能反欺诈、动态安全策略等最新技术，连续两年获得银监会信息科技风险课题奖。

[**03.FreeBuf：PhishPoint网络钓鱼攻击：一种绕过Microsoft Office 365保护的新技术**](http://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651070804&idx=1&sn=ec26d2c4f5fa73a34c758b889fa70032&chksm=bd1fb3df8a683ac99ad927188ebb17b0e4c37fb0aaec0ef4cab2ccb0eb058c530b0ca9fbbde4&scene=21#wechat_redirect)

  

**![](../Images/84635f29f1bb49d03c8d16c8a8a0594a.png)**

  

近期，来自云安全公司Avanan的安全研究专家发现了一种名叫PhishPoint的新型攻击技术，而这种攻击技术将允许攻击者绕过Microsoft Office365的保护机制。

  

PhishPoint是一种新型的SharePoint钓鱼攻击，在过去的两周内，大约有10%的Office 365用户受到了这种攻击的影响。安全专家警告称，已经有很多网络诈骗份子开始使用这种新型的攻击技术来绕过目前大多数电子邮件服务商所部署的高级威胁保护（ATP）机制了，其中受影响的就包括Microsoft Office 365在内。

  

  

![](../Images/7ad5c1081681b59f0cded7b10d24a866.png)

  

在PhishPoint的攻击场景中，目标用户会受到一份包含指向SharePoint文档链接的电子邮件，文件中的消息内容跟标准的SharePoint邀请合作函是完全一样的。

  

当用户点击了伪造邀请函中的超链接之后，浏览器将会自动打开一份SharePoint文件。这个SharePoint文件的内容会伪装成一种标准的OneDrive文件访问请求，其中会包含一条“访问文档”超链接，而这个超链接实际上是一条恶意URL，它会将用户重定向到一个伪造的Office 365登录页面。

  

专家表示，如果邮件的主题行中有类似“URGENT”（紧急）或“ACTION REQUIRED”（待办公事）等字样的内容，请一定要小心，并在确定了邮件来源之后再点击访问。

  

[**04.中国信息安全：安络科技CEO谢朝霞：服务国家需要是创新的动力**](https://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664113377&idx=1&sn=d2f82d9a1ad34778bc8feb152e4c39fe&scene=21#wechat_redirect)

  

![](../Images/1b8e7f060e12690eff6a7b5c17a9ee25.png)

  

1999年，谢朝霞创建安络科技，并成为首次在Bugtraq上发布漏洞发现成果的国内第一个人；2017年9月，创建广东安络司法鉴定所。谢朝霞曾获得“十八大网络安保红盾专项工作先进个人”、首届“CISP十大杰出人物”和“2017年度刑事侦查工作特别奉献奖”等多项奖励。

  

![](../Images/47412475c1a934109d5b45b72ab658cc.png)

  

谢朝霞认为，通过协助国家政法部门打击网络犯罪，履行社会责任，服务国家需要，为安络科技带来了明显的品牌效益，也有助于提高员工的责任感、荣誉感。

  

安络科技公司刚成立时，主要关注计算机安全，后来逐渐涉及维护国家关键基础设施和大中型企业的网络安全。从2016年开始，安络科技在打击网络犯罪这一领域的尝试和成果，使其更广泛地参与到维护社会稳定和国家安全的事业中。一路走来，安络科技业务的变革和递进都是围绕国家和社会的需求。

  

虽然在目前科技与网络犯罪的博弈中，安全技术并未占“上风”，但是依托技术进步对抗网络犯罪，永远是不可或缺的选择。这几年安络科技之所以成功实现业务转型，也是因为谢朝霞和他的团队服务国家、创新发展的两个“初心”。

  

[**05.E安全：五角大楼：中国自认网络作战功能滞后于美国**](https://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655300047&idx=1&sn=626576a7b84a4acd84076f6bcc755de8&scene=21#wechat_redirect)

  

![](../Images/9f0f8af282985ba3256419c410f64dcf.png)

  

据美国国防部透露，中国认为自己的网络作战能力滞后于美国，正在不懈地缩小差距。

  

![](../Images/ededbc9b9096d06956a9996136d5cbf8.png)

  

在五角大楼向国会出具的年度报告中，五角大楼对中国人民解放军的作战能力进行了描述，并警告称，中国一直尝试着对全球的各个组织发动网络攻击，其中就包括美国。

  

据五角大楼透露，中国军队有着战时网络行动及和平时期网络行动的区分。前者主要是帮助中国人民解放军了解敌方的作战动向，作战计划并确保战场的胜利。而在和平时期，其主要任务是保护网络空间的安全和电磁安全。

  

报告称，2017年，中国境内的网络攻击者一直针对全球计算机实施攻击，目标包括属于美国国防部的系统和其他美国政府机构，重点在于入侵网络和提取信息。

  

[**06.看雪学院：好玩不贵的无线遥控器克隆指南**](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458291677&idx=1&sn=b59dbb8158576cad8998c534fa07976e&chksm=b181bd5786f634412e89bd8323758f9bfd36ce9412a84148954297c24f54065d280ba75703c3&scene=21#wechat_redirect)

![](../Images/faf1ea27f98833496f582fde89a9672c.png)

  

怎么样克隆一个无线遥控器呢，具体步骤分为以下三步。

  

翻芯片手册理解信号编码方式。以芯片型号eV1527为例，同步信号有1个高电平，3个低电平；数据H有3个高电平，1个低电平；数据L有1个高电平，3个低电平；一条指令数据的构成由同步信号、C0~C19（一般是设备唯一码）、再加四个数据（不同数据组合对应不同指令）构成。

  

![](../Images/cd8bb29138ca3abbcc82aadfce97428a.png)

  

第二，采集无线信号进行分析。硬件：315M接收模块、逻辑分析仪、供电模块；软件：Logic 1.2.18。设置采样率为2M，一边按无线钥匙，一边采集，采集了有10s的数据。放大后可知指令数据是HLLLHLLLLHLHLHHHHHHHLHLL，刨去C0~C19，真正的指令其实就是LHLL，换一个按键采集信号，你会发现指令数据只有最后四位发生变化。

  

第三，模拟无线信号。硬件：315M发射模块、控制板。其实是给315M发射模块高低电平信号，保障电平周期和上面采集到的电平周期一致。比如说，在模拟同步信号的时候，你要先给315M发射模块0.321ms的高电平，再给10.38ms的低电平。 这样，你就get了如何以最低成本克隆无线遥控器。

  

[**07.网安视界：AE50网络安全产学研合作协同育人联席会，国家网安基地培训中心成为首批成员单位**](https://mp.weixin.qq.com/s?__biz=MzI4MTM5NDMwOQ==&mid=2247489941&idx=1&sn=afc8eb27685091146ad976cfaf6e1518&scene=21#wechat_redirect)

8月28日，AE50产学研合作协同育人联席会发布仪式在CSS2018 AE50安全产学研论坛举行，旨在打造一个公益组织和开放平台，以搭建中国信息安全人才培养体系，促进科研成果的产业转化和提高网络空间安全学科建设专业水平。国家网络安全人才与创新基地培训中心成为AE50联席会首批成员单位。

  

![](../Images/cc0772140ede06a661d9a30facb54709.png)

  

作为国内产学研人才培养高端公益平台——AE50产学研合作协同育人联席会（以下简称“联席会”），是由教育部高等学校网络安全教育指导委员会指导，腾讯科技，绿盟科技、国家网络安全人才与创新基地共同发起的公益组织。

  

据悉，联席会成立之后，将围绕人才培养、科研成果转化、产业协作、基地建设、师资培训、课程开发、培训认证、信安竞赛、就业创业、学术交流、技术推广等内容进行深入交流合作，致力于推动产业的全面升级，力求搭建中国领先的网络信息安全人才培养体系，推动科研成果的转化以及网络安全水平的提升。

  

**08.游侠安全网：一起来听云鼎实验室讲师聊 DDoS 攻防**

**http://www.youxia.org/2018/08/40930.html**

  

![](../Images/f8799e5d5bc45930a79b956031bf152e.png)

  

CSS 第二天的云安全分论坛上，腾讯安全云鼎实验室威胁情报研究员宋兵为我们带来了他的分享——2018 DDoS 新趋势。宋兵认为，DDoS 已经由分工明确的长链条黑产方式向自动化、平台化、高度的集成化转变，攻击平台的下单自动化和攻击自动化让企业防不胜防。

  

![](../Images/13402f6c6d09cebb2d95fc85d9d32f84.png)

  

DDoS 攻击流量峰值每年都不断地被超越，今年上半年的一起 Memcached DDoS 攻击，其峰值1.7 Tbps 达到了一个新的高度。

  

宋兵在演讲中表示，随着各行各业的互联网化，DDoS 的攻击面也越来越多。游戏行业因其日流水量最大、变现快，一直站在利益的风口浪尖上，当仁不让地成为 DDoS 首选的攻击目标。

  

讲到关键的 DDoS 黑产部分，宋兵提到传统攻击有7个环节，而当前最新的页端攻击则方便得多。主或者攻击手到相关网站进行注册，购买 DDoS 服务直接搞定，剩下的都会通过自动化的 API 去实现，200-500块钱就能打出一个很大的流量攻击。

  

最关键的是，页端 DDoS 攻击网站通过发卡平台把信任环节真正地建立了起来。据宋兵的介绍，发卡平台不光 DDoS 在用，很多其他黑灰色的产业也在用。
