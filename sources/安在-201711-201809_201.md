# 面对Android P更懂你的AI，我们在害怕什么？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532776&idx=3&sn=c8e135e0b47bed4107d0516d3b97caf9&chksm=febc2a28c9cba33ef2195bac468e03a9a8e16d69f98194f61a264fc68522ed69f10977497665&scene=126&sessionid=1681310741#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532776&idx=3&sn=c8e135e0b47bed4107d0516d3b97caf9&chksm=febc2a28c9cba33ef2195bac468e03a9a8e16d69f98194f61a264fc68522ed69f10977497665&scene=126&sessionid=1681310741#rd)

众所周知，比起苹果iOS系统的封闭统一、运行流畅，Android系统碎片化导致手机的卡顿发热，一直是谷歌以及众多手机厂商的一个莫大心病。

  

![](../Images/1829764be9e0e4c94ebb0de009eb9cff.png)

  

**安在君（AnZer\_SH）**也一直默默关注着Android系统的版本衍进与功能更新，而这些年谷歌也不负众望，Android系统功能越发完备，流畅也逐渐提升。

  

今年3月，Android系统最新版本Android P发布； 5月，困扰安卓多年的一个隐私缺陷问题，终于在Android P上得到修复。

  

根据XDA Developers报道，Android存在一个可以完全访问设备上的网络活动，并且不需要询问任何敏感权限的漏洞，这样系统将无法检测应用程序是否通过特定的网络连接上传手机数据。

  

对此，安在君（AnZer\_SH）感到十分欣慰，因为安在君（AnZer\_SH）是Android系统忠实的粉丝，苹果iOS与其他系统的数据不互通，一直是安在君（AnZer\_SH）的心头怨念。

  

![](../Images/2b611dbc61a95c63462b8aa18a022bc7.png)

  

**安在君（AnZer\_SH）**在欣悦同时，又有一个新发现：Android P除了更多全新人性化的特性之外，还全方位加入了 AI，推出多项AI相关功能。

  

据称，深度融入整个系统的 AI，让Android P成为十年来变化最大的系统，也反映出谷歌变革的决心。

  

是的，**安在君（AnZer\_SH）**所担心的，正是AI功能在系统层面的落地，也有可能引发新的隐私问题。

  

Android P知道你时刻在用手机做什么

  

这个问题简单来说，就是安装了Android P系统的手机，知道你使用手机时，哪些时间在做什么，并预测下一步要做什么。

  

手机对你全方位立体式的记录，惊不惊喜，意不意外，可不可怕！

  

![](../Images/c638d0d7df9e162c667bc0f0ece6adac.png)

  

Android P加入了一项名为“自适应电池技术”的大型更新，它使用谷歌DeepMind AI来查明用户开放的APP，以及一天中哪些时间在使用。

  

此项功能，通过不断学习用户的使用习惯，能够推断出他们未来几个小时内会用的APP及电量消耗。

  

最终，能够让系统掌握用户使用APP的习惯，且可自动调节电池使用量。

  

与此同时，Android P加入APP Action和Slice功能，让APP内容可更快显示在手机画面上。

  

其中，Action是一种“捷径”，目的是为了减少用户的操作动作。

  

而Slice则是Google Assistant（谷歌语音助手）的延伸，能让用户快速使用APP里的某个特定功能。

  

![](../Images/f2d77cae185c58b19ab1c7620a5042fd.png)

  

比如，在搜寻列中搜寻嘀嘀打车，过往系统只是帮用户找到嘀嘀打车APP并打开。

  

而现在，则能在搜寻列下方出现用户可能需要的资讯，如叫车回家、时间、车资等，点一下即可选择需要的服务。

  

此外，Android P连屏幕亮度调节都交给了AI。

  

当用户在夜晚看手机时习惯将亮度调到10%，那么AI将会记住，并在夜间自动保持10%的亮度。

  

即运行Android P的手机，不用光线传感器就能完成亮度调节。

  

谷歌想要通过Action和Slice让APP和操作行为更紧密结合、操作更简单。

  

谷歌Android工程副总裁Dave Burke表示，借助全新的“应用操作”功能，用户的手机会建议他们采取下一步行动。

  

换句话说，Android P已经“知道”用户如何使用手机，并给出了自己的预测和建议。

  

我们正把隐私交给越来越聪明的Android

  

通过对上述功能的描述，我们知道Android P通过AI变得越来越聪明。

  

让**安在君（AnZer\_SH）**感到不安的是，Android P的更加聪明是建立在记录用户越来越多的隐私和使用习惯的基础上。

  

虽然在谷歌I/O 2018大会上，谷歌曾表示Android P将限制网络活动监视权限。

  

但面对更懂、更会记录用户隐私和使用习惯的Android P，当一个冰冷的手机，时刻在预知着你即将做什么，当你不知道手机记录的各种隐私，会不会有意无意泄露的时候，你会可能觉得像活在一个无形的监视中，宛若《黑客帝国》设想的那样。

  

在I/O大会的现场演示中，谷歌语音助手展示了如何智能化地拨打当地美发沙龙以安排预约。

  

首先，用户要求谷歌语音助手进行发号预约，以便后者拨打电话，而谷歌语音助手的声音，居然听起来就像是真实的女性。

  

![](../Images/2b73cd64c117956c39feab34e221334e.png)

  

随后，谷歌语音助手可计算合适的时间和日期，最后它向用户发送通知，告诉他们完成了预约。

  

当时现场就有人感叹，对这个展示突然生出一些“恐惧感”，因为以后可能无法分辨是不是在跟机器人对话。因为Android P谷歌语音助手，更像是全局操控用户信息的“幕后者”。

  

![](../Images/fc34b8b3866116629fa5d2d3efb71fc2.png)

  

可以说，Android不仅正在像人一样思考，还是像“聪明人”那样思考。

  

忽略隐私的你究竟害怕什么

  

当下，AI成了一个炙手可热的词，尤其是科技类产品，不与AI沾点边，不玩转AI，似乎就没有吸引用户的噱头，也似乎就不高级，不先进，跟不上时代。

  

比如，从Android P到iOS，再到众多手机厂商的深度定制系统，都以加入AI功能为荣。

  

**安在君（AnZer\_SH）**同样担忧，手机变得越来越“主动”，用户会不会更加沉迷于手机，让“手机上瘾症”更加严重？

  

更为担忧的是，手机AI功能愈发强大，就意味着它们对用户隐私和使用习惯的记录、收集也会更强。忽略隐私的用户又该靠什么保护自己？

  

纯粹靠监管、靠隐私条例？显然不够。

  

靠商业良心、行业自律？安在君（AnZer\_SH）早已对此嗤之以鼻。

  

事实上，在智能科技爆发的当下，绝对隐私已经不存在，这是移动互联网时代发展到一定高度后的必然弊端。

  

除非你生活在深山老林里，摒弃一切现代化生活工具，过着与世隔绝的生活。

  

![](../Images/e95c81c84ebf801baa2fff94a87de5f5.png)

  

显然，人是社会性的动物，几乎没有人能够做到。

  

伟大的古希腊哲学家亚里士多德，早在公元前300多年就曾说过：“人的本质上是社会性动物。哪些生来就缺乏社会性的个体，要么是低级动物，要么就是超人。社会实际上是先于个体而存在的。不能在社会中生活的个体，或者是因为自我满足而无法参与社会活动的个体，不是野兽就是上帝。”

  

我们不是野兽，也不是上帝，我们人类创造了科技文明，我们也要享受科技文明。

  

所以，我们只好期待隐私被束缚在一个限定的范围。

  

比如手机，虽说手机记录着你一切隐私，但是，只要这个手机掌握在我们自己手心，手机无法主动散播你的隐私，就算别人捡获或窃取你的手机，也无法从中获得半点隐私，那我们才稍稍安心。

  

又或许，我们担忧的并不是手机真会泄露隐私，而是害怕一个手机，害怕一个冰冷的没有血肉的机器，比你还了解你自己。

  

当然，这还不是最可怕的，更可怕的是，你男/女朋友或对象的手机，比你更了解他/她，你们吵架的时候，他/她会不会来一句：要你何用，你还不如我手机了解我。

  

那就尴尬了！

  

![](../Images/63ec8006d861bfd5e42ff8644d83ad7f.png)

  

另外，这图上的鸡汤也可以改了：“每个人都有一个死角，自己走不出来，别人也闯不进去。我把最深沉的秘密放在那里，你不懂我，我不怪你。因为手机窃走的秘密，它更懂我。”

  

手机广告词也可以说：“XX手机，心灵死角的清洁器，它更懂你！”

  

以上，博君一笑尔。

  

关于隐私保护，我们还有很长的路要走，这远非安在君（AnZer\_SH）一个美好的期愿，或者简单的设想，就能达到。

  

愿诸君群策群力。
