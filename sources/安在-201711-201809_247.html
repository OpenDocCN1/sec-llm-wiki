Facebook之后，又一家大数据公司数据泄露

近日，大数据又出现了问题，一家名为Local Blox的公司被曝出信息泄露问题，这是Facebook数据泄露事件后又一次大规模数据泄露事件。



事情是这样的。


美国一家号称数据泄露猎手的公司Up guard发现Local Blox在网上暴露了一个不安全的在线AWS库。4月18日，Up guard发布报告指出，美国数据技术公司 Local Blox 收集社交网站的用户数据，分析后进行出售，但由于该公司亚马逊 AWS S3 存储库可公开访问，致4800万个人数据暴露在网上。


最令人惊讶的是，这些信息的可信度非常高，而且都是用户的隐私信息。


泄露的数据涉及：姓名、地址、出生日期、 LinkedIn 工作经历、公开的 Facebook 数据、Twitter 用户名和美国房地产网站 Zillow 的信息。这些信息其中一部分是来自Facebook，LinkedIn和Twitter等。


Facebook数据泄露事件后，各个社交媒体对于用户信息都捂得蛮严实，唯恐自己平台被曝出数据泄露事件后被叫去美国国会听证。此次Local Blox在网上曝光用户信息后，Facebook、Twitter、LinkedIn 和 Zillow 立马跳出来表示，Local Blox 未经用户许可收集了这些数据，这种做法违反了它们的条款。


这明显是被Facebook事件给吓着了，再有这样的事情先把自己撇干净再说。不过，Local Blox也不会傻乎乎的背下所有的锅。


Local Blox 创始人兼首席技术官阿什法克·拉赫曼表示，4800万这个数值被夸大了，因为该数据集中包含用于测试的虚假数据。


出了这样的事情，Local Blox也怂了。不过按照Local Blox 以前在网站上的吹牛，这么点量似乎很有可能。Local Blox曾经宣传自己拥有选民数据库包含1.8亿条记录，而汽车数据库包含4.4亿条数据。


另有4亿条用户邮箱地址以及其它类型的记录，且能自动从网络和交换网络收集、发现、提取并整合数据，帮助企业获取并利用网络上的大量信息。这些“精准”的分析还能知道一个人是否拥有信用卡以及他的“拒接来电”偏好、婚姻状况和净资产。


然而，Local Blox数据泄露早已被Up Guard发现并进行调查。2018年2月18日，Up Guard 网络威胁小组发现这个包含1.2TB(解压前为151.3 GB)数据的亚马逊 AWS S3 存储桶。十天后，Up Guard 通知了 Local Blox，不久之后该存储桶得以安全保护。


Up Guard 通过分析发现，Local Blox 利用复杂的方式将不同来源的数据进行整合，从而生成详细的个人资料。Up Guard 写到，Local Blox 似乎会追踪用户 IP 地址、将收集的数据与该 IP 地址进行匹配，从而呈现该 IP 地址对应用户的行为和背景。


UpGuard 指出，由于存在数据收集、处理和转售这样的商业利益，世界上存在如此大规模的入侵型数据集，这不足为奇。然而这些 LocalBlox 分析公司赖以生存的数据，竟然未得到应有的保护，公开暴露，由此可见大数据安全性问题亟待解决。


谁掌握着大数据，谁就掌握着未来的财富。随着大数据应用领域越来越广泛，作用越来越大，已逐渐成为生产要素之一。不论是今日头条的算法推送还是淘宝的只能推荐亦或是网页弹窗广告，大数据一直是其中的基础，其中的价值不言而喻。


大数据的重要性企业早已清楚，但随之而来的是大数据带给用户的风险，毕竟谁也不希望自己的信息会在网上被公开买卖。目前，经研究人员通报后，LocalBlox已于当天将数据库加上密码保护，但暂时未对此发表声明。
