# 赛宁网安竞赛平台同步完美支持XCTF联赛欧洲站两场赛事！

**![](../Images/b21a11e2ad2565a8c58f778852122c70.png)**

  

4月9日-13日，XCTF联赛再度携手HITBSecConf 2018精诚合作，首次在欧洲落地XCTF分站赛事！本站赛事在古丝绸之路的终点城市荷兰阿姆斯特丹举办，同期举办了线下赛及线上赛两场比赛，两场比赛均由赛宁网安“CP-AD网络安全攻防实战竞赛平台”提供支持！

  

![](../Images/61d4a7809f99a22c33997e70eb5f9300.png)

赛宁网安平台远赴欧洲，线下赛KITCTF战队成功卫冕！

  

本次大赛的线下赛事，来自8个国家的24支战队齐聚阿姆斯特丹竞技比拼，中国的Nu1L战队与荷兰HITB NL战队联合出题，经过两天共16小时的比拼，最终来自德国的KITCTF战队成功卫冕，中国战队JD-3kaPig位列第六名，**赛宁网安受邀为本次线下赛的提供平台支持，赴欧洲展示实力。**

  

![](../Images/b01975c87f56e01bdf549cf4557d4881.png)

KITCTF战队卫冕冠军

  

线上赛事全球战队争锋，日本战队TokyoWesterns夺冠！

  

同期举办的HITB-XCTF GSEC CTF 2018线上赛也于荷兰当地时间4月11日14点开赛，北京时间4月13日晚21点落下帷幕，持续48小时的比赛，采用解题的形式，特邀第三届XCTF联赛总决赛冠军战队FlappyPig担任出题，京东安全为线上赛事提供赞助支持。

  

![](../Images/a2ffabf8ea669e9b9ceb92dbcd5233c3.png)

线上赛最终排行榜

  

线上赛共吸引了来自142个国家和地区的425战队参与，344支战队得到分数。最终，来自日本的TokyoWesterns战队逆袭韩国CyKor战队夺得第一，中国台湾战队Balsn后来居上名列第二，长时间领跑的韩国Cykor战队最后阶段被超越排名第三，中国大陆的天枢战队、Eur3ka战队、ROIS战队排名均入围前十五。根据比赛规则，排名前十五的战队将受邀入围HITB-XCTF GSEC CTF 2018线下赛（8月30-31日于新加坡），最终入围战队信息XCTF联赛将在审核后发布。

  

下一场赛事\*CTF4月21日开启，MMSRC鼎力支持！

  

由复旦大学\*\*\*\*\*\*战队主办，赛宁网安提供技术支持，陌陌安全应急响应中心赞助支持的\*CTF国际赛（以下简称\*CTF）将于4月21日早9点正式打响，作为第四届XCTF联赛的分站选拔赛之一，本次比赛将持续48小时，面向全球战队开放。

  

陌陌安全应急响应中心（MMSRC ）赞助支持本场赛事奖金翻倍，MMSRC作为第四届XCTF联赛的金牌赞助商，高度认可 CTF 赛事在选拔和培养安全人才上的重要作用，也期待能通过赞助本届 XCTF 联赛，更进一步与安全社区建立联系，吸引更多志同道合的安全人才，在互联网安全发展之路上共同成长前行。
