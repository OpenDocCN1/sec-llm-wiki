# 恐吓后续：苹果确认员工入侵用户iCloud

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532705&idx=2&sn=ea837fb37763c759aab5a5df5849cc8a&chksm=febc2a61c9cba37792f4899d345f7af17f0230cf35bcb2b57da2175c861021014767f749a7d4&scene=126&sessionid=1681310747#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532705&idx=2&sn=ea837fb37763c759aab5a5df5849cc8a&chksm=febc2a61c9cba37792f4899d345f7af17f0230cf35bcb2b57da2175c861021014767f749a7d4&scene=126&sessionid=1681310747#rd)

3月5日晚间，一名叫做“美国往事1999”的用户在微博发文，直指苹果公司中国地区客服公报私仇，入侵iCloud并对自己进行了恐吓威胁。

  

![](../Images/f798e9bc2e0a34f418358cdf5b2a9a1b.png)

  

微博文章详细地说明了该用户与苹果客服发生口角的原因，并上传了苹果客服私下与自己的电话聊天录音，同时公开多张自己邮箱的图片，来证明已经遭遇苹果客服的入侵和威胁。

 

多家媒体曾对此事进行了报道，但由于“美国往事1999”以保护自身信息安全为由，始终未提供当时与这名客服的服务编号，所以事件的真实性一直有待考证。

 

不过就在3月8日下午，针对这一事件，**苹果公司向新浪科技发送了声明，确认了此次事件的发生，并表示将会帮助“美国往事1999”一同进行调查。**

 

以下是苹果公司声明原文

  

我们非常尊重顾客赋予我们的信任，将保护个人隐私和信息安全托付给Apple。捍卫用户的隐私是我们系统设计的出发点，任何一个AppleCare技术顾问均无法访问顾客的密码、电子邮件内容和照片等。我们将与这名顾客一起对该事件进行调查，并确保Apple员工和承包商团队遵守我们在顾客联络方面设定的严格标准。

  

在此声明中，苹果中国确认此事发生，并表达了捍卫用户隐私的意愿。同时也强调了以下几个要点：

  

1.任何一个苹果技术顾问均无法访问顾客的密码、电子邮件内容和照片等隐私信息；

  

2.苹果将与这位用户一同调查此事；

  

3.苹果确保自己员工和第三方团队遵守与客户联系交流时候的标准；

按照苹果之前公开的信息来看，iPhone采用的是端到端加密技术，苹果公司无法获取iCloud和手机里面的信息，技术服务人员也不会被授权通过iCloud账户获取用户个人信息。

 

那么“美国往事1999”的iCloud账户被入侵已成事实，这与苹果公司之前的声明完全相悖，在打脸自己的同时，不由得让用户对其一直以来所宣传的安全性产生质疑。

 

而且据媒体报道，这名涉事客服早在近一个月前就已提交了离职申请，并且现已离职，并表示离职原因也不是本次事件。

 

那么一个已经离职的客服为何还能够轻易轻易获取密码，公然挑衅入侵用户的iCloud并恐吓威胁，不得不说是一件耐人寻味的事情。

 

鉴于此用户表示已经报警，而且“高级技术顾问”入侵了用户iCloud账户并进行电话恐吓，已经触犯法律，后续会有警方介入调查。
