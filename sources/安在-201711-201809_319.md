# Uber创始人将发行1万亿枚数字加密货币

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532703&idx=2&sn=2971b7568aa8ac386816068aaa723b95&chksm=febc2a5fc9cba3494208241e3b960ea561f7837ddce2d8c7a15e94fabff9a9f719c6ad57d78a&scene=126&sessionid=1681310748#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532703&idx=2&sn=2971b7568aa8ac386816068aaa723b95&chksm=febc2a5fc9cba3494208241e3b960ea561f7837ddce2d8c7a15e94fabff9a9f719c6ad57d78a&scene=126&sessionid=1681310748#rd)

![](../Images/f81ae72010497fe922259da5f162fa5a.png)

据外媒报道，Uber联合创始人加勒特·坎普发行了自己的数字加密货币Eco，并决定首次发行1万亿枚。他希望Eco能够成为一种全球性的数字货币，并且可以用来当做用户日常交易的一种支付工具。

  

![](../Images/27e94dbe39d9a969102c507f5adffc3c.png)

据悉，Eco货币最初发行1万亿枚的50%会被分配给前10亿注册投资者。剩余部分会按照20%、10%、10%和10%的比例分别分配给管理人员、顾问、战略合作伙伴以及负责创立和维护网络的生态基金会。此外，坎普本人还将捐出1000万美元为基金会运营提供资金支持。

  

值得注意的是，坎普的加密货币不会有ICO过程，这就意味着该项目不会筹集任何资金，因此也就避免了潜在的法律纠纷风险。目前大多数通过ICO手段发行的虚拟货币都面临或多或少的法律问题。

  

![](../Images/798cad6a765a892ac0f86cb4d3db3958.png)

Eco加密货币白皮书中写到，希望能够针对现有加密货币出现的主要问题进行改进。

  

首先，Eco只使用经过验证的节点来提供网络支持和交易确认，这就意味着

匿名交易者无法通过一个未知节点在网络上进行交易。这么做既消除了51%概率的潜在欺诈问题，同时也不会失去加密货币去中心化的本质。

  

其次，Eco会拥有一个规模庞大的货币供应量(最少初期有1万亿的规模)，同时还有非常简单的Web和移动App操作平台，这么做的目的是提高对用户的友好度，象征性的展示一些基本价值，而普通用户也不会被加密货币高昂的价格吓跑。

  

同样，Web和移动App的支持意味着无论是专业投资者、技术爱好者还是普通用户，都可以轻松的使用Eco加密货币钱包。最后，Eco会设计更节约能源的系统，减少在生产和交易过程中的能源消耗。

  

据媒体报道，2017年5月，坎普首次买入了比特币和以太币，但随后对该领域感到失望。坎普称，“做的研究越多，我就越来越不想大笔买入任何数字加密货币。我意识到，自己发起一个新的加密货币项目可能会更好。”

  

近日，**众多企业家纷纷涉足币圈，发行自己的加密货币。**2018年1月，被称为“俄罗斯微信”的聊天软件Telegram发起了“史上最大规模”的ICO，创始人兼CEOPavelDurav计划通过ICO融资约12亿美元，引发了舆论和投资者热议。除此之外，柯达、在线零售公司Overstock、聊天软件Kik等，也都发起或计划发起ICO。

  

TechCrunch对此评论称，当下并不缺少改进了某些特征的加密货币，事实上，我们缺乏的是支持这些区块链能日常使用的生态系统。发行新币不难，真正难的是如何让成千上万服务提供者、商家和金融机构认可加密货币，让加密货币能真正应用起来。
