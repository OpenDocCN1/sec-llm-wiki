# 盘点2017 | 互联网十大内容安全事件

提及互联网安全，我们大多会将目光聚焦于黑客攻击、数据泄露这些主要关乎网络环境与信息保护的安全。

  

但随着国内互联网产业的发展与技术的革新，基于网络而产生的内容越来越多，不论是我们日常对于网站的浏览、聊天工具的使用甚至游戏与购物，我们所获取的视音频、图片或是文字，都可以称之为互联网内容。

  

2017是互联网内容成井喷式爆发的一年，以各种直播平台、短视频APP为代表的娱乐视听产品不断涌现，泛文娱产品交互形式更加丰富、UGC信息海量增长。

  

但与这些内容生产平台日益增多相悖的是，互联网内容审核的条件与水平严重不符。

  

安在曾就之前的文章指出，全国几千家的内容平台，有九成都处于无有效审核的状态之下。较之更为严重的是，国内甚至还没有相关的法律与审核标准，来对这些内容进行约束，用合适的门槛来限制适当内容的产生。

  

所以，在内容审核如此恶劣的环境之下，有害信息实时产生，不仅严重影响用户体验，甚至会对内容生产的平台与企业，带来毁灭性的打击。

  

另一方面，2017年多项互联网内容治理政策相继出台，《网络安全法》正式实施，互联网内容安全在政策和法律监管上表现进一步收紧，对内容平台不良信息治理能力的要求更加严格。

  

而习近平主席在十九大相关互联网内容的指示上，更是明确强调要加强互联网内容建设，建立网络综合治理体系，营造清朗的网络空间。

  

回首2017，到底有哪些互联网内容安全事件的产生，究竟又对我们的生活及相关企业的生存造成了哪些影响，且看安在如下盘点。

  

上海市网信办约谈熊猫与全民直播

**社会影响度 **☆☆☆  **媒体曝光度** ☆☆☆

  

2017年2月21日，上海市网信办会同市文广局、市网安总队、市文化执法总队，就直播中的低俗色情问题依法联合约谈熊猫直播和全民直播，要求上述直播网站进行全面整改。

  

市网信办强调，熊猫直播和全民直播的秀场频道和评论内容中，存在违反社会公序良俗的低俗色情内容。根据《互联网直播服务管理规定》《互联网文化管理暂行规定》等相关法律法规，市网信办责令熊猫直播和全民直播立即停止违法违规行为，并进行全面整改。

  

**上海市网信办负责人强调，网络空间不是法外之地，直播平台运营者要依法合规从事网络直播服务，加强自律，切实承担社会责任。**上海市网信办将继续加大互联网传播秩序整治力度。欢迎广大网民据实举报，共同维护良好网络舆论生态。

  

![](../Images/067dc1d9f011170427aa0da44b77d052.png)

  

安在观点：所谓约谈，重点不在谈而在约，更多的是对约谈对象的约束，内容平台应当认识到，法律范围之内的约束会对自己法律之外的行为施行怎样的制裁。

  

红杏直播、蜜桃秀等18款直播应用被查处关停

**社会影响度 **☆☆☆  **媒体曝光度** ☆☆☆

  

国家网信办4月2日发布，接到网民举报，“红杏直播”“蜜桃秀”等18款直播类应用存在违法违规行为，经核查取证后，国家网信办会同有关部门依法依规在应用商店下架并关停这些直播类应用。

  

核查发现，被举报的直播类应用缺乏内容安全审核机制，一些主播利用这些平台大肆传播违法违规内容。有的网络主播身着军队警察制服，佩戴军衔警衔臂章等；有的衣着暴露、行为极具挑逗性；有的直播发布私人微信、QQ，诱导粉丝至社交平台进行色情交易等。

  

国家网信办相关负责人表示，直播类应用要弘扬正能量，传播健康向上、导向正确的内容。对于违法违规行为，一经发现立即查处，绝不姑息，欢迎网民举报相关信息。

  

![](../Images/7b0922c3bb1cb670447695dcdaa203a1.png)

  

安在观点：人民警察的形象应当是维护社会稳定，而不是用来满足好色之徒对制服诱惑的性幻想需求，不仅涉黄，同时也是对社会的侮辱，恶心还不自知。

  

央视曝光今日头条、火山直播、花椒直播存在涉黄违规内容

**社会影响度** ☆☆☆☆  **媒体曝光度** ☆☆☆☆☆

  

2017年4月，央视曝出资讯类APP今日头条涉黄的消息，在调查中记者发现，从2016年下半年开始，“今日头条”客户端会不定期地推送一些直播秀链接，点开链接，就会进入一个叫“火山直播”的直播板块。

  

“火山直播”平台借助“今日头条”的推送优势，每天吸引大量用户的点击和关注，其中一些低俗的直播内容也被广泛传播。虽然火山直播平台也表明设有监管员，但平台监管员对这些低俗直播和违规行为却并没有进行制止。

  

除了今日头条，记者还发现“花椒直播”、“逗趣直播”等一些直播平台是依靠女主播低俗表演来吸引眼球，甚至一些不太知名的小型直播平台几乎是处于放任不管的状态，大肆传播色情内容、兜售淫秽视频。

  

4月18日，北京市网信办、公安局、市文化市场行政执法总队联合约谈今日头条、火山直播、花椒直播，依法查处上述网站涉嫌违规提供涉黄内容，责令限期整改。

  

下一步，三部门还将联合约谈美国苹果公司，要求其对“苹果应用商店”（AppStore）上的直播应用加强审核。

  

![](../Images/664f1fb59d023c868af454a04a085d22.png)

  

安在观点：其实苹果一直以来在APP内容审核方面都比较严格，但是国内的直播平台和相关资讯类APP经常变着法子来推送一些低俗内容，甚至可以说是防不胜防，苹果这一次有点躺枪。

  

以《网络安全法》为首的互联网领域法律正式施行

**社会影响度** ☆☆☆☆☆  **媒体曝光度** ☆☆☆☆☆

  

2017年6月，《中华人民共和国网络安全法》、《互联网新闻信息服务管理规定》、《网络产品和服务安全审查办法（试行）》等一批互联网领域的法律法规正式施行。

  

作为我国第一部全面规范网络空间安全管理方向问题的基础性法律，明确规定不得传播有害国家社会稳定、青少年身心健康的信息。

  

有了这把“正义之剑”，就能让用网者有“德”，凭良心去严格遵守社会公德；让上网者亲“善”，传播正能量，爱国家、遵礼义、讲诚信、重友善；让管网者执“法”，依法打击害群之马，清除黄、毒、赌信息，为未成年人上网创造愉悦、健康的网络环境。

  

![](../Images/4339518c425a0da78bdab2ecac2b80d9.png)

  

安在观点：《网络安全法》及相关互联网领域配套法律的施行，不仅会在未来为社会营造充满正能量的网络空间，构建良好的互联网内容安全生态圈，也必将成为互联网时代国家安全的稳定器。

  

“小猿搜题”和“作业帮”对薄公堂

**社会影响度** ☆☆☆☆☆ ** 媒体曝光度** ☆☆☆☆

  

2017年8月9日，多个新浪微博大号转发关于在线教育搜题类APP小猿搜题“涉黄”的截图。截图显示，小猿搜题评论区内存在多条含有色情诱导信息的内容。10日，中国教育电视台对此事件进行报道，小猿搜题陷“涉黄”危机。

  

8月14日下午，小猿搜题召开媒体沟通会，通过公布其掌握的相关证据，表示散发这些色情信息账号的登陆IP均来自“作业帮”的办公所在地，控诉作业帮对其构陷。

  

8月15日下午，小猿搜题联合创始人李鑫称，公司已经就此事报案，并表示，小猿搜题掌握的证据确凿，若作业帮方面否认其指控的相关行为，小猿搜题后续“将放出更多证据”。

作业帮发布公告称，作业帮“持续遭遇来自某同行无端的攻击和诬告”、“某同行的陈述与事实相悖”、“作业帮不做口舌之争”。并且表示，已经“对于任何故意诋毁和诽谤作业帮的行为”进行了证据保全，将通过司法途径追究其法律责任。

  

百度表示，不接受“小猿搜题”对其旗下产品“作业帮”的碰瓷行为。

  

![](../Images/d6742d2cfdf2b459939a56d412cb1995.png)

  

安在观点：教书者必先学为人师，育人者必先行为世范，公关恶战伤害的不是你的对手，而是自己的用户和行业的未来。

  

国家网信办发布 《互联网跟帖评论服务管理规定》

**社会影响度 **☆☆☆☆☆  **媒体曝光度** ☆☆☆☆☆

  

2017年8月25日，国家互联网信息办公室公布《互联网跟帖评论服务管理规定》，规定明确指出，不得向未认证真实身份信息的用户提供跟帖评论服务，并加强“弹幕”管理，《规定》还要求平台实行先审后发制度，自2017年10月1日起施行。

  

国家互联网信息办公室有关负责人表示，出台《规定》旨在规范互联网论坛社区服务，促进互联网论坛社区行业健康有序发展，保护公民、法人和其他组织的合法权益，维护国家安全和公共利益。

  

![](../Images/932d52c5bd3d54205e5bfc2528cdd7e7.png)

  

安在观点：《规定》的出台与施行，适应了互联网的特性和发展态势，保障了网络用户依法享有的言论权利，促进了网络跟帖评论服务管理的规范化和科学化，为构建网络空间治理新秩序补上了法治建设的重要一环。

  

全国“扫黄打非”互联网低俗色情信息专项整治行动

**社会影响度** ☆☆☆☆☆  **媒体曝光度** ☆☆☆☆☆

  

2017年8月，全国“扫黄打非”办公室会同七部门开展互联网低俗色情信息专项整治行动。

  

截至9月底，公安部门成功查办了一批网络传播淫秽物品牟利案件。据不完全统计，截至9月25日，全国共处置、删除色情低俗等有害信息超2000万条。

  

北京、海南等省市“扫黄打非”部门对天涯社区、纵横中文网、逐浪小说网、天极网、猫扑、红袖添香网、小说阅读网、言情小说吧、起点中文网、创世中文网等网站涉嫌传播低俗色情信息问题进行了调查，对查实的违法违规行为依法严惩。

  

全国“扫黄打非”办公室联合公安部治安管理局对上海“友视”、湖南岳阳“狼友”、湖北武汉“partylive”等7起直播平台传播淫秽物品牟利案进行挂牌督办。其中，湖南岳阳“狼友”直播平台传播淫秽物品牟利案中，专案组成功抓获网站运营者、主播经纪组织、社交平台管理员、群主、主播等主要涉案嫌疑人12名，查明涉案女主播1000余名、涉案金额1000万余元。

  

![](../Images/5a9e4f186e74c4f02ba7bdcc2964e7f2.png)

  

安在观点：专项整治行动的目的，是为了在十九大召开前，对互联网环境进行肃清，成果确实非常显著，但也着实暴露互联网内容安全存在极大威胁与严重隐患。专项整治行动已经结束，希望余威尚在。

  

360旗下水滴直播被爆涉嫌侵犯公众隐私

**社会影响度** ☆☆☆☆  **媒体曝光度** ☆☆☆☆

  

2017年12月，一篇名为《一位92年女生致周鸿祎：别再盯着我们看了》的微信公号文章，对360旗下的直播平台水滴直播将商家的公共空间视频公开播放出去的行为产生质疑。

  

文中指出水滴直播在视频中当事人不知情的情况下，将公共空间的视频公开直播出去，涉嫌侵犯隐私。而开通直播的商家则对此不以为意。

  

对此，360创始人周鸿祎发表《怎样以“90后创业者”的身份干黑公关》文章，直指前文作者陈菲菲乃是为帮助竞争对手抹黑自己的黑公关，一时间多家安全媒体纷纷站队，为周鸿祎与陈菲菲发文助威。

  

事件的最后，则是水滴直播产品团队公告用户，自12月20日起，将永久停止运营。

  

![](../Images/340c80a3b89f549e80633b455c1ae28a.png)

  

安在观点：“水滴直播”事件首先反映了规矩的缺失，当前最迫切的是立法或者出台司法解释，否则，在没有法律明确规定直播平台需要屏蔽哪些内容的前提下，平台若自觉屏蔽有些不适合直播的内容是其道德觉悟高，若不屏蔽也不违法，因为在法治社会，“法无禁止即可行”。

  

今日头条、凤凰新闻被勒令整改

**社会影响度** ☆☆☆☆  **媒体曝光度** ☆☆☆☆☆

  

2017年12月，今日头条、凤凰新闻手机客户端因涉及传播色情低俗信息，被北京网信办约谈责令整改，部分栏目暂时停更。

  

北京市互联网信息办公室相关负责人指出，**今日头条和凤凰新闻手机客户端违反国家有关互联网法律法规和管理要求，传播色情低俗信息，存在严重导向问题，对网上舆论生态造成恶劣影响。**

  

在尚未获得互联网新闻信息服务资质的情况下，今日头条手机客户端违规转载新闻信息，且“标题党”问题突出，严重干扰了网上传播秩序；凤凰新闻手机客户端违规自采和转载新闻信息，扰乱了网上传播秩序。

  

北京市互联网信息办公室责令两家企业深入自查自纠，全面清理网上违规内容，杜绝类似情况再次发生。

  

两家企业负责人表示，将严格落实网信部门管理要求，对相关问题进行自查自纠，分别对违规问题严重的部分频道暂停内容更新。

  

随后，今日头条公开招聘内容审核编辑2000人。

  

![](../Images/11061dc92001c5b63b7b1634938f0c1d.png)

  

安在观点：今日头条梅开二度，究其原因，是内容审核人员的巨大缺口以及内容审核标准的缺少，就连今日头条与凤凰新闻这类大型内容平台尚且存在内容审核环节的不足，其他上千家平台的情况可想而知。

  

QQ日迹圈子存在黄色视频

**社会影响度** ☆☆☆  **媒体曝光度** ☆☆☆

  

12月29日下午，有人透露，QQ的日迹圈子里存在大量少儿不宜的黄色视频，随后记者进行了核实，发现在某些圈子里的确存在大量情色视频，画面不忍直视。

  

在当日18时许，腾讯一位工作人员向记者通报：“感谢您的关注监督，目前你举报的两个日迹圈子都已经进行了关停，并会对涉及的QQ账号进行封停处理；目前已经关停了所有的日迹圈子，进行全面排查，发现有害信息将会及时清理并对涉及的QQ账号进行处理。”

  

随后记者再次点开上述几个账号，已无法看到小视频和圈子。

  

晚上20点许，腾讯再一次给记者发来一份正式的处理结果，表示会对违法账号进行永久封停，并加强内容审查的力度，维护清朗、健康的网络环境。

  

![](../Images/2462dde9a83a87db29ae7f2e685c61d1.png)

  

安在观点：这种方式方法，简直和小猿搜题事件所利用的手段如出一辙，安在感叹，卖片的，你们真的是防不胜防。

  

大咖之声

  

上海网络安全协会副主任 张威：互联网每天都在产生各种各样海量的信息，自然就导致了很多虚假的、不良的甚至是有害信息的传播，而在很长一段时间里，对这些内容的管理，相对来说比较薄弱。

  

2017年是内容管理发展最快的一年，不论是政府机构还是平台自身，都加大了监管与审查的力度。这主要是因为，一方面，由于内容审查力度不足，导致各种问题事件的频繁发生，促使了相关监管的出台；另一方面，用户在日常浏览内容平台的过程中，会自发对不良信息进行举报，希望能够以此来让自己获得更好的、更健康的内容。那么以此为基础，相信整个互联网领域，会在2018年继续推动互联网内容监管的发展。

  

同时，本文所盘点的内容安全事件不过是冰山一角，尚有更多的大量有害信息，需要进行清理。我们希望从政府相关部门继续出台一些政策，同时更要从《网络安全法》出发，网络的运营者也就是这些内容平台，有责任和义务自主地去监管平台上所产生的内容，这样就可以有效地进行过滤，避免内容安全问题的产生。

  

结尾

  

回顾整个2017，伴随着互联网内容疯狂生成的，是内容审核的漏洞百出与问题频发。

  

近日，在去年中已经进行过多次整改的花椒直播，又在时下最火热的“赏金答题”游戏活动力，大摆乌龙，这一次，却远比涉黄要更为严重。

  

在花椒直播1月13日12点场我的“百万赢家”游戏中，第六题“王祖贤目前定居在哪个国家”，竟然将香港与台湾列入答案选项。

  

![](../Images/a6c2fa52c83c6a7bf7a53be6296ee54c.png)

  

北京市网信办指出花椒直播未能有效履行主体责任，在“百万赢家”活动的信息安全管理方面存在重大漏洞，违反《互联网信息服务管理办法》《互联网直播服务管理规定》等相关法律法规，并造成不良社会影响。

  

涉黄暂且不表，一旦诸如此类涉政问题产生，极有可能会在未成年人中间，造成像某些游戏，误导儿童错误历史的情况。

  

所以，我们希望在2018年，相关部门能够继续加强监管与审查力度，企业自身能够提高内容审核的能力，而受众用户也能够明辨是非、洁身自好。

  

互联网清朗的内容环境，需要你我一同前行。
