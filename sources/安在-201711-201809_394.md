# 因为“色情小电影”，变态黑客黑掉数万台电脑13年

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532663&idx=2&sn=fd7630d13a345fda9293a5ef9336708e&chksm=febc2ab7c9cba3a1822875725a10b45a846a2fd75d62504f16e8721c8156daa9aded2c9e8a7a&scene=126&sessionid=1681310751#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532663&idx=2&sn=fd7630d13a345fda9293a5ef9336708e&chksm=febc2ab7c9cba3a1822875725a10b45a846a2fd75d62504f16e8721c8156daa9aded2c9e8a7a&scene=126&sessionid=1681310751#rd)

2003年，一个仅有15岁的少年杜拉琴斯怀着对性的懵懂与渴望，想要一探究竟，却奈何没有种子啊。于是，他利用自己高超的黑客技术，制作恶意软件把别人家电脑黑了，看看别人家电脑上有没有。

  

![](../Images/bbd1b832e6c00a13467047b2097321fc.png)

  

从此，一发不可收拾。

  

直到13年后，美国联邦司法部将其抓住，恶意软件Fruitfly的幕后黑手终于大白于天下。

  

本周三，美国司法部正式将菲利普·杜拉琴斯基告上法庭，指控他利用恶意软件攻击了成千上万台电脑。杜拉琴斯基的罪名有16项之多，其中包括窃听、盗窃他人身份信息和制作儿童色情影片等。

  

据了解，杜拉琴斯制作的这个恶意软件会对macOS和Windows PC系统进行感染。

  

在2017年1月被发现前，Fruitfly病毒感染了成千上万台电脑，最早的受害者甚至可以追溯到2003年。据悉，杜拉琴斯基通过该病毒渗透进了公司、学校、警察局甚至美国能源部下属公司的电脑中。美国司法部就惊讶的表示，他居然敢监视政府部门。

  

![](../Images/ebbf67f54eb294ff149ab3b657d1e14f.png)

  

代理助理检察长约翰·克洛南表示：“菲利普·杜拉琴斯基通过恶意软件攻击了数万台美国民众的计算机，并且盗取受害人的个人数据与通信记录。一直以来，司法部门都在努力打击这种以侵犯他人隐私为手段的网络犯罪活动。”

  

借助Fruitfly，杜拉琴斯基可以控制他人电脑上传和下载文档，截屏甚至记录用户的键盘敲击信息。同时，电脑的摄像头和麦克风也被他一手掌控。

  

安全专家沃尔德就警告称，黑客制作这样的恶意软件可不只是为了牟利，他可能还有一些不可告人的秘密，而杜拉琴斯基就有自己的怪癖好。

  

据美国司法部介绍，杜拉琴斯基会窃听并观察受感染电脑机主的生活，当受害者在计算机上搜索与色情影片相关的关键词时，如使用键盘敲出“色情”等词汇，他就能得到通知，通过受害人电脑上的网络摄像头拍摄了数百万张图片。

  

美国第一助力律师大卫·席尔勒加表示：“这名被告人在超过13年的时间里，一直在偷窥来自美国各地的受害者，并且盗取他们的个人信息。”

  

这个名为Fruitfly的恶意软件曾经一度让网络安全研究人员感到非常困惑，因为这个恶意软件混合了新旧两种编程风格。甚至曾经有人一度怀疑这个软件是美国政府资助编写的，还有人认为它是一个间谍工具。

  

公诉人表示，此前这个恶意软件曾经多次被植入到凯斯西储大学的服务器上，于是司法部门开始介入。在经过调查之后，犯罪嫌疑人杜拉琴斯基遭到逮捕。美国联邦调查局（FBI）表示，美国能源部门网络、一家警察局和多个学校的网络上也发现了这个软件。

  

FBI特工史蒂芬·安东尼（Stephen Anthony）对这件事情的评论为：“杜拉琴斯基利用他高超的网络技能做了错误的事情，入侵了大量系统和个人计算机。联邦调查局想要赞扬那些让执法当局注意到这件事情的机构，正是这种合作的态度让当局能够将这名网络黑客绳之以法。”
