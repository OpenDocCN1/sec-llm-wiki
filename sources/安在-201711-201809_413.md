# 盘点2017｜网络安全十大事件之：民生与共

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532655&idx=1&sn=4581d3ce9c5f894aebf3e8953b352be8&chksm=febc2aafc9cba3b93579f7e527cfe6d5dd6411afb153ec4fe016887587c7e924d2f5f15d0f63&scene=126&sessionid=1681310753#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532655&idx=1&sn=4581d3ce9c5f894aebf3e8953b352be8&chksm=febc2aafc9cba3b93579f7e527cfe6d5dd6411afb153ec4fe016887587c7e924d2f5f15d0f63&scene=126&sessionid=1681310753#rd)

![](../Images/0e8c8653cc765b9a68b4585a005b6179.png)

  

2017已尽，2018伊始，回顾过去一年，网络安全不乏热点且正持续发酵。作为系列回顾之一，本文将视角放在那些有着重大影响的事件上，阅览风云变幻，历数其中热闹。

  

纵观2017，全球性的网络安全事件层出不穷，有WannaCry之横扫天下，也有NotPetya和BadRabbit之席卷欧陆，有屡屡见诸报端的重大信息泄漏事件，也有不乏“战争”阴云的国际争端。

  

国外的“月亮”暂且不表，回望我们头顶的这方蓝天，大事不断，历历在目。

  

从总体趋势来看，事件越来越多，越闹越大，牵涉面越来越宽，且越来越关乎国计民生，因而也越来越吸引普通民众的热切关注，难道不是吗？

  

现在每每被曝光的与网络安全相关的事件，哪一个不牵涉个人隐私或数据泄漏的问题？哪一个不是牵一发而动全身的感觉？

  

作为具有大众传播视角的专业媒体，安在理所当然要以“民生”相关来切入这个话题。

  

“民生”是什么？

  

关乎每个民众的生存生活，而网络安全之“民生”与共，一方面是说网络安全人人相关，另一方面，也意味着我们不能再以圈内人习惯的漏洞、威胁等“干冷”术语示人，而应该以更“亲民”更“通俗”的方式，说与大家息息相关的那些事儿。

  

到底有哪些“民生”攸关之网络安全大事件？且看安在如下盘点。

  

央视曝光黑市贩卖个人信息

  

> **民生相关度** ☆☆☆☆☆  
> 
> **媒体曝光度** ☆☆☆☆☆

  

2017年年初，央视曝光的一则关于泄露的个人信息在网上被公开贩卖的新闻，掀起了广大市民对个人隐私泄露的担忧。

  

据央视记者发现，网络上活跃着贩卖个人信息的黑市，一些信息贩子甚至公然表示：只要提供一个人手机号码，就能查到他最为私密的个人信息，其中就包括身份户籍、婚姻关联、名下资产和通话记录等，并且声称可以进行三网定位，实时锁定手机用户的位置。

  

央视记者伪装客户与贩卖信息人员进行交易，以130元的价格在两个小时内获取了包括自己毕业院校与现居住所在内的所有网购地址，并且准确无误。

  

效率高、价格低、廉价的犯罪成本让贩卖信息的黑市日益壮大。

  

![](../Images/d0f7ff8382e61a83d49ef1015ca256aa.png)

图：央视报道信息贩卖

  

安在观点（AnZer\_SH）：要看到隐私交易的背后是一整套互联网地下产业链体系，只有打破其利益链条，方能扼制其壮大和发展。

  

“扫码骑单车”扫丢个人信息

  

> **民生相关度** ☆☆☆☆  
> 
> **媒体曝光度** ☆☆☆☆

  

共享单车在2017年的大热，不仅方便的人们的出行，同时也给不法分子提供了新的作案契机。

  

早在3月左右，就有不法分子在共享单车的开锁二维码上做起了文章：在车身原二维码周边加贴虚假二维码，甚至将原二维码覆盖。

  

一旦用户没有辨别清楚，就可能受到财产损失，甚至会跳转到含有木马的假租车软件，被盗取包含身份证号码、银行卡密码等在内的个人隐私和信息。

  

![](../Images/2cd0f1cb663cea1c97c8c833da03222d.png)

图：假冒共享单车二维码

  

安在观点（AnZer\_SH）：扫二维码要看清，有被涂鸦，覆盖痕迹的二维码可千万别扫哦！

  

假“共享充电宝” 让你秒变透明人

  

> **民生相关度** ☆☆☆  
> 
> **媒体曝光度 **☆☆☆☆☆

  

在2017年流行的共享经济中，除了共享单车外，同样火爆的还有共享充电宝。尽管共享充电宝的诞生在一定程度上缓解了不少用户对于手机充电的燃眉之急，但是其中存在的诸多隐患反而导致弊大于利。

  

在2017年3·15晚会上，使用共享充电宝导致强装软件、盗取信息的现象被曝光。

  

用户在使用共享充电宝时，手机会强制安装恶意程序，黑客由此便可获取手机中包括通讯录、相册等在内的个人信息，甚至可以远程控制支付软件，直接对用户的财产进行转移或者使用。

  

![](../Images/57a7a18d92773b51a3af11afee8483a6.png)

图：央视曝光恶意的免费充电桩

  

安在观点（AnZer\_SH）：电流进来了，数据却顺着连接线出去了，千万记住充电时不要把数据传输权限打开！

  

58同城招聘信息公开售卖

  

> **民生相关度**☆☆☆☆  
> 
> **媒体曝光度**☆☆☆☆

  

3月底，58同城被爆700元即可采集全国简历信息。

  

由于全国各地的58同城招聘网站对求职者的简历毫无防护，并且平台存在多个漏洞，所以黑客只需要通过采集工具就能轻易获取后台数据。

  

甚至有商家在网上出售700元一套的爬虫软件，可采集全国430多个城市，以及464个职业的简历数据。

  

![](../Images/61e63e657321700d1a8770ef177cc73d.png)

图：58同城爬虫软件

  

安在观点（AnZer\_SH）：我的简历只给我想让其看的人看，这是我的权利，那么对于保管包括简历在内等海量个人信息的58同城来讲，保护好我的数据，更是你们的义务。

  

勒索病毒WannaCry席卷全球

  

> **民生相关度** ☆☆☆☆☆  
> 
> **媒体曝光度** ☆☆☆☆☆

  

众所周知，5月29日，新型“蠕虫”式勒索病毒WannaCry爆发，短时间内瞬间席卷全球。美、英、中、俄、西、意等上百个国家和地区，共约2242.3万个IP地址遭受“永恒之蓝”漏洞的攻击。

  

据悉，一旦电脑感染这种勒索病毒，其中文件会就会被加密锁住。

  

而用户想要拿回使用权，只能向黑客支付5个比特币（当时价值人民币5万多元）的赎金，否则只能舍弃电脑中的文件。

  

![](../Images/b76dfc9f019f3e1ae3c8e6550e6a5e77.png)

图：黑客勒索用户缴纳赎金

  

安在观点(AnZer\_SH)：大多数用户在网络攻击面前都只能无力地支付赎金，纵容歹徒，着实令人想哭。只有安全厂商的改进与行动，才能够让用户们避免下一次的攻击，或是在攻击来临时拥有不同的选择。

  

勒索病毒搭上王者荣耀“全军出击”

  

> **民生相关度** ☆☆☆  
> 
> **媒体曝光度** ☆☆☆☆

  

2017年6月，时下吸金又吸睛的热门手游《王者荣耀》火遍全国，一款冒充其辅助工具的手机勒索病毒趁机出动。

  

该勒索病毒主要针对安卓手机用户，打着游戏外挂的名义吸引用户下载安装，界面与横扫全球的WannaCry极为相似。

  

用户中招后，桌面壁纸、软件名称、图标形态都会被恶意篡改，并对手机内个人文件进行加密，以此对用户进行勒索，索要赎金。

  

中招用户需要按规定时间支付赎金，否则将面临赎金加倍，甚至是“撕票”的威胁！

  

![](../Images/1e212e15be1f987c6b4fae105388d84d.png)

图：360手机卫士微博发布王者荣耀辅助勒索病毒预警

  

安在观点(AnZer\_SH)：玩个游戏却被绑架了整个手机，外挂真是害人不浅。记住！在非正规APP商店下载的应用程序都应该谨慎安装。

  

央视调查发现大量家庭摄像头被入侵

  

> **民生相关度** ☆☆☆☆  
> 
> **媒体曝光度** ☆☆☆☆☆

  

6月，央视《每周质量报告》调查发现，有不法分子在网络上兜售家庭摄像头所摄录的视频资料。不少黑客利用弱口令密码大范围扫描家用摄像头进行破解，可获得IP地址和登录密码，远程操作用户家中的摄像头。

  

在随后质检总局的抽检中，在涵盖市场关注度前5位产品的情况下，40批次采样产品中有32批次存在安全漏洞，占比高达80%。

  

![](../Images/3a21b3a6b953ff25848d58adfbdddf16.png)

图：央视报道摄像头被入侵

  

安在观点：摄像头是互联网这个怪物的眼睛，注意！保护好你自己，千万别让它瞎看。

  

清理微信僵尸粉 竟然是盗号骗局

  

> **民生相关度** ☆☆☆☆☆  
> 
> **媒体曝光度** ☆☆☆☆☆

  

“免费帮你清理微信僵尸粉”、“我在清理微信好友，一清吓一跳”，相信不少人应该收到过这样的微信消息。

  

所谓“僵尸粉”是指单方面删除了自己，而自己却不知道的好友。犯罪分子打着主动帮助清理“僵尸粉”的旗号，让不少人点开了信息中附带的清理链接，并按照其所说的步骤操作。

  

用户在这个过程中，实际上是将自己的微信在不法分子所使用的电脑上进行了授权登录，对方则趁机盗取用户微信信息，甚至会同时植入木马病毒。

  

![](../Images/d06cb07847fc7dd6a693d15acaecef84.png)

图：央视报道的清理微信僵尸粉骗局

  

安在观点(AnZer\_SH)：天下没有免费的午餐，免费只是诱饵，多考虑考虑背后的目的，大家就不会上当了。

  

年度重磅电信诈骗案 内地嫌犯超500人

> 
> **媒体曝光度** ☆☆☆☆☆

  

9月28日，我国公安部指挥大陆10省区市公安机关，联手台湾警方，与东盟8国警方统一行动，成功摧毁了两个特大跨国、跨两岸电信诈骗犯罪集团，抓获犯罪嫌疑人共计828名，其中大陆籍犯罪嫌疑人532名，涉案金额高达1亿多人民币。

  

9.28特大电信诈骗案成为2017年度重磅诈骗案。

  

![](../Images/e53c4e1a4e3daa7ab9edb5e9bde5c6ce.png)

图：嫌犯被押解回国

年内最大学生信息泄露案  趣店数百万名学生信息被卖

  

> **民生相关度** ☆☆☆☆☆  
> 
> **媒体曝光度** ☆☆☆

  

11月前后，有媒体报道称，网络黑市近期出现了一份疑似趣店学生个人隐私的数据。

  

该数据涵盖了借贷金额、学生及其亲属电话、学信网账户等多个维度的隐私和信息，而这份包含数百万学生个人隐私的详细数据，在网络上的打包售价高达10万元。

  

有趣店离职员工证实，该数据确实来源于趣店，可能是有内鬼将其泄露。

  

![](../Images/4cae70021acb092121e8c534aff1a633.png)

图：被泄露的学生信息数据

  

安在观点(AnZer\_SH)：触目惊心！互金平台的数据价值极高，但是又有多少平台重视对用户数据的保护呢？这真是值得反思的事。

  

大咖之声

![](../Images/202e5246e96dec10597205efa22cc6b7.png)

**杨卿 **（独角兽安全团队建立者、360 IoT安全研究院 副院长）

  

对于2017年国内网络安全事件的总结，我认为问题的根源依旧出在我们一直强调，但还是需要加大力度投入和改善的老三样问题：**新型网络攻击手段层出不穷，企业与机构对于安全防护的投入仍需加强，用户安全尚待提高。**

  

安全不是一个单纯依靠技术就能够解决的命题，在过去的一年中，《网络安全法》以及配套法规的实施，已经让政策站在国家层面上给网络安全的建设提供了强大的助力。

  

那么在2018年里，就需要国内的安全厂商加快安全技术的研发，提高应对网络安全事件的处理能力，同时加大安全人才培养的力度，普及百姓对于网络安全认知的教育。

  

各行业联动，让中国在2018更加成为网络信息的安全之地。

  

新年展望

  

**杨卿**（独角兽安全团队建立者、360 IoT安全研究院 副院长）

  

随着2017年底FBI侦破Mirai僵尸网络案件，算是在2018年初为“美国断网”的案件的做了“贺岁”。

  

这次事件的预警与侦破过程联动了多个国家的众多互联网、安全公司，以及政府执法机构，Mirai的出现，也催生了越来越多的变种。

  

也正因为这次FBI的完美结案，让通过僵尸病毒谋取黑色利益的编写者及犯罪团体更加“小心谨慎”，这势必会拉高网络安全公司对此类僵尸网络的预警、发现及溯源IoT僵尸病毒的技术能力要求。

  

未来针对于IoT智能设备的僵尸病毒依旧会持续出现，这对于互联网企业、安全企业及执法机关都将是更大的考验，**2018年之后也会是IoT安全产业较关键的时期，我们要警惕利用AI人工智能、区块链等新兴技术产生的新型攻击及类似Mirai这样的恶意程序对网络安全与IoT设备的影响。**

  

结尾

  

回顾2017年度十大安全事件，个人信息泄露成为国内网络安全首要威胁。

  

6月1日，《中华人民共和国网络安全法》正式实施。这是我国网络领域的基础性法律，明确加强了对个人信息的保护，对网络诈骗的打击，并将加强惩治破坏我国关键信息基础设施的境外组织和个人。

  

![](../Images/1a271d3cf80c91ecb1f6cd7c1e30a62b.png)

  

而在2017年度最最重要的十九大里，习近平总书记也明确指出，要高度重视传播手段建设和创新，提高新闻舆论传播力、引导力、影响力、公信力。加强互联网内容建设，建立网络综合治理体系，营造清朗的网络空间。

  

同时，全国人大常委会从2017年8月启动《网络安全法》和《关于加强网络信息保护的决定》“一法一决定”的执法检查，12月向常委会提交执法检查报告。

  

对于一部新制定的法律实施不满3个月即启动执法检查，这在全国人大常委会监督工作尚属首次，充分体现了国家对于《网络安全法》落地实施的高度重视。

  

在严峻的网络安全形势下，国家相关部门、安全厂商、运营商等应当多方联合，通力合作，继续为捍卫中国的网络信息安全，战斗在2018。
