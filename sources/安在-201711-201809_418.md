# 走进观安 | 18年媒体人教你如何做推广

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532650&idx=2&sn=3b3f3a706777800bc230584dcbeed3e1&chksm=febc2aaac9cba3bc3a17f856f34fbffcb5b58969102645b8896d88e4903390b1abad4c1cc48b&scene=126&sessionid=1681310754#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532650&idx=2&sn=3b3f3a706777800bc230584dcbeed3e1&chksm=febc2aaac9cba3bc3a17f856f34fbffcb5b58969102645b8896d88e4903390b1abad4c1cc48b&scene=126&sessionid=1681310754#rd)

12月22号难得的是个好天气，久违的阳光晒得人舒服地只想捧着咖啡坐在窗边打个盹。

  

而恰恰好，我们一行人受邀来到了**上海观安信息技术有限公司**，温馨的会议室，大大的落地窗，精致的茶点，舒心又惬意。

  

![](../Images/0b126178e011f7a66e6ae815b3070964.png)

  

![](../Images/a91cad27b193c0824ef078c68e6401fd.png)

  

在这样的氛围下，要干什么？

  

相亲大会？嗯，乍一看是很容易误会。。。

  

![](../Images/ece89d70230fee817d6b9f014fa81ad3.png)

  

但，很负责任地公布答案：我们在听一个18年媒体人吹牛逼，哦，不对，分享媒体推广经验。

  

要说活动的由来，其实很简单，只是因为大家对媒体推广的询问和好奇。而我们正好有这个能力来做解答。

  

作为新兴的信安圈，媒体推广这个词相比其他行业，一直以来并没有那么高的出镜率。作为信安圈媒体，安在接触了许许多多的安全厂商，渐渐地发现，安全厂商对品牌、对推广的意识太弱太弱了。

  

但随着市场的发展，近来，媒体投放、媒体推广、市场推广这些词却频频被提起，越来越多的厂商找到安在询问如何做推广，也有许多人私下想请教如何学习推广。

  

而其中，上海观安信息是较早开始重视媒体推广的一批公司，她们显然早早注意到了品牌的重要价值以及推广的关键性，在媒体推广方面也有了一定的积累和想法。所以，此次由观安信息任东道主，很迅速地组织了此次分享活动。

  

![](../Images/6c0e57431602d8efcdb51aa7a75da190.png)

  

此次活动主讲人安在总编辑成效伟，想必许多人都已见过，甚至聊过。本次以“媒体推广”为主题，成老师重点讲述以下三大板块：

**01**

如何高效导流、提升品牌知名度

**02**

如何打造爆款内容or文章 

**03**

你所知道与不知道的劫持流量那些事

  

![](../Images/4a91a629603f8a13ddc3a2db794ab409.png)

  

成效伟，男，70后。1999年毕业于南京师范大学历史学系，研究生毕业于中山大学国际关系学专业。

  

1999年10月进入新华社江苏分社，2003年进入上海文汇新民联合报业集团，任浙江办事处副主任，2012年出任香港成报浙江分社社长。

  

从业18年，独立参与了“5.12”汶川地震、“7.23”动车事故报道。2016年研究生毕业出任众美联集团PR总监。具备丰富的线上推广经验。现任安在总编辑。

  

成老师以自身18年媒体从业经验，以实际案例为大家讲述“推广是什么”，“品牌是什么”，“如何导流”，“如何打造爆款”等问题。现场演讲内容此处不做深入展开，相信在场的朋友们都受益匪浅。

  

![](../Images/bed459c87544e1b84a535d390938c8cc.png)

  

会后，参会的朋友说道：“身为新闻系出身的我，感觉今天才重新认识了媒体，这是在学校都学不到的知识和经验”。

  

其他参会者也纷纷表示，以实际案例进行讲解，更直接地让大家感受到了媒体推广的力量，也学习了更多的“套路”。

  

![](../Images/bd04c7949a470fd72048ee9cdc191d8b.png)

上海信息安全协会张威讲解网络安全法

  

最后，再次对**上海观安信息技术有限公司**表示感谢，感谢观安信息作为东道主准备的场地、精美的茶点及其他所有的准备。

  

观安信息一直以来都跟安在保持着紧密的合作，也早早就意识到了媒体推广的重要性。

  

正是如此，在活动最初只有雏形之时，就对成总、对此次活动表示大力支持。会后，观安信息也表示对此次活动十分满意，期待后续多多合作。

  

后续，成总还会不定时在不同的城市开讲，大家可以多多关注哦！
