# 芯盾时代：卫生医疗行业的保卫者

> 摘要：为深入交流区域卫生信息化助力健康扶贫的经验做法以及推进智慧医疗体系建设，江西省卫生信息学会定于2017年12月7日-8日在江西省上饶市鄱阳县举行主题为“区域卫生信息化助力健康扶贫”的2017年江西省卫生信息学会年会。由鄱阳县领导、国家卫生计生委统计信息中心领导做开幕式致辞。江西省卫生计生委信息中心、北京市卫生计生委信息中心等领导讲解了新时代区域卫生信息化推进策略以及科技与医疗相结合的重要性。

  

  

![](../Images/0d7f7837c61db7967893c899b36e90d1.png)

  

个人健康信息外泄屡见不鲜

  

健康医疗信息泄露已不是新鲜事。

截止到2017年中旬超7亿条公民个人信息遭泄露，8000余万信息被贩卖。

业内人士分析，信息泄露在医疗行业频繁发生的原因，主要由于医疗卫生行业的个人信息比较集中，吸引更多黑客的关注，并且我国医疗卫生机构的安全漏洞较大——比如弱口令，以及SQL注入等。

（来源：http://news.hexun.com/2017-09-14/190862499.html）

加快医疗数据安全建设

为打破信息孤岛，深入贯彻“智慧医疗”与“健康中国”的要求，充分动员发挥各方力量积极实施国家大数据战略和保障用户个人信息安全计划，推进信息安全技术与卫生健康的深度融合，加快用户身份安全在卫生医疗行业的应用。

  

本次江西卫生医疗年会还专门邀请了全国各地的医疗卫生信息化专家，来自江西省卫生信息学会会员，市、县级卫生计生委及各医疗卫生计生单位信息化分管领导、信息部门负责人、信息技术人员以及国内多家医疗IT企业的代表，深入探讨大数据时代，如何加快建设智慧医疗体系与全面构建公民信息安全平台。

  

而**北京芯盾时代科技有限公司以移动身份认证**行业领航者的身份参加此次会议。

  

![](../Images/20930d5ce4094f06ee47586a089b641c.png)

  

时代的变革，必有独角兽诞生

  

芯盾时代是全球专业的安全身份认证服务提供商，也是国内最早提出“智能身份认证”理念的移动安全公司。

在企业信息化的发展中，传统的密码验证已经无法保障用户的身份安全，密码验证本质是运营商与用户之间的双向认证方式，并不能够全方位的防止用户身份泄露事件发生。

随着企业的发展和其信息化的进程，必然会造成日益繁多的企业应用和复杂的用户角色，从而使得身份认证成为备受关注的问题。

移动互联网时代以人为核心， 加强**用户的身份认证安全是每个企业必须要着重解决的问题**。

本次卫生医疗会议，芯盾时代主携“善认•一站式移动身份管理”及“移动办公安全解决方案”两种产品，解决所有端口（B/S端、APP端、C/S端）的安全认证问题、移动设备OA、移动查房、移动HIS等应用场景的安全问题，与参会嘉宾探讨医疗大数据安全等问题。

而芯盾时代作为智能移动身份认证领域的独角兽企业，在本次会议获得广泛的关注。
