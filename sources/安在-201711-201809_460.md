# 化茧成蝶！指掌易荣获2017中国财经峰会两项大奖

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532630&idx=3&sn=88bff45950c1012347179cf9f5140a18&chksm=febc2a96c9cba380eb0bbeaec4c9819f91eef9ed9e8307fdc49f77815f02bbb558a13228273f&scene=126&sessionid=1681310756#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532630&idx=3&sn=88bff45950c1012347179cf9f5140a18&chksm=febc2a96c9cba380eb0bbeaec4c9819f91eef9ed9e8307fdc49f77815f02bbb558a13228273f&scene=126&sessionid=1681310756#rd)

![](../Images/115d1e23da6cf8bb8b452d9a9247faff.png)

2017年11月30日，以“进阶与蝶变”为主题的2017中国财经峰会冬季论坛在北京隆重举办，指掌易凭借其在移动安全领域的强大技术实力和良好的市场表现，荣获**“年度最具成长性公司”**大奖、同时指掌易CEO王伟先生获评**“时代创变榜-年度影响力人物”**。

  

这也是本届中国财经峰会论坛上唯一获得两项大奖的移动安全公司。

  

![](../Images/be672a625f057923a8d27731b1f31ba2.png)

  

“每个人心中都有对光荣与梦想的追求，正是这对梦想的矢志追求，书写了中国经济一个又一个传奇。”

  

峰会伊始，致敬盛典中就道出了本届峰会的主题：向新常态下推动经济增长与社会进步的企业与人物典范致敬，为他们点赞。

  

2017年是中国经济发展尤为重要的一年。在供给侧结构性改革背景下，稳中向好的中国经济向世界展示了强大的中国底气与信心。同时对指掌易来说2017也是不同寻常的一年。

> *   2017年1月获得了A轮8000万人民币的投资；
>     
> *   2017年9月获得了A+轮1.5亿元人民币投资，成为获投金额最高的企业移动办公安全公司；
>     
> *   2017年9月获得全球知名投资风向杂志《红鲱鱼》“亚洲科技100强”称号；
>     
> *   2017年11月荣获“中国企业服务领域最佳企业服务商”奖项；
>     
> *   2017年11月获得“2017年度最具成长性公司”“年度影响力人物”大奖。
>     

![](../Images/24f02227bd23d87f8a8376f7eb1177ce.png)

  

“纵观2017，指掌易获得了非凡的荣誉与成就，”王伟表示，“无论是从资本投资角度还是市场认可角度，都收获颇丰。然而我们并不会停下前进的脚步，指掌易将继续在移动办公安全领域深耕，为企业的移动化进程提供强有力的安全保障。”

  

据了解，中国财经峰会是中国经济领域最具影响力的思想盛会之一，峰会设立于2012年，由众多财经及大众媒体联袂打造，致力于汇聚和分享商业智慧，传递主流商业价值观。

  

本届峰会聚焦大变革时代的企业和企业家群体，展现他们在供给侧改革大潮中的进展与成果，并以他们为载体和样本，探寻中国经济转型和发展的动力。

  

众多政界精英、工商界领袖、经济学界翘楚、创业家及新青年代表共聚一堂，以跨界对话的形式探讨当下最热点的财经话题和经济事件，通过不同角度的思想碰撞，前瞻中国经济发展大势。共同探寻新时代背景下中国经济的进阶与蝶变之路。

  

指掌易科技将会继续以开放进取的心态，在移动办公全面来临的时代下，为各行业用户继续提供更加安全、高效的整体解决方案。
