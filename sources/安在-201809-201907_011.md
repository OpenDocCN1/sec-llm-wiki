# 命不由己（3）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247533174&idx=1&sn=e05b731d6d410802db1ede7451666fde&chksm=febc28b6c9cba1a0b0c8195d6e32b781c6bcfc3cd700fd685ec165b4e2aafd2f2cd99521771e&scene=126&sessionid=1681310699#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247533174&idx=1&sn=e05b731d6d410802db1ede7451666fde&chksm=febc28b6c9cba1a0b0c8195d6e32b781c6bcfc3cd700fd685ec165b4e2aafd2f2cd99521771e&scene=126&sessionid=1681310699#rd)

![](../Images/9105a3d368bfd94fb2e5a1c047ed0f08.png)

  

  

我不讨厌尝试各种各样的新鲜事物，但非常讨厌被强制要求的感觉。

  

打个比方来说，如果此刻我饥肠辘辘，面前摆放着一盘从来没见过的精致菜式，我很乐意在确认其安全之后大快朵颐一番；但若是有个人站在我身后，冷冰冰地催促我快吃，我怕是怎么也没办法提起胃口了。

  

明明是同一件事，区别不过是别人要求和出自于自己意愿，就会在我的行为上导致南辕北辙的结果。这种憎恨仿佛刻在我的骨头上，时不时会跳出来刺我一下。

  

![](../Images/63d73fc60d55bd03b02824a7e185aafa.png)

  

比如现在。

  

明明已经有联络人与我订好翌日见面的时间地点，我却突然接到机器快递小子的来电，说有要我亲自签收的一封信件，从城东区过来的。

  

彼时我正在自由市场里津津有味地围观一场即将升级为斗殴的讨价还价，本想和以往一样随意应付下，但它不依不饶，大有你不回来我就在门口搞事的意思，我只好百般不舍地放弃了继续做吃瓜群众，转头踏上归途。

  

快递小子看我出现后就开始大呼小叫，责怪我在这么重要的时候不在家云云，我照例左耳进右耳出，但不知怎的从他那张量产型的智械脸上看出来点大劫过后的确幸来。

  

总感觉这次的对象有点麻烦...不，店主哪次给我找的不是麻烦？

  

我极其敷衍地摸了下快递小子光滑的脑壳，得到一个没啥威慑力的抗议。目送他离开后，我拿着烫手山芋在门口立了半晌，才慢慢吞吞地开门进屋。

  

急躁到想追进我家这种程度的客户，不只有这一位，但真的找上门来的，绝对是头一个。

  

搓了搓上臂的鸡皮疙瘩，我强迫自己把隐隐的不祥预感抛之脑后。

  

抱怨归抱怨，敬业精神还是不能少。

  

信封的内容物，烦恼的来源——一封烫金的邀请函正躺在我的操作台上，款款散发出幽深的木质香氛。

  

邀请函开头是些让人牙酸的陈词滥调（也许那些大腕儿好的就是这口），第二段才写明音乐庆典的具体信息，详细陈述了进场方式，着装要求等等。

  

我把装它的纯黑色信封翻了个面，认真端详起刚刚被我用刀小心揭开的火漆。

  

银灰色火漆上镶着一只其貌不扬的鸟儿，和麻雀有点像，但是喙要更长些；左下角有个小小的圆体“M”，被描成了金红色。

  

我对鸟类并没有特别熟悉，想了一会儿其间的联系而不得解，只能再去研究纸制的邀请函。

  

正如我之前说过的，这年头大型绿植稀缺的程度不亚于没有改造过身体的普通人，电子化的书籍文件并不单是方便他人携带阅读，更多时候是为了节省成本。过去砍树制纸是天经地义之事，现今要是没有特殊批准想随便伐木造纸的话，就得做好被巨额罚款逼到走投无路的准备。

  

那老混蛋的经营预算大概有三分之一都花在纸上了吧。我颇有些幸灾乐祸，但这喜悦只持续了短短一瞬——按照信函的要求，我必须穿正装出席，全套行头得面面俱到，否则会被视为仪态不整请出场外。

  

虽说作为一名彻头彻尾的边缘游走者，我的破烂收藏稍稍有些多，但大部分都在可控范围内，但真有什么紧急情况的话，一个大背包把重要的都带走也绰绰有余。

  

与此相对的就是，我的衣服两只手就数得过来，里面别提成套的西装了，能勉强凑成对的的衣服也就只有一套家居服。

  

正当我认真考虑是不是该去找损友求助，放一回血的节骨眼上，之前与我联系的那位来了一条新信息：“明日约定照旧，会解答你所有的疑问。”

  

不坚定的破费念头像是被一阵风吹散了，但却没有远去，而是化成了细微颗粒，泛作我心中的大片疑云。

  

从其他区域去城东区不是件容易事儿，但也不会太难。即便你穿的是洗得发白的破洞牛仔裤和脏到看不出颜色的过时板鞋，只要付得起高昂路费，出租司机就会按照要求送你到位，一路上乖乖做个锯嘴葫芦。

  

我头靠玻璃，百无聊赖地看着远处鳞次栉比的高楼在车窗外缓缓袭来，像一群蓄势待发的无言巨兽。

  

城东区其实是个岛，外围有一片宽广的海域，和原生海紧密相连共用生态系统，但壳子却是纯人工制造。大部分住在城东区内的人都有自己的飞行载具和专用空位，真正踏踏实实在跨海大桥上通行的，基本就只剩我这种外来者。

  

本来岛屿上的人准备通过设置苛刻的入岛通行证，严格控制岛内常驻人员来实施所谓的阶级隔离政策，但最终因为反对声音太过声势浩大，岛内人群自身也受到严重影响，内部分裂成意见不统一的派系而最终作罢，是众志成城的胜利——历史书上是这么写的。

  

但据我了解，最终的导火索不是群众的唾沫星子，而是某一位的女儿因此而...

  

“马上要入岛了。”

  

前座的司机冷不丁地来了一句，打断了我漫游天外的神思。不知何时，那巨兽群已近在眼前。抬眼望去，天空湛蓝如洗，不时有载具穿行在钢铁丛林之间，在打扮入时的巨型女郎投影上留下扭曲的空气波动。

  

城东区近在咫尺。
