# 女神在出租屋洗澡时，房顶忽然掉下个摄像头......

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247533157&idx=1&sn=a0be5ad930cbd626a56d94c23443684b&chksm=febc28a5c9cba1b32e764b2c7097b9b63df5956f9591b9dfcba1008576a8123b140b44c271b8&scene=126&sessionid=1681310701#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247533157&idx=1&sn=a0be5ad930cbd626a56d94c23443684b&chksm=febc28a5c9cba1b32e764b2c7097b9b63df5956f9591b9dfcba1008576a8123b140b44c271b8&scene=126&sessionid=1681310701#rd)

你经历过最绝望的事情是什么？

 “洗澡时，房顶忽然掉下来个摄像头”。这是女神经历的最绝望是事情。

  

他不知道这个摄像头存在多久了，也不知道这个摄像头记录了自己多少洗澡的视频，也不知道这些视频究竟流向何处，又有哪些人在视频前评头论足，做着恶心的事情。

  

有那么一刻，她想到了死亡。

  

![](../Images/dffbb761ebc5eff997bb4e26fab6becc.png "动态黑色音符")

  

  

这里有一个问题：**入住酒店时，你会检查房间里是否有隐藏的摄像头吗？**

  

两年前，大概很多人对这个问题嗤之以鼻，从未担忧自己的一举一动被偷拍。但是在今天，恐怕绝大部多数人都不敢肯定，自己住的房间里没有针孔摄像头。

  

因为，已经有太多人用自己的实际经历证明了这一令人恐惧的事实：偷窥似乎无处不在！

  

![](../Images/b76534d807ede56407b87cfdde5e3c5e.png "1.png") 

酒店里，有人通过针孔摄像头记录着所有入住人的点点滴滴；在出租房，有人通过智能摄像头直播夫妻生活，一举一动都成了被人观赏的“节目”；甚至在地铁上、卫生间，都有人用手机偷偷拍着女生的裙底......

  

**针孔摄像头到处都是**

  

事实上，试衣间、酒店、民宿、出租房都是针孔摄像头偷拍的“重灾区”，某酒店经理称 “**八成酒店都有针孔摄像头**”，足见偷拍行为影响范围之广。

  

![](../Images/6d216450cb530a5a21e0e9b6ad39c095.png "2.png") 

仅2019年6月，已被媒体报道的针孔摄像头偷拍事件便是不少。找出这么多隐藏在背后的针孔摄像头，我们却反而感到更加惶恐，这意味着针孔摄像头真的无处不在，谁也无法保证你入住的那个酒店是安全的。

  

6月15日，深圳市某优衣库试衣间被顾客发现藏有针孔摄像头，伪装成一颗纽扣直接粘在了试衣镜上。如果顾客正常换衣服的话，摄像头正对着胸部位置。随后，该店店长赶过来后把摄像头连同线槽一起拆了下来，发现里面还有一张储存卡，里面早已存有录好顾客换衣服的视频。

  

![](../Images/dbeebc1c48de8842f294963017cc8b4f.png "3.png") 

同样是6月15日，一对情侣在郑州某酒店住宿时偶然发现在房间电视机下发的五孔插座里好像有灯光闪了一下，细细寻找发现竟是一个针孔摄像头。报警后，警方对涉事酒店的其它4个房间进行抽查，同样发现了针孔摄像头。警察取出针孔摄像头后发现这是一套完整且专业的设备。

  

**低门槛和高收益是主要推手**

  

利用针孔摄像头进行偷拍越来越多，以至于各类酒店、民宿、试衣间成为重灾区，用户防不胜防，究其原因有两方面：低门槛的犯罪途径和高昂的犯罪收益。

  

一方面，摄像头及储存设备的小型化、微型化、便宜化，使得偷拍隐私的门槛越来越低，在旅馆住宿甚至房屋出租行业中时有发生，成为侵犯公民隐私的洼地。在上述案件中，涉案人员虽然被依法处理，但是并未通报查处非法生产、销售环节的相关内容。

  

笔者通过关键词在电商平台搜索，便已发现大量售卖“针孔摄像头”、“微型摄像头”的店铺，月销量高者已有上万。随机进入一家店铺后发现其售卖的“微型摄像头”尺寸为1元硬币大小，商品介绍称可一键手机远程监控，商品价格大多在百元至数百元之间。

  

![](../Images/d97af31dfa690f95b042eea929ddbc2a.png "5.png") 

更有甚者直接售卖开关插座摄像机、挂钩摄像机、纸巾盒摄像机等多种款式，有“偷窥隐蔽”等多种功能特性。而买家仅需提供收件人姓名、地址、电话，还可以选择货到付款，不满意可直接退货等服务。

  

因此，有专家呼吁，网络销售平台要有严格的限制，一定要加大对商家在网络上出售这样的商品的限制，做到及时发现，及时清理，并且向公安机关提供相应的线索，同时相关部门也一定要严格地落实国家关于窃听窃视器材的生产销售的规定，依法严惩违规者，从源头上治理，摄像头乱象。

  

另一方面，在酒店尤其是情侣酒店偷拍隐私视频进行贩卖已经逐渐形成了一条利润丰厚的黑色产业链。据悉，每条偷拍的视频经过专业剪辑后，售价可高达数百元，不少非法网站甚至开设了专门的“自拍偷拍”板块。

  

同时，贩卖偷拍视频的QQ群、微信群等在网络社交平台并不少见。有人发帖往往以“宾馆直播”、“情侣偷拍”为噱头，吸引对此感兴趣的人加群，想要观看视频者付费购买或者直接购买会员。

  

这样的“商业模式”甚至催生了不少“著名”的偷拍者。据了解，这类偷拍视频往往会给男生打上马赛克，却将女性毫无保留的展现出来，甚至“露脸”还是其售卖的噱头之一。

  

**危险的摄像头**

  

**很明显，低门槛和高收益的诱惑下，偷拍已有愈演愈烈的趋势；一方面以此满足自己的丑恶的内心，另一方面借此牟取不当收益。**

  

但是，一般有点技术的偷拍者往往不屑于在酒店安装针孔摄像头，而是入侵家用摄像头，直接获取视频素材。用他们的话来说，一旦成功入侵家用摄像头，视频素材源源不断。

  

![](../Images/43de168ef939326a36c034a2cf3f1eb9.png "6.png") 

不可否认，随着人们的安全意识不断提升，在家里安装摄像头已经成为较为普遍的现象，既可监控宠物，又可以保护老人和小孩。因此，近年来居民房中摄像头数量急剧上升。

  

但是这些摄像头真的安全吗？恐怕未必。

  

2018年12月底发布的《2018年摄像头安全报告》显示，截至2018年11月底，全球共有2635万个摄像头设备对公网开放访问权限。

  

其中**越南位居第一，共有205万，约占20%；美国位列第二，共有183万，约占18%；中国位列第三，共有165万，约占17%；印度共有95万，约占10%；德国共有94万，约占9%。**

  

大量摄像头对公网开放权限给了黑客可趁之机，而黑客破解、买卖、偷窥于一体的视频摄像头网络黑产链已经成为全球各国网络安全的共同挑战。

  

此外，摄像头自身安全系数同样令人担忧。《2018年摄像头安全报告》显示，自2017年起，摄像头漏洞数量呈现爆发式增长，截至2018年11月，摄像头漏洞数量较2017年增长高达19%。

  

![](../Images/2136cdf58d3b7af0e67773c9254c895e.png "7.png")

 

其中，权限绕过、信息泄漏、代码执行等类型漏洞数量占比最高，分别占所有漏洞类型总数的23%、15%和10%。值得注意的是，厂商或厂商被攻击者入侵而在设备中制造的后门的硬编码、默认密码、隐藏后门等漏洞占比高达6%。

  

此前360安全大脑发布的国内首个智能设备安全报告——《典型IoT设备网络安全分析报告》也印证了这一事实。

  

360报告研究对象为IoT设备危害最大，也最为普遍的三大类安全漏洞：**远程弱口令漏洞、预置后门漏洞和敏感信息泄露漏洞在不同智能设备上的分布情况。**

  

数据显示，19.5%的智能摄像机存在上述常见**安全漏洞**，是三类设备中最“危险”的IoT设备。而在智能摄像机存在的漏洞中，远程弱口令漏洞占比最高，为91.7%。这一漏洞发生在智能摄像头上，可能导致摄像头变“偷窥狂”，泄露用户隐私。

  

![](../Images/dc6bd3587256a9030d55bd89abb69620.png "8.png")

 

当下与网络相连接的具有摄像功能的设备数量众多，安全性却常常被使用者忽视。一般网络摄像头的视频传输是基于通用通信协议，无需特定的摄像头客户端，这就意味着，一旦一个视频账号体系有缺陷且被渗透，将造成这一类账号体系被渗透的可能性直线上升。

  

同时，**廉价的摄像头、监视器等物联网应用产品被大量应用在生活的各个方面，但与智能手机频繁更新不同，视频硬件固件更新频率屈指可数，容易造成诸多安全隐患。**

  

因此，作为普通消费者，在家里安装好摄像头后，应在第一时间修改自家视频操控系统的默认用户名和密码，避免简单易破解密码给予黑客便利。同时，及时对硬件固件进行更新，加强漏洞修复。

  

此外，在外入住酒店的读者，若是没有专业的摄像头检测设备，可以通过手机检查房间内是否有针孔摄像头。

  

具体方法为，在漆黑的环境下打开手机摄像功能，围着房间进行拍摄，特别要注意正对着床的插座、排风扇等位置，一旦发现有红点即有可能是针孔摄像头。

  

**总结**

  

偷拍如此疯狂的背后，代表着的是极其低廉的犯罪成本。

  

在偷拍案件中，即便是发现了针孔摄像头并报警也难以抓到真正的元凶。大多数情况是顾客和酒店方面相互扯皮，最终不了了之。即便被警察抓住，在未传播和勒索的情况下，一般处以500元以下罚款或5日以下的拘留，情节严重的要处以5日以上10日以下的行政拘留。

  

倘若人们没有发现摄像头，那么你的一举一动都将被记录在存储卡中，某一天再被偷拍者取走，然后猥琐的欣赏或者是上传至网络。

  

但这对当事人尤其是女性的伤害是巨大的，甚至是留下终生难忘的心理阴影。人们和偷拍者之间的抗争不会结束，但是真的让人心累，且没有办法。
