# “武林大会”英雄集结！2019顺丰第三届信息安全峰会圆满落幕

现代版的武林应是何种模样？答案必然千人千面，但毋庸置疑的是，少不了“科技”的参与。

  

6月27日，一场科技感十足的“安全武林大会”——2019第三届顺丰信息安全峰会在深圳圆满落幕。

  

![](../Images/01842317183bc47237697c25f97c06dd.png)

  

本届峰会以“笃行·致远”为主题，来自邮政管理局、公安三所、中国电子技术标准化研究院、广东省公安厅网警总队、深圳互联网信息办公室、腾讯、光大证券、平安集团等政、企、学领域的数百位信息安全从业者齐聚一堂，交流行业技术与发展趋势，打破壁垒，共建信息安全新生态。会上，顺丰推出的“粹御数据安全解决方案”，更是吸引了各行各业的广泛关注。

  

![](../Images/f7b0b0a8a2931f039e8f7b225d3663bd.png)

  

顺丰科技CEO幺宝刚在开幕式致辞中表示，制度规范的顶层指导、各类企业的实践落地、资本方面的加持助推，都昭示着信息安全行业正在蓬勃发展。对此，顺丰将以保护客户利益为根、以安全运营为本、以行业互动为源，与各方伙伴携手共进。

  

![](../Images/d613c66bd0ae2d9cbb87e92cab55916e.png)

  

中国电子技术标准化研究院何延哲重点解析了APP专项治理，认为其是个人信息保护监管风向标。他提出用户在隐私保护上的意识，知识，观点非常重要，与大数据的发展息息相关。  

  

![](../Images/a8bcb94aae443714784014216c2a258c.png)

  

广东省公安厅网警总队何洪峰则解读了信息安全等级保护2.0。他梳理了等级保护制度的发展脉络，明确了等级保护是国家网络安全法的规定，向大家宣传网络安全法的主体责任，并提醒每个人都应牢记自己的主体责任，在合法合规的情况下进行工作。

  

**//****顺丰发布粹御数据安全解决方案，保障企业信息安全****//**

  

开幕式的重头戏，就是今年顺丰重磅推出的“粹御数据安全解决方案”。顺丰安全产品负责人刘小龙以“数据起源——企业核心数据安全的落地创新实践”为议题详细介绍了该方案如何全方位保护企业内部数据，保障各类企业信息安全。刘小龙表示，粹御数据安全解决方案涵盖数据资产管理、隐私数据管理、数据脱敏、数据追溯管理与数据加解密服务管理五大产品。

  

![](../Images/88823b09b2ca6a3ed11c37c7b9bec422.png)

  

“让数据安全的建设聚焦到数据本身，让数据安全的建设从数据的源头开始抓起。”刘小龙进一步提出，粹御数据安全解决方案拥有甲方视角、标准数据接口、框架式模块设计三大优势。顺丰将此解决方案推向市场，其对企业数据进行全方位保护的数据安全管理与定制化服务等功能点，均能被各行各业借鉴和运用，为各企业提供切实可靠的案例经验。  

  

**//****三大主题论坛同步召开，多方位探讨信息安全态势****//**

  

下午的分论坛主要分为云安全与数据安全、网络安全、威胁情报及态势感知三大主题。来自各领域的信息安全权威专家进行主题发言，共议信息安全热点话题和技术，直击行业发展的焦点与难点，探讨行业发展未来趋势。

  

**云安全与数据安全论坛**

  

在数字经济飞速发展的时代，数据就意味着竞争力。目前多数企业采用公有云、私有云或者混合云存储数据，云中的数据安全显得尤为重要。

  

![](../Images/9674f69541fc437a45564e5438b62636.png)

  

  

“

腾讯安全云基础安全总监吴昊分享了腾讯基于数据流安全方面的创新实践理念。

  

天空卫士合伙人、华南区高级销售总监曾东波讲述了天空卫士在中美贸易战下的数据安全应对之道。

  

Imperva中国区技术顾问路笑凡分享了Imperva在云环境下的应用和数据安全保护实践经验。

  

原摩拜高级安全总监李学庆讲述了目前行业内对于GDPR条例多样解读中的风险与误读。

  

Ucloud安全负责人宗泽从数据的生成，传输，存储，使用等角度阐述了在公有云，私有云以及混合云中数据安全的见解。

  

AWS的中国区云安全专家卢朝阳，分享了云上更安全、合规的自动化安全架构和部署方案。  

”

  

**网络安全论坛**

  

![](../Images/d09a962dd69c1ac2de10e144417fa443.png)

  

  

网络安全问题一直都是互联网发展的命脉和底线。本场论坛的主持人是安在CEO张耀疆。这也是他第二次担任顺丰安全峰会的主持人，他回顾了三届峰会的主旨，总结了今年网络安全的形势。

  

![](../Images/2e96d26ad0c72ad44babe0329ded89fd.png)

  

  

“

顺丰资深高级工程师苗圣法介绍了顺丰自适应寄递业务风控机制。

  

网易的安全负责人周深分享了在新时代背景下的隔离防御到业务导向的安全经验。

  

百度专家聂科峰讲述了百度在AIot背景下生态安全方面的考虑和布局。

  

行业资深专家黄承从黑和白的角度入手，探讨了领域内该如何"安全合力"。

  

招商局金融科技吴致远分享了基于开源软件打造企业安全建设的方法。

  

顺丰数据挖掘与分析工程师王南飞分享了顺丰基于自然语言内容处理的数据安全治理解决方案。

”  
**威胁情报及态势感知论坛**

  

对于每一个网络安全工作者来说，安全威胁是必须要面对和解决的问题。  

  

![](../Images/d8977dbac1a4f72cae0338d89a812320.png)

  

“

央视网网络安全部副总监黄乐从数据、策略、联动与展现等方面向与会嘉宾展示了央视网安全威胁管理体系的思路。

  

微步在线技术运营合伙人赵林林分享了情报的应用与落地，以及在企业中如何使用情报进行检测和发现威胁。

  

光大证券首席安全官刘嵩分析了移动安全在证券行业的发展趋势，以及移动态势感知平台在证券行业建设的必要性和独特性。

  

安恒信息高级技术总监杨锦峰分享在等保2.0下的全场景企业安全态势感知建设。

  

深信服安服安全总监李燕宏利用“切尔诺贝利”事件的案发处置现场，剖析情报在安全运营过程中的重要影响。

  

平安集团首席安全官陈建通过场景应用分享了平安集团就威胁情报技术在具体领域的实践情况。

”

  

![](../Images/464aeba7ee216d900bc690d798316bee.png)

  

**本届峰会不仅是一次跨行业交流，更是信息安全行业一个新的起点。在全球数字化浪潮下，将有更多的企业加入到数字化转型的队伍中来，越来越多的信息将被数据化。企业需采用更完善的数据安全产品来更新和完善数据安全策略，保障企业及用户信息安全。而顺丰也将致力于提高行业信息安全水平，携手各界，为国家信息安全及数字经济发展贡献力量。**
