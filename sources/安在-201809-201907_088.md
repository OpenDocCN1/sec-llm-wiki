# 不管好云同步，你手机里的不可描述或将一览无遗

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247533133&idx=1&sn=552aa870164e91b189e037a782ca8535&chksm=febc288dc9cba19bf87b0937b641b8848dc05c7668f0bd92993621b49b0183841c0c1f91369a&scene=126&sessionid=1681310704#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247533133&idx=1&sn=552aa870164e91b189e037a782ca8535&chksm=febc288dc9cba19bf87b0937b641b8848dc05c7668f0bd92993621b49b0183841c0c1f91369a&scene=126&sessionid=1681310704#rd)

“粽包分两髻，艾束著危冠”，又是一年端午，三日假期，好不快哉。

  

然而，就在这举国旅游的大好节日里，却也有人遇上了闹心的事。端午三日长假的第二日，便有一位安在女粉丝火急火燎地找到狗哥。

  

她之所以找狗哥，是她以为狗哥是技术中的大牛、安全界的黑客，黑手机，黑电脑，黑网络，黑天黑地黑空气，无所不黑，无所不能。所以，她让狗哥务必要帮她。

  

![](../Images/ebc504af9a96ee20c30b686ca78c6cd4.png)

  

为什么要强调是安在“女粉丝”，乃是因为，遇上这种事，女子往往比男的更加在乎和焦虑。那究竟是什么事？且看下文。

  

![](../Images/8b63ff0c7a165ad05d7fff67f79d5a74.png "端午节 划龙舟分割线")

  

废话不多说，先上聊天截图。

  

![](../Images/814b88b82912ebd7d49a3b1847011672.png)

  

前因后果一目了然。原来，女粉丝买了一台二手小米手机，没注意到别人的云同步账号未退出，使用两三个月方才察觉这问题，照片、通讯录等信息早已同步到云端，并且她对照片的同步问题尤为在乎。  

  

看到她如此急切的言语，大概是拍了不少“爱美”的照片。

  

![](../Images/e20888ca119f03f1a35679570f2aac14.png)

  

狗哥实在爱莫能助，只能长叹道：“妹子啊，你也太大意了啊，拍摄私密照片，也不事先看看手机的安全性，互联网时代，联网做过的事，不是什么事都能亡羊补牢呀。”

  

当然，这段话只是狗哥心里默默地说，若真说给她听，便是隔岸观火、火上浇油。

  

随后，她又发来几张云同步的截屏图片，狗哥截取了主要部分，并打码了一些私密信息，诸君且看：

  

![](../Images/42fdc01abe21a5a3afffb68dfd868c9e.png)

  

![](../Images/b52e73029ffe8d0cb6f54a277031a7b3.png)

  

图片中，标红的部分就是妹子最在乎的照片同步，时间显示，同步的时间为昨日。不得不说，这照片同步得可真及时。

  

此外，手机云端同步的类别，除了相册之外，还涉及到联系人、短信、通话记录、录音机、音乐、便签、无线网、日历、浏览器、安全中心、智能助理等，可谓是全方位立体式地上传隐私。

  

![](../Images/39a2f238bdeb504fd47ac877b9b1026d.png)

  

并且，还有“实时同步模式”，从查找手机选项中可以看到，云账号拥有者，可以实时查看到使用者的地理位置。如下图所示：  

  

![](../Images/405907f6dd94ee1ce3d99e13c9788cd8.png)

  

图片显示：“当手机丢失时，您可以在任何能联网的设备登录i.im.com用于定位（手机）……”故此，云账号原主人可以通过登录账号，定位到该女粉丝的位置。

  

颇为麻烦的是，如果没有原账号绑定手机的验证码，你连退出账号都无法做到，只能耐着性子，一步一步关闭掉所有云同步选项。

  

若想彻底解决这个问题，除了找到卖家之外，据查询网络，有刷机高手说只能通过强制刷机的方式来解决。

  

狗哥不是刷机专家，故而对此未作深入研究。不过某宝上大神很多，所以狗哥也建议那位女粉丝，去某宝找刷机大神试试。当然，刷机同时也要注意保护自己隐私，多留个心眼吧。

  

![](../Images/1ab357ee7e55d62b8ba46912aa78a0ee.png)

  

其实，说了这么多，或许很多人以为狗哥在黑小米。实则不然，因为这不光是小米云同步会遇到的问题，任何一家手机云服务，都会面临这个问题。只不过小米云服务比较出名，用户众多，所以反映出的问题相对多些。

  

如今，几乎所有品牌手机，都有各自的定制系统和云服务业务。

  

并且，随着各家物联网设备的逐渐增多，云账号自然也会多终端同步，若不仔细设置，很可能会让自己隐私暴露在众目睽睽之下。

  

随后，狗哥简单搜索网络，不难发现，随意登录云服务账号，而导致信息泄露的情况屡见不鲜，且场景多样化，令人防不胜防。

  

![](../Images/f9e9621cb471de6f4ce64f0d1ce0deab.png)

案例一：云相册多终端同步导致尴尬

  

下图中的网友，就遭遇不同设备间云同步导致隐私相册被暴露。

  

![](../Images/b8f7223570c99de65aaface63dc9c18e.png)

  

由图可知，手机微信图片会通过云相册，同步到小米盒子中，继而在电视里显示出来。

  

手机是私人物品，而电视是公用设备，如此一来，岂不乱套？

  

![](../Images/7f3933fc6626370f425c7886ad36d3a2.png)

  

试想一下，你和女朋友出去旅游，一路秀恩爱拍照，照片全部同步到云端相册。家人七大姑八大姨打开电视，对着你各种隐私照片面面相觑，那将会是一种怎样的场景？

  

![](../Images/22df1d46ba5ca4d878b85526a22b1823.png)

  

![](../Images/f9e9621cb471de6f4ce64f0d1ce0deab.png)

案例二：手机过户导致隐私泄露

  

小张使用某款手机，用手机号码注册了该手机云服务账号。后来他换手机号码，就把原号码过户给一个朋友。

  

巧的是，他的朋友也使用同款手机，于是就用该手机号注册云服务，可系统提示手机已注册，便通过手机验证方式修改密码，继而登录了云服务。

  

结果，朋友在云存储中，看到了小张大量的照片和通讯录信息。

  

幸好，朋友将这事告知了小张，小张既庆幸又后怕，立即让朋友删除了云端存储资料，并重新修改了云账户的关联手机号，这才解决问题。

  

![](../Images/fe97ca6a270a4421d01a158b998db415.png)

  

试想一下，如果手机号码不是过户给朋友，或者朋友心存异心，或者手机号码是自然停机更换了主人，云存储资料信息是不是就会完全泄露出去。  

  

一旦有过于私密的信息被别有用心的人获得，轻则敲诈勒索，重则全盘泄露出去，想想就极端可怕。

  

![](../Images/22df1d46ba5ca4d878b85526a22b1823.png)![](../Images/f9e9621cb471de6f4ce64f0d1ce0deab.png)

  

案例三：随意登录云账号导致混乱

  

女网友“璃璃”拥有某品牌手机的云服务账号，她见哥哥买了一步同品牌的新款手机，便借来试玩，并登录了自己的云服务账号。结果，她哥哥的联系人、短信、照片全同步到了自己手机上。

  

后来，璃璃手机不小心摔坏了，就借表姐的同款手机玩，并登陆了自己的云同步账号。

  

结果，等璃璃自己的手机修好后，又把表姐的短信、联系人、照片全都同步到了自己手机上。

  

于是，璃璃的手机同时同步着哥哥和表姐的信息资料，搞得她非常混乱，同时，她的很多照片和信息，也同步到了她哥哥与表姐的手机上。

  

![](../Images/0f5018e4e8b815687c6237d796cb45ef.png)

  

试想一下，璃璃要是看到哥哥和表姐的各种私密信息，还有璃璃自己的私密资料被哥哥姐姐看到，那将会是怎样的混乱不堪。  

  

![](../Images/22df1d46ba5ca4d878b85526a22b1823.png)

  

![](../Images/f0b3a6abea89b9e422a654398919588c.png)云时代个人的云安全不容轻视![](../Images/13c2933115d1eee6abbc485764bd292a.png)

  

如今，不光万物互联，而且是一个云端无处不在的时代。

  

以往，我们都经常会听到，企业上云的安全，很少收到提醒，个人上云同样需要注意保护隐私。

  

在前些年，手机号码一旦弃用，或被别人得到，与号码绑定的支付宝、微信、银行卡信息，有可能会被别人获取。但随着各方面保护系统的升级，现在单凭一个手机号，很难窃取别人的钱财。

  

但是，云服务却不一样。有媒体记者测试了多家云服务账号，在手机端登录，只要是账号和密码匹配，无需验证其他信息，就能轻易登录云账号，并且轻松同步云端存储的一切信息。

  

![](../Images/55bdd763bd7a5f9f5d6c9de0db796dd3.png)

  

  

由此可见，个人云端信息安全，是一个尚未被普遍重视的问题。

  

任何情况下，都不要指望服务商来替你规避一切风险，自己的云端，还是要靠自己管理好。

  

尤其是买了二手手机的朋友，以及准备弃用手机号的朋友，务必确认手机未绑定别人的云服务账号，确保手机号绑定的重要账号全都解绑。

  

云时代，信息安全不只是说说而已。一不留神，就可能懊悔不已。

  

最后，女粉丝希望狗哥在以她为鉴成文之后，拜托广大网安圈的高手，可否还有其他方法，帮她解决云端私密信息和手机云账号的问题。
