# 你名下银行卡若被诈骗份子滥用，后果很严重

新闻显示，打工两个月变“负翁”，小伙莫名“欠”银行999亿。由此，引发了部分群友热烈的讨论。讨论的内容主要集中在银行卡安全上。以下为谈论的部分截图。

  

![](../Images/d9da4194b1e43ed6e61b1bb28f6a3a64.png)

![](../Images/10d39cdb1d00d44ad69c3729cc158959.png)

  

这则新闻究竟是怎么回事呢？狗哥查询查询得知，杨先生在深圳一家公司工作2个月，账户上本来有钱的工资卡却一直用不了，到银行一查竟然发现，自己的卡里显示欠款999亿元。

  

![](../Images/226a64eab43621ced5a10a020ace65a9.png)

  

想必杨先生的内心是崩溃的，懵逼的，无语的。

  

于是，杨先生赶紧联系帮忙办卡的业务员，调查之后发现，问题出在杨先生的另一张银行卡上。原来在今年1月份，杨先生曾将自己的一张卡借给了朋友，而目前这张卡因为涉嫌电信诈骗行为，已经被冻结。

  

银行的工作人员则表示，杨先生的工资卡是储蓄卡，不能透支，所以手机银行上显示的欠款999亿元只是数字，并不是真的欠钱。而且杨先生的7700多元工资依然还在卡里。但是999亿这个数字究竟是怎么出现的，工作人员并没有给出解答。

  

由于涉嫌电信诈骗行为，如今杨先生已经上了银行的黑名单，个人征信受到影响，如果不尽早处理，其他银行卡也可能没有办法使用。目前杨先生已经向当地派出所报案，等待进一步处理结果。

  

![](../Images/7e041b7da1162e6a12afb72d7f283315.png)

  

人在家中坐，锅从天上来啊！不过，杨先生也并不算完全没有责任，自己的银行卡，岂能随意借给别人？

  

不得不说，群友的担心都是有道理的。如今，信用是每个人的一笔无形财富，一旦产生信用污点，买房、出行等都会受到很大的影响。

  

更为值得警惕的是，犯罪分子盗用你的身份信息，而产生的信用污点，也会对你的信用造成影响。

  

![](../Images/e61dc75c33b50f1f15b36d17c36df3ef.png)

  

那么，如何查询自己名下的银行卡，有没有被盗用，或者存在自己完全不知道的银行卡呢？其实也有查询途径。

  

银行卡分两大类，即信用卡（贷记卡）和借记卡。

  

信用卡可以到中国人民银行官网查询征信报告，即可显示自己名下共有多少银行卡。

  

至于借记卡，据查，目前只能一行一行地查，你可以到银行柜台凭身份证查询，也可以拨打各大银行客服电话，即可查询是否办卡。

此外，如今我们除了银行卡外，还常用到另外两个与金钱有关的账户——支付宝和微信。

  

大约在2013年时，狗哥注册第二个支付宝账户时，发现注册名额已满。

  

惊奇之下查询发现，狗哥名下居然有五个完全不认识的支付宝账户。一怒之下，通过实人认证加支付宝客服协助，最终注销了那五个账户。

  

![](../Images/74ab6cf9e513bfaa44ac5fc300709c7a.png)

  

或许很多人压根就没查过，自己名下究竟有多少支付宝或微信账户。其实查询起来也不难，方法如下：

  

首先是查询名下支付宝账户，登录电脑端支付宝首页，点击“账户设置”。

  

![](../Images/ec17a1c66205375332b90cff1b553728.png)

  

然后在下一页面中，找到“查看你名下的支付宝账户”

  

![](../Images/7b3428454e6605b06484b91ad2474218.png)

  

点击“查看”之后，即可看到自己名下所有支付宝账户，若是有陌生账户，可联系支付宝官方客服，即可解绑账户。

  

![](../Images/dea6ac65e9da65f8f9c5b1da95742df0.png)

  

查询名下微信账户，流程比支付宝要稍微复杂些。

  

打开微信APP，依次点击“我”-“支付”-“钱包”-“帮助中心”。“帮助中心”位于界面正下方，可能不太显眼。

  

进入“帮助中心”后，会看到依次有三个主列表，分别为“账户问题”、“实名认真”、“银行卡”。点击“实名认证”，再选择“实名规则”。

  

![](../Images/87740fc11849209d4d0381214f087a21.png)

  

进入实名规则，即可看到一堆问题列表，拖到最下面，即可看到“身份证能注册几个微信账户？”

  

![](../Images/8e33049d5f6732a2fb606ddd08adf591.png)

  

点击进去，选择下方“联系客服”，提交相关资料，即可看到自己名下注册了哪些账户，如果非自己注册的账户，可以选择注销。

  

![](../Images/be89da94728f91decbd4bd226cf4b07e.png)

  

![](../Images/0e0e1ee0c8043599da79b496bd598361.png)

  

信用社会，自己的信息格外重要。保护好自己的银行卡和金钱账户，远离诈骗份子，否则后果不堪设想。
