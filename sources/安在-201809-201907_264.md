# 有一颗不定时炸弹，一直都在我们掌心

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247533038&idx=1&sn=ffb96a5543ba023617df6d5b93f92f2f&chksm=febc2b2ec9cba23892678c46e5c2291ac7da8ab3eac6997e9a0c7fcb07f9664571881f78172c&scene=126&sessionid=1681310714#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247533038&idx=1&sn=ffb96a5543ba023617df6d5b93f92f2f&chksm=febc2b2ec9cba23892678c46e5c2291ac7da8ab3eac6997e9a0c7fcb07f9664571881f78172c&scene=126&sessionid=1681310714#rd)

我凝视着掌中的手机，似乎掌控着它发出的每一条信息。

但我却不知道，在我看不见的地方，它传出去多少隐私数据。

无论它是主动的，还是被动的。

一切恐惧，源于我的看不见、不知道！  

**撰稿 | 走狗**

**编辑 | 图图**

  

“TMD，她果然去酒店开房了！”

大学宿舍微信群里，舍友小吕留下了一句话和一张手机截屏，接下来便是长久的沉默。

毕业数年，当年大学时代几位舍友，如今依旧天天吹牛打屁，无话不谈。虽然现在天各一方，却难能可贵地保留了最真挚的友情。

到了而立之年，大家事业小成，但情感之路却不一定一帆风顺。小吕就是典型，时常在群里抱怨女友种种问题。

前段时间，小吕怀疑女友给他戴了绿帽，便偷偷在女友手机上安装了实时定位APP。于是便有了微信群里那张截屏图，正是小吕女友当时所在的位置——某家快捷酒店。

大白天，无缘无故跑到办公室附近的酒店，确实让人不免多想。

![](../Images/4c6b4f526ccb50b4d897eda41d163253.png)

  

![](../Images/8ce14314621f716a8cbdf3a0a8f0e602.png "动态黑色音符")

  

  

但我却是心中一紧，原来真有实时定位的APP啊。连忙打开手机，找到APP列表，从上到下仔细翻查一遍，最后长舒一口气，我手机里没被谁偷装实时定位APP。

  

片刻之后，我的神色又凝重起来。在你不注意的时候，身边的人可能会在你手机上动手脚；在你看不到的地方，那些技术高超、心怀歹意的黑客们，他们又会对你的手机做些什么？  

![](../Images/06012f1dbdb0e711c0a372d5bc794ec5.png)

我摩挲着整日与我形影不离的手机，不由陷入沉思。感觉有一颗不定时炸弹，一直都在我们掌心，你不知道它那天会出问题，引爆你隐私泄露的口子。  

  

莫非是我太过敏感？于是我找了几个小粉丝，看看他们如何看待手机安全问题。

  

问题皆为：“我是安在狗哥，问你一个问题，希望你如实详答。你觉得每天抓在手上的手机安全吗？手机会泄露你的隐私吗？你最担心手机泄露你哪些隐私？”

  

我收到以下几个回复。

  

![](../Images/4356a5f665f089c330bf50aaf9a45195.png)

![](../Images/08885afe72bbc835c165a4bd341ca1a9.png)

![](../Images/791e7d32c289cc02aa40d3f2d23f5393.png)

![](../Images/daec64a7c63bf4071601864097111b99.png)

  

原来，大家都和我一样，没太多安全感。最担心的还是泄露自己的隐私照片、私密聊天、通讯录、地理位置等等。  

  

原来，大家害怕泄露的隐私都差不多，我们都活在一个假装安全的万物互联的世界里，因为谁也不敢保证，自己在网络上百分百安全。除非抛弃一切电子产品，回归原始状态，到深山隐居，与世隔绝。

  

事实上，正如德国8.1分电影《我是谁：没有绝对安全的系统》所描述的那样，“知道吗，外部世界的人们……在寻求自我麻痹，根本不知道世界是怎么转的。安全，大家都想要安全，可根本就没有安全。一旦你领悟到这一点，那么……剩下的问题就是你想要如何分享这个世界。”

![](../Images/bfd53c2b85c104729e5f5f1c7765b627.png)

网络世界真的并没有想象中的安全。就在3月5日，Google发布安全公告，公布了一个可以用来ROOT目前国内外主流Android手机的“水滴”漏洞（编号CVE-2019-2025）。  

  

看到“水滴”，不由想到《三体》中拥有惊人破坏力的宇宙探测器——水滴。它由强互作用力材料所制成，表面光滑，温度处于绝对零度，原子核由被强互作用力锁死，无坚不摧。

  

在末日之战中，仅一个水滴就摧毁了人类太空武装力量1993艘战舰，并且封锁了太阳的电波放大功能。

![](../Images/8b9666d2e6ec8ab3ab165dfbe51eadab.png)

没错，本次“水滴”漏洞的名称，正是来源于《三体》中的水滴，寓意着这个漏洞同样拥有惊人的破坏力。  

  

“水滴”漏洞的破坏力究竟多强？据了解，该项漏洞攻击力可谓“稳准狠”，并且像狗皮膏药一样纠缠难解。

  

就目前发现来看，“水滴”漏洞可实现较稳定的任意地址读写、写任意内容、信息泄露，还可能用于沙箱逃逸，并且每触发一次漏洞便可以任意写一次、读一次。

  

这段话什么意思？通俗来说，就是黑客可以通过该漏洞，侵入你手机，任意读取你手机中的任何数据，包括照片、聊天记录、通讯录、存储文件等。还可以写入任何信息，包括恶意程序、不良文件等。你手机中的任何数据，黑客都能窃取，你不但察觉不了，而且还抓不住他，因为他超级狡猾，连逃跑的线路你都无法定位，甚至连一些专业人士都可能掌控不了。

  

更加令人不安的是，Google现有的内核安全缓解措施，对于这类能够任意地址读写的漏洞，暂无有效的防御策略。

  

或许有人说，Google官方每年公开的内核漏洞多达数百个，但这些年我手机还不照样用得好好的。

  

实际确实如此，但这数百个漏洞中，大多是Google官方自己发现的，然而真正能够成功提权的漏洞寥寥无几。

  

打个比方：Android是一艘木船，以前数百个漏洞，就像用缝衣针扎出的孔洞，拿根牙签就能把洞给堵住。而此次“水滴”漏洞，却是船底裂开了一块木板，水哗哗涌入，堵一袋沙袋都不一定挡得住。

![](../Images/3930f808e99016e96548b349f07a124a.png)

“水滴”漏洞虽然可怕，但也不是无药可救。虽说没有绝对安全的系统，但只要漏洞的发现，比恶意黑客发掘得早，安全便在可控范围之内。  

  

本次“水滴”漏洞的挖出，并非Google官方的功劳，而是国内一家知名安全厂商——360安全团队“360 C0RE Team”。

  

360 C0RE Team发现“水滴”漏洞后，成功利用这一漏洞，绕过了代表Google安卓目前最高水平的内核防护机制，完成了针对Google旗下三款Pixel系列机型的完美ROOT。

  

要知道，Pixel 3手机是由Google公司亲自操刀，且在去年秋季才发布的新款安卓手机，拥有着目前最强的内核防御巅峰水平，这也是该手机在全球范围内第一次“被攻破”。Pixel 3手机的失守，就意味着绝大多数安卓手机安全性岌岌可危。

![](../Images/f95bef6427cc160273772260755f6761.png)

如此说来，是不是该扔掉手中的安卓手机？  

  

其实不然。

  

360安全大脑早于2018年8月份，就成功发现了“水滴”漏洞的存在，并确认了其具体危害和可影响的范围。9月28日，360正式将该漏洞提交至Google。11月初，360提交漏洞利用至Google，并于11月6日，协助Google实现Linux kernel在主线上对该问题的修复。

  

也就是说，Google官方在3月5日发布“水滴”漏洞时，意味着已经对该漏洞完成了修复，抢在全球各大黑客之前。  

  

Google官方不傻，他们绝不会在漏洞还没修复时，对外宣布漏洞的存在，否则岂不是搬起石头砸自己的脚。

  

另外，在此之前，Google官方早已多次与360就此漏洞进行沟通，并向360表达了诚挚的谢意。

![](../Images/950de17ce5da04fe4d9ccd127ed3c60a.png)

这一次“水滴”漏洞，Android security bulletin也公开致谢了360安全团队，并奖励漏洞奖金14000美元。

![](../Images/96cf56ecd725053dc421073b20f05f6b.png)**Android security bulletin官方致谢360**

因此，我对360 C0RE Team产生了巨大的好奇，这是怎样一个安全团队，能在Google和全球黑客之前，挖掘出如此巨大的漏洞。  

  

查阅相关资料发现，360 C0RE Team是一个专注于Android内核及Framework安全攻防技术的安全团队，此前已经多次全球首家做出通杀型ROOT方案。

  

对，你没看错，你想折腾你的安卓手机，通过Root获得超级权限，很可能360 C0RE Team在背后默默帮助了你一把。

  

360 C0RE Team不光为我们Root手机做出卓著贡献，还向Google、Qualcomm、华为等厂商报告了多项安全漏洞，累计获得上百次致谢。

  

在Android系统安全防护日臻健全的时代，可以实现通杀的漏洞非常稀缺，正因如此，这种漏洞也是黑灰产梦寐以求的攻击突破口。

  

可以想象，安全研究人员如果不能赶在他们之前发现并修补该漏洞，一旦被黑灰产掌握并大规模利用，造成的损失将难以估计，那我们整日握在手心的手机，就真成了一颗不定时炸弹。

  

我静静地摩挲着手机，重重松了口气，好像拆除了炸弹引信一般。

  

庆幸之余，我们当感谢众多像360 C0RE Team这样的安全团队，正是因为有他们的默默守护，正是源于他们对最新攻击技术的不断研究，才能实现持续有效的防护，我们才不至于身陷“艳照门”，才能放心大胆地与亲密之人视频通话，才能在网上与亲朋好友畅所欲言。

  

正如电影《我是谁：没有绝对安全的系统》中主角MRX领悟到的——“最大的安全漏洞并不是存在于什么程序或者服务器内，人类才是最大的安全漏洞。”

  

是的，手机系统最大的安全漏洞，其实就是心怀歹意的黑灰产从业者，而最强的安全守护，也恰恰是严守漏洞、竭力修复的安全从业者。

  

致敬360安全团队，致敬360 C0RE Team。
