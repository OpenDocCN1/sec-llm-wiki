# 2018，网络安全盛会知多少？

此前，安在（AnZer\_SH）曾通过针对各类会议的统计和分析，整理出《2017中国网络安全会务调查报告》，并对2018年度商业价值最大的十大网络安全会作出了整理和推荐。

![](../Images/1f37892ee684968148b7d48832847c93.png)

  

时隔一年，虽然榜单上的网络安全会务大部分如约而至并日渐成熟、规模更大，但“国际前瞻信息安全会议”、“ISS网络安全生态峰会”、“全国网络安全等级保护技术大会”和“中国信息安全用户大会（UCON）”却意外地缺席了今年网络安全会务的战场。

 

但，在刚刚过去的2018年，我们除了感受到冬夜里刺骨的寒冷，却也同时见证了包括区块链的狂欢，全球范围内数以万亿计个人信息数据泄露等在内的众多网络安全事件的发生。随着海外GDPR的生效以及国内《网络安全等级保护条例》征求意见的发布，监管力度也得到了前所未有的加强。

 

在这样一个全民关注网络和信息安全的时代，网络安全会务并没有因为少数人的缺席而减少，反而呈现多点开花，星火燎原之势，在全国范围内越来越多的地域、越来越细的领域里落实和开展起来。不仅如此，我们更是迎来了多个全球顶级黑客大会在中国的落地，也让国内网络安全从业者的声音传播到了全世界更多的角落。

 

4月20日，在全国网络安全和信息化工作会议上，习近平总书记着重强调树立网络安全意识，就做好国家网络安全工作提出明确要求，为筑牢国家网络安全屏障、推进网络强国建设提供了根本遵循。

 

那句“没有网络安全就没有国家安全，就没有经济社会稳定运行，广大人民群众利益也难以得到保障”的指示至今仍余音绕梁，这也让网络安全会务的重要性上升到全新的高度。

 

为此，安在（AnZer\_SH）特进行了统计与梳理，带大家一起重返2018，回顾这一年国内影响力较高的网络安全会务大事记。（此为作者一人片面之观点，如与诸位多有出入或稍有遗漏，还望海涵）

**国家网络安全宣传周**

  

9月19日，2018年国家网络安全宣传周开幕式在成都举行。本届宣传周以“网络安全为人民，网络安全靠人民”为主题，9月17日至23日期间举办网络安全博览会、网络安全技术高峰论坛等活动。  

  

![](../Images/296e7ad5fc3e2a090adecef1533df8d3.png)

  

![](../Images/051d514d53f0020398b882b577dac50d.png)

  

宣传周期间，教育部、工业和信息化部、公安部、中国人民银行、共青团中央、全国总工会分别在成都组织开展了校园日、电信日、法治日、金融日、青少年日、个人信息保护日等主题日活动。

  

18日校园日中，发布了成都市中小学生媒介素养成果报告，面向成都市学生发起网络安全倡议书，通过开展网络安全主题班会、情景剧表演等系列活动，丰富学生网络安全知识，培养学生养成文明用网习惯，提升学生网络安全意识和防护技能。

  

19日电信日中，通过主题论坛、创意H5互动传播、现场竞答互动、网络安全知识进基层等形式，向社会广泛传播网络安全知识，引导公众提升网络安全意识，共同维护网络安全。

  

20日法治日中，举办了全国首届网络安全员法制与安全知识竞赛、第四届互联网安全与治理论坛，以提升互联网企业等联网单位的安全责任意识和全社会的网络安全意识。

  

21日金融日中，举办了中国金融网络安全论坛，邀请国内知名专家学者围绕支付安全发表演讲，开展金融网络安全进社区活动、金融网络安全知识现场脱口秀和现场采访活动，搭建金融网络安全体验长廊，展示汽车银行、无人银行等新兴金融场景。

  

22日青少年日中，开展了网络安全绘画作品展示、网络安全微课展播、全国青少年网络安全微倡议接力、青少年网络安全知识互动答题游戏、“网络安全·青年的责任与担当”微博话题和短视频征集等活动。

  

23日个人信息保护日中，举办了个人信息保护宣传“12351”计划启动仪式暨成都市总工会网络安全进企业、进工业园区、进社区活动，组织动员1000个基层工会组织，发展2万名网络安全宣传员，走进3000家企业，面对面接触50万名职工开展网络安全宣传，通过线上线下宣传，直接覆盖1亿职工网民。

  

**4.29 首都网络安全日**

![](../Images/13c993a706a5c7136c9d0f3c9b57d4ee.png)

中国工程院沈昌祥等7名院士、100余名专家学者、20余所高等院校参加了本次安全日活动，150余家国际知名的网络安全与信息企业在北京国际互联网科技博览会上展示最新的互联网尖端科技以及领先的互联网科技成果。

**NSC中国网络安全大会**

  

6月13日，备受关注的第六届中国网络安全大会（NSC 2018）在北京国家会议中心盛大召开。大会由赛可达实验室、国家计算机病毒应急处理中心、国家网络与信息系统安全产品质量监督检验中心、首都创新大联盟及百家行业联盟共同主办。来自国内外的40多位顶级网络安全专家和学者发表了精彩演讲，与2000多位与会者聚焦“国际视野下的网络安全”，共议信息安全热点话题与网络安全新技术。

  

![](../Images/ffb8ef59cb392816471065ba7aead5c9.png)

  

公安部网络安全保卫局副局长钟忠出席大会并致辞，他针对目前网络安全行业关注的三大问题：大数据安全、人工智能安全、互联网的全面融合带来的新的网络安全问题发表了观点。

  

关于大数据安全，钟副局长表示，“最近欧盟通用数据保护条例的实施，更提示我们要在全球化视野下思考大数据安全问题，应当在法律、政策、监管、技术多个维度视角下去思考、保证大数据安全”。关于人工智能安全，他指出要警惕高度依赖人工智能的自动化运行的系统网络，一旦遭受攻击可能会出现闪电式的崩盘。需要加快推进制订，统筹协调人工智能安全和发展的政策，要推进在网络安全领域从信息优势转变为技术优势的进程。

  

会议围绕“技术创新、自主可控”、“区块链安全”、“个人信息保护”、“5G安全”、“基于人工智能的网络安全”、“人才培养”、“工控智能终端安全”、“大数据网络安全等级保护”、“云和大数据安全”、“黑客攻防”共十大热词解析网络安全新动向。

同时，第五届“云鼎奖”颁奖盛典也在主题论坛同期进行了盛大的授予仪式。共计30家企业及杰出个人荣获奖项，五大类别包括2017-2018年度中国领先技术奖、2017-2018年度中国领先品牌奖、2017-2018年度中国潜力企业奖、2017-2018年度优秀应用案例奖、及2017-2018年度中国影响力人物奖。

  

**中国信息安全法律大会**

  

2018年12月17-18日，第九届中国信息安全法律大会在北京顺利举行，大会以“网络安全法治：过去、现在、未来”为主题，回顾我国网络安全法治30年的成果，关注新一代信息技术背景下的突出问题和事件，探讨未来网络空间安全治理规则构建，设立主论坛和“数据治理与安全合规”“安全漏洞治理”“网络社会创新治理”“网络犯罪治理”“开源软件与供应链安全”“密码法”（闭门）六个分论坛进行专业研讨。来自政府机构、科研院所、高校、互联网企业等网络安全领域的领导、专家600余人参加了会议。

  

![](../Images/00df81220bfbd133f15cf0db70e681eb.png)

  

会议由国家密码管理局、公安部网络安全保卫局、中国网络空间研究院指导，中国信息安全法律大会专家委员会主办，公安部第三研究所、西安交通大学苏州研究院承办，公安部第三研究所网络安全法律研究中心、西安交通大学苏州信息安全法律研究中心协办。

  

据了解，本次大会是我国信息安全法学领域从2010年至今连续召开的第九次全国性法律盛会，大会始终以推动国家政策法律的落实为原则，致力于构建政府与企业、国家与社会、技术与法律协同交流的平台，在业界产生了良好的影响。本次大会同时发布的两项重要研究成果：《从网络治理到网络空间安全—中国网络安全法治30年回顾与展望》和《中国云计算安全政策与法律蓝皮书——云计算平台相关主体的法律责任研究》，回顾过去，展望未来，对网络安全法治研究意义重大。

  

  

**EISS企业信息安全峰会**

  

2018年4月27日，安全+在北京成功举办了EISS-2018企业信息安全峰会，峰会的主题延续了前两届在上海的“直面信息安全挑战，创造最佳实践”。将近300位的企业信息安全专家齐聚一堂，就企业信息安全建设，云安全，数据安全，软件安全，UEBA，APT等话题展开热烈的讨论。

  

![](../Images/9742b641ce777da5eba9aa56797ba59e.png)

  

11月30日，EISS-2018企业信息安全峰会——上海站个在上海银星皇冠假日酒店功举办。引近400位的企业信息安圈专家就企业数据安全实践、企业安全管理、态势感知、物联网安全、云安全、密匙管理、DevSecOps等话题进行了深入的分享。

  

  

![](../Images/a0cc7e4978a86dc06400ba537774cd25.png "简约动态针分割线")

  

**题外话：DEF CON和HITB走进中国**

  

值得一提的是，除了众多的网络安全会务以外，百度和京东安全分别与DEF CON和HITB达成合作，成功将这两个全球最顶尖黑客狂欢盛会引入中国，让2018年国内网络安全会务更添异彩。

  

**DEF CON CHINA**

  

5月11日，万众瞩目的DEF CON CHINA终于正式揭开了面纱。令人兴奋的是，本次DEF CON带给了我们太多的惊喜。

  

![](../Images/1b78b06eec68344e0fe691131101c5f8.png)

  

作为安全行业顶级盛会、“黑客界的奥斯卡”，25年来，DEF CON一直在美国本土举行。此次DEF CON CHINA是在海外举办的第一次，并且第一站便选择和百度安全强强联手、落地中国，实在是国内安全爱好者的一大幸事。

  

和会前披露的信息一致，DEF CON CHINA不仅沿袭了原生的赛制和流程，还增添了不少新的亮点：干货和脑洞兼备的演讲、可以动手参与其中的破解体验、引入人工智能的BCTF，将在三天时间里为安全爱好者带来一场无与伦比的盛宴。

  

![](../Images/50d255e0c92fee25e8829cbacb34736e.png)

  

与此同时，百度也根据自身优势，通过DEF CON官方call for paper渠道投稿,被选中如指纹、虹膜、人脸、静脉等生物识别village，还有BCTF中首次登场的AI战队，在赛场中上演了激烈的人机、机机对抗。

  

DEF CON创始人Jeff Moss谈到 “双方携手将DEF CON成功引入中国，在DEF CON发展进程中是个里程碑事件，将对国际的极客精神和安全从业者的跨国界交流合作产生深远的影响。”JeffMoss同时对于百度安全将赛事引进到中国，进行本土化落地和创新表示感谢。

  

百度安全事业部总经理马杰表示：“中国安全从业者需要开源共享、追求极致的精神，这种精神是不分国界的，但是需要本土化的成长土壤。”DEF CON一直以来所强调的对技术前沿和边界的探索精神，正与百度安全崇尚开源共享、追求极致的精神达成一致，两种文化相遇必将发生精彩的碰撞与融合。

  

**京东HITB**

  

10月31日至11月2日，由京东安全和HITB联合举办的2018京东HITB安全峰会在京举行。HITB是全球安全研究人员每年必参加，全球影响力排名前三、长期活跃于欧洲和亚太地区的安全技术峰会。本次与京东安全联手，是HITB成立15年来首次来到中国。

  

![](../Images/17e589bb2a922f43d0eafa5ddd4bb6a7.png)

  

本次峰会上，Benjamin Kunz Mejri、James Forshaw、Nikias Bassen等享誉国际的知名极客与来自谷歌、腾讯、360等多家中外知名公司安全大咖齐聚一堂，聚焦前沿安全技术，从全球视野、战略高度共同探讨如何应对未来世界网络威胁。本届峰会包括11.1-11.2技术日，除了传统的极客干货分享和CTF比赛之外还有CommSec Village，众多好玩有趣的硬件破解项目和智能IoT设备展也让人们在现场感受到了极客文化的魅力。  

  

京东集团CTO张晨表示：“极客是一群富有创造力，天生热爱技术、探索技术的人，世界科技发展至今天，极客起了很大的作用，京东愿与全球极客同仁共同建设安全可信的网络世界。”京东首席信息安全专家Tony Lee和HITB创始人Dhillon Kannabhiran也同时出席，共同开启了信息安全的国际交流大门。

  

不同于传统大会的单纯分享，京东HITB将技术演讲与技术培训、科技展示和攻防比赛相结合，打造出一场酷炫有趣的安全冬令营。在HITB有一个传统活动，就是要教会小孩子编程和一些基本的安全知识。Tony在致辞中表示，“这和京东的理念不谋而合，此次京东安全把HITB落地中国，就是希望能把这种极客精神带到中国，培养更多极客人才，共同守护网络安全。”

  

![](../Images/6bf5bcfe274101bd541f7d6bc3403ce5.png)

  

在峰会上， Dhillon 也对京东安全将HITB落地中国表示了感谢，在他看来：“京东HITB安全峰会不仅仅是一次技术创新和交流的峰会，更是对极客精神、追求创新精神的致敬，我们希望通过交流和分享，提升全行业对安全的重视，让更多网民意识到安全的重要性。

  

  

**结尾**

  

回顾2018，真可谓是网络安全的多事之秋，但正因如此，才更加促成了国内外网络安全重大会务的举行，来共同应对新环境下网络安全将要发生的变化，更好地为守护这颗星球上的网络安全迸发出绚烂的火花。

  

事实证明，严峻的形势并不会逼迫网络安全的倒退，不论是多起大规模的投融资事件，还是网络安全会务欣欣向荣地召开，都说明了网络安全仍将在未来展现出更强大的生命力。

  

而国际顶尖网络安全会议的成功落地，不仅增强了网络安全从业者的自信心，更让国内网络安全事业的发展充满了信念和希望。 

  

2019，我们继续上路。
