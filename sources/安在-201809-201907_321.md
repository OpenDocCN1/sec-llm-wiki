# 临近年末，怎样才能年终奖过百万？

年关临近，连天气都洋溢着过年的气味；小伙伴们见面也不问“吃了吗？”；而是问“火车票抢了吗”，或者是“年终奖发了吗？”

  

听着小伙伴们喜气洋洋的讨论着年终奖发放的N种姿势，小编看着自己刚刚出炉的支付宝账单、信用卡还款以及日益消瘦的钱包，大概只有“![](../Images/66cfae8d3a37fe1ee018a29bb5b282cb.png)”这个表情才能表达我的哀伤。

  

![](../Images/1b72165bdbdfa02d0de2675892e1d7b0.png)

  

小编正犹豫要不要把兜里仅有的10块钱拿去买彩票，就听到同事大呼小叫，人家**360冰刃实验室给技术人员发放上百万的年终奖**。小编想代替所有读者问问，“你们还招人不”？

  

满怀着激动地心情，小编给360的小伙伴发了个风轻云淡的消息**↓**

![](../Images/30aeb9b257965db353e243f6fed26296.png)

  

* * *

  

在小伙伴的解释下，小编这才明白上百万的年终奖存在两点误解：

  

一，并非人人都有，这只是个例；

二，这钱是隔壁微软跑来发的大红包，不是360给的。

  

至于微软为何屁颠屁颠的给360安全研究人员发大红包，还得从Hyper-V漏洞说起。

  

近日，360冰刃实验室研究员洪祯皓发现了一个Hyper-V漏洞，（远程代码执行类型，Remote Code Execution，简称RCE，诸多漏洞类型中危害最大的一种），并及时上报给微软。为表示感谢，微软公司在确认漏洞后，发放高达20万美元**（约合人民币137万）**的奖金，并对漏洞发现者洪祯皓表示感谢，称其“守卫了数十亿用户的信息安全”。

![](../Images/c9ba8dfe9eb675deb29742dee38aea8b.png)

  

据了解，这也是微软20年以来发放奖金数额最高的漏洞挖掘奖励。

  

**为啥Hyper-V漏洞这么值钱？**

  

可能绝大部分读者对此感到一脸懵逼，一个安全漏洞价值上百万，这对大多数人而言都难以理解。可以肯定的是，微软公司也不是散财童子，必定是这个漏洞有这样的价值，才会匹配如此高额的奖励。

  

那么，问题来了，为啥Hyper-V漏洞这么值钱？先简单介绍一下微软的Hyper-V。

  

**科普**

  

*Hyper-V是**64位windows上基于hypervisor的虚拟化技术，它利用处理器的虚拟化扩展提供一个虚拟化平台，使得多个隔离的操作系统同时共享一个硬件平台。它的原理类似于开源的虚拟化项目Xen。*

  

*此外，Hyper-V还是微软Azure云虚拟化解决方案，也是微软云战略的重要基石。*

  

  

随着云计算的迅猛发展，企业上云已成为必然趋势。微软作为全球最大的软件服务提供商，2011年便开始发力云服务，并将Windows Server用户逐渐过渡到Azure计算平台。

  

如今，Azure基础云服务快速增长，站稳了公有云第二，私有云第一的位置。换句话说，微软Azure计算平台漏洞一旦被黑客利用，那么，全球数十亿用户都将受到影响。

  

![](../Images/e7bd180c7dbeed5a40a8db75eb4b696c.png)

  

因此，作为微软云战略的基石，Hyper-V自身的安全性就显得尤为重要。如果基石出现问题，整栋大厦的上层建筑都将出现问题，甚至于会因此而遭到大范围的恶意打击。

  

360冰刃实验室帮助微软找到了Hyper-V漏洞，并及时上报给微软对漏洞进行修复，从而避免了该漏洞被恶意黑客利用。从这方面来看，用20万美金来奖励保护了微软云战略的白帽黑客，从而避免一次重大的安全事故，对微软而言，怎么看都是一笔划算的买卖。

  

Hyper-V漏洞值钱的另一个原因是，漏洞挖掘难度太高，这也证明了360冰刃实验室拥有强悍的漏洞挖掘能力。

  

Hyper-V对于微软云战略的重要性不言而喻，因此，微软对于Hyper-V的安全性有着极高的要求，这也是用户信赖微软的原因之一。反过来说，Hyper-V漏洞挖掘的难度势必会非常大；官方数据显示，2015年到现在，公开细节的Hyper-V漏洞仅有8个。

  

物以稀为贵是亘古不变的道理，漏洞太难挖，太过于稀少，价值自然就高。例如此次360冰刃实验室挖掘的Hyper-V漏洞耗时5个多月，若是价格和一般漏洞一样，谁还会去攻坚高难度漏洞呢？

  

**Hyper-V漏洞炸了会怎样？**

  

小编一直很好奇的是，如果这个漏洞没有被挖出来，而是被恶意黑客利用，那么，他可以通过这个漏洞干什么呢？

  

对此，360冰刃实验室潘剑锋表示，此次挖掘的Hyper-V漏洞属于远程代码执行类型漏洞，一旦炸了，有可能会对微软造成严重危害。

  

如果把微软云平台比作是一座大厦，Hyper-V就是这栋大厦的主要建筑设施，每个虚拟主机就是一个个房间，每个企业只能使用自己的房间，彼此之间互不干扰。

  

有了这个漏洞后，攻击者可以通过潜入一个房间达到控制所有房间的目的，并窃取这座大厦的权限。攻击者可以轻易的获得其他房间的财产、信息、资源，甚至于控制这座大厦的所有设施。

  

潘剑锋表示，此次Hyper-V漏洞造成的影响如此巨大，最主要原因是攻击者利用该漏洞可以实现从虚拟机Guest(客户机)逃逸到Host(宿主机)内核，而Host内核又是Hyper-V虚拟化平台中最高权限的地方，控制了这里相当于控制了整台虚拟化设备，甚至可以利用这个漏洞访问、控制这台虚拟化设备的全部资源。

  

也就是说，攻击者只需要进入某个防御不是很严的虚拟机后，便可以利用该漏洞攻击整个虚拟化平台，掌控虚拟化平台的最高权限。如果真是如此，获取最高权限的攻击者岂不是可以为所欲为？整座大厦的权限都在别人手中，这座大厦里的每一个房间又有何安全可言？

  

如果漏洞真的炸了，微软所有的用户都将面临着被攻击的风险，无一幸免；微软和云平台上的企业都将遭受巨大损失。

  

而微软云平台全球用户量高达数十亿，哪怕每个用户损失一块钱，其金额也将高达数十亿人民币。这样看来，百万人民币的年终奖咋一听好像很多，实际上，和这个漏洞的价值与危害相比较，九牛一毛而已。

  

**攻防兼顾的冰刃**

  

随着“微软给360白帽黑客发137万年终奖”的消息在朋友圈刷屏，安全圈的大佬们纷纷在朋友圈转发，并给360冰刃实验室发来贺电。同时也感叹，现在白帽子真的是赶上了好时候，比以前好太多，哪怕是微软，也从不接受第三方漏洞过渡到发出史上最高的漏洞奖金。

![](../Images/60cf5c657e3bfcf4eb02190577e78348.png)

  

![](../Images/7efb9ec8f762bed08cfce6067342462a.png)

  

![](../Images/b78122e7a699b9f16cd4a6c3618066b6.png)

  

因此，360冰刃实验室也在朋友圈火了起来，颇有“天下谁人不识君”的赶脚。

  

其实，冰刃实验室对于各种攻击都有持续性的研究，长期战斗在对抗木马病毒的第一线，为新型木马攻击增加主动防御防御点，为android恶意软件的发现提供android样本沙箱，为众多软件开发商提供源码级安全防护等。如今，这类安全防护能力已加入到360安全大脑中，赋能于各行各业。

  

另一方面，在漏洞挖掘方面，冰刃实验室不再单纯以人力挖掘漏洞为主要目标，而是深入思考漏洞本质原理，以便长期开发出半自动、自动化辅助工具。

  

例如已经公开的Digtool自动化漏洞挖掘框架便是其中的代表。Digtool曾在一个月内自动化挖掘到多种类型的20个微软内核漏洞、以及数十个来自杀毒厂商的驱动漏洞，给漏洞挖掘工作带来明显提升。

![](../Images/251d466f7756f1f0d4902fbda54c4aa5.png)

微软为冰刃实验室白帽子发放百万年终奖，让圈内人对其漏洞挖掘能力有了一个新的认知。然而，大多数人都不知道的是，冰刃实验室是一支兼顾防御与攻击的队伍。一方面为数亿用户开发有效防护产品、研究前沿防御技术，另一方面也研究包括漏洞挖掘在内的攻击技术，一攻一守，平衡发展。

  

普通人对于安全一知半解，但是对于360安全卫士、360杀毒、360沙箱、360文档卫士等防御软件想必不陌生，也许电脑换了一代又一代，但是安全防护中心的界面依旧是那么熟悉和安心。

![](../Images/e43f80256742811158ece36203a8904b.png)

而这些安全防御软件内核的主力开发人员大多来自于冰刃实验室。截至2018年6月底，这些产品的国内市场占有率已经达到96.54%，平均月活跃用户数达5.12亿。同时，PJF也是嵌套虚拟化防御等国际先进技术的开创者。

  

当被问及挖掘出微软Hyper-V漏洞的感受时，漏洞发现者洪祯皓除了终于完成这一工作的成就感外，下一个反应竟然是“十分好奇这个漏洞产生的原理”，还想着继续研究下去。

  

除了难以理解安全研究员的脑回路、反射弧外，我对潘剑锋所说的“挖掘漏洞最主要的动力是个人兴趣”这句话又有了更深刻的理解。也许，正是这些“个人兴趣”的存在，安全人员才能一日复一日在安全的道路上一路前行；才能支持洪祯皓彻夜不眠，分析触发漏洞的原因。

  

恰如360冰刃实验室的那句格言，Work hard in silence；let success make the noise（在沉默中拼搏；让成功自己发声）

  

**漏洞挖掘秘密武器**

  

此次，冰刃实验室能够挖掘出Hyper-V漏洞，拿到百万年终大奖，离不开一款秘密武器的帮助——**360“安全大脑”，集“感知”、“推理”、“决策”、“学习”、“预测”五大功能于一体**，为所有由其支撑的平台赋予安全能力，被业界称之为“国之重器”。

  

![](../Images/94973fb10c2df9ca2b98a0d35db86338.png)

  

目前，360“安全大脑”在漏洞挖掘上集成了大量先进技术和工具。目前，360“安全大脑”已经具备自我挖掘漏洞、自我修复的功能，大大减轻了用户的负担。

  

而对于Hyper-V虚拟机漏洞等重量级漏洞挖掘，360“安全大脑”同样有着强大的辅助功能，为漏洞挖掘提供指导、分析等帮助；如Hyperpwn项目便是针对Hyper-V虚拟机漏洞挖掘所提出的。

  

在对Hyper-V漏洞进行挖掘时，分析程序将会在定制的支持嵌套的虚拟系统中工作，为挖掘漏洞的白帽子提供有力支持。据了解，该项目还可拓展分析其他虚拟机系统，对于虚拟机漏洞挖掘有不小的帮助。未来，“安全大脑”还将继续改进，强化辅助漏洞挖掘的能力。

  

值得一提的是，辅助漏洞挖掘只是“安全大脑”的一部分功能，安全大脑综合利用人工智能、大数据、云计算、IoT智能感知、区块链等新技术。“安全大脑”并非是一蹴而就，360为打造“安全大脑”耗时九年，在经历了无数的失败后，最终研发出的集大成式安全产品。

  

全球部署的数以亿计的终端设备将会成为“安全大脑”的感知器官，采集全球范围内的安全相关数据；而遍布世界的移动通信网络会将这些数据上传到云端；10万+台服务器的计算能力将会为此提供庞大算力；百亿级特征处理、千亿级图计算等智能算法提供支撑；加之人工智能赋予的自我学习、自我进化的能力；真正实现在“大安全”时代为赋予用户抵御安全的能力。

  

由此可见，360冰刃实验室白帽子能够拿到百万级的“年终奖”不是偶然，除却长时间的探索、研究和坚持不懈的努力，还有强大的“安全大脑”为其提供支持。

  

**后记**

  

一直以来，360在漏洞挖掘与利用方面有着得天独厚的优势。2016年，360获得苹果、谷歌、微软等企业的致谢共408次，首次位居全球第一；2017年获得致谢519次，再度获得第一，这体现了360在漏洞研究能力上的领先优势。

  

360董事长周鸿祎认为，漏洞需上升到网络战重要战略资源高度来认识和管理，有时候，一个重要漏洞的价值不亚于一枚导弹。

  

换句话说，漏洞是网络安全的“命门”。软硬件系统漏洞使得攻击者可以利用漏洞窃取信息或者控制、破坏目标系统，从而引发各种网络安全问题。

  

在系统漏洞无处不在的今天，唯有积极正视这个现实，并在此基础上积极查找漏洞，发展网络防御的技术和产品，才能在攻击来临时做到有效封堵和应对。
