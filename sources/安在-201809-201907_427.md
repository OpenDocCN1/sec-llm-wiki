# 黑客密探 | 零感安全屋

前情回顾

### 

### “十天之后就要进行透明人计划合法化公投了，咱们都是搞网络重案调查的，这件事跟咱们之后办案所能调动的资源关系太大了。”包小虎说：“私底下大家都议论纷纷，各选立场，我想知道你是支持自由派的四分之一透明人计划，还是监督派的二分之一透明人计划。”

  

**01**

  

从夜里开始，新泽市飘起了细雨，雷声闷响，空气夹杂水汽混绕在街上行人脊背的两侧。有的雨点儿星星地趴在黄铜区胡同里生锈的栅栏上，还有的洒脱地落在叶绿区晚归的车灯前。

  

当赵耿打着雨刷使进小区的时候，已经入夜。一路上，赵耿都在回想王林下午走进他办公室的样子。王林绕过了孙斌的办公室，推开了他的门，径直坐在了他面前。当时赵耿正在调查暗网。

  

“没想到顾问这么快就来找我了。”赵耿合上电脑对王林说：“顾问想起朱万金在哪儿了？”

  

“我不知道。”王林说：“不是赵警官邀请我来的吗？”

  

“对啊。”赵耿说：“我想请顾问告诉我，你认为保护洪淼主任的原因是什么？”

  

“最近网络安全事故频发，大多来自暗网且指向洪淼主任。洪主任是世界互联网安全联盟票选的中间调停人，他夹在了监督派与自由派之间，而监督派一直因为洪主任搁置了透明人计划感到不满。透明人计划投票临近，保护洪淼主任是理所应当的。”

  

“顾问总能想在别人前头。”赵耿说：“我是经孙局长提点，才想起来透明人计划，没想到顾问早就想到了。”

  

“赵警官不知道点别的？”

  

“顾问什么意思？”

  

“随便问问。”王林笑着说：“赵警官叫我来解惑，不会只和我说一些我们都已经知道的事情吧？”

  

“当然不会。”赵耿说：“我在调查暗网时，探听到了一个重要消息，不知道顾问是否已经知道。”

  

“赵警官不是本着保密原则，不愿意和我分享消息吗？”

  

“这则消息顾问知道了也没有关系。”赵耿说：“有一支78-2K被拆成几个部分，运输到了新泽市。我很担心新泽市市民的安全，所以想让顾问提点一下，什么人会购买78-2K，那支枪现在有可能被藏在了哪儿？”

  

“神网侦查队现在也管枪支了？”王林笑了笑：“我觉得赵警官去请教一些常年走在枪支管制线上的刑警。”

  

“我不太同意顾问的意见。78-2K会在新泽市流通重点不在于枪支，而是购买枪支的渠道。既然78-2K完全在暗网销售，那么流通到新泽市的78-2K，理应由神网侦查队负责调查。至少，也要和刑警部门联合调查。”

  

“赵警官说的很有道理。”王林说：“你可以去找刑警一起联合破案，我的意见无足轻重。”

  

“顾问没有什么自己的看法吗，我只是想了解一下，顾问认为那只78-2K有可能会藏在哪儿？”

  

“一支78-2K不成规模，大概率不是组织行为。如果是组织行为，很可能是山寨商人雇佣了一批科学家，想要研究一下已经在黑市大卖的78-2K并进行复制。”王林说：“至于谁需要78-2K，我想只要稍微喜欢刺激的人，都会爱上78-2K，尽管它违法，但毕竟它可以自动瞄准。从爱好者这个角度去追查范围太大了，我倒是觉得赵警官可以从源头查起，比如你的消息源，他们既然可以拿到78-2K被零散的寄到了新泽市的消息，就一定可以找到收件人。”

  

“顾问的思路和常人是不一样。”赵耿说：“我已经调查了，没有直接的收件人。我猜测大概是寄送的人先把零件分别埋在新泽市郊外的保留地，然后收件人再自行挖取。”

  

“赵警官的想象力很丰富，也确实是一种可能性。”王林说：“时候不早了，我不在这里耽误赵警官办工了。”

  

走出办公室之前，赵耿伸出一只手：“感谢顾问今天特地来找我。”

  

“不来怎么打消赵警官心中的疑虑。”王林伸出手，没有握实：“监督派和自由派之间的摩擦，并非两派之争，而是关系到人类、人工智能的未来走向，一旦失衡，后果赵警官很清楚。洪淼主任在这个时间不能出事，还请赵警官多留意。”

  

赵耿说：“孙局长已经给过指示了。包小虎副队长会亲自带领神网侦查队最好的持枪警卫在零感安全屋附近进行安保工作。”

  

王林轻轻地击了一下赵耿的手掌，然后转身离开。王林还未走出警局的大门，包小虎就走进了赵耿的办公室，关上门后还拉上了百叶窗的窗帘。

  

**02**

  

“王林对北欧杀手和78-2K都有自己的解释，虽然他一直以来都很会诡辩。”赵耿说：“但没有确凿证据的情况下，我无法完全判断他的身份。”

  

“这是我在暗网的线人发给我的聊天记录。”包小虎说：“LC是暗网地下货物区枪火军械模块的垄断者陆川，通过逻辑推导可以证明Everyman是王林。事情的起因是朱万金掌握了陆川走私枪火军械的实证，朱万金为了整垮陆川找到了被民间称为黑客密探的王林求助，王林出卖了他，三个北欧杀手就是陆川派去追杀朱万金的人。

  

陆川为了感谢王林，以心理治疗费的名义汇给了王林两千万美金和一把刚生产出来的升级版78-2K，走私进入新泽市的那把78-2K就是寄给王林的。至于两千万美金，我们去暗中调查了一下，王林存在了他于北欧的账户上，我们无法调取转入账户的详细背景数据，但是只要王林动了那笔钱，我们就有依据立案侦查。”

  

“虽然听起来符合逻辑，但是至少有三个疑点。”赵耿听完包小虎的叙述后皱着眉头说：“第一，为什么朱万金不直接将陆川走私枪火军械的证物交给警察而是要找王林；第二，王林将一个与朱万金体型相似的人带进了1887号，那个人走出1887号的时候，市政的摄像头拍到了照片，现在可以确认那个人不是朱万金；第三，无论朱万金是否还活着，我们都还没有找到他，而且那笔钱王林也没有动用，这种情况下，证据链不足。”

  

“针对第一个问题，我们走访了许多与朱万金家相熟的人，得知陆川现在的情妇就是朱万金的母亲，朱屠虎的前妻辛柏春。”包小虎说：“朱万金如果将朱屠虎的犯罪证据直接交到警察手里，她的母亲也难脱干系，所以他选择了找王林寻求帮助。我猜测朱万金的诉求大概是希望王林帮他摧毁陆川构筑在暗网的店铺，折磨陆川，给陆川一些活着的惩罚。”

  

“如果真的是这样，那么第二个质疑要如何解释呢？”赵耿问。

  

“针对第二个问题，那个蒙着头的人我们找到了。”包小虎说：“他是一个在片场扮演小角色的喜剧演员。他告诉我们，那天王林出了他演出价三倍的钱让他配合做一件事，很考验演技只是台词比较少。在王林家中他见到了那两个北欧杀手，他说在花石区1887号一楼的沙发上听到了王林与陆川的电话对话，大体上是关于如何处理朱万金的问题。在他的印象中，王林让陆川将朱万金交给他处理。”

  

“也就是说，是王林处理了朱万金？”赵耿问。

  

“从目前的证词来看是这样的。”

  

赵耿说说：“现在找到朱万金是最关键的事情，无论他是否还活着。”

  

“没错。”包小虎说：“无论朱万金是否还活着，在找到他之前，我们都要格外当心，王林的已经赢得了洪淼主任的信任，将史严森安排进了零感安全屋。如果王林确实和暗网有所勾结，我担心王林可能会命令史严森对洪淼主任下手。”

  

“我觉得即使之前推测的内容全部成立，史严森也不敢在零感安全屋内对洪淼下手。”赵耿说：“在零感安全屋外的保护措施没有出现任何披露的情况下，如果洪淼在零感安全屋内出现事故，最直接的怀疑对象就是史严森。”

  

包小虎说：“我会让持枪守卫特别注意史严森的一举一动。”

  

“在洪淼主任去北欧寒地市之前，你的重心都必须放在零感安全屋。”赵耿说：“寻找朱万金和调查王林的事就交给我吧。”

  

**03**

  

赵耿在办公室内一直忙到了晚上十点，因为已经过了晚高峰，所以他四十五分钟就驶进了小区的停车场，比平时快了大约半小时。按下电梯按钮的时候，是晚上十点五十分。

  

![](../Images/95e37df8fcc6a7dfef8b8829d8c81d51.png)

  

赵耿一路上都在思考王林和他的对话，以至于他都没有意识到自己正在掏钥匙开门。在赵耿出神地打开自己家房门的时候，他的思绪忽然被一种莫名的室内氛围强行拽了出来，赵耿感到了一丝异样，房间内黑漆漆的，没有开一盏灯，与往常不同的是，赵耿听到了一个人平稳的呼吸声，他在打开灯前顺手抄起了挂在鞋柜旁边的雨伞。

  

赵耿低声问：“是谁？”

  

刚开始没有人回应赵耿，他意欲打开灯的时候，从房间的正中央传来了一个怪异的变声：“你会后悔打开灯的，就在黑暗中说话吧。很多时候在黑暗中说的话才是真实的。”

  

“你是谁？”赵耿没有按下灯的开关：“来我家做什么？”

  

“我来确定你内心的答案，长话短说。”黑暗中怪异的变音说：“嫉妒驱使你怀疑，逻辑促使你质疑。你的内心产生了两个强大战士，他们互相厮杀，刀光剑影，扰乱的你心神不宁。”

  

赵耿打开灯的时候，原本站在黑暗中的人摘下了帽子和变音器。

  

**04**

  

史严森住进零感安全屋的时候带上了万喜。万喜与洪有家年龄相仿，两个人很快就熟络了起来，尽管他们不时因为一些小事争吵，但似乎没什么能让两个孩子彻底不再理睬对方，毕竟零感安全屋里只有他们两个孩子。

  

令两人稍稍感到有些不愉快的是上学问题。为了确保安全，洪有家向学校请了两周的事假，白天的时候只能留在零感安全屋，而万喜和往常一样每天都需要去上学。万喜羡慕洪有家可以不用去学校，洪有家羡慕万喜可以离开零感安全屋去见更多的小伙伴。

  

每当两个孩子在零感安全屋相聚的时候，就是那间屋子最欢腾的时间，有哭有笑，有最直接的打斗，还有更直接的友好。到了白天，屋里屋外大多没什么动静，坐在屋内的洪淼总是在读书，史严森则在摆弄着魔方，他把从二阶到七阶的魔方都带到了零感安全屋，没网络的时候这就是他最好的玩具。

  

屋外的神网侦查队持枪守卫笔挺地站在那里像个木桩子，不得不说他们是经过专业训练的保卫人员，面部没有任何表情，眼睛时刻监视着目力能及范围内的任何风吹草动。

  

包小虎穿着持枪守卫的制服在零感安全屋旁边的一间监控室内坐着，屏幕的灯光打在包小虎的脸上，他脸庞的轮廓在这个时候格外清晰，一张黝黑的国子脸，剃着寸头，浓厚的双眼皮下是一双溜黑的大眼睛，单从外表上看，他也许比赵耿的年龄还要大一些。

  

包小虎的手上有一张安保清单，包括饮食、物理攻击、语言刺激在内的三十项可能会对洪淼独立思考造成伤害的隐患都由包小虎负责预防。

  

洪淼所吃的每顿餐饭与屋内的其他人不同，他的饭必须经过多道检验。菜品由指定酒店制作后，送到安全应急响应中心。包小虎亲自用化学仪器对食物中的元素进行测量，凡是个别元素超标的菜品一律不可以进入零感安全屋，整个检测和洪淼吃饭的过程都会被摄像头完整记录。

  

测量数据会被包小虎记录在一张加密的电子表格内，在新泽大学化学系教授重复检测确保无误后，现场公证处的专员就会将记录传送给联合国网络部。几天下来，除了有一道肉菜中的含盐量过高外，没有出现太大的意外。

  

每天接近夜里十一点的时候，洪淼都会习惯性地写下日记，例如在他的又一个失眠夜之前，洪淼写下了一句与前几日相似的话——11月6日，距离透明人计划合法化公投还有五天。
