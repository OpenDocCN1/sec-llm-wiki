# 西北大漠72小时生存记

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532904&idx=1&sn=069e29b981ef1e07f10f604e1b3300e5&chksm=febc2ba8c9cba2bea3c265f08a0ed1bdcdf1ab0682deedcb1911780590574bf8eeb00d7a934f&scene=126&sessionid=1681310728#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532904&idx=1&sn=069e29b981ef1e07f10f604e1b3300e5&chksm=febc2ba8c9cba2bea3c265f08a0ed1bdcdf1ab0682deedcb1911780590574bf8eeb00d7a934f&scene=126&sessionid=1681310728#rd)

出了银川，就是一望无际的大漠了。

  

![](../Images/f5073453ae7e949e19190def1b5809e8.png)

  

晌午，沙暴刚过，大漠之上，唯有两处黑点，近了，才发现是两个身着白衣的年轻人。

  

![](../Images/f8f3cd865fc4ea47fd2e2f181589d3db.png)

  

两人对峙许久，其中一名年轻人便先开了口。

  

![](../Images/50dd33c10399f2b57e69b09a0b6e8667.png)

  

“放弃吧，论美貌，你是赢不了我的。”

  

![](../Images/66013a8ea4507ae3985c8ae1fb449210.png)

  

另一名少年也不甘示弱，愤然回击：“那得问问我手里的‘天上天下唯我独尊一击必中植树造林铲’答不答应。”

  

言罢，便提铲而上。

  

![](../Images/84dd38f6edcccb3ce6f5a620d797f16e.png)

  

高手过招，电光火石，风云变色，一道奇光闪过，二人便消失在原地，不见踪影。

  

谁曾想，几天过后，我竟离奇的卷入了这宗旷古奇闻。

  

![](../Images/4f0a2992899834dc2b017902306b7d58.png "音符GIF动图简约分割线")

  

月初的时候，我出差银川，忙碌完一天的工作回到酒店准备睡下。

手机响了，是我一个老同学，毕业后他就回到了银川，成为了一名人民警察。

电话那头，他告诉我，他们在荒漠里巡逻的时候，见到了一片奇幻的景象，还在现场还带回了两个神志有些不清的年轻人，他知道我来这里出差，想让我过去一趟，有些事也许能帮上点忙。

我和他其实并不十分熟络，这时找我，想必确实重要。

虽然才刚入秋，但银川的夜晚已经很冷，我只披了件外套，便急忙出门。

到了派出所，朋友早已在门口等候多时。

“来了？”

我点了点头。

他拿出一根烟递给我，我摆了摆手，他便自顾自地点上。

“人是在荒漠里发现的，根据我们调查，他们于9月1号抵达银川后，就直接赶赴了荒漠，一直到今天夜里被发现，已经过去了整整三天。”

说着，拿出手机，找了两张照片给我。

“诺，这是刚找到他们时候的样子，难以想象在他们身上发生了什么。”

![](../Images/7133a912aa7a4eb3ee7b0416c75e04df.png)

![](../Images/2e75009b26245c494d1ae3803749156b.png)

![](../Images/bb97023586b2184627b633e83c96d023.png)  

我没有答话，等他接着说下去。

“在这三天时间里，他们总共徒步行进了五十多公里，食物和水早就在两天前消耗殆尽，到了派出所，他们第一件事就是上了趟洗手间，好久都没出来，看得出忍了有段日子了。”

可是我想不明白，这跟我有什么关系。

朋友似乎也看出了我的疑虑。

“从我们遇见这两个小伙子开始，他们虽然已经精疲力尽、神志不清，但嘴里一直在嘟囔着‘守护网络安全’、‘挖洞植树’之类的话语，我想找你这个内行人来和他们沟通，会更容易一点。”

“网络安全”？“挖洞”？我渐渐对即将见到的两个年轻人产生了些许兴趣。

“好吧，人在哪？”我问他。

“休息室，这边。”

![](../Images/5b0fa5cf448ba166c440a879a3eef51f.png)

打开门，我见到了两个面容黝黑的少年。神情略有疲倦，脸颊和嘴唇上也有几处皲裂，看得出过去几天他们过得确实不太顺意。

朋友抽开椅子，示意我坐，转而对着那两个少年说：“这位蓝河先生是网络安全媒体的记者，专业的，也许他能懂你们。”

“你是记者啊，那太好了。”虽然疲惫，但其中一个少年仍稍显兴奋地看着我。

我礼貌地笑了笑：“对呀，有什么可以为你们效劳的呢？”

少年点点头。

“我叫IceCrown，他是cnRay，我们是网络安全志愿者。”

等等，网络安全志愿者，那不就是白......

我不由得一连茫然：“你们来这里干什么？”

IceCrown似乎对我的反应很满意，嘴里缓缓地突出两个字。

“**种树**。”

种树！种什么树！

“没错，就是种树。”朋友在这时开了口。

他拍了拍我的肩膀，接着说：“在这三天时间里，他们总共徒步行进了五十多公里，但同时，他们还在一路上种植了数百株树苗，我们之所以能够发现他们，也是因为巡逻的民警，发现这片荒漠，突然间多出了一方绿洲。”

![](../Images/d1ef1363ab060fdf3b3a75491f3faa67.png)

我的思绪一时间混乱，完全无法将网络安全志愿者和种树这两件事联系起来。

“我来说吧。”从我进来后就一直保持沉默的cnRay开了口，在接下来的几十分钟里，他向我完整地复盘了发生这一切的来龙去脉。

“一切都要从一个月前说起......”

为了肯定网络安全志愿者对于互联网安全保护的作用，同时也为了激励全行业、甚至每个人都能参加到维护网络安全的行动中来，蚂蚁金服安全应急响应中心（AFSRC），联合公益组织“根与芽”，携手12家公司SRC（安全应急响应中心）共同发起“互联网安全防护林计划”。

![](../Images/e78d93cec8233fffd04cb864cd69d514.png)

因为对于网络安全来说，找出漏洞最终的目的是填补，通过填补漏洞让企业网络安全的能力得到提升，降低面临网络安全的风险，这和在荒漠中挖洞再植树的方式不约而同。

因此，项目以**one bug（漏洞）= one tree 为口号**，倡议安全圈中的有识之士一同参与。通过公益植树的形式，将无形的“网络安全保障”，等价于有形的“现实环境保护”。鼓励更多的安全极客参与到网络安全保障的阵营中，为用户建设“看得到”、“摸得到”的“绿色城墙”。

网络安全志愿者们每找到一个漏洞，SRC联盟即以提交者的名义在宁夏自然保护区捐赠一棵树，让每个人亲手找出的漏洞所作出的贡献，通过种植林木的方式，得以回报。

但由于宁夏自然保护区有着严格的人员出入数量限制，因此只能从众多网络安全志愿者当中，挑选2位代表前往。

于是，从8月11日到19日期间，网络安全志愿者们需要在这12家已加入互联网安全防护林SRC/众测平台中提交并确认漏洞，将有机会获得这次宁夏之行的资格。

IceCrown和cnRay，就是几经鏖战，最终笑傲的幸运儿。

听cnRay说完以后，我怎么想都觉得哪里不太对劲。

“按说这么好的事，你俩怎么弄得这么狼狈？”

“别提了。”IceCrown苦笑一声，接着翻给我两张照片。

其实刚来的时候，他们是这样的。

![](../Images/7e4251e043552689f0003bb5eba896dd.png)

  

还有这样的。

![](../Images/29a4e82cef3c71e24730a7168795f78d.png)

  

等到了生态保护区以后，他们才意识到，这里的生态环境，比他们想象中还要恶劣得多。

于是他们非常努力地种树。

![](../Images/82a1149d2f6be78b9c2648f60c43e7c5.png)

![](../Images/4afb8c38ca049f89e7af8f2371b962cc.png)

![](../Images/dab6e37f64df77b14ad52b737729411e.png)

这种每找到一个漏洞都能以绿苗新生展现的形式，也让他俩觉得非常有成就感。

毕竟人有三急，种到一半，不约而同都想去趟洗手间，于是他俩就一起去寻找合适的地方。

但走了一路，到处都是光秃秃的一片，别说洗手间了，连一棵能遮挡四周的大树都没有，因此他们就更加认识到这里的生态环境有多么恶劣，植树造林是多么重要。

于是他们就每走一段距离，就种下一株树苗。边走边找，边找边种，走了一路也就种了一路，走过了日出日落，忘记了天亮天黑，就这样过去了四天之久，一直到被我朋友发现，他们已经在不经意间亲手种下了一片绿洲，同时也依然没有找到洗手间。

![](../Images/1957b85ef3870caf40e39622769aecf5.png)

听完以后，我恍然大悟。

原本只能默默贡献力量的网络安全志愿者们，终于有了情怀上的回应，而在“互联网安全防护林”计划的引导下，网络安全志愿者更是成为了线上和线下、网络环境和生态环境共同的守护者。

我朋友此时蓦地起身，面部紧绷，神情严肃，半晌，突然伸出手，握住了IceCrown和cnRay。

“真的非常感谢你们为生态环境做出的贡献。”

两位少年也腼腆地笑了，毕竟还只是孩子。

我看他俩也有些饿了，便转头对朋友说：“你下班了没？”

朋友点点头：“早就下了，还不是因为这俩傻小子，临时出的任务。”

“那咱们先去填点肚子吧，我对种树这事还挺有兴趣的，边吃边聊。”我提议道。

IceCrown和cnRay也挺兴奋的：“好啊，我们这当中还有好多有趣的故事呢，我全都说给你听。”

朋友似乎也来了兴致。

“好好好！今天真高兴，咱们小酌两口，庆祝一下。”

“你自己喝吧，谢谢。”

故事讲完了，种树的事情是真实的，当然整个串联的故事是我虚构的。

我很感谢IceCrown和cnRay愿意让我用这种戏剧化的文字来给大家分享他们这段有意思的经历，也很感谢12家SRC联盟所发起的“互联网安全防护林”项目。

因为在交谈过程中，有一个观点是我过去没有认真想过，但却是十分认同的，那就是对于网络安全志愿者来讲，他们对网络安全事业的贡献，绝不只是“挖一个漏洞”这样一个表层的意义，而是在填补漏洞以后，对网络安全环境的保护，给网络安全能力的提升。

这和在洞里种下树苗，最终成长为参天大树保护生态环境的本质是一样的。

IceCrown和cnRay在这段经历中的获得感我是能感受到的，他们觉得自己的努力得到了认同，“网络安全志愿者”的身份也受到了尊重。

其实他们和我分享了很多，我不过只是写下了点皮毛，这个故事在未来还会继续下去。
