# 国家网安人才“黄埔军校”宣传周重磅亮相

9月21日至23日，以“网络安全为人民，网络安全靠人民”为主题的2018年湖北省暨武汉市国家网络安全宣传周活动启幕，作为安全界的年度盛会，本次活动现场，国家网络安全基地培训中心的亮相，让人眼前一亮。

  

![](../Images/ad090bfbd471c55bcc1ecf675d2cec5c.png)

展会现场

  

依托网安基地，建立首个国家级网安培训中心

  

国家网络安全培训中心位于国家网络安全人才与创新基地核心区，它是依托国家网络安全人才与创新基地和当前国家网络安全行业发展优势，建立的首个国家级且唯一的网络安全人才培训中心。

  

培训中心总用地面积300亩，总建筑面积20万平方米，建有教学楼、实验楼、信息综合楼和宿舍等，中心一期建筑面积6.9万方，项目目前基本建成，预计今年年底将逐步投入使用，二期建筑面积14.6万方，在原有教学区基础上新增行业展区、攻防教室等多功能实操教学空间，预计明年九月将全面建成。

  

![](../Images/47f41dd437ec271714d28b79b1c0c44b.png)

国家网络安全基地培训中心亮相宣传周

  

年均学员七万人，打造中国网安人才培训“黄埔军校”

  

“网络安全的竞争，归根结底是人才竞争”。据《2018网络安全人才发展白皮书》显示，我国网络安全人才缺口70万人，缺口高达95%，亟需人才培养机制的创新。

  

国家网络安全培训中心将积极发挥平台优势，立足国家战略高度，联合更多网络安全知名企业和培训机构，在让学员通过系统化的网络安全课程学习，培养成为具备较强实操性的网络安全人才，为国家网络安全事业发展输出新生力量。打造国内高端、世界前沿的网络安全人才培训“黄埔军校”。预计，培训中心前三年将实现月均超6千人次，年均超过7万人次的培训规模。

  

![](../Images/a93ceed5594863beb2cc71fe547c49ed.png)

采用先进技术的大屏显示系统

  

接轨国际标准，打造智慧化教学园区

  

国家网络安全基地培训中心位于武汉市临空港经济技术开发区，一期四平方公里，南北西三面环绕径河天然水系，环境优美。教学楼主体建筑由国内专家团队设计，参照国际国内一流学院办学标准和风格规划，采用目前国内高端科技设备。为学员配有餐饮、住宿、公共服务、运动场馆等多个功能区域的，满足培训学院一站式生活需求；在教学空间的设计上，功能的复合型和室内空间的交流，立足国际化视野，学习空间已经扩展到教室之外，走廊可被用作教学空间，楼梯可当做座椅，阶梯教室兼具学术交流和互动功能等。

  

国家网络安全基地培训中心致力于为广大师生提供一个开放共享、功能复合、生态低碳、设施完善、环境宜人的智慧教学园区。

  

![](../Images/23c5f789f245279df70d83237c40afb5.png)

高端的课室环境

  

![](../Images/169d6b9047ecfff9020d25e09ad2cf7b.png)

自由的课间讨论空间

  

创新运营模式，打造专业级服务平台

  

在对标国内外网安行业先进培训经验，创新运营模式，建设超一流网络安全培训中心的运营理念之下，国家网络安全人才培训中心将致力打造一个集网络安全人才培养、战略推进、行业创新三位一体的专业服务平台。

  

中心将不再是单一的培训学校，而是为国内外网安培训机构，提供完善的培训机构入驻服务，引导国内知名的网络安全培训机构入驻中心园区，打造创新的平台级服务，聚合更大生态效应，构筑更高标准的培训集群阵地，利用培训中心良好的基础设施、国家级网安园区、整合的行业资源，促进网络安全培训机构专注各自专业课程研究和授课创新，实现大规模优秀网安人才的输送。

  

![](../Images/f2a3d01ac94064aac93135b732678cb3.png)

培训中心鸟瞰图

  

作为国家网安基地建设的龙头任务，国家网络安全培训中心将与高校、企业、地方政府充分互动，在园区内形成集学历教育、在职培训、研发中心、孵化平台、企业为一体的科技产业服务链，形成网络安全人才培养、技术创新、产业发展融合生长的良好生态环境，为社会输送网络安全专业人才，强化我国网络安全高级专业人才的队伍建设，为国际网络安全空间维护和我国网络安全事业快速发展贡献力量！
