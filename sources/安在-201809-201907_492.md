# APP备案急需加强 安全防护亦不可忽视

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247532898&idx=2&sn=18f1ff94385c9c90d5892f9f41f15781&chksm=febc2ba2c9cba2b4c90fbe31e017ece2e32ec33199c403ad33854ac772fe1ff505d5f632b2cb&scene=126&sessionid=1681310728#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247532898&idx=2&sn=18f1ff94385c9c90d5892f9f41f15781&chksm=febc2ba2c9cba2b4c90fbe31e017ece2e32ec33199c403ad33854ac772fe1ff505d5f632b2cb&scene=126&sessionid=1681310728#rd)

继上海市信息网络安全管理协会（以下简称“网安协会”）6月28日发布了《移动互联网应用（APP）应依法备案-多款应用曝高危漏洞》一文以来，不少企业通过登录“**上海互联网安全综合服务网****”（****https://wa.police.sh.cn****）**进行了注册登记。截止日前，平台中已注册的APP运营单位共计1191个。

  

![](../Images/6705c03de27a024687e621cc77290ab6.png)

  

  

早在1997年发布的公安部第33号令中就明确了“互联单位、接入单位、使用计算机信息网络国际联网的法人和其他组织（包括跨省、自治区、直辖市联网的单位和所属的分支机构），应当自网络正式联通之日起三十日内，到所在地的省、自治区、直辖市人民政府公安机关指定的受理机关办理备案手续”的要求。

  

随着我国经济建设和信息技术的迅速发展，党和国家各级领导越发重视我国的网络信息安全，各级机关也在通过各种渠道频繁地予以大力宣传。为加强监管力度，本市将陆续出台一系列的标准和规范，对行业进行监督和管理。

  

**网安协会呼吁广大APP运营者及时落实相关注册备案工作。经有关部门核实后，我们会持续、分批地公示未备案APP运营者名单；对少数置若罔闻、拒不备案的单位将面临相关部门处罚。**

  

此外，在APP运营者应履行的义务之中，安全防护也很重要。网安协会APP安全专业委员（以下简称“APP专委会”）会通，分别对已在“上海互联网安全综合服务网”备案的以及未在平台备案的APP进行了抽样检测，检测内容涉及：代码检测、防御检测、漏洞扫描、盗版检测等数十项指标，结果不容乐观。迄今为止，共检测3350个APP，共发现安全隐患313618个：其中高危风险212512个、中危风险3630个、低危风险97476个。

  

APP安全问题影响的不仅仅是产品自身功能正常运行，还涉及到企业的财产和声誉，广大用户的个人隐私和信息安全，一旦造成严重后果，APP运营者还可能面临法律制裁。

  

部分APP开发者会采取一些加密手段，但在加密技术与破解技术激烈冲击的高科技时代，老旧或简陋的加密手段几乎起不到任何防护作用，举例来说：有些开发人员采用硬编码的加密方式，这种加密方式在反编译等手段前完全抵挡不住、形同虚设。

  

破解后的APP往往会被黑客注入恶意代码、二次打包，致使用户数据泄露、支付劫持、账户被盗等损失，同时，也会给APP运营者带来薅羊毛、信息爬虫、资金盗取、敏感隐私遭窃取等危害。此时，亡羊补牢，为时晚矣。

  

目前，APP安全专委会提供的安全检测报告，为已备案单位深度解析了其APP产品的安全隐患情况，部分单位在APP安全专委会的指导下，针对各自APP的特性结合实际，从文件加密、代码混淆、动态防护、内存保护、安全编译等方面提供安全加固服务，并顺利通过复检后再次上架。
