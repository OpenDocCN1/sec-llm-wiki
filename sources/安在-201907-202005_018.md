# 诸子云 | 项目：POC 测试报告共享项目报告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247533447&idx=1&sn=b3a878e220c907eb238f62c39ee756e9&chksm=febc2947c9cba051efd9a37a1674d2f2cb5f669419fb0fa02a557d236ef88797a9cbc5d9bf60&scene=126&sessionid=1681310668#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247533447&idx=1&sn=b3a878e220c907eb238f62c39ee756e9&chksm=febc2947c9cba051efd9a37a1674d2f2cb5f669419fb0fa02a557d236ef88797a9cbc5d9bf60&scene=126&sessionid=1681310668#rd)

诸子云 ▪ 企业网络安全专家联盟——以中国境内各行业各领域企业组织的网络安全从业骨干为主体的社群组织，是为奋战在用户单位网络安全一线的实践者提供的交流互助平台。

  

  

2019年6月，**诸子云首次推出“项目”共建机制，鼓励会员群策群力、创新分享。**这一模式基于诸子云社群特点，以“众人拾柴火焰高”的理念出发，贴合现下安全从业者想要集中力量为安全行业办大事的想法。项目一经发起，就受到会员们的广泛认同和积极参与，第一季共计开展了11个“诸子项目”，取得了初步成果。

  
2020年1月，安在发布诸子项目第二季预告，在经历了第一期项目的积累和铺垫以后，项目第二季度受到了专家会员们更加热烈的呼应和参与，项目数量更多、覆盖范围更广、理论研究更深、参与人数和热情也更高。第二期诸子项目共计发起10个，今天我们要介绍的项目，将有助于提升甲方企业产品选型工作的效率和质量——**POC 测试报告共享项目报告**。

产品 POC 测试一直是甲方安全人员的重要工作之一，通过对产品POC测试报告的研究分析，可以总结其中的共性问题和经验，简化甲方产品选型的工作量。

  

本项目一共收集到了项目成员提供的17份POC测试报告，均为企业安全建设中常用到的安全产品。涵盖网络安全领域网络准入、防APT、WAF、HIDS、App安全测试、NGFW、IPS产品10份报告。涵盖数据安全领域的终端DLP、邮件DLP、数据加密、数据脱敏、数据安全解决方案等产品7份报告。

  

由于不同甲方关注点不一致，测试要求不一，通过对提供的样本报告进行分析，提供的测试报告主要分为以下两类：

  

1.以word为主，报告主体包括测试目标、测试环境、测试结论，附上测试内容项和截图。

2.以excel为主，报告按照测试大类、测试项、测试结果，辅助设置占比、测试项分值和备注。

  

  

  

**![](../Images/a85a92116f8130877361f5faf527f7be.png)**

**是如何想到对“POC 测试报告共享**

**项目****报告”进行研究？**

  

对于企业信息安全人员来说，采购和部署安全产品是必不可少的工作。不同的甲方，由于人力投入、专业技术、采购模式等不一样，在测试环节投入合产出都会有一定的侧重点。如何高效快速且少走弯路的选择一款适合自己的产品，是很多甲方安全从业者关心的一个课题。

  

![](../Images/b1ed6a9c0ac2ade64898bd91a699e1fc.png)

  

对此，潘盛合萌生了一个想法，想要撇开不同企业环境的差异，针对安全设备的共性问题，总结出POC测试经验，并探讨甲方在POC测试中可以共享的一些问题和经验。如果想法落地实现，那么将大大提升甲方在产品选型中的工作效率和质量，这也是本项目的价值所在。于是，项目议题就这样出现了，潘盛合和李维春共同探究POC测试报告能否共享，以及共享的价值点在哪里。

  

说起项目刚刚开始推进时，潘盛合表示，一开始我们陷入到“不同厂商到底谁的产品好”，这样的思考中，经过项目成员的讨论和分析后，最终认为厂商的产品是动态更新的，好与不好也是根据需要来评价，而非凭主观臆断。

  

![](../Images/87abe204f2fd0c5bac08405761cc6707.png)

  

本项目报告也分成三部分：样本说明、测试报告分析情况、结语，目的是探究安全产品测试报告的记录形式、不同产品的特点和相应产品测试中的关键考量点，通过共享这些信息，甲方在测试工作中结合自身情况，尽量少出现重大失误。

  

![](../Images/76c683cc59acb72df5276c92a314b56b.png)

  

从项目的工作内容来看，业内人士想必都清楚工作量绝对少不了，再者，本项目仅有两位成员：潘盛合和李维春，还有就诸子云项目周智坚老师的点评，所以每个人的工作量都比较大。

  

正因为如此，潘盛合和李维春把项目分为3个阶段。第一阶段收集报告，第二阶段讨论研究方向，第三阶段报告修改。具体分工工作为，第一阶段，潘盛合进行收集整理相关报告；第二阶项目组成员和周智坚老师一起讨论，项目组2位成员各责一部分，最后合并形成初稿；第三阶段，李维春负责对报告进行修订。

  

![](../Images/d35b33f73e57307964b24bc958ad6b33.png)

  

由于大家平时的工作都比较忙，所以潘盛合、李维春和周智坚一般选择周末或晚上，通过微信会议进行讨论，总体而言，整个合作的过程较为顺畅。

  

目前，该报告已经经过3轮的讨论修改，并最终确定下来，对于甲方有一定的参考价值。潘盛合表示，由于项目的难度比较大，以及测试报告质量的限制，报告未能覆盖各个层面，希望后续可以不断挖掘出更多有价值的参加点。

  

  

**![](../Images/a85a92116f8130877361f5faf527f7be.png)**
