# 安在新榜，甲方怎么看？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247533383&idx=1&sn=a84508bd6e6f75059bc029c311d0f2ae&chksm=febc2987c9cba0911b52f0d4e8ce3049362ea475c487bf5c6a1b47ab98dfc193cfd92687baf7&scene=126&sessionid=1681310675#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247533383&idx=1&sn=a84508bd6e6f75059bc029c311d0f2ae&chksm=febc2987c9cba0911b52f0d4e8ce3049362ea475c487bf5c6a1b47ab98dfc193cfd92687baf7&scene=126&sessionid=1681310675#rd)

相信大伙都知道了，我们春节前发布的《2020中国网络安全产品用户调查报告》（下简称“安在新榜”）可谓是“一石激起千层浪”！

  

我们邀请了各行各业的“甲方”代表——诸子云（企业网络安全专家联盟）社群会员，从最纯粹、本真的用户角度出发，以自己过往的经验为网络安全产品写出了“用后感”。**我们所有的反馈样本，覆盖了全国30个省市及自治区，49个行业，包含约300家大型企业，150家中型企业，200家小微企业和50家政府/社会机构。**

  

不过神兵利器虽好，出世后也要思量是否用对了法儿。在“安在新榜”发布后不久，我们就发布的调查结果，询问了数十位来自甲方单位的专家代表，从他们处获取进一步的建议，以便完善“安在新榜”的一系列报告。

  

正所谓偏听则暗，兼听则明。我们清楚人无完人的道理，即便没有获得一水的赞誉，但也乐意接受多种意见，绝不强求别人都应有一样的看法。故而在精简版排行、核心内容发布后引发的种种“争议”，我们也在第一时间给出了澄清与释疑，具体系列发文可参见本文推荐阅读。

  
  
  

  

此次针对甲方代表的问卷涵盖了四个方面内容，分别是：是否有参考意义、哪方面内容最有价值、想要进一步了解的话题及内容、对报告的意见或建议。

  

为了更直观地看到甲方代表的态度，请看这份简单的饼图↓

  

![](../Images/45ccf0db25b688939941121e468f9c35.png) 

收集到的甲方反馈中，有85%的反馈者给出了肯定的回答，这不得不说是对安在极大的鼓励。在觉得有意义的代表中，有认为**“通过该报告基本对安全产品的实际价值有了大致的了解”“****知道同类型设备有哪些厂家，以及这些产品在国内的市场情况****”**的，也有觉得新榜数据对**“金融属性和强监管要求的企业尤其重要”**的。

  

不过也有代表认为**“****同类全景图分类较多，由于出现较晚，参考价值较低****”**，或是以为我们拿人钱财替人办事胡乱做了个榜单，这倒也大可不必——我们的根本原则只有一条，便是**“中立客观”**。安在作为第三方独立媒体，自然是有自己要守住的道德操守底线的，一份真实透明的榜单，正是我们的承诺。

  

![](../Images/31fe957b4c14f0c4dc4a611b75764ac2.png)  

![](../Images/6d76953b7b282777be21ef0cbea2137d.png)**高清大图请“阅读原文”**

  

关于**“哪方面内容****最有价值****”**，甲方代表众说纷纭。不过大家基本都认同**“甲方的意见最有价值”**，**“各类产品的部署情况和排名意义较大，对后续产品部署和采用有借鉴意义”**。有专家坦言，具体的五个维度选的很好：**“合规性是作为国企的重要标准，有效性也体现了安全产品的能力”**，这些作为产品选型具有重要参考意义。

  

从**“对安全领域进行了细分”**的安在新榜中，既能够**“便于甲方对目前安全市场上安全产品的现状和主流厂家快速了解”**，知晓同类型设备有哪些厂家可以选择，方便进行后续的产品选型测试，又能进一步**“促进安全行业，尤其甲乙双方定位的清晰度”**。

  

![](../Images/be05ec5f659e39bc267b1bb93454dfa0.png)

  

提到想要进一步了解的话题和类型，甲方代表不约而同地提出了**“****按行业划分的产品选型****”**，金融科技、区块链等行业尤其受关注。他们同时也希冀未来报告中会包含**“****业务APP化，系统部署逐渐云化****等的新业务场景”**，以及**“****寻找和实施解决方案过程中遇到的坑**”。

  

![](../Images/ea65df85b5456ddda34a70acd134419a.png)

![](../Images/3139659e84037a4f7cd37086d038e0f8.png)

  

这些意见无疑是对我们的调研深度做出了一定要求，不过诸位请放宽心，除了这份以年度为单位的“安在新榜”（以广度为特点，力求覆盖面），后续，我们还会选择相对热门的几个细分领域，就具体的“点”做深度文章，**目前的“安在新榜”，只是未来一系列报告的“开场致辞”****。**

对于现有报告的建议，甲方代表的意见从宏观到微观一应俱全：有提出**“****应按年份区分部署率****、****评价权重****”**、**“****区分调查对象，调整评分模型****”**的，也有让我们**“继续加强****技术解析****”**，或者考虑**“****采用相关技术手段（如区块链）确保数据的真实性****”**的。这些我们都听在耳中，放在心底。

  

末了统计下来，大部分甲方代表都表示瑕不掩瑜，希望我们可以继续坚持，将“**整个国内安全领域的产品都做进来****”**，逐步细化和分类，做到更加专业、权威和详实。

  

有这样的鼓励与希冀作支撑，我们又怎舍得让你们失望？

“安在新榜”是系列报告  
  

  

按照我们的计划，“安在新榜”将会包含一系列报告，像《2020中国网络安全产品用户调查报告》是以年度为单位，并力求覆盖整个网络安全大面的“横向”作业，体现出网络安全的广度，接下来，我们还会在此基础上制作针对细分领域的深度报告。

  

系列深度报告可以在两个方面做“细分”：

  

**► 行业细分：**如针对金融业、能源交通、政府相关等典型行业的深度报告；

  

**► 品类细分：**如针对数据安全、终端安全、态势感知等细分品类的深度报告。

  

具体选择哪些“细分”，目前还在策划，欢迎感兴趣的厂商或组织接洽合作，我们期待能有更多懂专业、有经验并乐于合作者与我们一起，共同打造真正有价值的调查报告。
