[**01.安在：****安数云韩正平：登高望远，笃行卓越**](https://mp.weixin.qq.com/s?__biz=MzIzMTAzNzUxMQ==&mid=2652892942&idx=1&sn=2ca0694f57b6fe540137f87c272df108&scene=21#wechat_redirect)

2001年正是多事之秋。先是有名为“红色代码”的蠕虫病毒爆发，军网也受到波及，全网瘫痪。韩正平将新研制的IDS装进了军中计算机，借此找到源头，避免了更大的损失。也同样是在2001年，韩正平学以致用，将自己硕士毕业的安全课题与P2DR模型相结合，打包立项，整合成了“军网安全防护体系”。体系中包含防火墙、入侵检测、漏洞扫描、终端防护等多种功能，在专家院士鉴定之后，他创立的这一体系荣获了国家科技进步二等奖，更是记上了一个二等功：“获奖虽然不容易，更重要的是切实为军网安全发挥了作用。”![](../Images/0863168ff214fe9d25af90ca8de87a39.png)后来，韩正平拜入中科院高能物理研究所网络入侵防范专家许榕生教授名下，博士课题专研安全信息管理。他利用那段日子学来的弥足珍贵的知识，不断学以致用，完善了全军网络安全管理体系：从曾经小打小闹的试点到从上到下的初步管理层级，更新日常安全评估、实验、监测流程等等。谈到在总参这些年最大的收获，韩正平认为，因为长期进行全局性的网络架构工作，必须对网络安全领域不停地深度学习和了解，把握不断变化的大小需求，所以技术和意识都常学常新。再则，他也做了很多实务性工作，无论是网络架构、方案编写、安全事件处理还是组织应急响应、合规等都一一经历和深入接触过，因而不会被新出现的问题难住。入驻安数云担任CTO之后，韩正平遇到的第一个坎儿，就是将心态由甲方转变为乙方。他比较了双方的差异：“甲方考虑得更加全面，也相对简单，需要以点盖面，要技术好用；乙方则不会全面设计，主要是就具体问题针对性解决，同时也要求要有特色和长处，才能从众多厂商中脱颖而出。”在云上安全尚未火热的2016年，安数云就已经开始了对云安全系统的研发工作。目前，安数云云安全整体解决方案以擎安池（云安全调度运维管理平台系统）为中间件，以擎安云为基础平台，通过集成多种自有安全服务及第三方定制化服务，为第三方私有云、公有云提供各种安全服务及丰富灵活的安全方案。“我们要为用户提供更好用、更智能、更安全的产品”韩正平说。[**02.一本黑：****公益寻亲、非法牟利，一门靠“人血馒头”滋养的赚钱生意**](https://mp.weixin.qq.com/s?__biz=MzU4ODAwNzUwMQ==&mid=2247487040&idx=1&sn=31acd0a1276aa9da39e0243b2f7fa2e8&scene=21#wechat_redirect)

我在网上寻找可以申请志愿者的公益组织，最后选择了宝贝回家公益组织，他们不但是百度认证的官方网站，还和《等着我》这个节目有千丝万缕的联系。但是网站最后的友链挂着这样几个网站。我挨个点开这些链接，发现其中一些已经404 not found ，一些网站已经不再更新，但唯独这个中华寻人网还依旧在运行。网页正中间“重赏”“位置不变”几个字让我一下子警觉起来，这看起来像广告位招。公益寻亲，还要收费？“宝贝回家”和《等着我》难道不是免费的么？我只听说给予线索会有重金酬谢，没听说过在网站上登记照片和失踪信息还要收钱。![](../Images/83f7a62f7dce91a92f102e31201a3cbe.png)

  

我又找到另一个寻人网站，上面写着寻人电话。我给网站打了电话，说我弟弟丢了，客服让我加微信，问了我弟弟的样貌、走失过程后，他们义正辞严地告诉我：我应该报警。随后客服表示，想在网站上刊登照片，要交300元的费用。花钱没问题，但我想深入了解一下。可是对方却很谨慎，让我考虑好之后再联系，不然没有合作的必要，并且撤回了之前的收费要求。在看了此网站的收费套餐后，我突然觉得，专业还得是骗子们专业。99元的套餐，可以让你的寻人信息展示在寻人网首页重点关注区，并开通线索短信提醒。而199元的套餐，声称可以入驻全国失散人口数据库，成功率高，看到这里我就觉得他在扯机八蛋。更别说499的套餐了，什么官方抖音、公众号、微博宣传，全在扯犊子。从网站的费用标准来看，除了发布寻人启事要收取的服务费之外，如果有知情者提供信息或线索找到被寻人后，寻人者有义务提供相应的酬金。重点来了，在支付给信息提供者的酬金里，该网站还要从中抽取20%的费用，说是用于网站的发展。网络寻亲的骗子网站再多，目的也是为了挣钱，分辨的方式很简单，只要在寻亲过程中遇到的网站管你要钱，赶紧溜。  
[**03.FreeBuf：****“微软超级漏洞”？关于CVE-2020-0601的官方回复**](https://mp.weixin.qq.com/s?__biz=MjM5NjA0NjgyMA==&mid=2651080137&idx=1&sn=1ae166ed56cd183accd9ce15e0806a1c&scene=21#wechat_redirect)

![](../Images/1da3f523de915bc36a4b7ba41a22f31f.png)

在微软例行公布的1月补丁更新列表中，有一个漏洞引起了大家的高度关注：一个位于 CryptoAPI.dll 椭圆曲线密码 ( ECC ) 证书的验证绕过漏洞——CVE-2020-0601。有意思的是，在微软发布公告后，美国美国国家安全局（NSA）也发布了关于CVE-2020-0601漏洞的预警通告。根据通告可以得知，这个漏洞是由NSA率先独立发现并汇报给微软的（微软在报告中对NSA致谢）。![](../Images/2005eb9a2f5a65f6e284ba85d7722f5f.png)该漏洞位于Windows CryptoAPI(Crypt32.dll)验证椭圆曲线加密算法证书的方式，可能影响信任的一些实例包括（不限于）：HTTPS连接、文件签名和电子邮件签名、以用户模式启动的签名可执行程序。此外，该漏洞可以让攻击者伪造代码签名证书对恶意可执行文件进行签名，使文件看似来自可信的来源。例如，可以让勒索软件或其他间谍软件拥有看似有效的证书，从而促使用户安装。中间人攻击并解密用户连接到受影响软件的机密信息也是主要的攻击场景之一。快速采用补丁是目前唯一已知的缓解措施。尽管尚未出现公开的攻击方式和案例，但建议大家及时安装安全更新。更新后，当检测到有人试图利用CVE-2020-0601进行攻击时，系统将在每次重新启动Windows日志后在事件查看器中生成事件ID 1。**安全建议**除了安装修补程序之外，企业还可以采取其他措施保护端点，比如：**1、从网络流量中提取证书，检查可疑的属性；****2、通过执行TLS检查，但不使用Windows进行证书验证的代理设备来承载流量；****3、在企业内部部署私有根证书颁发机构，并且在特定计算机/服务器位置控制第三方软件的部署和使用；****4、符合条件的企业可以申请加入微软 Security Update Validation Program (SUVP) 或 Microsoft Active Protections Program (MAPP)，从而提前从微软获得安全更新以进行相关的测试分析。**  
[**04.中国信息安全：****移动互联网应用个人信息安全报告（2019年）**](https://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664123487&idx=1&sn=5eec317522785577abc2c26f8f4fbead&scene=21#wechat_redirect)

![](../Images/dd67872587c0d6c32c815b1a3365d0ac.png)

随着移动通信技术的快速发展，移动互联网应用正逐渐渗透到人们生活、工作的各个领域，移动应用种类和数量呈爆发式增长，对社会经济发展的基础性作用日益突显。大数据相关技术快速发展，企业对数据挖掘技术的利用和不断深入，用户数据已成为企业发展的重要战略性资产，数据安全面临的风险和威胁形势越来越严峻。移动互联网应用作为用户数据收集的主要入口之一，其用户个人信息保护问题正逐渐得到国家和社会的广泛重视。由于立法、标准和规范相对滞后，移动互联网应用个人信息保护水平参差不齐，用户信息强制收集、过度收集、非授权转移共享、个性化展示和定向推送不规范、账户注销难等问题严重威胁了广大人民群众的切身利益，进一步推进移动互联网应用个人信息保护工作已势在必行。《网络安全法》、《电信和互联网用户个人信息保护规定》（工业和信息化部令第24号）和《移动智能终端应用软件预置和分发管理暂行规定》（工信部信管〔2016〕407号）等多项法律法规，明确了收集使用用户个人信息的合法正当必要原则，规范了移动智能终端应用软件预置和分发行为。此次，中国信息通信研究院中国泰尔实验室联合人民网、中国互联网协会重点分析移动互联网应用用户个人信息保护发展趋势和安全挑战，梳理移动互联网应用用户个人信息保护常见问题，分析用户个人信息保护要点及实践案例，为企业规范移动互联网应用用户个人信息收集使用行为提供参考，促进用户个人信息保护意识提升。同时本报告提出移动互联网应用用户个人信息保护十大倡议，希望行业携手提升移动互联网应用个人信息保护能力，为用户提供更安全放心的移动互联网应用服务。  
[**05.E安全：****“红海地区”陷入大面积断网危机 也门海底网络基建脆弱**](https://mp.weixin.qq.com/s?__biz=MzI4MjA1MzkyNA==&mid=2655306012&idx=1&sn=f65e9a8f40d425e25f2f38ac15552aef&scene=21#wechat_redirect)

![](../Images/29c8f82efd94d5745f12fc58e889f3a2.png)

据外媒报道，上周也门地区的2800万网络用户的互联网一片漆黑，直到昨天网络都还没有完全恢复。实际上，自从上周四意外切断了一条海底电缆以后，整个红海地区的网络连接速度一直很慢，甚至可以说是部分区域处于断网的状态。目前的互联网行业，把“云”视为是流行的技术，但实际上在海底，一片巨大的电缆系统纵横交错，遍布了世界各地，为每个大陆和每个国家提供了网络连通性。但是，在海底的恶劣条件影响下，电缆会遭受到意外的断裂和割伤！![](../Images/1db6ce5c8743665861b69f5dddba86d1.png)近几年，与此次红海地区海底电缆损坏类似的事件屡见不鲜。2008年，由于同时切断连接中东，欧洲和亚洲部分地区的两条电缆，所导致的14个国家和地区停电。2017年，由于南非的一位农民用拖拉机损坏电缆，津巴布韦地区大约有五个小时互联网访问中断。对于此次事件，除了也门地区以外，科威特，沙特阿拉伯，苏丹和埃塞俄比亚等地区都受到了上周电缆事件的重大影响，这甚至影响了远至科摩罗和坦桑尼亚地区。在最严重的也门地区，一根电缆的意外切断导致该地区的网络容量下降了80％。

Oracle Internet Intelligence的互联网分析主管Doug Madory对此表示，该地区在过去很长一段时间内一直受到电缆意外切断的困扰。尽管该地区安装多少的互联网电缆，该国仍然会因为丢失了一条电缆而导致大面积断网，甚至有可能因为添加的电缆越多越复杂，就会有越多的电缆被卡死或折断。

  

[**06.看雪学院：****CVE-2018-8353漏洞分析笔记**](https://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458302823&idx=1&sn=0601badf36e3caa81dcdae1d65fc0e1a&scene=21#wechat_redirect)

![](../Images/68b0fc3637346f76da4ada43db84c6ca.png)

脚本引擎开发者在设计GC(Garbage Collect，简称GC)时追踪指针不善导致的UAF(Use-After-Free)是一类常见的漏洞，这类问题在主流脚本引擎中都比较常见，本文用一个例子来向读者介绍这类漏洞的成因与分析思路。![](../Images/4780daa7a39f990b4a85cdf43800e6f1.png)**漏洞简介**CVE-2018-8353是谷歌的Ivan Fratric发现的一个jscript漏洞，该漏洞在2018年8月被修复。这是一个UAF漏洞，Ivan Fratric在披露页清晰地描述了该漏洞的成因：通俗一点说就是RegExp类的lastIndex成员没有被加入GC追踪列表，如果给它赋值，在GC时会导致lastIndex处存储的指针变为悬垂指针。后续再访问lastIndex时，即造成一个典型的Use-After-Free场景。jscript模块目前已发现多个类似漏洞，例如CVE-2017-11793，CVE-2017-11903，CVE-2018-0866，CVE-2018-0935，CVE-2018-8353，CVE-2018-8653，CVE-2018-8389，CVE-2019-1429本文试图通过CVE-2018-8353一窥这类漏洞的成因，并在此基础上分析谷歌PoC中的信息泄露利用代码。读者将会看到一个GC导致的UAF如何被转化为高质量的信息泄露漏洞。**分析环境****Windows 7 SP1 x86****Windbg****IDA Pro****jscript.dll 5.8.9600.17840 (IE11)**由于篇幅有限，具体分析过程请点击原文查看  
[**07.游侠安全网：****人大代表：要把网络安全像消防安全一样重视起来，定期检查、演练**](https://mp.weixin.qq.com/s?__biz=MjM5NjI0NjcwMg==&mid=2652154280&idx=1&sn=5d6ee19622637841bd8133ddd123c8b2&scene=21#wechat_redirect)

![](../Images/c33de303ccf9d12e6630c8be065bb381.png)

网络、计算和存储是大数据的三大基础设施。但很多人并不知道，除此以外，全球还有一个千亿美元级产业：网络安全。上海市人大代表、万得信息技术股份有限公司董事长陆风说，可以说，网络安全已经成为大数据第四大基础产业。![](../Images/28db06b278460eb5340e6c8006aebc4f.png)

  

陆风说，当前，受全球网络安全攻击的地区分布主要集中在中美两国，在国内看，主要集中在江浙沪、广东和北京。“可见，越是经济发达地方，受攻击的可能越大，需保护需求越大。”与此同时，随着互联网的发展，各类软件层出不穷，保护网络安全的相关技术人员面临严重匮乏的局面。数据显示，2019年，全球网络安全人才缺口扩大到300万，且主要集中在亚洲，仅中国就存在150万缺口，占一半以上，以至于“网络犯罪人员的增长速度，比网络安全保护人员的增长快得多”。陆风认为，目前，上海在网络安全防范方面较为薄弱，网络安全技术人员缺乏，网络安全事件无法及时响应，造成极大损失。为此他呼吁，上海应加快网络安全立法的修改，扩大网络安全保护范围。“只要是联网的设备，哪怕是一个机床，一个话筒，都要有安全防控规范。”陆风说，“要把网络安全像消防安全一样重视起来，定期检查、演练。”他同时建议，上海应该加快网络安全人才的引进培养，吸引更多人才到上海落户，并探索高校与网络安全公司合作培养相关人才。
