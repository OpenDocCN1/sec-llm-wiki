# 它的最后一个月

是夜。我蹑手蹑脚地穿过回廊，轻声推开门，来到了它的床前。

它好像对我的到访毫不意外，披衣坐起，招呼我在床边坐下。

  

“我来了。”“你来了。”![](../Images/58acefc7dc12ae99b43880332859839e.png)Win7旗舰版 登入界面我自觉像一只前来报丧的乌鸦，因而扯不出一点客套和寒暄；它却面带笑意，帮我倒了一杯茶。我端着温热的搪瓷杯，心里五味杂陈。“...你都知道了？”“这有什么难猜的，毕竟这是...哈哈，年纪大了记性也差，我都忘了多久了。”“如果不算实习期，到今年整十年了。”“嗯，没错。”![](../Images/e6522af1e38fa2934cdd919fdcaca675.png)2020年1月14日，Win7系统将停止更新它比划了个高度。“你那时好像才...这么高。”我默默注视着它充满怀念的慈爱面容。“现在嘛，已经是个能独当一面的大人了。”“...我确实受了你们家许多照顾，从第二代那时候开始。”“我记得，你告诉我，是98把你领进来的。”![](../Images/8d673c17d08ba839e57a362543b16af7.png)Win98它又陷入了回忆。“98其实严格来说不算我的长辈，2000才是，NT之名是由它传下来的。”“在我看来，你们都有一个共同点，劳模。”

  

![](../Images/ab847240d6a03fe1553615bf12a164cb.png)Win2000从发行到落幕也经过了十年它笑了，笑着笑着又大咳起来，我赶忙帮它顺气。“咳咳，最劳模的，还是我上一辈那位。”“XP吗？”“没错，XP是我们家的顶梁柱。”![](../Images/9c6f82c28732cb4f6e2fbe68f77e8e60.png)Win XP经典的关机界面“说到这个，你还记得2017年3月吗？”我浑身一凛，忍不住坐直了。“肯定不敢忘，是‘永恒之蓝’那次对吧？”“那真是让我去了半条命，要是没有后来‘CVE-2017-0143’的帮助，我可能早就退休了。”![](../Images/82f6437ed02adce265d7476a9fcb2935.png)“永恒之蓝”及其衍生病毒利用了Win7的严重漏洞“这跟XP又有什么关系呢？”它眨了眨眼。“XP都已经退休三年了，还是热度不减，导致很多人被波及到，所以大老板没有办法，给它开了特别药方。”我“啊”了一声。“此一时彼一时，现在国民心里面的，还是你。”![](../Images/5389a288f826a5367dc02c459ff6770b.png)在多代系统共存的情况下，Win7销售表现依然强势它不说话，只是盯着我看。“现在选你跟选10的，是六四开。”“...它六我四？”“你六它四。”我原以为它听了这句话会高兴起来，没想到它反倒更愁了。![](../Images/509c7f31b9b9888ce3709e02a4233d88.png)百度统计流量研究院的数据表明，仍有58.5%的用户在使用Win7“这难道不是好事吗？”“你觉得，好在哪？”它反问道，我一时哑然。让别人都记得不是很好吗？![](../Images/df34b5447dd4d6404a5e6b814dabb8a9.png)许多人习惯了这面彩色旗帜“小10青出于蓝而胜于蓝，Defender给了它足够坚固的保护，”它顿了顿。“而我已是强弩之末，油尽灯枯...”“...别这么说。”我们相顾无言。![](../Images/2b4b0a8a8066ea090c3bc6b3ce1211cd.png)微软的应对：提供后续行动的建议

“天亮了。”

它突然出声。我抬头一看，过真有微光自地平线上缓缓析出，不禁窘然。“不必在意，事实上，我们并不是完全互相取代的。”![](../Images/16e92ea12d12ad4abfec1b50ae42453e.png)Win10Logo保留了经典的旗帜

未见它有一点点怨愤，我更觉难以割舍。

“我们代代传承，就如同你们和祖辈血脉相互连接一样。”日头慢慢爬升，我必须离开了。“所以这次，也绝不是再见。”
