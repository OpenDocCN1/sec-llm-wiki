# 《本市公共区域电子屏及相关信息系统安全自评估指引》系列微视频之技术防护篇

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247533271&idx=2&sn=3916b5208f1f0b67832abf100e1bafa3&chksm=febc2817c9cba101ceeda42226c67ba211c9216ced4ac0421c444ee61f014efdc5414a01327b&scene=126&sessionid=1681310688#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247533271&idx=2&sn=3916b5208f1f0b67832abf100e1bafa3&chksm=febc2817c9cba101ceeda42226c67ba211c9216ced4ac0421c444ee61f014efdc5414a01327b&scene=126&sessionid=1681310688#rd)

为进一步规范、指导本市公共区域内电子屏及相关信息系统的安全防护工作，有效防范电子屏发布法律、行政法规禁止发布的信息，推动《本市公共区域电子屏及相关信息系统安全自评估指引》的落实工作，在上海市公安局网络安全保卫总队的指导下，上海市信息网络安全管理协会组织专家围绕《指引》的总体编制情况、技术防护、运营管理、网络攻击防护等内容，制作了系列微视频，为电子屏运营责任单位开展有针对性的安全防范、安全自查工作提供技术措施及运营管理建议。

《本市公共区域电子屏及相关信息系统安全自评估指引》之技术防护篇微视频结合案例，分别解读了电子屏播控系统各组成部分，以及电子屏控制方式可能存在的安全风险，并根据各项风险提出有效的安全防范措施建议。
