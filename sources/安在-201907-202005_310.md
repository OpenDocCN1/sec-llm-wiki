# 《本市公共区域电子屏及相关信息系统安全自评估指引》系列微视频之攻击防护篇

为进一步规范、指导本市公共区域内电子屏及相关信息系统的安全防护工作，有效防范电子屏发布法律、行政法规禁止发布的信息，推动《本市公共区域电子屏及相关信息系统安全自评估指引》的落实工作，在上海市公安局网络安全保卫总队的指导下，上海市信息网络安全管理协会组织专家围绕《指引》的总体编制情况、技术防护、运营管理、网络攻击防护等内容，制作了系列微视频，为电子屏运营责任单位开展有针对性的安全防范、安全自查工作提供技术措施及运营管理建议。

《本市公共区域电子屏及相关信息系统安全自评估指引》之攻击防护篇微视频为大家解读黑客们攻击公共区域电子屏的一些常用攻击手段及其应对方法。建议电子屏运营责任单位既要利用技术手段防范恶意的网络攻击、科学管理电子屏底层系统的控制权限，同时也要完善管理手段，加强对关键业务信息的保护、建立播放内容的审核管理制度，有效保证电子屏的安全运营。
