# 她常将快递箱和单据丢门外，夜里接到陌生男来电要求登门

前不久，狗哥做了一个小型调查，即《你个人隐私信息泄露之后，都遇到了哪些可怕的事情？》，同时希望更多朋友能够就此话题，向狗哥提供更多的真实案例。

  

最近几日，狗哥陆陆续续收到了不少朋友的进一步反馈，见之真是触目惊心，三观震撼。

  

其实，很多案例，我们并不能彻底摸透背后的根源和罪魁祸首，但是，我们可以通过搜集整理大量朋友的真实遭遇，给广大读者提供一个案例借鉴。

  

如此一来，就算你无法刨根问底，**一旦自己遇到相似事件，便有了面对和处理的经验，方能做到遇事不乱，继而从容应对，减免人身伤害和财产损失。**

  

下面，狗哥便将近期收到的一些反馈案例整理而出，以供大家阅读参考。

  

![](../Images/9d772f2d47f117d42e6f02d84b7e7d21.png)

  

“**小豪**”是一名在校大学生，他说的遭遇与支付宝有关，让人感到发毛。

  

为了方便阅读，狗哥将长篇大论的案例反馈，以1234的方式编排精简，去粗取精。

  

1.上月，小豪接到一个陌生电话，称他在某天某时，在某家电商那里购买的某款产品，检测出有毒金属严重超标的问题，会直接影响身体健康；

  

2.小豪心生怀疑，但对方说出了该笔交易的金额、时间、收货地址以及收货人姓名和电话号码，使得小豪不得不信确实是卖家那边出了问题；

  

3.对方要求小豪将产品返厂寄回，称会有快递员上门取件，与小豪确认了地址之后，对方自称是支付宝理赔中心客服人员，该笔交易的赔偿金已经到达小豪支付宝账户，让小豪查收；

  

4.但是，对方并没有挂断电话，而是让小豪一步一步按照要求进行操作。继而又说小豪蚂蚁信用分不够，返还的资金被自动退回了，需要开通备用金；

  

5.小豪信以为真，就按照对方要求操作。开通备用金后，对方要求小豪全部取出备用金500元，承诺取出500元后会帮小豪关闭备用金，无需偿还500元备用金。因产品赔偿金为132元，需要小豪退回368元；

  

6.转给对方368元后，对方要求帮小豪提高信用等级，试图开通蚂蚁借呗，在身份验证的过程中，小豪越想越不对劲，坚决要求对方先帮他关闭备用金。对方纠缠几下，见事情败露，便挂断电话。

  

细观“小豪”案例，不难发现，“小豪”是在遭遇订单详细信息泄露之后，才遭遇到如此缜密的诈骗行径。对方先趁“小豪”不备，骗取备用金小钱，继而试图染指蚂蚁借呗的大钱，幸好“小豪”及时明悟，方才避免了更大的损失。

  

此事过程，狗哥也很奇怪，究竟是什么环节泄露了“小豪”的订单详情。如果“小豪”自己保护得很好，没有被黑灰产窃取信息的话，那问题应该是出在商家那边。

  

如此看来，只要通过电商买东西，信息不可避免要被泄露，地址和姓名可以模糊化处理，但电话总不能写假号码。因此，遇到此类事件，切不可轻易相信那些自称是银行、公安局、支付宝等企业机构的工作人员，尤其是涉及到协助你操作金钱的交易，更需警惕。

  

![](../Images/e3aa1a89ca736eafa884b998db894192.png)

  

“**HC**”是一位女性白领，年方三十，未婚未育，独自居住在某省会城市的自购公寓房内。

  

“HC”女士的遭遇，给广大单身女性提了个醒，个人信息泄露，有可能会危及到人身安全，对待个人隐私信息，必须要慎之又慎。

  

1.前几日“HC”下班回到家，大约晚上八点左右，她接到了一个电话，一名男子自称是燃气公司的工作人员，说通过远程检测到她家燃起管道出现漏气现象，需要紧急上门进行维修处理；

  

2.“HC”并不相信，以为对方打错了，或者是胡编乱造。没想到的是，对方道出了她的真实姓名、燃气公司账户号、家庭门牌号、身份证号，且准确说出了燃气管道的安装位置。她又惊又怕，此时一人在家，若来者不善，根本无法招架；

  

3.情急之下，她一边耐心咨询对方相关事宜，一边用微信联系了同小区居住的朋友，让朋友打电话给燃气公司客服和小区物业管理处，得到的回复均是务必不予理睬，燃气公司只会联合物业，定期进行上门检查，检查前会贴出告示，不会夜晚打电话说登门修理；

  

4.“HC”只好匆忙挂断电话，让物业登门检查到底有无漏气，确认没有漏气之后，她不敢一人在家睡觉，只好睡在同小区朋友家。

  

在“HC”反馈遭遇的过程中，狗哥一直在思考为何会出现如此惊悚之事，到底是哪个环节泄露了她的个人隐私信息。

  

狗哥想到了快递面单以及各种缴费单的随手丢失导致信息泄露的可能性，便如此发问，她说每逢收快递，都是在家门口拆箱，然后把纸箱放在门口，等清洁人员和拾荒人员收走，从未将快递面单撕毁。

  

此外，她的一些缴费单据，如宽带安装单、手机卡办理业务单、燃气缴费单之类，都是随手扔在门口纸箱中。

  

如此一来，可以推断，大概是同楼层不怀好意的男士，早已察觉到“HC”是单身女性，且知道她的住所，弄到了她的很多缴费单，继而导演出一场上门维修燃气管道的戏。

  

所以，狗哥再度郑重提醒，各种单据，万勿随意丢弃。否则给心怀叵测者获得，真不知他会干出什么事来。

  

![](../Images/71779795e2b95a38c03e7cffbad6ca16.png)

  

“**橙色黄昏**”是一名已婚妈妈，平时就带带孩子，上上班，没事喜欢逛淘宝，几乎每天都要网购一点东西，否则就感觉浑身不自在。

  

先说下结果吧，“橙色黄昏”一共被骗了6000多元，差一点就会被多骗3万多元，幸好她提前察觉到了不对劲。详情如下：

  

1.“橙色黄昏”某日接到一个电话，自称是淘宝工作人员（冒充阿里员工的骗子真TM多），说在淘宝后台处理数据时，出现了失误，将她上传成为经销商，以后每个月都会扣500元，若不取消，则会一直扣下去，取消的话则不会有任何影响。

  

2.她半信半疑，与对方进行了更深入的交谈，被对方套出了各种银行卡和存款余额。对方称欲要取消，则需要交纳一部分保证金，保证金在取消之后会原账号退回。随后，对方给出了一个银行卡号，她将信将疑转去了2000元；

  

3.对方骗得2000元，并未就此罢休，继续给她打电话称，刚才她没有严格按照要求操作，系统出错卡住了，需要信用卡才能解除错误。对方给了她一个银联网址（实则是高仿钓鱼网址），她点进去之后，被对方各种操作步骤绕晕了，又转给了对方4000元；

  

4.到此，对方还未罢休，继续打电话说还需要其他银行卡，提高信用等级之类，“橙色黄昏”越想越不对劲，要求对方将6000多元退回，对方自然不肯，双方纠缠几句，对方就挂断了电话。她想要回拨，发现来电是港澳台号码，根本打不通。

  

此案例中，骗子最初并未掌握“橙色黄昏”太多个人隐私，只是通过一些途径，获知了她的姓名、电话、地址、淘宝账户等信息。

  

骗子是通过一些话术，让“橙色黄昏”在无意识之下，自己说出更多的隐私信息，比如银行卡号、账户余额等，继而通过一些手段，让她暂时失去理性思考能力，趁乱得手。

  

在此，狗哥想要再度提醒一下，任何冒充相关企业机构工作人员让你转账的要求，请务必不用搭理。除非你因欠债被人告上法庭，法院会强制你还款，如果你账户有钱，则会在不经过你同意的情况下扣除。否则其他任何情况下，别人都无权要求你转账汇款，更不会有什么激活系统、解除错误等操作需要付钱才能办好的情况。

“**追风者**”是一名留学生，他的遭遇是发生在一年前的大学期间。

  

至今，他还对自己信息泄露的途径感到奇怪，因为他参加了GRE（全称Graduate Record Examination，美国研究生入学考试）考试后，从未向任何人泄露自己的详细信息，别人只知道他通过了GRE考试，连分数他都没告诉别人，但是，却有人知晓了他考试的详细信息。

  

1.大三时，“追风者”幸运地通过了GRE考试，并且考出了一个相当不错的分数。但他为人低调，同学只知他通过了考试，均不知他具体考了多少；

  

2.大半个月后，他接到一个陌生号码发来的短信，询问他愿不愿意做枪手，替人代考GRE。只要达到330分，就有数千元奖励；若能考到340以上，回报会更大，希望他好好考虑一下；

  

3.他深知替考的风险以及事情败露的后果，那几千上万元，比起自己前途来简直不值一提。所以他就未搭理对方。未料一小时后，对方又发来信息称，他们都是ETS（Educational Testing Service，美国教育考试服务中心）考场老师，全程均有内部人员操作，不会产生任何风险，无需担心事情败露；

  

4.“追风者”付出了巨大的代价才通过了GRE考试，想到居然有代考黑幕，不由不满加好奇，回发短信问对方知不知道他是谁，怎么知道他通过了GRE考试，如何证明说的是真的。片刻之后，他收到了短信，里面有他真实姓名、真实考分、所在院校等信息；

  

5.他感到十分的震惊与不可思议，随后继续追问，对方均避而不答。他觉得，如果对方说的是真的，他们是ETS考场老师，那么他的个人信息很可能是被ETS泄露出去，ETS内部与监考人员之间，已经有黑产介入，形成了一条泄露考生个人信息、联系优秀考生、入场代考等完整的产业链。

  

其实在交流的过程中，“追风者”称那时他很担心，一旦拒绝对方，对方会报复他，因为他的全部个人信息均被对方掌握，对方在暗他在明。

  

所以，全程交流，他都是在非常小心和卑微的态度中进行，生怕激怒对方，惹祸上身。

  

虽然狗哥无法判断，到底那些人说他们是ETS考场内部人员是真是假，不可否认的是，黑灰产已经深入到我们工作生活的方方面面，衣食住行，都已经有了他们的身影。

  

黑灰产最强大的利器，就是通过各种途径，获取我们的隐私信息，继而通过种种套路，对我们进行下钩，一不留神，就能成为他们的囊中之物。

除此之外，狗哥还收到一些较为简单的案例反馈，相关案例如下：

  

“

“袁佳”称：“某天上午陪老公去银行取款存款，无意间说漏嘴将要拿钱是买车。两小时之后，老公就接到了某保险公司来电，殷勤向他推荐车险服务。我当时吓得一头汗，万一银行内鬼将我们的信息泄露给绑架犯呢，后果不堪设想。”

  

“在水一方”称：“去年，我和男友商量着找哪家婚纱摄影公司拍结婚照，后来上网搜索了很多，包括淘宝、知乎、微博等平台都有搜索。然后过了不久，就有一家婚纱摄影店的微信加我，问我是不是要拍婚纱照。我就纳闷了，就搜搜也能泄露个人隐私信息？”

  

“龙卷风”称：“我爸在某招聘网站，投了一份做仓储搬运工相关的工作，只投了一家。但是随后几天，我爸就收到很多条短信，有搬家公司、仓库装卸工、快递分拣员等相关工作。莫非很多招聘信息就是网络钓鱼，专门钓取个人信息的？”

  

“梦到你傻”称：“我前年在一个网络购彩网站，注册了一个账号，主要是看一些专家推荐体彩预测。在接下来的两年中，我不断收到各种乱七八糟的博彩垃圾短信，以及各种推荐我玩赌博游戏的垃圾电话，真是受够了。”
