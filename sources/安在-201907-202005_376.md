# 你个人隐私信息泄露之后，都遇到了哪些可怕的事情？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247533244&idx=1&sn=45d2f68f71f8f525217e121ada37bf05&chksm=febc287cc9cba16a23fc38c9dec663afc58de0daf777bc0c244f0a4eeef9380849eb3a33109d&scene=126&sessionid=1681310692#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247533244&idx=1&sn=45d2f68f71f8f525217e121ada37bf05&chksm=febc287cc9cba16a23fc38c9dec663afc58de0daf777bc0c244f0a4eeef9380849eb3a33109d&scene=126&sessionid=1681310692#rd)

互联网时代，个人隐私问题一直是经久不衰的话题。

  

因为这些年来，个人隐私信息的泄露并没有随着法规政策的完善而销声匿迹，反而愈演愈烈，已经到了泛滥成灾的境地。

  

近日，狗哥翻看朋友圈，无意间见一友人吐槽：

**“刚接到自称神州租车客服的电话，说我昨天租的车今天到期，让我还车。****能够准确说出我的姓名、电话、身份证号和身份证地址。****我问我租车的时候交押金了吗,他说当然交了。****然而我并没有神州租车app,更别提交过什么押金了。****骗子真的无处不在，而我们永远不知道自己重要的个人信息是在何时何地泄露的。****”**

  

![](../Images/18362fcc783972dcee9bc65349ad8819.png)

  

狗哥当时就被震惊了。你想想，一个你完全不认识的人，突然打电话给你，并且知晓你的一切信息，你是不是有种被扒光一切的冰寒刺骨？是不是觉得对方宛若幽灵般的鬼魅恐怖？

  

由此，狗哥觉得，有必要与广大读者探讨交流一下，在你个人隐私信息泄露之后，都遇到了什么可怕的事情。

  

“前车之覆，后车之鉴”，在探讨交流中，咱们用发生在自己身上的案例，来告诫警示所有读者，以后若是面临同样的事件，该如何面对，以及如何处理。最重要的是，能够更好地保护自身安全，防止钱财遭受损失。

  

随后，狗哥将这个话题抛到安在官方粉丝群“**硬核安寨**”（加群方式在文末）中，当即引来了诸多粉丝的热议。

  

![](../Images/e0b98f0b55857638e02e7cd83eb7ee63.png)

  

寨迷**“碧落扶摇”**首先道出了她曾经遇到过的可怕事，她说：

  

**“两年前，我刚入职一家集团，对外地新人提供住宿，单人单间。但是，房间欠了1800多元电费，需要我先交费，然后拿到财务报销。我在财务部办理了一些手续，领卡然后去交费。”**

  

**“在坐公交的途中，收到一条短信，短信中有我真实的姓名，对我说不用去电力局交费，把电费直接打到某某账户，即可激活。奈何我当时取了现金，卡里没1800多元，只好打电话给财务主管。她说千万别打钱，那是骗子，一定要去电力局交费才行。我吓了一身冷汗，至今不知到底是哪个环节泄露了个人信息以及我要交电费的事情。”**

  

![](../Images/577d4ec2ca802526a9533088e1a2770c.png)

  

接下来，所有群友的矛头，都一致指向了内鬼作案。狗哥也有着同样的看法。

  

![](../Images/dcc20312344c0a4c3fc7a96f115be097.png)

  

“**碧落扶摇**”提到了集团。一般而言，集团属于大型企业，动辄成千上万人。

  

俗话说：“林子大了什么鸟都有”。所以，集团之中大概是有人从事黑灰产，或者与黑灰产有千丝万缕的联系，甚至就是黑灰产安插在集团内部的奸细。

  

否则的话，诈骗也很难如此精巧逢时。对方知道你要交电费，知道你将去哪里，明确要你把电费打入什么账户，没有内鬼，绝无可能如此神机妙算。

  

当然“**碧落扶摇**”比较幸运，初入职场卡里没钱，只好打电话向财务部门求助。恰好是这个电话，让她避免了被骗。

  

所以从“**碧落扶摇**”经历的案例中看出，一旦遇到打钱之类的短信，务必打电话询问相关人员。

  

就算现在有模拟人声的AI，声音可以骗过你，但AI还没强大到可以让你打向某人的电话转移到骗子那里，并且AI的情商远不及人，几段对话，就能分辨对方真假。

  

![](../Images/63672a8ed85d0c79f0ef13d0d783949f.png)

  

紧接着，寨迷“**底层工程师KC**”（陈欣炜，江湖人称KC，现招商银行全资子公司招银云创从事合规和信息安全工作）也分享了亲身经历的事件。他说：

  

**“前年，休息天我在家窝着，一个电话进来‘大哥你好，我叫傅彪，东北人，你是不是叫XXX，你老婆叫XXX，家里有个孩子，X岁，叫XXX，家里住杨浦区XX路XX号XXX室，兄弟手头有点紧，这边人口也多，要一点慰劳费……’我想了想，还是说大哥你打错电话了。”**

  

**“后来想想，如果硬刚的话，我这个地址你能说出来也是牛逼的（地图定位不出的那种）。对面是110，楼下是110，街对面也是110，我想你来刚我啊。最后结论是人不能贱，毕竟对方数据挺对的，万一来真的绑票，我也不太好搞。于是，在网上混淆个人信息是必要的行为。”**

  

![](../Images/a98f887cd551778a10c22a1a21157845.png)

  

直接拿家人的安全作为威胁进行诈骗（即便对方根本没打算行动，只是言语恐吓），换做一般人，绝对会乱了阵脚。

  

因为对方能够精准地报出你家的地址和家人的信息，你会觉得有一只无形黑手，将你家笼罩，随时面临生命威胁。

  

一旦心理素质不够硬，对骗子进行妥协。**骗子不但获得了钱财，而且断定他获得的信息确为真实。****你泄露的个人隐私信息，很可能将从庞杂的黑产数据库中提炼出来，归类为“优质客户”，用作更加精耕细作的诈骗行为。**

  

毕竟，黑灰产也讲求“有效性”和“成功率”，容易上钩的鱼，换种手法和套路，依旧容易上钩。

  

对此，诸多群友表达了各自的看法，并进行了一些揣测，不过依旧没能给出个人隐私究竟在哪个环节泄露出去，只能说每个环节都有可能。

  

![](../Images/7c5083da3225f5fae82f190fa3ce04c5.png)

  

随后，**寨迷“底层工程师KC”**又分享了第二例他亲身遇到的信息泄露可怕事件。他说：

  

**“第二次，我有事情要转给表弟35万，2008年。电话刚打完，他说短信把帐号给我。1秒后收到个短信，打款到某行XXX，XXXXXXXX。我就去银行了，排队的时候我想有问题，我弟不会搞某行的（他丫的看不起某行），于是再一个电话，我弟电话里蒙蔽，说短信还没发。”**

  

![](../Images/1c873ba30edb6e7cfe76f0ec202788ef.png)

  

针对此事，狗哥也没能想出是什么原因（以后会咨询相关专家，期待给出答案），情况与“碧落扶摇”案例有相似之处，但不同的是，“**底层工程师KC**”是挂断电话对方即发短信，而“**碧落扶摇**”则有一段时间延迟。

  

所以，“底层工程师KC”应该是遇到了对电话实时监听，“碧落扶摇”则推断是内鬼所为。

  

群友们也进行了简单的推测，不过也是众说纷纭，未能有确切解释。

  

![](../Images/d541092f3291c4c968b41ed71ccd96f7.png)

  

随后，寨迷“**Sinkyres**”也分享了一件亲身经历，她说：

  

**“我妈年初被骗了3万多积蓄。骗子诈骗手段很老套，就是发短信给我妈，说账户涉黑，为了资金安全，请配合公安部门调查，要把钱打入安全账户。”**

  

**“本来我妈是怀疑的，但是对方能够将我妈我爸还有我的信息全部告知，无一差错。甚至连我家两套房的地址都知道，并且居然真的是用本地110（公安局）的电话打来的。我妈就慌了，然后把卡里3万多打给了对方。”**

  

![](../Images/cb23a5d9982de6bd316a7269e8a3ea0b.png)

  

从“**Sinkyres**”的分享中可以看出，骗子的手法比较老套，但狗哥觉得，关键不在于手法老套，而在于骗子掌握了你大量真实有效的隐私信息。一旦这些信息与你家庭真实情况一一匹配，你就会默认对方说的一切都是真的，诈骗信息恰好就掺杂在这些真实的隐私信息之中。

  

群友也都针对此事，进行了一系列猜测，同样未有确切结果。

  

![](../Images/0b5eff71c0b3dd36d3787470d43c149d.png)

  

这也不怪群友不够睿智聪慧，而是如今泄露隐私的渠道实在太多，鬼知道黑灰产究竟从哪些渠道弄到了你的个人隐私，并将这些信息拼凑在一起，还原一个真实完整的你。

  

在粉丝群之外，狗哥也向部分亲朋好友发出了相关话题，也得到了一些有效的回复。

  

一位昵称为“**夏榆**”的朋友说：

  

**“去年年底，我妈突然给我打电话，问我在做什么。我说在工作，有什么事吗？我妈说接了个电话，显示是你的号码，说你在他们手上，让你爸赶紧拿钱去赎人。我连忙说那是骗子，别相信。没想到我妈十分平静地说我知道。我就好奇我妈疑神疑鬼的性格，怎么就这么淡定。就问我妈你们接到这电话，难道不慌吗？我妈说，那是你以前用的号码，都停机一两年了吧。”**

  

**“原来如此。幸好我聪明睿智，因为以前那号码，是专门用来注册各类APP和网站，虽然家人都知道那个号码，但我从不用那号码打电话给家人。后来垃圾电话和短信实在太多，我就停机销号了。骗子那里获取的我的手机号还是那个号，说明我私人号保护得很好，极少有垃圾电话和短信骚扰。”**

  

此事虽然骗子没有得逞，但细想起来极为可怕。幸好“夏榆”平时个人隐私保护得不错，父母能在第一时间联系到那个未被泄露的手机号码。

  

其实，骗子用这种方法诈骗，绝对不止骗这一例，漫天撒网，总有一条鱼会上钩。而这一切，均建立在个人隐私信息泄露的基础上。

  

黑灰产想要诈骗，对你一无所知，根本无从骗起。毕竟现代人再也不是那个活在深山野林、不问世事的无知莽夫，一般性诈骗手段，已经很难让人上当。

  

![](../Images/2e45d8b8f72e04615ff51b321d56318f.png)

  

另有一位名为“**熬夜帝**”的朋友，也分享了一件比较可怕的案例。他说：

  

**“我去年遇到的事才叫可怕。我在淘宝上买了一款收费软件，但不久后就不能使用，随即找客服，客服爱搭不理，死活不解决问题。我一气之下，就给了一个差评。接下来，我就收到各种威胁、谩骂（对方不是用客服号，而是用马甲号，但我知道肯定是他们搞的鬼），他们说已经掌握了我详细信息，让我晚上睡觉小心点。”**

  

**“我起初没当回事，因为购买软件，并不需要邮寄，我只是随便写了家附近的商场地址和化名。****没想到几天之后，我爸我妈都收到了威胁短信，并把我家详细地址、几口人、身份证号、在哪里工作都说了出来。****我当时就慌了，我妈也吓得睡不着觉。”**

  

**“我就找客服，客服说不是他们搞的，让我别乱诬陷。****折腾了好几天，我只能认怂，主动删掉了差评。****接下来我家人就再也没收到恐吓骚扰。后来我细想，一定是我家的隐私信息早就被泄露了，对方不知道通过什么途径，获知了我的详细信息。所以一定要保护好个人隐私，因为关键时候真的很吓人。”**

  

此事确实很可怕，被一个无形的人威胁恐吓，甚至比前文“**底层工程师KC**”遇到的恐吓更加吓人。

  

因为这是一起有针对性的威胁事件，对方一旦狗急跳墙，或许真的会干出什么危害人身安全的事情来。

  

正如“**熬夜帝**”所细想的那样，正是个人隐私信息早已泄露，对方才能掌握他的大量信息，从而使得恐吓得逞，并对他和家人造成了巨大的心理阴影。

  

![](../Images/9eb55e4c6ab0cd9314a7618aa7973ea5.png)

  

本次案例分享就到这里，但此话题并未就此终结，狗哥依旧在不断搜集整理，择日继续与大家进行分享剖析。

  

如果您也遇到过隐私信息泄露后的可怕事情，可以加**狗哥微信（zougou888）**进行分享。日后狗哥也会针对您的分享，咨询相关网络安全专家。若有可信答复，也会在后面的发文中分享出来。

  

我们的目的是，用更多的真实案例，让更多人看到黑灰产盗用个人隐私信息进行诈骗的手段，同时也让更多人重视保护个人隐私，避免遭遇这类事件。
