# 译文 | 2亿条数据泄露：为什么数据越多风险越大

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247533241&idx=2&sn=2f96a57848ca18e11be4e39a2c5d2652&chksm=febc2879c9cba16f96f51d0c556e92cdef651e903f6a7bf7b70e60d37acbc304d77c316fe367&scene=126&sessionid=1681310692#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247533241&idx=2&sn=2f96a57848ca18e11be4e39a2c5d2652&chksm=febc2879c9cba16f96f51d0c556e92cdef651e903f6a7bf7b70e60d37acbc304d77c316fe367&scene=126&sessionid=1681310692#rd)

![](../Images/9105a3d368bfd94fb2e5a1c047ed0f08.png)

  

如果你不曾收集过这些数据，那就不会有人能够窃取它们。

  

![](../Images/e5c68828cca9f29725b9bc9450641348.png)

很多时候，“收集”显然不是保护客户数据的最好方法。对很多企业来说，收集越多的数据将会给他们带来更高的价值，甚至他们现在不用投入过多服务，就已经可以满足消费者需求。但实际上，只有收集越少的数据，才能保证在安全风险发生的时候，将影响降到最低。

  

“我们从消费者品牌那里听说，他们给予消费者投入的服务越来越少了。”IDC市场营销和销售技术研究总监Gerry Murray表示：“因为他们把过多的精力用在对于消费者个人生活和隐私的精准调查上了。”

  

“但对于大多数商业目的，你其实并不需要了解一个人太多的信息，有时最好不要知道。”他补充道。

  

近日，一份来自2015年包括2亿条市场调查名单记录的数据泄露消息，又让这一问题成为了焦点。

  

**泄露的数据里包括什么内容****![](../Images/e5c68828cca9f29725b9bc9450641348.png)**

  

这些泄露的数据一共有42个种类，包括了家庭住址、电话、婚姻状况、收入情况、净资产、种族、性别和宗教信仰等。这份数据最初似乎是由Experian（益百丽，国际知名的第三方征信大数据机构）收集（Experian否认了这一点），并授权给遍布世界各地的数千家市场调查公司的，所以，这份数据也许并不是直接从Experian泄露出来的，数千家市场调查公司中的任何一位，都有可能是罪魁祸首。

  

不过，这些数据并不包含身份证、驾驶执照、护照号码或信用卡号码，因此不像其他泄露的数据那么敏感。比如美国人事管理办公室（OPM）此前所泄露的数据中，就暴露了美国政府工作人员的详细档案。然而，从总体上看，这些信息相当于了整个美国社会的概况，并有可能被犯罪分子或敌对国家给利用。

  

业内人士透露，这份数据在2015价值巨额的授权费，但放在今天来看，其实并没有太多的价值。

  

这些数据文件的名称中都包含了“Experian”这个名字，并且与第三方公司Data Monster公布的市场调查列表相匹配（此列表已从Data Monster网站上删除）。但Experian回应表示，这些数据并不是他们公司的，邮件中写道：“我们已经调查过，这不是Experian的数据。”

  

同时， Data Monster公司也否认自己是数据泄露的来源，并指出这份数据已经被授权给数千家第三方机构，泄漏源头有可能是其中的任何一个。

  

不久前，某不愿意透露姓名的演员在Ghostbin上发布了一个链接，链接内容是mega.nz上共享的文件，这份文件包括了共计美国10个州的2780万条数据。这份数据过去的用途是为了给顾客提供免费的样品，而记者在核查后发现，当中CSO网站出版商IDG Communications公司的员工数据确实是真实的。

  

在这之后，mega.nz上文件的链接便被遭到删除。

  

虽然此前也多次发生过声称数据泄露的事件，但这确实是第一次实打实地证明了数据是真实存在的。早在2016年底，黑客DoubleFlag就在网上表示要出售某类似声音数据库的文件，但并未公开具体内容，CSO网站的记者曾试图通过电子邮件联系黑客DoubleFlag，但并未收到回复。

  

而Experian此前曾在2015年发生过数据损坏的漏洞，当时共影响了超过1500万的用户，不过那起事件似乎与目前流传的数据无关，因为这份数据并没有包括身份证号、驾照和护照号码。

  

在元数据中我们发现了一些特殊的地方，这些数据被创建于2009年，作者名为“Albert Kohl”，最后一次由名为“Joe”编辑。不过，元数据很容易被伪造。

  

**另一起数据泄露事件****![](../Images/e5c68828cca9f29725b9bc9450641348.png)**

  

Experian的前安全工程师Jasun Tate告诉CSO网站，黑客DoubleFlag极有可能是一个全国性非法人肉搜索的媒介，是供犯罪分子使用的，这样一来就掩盖了自己本身的犯罪痕迹。

  

“所有这些泄露的数据，可能都来源于背后一个更成熟、更有组织性的活动组织或机构，而且是一个长期收集美国公民信息的机构。”Tate如是说道。“（他们）了解了我们是如何消费、思考和被影响的，基于此进行更有效的活动。”

  

![](../Images/b02265ba37b09d5bb4209942943ea3ac.png) 

虽然Experian对数据的来源进行了否认，但仍无法保证，这些数据在被泄露的时候，Experian本身或第三方机构有无玩忽职守。但这根本就不重要，重要的是收集了如此庞大的数据，却并没有采取强有力的网络安全控制措施来保护它们。而在监管部门改善这种情况之前，恐怕数据泄露的事件还将持续发生下去。

  

所以在此之前，企业一定要减少对个人信息数据的收集，因为预防员工数据泄露最简单的方法，就是从一开始就不要收集这些数据。在《GDPR》实施和“剑桥分析”事件发生以后，那些聪明的企业都能在消费者和监管机构之间找到平衡和协调利益的办法。

  

“各大品牌们正在研究如何在与客户建立的数据关系方面实现差异化。”Murray说。“他们如何对待客户，就应该如何对待客户的信息。”
