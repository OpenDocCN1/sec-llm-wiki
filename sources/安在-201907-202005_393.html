市场上有很多适用于Android的防病毒软件，以下是前12名Android杀毒软件在保护、可用性和功能方面的表现。



AV-TEST近期对20款Android安全应用程序的评估，以下是针对Android的12款最佳企业级防病毒工具。（AV-TEST Institute是一家位于德国的IT安全和反病毒研究的独立服务提供商。）


AV-TEST对三个区域的每个工具进行评级：保护（最多6个点），性能（最多6个点）和可用性（最多6个点）。这里列出的产品都有18个满分。


所有测试应用的平均实时恶意软件检测率为96.8％。对于过去四周发现的Android恶意软件的实时检测，平均速率为97.6％。


注意：测试结果不一定在现实网络上能防所有的病毒


这些测试是在实验室环境中完成的。具有不同威胁模型的不同企业系统将针对下面列出的每种产品看到不同的结果。


换句话说，不要指望实验室中100％的检测率意味着产品将检测到网络上的所有防病毒威胁。一个原因是，新提交的恶意软件样本可能需要数天才能进入任何给定的防病毒产品数据库。


AV-TEST结果显示，哪些Android防病毒产品在恶意软件检测的基础上始终处于最佳状态，对系统性能的影响最小。当您评估哪种产品最适合您的环境时，这是一个很好的起点。


以下应用按字母顺序排列。


1.安天实验室AVL 2.7


AVL在保护，性能和可用性方面拥有完美的分数。它对功能有点了解，仅提供未知号码的呼叫阻止。


2. Antiy Labs AVL Sec 1.1


该AVL二段产品额定几乎和它的兄弟产品，对保护agains得分99.9％的Android恶意软件攻击和恶意软件的Android在过去四周发现99.8％。在其他领域，其得分与AVL 2.7相同。


3. Avast Mobile Security 6.20


Avast Mobile Security 6.19可 在100％的时间内实时管理Android恶意软件检测。它还发现了过去四周内发现的最新Android恶意软件的100％。该应用程序不会对电池寿命产生负面影响或导致设备在正常使用期间变得迟缓。它在安装和第三方应用程序商店中注册了零错误警告。


移动安全的安全浏览功能有助于防止网络钓鱼攻击和恶意网站，并提供远程擦除等防盗功能。该应用程序还有一个呼叫拦截器。AV-TEST未评估的其他功能包括应用锁定，隐私顾问和Wi-Fi安全性。


4. AVG AntiVirus Free 6.19


AVG AntiVirus Free 6.19  对实时和最近发现的恶意软件具有完美的检测率。它没有给出任何虚假警告。该应用程序具有一系列不错的功能，包括防盗，远程擦除，呼叫阻止，安全浏览，Wi-Fi安全和隐私顾问。但是，它缺少个人数据的消息备份。


5. Avira Antivirus Security 5.8


Avira Antivirus Security几乎是完美的，在实时防御Android恶意软件方面得分为99.8％。它不是功能最丰富的选项，但它确实提供应用程序控制，隐私顾问和安全浏览。


6. Bitdefender移动安全版3.3


Bitdefender Mobile Security的 Android恶意软件实时检测率是100％，并且它发现了过去四周内发现的最新Android威胁100％的时间。为了实用性，该应用程序获得了大的复选标记，因为它不会拖延电池寿命或设备速度。AV-TEST在从Google Play安装/使用合法应用程序期间或在第三方商店安装和使用应用程序期间发现零错误警告。


与一些Android恶意软件防护应用不同，Bitdefender的移动安全提供防盗功能，包括远程锁定，擦除和定位，以及安全的网页浏览和网络钓鱼防护。与许多其他Android安全工具一样，它不包括邮件过滤或呼叫阻止，也不支持所有类型的加密。未评估的其他功能包括应用锁定和隐私顾问。


7.猎豹移动安全大师5.0


安全大师在两项保护测试中都获得了100％的完美分数，检查了所有方面的性能，并没有给出任何错误警告。它具有相当好的功能，包括防盗，应用程序控制，VPN，Wi-Fi顾问/检查和安全浏览。


8. Eset Endpoint Security 2.6


Eset Endpoint Security在恶意软件检测类别和可用性和性能的高评级方面都获得了满分。它具有一系列良好的功能，包括防盗，呼叫阻止，消息过滤和安全浏览。它不提供个人备份或加密。


9. G数据互联网安全26.5


G Data的Internet Security比其他许多顶级竞争对手拥有更多功能。AV-TEST选中了远程锁定，擦除和定位的方框; 呼叫阻塞; 消息过滤; 安全浏览; 和父母控制。收到的应用程序中唯一的'x'标志是不允许将个人数据保存到SD卡或云存储中，并且不支持任何类型的加密。


互联网安全的实时Android恶意软件检测率为100％，它也检测到过去四周内发现的威胁100％。在安装和使用来自第三方应用商店的合法应用时，该应用发出了虚假警告。


10. McAfee Mobile Security版本5.2


McAfee Mobile Security Android恶意软件扫描程序在99.9％的时间内实时检测到错误，并且在过去四周内100％的时间内发现了恶意软件。可用性很棒。该应用程序的功能很强大，包括一整套防盗工具，呼叫阻止，安全浏览和网络钓鱼防护，家长控制以及将个人数据保存到SD卡或云端的功能。但是，移动安全不支持所有类型的加密。


11.趋势科技移动安全10.3


趋势科技移动安全在所有三个测试领域都获得了满分。它还具有可靠的功能集，仅缺少个人数据备份和VPN功能。未经测试的功能包括防盗，信使保护，网络保护和家长控制。


12. Symantec Norton Mobile Security 4.6


赛门铁克诺顿手机安全软件捕获了所有Android恶意软件的100％，包括最近在四周内发现的恶意软件，没有任何错误警告。它具有一系列良好的可用性功能，包括安全浏览，个人数据备份，防盗和呼叫阻止。未经审核的功能包括应用顾问。


Android安全状态


AV-TEST研究所的研究表明，收集的Android恶意软件样本每年都在增加。2014年，总数超过3.26亿。2015年，恶意软件总数达到了4.7亿多。2016年，AV-TEST记录了近5.975亿个样本 - 几乎是两年前的两倍。而在2018年，已经达到83814万。
AV-TEST数据显示Android恶意软件急剧增长


根据Gartner 2017年8月的“移动威胁防御解决方案市场指南”，到2019年，移动恶意软件将占标准测试中报告的所有恶意软件的约33％，高于目前的7.5％。尽管iOS设备无法抵御恶意软件，移动恶意软件威胁主要来自Android系统。


Gartner研究主管Dionisio Zumerle表示，对于拥有Android用户的所有公司来说，威胁应该是一个大问题，尤其是那些拥有大量Android设备或处于高安全性垂直行业（如金融，医疗保健和政府）的企业单位。


Android恶意软件也越来越隐蔽，越来越复杂。例如，在2018年10月，人们发现恶意软件作者将手机银行特洛伊木马偷偷带入谷歌Play商店，伪装成设备助推器和清洁工，电池管理器和星座应用程序。


据IT安全公司ESET的We Live Security博客称：“这些远程控制的特洛伊木马程序能够动态定位受害者设备上的任何应用程序，并使用量身定制的网络钓鱼形式。” “除此之外，他们还可以拦截和重定向文本消息，以绕过基于SMS的双因素身份验证，拦截呼叫日志，以及在受感染设备上下载和安装其他应用程序。”


ESET高级研究员尼克菲茨杰拉德说：“Android安全性正在提高，平台可用的安全应用程序的多样性很强。” “这意味着破坏者必须清除不止一套障碍，才能获得非常成功的恶意软件活动。”
