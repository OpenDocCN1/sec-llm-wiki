# 人物 | 微软张美波：TOP GUN

**一身转战三千里，**

**一剑光寒四十州。**

**男儿本自重横行，**

**天下谁人不识君。**

**撰稿 | 流苏**

**编辑 | 图图**

  

  

![](../Images/9f26a54f9e0e4e0c15bc15366ab55fc2.png)

苏苏第一次听到这四句诗时，便震撼于诗中扑面而来的锐气，仿佛看到一位无所畏惧、纵横捭阖的年轻将军在战场上驰骋，如汉朝霍去病转战千里封狼居胥，又如三国周瑜谈笑间樯橹灰飞烟灭。

 ![](../Images/b83e43e64d8629ad8282ad0b8da84b25.png) ![](../Images/8c4560bd724c9f4b80a8e28eac048678.png)

  

实际上，这是张美波2009年写给自己的一首自喻诗，四句诗分别取自王维的《老将行》、贯休的《献钱尚父》、高适的《燕歌行》以及高适的《别董大》。这首诗既体现了他的雄心壮志，也是对其自身经历最真实的描绘。

  

从22年前（1997年）开始学习计算机、第一次接触到微软MS-DOS操作系统开始，张美波就在心里种下了梦想的种子，要成为微软有名的技术专家。如今，这个梦想早已实现，现在的他，不仅获得了微软全球最高级别的大师认证，并且是微软企业服务全球最高级别的技术专家之一，也是微软企业服务的大中华区Cybersecurity首席架构师。

  

张美波是个现实完美理想主义者。他深受中国传统文化的熏陶，身具侠者风范，常怀仁心，也是一位性情中人，相信缘分。

  

![](../Images/465c01cea023848c8c35b4abbc41d7e7.png)

  

![](../Images/dffbb761ebc5eff997bb4e26fab6becc.png "动态黑色音符")

  

  

**少年不识愁滋味，春风得意马蹄疾****![](../Images/0f7dee502736ffdff4f5b4614ac081e4.png)**

  

  

和大多数男孩一样，童年时期的张美波非常喜欢玩游戏，小霸王、街机样样精通。其中，侍魂4天草降临是他的最爱，他的网名“风间子”便取自侍魂4天草降临中的人物“风间苍月”。冥冥之中也让张美波和计算机结下不解之缘。

  

1997年，张美波以地区第二名的优异成绩进入四川省邮电学校，就读于当时极为热门的光纤通信专业，第一次接触到计算机的相关课程。

  

在张美波的记忆里，那时学校的计算机，大都是“老古董”级别的：配置为8M CPU/1MB内存/128M硬盘，MS-DOS 6.22操作系统（在学校里基本没有接触到Windows 95及之后的操作系统），但这并不妨碍他对计算机技术的痴迷。

  

Turbo Pascal是张美波最开始学习的编程语言，令他没有想到的是，17年之后，他在微软Redmond总部遇见了Turbo Pascal之父（同时也是.Net 之父、C#之父）、微软Tech Fellow **Anders Hejlsberg**，可见人与人之间的缘分有时就是如此奇妙。

  

![](../Images/edda8a3a552e09ea773941e2aa477ad0.png)（2014年11月11日，张美波与 Anders Hejlsberg合影，摄于微软美国Redmond总部）

  

此后，张美波又自学了汇编语言、C语言，展现出他在计算机技术方面的强大天赋，并于2000年连续通过国家计算机三级和四级的考试，当选学校第三届计算机爱好者协会的会长，妥妥的学校IT风云人物。

  

而张美波的网络安全生涯是从病毒和硬盘保护卡开始的。那时候学校机房虽然是MS-DOS系统，但是病毒横行，杀毒软件和硬盘保护卡是标配。当年的杀毒软件是江民Kv300一枝独秀，但价格奇贵无比。学校老师有一套正版Kv300，但是每次去借用的时候都很麻烦，因此他也很想自己能够有一套正版Kv300，可惜买不起。

  

在98年张美波自学汇编语言之后，对操作系统底层很感兴趣，于是深入研究了一下软件破解，对于SoftICE、TR等反汇编工具使用十分精通。由于难以接触到正版Kv300，于是他花了巨款（自己一周的生活费58元）邮购了一套Kv300的正版升级软盘，然后反向破解了Kv300的正版保护机制，并能够进行持续的正版升级。

  

学校机房的硬盘保护卡自然也不在话下。后来张美波研究发现对方只是修改了一个和磁盘读写的系统硬件中断，反向破解是轻而易举的事情。他后来自己写了一套硬盘保护程序，仅用了不到10KB的汇编源代码TSR程序，修改了三个硬件中断并进行自我代码防护和反破解，后来学校使用他写的硬盘保护程序替换了原来的硬盘保护卡，也节约了不少经费。

  

那时的他，仗着自己在MS-DOS下的破解技术能力出众，各种正版软件都拿来练手，例如计算机等级考试模拟、各种光盘游戏、加密狗保护的行业软件等等，自己也写过磁盘加密、文件加密等程序。

  

**人生得意须尽欢，未妨轻狂是惆怅****![](../Images/0f7dee502736ffdff4f5b4614ac081e4.png)**

  

刚开始接触计算机的时候，那时很多关于比尔盖茨的报道，因此张美波也梦想自己能够有一天可以进入微软工作，成为微软有名的技术专家。不过，这仅仅只是一个梦想而已。当时他就读的四川省邮电学校虽然是一个邮电行业内部的著名中专学校，但想要进入微软这种名牌外企，简直就是痴人说梦。

  

按照既定的轨迹，在2001年毕业的时候，由于校长的推荐，成绩优异的张美波被分配到四川电信集团公司下属的物资采购事业部做采购项目经理，负责四川电信项目建设的设备和物资采购。2001年3月15日，在学校里面坐上公司安排接待的小轿车，18岁的张美波自此踏上了滚滚红尘，进入了这花花世界。

  

由于公司里面都是原来邮电行业的老同事们，对于计算机不太了解，因此公司大老板希望招一个计算机高手，以帮助公司实现办公自动化，因此他通过自己老朋友-学校校长的关系，把张美波要了过来。鉴于这个背景，张美波很是受到大老板器重，公司上下领导都很关照，可谓是少年得志。

  

公司大老板是全国五一劳动奖章获得者，华为任正非任总的同龄人、老朋友，在当年四川邮电与华为合资成立成都华为的紧要关头力排众议帮助了华为渡过难关。他对张美波关爱有加，给了一台IBM ThinkPad 600E笔记本电脑让刚入职的张美波使用，并为张美波的办公室专线电话开通了拨号上网业务。在当年还在使用56K Modem的163拨号上网时，张美波在办公室下了几个G的RM和MP3文件，每个月办公室的电话费高达上千元，公司都全部报销。

  

在他的工作方面，总体而言还是比较轻松的。当时张美波负责了很多四川电信的重要工程项目的采购业务，例如第一个项目是四川电信163/169扩容项目，第一个国家一级干线项目是西成渝光缆建设项目，到后来的四川电信全省的上海贝尔/华为设备项目采购配送，以及成都市的ADSL新建试点以及四川电信全省的ADSL新建和扩容项目等等。

  ![](../Images/b83e43e64d8629ad8282ad0b8da84b25.png) 

![](../Images/ce131e3210733c3b346299d349965ede.png)（2003年1月9日，摄于四川遂宁灵泉寺）

  

2002年，随着ADSL的推广，公司计划在全公司构建企业网络，并实现全员接入。基于该需求，张美波开始研究上网的管理软件。从一开始使用的Sygate、WinRoute，到后来WinRoute的新版本Kerio WinRoute Firewall，再后来就研究到微软的防火墙ISA Server 2004。

  

ISA Server 2004的beta版本发布后，张美波发现这是个很好的产品，但国内却鲜为人知。为了让更多的人了解它，张美波在2004年建立了 ISA中文站（ISACN.org），专门原创或翻译介绍ISA Server 的相关技术文章，对ISA Server 以及后续版本Forefront TMG 在国内的推广和应用做出了极大的贡献，因此在2005年获得了ISA Server 类别的微软全球最有价值专家（MVP）称号。

  

![](../Images/b8ae0077b758be097574bd1519555b9f.png)![](../Images/b83e43e64d8629ad8282ad0b8da84b25.png) （2005年3月9日，摄于微软中国北京总部）

  

那几年在四川电信的日子，张美波过的很是舒心惬意。可惜天有不测风云，公司的大老板在2005年时年龄到站退休，后续接班人失利，大家树倒猢狲散。看着已经物是人非、满目疮痍的公司，张美波也在考虑自己应该何去何从。

  

恰好当时看到电脑报上报道建行年薪百万挖“最牛DBA”**牛新庄**的故事。牛新庄也是非计算机科班出身，通过自己的努力成为行业顶尖专家。这件事情给了张美波很大的触动，也很想自己出去闯一闯。于是在2005年国庆节之后，他正式辞去了四川电信的正式工职位，计划破釜沉舟，背水一战。

  

**长风破浪会有时，直挂云帆济沧海****![](../Images/0f7dee502736ffdff4f5b4614ac081e4.png)**

  

可惜这破釜沉舟效果很不明显。从四川电信辞职之后，张美波找不到理想的工作，于是在家里呆了大半年，每天无所事事，天天打各种游戏，把反恐精英倒是打的炉火纯青，也顺便把武林外传这部长达84集的电视剧给看完了。

  

直到2006年6月底，在微软朋友的帮助之下，张美波才入职微软西区企业服务团队做临时工，职位是技术专案经理，主要负责客户的技术项目实施。

  

这样一直到了2008年1月，张美波到微软上海办公室去参加Windows Server 2008的活动目录培训，一同参加培训的还有几位微软企业现场服务部（PFE）的同事。微软企业现场服务部（PFE）是微软企业服务部门中的精英团队，定位是特种兵，专门负责到客户现场解决各种疑难杂症。在培训过程中，张美波和这几位同事在技术方面交流比较多，聊的也很愉快。其中一位同事有次突然对张美波说，“你技术那么好，到我们部门来吧。”，于是他把张美波推荐给了他的老板。

  

这个部门本来没有计划在微软西区招人，但是部门老板面试了张美波之后，决定招聘他。于是从那时开始，那么多年过去了，张美波一直都是这个部门在西区的唯一一名员工。

  

2008年4月7日，张美波正式入职微软企业现场服务部（PFE），主攻方向是活动目录和系统安全。从1997年7月学习MS-DOS时梦想加入微软，到2008年4月梦想成真，张美波兜兜转转11年，终于修成正果。

  

加入微软的第一天，张美波就给自己定下了三个心愿：**一是成为微软全球有名的技术专家，二是获得微软最高级别的“微软大师”认证，三是想要见见比尔盖茨。****此后，他便一直朝着目标不断前行。**

 ![](../Images/0761d8546524495ec75c86b73b8a0b8a.png)

（2009年7月26日，摄于比尔盖茨办公楼下

微软美国总部 Redmond Building 34）

  

2012年1月，张美波首先实现了第二个心愿，获得了梦寐以求的“微软大师”认证。

  

这里苏苏“啰嗦”一下，简单科普下“微软大师”。

  

“微软大师”是原来微软最高级别的技术认证，它只面向微软最资深的技术专家，有着严苛的报名限制：如报名者必须要有7年以上的相关产品经验，预先通过8门MCITP（微软认证IT 专家）考试，还需通过相应的背景调查，最终参与者获得认证的比例也只有25%左右。此外，“微软大师”考试费用极其昂贵，单单是考试报名费就高达18,650美元，再加上往返美国机票和美国三周的生活费用，这绝对不是一笔小数目。

  

2012年1月，达到工作年限要求后，张美波出发去美国参加 “微软大师”认证考试。那时正值国内春节，登上飞机的他，颇有一股“风萧萧兮易水寒，壮士一去兮不复还”的悲壮之情。那一届微软大师认证考试，参与者共计23人，除了张美波之外，全部都来自欧洲或北美。

  

这是一门过程非常残酷的考试，每天仅有四五个小时的睡眠时间。功夫不负有心人，最终他以当届第一、全球第二的优异成绩一次性顺利通过了所有考试，获得了Exchange 服务器类别的“微软大师”称号。当届仅有5人一次性通过认证。

  

在“微软大师”认证开设的5年时间里，全球获得了Exchange 服务器类别“微软大师”认证的只有155人，全球所有类别的“微软大师”认证获得者只有800余人。

  

张美波一直认为，做技术就如攀登高峰，因此他特别喜欢应对超大规模企业环境的挑战。在他的日常工作中，主要负责为微软全球Top的企业客户环境提供相关的技术支持和项目实施。从2008年北京奥运会的现场支持，到参与全球最大活动目录环境的全球优化项目，到成为全球最大On-premise企业Exchange服务器环境的架构师，再到多个全球Top Account的微软方安全架构师，他一直在勇攀高峰，也逐渐的实现了自己的第一个心愿。

  

2008年4月，在加入微软企业现场服务部（PFE）时，张美波是整个大中华区部门里最年轻的工程师，5年之后他成为大中华区最年轻的资深解决方案专家，又过了4年，他已是全球部门里最年轻的首席解决方案专家（当时全球同职位类别仅有十一人，同产品类别只有四人）。

  

这十年的时光，对于张美波而言，可谓如梦似幻，终成圆满。

**浮云一别后，流水十年间。乘兴忽复起，挥翰凌云烟。****![](../Images/0f7dee502736ffdff4f5b4614ac081e4.png)**

  

2018年9月，张美波突然收到原微软安全产品部门ISD的总监**Fernando**的邮件，邀请他加入微软安全服务部门，负责在大中华区落地微软的安全服务业务。

  

这让张美波心里一阵恍惚，感概万千。

  

遥想当年（2009年），微软将所有的安全产品整合到一个新的安全产品部门——ISD部门。那年7月，微软推出了新的安全产品Forefront系列，邀请微软内部20多位全球级别的安全支持专家到公司总部参与相关的产品发布和培训。张美波就是其中之一，在这次培训中，他结识了Fernando，还一起合影留念。但一别之后，他和Fernando就再无联系了。

  

然而，到了2011年，微软决定终止大部分安全产品的后续开发，并撤销了ISD部门，原来ISD部门的同事要么转岗，要么离开了微软。而Fernando在2011年之后也很颠沛流离，先是去了南非，然后去了中东，再去了欧洲，最近才回到亚洲负责亚太区的微软安全服务部门。

  

一别9年，Fernando还能够记得张美波，这让张美波非常感动。但对于Fernando的邀请，张美波认真评估后便拒绝了。用他的话来说，“风险太高，九死一生”。

  

原因有两方面。

  

一是在大多数企业用户的固有认知中，微软产品的安全性并不好，并且微软也不是一家做安全服务的专业厂商，因此，想要真正开展业务就必须首先打破这种固有认知，这也就意味着前期需要投入无数的时间和精力。

  

二是微软安全服务只是微软中国一个很小的新业务，内部也缺乏相应的宣传、高层支持和认同感，想要从零开拓国内市场难度系数非常高。

  

但Fernando又锲而不舍的和张美波谈了几次，最后他说“我们都是微软安全的老兵了，也应该为微软安全做出点贡献”。这句话深深地触动了张美波，他想也许一切都是命中注定吧。

  

正是因为这句话，张美波之前的种种担忧全都抛之脑后，义无反顾地加入了安全服务团队，并于2019年1月1日起转任微软企业服务的大中华区Cybersecurity首席架构师，微软大中华区安全服务团队也就此成立。

  

“必胜之心无，必死之念有”，这是张美波临危受命时内心活动的真实写照。

  

接手安全服务团队后，张美波首先做了三件事情：**一是练好内功，梳理、统一并规范业务能力与范围，提高安全服务团队的标准实施能力，强化团队内部的凝聚力；****二是做好内部宣传和交流，在微软内部构建微软Cybersecurity 虚拟团队，实现微软内部各个Cybersecurity相关部门的交流和协作，增加内部宣传和教育，提高微软内部对于微软安全和微软安全服务的认同感；三是做好外部宣传并建立微软安全服务品牌形象，通过各种成功案例向我们的客户和外部安全行业宣传微软安全服务，提高微软安全服务的知名度，以实际案例打破客户和行业对于微软安全的固有成见。**

  

说到这里，张美波笑了笑说，“变化最明显的就是我的微信好友数量，从最开始的一百人不到，增加至现在的上千人”。为了拓展安全服务的业务，性格稍稍内向的他也必须适当外向起来。

 ![](../Images/b83e43e64d8629ad8282ad0b8da84b25.png) 

![](../Images/91b68a900c9882132f84625d8b90aa3a.png)（2019年1月19日，摄于澳大利亚布里斯班南岸公园）

  

相较于行业内愈发火热的“大安全”，微软安全服务反其道而行之，专注于用户的“小安全”。即重点关注于微软自身的产品、系统平台和服务的安全性，以及如何保护使用微软产品、系统平台和服务的用户。

  

专注于“小安全”虽然失去了广度，但也让微软安全服务收获了其他安全厂商难以企及的深度，从而更加贴合用户的业务和需求，更好的为企业用户提供深度定制的安全服务。

  

在张美波看来，“小安全”才是未来的趋势。当前网络安全形势下，广而平固然重要，专而精却更加重要。只有在重点的细分安全领域持续、深入地研究，才能更有效守护好企业核心资产的安全，提升企业安全防御水平，增加网络攻击的成本和难度，为企业带来真正的安全。

  

然而最让张美波感到郁闷的是，微软在网络安全方面的技术实力是全球超一流的，甚至不少后面火热的主流技术都是微软率先提出来的，但却由于太超前，无法大规模落地，导致在当时未能得到大规模应用，后面也就悄无声息了。

  

例如当下很火的安全集成联动概念，早在2009年就已经在微软的Forefront产品系列中实现，并在微软内部使用。而Google 2013年采用的“零信任模型”，实际上在微软2009年发布的Windows 7中，就已经实现了类似的技术DirectAccess。可惜的是，这些技术往往由于太过于领先或部署复杂，导致难以在当时实际的企业环境中应用，只能在微软内部使用，并最终慢慢被遗忘。

  

看着这些先进的技术就这样白白搁置，张美波心里很不是滋味，而这也是他加入微软安全服务团队的原因之一，即让微软全球领先的网络安全技术真正能够给用户带来更好的安全体验。在近期的多次攻防实战演习中，张美波带领微软安全服务团队积极参加，团队也表现卓越，为多个企业客户实现了完美的安全守护。

  

可以预见，重塑后的微软安全服务精英团队，再加上微软全球超一流的网络安全技术产品和经验，在不久的未来必定可以为企业用户带来更多的惊喜。

  

而令张美波颇感遗憾的是，直到现在也未能实现第三个目标，和比尔盖茨见面，“只能期待于未来的缘分”。

  

回首自己13年的微软职业生涯，张美波从心底感谢微软，正是在微软的大舞台上，他才得以实现人生的梦想。在张美波心中，微软是世界上最伟大的企业之一。毕竟，**这个世界可以没有苹果，但绝对不能没有微软**。 

  

恰如那追梦少年，意气风发。不论通往梦想的道路是多么曲折，但追求梦想的脚步从未停止。**正如“Top Gun”这个名称，是电影“壮志凌云”的英文名称，也是张美波在微软所获得的第一个公司奖项的名称。**  

  

![](../Images/e79da61d5eff5fb9d2db1ca630ac44b9.png)

  

  

**慷慨意气为君饮，相逢何必曾相识****![](../Images/0f7dee502736ffdff4f5b4614ac081e4.png)**

  

由于微软内部对于某项技术认证的要求，张美波于2010年7月时在北京通过CISSP考试，获得了CISSP证书。不过在此之后，除了每年按时给**(ISC)²**交“保护费”之外，和(ISC)²国际协会并没有任何交集。

  

2017年9月，张美波突然收到一封来自(ISC)²国际协会的邮件，内容是询问他是否有兴趣在本地创建(ISC)²分会。

  

张美波看完这封邮件后内心还有点小激动，“这么多年了，组织终于想起我了”。经过慎重的考虑，为了更好的增进国际与本地之间、本地安全行业之间、安全从业人士之间的沟通交流与人脉联系，促进本地安全行业的发展，张美波决定去挑战一下这个艰巨的任务。

  

但是在西部地区，IT发展水平相对薄弱，要创建(ISC)²分会谈何容易！分会创建十大流程里面，第一个流程要求15位(ISC)²持证会员的签名支持，连这个最基本的流程张美波都无法完成，后来全靠安全行业里面北京上海深圳的朋友们帮忙，才完成了第一个流程。

  

即便创建分会难度非常高，但张美波并没有放弃。最终，在(ISC)²西南分会所有管理人员和会员的共同努力下，2018年3月17日，(ISC)²西南分会正式成立。令所有会员感到巧合的是，(ISC)²西南分会成立当天共有66名正式会员，而在三个月后(ISC)²国际协会所颁发的分会成立许可上，(ISC)²西南分会是全球第166个(ISC)²分会。这两个超级吉利的数字，大概是上天送给(ISC)²西南分会最好的礼物。

 ![](../Images/b83e43e64d8629ad8282ad0b8da84b25.png) 

![](../Images/0a8bd5e3bcf7c078189a6fc4ae8e80b5.png)（2018年11月17日，摄于(ISC)²西南分会11月会员答谢活动）

  

(ISC)²西南分会的定位是一个“小而精”的分会，不追求大而全，因此对于会员的加入具有较为严格的入会流程。经过一年半的持续稳定发展，目前(ISC)²西南分会拥有正式会员接近200名，这对于一个新的(ISC)²分会而言是一个了不起的成绩。在未来，(ISC)²西南分会希望能够成为安全行业交流的平台、安全行业内部人际交流和人脉扩展的平台、为分会会员提供更多学习机会和会员福利的平台，以及让分会会员充分的展现自身的才华、提高会员行业知名度的舞台。

  

经过一年半的发展，如今的(ISC)²西南分会在行业内部初具知名度，并稳定以每月至少一次的频率举办会员活动，邀请嘉宾及会员参与分享、讨论和交流相关安全话题，现已成为会员们固定的线下交流平台。

  

会员是(ISC)²西南分会的核心。为了报答会员们的支持， (ISC)²西南分会同时在公众号上设立了“会员人物”宣传专栏，介绍并宣传分会的会员们，从而帮助分会会员提升行业知名度，塑造会员的个人形象。

  

**智信仁勇严****![](../Images/0f7dee502736ffdff4f5b4614ac081e4.png)**

  

采访快要结束时，苏苏向张美波请教：一个好的管理者需要具备哪些特质？

  

他想了想，答“智信仁勇严”，这句话出自《孙子兵法》始计篇，是指一个优秀将军必须具备的五个特质。

  

不等我继续发问，张美波解释道，一个好的管理者就好像一个优秀的将军，能够最大化激励并发挥出团队的价值。

  

“**智**”代表着智慧。优秀的管理者必须要洞悉当前的形势，明确未来的发展战略和战术，清楚团队中每一个人的优点和缺点，择人而任势，用其长避其短，才能使其发挥出最大的能量。

  

“**信**”代表着信用。优秀的管理者必须要言而有信，不轻言许诺，说到就要做到，这样员工才能信你、服你、支持你。

 “**仁**”代表着仁义。优秀的管理者常心存仁义，真心关爱成员，了解他们的生活状态和情绪，帮助和支持他们自身的发展，而不仅仅是冷冰冰的上下级关系。

  

“**勇**”代表着勇气。优秀的管理必须要有克服一切困难的勇气，在团队遇到困境迷茫不前时，这时候管理者应第一个站出来为团队成员指引方向，带领大家勇敢前行。

  

“**严**”代表着纪律。令之以文，齐之以武，无规矩不成方圆，缺乏纪律的团队是不可能获得成功，因此管理者应严格执行已制定好的规章制度。

 ![](../Images/b83e43e64d8629ad8282ad0b8da84b25.png) ![](../Images/e284b212a0332e4bd3a1f893f2f0f4c1.png)（2013年10月3日，摄于宁夏银川镇北堡影视城）

  

“智信仁勇严”，短短五个字道尽了管理者的精髓，也让苏苏真正见识到张美波深厚的传统文化功底。这大概要归功于张美波从小便在传统文化的熏陶中成长，这也就很好理解，为何张美波从四首古诗中准确摘出那四句诗，重新组成一首大气磅礴的诗。

  

在他身上，既有着古代传统文人固有的节操和风流，又有着现代顶尖技术专家开放的思想与行动。

  

一文一理，一古一今，完美的融合在一起。
