P17安全领袖圆桌：安全市场迎来千亿发展机遇，腾讯携手产业链伙伴共建安全生态

7月30日，为期两天的第五届互联网安全领袖峰会（Cyber Security Summit2019，简称CSS2019）在北京正式揭幕。作为每年CSS领袖峰会的重磅板块之一，由腾讯安全发起、汇聚国内安全上市企业领袖的P17安全领袖圆桌于会前的29日下午正式召开。


腾讯副总裁丁珂、腾讯副总裁马斌、腾讯云副总裁谢岳峰，以及来自包括天融信、卫士通、启明星辰、美亚柏科、拓尔思、蓝盾股份、任子行、北信源、绿盟科技、飞天诚信、数字认证、中孚信息、深信服、格尔软件、迪普科技在内的安全上市企业总裁（董事长、CEO）、董秘、技术副总裁（CTO）等行业领袖悉数出席。


P17安全领袖俱乐部成员合影


“安全领袖圆桌”已经成功举办三届，首届于2017年CSS安全领袖峰会发起，13家国内上市安全公司共同参与。今年P17以“产业互联网安全新生态”为主题，共同探讨产业互联网背景下的安全产业发展新趋势，达成“生态资源共享、能力互补、生态共建”全新合作机制，旨在推动构建最佳协同效应的安全生态，携手为企业提供更全面可靠的安全解决方案及服务，共同承担产业互联网安全发展责任。


腾讯副总裁丁珂在会上表示，产业互联网时代发展带来企业上云需求，给安全产业发展带来很多增量市场机遇；以往中国传统安全在企业IT投入占比只有3%左右，但在腾讯智慧政务等项目实践中发现，一些新业务场景的安全占比已经远远大于这一比例，产业数字化发展带来的安全市场变量日益显现，腾讯希望和安全产业链伙伴携手共建、共享产业安全增量红利。


//
产业安全步入发展快车道，市场迎来千亿发展机遇
//
 


美国权威市场研究和分析机构IDC预测，2019年中国安全解决方案总体支出预计达到69.5亿美元，2018-2022年预测期内的年复合增长率为25.6%，增速远高于全球平均水平。到2022年，其市场规模将增长至千亿级。


对此，腾讯公司云与智慧产业总裁汤道生在主题发言中也提出，数字化技术推动行业升级过程中，网络安全的重要性在日益凸显。比如医疗、金融、物联网，甚至是能源和工业，在这些产业领域，数字化程度相对较高，对安全的需求最迫切。他预计，未来3-5年，安全加速“驶入”产业发展快车道。


一方面，产业互联网发展，各行各业都在通过云计算等数字技术加速发展，安全建设将贯穿企业研发、生产、流通、服务等全过程，给产业安全带来新的增量市场。另一方面，安全在产业数字化发展中降本增效的价值逐步显现，企业客户也更加在业务安全、安全服务等领域投入预算。


“传统存量安全市场，客户需求和行业市场分工相对比较清晰，比较难有大的突破；但云计算的发展，给安全产业发展带来了非常大的增量空间。”结合腾讯过去一个阶段在安全领域的业务实践，丁珂分享了其对产业增量安全的市场机遇的理解。他认为，一些大企业在产业数字化过程中，对安全的渴求非常强烈；与此同时，诸如金融、监管行业、车联网等新兴业务领域，应用安全需求几乎伴随业务发展体系，预算不再受IT投入限制。


 

腾讯与P17成员达成全新合作机制：

“生态资源共享、能力互补、生态共建”


//
P17携手共建合作新生态，共享产业安全红利
//


“独行快、众行远！伴随产业互联网的发展，以及增量安全需求的复杂性，加快安全生态协同共建，已经迫在眉睫。”马斌表示，产业互联网背景下的安全产业趋势变化，促使安全产业链伙伴的加速融合。云计算打破了传统的网络边界防护，物联网使企业的信息资产无处不在，企业业务模式和场景越趋复杂，对于安全服务提出了更高要求；一家企业或机构的安全规划与建设，很难由单一一家安全企业提供完整技术能力来解决。


谢岳峰在会上也分享了腾讯产业合作的政策和经验。谢岳峰表示，“长沙超级大脑”、“一部手机游云南”、“成都绿道”等腾讯今年合作的几个大型项目中，都有很大一部分对安全服务的需求。实际上，腾讯已经与安全产业链伙伴探索了包括产品开发、渠道合作、建设实施等广泛合作模式，合作效应日益显现。


据谢岳峰介绍，目前腾讯与合作伙伴共同打造的安全联合解决方案超过20个，这些联合解决方案占腾讯安全全品类销售比例达到26%，而在2019年上半年，腾讯安全产品通过渠道伙伴销售的增速达到200%；基于良好的合作实践，腾讯正在与P17等安全生态伙伴探索“生态资源共享、能力互补、生态共建”的协同机制，共享产业安全红利。


一方面，腾讯将面向伙伴开放腾讯云生态资源，尤其在腾讯所主导的大型客户项目中，联合生态伙伴共同为客户提供全栈服务。比如在某智慧政务项目中，腾讯与超过10家腾讯安全生态伙伴共同合作，协助政府从0到1构建了完整的数字化安全防护体系，涉及基础安全、业务安全、内容安全等全栈能力。这套系统，在去年中央主管部门组织的50余家测评机构测评中，获得了零失分成绩，树立了智慧政务安全标杆。


另一方面，腾讯将全面开放多年积累的安全中台能力，并按需被集成到生态伙伴的解决方案中，实现能力与产品互补，提升P17生态伙伴的安全服务能力及业务竞争力。马斌认为，安全行业伙伴各有所长，作为P17的发起者，腾讯愿意将自己深入产业互联网实践，服务10 亿级用户及海量业务场景所积累的安全大数据、技术共享给生态伙伴，与大家强强联合，优势互补。


目前，腾讯云自身已取得26项国内最全的安全合规资质，并且基于“云管端”的智慧安全体系，将包括数据安全、网络安全、主机安全在内的八大领域的安全能力对外输出，为合作生态提供强大的底层支持、中台能力，有利于伙伴灵活部署，自主创新。


马斌表示，腾讯将一直坚持共生共赢的生态合作理念，与安全伙伴相互开放资源、优势互补、共谋发展，携手促进企业机构数字化升级顺利实施。


//
举生态之力，共担产业互联网安全责任
//


从2017年的P13领袖圆桌发起，到如今的P17共议产业安全发展新契机，腾讯与国内安全上市公司通过生态联盟的升维，持续加深了开放、互通、共享的协作机制，而每年一度的CSS安全领袖圆桌会议，已经成为中国安全产业发展风向标。


丁珂在会议最后总结中表示，P17的存在，不仅是为了探索更深入的合作模式，打开安全行业更大的想象空间，更重要的使命是通过安全生态链的协同共建，打造贴近真实业务场景的安全解决方案，降低企业客户的安全门槛，保障各行各业的安全发展，共担守护产业互联网安全的职责。


会上，腾讯安全生态中心联合P17发布了《中国产业互联网安全发展研究报告》，该报告从产业视角解读数字化升级下安全新价值与新挑战，为安全行业与智慧产业提供系统性的规划和建设方向，成为国内首个聚焦产业安全议题的理论指导。
