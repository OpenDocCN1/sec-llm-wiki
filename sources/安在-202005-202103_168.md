# 让我看看你的账号

如果说信息是新时代的资源富矿，那么用什么方式去挖掘、挖好这个矿，就是背靠互联网的打工人们的毕生追求。  

  

众所周知的道理：要想富，先修路。在资源的交换通路中蕴含着无尽的财富密码，赛博空间中的“路”是一个个平台载点，而账号则是自然人在互联网上的映射。人们以此为媒介，或是把现实所得转移成一堆堆别有意义的数据，又或是利用已经建立起来的人际关系网，将情分逐一量化成生意场上的明码标价。

  

无论是什么样的方式，打造以本人为基准的网络形象并无对错，只是当账号成为了一般人生活中不可缺少的一部分后，原本不存在的安全风险也因此产生了——从个人到国家组织，无一幸免。

  

  

**如果你玩游戏**

  

  

11月13日，米哈游旗下游戏原神的玩家遭遇了有史以来最大规模的一次盗号事件。几乎所有的受害者都是在同一时间段被同一手法盗取了原神游戏账号，而起因很可能是米游社的一个古早漏洞——早在9月开服时，nga论坛就有玩家发帖询问并向官方举报此事，但在当时并未受到任何重视。

  

![](../Images/b38ab4a6422b34daed6f6617aea26884.png)

9月已发布在nga论坛的帖子

  

**事件中所有的受害者都满足两个条件：一是手机注册，二是没有绑定邮箱和安全手机。**这些玩家的手机都在凌晨收到大量验证码，其中就有着原神这款游戏的改绑验证码，手机也因此被不法分子改绑，所有虚拟财产落入他人手中。

  

  

![](../Images/07b3f32c5b9f395e01381ff1f6313800.png)

  

而盗号者的盗号难度奇低，只需要账号密码即可完成这一流程，原因在于原神账号找回的权限设置不够完善，注册门槛更低的邮箱和安全手机的权重反而大于绑定手机和实名认证，玩家被盗号后即便向客服提供了身份证和手机号也无法找回。事后有人质疑这一方法的可行性，也很快被现成的案例惊得哑口无言。

  

![](../Images/49d4aacc01ba5125edc3266d17c32f4f.png)

  

虽然事后原帖主回复称米游社盗号难度很大，很有可能不是这次事件的主因，该漏洞也已经被修复，但造成的损失已难以挽回。根据官方的声明，绝大部分风险账号存在共享账号的情况。

  

  

**如果你用微信**

  

  

有人说要送你游戏皮肤和装备，是不是难得一遇的好事？不过要借一下账号登上一登，你从还是不从？从了，那你就摊上事儿了。

  

11月19日，湖南省公安厅通报了公安部督办“8·16”特大盗销微信号犯罪专案的侦破情况，共抓获犯罪嫌疑人113名，涉案微信账号逾6000个。

  

![](../Images/e7d5bf4965678c7b583495c777bf23d2.png)

  

今年8月以来，长沙发生多起冒用政府和企业领导微信实施电信网络诈骗的案件。长沙市公安局通过研判涉案微信号，发现一个涉及全国10个省、自治区、直辖市的“黑灰产”犯罪网络。

  

这一贩卖微信号帮助电信网络诈骗的团伙分为三个层级：第一层级是“大强工作室”等收购、贩卖微信号犯罪团伙；第二层级是盗号团伙，非法盗取他人微信号，经技术团队技术处理后出售；第三层级是技术团队，为盗号团伙提供微信号保号和解绑等技术支持，使受害人无法通过申诉渠道找回被盗微信号。

  

为“大强工作室”提供微信号的卖家主要有两类：一是收购贩卖微信号犯罪嫌疑人。通过各种渠道低价收购微信号，再将收购的微信号出售赚取差价。二是多个盗号团伙。盗号团伙先以赠送游戏皮肤、装备的名义将游戏玩家吸引至微信和QQ聊天群内，再以赠送皮肤装备需要登录对方微信号为由，骗取受害人微信账号和密码，然后登录受害人微信，立即删除受害人微信上的联系人和绑定的银行卡，并修改微信登录密码，随后将盗取的微信号交给技术团队进行解绑和保号处理。

  

![](../Images/f7da942e2fdc6291eb19415c6050702e.png)

  

不同微信号在圈内明码标价，仅使用了几个月的微信号在150~200元之间，如果使用年限比较久，约在四五年左右，可能会卖到600~700元。2020年以来，该“黑灰产”犯罪团伙总计盗销微信账号6000余个，非法获利数百万元。初查涉及案件30余起，涉案金额超千万元。

  

  

**就连欧盟也……**

  

  

相信大家都知道，早年间剧组没有完善的安全隐私意识时，大热电视剧里会不打码出现一些手机号，如果是空号则罢，若是确有其人其号，那常常是被打爆到影响生活，苦不堪言。这也证明了，人的好奇心和窥私欲是无穷无尽的。

  

  

![](../Images/bd88e128ee584bb1e7d8935009540490.png)

  

电视剧《爱情进化论》中出现手机号的机主收到大量信息骚扰。

  

如果有一天，社交媒体上明晃晃出现了国家级别会议的地址和密码，你会不会也想一探究竟？荷兰的一名记者就这么做了。

  

11月20日，欧盟成员国举行高级别视频会议，讨论欧盟面临的安全威胁等一些涉密议题。然而，就在会议进行过程中，一名名叫费尔兰的荷兰记者却突然上线，加入到了视频会议中，还向与会者挥手致意。在被警告其行为已涉嫌犯罪后，这名记者道歉“下线”。此次会议也因为这一小插曲而提前结束。

  

![](../Images/d89a0cfd383f4a1bb6369e6401d59f81.png)

据央视网报道，费尔兰在事发后向媒体解释称，他是根据荷兰国防部在其社交媒体账号发布的地址和密码成功“闯入”这次会议的，他也没想到能这么容易就进入一个欧盟号称采取了多重安全措施的保密会议。

  

目前还不清楚费尔兰会面临什么样的法律后果，不过他表示，如果自己遭到起诉，那说明欧盟“宁可向记者下手，也不愿意解决自己的安全漏洞”。

  

  

 ![](../Images/847510948e317ee1a15468eee9720497.png)

  

  

  

在此，**笔者希望各位能注重自己的账号安全，多重验证，不要让盗号者啪的一下就得手了！也规劝有歪心思的人好自为之，好好反思，以后不要犯这样的小聪明。法网恢恢，要讲道德。**
