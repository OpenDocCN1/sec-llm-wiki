# 首届中国I2S峰会暨工业互联网安全大赛 在南通成功召开

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247533629&idx=2&sn=2d466c8560d4e64c192d26f208f98292&chksm=febc2efdc9cba7eb4725fb1936685448b3ef22f0a148041088976d73fbbecb307d0fc18fb5ff&scene=126&sessionid=1681310649#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247533629&idx=2&sn=2d466c8560d4e64c192d26f208f98292&chksm=febc2efdc9cba7eb4725fb1936685448b3ef22f0a148041088976d73fbbecb307d0fc18fb5ff&scene=126&sessionid=1681310649#rd)

2020年10月30-31日，由南通市人民政府、公安部第三研究所主办，南通市崇川区人民政府、中共南通市委网信办、南通市工业和信息化局、南通市公安局、北京天地和兴科技有限公司、江苏智慧安全可信技术研究院共同承办的“首届中国I²S峰会暨工业互联网安全大赛”在江苏南通成功召开。

  

本次峰会与大赛，以“新基建，新安全”为主题，旨在深入贯彻习近平总书记关于网络强国和制造强国的战略思想，响应及落实“网络安全为人民，网络安全靠人民”的号召，提升长三角网络安全产业园的品牌形象，促进南通市网络安全产业的发展。

  

公安部第三研究所所长黄胜华，江苏省委网信办副主任王万军，南通市委常委、崇川区委书记刘浩，江苏省公安厅网络安全保卫总队副总队长裴建新，江苏省工业和信息化厅信息化发展处副处长金雷等领导出席峰会。峰会由崇川区委副书记、区长黄卫锋主持。

  

中国工程院院士沈昌祥，国家网信军民融合发展联盟自主可控专委会主任、少将冯燕春，军委联参网络电子局原副局长林世山，国家信息中心首席工程师李新友，国家能源局信息中心副主任温红子，国家信息技术安全研究中心副主任李冰，中科院信息安全国家重点实验室教授、北京知识安全工程中心主任吕述望，北京大学软件与微电子学院创始院长陈钟，网络信息安全管理监控与服务教育部工程研究中心主任李建华，广东技术师范大学网络空间安全学院院长蔡君，中国海洋石油集团公司科技信息部副总经理竹蔚文，中国移动通信有限公司研究院安全技术研究所所长何申，中国华电原总信息师唐义良等专家参加峰会。

  

10月30日，工业互联网大赛率先启动，大赛紧密结合实际场景和工业互联网安全技术应用发展状况，采用线下5G环境半实物仿真环境决赛的方式，通过竞赛验证5G+工业互联网安全防御方案的效果，同时演练工控安全及工业互联网安全应急预案，提高工业互联网安全运维保障能力。参赛团队需通过逐步渗透，完成题目闯关，考察参赛选手在工业互联网网络、设备、控制、平台、应用、数据等方面的安全测试、评估、运维、保障能力以及完成指定任务的理论和技术水平。大赛组委会从来自全国各地的众多报名队伍中优选了36支参赛队伍，参赛选手及专业裁判团队共200余人。经过一天半时间的激烈角逐，恒安嘉新（北京）科技股份公司、广西壮族自治区信息安全测评中心、成都安美勤信息技术股份有限公司、山东新潮信息技术有限公司、江苏正信信息安全测试有限公司、杭州默安科技有限公司这六家单位战队获得前六名。

  

![](../Images/30b68b569c48aebfc98492089942483d.png)

  

10月31日下午，首届中国I²S峰会隆重召开，72家企业、300余位参会专家、领导及企业高管相聚一堂，围绕工控安全及工业互联网安全现状、主要问题和发展趋势等展开研讨与交流。

  

南通市委常委、崇川区委书记刘浩在欢迎词中指出，在南通举办中国工业互联网安全峰会及大赛，是“风口”产业与“风口”城市的相遇，必将促进行业企业与地方政府全方位对接，促进行业与地区融合发展，欢迎众多嘉宾关注南通，选择南通，在南通加速构建完整的网络安全产业生态圈。

  

![](../Images/2436f4e3e5d46cd89576e73851e9faa5.png)

  

公安部第三研究所所长黄胜华在致辞中指出，工业互联网作为制造业和互联网深度融合的产物，已经成为工业革命的关键支撑和智能制造的重要基石，公安部第三研究所将全力支持南通打造工业互联网安全产业，愿意与社会各界携手共同，在工业互联网安全领域做出新的贡献。

  

![](../Images/618b6ad636bb13d4217b4eee7ad2e1fb.png)

  

江苏省委网信办副主任王万军在致辞中表示，南通市积极发展网络安全产业，特别是与公安部等保中心合作共建的长三角网络安全产业园落户崇川，更是为网络安全产业提供了有力的平台载体，希望园区进一步抢抓机遇，稳扎稳打，在技术创新和产业规模上不断取得突破，为江苏网络安全产业发展创造新的经验。

  

![](../Images/24b47c3d33f625dbf15a5ea04ea71d24.png)

  

在随后的产业推介中，崇川区委常委、副区长闫静翔在推介南通崇川区网络安全产业发展环境时指出，南通是长三角北翼经济中心，地处长三角地理格局塑造的核心位置，随着新机场、北江沿高铁、通州湾新出海口等重大基础设施建设的加快推进，南通站上了发展“风口”，正成为各方关注的“网红”城市，今年有望迈入“GDP万亿俱乐部”。南通发展网络安全产业，有着良好的产业基础、央地合作基础，已经制定出个性化产业扶持政策，在载体使用、平台建设、研发投入、人才激励、产业投资、应用示范、举办大赛大会等方面给予大力支持。

  

![](../Images/5de307123d3deef67253d02e6fe12334.png)

  

在主题演讲环节，沈昌祥院士提出面对日益严峻的网络威胁，要牢记总书记“没有网络安全就没有国家安全，没有信息化就没有现代化”的重要论述，建立起安全可信-科学的网络安全观，落实等级保护2.0标准，夯实网络安全基础，建设可信安全管理中心支持下的主动免疫三重防护框架，用主动防御可信计算打造工业互联网安全新生态。

  

![](../Images/ea261ff0a9552b9e8124c04f334cc1af.png)

  

吕述望教授提出，创新网络强国建设是中国今后的头等大事，要牢牢把握主动权，实现自主可控，要加快互联网关键技术的开发和创新，只有在技术领域走到最前列，中国才能根本改变网络安全的形势。

  

![](../Images/109a84fb440f0bdcdfc5b14d721e8e4a.png)

  

中国移动通信有限公司研究院安全技术研究所所长何申、北京天地和兴科技有限公司副总裁孙高岭分别发表了《可传递信任链的安全赋能体系》、《工业网络安全融合发展的思考》主题演讲，认为要坚守工业网络安全新高地，构建新一代工业网络安全融合发展新生态真生态。

  

![](../Images/0d8ce65e4522c1f496d469e72b79c2d6.png)

  

会上，天地和兴、安帝、思特奇、开源网安、曙光星云、知道创宇、国信金通、安盟、中天数港、国利网安等企业落户园区并签约。天地和兴、江苏智慧安全可信技术研究院、中国移动、梆梆安全、开源网安、安帝、思特奇、圣博润等企业启动工业互联网安全产业联盟（I²S联盟）筹建仪式，为工业互联网安全产业发展聚力赋能。

  

![](../Images/d3ca06543e4cd5aa7a809ed8a02dec17.png)

  

据了解，长三角网络安全产业园是南通市崇川区政府、南通市工信局、公安部等保中心共建，于2019年11月启动建设，经过一年的建设，园区快速发展、茁壮成长，“两院、两基地、两基金、五中心”的总体框架全面形成，中国系统、深信服、启明星辰等20多家企业相继落户，等保云防、等保云查系列产品完成研发并投入使用。下一步，南通将借此次大会机遇，全力统筹资源，坚定不移发展网络安全产业，打造成为具有区域影响力的网络安全产业高地。
