# 人物｜勃林格殷格翰陈龚旖：人生就是一次次选择

成长是什么？

  

电影《寒战》中，梁家辉用一句话回答，“没学会走，先学跑，从来不是问题，先问问自己是不是天才。如果不是，就要一步步来。”

  

陈龚旖理解的成长是step by step，人生中的每一小步都是一个选择，而成长其实就是选择的最终结果。这里的选择并不是指那些阶段性的抉择，而是指在生活和工作中，我们每一天、每一刻都在做的选择。

  

我们每个人的成长道路就如同树枝一样到处有细小的分叉口，而每一个细小的选择，都可能对你今后的发展起到至关重要的作用——颇像心理学上的“蝴蝶效应”，即任何细小的变化最终的发展方向可能截然不同。

  

陈龚旖是标准的科班毕业出身，其成长过程也跟安全有着千丝万缕的联系，拥有十几年的网络和信息安全的从业经验。而在他的职业生涯中，又何尝不是在选择：从甲方到乙方再到甲方，历经神州数码、宜家等多个内外资企业，考取了Microsoft MCSE和CCIE等多个高含金量证书......

  

正是十几年中一次次的选择，让他和网络安全之间的距离越来越近，并最终相交在一起，而**这也正是他的成长故事。**如今，陈龚旖已经是世界上最大、最成功的私人拥有的制药集团——勃林格殷格翰大中华区信息安全负责人，目前正在积极打造其相应的企业信息安全体系。

**因为喜欢所以选择**

  

2000年，经过之前的宣传和推广，电脑逐步开始在城市中普及开来，而我们的主人公陈龚旖就是在那个时候开始接触电脑，是笔者采访的诸多大咖中接触电脑比较早的一批。

  

回忆起那时候的场景，即便相隔近20年，陈龚旖却依旧历历在目。虽然那个时候的windows 32电脑不像现在这么好用，更加没有Linux，但那稍显奇怪的语言、难用的系统和简单的功能所组成的电脑依旧给他带去了最初级的计算机启蒙。

  

至此，好奇心重的陈龚旖喜欢上了计算机，不论是娱乐还是简单的编程，都让他乐此不疲。现在回过头看，那个时候的游戏和编程都太过简单，但是却不妨碍给当时“刚刚见过世面”的他留下深深的印象，直接导致他在高二时选择报考计算机二级。

  

对计算机技术的热爱让陈龚旖毫不犹豫地选择了计算机信息与技术专业，这个专业当时国内的大学也才开设不久，更令人无奈的是，他们是上海海洋大学第一批就读该专业的学生。

  

新专业就意味着教师没有多少直接的教学经验，课程和教材的安排也难以达到完美的效果。用陈龚旖的话来说，“我们更像是一群小白鼠，用来实验这个专业和教学效果”。

  

那时候的计算机信息与技术的课程基础到令人不敢相信，大一的课程甚至包括了鼠标、键盘的介绍和教学。当然，更多的还是对于计算机以及信息技术的教学和实践。

  

大学四年的课程很快就结束了，虽然大部分都是极其基础的知识，但却也给陈龚旖打下了十分坚实的基础，而且，很快他就在工作中遇到了相应的实践。

  

2006年，陈龚旖进入上海市交通运输集团的一家下属企业，担任信息技术岗位。就在他进入公司不久后，上海市交通运输集团下发一纸命令，要求企业必须将纸质的系统向信息系统过渡，正式打造电子售票系统。

  

作为科班毕业的大学生，陈龚旖毫无疑问是其中的主力军之一。在了解了领导的意思以及参照其他行业的信息系统之后，属于他们企业的电子售票系统很快就诞生了。并且受到领导和同事的好评。

  

而后，陈龚旖的一个选择出乎所有人的意料，他打算脱产学习考取Microsoft MACE和CCIE的证书。很多人对此十分不理解，但是他有自己的考量和坚持。虽然大学四年学习了计算机信息与技术，但是其知识终究还是过于基础，而在工作中也很难快速提高技术能力。

  

![](../Images/009bbd2e33d176f2db16e0ae316a53cd.png)

  

![](../Images/9a6c57e772fbe53f22582e67591e9720.png)

  

陈龚旖考证的目的也正在此，通过系统的学习提升自己实践的技术能力，从最底层的网络系统开始，一步步学习最新的技术和知识。

  

这里简单科普下这两个证书的含金量。

  

Microsoft MCSE是整个微软认证体系中等级最高的一个认证，所以它要求的考试科目也最多（共7科，更提供了30余门选考科目），划分为WIN2000 和WIN2003两个版本的认证，又在这2个操作系统上衍生出了共计6个专业方向。而CCIE是全球公认为IT业最权威的认证，是全球Internet working领域中最顶级的认证证书，2008年全国CCIE证书持有者不过几千人而已。

  

一年左右的时间里，陈龚旖拿到了这两份高含金量、高考试难度的证书。这就是他要辞去工作的原因所在，必须要集中所有的精力全力以赴，倘若想要一边工作一边准备考试，很有可能一个证书都拿不到，而这些证书的存在也大大弥补了他在信息技术方面的工作能力。

  

**乙方到甲方，技术到安全**

  

2010年左右，已经拿到了MCSE和CCIE证书的陈龚旖选择进入神州数码，成为一名网络工程师，主要负责前端的技术支持。在这里，他站在乙方的角度，开始接触到大量的网络安全基础设施建设的项目，其中不少项目安全还是重要的考核指标之一。。

  

然而，在那个时候网络安全依旧还处于初级阶段，企业更关心的大多都是主机安全，而非今天真正意义上的网络信息安全。人们对于网络安全的认知依旧还停留在控制点、防火墙、IPS等传统领域。

  

但是，不可否认的是，安全已经逐渐兴起，越来越多的安全事件驱动着企业开始重视安全。陈龚旖加入安全部门不久之后，神州数码服务的重点也由企业架构安全、系统安全逐渐向应用安全、数据安全等，也让他有更多的机会接触到更多的安全领域和当下新兴的安全技术。

  

接触的越多，对于安全的兴趣就越浓。于是，陈龚旖开始慢慢地了解什么是真正的安全，企业为什么越来越重视安全，安全的作用点和切入点是在哪里......

  

不知不觉中，在神州数码陈龚旖完成了网络安全的自我启蒙，“网络安全”的概念已经在陈龚旖的心中落地生根，他似乎已经知道自己未来的道路通向哪里了。

  

![](../Images/ae88cf19d4cf890734d412bb40b553ba.png)

  

2012年，陈龚旖离开神州数码，前往一家外资任职，再次回到了甲方企业。其原因在于，这家外资企业的network security team需要一个既懂技术又懂网络安全的人才，而他恰好合适，更重要的是，选择这个岗位离安全将更近一步。

  

从乙方回到甲方，陈龚旖最大的感受就是思维和方式的转变。在乙方关注更多的是项目，而在甲方所需要考虑的问题就需要更全面和可持续性，是两种完全不同的思维方式，而这样的经历也让他在做安全时更加游刃有余。

  

2013年，这家外资公司成立了Information security部门，一改之前安全分散于各个部门的现状，开始将所有的安全相关的工作全部独立出来，企业信息安全迎来了高光时刻。也正是在这个时候，陈龚旖逐渐理解甲方人员眼中的Information security，那是一个非常大的范畴，除却技术、攻防以外，还有政策合规、行业要求以及各种流程管控等。

  

这一刻，他惊喜地发现，原来信息安全竟是如此辽阔，而对安全的理解也从单纯关注安全技术上升至一个新的高度——**想要真正做好信息安全，单靠技术永****远无法实现，因为和攻击相比，防护技术几乎永远存在滞后性，唯有将****governance control****和****technology****互补才能有效降低企业面临的安全风险。**

  

**真正意义踏入网络安全**

  

2017年，对于陈龚旖而言颇具纪念意义。

  

这一年，我国网络安全史上极为重要的一步法律——网络安全法正式实施，是网络安全行业最为重要的里程碑事件之一。这一刻，网络安全才真正进入了爆发式增长的阶段，信息安全的重要程度直线上升。

  

这一年，陈龚旖从上一家公司离职，加入宜家，担任信息安全部门主管一职，真正意义上踏入网络安全这一行业。之所以加入宜家，也是他深思熟虑之后的结果：因为喜欢，更是看好网络安全这一行业的发展方向。

  

![](../Images/333de10fd948086b986e85698ae8fe5f.png)

  

众所周知，到了2017年，中国互联网信息化高速公路已经基本建设完毕，那么接下来需要什么呢？陈龚旖认为是“安全”，是保障这条高速公路能够顺利通过的安全。

  

彼时宜家已经提出了multi channel 战略，即以线上加线下的销售形式取代之前的纯线下门店的模式。作为一家国际性的零售企业，宜家想要在国内真正落地multi channel战略，势必绕不过网络安全，尤其是在2017年网络安全法已经落地的情况下。

  

很明显，这时候的宜家需要一个既了解国内网络安全形势，擅长合规和网络安全技术，同时还拥有一定外语水平的人，而有过外企和信息安全工作经验的陈龚旖刚好完全满足这些条件，双方自然一拍即合。

  

进入宜家之后，陈龚旖首先做的就是合规、风险评估和内控体系。在他看来，外企想要在我国开展业务，合规必不可少且极其重要。这是一条红线，没有任何商量的余地。因为重视，所以宜家应该是外资中第一批完成了等保1.0 的所有流程，2017年，宜家有4个系统通过了等保三级，在所有的外资企业中排在前列。

  

某种程度来说，合规更像是一个最基本的准入门槛，而风险评估才是对自身的全面体检，也是安全部门能力强弱的具体表现形式。因为安全的目的之一就是在事件发生之前找出企业潜在的风险，并根据结果对企业的内控体系进行改进，包括技术、管理和流程三个方面。

  

在宜家的时间，陈龚旖开始真正地在现在意义上的信息安全领域大展拳脚，开始真正地将自己的多年所学的知识和经验付诸于实践。

  

然而，在宜家的两年多时间里，陈龚旖慢慢发现自己遇到了瓶颈，于是萌发了离职的想法。2019年，他选择离开宜家，加入一个更大的平台——勃林格殷格翰，其原因自然是希望自己能够在信息安全上更进一步，真正从企业信息安全负责人的高度审视企业的信息安全体系的建设和落地，真正输出安全应有的价值。

  

**薅羊毛并不是一件坏事情**

  

对于电商而言，“薅羊毛”的行为怎么看似乎都不是一件好事情，但陈龚旖却说“薅羊毛并不是一件坏事情”。彼时，他还在宜家担任信息安全主管，而宜家想要进军电商领域势必要面临“被用户薅羊毛”的风险。

  

但是，从企业的角度出发，薅羊毛就一定是有害的吗？陈龚旖表示“薅羊毛”原来其实是个中性词，事实上，业务想要有所发展就必须存在一定的羊毛让用户来薅，否则业务就没有任何的吸引力，反而要认真思考业务的问题。而企业真正在意的应该是不正当的薅羊毛行为，以及把握好薅羊毛和业务发展之际的平衡关系。

  

对此，陈龚旖有着切身体会。2017年，他刚刚入职宜家，通过后台发现存在很多的薅羊毛的行为，很多账号不是真正的用户，而是他人拿来薅羊毛的人机。

  

![](../Images/ea9f8ea89e45b5ca9b9fe69add0b9204.png)

  

而当他拿着这些数据向boss报告时，对方反问了他一个问题，“薅羊毛的量有多少，具体行为是什么，现阶段业务收入如何？”

  

原来，老板并不care到底谁在薅羊毛，薅来的羊毛到底是自用还是卖给他人，他关心的是库房的货发出去以后，业务的收入到底有多少，产生的利润能不能cover这些风险。对于老板来说，可控状态的薅羊毛行为可以接受，甚至在业务推广初期还是一个不错的市场培育的行为。

  

当然，这里需要说明的是，我们讨论薅羊毛行为必须要基于相应的业务模式，撇开业务模式谈薅羊毛没有任何的意义。

  

有时候，业务就像是一座天平，在它的两端分别是risk和business benefits，当你的risk大于你的business benefits，则意味着出现了问题；反之问题则是在可控的范围之内。安全需要做的就是尽可能的降低risk，提升企业的business benefits。

  

说到底，企业最终的目的必定是为了发展和利润，如果一定程度的薅羊毛行为能够为企业业务带来更大的活力，更多的利润，那又何乐而不为呢？而安全存在的意义在于将薅羊毛的行为尽可能的限定在规则之内，降低企业业务面临的风险。

  

而在跟老板汇报沟通的过程中，陈龚旖发现了一个新的问题，那就是领导或者老板并不关心具体的安全工作，他们更愿意知道安全究竟给公司带来了怎样的收益，降低了哪些风险，节省了多少资金等。

  

其实这也正是很多安全从业者跟领导或者上级汇报时普遍存在的问题：如何量化企业信息安全的价值？陈龚旖的应对之法同样简单直接：将安全的语言翻译成对方最关心的指标和最擅长的表达方式，而不是直白的用安全的语言沟通 。

  

例如对于企业的CFO来说，他最关心的指标最直接的就是，安全部门赚了多少钱，或者省下了多少钱，所以汇报的时候安全的价值就必须和钱直接挂钩。

  

其中最关键的地方就是如何将安全和钱之间划上等号。对此，陈龚旖表示有两种方式：一是将现有的商业模式进行计算，只要将具体的数据输入就可以得出产生风险的可能性有多大，产生的经济损失有多少。

  

二是横向进行比较，即和行业中其他公司在信息安全方面的投入和现状进行对比，对于管理层来说，这是一个很好的说明方式，也是体现安全部门价值和能力的最好方式。

  

值得一提的是，陈龚旖表示，作为企业信息安全负责人，除了需要拥有一定的沟通技巧外，更重要的是一定要守住两条线：**底线和上限。**

  

底线其实就是监管红线，企业的业务经营必须要满足政策合规和行业合规，确保企业不会因此产生监管风险就是底线。上限则是指风险可能造成的损失将大于业务所产生的收益，这是安全必须要遵守的上限。

  

所有的安全工作都必须优先满足这两个关键目标，安全部门也可以通过这两条线来制定相应的目标和战略，并以此为重要指标制定落地实施的具体动作和规划。

  

**给后浪们的话**

  

聆听大佬故事的时间总是过的非常快，就在采访即将进入尾声时，苏苏问了陈龚旖一个略显尴尬的问题：您的英文水平毋庸置疑，那么您第一次进入外企时，您的英语水平如何？

  

出乎意料的是，陈龚旖表示那时候自己的英文水平并不厉害，甚至还有点糟糕。那么他是怎么做的呢？

  

过程很简单，无非是不停的背单词，不停的和国外的同事沟通，一个一个单词掰开来学习。但是在实际工作和生活中想要做到这几点却又千难万难，因为这要求我们必须要有持之以恒的坚持，长时间学习枯燥知识的耐心，以及敢于开口、不怕丢脸的勇气。对于很多人来说，也许勇气比前面的两者还要难的多。

  

“学英文就是这样，没有任何的捷径可以走“，陈龚旖笑了笑，”最早我和同事之间的交流是一个一个单词往外蹦，然后是慢慢可以说一些简单的句子，再到可以听懂别人在说什么，最后才可以进行流利的沟通。”

  

其实，苏苏想说的是，安全又何尝不是如此？

  

正如陈龚旖想要对即将或刚刚踏入这个行业的后浪们所说的一样，多一些耐心，多学一些知识，千万别着急的将知识变现。**网络安全是一个充满着朝阳的产业，我们要做的是真正地耐下性子投入其中，跟上它前进的步伐，那么有一天你会发现原来自己已经这么厉害了。**
