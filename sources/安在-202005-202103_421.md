# 疫情重来？警惕个人信息再泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247533498&idx=1&sn=66cc00be79068395e9523668fc7bd8b2&chksm=febc297ac9cba06c72d9a73226d799f1687c2188dc2d5e44bc5af0684804414e318322be1ebd&scene=126&sessionid=1681310663#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247533498&idx=1&sn=66cc00be79068395e9523668fc7bd8b2&chksm=febc297ac9cba06c72d9a73226d799f1687c2188dc2d5e44bc5af0684804414e318322be1ebd&scene=126&sessionid=1681310663#rd)

北京突发的疫情牵动着全国人民的心，防控工作又一次从常态转变为了应急。在不知何时会卷土重来的灾难面前，众人的神经被一次又一次地刺激着，对任何一点风吹草动都异常敏感。这份敏感是一把双刃剑——既是能够提前敲响警钟的保障，又是可能侵犯他人隐私、泄露敏感信息的导火索。

  

  

![](../Images/8066a304907a2dbc5541c05575a19278.png)

6月14日，河北燕郊三河市公安局在工作中发现本地多个微信群传播标题为《紧急突发事件快速报告表》的传真文件照片，内容涉及三河市居民的隐私信息。经警方查证后发现，是由街道办工作人员贾某某私自转发至家庭群，继而扩散至外部社会微信群，在本地造成了大量传播。

  

违法嫌疑人贾某某因侵犯公民个人隐私被三河市公安局依法行政拘留10日，并处罚款500元，但居民的隐私外泄已成定局。据文件内容可知，当事人早在发现全家低烧的情况后很快便报警告知，当地社区街道已进入核查阶段，但贾某某未对信息进行脱敏处理，直接将个人隐私信息对外公开，这一举动对当事人造成了难以磨灭的伤害。

  

![](../Images/3ba0f398c71d39322c1199020af0bab5.png)

无独有偶，就在6月初，河南郑州一民办高校近两万名学生信息也遭到了泄露。根据学生的反馈，他们填写了返校相关的资料，包括姓名、身份证号、宿舍门牌号、专业等二十余项信息，表格详细定位到个人。多名学生反映，在交上资料后不久，就收到了骚扰电话。

  

![](../Images/8650b2b667dd38e1c6bf9dcf86ea6d1f.png)

6月10日，该学校就学生个人信息泄露事件发布《致歉声明》。声明称，由于工作人员缺乏保密意识，造成部分学生的个人信息泄露，已对直接责任人予以解除劳动合同，对相关部门负责人及两名主管校领导予以记过处分。

  

只是这些已经被泄露的学生信息，已经流入了灰黑产的汪洋大海，在未来的无数时刻，都将被贪婪的眼睛注视着，成为诈骗犯罪的新温床。

  

而在我们的邻国俄罗斯，也发生了一起大规模泄露个人信息的案件。据俄罗斯卫星通讯社sputniknews报道， 一个包含11.5万名因受新冠疫情影响滞留海外、后又回到祖国的俄罗斯公民的信息数据库被人拿到网上售卖，卖主声称内含11.5万条信息。

  

![](../Images/470810ac18e713d68e6eaa2a75db4220.png)

根据卖家披露的信息，数据库有58栏，含姓名、出生日期、本国护照信息、地址、电话、邮箱、俄罗斯出入境日期、在国家服务门户网站递交申请的日期以及银行卡和帐户信息，出国护照信息数以及所在国。技术人员认为，数据库极有可能是在从一个部门通过电子邮件转发到另一个部门时被复制了。

  

当一个企业发生这种情况时，最有可能产生的是随之而来的责权分配问题，相关人员往往会因为责任归属而吵得不可开交。但从企业发展的角度去判断，绝不能草率简单地定案，所有发生在系统内部的一切都和安全脱不开干系，即便外包也同样如此。

  

![](../Images/847510948e317ee1a15468eee9720497.png)

  

  

无论是街道、学校还是企业，为了应对疫情，都在进行大量的数据搜集整理归纳工作，这是当下最合理的解决方案，但数据的保管、存储及脱敏却成为了新的问题——在很多人没有安全意识的情况下，该如何阻止频发的事故？

  

我们可以参考GDPR在面对这种情况时的应对。在欧洲，GDPR将健康数据归类为“特殊类别数据”。组织在考虑证明其数据收集合理性的任何要求时，应该使用公共卫生紧急情况，可依据本地数据保护机构发表的指导，跟踪和追踪数据来源。

  

![](../Images/7d9cfe42d03d5a4456c1445d0946bc55.png)

  

针对当前情况，有专家指出：**“人们错误地认为，因为一切都在匆忙进行，因此可以以某种方式放弃个人数据的正常规则和健康数据的敏感性质。”**

  

事实上，在疫情防控期间，政企部门都应掌握好知情权与隐私权的平衡，严格依据相关规定执行，按照“涉密不公开、公开不涉密”的要求，遵循“谁公开、谁负责”的原则，严格做好疫情期间信息公开保密审查工作，确保国家秘密、工作秘密、内部敏感信息和个人隐私不被泄露。
