# 数亿资本入局“派拉零信任”背后的逻辑是？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247533985&idx=1&sn=7a56d64fff4c84b8688bb9acea6d1bc4&chksm=febc2f61c9cba6778a4d9d661ef18e051f870cf38804826315886549e10b7220d977afda1bf0&scene=126&sessionid=1681310612#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247533985&idx=1&sn=7a56d64fff4c84b8688bb9acea6d1bc4&chksm=febc2f61c9cba6778a4d9d661ef18e051f870cf38804826315886549e10b7220d977afda1bf0&scene=126&sessionid=1681310612#rd)

这是一个风起云涌的年代，安全愈渐成为一个炙手可热的词汇。

  

自去年以来，疫情成为互联网不可绕过的门槛，远程办公、云计算、大数据、企业数字化等快速推进，我们以前所未有的速度奔向了数字经济时代。与此同时，网络安全也势不可挡地闯入我们的视野。

  

为了解决网络安全难题，全球各国均在探索解决方案与技术理念。其中，“零信任”概念脱颖而出，尤其是自2019年开始，呈爆炸式规模发展。而彼时，即2019年7月12日，美国国防部发布的《国防部数字现代化战略》附录中列出的在国防领域有应用前景的技术中，将零信任安全（Zero Trust Security）作为优先发展的技术之一。

  

两年多来，零信任理念愈发成熟，同时也受到了资本的认可。而以零信任理念为主打产品服务的安全厂商，自然更是受到资本的热捧。譬如11月1日，国内零信任安全的领军企业派拉宣布完成数亿元人民币的D轮融资。

  

据悉，本轮融资，派拉将主要用于零信任安全相关的研发技术投入、人才引进和市场开拓，持续优化产品矩阵，增强一体化零信任安全服务能力和落地能力。

  

  

**资本为何看好派拉与零信任？**

  

资本所向，乃重其利；利之所生，乃缘其技。

  

对于网安领域的安全企业，数亿级投资规模实属不多。数亿的融资，是资本对零信任的认可。具体到派拉，资本热捧的无疑是他们基于零信任安全理念所研发的技术产品。尤其是在解决身份安全层面，派拉手持利刃，眺望远方，壮志在胸。

  

在派拉研发副总裁&联合创始人李广兵看来，资本坚定地大规模投资派拉，主要基于三个层面的因素：

  

首先，一直以来，派拉发展非常迅速，新客户增长也相当快，2020年增长了200多家新客户，今年至今已有近300家新客户的增长，并且新老客户的满意度在业内处于领先水平；

  

其次，派拉致力于身份安全，而零信任就是以身份管理为核心的，同时派拉在前几年就开始布局API网关、数据访问安全等领域技术，为派拉一体化零信任战略的升级提供了非常扎实的技术能力和产品能力；

  

再者，投资方更能看到当下对安全的需求量非常大，派拉不但持续有新产品发布，已开发出四大产品，包括SDP、IAM、API网关、特权账号，未来两年，派拉在零信任领域还会继续发布新产品，为一体化零信任安全的落地不断积蓄产品能力。同时，派拉还组建了创新中心来探索安全领域新方向，确保技术的领先性和专业性。

  

![](../Images/d1a594707325de6bc24505048d013952.png)

  

当然，这是一个宏观的视野，为派拉的发展奠定了更强的信心。聚焦到当下，自然还是要看当前产品的安全能力。对此，李广兵执掌派拉研发多年，拥有深厚的经验与细腻的感触。

  

为什么要做零信任？李广兵认为，目前已经进入到一个高速发展的数字时代，以边界为核心、默认内网安全、信息化环境相对静态的传统边界安全防护逐渐失效，而云计算、大数据、AI等新兴技术的蓬勃发展，使得企业机构的平台、业务、用户、终端、网络环境等呈现复杂化、多样化的发展趋势，安全风险随之而生，安全态势也愈发复杂。

  

零信任以身份为中心实现动态访问控制，基于多维属性构建动态策略，同时实现多点精细检控，进行持续评估并实时调整，被认为是提升系统和网络整体安全性的行之有效的方式，或将成为未来一段时间主流的网络安全架构。当下海外零信任产业已进入规模化发展阶段，这对国内安全厂商也是一种指引与激励。

  

然而，零信任概念虽好，并不代表人人都能将其做好。当前，专注于零信任的安全厂商目不暇接，找准着力方向，明确差异化，是安全厂商发展的必行之事。对此，派拉又是如何做的呢？

  

李广兵回忆道，2019年零信任很火的时候，其实很多安全厂商就逐渐往零信任靠近，成为零信任中的一环。因为零信任不是一个产品，而是一个体系，从最前端的比如终端安全，到SDP网关，到微隔离，到最核心的身份安全，再往后还有主机安全、数据安全，覆盖面非常广，每个厂商都有一个非常专注的点。有些厂商侧重于SDP，有些侧重于微隔离。

  

派拉做零信任，原先主要专注于身份安全领域，去年到今年，连续两年融资，建立了以IAM身份安全为核心，逐渐延伸到一体化零信任安全。通过前端打造SDP，把零信任的一些通道打通；通过IAM打通面向应用系统的通道；通过API安全网关打通后端API的通道；通过特权管理打通的是后台，如数据库、服务器、中间件等。

  

李广兵介绍称，派拉一体化零信任安全解决方案拥有三大技术：1、身份管理与访问控制；2.统一授权和动态访问策略；3、SDP网关构建与应用。该解决方案可以很好地兼容云平台、大数据、物联网等各类数字化进程下的新技术，并支持远程办公、移动设备接入、远程运维、互联网业务访问、动态风险分析与评估等复杂应用场景，有效解决企业数字化建设中风险暴露面大、过度信任、安全闭环等难点，实现端到端的一体化零信任安全体系，为企业数字化转型的高效落地提供强有力的安全保障。

  

  

**两大热点安全：内网访问与云安全访问**

  

任何一项技术产品，都是为解决问题而服务。网络安全拥有诸多细分领域，同时也存在相当复杂的网络环境与应用场景。派拉一体化零信任安全解决方案适用于解决哪些问题呢？

  

李广兵分析道，派拉零信任有着四大典型应用场景：**远程安全办公（取代VPN）、基于公有云构建私有安全数据中心PDC、内网安全访问和SaaS安全访问、数字化转型（面向互联网业务的零信任安全）**。其中，他就内网访问和云安全访问这两大最为常见的场景予以分析说明。

  

**内网安全访问场景**

  

当前，网络环境日趋复杂，企业内网安全面临网络边界扩大、企业资源暴露程度大幅增加、传统安防体系已无法满足安全管控要求等问题，并且企业机构往往存在总部与分部，异地办公、远程访问需求暴增，企业运维人员随时响应导致远程访问内网，必然导致安全面临各种隐患。

  

李广兵就其中一点展开介绍。从企业内部来讲，内部员工访问系统，需要做单点登录，甚至无密码登录。在此认证过程中，怎么去保证客户认证的便捷性以及整个系统的抗风险能力。因此安全与便捷成了一对矛盾的存在。

  

对此，派拉在零信任和身份安全领域会有一些持续的认证，或是基于风险评估的一种认证体系。

  

李广兵举了一个案例：比如当在公司访问业务系统时，可能只需用户名和密码就可以登录，但当你在家访问公司的业务系统时，可能需要用户名、密码再加一个指纹验证，因为后台能够识别到你访问的区域可能存在风险；当你经常在此区域访问后，派拉零信任安全后台能识别你一直在家访问，会认为你家这个环境可以列为安全环境，系统会自动降低认证级别。

  

![](../Images/4295dc757d3d4be03c99248193882521.png)

  

在办公室访问时，你正常是早上8点到晚上10点在公司，如果你在凌晨2点在公司访问系统，派拉零信任安全平台会评估为异常访问，同时会自动提高认证级别。

  

这种就是在访问控制里有一个持续的访问控制，这也是目前很多企业比较看重的应用场景。不像原先的一次认证授权，整个访问期间都有权限。派拉零信任理念则是任何一次访问，都会去做认证授权。

  

**云端访问安全场景**

  

如今，数字化进程已然加速，企业机构上云已是大势所趋，而公有云成为诸多企业上云过程中经济便捷的选择。但是，虽说云端拥有各种安全防护系统，但并不意味着就是绝对安全。

  

全球权威市场研究机构IDC调查报告显示，在过去18个月中，近80％的公司至少经历了一次云数据泄露，而43％的公司报告了10次或更多泄露。IBM的《2021 X-Force云安全威胁形势报告》详细阐述了不法黑客当前所采用的各种顶尖渗透策略，以及如何在暗网市场上窃取云资源。

  

数据往往是企业的生命力，一旦泄露，后果不堪设想。在此方面，派拉近些年不断探索应对数据泄露、助力企业数字化转型的解决方案。比如，派拉云身份管理平台为用户提供统一的云用户账号管理功能以及平台级的多项目、多租户管理、计价管理、服务管理以及流量管理等运营管理功能，实现不同维度的身份操作审计与日志审计，实现一体化事前预警、事中控制和事后追溯的合规管控和监督，助力企业应对数字化进程中的数据安全问题。

  

![](../Images/a407595dc8ceb9f5d0ac3b19fb3b1909.png)

  

具体说来，企业上云以及远程访问过程中，如何保证客户端到云端访问通道的安全，李广兵认为，派拉可以通过SDP保证整个通道的安全。到了云端之后，云端往往拥有多个应用，多个应用之间的访问如何保证安全？派拉则拥有应用安全、API安全、特权管理等功能，保障应用访问的安全。

  

此外，在云端还会存在一些问题，比如数据存在云端，企业机构对云供应商是不是足够信任？利用派拉零信任产品，通过API访问时，API可以对数据进行加密，保证存储在云端的数据云供应商无法看到。

  

  

**适应市场贴合需求才有持久生命力**

  

其实，许多技术产品都能解决某些应用场景下的安全问题，但是，安全通常变化莫测，技术产品也要紧随市场变化和用户需求，才能拥有更强更持续的生命力。

  

因此，派拉的零信任安全产品也正做着许多难以察觉的调整，例如针对不同行业的细微调整。比如制造业，尤其是汽车制造业，其身份认证往往会覆盖几个维度：企业内部员工、供应商、经销商以及一些客户，共有四大类人的身份认证；又如像零售行业，则有门店、员工、供应商、会员等不同维度，也有自身的身份管理需求。

  

孤木不成林，安全往往是一个整体性的问题。任何一家安全厂商，都很难在所有安全领域技术都独占鳌头。认识到这一点，派拉没有选择闭门造车，而是选择融入安全生态。

  

比如，在零信任领域，派拉加入了零信任产业标准工作组、零信任联盟、CSA零信任工作组，主导并参与了零信任国标、行标和团标，联盟内有很多在安全细分领域中比较领先的一些产品，派拉选择与他们合作，比如微隔离、终端安全，致力于产品间的打通和协力，通过零信任生态的打造，交付给客户一体化的零信任安全解决方案。

  

因为客户往往不需要一个单一产品，而是一整体的解决方案。目前派拉在很多客户中做POC，从SDP到身份安全，再到微服务，包括第三方情报威胁系统，都逐一打通，避免客户需要对接多家安全产品，发挥不出整体的安全效力。

  

![](../Images/c4b72326ddd2ffc1229b8a8d2eb1cbe3.png)

  

李广兵强调，近几年，派拉在客户数量上每年保持较快的增长，目前已有1200多家企业和机构选择了派拉的产品和服务。为了能给客户提供更加安全、高效、极致体验的产品和服务，派拉始终强调产品的通用性和易用性。作为一款平台级的软件，派拉零信任平台在通用性、易用性、兼容性、安全性上都有不俗的表现。

  

  

**安全趋势预判与未来技术研发**

  

新的技术浪潮，无论是大是小，都必然会带来新的威胁。区块链、云计算、人工智能、大数据、物联网、生物识别、无人驾驶、智慧城市等概念，不断冲击着安全领域的边界，科技的迅猛发展，或许正让安全朝着一个未知的方向狂奔。

  

科幻电影《复仇者联盟2》中有一句台词：“每当地球归于平静，上帝就会投一块石头掀起波澜。相信我，他马上就要投了。”

  

同理，网络安全不可能归于平静，只要有利益存在，不法黑客必会持续投下一块块大小不一、形态万状的石头。所以，对未来安全的预判，对安全的技术储备，同样是不可懈怠之事。

  

李广兵也同样看到了未来安全许多纬度，他感觉两个方向尤为重要。

  

其一，则是企业会往云原生方向发展，派拉安全也会往云原生方向迁移，包括自身产品架构以及第三方的应用、基础架构的支持，最终全面拥抱云时代；

  

其二，则是涉及身份隐私层面。身份安全如何跟区块链、同态加密去整合，既能做到身份认证，又能保证个人隐私数据不被泄露出去。这是未来技术层面要去做的事情。

  

对此，李广兵展开道，从业务层面讲，原先侧重于人的认证、API的认证、数据的认证，后续会往IoT等设备的一些认证上去发展。他发现目前国内国外在终端设备的认证方面都做得都比较弱，机器身份认证也会是安全的一个大方向。此外，身份监控和身份合规尚有开拓空间，眼下许多客户还没有很强的意识，后续身份治理也是比较大的领域。

  

既往可鉴，当下不乱，未来不忧。零信任之路还很漫长，期待派拉大展拳脚，也期待更多安全厂商百花齐放。
