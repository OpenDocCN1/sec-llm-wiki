# 大事件！美国务院遭黑客攻击

这两天国外又发生了一次网安大事件，美国国务院竟然遭受了网络攻击。 

  

![](../Images/ce84a7e0ab4cbf8e5951fb37fac39bdb.png)

  

据美国福克斯新闻频道（Fox News）记者海因里希（Jacqui Heinrich）信息，美国务院遭到网络攻击。 

  

海因里希表示，美军网络司令部报告，可能存在严重入侵情况。同时，网络攻击的规模，以及对犯罪嫌疑人的调查规模“尚不清楚”。也不清楚采取了哪些措施来减轻攻击的影响，以及“当前哪些行动面临风险”。 

  

![](../Images/e49ce79c9a6cb493923ac11d57a20139.png)

  

但据一名知情人士表示，国务院没有受到严重干扰，目前从阿富汗撤离美国公民和阿难民的任务“没有受到影响”。 

  

国务院发言人则在一份声明中也强调，“国务院在信息保护方面抱有认真负责的态度，而且持续采取措施以确保信息得到严密保护。出于安全原因，我们目前无法讨论任何所谓网络安全事件的性质或影响范围。”
