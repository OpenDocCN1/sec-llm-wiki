# 涉疫欺诈、抢购茅台、组团交电费、直播刷单、套路租车……近期新型网诈层出不穷

电信网络诈骗，一直是一个一本万利的生意。所以，大量的黑灰产你追我赶、层不不穷。  
  

  

通常，一个诈骗套路往往可以使用很多年，依旧能源源不断地得手。比如美女钓鱼等手段，百试不爽。但是呢，人是一种善变的物种，为了利益，必然会开动脑筋，搞出一些新花样新套路。

  

那么，近期又有哪些新型电信网络诈骗套路呢，我们整理了一下，以飨诸君，愿有裨益。

  

![](../Images/458c1055271af88b720d9b633d8cd0f6.png)

  

  

  
疫情反弹下涉疫诈骗套路花样多  
  

近期国内疫情有所反弹，全民战疫的大背景下，一些不法分子们却在蠢蠢欲动，“创作”各类新型诈骗手段，死死地盯着大众的“钱袋子”。  

  

比如，现在人们离开一些中高风险地区，需要有48小时内的核酸检测报告。黑产就利用这一点，冒充防疫机构人员称，可通过“私人渠道”快速出具核酸检测结果。他们惯用的手法是：

● 首先大范围添加好友，对方自称是防疫机构人员。目前全民防疫，大众看到这种信息，一般会同意添加，主动配合；

  

● 对方会和你简单聊几句，如果你有外出需求，便称有“私人渠道”，半小时即可出具核酸检测阴性证明，不用出门，在家也能做；

  

● 对方会要求你提供真实的身份信息，同时备注先付款，后拿报道。此时你若提供，等于把个人隐私和钱财一并送给了对方；

  

● 对方会提供一些虚假材料证明，让你信以为真。你一旦转账之后，等下催要检测报告时，就会发现，你已经进入了他们的黑名单。

其实，在家做核酸检测，目前并不具备这种条件。据悉，核酸检测一定要在经卫健委部门认证的具备资质的医院、专业医疗机构或第三方检测机构进行。不要轻信网络不实信息和所谓“私人渠道”。这不仅可能影响自身正常出行，更有可能落入不法分子非法敛财的骗局。

  

![](../Images/d19baf97459503dc13e35ffa781543dc.png)

  

此外，还有“免费领取新冠疫苗接种意外保障”的诈骗，常用的手段为：

● 群发关于“免费领取新冠疫苗接种意外保障”的诱导短信；

  

● 不少接种过新冠疫苗的群众便信以为真，点击进入链接；

  

● 弹出的对话框要求提供真实姓名、身份证号以及手机号码即可领取；

  

● 通过盗取个人信息，进而达到骗取钱财的目的。

  

另有售卖新冠治疗“特效药”的诈骗，诈骗步骤如下：

● 骗子通过技术手段使来电显示为某某区疫情防控专线，同时自称是防控中心某主任；

  

● 告知你的健康码或检测报告存在异常，可能感染了新冠肺炎，目前尚在潜伏期；

  

● 介绍现有新冠特效药，每天坚持服用即可恢复健康，只需5800块三个疗程。

  

事实上，流调人员会主动表明身份，不会询问财产、特效药等，只需核实你的个人基本信息、健康状况、近期行程、其他对疫情防控有用信息等。

  

  

  

  
警惕茅台等高档酒虚假购买链接  
  

  

近日，贵州省仁怀市公安局官方微信“仁怀反诈”，发布了一则紧急预警。  

  

预警称，近期，仁怀市辖区出现一种新型电信网络诈骗，犯罪嫌疑人利用部分市民想要购买茅台酒的心理，专门针对抢购茅台酒创建一个虚假链接，骗取受害人钱财。诈骗流程为：

● 犯罪嫌疑人在各类酒业销售微信群里添加受害人后，发送购酒链接给受害人，并诱导受害人点击链接抢购茅台酒；

  

● 受害人点击抢购以后，在链接平台内通过微信支付的方式付款；

  

● 付款完成后，受害人便无法再进入链接网站查看购酒情况，并且微信已被对方拉黑。

实际上，在整个过程中，受害人微信付款过程，就是通过虚假链接转账给犯罪嫌疑人的过程。

  

![](../Images/289c8ef40c3c41ef2e224cf0aeffd369.png)

  

在日常生活中，面对陌生人发送的二维码、陌生链接，许诺转发“购物链接、二维码”返现、送礼品或其他报酬的，都不要轻易相信。凡是对方要求先转账汇款的，全部都是诈骗，同时注意保护个人身份证、银行卡、密码、验证码信息，更不能与陌生人使用“屏幕共享”操作。  

  

  

  

  
电费交费也能搞出花样诈骗  
  

  

8月11日，媒体记者从合肥供电部门获悉，近期网上出现一种通过手机“组团”跟单、参加交电费享优惠的新型骗局，稍不留意就会损失钱财，已经有市民中招。

  

**骗局一：手机“组团”跟单能享更多优惠**

  

近日，一位年轻女士来到国网合肥供电公司庐阳营业厅询问，“你们电网最近是不是有手机组团交费优惠活动？”

  

女士点开手机，上面显示一条服务信息：“475充500、949充1000，务必注意，欠费超过50无法充值，3000以上充值会延时到账3-5天……”

  

营业厅坚称目前没有像这样的交费优惠活动，这可能是新型诈骗。女士竟还不信：“这电费还能诈骗吗？但是我朋友这么交费的，都到账了哎！真的不能跟团吗？”

  

**骗局二：预存电费送空调索要“验证码”**

  

前不久，黎女士来到合肥供电公司电费计量中心蜀山营业厅咨询：“最近收到短信通知称，我是优质用电客户，可以享受预存电费送大礼活动，存3000元送空调；还有人打电话告诉我，这个活动月底就截止了，让我把手机收到的验证码提供给他们，以便帮我申请优惠，你们有这种活动吗？”

  

根据描述，营业厅人员发下，电信并非供电公司发送，验证码关系账号安全，工作人员绝对不会询问验证码信息。

  

**骗局三：电费催缴单出现可疑二维码**

最近，安徽有居民发现自家大门上贴了一张电费催缴单，这张“催缴单”上印有二维码，上面提示住户可选择扫码进行快捷交费。

  

由于以为是供电公司出了新功能，该居民便习惯性地用微信进行付款，向对方打款，直到几天后收到电费欠费通知才发现自己被骗。

  

供电公司提醒，遇到带有链接或者印有二维码的电费单据不要轻易相信。只要涉及到钱财都要多个心眼，养成先核实后支付的习惯，同时妥善保管自己的付款码。

  

  

  
抖音平台直播引诱刷单诈骗  
  

  

刷短视频已经成为人们消磨时间的习惯，其中各式各样的直播，更是让人趋之若鹜，尤其是五花八门的赚钱之道......

  

近日，刘女士就因在某短视频平台上看直播被诈骗了3万多。前段时间，刘女士在某短视频平台上看一个叫“蒋飞翔”的主播在直播推荐赚钱项目，顿时来了兴趣。

  

根据对方指示，刘女士关注了一个微信公众号，她就通过这个公众号和对方联络。对方让刘女士下载一个叫当当商城的APP，然后注册账号，开始充值刷单。里面有相应的商品任务，需要通过账号的充值金额进行购买提交订单，每完全一笔就会有相应的报酬，但是只在APP内显示，并不能提现。

  

![](../Images/2bb4b4b9b123b37158b342f0dab3e264.png)

  

对方总是以任务未完成，刷单的数量还不够等理由让刘女士继续充值刷单，直到最后发觉被骗，损失32000元。

  

这套路是不是很熟悉？实际上，这就是刷单诈骗黑产利用短视频平台人流量大，广撒网的诈骗伎俩，实则换汤不换药。除了短视频平台直播，骗子也会通过平台私信“寻找目标”。

  

其实，刷单本就违法，更加不要轻信短视频平台上带有营销等性质的视频。

  

  

  
租车公司导演“套路租”新型诈骗  
  

  

今年3月15日，上海市公安局边防和港航公安分局接到一起离奇报警：在某汽车进出口码头，一辆欲出口二手车引起纠纷，苏州某汽车租赁公司称该车是他们的，有客户租了车拆掉GPS，准备出口销售。  

  

8月11日，上海市公安局透露，该租车公司为苏州卡踪汽车租赁公司，前后使用4辆车诈骗，涉案金额50多万元，目前6名嫌疑人已被移送检方审查起诉。

  

警方称：“这辆车是租赁用来跑网约车的，租赁人未支付车费，车上一共3个GPS装置，其中两个被拆掉了，最后一个是苏州运管部门安装的，没办法拆掉。我们根据GPS定位找到这里。”

  

最终，警方查明了真相：苏州卡踪汽车租赁公司法定代表人王某甲伙同王某辉、王某乙，指使姜某超安排无业人员刘某，于今年3月1日与卡踪公司签订租车协议，租赁了一辆车牌号为苏ED67XXX的广汽传祺埃安V5小型新能源车。

  

随后，姜某超和王某伦将刘某伪装成车主，以刘某名义伪造了一份3万元的抵押合同。在拆除车辆GPS系统后，经王某伦手以4.75万元将车卖给了葛某。刘某从中获得了2万元好处费。

  

![](../Images/e5a138449acdbd006df0480c2be8170f.png)

  

  

案发当天，卡踪公司打算以租车人未支付租车费、擅自拆除车辆GPS等违约行为为由，从葛某处强行收回车辆，同时要挟葛某可能存在“收赃”嫌疑，从而实现非法获利、车辆追回的“双赢”目的。因现场产生纠纷，其诈骗目的被警方发现。

  

民警介绍，这是一起新型的“套路租车”诈骗案，市民购买二手车应持有效合同、相关证件到车辆管理所完成过户手续。切莫贪图小利，购买明显低于市场价的车辆。

  

  

  

  
结语：年轻人更要警惕网络诈骗  
  

  

可别说网络电信诈骗与你无关。8月9日，上海警方在新闻发布会上介绍，近两年，电信网络诈骗的作案手法，已经从传统的电话、短信诈骗，朝着网络诈骗转变，网络诈骗案件的占比超过85%。

  

今年，上海警方平均每天拦截诈骗电话21.5万通、封堵诈骗短信41.2万条，电话、短信诈骗发案数同比降低17.9%、8.5%。而对于越发常见的网络诈骗，其受害者几乎覆盖各个年龄段，但90后人群占比却高达62.7%。

  

此外，今年年初，中国信通院发布的《新形势下电信网络诈骗治理研究报告(2020年)》显示，“90”后已成电信网络诈骗主要受骗对象，占比达63.7%，数量超过其他年龄段人数总和；“00”后群体受骗用户数量超过“60”后群体，占比4.3%。

  

![](../Images/b73e3ef50d8df73e8859e6a39e3ced27.png)

  

这确实与我们的直觉有些相违背，因为在很多人看来，年轻人常活跃于网络，见多识广，对于各种新型事物应该具有更好的识别能力。反倒是一些中老年人，不怎么接触网络，容易成为受骗对象。  

  

调查数据不会骗人，事实就是如此残酷。为何会如此？其实原因也很简单。

  

如今，很多APP、网站平台的账号注册，都必须用到手机号，而相关网站信息保护能力强弱不一。一旦这些网站信息泄露，你的手机号以及账号信息就会随之泄露。另外，电商平台、外卖或快递的地址信息也有可能泄露。今年315晚会还曝光，部分网络招聘平台，甚至无耻地把求职者简历打包批量出售。

  

不法分子获取到你的手机号码以及部分个人信息，就能具有针对性地、精准性地伪造出各种套路陷阱来对你实施诈骗。比如常见的诈骗手段有冒充平台客服、网络兼职、网络交友等，成功率往往还挺高。

  

所以，年轻人更要学习防诈知识，才能更好地游弋于互联网中。
