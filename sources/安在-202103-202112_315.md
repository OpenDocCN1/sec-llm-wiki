# 按下信创发展加速键，中孚信息谋篇布局为网络安全夯基垒石

过去的2020年，极不平凡，新冠疫情肆虐不仅未给网络攻击活动按下“暂停键”，反而是按下前所未有的“加速键”，围绕关键基础设施的网络攻击活动，呈现出前所有地肆意蔓延、越发猖狂态势，对于全球的网络安全来说都是前所未有的“至暗”时刻。

  

面对网络安全的这场“看不见硝烟的战争”，政府、企业应该如何下好网络安全这盘“大棋”？站在时代新起点，中孚信息副总工程师苗功勋结合中孚信息近二十年的耕耘实践，带来了保障国家网络安全的答卷。

  

在网络安全形势日趋复杂的背景下，中孚信息加大研发投入，聚焦信创领域核心技术探索研究，为网络安全发展不断注入新活力，也为加快构筑信息产业发展新高地加油添力。

  

![](../Images/646463d1157534a2db3132dd5daa9520.png)

  

**信创何以成为保障网络安全的重要抓手？**

  

多年来，国内 IT 底层标准、架构、生态等领域大多都由国外 IT 巨头制定，由此存在诸多安全风险。

  

在最新发布的《“十四五”规划和2035年远景目标纲要》中，“网络安全”一词总共出现多达14次，“数据安全”出现了4次。

  

习总书记也多次强调 “没有网络安全就没有国家安全”，彰显出网络安全在国家建设的重要地位。

  

安全与发展是一体之两翼，驱动之双轮，网络安全问题已对各领域安全都产生了深刻影响，保护国家关键信息基础设施、重要网络和数据安全等涉及政治、经济、文化、社会等关乎国计民生行业的“神经中枢”是重中之重。

  

底层基础决定上层建筑。只有信息产业实现全面国产化，做到技术自主可控、服务自主可靠，才是我国解决核心技术受制于人以及推动建立中国标准、中国体系、中国方案的重要举措。

  

攻坚核心技术“卡脖子”环节，促进核心技术国产化一直是中孚信息奋斗目标。作为国内最早提出基于国产操作系统的终端安全防护工具集的企业，中孚信息紧紧把握住“十四五”的契机，构建国产化信息技术全周期生态体系，打造信创产业发展集聚区，形成以企业为主体、市场为导向、产学研用深度融合的技术创新体系，为数字经济和数字化社会发展奠定坚实基础。

  

![](../Images/7110acf31935b2e205c281251bad2b51.png)

  

**聚焦信创数据安全，加速信创安全防护解决方案可复制化**

  

惟改革者进，惟创新者强，惟改革创新者胜。

  

新业务场景推动信创发展，也对“网络安全+业务”融合趋势下对综合防御能力提出更高要求。中孚信息始终坚持数字化场景加快落地和数字产业扩围提速，为网络安全产业发展打开一个新的空间。

  

中孚信息自2011年开始涉足信创类产品研发、适配应用及产品化推广，经过近10年的积累与磨合，围绕主机安全防护、保密检查、网络安全以及数据安全等方面，最终形成了一套符合信创产品特点的市场、研发、技术支撑、生产及商务运营体系。

  

“统一部署、统一运维，是当前客户的普遍诉求”，苗功勋表示，“政企客户在完成信息化工作后，在运维层面往往依赖网络运维、安全运维、数据运维等不同角色队伍，用户往往难以理解其中的差异而造成运维工作复杂化。”

  

能够实现跨平台（Wintel体系,信创体系）的一体化的安全管理，是中孚整合所有终端防护产品形成的解决方案最大创新点，能够提高整个解决方案的可复制性，使其易于推广，为企业数字化转型提供有力的保驾护航。

  

目前在工控网络安全防护、车联网网络安全、云安全等业务场景的已经取得了有效的赋能。

  

另外，数字化转型不只在企业“发酵”，更成为政府现代化治理的核心引擎。中孚信息紧抓数字中国战略契机，服务于中孚数字安全战略，以数据安全治理为主线，重点围绕国家电子政务网络、新型智慧城市、数字化转型等建设需求，开展创新和研发布局。

  

搭载“新基建”的春风，中孚信息将加大投入山东等智慧城市安全能力建设。针对数字政府政务数据共享交换面临的安全保密治理难题，中孚信息打造的城市级数据安全大脑已经在一些城市开始试用，实现了数据全域防护和监管，提升了网络安全保密的对抗能力。

  

![](../Images/03457628b962baa92648ce8ab17a2fd5.png)

  

服务政府、企业、社会、大众，中孚信息以数字安全领军企业为目标，通过承接国家网络安全战略，进一步发挥高科技企业的技术和资源优势，也为国家和人民的长治久安贡献力量！

  

**深耕零信任领域，重构智能化数据安全系统**

  

如今，网络安全的主要矛盾已经由外部防御逐渐转换成了内部防御，以身份为中心的零信任安全架构的由此诞生。

  

零信任究竟是什么？从行业角度来看，该如何理解零信任的落地区间？

  

“实际上零信任里面强调的是身份”苗功勋提到，“零信任的难点主要集中在对用户信任的持续评估、对用户行为的精确感知以及对用户访问信息资产的动态授权上。”

  

实际上，这些技术的实现过程并不是最难的部分，在实现的同时，又能使系统兼具高可用性和易用性才是整个方案实现过程中的核心难点问题。

  

从理论上讲，零信任解决方案可适用于面对高级网络攻击和内部威胁风险时，组织传统的网络安全架构无法应对的远程访问、数据交换等众多业务场景，因此中孚信息的零信任探索之路，不仅可用于电子政务领域，还可以用于企业级数据安全防护等业务领域。

  

中孚信息以“密码定义安全”，通过密码技术的使用，研发了下一代的网络安全设备——TNA（高保障可信接入网关），逐步替代传统安全设备，构建了一整套涵盖身份认证、内容识别、风险管控等安全管控组件、提供以身份风险管控为基础的智能化数据安全管理控制系统。

  

![](../Images/6d4f4053530a3be4c70caadc36d8070d.png)在苗功勋看来，TNA网管一方面提供了应对内外部攻击的智能化主动防御能力，还通过用最为经济的密码的使用，使得边界全设备的价格成数量级的降低，解决了行业内提升安全防御能力就意味着安全支出提高的痛点问题。

  

“零信任”将成为行业新风口，中孚还将构建以DPI、大数据和AI为特征的风控平台用于实现持续身份认证、精确行为感知和动态访问控制。

  

随着诸多解决方案和思路的提出和完善，中孚信息未来将充分发挥自身在产品、市场等方面的优势，深耕零信任领域，推动安全行业资源共享，加大战略合作，持续为国家网络安全事业发展提供有力支撑，承担起网络安全领军企业的重任。

  

**奔向全面安全新布局 ，勇担数字安全领域领军者**

  

只有对自身有新要求，才能真正有新作为。

  

新时代，中孚信息不忘使命紧跟大潮，以数据安全为主线，以构建网络空间对抗能力为目标，2025年实现集团化、全面安全产业布局，成为业界认可的数字安全领军企业，从“国内领先的网络与信息安全解决方案提供商”到“数字安全领军企业”的战略。

  

方向既明，步履坚定。中孚信息未来的发展仍将紧扣全面数字安全这一主题，打造数字空间安全防控整体解决方案；加强前瞻性技术创新，探索构建多领域、多层次产品和技术服务体系；同时，建立产学研用深度融合的生态协同体系，面向数字安全领域关键安全问题，实现创新技术向产品、服务、整体解决方案落地。

  

大鹏一日同风起，扶摇直上九万里。未来中孚信息将持续聚焦数字安全领域，为网络强国战略提供保障，为区域经济高质量发展注入澎湃新动能，共筑国家网络安全产业高地。
