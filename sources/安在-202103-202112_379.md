# 虎符网络发布零信任新品：升级版VPN提供更安全远程访问

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247533825&idx=2&sn=bf520b5110ece52156fae57038cd3043&chksm=febc2fc1c9cba6d7b11585db34458ea9dc1ffaa5ebf17d61ebe8e835e1872a38c19c571f0f4a&scene=126&sessionid=1681310628#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247533825&idx=2&sn=bf520b5110ece52156fae57038cd3043&chksm=febc2fc1c9cba6d7b11585db34458ea9dc1ffaa5ebf17d61ebe8e835e1872a38c19c571f0f4a&scene=126&sessionid=1681310628#rd)

5月21日，由杭州市余杭区数字经济协会指导、杭州虎符网络有限公司主办、浙江菜根科技产业发展有限公司协办的零信任落地探索研讨会在杭州人工智能小镇会客厅成功举办。来自能源企业、互联网企业、政府单位等领域的安全专家分享了在组织内部运用零信任安全理念、通过引入零信任解决方案来构建外防攻击、内护数据的新安全体系的实践情况。研讨会期间，**虎符网络正式发布零信任新品——虎盾零信任远程访问系统（Zero-trust Remote Access System，简称“虎盾ZRA”）。**

 

近年来，在产业数字化升级和政企业务上云的趋势下，传统的基于边界的安全防护体系在当前环境下已呈现出捉襟见肘的局面，难以应对各类组织所面临的安全新挑战：云计算、移动物联、远程办公导致的企业边界不断瓦解，无法继续基于物理边界构筑安全防线；以APT攻击为代表的高级安全威胁能连续突破传统的网络边界防线；对私有业务的非授权访问、数据窃取等内部威胁层出不穷。

  

正如余杭区数字经济协会秘书长任中起先生代表指导单位发表的致辞中所述，“在我们推进数字化改革、产业数字化、数字产业化过程中，网络安全问题、数据安全等问题接踵而至，我们在享受数字化改革、数字化发展带来的便利和快捷的同时，我们也不得不面对网络安全、数据安全等问题”，“做好网络安全、数据安全保护不仅关系到普通老百姓的切身利益，更是对数字经济发展关键生产要素的保护，必须与数字经济发展协调一致、齐头并进，以安全保发展，以发展促安全”。

  

![](../Images/f12f0d99426aaf89bbacb18fe72544c8.png) 余杭区数字经济协会秘书长任中起代表指导单位致辞

 

以“永不信任、永远验证”为核心理念的零信任安全模型应运而生，它是解决物理边界消融、重塑企业安全体系的新方式，已逐渐成为行业关注的焦点。作为零信任安全领域的创新型安全厂商，虎符网络自从2019年底成立以来，始终聚焦并持续发力零信任安全产品，继2020年8月发布首款产品“虎盾应用安全访问系统后”，**此次研讨会期间正式发布重磅新品——虎盾零信任远程访问系统（虎盾ZRA）。**

  

![](../Images/a0b76f9159bbb51af3d2b18cfc99b719.png) 虎盾ZRA发布仪式

 

虎盾ZRA是可用于升级换代传统VPN设备的下一代远程安全访问系统。在提供远程访问通道之外，同时提供多种安全保障。之所以被定义为下一代零信任远程访问系统，是由于虎盾ZRA比传统VPN具备更好的体验，更安全的防御措施。

  

![](../Images/45da23784e9529a985b6ce519175a304.png) 虎符网络CEO王伟（alert7）发表主旨演讲

 

虎符网络CEO王伟发表题为《“知码开门”——虎盾零信任远程访问系统》的主旨演讲。王伟介绍，针对远程访问企业内部服务资源的全业务流程，虎盾ZRA提供基于设备侧环境信息和网络侧行为信息，覆盖网络层、登录层、访问层一体化的零信任防御体系，包括SDP网络敲门、用户认证、设备准入、SARE模型访问控制、异常行为监测、深度审计等六大安全能力，可应用于远程安全办公、渗透测试、重保等场景。

 

在企业互联网边界处部署虎盾ZRA后，可在互联网上为企业架设一层以身份为边界的逻辑私有网络，实现四大安全目标：自己服务隐身、人员身份明确、可信设备防御、动态评估授权。

5月21日是24节气中的小满。“四月中，小满者，物致于此小得盈满”。此时夏熟作物籽粒已开始饱满，但还没有成熟，因此称为小满。虎符网络选择在这一天发布新品，有其寓意：创业一年多以来，虎符网络羽翼渐丰，但还远未到成熟之时。未来，虎符网络将不忘初心，持续创新，秉承工匠精神打造更具竞争力的产品和服务。
