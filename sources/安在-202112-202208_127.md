回顾业界安全漏洞威胁，Apache Log4j 远程代码执行漏洞（CVE-2021-44228）一经出现，便在安全领域引起轩然大波。Apache Log4j 是一款普适性强的开源 Java 日志框架，被广泛应用于不同业务开发过程之中。黑客可通过该漏洞，直接发起恶意请求，触发远程代码执行漏洞。

  

应对这一“核弹级”攻击威胁，Akamai 及时开启云端防护引擎，建立防护屏障，为众多客户争取更多的时间去升级系统。监测数据显示，利用 Log4j 漏洞发起攻击的基础架构中，**约57%攻击源曾被 Akamai 记录在案，即已知攻击者和新攻击者，约各占一半比例。**

  

为全面剖析 Log4j 漏洞的起因、利用方式、演化方向，我们将于6月16日举行“零日漏洞攻防战：Log4j 安全实践”主题直播。届时，安全专家将结合实战案例，整体复盘分享 Akamai 是如何通过 Log4j 的应急响应和相关安全服务，积累和总结应对零日攻击经验和教训的全过程，以及未来将持续帮助客户缓解并根除 Log4j 后续演化的攻击威胁和其他类似零日攻击的应对策略。
