# 网安发展30年，来看看安全从业者的真实感受

很多时候，政策的变动会对行业的发展产生巨大影响。去年5月，美国总统拜登签署《关于加强国家网络安全的行政令》（以下简称“行政令”）。该行政令针对消除共享威胁信息的的阻碍、联邦政府网络安全现代化、提高软件供应链的安全性等方面提出了要求和指示。

 

在行政令的影响下，美国对联邦政府的网络安全、软件供应链安全和零信任架构的落地等方面都取得了非常明显的进步，其中的许多举措对我国来说也非常值得借鉴。

 

我国网络安全产业的发展也离不开国家政策的扶持和指引。自1991年瑞星建立，我国网络安全产业已经发展了30年。现如今，我国的网络安全市场总额已经达到101亿美元，年均增速达到了21%。日新月异的网络安全产业在发展的过程中受到了哪些政策的影响？安全从业者们对于整个产业的变化又有哪些感受？

  

![](../Images/3ddf0e648a8183be07355934bd6ec5b2.png)

  

  

**0****1****行政令的效果**

  

2020年年底，美国发生了包括SolarWinds 供应链攻击、微软 Exchange 漏洞攻击以及Colonial Pipeline输油管道勒索攻击等一连串备受瞩目的重大网络安全事件。这些事件让美国惊讶地发现，越来越多的公共和私营部门实体面临来自国家行为者和网络犯罪分子的持续且日益复杂的恶意网络攻击。这些事件充分暴露了美国网络安全防御能力的不足。 在此背景下，拜登签署了行政令。对消除共享威胁信息的障碍、提升联邦政府网络安全现代化进程、提高软件供应链的安全性、建立网络安全审查委员会、使美联邦政府《网络安全事件和漏洞响应手册》标准化、加强联邦政府对网络安全漏洞的检测能力以及提高联邦政府的调查和补救能力等方面提出了非常多要求和措施。 行政令一经推出便引发热议，大部分专家认为该行政令的范围很广，而且美国政府制定的时间表也很激进，下一步如何实施、贯彻以及执行将是绝对关键。如何改善政府与和行业的合作方式，如何确认是否有足够的财力和人力来执行任务以及如何制定新的立法都是很大的挑战。 如今，一年时间过去，许多专家转变了之前想法。Exiger关基高级副总裁鲍勃·科拉斯基(Bob Kolasky)表示：“联邦政府通过行政令关注零信任、合同改进以及软件供应链安全是一个很好的起点，虽然时间很短，但这让我们开始变得井然有序。”另一位来自网络威胁联盟 (CybeThreat Alliance) 的总裁迈克尔·丹尼尔 (Michael Daniel) 表示：“行政令为联邦正在进行的项目奠定了基础，是政府优先事项的指南针。” 回顾2021上半年美国政府的网络安全政策，可以得出以下特点。首先是拜登政府的网络安全政策无论是在出台速度与频率上，还是在具体内容上都被打上了安全事件驱动的烙印，行政令的签署正是因为在2020年年底美国遭受的一系列安全事件；其次是自上而下的“专业精英”治网模式回归，舍弃了特朗普政府的“对总统忠诚度”为标准的人事任命逻辑，采用“专业性”、“任职经验”为标准组建了有网络安全领域“专业精英”构成的治网团队，行政令设立了一个由政府和私营部门领导共同主持的网络安全审查委员会，该委员会负责审查和评估影响联邦信息系统或非联邦系统的重大网络事件、威胁活动、漏洞、修复活动和机构响应；第三是强化了“公私协作”模式，并且突出了联邦政府在网络安全事物方面的主导性作用，行政令强调了联邦信息系统的网络和日志信息是无价的，各机构及其IT服务提供商必须收集和维护此类数据。 总体而言，行政令是拜登政府致力于改善国家网络安全及保护联邦政府网络而制定的新路线和战略方向。在改善美国政府与私营部门在网络上的信息共享问题，实现国家网络防御现代化，促进零信任的落地和实施，审查和评估网络安全重大事件，增强美国对事件发生时的响应能力等方面寻求突破，力图提高其国家网络安全防御能力，这些重要举措对我国网络强国战略的政策制定和实施有着重要的借鉴意义。

**0****2****我国的网络安全政策与产业发展**

  

我国的网络安全产业始终伴随着国家政策的发展而发展。1994年我国正式介入国际互联网，当时的安全还是拘泥于计算机系统，在政策层面多数是对计算机和网络系统下定义。1994年国务院发布《中华人民共和国计算机信息系统安全保护条例》，首次建立信息安全管理框架，从安全保护制度、安全监督、法律责任等方面明确了计算机信息系统运行及服务保护措施。与此同时，瑞星、江民、金山、天融信、启明星辰、绿盟、深信服等安全厂商接连成立，江民KV100防病毒软件也取代了瑞星早期的防病毒卡（硬件），安全市场逐步兴起，C端市场占据主流。

  

21世纪后，受到全球信息化浪潮的影响，我国开始出台具有战略意义的信息安全政策文件。2003年《国家信息化领导小组关于加强信息安全保障工作的意见》提出了10个层面的信息安全部署，包括实行等保、加强信息安全技术研究、加快信息安全人才培养、加强信息安全法治建设和标准化建设等。在此期间，两化融合首次提出，2008年，国家工信部成立，其主要职责为拟订实施行业规划、产业政策和标准；指导推进信息化建设；协调维护国家信息安全等。

  

1990-2007年是我国网络安全C端市场的黄金发展阶段。在此期间，安全需求的主流是防范和查杀病毒，产品形态的主流是杀毒软件，商业模式的主流是传统软件收费方式。而B/G端市场还处于萌芽阶段，这一时期诞生的主要安全产品为传统防火墙（FW）、入侵检测/防御（IDS/IPS）等安全硬件。直到2008年，这一局面才开始改变。2008年，360的免费策略迫使整个C端市场的商业模式开始转型，政企端开始发展。

  

2010-2020年，我国发布信息安全相关政策近60份。在这10年中，大数据技术、移动互联网、物联网、云计算等新技术和新应用不断发展，在此期间，信息安全的内涵和外延更加丰富，囊括信息安全产业、信息安全标准、信息安全威胁、个人信息安全保护等诸多重点。为了有针对性地推进信息安全工作、健全我国信息安全保障体系，2011年网信办成立，2012年国务院发布《关于大力推进信息化发展和切实保障信息安全的若干意见》，在工控系统安全、信息资源和个信保护、云计算安全技术与标准等诸多领域提出兼具指导性和操作性的科学规划。

  

2013年，党的十八届三中全会提出要加大依法管理网络的力度，进一步做好国家网络和信息安全工作。随后，相关政策文件颁布数量逐渐增加，并在2014年达到高峰。“棱镜门”让我国意识到美国宣扬“互联网自由”背后所隐藏的网络间谍活动对国家安全构成的巨大隐患，于是在2014年我国成立了中央网络安全和信息化领导小组（现更名为中国共产党中央网络安全和信息化委员会），成为总揽安全战略的最高决策小组。2016年《网络安全法》正式通过，我国网络安全治理进入全新阶段。《网络安全法》与其他相关政策互为呼应，共同构成我国信息安全政策制度的综合框架。

  

在这十年里，安全市场迎来井喷发展，政企端开始迅速发展。层出不穷的网络攻击业内有识之士早已形成共识：网络攻击已经不分军用民用，不分战时平时，不分国家、企业、个人，每个节点都可能成为攻击跳板，随时可以发生造成黑天鹅事件，尤其是关键基础设施单位必须要重视网络安全防范工作。安全市场的合规驱动逐步转变成基础需求。

**0****3****政策红利下的网络安全产业**

  

纵观我国的信息安全产业发展进程，政策红利是其发展的主要动能。多年来持续不断的政策红利支持，让我国的网络安全产业迎来更加广阔的发展前景和契机。据CCIA数据显示，2015年我国网络安全市场规模是32亿美元，2021年是101亿美元，年平均增速约为21%。其中2020年受疫情影响，较2019年仅增长9%。据信通院数据，北美市场约占全球市场的46.8%，我国占6.1%；从网络安全支出占比看，美国网安预算占IT预算的比重为 20.4%，而我国仅为1.87%。根据工信部“网络安全支出在IT支出占比达10%”的要求与GARTNER对我国IT支出的预测，2024 年我国网络安全行业规模约3570亿元。

  

政策红利带来的是从顶层设计、集群效应、产业生态等全领域赋能整个信息安全产业。一是通过法律政策对信息安全产业的发展路径进行顶层设计。在中央网信办、工信部等信息安全主管部门的积极统筹规划下，我国信息安全产业的发展重点、路径选择和未来态势更为明确。我国紧紧围绕信息安全产业发展面临的主要问题如技术自主性较弱、信息安全产业的发展方向尚待明晰、产业发展需要政策支持等问题密集展开研讨，厘清了信息安全产业的行业特点、范畴和具体分类。在此基础上，通过颁布网络安全产业分级分类的指导性政策文件，为信息安全技术产业发展指引方向。

  

二是培育国家级产业园区，充分释放网络安全产业的集群发展效应。其中武汉、北京、天津等全国多个城市重视网络安全产业的集聚发展效应，协同打造“政产学研用”一体化网络安全产业发展生态。信息安全产业集群发展效应的释放，应聚合各方主体的合力，这包括信息安全产业的主体（信息安全企业）、网络基础设施的提供者（网络运营商）、信息安全产业的人才培育机构（如高校、科研机构等）、信息安全产业的支撑机构（如金融机构、律师事务所等专业机构）等，制定实施信息安全产业发展的一揽子优惠措施，聚焦信息安全产业技术发展的关键环节，集中攻克信息安全技术的核心短板，为产业的发展搭建协作平台。

  

政策的变化让网络安全从业者也分得一杯羹。2021年《网络安全人才发展报告》（下称报告）中指出，目前我国网络安全人才市场每年平均需求与供给之比约为2:1，专业人才累计缺口在140万以上，人才供给存在“青黄不接”的情况。

  

具体到岗位上，熟悉各种防御技术的安全研究岗位人才最为短缺，认为这一岗位人才短缺的人数占调查总人数的42.96%。其次是审计与评估、应急响应、安全态势分析、内容安全等技术岗位，均有超30%的从业者认为符合岗位职能的人才仍有所欠缺。有专家表示，现在越来越多的年轻从业者趋向于红队，渴望通过技术突破重重防御，对于防御技术缺少主观能动性，防御技术岗位的招聘往往需要3-6个月才能满足。

  

另一方面，从业者薪资也在稳步提升。2021年上半年，网络安全领域的平均招聘薪酬达到22387元/月，较去年同一时期提高了4.85%。从不同岗位的平均薪资比较来看，技术岗和产品岗由于其各方面岗位能力要求较高，相应的工资水平也显著高于其他岗位。其中，市场需求量最高的研发技术岗成为含金量最高的岗位，2021年上半年平均月薪24887元/月。

**0****4****安全从业者的亲身感受**

  

据调查显示，2021年中国IT安全服务市场厂商整体收入约为28.61亿美元(约合184.6亿元人民币)，厂商收入规模较上年同期实现快速增长，涨幅达到41.7%。

  

IDC中国网络安全市场分析师王一汀表示，2021年，在疫情好转、积压需求爆发等因素的影响下，中国网络安全服务市场实现了高速增长。战略规划、应急响应、重大活动保障、实训演练、运营服务、托管检测与响应成为服务市场的年度热词。

  

具有20多年信息安全工作经验的刘歆轶表示，越来越多的行业增添了安全岗位。据他回忆，2013年以前，很多网络安全从业者大多就职于外企，国内相应的岗位和企业并不充分。随着政策的不断调整，安全厂商、互联网和金融行业的安全岗位逐渐增多，安全从业者拥有了更多的选择空间。现如今，包括制造业在内的其他行业，在数字化转型的过程中也开始注重安全，组建安全团队和安全岗位。

  

另一位专家表示，随着政策的利好，网络安全人才培养环境也越来越优渥。部分大学开始针对网络安全专业进行建设和扩招，社会上也出现了很多网络安全技能和意识的培训机构，民众对于网络安全也有了更深层次的认知。另一方面，越来越多的企业增添了网络安全职位，不仅预算投入不断增加，对安全从业者的薪资待遇也逐渐提高。

  

最后，拥有10年安全经验的于利新认为，目前，是所有从业者在安全行业大展拳脚的最佳时机，无论安全服务商还是甲方企业都拥有非常多的岗位和良好的待遇，尤其是合规安全方向，更是现在的重中之重。

**0****4****结语**

  

我们正处在一个前所未有的数字时代，它是继农业和工业文明之后的一种文明新形态。随着我国《“十四五”数字经济发展规划》的出台，网络安全产业也必将顺应数字经济时代需求，紧扣数字经济特征优势，从要素、产业、融合、治理等方面系统布局。“没有网络安全就没有国家安全，没有信息化就没有现代化”，这显示出国家在保障网络安全、维护国家利益、推动信息化发展方面的决心，也反映了网络安全产业的相关政策还回持续不断地更新与完善。
