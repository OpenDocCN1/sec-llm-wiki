# 2021超级CSO年度评选颁奖盛典，再再延期：？

原定2022.3.26举办的2021超级CSO年度评选颁奖盛典，疫情骤紧，为妥善计，曾延期至2022.4.23。随着疫情波折，管控日紧，我们不得不再次延期，至2022.5.28。可现在看来，我们之前的预期还是过于乐观了，疫情尚在，管控继续，我们的活动，不得不再次、再次，延期。

  

这次延至何时？不知道，不敢说，**希望是6月，也许在7月**，总之，先留个非预设不刻意的悬念吧，保留希望，一切只能走着看。

  

还得再次诚恳地向大家说声抱歉，毕竟，一而再再而三。但，还是那句话，千变万变一样不变，初心不改，如约有情。

  

就当真的是，好事多磨吧。

  

无论如何，我们都**期待，相聚那天**！

  

  

2021超级CSO年度评选活动，是由**安在新媒体**策划发起并组织举办，得到包括**中国网络安全审查技术与认证中心（CCRC）、大数据协同安全技术国家工程实验室、中国管理科学学会应急与安全管理专委会、国家信息中心《信息安全研究》杂志社**等在内多家机构的大力支持。

  

本届评选，旨在站位用户立场，凭借 CSO/CISO视角，聚焦企业人员意识、团队能力、项目建设、技术创新、安全运营、生态合作等方面，做年度盘点，树标杆典范，同时传播CSO理念，培育CSO文化，逐渐引导业界形成重视用户、场景针对、供需协同、效果为重的网络安全发展观。

  

借此，希望能够助推并见证中国CSO/CISO群体的崛起和发展。

独乐乐不如众乐乐，众乐乐更需礼多多！贯穿本次颁奖盛典全程，我们共策划推出六重豪礼：

  

■ 媒体通告留言有奖：针对此前活动预告发文，留言获赞最多者，可**获价值1000元的数码潮品**，截至目前，此奖项已因一而再再而三活动延期而“重复”兑现三次（具体获奖参见后文）。

  

■ 邀请函晒朋友圈抽奖：本活动需定向邀约，凭有个人姓名的电子邀请函参会，因延期而需更新邀请函，稍后再发。凡收到更新后邀请函者，可在朋友圈再做分享，凭截图受邀加入活动群并参与群内抽奖，奖品为**价值2000元的数码潮品**。本奖项继续有效，截止时间待定（此前曾抽过一次，这次为第二次）。

  

■ 参会礼包盲盒有奖：凡受邀参会者，活动当日，皆获赠礼一份，包含专为本次活动定制的**盲盒**，神秘大奖尽在其中。

  

■ 颁奖盛典现场抽奖：颁奖盛典活动当日，现场多轮抽奖，除各类数码潮品，更有**最新款iphone13手机一部**。

  

■ 颁奖盛典晚宴抽奖：颁奖盛典活动当日，晚宴期间（诸子云社群年度评优颁奖）也有**多轮抽奖**。

  

■ 拆盲盒晒朋友圈抽大奖：颁奖盛典活动期间及稍后，参会者可在朋友圈分享拆盲盒照片+活动海报，凭截图可参与抽大奖活动，该项大奖为**最新款iphone13手机一部**。截止时间待定。
