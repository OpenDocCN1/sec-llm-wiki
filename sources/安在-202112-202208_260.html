“领航计划—未来数据安全人才专场培训”推介会顺利召开

2022年4月13日下午，由工业和信息化部人才交流中心、全国工商联大数据运维（网络安全）委员会主办，大数据协同安全技术国家工程研究中心、贵州大数据安全工程研究中心承办，中关村网络安全与信息化产业联盟、《信息安全研究》杂志社协办的“领航计划—未来数据安全人才专场培训”第一期公开推介会顺利举行。


为落实国家层面法律法规的相关要求，服务国家数据安全治理体系的构建，提高人员数据安全意识，促进数字经济的健康持续发展，培养数据安全专业人才，大数据协同安全技术国家工程研究中心和贵州大数据安全工程研究中心推出了注册数据安全官（Certified Data Security Officer，CDSO）、注册数据安全工程师（Certified Data Security Engineer，CDSE）和 DSMM 测评师人才培训。

本次推介会邀请了国家信息技术安全研究中心总师组专家李京春、大数据协同安全技术国家工程研究中心副主任钟力博士对数据安全人才培养进行介绍。

李京春总工从数字化转型是历史发展的创新产物、云大物网新技术带来诸多风险挑战、数智时代亟待培育高端数据安全官三个主题进行分享。数智时代，物理世界与现实世界完全映射，数据安全官等高端人才需要系统性、体系化地进行培养，针对数据安全，也需要从内防（事前保护）、协防（事中监控）、攻防（以攻促防）、外防（事后处置）等方面进行全面防护。


数字经济时代下数据流通共享和开发利用成为数据的新特征，新应用场景下数据安全保障问题突出，为数据安全引入了复杂性。数据安全的复杂新形势也对当今的数据安全人才提出了更多要求，基于此，钟力博士分享了新时代下的数据安全专业人才能力要求，以及大数据协同安全技术国家工程研究中心在注册数据安全官、注册数据安全工程师、DSMM测评师三类人才培训方面的课程设计，并发布将于4月21日启动新的一期培训。




据悉，注册数据安全官系列培训证书（含注册数据安全官（CDSO）、注册数据安全工程师（CDSE）、DSMM测评师）现已纳入国家工业和信息化部人才序列，实现“一考双证”。日后，通过大数据协同安全技术国家工程研究中心或贵州大数据安全工程研究中心培训及考核的学员，可同时获得两个证书，并且能够在工信部工业和信息化人才评价系统（https://pj.miitec.cn/）、大数据协同安全技术国家工程研究中心官方网站（http://www.nelab-bdst.org.cn/）以及全国DSMM公共服务平台（https://www.dsmm.org.cn/）同步查询证书信息。

本次推介会共吸引了近百人线上参加，下期数据安全人才培训推介会将于4月19日召开，敬请后续关注。
