**融资**  
  
  

  

1、「众智维」完成数千万元Pre-A轮融资

  

南京众智维信息科技有限公司近期完成数千万元Pre-A轮融资，由容亿投资领投，淳创投资跟投。

  

  

2. 「中安网星」完成战略融资，投资方为「微步在线」

  

身份威胁安全方案提供商「中安网星」已于日前完成战略融资。本轮投资方为微步在线。航行资本担任本轮融资财务顾问。

  

  

3. 「安信服科技」获千万元天使轮投资

  

私有云数据安全公司安信服科技获得著名投资公司创东方的千万元天使轮融资。据悉，本轮融资将主要用于市场推广、产品研发、团队建设等。

  

  

4. 「永安在线」获金沙江创投数千万元独家投资

  

安全企业「永安在线」已于日前完成新一轮融资。本轮融资金沙江创投独家投资，金额在数千万元级别。指数资本担任独家财务顾问。

  

  

  
  
  
  
  
  
  
  
  
  
  
  
  
  
  
  
**报告**  
  
  

  

[1. 《深度合成十大趋势报告》发布](https://mp.weixin.qq.com/s?__biz=MzIyNjUxOTQ0MQ==&mid=2247523570&idx=1&sn=fb11eca02d0330d46410c499c2a726e0&scene=21#wechat_redirect)

  

为了对人工智能和深度合成技术的健康发展提供参考和指引，清华大学人工智能研究院、北京瑞莱智慧科技有限公司、清华大学智媒研究中心、国家工业信息安全发展研究中心、北京市大数据中心近日联合发布《深度合成十大趋势报告（2022）》（以下简称《报告》）。《报告》从技术研究、领域应用、发展趋势等多个方面，全面深入地介绍和研判深度合成技术及应用带来的机遇与挑战，并就其发展与治理给出切实可行的建议和措施。

俄罗斯政府当地时间2022年2月24日警告其国内关键基础设施运营商“计算机攻击强度增加的威胁”，并表示应考虑任何没有“可靠确定”原因的关键基础设施运行故障“计算机攻击的后果。”美国全国广播公司新闻频道25日最新报道称，总统乔·拜登已收到一份可供美国实施大规模网络攻击的选项，这些攻击旨在破坏俄罗斯维持其在乌克兰的军事行动的能力。

  

  

  

[2. 乌克兰政府和银行网站又遭大规模网络攻击被迫关闭](https://mp.weixin.qq.com/s?__biz=MzkyMzAwMDEyNg==&mid=2247524902&idx=5&sn=cea09e082b481085bd37912c97ab3198&scene=21#wechat_redirect)

[ ](https://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247501164&idx=2&sn=ba1d5d8c9271f223b5951d935ce6d3c1&scene=21#wechat_redirect)

2022年2月23日，乌克兰境内多个政府机构(包括外交部、国防部、内政部、安全局及内阁等)以及两家大型银行的网站再次沦为DDoS攻击的受害者。报道指出乌克兰政府单位和银行遭到了大规模网络攻击，网站陷入瘫痪被迫关闭。这是乌克兰本月第二次、今年第三次遭受大型网络袭击。 

  

  

[](https://mp.weixin.qq.com/s?__biz=Mzg2NjY1NzM3NQ==&mid=2247483873&idx=1&sn=5fc684e2a1da4efda1ed206acc9c3a21&scene=21#wechat_redirect)

[3\. NCSC、CISA、NSA和FBI联合警告：疑是俄Sandworm黑客组织携超强恶意软件Cyclops Blink卷土重来](https://mp.weixin.qq.com/s?__biz=MzkyMzAwMDEyNg==&mid=2247524864&idx=3&sn=7b1babda375c5dab4db050c608491c23&scene=21#wechat_redirect)

  

当地时间2022年2月23日，美国和英国网络安全和执法机构发出联合警报，一个与俄罗斯情报机构相关的长期黑客组织开发了一套新工具来替换 2018 年已被披露的恶意软件。这份由英国国家网络安全中心(NCSC)、美国网络安全和基础设施安全局(CISA)、国家安全局 (NSA) 和联邦调查局 (FBI) 发布的警报详细介绍了新的恶意软件Cyclops Blink，并将其归因于Sandworm是他们之前与俄罗斯GRU相关联的攻击性黑客行动。

  

  

[](https://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247501440&idx=3&sn=731ea193e43ae762773a51b6ee6805f9&scene=21#wechat_redirect)

[4. 俄乌冲突加剧，网络安全股价大涨，最高涨幅超110%](https://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247501589&idx=1&sn=720583969e1b49b109438797a672fb7c&scene=21#wechat_redirect)

  

俄乌冲突加剧，关基网络安全备受关注，使得国际网络安全公司股价大涨，龙头厂商涨幅普遍超10%，创下近期新高；财富管理公司Wedbush Securities的分析师认为，对网络攻击的担忧可能将整个网络安全行业股价拉高200至300个基点。 

  

  

  

[5\. “火线支援”：欧盟部署网络快速响应团队支持乌克兰](https://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247501547&idx=3&sn=7dab841ac848ab877442c9910804c789&scene=21#wechat_redirect)

  

应乌克兰政府要求，欧盟计划部署一支网络快速响应团队，以帮助乌克兰抵御来自俄罗斯的网络攻击。该团队隶属于欧盟的国防合作项目“永久结构性合作”（PESCO），该项目旨在为欧盟机构和“合作伙伴”提供网络防御能力。

  

  

[](https://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247501356&idx=1&sn=fd3643b857a86b581519b457f66ae3ef&scene=21#wechat_redirect)

[6\. 勒索凶猛！国际货运巨头紧急关闭全球业务系统](https://mp.weixin.qq.com/s?__biz=MzI4NDY2MDMwMw==&mid=2247501533&idx=1&sn=0888d4e636c11bddd447c60d8c452d22&scene=21#wechat_redirect)

  

年营收百亿美元的国际货运巨头Expeditors International遭遇疑似勒索软件攻击，被迫紧急关闭全球主要业务系统；该事件对公司影响巨大，Expeditors的货运、海关与配送等业务运营活动受到限制，很可能导致客户的货物停滞不前；Expeditors表示，这是一次“可能对公司业务、收入、运营能力和商业声誉造成严重负面影响”的“重大事件”。
