# 译文 | 华为美国分区CSO 的安全警告

华为美国首席安全官Andy Purdy警告说，在当下这个任何主要民族国家或恶意行为者都可以随意攻击任何人的时代里、世界里，供应链透明度至关重要。

  

Purdy认为，最近对Microsoft Exchange Server 和SolarWinds 的攻击表明了“所谓的可信供应商其实是不可信的”。他说，那些能力较为突出的国家，比如美国、中国、以色列或其他的一些国家等，他们是有能力入侵任何人的。

  

而为了解决这个问题，华为则建立了全球网络安全和隐私保障并企业范围的风险管理和内部一致性计划等。Andy Purdy表明，这就是他们想向所有组织推荐的内容。

  

此外，Purdy 强调了可见性和透明度的重要性。

  

“我们非常开放并努力做到透明，我们相信华为是世界上最透明的公司之一，”他如此坚信：“这本就是我们一致认为比较重要的内容。”

  

  

**华为的透明度挑战**

  

然而，华为对透明度的强调与美国及其盟友提出的指控形成鲜明对比，美国方认为，“这家电信巨头”正应中国政府的要求在其设备中安装了后门，而华为坚决否认了这些指控。

  

为了安抚客户，华为将其设备置于大众视野之下， 在全球开设了 七个透明度中心，最近一次则是在去年6月于中国东莞地区开设。珀迪说，这些中心允许客户、合作伙伴、政府和专家测试华为的产品，看看他们是否真的找到了什么“后门”问题。

  

“如果有哪些事情是需要我们做的，或者是我们应该做的，那就让我们沟通一下，你可以发表各种意见。”Purdy说：“为了打造出更安全的网络空间，沟通是合作环节里非常重要的内容。”

由于对华为有相关法律法规的限制，所以他人不能将任何产品带入美国的透明度中心进行测试。同时，Purdy 要求华为的竞争对手以及所有主要供应商和运营商更加透明。“美国也应该有透明度中心，为了全世界所有人并所有网络的安全，我们彼此都应该具备。”

  

  

**呼吁平等审查、信息共享**

  

Purdy 还呼吁对每个供应商的关键组件和产品进行同等审查，他警告说：“人们对5G和对5g相关技术的依赖性越来越大，从趋势来看，同时可以把这理解为人类生存生活和关键基础设施的功能将会越来越多的面临安全问题，因此，是时候放下各种倾轧和谩骂了，是时候共同努力提高标准了。”

  

Purdy表示有太多太多的焦点在于“怎么阻止华为”、“怎么阻止中国”，而其实大家都更应该注重安全问题。

  

Purdy的表态并非空穴来风，现实是，即使华为一再否认其网络设备和软件有为中国间谍提供监控流量的后门，许多西方政府还是颁布了在境内禁止使用华为设备的法律，并且他们对其他限制华为的机制依旧持坚定的态度。

  

当被问及彭博社报道的“最近指控中国黑客在澳大利亚使用华为的设备进行恶意活动时”，Purdy说他并不熟悉这一指控。 

  

“虽然我本人不怎么了解，但对于世界各国政府或私人专家来说，关注和分享有关各种重大网络攻击的信息还是至关重要的。”他补充道。

  

在最近的一份声明中，华为驳斥了该报告，并声称其设备“没有恶意软件”。
