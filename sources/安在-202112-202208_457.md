# 译文 | 英特尔之下一代加密技术

数据分析并营销供应商 AppsFlyer 本月早些时候宣布与Intel建立长期合作关系，希望加快同态加密的商业可行性。

  

对整个信息领域而言，完全同态加密 (FHE)被誉为机密计算的“圣杯”。与在服务器上的安全区域内解密和处理敏感数据的传统机密计算环境相比，同态加密具有多种优势，尤其是在涉及隐私的情况下。

  

也许技术领域里最大的效用是无需先解密即可处理数据的能力，但同态加密还处于起步阶段。根据Intel实验室工程师 Rosario Cammarota 的说法，早期实施在性能方面有很多问题，即使是简单的指令也一样。

  

**数据经济的未来**

  

对于像 AppsFlyer 这样的公司来说，同态加密是在线营销的未来。

  

该公司专注于移动营销分析，并同时会向市场提供一系列的工具，旨在帮助客户、合作伙伴等以用户获取的数据为依据做出更明智的决策。

  

AppsFlyer 营销操作系统团队总经理 Edik Mitelman 说：“移动营销可被视为一个巨大的市场，合作伙伴和客户可以在其中共享数据并同时能洞察到更好的机遇，其目的是为了开展更好的活动。”“自从互联网诞生以来，整个生态系统都是建立在了用户级数据的基础上。我们将我们的用户数据提供给公司，并期望用户能获得舒适的体验。”

  

在过去几年中，隐私问题迫使企业不得不重新思考该如何收集、存储和商业化用户数据。因此，Intel和他的合作伙伴准备在收集可用数据和保护用户隐私之间找到线索，他们准备将用户级数据输入到隐私云中，在那里去除标识符、分析和聚合，因为只有这样，结果才会与相关方共享。

  

这种方法极大地改善了用户隐私，因为它限制了为得出这些分析结果而易手的数据量。

  

  

**隐私的新领域**

  

实施同态加密是确保用户数据保密的下一步。然而，实现跳跃并不容易，尤其是在公司规模上，同态加密还没有为营销生态系统的数据规模做好准备。比如AppsFlyer 每天处理超过 1200 亿个事件，尝试加密这种规模的数据一般都会失败。而这恰巧是AppsFlyer与Intel合作的切入点，同态加密是Intel正在开发的几种安全技术之一，虽然其仍处于概念验证阶段，但同态加密有望实现端到端的数据隐私。

  

“以前从未有人为我们规模的数据创建零信任环境，”Mitelman 说。“当它准备好时，它将把隐私保护技术带到下一个前沿。”

  

  

**DARPA 利用Intel进行同态加速**

  

与 AppsFlyer 的合作远非Intel在该领域的首创。今年早些时候，美国国防高级研究计划局 (DARPA)就已经委托他们开发用于完全同态加密应用的加速器了。

  

其中的芯片最终将在 Microsoft Azure 中进行测试和部署，以保护政府工作负载，最终目标是启用敏感的政府数据，无需在任何时候对其进行解密即可存储、传输和处理这些数据。

  

然而，这样做需要绕过性能瓶颈，Intel计划使用目前正在开发的定制Asic来解决这个问题。

  

他们声称：“当完全实现时，加速器可以在执行 FHE 工作负载方面提供比现有 CPU 驱动系统的巨大改进，有可能将处理密码的时间减少五个数量级。”
