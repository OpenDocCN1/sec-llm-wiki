# 什么是元宇宙 #


赛博文化是人们对现实与可触及的未来的隐喻，是后现代思潮兴起以来的新未来主义运动（Neo-Futurism）的重要组成因素之一，因此，服务器存储、能耗、算法、编程建模、数据宽带传输等可以算是在发展的道路上，至少方向是确定的，就好像“VR的不协调问题”至今都没解决、单眼4k的vr眼镜还没造出半导体技术就已经到瓶颈了，难道有这些小牵绊在眼前，对整个时代发展的期望就该降低吗？不，我们应该见仁见智！


会说到赛博文化，是因为《雪崩》是赛博朋克的经典作品，而元宇宙一词就诞生于这部著作。元宇宙从本质上讲是对现实世界的虚拟化、数字化过程，需要对内容生产、经济系统、用户体验以及实体世界内容等进行大量改造。它整合了多种新技术而产生的新型虚实相融的互联网应用和社会形态，它基于扩展现实技术提供沉浸式体验，基于数字孪生技术生成现实世界的镜像，基于区块链技术搭建经济体系，将虚拟世界与现实世界在经济系统、社交系统、身份系统上密切融合，并且允许每个用户进行内容生产和世界编辑。


同时，它包含三个特征：第一是现实世界用户与虚拟世界、虚拟设备、虚拟用户在同一空间内产生互动关系。第二是该世界中的互动过程可以得到完整保存，也可以完整再现。第三是虚拟世界中设备、产品和服务具有明确价值，可以永久保存。


简而言之，就是元宇宙将现实生活与虚拟世界紧密联系在了一起。




# 元宇宙的到来会带来哪些威胁 #


在信息技术领域，融合人类社会、信息世界、物理世界是国内乃至全世界都想完成的命题，以人、机、物三元融合为主要特征的技术革命和产业变革就是信息技术领域中最为重要的前景。而元宇宙则体现了对人、机、物融合这一革命性信息技术的探索。


因此，如果元宇宙真的到来，我们将面临哪些安全上的挑战？


首当其冲的，是人机物三元世界的融合大大增加了身份管理与信任管理的复杂性和管理难度，所以它对身份管理与信任体系提出了严峻的挑战；再比如雾计算（海云计算）模式的动态、异构、海量特性又对身份，行为、环境、数据的有效隐私保护提出了挑战；还有海计算网络终端数量庞大、终端类型多样，其网络结构动态自适应，在数据规模和复杂性方面，对现有的安全态势监测体系又是重大挑战。


随着数字化技术的发展，人类已经进入到了数字文明时代，我们面临的信息安全挑战已经从最初的计算机安全、网络安全，演进为数字化安全。而随着软件重新定义世界，在数字化安全时代，数字化威胁与现实世界交织融合，网络攻击将会对现实世界造成直接的伤害。比如近年发现的Stuxnet（震网）、Duqu、Flame等病毒，标志着过去所谓的“计算机病毒”已经跨越信息网络的界限，进入到物理世界并具有实质性破坏的能力，对电力、交通、金融、乃至国防安全等国家重要基础设施形成威胁。如果这些病毒、危害对任何核武器国家的网络安全进行攻击，它可以轻易的使该国领导人相信他们正在遭受核武器攻击，这便很可能导致他们错误地发动核战争！如此看来，在真正的元宇宙时代里，网络威胁将超越传统安全威胁，成为数字文明主要的威胁之一。其安全风险将遍布数字时代的所有场景，直接影响国家安全、国防安全、经济安全、社会安全乃至人身安全。




# 主要复杂问题和一些场景下的安全挑战 #


“元宇宙可能带来的安全危害”还涉及到了几个复杂安全问题，它们是指应用安全、供应链安全、云安全、大数据安全、网络通信安全、物联网安全、新终端安全等。就拿物联网安全举例，由于物联网大部分所使用的终端属于弱终端，很容易被非法入侵，甚至破坏，这就意味着在元宇宙这大环境下，使用者在使用过程中隐私信息很有可能被攻击者获取，例如，攻击者通过获得使用者的身份信息、兴趣爱好，甚至是商业机密等信息，将给使用者带来安全隐患。


而各大场景下的安全挑战则分别是关键基础设施、工业互联网、车联网、能源互联网、数字金融、智慧医疗、数字政府、智慧城市等。如车联网，不安全的云端接口、未经授权的访问、系统存在的后门、不安全的车载通讯、车载网络未做安全隔离等都可能成为巨大的风险。不法分子通过这些漏洞风险可以入侵服务器篡改数据内容、破坏硬盘数据，在车主未操作汽车的情况下使汽车开车门、上电、点火，或通过暴露的调试端口，造成车载娱乐系统固件被攻击提取等。大家可以试想一下，如果黑客成功攻击了车企云端网络，那么将会有怎样的后果？每一位车主的人身安全又该如何保障？而这在元宇宙所到来的时代里很可能将不足为奇。


360创始人周鸿祎提出，要想迎接元宇宙，第一步要做的事就是要构建好安全的基础设施。因为在元宇宙中，人类面临的网络威胁相比现在一个都不会少，反而会更加变本加厉，并极大地促进新型网络犯罪的发生。从这个角度来看，所有的安全挑战到了元宇宙时代都将上升到一个新的维度，威胁更广、伤害更大；这也从另一个侧面说明，数字化技术的发展和安全威胁永远是呈正比的。


因此，可以从他的话语中得到这样的结论：面对网络安全问题的快速变化，传统安全应对能力的发展过于缓慢，像目前主流的“防御”型产品都是基于已知攻击的，根本无法应对当前复杂的网络安全环境，以及未来元宇宙发展带来的更加复杂、更加专业的网络安全问题。所以，网络产品、互联网形态、数字经济生态不断发展的同时，信息安全技术也得未雨绸缪、防患于未然，这是所有信息安全行业都该重视起来的问题。



# 它虽是宇宙，但也该在文明之下 #


另外，目前人们心中期待的元宇宙是个去中心化的元宇宙，用户可以在上面自产内容，现在有传言随便什么东西挂个NFT都能卖出天价。也就是说按现在这个预期发展下去，不但元宇宙里完全无法监管，甚至很多内容无法屏蔽、无法更改，而且虚拟资产也会具备挑战现实资产的能力。更不要说元宇宙的虚拟资产购买力本就来自于虚拟货币，一旦涉及的人群超过一定的范围，虚拟货币甚至可以挑战法币的地位！


随着这概念拓展出去，意味着在元宇宙中个人可以通过技术来完成某种意义上的虚拟空间不平等。比如个人将全部数据赋权给元宇宙所属公司，数据所派生的权利重塑；比如黑客及黑客组织将成为某种意义上最具有权力的群体；比如现有的法律、道德、权力结构、组织形态、意识形态都将在元宇宙中失去意义。


“元宇宙之父”钱学森钱老曾说：“智慧的社会表现是人的思想品德。”


若在元宇宙或说虚拟世界里再也体现不出我国的文化底蕴、道德涵养和人文精神，那“参与元宇宙的意义”又在哪儿呢？人类技术的发展方向应该是解决核聚变问题，去实现能源自由，解决宇宙航行的问题，甚至走出地球！而不是利用Facebook式的元宇宙在虚拟的世界里进行文明内卷、进行资本诈骗！理想形态的元宇宙是能够帮助人类更全面的认识这个世界、反映这个世界，一如科学的目的本就是对世界能有更好的认知，并因此去改造它、去升华它。




# 当下，我们该怎么面对元宇宙 #


当前的互联网产业在内容载体、传播方式、交互方式、参与感和互动性上长期缺乏突破，正陷入内卷化的平台形态，因此，整个市场正是技术渴望新产品、资本寻找新出口、用户期待新体验的时候。如今，元宇宙正好带来了新的想象空间，因此不论是一众互联网巨头还是新兴创业公司都瞄准了这前所未有的新赛道。而抛开这所有契机不谈，元宇宙的出现是不是又一次表明了美国企业在设置全球议程？在掌控全球话语权？而我们除了跟随讨论或被动反驳或穷于应付或被割韭菜外，还能有怎样的“表现”？中国那么多年收入远超千亿元的企业，怎么做才能像他们一样掌控全球话语权？我们也可以制定自己的游戏规则，甚至像他们一样去国际上指定各种“战场”。这、才是我们当下最该拥有的觉悟！


资本逐利、百花齐放的时代，警惕元宇宙的骗局不失为一声警钟，而这并不是否认元宇宙，是通过历史经验所不得不具备的一种认知。就好像作为前车之鉴的区块链，明明是尚好的技术，最后却让“币圈”给糟蹋了，这著名的“割韭菜”事件是不是该让我们都打起精神？美国人“造概念”、中国人“炒概念”都成了家喻户晓的诟病了，国内资本几乎无孔不入，包装炒作一些新技术、改头换面一些新概念，最后都设局套现了谁？还不是一叶障目的老百姓？！如今元宇宙被热炒，这套路大家是不是又很眼熟呢？所以得再说重复一遍：我们要见仁见智！
