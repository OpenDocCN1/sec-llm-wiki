# 滴滴退市，数据安全的反思和感悟

12月3日，滴滴出行官方微博发布消息称：经认真研究，公司即日起启动在纽交所退市的工作，并启动在香港上市的准备工作。滴滴在纽交所上市至今，仅5个月的时间。

  

![](../Images/fcc8da7e2ad47a70a31c1791c298a4bc.png)

  

6月30日，滴滴正式在纽交所挂牌上市，股票代码为 “DIDI”。本次IPO中，滴滴发行价定为14美元，位于13-14美元/ ADS的发行区间上限。滴滴发行3.17亿股ADS，比原计划的2.88亿股多10%。上市首日，滴滴市值一路飙升至800亿美元。但在第四日，滴滴就跌破发行价，随后开始了5个月的震荡下跌。截至12月3日，滴滴最新股价为7.8美元/股，最新市值约376亿美元。按照滴滴最高价18.01美元/股来算，滴滴股价下跌56.69％，总市值蒸发492亿美元。从上市到宣布退市，滴滴一共在纽交所交易了109个交易日，股价和总市值双双腰斩。

  

01

**静默上市，滴滴到底做了什么？**

  

2012年，滴滴母公司小桔科技，在北京海淀成立。同年，随着支付宝VIE事件的爆发，中美经济战进入深水区，美国对中国上市公司的信任度降到冰点，中美证监部门就上市公司审计底稿等监管协同问题产生分歧。

  

2017年，滴滴发生多起安全事件，舆论对滴滴的讨伐空前激烈，借此机会，滴滴上线了过去阻力极大的桔视。桔视行车记录仪，不仅行车过程全程录音录像，而且所有司机被强制安装，否则将失去出车资格。

  

2020年10月，桔视上线3周年，滴滴地图事业部总经理柴华，在中国测绘学会年会上公布了一组数据：滴滴地图基础数据准确率已经超过95%，而且每天新增轨迹数据超108TB。这些轨迹数据和场景，具备海量、连续、高质量等特点。此外，5.5亿用户，每天还会上报数十万量级的路况事件。1000多万滴滴车辆，每天通过桔视，成为滴滴的街景实时测绘车。

  

7月1日凌晨，滴滴在纽交所上市；7月2日，网络安全审查办公室对“滴滴出行”启动网络安全审查，为配合网络安全审查工作，防范风险扩大，审查期间“滴滴出行”停止新用户注册；7月4日，国家网信办通知各应用商店下架“滴滴出行”APP；7月9日，“滴滴企业版”等25款App被下架；7月16日，国家网信办、公安部、国家安全部等七部门进驻滴滴出行，开展网络安全审查；9月8日，天津六部门联合约谈滴滴出行等8家网约车平台。

  

![](../Images/0ad0e30dc71843a6f8a217baa41e1bf9.png)

  

可以看到，自滴滴赴美上市以来，我国采取了一系列关于滴滴的审查措施，并对其APP进行下架处理。赴美上市的科技公司有很多，为什么只有滴滴被格外重视，原因就在于滴滴公司所收集的数据与中美证监部门所争议的审计底稿。

  

审计底稿，是一家公司的纸质表达形式，涵盖着一个企业的所有商业机密，特别是与国家有密切联系的企业，其重要程度不亚于国家机密。2012年6月20日，路透社报道，美国证监会SEC正式要求四大会计师事务所，必须向其提交在美国上市的中国公司审计底稿。为此，中国证监会CRSC态度十分强硬。“宁愿付出中概股连续2年不赴美上市的代价，也绝不允许SEC拿走一份审计底稿。”

  

![](../Images/dd1af8b723ec22010d755eaeeb3aaa45.png)

  

7月1日凌晨，滴滴在美国纳斯达克静默上市，官网没有任何公告，没有敲钟的照片，员工没有发任何朋友圈，一个市值4000亿的巨无霸，上市竟然如此悄无声息。虽然不能100%确定滴滴给了SEC审计底稿。但从结果倒推，滴滴近乎诡异的上市以及网信办及近严厉的措辞，都无限放大了这个可能。

  

  

02

**数据地位日渐提高**

  

滴滴事件的发生引发了我国对于数据安全的探讨，过去，《中华人民共和国网络安全法》认为，保护重要数据只需要关注和保障关键信息基础设施，但随着传统经济向数字化转型，无论是政务数据还是企业流动的商业秘密数据，数据体量的增加导致其无论是泄露还是非法利用所引发的危害不仅是简简单单的数据个体问题，而是会影响到整个社会以及国家安全问题。

  

9月1日《中华人民共和国数据安全法》的出台，让我们看到了国家对于数据安全的态度。首先，数据的定位是基础性战略资源，目前，我国基础性战略资源只有两个，一个是全民的档案，另外一个就是数据。第二，数据是国家层面的战略目标。第三，数据与土地、人、资源、技术并列为生产要素。数安法中明确指出，数据不再是过去网安法规定的电子数据，而是任何以电子或者其他方式对信息的记录。因此，对于国家而言，数据安全不仅是网络空间安全的重要组成部分，它更是总体安全观里的有机组成。对于企业而言，数据安全已然成为企业发展的重中之重。

  

对此，有人会问，国家对于数据安全如此重视，为什么还有企业选择赴美上市？这就关系到滴滴身后资本的选择。自2012年成立以来，滴滴共融资23次，燃烧1500亿，运营亏损还在持续扩大，这意味着在监管和上市严格的A股和港股下，持续亏损的滴滴几乎不可能获得上市的通行证。因此，在资本看来，纳斯达克成为了最后上岸的选择。可选择赴美上市，就要考虑数据跨境的问题。

  

![](../Images/a179c456faf4a62a8b686732cfc4cf02.png)

  

数据跨境通常是指将在中华人民共和国境内收集和产生的电子形式的个人信息和重要数据，提供给境外机构、组织、个人。这里的“提供”不仅指网络运营者直接把数据传输至境外的行为，还包括网络运营者通过开展业务、提供服务、产品等方式使用户通过使用其提供的产品或服务的功能，向境外机构、组织或个人提供数据的行为。

  

我国今年推出的一系列法律法规就数据跨境方面进行了解释。《数据安全法》第三十一条规定：关键信息基础设施的运营者在中华人民共和国境内运营中收集和产生的重要数据的出境安全管理，适用《中华人民共和国网络安全法》的规定；其他数据处理者在中华人民共和国境内运营中收集和产生的重要数据的出境安全管理办法，由国家网信部门会同国务院有关部门制定。10月29日，《数据出境安全评估办法（征求意见稿）》向社会公开征求意见，其中规定了处理个人信息达到一百万人的个人信息处理者向境外提供个人信息，需通过所在地省级网信部门向国家网信部门申报数据出境安全评估。11月25日，上海市发布了《上海市数据条例》，其中第六十九条规定：在临港新片区内探索制定低风险跨境流动数据目录，促进数据跨境安全、自由流动。越来越多的法律法规相继出台体现出我国对于数据跨境流动的重视，不仅细化了数据跨境法规政策和制度标准，同时也加强数据安全监管和网络安全审查并逐步完善数据安全认证体系和风险评估机制。因此，数据能否进行跨境传输的核心不在于网络运营者是否属于关键信息基础设施的运营者，而在于数据本身是否属于“个人信息”或“重要数据”。也就是说，只要企业属于网络的所有者、管理者或网络服务提供者，对于数据出境就应当格外关注。

  

  

03

**数据安全，也是国家安全**

  

国家安全是一种状态，是持续保障安全的状态，因此，对于数据安全问题，国家一定会不断调整、巩固、完善，但这并不是运动型监管，而是既规范平台行为，也充分考虑平台经济的特点，建立一个包括司法、监管和自律等多维度、综合性的治理体系。

  

回归滴滴事件本身，当下是我国推动数字经济发展的关键时期，数据安全的重要性怎么强调都不过分，可以看出，网络安全这套治理体系既急需，又深谋远虑，是从构筑国家竞争新优势的战略高度出发，明确规则，压实责任。既能消除网络安全隐患，也能规范企业，帮助企业找到盲点弱点，更是守住了国家数据安全。

  

![](../Images/97ad9a06dd01da78c4db913a00d00e1a.png)

  

截止目前，通过下架整改来规范是恰到好处的震慑和处罚，没有打压企业，考虑到国际环境的变化，退市也在很多人的预料之中。数据安全的保护，是当下国际互联网治理的重要方向，在这一点上，中国在大数据治理方面的成就，体现了中国政府的决心、能力。中国企业自主的觉悟也在提高，普遍能够诚恳接受，加强自律，做负责任的大企业，兼顾经济目标与社会目标。

  

对于企业而言，随着数据资产日益成为互联网企业最重要的资产之一，保持良性发展的同时也要做到用户至上，严格遵守包括《数据安全法》在内的各项法律，要在数据安全保护上加大投入。同时，用户数据不再是可以任意变现售卖的“唐僧肉”了，从《数据安全法》到《个人信息保护法》，我国陆续出台的法律法规正在告诫所有互联网企业，“数据安全”、“个人信息保护”和“国家层面的数据保护”是每家企业不可推卸的责任，为实现我国数字基础设施的有序建设，以及数据在各行各业的合规化应用做出积极贡献，完善和自我制约，缺一不可。
