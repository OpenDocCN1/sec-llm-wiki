# 百家智库二度纳新，持续招募欢迎加入

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247582357&idx=1&sn=e1be258d678454dfef564366663114c4&chksm=febde855c9ca61430632cdbb9ef9e14ea60ead2465fd8200f91e4da14d010dfe39b4e8d971c7&scene=126&sessionid=1681310563#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247582357&idx=1&sn=e1be258d678454dfef564366663114c4&chksm=febde855c9ca61430632cdbb9ef9e14ea60ead2465fd8200f91e4da14d010dfe39b4e8d971c7&scene=126&sessionid=1681310563#rd)

百家智库是一个专注网络安全，由安在新媒体发起并运营，经定向邀约、公开报名、审核选聘，以社会协作方式运作的民间智库组织。面向中国境内、各地方、各行业、各典型机构、企业和组织，百家智库欢迎以诸子云和CSO俱乐部社群为代表的甲方网络安全业者，以及更广泛意义上的业界专家加盟入驻。入库专家，会以观点输出、专业分享、课题项目、调查报告、联合出版、顾问高参等方式或形式，持续输出专业价值。与此同时，获得专家荣誉称号、个人品牌打造推广、业界影响力提升、智库专享福利，以及专家津贴等收益。

2021年8月12日，安在发布百家智库成立公告，经公开报名、资格审核、项目协作和综合评议，于2022年3月25日通告宣布，首批13位专家正式受聘加入百家智库。紧接着，百家智库启动第二期专家招募，又有十多位专家受邀，与首期正式获聘专家一起，在过去的近一年时间里，通力协作，积极分享，锐意创新，共同推动百家智库各项工作的开展。那么，继首期13位专家后，又有谁在综合评议后，正式受聘加入到百家智库？以及，百家智库过去一年里，又做了哪些事情，取得哪些成绩呢？本文再做揭晓。

**百家智库2022：受聘专家（第二期）**  
![](../Images/990361483e947f7992ec3d13dba56dca.png)

与首期一样，百家智库第二期受邀专家，在一段时间里积极参与智库策划的各类活动和项目，包括直播分享、社群项目、赛事评委、笔会征文、观点输出等，同时达标完成百家智库应邀受聘的基本“门槛”——预备期专家积分。这里，我们对这些专家在参与专业协作和公益分享过程中所作努力与贡献，表示由衷的感谢，同时，也祝贺新一批专家越过“门槛”，正式加入百家智库！

经积分统计和综合评议，百家智库第二期共有12位专家正式获聘加入，恭喜！

**百家智库2022：直播分享**  
![](../Images/990361483e947f7992ec3d13dba56dca.png)

  

作为“诸子云 · 分享汇”社群公益活动的一部分，以百家智库第二期预备专家为主的本季直播共10场，于2022年5月隆重推出，内容涵盖数字化转型、企业上云安全、车联网安全、漏洞治理、数据安全、个信保护、工业互联网安全、安全运营等诸多领域。本次活动得到绿盟冠名赞助和全程支持，这里表示感谢。

**百家智库2022：诸子项目**  
![](../Images/990361483e947f7992ec3d13dba56dca.png)

  

百家智库成立伊始，由智库专家牵头，在诸子云社群内发布并招募成员，共同协作完成公益性质的诸子项目，就成为智库的特色活动之一。自第二期受邀专家就位，2022年度的诸子项目便火热开展。全年共计16个项目，关注“数据安全”、“个人信息保护”、“安全合规”等热点话题和政策，围绕“算法安全”、“反钓鱼”、“车联网”等热门领域，总结企业安全工作中“外购产品”、“资产管理”方面经验积累，为企业“安全架构”建设以及“隐私保护”设计提供宝贵的参考意见。

2022年末，在所有已经完成的诸子项目中，共有8项以直播大赛的方式参与了“诸子云 · 分享汇”2022第二季的活动当中，经专家打分和网络投票，最终决出前三甲，分别获得荣誉证书和10000、5000、2000元奖励。

**百家智库2023：特色活动预告**  
![](../Images/990361483e947f7992ec3d13dba56dca.png)

  

2023年，以百家智库专家为主，我们计划开展包括但不限于如下特色活动：

**▶ 诸子项目&直播大赛：**2023年，百家智库计划开展两季诸子云社群项目的征集和实施活动，并以直播大赛的方式进行成果分享，延续2022年基调，我们会设立大额奖金，并请业界大咖担任评委并坐镇交流。

**▶ 诸子笔会&有奖征文：**2023年的诸子笔会活动与往届稍有不同，我们会以百家智库专家为主，发起有奖征文活动，届时会有更为新颖的形式，针对更具热度的主题，当然也有更具吸引力的评奖和激励。

**▶ 成立专题研究小组（专研组）并开展专项工作：**在百家智库框架下，我们拟成立一些特色专研组，即针对网络安全业界最热点也最具发展潜力的前沿方向，比如零信任、攻击面管理及安全验证、软件供应链安全、API安全、工业互联网安全等，联合业界具有代表性的创新团队，共同实施一些有用户端特色的公益分享活动，包括但不限于调查报告、产品评测POC、最佳实践指南/典型案例集/白皮书、专题研讨会等。

  

**百家智库2023：招募纳新，欢迎报名**  
![](../Images/990361483e947f7992ec3d13dba56dca.png)

  

  

2023年伊始，百家智库继续欢迎各界专家报名加入：

▷ 是诸子云（含超级CSO俱乐部）注册会员，或有较高知名度的业界专家；

▷ 有5年以上网络安全相关领域从业经历，接受过系统性的方法论训练和学识积累，对所在行业有深刻理解，具备深厚的专业技术和管理能力，有着丰富的实践经验；

▷ 所在单位具有一定的地域、行业或组织的典型性与代表性；

▷ 是所在单位信息安全负责人、业务核心或专业骨干；

▷ 个人及所处环境相对Open，有互通协作、跨界创新的意识和实操；

▷ 有持续对外分享和知识输出习惯，包括但不限于写作、出书、培训、讲座等；

▷ 有“专业化生存”的认知、意愿与探索；

▷ 认同并接受“百家智库”理念、宗旨和公约。

经资格审定、预备期考察并最终获聘加入智库的专家，**可获得专属福利、专家津贴，以及个人品牌打造等全方位的收益和价值**，具体包括：

■百家智库特聘专家荣誉称号；

■安在新媒体全方位专家个人品牌打造和推广；

■全面提升个人在网安业界参与度、话语权和影响力；

■智库专家专属福利：诸子云知识星球免费券；获赠安在所有知识出品；适当并免费参加安在组织的各类活动；优先获推参加业界各大峰会和主题论坛；

■以恰当方式参与各类智库项目和专家服务所获酬劳，包括但不限于：顾问费，培训费，项目津贴，知识付费，版税等。
