本期焦点



全美航班停飞


据彭博商业新闻台（BNN Bloomberg）消息，当地时间周三（11日）凌晨，美国联邦航空管理局“航行通告系统”（Notam系统）出现故障，导致全美所有航班停飞。目前，停飞令已经取消，全美超4000架班机延误。

事故刚发生后，数十名因航班延误的乘客在社交媒体上透露了现场情况，暂不清楚何时可以恢复。而按照航班追踪应用“Flight Aware”显示，短时间内就有超过1160架次美国航班受到影响而延误。

美国航空公司称，他们已向飞行员和其他人员通报了故障的问题，眼下正与联邦航空管理局合作，等待问题解决的进一步信息。
另一方面，白宫新闻秘书让-皮埃尔称，拜登在周三上午已听取了关于联邦航空管理局系统故障的简报，目前没有网络攻击的证据，但拜登已指示运输部进行全面调查。



 

专家点评：


企业安全核心重点是业务安全，比如航空管理局，若飞机出了问题，业务无法正常运转，那说明安全部门就有不可推卸的责任，因为我们当下的信息安全包含了系统安全、物理安全、网络安全，而且是动态并非静态的，所以防护未知的攻击才是最重要的，同时只有做好了应急响应、事后处理，才不会影响到业务。


关于业务上的安全问题，安全部门是需要让业务部门的领导看到价值的，安全团队要主动积极地去和业务部门合作沟通，帮助他们。发现风险后，通过可视化直观的形式暴露出来，同时展现安全团队能产生的价值，提出改进建议和改进措施，从而确保业务流程正常安全地进行。在具备专业的人员，和技能的前提下让业务部门与安全部门进行适当的面对面的沟通与交流，一起探讨研究，也能更好地促进整个业务安全工作的落地。

安全事件




1、公安部：2022侦办侵犯公民个人信息案件1.6万余起

截至2022年12月底，共侦办案件8.3万起，其中侵犯公民个人信息案件1.6万余起、严重侵犯人民群众隐私案件340余起；侦破“网络水军”相关案件550余、网络黑产相关案件3.1万起、网络黑号相关案件1.1万起。

2、航天器关键技术爆严重漏洞

研究发现，航天器关键技术之一时间触发以太网的安全机制可能因电磁干扰而受到损害；对高优先级信号的计时干扰，足以导致模拟对接程序出现严重故障。

3、网络攻击致使英国邮政巨头中断国际寄件服务

因发生“网络故障”事件，英国皇家邮政暂时无法将邮件发往境外目的地，已经寄出的国际邮件递送也面临延迟或取消。

4、鹅鸭杀停服DDoS攻击事件见证

2023.1.10 日上午，鹅鸭杀官方于Steam论坛上发布了公告，公开其服务器自2022年12月14日以来被断断续续的 DDoS 攻击。

5、旧金山湾区地铁遭勒索攻击，轨交业已成黑客攻击重灾区

安全内参1月10日消息，在被勒索软件团伙公开列入“已勒索”名单后，旧金山湾区城轨交通系统（BART）开始对这起疑似勒索事件开展调查。

6、法航和荷航部分客户个人信息被盗

Bleeping Computer 网站披露，法航和荷航已经通知“蓝天飞行”的旅客，他们的一些个人信息可能被网络犯罪分子盗取了。

7、奔驰、宝马等汽车品牌存在 API 漏洞，可能暴露车主个人信息

Bleeping Computer 网站披露，近 20 家汽车制造商和服务机构存在 API 安全漏洞，这些漏洞允许黑客进行远程解锁、启动车辆、跟踪汽车行踪，窃取车主个人信息的恶意攻击活动。
