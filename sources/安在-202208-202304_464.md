# 网络错误、设备配置错误竟可让企业损失年收入的9%

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5ODgzNTExOQ==&mid=2247562535&idx=1&sn=c0c83c89323612531869f6b47c4009bd&chksm=febd9fe7c9ca16f1e4e20e58b5c43aa5c6d1bef047a1739163352660de9d22536cbb24cbd54e&scene=126&sessionid=1681310582#rd](http://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247562535&idx=1&sn=c0c83c89323612531869f6b47c4009bd&chksm=febd9fe7c9ca16f1e4e20e58b5c43aa5c6d1bef047a1739163352660de9d22536cbb24cbd54e&scene=126&sessionid=1681310582#rd)

****![](../Images/ec03a52bc4c05aea2c6e258462f5c0df.png)****

  

  

根据国外一家网络安全与合规公司Titania近期发布的一项研究显示，网络配置错误使得公司平均损失年收入的9%左右。

  

Titania的研究基于对广泛的政府和工业垂直领域的160名高级网络安全决策者的调查。报告还警告说，由于对连接设备的审计不够频繁，使得企业容易受到网络攻击的错误配置可能会在网络上保持数月或数年时间。

  

Titania首席执行官Phil Lewis说：“网络每天都可能发生变化，通常是已经列入计划的事项，往往会导致网络配置产生安全偏差。”

  

Phil Lewis建议，由于防火墙、路由器和交换机是所有网络安全的关键，企业组织应当定期（最好是每天）检查所有设备，是否存在可能导致严重安全风险的意外或故意配置错误。

  

Phil Lewis补充道：“只有4%的组织通过审核其交换和路由设备以及防火墙，来评估其所有网络设备，这一事实本身就存在问题，并且可能是由于缺乏准确的自动化检测功能。”

  

![](../Images/319c50a7daac6fc167168c31ef053958.png)

  

![](../Images/7332ae9185ccd271724065fff424cfe2.png)**0****1****优先考虑设备风险排查是项挑战**

  

该项研究还显示，组织往往在优先考虑网络设备带来的风险时就遇到了困难。研究发现，70%的人报告难以根据风险确定补救措施的优先顺序。他们还将不准确的自动化检测工具，视为满足安全性和合规性要求时所面临的最大挑战。

  

Lewis认为：“许多组织目前依靠的工具来自动化漏洞检测，但并未能使日常网络安全检查过程更加高效和有效……它通常涉及采样。这最终会使网络面临由配置偏差而引起的未检测到的潜在关键风险。”

  

报告指出，越来越多的组织正在投资自动化漏洞管理以确保其环境安全，预计全球漏洞管理市场将从2021年的138亿美元增长到2026年的187亿美元。

  

![](../Images/7332ae9185ccd271724065fff424cfe2.png)**0****2****路由器设置错误时有发生**

  

漏洞修复公司Vicarius的首席执行官兼联合创始人Michael Assraf解释则认为，许多组织可能不愿意在网络配置错误上大费周章。“在更改网络配置以进行威胁修复时，很容易‘破坏’工作中的Web应用程序和正常运行的服务……网络设备通常运行Linux的旧版本和精简优化版本，除非硬件供应商发布升级，否则不会收到一般的内核更新。检测错误并从错误配置中恢复，一般也是手动完成，这就需要操作者具备特定的专业知识。”

  

完全依赖防火墙来保护网络设备免受损害，这是一种过时网络体系结构，这也可能导致给组织带来的风险。

  

Corey Nachreiner强调：“管理员可以错误地对路由器设置做很多事情，这些事情可能会意外绕过你的防火墙。”

  

![](../Images/89616467e8d0aecc09ba9ef167af3e20.png)

  

网络安全技术公司WatchGuard Technologies的首席战略官则认为：“我见过管理员使用路由器的多个接口，无意中将第二个接口直接连接到他们的网络之中，在此过程中绕过防火墙的情况。

  

Corey Nachreiner还认为：“一些交换机还有备用的远程管理通道，这些通道可能位于防火墙和网关路由器之外。因此，确保这些功能没有因配置错误而向外部网络暴露你的内部网络交换机，这一点也很重要。”

  

![](../Images/7332ae9185ccd271724065fff424cfe2.png)**0****3****经常被忽视的交换机和路由器**

  

该报告还发现，路由器和交换机在很大程度上被忽视了。大多数组织（96%）优先考虑防火墙的配置和审核，但只有4%的组织评估交换机和路由器以及防火墙。

  

![](../Images/ca898268f443048b430c219ba281f83b.png)

  

IT托管服务提供商MainSpring的首席战略官Ray Steen认为：“商用路由器和网络设备具有强大的安全协议，这些协议被大量宣传。网络管理员信任这种安全性，但是包含易受攻击代码的产品中的强大安全协议，就如同保护纸板箱的三英寸钢门一样，网络攻击者往往不需要去触碰钢门，而只需要去打破盒子。”

  

风险管理平台制造商DeviceTotal的创始人兼首席执行官Carmit Yadin补充道：“我认为人们更多地关注个人计算和服务器，因为很容易保护它们，而且它们很直观。而物联网和网络设备是客户购买并连接网络的黑匣子。无需安装客户端或代理，因此它们看起来没那么直观显眼，继而容易被忽视。”

  

![](../Images/7332ae9185ccd271724065fff424cfe2.png)**0****4****企业机构应如何进行设备管理**

  

安全配置管理（SCM）已经成为现代企业组织开展网络安全建设的重要基础工作，是各种安全能力有效运营的基础。如果没有SCM，企业安全大厦将缺乏坚实的基础，随时都有将倾的可能性。

  

随着数字化与数字经济的不断深入，企业机构应用和服务器的数量及种类日益增多，生产、业务支撑系统的网络结构也愈发复杂，一旦发生维护人员错误操作，以及系统设置没有得到及时有效的更新，便可能带来安全隐患，影响系统的稳定可靠运行。

  

![](../Images/cd693bb1400305b6ebe3835285ae5484.png)

  

SANS 研究所和互联网安全中心建议，当企业全面梳理IT资产后，最重要的安全控制就是进行可靠的安全配置。

  

CIS关键安全控制第4项（Critical Security Control 4）也表明：“企业应建立和维护硬件（包括便携式和移动设备的最终用户设备、网络设备、非计算/物联网设备及服务器）和软件（操作系统及应用程序）的安全配置。”

  

![](../Images/7332ae9185ccd271724065fff424cfe2.png)**0****5****什么是安全配置管理？**

  

通常认为，安全配置是指操作系统（也包括网络设备和安全设备等）、数据库、中间件、第三方应用和业务系统可更改的配置中与安全相关的设置参数，版本，补丁等信息。

  

美国国家标准与技术研究所（NIST）给安全配置管理SCM进行了以下定义：以实现安全和管理风险为目标的信息系统配置管理和控制。通过为系统设置一套标准配置，并持续监控各个指标，组织就可以迅速识别违规行为，并减少攻击面。

  

如果组织使用SCM执行安全加强标准（比如CIS、NIST和ISO 27001）或合规标准（比如PCI、SOX、NERC或HIPAA），便能持续加强系统安全，减小不法攻击者发动攻击的机会。

  

![](../Images/738644674347e0fa6f2e3223691387c6.png)

  

安全配置检查往往是指针对IT范围内，自动化扫描工具不能有效发现的地方，比如网络设备的安全策略弱点和部分主机的安全配置错误等等，进行安全辅助的一种评估手段。  

  

除了已知、未知的漏洞外，安全配置的弱点或缺陷也同样会被攻击者利用。因此，有必要对IT范围内的IT系统和设备进行安全配置检查。

  

![](../Images/7332ae9185ccd271724065fff424cfe2.png)**0****6****安全配置检查的内容**

  

安全配置检查的内容主要集中在设备的账号管理、口令管理、认证授权、日志配置、进程服务、外部端口等几个方面，覆盖了与安全问题相关的各个层面。针对不同系统的具体检查内容一般如下：

  

  

![](../Images/f5eec29c1c5837970cdc63cd1cf67876.png)

  

也就是说，安全配置检查的范围包括网络设备、主机操作系统、数据库、常见中间件及网络服务。

  

安全配置检查方式，通常是人工加自动化检查的方式。

  

人工检查的内容主要包括登录信息收集、配置安全分析和形成检查报告；自动化检查是借助安全配置核查系统或专门开发的检查脚本来自动化完成部分工作。

  

信息系统的网络设备、主机、数据库、中间件、应用软件的安全策略，通常为安全配置检查的主要对象。

  

通过安全配置检查，能够使企业充分掌握当前IT设备的配置情况，以及了解IT设备、系统配置潜在的隐患，同时还可以使企业进一步完善配置管理体系、满足合规需求、降低安全风险。

![](../Images/f254741b053bd0c94938e9860d045904.png)

  

![](../Images/7332ae9185ccd271724065fff424cfe2.png)**0****7****安全配置管理计划与实施**

  

组织如果没有安全配置管理计划，可能会导致哪怕在一台服务器上维护安全配置，也会遇到困难重重，更何况，企业组织往往拥有成千上万个端口、服务和配置需要跟踪。

  

为有效跟踪企业众多服务器、虚拟机管理程序、云资产、路由器、交换机和防火墙的配置情况，最好的方法是借助自动化。

  

一款好的SCM工具，可以为组织自动处理这些任务，同时清晰显示系统情况。一旦组织的系统配置有误，安全人员就会立即接到通知，并获得详细的处置说明，以纠正错误配置。

  

  

**成熟的SCM计划有四个关键阶段：**

  

**1.发现设备**

首先组织要找到需要管理的设备，可以借助整合资产管理存储库的SCM平台完成。还需要对资产进行分类和标记，比如，技术部门的工作站需要与财务系统不一样的配置，避免启动不必要的服务；

  

**2.建立配置基准**

组织需要为每种类型的受管理设备确定可接受的安全配置。许多组织从CIS或NIST等权威机构的基准入手，以获得配置设备的详细指导。

  

**3.评估和报告变更**

组织在找到需要管理的设备，并进行分门别类后，随之就是定义评估设备的频次，即组织应多久审查一次安全策略。有些企业可以使用实时评估，但并非所有场景都需要实时评估，应根据企业的具体情况进行设置。

  

**4.及时补救**

一旦发现问题，就需立即修复，否则攻击者就会趁虚而入。组织需要确定待处理事项的优先级，根据轻重缓急处理不同问题，还需要验证系统或配置确实发生了变更。

  

 ![](../Images/9e7d014a4c18a31e29a6db1c54f62f88.png)

  

**设计安全配置管理计划注意事项：**

  

1、避免IT系统环境中出现资产盲点，通常需要结合基于代理的扫描和无代理扫描，以确保始终正确配置了整个环境；

  

2、组织需要为技术用户和非技术用户设置可选择的设置模式，并且需要能够实现仅向授权用户或用户组显示某些要素、策略及/或警报，这些权限通常存储在企业目录之中；

  

3、安全警报通常由系统中配置的策略驱动。为确保SCM方案满足企业独特需求，创建和管理策略至关重要；

  

4、快速处理在事件响应中极其重要。能够通过深入分析，为事件响应流程提供有价值的信息，就显得很有必要。管理员可以监控和管理表明有违规行为的策略违反行为。

  

事实上，虽然安全配置管理过程很复杂，但如果组织使用合适的SCM工具，大部分工作都可以借助自动化来完成。组织需要加强安全标准，并设立基准基线，以识别该标准出现的变化。
