# 安恒信息2018年度盛会暨颁奖典礼盛大举行！

  “新十年 新使命”安恒信息2018年度盛典暨颁奖典礼于今日圆满举行。

  

![](../Images/0089a0fa09bd6e3f68189338be697417.png)

![](../Images/7d45ff723c455c492f846aa83da00398.png)

       安恒暨十周年庆典之后再次将全国各地1000多名安恒的小伙伴们齐聚一堂，共同欢聚这个辞旧迎新的时刻，总结过去，畅想未来。这是属于安恒人的年度盛会。
