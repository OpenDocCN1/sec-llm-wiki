# 安恒信息助力山东省第四届“技能兴鲁”职业技能大赛成功举办

**关注**

![](../Images/ede02f71047e532e5a3142de93ba6fdd.png)

  

9月18日-19日，“山东省第四届‘技能兴鲁’职业技能大赛—山东省信息网络安全技能大赛”赛前培训举办。来自全省各行各业120人参加了此次为期两天的培训。据了解，此次培训围绕闯关模式和解题模式等主题展开。安恒信息技术专家对参赛人员进行了初赛、决赛的集中培训及模拟竞赛。

  

![](../Images/1e063d49d74cc7c70aac4eb21f65eb85.png)

               

9月20日9:00，“山东省第四届‘技能兴鲁’职业技能大赛—山东省信息网络安全技能大赛”在山东政法学院正式拉开帷幕。本次比赛，由山东省人力资源和社会保障厅、山东省公安厅指导，山东省信息网络安全协会、山东电子学会主办，安恒信息、山东政法学院承办。本次大赛吸引了来自全省约73个党政机关、事业单位等信息系统管理和技术负责人员参赛，共计203人。

  

山东省信息网络安全协会秘书长张娜主持了比赛的开幕式。山东政法学院副院长张振智、山东省人力资源和社会保障厅职业能力建设处副处长李建军、山东省公安厅网络安全保卫总队调研员、副总队长谢文赞，山东省密码管理局副局长徐卫国、山东省信息网络安全协会会长肖义、山东电子学会副秘书长张俭出席并致辞。

  

出席开幕式的领导均强调，加快我省网络安全技能人才培养，是网络安全建设的重要组成部分，是建设网络强省战略的基本保障。网络安全职业技能大赛，是培养、选拔优秀人才的重要途径。竞赛以提高专业技能水平为核心，以赛代练、以赛代训，激发网络安全技术人员的学习热情。他们也表示，希望通过本次竞赛，有效提升参赛人员知识技能和实际操作水平，并在比赛中及时发现、掌握、选拔优秀技能人才。

  

安恒信息技术总监李文昌宣读了比赛纪律和规则。

  

![](../Images/8242b7680b1515768750e1d0315e12eb.png)

  

安恒信息相关负责人介绍，为保证本次大赛顺利举行，在为期三天的培训和比赛中，安恒信息先后为比赛提供了20余人次的大赛支撑，并提供了信息安全竞赛平台。在现场，网络安全工程师凭借一流的技术水平、丰富的工作经验，搭建了安全可靠的网络安技能竞赛战场，从根本上保证了大赛的公平性，为参赛者提供了更加广阔的技术发展空间，并且充分调动了选手的参赛热情。

  

![](../Images/eb12d148659cf9d60fe0eac4a474766f.png)

  

据了解，大赛分为初赛和决赛两个阶段。初赛闯关模式与决赛解题模式均以上机技术操作为主。竞赛命题由命题委员会根据网络安全等级保护技术标准体系内容要求和不同行业网络安全存在的共性问题进行命题。经过两个小时的激烈角逐，40名省直机关、事业单位和国企选手，以及5名企业选手以优异的成绩进入了下午决赛。

  

![](../Images/f4ada4ef6125169af58febcd4d9fce35.png)

  

决赛历经4小时。最终，十位网络安全优秀专业技能人才从众多参赛选手中脱颖而出。国网山东省电力公司孙强斩获个人第一名。而对本次竞赛做出贡献的单位,竞赛组委会也对其颁发了“山东省第四届‘技能兴鲁’职业技能大赛—山东省信息网络安全职业技能大赛个人赛”优秀组织奖和优胜奖。

  

![](../Images/fb3ae46004460b714c638a9afccaa657.png)

 

本次网络安全技能大赛活动的成功举办，充分提升了全省关键信息基础设施的信息安全管理和技术人员专业素养和业务水平，并全面适应了“网络强国”战略对网络安全高层次专门人才的需要，为发现、选拔高素质的信息安全人才提供了有效途径，在提高全省的信息安全水平等方面也起到了重要的推动作用。

 

![](../Images/3da7957c59975e26486855b312bf4a1e.png)

安恒信息作为全球网络安全的领军型企业，已具有十余年信息安全积累，汇聚最佳实践经验；明御攻防实验室平台具有多项独创技术，遥遥领先同类产品，完全自主知识产权，具有核心竞争力；安恒信息攻防比赛平台稳定、可靠，支撑全国多个行业类比赛，获得上百家客户检验认可。同时，安恒信息还具备适用于各行各业网安人才培养；最贴近实战、行业场景、丰富的各种岗位培养方案。
