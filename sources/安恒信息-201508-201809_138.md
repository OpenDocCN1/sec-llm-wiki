# 中国友谊促进会与安恒信息聚焦“一带一路” 达成战略合作

**关注**

![](../Images/269ce485b7a57fdefe6c41d11637ac9d.png)

  

7月5日，安恒信息董事长范渊率团赴中国友谊促进会访问，受到了友促会陈智敏理事长的亲切接见，双方进行了友好会谈并签署战略合作协议。中国友谊促进会副秘书长陈少信、副秘书长彭邦富，安恒信息高级副总裁刘志乐、副总裁段平霞等出席会议。

  

![](../Images/c27ccebb0b7b979197ad679cc2d8ce63.png)

  

陈智敏表示，范渊先生作为早期的留美归国科学家、国家“千人计划”特聘专家，带领安恒信息积极创新，开拓进取，成为国内领先的网络安全公司，为我国网络安全事业做出了突出贡献。陈智敏指出，安恒信息是一支特别年轻、有活力的团队，希望安恒信息能够进一步发挥民营企业创新活力，努力研发自主可控的核心技术，取得新的突破，同时鼓励安恒信息主动承担更多的社会责任和国家安全责任。

  

![](../Images/bf87d6b1541f43c4c398b07cf62bd23e.png)

  

双方将以“战略合作、优势互补、平等互利、协同发展”为原则，聚焦“一带一路”倡议，发挥双方优势，广泛开展国际交流活动，紧紧围绕构建人类命运共同体，积极推动中国及“一带一路”沿线国家网络安全建设。
