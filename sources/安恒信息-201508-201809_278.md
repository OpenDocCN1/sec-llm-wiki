# 共享共建 渠领未来：2018安恒信息第二届渠道高峰论坛举办

网络安全前沿资讯、 应急响应解决方案、技术热点深度解读

**关注**

![](../Images/152e60f159742b3e8ce9372bc0d27a89.png)

  

4月26日至28日，由国家互联网信息办公室网络安全协调局、公安部网络安全保卫局指导，浙江省互联网信息办公室、浙江省公安厅、杭州市人民政府联合主办，杭州市经济和信息化委员会、杭州市萧山区人民政府、杭州安恒信息技术股份有限公司承办的“西湖论剑•网络安全大会”在杭州国际博览中心举办。

  

![](../Images/402067f1310bb49a91e7657c5f9cdb92.png)

论坛现场

  

作为市场营销中的重要环节和战略，“共享共建，渠领未来：2018安恒信息第二届渠道高峰论坛”于4月26日在杭州市萧山区举行。来自全国的200家渠道代表齐聚杭州，共商未来合作之计。安恒信息董事长范渊、高级副总裁马红军、副总裁秦永平、郑赳、杨勃、罗贤斌等出席了此次会议并发表讲话。

  

![](../Images/6d3901dd861f73b7ebbf1cb9cc03c50a.png)

安恒信息总裁范渊

  

“过去十年，安恒信息见证了国内信息化和网络安全的发展历程，而在这十年间，安恒信息不断成长，尤其是在预警能力、情报能力、漏洞挖掘等一系列能力中不断提升，均走在国内前沿。”范渊介绍，十年间，安恒信息参与了先后为北京奥运会、国庆60周年庆典、上海世博会、广州亚运会、抗战七十周年、连续四届世界互联网大会、G20峰会、厦门金砖峰会等众多重大活动提供网络信息安全保障。

  

范渊表示，正因为安恒有简单易用的产品，有标准化的交付能力，所以渠道模式是最适合安恒的销售模式。很多大的竞争对手都去直接做客户了，这恰恰是把广泛的渠道留给了安恒，因此，安恒的发展渠道的速度要更快一点。  

  

![](../Images/90387267534ea5d69796fd081f5975e8.png)

安恒信息高级副总裁马红军

  

马红军也表达了类似期许。其表示，在之前的十年中，安恒信息一直在健康稳步地成长，在未来的营销政策中，渠道将非常重要，期待大家与安恒信息继续合作，在事业上取得更大成功。

  

![](../Images/bd243bf1c3cbe372c7e8fbd37af0a30a.png)  

颁奖现场

  

罗贤斌介绍，安恒如今的渠道政策愿景，已经有了大幅度的转变。从赋能渠道共同成长，到共创公司级的合作平台，安恒的渠道政策，一直在不断地完善。而安恒的渠道行销运营，将以持续精准营销，加强认可为目的，继续构建互动通道，对渠道按区域、行业、类型实现精准推送，实现标签化。而除了精准推送以外，安恒渠道也会对信息安全趋势、公司喜报、市场活动等每周进行全面推送，并推送相应的解决方案与案例、区域特性需求与案例。

  

![](../Images/10e30b563c31f44e2dacebd91b6e7c90.png)

安恒信息副总裁罗贤斌

  

其表示，未来的安恒，将继续服务好渠道，提高产品及服务质量，并通过校企合作，加快人才输出能力。与此同时，安恒还将继续提升安恒产品在客户端满意度，进一步解决渠道跟厂商的粘度，建立生态圈。

  

罗贤斌说，坚持渠道战略作为市场的核心战略，在市场体系已经有了广泛的共识。但过去的工作方式影响了渠道战略的落地。如今，安恒改变了一线的工作模式和思维，从以项目为核心，调整到以渠道建设为核心。

  

“我们做渠道，并不是说就不做客户了。我们在客户端的工作要从做项目，转变为去影响客户，建立客户对安恒品牌和产品的认可，不断扩大在各个行业的影响力。一方面给渠道的空间更多了，另一方面在客户端的影响力加强了，这样进一步促进了我们跟渠道的合作。”罗贤斌说。

  

同舟共济扬帆起，乘风破浪万里航。安恒愿意投入资源、开放客户与诸位精诚合作，互利共赢！
