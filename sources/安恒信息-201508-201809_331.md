# 国测最新认证第二弹，CISP-BDSA和CISP-CSE认证培训开班在即

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650460806&idx=1&sn=af5c7abb4a9cf9eb7c34f35838eb14ed&chksm=bef37cff8984f5e94e14e5c45eede303577259d1dc8591a7a4f0d41862a070f08dcd9a489e97&scene=126&sessionid=1681367145#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650460806&idx=1&sn=af5c7abb4a9cf9eb7c34f35838eb14ed&chksm=bef37cff8984f5e94e14e5c45eede303577259d1dc8591a7a4f0d41862a070f08dcd9a489e97&scene=126&sessionid=1681367145#rd)

继一周前正式推出注册Web安全工程师和注册工业控制系统安全工程师两大认证之后，今日安恒信息再度出手，联合中国信息安全测评中心（简称“国测”）放出本年度最新认证第二弹：首届**注册大数据安全分析师**（CISP Big Data Security Analyst，简称CISP-BDSA）和**注册云安全工程师**（CISP Cloud Security Engineer，简称CISP-CSE）认证培训班，将于4月21日在杭州开班。国内首批国测认证的注册大数据安全分析师和注册云安全工程师，即将亮相。国测与安恒信息强强联手，推出的四个全新安全认证体系首期培训班相继开班，可谓一年磨砺终出鞘，四箭齐发直指产业人才热点。

**关于CISP-BDSA和CISP-CSE认证**

注册大数据安全分析师（CISP-BDSA）

![](../Images/cb984a11fe11a266cfc3a4c16260571b.png)

CISP-BDSA是对我国大数据安全分析人员进行资质评定的重要形式之一。持证人员掌握涵盖大数据概述和分析过程、数据分析算法原理和示例、大数据系统工程实现、大数据安全分析常见案例、大数据系统安全法律法规等知识内容，具备大数据安全分析理论基础和实践能力，可从事大数据安全分析、安全管理等工作。

注册云安全工程师（CISP-CSE）

![](../Images/05c707dcfc1b4dd3d8a4ab95d9407511.png)

CISP-CSE是对我国云计算安全技术人员进行资质评定的重要形式之一。持证人员掌握云计算体系架构及关键技术、云计算安全威胁与需求分析、云计算安全技术、云计算安全防护应用、云计算安全管理、云安全政策法规与标准规范等知识内容，具备从事云计算安全规划和系统运维等安全工作的技能，可从事云计算安全设计、服务、运维、安全管理等工作。

**国测新认证四箭齐发**

**首届培训班全部落户安恒信息**

安恒信息是最早一批国测认定的“授权培训机构”之一，也是目前浙江省唯一的一家CISP授权培训机构。2017年“西湖论剑”期间，国测联合安恒信息举行网络空间安全人才培养战略合作发布仪式，正式启动CISM-WSE、CISP-ICSSE、CISP-BDSA和CISP-CSE四大认证项目。

**首批证书将于2018年“西湖论剑”颁发**

起点高，技能全满，实战动手能力强，“黄埔一学”学员的“前途”和“钱途”，将十分值得期待。完成上述四个认证培训并通过考试的学员，将会在2018“西湖论剑”期间获得由国测朱胜涛主任亲手颁发的首批证书。  

将信息安全从业人员的认证细分到Web安全、工业控制系统安全、云安全和大数据安全等新兴安全领域，在业界尚属首次，也是对业界热点安全人才需求的及时回应。从四年前成立安恒信息网络空间安全学院，到与国内十所顶级高校联合建设实训基地，再到目前推出网络安全的认证培训体系，安恒信息总裁范渊带领安恒信息，仍在身体力行地探索国内网络安全人才培养体系的建设。他立下宏愿，要“以公益或者半公益的心态，来推动中国网络安全产业发展。”
