# 2018 “安恒信息”高校教师网络安全技能精讲班顺利结业

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650459933&idx=2&sn=6f1af4fa3c4ecccc48a69eea916995b4&chksm=bef361648984e8728a9a39aa25aa4bb430c0900fe80283115a258e5b9ce541328cdd30d62a39&scene=126&sessionid=1681367170#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650459933&idx=2&sn=6f1af4fa3c4ecccc48a69eea916995b4&chksm=bef361648984e8728a9a39aa25aa4bb430c0900fe80283115a258e5b9ce541328cdd30d62a39&scene=126&sessionid=1681367170#rd)

> 网络空间安全专业被定义为一级学科，各大相关高校、职业院校纷纷开设相关课程。教师是支撑学科建设的主要力量，这不仅体现在教师的理论基础上，更加体现在网络安全攻防实战中。

  

安恒信息于2018年2月1-3日如期举办了 “高校教师网络安全技能精讲班”。精讲班通过与导师面对面交流探讨、实验实操、参观企业等形式促进专业教师的互动交流，增强科研兴趣，拓展学术视野，明确研究方向。

参加此次培训的学员主要来自于全国各地的本科院校、高职院校中的计算机或网络安全专业负责人、教研室主任、实验室人员以及网络中心安全维护责任人。这些院校都已经开设或者计划开设网络空间安全等相关专业，安排人员参加此次培训，是为了更好完成专业建设的前期筹备工作。

![](../Images/8efc8e34b5074cafff95dacfb9d3a6f5.png)

图：培训现场

学员们作为高校教师，都具备系统的知识结构和扎实的理论基础。因此，这次培训内容主要是以实战为主的渗透测试。我们邀请了“拼杀”在各个行业的网络安全攻防一线的工程师，为老师们进行现场实操，从知识基础到深入讲解，全方面分析网络空间安全的现实环境，包括针对信息系统黑盒检测、白盒检测实操技巧，以及对高危漏洞SQL注入的深入分析以及“花式利用”。

  

![](../Images/b59add1d0994c15932d6fcd0f984e1f7.png)

图：老师们在培训现场现场讨论中

  

在培训现场，教师们就针对课程内容进行深入探讨，并结合实际教学中遇到的问题进行了深刻的交流与经验分享。
