# 安恒信息获评IDC MarketScape“2019年中国Web 应用安全市场领导者”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650467696&idx=1&sn=24e5fe30e6510fc70a626667b89b94e7&chksm=bef343098984ca1fb4ae35695322fbb0dd96b00236cdb43631d7cb56d26867f4f3ec1801c696&scene=126&sessionid=1681366912#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650467696&idx=1&sn=24e5fe30e6510fc70a626667b89b94e7&chksm=bef343098984ca1fb4ae35695322fbb0dd96b00236cdb43631d7cb56d26867f4f3ec1801c696&scene=126&sessionid=1681366912#rd)

![](../Images/7cf2befc8248e54272da27e818d4c8be.png)

  

近日，全球知名咨询机构IDC发布了最新的《IDC MarketScape: 中国Web应用安全市场2019年厂商评估》报告，从产品和服务成熟度、行业影响力、持续投入能力等方面梳理出了十余家Web 应用安全解决方案主流厂商，涵盖了国内外综合型安全厂商、典型云服务提供商以及新兴Web应用安全产品提供商，并针对其公司规模、产品技术能力、行业和客户拓展、生态系统建设以及未来发展战略等进行综合评估。

  

安恒信息作为第一批推出 Web 应用安全解决方案的厂商，在能力、战略、市场份额等维度考量中均处于领先，入选**2019年中国Web 应用安全市场领导者**。安恒信息在国内外综合型安全厂商、新兴Web应用安全产品提供商队伍中**市场份额领先**，**持续保持在中国Web应用安全市场的头部地位**。

![](../Images/bbdea3e268e0a8d97417871f26c40920.png)

  

  

报告认为，安恒信息的安全产品和服务具备对Web应用安全的全面防护能力。从产品分类角度看，此次入围的Web应用安全产品和服务包括Web应用防火墙、玄武盾云防护服务、Web 应用弱点扫描器、明鉴网站安全监测平台、网站卫士网页防篡改系统等；从产品形态角度看，涵盖软件、硬件、SaaS多种交付形态，可以满足不同规模用户差异化的Web业务场景，构建了覆盖“事前监测+事中防御+事后审计溯源取证”的全生命周期Web应用安全解决方案。

  

针对每类入围的产品，《IDC MarketScape: 中国Web应用安全市场2019年厂商评估》报告一一梳理出其独特的优势：

  

![](../Images/da643aae6e071d6297b1248caf9a0e15.png)

**Web应用防火墙**

专注于Web 应用的安全防护，2019年新推出的新一代智能 Web 应用防火墙，采用智能语义分析引擎、机器学习引擎、云端威胁情报引擎、智能行为分析引擎、特征安全引擎，五大安全引擎有机协作，对网站及应用程序（App）业务流量进行多维度、深层次的安全检测和防护，能够基于用户行为分析及上下文内容逻辑的攻击检测，在减少误报和漏报的前提下，将安全引擎的防护准确率提升到极致。

  

![](../Images/da643aae6e071d6297b1248caf9a0e15.png)

**玄武盾云防护服务**

一款针对网站及在线应用的云端安全托管式服务，采用全天候实时在线的安全托管服务，有效解决传统模式下用户侧缺少持续安全运营的困境。玄武盾储备有丰富的网络带宽资源池，根据各服务用户情况实时进行网络带宽分配，有效解决了单个用户抵抗大量 DDoS 攻击时高成本问题。

  

![](../Images/da643aae6e071d6297b1248caf9a0e15.png)

**Web应用弱点扫描器**

对Web应用进行深度弱点探测，可帮助应用开发者和管理者了解应用系统存在的脆弱性，为改善并提高应用系统安全性提供依据，帮助用户建立安全可靠的 Web 应用服务，并提升应用系统抗各类 Web 应用攻击的能力。

  

![](../Images/da643aae6e071d6297b1248caf9a0e15.png)

**网站卫士网页防篡改系统**

新一代专利级网页防篡改产品。采用"事前阻止+事后恢复" 作为网页防篡改方案，通过操作系统底层驱动技术实现事前阻止网页篡改行为，通过高效率的文件同步技术实现网页篡改后的实时恢复，通过深度扫描网页木马发现已存在的隐藏的网页木马，从根本上解决页面篡改、挂马、暗链等网页风险问题。

  

![](../Images/da643aae6e071d6297b1248caf9a0e15.png)

**明鉴网站安全监测平台**

对Web应用提供 7\*24 小时实时安全监测服务，提升网站的安全防护能力和网站服务质量，并通过安全监测平台的事件跟踪功能建立起长效的安全保障机制。

  

  

安恒信息Web应用防火墙多次获得 Web应用防火墙领域国际认可，Web漏洞扫描产品连续四届入围中国移动Web漏洞扫描集采，网站卫士网页防篡改系统连续三届入围中国移动网页防篡改产品集采。玄武盾自2016年发布以来，防护超过数十万个互联网系统，平均每天清洗的访问多达15亿次，每天拦截的攻击次数多达600多万次，累计拦截54亿次攻击。

  

在IDC此前发布的《中国Web 应用安全市场看法，2018》报告中，安恒信息在竞争性和成长性两个维度考量中均名列前茅，入选中国Web应用安全市场“领导厂商”。

  

  

关于IDC MarketScape

 

IDC MarketScape厂商分析模型是一个对ICT（信息和通信技术）厂商在既定市场中的竞争力综合评估的模型。研究方法利用了基于定性和定量标准的严格评分方法，在既定市场中对每个供应商的位置进行单一的图解说明。IDC MarketScape设定了清晰评估维度，可以对IT和电信供应商的产品和服务，能力和策略以及当前和未来的市场成功因素进行有意义的比较，同时也为技术买家在评估当前或者潜在供应商时提供360度的评估建议。
