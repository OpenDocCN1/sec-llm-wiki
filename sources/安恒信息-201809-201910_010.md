# 四大创新成果重磅发布 安恒信息完美收官第六届世界互联网大会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650467660&idx=1&sn=fd226f80d57639cf84b0319ade046fd9&chksm=bef343358984ca2397713b9649355c2c2b05d9457504fef6de9618f613c818ad222b48e1e38a&scene=126&sessionid=1681366912#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650467660&idx=1&sn=fd226f80d57639cf84b0319ade046fd9&chksm=bef343358984ca2397713b9649355c2c2b05d9457504fef6de9618f613c818ad222b48e1e38a&scene=126&sessionid=1681366912#rd)

![](../Images/7cf2befc8248e54272da27e818d4c8be.png)  

  

第六届世界互联网大会圆满落幕，重头戏之一“互联网之光”博览会再次带来一场科技新体验。最新最前沿、有趣有料、可互动可体验的“硬核”成果集中展示，多家中外企业发布新产品、新技术。

  

“网络安全”依然是本届世界互联网大会关心的热点话题，诸多先进创新成果也与安全相关。在本次的创新发布现场，安恒信息重磅发布了**四大创新成果，智能网联汽车信息安全方案、工业互联网安全平台化运营、网络空间与新经济监管实践、智慧城市安全运营平台**。聚焦行业热点、前沿技术的网络安全产品及解决方案，展现了国产自主品牌产品的创新能力和技术水平。

  

  

**智能网联汽车信息安全方案**

  

  

**关键词：安行 安全心**

汽车联网能力在不断增强， 交互应用更加广泛， 但黑客攻击也在逐步渗透至车联网领域。面对新型网络威胁，汽车厂商抵御攻击的手段有限。基于此，安恒信息带来了智能网联汽车信息安全方面的最新研究成果，提出了智能网联汽车信息安全“安恒安行” 和 “安全心”两个核心产品的解决方案。“安恒安行”通过借助高强度的国密算法、标准的身份认证与密钥管理平台，为汽车的车联网系统在汽车数字钥匙、数据通信、V2X等场景中提供身份认证、数据保密等安全措施，“安全心”让汽车IVI、T-BOX等拥有天然的内生安全性，结合云端的态势感知有效防御内外部攻击保障数据安全。

![](../Images/9147fc6d10b3f588904bf8bb39e1aea5.png)

发布人：车联网事业部总监蒋洪琳

  

  

**工业互联网安全平台化运营**

  

  

**关键词：定制化服务 平台化运营**

解决方案强调工业企业之间安全需求的差异性，为企业提供的服务也有由单一维度向多维度转变，通过对每一个行业企业安全需求和状态的深度挖掘，实现工业企业专属安全的数据和产品的归一，形成定制化工控安全服务。甚至是细分到日常的工业企业安全服务事项，企业级和系统级的威胁预警和安全应急，以及联合开发、技术集成、长效服务等合作方式。

![](../Images/7ae7e19e043b9f02e73de04589fdd8bb.png)

发布人：工业互联网安全事业部总经理叶鹏

  

  

**网络空间与新经济监管实践**

  

  

**关键词：安全大脑 经济金融风险防控**

安恒安全大脑的涉众型经济风险监管新平台，通过汇集整合提炼分析互联网公开信息、政府行业监管信息和公安网警情信息，采用特定风险特征和一般风险特征相结合的方式，进一步拓展网络信息安全的边界，为建立全方位、立体式的经济金融风险防控体系，做出新的探索性实践。在涉众型经济犯罪领域协助公安经侦、地方金融局开展对P2P网贷、网络传销等涉众型金融风险目标和私募基金、投融资中介等涉嫌非法集资犯罪的业态风险进行监测预警；在市场主体经济分析领域协助工商、税务、管委会等在园区楼宇管理、招商引资、政企协同、人才引进，以及支持中小微企业发展等方面的科学决策提供数据支持；在反电信网络诈骗域协助公安刑侦、运营商，对电信网络诈骗线索进行全网监测预警和市、县、派出所三级反诈联动预警劝阻机制。

![](../Images/1381a7ff38ea5b22ccbd178da8288b71.png)

发布人：金融风险事业部副总经理戚华春

  

  

**智慧城市安全运营平台**

  

  

**关键词：服务+产品 未来安全运营**

智慧城市安全运营平台，采用创新的安全运营与分析平台架构(SOAPA)和IPDRRRM+PPDR双模型，让安全服务线下能力线上化、专家与产品协作分析数据化、信息安全运营治理工作流程可视化，并结合威胁情报、EDR 、安全资产管理等网络安全产品，形成安全运营生态。平台主要应用于企业级安全运营中心，监管机构，行业级、区域安全运营中心，城市级安全运营中心等方向。获得了监管机构、金融、能源、运营商、政府等多个重量级客户的认可。

![](../Images/c053b191d6607dce1ae3873aa72be5bd.png)

发布人：首席安全运营官李贵鹏

  

  

创新驱动发展，技术引领未来。在时代快速变迁，网络安全需求不断变化的当下，安恒信息深谙一个道理，唯有不断自主创新，专注行业前瞻技术、核心技术的突破，才能持续推动企业乃至行业的进步。每年，安恒信息都会推出新产品，打造更全面、完善的解决方案，真正解决客户的痛点和难点，推进网络空间互联互通、共享共治，让网络安全成为驱动引领经济社会发展的重要动力引擎。安恒信息也期待和更多的伙伴一起，共同携手构筑网络安全新长城。
