# 公安部第三研究所与安恒信息，进入“合作2.0时代”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650467594&idx=1&sn=77f4791a49f0bad123446544f79209c2&chksm=bef343738984ca65d2fb09b851f4e867e02bbb26d62931bcdb84e692b696e5b99f478a6613fd&scene=126&sessionid=1681366917#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650467594&idx=1&sn=77f4791a49f0bad123446544f79209c2&chksm=bef343738984ca65d2fb09b851f4e867e02bbb26d62931bcdb84e692b696e5b99f478a6613fd&scene=126&sessionid=1681366917#rd)

![](../Images/7cf2befc8248e54272da27e818d4c8be.png)

  

**合作签约**

  

10月14日，公安部第三研究所副所长李建瓴一行莅临安恒信息考察指导。会上，公安部第三研究所副所长李建瓴与安恒信息董事长范渊签署合作协议。这表明，公安部第三研究所和安恒信息的合作正式进入2.0时代。

  

双方将依托各自优势资源、积极探索合作模式，在科学研究、网络安全人才培养、国家及行业标准制定等方面开展深度合作，共同提升我国网络安全治理水平和网络安全人才的综合技能水平，为国家发展和社会经济建设培养各层次网络安全人才。

![](../Images/519f0b77fd34342f557fd42192117dff.png)

图：签约仪式

  

公安部第三研究所和安恒信息颇有渊源，早在安恒信息初创期就开展合作，并打下了很好的合作基础，随着合作深度的推进，双方在网络安全技术、行业标准等方面有诸多业务合作。在人才培养方面，在公安部第三研究所的指导下，安恒信息为第45届世界技能大赛、2019全国信息安全管理员知识与技能竞赛等多个国内外重要赛事提供技术支撑。

  

以此次合作签约为契机，双方将联合打造从理论基础教育、工程实践实训、竞赛支撑服务、就业指导推荐等全方位的人才培养体系，共同协助全国各省做好世界技能大赛网络安全赛项的技能型人才培养，共同推动我们网络安全技能型人才教学、实训工作；同时，双方共同开发符合当下安全人才技能所需要的培训教材、题目等教学资源，加强网络安全管理防护领域前沿技术的共同研究和成果转化等等。

  

![](../Images/b88b375a46a4d66a57dc0fddfaa6a943.png)

公安部第三研究所副所长李建瓴表达了对安恒信息深耕网络安全领域的认可，以及在网络安全人才培养能力的肯定。他表示，希望双方着眼于未来，在此次签约的指导性合作框架协议下，开展更紧密、多领域、全方位的深度合作，助推公安部第三研究所“培训、实训、认证” 三驾马车齐头并进，深入研究网络安全技术、让网络安全人才培养工作更扎实。

  

![](../Images/726e4afcb1dfd5d2732cc3958cc87da8.png)

  

安恒信息董事长范渊表示，未来，双方将在长三角一体化、服务公安实战、网警培训等方面加强合作。相信在公安部第三研究所的指导下，安恒信息将更好地为网络强国、数字中国人才战略贡献力量。

  

签约仪式后，公安部第三研究所副所长李建瓴一行参观了安恒信息安全创新体验中心，了解安恒信息前沿技术和应用实践。

![](../Images/da2fb07c6a0d1b11a110a86c44505b2b.png)

图：合影留念

  

此次与公安部第三研究所的合作，是安恒信息在网络安全合作领域迈出的坚实一步。安恒信息也将继续依托自身技术优势和丰富的经验积累，助推中国网络安全人才体系的建设，筑牢网络安全防线。
