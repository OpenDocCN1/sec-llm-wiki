# 安恒信息入选成都市委网信办第一届网络安全技术服务单位

近日，成都市委网信办公布了**第一届网络安全技术服务单位名单**，安恒信息成功入选。

  

据了解，本次网络安全技术服务单位遴选工作，是为了加强成都市网络安全技术服务体系建设，强化网络安全事件应急处置能力，提升网络安全工作保障水平。入选的单位将参与成都市委网信办相关网络安全保障及事件的应急处置工作，市委网信办还将定期对各单位工作完成情况进行评估。

  

技术服务单位

→

![](../Images/733420cdceeb4e9511403b0f86406f6b.png)![](../Images/ef56c32347344f497ebea1a9656f73f8.png)

  

今年以来，安恒信息连续三届荣获国家计算机网络应急技术处理协调中心颁发的**网络安全应急服务支撑单位证书（国家级）**，并获得福建、黑龙江、浙江等分中心颁发的合作支撑单位证书；入选**上海市委网信办首批网络安全技术支撑单位、第一批贵州省网络安全应急技术支撑队伍、济南市网络安全应急服务首家支撑单位，以及工业信息安全产业发展联盟第一届工业信息安全应急服务支撑单位**等，这是主管部门及专项技术评选部门对安恒信息信息安全综合能力、安全应急能力的肯定。

![](../Images/0c0effc4456a5a09994a96b41d72bbdd.png)

  

安恒信息深耕区域、立足区域，不断提升自身安全技术水平，积极配合相关部门网络安全建设。作为国家级重大会议的网络安保支撑单位，安恒信息为北京奥运会、上海世博会、广州亚运会、历届世界互联网大会、G20杭州峰会、厦门金砖峰会、上合组织青岛峰会、上海进博会等国家级重大活动提供网络安全保障支撑。

  

未来，安恒信息也将继续发挥主观能动性、积极配合，为成都市委网信办提供应急响应、风险评估、应急处置等服务支撑，提升成都市网络安全事件应急能力和防御能力，推进成都市网络安全建设。
