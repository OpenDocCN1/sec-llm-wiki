# 《2019网络安全人才现状白皮书》发布，精华都在这了！（附全文）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650467389&idx=1&sn=4b773cc00c4bc54e5968cbbf2a8c4658&chksm=bef342448984cb5212a043e8c7ff75debe9ea91dceb61963aca0f7974f4b90aa290ec108da5a&scene=126&sessionid=1681366922#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650467389&idx=1&sn=4b773cc00c4bc54e5968cbbf2a8c4658&chksm=bef342448984cb5212a043e8c7ff75debe9ea91dceb61963aca0f7974f4b90aa290ec108da5a&scene=126&sessionid=1681366922#rd)

继去年国家网络安全周上发布《2018网络安全人才发展白皮书》，在2019年国家网络安全宣传周上，中国信息安全测评中心、杭州安恒信息技术股份有限公司、猎聘网再度联合发布了《2019网络安全人才现状白皮书》，从网络安全从业人员的特征、网络安全行业需求、网络安全人才培养现状、网络安全行业人才供给情况等多个维度对网络安全人才现状的整体形势进行全面的分析。

![](../Images/1f32133eb7a1a32456cc4f9c522d81ac.png)

  

如白皮书显示，目前网络安全人才现状呈现**几个主要特点:**

  

**No.1**

**2019年网络安全行业即将迎来第一批“网络空间安全”专业毕业人才**

  

  

2015年6月，为实施国家安全战略，加快网络空间安全高层次人才培养，国务院学位委员会决定在“工学”门类下增设“网络空间安全”一级学科。2019年网络安全行业即将迎来第一批“网络空间安全”专业毕业 人才，一批在校生寻找就业机会，已经提前走入企业或单位中。

  

在网络安全从业人员年龄来看，网络安全从业人员的年龄最多集中在25-30岁之间，占比为36.71%，但25岁以下的网络安全从业人员相比2018年的9.6%占比显著提高，占总数的19.34%。

  

![](../Images/4cbbd8f3e732a5203926d8ee377b6b0f.png)

  

  

**No.2**

**网络安全人才中女性占比有较大提升**

  

  

男性仍然是网络安全人才的绝对主体占比为77.06%，女性占比为22.94%，比较去年的女性占比14.4%有较大提升，在技术和管理岗的比例上，女性负责管理岗位的人员较多，而男性负责技术岗位的较多。

![](../Images/1726160d9e8310de6748268b27ee2021.png)

  

此外，行业人员本科学历占比较高为65%，相比较去年增长1.8%，网络安全行业从业人员薪资水平10-20万占比高达69%，网安人才队伍正在逐步扩大。

  

**No.3**

**国内网络安全人才培养的主要途径是大学教育以及网络空间安全学科建设，主要培养本科及本科以上专业人才。**

  

根据数据，梳理了**网络安全从业人员毕业院校前50强**，其中北京邮电大学仍然排名第一，占比2.91%。目前大学前五，分别是北京邮电大学、西安电子科技大学、电子科技大学、北京航空航天大学、上海交通大学。几个值得关注的变化，天津高校排名明显提升，整体排名并列第四；重庆邮电大学，从去年的22名，上升到2019年的第10名；广西，桂林电子科技大学，首次进入前50名。

![](../Images/6924dd236abbc5dbd5862385e09ce69d.png)

**No.4**

**北上广的人才需求量最大，浙江需求翻倍**

  

随着网络安全受重视程度日益增高，行业发展也日益增速。中小型企业、私营企业等逐步设立网络安全专岗人员，使得其人才需求量不断增加，特别是以北上广为代表的一线和新一线等省市，人才需求数量占全国需求总量60%以上。这和北上广聚集了大量的网络安全相关的企业和机关有很大的关系。

  

另外，浙江对网络安全人才的需求量有了显著提高，比起去年的5.4%的需求量增长了一倍多。这和浙江的互联网和通信电子行业的兴起和发展有着密不可分的联系。

  

![](../Images/651a9b770085982dbcced56a92af168b.png)

  

再从用人单位规模来看，大型企业与国家党政机关的相关从业人员较多。但随着2019网络安全等级保护制度2.0标准正式发布，对中小型机构的安全等级要求更高，中小型机构对网络安全人才的需求量普遍较高。其中，规模在100-499人的中小型企业对网络安全人才的需求量最大，占比约30%;其次是2000-5000人的企业，网络安全人才的需求量占比20%。

  

![](../Images/d0da2abf0170962835f7d06ae3db5464.png)

  

**No.5**

**网络安全人才短缺岗位：技术服务人员和研发人员**

  

即使从事技术岗位的人员占比最多，技术服务人员的需求量还是居于最高位，达53.02%;研发人员和项目管理人员的需求量占比分别为 28.84%和15.81%，网络安全人才还是处于短缺状态。

  

  

再从网络安全行业人才培养现状分析，国家对网络安全宣传力度的不断加大和普适性教育的推广，使得国民对网络安全的了解也进一步提升。但网络安全专业发展时间较短，学生对该专业的本质并没有深入的理解。各高校通过竞赛、实习见习类活动，激发学生学习热情，提升学生专业素养。同时，在普遍看好的就业前景下，学生能在较为明确的培养目标下更为主动地注重自身能力培养，这也促进了网安人才质量的提高。

  

从网络安全行业人才供给情况来分析，随着我国网络安全人才培养和认证体系的建立和日益完善，更多网络安全从业人员选择通过考取资质证书来提升自身发展空间。除国家推出的各类资质证书外，各校企也同步发展，企业内训及职业类培训已成为人才自我提升的主要途径。网络安全人才平均水平的提高，不仅推进企业和行业发展，也使得从业人员的薪酬更为乐观，逐步进入良性循环。
