# 草原云谷论安全 | 2019草原云谷大数据安全高峰论坛成功举行

8月15日，“2019草原云谷大数据安全高峰论坛”在乌兰察布举行，论坛以“草原云谷·绿色数据·安全赋能”为主题，旨在推动乌兰察布大数据安全产业交流与合作、开展大数据安全政策宣贯，展示乌兰察布大数据产业最新发展成果，搭建交流合作平台，助推乌兰察布网络安全产业发展。论坛汇聚来自国家科研机构、政府主管部门、行业企业等领导、专家及学者等300余人参会。

  

![](../Images/b87399872016bda1c01771e5a73f0f48.png)

  

此次论坛由国家信息中心、国家信息技术安全研究中心、中国电子技术标准化研究院、内蒙古大数据发展管理局指导，乌兰察布市人民政府主办，乌兰察布市委网信办（大数据管理局）、国家信息中心《信息安全研究》杂志社、杭州安恒信息技术股份有限公司承办。

  

**重磅战略合作签约，共建草原云谷**

  

近年来，乌兰察布紧紧抓住内蒙古获批成为大数据基础设施统筹发展类综合试验区的历史机遇，围绕建设“一个核心区、五个基地”的发展定位和“草原云谷”的战略决策，将云计算、大数据产业作为大力引进和重点扶持的战略性产业与支柱产业加以培育，加强组织领导，完善配套服务、出台优惠政策，全力为产业发展创造良好环境，取得了显著成效。

  

在本次论坛中，乌兰察布市人民政府与杭州安恒信息技术股份有限公司签订战略合作协议。未来，安恒信息将助力乌兰察布市推进智慧城市安全顶层设计、城市级安全运营中心、网络信息安全人才培养体系等方面的建设，依托各自优势资源和能力，探索合作模式，增加合作层次，拓宽合作领域，推动乌兰察布市数字化转型及数字经济发展。

  

![](../Images/bcde66ea723393d5c1803f5e278e29a3.png)

  

  

**三大院士分享安全前沿议题，共话安全新趋势**

  

作为本次论坛的一大亮点，论坛邀请中国工程院倪光南、中国工程院院士沈昌祥及中国科学院院士王小云等国内网络安全届的泰斗分别就自主可控与网络安全、数字经济时代的机遇与网络安全、工控安全与密码技术等前沿话题展开了分享。

  

倪光南认为，当前我国网信领域要求采用自主可控技术、产品、服务、系统的呼声越来越高。自主可控是实现网络安全的前提，是一个必要条件，但并不是充分条件。换言之，采用自主可控的技术不等于实现了网络安全，但没有采用自主可控的技术一定不安全。因此，为了实现网络安全，首先要实现自主可控，再实现传统意义上的安全，最终再结合其他各种安全措施，达到保障网络安全的目标。

  

![](../Images/cde484531c311fcf9edde114c9ad75d4.png)

  

沈昌祥认为，大数据给现有信息技术体系带来了新挑战，需要投入与创新，还需要营造有利于大数据产业健康有序发展的良好环境。随着海量数据的进一步集中和信息技术的进一步发展，信息安全成为大数据快速发展的瓶颈，树立科学的网络安全观，筑牢网络安全防线势在必行。

  

![](../Images/1445865c4e429d01745575a08e4df28c.png)

  

王小云认为，密码技术是保障大数据安全，助力数字经济高质量发展的一个重要技术手段，数字经济高质量发展离不开密码技术。信息与网络安全保障体系需要完善一些技术：比如云服务的远程身份鉴别、隐私保护问题、大数据的安全治理问题、支付的安全问题、芯片的安全问题等等。

  

![](../Images/b2ed0e58dabc87986c98eccca76341c4.png)

  

此后，公安部第三研究所等保评估中心常务副主任张宇翔、北京大学软件与微电子学院创始院长陈钟、乌兰察布市大数据发展局局长仝晓林、江之恒网络信息安全研究中心主任刘博分别作报告。

  

刘博表示，“云和大数据时代下，要利用‘数据’来推动城市治理模式的提高，并且提供便捷且安全的服务。”此后，刘博介绍了如何保证数据资源共享过程中合规以及全生命周期安全的对策，并分享了安恒信息在安全领域所输出的产品和能力，让用户能够放心上云，放心地使用大数据。

  

![](../Images/f224f09832c64f47caeb5b4646347f31.png)

  

  

**赋能人才，颁发乌兰察布大数据安全分析师资格证书**

  

论坛同时为参加大数据安全人才训练营认证培训的学员颁发资格证书，来自乌兰察布全市各个事业单位的20余名学员获得“CISP-BDSA”证书，中央保密办副巡视员陈荣辉、中国信息安全测评中心副处长张晓菲、乌兰察布市网信办副主任吕佐鹏、公安部三所原驻京办主任王刘健等领导为学员颁奖。本次培训，旨在通过理论和应用场景相互结合的安全培训，夯实学员技术基础，同时用案例教学培养专业人员的应用实践能力，以弥补安全技术手段的不和落后，帮助乌兰察布市事业单位正确的分析安全数据，从海量数据中识别攻击活动，掌握完整的网络和信息安全风险脉络，为我国关键信息基础设施的安全运行提供技术保障。

  

注册信息安全专业人员-大数据安全分析师（Certified Information Security Professional-Big Data Security Analyst，简称CISP-BDSA）是中国信息安全测评中心实施的大数据安全分析专业技术人员国家认证。**2018年4月，由中国信息安全测评中心授权的安恒信息新技术领域考试中心正式运营**，双方共同负责CISP-ICSSE、CISP-CSE、CISP-BDSA资质证书知识体系的开发维护、业务推广、市场宣传及持证人员的服务。截至目前，已有上百学员通过培训获得专业认证。

  

近些年来,信息技术飞速发展,尤其是互联网的出现和应用的普及,信息技术成为推动经济社会发展的强大动力。2019草原云谷大数据安全高峰论坛的成功举办，是乌兰察布市牢牢把握大数据发展大势，充分发挥区位优势，致力打造“草原云谷”战略的体现。**安恒信息将继续以科技创新为本，扎根区域，将自身多年积累的网络安全能力，赋能到乌兰察布，助力乌兰察布网络安全走向新发展。**
