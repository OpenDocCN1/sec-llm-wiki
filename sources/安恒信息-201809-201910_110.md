# 安恒信息发布“全流程防御”安全网关 打造下一代安全防护体系

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650466864&idx=1&sn=d58dfa07bbc9a54893b4875294d58f1d&chksm=bef344498984cd5f472659495b829411286af78dfe48b3dbb6677136076890252e4a684b7de2&scene=126&sessionid=1681366947#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650466864&idx=1&sn=d58dfa07bbc9a54893b4875294d58f1d&chksm=bef344498984cd5f472659495b829411286af78dfe48b3dbb6677136076890252e4a684b7de2&scene=126&sessionid=1681366947#rd)

  

***New***

**安全网关新版本  
**

号外号外！安恒信息正式发布**明御安全网关新版本**！

  

新版本将秉持安全可视、简单有效的理念，以资产为视角，构建“事前+事中+事后”全流程防御的下一代安全防护体系，并融合传统防火墙、入侵防御、病毒防护、上网行为管控、VPN、威胁情报等安全模块于一体的智慧化安全网关。

  

  

全新升级的安恒明御安全网关新版本，能解决哪些问题？那就要从现阶段防火墙存在的问题说起。

  

**缺乏有效的联动分析**

***1***

当前，大部分网络安全设备都有一个“通病”：日志量太多，且不能结合业务形成有效的安全状态分析。这一问题，导致了攻击发生却不能及时在日志中发现；大量无效的日志淹没了关键日志，对攻击的取证和溯源造成很大的困扰；各类攻击的日志分别呈现，管理员在分析时无法有效关联。

  

**安全策略繁杂、管理困难**

***2***

安全策略是防火墙安全防御建设的基础，有数据显示，因安全策略配置不当导致的安全事件超过40%。

*   等保2.0中对访问控制有要求：应删除多余或无效的访问控制规则，优化访问控制列表，并保障访问控制规则数量最小化。  
    
*   因系统管理员安全意识不高，多数防火墙安全策略any全放行，给攻击者有机可乘。
    
*   管理人员经常更换，导致大量策略处于“无人认领”，旧策略不敢删，策略管理更困难。
    

  

**新型网络攻击防护能力不足**

***3***

近年来各种攻击破坏能力提升，传统的安全检测手段难以对付未知威胁攻击。攻防双方力量不均衡和信息不对称的博弈，推动着防火墙厂商从传统的威胁响应方式，快速迁移至提供网络空间安全解决方案。

  

**防护流程不完整**

***4***

传统信息安全建设，以事中防御为主，缺乏事前预防和事后分析取证的闭环安全保障能力。

  

  

基于防火墙存在的问题和不断变化的市场需求，安恒信息推出**“全流程防御”安全网关**，一改传统防火墙安全策略繁杂、防护流程不完整等现状，**实现攻击链可视化分析、威胁情报与防护建议、安全策略评估等功能**，增强感知维度，合理控制风险，提升安全效能。

**新版本价值**

  

**资产风险识别，安全防护无死角**

  

安恒明御安全网关采用主动扫描和监控主机流量的方式，识别网络中的资产信息。通过以资产为视角对各种安全事件进行关联分析统计，便于管理员定位风险主机，并根据关联的威胁事件进行针对性的防护。

  

**策略精确分析，策略管理更简单**

  

安恒明御安全网关通过策略分析引擎梳理问题策略，计算策略精确度，给出策略调整建议。让每一条策略直观可视，更易于使用和维护管理。

  

**全网威胁情报，未知风险可防护**

  

安恒明御安全网关基于大数据关联分析得到的威胁情报，可以推动组织快速发现内网未知威胁、0day攻击等，准确发现内部失陷主机，结合威胁情报提供的丰富上下文信息，帮助组织提前做好安全防范、快速进行攻击检测与响应。

  

**攻击链分析，事后回溯更清晰**

  

安恒明御安全网关通过对检测出的威胁时间日志进行汇总分析整理，以攻击链的形式可视化展示攻击者的入侵路径、入侵程度等。精确、简单、统一、有效，便于管理员对内部网络进行分析，对攻击者进行取证溯源。

  

**全流程防御，闭环体系更安全**

  

事前感知预警 -> 事中防护响应 -> 事后分析取证溯源，并持续检测分析，帮助企业大幅度降低安全事件产生的不良影响。
