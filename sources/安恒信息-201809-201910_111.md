# 103家单位入选第八届CNCERT网络安全应急服务支撑单位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650466863&idx=2&sn=1834685ab7855b4e9ee350419a1384b5&chksm=bef344568984cd408d821164775a770b33d6a707e410f09e2d2a3305d43352d9f1c59408c5db&scene=126&sessionid=1681366947#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650466863&idx=2&sn=1834685ab7855b4e9ee350419a1384b5&chksm=bef344568984cd408d821164775a770b33d6a707e410f09e2d2a3305d43352d9f1c59408c5db&scene=126&sessionid=1681366947#rd)

2019年7月17日下午，国家互联网应急中心（CNCERT）在2019年中国网络安全年会上举行了第八届网络安全应急服务支撑单位授牌仪式，为103个支撑单位授牌。  

本次支撑单位遴选工作自2019年4月起启动，经自主申报、提名推荐、专家评审、结果公示等环节，共选出103个支撑单位，其中国家级11个、省级69个、反网络诈骗领域5个、工业控制领域18个，包括国内主流网络安全企业、电信运营企业、IDC企业、安全设备厂商、云服务提供商和反网络诈骗、工业控制等领域的技术优秀企业。  

国家互联网应急中心自2004年起启动网络安全应急服务支撑单位遴选工作，经过多年发展，支撑单位逐渐成为我国网络安全应急体系的重要组成部分。面对国家网络安全保障新形势新要求，国家互联网应急中心将不忘初心，牢记使命，坚持以习近平新时代中国特色社会主义思想特别是习近平总书记关于网络强国的重要思想为指导，扎实开展网络安全工作，与各支撑单位加强协作，共同推动构建国家网络安全应急技术支撑体系，坚决维护国家网络安全，助力网络强国建设，为实现“两个一百年”奋斗目标、实现中华民族伟大复兴的中国梦贡献力量。
