# 安恒信息再次独家中标中国移动漏洞扫描产品集采

近日，安恒信息明鉴网站安全监测平台凭借着过硬的实力，再次**独家入围**中国移动漏洞扫描产品集采。

  

作为唯一的中标单位，安恒信息将为中国移动通信集团公司、各省有限公司提供全面的Web应用漏洞扫描系统，该系统应用于中国移动全国各部门的应用安全检查工作，直接提高各类应用系统的安全水平，从而保障业务系统的运行支撑能力，推动整个移动行业的信息安全建设。

  

在此次Web漏洞扫描产品集采中，中国移动针对产品的漏洞探测能力、IPv6网站探测能力、集中控制能力、页面发现率、漏洞误报率及漏报率、扫描速度等多方面能力要求进行了全方位测试，从产品的稳定性、成熟度、系统可靠性等多个维度对产品的真实能力进行了综合评估，并从中国移动多个网络环境中各种应用场景出发，对产品性能及实际效果进行了客观的评判。最终，**安恒信息明鉴网站安全监测平台通过了严格的测试，以100%份额成功入围**。

安恒信息已连续四届入围中国移动Web漏洞扫描集采，作为国内最早推出商业版Web漏洞扫描的公司，将持续保持创新、突破。

  

全球知名咨询机构IDC发布了的《中国Web 应用安全市场看法，2018》报告显示，安恒信息作为第一批推出 Web 应用安全解决方案的厂商，为客户提供"事前检测预警"+"事中防御响应"+" 事后取证分析"+"持续监测分析"整体 Web 应用安全生命周期解决方案，在竞争性和成长性两个维度考量中均名列前茅，入选中国Web应用安全市场“领导厂商”。
