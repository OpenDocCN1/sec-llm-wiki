# 安全成就联接价值 2019西湖论剑工业互联网安全分论坛看点

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650465935&idx=2&sn=a15e28d3cbf186ffd3e5f8dc5234d483&chksm=bef348f68984c1e0b512be0d0f4c065c65b1ecc356a9deacf64dd5d973cd6f2f037caeef4bbd&scene=126&sessionid=1681366978#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650465935&idx=2&sn=a15e28d3cbf186ffd3e5f8dc5234d483&chksm=bef348f68984c1e0b512be0d0f4c065c65b1ecc356a9deacf64dd5d973cd6f2f037caeef4bbd&scene=126&sessionid=1681366978#rd)

4月21日上午，2019西湖论剑·网络安全大会工业互联网安全分论坛正式举办。来自全国主管部门、企业行业等12位专家学者就“安全成就联接价值”这一主题展开了分享，通过全方位系统解读工业互联网系统、剖析工业互联网相关案例、发布蓝皮书等，分析工业互联网发展现状及趋势，旨在为工业互联网的健康发展提供强有力的网络安全保障新思路。

  

![](../Images/8ddf0607235568dbb8f62e6e6dd93864.png)

  

本次论坛由国家工业信息安全发展研究中心副主任何小龙主持，工业和信息化部网络安全管理局网络与数据安全管理处处长付景广、浙江省经济和信息化厅副厅长吴君青出席论坛并致辞, 江西省工业和信息化厅副厅长蒋文定、江西省信息安全测评中心主任任丽民、江西省工业和信息化厅电子信息处处长陈伟涛出席会议。

  

随着网络信息技术的发展，我国由消费互联网正逐步走向工业互联网。在工业互联网中，云计算、大数据、人工智能、物联网等产业快速兴起，并与传统产业相融，形成新业态。

  

工信部网络安全管理局网络与数据安全管理处付景广处长认为，工业互联网是第四次工业革命的关键支撑，通过实现人机物的全面互联，构建起全要素、全产业链、全价值链、全面连接的新型工业生产制造和服务体系，是促进传统产业转型升级，实现制造业高质量发展的重要驱动。

  

![](../Images/0899fa5aa525996406249adcc1c0948d.png)

*工信部网络安全管理局、网络与数据安全管理处 付景广处长*

  

在工业互联网安全分论坛上，国家工业信息安全发展研究中心副主任何小龙，江西省工业和信息化厅副厅长蒋文定，杭州安恒信息技术股份有限公司董事长范渊，江西省国家保密局总工程师、江西省信息安全测评中心主任任丽民一同发布了《江西省工业信息安全态势蓝皮书》（以下简称“《蓝皮书》”）。

  

![](../Images/2b5ae8765c3024d87cd101479437d7b0.png)

  

《蓝皮书》重点从工业信息安全总体态势、江西省工业控制系统现状、江西省工控系统网络安全状况分析、下一步工作建议等方面对全省工控态势进行阐述。此外，《蓝皮书》也为关注工业信息安全发展的政府机构、企业、科研院校以及相关单位和个人提供了参考和帮助。

  

消费互联网上的安全问题还在继续涌现甚至发酵，比如大数据下如何保障个人隐私；而工业互联网的发展，尤其是人工智能、云计算、智慧城市等新兴技术的应用，让新兴的安全挑战也不断出现。

  

安恒信息工业互联网安全事业部副总经理叶鹏在论坛上发表主题报告，他认为，隐蔽式攻击是工业控制网络中面临的最大的威胁，也是最难防护的。隐蔽式的过程是违背了生产过程的攻击，所有的命令和报文都符合正常协议规约，只是违背了工业生产的生产逻辑，并导致了危险的状况。叶鹏说，工业控制网络中的异常行为和风险，都会反映在生产的运行数据中。构建一体化的运营中心，实现控制网络中资产和运行数据进行描述与可视化呈现，监测运行数据的异常，及时发现控制网络中复杂的安全状态和威胁行为，利用配套防护的手段，及时阻断风险行为。叶鹏最后还强调，回到工业控制本身，应该认识工业企业之间安全需求的差异性，通过向工业企业提供定制化运营方案，建设覆盖工业企业不同需求的技术、产品、管理互补的三位一体防护体系，来代替安全解决方案的通用性。

  

![](../Images/ce77a8567530006295f4983bec8672fe.png)

*安恒信息工业互联网安全事业部副总经理叶鹏*

  

数字时代已经到来，在未来智慧城市这个庞大的系统中，工业互联网支撑着海量网络数据的流通。工业互联网不是一个单独的产业，工业互联网需要更多产业的融合、更多技术的注入，在此过程中，网络威胁的增加会很大程度地制约工业互联网的发展。因此，持续聚焦网络空间安全技术的研发投入，注重网络安全技术的发展有利于提升工业互联网的持续发展，有利于安全社会、安全中国的建设。
