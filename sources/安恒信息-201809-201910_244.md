# 智慧城市安全要做“多选题”

智慧城市从来都不是单一领域发展的产物，而是多技术、多领域协同搭建，抓好大数据、云计算、人工智能、区块链等新一代信息技术与传统产业的深度融合，从而催生一系列的新技术、新产品、新产业、新业态和新模式，促进经济的发展。

  

建设新型智慧城市是实现数字中国、智慧社会的有效途径，是经济发展的内生动力，智慧化发展是当前及未来城市建设及转型发展的主旋律，是“利政、强企、惠民”等城市发展需求的必然选择。

  

然而安全问题一直伴随着信息技术的发展，特别是智慧城市这个复杂而庞大的系统工程，更是面临着诸多的安全风险与挑战。

  

**面对安全问题，智慧城市安全要做“多选题”，即A.人工智能、B.区块链、C.云计算、D.大数据，四个选项一个不能落下。**

**主题：数字经济时代下的智慧城市与信息安全建设**

  
◆◆亮点抢先看~◆◆

**亮点一：发布《数字经济时代的智慧城市与信息安全》**

《数字经济时代的智慧城市与信息安全》一书是安恒信息智慧城市系列的第四部作品，记录了范渊团队对数字经济和智慧城市建设的客观认识，讲述了大数据对城市发展和经济社会带来的机遇与挑战，提出了在全球数字化的大背景下，智慧城市建设如何促进经济、社会和产业的发展，如何为数字经济发展提供基础支撑。并重点围绕城市数字化、数字产业化和产业数字化过程中的安全问题，提出可行的解决方案，切实保障城市的安全运行。

  

**亮点二：杭州市数据资源管理局与安恒信息联合发布《政府数字化转型下的数据安全防护实践指南》**

《政府数字化转型下的政务数据安全实践》旨在为数字政府建设过程中的政务数据安全防护提供一套最佳的方法实践。聚焦政府数字化转型下的政务数据安全问题，结合安恒信息在全国多个城市的项目经验，从组织、制度、技术体系建设以及数据生命周期的安全运营保障等方面构建政务数据安全保障体系框架，并基于对行业内主流安全技术的研究，给出了政务数据安全保障体系建设的最佳实践。
