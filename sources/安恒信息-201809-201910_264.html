当前，绝大多数的业务都是基于浏览器完成的，Web服务器成为黑客首要的入侵对象。2018 年，Web 缓存欺骗攻击技术、票据欺骗、云出血、高级 Flash 漏洞系列等多个针对 Web 服务器的攻击漏洞被连续曝出，大量重要信息被盗取。随着公有云、行业云的快速发展，越来越多的Web 应用从传统的数据中心迁移到云上，云环境下的Web 应用安全防护愈发复杂，Web应用安全防护依旧严峻。


日前，全球知名咨询机构IDC发布了最新的《中国Web 应用安全市场看法，2018》报告，介绍了中国Web 应用安全市场发展，分析市场发展动力、厂商竞争格局，并提出如何建设 Web 应用安全防御体系的建议。


安恒信息作为第一批推出 Web 应用安全解决方案的厂商，为客户提供"事前检测预警"+"事中防御响应"+" 事后取证分析"+"持续监测分析"整体 Web 应用安全生命周期解决方案，在竞争性和成长性两个维度考量中均名列前茅，入选中国Web 应用安全市场“领导厂商”。

 


Web应用安全定义


IDC定义：Web 安全产品基于软件、设备、SaaS 和虚拟平台的形式部署，可防御入站威胁(恶意软件)和出站威胁(数据泄漏)。


Web 安全市场包括四个子市场: 

  • Web应用防火墙：应用程序防火墙可监视进出服务器的Web流量，尝试阻止网络钓鱼、SQL 注入和跨站点脚本攻击。

  • URL过滤产品：可基于网站URL来阻止访问某些网站，以防止网络钓鱼、恶意软件和其他威胁攻击。

  • Web反恶意软件：产品通过基于签名、白名单或其他技术，可防止间谍软件和病毒入侵，并阻止用户下载恶意软件。

  • Web内容过滤产品：可基于网站内容来阻止访问某些网站，以防止网络钓鱼、恶意软件和 其他威胁攻击。



市场规模大、增长快速


全球数字化转型进程加速，Web应用无处不在，针对Web应用的安全防护受到普遍关注，IDC 认为，在当前网络攻击形势下，Web 应用安全市场快速增长的趋势将保持不变。

 

2017 年，中国 Web 应用安全市场规模为 US$142.6M，同比增长 18.8%。IDC 预计，未来五年中国 Web 应用安全市场市场仍将保持稳定的增长，到 2022年，总市场规模将达到 US$381.7M，2017–2022年的复合增长率将达到 17.8%。


2018年，Web 应用安全市场发展有着强大的驱动力。《网络安全法》的发布，标志着网络安全问题已经上升到国家高度。后续配套的标准与法规将逐步落地，网络安全建设在各个行业铺开，其中Web安全更是不容忽视的重要环节。而一批防机器行为攻击、浏览器隔离、动态白名单、文件杀毒和机器学习等新产品和新兴公司涌现，为Web 应用安全市场注入创新活力。


IDC报告分析，传统的数据中心，Web 应用防火墙(WAF)仍然是保护 Web安全的主要安全产品；而当大量业务逐步向云迁移，虚拟 WAF 成为租户的首选；针对 Web 站点的远程监测服务也成为一种发展趋势，实时监测网站安全状况、快速响应。另外还有一种新的变化趋势，Web 应用程序防火墙已经从需要大量调优的本地产品转变为通过订阅交付的托管解决方案。安全厂商可以通过将其与拒绝服务攻击防御和其他防御系统相结合来阻止对关键网站的攻击，从而提供 WAF 即(WAF-as-a-Service)服务。这种交付模式正受到大型企业的欢迎，一些内容交付供应商增加了面向中端市场的入门级产品。



给技术买家的建议


在《中国Web 应用安全市场看法，2018》报告中，IDC向用户提出了在选择Web安全产品时的建议：


1、自查资产，摸清家底：通过可视化的相关技术识别自身资产的运行状况

2、接纳新技术：积极采用人工智能、机器学习等新技术的Web安全产品

3、云租户的选择：需要采用与云平台兼容的虚拟化 Web 安全软件或 SaaS 化的 Web 安全服务

4、合理的安全解决方案：提升 Web 应用系统的安全性


下面，我们来逐一分析：


1、自查资产，摸清家底

企业经过多年发展，拥有大量的Web服务器，其中包含了被闲置的、未被使用的“隐形”服务器，甚至还有员工私自搭建的Web 服务器。这无疑增加了网络管理员的管理难度，同时也给攻击者预留了可乘之机。IDC建议，企业需要对自身的Web资产有清晰、全面的认识，开展有效的梳理，并可通过可视化的相关技术识别自身 Web 资产的运行状况，加强对Web 资产的检测防御和安全治理。


摸清家底的方法，可以是主动和被动的方法“双管齐下”：


1、利用扫描器对全网web资产进行扫描，通过识别目标资产所开放的端口和服务进行分析是否存在“隐形”资产。


2、基于对流量的检测，实时快速地发现Web 资产，具有更高检测效率以及准确率，业务运转零损耗。



2、接纳新技术

为有效防范攻击者利用新型技术进行攻击，在防范Web 攻击的过程中，IDC建议采用融入防机器行为攻击、人工智能、机器学习等新技术的 Web 安全产品。


AiLPHA大数据实验室对于机器行为问题采用AI人工智能分析，通过长时间的机器学习训练以一周时间为一个周期的呈规律性分布的时间序列数据，web网站访问量数据满足该规律。任意时刻的数据与之前几周同时刻数据应该符合高斯分布，利用 3-sigma 准则进行异常检测。AiLPHA大数据智能安全分析平台充分融合人工智能、机器学习等新技术，网络流量刻画加持AI异常检测，发现实体行为异常引发的未知安全威胁，对机器行为有较高的判别度。



3、云租户的选择

对于在云环境中部署业务系统的用户，无论是在公有云、行业云或私有云，都需要采用与云平台兼容的虚拟化 Web 安全软件或 SaaS 化的 Web 安全服务。


在云环境下，构建全方位的SaaS云安全运营中心，成立一套包括风险监测预警机制、威胁情报机制、攻击防护溯源机制和应急响应机制为一体的云安全平台，通过大数据流量处理，提供详细的可视化监测报告，开展一系列的安全态势感知、Web应用防护及DDoS攻击防护等工作。 



4、合理的安全解决方案提升 Web 应用系统的安全性

面对普遍而复杂的网络攻击，不能完全依赖一种安全技术或产品，而应该通过解决方案将产品、技术、服务有机融合，形成完整的Web整体解决方案，更为有效地提升 Web 应用系统的安全性。


针对不同的应用场景和应用需求，安恒信息都具备完整的解决方案：AiLPHA大数据智能分析平台基于大数据技术的多源异构安全数据收集服务，分布式复杂事件处理引擎，安全建模与运营编排框架，攻击溯源与威胁回放能力，实现剔除误报精准告警，提升安全运维响应效率；玄武盾全方位SaaS云安全监测防御系统，是包括事前安全检测+事中实时防护+事后分析加固的整体Web安全解决方案，能够精准覆盖各类 Web 应用攻击，实现高达 2.5T DDoS 防御， 提供IPv4/IPv6 双栈转换安全防护等，同时配置 7x24 小时安全预警机制与应急响应机制，风暴中心400运营中心值班室常年保持全天候的值守理念，实行体系化安全运维支撑。
