# 完美诠释安全企业的社会价值丨安恒信息协助杭州“净网行动”获表彰

**每个企业都有其存在的价值，有些是追逐利益，有些远不止如此。**

  

“净网行动”即“净化网络环境专项行动”。2014年4月，为依法严厉打击利用互联网制作传播淫秽色情信息行为，全国“扫黄打非”工作小组办公室、国家互联网信息办公室、工业和信息化部、公安部发布公告，在全国范围内统一开展打击网上淫秽色情信息“扫黄打非净网2014”专项行动，自此，净网行动正式启动，至今已持续开展多年，在各地部门的共同努力下，收效明显。全国净网行动全面展开后，杭州市公安局立即开展地方专项行动，包括侵犯公民个人信息线索排摸、打击整治各类网络犯罪行为。  

彼时，作为以技术安身立命的网络安全企业，当“网络强国”的国家战略提出之时，安恒已经开始思考：**除了企业自身经营，我们是否可以为国家和社会再多做些事情？**

2016年，为配合杭州市公安局净网专项行动，安恒信息从公司技术团队中挑选精英，组成专项服务小组，协助杭州市局开展专项工作，至今从未间断。2018年，随着公司规模扩大，这支虚拟团队的人数已经增加到数十名，除了协助杭州市公安局网络警察分局开展专业网络安全监测、保障、应急处置等网络安全管理工作，他们利用多年磨炼的安全攻防与服务能力、结合专业安全产品，为杭州市公安局网警分局提供专业网络安全技术支撑。

1月28日，年关将至，杭州市公安局网警分管领导一行莅临安恒信息杭州总部，对于安恒信息在杭州公安“净网2018”专项行动中的出色表现，特别向安恒信息授予锦旗——**净化网络空间 弘扬社会责任**，安恒信息安全服务部副总裁袁明坤代表公司接受表彰。分局领导对于安恒信息为社会网络安全环境净化与保障作出的突出贡献，以及在专项行动中表现出来的技术专业度予以肯定。

![](../Images/0ed1e2134290403c3debfc8e524cffc3.png)杭州市公安局网警分管领导一行向安恒授予锦旗

除了对安恒信息的整体认可，杭州市公安局网警分局还特别授予公司4位安全服务人员“**净网之星**”奖杯，以表彰他们在本次支撑服务中的杰出贡献。

![](../Images/a888a2656a01fabdb0601e44a02e462f.png)4位安恒信息技术人员被授予“净网之星”奖杯

杭州“净网2018”专项行动开展以来，已成功侦破侵犯公民个人信息案件80余起，抓获犯罪嫌疑人200余人，打掉犯罪团伙35个，缴获各类公民个人信息1300万余条，铲除了一系列侵犯公民个人犯罪产业链条，特别是针对房产、中介、物业等行业侵犯公民个人信息乱象进行了严厉打击。未来，净网行动还将持续开展，更深、更广，其中对技术力量的支撑需求也会更高，而安恒将会是这支绿色保护军背后固定的身影，发挥所长践行初心，助力安全中国。
