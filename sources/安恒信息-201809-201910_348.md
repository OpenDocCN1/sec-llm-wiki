# 安恒信息荣获“国家重大活动网络安全保卫、国家网络与信息安全信息通报优秀技术支持单位”等五项荣誉

1月10日，国家网络与信息安全信息通报机制和国家重大活动网络安全保卫技术支持单位2018年度工作总结及表彰会议在北京瑞安宾馆举行。

  

![](../Images/b72b04b2e4204b382e89d5898c5b4476.png)

  

公安部网络安全保卫局总工程师郭启全主持会议，七处处长祝国邦、九处处长盘冠员、十处处长黄小苏参加会议并发表重要讲话，分别介绍了各处2018年年度工作及点评了优秀技术支持单位及先进个人。

  

鉴于在国家重大活动网络安全保卫技术支持、国家网络与信息安全信息通报技术支持等工作中表现突出，杭州安恒信息技术股份有限公司（简称：安恒信息），被国家网络与信息安全信息通报中心和公安部网络安全保卫局分别授予“优秀技术支持单位”称号，并获得“国家重大活动网络安全保卫技术支持单位”授牌。

安恒信息副总裁周丽萍、金龙分别被国家网络与信息安全信息通报中心和公安部网络安全保卫局授予“先进个人”称号。

安恒信息本次荣获五项荣誉，衷心感谢公安部网络安全保卫局领导给与的充分认可与鼓励。

 

![](../Images/a02870af3d8db5347bbbb8eb9971c608.png)

 

近年来，我国先后成功主办了抗战胜利70周年庆祝活动、G20杭州峰会、“一带一路”高峰论坛、厦门金砖会晤、青岛上合峰会、中非合作论坛、中国首届国际进口博览会、夏季达沃斯论坛、博鳌亚洲论坛、中国东盟博览会、世界互联网大会等一系列国际重大活动。在公安部党委和活动安保组的统一领导下，公安部网络安全保卫局牵头会同有关单位、网络安全专家和技术支持单位圆满完成各场重大活动网络安全保卫任务，为活动的顺利举办作出重要贡献。

  

自2007年成立以来，安恒信息多次参与国家级网络安全保卫工作，共投入10000+人次，参与网络安全保卫活动100余场（如G20杭州峰会、敦煌丝绸之路、世界互联网大会、北京“一带一路”高峰论坛、厦门金砖会议、中国共产党十九次全国代表大会、青岛上合峰会、北京中非论坛、中国首届国际进口博览会、世游赛等），为我国重要会议及大型活动的顺利举办保驾护航，共收到近百封感谢信。

  

仅2018年一年，安恒信息共计投入数千人次安全专家及众多安全产品，成功拦截数亿次攻击，达到全程0安全事件发生，圆满完成三十几个重大活动的安保工作。

  

如2018年中国首届国际进口博览会活动中，为了更好地开展进博会网络安保工作，肩负起助力安全中国的责任与使命，安恒信息历经数月的筹备，专门成立了由范渊亲自挂帅的安保领导小组，落实人员分工，设立了特别专家顾问团，为进博会网络安全工作献计献策，贡献网络安全保障力量。安恒信息保障进博会官网提供正常访问3.84亿次，所有攻击均在3分钟内完成处理、拦截，官网访问一切正常。

  

以世界互联网大会为例，该会议是由国家互联网信息办公室和浙江省人民政府联合主办的世界性互联网年度盛会。安恒信息作为连续五届世界互联网大会网络安全保卫主要支持单位，成立了专职网络安全保障团队，对相关重要信息系统实行7\*24小时实时监测，百人安全专家团队轮番值守，累计阻断攻击超亿次。

  

安恒信息具备完善的网络安保体系流程，从会前筹备，到安保方案设置，公司根据会议规模有严格的人员配置标准，并自上而下的执行。十一年来，安恒已经总结了自己的一套网络安保打法：重设计、摸底数、掌态势、分轻重、勤演练、强值守、深防护、构闭环、人为本、要常态。并且安恒信息在网络信息安全通报机制建设、追溯分析、重大活动网络安全保障等方面具有明显的技术优势。依托自主研发的大数据态势感知平台的全网威胁感知能力、通报预警能力、快速处置能力、关联分析能力、追踪溯源能力，以及玄武盾网络安全防护能力、流量清洗能力，可以为重保信息系统构建覆盖“事前监测”+“事中防护”+“事后溯源处置”的全生命周期的整体安全解决方案。此外，安恒信息数百人规模的安全研究及团队及安全服务团队，具备对0day漏洞、蠕虫爆发、勒索病毒等网络安全事件的快速响应及深度分析能力，成功经受住struts2高危漏洞、“永恒之蓝”等多次重大险情的考验，广受赞扬。

  

构筑网络安全防线，保卫国家网络安全。在网络安保的道路上，安恒信息从未松懈。未来，安恒信息也将不断提高网络安全服务保障专业能力和手段创新，结合关键信息基础设施安全防护管理平台、大数据技术、云监测及云防护技术、网络安全保卫服务经验，为国家重大活动网络安全保卫工作再立新功。
