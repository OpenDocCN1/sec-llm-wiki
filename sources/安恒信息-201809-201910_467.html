安恒信息入选“2018年度浙江省专利示范企业名单”

安恒信息

网络安全前沿资讯、 应急响应解决方案、技术热点深度解读

关注

近日，由浙江省知识产权局、浙江省经济和信息化委员会发布的“2018年度浙江省专利示范企业名单”新鲜出炉。安恒信息等154家企业成功入选，有效期3年。

据了解，评选浙江省专利示范企业，是为了进一步推进浙江省企业专利工作，充分发挥专利制度在促进企业技术创新，增强企业核心竞争力中的作用，提高企业创造、管理、保护和运用知识产权的能力。


安恒信息自成立以来，专注于产品研发，每年的研发投入占年度销售收入的20%以上，对核心技术已申请了相关的知识产权保护，现已申请341件国家发明专利，拥有已授权国家专利44件（其中发明专利38件，实用新型专利5件，外观专利1件），拥有商标注册证书34件，已获得计算机软件著作权95项。


安恒信息拥有众多的专利产品：明鉴 Web 应用弱点扫描器、明鉴数据库漏洞扫描系统、明御 Web 应用防火墙、明御数据库审计与风险控制系统、明御综合日志审计系统、明御运维审计与风险控制系统、明御 APT 攻击（网络战）预警平台、明鉴信息安全等级保护检查工具箱、明鉴网站安全监测平台、明御安全网关、明御 Web 业务安全审计系统、明鉴自动化渗透测试平台、明御攻防实验室、安恒网站卫士网页防篡改系统、明鉴远程安全评估系统、网络安全态势感知通报预警管理平台、玄武盾、明御全流量深度威胁分析系统、安恒 AiLPHA 大数据智能安全平台、安恒应用及数据库深度防御审计系统等。
