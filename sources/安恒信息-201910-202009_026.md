# 今晚8点30！安恒信息海特实验室亮相网络安全届“3.15晚会”

![](../Images/c10e3a53dee9c32c3fd9f3f1746e3529.png)

  

作为**2020国家网络安全宣传周**系列重要活动的创新之举、“网络安全 e同守护”特别节目，将于**9月17日晚8点30分**在郑州揭开面纱，并通过电视、网络等多家平台面向全国播出。

  

![](../Images/8239b25b4542dcf17e2f23b3bb9b7796.png)

图：“网安周”特别节目进行彩排

  

届时，**安恒信息“**黑科技**”将会亮相晚会现场**，通过郑州演播厅与安恒信息创新体验中心进行连线，两地同台直播演绎。

  

![](../Images/ad982b199167be97da69c26edabbb96e.png)![](../Images/aa28e77af38fd078a0bbd17d400abd1a.png)![](../Images/f0895c9f490b94b12c21dd6a5d397367.png)

图：节目录制花絮

  

据了解，**“网安周”特别节目以“网络安全 e同守护”为主题**，旨在提醒广大民众，维护网络安全不仅是政府需要承担的重要责任，更是需要每位公民从自身出发，一起共同努力、共同应对。只有同心共筑网络安全防线，才能保障经济快速健康发展，人民生活稳定繁荣。  

  

**特别节目有什么？**

  

“网安周”特别节目将通过案例专题、互动实验、网友互动、情景剧等多种方式，聚焦“个人信息泄露”、“网络诈骗”、“网络谣言”等重要网络安全问题。

  

安恒信息安全研究院海特实验室受邀参加本次互动实验！在期间，安恒信息将展示一些自主研究的黑科技实验，借以提高人民群众的个人隐私保护意识，快来一起看看**海特实验室**的“神秘老师傅”吧！

  

  

**怎么看？**

  

**2020年国家网络安全宣传周特别节目，将于9月17日20：30至22：00在河南卫视全程直播**，并通过人民日报、新华社、央视频、央视新闻客户端、腾讯视频、哔哩哔哩、今日头条、百度百家号、抖音、快手、微博、触电新闻、郑州晚报郑州+、正观客户端、澎湃等多家平台同步直播。
