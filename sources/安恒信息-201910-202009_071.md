# 范渊辽商总会演讲：这些安全领域都要敲响警钟！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650474657&idx=2&sn=634387eea1514051fd17e407e30144eb&chksm=bef2a6d889852fce39cd41bcfb2b8722562c46d01aa37e08cf844c57a2d2129e75ebfd073361&scene=126&sessionid=1681366786#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650474657&idx=2&sn=634387eea1514051fd17e407e30144eb&chksm=bef2a6d889852fce39cd41bcfb2b8722562c46d01aa37e08cf844c57a2d2129e75ebfd073361&scene=126&sessionid=1681366786#rd)

随着新兴技术的加速发展，数字经济已经充分地渗透和应用到生产、生活的各个领域，并引发新一轮市场变革。如何把握时代脉搏，占领前沿高地，是每个企业家需认真思考的问题。8月24日，由辽商总会主办，软件和电子信息委员会、辽宁ICT生态俱乐部承办的“**和你-共进数字经济时代**”专题论坛召开。

  

杭州安恒信息技术股份有限公司董事长、浙商总会青年企业家委员会副主席、辽商总会会员范渊担任本次专题论坛的演讲嘉宾，发表题为**《数字经济时代的安全挑战与实践》**的演讲。

  

  

![](../Images/1973fb78651e3961530129d0e16a08ae.png)

  

  

**数字经济时代的安全挑战**

  

当前，我国面临着复杂严峻的内外部形势挑战。范渊认为，国家的主权与安全是关键基础设施安全的基本屏障，网络空间安全、关键基础设施安全需要相应的基础支撑条件。近几年发生了多起关键基础设施安全事件，以“委内瑞拉电厂停电事件”为例，根据安恒Sumap分析，发现以下三个关键问题：

  

**①国家网络资产测绘：**网络发展落后，设备类型简单；

**②网络安全测绘：**存在大量高危害漏洞，补丁升级缓慢；

**③关键网络设施测绘：**大量暴露面，容易被攻击。

  

这些问题告诉我们，网络安全防控能力薄弱，难以有效应对有组织的高强度网络攻击。如今，在数字经济时代，数据是一种经济生产工具和战略资源，对数据的使用，需要**在确保数据安全的前提下，发挥数据资源的经济价值**。范渊为我们指出，数字经济时代将迎接数字产业化、产业数字化和城市数字化。

  

**•数字产业化：**数据成为新的生产要素，数字产业化过程伴随数据安全、隐私保护问题和挑战；

**•产业数字化：**以工业互联网为代表的产业升级转型，新旧动能转换，这其中效能是核心要素，安全是重要挑战；

**•城市数字化：**万物互联，云、网、端的协同，构筑数字经济的基础设施，以城市大脑为核心的新一代城市基础设施面临着更加严峻的安全挑战。

  

范渊提到，数据作为新的生产资料，在流通和使用过程中产生新的价值，数据“流动”将成为常态，打破了传统的数据边界，带来了全新的挑战。诸如：缺乏法律法规和规章制度的约束、数据供应链参与方责任边界模糊、数据的跨界流通带来的监管难题、传统数据安全防护技术难以适配。

  

  

**网络安全法和等保合规2.0**

  

2017年6月1日，《网络安全法》正式施行。作为我国首部网络安全法，对数据应用进行规范，明确对公民个人信息安全进行保护。范渊指出，《网络安全法》的实施具有以下几个重要意义：**明确了网络主权原则、保障网络数据安全、关键信息基础设施、打破部门壁垒、对个人信息的保护**。

  

![](../Images/919fc6636e4ef32251de7eb2cd9da1da.png)

  

而**等保2.0标准**于2019年正式实施。等级保护2.0为应对新技术对传统安全和传统等保的冲击，通过安全扩展要求提出了新的安全要求，以保障云计算、大数据等新技术下安全合规。同时增强了对未知威胁的防范要求，针对邮件攻击威胁提出邮件安全要求，提出统一管控，要求能够对攻击进行溯源和取证。  

  

在建立主动安全保障体系上，等保2.0感知预警、安全分析、动态防护、全面检测、应急处置并重，打造主动安全保障体系，避免为合规而合规，切实提高信息系统网络抗攻击能力。更加注重数据安全保障和个人信息保护，数据是IT的核心和生命，个人信息保护在互联网时代被无限放大。

  

  

**为数字经济时代保驾护航**

  

网络安全问题正在变成一个大数据分析问题，大规模的安全数据需要被有效关联、分析和挖掘。而大数据AI助力将成为关键，能从数据巨大、结构复杂、类型众多的数据中快速获得有价值信息的能力，能够揭示传统手段所看不到的内容和变化趋势。

  

![](../Images/ffb055c3c3206fcf47496ddd35939fd0.png)

  

演讲现场，范渊以安恒信息的AiLPHA深度感知智能引擎DSI为例，为大家深度分析了资产行为异常检测场景，并以某三甲医院感染勒索病毒案件智能分析研判整个感染过程。  

  

疫情催生了“非接触式”在线新经济。疫情期间安恒信息利用人工智能、大数据和云计算等技术测绘全国医疗行业系统，并提供**无感知情报服务**，监测发现全国504个重点医疗机构存在被黑客控制的安全事件，涉及13,887个网站。无感知地监测告警省内重要医院出现勒索病毒感染事件，现场取证发现，系统已被控制。

  

范渊指出，**一切产品皆资源，一切资源皆服务**，新型安全服务运营中心需要**数据化、智能化、自动化、集约化、实战化、闭环化**。数字经济下，新技术的应用可能会带来更丰富的应用场景、更高的生产效率，彰显着共创的价值，但也可能会在各个方面提出挑战。我们当安于责任，恒于创新，让安全跃进升级。

  

  

  

此外，安恒信息董事长范渊于同日在东软集团进行参观交流，与东软集团董事长兼首席执行官、辽商总会会长、中国电子协会常任理事刘积仁博士就数字经济的变革与挑战展开了深入探讨。
