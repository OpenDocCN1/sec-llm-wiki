# 构建信创新生态，人大金仓与安恒信息签署战略合作协议

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650473742&idx=1&sn=a44b51c9d9213bbb93d3448b9eaec370&chksm=bef2ab77898522612afc1d8dbdffc48e706481142e31ccaa36db0595866ce78ffbb2d6a6e576&scene=126&sessionid=1681366796#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650473742&idx=1&sn=a44b51c9d9213bbb93d3448b9eaec370&chksm=bef2ab77898522612afc1d8dbdffc48e706481142e31ccaa36db0595866ce78ffbb2d6a6e576&scene=126&sessionid=1681366796#rd)

8月7日，北京人大金仓信息技术股份有限公司（以下简称“人大金仓”）与杭州安恒信息技术股份有限公司（以下简称“安恒信息”）战略合作签署仪式于安恒大厦顺利举行，未来双方将在信息技术应用创新领域展开深入合作，共同推进数据安全解决方案。现场，**人大金仓总裁杜胜和安恒信息董事长范渊出席仪式并共同签署了战略合作协议。**

  

![](../Images/e49eef4c03b7c204c9f69bb08f608bd0.png)

  

在复杂的国际环境下，我们面临着日益严峻的网络安全形势挑战，也让我们清晰地认识到核心技术受制于人是我们发展过程中最大的隐患。在信息技术应用创新的浪潮下，网络安全领域正在不断探索构建信创新生态。

  

**人大金仓总裁杜胜**在仪式现场发表了讲话。他表示：国家出台了一系列网络安全办法和指导意见，也明确提出了对安全性和可控性方面的审查，可以预见未来对信创领域有较强的指引作用。人大金仓自1999年创立以来，依托中国人民大学信息学院在数据库技术领域长期教学科研的深厚积累，其研发的国产数据库产品在技术和实用性方面都已达国内领先、国际先进水平，已成为中国数据库领域第一品牌。此次与安恒信息的战略合作，将发挥自主研发优势，出台合作落地的方案，期待未来双方在合作中推出一系列的产品与服务解决方案。

  

![](../Images/73afab0e4dec3d855380daba507e2d03.png)

  

信创根基依靠行业，只有在行业中不断积累，才能厚积薄发，方能更好地为行业赋能。**安恒信息董事长范渊**在讲话中表示，网络安全与信创是融为一体的，网络安全是信创的安全基石，作为网络安全服务商，安恒信息希望和信创体系伙伴一起，构建安全的信创网络安全生态。此次合作将深化合作内容、落实合作措施，本着“共同发展，协作共赢”的原则，安恒信息将在数据安全领域继续深耕细作，提供信创安全管理解决方案。

  

![](../Images/1e50f2f04175d4ca940b33f51a196bb9.png)

  

值得一提的是，2020西湖论剑·网络安全线上峰会首次“剑指”信息技术创新应用，特别开设信创分论坛。信创作为国家战略，未来信息化的基石，其重要性不言而喻，在当前后疫情新基建的大背景下，对于信创市场的想象空间充满期待。此次战略合作也标志双方将共同推动信创产业发展，安恒信息将与合作伙伴共同经历历史、携手创造历史。
