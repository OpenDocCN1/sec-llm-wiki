# 安恒信息战略布局上海浦东新区 落地中国智慧城市安全总部

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650470735&idx=1&sn=57063dc09948ebeca7dca93d233d3c57&chksm=bef357368984de203ff3be06fd3df15c713292c8f97ba3d7e01c41ed73dd1848184aca557578&scene=126&sessionid=1681366821#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650470735&idx=1&sn=57063dc09948ebeca7dca93d233d3c57&chksm=bef357368984de203ff3be06fd3df15c713292c8f97ba3d7e01c41ed73dd1848184aca557578&scene=126&sessionid=1681366821#rd)

近日，安恒信息发布消息称，拟于上海浦东新区，落地安恒信息中国智慧城市安全总部。

  

![](../Images/fcf275fc5d919c067e575701ee713dcf.png)

  

上海市委常委、副市长吴清，上海市委常委、浦东新区区委书记翁祖亮，上海市政府副秘书长陈鸣波，上海市政府副秘书长、浦东新区区委副书记、区长杭迎伟，上海科创办执行副主任、浦东新区区委常委彭崧，浦东新区副区长管小军，上海科创办专职副主任侯劲、吴强、王鼐，自贸区管委会张江管理局副局长付军、张丁发、吴俊等领导出席了签约仪式。

  

此次，安恒信息战略布局浦东新区，打造中国智慧城市安全总部，重点投资建设**“一基地二研院三中心”**，即智慧城市安全研发研究与运营基地，安全芯研究院、AI研究院，网络犯罪大数据侦查处置作战中心、网络安全高级威胁分析预警中心及企业安全防护中心。

  

安恒信息中国智慧城市安全总部将聚焦智慧城市与重点行业领域的新基建、新场景，研发研究具备真正的城市级感知、智能防护产品，提升全天候应急运营能力，致力于打造智慧城市安全中国样板，服务政府和企业数字化转型，在新基建的浪潮下，护航数字新经济。

  

![](../Images/bf12fd4a9a3986274e6bbaeaec51d1db.png)

  

正如安恒信息董事长范渊在发言中表示：安恒信息作为一家专注于网络信息安全领域的高新技术企业，非常期待进一步深化双方间的合作，下好“先手棋”、筑牢“防火墙”、加上“安全锁”，为新时代的智慧城市建设和数字经济发展做出积极的贡献。
