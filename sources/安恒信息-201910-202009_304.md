# 安恒信息多款云安全产品，入驻AWS Marketplace China

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650468971&idx=1&sn=d11c2558ae25c27cf7e82075c5b6a99f&chksm=bef35c128984d5047cbc34189821fe456452bf8b7ab57cd1202a88681bf6ee4712682574fcab&scene=126&sessionid=1681366847#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650468971&idx=1&sn=d11c2558ae25c27cf7e82075c5b6a99f&chksm=bef35c128984d5047cbc34189821fe456452bf8b7ab57cd1202a88681bf6ee4712682574fcab&scene=126&sessionid=1681366847#rd)

3月27日，安恒信息宣布，安恒信息**云WAF 、云堡垒机、云数据库审计三款产品现已上线AWS Marketplace China**，可供客户使用。

  

2020年1月， AWS  Marketplace 在中国全面上线。AWS Marketplace China是一个精挑细选的数字化产品目录，它使客户能够轻松查找、测试、部署和管理他们在 AWS 中国（北京）区域和 AWS 中国（宁夏）区域上运行系统所需要的第三方软件。借助 AWS Marketplace China，客户可以从这一应用软件商店查找和比较软件产品，并在登录其 AWS 中国账户后，几分钟内快速启动预配置的软件。客户可以在AWS Marketplace China官方网站 (https://awsmarketplace.amazonaws.cn/) 或Amazon Elastic Compute Cloud (Amazon EC2) 控制台中找到 AWS Marketplace China。

  

![](../Images/0f3198a2ce76f3f96e1d1a7eec9ae474.png)

  

安恒信息作为获得AWS 能力计划安全能力认证的APN合作伙伴，为客户提供云监测、云防御、云审计、云服务等一系列产品和服务，遵循云安全合法合规政策，帮助客户加速公有云应用，助力客户云战略的开展、价值最大化。

  

**入驻AWS Marketplace China的产品需经过精心挑选与严格的安全性及易访问性验证，安恒信息首批上线的云WAF 、云堡垒机、云数据库审计三款产品在安全性、合规性等方面都通过了AWS的测试****。**客户可以根据自身特定需求场景、业务目标等方面综合考虑，自由进行产品组合，用以解决不同的网络安全问题：

  

**云WAF：**对网站及APP业务流量进行多维度、深层次的安全检测和防护，拦截各种异常攻击行为，防护高精准、低漏报、低误报，取证溯源攻击行为，监控网站业务状态，感知整体安全风险趋势；提供覆盖"事前+事中+事后"的全生命周期Web应用安全防护解决方案。

  

**云堡垒机：**结合了各类法案法规对IT运维管理与IT内控外审的要求，集成身份鉴别、单点登录、授权管理、运维审计、自动运维等功能，解决云计算环境中用户的IT运维管理风险，适用于云平台上所承载各类网络资产的云管控和云审计。

  

**云数据库审计：**提供安全合规、行为监控、风险识别、业务优化四大核心能力。对数据库的访问行为进行监控，并通过内置的安全规则识别出数据库访问行为中的可疑行为并实时触发告警，可直观地查看到每个数据库系统的整体运行情况。同时，云数据库审计满足等级保护的评测要求。

  

通过这些产品，安恒信息可以帮助 AWS 中国客户构筑坚固的网络安全防线，使客户将安恒信息的安全服务无缝集成到业务全生命周期中。

  

  
  
  

  

如何在AWS Marketplace China网站上，快速找到安恒信息安全产品，并进行订阅启用呢？

  

第一步：通过AWS Marketplace China官方网站搜索框，搜索安恒信息。

![](../Images/ab5d476713eb9524c9a0438c7d77eb1c.png)

即可查看安恒信息所有上线的产品。  

![](../Images/5a52b4983651c70d8e7ebfaeb352041f.png)

  

第二步，选择产品，并在产品页面选择右侧“继续订阅”。按照步骤提示，接受协议、继续配置、启动该软件……一步步操作即可。

![](../Images/a328e9b3314d24f192c43977d3d9c4fa.png)

  

  

  

  

“我们很高兴能够在AWS Marketplace China上线多款云安全产品，并将持续推动网络安全能力的集成，打造易用、便捷、安全的产品和解决方案，确保云上用户的安全需求。”安恒信息董事长范渊表示。

  

安恒信息基于10余年网络安全行业专业积累，在云端打造全生命周期的安全整体解决方案。涵盖公有云、私有云、混合云等不同环境，兼容国内外主流的云平台，现已广泛应用于政务云、警务云、医疗云、金融云、教育云、企业云等重要行业领域。
