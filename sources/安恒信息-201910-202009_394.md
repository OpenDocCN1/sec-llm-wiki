# 微软宣告Windows7系统停服，安恒EDR助你抵御安全风险

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650468351&idx=1&sn=0dd8450561ca3576c44e815ab7946b44&chksm=bef341868984c890d23d1487a966d3983ca812db60ab25756129ebcc05b726bc4f1b2e1510ec&scene=126&sessionid=1681366877#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650468351&idx=1&sn=0dd8450561ca3576c44e815ab7946b44&chksm=bef341868984c890d23d1487a966d3983ca812db60ab25756129ebcc05b726bc4f1b2e1510ec&scene=126&sessionid=1681366877#rd)

![](../Images/7cf2befc8248e54272da27e818d4c8be.png)

  

此前，微软正式宣告Windows7系统（以下简称“Win7”）于1月14日停止更新，官方停止技术支持、软件更新和安全问题的修复。

![](../Images/7437fa961e1ced72dc663406686b50e8.png)

（图片来源于网络）

  

很多用户可能有点慌，Win7停服，部分没有技术支持的电脑系统就处于“裸奔”状态。如何应对网络攻击、恶意威胁等安全风险，保障系统安全呢？

  

安恒信息安全专家建议用户，尽快升级到Windows10或者其他操作系统；如果仍然使用Win7或是过渡期，建议安装主机防护系统进行加固。安恒信息提供了以安恒EDR为主的安全防护方案。

  

安恒EDR是一款具有系统加固防护，网络加固防护的主机安全管理系统，全面保障用户系统安全。

  

**01  
**

**安恒EDR将持续为Win 7系统提供安全补丁**

安恒EDR会跟微软提供的补丁保持同步状态，只要后续微软再次给Win7系统提供特殊紧急补丁，安恒EDR将会第一时间跟进更新。

  

针对日前爆出的微软CVE-2020-0601漏洞，安恒EDR已第一时间更新策略库。此漏洞主要影响Windows 10、Windows Server 2016/2019、Windows Server 1803/1903/1909版本。Windows 10 之前的版本，例如Windows 7、Windows Server 2008 R2 等不受到该漏洞的影响。

  

**02  
**

**安恒EDR将会进行升级增强Win 7等系统防御**

对于微软未对Win7安全问题提供方案的，安恒EDR也会通过后续版本升级增强防御，保护用户系统安全。

  

**03  
**

**安恒EDR现有的解决方案已足够应对部分风险**

安恒EDR目前的提供的技术和功能(包括但不限于主动防御、勒索&挖矿防御、微隔离等)针对所有的支持系统，包括Windows XP和win7等系统。

  

**04  
**

**协同联动，纵深防护体系**

安恒EDR与安恒旗下安全产品能有效联动，形成一体化防护解决方案，满足风险发现、主动防御、应急处置等要求，实现对Win 7系统的全方位保障。

  

  

  

  

据相关数据统计，Win7仍占有非常高的市场份额，特别是在国内，Win7在政府机关、卫生教育等行业占比甚高。因此，系统安全防护至关重要。安恒信息将持续为网络和终端系统用户提供安全保障，抵御安全风险，提升安全能力。用户可拨打安恒信息服务热线：**400-6059-110**，获取更多的技术支持服务和安全建议。
