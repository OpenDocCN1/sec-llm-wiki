# 安恒信息接连荣获“盘古”“伏羲”“影响力企业”三项奖项

持续耕耘，收获认可，捷报频传。近日，安恒信息收到中国关键信息基础设施技术创新联盟、ToB行业头条颁发的多项奖项。多方认可体现了各界对安恒信息坚守职责、坚持创新的肯定，以及对安恒信息继续开拓创新、不断进取的期待。

  

**1**

  

**不断创新 聚焦关键信息基础设施安全**

![](../Images/69f7c2767e9ea1333c0d8fc676139b0a.png)

  

2019年12月26日，第二届金融关键信息基础设施保护论坛暨2019关键信息基础设施安全优秀产品、解决方案评选活动颁奖仪式在京举办，论坛由中国关键信息基础设施技术创新联盟主办。

  

论坛进行了“2019关键信息基础设施安全优秀产品、解决方案评选”颁奖典礼。**安恒信息AiLPHA大数据智能安全平台荣获“盘古奖”****（优秀产品之技术创新奖）**，**天池云安全管理平台荣获“伏羲奖”（优秀解决方案之技术创新奖）**。安恒信息已连续两届收获奖项，2018年，安恒信息天鉴关键信息基础设施安全防护管理平台获得“盘古奖”（优秀产品之技术创新奖）。

  

![](../Images/6731aab30790b2a5a24f058aea232353.png)![](../Images/0e51490e4ef49b2dea762e730d0fd0b3.png)

  

据悉，评选活动共收到238个评选项目申报材料。其中，126个产品类项目和61个解决方案类项目进入复审。在复审阶段，邀请了业内领导和专家组成专家组，专家组在评审中，从材料的规范完整、技术的创新性和应用的前景三个方面逐个项目集体讨论并打分，最后采用加权计算平均分遴选入围项目提交公示。

  

**AiLPHA大数据智能安全平台**能够有效发现、预警和联动安全设备处置网络安全威胁、异常活动和突发事件。加强了对重点网站和重要信息系统的安全监督管理，同时对互联网网站与在线信息系统进行全网检扫，掌握网站的基本信息如网站指纹信息、网站安全、网站数量等情况，发现和堵塞了安全漏洞，确保关键信息基础设施的安全。目前，平台产品已经全面应用于政府、税务、金融、运营商、能源、医疗、军工等多个行业，为用户提供了可靠的关键信息基础设施安全保障能力，推动了大数据安全分析技术的进步和成果化。

  

**天池云安全管理平台**是安恒信息根据对云计算多年的深入研究和风险分析，结合自身在安全领域多年的经验及技术积累，打造的专门针对云上安全的安全产品，旨在帮助用户解决云上的安全问题。天池通过不断的汇聚云安全能力，帮助用户构建一个统一管理、弹性扩容、按需分配、安全能力完善的云安全资源池，为用户提供一站式的云安全综合解决方案。

  

**2**

  

**持续赋能 行业影响力显著提升**

![](../Images/69f7c2767e9ea1333c0d8fc676139b0a.png)

  

日前，ToB行业头条发布了“2019 ToB影响力企业榜”，**安恒信息入选“2019年中国ToB行业的影响力企业”**。

  

  

![](../Images/b972440bafd46b6ee65b7c4d9f9b0fec.png)

  

2019ToB行业影响力价值榜单评选，是由3W产业媒体中心发起，联合50+投资机构、100+行业专家及研究机构，共同参与评审、传播的ToB领域评选活动。

  

其中，ToB影响力企业榜主要表彰中国ToB市场中，能够一直产生重大影响力的企业。自开启榜单报名通道以后，吸引了国内数百家优质ToB企业报名参与，经由多家投资机构、媒体及行业专家历时数月的评审，共有30家ToB企业脱颖而出，成为2019年中国ToB行业的影响力企业。

  

  

已经在科创板上市、全球网络安全创新500强之一的安恒信息，成为网络安全细分领域的佼佼者。凭借创新的技术能力和领先的服务能力，多次荣获权威机构认可。安恒信息围绕应用安全、大数据安全、云安全、物联网安全、工业互联网安全等领域，为用户提供全生命周期的安全监测与防护整体解决方案，现已在众多行业落地，持续多年保持国内市场占有率领先的行业地位。
