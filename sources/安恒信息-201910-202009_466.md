# 两场签约仪式，都为打造网络安全人才摇篮

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650467931&idx=1&sn=9b93dc0105c542ac72d698c0ca783d06&chksm=bef340228984c9348189f52d2826dd40c6e3a1f392e439c71ea061f39c11b2a53c78ca9756d7&scene=126&sessionid=1681366902#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650467931&idx=1&sn=9b93dc0105c542ac72d698c0ca783d06&chksm=bef340228984c9348189f52d2826dd40c6e3a1f392e439c71ea061f39c11b2a53c78ca9756d7&scene=126&sessionid=1681366902#rd)

**吉林警察学院&中玖集团&安恒信息**

![](../Images/e8878eedb25b4567f81f80e291efc844.png)

  

日前，吉林警察学院、杭州安恒信息技术股份有限公司、吉林省中玖科技发展有限公司举行校企合作签约仪式。

  

三方将依托各自优势、资源，秉承“校企合作、工学结合、优势互补、资源共享、互惠双赢、共同发展”的宗旨，从产学合作协同育人、成立网络安全联合实验室、建立网络安全人才培训基地、联合开展科研课题及科研成果转化与推广合作等方面着手，共同建立校企合作平台，进行全面的校企合作。   

  

![](../Images/17a80f81fff932b9685ff99a03ece4d2.png)

吉林警察学院党委副书记钟新文、中玖科技总经理李延杰、安恒信息副总裁苗春雨代表三方签署协议。

 

![](../Images/f5f093371e34e683f7dca15752281709.png)

  

钟新文书记详细介绍了学校的办学历史、理念以及规模，同时介绍了信息安全人才培养的现状。他介绍，随着公安行业对信息安全人才需求的急剧上升，吉林警察学院不断加强在信息安全领域的人才培养和教学创新，近年来为公安输送了大量的人才。希望能借此次校企合作进一步助推学校在网络安全与执法、计算机科学与技术等方向的人才队伍建设。

 

中玖科技董事长杨金峰、安恒信息副总裁苗春雨纷纷表达了对此次校企合作的信心和决心。苗春雨表示，安恒信息一直致力于通过校企合作、协同育人等方式助力网络安全人才培养，服务国家网络安全人才战略。并在产教融合，警企合作方面积累了宝贵经验。希望未来能与吉林警察学院、中玖科技形成良好的多元合作模式，凝练网络安全产学研合作成果，打造合作育人品牌。

![](../Images/b07a7a9ff638cf82a83d0a2020399825.png)

  

  

![](../Images/e8878eedb25b4567f81f80e291efc844.png)

**新龙集团&安恒信息**

![](../Images/e8878eedb25b4567f81f80e291efc844.png)

  

11月14日，中共灵寿县委副书记、县长冯素伟等一行莅临安恒信息参观指导，并见证了安恒信息与新龙集团战略合作签约仪式。

![](../Images/81649175a898aa757ceed15172b7ab96.png)

  

基于国家网络空间安全人才战略导向、《网络安全法》等国家法律法规对提升全民网络安全素养的要求，结合本地区域经济发展对网络安全教育培训的需求，安恒信息与新龙集团将在网络空间安全人才培养和网络空间安全人力资源服务方面开展合作，建立一套网络空间安全人才培养体系和一套服务北方区域辐射全国的人力资源服务体系，打造北方地区人才培养、科技创新和产业发展良性生态。

  

在与会领导们的见证下，安恒信息高级副总裁冯旭杭、新龙集团产教融合研究院院长刘军池签署合作协议。

![](../Images/798a4da684ef4f76e14a7de98122c00c.png)

  

签约仪式前，与会嘉宾还一同参观了安恒信息安全创新体验中心和网络空间安全学院，进一步了解安恒信息前沿技术、应用实践，以及人才培养体系。

![](../Images/4f9b547193eaf8741f99d6268fbe25eb.png)

  

关于新龙集团：创立于1995年，业务涉及软件与服务、软件人才培养和人才服务。新龙集团是河北省政府批准的股份制软件企业，被科技部认定为“国家火炬计划软件产业基地骨干企业”。

  

  

安恒信息与北京航空航天大学、广州大学、中国矿业大学、山东科技大学等全国多所高校达成战略合作，并且通过政校企合作、产学研合作等模式，不断为网络安全人才的养成提供更多可能的成长途径，打造网络安全人才培养的特色品牌。
