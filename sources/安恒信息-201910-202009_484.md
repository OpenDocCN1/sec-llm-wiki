# 成功登陆科创板，安恒信息开启2.0时代

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650467811&idx=1&sn=841f0f2150906d7bab01894172f7b92a&chksm=bef3439a8984ca8cdfc7f9ff61d1d775aa73ba55e6d6f98ec28b636abfc5dc97ad740cae2bc3&scene=126&sessionid=1681366907#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650467811&idx=1&sn=841f0f2150906d7bab01894172f7b92a&chksm=bef3439a8984ca8cdfc7f9ff61d1d775aa73ba55e6d6f98ec28b636abfc5dc97ad740cae2bc3&scene=126&sessionid=1681366907#rd)

2019年11月5日，安恒信息在上海证券交易所科创板挂牌上市，这是安恒信息里程碑意义的大事，也是国内网络安全领域的一件盛事。  

![](../Images/d5f8c890a303bd483b66d332bc4c6b45.png)

*来自浙江省市领导及相关领域的代表在上海证券交易所共同见证了这一难忘时刻。  
*

  

安恒信息董事长范渊在接受人民网采访时表示，2019年11月5日是科创板提出一周年，这是资本市场非常重要的改革，科创板有可能成为中国的纳斯达克。科创板的舞台也鼓励我们企业今后更加专注核心技术的积累和持续竞争力的培养，为网络强国、数字中国战略服务。

  

上市首日，安恒信息开盘价75元，涨32.74%；截至收盘，股价报79.06元，涨39.93%。对于上市首日股价表现，范渊表示：“我们立志成为最好的企业，这其实是不容易的，既要有很好的成长，又要有持续的积累，但我对公司未来整个发展充满信心。”

  

在接受新华网采访时，范渊表示，成功登陆资本市场后，这是一个新的开始，安恒信息要坚持网络安全创新发展，坚定不移的服务于数字中国、网络强国的国家战略。

  

登陆科创板这也意味着开启了安恒企业的2.0。范渊表示，我们必将不忘初心的安恒基因放到新的高度，也必将在责任和创新上达到新的极致，回报客户、回报投资者、回报团队、回报社会。

  

**创新引领，“硬科技”支撑企业发展**

![](../Images/a6c6e04bd5986ea66cc05295cc83c231.png)

众所周知，科创板非常看重企业的技术创新和研发投入，并且将研发占营收比作为判断企业研发投入的重要标准之一。《中国信息安全》做了梳理：  

  

**从营业收入和研发投入来看**，安恒信息营业收入主要来源于网络信息安全产品及网络信息安全服务。

  

**在研发投入上**，安恒信息近三年研发投入占营业收入比例平均高达22.27%，该比例在目前已受理的50多家科创板企业里处于上游水平。另外，安恒信息采用内部培训、外部培训、激励制度相结合的方式，建立全方位的人才培养和激励模式。

  

**从产品和服务来看**，安恒信息围绕事前、事中、事后几个维度已形成覆盖网络信息安全生命全周期的产品体系，包括网络信息安全基础产品、网络信息安全平台以及网络信息安全服务。各产品线在行业中均形成了强竞争力。

  

**从核心技术来看**，作为科创企业，截至招股说明书签署日，安恒信息共拥有48项核心技术，其中22项是公司基于云安全、大数据安全、物联网安全和智慧城市安全等新兴安全领域进行深入研发积累所得。这些核心技术均来源于长期的技术投入和自主创新，拥有独立的知识产权，目前安恒信息拥有已获授权的专利66项（其中发明专利57项）、已登记的软件著作权153项。

  

**从销售模式来看**，安恒信息实行渠道加直销的销售模式，主要集中在政府（含公安）、金融机构、教育机构、电信运营商等单位，客户群体信誉度及诚信度较高。

  

**从社会责任来看**，安恒信息积极承担我国网络信息安全产业发展的社会责任，参与了众多国家与行业标准的制定；先后为北京奥运会、上海世博会、G20杭州峰会、厦门金砖会议、历届世界互联网大会、第七届世界军人运动会等提供网络安全保障服务。还为广大政府、企业及客户提供专业信息安全服务，建立了良好的市场知名度及行业口碑。

  

由此看来，安恒信息科创板上市可谓水到渠成。

  

**科创板带来新机遇，实现2.0跨越**

![](../Images/0e7b18c9a576fdb1c6ae8d272397b909.png)

科创板为网络安全产业带来了巨大机遇。此次科创板上市既是安恒信息自身发展的需要，也必将带动安恒信息实现崭新跨越。  

  

一方面，安全服务市场机遇显现。近年来，网络安全威胁日趋复杂多变，仅靠单一的安全产品已无法满足用户需求。风险评估、安全管理咨询、安全应急响应、安全托管服务等安全服务的作用备受重视，用户对安全服务的需求日益增加。网络信息安全市场持续向服务化转型，这意味着，安全服务业务未来将呈现高速增长态势。

  

据招股书数据显示，安恒信息营业收入主要来源于网络信息安全产品（营收占比约70%）及网络信息安全服务。所以安全服务市场的增长，对安恒来说无疑是实现营业收入高增长的重大机遇。

  

近年来，人工智能、5G、量子通信等具有颠覆性的战略性新技术突发猛进，大数据、云计算、物联网等基础应用持续深化。同时，伴随物联网市场规模的快速增长，设备、网络、应用也面临严峻的安全挑战，物联网安全将成为万亿规模市场下的蓝海。

  

安恒信息已开始布局，本次在科创板上市后募集的资金将围绕着云安全、大数据安全、物联网安全和智慧城市安全的发展方向对已有的网络信息安全产品进一步升级。

  

“随着万物互联时代的到来，网络安全已经成为数字化转型中全产业链全生命周期不可或缺的一环，忽视安全带来的后果可能是致命的，整个产业内生需求也越来越大。”范渊表示，在资本市场金融的助力下，结合科技的力量，相信安恒未来还将取得更快速更高质量的发展。
