# 安恒信息斩获双奖！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650489873&idx=1&sn=08e8fe68c3c0854eea65f45036978ec2&chksm=bef2ea688985637e322bedb5e424fb96f33a9e6c96fb10c57b337254f3c11c15171b430bcf95&scene=126&sessionid=1681366625#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650489873&idx=1&sn=08e8fe68c3c0854eea65f45036978ec2&chksm=bef2ea688985637e322bedb5e424fb96f33a9e6c96fb10c57b337254f3c11c15171b430bcf95&scene=126&sessionid=1681366625#rd)

近日，安恒信息在由中国信息通信研究院（以下简称“中国信通院”）参与主办的“众智护网”·2021年度防范治理电信网络诈骗创新实践案例征集活动和“2021数字化治理先锋实践征集活动”中双双获奖，分别获得**“2021年度信息通信行业反诈创新项目”与“智能安全与隐私合规类创新先锋解决方案”的荣誉**。

  

![](../Images/fcfea66da6ab106bb20ea053f28fcfd5.png)

  

![](../Images/dd658f3aa47026bb96c4044af37b759b.png)

  

**“天玑•网络诈骗预警平台”入选**“2021年度信息通信行业反诈创新项目”****

为坚决贯彻习近平总书记关于打击治理电信网络新型违法犯罪重要指示精神，落实国务院打击治理电信网络新型违法犯罪工作部际联席会议工作部署，进一步推动行业反诈技术治理创新，中国信通院联合中国互联网协会发起2021年度信息通信行业反诈创新实践案例征集活动，共收到来自基础电信企业、互联网企业、安全厂商等68个单位申报的107个创新项目，由安恒信息与浙江移动联合申报的“天玑•网络诈骗预警平台”项目凭借其创新性、良好的防范和打击效果以及广泛的用户认可度，**取得了前十的好成绩**，获得**“2021年度信息通信行业反诈创新项目”**称号。

创新项目有较强的前瞻性和示范性，如进一步加强推广应用，对有效提升全行业技术防范能力具有积极意义。

  

![](../Images/019263d05d292b1e91c52eecd639e7ed.png)

  

**“AiGuard数据智能安全管控解决方案”荣获“智能安全与隐私合规类创新先锋解决方案”称号**

在“2021数字化治理先锋实践征集活动”中，经过线上投票与专家评审双重评选，有 44家企业申报的案例入围了“最具价值应用案例”和“创新先锋解决方案”，分别在数字化运营、智能安全与隐私合规、法律科技、智能风控、数字化审计等领域展现出技术创新与应用价值上优势。安恒信息**“AiGuard数据智能安全管控解决方案”获得“****智能安全与隐私合规类创新先锋解决方案”**称号。

  

![](../Images/30c63b89f0892c136a12cb989d420afc.png)

  

现今，数据安全所面临的难题已转变为如何在满足数据安全和隐私保护的同时，去实现数据的流动和价值的最大化/最优化。进一步说，**“鱼和熊掌兼得”，即数据安全与价值挖掘，成为了数字化改革下的主旋律**。在此背景下，安恒信息大数据实验室创立了以“赋能数据开放、激活数据价值”为宗旨、“CAPE数据安全能力框架”为核心思想的AiGuard数据安全解决方案，通过对数据资源活动整个生命周期的全面覆盖，有效降低安全风险，保障数据安全。

此次双奖的获得，是行业对安恒信息实力的认可，也是对安恒信息在网络安全方面所作努力的肯定。秉承“助推数字经济，助力安全中国”的企业愿景，争做“数字经济的安全基石”，安恒信息将始终坚守企业初心，为祖国的数字化建设持续添砖加瓦。
