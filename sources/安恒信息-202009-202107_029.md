人脸识别时

摄像头拍到的可能不止是脸…

近日，教育博主 @法小岛 发微博提醒，大家使用App人脸识别功能时，一定要穿衣服！因为“**摄像头采集的不仅仅是被识别者人脸部分**”。该博主表示，有从事后台审核的朋友告诉他，工作中在进行人脸识别审核时，经常会看到很多人在洗澡、和另一半拥抱、没穿衣服等各种“奇奇怪怪”场景。

![](../Images/59e25bcff161bc09f1abd25c00c03680.png)

  

我们应该如何避免用户的隐私受到侵犯？一方面，需要在法律法规层面对技术背后可能出现的漏洞进行规避；另一方面，企业也需要尽到告知义务，广大用户也当加强隐私保护意识。

Windows 打印服务0 Day漏洞风险通告

2021年7月1日，微软提前发布Windows Print Spooler 远程代码执行漏洞（CVE-2021-34527）。当 Windows Print Spooler 服务不正确地执行特权文件操作时，存在远程执行代码漏洞风险。成功利用此漏洞的**攻击者可以使用 SYSTEM权限运行任意代码**，安装程序，查看、更改或删除数据；或创建具有完全用户权限的新帐户。

中国移动正式进军物联网芯片制造业

据中移芯片官微披露，中移物联网全资子公司芯昇科技有限公司于2021年7月正式独立运营。7月2日，芯昇科技有限公司成立仪式在北京隆重举行，公司**将围绕物联网芯片国产化，解决芯片内核卡脖子问题**，以促进国家集成电路产业振兴为目标，开展产品研发、生态建设及行业推广工作。

麻省理工创造出

可以实现排汗的智能皮肤

麻省理工开发出一种新的防汗材料，称之为 "电子皮肤"。其被描述为一种佩戴舒适、嵌入传感器的粘性贴片，能够监测佩戴者的健康状况，即使佩戴者出汗时也不会出现故障或从身体上脱落，这要归功于蚀刻在材料超薄层中的类似于人体皮肤毛孔的人工汗液管道。

我国完成智能网联汽车

第一阶段标准建设

全国汽车标准化技术委员会7日宣布，我国完成了智能网联汽车第一阶段标准体系建设。专家指出，这**标志着我国基本形成了能够支撑驾驶辅助及低级别自动驾驶的智能网联汽车标准体系**。十四五期间，我国将进一步优化完善智能网联汽车标准体系，加快高级别自动驾驶的标准体系建设。

国家网信办：

掌握超过100万用户个人信息运营者赴国外上市需审查

7月10日，国家互联网信息办公室发布关于**《网络安全审查办法（修订草案征求意见稿）》公开征求意见**的通知。征求意见稿包括了“掌握超过100万用户个人信息的运营者赴国外上市，必须向网络安全审查办公室申报网络安全审查”等内容。
