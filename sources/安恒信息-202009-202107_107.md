# 一场签约，安恒开启与徐州数字未来城建设的故事

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650487806&idx=1&sn=3d5afaa046b1c88b7020127734d19d38&chksm=bef2958789851c912b4c38594aaa856c9246251b5e021fbf7a50ef10c6a57fdf0ddbb3a91121&scene=126&sessionid=1681366655#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650487806&idx=1&sn=3d5afaa046b1c88b7020127734d19d38&chksm=bef2958789851c912b4c38594aaa856c9246251b5e021fbf7a50ef10c6a57fdf0ddbb3a91121&scene=126&sessionid=1681366655#rd)

![](../Images/eb647674980a95dea8b55f948b3d089c.png)

  

近日，安恒信息布局淮海经济区网络空间安全生态产业在徐州市成功打响第一枪，在2021徐州长三角（上海）投资推介会上，安恒信息签约徐州市鼓楼区人民政府。

  

双方将在城市安全大脑、工业互联网、信创产业、人才培养等方面展开深度合作，共同促进徐州新型智慧城市和数字经济发展。

  

![](../Images/ff01c15f690969f20f4b562a77ceab2c.png)

  

  

近年来，依托数字经济发展，徐州市高新技术产业、战略性新兴产业和“四新经济”，以及老工业基地产业转型升级取得显著成效。徐州人民政府精准定位数字未来城的发展目标，集聚更多高端生产要素，不断增强新产业、新模式、新业态的核心竞争力和辐射带动力，让徐州在淮海经济区的核心引领地位更加巩固、更加凸显。

  

![](../Images/d49e2905de375fd24165b6f2a2ebbaaa.png)

  

此次合作，双方将共同落实大数据及网络安全发展战略，携手建设智慧城市安全运营中心和“城市安全大脑”中心。同时重点关注新一代网络安全信息技术的研究与运用，围绕徐州传统优势行业，打造具有产业特色、行业引领的**工业互联网一站式云安全服务平台**和开放共赢的工业互联网发展新生态，赋能传统产业转型升级和高质量发展。依托双方产业和科研优势，建设**网络安全人才培育基地**，推动本地高校、科研院所在学科建设和人才培育领域的深度合作，共同培养网络安全高素质人才，促使徐州发展为全国有影响力的网络安全人才培育和人才输出的集散地。

双方充分发挥各自人才优势和技术优势建立安全运营机制，实现对全市全方位全天候保护、统一集中运营管理及常态化的威胁发现和应急处置，提升全市智慧城市的网络安全运营服务能力；打造徐州智慧城市安全底座，建立全程在线、全域覆盖、实时反馈的“城市网络安全空间态势”，优化安全防护策略，提升安全防护能力。
