# 范渊当选中国科学技术协会第十届全国委员会委员

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650487654&idx=1&sn=591573c13f081935f2077c13baea43fa&chksm=bef2951f89851c093c7566839f446c9de3968528b83bbe72ab8db68a62e7a3493a19e71561d2&scene=126&sessionid=1681366655#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650487654&idx=1&sn=591573c13f081935f2077c13baea43fa&chksm=bef2951f89851c093c7566839f446c9de3968528b83bbe72ab8db68a62e7a3493a19e71561d2&scene=126&sessionid=1681366655#rd)

![](../Images/d9ba72a3e3bb1b62b5d60c004487381a.png)

  

5月28日，中国科学院第二十次院士大会、中国工程院第十五次院士大会和中国科学技术协会第十次全国代表大会在北京人民大会堂隆重召开。

  

![](../Images/a630e359cd28d0ef7dfd29d293168d7e.png)

  

习近平总书记发表重要讲话强调，坚持把科技自立自强作为国家发展的战略支撑，立足新发展阶段、贯彻新发展理念、构建新发展格局、推动高质量发展，面向世界科技前沿、面向经济主战场、面向国家重大需求、面向人民生命健康，深入实施科教兴国战略、人才强国战略、创新驱动发展战略，把握大势、抢占先机，直面问题、迎难而上，完善国家创新体系，加快建设科技强国，实现高水平科技自立自强。

  

  

**以下为讲话内容全文：**

[《在中国科学院第二十次院士大会、中国工程院第十五次院士大会、中国科协第十次全国代表大会上的讲话》](https://mp.weixin.qq.com/s?__biz=MzAwMjU0MjIyNw==&mid=2651382682&idx=2&sn=27b4359911c533c4990126fc6137a931&scene=21#wechat_redirect)

 

**安恒信息董事长范渊作为科技工作者代表出席此次大会，并当选中国科学技术协会第十届全国委员会委员。**

 

![](../Images/48dd60596c28cd18d1aaa051fcfd4e57.png)

  

范渊在大会现场聆听总书记讲话后表示：“自从2007年回国创业后，十几年来深切感受到党和国家对人才和科技创新的重视。成长在这样一个时代，作为一个科技工作者和企业家是幸运的。”安恒信息于2019年在科创板上市，是在时代背景和优越的政策环境下必然收获的丰硕果实。

 

未来，安恒信息将以习总书记的指示为努力方向，在新时代建设世界科技强国号角的指挥下，重视自主可控的前沿技术研究，聚焦网络安全核心技术突破，着力培养网络安全复合型科技人才，注重企业的长期创新驱动能力，为建设新时代数字中国和世界科技强国做出更大的贡献！
