5亿名LinkedIn用户信息在黑客论坛出售




近日，一个宣称包含5亿条LinkedIn个人资料的数据包在黑客论坛中出售，卖家免费发布两百万条数据以供客户查验。泄露数据中的LinkedIn用户信息包括全名，电子邮件地址，电话号码，工作场所信息等。卖家表示数据是从LinkedIn上爬取的，根据提供的数据示例来看，泄露来源是爬虫。

虽然本次泄露的文件只包含LinkedIn个人资料信息，但这些信息已经足以让网络犯罪分子牟利并使受害者遭受损失。如果有黑客将泄漏文件中的信息与其他泄漏数据相结合，就可以发起网络钓鱼和漏洞攻击。

研究人员发现Bitter组织在野使用的0-day漏洞

































研究人员发现Bitter组织在攻击中使用Windows内核提权0-day漏洞（CVE-2021-28310），并上报给了微软。CVE-2021-28310漏洞等级为高危，攻击者可利用该漏洞在获得权限的情况下，构造恶意数据执行本地权限提升攻击，最终获取服务器最高权限。官方将该漏洞命名为Win32k本地权限提升漏洞。


受该漏洞影响的Windows版本如下：

● Windows 10 Version 1803, 1809, 1909, 2004, 20H2

● Windows Server 2019

● Windows Server version 1909, 2004, 20H2


当前微软已发布关于该漏洞的修复补丁，用户可通过以下链接进行安全更新：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-28310

Swarmshop卡商店被黑，62万张银行卡记录在暗网曝光


































Swarmshop信用卡商店的用户数据遭到泄露并被发布在一个地下暗网论坛，总共包含12344条信用卡商店管理员、卖家和买家的信息。


泄露的数据包括用户的昵称、哈希密码、联系方式、当前余额等等，涉及美国、加拿大、英国、中国、新加坡、法国、巴西、沙特阿拉伯和墨西哥等国银行发行的623036张银行卡。除此之外，还有498份网银凭证和69592份美国、加拿大社会保险号码共同遭到泄露。


虽然导致此次数据泄露事件的漏洞来源尚未调查清楚，但有研究人员从曝光的数据记录发现，有两名信用卡商店的用户曾试图注入恶意脚本，并搜索网站联系人信息功能中的安全漏洞。

IoT快播

DNS高危漏洞威胁全球数百万物联网设备



近日，Forescout研究实验室与JSOF合作，披露了一组新的DNS漏洞，称为NAME:WRECK。

漏洞存在于四个流行的TCP/IP堆栈中，即FreeBSD、IPnet、Nucleus NET和NetX，这些堆栈通常存在于流行的IT软件和IoT/OT固件中，影响全球数以百万计的IoT物联网设备。


其中，FreeBSD被广泛用于数百万个IT网络中的高性能服务器，包括Netflix和Yahoo等网络巨头的主要网络节点。同时，类似西门子Nucleus NET这样的IoT/OT固件也已在关键的OT和物联网设备中使用了数十年之久。


据初步评估，WRECK漏洞将影响众多行业与组织，包括政府、企业、医疗、制造和零售业等，仅美国就有超过18万台设备受到影响。不法分子可以利用这些漏洞使目标设备脱机，或者接管控制并执行操作。

一个App控制全球18万个网络摄像头，万名会员付费偷窥隐私“直播”



在北京市第三中级人民法院日前审结的一起案件中，被告人巫某某控制了全球18万个摄像头。


记者根据此案件调查发现，在部分社交软件中，不法分子通过较为隐蔽的方式出售已经被破解的摄像头ID和破解软件。例如，在QQ上，他们以“摄像头”为用户名吸引客户，在客户添加好友时，会收到提醒，需添加另一个名为“客服”的QQ号才能通过。


简单咨询后，客服人员会给出“价目表”。其中包括168元、238元的“家庭套餐”以及收费更高的“酒店套餐”和大学附近酒店，破解摄像头ID数量在12个至15个之间。当记者询问是否用某App（可公开下载的网络监控系统）进行绑定观看时，对方表示，现在不能用了，需换成另一款远程监控系统。


该客服列出的价目表中还包括摄像头破解软件，可扫描破解附近摄像头，价格为520元。随着相关部门和网络平台加强该黑灰产业的防范打击，这些违法资源价格也有所上涨，破解软件的价格上涨了200元，破解ID的单价也上涨了近一倍。
