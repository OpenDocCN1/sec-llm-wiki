# 2021西湖论剑·网络安全大会主题揭晓！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650484652&idx=2&sn=70904fa2a423e79366957adf1a8304b6&chksm=bef281d5898508c3ee242206877c1bb20a1d6203d5e6cefc1aa34124ae37f2afa21fc9206a99&scene=126&sessionid=1681366690#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650484652&idx=2&sn=70904fa2a423e79366957adf1a8304b6&chksm=bef281d5898508c3ee242206877c1bb20a1d6203d5e6cefc1aa34124ae37f2afa21fc9206a99&scene=126&sessionid=1681366690#rd)

4月6日，2021西湖论剑·网络安全大会（以下简称“西湖论剑”）媒体吹风会在杭州举行。浙江省互联网信息办公室副主任马晓军出席吹风会并介绍本届大会整体情况。现场，马晓军宣布了本届大会将围绕**“安全：数字化改革之根基”**这一主题于4月24日正式举行。

  

![](../Images/bc6a04642a3981fda55d8b74fcf113f3.png)

  

  

2021年的政府报告中，数字经济占了浓重的一笔。报告指出，**要加快数字化发展，打造数字经济新优势，协同推进数字产业化和产业数字化转型，加快数字社会建设步伐，提高数字政府建设水平，营造良好数字生态，建设数字中国**。  

随着我国进入高质量发展阶段，经济数字化转型加速，数字经济正成为撬动经济增长的新杠杆。网络安全作为数字化的基础，已成为数字经济、数字未来的重要防护屏障，在全球数字经济浪潮中，网络安全保障也成为了衡量国家之间竞争力的核心要素。

在《中华人民共和国国民经济和社会发展第十四个五年规划和2035年远景目标纲要》中，“网络安全”一词文中出现了14次，“数据安全”出现了5次，网络安全、数据安全已成为国家社会发展面临的重要议题，其保障体系和能力建设同时是对国家安全的有力维护。  

站在“十四五”的起点，**数字化改革亦是蓝图绘就的助推器、经济发展的优选项**。基于网络协同和数据智能的新基建，将技术乘数效应与数字赋能效应相叠加，将引爆数字经济一个又一个新的增长点，将重塑现代社会一个又一个新的生活样态。

  

  

作为数字经济创新策源地的浙江，近年来一直围绕数字浙江建设持续发力，目前已迈入了数字浙江的**第三个阶段——数字化改革**。2021年2月18日，浙江省召开全省数字化改革大会，发布《浙江省数字化改革总体方案》，尝试为全球数字变革写下“浙江方案”。

“数字化改革是政府数字化转型的一次全方位拓展和升级，是浙江立足新发展阶段、贯彻新发展理念、构建新发展格局的重大战略举措。”在今年全国两会期间，全国人大代表、浙江省委书记袁家军这样说道。

  

开启“十四五”，奋进新征程。2021西湖论剑·网络安全大会将以“安全：数字化改革之根基”为主题，于2021年4月24日在杭州举办。**作为“十四五”开局之年首场顶级网络安全盛会**，本届西湖论剑将面对网络安全治理的国际新形势，站在高起点从我国网络安全保障体系和能力建设的任务出发，为夯实网络安全保障体系和能力建设的基础，营造更加良好的网络安全环境目标而推进。

聚焦于安全，见证一个时代的呼啸而来；致力于安全，期待一个世界的厚积薄发。西湖论剑作为网络安全领域标杆会议，将多元解读网络安全产业政策、法规、标准，指明网络安全发展方向，为全球数字变革中的“浙江方案”献计献策。
