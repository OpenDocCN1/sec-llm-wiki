# 2021西湖论剑·网络安全大会4月24日开幕！(附报名通道)

“十四五”开局之际，2021年**国内首场顶级网络安全大会**伴着浓浓的春意来了。4月6日，2021西湖论剑·网络安全大会（以下简称“西湖论剑”）媒体吹风会在杭州举行。浙江省互联网信息办公室副主任马晓军出席吹风会并介绍本届大会整体情况。

  

![](../Images/346c2691933087594a3ba00406e7d165.png)

  

马晓军介绍，本届大会紧抓数字化改革重要历史进程，围绕“安全：数字化改革之根基”这一主题，设立一场主论坛、十二场分论坛和一场网络安全展览。大会将于**4月24日在杭州国际博览中心**举行，届时将进行线上同步直播。  

西湖论剑由浙江省互联网信息办公室、浙江省经济和信息化厅、浙江省公安厅、浙江省通信管理局、杭州市人民政府主办，由之江实验室、杭州市经济和信息化局、杭州市萧山区人民政府、国家计算机网络应急技术处理协调中心浙江分中心、浙江省网络空间安全协会、浙江省计算机信息系统安全协会、杭州安恒信息技术股份有限公司共同承办。杭州市数据资源管理局等15家单位联合承办。

  

网络安全突显时代关键词

2021年是“十四五”规划开局之年、全面建设社会主义现代化国家新征程起步之年，也是中国共产党成立100周年。当前，各地城市纷纷出台“十四五”规划和城市数字化转型行动方案，抢抓数字发展机遇。**推进数字化转型已经成为未来塑造核心竞争力的关键之举，也是城市治理体系和治理能力现代化的必然要求。**在这特殊的历史时期，数字化改革成为蓝图绘就的助推器、经济发展的优选项，也是未来社会发展的核心关键词。

网络安全作为数字经济、数字未来的重要防护屏障和基石，将在我国数字化转型时期起着不可替代的重要作用。在国家“十四五”规划中，14次出现“网络安全”，5次出现“数据安全”，可见强化安全保障同样成为未来五年国家社会发展的重要共识。今年，数据安全法、个人信息保护法即将出台，西湖论剑在关键历史节点上发布众多网络安全相关成果，将形成网络安全较为完整的发展框架，勾勒网络安全未来可能的发展路径，从而为数字化发展“保驾护航”。

今年，西湖论剑聚焦于筑牢数字化改革之根基，统筹安全与发展，为网络强国、数字中国建设扶辇同行。据介绍，今年的西湖论剑旨在推进三大任务。**一是助力新经济**，主要针对数字化重点优势的基础设施建设，形成新的数字优势，以数据安全与网络安全为数字经济社会保驾护航。**二是展示新成果**，本次大会将是对网络安全的最新理念、产品、趋势和方案充分的展现，让各企业和专业人士了解和洞察先机。**三是聚集新动能**，本届西湖论剑将面对网络安全治理的国内外新形势，站在高起点从我国网络安全保障体系和能力建设的任务出发，为夯实网络安全保障体系和能力建设的基础，营造更加良好的网络安全环境目标贡献智慧和动能。

  

三大创新提升大会含金量

诞生于数字经济创新策源地浙江的西湖论剑创始于2012年，历经近10年的砥砺前行，始终紧密契合国家网络安全战略，已成为**中国网络安全领域的金名片**。

本次大会是在抗击疫情取得阶段性重大胜利的背景下召开的首场大型标志性网络安全线下盛会。去年西湖论剑线上峰会曾经吸引了超过440万人在线观看，今年大会诸多创新内容更加值得期待。

据大会组委会透露，相较去年，今年的西湖论剑着力内容和形式三大创新。**从内容的深度看**，西湖论剑关注新型智慧城市安全，发布新型智慧城市安全指数，走访10个智慧城市，讲述不同城市的数字化、智慧化发展理念，让参观嘉宾能够现场感受新型智慧城市安全能力。**从内容的广度看**，2021年西湖论剑结合2022杭州亚运会的契机，西湖论剑还将携手杭州亚组委，齐聚杭州亚运会、成都大运会等国际赛事技术官员共话赛事网络安保，专门增设智能亚运安全分论坛，邀请国内外知名专家等为亚运网络安全建言献策。**从内容的形式看**，今年的西湖论剑拟设立院士对话、名企共商等环节，就网络安全发展进行探讨和对话。

此外，大会还拟举办专场音乐会，邀请中央歌剧院歌剧团围绕建党100周年尤其是近年来祖国飞速发展取得的成绩，邀请专业歌唱家、网络安全歌唱爱好者歌颂党和祖国，为建党百年献礼。同时，在展区打造了集网络安全、亚运知识于一体的互动游戏，以极具趣味的方式传递专业化知识。

西湖论剑顺应潮流更致力于引领潮流，本届大会邀请相关行业主管单位领导及行业专家解读网络安全产业政策、法规、标准，共同探讨影响社会民生的网络安全趋势。

大咖云集，群英荟萃一直是西湖论剑为业内所乐道的特色。此次大会将邀请多位院士等嘉宾，以圆桌聚群英，以论辩出真知。

自大会举办以来，西湖论剑始终坚持凝聚各方共识、汇集各方资源，以更团结、更全面的姿态为发展新格局持续发力。当数字化的触角不断延伸，网络安全议题的范围也不断扩展，通过从实体经济到云端平台的全维度探讨，必将促进数字化改革的根基打得更牢、扎得更深。

  

  

多项成果展示行业主脉络

作为网络安全行业的金名片，西湖论剑始终注重会议成果产出及行业发展赋能，力求将专业程度提得更高、成果链条拉得更长。

在行业会议之外，西湖论剑设立了网络安全创新成果展，展示网络安全的前沿技术和应用，还有网络安全黑科技破解等多个环节，让黑科技不再神秘。

大会将发布新型智慧城市安全指数、无人机安全白皮书等多个网络安全成果。系列成果都以生产生活相关的网络安全问题为切口，深度剖析网络安全的重要意义，引领相关行业的发展趋势。

作为2021年国内首场大型标志性网络安全线下大会，各界对今年西湖论剑的召开充满着期待。四月是杭州最美的时节，四月的西湖论剑也将以崭新的风貌为年度网络安全盛典开个好头！
