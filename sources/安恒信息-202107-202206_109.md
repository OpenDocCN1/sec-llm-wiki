# 袁家军主持召开浙江省委网络安全和信息化委员会第四次全体会议

3月25日上午，省委网络安全和信息化委员会举行第四次全体会议。  

　　25日上午，省委网络安全和信息化委员会举行第四次全体会议，深入学习贯彻习近平总书记关于网络强国的重要思想，贯彻落实中央有关会议精神，总结2021年全省网信工作，研究部署2022年重点任务。  

  

　　省委书记、省委网络安全和信息化委员会主任袁家军主持会议并讲话。王浩、陈奕君、王成国、夏俊友出席。会议审议了2022年省委网信工作要点、数字化改革网络安全保障工作等文件。

  

　　袁家军强调，习近平总书记关于网络强国的重要思想，为我们做好新时代网信工作指明了前进方向、提供了根本遵循。浙江是习近平新时代中国特色社会主义思想重要萌发地，肩负着高质量发展建设共同富裕示范区的重大使命，同时作为世界互联网大会永久举办地，我们必须在学习领悟习近平总书记关于网络强国的重要思想上更加深入，在运用科学理论武装头脑、指导实践上更加自觉，努力为网络强国建设贡献更多浙江力量。

  

　　袁家军充分肯定2021年我省网信工作取得的成绩，强调要深刻认识我省网信工作面临的新形势新要求新挑战，突出迎接服务保障和学习宣传贯彻党的二十大精神这条主线，坚持围绕中心抓工作统筹、聚焦重点抓宣传引导、多跨协同抓风险管控、综合施策抓依法治网、守正创新抓融合赋能、党建引领抓平台治理、政治统领抓队伍建设，统筹抓好疫情防控和经济社会发展、统筹发展和安全、统筹网上和网下，全面提高网络安全和信息化工作水平，加快打造网络强国“重要窗口”，以优异成绩迎接党的二十大和省第十五次党代会胜利召开。

  

　　袁家军强调，要创新做好习近平新时代中国特色社会主义思想的宣传贯彻，特别是要把党的二十大精神宣传好阐释好，汇聚强大正能量。要全力做好重要会议、重大活动的服务保障，向世界展示好浙江在“八八战略”指引下取得的辉煌成就、展示好中国在习近平新时代中国特色社会主义思想引领下所发生的精彩蝶变。要积极有为助力高质量发展建设共同富裕示范区，构建共同富裕浙江全媒体传播体系，深化数字应用适老化改造，加大山区26县和海岛县数字乡村扶持力度，打造全省人民精神富有的网络高地。要坚决筑牢网络安全屏障，进一步提升网络安全防护能力。要纵深推进全球数字变革高地建设，深入实施数字经济“一号工程”2.0版，深化“互联网+”科创高地建设，加快推进网信科技自立自强。

  

　　袁家军强调，要全面加强网信战线党的领导和党的建设，着力构建全省一体、上下联动的大网信工作格局，切实把党的领导、党的意志、党的主张贯彻到工作各方面、各环节。要加强网信系统各级领导班子建设，创新网信人才工作机制，着力打造忠诚干净担当的网信铁军，打牢网络强省、数字浙江建设的人才基础。

  

　　省委网络安全和信息化委员会成员单位及省直有关单位负责人参加会议。
