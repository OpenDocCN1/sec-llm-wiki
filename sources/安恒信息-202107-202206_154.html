随着疫情防控进入常态化，健康码已成为人们出行的“必需品”。当前正处于抗击疫情的关键时刻，健康码一旦出现问题，直接影响防疫工作的开展，这会给人民群众带来很大不便。各地政府亟需思考的这个重要问题是：如何防止健康码以及类似的重要民生系统出现崩溃，在发生故障之后又该如何快速解决。

安恒信息推出

重要民生系统安全保障服务


我们通过望闻问切一系列的手段给政府客户提供优质服务与建议。


针对目前的重要民生系统，发现系统瓶颈，给出整改建议。根据以往经验做出预案，发生问题及时响应，将损失降到最低。技术和运营都有一定的门槛，安恒信息的运营托管服务可帮客户解决运营问题。




1.

性能测试｜系统体检


安恒信息为客户现网进行把脉，帮助客户发现系统瓶颈，给出整改建议，让系统能够应对峰值流量。“体检”的主要过程包括：容量规划分析、全链路压测、性能监控、测试报告。


向上滑动阅览

● 容量规划分析--你现在还有多强？

这一步通常在系统建设之初就会设计，但是由于最初对高峰流量预测不准等问题，根据当前形势，往往容量规划需要根据人口重新分析。

容量规划的目的在于让每一个业务系统能够清晰地知道：什么时候应该加机器、什么时候应该减机器？防疫健康码场景需要准备多少机器，既能保障系统稳定性、又能节约成本？


● 全链路压测--体验就是要全方位

基于实际的生产业务场景和系统环境，模拟海量的用户请求和数据，对整个业务链路进行各种场景的测试验证，持续发现并进行瓶颈调优，保障系统稳定性的一个技术工程。


● 性能监控--体检报告的数据来源

业务性能监控：性能分析的目的是找出系统性能存在的瓶颈与风险，性能调优就是尽可能用更少的资源提供更好的服务。

日志监控：日志的重要性不言而喻，基本上绝大多数的监控系统都是基于日志来进行聚合展示，排查问题。

数据库性能监控：数据库监控在性能测试过程中，主要监控如下指标：CPU资源耗用、慢SQL等。数据库异常状态将被迅速发现和响应。


● 测试报告--业务系统体检报告

测试报告的产出就意味着一次完整性能测试项目的结束。安恒信息给出的测试报告包括系统问题与改进建议，让系统最终能应对峰值流量。



2.

应急预案｜打预防针


如同打了新冠疫苗能让我们对新冠病毒的免疫力提升，做好应急预案才能让我们更好的应对系统的突发状况。

安恒信息有丰富的应急预案来保障客户系统的运行安全，应急预案内容包括

安全攻击类：DDOS攻击、网页篡改等。

设备故障类：平台瘫痪、平台过载等。



3.

应急响应｜吃特效药


经过预案的制定之后，在发生相关问题之后，及时通报给各部门进行响应，快速解决发生的问题，损失可降到最低。安恒信息在帮助客户制定完成预案之后，提供更加快速的响应保障。


● 故障发现和处置流程

7*24小时运维值班机制，责任到人。根据故障的等级进行不同方式的告警（电话、短信、钉钉等），第一时间发现告警，每日有质量监督团队负责整体运维工作的监控响应质量。监控发现故障后，7*24小时运维团队和7*24小时运营团队有效配合，同时服务质量团队每日复盘服务质量，提升服务的及时性和满意度。


4.

组织建设｜医疗团队


任何时候我们身体出现问题，都希望得到专业医生的治疗。对于重要民生系统的安全保障同样如此，安全运营团队到底该如何选择？


运营团队组建模式以安恒信息服务为例，安恒信息安全产品支持三种交付和服务方式

本地模式：采用本地安装，结合本地驻场进行运维服务；

云上云下联动：采用本地安装，开通远程通道，采用云端运维服务。

云端模式：将重要业务系统接入安恒信息在本市的防护节点，有效解决访问时延问题，并由云端安全运营专家在线保障。

● 本地运维能力建设

安恒信息具备丰富的运营运维经验，可赋能客户构建组织所需的流程和技术。



● 托管式安全运营服务（MSS）

政府部门可以选择更高效的安全运营服务-MSS。

安恒信息托管式安全运营服务（Managed Security Service，简称：MSS）以用户安全的全生命周期需求为导向，综合安恒信息安全运营中心的安全运营梯队、标准化运营流程、安全运营平台/工具，通过暴露面监测、资产管理、威胁狩猎、应急响应等服务子项保障业务安全。服务过程中运营服务专家将主动协助用户对风险管理控制，对事件应急闭环处置，构建7*24小时有效、主动、闭环的安全运营体系。


安全托管服务是在原有本地运营运维能力上的有力补充。托管式安全运营服务价值体现为：

（1）低成本共享高阶专家安全运营服务；

（2）托管式安全运营服务，专注核心业务发展。
