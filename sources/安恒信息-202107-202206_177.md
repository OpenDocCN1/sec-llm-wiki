# 范渊受邀新华网数字经济领军者新春寄语

农历壬寅虎年新春佳节来临之际，新华网联合北京软件和信息服务业协会，围绕“2022，数字经济看北京”主题，特别推出数字经济领军者新春寄语系列策划，邀请头部企业、机构、单位负责人梳理新成就，分享新思路，阐述新举措。  

  

**安恒信息董事长范渊在新春寄语中指出：数字经济的安全健康发展离不开网络安全、数据安全全方位守护数字经济发展成果。推进数字安全建设，势在必行。2022年是数字经济发展的关键之年，让我们一起踔厉奋发，一起向未来。恭祝全国网友虎年新春大吉。**

目前，新华网数字化转型专题上线，清华大学管理学院院长江小涓、中国联通董事长刘烈宏、中国电信董事长柯瑞文、中国移动董事长杨杰、安恒信息董事长范渊等数字经济企业家代表一同以“数字化转型先行者”身份现身专题首页。

![](../Images/7bd5ccd04b6164796cf3c00526c35bbb.png)

  

数字经济正在成为重组全球要素资源、重塑全球经济结构、改变全球竞争格局的关键力量，发展数字经济是把握新一轮科技革命和产业变革新机遇的战略选择。一起期待2022全球数字经济大会，期待安恒信息在赋能数字经济安全高质量发展过程中展现专业实力。
