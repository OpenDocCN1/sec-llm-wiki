# 安恒信息两大方案获评2021年浙江省数字经济“五新”优秀案例

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650501378&idx=2&sn=d17389634ee72d7a7c506c2b0994a2d9&chksm=bef2df7b8985566dc3561dda811d71581d51dd27446ff68aa6a939f6d3797b81e119193ea68f&scene=126&sessionid=1681366522#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650501378&idx=2&sn=d17389634ee72d7a7c506c2b0994a2d9&chksm=bef2df7b8985566dc3561dda811d71581d51dd27446ff68aa6a939f6d3797b81e119193ea68f&scene=126&sessionid=1681366522#rd)

![](../Images/3e4a632bc3cee682a2e42de57f057f71.png)

  

近日，浙江省数字经济发展领导小组办公室公布2021年浙江省数字经济“五新”优秀案例，安恒信息斩获2项大奖，分别是** “安恒信息零信任API安全管控解决方案 ”**获评“新技术”优秀案例，**“安恒信息AiLand数据安全岛解决方案”**获评“新治理”优秀案例。  
![](../Images/f8c59cf508d7f48d0e9082a459f807ea.png)![](../Images/443ac67a5068cd7f9e754b387a52bc90.png)  

本次活动通过对新技术、新制造、新业态、新基建、新治理案例的征集和评选，贯彻落实数字经济“一号工程”，深化数字经济系统建设，推进数字产业化、产业数字化、治理数字化和数据价值化协同发展。

 其中，**“新技术”**聚焦人工智能、大数据、云计算、区块链、新一代网络通信、集成电路、量子信息、柔性电子等领域，以发展新产业、壮大数字经济生产力为目标，评选出24个自主创新性强、应用前景好的案例。**“新治理”**聚焦数字化改革，围绕政府数据资源开放共享、城市大脑、未来社区、数字乡村、数字园区、数字贸易、平台治理等领域，以实现治理数字化为目标，评选出38个应用效果明显、社会价值突出、可复制推广的案例。安恒信息两项方案分别入围其中。

  

1

**安恒信息零信任API安全管控解决方案**

  

安恒信息零信任API安全管控解决方案依照多年以来在数据安全领域的积累，结合大数据安全分析能力基础，围绕“零信任”核心理念，**通过拉通终端、用户、应用、接口、数据身份，引入可信身份认证、动态权限控制、数据脱敏、敏感数据识别等技术，对API访问请求实行持续信任评估和动态访问控制**。

该方案**应用于政府、企业、金融等行业场景**，为用户海量的API及通过API开放的共享数据实施防护，实现“未认证不能访问、已认证不能违规访问”，保障API访问的身份、权限可控、数据可视。

  

  

**实力认证**

AiTrust零信任系统获得IDAC接口兼容性认证，该认证是国内目前唯一的零信任接口认证，标志着安恒信息AiTrust零信任系统开放兼容、标准对接的能力受第三方认可，可与兼容此标准的零信任或用户认证安全组件（产品、服务）共同稳定运行、安全可靠，为用户应用提供全面保障。

![](../Images/b47f599cf67d33183d7eb5ad7d3e1f6e.png)

  

  

  

**全链路防护及监管  
**

基于零信任理念，该方案采取终端基线检查、终端识别、用户认证、权限管控等技术手段，构建构建基于政务终端、政务应用、政务数据共享交换平台的全链路防护及监管体系，实现“全程可控”。![](../Images/42f2dcf70bb3fe84e5192bdbceae2351.png)

零信任全链路能力架构  

  

  

**温州市大数据发展管理局零信任实践案例  
**

基于零信任理念，方案强调“永不信任、始终确认”，通过在业务访问的全流程中引用身份认证的能力，对管控的客体对象“用户”、“应用”的身份进行持续校验。![](../Images/8b8f9b3338fef0fb559fb3fdc958b523.png)

零信任实践案例架构图

  

该方案针对防护对象 API 资源，实现“先认证、再授权、再访问”的管控逻辑，通过为公共数据平台构建虚拟身份安全边界，最大程度上收窄公共数据平台的暴露面，保障业务安全开展。  

2

**安恒信息AiLand数据安全岛解决方案**

  
安恒信息AiLand数据安全岛是一款隐私计算平台，专注于保障数据安全流通，致力于解决数据共享过程中的安全、信任和隐私保护问题的平台，应用于**政务数据共享开放、大数据交易中心数据要素交易、政企与其他单位进行数据安全交换、数据跨境等场景**。采用了“数据可用不可见，可用不可取”的技术，保障了数据安全同时释放了数据计算价值。  

  

**大数据局赋能“普惠金融"案例**

为贯彻普惠金融政策，缓解中小微企业、特殊人群融资难问题，银行等金融机构可通过AiLand数据安全岛增加多维数据进行信用评分，让数据成为信用的依据，让隐私计算技术成为数据安全保障。在信用评分维度上，针对企业贷款用户可设立如企业法人是否是失信人员、企业经营状态、企业纳税情况、企业不动产情况等；针对个人贷款用户可设立个人基本信息、工作证明、资产证明以及是否有负面评价等信息。![](../Images/52245da776a29372136be7677ced1b94.png)

大数据局赋能普惠金融

AiLand数据安全岛信用评分可以有效降低资金坏账率，推动大众创业、万众创新，助推经济发展方式转型升级，增进社会公平和社会和谐。 ![](../Images/d31c38d79ad0a477fa00b1df2653f9e7.png)  
伴随《“十四五”数字经济发展规划》出台，安恒信息将持续深入学习《规划》中关于“着力加强数字经济安全体系建构”等的重要任务部署和具体要求，通过不断吸收各行业客户的数字化转型的新场景安全需求和数字经济发展安全需求，深度参与到政府、客户的常态化网络安全规范制度体系构建、系统化网络安全技术体系构建、实战化网络安全运营体系构建、一体化网络安全监管体系构建等方方面面，助力我国数字经济发展，为建设数字中国贡献网络安全专业力量。
