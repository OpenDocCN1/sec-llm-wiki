# 中国信通院蜜罐类产品评测：迷网欺骗诱捕防御系统高居前列

近日，中国信通院发布了《国内威胁诱捕（蜜罐）类产品研究与测试报告（2021年）》，本次国内蜜罐类产品测试从服务伪装功能、欺骗防御功能、风险分析功能等维度对34家参测企业的蜜罐类产品进行评估，安恒信息迷网欺骗诱捕防御系统在5项测试中进入前十，其中4项高居前五，成绩亮眼。

  

![](../Images/84496ce929f0e883422149c6e0db3c8b.png) 测试报告中的迷网

  

  
  
●迷网介绍●  
  

  

迷网欺骗诱捕防御系统（以下简称“迷网”）是安恒信息根据多年在安全领域的攻防经验，打造的一款应对攻防实战场景的安全产品。基于网络欺骗和主动防御理论，通过在真实业务网络中部署各种高仿真蜜罐、蜜饵，形成沉浸式诱捕蜜网，混淆攻击视听，增加攻击代价，达到延缓攻击进程，进而保护用户资产的目的。

  

![](../Images/bc544f9371c361003a396dbedf605a62.png) 

  

  
  
●迷网五大优势●  
  
**1. 丰富的欺骗诱捕网络**

集蜜罐、蜜饵、流量重定向、影子服务、流量黑洞、预置漏洞等手法构建欺骗诱捕网络，多方位吸引攻击。

**2. 驱动级数据捕获与分析**

基于驱动级监控技术捕获攻击交互行为、投放文件，多维度检测与分析攻击动作、解析流量包，还原攻击过程。

**3. 黑客溯源及攻击反制**

结合威胁情报库进行云端情报分析、沙箱分析，识别攻击者指纹特征，甚至进行攻击反制。

**4.自动化部署及联动响应**

提供一键式自动化部署，并与多种安全产品联动，构建纵深防御体系。

**5.八层自身安全防护**

使用反虚拟化检测、自动降权、数据过滤、监控进程隐藏、通信加密、消息中转、回滚重置、东西向隔离等八大技术保护系统自身安全。
