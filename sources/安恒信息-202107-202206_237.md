# 安恒EDR入选ISC网络安全创新能力百强

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650495930&idx=2&sn=3564a517fbd83f8e3d9d8f538d35d250&chksm=bef2f5c389857cd57917282fa61f63093231a9bc1d1c69a7f97e8f93beeb8d7dbb42192bbf63&scene=126&sessionid=1681366537#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650495930&idx=2&sn=3564a517fbd83f8e3d9d8f538d35d250&chksm=bef2f5c389857cd57917282fa61f63093231a9bc1d1c69a7f97e8f93beeb8d7dbb42192bbf63&scene=126&sessionid=1681366537#rd)

第二届ISC网络安全创新能力百强颁奖典礼上，**安恒明御主机安全及管理系统（以下简称安恒EDR）凭借出色功****能技****术优势和市场影****响力入围终端安全领域创新百强。**此次创新百强共吸引了超200家网络安全企业、500+网络安全创新产品参选。经过专家评审团以及客户智库的双重评审，严格甄选出了年度网络安全十大热点领域创新产品。

![](../Images/91ed4b63dbf58a43a641e3587328af97.png "图片1.png")

今年下半年安恒EDR频频发力，**本次入围是在取得赛可达实验室“东方之星”证书、排行数世咨询“EDR产品能力图谱”前三之后获得的又一荣誉奖项。**此次入围全方位展现了**安恒EDR在终端安全领域的前沿创新能力和尖端安全能力。**

创新是网络安全产品在数字化时代大背景下的破局之道，也是安恒EDR始终坚守之路。**产品发布至今已获得多项的核心技术专利，申请中专利多达数十项。在勒索防护以及高级威胁防护场景的安全检测上，我们始终引领着行业的步伐。**未来安恒EDR将依托强大的技术能力持续发挥自主创新优势，赋能不同数字化业务场景下的终端安全建设，为广大企事业客户终端安全保驾护航。![](../Images/2785e6ef6b79f7a735d34d37b155fbe9.png)**EDR产品简介**![](../Images/2785e6ef6b79f7a735d34d37b155fbe9.png)  

EDR是一款集成了丰富的系统防护与加固、网络防护与加固等功能的主机安全产品。业界独有的高级威胁模块，专门应对攻防对抗场景；自主研发的免疫引擎与专利级文件诱饵引擎，有着业界领先的勒索专防专杀能力；通过内核级东西向流量隔离技术，实现网络隔离与防护、流量画像；拥有补丁修复、外设管控、文件审计、违规外联检测与阻断等主机安全能力。目前产品广泛应用在服务器、桌面PC、虚拟机、工控系统、国产操作系统、容器安全等各个场景。
