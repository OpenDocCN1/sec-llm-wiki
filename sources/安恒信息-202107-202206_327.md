# 逐梦亚运|倒计时装置又刷了一波存在感

![](../Images/d6e900c65bf2b09ad0d63b7748611895.png)金秋9月，亚运会倒计时来到了一周年的时间节点。至此，亚运会就开始在365天一日一日的倒计时节奏中，一天一天款款走近，对亚运会的期盼也与日俱增。

  

10月23日晚，为了充分挖掘大运河历史人文内涵、展示杭州“最江南”文化盛景，由中共杭州市委、杭州市人民政府主办的**2021****大运河文化旅游****节****开幕式****暨****运河****“****旗****”****妙夜晚会**在拱墅区运河文化广场举行，浙江省委宣传部副部长、省电影局局长葛学斌，省文化和旅游厅党组书记、厅长褚子育，市人民政府副市长丁狄刚等领导出席活动。

![](../Images/6a2c159b13060c99c5efb695a15377a5.png)

  

在拱墅区运河文化广场，安恒信息“心心相融，@未来”亚运会倒计时装置亮眼、吸睛，上面赫然出现的距杭州2022年亚运会倒计时322天，也在提醒安恒信息作为亚运会官方合作伙伴，在同整个杭城倒计时的数字变化中，一起敞开怀抱迎接这场举世瞩目的盛会。

![](../Images/53c1b791ed3e041e0a1237743a58968d.png)

关于倒计时装置REMEMBER  
倒计时装置命名为“城市之眼”，整体采用杭州亚运会会徽的线条与曲线，造型色调以“虹韵紫”为主，以“映日红、水墨白、月桂黄、水光蓝、湖山绿”为辅，契合亚运会色彩系统“淡妆浓抹”的主题。装置灯光相互交错，构成强烈、丰富、持久的视觉冲击，释放浓郁的全民迎亚运的城市氛围。  
造型为两个半圆相互交错，其中一边以线条的形式排列，虹韵紫、映日红、月桂黄、水光蓝四色融合，另一边以湖山绿的城市高楼建筑镶嵌在水墨白的空间中为背景，以斜面的方式呈现，充满动态感与空间感，展现出既有葱郁湖山自然生态，又富创新活力运动激情的新时代杭城华彩画卷。![](../Images/c476b544770b7b7d7da8e31941f0a0a6.png)  
▼故事开始的时候  
  
  
2020年11月23日，安恒信息正式官宣成为“杭州2022年第19届亚运会官方网络安全服务合作伙伴”。发布会上，安恒信息正式发布“让智能更安全，让安全更智能”亚运网络安保宣言，安恒信息亚运安保战略，将为杭州亚运会定制专属的一揽子网络安全服务，提供科学、专业、全方位、持续性的网络安全保障。安恒信息将为杭州亚运会打造“九维五星”网络安全场景化保障体系，实现多云安全融合、安全态势全感知、空天一体化物联网安全防护、城市安全智慧运营，让全天候全栈式服务渗透到网络安保的每一个细节，以确保亚运会“零失误”，让智能亚运安全且精彩，为“数字经济第一城”打造“数字经济第一盾”。  
  
  
  
倒计时500天的时候  
  
  
2021年4月28日，距离杭州亚运会倒计时500天之日，由杭州亚组委指导，安恒信息承办的杭州2022年亚运会倒计时装置——城市之眼，在杭州运河广场揭幕，标志着首批亚运倒计时装置建设落成。聚焦城市、亚运、互联、人文，点亮城市之眼倒计时装置，为杭州增添时空的定义。从揭幕开始，整个杭城都在倒计时的数字变化中，期盼着盛会的到来。
