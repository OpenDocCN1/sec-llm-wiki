# 推进智慧城市建设|昆明副市长王迅一行莅临安恒信息参观指导

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650493367&idx=2&sn=950e81193c272b891a7a620c3d0f4c8a&chksm=bef2ffce898576d88ab15ecac6a3b492bb1e8591dc16c05b9bfb1882afdbc2be87c3d5a61f36&scene=126&sessionid=1681366568#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650493367&idx=2&sn=950e81193c272b891a7a620c3d0f4c8a&chksm=bef2ffce898576d88ab15ecac6a3b492bb1e8591dc16c05b9bfb1882afdbc2be87c3d5a61f36&scene=126&sessionid=1681366568#rd)

![](../Images/4f8aa5474fdd191d36680efcdd2aa2d3.png)

10月19日，云南省昆明市副市长王迅一行莅临安恒信息参观指导。安恒信息党委书记、高级副总裁张小孟，副总裁吴小珍，副总裁周俊等人热情接待并参与座谈。双方就网络安全、城市大脑及安全建设等展开深入交流讨论。

![](../Images/f2ee812a37401220feca3dac1228f824.png)

图：政企双方代表合影留念

  

昆明市副市长王迅一行首先参观了安恒信息安全创新体验中心，详细了解了安恒信息当前在云安全、大数据安全、大数据态势感知、智慧城市安全等业务领域的布局和成果，以及安恒信息自成立以来的发展情况及战略规划。

![](../Images/fbaf61a49b565ffb2331f38149f8a518.png)

图：昆明市副市长王迅参观安恒信息安全创新体验中心

  

座谈会上，双方就数据安全及城市大脑规划等开展深入交流。安恒信息副总裁周俊从安恒信息技术优势、城市大脑的建设模式和网络安全保障实践，以及公司在云南的战略布局等方面展开分享。他指出，**安全需求已成为中国社会增长速度最快的市场之一，云南作为我国历来的战略大后方，将成为国家网络安全战略实施的最大受益者之一。未来安恒信息愿意成为昆明城市长期合伙人，双方共同打造让市民有安全感和温度感的城市**。

![](../Images/f3db53e72f70707f5520ab267158e563.png)

图：安恒信息副总裁周俊现场分享

  

昆明市副市长王迅一行认真观看了安恒信息关于城市大脑建设模式和网络安全保障实践过程中技术投入与丰富成果的现场演示。王迅副市长表示，信息产业将是昆明发展的排头兵，**安恒信息在昆明已迈入快速发展阶段，发展正当其时，需要抓住机遇**。还对安恒信息昆明子公司的业务发展提出建议，认为公司的发力点可以集中在推动昆明本地网络安全产业集聚，努力打造网络安全产业高地等领域上。

![](../Images/439c125a46a89ffc4aa310ae4a6d9977.png)

图：昆明市副市长王迅现场分享

  

安恒信息目前已在昆明成立子公司，将立足昆明深耕西南，为城市数字化发展提供综合网络信息安全解决方案。作为网络安全领域领军企业之一，安恒信息将持续释放网络安全建设能力，通过自身产业优势协同城市发展，将城市大脑推广到更多地方，推动更多智慧城市的安全建设和数字化发展。
