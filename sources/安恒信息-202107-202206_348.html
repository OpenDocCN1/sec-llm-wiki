完美兼容！安恒EDR产品已兼容Windows 11

近日，微软发布了全新一代的 Windows 11操作系统，并于10月5日在全球范围内推送。


安恒明御®主机安全及管理系统（简称安恒EDR）自2021年Windows 11系统预发布以来，一直持续投入相关的兼容性验证与功能测试。


Windows 11版本正式发布后，安恒EDR第一时间进行了全面的兼容性、功能性、产品性能、运行稳定性等相关测试，结果显示安恒EDR能完美兼容Windows 11 和 Windows Server 2022版本。




除了兼容最新版本的操作系统，安恒EDR与国内多家IT科技产品制造商也完成了信创互认证。依靠稳定性与强大的兼容性，安恒EDR能够实现不同用户的普适性与兼容性需求。


未来，安恒EDR将携手更多厂商，不断拓展产品兼容范围，持续发挥自身产品在技术、市场、服务等方面独特的优势，为更多用户提供兼容易用的终端安全产品，构筑更智能、更高效、更主动的终端安全防御体系。


安恒EDR服务的各类政企用户已达到数万家，业务范围全面覆盖政府、医疗、教育、金融、等诸多行业，凭借着良好的市场认可度取得了业界良好口碑，是各行业用户建设终端安全能力的最佳选择之一。
