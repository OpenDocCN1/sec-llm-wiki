# 快来看！哪些产品可以让安恒信息荣当代表者

基于网络安全三元论的三大支点--信息技术、业务应用和网络攻防，数世咨询推出2021年度《中国数字安全能力图谱》，图谱分为七大方向：信息基础设施保护、信息计算环境保护（信息安全）、行业环境安全、应用场景安全（业务安全）、基础通用、体系框架、安全服务（网络攻防）。近日，2021年度《中国数字安全能力图谱》其中一个方向——信息基础设施保护率先发布，安恒信息网页防篡改、Web漏洞扫描、WAF登上代表者榜单；网站监测/反网站钓鱼、统一端点安全、EPP/EDR位列能力者前列。

我们以安恒EDR产品为例，梳理一下产品入围的实力表现。安恒EDR最近的表现可以用两个字来概括：优秀。不久前，**中央国家机关****2021****年****杀****毒****软****件****协议****供****货****采****购项****目成交公告**发布，凭借良好的企业信誉、强大的产品竞争力和卓越的技术服务等综合能力，安恒信息**明御****®****主机安全及管理系****统****（****EDR****）****Linux****版****&Windows****版**在众多厂商中脱颖而出，成功入围。（[安恒信息EDR成功入围央采！](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650491148&idx=1&sn=6b9aec2e40b892e4fc10f8bfbdc2e854&chksm=bef2e77589856e63c0fb0961a3a61b8fdd33b0a191f712bd912ee6ca6b3922c9f58287e7d514&scene=21#wechat_redirect)）而此次入围2021年度《中国数字安全能力图谱》“信息基础设施保护”方向，意味着安恒EDR是终端安全防护的最佳选择之一。安恒EDR是安恒信息在深入研究与分析黑客攻击手段的基础上，总结归纳大量安全漏洞信息和攻击方式后，自研开发的新一代终端安全防护产品。**围绕端点防护为目标，安恒EDR以资产为中心****构建的风险处置闭环，包括威胁预防、监测、防御、响应、溯源、加固6大阶段。**在事前通过资产风险监测、威胁事件监测有效发现端点风险信息，事中通过专项防护手段针对风险进行及时防御以及响应处置，事后对风险信息进行追踪溯源、对系统和网络进行安全加固。

![](../Images/e362aa786f84a65b056eb1ed3d7bae1a.png)

目前，安恒EDR已广泛应用于政府、医疗、教育、企业等诸多行业，服务各类用户达8000家。未来安恒EDR也将依托于终端安全能力平台，构筑更简单、更智能、更高效、更主动的安全防御体系，全面保障政企事业单位的终端安全，持续为用户提供领先业界的终端安全防护服务。

说明：《中国数字安全能力图谱》信息基础设施保护包括6个领域和29个子领域，并将相应的能力提供者分为“代表者”、“能力者”和“创新者”。代表者是指该能力提供者在该领域具备明显的市场领先地位，能力者是指该能力提供者在该领域具备重要的市场地位，创新者是指该能力提供者在该领域的市场规模较小，但拥有“专精特新”的创新技术。
