# 安恒信息参加中国移动智慧家庭线上“开放日” 共话物联网安全产业发展

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650490590&idx=2&sn=47ef608f565c5446fcb99a4a33946585&chksm=bef2e8a7898561b19475d7a4a2c09a2cce71eadc716bfa2539ea2c6ce7986ee5d736440890f0&scene=126&sessionid=1681366613#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650490590&idx=2&sn=47ef608f565c5446fcb99a4a33946585&chksm=bef2e8a7898561b19475d7a4a2c09a2cce71eadc716bfa2539ea2c6ce7986ee5d736440890f0&scene=126&sessionid=1681366613#rd)

![](../Images/0b2532724f874671662224b42f8bc663.png)

  

为加快推动网络安全产业高质量发展，提升网络安全产业综合实力，工业和信息化部起草了《网络安全产业高质量发展三年行动计划（2021-2023年）（征求意见稿）》（以下简称《行动计划》）。8月3日，中国移动智慧家庭线上【开放日】携手安恒信息，聚焦网络安全，从市场需求、技术创新、未来应用等多角度进行全面解读。

  

![](../Images/aa2034660a875f5b0f92aaf857af2267.png)

  

安恒信息物联网安全事业部产品专家围绕《从新时代新规划，看物联网安全产业发展新机遇》，通过物联网具体细分行业发展历程，透析物联网安全技术演变方向与未来趋势。

  

![](../Images/3ef2007cda713fd6278d9c3e7ecf294b.png)

  

  

**1**

**从“行动计划”看物联网安全方向**

  

十四五规划纲要中提到要“加快数字化发展 建设数字中国”，七大数字经济重点产业中物联网位列第三，粗略估算市场规模超万亿。同时也提到要加强网络安全防护，健全国家网络安全法律法规与标准制度，未来亟需加强物联网安全相关立法与安全监管，提升物联网安全意识、安全防护能力体系建设，打造坚实可靠的物联网安全底座，保障数字经济平稳、健康发展。

  

工业和信息化部发布的《行动计划》首次明确并细化地提出了网络安全产业发展思路和目标。

  

**物联网安全企业发展目标**

近年来，我国网络安全产业取得积极进展，特别是随着5G、大数据、人工智能、车联网、工业互联网、物联网等新技术新业务新模式出现，网络安全、数据安全等技术、产品和服务蓬勃发展。关于企业发展，《行动计划》提出到2023年一批质量品牌、经营效益优势明显的具有网络安全生态引领能力的领航企业初步形成，一批面向车联网、工业互联网、物联网、智慧城市等新赛道的“专精特新”中小企业群体迅速成长，网络安全产品、服务、解决方案单项冠军企业数量逐步壮大。

**物联网安全发展方向**

针对车联网和物联网，推动内生结合的轻量级终端安全产品或中间件，以及通信安全、身份认证、平台安全等防护方案应用；推动联邦学习、多方安全技术、隐私计算、密态计算、安全检索、多阈协同追踪等数据安全技术研究应用。

**加快新兴融合领域安全应用**

实施物联网基础安全“百企千款”产品培育行动，面向物联网终端、网关、平台等物联网关键环节，开展物联网安全检测、异常处置和公共服务，打造“物联网安心产品”。

**物联网安全能力建设**

积极推进智慧能源、智慧农业、智能家居、智能穿戴设备等物联网场景网络安全应用，鼓励企业研制适应异构物联网场景下的端到端安全防护解决方案。针对物联网平台，发展基于安全传输、异常行为分析、可信身份、威胁分析、数据防泄漏等技术的平台安全类产品。针对物联网设备可信接入网关，加快发展身份识别、协议解析和安全检测分析技术，鼓励企业将更多安全能力集成至网关。针对物联网终端，加强物联网设备及固件的漏洞挖掘，研制集接口防护、安全认证、应用安全、敏感数据保护等于一体的嵌入式集约化安全产品，打造安心物联网。

  

  

**2**

物联网安全技术与产业发展未来

  

IDC预测，到2024年中国物联网市场支出预计将达到约3,000亿美元，成为全球第一大物联网市场，其中2021年物联网安全市场规模有望超过300亿元，成为千亿规模市场下的蓝海。

  

随着物联网应用场景的不断增多，物联网安全事件发生越来越频繁，针对物联网业务系统的攻击形式也呈现多样化。因此，物联网安全也由传统的“被动防御”走向了“主动防护”。加强物联网终端设备自身防护，实现端到端的数据加密。

  

传统的网络安全技术主要集中在网络层，利用网络层来检测平台的漏洞、终端的安全状态。但大量的物联网终端暴露在网络之外，使得设备更容易遭受攻击，加强物联网终端设备自身防护，实现端到端的数据加密尤其关键。

  

![](../Images/d2dc7adecc192095664a73eced5eca72.png)

  

“主动防护”为每一个终端提供量身定制的安全防护，让每一个终端面对网络攻击时具备免疫力和自我防护能力，从单侧实现数据安全加密。

  

针对物联网安全问题的多样化、个性化、碎片化等特点，安恒信息打造了完善的物联网安全“136产品体系”，结合安恒信息过去十四年积累的威胁识别、防御、检测、响应等方面的网络安全能力，推出了囊括“云、管、边、端、模、芯”的六大维度的物联网安全解决方案，提供安全芯片、安全模组及安全传输加密等功能，打造统一的物联网设备接入与管理，实现多元化的物联网场景安全能力定制。

  

![](../Images/d7fbaabe5c1154c0ef10aa085f270c4c.png)

  

目前，安恒信息物联网安全解决方案已经在政府、公安科信、公安网信、教育、大数据局、医疗等行业广泛应用，覆盖全国25个省市，合作客户数百个。

  

未来，我们相信随着产业数字化、数字产业化进程的推进，物联应用场景不断丰富，物联网安全监管不断完善，物联网行业生态会愈发蓬勃，物联网安全产业也会更加健康地发展。

  

通过此次中国移动智慧家庭线上【开放日】，安恒信息将进一步强化与中国移动的合作，拓展物联网在智能家居领域的安全防护，保障智慧生活场景下的个人隐私安全、人身财产安全，共同驱动智能家居安全落地，共建智慧生活安全防护网。
