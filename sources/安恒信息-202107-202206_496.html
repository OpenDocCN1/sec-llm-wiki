Windows Hello漏洞

可绕过物联网生物识别认证

Windows Hello是Windows 10提供的新的安全功能，该功能通过生物识别技术诸如指纹、人脸和虹膜等提供多种身份验证方式。研究人员早在 3 月就发现了该漏洞并命名为 CVE-2021-34466 ，攻击者可以利用漏洞欺骗面部识别设备来绕过整个身份验证系统，从而控制设备，这也是物联网生物识别的薄弱环节之一。

WiFiDemon–iOS WiFi RCE 0-Day漏洞利用

Wifid 是处理与WiFi连接相关的协议的系统daemon，研究人员发现wifid在处理SSID 时存在格式字符串问题，攻击者利用该wifid漏洞可以引发DoS攻击，禁用iPhone的WiFi功能和热点功能，且该漏洞可通过零点击的非交互形式启动，受害者只需要将WiFi开启就会触发有漏洞的代码。
