# 浙江省安防协会秘书长赵永华一行到访安恒信息调研交流

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650564516&idx=1&sn=1e397fa604f9a791c0af169ccf43296f&chksm=bef5c9dd898240cb3c2e1ca706e6a6d39464638d3e223c79ff2b25f9b576ebcb34e452e8064b&scene=126&sessionid=1681366344#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650564516&idx=1&sn=1e397fa604f9a791c0af169ccf43296f&chksm=bef5c9dd898240cb3c2e1ca706e6a6d39464638d3e223c79ff2b25f9b576ebcb34e452e8064b&scene=126&sessionid=1681366344#rd)

  

![](../Images/21acb0ed0d48292d57e101b002cc824a.png)

  

3月22日，浙江省安全技术防范行业协会秘书长赵永华一行到访安恒信息，安恒信息技术委员会主任、智能检测与终端产品线总裁吴卓群热情接待，并共同参与调研交流。

  

在吴卓群的陪同下，赵永华一行参观了安恒信息安全创新体验中心，了解安恒信息近十六年的发展历程、人才培养，以及安恒信息在网络安全方面的产品研发和行业场景应用成果。

  

  
![](../Images/d86a8e5ddc837793743d5751ab1ca634.png)

智能检测与终端产品线总裁吴卓群陪同参观

  

参观结束后，双方就网络安全与安防产业发展开展交流。安恒信息明鉴物联网产品部副总经理王聪就视频安全作相关汇报，介绍安恒信息视频安全方案在**公安、智慧城市、电力等场景下**成熟应用以及行业参编情况。

  

![](../Images/ecf725a197f2d816559fe9b5caafb517.png)

安恒信息明鉴物联网产品部副总经理王聪

  

赵永华肯定了安恒信息视频安全方向的产品能力，同时从国家战略总体安全观出发，指出**网络安全和数据安全为重要建设方向。其中，视频安全产业大有可为**，例如公共视频资源的“五统一”安全问题更是重要的攻克方向，后续将与安恒信息展开深入合作，共同赋能安防产业发展。

  

![](../Images/682299599a8f6e14d4955e287af7dea6.png)

浙江省安全技术防范行业协会秘书长赵永华

  

随后，神盾局主任姚龙飞汇报了安恒信息在反诈方面的成果。安恒神盾局作为新型网络犯罪侦查研究部门，**持续开展新型网络犯罪生态研究，独创“网络犯罪生态节点监测模型”**，赋能公安、网信、工信等行业主管部门统筹行业监管，并提供侦查打击技术支撑服务和电信网络诈骗技术反制一体化解决方案。目前已常态化支撑上海、杭州等地公安部门开展新型网络犯罪的监测、预警和溯源等工作，协助侦破要案数百起。

  

![](../Images/ee6941c95dc44b5eab4604cafc0c2a6e.png)

神盾局主任姚龙飞

  

赵永华表示，后续将成立专人专班制定反诈标准，认可安恒神盾局在反诈方面的技术水平有深厚积累，鼓励安恒信息在行业标准制定中发挥带头作用。

  

未来，浙江省安全技术防范行业协会与安恒信息将**在人才培养、数据安全等方面开展更多交流合作**，共同探索网络安全建设发展之道。
