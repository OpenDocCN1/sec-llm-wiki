# 安恒信息与崇左市大数据发展局达成战略合作 助力“数字崇左”建设

**战略合作框架协议**

  

  

2月21日，**崇左市大数据发展局**与**安恒信息**正式签署**战略合作框架协议**。

  

崇左市大数据发展局党组书记、局长朱厚岩，安恒信息高级副总裁王刚等出席签约仪式，崇左市大数据发展局党组成员、总工程师张红海，安恒信息广西办事处主任郭金海代表双方签署战略合作协议。

  

![](../Images/733d603b900602fd8508c8e588491492.png)

  

此次签约，双方将围绕加强城市级安全顶层设计、加强云网基础安全合作力度、加强数据安全能力建设、共同推进崇左市网络安全人才队伍建设等方面开展深入交流，进一步加深在**网络安全体系建设、人才培养、数字产业发展**等领域的合作，推动崇左市**全域性城市网络安全防护体系建设**，助力“数字崇左”建设。

  

![](../Images/ac58afd4574eb5d26c30a812412ffa28.png)

  

会前，崇左市大数据发展局朱厚岩一行还参观了安恒信息安全创新体验中心。  
会议期间，安恒信息相关负责人围绕数字政府安全建设解决方案和典型案例作专题分享，介绍了安恒信息在**构建数字政府全方位安全保障体系方面**的专业实力。安恒信息一直以来积极与全国多城市在数字政府治理中达成合作，从前期的数据安全咨询规划、到中期的数据安全体系落地、到后期的数据安全持续运营，**持续为客户提供全生命周期的解决方案**，助力数字政府转型升级。
