# 安恒信息董事长范渊获首届安全可信创业领军人物称号

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650554519&idx=2&sn=a7645e2ad4a718489092ba82dd5b25cd&chksm=bef5eeee898267f83dd68d10fb095aa5700b9846cbc26a6d654b7f751ef1ee3fa248ab52c164&scene=126&sessionid=1681366385#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650554519&idx=2&sn=a7645e2ad4a718489092ba82dd5b25cd&chksm=bef5eeee898267f83dd68d10fb095aa5700b9846cbc26a6d654b7f751ef1ee3fa248ab52c164&scene=126&sessionid=1681366385#rd)

近日，由中关村可信计算产业联盟主办的首届“中国可信计算创新发展三十年成果评选表彰”活动结果揭晓，经过5场专家评审会和1场媒体评审会，近2个月的严格评选，**安恒信息董事长范渊获评“2022年度首届安全可信领军人物”称号，安恒信息荣获“2022年度安全可信突出贡献企业”。**

✦  ✦  ✦  ✦  ✦  ✦  ✦  ✦  

![](../Images/4da7b0439b74017530264c0b00fbb624.png)

此次活动旨在推进可信计算产业结构的优化升级，全面提高可信计算领域的自主创新能力，扩大可信计算产业联盟的社会知名度和行业影响力。报奖推荐渠道由科学技术指导委员会院士提名推荐及联盟专委会提名推荐。

![](../Images/f4f8a727960c2d410e800e4304831f52.png)

  

**布局信创生态，贡献安全力量**

  

在范渊表示：“网络安全是信创不可或缺的一环，安恒信息通过布局全体系信创安全产品及信创属性的安全技术体系建设，结合专家级安全服务、教育培训，为监管单位、企业客户提供威胁情报、安全监测、通报预警、应急处置、态势感知、技术检测、智能分析等多种信创安全能力，以信创安全助力数字化转型。”

目前，安恒信息**实现了18个品类80余款型号的全信创架构并推出市场，与其他信创生态厂商形成260余份技术互认证证明，拥有鲲鹏、海光、飞腾等多款高性能信创产品，产品整体覆盖6大CPU、两大操作系统，**经过测试和市场验证，多款一体机产品和平台类产品在硬件规格、性能表现、技术先进度表现优异，在网安信创领域，甚至在传统网安市场中，均已呈现强势的性能领先趋势。  

  

![](../Images/832b92d19fa1674f8e8a5f8e5711a6fb.png)

  

在信创生态下，安恒信息不仅实现了安全计算环境、安全通信网络、安全区域边界等通用技术体系构建，同时在大数据安全、云安全等扩展技术上也具备信创能力。**安恒信息推出“多云多芯一体防护”多云管理安全运营平台，在信创云安全领域，初步调研市占率位居第一梯队**（华为云、自建平台），在浙江、山西、海南、广西等省市级项目落地。态势感知（AiLPHA）全面兼容鲲鹏、海光、飞腾规格，并在公安、网信、金融等行业持续落地标杆项目。

在除了党政、金融、运营商等行业持续深入，安恒信息也将加大其他行业信创的业务拓展，**融合商用密码产品，形成更为完整的信创、商密整体解决方案**，为客户在数据安全、网络安全、个人信息安全提供更有力量的支持。

信创是中国人的科技之路，在新冠肺炎疫情和错综复杂的国际形势下，更需要科技工作者迎难而上，着力攻克关键核心技术，坚持走自主创新之路。未来，安恒信息通过网络安全科技的不断创新、突破，积极推动产业数字化转型，为科技强国、网络强国贡献信息安全智慧和力量。
