# 攻守有道、实战为先——安全运营是安全的终极形态

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650551163&idx=2&sn=ee0a518d0f3bb5ca51c128d2cef2d25a&chksm=bef59d0289821414ff0b42230d78f0c6e33cdc29d7e4573bed0a44bc049183b66fc1d8f6fb83&scene=126&sessionid=1681366400#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650551163&idx=2&sn=ee0a518d0f3bb5ca51c128d2cef2d25a&chksm=bef59d0289821414ff0b42230d78f0c6e33cdc29d7e4573bed0a44bc049183b66fc1d8f6fb83&scene=126&sessionid=1681366400#rd)

11月17日，攻守有道、实战为先——安全托管运营服务发展态势研讨会在上海举行。本次研讨会由上海市通信学会通信技术专业委员会指导，**以网络攻防实战为场景索引，聚焦攻守之道、红蓝之力，探讨安全托管运营服务发展的可能性、必要性与未来道路。**

  

  

数字化推动着全球关键基础设施体系建设步伐加快，全球化推动着云服务的市场的快速扩张。网络安全事件频发，诸如数据泄漏、勒索软件、黑客攻击等层出不穷，有组织、有目的的网络攻击形势愈加明显。  

为应对全球网络安全问题，网络安全实战化的趋势不断攀升，各国纷纷开展网络安全实战演练。国内各级政府、各行业也在不断开展贴近实际的情况的演练行动，推动着网络安全运营管理逐渐从“静态、基于威胁的保护”转向“动态，基于风险的防护”模式，以构建立体式主动防御体系。

  

**攻守道之当下**

  

![](../Images/f8cb3556f9748c2b3b80fd48850d8193.png)

安恒信息首席安全官、高级副总裁袁明坤

现场，安恒信息首席安全官、高级副总裁袁明坤为我们介绍了网络安全实战化运营的重要性与必要性，并认为**安全的终极形态一定是安全运营**。在长达15年的国内外重大活动保障中，安全服务整体能力也在与时代和行业共生共长，并与数字化转型的各行业联手成为了一个网络安全共同体。

  

![](../Images/3b6e56a15def3d2063966d08b161c156.png)

公安部第三研究所副研究员俞少华

网络安全实战能力如何评价？公安部第三研究所副研究员俞少华认为**实战是找寻安全“短板”的最佳方式**。在网络边界越来越模糊、资产云化、攻击手段多样化的当下，实战能力成为企业安全建设的指引。运营、识别、防护、检测、响应、恢复是网络安全实战能力的六个维度，并通过资源、技术和管理“三位一体”组成了兼顾高效协调性与组织性的评价角度。

  

![](../Images/c030a97265c10cd0e92c43157ea22b23.png)  

国泰君安网络安全架构师陈凯晖

国泰君安网络安全架构师陈凯晖分享了证券行业的攻守之道。以网络攻防的视角，结合实战演练和常态化安全运营的体会，分析了VPN的攻击面、攻击方法和防御思路，从确认目标到定点突破，从常规防御到失效绕过，从防线突破到纵深防御，并基于零信任的思想提出了双重认证、流量解密分析与阻断、蜜罐捕获、关联分析、异常行为分析、下一代防火墙联动等主动防御体系的思考和探索。

  

**攻守道之未来**

  

![](../Images/a578310ce9634b2bc4f822328d2ce2cc.png)

活动最后，五位行业专家共聚圆桌对话，以安全托管运营场景应用与标准化服务为主题，以金融、智能网联汽车行业的高监管要求，共同探讨在实战化运营的前提下，安全云服务的数据资源与安全、安全运营的资源投入与收入回报比、安全托管运营服务的标准化发展、安全托管运营服务可作为安全底线来构建的必要性等建设性问题。  

面对新的数字时代、面对新的安全需求，基于时代的新要求、基于业务的新需求，安全托管运营服务作为行业创新升级的体系化服务产品与内容，是当前实战化、常态化、体系化的安全发展趋势的最优解之一。安全托管运营服务的发展则预示着安全运营不再只救城门火，而去建设护城河，以实战之力应常态化之挑战，以运筹帷幄之力守得赛博城池的底线安全。
