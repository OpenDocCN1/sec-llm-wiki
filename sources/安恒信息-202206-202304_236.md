# 《焦点访谈》、新华社、人民日报…乌镇72小时，媒体聚焦安恒

2022世界互联网大会已圆满落幕。在今年的乌镇时间里，来自120余个国家和地区的2100余位代表，以线下或线上形式参加世界互联网大会乌镇峰会，来自40多个国家和地区的415家企业以线上、线下相结合的方式参加“互联网之光”博览会，创历届峰会之最。**安恒信息连续9届参与大会**，这一次，**我们在“互联网之光”博览会、4大主题论坛、新产品新技术发布会、“直通乌镇”世界互联网大赛等多个环节精彩亮相**，赢得上百家媒体争相报道，**从CCTV1《焦点访谈》、CCTV13，到新华社、人民日报、中新社、光明日报、中国青年报，再到浙江卫视、浙江日报、新京报、新民晚报、美丽浙江......**众多网安金句被广为传播，小编精选了一小部分，与你分享。

✦  ✦  ✦  ✦  ✦  ✦  ✦  ✦  

  

  

  

  

  

**CCTV1《焦点访谈》和CCTV13央视新闻**

在《焦点访谈》特别版探会专题报道中，安恒信息董事长范渊向记者介绍、演示了安恒信息展位“勒索病毒互动体验区”，直观展示常见的勒索病毒风险以及安恒信息EDR的快速拦截过程。**安恒信息从2014年首届世界互联网大会开始就承担了大会的网络安保工作**，在保障数据安全上，通过隐私计算等技术让数据可用不可见、可用不可取，确保隐私数据、重要数据在应用中不被泄露，避免被盗，也通过防勒索专项产品保护电脑等终端设备的重要数据和文件安全。

  

央视新闻采访报道安恒信息董事长范渊：“**真正好的技术是买不来，换不来的。还是要靠我们扎扎实实的研发研究，我相信各行各业随着我们的努力，在这样的大好时代和环境下，一定会有更多的科技创新的成果涌现。**”

  

  

  

  

  

**新华社和新华网**

![](../Images/ad3825b09ead2aeebc390c0f46006a35.png)![](../Images/43470c785cc7ad6007e3d2ae55712f15.png)

数字文明在突破传统生产要素流动限制、促进市场效率和文化多样性的同时，带来了不可忽视的信息安全问题。范渊在接受新华采访时表示，**需要更加重视数字安全的基础作用，筑牢数字文明的安全底座，坚持自主可控对于新安全格局构建至关重要。**

  

![](../Images/bf8dd18205f2103871c2e5cc362ba063.png)

范渊在接受新华网专访时表示，**安恒提出建立可信、可用、可管的数字世界。**其中，信任的建立和我们的安全架构、安全技术息息相关。在可用的基础上，让企业放心、百姓安心、政府可管的数字世界的蓝图，已经开始绘就。

网络安全、数据安全也涉及网络安全科技的问题。要努力让我们的网络安全科技基石筑得牢，只有这个基石筑得牢，我们的网络大厦、数字大厦才能牢固。

  

  

  

  

**人民日报和人民网**

![](../Images/e76cd180b411d229e100d60b04db2e26.png)

范渊在接受人民日报采访时表示，“**习近平主席的贺信向全世界展现了中国在携手构建网络空间命运共同体进程中的大国担当。我们将坚持安全可控和开放创新并重，为构建安全可信的数字世界、世界数字经济蓬勃发展贡献中国力量。**”

  

![](../Images/35f1590dec2490ad5f8ad742f8a70c86.png)

人民网浙江频道走进大会，探索安恒信息展位的精彩内容。包括安恒数盾产品的介绍以及勒索病毒互动体验的场景讲解。

  

  

  

  

  

**央广网**

![](../Images/e56efa5f47a1d4316c88c1a45cbcb5be.png)

范渊在接受央广网记者专访时表示，**作为网络安全领域的赋能者，安恒信息深度参与本届大会，携数据安全、MSS安全托管运营服务、安全服务能力、大型赛事安保案例等参展。**  

  

![](../Images/30bb82dfed8ed0c22e7d089c552f4423.png)

**由杭州亚运会火炬“薪火”、成都大运会火炬“蓉火”领衔的六大国际赛事火炬集中在安恒信息展位亮相。**安恒信息曾先后参与了北京奥运会、上海世博会、G20杭州峰会、武汉军运会、上海进博会、历届世界互联网大会等国家重大活动的网络安保工作，谱写“零失误”的满意答卷。

  

  

  

  

  

**光明日报**

![](../Images/0703c239b22c5231773371eeb4a35b81.png)

光明日报报纸版面刊出范渊见解：**数字化的核心是数据，贯穿产业链重构的全过程。**为了解决数据安全保护问题，迫切需要创建受隐私保护与安全约束的新型计算范式，结合边缘数据存储、去中心化分布式数据存储、敏感信息匿名化等技术，构建分布式数据安全管理方案，实现数据安全及隐私保护。

  

  

  

  

  

**中国新闻网**

![](../Images/4744e48b89963e7ed4fa3a1fe9eea95e.png)![](../Images/750c57fee934c8d5e08709632d5be9a7.png)

中国新闻网报道**互联网技术的快速发展向前，离不开网络安全的保障。**安恒信息已连续9年参与世界互联网大会网络安全保障工作。博览会上，其带来的“数盾数据安全”项目引得不少关注。

  

  

  

  

  

**经济日报**

![](../Images/d49f412cebbeec6bed845456fb9545d2.png)

经济日报报纸版面报道本次世界互联网大会安恒信息展台反勒索病毒互动专区。**终端安全防勒索解决方案采用诱饵引擎，在未知类型勒索病毒试图加密时发现并阻断其加密行为，可有效守护主机安全。**在攻防对抗的各个阶段进行防护，不仅可以做到威胁攻击审计，而且还可以防止黑客进行渗透攻击。

  

  

  

  

  

**中国青年报**

![](../Images/9322c1cc859e9f3f297534d7765cb86b.png)

中国青年报报道范渊出席工业互联网论坛，和与会专家探讨数字化在产业链重构中的重要作用，以及在工业互联网场景下的安全保障体系建设等话题。他认为，**从数据安全着手构建更独立、更完整、更健康的产业链将是新的趋势。**

  

  

  

  

  

**浙江卫视**

![](../Images/2423a2b103c8ad1b211a606dd272a406.png)

在浙江卫视新闻联播的《乌镇问大咖》节目中，范渊表示，**数字化转型的过程，不是简单的一套信息化系统，需要站在更全局的视角。从生产经营、数据采集分析、数据利用、数据再加工，甚至外部的协同，以达到最终效果。**

不管是大型的智能制造，还是中小企业集群，都应该有方法和途径能够进行一些关键场景、关键路径的数字化重构的尝试。

  

  

  

  

  

**新京报**

![](../Images/982416a02e0ccf7b4117f56f93199f2e.png)

范渊在峰会现场接受新京报采访时表示，站在产业的角度，安恒信息积累了不少在网络空间治理方面好的经验做法，“**事实上，不论是共同打击网络犯罪，还是进行网络空间治理，都体现了不同的主体需要不断进行交流，这本身就是一种趋势。**”

  

  

  

  

  

**新民晚报**

![](../Images/59e78b1d63ec04ed8abebe363c705b3b.png)

中国共产党上海市委直接领导的面向广大市民的综合性报纸《新民晚报》报道安恒信息世界互联网大会内容：2008年北京奥运会火炬“祥云”、杭州亚运会火炬“薪火”、成都大运会火炬“蓉火”……另一边的安恒信息展台上，**六大国际赛事火炬集中亮相，让人眼前一亮。**

  

![](../Images/060c8e5224db814f816417dc08a1b63b.png)

  

以乌镇峰会的举办为新的起点，构建网络空间命运共同体的步伐又向前迈进了一大步。安恒信息愿与业界共同努力，共建网络世界，共创数字未来，为网络空间的文明健康发展和数字经济的腾飞不懈努力。
