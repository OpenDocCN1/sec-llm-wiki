# 安恒信息与深圳市政务服务数据管理局开展联合党建活动

![](../Images/9624e4d60c916c77472ff562b1395be7.png)

党的二十大明确提出国家安全是民族复兴的根基，社会稳定是国家强盛的前提，要加快建设网络强国、数字中国。作为网络安全领域的领军企业之一，安恒信息不断强化党建引领，筑牢发展根基，以高质量党建推动高质量发展，更好地助力新时代数字中国、网络强国的建设。

近日，深圳市政务服务数据管理局信息安全处党支部与安恒信息深圳党支部开展了一场以**“党建引领强堡垒，网络安全树标杆”**为主题的联合党建活动，深圳市政务服务数据管理局党组成员、副局长、机关党委书记王卓民，信息安全处处长、支部书记罗菁春等领导，安恒信息大湾区总部总经理吴伟京，安恒信息深圳党支部书记钟伟，以及党员代表们共同参与本次活动。

  

  

  

  

活动伊始，王卓民副局长一行在吴伟京的陪同下参观了安恒科技展厅，充分了解公司的发展过程，以及在**云安全、数据安全、物联网安全、态势感知**等方面的技术成果。

  

![](../Images/0a718b96cbe6eb38ad7937e5607da050.png)

  

随后，支部书记钟伟围绕本支部的基本情况、二十大专题学习等内容进行汇报。他介绍，安恒信息党建以铸造一支**政治过硬、业务过硬、责任过硬、纪律过硬、作风过硬**的“红色卫士”队伍为目标，在“双强领导、一体双培、两个共同”的工作思路指引下，做到把优秀党员培养成业务骨干、把业务骨干发展成党员，以高质量党建促进企业高质量发展。  

  

![](../Images/84708a7951c370d02b361393d96c7270.png)

  

吴伟京主要针对公司战略、大湾区总部发展规划等内容进行了汇报。他介绍，进入安恒2.0时代，**安恒人始终牢记助力安全中国，助推数字经济，筑牢可信社会的初心，**以成就客户为本，不断强化技术创新，为用户数字化转型筑牢安全基石，为构建安全可信的数字世界而不断努力。

  

![](../Images/e627e7cb8f6a29125c04900d070a887d.png)

  

会上，安恒信息还进行了数据安全体系规划建设实践专题介绍，围绕数字政府建设过程中的数据安全风险、数据安全体系化建设思路、行业实践等内容做了汇报。

  

![](../Images/2a9265fac975569012eaa61a31c71d7b.png)

  

在交流座谈环节，罗菁春处长对安恒信息在政务数据安全方面的理解与实践积累深表认同，并期望安恒信息能继续保持自信自强，勇毅前行的红色基因，发挥技术特长，进一步提供更好更可靠的安全解决方案，助力城市数字化转型。

  

![](../Images/2792e4c3c262af7e6eb70487f24ac508.png)

  

王卓民副局长对安恒信息的业务能力和党建工作给予高度评价，表示此次活动交流感触颇多、收获满满、期待合作，尤其对党建业务双融双促、党员积分管理等创新做法印象深刻，希望以此次党建活动为契机，强化合作，共同为深圳打造**全球新型智慧城市标杆和“数字中国”城市典范**贡献智慧。

  

![](../Images/0acef73601534aa209f7771e1d2b5264.png)

  

  

  

本次活动进一步推进了双方在党建与业务的双融互促，把党对新兴领域的领导落到实处。安恒信息将进一步凝聚共识、汇聚力量，注重党建与业务的相互促进融合发展，为中国网络安全、数字经济保驾护航。
