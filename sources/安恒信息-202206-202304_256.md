# 入选神兽方阵，发表精彩演讲，打造县域样板！安恒零信任尽显风采

11月3日，第三届国际零信任峰会暨首届西塞论坛在湖州圆满召开，本届峰会以**“因为看见，所以信任”**为主题，吸引了众多国内外院士、专家、学者共聚一堂，探讨数据安全时代下零信任新突破，以期携手构筑数字安全新底座。

作为行业零信任解决方案提供商，安恒信息受邀出席本次大会，并通过**大会演讲、客户案例、荣誉奖项**等多角度整装亮相，全面展示了安恒信息零信任解决方案创新及市场优势。

  

  

  

**重磅亮相，神兽方阵首次发布**

  

为了客观、公正、专业化地评估中国公司的数字安全能力，**云安全联盟大中华区创立中国神兽方阵模型（China Matrix Quadrant），**方阵接受联合国科学技术促进发展委员会和联合国数字安全联盟指导，秉承中立公正、专业权威的原则，相关数据将作为联合国全球数字安全报告内容的重要参考。

  

![](../Images/91a0b637140b91d8f38cdaff02fec0d6.png)

  

基于方阵工具模型，经过前期专家分析评选，**安恒信息入选方阵——玄武。**再度彰显了安恒信息的技术实力与解决方案能力。

  

![](../Images/27c621fa8327df7570df637ae60b7ed6.png)

  

**金句频出，大咖齐聚共话零信任**  

  

零信任架构重新评估和审视了传统的边界安全架构，成为近两年火热的安全思想，其代表了新一代的网络安全战略理念。每届举办的国际零信任峰会已成为零信任领域风向标。大会现场各路大咖观点输出，金句频出。安恒信息结合以往零信任领域研究成果，分析当前网络安全现状与客户需求，采用SDP、IAM等零信任技术，结合商用密码技术，推出零信任解决方案。

  

![](../Images/4936732c7c0c456f2464246ad7308c90.png)

  

安恒信息首席科学家刘博代表出席，并发表了题为**《基于零信任的全链路数据安全管控体系》**的演讲。他表示，要紧贴数据安全场景打造中国特色零信任方案，安恒信息提出**基于内生数据安全框架零信任体系，基于身份的溯源，基于数据操作上下文安全分析，**让用户看得见数据问题，让用户可持续性运营起数据安全。

  

**打造生态，树立零信任落地县域样板**  

  

网络安全已成为建设网络强国、数字中国、发展数字经济的安全基石。站在新的起点，新的高度，安恒信息加快推动数字安全领域的新征程，打造行业创新生态格局，发展建设全国零信任解决方案的“县域样板”。

  

![](../Images/ccadfbb9abdf994fd69abeab1995e11d.png)

  

峰会当天，**安恒信息湖州客户——湖州长兴县大数据荣获“安全变革奖”，**用于表彰甲方企业在内部全面部署“零信任”，在安全建设过程中不断突破自我，推陈出新，反复自我迭代。寻求更新、更完善的产品或解决方案用于企业的安全建设中。

  

  

  

  

KEEP GOING 

未来，安恒信息将联合更多生态伙伴的技术力量，为客户提供具备竞争力的零信任产品、解决方案和服务，共同推动提升各行各业的网络安全防护能力。
