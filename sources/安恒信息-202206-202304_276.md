# 助力建设人才高地，安恒信息牵头开发省级题库项目

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650548014&idx=2&sn=1ef2fa651ff3a7e19d3e15e65a5a2dde&chksm=bef5895789820041c6f45ff6ed2a1dbfa2aa3e72e86c084803174b7509440fce9cf6367262d2&scene=126&sessionid=1681366411#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650548014&idx=2&sn=1ef2fa651ff3a7e19d3e15e65a5a2dde&chksm=bef5895789820041c6f45ff6ed2a1dbfa2aa3e72e86c084803174b7509440fce9cf6367262d2&scene=126&sessionid=1681366411#rd)

![](../Images/3e4a632bc3cee682a2e42de57f057f71.png)

  

  

近日，由安恒信息牵头开发的**浙江省2021—2022年首批职业技能等级认定省级题库《信息安全测试员》专家评审会**在杭州市职业能力建设指导服务中心召开。杭州市职业能力建设指导服务中心技能人才评价科副科长鲍柯、浙江工业大学网络空间安全研究院院长宣琦、北京航空航天大学杭州创新研究院网络空间安全研究中心主任吴铤、杭州电子科技大学网络空间安全学院教授焦鹏飞、安恒信息数字人才创研院教研部经理王伦、安恒信息数字人才创研院高级安全培训工程师李肇共同参加了本次评审会。

  

![](../Images/8ff45dfd105c78bb70bc3abc5962ea6a.png)

  

  

会上，王伦对本次题库开发工作的项目团队进行了介绍，并通过分析当下行业现状和产业需求，从**体系构建，题库建设到人才评价的实施**三个方面详细说明了本次《信息安全测试员国家职业技能鉴定国家题库试题资源》的开发流程。

  

![](../Images/a9145e8807cec61c3a42f6ad3f08cc25.png)

  

其次，王伦向评审会的各位专家汇报了此次题库开发的阶段性成果，通过基础调研、熟悉《标准》《技术规程》、收集教材资料等，团队已于2022年9月30日完成理论认定要素细目表、操作技能考核内容结构表、操作技能认定要素细目表的编写。评审专家组严格参照国家职业标准，遵循现实可操作性和时效性原则，对题库的《理论知识鉴定要素细目表》、《操作技能鉴定要素细目表》、《操作技能考核内容结构表》等内容进行了逐一审阅，并给予了中肯的建议和良好的评价。

  

![](../Images/c0076be175a1e120ad6db50622410125.png)

  

通过此次评审会，王伦表示在有关部门以及各方专家的指导建议下，后续工作也会向着更高质量、更深层次的水准迈进。2021至2022年，安恒信息首席人才官、高级副总裁苗春雨和副总裁吴鸣旦先后带领团队参与人社部《网络与信息安全管理员职业技能等级认定》国家标准和杭州职业能力建设指导中心《网络和信息安全管理员（4-1级）》的省级题库等**多个国家级、省级项目开发，**助力新时代人才培养建设。

  

  

二

十

大

党的二十大报告指出，深入实施人才强国战略，加快建设世界重要人才中心和创新高地，着力形成人才国际竞争的比较优势。多年来，安恒信息深耕网络安全领域，将“网络安全人才培养”作为企业三大战略之一，通过技能培训、产学研合作、赛事竞技等多种方式位国家培养网络安全人才。未来安恒信息也将继续加大投入，坚定科技创新自信，以国家战略需求为导向，推动关键核心技术攻坚，为我国打造网络强国贡献力量。
