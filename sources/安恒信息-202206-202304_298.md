# 安恒信息携手电信数智，筑牢千行百业数智化转型安全基石

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650545831&idx=1&sn=b2f552790b0617147d7d37bff64d1173&chksm=bef5b0de898239c8e016eb36fd23e1d87521b321c29a70ba6c03892e36ae0f476dff4bde8d5b&scene=126&sessionid=1681366421#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650545831&idx=1&sn=b2f552790b0617147d7d37bff64d1173&chksm=bef5b0de898239c8e016eb36fd23e1d87521b321c29a70ba6c03892e36ae0f476dff4bde8d5b&scene=126&sessionid=1681366421#rd)

9月28日，安恒信息与中电信数智科技有限公司（以下简称“电信数智”）达成战略合作协议，双方将围绕安全产品和解决方案建立全面业务合作伙伴关系，重点深化国产密码改造和信创安全领域的合作，打造电信特色的国密及信创一体化解决方案，联合建设安全实验室，共同研发面向数智化场景的安全新产品。

![](../Images/d150040cbf6886f435be88eff944aa54.png)![](../Images/21033f9f3eecbbf8d63efd9c36bad6b0.png)

电信数智总经理李忠，副总经理朱庭俊，副总工薛希俊，网信安全业务部总经理黄鹏等，安恒信息董事长范渊，高级副总裁郑赳，副总裁、运营商行业部总经理卢小波，副总裁、电信事业部总经理秦树春等领导出席签约仪式。由于疫情管控，本次签约仪式在线上举行。

安恒信息副总裁、运营商行业部总经理卢小波首先介绍了本次合作内容。电信数智和安恒信息的结缘已久，在前期项目中，双方已经建立了良好的合作基础。

![](../Images/ecd30be3c3bfe641c9579bcc4967783a.png)

**电信数智总经理李忠**表示，安恒信息是国内领先的网络安全企业，与中国电信互为战略投资者，这为本次双方合作打下了坚实的基础。电信数智秉承“用户至上、用心服务”的服务理念，希望未来双方坚持技术创新驱动，在产品、技术、服务上实现优势互补，打造更加完善的安全产品和解决方案。

![](../Images/a030430d9d4e2e68ee3909b3f4d625e1.png)

**安恒信息董事长范渊**表示，本次与电信数智的战略合作，彰显了双方在发展方向上的高度契合。希望以此为契机，实现电信数智解决方案能力和安恒信息产品能力的深度融合，共同开拓市场机遇，推动双方合作向更宽领域、更深层次、更高水平迈进，打造业内标杆案例，助力网络强国和数字中国建设。

**中电信数智科技有限公司**践行中国电信综合信息服务提供商和聚焦客户的信息化创新战略，为政企、金融行业客户提供综合信息服务和信息系统整体解决方案、为电信运营商提供应用软件开发和IT服务支撑。公司建立了覆盖全国各省市区的分公司体系，同时依托于中国电信全业务运营基础，依托于全国垂直一体化的三级营销服务体系和运行维护体系，面向政府、企业、金融和电信运营商等行业客户，提供网络集成、主机存储集成及IT系统外包、设备维保、软件开发等随需而变的“一站式”服务和解决方案。

安全是发展的前提，发展是安全的保障。安恒信息以“构建安全可信的数字世界”为企业使命，凭借强大的研发实力和持续的产品创新，完成覆盖网络安全生命全周期的产品、服务及解决方案体系，护航广大政企数字化转型升级。前行道路上，安恒信息愿与志同道合的伙伴携手，共同融入数字经济建设，在数字化浪潮中激活科技创新动力，筑牢安全防护城墙，为网络强国和数字中国建设贡献力量。
