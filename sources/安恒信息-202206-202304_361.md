# 五个一血！安恒信息荣获“强网杯”一等奖，RealWorld榜单第一

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650540464&idx=1&sn=b7073eb4124c590a18994305b48bdebb&chksm=bef5a7c989822edf670352d067b13b7e7f769f57e1d4eaffe95468a43b7d092716dfe0001f3b&scene=126&sessionid=1681366436#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650540464&idx=1&sn=b7073eb4124c590a18994305b48bdebb&chksm=bef5a7c989822edf670352d067b13b7e7f769f57e1d4eaffe95468a43b7d092716dfe0001f3b&scene=126&sessionid=1681366436#rd)

8月20-21日，安恒信息DAS战队征战第六届“强网杯全国网络安全挑战赛”线下赛，在众多战队中脱颖而出，**勇夺一等奖（总分第四）**，其中在**RealWorld（基于实网软件/设备漏洞设置的赛题）分项赛中以绝对优势排名第一**。

![](../Images/e885ac042057ce51de2c30d84a4d4d87.png)安恒信息DAS战队部分成员 画船听雨、H4lo、Smi1e、Catalpa

第六届“强网杯”由中央网信办、河南省人民政府指导，信息工程大学、河南省委网信办、河南省教育厅、郑州市人民政府联合主办，教育部高等学校网络空间安全教指委协办，汇聚了来自全国各地的2358支战队、10147名选手，覆盖国家关键信息基础设施单位、重要行业部门、高等院校、科研机构、网络安全企业、互联网企业及社会力量等行业领域。

![](../Images/8f240d0044d195c918c6ae7c7679c5ee.png)

在RealWorld分项赛中安恒信息排名第一

  

线下赛首日，随着裁判长一声令下，精彩的战斗迅速打响。**安恒信息DAS战队在比赛开始仅17分钟时就第一个登台挑战RealWorld题目，成功拿到全场一血。**经过两天一夜的鏖战，安恒信息DAS战队一路披荆斩棘，过关斩将，最终获得RealWorld榜单第一名。值得一提的是，在全场解出的七道赛题中，**有五道题安恒信息DAS是最快解出（全场一血）的战队，PAN赛题全场唯一解**，体现了安恒信息在软件漏洞研究的国内顶尖水平。

  

![](../Images/3caeea53c5b7340af201f182a6e4226d.png)![](../Images/2f951817f9cca363242c7c900245f697.png)![](../Images/3a1f2de7aa210547de73bb64c3d53d6c.png)

DAS战队获得全场最快解出题目所获得的战旗

**安恒信息中央研究院**

**精锐集结  斩获荣誉**

**安恒信息中央研究院下设多个实验室，持续在Web应用、操作系统、移动安全、浏览器安全、物联网安全等方向开展漏洞研究工作，**先后挖掘包含微软、苹果、Apache、Google、Cisco、Paypal、Juniper、PaloAlto等大型软件及设备制造商相关应用的重大漏洞数百个，其相关研究成果也多次在BlackHat、HITB、ZeroNights、天府杯、GeekPWN等国内外顶级会议竞赛中展示。

**安恒数字人才创研院**

**实力创新  荣誉集锦**

安恒数字人才创研院恒星实验室主要从事网络安全领域技术研究与人才能力养成等方面的创新探索工作。在漏洞挖掘与研究方面，团队先后发现Cisco、Dlink、TP-Link等知名厂商设备漏洞并为其提供安全输出。近年来，实验室成员征战各大网络安全技能竞赛，成绩斐然；同时致力于将各类网络安全研究成果转化为课程和实验场景，为院校学生和从业人员提供实战导向的网络安全人才培养服务。
