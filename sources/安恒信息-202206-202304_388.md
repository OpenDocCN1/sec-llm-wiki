# 【行业标杆】数据安全岛赋能疾控中心释放数据计算价值

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650538975&idx=1&sn=30c427979a02e909d8bf5dac7d7bd3e5&chksm=bef5ada6898224b07fd02ffa25e2e9aefac199dfbf082a94cac270c0d4302dac21288a8f2b20&scene=126&sessionid=1681366441#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650538975&idx=1&sn=30c427979a02e909d8bf5dac7d7bd3e5&chksm=bef5ada6898224b07fd02ffa25e2e9aefac199dfbf082a94cac270c0d4302dac21288a8f2b20&scene=126&sessionid=1681366441#rd)

在大数据产业迅猛发展的背后，数据隐私安全相关问题也在逐渐暴露，传统“复制式”的数据流通方式让商业隐私信息、个人隐私信息等产生了泄漏，无法满足法律合规要求，需要通过创新的技术或模式来实现数据要素的可信流通。

**山东省疾控中心**是安恒信息多年来服务的老客户，作为山东省疾病预防控制工作的技术指导中心，在疾病预防与控制、突发公共卫生事件应急处置、疫情及健康相关因素信息管理等多项工作中发挥重要作用。同时，山东省疾控中心与著名高校开展合作共建公共卫生科研平台，推动产学研用协同创新发展与疾控领域人才培养。

  

**一**

**如何发挥疾控数据价值赋能科学研究**

疾控大数据是高校科研的重要依据和理论基础，在研究过程中必然涉及到疾控大数据的使用。如果通过拷贝的方式，势必会带来原始数据泄露问题，一旦发生数据安全事故，海量的用户个人隐私数据曝光，其后果不堪设想。  

因此，在本次疾控中心和高校的合作中，**疾控中心**要求自身数据不出本地，数据流通过程是密态的，并且对自身数据授权使用可控，高校对疾控中心的原始数据可用不用见；**高校**的科研算法不出本地，算法计算环境安全可靠，以此保障双方的利益，实现在公网环境下数据共享安全，科研成果共享。

**二**

**安恒信息AiLand数据安全岛平台优势**

在了解疾控中心高校双方的需求之后，安恒信息凭借多年来在隐私计算技术的实战化经验积累，提出在疾控中心的业务场景下构建风控模型，引入安恒信息“AiLand数据安全岛”平台，既保护原始数据隐私不泄漏，又保障了计算模型商业机密，实现了数据价值的流转。

![](../Images/430ca1489e8d28a930fa11b6177d7831.png)

疾控中心牵手高校联合科研课题研究方案图

彼时，业内众多安全厂商参与项目竞争。最终，安恒信息凭借技术应答的准确性、解决方案的完整性，以及长期合作树立的良好口碑，从众多安全厂商中脱颖而出，争取到了这个项目。  

  

  

AiLand数据安全岛平台是一个专注于保障数据安全流通，致力于解决数据共享的信任和隐私保护问题的数据开放和共享交换平台。综合应用了可信执行环境，联邦学习，多方安全计算（MPC）等多种前沿技术，配合密钥管理系统和区块链审计技术，实现共享数据的所有权和使用权分离，确保原始数据的“可用不可见”、“可控可计量”，保障多方数据联合计算过程的可靠、可控和可溯。

✓

国内首创大数据安全技术沙箱BDTee技术

搭建多方安全可信融合计算平台，提供安全计算沙箱、安全测试沙箱等功能，支持政府、企业、境内外企业直接在平台上开展数据处理和利用，实现原始数据不出域情况下，数据处理、分析和计算结果的跨组织、跨单位和跨境交互。

✓

区块链辅助的隐私计算技术创新

在数据安全计算任务完成后，主动销毁沙箱内的明文数据，并利用区块链技术保存沙箱审计日志，保障数据主动销毁的可信度。区块链辅助的隐私计算技术获得由信通院颁发的区块链辅助隐私计算基础能力专项评测证书。

✓

核心技术的自主可控

AiLand 数据安全岛平台在技术层面，基于大数据架构的 BDTee 软件可信执行环境，实现调试和执行环境分离，任务与计算容器绑定，多任务互不影响。此方案不依赖于国外硬件厂商，实现核心技术的自主可控。

  

目前项目进展顺利，疾控中心对安恒信息给予肯定的评价。**本次项目深入推进医疗数据在科研中的应用，充分挖掘医疗数据价值，充分发挥医疗数据在拓展科研思路、提高科研效率、促进医学专业建设的重要作用。而科研成果可进一步反哺疾控事业高质量发展，对整个社会流行疾病预防和控制的都有着深远意义。**  

  

充分发挥数据要素作用，离不开先进技术的加持。安恒信息在保障数据安全可控、数据隐私不泄露的情况下创造新的数据交易模式，合法合规、安全地对外开放数据，释放出数据的潜在价值，为我国的数据要素流通产业化贡献力量，助力数字经济发展高质量发展。

  

  
**AiLPHA大数据智能安全事业群**  

    AiLPHA大数据智能安全事业群在安恒信息首席科学家刘博博士带领下，以“智引新安全，数领大未来”为理念，打造行业引领的态势感知、数据安全、零信任、隐私计算系列产品。目前AiLPHA平台产品已经服务于全国200多家省市级监管单位，3000余家中大型政府、企业、金融、运营商等单位。产品和技术累计获得世界互联网大会领先科技成果、工信部示范试点项目、“携手构建网络空间命运共同体精品案例”等60多个奖项，团队拥有核心技术发明专利400余项，承担省部级重大课题10项，核心产品AiLPHA态势感知平台连续多年被第三方咨询机构评为国内综合排名第一。
