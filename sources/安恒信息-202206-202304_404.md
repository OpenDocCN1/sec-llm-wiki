# 安恒信息亮相数字中国建设峰会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650537271&idx=2&sn=2e132aad51c267fbed96a74c18b1183b&chksm=bef2534e8985da582250d3d69789d8d4a52b68dde627932e33635fc5da9d01958e1a202a2b43&scene=126&sessionid=1681366446#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650537271&idx=2&sn=2e132aad51c267fbed96a74c18b1183b&chksm=bef2534e8985da582250d3d69789d8d4a52b68dde627932e33635fc5da9d01958e1a202a2b43&scene=126&sessionid=1681366446#rd)

![](../Images/3e4a632bc3cee682a2e42de57f057f71.png)

由国家互联网信息办公室、国家发展和改革委员会、科技部、工业和信息化部、国务院国有资产监督管理委员会、福建省人民政府共同主办的第五届数字中国建设峰会23日在福建省福州市开幕，围绕“创新驱动新变革 数字引领新格局”这一主题，安恒信息全面展现数字化进程中领先成果及创新风采。

![](../Images/8bc5a23894a41920594e736bb3b05729.png)

  

***四个统一***

**构筑数字化时代安全底座**

**安恒信息董事长范渊在数字中国建设峰会网络安全论坛上发表《筑牢数字化改革网络安全根基》主题演讲**，此次网络安全论坛由国家网信办、福建省人民政府主办，国家网信办网安局、福建省网信办、泉州市人民政府共同承办。论坛以“守护云服务安全，护航数字中国建设”为主题，邀请国内知名院士、专家学者以及网络安全头部企业高管共同参与，围绕云安全形势、云计算服务安全评估政策进行深入研讨。

![](../Images/362b0661d951501044590cb05e06dbe7.png)

安恒信息董事长范渊演讲

![](../Images/b7f4b651b3c55aca5b820fe834ec8906.png)

在范渊看来，相当长一段时间内，在可信、可用、可管的前提下，数据产品等数字资产将在各个行业开花结果，数字资产很可能成为贯穿数字政府、数字经济、数字社会、数字文化和数字生态等协同发展和相互交融的关键血液。  

安恒信息致力于构建“网络安全和数据安全统一，安全态势和安全预警、预防统一，安全合规与安全实战统一，开放性和系统性统一”的“四统一”数字安全底座，同时结合安全托管运营及隐私计算，为各行业用户实现更轻松、更合规、更多的价值延伸提供了可能。

  

***生态共赢***

**打造数字城市发展新动能**

作为峰会重要组成部分，**云生态大会**以“共铸国云 智领未来”为主题，旨在助力建设网络强国、数字中国和数字社会，夯实数字技术新基础，激发数字经济新活力，推动云计算产业科技创新。安恒信息作为天翼云重要合作伙伴，与华为公司、中兴通讯、软通动力集团、用友网络等行业知名企业出席合作论坛，**安恒信息高级副总裁郑赳带来《生态共筑安全国云》主题演讲**，分享创新，助力企业上云，为各行各业数字化改革筑牢安全底座。  

![](../Images/f49e3a69eb535968bdd5c423de411864.png)

安恒信息高级副总裁郑赳演讲

数字城市的发展离不开生态伙伴的支持，安恒信息在提供网络安全整体保障方案的同时，积极携手生态合作伙伴落地合作城市。**大会****现场，安恒信息被授予“2022年最具价值云应用合作伙伴”，**未来，安恒信息将持续推动天翼云应用生态合作伙伴体系建设，联合应用生态合作伙伴整合技术、平台及团队资源，为城市的数字经济发展添砖加瓦。  

![](../Images/17ec70e1d40ed4d87d31280b7195b2d4.png)

![](../Images/9985a6b9607df79644832004b214fe1a.png)

左三：安恒信息副总裁、电信集团事业部总经理秦树春

  

***积极践行***

**多维展示数字城市安全保障能力**

安恒信息作为数字中国建设的积极参与者，亮相本次数字中国建设成果展，为大家多维度展示数字城市安全技术能力、建设行业场景和实践案例，引发各方关注。

![](../Images/dba9b110e7ea0c60c5449c793f1c7417.png)

以技术赋能的数字经济是驱动城市数字化发展的核心引擎，而安全则是发展的前提。如何设计定制化的安全运营方案，立足城市数字化管理和创新治理，服务于政府决策科学化、社会治理的精准化以及公共服务的高效化，为城市数字经济的发展保驾护航成为日渐突出的问题。安恒信息展示的新型数字城市安全保障体系，以“四统一”数字安全底座为基础，通过城市安全大脑，将情报价值赋能到各类安全产品和应用场景，形成城市治理数字化运营能力。充分赋能数字化改革相关的数字智治、数字政府、数字经济、数字社会、数字法治等应用场景，让安全成为城市关键的信息基础设施。  

在峰会同期举办2022数字中国创新大赛，在网络安全赛道车联网安全赛中，**安恒车联网安全技术有限公司天问实验室获得车联网安全场景挑战赛团队赛一等奖**；在鲲鹏赛道全国总决赛中，**安恒信息AiLPHA大数据实验室的Tony荣获二等奖**，充分展示了安恒信息与时俱进的创新实力。

![](../Images/f18b6b7b84c739110d1fab898a4c08a7.png)![](../Images/65df0291019037eff2a152aa16aa3cf5.png)

2022数字中国创新大赛获奖

承接新时代赋予的新使命，安恒信息深化重点垂直行业创新应用，聚焦工业、政务、金融、教育、医疗、个人信息等多个领域，筑牢数字化改革安全根基，助力社会各领域数字化转型、智能化升级、融合化创新。
