# 大胜！第二届“鹏城杯”联邦靶场协同攻防演练决赛预赛双第一

近日，第二届“鹏城杯”联邦靶场协同攻防演练赛决赛成绩出炉，历经27小时激烈奋战，**安恒信息数字人才创研院恒星实验室****从全国40支决赛队伍中脱颖而出，****以超出第二名1100分的成绩****实力取胜****，荣获一等奖****。**  

![](../Images/1c471dfbd81fcb80bb0b124cc0879748.png)![](../Images/0027d823f9e2eebf1bf3998c6307f2e0.png)

2022/7/18

![](../Images/ec764daf29add966fb68b3f0ade18066.png)

鹏城实验室是中央批准成立的突破型、引领型、平台型一体化的网络通信领域新型科研机构。第二届“鹏城杯”网络安全竞赛由中国网络空间安全协会竞评演练工作委员会指导、鹏城实验室主办，面向全国企事业单位、高校和科研院所的网络安全团队，通过竞赛的方式，“以赛促学、以赛促练”，提高网络安全人才技能水平，提升网络安全人才队伍专业素养，带动更多人才投身到国家网安事业中。  

本届“鹏城杯”，恒星实验室共派出glzjin、Alphabug、Xenny、美豆4名90后、00后选手出战。值得一提的是，初赛为CTF线上解题赛，决赛为联邦靶场智慧城市场景协同攻击模式，恒星实验室的**初赛和决赛成绩均位列第一名，充分展示了选手们扎实的理论基础研究和丰富的攻防对抗实战经验。**

当今世界网络安全形式瞬息万变，攻击手段日新月异，关键基础设施安全保护面临严峻的风险和挑战。人才是第一资源，创新是第一动力。安恒信息将人才培养、技术创新和企业发展有机融合，打造网络安全人才精英团队，提升应急响应作战水平，强化关键信息基础设施的网络安全防护体系建设，为国家网信事业的发展提供坚强的人才储备和技术支撑。

**恒星实验室介绍**

恒星实验室由安恒信息数字人才创研院“叶雷鹏网络与信息安全管理员技能大师工作室”牵头组建，主要从事网络安全领域技术研究与人才能力养成等方面的创新探索工作。近年来实验室成员征战各大网络安全技能竞赛，成绩斐然；漏洞挖掘与研究方面也先后发现Cisco、Dlink、TP-Link等知名厂商设备漏洞并获得致谢，并致力于将各类网络安全研究成果转化为课程和实验场景，为院校学生和从业人员提供实战导向的网络安全人才培养服务。
