# 来自国家信息安全漏洞库的感谢信！

7月8日，**国家信息安全漏洞库（CNNVD）向安恒信息在内的11家单位发来了感谢信**。针对2022年上半年国家信息安全漏洞库（CNNVD）“漏洞通报”业务开展中，安恒信息等技术支撑单位积极参与、大力支持，在报送的漏洞通报数量和质量方面贡献突出，为我国网络安全漏洞通报、消控等工作发挥了积极作用，依据《CNNVD技术支撑单位计划指南》给予公开致谢。

![](../Images/3d5e8250fb7110d630cc331ebeec1316.png)

**CNNVD**

  

中国国家信息安全漏洞库（CNNVD），是国家信息安全测评中心为切实履行漏洞分析和风险评估的职能，负责建设运维的国家信息安全漏洞库，为我国信息安全保障提供基础服务。创办至今已经在信息安全漏洞搜集、重大漏洞信息通报、高危漏洞安全消控等方面发挥了重大作用，为我国重要行业和关键基础设施安全保障工作提供了重要的技术支撑和数据支持。

  

安恒信息自2014年成为首批入选国家信息安全漏洞一级支撑单位的厂商以来，积极为CNNVD提交重要数据漏洞，多年来，凭借实力和丰富经验先后获得来自CNNVD的多项荣誉。**2021年，安恒信息荣获CNNVD颁发的“2021年度特殊贡献奖”和“2021年度优秀技术支撑单位”，****不断支持国家漏洞库的建设，助力信息安全漏洞研究。**

![](../Images/d7170536e4329dde60d4d45ab0a24216.png)![](../Images/e0671775e67af60abd0d0130384b9558.png)

  

安恒信息持续跟踪各种操作系统与应用系统漏洞和恶意代码，建立了全面专业的攻击特征库、漏洞库和恶意代码库，发现并解决了大量国内外各类高危漏洞，其中多个获得CNNVD、CVE漏洞编号。**每次发现通用系统高危漏洞和安全缺陷后，均第一时间提交给CNNVD及客户并协助修复。**

❖

本次收到感谢信，是国家信息安全漏洞库对安恒信息所做工作的认可，同时也激励着安恒信息在未来持续跟踪国内外安全漏洞情况，积极响应CNNVD工作。目前，互联网的迅速发展，相伴产生的新安全问题也层出不穷，基础网络和新型网络产品带来的漏洞风险日益上升，潜藏的安全漏洞问题将会给网络不法分子以可乘之机，所引发的安全事件可能直接导致关键基础设施网络被攻击，我国数据信息保护仍面临严峻挑战。作为一家有社会责任感的网络安全企业，**安恒信息将一如既往地履行维护网络安全的责任和义务，不断在网安领域尤其是漏洞研究领域深耕，基于专业性发挥丰富实战经验和技术能力，为维护国家网络安全贡献“安恒”力量！**
