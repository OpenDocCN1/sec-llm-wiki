# 筑牢数字经济安全基石|2022西湖论剑·数字化改革主题论坛成功举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTE0MjQyMg==&mid=2650534535&idx=2&sn=2ca113c12a0beeb8d9b481d5f4bcfe88&chksm=bef25cfe8985d5e876f455af591b3b24888149d9dacfb325887492944f4d2a2d931285073b0a&scene=126&sessionid=1681366456#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTE0MjQyMg==&mid=2650534535&idx=2&sn=2ca113c12a0beeb8d9b481d5f4bcfe88&chksm=bef25cfe8985d5e876f455af591b3b24888149d9dacfb325887492944f4d2a2d931285073b0a&scene=126&sessionid=1681366456#rd)

7月2日，**2022西湖论剑·网络安全大会数字化改革主题论坛在浙江杭州举行**。中国工程院院士谭建荣，浙江省大数据发展管理局副局长蒋汝忠，公安部第三研究所网络安全法律研究中心主任黄道丽，嘉善县委副书记、县长张锡锋，湖州市大数据发展管理局党组书记、局长蔡丰，杭州市数据资源管理局党组成员、数据资源与安全处处长齐同军，浙江大学网络空间安全学院院长、教授任奎，安恒信息首席科学家、高级副总裁刘博出席本次论坛。

数字化改革主题论坛嘉宾金句

当前，新科技革命和产业数字化变革蓬勃兴起。**谭建荣提到，网络安全技术不是孤立的，是随着数字化、网络化、智能化技术演进，以及数字经济发展而提升的。**在数字化转型升级过程中，数字经济发展和网络安全保障“两个轮子”缺一不可。正确的网络安全观是将数据盘活，利用先进的安全技术、可靠的安全措施，保证数字经济和数字化转型健康、快速、高质量发展。

![](../Images/6771ea451a8c067843ce87d6cc175555.png)

中国工程院院士谭建荣

  

于2022年3月施行的我国首部公共数据领域地方性法规《浙江省公共数据条例》，围绕公共数据统筹管理、有序共享开放及安全利用提出了浙江方案。**蒋汝忠认为，制度安全是网络安全的重要方面。**浙江省公共数据制度提出一体化数字基础设施、数据目录体系、数字资源体系、数字资源体系、数据标准体系及共享开放通道等六方面一体化建设任务，未来要进一步贯通制度规范体系，强化技术防护。

![](../Images/901ecd007955586f7702b30fe2b69b21.png)

浙江省大数据发展管理局副局长蒋汝忠

  

**有法可依，方能“依法善治”。**针对新时代数字经济安全的法治保障，黄道丽认为，一是要避免法律法规对数据流通的过度监管，抑制产业创新；二是要在数据出境、等级保护、认证及检测等制度方面，做好立法的衔接；三是持续性推动重要数据保护、数据促进评估、个人信息认证等细化规则落实。

![](../Images/722946d2dd56e5cbfaaa6e1036f2fb8d.png)

公安部第三研究所网络安全法律研究中心主任黄道丽

  

从法律法规制定到落地实践，网络安全需要进行生态治理。论坛上，张锡锋围绕构建县级网络安全生态治理体系的长三角一体化示范区嘉善探索作主题演讲，介绍了嘉善数字化改革推进情况，嘉善构建县域网络安全生态治理体系实践探索以及初步工作成效。他表示，**嘉善将全面拥抱数字变革，不断夯实数字网络安全底座，推动县域安全体系构建重塑再造，为长三角乃至全国贡献示范经验。**

![](../Images/c1ca617a803896d4368564c6c3f62493.png)

嘉善县委副书记、县长张锡锋

  

蔡丰围绕**“用数智绘就城市未来”**的主题，讲述了湖州数字化改革工作。他提到，数据供给力就是数据的整体规制，湖州正在跨多领域归集大量数据，将其放在不同网络里，通过打造民生领域云平台与政务数据形成有效互补。

![](../Images/21a338b1c7cecd38eb8dcd0c6fe1789b.png)

湖州市大数据发展管理局党组书记、局长蔡丰

  

“构建安全可信的数字世界，**需要解决三类问题：防御外部网络安全威胁，细粒度感知和管控内部数据使用，数据共享给不可控第三方时的新风险问题。**”围绕数据安全与隐私计算实践，刘博表示，通过态势感知常态化，可以有效规避数据安全的风险，他建议以数据安全治理的思路落地“安恒数盾”整体解决方案，从安全咨询规划出发，做好合规保障，进而做到风险可控。

![](../Images/a2a1d3dcc3dfbecd0eafaa720b3b4c36.png)

安恒信息首席科学家、高级副总裁刘博

  

“数据被称为新时代的‘石油’，我觉得它比石油更重要。我们可以通过交易，把数据从原来为一个部门、一家企业所用，变成社会上所有企业、所有政府部门都可以用，这样数据就可以发挥更大价值。”**任奎围绕数据要素安全合规审计的智能化探索表示，合规审计工具是数字化转型的关键，技术创新配合良好应用工具，可以极大提升审计工作效率和质量**。

![](../Images/775d1eebb1d339e41248577f2b6c26c2.png)

浙江大学网络空间安全学院院长、教授任奎

  

齐同军就数字化时代下数字交易和安全保障作主题演讲。他表示，**期待建立合规高效的数据要素流通和交易制度，做到有章可循，**不断完善数据要素市场化配置机制，使安全贯穿数据治理全过程，既要“要素”，又要“安全”。

![](../Images/f479023b227f33ff4e8c00b442b0c890.png)

杭州市数据资源管理局党组成员、数据资源与安全处处长齐同军

  

为推动《数据安全法》的贯彻实施，汇聚数字经济高质量发展动力，**论坛中，“2022数据安全典型示范应用十大案例”揭晓。**

![](../Images/b9b0e22795addcaba82a718d184d1acf.png)

2022数据安全典型示范应用十大案例

  

2022西湖论剑·网络安全大会数字化改革主题论坛由浙江省互联网信息办公室、浙江省经济和信息化厅、浙江省公安厅、浙江省科学技术协会、浙江省工商业联合会、浙江省通信管理局、杭州市人民政府主办，国家计算机网络应急技术处理协调中心、中国网络空间研究院、中国信息通信研究院、中国电子信息产业发展研究院、国家工业信息安全发展研究中心、中国电子技术标准化研究院联合主办，安恒信息、之江实验室、杭州市互联网信息办公室、杭州市经济和信息化局、杭州市滨江区人民政府、国家计算机网络应急技术处理协调中心浙江分中心、浙江省网络空间安全协会、浙江省计算机信息系统安全协会共同承办。
