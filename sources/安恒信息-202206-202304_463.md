# 【论剑预热】护航数据安全 共话个人信息保护

伴随数字产业化、产业数字化迅速发展，当下各行各业正在全方位推进数字化改革的同时，数据安全、个人信息保护、关键信息基础设施安全等问题持续存在，这些问题不仅关系着国家安全、社会稳定，也关系着广大人民群众在数字时代的获得感、幸福感、安全感。尤其在数字时代，现实与网络的区隔进一步消弭，个人信息会在各种各样的平台上留下痕迹，其中不免出现对个人信息的非法收集、滥用、泄露等问题情况，个人信息安全面临严重威胁。

2021年9月1日，《中华人民共和国数据安全法》正式施行；11月1日，《中华人民共和国个人信息保护法》正式实施。法律条例的颁布落地进一步显示出数据安全与个人信息保护的重要性，这一背景下，如何护航数据安全，加强个人信息保护同样成为网络安全领域学界和业界所关注的重点。  

为共话新时代网络安全新议题，**2022西湖论剑·网络安全大会特开设数据安全治理和个人信息保护论坛，将于7月3日下午13:30在北京隆重召开，并通过西湖论剑官方网站、新华网、光明网等平台同步线上直播。**

作为大会的重要活动之一，本论坛由全国信息安全标准化技术委员会秘书处主办，中国电子技术标准化研究院、中国信息协会信息安全专业委员会、清华大学技术创新研究中心、杭州数据安全联盟、杭州安恒信息技术股份有限公司承办。论坛**以“加强数据安全和个人信息保护标准宣贯实施、促进标准应用与技术产业协同联动”为目的**，将邀请相关部门领导解读数据安全治理和个人信息保护相关政策法规，邀请业界专家围绕数据安全产业面临的发展机遇和安全挑战，聚焦数据安全保护和跨境合规、个人信息保护标准实践、数据安全评估与认证、“东数西算”工程及企业数据安全治理体系等主题，分享标准与技术的最佳实践。同时，将举行数据要素流动安全与资产合规交易圆桌对话，助力各行业各组织数据安全治理和个人信息安全保障体系建设。

**《个人信息与隐私保护白皮书》**与主题内容相衔接，也将在本次论坛上发布。白皮书中将针对个人信息如何界定，法律规定的隐私权是什么？个人信息与隐私保护现状如何，有哪些泄露个人隐私的典型事件，又是怎么发生的？作为个人，我该怎么办……等问题进行解读。（点击阅读原文，参与白皮书免费寄送活动）
