# 看、学、玩|邀你来逛西湖论剑主题科普展啦

2022西湖论剑·网络安全大会（以下简称“西湖论剑”）佳期渐近，大会中各个创新亮点也正逐渐惊喜揭面。  

6月22日，2022西湖论剑网络安全科普展正式亮相浙江省科技馆，作为首个入驻省级科技馆的网络安全大会科普展，本次展览由浙江省科学技术协会主办，安恒信息承办，浙江省科技馆给予支持与保障，备受业界关注。展览主题丰富，形式多样，通过“看、学、玩”相结合的方式，向社会群体普及宣传网络安全知识。**浙江省互联网信息办公室副主任马晓军、浙江省科学技术协会副厅长级领导王忠民****和安恒信息党委书记、高级副总裁张小孟****出席启动仪式。**本次活动吸引包括浙江卫视、浙江日报、杭州日报到场报道，同时得到了都市快报、浙江经视、华数传媒、网易、天目新闻、科技金融时报、今日头条、北京科技报运维的省科协新媒体官宣矩阵共同报道支持。

![](../Images/27f080be5698f45840d664c5b65448a2.png)

浙江省互联网信息办公室副主任马晓军（中）、浙江省科学技术协会副厅长级领导王忠民（右）和安恒信息党委书记、高级副总裁张小孟（左）共同启动西湖论剑网络安全科普展

马晓军在致辞中表示，据第49次《中国互联网络发展状况统计报告》显示，截至2021年12月，我国网民规模已达10.32亿,其中10-39岁网民占比达50.5%，加强学生群体、青年群体网络安全教育，使其成为网络安全的宣传者、践行者和维护者，对于提升全社会网络安全素养至关重要。

西湖论剑网络安全科普展共分为5个展区，内容上涉及黑科技破解体验、个人信息安全知识普及、防范电信网络诈骗等，并加入了网络安全闯关游戏，通过多元生动的方式寓学于乐，传递网络安全防范知识与技巧，让网络安全走进人民，服务人民。

  

![](../Images/0761693f58e1d76b3ec50aef857c72d1.png)

  

**涨知识：守护你的个人信息**

当网络技术的快速发展和迭代赋予经济社会发展强大的助推力，暗藏在背后的风险和挑战也悄然出现。当今社会如何守护好个人信息安全？来这个展区就能找到答案！**展览期间，本展区将轮流播放有关“网络安全意识生活篇”的三集动画片，看视频的过程中轻松get保护个人信息小知识！**

![](../Images/a989e1a630534d5e52d058028cb66d5e.png)

  

**看实例：智慧生活 从安全开始**

智能化、万物互联的理念正逐渐深入人心并应用于生活的各个方面，其中，智能家居无疑给居家生活提供了极大的便利，但安全永远是智能的底座。设想在遭受网络攻击的情境下，摄像头可能会无故转动，人脸识别门锁仅用照片就能打开……若无法保障智能家居的网络安全，后果将难以预料。**在本展区中，除了展播物联网破解视频外，还可现场体验手机蓝牙窃密、智能电视、智能音箱等互动，以此反推如何真正规避安全漏洞，面对即将到来的智能家居时代，掌握物联网安全的秘诀。**

![](../Images/d05863fd8030ffb32136d343d58eb5b6.png)

  

**畅玩乐：“元宇宙”工厂**

元宇宙是什么？它是一个将所有⼈相互关联起来的“3D虚拟世界”。在元宇宙，你可以拥有自己的数字身份。进⾏开放性的探索和社交，还可以通过智能终端设备参与虚拟世界的游戏和娱乐，虚实互动，任何你想要的东西，都能在元宇宙中创造。元宇宙或将成为又一种全新的互联网形态，网络安全也将成为元宇宙发展的重中之重。**在这个展区，通过播放视频带你了解神秘的“元宇宙”，同时还能在互动区体验VR小游戏，扫描“西、湖、论、剑”几个字，进行答题闯关。答对每一道题后，即可获得“安全小卫士”称号，还能获得一份神秘礼品哦。**

![](../Images/16dbc50c47a10ab2617bdd04bbc382f0.png)

  

“云”逛展觉得意犹未尽？还有“反诈大本营”展区、“网络空间安全”展区等待解锁。6月22日-30日，邀小伙伴一起，来浙江省科技馆线下实地打卡“西湖论剑”主题科普展吧！另设巧手DIY小工厂等你体验，制作专属于你的徽章、镜子、冰箱贴等精致小物件。“没有网络安全就没有国家安全”，在逛与玩中了解更多网络安全小知识，提升网络安全意识，共筑网络安全防线！
