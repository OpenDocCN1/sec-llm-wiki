# 应邀参加西湖论剑 谭晓生纵论后疫情时代网络安全

6月16日，2020西湖论剑·网络安全线上峰会如期召开。本届大会主题为“数治安全·智理未来”，即以数字技术变革来推动治理变革，将网络安全赋能数字治理，用智能化的治理手段保证未来安全。

![](../Images/69305b2fc8eec5f48c1c1eb596c759db.png)

  

提到网络信息安全，在这个圈子里，有一位响当当的人物，真正称得上“平生不识陈近南，纵使英雄也枉然”。他的名字，叫谭晓生。  

  

 谭晓生，1992年毕业于西安交通大学计算机科学与工程系计算机应用专业，科班毕业，技术出身，于去年3月成立了北京赛博英杰科技有限公司，在安全圈子里有着极高的威望，被亲切地称呼为“谭校长”。借助本次峰会，赛迪网记者有幸采访到这位英雄级人物。

  

  

应邀参加西湖论剑，“谭校长”纵论安全运营

  

在本次峰会的安全运营分论坛上，谭晓生针对安全运营的标准和模型做了分享。谈到2020西湖论剑·网络安全线上峰会，谭晓生表示，网络安全从不是“单打独斗”，而是“协同作战”。只有共建共治，才能共享网络安全生态。西湖论剑经过几年的发展，已经成为了网络安全会议的一大品牌。本次峰会邀请到了相关主管部门领导、专家学者开展了近70场专题报告与主题演讲，进一步提升了后疫情时代全社会网络安全意识，更好的推进了网络安全工作。作为本次会议的承办方，杭州安恒信息技术股份有限公司近年来成功跻身网络安全空间企业第一阵营，在进行研发创新和市场开拓的同时，参与了众多国家与行业标准的制定，积极承担着助力我国信息安全产业发展的社会责任。  

 

![](../Images/881376dfd44cfab7521a3fab1f8430df.png)

  

谭晓生认为，网络安全运营在近两年内备受重视，不仅需要一个统一的行业标准，还需要动态的演进与提升。

  

目前的网络安全运营标准尚未在行业内形成共识，而对于中国来说，应当拥有一个具有足够公信力的标准作为准绳，对网络安全运营进行评测与认证。此外，针对网络攻防演习与安全运营的关系，他认为网络攻防是一个动态的过程，而这一过程就是运营的过程。“网络安全面对的是未知，对于防守方的要求非常高，不仅是照本宣科把东西做出来，还要根据新的威胁改善你的防御体系，有一个动态的去演进，去提升的过程。”谭晓生表示。

 

  

后疫情时代，对网络安全行业的影响是暂时性的

  

就目前来说，疫情的爆发对经济影响颇大。谈及疫情对于安全行业的影响。谭晓生在采访中说，当生活、学习、工作、社交、娱乐全部切换到网上时，网络安全已经成为人类社会生存发展的基础，而网络安全运营也成为了一大重要课题。但是后疫情时代，对网络安全行业的影响是暂时性的。

  

首先，谭晓生阐述了疫情对网络安全行业产生的不利影响。他认为，在全球的一体化的前提下，中国的经济受全球经济下滑的影响很大。还有一些中小企业现在开工不足，这其实是一个连锁的效应，后面会持续产生影响，中央和地方的财政收入和支出受到影响，在短期内会压缩网络安全方面的投入。包括企业在网络安全的预算可能会受到压缩。另外，一些工程可能会被滞后，回款可能也会延迟，甚至有些项目可能会被取消。

  

![](../Images/8016e8c1858524e265cda51f3f3f250c.png)

  

当然，谭晓生认为，新冠肺炎疫情对网络安全行业也会产生一些有利的影响。比如，后疫情时代，中国加大了对新基建的支持力度，尤其是5G和人工智能。在进一步刺激经济发展的过程之中，对于网络安全的需求客观上呈增加趋势。

  

但是在提到疫情期间对民众信息轨迹的搜集时，谭晓生也表达了自己的担忧。他认为，这些信息非常危险，甚至会影响国家安全，所以在短期会有不利影响。但是中长期来看，这是一个大的利好消息。对于网络安全企业来讲，现在选择活下去，需要提高效率，控制成本，然后活到明天、后天。

  

  

线上会议将在一段时间内维持高姿态

  

谭晓生认为，经过这次疫情的冲击，线上活动将成为众多企业的一种常态化选择。他特从几点进行分析：

  

第一， 本次疫情将会持续一段时间。虽然目前国内疫情有了很大好转，但今年冬天会不会再来一波，或者境外输入会不会给中国带来新一轮影响，都是未知数。

  

第二，疫情期间，大部分企业选择网络会议的形式，不用在北京拥堵的路上来回跑，也不用再坐几个小时飞机高铁到另外一个地方，协同效率大大提高。

  

第三，除了线上会议之外，很多公司开始线上协同办公，其背后就是线上的协同系统，这都是数字化转型过程中一些支撑性平台或者工具的应用。

  

最后，谭晓生总结道，后疫情时代，企业数字化转型意识越来越强。可以说，疫情加速了企业的数字化转型趋势，而这种趋势还会持续下去。即便未来某个时点权威机构宣布疫情解除，人们出于防范需要也不会立刻放松警惕，毕竟新冠疫情的潜伏期太长。届时，线上会议将在一段时间内维持高姿态。

  

据悉，西湖论剑·网络安全大会已成功举办了八届，自创办以来，大会始终关注互联网发展趋势，立足推动网络安全行业有序健康发展。共同分享成果观点、共同促进技术创新、共同参与网络治理、共同推进网络强国建设，西湖论剑目前已经成为中国网络安全大会的金名片，其核心价值正逐步落地全国、赋能数字中国建设。
