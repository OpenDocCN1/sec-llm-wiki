一、漏洞介绍


SpringCloud Gateway 是基于 Spring Framework 和 Spring Boot 构建的网关，它旨在为微服务架构提供一种简单、有效、统一的 API 路由管理方式。


于2022年3月1日，VMware发布安全公告，Spring Cloud Gateway中存在远程代码执行漏洞（CVE-2022-22947）。当启用或暴露不安全的 Gateway Actuator 端点时，使用 Spring Cloud Gateway 的应用程序容易受到代码注入攻击，远程攻击者可以通过发送恶意请求以执行任意代码。


二、漏洞影响版本


Spring Cloud Gateway 3.1.0Spring Cloud Gateway 3.0.0 - 3.0.6Spring Cloud Gateway 其它不支持的、已不再更新的版本

（1）回显的原理：

在有回显利用链中，Spring不仅对过滤器的name进行过滤，对args的参数类型、参数个数也有对应的限制，可通过查看官网中的过滤器详情进行判断是否存在可利用链。


修复方案


1

临时修复方案

（1）如果不需要 Actuator接口，可以通过如下配置将其禁用,由于Gateway网关是通过Spring的Actuator接口统一管理的,而此漏洞的漏洞原理是创建网关后通过Actuator刷新网关时触发漏洞的,所以关闭Actuator接口或限制可访问此接口IP是最快捷的方法。

management.endpoint.gateway.enabled=false

（2）如果系统需要使用Actuator 接口进行系统业务监测之类的操作，则应通过 Spring Security 对这些高危接口进行身份验证,并杜绝出现弱口令。
