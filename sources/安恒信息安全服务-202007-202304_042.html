前 言

平时做安全服务除了要懂挖掘漏洞外，应急响应也是不可或缺的技能，本文将会为大家介绍整理一些较为常用的linux应急排查指令，包括查看用户信息、历史命令、端口、进程、服务等内容。



1.查看用户信息


用户信息存放在/etc/passwd和/etc/shadow两个文件中。

系统默认特权用户只有一个root（uid为0），当应急时可以查看passwd是否有其他特权用户，可以使用命令

awk -F: ‘$3==0{print $1}’ /etc/passwd


查看用户信息文件：

/etc/passwd


查看影子文件：

/etc/shadow


查看系统是否还存在其他的特权账户：

awk -F: ‘$3==0{print $1}’ /etc/passwd #uid 为 0，默认系统只存在 root 一个特权账户。

查看当前登录用户：

who #tty:本地登陆  pts:远程登录


w #查看系统信息，想知道某一时刻用户的行为


下图表示，用户ubuntu通过远程登录到服务器（pts就是远程），from是客户机ip，登录时间等等。

uptime #查看登陆了多久、多少用户，负载


passwd -d username #删除用户口令


stat /etc/passwd #查看密码文件上一次修改的时间如果最近被修改过，那就可能存在问题。


cat /etc/passwd | grep -v nologin #查看除不可登录以外的用户都有哪些，是否有新增的
cat /etc/passwd | grep x:0 #查看哪些用户为 root 权限，是否有新增的
cat /etc/passwd | grep /bin/bash #可以查看哪些用户能够使用 shell



查询可以远程登录的账号：

awk ‘/$1|$6/{print $1}’ /etc/shadow


查询具有 sudo 权限的账号：

more /etc/sudoers | grep -v “^#|^$” grep “ALL=(ALL)”

2.历史命令


当应急的时候我们最需要的就是查看攻击者做了什么，使用history命令就可以查看历史命令，排查攻击者做了什么。


很多的服务器会有存在多用户登陆情况，登陆 root 用户可查看其他用户的相关账户登录信息，其中 .bash_history 保存了用户的登陆所操作的命令信息。

home/root/.bash_historyhistory 查看历史命令


cat .bash_history >>history.txt 保存历史命令

4.查看进程


ps -aux 查看


如果某个程序的cpu占用过高，可以通过pid查看对应程序：

ps –aux | grep pid


监控某一应用线程数（如 ssh）：

ps -eLf | grep ssh| wc –l


监控网络客户连接数：

netstat -n | grep tcp | grep 侦听端口 | wc -l


ps aux –sort=pcpu | head -3#查看 cpu 占用率前三的进程

8.top 命令


top 命令是 Linux 下常用的性能分析工具，能够实时显示系统中各个进程的资源占用状况，类似于 Windows 的任务管理器。


默认 top 是根据 cpu 的占用情况进行排序的：


top -p pid 监控指定进程


free 查看当前系统内存使用情况


top -b -n1 | head

10.日志分析


日志默认存放位置：

var/log


查看日志配置情况：

more /etc/rsyslog.conf


登录失败记录：

/var/log/btmp     //lastb


最后一次登录：

/var/log/lastlog  //lastlog

登录成功记录: 

/var/log/wtmp     //last

登录日志记录：

/var/log/secure

目前登录用户信息：

/var/run/utmp  //w、who、users

历史命令记录：

history

仅清理当前用户：

history -c

定位有多少 IP 在爆破主机的 root 帐号：

grep "Failed password for root" /var/log/secure | awk '{print $11}' | sort | uniq -c | sort -nr | more

11.文件清除


很多时候会遇到无法查看文件权限或是病毒在一直向某个文件写入程序，可尝试如下命令：

lsattr 恶意文件  #查看文件属性
e：该文件使用extends来映射磁盘块i：文件不能被删除


解除文件锁定：

chattr -i 恶意文件

结束某一进程：

Kill -9 pid
