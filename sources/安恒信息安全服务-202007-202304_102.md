**四**

**组策略首选项提权分析及防范**

  
  
  

  

**一、组策略首选项提权简介**

  

SYSVOL是活动⽬录⾥⾯的⼀个⽤于存储域公共⽂件服务器副本的共享⽂件夹，在域中的所有域控制器之间进⾏复制。SYSVOL⽂件夹是安装活动⽬录时⾃动创建的，主要⽤来存放登录脚本、组策略数据及其他域控制器需要的域信息等。SYSVOL在所有经过身份验证的域⽤户或者域信任⽤户具有读权限的活动⽬录的域范围内共享。

  

在⼀般的域环境中，所有机器都是脚本化批量部署的，数据量通常很⼤。为了⽅便地对所有的机器进⾏操作，⽹络管理员往往会使⽤域策略进⾏统⼀的配置和管理。⼤多数组织在创建域环境后，会要求加⼊域的计算机使⽤域⽤户密码进⾏登录验证。为了保证本地管理员密码的安全性，这些组织的⽹络管理员往往会修改本地管理员密码。

  

尽管如此，安全问题依旧存在。通过组策略统⼀修改的密码，虽然强度有所提⾼，但是所有机器的本地管理员密码都是相同的。攻击者获得了⼀台机器的本地管理员密码，就相当于获得了整个域中的所有机器的本地管理员密码。

  

**二、针对组策略首选项提权的防御措施**

  

在⽤于管理组策略的计算机上安装KB2962486补丁，防⽌新的凭据被放置在组策略⾸选项中。

  

此外，需要对访问权限进⾏设置，具体建议如下：

*   设置共享⽂件夹SYSVOL的访问权限。
    
*   将包含组策略密码的xml⽂件从SYSVOL⽬录中删除。
    
*   不要把密码放在所有域⽤户都有权访问的⽂件中。
    
*   如果需要更改域中机器的本地管理员密码，建议使⽤LAPS。
    

  

**五**

**绕过UAC提权分析及防范**

  
  
  
  

**一、绕过UAC提权分析**

  

如果电脑的操作系统版本是Windows Vista或更⾼版本，在权限不⾜的情况下，访问系统盘根⽬录（例如C:）、Windows⽬录、程序⽂件⽬录，并读取、写⼊系统登录数据库（ Registry）程序等，都需要经过UAC（User Account Control，⽤户账户控制）的认证才能进⾏。

  

**二、UAC简介**

  

UAC 要求⽤户在进⾏可能影响计算机运⾏的操作或进⾏可能影响其他⽤户的设置之前，具有相应的权限或管理员密码。UAC 在操作开始前对⽤户进⾏身份验证，防⽌恶意软件和间谍软件安装在计算机上计算机或未经许可更改计算机设置。

  

需要 UAC 才能执⾏的操作如下所列：

*   配置 Windows 更新
    
*   增加/删除帐户
    
*   更改帐户类型
    
*   更改 UAC 设置
    
*   安装 ActiveX
    
*   安装卸载程序
    
*   安装设备驱动程序
    
*   将⽂件移动和复制到 Program Files 或 Windows ⽬录下
    
*   查看其他⽤户的⽂件夹
    

  

UAC 有以下四个设置要求：

*   始终通知：这是最严格的设置，每当程序需要使⽤⾼级权限时，都会提示本地⽤户。 
    
*   仅在程序尝试更改我的计算机时通知我：这是⼀个 UAC 默认设置。当本地 Windows 程序想要使⽤⾼级权限 时，不会通知⽤户。但是，当第三⽅程序要使⽤⾼级权限时，会提示本地⽤户。
    
*   仅在程序尝试更改我的电脑时通知我（不要降低桌⾯亮度）：与之前的设置相同，但不要在提示⽤户时降低桌⾯亮度。 
    
*   从不提示：当⽤户是系统管理员时，所有程序都会以最⾼权限运⾏。

**五、绕过针对UAC提权的防御措施**

  

在企业⽹络环境中，防⽌绕过UAC最好的办法是内⽹终端⽤户不拥有本地管理员权限，可以减少系统被攻击的可能性。

  

在家庭⽹络环境下，⽇常办公娱乐活动建议使⽤⾮管理员权限。⽤户以本地管理员权限登录，要将 UAC 设置为“始终通知”或删除⽤户的本地管理员权限。

  

此外，还可以使⽤微软的 EMET 或 Malwarebytes 来更好地防⽌ 0day 漏洞。

  

**六**

**令牌窃取分析与防范**

  
  
  

  

**一、令牌窃取提权简介**

  

令牌(TOKEN)是指系统中的临时秘钥，相当于⽤户和密码，⽤于决定是否允许那个钱请求及判断当前请求是属于那个⽤户的。获得了令牌，就可以在不提供密码或其他凭证的情况下访问⽹络和系统资源，这些令牌将持续存在域于系统中(除⾮系统重新启动)。

  

令牌最⼤的特点是随机性和不可预测性。⼀般的攻击者或软件都⽆法将令牌猜测出来。访问令牌(Access Token)代表访问控制操作主题的系统对象。密保令牌(Security Token)也叫作认证令牌或者硬件令牌，是⼀种⽤于实现计算机身份校验的物理设备。会话令牌(Session Token)是交会话中唯⼀的身份标识符。

  

伪造令牌攻击的核⼼是Kerberos协议。Kerberos协议是⼀种⽹络认证协议，其设计的⽬的是通过密钥系统为客户机/服务器应⽤程序提供强⼤的认证服务。客户端登录服务器后，攻击者就能通过⼊侵服务器来窃取客户端的令牌。

**二、令牌窃取方法**

  

假设已经获得了⽬标机器的 meterpreter Shell⾸先输⼊“ use incognito”命令，然后输⼊'list\_tokens-u”命令，列出可⽤的令牌。

  

![](../Images/9f014e7ee0dd3cd014f3f68de3aa3e83.png)

  

这⾥有两种类型的令牌：⼀种是 Delegation Tokens,也就是授权令牌，它⽀持交互式登录（例如，可以通过远程桌⾯登录及访问）；另⼀种是 Impersonation Tokens,也就是模拟令牌，它⽀持交互式的会话。令牌的数量其实取决于 meterpreter Shell的访问级别。假设已经获得了⼀个系统管理员的授权令牌，如果攻击者可以伪造这个令牌，便可以拥有它的权限。

  

接下来在incognito中调⽤impersonate\_token假冒testuser⽤户进⾏渗透测试，在输⼊主机名\\⽤户名时需要输⼊两个反斜杠。

  

![](../Images/4be9a728ebf6fa0d5eeb3affad2c3785.png)

  

  

**三、令牌窃取提权的防御措施**

  

针对令牌窃取提权的防御措施如下：

*   及时安装微软推送的补丁。
    
*   对于来路不明的或者危险的软件，既不要在系统中使⽤，也不要在虚拟机中使⽤。
    
*   对令牌的时效性进⾏限制，以防⽌散列值被破解后泄露有效的令牌信息。
    
*   对于令牌，应采取加密存储及多⻓验证保护。
    
*   使⽤加密链路SSL/TLS传输令牌，以防⽌被中间⼈窃听。

**二、Mssql提权**

  

**1.Mssql提权分析**

“存储过程”：其实质就是⼀个“集合”，那么是什么样的集合呢？其实就是存储在SqlServer中预先定义好的“SQL语句集合”，说的更直⽩⼀些就是使⽤T-SQL语⾔编写好的各种⼩脚本共同组成的集合体，我们称之为“存储过程”。

  

⽽存储过程中的这些⼩脚本中，其危险性最⾼的“⼩脚本”就是扩展存储过程中的“xp\_cmdshell脚本”，它可以执⾏操作系统的任何指令。如果我们能够获取SA的管理员权限，我们就可以使⽤SA的管理权限可以直接执⾏扩展存储过程中的“xp\_cmdshell脚本”，并获得返回值。

  

**2.xp\_cmdshell**

xp\_cmdshell可以执⾏系统命令，该组件默认是关闭的，因此需要把它打开。xp\_cmdshell默认在mssql2000中是开启的，在mssql2005之后的版本中则默认禁⽌。如果⽤户拥有管理员sa权限则可以⽤sp\_configure重新开启它。

  

**3.MSSQL的权限**

在Windows server类的操作系统上，默认具有system权限。System权限在Windows server2003中权限仅⽐admin⼩，⽽在2003以上的版本，则为系统权限。

  

**4.Mssql防御⽅法**  

及时升级mssql版本。
