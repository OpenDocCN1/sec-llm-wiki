写在前面


之前大家可能听说过，dingding在发送链接时，会尝试加载该链接，因此可通过利用dingding的此功能发起基于get请求的攻击。

除了dingding之外，其他工具如笔记软件（如语雀、notion）插入书签、在线爬虫等也可以发起类似的请求，但其攻击面较窄，仅仅可以实现基于get请求的攻击。

近期研究 Google Apps Script 时发现，其不仅能实现在线发送 post 请求，Doogle 官方也提供了很多接口，使其有很大可玩性。如，利用 Google Apps Script 实现使用 Google 云作为出口，在线执行攻击代码、利用其 doGet、doPost实现简单的http代理等。

01

什么是 Google Apps Script

Google Apps Script 是为谷歌工作表 Sheets、文档、 Docs、幻灯片Slides或表单 Forms创建附加组件、自动化的工作流，与外部api集成。打开Apps Script的脚本管理页面，就可以对其进行脚本编写，编写的脚本会运行于google的服务器中。


网站：https://script.google.com/
官方文档：https://developers.google.com/apps-script/reference/

实现在线攻击

Google Apps Script 类似于JavaScript，可以利用其 UrlFetchApp.fetch 进行异步发送数据包，该方法不仅可以使用get请求，也可以使用post请求。且由于在云端服务器每次发起的请求出口地址都不一样，因此蓝队无法根据IP进行溯源，也无法进行有效的IP封禁。

利用 Google Apps Script 攻击基于 get 请求的 log4j2 漏洞。

输入如下测试代码：

04

总 结

Google Apps Script 本质上就是一门在云端运行的脚本语言，依托谷歌提供的运行环境，可以做很多事情。除了进行漏洞攻击，也可以利用此方法进行简单的http代理。


通过 Google 随机的出口IP，理论上很多功能可以替代现在的云函数，当然，因为Google本身也是 Google Apps Script 有限制，（除免费外）其可用性还是无法跟云函数媲美。
