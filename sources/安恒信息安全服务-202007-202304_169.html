前言

验证码是现代应用系统常见的防暴力猜解、拒绝服务等恶意攻击的安全措施，在攻防领域的不断对抗中，对验证码的自动识别技 术也在同步快速发展，本文将介绍一下常见的验证码识别技术和效果，希望能帮防御方改善、优化基于验证码的实现机制。

burp本地验证码识别-踩坑过程



首先是安装ddddocr模块

pip3 install ddddocr


M1系列芯片安装ddddoc会有好几个坑点，例如ddddocr是基于onnx的,但是git上的onnx项目原生不支持m1系列芯片需要自己编译，编译过程中还有更多模块的坑需要踩，好在官网版测试版已经能完美解决了。


安装完ddddocr之后就是去想办法对接burp，这里我们使用开源的captcha-killer去解决。

网址：https://github.com/c0ny1/captcha-killer/

*左右滑动查看更多



这里如果是2021版之后的burp会踩坑，原项目是基于老版本java的,但是新版burp环境要求是java9及其以上,插件中的部分代码例如从 java 8 开始，就用 java.util.Base64 类来替换工具中的sun.misc.BASE64Encoder ，所以需要我们自己重新改写编译一下。

验证码优化建议



  1. 采用滑动/点选等多种行为验证智能切换，搭载风险感知引擎，拦截恶意行为。

  2. 采用空间推理、逻辑解题能力结合3D立体元素识别。

  3. 采用短信上行方式，发送随机数字至指定平台方验证。

  4. 对传输过程添加数字签名标识。

  5. 增加多因素认证。

  6. 采用SIM一键登录认证。
