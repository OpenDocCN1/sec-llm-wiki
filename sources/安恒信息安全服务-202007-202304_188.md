# 九维团队-青队（处置）| 某网暗链应急分析-基于.NET模块劫持后端跳转

**前言**

在黑客恶意攻击和篡改网页的案例中，为了经济利益的行为越来越多，比如攻击成功后植入博彩暗链类推广页面的行为，隐蔽性较高，排查过程中可能会走弯路，为了方便大家遇到类似案例少走弯路和多个思路，因此写下此文供大家参考。

  

**1**

**现象**

  

在搜索引擎爬虫（如百度、谷歌、搜狗等）访问网站或用户修改浏览器**User-Agent**为搜索引擎的爬虫特征时，网站自动跳转到博彩站点，URL特征均为**/app\***或**/zqb\***，初步判断为**网站被黑客非法植入暗链做黑帽SEO**。

![](../Images/8bbae9abaa890b194af28d4b2598082c.png)

  

  

**2**

**问题**

  

**<1> 日志缺失**

通过查看网站配置，查看IIS日志，发现日志记录不连续，**201x/08/30至201x/09/02、20xx/04/22**存在明显断层，查找文件分析，发现更早之前的日志可能被运维人员或管理员通过**Del\_IIS\_log.bat脚本**于20xx/04/22 23:11:39删除，此问题直接导致了溯源人员无法根据日志记录对攻击者进行精准画像，无从查证漏洞利用点。

  

**<2> IIS解析漏洞**

通过登录服务器和本地日志分析，发现目标站点访问日志存在**大量IIS7.5解析漏洞访问记录**，特征：**\*.gif/.php asp**，**POST请求返回状态码200**，访问成功。

  

**<3> 异常系统账号**

查看系统用户和管理组用户，发现存在**异常SafeDog**用户，上次登录时间为20xx/05/09 07:54:40，且该用户已被加入**administrators组和Remote Desktop Users组。**

  

**<4> 已知木马检测**

通过工具和手工分析，发现存在的可疑文件和后门。

  

**3**

**分析**

  

根据暗链表现出来的特征，可知普通用户访问网站时，抓包查看**URL**请求，未发现前端浏览器跳转到暗链的情况，判断为**直接通过服务器后端跳转到暗链站点并通过服务端返回博彩页面给前端用户**，通过监控网络请求，证实了前面的判断，如下图：

![](../Images/08705ed970391fde5c2edd8d2035f46a.png)

  

排查网站webshell情况，发现存在**大量webshell后门**，图片木马居多。结合日志分析以及上面提到的服务端跳转，发现**可疑日志访问请求**，来源IP和目标IP均为**127.0.0.1**，访问了根目录下的**/api.aspx**，如下图：

![](../Images/f068b696e8438c7856d8897ddcd6de87.png)

  

但在网站根目录**（E:\\程序\\XXX\\XX.Web\\）**并未找到**api.aspx**，通过全局文件搜索，发现文件存放在**C:\\inetpub\\wwwroot\\**下面仍有一个根目录（IIS服务设置为多协议的原因），文件属性被设置为隐藏。

![](../Images/3e73445eba28ec3d29610d234c81b9d6.png)

  

查看文件内容，发现指向第三方站点，如下：

![](../Images/de089cd323dd2f7439c0aa9974c7b32f.png)

  

但是需要跳转到暗链站点

**“http://error.XXX.XX/”**，仅靠api.aspx无法实现，需要**主动执行或间接调用api.aspx**方可实现。

  

经过对IIS站点的配置文件**web.config、IIS服务**设置排查，细心观察下，发现IIS设置中的ISAPI筛选器存在异常设置，如下：

![](../Images/43c70b851b5674567ea56746f2791c73.png)

  

定位到文件路径，发现

**C:\\Windows\\Microsoft.NET\\Framework64\\v3.0\\aspnet\_filter.dll**文件存在异常，原始文件名为ISAPI\_Rewrite3.dll，数字签名证书早在2010年过期，如下图：

![](../Images/b7c84062c58eacdca8e2ed54e6fd3276.png)

  

![](../Images/5a9a64da7a196b8961cfe01b4af8ebbe.png)

简单分析发现，aspnet\_filter.dll主要实现类似**IIS的URL Rewrite重定向功能**，如下图：

![](../Images/1439dfb9fd1105f4e3a1aa104a25b8ba.png)

  

同时它需要加载一个**httpd.conf配置文件**，我们可以在同一目录下找到该文件，如下图：

![](../Images/fcd86e546e09eb95feb969bcca7d4f0e.png)

  

查看httpd.conf配置文件内容，发现实现了根据访问请求中的**HTTP\_REFERER和User\_Agent**判断跳转，跳转目标文件就是上述的api.aspx。

  

至此，整个暗链跳转链已经明朗，IIS的ISAPI筛选器调用了恶意构造的**aspnet\_filter.dll**，同时加载**httpd.conf指向wwwroot的api.aspx**，由该aspx文件指向第三方暗链的一系列跳转请求。

  

根据前面存在的问题，服务器存在异常账号并成功登录操作，直接下载该用户行为记录文件**C:\\Users\\SafeDog\\NTUSER.DAT**，通过特定工具导出记录，如下图：

![](../Images/006e30b9bdeadca8d7a82ec7a63dbfab.png)

  

分析该用户行为，大致操作如下：

![](../Images/b154ee341bdd126fe53539823d026ee2.png)

  

最近打开的文档操作记录与上面分析基本符合。

值得注意的是，攻击者对**HttpModule64.dll和HttpModule32.dll**做了修改操作，如下图：

![](../Images/ea3538d2b20f7e52399525268e77dcb4.png)

  

对此简单分析下，发现存在硬编码指向的不明URL，如下图：

![](../Images/bcd7775704bb3b47ebad18d3c7f8e54b.png)

  

在HttpModule32.dll中实现了**User-Agent判断跳转功能**，如下图：

![](../Images/59ab876c6c3afa07e98e1440fc684a97.png)

  

进一步分析发现这**两个dll文件疑为定制修改过的MSF**后门模块，如下图：

![](../Images/699c01bceb4a50570e129651379164dd.png)

  

![](../Images/79e60e90edbec562a3ae9e73a17f22d9.png)

  

  

**4**

**技术总结**

  

IIS的ISAPI筛选器调用了恶意构造的**aspnet\_filter.dll**，同时加载**httpd.conf指向wwwroot的api.aspx**，由该aspx文件指向第三方暗链的一系列跳转请求。

  

**5**

**分析总结**

  

由于**缺失关键的IIS日志（2019/04/22之前）**，目前已无法定位攻击者所利用的漏洞，下面针对攻击者成功入侵后做的操作进行分析。

  

根据暗链表现出来的特征，可知普通用户访问网站时，抓包查看URL请求，未发现前端浏览器跳转到暗链的情况，判断为**直接通过服务器后端跳转到暗链站点并通过服务端返回博彩页面给前端用户**，通过监控网络请求，证实了前面的判断。

  

排查网站webshell情况，发现存在**大量webshell后门**，图片木马居多。结合日志分析以及上面提到的服务端跳转，发现可疑日志访问请求，来源IP和目标IP均为**127.0.0.1**，访问了根目录下的/api.aspx，但在网站根目录（E:\\程序\\XXX网\\YZ.Web\\）并未找到**api.aspx**。

  

通过全局文件搜索，

发现文件存放在**C:\\inetpub\\wwwroot\\**下面仍有一个根目录，文件属性被设置为隐藏，查看文件内容，发现指向第三方站点，经过对IIS站点的配置文件**web.config、IIS服务设置排查**，细心观察下，发现IIS设置中的ISAPI筛选器存在异常设置，定位到文件路径，发现

**C:\\Windows\\Microsoft.NET\\Framework64\\v3.0\\aspnet\_filter.dll文件存在异常。**

  

原始文件名为ISAPI\_Rewrite3.dll，简单分析发现，aspnet\_filter.dll主要实现类似**IIS的URL Rewrite重定向功能**，同时它需要加载一个httpd.conf配置文件，可以在同一目录下找到该文件，查看httpd.conf配置文件内容，发现实现了根据访问请求中的**HTTP\_REFERER和User\_Agent**判断跳转，跳转目标文件就是上述的api.aspx。

  

**6**

**安全建议**

  

针对以上存在的问题，建议对服务器进行以下方面的**安全加固行为，以保障服务器的数据安全以及正常运营**：

<1> 完善日志审计保护措施，定期备份网站和服务器日志；

<2> 及时更新windows安全补丁，修复IIS解析漏洞；

<3> 清除系统异常账号（SafeDog）；

<4> 对后门文件进行删除处理。
