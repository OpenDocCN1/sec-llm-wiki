5.参考：SUID介绍


SUID (Set owner User ID up on execution) 是给予文件的一个特殊类型的文件权限。在 Linux/Unix中，当一个程序运行的时候， 程序将从登录用户处继承权限。


SUID被定义为给予一个用户临时的（程序/文件）所有者的权限来运行一个程序/文件。简而言之用户在执行程序/文件/命令的时候，将获取文件所有者的权限以及所有者的UID和GID。




如何在Linux/Unix中寻找设置了SUID的文件：

find **/ -perm +4000**






6.缓解与修复措施


这个文件上传漏洞是因为Apache的.htaccess文件的错误配置导致出现了解析漏洞，从而使得我们上传的.php.jpg文件被解析为.php文件执行。


.htaccess 中是按照正则匹配规则来进行文件后缀匹配，不安全的匹配规则：

<FilesMatch ".+\.ph(ar|p|tml)">    SetHandler application/x-httpd-php</FilesMatch>
*左右滑动查看更多

正则为 .+\.ph(ar|p|tml) ，所以当我们传入 .php.jpg 文的时候，满足该正则匹配，所以会将该文件按照php文件来进行执行。


所以要对该解析漏洞进行修复，应该使用正则表达式的 $ 来进行字符串结尾匹配。

修复后的安全匹配策略：

<FilesMatch ".+\.ph(ar|p|tml)$">    SetHandler application/x-httpd-php</FilesMatch>
*左右滑动查看更多

正则为 .+\.ph(ar|p|tml)$ ，这样当我们传入 .php.jpg 文件的时候，不满足正则规则，所以不会传入application/x-httpd-php 这个handler进行执行，必须传入文件后缀为如.php、.phar、.phtml 等才会被执行。这样就完成了修复。
