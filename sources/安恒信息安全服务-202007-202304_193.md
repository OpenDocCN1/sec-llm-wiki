**6.缓解与修复措施**

![](../Images/1c2bb614a62fd9edeed814f143888307.png)

  

这个文件上传漏洞是因为Apache的**.htaccess文件**的错误配置导致出现了解析漏洞，从而使得我们上传的**.php.jpg****文件**被解析为**.php文件**执行。

  

**.htaccess **中是按照正则匹配规则来进行文件后缀匹配，不安全的匹配规则：

```


*   
*   
*   

```
<FilesMatch ".+\.ph(ar|p|tml)">    SetHandler application/x-httpd-php</FilesMatch>
```

\*左右滑动查看更多

```

正则为 **.+\\.ph(ar|p|tml) **，所以当我们传入 **.php.jpg **文的时候，满足该正则匹配，所以会将该文件按照php文件来进行执行。

  

所以要对该解析漏洞进行修复，应该使用正则表达式的 **$ **来进行字符串结尾匹配。

修复后的安全匹配策略：

```


*   
*   
*   

```
<FilesMatch ".+\.ph(ar|p|tml)$">    SetHandler application/x-httpd-php</FilesMatch>
```

\*左右滑动查看更多

```

正则为 **.+\\.ph(ar|p|tml)$ **，这样当我们传入 **.php.jpg **文件的时候，不满足正则规则，所以不会传入**application/x-httpd-php **这个**handler**进行执行，必须传入文件后缀为如**.php、.phar、.phtml** 等才会被执行。这样就完成了修复。
