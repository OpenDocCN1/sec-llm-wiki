**Hackthebox简介**

Hackthebox是国外的在线靶场平台，通过平台特定的vpn进行连接，之后就可以进行靶场练习。在靶场中有两个flag，分别为用户权限的user.txt和管理员权限的root.txt。

  

**本文简介**

本文主要介绍了YAML反序列化漏洞的利用方式，cve-2021-4034提权漏洞的利用方式。提供了拿下一个服务器之后的信息搜集思路。

  

**1**

靶场环境

  

**攻击机：**kali liunx操作系统，IP为10.10.16.59。

**靶机：**linux操作系统，IP为10.129.96.171。

这个时候可以从端口扫描中信息中进行分析，在信息中发现靶机开了两个端口，一个是22端口的SSH，一个是8080端口的Web服务。同时扫描显示是Tomcat，这时可以知道这是个Java站点。

![](../Images/67f34828b67292ddaa982f990368ca2c.png)

  

当访问过来转到这个页面，在网站中找到了一个 YAML 解析器。YAML是一种人类可读的数据序列化语言。它通常用于配置文件和存储或传输数据的应用程序。  

  

这个时候去判断是否可以使用反序列化漏洞来利用它。在谷歌进行漏洞的搜索，经过寻找发现在 Java 应用程序中使用的SnakeYAML容易被反序列化。
