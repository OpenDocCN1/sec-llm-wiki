# 《个人信息保护法》即将施行：从此个人信息有了法律“安全锁”！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMDgyNTQzMQ==&mid=2247487923&idx=1&sn=e14a1e08f3e81e765427a0a548eb9019&chksm=9ae2508bad95d99d781fee127207ed4e9beae0100f9a2261ddbdba2630deb2f241ac42f5ac8b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMDgyNTQzMQ==&mid=2247487923&idx=1&sn=e14a1e08f3e81e765427a0a548eb9019&chksm=9ae2508bad95d99d781fee127207ed4e9beae0100f9a2261ddbdba2630deb2f241ac42f5ac8b&scene=27#wechat_redirect)

![](../Images/4f3949b19067474ffba564a0e194c0a6.png)

  

2021年8月20日，**《中华人民共和国个人信息保护法》**（下文简称《个保法》）正式发布，并**将于2021年11月1日起施行**。

  

**《个保法》的颁布，是数字安全领域中又一块重要的里程碑**：

如果说《网络安全法》（2017年6月1日施行）规定了网络安全的治理道路、《密码法》（2020年1月1日施行）提出了数据保护的技术手段、《数据安全法》（2021年9月1日施行）提升了国家数据安全的保障能力，那么《个人信息保护法》就相当于为个人信息法制化进程进行了加速。

  

很多人可能会问：《个保法》的出台究竟带来了怎么的变化？对我们个人来说又带来了哪些切实的保障呢？

  

**1.明确了个人信息的定义**

**![](../Images/e0b4a8b58752ad520209a5306cdf09d8.png)**

![](../Images/950058c9d95808a05379257a781b2f68.png)

《个保法》第四条：个人信息是以电子或者其他方式记录的与已识别或者可识别的自然人有关的各种信息，不包括匿名化处理后的信息。个人信息的处理包括个人信息的收集、存储、使用、加工、传输、提供、公开、删除等。

  

从个人的**身份信息**（如身份证、社保卡、驾驶证等），到**生物识别信息**（如指纹、声纹、虹膜等）、**健康生理信息**（如过敏信息、既往病史、体检报告等），再到**财产信息**（如存款信息、房产信息、征信信息、消费交易记录等）、**网络身份识别信息**（如某系统账号、邮箱地址及相关的密码、密保问题及答案等）……

  

毫不夸张地说，个人信息“包围”了我们生活的方方面面，它的涉猎范围，远比你能想到的多。

  

![](../Images/b53962fab66ab897ed038594e7f0effe.png)  

**2.规定了个人对个人信息处理活动的权利**

**![](../Images/e0b4a8b58752ad520209a5306cdf09d8.png)**

![](../Images/950058c9d95808a05379257a781b2f68.png)

《个保法》第四十四条：个人对其个人信息的处理享有知情权、决定权，有权限制或者拒绝他人对其个人信息进行处理；法律、行政法规另有规定的除外。

  

前边提到了个人信息的定义和个人信息的处理概念，在我们的日常生活中，总有一部分个人信息是具有敏感性、轻易不愿意让其他人或组织机构知道的。

  

出于隐私保护的考虑，对于需要对个人信息进行处理的行为，一定要满足**“知情同意”、“最小必要”**的**原则**，对超出合理范围的**违规操作**，《个保法》让我们能够有权利**及时说不**。

![](../Images/b53962fab66ab897ed038594e7f0effe.png)  

**3.明确了何为侵犯个人信息的违法行为**

**![](../Images/e0b4a8b58752ad520209a5306cdf09d8.png)**

![](../Images/950058c9d95808a05379257a781b2f68.png)

《个保法》第十条：任何组织、个人不得非法收集、使用、加工、传输他人个人信息，不得非法买卖、提供或者公开他人个人信息；不得从事危害国家安全、公共利益的个人信息处理活动。

  

**个人信息的保护**可以说是**关乎国计民生**，已明确被纳入《民法典》人格权保护范围。

  

随着互联网时代的到来，**个人信息被赋予了巨大的商业价值**。从消费层面来说，越来越多的商家为了能达到增加客源、推广自身品牌、拓展市场的目的，将目标瞄准了消费者的个人信息。

  

许多不法商家为了牟取暴利而铤而走险，肆无忌惮地对个人信息进行收集、买卖和使用，这也直接**催生促成**了**个人信息贩卖的灰色产业链**，导致了各类**个人信息泄露事件的频发**。

![](../Images/b53962fab66ab897ed038594e7f0effe.png)  

**4.禁止“大数据杀熟”、不得强制推送个性化广告**

**![](../Images/e0b4a8b58752ad520209a5306cdf09d8.png)**

![](../Images/950058c9d95808a05379257a781b2f68.png)

《个保法》第二十四条：个人信息处理者利用个人信息进行自动化决策，应当保证决策的透明度和结果公平、公正，不得对个人在交易价格等交易条件上实行不合理的差别待遇。  
通过自动化决策方式向个人进行信息推送、商业营销，应当同时提供不针对其个人特征的选项，或者向个人提供便捷的拒绝方式。  
通过自动化决策方式作出对个人权益有重大影响的决定，个人有权要求个人信息处理者予以说明，并有权拒绝个人信息处理者仅通过自动化决策的方式作出决定。

  

大数据的兴起带动了技术发展，却也免不了被利欲熏心的某些人利用，很多人对大数据本身可能没什么概念，却早在不经意间就被“**大数据杀熟**”骗的团团转。

  

在日常生活中，我们在下载使用很多APP时，被要求**同意**软件所谓的“**服务协议**”及相关“**隐私政策**”，这其中有部分条款是不必要甚至是损害用户利益的“隐藏条款”，是为了过度收集个人信息而立的幌子。

  

一旦点击了同意，就会在后台神不知鬼不觉地窃取隐私信息，用于大数据杀熟、个性化广告推送，或是其他更多不法行为。

  

而且更多时候的情况是，明知道软件存在不正当的信息窃取行为而又不得不使用软件中的某项功能时，**点击不同意**也无济于事——这会致使**无法继续使用该软件**。

  

这种举动明显**违背了对个人信息处理的合法性、正当性和必要性原则**，所幸《个保法》对这一行为也进行了明令禁止。

  

在这里为大家简单介绍一个非常典型的**大数据杀熟**的**司法案例**：

![](../Images/a9574ef7e3bf9a33aff7d1771f8e682c.png)

  

2020年7月，胡女士通过携程APP订购了舟山希尔顿酒店的一间豪华湖景大床房，实际支付价格为2889元。然而，胡女士在离开酒店时偶然发现，酒店的实际挂牌价仅为1377.63元，自己作为平台的钻石贵宾客户，不仅没有享受到星级客户应当享受的优惠待遇，反而多支付了一倍多的房价。  
胡女士与携程沟通，携程以其作为平台方为由仅退还了部分差价。胡女士以上海携程商务有限公司采集其个人非必要信息，进行“大数据杀熟”等为由诉至法院。  
法院经审理后，认定被告确实存在虚假宣传、价格欺诈和欺骗行为，支持胡女士提出的退一赔三、携程APP为其增加不同意“服务协议”和“隐私政策”时仍可继续使用的选项, 以避免携程采集其个人信息，掌握胡女士数据。  
![](../Images/a9574ef7e3bf9a33aff7d1771f8e682c.png)  
![](../Images/b53962fab66ab897ed038594e7f0effe.png)  

**5.对违反《个保法》的单位和个人进行严惩**

**![](../Images/e0b4a8b58752ad520209a5306cdf09d8.png)**

![](../Images/950058c9d95808a05379257a781b2f68.png)

《个保法》第六十六条：违反本法规定处理个人信息，或者处理个人信息未履行本法规定的个人信息保护义务的，由履行个人信息保护职责的部门责令改正，给予警告，没收违法所得，对违法处理个人信息的应用程序，责令暂停或者终止提供服务；拒不改正的，并处一百万元以下罚款；对直接负责的主管人员和其他直接责任人员处一万元以上十万元以下罚款。  
有前款规定的违法行为，情节严重的，由省级以上履行个人信息保护职责的部门责令改正，没收违法所得，并处五千万元以下或者上一年度营业额百分之五以下罚款，并可以责令暂停相关业务或者停业整顿、通报有关主管部门吊销相关业务许可或者吊销营业执照；对直接负责的主管人员和其他直接责任人员处十万元以上一百万元以下罚款，并可以决定禁止其在一定期限内担任相关企业的董事、监事、高级管理人员和个人信息保护负责人。  

  

从此法条的**处罚金额**来看，《个保法》对违反个人信息保护的单位和个人规定了**较高**的处罚水平。除此之外，还会依照有关法律法规**记入信用档案并公示、承担损害赔偿、构成犯罪的，依法追究刑事责任等处罚**（具体可参见《个保法》第七章：法律责任）。**行政处罚和经济处罚双管齐下，大幅提升了违法成本。**

![](../Images/b53962fab66ab897ed038594e7f0effe.png)

  

**个人信息一旦泄漏**，就具有“**不可控、难以追溯**”的特性，只要有任意一个拥有者继续传播，就**无法彻底追回**。

  

**被泄露信息者轻则频繁被“精准”骚扰，重则可能遭遇电信诈骗、套路贷、敲诈勒索等恶性事件。**如果你也经有过被五花八门的推销电话短信狂轰乱炸的经历，一定能对此深有体会。

  

那么，该**如何对个人信息泄露进行防范呢**？

  

正所谓知己知彼百战不殆，在平时的工作生活当中，**一定要建立个人信息保护的意识，提高警惕，同时建议对网络安全的常见骗局要有所了解。**

**总结**

  
《个保法》中，明确规定了不得过度收集个人信息、进行大数据杀熟，对敏感个人信息的处理作出了规制，同时完善了个人信息保护的投诉、举报工作机制。  
**《个保法》的施行，将会对我国的数字经济、数字社会、数字政府发展具有重要意义。**![](../Images/2958940546bd2bddae2eae98edfb0a96.png)
