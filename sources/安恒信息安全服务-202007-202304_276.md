# 安恒信息董事长范渊接受央视采访：数据既要保护又要利用，应构建全方位数据安全能力体系

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMDgyNTQzMQ==&mid=2247486659&idx=1&sn=c5fee0a5cbc13c84f35427f7a39229ee&chksm=9ae24dfbad95c4ed30faf5f9ae7aa7866b618899e363634ec686ced9f1a06132c39c57fae193&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMDgyNTQzMQ==&mid=2247486659&idx=1&sn=c5fee0a5cbc13c84f35427f7a39229ee&chksm=9ae24dfbad95c4ed30faf5f9ae7aa7866b618899e363634ec686ced9f1a06132c39c57fae193&scene=27#wechat_redirect)

《数据安全法》今天正式施行。安恒信息董事长范渊接受央视新闻采访时指出：《数据安全法》强调数据既要保护又要利用，包含对数字经济的创新提法也有所体现，新规将更好地指导数据在合法合规前提下开放应用、释放价值。  
《数据安全法》的落地，意味数据安全进入强监管时代，数字化成为主导国际竞争的关键力量，作为专业的数据安全产品、服务与解决方案提供商，在安恒信息看来，《数据安全法》提出要对数据全生命周期保护，这对政企单位的数据安全建设提出了更高要求，企业需要完成从顶层设计到数据安全咨询服务，再到数据安全技术产品落地和数据安全管理运营的完整规划，构建全方位数据安全能力体系。  

对数据安全的重视根植于安恒信息的基因。随着新规的到来，数据安全产业市场会变得更强、更大，并将会和数字化改革紧紧耦合在一起，成为赋能数字化中国和网络强国的中坚力量。
