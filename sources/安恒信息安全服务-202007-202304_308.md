# 西湖论剑·ZJCERT威胁情报及应急响应分论坛议程出炉

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMDgyNTQzMQ==&mid=2247486286&idx=1&sn=3671f30da0be6d50f122b008e4fbfcb7&chksm=9ae24a76ad95c360329278389c5b24dd19e859ef04db2edaa9e0a77275eaf2191e508a0ce679&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMDgyNTQzMQ==&mid=2247486286&idx=1&sn=3671f30da0be6d50f122b008e4fbfcb7&chksm=9ae24a76ad95c360329278389c5b24dd19e859ef04db2edaa9e0a77275eaf2191e508a0ce679&scene=27#wechat_redirect)

  

![](../Images/bf27c76c8f56e4f2fe5bce05d1ae2010.png)由ZJCERT主办的“西湖论剑·威胁情报及应急响应分论坛”将于4月24日下午14时30分举行。  
论坛旨在从体系建设、趋势分析、思路方法、实践经验等多个角度入手，共同探讨全网威胁情报及应急响应工作的特点和思路，促进国家公共互联网网络安全应急体系成员间合作，实现威胁数据共享，加强互联网行业网络安全保障和突发安全事件应急处置联动。![](../Images/bc50b4e9c296b694c026e59a759d6df1.png)
