# 再获殊荣丨安恒信息荣获安全服务创新能力奖！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMDgyNTQzMQ==&mid=2247485805&idx=1&sn=b2706ec1451a3f9e9563533f4f5f8b40&chksm=9ae24855ad95c143dd5e2dcdb5df678cd696bf272ec74afa9f3ef91f44fce391aef45e36f4db&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMDgyNTQzMQ==&mid=2247485805&idx=1&sn=b2706ec1451a3f9e9563533f4f5f8b40&chksm=9ae24855ad95c143dd5e2dcdb5df678cd696bf272ec74afa9f3ef91f44fce391aef45e36f4db&scene=27#wechat_redirect)

  

日前，由ISC、数世咨询联合发起的2020“网络安全创新能力100强评选”（以下简称“创新百强”）颁奖典礼在京举行。

本次创新百强评选活动历时近1个月，100家网络安全创新企业经过普通投票人、资深投票人、专家评审团三级投票机制，根据科技实力、投资价值、成长价值、领先价值等四个维度打分。

  

![](../Images/dad88b5c368b53a3d8af0947d12bec39.png)

  

[安全服务创新领域能力奖]

  

  

通过层层选拔，杭州安恒信息技术股份有限公司成功入围安全服务创新、数据安全创新、安全管理创新、云安全创新和访问控制创新五大创新能力榜单**。****在网络安全服务创新领域，安恒信息凭借业界首个网络安全人才彩虹体系、强大的自研平台、优异的攻防能力以及卓越的服务质量等，获得评委青睐。**

  

![](../Images/a349739f07c8ce8da1ca779cb5731ae1.png)

  

[创新百强颁奖现场]

  

  

安恒信息高级副总裁兼首席安全运营官袁明坤表示：

  

“**随着网络对抗形态的持续演进，在数字经济和云、大、物、移、智新兴技术驱动下，安全服务由最初单一维度的服务模式已然转变为云、 地、人、机共智式服务。通过服务创新使各类安全能力相融交汇形成合力，才能最快速适应瞬息万变的网际空间战场，未来已来，创新不止，网络安全服务领域势必不断演进，一切产品皆资源，一切资源皆服务。”**

  

  

**关于安恒信息安全服务团队**

  

  

安恒信息安全服务拥有国内一流的安全专家团队、专业的自研安全服务工具、完备的高级网络安全服务资质、标准化的安全服务流程，全生命周期覆盖网络安全建设的顶层安全服务设计到具体的方案落地。

![](../Images/1131932564396120e23ba83f2149cc2d.png)

专业的安全服务团队

以网络安全彩虹架构为模型，九大方向专业安服人才遍布全国各地，均具备顶尖网络安全技术能力和丰富安全攻防实战经验。  

![](../Images/1131932564396120e23ba83f2149cc2d.png)

自主研发的安全工具

致力于研发网络安全技术专用的检测、加固、防御工具，并拥有多项国内外专利技术，以自研工具结合专业服务保障客户网络安全运营。

![](../Images/1131932564396120e23ba83f2149cc2d.png)

标准化的服务流程

构建业界标准体系化的安全服务流程，落地不同场景下网络安全制度流程，多维度、立体化为客户做好全生命周期的安全保障。

![](../Images/1131932564396120e23ba83f2149cc2d.png)

完备的高级网络安全服务资质

具备包括中国信息安全测评中心认证的安全工程类三级资质(第一家获得001证书的企业)、国家互联网应急中心颁发的国家级网络安全应急服务支撑单位证书、中国网络安全审查技术与认证中心认证的风险评估一级资质、应急响应一级资质、安全集成一级资质等多项国家最高级安全服务资质。
