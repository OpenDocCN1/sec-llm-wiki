# 安恒技术：护航亚运！小会议室大作战！

**“啊——又掉头发了，又拉近了我与‘地中海’的距离！”**

  

安恒大厦一间小会议室里，网络安保部的Ming，他看着手上几根头发丝叹息道。

  

 “没事，自然脱落寿终正寝，至少不是非自然死亡。” “哈哈哈！我也和你一样掉头发了！”说话的是技术中心的成员Darcy和Zeki。

  

11月23日，安恒信息正式宣布成为杭州亚运会官方网络安全服务合作伙伴！

  

此前，他们被上级赋予了一项重要而艰巨的任务——**负责杭州亚运会网络安保项目的投标工作。**

  

而所有的故事都从一间会议室开始，本期“员工说·一线情报局”就和大家聊聊临时组建的“亚运作战先锋队”。

  

  

亚运作战第一步

**学海无涯苦作舟**

**沉浸文档无止休**  

为了更有把握地拿下亚运项目，公司从多个部门挑选了拥有丰富安保经验的老兵，组成**“亚运作战先锋队”**，其中Darcy和Zeki作为技术侧的重要支撑力量，负责招标文件中技术方案的编写工作。

  

“为了做到**‘让智能更安全，让安全更智能’**，本期的项目落地实施不仅仅需要动用我们现有的能力建设，还得预估到两年后的形式，因此对于我们的挑战很大。” Darcy回忆道。

  

“作战先锋队”不断翻看招标书上的要求，对重点进行标注，同时借用公司内最前沿的团队力量知识，以及翻阅国内外相关的文献资料，有针对性地去研究杭州“智能亚运”的安全风险及合适的的网络安全体系框架，确保两年后的亚运会**“零失误”**！

  

虽然在此之前，安恒信息已经先后参与了北京奥运会、广州亚运会、深圳大运会、武汉军运会等众多国际综合性体育赛事的网络信息安全保障工作，积累了丰富的大型体育赛事网络安全保障的经验。

  

但对于亚运，这个国际大型综合型赛事历史上网络信息安全类最高级别的合作，尘埃落定前，任何环节都不敢放松警惕！

  

这个时期的会议室，文件已经堆积成山，大家虽然来自不同团队，平时交往不会特别频繁，但亚运项目期间的朝夕相处，让这个会议室充满了“加油鼓劲”。

  

  

亚运作战第二步

**衣带渐宽终不悔**

**多方合作拼智慧**  

  
  

在深刻理解亚运会网络架构及业务系统设计后，“作战先锋队”开始进入撰写环节。

  

为了保质保量地完成材料输出，做好技术方案的质量把关，**“作战小组”每位成员遵循总体分工，职责到人**。

  

他们都需要对每一块设计内容都要深入思考和反复斟酌，结合杭州亚运会“没有重来一次机会”的保障特点，孕育出专业、可靠、全方位的技术材料！

  

例如Darcy，亚运会场馆所的安全规划设计，就是他专项负责的内容之一。

  

他需要针对**不同级别的竞赛场馆和非竞赛场馆进行一馆一册的设计，同时考虑场馆的不同场景，如开幕式场景等，进行风险评估和安全建模。**

  

为了保证产品组提供的方案，能更好符合项目需要，“作战小组”成员们投入了大量时间去研究产品的专业知识，甚至去解析市面成熟云平台的底层安全架构，不断重塑和挖掘，逐步构建杭州亚运会网络安全保障的技术支柱。

  

每一位成员仿佛达成了默认的共识——站在更高的角度去要求自己。

  

为了实现多云安全融合、安全态势全感知、一体化物联网安全防护、城市安全智慧运营，让全天候全栈式服务渗透到网络安保的每一个细节，尽可能做更优的保障体系设计，优化再优化，构思再构思！

  

Darcy告诉我，这段时期，每位成员都扛着巨大的压力，但既然这杆旗到了他们这里，就要挥舞出最优的姿态。

  

那时候你进入会议室，你会听到这些话：  

  

**“这个东西有难度，但问题不大！”**

**“你们的水平绝对可以！”**

**“我们都是最优秀的！”**

  

随后就是一阵大笑。

  

本次保障体系设计覆盖杭州亚运会所有的信息与网络系统、竞赛场馆与非竞赛场馆等安全范围，涉及从赛前规划实施阶段、赛时运行保障阶段、赛后验收审计阶段的全流程保障。

  

因此，在完成全部稿件撰写后，他们又进入交叉复查，反复修改的阶段。

  

![](../Images/b15e12f1d3015906a6cfed2a0ad497e6.png)

  

期间，针对杭州亚运会复杂的安全防护视角，以及不可预估的安全风险展开深入讨论，借助重保的丰富经验和缜密的研讨，最终构建出针对“智能亚运”定制化场景、多维度网络安全服务的雏形。 服务中心提出了**“九维五星”**的概念，去面对安全防护场景中的不同变化，为亚运提供定制化的五星“云、大、物、智、服”场景化的网络安全服务。 这一概念得到了集体的点赞！

  

  

亚运作战第三步

**笔扫千军齐合力**

**万众一心定乾坤**

  

Darcy告诉我项目结束最后一天，一大群人围在Zeki的电脑前，注视着Zeki做最后的文档整合。

  

几千页的标书，包含了各类图片，导致系统时常卡顿，大家都担心新版本会被替换掉，一切又要重头再来，所以Zeki每一步操作牵动着在场所有人的心。

  

电脑一卡住，大家的心就被提到了嗓子眼，不由自主地喊道：**“你别动！千万别动！”**

  

等到这一波恢复稳定，刚松了一口气，稍一动又卡住了，整个会议室的心再次被提了起来，那个晚上他们的心就像过山车一样，起起伏伏。

 

而他们所有的期盼都汇聚到了那个块电子屏上。

  

深夜，一阵欢呼声从会议室里传出！文档工作顺利结束！

  

![](../Images/68091b78b8e549ea66b5bfe967a8d029.png)![](../Images/4e837ba6a2613d65c2b3dc4ff98deff0.png)

  

在项目投标当天，凌晨四点，所有人推着标书来到安恒楼下，又看着标书被送去现场，大家的心仿佛松了一口气，又像提起了千斤石。  
最后，宣布中标！安恒信息成为了杭州亚运会的网络安全护航者！  
所有“作战先锋队”的成员们互相致敬——“与有荣焉”。 签约会当天，我们提出“让智能更安全，让安全更智能”护航亚运，让智能亚运安全且精彩！这是每个安恒人的荣耀，也是安恒人被认可的又一里程碑！

  

  

![](../Images/fd224baeefcaac6db907a5a1ddfac2a1.png)

  

而技术人在翻山越岭完成一次次投标，一次次护航，一次次保障中，再次出发！

  

什么是技术？

  

Darcy告诉我，技术需要细致的诠释不同的角色，例如方案解读的讲师、技术架构的设计师、竞争分析的谈判专家、主题宣讲的传播者、投标战场的冲锋兵等等。

  

在技术输出时，如何诠释好对应的角色，每个技术都会有自己的答案。而每个技术都将诠释为更好的自己。

  

**“当你真心想做什么事时，整个宇宙都会来帮你。”**
