# 安恒信息入选浙江省产教融合“五个一批”建设名单

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMDgyNTQzMQ==&mid=2247496108&idx=1&sn=a9cfd88077850866b190d40dd0ccefec&chksm=9ae1b094ad963982b3b05c6aac362a3bc8d88b6ef39d99e7de8509903a9805b331a659f729de&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMDgyNTQzMQ==&mid=2247496108&idx=1&sn=a9cfd88077850866b190d40dd0ccefec&chksm=9ae1b094ad963982b3b05c6aac362a3bc8d88b6ef39d99e7de8509903a9805b331a659f729de&scene=27#wechat_redirect)

近日，浙江省发展改革委等10部门发布通知，公布了浙江省2019—2020年度产教融合“五个一批”名单，其中，安恒信息入选“2019—2020年度省产教融合型试点企业名单”。

  

![](../Images/29cb8b92bb742baa699a4017db511831.png)

  

浙江省产教融合“五个一批”是落实《国务院办公厅关于深化产教融合的若干意见》和《浙江省人民政府办公厅关于深化产教融合的实施意见》推出的产教融合项目，旨在通过建设一批产教融合联盟、一批产教融合示范基地、一批产教融合试点企业、一批产教融合工程项目和一批产学合作协同育人项目，推进教育链、人才链与产业链、创新链的有机衔接，全面提升教育水平和人才资源质量。  
安恒信息一直高度重视产教融合工作的推进落实，在学科建设、教学内容和课程体系改革、师资培训、实践条件和实践基地建设等多个领域，与合作院校共建新工科专业，打造产学研融合的教学模式，探索应用人才培养方式，致力于帮助更多院校提升网络空间安全人才培养能力，全方位推进信息安全教育领域产教融合，为推动网络空间安全教育事业助力。  
产教融合是国家推动经济发展和产业升级的战略需求，是浙江省落实高等教育强省战略的重要举措，安恒信息将充分利用此轮省级产教融合“五个一批”建设契机和已有建设成果，从人才培养的新形势新任务出发，聚焦产业发展前沿，在新工科建设、教学内容和课程体系改革、师资培训、实践条件和实践基地建设等方面，助力高等教育改革与发展，进一步让教育链、人才链与产业链、创新链有机衔接，持续深化产教融合。
