# “十一”黄金周攻防数据反映，国内网络安全自检意识明显提高

国庆长假结束，安恒风暴中心发布《安全半月谈（十一特刊）》，其中包含“十一”黄金周期间的网络攻防数据。我们在本次推送中将这些攻防数据与大家分享，帮助各位更好地了解近期网络安全威胁态势。

  

 

**网站群受攻击趋势分析**

2020-10-01至2020-10-08, 今年的“十一”长假期间，玄武盾参与防护网站群共计受到攻击18,752.15万次。  

  

在玄武盾专业、稳定的云安全防护服务与安全服务工程师积极有力的应急响应支撑下，网站所有攻击均被有效阻断，未造成攻击成功或篡改成功的安全事件，有效地保障网站安全、平稳地运行。

  

![](../Images/d619deb09bd4fb780d9f45e43a127d28.png)

以下是网站群受攻击趋势图：

**攻击时间段趋势分析**

根据风暴中心拦截攻击趋势分析，十一期间的攻击数据保持较高的态势，日均攻击态势约在2,344万次，网络空间安全攻防抵抗激烈。经深入分析发现，绝大部分攻击数据为自检行为，相比过去而言国内安全意识明显提高。

  

攻击时间段趋势如下：

  

![](../Images/8387802dc4a730ac8022e22c37d438cc.png)

  

根据时间段攻击趋势分析，在凌晨1:00-8:00攻击态势比较低，攻击态势保持低谷阶段，平均攻击量约在617.3万，其他时间段的攻击力攻击态势均比较高，峰均值约在863.3万。

  
 

**攻击区域分布情况分析**

  

通过数据可视化分析，国内安全态势约占整体安全态势的97.39%，其中北京、浙江和江苏三地的攻击态势之和，约占整体安全态势的79.86%。

  

国外的攻击态势约占整体安全态势的2.61%，其中美国占比最大，约占整体安全态势的0.84%。

  

![](../Images/e6383f7b6bd285e6ee8a0bf161a6149b.png)

  

 

**攻击类型情况分析**

  

根据数据分析得出，主要攻击类型为目录信息泄露和命令注入攻击，占总攻击数据量的57.44%。
