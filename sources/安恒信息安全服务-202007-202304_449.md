# 蜀山论剑，听听安恒对教育行业的网络安全观

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMDgyNTQzMQ==&mid=2247496102&idx=1&sn=c864f29d1553592ce753e36e56a32be8&chksm=9ae1b09ead963988e6fc39859cd29be589c38f05886eb3bec76eff44b2d9b98d50ec291b12eb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMDgyNTQzMQ==&mid=2247496102&idx=1&sn=c864f29d1553592ce753e36e56a32be8&chksm=9ae1b09ead963988e6fc39859cd29be589c38f05886eb3bec76eff44b2d9b98d50ec291b12eb&scene=27#wechat_redirect)

![](../Images/5e24ae831d416b1fb9f0cc6a87f8262c.png)

9月18日，由四川省互联网信息办公室指导，成都市互联网信息办公室主办，成都市互联网界联合会及杭州安恒信息技术股份有限公司承办的“2020蜀山论剑·网络安全大会”于成都市举办。

  

大会以“新形势 新场景 新安全”为主题，汇集网络安全领域知名专家、政府部门、行业单位和优秀企业，共同探讨网络安全管理，共绘产业发展蓝图。

  

在大会教育分论坛，杭州安恒信息技术股份有限公司高级副总裁杨勃发表了《教育行业网络治理能力建设探讨》主题演讲。

![](../Images/6c39744ed46e658e5a6eee2bde8bb06f.png)

  

![](../Images/c1847c0bb56bbf6ed3fe293fc1f0ca4d.png)

**教育行业网络安全威胁与形势**

  

一直以来，教育行业的网络安全存在的问题，是教育行业的系统多，漏洞多，威胁攻击多，而相关的安全工作人员人手不足。如今，教育行业网络安全技术不断提高，但教育行业仍然面临数据泄露、数据篡改、网页篡改、网站瘫痪等威胁。

  

这些威胁具体到教育行业的实践场景中，体现为部分教育App用户信息泄露、分数查询系统被黑客恶意攻击、教育网站被恶意篡改、在线教育服务中断等现象。  

  

在信息化发展的过程中，教育行业需要在业务发展与网络安全之间找到平衡。

  

![](../Images/c1847c0bb56bbf6ed3fe293fc1f0ca4d.png)

**相关政策与社会环境的推进**

  

《网络安全法》出台之后，2017年宜宾市翠屏区“教师发展平台”网站因网络安全防护工作落实不到位，网站被黑客攻击入侵。翠屏区教师培训与教育研究中心相关人员被处罚，这是教育系统违反《网络安全法》的第一案。

  

近年来，不少教育单位因为未进行网络安全等级保护的定级备案、等级测评；未落实网络安全等级保护制度，履行网络安全保护义务等工作，使己方安全处于威胁之中。

  

新冠疫情期间，在线教育兴起，除了网站崩溃，用户在使用教育APP时，还面临个人隐私被泄露、被滥用的风险。

![](../Images/a85d3039f6727e3913c2555404b14d05.png)

疫情下的在线教育网络安全特征及挑战

  

以上问题，都敦促着教育行业加强对网络安全的重视。

  

![](../Images/c1847c0bb56bbf6ed3fe293fc1f0ca4d.png)

**网络安全治理能力建设实践**

  

保障网络空间安全的首要任务就是增强数据保护意识，完善自身安全体系，做好网络安全建设工作。安恒打造全生命周期网络安全建设，建设内容包括：网络边界测绘及资产管理、常态化安全监测能力、威胁情报分析与应用能力、安全防御能攻击感知能力、应急响应及安全运营团队、专业网络安全人才培养。

![](../Images/145cb74e8d142389ac2671e7ee927a24.png)

**威胁情报应用**

安恒安全数据大脑能够对网络空间进行精准测绘，支持用户发现风险目标。

![](../Images/e22214cb5c0216c9905cb143512c54ff.png)

安恒威胁情报分析

  

获得威胁情报之后，对威胁信息进行及时通报、并根据现实需要，整理数据，形成专业报告，有助于提升行业整体风险规避效果、精准化决策。

![](../Images/6eb3c29b06247ffd31c9b9483cfbb019.png)

今年，安恒信息发布《教育行业网络安全白皮书》，分享了2020年1月-6月的教育行业网络安全态势。

  

![](../Images/6105ffbfaf15005ad8b4b807cc63b91e.png)

除了《教育行业网络安全白皮书》、安恒还制作了《安全半月谈》、《文件解析漏洞风险影响资产专题报告》、及多份行业/省市级资产态势分析报告。

  

**网络安全人才培养**

十年寒窗，为中华之崛起而读书，培养网络安全人才是国家发展之所需。安恒信息实战平台为学生提供综合实训和实战演练，满足学生对安全研究、红蓝对抗、护网演练等实践的需求，培养实战型人才。

![](../Images/993402b3fa483d9f12eb0033963566e6.png)

新型实战型人才培养体系

  

通过“西湖论剑”网络安全大会、世界技能大赛网络安全项目等活动，让人才在实践中成长。
