# 昨天这场会，滨江企业错过了只能……

昨天，风小妹跟着好朋友“小石头”去了浙农科创园，帮助小石头在那里举办了**“扶上马、送一程”——上马石企业e服务平台宣讲会”**。现场来了好多人，小石头给园区的朋友们发了好多福利，风小妹也帮了很多忙哟~

  

**这场宣讲会**

**由杭州高新技术产业开发区（滨江）市场监督管理局牵头主办**

**浙农科创园承办**

**杭州安恒信息技术股份有限公司协办**

至于昨天我们到底在现场做了什么

读者朋友们可以跟着风小妹回顾一下~

  

***活动简讯***

 ![](../Images/a1f3cab5928b44515734b0c06c5f936e.png)

杭州高新区(滨江)市场监管局局长钱毓军

在活动现场讲话

  

9月14日14时，由杭州高新技术产业开发区（滨江）市场监督管理局牵头主办、浙农科创园承办、杭州安恒信息技术股份有限公司协办的“扶上马、送一程”——上马石企业e服务平台宣讲会”在浙农科创园3号楼二层2201室成功举办。  

  

杭州高新区(滨江)市场监管局局长钱毓军、杭州高新区（滨江）市场监管局企业监管科科长高轶舟、浙农科创园董事施胜锡、泰隆银行滨江支行行长徐葳、杭州银行滨江文化中心小微企业专营支行行长叶小丽等人出席了本次活动。

  

**活动预热点**

![](../Images/1c084e7ea0d4ee8e5e16e4dac44f74a1.png)![](../Images/80dbfc75f70e7ec30e1205aa5e0f6a17.png)

在宣讲会开始之前，园区工作人员在活动预热点，为来往的园区用户送上马石精美小礼品。

  

**活动会场**

![](../Images/56872dbbbf41f9de95af809327828947.png)![](../Images/829e930f1ebafbc3da29048451426d66.png)

临近会议开始，大家有序到场，只要扫码关注我们的公众号，就能够获得精美伴手礼礼包！里面不仅有新鲜的手工烘焙面包，还有多种实用小物、商家优惠券。

**宣讲会ing**

下午两点，观众们准时到场，宣讲会开始啦！

  

**#** 上马石产品介绍

![](../Images/64cdb6a2a07a8981e3d959468418ab56.png)

上马石这款小程序究竟有什么样的功能？

为什么能帮助到滨江区的企业？

  

滨江区市场监管局企业监管科科长高轶舟

为现场的企业代表们介绍了

“上马石企业e服务平台”

主要功能及建设意义

![](../Images/968e49a4e998ee145d957097f02710bb.png)

**课代表划一下重点：**

  

**“滨江上马石企业e服务平台”是由滨江区市场监督管理局支持建设，只为帮助企业解决发展难题！**

  

**小程序内置九大功能：政策服务、金融服务、园区服务、企业互助、活动沙龙、闲置易物、企业查询、留言板、机构服务。  
**

  

**通过智能推荐匹配，帮助企业了解、享受区域内的政策和金融优惠、园区租赁优惠；**

  

**搭建企业互助渠道，闲置交易、活动沙龙等方式降低企业运营成本；**

  

**小程序支持用户查询企业信息（包括小微企业认定）、自行发布产品优惠福利；还支持留言咨询，由后台客服联系相关部门给予详细、专业的解答。**

![](../Images/76abef0e090b085c9bbd5784b8b3f576.png)

赶紧扫码用起来！

**#** 园区“上马”环节

  

![](../Images/d0d8d7a7502c92daa6d80cc7d5f82e9a.png)

浙农科创园董事施胜锡为第一次来到园区的企业家伙伴们做一个简单的园区介绍，园区和安恒在这次活动中都尽力帮助宣讲会顺利举办，大家都辛苦啦~

![](../Images/f10ac065441e6cfedb35053363dd1684.png)![](../Images/829e95f7ef39e7889db96b34c4013fa7.png)

在园区内，早有几家入驻上马石的企业，在现场，他们的企业代表分享了各自与上马石之间的故事。

![](../Images/24069039d1eedcf7c53e8a0cfaef2277.png)![](../Images/975a887db347b98896ac14d843d4f28f.png)![](../Images/8705afed3deb04234a04f0c1cf405ece.png)

还有几家企业在活动现场对上马石十分感兴趣，举手上台向现场企业代表们介绍了各自企业的产品，争取“上马”。

  

**#** 银行产品介绍

  

上马石能让银行与企业进行信息匹配，精准提供服务，但是在上马石里，银行具体能提供什么样的优惠服务？现场两位银行代表为企业答疑解惑。

  

在了解了银行在上马石的金融产品优惠之后，两家企业的代表当场和银行进行了签约，现场举行了简短的签约仪式。

![](../Images/83fd5c2267ae434f4d086e5409b41c97.png)

↑↑↑泰隆银行滨江支行向杭州陀飞科技有限公司授信200万元整。

![](../Images/1490ade96c3569ba2b54715f1caf1ce1.png)

↑↑↑浙江沐川贸易有限公司的代表与杭州银行滨江文化中心小微企业专营支行现场签约，放款内容为：抵押贷款500万元整、信用贷款200万元整。

  

  

**活动结束**

![](../Images/82bec93e8b758b2a7aa82b923ab06b10.png)

在活动结束之际，杭州高新区(滨江)市场监管局局长钱毓军为活动发表了讲话感言，钱局长表示，希望滨江上马石能帮助滨江企业越来越好，并对各位支持上马石发展的企业表示了诚挚感谢。

![](../Images/533f28956b4f81c17efa5ec6eb7c1b9f.png)

小石头之后会继续在线下和大家见面，让滨江企业更加了解上马石，积极入驻上马石。而作为小石头的好朋友，风小妹会一直支持上马石的！

  

也请大家继续支持我们的好朋友上马石哦！
