# SANS研究所表示，近期其多名员工受到钓鱼攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMDgyNTQzMQ==&mid=2247485195&idx=1&sn=a9fd18b905e4159e01e37cb5e571eb21&chksm=9ae24633ad95cf25e119b44762b20b876fd8cfaf2e719097ccd01d0e61e8d3fcd5ce65502aac&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMDgyNTQzMQ==&mid=2247485195&idx=1&sn=a9fd18b905e4159e01e37cb5e571eb21&chksm=9ae24633ad95cf25e119b44762b20b876fd8cfaf2e719097ccd01d0e61e8d3fcd5ce65502aac&scene=27#wechat_redirect)

SANS研究所表示，最近披露的安全事件涉及攻击者向其数名员工发送的钓鱼邮件。  

  

该攻击于8月6日被发现，导致28,000条个人身份信息（PII）记录被转发到外部未知电子邮件地址。总共转发了513封电子邮件，但其中大多数未包含重要信息。

  

在首次披露安全事件后，SANS发布了与此事件相关的危害指标，其显示，在7月24日，攻击者向多名员工发送了网络钓鱼电子邮件，其中只有一名被骗。

  

“网络钓鱼电子邮件诱使单个用户为其帐户安装恶意的Office 365加载项。Office365加载项导致在受害者的帐户上配置了转发规则，从而导致513封电子邮件被转发到未知的外部电子邮件地址。” SANS解释说。

  

该公司指出，这封电子邮件的主题是《文件名为”sans 7月份奖金 2020年7月24日.xls副本”已与<某接收者>共享》，该电子邮件似乎来自Office 365。

  

作为攻击的一部分，诱使受害者单击了“打开”按钮。这导致安装了恶意Office 365应用程序，以配置包含与财务数据关联的关键字的电子邮件转发规则。

  

SANS还解释说，恶意Office 365加载项名为Enable4Excel，非常类似于合法的Salesforce加载项Enabler4Excel。

  

“基于收到网络钓鱼电子邮件的用户以及攻击者希望通过恶意电子邮件转发规则获取的数据，没有迹象表明这直接针对SANS组织或其客户。这次攻击似乎是出于意图进行金融盗窃的机会，” SANS说。

  

上周，该公司报告说，攻击者访问的数据不包含密码或财务信息，例如信用卡数据。该公司正在将有关事件通知受影响的用户，但表示并未警告当局，而是选择自行调查。

  

SANS表示，“ SANS数据保护团队有考虑这是否触犯美国还是欧盟法律任何法律要求，最终的结论是没有。我们进行了全面的风险评估，涉及数据的性质和质量，以及围绕这些数据的风险对客户潜在重要性。

  

该公司还透露，此次事件影响了有限的行业联系信息数据，因为大部分数据可以在公共领域找到，并且它认为该事件不符合法律报告标准。

  

该公司指出：“尽管法律上没有要求SANS报告此事件，但重视安全防护实践的SANS还是出于充分透明的目的通知了其受影响的客户，并确保我们受影响的客户掌握了相关信息” 。
