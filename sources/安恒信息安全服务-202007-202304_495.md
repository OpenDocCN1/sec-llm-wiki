# 风险评估怎么做？一览本文get要点！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMDgyNTQzMQ==&mid=2247485056&idx=1&sn=28df9793ed5a0d1dee81693d32ff2ebe&chksm=9ae247b8ad95ceae058ece42a72534de74e9d54fe6914107ad8074fa9c896f0bbc7a625a6971&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMDgyNTQzMQ==&mid=2247485056&idx=1&sn=28df9793ed5a0d1dee81693d32ff2ebe&chksm=9ae247b8ad95ceae058ece42a72534de74e9d54fe6914107ad8074fa9c896f0bbc7a625a6971&scene=27#wechat_redirect)

风险评估是我们生活中常用高频词，在不同场景下会有不同含义。网上对风险评估的定义是在风险事件发生之前或之后（但还没有结束），该事件给人们的生活、生命、财产等各方面造成的影响和损失的可能性进行量化评估的工作。从描述来看不难得出风险评估的重要性，那它具体包含哪些重点内容和流程呢？今天我们通过这篇小短文向大家介绍啦，话不多说，我们直奔主题~

![](../Images/f942d83f74dc003ef9ccaa240765aa7c.png)

在信息网络安全领域，风险评估对信息资产（即某事件或事物所具有的信息集）所面临的威胁、存在的弱点、造成的影响，以及这三个要素综合作用所带来风险的可能性的评估。每个要素都有各自的属性，资产的属性是资产价值；威胁的属性可以是威胁主体、影响对象、出现频率、动机等，脆弱性的属性是资产脆弱性的严重程度。  

 

企业安全部门评估、监控和降低风险的有效方法就是设立管控机制，使企业具备长期稳定的风险管理能力。而风险评估过程本身则有一定风险，为规避风险，开展信息安全风险评估工作应遵循以下原则：

1.可控性原则：提高风险控制能力。

2.完整性原则：在已确定评估范围内进行全面的评估活动。

3.最小影响原则：将风险评估过程对信息系统运行可能造成的影响降低到最低。

4.保密性原则：在风险评估实施前，签署书面形式的保密协议。

5.可恢复性原则：在风险评估实施前，在实施方案中应明确指出意外情况下系统恢复的手段和具体的恢复策略。

 

资产的价值由机密性、完整性、可用性、业务相关性四个属性的价值综合评定得出，计算公式如下：

资产值（D）=（机密性赋值+完整性赋值+可用性赋值+业务相关性赋值）/4。

 

评估者应根据所采用的风险计算方法，计算每种资产单个漏洞面临的风险值，根据风险值的分布状况，为每个等级设定风险值范围，并对所有风险计算结果进行等级处理，实现对风险的控制与管理。将风险划分为五个等级，每个等级代表了相应风险的严重程度，等级越高，风险越高。

随着网络信息安全的发展，信息安全风险的指导变得尤为重要。既要鉴别和评估业务风险，又要审查变化中的风险水平，以满足环境的变化。

  

安全风险分析和评估阶段主要包含：资产识别和评估、威胁识别和评估、脆弱性识别和评估、已有安全措施评估等阶段。根据风险分析结果，我们可以有四种不同类型的风险处置，分别是：规避风险，转移风险，控制风险和接受风险。

  

任何项目在实施前都需要做好风险评估，这样可避免资产受损时遭受更大威胁。虽说风险评估做起来并不是很容易，但做得好项目运行起来更省心，小伙伴们在进行项目管理时可以试试噢~
