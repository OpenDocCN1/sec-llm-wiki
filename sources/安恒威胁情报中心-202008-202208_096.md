**恶意软件威胁情报**

  

**1.Siloscape：针对Windows容器的恶意软件**

2021 年 3 月，研究人员发现了一个针对 Windows 容器的恶意软件，研究人员将其命名为 Siloscape。Siloscape 是一种经过高度混淆的恶意软件，它积极尝试在野利用 Windows Server 容器，利用影响 Web 服务器和数据库的已知漏洞针对 Kubernetes 集群。其主要目的是在配置不当的 Kubernetes 集群中创建后门，以运行恶意容器。该恶意软件可以利用 Kubernetes 集群中的计算资源进行加密劫持，并可能从受感染集群中运行的数百个应用程序中窃取敏感数据。

![](../Images/d057529b3bb0e55a9b7ea9f72080ef2c.png)

**2****.研究人员发布对Gootkit银行木马的分析**

研究人员捕获了Gootkit银行木马的最新样本并进行分析。Gookit是一种复杂的多阶段银行恶意软件，于 2014 年首次发现，最近针对意大利和德国银行用户展开攻击。Gootkit 通过垃圾邮件活动和被感染的网站传播，能够从浏览器窃取数据，黑客可以执行键盘记录、截屏和许多其他恶意操作。它的加载程序执行各种虚拟机和沙箱检查，并使用复杂的持久性算法。

**参考链接**  

https://ti.dbappsecurity.com.cn/informationDetail/2049

  

  

**3****.SteamHide恶意软件利用Steam游戏平台进行传播**

近日，研究人员发现SteamHide恶意软件滥用Steam游戏平台进行传播，黑客通过在Steam上添加新的个人资料图像来更新已经被感染的机器上的恶意软件。虽然在图像文件的元数据中隐藏恶意软件并不是一个新现象，但使用 Steam 等游戏平台以前是闻所未闻的。对于黑客来说，替换恶意软件就像替换个人资料图片一样简单。

https://ti.dbappsecurity.com.cn/informationDetail/2054

  

  

**4.****研究人员对新型勒索软件BlackCocaine进行分析**

2021 年 5 月 30 日，总部位于印度的银行和金融服务行业 IT 公司 Nucleus Software遭到了网络攻击。近日，研究人员调查了此次攻击，并把该攻击事件归因于BlackCocaine Ransomware团伙。黑客使用了各种反虚拟机和反调试方法以规避检测。此外，在这次攻击中，BlackCocaine 勒索软件团伙还使用了 AES 和 RSA 加密方法。

https://ti.dbappsecurity.com.cn/informationDetail/2055

  

  

**5.Keksec组织使用Tsunami-Ryuk进行恶意活动**

近日，Keksec组织更新了他们的工具集和漏洞利用组件，并使用Tsunami-Ryuk DDOS恶意软件进行活动，还改进了DGA 算法。Keksec，又名 Necro 和 Freakout，是一个以云基础设施为目标的黑客组织，其目的是执行加密货币挖掘和 DDoS 操作。

  

Keksec组织使用了Tsunami-Ryuk DDOS恶意软件，更新了 Necro恶意软件的DGA算法，持续更新他们的工具集和漏洞利用组件，是一个不断发展的威胁组织。

**2****.国际钓鱼执法“Ironside”行动收网：通过加密聊天平台截获通讯信息**

自2018年起，美国联邦调查局及其国际执法合作伙伴依托虚假加密手机实施名为“Ironside”的全球“钓鱼执法”行动，运营了名为AN0M（又名 Anøm）的加密聊天平台，通过该平台的内部人员秘密获得了访问权限，并拦截了来自全球各地的犯罪成员之间的通讯信息。目前，联邦调查局及其国际执法合作伙伴的收网行动已在新西兰、澳大利亚和欧洲启动，仅在澳大利亚大陆就以 526 项罪名逮捕了来自澳大利亚、亚洲和南美的224 名涉及毒、武器和人口贩运等罪行的罪犯。

  

“Ironside”钓鱼行动有两个主要目标：一是利用AN0M加密手机所收集的犯罪证据，彻底摧毁跨国犯罪组织；二是在全球犯罪地下社群中散布“加密手机等秘密通信手段不可靠”的印象。

**2****.RockYou2021：黑客论坛泄露84亿条密码记录**

近日，研究人员发现某黑客论坛有用户发布了一个100GB的txt文件，其中含有84亿条密码记录。据发布的用户称，所有密码长度都在6-20个字符之间，并移除了所有的非ASCII码字符和空格。该用户声称其中包含820亿密码记录，但研究人员检查后发现其中包含的实际密码数量为84.59亿。这84亿条密码和其他包含用户名、邮箱地址、密码的密码集可以组合使用，因此攻击者可以使用RockYou2021数据集来进行词典攻击和一系列的暴力破解攻击。

**3.暗网出售美国1.07亿选民信息**

研究人员发现，目前有超过 1.07 亿美国人的选民记录在暗网上以低至 10 美元的价格出售。出售的数据包含美国 27个州的选民数据库以及公民的私人信息。被泄露的选民记录包括极其敏感的信息，如选民编号、全名、实际地址、曾住址、出生日期、性别和公民身份。泄露的数据还会显示选民之前是否登记投票以及在哪次选举中投过票。

**1.全球第二大内存制造商威刚遭Ragnar Locker勒索软件攻击**

2021年6月9日，全球第二大存储器和存储制造商威刚（ADATA）表示曾在5月23日遭到勒索软件攻击。此次攻击迫使其关闭受影响系统。勒索团伙Ragnar Locker声称是此次攻击的始作俑者，并表示在部署勒索软件有效载荷之前，已经从威刚的网络中窃取了1.5TB的敏感数据。到目前为止，该勒索软件团伙只发布了被盗文件和文件夹的截图作为自证。Ragnar Locker称，如果该公司不支付赎金，将泄露其余数据。

威刚总部位于台湾，生产高性能 DRAM 内存模块、NAND 闪存卡和其他产品，包括移动配件、游戏产品、电力系统和工业解决方案。该公司在2018年被评为全球第二大 DRAM 内存和固态硬盘 (SSD) 制造商。

**1****.SideWinder武器库更新：利用外交政策针对巴基斯坦的攻击活动分析**

今年3月，研究人员捕获到几例利用相关国家外交政策为诱饵的恶意样本，并将其归因为响尾蛇(SideWinder)组织。此类样本伪装成大使馆向巴基斯坦委员会的投资回信、建立港口防疫能力等热点信息开展攻击。一旦受害者执行此类恶意样本，初始LNK文件将从远程服务器下载恶意脚本执行，恶意脚本将释放展示正常的诱饵文档以迷惑受害者，并继续从远程服务器获取第二阶段恶意脚本执行。第二阶段恶意脚本中更新了在受害者计算机上部署相关恶意软件的流程，最后通过白加黑的方式加载最终的远程木马，控制受害者机器，从而窃取敏感信息。

**2****.研究人员将BigNox供应链攻击归因于Gelsemium组织**

近日，研究人员在对BigNox 的供应链攻击的调查中，发现了此次供应链攻击与 Gelsemium 组织之间存在重叠，因此研究人员把 BigNox 供应链攻击归因于 Gelsemium（狼毒草）组织。Gelsemium 是一个自 2014 年以来活跃的网络间谍组织，主要针对的目标包括东亚和中东的政府、大学、电子制造商和宗教组织。

![](../Images/cc7016fb20c6d2a331f26c39b2fcded0.png)

BigNox 供应链攻击事件只影响了台湾、香港和斯里兰卡的有限目标，具有高度针对性。研究人员认为，黑客使用的插件系统表明其开发人员精通C++知识。此次供应链攻击与 Gelsemium 组织之间存在重叠，使用大量适应性组件。因此，研究人员以中等置信度得出结论，BigNox 供应链攻击事件与 Gelsemium 组织有关。

**参考链接**  

https://ti.dbappsecurity.com.cn/informationDetail/2063

  

  

**3****.Fancy Lazarus组织发起DDOS 勒索攻击活动**

研究人员发现了勒索组织“Fancy Lazarus”发起的新的分布式拒绝服务 (DDoS) 勒索活动，该组织以伪装成各种APT组织而闻名，与同名的朝鲜Lazarus Group 和俄罗斯的 Fancy Bear组织没有联系。Fancy Lazarus针对的行业包括能源、金融、保险、制造、公用事业和零售业，此次活动主要针对美国公司或遍布全球的公司。该组织向受害公司索要两枚比特币作为赎金（约 75,000 美元），以避免公司遭受严重的 DDoS 攻击，截止日期后未付款将把赎金翻倍至 4 BTC，之后每天增加 1 BTC。Fancy Lazarus在2021 年 4 月到 5 月停止了活动，近日该组织在改进其技术和程序后再次活跃。

**参考链接**  

https://ti.dbappsecurity.com.cn/informationDetail/2068

  

  

**4****.新威胁组织PuzzleMaker利用Chrome和Windows 0 day漏洞进行攻击活动**

研究人员发现了一个名为PuzzleMaker的新威胁组织，该攻击者使用了一系列 Google Chrome 和 Microsoft Windows 0 day漏洞，对全球多家公司进行了攻击。活动中部署的0 day漏洞利用链利用 Google Chrome V8 JavaScript 引擎中的远程代码执行漏洞访问目标系统。PuzzleMaker 攻击者利用提权漏洞以针对 Windows 10 的最新版本（17763 – RS5、18362 – 19H1、18363 – 19H2、19041 – 20H1、19042 – 20H2），同时也利用了Microsoft Windows操作系统内核中的信息泄露漏洞：CVE-2021-31955。

**参考链接**  

https://ti.dbappsecurity.com.cn/informationDetail/2058
