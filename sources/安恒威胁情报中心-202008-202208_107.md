# 2021西湖论剑·网络安全大会威胁情报及应急响应分论坛成功举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1MDU5NjYwNg==&mid=2247489308&idx=1&sn=625a598522e5c71a35f267d573d87194&chksm=e9fe8a8dde89039bccff33465674bbb70e2a752732c5bdbf32678c24ab5be5004facdd180f59&scene=126&sessionid=1681273578#rd](http://mp.weixin.qq.com/s?__biz=MzI1MDU5NjYwNg==&mid=2247489308&idx=1&sn=625a598522e5c71a35f267d573d87194&chksm=e9fe8a8dde89039bccff33465674bbb70e2a752732c5bdbf32678c24ab5be5004facdd180f59&scene=126&sessionid=1681273578#rd)

![](../Images/dbe6208f322b7d2186a81e3f89ebc2ed.png)

由国家计算机网络应急技术处理协调中心指导，国家计算机网络应急技术处理协调中心浙江分中心主办，安恒信息、阿里云计算有限公司联合承办的威胁情报及应急响应分论坛于4月24日在杭州国际博览中心成功举办。  
本次分论坛以“主动防御共享安全”为主题，旨在从体系建设、趋势分析、思路方法、实践经验等多个角度入手，共同探讨全网威胁情报及应急响应工作的特点和思路，促进国家公共互联网网络安全应急体系成员间合作，实现威胁数据共享，加强互联网行业网络安全保障和突发安全事件应急处置联动。

> > 
> >   
> >   
> >   

  
国家计算机网络应急技术处理协调中心浙江分中心主任胡红宪为分论坛发表致辞。![](../Images/e4d871059b519a460b522a87de7f30f9.png)

ZJCERT  胡红宪

他表示，党的十八大以来，在习近平总书记网络强国重要思想引领下，我国网信事业取得了历史性成就。在2020年抗击疫情过程中，大量新型互联网技术、产品、业务应运而生，进一步推进了社会的数字化转型，但也为网络安全防护工作带来新的挑战。  
当前网络强国建设在“两个一百年”奋斗目标接续推进中进入了新发展阶段，浙江分中心作为中央网信办管理领导下的技术支撑和业务保障单位，将继续深入贯彻总书记关于网络强国的重要思想和网络安全工作会议重要讲话精神，紧紧围绕保障数字化改革，全面实施网络安全整体能力提升行动，为护航建党百年庆祝活动保驾护航。

> >

从‍‍2013年威胁情报概念的首次提出，到如今落地成熟并逐渐规模化发展，威胁情报与应急响应工作已有大量的实践与经验。论坛上，各家行业带来精彩的经验分享。  

![](../Images/70c8dd03a475a83f5ed10f1af5671ac6.png)

CNCERT  何能强

  
围绕《网络安全众测工作的探索与实践》主题，国家计算机网络应急技术处理协调中心高级工程师何能强发表演讲。  
他介绍了网络安全众测的发展情况、国家级众测平台的探索以及CNVD众测和CCTGA联盟的实践，开展网络安全众测工作，有助于培养网络安全人才、加强信息技术产品安全性、促进产业整体安全能力提升，能够有效推动网络安全教育、技术与产业的融合发展。  
  
![](../Images/cdb130e54a089e7b8553ab1d12b21412.png)

ZJCERT  马骏野

  

国家计算机网络应急技术处理协调中心浙江分中心工程师马骏野结合浙江省网络安全态势，对《信息安全技术 网络安全应急能力评估准则》进行了解读，诠释了网络运营者应当如何提升自身网络安全应急能力。

  

  

  

> > **面向未来  业内精英共思考**
> > 
> >   
> >   
> >   

  

数字化转型进程不断深入，各行各业对数字风险防护管理的需求与日俱增。威胁情报作为网络空间治理的重要一环，利用其加快应急响应、辅助安全决策成为未来网络安全建设的一大方向。

  

针对过往实践经验和这一发展方向，此次分论坛邀请业内精英一同思考，促进网络安全“未攻先防”效果的达成。

  
![](../Images/1996b81a7b6e0a09d466bea731c28c4b.png)安恒信息  涂小毅  
安恒信息威胁情报中心研究总监涂小毅针对如何构建一体化的威胁情报中心问题从定义威胁情报开始，进而分享了安恒信息的威胁情报处理过程。  

他介绍，安恒信息从情报的获取和处理开始，进而搭建情报平台的搭建，并进行威胁情报的应用。在情报的转移应用方面，涂小毅给出了三个方向，分别是情报的赋能、线索剥线和态势感知。

  

此外，来自阿里云、腾讯、浙江电信、安博通、天际友盟等专家围绕网络威胁情报实践、应急处置等内容发表主题演讲。
