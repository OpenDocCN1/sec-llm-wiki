恶意软件威胁情报


1.Clast82：通过合法应用进行分发的Android恶意软件

Check Point（CPR）的研究人员发现了10个传递Clast82恶意软件的合法应用程序，Clast82旨在绕过Google Play商店的保护，然后传递其他恶意软件，使黑客可以访问受害者的财务帐户并控制他们的手机。

参考链接

https://ti.dbappsecurity.com.cn/informationDetail/1741



2.Gootloader恶意软件正在感染全球WordPress网站

被称为Gootloader的Downloader恶意软件正在感染全球的 WordPress 网站，这是一场大规模的drive-by攻击和水坑攻击活动，该活动通过向WordPress网站注入数百页虚假内容来滥用 WordPress 网站。到目前为止，攻击者已经分发了Cobalt Strike入侵工具，Gootkit银行木马或REvil勒索软件。

参考链接

https://ti.dbappsecurity.com.cn/informationDetail/1736



3.研究人员发现两个新型勒索软件：AlumniLocker，Humble

研究人员最近发现两个新的勒索软件变体，分别是AlumniLocker和Humble。用户和组织应遵循安全建议，以保护其设备和系统免受勒索软件的侵害，包括实施最低特权原则，禁用本地管理员帐户以及限制对共享驱动器或网络驱动器的访问。

参考链接

https://ti.dbappsecurity.com.cn/informationDetail/1753


物联网行业威胁情报


1.Gafgtyt_tor僵尸网络针对D-Link和物联网设备

Gafgyt_tor是Gafgyt僵尸网络的新变种，Gafgyt_tor是第一个依赖于Tor通信的恶意软件，主要针对易受攻击的D-Link和物联网设备。僵尸网络主要通过Telnet弱密码和利用三个漏洞进行传播。这些漏洞包括D-Link设备中的远程代码执行漏洞（CVE-2019-16920）；Liferay企业门户软件中的的远程代码执行漏洞（没有可用的CVE）；Citrix应用程序交付控制器中的漏洞（CVE-2019-19781）。

参考链接

https://ti.dbappsecurity.com.cn/informationDetail/1731



2.黑客入侵Verkada系统访问多家企业监控摄像头

据黑客组织的逆向工程师Tillie Kottmann说，他们使用Verkada的超级管理员帐户访问了这些监控系统， 这导致他们可以访问安装在Tesla、Equinox、医疗诊所、监狱和银行(包括犹他银行)的实时监控摄像头。除了从摄像头捕捉到的图像外，黑客还分享了获得Cloudflare和Telsa总部使用的监视系统的root shell访问权限的截图。

参考链接

https://ti.dbappsecurity.com.cn/informationDetail/1747



3.特斯拉远程监控被攻击，安全问题也不能忽视

3月10日，有媒体报导特斯拉又双叒出事了......起因是河南一处特斯拉供应商生产现场使用了某硅谷初创企业品牌智能摄像机作为远程质量管理的手段，一小群黑客通过漏洞获取了该品牌的摄像头管理权限，致使车间内部画面被公开，图片里甚至能够看到装配线上的工人，差点曝光量子波动定价的秘密。

基础设施威胁情报


1.俄罗斯APT组织利用立陶宛基础设施发动攻击

立陶宛国家安全部门发布的年度国家安全威胁评估报告称，与俄罗斯的APT组织在2020年对立陶宛高级官员和决策者进行了网络攻击。国家资助的黑客APT29还利用立陶宛的信息技术基础设施，对“研制COVID-19疫苗的外国实体”进行攻击。

参考链接

https://ti.dbappsecurity.com.cn/informationDetail/1743


钓鱼攻击威胁情报


1.利用被黑SendGrid账户窃取用户凭据的钓鱼活动

研究人员发现一场针对Outlook Web Access和Office 365服务用户的钓鱼活动。自去年12月以来，攻击者在多个恶意活动中收集了超过40万个Outlook Web Access和Office 365凭据凭据。

参考链接

https://ti.dbappsecurity.com.cn/informationDetail/1734



2.利用微软主题针对企业高管的钓鱼活动

研究人员最近发现了一系列以微软为主题的钓鱼攻击，目标是多个组织的高级员工。此次攻击的目标是拥有副总裁和董事总经理等头衔的高级商业领袖，他们可能对公司的敏感数据拥有更高程度的访问权限。这些活动的目的是窃取这些受害者的登录凭证，从而让攻击者可以访问有价值的公司资产。攻击已经蔓延到许多行业，其中银行和IT行业的攻击最为频繁。

参考链接

https://ti.dbappsecurity.com.cn/informationDetail/1737


高级威胁情报


1.MuddyWater针对中东组织的最新攻击活动

研究人员最近检测到针对中东和周边地区各种组织的攻击活动，通过分析，以中等可信度将本次活动与MuddyWater组织关联。本次活动中使用了ScreenConnect和RemoteUtilities远程管理工具，研究人员将这些入侵工具命名为Earth Vetala。

参考链接

https://ti.dbappsecurity.com.cn/informationDetail/1739



2.疑似Donot组织针对泰国的攻击活动

近日，研究人员发现Donot APT组织的攻击活动，其利用恶意RTF模板注入以及公式编辑漏洞利用样本对周边国家地区开展了多次攻击活动。捕获的样本以“泰国皇家海军第82指挥和参谋课程”、“OPS检查细节”，“OPS需求”、“国防部副本”等标题作为诱饵文档进行攻击活动。其中OPS疑似是位于泰国的石油天然气公司。根据诱饵标题猜测该组织疑似开始针对泰国开展攻击活动。

参考链接

https://ti.dbappsecurity.com.cn/informationDetail/1735



3.多个APT组织展开针对Exchange服务器的攻击活动

近日，研究人员观察到至少10个APT组织加入了针对本地Exchange服务器的攻击活动，这些服务器由于存在ProxyLogon漏洞而受到严重影响。微软称该漏洞最初是由Hafnium组织使用的，之后ESET安全公司发现其他APT组织在攻击中滥用ProxyLogon漏洞。


通过遥测技术，发现攻击者已经在115个以上国家/地区的5000多台Exchange服务器上部署了Web shell。

参考链接

https://ti.dbappsecurity.com.cn/informationDetail/1745
