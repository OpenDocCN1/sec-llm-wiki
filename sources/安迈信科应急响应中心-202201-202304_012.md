## **0x01**** 漏洞信息**  

  
漏洞名称：Apache HTTP Server请求走私漏洞漏洞编号：CVE-2023-25690漏洞等级：高披漏时间：2023年3月8日  

## **0x02** 漏洞描述

  

Apache HTTP Server 版本2.4.0 - 2.4.55的某些mod\_proxy配置可能导致HTTP请求走私攻击，这种攻击可能会导致绕过代理服务器中的访问控制，将非预期的URL代理到现有源服务器，以及缓存中毒等。

| --- | --- | --- | --- |
| 广 || 低 || 未公开 || 未公开 |

## **0x04 影响版本**

  
Apache HTTP Server <= 2.4.55  

## **0x05 漏洞排查**  

  
用户尽快排查所有应用系统Apache HTTP Server应用版本是否小于2.4.55。若存在应用使用，极大可能会受到影响。  

## **0x06 漏洞加固**

  
目前已有可更新版本，建议升级至 Apache HTTP Server 2.4.56 及以上版本。
