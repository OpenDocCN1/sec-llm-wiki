0x01 漏洞信息


漏洞名称：Windows Subsystem for Linux (WSL2) 内核特权提升漏洞
漏洞编号：CVE-2022-38014
漏洞等级：高
披漏时间：2022年11月08日

0x02 漏洞描述


Microsoft Windows是一款由美国微软公司开发的窗口化操作系统。
Microsoft Windows Subsystem for Linux (WSL2) Kernel存在权限提升漏洞。攻击者可利用该漏洞提升权限。
