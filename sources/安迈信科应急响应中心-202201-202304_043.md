## **0x01**** 漏洞信息**  

  
漏洞名称：Windows Subsystem for Linux (WSL2) 内核特权提升漏洞漏洞编号：CVE-2022-38014漏洞等级：高披漏时间：2022年11月08日  

## **0x02** 漏洞描述

  
Microsoft Windows是一款由美国微软公司开发的窗口化操作系统。Microsoft Windows Subsystem for Linux (WSL2) Kernel存在权限提升漏洞。攻击者可利用该漏洞提升权限。

## **0x04 影响版本**

  
Microsoft Microsoft Azure EFLOW  
Microsoft Microsoft Windows Subsystem for Linux (WSL2)  

## **0x05 漏洞排查**  

  
用户尽快排查由microsoft开发的应用azure\_iot\_edge\_for\_linux和windows\_subsystem\_for\_linux。若存在应用使用，极大可能会受到影响。  

## **0x06 漏洞加固**

  
目前官方已经发布了升级补丁以修复这个安全问题，请到受影响的用户更新下载。链接如下：https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2022-38014
