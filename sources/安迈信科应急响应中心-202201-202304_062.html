0x01 漏洞信息


漏洞名称：Active Directory 域服务特权提升漏洞
漏洞编号：CVE-2022-26923
漏洞等级：严重
披漏时间：2022年5月11日

0x02 漏洞描述


Active Directory 域服务存在特权提升漏洞。该漏洞是由于对用户属性的不正确获取，经过身份验证的攻击者可以操纵他们拥有或管理的计算机帐户的属性，并从 Active Directory 证书服务获取允许提升特权的证书，从而实现权限提升，最终导致域服务被接管。
