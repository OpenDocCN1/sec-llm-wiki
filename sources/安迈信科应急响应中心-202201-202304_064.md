## **0x01**** 漏洞信息**  

  
漏洞名称：Windows LSA远程代码执行漏洞漏洞编号：CVE-2022-26925漏洞等级：高披漏时间：2022年05月11日  
  

## **0x02** 漏洞描述

  
Windows LSA存在远程代码执行漏洞。该漏洞是由于逻辑错误，攻击者可利用该漏洞在未授权的情况下，构造恶意数据执行远程代码执行攻击，最终获取服务器最高权限。

## **0x04 影响版本**

  
Windows 8.1、Windows 10 Version 1607、Windows 10 Version 1809、Windows 10 Version 1909、 Windows 10 Version 2004、 Windows 10 Version 20H2、Windows Server version 2008、Windows Server version 2012、Windows Server version 2016、Windows Server version 2019、Windows Server version 2004、Windows Server version 20H2、Windows 7  

## **0x05 漏洞排查**  

  
用户尽快排查所有应用系统:Windows LSA应用版本是否处于被影响的版本中，若存在应用使用，极大可能会受到影响。
