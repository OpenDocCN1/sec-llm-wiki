## **0x01**** 漏洞信息**  

  
漏洞名称：Windows 内核特权提升漏洞(CVE-2022-29142)漏洞编号：CVE-2022-29142漏洞等级：高披漏时间：2022年5月11日  

## **0x02** 漏洞描述

  
Windows 内核存在特权提升漏洞。攻击者可利用该漏洞在获得权限的情况下，构造恶意数据执行本地提权攻击，最终获取服务器最高权限。

## **0x04 影响版本**

  
Windows 10 Version 1909 for 32/64-bit/ARM64-based Systems、Windows 10 Version 20H2 for 32/64-bit/ARM64-based Systems、Windows 10 Version 21H1 for 32/64-bit/ARM64-based Systems、Windows 10 Version 21H2 for 32/64-bit/ARM64-based Systems、Windows Server 2019、  Windows Server 2022 (Server Core installation)、  Windows Server Version 20H2 (Server Core Installation)、Windows 10 Version 1809 for 32/64-bit/ARM64-based Systems  

## **0x05 漏洞排查**  

  
在cmd中执行命令systeminfo，从命令行输出结果中查找是否已安装对应系统的补丁包。若未安装补丁包，需尽快安装。打补丁方法：Windows设置-更新与安全-Windows更新-检查更新  

## **0x06 漏洞加固**

  
当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁。链接如下：https://msrc.microsoft.com/update-guide/vulnerability/CVE-2022-29142
