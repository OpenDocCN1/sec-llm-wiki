## **0x01**** 漏洞信息**  

  
漏洞名称：Oracle Java SE 身份认证绕过漏洞漏洞编号：CVE-2022-21449漏洞等级：高披漏时间：2022年4月27日  

## **0x02** 漏洞描述

  
Oracle Java SE 存在身份认证绕过漏洞。该漏洞是由于Oracle Java SE受影响版本中对椭圆曲线数字签名算法（ECDSA）的实现存在缺陷，攻击者可利用该漏洞伪造签名并绕过身份认证措施。

## **0x04 影响版本**

  
Oracle Java SE 16、 Oracle Java SE 17.0.2、 Oracle Java SE 18、Oracle GraalVM Enterprise Edition 21.3.1、 Oracle GraalVM Enterprise Edition 22.0.0.2、Oracle Java SE 15  

## **0x05 漏洞排查**  

  
用户尽快排查所有应用系统Oracle Java SE应用版本是否在漏洞影响版本之间。若存在应用使用，极大可能会受到影响。  

## **0x06 漏洞加固**

  
当前官方已发布最新版本，建议受影响的用户及时更新升级到最新版本。链接如下：https://support.oracle.com/
