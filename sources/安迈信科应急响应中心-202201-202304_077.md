## **0x01**** 漏洞信息**  

  
漏洞名称：Windows DNS 服务器远程代码执行漏洞漏洞编号：CVE-2022-26815漏洞等级：高披漏时间：2022年4月13日  

## **0x02** 漏洞描述

  
Windows DNS 服务器存在远程代码执行漏洞。该漏洞是由于对数据的错误处理而导致，攻击者可利用该漏洞在获得权限的情况下，构造恶意数据执行远程代码，最终获取服务器最高权限。

## **0x04 影响版本**

  
Windows Server 2012、Windows Server 2016、Windows Server 2019、Windows Server 2022、Windows Server 2008  

## **0x05 漏洞排查**  

  
用户尽快排查所有windows系统版本是否为Windows Server 2012、Windows Server 2016、Windows Server 2019、Windows Server 2022、Windows Server 2008。若使用以上系统版本，极大可能会受到影响。  

## **0x06 漏洞加固**

  
当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁。链接如下：
