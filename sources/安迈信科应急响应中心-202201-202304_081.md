## **0x01**** 漏洞信息**  

  
漏洞名称：VMware 远程代码执行漏洞漏洞编号：CVE-2022-22957漏洞等级：严重披漏时间：2022年4月6日  
  

## **0x02** 漏洞描述

  
VMware 存在远程代码执行漏洞，具有管理访问权限的攻击者可以通过恶意 JDBC URI 触发不可信数据的反序列化，从而导致远程代码执行。  

## **0x03 漏洞状态**

| --- | --- | --- | --- |
| 低 || 中 || 未公开 || 未公开 |

## **0x04 影响版本**

  
VMware Workspace ONE Access 21.08.0.0、  VMware Workspace ONE Access 20.10.0.1、   VMware Workspace ONE Access 20.10.0.0、  VMware Identity Manager 3.3.6、  VMware Identity Manager 3.3.5、  VMware Identity Manager 3.3.4、  VMware Identity Manager 3.3.3、  VMware Cloud Foundation (vIDM) 4.x、  VMware Cloud Foundation (vRA) 3.x、  vRealize Suite Lifecycle Manager 8.x、VMware Workspace ONE Access 21.08.0.1  

## **0x05 漏洞排查**  

  
用户尽快排查所有应用系统VMware应用版本是否在以上版本之间。若存在应用使用，极大可能会受到影响。  

## **0x06 漏洞加固**

  
当前官方已发布最新版本, 建议受影响的用户可以参考如下官方修复方案，及时更新升级到最新版本。链接如下：https://kb.vmware.com/s/article/88099
