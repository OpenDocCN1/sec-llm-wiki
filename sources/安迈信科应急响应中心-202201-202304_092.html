0x01 漏洞信息


漏洞名称：Oracle Access Manager任意代码执行漏洞
漏洞编号：CVE-2021-35587
漏洞等级：高
披漏时间：2022年3月23日

0x02 漏洞描述


Oracle Access Manager存在任意代码执行漏洞。该漏洞是由于其使用了收影响的Weblogic组件，导致其内部存在的反序列化漏洞可被恶意利用并造成远程代码执行。

0x03 漏洞状态


脆弱组件覆盖面
利用门槛
POC工具
EXP工具
广
低
已公开
未公开

0x04 影响版本


Oracle Access Manager 11.1.2.3.0
Oracle Access Manager 12.2.1.3.0
Oracle Access Manager 12.2.1.4.0

0x05 漏洞排查


用户尽快排查使用的Oracle Access Manager应用版本是否为影响版本。若存在应用使用，极大可能会受到影响。

0x06 漏洞加固


Oracle官方已经针对该漏洞发布了安全补丁：https://www.oracle.com/security-alerts/cpujan2022.html
