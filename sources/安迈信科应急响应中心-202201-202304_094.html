0x01 漏洞信息


漏洞名称：Veeam多个远程代码执行漏洞
漏洞编号：CVE-2022-26500、CVE-2022-26501、CVE-2022-26503
漏洞等级：高
披漏时间：2022年1月11日

0x02 漏洞描述


Veeam Backup & Replication存在远程代码执行漏洞。该漏洞是由于Veeam 分发服务（默认端口为 TCP 9380）允许未经身份验证的用户访问内部 API 函数。远程攻击者可通过该方式向内部 API 发送恶意输入，并最终导致恶意代码的上传和执行。
Veeam Agent for Windows存在远程代码执行漏洞。该漏洞是由于Veeam Agent for Microsoft Windows （默认端口为 TCP 9395）中存在.NET反序列化漏洞。远程攻击者成功利用该漏洞后可远程代码执行漏洞。

0x05 漏洞排查


用户尽快排查所有应用系统Veeam Backup & Replication应用版本是否在漏洞影响范围之间。若存在应用使用，极大可能会受到影响。

0x06 漏洞加固
