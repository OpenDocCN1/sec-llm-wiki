## **0x01**** 漏洞信息**  

  
漏洞名称：Spring Cloud Gateway Actuator API SpEL表达式注入漏洞漏洞编号：CVE-2022-22947漏洞等级：高披漏时间：2022年3月3日  
  

## **0x02** 漏洞描述

  
Spring Cloud Gateway Actuator API 存在SpEL表达式注入漏洞。Spring Cloud Gateway Actuator API SpEL表达式注入漏洞该漏洞是由于Spring Cloud Gateway 的应用程序在启用、暴露和不安全的 Gateway Actuator 端点时容易受到代码注入攻击。攻击者可利用该漏洞在未授权，构造恶意数据进行远程代码执行攻击，最终获取服务器最高权限。

| --- | --- | --- | --- |

## **0x04 影响版本**

  
 Spring Cloud Gateway < 3.0.7、Spring Cloud Gateway < 3.1.1  

## **0x05 漏洞排查**  

  
用户尽快排查应用版本是否在Spring Cloud Gateway < 3.0.7、Spring Cloud Gateway < 3.1.1之间。若存在应用使用，极大可能会受到影响。  
  

## **0x06 漏洞加固**

  
当前官方已发布最新版本，建议受影响的用户及时更新升级到最新版本。链接如下：https://github.com/spring-cloud/spring-cloud-gateway/tags
