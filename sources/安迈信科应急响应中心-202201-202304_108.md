## **0x01**** 漏洞信息**  

  
漏洞名称：Oracle WebLogic远程代码执行漏洞漏洞编号：CVE-2022-21306漏洞等级：高披漏时间：2022年1月19日  
  

## **0x02** 漏洞描述

  
攻击者可以在未授权的情况下通过T3协议对存在漏洞的Oracle WebLogic Server组件进行攻击。成功利用该漏洞的攻击者可以接管Oracle WebLogic Server。  

## **0x03 漏洞状态**

  

| 脆弱组件覆盖面 || 利用门槛 || POC工具 || EXP工具 |
| --- | --- | --- | --- |
| 广 || 低 || 未公开 || 未公开 |

## **0x04 影响版本**

  

Oracle WebLogic Server 12.1.3.0.0

Oracle WebLogic Server 12.2.1.3.0

Oracle WebLogic Server 12.2.1.4.0

Oracle WebLogic Server 14.1.1.0.0

  

## **0x05 漏洞排查**  

  
用户尽快排查所有应用系统Oracle WebLogic Server 应用版本是否在12.1.3.0.0<= Oracle WebLogic Server  <=14.1.1.0.0之间。若存在应用使用，极大可能会受到影响。  

## **0x06 漏洞加固**

  
建议升级官方发布的最新补丁：https://www.oracle.com/security-alerts/cpujul2022.html
