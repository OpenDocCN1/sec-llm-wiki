## 工具简介

He3 则作为纯开发者工具箱，内置超过 200 种实用工具，免费持续更新更多品类。包含智能搜索、类型识别、自定义快捷键等特性，让你的开发效率直接起飞。

而对于搞安全的人来说，相信你肯定找过一个又一个单独的如下功能的小工具：

*   进制转换
    
*   编码解码
    
*   加密解密
    
*   时间戳转换
    
*   代码对比
    
*   文本提取
    
*   whois查询等
    
*   ......

## 工具使用

He3的使用教程在官网博客有，下面讲一些特色功能，便于大家开箱试用。

### 快速唤起搜索

He3 可以通过 Alt + Space (可设置) 一键唤起，通过使用搜索框快速找到工具，直接在右侧打开和关闭，所有操作在一个界面无需跳转：

![](../Images/9efdc90f3deaabde609a54ec184f9768.png)

### 剪切板内容智能识别

He3 一大亮点就是会智能识别剪切板的内容。比方说，当你先复制一段 JSON 代码到剪切板，然后打开 He3 就会自动推荐跟 JSON 相关的工具 (下图中红框部分)：

![](../Images/64a2f540eff737af4575256e6203774e.png)
