## WindTerm：9.8k stars

之前试用过FinalShell，有点比较多，但是就像很多人吐槽的那样，这货的问题也比较突出：标签页数量变多的时候FinalShell越来越卡，而且内存占用也比较高。

最近发现一款使用C语言开发的跨平台SSH客户端WindTerm，完全免费用于商业和非商业用途，没有限制。性能方面也比FinalShell和Electerm好很多。

![](../Images/9d88b8e891634eb391d2b20eec4ca55f.png "null")

img

### 主要功能和优点

*   • 支持黑暗模式
    
*   • 支持 SSH v2、Telnet、Raw Tcp、**串行**、Shell 协议。
    
*   • 会话认证时支持 SSH 自动执行。即**可以记住SSH密码或公钥**，方便登录。
    
*   • 支持 SSH ProxyCommand 或 ProxyJump。可以**设置跳板机登录。**
    
*   • 支持SSH代理转发。
    
*   • 支持使用密码、公钥、键盘交互、gssapi-with-mic 的 SSH 自动登录。
    
*   • 支持直接/本地端口转发、反向/远程端口转发和动态端口转发。
    
*   • **集成sftp、scp客户端**，支持下载、上传、删除、重命名、新建文件/目录等。
    
*   • 集成本地文件管理器，支持移动到、复制到、复制自、删除、重命名、新建文件/目录等。
    

### 安装WindTerm

WindTerm支持三大平台（Windows、Linux、macOS），前往Github：https://github.com/kingToolbox/WindTerm/releases下载最新版本。

没有很好的网络环境可以访问这里：https://hub.nuaa.cf/kingToolbox/WindTerm/releases/tag/2.5.0

### 设置与使用

#### 设置终端字体

WindTerm并没有将设置字体的功能做到窗口选项，不过我们可以通过修改主题文件来完成。默认使用的dige-black这个主题，打开：WindTerm目录下的global\\themes\\dige-black\\scheme.theme找到：

```

{
```

修改fontFamily属性即可。

#### 配置同步

如果您需要在多台电脑使用WindTerm，希望Session信息保持同步，可以用网盘直接同步WindTerm下的profiles文件夹即可。有点遗憾的是WindTerm不支持自定义profiles路径，希望后续能够支持吧。

#### 快捷命令

挺实用的一个功能，可以将常用且难记的命令添加到快捷命令中，方便下次快速使用。点击右下方齿轮按钮，根据提示添加即可。

![](../Images/bc9b3b0604c241d7e5e4ba086efc055e.png "null")

img

#### 设置跳板机

当你连接某台VPS网络不佳，还可以通过现有的任何机器作为跳板机登录，只需要编辑Session - SSH - Proxy - Jump Server 1进行选择即可。

## Tabby：39.2k stars

Tabby（原名 Terminus）是一个高度可配置的终端模拟器、SSH 和串行客户端，适用于 Windows、macOS 和 Linux。

默认界面，跟Windows Terminal类似（WT仅可在Windows下使用）。

![](../Images/a2846120c62a788201d95c44939cd51d.png "null")

img

### 主要功能和优点

*   • 集成的 SSH 客户端和连接管理器，**可以记住SSH密码或公钥**，方便登录
    
*   • 集成的串行终端
    
*   • **丰富的主题设计和色彩方案，内置很多配色**，不用自己寻找主题配置文件
    
*   • 支持 PowerShell（和 PS Core）、WSL、Git-Bash、Cygwin、Cmder 和 CMD
    
*   • **集成sftp、scp客户端，**通过 Zmodem 在 SSH 会话中直接传输文件
    
*   • 为 SSH secrets 和配置提供集成的加密容器
    
*   • 自定义 shell 配置文件

### 小结

Tabby功能完善，日常使用没有任何功能缺失，同时它还提供了配置同步的功能，当你有多台安全测试机器时，可以使用同步功能免去反复配置的麻烦。

个人最喜欢Tabby的简洁，功能丰富的同时保证了配置的简洁性，即便没有任何手册，也能很快上手使用。

唯一的缺点是，速度不算快。由于时Electron写的，性能方便并不算突出，但个人日常使用下来，除了启动较慢（3秒左右），Windterm基本秒启动。
