![](../Images/f212ff0e085a5dee6d1dbbf00e620761.png)满族屯满族乡，位于科右前旗西北部，是全国唯一以畜牧业为主的满族自治乡。这里最为出名的便是那充满神奇色彩和历史传说的科尔沁草原。但满族屯偏远的位置，致使曾经辉煌的草原未能赶上中国经济发展的时代班车。我们本次捐赠的满族屯学校是一所九年制边境乡村学校。建于1984年，目前有在校学生234名，教职工70 人。本次教育公益活动，由完美世界工会联合会与完美世界、爱奇艺、滴滴、小米、贝壳、VIPKID、微博、智联招聘 8 家企业的安全应急响应中心（SRC）联合发起。整个活动，在4月23日（世界读书日）开启直到5月31日结束，企业SRC与新老白帽们一起伸出圆梦之手！  
**❤️  爱心白帽，公益挖洞**国家越来越富强，社会越来越进步。我们熟练的在网络世界里驰骋，每天都享受着科技带给我们的便捷和快乐。但仍然有那么一群孩子，为了上学，他们要走最泥泞的路，翻过一个又一个山坡，每一个脚印都是为了完成“我的梦”。你愿意和我一起牵手，帮助那些在草原追梦的孩子吗？用白帽子的方式，来帮助他们完成梦想吧！一个“低危”能让一个孩子吃上香喷喷的米饭，一个“中危”能让一个孩子背上崭新的书包，一个“高危”能解决一个孩子一学期的生活费，一个“严重”能资助一个孩子顺利完成学业。在这个读书日，让我们帮助孩子有书可读，才是这个节日存在的重要意义。

**❤️  企业联合活动规则**  
白帽子自愿参加企业联合教育公益活动。活动期间向参与企业联合教育公益活动（PWSRC、MISRC、DSRC、71SRC、BKSRC、VKSRC、WSRC、ZPSRC）的任意一家提交漏洞报告即视为报名参与。  

*   活动期间，若白帽子向参与企业联合教育公益活动物资捐助的 SRC **提交有效中危漏洞报告达到三家**，白帽子将会收到所有提交中危有效漏洞 SRC 准备的精美礼品一份，同时获得由完美世界工会联合会发放的捐赠公益证书。
    
*   在活动期间，写下对学生们的祝福和鼓励，分享到微信、微博、Twitter、Facebook 等渠道邀请更多国内外白帽朋友参与！截图发送至任意一家参与教育公益活动的企业 SRC 微信后台，活动结束将随机抽取白帽子获得礼品一份。
    
*   建议：白帽子的 ID 在所有参与企业联合教育公益活动的 SRC 平台上保持一致，以便后续统计。
    

  

  
  
  
PWSRC 活动时间4月23日 - 5月31日

  

**❤️  PWSRC 活动规则 **

*   活动期间在 PWSRC 提交 **严重/高危 **的漏洞，一般业务享受额外奖励2000元，边缘业务享受额外奖励1000元的同时，PWSRC 追加同等价格物资捐赠给学校。
    
*   活动期间内提交 **有效漏洞 **的白帽子，白帽子奖金不变，PWSRC 追加漏洞同等金额物资以白帽子的名义捐赠给学校。
    
*   PWSRC 还将在公众号致谢所有白帽捐赠者。
    
*   本次活动范围：完美世界教育官网、洪恩教育、完美万词王、洪恩识字、洪恩双语绘本、洪恩儿童英语、洪恩故事、洪恩数学、洪恩学堂教师端、洪恩拼音拼读、洪恩学堂、像素种子等教育平台网站和最新版 APP。
    
*   漏洞报告标题前请添加【企业联合公益活动】字眼。
