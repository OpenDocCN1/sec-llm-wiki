# 邮箱密码忘了怎么办

前两天发生的事情，一个同事妹子说记不起自己注册过的邮箱密码，而且还没来得及绑定手机，急得不要不要的

![](../Images/39df764f677cf355b0ed67a092dbadc1.png)

  

妹子说了，只要能找回密码，什么愿望都能满足我

![](../Images/ccde2a73422b09211a29c2d435dfaf0e.png)

  
作为一个热心肠的工程师，关键时刻一定要帮妹子解决难题；于是各种社工、字典，结果忙乎了半天，失败了...

就在快要放弃的时候，妹子说自己平时也用客户端收邮件，账号也存在FOXMAIL里

![](../Images/8cd40dbf53f94d525eb297083fdfe812.png)

  

  

踏破铁鞋无觅处 得来全不费工夫；这下就简单了，直接在妹子电脑上装上网络分析神器WIRESHARK，点收邮件，抓通讯包，过滤POP3协议，轻松拿到密码"test123@&#test"

![](../Images/58a169b7c6d5d8ad06816a80990c3a68.png)

* * *

  

帮妹子处理完问题后，想到有的邮件服务器是强制SSL加密，只开995端口的，通讯包都是加密的，那该怎么办呢？

![](../Images/79847464fc4ae4f3a1d999bd242a91ea.png)

![](../Images/1d638d3994acc1f54cca4ea60be5ef86.png)

于是乎想到，在客户端上不勾选SSL，走普通的110端口，然后自己本地起个假的邮件服务器

![](../Images/7570a27430e902403ca9ff3233278af6.png)

  

这次再点下收邮件，搞定... 假的邮件服务器把密码打出来了

![](../Images/b8a8c4e7adf5d11da5b3213ec901fa1f.png)

  

假的邮件服务器就几十行py代码而已

\# coding:utf-8

import socket

server = socket.socket(socket.AF\_INET, socket.SOCK\_STREAM)

server.bind(('127.0.0.1', 110))

server.listen(1)

while True:

    s, addr = server.accept()

  

    data = '+OK Welcome to coremail Mail Pop3 Server\\r\\n'

    s.send(data)

    print '\*put\* %s' % data

    

    data = s.recv(1024)

    print '\*get\* %s' % data

    

    data = '+OK core mail\\r\\n'

    s.send(data)

    print '\*put\* %s' % data

    

    data = s.recv(1024)

    print '\*get\* %s' % data

    

    data = '-ERR authentication failed\\r\\n'

    s.send(data)

    print '\*put\* %s' % data

  

又学会一招，就这么easy，以后这样帮妹子找邮箱密码，然后就等着妹子投来崇拜的目光吧
