### 1.1 图形化抓包

图形化相对来说比较简单，分为两种情况：

*   
*   

```
1、若手机和电脑登录了同一个AppleID账号，处在同一网络下，可实现网络获取日志。2、若手机和电脑未登录同一个AppleID账号，则需要数据线进行连接，手机和电脑互相信任后，获取日志。
```

连接后，打开电脑上的`控制台app`。  

![](../Images/b41aa46db9ee9b8c9cd130f3e689181e.png)

可在左边边栏的设备处见到手机和电脑的相关标志。  

![](../Images/4e6e7f3fc4f8fca2ec53fbb162e6ebb1.png)

右边则是日志，若需要查询相关的信息，在右上角搜索处直接进行关键词搜索就行了。

但是有个问题就是，`控制台app`显示的都是流化的日志，关闭后就丢失了，无法对抓到的日志进行单独的保存，若需要保存的话，就要使用命令行进行抓包。

### 1.2 命令行抓包

命令行抓包的相对来说麻烦一点，`mac`自带了一个命令叫做`log`命令，需要使用`log`命令进行日志的抓取、保存、查询、展示等功能。

![](../Images/f11f288d20fd5613dc79cf0e555781ad.png)

若要抓取`mac`的日志，直接使用命令`log collect`即可。

若要抓取其他设备的日志，则需要再添加另外的参数。

![](../Images/353004d4d3296e6b2e3ac15249a4b982.png)

在知道`iphone`的`name`情况下可以使用`--device-name`进行指定设备，若不知道`name`或者`udid`，则可以使用第三方工具`libimobiledevice`进行获取。`macos`系统使用`brew install libimobiledevice`命令进行安装，安装完后多了很多`idevice`开头的命令行工具。

![](../Images/74b022139b0d41c23fa2946a9994952a.png)

其中，`idevicename`和`idevice_id`这两条命令是分别获取`name`和`udid`数据的。  

![](../Images/4a4891b929be979cf314c1d12f412ac6.png)

获取到这两部分数据之后，就可以对设备进行指定，然后获取并保存日志了。

![](../Images/92d2cac40ee3910045c6b7a60c2a02b4.png)

## 0x02 日志分析

### 2.1 加载日志

前面我们使用命令行获取了日志，接下来我们进行分析，使用`log show`命令，此时我们会发现是无法显示日志的，用控制台还是命令行都无法进行加载，报错原因是版本问题。

![](../Images/d14d8308b9626e0588e117fcbb854852.png)

我们【右键=>显示包内容】，查看配置文件`info.plist`，在其中可以发现`OSArchiveVersion`的版本号为`5`

![](../Images/e785b676ace75fa5ba362e618cbff639.png)

根据系统对应关系，`10.15`系统的`OSArchiveVersion`是`4`，无法读取`OSArchiveVersion`为`5`的日志包。

![](../Images/81f216356fd2f934eacd20a0caebe503.png)

所以既然无法读取`5`版本的包，就直接走捷径，强行修改`info.plist`文件里的版本号，修改为`4`，当前系统就可以读取了。

![](../Images/98d1fd40755501ceaabfff9d9504ff5a.png)

修改完后就可以使用命令行和`控制台app`进行读取了。

![](../Images/e5e235e87b1c295fc8cd92b023a8cf41.png)

![](../Images/94a76830e189c49b3b43497ae7feb60a.png)

** 注意 ：** 这里是我想当然了，本以为直接修改版本号即可在本系统上打开存储的日志数据包，但是通过这种方式读取的日志，存在部分数据无法解析的情况，只能以`<compose failure [shared UUID]`的形式展示，无法显示详细的数据。后来找了一台`mac`系统版本在`12.1`的电脑，才成功读取了`OSArchiveVersion`为`5`的数据包。

## 0x03 总结

以前从未接触过`ios`手机日志取证，本次学习过后发现手机日志中包含的信息很多，我们的每一步操作、每一次点击都会留下痕迹。通过分析发现，`ios`日志中只能记录传输的图片名称，无法记录传输的图片的具体内容，传输的具体内容是通过`awdl`的，应该可以通过网络抓包获取，暂时还不知道如何从手机端抓取流量，等后面学会了再抓抓看吧。
