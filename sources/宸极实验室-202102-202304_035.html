0x01 图像处理

1.1 特征向量

如果图像的大小是64 * 64个像素（一个像素就是一个颜色点，一个颜色点由红绿蓝三个值来表示，例如，红绿蓝为255,255,255，那么这个颜色点就是白色）。所以3个64 * 64大小的矩阵在计算机中就代表了这张图像。矩阵里面的数值就对应于图像的红绿蓝强度值。将这三个矩阵转化为一个向量，这个向量就是特征向量。

1.2 欧式距离

一个发光的灯泡，从某一点到灯泡的距离，这个距离就是欧几里得距离，也叫欧式距离。专业点讲，n维空间中的两个点之间的真实距离，就是欧几里得距离。

在图像处理中，判断两张图片是否匹配经常要计算两张图片的欧式距离，越大越不匹配。

计算脚本（黑白比较法）：

import numpy as npfrom PIL import Imagefrom scipy.spatial.distance import pdist

def euclidean(image1, image2):    '''欧氏距离'''    X = np.vstack([image1, image2])    return pdist(X, 'euclidean')[0]

1.3 噪声

在AI类题目中经常可以看到噪声，噪声是什么呢？噪声就是杂乱的声音。

噪声在机器学习中指的是搞错的数据，分为输入错误和输出错误两种。

它的存在会使我们的目标存在一定的波动性。可以理解为误差。

有的题目中要求制造与原图片不同的图片时，可以利用噪声控制误差范围，实现欺骗AI的效果。

2.2 最短路径

最短路径问题是经常出现的一种数据处理的问题，一般样本量不会很大的情况下，一般用两种算法即进行数据的处理。Dijikstra算法用于计算某一个点到其它点的距离，而Floyd算法用于一次性计算出所有点之间的相互距离。

#Dijikstra算法def dijkstra(matrix, start_node):    matrix_length = len(matrix)     used_node = [False] * matrix_length    distance = [MAX] * matrix_length     distance[start_node] = 0      while used_node.count(False):        min_value = MAX        min_value_index = -1        for index in range(matrix_length):            if not used_node[index] and distance[index] < min_value:                min_value = distance[index]                min_value_index = index        used_node[min_value_index] = True          for index in range(matrix_length):            distance[index] = min(distance[index], distance[min_value_index] + matrix[min_value_index][index])    return distance
