介绍：钓鱼平台 - Gophish的使用。

0x01 服务搭建

1.1 项目地址

https://github.com/gophish/gophish

下载对应的版本到服务器，这里使用的是gophish-v0.11.0-linux-64bit版本。

1.2 修改配置文件并运行

使用unzip gophish-v0.11.0-linux-64bit.zip命令解压缩。

修改配置文件。

vim config.json

修改后台管理地址为0.0.0.0，可以方便进行外部访问，

管理地址端口自定为3333，

钓鱼服务页面端自定为3443，

最后确认iptables和腾讯云防火墙已放行相应端口。

//配置文件{        "admin_server": {                "listen_url": "0.0.0.0:3333",    //管理地址可远程访问                "use_tls": true,                "cert_path": "gophish_admin.crt",                "key_path": "gophish_admin.key"        },        "phish_server": {                "listen_url": "0.0.0.0:3443",    //钓鱼页面服务地址（本地访问可为127.0.0.1）                "use_tls": false,                //改为ture                "cert_path": "example.crt",                "key_path": "example.key"        },        "db_name": "sqlite3",        "db_path": "gophish.db",        "migrations_prefix": "db/db_",        "contact_address": "",        "logging": {                "filename": "",                "level": ""        }}

完成配置后运行gophish服务：

chmod +x gophish   //加执行权限./gophish

新版的11.0会自动生成一个随机密码，11.0以下版本则是默认密码gophish。

使用随机密码登录后会要求修改admin密码。

1.3 配置钓鱼服务

登录系统后开始配置钓鱼服务。

点击添加策略文件：

Passsword为授权码，如果为163邮箱则在【设置】-【POP3/SMTP/IMAP】中设置。

添加完成后可以发送一封邮件测试是否成功。

查看邮箱中由gophish发送的测试邮件。

1.4 添加钓鱼界面-Landing Pages

首先在浏览器中添加我们需要用到的插件SingleFile。

添加完成后我们找到需要用到的界面，比如腾讯文档。

点击右上角插件下载功能，会将该页面前端源代码下载保存至一个HTML文件中。

点击钓鱼页面-Landing Pages，将保存下来的代码导入进去。

导入完成后开启抓取密码并保存，并将完成抓取后将页面重定向到真实界面中。

1.5 编辑钓鱼模板-Email Templates

配置邮件模板，设置邮件主题，邮件内容等。

邮件内容的钓鱼地址要写成如下格式：

{.URL}}

1.6 编辑收件用户-Users&Groups

可以批量导入收件地址和手动添加地址。

0x02 mip22搭建

mip22最大的好处是在方便快捷。

并且符合gophish获取数据的格式。

使用SingleFile插件保存的代码有时需要修改。

下载配置mip22。

项目地址https://github.com/makdosx/mip22chmod -R 777 mip22 cd mip22bash mip22.sh

完成配置后选择第一项：

在六十多个随意挑选一个需要的模板并填写数字。

继续选择本地还是外网访问，看需要进行选择。

选择完成后会生成一个随机链接。

复制链接后在钓鱼模板中下载。

0x03 创建钓鱼事件-Campaigns

点击Campaigns开始配置钓鱼事件。

发送钓⻥邮件，查看效果。

点击链接后输入账户密码后，点击登录，页面会跳转至真实界面的账户密码错误来伪造失败。

后台则会收到输入的账户和密码，至此钓鱼结束。

0x04 总结

使用自己配置的邮件服务器进行发送迷惑性会更高成功率也会提高。

页面钓鱼看实际场景需求来使用不同的模板或截取页面。


预防小贴士

1、注意发件人地址；

2、切勿点击附件中.exe.bat等可执行文件；.doc.pdf.xlsx.pptx、.zip等文件中也有可能植入木马；

3、请勿轻易点击链接或退订按钮等。
