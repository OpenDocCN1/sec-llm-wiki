## 0x01 服务搭建

### 1.1 项目地址

`https://github.com/gophish/gophish`

下载对应的版本到服务器，这里使用的是`gophish-v0.11.0-linux-64bit`版本。

### 1.2 修改配置文件并运行

使用`unzip gophish-v0.11.0-linux-64bit.zip`命令解压缩。

![](../Images/92f09ce23d79ed8f7b00d21eb622d826.png)

修改配置文件。

`vim config.json`

修改后台管理地址为`0.0.0.0`，可以方便进行外部访问，

管理地址端口自定为`3333`，

钓鱼服务页面端自定为`3443`，

最后确认`iptables`和腾讯云防火墙已放行相应端口。

```
//配置文件{        "admin_server": {                "listen_url": "0.0.0.0:3333",    //管理地址可远程访问                "use_tls": true,                "cert_path": "gophish_admin.crt",                "key_path": "gophish_admin.key"        },        "phish_server": {                "listen_url": "0.0.0.0:3443",    //钓鱼页面服务地址（本地访问可为127.0.0.1）                "use_tls": false,                //改为ture                "cert_path": "example.crt",                "key_path": "example.key"        },        "db_name": "sqlite3",        "db_path": "gophish.db",        "migrations_prefix": "db/db_",        "contact_address": "",        "logging": {                "filename": "",                "level": ""        }}
```

完成配置后运行`gophish`服务：

*   
*   

```
chmod +x gophish   //加执行权限./gophish
```

新版的`11.0`会自动生成一个随机密码，`11.0`以下版本则是默认密码`gophish`。

使用随机密码登录后会要求修改`admin`密码。

### 1.4 添加钓鱼界面-Landing Pages

首先在浏览器中添加我们需要用到的插件`SingleFile`。

![](../Images/db954cb289b51effe6e79cba37598619.png)

添加完成后我们找到需要用到的界面，比如腾讯文档。

点击右上角插件下载功能，会将该页面前端源代码下载保存至一个`HTML`文件中。

![](../Images/b68b9df2d5ee443d73becb7d3fbaf765.png)

点击钓鱼页面-`Landing Pages`，将保存下来的代码导入进去。

![](../Images/e59f7a117eb6bbbc7cd3cc1679a7e392.png)

![](../Images/f325674d3147a6989a90a9a6f934fb0d.png)

导入完成后开启抓取密码并保存，并将完成抓取后将页面重定向到真实界面中。

![](../Images/011a1a9566da47831aede1f2def79065.png)

## 0x02 mip22搭建

`mip22`最大的好处是在方便快捷。

并且符合`gophish`获取数据的格式。

使用`SingleFile`插件保存的代码有时需要修改。

下载配置`mip22`。

*   
*   
*   
*   

```
项目地址https://github.com/makdosx/mip22chmod -R 777 mip22 cd mip22bash mip22.sh
```

完成配置后选择第一项：

![](../Images/59b1290cec0f8f06ecffd46fd37e1ae0.png)

在六十多个随意挑选一个需要的模板并填写数字。

![](../Images/8c0b61d4e9cae2bdf759b51d9c9959a4.png)

继续选择本地还是外网访问，看需要进行选择。

选择完成后会生成一个随机链接。

![](../Images/208ae13bc486bc6adabfe5de4a5bfa4f.png)

复制链接后在钓鱼模板中下载。

![](../Images/404fc60d951a9386d9934074f8e6397a.png)

## 0x03 创建钓鱼事件-Campaigns

点击`Campaigns`开始配置钓鱼事件。

![](../Images/6f75383df3a9d877a0659494d902f994.png)

## 0x04 总结

使用自己配置的邮件服务器进行发送迷惑性会更高成功率也会提高。
