## 0x00 前言

前提条件: 拿到目标服务器`administrator`权限。 

环境：`windows Server2012/windows 10`

## 0x01 维持方式

### 1.1 命令行添加隐藏用户

运行`cmd`，添加一个名为`test1`用户并把它添加进管理员组中，用户名称后添加`$`可以达到隐藏的效果。

*   
*   

```
net user test1$ 123456 /addnet localgroup administrators test1$ /add
```

![](../Images/adb4d6bcbcfbc7869b7c91aac7291b57.png)

在命令行中无法查看到`test1$`用户，但在控制面板中仍会查询到该用户。

我们需要做进一步的隐藏。

![](../Images/032a6c009a4bede6744f39acaac71ef5.png)

![](../Images/57f0a2ea9374057b8980bb77af25ca83.png)

注意我们要在控制面板中给新建的`test1$`添加一个远程桌面连接权限。

![](../Images/b4912d583661fb08422587a65cb9b1a8.png)

### 1.2 注册表隐藏用户

输入命令：`regedt32` 打开注册表。

![](../Images/60ff6ff2d75b7d3f05a6db036df4e7af.png)

定位到`HKEY_LOCAL_MACHINE\SAM\SAM`中，添加一个管理员控制权限。

![](../Images/ebeffef6c2ada2179a31843436e8e4dd.png)

重启一下注册表编辑器，访问`HKEY_LOCAL_MACHINE\SAM\SAM\Domains\Account\Users\Names`。

![](../Images/f247d7bfdca9e5e649c52011a0eb0b72.png)

找到`Administrator`对应的键值，将`F`值复制到`test1$`对应目录中的`F`值。

![](../Images/b9a09800f34c9069c9d4552814d22fbe.png)

复制完成后，把`test1$`和其对应的`000003EB`目录先导出。

![](../Images/89d31598f7b51e74443c93cda403624e.png)

输入`net user test1$ /del`命令将其删除。

![](../Images/e7304f210cf109a9ee6238ba397bb2ae.png)

最后双击保存的目录，会自动导入到注册表中。

![](../Images/83383740002850d6d42c60ad14066cb2.png)

查看命令行、控制面板、计算机管理都无法找到`test1$`了。

![](../Images/9282f8c2df1e58b2d26719fc64bc1644.png)

使用`test1$`账号连接，`echo %username%`查看会显示为管理员用户。

![](../Images/39c9919c626e46a5586462e32a4eb698.png)

![](../Images/a45a1c9dda0603f475aa7cb2ea02a657.png)

把注册表刚才赋予`administrator`的权限关掉，这样这个账户就很难被发现了。

![](../Images/8e3caf4b2a8c54360f4763f98ea1eb60.png)

  

### 1.3 多用户登录

在注册表隐藏用户后，管理员在登录时会被下线，所以可以设置多用户登录。

输入`gpedit.msc`组策略，找到【计算机设置】–【管理模板】–【`windows`组件】–【远程桌面服务】–【远程桌面会话主机】–【连接】。

*   
*   
*   

```
拒绝将已经登录到控制台会话的管理员注销—已启用限制连接的数量-已启用（1-999999）将远程桌面服务用户限制到单独的远程桌面服务会话—已禁用
```

![](../Images/04733c9c428a33f64fc7f70422188601.png)

`cmd`输入`gpupdate /force`更新组策略。

![](../Images/67ae6c0d87672b25d37f025c051d305f.png)

远程登录后的结果如下：

![](../Images/448eb54256fb61acbf5d0b66e135f449.png)

### 1.4 镜像劫持

利用`Windows`的`IFEO`（`Image File Execution Options`）功能来实现。当你执行某一程序`A`的时候，运行的却是另外一个程序`B`。我们通过修改注册表来实现此功能，使用`regedt32`打开注册表。找到`HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options`。

新建一个名为`sethc.exe`的项。

![](../Images/20028e777fe5729976b7ff186b3e7466.png)

添加一个`debugger`的新建，为其加入`cmd`的路径`C:\Windows\System32\cmd.exe`。

![](../Images/5795e393a84640986a24c719a856e59a.png)

在登录界面连续点击五次`shift`出现命令行。

![](../Images/3890fe389fb4d51289e7720d28f0a292.png)

### 1.7 服务启动后门

利用`msfconsole`生成的木马，创建名为`test`的自启动服务。

*   
*   
*   
*   

```

```

![](../Images/c3271dceced531478755eccf5965df1f.png)
