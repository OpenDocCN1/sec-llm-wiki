1、 前言

由于谷歌旗下的 Pixel 系列手机因其开放性以及对自家安卓系统的兼容非常好，所以很多移动安全人员都喜欢用该系列的手机作为测试机，进行日常应用测试及脱壳分析等工作，本文为刚接触移动安全的朋友提供一份靠谱的基础环境构建指南。

2.1 安装 SDK Platform Tools

正式开始之前（如果系统中 adb、fastboot命令正常可用，可跳过此步骤），需要先下载一个 Android SDK Platform Tools 组件，常见的 adb 命令就包含在其中，使用这些工具可以很方便的对设备进行操作，当然也是刷机必备组件，这里就引用下官方的介绍。

Android SDK Platform Tools 是 Android SDK 的一个组件。

它包含与 Android 平台进行交互的工具，例如 adb、fastboot 和 systrace。

开发 Android 应用时需要使用这些工具。如果您想要解锁设备的引导加载程序并为其刷入新的系统映像，同样需要使用这些工具。

Android SDK Platform Tools 官方下载地址：
 https://developer.android.com/studio/releases/platform-tools

Mac 用户可直接通过brew进行安装。 brew install android-platform-tools

Windows 用户下载压缩包后，将其解压到自己的工具文件夹中，本文路径为D:\Android-platform-tools

然后将路径加至系统环境变量 PATH 中。

之后新开一个命令行窗口，输入adb命令测试是否正常。

如果输出与上图类似，说明环境变量配置的没有问题。Windows 用户如果连接手机后提示缺少驱动的话可以从以下地址下载安装。
获取 Google USB 驱动程序https://developer.android.com/studio/run/win-usb
安装原始设备制造商 (OEM) USB 驱动程序https://developer.android.com/studio/run/oem-usb

2.3 刷入 Android 官方镜像

刷机需要先进入fastboot模式，方法是在关机状态下按住音量键同时开机即可，由于第一部分安装的工具包已经可以使用，个人更喜欢的方法是直接用其中的adb命令让手机重启自动进入刷机模式，这个比关机再按音量键开机的方法省事，当然，如果手机目前处于关机状态，还是按键方式更方便一些。

在设置 > 系统 > 开发者选项中打开 USB调试，如果没有开发者选项这个菜单，需要先去设置 > 关于手机，连续点击版本号便可激活开发者选项。

在设置 > 系统 > 开发者选项中打开 USB调试。

命令行中将手机重启至刷机模式：
# 将手机重启至 fastboot 模式adb reboot fastboot
# 稍等片刻，等待手机屏幕出现画面再操作# 验证手机是否处在 fastboot 模式、手机与电脑的连接是否正常fastboot devices
# 如果能列出手机，说明一切正常，可以进行刷机，类似这样F78901A123456    fastboot

将命令行切换到上一步解压好的镜像目录中，运行flash-all.bat开始刷机。

此时需要耐心等待刷机完成，完成后命令行输出如下。

刷机结束后手机会自动重启进入系统，按照向导完成手机的初始设置，设置完成后打开开发者选项，重新激活ADB 调试。

2.4 获取 Root 权限

SuperSU的时代过去了，新版本系统出现了更好的替代品Magisk，这里通过刷入Magisk来获取Root 权限。

Magisk下载地址：
 https://github.com/topjohnwu/Magisk

下载得到 Magisk-v23.0.apk，将应用安装到手机，adb install Magisk-v23.0.apk，稍等片刻。

安装完成后，将系统镜像包中的image-walleye-rp1a.201005.004.a1.zip解压缩，并且在命令行中进入到该目录，执行adb push boot.img /sdcard/Download/。

手机中启动安装好的 Magisk应用，并点击安装按钮。

选择选择并修补一个文件。

选择下载目录中的boot.img，然后点击开始按钮。

等待程序修补完成。

此时记下输出的文件名，使用命令将其复制到电脑中。 adb pull /sdcard/Download/magisk_patched-23000_04Pgm.img ./
将修补后的镜像刷入手机中。

2.5 解决 WLAN 网络受限问题

连接 WIFI 后会发现，系统会提示网络连接受限通知，同时快捷栏中的图标下面也会有相应的文字。


不必担心此问题是正常现象，这是 Android 的网络评估机制，当连上网络后，会给目标服务器发送给一个请求，如果服务器返回的状态码是 204，那么系统就认为网络可以正常连通，否则系统认为网络不可联通，被判定为受限网络环境，可能需要二次认证等操作，如果服务器没有响应的话，系统就认为网络不可访问。
由于内置的服务器地址国内环境无法访问，所以才会出现此问题，针对此问题，国内出现了很多公益性质的 204 服务器，用于解除这个问题。
通过命令解决该问题：
# Android 7.1.2 ~adb shell settings put global captive_portal_mode 0
# Android 5.0 ~ 7.1.1adb shell settings put global captive_portal_detection_enabled 0adb shell settings put global captive_portal_server https://connect.rom.miui.com/generate_204
# 上面是用的小米提供的 204 服务器，还有其他备选。# https://www.v2ex.com/generate_204# https://204.ustclug.org# https://wifi.vivo.com.cn/generate_204# https://connectivitycheck.platform.hicloud.com/generate_204# https://cp.cloudflare.com/generate_204# https://g.cn/generate_204

此时需要断开网络重新连接一下，网络受限提示就不再出现了。

当然也有更简单的方式，安装CaptiveMgr这个应用，GUI 形式进行配置更加方便。

2.6 优化 WIFI ADB 调试体验

USB调试 功能很好用，但是要连数据线，开发者选项自带的无线调试解决了这一问题，但是每次都需要点好几个菜单进去开启，优化下这一步骤，让环境更加顺手，先上效果图。

WADB下载地址： 

https://github.com/RikkaApps/WADB

通过命令进行安装。 adb install wadb-v5.1.1.r161.b5b65a7-release.apk
安装完成后，需要点击快捷栏左下角图标进入编辑模式，将无线调试开关按钮位置拖放到自己需要的位置。

之后点击快捷栏的无线开关图标，首次点击需要给予授权，允许即可。
