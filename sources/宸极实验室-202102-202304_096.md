## 1、 前言

由于谷歌旗下的 `Pixel` 系列手机因其开放性以及对自家安卓系统的兼容非常好，所以很多移动安全人员都喜欢用该系列的手机作为测试机，进行日常应用测试及脱壳分析等工作，本文为刚接触移动安全的朋友提供一份靠谱的基础环境构建指南。

## 2、 正文

相关信息：

•手机型号：`Google Pixel 2` 无锁版•官方镜像版本：11.0.0 (RP1A.201005.004.A1, Dec 2020)•`Magisk`：v23.0注：本文涉及到的文件均已打包，开箱即用，获取方式见文末。

### 2.1 安装 SDK Platform Tools

正式开始之前（如果系统中 `adb`、`fastboot`命令正常可用，可跳过此步骤），需要先下载一个 `Android SDK Platform Tools` 组件，常见的 `adb` 命令就包含在其中，使用这些工具可以很方便的对设备进行操作，当然也是刷机必备组件，这里就引用下官方的介绍。

> `Android SDK Platform Tools` 是 `Android SDK` 的一个组件。
> 
> 它包含与 Android 平台进行交互的工具，例如 `adb`、`fastboot` 和 `systrace`。
> 
> 开发 Android 应用时需要使用这些工具。如果您想要解锁设备的引导加载程序并为其刷入新的系统映像，同样需要使用这些工具。

`Android SDK Platform Tools` 官方下载地址： https://developer.android.com/studio/releases/platform-tools

![](../Images/0debe70c3337321f4708973c2c991c70.png)

`Mac` 用户可直接通过`brew`进行安装。 `brew install android-platform-tools`

`Windows` 用户下载压缩包后，将其解压到自己的工具文件夹中，本文路径为`D:\Android-platform-tools`

![](../Images/1c8c4b984b20dc8e3fb1225f45f945fa.png)

然后将路径加至系统环境变量 `PATH` 中。

![](../Images/71e92cc7b8bc83492a9d3dc1a298afb5.png)

之后新开一个命令行窗口，输入`adb`命令测试是否正常。

![](../Images/9c4641017a423fad019b003680520643.png)

如果输出与上图类似，说明环境变量配置的没有问题。`Windows` 用户如果连接手机后提示缺少驱动的话可以从以下地址下载安装。

*   
*   
*   
*   
*   

```
获取 Google USB 驱动程序https://developer.android.com/studio/run/win-usb
安装原始设备制造商 (OEM) USB 驱动程序https://developer.android.com/studio/run/oem-usb
```

### 2.2 获取 Android 官方镜像

`Google` 官方的 `Factory Image` 下载页面：https://developers.google.com/android/images

需要注意一点，该页面打开后需要点击 `Acknowledge` 按钮后才可以看到下载地址。

![](../Images/9ae491cef6c4ef0502d4d0d8514f4ab4.png)

点击 `Acknowledge` 按钮后，页面右侧会出现导航条，通过点击对应的手机型号，可快速跳转到相应位置。

### 2.3 刷入 Android 官方镜像

刷机需要先进入`fastboot`模式，方法是在关机状态下按住音量键同时开机即可，由于第一部分安装的工具包已经可以使用，个人更喜欢的方法是直接用其中的`adb`命令让手机重启自动进入刷机模式，这个比关机再按音量键开机的方法省事，当然，如果手机目前处于关机状态，还是按键方式更方便一些。

在`设置` > `系统` > `开发者选项`中打开 `USB调试`，如果没有`开发者选项`这个菜单，需要先去`设置` > `关于手机`，连续点击`版本号`便可激活`开发者选项`。

![](../Images/9cd484bc21e935289351b831c10235df.png)

在`设置` > `系统` > `开发者选项`中打开 `USB调试`。

![](../Images/8c214607171c0d62ade104f41fc2c2f5.png)

命令行中将手机重启至刷机模式：

*   
*   
*   
*   
*   
*   
*   
*   
*   

```
# 将手机重启至 fastboot 模式adb reboot fastboot
# 稍等片刻，等待手机屏幕出现画面再操作# 验证手机是否处在 fastboot 模式、手机与电脑的连接是否正常fastboot devices
# 如果能列出手机，说明一切正常，可以进行刷机，类似这样F78901A123456    fastboot
```

将命令行切换到上一步解压好的镜像目录中，运行`flash-all.bat`开始刷机。

![](../Images/5b276d627e0ef5e1afdc98b01b6f5d6e.png)

此时需要耐心等待刷机完成，完成后命令行输出如下。  

![](../Images/64d80afac8cdfb2b3bf778d00c9c64cb.png)

刷机结束后手机会自动重启进入系统，按照向导完成手机的初始设置，设置完成后打开开发者选项，重新激活`ADB 调试`。

### 2.4 获取 Root 权限

`SuperSU`的时代过去了，新版本系统出现了更好的替代品`Magisk`，这里通过刷入`Magisk`来获取`Root` 权限。

`Magisk`下载地址： https://github.com/topjohnwu/Magisk

下载得到 `Magisk-v23.0.apk`，将应用安装到手机，`adb install Magisk-v23.0.apk`，稍等片刻。

安装完成后，将系统镜像包中的`image-walleye-rp1a.201005.004.a1.zip`解压缩，并且在命令行中进入到该目录，执行`adb push boot.img /sdcard/Download/`。

手机中启动安装好的 `Magisk`应用，并点击`安装`按钮。

![](../Images/5721d8e4dd96ba90a825ca420db2dda8.png)

选择`选择并修补一个文件`。

![](../Images/53f3aa5bb148fc0ec072cdebdf0c702f.png)

选择下载目录中的`boot.img`，然后点击`开始`按钮。

![](../Images/ef76f57b5b2a40fbf895835e98d9d155.png)

等待程序修补完成。

![](../Images/7dc1a908012fd5975516c598bbfb1c63.png)

此时记下输出的文件名，使用命令将其复制到电脑中。 `adb pull /sdcard/Download/magisk_patched-23000_04Pgm.img ./`将修补后的镜像刷入手机中。

*

*   
*   
*   
*   
*   
*

*

```

# 刷入# 因为我这里确认可以正常启动系统，所以直接刷了# 第一次测试可以使用如下命令临时引导，进入系统点击安装，选择直接安装方式即可转为永久# > fastboot boot magisk_patched-23000_04Pgm.img
```

手机启动完成后，查看状态。

![](../Images/8315e8d75c2546ce18df1feb1bde2145.png)

### 2.5 解决 WLAN 网络受限问题

连接 `WIFI` 后会发现，系统会提示网络连接受限通知，同时快捷栏中的图标下面也会有相应的文字。

![](../Images/aa3947c97203648f21e3e40a61483ad9.png)

  
不必担心此问题是正常现象，这是 `Android` 的网络评估机制，当连上网络后，会给目标服务器发送给一个请求，如果服务器返回的状态码是 `204`，那么系统就认为网络可以正常连通，否则系统认为网络不可联通，被判定为受限网络环境，可能需要二次认证等操作，如果服务器没有响应的话，系统就认为网络不可访问。由于内置的服务器地址国内环境无法访问，所以才会出现此问题，针对此问题，国内出现了很多公益性质的 `204` 服务器，用于解除这个问题。通过命令解决该问题：

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
# Android 7.1.2 ~adb shell settings put global captive_portal_mode 0
# Android 5.0 ~ 7.1.1adb shell settings put global captive_portal_detection_enabled 0adb shell settings put global captive_portal_server https://connect.rom.miui.com/generate_204
# 上面是用的小米提供的 204 服务器，还有其他备选。# https://www.v2ex.com/generate_204# https://204.ustclug.org# https://wifi.vivo.com.cn/generate_204# https://connectivitycheck.platform.hicloud.com/generate_204# https://cp.cloudflare.com/generate_204# https://g.cn/generate_204
```

此时需要断开网络重新连接一下，网络受限提示就不再出现了。

![](../Images/2e9ee58dc36930cf8819ae5e31229ca8.png)

当然也有更简单的方式，安装`CaptiveMgr`这个应用，`GUI` 形式进行配置更加方便。  

### 2.6 优化 WIFI ADB 调试体验

`USB调试` 功能很好用，但是要连数据线，开发者选项自带的`无线调试`解决了这一问题，但是每次都需要点好几个菜单进去开启，优化下这一步骤，让环境更加顺手，先上效果图。

![](../Images/f82376f700a99706ed92d85e890a4471.png)

`WADB`下载地址： 

https://github.com/RikkaApps/WADB

通过命令进行安装。 `adb install wadb-v5.1.1.r161.b5b65a7-release.apk`安装完成后，需要点击快捷栏左下角图标进入编辑模式，将无线调试开关按钮位置拖放到自己需要的位置。

![](../Images/b34f4179ed7e6a96547dc1106f28969a.png)

之后点击快捷栏的无线开关图标，首次点击需要给予授权，允许即可。

![](../Images/411aff13a83abf4eed218cf3a064d2d8.png)
