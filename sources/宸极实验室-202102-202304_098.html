介绍: z3 一款微软出品的开源约束求解器。

0x00 前言

现阶段的 Reverse 类型题目花样是越玩越多，回想自己 2015 年左右做的题目，很多题目都可以使用 strings 命令直接搜到 flag 。再到后来的通过 XXX Pro 反编译就可以找到 flag 再到后来出现各种算法，BASE64、TEA、XTEA、XXTEA、AES 。

题目是越出越难，思路是越出越开阔，考查点是越来越复杂，也慢慢的带动了自动化求解工具的发展。本篇文章讲述的 z3 已经被 python 集成，用来求解复杂的方程，同样也可以用来做题目。本文旨在讲述一些基础的 z3 模块用法。

0x01 基础

其实 z3 模块的使用非常简单，三步走即可，第一步申请变量，第二步添加约束，第三步求解。只不过在第二步添加约束的时候可能会有复杂的变形问题。z3 内置了很多变量类型，可以包含常见的计算机中的数据结构。整数、浮点数、数组等。

注意：在数据结构中，整数类型，并不是 C\C++ 语言中的 int 类型，这里的整数类型，没有范围限制，即整数类型可以表示自然数集中的所有整数，没有 int 类型的可表示范围限制。

from z3 import *a = Int('a')    # 声明变量为整数类型。b = Real('b')   # 声明变量为实数类型。c = Bool('c')   # 声明变量为bool类型。d = IntVector('d', 3)   # 声明变量为int类型数组。……

z3 模块的使用和普通其他 Python 语法相同，使用 = 赋值，使用 <、<=、>、>=、==、!= 进行比较操作。同时 z3 模块中也集成了大量函数可供使用，而在 CTF 中我们只是运用到了该模块极少数函数，对相对复杂的方程问题进行自动化求解。

from z3 import *x, y, z = Reals('x y z')    # 使用Reals声明多个实数类型变量s = Solver()    # 创建通用求解器，用于后续求解。s.add(x > 1, y > 1, x + y > 3, z - x < 10)    # add函数用来对上文通用求解器添加约束规则。print s.check()    # check函数用来表示该约束是否找到解print s.model()    # model函数用来返回解

0x02 上手

在解决一些涉及到较为复杂的数学变换过程的 CTF 题目时，比如说涉及到未知的数学技巧、暴力破解时间过长、涉及各种位运算等可以考虑使用 z3 对其进行自动化求解，不需要做题者去手工分析，使用其进行自动化求解的关键是，需要做题者对其数学变换过程进行整理化简，得到其中的所有约束条件。

但是 z3 也不是万能的，一些时间复杂度较高的数学问题，z3仍旧无法解出。下面就让我们上手一些简单的 CTF 题目来演示对 z3 模块的运用。
