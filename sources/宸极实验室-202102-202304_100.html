介绍：实验室新人的靶场练习，熟悉一下完整的渗透过程。

0x00 前言

DC-1靶场共有5个flag。靶机下载地址为https://download.vulnhub.com/dc/DC-1.zip

0x01 渗透经过

安装好之后两台虚拟机使用net模式连接起来。

1.1 信息收集

nmap、dir一条龙服务。使用nmap -sP 192.168.30.0/24 判断局域网内的主机状态。使用dir扫描后未发现可用信息。

nmap -A 192.168.30.0/24 查看端口。

发现开启了80端口，登录后使用Wappalyzer插件发现为Drupal 7版本。

1.2 漏洞利用

使用burp先进行密码爆破，发现被封，此路不通。

试着在MSF上查找Drupal的exp。

使用use 1选择drupal_drupalgeddon2模块。
使用show options查看需要的配置，发现只需要IP地址就好。
配置完毕后run。

成功shell后ls查看得到flag1.txt。

查看flag1.txt后提示Every good CMS needs a config file - and so do you.。
是需要我们去找drupal的配置文件。
这里我们使用python -c 'import pty; pty.spawn("/bin/bash")'命令进入交互式界面，啥也别说了，开找吧。

最后在sites/default/settings.php目录下找到了flag2.txt和数据库的信息。

1.3 连接数据库

输入mysql -udbuser -p 密码：R0ck3t连接数据库。

show databases;  查看数据库use  drupaldb;  进入drupaldbshow tables;  查看表select * from users;  进入user表
进入users表后发现账号密码，尝试破解密码后无果。

尝试渗透一下百度发现drupal的加密文件在scripts/password-hash.sh文件下。输入php scripts/password-hash.sh admin得到加密后的密码。

重进进入mysql输入。
update users set pass='$S$D5Hu6kaYSPW1iL2dGkvdKTETpl/mYQvLLwEGdoT33lpLTfLmTC9u' where name='admin';

admin：admin后进去系统找到flag3。

1.4 提权

查看flag3的提示我们查看一下passwd文件。发现falg4在home文件下。

查看falg4的时候提示需要越权。

find中有一个-exec的参数可以执行命令。而root的控制台一般是在/bin/sh中。

使用find ./ lll -exec '/bin/sh' \;提权成功。

在root下成功的查看到最后一个flag。

0x02 总结

前期需要搜集关于Drupal的相关信息包括配置文件的位置和加密文件的位置。

可以使用python -c 'import pty;pty.spawn("/bin/sh")'来获得交互shell。

提权和msf的使用熟练，也可以通过msf模块来添加账户来登录界面。

附上提权参考链接：
