## 0x00 前言

`DC-1`靶场共有5个`flag`。靶机下载地址为`https://download.vulnhub.com/dc/DC-1.zip`

## 0x01 渗透经过

安装好之后两台虚拟机使用`net`模式连接起来。

### 1.1 信息收集

`nmap、dir`一条龙服务。使用`nmap -sP 192.168.30.0/24 `判断局域网内的主机状态。使用`dir`扫描后未发现可用信息。

![](../Images/b27370cf9ce69e4329360fe116203da7.png)

`nmap -A 192.168.30.0/24 `查看端口。

![](../Images/47fd74544e5a966ba14c42ae504e9db3.png)

发现开启了`80`端口，登录后使用`Wappalyzer`插件发现为`Drupal 7`版本。

![](../Images/9ece3c99c212a8b3a83a6c54df46eccb.png)

### 1.2 漏洞利用  

使用`burp`先进行密码爆破，发现被封，此路不通。

![](../Images/18bf2c1497470656c0ae473c8b7e5b29.png)

试着在`MSF`上查找`Drupal`的`exp`。

![](../Images/97bc0cc1def950114eabe7afc11b868f.png)

使用`use 1`选择`drupal_drupalgeddon2`模块。使用`show options`查看需要的配置，发现只需要`IP`地址就好。配置完毕后`run`。

![](../Images/f05a6781018b836bbf9fe68f52fe1d07.png)

成功`shell`后`ls`查看得到`flag1.txt`。

![](../Images/0073a2ad4e0480af2ca546a34c05da9b.png)

查看`flag1.txt`后提示`Every good CMS needs a config file - and so do you.`。是需要我们去找`drupal`的配置文件。这里我们使用`python -c 'import pty; pty.spawn("/bin/bash")'`命令进入交互式界面，啥也别说了，开找吧。

![](../Images/f7ad6780ee74ea37772284c5770939de.png)

最后在`sites/default/settings.php`目录下找到了`flag2.txt`和数据库的信息。

![](../Images/55bc8e2bfa8a04f39db548ec84d77ed7.png)

### 1.3 连接数据库

输入`mysql -udbuser -p 密码：R0ck3t`连接数据库。

### 1.4 提权

查看`flag3`的提示我们查看一下`passwd`文件。发现`falg4`在`home`文件下。

![](../Images/24fa747fc4df9b795e5f61740f831b56.png)

查看`falg4`的时候提示需要越权。

![](../Images/8597cd43f4ef31a50e7b8547c3ddc763.png)

`find`中有一个`-exec`的参数可以执行命令。而`root`的控制台一般是在`/bin/sh`中。

![](../Images/9775a996a617073c7a20ab1ec3c87ad6.png)

使用`find ./ lll -exec '/bin/sh' \;`提权成功。

![](../Images/58b32a51d15b45ba6842c44dc0b8f032.png)

在`root`下成功的查看到最后一个`flag`。

![](../Images/ace0518340ae599819fed45f9d49c8b4.png)

## 0x02 总结

前期需要搜集关于`Drupal`的相关信息包括配置文件的位置和加密文件的位置。

可以使用`python -c 'import pty;pty.spawn("/bin/sh")'`来获得交互`shell`。

提权和`msf`的使用熟练，也可以通过`msf`模块来添加账户来登录界面。
