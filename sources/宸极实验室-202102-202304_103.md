## 0x01 理论基础  

**本文内容基于`python`语言**

首先我们要明白一个爬虫的基本流程，我个人习惯三步划分：

**发送请求 --> 获得页面**

**解析页面 --> 获得链接**

**下载内容 --> 储存内容**

大部分情况下，虽然网站不同，但是基本原理还是一致的。

接下来，我们从这三步流程，逐个分解。

![](../Images/e77602123ca1b7906c3c92c2e1249cba.png)

### 1.1 发送请求 --> 获得页面

这是爬虫的第一步，无非就是通过发送`HTTP`请求来获取页面内容，将页面内容存储至变量，以供给下一步使用。

比较常用的模块是`urllib2`，`requests`等。

我个人习惯用`requests`模块，方便简单。

举个栗子：

*   
*   
*   
*   
*   

```
import requests
url = 'http://www.xxx.com'tmp = requests.get(url)print(tmp.content)
```

上述代码的意思是，通过`GET`方式请求了`url`，并且输出了访问结果。

同理还有`POST`等其他请求方式。

![](../Images/27ed399873ab372a629500f76a218bfe.png)

### 1.2 解析页面 --> 获得链接

经过上一步获得的请求内容，在这一步需要进行解析，用来提取出所要爬取的资源的链接。

请求内容其实大部分情况下，与查看网页源代码的内容一致。

这一步常用的模块是`re`，`BeautifulSoup`等。

`re`模块是通过正则表达式，提取文本中的关键信息。

`BeautifulSoup`是通过将文本内容解析成`html`格式，进而通过标签等特点，分离出所需信息。

二者没有好坏之分，只是适用场合不同和个人使用习惯不同。

举个栗子：

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
import reimport requests
url = 'http://www.xxx.com'tmp = requests.get(url)data=tmp.content
key=re.compile(r'http(.*?)jpg')
print(key.findall(data))
```

上述代码的意思是，通过`compile`设定正则表达式匹配的规则，通过`findall`进行内容匹配，结果为数组格式。

规则是匹配`http`开头，`jpg`结尾的字符串。

![](../Images/6fb7a364ef3836b1b455e7442275079f.png)

另一个栗子:

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
import requestsfrom bs4 import BeautifulSoup
url = 'http://www.xxx.com'tmp = requests.get(url)data=tmp.content
html = BeautifulSoup(data,"html.parser")
print(html.find_all('img'))
```

上述代码的意思是，通过`BeautifulSoup`模块将请求内容解析为`html`格式，查找所有的`img`标签，结果为数组格式。

以上就是常用两个模块的简单介绍，正式写代码的时候可能会需要更多的需求。

这时候就需要及时百度，查找官方的文档手册。

调试`bug`，也是一种乐趣所在。

### 1.3 下载内容 --> 储存内容

最后，在查找到资源链接后，再次通过`HTTP`请求，将资源内容下载，之后保存到本地。

举个栗子：

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
import reimport requests
url = 'http://www.xxx.com'tmp = requests.get(url)data = tmp.content
key = re.compile(r'http(.*?)jpg')images = key.findall(data)
t=0for img in images:    p = requests.get(img)    pic = p.content    f = open (str(t)+'.jpg','wb')    f.write(pic)    f.close()    t=t+1
```

上述代码意思是，将提取到的图片链接，通过`for`循环去请求访问，得到图片内容。

将其按照序号进行保存。

至此，流程结束。

## 0x02 实践开始

理论讲完，实践开始。我们以`https://www.fabiaoqing.com/`这个表情包网站为例。首先在首页上随便点个链接，可以看到是如下情况。

![](../Images/a0cf34eaee50a60f5bba9d5f30bfa7ef.png)

首先观察一下他的`URL`链接，可以发现规律，通过`id`来进行控制，我们可以通过`for`循环来进行处理。例如：

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
import requestsfrom bs4 import BeautifulSoupimport re
url = 'https://www.fabiaoqing.com/bqb/detail/id/'t = 1
for i in range(54611,1,-1):    tmp = requests.get(url+str(i)+'.html',verify = False)    data = tmp.content
```

由于网站是`HTTPS`协议，所以需要在请求时加上`verify = False`，

用来忽略`SSL`证书。

但忽略证书会导致，在命令行存在`warning`信息，影响体验。

我们可以加入如下两行代码，即可取消告警信息的输出。

*   
*   

```
from requests.packages.urllib3.exceptions import InsecureRequestWarningrequests.packages.urllib3.disable_warnings(InsecureRequestWarning)
```

之后需要提取出图片链接。

我们可以通过`F12`来定位到这些表情包所在的标签和链接。

![](../Images/fc2555865769c2c49a58169b9f70e53f.png)

可以发现，我们需要的链接是上半部分，而下半部分并不是当前页面的表情包。而他们直接的区别是class值不同。`<img class="bqbppdetail lazy"``<img class="ui image lazy"`我们可以根据这一点构造正则表达式的匹配规则。`key=re.compile(r'bqbppdetail lazy(.*?)src')`拼接之后的代码为：

url = 'https://www.fabiaoqing.com/bqb/detail/id/'t = 1
for i in range(54611,1,-1):    tmp = requests.get(url+str(i)+'.html',verify = False)    data = tmp.content    key = re.compile(r'bqbppdetail lazy(.*?)src')    print(key.findall(data))
```

但是这样并没有提取到直接可以访问的图片链接，

还需要进行字符处理。

我们得到的内容，大致为：

`data-original="http://wx2.sinaimg.cn/bmiddle/003zDf54ly1gtl9yrmmobj603c02s0sl02.jpg"`

只要对字符串进行切片操作，即可得到正常的`URL`。

url = 'https://www.fabiaoqing.com/bqb/detail/id/'t = 1
for i in range(54611,1,-1):    tmp = requests.get(url+str(i)+'.html',verify = False)    data = tmp.content
    key = re.compile(r'bqbppdetail lazy(.*?)src')    pics = key.findall(data)
    for pic in pics:        print(pic[17:-2])
```

至此，我们得到了表情包的图片链接。

之后就是发送对应的`HTTP`请求，将图片内容保存至本地。
