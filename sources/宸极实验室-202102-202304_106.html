0x00 前言

一直黑盒测试挖漏洞久了，除了打CTF的时候几乎没做过什么代码审计，最近突然看到E4师傅的代码审计挖洞发现原来代码审计这么刺激啊，这不比黑盒有意思多了，还要啥自行车啊，直接开整，好好深入学习学习，通过这篇文章来系统的整理一下代码审计的思路。

0x01 环境搭建

XYHCMS是大家比较熟悉的cms了，3.6版本后台有比较严重的任意代码执行漏洞、文件上传。并且部署起来比较容易，win的师傅们可以在本机使用phpstudy部署环境，mac的师傅们可以用MAMP集成环境进行部署也很方便。

（1）下载源码，将uploads_code部署到MAMP中。

（2）保存重启一下MAMP就可以进入XYHcms的安装配置页面了。

（3）然后会对环境进行一个检测，直接进入下一步。

（4）配置一下数据库地址端口和用户名密码，以及后台管理员账号密码。

（5）点击下一步以后安装完成，环境搭建完毕。

0x02 代码分析

2.1 代码审计工具seay源码审计系统

一般在代码审计时如果自己去通读代码会很麻烦，所以一般都会使用一些代码审计工具来帮助我们更快更好的去完成代码审计，一般最常用的的就是seay源码审计系统了，非常好用。

（1）我们去通过其扫描出来的漏洞看一下。首先第一个问题在 uploads_code/App/Manage/Controller/SystemController.class.php文件中，

public function site() {        if (IS_POST) {
            $data = I('config', array(), 'trim');            //<script\s+language[\s=]+["\']*php["\']*[^>]*?\>.*?<\/script>            $preg_param = '/<script\s+language[\s=]+["\']*php["\']*[^>]*?\>/is';            foreach ($data as $key => $val) {                if (stripos($val, '<?php') !== false) {                    $data[$key] = preg_replace('/<\?php(.+?)\?>/i', '', $val);                }                if (stripos($val, '<script') !== false && stripos($val, 'php') !== false) {                    $data[$key] = preg_replace('/<script\s+language[\s=]+["\']*php["\']*[^>]*?\>.*?<\/script>/i', '', $val);                }
                if (stripos($data[$key], '<?php') !== false || preg_match($preg_param, $data[$key])) {                    $this->error('禁止输入php代码');                }
            }

我们可以发现这里的过滤了<?php ?>和<script language="php"></script>,但是这里我们知道php还有一种写法是<? ?>,所以我们是可以通过<? ?>来绕过这个过滤。当绕过这个过以后我们写入的php语句就会被写入site.php中。

（2）第二处问题代码也在这个文件中，我们可以看到，在线客服这个地方接受了POST的数据，并且写入到了config/site中，而且最重要的是，这个地方并没有对其进行过滤，就意味着可以直接写入<?php ?>。
