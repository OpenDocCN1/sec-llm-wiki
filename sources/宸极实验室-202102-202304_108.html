介绍：一款很稳定的多级代理工具stowaway。

0x00 前言

经某位天天参加比赛的大佬介绍了一款稳定的代理工具，于是就有了本篇学习笔记。

0x01 stowaway 介绍

stowaway是一个利用go语言编写、专为渗透测试工作者制作的多级代理工具。

用户可使用此程序将外部流量通过多个节点代理至内网，突破内网访问限制，构造树状节点网络，并轻松实现管理功能。

stowaway分为admin端和agent端两种形式。在stowaway中，组成多级网络需要借助admin中的listen、connect、 sshtunnel命令来实现。

0x02 举个栗子

多级代理的结构如下图所示：

实验环境是在本地搭建，其中，admin主控端是macos，node1被控端是macos，node2被控端是kali机器，node3被控端是windows 7机器。

2.1 开启主控端

admin主控端运行命令: ./macos_admin -l 9999 -s 111
其中-l参数表示监听端口。-s参数表示节点通信的加密密钥（密钥需要admin端和agent端保持一致）。

2.2 agent-1 连接 admin

agent-1运行命令: ./macos_agent -c 10.27.2.17:9999 -s 111

此时agent-1被控端已经和admin主控端进行了连接。

2.3 agent-2 连接 agent-1

此时的agent-1可以和agent-2正常通信，可以采用正向连接。

agent-2运行命令: ./linux_x64_agent -l 10000 -s 111

那么，此时用户可以通过admin主控端，输入use 0 进入agent-1，运行命令connect agent-2的IP:10000，将agent-2加入agent-1网络，并成为agent-1的一个子节点。

2.4 agent-3 连接 agent-1

假如此时用户还希望连入一个节点agent-3，但是通过agent-1无法访问到agent-3，我们可以采用反向代理。

那么，此时用户可以通过admin主控端，输入use 0 -> listen -> 选择1.Normal Passive -> 输入10001从而使得agent-1监听在10001端口上，并等待子节点的连接。

等admin操作完成后，agent-3启动如下：

agent-3: windows_x64_agent.exe -c 10.27.2.17:10001  -s 111

就可以将agent-3作为agent-1的第二个子节点加入网络了。

2.5 主控端查看被控节点

在admin主控端运行命令topo，可以看到有三个子节点，以数据的形式进行排序。

运行命令use 0选择进入第一个节点，运行命令shell可成功进入终端。

运行命令use 1选择进入第二个节点，运行命令shell可成功进入终端，被控端是台linux主机。

运行命令use 2选择进入第三个节点，运行命令shell可成功打开dos窗口，被控端是台windows主机。

除了可以进入shell之外还能上传、下载、ssh登录等操作，操作非常方便。


0x03 总结

代理工具千千万，选择一款适合于当前网络环境的最重要。

stowaway相比较与其他的代理工具最大的优势就是稳定，当你的代理老是断掉连接，不妨考虑一下它。
