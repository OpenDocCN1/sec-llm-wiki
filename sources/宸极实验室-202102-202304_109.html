介绍：第一次做项目的时候挖掘到了一个漏洞便是文件上传漏洞，所以整理纪念一下。

0x00 前言

现在的大部分站点都具有文件上传功能，例如头像更改、留言板、文章编辑，附件上传等。

0x01 文件上传漏洞概述

1.1 文件上传功的业务逻辑

文件上传功其实就是是将本地文件上传至服务器上进行保存。

我们可以通过burp抓包回显的文件路径来访问达到浏览服务器中文件的目的。

使用pickchu靶场可以很直观的看到。

1.2 文件上传漏洞

一些网站会对文件上传功能点做一些严格的过滤。

攻击者可以利用此功能上传一些恶意的被服务器解析的文件来获取服务器端的能力。

0x02 文件上传漏洞绕过

下载靶机https://github.com/Tj1ngwe1/upload-labs
切换PHPstudy版本为 5.2.17。

2.1 客户端JavaScript验证

客户端JavaScript验证是对上传文件的文件格式进行一个验证，验证的方式有：

•服务端文件扩展名验证（黑名单/白名单）
•服务端MIME类型验证
• 服务器文件内容验证

首先进行js审查。

<?phpinclude '../config.php';include '../head.php';include '../menu.php';
$is_upload = false;$msg = null;if (isset($_POST['submit'])) {    if (file_exists(UPLOAD_PATH)) {        $temp_file = $_FILES['upload_file']['tmp_name'];        //取出文件上传后临时存储的文件名        $img_path = UPLOAD_PATH . '/' . $_FILES['upload_file']['name'];        //生成一个新的文件存储路径，文件名保持文件上传前的文件名        if (move_uploaded_file($temp_file, $img_path)){        //move_uploaded_file函数把上传的文件移动到新的位置，成功则返回true，失败则返回false            $is_upload = true;        } else {            $msg = '上传出错！';        }    } else {        $msg = UPLOAD_PATH . '文件夹不存在,请手工创建！';    }}?>

下面这段js代码定义了检查上传文件的函数。

<script type="text/javascript">    function checkFile() {        var file = document.getElementsByName('upload_file')[0].value;        //获取到文件名        if (file == null || file == "") {            alert("请选择要上传的文件!");            return false;        }
        var allow_ext = ".jpg|.png|.gif";         //定义允许上传的文件类型
        var ext_name = file.substring(file.lastIndexOf("."));        //提取上传文件的类型。        //通过lastIndexOf取到“.”的索引，再使用substring函数截取 .后缀名
        if (allow_ext.indexOf(ext_name) == -1) {        //如果 allow_ext 中没有 ext_name字符串，则返回-1            var errMsg = "该文件不允许上传，请上传" + allow_ext + "类型的文件,当前文件类型为：" + ext_name;            alert(errMsg);            return false;        }         //判断上传文件类型是否允许上传    }</script>

绕过客户端JavaScript验证的方法有两个：

•修改JavaScript去修改其中关键的检测函数。

•直接通过插件禁用JavaScript。插件可以使用火狐里的JavaScript Switcher。

直接发送请求包，通过burp修改报文的内容，直接跳过js验证。

2.2 服务端MIME类型验证

服务端MIME就是通过MIME类型去判断文件是GIF还是其他的一些文件，常见的一些MIME类型有：

超文本标记语言文本：.html, .text/html普通文本：.txt, txt/plainRTF文本：.rtf, application/rtfGIF图形：.gif, image/gifJPEG图形：.ipeg, .jpg, image/jpeg

upload-labs源码示例。

$is_upload = false;$msg = null;if (isset($_POST['submit'])) {    if (file_exists(UPLOAD_PATH)) {        if (($_FILES['upload_file']['type'] == 'image/jpeg') || ($_FILES['upload_file']['type'] == 'image/png') || ($_FILES['upload_file']['type'] == 'image/gif')) {            $temp_file = $_FILES['upload_file']['tmp_name'];            $img_path = UPLOAD_PATH . '/' . $_FILES['upload_file']['name'];                      if (move_uploaded_file($temp_file, $img_path)) {                $is_upload = true;            } else {                $msg = '上传出错！';            }        } else {            $msg = '文件类型不正确，请重新上传！';        }    } else {        $msg = UPLOAD_PATH.'文件夹不存在,请手工创建！';    }}

我们可以用burp抓包将Content-Type改成允许的类型比如image/gif、image/jpg、image/png就可以了。

2.3 文件头-文件内容验证

文件头的内容验证是利用每一个特定类型的文件都会有不一样的开头或者标志位。

一个通过这种方法来过滤的示例代码如下：

if (! exif_imagetype($_FILES['uploadedfile']['tmp_name'])) {
        echo "File is not an image";
        return;
    }

首先我们要知道文件类型是操作系统为存储信息而使用的对信息的特殊编码，用于识别内部存储的资料。

即每一类信息，可以以一种或多种文件格式保存在电脑存储中。

在操作系统中，幻数是用于标识文件格式的常量，通过用常量来区分运行时文件类型。

我们可以通过010 Editor来看观看，一般常见的一些文件头幻数有：

•JPEG (jpg)，文件头：FF D8 FF EO

•PNG (png)， 文件头：89 50 4E 47

•GIF (gif)， 文件头：47 49 46 38

upload-labs源码示例：

function getReailFileType($filename){    $file = fopen($filename, "rb");    $bin = fread($file, 2); //只读2字节    fclose($file);    $strInfo = @unpack("C2chars", $bin);        $typeCode = intval($strInfo['chars1'].$strInfo['chars2']);        $fileType = '';        switch($typeCode){              case 255216:                        $fileType = 'jpg';            break;        case 13780:                        $fileType = 'png';            break;                case 7173:                        $fileType = 'gif';            break;        default:                        $fileType = 'unknown';        }            return $fileType;}
$is_upload = false;$msg = null;if(isset($_POST['submit'])){    $temp_file = $_FILES['upload_file']['tmp_name'];    $file_type = getReailFileType($temp_file);
    if($file_type == 'unknown'){        $msg = "文件未知，上传失败！";    }else{        $img_path = $UPLOAD_ADDR."/".rand(10, 99).date("YmdHis").".".$file_type;        if(move_uploaded_file($temp_file,$img_path)){            $is_upload = true;        }        else{            $msg = "上传失败";        }    }}

我们要绕过文件幻数检测就要在文件开头写上对应的文件幻数。

再在其后加上一句话木马即可。

图片马生成命令：

cmd：copy xx.png/b+一句话.php/a 新的图片名称.png

2.4 黑名单-文件扩展名验证

基于文件后缀名验证方式分类：

•基于白名单验证：只针对白名单中有的后缀名，文件才能上传成功。

•基于黑名单验证：只针对黑名单中没有的后缀名，文件才能上传成功。
我们可以修改后缀名绕过，但前提是apache的httpd.conf中有下列配置代码。
AddType application/x-httpd-php .php .phtml .phps .php5 .pht

也可以进行后缀名大小写进行绕过，直接上传后缀名为.pHP的文件。重写绕过可以上传.phpphp，因为服务器端将黑名单的后缀名仅替换一次。

upload-labs源码示例。

$is_upload = false;$msg = null;if (isset($_POST['submit'])) {    if (file_exists(UPLOAD_PATH)) {        $deny_ext = array("php","php5","php4","php3","php2","html","htm","phtml","pht","jsp","jspa","jspx","jsw","jsv","jspf","jtml","asp","aspx","asa","asax","ascx","ashx","asmx","cer","swf","htaccess");
        $file_name = trim($_FILES['upload_file']['name']);        $file_name = str_ireplace($deny_ext,"", $file_name);        $temp_file = $_FILES['upload_file']['tmp_name'];        $img_path = UPLOAD_PATH.'/'.$file_name;                if (move_uploaded_file($temp_file, $img_path)) {            $is_upload = true;        } else {            $msg = '上传出错！';        }    } else {        $msg = UPLOAD_PATH . '文件夹不存在,请手工创建！';    }}

%00截断是在php<5.3.4之前，因为当一个字符串中存在空字符的时候。

即在被解析的时候会导致空字符后面的字符被丢弃。

在burp里的Hex里可以添加%00截断。

2.5 上传连接工具

这里推荐三款连接工具：中国蚁剑、冰蝎、哥斯拉。

中国蚁剑：

•内置代理功能。
•支持HTTP、HTTPS、SOCKS4、SOCKS5四种代理协议。
•使用代理，可以连接处于内网中的Shell、加快连接速度、隐藏自身、与 BurpSuite 等工具配合使用等。

•还有编码器和解码器，用于蚁剑客户端和Shell服务端通信时的加密、编码操作，可用于绕过WAF。

中国蚁剑url:https://github.com/AntSwordProject/AntSword-Loader

冰蝎：

•客户端基于JAVA，所以可以跨平台使用。

•流量加密，难以被检测，webshell免杀性好，使用AES加密方式。
冰蝎url：https://github.com/rebeyond/Behinder/releases/tag/Behinder_v3.0_Beta_11

哥斯拉：

•全部类型的shell均过市面所有静态查杀，工具放出来之后可能会免杀一段时间后来就不行了，这时候只需要修改一下代码还能继续过狗。

•哥斯拉的流量加密和一些自带的插件，它的流量加密能过市面全部流量waf。

•这些自带的插件是冰蝎、蚁剑不能比拟的，有兴趣的可以深入研究一下。

哥斯拉url：https://github.com/BeichenDream/Godzilla/releases/tag/v3.03-godzilla
