0x01 理论

前几年的CTF比赛中，有时会出现移动安全的题目类型，也就是andriod或者ios逆向。

安卓逆向的话，一般可能是反编译为java代码，之后代码审计。

并不会修改apk本身的代码，因为与解题无关。

但是，小游戏的破解则不一样，我们需要修改apk本身的代码，

从而达到我们想要实现的破解效果。

比如，无限金钱，无限体力等。

玩过安卓逆向的大佬应该都知道，反编译apk之后，会生成smali文件，
而我们破解游戏，最终就是要修改samli代码。

1.1 APK 结构

首先说一下Apk 文件的结构：

1.META-INF：签名文件。

2.res：资源文件，里面的 xml 格式文件在编译过程中由文本格式转化为二进制的 AXML 文件格式。

3.AndroidManifest.xml：Android 配置文件，编译过程依然被转换为 AXML 格式。

4.classes.dex：java 代码编译后产生的类似字节码的文件（dalvik 字节码）。

5.resources.arsc：具有 id 值资源的索引表（asserts 文件夹中的资源不会生成索引）。

6.其他文件：可由开发者自己添加，诸如 assets 等。

分段翻译一下：

.class public Lcom/androidemu/harvemario/MainActivity;.super Lcom/androidemu/harvemario/FileChooser; .source "MainActivity.java"

翻译成java：

package com.androidemu.harvemario;import com.androidemu.harvemario.FileChooser;public class MainActivity extends FileChooser{
}
# static fields   
.field private static final DIALOG_SHORTCUT:I = 0x1                                               .field private static final HELP_URI:Landroid/net/Uri;.field private static emulatorIntent:Landroid/content/Intent;

翻译成java：

import android.net.Uri;import android.content.Intent;
private static final int DIALOG_SHORTCUT = 1;private static final Uri HELP_URI;private static final Intent emulatorIntent;
# instance fields
.field private creatingShortcut:Z.field private settings:Landroid/content/SharedPreferences;

翻译成java：

import android.content.SharedPreferences;
private boolean creatingShortcut;private SharedPreferences settings;

最终合成：

package com.androidemu.harvemario;import com.androidemu.harvemario.FileChooser;import android.net.Uri;import android.content.Intent;import android.content.SharedPreferences;
public class MainActivity extends FileChooser{    private static final int DIALOG_SHORTCUT = 1;    private static final Uri HELP_URI;    private static final Intent emulatorIntent;    private boolean creatingShortcut;    private SharedPreferences settings;}

0x02 实践

声明：

本文中破解样例为2010年的单机游戏，并不涉及到充值等功能。

破解过程仅供入门娱乐，不具有现实参考意义。

本次挑选的软柿子是我当年很喜欢的一个黄金矿工游戏，

第一次在手机上玩到黄金矿工，感觉还是很哇塞的。

话不多说，进入正题。

要破解游戏，首先就要试玩游戏。

为了本次的实验，特地找来了一台远古手机。

安装完成，进入游戏。

可以看出画质还是很粗糙的，过关之后，会出现商店界面。

而这，就是我们今天的重点。

商店的物品有价格，而价格是固定的，这是最容易修改破解的。

直接把apk扔进工具反编译，这里我用的是APKIDE。

反编译之后，可以直接找到samli文件夹，
随便找一个smali文件，进行查看java代码。

之后，去寻找我们想要的变量。

要修改物品的价格，首先要找到商店。

而我们的目标就是UI_Shop.java

简单一看，就可以发现有明显的Price变量，

而且里面的数值与商店的道具价格是可以完全匹配的。

这时候，我们需要找到它对应的smali文件。

在这里我们可以发现这几个16进制的数值，
转为10进制后就是道具的价格。

修改完成之后，选择编译生成APK，
成功后可在原APK同目录下看到新编译的APK。
安装运行，发现修改成功。

0x03 总结

这只是最简单的修改样例，后续还可以有很多操作。

比如：无条件过关等。

而且，这里没有提到签名的问题，

有时候修改之后，会破坏原本APK包的结构，

这时候就需要用工具重新进行签名。

总而言之，仅供娱乐。
