## 0x01 理论

前几年的`CTF`比赛中，有时会出现移动安全的题目类型，也就是`andriod`或者`ios`逆向。

安卓逆向的话，一般可能是反编译为`java`代码，之后代码审计。

并不会修改`apk`本身的代码，因为与解题无关。

但是，小游戏的破解则不一样，我们需要修改`apk`本身的代码，

从而达到我们想要实现的破解效果。

比如，无限金钱，无限体力等。

![](../Images/1591e329f18931ce3ce0fa0863a16a1d.png)

玩过安卓逆向的大佬应该都知道，反编译`apk`之后，会生成`smali`文件，而我们破解游戏，最终就是要修改`samli`代码。

![](../Images/2581f37dfa0aba71921ef67ed3ab5540.png)

### 1.1 APK 结构

首先说一下`Apk` 文件的结构：

1.`META-INF`：签名文件。

2.`res`：资源文件，里面的` xml` 格式文件在编译过程中由文本格式转化为二进制的 `AXML` 文件格式。

3.`AndroidManifest.xml`：`Android` 配置文件，编译过程依然被转换为 `AXML` 格式。

4.`classes.dex`：`java` 代码编译后产生的类似字节码的文件（`dalvik` 字节码）。

5.`resources.arsc`：具有 `id` 值资源的索引表（`asserts `文件夹中的资源不会生成索引）。

6.其他文件：可由开发者自己添加，诸如` assets` 等。

### 1.2 samli语法

下面简单说明一下`samli`的语法结构。

类型关键字：

| 类型关键字 || 表示类型 |
| --- | --- |
| `B` || `byte` |
| --- | --- |
| `S` || `short` |
| `C` || `char` |
| `I` || `int` |
| `J` || `long(64 bits)` |
| `F` || `float` |
| `D` || `double(64 bits)` |
| `V` || `void` |
| `Z` || `boolean` |
| `L` || `Object` |
| `[I` || `int[]` |

![](../Images/a67bba2f43d8dfb63257bf71efb019b8.png)

指令关键字：

| 指令 || 说明 |
| --- | --- |
| `.class` || 包名+类名 |
| --- | --- |
| `.super` || 父类类名 |
| `.source` || 源文件名 |
| `.implements` || 接口实现 |
| `.field` || 定义字段 |
| `.method`  
`.end method` || 方法的开始  
方法的结束 |
| `.locals` || 方法内使用的v开口的寄存器个数 |
| `.prologue` || 表示方法中代码的开始处 |
| `.line` || 对应`java`中的行数 |
| `.param` || 指定了方法的参数 |
| `.paramter` || 和`.paramter`含义相同 |
| `.annotation`  
`.end annotation` || 注解的开始  
注解的结束 |

## 0x02 实践

**声明：**

**本文中破解样例为2010年的单机游戏，并不涉及到充值等功能。**

**破解过程仅供入门娱乐，不具有现实参考意义。**

本次挑选的软柿子是我当年很喜欢的一个黄金矿工游戏，

第一次在手机上玩到黄金矿工，感觉还是很哇塞的。

话不多说，进入正题。

要破解游戏，首先就要试玩游戏。

为了本次的实验，特地找来了一台远古手机。

安装完成，进入游戏。

![](../Images/b1ca50302c77b9469242837c3bc1671f.png)

可以看出画质还是很粗糙的，过关之后，会出现商店界面。

![](../Images/4a6ee3255effd22a5588a72fd7fb61d3.png)

而这，就是我们今天的重点。

商店的物品有价格，而价格是固定的，这是最容易修改破解的。

直接把`apk`扔进工具反编译，这里我用的是`APKIDE`。

![](../Images/e2dcffefc86b392941ca48750fa163b0.png)

反编译之后，可以直接找到`samli`文件夹，随便找一个`smali`文件，进行查看`java`代码。

![](../Images/afb7278f0c2e616be43c605235a6c0b9.png)

之后，去寻找我们想要的变量。

要修改物品的价格，首先要找到商店。

而我们的目标就是`UI_Shop.java`

![](../Images/bebccbf0b49979ea8221a78b78088dc7.png)

简单一看，就可以发现有明显的`Price`变量，

而且里面的数值与商店的道具价格是可以完全匹配的。

这时候，我们需要找到它对应的`smali`文件。

![](../Images/4e12bad469a8e4be91d1d1dbefededb1.png)

在这里我们可以发现这几个`16`进制的数值，转为`10`进制后就是道具的价格。

![](../Images/4d4c764c2c66984b38f5e9e45d4d8281.png)

修改完成之后，选择编译生成`APK`，成功后可在原`APK`同目录下看到新编译的`APK`。安装运行，发现修改成功。

![](../Images/fde2030fe59d4173f3dfa6b5dd75a03e.png)

## 0x03 总结

这只是最简单的修改样例，后续还可以有很多操作。

比如：无条件过关等。

而且，这里没有提到签名的问题，

有时候修改之后，会破坏原本`APK`包的结构，

这时候就需要用工具重新进行签名。
