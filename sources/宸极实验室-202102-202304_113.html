知道了密码是md5(md5($password)），但是解不开，就去看了一下他的admin账号密码加密实现。

//生成随机字符串function get_random($length = "") {    $length =  $length ¿ $length : rand(6,12);    $chars='123456789abcdefghijklmnpqrstuvwxyz';    $hash = '';    $max = strlen($chars) - 1;    for($i = 0; $i < $length; $i++) {        $hash .= $chars[mt_rand(0, $max)];    }    return $hash;}

看到admin密码的这个加密方式，只要知道了encrypt 我完全是可以反推出明文的，我们通过注入拿到这个encrypt，然后通过字典去爆破。

我们可以验证一下自己的猜想，我把密码改为了1234567，通过上面的注入得到encrypt然后通过加密代码去加密得到的值正是我们数据库里面的hash，也就是我们知道了密码生成规则，那我们就可以去脚本去爆破了。
