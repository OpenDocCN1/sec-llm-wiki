#### dump LDAP

查询到目标机器在域内，域用户登录

```

shell wmic computersystem get domain
```

![](../Images/63a9e40713dff29bfccf200c5ca1e529.png)

```

shell whoami /all
```

![](../Images/e3121f705f9f971244cffca28ffe2856.png)

前面已经确定目标机器在域内，并且目标机器是域用户登录。

域成员用户可以通过LDAP访问域的目录数据库从而看到整个域的信息。

这是使用的一种方式是通过 ADExplorer软件dump

将ADExplorer.exe上传到目标机器，使用以下命令执行

```
D:\bea\xx\ADExplorer.exe -snapshot 
```

![](../Images/df27bbc7f53c26c26816df3a18160097.png)

将resul.dat 在本地用ADExplorer打开即可看到域的信息

![](../Images/a5406dddd8fb7077c28a690b83633e2e.png)

#### 扫描内网

查看本机IP，本机IP为192.168.10.3.

使用fscan工具扫描一下192.168.10内网段，从扫描结果看出192.168.10.10和192.168.10.32应该是域控服务器

![](../Images/2638be638371cf1eeb6a87f07605b18b.png)![](../Images/ca8451817e5384d98aee575c04de8401.png)

#### 横向

通过LDAP和内网扫描看到域内有两台域控：192.168.10.10、192.168.10.32

判断用户权限

```

shell whoami /all
```

![](../Images/c80019013e6ee045bdb1c5b3ded62a74.png)![](../Images/d8ff30a1e1d5e3dca6112be29390266b.png)

```
shell net group 
```

![](../Images/51d341e0a57dbb52e9f6ad88c27fcfa3.png)

比较幸运，上线就是域管用户可以直接使用域管用户身份横线域内其他机器

先尝试横向域控192.168.10.10机器，wmic可用，通过wmic进行横向

```

shell wmic /node:192.168.10.10 os get name
```

![](../Images/be24c1c404f76f782e2142d752b0119c.png)

判断是否有杀软

```

shell wmic /node:192.168.10.10 process get processid,name
```

![](../Images/75b069715421e184cf24bea68b2d0c1d.png)![](../Images/112a55252fb8634a23a0f5b3e12e978f.png)

列出192.168.10.10进程，使用杀软在线查询，目标机器有杀软

判断192.168.10.10是否出网，如果直接执行ping 8.8.8.8或者其他公网地址，但是CS上没有回显就无法判断，在这里分享一下我常用的两种方法：

1.通过DNSlog （http://www.dnslog.cn/）

```
shell wmic /node:192.168.10.10 process call create 
```

![](../Images/29ef7a99e80efb437bcfceaad96ecd18.png)

2.通过tcpdump

```


tcpdump -i 网卡名 icmp
```

![](../Images/f4b42b4d939c12159b6522d8b84e4eff.png)

两种方法都没有回显，192.168.10.10不出网。

192.168.10.10不出网而且有杀软，先做免杀，然后通过CS的smb隧道将192.168.10.10link上线

在CS上创建SMB监听，使用smb监听生成beacon。

将做好免杀的beacon 上传到192.168.10.10。

![](../Images/464840bf706b45019aec0877e56eb596.png)![](../Images/f8b43969ec5c0838f07ebb2f9ae07d90.png)![](../Images/b163ef6d92b25dc7b741c828029cf190.png)

通过link192.168.10.10 上线

```
shell wmic /node:192.168.10.10 process call create 
```

![](../Images/9b74ac748b08174ec55623499f88fe4f.png)![](../Images/e2fb0da2eddc55df0fbfd6d1d0a4ef20.png)

第一台域控上线，接着横向另一台192.168.10.32机器，方法跟上面一样，判断出网和杀软。

![](../Images/a473dc7f31d39dd61b598ce572e43afe.png)![](../Images/112a55252fb8634a23a0f5b3e12e978f.png)

192.168.10.32出网有杀软，这样就不用通过link上线了，直接做免杀beacon上线就行。

```
shell wmic /node:192.168.10.32 process call create 
```

![](../Images/2c40e2742898c5a8a445a7c461101ed9.png)

拿到域控可以导出域hash

Windows的密码是经过hash后存储的，本地存在hklm\\sam，hklm\\system注册表中

域里面存在域控制器的c:\\windows\\ntds\\ntds.dit中，我们取出来解密即可

```
shell ntdsutil 
```

![](../Images/2f876b162f3d7012a814a1dbf6782fff.png)

再使用reg命令导出system 和security

```



  reg save hklm\system system
```

![](../Images/81f042e2eb0df93a3163ef3b5ab82431.png)

使用impacket下的secretsdump.py 解hash

```
python secretsdump.py -ntds 
```

最后成功获取当前域控中所有域账户和密码

![](../Images/7f4f34feedb378c216ea69b48010222d.png)
