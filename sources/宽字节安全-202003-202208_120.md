# CVE-2020-3452 CISCO ASA远程任意文件读取 poc

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzNTEyMTE0Mw==&mid=2247483943&idx=1&sn=6d3b6fd1a294aea12f5b6ca363208d43&chksm=fa8b1fbfcdfc96a95cebfb14f248a7230c65c868f53153d4ac4ee3a0268c630e86199611a496&scene=126&sessionid=1681663413#rd](http://mp.weixin.qq.com/s?__biz=MzUzNTEyMTE0Mw==&mid=2247483943&idx=1&sn=6d3b6fd1a294aea12f5b6ca363208d43&chksm=fa8b1fbfcdfc96a95cebfb14f248a7230c65c868f53153d4ac4ee3a0268c630e86199611a496&scene=126&sessionid=1681663413#rd)

## 简介

Cisco Adaptive Security Appliance (ASA) 防火墙设备以及Cisco Firepower Threat Defense (FTD)设备的web管理界面存在未授权的目录穿越漏洞和远程任意文件读取漏洞。攻击者只能查看web目录下的文件，无法通过该漏洞访问web目录之外的文件。该漏洞可以查看webVpn设备的配置信息，cookies等。

#### 漏洞评分：高
