Kali 2019.1发布，想早点把它部署到外网嗨一把。也就有了下文...

  • 准备条件

  1. 谷歌云账号

  2. 谷歌云SDK

  3. VirtualBox（VboxManage）

  4. Kali Linux 2019.1 ISO镜像

创建虚拟机

  1. 考虑系统配置影响系统运行效率和实例费用，建议1H2G

  2. 虚拟硬盘文件类型QCOW，因为谷歌默认分配10G免费硬盘空间，所以测试的话不超10G就好

  3. 虚拟机设置关闭软驱启动，关闭声音，开启准虚拟化网络



  4. 最后加载ISO镜像，开机

系统安装

  • 关键操作步骤截图









系统配置

  • 默认只需开启SSH即可

安装Cloud SDK

参考官方文档

  • https://cloud.google.com/sdk/docs/quickstarts

Create a raw file

  1. Convert qcow to raw file.

    vboxmanage clonehd -format raw kali.qcow disk.raw

  2. Convert into tar format.

    tar -zcvf ~/kali.tar.gz disk.raw

Upload image to Google Cloud

  1. Create bucket

    https://cloud.google.com/storage/docs/naming#requirements

    gsutil mb gs://my-awesome-bucket/

  2. Upload to bucket

    gsutil cp kali.tar.gz gs://bucket-name/kali.tar.gz

Start Kali Linux virtual machine

  • gcloud compute images create kali -source-uri gs://bucket-name/kali.tar.gz
gcloud compute instances create kali -image kali -machine-type n1-standard-1 -zone us-central1-b

  • -machine-type 指定GCE类型

  • -zone 指定区域
