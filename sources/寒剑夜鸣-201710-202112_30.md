# 获取Office 365 A1 Plus for students

目前有不少国外高校的邮箱是托管于office365的，并且带有Office 365 A1(或A1 Plus) for students订阅，例如之前介绍的：塔拉哈西社区学院edu邮箱就有A1 Plus订阅。还有的高校，虽然邮箱用的是G Suite等系统，但是也有Office 365 A1(或A1 Plus) for students的订阅，可以通过Office 365 for Education申请。

Office 365 for Education官网地址：https://www.microsoft.com/zh-cn/education/products/office/default.aspx

输入你的edu邮箱即可开始，如果提示“从你的电子邮件地址来看，你的学校似乎尚不在我们的合格机构列表中。可以通过提供以下信息让你的学校出现在我们的列表中”，说明你用的邮箱不行。

如果用的邮箱合格，后面的步骤就很简单了，可以选择你是学生，或者老师，其实基本没区别，选老师获取的是Office 365 A1 (Plus) for faculty订阅。

我试了几个学校的邮箱，发现有的学校的订阅是Office 365 A1 Plus for students，有的是Office 365 A1 for students，这两个的区别是前者支持最新桌面版office的安装，后者只支持在线版office。

本站介绍的不少校友邮箱都是可以成功申请的。

支持Office 365 A1 Plus for students的edu邮箱有：耶鲁大学校友edu邮箱，埃默里校友大学edu邮箱等。

![](../Images/4a1c448821f2aa2d4f93506ff059892d.png)

其他校友邮箱我没有一一测试，感兴趣的可以试一下。Office 365 A1 Plus for students对于个人用户来说是够用的。下图为office安装后的效果(我在windows vps上安装测试的):

# 申请埃默里大学(Emory University)校友edu邮箱

这个之前提到过，只是没详细介绍，现在说一下具体方法。  
地址：http://www.engage.emory.edu/s/1705/alumni/index.aspx?sid=1705&gid=3&pgid=383  
点击Create My Account会发现需要ID NUMBER和Preferred Email，那么如何获取ID NUMBER呢？  
去这里填一下信息提交即可：http://www.engage.emory.edu/s/1705/alumni/index.aspx?sid=1705&gid=3&pgid=546&cid=1288  
记得在Please provide my alumni id number to register for the community后面打钩。  
提交这个form以后需要等一段时间（大概一两个工作日）就会收到包含alumni id number的邮箱，有了这个id number就可以回到第一步Create My Account了。。有了账号就可以开始设置校友邮箱前缀了。  
邮箱后缀是@alumni.emory.edu(和@alum.emory.edu)，托管于G suite。每次更改邮箱前缀，原来的前缀自动变成别名，上限是几十个。  
![](../Images/ebaa1bd15caa3444707428b9553d4f79.png)  
可以看到，别名上限60多个，但是其中包括一些无意义后缀的（@alumni.emory.edu.test-google-a.com）。  
其实这个上限可能是谷歌这边限制的，在emory校友在线社区倒是可以无限更改前缀，只是到一定数量后，谷歌这边显示的别名不再更新和增加。

# 申请@uwalumni.com邮箱(无限g drive)

注册地址：https://www.uwalumni.com/benefits-services/email/sign-up/

必要的信息：建议把first name, last name, middle name和grad year都填一下，这样成功率比较高。

校友列表：https://en.wikipedia.org/wiki/List\_of\_University\_of\_Wisconsin%E2%80%93Madison\_people

提交后需要等待1-4个工作日。我是下午提交，晚上就收到了邮件。

![](../Images/c77b3fd39f757a605149738567090ae9.png)如果你一个edu邮箱都没申请到，可以试试这个，虽然不是edu邮箱，但好歹有无限容量的google drive。不需要的就不要申请了，防止被滥用。

# 申请@unmalumni.com邮箱（无限Goole drive容量）

鉴于有人需要无限G drive容量的账号，就写了这篇文章。

![](../Images/c485abd6e9f1c98331d92f8408067fa7.png)

该邮箱其实是The University of New Mexico这所大学的校友邮箱，不过并不是edu邮箱，但也是有无限容量的g drive的。

一. 地址：https://securelb.imodules.com/s/1730/interior2-name.aspx?sid=1730&gid=2&pgid=8&cid=46

二. 需要的信息：Birth Date&Class Year。

三. 从第一步链接注册成功后去这个地址申请邮箱：http://alumniconnections.unmalumni.com/s/1730/interior2-name.aspx?sid=1730&gid=2&pgid=95&cid=1005&gfid=158&pem=1。申请后就会收到邮箱初始密码。和以前的套路一样。

四. 提供一个校友列表：https://en.wikipedia.org/wiki/List\_of\_University\_of\_New\_Mexico\_alumni 。  当然，还有其他途径获取校友信息，自己摸索吧。

这种账号就不要拿来储存重要文件了~毕竟有风险。
