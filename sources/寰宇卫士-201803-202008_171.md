# 忘改路由器密码导致美国军方文件被盗

“只要正确设置路由器，你也可以拥有比美军更好的网络安全。”虽然只是一句调侃，但是还是道出了美军网络被黑的原因。

![](../Images/16916e5cbc1bdd0eb24fb7f5fe94c4f7.png)  
**美国军方遭受黑客袭击原因竟是因为没有更改路由器的密码**

    美国研究分析师近期发现了与无人机、坦克和战术计划有关的敏感文件被整合为一个手册，将在黑客经营的网站上进行出售。根据研究分析师的说法，这个手册是通过一个普通的网络漏洞获得的，而且只要简单的密码更新就可以避免。

    网络安全公司“记录未来”在上周二报道了这一发现。“记录未来”称在监控黑暗网络上的黑客论坛时，该公司的分析师偶然发现了一位会说英语的黑客，这位黑客正在提供与MQ-9无人机-相关的军方优选的无人驾驶飞机相关文件。这些文件包括收割机维修手册和分配到收割机AMU的飞行员名单。

    分析人员与提供文件的人进行了接触，发现了文件提供者并没有想象中的小心翼翼。卖家告诉研究人员，他们是通过一个流行的互联网设备搜索引擎发现这些文件的，这些搜索引擎通常用来查找没有设置正确配置的路由器。由于这些文件是“机密信息”，他们索要150至200美元(113至151英镑)。根据“记录未来”报道，这些文件不是机密的，但只能在内部使用，供军方和承包商使用。研究人员写道，尽管如此，他们还是可以为对手提供一个“评估最先进飞机的技术能力和弱点”的机会。BuzzFeed新闻公司的一位分析师安德烈·巴里塞维奇(Andrei Barysevich)解释说，这个价格非常低：“我们觉得他对这些信息的价值没有真正的理解，他不知道如何出售，他只是想甩掉它。”

    同样的卖家后来又公布了另一批文件，其中包括：十多本描述简易爆炸装置失败战术的训练手册，一本M1艾布拉姆斯坦克操作手册，一本船员训练和生存手册，以及坦克排战术。同时还声称这些材料不是机密材料，大多数据说只供军方及其承包商使用。

    “记录未来”与美国军方取得了联系，并继续就这一案件与他们合作。首先，在涉及无人机相关文件的情况下，黑客准确地告诉分析人士，飞机维修中队的哪个机长是攻击目标。受害人的身份尚未公开，但报告中载有一份经编辑的证书副本，其中确认该机长最近完成了“网络意识挑战”。第二份文件的来源尚未确定，但分析人士说，“它们似乎是从五角大楼或美国陆军官员那里偷来的。”

    Barysevich告诉Buzzfeed，“曝光可能比这些被偷的文件要大得多。”这是因为他们是通过利用网具路由器的漏洞获得的，该公司曾在2016年警告过这种漏洞。默认情况下，路由器容易受到恶意攻击，需要使用用户创建的密码进行更新。RecordFuture在最近一次调查中发现了4000多台网络连接设备，仍然没有进行路由器密码的更新，依然采用较为简单的密码设置，在黑客面前不堪一击。
