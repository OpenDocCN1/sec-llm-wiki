> Docker 桌面是容器化应用程序的最简单方法。无需考虑在你选择的系统上设置环境即可开始使用。

> 只需要安装 Docker 桌面，就可以开始了。Docker 桌面应用程序附带容器工具，如 Kubernetes、Docker Compose、BuildKit 和漏洞扫描。

> 之前只支持Windows和macOS，不支持Linux平台。因此Linux 用户只能通过命令行来使用docker。

### 适用于 Linux 的 Docker Desktop 它来了

> 使用 Linux 上的 Docker 桌面，终于可以毫不费力地体验跨平台的 Docker 体验。

> 提到一些亮点，作为 Linux 桌面上的开发人员，你现在可以：

*   使用 Docker 扩展访问新功能
*   与 Kubernetes 无缝集成
*   轻松管理和组织卷、容器和映像。  
    

### 在 Linux 上安装 Docker Desktop

> 值得注意的是，目前安装 Docker 桌面可能不是很容易，但也不是太复杂。Docker 团队计划尽快改进安装和更新过程。

> 截至目前，你可以获得 Ubuntu、Debian 和 Fedora 正式支持的 deb 和 rpm 软件包。适用于 Arch Linux 的 Docker Desktop 软件包正在进行中，但可供测试。

> 如果你使用的是非 GNOME 桌面环境，它还需要你安装 GNOME 终端。

> Linux 上的 Docker Desktop 的软硬件要求：

*   64 位 Ubuntu 22.04 LTS、Ubuntu 21.10、Fedora 35、Fedora 36 或 Debian 11。
*   KVM 虚拟化支持
*   QEMU 5.2 或更高版本
*   系统初始化系统
*   GNOME 或 KDE 桌面环境
*   4 GB 内存

> 在未来将增加对 Raspberry Pi OS 64 位变体的支持。
