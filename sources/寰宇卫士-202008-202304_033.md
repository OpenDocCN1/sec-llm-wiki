# 安装 Linux 后绝对不要做的 8 件事

Linux 使您可以自由地做任何您想做的事情。但是有些事情是您不应该对新安装的 Linux 做的。在您的 Linux 之旅中的某个时刻，您可能发现自己在安装 Linux 后在互联网上搜索要做的事情。虽然知道在第一次启动 Linux 后应该做什么很重要，但知道不该做什么对于避免破坏新设置的系统更为重要。让我们看看在使用新的 Linux 安装时应该避免的一些常见问题。这些技巧对所有 Linux 用户都有帮助，无论他们的专业知识如何。

## **1.从互联网上复制/粘贴随机命令**

大多数新手犯的第一个错误是在没有真正理解的情况下从互联网上复制和粘贴命令。虽然您不太可能将命令从网站复制到您的终端并让您的数据被盗，但风险还是存在的，您应该尽力防止它。![](../Images/6b76bc406ceb145dbbf843ef7bf15a7a.png)因此，在按下 Enter之前，请始终尝试理解这些命令。当然，Linux 命令可能很复杂，初学者很难本能地识别出旨在造成伤害的命令。但是，如果您可以剖析一个命令并在互联网上搜索正确的关键字，您只需几分钟就可以大致了解它的作用。一开始可能会觉得很费时间，但这种小小的努力却大有帮助。因此，下次有人要求您在终端中输入“**sudo rm -rf --no-preserve-root /** ”时，请确保先用 Google 搜索该命令。

## **2\. 以 root 身份运行所有 Linux 命令**

![](../Images/e860af4bc64743d9f0be329962e80ef4.png)Linux 假设用户知道他们在做什么，并且它很少在运行命令之前发出警告。以 root 身份运行命令时更是如此。sudo、su 和 doas 允许您以另一个用户（通常是 root）身份执行 Linux 命令。尽管在某些情况下以 root 身份运行程序至关重要，但您不应该总是在命令的开头添加 sudo，因为它对您的 PC 造成的危害比您想象的要大。通过简单地在命令前添加单词“sudo”或“doas”，您就可以让程序完全访问您的系统，并允许它做任何它想做的事情，包括删除整个操作系统。旨在造成伤害的程序会利用这一点并危及计算机的安全。因此，仅在绝对必要时或您信任该程序及其开发人员时才使用 sudo 或其他类似实用程序。

## **3.随意删除根目录中的文件**

Linux 目录结构将用户和系统文件隔离到不同的目录中。主目录（Home）是您存储个人文件的地方，根目录中的其他文件夹包含系统文件和软件包文件。![](../Images/fe4f21d3b3d0fc5e571d24db94d080c9.png)为了保持稳定性，您永远不应删除主目录以外的任何目录中的文件。这可能会导致程序出现意外行为，因为您可能会不小心删除配置文件。删除系统文件还会使您的机器无法使用，并导致进入黑屏，无事可做或无法控制。

## **4\. 添加未知 PPA 和包源**

由于大多数 Linux 程序都是开源的，因此许多人都在仔细检查它们的源代码，并删除了任何有害的方法或漏洞。但是在线有数十万个存储库，不可能监控每一行代码是否存在恶意操作。对于未知的 PPA 和第三方包源尤其如此。![](../Images/510c4c9600d2fa405eed4876a5dab0bb.png)在官方发行版存储库中找到的程序有数百名贡献者和维护者，他们自愿确保代码的完整性保持不变。大多数时候，您可以信任此类程序并在不考虑太多的情况下安装它们。但是，由没有信誉的个人创建的存储库怎么办？在这种情况下，在将代码安装到您的机器上之前检查代码很重要。如果不懂代码，就暂时打消安装的念头，等项目火起来吧。这将带来更多的贡献者，他们将确保该程序没有恶意代码并且可以毫无问题地安装。

## **5\. 切换回 Windows 或跳发行版**

当您从另一个操作系统切换到 Linux 时，可能暂时会有点不适应。这将导致您切换回到 Windows，但是您应该花更多时间在 Linux 上。如果看过这方面的教程，那么您会欣慰地知道可以将 Linux 定制为像 Windows 或 macOS 一样。只需要一些时间和Linux迷上的一些教程。你也不应该跳发行版，因为它会让你更难适应 Linux。每个 Linux 发行版系列都有不同的工具集，并提供独特的桌面体验。这让情况变得更糟，因为您对五个不同的包管理器和十几个可供选择的桌面环境感到困惑。因此，最好的方法是选择一个对初学者友好的发行版并坚持使用几个月。

## **6\. 害怕命令行**

命令行是你的朋友。时期。如果您在安装 Linux 时认为使用终端就可以了，那您可能就错了。总有一天，您必须在终端中键入命令，具体取决于您要解决的问题的严重程度。![](../Images/3aaf35c44d3a24586fd9199d1899396a.png)许多 Linux 发行版都尝试尽量减少命令行的使用，但终端已经成为 Linux 几十年来不可或缺的一部分，现在几乎不可能将两者分开。

## **7\. 纠缠你的朋友和家人切换到 Linux**

您成功地在您的机器上安装了Linux发行版。你似乎很喜欢它。它稳定、可定制，并免费提供您在操作系统中所需的一切。下一步就是向你所爱的人推荐 Linux。你想给他们带去这种可定制的系统，让他们变成和你一样，对吧?不。向人们推荐 Linux 是可以的，但只是在一定程度上。你可不要在聚会上谈论Linux，向那些根本不在乎它的人解释它为什么比 Windows 更好。请记住，每个人都有不同的用例，他们可能不像您那样对 Linux 印象深刻。如果您仍然觉得有必要向其他人介绍 Linux 及其优点，为什么不去网上论坛，在询问操作系统建议的主题上留下评论呢?

## **8.低估备份的力量**

到目前为止，您已经知道程序可能会破坏您的安装。在这种情况下，有一个可以依靠的备份会有所帮助。即使您的操作系统无法启动，这也可以确保您的文件安全。![](../Images/9b6b10f8a596048e093112b7dd8bec30.png)更好的是，您可以设置一个快照实用程序，以便在指定的时间段对系统进行快照。当你将来遇到问题时，你可以简单地将最后保存的快照导入应用程序，它会将你的计算机恢复到最后保存的状态。在Linux上配置备份或快照实用程序很容易，总比以后后悔好得多。**相关：**

## **现在你知道你不应该在 Linux 上做什么了**

预防胜于治疗。作为初学者使用 Linux 时，了解哪些事情是完全禁忌的是很重要的。您应该了解您的机器的局限性，以及在您甚至没有意识到的情况下使其无用的方法。如果您选择使用 Linux 作为您的下一个操作系统，请了解在第一次启动计算机后应该立即执行的一些事情。
