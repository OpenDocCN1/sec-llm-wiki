helloSystem 0.8发布，酷似macOS的FreeBSD桌面发行版

原文：http://mp.weixin.qq.com/s?__biz=MzIwMzU0NDY5OA==&mid=2247496218&idx=1&sn=5c6ba5ec97f4849014b446030322a812&chksm=96cf730fa1b8fa19277d56c56c96fb69bd1fed04572eeab2d7c990a6fe5f087c5c55f7b33ba8&scene=126&sessionid=1681669323#rd

helloSystem 0.8 已发布，此版本基于 FreeBSD 13.1 构建，目标是打造一个简洁、优雅和实用的桌面操作系统。
0.8 主要变化：

  • 改进启动命令

  • 预安装 VirtualBox Guest Additions 以获得更好的 Oracle VM VirtualBox 用户体验

  • 改进对 MIDI 控制器的处理

  • 初步支持使用启动命令来启动一些 AppImage 文件

  • 使用从 Linux 5.10 移植过来的 DRM 内核模块支持 Gen12/Xe Tigerlake 等最新 Intel 显卡

helloSystem 0.8 还对用户界面进行了改进，比如在系统菜单中支持 “强制退出应用程序”，以及其他新增的各种桌面基础设施和 UI 工具。helloSystem 现在还配备了 Trojita 作为其电子邮件客户端，为基于 WebEngine 的浏览器（如 Falkon）启用了 GPU 加速，此外还有一个新的 “进程” 工具，以及针对整个平台的大量修复。
详情查看 Release Notes：https://github.com/helloSystem/ISO/releases/tag/r0.8.0
helloSystem 是热度颇高的 BSD 桌面发行版之一，它提供了精良的桌面体验，希望成为 BSD 中的 macOS。
helloSystem 项目具有与 macOS 相似的设计目标，即 “能够正常工作”，不需要太多配置就可以带来良好的开箱即用的桌面体验。helloSystem 基于 FreeBSD，除了设计理念，helloSystem 桌面环境也已被配置为看起来像早期 MacOS X 的桌面。
helloSystem 的开发人员不是要创建一个 macOS 的 1:1 副本，而是要与 macOS 的用户体验理念保持一致。因此 helloSystem 不能直接重新打包现有软件，为此他们还在开发更多专门用于 helloSystem 的桌面应用程序，其中许多应用程序都是用 PyQt 编写的。
