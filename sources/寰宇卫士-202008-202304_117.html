你应该停止相信的关于 Linux 的 7 个神话

Linux 发行版功能强大、可靠且易于使用，但互联网上对 Linux 存在太多误解。
互联网对几乎所有事情都充满了神话（或者是不真实的说法），并且充斥着随时准备宣扬这种误解的人。如果你经常在一些在线论坛上阅读过关于 Linux 的文章，那么你很可能会遇到一些广为人知的 Linux 神话。
以下是一些关于 Linux 的神话，它们像野火一样在互联网上蔓延开来。

1、Linux 仅供开发人员和编码人员使用

Linux 的历史一直与程序员密切相关，即使在今天，为该项目做出贡献的大多数人都是软件开发人员。这就是为什么大多数普通桌面用户认为 Linux 是为具有技术背景的计算机用户保留的。
事实上，大多数预装在 Linux 发行版上的标准实用程序和软件包都与软件开发相关，但现在几乎每个发行版都开始为对编写代码完全不感兴趣的公众添加应用程序。
大多数人没有意识到 Linux 已经成为他们日常生活中不可或缺的一部分。任何通过互联网浏览网站的人，或使用 Android 智能手机的人都在使用 Linux，其形式为网络服务器和为手持设备定制的操作系统。
撇开间接的 Linux 使用不谈，如果你愿意，你甚至可以在你的计算机上安装一个适合初学者的 Linux 发行版。您无需成为程序员或技术极客即可学习如何使用它。需要的是强烈的学习意愿和坚持不懈的精神。

2、你必须掌握命令行才能使用Linux

命令行或终端是 Linux 发行版中固有的，从一开始就是这种情况。当 Linus 开始开发 Linux 时，计算机的功能还不足以支持图形用户界面，而命令行对于任何想要与系统交互的人来说都是必不可少的。

快进到现在，指代 GUI 的术语“桌面”通常用作“计算机”的替代品，这两个术语组合在一起具有完全不同的含义。除了底层的桌面环境，机器现在可以运行资源密集型游戏，而对于普通用户来说，命令行的使用并不多。
如果您愿意，您无需使用终端或在 Linux 发行版上根本无需键入命令即可摆脱困境。有时您可能需要对问题进行故障排除，并且可能需要您在 shell 中输入命令，但不要担心，大多数帮助都可以在线获得。您需要做的就是将命令复制并粘贴到您的终端中，您就可以开始了。
相关：为什么命令行在 Linux 生态系统中如此重要 https://www.linuxmi.com/linux-command-line-important.html

3、Linux 不适合游戏

即使在今天，游戏也是 Linux 应该缺乏的一个众所周知的应用领域。但现在情况不再如此。Linux 发行版在游戏方面正在取得进展，您现在可以将 Linux 视为游戏玩家的操作系统。
众所周知，像 CS:GO 这样的原生 Linux 游戏在 Linux 上的表现优于在其他操作系统（包括 Windows）上的表现。这很明显，如果游戏开发者开始为 Linux 原生开发，Linux 在性能方面实际上可能有机会超越 Windows。
然而，目前还不是这样。许多游戏的多人游戏支持在 Linux 上仍然不起作用，因为 Linux 架构不允许内核级访问反作弊软件。但这可能很快就会改变，考虑到 Linux 上的游戏已经取得了如此多的成就。
相关：Wine 7.8 实现驱动程序增强，在 Linux 上玩更多 Windows 游戏 https://www.linuxmi.com/wine-7-8.html

4、很难找到适用于 Linux 的应用程序

Windows 用户享受对 Adobe Photoshop、Microsoft Office 等高级应用程序的原生支持。
另一方面，此类专有软件公司不为基于 Linux 的操作系统提供软件支持。这导致很多用户认为Linux没有很多应用程序，如果他们切换到Linux，他们可能会错过一些黄金程序。然而，这完全不真实。
Linux 的应用程序数量至少与 Windows 相同（如果不是更多的话）。他们可能在公众中没有那么有声望或知名度，但他们完成了工作。仅举几例，Linux 使用 GIMP 作为 Adobe Photoshop 的替代品，并使用 LibreOffice 套件作为 Microsoft Office 的替代品。

5、Linux 不会被病毒感染

“如果你使用 Linux，就不会感染病毒或恶意软件。”这个关于 Linux 的神话自远古以来就一直围绕在互联网上。然而，这种说法的长期存在并不意味着它是准确的。
感染Linux系统是完全有可能的。但事实是，Linux 只占桌面操作系统市场的一小部分，这意味着攻击者不太喜欢会为 Linux 开发恶意软件，因为利润率很低。事实上，您甚至不需要在桌面 Linux 系统上使用杀毒软件或防火墙。
这是因为大多数 Linux 防病毒软件通常会检查与 Windows 相关的恶意软件，这样你就不会与其他系统共享被感染的文件。另外，由于权限在 Linux 上的工作方式，它比其他操作系统要安全得多。

6、Linux 只用在服务器上

许多长期使用 Windows 的用户的印象是 Linux 只用于服务器，如果它是桌面操作系统，它会像 Windows 或 macOS 一样突出。尽管 Linux 最初是由 Linus Torvalds 作为桌面操作系统创建的，但由于其底层架构，它在服务器世界中更具主导地位。
除了在服务器上运行之外，Linux 还为台式计算机、智能手机、嵌入式设备甚至超级计算机提供动力。您在家中使用的大多数智能电器很有可能在后台使用 Linux。

7、Linux 过于碎片化

有数千个可用的 Linux 发行版，每个发行版都带有一组不同的软件、用户界面和管理软件包的独特方式。所有这些可能会让您认为 Linux 世界是碎片化的，或者至少是不受管理的。
但是这个表面上的弱点，其实是Linux的强项。众多不同选项的可用性为您提供了选择。您可以选择您要使用的操作系统，安装适合您的桌面环境，并使用更易于学习的包管理器。这些选择通常已经在其他操作系统（如 Windows 或 macOS）上为您做出。
这还不是全部。Linux 在您看来可能是支离破碎的，但只是从远处看。如果您了解有关操作系统的更多信息，您会发现不同发行版之间的相似之处多于差异。
只有少数父发行系列可以从中创建其他发行版。这些 Linux 发行版系列中的每一个都有自己独特的包管理器，这意味着选择一个适合您需求的包管理器会过滤掉几乎 80% 的可用发行版。
但是，可以使用 Snap 和 Flatpak 等打包系统，它们与发行版无关，并且可以在任何基于 Linux 的操作系统上运行，前提是您拥有正确的软件。

要更好地揭穿 Linux 神话

Linux 神话在互联网上流传了很长时间。许多这些误解使人们远离在他们的计算机上尝试基于 Linux 的操作系统。因此，重要的是要更好地打破这些神话。
既然现在你知道了这些错误观念，如果你最终想尝试 Linux，那么可以从 Ubuntu 和 Manjaro Linux 两个发行版开始。但是哪一款适合 Linux 初学者呢，您应该为您的桌面选择哪一款呢？
