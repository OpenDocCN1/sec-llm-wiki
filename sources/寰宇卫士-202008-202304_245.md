> Kali Linux 在 2022 年的第一次升级带来了明显的视觉更新和一个新的“全都有”离线 ISO。

2022 年的第一个 Kali Linux 版本来了。

Kali Linux 在  2021 年里做了许多改进，包括 Linux 内核升级、实时虚拟机支持、新的黑客工具、苹果 M1 支持等等。

让我们来看看 Kali Linux 2022.1 版本中的主要亮点。

## Kali Linux 2022.1 到底有什么新内容？

从这个版本开始，Kali Linux 团队决定对他们每年的第一个版本进行明显的视觉更新。

因此，Kali Linux 2022.1 的更新带来了视觉上的刷新和其他新的增加和改变。

### 主题更新

![](../Images/7bed08725db1d151425e814e77ef505c.png)

升级后，可以看到一些新的桌面、登录和启动屏幕的壁纸。

安装程序的主题也得到了视觉上的更新，使其更加具有现代风格的外观。

总之，通过主题、新壁纸还有细微的布局变化，很期待从 UEFI/BIOS 启动菜单再到桌面统一用户体验。

![](../Images/e039e3f468c040846e47ea602b20971a.png)

浏览器的登录页面也有视觉上的更新，可以尝试访问 Kali 文档、工具、还有通常的搜索功能来查看。

![](../Images/76fa8477e1cb8cfb2bb586744083b4c6.png)

###  “全都有” ISO

Kali Linux 现在将提供一个新的分发方式，提供一个独立的离线 ISO，包括了 “kali-linux-everything” 软件包所有内容。

这个产品的目的是让你下载一个离线 ISO，不需要单独下载软件包。

它应该对偏远地区教育机构使用 Kali Linux 进行道德黑客学习很有帮助。

考虑到它是一个大的 ISO 文件，你只能通过 BitTorrent 找到这个 ISO。

### 对 VMware  i3 桌面的改进

如果在带有 i3 桌面环境的虚拟机上使用 Kali Linux，一部分客户功能是默认禁用的。

现在，这些功能，如拖放、复制/粘贴已经默认启用，可以带来更好的开箱即用的 i3 虚拟机的体验。

### 其他

除了新增关键功能外，Kali Linux 2022.1 还带来了工具的整体改进，其中包括：

*   在 Kali 的设置屏幕中使用带有合成语音的无障碍性改进。
*   新的工具，如 dnsx、naabu、email2phonenumber、proxify 等等。
*   可用于 ARM64 架构的新软件包，包括 feroxbuster 和 ghidra。
*   Linux 内核 5.15
*   你现在可以使用 kali-tweaks 中的设置来启用传统的算法、密码和 SSH。
*   对 shell 提示符进行调整，删除了骷髅头图标、退出码还有后台进程数量的显示。

总的来说，这个版本对桌面和树莓派的重大改进值得期待。

你可以通过 官方公告^(\[1\]) 来了解更多细节。
