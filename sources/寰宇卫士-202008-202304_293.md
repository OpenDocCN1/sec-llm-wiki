# 【CVE-2018-10933】libssh 认证绕过漏洞复现题解

漏洞名称：libssh 认证绕过漏洞

漏洞编号：CVE-2018-10933

影响版本：libssh版本0.6及更高版本

漏洞等级：高危

漏洞原理：

libssh是一个用于访问SSH服务的C语言开发包，它能够执行远程命令、文件传输，同时为远程的程序提供安全的传输通道。server-side state machine是其中的一个服务器端状态机。

通过向服务端提供SSH2\_MSG\_USERAUTH\_SUCCESS消息来代替服务端期望启动身份验证的 SSH2\_MSG\_USERAUTH\_REQUEST消息，攻击者可以在没有任何凭据的情况下成功进行身份验证。进而可以进行一些恶意操作。

其服务端代码中存在一处逻辑错误，攻击者可以在认证成功前发送MSG\_USERAUTH\_SUCCESS消息，绕过认证过程，未授权访问目标SSH服务器。

  

复现过程：

使用POC脚本传入libssh运行的所在ip地址和端口号以及需要运行的命令即可。
