漏洞影响：

              Apache Tomcat 6

              Apache Tomcat 7 < 7.0.100

             Apache Tomcat 8 < 8.5.51

             Apache Tomcat 9 < 9.0.31

  

漏洞说明：Apache Tomcat会开启AJP连接器,方便与其他Web服务器通过AJP协议进行交互。而该漏洞是由于Tomcat AJP协议存在缺陷而导致，攻击者可通过构造特定参数读取webapp目录下的任意文件，如：webapp 配置文件或源代码等。
