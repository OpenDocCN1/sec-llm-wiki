CVE2020-1938 Apache Tomcat文件包含漏洞

1. 漏洞介绍：

2020年1月6日，国家信息安全漏洞共享平台（CNVD） 发布了Apache Tomcat文件包含漏洞（CNVD-2020-10487，对应CVE-2020-1938）。该漏洞是因为Tomcat AJP协议存在缺陷而导致得，攻击者可以利用该漏洞通过构造特定参数，从而读取服务器webapp下的任意文件。如果目标服务器同时存在文件上传功能，攻击者便可进一步实现远程代码执行。利用方式属于文件包含漏洞。CNVD对该漏洞综合评级为“高危”。目前，厂商已发布新版本完成漏洞修复。

2. 影响版本如下：

Apache Tomcat 6

Apache Tomcat 7 < 7.0.10

Apache Tomcat 8 < 8.5.51

Apache Tomcat 9 < 9.0.31

 

3. 漏洞环境：

在vmware15.5里面安装win10

在win10里面装JDK8+apache-tomcat8.5.49配置

4. 漏洞复现：

下载exp

 

【nmap -sV ip地址】

利用

 

5. 漏洞修复：

建议更新高版本

目前为止，Apache官方已发布了9.0.31、8.5.51还有7.0.100版本对此漏洞进行修复，CNVD建议用户尽快升级到新版本或者采取临时缓解措施。

 

如未使用Tomcat AJP协议

如果没有使用 Tomcat AJP 协议，可以直接将 Tomcat 升级至 9.0.31、8.5.51或者 7.0.100 版本进行漏洞修复。如没有办法立即进行版本更新、或者是更老版本用户，建议直接关闭AJPConnector，或者将其监听地址改为仅监听本机localhost。

具体操作：

第一步 编辑 <CATALINA_BASE>/conf/server.xml，

 

找到如下行（<CATALINA_BASE> 为 Tomcat 的工作目录）：

<Connector port="8009"protocol="AJP/1.3" redirectPort="8443" />

 

第二步 将此行注释掉或者删掉：

<!--<Connectorport="8009" protocol="AJP/1.3"redirectPort="8443" />-->

 

第三步 保存后需要重新启动，规则方可生效。

情况三 如果使用Tomcat AJP协议

建议将Tomcat立即升级至9.0.31、8.5.51或者7.0.100版本进行修复，同时为AJP Connector配置secret以此来设置AJP协议的认证凭证。

例如（注意必须将YOUR_TOMCAT_AJP_SECRET更改为安全性高、无法被轻易猜解的值）：

<Connector port="8009"protocol="AJP/1.3" redirectPort="8443"address="YOUR_TOMCAT_IP_ADDRESS" secret="YOUR_TOMCAT_AJP_SECRET"/>

 


如没有办法立即进行版本更新、或者更老版本用户，建议为AJPConnector配置`‘’requiredSecret以此来设置AJP协议认证凭证。

例如（注意必须将YOUR_TOMCAT_AJP_SECRET更改为安全性高、无法被轻易猜解的值）：

<Connector port="8009"protocol="AJP/1.3"redirectPort="8443"address="YOUR_TOMCAT_IP_ADDRESS"requiredSecret="YOUR_TOMCAT_AJP_SECRET" />
