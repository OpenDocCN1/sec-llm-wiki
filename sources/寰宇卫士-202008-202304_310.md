本次的靶机我们选择的是DVWA CSRF的medium等级，我们先用brup抓包，然后自动生成一个poc：

![](../Images/153fecf215af8a6ae0960db7cf8f09bb.png)

   

将POC的内容用网页打开：

![](../Images/f51d2023836b8c687d2b88349f140704.png)

   

点击按钮后发现无法请求：

 

![](../Images/d627a4ff867e9f280a0f5fcb01dff5c7.png)

   

查看一下源码：

if( eregi( $\_SERVER\[ ‘SERVER\_NAME’ \], $\_SERVER\[ ‘HTTP\_REFERER’ \] ) )

（注：在php语言中int eregi(string pattern, string string)，译为检查string函数中是否含有pattern，如果有返回True，反之False。）因此，此句是判断HTTP\_REFERER中是否包含SERVER\_NAME

HTTP\_REFERER是Referer参数值，即来源地址

SERVER\_NAME是host参数及主机ip名（我这里是127.0.0.1）

所以，如果我们想要破解它，就要让Referer参数值包含主机名，我们使用brup打开拦截模式，在请求包中加入referer参数：

![](../Images/623d5a733ee9ec9051f4d91c27869729.png)

   

请求发送成功，密码被更改了：

![](../Images/56f66461acf882d7df5deb44224e5e8b.png)

   

medium等级的csrf被攻破了，你学会了吗？
