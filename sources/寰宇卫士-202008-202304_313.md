**1.Fake-Hwclock**

有些机器没有工作的实时时钟 (RTC) 单元，或者没有硬件驱动程序。fake-hwclock 是一组简单的脚本，用于定期（包括关闭时）保存内核的当前时钟并在启动时恢复它，以便系统时钟至少保持接近实时。这将阻止一些可能由系统认为它已经穿越到 1970 年引起的问题，例如需要在每次启动时执行文件系统检查。

 

最重要的是，仍然建议使用 NTP 来处理硬件停止或重新启动时假时钟“漂移”。

 

# **2.Fcrackzip**

fcrackzip 是部分用汇编程序编写的快速密码破解程序。它能够使用暴力或基于字典的攻击来破解受密码保护的 zip 文件，可选择使用解压缩其结果进行测试。它还可以破解 cpmask 的图像。

 

该软件包对渗透测试人员、道德黑客和取证专家很有用。

 

# **3.Fern-Wifi-Cracker**

该软件包包含使用 Python 编程语言和 Python Qt GUI 库编写的无线安全审计和攻击软件程序，该程序能够破解和恢复 WEP/WPA/WPS 密钥，还可以在无线或基于以太网的网络上运行其他基于网络的攻击。

#   

# **4.Feroxbuster**

feroxbuster 是一种用于执行强制浏览的工具。强制浏览是一种攻击，其目的是枚举和访问 Web 应用程序未引用但攻击者仍可访问的资源。feroxbuster 使用暴力力结合词表来搜索目标目录中未链接的内容。这些资源可能存储有关 Web 应用程序和操作系统的敏感信息，例如源代码、凭据、内部网络寻址等……这种攻击也称为可预测资源位置、文件枚举、目录枚举和资源枚举。

 

# **5.Ffuf**

ffuf 是一个用 Go 编写的 fest web fuzzer，它允许典型的目录发现、虚拟主机发现（没有 DNS 记录）以及 GET 和 POST 参数模糊测试。

 

# **6.Fierce**

Fierce 是一种半轻量级扫描器，可帮助针对指定域定位非连续 IP 空间和主机名。它确实是 nmap、unicornscan、nessus、nikto 等的前身，因为所有这些都要求您已经知道您正在寻找的 IP 空间。这不会进行攻击，也不会不加区分地扫描整个互联网。它专门用于定位企业网络内部和外部的可能目标。

 

因为它主要使用 DNS，所以您经常会发现配置错误的网络会泄漏内部地址空间。这在有针对性的恶意软件中特别有用。最初由 RSnake 和其他人在http://ha.ckers.org/ 上编写。这只是对 Python 3 的转换，以简化和现代化代码库。

 

# **7.Fiked**

FakeIKEd，或简称 fiked，是一个伪IKE 后台进程，支持的标准和Cisco扩展刚好足以攻击常见的不安全的Cisco VPN PSK+基于XAUTH的IPsec身份验证设置，可以称之为半MitM攻击。Fiked 可以模拟 VPN 网关的 IKE 响应程序以捕获 XAUTH 登录凭据；它目前不做完整 MitM 的客户端部分。

 

# **8.Finalrecon**

一个用于网络侦察的快速而简单的 Python 脚本，它遵循模块化结构并提供有关各个领域的详细信息。

 

# **9.Firefox-Developer-Edition-Kbx**

Firefox 是一款功能强大、可扩展的 Web 浏览器，支持现代 Web 应用程序技术。这是开发人员版，在 kaboxer 的帮助下在容器中运行，针对 en-US 进行了本地化。

 

# **10.Firewalk**

Firewalk 是一种主动侦察网络安全工具，它尝试确定给定 IP 转发设备将通过哪些第 4 层协议。Firewalk 的工作原理是发送 TTL 大于目标网关 1 的 TCP 或 UDP 数据包。

 

# **11.Firmware-Mod-Kit**

Firmware-Mod-Kit允许轻松解构和重建各种嵌入式设备的固件映像。虽然它主要针对基于 Linux 的路由器，但它应该与大多数使用常见固件格式和文件系统的固件兼容，例如 TRX/uImage 和 SquashFS/CramFS。

 

# **12.Firmware-Sof**

提供某些 Intel 系统上的音频功能所需的 Intel SOF 音频固件和拓扑。

 

# **13.Flashrom**

flashrom 是一种用于识别、读取、写入、验证和擦除闪存芯片的工具。它通常用于使用支持的主板在系统内闪存 BIOS/EFI/coreboot/firmware/optionROM 映像，但它也支持闪存网卡 (NIC)、SATA 控制器卡和其他可以对闪存芯片进行编程的外部设备。

 

支持多种DIP32、PLCC32、DIP8、SO8/SOIC8、TSOP32/40/48、BGA芯片，使用LPC、FWH、并行闪存、SPI等多种协议。

 

例如，该工具可用于闪存 BIOS/固件映像——无论是专有 BIOS 映像还是 coreboot（以前称为 LinuxBIOS）映像。

 

它还可用于从闪存芯片读取当前现有的 BIOS/固件。

 

目前支持的程序员包括：

 

*    内部（用于主板中的系统内闪存）

*    nic3com（用于 3COM 网卡上的闪存 ROM）

*    it8212（用于 ITE IT8212F ATA/RAID 控制器上的闪存 ROM）
    
*    ft2232\_spi（用于连接到基于 FT2232/FT4232H/FT232H 系列的 USB SPI 编程器的 SPI 闪存 ROM），包括 DLP 设计 DLP-USB1232H、FTDI FT2232H 迷你模块、FTDI FT4232H 迷你模块、AJbiosprogkey/Jbiosprog tiny/JTAGkey-2、Dangerous Prototypes Bus Blaster、Olimex ARM-USB-TINY/-H、Olimex ARM-USB-OCD/-H、TIAO/DIYGADGET USB 多协议适配器 (TUMPA)、TUMPA Lite、GOEPEL PicoTAP、Google Servo v1/v2 和 FIC OpenMoko Neo1973 调试板。
    
*    serprog（用于连接到使用 serprog 的程序员的闪存 ROM），包括 Urja Rannikko 的 AVR flasher、80dot 的 AVR flasher、fritz 的 Arduino Mega flasher、Juhana Helovuo 的 InSystemFlasher 和 Stefan Tauner 的 atmegaXXu2-flasher。
    
*    buspirate\_spi（用于连接到 Bus Pirate 的 SPI 闪存 ROM）

# **14.Foremost**

Foremost 是一个取证程序，可根据文件的页眉、页脚和内部数据结构恢复丢失的文件。

 

Foremost 可以处理图像文件，例如由 dd、Safeback、Encase 等生成的文件，也可以直接处理驱动器。页眉和页脚可以由配置文件指定，也可以使用命令行开关指定内置文件类型。这些内置类型查看给定文件格式的数据结构，从而实现更可靠和更快的恢复。

 

# **15.Forensic-Artifacts**

一个免费的、社区来源的、机器可读的取证工件知识库，全世界都可以将其用作信息源和其他工具。

 

# **16.Forensics-Colorize**

forensics-colorize 是一组工具，用于直观地比较大文件，如文件系统图像，创建它们的图形。它很直观，因为生成的图形提供了关于两个文件之间更改百分比的快速而完美的感觉。

 

使用简单的差异比较大型文本文件可能会在行中产生非常大的结果，从而导致混乱。另一方面，diff 不适合比较二进制文件。

 

这个包提供了两个命令行程序：filecompare 和 colorize。filecompare 命令用于创建用于着色的特殊和辅助输入文件。colorize 命令将生成一个直观的图形，可以更容易地感知文件之间的变化程度。

 

# **17.Fping**

fping 是一个类似于 ping 的程序，它使用 Internet 控制消息协议 (ICMP) 回显请求来确定目标主机是否正在响应。fping 与 ping 的不同之处在于您可以在命令行上指定任意数量的目标，或者指定一个包含要 ping 的目标列表的文件。fping 将发送一个 ping 数据包并以循环方式移动到下一个目标，而不是发送到一个目标直到超时或应答。

 

# **18.Fragrouter**

Fragrouter 是一个网络入侵检测规避工具包。

 

网络入侵检测系统可以通过拦截数据包，获取内容进而判断是否为恶意数据包。对于传输较大的数据包，通常会采用分片的方式，将大数据包拆分为小数据包进行传输。如果入侵检测系统不具备数据包重组功能，就无法侦测到分片的恶意数据包。

 

而Kali Linux提供的fragrouter就是基于该漏洞开发的规避工具。该工具可以拦截发送给网卡的数据，进行重新分片，然后再发送。它支持22种分片方式。这些分片方式采用乱序、重复分片、空包、交叉发包等措施，以规避检测系统。使用该工具后，再使用其他工具进行扫描和探测，就可以降低被入侵检测系统发现的概率。

 

# **19.Framework2**

Metasploit 框架的第 2 版。不再更新但仍然有用，特别是对于 shellcode。

 

CLR，基础运行时，它包括了.net运行所需要的运行时类库、JIT实时编译器和运行时环境，.net编写的程序需要通过它才能运行。

 

# **20.Freeradius**

FreeRADIUS 是一个高性能 RADIUS 服务器，支持：

 

*    通过本地文件、SQL、Kerberos、LDAP、PAM 等进行身份验证。
    
*    强大的策略配置语言。
    
*    按任何标准代理和复制请求。
    
*    支持多种 EAP 类型；TLS、PEAP、TTLS 等。
    
*    许多特定于供应商的属性。
    
*    字符串属性中的正则表达式匹配。还有更多。
    

 

# **21.Freeradius-Wpe**

该软件包是 FreeRadius 无线 Pawn 版。有受支持和测试的 EAP 类型/内部身份验证方法（其他也可能有效）：

 

*    PEAP / PAP (OTP)
    
*    PEAP/MSCHAPv2
    
*    EAP-TTLS/PAP（包括 OTP）
    
*    EAP-TTLS/MSCHAPv1
    
*    EAP-TTLS/MSCHAPv2
    
*    EAP-MD5
    

 

# **22.Freerdp2**

FreeRDP 是远程桌面协议 (RDP) 的自由客户端/服务器实现。用于从 Linux 下远程连接到 Windows 桌面。

 

目前，FreeRDP 客户端支持以下 Windows 版本：

 

*    Windows NT Server
    
*    Windows 2000 Terminal Server
    
*    Windows XP
    
*    Windows 2003 Server
    
*    Windows Vista
    
*    Windows 2008/2008r2/2011SBS Server
    
*    Windows 7
    
*    Windows 2012/2012r2 Server
    
*    Windows 8
    
*    Windows 10
    

 

# **23.Ftester**

Firewall Tester (FTester) 是一种用于测试防火墙过滤策略和入侵检测系统 (IDS) 功能的工具。

 

特征：

 

*    防火墙测试
    
*    入侵检测
    
*    状态检测防火墙和 IDS 的真实 tcp 连接模拟
    
*    TCP连接欺骗
    
*    IP分片/TCP分片
    
*    IDS 规避技术
