1.Eaphammer

此软件包包含一个工具包，用于对WPA2企业网络执行有针对性的Evil Twin攻击。它设计用于全范围无线评估和红队参与。因此，重点放在提供易于使用的界面上，该界面可以利用最少的手动配置来执行强大的无线攻击。


2.Eapmd5pass

EAP-MD5 是一种传统的身份验证机制，不能为用户身份验证凭据提供足够的保护。使用 EAP-MD5 进行身份验证的用户会受到离线字典攻击漏洞的影响。

 

该工具从监控模式下的实时网络接口或存储的 libpcap 捕获文件中读取，并提取 EAP-MD5 身份验证交换的部分。一旦从这次交换中收集到质询和响应部分，eapmd5pass 将针对用户的密码发起离线字典攻击。

 

3.Edb-Debugger

edb 是一个图形化的跨平台 x86/x86-64 调试器。它的灵感来自 Ollydbg，但目标是在 x86 和 x86-64 以及多个操作系统上运行。Linux 是目前唯一官方支持的平台，但 FreeBSD、OpenBSD、OSX 和 Windows 端口正在开发中，具有不同程度的功能。

 

4.Emailharvester

该软件包包含 EmailHarvester，这是一种从搜索引擎检索域电子邮件地址的工具。特征：

 

  •  从流行的搜索引擎（谷歌、必应、雅虎、ASK、百度、Dogpile、Exalead）检索域电子邮件地址

  •  将结果导出到 txt 和 xml 文件

  •  限制搜索结果

  •  定义您自己的用户代理字符串

  •  使用代理服务器

  •  插件系统

  •  使用搜索引擎（Twitter、LinkedIn、Google+、Github、Instagram、Reddit、Youtube）在流行网站中搜索

 

5.Enum4linux

Enum4linux是从Windows和Samba系统枚举信息的工具。它试图提供与以前从www.bindview.com获得的enum.exe类似的功能。

 

它是用 PERL 编写的，基本上是 Samba 工具 smbclient、rpclient、net 和 nmblookup 的包装器。因此，samba 包是一个依赖项。

 

功能包括：

  •  RID循环（在Windows 2000上将RestrictAnonymous设置为1时）

  •  用户列表（Windows 2000上RestrictAnonymous设置为0时）

  •  集团成员信息列表

  •  共享枚举

  •  检测主机是否位于工作组或域中

  •  识别远程操作系统

  •  密码策略检索（使用polenum）

 

6.Enumiax

enumIAX 是 Inter Asterisk Exchange 协议用户名暴力枚举器。enumIAX 可以在两种不同的模式下运行；顺序用户名猜测或字典攻击。

 

7.Ethtool

ethtool 可用于查询和更改许多网络设备（尤其是以太网设备）上的设置，例如速度、自动协商和校验和卸载。

 

8.Ettercap

Ettercap 支持对许多协议（甚至加密协议）的主动和被动剖析，并包括许多用于网络和主机分析的功能。

 

还可以在已建立的连接中注入数据并动态过滤（替换或丢弃数据包），从而保持连接同步。

 

实现了许多嗅探模式，以获得强大而完整的嗅探套件。嗅探有四种模式：基于IP、基于MAC、基于ARP（全双工）和基于PublicARP（半双工）。

 

Ettercap 还能够检测交换 LAN，并使用操作系统指纹（主动或被动）来查找 LAN 的几何结构。

 

9.Evil-Ssdp

该工具响应 SSDP 多播发现请求，伪装成本地网络上的通用 UPNP 设备。您的欺骗设备将神奇地出现在本地网络中计算机上的 Windows 资源管理器中。想要打开设备的用户会看到一个可配置的网页。

 

10.Exe2hexbat

一个 Python 脚本，用于将 Windows PE 可执行文件转换为批处理文件，反之亦然。

 

11.Exifprobe

Exifprobe 读取数码相机生成的图像文件（包括几种所谓的“原始”文件格式）并报告文件的结构以及其中包含的辅助数据和元数据。

 

除了 TIFF、JPEG 和 EXIF，该程序还可以识别可能包含“原始”相机数据的多种格式，包括 MRW、CIFF/CRW、JP2/JPEG2000、RAF 和 X3F，以及大多数 TIFF 衍生的“原始”格式，包括 DNG、ORF、CR2、NEF、K25/KDC/DCR 和 PEF。

 

该程序在取证调查中很有用。

 

12.Exiv2

Exiv2 是一个 C++ 库和一个命令行实用程序，用于管理图像元数据。它提供对各种格式图像的 Exif、IPTC 和 XMP 元数据的快速、轻松的读写访问

 

Exiv2 命令行实用程序用于：

 

  •  以不同格式打印 Exif、IPTC 和 XMP 图像元数据：

  • 每个标签的 Exif 摘要信息、解释值或纯数据

  •  从命令行修改命令或命令脚本设置、添加和删除 Exif、IPTC 和 XMP 图像元数据

  •  调整 Exif 时间戳（这就是一切的开始……）

  •  根据 Exif 时间戳重命名 Exif 图像文件

  •  提取、插入和删除 Exif、IPTC 和 XMP 元数据以及 JPEG 注释

  •  从 Exif 元数据中提取 RAW 图像和缩略图的预览

  •  插入和删除嵌入在 Exif 元数据中的缩略图

  •  打印、设置和删除 JPEG 图像的 JPEG 注释

  •  修复使用佳能和尼康相机拍摄的照片的 Exif ISO 设置

 

Exiv2 库提供：

 

  •  对图像的 Exif、IPTC 和 XMP 元数据的快速读写访问

  •  易于使用且文档齐全的 API

  •  Exif 和 IPTC 元数据到 XMP 的转换，反之亦然

  •  一种智能 IPTC 实现，不会影响 Photoshop 等程序存储在同一图像段中的数据

  •  Exif Makernote 支持：

  • Makernote 标签可以像任何其他元数据一样读取和写入

  • 复杂的写入算法可避免损坏 Makernote

  •  一个简单的界面，用于提取嵌入在 RAW 图像和 Exif 缩略图中的预览

  •  Exif 缩略图的设置和删除方法

 

13.Expect

Expect 是一种根据脚本自动化交互式应用程序的工具。按照脚本，Expect 知道可以从程序中得到什么以及正确的响应应该是什么。Expect 也可用于测试这些相同的应用程序。通过添加 Tk，您还可以在 X11 GUI 中包装交互式应用程序。解释型语言提供分支和高级控制结构来指导对话。此外，用户可以在需要时直接进行控制和交互，然后将控制权返回给脚本。

 

14.Exploitdb

ExploitDB 是一个面向全世界黑客的漏洞提交平台，该平台会公布最新漏洞的相关情况，这些可以帮助企业改善公司的安全状况，同时也以帮助安全研究者和渗透测试工程师更好的进行安全测试工作。Exploit-DB提供一整套庞大的归档体系，其中涵盖了各类公开的攻击事件、漏洞报告、安全文章以及技术教程等资源。

 

利用漏洞数据库中的可搜索存档。

 

15.Exploitdb-Bin-Sploits

利用漏洞数据库中的可搜索二进制漏洞

 

16.Exploitdb-Papers

利用数据库中的可搜索论文和电子杂志档案。

 

17.Ext3grep

ext3grep 是一个简单的工具，旨在帮助那些不小心删除了 ext3 文件系统上的文件的人，之后不久才发现他们想要它。

 

这个包在取证调查中很有用。

 

18.Ext4magic

ext4magic 是一个文件雕刻器（或文件雕刻）。它可用于灾难恢复或数字取证活动。

 

ext3/4 文件系统中的文件删除不能轻易逆转。将 inode 中的块引用清零使得这不可能。使用其他程序的经验证明，可以直接从文件系统日志中恢复足够的信息来恢复许多数据文件。

 

如果日志中的信息足够，ext4magic 可以从日志中提取信息并还原整个目录树中的文件。

 

此工具可以恢复大多数文件类型，包括原始文件名、所有者和组、文件模式位以及旧的 atime/mtime 标记。

 

19.Extundelete

extundelete 使用存储在分区日志中的信息来尝试恢复已删除的文件。不能保证任何特定文件都能够被取消删除。

 

20.Eyewitness

EyeWitness 旨在截取网站的屏幕截图，提供一些服务器标头信息，并在可能的情况下识别默认凭据。

 

EyeWitness 被设计为在 Kali Linux 上运行。它将自动检测您使用 -f 标志提供给它的文件，该文件是一个文本文件，每行上都有URL、nmap xml输出或nessus xml输出。-t（timeout）标志是完全可选的，允许您在尝试呈现和截屏网页时提供最大等待时间。–open 标志是可选的，它将在 Firefox 中的新选项卡中打开 URL。
