1. mac-robber

    mac robber是一种数字调查工具（数字取证），它从已装入的文件系统中分配的文件中收集元数据。这在分析带电系统或在实验室分析死机系统时的事件响应期间非常有用。数据可由侦探工具包（仅TSK或侦探工具包）中的mactime工具用于创建文件活动的时间线。mac robber工具基于TCT（验尸官工具包）中的盗墓工具。

MacRobber要求文件系统由操作系统装载，这与Sleuth工具包中处理文件系统本身的工具不同。因此，mac robber不会从已删除的文件或rootkit隐藏的文件中收集数据。mac robber还将修改具有写权限的目录的访问时间。

mac robber在处理Sleuth工具包或其他文件系统分析工具不支持的文件系统时非常有用。您可以在一个模糊、可疑的UNIX文件系统上运行mac robber，该文件系统已以只读方式安装在受信任的系统上。

 

    如何安装：sudo apt install mac-robber


2. Macchanger

    GNU MAC转换器是一种使网络接口MAC地址的计算更容易的实用程序。MAC地址是网络上唯一的标识符，它们只需要唯一，在大多数网络硬件上都可以更改。不择手段的营销公司、政府机构和其他机构已经开始滥用MAC地址，以提供一种跨多个网络跟踪计算机的简便方法。通过定期更改MAC地址，这种跟踪可能会受阻，或者至少会变得更加困难。

特征：

  •  设置网络接口的特定MAC地址

  •  随机设置MAC

  •  设置另一供应商的MAC

  •  设置同一供应商的另一个MAC

  •  设置相同类型的MAC（例如：无线网卡）

  •  显示可供选择的供应商MAC列表（目前为6200项）

 

    如何安装：sudo apt install macchanger


3. Magicrescue

    Magic Rescue扫描一个块设备，寻找它知道如何恢复的文件类型，并调用一个外部程序来提取它们。它查看文件内容中的“魔法字节”（文件模式），因此它既可以用作取消删除实用程序，也可以用于恢复损坏的驱动器或分区。只要文件数据存在，它就会找到它。

Magic Rescue使用名为“配方”的文件。这些文件具有字符串和命令，用于从设备或取证图像中识别和提取数据。所以，你可以自己写食谱。目前，有以下配方：avi、佳能cr2、elf、flac、gpl、gzip、jpeg exif、jpeg jfif、mbox、mbox mozilla收件箱、mbox mozilla sent、mp3-id3v1、mp3-id3v2、msoffice、尼康raw、perl、png、ppm、sqlite和zip。

此软件包提供magicrescue、dupemap和magicsort命令。magicrescue是一名雕刻师，在法医调查中很有用。

 

    如何安装：sudo apt install magicrescue

  

4. Maltego

    Maltego是一个开源的情报和取证应用程序。它将为您提供大量的信息挖掘和收集，并以易于理解的格式表示这些信息。

此软件包取代以前的软件包matlegoce和casefile。

    

    如何安装：sudo apt install maltego


5. Maskprocessor

    Maskprocessor是一个快速单词列表生成器。它枚举给定用户定义的键空间中的所有组合，并输出结果。由于它在生成模板（“掩码”）的不同位置支持不同的字母表（也可以组合），因此这种方法允许比使用“朴素”的强力单词枚举更精细地生成候选字母。使用Hashcat密码恢复实用程序中也使用的描述定义掩码。

    

    如何安装：sudo apt install maskprocessor


6. Masscan

MASSCAN是TCP端口扫描程序，它异步传输SYN数据包，并产生与最著名的端口扫描程序nmap类似的结果。在内部，它更像scanrand、unicornscan和ZMap，使用异步传输。它是一个灵活的实用程序，允许任意地址和端口范围。

 

如何安装：sudo apt install masscan


7. Massdns

这个软件包包含一个简单的高性能DNS存根解析器，目标是那些试图解析数以百万甚至数十亿计的大量域名的人。没有特殊配置，MassDNS能够使用公开可用的解析程序每秒解析350000多个名称。

 

如何安装：sudo apt install massdns


8. Mc

    GNU Midnight Commander是一个文本模式全屏文件管理器。它使用一个双面板接口和一个子shell来执行命令。它包括一个带语法高亮显示的内部编辑器和一个支持二进制文件的内部查看器。还包括虚拟文件系统（VFS），它允许远程系统上的文件（如FTP、SSH服务器）和档案中的文件像真实文件一样进行操作。

 

如何安装：sudo apt install mc


9. Mdbtools

(1) libmdb3

        用于以编程方式访问JET/MS Access数据库（MDB）文件的核心库。

例如，允许将MDB文件与PHP一起使用。

 

        如何安装：sudo apt install libmdb3

 

(2) libmdbsql3

       在libmdb上构建的库提供了一个用于读取JET/msaccess数据库（MDB）文件的SQL引擎。请参阅mdbtools包中的mdb sql util。

 

       如何安装：udo apt install libmdbsql3

 

(3) Mdbtools

        以下是用于操作JET/MS Access数据库（MDB）文件的各种工具：

l utils-提供命令行实用程序来列出表、导出架构和数据、显示文件版本以及其他有用的内容。

l mdb sql—一种命令行sql工具，允许键入sql查询并获取结果。

   

        如何安装：、sudo apt install mdbtools

 

(4) mdbtools-dev

        用于读取MS Access数据库（MDB）文件的实用程序这些是mdbtools的开发文件，需要它来构建应用程序。

        

        如何安装：sudo apt install mdbtools-dev

 

(5) mdbtools-doc

        这是一个过渡方案。它可以安全地移除。请参阅程序包libmdb3文档。

        

        如何安装：sudo apt install mdbtools-doc

 

(6) odbc-mdbtools

        这是通过ODBC访问JET/MS access数据库（MDB）文件的软件驱动程序。这还包含unixodbc的安装接口。

 

        如何安装：sudo apt install odbc-mdbtools


10. Mdk3

    MDK是利用常见IEEE 802.11（Wi-Fi）协议弱点的概念验证工具。特征：

  •  蛮力MAC过滤器。

  •  Bruteforce隐藏的SSID（包括一些小型SSID字表）。

  •  探测网络，检查他们是否能听到你的声音。

  •  用于冻结AP的智能身份验证DoS（带有成功检查）。

  •  伪造-信标泛洪与频道跳跃（可以崩溃NetStumbler和一些有轨电车司机）

  •  断开所有具有取消身份验证和解除关联数据包的连接（又名AMOK-MODE）。

  •  WPA TKIP拒绝服务。

  •  WDS混乱-关闭大规模多AP安装。

 

如何安装：sudo apt install mdk3


11. mdk4

    此软件包包含一个概念验证工具，用于利用常见的IEEE 802.11协议弱点。

MDK4是MDK3的新版本。MDK4是来自360PegasusTeam的E7mer、k2wrlz的ASPj的Wi-Fi测试工具，它使用aircrack ng项目的osdep库在多个操作系统上注入帧。

重要提示：在对其运行MDK之前，您有责任确保获得网络所有者的许可。

 

如何安装：sudo apt install mdk4


12. Medusa

Medusa旨在成为一个快速，大规模并行，模块化，登录蛮力。目标是支持尽可能多的允许远程身份验证的服务。作者认为以下项目是该应用程序的一些关键特性：*基于线程的并行测试。可以同时对多台主机、用户或密码执行暴力测试。*灵活的用户输入。可以通过多种方式指定目标信息（主机/用户/密码）。例如，每个项目可以是单个条目，也可以是包含多个条目的文件。此外，组合文件格式允许用户优化其目标列表。*模块化设计。每个服务模块都作为一个独立的.mod文件存在。这意味着无需对核心应用程序进行任何修改即可扩展受支持的暴力强制服务列表。

 

如何安装：sudo apt install medusa


13. Memdump

    将系统内存转储到标准输出流的程序，跳过内存映射中的漏洞。默认情况下，程序转储物理内存的内容。

如果内核中启用了CONFIG_STRICT_DEVMEM，该程序将无法工作。从2.6版本开始，默认情况下有几个内核启用此选项。

memdump在安全测试和取证调查中非常有用。

 

如何安装：sudo apt install memdump


14. Mercurial

    Mercurial是一个快速、轻量级的源代码管理系统，旨在高效处理大型分布式项目。

其特点包括：

  •  增量压缩文件存储和检索方案

  •  完成文件和变更集的交叉索引，以有效探索项目历史

  •  健壮的基于SHA1的完整性检查和仅附加存储模型

  •  树间任意合并的分散开发模型

  •  基于HTTP的高速网络合并协议

  •  易于使用的命令行界面

  •  集成的独立web界面

  •  小型Python代码库

此包包含与体系结构相关的文件。

 

    如何安装：sudo apt install mercurial


15. Metacam

    EXIF（可交换图像文件格式）是一种标准，用于在图像文件中存储交换信息，尤其是使用JPEG压缩的图像文件。大多数数码相机，包括手机，现在都使用EXIF格式。

该格式是JEIDA创建的DCF标准的一部分，旨在鼓励成像设备之间的互操作性。除了标准EXIF字段外，MetaCam还支持尼康、奥林巴斯、佳能和卡西欧的供应商特定扩展。

这个程序在法医调查中很有用。

    

    如何安装：sudo apt install metacam


16. Metagoofil

    Metagoofil是一种信息收集工具，用于提取属于目标公司的公共文档（pdf、doc、xls、ppt、docx、pptx、xlsx）的元数据。

Metagoofil将在Google中执行搜索，以识别文档并将其下载到本地磁盘。Metagoofil不再提取元数据。请参阅/usr/share/doc/metagoofil/README.md.gz。

 

如何安装：sudo apt install metagoofil


17. metasploit-framework

    Metasploit框架是一个开源平台，支持漏洞研究、漏洞利用开发和定制安全工具的创建。

 

    如何安装：sudo apt install metasploit-framework


18. Mfcuk

    工具包包含基于libnfc和crapto1的示例和各种工具，重点是Mifare经典NXP/Philips RFID卡。工具包特别强调以下内容：

l mifare经典弱点演示/利用

l 演示libnfc（和ACR122读卡器）的使用

l 演示如何使用Crapto1实现来确认内部工作并验证理论/实践弱点/攻击。

 

    如何安装：sudo apt install mfcuk


19. Mfoc

    MFOC是Nethemba“离线嵌套”攻击的开源实现。该程序允许从MIFARE Classic卡恢复身份验证密钥。请注意，只有当目标具有已知密钥时，MFOC才能从目标恢复密钥：默认密钥（在MFOC中硬编码）或自定义密钥（用户使用命令行提供）。

    

    如何安装：69 KB sudo apt install mfoc


20. Mfterm

    mfterm是用于处理Mifare经典标记的终端接口。命令上的制表符完成可用。此外，具有文件名参数的命令提供文件的制表符完成。还有一个命令历史记录，就像在大多数普通shell中一样。

   

 如何安装：107 KB sudo apt install mfterm


21. Mimikatz

    Mimikatz在Windows上使用管理员权限以明文形式显示当前登录用户的密码。

    

   如何安装：sudo apt install mimikatz


22. Minicom

Minicom是MS-DOS“Telix”通信程序的克隆。它模拟ANSI和VT102终端，具有拨号目录和自动zmodem下载。

 

如何安装：sudo apt install minicom


23. Miredo

    Teredo IPv6隧道协议将IPv6数据包封装到UDP/IPv4数据报中，以允许NAT设备后面的主机访问IPv6 Internet。

Miredo是Teredo客户端（根据RFC 4380）：它可以提供到双栈IPv6/IPv4主机的IPv6连接，即使它位于NAT后面。它还可以作为Teredo中继，在IPv6 Internet和远程Teredo客户端之间转发IPv6数据包。

     

如何安装：sudo apt install miredo

 

(1) miredo-server

            Teredo IPv6隧道协议将IPv6数据包封装到UDP/IPv4数据报中，以允许NAT设备后面的主机访问IPv6 Internet。

Miredo服务器提供Teredo服务器。Teredo服务器帮助Teredo客户端确定其NAT配置，维护其NAT绑定，并在将IPv6数据包传输到其他Teredo客户端和/或Teredo中继时执行穿孔。

 

如何安装：sudo apt install miredo-server


24. Missidentify

    Miss Identity（MissIdentity）是一个查找MS Windows类型win32应用程序的程序。默认情况下，它显示没有扩展名的任何可执行文件的文件名，如exe、dll、com、sys、cpl、hxs、hxi、olb、rll或tlb。它还可以显示所有可执行文件，而不考虑扩展名。

识别失误在法医调查中很有用。

    

    如何安装：sudo apt install missidentify


25. Mitmproxy

    mitmproxy是一个支持SSL的中间人HTTP代理。它提供了一个控制台界面，允许动态检查和编辑交通流。

还提供了mitmdump，它是mitmproxy的命令行版本，具有相同的功能，但没有装饰。想想HTTP的tcpdump。

特征：

l 实时拦截和修改HTTP流量

l 保存HTTP对话以供以后重播和分析

l 重播HTTP客户端和服务器

l 使用Python对HTTP流量进行脚本化更改

l 动态生成的SSL拦截证书

 

    如何安装：sudo apt install mitmproxy


26. Msfpc

    使用msfvenom生成各种“基本”流量计有效载荷的快速方法，msfvenom是Metasploit框架的一部分。

 

   如何安装：sudo apt install msfpc

27. Multimac

    Multimac是一个linux虚拟以太网tap分配器，用于使用单个网络适配器在LAN上模拟和使用多个虚拟接口（具有不同的MAC地址）。

    

    如何安装：sudo apt install multimac


28. multimon-ng

    multimon的后续产品，支持更多模式，并改进了与moderns系统的兼容性。它对VHF/UHF频段上常见的以下数字传输模式进行解码：

POCSAG512 POCSAG1200 POCSAG2400 FLEX EAS UFSK1200 CLIPFSK AFSK1200 AFSK2400 AFSK2400_2 AFSK2400_3 HAPN4800 FSK9600 DTMF ZVEI1 ZVEI2 ZVEI3 DZVEI PZVEI EEA EIA CCIR MORSE CW X10

多个解码器可以在同一信号上同时运行，该信号通过文件或管道提供。常见设置有：通过声卡连接的收音机（可能需要对收音机进行修改）；通过GNU无线电接收器或gqrx中的UDP音频流（通过netcat和sox）提供的样本。

 

    如何安装：sudo apt install multimon-ng


29. Myrescue

    myrescue是一个程序，用于从损坏的硬盘、CD-ROM、DVD、闪存驱动器等中拯救仍然可读的数据。它的目的类似于dd_rescue（或ddrescue），但它尝试快速走出损坏区域，首先处理磁盘中尚未损坏的部分，然后返回。

此软件包可用于从任何媒体恢复数据和进行取证调查。

   

  如何安装：sudo apt install myrescue

 

30. Mysql-Defaults

(1) default-libmysqlclient-dev

MySQL是一个快速、稳定、真正的多用户、多线程SQL数据库服务器。SQL（结构化查询语言）是世界上最流行的数据库查询语言。MySQL的主要目标是速度、健壮性和易用性。

这个包依赖于客户端开发库和头文件（由MySQL定义的API和ABI）的默认实现。根据此元包定义的默认值，底层实现可能由MySQL或MariaDB提供。构建依赖于此包，然后使用-lmysqlclient链接。最终得到的二进制文件取决于libmysqlclient.so.X或libmariadbclient.so.X，具体取决于当前默认值。dpkg shlibdeps应根据需要正确生成对libmysqlclientX或libmariadbclientX的依赖项。

 

       如何安装：sudo apt install default-libmysqlclient-dev

 

(2) default-libmysqld-client

    MySQL是一个快速、稳定、真正的多用户、多线程SQL数据库服务器。SQL（结构化查询语言）是世界上最流行的数据库查询语言。MySQL的主要目标是速度、健壮性和易用性。

此包取决于客户端二进制文件的默认实现以及innotop和mysqlreport的附加工具。

 

如何安装：sudo apt install default-libmysqld-client

 

(3) default-mysql-client-core

    MySQL是一个快速、稳定、真正的多用户、多线程SQL数据库服务器。SQL（结构化查询语言）是世界上最流行的数据库查询语言。MySQL的主要目标是速度、健壮性和易用性。

这个包依赖于Akonadi使用的核心客户机文件的默认实现。

 

如何安装：sudo apt install default-mysql-client-core

 

(4) default-mysql-server

    MySQL是一个快速、稳定、真正的多用户、多线程SQL数据库服务器。SQL（结构化查询语言）是世界上最流行的数据库查询语言。MySQL的主要目标是速度、健壮性和易用性。

此包取决于设置系统数据库所需的所有基础结构的默认实现。

 

如何安装：sudo apt install default-mysql-server

 

(5) default-mysql-server-core

        MySQL是一个快速、稳定、真正的多用户、多线程SQL数据库服务器。SQL（结构化查询语言）是世界上最流行的数据库查询语言。MySQL的主要目标是速度、健壮性和易用性。

此包依赖于服务器二进制文件的默认实现，但不依赖于设置系统数据库所需的所有基础结构。

 

如何安装：sudo apt install default-mysql-server-core

 

(6) mysql-common

    MySQL是一个快速、稳定、真正的多用户、多线程SQL数据库服务器。SQL（结构化查询语言）是世界上最流行的数据库查询语言。MySQL的主要目标是速度、健壮性和易用性。

此包包括所有版本的客户端库所需的文件，例如/etc/mysql/my.cnf。

 

如何安装：sudo apt install mysql-common
