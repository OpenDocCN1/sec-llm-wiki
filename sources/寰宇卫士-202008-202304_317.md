# CTF练习之Secret File

今天做了一道非常好玩的题，它是BUU web系列的secret file练习题，当我们启动靶机后进入页面后看见：

 

![](../Images/8a8aaf91c977d2217dd1eec9c236da08.png)

  

蒋璐源的秘密？咋一看完全没有思路，让我们看看网页元素：

![](../Images/d1c0aa3c0b40b5744f0f0f96a0ff3c0a.png)

   

发现网页元素里面有一个a标签的链接，我们打开看一看！

![](../Images/4faad35c49d94b1e85c0c96a263464f9.png)

   

顺着网页，继续点击secret：

![](../Images/37a7a5c0dc7fb0527238ca85a3136e49.png)

   

发现没有什么提示，查看前一个和后一个网页的元素也没有隐藏的链接，怎么办？

只能试一试brup抓包看一看了，因为点击第二个网页是自动重定向了，感觉数据包里面会有提示。

 

![](../Images/abf39b003081dfc2b78613187ca157a0.png)

  

果不其然，查看response有一个秘密网址，我们拼接到路径上看一看：

  

![](../Images/fefb8d2913b36e40b6b3b129438c7f72.png)  

哦吼！找到这个题目的源码了，总是可以开始解题了；咋一看是文件包含的题目，因为它有include函数，它还过滤了input,data常见的伪协议，这可咋整？等等，它没有过滤filter关键字！

Php://filter与文件包含函数结合时，php://filter流会被当作php文件执行，一般对其编码，阻止其不执行，从而导致任意文件读取；在加上read=convert.base64-encode，用base64编码输出，这样就可以防止当成php代码执行，从而爆出flag！所以我们的payload是：

?file=php://filter/read=convert.base64-encode/resource=flag.php

![](../Images/105b84b7dc91ed2dc5defc080f680f14.png)

输入payload后爆出了base64编码的字符串，我们复制下来，用一个在线编辑php网址，编写一下解码脚本，就可以看到flag了！

 

![](../Images/4cc53d476cfeca093b993a964678a313.png)

   

不得不说这一题虽然难道不怎么大，但是很考验知识面，需要找到真正的做题页面才能开始解题，很不错的一道题！
