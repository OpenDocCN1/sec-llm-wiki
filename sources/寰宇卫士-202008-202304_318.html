7. Libnfc

    libnfc是一个近场通信库。它在易于使用的高级API后面抽象出与设备通信的低级细节。它支持大多数基于NXP PN531、PN532或PN533控制器芯片的硬件。

9. linux-exploit-suggester

    此软件包包含Linux权限升级审核工具。它旨在帮助检测给定Linux内核/基于Linux的机器的安全缺陷。它提供以下功能：

l 评估公开攻击的内核暴露工具（使用本文详细讨论的启发式方法）评估给定内核在每个公开的Linux内核攻击中的暴露。对于每个漏洞，计算暴露

l 验证内核强化安全措施的状态LES可以检查Linux内核提供的大多数安全设置。它不仅验证内核编译时配置（CONFIGs），还验证运行时设置（sysctl），从而更全面地了解运行内核的安全状态。这个功能是Tobias Klein的checksec.sh工具的内核切换的现代延续。

11. Lvm2

(1) dmeventd

        Linux内核设备映射器是LVM（Linux逻辑卷管理）团队实现的一个最小内核空间驱动程序，它处理卷管理，同时保持对用户空间中底层设备布局的了解。这使得它不仅适用于LVM，而且适用于软件raid和其他创建“虚拟”块设备的驱动程序。

此包包含一个守护进程，用于监视devmapper设备的事件。

 

如何安装：sudo apt install dmeventd

 

(2) Dmsetup

此软件包包含用于修改设备映射的实用程序。

 

    如何安装：sudo apt install dmsetup

 

(3) libdevmapper-dev

此包包含用于访问设备映射器的（用户空间）头文件；它允许通过干净、一致的接（而不是通过内核ioctl）使用设备映射器。

 

如何安装：sudo apt install libdevmapper-dev
