2. kali-defaults

这个包在Kali中实现了各种默认设置。这个包的大小（包括它的依赖项）应该相当有限，因为它包含在所有Kali图像中，即使是docker图像这样的极简图像中。

 

如何安装：sudo apt install kali-defaults

5. Kali-Wallpapers

(1) kali-legacy-wallpapers

        该软件包已更名为kali Wallpers legacy，现在是kali Wallpers源软件包的一部分。一旦在系统上安装kali Wallpaps legacy，就可以安全地删除此虚拟包。

        

        如何安装：sudo apt install kali-legacy-wallpapers

 

(2) kali-wallpapers-2019.4

        此软件包包含多个墙纸，这些墙纸在2019.4版和2020.3版之间的Kali Linux中使用。

如果您的系统上有多个kali墙纸YYYY.X软件包，则可以将其全部删除，但最新的软件包除外，该软件包是kali主题通用的依赖项，因此是必需的。

    

如何安装：sudo apt install kali-wallpapers-2019.4

 

(3) kali-wallpapers-2021.4

        此软件包包含用于Kali Linux 2021.4及未来版本的多张墙纸。如果您的系统上有多个kali墙纸YYYY.X软件包，则可以将其全部删除，但最新的软件包除外，该软件包是kali主题通用的依赖项，因此是必需的。

        

        如何安装：sudo apt install kali-wallpapers-2020.4

 

(4) kali-wallpapers-all

        此元包依赖于所有kali墙纸-*包，提供用于回溯和kali Linux的所有墙纸

        

        如何安装：sudo apt install kali-wallpapers-all

(5) kali-wallpapers-legacy

        回溯和Kali Linux多年来使用的壁纸和资源，用于怀旧的化妆品价值

9. Knocker

Kismet是一个无线网络和设备检测器、嗅探器、监护工具和WIDS（无线入侵检测）框架。Kismet与Wi-Fi接口、蓝牙接口、一些SDR（软件定义无线电）硬件（如RTLSDR）以及其他专用捕获硬件配合使用。这是一个包含kismet工具的元包。

 

如何安装：sudo apt install knocker


10. Koadic

Knocker是一个新的、简单的、易于使用的TCP安全端口扫描程序，使用线程，用C编写。它能够分析主机及其上运行的网络服务。

 

如何安装：sudo apt install koadic
