1.Safecopy

Safecopy尝试从源获取尽可能多的数据，甚至在适用的情况下求助于特定于设备的低级别操作。这是通过识别有问题或损坏的区域，跳过它们，然后继续阅读来实现的。目标文件中的相应区域要么被跳过（在初始创建时，这意味着用零填充），要么故意用可识别的模式填充，以便稍后在损坏的设备上查找受影响的文件。该工作类似于ddrescue，生成原始媒体的图像。这种介质可以是软盘、硬盘分区、CD、DVD、磁带设备，在这些介质中，其他工具（如dd）会由于I/O错误而失败。

Safecopy使用增量算法来确定坏区的确切开始和结束，允许用户用对坏区的最少访问来换取彻底的数据恢复。

在同一个文件上进行多次传递是可能的，首先从设备中检索尽可能多的数据，并将危害降到最低，然后尝试检索一些剩余的数据，并进行越来越积极的读取尝试。

Safecopy包括一个低级I/O层，用于在原始模式下读取CDROM磁盘，并在许多其他设备类上执行设备重置和其他有用的低级操作。

Safecopy在取证调查和灾难恢复中非常有用。

3.Samba

Ctdb

CTDB 是 Samba 等项目用来存储临时数据的 TDB 数据库的集群实现。如果一个应用程序已经在使用 TDB 来处理临时数据，那么很容易将该应用程序转换为集群感知并使用 CTDB 来代替。

CTDB 提供与 TDB 相同类型的功能，但采用集群方式，提供跨集群中多个物理主机的 TDB 风格的数据库。

功能包括：

CTDB 提供了一个 TDB，它在集群中的所有节点之间具有一致的数据和一致的锁定。

CTDB 非常快。

如果节点发生故障，CTDB 将自动恢复和修复其管理的所有 TDB 数据库。

CTDB 是为 Samba3/4 提供 pCIFS（“并行 CIFS”）的核心组件。

CTDB提供节点监控、节点故障转移、IP接管等HA特性。

CTDB 提供可靠的消息传输，以允许与 CTDB 链接的应用程序与在集群中不同节点上运行的应用程序的其他实例进行通信。

CTDB 具有可插拔的传输后端。当前实现的后端是 TCP 和 Infiniband。

CTDB 支持特定于应用程序的管理脚本系统，允许在集群上以高可用性方式管理依赖于网络或文件系统资源的应用程序。

8.Samdump2

此工具旨在使用系统配置单元中的syskey引导密钥从SAM文件中转储 Windows 2k/NT/XP 密码哈希。

该软件包还提供了 bkhive 的功能，它可以从 Windows NT/2K/XP 系统配置单元中恢复 syskey 引导密钥。

9.Sbd

sbd是一个Netcat克隆，设计为可移植，并提供强大的加密功能。它在类Unix操作系统和Microsoft Win32上运行。sbd具有AES-CBC-128+HMAC-SHA1加密（由Christophe Devine编写）、程序执行（-e选项）、选择源端口、带延迟的连续重新连接以及其他一些不错的功能。sbd仅支持TCP/IP通信。

 

10.Scalpel

手术刀是一个快速的文件雕刻器，它读取页眉和页脚定义的数据库，并从一组图像文件或原始设备文件中提取匹配的文件。

手术刀与文件系统无关，可以从 FAT16、FAT32、exFAT、NTFS、Ext2、Ext3、Ext4、JFS、XFS、ReiserFS、原始分区等中雕刻文件。

手术刀是对 Foremost 0.69 文件雕刻器的完全重写，可用于数字取证调查和文件恢复。

  

11.Scapy

python3-scapy

Scapy 是一个强大的交互式数据包操作工具，数据包生成器，网络扫描器，网络发现，数据包嗅探器等。它目前可以替代 hping、85% 的 nmap、arpspoof、arp-sk、arping、tcpdump、tethereal、p0f、 ……

在 scapy 中，您定义一组数据包，然后发送它们，接收答案，将请求与答案匹配并返回数据包对（请求，答案）列表和未匹配数据包列表。与 nmap 或 hping 等工具相比，这具有很大的优势，即答案不会简化为（打开/关闭/过滤），而是整个数据包。

这个包包含库的 Python 3 版本和 scapy 可执行文件。

  

12.Screen

GNU Screen 是一个终端多路复用器，它在单个基于字符的物理终端上运行多个单独的“屏幕”。每个虚拟终端模拟一个 DEC VT100 加上几个 ANSI X3.64 和 ISO 2022 功能。屏幕会话可以分离并稍后在不同的终端上恢复。

Screen 还支持一系列其他功能，包括可配置的输入和输出转换、串行端口支持、可配置的日志记录和多用户支持。

21.Shellter

Shellter 是一个动态 shellcode 注入工具，又名动态 PE 感染器。它可用于将 shellcode 注入本机 Windows 应用程序（目前仅限 32 位应用程序）。shellcode 可以是你的东西，也可以是通过框架生成的东西，比如 Metasploit。

Shellter 利用 PE 文件的原始结构并且不应用任何修改，例如更改部分中的内存访问权限（除非用户想要），添加具有 RWE 访问权限的额外部分，以及在 AV 下看起来不可靠的任何内容扫描。

24.Siege

Siege 是一个回归测试和基准实用程序。它可以使用用户定义的模拟用户数量对单个 URL 进行压力测试，也可以将多个 URL 读入内存并同时对它们进行压力测试。该程序报告记录的命中总数、传输的字节数、响应时间、并发性和返回状态。Siege 支持 HTTP/1.0 和 1.1 协议、GET 和 POST 指令、cookie、事务日志和基本身份验证。其功能可根据每个用户进行配置。

62.Statsprocessor

Statsprocessor 是一个基于每个位置的马尔可夫链的单词生成器，它被打包成一个独立的二进制文件。它基于 Hashcat 格式的 .hcstat 文件生成候选词，通过使用此信息根据用于生成 .hcstat 的原始输入字典的分析来确定哪个字母跟在哪个字母之后。例如，生成的单词可以进行后处理并输入 Hashcat 或其他密码恢复工具。

64.Steghide

Steghide 是一种隐写术程序，它将数据文件的某些位隐藏在另一个文件的一些最低有效位中，从而使数据文件的存在不可见且无法证明。

Steghide 被设计为可移植和可配置的，具有在 bmp、jpeg、wav 和 au 文件中隐藏数据、blowfish 加密、密码短语的 MD5 散列到河豚密钥以及容器数据中隐藏位的伪随机分布的特点。

Steghide 在数字取证调查中很有用。

65.Stegsnow

此实用程序可以通过在行尾附加空格来隐藏 ASCII 文本中的消息。由于空格和制表符在文本查看器中通常不可见，因此对于临时观察者而言，该消息实际上是隐藏的。如果使用内置加密，即使检测到消息也无法读取。

关于名称：在文本中定位尾随空格就像在暴风雪中找到北极熊。并且它使用了ICE加密算法，所以名字在主题上是一致的。

该软件包可用于个人安全、取证调查和其他操作。

  

66.Stunnel4

stunnel 程序旨在用作远程客户端和本地（inetd-startable）或远程服务器之间的 SSL 加密包装器。这个概念是在您的系统上运行非 SSL 感知守护程序，您可以轻松设置它们以通过安全 SSL 通道与客户端通信。

stunnel 可用于将 SSL 功能添加到常用的 inetd 守护程序，如 POP-2、POP-3 和 IMAP 服务器，而无需对程序代码进行任何更改。

这个包包含一个与 stunnel 3.x 兼容的包装脚本

Subfinder

67.Subjack

该软件包包含一个用 Go 编写的子域接管工具，旨在同时扫描子域列表并识别能够被劫持的子域。凭借 Go 的速度和效率，该工具在大规模测试方面确实脱颖而出。始终手动仔细检查结果以排除误报。

Subjack 还将检查附加到不存在的域 (NXDOMAIN) 并且可以注册的子域。

  

68.Sublist3r

该软件包包含一个 Python 工具，旨在使用 OSINT 枚举网站的子域。它可以帮助渗透测试人员和漏洞猎人收集和收集他们所针对的域的子域。Sublist3r 使用许多搜索引擎（例如 Google、Yahoo、Bing、Baidu 和 Ask）枚举子域。Sublist3r 还使用 Netcraft、Virustotal、ThreatCrowd、DNSdumpster 和 ReverseDNS 枚举子域。

由于 subbrute 的作者 TheRook，Subbrute 与 Sublist3r 集成在一起，以增加使用 bruteforce 和改进的词表查找更多子域的可能性。

70.Subversion

Apache Subversion，也称为 svn，是一个集中的版本控制系统。版本控制系统允许许多人（可能分布在不同的地理区域）在一组文件（源代码、网站等）上进行协作。Subversion 以 CVS 范式开始，支持 CVS 的所有主要功能，但已经发展到支持 CVS 用户通常希望他们拥有的许多功能。

该软件包包括 Subversion 客户端（svn、svnsync）、存储库管理工具（svnadmin、svnlook）和网络服务器（svnserve）。

 

subversion-tools

该软件包包括用于 Apache Subversion 客户端和服务器的各种工具：

svn-backup-dumps：基于转储文件的增量备份脚本

svn-bisect：二等分修正以找到回归

svn-clean：从工作副本中删除未版本控制的文件

svn-hot-backup：备份脚本，主要用于 BDB 存储库

svn_apply_autoprops：将 .subversion/config 文件中的属性设置应用到现有存储库

svn_load_dirs: 'svn import' 的高级替换

svnwrap：在调用 svn 或 svnserve 之前将 umask 设置为 002

fsfs-access-map：将 strace 输出转换为 FSFS 访问映射

几个示例钩子脚本：commit-access-control、commit-email、log-police、mailer、svnperms、verify-po

请注意，其中一些脚本不受上游支持，并且可能会在未来版本中发生根本性变化或消失。其中一些脚本需要推荐列表中的包。

  

71.Sucrack

sucrack 是一个多线程 Linux/UNIX 工具，用于通过 wordlist bruteforcing su 破解本地用户帐户。当您获得对低权限用户帐户的访问权限但允许其他用户使用时，此工具会派上用场。许多 su 实现需要附加一个伪终端，以便从用户那里获取密码。这不能通过简单的 shell 脚本轻松实现。这个工具是用 C 写的，效率很高，可以同时尝试多次登录。

  

72.Sudo

Sudo 是一个程序，旨在允许系统管理员向用户授予有限的 root 权限并记录 root 活动。基本理念是给予尽可能少的特权，但仍然允许人们完成他们的工作。

此版本使用最少的共享库依赖项构建，如果您需要对 sudoers 的 LDAP 支持，请改用 sudo-ldap 包。

73.Swaks

swaks（瑞士军刀 SMTP）是一个用 Perl 编写的用于测试 SMTP 设置的命令行工具；它支持 STARTTLS 和 SMTP AUTH（PLAIN、LOGIN、CRAM-MD5、SPA 和 DIGEST-MD5）。swaks 允许在任何阶段停止 SMTP 对话，例如检查 RCPT TO: 而不实际发送邮件。

如果您花费太多时间来迭代“telnet foo.example 25” swaks 适合您。
