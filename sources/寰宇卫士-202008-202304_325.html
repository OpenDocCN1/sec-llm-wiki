1.Radare2

该项目旨在为逆向工程创建一个完整的、可移植的、多架构的、类似Unix的工具链。

6.Rainbowcrack

RainbowCrack是Philippe Oechslin的快速时间记忆折衷技术的一个通用实现方案。它用彩虹表破解散列。

RainbowCrack使用时间记忆折衷算法来破解散列。它不同于使用暴力算法的散列破解程序。

 

7.Rake

Rake 是一个简单的ruby构建程序，其功能类似于 make。

Rake具有以下特性：

rakefile（rakes版本的makefile）完全是用标准的Ruby语法定义的。没有可编辑的XML文件。无需担心奇怪的Makefile语法（这是一个选项卡还是一个空格？）

用户可以指定具有先决条件的任务。

Rake支持规则模式来综合隐式任务。

耙子很轻。它可以作为单个文件与其他项目一起分发。依赖于rake的项目不需要在目标系统上安装rake。

该程序可以破解zip、7z和rar文件密码。

  

9.Rcracki-Mt

rcracki_mt 是我们对 rcrack 的修改版本，它支持混合表和索引表。除此之外，它还增加了多核支持。

  

10.Rdesktop

rdesktop 是Windows NT/2000终端服务器和Windows Server 2003/2008 的开源客户端。能够本地使用其远程桌面协议(RDP)以呈现用户的 Windows 桌面。与 Citrix ICA 不同，不需要服务器扩展。

  

11.Reaver

Reaver 对接入点的 WiFi Protected Setup PIN 号执行暴力攻击。一旦找到 WPS 引脚，就可以恢复 WPA PSK，或者可以重新配置 AP 的无线设置。

  

12.Rebind

重新绑定是一种实现多记录DNS重新绑定攻击的工具。虽然这个工具最初是针对家庭路由器编写的，但它可以用于针对任何公共（非RFC1918）IP地址。

重新绑定使外部攻击者能够访问目标路由器的内部Web界面。此工具适用于在IP堆栈中实现弱端系统模型、专门配置防火墙规则以及将其Web服务绑定到路由器WAN接口的路由器。请注意，无需启用远程管理即可使此攻击生效。只需目标网络中的用户浏览到受攻击者控制或已被攻击者破坏的网站即可。 

 

13.Recon-Ng

Recon ng是一个用Python编写的功能齐全的Web侦察框架。通过独立模块、数据库交互、内置便利功能、交互式帮助和命令完成，Recon ng提供了一个强大的环境，在这个环境中，可以快速、彻底地进行基于web的开源侦察。

Recon ng的外观与Metasploit框架相似，减少了利用该框架的学习曲线。然而，情况却大不相同。Recon ng无意与现有框架竞争，因为它专门为基于web的开源侦察而设计。如果要利用此漏洞，请使用Metasploit框架。如果您想成为社会工程师，请使用社会工程师工具包。 

 

14.Recordmydesktop

该应用程序生成一个 ogg 封装的 theora-vorbis 文件。recordMyDesktop 试图通过只处理屏幕上发生变化的区域来尽可能不引人注目。

  

15.Recoverdm

recoverdm恢复具有坏扇区的磁盘。您可以恢复文件以及完整的设备。如果发现无法恢复的扇区，它会将空扇区写入输出文件并继续。

恢复CD或DVD时，程序无法在“正常模式”下读取扇区，则程序将尝试在“原始模式”下读取扇区（无错误检查等）。该工具包还有一个名为“mergebad”的实用程序，它将多个图像合并到一个图像中。

该软件包在法医调查中很有用。

  

16.Recoverjpeg

recoveryjpeg 尝试从外围设备恢复 JFIF (JPEG) 图片和 MOV 电影。如果您错误地覆盖了分区，或者如果数码相机存储卡等设备是伪造的，这可能会很有用。

这个包提供了这些可执行文件：recoverjpeg、recovermov、remove-duplicates 和 sort-pictures。remove-duplicates 可用于删除找到的重复文件。sort-pictures 可用于根据 exif 日期对图片进行排序。

这个包充当雕刻者（数据雕刻），在取证调查中很有用。

19.Redsocks

Redsocks 是一个运行在本地系统上的守护进程，它将通过远程 SOCKS4、SOCKS5 或 HTTP 代理服务器透明地建立任何 TCP 连接的隧道。它使用系统防火墙的重定向工具来拦截 TCP 连接，因此重定向是系统范围的，具有细粒度的控制，并且不依赖于LD_PRELOAD库。

Redsocks 支持隧道 TCP 连接和UDP数据包。它同时支持 SOCKS 和 HTTP 代理的身份验证。

还包括一个小型 DNS 服务器，为任何 UDP 查询返回带有“截断”标志的答案，强制解析器使用 TCP。

22.Regripper

RegRipper 是一个开源工具，用 Perl 编写，用于从注册表中提取/解析信息（键、值、数据）并将其呈现以供分析。

RegRipper 由两个基本工具组成，两者都提供类似的功能。RegRipper GUI 允许分析师选择要解析的配置单元、结果的输出文件以及针对配置单元运行的配置文件（插件列表）。当分析人员针对 hive 启动该工具时，结果将转到分析人员指定的文件中。如果分析师选择解析 System hive，他们也可能选择将结果发送到 system.txt。GUI 工具还将在与输出文件相同的目录中创建其活动的日志，使用相同的文件名但使用 .log 扩展名（即，如果输出写入 system.txt，日志将写入系统日志）。

25.Responder

该包包含应答器/多继电器、LLMNR、NBT-NS和MDNS毒药。它将根据特定的NBT-NS（NetBIOS名称服务）查询的名称后缀（请参阅：http://support.microsoft.com/kb/163409). 默认情况下，该工具将只响应文件服务器服务请求，这是针对SMB的。

这背后的理念是瞄准你的答案，在网络上更加隐蔽。这也有助于确保您不会破坏合法的NBT-NS行为。如果要回答工作站服务请求名称后缀，可以通过命令行设置-r选项。

  

26.Rfcat

Rfcat 是一个 sub GHz 分析工具。该项目的目标是减少安全研究人员创建分析未知目标所需工具的时间，以帮助对硬件进行逆向工程。

  

27.Rfdump

RFDump 是一种用于解码 RFID 标签并显示其元信息的工具：标签 ID、标签类型、制造商等。可以使用十六进制或 ASCII 编辑器显示和修改标签的用户数据存储器。此外，集成的 cookie 功能展示了公司滥用 RFID 技术来监视其客户是多么容易。RFDump 与 ACG 多标签阅读器或类似的读卡器硬件配合使用。 

 

28.Ridenum

Rid Enum 是一种 RID 循环攻击，它试图通过空会话和 SID 到 RID 枚举来枚举用户帐户。如果您指定密码文件，它会在完成枚举后自动尝试对用户帐户进行暴力破解。 


29.Rifiuti

这个包在取证调查中很有用。

  

30.Rifiuti2

Rifiuti2 分析来自 Windows 的回收站文件。Windows 回收站的分析通常在 Windows 计算机取证过程中进行。

Rifiuti2可以提取文件删除时间、被删除文件的原始路径和大小，以及被删除的文件被删除后是否已经从回收站中移出。

Rifiuti2 是对 rifiuti 的重写，它最初是为了相同的目的而编写的。然后扩展到涵盖更多功能，例如：

处理高达 Windows 10 的回收站；

处理像95、NT4和ME这样的古老窗口；

支持所有本地化版本的Windows，包括基于Unicode的版本和旧版本（使用ANSI代码页）；

支持 XML 格式的输出以及原始的制表符分隔文本。

Rifiuti2 被设计为可移植的并在命令行环境中运行。根据相关的 Windows 回收站格式选择两个程序 rifiuti 和 rifiuti-vista。 

 

31.Rkhunter

Rootkit Hunter 会扫描系统中的已知和未知 Rootkit、后门、嗅探器和漏洞。

它检查：

SHA256 哈希更改；

通常由 rootkit 创建的文件；

具有异常文件权限的可执行文件；

内核模块中的可疑字符串；

系统目录中的隐藏文件；并且可以选择在文件内扫描。

单独使用 rkhunter 并不能保证系统不会受到损害。建议运行其他测试，例如 chkrootkit。

35.Routersploit

36.Rsakeyfind

rsakeyfind 是一种在 MEMORY-IMAGE 中定位 BER 编码的 RSA 私钥的工具。如果指定了模数文件，它将找到与从该文件读取的十六进制编码模数匹配的私钥和公钥。

该软件包对多种活动很有用，例如法医调查。

  

37.Rsmangler

RSMangler 将获取一个词表并对其执行类似于开膛手John所做的各种操作，主要区别在于它将首先获取输入词并生成所有排列和词的首字母缩略词（按它们出现在文件中的顺序）在它应用其余的 mangle 之前。

  

38.Rtlsdr-Scanner

OsmoSDR rtl-sdr 库的跨平台 Python 频率扫描 GUI。

扫描器试图通过对基带数据的正负频率偏移进行平均扫描来克服调谐器的频率响应。

 

39.Rtpbreak

使用 rtpbreak，您可以检测、重建和分析任何 RTP 会话。它不需要 RTCP 数据包的存在，并且独立于使用的信令协议（SIP、H.323、SCCP 等）工作。输入是一个数据包序列，输出是一组文件，您可以将其用作其他工具（wireshark/tshark、sox、grep/awk/cut/cat/sed 等）的输入。它还支持无线 (AP_DLT_IEEE802_11) 网络。 

 

40.Rtpflood

一种命令行工具，用于处理RTP的任何设备。 

 

41.Rtpinsertsound

在 2006 年 8 月至 9 月的时间范围内创建了将音频插入指定音频（即 RTP）流的工具。该工具名为 rtpinsertsound。它在 Linux Red Hat Fedora Core 4 平台（Pentium IV，2.5 GHz）上进行了测试，但预计该工具将成功构建并在各种 Linux 发行版上执行。

 

42.Rtpmixsound

一种将预先录制的音频与指定目标音频流中的音频（即 RTP）实时混合的工具。
