1.xsser

跨站点“脚本程序”（又名 XSSer）是一个自动框架，用于检测、利用和报告基于 Web 的应用程序中的 XSS 漏洞。它包含几个尝试绕过某些过滤器的选项，以及各种特殊的代码注入技术。

 

2.yara

YARA 是一种旨在帮助恶意软件研究人员识别和分类恶意软件样本的工具。使用 YARA，可以根据恶意软件家族样本中包含的文本或二进制模式创建恶意软件家族的描述。每个描述由一组字符串和一个确定其逻辑的布尔表达式组成。通过使用带有通配符的二进制字符串、不区分大小写的文本字符串、特殊运算符、正则表达式和许多其他功能，可以创建复杂而强大的规则。

  

3.yersinia

Yersinia 是一个执行第 2 层攻击的框架。它旨在利用不同网络协议的一些弱点。它伪装成一个可靠的框架，用于分析和测试已部署的网络和系统。

在此特定版本中实施了针对以下网络协议的攻击：

· 生成树协议 (STP)。

· 思科发现协议 (CDP)。

· 动态中继协议 (DTP)。

· 动态主机配置协议 (DHCP)。

· 热备路由器协议 (HSRP)。

· 802.1q。

· 802.1x。

· 交换机间链路协议 (ISL)。

· VLAN 中继协议 (VTP)

 

4.zaproxy

OWASP Zed 攻击代理 (ZAP) 是一种易于使用的集成渗透测试工具，用于查找 Web 应用程序中的漏洞。它旨在供具有广泛安全经验的人使用，因此非常适合不熟悉渗透测试的开发人员和功能测试人员，也是经验丰富的渗透测试人员工具箱的有用补充。

 

5.zenmap-kbx

Zenmap 是一个 Nmap 前端。它旨在对高级用户有用，并使 Nmap 易于初学者使用。它最初源自 Umit，一个 Nmap GUI，作为 Google Summer of Code 的一部分创建。

 

6.zerofree

Zerofree 在 ext2、ext3 或 ext4 文件系统中查找具有非零值内容的未分配块，并用零填充它们（zerofree 也可以使用除零以外的其他值）。如果此文件系统所在的设备是磁盘映像，这将非常有用。在这种情况下，根据磁盘映像的类型，辅助实用程序可能能够在运行 zerofree 后减小磁盘映像的大小。Zerofree 要求文件系统被卸载或以只读方式挂载。实现相同结果（将未使用的块清零）的常用方法是运行“dd”以创建一个充满零的文件，该文件占用驱动器上的整个可用空间，然后删除该文件。这有很多缺点，而 zerofree 可以缓解：

· 它很慢；

· 它使磁盘映像（临时）增长到最大程度；

· 它（暂时）使用磁盘上的所有可用空间，因此其他并发写入操作可能会失败。

Zerofree 已被编写为从作为虚拟机内的来宾操作系统安装的 GNU/Linux 系统运行。如果这不是你的情况，你几乎肯定不需要这个包。（另一个用例是比使用简单的“rm”更安全地擦除敏感数据）。

 

7.Zim

Zim 是一个图形文本编辑器，用于维护维基页面的集合。

每个页面都可以包含到其他页面的链接、简单的格式和内嵌图像。页面存储在文件夹结构中，就像在大纲中一样，并且可以有附件。创建一个新页面就像链接到一个不存在的页面一样简单。

所有数据都存储在具有 wiki 格式的纯文本文件中。各种插件提供附加功能，如任务列表管理器、方程编辑器、托盘图标和版本控制支持。

Zim 可用于：

· 保留笔记存档

· 在会议或讲座期间做笔记

· 整理任务清单

· 草稿博客条目和电子邮件

· 进行头脑风暴

 

8. Zonedb

该软件包提供了一个免费的开源数据库 ( http://opendatacommons.org/licenses/odbl/1.0/ )，其中包含公共 DNS 区域的列表和相关元数据 ( http://en.wikipedia.org/wiki/DNS_zone )（域名后缀）。它试图详尽无遗，包括当前、已停用和已撤销的顶级域和子域。

 

9.Zsh

Zsh 是一个 UNIX 命令解释器 (shell)，可用作交互式登录 shell 和 shell 脚本命令处理器。在标准 shell 中，zsh 与 ksh 最相似，但包括许多增强功能。Zsh 具有命令行编辑、内置拼写更正、可编程命令完成、shell 功能（带自动加载）、历史记录机制和许多其他功能。

 

10.zsh-autosuggestions

当您键入命令时，您会看到光标后出现一个以柔和的灰色显示的补全。如果您在缓冲区末尾按右箭头键或 End 光标，它将接受建议，将命令行缓冲区的内容替换为建议。如果您调用前向词小部件，它将部分接受建议，直到光标移动到该点为止。

 

11.zsh-syntax-highlighting

这个包为 shell zsh 提供语法高亮效果。它可以在命令在 zsh 提示符下输入到交互式终端时突出显示它们。这有助于在运行命令之前查看命令，特别是在捕获语法错误方面。此功能的灵感来自默认提供的 Fish shell。有多种方法可以配置用于突出显示的颜色，以及配置突出显示的内容。
