1. windows-binaries

用于渗透测试的 Windows 可执行文件的集合。

 

2. windows-privesc-check

Windows-privesc-check 是在 Windows 系统上运行的独立可执行文件（目前仅在 XP、Windows 7 上测试过）。它试图找到可能允许本地非特权用户将权限提升到其他用户或访问本地应用程序（例如数据库）的错误配置。它是用 python 编写的，并使用 pyinstaller 转换为可执行文件，因此可以轻松上传和运行（而不是解压缩 python + 其他依赖项）。它可以以普通用户或管理员身份运行（显然以管理员身份运行时效果更好，因为它可以读取更多文件）。

 

3. Winexe

Winexe 在 Windows NT/2000/XP/2003 系统上从 GNU/Linux（也可能来自其他能够构建 Samba 4 软件包的 Unices）远程执行命令。

 

4. Winregfs

Winregfs 是一个基于 FUSE 的文件系统驱动程序，它可以像普通文件系统一样访问 Windows 注册表配置单元文件。注册表配置单元文件编辑可以在安装后使用普通的 shell 脚本和命令行工具执行。

fsck.winregfs 扫描 Windows 注册表配置单元文件以查找表明配置单元已被硬件或软件问题损坏的问题，递归读取注册表配置单元中的键和值数据结构。这个包提供 mount.winregfs 和 fsck.winregfs 命令。Winregfs 对渗透测试人员、道德黑客和取证专家很有用。

 

5. Wireshark

Wireshark 是一个网络“嗅探器”——一种捕获和分析离线数据包的工具。

 

6. Witnessme

这个包包含一个受 Eyewitness 启发的 Web Inventory 工具，它也被编写为可扩展的，允许您创建自定义功能，以利用它在后端驱动的无头浏览器。

 

7. Wordlistraider

这个包包含一个用于准备现有单词表的 Python 工具。它返回与现有列表中传递的条件匹配的单词选择。例如，您有一个 GB 大的词表，而您只需要长度至少为 8 个字符的密码。这可以优化单词列表并节省不必要的请求。

 

8.Wordlists

这个包包含rockyou.txt 词表，安装大小为134 MB。

 

9.wpa-sycophant

该软件包包含一个工具，可在不破解密码的情况下中继第 2 阶段身份验证尝试以访问公司无线网络。要使用此技术，您需要运行一个恶意接入点，以便合法用户连接到您，以便您可以将身份验证尝试转发给 Sycophant。

  

10. Wpscan

WPScan 扫描远程 WordPress 安装以查找安全问题。

 

11. Xmount

xmount 可用于通过 QEMU、KVM、VirtualBox、VMware 等引导取证磁盘映像，因为它支持重定向到缓存文件的虚拟写访问。

xmount 使用 FUSE（用户空间中的文件系统）在多个输入和输出磁盘映像类型之间动态转换，以创建表示输入映像的虚拟文件系统。虚拟表示可以是原始 DD、DMG、VirtualBox VDI 格式、Microsoft VHD 格式或 VMware VMDK 格式；输入图像可以是原始 DD、EWF（专家证人压缩格式）或 AFF（高级取证格式）文件。

 

12.xplico

Xplico 的目标是从互联网流量中提取包含的应用程序数据。例如，Xplico 从 pcap 文件中提取每封电子邮件（POP、IMAP 和 SMTP 协议）、所有 HTTP 内容、每个 VoIP 呼叫（SIP、MGCP、H323）、FTP、TFTP 等。Xplico 不是网络协议分析器。

 

13.xprobe

xprobe2 允许您确定远程主机上运行的操作系统。它向主机发送多个数据包并分析返回的答案。Xprobe2 的功能类似于 nmap 中的操作系统指纹识别功能（由不同的 Fyodor 编写）：

· 输出其对远程主机上操作系统的置信度。

· 即使中间系统（路由器、防火墙）对数据包稍作修改，它仍然可用。

· 可以列出中间设备的类型（例如“Linux IP masquerading”）。

· 模块化架构允许添加新的指纹测试和新的操作系统签名

  

14.xspy

嗅探远程或本地 X-Windows 服务器上的击键。

 

15.xsser

跨站点“脚本程序”（又名 XSSer）是一个自动框架，用于检测、利用和报告基于 Web 的应用程序中的 XSS 漏洞。它包含几个尝试绕过某些过滤器的选项，以及各种特殊的代码注入技术。

 

16.yara

YARA 是一种旨在帮助恶意软件研究人员识别和分类恶意软件样本的工具。使用 YARA，可以根据恶意软件家族样本中包含的文本或二进制模式创建恶意软件家族的描述。每个描述由一组字符串和一个确定其逻辑的布尔表达式组成。通过使用带有通配符的二进制字符串、不区分大小写的文本字符串、特殊运算符、正则表达式和许多其他功能，可以创建复杂而强大的规则。
