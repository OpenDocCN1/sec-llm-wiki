**1. Jadx**

    这个包包含一个Dex-to-Java反编译器。它包含一个命令行和GUI工具，用于从Android Dex和Apk文件生成Java源代码。

主要功能：-将Dalvik字节码从APK、dex、aar和zip文件反编译为java类-解码resources.arsc中的AndroidManifest.xml和其他资源-包括Deobfousator

jadx gui功能：-使用突出显示的语法查看反编译代码-跳转到声明-查找用法-全文搜索

 

如何安装：sudo apt install jadx

  

**2. Javasnoop**

    通常，如果无法访问原始源代码，测试Java客户机的安全性最好是不可预测的，最坏是不现实的。通过访问原始源代码，您可以运行一个简单的Java程序并远程附加调试器，单步执行代码并在需要时更改变量。对小程序执行同样的操作有点困难。JavaSnoop试图通过允许您附加到现有进程（如调试器）并立即开始篡改方法调用、运行自定义代码或只是观察系统上发生的情况来解决此问题。

 

如何安装：sudo apt install javasnoop

  

**3. jboss-autopwn**

    这个JBoss脚本在目标JBoss AS服务器上部署了一个JSP shell。部署后，脚本使用其上载和命令执行功能来提供交互式会话。

功能包括：-多平台支持-在Windows、Linux和Mac目标上测试-支持绑定和反向绑定外壳-MeterMeter外壳和对Windows目标的VNC支持

 

如何安装：sudo apt install jboss-autopwn

  

**4. jd-gui ** 

JD-GUI是一个独立的图形工具，显示“.class”文件的Java源代码。您可以使用JD-GUI浏览重构的源代码，以便即时访问方法和字段。

 

如何安装：sudo apt install jd-gui

  

**5. John**

    John the Ripper是一个工具，旨在帮助系统管理员找到弱（易于猜测或通过暴力破解）密码，甚至在需要时自动向用户发送警告邮件。

除了在各种Unix版本上最常见的几种crypt（3）密码散列类型外，开箱即用的还支持Kerberos AFS和Windows NT/2000/XP/2003 LM散列，以及其他一些附带补丁的散列类型。

   

 如何安装：sudo apt install john

 

(1) john-data

John the Ripper是一个工具，旨在帮助系统管理员找到弱（易于猜测或通过暴力破解）密码，甚至在需要时自动向用户发送警告邮件。

该软件包包含可由john和架构无关脚本使用的架构无关字符集。

 

  如何安装：sudo apt install john-data

  

**6. Johnny**

Johnny is为John the Ripper密码破解工具提供了GUI。

 

如何安装：sudo apt install johnny

 

**7. Joomscan**

此软件包包含JoomScan，是\[Joom\]la漏洞\[Scan\]ner的缩写。这是一个perl编程语言项目，用于检测并分析Joomla CMS漏洞。

 

如何安装：sudo apt install joomscan

 

**8. Joplin**

    这个软件包包含一个免费的、开源的笔记和待办事项应用程序，它可以处理组织到笔记本中的大量笔记。注释可以搜索，可以直接从应用程序或您自己的文本编辑器中复制、标记和修改。注释采用降价格式。

通过.enex文件从Evernote导出的注释可以导入Joplin，包括格式化内容（转换为标记）、资源（图像、附件等）和完整元数据（地理位置、更新时间、创建时间等）。也可以导入普通标记文件。

笔记可以与各种云服务同步，包括Nextcloud、Dropbox、OneDrive、WebDAV或文件系统（例如网络目录）。同步笔记时，笔记本、标签和其他元数据会保存到纯文本文件中，以便检查、备份和移动。

 

如何安装：sudo apt install joomscan

 

(1) joplin-cli

此包包含命令行界面。

       

如何安装：sudo apt install joplin-cli

 

**9. Jsql**

 jsql包已被jsql注入包取代。

 

如何安装：sudo apt install joplin

 

(1) jsql-injection

        jSQL注入是一个轻量级应用程序，用于从远程服务器查找数据库信息。jSQL是免费的、开源的、跨平台的（Windows、Linux、Mac OS X、Solaris）。

       

 如何安装：sudo apt install jsql-injection
