# KALI工具介绍专栏系列（15）

**1. i2c-tools**

(1) i2c-tools

该软件包包含一组用于Linux的I2C异构工具：总线探测工具、芯片转储程序、寄存器级访问帮助程序、EEPROM解码脚本等等。

 

如何安装：sudo apt install i2c-tools

 

(2) libi2c-dev

        I2C设备通常由内核驱动程序控制。使用这个库，还可以从用户空间访问适配器上的所有设备，而不需要了解Linux内核内部结构。

此包包含编译在您自己的代码中使用此库的源代码所需的内容。

 

如何安装：sudo apt install libi2c-dev

 

(3) libi2c0

I2C设备通常由内核驱动程序控制。使用这个库，还可以从用户空间访问适配器上的所有设备，而不需要了解Linux内核内部结构。此软件包包含运行使用此库的程序所需的内容。

 

如何安装：sudo apt install libi2c0

 

(4) python3-smbus

此Python 3模块允许SMBus通过Linux主机上的I2C/dev接口进行访问。主机内核必须具有I2C支持、I2C设备接口支持和总线适配器驱动程序。

 

如何安装：sudo apt install python3-smbus

  

**2. iaxflood**

从两个星号IP PBX之间的IAX通道捕获UDP星号间交换（即IAX）数据包。该数据包的内容是该工具所包含攻击的有效负载的来源。虽然IAX协议头可能与您将使用此工具攻击的星号PBX不匹配，但与没有任何类似IAX负载的简单udpflood相比，它可能需要PBX进行更多的处理。

 

如何安装：sudo apt install iaxflood

  

**3. ibombshell**

    此软件包包含一个在Powershell中编写的工具，该工具允许您在任何时候使用利用后功能（在某些情况下还包括利用后功能）发出提示。它是一个直接下载到内存的shell，提供了对大量pentesting功能的访问。这些功能可以以Powershell函数的形式直接下载到内存中。这种执行方式在任何地方都是众所周知的。

此外，ibombshell还提供了第二种执行模式，称为静默，因此pentester可以执行ibombshell的实例（称为warrior）。受损计算机将通过HTTP连接到指挥与控制面板。因此，有可能控制战士，并能够在内存中加载有助于pentester的函数。这种情况发生在开发后阶段。

 

    如何安装：sudo apt install ibombshell

  

**4. ident-user-enum**

    这个包是一个简单的PERL脚本，用于查询ident服务（113/TCP），以确定侦听目标系统每个TCP端口的进程的所有者。

这有助于在pentest期间对目标服务进行优先级排序（您可能希望首先攻击以root身份运行的服务）。或者，收集的用户名列表可用于对其他网络服务进行密码猜测攻击。

    

     如何安装：sudo apt install ident-user-enum

  

**5. ifenslave**

    这是一种将从属网络接口连接和分离到绑定设备的工具。绑定设备将像普通以太网设备一样作用于内核，但将使用简单的循环调度程序通过从设备发送数据包。这允许简单的负载平衡，与交换机中使用的“通道连接”或“中继”技术相同。

内核必须支持绑定设备，ifenslave才有用。这个包支持2.6.x内核和最近的3.x.x内核。

    

如何安装：sudo apt install ifenslave

  

**6. ike-scan**

    ke scan发现IKE主机，还可以使用重传退避模式对其进行指纹识别。

ike扫描有两个功能：

a） 发现：确定哪些主机正在运行IKE。这是通过显示响应IKE扫描发送的IKE请求的主机来完成的。

b） 指纹：确定主机正在使用的IKE实现。这是通过记录来自目标主机的IKE响应数据包的时间并将观察到的重传退避模式与已知模式进行比较来实现的。

 

如何安装：sudo apt install ike-scan

  

**7. impacket**

    Impacket是Python3类的集合，专注于提供对网络数据包的访问。Impacket允许Python3开发人员以简单一致的方式制作和解码网络数据包。它包括对IP、UDP和TCP等低级协议的支持，以及对NMB和SMB等高级协议的支持。

Impacket与包捕获实用程序或包（如Pcapy）结合使用时非常有效。数据包可以从头构造，也可以从原始数据解析。此外，面向对象的API使使用深层协议层次结构变得简单。

 

     如何安装：sudo apt install python3-impacket

  

**8. impacket-scripts**

    此包包含指向有用impacket脚本的链接。它是一个单独的包，用于将impacket包与Debian分开，并在Kali的路径中包含有用的脚本。

   

    如何安装：sudo apt install impacket-scripts

  

**9. inetsim**

    INetSim是一个用于在实验室环境中模拟常见互联网服务的软件套件，例如用于分析未知恶意软件样本的网络行为。

INetSim支持模拟以下服务：HTTP、SMTP、POP3、DNS、FTP、NTP、TFTP、IRC、Ident、Finger、Syslog、“小型服务器”（日间、时间、回音、计费、丢弃、Quotd）

其他功能：

l 伪造时间

l 连接重定向

l 详细的日志记录和报告

l 对多种服务的TLS/SSL支持

 

    如何安装：sudo apt install inetsim

  

**10. initramfs-tools**

    这个包为Linux内核包构建了一个可引导的initramfs。initramfs与内核一起加载，并负责装载根文件系统和启动主init系统。

 

    如何安装：sudo apt install initramfs-tools

  

**11. inspectrum**

    inspectrum是一种分析捕获信号的工具，主要来自软件定义的无线电接收机。

inspectrum支持以下文件类型：\*.cf32、\*.cfile-复数32位浮点（GNURadio、osmocom\_fft）\*.cs16-复数16位有符号整数（BladeRF）\*.cs8-复数8位有符号整数（HackRF）\*.cu8-复数8位无符号整数（RTL-SDR）

特征：

l 大型（100GB以上）文件支持

l 具有缩放/平移功能的光谱图

l 振幅、频率、相位和IQ样本图

l 用于测量周期、符号速率和提取符号的游标

l 导出选定时间段、过滤样本和解调数据

 

如何安装：sudo apt install inspectrum    

  

**12. inspy**

    这个包包含一个基于Python的LinkedIn枚举工具。您将需要来自HunterIO的API密钥。

 

    如何安装：sudo apt install inspy

  

**13. instaloader**

下载公共和私人档案、哈希标签、用户故事、提要和保存的媒体下载每篇文章的评论、地理标签和标题。自动检测配置文件名称的更改并相应地重命名目标目录，从而允许对筛选器和下载媒体的存储位置进行细粒度自定义

 

如何安装：sudo apt install instaloader

  

**14. intrace**

InTrace是一个类似于traceroute的应用程序，它使用户能够枚举利用现有TCP连接的IP跃点，这两种连接都是从本地网络（本地系统）或远程主机启动的。它可以用于网络侦察和防火墙绕过。

 

如何安装： sudo apt install intrace

  

**15. inviteflood**

    通过UDP/IP执行SIP/SDP INVITE消息泛洪的工具。它在Linux Red Hat Fedora Core 4平台（奔腾IV，2.5 GHz）上进行了测试，但预计该工具将成功构建并在各种Linux发行版上执行。

 

    如何安装：sudo apt install inviteflood

  

**16. iodine**

    这是一款软件，可用于通过DNS服务器对IPv4数据进行隧道传输。这可以在不同的情况下使用，在不同的情况下，互联网访问是防火墙，但DNS查询是允许的。

 

    如何安装：sudo apt install iodine

  

**17. ipv6-toolkit**

    包括的工具：

l addr6：一个IPv6地址分析和操作工具。

l flow6：用于对IPv6流标签执行安全评估的工具。

l frag6：一种用于执行基于IPv6碎片的攻击并对许多碎片相关方面进行安全评估的工具。

l icmp6：根据ICMPv6错误消息执行攻击的工具。

l jumbo6：一种评估IPv6巨型程序处理中潜在缺陷的工具。

l na6：发送任意邻居广告消息的工具。

l ni6：一种发送任意ICMPv6节点信息消息的工具，用于评估处理此类数据包时可能存在的缺陷。

l ns6：发送任意邻居请求消息的工具。

l ra6：发送任意路由器广告消息的工具。

l rd6：发送任意ICMPv6重定向消息的工具。

l rs6：发送任意路由器请求消息的工具。

l scan6：IPv6地址扫描工具。

l tcp6：发送任意TCP段并执行各种基于TCP的攻击的工具。

       如何安装：sudo apt install ipv6-toolkit

**18. irpas**

    此软件包包含用于高级网络操作、测试和调试的程序集合。

CDP和route喷油器在生产网络中非常有用。其他一些工具对于安全和防火墙测试非常有用。最后，一些工具（如netenum）对于一般管理脚本非常有用。

就像所有强大的工具一样，它可能会造成巨大的伤害，所以要小心。

   

   如何安装：sudo apt install irpas

  

**19. ismtp**

    测试 SMTP 用户列举 （RCPT TO 和 VRFY）、内部欺骗和继电器。

    

    如何安装：sudo apt install ismtp

  

**20. isr-evilgrade**

Evilgrade是一个模块化框架，允许用户通过注入虚假更新来利用糟糕的升级实施。它带有预先制作的二进制文件（代理），这是fast Pentest的默认配置，并且有自己的WebServer和DNSServer模块。易于设置新设置，并在设置新的二进制代理时自动配置。

 

如何安装： sudo apt install isr-evilgrade

  

**21. ivre**

    该软件包包含一个网络识别框架，包括被动识别工具（基于BRO、ARGUS、NFDUMP的流量分析、基于BRO和P0F的指纹分析以及主动识别）。

醉酒使用NMAP运行扫描，可以使用ZMAP作为预扫描程序；醉酒还可以从NMAP和Masscan导入XML输出。

 

    如何安装：sudo apt install ivre

  

**22. iw**

    此软件包包含“iw”命令行工具，可用于配置和显示有关无线设备的信息。

iw基于nl80211内核接口，支持大多数较新的硬件。使用无线扩展接口的旧工具iwconfig已被弃用，强烈建议切换到iw和nl80211。

    

   如何安装：sudo apt install iw
