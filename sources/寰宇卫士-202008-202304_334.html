1.Qemu

QEMU是一种快速处理器仿真器。从前，只有一个名为qemu的包，包含所有功能。如今，qemu变得越来越大，并被分成了许多包。不同的软件包提供完全不同的服务，人们不太可能同时需要所有这些服务。因此，当前qemu的包不再有意义，并且正在成为一个虚拟包。

如果希望对某些体系结构进行完整的系统仿真，请安装一个或多个qemu系统ARCH软件包。如果需要用户模式模拟，请安装qemu user或qemu user静态软件包。如果您需要实用程序，请使用qemu utils包。

这个包裹可以安全地取下。

 

qemu-block-extra

QEMU 是一个快速处理器仿真器：目前该包支持 ARM、CRIS、i386、M68k (ColdFire)、MicroBlaze、MIPS、PowerPC、SH4、SPARC 和 x86-64 仿真。通过使用动态转换，它可以实现合理的速度，同时易于移植到新的主机 CPU 上。

该包为 qemu-system 仿真和 qemu-utils 包中的 qemu-img 提供了额外的块设备后端模块，这些模块很少使用并且具有额外的依赖项。

 

qemu-guest-agent

QEMU 是一个快速处理器仿真器：目前该包支持 ARM、CRIS、i386、M68k (ColdFire)、MicroBlaze、MIPS、PowerPC、SH4、SPARC 和 x86-64 仿真。通过使用动态转换，它可以实现合理的速度，同时易于移植到新的主机 CPU 上。

这个包提供了一个守护进程（代理）来在 qemu-system 来宾（完整系统模拟）中运行。它使用 virtio 串行通道 org.qemu.guest_agent.0 与主机通信，并允许从主机在来宾中执行一些功能，包括：

查询和设置访客系统时间

执行来宾文件系统同步操作

启动来宾关闭或暂停到 ram

访问访客文件

冻结/解冻客户文件系统操作

其他。

在 qemu 虚拟机中作为来宾运行的系统上安装此软件包。它不在主机上使用。

 

qemu-system

QEMU 是一个快速处理器仿真器：目前该包支持 ARM、CRIS、i386、M68k (ColdFire)、MicroBlaze、MIPS、PowerPC、SH4、SPARC 和 x86-64 仿真。通过使用动态转换，它可以实现合理的速度，同时易于移植到新的主机 CPU 上。

这个元包为所有受支持的目标提供完整的系统仿真二进制文件，依赖于 QEMU 支持的所有每个架构的系统仿真包。

 

qemu-system-arm

QEMU 是一个快速处理器仿真器：目前该包支持 ARM 仿真。通过使用动态转换，它可以实现合理的速度，同时易于移植到新的主机 CPU 上。

这个包提供了完整的系统仿真二进制文件来仿真以下 arm 硬件：aarch64 arm。

在系统仿真模式下，QEMU 仿真一个完整的系统，包括一个处理器和各种外设。它可以更轻松地测试和调试系统代码。它还可以用于在单个服务器上提供多个虚拟机的虚拟托管。

 

qemu-system-common

QEMU 是一个快速处理器仿真器：目前该包支持 ARM、CRIS、i386、M68k (ColdFire)、MicroBlaze、MIPS、PowerPC、SH4、SPARC 和 x86-64 仿真。通过使用动态转换，它可以实现合理的速度，同时易于移植到新的主机 CPU 上。

此包提供特定于目标的完整系统仿真 (qemu-system-*) 包所需的通用文件。

 

qemu-system-data

这个包为系统模式 QEMU 仿真 (qemu-system-*) 包提供架构中立的数据文件（例如键盘定义、图标）。

 

qemu-system-gui

该软件包为完整系统仿真 (qemu-system-*) 软件包提供本地图形用户界面（当前为 GTK）和音频后端。

默认的基于 GTK 的 qemu-system-gui 通常更好并推荐使用，但一些极端情况仍然需要 SDL，因此也提供了它。

qemu-system-misc

QEMU 是一个快速处理器仿真器：目前该包支持 ARM、CRIS、M68k (ColdFire)、MicroBlaze 和 SH4 仿真。通过使用动态转换，它可以实现合理的速度，同时易于移植到新的主机 CPU 上。

该软件包提供了完整的系统仿真二进制文件，以模拟未制成单独软件包的各种其他硬件。提供了以下架构的模拟器：alpha avr cris hppa m68k microblaze microblazeel nios2 or1k riscv32 riscv64 rx sh4 sh4eb s390x tricore xtensa xtensaeb。

在系统仿真模式下，QEMU 仿真一个完整的系统，包括一个处理器和各种外设。它可以更轻松地测试和调试系统代码。它还可以用于在单个服务器上提供多个虚拟机的虚拟托管。

qemu-system-x86

QEMU 是一个快速处理器仿真器：目前该包支持 i386 和 x86-64 仿真。通过使用动态转换，它可以实现合理的速度，同时易于移植到新的主机 CPU 上。

该软件包提供了完整的系统仿真二进制文件来仿真以下 x86 硬件：i386 x86_64。

在系统仿真模式下，QEMU 仿真一个完整的系统，包括一个处理器和各种外设。它可以更轻松地测试和调试系统代码。它还可以用于在单个服务器上提供多个虚拟机的虚拟托管。

在 x86 主机硬件上，此软件包还支持在支持它的系统上使用 KVM 内核虚拟机。

 

qemu-user

QEMU 是一个快速处理器仿真器：目前该包支持 ARM、CRIS、i386、M68k (ColdFire)、MicroBlaze、MIPS、PowerPC、SH4、SPARC 和 x86-64 仿真。通过使用动态转换，它可以实现合理的速度，同时易于移植到新的主机 CPU 上。

这个包提供了用户模式仿真二进制文件。在这种模式下，QEMU 可以在另一个 CPU 上启动为一个 CPU 编译的 Linux 进程。

如果还安装了 qemu-user-binfmt 软件包，它将从这个 qemu-user 软件包向内核注册二进制格式处理程序，因此可以直接运行外部二进制文件。但是，这可能不适合在外部 chroot 内部使用，在这种情况下，可以使用 qemu-user-static 包代替 qemu-user-binmft，– qemu-user-static 将注册静态链接的 binfmt 处理程序。

 

qemu-user-binfmt

QEMU是一个快速处理器仿真器：目前该包支持 ARM、CRIS、i386、M68k (ColdFire)、MicroBlaze、MIPS、PowerPC、SH4、SPARC 和 x86-64 仿真。通过使用动态转换，它可以实现合理的速度，同时易于移植到新的主机 CPU 上。

这个包为 qemu-user 的用户模式仿真二进制文件提供 binfmt 支持注册。这是一个空包，它不包含任何附加文件，仅包含在安装和删除时运行的注册脚本。

 

qemu-user-static

QEMU 是一个快速处理器仿真器：目前该包支持 ARM、CRIS、i386、M68k (ColdFire)、MicroBlaze、MIPS、PowerPC、SH4、SPARC 和 x86-64 仿真。通过使用动态转换，它可以实现合理的速度，同时易于移植到新的主机 CPU 上。

这个包提供了静态构建的用户模式仿真二进制文件。在这种模式下，QEMU 可以在另一个 CPU 上启动为一个 CPU 编译的 Linux 进程。

qemu-user-static 包将注册提供的模拟器可以处理的二进制格式，以便可以直接运行外部二进制文件。

 

qemu-utils

QEMU 是一个快速处理器仿真器：目前该包支持 ARM、CRIS、i386、M68k (ColdFire)、MicroBlaze、MIPS、PowerPC、SH4、SPARC 和 x86-64 仿真。通过使用动态转换，它可以实现合理的速度，同时易于移植到新的主机 CPU 上。

这个包提供了 QEMU 相关的工具：

qemu-img：QEMU 磁盘映像实用程序

qemu-io：QEMU 磁盘练习器

qemu-nbd：QEMU 磁盘网络块设备服务器

3.Quark-Engine

Quark Engine是一个功能齐全的Android分析框架，用Python编写，用于在APK、DEX文件中查找威胁情报。因为它是基于规则的，所以您可以使用内置的或根据需要自定义的。Quark Engine从刑法中破译出的思想为Android分析提供了独特的视角。一个Dalvik字节码加载器已经被开发出来，它在内部进行了污染分析，但也击败了用于反向工程的模糊技术。令人惊讶的是，加载器完全符合恶意软件评分系统的设计。Quark引擎非常易于使用，还提供灵活的输出格式。输出报告有三种类型：详细报告、调用图和摘要报告。有了这些报告，您可以在几秒钟内了解Android内部的高风险行为。此外，通过与其他Android分析工具（如Ghidra、APKLAB、Jadx）集成，Quark Engine可以极大地提高逆向工程师的效率。
