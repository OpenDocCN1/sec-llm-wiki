1.P0f

p0f 基于 SYN 数据包执行被动操作系统检测。与 nmap 和 queso 不同，p0f 无需发送任何数据即可进行识别。此外，它能够确定到远程主机的距离，并可用于确定外部或本地网络的结构。在网络网关上运行时，它能够收集大量数据并提供有用的统计数据。在用户端计算机上，它可以用作强大的 IDS 插件。p0f 支持完整的 tcpdump 式过滤表达式，并具有可扩展的详细指纹数据库。


2.P7zip

p7zip 是 7-Zip 的 Unix 命令行端口，7-Zip 是一种文件归档程序，可处理具有非常高压缩率的 7z 格式。

p7zip 提供：

/usr/bin/7zr 是 7-zip 工具的独立最小版本，仅处理 7z、LZMA 和 XZ 档案。7z 压缩比 ZIP 压缩好 30-50%。

/usr/bin/p7zip 一个类似 gzip 的 7zr 包装器。

p7zip 可以与流行的压缩接口（例如 File Roller 或 Nautilus）一起使用。

另一个包 p7zip-full 提供了支持更多压缩格式的 7z 和 7za。

 

p7zip-full

p7zip 是 7-Zip 的 Unix 命令行端口，7-Zip 是一种文件归档程序，可处理具有非常高压缩率33.的 7z 格式。

p7zip-full 提供了用于在 shell 中或使用 GUI（例如 Ark、File Roller 或 Nautilus）打包和解压缩 7z 档案的实用程序。

安装 p7zip-full 允许 File Roller 使用非常有效的 7z 压缩格式来打包和解包文件和目录。此外，它还提供了 7z 和 7za 命令。

支持的格式列表：

打包/解包：7z、ZIP、GZIP、BZIP2、XZ和TAR

仅解包：APM、ARJ、CAB、CHM、CPIO、CramFS、DEB、DMG、FAT、HFS、ISO、LZH、LZMA、LZMA2、MBR、MSI、MSLZ、NSIS、NTFS、RAR（仅当非免费 p7zip- rar 包已安装）、RPM、SquashFS、UDF、VHD、WIM、XAR 和 Z。

依赖包 p7zip 提供了 7zr（7za 的轻量版本）和 p7zip（围绕 7zr 的类似 gzip 的包装器）。

 

3.Pack

PACK 的开发是为了帮助在 Defcon 2010 期间发生的密码破解竞赛“Crack Me If You Can”。该工具包的目标是通过分析人们的常见方式来帮助为“比暴力破解更好”的密码攻击做准备创建密码。在分析阶段之后，可以使用统计数据库为 oclHashcat 等工具生成攻击掩码。

注意：此工具本身无法破解密码，但可以帮助其他工具更快地破解更多密码。

  

4.Pacu

该软件包包含一个开源 AWS 开发框架，旨在针对云环境进行攻击性安全测试。Pacu 由 Rhino 安全实验室创建和维护，允许渗透测试人员利用 AWS 账户中的配置缺陷，使用模块轻松扩展其功能。当前模块支持一系列攻击，包括用户权限提升、IAM 用户的后门、攻击易受攻击的 Lambda 函数等等。

7.Parsero

Parsero 是一个用 Python 编写的免费脚本，它读取 Web 服务器的 Robots.txt 文件并查看 Disallow 条目。Disallow 条目告诉搜索引擎不得对托管在 Web 服务器上的哪些目录或文件编入索引。例如，“Disallow: /portal/login”意味着www.example.com/portal/login上的内容 不允许被 Google、Bing、Yahoo 等爬虫编入索引……这是管理员必须不共享的方式搜索引擎提供的敏感或私人信息。

该软件的性质意味着任何错误都可能导致大量数据丢失。虽然目前没有已知的此类错误，但它们可能存在，因此请在运行之前备份所有重要文件，并自担风险。

19.Pdfcrack

PDFCrack 是一个简单的工具，用于从 pdf 文档中恢复密码。

它应该能够处理使用标准安全处理程序的所有 pdf，但 pdf 解析例程有点快速，因此您可能会偶然发现一些需要修复解析器才能处理的 pdf。

PDFCrack 的主要功能是：

支持所有已知 PDF 版本的标准安全处理程序（修订版 2、3 和 4）。

支持破解所有者和用户密码。

支持词表和暴力破解密码。

简单排列（目前只尝试第一个字符作为大写）。

保存并加载正在运行的作业。

简单的基准测试。

当用户密码已知时优化搜索所有者密码。

该程序可用于取证调查或类似活动，以破解合法密码。
