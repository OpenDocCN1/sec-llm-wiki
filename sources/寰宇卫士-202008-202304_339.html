1. Wce

Windows 凭据编辑器 (WCE) v1.3beta 允许您：

NTLM身份验证：

1.列出登录会话并添加、更改、列出和删除关联的凭据（例如：LM/NT 哈希）

2.在 Windows 上本地执行哈希传递

3.从内存（从交互式登录、服务、远程桌面连接等）中获取 NT/LM 哈希，可用于向其他系统进行身份验证。WCE 可以在不注入代码的情况下执行此任务，只需读取和解密存储在 Windows 内部内存结构中的信息即可。当上述方法无法执行时，它还具有自动切换到代码注入的能力。

 

2. Webacoo

网络后门 Cookie 脚本套件

 

3. Webscarab

WebScarab 旨在成为任何需要公开基于 HTTP(S) 的应用程序工作的人的工具，无论是允许开发人员调试其他困难的问题，还是允许安全专家识别应用程序中的漏洞已经设计或实施。

 

4. Webshells

用于 ASP、ASPX、CFM、JSP、Perl 和 PHP 服务器的 webshell 集合。

 

5. Websploit

WebSploit 是一个开源项目，用于扫描和分析远程系统以查找各种类型的漏洞。这个工具非常强大，支持多个漏洞。

 

6. Weevely

Weevely 是一个隐蔽的 PHP web shell，可以模拟类似 telnet 的连接。它是 Web 应用程序后期利用的重要工具，可用作隐形后门或 Web Shell 来管理合法的 Web 帐户，甚至是免费托管的帐户。

 

7. Wfuzz

Wfuzz 是一个专为暴力破解 Web 应用程序而设计的工具，它可用于查找未链接目录、servlet、脚本等的资源，用于检查不同类型注入（SQL、XSS、LDAP 等）的 bruteforce GET 和 POST 参数，bruteforce Forms参数（用户/密码）、模糊测试等。

 

8. Wgetpaste

这个包包含一个脚本，可以自动粘贴到许多 pastebin 服务。

 

9. WhatWeb

WhatWeb 识别网站。它认可 Web 技术，包括内容管理系统 (CMS)、博客平台、统计/分析包、JavaScript 库、Web 服务器和嵌入式设备。

WhatWeb 有超过 900 个插件，每个插件都能识别不同的东西。它还标识版本号、电子邮件地址、帐户 ID、Web 框架模块、SQL 错误等。

 

10. Whois

该软件包为 WHOIS (RFC 3912) 协议提供命令行客户端，该协议可查询在线服务器以获取诸如域的联系方式和 IP 地址分配等信息。它可以智能地为大多数查询选择合适的 WHOIS 服务器。该软件包还包含 mkpasswd，这是一个功能丰富的密码加密函数 crypt(3) 的前端。

 

11. wifi-honey

在 WPA/WPA2 的情况下，通过同时运行 airodump-ng，您最终还可以捕获四次握手的前两个数据包，因此可以尝试使用 aircrack-ng 或 coWPAtty 破解密钥。

这个脚本的作用是自动化设置过程，它创建五个监控模式接口，四个用作 AP，第五个用于 airodump-ng。为了使事情更容易，而不是有五个窗口，所有这些都是在一个屏幕会话中完成的，它允许您在屏幕之间切换以查看正在发生的事情。所有会话都有标签，所以你知道哪个是哪个。

 

12. Wifiphisher

该软件包包含一个安全工具，可对 WiFi 网络进行自动网络钓鱼攻击，以获取秘密密码或其他凭据。这是一种社会工程攻击，与其他方法不同，它不包括任何暴力破解。这是从强制门户和第三方登录页面或 WPA/WPA2 密码短语获取凭据的简单方法。


13. Wifite

Wifite 是一种审计 WEP 或 WPA 加密无线网络的工具。它使用 aircrack-ng、pyrit、reaver、tshark 工具来执行审计。此工具可自定义为仅使用几个参数即可自动化，并且可以在没有监督的情况下运行。

 

14.wig

该软件包包含一个 Web 应用程序信息收集工具，可以识别众多内容管理系统和其他管理应用程序。应用指纹识别基于不同版本 CMS 的已知文件的校验和和字符串匹配。这导致为每个检测到的 CMS 及其版本计算分数。每个检测到的 CMS 都与其最可能的版本一起显示。分数计算基于权重和给定校验和的“命中”数量。wig 还尝试根据“server”和“x-powered-by”标头猜测服务器上的操作系统。wig 中包含一个包含不同操作系统的已知头值的数据库，它允许 wig 猜测 Microsoft Windows 版本和 Linux 发行版和版本。

 

15.wig-ng

该软件包包含 WIG（Wi-Fi 信息收集），这是一种用于 Wi-Fi 设备指纹识别的实用程序。支持的协议和标准：

1.苹果无线直连 (AWDL)

2.思科客户端扩展 (CCX)

3.HP 打印机自定义信息元素

4.无线直连 (P2P)

5.Wi-Fi 保护设置 (WPS)

此工具不执行信道跳跃，使用诸如chopping 或airodump-ng 之类的工具。
