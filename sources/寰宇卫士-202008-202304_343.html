1.Darkstat

它是一个数据包嗅探器，作为后台进程运行并将其统计信息提供给 Web 浏览器：


  • 按机器、端口和协议输入和输出 IP 流量，

  • 最后一分钟、每小时、每天和每月的全球输入和输出图形。

众所周知，它比 ntop 更小（就内存占用而言）和更稳定。


2.Davtest

DAVTest 通过上传测试可执行文件，然后（可选）上传允许直接在目标上执行命令或其他操作的文件来测试启用了 WebDAV 的服务器。它旨在让渗透测试人员快速轻松地确定启用的 DAV 服务是否可利用。


3.Dbd

dbd 是一个 Netcat 克隆，旨在便携并提供强大的加密。它在类 Unix 操作系统和 Microsoft Win32 上运行。dbd 具有 AES-CBC-128 + HMAC-SHA1 加密（由 Christophe Devine 提供）、程序执行（-e 选项）、选择源端口、带延迟的连续重新连接以及其他一些不错的功能。dbd 仅支持 TCP/IP 通信。源代码和二进制文件在 GNU 通用公共许可证下分发。


4.Dbeaver

该软件包包含 DBeaver 社区版。它是面向开发人员、SQL 程序员、数据库管理员和分析师的免费多平台数据库工具。支持所有流行的数据库：MySQL、PostgreSQL、SQLite、Oracle、DB2、SQL Server、Sybase、Teradata、Cassandra。


5.Dc3dd

dc3dd 是 GNU dd 的修补版本，具有用于计算机取证的附加功能：


  • 即时散列（md5、sha-1、sha-256 和 sha-512）；

  • 将错误写入文件的可能性；

  • 在错误日志中分组错误；

  • 图案擦拭；

  • 进度报告;

  • 分割输出的可能性。


6.Dcfldd

dcfldd 最初是在国防部计算机取证实验室 (DCFL) 开发的。此工具基于 dd 程序，具有以下附加功能：


  • 即时散列：dcfldd 可以在输入数据传输时对其进行散列，有助于确保数据完整性。

  • 状态输出：dcfldd 可以根据传输的数据量和操作需要多长时间来更新用户的进度。

  • 灵活的磁盘擦除：如果需要，dcfldd 可用于以已知模式快速擦除磁盘。

  • 图像/擦除验证：dcfldd 可以验证目标驱动器是否与指定的输入文件或模式逐位匹配。

  • 多输出：dcfldd 可以同时输出到多个文件或磁盘。

  • 拆分输出：dcfldd 可以将输出拆分为多个文件，比 split 命令具有更多的可配置性。

  • 管道输出和日志：dcfldd 可以将其所有日志数据和输出发送到命令和本地文件。

  • 当 dd 使用 512 字节的默认块大小（bs、ibs、obs）时，dcfldd 使用 32768 字节（32 KiB），这非常高效。

  • 以下选项存在于 dcfldd 但不在 dd 中：ALGORITHMlog:、errlog、hash、hashconv、hashformat、hashlog、hashlog:、hashwindow、limit、of:、pattern、sizeprobe、split、splitformat、statusinterval、textpattern、totalhashformat、verifylog , 验证日志:, vf.


7.Ddrescue

当您的磁盘崩溃并尝试将其复制到另一个磁盘时，cp、cat 和 dd 等标准 Unix 工具将在每次 I/O 错误时中止，而 dd_rescue 则不会。只要不发生错误并回退到较小的块，它就会通过使用大块来优化复制。它支持反向复制（从顶部接近坏点）、稀疏复制、预分配空间、拼接零复制以及使用 O_DIRECT 绕过内核页面缓存。dd_rescue 通过使用快速随机数多次覆盖文件（或更好的分区/磁盘）来安全删除数据。使用 ddr_hash 插件，它支持在复制过程中计算哈希值（例如 sha256sum）或 HMAC。


8.De4dot

de4dot 是一个 .NET 反混淆器和解包器。它将尽力将打包和混淆的程序集恢复到几乎原始程序集。


大多数混淆可以完全恢复（例如字符串加密），但符号重命名是不可能恢复的，因为原始名称（通常）不是混淆程序集的一部分。


9.Dex2jar

dex2jar 包含 4 个组件：


dex读取器用于读取Dalvik可执行文件（.dex/.odex）格式。它有一个类似于ASM的轻量级API。这里的一个例子是设计dex转换器来完成转换工作。它将dex指令读取为dex ir格式，经过一些优化后，转换为ASM格式。dex translator使用的dex ir设计用于表示dex指令dex tools以处理.class文件。


10.Dfdatetime

dfDateTime ，又名Digital Forensics 日期和时间，提供日期和时间对象以保持准确性和精确度。


11.Dfvfs

数字取证虚拟文件系统提供对来自各种存储介质类型和文件格式的文件系统对象的只读访问。dfVFS 的目标是提供用于访问文件系统对象的通用接口，为此它使用多个后端，这些后端提供各种存储介质类型、卷系统和文件系统的实际实现。


12.Dfwinreg

dfWinReg，又名Digital Forensics Windows Registry，提供对 Windows 注册表对象的只读访问。dfWinReg 的目标是提供一个通用接口来访问 Windows 注册表对象，该对象类似于在实时 Windows 系统上看到的注册表项层次结构。


13.Dhcpig

DHCPig 发起高级 DHCP 耗尽攻击。它将消耗 LAN 上的所有 IP，阻止新用户获取 IP，释放任何正在使用的 IP，然后发送免费 ARP 并将所有 Windows 主机脱机。


它基于 scapy 库并请求管理员权限执行。它已经在多个 Linux 发行版和多个 DHCP 服务器（ISC、Windows 2k3/2k8 等）上进行了测试。


14.Dirb

DIRB 是一个 Web 内容扫描器。它寻找现有的（和/或隐藏的）Web 对象。它的工作原理是对 Web 服务器发起基于字典的攻击并分析响应。


DIRB 带有一组预配置的攻击词表，易于使用，但您可以使用自定义词表。此外，DIRB 有时可以用作经典的 CGI 扫描程序，但请记住，它是一个内容扫描程序，而不是漏洞扫描程序。


DIRB 的主要目的是帮助进行专业的 Web 应用程序审计。特别是在安全相关的测试。它涵盖了经典 Web 漏洞扫描程序未涵盖的一些漏洞。DIRB 查找其他通用 CGI 扫描程序无法查找的特定 Web 对象。它不会搜索漏洞，也不会查找可能存在漏洞的 Web 内容。


15.Dirbuster

DirBuster 是一个多线程 Java 应用程序，旨在暴力破解 Web/应用程序服务器上的目录和文件名。现在通常情况下，看起来像处于默认安装状态的 Web 服务器实际上并非如此，并且其中隐藏了页面和应用程序。DirBuster 试图找到这些。


然而，这种性质的工具通常与它们附带的目录和文件列表一样好。采取了不同的方法来生成它。该列表是从头开始生成的，通过抓取互联网并收集开发人员实际使用的目录和文件！DirBuster 共有 9 个不同的列表，这使得 DirBuster 在查找那些隐藏的文件和目录方面非常有效。如果这还不够，DirBuster 还可以选择执行纯暴力破解，从而使隐藏的目录和文件无处可藏。


16.Dirsearch

该软件包包含一个命令行工具，旨在暴力破解网络服务器中的目录和文件。


作为一个功能丰富的工具，dirsearch 为用户提供了执行复杂的 Web 内容发现的机会，它具有许多词表向量、高精度、令人印象深刻的性能、先进的连接/请求设置、现代暴力破解技术和良好的输出。


17.Dislocker

Dislocker 旨在读取 Linux 系统下的 BitLocker 加密分区。用于读取在 Windows 系统版本的 Vista to 10 和 BitLocker-To-Go 加密分区中加密的卷的驱动程序，即 USB/FAT32 分区。


该软件使用由库组成的驱动程序，多个二进制文件使用该库。解密分区，你必须给它一个挂载点，一旦密钥被解密，就会出现一个名为 dislocker-file 的文件。此文件是一个虚拟 NTFS 分区，因此您可以将其挂载为任何 NTFS 分区，然后对其进行读取或写入操作。写入 NTFS 虚拟文件将更改底层 BitLocker 分区内容。要使用 dislocker-find Ruby 是必需的。


该工具在密码管理和取证调查中很有用。


18.Distorm3

diStorm3 是一个二进制流反汇编库项目。


使用 diStorm3，不再需要解析字符串。diStorm3 实际上是一个分解器，这意味着它接受一条指令并返回一个描述它的二进制结构而不是静态文本。这对于高级二进制代码分析非常有用。


19.Dmitry

DMitry 是一个用 C 编写的 UNIX/(GNU)Linux 命令行应用程序。DMitry 可以找到可能的子域、电子邮件地址、正常运行时间信息、执行 tcp 端口扫描、whois 查找等。


20.Dns2tcp

dns2tcp 是一组将 TCP 会话封装在 DNS 数据包中的工具。与 IP-over-DNS 相比，这种类型的封装会生成更小的数据包，从而提高吞吐量。客户端不需要 root 权限。


21.Dnscat2

该工具旨在通过 DNS 协议创建加密的命令和控制 (C&C) 通道，这是几乎所有网络的有效隧道。


客户端设计为在受感染的机器上运行。


服务器设计为在权威 DNS 服务器上运行。


22.Dnschef

DNSChef 是一个高度可配置的 DNS 代理，适用于渗透测试人员和恶意软件分析师。DNS 代理（又名“假 DNS”）是一种用于应用程序网络流量分析等用途的工具。例如，DNS 代理可用于伪造对“badguy.com”的请求，以指向本地机器进行终止或拦截，而不是互联网上某处的真实主机。


23.Dnsenum

Dnsenum 是一个多线程 perl 脚本，用于枚举域的 DNS 信息并发现不连续的 ip 块。Dnsenum 的主要目的是收集尽可能多的域信息。该程序当前执行以下操作：


  • 获取主机地址（A 记录）。

  • 获取 namservers（线程）。

  • 获取 MX 记录（线程）。

  • 在名称服务器上执行 axfr 查询并获取 BIND 版本（线程）。

  • 通过谷歌抓取获取额外的名称和子域（谷歌查询 = “allinurl: -www site:domain”）。

  • 来自文件的蛮力子域，也可以对具有 NS 记录（所有线程）的子域执行递归。

  • 计算 C 类域网络范围并对它们执行 whois 查询（线程）。

  • 对网络范围（C 类或/和 whois 网络范围）（线程）执行反向查找。

  • 写入 domain_ips.txt 文件 ip-blocks。

该程序对渗透测试人员、道德黑客和取证专家很有用。它还可以用于安全测试。


24.Dnsgen

这个包提供了一个根据提供的输入生成域名组合的生成器。组合是基于单词列表创建的。每次执行都会提取自定义单词。

25.Dnsmap

dnsmap 使用内置或外部词表（如果使用 -w 选项指定）扫描域中的公共子域。内部单词表有大约 1000 个英语和西班牙语单词，如 ns1、firewall servicios 和 smtp。因此可以在 example.com 中自动搜索 smtp.example.com。结果可以保存为 CSV 和可读的格式以供进一步处理。dnsmap 不需要运行 root 权限，出于安全原因，不应使用此类权限运行。


dnsmap 最初于 2006 年发布，其灵感来自 Paul Craig 的虚构故事“无人看见的小偷”，该故事可以在“窃取网络 - 如何 0wn the Box”一书中找到。


dnsmap 主要供渗透测试人员在基础设施安全评估的信息收集/枚举阶段使用。在枚举阶段，安全顾问通常会发现目标公司的 IP 网络块、域名、电话号码等。


子域暴力破解是另一种应该在枚举阶段使用的技术，因为它在其他域枚举技术（例如区域转移）不起作用时特别有用（顺便说一下，我现在很少看到公开允许区域转移）。


可能发生的有趣事情：


  • 寻找有趣的远程访问服务器（例如：https://extranet.example.com）。

  • 查找配置不当和/或未打补丁的服务器（例如：test.example.com）。

  • 寻找新的域名，这将使您能够映射目标组织的不明显/难以找到的网络块（注册查询 - 又名 whois 是您的朋友）。

  • 有时您会发现一些暴力破解的子域解析为内部 IP 地址 (RFC 1918)。这很好，因为有时它们是真正的最新“A”记录，这意味着可以仅使用标准 DNS 解析（而不是区域传输）从 Internet 枚举目标组织的内部服务器。

  • 发现使用动态 DNS 服务配置的嵌入式设备（例如：IP 摄像机）。此方法是通过 Google 黑客技术查找设备的替代方法。

这个包提供了两个可能的命令：dnsmap 和 dnsmap-bulk。


该程序对渗透测试人员、道德黑客和取证专家很有用。它还可以用于安全测试。


26.Dnsrecon

DNSRecon 是一个 Python 脚本，可提供以下功能：


  • 检查区域转移的所有 NS 记录。

  • 枚举给定域的通用 DNS 记录（MX、SOA、NS、A、AAAA、SPF 和 TXT）。

  • 执行常见的 SRV 记录枚举。

  • 顶级域 (TLD) 扩展。

  • 检查通配符分辨率。

  • 给定域和词表的蛮力子域和主机 A 和 AAAA 记录。

  • 对给定的 IP 范围或 CIDR 执行 PTR 记录查找。

  • 检查 A、AAAA 和 CNAME 的 DNS 服务器缓存记录

  • Records 在文本文件中提供了主机记录列表以供检查。

  • 使用 Google 枚举主机和子域


27.Dnstracer

dnstracer 确定给定的域名服务器 (DNS) 从何处获取给定主机名的信息，并沿着DNS 服务器链返回权威答案。


28.Dnstwist

dnstwist 为给定的域名生成一个外观相似的域名列表，并为它们执行 DNS 查询（A、AAAA、NS 和 MX）。对于 MX 记录，它会检查是否存在可用于拦截误发电子邮件的活动邮件服务器。此外，它基于模糊哈希估计网页相似度。此功能可能有助于检测盗版者、网络钓鱼攻击、欺诈和企业间谍活动。


29.Dnswalk

dnswalk 是一个 DNS 调试器。它执行指定域的区域传输，并以多种方式检查数据库的内部一致性和准确性。


30.Doona

Doona 是 Bruteforce Exploit Detector Tool (BED) 的一个分支。BED 是一个程序，旨在检查后台进程是否存在潜在的缓冲区溢出、格式字符串错误等。


31.Dos2unix

该软件包包含实用程序 dos2unix、unix2dos、mac2unix、unix2mac，用于在 UNIX (LF)、DOS (CRLF) 和 Mac (CR) 格式之间转换文本文件的行尾。


Windows 和 DOS 下的文本文件通常在每行末尾有两个 ASCII 字符：CR（回车）后跟 LF（换行）。较旧的 Mac 仅使用 CR，而 UNIX 仅使用 LF。虽然大多数现代编辑器可以读取所有这些格式，但可能仍然需要在它们之间转换文件。


32.Dotdotpwn

DotDotPwn 是一个非常灵活的智能模糊器，用于发现软件（如 HTTP/FTP/TFTP 服务器）、Web 平台（如 CMS、ERP、博客等）中的遍历目录漏洞。


33.Dradis

Dradis 是一个帮助渗透测试过程的工具。渗透测试是关于信息的：


1.信息发现

2.利用有用的信息

3.报告调查结果

但是渗透测试也是关于共享您和您的队友收集的信息。不以有效方式共享可用信息将导致失去开发机会和工作重叠。


34.Driftnet

受 EtherPEG 的启发，Driftnet 是一个侦听网络流量并从它观察到的 TCP 流中挑选图像的程序。在看到大量网络流量的主机上运行它很有趣。


（显然，这是一种相当公然侵犯隐私的行为。此外，如果您具有维多利亚时代的敏感性，并与其他人共享未切换的网络，则您可能不应该使用它。）


35.Dsniff

这个包包含几个监听和创建网络流量的工具：


  • arpspoof - 发送未经请求的（可能是伪造的）arp 回复。

  • dnsspoof - 伪造对局域网上任意 DNS 地址/指针查询的回复。

  • dsniff - 多种协议的密码嗅探器。

  • filesnarf - 保存从 NFS 流量中嗅探到的选定文件。

  • macof - 用随机 MAC 地址淹没本地网络。

  • mailsnarf - 嗅探 LAN 上的邮件并将其存储为 mbox 格式。

  • msgsnarf - 记录来自不同 Instant Messenger 的选定消息。

  • sshmitm - SSH 中间人。代理和嗅探 SSH 流量。

  • sshow - SSH 流量分析器。

  • tcpkill - 杀死指定的正在进行的 TCP 连接。

  • tcpnice - 通过“主动”流量整形减慢指定的 TCP 连接。

  • urlsnarf - 输出从 CLF 中的 HTTP 流量中嗅探到的选定 URL。

  • webmitm - HTTP / HTTPS 中间人。透明代理。

  • webspy - 将从客户端嗅探到的 URL 发送到您的本地浏览器（需要安装 libx11-6）。

请不要滥用本软件。


36.Dumpsterdiver

该软件包包含一个工具，该工具可以分析大量数据以搜索硬编码的秘密，例如密钥（例如 AWS 访问密钥、Azure 共享密钥或 SSH 密钥）或密码。此外，它还允许创建具有基本条件的简单搜索规则（例如，仅报告包含至少 10 个电子邮件地址的 csv 文件）。


该工具的主要思想是检测任何潜在的秘密泄漏。


37.Dumpzilla

Dumpzilla 应用程序是在 Python 3.x 中开发的，该工具适用于Firefox、Iceweasel、Seamonkey浏览器。它能提取这些浏览器中的各种隐私信息，如Cookie、用户偏好设置、下载记录、表单、浏览历史、书签、HTML5缓存、缩略图、组件、SSL证书等。同时，该工具允许渗透测试人员对信息进行过滤，如根据时间过滤。对于部分信息，它还提供导出功能。由于其 Python 3.x 开发，在旧的 Python 版本中可能无法正常工作，主要是某些字符。在 Unix 和 Windows 32/64 位系统下工作。在命令行界面中工作，因此信息转储可以通过管道使用 grep、awk、cut、sed 等工具重定向…… Dumpzilla 允许人们可视化以下部分、搜索自定义和提取某些内容。
