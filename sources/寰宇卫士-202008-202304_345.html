1.Cabextract

Cabextract 是一个解包压缩文件 (.cab) 的程序，这是微软用来分发其软件和 Windows 字体包之类的一种存档形式。


2.Cadaver

cadaver 支持文件上传、下载、屏幕显示、就地编辑、命名空间操作（移动/复制）、集合创建和删除、属性操作和资源锁定。


它的操作类似于标准的 BSD ftp(1) 客户端和 Samba 项目的 smbclient(1)。


该软件包包括 GnuTLS (HTTPS) 支持。


WebDAV（基于 Web 的分布式创作和版本控制）是 HTTP 协议的一组扩展，允许用户协作编辑和管理远程 Web 服务器上的文件。


3.Caldera

CALDERA是一个网络安全框架，旨在轻松模拟自动化的对手，协助手动红队或自动化事件响应。


4.Capstone

Capstone 是一个轻量级的多平台、多架构的反汇编框架。


特征：


  • 支持硬件架构：ARM、ARM64（又名 ARMv8）、Mips、PowerPC 和 Intel。

  • 干净/简单/轻量级/直观的架构中立 API。

  • 提供有关反汇编指令（被其他人称为“分解器”）的详细信息。

  • 提供反汇编指令的一些语义，例如读取和写入的隐式寄存器列表。

  • 用纯 C 语言实现，带有 Java、OCaml 和 Python 的绑定可供使用，Ruby、C#、GO 和 Vala 可在 git repos 上使用。

  • 对 Windows 和 *nix 的本机支持（已确认 OS X、Linux、*BSD 和 Solaris）。

  • 线程安全的设计。

  • 特别支持嵌入固件或操作系统内核。

  • 在开源 BSD 许可下分发。


5.Ccrypt

ccrypt 是一个用于加密和解密文件和流的实用程序。它被设计为标准 unix crypt 实用程序的替代品，后者因使用非常弱的加密算法而臭名昭著。ccrypt 基于 Rijndael 密码，这是美国政府为高级加密标准 (AES，请参阅http://www.nist.gov/aes)选择的候选密码。这种密码被认为提供了非常强大的安全性。


6.Certgraph

这个工具用来爬取证书备用名称的图表。CertGraph 抓取 SSL 证书，创建一个有向图，其中每个域都是一个节点，该域证书的证书替代名称是其他域节点的边。新域在发现时打印。在详细模式下，完成后会打印图形的邻接列表。


抓取默认通过 TCP 连接收集证书，但是有多个驱动程序可以搜索证书透明度日志。


该工具旨在用于通过 SSL 证书进行主机名枚举，但它也可以向您显示域之间的信任“链”以及在它们之间重复使用的证书。


7.Cewl

CeWL（自定义单词列表生成器）是一个ruby应用程序，它爬取给定的 URL，达到指定的深度，并返回一个单词列表，然后可以将其用于密码破解程序，例如开膛手约翰。或者，CeWL 可以遵循外部链接。


CeWL 还可以创建在 mailto 链接中找到的电子邮件地址列表。这些电子邮件地址可用作暴力破解中的用户名。


CeWL 项目提供的另一个工具是 FAB（Files Already Bagged）。FAB 从一些文件的元数据中提取作者/创建者字段的内容，以创建可能的用户名列表。这些用户名可以与 CeWL 生成的密码列表结合使用。FAB 使用与 CeWL 相同的元数据提取技术。目前，FAB 处理 Office pre 2007、Office 2007 和 PDF 格式。


CeWL 在安全测试和取证调查中很有用。


8.Changeme

这是一个默认的凭证扫描器。商业漏洞扫描器会丢失常见的默认凭据。将默认凭据添加到商业扫描仪通常既困难又缓慢。changeme 旨在轻松添加新凭据，而无需编写任何代码或模块。


changeme 将凭证数据与代码分开。所有凭据都存储在 yaml 文件中，因此它们既可以被人类轻松读取，也可以由 changeme 处理。可以使用 ./changeme.py –mkcred 工具并回答几个问题来创建凭证文件。


changeme 支持 http/https、MSSQL、MySQL、Postgres、ssh 和 ssh w/key 协议。使用 ./changeme.py –dump 输出所有当前可用的凭据。


9.Chaosreader

Chaosreader 跟踪 TCP/UDP/others 会话并从 snoop 或 tcpdump 日志（或其他 libpcap 兼容程序）获取应用程序数据。这是一种“any-snarf”程序，因为它将从网络流量日志中捕获的数据中获取 telnet 会话、FTP 文件、HTTP 传输（HTML、GIF、JPEG 等）和 SMTP 电子邮件。创建一个 html 索引文件，该文件链接到所有会话详细信息，包括 telnet、rlogin、IRC、X11 和 VNC 会话的实时重播程序。Chaosreader 报告，例如图像报告和 HTTP GET/POST 内容报告。


它还为 telnet 会话创建重播程序，以便您可以实时（甚至以不同的速度）播放它们。


Chaosreader 也可以在独立模式下运行，它调用 tcpdump 或 snoop（类似于 Solaris 的 tcpdump 程序）来创建日志文件，然后处理它们。


该工具可用于取证调查和网络流量分析。


10.Cherrytree

CherryTree是一个分层笔记应用程序，具有富文本、语法突出显示、图像处理、超链接、支持多种格式的导入/导出、支持多种语言等功能。


11.Chirp

CHIRP 是一种免费的开源工具，用于对业余无线电进行编程。它支持大量的制造商和型号，并提供了一种与多种数据源和格式进行交互的方式。


CHIRP 可以处理以下格式的数据：


Comma Separated Values (.csv)

Comma Separated Values generated by RT Systems (.csv)

EVE for Yaesu VX-5 (.eve)

Kenwood HMK format (.hmk)

Kenwood commercial ITM format (.itm)

Icom Data Files (.icf)

ARRL TravelPlus (.tpe)

VX5 Commander Files (.vx5)

VX7 Commander Files (.vx7)

CHIRP 通过其接口电缆支持大多数流行的现代业余无线电。


12.Chisel

这是一个快速的 TCP/UDP 隧道，通过 HTTP 传输，通过 SSH 保护。单个可执行文件，包括客户端和服务器。Chisel 主要用于通过防火墙，但它也可用于为您的网络提供安全端点。


13.Chkrootkit

chkrootkit 安全扫描程序会在本地系统中搜索是否有感染“rootkit”的迹象。Rootkit 是一组程序和黑客，旨在通过使用已知的安全漏洞来控制目标机器。


chkrootkit 可以识别的类型列在项目的主页上。


请注意，在 chkrootkit 没有检测到入侵的情况下，这并不能保证系统不会受到损害。除了运行 chkrootkit 之外，还应始终执行更具体的测试。


14.Chntpw

这个小程序提供了一种在 Windows NT/2000 用户数据库文件中查看信息和更改用户密码的方法。不需要知道旧密码，因为它们会被覆盖。此外，它还包含一个简单的注册表编辑器（相同大小的数据写入）和一个十六进制编辑器，它使您可以随意修改文件中的位和字节。


如果您想要 GNU/Linux 引导盘用于离线密码恢复，您可以将此实用程序添加到自定义映像磁盘或使用工具主页上提供的那些。


15.Chromium

旨在构建更安全、更快、更稳定的互联网浏览体验的Web浏览器。


16.Cifs-Utils

SMB/CIFS 协议支持与 Microsoft Windows、OS X 和其他 Unix 系统的跨平台文件共享。


该软件包提供了用于管理 CIFS 网络文件系统挂载的实用程序。


17.Cisco-Auditing-Tool

Perl 脚本，用于扫描 cisco 路由器的常见漏洞。


18.Cisco-Global-Exploiter

Cisco Global Exploiter (CGE)，是一种先进、简单、快速的安全测试工具。


19.Cisco-Ocs

大规模思科扫描工具。


20.Cisco-Torch

使 cisco-torch 与同类工具不同的主要特点是广泛使用 fork 在后台启动多个扫描进程，以实现最大扫描效率。此外，如果需要，它还可以同时使用多种应用层指纹识别方法。我们想要快速发现运行 Telnet、SSH、Web、NTP、TFTP 和 SNMP 服务的远程 Cisco 主机，并对发现的服务发起字典攻击，包括 SNMP 社区攻击（您需要 community.txt 列表 :-) 和 TFTP 服务器（配置文件名 bruteforcing 与以下配置窃取）。如果找到 SNMP RW 社区，该工具还可以自动获取设备配置文件。


21.Cloud-Enum

cloud_enum 枚举公共云中匹配用户请求关键字的公共资源：

亚马逊网络服务：

谷歌云平台：

  • 受保护的 GCP 存储桶

  • Google App Engine 网站


22.Cloudbrute

该软件包包含一个工具，用于在顶级云提供商（亚马逊、谷歌、微软、DigitalOcean、阿里巴巴、Vultr、Linode）上查找公司（目标）基础设施、文件和应用程序。


结果对漏洞赏金猎人、红队人员和渗透测试人员都很有用。


  • 云检测（IPINFO API 和源代码）

  • 支持所有主要提供商• Black-Box（未经身份验证）

  • 快速（并发）

  • 模块化且易于定制

  • 跨平台（windows、Linux、mac）

支持的云提供商

23.Cmospwd

CmosPwd 是一种跨平台工具，用于解密存储在 CMOS 中的密码，用于访问计算机的 BIOS 设置。


这个应用程序应该在大多数现代系统上开箱即用，但一些更深奥的 BIOS 可能不受支持或可能需要额外的步骤。


24.Cmseek

该软件包包含一个 CMS 检测和利用套件。它扫描 WordPress、Joomla、Drupal 和 180 多个其他 CMS。


内容管理系统 (CMS) 管理数字内容的创建和修改。它通常支持协作环境中的多个用户。


25.Code-Oss

这是一个代码编辑器，具有开发人员在其核心编辑-构建-调试周期中所需的功能。它提供全面的代码编辑、导航和理解支持以及轻量级调试、丰富的可扩展性模型以及与现有工具的轻量级集成。


这个包是由名为 code-oss 的微软开源代码构建的。


26.Command-Not-Found

该软件包将为 command_not_found 安装一个处理程序，用于查找当前未安装但可从存储库中获得的程序。


27.Commix

该软件包包含 Commix（[comm] 和 [i]njection e[x]ploiter 的缩写）。它有一个简单的环境，可以被 Web 开发人员、渗透测试人员甚至安全研究人员用来测试 Web 应用程序，以发现与命令注入攻击相关的错误、错误或漏洞。通过使用该工具，可以很容易地发现并利用某个易受攻击的参数或字符串中的命令注入漏洞。Commix 是用 Python 编程语言编写的。


28.Copy-Router-Config

该软件包从运行 SNMP 的 Cisco 设备复制配置文件。


29.Covenant-Kbx

该软件包包含 Covenant：.NET 命令和控制框架，旨在突出 .NET 的攻击面，使.NET 技术的使用更容易，并作为红队人员的协作命令和控制平台。


Covenant 是一个 ASP.NET Core 跨平台应用程序，它包括一个允许多用户协作的基于 Web 的界面。


30.Cowpatty

如果您正在审核 WPA-PSK 或 WPA2-PSK 网络，您可以使用此工具来识别用于生成 PMK 的弱密码短语。提供包含 4 次握手的 libpcap 捕获文件、用于猜测的密码短语字典文件以及网络的 SSID。


31.Crack

破解程序旨在通过扫描密码文件的内容来快速定位 Unix（或其他）密码文件中的漏洞，寻找误选弱登录密码的用户。


32.Crackle

Crackle 利用了 BLE 配对过程中的一个缺陷，该缺陷允许攻击者猜测或非常快速地暴力破解 TK（临时密钥）。通过配对过程中收集的 TK 和其他数据，可以收集 STK（短期密钥）和以后的 LTK（长期密钥）。


使用STK和LTK，可以解密主从之间的所有通信


33.Crackmapexec

该软件包是用于渗透测试 Windows/Active Directory 环境的瑞士军刀。


从枚举登录用户和爬取 SMB 共享到执行 psexec 风格的攻击，使用 Powershell 将 Mimikatz/Shellcode/DLL 自动注入内存，转储 NTDS.dit 等等。


对上述工具的最大改进是：


  • 纯 Python 脚本，无需外部工具

  • 全并发线程

  • 仅使用本机 WinAPI 调用来发现会话、用户、转储 SAM 哈希等……

  • Opsec 安全（不上传二进制文件以转储明文凭据、注入 shellcode 等……）

此外，数据库用于存储使用/转储的凭据。它还自动将管理员凭据与主机相关联，反之亦然，使您可以轻松跟踪凭据集并在大型环境中获得额外的态势感知。


34.Creddump7

这个包包含一个 Python 工具，用于从 Windows 注册表配置单元中提取各种凭据和机密。它基于 creddump 程序。Ronnie Flathers 应用了许多补丁和修复程序。


35.Crowbar

该软件包包含 Crowbar（正式名称为 Levye）。它是一种可以在渗透测试期间使用的暴力破解工具。它的开发目的是根据其他流行的暴力破解工具以不同的方式暴力破解某些协议。例如，虽然大多数暴力破解工具使用用户名和密码进行 SSH 暴力破解，但 Crowbar 使用 SSH 密钥。这允许在渗透测试期间获得的任何私钥用于攻击其他 SSH 服务器。


目前 Crowbar 支持：* OpenVPN (-b openvpn) * 支持 NLA 的远程桌面协议 (RDP) (-b rdp) * SSH 私钥认证 (-b sshkey) * VNC 密钥认证 (-b vpn)


36.Crunch

Crunch 是一个词表生成器，您可以在其中指定一个标准字符集或任何用于生成词表的字符集。词表是通过一组字符的组合和排列来创建的。您可以确定字符数和列表大小。


该程序支持数字和符号、大小写字符分别和Unicode。


37.Cryptcat

Cryptcat 是一个简单的 Unix 实用程序，它使用 TCP 或 UDP 协议通过网络连接读取和写入数据，同时对正在传输的数据进行加密。它被设计成一个可靠的“后端”工具，可以直接使用或由其他程序和脚本轻松驱动。同时，它还是一个功能丰富的网络调试和探索工具，因为它几乎可以创建您需要的任何类型的连接，并且具有几个有趣的内置功能。


38.Cryptsetup

Cryptsetup 提供了一个接口，用于在块设备（例如 /home 或交换分区）上配置加密，使用 Linux 内核设备映射器目标 dm-crypt。它具有集成的 Linux 统一密钥设置 (LUKS) 支持。


Cryptsetup 向后兼容 cryptoloop 的磁盘格式，但也支持更安全的格式。该软件包支持在启动时通过配置文件 /etc/crypttab 自动配置加密设备。其他功能是通过 initramfs-tools 支持加密根，以及读取密码或密钥的几种支持方式。


39.Cryptsetup-Nuke-Password

安装这个包可以让你配置一个特殊的“nuke 密码”，它可以用来破坏解锁加密分区所需的加密密钥。可以在通常的早期启动提示中输入此密码，要求密码短语解锁加密分区。


这提供了一种相对隐蔽的方式，让您的数据无法读取，以防您担心您的计算机会被没收。


安装后，使用“dpkg-reconfigure cryptsetup-nuke-password”来配置你的nuke密码。


40.Curlftpfs

CurlFtpFS 是一个将 FTP 主机挂载为本地目录的工具。它连接到 FTP 服务器并将其目录结构映射到本地文件系统。


基于 FUSE（用户空间中的文件系统）和 cURL 库，CurlFtpFS 有一些区别于其他 FTP 文件系统的特性：


  • 支持 SSLv3 和 TLSv1

  • 通过隧道 HTTP 代理连接

  • 如果服务器超时自动重新连接

  • 转换绝对符号链接以指向回 FTP 文件系统


41.Cutecom

Cutecom 是一个图形串行终端，类似于 minicom。它主要针对硬件开发人员或其他需要终端与设备对话的人。它具有面向行的界面而不是面向字符的、xmodem、ymodem、zmodem 支持（需要 lrzsz 包）和十六进制输入和输出等。它是使用 Qt 库最初由 Trolltech ( www.trolltech.com )编写的。


42.Cutycapt

CutyCapt 是一个小型跨平台命令行实用程序，用于将 WebKit 对网页的渲染捕获为各种矢量和位图格式，包括 SVG、PDF、PS、PNG、JPEG、TIFF、GIF 和 BMP。


43.Cymothoa

Cymothoa 是一种隐形后门工具，它将后门的 shellcode 注入现有进程。该工具使用 ptrace 库（几乎在所有 * nix 上都可用）来操纵进程并感染它们。
