**1.galleta**

Galleta是一种取证工具，用于检查由Microsoft Internet Explorer（MSIE）生成的cookie文件的内容。它解析文件并输出一个分隔的字段，该字段可以加载到电子表格中。

  

如何安装：sudo apt install galleta

  

**2.gdb**

GDB是一个源代码级调试器，能够在任何特定行中断程序，显示变量值，并确定错误发生的位置。目前，GDB支持C、C++、D、Objto-C、FORTRAN、java、OpenCL C、PASCAL、汇编、Muldia2、GO和艾达。对于任何一个认真的程序员来说，这都是必须的。

  

如何安装：sudo apt install gdb

  

(1)gdb-minimal

此包包含禁用可选功能的 GDB 的最小版本。

  

如何安装：sudo apt install gdb-minimal

  

(2)gdb-multiarch

此包包含支持多个目标架构的 GDB 版本。

  

如何安装：sudo apt install gdb-multiarch

  

(3)gdbserver

此包包含 gdbserver。安装此以从安装 GDB 的另一个系统远程调试。

  

如何安装：sudo apt install gdbserver

  

**3.gdisk**

GPT fdisk（又名gdisk）是一种文本模式分区工具，为全局唯一标识符（GUID）分区表（GPT）磁盘提供实用程序。

特征：

*   编辑GUID分区表定义
    
*   将BSD磁盘标签就地转换为GPT
    
*   MBR就地转换为GPT
    
*   GPT就地转换为MBR
    
*   创建混合MBR/GPT布局
    
*   修复损坏的GPT数据结构
    
*   修复受损的MBR结构
    
*   将GPT数据备份到文件（并从文件还原）
    

  

如何安装：sudo apt install gdisk

  

**4.getallurls**

此包包含getallurls（gau）。它从AlienVault的开放式威胁交换获取已知URL(https://otx.alienvault.com)、回程机器和任何给定域的通用爬网。灵感来源于Tomnom的WaybackURL。

  

如何安装：sudo apt install getallurls

  

**5.ghidra**

该软件包包含由国家安全局研究局创建和维护的软件逆向工程（SRE）框架。该框架包括一套功能齐全的高端软件分析工具，使用户能够在各种平台（包括Windows、macOS和Linux）上分析编译后的代码。功能包括反汇编、组装、反编译、绘图和脚本，以及数百种其他功能。Ghidra支持多种处理器指令集和可执行格式，可以在用户交互和自动模式下运行。用户还可以使用Java或Python开发自己的Ghidra扩展组件和/或脚本。

为了支持NSA的网络安全任务，Ghidra旨在解决复杂SRE工作中的扩展和团队问题，并提供可定制和可扩展的SRE研究平台。NSA已将Ghidra SRE能力应用于各种问题，包括分析恶意代码，并为SRE分析师提供深入见解，以便他们更好地了解网络和系统中的潜在漏洞。

  

如何安装：sudo apt install ghidra

**8.gnuradio**

GNU无线电提供信号处理模块来实现软件无线电。它可以与现成的低成本外部射频硬件一起使用，以创建软件定义的无线电，也可以在类似模拟的环境中不使用硬件。它广泛用于业余爱好者、学术界和商业环境，以支持无线通信研究和现实世界的无线电系统。

GNU无线电应用程序主要是使用Python编程语言编写的，而提供的性能关键信号处理路径是在C++中使用处理器浮点扩展（可用）实现的。因此，开发人员能够在简单易用、快速的应用程序开发环境中实现实时、高吞吐量的无线电系统。

虽然GNU Radio主要不是一个模拟工具，但它确实支持使用预记录或生成的数据开发信号处理算法，从而避免了对实际射频硬件的需要。

这个包包含gnuradio companion，一个用于创建信号流图和生成流图源代码的图形工具。还包括各种工具和实用程序。

  

如何安装：sudo apt install gnuradio

**15.gpart**

Gpart是一种工具，用于在扇区0中的主分区表损坏、不正确或删除时，尝试猜测PC类型磁盘的主分区表。

它还擅长查找和列出无意中删除的分区（包括主分区和逻辑分区）的类型、位置和大小。它为您提供手动重新创建它们所需的信息（使用fdisk、cfdisk、sfdisk等）。

  

猜测表也可以写入文件，或者（如果您坚信猜测表完全正确）直接写入磁盘设备。

当前支持的（可猜测的）文件系统或分区类型：

*   BeOS文件系统类型。
    
*   BtrFS文件系统类型。
    
*   英特尔平台上使用的FreeBSD/NetBSD/386BSD disklabel子分区方案。
    
*   Linux第二扩展文件系统（Ext2）。
    
*   MS-DOS FAT12、FAT16和FAT32“文件系统”。
    
*   IBM OS/2高性能文件系统。
    
*   Linux LVM和LVM2物理卷。
    
*   Linux交换分区（版本0和1）。
    
*   Minix操作系统文件系统类型。
    
*   MS Windows NT/2000文件系统。
    
*   qnx4.x文件系统。
    
*   Reiser文件系统（版本3.5.X，X>11）。
    
*   英特尔平台上的Sun Solaris在PC硬盘上使用类似于BSD磁盘标签的子分区方案。
    
*   用于Linux的Silicon Graphics日志文件系统。
    

Gpart在恢复行动和取证调查中非常有用。

  

如何安装：sudo apt install gpart
