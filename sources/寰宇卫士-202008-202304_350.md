**1.0trace**

该软件包是 traceroute 工具，可以在现有的开放 TCP 连接中运行，因此可以轻松绕过某些类型的有状态数据包过滤器。

  

**2.O-Saft**

O-Saft 是一个易于使用的工具，用于显示有关 SSL 证书的信息并根据给定的密码列表和各种 SSL 配置测试 SSL 连接。

它旨在供渗透测试员、安全审计员或服务器管理员使用。这个想法是通过简单的工具调用来显示重要信息或特殊检查。但是，它提供了广泛的选项，因此可以由有经验的人员进行全面和特殊的检查。

  

**3.Oclgausscrack**

该程序的目标是破解高斯病毒加密载荷的验证哈希。

  

**4.Odat**

该软件包包含 ODAT（Oracle 数据库攻击工具），这是一种开源渗透测试工具，可远程测试 Oracle 数据库的安全性。

ODAT 的使用示例：

您有一个Oracle数据库正在远程侦听，并希望找到有效的SID和凭据以连接到数据库

您在数据库上拥有有效的 Oracle 帐户，并希望将您的权限提升为 DBA 或 SYSDBA

您有一个Oracle帐户，并且希望执行系统命令（例如，reverse shell），以便在托管数据库的操作系统上向前移动

  

**5.Offsec-Courses**

offsec-awae

这是 Kali Linux，最先进的渗透测试和安全审计发行版。

这个元包依赖于 OffSec 的 AWAE/WEB-300/OSWE 所需的资源。

  

offsec-awe-python2

本包为OffSec的AWAE提供Python 2资源，依赖于OffSec的AWAE/WEB-300/OSWE所需的资源。

  

offsec-exp301

这是 Kali Linux，最先进的渗透测试和安全审计发行版。

该元数据包取决于 OffSec 的 WUMED/EXP-301/OSED 所需的资源。

  

offsec-pen300

这是 Kali Linux，最先进的渗透测试和安全审计发行版。

此元数据包取决于 OffSec 的 ETBD/PEN-300/OSEP 所需的资源。

  

offsec-pwk

这是 Kali Linux，最先进的渗透测试和安全审计发行版。

这个元包依赖于 OffSec 的 PWK2/PEN-200/OSCP 所需的资源。

  

**6.Ohrwurm**

ohrwurm 是一个小巧而简单的 RTP 模糊器，已在少量 SIP 电话上成功测试。

  

**7.Ollydbg**

OllyDbg 是用于 Microsoft Windows 的 32 位汇编程序级分析调试器。强调二进制代码分析使其在源不可用的情况下特别有用。

  

**8.Onesixtyone**

oneixtyone 是一个简单的 SNMP 扫描器，它以用户可调整的发送时间异步发送 sysDescr 值的 SNMP 请求，然后记录响应，给出设备上运行的软件的描述。

使用 -w 10 在 B 类网络（交换 100Mbs 和 1Gbs 主干网）上运行 oneixtyone，每个 C 类网络的性能为 3 秒，没有丢包，并且所有 65536 个 IP 地址都在不到 13 分钟的时间内完成扫描。

  

**9.Openocd**

OpenOCD 旨在为嵌入式目标设备提供调试、系统内编程和边界扫描测试。

调试器使用符合 IEEE 1149-1 标准的 JTAG TAP 总线主机来访问基于 ARM 的微控制器或片上系统解决方案上可用的片上调试功能。对于 MIPS 系统，支持 EJTAG 接口。此外，还支持 eSi-RISC、Intel、OpenRISC、RISC-V 和 ARC 控制器。

用户交互是通过 telnet 命令行界面、gdb（GNU 调试器）远程协议服务器和可用于与 OpenOCD 的 Jim Tcl 引擎进行交互的简化 RPC 连接来实现的。

OpenOCD 支持许多不同类型的 JTAG 接口/编程器。

  

**10.Openssh**

openssh-client

这是 OpenSSH 的可移植版本，是 IETF secsh 工作组指定的 Secure Shell 协议的免费实现。

Ssh（Secure Shell）是一个用于登录远程机器并在远程机器上执行命令的程序。它通过不安全的网络在两个不受信任的主机之间提供安全的加密通信。X11 连接和任意 TCP/IP 端口也可以通过安全通道转发。它可用于为应用程序提供安全的通信通道。

这个包提供了 ssh、scp 和 sftp 客户端、ssh-agent 和 ssh-add 程序，使公钥认证更方便，以及 ssh-keygen、ssh-keyscan、ssh-copy-id 和 ssh-argv0 实用程序。

在某些国家/地区，未经特别许可使用任何加密都可能是非法的。

ssh 替换了不安全的 rsh、rcp 和 rlogin 程序，这些程序在大多数情况下已过时。

  

openssh-server

这是 OpenSSH 的可移植版本，是 IETF secsh 工作组指定的 Secure Shell 协议的免费实现。

Ssh（Secure Shell）是一个用于登录远程机器并在远程机器上执行命令的程序。它通过不安全的网络在两个不受信任的主机之间提供安全的加密通信。X11 连接和任意 TCP/IP 端口也可以通过安全通道转发。它可用于为应用程序提供安全的通信通道。

这个包提供了 sshd 服务器。

在某些国家/地区，未经特别许可使用任何加密都可能是非法的。

sshd 替换了不安全的 rshd 程序，该程序在大多数情况下已过时。

  

openssh-sftp-server

这是 OpenSSH 的可移植版本，是 IETF secsh 工作组指定的 Secure Shell 协议的免费实现。

Ssh（Secure Shell）是一个用于登录远程机器并在远程机器上执行命令的程序。它通过不安全的网络在两个不受信任的主机之间提供安全的加密通信。X11 连接和任意 TCP/IP 端口也可以通过安全通道转发。它可用于为应用程序提供安全的通信通道。

该软件包为 SSH 服务器提供了 SFTP 服务器模块。如果您想使用 SFTP 访问您的 SSH 服务器，则需要它。SFTP 服务器模块还可以与 dropbear 等其他 SSH 守护程序一起使用。

OpenSSH 的 sftp 和 sftp-server 实现了 SSH filexfer 协议的修订版 3，如下所述：

http://www.openssh.com/txt/draft-ietf-secsh-filexfer-02.txt

不支持较新版本的草稿，但有些功能是作为扩展单独实现的。

  

openssh-tests

这个包提供了 OpenSSH 的回归测试套件。它主要用于 autopkgtest 系统，但也可以直接使用 /usr/lib/openssh/regress/run-tests 运行。

  

ssh

此元数据包是安装 OpenSSH 客户端和 OpenSSH 服务器的便捷方式。它本身不提供任何内容，因此如果没有任何依赖，您可以将其删除。

  

ssh-askpass-gnome

这已经从主openssh客户端包中分离出来，因此openssh客户端不需要依赖GTK+。

您可能希望使用ssh askpass包，但这会增加您的选择和/或困惑。

  

**11.Openvpn**

OpenVPN 是一种通过单个 UDP 或 TCP 端口安全地建立 IP 网络隧道的应用程序。它可用于访问远程站点、建立安全的点对点连接、增强无线安全性等。

OpenVPN 使用 OpenSSL 库提供的所有加密、身份验证和认证功能（任何密码、密钥大小或 HMAC 摘要）。

OpenVPN 可以使用静态的、预共享的密钥或基于 TLS 的动态密钥交换。它还支持具有动态端点（DHCP 或拨号客户端）、NAT 隧道或面向连接的状态防火墙（例如 Linux 的 iptables）的 VPN。

  

**12.Ophcrack**

Ophcrack 是一个 Windows 密码破解程序，它基于使用彩虹表的时间——内存权衡。这是 Hellman 原始权衡的新变体，具有更好的性能。它可以在几秒钟内恢复 99.9% 的字母数字密码。

它适用于 Windows NT/2000/XP/Vista/7。

该软件包包含基于 QT4 的图形 UI 的 ophcrack。请注意，它也可以在命令行中使用。

  

ophcrack-cli

Ophcrack 是一个 Windows 密码破解程序，它基于使用彩虹表的时间——内存权衡。这是 Hellman 原始权衡的新变体，具有更好的性能。它可以在几秒钟内恢复 99.9% 的字母数字密码。

它适用于 Windows NT/2000/XP/Vista/7。

该软件包仅包含带有命令行界面的 ophcrack。

  

**13.Oscanner**

Oscanner 是一个用 Java 开发的 Oracle 评估框架。它有一个基于插件的架构，并带有几个目前可以执行的插件：

Sid 枚举

密码测试（常用和字典）

枚举 Oracle 版本

枚举帐户角色

枚举帐户权限

枚举帐户哈希

枚举审计信息

枚举密码策略

枚举数据库链接

结果以图形 Java 树形式给出。

  

**14.Osrframework**

该软件包包含一组由 i3visio 开发的用于执行开源智能任务的库。它们包括对一系列与用户名检查、DNS 查找、信息泄漏研究、深度网络搜索、正则表达式提取等相关的不同应用程序的引用。

  

**15.Outguess**

OutGuess 是一种通用的隐写术工具，它允许将隐藏信息插入到数据源的冗余位中。数据源的性质与 OutGuess 的核心无关。

该程序依赖于数据特定处理程序，这些处理程序将提取冗余位并在修改后将它们写回。支持的格式为 JPEG、PPM 和 PNM。

这个包在取证调查和安全行动中很有用。

  

**16.Owasp-Mantra-Ff**

Mantra 是一款专为 Web 应用程序安全测试而设计的浏览器。通过拥有这样的产品，更多的人将了解能够在浏览器中遵循基本测试程序的简单性和灵活性。Mantra 认为，拥有这样一个便携、易于使用且功能强大的平台会对行业有所帮助。

Mantra 有许多内置工具来修改标头、操作输入字符串、重放 GET/POST 请求、编辑 cookie、在多个代理之间快速切换、控制强制重定向等。这使其成为执行基本安全检查和有时进行利用的好软件。因此，Mantra 可用于解决各种基于 Web 的 CTF 的基本级别，展示易受攻击的 Web 应用程序中的安全问题等。

  

**17.Owl**

该软件包包含用 C 编写的适用于 Linux 和 macOS 的 Apple Wireless Direct Link (AWDL) ad hoc 协议的开放实现以及 Open Wireless Link 项目的一部分。

OWL 在用户空间运行，并利用 Linux 的 Netlink API 进行 Wi-Fi 特定操作，例如信道切换，并通过提供虚拟网络接口将自身集成到 Linux 网络堆栈中，以便现有支持 IPv6 的程序无需修改即可使用 AWDL。
