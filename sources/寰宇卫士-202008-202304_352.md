**1.Nasm**

网络汇编程序。NASM 当前将输出平面形式的二进制文件、a.out、COFF 和 ELF Unix 目标文件，以及 Microsoft 16 位 DOS 和 Win32 目标文件。

还包括 NDISASM，这是一个原型 x86 二进制文件反汇编程序，它使用与 NASM 相同的指令表。

NASM 是在 GNU 宽松通用公共许可证 (LGPL) 下发布的。

  

**2.Nasty**

Nasty 是一个程序，它可以帮助您恢复 PGP 或 GPG 密钥的密码，以防您忘记或丢失它。以下功能将使事情变得更容易：

设置密码的最小/最大长度

增量模式、随机模式或读取文件进行猜测

字符集过滤器

这个包在取证调查中很有用。

  

**3.Nbtscan**

NBTscan 是一个用于扫描 IP 网络以获取 NetBIOS 名称信息的程序。它向提供范围内的每个地址发送 NetBIOS 状态查询，并以人类可读的形式列出接收到的信息。对于每个响应的主机，它会列出 IP 地址、NetBIOS 计算机名称、登录用户名和 MAC 地址（例如以太网）。

该程序可用于安全检查、网络发现和取证调查。

  

**4.Nbtscan-Unixwiz**

nbtscan-unixwiz该软件包包含一个命令行工具，用于扫描本地或远程 TCP/IP 网络上的开放 NETBIOS 名称服务器，这是查找开放共享的第一步。它基于标准 Windows 工具 nbtstat 的功能，但它在一系列地址上运行，而不仅仅是一个地址。

  

**5.Ncat-W32**

Ncat 是一个功能丰富的网络实用程序，它可以从命令行跨网络读取和写入数据。Ncat 是为 Nmap 项目编写的，是对古老的 Netcat 进行了大幅改进的重新实现。它同时使用 TCP 和 UDP 进行通信，并被设计为一种可靠的后端工具，可以立即为其他应用程序和用户提供网络连接。Ncat 不仅适用于 IPv4 和 IPv6，还为用户提供了几乎无限的潜在用途。在 Ncat 的众多功能中，包括将 Ncat 链接在一起、将 TCP 和 UDP 端口重定向到其他站点、SSL 支持以及通过 SOCKS4 或 HTTP（CONNECT 方法）代理（以及可选的代理身份验证）进行代理连接的能力。一些通用原则适用于大多数应用程序，从而使您能够立即向通常不支持它的软件添加网络支持。

  

**6.Ncrack**

Ncrack 是一种高速网络认证破解工具。它旨在通过主动测试所有主机和网络设备的密码错误来帮助公司保护其网络。安全专家在审计客户时也依赖 Ncrack。Ncrack 使用模块化方法、类似于 Nmap 的命令行语法和可以根据网络反馈调整其行为的动态引擎进行设计。它允许对多个主机进行快速而可靠的大规模审计。Ncrack 的功能包括一个非常灵活的界面，允许用户完全控制网络操作，允许非常复杂的暴力攻击，易于使用的计时模板，类似于 Nmap 的运行时交互等等。支持的协议包括 RDP、SSH、http(s)、SMB、pop3(s)、VNC、FTP 和 telnet。

  

**7.Ncurses-Hexedit**

Hexedit 是一个文件编辑器，它允许编辑和查看十六进制文件，以及它的 ASCII 或 EBCDIC 文本等价物。标准编辑功能包括插入、删除、搜索（文本或字节搜索）、突出显示的更改、撤消、两种不同的查看格式和全屏文本快照。也允许编辑固定磁盘。包括一个二进制/八进制/十进制/十六进制转换器。

  

**8.Net-Snmp**

libnetsnmptrapd40

简单网络管理协议 (SNMP) 为代理（服务器）和客户端之间的管理信息交换提供了一个框架。

Net-SNMP 陷阱库包含用于接收 SNMP 陷阱和通知消息的函数。

  

**9.libsnmp-base**

简单网络管理协议 (SNMP) 为代理（服务器）和客户端之间的管理信息交换提供了一个框架。

该软件包包括 SNMP 库、代理和应用程序的文档和 MIB（管理信息库）。MIB 包含可以使用 SNMP 和应用程序管理的数据的正式描述。

注意：如果您希望 OID（对象标识符）解析为它们的文本描述，您需要激活非免费存储库并安装“snmp-mibs-downloader”包。

  

**10.libsnmp-dev**

简单网络管理协议 (SNMP) 为代理（服务器）和客户端之间的管理信息交换提供了一个框架。

Net-SNMP 开发文件包括开发自定义 SNMP 应用程序所需的库头文件、静态库、net-snmp-config 脚本和文档。

  

**11.libsnmp-perl**

简单网络管理协议 (SNMP) 为代理（服务器）和客户端之间的管理信息交换提供了一个框架。

Net-SNMP Perl5 支持文件提供 Perl 函数，用于将 SNMP 集成到用 Perl 编写的应用程序中。

  

**12.libsnmp40**

简单网络管理协议 (SNMP) 为代理（服务器）和客户端之间的管理信息交换提供了一个框架。

Net-SNMP 库包含用于构建、发送、接收、解码和操作 SNMP 请求和响应的通用函数。

  

**13.smp**

简单网络管理协议 (SNMP) 为代理（服务器）和客户端之间的管理信息交换提供了一个框架。

Net-SNMP 应用程序是一组命令行客户端，用于向代理发出 SNMP 请求。

  

**14.snmpd**

简单网络管理协议 (SNMP) 为代理（服务器）和客户端之间的管理信息交换提供了一个框架。

Net-SNMP 代理是一个守护进程，它侦听来自客户端的传入 SNMP 请求并提供响应。

  

**15.smptrapd**

简单网络管理协议 (SNMP) 为代理（服务器）和客户端之间的管理信息交换提供了一个框架。

snmptrapd 是一个 SNMP 应用程序（守护进程），它接收和记录 SNMP TRAP 和 INFORM 消息。

  

**16.tkmib**

简单网络管理协议 (SNMP) 为代理（服务器）和客户端之间的管理信息交换提供了一个框架。

Net-SNMP MIB（管理信息库）浏览器为 Net-SNMP 工具提供图形前端。它可用于浏览 MIB 树并以交互方式向 SNMP 代理发送请求。

  

**17.Netcat**

netcat-traditional

一个简单的 Unix 实用程序，它使用 TCP 或 UDP 协议通过网络连接读取和写入数据。它被设计成一个可靠的“后端”工具，可以直接使用或由其他程序和脚本轻松驱动。同时，它还是一个功能丰富的网络调试和探索工具，因为它几乎可以创建您需要的任何类型的连接，并且具有几个有趣的内置功能。

这是霍比特人编写的“经典”网猫。它缺少 netcat-openbsd 中的许多功能。

  

**18.Netdiscover**

Netdiscover是一个主动/被动地址侦察工具，主主要针对那些在您驾驶时没有dhcp服务器的无线网络开发。它也可用于集线器/交换网络。

它建立在 libnet 和 libpcap 之上，它可以通过主动发送 ARP请求，可以被动检测或搜索在线主机。

Netdiscover 还可用于检查您的网络 ARP 流量，或使用自动扫描模式查找网络地址，该模式将扫描常见的本地网络。

Netdiscover 使用 OUI 表来显示发现的每个 MAC 地址的供应商，这对于安全检查或渗透测试非常有用。

  

**19.Netkit-Ftp**

FTP

这是 ARPANET 标准文件传输协议的用户界面。该程序允许用户与远程网络站点之间传输文件。

  

**20.Netkit-Telnet**

Telnet

telnet 命令用于使用 TELNET 协议与另一台主机进行交互通信。

出于远程登录的目的，当前的客户端可执行文件应该被贬低以支持 ssh 客户端，或者在某些情况下使用 telnet-ssl 或 Kerberized TELNET 客户端等变体。最重要的原因是这种实现以明文形式交换用户名和密码。

另一方面，本程序确实满足了网络诊断的常见用例，例如 SMTP 服务的协议测试，因此它可以变得足够方便。

telnetd

in.telnetd 程序是一个支持 DARPA telnet 交互通信协议的服务器。

通常应该放弃这个遗留服务器，转而使用现代 ssh 服务器，因为这个实现只能以明文形式处理密码和用户名。其他变体，如 telnetd-ssl 和一系列 Kerberized TELNET 服务器，能够通过提供安全形式的身份验证和加密来改进这一点。

  

**21.Netkit-Tftp**

Tftp

Tftp 是 Internet TFTP（普通文件传输协议）的用户界面，它允许用户与远程机器传输文件。远程主机可以在命令行中指定，在这种情况下 tftp 使用主机作为未来传输的默认主机。

Tftpd

Tftpd 是一个支持 Internet Trivial File Transfer Protocol (RFC 783) 的服务器。TFTP 服务器在 \`tftp' 服务描述中指定的端口上运行；见服务(5)。服务器通常由 inetd(8) 启动。

警告：不支持“tsize”，这是某些 tftp 客户端（尤其是 PXE）和其他各种网络引导客户端所必需的。对于那些，使用 atftpd 或 tftpd-hpa。

  

**22.Netmask**

如果您偶尔使用防火墙或路由器（可能将其用作 shell 脚本的助手），这是一个非常方便的小程序。它可以确定最小的网络掩码集来指定主机范围。它还可以在常见的 IP 网络掩码和地址格式之间进行转换。

  

**23.Netsed**

NetSED 是一个小巧而方便的实用程序，旨在实时更改通过您的网络转发的数据包的内容。它对于网络数据包更改、伪造或操纵非常有用。NetSED 支持：

黑盒协议审计——每当有两个或更多专有盒子使用一些未记录的协议进行通信时。通过在正在进行的传输中强制更改，您将能够测试检查的应用程序是否可以声明为安全的；

模糊生成实验、完整性测试——每当您对应用程序进行稳定性测试以查看它如何关心数据完整性时；

其他常见用例：欺骗性传输、内容过滤、协议转换——任何最适合您手头任务的。

它理想地补充了基于 ngrep、netcat 和 tcpdump 的工具套件。

  

**24.Netsniff-Ng**

netsniff-ng 是用于数据包检查的高性能 Linux 网络嗅探器。可用于协议分析、逆向工程或网络调试。性能的提升是通过“零复制”机制实现的，因此内核不需要将数据包从内核空间复制到用户空间。

netsniff-ng 工具包目前包含以下实用程序：

netsniff-ng：零拷贝数据包分析器，pcap 捕获/重放工具

trafgen：多线程低级零拷贝网络数据包生成器

mausezahn：用于带有 Cisco-CLI 的设备的高级数据包生成器

ifpps：一个顶级的内核网络和系统统计工具

curvetun：基于curve25519的轻量级多用户IP隧道

astraceroute：自主系统跟踪路由和 DPI 测试实用程序

flowtop：一个类似top的netfilter连接跟踪工具

bpfc：\[seccomp-\]BPF（伯克利包过滤器）编译器，JIT 反汇编器

Netwag 是 netwox 的图形前端，包含 200 多个工具。Netwag 允许人们轻松地：

构建命令行

**27.Nextnet**

这个包包含一个用 Go 编写的枢轴点发现工具。

  

**28.Nfs-Utils**

nfs-common

在任何使用 NFS 的机器上使用这个包，无论是作为客户端还是服务器。程序包括：lockd、statd、showmount、nfsstat、gssd、idmapd 和 mount.nfs。

  

nfs-kernel-server

NFS 内核服务器是目前推荐用于 Linux 的 NFS 服务器，具有 NFSv3 和 NFSv4 等功能，通过 GSS 支持 Kerberos 等等。它也明显比用户空间 NFS 服务器（来自 unfs3 和 nfs-user-server 包）更快并且通常更可靠。但是，它比用户空间服务器更难调试，并且功能集略有不同。

该软件包包含使用 NFS 内核服务器所需的用户空间支持。大多数希望设置 NFS 服务器的管理员都希望安装此软件包。

  

**29.Ngrep**

ngrep 努力提供大部分 GNU grep 的共同特性，并将它们应用到网络层。ngrep 是一个 pcap-aware 工具，它允许您指定扩展的正则表达式以匹配数据包的数据负载。它目前识别跨以太网、PPP、SLIP 和空接口的 TCP、UDP 和 ICMP，并以与更常见的数据包嗅探工具（例如 tcpdump 和 snoop）相同的方式理解 bpf 过滤器逻辑。

  

**30.Nikto**

Nikto 是用 Perl 编写的可插拔 Web 服务器和 CGI扫描器，使用 rfp 的 LibWhisker 执行快速安全或信息检查。

特征：

易于更新的 CSV 格式检查数据库

以纯文本或 HTML 格式输出报告

可用HTTP版本自动切换

通用和特定服务器软件检查

SSL 支持（通过 libnet-ssleay-perl）

代理支持（带身份验证）

饼干支持

  

**31.Nipper-Ng**

Nipper-ng 是下一代 nippper，并将始终保持免费和开源。该软件将用于观察许多不同设备类型的安全配置，例如网络基础设施的路由器、防火墙和交换机。

这是 GNUv3 GPL 代码的 nipper 0.11.10 版本的一个分支。

  

**32.Nishang**

Nishang 是一个框架和脚本和有效负载的集合，它允许在渗透测试期间使用 PowerShell 进行攻击性安全和后期利用。脚本是根据作者在实际渗透测试中的要求编写的。

  

**33.Nmap**

Ncat

ncat 是 NMAP 项目对 Netcat 的重新实现，提供原始实现中存在的大部分功能，以及一些新功能，例如 IPv6 和 SSL 支持。端口扫描支持已被删除。

  

**34.Ndiff**

Ndiff 是一个帮助比较 Nmap 扫描的工具。它需要两个 Nmap XML 输出文件并打印它们之间的差异：主机启动和关闭，端口打开或关闭，等等。它可以以人类可读的文本或机器可读的 XML 格式生成输出。

  

**35.Nmap**

Nmap 是用于网络探索或安全审计的实用程序。它支持 ping 扫描（确定哪些主机处于运行状态）、许多端口扫描技术、版本检测（确定服务协议和应用程序版本监听端口）和 TCP/IP 指纹（远程主机操作系统或设备识别）。Nmap 还提供灵活的目标和端口规范、诱饵/隐形扫描、sunRPC 扫描等。大多数 Unix 和 Windows 平台都支持 GUI 和命令行模式。还支持多种流行的手持设备，包括 Sharp Zaurus 和 iPAQ。

  

nmap-common

Nmap 是用于网络探索或安全审计的实用程序。它支持 ping 扫描（确定哪些主机处于运行状态）、许多端口扫描技术、版本检测（确定服务协议和应用程序版本监听端口）和 TCP/IP 指纹（远程主机操作系统或设备识别）。Nmap 还提供灵活的目标和端口规范、诱饵/隐形扫描、sunRPC 扫描等。大多数 Unix 和 Windows 平台都支持 GUI 和命令行模式。还支持多种流行的手持设备，包括 Sharp Zaurus 和 iPAQ。

这个包包含所有架构共享的 nmap 文件。

  

**36.Nmapsi4**

NmapSI4 是一个完整的基于 Qt 的 GUI，其设计目标是为用户提供一个完整的 nmap 接口，以便管理此电源安全网络扫描器的所有选项。
