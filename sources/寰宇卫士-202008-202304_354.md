# KALI工具介绍专栏系列（4）

**1.Backdoor-Factory**

通过直接修补 exe/dll 将 shellcode 注入 win32/64 PE 文件，32/64 位 ELF 二进制文件，以继续正常的文件执行（如果 shellcode 支持）。

  

一些可执行文件具有内置保护，因此这不适用于所有 ELF/PE 文件。建议先测试目标 ELF/PE 文件，然后再将它们部署到客户端或在练习中使用它们

  

**2.Bed**

BED 是一个程序，旨在检查守护进程是否存在潜在的缓冲区溢出、格式字符串等。

  

**3.Beef-Xss**

BeEF 是浏览器开发框架的缩写。它是一个专注于网络浏览器的渗透测试工具。

  

随着对客户端（包括移动客户端）的网络攻击的担忧日益增加，BeEF 允许专业渗透测试人员通过使用客户端攻击媒介来评估目标环境的实际安全状况。与其他安全框架不同，BeEF 超越了强化的网络边界和客户端系统，并在一个敞开的门：Web 浏览器的上下文中检查可利用性。BeEF 将挂钩一个或多个 Web 浏览器，并将它们用作启动定向命令模块和从浏览器上下文中进一步攻击系统的滩头阵地。

  

**4.Berate-Ap**

该软件包包含一个用于编排恶意 Wi-Fi 接入点的脚本。它还可以处理常规的 hostapd AP 并轻松创建 AP。

  

**5.Bettercap**

该软件包包含用于 802.11、BLE 和以太网网络侦察和攻击的瑞士军刀。

  

**6.Bind9**

Berkeley Internet Name Domain (BIND 9) 实现了一个 Internet 域名服务器。BIND 9 是 Internet 上使用最广泛的名称服务器软件，并得到 Internet Software Consortium ( www.isc.org) 的支持。

  

**7.arpaname**

将 IP 地址转换为相应的 ARPA 名称

  

**8.ddns-confgen**

Ddns 密钥生成工具

  

**9.dnssec-importkey**

从外部系统导入 DNSKEY 记录，以便对其进行管理

  

**10.named**

互联网域名服务器

  

**11.named-journalprint**

以可读的形式打印区域日志

  

**12.named-nzd2nzf**

将新西兰元数据库转换为 NZF 文本格式

  

**13.named-rrchecker**

单个 DNS 资源记录的语法检查器

  

**14.nsec3hash**

生成 NSEC3 哈希

  

**15.tsig-keygen**

Ddns 密钥生成工具

  

**16.Bing-Ip2hosts**

这个包包含一个 Bing.com 网络爬虫，它通过 IP 地址发现主机名。Bing 是 Microsoft 的旗舰搜索引擎，前身为 MSN 搜索和 Live Search。

  

它提供了搜索引擎独有的功能 - 它允许通过 IP 地址进行搜索。Bing-ip2hosts 使用此功能。

  

它可用于发现子域和其他相关域。它还有助于识别在共享托管环境中托管的网站。该技术遵循渗透测试或漏洞赏金的侦察阶段的最佳实践，以扩大目标的攻击面。

  

与其他许多网络抓取 Bing 的侦察工具不同，该工具具有智能抓取行为，可以最大限度地发现主机名。

  

**17.Binwalk**

Binwalk 是一个工具，用于在给定的二进制图像中搜索嵌入的文件和可执行代码。具体来说，它旨在识别嵌入在固件映像中的文件和代码。Binwalk 使用 libmagic 库，因此它与为 Unix 文件实用程序创建的魔术签名兼容。

  

Binwalk 还包括一个自定义魔术签名文件，其中包含固件映像中常见文件的改进签名，例如压缩/存档文件、固件头文件、Linux 内核、引导加载程序、文件系统等。

  

**18.Bloodhound**

这个包包含 BloodHound，一个单页 Javascript Web 应用程序。BloodHound 使用图论来揭示 Active Directory 环境中隐藏且通常是意外的关系。攻击者可以使用 BloodHound 轻松识别高度复杂的攻击路径，否则无法快速识别。防御者可以使用 BloodHound 来识别和消除那些相同的攻击路径。蓝队和红队都可以使用 BloodHound 轻松深入了解 Active Directory 环境中的权限关系。

  

**19.Bluelog**

Bluelog 是一种蓝牙扫描仪，旨在尽快告诉您一个区域内有多少可发现的设备。它旨在用作现场调查工具，确定周围环境中可能存在的蓝牙目标数量。

  

**20.Blueranger**

BlueRanger 是一个简单的 Bash 脚本，它使用链接质量来定位蓝牙设备无线电。它发送 l2cap（蓝牙）ping 以在蓝牙接口之间创建连接，因为大多数设备允许 ping 无需任何身份验证或授权。链路质量越高，距离设备越近（理论上）。

  

使用蓝牙 1 类适配器进行远程位置检测。切换到 3 类适配器以获得更精确的短距离定位。精度和准确度取决于蓝牙适配器的构建质量、干扰和远程设备的响应。即使两个设备都没有运动，也可能会发生波动。

  

**21.Bluesnarfer**

Bluesnarfer用于扫描远程设备地址，并获取设备信息。

  

**22.Bluez**

**23.bluetooth**

该软件包提供了 Bluez 蓝牙堆栈支持的所有不同插件。

  

**24.bluez**

这个包包含使用蓝牙设备的工具和系统守护进程。

  

BlueZ 是官方的 Linux 蓝牙协议栈。它是在 GNU 通用公共许可证 (GPL) 下分发的开源项目。

  

**25.bluez-cups**

此软件包包含一个驱动程序，可让 CUPS 打印到蓝牙连接的打印机。

  

**26.bluez-hcidump**

hcidump 实用程序允许监控蓝牙活动。它提供蓝牙流量的分解，并可以显示来自更高级别协议（如 RFCOMM、SDP 和 BNEP）的数据包。

  

**27.bluez-meshd**

蓝牙 Mesh 网络是一项新的蓝牙功能，它扩展了“蓝牙低功耗 (BLE)”。

  

该软件包提供了提供蓝牙网状网络功能的守护进程 (meshd) 和工具。

  

**28.bluez-obexd**

这个包包含一个 OBEX(OBject EXchange) 守护进程。

  

OBEX 是促进设备之间二进制对象交换的通信协议。

  

**29.bluez-source**

这个包包含构建 bluez 所需的源代码和补丁。

  

**30.bluez-test-scripts**

这个包包含使用 BlueZ 的测试脚本。

  

**31.bluez-test-tools**

这个包包含使用 BlueZ 的测试工具。

  

**32.Braa**

Braa 是一个大规模的 snmp 扫描器。这种工具的预期用途当然是进行 SNMP 查询 - 但与来自 net-snmp 的 snmpget 或 snmpwalk 不同，它能够在单个进程中同时查询数十或数百台主机。因此，它消耗很少的系统资源并且扫描速度非常快。

  

Braa 实现了它自己的 snmp 堆栈，所以它不需要任何像 net-snmp 这样的 SNMP 库。实现很脏，只支持几种数据类型，无论如何都不能说“符合标准”！它被设计得很快，而且很快。出于这个原因（好吧，也因为作者懒惰；），braa 中没有 ASN.1 解析器 - 用户必须知道 OID 的数值（例如 .1.3.6.1.2.1.1.5.0 而不是system.sysName.0）。

  

**33.Bruteforce-Salted-Openssl**

bruteforce-salted-openssl 对于安全、渗透测试和取证调查很有用，可以尝试查找使用 openssl 命令加密的文件的密码或密码。它可以通过两种方式使用：

  

在穷举模式下，程序会尝试通过尝试所有可能的密码来解密文件。如果您对密码有所了解（即您忘记了密码的一部分，但仍然记得大部分），这将特别有用。在不知道任何信息的情况下查找文件的密码会花费太多时间（除非密码非常短和/或弱）。

  

在字典模式下，程序尝试通过尝试文件中包含的所有密码来解密文件。该文件每行必须有一个密码。

  

**34.Brutespray**

这个 Python 脚本采用 nmap GNMAP/XML 输出，并使用 Medusa 使用默认凭据自动暴力破解服务。BruteSpray 甚至可以通过使用 Nmap 中的 -sV 来查找非标准端口。

可使用特定的用户列表 ( unix\_users.txt) 和密码列表 ( password.lst)攻击所有服务。

交互模式，仅暴力破解FTP服务。

  

**35.Btscanner**

btscanner 是一种专门设计用于从蓝牙设备中提取尽可能多的信息而无需配对的工具。详细信息屏幕提取 HCI 和 SDP 信息，并保持开放连接以监控 RSSI 和链接质量。btscanner 基于 BlueZ 蓝牙堆栈（包含在最新的 Linux 内核中）和 BlueZ 工具集。btscanner 还包含 IEEE OUI 编号和类查找表的完整列表。使用从这些来源收集的信息，可以对主机设备类型进行有根据的猜测。

  

**36.Bulk-Extractor**

bulk\_extractor 是一个 C++ 程序，它扫描磁盘映像、文件或文件目录并提取有用的信息，而无需解析文件系统或文件系统结构。结果存储在特征文件中，可以使用自动化工具轻松检查、解析或处理这些文件。bulk\_extractor 还会创建它找到的特征的直方图，因为更常见的特征往往更重要。

  

**37.Bully**

Bully 是 WPS 蛮力攻击的新实现，用 C 编写。它在概念上与其他程序相同，因为它利用了 WPS 规范中的（现在众所周知的）设计缺陷。与原始的 reaver 代码相比，它有几个优点。这些包括更少的依赖性、改进的内存和 CPU 性能、正确处理字节顺序以及更强大的选项集。

通过监听模式下的无线接口攻击无线ESSID。

  

**38.Burpsuite**

Burp Suite 是一个用于执行 Web 应用程序安全测试的集成平台。其各种工具可无缝协作以支持整个测试过程，从应用程序攻击面的初始映射和分析，到查找和利用安全漏洞。

  

Burp 为使用者提供完全控制，让使用者将高级手动技术与最先进的自动化相结合，使得工作更快、更有效、更有趣。

  

**39.Bytecode-Viewer**

Bytecode-Viewer是一个高级轻量级 Java 字节码查看器、GUI Java 反编译器、GUI 字节码编辑器、GUI Smali、GUI Baksmali、GUI APK 编辑器、GUI Dex 编辑器、GUI APK 反编译器、GUI DEX 反编译器、GUI Procyon Java 反编译器、GUI Krakatau、GUI CFR Java反编译器、GUI FernFlower Java 反编译器、GUI DEX2Jar、GUI Jar2DEX、GUI Jar-Jar、十六进制查看器、代码搜索器、调试器等等。

  

还有一个插件系统可以让你与加载的类文件进行交互，例如你可以编写一个字符串反混淆器、一个恶意代码搜索器或其他你能想到的东西。您可以使用预先编写的插件之一，也可以编写自己的插件。它支持常规脚本。一旦插件被激活，它将使用加载在 BCV 中的每个类的 ClassNode ArrayList 来执行插件，这允许用户完全使用 ASM 处理它。

  

它目前由 Konloch 维护和开发。
